**날짜**: 2024-12-24

**도입된 CLI 버전**: `v1.1.0`

![v1.1.0 CLI text-to-i18n 데모](/images/text-to-i18n.gif)

Nuxt I18n Micro CLI의 새로운 `text-to-i18n` 명령을 발표하게 되어 기쁩니다! 이 강력한 기능은 코드베이스에서 하드코딩된 텍스트 문자열을 추출해 i18n 번역 키로 변환하는 과정을 자동화합니다. 시간을 절약하고 오류를 줄이며 현지화 워크플로를 간소화하도록 설계되었습니다.

## 주요 이점 {#key-benefits}

- **자동 텍스트 추출**: Vue 템플릿, JavaScript, TypeScript 파일을 스캔합니다.
- **매끄러운 키 생성**: 파일 경로와 내용을 기반으로 구조화된 번역 키를 만듭니다.
- **효율적인 번역 관리**: 기존 항목을 유지하면서 번역 파일을 업데이트합니다.

## 작동 방식 {#how-it-works}

1. **파일 스캔**: `pages`, `components`, `plugins` 같은 주요 디렉터리의 파일을 처리합니다.
2. **텍스트 처리**: 번역 가능한 문자열을 식별하고 추출하여 고유한 키를 생성합니다.
3. **번역 업데이트**: 새 키를 번역 파일에 자동으로 삽입하고 중첩 구조를 유지합니다.

## 사용법 {#usage}

```bash
i18n-micro text-to-i18n [options]
```

예시:

```bash
i18n-micro text-to-i18n --translationFile locales/en.json --context auth
```

## 변환 예시 {#example-transformations}

### 이전 {#before}

```vue
<template>
  <div>
    <h1>Welcome to our site</h1>
    <p>Please sign in to continue</p>
  </div>
</template>
```

### 이후 {#after}

```vue
<template>
  <div>
    <h1>{{ $t('pages.home.welcome_to_our_site') }}</h1>
    <p>{{ $t('pages.home.please_sign_in') }}</p>
  </div>
</template>
```
