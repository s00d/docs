**날짜**: 2026-07-30

**버전**: `v3.24.0`

![v3.24.0 릴리스](/images/3.24.0.png)

Node 프로덕션 빌드는 더 이상 번역 페이로드를 Nitro `serverAssets` / Rollup `raw:`로 임베드하지 않습니다(대규모 카탈로그에서 빌드 RSS가 수 GB에 달함). SSR은 클라이언트가 가져오는 것과 동일한 `/{apiBaseUrl}/{page}/{locale}/data.json` 트리를 `public/`에서 `readFile`로 읽습니다. Edge는 Nitro 임베드를 유지하며 `mode: 'source'`를 사용하는 것이 좋습니다.

## 새로운 기능 {#what’s-new}

### Node: `public/<apiBaseUrl>`에서 SSR {#node-ssr-from-public/&lt;apibaseurl&gt;}

- 디스크에서 `public/`을 제공하는 Node 프리셋은 Nitro `serverAssets`를 등록하지 **않습니다**.
- 페이로드는 `public/<apiBaseUrl>`(기본값 `_locales`)에 `{page}/{locale}/data.json` 형태로 복사됩니다.
- SSR은 `#i18n-internal/payload-source` → `readFile`을 통해 이를 로드합니다(프로덕션 경로는 `.output/server` 옆).
- `translationPayloads.serverAssets: true`는 여전히 "로컬 SSR"을 의미하며, `publicAssets`가 false여도 해당 공개 복사본을 **강제로** 생성합니다.

플레이그라운드(이전 `serverAssets` 임베드 대비): 약 **1.25 GB** / 약 6–7초 / `raw`=0 대 약 **3 GB** / 약 13초 / 약 170개의 raw 청크.

### Edge: 필요할 때만 `serverAssets` 사용 {#edge-serverassets-only-when-needed}

- Edge(`nitro.node === false`)는 여전히 `mode`와 동일한 레이아웃으로 Nitro `serverAssets`(`assets:i18n`)를 통해 임베드합니다.
- Edge는 공개 복사본을 강제하지 **않습니다**. CDN/정적 호스팅에는 `publicAssets: true`를 설정하세요.
- Edge + `mode: 'premerged'` 조합이면 경고를 표시합니다(대규모 카탈로그에는 `mode: 'source'` 권장).

### `publicDir`이 클라이언트 URL과 일치 {#publicdir-aligns-with-client-urls}

- `translationPayloads.publicDir`의 기본값은 `translationDir`이 아니라 **`apiBaseUrl`**입니다.
- 사전 병합된 공개/Edge 트리는 `{page}/{locale}/data.json`이며, `$fetch('/_locales/...')`와 일치합니다.
- 모듈 기본값은 더 이상 중첩된 `publicAssets: true`를 설정하지 않습니다(Nuxt의 깊은 병합 때문에 `mode: 'source'`에서도 공개 복사본이 강제되었습니다).

[모듈 옵션 — `translationPayloads`](/ko/api/module-options#translationpayloads), [배포 — 서버리스 및 Edge](/ko/guide/deployment#serverless-and-edge), [캐시 및 스토리지 아키텍처](https://s00d.github.io/nuxt-i18n-micro/v3/api/i18n-cache-api)를 참고하세요.

## 호환성이 깨지는 변경 사항 {#breaking-changes}

- **Nuxt SSR HTML 페이로드에 사전이 포함되지 않습니다.** `payload.data['i18n-ssr-chunks']`, `setSsrChunk`, `seedFromSsrChunks`가 **제거되었습니다**. `@nuxtjs/i18n`(`experimental.preload: false`)과 같은 기본 방식입니다. 서버는 SSR을 위해 번역을 메모리에 유지하고, 클라이언트는 플러그인 설정 중에 `/{apiBaseUrl}/.../data.json`을 로드합니다(`await switchContext`).
- **`prerenderRoutes`의 기본값은 `false`입니다.** `publicAssets`가 아직 트리를 쓰지 않은 상황에서 Nitro가 핸들러 라우트를 생성해야 할 때만 활성화하세요(사전 병합된 `publicAssets`는 이미 `{page}/{locale}/data.json`을 생성합니다).
- **`publicDir`의 기본값은 `translationDir`이 아니라 `apiBaseUrl`입니다.** `publicDir`을 명시적으로 설정하지 않으면 정적 출력이 예를 들어 `public/locales/...`에서 `public/_locales/{page}/{locale}/data.json`으로 이동합니다.
- **사전 병합 스토리지 레이아웃**이 이제 `{page}/{locale}/data.json`입니다(이전에는 `pages/{page}/{locale}.json`). 이전 구조로 Nitro/스토리지 키를 읽거나 트리를 복사하던 모든 코드는 업데이트해야 합니다.
- **Node에서 `serverAssets: true`는 더 이상 Nitro 임베드를 의미하지 않습니다.** 공개 복사본을 통한 로컬 SSR을 의미합니다. 실제 Rollup `raw:` 임베드는 Edge 전용으로 남습니다.

## 마이그레이션 {#migration}

1. `payload.data['i18n-ssr-chunks']`를 읽거나 `seedFromSsrChunks` / `setSsrChunk`를 호출하는 코드를 모두 제거하세요.
2. 순수 정적 호스트의 경우: 기본 사전 병합 + `publicAssets`를 유지하거나(파일은 `/_locales/.../data.json`에 위치), `prerenderRoutes: true`를 설정하거나 / 페이로드를 CDN에 호스팅하세요.
3. Cloudflare / 기타 Edge의 경우: 대규모 카탈로그에서는 `translationPayloads: { mode: 'source' }`를 설정하고, 정적/CDN 복사본이 필요할 때만 `publicAssets: true`를 추가하세요.
4. `public/<translationDir>` 아래의 페이로드에 의존했다면 `translationPayloads.publicDir`을 설정하거나 도구가 `public/<apiBaseUrl>`을 가리키도록 하세요.

## 수정: 사전 병합된 공개 페이로드에서 비활성화된 로케일 건너뛰기 {#fix-skip-disabled-locales-in-premerged-public-payloads}

`preMergeLocales`는 이제 병합에 전달된 로케일에 대해서만 `{page}/{locale}/data.json`을 씁니다(빌드 시점의 `locale.disabled: true`는 제외됩니다). 이전에는 디스크의 모든 JSON 로케일이 `public/`으로 복사되어, Nitro 정적 서버가 비활성화된 로케일을 200으로 제공하고 핸들러를 우회했습니다. 런타임 `disabledLocales`로는 이미 빌드된 파일의 게시를 취소할 수 없습니다. `publicAssets` / Node 공개 SSR 복사가 켜져 있을 때는 빌드 시 `locale.disabled`를 사용하세요.

## 왜 중요한가 {#why-it-matters}

- Node 빌드가 가볍게 유지됩니다. 번역 카탈로그로 인해 Rollup `raw:` 메모리가 수 GB로 치솟지 않습니다.
- 공개 파일과 클라이언트 `$fetch` URL이 하나의 경로 레이아웃을 공유하므로, 특별한 재매핑 없이 정적 호스팅이 동작합니다.
- Edge는 중복된 공개 트리를 강제하지 않고도 압축된 `source` 페이로드를 임베드할 수 있습니다.
