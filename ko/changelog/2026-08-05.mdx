릴리스: **v3.22.0 → v3.26.0**.

## 새로운 기능

- **번역 메모리 API.** `$resolveTranslations()`와 `$setTranslation(key, value)`로 런타임에 활성 로케일 사전을 읽고 패치합니다. DevTools, 테스트, 인앱 편집기에 유용합니다. [메서드](/api/methods#resolvetranslations)를 참고하세요.
- **명명된 `numberFormats` 및 `datetimeFormats`.** Vue I18n 호환 명명된 형식을 로케일별로 설정하고, `$tn(1000, 'currency')` 또는 `$td(date, 'short')`을 호출하세요. [모듈 옵션](/api/module-options)을 참고하세요.
- **`/_locales` 페이로드에 대한 HTTP 캐시 제어.** 새로운 [`httpCacheDuration`](/api/module-options)이 번역 페이로드에 `Cache-Control: public, max-age=…, immutable`을 설정합니다. 기본값은 1년이며, `?v={dateBuild}` 캐시 무효화와 안전하게 짝을 이룹니다.
- **압축된 번역 페이로드.** `nitro.compressPublicAssets`가 활성화되면 공용 번역 페이로드가 자동으로 압축됩니다. [성능 가이드](/guides/performance)를 참고하세요.
- **`splitLocaleRoutes` 유틸리티.** 단일 프로그래매틱 목록에서 `pages`와 `globalLocaleRoutes`를 모두 빌드합니다(`pages:extend` 시나리오용). 라우트 이름으로 키가 지정됩니다. [사용자 정의 로케일 라우트](/guides/custom-locale-routes#programmatic-routes-pagesextend--244)를 참고하세요.
- **SEO 기본에 대한 `site.url` 대체.** `metaBaseUrl`이 설정되지 않은 경우, SEO 태그는 `nuxt-site-config`가 있으면 `site.url`로 대체되고 그렇지 않으면 요청 원본으로 대체됩니다. [`metaBaseUrl`](/api/module-options)을 참고하세요.

## 업데이트

- **Astro 어댑터.** 라우팅 컨텍스트 격리, `numberFormats`와 `datetimeFormats` 배선 추가.
- **React 및 Preact.** `I18nSwitcher`가 이제 올바른 `aria-haspopup` 및 `aria-expanded` 속성을 설정합니다.
- **벤치마크.** 성능 벤치마크가 citty 기반 CLI로 이동되었습니다.
- **콘텐츠 지문 `dateBuild`.** 기본 `dateBuild`가 이제 콘텐츠 지문이므로, 페이로드 `?v=`는 번역이 실제로 변경될 때만 변경됩니다.

## 수정

- **라우팅.**
  - 지역화된 라우트 매처가 이제 대시가 있는 경로와 중첩된 경로 및 매개변수 세그먼트를 올바르게 처리합니다.
  - 자식 라우트가 절대 경로일 때 중첩된 부모가 유지됩니다.
  - `hreflang`은 라우팅 코드가 아닌 로케일 `iso`에서 방출됩니다.
  - `no_prefix`에서 로케일 전환이 이제 pushing 대신 history를 replace합니다.
- **리디렉션.**
  - 쿠키 및 `Accept-Language` 기본 설정 리디렉션에 대해 `autoDetectPath`가 존중됩니다.
  - `autoDetectPath: '/'`에서 `localeRoutes` 별칭이 보존됩니다.
- **번역.**
  - `null`을 반환하는 사용자 정의 복수형 함수가 이제 기본 복수형 규칙으로 대체됩니다.
  - 번역 레이어가 병합 시 덤프를 평탄화하지 않습니다.
  - 비활성화된 로케일이 premerged 공용 페이로드에서 제외됩니다.
  - HMR은 no-op 파일 쓰기를 건너뛰고 루트 로케일 변경 시 동시에 다시 병합합니다.
- **전환기.** `disabled` 로케일을 숨기고 `customDisabledLinkStyle`과 active-style 우선순위를 복원합니다.
- **모듈.** Nuxt Kit 호환성을 위해 unplugin Vite 8 `Plugin` 타입을 브리지했습니다.
- **SSR.** Node SSR이 이제 공용 페이로드에서 읽습니다 (Rollup `raw:` 임포트 없음).

## 주요 변경 사항 (v3.22.0)

- SSR 청크가 `useState('i18n-ssr-chunks')`에서 `nuxtApp.payload.data['i18n-ssr-chunks']`로 이동되었습니다.
- `getAllTranslations()`가 `@i18n-micro/vue`에서 제거되었습니다. 대신 `resolveTranslations()`, `getStorage()`, 또는 `getRouteCache()`를 사용하세요.
- 기본 `dateBuild`가 이제 콘텐츠 지문이므로, 업그레이드 시 페이로드 `?v=`가 한 번 변경됩니다.
