**도입 버전**: `v1.58.0`

![v1.58.0 release](/images/1.58.0.png)

Nuxt I18n Micro의 **새로운 번역 로딩 알고리즘** 출시를 알리게 되어 매우 기쁩니다. 이번 업데이트는 상당한 성능 향상, 더 깔끔한 아키텍처, 더 효율적인 메모리 사용을 제공합니다.

## 새로운 기능 {#what’s-new}

새로운 번역 로딩 알고리즘은 다음에 중점을 둡니다:

1. **최적화된 파일 병합**: 번역을 더 효율적으로 처리하도록 딥 머지 기능을 개선했습니다.
2. **캐싱 개선**: 사전 렌더링된 번역에 서버 스토리지를 활용하여 중복 연산을 줄였습니다.
3. **간소화된 코드**: 유지보수성을 높이기 위해 파일 경로와 구조를 단순화했습니다.

---

## 주요 이점 {#key-benefits}

### **1. 더 빠른 빌드 시간** {#1-faster-build-times}

새 알고리즘은 번역 파일을 효율적으로 처리하고 메모리 오버헤드를 최소화하여 빌드 시간을 줄입니다.

- **이전 빌드 시간**: 7.20초
- **새 빌드 시간**: 6.91초
- **개선**: **4.03% 더 빠름**

### **2. CPU 사용량 감소** {#2-reduced-cpu-usage}

빌드 및 스트레스 테스트 중 최대 및 평균 CPU 사용량이 낮아졌습니다:

- **빌드 최대 CPU**: **257.60%** → **198.20%** (23.06% 감소)
- **스트레스 테스트 평균 CPU**: **93.85%** → **89.14%** (5.01% 감소)

### **3. 메모리 사용량 감소** {#3-lower-memory-usage}

빌드와 런타임 스트레스 테스트 전반에서 메모리 사용량이 크게 최적화되었습니다:

- **빌드 최대 메모리**: **1286.00 MB** → **885.19 MB** (31.15% 감소)
- **스트레스 테스트 최대 메모리**: **624.22 MB** → **429.52 MB** (31.20% 감소)

### **4. 향상된 응답 시간** {#4-enhanced-response-times}

스트레스 테스트 응답 시간이 대폭 개선되었습니다:

- **평균 응답 시간**: **411.50 ms** → **9.30 ms** (97.74% 더 빠름)
- **최대 응답 시간**: **2723.00 ms** → **187.00 ms** (93.13% 더 빠름)

### **5. 요청 처리량 증가** {#5-increased-request-throughput}

새 알고리즘은 초당 처리되는 요청 수를 늘립니다:

- **초당 요청 수**: **288.00** → **305.00** (5.90% 증가)

---

## 왜 중요한가 {#why-it’s-important}

현지화는 글로벌 애플리케이션에 필수적이며, 번역 로딩 성능을 개선하면 다음에 직접적인 영향을 줄 수 있습니다:

- **사용자 경험**: 더 빠른 응답 시간은 더 매끄러운 사용자 경험으로 이어집니다.
- **확장성**: 리소스 사용량이 줄어 높은 트래픽을 더 잘 처리할 수 있습니다.
- **개발자 생산성**: 빌드 시간 단축과 단순화된 코드베이스가 워크플로를 간소화합니다.

---

## 작동 방식 {#how-it-works}

1. **효율적인 딥 머지**

- 번역 병합을 더 지능적으로 처리하도록 알고리즘을 다시 작성하여 메모리 오버헤드를 최소화하고 작업 속도를 높였습니다.

2. **스마트 캐싱**

- 이제 사전 렌더링 중 번역을 캐시하는 데 서버 측 스토리지를 사용하며, 캐시된 번역은 런타임에 재사용됩니다. 이를 통해 반복적인 읽기와 병합을 피합니다.

3. **간소화된 파일 로딩**

- 폴백 처리와 캐싱을 통합하여 번역 파일을 더 예측 가능하고 유지보수하기 쉬운 방식으로 로드합니다.
