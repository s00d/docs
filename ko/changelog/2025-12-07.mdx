**날짜**: 2025-12-07

**버전**: `v2.14.1`

![v2.14 릴리스](/images/2.14.0.png)

Node.js, Vue 3, Astro를 위한 완전히 새로운 통합을 담은 **v2.14.1**을 발표하게 되어 기쁩니다! 이 패키지들은 동일한 핵심 로직을 공유하여 일관성과 성능을 유지하면서, 같은 강력한 i18n 기능을 여러분이 즐겨 쓰는 프레임워크에 제공합니다.

## 새로운 기능 {#what’s-new}

- **@i18n-micro/node** - 모든 Node.js 애플리케이션, CLI 도구 또는 백엔드 서비스에서 i18n 번역 사용
- **@i18n-micro/vue** - 반응형 번역과 라우트별 지원을 제공하는 국제화용 Vue 3 플러그인
- **@i18n-micro/astro** - 완전한 TypeScript 지원을 갖춘 국제화용 Astro 통합
- **@i18n-micro/types-generator** - 완전한 타입 안전성과 IDE 자동 완성을 제공하는 번역 키용 TypeScript 타입 자동 생성

## 주요 기능 {#key-features}

모든 통합은 동일한 핵심 이점을 공유합니다.

- 가볍고 성능이 뛰어남
- 라우트별 번역 지원
- 내장 복수형 처리
- 숫자, 날짜, 상대 시간 서식 지정
- 완전한 TypeScript 지원
- 동일한 JSON 번역 파일 구조

**Types Generator**는 추가로 다음과 같은 개발자 경험 향상을 제공합니다.

- JSON 번역 파일로부터 타입 자동 생성
- 컴파일 타임 검증을 거치는 타입 안전한 번역 키
- 완전한 IDE 자동 완성 지원
- 번역 파일 변경 시 핫 리로드
- 런타임 오버헤드 없음

자세한 문서와 예제는 [저장소](https://github.com/s00d/nuxt-i18n-micro)를 방문하거나 [문서](https://s00d.github.io/nuxt-i18n-micro/)를 확인하세요.
