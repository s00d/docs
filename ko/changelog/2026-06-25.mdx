**날짜**: 2026-06-25

**버전**: `v3.21.0`

![v3.21.0 release](/images/3.21.0.png)

이번 릴리스는 **`useI18nHead`**를 추가합니다. 내장 `02.meta` 플러그인 위에서 i18n SEO 재정의를 위한 페이지 수준 컴포저블입니다. 커스텀 메타 플러그인이나 `meta: false` 없이 라우트별로 `hreflang`, canonical, `og:url`, Open Graph 태그를 사용자 정의할 수 있습니다.

## 새로운 기능 {#what’s-new}

### `useI18nHead` 컴포저블 {#usei18nhead-composable}

`meta: true`(기본값)일 때 어떤 페이지에서든 `useI18nHead`를 호출하세요. 모듈은 라우트가 업데이트될 때마다 `useLocaleHead` 다음에 입력을 병합합니다:

```vue
<script setup lang="ts">
useI18nHead(() => ({
  meta: [{ property: 'og:title', content: article.value?.title }],
  replace: {
    canonical: article.value?.canonicalUrl,
    ogUrl: article.value?.canonicalUrl,
    hreflang: localeCodes.map((locale) => ({
      rel: 'alternate',
      hreflang: locale,
      href: article.value!.locales[locale]!,
    })),
    ogAlternates: localeCodes,
  },
}))
</script>
```

정적 객체, 반응형 getter, `meta` / `link` 추가, 내장 그룹에 대한 `replace`, 자동 생성 태그를 제거하는 `disable`을 지원합니다. [`useI18nHead`](/ko/composables/useI18nHead)를 참고하세요.

### `mergeI18nHead` 유틸리티 (`@i18n-micro/utils`) {#mergei18nhead-utility-i18n-microutils}

프레임워크에 독립적인 병합 로직은 `@i18n-micro/utils/merge-i18n-head`에 있습니다. `02.meta` 플러그인에서 사용되며 독립적으로 테스트할 수 있습니다. 타입(`I18nHeadInput`, `I18nHeadLink`, `I18nHeadMeta`)은 `@i18n-micro/types`에서 내보냅니다.

### 플러그인 통합 {#plugin-integration}

- **`02.meta`** — `useLocaleHead` 출력과 `useI18nHead`의 페이지 상태를 `useHead`를 통해 병합합니다
- **`01.plugin`** — 라우트 이름이 변경되면 `resetPageHead()`를 통해 페이지 재정의를 초기화합니다(컴포저블과 상태 공유)

### 문서 및 테스트 {#documentation-&-tests}

- 새 가이드: CMS/기사 예제가 포함된 [`useI18nHead`](/ko/composables/useI18nHead)
- [SEO](/ko/guide/seo)와 [`useLocaleHead`](/ko/composables/useLocaleHead) 업데이트 — 어떤 API를 언제 사용할지
- Playwright + Vitest 커버리지: SSR, SPA 내비게이션, 새로고침, `nuxi generate`, 부분 alternate, `x-default`, 반응형 클라이언트 로드

## 일반적인 사용 사례 {#typical-use-cases}

| 시나리오                                     | 접근 방식                                                       |
| -------------------------------------------- | -------------------------------------------------------------- |
| 부분 번역이 있는 블로그/CMS           | API 로케일에서 `replace.hreflang` + `replace.ogAlternates`   |
| CMS의 커스텀 canonical                    | `replace.canonical` + `replace.ogUrl`                          |
| 랜딩 페이지 OG만                         | `meta: [{ property: 'og:title', ... }]` — 모듈 hreflang 유지 |
| 페이지에 hreflang 없음                        | `disable: ['hreflang', 'x-default']`                           |
| 커스텀 플러그인 대체(`i18nManualHreflang`) | 콘텐츠 페이지별 `useI18nHead` + `meta: true`                  |

**JSON-LD**는 `useHead({ script: [...] })`에 그대로 둡니다. `useI18nHead`는 구조화된 데이터를 생성하지 않습니다.

## 호환성이 깨지는 변경 사항 {#breaking-changes}

표준 `nuxt.config` 사용에는 없습니다. 새 컴포저블과 utils 하위 경로는 추가 사항입니다.

## 중요한 이유 {#why-it-matters}

- CMS 게시물, 뉴스, 로케일별 URL이 있는 가이드에 **커스텀 메타 플러그인이 필요 없음**
- **단일 파이프라인** — 모듈 기본값 + 페이지 재정의가 하나의 `useHead` 호출에
- **타입 안전** — `buildArticleHead(content)` 같은 헬퍼를 위한 `I18nHeadInput`

전체 변경 로그는 릴리스와 함께 [GitHub](https://github.com/s00d/nuxt-i18n-micro/blob/main/CHANGELOG.md)에 게시됩니다.
