**날짜**: 2025-10-30

**버전**: `v2.0.0`

![v2.0.0 릴리스](/images/2.0.0.png)

개발 환경에서 번역 파일에 대한 서버 측 HMR을 도입합니다. JSON 번역이 변경되면 서버 캐시는 영향을 받는 키만 무효화하고, 이후 요청은 즉시 새로운 데이터를 받습니다. 재시작이 필요 없습니다.

## 새로운 기능 {#what’s-new}

- 번역 파일에 대한 서버 측 HMR
- 페이지/로케일 단위의 즉각적인 캐시 무효화
- 콘텐츠 편집 중 매끄러운 DX

## 작동 방식 {#how-it-works}

- `src/runtime/server/plugins/watcher.dev.ts`의 감시자가 `<rootDir>/<translationDir>/**/*.json`을 관찰합니다
- 페이지 파일(예: `pages/<page>/<locale>.json`)은 `_locales:merged:<page>:<locale>`을 무효화합니다
- 루트 수준 파일(예: `<locale>.json`)은 해당 로케일의 모든 병합된 키를 무효화합니다
- `experimental.hmr !== false`일 때 개발 환경에서 `src/module.ts`에 의해 자동 등록됩니다

## 구성 {#configuration}

```ts
export default defineNuxtConfig({
  i18n: {
    experimental: { hmr: true }, // default in dev
  },
})
```
