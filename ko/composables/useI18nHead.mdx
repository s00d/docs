---

`useI18nHead()`는 모듈이 생성하는 SEO 태그를 한 페이지에 한해서만 변경합니다. 페이지가 라우터보다 더 잘 알고 있을 때 사용하세요: 일부 로케일에만 존재하는 CMS 기사, API에서 받은 canonical URL, 추가 `og:` 태그 등. 생성된 태그 위에 재정의가 병합된 결과를 얻습니다.

## 시그니처 {#signature}

```ts
useI18nHead(input?: MaybeRefOrGetter<I18nHeadInput | null>): { pageHead: any; resetPageHead: () => void }
```

i18n SEO head 태그에 대한 페이지 수준 재정의를 등록합니다.
`02.meta` 플러그인이 `useLocaleHead` 출력 위에 병합합니다.

값이 `$t` / `t`에서 오는 경우 로케일이 바뀔 때 다시 해석되도록 getter(`() => ({ … })`)를
사용하는 것이 좋습니다. 일반 객체는 한 번만 평가되고 고정된 상태로 유지됩니다.

| 매개변수 | 타입 | 설명 |
| --- | --- | --- |
| `input` *(선택)* | `MaybeRefOrGetter<I18nHeadInput \| null>` |  |

[`meta: true`](/ko/api/module-options#meta)(기본값)와 함께 동작합니다: 모듈의 meta 플러그인이 head를 렌더링할 때마다 입력을 [`useLocaleHead`](/ko/composables/useLocaleHead) 출력 위에 병합합니다. `meta: false`이면 아무것도 이를 읽지 않습니다.

재정의는 라우트 이름이 바뀌면 초기화됩니다. `disableMeta`를 설정한 페이지는 재정의를 포함하여 i18n 태그를 전혀 받지 않습니다.

## 입력 {#input}

`I18nHeadInput` (`@i18n-micro/types`에서 제공):

| 키 | 타입 | 효과 |
| --- | --- | --- |
| `htmlAttrs` | `Record<string, string>` | `<html>` 속성(`lang`, `dir`)에 병합됩니다. |
| `meta` | `I18nHeadMeta[]` | 생성된 태그 뒤에 추가되며, 같은 `id`, `property` 또는 `name`을 가진 태그를 교체합니다. |
| `link` | `I18nHeadLink[]` | 생성된 링크 뒤에 추가되며, 같은 `id` 또는 `rel` + `hreflang`을 가진 링크를 교체합니다. |
| `replace.canonical` | `string \| false` | canonical `href`를 교체하거나 링크를 제거합니다. |
| `replace.hreflang` | `I18nHeadLink[] \| false` | `x-default`를 포함한 **모든** `rel="alternate"` 링크를 교체하거나 제거합니다. |
| `replace.xDefault` | `I18nHeadLink \| false` | `x-default` 링크를 교체하거나 제거합니다. |
| `replace.ogLocale` | `string \| false` | `og:locale`을 교체하거나 제거합니다. |
| `replace.ogUrl` | `string \| false` | `og:url`을 교체하거나 제거합니다. |
| `replace.ogAlternates` | `string[] \| false` | 이 로케일 코드들로부터(`og` / `iso`를 통해) `og:locale:alternate`를 다시 만들거나(현재 로케일, 알 수 없는 코드, `og` 또는 `iso` 값이 없는 코드는 건너뜀) 제거합니다. |
| `disable` | `I18nHeadDisableGroup[]` | 생성된 그룹을 제거합니다: `'hreflang'`(`x-default` 제외), `'x-default'`, `'canonical'`, `'og'`(`og:locale` + `og:url`), `'og-alternates'`, `'html'`. |

적용 순서: `disable`, 그다음 `replace`, 그다음 `htmlAttrs`, `meta`, `link`.

## 예제 {#example}

API에서 받은 대체 URL을 사용하는, 일부 로케일에만 존재하는 기사:

```vue
<script setup lang="ts">
const route = useRoute()
const { t } = useI18n()
const { data: article } = await useFetch<{ title: string; urls: Record<string, string> }>(`/api/articles/${route.params.slug}`)

useI18nHead(() => {
  if (!article.value) return null
  const codes = Object.keys(article.value.urls)
  return {
    meta: [{ property: 'og:title', content: article.value.title || t('blog.title') }],
    replace: {
      hreflang: codes.map((code) => ({ rel: 'alternate', hreflang: code, href: article.value!.urls[code]! })),
      ogAlternates: codes,
    },
  }
})
</script>
```

값이 `t()`나 비동기 데이터에서 오는 경우 여기서처럼 getter를 전달하세요: 로케일이 바뀌면 다시 실행됩니다. 일반 객체는 한 번만 읽힙니다.
