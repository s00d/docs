---

`useI18n()`은 모듈의 런타임 헬퍼를 일반 객체로 반환합니다. `useNuxtApp()`을 사용하는 대신 `<script setup>`, 컴포저블, 플러그인에서 이것을 사용하세요. 모든 헬퍼는 `$` 이름과 접두사 없는 별칭으로 제공됩니다: `t`와 `$t`는 같은 함수입니다.

## 시그니처 {#signature}

```ts
useI18n(): PluginsInjectionsWithAliases
```

모든 런타임 헬퍼를 일반 객체로 제공합니다.

플러그인이 `$t`, `$tc` 등으로 주입하는 것과 같은 함수를 달러 접두사가 붙은 이름과
접두사 없는 별칭 모두로 사용할 수 있습니다. 따라서 `const { t } = useI18n()`과
`const { $t } = useI18n()` 모두 동작합니다.

**반환 값** — [메서드 레퍼런스](/ko/api/methods)에 설명된 헬퍼

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

반환된 객체에는 [`PluginsInjections`](/ko/api/methods)의 모든 헬퍼가 들어 있습니다. 각 헬퍼는 [헬퍼](/ko/api/methods) 페이지에 문서화되어 있습니다.

## 예제 {#example}

```vue
<script setup lang="ts">
const { t, tc, localePath, switchLocale, getLocale } = useI18n()

const title = computed(() => t('page.title'))
</script>

<template>
  <h1>{{ title }}</h1>
  <p>{{ tc('items', 3) }}</p>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
  <button @click="switchLocale(getLocale() === 'en' ? 'de' : 'en')">{{ t('nav.switch') }}</button>
</template>
```

## 타입에 포함되지 않은 항목 {#not-in-the-type}

`$defineI18nRoute`는 `useNuxtApp()`에서만 타입이 지정됩니다:

```ts
const { $defineI18nRoute } = useNuxtApp()
```
