---
title: "useLocaleHead"
description: "useLocaleHead는 i18n SEO 태그(lang, dir, canonical, hreflang, og:locale)를 useHead에 전달할 객체로 만듭니다."
---

`useLocaleHead()`는 현재 라우트에 대한 i18n head 태그를 만듭니다: `<html>`의 `lang`과 `dir`, canonical 링크, `x-default`를 포함한 `hreflang` 대체 링크, `og:url`, `og:locale`, `og:locale:alternate`. [`meta: false`](/ko/api/module-options#meta)로 설정하고 `useHead`를 직접 관리할 때 사용하세요. `meta: true`이면 모듈이 이미 이 태그들을 등록하며, 페이지별 변경은 [`useI18nHead`](/ko/composables/useI18nHead)를 통해 합니다.

## 시그니처 {#signature}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { build: () => LocaleHead; metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }, LocaleHead | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

현재 라우트에 대한 SEO head 태그: 모든 로케일에 대한 `hreflang` 대체 링크와
`x-default`, canonical 링크, `og:locale`, 그리고 `<html>`의 `lang`/`dir`.

`meta`가 비활성화되어 있거나 기본값을 조정해야 할 때만 필요합니다. `meta: true`이면
모듈이 같은 태그를 직접 등록합니다.

| 매개변수 | 타입 | 설명 |
| --- | --- | --- |
| `options` | `UseLocaleHeadOptions` |  |

**반환 값** — `metaObject`는 `useHead`에 바로 전달할 수 있는 head 객체를 담은 ref입니다. `updateMeta`는 이를 갱신합니다. `build`는 현재 라우트로부터 head 객체를 계산합니다(getter 안에서 읽으면 반응형입니다. 예: `useHead(() => build())`)

```ts
const { metaObject } = useLocaleHead({ addSeoAttributes: true })
useHead(metaObject)
```

## 옵션 {#options}

| 옵션 | 기본값 | 설명 |
| --- | --- | --- |
| `addDirAttribute` | `true` | 로케일의 `dir`로 `<html>`에 `dir`을 설정합니다(없으면 `'auto'`). |
| `identifierAttribute` | `'id'` | 각 태그를 식별하는 속성(`i18n-can`, `i18n-og`, `i18n-alternate-<hreflang>`, …)으로, 업데이트 시 태그를 추가하지 않고 교체합니다. |
| `addSeoAttributes` | `true` | canonical, `hreflang`, `og:` 태그를 출력합니다. `false`이면 `htmlAttrs`만 유지합니다. |
| `baseUrl` | `'/'` | 모든 URL 앞에 붙는 origin. 상대 URL을 원하면 `'/'`를 유지하고, 절대 URL을 원하면 `'https://example.com'`을 전달하세요. |
| `autoUpdate` | `true` | 라우트나 `i18n-locale` 상태가 바뀌면 `metaObject`를 다시 만듭니다. |

## 출력 내용 {#what-it-emits}

- 일치하는 라우트가 없는 경우(404) 또는 활성 로케일에 `disableMeta`가 설정된 라우트에서는 아무것도 출력하지 않습니다.
- Canonical 및 `og:url`: `$switchLocalePath(<active locale>)`, 쿼리는 [`canonicalQueryWhitelist`](/ko/api/module-options#canonicalquerywhitelist)로 축소되고 [`trailingSlash`](/ko/api/module-options#trailingslash)가 적용됩니다.
- `hreflang`: 페이지가 존재하는 활성화된 로케일마다 링크 하나, `hreflang = iso || code`, `seo: false`인 로케일은 건너뜁니다. `hreflangBaseLanguage: true`이면 한 언어의 첫 번째 지역 로케일이 언어만 있는 태그도 출력합니다. `no_prefix`에서는 출력하지 않습니다.
- `x-default`: 기본 로케일의 URL. 단, 전략이 `no_prefix`이거나, 기본 로케일에 `seo: false`가 있거나, 페이지가 기본 로케일에 존재하지 않으면 출력하지 않습니다.
- `og:locale` / `og:locale:alternate`: 로케일의 `og`, 또는 변환된 `iso`(`en-US` → `en_US`)에서 가져옵니다. 둘 다 사용할 수 없으면 개발 경고와 함께 건너뜁니다.

## 예제 {#example}

```ts
// app.vue, with i18n.meta: false
const { metaObject } = useLocaleHead({ baseUrl: 'https://example.com' })
useHead(metaObject)
```

`build()`는 ref 없이 같은 객체를 반환합니다: `useHead(() => build())`는 watcher 없이도 반응형으로 유지됩니다.
