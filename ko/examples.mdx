# 📚 Nuxt I18n Micro 예제 및 사용법

이 섹션에서는 Nuxt.js 애플리케이션에서 `Nuxt I18n Micro`를 사용하는 다양한 예제를 제공합니다. 로케일 전환, `<i18n-link>`, `<i18n-switcher>`, `<i18n-t>` 컴포넌트 사용, 동적 번역 키 처리 방법을 살펴봅니다.

## 🛠️ 기본 설정

`Nuxt I18n Micro`를 시작하기 위한 기본 설정입니다:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 로케일 전환

### 프로그래매틱하게 로케일 전환하기

버튼을 사용하여 프로그래매틱하게 로케일을 전환하는 예제입니다:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### 로케일 전환용 JSON 예제

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### `<i18n-switcher>` 컴포넌트 사용하기

`<i18n-switcher>` 컴포넌트는 사용자 정의 가능한 라벨을 갖춘 로케일 전환용 드롭다운을 제공합니다:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 🌐 지역화된 내비게이션을 위한 `<i18n-link>` 사용

## 📝 번역 파일에서 동적 키 렌더링하기

경우에 따라 번역 파일에 저장된 동적 키를 반복하며 조건부로 값을 렌더링하고 싶을 수 있습니다. 아래 예제는 `Nuxt I18n Micro`를 사용하여 이를 구현하는 방법을 보여줍니다.

### 예제: 동적 키 렌더링

이 예제는 특정 번역 경로(여기서는 `dynamic`)에서 키 배열을 가져와 반복 처리합니다. 각 키는 값을 `$t`로 렌더링하기 전에 `$has`로 존재 여부를 확인합니다.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### 번역 파일 예제 (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### 예제: 객체에서 동적 키 렌더링

이 예제에서는 번역 파일에 저장된 객체를 다룹니다. 객체의 키를 가져와 반복하며, 키 이름과 관련 값을 동적으로 렌더링합니다.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### 번역 파일 예제 (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 슬롯과 보간을 사용한 번역을 위한 `<i18n-t>` 사용

`<i18n-t>` 컴포넌트는 동적 콘텐츠와 HTML 태그를 포함하는 번역을 렌더링할 때 유용합니다:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### `<i18n-t>`용 JSON 예제

```json
{
  "greeting": "Welcome to the page"
}
```

### 보간 사용

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### 보간용 JSON 예제

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 복수형 처리를 위한 `$tc` 사용

`Nuxt I18n Micro`의 `$tc` 함수는 수량과 로케일 설정에 따라 복수형을 처리합니다. 이는 항목, 알림 또는 수량이 변하는 다른 엔티티와 같이 카운트를 포함하는 메시지를 동적으로 조정하는 데 유용합니다.

### 예제: 복수형 처리를 위한 `$tc` 사용

다음 예제에서는 `$tc`를 사용하여 사과의 개수를 나타내는 메시지를 표시합니다. 번역 키는 제공된 개수에 따라 여러 복수형을 처리합니다.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### 복수형 처리용 JSON 예제

다음은 다양한 복수형을 처리하기 위해 JSON 파일에서 번역을 정의하는 방법입니다:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### 설명

- **`$tc('apples', 0)`**: 첫 번째 형식을 반환하며, 개수가 0일 때 사용됩니다(`"no apples"`).
- **`$tc('apples', 1)`**: 두 번째 형식을 반환하며, 개수가 1일 때 사용됩니다(`"one apple"`).
- **`$tc('apples', 10)`**: 개수 값을 포함하는 세 번째 형식을 반환하며, 개수가 2 이상일 때 사용됩니다(`"10 apples"`).

### 더 복잡한 복수형이 포함된 추가 예제

애플리케이션이 더 복잡한 복수형 규칙(예: zero, one, two, few, many, other의 특정 경우)을 처리해야 한다면, 번역 문자열을 다음과 같이 확장할 수 있습니다:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: `"two apples"`를 반환하도록 설정할 수 있습니다.
- **`$tc('apples', 3)`**: 개수에 대해 정의된 규칙에 따라 `"a few apples"`를 반환할 수 있습니다.

## 🌐 숫자 형식화를 위한 `$tn` 사용

`$tn` 함수는 `Intl.NumberFormat` API를 사용하여 현재 로케일에 따라 숫자를 형식화합니다. 이는 통화, 백분율 또는 기타 숫자 형식과 같이 사용자의 지역 설정에 맞게 숫자를 표시하는 데 유용합니다.

### 예제: 숫자 형식화를 위한 `$tn` 사용

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ 날짜 및 시간 형식화를 위한 `$td` 사용

`$td` 함수는 `Intl.DateTimeFormat` API를 사용하여 현재 로케일에 따라 날짜와 시간을 형식화합니다. 이는 로케일 설정을 기반으로 사용자에게 익숙한 형식으로 날짜와 시간을 표시하는 데 유용합니다.

### 예제: 날짜 및 시간 형식화를 위한 `$td` 사용

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ 상대 날짜 형식화를 위한 `$tdr` 사용

`$tdr` 함수는 `Intl.RelativeTimeFormat` API를 사용하여 현재 로케일에 따라 날짜를 상대 시간(예: "5분 전", "2일 전")으로 형식화합니다. 이는 현재 날짜 및 시간을 기준으로 상대적인 시간 차이를 표시하는 데 유용합니다.

### 예제: 상대 날짜 형식화를 위한 `$tdr` 사용

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
