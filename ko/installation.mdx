## 요구 사항

- **Node.js**: 18 이상.
- **Nuxt**: 3.x 또는 4.x.

이 모듈은 Nuxt 3 프로젝트 레이아웃(`pages/**/*.vue`)과 Nuxt 4 레이아웃(`app/pages/**/*.vue`)을 모두 지원합니다. 번역 파일은 관례상 프로젝트 루트(`locales/`)에 위치하며, Nuxt 4의 `app/` 디렉터리를 사용할 때도 마찬가지입니다.

## Nuxt 모듈 설치

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

`nuxt.config.ts`에 등록합니다:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

전체 설명은 [빠른 시작](/quickstart)을, 모든 옵션은 [설정 레퍼런스](/guides/configuration)를 참고하세요.

## 프로젝트 레이아웃

기본적으로 모듈은 다음을 기대합니다:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

루트 레벨 파일은 빌드 시 모든 페이지별 파일과 병합됩니다. 페이지별 파일은 `nuxt dev` 중 누락되었을 때 자동으로 생성됩니다.

## Nuxt 4 레이아웃

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

번역을 `app/` 아래에 함께 두려면 `translationDir: 'app/locales'`로 설정하세요.

## 생태계 패키지

| 패키지 | 용도 |
| --- | --- |
| [`@i18n-micro/vue`](/integrations/vue) | Vue 3 통합(Nuxt 없이 독립 실행). |
| [`@i18n-micro/react`](/integrations/react) | React 통합. |
| [`@i18n-micro/preact`](/integrations/preact) | Preact 통합. |
| [`@i18n-micro/solid`](/integrations/solid) | SolidJS 통합. |
| [`@i18n-micro/astro`](/integrations/astro) | Astro 통합. |
| [`@i18n-micro/node`](/integrations/nodejs) | Node.js 서버 사이드 로더. |
| [`@i18n-micro/types-generator`](/integrations/types-generator) | 번역 파일로부터 TypeScript 타입 생성. |
| [`@i18n-micro/devtools-ui`](/integrations/devtools-ui) | 프레임워크에 구애받지 않는 DevTools 패널. |

공유 내부 패키지는 전이적으로 함께 설치됩니다.

## TypeScript

이 모듈은 기본 로케일 파일을 기반으로 `useI18n`, `$t` 및 관련 헬퍼를 위한 앰비언트 타입을 생성합니다. 기본적으로 활성화되어 있습니다(`types: true`).

번역 키에 대한 더 강력한 타이핑은 [`@i18n-micro/types-generator`](/integrations/types-generator)를 참고하세요.
