`@i18n-micro/vue`는 Nuxt I18n Micro의 번역 코어를 담은 Vue 3 플러그인으로, 반응형 `t()`, 전역 `$t`, 네 가지 컴포넌트, 선택적 vue-router 어댑터를 제공합니다. Nuxt로 빌드하지 않은 Vite 또는 SSR Vue 앱에서 사용하세요. 인스턴스 모델, 라우터 계약, 컴포넌트 props는 다른 패키지와 공유되며 [프레임워크](/ko/integrations/overview)에 설명되어 있습니다.

## 설치 {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vue
```

```bash npm
npm install @i18n-micro/vue
```

```bash yarn
yarn add @i18n-micro/vue
```

</CodeGroup>

피어 의존성: `vue` `^3.3.0`; `vue-router` `^4.5.1 || ^5.0.0`(선택 사항, `@i18n-micro/vue/router`에만 필요). 배포된 타입은 `skipLibCheck: false`일 때 Vue 3.5.5 이상이 필요합니다. 일반적인 템플릿 설정인 `skipLibCheck: true`에서는 이전 버전도 컴파일됩니다.

## 설정 {#setup}

```ts
// src/main.ts
import { createApp } from 'vue'
import { createI18n } from '@i18n-micro/vue'
import App from './App.vue'
import en from './locales/en.json'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales: [
    { code: 'en', iso: 'en-US', displayName: 'English' },
    { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
  ],
  defaultLocale: 'en',
})

createApp(App).use(i18n).mount('#app')
```

`useI18n()`에는 `locales`와 `defaultLocale`이 필요합니다. 없으면 `I18nLocalesKey not provided` 오류를 던집니다. 이 값들은 `createI18n`에 전달하거나(위 예시처럼), `useI18n({ locales, defaultLocale })`에 전달하거나, `app.provide(I18nLocalesKey, …)`와 `app.provide(I18nDefaultLocaleKey, …)`를 통해 제공하세요.

플러그인은 `I18nT`, `I18nLink`, `I18nGroup`, `I18nSwitcher`를 전역으로 등록하고 템플릿에 `$t`, `$ts`, `$tc`, `$tn`, `$td`, `$tdr`, `$has`, `$i18n`을 추가합니다. 컴포넌트 외부에서 인스턴스는 `i18n.global`입니다. 다른 옵션은 [인스턴스](/ko/integrations/overview#the-instance)에 있습니다. Vue에서는 `routeMessages`를 사용할 수 없으므로 `addRouteTranslations`를 사용하세요.

## 번역 {#translate}

```vue
<script setup lang="ts">
import { useI18n } from '@i18n-micro/vue'

const { t, tc, tn } = useI18n()
</script>

<template>
  <h1>{{ t('greeting', { name: 'Ada' }) }}</h1>
  <!-- Hello, Ada! -->
  <p>{{ tc('apples', 3) }}</p>
  <!-- 3 apples -->
  <p>{{ $t('nav.home') }} · {{ tn(1234.5) }}</p>
</template>
```

`useI18n()`은 번역 메서드(`t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`), `locale`(쓰기 가능한 computed), `getLocale`, `getLocales`, `defaultLocale()`, `getLocaleName`, `localePath`, `localeRoute`, `switchLocale`, `setRoute`, `getRoute`, `addTranslations`, `addRouteTranslations`, `mergeTranslations`, `resolveTranslations`, `setTranslation`, `clearCache`, `instance`를 반환합니다.

언제든지 사전을 추가로 로드할 수 있으며, 해당 사전을 읽는 모든 컴포넌트가 다시 렌더링됩니다.

```ts
const { addTranslations, addRouteTranslations, setRoute } = useI18n()

addTranslations('de', (await import('./locales/de.json')).default)
addRouteTranslations('en', 'about', { title: 'About us' })
setRoute('about') // t('title') now reads the 'about' dictionary first
```

## 로케일 전환 {#switch-locale}

```ts
const { locale, switchLocale } = useI18n()

locale.value = 'de' // only the locale
switchLocale('de') // the locale, then router.push to the localized current path
```

전환 전이나 후에 해당 로케일의 사전을 로드하세요. 전환 자체는 아무것도 가져오지 않습니다.

`<I18nGroup>`은 슬롯에 접두사가 붙은 `t`를 제공합니다. `<I18nT>` 내부의 키나 일반 `t()`에는 접두사가 붙지 않습니다.

```vue
<I18nGroup prefix="profile" v-slot="{ t }">
  <h2>{{ t('title') }}</h2>
  <!-- profile.title -->
</I18nGroup>
```

## 라우팅 {#routing}

vue-router 어댑터는 서브패스에 있으므로 메인 진입점은 `vue-router`를 절대 import하지 않습니다.

```ts
// src/main.ts
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import { createI18n } from '@i18n-micro/vue'
import { createVueRouterAdapter } from '@i18n-micro/vue/router'
import App from './App.vue'
import Home from './pages/Home.vue'
import About from './pages/About.vue'
import en from './locales/en.json'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English' },
  { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
]

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/:locale(de)?', component: Home },
    { path: '/:locale(de)?/about', component: About },
  ],
})

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales,
  defaultLocale: 'en',
  routingStrategy: createVueRouterAdapter(router, locales, 'en'),
})

createApp(App).use(router).use(i18n).mount('#app')
```

`createVueRouterAdapter(router, locales, defaultLocale)`는 기본 로케일을 제외한 모든 로케일에 접두사를 붙이고(`/about`, `/de/about`), `<I18nLink>`를 `RouterLink`로 렌더링합니다. 라우트에서 로케일을 직접 읽어(예: `router.beforeEach`에서) `i18n.global.locale.value`를 설정하세요. 나중에 `i18n.setRoutingStrategy(adapter)`로 어댑터를 연결할 수도 있습니다. 사용자 정의 어댑터는 [라우터 어댑터](/ko/integrations/overview#router-adapter)를 참고하세요.

## SSR {#ssr}

- 라우터, i18n 인스턴스, 앱을 요청별 렌더 함수 내부에서 생성하세요. 하나의 공유 인스턴스를 사용하면 한 방문자의 로케일이 다른 방문자에게 새어 나갑니다.
- 서버에서는 `createMemoryHistory()`를 사용하고, URL에서 로케일을 가져와 `renderToString` 전에 해당 사전(및 폴백 사전)을 로드하세요.
- 로케일을 클라이언트로 전송하고(예: `window.__STATE__` 스크립트로) 동일한 `locale`로 클라이언트 인스턴스를 생성하여 하이드레이션이 일치하도록 하세요.
- `<I18nSwitcher>`는 드롭다운이 열려 있을 때만 `window.location`을 읽으므로 서버에서 렌더링됩니다.

`packages/vue/playground`에 완전한 `entry-server.ts` / `entry-client.ts` 쌍이 있습니다.

## SEO head {#seo-head}

`useLocaleHead(options)`는 로케일과 라우터 어댑터로부터 `lang`/`dir`, canonical, `hreflang`, `og:locale` 태그를 생성합니다. 라우트가 변경될 때 `updateMeta()`를 호출하고 `metaObject`를 head 관리자에 전달하세요.

```ts
import { watch } from 'vue'
import { useRoute } from 'vue-router'
import { useHead } from '@unhead/vue'
import { useLocaleHead } from '@i18n-micro/vue'

const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
watch(() => route.fullPath, () => updateMeta(), { immediate: true })
useHead(metaObject)
```

옵션: `baseUrl`(문자열 또는 함수), `addDirAttribute`(기본값 `true`), `addSeoAttributes`(기본값 `true`), `identifierAttribute`(기본값 `'id'`), `hreflangBaseLanguage`(기본값 `false`). `disabled: true` 또는 `seo: false`인 로케일에는 alternate 링크가 생성되지 않습니다.

## API {#api}

| 내보내기 | 진입점 |
| --- | --- |
| `createI18n`, `useI18n`, `useLocaleHead` | `@i18n-micro/vue` |
| `I18nT`, `I18nLink`, `I18nSwitcher`, `I18nGroup` | `@i18n-micro/vue` |
| `VueI18n` (인스턴스 클래스), `I18nInjectionKey`, `I18nLocalesKey`, `I18nDefaultLocaleKey` | `@i18n-micro/vue` |
| `defaultPlural`, `FormatService`, `interpolate` | `@i18n-micro/vue` |
| 타입: `I18nRoutingStrategy`, `Locale`, `Translations`, `PluralFunc`, `Params`, `Getter`, `CleanTranslation`, `LocaleCode`, `VueI18nOptions`, `UseI18nOptions`, `UseLocaleHeadOptions`, `I18nPlugin` | `@i18n-micro/vue` |
| `createVueRouterAdapter` | `@i18n-micro/vue/router` |
