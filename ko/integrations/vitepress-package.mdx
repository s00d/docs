`@i18n-micro/vitepress`는 VitePress 사이트에 런타임 사전을 추가합니다: 마크다운 안의 `$t`와 `<I18nT>`, 경로 헬퍼, SEO 태그를 제공하며 [`@i18n-micro/vue`](/ko/integrations/vue-package) 위에 구축되었습니다. 같은 UI 문자열이 여러 페이지에 나타나고 로케일마다 중복하고 싶지 않을 때 사용하세요. 로케일은 VitePress 자체의 경로 로케일(`/`, `/fr/`)을 따릅니다.

## 언제 사용하나요 {#when-to-use-it}

| 필요 | 해결책 |
|------|----------|
| `.md` 중복, URL 접두사 | VitePress `locales` |
| 런타임 `$t` / 컴포넌트 / 경로 동기화 / SEO head | `@i18n-micro/vitepress` |
| 기본 테마 UI 레이블(`docFooter`, 검색 UI) | 로케일별 자체 `themeConfig` |

<Tip>

**플레이그라운드** — [`packages/vitepress/playground`](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/vitepress/playground) — `pnpm -C packages/vitepress/playground dev`

</Tip>

## 설치 {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vitepress
```

```bash npm
npm install @i18n-micro/vitepress
```

```bash yarn
yarn add @i18n-micro/vitepress
```

</CodeGroup>

피어 의존성: `vitepress` `>=1.0.0 || >=2.0.0-alpha.0`, `vue` `^3.3.0`. Node 스크립트는 패키지와 함께 설치되고 `/node`를 통해 다시 내보내지는 `@i18n-micro/node`를 사용합니다. 게시된 타입에는 `skipLibCheck: false`에서 Vue 3.5.5 이상이 필요합니다. 일반적인 템플릿 설정인 `skipLibCheck: true`에서는 이전 버전도 컴파일됩니다.

## 설정 {#setup}

```
locales/en.json
locales/fr.json
locales/pages/guide/demo/en.json   # optional page-scoped
locales/pages/guide/demo/fr.json
```

페이지 파일은 Nuxt/Astro와 같은 방식으로 라우트 이름에 매핑됩니다(`guide/demo` → `guide-demo`).

### 1. 설정 — `@i18n-micro/vitepress/config` {#1-config-—-@i18n-micro/vitepress/config}

```ts
// .vitepress/config.mts
import { defineConfig } from 'vitepress'
import { withI18n, buildVitePressLocales } from '@i18n-micro/vitepress/config'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English', og: 'en_US' },
  { code: 'fr', iso: 'fr-FR', displayName: 'Français', og: 'fr_FR' },
]
const defaultLocale = 'en'

export default defineConfig(
  withI18n(
    {
      locales: buildVitePressLocales(locales, defaultLocale),
      // themeConfig.i18nRouting is injected automatically
    },
    {
      locale: defaultLocale,
      defaultLocale,
      locales,
      translationDir: 'locales',
      metaBaseUrl: 'https://example.com', // optional SEO head
    },
  ),
)
```

### 2. 테마 — `@i18n-micro/vitepress/theme` {#2-theme-—-@i18n-micro/vitepress/theme}

```ts
// .vitepress/theme/index.ts
import DefaultTheme from 'vitepress/theme'
import { defineI18nTheme } from '@i18n-micro/vitepress/theme'

export default defineI18nTheme(DefaultTheme)
```

초기 로케일은 설치 전에 현재 경로에서 가져옵니다(`/fr/…`에서 기본 로케일이 잠깐 보이는 현상 없음).

### 고급: 수동 `createI18n` {#advanced-manual-createi18n}

클라이언트용 단일 팩토리: Vue 플러그인 + 경로 메서드 + `enhanceApp`(별도의 라우터 헬퍼 내보내기 없음).

```ts
import { createI18n, messagesFromGlob } from '@i18n-micro/vitepress'

const i18n = createI18n({
  locale: 'en',
  defaultLocale: 'en',
  locales: [{ code: 'en' }, { code: 'fr' }],
  messages: messagesFromGlob(import.meta.glob('../../locales/*.json', { eager: true })),
})

i18n.localizePath('/guide', 'fr')
// in theme enhanceApp:
i18n.enhanceApp({ app, router })
```

### Node 스크립트 — `@i18n-micro/vitepress/node` {#node-scripts-—-@i18n-micro/vitepress/node}

`@i18n-micro/node`의 `createI18n` / `loadTranslations`(Astro 및 CLI와 동일)를 사용한 다음, `BaseI18n.extend`로 VitePress 경로 메서드를 연결합니다:

```ts
import { createI18n } from '@i18n-micro/vitepress/node'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  translationDir: './locales',
  locales: ['en', 'fr'],
  defaultLocale: 'en',
})
await i18n.loadTranslations()
i18n.t('cta.readMore')
i18n.localizePath('/guide', 'fr')
```

경로 없는 일반 Node: `import { createI18n } from '@i18n-micro/node'`.

## 페이지 내 번역 {#in-page-translations}

각 VitePress 마크다운 파일은 Vue SFC입니다.

### 전역 컴포넌트와 `$t` (마크다운에서 권장) {#global-components-and-$t-recommended-in-markdown}

`createI18n` / `defineI18nTheme`은 `@i18n-micro/vue`를 설치하며, 이는 `I18nT` / `I18nLink` / `I18nGroup` / `I18nSwitcher`와 `$t` / `$tc` / `$ts`를 등록합니다.

```md
{{ $t('cta.readMore') }}

<I18nT keypath="greeting" :params="{ name: 'VitePress' }" />

<I18nLink to="/guide/demo">Demo</I18nLink>
```

### `<script setup>`에서 `useI18n` 사용 {#usei18n-in-<script-setup>}

```md
<script setup>
import { useI18n } from '@i18n-micro/vitepress'
const { t, tc, locale, localePath, switchLocale } = useI18n()
</script>

# {{ t('section.title') }}
```

## 언어 드롭다운 {#language-dropdown}

`locales`에 항목이 둘 이상이면 VitePress는 자체 언어 메뉴(`VPNavBarTranslations`)를 표시합니다. `withI18n`은 `themeConfig.i18nRouting`을 연결하여 지구본 메뉴가 `<I18nSwitcher>` / 경로 헬퍼와 일치하도록 합니다.

`<I18nSwitcher>`는 기본 지구본 메뉴 옆이 아니라 사용자 지정 레이아웃에서만 사용하세요.

## SSR 참고 사항 {#ssr-notes}

- 프리렌더 시 로케일은 쿠키가 아니라 URL 경로에서 옵니다.
- 테마 코드는 가져오기 시점에 `window`에 접근하면 안 됩니다.
- Node 설정 평가가 `virtual:i18n-micro/*`를 절대 로드하지 않도록 `/theme`에서 `defineI18nTheme`을 가져오세요.

## API 구성 {#api-surface}

| 내보내기 | 역할 |
|--------|------|
| `createI18n` (`.`) | 클라이언트: Vue 플러그인 + 경로 메서드 + `enhanceApp` |
| `getLocaleFromPath` / `stripSiteBase` / `routeNameFromPath` (`.`) | `syncWithVitePress: false`일 때 수동 로케일 동기화 |
| `createI18n` (`/node`) | Node: `@i18n-micro/node` + 경로 메서드 |
| `defineI18nTheme` (`/theme`) | 보일러플레이트 없는 테마 |
| `withI18n` (`/config`) | 설정 + 가상 모듈 + 선택적 SEO |
| `buildVitePressLocales` (`/config`) | `Locale[]`에서 VitePress `locales` 생성 |
| `buildVitePressLocaleHead` (`/config`) | 수동 SEO head(`metaBaseUrl`에서도 사용) |
| `messagesFromGlob` | `createI18n`을 위한 선택적 glob → 메시지 맵 |
| `useI18n` / `I18nT` / … | `@i18n-micro/vue`에서 다시 내보냄 |
| `BaseI18n.extend` (`@i18n-micro/core`) | 모든 i18n 인스턴스에 사용자 지정 메서드 연결 |

## OpenAPI 스타일 사이트(통합 고정 사항) {#openapi-style-sites-integration-locks}

회귀 테스트 모음: `packages/vitepress/tests/integration-openapi.test.ts`(깊은 경로, `base=/openapi_docs/`, 동기화 끔 + 수동 로케일, Node 생성기, SEO).

| 패턴 | 조치 |
|---------|---------|
| 깊은 `/…/{spec}/{op}` 페이지, 루트 UI JSON만 있음 | 기본값 `syncWithVitePress: true`(페이지 사전이 없으면 `setRoute('index')` 유지) **또는** `syncWithVitePress: false` + `getLocaleFromPath`를 사용하세요 |
| 페이지 사전 없이 `setRoute(deepName)`을 절대 호출하지 마세요 | `setRoute('index')`까지 루트 UI 키가 사라집니다 |
| 생성기 / `getTranslation` | `/node`의 `createI18n` + `await loadTranslations()` + `i18n.t(key)`(`i18n.locale` 설정) |
| `transformPageData`의 사용자 지정 canonical | `withI18n`에 `meta: false`를 전달하세요(태그 중복 방지) |
| 사이트 base와 함께 패키지 SEO 사용 | `metaBaseUrl` + VitePress `base` → 절대 URL에 base가 포함됩니다 |
| 이전 패키지 빌드에서 이름 변경 | `withI18nMicro` → `withI18n`, `createVitePressI18n` → `createI18n`, `loadMessages` → node `createI18n` |
