`@i18n-micro/devtools-ui`는 Nuxt DevTools 탭의 번역 에디터를 Vite 플러그인과 함께 웹 컴포넌트로 패키징한 것입니다. Vue, React, Preact, Solid 또는 Astro 프로젝트에 추가하면 개발 중 브라우저에서 번역 폴더의 JSON 파일을 탐색하고 편집할 수 있습니다. Nuxt 앱에는 이미 [Nuxt DevTools](/ko/guide/devtools)에 포함되어 있습니다.

![DevTools UI: 파일 트리와 각 키 옆에 기본 로케일 텍스트가 표시되는 에디터](/images/devtools/02-translations-editor-dark.webp)

## 설치 {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/devtools-ui
```

```bash npm
npm install -D @i18n-micro/devtools-ui
```

```bash yarn
yarn add -D @i18n-micro/devtools-ui
```

</CodeGroup>

피어 의존성은 없습니다.

## 설정 {#setup}

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import { i18nDevToolsPlugin } from '@i18n-micro/devtools-ui/vite'

export default defineConfig({
  plugins: [i18nDevToolsPlugin({ translationDir: 'src/locales' })],
})
```

| 옵션 | 기본값 | 참고 |
| --- | --- | --- |
| `translationDir` | `'src/locales'` | JSON 파일이 있는 폴더, Vite 루트 기준 상대 경로. |
| `base` | `'/__i18n_api'` | API 엔드포인트의 기본 경로. |
| `injectButton` | `true` | Vite의 `index.html` 변환을 통해 제공되는 페이지에 플로팅 버튼을 추가합니다. Astro에는 그런 페이지가 없습니다: 아래를 참고하세요. |
| `defaultLocale` | `translationDir`의 첫 번째 로케일 파일 | `/config`에서 보고됩니다. |
| `fallbackLocale` | `defaultLocale` | `/config`에서 보고됩니다. |

플러그인은 개발 서버에서만 실행되며(`apply: 'serve'`), 프로덕션 빌드에는 아무것도 포함되지 않습니다. 버튼은 `/__i18n_devtools.html`을 열며, 이 페이지는 플러그인의 엔드포인트를 통해 파일을 읽고 저장합니다.

| 엔드포인트 | 동작 |
| --- | --- |
| `GET <base>/translations` | `translationDir` 아래의 모든 사전, 상대 경로별 |
| `POST <base>/save` | 본문 `{ file, content }`; `translationDir` 안의 기존 `.json`을 덮어쓰며, 그 외에는 403. 파일을 새로 만들지 않습니다 |
| `GET <base>/config` | `{ defaultLocale, fallbackLocale, locales, translationDir }`; `locales`는 `translationDir`의 루트 파일에서 가져옵니다 |

엔드포인트는 devtools 페이지에만 응답합니다. 다른 출처나 호스트에서 온 요청은 `403`이며, `/save`는 `application/json`만 받습니다(`415`). 페이지는 Vite의 HMR 소켓을 통해 파일 변경을 감지합니다.

Astro에서는 플러그인 대신 통합을 추가하세요. 개발 툴바에 앱이 추가됩니다.

```ts
// astro.config.mjs
import { defineConfig } from 'astro/config'
import { i18nDevToolsIntegration } from '@i18n-micro/devtools-ui/vite'

export default defineConfig({
  integrations: [i18nDevToolsIntegration({ translationDir: 'src/locales' })],
})
```

저장은 파일을 쓰기만 합니다. Vite를 통해 JSON을 import하는 앱은 HMR로 변경 사항을 받습니다. 실행 중인 인스턴스에 편집 내용을 직접 적용하려면 브리지를 사용하세요.

## 실행 중인 인스턴스에 연결하는 브리지 {#bridge-to-a-live-instance}

에디터를 자체 페이지에 임베드하고 편집 내용을 실행 중인 인스턴스에 즉시 적용하려면, 어댑터로 브리지를 만들어 `<i18n-devtools-ui>` 요소에 전달하세요.

```ts
import { createBridge, register } from '@i18n-micro/devtools-ui'
import { i18n, locales } from './i18n' // a runtime, React, Preact or Solid instance

register() // defines <i18n-devtools-ui> once

const bridge = createBridge({
  adapter: {
    getRouteCache: () => Object.fromEntries(i18n.storage.translations),
    addTranslations: (locale, content, merge) => i18n.addTranslations(locale, content, merge),
    addRouteTranslations: (locale, route, content, merge) => i18n.addRouteTranslations(locale, route, content, merge),
    subscribe: (cb) => i18n.subscribe(cb),
    getCurrentLocale: () => i18n.locale,
  },
  locales,
  defaultLocale: 'en',
  translationDir: 'src/locales',
})

const el = document.createElement('i18n-devtools-ui') as HTMLElement & { bridge: typeof bridge }
el.bridge = bridge
document.body.append(el)
```

`getRouteCache`는 `locale:route`(`en:index`, `en:blog-post`)를 키로 하는 사전을 반환해야 하며, 이는 `i18n.storage.translations`가 보관하는 형태입니다. Vue 인스턴스의 경우 `i18n.global.getRouteCache()`와 `i18n.global.subscribeToChanges(cb)`를 사용하세요.

`saveTranslation`은 먼저 인스턴스를 업데이트한 다음 `<base>/save`로 POST합니다. 엔드포인트가 없거나(정적 미리보기 빌드) 개발 서버에 연결할 수 없으면 편집 내용은 `localStorage`에 보관됩니다. 그 외의 저장 오류가 발생하면 이전 사전을 복원하고 예외를 던집니다.

## API {#api}

| 내보내기 | 진입점 |
| --- | --- |
| `i18nDevToolsPlugin(options)`, `i18nDevToolsIntegration(options)` | `@i18n-micro/devtools-ui/vite` |
| `register()`, `I18nDevToolsElement` | `@i18n-micro/devtools-ui` |
| `createBridge(options)`, 타입 `BridgeAdapter`, `CreateBridgeOptions` | `@i18n-micro/devtools-ui` (`/bridge/create`에서도 제공) |
| 타입 `I18nDevToolsBridge` | `@i18n-micro/devtools-ui` (`/bridge`에서도 제공) |
| `createRpcClient`, `setupRpcHost` | `@i18n-micro/devtools-ui` |

전체 시그니처: [패키지 레퍼런스](/ko/api/packages/devtools-ui).
