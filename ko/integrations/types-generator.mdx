title: "타입 생성기"
description: "Nuxt나 모든 Vite 프로젝트에서 JSON 파일로부터 번역 키에 대한 TypeScript 자동 완성을 생성하세요."
---

`@i18n-micro/types-generator`는 번역 폴더의 모든 JSON 파일을 읽고 모든 키를 나열하는 선언 파일을 작성합니다. 에디터가 `t()`, `$t()`, `<I18nT keypath>`에서 키를 제안하도록 하려면 추가하세요. Nuxt 모듈로도, Vite 또는 Rollup 플러그인으로도 동작하며, 파일이 변경되면 다시 생성합니다.

## 설치 {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/types-generator
```

```bash npm
npm install -D @i18n-micro/types-generator
```

```bash yarn
yarn add -D @i18n-micro/types-generator
```

</CodeGroup>

피어 의존성: `@nuxt/kit` `^3.18.0 || ^4.0.0`. `/nuxt` 엔트리만 이를 import하므로, Vite 전용 프로젝트에서는 피어 경고를 무시해도 됩니다.

## Nuxt {#nuxt}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro', '@i18n-micro/types-generator/nuxt'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

모듈은 `.nuxt/types/i18n-micro.d.ts`를 작성하고 Nuxt가 이를 타입 컨텍스트에 추가하므로, 직접 포함할 필요가 없습니다. `i18nTypes.translationDir`를 읽고, 없으면 `nuxt-i18n-micro`가 번역을 읽는 위치를 사용합니다: 모든 레이어의 `translationDir`(`i18n` 또는 인라인 모듈 옵션에서, 기본값 `'locales'`)와 `additionalTranslationDirs`. 해당 폴더의 JSON 파일을 편집하면 `nuxi dev`에서 타입이 다시 생성됩니다. Nuxt에서는 `i18nTypes.outputFile`이 무시됩니다(경고가 표시됩니다).

## Vite {#vite}

`I18nTypesPlugin`은 Vite 플러그인이며, Rollup에서도 사용할 수 있습니다. 다른 번들러의 경우 스크립트에서 `generateTypes`를 호출하세요.

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { I18nTypesPlugin } from '@i18n-micro/types-generator'

export default defineConfig({
  plugins: [
    vue(),
    I18nTypesPlugin({
      srcDir: process.cwd(),
      translationDir: 'src/locales',
      outputFile: 'src/i18n-micro.d.ts',
    }),
  ],
})
```

| 옵션 | 필수 | 참고 |
| --- | --- | --- |
| `srcDir` | 예 | 기본 디렉터리. `translationDir`는 이를 기준으로 해석됩니다. |
| `translationDir` | 예 | JSON 파일이 있는 폴더(`pages/` 같은 하위 폴더 포함) 또는 폴더 배열. |
| `outputFile` | 아니요 | 선언 파일을 작성할 위치. 기본값 `<srcDir>/i18n-micro.d.ts`. |

플러그인은 빌드 시작 시 한 번 생성하고, 개발 서버에서는 폴더가 변경된 후 300ms 뒤에 다시 생성합니다. `tsconfig.json`의 `include`가 출력 파일을 포함하는지 확인하세요.

## 키 사용하기 {#use-the-keys}

생성된 파일은 `@i18n-micro/types`의 `DefineLocaleMessage`를 확장하며, 이를 통해 `TranslationKey`가 사용자의 키가 됩니다:

```ts
declare module '@i18n-micro/types' {
  export interface DefineLocaleMessage {
    nav: object
    'nav.home': string
    'profile.title': string
  }
}
```

키는 모든 로케일과 모든 페이지 파일에서 `t()`가 응답하는 키(객체 포함)이며, JSON 값의 타입을 가집니다. `TranslationKey`는 이 키들과 임의의 문자열의 유니온이므로, 오류가 아닌 자동 완성을 얻습니다. 철자가 틀리거나 동적인 키도 여전히 컴파일됩니다. 매개변수와 반환 값에는 타입이 지정되지 않습니다.

알려진 접두사 아래의 동적 키에 대해서는 `ScopedKey<'prefix'>`가 일치하는 키로 범위를 좁힙니다:

```ts
import type { ScopedKey } from '@i18n-micro/types'

const statusText = (status: string) => t(`status.${status}` as ScopedKey<'status'>)
```

`TranslationKey`와 `ScopedKey`는 `@i18n-micro/types`에서 제공됩니다(React, Preact, Solid는 `TranslationKey`를 다시 내보내지만 Vue는 그렇지 않습니다).

## API {#api}

| 내보내기 | 엔트리 | 참고 |
| --- | --- | --- |
| `I18nTypesPlugin(options)` | `@i18n-micro/types-generator` | Vite 및 Rollup 플러그인 |
| `generateTypes(options)` | `@i18n-micro/types-generator` | 파일을 작성하고 경로를 반환 |
| `getTypesString(options)` | `@i18n-micro/types-generator` | 작성하지 않고 선언을 반환 |
| `formatKeyProperty(key)` | `@i18n-micro/types-generator` | 헬퍼 |
| Nuxt 모듈 (`configKey: 'i18nTypes'`) | `@i18n-micro/types-generator/nuxt` | 옵션 `translationDir` |

전체 시그니처: [패키지 레퍼런스](/ko/api/packages/types-generator).
