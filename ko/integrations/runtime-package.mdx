`@i18n-micro/runtime`은 프레임워크에 독립적인 i18n 인스턴스입니다: 사전, `t()`, 복수형, `Intl` 서식, 변경 구독을 제공하며 `fs`나 프레임워크가 없습니다. 일반 TypeScript, 웹 워커, 엣지 함수에서 사용하거나 자체 바인딩의 기반으로 사용하세요. React, Preact, Node, Astro 패키지는 이 같은 클래스를 확장합니다.

## 설치 {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/runtime
```

```bash npm
npm install @i18n-micro/runtime
```

```bash yarn
yarn add @i18n-micro/runtime
```

</CodeGroup>

피어 의존성이 없습니다. 디스크의 번역 파일에는 [`@i18n-micro/node`](/ko/integrations/nodejs-package)를 사용하세요.

## 설정 {#setup}

```ts
import { createI18n } from '@i18n-micro/runtime'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    en: { greeting: 'Hello, {name}!', apples: 'no apples | one apple | {count} apples' },
    de: { greeting: 'Hallo, {name}!' },
  },
  routeMessages: {
    about: { en: { title: 'About us' } },
  },
})
```

모든 옵션(`plural`, `missingWarn`, `missingHandler`, `numberFormats`, `datetimeFormats`)은 [인스턴스](/ko/integrations/overview#the-instance)에 나열되어 있습니다.

## 번역 {#translate}

```ts
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.tc('apples', 5) // '5 apples'
i18n.tn(1234.5) // '1,234.5'

i18n.setRoute('about')
i18n.t('title') // 'About us' (route dictionary)
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!' (root, still visible)
```

나중에 사전을 더 로드하기:

```ts
i18n.loadMessages({ fr: { greeting: 'Bonjour, {name} !' } }, { about: { fr: { title: 'À propos' } } })
i18n.addTranslations('fr', { nav: { home: 'Accueil' } }) // deep merge; pass false to replace

await i18n.loadFromUrl('/locales/fr.json', { locale: 'fr' })
await i18n.loadFromUrl('/locales/pages/about/fr.json', { locale: 'fr', routeName: 'about' })
await i18n.loadFromUrls([
  { url: '/locales/en.json', locale: 'en' },
  { url: '/locales/de.json', locale: 'de' },
])
```

`loadFromUrl`은 `fetch`를 사용하며(헤더는 `init`으로 전달), 응답이 OK가 아니면 예외를 던집니다. `loadFromUrls`는 하나씩 차례로 로드합니다.

## 로케일 전환 {#switch-locale}

```ts
i18n.locale = 'de'
i18n.t('greeting', { name: 'Ada' }) // 'Hallo, Ada!'
```

로케일, 라우트, 사전 변경은 구독자에게 알림을 보내며, 프레임워크 바인딩은 이를 통해 다시 렌더링합니다:

```ts
const stop = i18n.subscribe(() => {
  document.querySelector('#greeting')!.textContent = i18n.t('greeting', { name: 'Ada' }) as string
})
i18n.locale = 'fr'
stop()
```

`getSnapshot()`은 알림마다 바뀌는 문자열을 반환합니다(`useSyncExternalStore` 스타일의 스토어용).

## 요청별 인스턴스 {#per-request}

인스턴스는 하나의 로케일과 하나의 라우트를 가집니다. 서버에서는 공유 인스턴스를 요청마다 전환하지 마세요: 동시에 처리되는 두 요청이 서로의 로케일을 보게 됩니다. `i18n.fork(locale)`는 요청에 자체 인스턴스를 제공합니다: 자체 로케일, 폴백, 라우트를 가지며, 사전, 포매터, 규칙은 공유합니다. 포크 비용은 사전이 몇 개든 동일합니다. 포크는 첫 자체 쓰기 전까지 부모에 대한 쓰기를 보며, 자신의 쓰기는 포크 안에 머무릅니다. [Node.js](/ko/integrations/nodejs-package#per-request)는 `run`을 추가합니다.

## API {#api}

| 멤버 | 참고 |
| --- | --- |
| `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has` | [번역과 서식](/ko/integrations/overview#translate-and-format) 참조 |
| `locale`, `fallbackLocale` | get/set |
| `currentRoute`, `setRoute(name)`, `getRoute()` | 활성 라우트, 기본값 `'index'` |
| `loadMessages(messages?, routeMessages?)` | 여러 로케일과 라우트를 한 번에 병합 |
| `addTranslations(locale, tree, merge = true)`, `addRouteTranslations(locale, route, tree, merge = true)` | |
| `loadFromUrl(url, { locale?, routeName?, init? })`, `loadFromUrls(entries)` | JSON을 `fetch` |
| `hasTranslation(key)` | 활성 로케일, 모든 라우트(활성 라우트와 루트를 확인하는 `has`와 다름) |
| `setTranslation(key, value)`, `resolveTranslations()` | 키 하나 쓰기, 병합된 트리 읽기 |
| `clear()`, `clearCache()` | 모든 사전 제거 |
| `subscribe(cb)`, `getSnapshot()` | 변경 알림 |
| `storage` | `{ translations: Map<'locale:route', Translations> }` |

언어 태그가 아닌 코드는 `localeIso: { ua: 'uk-UA' }`에서 복수형 규칙을 가져옵니다. `localeIsoMap(locales)`는 로케일 목록에서 `iso`가 있는 항목으로 이를 만듭니다.

모듈 내보내기: `createI18n`, `I18n`, `fetchJsonTranslations`, `FormatService`, `interpolate`, `localeIsoMap`과 타입 `I18nOptions`, `LoadFromUrlOptions`, `LoadFromUrlEntry`, `TranslationStorage`, `Translations`, `Locale`, `PluralFunc`. 전체 시그니처: [패키지 레퍼런스](/ko/api/packages/runtime).
