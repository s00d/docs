`@i18n-micro/*` 패키지는 Nuxt I18n Micro의 번역 코어를 Vue, React, Preact, Solid, Astro, VitePress, 순수 JavaScript로 가져옵니다. 앱이 Nuxt 앱이 아니거나, Nuxt 밖의 스크립트나 서버가 같은 번역 파일을 필요로 할 때 사용하세요. 모든 패키지는 하나의 인스턴스 모델, 하나의 라우터 어댑터 규약, 같은 네 가지 컴포넌트를 공유하며, 이 페이지에서 한 번에 설명합니다.

## 패키지 {#packages}

| 스택 | 패키지 | 라우터 진입점 |
| --- | --- | --- |
| [Vue 3 SPA](/ko/integrations/vue-package) | `@i18n-micro/vue` | `@i18n-micro/vue/router` |
| [React](/ko/integrations/react-package) | `@i18n-micro/react` | `@i18n-micro/react/router` |
| [Preact](/ko/integrations/react-package#preact) | `@i18n-micro/preact` | — |
| [SolidJS](/ko/integrations/solid-package) | `@i18n-micro/solid` | `@i18n-micro/solid/router` |
| [Astro](/ko/integrations/astro-package): SSR 및 [아일랜드](/ko/integrations/astro-islands) | `@i18n-micro/astro` | — |
| [VitePress](/ko/integrations/vitepress-package) | `@i18n-micro/vitepress` | — |
| [브라우저 또는 엣지](/ko/integrations/runtime-package), 프레임워크 없음 | `@i18n-micro/runtime` | — |
| [Node.js](/ko/integrations/nodejs-package) 서버, CLI | `@i18n-micro/node` | — |
| [타입이 지정된 키](/ko/integrations/types-generator), Vite 또는 Nuxt | `@i18n-micro/types-generator` | — |
| 개발 중 [번역 편집기](/ko/integrations/devtools-ui-package) | `@i18n-micro/devtools-ui` | — |

라우터 진입점은 별도의 임포트이므로, 라우터가 없는 앱은 라우터를 번들에 포함하지 않습니다.

`@i18n-micro/core`, `@i18n-micro/types`, `@i18n-micro/utils`는 이 패키지들과 함께 설치되며, 직접 임포트할 일은 거의 없습니다. 모든 export의 시그니처는 생성된 [패키지 레퍼런스](/ko/api/packages/overview)에 있습니다.

각 패키지에는 저장소의 `packages/<name>/playground` 아래에 플레이그라운드가 있습니다.

## 인스턴스 {#the-instance}

`createI18n(options)`는 사전, 현재 로케일, 현재 라우트를 보유하는 인스턴스 하나를 반환합니다. 옵션은 모든 패키지에서 같습니다:

| 옵션 | 타입 | 기본값 | 참고 |
| --- | --- | --- | --- |
| `locale` | `string` | 필수 | 활성 로케일. |
| `fallbackLocale` | `string` | `locale` | `locale`에 키가 없을 때 조회합니다. |
| `messages` | `Record<locale, Translations>` | `{}` | 루트 사전(`'index'` 라우트). |
| `routeMessages` | `Record<route, Record<locale, Translations>>` | `{}` | 라우트 사전. Runtime, React, Preact, Node, VitePress 전용. |
| `plural` | `PluralFunc` | `defaultPlural` | 사용자 정의 복수형 규칙. |
| `missingWarn` | `boolean` | `true` | 키가 없을 때 브라우저에서 개발 환경 전용 `console.warn`. |
| `missingHandler` | `(locale, key, routeName) => void` | — | 경고 대신 호출됩니다. |
| `numberFormats` | `Record<locale, Record<name, Intl.NumberFormatOptions>>` | — | 이름이 있는 형식: `tn(9.5, 'currency')`. |
| `datetimeFormats` | `Record<locale, Record<name, Intl.DateTimeFormatOptions>>` | — | 이름이 있는 형식: `td(date, 'short')`. |
| `timeZone` | `string` | 런타임의 시간대 | `td` 날짜용 IANA 시간대이며, `tdr`에는 영향을 주지 않습니다. 서버와 브라우저가 같은 날짜를 렌더링하도록 설정하세요. |
| `now` | `() => number` | `Date.now` | `tdr`의 시계. 둘이 같은 텍스트를 렌더링하도록 하이드레이션에 서버의 시간을 전달하세요. |
| `localeIso` | `Record<code, string>` | — | 복수형 규칙에 사용하는 BCP 47 태그(`ua` → `uk-UA`). React, Preact, Solid는 provider의 `locales`에 있는 `iso`에서 가져옵니다. |

사전은 `locale:route`(`en:index`, `en:about`)를 키로 하는 `Map`인 `i18n.storage.translations`에 저장됩니다.

키는 현재 라우트의 사전, 그다음 루트 사전에서 조회하며, 먼저 `locale`에 대해, 그다음 `fallbackLocale`에 대해 조회합니다. 없는 키는 키 자체(또는 전달한 `defaultValue`)를 반환합니다.

```ts
i18n.addTranslations('en', { nav: { home: 'Home' } }) // root, deep-merged
i18n.addRouteTranslations('en', 'about', { title: 'About us' }) // route chunk
i18n.addTranslations('en', { nav: { home: 'Start' } }, false) // replace instead of merge
i18n.setRoute('about')
i18n.t('title') // 'About us'
i18n.t('nav.home') // 'Start' (root key, still visible on the route)
```

### 번역과 형식 지정 {#translate-and-format}

| 메서드 | 반환 값 |
| --- | --- |
| `t(key, params?, defaultValue?, routeName?)` | `{param}`이 보간된 값(문자열, 숫자, 객체). |
| `ts(...)` | `t`와 같지만 문자열로 반환. |
| `tc(key, count \| params, defaultValue?)` | 복수형. |
| `tn(value, options \| name)` | 활성 로케일의 `Intl.NumberFormat`. |
| `td(value, options \| name)` | `Intl.DateTimeFormat`. |
| `tdr(value, options?)` | 상대 시간(`3 days ago`). |
| `has(key, routeName?)` | 활성 로케일에 키가 있으면 `true`(라우트 또는 루트 사전, 폴백은 확인하지 않음). |

`defaultPlural`은 값을 `|`로 나누고 인덱스 `count`의 형태를 선택하며, 마지막 형태로 제한됩니다. 음수, 소수 또는 `NaN` count는 마지막 형태를 선택합니다.

사용자 정의 `plural`은 `(key, count, params, locale, getter)`를 받습니다. 값은 `getter(key)`로 읽고, 키를 나누지 마세요:

```ts
import type { PluralFunc } from '@i18n-micro/vue'

const plural: PluralFunc = (key, count, params, _locale, getter) => {
  const value = getter(key)
  if (typeof value !== 'string') return null
  const forms = value.split('|').map((form) => form.trim())
  return (count === 1 ? forms[0] : forms[1] ?? forms[0])!.replace('{count}', String(count))
}
```

## 라우터 어댑터 {#router-adapter}

SPA 패키지는 라우터에 의존하지 않습니다. 라우터 어댑터(`I18nRoutingStrategy`)가 현재 경로를 읽는 방법, 이동하는 방법, 현지화된 경로를 만드는 방법을 알려 줍니다. 내장 어댑터는 `defaultLocale`을 제외한 모든 로케일에 접두사를 붙입니다(`/about`, `/de/about`).

| 멤버 | 필수 | 사용처 |
| --- | --- | --- |
| `getCurrentPath(): string` | 예 | 활성 링크 확인(페이지 기준, 쿼리와 해시는 고려하지 않음), `switchLocale`(이를 유지함) |
| `push({ path }): void` | 예 | `switchLocale`, `linkComponent`가 없는 `<I18nLink>`, `<I18nSwitcher>` |
| `replace({ path }): void` | 예 | — |
| `resolvePath(to, locale)` | 아니요 | `localePath`, `localeRoute`, `<I18nLink>`. 없으면 경로가 그대로 반환됩니다 |
| `linkComponent` | 아니요 | `<I18nLink>`가 `<a>` 대신 이를 렌더링합니다(예: `RouterLink`) |
| `getRoute()` | 아니요 | SEO 헬퍼용 `{ fullPath, query }` |

`push`와 `replace`는 Vue, React, Preact, Solid에서 필수입니다. Astro에는 `push`/`replace`가 선택 사항인 자체 서버 측 어댑터가 있습니다([Astro](/ko/integrations/astro-package#router-adapter) 참고).

히스토리 기반 라우터용 최소 어댑터:

```ts
import type { I18nRoutingStrategy } from '@i18n-micro/react'

const locales = ['en', 'de']
const stripLocale = (path: string) => path.replace(/^\/(en|de)(?=\/|$)/, '') || '/'

export const historyAdapter: I18nRoutingStrategy = {
  getCurrentPath: () => window.location.pathname + window.location.search + window.location.hash,
  push: ({ path }) => window.history.pushState({}, '', path),
  replace: ({ path }) => window.history.replaceState({}, '', path),
  resolvePath: (to, locale) => {
    const path = stripLocale(typeof to === 'string' ? to : to.path || '/')
    return locale === 'en' ? path : `/${locale}${path === '/' ? '' : path}`
  },
}
```

## 컴포넌트 {#components}

Vue, React, Preact, Solid는 같은 네 가지 컴포넌트를 제공합니다. props가 일치하며, React, Preact, Solid는 그 밖의 props를 루트 요소에 전달합니다.

### `<I18nT>` {#&lt;i18nt&gt;}

| Prop | 타입 | 참고 |
| --- | --- | --- |
| `keypath` | `string` | 필수 |
| `params` | `object` | 보간 값 |
| `plural` | `number \| string` | `tc(keypath, count)`를 렌더링 |
| `number` | `number \| string` | `tn(number)`를 `{number}`로 전달 |
| `date` | `Date \| string \| number` | `td(date)`를 `{date}`로 전달 |
| `relativeDate` | `Date \| string \| number` | `tdr(relativeDate)`를 `{relativeDate}`로 전달 |
| `tag` | `string` | 래퍼 요소, 기본값 `span` |
| `html` | `boolean` | 번역을 HTML로 렌더링. 신뢰할 수 있는 번역이어야 하며, 매개변수는 이스케이프됩니다 |
| `defaultValue` | `string` | 없는 키를 대신하며, `hideIfEmpty`가 빈 값을 숨길 때 그대로 렌더링됩니다 |
| `hideIfEmpty` | `boolean` | 빈 번역이면 아무것도 렌더링하지 않음 |
| `customPluralRule` | `PluralFunc` | 이 요소의 복수형 규칙 |

형식 지정 prop은 하나만 적용되며, 다음 순서로 확인합니다: `number`, `date`, `relativeDate`, `plural`.

#### 리치 텍스트 {#rich-text}

`{placeholder}`에는 요소를 넣을 수 있습니다. Vue에서는 이름 있는 슬롯이고, React, Preact, Solid에서는 `components` prop이 이름별로 요소 또는 요소를 반환하는 함수를 제공합니다. 어느 쪽이든 같은 이름의 매개변수보다 우선하고, 모든 분기에서 동작하며, 플레이스홀더 순서를 바꾸는 로케일에서도 유지됩니다.

```tsx
// { "terms": "I accept the {link} of {company}" }
<I18nT keypath="terms" params={{ company: 'ACME' }} components={{ link: <a href="/terms">terms</a> }} />
```

Solid에서는 플레이스홀더가 반복되면 함수를 전달하세요: 노드 하나는 한 곳에만 들어갈 수 있습니다. `children`은 텍스트를 대체하며, 함수로 전달하면 Vue의 기본 슬롯처럼 `{ translation }`을 받습니다. `html`은 이 모든 것을 무시합니다.

### `<I18nLink>` {#&lt;i18nlink&gt;}

| Prop | 타입 | 참고 |
| --- | --- | --- |
| `to` | `string \| { path }` | 어댑터의 `resolvePath`를 통해 현지화됨 |
| `activeStyle` | 스타일 객체 | 현재 페이지에서 `style` 위에 병합됩니다. React, Preact, Solid는 상위 섹션에도 적용합니다 |
| `localeRoute` | 함수 | 이 링크에 대해 `resolvePath`를 재정의 |

외부 URL(`https://`, `mailto:`, `tel:`)은 `<a target="_blank" rel="noopener noreferrer">`로 렌더링되며, 직접 지정한 `target`이나 `rel`이 우선합니다. `onClick`은 항상 실행됩니다. 보조 키를 누른 클릭, 다른 마우스 버튼, 또는 `target`이 있는 경우는 브라우저가 처리합니다.

### `<I18nSwitcher>` {#&lt;i18nswitcher&gt;}

활성화된 로케일의 드롭다운(`disabled: true` 로케일은 숨겨짐)으로, 인라인 기본 스타일이 있습니다. 항목은 로케일의 `lang`, `hreflang`, `dir`이 지정된 링크입니다. 기본적으로 항목을 클릭하면 로케일을 설정하고 현지화된 현재 경로로 어댑터의 `push`를 호출합니다. `switchLocale` prop은 이 동작을 대체합니다. `localeRoute`가 있고 라우터가 없으면 브라우저가 링크를 따라갑니다. Escape 키 또는 바깥 클릭으로 닫힙니다.

| Prop | 참고 |
| --- | --- |
| `locales`, `currentLocale`, `getLocaleName` | 제공된 값을 재정의 |
| `switchLocale(code)` | 내장 전환 동작을 대체 |
| `localeRoute` | `resolvePath`를 대체 |
| `customLabels` | `{ de: 'DE' }` |
| `customWrapperStyle`, `customButtonStyle`, `customDropdownStyle`, `customItemStyle`, `customLinkStyle`, `customActiveLinkStyle`, `customDisabledLinkStyle`, `customIconStyle` | 스타일 재정의 |

### `<I18nGroup>` {#&lt;i18ngroup&gt;}

자식에게 접두사가 붙은 `t`를 전달하는 `<div class="i18n-group">`입니다. 내부의 `<I18nT>`나 `t()` 호출에는 접두사를 붙이지 **않습니다**. 전달하는 `t`에만 접두사가 붙습니다.

| Prop | 참고 |
| --- | --- |
| `prefix` | 필수, 예: `'profile'` |
| `groupClass` | 래퍼에 추가할 클래스 |

접두사가 붙은 `t`는 Vue에서는 스코프 슬롯(`v-slot="{ t }"`)으로, React, Preact, Solid에서는 render-prop 자식(`{({ t }) => …}`)으로 전달됩니다.

## 타입이 지정된 키 {#typed-keys}

`t()`는 어떤 문자열이든 받습니다. 키 자동 완성을 얻으려면 [타입 생성기](/ko/integrations/types-generator)로 선언을 생성하세요. 키는 제안될 뿐 강제되지 않으며, 매개변수에는 타입이 지정되지 않습니다.

## Nuxt 모듈과의 비교 {#compared-with-the-nuxt-module}

패키지에는 파일 기반 라우팅, 서버 미들웨어, 번역 로더가 없습니다: JSON을 언제 로드할지(`import`, `fetch`, 또는 서버의 `@i18n-micro/node`)와 어떤 라우터 어댑터를 사용할지 직접 결정합니다. 로케일 감지, SEO 메타, 라우트 생성은 Nuxt 기능입니다. Astro에는 감지용 자체 미들웨어와 SEO용 `useLocaleHead`가 있습니다.
