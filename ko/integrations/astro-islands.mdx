---
title: "Astro 아일랜드"
description: "@i18n-micro/astro로 Vue, React, Preact, Svelte 아일랜드 내부에서 번역을 사용합니다."
---

아일랜드는 서버의 i18n 인스턴스가 존재하지 않는 브라우저에서 실행됩니다. `@i18n-micro/astro`를 사용하면 페이지가 아일랜드에 필요한 키를 골라 하나의 prop으로 전달하고, 아일랜드에서는 작은 프레임워크 어댑터를 통해 이를 읽을 수 있습니다. Vue, React, Preact, Svelte 아일랜드에서 `t`, `tc`, `tn`, `td`, `tdr`, `has`를 사용할 수 있으며, HTML에는 선택한 문자열만 포함됩니다.

## 설정 {#setup}

먼저 [Astro 통합과 미들웨어](/ko/integrations/astro-package#setup)를 설정한 다음, 사용하는 프레임워크 통합(`@astrojs/vue`, `@astrojs/react`, `@astrojs/preact`, `@astrojs/svelte`)을 추가하세요. 아일랜드 어댑터에는 해당 프레임워크가 피어로 필요합니다: `vue` `^3.3.0`, `react` `^16.8.0 || ^17.0.0 || ^18.0.0 || ^19.0.0`, `preact` `^10.0.0 || ^11.0.0` 또는 `svelte` `^4.0.0 || ^5.0.0`.

## 아일랜드에 번역 전달하기 {#pass-translations-to-an-island}

```astro
---
// src/pages/index.astro
import { getI18nProps } from '@i18n-micro/astro'
import Counter from '../components/Counter.vue'

const i18n = getI18nProps(Astro, ['counter.title', 'counter.apples'])
---

<Counter client:load i18n={i18n} />
```

`getI18nProps(Astro, keys?)`는 `{ locale, fallbackLocale, currentRoute, translations }`(타입 `I18nClientProps`)를 반환합니다. 아일랜드가 사용하는 키를 전달하세요: 각 키는 서버에서 `t()`처럼(라우트, 루트, 폴백 사전) 해석되며, 찾은 키만 HTML에 포함됩니다. `keys`가 없으면 이 페이지에서 `t()`가 응답할 수 있는 모든 것이 모든 아일랜드에 전송되므로, 루트 키 2000개는 아일랜드당 약 100 KB가 됩니다. 개발 환경에서는 20 KB를 넘으면 경고가 표시됩니다.

아일랜드는 해당 객체에서만 번역합니다. `t`는 전달되지 않은 항목에 대해 키를 반환하며, 연결된 메시지는 해석되지 않습니다.

## Vue {#vue}

아일랜드의 루트 컴포넌트에서 `provideI18n(() => props.i18n)`을 호출하고 자식에서 `useAstroI18n()`을 호출하세요. Vue의 `inject`는 같은 컴포넌트가 제공한 값을 보지 못하므로, 훅은 루트가 아닌 자식에서 실행해야 합니다:

```vue
<!-- src/components/Counter.vue -->
<script setup lang="ts">
import { provideI18n } from '@i18n-micro/astro/client/vue'
import type { I18nClientProps } from '@i18n-micro/astro'
import CounterBody from './CounterBody.vue'

const props = defineProps<{ i18n: I18nClientProps }>()
provideI18n(() => props.i18n)
</script>

<template><CounterBody /></template>
```

```vue
<!-- src/components/CounterBody.vue -->
<script setup lang="ts">
import { ref } from 'vue'
import { useAstroI18n } from '@i18n-micro/astro/client/vue'

const { t, tc } = useAstroI18n()
const count = ref(0)
</script>

<template>
  <h3>{{ t('counter.title') }}</h3>
  <button @click="count++">{{ tc('counter.apples', count) }}</button>
</template>
```

## React와 Preact {#react-and-preact}

```tsx
// src/components/Counter.tsx
import { useState } from 'react'
import { I18nProvider, useAstroI18n } from '@i18n-micro/astro/client/react'
import type { I18nClientProps } from '@i18n-micro/astro'

function Body() {
  const { t, tc } = useAstroI18n()
  const [count, setCount] = useState(0)
  return <button onClick={() => setCount(count + 1)}>{t('counter.title')}: {tc('counter.apples', count)}</button>
}

export default function Counter({ i18n }: { i18n: I18nClientProps }) {
  return (
    <I18nProvider value={i18n}>
      <Body />
    </I18nProvider>
  )
}
```

Preact에서는 `@i18n-micro/astro/client/preact`에서 `I18nProvider`와 `useAstroI18n`을 가져오세요. API는 같습니다.

## Svelte {#svelte}

```svelte
<!-- src/components/Counter.svelte -->
<script lang="ts">
  import { createI18nStore, useAstroI18n } from '@i18n-micro/astro/client/svelte'
  import type { I18nClientProps } from '@i18n-micro/astro'

  export let i18n: I18nClientProps
  const { t, tc } = useAstroI18n(createI18nStore(i18n))
  let count = 0
</script>

<button on:click={() => count++}>{t('counter.title')}: {tc('counter.apples', count)}</button>
```

`useAstroI18n(store)`는 템플릿에서 `$store`로 읽을 수 있도록 `store`도 반환합니다.

## 유지되는 아일랜드 {#persisted-islands}

`transition:persist`가 있는 아일랜드는 내비게이션 후 새 props를 받습니다. React, Preact, Vue(getter가 주어진 경우)는 이를 따릅니다. Svelte에서는 스토어를 유지하고 props를 전달하세요: `const store = createI18nStore(i18n)`, `const { t } = useAstroI18n(store)`, 그다음 `$: store.set(i18n)`(runes를 사용하면 `$effect(() => store.set(i18n))`).

## API {#api}

| 진입점 | 내보내기 |
| --- | --- |
| `@i18n-micro/astro` | `getI18nProps`, 타입 `I18nClientProps` |
| `@i18n-micro/astro/client/vue` | `provideI18n(props \| () => props)`, `useAstroI18n()` |
| `@i18n-micro/astro/client/react` | `I18nProvider` (`value` prop), `useAstroI18n()` |
| `@i18n-micro/astro/client/preact` | `I18nProvider` (`value` prop), `useAstroI18n()` |
| `@i18n-micro/astro/client/svelte` | `createI18nStore(props)`, `useAstroI18n(store)` |
| `@i18n-micro/astro/client` | 프레임워크 없는 순수 `translate`, `hasTranslation` |

모든 `useAstroI18n`은 `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`, `setLocale`, `setRoute`와 `locale`을 반환합니다. 아일랜드에는 병합된 사전이 하나 있으므로, `has`는 폴백 로케일을 포함해 `t`가 응답할 수 있는 키에 대해 true입니다. 서버에서 `has`는 활성 로케일만 확인합니다.
