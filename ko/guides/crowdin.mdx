# 🌐 Crowdin 통합 가이드

## 📖 소개

Crowdin을 프로젝트에 통합하면 지역화 및 번역 프로세스를 간소화하여 여러 언어와 플랫폼 간 번역을 더 쉽게 관리할 수 있습니다. 이 가이드는 프로젝트에서 Crowdin을 설정하는 단계별 안내를 제공하며, 설정, 소스 업로드, 번역 다운로드를 포함합니다.

## 🔧 설치 및 설정

Crowdin을 시작하려면 컴퓨터에 Crowdin CLI를 전역으로 설치하고 프로젝트 디렉터리 내에서 초기화해야 합니다.

### 📦 Crowdin CLI 설치

먼저 npm을 사용하여 Crowdin CLI를 전역으로 설치합니다:

```bash
npm install -g @crowdin/cli
```

### 🛠 프로젝트에서 Crowdin 초기화

다음을 실행하여 프로젝트에서 Crowdin을 초기화합니다:

```bash
crowdin init
```

이 명령은 프로젝트 ID, API 토큰 및 기타 설정 세부 정보를 설정하는 단계로 안내합니다.

## 🗂️ 설정 가이드

### 📄 Crowdin 설정 파일 (`crowdin.yml`)

Crowdin 설정 파일(`crowdin.yml`)은 소스 파일이 매핑되는 방식과 번역이 배치되어야 하는 위치를 정의합니다. 다음은 예제 설정입니다:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 주요 설정 매개변수

- **`project_id`**: Crowdin 프로젝트 ID. 번역이 관리되는 Crowdin 내 프로젝트를 식별합니다.
- **`api_token`**: 인증에 사용되는 API 토큰. 이 토큰이 번역을 업로드하고 다운로드할 수 있는 올바른 권한을 갖고 있는지 확인하세요.
- **`base_path`**: 소스 파일의 기본 디렉터리를 지정합니다. 이 예제에서 번역은 `./locales` 디렉터리에 저장됩니다.
- **`base_url`**: Crowdin API의 기본 URL.
- **`preserve_hierarchy`**: `true`로 설정하면 Crowdin이 프로젝트에서 소스 파일의 폴더 구조를 유지합니다.

### 📂 파일 설정

`files` 섹션은 소스 파일을 번역이 저장될 경로에 매핑합니다. 예를 들어:

- **Source Path**: 원본 번역 파일의 위치를 정의합니다.
- **Translation Path**: Crowdin에서 번역된 파일이 저장될 위치를 지정합니다. `%two_letters_code%` 같은 자리 표시자는 파일 경로에서 언어 코드를 동적으로 설정하는 데 사용됩니다.

## ⬆️ Crowdin에 소스 파일 업로드

Crowdin 설정이 완료되면 다음 명령을 사용하여 소스 파일을 업로드할 수 있습니다:

```bash
crowdin upload sources
```

이 명령은 설정에서 지정된 모든 소스 파일을 Crowdin에 업로드하여 번역할 수 있게 합니다.

## ⬇️ Crowdin에서 번역 다운로드

Crowdin에서 번역이 완료되거나 업데이트된 후, 다음을 사용하여 프로젝트에 다운로드할 수 있습니다:

```bash
crowdin download
```

이 명령은 Crowdin에서 최신 번역을 가져와 설정 파일에 지정된 경로에 따라 저장합니다.

## ⚙️ 모범 사례

### 🔑 일관된 키 명명

혼란과 중복을 피하기 위해 모든 파일에서 번역 키가 일관되도록 하세요.

### 🧹 정기적인 유지 관리

사용하지 않는 번역 키를 주기적으로 검토하고 정리하여 파일을 정리되고 관리 가능하게 유지하세요.

### 🛠 업로드 및 다운로드 자동화

Crowdin CLI 명령을 CI/CD 파이프라인에 통합하여 소스 파일 업로드와 번역 다운로드를 자동화하고, 번역이 항상 최신 상태로 유지되도록 하세요.

이 가이드를 따르면 프로젝트에 Crowdin을 매끄럽게 통합하여 국제화 노력을 효율적이고 조직적으로 관리할 수 있습니다.
