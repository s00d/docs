# 🛠️ `nuxt-i18n-micro`의 DevTools

## Vue DevTools (브라우저 확장)

개발 중에 이 모듈은 `@vue/devtools-api`를 통해 **Vue DevTools** 사용자 정의 인스펙터와 타임라인을 등록할 수 있습니다. 이는 아래의 Nuxt DevTools 탭과는 별개입니다.

| 도구 | 최적 용도 |
|------|----------|
| **Vue DevTools** | 라이브 로케일, 메모리 내 번역 캐시, `$t` 타임라인(`debug: true`), 누락된 키 이벤트 |
| **Nuxt DevTools 탭** | 디스크의 JSON 파일 편집, 설정 개요, 가져오기/내보내기 |

vue-devtools 플러그인은 `nuxt dev` 중에만 등록됩니다(프로덕션 빌드에서는 아님). 메인 플러그인의 개발 전용 브리지 상태는 `import.meta.dev` 데드 코드 제거로 제거됩니다.

Nuxt 탭은 유지하면서 브라우저 통합을 비활성화하려면:

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

자세한 `$t` 타임라인 이벤트에는 `debug: true`가 필요합니다.

## 📖 Nuxt DevTools란?

DevTools는 `nuxt-i18n-micro` 모듈에 매끄럽게 통합된 강력한 개발 도우미입니다. 지역화 및 번역 작업을 관리하는 직관적인 인터페이스를 제공하여 워크플로를 더 빠르고 효율적으로 만들어 줍니다. 편의성을 중시하는 개발자를 위해 설계된 Nuxt DevTools는 코딩과 런타임 관리 간의 격차를 메웁니다.

## 🌟 `nuxt-i18n-micro`의 DevTools 주요 기능

### 1. **로케일 관리**

애플리케이션에서 로케일을 손쉽게 탐색, 선택, 관리하세요. 단일 언어로 작업하든 여러 언어로 작업하든, DevTools는 모든 지역화 설정을 처리하기 위한 중앙 허브를 제공합니다.

### 2. **번역 편집**

통합된 JSON 편집기를 통해 번역 파일을 직접 편집할 수 있습니다. 이는 외부 도구가 필요 없게 하여 워크플로를 중단시키지 않고 실시간으로 업데이트와 변경을 할 수 있게 합니다.

### 3. **파일 가져오기 및 내보내기**

번역 파일 관리 프로세스를 단순화합니다:

- **내보내기**: 백업이나 외부 사용을 위해 번역을 JSON 파일로 저장합니다.
- **가져오기**: 프로젝트에 업데이트된 번역 파일을 로드하여 콘텐츠를 최신 상태로 유지합니다.

### 4. **실시간 미리 보기**

개발 환경 내에서 변경 사항을 즉시 확인하세요. 이 기능은 번역과 설정이 라이브로 가기 전에 정확한지 확인합니다.

### 5. **매끄러운 Nuxt 통합**

DevTools는 `nuxt-i18n-micro`와 기본적으로 함께 작동하며 추가 설정 없이 기능을 향상시킵니다. Nuxt의 모듈식이고 유연한 구조를 유지하면서 지역화 요구에 적응합니다.

---

## 🛠️ DevTools를 사용하는 이유는?

Nuxt DevTools는 지역화가 필요한 프로젝트에 필수적인 추가 기능입니다. 개발자에게 다음과 같은 도움을 줍니다:

- **시간 절약**: 파일 관리 및 형식 검증 같은 반복 작업을 자동화합니다.
- **오류 감소**: 번역을 편집하기 위한 안전하고 직관적인 환경을 제공합니다.
- **협업 개선**: 비개발자가 번역을 쉽게 관리할 수 있게 합니다.
- **워크플로 간소화**: 여러 지역화 작업을 단일 인터페이스로 통합합니다.

---

## 🚀 지역화 제어

`nuxt-i18n-micro`에 통합된 Nuxt DevTools를 사용하면 다국어 애플리케이션 관리가 간단하고 효율적으로 됩니다. 번역을 미세 조정하든 새 로케일을 추가하든, DevTools는 세련되고 사용자 친화적인 경험을 제공하는 데 필요한 도구를 제공합니다.
