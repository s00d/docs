# 컴포넌트에서 번역 사용하기

모듈이 설치되고 구성되면 Vue 템플릿과 스크립트 내에서 `$t('your_key')`를 호출하여 번역을 표시할 수 있습니다.

## 1. 루트 레벨 및 페이지별 번역 파일

1. **루트 레벨** 번역은 `/locales` 폴더 바로 아래에 위치합니다(예: `/locales/en.json`, `/locales/fr.json`). 빌드 타임에 모든 페이지별 파일로 자동 병합되어 모든 페이지에서 사용할 수 있게 됩니다.
2. **페이지별** 번역은 Nuxt pages 폴더 구조와 일치하는 `/locales/pages/...` 아래에 위치합니다:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. `$t`를 사용한 템플릿 사용법

`.vue` 파일에서 템플릿에 `$t`를 직접 사용할 수 있습니다:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
키가 중첩된 JSON 노드를 가리키는 경우 `$t`는 **객체**를 반환할 수 있습니다(예: `$t('header')` → `\{ title: "Hi" \}`). 템플릿에서는 `[object Object]`로 렌더링됩니다. 문자열이 보장되어야 할 때는 `$ts`를 사용하거나 `$t('header.title')`처럼 더 구체적인 키를 제공하세요. 자세한 내용은 [API 참조 — $t vs $ts](/api/methods#t)를 확인하세요.
</Tip>

## 3. 현재 로케일 전환

앱에서 언어를 변경하려면 `useI18n()`에서 `$locale`을 가져오고 새 코드를 할당하면 됩니다:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. 중첩 키와 플레이스홀더

- **중첩 키**는 점 표기법을 사용합니다. 예: `nested.key.deeper`.
- **플레이스홀더**로 동적 값을 삽입할 수 있습니다:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. 팁 및 모범 사례

- **충돌하는 키**: 페이지별 파일에 루트 레벨 파일과 같은 키가 포함된 경우 페이지별 버전이 우선합니다(루트 번역은 빌드 타임에 기본으로 병합됨).
- **페이지 파일 비활성화**: 페이지별 번역을 사용하지 않으려면 Nuxt 설정에서 `disablePageLocales: true`로 지정할 수 있습니다. 이 경우 `/locales/*.json` 파일만 사용됩니다.
- **직접 import 불필요**: `import \{ useI18n \} from 'nuxt-i18n-micro'`를 할 필요가 없습니다. 모듈의 자동 주입 기능이 이를 처리합니다.

이것으로 끝입니다! 이러한 단계로 루트 레벨 또는 페이지별 JSON 파일에서 번역을 빠르게 **가져와서** Nuxt 애플리케이션에 `$t`를 사용해 **표시**할 수 있습니다.

## 추가 자료

더 고급 기능을 살펴보려면 다음을 확인하세요:

1. **`<i18n-t>` 컴포넌트**  
   `<i18n-t>` 컴포넌트는 `$t`의 강력한 대안으로, 특히 중첩된 요소, 고급 플레이스홀더 사용, 더 복잡한 번역 구조가 관련된 상황에서 유용합니다.

- **문서**: [i18n-t](/api/components/i18n-t)

2. **`useI18n` 컴포저블**  
   `useI18n` 컴포저블은 번역 관리, 로케일 전환 처리, 형식화 등에 필요한 전체 함수와 반응형 속성을 제공합니다.

- **문서**: [useI18n](/api/composables/use-i18n)
