## 🚀 빠른 시작

### 설치

Nuxt 애플리케이션에 모듈을 설치합니다:

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

### 기본 설정

`nuxt.config.ts`에 모듈을 추가합니다:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

<Tip>
- **루트 레벨 파일**(`locales/en.json` 등) — 앱 전체에서 공유되는 번역(메뉴, 푸터, 공통 UI). 기본값인 `translationPayloads.mode: 'premerged'`에서는 빌드 시 모든 페이지에 병합됩니다.
- **페이지별 파일**(`locales/pages/<route>/<locale>.json`) — 특정 페이지에 고유한 번역이며, 페이지 방문 시에만 로드됩니다.
- **동적 라우트** — `pages/articles/[id].vue`는 `locales/pages/articles-id/`에 매핑됩니다(대괄호는 대시로 대체됨).
- **자동 생성** — 모든 번역 파일은 `nuxt dev` 중 누락되었을 때 자동으로 생성됩니다.
</Tip>

<Info>
이 모듈은 두 레이아웃을 모두 지원합니다:

- **페이지**: `pages/**/*.vue` (Nuxt 3) 또는 `app/pages/**/*.vue` (Nuxt 4)
- **번역**: 기본적으로 `locales/`를 **프로젝트 루트**에 유지합니다(권장 관례). `app/` 내부가 아닙니다.

```tree
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   ├── en.json
│   └── pages/
└── nuxt.config.ts
```

선택적 콜로케이션: `i18n: \{ translationDir: 'app/locales' \}` ([픽스처 `n3`](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/n3) 참고).

선택적 CLI 헬퍼 `text-to-i18n`을 사용하려면 [`nuxt-i18n-micro-cli` ≥ 2.1.1](/guides/cli#-text-to-i18n-command)을 사용하여 `app/pages` 및 `app/components`가 프로젝트 루트에서 스캔되도록 하세요.
</Info>

### 기본 사용법

컴포넌트에서 번역을 사용합니다:

```vue
<template>
  <div>
    <h1>{{ $t('welcome') }}</h1>
    <p>{{ $t('description', { name: 'World' }) }}</p>

    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" @click="$switchLocale(locale.code)">
        {{ locale.code }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useI18n } from '#imports'

const { $t, $getLocales, $switchLocale } = useI18n()
</script>
```
