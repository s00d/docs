---
title: "경로 제외"
description: "excludePatterns로 페이지와 파일을 로케일 라우팅에서 제외하고, 이미 제외된 경로를 확인합니다."
---

일부 경로는 로케일 접두사나 로케일 리디렉션을 절대 받으면 안 됩니다: 관리자 영역, 헬스 체크, 생성된 피드 등입니다. `excludePatterns`가 이러한 경로를 표시하며, 기본 제공 목록이 이미 Nuxt 내부 경로와 일반적인 정적 파일을 처리합니다. 제외된 페이지는 작성한 경로를 그대로 유지하며 여전히 `$t`로 렌더링됩니다.

## 경로 제외하기 {#exclude-a-path}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    excludePatterns: [
      '/admin', // /admin and everything below it
      '/preview-*', // glob over the whole path
    ],
  },
})
```

이 설정에서 `pages/admin/index.vue`는 `/admin`에서만 응답합니다. `/de/admin`은 없으며, `/admin`은 절대 `/de/admin`으로 리디렉션되지 않습니다.

## 패턴 구문 {#pattern-syntax}

패턴은 `app.baseURL`을 제외한 경로와 비교됩니다:

| 패턴 | 일치 | 불일치 |
| --- | --- | --- |
| `'/admin'` | `/admin`, `/admin/users` | `/administrator`, `/de/admin` |
| `'/preview-*'` | `/preview-1`, `/preview-a/b` | `/de/preview-1` |
| `'/file-?'` | `/file-a` | `/file-ab` |
| `/^\/v\d+\//` | `/v2/docs` | `/docs` |

`*`나 `?`가 없는 문자열은 해당 경로와 그 아래의 전체 세그먼트에 일치합니다. `*`(슬래시를 포함한 임의의 문자열) 또는 `?`(한 문자)가 있으면 전체 경로와 일치해야 합니다. 문자열은 항상 `/`로 시작하세요.

## 이미 제외된 경로 {#what-is-excluded-already}

다음 경로는 아무 설정 없이도 로케일 라우트나 리디렉션을 받지 않습니다:

- `/api`와 `/_nuxt`, 그리고 그 아래의 모든 경로;
- 번역 라우트, 기본값은 `/_locales` ([`apiBaseUrl`](/ko/api/module-options#apibaseurl));
- `__`로 시작하는 세그먼트가 있는 모든 경로 (`/__nuxt_content`, `/en/__og-image__`);
- `/sitemap*.xml`, `/robots.txt`, `/favicon.ico`, `/apple-touch-icon*.png`, `/manifest.json`, `/sw.js`, `/workbox-*.js`;
- 마지막 세그먼트가 정적 파일 확장자로 끝나는 모든 경로: `xml txt ico json js css png jpg jpeg gif svg webp avif pdf wasm map mp4 webm mp3 zip gz woff woff2 ttf eot`. `/user/john.doe` 같은 점이 포함된 페이지 슬러그와 `.html` 경로는 페이지로 유지됩니다.

## 제외의 효과 {#what-an-exclusion-does}

- **라우트:** 현지화된 변형이 생성되지 않으며, 페이지는 작성된 그대로 유지됩니다.
- **리디렉션과 404:** 서버 리디렉션 플러그인과 클라이언트 리디렉션 미들웨어가 해당 경로를 건너뜁니다.
- **프리렌더:** 일치하는 경로는 프리렌더 라우트 목록에서 제거됩니다.

제외는 i18n 서버 미들웨어가 요청의 로케일을 감지하는 것을 막지 않으며, 페이지가 번역을 사용하는 것도 막지 않습니다. 페이지를 현지화된 상태로 유지하되 SEO 태그에서 빼려면 `disableMeta`를 사용하세요 ([페이지 설정](/ko/guide/per-component-translations#turn-off-seo-tags)). `nuxt.config.ts`에서 경로로 한 페이지를 현지화하지 않으려면 `globalLocaleRoutes: { '/admin': false }` ([현지화된 경로](/ko/guide/custom-locale-routes#in-nuxt-config))가 라우팅에 대해 같은 역할을 합니다.
