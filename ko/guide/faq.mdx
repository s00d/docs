주제별 페이지에서 직접 답하지 않는 질문 중, 사람들이 가장 자주 겪는 문제에 대한 짧은 답변입니다. 각 답변은 해당 주제를 다루는 페이지로 연결됩니다. 원하는 답이 없다면 문서를 검색하거나 [이슈](https://github.com/s00d/nuxt-i18n-micro/issues)를 등록하세요.

## 번역 {#translations}

### 플러그인이나 유틸리티 함수에서 `$t`가 실패합니다 {#$t-fails-in-a-plugin-or-a-utility-function}

컴포저블에는 Nuxt 컨텍스트가 필요합니다. `setup` 외부에서는 앱에서 헬퍼를 가져오거나, `await` 이후에는 앱의 컨텍스트 안에서 실행하세요:

```ts
const nuxtApp = useNuxtApp()
const title = nuxtApp.$t('errors.unknown')
await nuxtApp.runWithContext(() => nuxtApp.$t('errors.unknown'))
```

앱이 전혀 없는 서비스에서는 키를 전달하고 컴포넌트에서 번역하세요.

### 한 페이지에서만 키가 원시 텍스트로 표시됩니다 {#a-key-shows-as-raw-text-on-one-page-only}

키가 다른 페이지의 파일에 있습니다. 페이지는 루트 파일과 자신의 `locales/pages/<route-name>/` 파일만 볼 수 있으므로, 공유 키는 루트 파일로 옮기세요. [번역 파일](/ko/guide/translations)을 참고하세요.

### 페이지 전환 중에 키가 깜빡입니다 {#keys-flash-while-a-page-transition-runs}

그래서는 안 됩니다: 떠나는 페이지의 키는 전환이 끝날 때까지 해석됩니다. 그래도 깜빡인다면, 키가 어느 페이지에도 속하지 않는 페이지 파일(예: 레이아웃)에만 있는 것입니다. 루트 파일로 옮기세요.

### Vercel, Netlify 또는 Edge에서 SSR 중 번역이 누락됩니다 {#translations-are-missing-during-ssr-on-vercel-netlify-or-edge}

그곳에서는 서버 함수가 `public/`을 읽을 수 없으므로 페이로드가 서버 번들에 포함됩니다. 이것이 기본값이니 `translationPayloads.serverAssets`가 꺼져 있지 않은지 확인하세요. 로그에 `public/ is not deployed next to the server`가 표시되면 `nitro.serveStatic: false`를 설정하세요. [배포](/ko/guide/deployment)를 참고하세요.

### 번역된 문장 안에 링크를 넣으려면 어떻게 하나요? {#how-do-i-put-a-link-inside-a-translated-sentence}

`<i18n-t>`를 사용하세요: 각 이름이 지정된 슬롯이 같은 이름의 `{placeholder}`를 채웁니다.

```vue
<!-- "share": "Share your {link} with friends" -->
<i18n-t keypath="share">
  <template #link>
    <i18n-link :to="{ name: 'referral' }">{{ $t('referralLink') }}</i18n-link>
  </template>
</i18n-t>
```

[`<i18n-t>`](/ko/components/i18n-t)를 참고하세요. vue-i18n의 연결된 메시지와 수정자는 지원되지 않으므로, 이처럼 템플릿에서 조합하세요.

## 로케일과 URL {#locales-and-urls}

### `/en/about`이 404입니다 {#/en/about-is-a-404}

기본값인 `prefix_except_default`에서는 기본 로케일에 접두사가 없습니다: `/about`이 영어입니다. `/en/...`을 원한다면 `prefix` 또는 `prefix_and_default`를 사용하세요. [라우팅 전략](/ko/guide/strategy)을 참고하세요.

### 딥 링크에서 방문자가 리디렉션되지 않습니다 {#visitors-are-not-redirected-on-deep-links}

기본적으로 `/`만 브라우저 언어나 쿠키를 따르므로, 공유된 링크는 해당 언어를 유지합니다. `autoDetectPath: 'no_prefix'` 또는 `'*'`를 설정하세요. [로케일 감지](/ko/guide/locale-detection#autodetectpath)를 참고하세요.

### 새로고침 후 선택한 언어가 잊혀집니다 {#the-chosen-language-is-forgotten-after-a-reload}

접두사 전략에서는 로케일 쿠키가 꺼져 있습니다. `localeCookie: 'user-locale'`을 설정하세요. [로케일 감지](/ko/guide/locale-detection#the-cookie)를 참고하세요.

### URL을 바꾸지 않고 로케일을 전환할 수 있나요? {#can-i-switch-locale-without-changing-the-url?}

`strategy: 'no_prefix'`에서만 가능하며, 이때 `$switchLocale('de')`는 같은 경로에서 사전을 다시 로드합니다. 접두사 전략에서는 로케일이 URL의 일부이므로 전환 시 페이지 이동이 발생합니다. 호출 대신 링크를 원한다면 `$switchLocalePath('de')`를 사용하세요.

### 로케일을 전환하면 페이지가 맨 위로 스크롤됩니다 {#the-page-scrolls-to-the-top-when-i-switch-locale}

이는 모든 페이지 이동에 적용되는 Nuxt의 `scrollBehavior`입니다. `definePageMeta({ scrollToTop: false })`를 설정하고 위치를 직접 복원하세요. 플레이그라운드의 [`SwitchLocalePreserve.vue`](https://github.com/s00d/nuxt-i18n-micro/blob/main/playground/components/SwitchLocalePreserve.vue)는 복사해서 쓸 수 있는 래퍼입니다([데모 페이지](https://github.com/s00d/nuxt-i18n-micro/blob/main/playground/pages/scroll-test.vue)).

## 빌드와 통합 {#build-and-integrations}

### `nuxt-seo:defaults depends on nuxt-site-config:i18n but they are not registered` {#nuxt-seodefaults-depends-on-nuxt-site-configi18n-but-they-are-not-registered}

오래된 `nuxt-site-config`는 `@nuxtjs/i18n`만 인식합니다. `@nuxtjs/seo`를 3 이상으로 업그레이드하고 `modules`에서 `nuxt-i18n-micro`를 그보다 앞에 나열하세요. [SEO](/ko/guide/seo)를 참고하세요.

### Cloudflare에서 `@unhead/vue` 관련 빌드 오류 {#build-error-about-@unhead/vue-on-cloudflare}

사전 렌더링 단계에서 찾을 수 있도록 앱에 `@unhead/vue`를 설치하세요. 모듈 자체는 `nodejs_compat`이 필요하지 않습니다: 앱의 다른 무언가가 필요로 하는 경우에만 `wrangler.toml`에 `compatibility_flags = ["nodejs_compat"]`를 추가하세요.
