`nuxt dev`에서 모듈은 두 가지 디버깅 도구를 추가합니다. 번역 파일을 탐색하고 편집하기 위한 Nuxt DevTools의 **i18n Micro** 탭과, 실시간 로케일 및 로드된 사전을 위한 Vue DevTools 인스펙터입니다. 둘 다 개발 모드에서만 존재하며 프로덕션 빌드에는 아무것도 추가하지 않습니다. Nuxt 탭은 Nuxt DevTools만 활성화되어 있으면 되고, Vue 인스펙터는 추가로 Vue DevTools 브라우저 확장 프로그램이 필요합니다.

## Nuxt DevTools 탭 {#nuxt-devtools-tab}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  devtools: { enabled: true }, // the tab is registered only when DevTools are on
})
```

Nuxt DevTools(`Shift + Alt + D`)를 열고 **i18n Micro**를 선택하세요. 탭에는 다음이 표시됩니다.

- 모든 레이어의 `locales/`(루트 및 `pages/`) 아래에 있는 모든 JSON 파일과 `additionalTranslationDirs`의 루트 파일
- 파일별 편집기. **Save**를 누르면 파일이 디스크에 다시 기록되고 개발 서버가 번역을 다시 로드합니다
- 파일의 JSON **Export** / **Import**, 그리고 키 개수와 번역 커버리지를 보여 주는 **Stats**
- 해석된 모듈 옵션의 설정 보기
- 탭 설정에서 구성한 기계 번역 엔진으로 누락된 키를 채우는 **Translate**

저장은 번역 디렉터리 안에 이미 존재하는 `.json` 파일에만 기록합니다. 파일이 여러 레이어에 존재하면 프로젝트의 사본에 기록됩니다.

## Vue DevTools 인스펙터 {#vue-devtools-inspector}

Vue DevTools 브라우저 확장 프로그램이 있으면, 모듈은 i18n 인스펙터(현재 로케일, 라우트 청크, 로드된 키)와 로케일 전환, 청크 로드, 누락된 키를 보여 주는 타임라인을 등록합니다.

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    debug: true, // also log every $t / $ts / $tc call on the timeline
    // vueDevtools: false, // turn the inspector off, keep the Nuxt tab
  },
})
```

[`vueDevtools`](/ko/api/module-options)의 기본값은 `true`입니다. `debug: true`는 출력이 많으므로 짧은 세션에서만 사용하세요.

## Nuxt 외부에서 {#outside-nuxt}

같은 UI가 프레임워크 패키지 기반의 Vite 앱을 위해 [`@i18n-micro/devtools-ui`](/ko/integrations/devtools-ui-package)로 게시되어 있습니다. 설정 방법은 해당 페이지를 참고하세요.
