이 페이지는 i18n이 없는 Nuxt 앱을 언어 스위처가 있는 번역된 페이지로 만드는 과정을 안내합니다. 프로젝트를 시작할 때 한 번만 필요합니다. 결과적으로 현지화된 URL(`/about`, `/de/about`), 로케일 및 페이지별 JSON 파일 하나, 그리고 템플릿에서 사용하는 `$t`를 얻게 됩니다.

## 설치 {#install}

이 모듈은 Nuxt 3.18 이상(Nuxt 4도 동작)과 Node 20 이상이 필요합니다.

<CodeGroup>

```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>

## 로케일 구성 {#configure-the-locales}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', displayName: 'English' },
      { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
      { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
    ],
    defaultLocale: 'en',
  },
})
```

첫 앱에 필요한 구성은 이것이 전부입니다. 기본값은 다음을 제공합니다:

- `strategy: 'prefix_except_default'`: 기본 로케일에는 접두사가 없고(`/about`), 나머지에는 있습니다(`/de/about`). [라우팅 전략](/ko/guide/strategy)을 참고하세요.
- `translationDir: 'locales'`: 번역 파일은 프로젝트 루트의 `locales/`에 있으며, Nuxt 4 `app/` 레이아웃에서도 마찬가지입니다.
- `meta: true`: `hreflang`, canonical, `og:locale` 태그와 `<html>`의 `lang` 및 `dir`. [SEO](/ko/guide/seo)를 참고하세요.
- `/`를 연 방문자는 브라우저가 요청하는 언어(`Accept-Language`)로 보내집니다. [로케일 감지](/ko/guide/locale-detection)를 참고하세요.

`iso`는 SEO 태그에 사용되는 언어 태그이고, `code`는 URL에 나타나는 값입니다. 모든 옵션은 [모듈 옵션](/ko/api/module-options)에 나열되어 있습니다.

## 번역 파일 추가 {#add-translation-files}

`nuxt dev`로 개발 서버를 시작하세요. Nuxt가 페이지를 해석할 때, 모듈은 파일이 없는 모든 로케일과 페이지에 대해 빈 `{}` 파일을 생성합니다([`disableWatcher`](/ko/api/module-options#disablewatcher)로 끌 수 있습니다):

```text
locales/
├── en.json            # root: keys every page can use
├── de.json
├── fr.json
└── pages/
    ├── index/         # pages/index.vue
    │   ├── en.json
    │   ├── de.json
    │   └── fr.json
    └── about/         # pages/about.vue
        ├── en.json
        ├── de.json
        └── fr.json
```

루트 파일과 페이지 파일을 채우세요:

```json
// locales/en.json
{ "nav": { "home": "Home", "about": "About" } }
```

```json
// locales/pages/index/en.json
{ "welcome": "Welcome, {name}!", "items": "no items | one item | {count} items" }
```

페이지는 루트 키와 자체 키를 모두 볼 수 있으며, 충돌 시 자체 파일이 우선합니다. 폴더 이름은 라우트 이름을 따릅니다(`pages/articles/[id].vue`는 `locales/pages/articles-id/`). [번역 파일](/ko/guide/translations)에서 레이아웃, 폴백, 로딩을 다룹니다.

## 페이지에서 `$t` 사용 {#use-$t-on-a-page}

```vue
<!-- pages/index.vue -->
<script setup lang="ts">
const { t, tc, getLocale } = useI18n()

const title = t('nav.home') // 'Home'
</script>

<template>
  <h1>{{ $t('welcome', { name: 'Ada' }) }}</h1>
  <!-- Welcome, Ada! -->
  <p>{{ $tc('items', 3) }}</p>
  <!-- 3 items -->
  <p>{{ getLocale() }}</p>
  <!-- en -->
</template>
```

- 템플릿에서는 모든 헬퍼를 `$`와 함께 사용할 수 있습니다(`$t`, `$tc`, `$localePath`, …).
- `<script setup>`에서는 `useI18n()`이 `$`가 있는 형태와 없는 형태로 같은 헬퍼를 반환합니다(`t`와 `$t`는 같은 함수입니다). 자동으로 import됩니다.
- `{name}` 자리 표시자는 params 객체에서 채워집니다. 복수형은 `|`로 구분하며, 개수에 따라 형태가 선택됩니다(0, 1, 그 이상은 마지막 형태).

모든 헬퍼는 [메서드](/ko/api/methods)에 나열되어 있습니다.

## 페이지 간 링크와 로케일 전환 {#link-between-pages-and-switch-locale}

```vue
<!-- components/AppHeader.vue -->
<template>
  <nav>
    <i18n-link :to="{ name: 'index' }">{{ $t('nav.home') }}</i18n-link>
    <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
    <i18n-switcher />
  </nav>
</template>
```

- [`<i18n-link>`](/ko/components/i18n-link)는 현재 로케일의 페이지를 가리키는 `NuxtLink`입니다. `/de`에서 about 링크는 `/de/about`으로 이동합니다.
- [`<i18n-switcher>`](/ko/components/i18n-switcher)는 활성화된 로케일의 드롭다운으로, 방문자를 같은 페이지에 머물게 합니다.
- 직접 만든 버튼에서는 `$switchLocale('de')`를 호출하세요. 현재 페이지의 독일어 버전으로 이동하고 선택을 기억합니다. 일반 `NuxtLink`에는 `$localePath({ name: 'about' })` 또는 `$switchLocalePath('de')`를 사용하세요.

## 확인하기 {#check-it}

`nuxt dev`를 실행하고 다음을 여세요:

| URL | 표시 내용 |
| --- | --- |
| `/` | 영어 홈(브라우저가 독일어를 선호하면 `/de`로 리디렉션) |
| `/de` | 독일어 홈 |
| `/de/about` | 독일어 about 페이지 |
| `/en/about` | 404: `prefix_except_default`에서는 기본 로케일에 접두사가 없습니다 |

JSON 파일을 편집하면 새로고침 없이 열린 페이지에 적용됩니다.
