이 페이지는 `@nuxtjs/i18n` 앱을 nuxt-i18n-micro에 대응시킵니다: 옵션, 헬퍼, 파일 구성. 기존 앱에서 모듈을 교체할 때 사용하세요. URL은 그대로 유지되며(전략 이름이 같습니다), 번역은 페이지별 JSON 파일로 옮깁니다.

<Tip>

**nuxt-i18n-micro 자체를 업그레이드하나요?** — [업그레이드](/ko/guide/upgrade)를 참고하세요.

</Tip>

## 모듈 교체하기 {#swap-the-module}

```bash
npm uninstall @nuxtjs/i18n
npm install nuxt-i18n-micro
```

```ts
// nuxt.config.ts — before
export default defineNuxtConfig({
  modules: ['@nuxtjs/i18n'],
  i18n: {
    locales: [
      { code: 'en', language: 'en-US', file: 'en.json' },
      { code: 'de', language: 'de-DE', file: 'de.json' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    langDir: 'locales',
    detectBrowserLanguage: { useCookie: true, cookieKey: 'i18n_redirected', redirectOn: 'root' },
  },
})
```

```ts
// nuxt.config.ts — after
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    translationDir: 'locales',
    localeCookie: 'i18n_redirected',
    autoDetectPath: '/',
  },
})
```

## 옵션 {#options}

| `@nuxtjs/i18n` | nuxt-i18n-micro |
| --- | --- |
| `locales[].code` | `locales[].code` |
| `locales[].language` (v9 이전에는 `iso`) | `locales[].iso` |
| `locales[].name` | `locales[].displayName` |
| `locales[].dir` | `locales[].dir` |
| `locales[].domain` | `locales[].baseUrl` (스킴을 포함한 오리진) |
| `locales[].domainDefault` | `locales[].baseDefault` |
| `differentDomains`, `multiDomainLocales` | 필요 없음: `baseUrl`만으로 호스트별 라우팅이 됩니다. [레이어와 도메인](/ko/guide/layers#multiple-domains) 참고 |
| `locales[].file` / `files`, `langDir`, `lazy` | `translationDir`; 파일은 이름으로 찾으며 항상 페이지별로 로드됩니다 |
| `defaultLocale`, `strategy` | 같은 이름, 같은 네 가지 값 |
| `baseUrl` | `metaBaseUrl` |
| `customRoutes: 'config'` + `pages` | `globalLocaleRoutes` |
| `detectBrowserLanguage: false` | `redirects: false` (리디렉션 없음) 또는 `autoDetectLanguage: false` (헤더 무시) |
| `detectBrowserLanguage.useCookie` / `cookieKey` | `localeCookie: '<name>'` (`null`은 쿠키를 끕니다) |
| `detectBrowserLanguage.redirectOn: 'root'` | `autoDetectPath: '/'` (기본값) |
| `detectBrowserLanguage.redirectOn: 'no prefix'` | `autoDetectPath: 'no_prefix'` |
| `detectBrowserLanguage.redirectOn: 'all'` | `autoDetectPath: '*'` |
| `vueI18n` 구성 파일 (`fallbackLocale`, `numberFormats`, `datetimeFormats`) | `i18n`의 `fallbackLocale`, `numberFormats`, `datetimeFormats` |

`alwaysRedirect`는 없습니다: 쿠키가 설정되어 있으면 `/`는 방문할 때마다 쿠키를 따릅니다. 전체 목록은 [모듈 옵션](/ko/api/module-options)에 있으며, 감지 규칙은 [로케일 감지](/ko/guide/locale-detection)에 있습니다.

## 헬퍼와 컴포저블 {#helpers-and-composables}

| `@nuxtjs/i18n` / vue-i18n | nuxt-i18n-micro (템플릿 / `useI18n()`) |
| --- | --- |
| `const { t } = useI18n()` | `const { t } = useI18n()`, 템플릿에서는 `$t` |
| `t('key', count)`, `tc` | `$tc('key', count)` |
| `te('key')` | `$has('key')` |
| `n(value, 'currency')`, `d(date, 'short')` | `$tn(value, 'currency')`, `$td(date, 'short')` |
| — | `$tdr(date)`: 상대 시간("3일 후") |
| `locale.value` | `$getLocale()` |
| `locales.value` | `$getLocales()` |
| `setLocale('de')` | `$switchLocale('de')` |
| `useLocalePath()('about')` | `$localePath({ name: 'about' })` |
| `useLocaleRoute()` | `$localeRoute()` |
| `useSwitchLocalePath()('de')` | `$switchLocalePath('de')` |
| `useSetI18nParams()` | `$setI18nRouteParams()` |
| `useLocaleHead()` | `meta: true`로 자동 처리; 사용자 정의 head에는 [`useLocaleHead`](/ko/composables/useLocaleHead) |
| `defineI18nRoute({ paths: { de: '/ueber-uns' }, locales: [...] })` | `$defineI18nRoute({ localeRoutes: { de: '/ueber-uns' }, locales: [...] })` |
| `<NuxtLinkLocale to="about">` | `<i18n-link :to="{ name: 'about' }">` |
| `<i18n-t>` | `<i18n-t>` (슬롯이 `{name}` 플레이스홀더를 채움) |
| 서버 라우트의 `$i18n` | `useTranslationServerMiddleware(event)`, [서버 라우트와 API](/ko/guide/server-side-translations) 참고 |

`useI18n()`은 자동으로 import됩니다. `$defineI18nRoute`는 `$`를 유지해야 합니다: 빌드가 그 호출을 읽기 때문입니다. 모든 헬퍼: [메서드](/ko/api/methods).

## 번역 파일 {#translation-files}

로케일당 하나의 큰 파일에 있던 키를 루트 파일과 페이지당 하나의 파일로 옮기세요:

```text
locales/
├── en.json              # keys used on many pages (nav, footer)
├── de.json
└── pages/
    ├── index/en.json    # keys of pages/index.vue
    └── about/en.json    # keys of pages/about.vue
```

모든 것을 루트 파일에 두는 것도 동작하며, 가장 빠른 첫 단계입니다. 파일을 나누기 전까지는 `disablePageLocales: true`를 설정하세요. [번역 파일](/ko/guide/translations)을 참고하세요.

### 메시지 구문 {#message-syntax}

| vue-i18n | nuxt-i18n-micro |
| --- | --- |
| `{name}` 이름 있는 보간 | 동일 |
| `car \| cars` (2가지 형태: 1 → 첫 번째) | 형태는 0부터 개수로 선택됩니다: `no cars \| one car \| {count} cars`로 작성 |
| `@:other.key` 연결된 메시지 | 지원되지 않음: 텍스트를 반복하거나 코드에서 조합 |
| `@.upper:` 수정자 | 지원되지 않음: 코드에서 서식을 지정하거나 `<i18n-t>` 사용 |
| `{'@'}` 리터럴 이스케이프 | 필요 없음: `{word}` 토큰만 대체됩니다 |
| JS/TS 메시지 파일 | JSON 전용 |

복수형 규칙은 [`plural`](/ko/api/module-options#plural) 옵션으로 교체할 수 있습니다.

## 전환 후 확인 사항 {#check-after-the-switch}

- 기존의 모든 URL이 여전히 해석됩니다. 전략 이름은 일치하며, 사용자 정의 경로는 `globalLocaleRoutes` 또는 `$defineI18nRoute`로 옮겨집니다.
- `hreflang`, canonical, `og:locale`은 `meta: true`로 기본 제공되므로 직접 작성한 것은 제거하세요.
- JSON 파싱 오류는 파일 경로를 기록하며, 누락된 키는 개발 환경에서 브라우저 콘솔에 경고를 기록합니다.
