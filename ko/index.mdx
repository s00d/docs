---

Nuxt I18n Micro는 대규모 프로젝트를 위해 설계된 Nuxt 3 및 4용 경량 고성능 i18n 모듈입니다. `@nuxtjs/i18n` 같은 기존 i18n 솔루션에 비해 빌드 시간, 메모리 사용량, 번들 크기를 낮게 유지합니다.

현지화된 라우트는 빌드 시 `@i18n-micro/route-strategy`에 의해 생성되고 런타임에 `@i18n-micro/path-strategy`에 의해 해석되므로, 링크, 스위처, `hreflang`, 리디렉션이 모두 라우터와 일치합니다. 번역은 JSON 전용이며, 공유 루트 파일과 개발 서버가 대신 만들어 주는 페이지별 파일로 나뉘고, HMR이 내장되어 있습니다.

<CodeGroup>

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>
