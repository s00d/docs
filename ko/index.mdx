Nuxt I18n Micro는 대규모 프로젝트를 위해 설계된 가볍고 고성능의 Nuxt용 i18n 모듈입니다. `@nuxtjs/i18n`과 같은 전통적인 i18n 솔루션에 비해 빌드 시간, 메모리 사용량, 번들 크기를 줄여줍니다.

핵심은 단일 Nuxt 모듈과 소수의 런타임 플러그인으로 구성됩니다. 로케일 접두사는 `@i18n-micro/route-strategy`(빌드 타임)와 `@i18n-micro/path-strategy`(런타임)가 처리합니다. 번역은 JSON만 사용하며, 공유 루트 파일과 페이지별 파일로 분리되어 개발 시 자동 생성됩니다.

## Nuxt I18n Micro가 필요한 경우

- Nitro 페이로드를 부풀리지 않고 지연 로드되는 페이지별 번역이 필요할 때.
- 런타임 라우트 생성 오버헤드 없이 전략 기반 라우팅을 원할 때.
- SSR 및 엣지 배포가 부하 상황에서도 빠르게 유지되어야 할 때.
- `@nuxtjs/i18n`에서 마이그레이션하면서 유사한 사용성을 가진 더 작은 런타임을 원할 때.
