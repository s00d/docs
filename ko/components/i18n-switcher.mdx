`<i18n-switcher>`는 활성 로케일이 표시된 버튼과, 활성 로케일을 포함한 모든 활성화된 로케일의 드롭다운을 렌더링합니다. 바로 쓸 수 있는 언어 메뉴가 필요할 때 사용하세요. 다른 마크업이 필요하다면 [`$getLocales`](/ko/api/methods#$getlocales)와 [`$switchLocalePath`](/ko/api/methods#$switchlocalepath)로 직접 만드세요. 각 항목은 해당 로케일의 현재 페이지로 연결됩니다.

## Props 및 슬롯 {#props-and-slots}

| Prop | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `customLabels` | `Record<string, string>` | `() => ({})` | 로케일 코드별 표시 이름으로, 로케일 설정의 `displayName`을 재정의합니다. |
| `customWrapperStyle` | `CSSProperties` | `() => ({})` | 바깥 래퍼의 인라인 스타일. |
| `customButtonStyle` | `CSSProperties` | `() => ({})` | 드롭다운을 여는 버튼의 인라인 스타일. |
| `customDropdownStyle` | `CSSProperties` | `() => ({})` | 드롭다운 패널의 인라인 스타일. |
| `customItemStyle` | `CSSProperties` | `() => ({})` | 드롭다운의 각 항목에 대한 인라인 스타일. |
| `customLinkStyle` | `CSSProperties` | `() => ({})` | 항목 내부 링크의 인라인 스타일. |
| `customActiveLinkStyle` | `CSSProperties` | `() => ({})` | 현재 활성 로케일 링크의 인라인 스타일. |
| `customDisabledLinkStyle` | `CSSProperties` | `() => ({})` | 설정에서 `disabled: true`인 *현재* 로케일 버튼의 인라인 스타일. |
| `customIconStyle` | `CSSProperties` | `() => ({})` | 버튼의 캐럿 아이콘에 대한 인라인 스타일. |

### 슬롯 {#slots}

| 슬롯 | 바인딩 | 설명 |
| --- | --- | --- |
| `before-button` | — | 드롭다운을 여는 버튼 앞의 콘텐츠. |
| `before-selected-locale` | — | 버튼 내부의 활성 로케일 레이블 앞 콘텐츠. |
| `after-selected-locale` | — | 버튼 내부의 활성 로케일 레이블 뒤 콘텐츠. |
| `before-dropdown` | — | 버튼과 드롭다운 패널 사이의 콘텐츠. |
| `before-dropdown-items` | — | 드롭다운 상단, 로케일 목록 위의 콘텐츠. |
| `before-item` | `locale` | 각 로케일 항목 앞의 콘텐츠. |
| `before-link-content` | `locale` | 링크 내부의 로케일 레이블 앞 콘텐츠. |
| `after-link-content` | `locale` | 링크 내부의 로케일 레이블 뒤 콘텐츠. |
| `after-item` | `locale` | 각 로케일 항목 뒤의 콘텐츠. |
| `after-dropdown-items` | — | 드롭다운 하단, 로케일 목록 아래의 콘텐츠. |
| `after-dropdown` | — | 드롭다운 패널 뒤의 콘텐츠. |

## 동작 {#behaviour}

- `disabled: true`가 아닌 모든 로케일을 활성 로케일을 포함하여 나열합니다.
- 각 항목은 `$switchLocalePath(code)`로 가는 `<a>`입니다. 경로는 `app.baseURL` 아래에서 해석되며, 다른 도메인의 로케일 `baseUrl`은 절대 경로로 유지됩니다. `hreflang`과 `lang`은 `iso || code`로 설정되고, 로케일에 `dir`이 있으면 `dir`이, 현재 로케일에는 `aria-current="page"`가, 그리고 `switcher-locale-<code>` 클래스가 설정됩니다. 클릭하면 `$switchLocale(code)`를 호출하고 드롭다운을 닫습니다. 수정자 키와 함께 클릭하면 브라우저에 맡깁니다.
- 목록은 숨겨진 상태로 서버 HTML에 남아 있으므로 크롤러가 링크를 볼 수 있습니다. Escape 키를 누르거나 바깥을 클릭하면 닫힙니다.
- 레이블: `customLabels[code]`, 그다음 로케일의 `displayName`, 그다음 코드(개발 모드 경고와 함께) 순입니다.
- 스타일: 작은 인라인 기본값(테두리가 있는 흰색 버튼과 패널, 활성 항목은 굵은 파란색)이 적용됩니다. 각 `custom*Style` prop은 해당 부분의 기본값 다음에 적용됩니다. 버튼에는 `i18n-switcher-button`과 `language-switcher` 클래스가, 래퍼에는 `i18n-switcher-wrapper`가, 목록에는 `i18n-switcher-dropdown`이 있습니다. 위치 지정에 논리적 CSS 속성을 사용하므로 `dir="rtl"`이 동작합니다.

## 예제 {#example}

```vue
<template>
  <i18n-switcher
    :custom-labels="{ en: 'English', de: 'Deutsch' }"
    :custom-button-style="{ borderRadius: '4px' }"
  >
    <template #before-link-content="{ locale }">
      <img :src="`/flags/${locale.code}.svg`" alt="" width="16" />
    </template>
  </i18n-switcher>
</template>
```
