---

`<i18n-t>`는 하나의 번역을 요소로 렌더링합니다. 번역 안에 컴포넌트(문장 속 링크)가 필요하거나, 복수형 또는 서식이 지정된 숫자나 날짜가 필요할 때 사용하세요. `$t`처럼 현재 라우트에 대한 키를 해석합니다.

## Props {#props}

| Prop | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `keypath` **\*** | `string` | — | 렌더링할 번역 키. |
| `plural` | `number \| string \| null` | — | 복수형을 선택하는 개수. 설정하면 `$t` 대신 `$tc`를 사용합니다. `null`은 설정되지 않음을 의미합니다. |
| `tag` | `string` | `'span'` | 렌더링할 요소. |
| `params` | `Record<string, string \| number \| boolean>` | — | 번역에 대입되는 보간 값. |
| `defaultValue` | `string` | `''` | `hideIfEmpty`가 빈 번역을 숨길 때 컴포넌트 대신 렌더링됩니다. |
| `html` | `boolean` | `false` | 번역을 텍스트가 아닌 HTML로 렌더링합니다. 직접 관리하는 번역에만 사용하세요: `params`는 이스케이프되지만 번역은 이스케이프되지 않습니다. |
| `hideIfEmpty` | `boolean` | `false` | 번역이 빈 문자열로 해석되면 아무것도 렌더링하지 않습니다. |
| `customPluralRule` | `PluralFunc` | `null` | 이 요소에만 적용되는 복수형 규칙으로, 구성된 규칙을 재정의합니다. 그 결과는 그대로 사용되며, `null`은 빈 값으로 렌더링됩니다. |
| `number` | `number \| string \| null` | — | 값을 `$tn`으로 서식 지정하고 `params`와 함께 번역에 `{number}`로 전달합니다. |
| `date` | `Date \| string \| number \| null` | — | 값을 `$td`로 서식 지정하고 `params`와 함께 번역에 `{date}`로 전달합니다. |
| `relativeDate` | `Date \| string \| number \| null` | — | 값을 `$tdr`로 서식 지정하고 `params`와 함께 번역에 `{relativeDate}`로 전달합니다. |

**\*** 필수.

## 렌더링 규칙 {#rendering-rules}

처음으로 일치하는 경우가 출력을 결정합니다:

1. `number` — `{ ...params, number: $tn(number) }`가 적용된 번역.
2. `date` — `{ ...params, date: $td(date) }`가 적용된 번역.
3. `relativeDate` — `{ ...params, relativeDate: $tdr(relativeDate) }`가 적용된 번역.
4. `plural` — [`=0 ` 마커](/ko/api/methods#$tc)를 포함하여 `$tc`가 선택한 형태에 `{ ...params, count }`가 적용된 것; 또는 설정된 경우 `customPluralRule(keypath, count, params, locale, t)`로, 마커를 포함한 원시 값을 읽으며 그 결과는 그대로 사용되고 `null`은 빈 값이 됩니다.
5. 그 외에는 `params`가 적용된 번역.

`null`은 설정되지 않은 것으로 간주됩니다. 모든 경우에:

- 모든 분기에서 `defaultValue`가 누락된 키를 대신합니다.
- `hideIfEmpty`는 빈 결과 대신 `defaultValue`를 렌더링합니다.
- `html`은 결과를 HTML로 렌더링합니다. `params`는 이스케이프되지만 번역은 이스케이프되지 않으며, 슬롯은 무시됩니다.
- `default` 슬롯은 `{ translation }`을 받으며, 이름이 지정된 슬롯은 무시됩니다.
- 그렇지 않으면 각 이름이 지정된 슬롯이 같은 이름의 param보다 먼저 모든 `{name}` 플레이스홀더를 대체합니다. 플레이스홀더처럼 보이는 param 값은 텍스트로 남습니다.

`date`와 `relativeDate`의 출력에는 `data-allow-mismatch="text"`가 붙습니다. 서버의 시간대와 시계가 브라우저와 다르기 때문입니다. 양쪽에서 동일한 달력 날짜를 렌더링하려면 [`timeZone`](/ko/api/module-options#timezone)을 설정하세요. `relativeDate`는 시계에 의존하므로 여전히 다를 수 있습니다.

## 예제 {#example}

```json
{
  "terms": "I accept the {link}.",
  "termsLink": "terms of use",
  "items": "no items | one item | {count} items"
}
```

```vue
<template>
  <i18n-t keypath="terms" tag="p">
    <template #link>
      <NuxtLink :to="$localePath('/terms')">{{ $t('termsLink') }}</NuxtLink>
    </template>
  </i18n-t>

  <i18n-t keypath="items" :plural="cart.length" />
</template>
```

`html`은 `innerHTML`을 설정합니다: 직접 관리하는 번역에만 사용하세요. `params`는 이스케이프되므로 사용자 데이터는 안전하며, 번역을 찾지 못한 키도 마찬가지입니다.
