`<i18n-group>`은 마크업 블록의 범위를 하나의 키 접두사로 지정합니다. 한 섹션의 여러 키가 같은 접두사를 공유하고 이를 반복하고 싶지 않을 때 사용하세요. 기본 슬롯은 접두사를 앞에 붙이는 `t`를 받습니다.

## Props와 슬롯 {#props-and-slot}

| Prop | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | 슬롯 내부의 모든 조회가 기준으로 삼는 키 접두사. |
| `groupClass` | `string` | `''` | 래퍼 요소에 추가되는 클래스. |

**\*** 필수.

### 슬롯 {#slots}

| 슬롯 | 바인딩 | 설명 |
| --- | --- | --- |
| `default` | `prefix`, `t` | `prefix`와 그 범위로 지정된 `t` 함수를 받습니다. |

## 동작 {#behaviour}

- 슬롯 주위에 `<div class="i18n-group {groupClass}">`를 렌더링합니다.
- `t(key, params)`는 현재 라우트에 대한 `$t(prefix + '.' + key, params)`입니다.
- 슬롯의 `t`만 범위가 지정됩니다: 그룹 내부의 `$t`와 중첩된 `<i18n-t>`는 여전히 전체 키를 받습니다.

## 예제 {#example}

```json
{
  "checkout": { "title": "Checkout", "items": "Items: {count}" }
}
```

```vue
<template>
  <i18n-group prefix="checkout" group-class="checkout">
    <template #default="{ t }">
      <h2>{{ t('title') }}</h2>
      <p>{{ t('items', { count: 3 }) }}</p>
    </template>
  </i18n-group>
</template>
```
