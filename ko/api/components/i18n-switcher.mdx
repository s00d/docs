# 🌍 `<i18n-switcher>` 컴포넌트

`Nuxt I18n Micro`의 `<i18n-switcher>` 컴포넌트는 애플리케이션에서 다양한 로케일 간 전환을 위한 사용자 친화적인 드롭다운 인터페이스를 제공합니다. 이 컴포넌트는 고도로 사용자 정의 가능하며, 애플리케이션의 디자인 및 레이아웃과의 원활한 통합을 가능하게 합니다.

`disabled: true`인 로케일은 드롭다운에서 **생략**됩니다(SEO / head 태그를 위해 `$getLocales()`를 통해 계속 사용 가능). 전환 가능한 로케일만 `NuxtLink` + `hreflang`을 얻습니다.

| Slot | Bindings | Description |
| --- | --- | --- |

| `before-selected-locale` | — | Content before the active locale label inside the button. |
| `after-selected-locale` | — | Content after the active locale label inside the button. |
| `before-dropdown` | — | Content between the button and the dropdown panel. |
| `before-dropdown-items` | — | Content at the top of the dropdown, above the locale list. |

모든 부분은 기본적으로 스타일이 없습니다: `custom*Style` prop은 인라인 스타일 객체를 받고, 스타일링만으로 충분하지 않을 때 아래의 슬롯이 마크업을 완전히 대체합니다.

## 🛠️ 사용 예제

### 기본 사용법

```vue
<template>
  <i18n-switcher />
</template>
```

이는 기본 스타일링과 동작으로 로케일 스위처를 렌더링합니다.

### 사용자 정의 라벨과 인라인 스타일

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

이 예제는 사용자 정의 라벨과 인라인 스타일로 완전히 사용자 정의된 로케일 스위처를 보여줍니다.

## 🔌 슬롯

스위처의 모든 시각적 부분을 대체할 수 있습니다. 슬롯은 위의 props 표에 나열되어 있으며, 각각은 템플릿 콘텐츠를 받습니다:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

이름이 `-item`, `-link-content`로 끝나거나 `before-item`으로 시작하는 슬롯은 소속된 `locale` 객체를 받습니다.

## 🎨 스타일 개요

`<i18n-switcher>` 컴포넌트는 인라인 스타일로 정의된 기본 스타일과 함께 제공되며, props를 통해 사용자 정의 스타일을 전달하여 쉽게 재정의할 수 있습니다. 다음은 기본 스타일링에 대한 간략한 개요입니다:

- **Wrapper**: 드롭다운의 위치를 제어합니다.
- **Button**: 드롭다운 토글 버튼을 스타일링합니다.
- **Dropdown**: 드롭다운 목록을 스타일링합니다.
- **Items**: 목록의 각 항목을 스타일링합니다.
- **Links**: 각 항목 내부의 링크를 스타일링합니다.
- **Icon**: 드롭다운 표시 아이콘을 스타일링합니다.

각 props를 통해 사용자 정의 스타일을 전달하여 이러한 스타일을 사용자 정의하고, 로케일 스위처가 애플리케이션의 UI와 원활하게 통합되도록 할 수 있습니다.
