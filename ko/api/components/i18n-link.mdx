# 🌍 `<i18n-link>` 컴포넌트

`Nuxt I18n Micro`의 `<i18n-link>` 컴포넌트는 현재 로케일에 따라 라우트를 자동으로 지역화하는 다용도 링크 컴포넌트입니다. `<NuxtLink>` 컴포넌트를 감싸며, 활성 링크 스타일링 및 외부 링크 지원 같은 추가 기능을 제공합니다.

## ⚙️ Props

{/* generated:component:i18n-link — do not edit; run `pnpm run docs:generate` */}

| Prop | 유형 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | 대상 라우트. 자동으로 지역화됩니다. 외부 URL은 변경 없이 그대로 전달됩니다. |
| `activeStyle` | `Partial<CSSStyleValue>` | — | 링크가 현재 라우트를 가리킬 때 적용되는 인라인 스타일. |

**\*** 필수.

### 슬롯

| 슬롯 | 바인딩 | 설명 |
| --- | --- | --- |
| `default` | — | 링크 콘텐츠. |

{/* /generated:component:i18n-link */}

`to`는 `NuxtLink`가 받는 모든 것을 받습니다 — 경로, 이름이 지정된 라우트 또는 해결된 라우트 객체. 절대 URL은 감지되어 지역화되는 대신 일반 `<a target="_blank" rel="noopener noreferrer">`로 렌더링됩니다.

## 🛠️ 사용 예제

### 기본 사용법

```vue
<i18n-link to="/about">About Us</i18n-link>
```

이 예제는 현재 로케일로 지역화된 `/about` 페이지 링크를 생성합니다.

### 인라인 스타일로 활성 링크 스타일링

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

사용자가 `/about` 페이지에 있을 때 링크는 굵은 텍스트가 되며, 인라인 스타일로 활성 링크를 직접 스타일링할 수 있습니다.

### 외부 링크 처리

이 컴포넌트는 외부 링크를 자동으로 감지하고 보안에 필요한 속성을 추가합니다.

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

이 링크는 `rel="noopener noreferrer"`가 적용된 새 탭에서 `https://example.com`을 엽니다.

## 🎨 스타일

이 컴포넌트는 활성 상태에 클래스 대신 인라인 스타일을 사용합니다. `activeStyle` prop을 통해 이러한 스타일을 사용자 정의할 수 있습니다.

### 기본 활성 스타일

- **글꼴 굵기**: `bold`
- **색상**: 브라우저 기본 색상 상속 (`activeStyle`에 `color`가 지정되지 않은 경우).

`activeStyle` prop을 통해 사용자 정의 스타일을 제공하여 이러한 것들을 재정의할 수 있습니다.

### 사용자 정의 활성 스타일

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

이 예제에서 활성 상태일 때 링크는 굵고 녹색이 됩니다.

## 🚀 추가 기능

### 사용자 정의 콘텐츠를 위한 슬롯

슬롯을 사용하여 링크 내부에 사용자 정의 콘텐츠를 전달할 수 있으므로, 다양한 사용 사례에 유연하게 대응할 수 있습니다.

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### 접근성 향상

이 컴포넌트는 `aria-label` 및 기타 접근성 속성을 지원하여 더 접근성 있는 경험을 제공합니다.

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
