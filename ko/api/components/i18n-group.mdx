# 🌍 `<i18n-group>` 컴포넌트

Nuxt I18n Micro의 `<i18n-group>` 컴포넌트는 공통 접두사 아래에 번역을 그룹화하는 편리한 방법을 제공하여 반복을 줄이고 코드 구성을 개선합니다.

## ⚙️ Props

{/* generated:component:i18n-group — do not edit; run `pnpm run docs:generate` */}

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | Key prefix every lookup inside the slot is resolved against. |
| `groupClass` | `string` | `''` | Extra class on the wrapper element. |

**\*** required.

### Slots

| Slot | Bindings | Description |
| --- | --- | --- |
| `default` | `prefix`, `t` | Receives `prefix` and a `t` function scoped to it. |

{/* /generated:component:i18n-group */}

## 🎯 슬롯

기본 슬롯은 `prefix`와 그 안에 범위 지정된 `t` 함수를 받으므로 내부의 키는 접두사에 상대적으로 작성됩니다:

```vue
<i18n-group prefix="checkout">
  <template #default="{ t }">
    <h2>{{ t('title') }}</h2>
    <p>{{ t('summary', { count: 3 }) }}</p>
  </template>
</i18n-group>
```

## 🛠️ 사용 예제

### 기본 사용법

```vue
<template>
  <i18n-group prefix="product.details">
    <template #default="{ t }">
      <h1>{{ t('title') }}</h1>
      <p>{{ t('description') }}</p>
      <div class="price">{{ t('price', { value: 99.99 }) }}</div>
    </template>
  </i18n-group>
</template>
```

번역 파일:

```json
{
  "product": {
    "details": {
      "title": "Premium Product",
      "description": "This is a premium product",
      "price": "Price: ${value}"
    }
  }
}
```

### 사용자 정의 클래스와 함께 사용

```vue
<template>
  <i18n-group prefix="user.profile" group-class="profile-section">
    <template #default="{ t }">
      <div class="user-info">
        <h2>{{ t('title') }}</h2>
        <p>{{ t('bio') }}</p>
        <div class="stats">
          <span>{{ t('stats.followers') }}</span>
          <span>{{ t('stats.following') }}</span>
        </div>
      </div>
    </template>
  </i18n-group>
</template>
```

번역 파일:

```json
{
  "user": {
    "profile": {
      "title": "User Profile",
      "bio": "User biography goes here",
      "stats": {
        "followers": "Followers: {count}",
        "following": "Following: {count}"
      }
    }
  }
}
```

### 동적 콘텐츠와 함께

```vue
<template>
  <i18n-group prefix="blog.post">
    <template #default="{ t }">
      <article>
        <h1>{{ t('title') }}</h1>
        <div class="meta">
          {{ t('meta.author', { name: author }) }} |
          {{ t('meta.date', { date: publishDate }) }}
        </div>
        <div v-for="(section, index) in sections" :key="index">
          <h2>{{ t(`sections.${index}.title`) }}</h2>
          <p>{{ t(`sections.${index}.content`) }}</p>
        </div>
      </article>
    </template>
  </i18n-group>
</template>

<script setup>
const author = 'John Doe'
const publishDate = '2024-01-01'
const sections = ['intro', 'main', 'conclusion']
</script>
```

## 🎨 스타일링

컴포넌트는 콘텐츠를 `i18n-group` 클래스와 `groupClass` prop에 지정된 추가 클래스가 있는 div로 감쌉니다:

```css
.i18n-group {
  /* Your base styles */
}

.profile-section {
  /* Additional styles for profile sections */
}
```

## 🚀 모범 사례

1. **일관된 접두사**: 애플리케이션 구조를 반영하는 일관되고 논리적인 접두사를 사용하세요.

```vue
<i18n-group prefix="features.pricing">
<i18n-group prefix="features.security">
```

2. **모듈식 구성**: 의미 있는 접두사 아래에 관련 번역을 함께 그룹화하세요.

```vue
<i18n-group prefix="checkout.payment">
<i18n-group prefix="checkout.shipping">
```

3. **재사용 가능한 컴포넌트**: 자체 번역 그룹이 있는 재사용 가능한 컴포넌트를 만드세요.

```vue
<!-- UserProfile.vue -->
<i18n-group prefix="user.profile">

<!-- UserSettings.vue -->
<i18n-group prefix="user.settings">
```

4. **중첩된 그룹**: 명확성을 유지하기 위해 그룹을 깊이 중첩하지 마세요.

```vue
<!-- Good -->
<i18n-group prefix="shop.product">

<!-- Avoid -->
<i18n-group prefix="shop.category.product.details.specs">
```
