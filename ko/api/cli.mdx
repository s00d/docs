[CLI 가이드](/ko/guide/cli)에서는 일반적인 워크플로를 보여 줍니다. 이 페이지는 모든 항목을 나열하며, `--help`를 구동하는 것과 동일한 테이블에서 생성됩니다.

## 공통 플래그 {#common-flags}

| 플래그 | 기본값 | 설명 |
| --- | --- | --- |
| `--cwd` | 현재 디렉터리 | 프로젝트 디렉터리 |
| `--logLevel` | `info` | 출력 수준: silent, info |
| `--debug` | `false` | 명령이 실패하면 스택 트레이스를 출력 |

## 검사 {#inspect}

### `info` {#info}

프로젝트의 확인된 i18n 구성을 출력합니다

| 플래그 | 기본값 | 설명 |
| --- | --- | --- |
| `--json` | `false` | 텍스트 대신 JSON 출력 |

### `check` {#check}

CI 게이트: 누락된 키, 빈 키, 불필요한 키, 정의되지 않은 키, 사용되지 않는 키, 깨진 플레이스홀더가 있으면 실패합니다

| 플래그 | 기본값 | 설명 |
| --- | --- | --- |
| `--translationDir` | nuxt.config의 `i18n.translationDir` | 번역 디렉터리, 프로젝트 기준 상대 경로 |
| `--only` | duplicates를 제외한 전체 | 실행할 검사(쉼표로 구분): missing, empty, extra, placeholders, undefined, unused, duplicates. 여기에 `unused`를 지정하면 실행할 수 없을 때 실패합니다 |
| `--duplicates` | `false` | 서로 다른 키 아래의 동일한 텍스트도 보고 |
| `--ignore` | — | 건너뛸 소스 파일의 glob(쉼표로 구분), 프로젝트 기준 상대 경로 |
| `--json` | `false` | 텍스트 대신 JSON 출력 |

```bash
i18n-micro check
i18n-micro check --only missing,placeholders --json
```

### `stats` {#stats}

로케일별 번역 완료율을 표시합니다

| 플래그 | 기본값 | 설명 |
| --- | --- | --- |
| `--translationDir` | nuxt.config의 `i18n.translationDir` | 번역 디렉터리, 프로젝트 기준 상대 경로 |
| `--html` | — | 이 파일에 HTML 보고서도 작성 |
| `--json` | `false` | 텍스트 대신 JSON 출력 |
| `--baseRef` | — | 완료율을 비교할 Git ref (예: HEAD~1 또는 main) |

```bash
i18n-micro stats --baseRef main
i18n-micro stats --html reports/i18n.html
```

### `lint` {#lint}

번역 텍스트를 검사하며, 문제가 남아 있으면 실패합니다

| 플래그 | 기본값 | 설명 |
| --- | --- | --- |
| `--translationDir` | nuxt.config의 `i18n.translationDir` | 번역 디렉터리, 프로젝트 기준 상대 경로 |
| `--rules` | 전체, 또는 .i18n-lintrc.json의 `enabledRules` | 실행할 규칙(쉼표로 구분): no-trailing-spaces, no-multiple-spaces, no-empty-translation 또는 사용자 정의 규칙 |
| `--fix` | `false` | 수정 가능한 항목 수정: 공백, 그리고 대체값이 있는 사용자 정의 규칙 |
| `--json` | `false` | 텍스트 대신 JSON 출력 |

```bash
i18n-micro lint --rules no-trailing-spaces --fix
```

### `search` {#search}

키와 값을 검색하고, 각 키가 사용되는 위치를 표시합니다

| 플래그 | 기본값 | 설명 |
| --- | --- | --- |
| `--translationDir` | nuxt.config의 `i18n.translationDir` | 번역 디렉터리, 프로젝트 기준 상대 경로 |
| `<query>` | — | 검색할 텍스트 또는 키 |
| `--caseSensitive` | `false` | 대소문자 구분 |
| `--onlyUnused` | `false` | `clean`이 제거할 키만 표시; 쿼리는 선택 사항이 됩니다 |
| `--scope` | `all` | 검색 범위: global, pages, all |
| `--limit` | — | 반환할 최대 키 수 |
| `--ignore` | — | 건너뛸 소스 파일의 glob(쉼표로 구분), 프로젝트 기준 상대 경로 |
| `--json` | `false` | 텍스트 대신 JSON 출력 |

```bash
i18n-micro search "Welcome"
i18n-micro search --onlyUnused
```

## 번역 워크플로 {#translation-workflow}

### `extract` {#extract}

소스 파일에서 사용하지만 아직 텍스트가 없는 키를 나열하고, 기본 텍스트가 있는 키를 기본 로케일에 추가합니다

| 플래그 | 기본값 | 설명 |
| --- | --- | --- |
| `--translationDir` | nuxt.config의 `i18n.translationDir` | 번역 디렉터리, 프로젝트 기준 상대 경로 |
| `--ignore` | — | 건너뛸 소스 파일의 glob(쉼표로 구분), 프로젝트 기준 상대 경로 |

```bash
i18n-micro extract
```

### `translate` {#translate}

번역 서비스를 통해 기본 로케일에서 누락된 번역을 채웁니다

| 플래그 | 기본값 | 설명 |
| --- | --- | --- |
| `--translationDir` | nuxt.config의 `i18n.translationDir` | 번역 디렉터리, 프로젝트 기준 상대 경로 |
| `--service` | — | 번역 서비스: ai, azure, deepl, google, libretranslate, yandexcloud |
| `--token` | — | API 키. I18N_TRANSLATE_TOKEN 환경 변수를 권장합니다: 플래그는 셸 기록에 남습니다 |
| `--options` | — | 쉼표로 구분된 key:value 쌍 형식의 서비스 옵션 |
| `--locale` | 기본 로케일을 제외한 모든 로케일 | 채울 로케일(쉼표로 구분) |
| `--replace` | `false` | 모든 키를 다시 번역하여 기존 값을 대체 |
| `--dryRun` | `false` | 로케일별 키와 문자 수만 계산하고 아무것도 전송하지 않음 |
| `--chunkSize` | — | 요청당 문자열 수; 서비스가 허용하는 한도로 제한됨 |
| `--pluralSeparator` | `\|` | 메시지 내 복수형 구분자 |
| `--glossaryFile` | 존재하는 경우 `.i18n-glossary.json` | 용어집 파일, `ai` 서비스에서 사용 |

```bash
i18n-micro translate --dryRun
I18N_TRANSLATE_TOKEN=... i18n-micro translate --service deepl --locale de,fr
i18n-micro translate --service ai --options provider:openai,model:gpt-4o-mini
i18n-micro translate --service libretranslate --options baseUrl:https://translate.example.com
```

### `sync` {#sync}

기본 로케일에 없는 키를 제거합니다. 안전함을 증명할 수 없으면 중단합니다. 누락된 키는 누락된 상태로 남습니다

| 플래그 | 기본값 | 설명 |
| --- | --- | --- |
| `--translationDir` | nuxt.config의 `i18n.translationDir` | 번역 디렉터리, 프로젝트 기준 상대 경로 |
| `--ignore` | — | 건너뛸 소스 파일의 glob(쉼표로 구분), 프로젝트 기준 상대 경로 |
| `--dryRun` | `false` | 제거될 항목만 나열하고 아무것도 쓰지 않음 |
| `--force` | `false` | 안전함을 증명할 수 없어도 키를 제거 |

```bash
i18n-micro sync --dryRun
```

### `clean` {#clean}

프로젝트에서 사용하지 않는 키를 제거합니다. 이를 증명할 수 없으면 중단합니다

| 플래그 | 기본값 | 설명 |
| --- | --- | --- |
| `--translationDir` | nuxt.config의 `i18n.translationDir` | 번역 디렉터리, 프로젝트 기준 상대 경로 |
| `--include` | — | 정규식: 일치하는 키만 제거 대상으로 고려 |
| `--exclude` | — | 정규식: 일치하는 키는 절대 제거하지 않음 |
| `--ignore` | — | 건너뛸 소스 파일의 glob(쉼표로 구분), 프로젝트 기준 상대 경로 |
| `--dryRun` | `false` | 제거될 항목만 나열하고 아무것도 쓰지 않음 |
| `--force` | `false` | 모든 키의 사용 여부를 증명할 수 없어도 키를 제거 |

```bash
i18n-micro clean --dryRun
i18n-micro clean --exclude '^errors\.'
```

## 리팩터링 {#refactoring}

### `text-to-i18n` {#text-to-i18n}

Vue 템플릿의 하드코딩된 텍스트를 번역 호출로 바꾸고, 코드 내 하드코딩된 텍스트를 보고합니다

| 플래그 | 기본값 | 설명 |
| --- | --- | --- |
| `--translationFile` | `<translationDir>/<defaultLocale>.json` | 새 키가 추가될 파일 |
| `--path` | 프로젝트 전체 | 처리할 파일 또는 디렉터리 |
| `--context` | — | 생성되는 키의 접두사 |
| `--ignore` | — | 건너뛸 소스 파일의 glob(쉼표로 구분), 프로젝트 기준 상대 경로 |
| `--dryRun` | `false` | 변경될 내용만 표시하고 아무것도 쓰지 않음 |
| `--interactive` | `false` | 생성되는 모든 키를 확인하거나 편집 |

```bash
i18n-micro text-to-i18n --dryRun
i18n-micro text-to-i18n --path components --context ui
```

### `rename` {#rename}

모든 로케일과 소스 파일에서 키 또는 네임스페이스의 이름을 변경합니다

| 플래그 | 기본값 | 설명 |
| --- | --- | --- |
| `--translationDir` | nuxt.config의 `i18n.translationDir` | 번역 디렉터리, 프로젝트 기준 상대 경로 |
| `--from` **\*** | — | 현재 키 또는 네임스페이스 |
| `--to` **\*** | — | 새 키 또는 네임스페이스 |
| `--ignore` | — | 건너뛸 소스 파일의 glob(쉼표로 구분), 프로젝트 기준 상대 경로 |
| `--dryRun` | `false` | 변경 사항만 보고하고 아무것도 쓰지 않음 |

**\*** 필수.

```bash
i18n-micro rename --from common.save --to actions.save
```

레이아웃 문제와 하드코딩된 텍스트 문제를 찾기 위해 로케일을 의사 번역으로 채웁니다

| 플래그 | 기본값 | 설명 |
| --- | --- | --- |
| `--translationDir` | nuxt.config의 `i18n.translationDir` | 번역 디렉터리, 프로젝트 기준 상대 경로 |
| `--sourceLocale` | 기본 로케일 | 읽을 로케일 |
| `--targetLocale` **\*** | — | 채울 로케일 |
| `--replace` | `false` | 기존 값 덮어쓰기 |

**\*** 필수.

### `format` {#format}

키를 정렬하고 들여쓰기를 통일하여 로케일 파일을 다시 작성합니다

| 플래그 | 기본값 | 설명 |
| --- | --- | --- |
| `--translationDir` | nuxt.config의 `i18n.translationDir` | 번역 디렉터리, 프로젝트 기준 상대 경로 |
| `--indent` | `2` | 들여쓰기 공백 수 |
| `--sortKeys` | `true` | 키 정렬; 순서를 유지하려면 --no-sortKeys 사용 |
| `--check` | `false` | 파일이 변경될 경우 실패하고 아무것도 쓰지 않음 |

```bash
i18n-micro format --check
```

## 교환 {#exchange}

### `export` {#export}

기본 로케일 텍스트를 원문으로 하여 로케일 파일을 PO 또는 CSV로 내보냅니다

| 플래그 | 기본값 | 설명 |
| --- | --- | --- |
| `--translationDir` | nuxt.config의 `i18n.translationDir` | 번역 디렉터리, 프로젝트 기준 상대 경로 |
| `--format` | `po` | 파일 형식: po, csv |
| `--dir` | po는 `pots`, csv는 `csv_exports` | 출력 디렉터리, 프로젝트 기준 상대 경로 |
| `--force` | `false` | 마지막 내보내기 이후 변경되었지만 가져오지 않은 파일도 덮어쓰기 |

```bash
i18n-micro export --format csv
```

### `import` {#import}

PO 또는 CSV 파일을 로케일 파일에 병합합니다

| 플래그 | 기본값 | 설명 |
| --- | --- | --- |
| `--translationDir` | nuxt.config의 `i18n.translationDir` | 번역 디렉터리, 프로젝트 기준 상대 경로 |
| `--format` | `po` | 파일 형식: po, csv |
| `--dir` | po는 `pots`, csv는 `csv_exports` | 입력 디렉터리, 프로젝트 기준 상대 경로 |
| `--dryRun` | `false` | 가져올 항목만 보고하고 아무것도 쓰지 않음 |

```bash
i18n-micro import --format csv --dryRun
```

### `sync-remote` {#sync-remote}

.i18n-remote.json에 지정된 HTTP 엔드포인트에서 전역 번역을 가져오거나(pull) 엔드포인트로 보냅니다(push)

| 플래그 | 기본값 | 설명 |
| --- | --- | --- |
| `--translationDir` | nuxt.config의 `i18n.translationDir` | 번역 디렉터리, 프로젝트 기준 상대 경로 |
| `--pull` | `true` | 원격에서 가져오기 |
| `--push` | `false` | 원격으로 보내기 |
| `--force` | `false` | pull 시 원격 값을 채택; push 시 원격에만 있는 텍스트를 덮어쓰기 |
| `--dryRun` | `false` | pull로 변경될 내용만 보고하고 아무것도 쓰거나 보내지 않음 |

```bash
i18n-micro sync-remote --dryRun
i18n-micro sync-remote --no-pull --push
```

## Lint 규칙 {#lint-rules}

| 규칙 | 찾는 대상 | `--fix`로 수정 |
| --- | --- | --- |
| `no-trailing-spaces` | 값 또는 줄 끝의 공백 | 예 |
| `no-multiple-spaces` | 연속된 두 개 이상의 공백 | 예 |
| `no-empty-translation` | 비어 있거나 공백뿐인 값 | 아니요 |

## 종료 코드 {#exit-codes}

| 코드 | 의미 |
| --- | --- |
| `0` | 완료, 보고할 내용 없음 |
| `1` | 발견 사항: `check`, `lint` 또는 `format --check`가 무언가를 찾음, `clean` 또는 `sync`가 제거의 안전성을 증명하지 못함, `export`가 가져오지 않은 작업을 덮어쓰게 됨, `translate`가 키를 누락함, `import` 또는 `sync-remote`가 충돌을 만남, `sync-remote` push가 원격 텍스트를 삭제하게 됨. `clean`, `sync` 또는 `sync-remote` pull의 `--dryRun`은 이를 보고하고 `0`으로 종료합니다 |
| `2` | 실패: 잘못된 사용법, 읽을 수 없는 프로젝트, 네트워크 또는 파일 오류 |

## 구성 파일 {#configuration-files}

| 파일 | 사용처 |
| --- | --- |
| `.i18n-lintrc.json` | `lint`: `enabledRules`, `disabledRules`, `customRegexRules` (`name`, `pattern`, `flags`, `description`, `replacement`) |
| `.i18n-remote.json` | `sync-remote`: `url`, `path`, `token`, `auth` (`username`, `password`). `type`은 생략할 수 있으며, `custom`만 존재합니다 |
| `.i18n-glossary.json` | `translate --service ai`: `source`, `target` 및 선택적 `from`, `to`로 구성된 `entries` |

## 환경 변수 {#environment-variables}

| 이름 | 용도 |
| --- | --- |
| `I18N_TRANSLATE_TOKEN` | `translate`의 API 키. `.env`에서도 읽음 |
| `I18N_REMOTE_TOKEN` | `sync-remote`의 Bearer 토큰. `.env`에서도 읽음 |
| `AI_GATEWAY_API_KEY, OPENAI_API_KEY, ANTHROPIC_API_KEY` | `I18N_TRANSLATE_TOKEN`이 설정되지 않은 경우 `ai` 서비스의 키 |
| `DEFAULT_LOCALE` | 모듈과 마찬가지로 `defaultLocale`을 재정의 |
