# API 참조

## 런타임 API

- [메서드](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, 로케일 전환, 라우팅 헬퍼
- [이벤트](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [번역 및 캐시](/api/cache) — `TranslationStorage`, 페이로드 로드, `$clearCache`

## 서버 미들웨어

서버 핸들러는 클라이언트 `$t` 헬퍼가 아닌 전용 미들웨어를 사용합니다:

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — API 라우트 및 서버 핸들러에서 번역
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — 감지된 로케일 및 메타데이터 읽기

설정, 로케일 감지 우선순위 및 예제는 전체 [서버 측 번역 가이드](/guides/server-side-translations)를 참조하세요.
