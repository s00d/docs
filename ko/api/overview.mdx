이 섹션에는 Nuxt 모듈의 모든 옵션, 헬퍼, 훅, 컴포저블, 컴포넌트와 각 `@i18n-micro/*` 패키지에서 내보내는 API가 정리되어 있습니다. 시그니처나 기본값을 찾아볼 때 사용하세요. 사용 방법은 [가이드](/ko/guide/getting-started)에서 설명합니다. 여기 있는 대부분의 표는 소스에서 생성되므로 코드와 일치합니다.

## Nuxt 모듈 {#nuxt-module}

| 페이지 | 다루는 내용 |
| --- | --- |
| [모듈 옵션](/ko/api/module-options) | `nuxt.config`의 모든 `i18n` 키와 그 타입 및 기본값 |
| [헬퍼](/ko/api/methods) | `$t`, `$tc`, `$tn`, `$td`, `$localePath`, `$switchLocale`, `$defineI18nRoute` 등 |
| [훅](/ko/api/events) | `i18n:register` 런타임 훅 |

## 컴포저블 {#composables}

| 컴포저블 | 용도 |
| --- | --- |
| [`useI18n`](/ko/composables/useI18n) | `<script setup>`에서 헬퍼 사용 |
| [`useI18nLocale`](/ko/composables/useI18nLocale) | 사용자 정의 감지 플러그인에서 로케일 상태와 쿠키 사용 |
| [`useI18nHead`](/ko/composables/useI18nHead) | 생성된 SEO 태그를 페이지별로 재정의 |
| [`useLocaleHead`](/ko/composables/useLocaleHead) | 직접 작성한 `useHead`에 사용할 객체 형태의 SEO 태그 |

## 컴포넌트 {#components}

| 컴포넌트 | 렌더링 내용 |
| --- | --- |
| [`<i18n-t>`](/ko/components/i18n-t) | 복수형, 서식 지정, 슬롯 보간을 지원하는 하나의 번역 |
| [`<i18n-link>`](/ko/components/i18n-link) | 현지화된 라우트로 가는 `NuxtLink` |
| [`<i18n-switcher>`](/ko/components/i18n-switcher) | 로케일 드롭다운 |
| [`<i18n-group>`](/ko/components/i18n-group) | 공통 키 접두사를 가진 블록 |

## 서버 {#server}

Nitro 핸들러는 클라이언트 헬퍼가 아니라 `useTranslationServerMiddleware`와 `useLocaleServerMiddleware`를 사용합니다. [서버 라우트](/ko/guide/server-side-translations)를 참고하세요.

## 패키지 {#packages}

[패키지 API](/ko/api/packages/overview)에는 모든 `@i18n-micro/*` 패키지의 내보내기 항목이 패키지별로 생성된 페이지에 정리되어 있습니다.
