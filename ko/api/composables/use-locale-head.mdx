# 🌍 `useLocaleHead` 컴포저블

`useLocaleHead` 컴포저블은 지역화된 라우트에 대한 SEO 속성과 HTML 메타 태그를 관리하는 데 도움이 되는 `Nuxt I18n Micro`의 유틸리티입니다. HTML 문서의 `lang`과 `dir`에 대한 속성을 동적으로 생성하고, 지역화된 콘텐츠의 SEO를 개선하기 위한 `meta`와 `link` 태그를 생성합니다.

현재 라우트의 SEO head 태그: 모든 로케일의 `hreflang` 대체와 `x-default`, canonical 링크, `og:locale`, `<html>`의 `lang`/`dir`.

`meta`가 비활성화되어 있거나 기본값을 조정해야 할 때만 필요합니다. `meta: true`인 경우 모듈이 동일한 태그를 자체적으로 등록합니다.

## 🛠️ 반환값

`useLocaleHead` 컴포저블은 소스 데이터가 변경될 때 호출해야 하는 반응형 객체와 업데이터 함수를 반환합니다. 두 형태 모두 위의 시그니처에 있으며, 소스에서 생성되었습니다.

### `metaObject`

`useHead(metaObject)`에 적합한 반응형 head 페이로드 (html attrs, meta, link).

- **예제**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

현재 라우트, 로케일, 설정에 따라 `metaObject`를 다시 계산합니다. 입력이 변경될 때 호출하세요 — 예를 들어 라우트 변경 시.

- **예제**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### `link`와 `meta`에 접근

`link`와 `meta` 배열은 `metaObject.value`를 통해 접근할 수 있습니다:

- **예제**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ 사용 예제

### 기본 사용법

기본 옵션으로 로케일별 head 속성을 생성합니다.

```js
const head = useLocaleHead()
```

### 식별자 속성 사용자 정의

생성된 태그에 사용자 정의 식별자 속성을 사용합니다.

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### SEO 속성 비활성화

SEO 관련 메타 및 링크 태그를 추가하지 않고 head 속성을 생성합니다.

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### 기본 URL 지정

canonical 및 대체 URL에 사용자 정의 기본 URL을 설정합니다.

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 추가 기능

### SEO 메타 및 링크 태그

`addSeoAttributes`가 활성화되면, 컴포저블은 자동으로 다음 태그를 생성합니다:

- 현재 로케일에 대한 `og:locale` (`language_TERRITORY`, 밑줄). `locale.og`에서 파생되거나 가능한 경우 `locale.iso`에서 변환됩니다.
- 페이지의 canonical URL에 대한 `og:url`.
- 대체 언어 버전에 대한 `og:locale:alternate`.
- SEO 최적화를 위한 `rel="canonical"` 및 `rel="alternate"` 링크.
- 기본 로케일 URL을 가리키는 `hreflang="x-default"` 링크. 이는 검색 엔진에게 정의된 로케일과 언어가 일치하지 않는 사용자에게 표시할 URL을 알려줍니다.

### 동적 로케일 및 방향

컴포저블은 현재 라우트의 로케일에 따라 `lang`과 `dir` 속성을 동적으로 결정하여 국제 사용자를 위해 HTML 문서가 올바르게 설정되도록 합니다.

### 지역화된 라우트 처리

라우트에 로케일 코드가 접두사로 지정되어 있다면 (예: `/en/about`), 컴포저블은 URL 생성을 위해 전체 경로를 지능적으로 조정하여 SEO 속성이 정확하고 관련이 있도록 합니다.

이 컴포저블은 국제 사용자를 위해 Nuxt 애플리케이션을 최적화하는 프로세스를 단순화하여, 사이트가 글로벌 검색 엔진과 사용자를 위해 잘 준비되도록 합니다.

## 🛠️ 사용 예제

다음 예제는 기본 설정으로 Vue 컴포넌트 내에서 `useLocaleHead` 컴포저블을 사용하는 방법을 보여줍니다:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### 코드 설명

- **`useLocaleHead` 컴포저블**: 이 컴포저블은 `<script setup>` 섹션에서 호출되며 `htmlAttrs`, `meta`, `link`를 포함하는 객체를 반환합니다.

- **`<html>` 태그**: HTML 문서의 `lang`과 `dir` 속성은 현재 로케일에 따라 동적으로 결정되어 `<html>` 태그에 적용됩니다.

- **`<head>` 섹션**:
  - **메타 태그**: SEO 관련 메타 태그가 생성됩니다. 여기에는 페이지의 대체 언어 버전을 지정하는 `og:locale`, `og:url`, `rel="canonical"` 및 `rel="alternate"` 태그가 포함됩니다.
  - **링크 태그**: canonical 링크, 대체 언어 버전에 대한 링크, `hreflang="x-default"` 링크 (기본 로케일 URL을 가리킴)가 포함됩니다.

- **`<body>` 섹션**: 페이지의 주요 콘텐츠가 여기에 표시됩니다. 이 예제에서는 간단한 헤더와 문단이 사용됩니다.

### 📝 참고

1. **속성**: 사용된 속성 (`lang`, `dir`, `rel`, `href`, `hreflang`, `property`, `content`)은 `useLocaleHead`가 반환하는 객체에서 추출됩니다.

2. **SEO 태그 생성**: `addSeoAttributes` 옵션이 `true`로 설정되면 컴포저블은 현재 로케일에 대한 SEO 태그를 자동으로 생성합니다.

3. **기본 URL**: `baseUrl` 옵션을 사용하여 canonical 및 대체 링크를 올바르게 생성하기 위한 사용자 정의 기본 URL을 설정할 수 있습니다.

이 예제는 애플리케이션의 컴포넌트에 `useLocaleHead`를 통합하여 올바른 SEO 속성을 보장하고 지역화된 페이지의 검색 엔진 인덱싱을 개선하는 것이 얼마나 쉬운지 보여줍니다.

## 🧩 사용자 정의 및 라이프사이클

- `useLocaleHead`는 자체적으로 변경 사항을 구독하지 않습니다. `metaObject`와 `updateMeta`를 반환합니다.
- 입력이 변경될 때 `updateMeta()`를 호출해야 합니다 (일반적으로 라우트 변경 시). 예를 들어 플러그인에서:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## 대신 `useI18nHead`를 사용할 때

`meta: true` (기본값)인 경우, **페이지별** 재정의 (사용자 정의 hreflang, 추가 `og:title`, 부분 비활성화)를 위해 [`useI18nHead`](/api/composables/use-i18n-head)를 선호하세요. `meta: false`이거나 `useHead`를 직접 관리하는 경우에만 `useLocaleHead`를 직접 사용하세요.
