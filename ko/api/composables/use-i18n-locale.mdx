# useI18nLocale

## 시그니처

i18n 로케일 관리를 위한 중앙 진입점.
useState('i18n-locale'), 로케일 쿠키, 동기화 유틸리티를 결합합니다.

## 사용법

```vue
<script setup>
const {
  locale,
  localeCookie,
  hashCookie,
  validLocales,
  getPreferredLocale,
  getLocale,
  getLocaleWithServerFallback,
  getEffectiveLocale,
  resolveInitialLocale,
  setLocale,
  syncLocale,
  isValidLocale,
} = useI18nLocale()

// Set locale (updates state and cookies)
setLocale('de')

// Get current locale (state → cookie)
const current = getLocale()

// Get valid preferred locale
const preferred = getPreferredLocale()
</script>
```

## API

| 속성/메서드                                       | 유형                                | 설명                                                                                   |
| ----------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| `locale`                                        | `Ref<string \| null>`               | 반응형 로케일 상태 (`useState('i18n-locale')`)                                          |
| `localeCookie`                                  | `Ref`                               | 로케일 쿠키 (`localeCookie` 옵션이 활성화된 경우)                                        |
| `hashCookie`                                    | `Ref`                               | `hashMode`가 활성화되었을 때 사용되는 쿠키                                              |
| `validLocales`                                  | `string[]`                          | 모듈 설정의 활성화된 로케일 코드 (`disabled` 제외)                                       |
| `getLocale()`                                   | `() => string \| null`              | 현재 로케일: 상태 → 쿠키 (hash 모드에서는 hash 쿠키)                                    |
| `getPreferredLocale()`                          | `() => string \| null`              | 상태/쿠키의 로케일 중 `validLocales`에 대해 **검증된** 것 또는 `null`                    |
| `getLocaleWithServerFallback(serverLocale?)`    | `(serverLocale?) => string \| null` | 상태 → 쿠키 → 선택적 서버 컨텍스트 (`no_prefix` 초기화 중 사용)                          |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string`             | 번역 로딩을 위한 로케일: hash 모드는 상태를 선호하고 그렇지 않으면 라우트에서 읽음         |
| `resolveInitialLocale(options)`                 | `(options) => string`               | 로케일 해결: 상태 → `serverLocale` → 라우트; 필요할 때 상태 동기화                        |
| `setLocale(locale)`                             | `(locale: string \| null) => void`  | 로케일을 설정하고 쿠키에 동기화                                                          |
| `syncLocale(locale)`                            | `(locale: string \| null) => void`  | 쿠키만 동기화 (상태 업데이트 없음)                                                      |
| `isValidLocale(locale)`                         | `(locale) => boolean`               | 문자열이 `validLocales`에 있는지 확인                                                   |

### `resolveInitialLocale` 옵션

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

시작 시 메인 플러그인에서 내부적으로 사용됩니다. 대체 감지 흐름을 구현할 때 사용자 정의 플러그인에서 호출할 수 있습니다.

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

주어진 라우트 객체에 대해 번역을 로드하고 메시지를 형식화하는 데 사용되는 로케일을 반환합니다.

## 프로그래매틱 로케일 설정

`useState('i18n-locale')`을 직접 사용하는 것보다 `useI18nLocale()`을 선호하세요:

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
`setLocale()`은 로케일 기본 설정(상태 + 쿠키)만 업데이트합니다. 클라이언트에서 활성 번역 컨텍스트도 다시 로드하려면 `useNuxtApp()` 또는 `useI18n()`의 `$switchLocale()`을 사용하세요. URL이 변경되지 않는 `no_prefix`에서 특히 중요합니다. [FAQ — URL을 변경하지 않고 로케일 전환](/guides/faq#-switch-locale-without-changing-the-url)을 참고하세요.
</Tip>
