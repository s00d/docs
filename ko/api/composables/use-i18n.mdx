# 🛠️ `useI18n` 컴포저블

`Nuxt I18n Micro`의 `useI18n` 컴포저블은 컴포넌트와 스크립트에서 대부분의 런타임 i18n 헬퍼에 접근할 수 있게 합니다. 메서드는 `$` 접두사가 있는 형태와 없는 형태 **모두** 사용할 수 있습니다 (예: `$t`와 `t`).

일부 주입 — `$defineI18nRoute`와 `$clearCache` — 은 `useNuxtApp()`에서만 사용 가능합니다. [메서드 — `$defineI18nRoute`](/api/methods#definei18nroute)와 [`$clearCache`](/api/methods#clearcache)를 참고하세요.

## 📊 반환값

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

일반 객체로 된 모든 런타임 헬퍼.

플러그인이 `$t`, `$tc` 등으로 주입하는 것과 동일한 함수들이며, 달러 접두사가 있는 이름과 접두사 없는 별칭 두 가지로 모두 사용할 수 있습니다. 따라서 `const \{ t \} = useI18n()`과 `const \{ $t \} = useI18n()` 모두 작동합니다.

**반환** — [메서드 레퍼런스](/api/methods)에 설명된 헬퍼

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

반환되는 모든 헬퍼 — `$t`, `$tc`, `$has`, `$switchLocale` 등 — 는 시그니처와 함께 나열되며 [메서드 레퍼런스](/api/methods)에 자세히 문서화되어 있습니다.

## `useNuxtApp()` 전용 API

이들은 `useI18n()`에서 반환되지 **않습니다**. `useNuxtApp()`에서 임포트하세요:

| 메서드                       | 목적                                                                             |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | 페이지별 로케일 라우트, 제한사항, `script setup` 내 인라인 번역                           |
| `$clearCache()`            | 메모리 내 번역 캐시와 로드된 청크를 지웁니다                                              |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

전체 시그니처와 예제는 [메서드](/api/methods)를 참고하세요.

## 🛠️ 사용 예제

### 기본 로케일 검색

애플리케이션의 현재 로케일을 검색합니다.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### 매개변수를 사용한 번역

대체 기본값과 함께 동적 매개변수로 문자열을 번역합니다.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### 로케일 전환

애플리케이션을 다른 로케일로 전환합니다.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### 지역화된 라우트 생성

현재 또는 지정된 로케일로 지역화된 라우트를 생성합니다.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
