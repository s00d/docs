# 🛠️ `useI18n` 컴포저블

`Nuxt I18n Micro`의 `useI18n` 컴포저블은 컴포넌트와 스크립트에서 대부분의 런타임 i18n 헬퍼에 접근할 수 있게 합니다. 메서드는 **`$` 접두사가 있는 형태와 없는 형태 모두** 사용할 수 있습니다(예: `$t`와 `t`).

일부 주입 — `$defineI18nRoute`와 `$clearCache` — 은 `useNuxtApp()`에서만 사용할 수 있습니다. [Methods — `$defineI18nRoute`](/api/methods#definei18nroute)와 [`$clearCache`](/api/methods#clearcache)를 참조하세요.

## 📊 반환값

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

모든 런타임 헬퍼를 일반 객체로 제공합니다.

플러그인이 `$t`, `$tc` 등으로 주입하는 동일한 함수를 달러 접두사가 있는 이름과 순수 별칭 모두에서 사용할 수 있습니다 — 즉, `const \{ t \} = useI18n()`과 `const \{ $t \} = useI18n()`이 모두 작동합니다.

**반환값** — [methods reference](/api/methods)에서 설명하는 헬퍼

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

반환하는 모든 헬퍼 — `$t`, `$tc`, `$has`, `$switchLocale` 등 — 는 서명과 함께 나열되어 있으며 [Methods 참조](/api/methods)에 자세히 설명되어 있습니다.

## `useNuxtApp()` 전용 API

이러한 것들은 `useI18n()`에서 반환되지 **않습니다**. `useNuxtApp()`에서 가져오세요:

| 메서드                     | 목적                                                                         |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | 페이지별 로케일 라우트, 제한 및 `script setup`의 인라인 번역 |
| `$clearCache()`            | 인메모리 번역 캐시 및 로드된 청크를 지웁니다.                            |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

전체 서명과 예제는 [Methods](/api/methods)를 참조하세요.

## 🛠️ 사용 예제

### 기본 로케일 검색

애플리케이션의 현재 로케일을 검색합니다.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### 매개변수를 사용한 번역

폴백 기본값과 함께 동적 매개변수로 문자열을 번역합니다.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### 로케일 전환

애플리케이션을 다른 로케일로 전환합니다.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### 지역화된 라우트 생성

현재 또는 지정된 로케일로 지역화된 라우트를 생성합니다.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
