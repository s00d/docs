---

모듈은 하나의 런타임(앱) 훅인 `i18n:register`를 호출합니다. 플러그인이나 모듈이 `locales/` 파일에 없는 번역을 추가할 때 사용하세요. 콜백은 현재 표시 중인 페이지에 번역을 병합하는 `register` 함수를 받습니다.

## `i18n:register` {#i18nregister}

```ts
'i18n:register': (
  register: (translations: unknown, locale?: string) => void,
  locale: string,
) => HookResult
```

| 인수 | 설명 |
| --- | --- |
| `register(translations, locale?)` | `translations`를 로드 중인 라우트의 페이지 청크에 `locale`(기본값: 훅의 `locale`)용으로 깊은 병합합니다. 이미 있는 키는 덮어씁니다. |
| `locale` | 로드 중인 라우트의 로케일입니다. |

이 훅은 `RuntimeNuxtHooks`를 통해 타입이 지정되므로 `nuxtApp.hook('i18n:register', …)`에 캐스트가 필요 없습니다.

## 실행 시점 {#when-it-fires}

로더 플러그인(`i18n-plugin-loader`)이 다음 시점에 호출합니다:

1. 시작 시 한 번, 모든 플러그인이 실행된 후(`app:created`) 앱이 렌더링되기 전에;
2. `router.beforeEach`에서, 대상 페이지의 번역이 로드된 후 경로가 바뀔 때 — `no_prefix`에서는 모든 내비게이션마다.

모든 콜백과 모든 `register` 호출은 앱이 렌더링되거나 내비게이션이 계속되기 전에 await되므로, 페이지는 병합된 키로 렌더링됩니다. [`hooks: false`](/ko/api/module-options#hooks)를 사용하면 훅은 호출되지 않습니다.

## 예시 {#example}

```ts
// plugins/i18n-extra.ts
export default defineNuxtPlugin((nuxtApp) => {
  nuxtApp.hook('i18n:register', async (register, locale) => {
    const extra = await $fetch<Record<string, unknown>>(`/api/cms-strings/${locale}`)
    register(extra, locale)
  })
})
```

이것은 런타임 훅입니다: `nuxt.config`의 `nuxt.hook`이나 모듈의 `setup`이 아니라 플러그인에서 `nuxtApp.hook`으로 등록하세요. 모듈은 `addPlugin`으로 이런 플러그인을 추가합니다.
