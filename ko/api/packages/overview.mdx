title: "패키지 API"
description: "CI가 소스와 대조하는 API 스냅샷에서 생성된 모든 @i18n-micro/* 패키지의 내보낸 API."
---

Nuxt 모듈은 작은 `@i18n-micro/*` 패키지들로 구성되며, 대부분은 단독으로도 동작합니다: Vue 앱에서는 `@i18n-micro/vue`, 어디서든 `@i18n-micro/core`. 이 페이지들에서 패키지가 엔트리 포인트별로 무엇을 내보내는지 찾아보세요. 각 페이지는 [`pnpm run api:surface`](https://s00d.github.io/nuxt-i18n-micro/contributing/maintenance-commands#api-surface)가 TypeScript 소스와 대조하는 스냅샷에서 생성되므로, CI가 알아채지 못한 채 내보내기가 변경될 수 없습니다.
