# 패키지 API

`nuxt-i18n-micro`는 대부분 독립적으로 사용 가능한 작은 패키지들로 구성되어 있습니다 — 일반 Vue 앱에서는 `@i18n-micro/vue`, 어디서나 `@i18n-micro/core`.

아래 각 페이지는 [`pnpm run api:surface`](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/maintenance-commands.md#api-surface)가 TypeScript 소스에 대해 확인하는 API 스냅샷에서 생성되므로, 이 레퍼런스가 변경되거나 CI가 실패하지 않고서는 내보내기가 사라질 수 없습니다.
