2개 진입점에 걸친 7개의 내보내기.
[`pnpm run api:surface`](https://s00d.github.io/nuxt-i18n-micro/contributing/maintenance-commands#api-surface)가 TypeScript 소스와 대조하여 검사하는
API 스냅샷에서 생성되었습니다.

## `@i18n-micro/types-generator` {#@i18n-micro/types-generator}

```ts
import { /* … */ } from '@i18n-micro/types-generator'
```

| 내보내기 | 종류 | 시그니처 |
| --- | --- | --- |
| `formatKeyProperty` | function | `(key: string) => string` |
| `generateTypes` | function | `(options: GeneratorOptions) => string` |
| `GeneratorOptions` | interface | 4개 멤버 |
| `getTypesString` | function | `(options: GeneratorOptions) => string` |
| `I18nTypesPlugin` | function | `(options: GeneratorOptions) => Plugin` |

<Accordion title="`GeneratorOptions` — 4개 멤버">

| 멤버 | 타입 |
| --- | --- |
| `additionalDirs?` | `string[] \| undefined` |
| `outputFile?` | `string \| undefined` |
| `srcDir` | `string` |
| `translationDir` | `string \| string[]` |

</Accordion>

</Accordion>
