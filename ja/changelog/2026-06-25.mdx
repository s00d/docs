**日付**: 2026-06-25

**バージョン**: `v3.21.0`

![v3.21.0 release](/images/3.21.0.png)

このリリースでは **`useI18nHead`** を追加しました。これは組み込みの `02.meta` プラグインの上で i18n の SEO を上書きするための、ページレベルの composable です。カスタムの meta プラグインや `meta: false` を使わずに、ルートごとに `hreflang`、canonical、`og:url`、Open Graph タグをカスタマイズできます。

## 新機能 {#what’s-new}

### `useI18nHead` Composable {#usei18nhead-composable}

`meta: true`(デフォルト)のとき、任意のページで `useI18nHead` を呼び出します。モジュールはルートが更新されるたびに、`useLocaleHead` の後にあなたの入力をマージします:

```vue
<script setup lang="ts">
useI18nHead(() => ({
  meta: [{ property: 'og:title', content: article.value?.title }],
  replace: {
    canonical: article.value?.canonicalUrl,
    ogUrl: article.value?.canonicalUrl,
    hreflang: localeCodes.map((locale) => ({
      rel: 'alternate',
      hreflang: locale,
      href: article.value!.locales[locale]!,
    })),
    ogAlternates: localeCodes,
  },
}))
</script>
```

静的オブジェクト、リアクティブな getter、`meta` / `link` の追加、組み込みグループに対する `replace`、自動生成タグを削除する `disable` をサポートします。[`useI18nHead`](/ja/composables/useI18nHead) を参照してください。

### `mergeI18nHead` ユーティリティ(`@i18n-micro/utils`) {#mergei18nhead-utility-@i18n-micro/utils}

フレームワーク非依存のマージロジックは `@i18n-micro/utils/merge-i18n-head` にあります。`02.meta` プラグインで使用されており、単体でテストできます。型(`I18nHeadInput`、`I18nHeadLink`、`I18nHeadMeta`)は `@i18n-micro/types` からエクスポートされます。

### プラグインとの統合 {#plugin-integration}

- **`02.meta`** — `useLocaleHead` の出力と `useI18nHead` のページ状態を `useHead` でマージします
- **`01.plugin`** — ルート名が変わると `resetPageHead()`(composable と共有される状態)でページの上書きをリセットします

### ドキュメントとテスト {#documentation-&-tests}

- 新しいガイド: CMS/記事の例を含む [`useI18nHead`](/ja/composables/useI18nHead)
- [SEO](/ja/guide/seo) と [`useLocaleHead`](/ja/composables/useLocaleHead) を更新 — どの API をいつ使うか
- Playwright + Vitest によるカバレッジ: SSR、SPA ナビゲーション、リロード、`nuxi generate`、部分的な alternate、`x-default`、リアクティブなクライアント読み込み

## 典型的なユースケース {#typical-use-cases}

| シナリオ                                     | アプローチ                                                       |
| -------------------------------------------- | -------------------------------------------------------------- |
| 部分的に翻訳されたブログ/CMS           | API のロケールから `replace.hreflang` + `replace.ogAlternates`   |
| CMS からのカスタム canonical                    | `replace.canonical` + `replace.ogUrl`                          |
| ランディングページの OG のみ                         | `meta: [{ property: 'og:title', ... }]` — モジュールの hreflang は維持 |
| ページに hreflang を出さない                        | `disable: ['hreflang', 'x-default']`                           |
| カスタムプラグイン(`i18nManualHreflang`)の置き換え | コンテンツページごとに `useI18nHead` + `meta: true`                  |

**JSON-LD** は引き続き `useHead({ script: [...] })` で扱います。`useI18nHead` は構造化データを生成しません。

## 破壊的変更 {#breaking-changes}

標準的な `nuxt.config` の使い方ではありません。新しい composable と utils のサブパスは追加のみです。

## なぜ重要か {#why-it-matters}

- ロケールごとの URL を持つ CMS の投稿、ニュース、ガイドに **カスタム meta プラグインは不要**
- **単一のパイプライン** — モジュールのデフォルトとページの上書きを 1 回の `useHead` 呼び出しで
- **型安全** — `buildArticleHead(content)` のようなヘルパー向けの `I18nHeadInput`

完全な変更履歴はリリースとともに [GitHub](https://github.com/s00d/nuxt-i18n-micro/blob/main/CHANGELOG.md) で公開されます。
