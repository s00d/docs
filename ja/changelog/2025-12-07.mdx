![v2.14 リリース](/images/2.14.0.png)

Node.js、Vue 3、Astro 向けのまったく新しいインテグレーションを含む **v2.14.1** のリリースをお知らせします！これらのパッケージは、同じ強力な i18n 機能をお気に入りのフレームワークにもたらし、一貫性とパフォーマンスのために同じコアロジックを共有しています。

## 新機能 {#what’s-new}

- **@i18n-micro/node** - あらゆる Node.js アプリケーション、CLI ツール、バックエンドサービスで i18n 翻訳を利用できます
- **@i18n-micro/vue** - リアクティブな翻訳とルート固有のサポートを備えた、国際化のための Vue 3 プラグイン
- **@i18n-micro/astro** - 完全な TypeScript サポートを備えた、国際化のための Astro インテグレーション
- **@i18n-micro/types-generator** - 翻訳キーの TypeScript 型を自動生成し、完全な型安全性と IDE の補完を提供します

## 主な機能 {#key-features}

すべてのインテグレーションは、共通して次の利点を備えています：

- 軽量かつ高性能
- ルート固有の翻訳をサポート
- 組み込みの複数形処理
- 数値、日付、相対時間のフォーマット
- 完全な TypeScript サポート
- 同じ JSON 翻訳ファイル構造

**Types Generator** は、開発者体験をさらに向上させます：

- JSON 翻訳ファイルからの自動型生成
- コンパイル時に検証される型安全な翻訳キー
- IDE の完全な補完サポート
- 翻訳ファイル変更時のホットリロード
- ランタイムオーバーヘッドなし

詳細なドキュメントとサンプルについては、[リポジトリ](https://github.com/s00d/nuxt-i18n-micro)または[ドキュメント](https://s00d.github.io/nuxt-i18n-micro/)をご覧ください。
