リリース: **v3.22.0 → v3.26.0**。

## 新機能

- **翻訳メモリ API。** `$resolveTranslations()` と `$setTranslation(key, value)` を使って、アクティブなロケール辞書をランタイムで読み取り、パッチできます。DevTools、テスト、アプリ内エディターに便利です。[メソッド](/api/methods#resolvetranslations) を参照してください。
- **名前付き `numberFormats` と `datetimeFormats`。** Vue I18n 互換の名前付きフォーマットをロケール単位で設定し、`$tn(1000, 'currency')` や `$td(date, 'short')` を呼び出せます。[モジュールオプション](/api/module-options) を参照してください。
- **`/_locales` ペイロードでの HTTP キャッシュ制御。** 新しい [`httpCacheDuration`](/api/module-options) は、翻訳ペイロードに `Cache-Control: public, max-age=…, immutable` を設定します。デフォルトは 1 年で、`?v={dateBuild}` によるキャッシュバスティングと安全に組み合わせられます。
- **圧縮された翻訳ペイロード。** `nitro.compressPublicAssets` が有効な場合、パブリック翻訳ペイロードが自動的に圧縮されます。[パフォーマンスガイド](/guides/performance) を参照してください。
- **`splitLocaleRoutes` ユーティリティ。** ルート名でキー付けされたプログラム的なリストから `pages` と `globalLocaleRoutes` の両方を構築できます(`pages:extend` シナリオ向け)。[カスタムロケールルート](/guides/custom-locale-routes#programmatic-routes-pagesextend--244) を参照してください。
- **SEO ベースの `site.url` フォールバック。** `metaBaseUrl` が未設定の場合、SEO タグは存在する場合は `nuxt-site-config` の `site.url` にフォールバックし、そうでなければリクエストオリジンにフォールバックします。[`metaBaseUrl`](/api/module-options) を参照してください。

## 更新

- **Astro アダプター。** ルーティングコンテキストの分離、および `numberFormats` と `datetimeFormats` の接続。
- **React と Preact。** `I18nSwitcher` が正しく `aria-haspopup` と `aria-expanded` 属性を設定するようになりました。
- **ベンチマーク。** パフォーマンスベンチマークが citty ベースの CLI に移行しました。
- **コンテンツフィンガープリントの `dateBuild`。** デフォルトの `dateBuild` はコンテンツフィンガープリントになりました。これによりペイロードの `?v=` は翻訳が実際に変わったときにのみ変化します。

## 修正

- **ルーティング。**
  - ローカライズされたルートマッチャーが、ダッシュ付きパス、ネストされたパス、パラメーター化されたセグメントを正しく扱うようになりました。
  - 子ルートが絶対パスの場合でも、ネストされた親が保持されます。
  - `hreflang` がロケールの `iso` から出力されるようになり、ルーティングコードは使用されません。
  - `no_prefix` 下でのロケール切り替えが、履歴を push するのではなく replace するようになりました。
- **リダイレクト。**
  - Cookie と `Accept-Language` の設定に基づくリダイレクトで `autoDetectPath` が尊重されるようになりました。
  - `autoDetectPath: '/'` の下で `localeRoutes` エイリアスが保持されるようになりました。
- **翻訳。**
  - `null` を返すカスタム複数形関数がデフォルトの複数形ルールにフォールスルーするようになりました。
  - 翻訳レイヤーが平坦化ダンプなしにマージされるようになりました。
  - 無効化されたロケールが premerged パブリックペイロードから除外されるようになりました。
  - HMR がノーオペレーションのファイル書き込みをスキップし、ルートロケール変更時に並行して再マージするようになりました。
- **スイッチャー。** `disabled` ロケールを非表示にし、`customDisabledLinkStyle` とアクティブスタイルの優先順位を復元しました。
- **モジュール。** Nuxt Kit との互換性のため、unplugin Vite 8 の `Plugin` 型をブリッジしました。
- **SSR。** Node SSR がパブリックペイロードから読み取るようになりました(Rollup `raw:` インポートなし)。

## 破壊的変更 (v3.22.0)

- SSR チャンクが `useState('i18n-ssr-chunks')` から `nuxtApp.payload.data['i18n-ssr-chunks']` に移動しました。
- `@i18n-micro/vue` から `getAllTranslations()` が削除されました。代わりに `resolveTranslations()`、`getStorage()`、または `getRouteCache()` を使用してください。
- デフォルトの `dateBuild` はコンテンツフィンガープリントになりました。アップグレード時にペイロードの `?v=` が 1 回変化します。
