title: "useI18nHead"
description: "useI18nHead は、1 つのページについて生成された i18n SEO タグを上書きします：canonical、hreflang、og タグの置き換えや削除、独自タグの追加が可能です。"
---

`useI18nHead()` は、モジュールが生成する SEO タグを 1 つのページに限って変更します。ページ側がルーターよりも正確な情報を持っている場合に使用します：一部のロケールにしか存在しない CMS の記事、API から取得した canonical URL、追加の `og:` タグなどです。生成されたタグの上にオーバーライドがマージされた結果が得られます。

## シグネチャ {#signature}

```ts
useI18nHead(input?: MaybeRefOrGetter<I18nHeadInput | null>): { pageHead: any; resetPageHead: () => void }
```

i18n SEO head タグに対するページレベルのオーバーライドを登録します。
`02.meta` プラグインによって `useLocaleHead` の出力の上にマージされます。

値が `$t` / `t` から得られる場合は、ロケール変更時に再解決されるよう
ゲッター（`() => ({ … })`）を使用してください。プレーンオブジェクトは一度だけ評価され、固定されたままになります。

| パラメーター | 型 | 説明 |
| --- | --- | --- |
| `input` *(任意)* | `MaybeRefOrGetter<I18nHeadInput \| null>` |  |

[`meta: true`](/ja/api/module-options#meta)（デフォルト）で動作します：モジュールの meta プラグインが、head のレンダリングごとに [`useLocaleHead`](/ja/composables/useLocaleHead) の出力に入力をマージします。`meta: false` の場合は何も読み取られません。

オーバーライドはルート名が変わるとリセットされます。`disableMeta` を設定したページには、オーバーライドを含め i18n タグが一切付与されません。

## 入力 {#input}

`I18nHeadInput`（`@i18n-micro/types` から）：

| キー | 型 | 効果 |
| --- | --- | --- |
| `htmlAttrs` | `Record<string, string>` | `<html>` の属性（`lang`、`dir`）にマージされます。 |
| `meta` | `I18nHeadMeta[]` | 生成されたタグの後に追加されます。同じ `id`、`property`、`name` を持つタグを置き換えます。 |
| `link` | `I18nHeadLink[]` | 生成されたリンクの後に追加されます。同じ `id`、または `rel` + `hreflang` を持つリンクを置き換えます。 |
| `replace.canonical` | `string \| false` | canonical の `href` を置き換えるか、リンクを削除します。 |
| `replace.hreflang` | `I18nHeadLink[] \| false` | `x-default` を含む**すべての** `rel="alternate"` リンクを置き換えるか削除します。 |
| `replace.xDefault` | `I18nHeadLink \| false` | `x-default` リンクを置き換えるか削除します。 |
| `replace.ogLocale` | `string \| false` | `og:locale` を置き換えるか削除します。 |
| `replace.ogUrl` | `string \| false` | `og:url` を置き換えるか削除します。 |
| `replace.ogAlternates` | `string[] \| false` | これらのロケールコードから（`og` / `iso` 経由で）`og:locale:alternate` を再構築します。現在のロケール、不明なコード、`og` または `iso` の値を持たないコードはスキップされます。または、それらを削除します。 |
| `disable` | `I18nHeadDisableGroup[]` | 生成されたグループを削除します：`'hreflang'`（`x-default` は除く）、`'x-default'`、`'canonical'`、`'og'`（`og:locale` + `og:url`）、`'og-alternates'`、`'html'`。 |

適用順序：`disable`、次に `replace`、その後 `htmlAttrs`、`meta`、`link`。

## 例 {#example}

一部のロケールにのみ存在し、API から代替 URL を取得する記事：

```vue
<script setup lang="ts">
const route = useRoute()
const { t } = useI18n()
const { data: article } = await useFetch<{ title: string; urls: Record<string, string> }>(`/api/articles/${route.params.slug}`)

useI18nHead(() => {
  if (!article.value) return null
  const codes = Object.keys(article.value.urls)
  return {
    meta: [{ property: 'og:title', content: article.value.title || t('blog.title') }],
    replace: {
      hreflang: codes.map((code) => ({ rel: 'alternate', hreflang: code, href: article.value!.urls[code]! })),
      ogAlternates: codes,
    },
  }
})
</script>
```

値が `t()` や非同期データから得られる場合は、この例のようにゲッターを渡してください：ロケール変更時に再実行されます。プレーンオブジェクトは一度だけ読み取られます。
