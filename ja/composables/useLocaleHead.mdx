---
title: "useLocaleHead"
description: "useLocaleHead は、i18n SEO タグ（lang、dir、canonical、hreflang、og:locale）を useHead に渡せるオブジェクトとして構築します。"
---

`useLocaleHead()` は、現在のルートの i18n head タグを構築します：`<html>` の `lang` と `dir`、canonical リンク、`x-default` を含む `hreflang` 代替リンク、`og:url`、`og:locale`、`og:locale:alternate` です。[`meta: false`](/ja/api/module-options#meta) を設定して `useHead` を自分で管理する場合に使用します。`meta: true` の場合はモジュールがすでにこれらのタグを登録しており、ページごとの変更は [`useI18nHead`](/ja/composables/useI18nHead) で行います。

## シグネチャ {#signature}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { build: () => LocaleHead; metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }, LocaleHead | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

現在のルートの SEO head タグ：すべてのロケールの `hreflang` 代替リンクと
`x-default`、canonical リンク、`og:locale`、および `<html>` の `lang`/`dir`。

`meta` が無効な場合や、デフォルトの調整が必要な場合にのみ必要です — `meta: true` の場合は
モジュール自身が同じタグを登録します。

| パラメーター | 型 | 説明 |
| --- | --- | --- |
| `options` | `UseLocaleHeadOptions` |  |

**戻り値** — `metaObject`：`useHead` にそのまま渡せる head オブジェクトを保持する ref。`updateMeta`：それを更新します。`build`：現在のルートから head オブジェクトを計算します（ゲッター内で読み取るとリアクティブになります。例：`useHead(() => build())`）

```ts
const { metaObject } = useLocaleHead({ addSeoAttributes: true })
useHead(metaObject)
```

## オプション {#options}

| オプション | デフォルト | 説明 |
| --- | --- | --- |
| `addDirAttribute` | `true` | ロケールの `dir` から `<html>` に `dir` を設定します（指定がない場合は `'auto'`）。 |
| `identifierAttribute` | `'id'` | 各タグのキーとなる属性（`i18n-can`、`i18n-og`、`i18n-alternate-<hreflang>` など）。これにより、更新時にタグが追加されるのではなく置き換えられます。 |
| `addSeoAttributes` | `true` | canonical、`hreflang`、`og:` タグを出力します。`false` の場合は `htmlAttrs` のみを保持します。 |
| `baseUrl` | `'/'` | すべての URL に結合されるオリジン。相対 URL の場合は `'/'` のままにし、絶対 URL の場合は `'https://example.com'` を渡します。 |
| `autoUpdate` | `true` | ルートまたは `i18n-locale` の状態が変わったときに `metaObject` を再構築します。 |

## 出力内容 {#what-it-emits}

- 一致するルートがない場合（404）や、アクティブなロケールに `disableMeta` が設定されている場合は何も出力しません。
- canonical と `og:url`：`$switchLocalePath(<active locale>)`。クエリは [`canonicalQueryWhitelist`](/ja/api/module-options#canonicalquerywhitelist) に絞り込まれ、[`trailingSlash`](/ja/api/module-options#trailingslash) が適用されます。
- `hreflang`：ページが存在する有効なロケールごとに 1 つのリンク。`hreflang = iso || code` で、`seo: false` のロケールはスキップされます。`hreflangBaseLanguage: true` の場合、ある言語の最初の地域ロケールは、言語のみのタグも出力します。`no_prefix` では出力されません。
- `x-default`：デフォルトロケールの URL。ただし、ストラテジーが `no_prefix` の場合、デフォルトロケールに `seo: false` が設定されている場合、またはページがデフォルトロケールに存在しない場合を除きます。
- `og:locale` / `og:locale:alternate`：ロケールの `og`、またはその `iso` を変換したもの（`en-US` → `en_US`）。どちらも使えない場合は、開発時に警告を出してスキップされます。

## 例 {#example}

```ts
// app.vue, with i18n.meta: false
const { metaObject } = useLocaleHead({ baseUrl: 'https://example.com' })
useHead(metaObject)
```

`build()` は ref なしで同じオブジェクトを返します：`useHead(() => build())` はウォッチャーなしでリアクティブなままです。
