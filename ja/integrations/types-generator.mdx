---
title: "型ジェネレーター"
description: "Nuxt または任意の Vite プロジェクトで、JSON ファイルから翻訳キーの TypeScript 補完を生成します。"
---

`@i18n-micro/types-generator` は翻訳フォルダー内のすべての JSON ファイルを読み取り、すべてのキーを列挙した型宣言を書き出します。`t()`、`$t()`、`<I18nT keypath>` でエディターにキーを補完させたい場合に追加してください。Nuxt モジュールとしても、Vite や Rollup のプラグインとしても動作し、ファイルが変更されると再生成されます。

## インストール {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/types-generator
```

```bash npm
npm install -D @i18n-micro/types-generator
```

```bash yarn
yarn add -D @i18n-micro/types-generator
```

</CodeGroup>

ピア依存関係: `@nuxt/kit` `^3.18.0 || ^4.0.0`。これをインポートするのは `/nuxt` エントリーだけなので、Vite のみのプロジェクトではピア依存関係の警告は無視して構いません。

## Nuxt {#nuxt}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro', '@i18n-micro/types-generator/nuxt'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

モジュールは `.nuxt/types/i18n-micro.d.ts` を書き出し、Nuxt がそれを型コンテキストに追加するため、手動で含める必要はありません。読み取り先は `i18nTypes.translationDir`、指定がなければ `nuxt-i18n-micro` が翻訳を読み取る場所、つまり各レイヤーの `translationDir`(`i18n` またはインラインのモジュールオプションから、デフォルトは `'locales'`)と `additionalTranslationDirs` です。`nuxi dev` では、そのフォルダー内の JSON ファイルを編集すると型が再生成されます。Nuxt では `i18nTypes.outputFile` は無視されます(その旨の警告が表示されます)。

## Vite {#vite}

`I18nTypesPlugin` は Vite プラグインで、Rollup でも使えます。それ以外のバンドラーでは、スクリプトから `generateTypes` を呼び出してください。

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { I18nTypesPlugin } from '@i18n-micro/types-generator'

export default defineConfig({
  plugins: [
    vue(),
    I18nTypesPlugin({
      srcDir: process.cwd(),
      translationDir: 'src/locales',
      outputFile: 'src/i18n-micro.d.ts',
    }),
  ],
})
```

| オプション | 必須 | 備考 |
| --- | --- | --- |
| `srcDir` | はい | ベースディレクトリ。`translationDir` はこれを基準に解決されます。 |
| `translationDir` | はい | JSON ファイルを含むフォルダー(`pages/` などのサブフォルダーを含む)、またはフォルダーの配列。 |
| `outputFile` | いいえ | 型宣言の書き出し先。デフォルトは `<srcDir>/i18n-micro.d.ts`。 |

プラグインはビルド開始時に一度生成し、開発サーバーではフォルダー内の変更から 300 ms 後に再生成します。`tsconfig.json` の `include` が出力ファイルを含んでいることを確認してください。

## キーを使う {#use-the-keys}

生成されたファイルは `@i18n-micro/types` の `DefineLocaleMessage` を拡張し、`TranslationKey` をあなたのキーに変えます:

```ts
declare module '@i18n-micro/types' {
  export interface DefineLocaleMessage {
    nav: object
    'nav.home': string
    'profile.title': string
  }
}
```

キーは `t()` が応答するもの(オブジェクトも含む)で、すべてのロケールとすべてのページファイルから集められ、JSON の値の型を持ちます。`TranslationKey` はそれらのキーと任意の文字列のユニオンなので、エラーではなく補完が得られます。つづりを誤ったキーや動的なキーでもコンパイルは通ります。パラメーターと戻り値には型が付きません。

既知のプレフィックスの下にある動的キーには、`ScopedKey<'prefix'>` で一致するキーに絞り込めます:

```ts
import type { ScopedKey } from '@i18n-micro/types'

const statusText = (status: string) => t(`status.${status}` as ScopedKey<'status'>)
```

`TranslationKey` と `ScopedKey` は `@i18n-micro/types` から提供されます(React、Preact、Solid は `TranslationKey` を再エクスポートしますが、Vue はしません)。

## API {#api}

| エクスポート | エントリー | 備考 |
| --- | --- | --- |
| `I18nTypesPlugin(options)` | `@i18n-micro/types-generator` | Vite および Rollup プラグイン |
| `generateTypes(options)` | `@i18n-micro/types-generator` | ファイルを書き出し、そのパスを返します |
| `getTypesString(options)` | `@i18n-micro/types-generator` | 書き出さずに型宣言を返します |
| `formatKeyProperty(key)` | `@i18n-micro/types-generator` | ヘルパー |
| Nuxt モジュール(`configKey: 'i18nTypes'`) | `@i18n-micro/types-generator/nuxt` | オプション `translationDir` |

完全なシグネチャ: [パッケージリファレンス](/ja/api/packages/types-generator)。
