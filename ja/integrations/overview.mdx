# 統合

`@i18n-micro` パッケージは、さまざまなフレームワークや環境への統合用に設計された、Nuxt I18n Micro の軽量なフレームワーク固有版です。これらのパッケージは、最小限のフットプリントでコアの国際化機能を提供し、必須の翻訳機能と基本コンポーネントに焦点を当てています。

## 概要

これらの統合パッケージは、完全な Nuxt I18n Micro モジュールの **ミニチュア版** で、国際化に必要な必須機能のみを含んでいます:

- **コア翻訳機能** - 基本的な翻訳メソッド、複数形化、書式設定
- **必須コンポーネント** - 一般的な i18n タスク向けの少数の UI コンポーネント
- **ルーターアダプターパターン** - アダプター抽象化を通じた柔軟なルーティング統合
- **TypeScript サポート** - 型安全な開発のための完全な型定義

完全な Nuxt モジュールと異なり、これらのパッケージは:

- フレームワーク固有のルーティングロジックを含みません
- ルーティング機能のためにルーターアダプターの実装が必要です
- フレームワーク統合よりも翻訳機能に焦点を当てます
- 可能な限り軽量でフレームワーク非依存になるよう設計されています

## コアコンポーネント

すべてのフレームワークパッケージには以下の必須コンポーネントが含まれます:

### `<I18nT>`

以下をサポートして翻訳テキストをレンダリングする翻訳コンポーネント:

- **パラメーター補間** - プレースホルダーを動的な値に置換
- **複数形化** - カウントに基づく自動複数形形式選択
- **数値の書式設定** - ロケールに応じた数値のフォーマット
- **日付の書式設定** - 日付と相対時間のフォーマット
- **HTML レンダリング** - オプションの HTML コンテンツレンダリング
- **デフォルト値** - 翻訳が不足しているときのフォールバックテキスト

**例:**

```vue
<!-- Vue -->
<I18nT keypath="greeting" :params="{ name: 'World' }" />
```

```tsx
// React
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```tsx
// Solid
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```astro
<!-- Astro -->
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

### `<I18nLink>`

URL でロケールプレフィックスを自動的に処理するローカライズされたリンクコンポーネント。機能:

- **自動パスローカライズ** - ルーティング戦略に基づいてロケールプレフィックスを追加 / 削除
- **アクティブ状態検出** - 現在のルートをハイライト
- **外部リンクサポート** - 外部 URL を自動検出して処理
- **ルーター統合** - 利用可能な場合はルーターアダプターのリンクコンポーネントを使用
- **カスタムスタイリング** - アクティブおよびホバー状態をサポート

**例:**

```vue
<!-- Vue -->
<I18nLink to="/about" active-class="active">
  About Us
</I18nLink>
```

```tsx
// React
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```tsx
// Solid
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```astro
<!-- Astro -->
<I18nLink href="/about" class="nav-link">
  About Us
</I18nLink>
```

### `<I18nSwitcher>`

ロケール変更のためのドロップダウンまたはリストインターフェースを提供する言語スイッチャーコンポーネント。機能:

- **自動ロケールリスト** - 設定されたロケールからオプションを生成
- **現在ロケールのハイライト** - アクティブな言語を視覚的に示す
- **カスタムラベル** - ロケールごとのカスタム表示名をサポート
- **ルーター統合** - ローカライズされたパスへ自動的にナビゲート
- **アクセシビリティ** - 適切な ARIA 属性とキーボードナビゲーション

**例:**

```vue
<!-- Vue -->
<I18nSwitcher />
```

```tsx
// React
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```tsx
// Solid
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```astro
<!-- Astro -->
<I18nSwitcher />
```

### `<I18nGroup>`

共通のプレフィックスで翻訳をグループ化するコンポーネント。ページや機能ごとに翻訳を整理するのに便利です。機能:

- **プレフィックススコープ** - グループ内のすべての翻訳キーにプレフィックスを自動的に付与
- **ネストされたグループ** - 入れ子の翻訳グループをサポート
- **クリーンな整理** - 整理された翻訳構造の維持に役立つ

**例:**

```vue
<!-- Vue -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

```tsx
// React
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```tsx
// Solid
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```astro
<!-- Astro -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

## 共有の `createI18n` オプション \{#create-i18n-options\}

すべてのフレームワークパッケージは同じ方法で作成されます — オプションの型名だけがフレームワーク名になります(`ReactI18nOptions`、`SolidI18nOptions` など)。オプション自体は同一です:

| プロパティ         | 型                                                       | 必須 | デフォルト          | 説明                                    |
| ---------------- | ---------------------------------------------------------- | -------- | ---------------- | ---------------------------------------------- |
| `locale`         | `string`                                                   | ✅       | -                | 現在のロケールコード(例: `'en'`)             |
| `fallbackLocale` | `string`                                                   | ❌       | `locale` と同じ | 翻訳が不足しているときのフォールバックロケール    |
| `messages`       | `Record<string, Translations>`                             | ❌       | `\{\}`             | 初期翻訳メッセージ                   |
| `plural`         | `PluralFunc`                                               | ❌       | `defaultPlural`  | カスタム複数形化関数                  |
| `missingWarn`    | `boolean`                                                  | ❌       | `true`           | 不足している翻訳のコンソール警告を表示 |
| `missingHandler` | `(locale: string, key: string, routeName: string) => void` | ❌       | -                | 不足している翻訳用のカスタムハンドラー        |

これら以外のものはフレームワーク固有で、そのパッケージのページで説明されます。

## ルーターアダプター抽象化

すべてのフレームワークパッケージは、特定のルーター実装から i18n 機能を分離するための **ルーターアダプターパターン** を使用します。この設計により、以下が可能になります:

- **柔軟性** - 任意のルーターライブラリ、またはルーターなしでも使用可能
- **フレームワーク独立性** - ルーティングロジックを i18n パッケージではなくアプリケーション側に保持
- **軽量なコア** - i18n パッケージは小さく焦点を絞ったまま

### ルーターアダプターの実装

ルーティング機能を使うには、`I18nRoutingStrategy` インターフェースを実装する必要があります:

```typescript
interface I18nRoutingStrategy {
  getCurrentPath: () => string
  linkComponent?: Component
  push: (target: { path: string }) => void
  replace: (target: { path: string }) => void
  resolvePath?: (to: string | { path?: string }, locale: string) => string | { path?: string }
  getRoute?: () => { fullPath: string; query: Record<string, unknown> }
}
```

各パッケージのドキュメントには、人気のあるルーター向けのアダプター実装の完全な例が含まれています:

- **Vue**: Vue Router アダプターの例
- **React**: React Router アダプターの例
- **Solid**: Solid Router アダプターの例
- **Astro**: ファイルベースルーティングアダプターの例

## コア機能

すべてのパッケージは以下のコア機能を共有します:

### 翻訳メソッド

- `t()` - パラメーター補間付きの基本翻訳
- `ts()` - 常に文字列を返す翻訳
- `tc()` - 複数形対応の翻訳
- `tn()` - 数値の書式設定
- `td()` - 日付の書式設定
- `tdr()` - 相対時間の書式設定
- `has()` - 翻訳キーが存在するか確認

### ロケール管理

- **ロケール切り替え** - プログラム的に現在のロケールを変更
- **フォールバックロケール** - 翻訳が不足しているときの自動フォールバック
- **ルート固有の翻訳** - ページレベルの翻訳整理
- **翻訳キャッシュ** - パフォーマンスのためのインテリジェントなキャッシュ

### TypeScript サポート

すべてのパッケージは以下を提供します:

- 完全な TypeScript 定義
- 型安全な翻訳キー(types generator を利用)
- IDE での IntelliSense サポート
- コンパイル時のエラーチェック

## はじめに

1. **パッケージを選ぶ** - フレームワーク用のパッケージを選択
2. **パッケージをインストール** - お好みのパッケージマネージャーを使用
3. **ドキュメントを読む** - 各パッケージには詳細なセットアップ手順があります
4. **ルーターアダプターを実装** - ルーティング機能が必要なら、アダプターを実装
5. **翻訳を開始** - コンポーネントとメソッドを使って翻訳を追加

詳細なセットアップ手順については、特定のパッケージのドキュメントを参照してください:

- [Vue パッケージのドキュメント](/integrations/vue)
- [React パッケージのドキュメント](/integrations/react)
- [Solid パッケージのドキュメント](/integrations/solid)
- [Astro パッケージのドキュメント](/integrations/astro)
