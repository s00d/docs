`@i18n-micro/runtime` はフレームワークに依存しない i18n インスタンスです。辞書、`t()`、複数形、`Intl` による書式化、変更のサブスクリプションを提供し、`fs` にもフレームワークにも依存しません。素の TypeScript、Web Worker、エッジ関数で使ったり、独自のバインディングのベースとして使ったりできます。React、Preact、Node、Astro の各パッケージはこの同じクラスを拡張しています。

## インストール {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/runtime
```

```bash npm
npm install @i18n-micro/runtime
```

```bash yarn
yarn add @i18n-micro/runtime
```

</CodeGroup>

ピア依存関係はありません。ディスク上の翻訳ファイルを使う場合は [`@i18n-micro/node`](/ja/integrations/nodejs-package) を使用してください。

## セットアップ {#setup}

```ts
import { createI18n } from '@i18n-micro/runtime'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    en: { greeting: 'Hello, {name}!', apples: 'no apples | one apple | {count} apples' },
    de: { greeting: 'Hallo, {name}!' },
  },
  routeMessages: {
    about: { en: { title: 'About us' } },
  },
})
```

すべてのオプション（`plural`、`missingWarn`、`missingHandler`、`numberFormats`、`datetimeFormats`）は[インスタンス](/ja/integrations/overview#the-instance)に一覧があります。

## 翻訳する {#translate}

```ts
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.tc('apples', 5) // '5 apples'
i18n.tn(1234.5) // '1,234.5'

i18n.setRoute('about')
i18n.t('title') // 'About us' (route dictionary)
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!' (root, still visible)
```

後から辞書を追加で読み込むには：

```ts
i18n.loadMessages({ fr: { greeting: 'Bonjour, {name} !' } }, { about: { fr: { title: 'À propos' } } })
i18n.addTranslations('fr', { nav: { home: 'Accueil' } }) // deep merge; pass false to replace

await i18n.loadFromUrl('/locales/fr.json', { locale: 'fr' })
await i18n.loadFromUrl('/locales/pages/about/fr.json', { locale: 'fr', routeName: 'about' })
await i18n.loadFromUrls([
  { url: '/locales/en.json', locale: 'en' },
  { url: '/locales/de.json', locale: 'de' },
])
```

`loadFromUrl` は `fetch` を使い（ヘッダーには `init` を渡します）、OK でないレスポンスでは例外を投げます。`loadFromUrls` は 1 つずつ順番に読み込みます。

## ロケールを切り替える {#switch-locale}

```ts
i18n.locale = 'de'
i18n.t('greeting', { name: 'Ada' }) // 'Hallo, Ada!'
```

ロケール、ルート、辞書の変更はサブスクライバーに通知され、フレームワークのバインディングはこれによって再レンダリングします：

```ts
const stop = i18n.subscribe(() => {
  document.querySelector('#greeting')!.textContent = i18n.t('greeting', { name: 'Ada' }) as string
})
i18n.locale = 'fr'
stop()
```

`getSnapshot()` は通知のたびに変わる文字列を返します（`useSyncExternalStore` 形式のストア向け）。

## リクエストごと {#per-request}

インスタンスは 1 つのロケールと 1 つのルートを保持します。サーバーでは、共有インスタンスをリクエストごとに切り替えないでください：同時に 2 つのリクエストがあると、互いのロケールが見えてしまいます。`i18n.fork(locale)` はリクエストに専用のインスタンスを与えます：独自のロケール、フォールバック、ルートを持ち、辞書、フォーマッター、ルールは共有します。フォークのコストは辞書の数にかかわらず同じです。フォークは自身が最初に書き込むまで親への書き込みを参照し、フォーク自身の書き込みはフォーク内に留まります。[Node.js](/ja/integrations/nodejs-package#per-request) は `run` を追加します。

## API {#api}

| メンバー | 備考 |
| --- | --- |
| `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has` | [翻訳と書式化](/ja/integrations/overview#translate-and-format)を参照 |
| `locale`, `fallbackLocale` | 取得/設定 |
| `currentRoute`, `setRoute(name)`, `getRoute()` | アクティブなルート、デフォルトは `'index'` |
| `loadMessages(messages?, routeMessages?)` | 多数のロケールとルートを一度にマージ |
| `addTranslations(locale, tree, merge = true)`, `addRouteTranslations(locale, route, tree, merge = true)` | |
| `loadFromUrl(url, { locale?, routeName?, init? })`, `loadFromUrls(entries)` | JSON を `fetch` |
| `hasTranslation(key)` | アクティブなロケール、任意のルート（アクティブなルートとルートファイルをチェックする `has` とは異なる） |
| `setTranslation(key, value)`, `resolveTranslations()` | 1 つのキーを書き込む；マージされたツリーを読む |
| `clear()`, `clearCache()` | すべての辞書を破棄 |
| `subscribe(cb)`, `getSnapshot()` | 変更通知 |
| `storage` | `{ translations: Map<'locale:route', Translations> }` |

言語タグでないコードは、`localeIso: { ua: 'uk-UA' }` から複数形を取得します。`localeIsoMap(locales)` は、ロケール一覧のうち `iso` を持つ項目からそれを構築します。

モジュールのエクスポート：`createI18n`、`I18n`、`fetchJsonTranslations`、`FormatService`、`interpolate`、`localeIsoMap`、および型 `I18nOptions`、`LoadFromUrlOptions`、`LoadFromUrlEntry`、`TranslationStorage`、`Translations`、`Locale`、`PluralFunc`。完全なシグネチャ：[パッケージリファレンス](/ja/api/packages/runtime)。
