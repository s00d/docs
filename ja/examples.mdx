# 📚 Nuxt I18n Micro のサンプルと使用例

このセクションでは、Nuxt.js アプリケーションで `Nuxt I18n Micro` を使用する方法をさまざまな例で示します。ロケールの切り替え、`<i18n-link>`、`<i18n-switcher>`、`<i18n-t>` コンポーネントの使用方法、翻訳キーの動的な扱い方などを紹介します。

## 🛠️ 基本セットアップ

`Nuxt I18n Micro` を始めるための基本的なセットアップです:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 ロケールの切り替え

### プログラムによるロケールの切り替え

この例は、ボタンでプログラム的にロケールを切り替える方法を示しています:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### ロケール切り替え用の JSON 例

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### `<i18n-switcher>` コンポーネントの利用

`<i18n-switcher>` コンポーネントは、カスタマイズ可能なラベル付きのロケール切り替えドロップダウンを提供します:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 📝 翻訳ファイルからの動的キーのレンダリング

シナリオによっては、翻訳ファイル内に格納された動的なキーを反復処理して、その値を条件付きでレンダリングしたい場合があります。以下の例は、`Nuxt I18n Micro` を使ってこれを実現する方法を示します。

### 例: 動的キーのレンダリング

この例では、特定の翻訳パス(この場合は `dynamic`)からキーの配列を取得して反復処理します。各キーは `$has` で存在確認された後、`$t` で値がレンダリングされます。

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### 翻訳ファイル例(`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### 例: オブジェクトからの動的キーのレンダリング

この例では、翻訳ファイル内に格納されたオブジェクトを扱います。オブジェクトのキーを取得して反復処理し、キー名と関連する値の両方を動的にレンダリングします。

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### 翻訳ファイル例(`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 スロットと補間を伴う翻訳のための `<i18n-t>`

`<i18n-t>` コンポーネントは、動的コンテンツや HTML タグを含む翻訳のレンダリングに便利です:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### `<i18n-t>` 用の JSON 例

```json
{
  "greeting": "Welcome to the page"
}
```

### 補間を伴う例

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### 補間用の JSON 例

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 複数形化のための `$tc` の利用

`Nuxt I18n Micro` の `$tc` 関数は、カウントとロケール設定に基づいて複数形化を処理します。アイテム数、通知数、その他数によって変化するメッセージを動的に調整するのに便利です。

### 例: 複数形化のための `$tc` の利用

以下の例では、`$tc` を使って林檎の数を示すメッセージを表示します。翻訳キーは、提供されるカウントに基づいて複数の複数形形式を処理します。

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### 複数形化のための JSON 例

異なる複数形形式を扱う翻訳を JSON ファイルで次のように定義できます:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### 説明

- **`$tc('apples', 0)`**: カウントがゼロの場合の最初の形式(`"no apples"`)を返します。
- **`$tc('apples', 1)`**: カウントが 1 の場合の 2 番目の形式(`"one apple"`)を返します。
- **`$tc('apples', 10)`**: カウントが 2 以上の場合の、カウント値を含む 3 番目の形式(`"10 apples"`)を返します。

### より複雑な複数形化を伴う追加例

アプリケーションでより複雑な複数形化ルール(例: zero、one、two、few、many、other の特定ケース)を扱う必要がある場合、翻訳文字列を次のように拡張できます:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: `"two apples"` を返すように設定できます。
- **`$tc('apples', 3)`**: カウントに対して定義されたルールに応じて `"a few apples"` を返すことができます。

## 🌐 数値の書式設定のための `$tn` の利用

`$tn` 関数は、`Intl.NumberFormat` API を使用して現在のロケールに従って数値を書式設定します。通貨、パーセンテージ、その他の数値形式など、ユーザーの地域設定に合わせて数値を表示するのに便利です。

### 例: 数値の書式設定のための `$tn` の利用

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ 日時の書式設定のための `$td` の利用

`$td` 関数は、`Intl.DateTimeFormat` API を使用して現在のロケールに従って日付と時刻を書式設定します。ロケール設定に基づいてユーザーになじみのある形式で日付と時刻を表示するのに便利です。

### 例: 日時の書式設定のための `$td` の利用

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ 相対日付書式設定のための `$tdr` の利用

`$tdr` 関数は、`Intl.RelativeTimeFormat` API を使用して現在のロケールに従って日付を相対時間(例: 「5 分前」「2 日前」)として書式設定します。現在の日時に対する時間差を表示するのに便利です。

### 例: 相対日付書式設定のための `$tdr` の利用

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
