title: "<i18n-switcher>"
description: "<i18n-switcher> コンポーネントは、有効なロケールのドロップダウンで、各項目はそのロケールでの現在のページにリンクします。"
---

`<i18n-switcher>` は、アクティブなロケールを表示するボタンと、アクティブなものを含むすべての有効なロケールのドロップダウンを描画します。既製の言語メニューとして使用してください。異なるマークアップが必要な場合は、[`$getLocales`](/ja/api/methods#$getlocales) と [`$switchLocalePath`](/ja/api/methods#$switchlocalepath) を使って独自に構築できます。各項目は、そのロケールでの現在のページにリンクします。

## Props とスロット {#props-and-slots}

| Prop | 型 | デフォルト | 説明 |
| --- | --- | --- | --- |
| `customLabels` | `Record<string, string>` | `() => ({})` | ロケールコードごとの表示名。ロケール設定の `displayName` を上書きします。 |
| `customWrapperStyle` | `CSSProperties` | `() => ({})` | 外側のラッパーのインラインスタイル。 |
| `customButtonStyle` | `CSSProperties` | `() => ({})` | ドロップダウンを開くボタンのインラインスタイル。 |
| `customDropdownStyle` | `CSSProperties` | `() => ({})` | ドロップダウンパネルのインラインスタイル。 |
| `customItemStyle` | `CSSProperties` | `() => ({})` | ドロップダウン内の各項目のインラインスタイル。 |
| `customLinkStyle` | `CSSProperties` | `() => ({})` | 項目内のリンクのインラインスタイル。 |
| `customActiveLinkStyle` | `CSSProperties` | `() => ({})` | 現在アクティブなロケールのリンクのインラインスタイル。 |
| `customDisabledLinkStyle` | `CSSProperties` | `() => ({})` | 設定で `disabled: true` になっている場合の、*現在の*ロケールのボタンのインラインスタイル。 |
| `customIconStyle` | `CSSProperties` | `() => ({})` | ボタン上のキャレットアイコンのインラインスタイル。 |

### スロット {#slots}

| スロット | バインディング | 説明 |
| --- | --- | --- |
| `before-button` | — | ドロップダウンを開くボタンの前のコンテンツ。 |
| `before-selected-locale` | — | ボタン内のアクティブなロケールラベルの前のコンテンツ。 |
| `after-selected-locale` | — | ボタン内のアクティブなロケールラベルの後のコンテンツ。 |
| `before-dropdown` | — | ボタンとドロップダウンパネルの間のコンテンツ。 |
| `before-dropdown-items` | — | ドロップダウンの上部、ロケール一覧の上のコンテンツ。 |
| `before-item` | `locale` | 各ロケール項目の前のコンテンツ。 |
| `before-link-content` | `locale` | リンク内のロケールラベルの前のコンテンツ。 |
| `after-link-content` | `locale` | リンク内のロケールラベルの後のコンテンツ。 |
| `after-item` | `locale` | 各ロケール項目の後のコンテンツ。 |
| `after-dropdown-items` | — | ドロップダウンの下部、ロケール一覧の下のコンテンツ。 |
| `after-dropdown` | — | ドロップダウンパネルの後のコンテンツ。 |

## 動作 {#behaviour}

- `disabled: true` でないすべてのロケールを、アクティブなものも含めて一覧表示します。
- 各項目は `$switchLocalePath(code)` への `<a>` です。パスは `app.baseURL` 配下で解決され、別ドメインのロケール `baseUrl` は絶対 URL のままです。`hreflang` と `lang` には `iso || code` が設定され、ロケールに `dir` がある場合は `dir` が、現在のロケールには `aria-current="page"` が設定され、クラス `switcher-locale-<code>` が付きます。クリックすると `$switchLocale(code)` が呼ばれてドロップダウンが閉じます。修飾キーが押されている場合はブラウザーに処理を任せます。
- 一覧はサーバーの HTML 内に非表示のまま残るため、クローラーはリンクを認識できます。Escape キーまたは外側のクリックで閉じます。
- ラベル：`customLabels[code]`、次にロケールの `displayName`、最後にコード（開発時に警告を表示）の順で決まります。
- スタイル：小さなインラインのデフォルト（枠線付きの白いボタンとパネル、アクティブな項目は太字で青色）。各 `custom*Style` prop は、対応するパーツのデフォルトの後に適用されます。ボタンには `i18n-switcher-button` と `language-switcher`、ラッパーには `i18n-switcher-wrapper`、一覧には `i18n-switcher-dropdown` のクラスが付きます。位置指定には論理 CSS プロパティを使用しているため、`dir="rtl"` でも機能します。

## 例 {#example}

```vue
<template>
  <i18n-switcher
    :custom-labels="{ en: 'English', de: 'Deutsch' }"
    :custom-button-style="{ borderRadius: '4px' }"
  >
    <template #before-link-content="{ locale }">
      <img :src="`/flags/${locale.code}.svg`" alt="" width="16" />
    </template>
  </i18n-switcher>
</template>
```
