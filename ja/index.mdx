---
title: "Nuxt I18n Micro"
description: "Nuxt 向けの小さく高速な i18n: ページごとの JSON 翻訳、ビルド時にローカライズされるルート、標準で付属する SEO タグ。"
---

Nuxt I18n Micro は、大規模プロジェクト向けに設計された Nuxt 3 および 4 用の軽量で高性能な i18n モジュールです。`@nuxtjs/i18n` のような従来の i18n ソリューションと比べて、ビルド時間、メモリ使用量、バンドルサイズを小さく抑えます。

ローカライズされたルートはビルド時に `@i18n-micro/route-strategy` によって生成され、ランタイムに `@i18n-micro/path-strategy` によって解決されるため、リンク、スイッチャー、`hreflang`、リダイレクトはすべてルーターと一致します。翻訳は JSON のみで、共有のルートファイルと、開発サーバーが自動作成するページごとのファイルに分かれており、HMR も組み込まれています。

<CodeGroup>

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>
