Nuxt I18n Micro は、大規模プロジェクト向けに設計された、軽量かつ高性能な Nuxt 用 i18n モジュールです。`@nuxtjs/i18n` などの従来の i18n ソリューションと比較して、ビルド時間、メモリ使用量、バンドルサイズを削減します。

コアは単一の Nuxt モジュールと、少数のランタイムプラグインで構成されています。ロケールプレフィックスは `@i18n-micro/route-strategy`(ビルド時)と `@i18n-micro/path-strategy`(ランタイム)によって処理されます。翻訳は JSON のみで、共有のルートファイルとページ単位のファイルに分割され、開発時に自動生成されます。

## Nuxt I18n Micro を使うべきとき

- Nitro のペイロードを肥大化させずに、ページごとに遅延読み込みされる翻訳が必要な場合。
- ランタイムでのルート生成オーバーヘッドなしに、戦略ベースのルーティングを利用したい場合。
- SSR やエッジデプロイメントを高負荷下でも高速に保つ必要がある場合。
- `@nuxtjs/i18n` から移行して、同等の使いやすさをより小さなランタイムで実現したい場合。
