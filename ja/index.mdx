Nuxt I18n Micro は、大規模プロジェクト向けに設計された、Nuxt 用の軽量かつ高性能な i18n モジュールです。`@nuxtjs/i18n` のような従来の i18n ソリューションと比較して、ビルド時間、メモリ使用量、バンドルサイズを削減します。

コアは単一の Nuxt モジュールと小さなランタイムプラグインのセットで構成されています。ロケールプレフィックスは `@i18n-micro/route-strategy`(ビルド時)と `@i18n-micro/path-strategy`(ランタイム)によって処理されます。翻訳は JSON のみで、共有のルートファイルとページ単位のファイルに分割され、開発時に自動生成されます。

## Nuxt I18n Micro を使うべき場面

- Nitro ペイロードを肥大化させずに、遅延読み込みされるページ単位の翻訳が必要な場合。
- ランタイムのルート生成オーバーヘッドなしにストラテジーベースのルーティングを使いたい場合。
- SSR やエッジデプロイメントを高負荷下でも高速に保ちたい場合。
- `@nuxtjs/i18n` から移行し、同様の使い勝手でよりコンパクトなランタイムが必要な場合。
