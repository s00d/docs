`nuxt dev` では、モジュールが 2 つのデバッグ支援機能を追加します：翻訳ファイルを閲覧・編集するための Nuxt DevTools の **i18n Micro** タブと、ライブのロケールと読み込まれた辞書を確認するための Vue DevTools のインスペクターです。どちらも開発時のみ存在し、本番ビルドには何も追加しません。Nuxt のタブは Nuxt DevTools が有効になっていれば使えます。Vue のインスペクターには、さらに Vue DevTools のブラウザー拡張機能が必要です。

## Nuxt DevTools タブ {#nuxt-devtools-tab}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  devtools: { enabled: true }, // the tab is registered only when DevTools are on
})
```

Nuxt DevTools（`Shift + Alt + D`）を開き、**i18n Micro** を選択します。タブには以下が表示されます：

- すべてのレイヤーの `locales/`（ルートと `pages/`）配下にあるすべての JSON ファイル、および `additionalTranslationDirs` のルートファイル
- ファイルごとのエディター。**Save** でファイルをディスクに書き戻し、開発サーバーが翻訳を再読み込みします
- ファイルの JSON としての **Export** / **Import**、およびキー数と翻訳カバレッジを表示する **Stats**
- 解決済みのモジュールオプションを表示する設定ビュー
- **Translate**：タブの設定で構成した機械翻訳エンジンで、欠けているキーを埋めます

保存では、翻訳ディレクトリ内の既存の `.json` ファイルのみが書き込まれます。ファイルが複数のレイヤーに存在する場合は、プロジェクトのコピーが書き込まれます。

## Vue DevTools インスペクター {#vue-devtools-inspector}

Vue DevTools のブラウザー拡張機能があると、モジュールは i18n インスペクター（現在のロケール、ルートチャンク、読み込まれたキー）と、ロケールの切り替え、チャンクの読み込み、欠けているキーを示すタイムラインを登録します。

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    debug: true, // also log every $t / $ts / $tc call on the timeline
    // vueDevtools: false, // turn the inspector off, keep the Nuxt tab
  },
})
```

[`vueDevtools`](/ja/api/module-options) のデフォルトは `true` です。`debug: true` は出力が多いため、短いセッションでのみ使用してください。

## Nuxt 以外での利用 {#outside-nuxt}

同じ UI が、フレームワークパッケージで構築された Vite アプリ向けに [`@i18n-micro/devtools-ui`](/ja/integrations/devtools-ui-package) として公開されています。セットアップについてはそのページを参照してください。
