# 🛠️ `useI18n` コンポーザブル

`Nuxt I18n Micro` の `useI18n` コンポーザブルは、コンポーネントやスクリプトでほとんどのランタイム i18n ヘルパーへのアクセスを提供します。メソッドは**`$` プレフィックス付きと付いていない両方**の形式で利用できます(たとえば `$t` と `t`)。

`$defineI18nRoute` と `$clearCache` の一部インジェクションは `useNuxtApp()` からのみ利用可能です。[メソッド — `$defineI18nRoute`](/api/methods#definei18nroute) と [`$clearCache`](/api/methods#clearcache) を参照してください。

## 📊 戻り値

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

すべてのランタイムヘルパーをプレーンなオブジェクトとして返します。

プラグインが `$t`、`$tc` などとして注入するのと同じ関数が、ドル記号プレフィックス付きの名前とプレフィックスなしのエイリアスの両方で利用できます。つまり `const \{ t \} = useI18n()` と `const \{ $t \} = useI18n()` の両方が動作します。

**戻り値** — [メソッドリファレンス](/api/methods) で解説されているヘルパー

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

戻り値のすべてのヘルパー(`$t`、`$tc`、`$has`、`$switchLocale` など)は、そのシグネチャとともに [メソッドリファレンス](/api/methods) に完全に記載されています。

## `useNuxtApp()` 専用の API

これらは `useI18n()` からは**返されません**。`useNuxtApp()` からインポートしてください。

| メソッド                     | 目的                                                                         |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | `script setup` 内でページ単位のロケールルート、制限、インライン翻訳を設定します。 |
| `$clearCache()`            | インメモリの翻訳キャッシュと読み込まれたチャンクをクリアします。                            |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

完全なシグネチャと例は [メソッド](/api/methods) を参照してください。

## 🛠️ 使用例

### 基本的なロケール取得

アプリケーションの現在のロケールを取得します。

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### パラメーター付きの翻訳

動的なパラメーターとフォールバックのデフォルト値を伴って文字列を翻訳します。

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### ロケールの切り替え

アプリケーションを別のロケールに切り替えます。

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### ローカライズされたルートの生成

現在のロケール、または指定したロケールでローカライズされたルートを生成します。

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
