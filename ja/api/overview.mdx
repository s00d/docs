このセクションでは、Nuxt モジュールのすべてのオプション、ヘルパー、フック、コンポーザブル、コンポーネントに加え、各 `@i18n-micro/*` パッケージがエクスポートする API を掲載しています。シグネチャやデフォルト値を調べる際に利用してください。使い方は[ガイド](/ja/guide/getting-started)で説明しています。ここにあるほとんどの表はソースコードから生成されているため、コードと一致しています。

## Nuxt モジュール {#nuxt-module}

| ページ | 内容 |
| --- | --- |
| [モジュールオプション](/ja/api/module-options) | `nuxt.config` 内のすべての `i18n` キーとその型・デフォルト値 |
| [ヘルパー](/ja/api/methods) | `$t`、`$tc`、`$tn`、`$td`、`$localePath`、`$switchLocale`、`$defineI18nRoute` など |
| [フック](/ja/api/events) | `i18n:register` ランタイムフック |

## コンポーザブル {#composables}

| コンポーザブル | 用途 |
| --- | --- |
| [`useI18n`](/ja/composables/useI18n) | `<script setup>` 内でのヘルパー利用 |
| [`useI18nLocale`](/ja/composables/useI18nLocale) | カスタム検出プラグインでのロケール状態と Cookie |
| [`useI18nHead`](/ja/composables/useI18nHead) | 生成される SEO タグのページごとの上書き |
| [`useLocaleHead`](/ja/composables/useLocaleHead) | 独自の `useHead` 用に SEO タグをオブジェクトとして取得 |

## コンポーネント {#components}

| コンポーネント | 描画内容 |
| --- | --- |
| [`<i18n-t>`](/ja/components/i18n-t) | 複数形、フォーマット、スロット補間に対応した 1 つの翻訳 |
| [`<i18n-link>`](/ja/components/i18n-link) | ローカライズされたルートへの `NuxtLink` |
| [`<i18n-switcher>`](/ja/components/i18n-switcher) | ロケールのドロップダウン |
| [`<i18n-group>`](/ja/components/i18n-group) | 共通のキープレフィックスを持つブロック |

## サーバー {#server}

Nitro ハンドラーでは、クライアント用ヘルパーではなく `useTranslationServerMiddleware` と `useLocaleServerMiddleware` を使用します。[サーバールート](/ja/guide/server-side-translations)を参照してください。

## パッケージ {#packages}

[パッケージ API](/ja/api/packages/overview) では、すべての `@i18n-micro/*` パッケージのエクスポートを、パッケージごとに生成された 1 ページずつで掲載しています。
