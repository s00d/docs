# 🌍 `<i18n-switcher>` コンポーネント

`Nuxt I18n Micro` の `<i18n-switcher>` コンポーネントは、アプリケーション内で異なるロケール間を切り替えるための使いやすいドロップダウンインターフェースを提供します。このコンポーネントは高度にカスタマイズ可能で、アプリケーションのデザインやレイアウトへシームレスに統合できます。

`disabled: true` のロケールはドロップダウンから **除外** されます(SEO / head タグ用に `$getLocales()` からは引き続き利用可能です)。切り替え可能なロケールのみが `NuxtLink` + `hreflang` を取得します。

## 🛠️ 使用例

### 基本的な使い方

```vue
<template>
  <i18n-switcher />
</template>
```

これはデフォルトのスタイリングと挙動でロケールスイッチャーをレンダリングします。

### カスタムラベルとインラインスタイル

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

この例は、カスタムラベルとインラインスタイルで完全にカスタマイズされたロケールスイッチャーを示します。

## 🔌 スロット

スイッチャーの視覚的なすべての部分を置き換えられます。スロットは上記の props テーブルとともに列挙されており、それぞれがテンプレートコンテンツを受け取ります:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

`-item`、`-link-content` で終わるか、`before-item` で始まる名前のスロットは、対応する `locale` オブジェクトを受け取ります。

## 🎨 スタイルの概要

`<i18n-switcher>` コンポーネントには、インラインスタイルで定義された基本的なスタイルが用意されており、prop を通じてカスタムスタイルを渡すことで簡単に上書きできます。デフォルトのスタイリングの概要:

- **Wrapper**: ドロップダウンの配置を制御します。
- **Button**: ドロップダウン切り替えボタンをスタイル付けします。
- **Dropdown**: ドロップダウンリストをスタイル付けします。
- **Items**: リスト内の各項目をスタイル付けします。
- **Links**: 各項目内のリンクをスタイル付けします。
- **Icon**: ドロップダウンインジケーターアイコンをスタイル付けします。

対応する props を通じてカスタムスタイルを渡すことでこれらをカスタマイズでき、ロケールスイッチャーをアプリケーションの UI にシームレスに統合できます。
