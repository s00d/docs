# 🌍 `<i18n-link>` コンポーネント

`Nuxt I18n Micro` の `<i18n-link>` コンポーネントは、現在のロケールに基づいて自動的にルートをローカライズする多用途なリンクコンポーネントです。`<NuxtLink>` コンポーネントのラッパーとして動作し、アクティブリンクのスタイリングや外部リンクのサポートといった追加機能を提供します。

## ⚙️ Props

{/* generated:component:i18n-link — do not edit; run `pnpm run docs:generate` */}

| Prop | 型 | デフォルト | 説明 |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | 遷移先のルート。自動的にローカライズされます。外部 URL はそのまま渡されます。 |
| `activeStyle` | `Partial<CSSStyleValue>` | — | リンクが現在のルートを指しているときに適用されるインラインスタイル。 |

**\*** 必須。

### スロット

| スロット | バインディング | 説明 |
| --- | --- | --- |
| `default` | — | リンクのコンテンツ。 |

{/* /generated:component:i18n-link */}

`to` は `NuxtLink` が受け付けるものすべて(パス、名前付きルート、解決済みルートオブジェクトなど)を受け付けます。絶対 URL は自動的に検出され、ローカライズされる代わりに `<a target="_blank" rel="noopener noreferrer">` としてレンダリングされます。

## 🛠️ 使用例

### 基本的な使い方

```vue
<i18n-link to="/about">About Us</i18n-link>
```

この例では、現在のロケールにローカライズされた `/about` ページへのリンクを作成します。

### インラインスタイルによるアクティブリンクスタイリング

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

ユーザーが `/about` ページにいるときに、このリンクは太字テキストになります。インラインスタイルで直接アクティブリンクをスタイルできます。

### 外部リンクの処理

このコンポーネントは自動的に外部リンクを検出し、セキュリティのために必要な属性を追加します。

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

このリンクは `rel="noopener noreferrer"` を付与した新しいタブで `https://example.com` を開きます。

## 🎨 スタイル

コンポーネントは、アクティブ状態にクラスではなくインラインスタイルを使用するようになりました。`activeStyle` prop を使ってこれらのスタイルをカスタマイズできます。

### デフォルトのアクティブスタイル

- **フォントウェイト**: `bold`
- **色**: ブラウザのデフォルトカラーを継承します(`activeStyle` に `color` が指定されていない場合)。

`activeStyle` prop でカスタムスタイルを提供することでこれらを上書きできます。

### カスタムアクティブスタイル

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

この例では、アクティブなときにリンクが太字で緑色になります。

## 🚀 追加機能

### カスタムコンテンツ用のスロット

スロットを使ってリンク内にカスタムコンテンツを渡すことができ、さまざまなユースケースに柔軟に対応できます。

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### アクセシビリティの強化

このコンポーネントは `aria-label` などのアクセシビリティ属性をサポートし、よりアクセシブルな体験を提供します。

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
