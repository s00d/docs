# 🌍 `<i18n-group>` コンポーネント

Nuxt I18n Micro の `<i18n-group>` コンポーネントは、共通のプレフィックス配下に翻訳をグループ化するための便利な方法を提供し、繰り返しを削減してコード構成を改善します。

## ⚙️ Props

{/* generated:component:i18n-group — do not edit; run `pnpm run docs:generate` */}

| Prop | 型 | デフォルト | 説明 |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | スロット内のすべてのルックアップを解決するキープレフィックス。 |
| `groupClass` | `string` | `''` | ラッパー要素に追加するクラス。 |

**\*** 必須。

### スロット

| スロット | バインディング | 説明 |
| --- | --- | --- |
| `default` | `prefix`、`t` | `prefix` とそれにスコープされた `t` 関数を受け取ります。 |

{/* /generated:component:i18n-group */}

## 🎯 スロット

デフォルトスロットは `prefix` とそれにスコープされた `t` 関数を受け取るため、内部のキーはプレフィックスからの相対パスで書かれます:

```vue
<i18n-group prefix="checkout">
  <template #default="{ t }">
    <h2>{{ t('title') }}</h2>
    <p>{{ t('summary', { count: 3 }) }}</p>
  </template>
</i18n-group>
```

## 🛠️ 使用例

### 基本的な使い方

```vue
<template>
  <i18n-group prefix="product.details">
    <template #default="{ t }">
      <h1>{{ t('title') }}</h1>
      <p>{{ t('description') }}</p>
      <div class="price">{{ t('price', { value: 99.99 }) }}</div>
    </template>
  </i18n-group>
</template>
```

翻訳ファイル:

```json
{
  "product": {
    "details": {
      "title": "Premium Product",
      "description": "This is a premium product",
      "price": "Price: ${value}"
    }
  }
}
```

### カスタムクラス付き

```vue
<template>
  <i18n-group prefix="user.profile" group-class="profile-section">
    <template #default="{ t }">
      <div class="user-info">
        <h2>{{ t('title') }}</h2>
        <p>{{ t('bio') }}</p>
        <div class="stats">
          <span>{{ t('stats.followers') }}</span>
          <span>{{ t('stats.following') }}</span>
        </div>
      </div>
    </template>
  </i18n-group>
</template>
```

翻訳ファイル:

```json
{
  "user": {
    "profile": {
      "title": "User Profile",
      "bio": "User biography goes here",
      "stats": {
        "followers": "Followers: {count}",
        "following": "Following: {count}"
      }
    }
  }
}
```

### 動的なコンテンツ付き

```vue
<template>
  <i18n-group prefix="blog.post">
    <template #default="{ t }">
      <article>
        <h1>{{ t('title') }}</h1>
        <div class="meta">
          {{ t('meta.author', { name: author }) }} |
          {{ t('meta.date', { date: publishDate }) }}
        </div>
        <div v-for="(section, index) in sections" :key="index">
          <h2>{{ t(`sections.${index}.title`) }}</h2>
          <p>{{ t(`sections.${index}.content`) }}</p>
        </div>
      </article>
    </template>
  </i18n-group>
</template>

<script setup>
const author = 'John Doe'
const publishDate = '2024-01-01'
const sections = ['intro', 'main', 'conclusion']
</script>
```

## 🎨 スタイリング

コンポーネントは、コンテンツを `i18n-group` クラスの div と、`groupClass` prop に指定された追加のクラスでラップします:

```css
.i18n-group {
  /* Your base styles */
}

.profile-section {
  /* Additional styles for profile sections */
}
```

## 🚀 ベストプラクティス

1. **一貫したプレフィックス**: アプリケーション構造を反映した、一貫性のある論理的なプレフィックスを使いましょう

```vue
<i18n-group prefix="features.pricing">
<i18n-group prefix="features.security">
```

2. **モジュール的な整理**: 関連する翻訳を意味のあるプレフィックスの下にまとめましょう

```vue
<i18n-group prefix="checkout.payment">
<i18n-group prefix="checkout.shipping">
```

3. **再利用可能なコンポーネント**: 独自の翻訳グループを持つ再利用可能なコンポーネントを作りましょう

```vue
<!-- UserProfile.vue -->
<i18n-group prefix="user.profile">

<!-- UserSettings.vue -->
<i18n-group prefix="user.settings">
```

4. **入れ子グループ**: 明瞭さを維持するため、グループの深い入れ子を避けましょう

```vue
<!-- Good -->
<i18n-group prefix="shop.product">

<!-- Avoid -->
<i18n-group prefix="shop.category.product.details.specs">
```
