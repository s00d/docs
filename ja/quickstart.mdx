## 🚀 クイックスタート

### インストール

Nuxt アプリケーションにモジュールをインストールします:

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

### 基本設定

`nuxt.config.ts` にモジュールを追加します:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

<Tip>
- **ルートレベルのファイル**(`locales/en.json` など) — アプリ全体で共有される翻訳(メニュー、フッター、共通 UI)。`translationPayloads.mode: 'premerged'`(デフォルト)では、ビルド時にすべてのページにマージされます。
- **ページ固有のファイル**(`locales/pages/<route>/<locale>.json`) — 特定のページ固有の翻訳で、そのページを訪問したときにのみ読み込まれます。
- **動的ルート** — `pages/articles/[id].vue` は `locales/pages/articles-id/` にマッピングされます(角括弧はダッシュに置き換えられます)。
- **自動生成** — 翻訳ファイルが存在しない場合、`nuxt dev` 中に自動作成されます。
</Tip>

<Info>
このモジュールは両方のレイアウトをサポートしています:

- **ページ**: `pages/**/*.vue`(Nuxt 3)または `app/pages/**/*.vue`(Nuxt 4)
- **翻訳**: デフォルトでは `locales/` を **プロジェクトルート** に置きます(推奨される慣例)。`app/` 内には置きません。

```tree
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   ├── en.json
│   └── pages/
└── nuxt.config.ts
```

オプションのコロケーション: `i18n: \{ translationDir: 'app/locales' \}`([フィクスチャ `n3`](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/n3) を参照)。

オプションの CLI ヘルパー `text-to-i18n` を使う場合は、[`nuxt-i18n-micro-cli` ≥ 2.1.1](/guides/cli#-text-to-i18n-command) を使用して、`app/pages` と `app/components` がプロジェクトルートからスキャンされるようにします。
</Info>

### 基本的な使い方

コンポーネント内で翻訳を使用します:

```vue
<template>
  <div>
    <h1>{{ $t('welcome') }}</h1>
    <p>{{ $t('description', { name: 'World' }) }}</p>

    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" @click="$switchLocale(locale.code)">
        {{ locale.code }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useI18n } from '#imports'

const { $t, $getLocales, $switchLocale } = useI18n()
</script>
```
