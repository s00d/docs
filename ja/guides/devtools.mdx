# 🛠️ `nuxt-i18n-micro` の DevTools

## Vue DevTools(ブラウザ拡張機能)

開発時には、モジュールが `@vue/devtools-api` を通じて **Vue DevTools** のカスタムインスペクターとタイムラインを登録できます。これは、以下の Nuxt DevTools タブとは別のものです。

| ツール | 適した用途 |
|------|----------|
| **Vue DevTools** | ライブロケール、メモリ内翻訳キャッシュ、`$t` タイムライン(`debug: true`)、欠落キーイベント |
| **Nuxt DevTools タブ** | ディスク上の JSON ファイルの編集、設定概要、インポート/エクスポート |

vue-devtools プラグインは `nuxt dev` の間だけ登録されます(プロダクションビルドには含まれません)。メインプラグイン内の開発専用ブリッジ状態は、`import.meta.dev` のデッドコード除去によって取り除かれます。

Nuxt タブを保持したままブラウザ統合を無効にする方法:

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

詳細な `$t` タイムラインイベントを取得するには `debug: true` が必要です。

## 📖 Nuxt DevTools とは?

DevTools は、`nuxt-i18n-micro` モジュールにシームレスに統合された強力な開発アシスタントです。ローカライズと翻訳作業を管理するための直感的なインターフェースを提供し、ワークフローをより高速かつ効率的にします。利便性を重視する開発者のために設計されており、Nuxt DevTools はコーディングとランタイム管理の橋渡しをします。

## 🌟 `nuxt-i18n-micro` の DevTools の主な機能

### 1. **ロケール管理**

アプリケーション内のロケールを簡単に閲覧、選択、管理できます。単一言語でも複数言語でも、DevTools はすべてのローカライズ設定を扱うための一元的なハブを提供します。

### 2. **翻訳の編集**

統合された JSON エディターを通じて、翻訳ファイルを直接編集できます。これにより、外部ツールが不要となり、ワークフローを中断することなくリアルタイムで更新や変更が行えます。

### 3. **ファイルのインポートとエクスポート**

翻訳ファイルの管理プロセスを簡素化します:

- **エクスポート**: バックアップや外部利用のために翻訳を JSON ファイルとして保存します。
- **インポート**: 更新された翻訳ファイルをプロジェクトに読み込み、コンテンツを最新に保ちます。

### 4. **リアルタイムプレビュー**

変更を開発環境内で即座に確認できます。この機能により、公開前に翻訳や設定が正しいかを確認できます。

### 5. **シームレスな Nuxt 統合**

DevTools は `nuxt-i18n-micro` とネイティブに動作し、追加のセットアップなしにその機能を強化します。Nuxt のモジュール式で柔軟な構造を維持しながら、ローカライズのニーズに適応します。

## 🛠️ DevTools を使う理由

Nuxt DevTools は、ローカライズを必要とするプロジェクトに欠かせない追加機能です。以下の面で開発者を支援します:

- **時間の節約**: ファイル管理や形式検証などの反復作業を自動化します。
- **エラーの削減**: 翻訳を編集するための安全で直感的な環境を提供します。
- **コラボレーションの改善**: 開発者以外の人が翻訳を簡単に管理できるようにします。
- **ワークフローの合理化**: 複数のローカライズ作業を単一のインターフェースに集約します。

---

## 🚀 ローカライズをコントロール

`nuxt-i18n-micro` に統合された Nuxt DevTools により、多言語アプリケーションの管理が簡単かつ効率的になります。翻訳の微調整や新規ロケールの追加など、DevTools は洗練された使いやすい体験を提供するために必要なツールを備えています。
