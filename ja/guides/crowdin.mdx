# 🌐 Crowdin 統合ガイド

## 📖 はじめに

Crowdin をプロジェクトに統合すると、ローカライズと翻訳のプロセスが合理化され、複数の言語やプラットフォームにわたる翻訳管理が容易になります。このガイドでは、Crowdin をプロジェクトに設定する手順として、設定、ソースのアップロード、翻訳のダウンロードまでを順を追って説明します。

## 🔧 インストールとセットアップ

Crowdin を始めるには、Crowdin CLI をマシンにグローバルにインストールし、プロジェクトディレクトリ内で初期化する必要があります。

### 📦 Crowdin CLI のインストール

まず、npm を使って Crowdin CLI をグローバルにインストールします:

```bash
npm install -g @crowdin/cli
```

### 🛠 プロジェクトでの Crowdin の初期化

次のコマンドを実行して、プロジェクト内で Crowdin を初期化します:

```bash
crowdin init
```

このコマンドは、プロジェクト ID、API トークン、その他の設定内容を含むセットアップ手順を案内します。

## 🗂️ 設定ガイド

### 📄 Crowdin 設定ファイル(`crowdin.yml`)

Crowdin 設定ファイル(`crowdin.yml`)は、ソースファイルのマッピング方法と翻訳の配置先を定義します。以下は設定例です:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 主な設定パラメーター

- **`project_id`**: Crowdin プロジェクト ID。翻訳が管理される Crowdin 内のプロジェクトを識別します。
- **`api_token`**: 認証に使用する API トークン。このトークンには翻訳のアップロードとダウンロードに必要な権限があることを確認してください。
- **`base_path`**: ソースファイルのベースディレクトリを指定します。この例では、翻訳は `./locales` ディレクトリに保存されます。
- **`base_url`**: Crowdin API のベース URL。
- **`preserve_hierarchy`**: `true` に設定すると、Crowdin はプロジェクト内でソースファイルのフォルダー構造を維持します。

### 📂 ファイル設定

`files` セクションは、ソースファイルを翻訳ファイルの保存先パスにマッピングします。例えば:

- **ソースパス**: 元の翻訳ファイルの場所を定義します。
- **翻訳パス**: Crowdin に翻訳ファイルを保存する場所を指定します。`%two_letters_code%` のようなプレースホルダーを使うと、ファイルパスの言語コードを動的に設定できます。

## ⬆️ ソースファイルの Crowdin へのアップロード

Crowdin の設定が完了したら、次のコマンドでソースファイルをアップロードできます:

```bash
crowdin upload sources
```

このコマンドは、設定で指定したすべてのソースファイルを Crowdin にアップロードし、翻訳可能な状態にします。

## ⬇️ Crowdin からの翻訳のダウンロード

Crowdin での翻訳が完了または更新された後、次のコマンドでプロジェクトにダウンロードできます:

```bash
crowdin download
```

このコマンドは、Crowdin から最新の翻訳を取得し、設定ファイルで指定されたパスに従って保存します。

## ⚙️ ベストプラクティス

### 🔑 一貫したキー命名

混乱や重複を避けるため、翻訳キーはすべてのファイルで一貫させてください。

### 🧹 定期的なメンテナンス

未使用の翻訳キーを定期的に見直して整理し、ファイルを管理しやすい状態に保ちましょう。

### 🛠 アップロードとダウンロードの自動化

Crowdin CLI コマンドを CI/CD パイプラインに統合して、ソースファイルのアップロードと翻訳のダウンロードを自動化することで、翻訳を常に最新の状態に保てます。

このガイドに従うことで、Crowdin をプロジェクトへスムーズに統合し、効率的かつ整理された方法で国際化への取り組みを管理できます。
