# 🌐 Crowdin 統合ガイド

## 📖 はじめに

Crowdin をプロジェクトに統合すると、ローカライズと翻訳のプロセスが効率化され、複数の言語やプラットフォーム間で翻訳を管理しやすくなります。このガイドでは、設定、ソースのアップロード、翻訳のダウンロードなど、プロジェクトで Crowdin をセットアップする手順をステップバイステップで解説します。

## 🔧 インストールとセットアップ

Crowdin を使い始めるには、Crowdin CLI をマシンにグローバルインストールし、プロジェクトディレクトリで初期化する必要があります。

### 📦 Crowdin CLI のインストール

まず、npm で Crowdin CLI をグローバルインストールします。

```bash
npm install -g @crowdin/cli
```

### 🛠 プロジェクトでの Crowdin の初期化

次のコマンドを実行して、プロジェクトで Crowdin を初期化します。

```bash
crowdin init
```

このコマンドは、プロジェクト ID、API トークン、その他の設定詳細を含むセットアップ手順を案内します。

## 🗂️ 設定ガイド

### 📄 Crowdin 設定ファイル (`crowdin.yml`)

Crowdin 設定ファイル (`crowdin.yml`) は、ソースファイルのマッピング方法と翻訳の配置場所を定義します。以下は設定の例です。

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 主な設定パラメーター

- **`project_id`**: Crowdin のプロジェクト ID。翻訳が管理される Crowdin 内のプロジェクトを識別します。
- **`api_token`**: 認証に使用する API トークン。翻訳のアップロードとダウンロードに必要な権限を持っていることを確認してください。
- **`base_path`**: ソースファイルのベースディレクトリを指定します。この例では翻訳は `./locales` ディレクトリに格納されます。
- **`base_url`**: Crowdin API のベース URL。
- **`preserve_hierarchy`**: `true` に設定すると、Crowdin はプロジェクト内でソースファイルのフォルダー構造を維持します。

### 📂 ファイル設定

`files` セクションは、ソースファイルを翻訳が格納されるパスにマッピングします。例えば以下のようになります。

- **ソースパス**: 元の翻訳ファイルの場所を定義します。
- **翻訳パス**: Crowdin で翻訳ファイルが格納される場所を指定します。`%two_letters_code%` などのプレースホルダーは、ファイルパスに言語コードを動的に設定するために使われます。

## ⬆️ Crowdin へのソースファイルのアップロード

Crowdin の設定が完了したら、以下のコマンドでソースファイルをアップロードできます。

```bash
crowdin upload sources
```

このコマンドは、設定で指定されたすべてのソースファイルを Crowdin にアップロードし、翻訳可能な状態にします。

## ⬇️ Crowdin からの翻訳のダウンロード

Crowdin で翻訳が完了または更新されたら、以下のコマンドでプロジェクトにダウンロードできます。

```bash
crowdin download
```

このコマンドは Crowdin から最新の翻訳を取得し、設定ファイルで指定されたパスに従って保存します。

## ⚙️ ベストプラクティス

### 🔑 一貫したキー命名

混乱と重複を避けるため、すべてのファイルで翻訳キーが一貫していることを確認してください。

### 🧹 定期的なメンテナンス

未使用の翻訳キーを定期的に確認して整理し、ファイルを整理された管理しやすい状態に保ちます。

### 🛠 アップロードとダウンロードの自動化

Crowdin CLI コマンドを CI/CD パイプラインに統合し、ソースファイルのアップロードと翻訳のダウンロードを自動化して、翻訳を常に最新の状態に保ちます。

このガイドに従うことで、Crowdin をプロジェクトにシームレスに統合し、国際化の取り組みを効率的かつ整理された方法で管理できるようになります。
