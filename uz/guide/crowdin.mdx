[Crowdin](https://crowdin.com/) — tarjima platformasi: siz sukut bo'yicha lokal fayllarini yuklaysiz, tarjimonlar Crowdin'da ishlaydi va siz boshqa lokallarni qaytarib yuklab olasiz. Modul oddiy JSON fayllarni o'qiydi, shuning uchun Crowdin CLI'ga faqat `locales/` va `locales/pages/` ni to'g'ri moslaydigan `crowdin.yml` kerak. Modul sozlamalarida hech narsa o'zgarmaydi.

## crowdin.yml ni sozlash {#configure-crowdin-yml}

```yml
# crowdin.yml
project_id_env: CROWDIN_PROJECT_ID
api_token_env: CROWDIN_PERSONAL_TOKEN
base_path: ./locales
preserve_hierarchy: true

files:
  - source: /en.json
    translation: /%two_letters_code%.json
  - source: /pages/**/en.json
    translation: /pages/**/%two_letters_code%.json
```

- `en` — sizning sukut bo'yicha lokalingiz; uning fayllari manba hisoblanadi.
- `project_id_env` / `api_token_env` ID va tokenni muhit o'zgaruvchilaridan o'qiydi, shuning uchun hech qanday maxfiy ma'lumot commit qilinmaydi.
- `preserve_hierarchy: true` `pages/<page>/` papkalarini o'z holicha saqlaydi.
- Tarjima qilingan fayl nomi `nuxt.config.ts` dagi lokal `code` qiymatiga teng bo'lishi kerak. `%two_letters_code%` `de` kabi kodlarga mos keladi; `pt-BR` kabi kodlar uchun `%locale%` dan foydalaning yoki Crowdin kodlarini `languages_mapping` orqali o'zingiznikiga moslang.

## Yuklash va yuklab olish {#upload-and-download}

```bash
npm install -g @crowdin/cli

export CROWDIN_PROJECT_ID=123456
export CROWDIN_PERSONAL_TOKEN=...   # from Crowdin account settings

crowdin upload sources   # push locales/en.json and locales/pages/**/en.json
crowdin download         # write locales/de.json, locales/pages/**/de.json, ...
```

Fayllarni dolzarb saqlash uchun ikkalasini ham CI'da ishga tushiring. Yuklab olingan fayllar repozitoriyingizga qo'lda tahrirlangan fayllar kabi tushadi; keyingi build yoki dev qayta yuklanishi ularni oladi.

## Yuklashdan oldin {#before-uploading}

Tarjimonlar o'lik kalitlar ustida ishlamasligi uchun avval manbalarni tozalang: [`i18n-micro clean`](/uz/api/cli#clean) foydalanilmagan kalitlarni olib tashlaydi, [`i18n-micro check`](/uz/api/cli#check) yuklab olishdan keyin bo'shliqlar haqida xabar beradi. CLI'ning o'zida Crowdin integratsiyasi yo'q: qo'llab-quvvatlanadigan usul — shu sahifadagisi.
