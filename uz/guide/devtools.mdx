`nuxt dev` rejimida modul ikkita disk raskadka vositasini qo'shadi: tarjima fayllarini ko'rish va tahrirlash uchun Nuxt DevTools'dagi **i18n Micro** tabi hamda jonli locale va yuklangan lug'atlar uchun Vue DevTools inspektori. Ikkalasi ham faqat development rejimida mavjud va production yig'ishlariga hech narsa qo'shmaydi. Nuxt tabi uchun faqat Nuxt DevTools yoqilgan bo'lishi kifoya; Vue inspektori uchun esa Vue DevTools brauzer kengaytmasi ham kerak.

## Nuxt DevTools tabi {#nuxt-devtools-tab}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  devtools: { enabled: true }, // the tab is registered only when DevTools are on
})
```

Nuxt DevTools'ni oching (`Shift + Alt + D`) va **i18n Micro** ni tanlang. Tab quyidagilarni ko'rsatadi:

- har bir qatlamning `locales/` (ildiz va `pages/`) ostidagi barcha JSON fayllari, shuningdek `additionalTranslationDirs` dagi ildiz fayllari;
- har bir fayl uchun muharrir; **Save** faylni diskka qayta yozadi va dev server tarjimalarni qayta yuklaydi;
- faylni JSON sifatida **Export** / **Import** qilish hamda kalitlar soni va tarjima qamrovi ko'rsatilgan **Stats**;
- aniqlangan modul sozlamalarining konfiguratsiya ko'rinishi;
- **Translate** — yetishmayotgan kalitlarni tab sozlamalarida siz sozlagan mashina tarjimasi dvigateli bilan to'ldiradi.

Saqlash faqat tarjima kataloglaringiz ichidagi mavjud `.json` fayllarga yozadi. Fayl bir nechta qatlamda mavjud bo'lsa, loyihadagi nusxasi yoziladi.

## Vue DevTools inspektori {#vue-devtools-inspector}

Vue DevTools brauzer kengaytmasi mavjud bo'lsa, modul i18n inspektorini (joriy locale, marshrut bo'lagi, yuklangan kalitlar) hamda locale almashinuvlari, bo'laklar yuklanishi va yetishmayotgan kalitlar ko'rsatilgan vaqt shkalasini ro'yxatdan o'tkazadi.

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    debug: true, // also log every $t / $ts / $tc call on the timeline
    // vueDevtools: false, // turn the inspector off, keep the Nuxt tab
  },
})
```

[`vueDevtools`](/uz/api/module-options) standart holatda `true`. `debug: true` juda batafsil log chiqaradi; uni qisqa seanslar uchun qoldiring.

## Nuxt'dan tashqarida {#outside-nuxt}

Xuddi shu UI freymvork paketlari asosida qurilgan Vite ilovalari uchun [`@i18n-micro/devtools-ui`](/uz/integrations/devtools-ui-package) sifatida nashr etilgan; sozlash uchun o'sha sahifaga qarang.
