Ba'zi yo'llar hech qachon lokal prefiksi yoki lokal yo'naltirishini olmasligi kerak: admin bo'limi, health check, generatsiya qilingan feed. `excludePatterns` ularni belgilaydi, o'rnatilgan ro'yxat esa Nuxt ichki yo'llari va keng tarqalgan statik fayllarni allaqachon qamrab oladi. Istisno qilingan sahifa siz yozgan yo'lni aynan saqlaydi va baribir `$t` bilan render qilinadi.

## Yo'lni istisno qilish {#exclude-a-path}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    excludePatterns: [
      '/admin', // /admin and everything below it
      '/preview-*', // glob over the whole path
    ],
  },
})
```

Bu konfiguratsiya bilan `pages/admin/index.vue` faqat `/admin` manzilida javob beradi; `/de/admin` mavjud emas va `/admin` hech qachon `/de/admin` ga yo'naltirilmaydi.

## Pattern sintaksisi {#pattern-syntax}

Patternlar `app.baseURL` siz yo'lga nisbatan solishtiriladi:

| Pattern | Mos keladi | Mos kelmaydi |
| --- | --- | --- |
| `'/admin'` | `/admin`, `/admin/users` | `/administrator`, `/de/admin` |
| `'/preview-*'` | `/preview-1`, `/preview-a/b` | `/de/preview-1` |
| `'/file-?'` | `/file-a` | `/file-ab` |
| `/^\/v\d+\//` | `/v2/docs` | `/docs` |

`*` yoki `?` bo'lmagan satr yo'lga va uning ostidagi butun segmentlarga mos keladi. `*` (istalgan belgilar ketma-ketligi, slashlar ham kiradi) yoki `?` (bitta belgi) bilan u butun yo'lga mos kelishi kerak. Satrlarni har doim `/` bilan boshlang.

## Allaqachon nimalar istisno qilingan {#what-is-excluded-already}

Quyidagilar hech qanday konfiguratsiyasiz lokal marshrutlar yoki yo'naltirishlarni olmaydi:

- `/api` va `/_nuxt`, hamda ularning ostidagi hamma narsa;
- tarjimalar marshruti, standart bo'yicha `/_locales` ([`apiBaseUrl`](/uz/api/module-options#apibaseurl));
- `__` bilan boshlanadigan segmentga ega har qanday yo'l (`/__nuxt_content`, `/en/__og-image__`);
- `/sitemap*.xml`, `/robots.txt`, `/favicon.ico`, `/apple-touch-icon*.png`, `/manifest.json`, `/sw.js`, `/workbox-*.js`;
- oxirgi segmenti statik fayl kengaytmasi bilan tugaydigan har qanday yo'l: `xml txt ico json js css png jpg jpeg gif svg webp avif pdf wasm map mp4 webm mp3 zip gz woff woff2 ttf eot`. `/user/john.doe` kabi nuqtali sahifa sluglari va `.html` yo'llari sahifa bo'lib qoladi.

## Istisno nima qiladi {#what-an-exclusion-does}

- **Marshrutlar:** lokallashtirilgan variantlar generatsiya qilinmaydi; sahifa yozilganidek saqlanadi.
- **Yo'naltirishlar va 404 lar:** server yo'naltirish plagini va klient yo'naltirish middleware'i bu yo'lni o'tkazib yuboradi.
- **Prerender:** mos keladigan yo'llar prerender marshrutlari ro'yxatidan olib tashlanadi.

U i18n server middleware'ining so'rov uchun lokalni aniqlashini to'xtatmaydi va sahifaning tarjimalardan foydalanishiga to'sqinlik qilmaydi. Sahifani lokallashtirilgan holda saqlab, lekin SEO teglaridan chetda qoldirish uchun `disableMeta` dan foydalaning ([Sahifa konfiguratsiyasi](/uz/guide/per-component-translations#turn-off-seo-tags)). Bitta sahifani `nuxt.config.ts` dan yo'l bo'yicha lokallashtirilmagan holda saqlash uchun `globalLocaleRoutes: { '/admin': false }` ([Lokallashtirilgan yo'llar](/uz/guide/custom-locale-routes#in-nuxt-config)) marshrutlash uchun xuddi shu ishni qiladi.
