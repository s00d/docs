title: "Runtime’da qayta belgilash"
description: "Bitta build’ning har bir nusxasi uchun standart lokal, zaxira lokal yoki o‘chirilgan lokallarni muhit o‘zgaruvchilari yoki runtimeConfig orqali o‘zgartirish."
---

Runtime’da qayta belgilash bitta build artefaktiga qayta build qilmasdan har bir muhit yoki tenant uchun turli lokal sozlamalari bilan ishlash imkonini beradi. Siz standart lokalni, zaxira lokalni va qaysi lokallar o‘chirilganini o‘zgartirishingiz mumkin. Marshrutlash, qayta yo‘naltirishlar, render qilish va server yordamchilari qayta belgilangan qiymatlardan foydalanadi, serverda render qilingan sahifadagi brauzer ham shunday.

## Muhit o‘zgaruvchilari bilan qayta belgilash {#set-overrides-with-environment-variables}

```bash
NUXT_I18N_DEFAULT_LOCALE=de \
NUXT_I18N_FALLBACK_LOCALE=en \
NUXT_I18N_DISABLED_LOCALES=fr,it \
node .output/server/index.mjs
```

| O‘zgaruvchi | Taxallus |
| --- | --- |
| `NUXT_I18N_DEFAULT_LOCALE` | `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE` |
| `NUXT_I18N_FALLBACK_LOCALE` | `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE` |
| `NUXT_I18N_DISABLED_LOCALES` (vergul bilan ajratilgan) | `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES` |

Server ularni ishga tushishda bir marta o‘qiydi; o‘zgarishni qo‘llash uchun qayta ishga tushiring. Serverda render qilingan sahifada brauzer aniqlangan qiymatlarni serverdan oladi. `ssr: false` bilan server render bo‘lmaydi va brauzerda muhit yo‘q: u yerda faqat `runtimeConfig.public.i18nRuntime` qo‘llaniladi va brauzer quyidagi ogohlantirishlarni logga yozadi.

## runtimeConfig’da qayta belgilash {#set-overrides-in-runtimeconfig}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

`runtimeConfig.public.i18nRuntime` da o‘rnatilgan qiymat xuddi shu maydon uchun `NUXT_I18N_*` o‘zgaruvchisidan ustun turadi.

Buni build vaqtidagi `DEFAULT_LOCALE` o‘zgaruvchisi bilan adashtirmang: u build paytida `defaultLocale` ni almashtiradi va runtime qo‘llab-quvvatlashini talab qilmaydi.

## Nima o‘zgarishi mumkin va nima o‘zgarmaydi {#what-can-and-cannot-change}

| Sozlama | Runtime’da |
| --- | --- |
| `defaultLocale` | `prefix` va `no_prefix` da ha. `prefix_except_default` va `prefix_and_default` da u build paytida qat’iy belgilanadi (uning sahifalari prefikssiz marshrutlar); qayta belgilash ogohlantirish bilan e’tiborga olinmaydi. |
| `fallbackLocale` | Ha. |
| `disabledLocales` | Build paytida o‘chirilgan lokallarga qo‘shiladi; hech qachon birortasini qayta yoqmaydi. `prefix_except_default` / `prefix_and_default` da build standarti o‘chirilishi mumkin emas. |
| `strategy` | Yo‘q. Runtime strategiyasi ogohlantirish bilan e’tiborga olinmaydi; har bir strategiya uchun bitta artefakt build qiling. |

Noto‘g‘ri qiymatlar hech qachon ilovani buzmaydi. Har bir holat har bir server jarayoni uchun bitta ogohlantirish yozadi:

- barcha lokallarni o‘chirish e’tiborga olinmaydi;
- yoqilmagan `defaultLocale` birinchi yoqilgan lokalga qaytadi;
- yoqilmagan `fallbackLocale` build qiymati yoqilgan bo‘lsa uni saqlaydi, aks holda zaxira bo‘lmaydi.

## Amaldagi konfiguratsiyani o‘qish {#read-the-effective-config}

```vue
<script setup lang="ts">
const { $getI18nConfig } = useNuxtApp()
const config = $getI18nConfig() // build config with overrides applied
</script>
```

Uni faqat o‘qish uchun deb hisoblang: serverda u har bir so‘rov tomonidan bo‘lishiladi va ishlab chiqish rejimida muzlatilgan; brauzerdagi nusxa muzlatilmagan. Konfiguratsiyani `#build/i18n.strategy.mjs` dan import qilish qayta belgilashlarsiz build qiymatlarini beradi.

## O‘chirilgan lokallar va statik fayllar {#disabled-locales-and-static-files}

Runtime’da o‘chirilgan lokal o‘z marshrutlari va payload marshrutida 404 qaytaradi, lekin uning payload fayllari hamon `.output/public/_locales/` da bo‘ladi va statik fayl serveri ularni qaytaradi. Agar bu fayllarga kirish imkoni bo‘lmasligi kerak bo‘lsa, lokalni build vaqtida `disabled: true` bilan o‘chiring.
