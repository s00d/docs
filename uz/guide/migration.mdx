Bu sahifa `@nuxtjs/i18n` ilovasini nuxt-i18n-micro ga moslashtiradi: opsiyalar, yordamchilar va fayl tuzilishi. Mavjud ilovada modulni almashtirganda undan foydalaning. URL’laringiz saqlanadi (strategiya nomlari bir xil) va tarjimalar har bir sahifa uchun JSON fayllarga ko‘chiriladi.

<Tip>

**nuxt-i18n-micro ning o‘zini yangilayapsizmi?** — [Yangilash](/uz/guide/upgrade) ga qarang.

</Tip>

## Modulni almashtirish {#swap-the-module}

```bash
npm uninstall @nuxtjs/i18n
npm install nuxt-i18n-micro
```

```ts
// nuxt.config.ts — before
export default defineNuxtConfig({
  modules: ['@nuxtjs/i18n'],
  i18n: {
    locales: [
      { code: 'en', language: 'en-US', file: 'en.json' },
      { code: 'de', language: 'de-DE', file: 'de.json' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    langDir: 'locales',
    detectBrowserLanguage: { useCookie: true, cookieKey: 'i18n_redirected', redirectOn: 'root' },
  },
})
```

```ts
// nuxt.config.ts — after
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    translationDir: 'locales',
    localeCookie: 'i18n_redirected',
    autoDetectPath: '/',
  },
})
```

## Opsiyalar {#options}

| `@nuxtjs/i18n` | nuxt-i18n-micro |
| --- | --- |
| `locales[].code` | `locales[].code` |
| `locales[].language` (v9 dan oldin `iso`) | `locales[].iso` |
| `locales[].name` | `locales[].displayName` |
| `locales[].dir` | `locales[].dir` |
| `locales[].domain` | `locales[].baseUrl` (sxemasi bilan origin) |
| `locales[].domainDefault` | `locales[].baseDefault` |
| `differentDomains`, `multiDomainLocales` | kerak emas: `baseUrl` ning o‘zi xost bo‘yicha yo‘naltiradi, [Qatlamlar va domenlar](/uz/guide/layers#multiple-domains) ga qarang |
| `locales[].file` / `files`, `langDir`, `lazy` | `translationDir`; fayllar nomi bo‘yicha topiladi va har doim har bir sahifa uchun yuklanadi |
| `defaultLocale`, `strategy` | bir xil nomlar, bir xil to‘rtta qiymat |
| `baseUrl` | `metaBaseUrl` |
| `customRoutes: 'config'` + `pages` | `globalLocaleRoutes` |
| `detectBrowserLanguage: false` | `redirects: false` (qayta yo‘naltirishlarsiz) yoki `autoDetectLanguage: false` (sarlavhani e’tiborsiz qoldirish) |
| `detectBrowserLanguage.useCookie` / `cookieKey` | `localeCookie: '<name>'` (`null` cookie’ni o‘chiradi) |
| `detectBrowserLanguage.redirectOn: 'root'` | `autoDetectPath: '/'` (standart) |
| `detectBrowserLanguage.redirectOn: 'no prefix'` | `autoDetectPath: 'no_prefix'` |
| `detectBrowserLanguage.redirectOn: 'all'` | `autoDetectPath: '*'` |
| `vueI18n` konfiguratsiya fayli (`fallbackLocale`, `numberFormats`, `datetimeFormats`) | `i18n` ichida `fallbackLocale`, `numberFormats`, `datetimeFormats` |

`alwaysRedirect` yo‘q: cookie o‘rnatilgan bo‘lsa, `/` har bir tashrifda unga amal qiladi. To‘liq ro‘yxat — [Modul opsiyalari](/uz/api/module-options); aniqlash qoidalari [Lokalni aniqlash](/uz/guide/locale-detection) sahifasida.

## Yordamchilar va composable’lar {#helpers-and-composables}

| `@nuxtjs/i18n` / vue-i18n | nuxt-i18n-micro (shablon / `useI18n()`) |
| --- | --- |
| `const { t } = useI18n()` | `const { t } = useI18n()`, shablonlarda `$t` |
| `t('key', count)`, `tc` | `$tc('key', count)` |
| `te('key')` | `$has('key')` |
| `n(value, 'currency')`, `d(date, 'short')` | `$tn(value, 'currency')`, `$td(date, 'short')` |
| — | `$tdr(date)`: nisbiy vaqt ("3 kundan keyin") |
| `locale.value` | `$getLocale()` |
| `locales.value` | `$getLocales()` |
| `setLocale('de')` | `$switchLocale('de')` |
| `useLocalePath()('about')` | `$localePath({ name: 'about' })` |
| `useLocaleRoute()` | `$localeRoute()` |
| `useSwitchLocalePath()('de')` | `$switchLocalePath('de')` |
| `useSetI18nParams()` | `$setI18nRouteParams()` |
| `useLocaleHead()` | `meta: true` bilan avtomatik; maxsus head’lar uchun [`useLocaleHead`](/uz/composables/useLocaleHead) |
| `defineI18nRoute({ paths: { de: '/ueber-uns' }, locales: [...] })` | `$defineI18nRoute({ localeRoutes: { de: '/ueber-uns' }, locales: [...] })` |
| `<NuxtLinkLocale to="about">` | `<i18n-link :to="{ name: 'about' }">` |
| `<i18n-t>` | `<i18n-t>` (slotlar `{name}` o‘rinbosarlarini to‘ldiradi) |
| server marshrutlarida `$i18n` | `useTranslationServerMiddleware(event)`, [Server marshrutlari va API](/uz/guide/server-side-translations) ga qarang |

`useI18n()` avtomatik import qilinadi. `$defineI18nRoute` o‘zining `$` belgisini saqlashi kerak: build aynan shu chaqiruvni o‘qiydi. Barcha yordamchilar: [Metodlar](/uz/api/methods).

## Tarjima fayllari {#translation-files}

Har bir lokal uchun bitta katta faylning kalitlarini ildiz fayl va har bir sahifa uchun bitta faylga ko‘chiring:

```text
locales/
├── en.json              # keys used on many pages (nav, footer)
├── de.json
└── pages/
    ├── index/en.json    # keys of pages/index.vue
    └── about/en.json    # keys of pages/about.vue
```

Hammasini ildiz fayllarda saqlash ham ishlaydi va bu eng tez birinchi qadam. Ularni bo‘lmaguningizcha `disablePageLocales: true` ni o‘rnating. [Tarjima fayllari](/uz/guide/translations) ga qarang.

### Xabar sintaksisi {#message-syntax}

| vue-i18n | nuxt-i18n-micro |
| --- | --- |
| `{name}` nomlangan interpolatsiya | xuddi shunday |
| `car \| cars` (2 shakl: 1 → birinchisi) | shakllar 0 dan boshlab son bo‘yicha tanlanadi: `no cars \| one car \| {count} cars` deb yozing |
| `@:other.key` bog‘langan xabarlar | qo‘llab-quvvatlanmaydi: matnni takrorlang yoki kodda tuzing |
| `@.upper:` modifikatorlar | qo‘llab-quvvatlanmaydi: kodda formatlang yoki `<i18n-t>` dan foydalaning |
| `{'@'}` literal ekranlashlar | kerak emas: faqat `{word}` tokenlari almashtiriladi |
| JS/TS xabar fayllari | faqat JSON |

Ko‘plik qoidasini [`plural`](/uz/api/module-options#plural) opsiyasi bilan almashtirish mumkin.

## Almashtirishdan keyin tekshirish {#check-after-the-switch}

- Sizda bo‘lgan har bir URL hamon ishlaydi; strategiya nomlari mos keladi, maxsus yo‘llar `globalLocaleRoutes` yoki `$defineI18nRoute` ga ko‘chadi.
- `hreflang`, canonical va `og:locale` `meta: true` bilan tayyor holda chiqadi; qo‘lda yozilganlarini olib tashlang.
- JSON tahlil xatosi fayl yo‘lini logga yozadi; yo‘q kalit dev rejimida brauzer konsolida ogohlantirish yozadi.
