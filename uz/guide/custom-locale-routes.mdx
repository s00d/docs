Sukut bo'yicha har bir lokal sahifani bir xil yo'lda taqdim etadi: `/en/about`, `/de/about`. Lokallashtirilgan yo'llar sahifa fayli o'zgarmagan holda har bir lokalga o'z so'zlaridan foydalanishga imkon beradi, masalan, `/de/ueber-uns`. Ularni sahifaning o'zida `$defineI18nRoute` bilan yoki bir vaqtning o'zida ko'plab sahifalar uchun `nuxt.config.ts` da o'rnatasiz.

## Sahifada {#in-the-page}

```vue
<!-- pages/about.vue -->
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  localeRoutes: {
    de: '/ueber-uns',
    fr: '/a-propos',
  },
})
</script>
```

`prefix_except_default` va `defaultLocale: 'en'` bilan sahifa `/about`, `/de/ueber-uns` va `/fr/a-propos` manzillarida javob beradi. Yozuvi bo'lmagan lokal sukut bo'yicha yo'lni saqlaydi. Yo'llarni lokal kodisiz yozing: prefiksni [strategiya](/uz/guide/strategy) qo'shadi, lokal kodi bilan boshlanadigan yo'l esa ogohlantirish yozadi. Chaqiruv yana nimalarni qabul qilishi [Sahifa konfiguratsiyasi](/uz/guide/per-component-translations) sahifasida keltirilgan.

## nuxt.config da {#in-nuxt-config}

[`globalLocaleRoutes`](/uz/api/module-options#globallocaleroutes) xuddi shu ishni istalgan sahifa uchun bajaradi, kalit sifatida uning yo'li (yoki boshida slash bo'lmasa, route nomi) ishlatiladi:

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    globalLocaleRoutes: {
      '/about': { de: '/ueber-uns' },
      '/about/team': { de: '/ueber-uns/team' },
      '/admin': false, // not localized: one /admin route, no locale prefix
    },
  },
})
```

Sahifa `localeRoutes` ni o'rnatsa va `globalLocaleRoutes` da xuddi shu kalit bo'lsa, konfiguratsiyadagi yozuv ustun keladi.

## Dinamik parametrlar {#dynamic-params}

Parametrlarni istalgan Nuxt shaklida yozing: `[id]`, `[[page]]`, `[...slug]` yoki `:id()`. Parametr nomlari sahifa fayliga mos kelishi kerak.

```ts
// pages/products/[...slug].vue
$defineI18nRoute({
  localeRoutes: {
    en: '/our-products/[...slug]',
    de: '/unsere-produkte/[...slug]',
  },
})
```

Ichma-ich sahifalar absolyut bola yo'lini (`/ueber-uns/team`) yoki ota-sahifaning lokallashtirilgan yo'liga nisbatan yo'lni (`team`) oladi.

## Lokallashtirilgan sahifalarga havola berish {#linking-to-localized-pages}

Route nomini yoki oddiy yo'lni uzatishingizdan qat'i nazar, havolalar maqsadli lokalning lokallashtirilgan yo'liga aylanadi:

```vue
<template>
  <i18n-link :to="{ name: 'about' }">About</i18n-link>
  <i18n-link to="/about">About</i18n-link>
  <!-- de: both render /de/ueber-uns -->
  <NuxtLink :to="$localePath('/about', 'de')">Deutsch</NuxtLink>
</template>
```

Route nomlari fayl yo'lidan olinadi (`pages/about/team.vue` — `about-team`), agar siz `definePageMeta({ name })` bilan nom o'rnatmagan bo'lsangiz.

## Lokalga xos slug'lar {#per-locale-slugs}

Slug'ning o'zi har bir lokalda farq qilganda (`/our-products/red-shoe` va `/de/unsere-produkte/roter-schuh`), ma'lumotlar yuklangach `$setI18nRouteParams` orqali til almashtirgichga qaysi parametrlardan foydalanishni ayting:

```vue
<script setup lang="ts">
const { $setI18nRouteParams } = useNuxtApp()
const route = useRoute()

const { data: product } = await useFetch(`/api/products/${route.params.slug}`)

if (product.value) {
  $setI18nRouteParams({
    en: { slug: product.value.slugEn },
    de: { slug: product.value.slugDe },
  })
}
</script>
```

Shundan so'ng `$switchLocalePath('de')` va `<i18n-switcher>` `/de/unsere-produkte/roter-schuh` ga havola beradi. Kalitlar — lokal kodlari, qiymatlar — nomi bo'yicha parametrlar (sahifa faylidagidek).

Layout'dagi almashtirgich sahifaning asinxron setup'i bu yerga yetib kelishidan oldin render qilinadi, shuning uchun render tugaganda modul `<i18n-switcher>` havolalarini `app.vue` da ham, sahifada ham qayta yozadi. Shunda server HTML'i, JavaScript'siz tashrif buyuruvchi va birinchi mijoz renderi bir-biriga mos keladi. Buning uchun parametrlarni SSR paytida o'rnating: `lazy` yoki `server: false` bilan havolalar faqat gidratatsiyadan keyin o'zgaradi. Nuxt'ning SSR streaming'i HTML'ni parametrlar ma'lum bo'lishidan oldin yuboradi, shuning uchun u ishlatilganda birinchi HTML'dagi havolalar URL'ning o'z parametrlarini saqlaydi.

Faqat almashtirgichning o'z havolalari qayta yoziladi. Qo'lda yozilgan `$switchLocalePath` havolasi parametrlar o'rnatilgandan keyin render qilinishi kerak, shuning uchun uni parametrlarni o'rnatadigan sahifaga, shuningdek `await` dan keyin joylashtiring. Layout'da u birinchi render qilinadi: uning server HTML'i URL parametrlarini saqlaydi va gidratatsiya nomuvofiqlik haqida ogohlantiradi. U yerda ko'rinish uchun slotlari va `custom*Style` prop'lari bilan `<i18n-switcher>` dan foydalaning.

Parametrlar ularni o'rnatgan sahifaga tegishli:

- Boshqa yo'lga navigatsiya yakunlanganda ular tashlab yuboriladi, shuning uchun har bir sahifa o'zinikini o'rnatadi. Bekor qilingan navigatsiya ularni joyida qoldiradi.
- `$setI18nRouteParams` ni `setup` ichida `useNuxtApp()` yoki `useI18n()` dan oling, hatto uni keyinroq `useAsyncData` handler'ida chaqirsangiz ham. U yerda olingan funksiya o'z sahifasini biladi: agar tashrif buyuruvchi chiqib ketgan bo'lsa, kechikkan chaqiruv hech narsa qilmaydi.
- `keepalive` bilan sahifa tashrif buyuruvchi qaytganda o'zi o'rnatgan parametrlarni qaytarib oladi. `useI18nHead` ham xuddi shunday ishlaydi.

## pages:extend da qo'shilgan route'lar {#routes-added-in-pagesextend}

`pages:extend` hook'ida qo'shadigan route'laringizda `$defineI18nRoute` ni o'qish uchun sahifa fayli yo'q va ularning bir nechtasi ko'pincha bitta o'rovchi komponentni baham ko'radi. `name` siz qo'shilgan route Nuxt uning yo'liga beradigan nomni oladi (`/a/:id()` — `a-id`), shuning uchun til havolalari unga yetib boradi, agar boshqa route'da allaqachon shu nom bo'lmasa; bunday holda unga aniq `name` bering. Bitta ro'yxat yuriting va uni `@i18n-micro/utils/split-locale-routes` dagi `splitLocaleRoutes` yordamida sahifalarga hamda route nomi bo'yicha kalitlangan `globalLocaleRoutes` ga ajrating (paketni bog'liqliklaringizga qo'shing):

```ts
// nuxt.config.ts
import { splitLocaleRoutes } from '@i18n-micro/utils/split-locale-routes'

const dynamic = splitLocaleRoutes([
  { name: 'products-tag', path: '/products/:tag', file: '~/pages/_dynamic.vue', paths: { de: '/produkte/:tag' } },
  { name: 'internal', path: '/internal', file: '~/pages/_dynamic.vue', paths: false }, // not localized
])

export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  hooks: {
    'pages:extend'(pages) {
      pages.push(...dynamic.pages)
    },
  },
  i18n: {
    globalLocaleRoutes: dynamic.globalLocaleRoutes,
  },
})
```

Lokallashtirilgan yo'llarni `route.meta` ga qo'ymang: ular mijozdagi route jadvaliga tushib qoladi.
