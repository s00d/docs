`strategy` sozlamasi lokal URL'da paydo bo'lishini va qaysi lokallar uchun ekanligini hal qiladi. Uni URL'larni e'lon qilishdan oldin bir marta tanlang: keyinroq o'zgartirish har bir havolani o'zgartiradi. Shundan so'ng modul build vaqtida lokallashtirilgan marshrutlarni generatsiya qiladi, `$localePath`, `<i18n-link>` va almashtirgich esa ularni o'qiydi.

## To'rtta strategiya {#the-four-strategies}

![Har bir strategiya ostida en (standart) va de dagi /about sahifasi; xuddi shu URL'lar quyidagi matnda keltirilgan](/images/diagrams/strategies.svg)

**Tip** `Strategies` · **Standart** `'prefix_except_default'`

Lokal prefikslari uchun URL marshrutlash strategiyasi.

- `'no_prefix'` — URL'da lokal yo'q; lokal cookie'da saqlanadi.
- `'prefix_except_default'` — standartdan tashqari barcha lokallarga prefiks qo'shiladi.
- `'prefix'` — har doim prefiks, standart lokal ham.
- `'prefix_and_default'` — `prefix` kabi, lekin standart lokal prefikssiz ham ochiladi.

`defaultLocale: 'en'` va `en`, `de` lokallari bilan `about` sahifasi uchun URL'lar:

| Strategiya | Inglizcha | Nemischa | Xizmat qilinmaydi |
| --- | --- | --- | --- |
| `prefix_except_default` (standart) | `/about` | `/de/about` | `/en` va `/en/about` 404 bo'ladi |
| `prefix` | `/en/about` | `/de/about` | `/about` prefiksli URL'ga yo'naltiriladi |
| `prefix_and_default` | `/about` va `/en/about` | `/de/about` | — |
| `no_prefix` | `/about` | `/about` | lokal URL'da yo'q |

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix',
  },
})
```

Strategiya build vaqtida qat'iy belgilanadi: uni runtime'da qayta belgilash ogohlantirish bilan e'tiborsiz qoldiriladi ([Runtime qayta belgilashlar](/uz/guide/runtime-overrides)).

## Qaysi birini tanlash kerak {#which-one-to-choose}

- **`prefix_except_default`**: ko'pchilik saytlar. Mavjud prefikssiz URL'lar standart til uchun ishlashda davom etadi.
- **`prefix`**: barcha tillar teng; `/` har doim prefiksli bosh sahifaga olib boradi.
- **`prefix_and_default`**: sizga `/en/...` va prefikssiz URL'larning ikkalasi ham ishlashi kerak, masalan biridan ikkinchisiga o'tish davomida. Prefikssiz URL'lar hech qachon yo'naltirilmaydi.
- **`no_prefix`**: login ortidagi ilovalar yoki har bir til uchun bitta sahifaga bitta URL. Lokal cookie'dan yoki `?locale=` dan olinadi. Qidiruv tizimlari har bir URL'da bitta tilni ko'radi, shuning uchun `hreflang` muqobillari chiqarilmaydi.

URL uchun lokal qanday tanlanishi va tashrif buyuruvchi qachon yo'naltirilishi [Lokalni aniqlash](/uz/guide/locale-detection) sahifasida yozilgan.

## Generatsiya qilingan marshrutlar {#generated-routes}

Build vaqtida har bir sahifa o'z strategiyasi talab qiladigan marshrut yozuvlarini oladi. Har bir yozuv `meta.i18n = { name, locales }` ni o'z ichiga oladi: u ko'rsatadigan sahifa va u xizmat qiladigan lokallar. Havolalar, almashtirishlar va yo'naltirishlarning barchasi shu yozuvlar asosida hal qilinadi, shuning uchun modul beradigan URL har doim router xizmat qiladigan URL bo'ladi.

Sahifa yo'lini bo'lishadigan lokallar bitta yozuvni bo'lishadi: `/:locale(de|fr)/about`. O'z yo'liga ega lokal `localized-<page>-<locale>` nomli alohida yozuv oladi:

```ts
// nuxt.config.ts: German has its own path for the about page
i18n: {
  globalLocaleRoutes: { about: { de: '/ueber-uns' } },
}
// prefix_except_default, locales en (default), de, fr:
// about                 /about
// localized-about       /:locale(fr)/about
// localized-about-de    /:locale(de)/ueber-uns
```

Maxsus yo'llar, sahifa bo'yicha lokal ro'yxatlari va sahifani lokalizatsiyadan istisno qilish [Lokallashtirilgan yo'llar](/uz/guide/custom-locale-routes) va [Sahifa konfiguratsiyasi](/uz/guide/per-component-translations) sahifalarida yozilgan. `localized-` prefiksi — [`localizedRouteNamePrefix`](/uz/api/module-options#localizedroutenameprefix).

<Warning>

**Marshrut nomlari generatsiya qilinadi** — `router.push({ name })` da `localized-…` nomlarini qattiq yozmang. Sahifaning o'z nomini `$localeRoute` yoki `<i18n-link>` ga bering; ular to'g'ri yozuvni tanlaydi.

</Warning>

## Lokaldagi sahifaga havola berish {#linking-to-a-page-in-a-locale}

```vue
<script setup lang="ts">
const { localePath, localeRoute, switchLocalePath } = useI18n()

localePath({ name: 'about' }) // '/de/ueber-uns' while the page is German
localePath({ name: 'about' }, 'en') // '/about'
localePath('/about', 'de') // '/de/ueber-uns': a path is read as the page it shows
localeRoute({ name: 'products-id', params: { id: '42' } }, 'de') // resolved route: name, params, fullPath
switchLocalePath('fr') // the current page in French
</script>

<template>
  <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
  <NuxtLink :to="$switchLocalePath('de')">Deutsch</NuxtLink>
</template>
```

- Nomlangan marshrutlar ham, yo'llar ham ishlaydi. Yo'l generatsiya qilingan marshrutlar bilan solishtiriladi, shuning uchun uning istalgan lokaldagi shakli qabul qilinadi.
- Sahifaga xizmat qilmaydigan lokal ([Sahifa konfiguratsiyasi](/uz/guide/per-component-translations) dagi `locales` ga qarang) mavjud bo'lmagan sahifa o'rniga o'sha lokalning bosh sahifasiga havola beradi.
- Lokal bo'yicha parametrlar (tarjima qilingan slug) `$setI18nRouteParams` orqali o'tadi, [Lokallashtirilgan yo'llar](/uz/guide/custom-locale-routes) ga qarang.

Signaturalar [Metodlar](/uz/api/methods) sahifasida.

## `no_prefix` tafsilotlari {#no_prefix-details}

- `no_prefix` da [`localeCookie`](/uz/api/module-options#localecookie) standart bo'yicha `'user-locale'` bo'ladi, shuning uchun tanlov sahifa qayta yuklanganda saqlanib qoladi.
- `$switchLocale('de')` nemischa lug'atni yuklaydi va joriy tarix yozuvini almashtiradi; URL o'zgarmaydi.
- Lokal bo'yicha maxsus yo'llar baribir ishlaydi: `globalLocaleRoutes: { about: { de: '/ueber-uns' } }` bilan nemis o'quvchilar `/ueber-uns` ni oladi. Bu URL tashrif buyuruvchi nimani afzal ko'rishidan qat'i nazar har doim nemischa render qilinadi, ba'zi lokallar bilan cheklangan sahifa esa ulardan birida render qilinadi. Bir nechta lokal bo'lishadigan yo'l (`en` va `de` ikkalasi ham `/page/:id` da) afzallik ulardan biri bo'lsa, o'shani render qiladi. Afzallikning o'zi saqlanib qoladi: keyingi sahifa unga qaytadi.
- [`noPrefixRedirect: true`](/uz/api/module-options#noprefixredirect) standart lokalda maxsus yo'lga ega sahifaning asl yo'lini yo'naltiradi: tashrif buyuruvchi lokalining maxsus yo'liga, aks holda standart lokalnikiga (`en` da `/about-us` bo'lsa `/about` → `/about-us`, `de` cookie bilan → `/ueber-uns`). O'z maxsus yo'li bo'lmagan lokal asl yo'lda qoladi va o'sha yerda render qilinadi. Parametrli sahifalar yo'naltirilmaydi.

## `pages/` siz ilovalar {#apps-without-pages/}

`pages: false` bilan lokallashtiriladigan sahifa marshrutlari yo'q. Faqat ildiz tarjima fayllaridan foydalaning (`disablePageLocales: true`); aniqlash, cookie va `$switchLocale` baribir ishlaydi. Repozitoriydagi `test/fixtures/basic` ning `pages-false` varianti ishlaydigan sozlamadir.
