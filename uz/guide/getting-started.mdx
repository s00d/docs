Bu sahifa Nuxt ilovasini i18n'siz holatdan til almashtirgichli tarjima qilingan sahifagacha olib boradi. U sizga loyiha boshida bir marta kerak bo'ladi. Natijada sizda lokallashtirilgan URL'lar (`/about`, `/de/about`), har bir lokal va sahifa uchun bitta JSON fayl hamda shablonlaringizda `$t` bo'ladi.

## O'rnatish {#install}

Modulga Nuxt 3.18 yoki undan yangiroq (Nuxt 4 ham ishlaydi) va Node 20 yoki undan yangiroq kerak.

<CodeGroup>

```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>

## Lokallarni sozlash {#configure-the-locales}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', displayName: 'English' },
      { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
      { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
    ],
    defaultLocale: 'en',
  },
})
```

Birinchi ilova uchun kerak bo'ladigan barcha sozlama shu. Standart qiymatlar sizga quyidagilarni beradi:

- `strategy: 'prefix_except_default'`: standart lokalda prefiks yo'q (`/about`), boshqalarida bor (`/de/about`). [Marshrutlash strategiyalari](/uz/guide/strategy) sahifasiga qarang.
- `translationDir: 'locales'`: tarjima fayllari loyiha ildizidagi `locales/` papkasida joylashadi, Nuxt 4 `app/` tuzilmasida ham.
- `meta: true`: `hreflang`, canonical va `og:locale` teglari, shuningdek `<html>` elementida `lang` va `dir`. [SEO](/uz/guide/seo) sahifasiga qarang.
- `/`ni ochgan tashrif buyuruvchi brauzeri so'ragan tilga (`Accept-Language`) yo'naltiriladi. [Lokalni aniqlash](/uz/guide/locale-detection) sahifasiga qarang.

`iso` — SEO teglarida ishlatiladigan til tegi; `code` — URL'da ko'rinadigan qiymat. Barcha opsiyalar [Modul opsiyalari](/uz/api/module-options) sahifasida keltirilgan.

## Tarjima fayllarini qo'shish {#add-translation-files}

Dev serverni `nuxt dev` bilan ishga tushiring. Nuxt sahifalarni aniqlaganda, modul fayli bo'lmagan har bir lokal va sahifa uchun bo'sh `{}` fayl yaratadi (buni [`disableWatcher`](/uz/api/module-options#disablewatcher) bilan o'chirishingiz mumkin):

```text
locales/
├── en.json            # root: keys every page can use
├── de.json
├── fr.json
└── pages/
    ├── index/         # pages/index.vue
    │   ├── en.json
    │   ├── de.json
    │   └── fr.json
    └── about/         # pages/about.vue
        ├── en.json
        ├── de.json
        └── fr.json
```

Ildiz faylini va sahifa faylini to'ldiring:

```json
// locales/en.json
{ "nav": { "home": "Home", "about": "About" } }
```

```json
// locales/pages/index/en.json
{ "welcome": "Welcome, {name}!", "items": "no items | one item | {count} items" }
```

Sahifa ildiz kalitlarini ham, o'z kalitlarini ham ko'radi; to'qnashuv bo'lganda o'z fayli ustun keladi. Papka nomlari marshrut nomiga mos keladi (`pages/articles/[id].vue` — bu `locales/pages/articles-id/`). Tuzilma, zaxira tillar va yuklash [Tarjima fayllari](/uz/guide/translations) sahifasida yoritilgan.

## Sahifada `$t`dan foydalanish {#use-t-on-a-page}

```vue
<!-- pages/index.vue -->
<script setup lang="ts">
const { t, tc, getLocale } = useI18n()

const title = t('nav.home') // 'Home'
</script>

<template>
  <h1>{{ $t('welcome', { name: 'Ada' }) }}</h1>
  <!-- Welcome, Ada! -->
  <p>{{ $tc('items', 3) }}</p>
  <!-- 3 items -->
  <p>{{ getLocale() }}</p>
  <!-- en -->
</template>
```

- Shablonlarda har bir yordamchi `$` bilan mavjud (`$t`, `$tc`, `$localePath`, …).
- `<script setup>` ichida `useI18n()` xuddi shu yordamchilarni `$` bilan ham, usiz ham qaytaradi (`t` va `$t` — bitta funksiya). U avtomatik import qilinadi.
- `{name}` o'rinbosarlari parametrlar obyektidan to'ldiriladi. Ko'plik shakllari `|` bilan ajratiladi; son shaklni tanlaydi (0, 1, so'ngra undan kattalari uchun oxirgisi).

Barcha yordamchilar [Metodlar](/uz/api/methods) sahifasida keltirilgan.

## Sahifalar orasida havola qilish va lokalni almashtirish {#link-between-pages-and-switch-locale}

```vue
<!-- components/AppHeader.vue -->
<template>
  <nav>
    <i18n-link :to="{ name: 'index' }">{{ $t('nav.home') }}</i18n-link>
    <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
    <i18n-switcher />
  </nav>
</template>
```

- [`<i18n-link>`](/uz/components/i18n-link) — joriy lokaldagi sahifaga ishora qiluvchi `NuxtLink`: `/de` sahifasida about havolasi `/de/about`ga olib boradi.
- [`<i18n-switcher>`](/uz/components/i18n-switcher) — yoqilgan lokallarning ochiluvchi ro'yxati; u tashrif buyuruvchini o'sha sahifada qoldiradi.
- O'z tugmalaringiz uchun `$switchLocale('de')`ni chaqiring — u joriy sahifaning nemischa versiyasiga o'tadi va tanlovni eslab qoladi. Oddiy `NuxtLink` uchun `$localePath({ name: 'about' })` yoki `$switchLocalePath('de')`dan foydalaning.

## Tekshirish {#check-it}

`nuxt dev`ni ishga tushiring va oching:

| URL | Ko'rsatadi |
| --- | --- |
| `/` | Inglizcha bosh sahifa (yoki brauzeringiz nemis tilini afzal ko'rsa, `/de`ga yo'naltirish) |
| `/de` | Nemischa bosh sahifa |
| `/de/about` | Nemischa about sahifasi |
| `/en/about` | 404: `prefix_except_default`da standart lokalda prefiks yo'q |

JSON fayllaridagi o'zgarishlar ochiq sahifada qayta yuklashsiz qo'llaniladi.
