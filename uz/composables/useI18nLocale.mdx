---
title: "useI18nLocale"
description: "useI18nLocale locale holati va locale cookie'sini o'qiydi hamda yozadi — locale'ni maxsus aniqlash uchun kirish nuqtasi."
---

`useI18nLocale()` ilova tanlagan locale'ga kirishni beradi: `i18n-locale` state'i va locale cookie'si. Uni locale'ni o'zi aniqlaydigan plaginda (domen, foydalanuvchi profili, header) `useState('i18n-locale')` yoki cookie'ni qo'lda yozish o'rniga ishlating. Uning yaroqlilik tekshiruvlari yoqilgan locale'lardan, jumladan runtime override'lardan foydalanadi.

## Signatura {#signature}

```ts
useI18nLocale(): { getEffectiveLocale: (route: unknown, getLocaleFromRoute: GetLocaleFromRoute) => string; getLocale: () => string | null; getPreferredLocale: () => string | null; hashCookie: CookieRef; isValidLocale: (locale: string | null | undefined) => locale is string; locale: any; localeCookie: CookieRef; resolveInitialLocale: (options: ResolveInitialLocaleOptions) => string; setLocale: (locale: string | null) => void; syncLocale: (locale: string | null) => void; validLocales: string[] }
```

i18n locale boshqaruvi uchun markazlashgan kirish nuqtasi.
useState('i18n-locale'), locale cookie'si va sinxronlash utilitalarini birlashtiradi.

## Qaytariladigan qiymatlar {#returned-values}

| A'zo | Turi | Tavsif |
| --- | --- | --- |
| `locale` | `Ref<string \| null>` | `useState('i18n-locale')` ref'i. |
| `localeCookie` | `Ref<string \| null>` | [`localeCookie`](/uz/api/module-options#localecookie) cookie'si; parametr `null` bo'lganda oddiy `{ value: null }`. |
| `hashCookie` | `Ref<string \| null>` | Hash marshrutlashda `hash-locale` cookie'si; aks holda `{ value: null }`. |
| `validLocales` | `string[]` | Yoqilgan locale'lar kodlari. |
| `setLocale(locale)` | `(locale: string \| null) => void` | State va cookie'larni yozadi. Tekshirmaydi va tarjimalarni yuklamaydi. |
| `syncLocale(locale)` | `(locale: string \| null) => void` | Faqat cookie'larni yozadi. |
| `getLocale()` | `() => string \| null` | Avval state, so'ng afzallik cookie'si (hash marshrutlashda hash cookie). Tekshirilmaydi. |
| `getPreferredLocale()` | `() => string \| null` | State va afzallik cookie'sidan birinchi **yaroqli**si yoki `null`. |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string` | Hash marshrutlashda o'rnatilgan bo'lsa state; aks holda `getLocaleFromRoute(route)`. |
| `resolveInitialLocale(options)` | `(options: ResolveInitialLocaleOptions) => string` | `options.urlLocale`, so'ng yaroqli state, so'ng `options.serverLocale`, so'ng marshrut locale'i. State yaroqsiz bo'lsa natijani state'ga saqlaydi; klientda cookie'ni ham yozadi. |
| `isValidLocale(locale)` | `(locale) => locale is string` | `locale` `validLocales` ichida bormi. |

Cookie'lar bir yil amal qiladi, `path: '/'` va `sameSite: 'lax'` bilan.

## Misol {#example}

```ts
// plugins/locale-from-domain.server.ts
export default defineNuxtPlugin({
  name: 'locale-from-domain',
  enforce: 'pre',
  setup() {
    const { setLocale, isValidLocale } = useI18nLocale()
    const host = useRequestURL().hostname // e.g. de.example.com
    const code = host.split('.')[0]
    if (isValidLocale(code)) setLocale(code)
  },
})
```

Modulning loader plagini ishga tushganda state'ni o'qiydi, shuning uchun uni o'rnatadigan plagin birinchi ishlashi kerak (`enforce: 'pre'`). State URL, cookie va `Accept-Language` bilan qanday raqobatlashadi: [Locale'ni aniqlash](/uz/guide/locale-detection). To'liq qo'llanma: [Maxsus aniqlash](/uz/guide/custom-auto-detect).

`setLocale()` ekrandagi tarjimalarni almashtirmaydi. Joriy sahifaning locale'ini o'zgartirish uchun [`$switchLocale()`](/uz/api/methods#$switchlocale) ni chaqiring.
