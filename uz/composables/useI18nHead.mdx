`useI18nHead()` modul generatsiya qiladigan SEO teglarini faqat bitta sahifa uchun o'zgartiradi. Sahifa routerdan yaxshiroq bilgan hollarda undan foydalaning: faqat ba'zi lokallarda mavjud bo'lgan CMS maqolasi, API'dan kelgan canonical URL, qo'shimcha `og:` teglari. Siz generatsiya qilingan teglarni ustiga qayta belgilashlaringiz birlashtirilgan holda olasiz.

## Signatura {#signature}

```ts
useI18nHead(input?: MaybeRefOrGetter<I18nHeadInput | null>): { pageHead: any; resetPageHead: () => void }
```

i18n SEO head teglari uchun sahifa darajasidagi qayta belgilashlarni ro'yxatdan o'tkazadi.
`02.meta` plagini tomonidan `useLocaleHead` natijasi ustiga birlashtiriladi.

Qiymatlar `$t` / `t` dan kelganda getter (`() => ({ … })`) afzal, shunda ular
lokal o'zgarganda qayta hisoblanadi. Oddiy obyekt bir marta baholanadi va muzlatilgan holda qoladi.

| Parametr | Tip | Tavsif |
| --- | --- | --- |
| `input` *(ixtiyoriy)* | `MaybeRefOrGetter<I18nHeadInput \| null>` |  |

U [`meta: true`](/uz/api/module-options#meta) (sukut bo'yicha) bilan ishlaydi: modulning meta plagini har bir head renderida kiritilgan qiymatlarni [`useLocaleHead`](/uz/composables/useLocaleHead) natijasi ustiga birlashtiradi. `meta: false` bo'lganda uni hech narsa o'qimaydi.

Route nomi o'zgarganda qayta belgilash tiklanadi. `disableMeta` ni o'rnatgan sahifa hech qanday i18n tegini, jumladan qayta belgilashlarni ham olmaydi.

## Kirish qiymatlari {#input}

`I18nHeadInput` (`@i18n-micro/types` dan):

| Kalit | Tip | Ta'siri |
| --- | --- | --- |
| `htmlAttrs` | `Record<string, string>` | `<html>` atributlariga (`lang`, `dir`) birlashtiriladi. |
| `meta` | `I18nHeadMeta[]` | Generatsiya qilingan teglardan keyin qo'shiladi; bir xil `id`, `property` yoki `name` ga ega tegni almashtiradi. |
| `link` | `I18nHeadLink[]` | Generatsiya qilingan havolalardan keyin qo'shiladi; bir xil `id` yoki `rel` + `hreflang` ga ega havolani almashtiradi. |
| `replace.canonical` | `string \| false` | Canonical `href` ni almashtiradi yoki havolani olib tashlaydi. |
| `replace.hreflang` | `I18nHeadLink[] \| false` | **Barcha** `rel="alternate"` havolalarini, `x-default` ni ham qo'shib, almashtiradi yoki olib tashlaydi. |
| `replace.xDefault` | `I18nHeadLink \| false` | `x-default` havolasini almashtiradi yoki olib tashlaydi. |
| `replace.ogLocale` | `string \| false` | `og:locale` ni almashtiradi yoki olib tashlaydi. |
| `replace.ogUrl` | `string \| false` | `og:url` ni almashtiradi yoki olib tashlaydi. |
| `replace.ogAlternates` | `string[] \| false` | `og:locale:alternate` ni shu lokal kodlaridan (`og` / `iso` orqali) qayta quradi, joriy lokalni, noma'lum kodlarni va `og` yoki `iso` qiymati bo'lmagan kodlarni o'tkazib yuboradi, yoki ularni olib tashlaydi. |
| `disable` | `I18nHeadDisableGroup[]` | Generatsiya qilingan guruhlarni olib tashlaydi: `'hreflang'` (`x-default` emas), `'x-default'`, `'canonical'`, `'og'` (`og:locale` + `og:url`), `'og-alternates'`, `'html'`. |

Qo'llash tartibi: `disable`, keyin `replace`, keyin `htmlAttrs`, `meta`, `link`.

## Misol {#example}

Faqat ba'zi lokallarda mavjud bo'lgan, muqobil URL'lari API'dan keladigan maqola:

```vue
<script setup lang="ts">
const route = useRoute()
const { t } = useI18n()
const { data: article } = await useFetch<{ title: string; urls: Record<string, string> }>(`/api/articles/${route.params.slug}`)

useI18nHead(() => {
  if (!article.value) return null
  const codes = Object.keys(article.value.urls)
  return {
    meta: [{ property: 'og:title', content: article.value.title || t('blog.title') }],
    replace: {
      hreflang: codes.map((code) => ({ rel: 'alternate', hreflang: code, href: article.value!.urls[code]! })),
      ogAlternates: codes,
    },
  }
})
</script>
```

Qiymatlar `t()` yoki asinxron ma'lumotlardan kelganda, bu yerdagidek getter uzating: u lokal o'zgarganda qayta ishga tushadi. Oddiy obyekt bir marta o'qiladi.
