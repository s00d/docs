---
title: "useI18n"
description: "useI18n runtime yordamchilarini (`$t`, `$tc`, `$localePath`, …) `$` prefiksli va prefikssiz oddiy obyekt sifatida qaytaradi."
---

`useI18n()` modulning runtime yordamchilarini oddiy obyekt sifatida qaytaradi. Uni `useNuxtApp()` ga murojaat qilish o'rniga `<script setup>`, composable'lar va plaginlarda ishlating. Har bir yordamchi o'zining `$` nomi va prefikssiz taxallusi ostida keladi: `t` va `$t` bir xil funksiya.

## Signatura {#signature}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Barcha runtime yordamchilari, oddiy obyekt sifatida.

Plagin `$t`, `$tc` va hokazo sifatida inject qiladigan aynan o'sha funksiyalar, ham dollar
prefiksli nom, ham prefikssiz taxallus ostida mavjud — shuning uchun `const { t } = useI18n()` ham,
`const { $t } = useI18n()` ham ishlaydi.

**Qaytaradi** — [metodlar ma'lumotnomasida](/uz/api/methods) tasvirlangan yordamchilar

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

Qaytarilgan obyekt [`PluginsInjections`](/uz/api/methods) ning barcha yordamchilarini o'z ichiga oladi. Ularning har biri [Yordamchilar](/uz/api/methods) sahifasida hujjatlashtirilgan.

## Misol {#example}

```vue
<script setup lang="ts">
const { t, tc, localePath, switchLocale, getLocale } = useI18n()

const title = computed(() => t('page.title'))
</script>

<template>
  <h1>{{ title }}</h1>
  <p>{{ tc('items', 3) }}</p>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
  <button @click="switchLocale(getLocale() === 'en' ? 'de' : 'en')">{{ t('nav.switch') }}</button>
</template>
```

## Tipda mavjud emas {#not-in-the-type}

`$defineI18nRoute` faqat `useNuxtApp()` da tiplangan:

```ts
const { $defineI18nRoute } = useNuxtApp()
```
