---
title: "useLocaleHead"
description: "useLocaleHead i18n SEO teglarini (lang, dir, canonical, hreflang, og:locale) useHead ga uzatiladigan obyekt sifatida quradi."
---

`useLocaleHead()` joriy route uchun i18n head teglarini quradi: `<html>` dagi `lang` va `dir`, canonical havola, `x-default` bilan `hreflang` muqobillari, `og:url`, `og:locale` va `og:locale:alternate`. Uni [`meta: false`](/uz/api/module-options#meta) o'rnatib, `useHead` ni o'zingiz boshqarganingizda ishlating; `meta: true` bo'lganda modul bu teglarni allaqachon ro'yxatdan o'tkazadi, sahifa bo'yicha o'zgarishlar esa [`useI18nHead`](/uz/composables/useI18nHead) orqali amalga oshiriladi.

## Signatura {#signature}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { build: () => LocaleHead; metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }, LocaleHead | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

Joriy route uchun SEO head teglari: har bir lokal uchun `hreflang` muqobillari hamda
`x-default`, canonical havola, `og:locale` va `<html>` dagi `lang`/`dir`.

Faqat `meta` o'chirilganda yoki sukut bo'yicha qiymatlarni moslash kerak bo'lganda kerak — `meta: true` bo'lganda
modul aynan shu teglarni o'zi ro'yxatdan o'tkazadi.

| Parametr | Tip | Tavsif |
| --- | --- | --- |
| `options` | `UseLocaleHeadOptions` |  |

**Qaytaradi** — `metaObject`, `useHead` ga uzatishga tayyor head obyektini saqlaydigan ref; `updateMeta` uni yangilaydi; `build` head obyektini joriy route'dan hisoblaydi (getter ichida o'qilganda reaktiv, masalan, `useHead(() => build())`)

```ts
const { metaObject } = useLocaleHead({ addSeoAttributes: true })
useHead(metaObject)
```

## Parametrlar {#options}

| Parametr | Sukut bo'yicha | Tavsif |
| --- | --- | --- |
| `addDirAttribute` | `true` | `<html>` dagi `dir` ni lokalning `dir` qiymatidan o'rnatadi (u bo'lmasa `'auto'`). |
| `identifierAttribute` | `'id'` | Har bir tegni kalitlaydigan atribut (`i18n-can`, `i18n-og`, `i18n-alternate-<hreflang>`, …), shunda yangilanishlar teglarni qo'shish o'rniga almashtiradi. |
| `addSeoAttributes` | `true` | Canonical, `hreflang` va `og:` teglarini chiqaradi. `false` faqat `htmlAttrs` ni qoldiradi. |
| `baseUrl` | `'/'` | Har bir URL'ga qo'shiladigan origin. Nisbiy URL'lar uchun `'/'` ni qoldiring; absolyut URL'lar uchun `'https://example.com'` ni uzating. |
| `autoUpdate` | `true` | Route yoki `i18n-locale` holati o'zgarganda `metaObject` ni qayta quradi. |

## U nimalarni chiqaradi {#what-it-emits}

- Mos kelmagan route'da (404) yoki faol lokal uchun `disableMeta` o'rnatilgan route'da hech narsa.
- Canonical va `og:url`: `$switchLocalePath(<active locale>)`, query [`canonicalQueryWhitelist`](/uz/api/module-options#canonicalquerywhitelist) gacha qisqartiriladi, [`trailingSlash`](/uz/api/module-options#trailingslash) qo'llaniladi.
- `hreflang`: sahifa mavjud bo'lgan har bir yoqilgan lokal uchun bitta havola, `hreflang = iso || code`, `seo: false` bo'lgan lokallar o'tkazib yuboriladi; `hreflangBaseLanguage: true` bo'lganda tilning birinchi mintaqaviy lokali o'zining sof til tegini ham chiqaradi. `no_prefix` ostida hech biri chiqmaydi.
- `x-default`: sukut bo'yicha lokalning URL'i; strategiya `no_prefix` bo'lgan, sukut bo'yicha lokalda `seo: false` bo'lgan yoki sahifa unda mavjud bo'lmagan hollar bundan mustasno.
- `og:locale` / `og:locale:alternate`: lokalning `og` qiymatidan yoki uning konvertatsiya qilingan `iso` qiymatidan (`en-US` → `en_US`); ikkalasi ham ishlamasa, dev ogohlantirishi bilan o'tkazib yuboriladi.

## Misol {#example}

```ts
// app.vue, with i18n.meta: false
const { metaObject } = useLocaleHead({ baseUrl: 'https://example.com' })
useHead(metaObject)
```

`build()` xuddi shu obyektni ref'siz qaytaradi: `useHead(() => build())` watcher'siz reaktiv bo'lib qoladi.
