---

`<i18n-switcher>` faol locale ko'rsatilgan tugmani va barcha yoqilgan locale'lar, jumladan faol locale'ning ochiladigan ro'yxatini render qiladi. Tayyor til menyusi uchun undan foydalaning; boshqacha markup kerak bo'lganda o'zingiznikini [`$getLocales`](/uz/api/methods#$getlocales) va [`$switchLocalePath`](/uz/api/methods#$switchlocalepath) asosida yarating. Har bir element joriy sahifaning shu locale'dagi versiyasiga havola qiladi.

## Props va slotlar {#props-and-slots}

| Prop | Turi | Standart | Tavsif |
| --- | --- | --- | --- |
| `customLabels` | `Record<string, string>` | `() => ({})` | Har bir locale kodi uchun ko'rsatiladigan nom, locale konfiguratsiyasidagi `displayName` ni qayta belgilaydi. |
| `customWrapperStyle` | `CSSProperties` | `() => ({})` | Tashqi o'ram uchun inline uslub. |
| `customButtonStyle` | `CSSProperties` | `() => ({})` | Ochiladigan ro'yxatni ochuvchi tugma uchun inline uslub. |
| `customDropdownStyle` | `CSSProperties` | `() => ({})` | Ochiladigan panel uchun inline uslub. |
| `customItemStyle` | `CSSProperties` | `() => ({})` | Ochiladigan ro'yxatdagi har bir element uchun inline uslub. |
| `customLinkStyle` | `CSSProperties` | `() => ({})` | Element ichidagi havola uchun inline uslub. |
| `customActiveLinkStyle` | `CSSProperties` | `() => ({})` | Hozirgi faol locale havolasi uchun inline uslub. |
| `customDisabledLinkStyle` | `CSSProperties` | `() => ({})` | Konfiguratsiyada `disabled: true` bo'lgan *joriy* locale tugmasi uchun inline uslub. |
| `customIconStyle` | `CSSProperties` | `() => ({})` | Tugmadagi strelka belgisi uchun inline uslub. |

### Slotlar {#slots}

| Slot | Bog'lanishlar | Tavsif |
| --- | --- | --- |
| `before-button` | — | Ochiladigan ro'yxatni ochuvchi tugmadan oldingi kontent. |
| `before-selected-locale` | — | Tugma ichidagi faol locale yorlig'idan oldingi kontent. |
| `after-selected-locale` | — | Tugma ichidagi faol locale yorlig'idan keyingi kontent. |
| `before-dropdown` | — | Tugma va ochiladigan panel orasidagi kontent. |
| `before-dropdown-items` | — | Ochiladigan ro'yxatning yuqori qismidagi, locale'lar ro'yxatidan yuqoridagi kontent. |
| `before-item` | `locale` | Har bir locale elementidan oldingi kontent. |
| `before-link-content` | `locale` | Havola ichidagi locale yorlig'idan oldingi kontent. |
| `after-link-content` | `locale` | Havola ichidagi locale yorlig'idan keyingi kontent. |
| `after-item` | `locale` | Har bir locale elementidan keyingi kontent. |
| `after-dropdown-items` | — | Ochiladigan ro'yxatning pastki qismidagi, locale'lar ro'yxatidan pastdagi kontent. |
| `after-dropdown` | — | Ochiladigan paneldan keyingi kontent. |

## Xatti-harakati {#behaviour}

- `disabled: true` bo'lmagan barcha locale'larni, jumladan faol locale'ni sanab o'tadi.
- Har bir element `$switchLocalePath(code)` ga olib boradigan `<a>`. Yo'l `app.baseURL` ostida aniqlanadi; boshqa domendagi locale `baseUrl` absolyut holda qoladi. Unda `hreflang` va `lang` `iso || code` ga o'rnatilgan, locale'da `dir` bo'lsa u ham, joriy locale'da `aria-current="page"` hamda `switcher-locale-<code>` klassi mavjud. Bosish `$switchLocale(code)` ni chaqiradi va ochiladigan ro'yxatni yopadi; modifikator tugmasi bilan bosilganda bu brauzerga qoldiriladi.
- Ro'yxat server HTML'ida yashirin holda qoladi, shuning uchun qidiruv robotlari havolalarni ko'radi. Escape yoki tashqariga bosish uni yopadi.
- Yorliq: `customLabels[code]`, keyin locale'ning `displayName` qiymati, keyin kod (dev ogohlantirishi bilan).
- Uslublar: kichik inline standartlar (chegarali oq tugma va panel, faol element qalin va ko'k). Har bir `custom*Style` prop o'z qismining standart uslubidan keyin qo'llaniladi. Tugmada `i18n-switcher-button` va `language-switcher` klasslari, o'ramda `i18n-switcher-wrapper`, ro'yxatda `i18n-switcher-dropdown` bor. Joylashuvlar mantiqiy CSS xususiyatlaridan foydalanadi, shuning uchun `dir="rtl"` ishlaydi.

## Misol {#example}

```vue
<template>
  <i18n-switcher
    :custom-labels="{ en: 'English', de: 'Deutsch' }"
    :custom-button-style="{ borderRadius: '4px' }"
  >
    <template #before-link-content="{ locale }">
      <img :src="`/flags/${locale.code}.svg`" alt="" width="16" />
    </template>
  </i18n-switcher>
</template>
```
