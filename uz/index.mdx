Nuxt I18n Micro — katta loyihalar uchun mo‘ljallangan Nuxt 3 va 4 uchun yengil, yuqori unumdor i18n moduli. U `@nuxtjs/i18n` kabi an’anaviy i18n yechimlariga nisbatan build vaqtini, xotira sarfini va bundle hajmini past darajada saqlaydi.

Lokallashtirilgan marshrutlar build vaqtida `@i18n-micro/route-strategy` tomonidan yaratiladi va runtime’da `@i18n-micro/path-strategy` tomonidan aniqlanadi, shuning uchun havolalar, almashtirgich, `hreflang` va qayta yo‘naltirishlar router bilan mos keladi. Tarjimalar faqat JSON formatida bo‘lib, umumiy ildiz fayllar va dev server siz uchun yaratadigan har bir sahifa fayllari o‘rtasida bo‘linadi, HMR esa o‘rnatilgan.

<CodeGroup>

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>
