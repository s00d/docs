# 🌐 Crowdin integratsiyasi qo'llanmasi

## 📖 Kirish

Crowdin'ni loyihangizga integratsiya qilish lokalizatsiya va tarjima jarayonini soddalashtiradi, bir nechta tillar va platformalar bo'yicha tarjimalarni boshqarishni osonlashtiradi. Ushbu qo'llanma Crowdin'ni loyihangizga sozlash, konfiguratsiya, manba fayllarini yuklash va tarjimalarni yuklab olishni o'z ichiga olgan bosqichma-bosqich yo'nalishni taqdim etadi.

## 🔧 O'rnatish va sozlash

Crowdin bilan boshlash uchun kompyuteringizga Crowdin CLI'ni global tarzda o'rnatishingiz va uni loyiha katalogingizda ishga tushirishingiz kerak.

### 📦 Crowdin CLI'ni o'rnatish

Avval Crowdin CLI'ni npm yordamida global tarzda o'rnating:

```bash
npm install -g @crowdin/cli
```

### 🛠 Loyihangizda Crowdin'ni ishga tushirish

Loyihangizda Crowdin'ni ishga tushirish uchun:

```bash
crowdin init
```

Ushbu buyruq sozlash jarayoni davomida sizga yo'l ko'rsatadi, jumladan loyiha ID, API token va boshqa konfiguratsiya tafsilotlarini o'rnatish.

## 🗂️ Konfiguratsiya qo'llanmasi

### 📄 Crowdin konfiguratsiya fayli (`crowdin.yml`)

Crowdin konfiguratsiya fayli (`crowdin.yml`) manba fayllaringiz qanday xaritalanishini va tarjimalar qayerga joylashtirilishi kerakligini aniqlaydi. Quyida konfiguratsiya namunasi keltirilgan:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Asosiy konfiguratsiya parametrlari

- **`project_id`**: Sizning Crowdin loyiha ID. Bu Crowdin ichida tarjimalar boshqariladigan loyihani aniqlaydi.
- **`api_token`**: Autentifikatsiya uchun ishlatiladigan API token. Ushbu token tarjimalarni yuklash va yuklab olish uchun to'g'ri ruxsatlarga ega ekaniga ishonch hosil qiling.
- **`base_path`**: Manba fayllar uchun asosiy katalogni belgilaydi. Ushbu misolda tarjimalar `./locales` katalogida saqlanadi.
- **`base_url`**: Crowdin API'sining asosiy URL manzili.
- **`preserve_hierarchy`**: `true` ga o'rnatilganda, Crowdin loyihada manba fayllaringizning papka tuzilishini saqlaydi.

### 📂 Fayllar konfiguratsiyasi

`files` bo'limi manba fayllaringizni tarjimalar saqlanadigan yo'llarga xaritalaydi. Masalan:

- **Source Path**: Asl tarjima fayllarining joylashuvini aniqlaydi.
- **Translation Path**: Tarjima qilingan fayllar Crowdin'da qayerda saqlanishini belgilaydi. `%two_letters_code%` kabi placeholder'lar fayl yo'llarida til kodini dinamik ravishda o'rnatish uchun ishlatiladi.

## ⬆️ Manba fayllarini Crowdin'ga yuklash

Crowdin konfiguratsiyangiz sozlangandan so'ng, quyidagi buyruq yordamida manba fayllaringizni yuklashingiz mumkin:

```bash
crowdin upload sources
```

Bu buyruq konfiguratsiyangizda ko'rsatilgan barcha manba fayllarini Crowdin'ga yuklab, ularni tarjima uchun mavjud qiladi.

## ⬇️ Crowdin'dan tarjimalarni yuklab olish

Crowdin'da tarjimalar tugallangan yoki yangilangandan so'ng, quyidagi buyruq bilan ularni loyihangizga yuklab olishingiz mumkin:

```bash
crowdin download
```

Bu buyruq Crowdin'dan eng so'nggi tarjimalarni oladi va ularni konfiguratsiya faylingizda ko'rsatilgan yo'llarga muvofiq saqlaydi.

## ⚙️ Eng yaxshi amaliyotlar

### 🔑 Kalitlar nomlashda izchillik

Chalkashlik va takrorlanishning oldini olish uchun barcha fayllarda tarjima kalitlari izchil bo'lishini ta'minlang.

### 🧹 Muntazam texnik xizmat

Fayllaringizni tartibli va boshqarish oson holatda saqlash uchun foydalanilmagan tarjima kalitlarini vaqti-vaqti bilan ko'rib chiqing va tozalang.

### 🛠 Yuklash va yuklab olishlarni avtomatlashtirish

Crowdin CLI buyruqlarini CI/CD pipeline'ingizga integratsiya qiling, shunda manba fayllarini yuklash va tarjimalarni yuklab olish avtomatlashtiriladi va tarjimalaringiz doim yangilanib turadi.

Ushbu qo'llanmaga rioya qilib, Crowdin'ni loyihangizga muammosiz integratsiya qilishingiz va xalqarolashtirish ishlaringizni boshqarish uchun samarali va tartibli yondashuvni ta'minlashingiz mumkin.
