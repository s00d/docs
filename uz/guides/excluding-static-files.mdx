# Statik fayllarni i18n yo'naltirishdan chiqarish

## Umumiy ko'rinish

Standart holatda, nuxt-i18n-micro umumiy statik fayllarni i18n yo'naltirish qayta ishlashidan avtomatik chiqarib tashlaydi. Biroq, muayyan yo'llarning i18n tizimi tomonidan qayta ishlanishining oldini olish uchun maxsus istisno naqshlarini ham sozlashingiz mumkin.

## O'rnatilgan istisnolar

Modul avtomatik ravishda quyidagi fayl turlari va naqshlarni chiqarib tashlaydi:

- **Sitemap'lar**: `/sitemap*.xml`, `/sitemap-en.xml` va h.k.
- **SEO fayllari**: `/robots.txt`, `/favicon.ico`
- **PWA fayllari**: `/manifest.json`, `/sw.js`, `/workbox-*.js`
- **Statik aktivlar**: `.xml`, `.txt`, `.ico`, `.json`, `.js`, `.css`, `.png`, `.jpg`, `.jpeg`, `.gif`, `.svg`, `.woff`, `.woff2`, `.ttf`, `.eot` kabi kengaytmalarga ega fayllar
- **Nuxt'ning ichki yo'llari**: `__` bilan boshlanadigan har qanday yo'l (masalan, `/__nuxt/`)

## Maxsus istisno naqshlari

`excludePatterns` opsiyasidan foydalanib maxsus istisno naqshlarini aniqlashingiz mumkin:

```typescript
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],

  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'it', iso: 'it-IT' },
    ],
    defaultLocale: 'en',

    // Custom exclusion patterns
    excludePatterns: [
      // String patterns (exact match or prefix)
      '/api/health',
      '/admin',

      // String patterns with wildcards
      '/api/*',
      '/admin/**',

      // Regular expressions
      /^\/api\/v\d+\//,
      /\.(pdf|doc|docx)$/,
    ],
  },
})
```

## Naqsh turlari

### Satr naqshlari

- **Aniq moslik**: `'/api/health'` — aynan `/api/health` ga mos keladi
- **Prefiks moslik**: `'/admin'` — `/admin` va `/admin/dashboard` ga mos keladi
- **Wildcard'lar**: `'/api/*'` — `/api/users` ga mos keladi, lekin `/api/users/123` ga mos kelmaydi
- **Chuqur wildcard'lar**: `'/admin/**'` — `/admin/users` va `/admin/users/123` ga mos keladi

### Muntazam ifodalar

Murakkab naqsh mosligi uchun RegExp obyektlaridan foydalaning:

```typescript
excludePatterns: [
  /^\/api\/v\d+\//, // API versioned routes
  /\.(pdf|doc|docx)$/, // Document files
  /^\/static\//, // Static directory
  /^\/[a-z]{2}\/api\//, // Localized API routes
]
```

## Foydalanish holatlari

### SEO fayllari

```typescript
excludePatterns: ['/sitemap.xml', '/sitemap-*.xml', '/robots.txt', '/favicon.ico']
```

### API yo'nalishlari

```typescript
excludePatterns: ['/api/**', '/graphql', '/webhook/**']
```

### Admin panellari

```typescript
excludePatterns: ['/admin', '/admin/**', '/dashboard']
```

### Statik aktivlar

```typescript
excludePatterns: ['/assets/**', '/static/**', '/uploads/**']
```

## Qanday ishlaydi

1. **Server Middleware**: Istisno naqshlarini tekshirish uchun avval Nitro middleware ishga tushadi
2. **Sahifani qayta ishlash**: Sahifani hal qilish davomida chiqarib tashlangan yo'llar o'tkazib yuboriladi
3. **Catch-all yo'nalish**: Fallback yo'nalish qayta ishlashdan oldin istisnolarni tekshiradi
4. **Prerender qilish**: Chiqarib tashlangan yo'llar prerender qilingan yo'nalishlarga kiritilmaydi

## Ishlashga ta'siri

- Istisno tekshiruvlari optimallashtirilgan va so'rov hayotiy siklining boshlarida ishga tushadi
- O'rnatilgan naqshlar samarali regex moslikdan foydalanadi
- Maxsus naqshlar keshlanadi va qayta ishlatiladi
- Chiqarib tashlangan yo'llar uchun minimal ishlash yuki

## Muammolarni bartaraf etish

### Statik fayllar hali ham to'sib qolinmoqda

1. **Naqsh sintaksisini tekshiring**: Naqshlaringiz aniq yo'l tuzilishiga mos kelishiga ishonch hosil qiling
2. **Murakkab naqshlar uchun regex ishlatilsin**: Satr wildcard'larining cheklovlari bor
3. **Naqshlarni test qiling**: Haqiqiy so'rov yo'lini tekshirish uchun brauzer dev vositalaridan foydalaning
4. **Tartibni tekshiring**: Istisno naqshlari boshqa i18n konfiguratsiyasidan oldin aniqlanganligiga ishonch hosil qiling

### Naqsh ishlamayapti

```typescript
// ❌ Wrong - this won't work
excludePatterns: ['sitemap.xml']

// ✅ Correct - include leading slash
excludePatterns: ['/sitemap.xml']

// ✅ Better - use regex for flexibility
excludePatterns: [/^\/sitemap.*\.xml$/]
```

### Debug rejimi

Istisno qayta ishlashini ko'rish uchun debug rejimini yoqing:

```typescript
i18n: {
  debug: true,
  excludePatterns: ['/api/**']
}
```

Bu istisno qarorlarini konsolga log qiladi.

## Vaqtincha yechimlardan ko'chirish

Agar siz route qoidalari yoki middleware kabi vaqtincha yechimlardan foydalangan bo'lsangiz, endi ularni `excludePatterns` bilan almashtirishingiz mumkin:

```typescript
// ❌ Old workaround
export default defineNuxtConfig({
  routeRules: {
    '/sitemap*.xml': { headers: { 'content-type': 'application/xml' } },
  },
})

// ✅ New approach
export default defineNuxtConfig({
  i18n: {
    excludePatterns: ['/sitemap*.xml'],
  },
})
```

Yangi yondashuv ishonchli va yo'naltirish tizimining bir nechta darajalarida ishlaydi.
