# 🧪 `Nuxt I18n Micro` modulini test qilish

## 📖 Test qilishga kirish

`Nuxt I18n Micro` modulini test qilish ilovangizning lokalizatsiya xususiyatlari kutilganidek ishlashini ta'minlash uchun juda muhim. Ushbu hujjat test muhitini sozlash, vitest uchun mock konfiguratsiyalarni yaratish va komponentlaringiz uchun testlar yozish bo'yicha sizga yo'l ko'rsatadi. Amaliy misol uchun [GitHub'dagi misol loyihaga](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/test-utils/example) murojaat qilishingiz mumkin.

Ushbu repository o'zining test to'plamlarini qanday ishga tushirishi haqida — `unit` / `integration` / `e2e` Vitest loyihalari, har bir strategiya bo'yicha fayllar (`test/strategies-*.test.ts`) va regressiyalarni generatsiya qilish — [Yo'naltirish strategiyalarini test qilish](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/testing-strategies.md) ga qarang.

## 🛠️ Test muhitini sozlash

### 1. `@i18n-micro/test-utils` ni o'rnatish

Avval, `Nuxt I18n Micro` uchun test yordamchi vositalarini o'rnatishingiz kerak. Ushbu paket i18n konfiguratsiyalaringizni mock qilish va test qilish uchun zarur vositalarni taqdim etadi.

```bash
npm install @i18n-micro/test-utils --save-dev
```

### 2. Mock konfiguratsiya faylini yaratish

So'ngra, mock i18n konfiguratsiyasini sozlash uchun fayl yarating. Ushbu fayl testlaringiz davomida i18n funksiyalari va yordamchilarini mock qilish uchun ishlatiladi.

```typescript
// tests/unit-setup.ts

import { mockNuxtImport } from '@nuxt/test-utils/runtime'
import { vi } from 'vitest'
import { i18nUtils } from '@i18n-micro/test-utils'

export function createFakeI18n() {
  return {
    $getLocale: vi.fn(i18nUtils.getLocale),
    $t: vi.fn(i18nUtils.t),
    $tc: vi.fn(i18nUtils.tc),
    $setLocale: vi.fn(i18nUtils.setLocale),
    $getLocaleName: vi.fn(i18nUtils.getLocaleName),
    $setLocaleName: vi.fn(i18nUtils.setLocaleName),
    $getLocales: vi.fn(i18nUtils.getLocales),
    $setLocales: vi.fn(i18nUtils.setLocales),
    $defaultLocale: vi.fn(i18nUtils.defaultLocale),
    $setDefaultLocale: vi.fn(i18nUtils.setDefaultLocale),
    $getRouteName: vi.fn(i18nUtils.getRouteName),
    $settRouteName: vi.fn(i18nUtils.settRouteName),
    $ts: vi.fn(i18nUtils.ts),
    $tn: vi.fn(i18nUtils.tn),
    $td: vi.fn(i18nUtils.td),
    $has: vi.fn(i18nUtils.has),
    $resolveTranslations: vi.fn(i18nUtils.resolveTranslations),
    $setTranslation: vi.fn(i18nUtils.setTranslation),
    $mergeTranslations: vi.fn(i18nUtils.mergeTranslations),
    $switchLocaleRoute: vi.fn(i18nUtils.switchLocaleRoute),
    $switchLocalePath: vi.fn(i18nUtils.switchLocalePath),
    $switchLocale: vi.fn(i18nUtils.switchLocale),
    $switchRoute: vi.fn(i18nUtils.switchRoute),
    $localeRoute: vi.fn(i18nUtils.localeRoute),
    $localePath: vi.fn(i18nUtils.localePath),
    $setI18nRouteParams: vi.fn(i18nUtils.setI18nRouteParams),
  }
}

mockNuxtImport<() => ReturnType<typeof createFakeI18n>>('useI18n', () => vi.fn(() => createFakeI18n()))

export const setTranslationsFromJson = i18nUtils.setTranslationsFromJson
```

### 3. Vitest'ni sozlash

Endi Vitest'ni mock konfiguratsiya faylidan foydalanish va test muhitini sozlash uchun sozlang.

```typescript
// vitest.config.ts

import { defineVitestConfig } from '@nuxt/test-utils/config'

export default defineVitestConfig({
  test: {
    watch: false,
    setupFiles: ['./tests/unit-setup.ts'],
    include: ['./**/*.spec.ts'],
  },
})
```

## 🧪 Testlar yozish

### Misol komponent

Xabarlarni tarjima qilish uchun `useI18n` composable'idan foydalanadigan oddiy komponentga misol:

```vue
<script setup lang="ts">
const { $t } = useI18n()

const props = defineProps({
  message: {
    type: String,
    default: null,
  },
})

// Test to see that $t works in script setup as well as the template
const message = props.message || $t('defaultMessage')
</script>

<template>
  <div>
    <p>Test from component: {{ $t('welcome') }}</p>
    <p data-testid="message">Test message from props: {{ message }}</p>
  </div>
</template>
```

### Test fayli

Endi ushbu komponent uchun test yozamiz.

```typescript
// tests/unit/example.spec.ts

import { describe, it, expect, beforeEach } from 'vitest'
import { mount } from '@vue/test-utils'
import ExampleComponent from '@/components/ExampleComponent.vue'
import fs from 'fs'
import path from 'path'
import { setTranslationsFromJson } from './unit-setup'

describe('ExampleComponent', () => {
  beforeEach(async () => {
    const fileContent = fs.readFileSync(path.join(__dirname, '../../locales/en-GB.json')).toString()
    await setTranslationsFromJson('en', JSON.parse(fileContent))
  })

  it('renders the welcome message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.text()).toContain('Test from component: Welcome')
  })

  it('renders the default message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Default Message')
  })

  it('renders the custom message correctly', () => {
    const wrapper = mount(ExampleComponent, {
      props: {
        message: 'Custom Message',
      },
    })
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Custom Message')
  })
})
```

## 📝 Test qilishda eng yaxshi amaliyotlar

- **🔧 i18n funksiyalarini mock qiling:** Izchil va oldindan aytiladigan test natijalarini ta'minlash uchun har doim `@i18n-micro/test-utils` yordamida i18n funksiyalarini mock qiling.
- **⚙️ Unit testlar uchun Vitest'dan foydalaning:** Vitest — Vue ilovalari uchun kuchli test freymvorki. Komponentlaringiz uchun unit testlar yozish uchun undan foydalaning.
- **📚 Testlaringizni hujjatlashtiring:** Har bir testning maqsadi va kutilgan natijalarini aniq hujjatlashtiring. Bu ravshanlikni saqlashga yordam beradi va boshqalarga (yoki kelajakdagi sizga) testlarni tushunishni osonlashtiradi.

## 📊 i18n yordamchi metodlari

Quyida `@i18n-micro/test-utils` tomonidan taqdim etilgan barcha yordamchi metodlarni tavsiflaydigan jadval keltirilgan.

| Metod                                          | Tavsif                                                                                                                                |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `t(key, params, defaultValue)`                  | Ixtiyoriy parametrlar va standart qiymat bilan kalitni tarjima qiladi.                                                                             |
| `tc(key, params, defaultValue)`                 | Ko'plikni qo'llab-quvvatlash bilan kalitni tarjima qiladi.                                                                                               |
| `setTranslationsFromJson(locale, translations)` | Muayyan locale uchun JSON obyektdan tarjimalarni yuklaydi.                                                                               |
| `getLocale()`                                   | Joriy locale'ni qaytaradi.                                                                                                                |
| `setLocale(val)`                                | Joriy locale'ni o'rnatadi.                                                                                                                   |
| `getLocaleName()`                               | Joriy locale nomini qaytaradi.                                                                                                           |
| `setLocaleName(val)`                            | Joriy locale nomini o'rnatadi.                                                                                                              |
| `getLocales()`                                  | Mavjud locale'lar ro'yxatini qaytaradi.                                                                                                     |
| `setLocales(val)`                               | Mavjud locale'lar ro'yxatini o'rnatadi.                                                                                                        |
| `defaultLocale()`                               | Standart locale'ni qaytaradi.                                                                                                                |
| `setDefaultLocale(val)`                         | Standart locale'ni o'rnatadi.                                                                                                                   |
| `getRouteName()`                                | Joriy yo'nalish nomini qaytaradi.                                                                                                            |
| `settRouteName(val)`                            | Joriy yo'nalish nomini o'rnatadi.                                                                                                               |
| `ts(key, params, defaultValue)`                 | Kalitni tarjima qiladi va natijani satr sifatida qaytaradi.                                                                                       |
| `tn(value, options?)`                           | Inline `Intl.NumberFormatOptions` bilan sonni formatlaydi. Nomli formatlar modul konfiguratsiyasini talab qiladi va ushbu mustaqil yordamchida mavjud emas. |
| `td(value, options?)`                           | Inline `Intl.DateTimeFormatOptions` bilan sanani formatlaydi. Nomli formatlar modul konfiguratsiyasini talab qiladi va ushbu mustaqil yordamchida mavjud emas. |
| `has(key)`                                      | Tarjima kaliti mavjudligini tekshiradi.                                                                                                        |
| `resolveTranslations()`                             | Joriy locale va yo'nalish uchun faol tarjima daraxtini qaytaradi.                                                                      |
| `setTranslation(key, value)`                    | Faol lug'atda `key` dagi qiymatni almashtiradi (birlashtirmasdan, almashtirish).                                                                 |
| `mergeTranslations(newTranslations)`              | Runtime'da faol locale'ga tarjimalarni birlashtiradi.                                                                                     |

Ushbu qadamlarni bajarish orqali `Nuxt I18n Micro` modulini samarali test qilishingiz va ilovangizning lokalizatsiya xususiyatlari kutilganidek ishlashini ta'minlashingiz mumkin.
