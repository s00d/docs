# Komponentlarda tarjimalardan foydalanish

Modul oʻrnatilgan va sozlangandan soʻng, Vue shablonlaringiz va skriptlaringiz ichida `$t('your_key')` ni chaqirish orqali tarjimalarni koʻrsatishingiz mumkin.

## 1. Root darajadagi va sahifa boʻyicha tarjima fayllari

1. **Root darajadagi** tarjimalar `/locales` papkasi ostida bevosita joylashadi (masalan, `/locales/en.json`, `/locales/fr.json`). Build vaqtida ular avtomatik ravishda har bir sahifa boʻyicha faylga birlashtiriladi va barcha sahifalarda mavjud boʻladi.
2. **Sahifa boʻyicha** tarjimalar `/locales/pages/...` ostida joylashadi va Nuxt sahifalar papkasi tuzilishiga mos keladi:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. `$t` bilan shablonda foydalanish

`.vue` fayllaringizda `$t` ni shablon ichida bevosita ishlatishingiz mumkin:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This bu page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, masalan:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
`$t` kalit ichma-ich JSON tugunga ishora qilsa **obyektlarni** qaytarishi mumkin (masalan, `$t('header')` → `\{ title: "Hi" \}`). Shablonlarda bu `[object Object]` sifatida chiqadi. Kafolatlangan satr kerak boʻlsa `$ts` dan foydalaning yoki `$t('header.title')` kabi aniqroq kalit taqdim eting. Tafsilotlar uchun [API havolasi — $t va $ts](/api/methods#t) ga qarang.
</Tip>

## 3. Joriy locale’ni almashtirish

Ilovangizda tillarni almashtirish uchun `useI18n()` dan `$locale` ni olib, unga yangi kod berishingiz mumkin:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. Ichma-ich kalitlar va placeholderlar

- **Ichma-ich kalitlar** nuqta notatsiyasidan foydalanadi, masalan `nested.key.deeper`.
- **Placeholderlar** dinamik qiymatlarni kiritish imkonini beradi:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. Maslahatlar va eng yaxshi amaliyotlar

- **Ziddiyatli kalitlar**: sahifa boʻyicha fayl root darajadagi fayl bilan bir xil kalitni oʻz ichiga olsa, sahifa boʻyicha versiya ustunlik oladi (root tarjimalar build vaqtida asos sifatida birlashtiriladi).
- **Sahifa fayllarini oʻchirish**: sahifa boʻyicha tarjimalardan foydalanishni istamasangiz, Nuxt konfiguratsiyangizda `disablePageLocales: true` ni oʻrnatishingiz mumkin. Bu holda faqat `/locales/*.json` fayllardan foydalaniladi.
- **Toʻgʻridan-toʻgʻri importlar yoʻq**: `import \{ useI18n \} from 'nuxt-i18n-micro'` qilishingiz shart emas; modulning avtomatik inyektsiya xususiyati buni siz uchun bajaradi.

Xolos! Ushbu qadamlar bilan siz root darajadagi yoki sahifa boʻyicha JSON fayllardan **tarjimalarni tezda olishni** va Nuxt ilovangizda `$t` yordamida **ularni koʻrsatishni** boshlashingiz mumkin.

## Qoʻshimcha resurslar

Ilgʻor xususiyatlarni oʻrganish uchun quyidagilarga qarab chiqing:

1. **`<i18n-t>` komponenti**  
   `<i18n-t>` komponenti `$t` uchun kuchli muqobildir, ayniqsa ichma-ich elementlar, ilgʻor placeholder foydalanishi va murakkabroq tarjima tuzilishlari holatlarida foydalidir.

- **Hujjatlar**: [i18n-t](/api/components/i18n-t)

2. **`useI18n` composable**  
   `useI18n` composable tarjimalarni boshqarish, locale almashtirish, formatlash va boshqalar uchun funksiyalar va reaktiv xususiyatlarning toʻliq toʻplamini taqdim etadi.

- **Hujjatlar**: [useI18n](/api/composables/use-i18n)
