# Komponentlarda tarjimalardan foydalanish

Modul o'rnatilib sozlangandan so'ng, Vue shablonlaringiz va skriptlaringiz ichida `$t('your_key')` ni chaqirish orqali tarjimalarni ko'rsatishingiz mumkin.

## 1. Root darajasidagi va sahifaga tegishli tarjima fayllari

1. **Root darajasidagi** tarjimalar to'g'ridan-to'g'ri `/locales` papkasi ostida joylashadi (masalan, `/locales/en.json`, `/locales/fr.json`). Build vaqtida ular avtomatik ravishda har bir sahifaga tegishli faylga birlashtiriladi va shu tariqa barcha sahifalarda mavjud bo'ladi.
2. **Sahifaga tegishli** tarjimalar `/locales/pages/...` ostida joylashadi va Nuxt sahifalari papka tuzilishiga mos keladi:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. `$t` bilan shablonda foydalanish

`.vue` fayllaringizda `$t` ni to'g'ridan-to'g'ri shablonda ishlatishingiz mumkin:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
`$t` agar kalit nested JSON tuguniga ishora qilsa, **obyekt** qaytarishi mumkin (masalan, `$t('header')` → `\{ title: "Hi" \}`). Shablonlarda bu `[object Object]` sifatida render qilinadi. Kafolatlangan satr kerak bo'lganda `$ts` dan foydalaning yoki `$t('header.title')` kabi aniqroq kalitni bering. Batafsil ma'lumot uchun [API ma'lumotnomasi — $t vs $ts](/api/methods#t) ga qarang.
</Tip>

## 3. Joriy locale'ni almashtirish

Ilovangizda tillarni o'zgartirish uchun `useI18n()` dan `$locale` ni olishingiz va unga yangi kod berishingiz mumkin:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. Nested kalitlar va placeholder'lar

- **Nested kalitlar** nuqtali notatsiyadan foydalanadi, masalan, `nested.key.deeper`.
- **Placeholder'lar** dinamik qiymatlarni kiritish imkonini beradi:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. Maslahatlar va eng yaxshi amaliyotlar

- **Ziddiyatli kalitlar**: Agar sahifaga tegishli fayl root darajasidagi fayl bilan bir xil kalitni o'z ichiga olsa, sahifaga tegishli versiya ustuvorlikka ega bo'ladi (root tarjimalar build vaqtida asos sifatida birlashtiriladi).
- **Sahifa fayllarini o'chirish**: Sahifaga tegishli tarjimalardan foydalanmoqchi bo'lmasangiz, Nuxt konfiguratsiyangizda `disablePageLocales: true` ni o'rnatishingiz mumkin. Bu holda faqat `/locales/*.json` fayllari ishlatiladi.
- **To'g'ridan-to'g'ri import yo'q**: `import \{ useI18n \} from 'nuxt-i18n-micro'` qilishingiz shart emas; modulning avtomatik-inyeksiya xususiyati buni siz uchun bajaradi.

Shu bilan tamom! Ushbu qadamlar bilan siz root darajasidagi yoki sahifaga tegishli JSON fayllardan **tez tarjimalarni olishingiz** va Nuxt ilovangizda ularni `$t` yordamida **ko'rsatishingiz** mumkin.

## Qo'shimcha manbalar

Ko'proq kengaytirilgan xususiyatlarni o'rganish uchun quyidagilarni ko'rib chiqing:

1. **`<i18n-t>` komponenti**  
   `<i18n-t>` komponenti `$t` ga kuchli muqobil bo'lib, ayniqsa nested elementlar, kengaytirilgan placeholder foydalanishi va murakkabroq tarjima tuzilmalarini o'z ichiga olgan holatlarda foydalidir.

- **Hujjatlar**: [i18n-t](/api/components/i18n-t)

2. **`useI18n` composable**  
   `useI18n` composable'i tarjimalarni boshqarish, locale almashtirishni bajarish, formatlash va boshqalar uchun to'liq funksiyalar va reaktiv xususiyatlar to'plamini taqdim etadi.

- **Hujjatlar**: [useI18n](/api/composables/use-i18n)
