# Runtime i18n bekor qilishlari

Ushbu qo'llanmadan bitta build artefakti har xil muhitlarda turli locale standart qiymatlari bilan ishlashi kerak bo'lganda foydalaning (masalan: turli tenant instance'lari uchun).

## Runtime'da nimalarni bekor qilish mumkin

Modul quyidagilar uchun xavfsiz runtime bekor qilishlarni qo'llab-quvvatlaydi:

- `defaultLocale`
- `fallbackLocale`
- `disabledLocales`

Ushbu bekor qilishlar `.nuxt/i18n.strategy.mjs` va `.nuxt/i18n.config.mjs` dan olingan build-time konfiguratsiyasi ustiga qo'llaniladi.

## Runtime'da nimalarni bekor qilib bo'lmaydi

`strategy` (`no_prefix`, `prefix`, `prefix_except_default`, `prefix_and_default`) — bu build-time masalasi, chunki u generatsiya qilingan yo'nalish xatti-harakatiga ta'sir qiladi.

Agar runtime strategiya bekor qilishini uzatsangiz, u e'tiborga olinmaydi va ogohlantirish chiqariladi.

## RuntimeConfig asosidagi bekor qilishlar

Runtime qiymatlarini `runtimeConfig.public.i18nRuntime` ostida taqdim eting:

```ts
export default defineNuxtConfig({
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

## Muhit o'zgaruvchilari bilan bekor qilishlar

Bekor qilishlarni muhit o'zgaruvchilari orqali ham sozlashingiz mumkin:

- `NUXT_I18N_DEFAULT_LOCALE`
- `NUXT_I18N_FALLBACK_LOCALE`
- `NUXT_I18N_DISABLED_LOCALES` (vergul bilan ajratilgan, masalan `fr,it`)

Fallback taxalluslar ham qo'llab-quvvatlanadi:

- `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES`

## Tekshirish qoidalari

Runtime'da modul yaroqsiz holatlardan qochish uchun bekor qilishlarni tekshiradi:

- Barcha locale'larni o'chirib bo'lmaydi.
- `defaultLocale` yoqilgan locale'ga ishora qilishi kerak.
- `fallbackLocale` deklaratsiya qilingan locale'larda mavjud bo'lishi kerak.

Agar bekor qilish yaroqsiz bo'lsa, modul xavfsiz qiymatni saqlaydi va ogohlantirish log qiladi.

## Ko'p-instance deployment'lari uchun eslatmalar

Bu runtime xususiyati qayta build qilmasdan har bir instance uchun locale faollashtirish va standart qiymatlar uchun mo'ljallangan.

Agar instance'lar turli URL strategiyalarini (`no_prefix` vs `prefix`) talab qilsa, har bir strategiya uchun alohida build'lardan foydalaning.

## O'chirilgan locale'lar va statik payload'lar

`runtimeConfig.public.i18nRuntime.disabledLocales` yo'naltirish, switcher va Nitro payload **handler**'ini yangilaydi — ammo Nitro `public/` ostidagi fayllarni ushbu handler'dan **oldin** taqdim etadi.

Agar `translationPayloads.publicAssets` (yoki Node SSR'ning majburiy public nusxasi) allaqachon `/_locales/\{page\}/\{locale\}/data.json` ni yozgan bo'lsa, runtime o'chirish o'sha faylni yashira olmaydi. Build'da `locale.disabled: true` ni afzal ko'ring, shunda premerge o'sha locale'ning statik payload'larini chiqarmaydi.
