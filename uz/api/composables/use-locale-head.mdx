# 🌍 `useLocaleHead` composable

`useLocaleHead` composable — bu `Nuxt I18n Micro` dagi yordamchi boʻlib, mahalliylashtirilgan marshrutlar uchun SEO atributlari va HTML meta teglarini boshqarishga yordam beradi. U HTML hujjatining `lang` va `dir` atributlarini dinamik ravishda yaratadi va mahalliylashtirilgan kontentingiz SEO’sini yaxshilash uchun `meta` va `link` teglarini yaratadi.

## ⚙️ Parametrlar

```ts
useLocaleHead(options: UseLocaleHeadOptions): { metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }, MetaObject | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

Joriy marshrut uchun SEO head teglari: har bir locale uchun `hreflang` muqobillari va
`x-default`, canonical havola, `og:locale` va `<html>` dagi `lang`/`dir`.

Faqat `meta` oʻchirilganda yoki standart qiymatlarni sozlash kerak boʻlganda kerak. `meta: true` boʻlganda modul bir xil teglarni oʻzi roʻyxatdan oʻtkazadi.

| `options` | `UseLocaleHeadOptions` |  |

**Qaytaradi** — head obyektini ushlab turadigan ref, `useHead` ga uzatishga tayyor

```ts
const head = useLocaleHead({ addSeoAttributes: true })
useHead(head)
```

## 🛠️ Qaytish qiymatlari

`useLocaleHead` composable manba maʼlumotlari oʻzgarganda chaqirishingiz kerak boʻlgan reaktiv obyekt va yangilash funksiyasini qaytaradi. Ikkala shakl ham manbadan yaratilgan yuqoridagi imzoda mavjud.

### `metaObject`

`useHead(metaObject)` uchun mos reaktiv head yuki (html attrs, meta, link).

- **Misol**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

Joriy marshrut, locale va konfiguratsiyaga asoslanib `metaObject` ni qayta hisoblaydi. Kirishlar oʻzgarganda uni chaqiring — masalan, marshrut oʻzgarganda.

- **Misol**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### `link` va `meta` ga kirish

`link` va `meta` massivlariga `metaObject.value` orqali kirish mumkin:

- **Misol**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ Foydalanish misollari

### Asosiy foydalanish

Standart parametrlar bilan locale boʻyicha head atributlarini yarating.

```js
const head = useLocaleHead()
```

### Identifikator atributini sozlash

Yaratilgan teglar uchun maxsus identifikator atributidan foydalaning.

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### SEO atributlarini oʻchirish

SEO bilan bogʻliq meta va link teglarini qoʻshmasdan head atributlarini yarating.

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### Asosiy URL ni belgilash

Canonical va muqobil URL’lar uchun maxsus asosiy URL ni oʻrnating.

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 Qoʻshimcha xususiyatlar

### SEO meta va link teglari

`addSeoAttributes` yoqilganda, composable quyidagi teglarni avtomatik yaratadi:

- Joriy locale uchun `og:locale` (`language_TERRITORY`, pastki chiziq). `locale.og` dan olinadi yoki iloji boʻlsa `locale.iso` dan aylantiriladi.
- Sahifaning canonical URL uchun `og:url`.
- Muqobil til versiyalari uchun `og:locale:alternate`.
- SEO optimizatsiyasi uchun `rel="canonical"` va `rel="alternate"` havolalari.
- Standart locale URL’iga ishora qiladigan `hreflang="x-default"` havolasi. Bu qidiruv tizimlariga qaysi URL ni tili aniqlangan locale’larga mos kelmagan foydalanuvchilarga koʻrsatishni bildiradi.

### Dinamik locale va yoʻnalish

Composable joriy marshrut locale’siga asoslanib `lang` va `dir` atributlarini dinamik ravishda aniqlaydi va HTML hujjatingiz xalqaro foydalanuvchilar uchun toʻgʻri sozlanganini taʼminlaydi.

### Mahalliylashtirilgan marshrutlarni boshqarish

Agar marshrutlaringiz locale kodlari bilan prefikslangan boʻlsa (masalan, `/en/about`), composable URL’lar yaratish uchun toʻliq yoʻlni aqlli ravishda sozlaydi va SEO atributlari aniq va tegishli boʻlishini taʼminlaydi.

Ushbu composable Nuxt ilovangizni xalqaro auditoriyalar uchun optimallashtirish jarayonini soddalashtiradi va saytingizni global qidiruv tizimlari va foydalanuvchilar uchun yaxshi tayyorlaydi.

## 🛠️ Foydalanish misoli

Quyidagi misolda Vue komponentida standart sozlamalar bilan `useLocaleHead` composable’dan qanday foydalanish koʻrsatilgan:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### Kodni tushuntirish

- **`useLocaleHead` composable**: bu composable `<script setup>` boʻlimida chaqiriladi va `htmlAttrs`, `meta` va `link` ni oʻz ichiga olgan obyekt qaytaradi.

- **`<html>` tegi**: HTML hujjati uchun `lang` va `dir` atributlari joriy locale asosida dinamik ravishda aniqlanadi va `<html>` tegiga qoʻllaniladi.

- **`<head>` boʻlimi**:
  - **Meta teglar**: SEO bilan bogʻliq meta teglar yaratiladi, jumladan `og:locale`, `og:url` va sahifaning muqobil til versiyalarini belgilash uchun `rel="canonical"` va `rel="alternate"` teglar.
  - **Link teglar**: canonical havolalar, muqobil til versiyalariga havolalar va `hreflang="x-default"` havolasi (standart locale URL’iga ishora qiladigan) kiritiladi.

- **`<body>` boʻlimi**: sahifaning asosiy kontenti bu yerda koʻrsatiladi. Ushbu misolda oddiy sarlavha va paragraf ishlatilgan.

### 📝 Eslatmalar

1. **Atributlar**: ishlatiladigan atributlar (`lang`, `dir`, `rel`, `href`, `hreflang`, `property`, `content`) `useLocaleHead` qaytargan obyektdan olinadi.

2. **SEO teglarini yaratish**: `addSeoAttributes` parametri `true` ga oʻrnatilgan boʻlsa, composable joriy locale uchun SEO teglarini avtomatik yaratadi.

3. **Asosiy URL**: canonical va muqobil havolalarni toʻgʻri yaratish uchun `baseUrl` parametri orqali maxsus asosiy URL ni oʻrnatishingiz mumkin.

Ushbu misolda `useLocaleHead` ni ilovangiz komponentlariga integratsiya qilish qanchalik oson ekanligi koʻrsatilgan. Bu toʻgʻri SEO atributlarini taʼminlash va mahalliylashtirilgan sahifalarning qidiruv tizimida indekslanishini yaxshilashga yordam beradi.

## 🧩 Sozlash va hayotiy sikl

- `useLocaleHead` oʻzgarishlarga oʻzi obuna boʻlmaydi. U `metaObject` va `updateMeta` ni qaytaradi.
- Kirishlar oʻzgarganda (odatda marshrut oʻzgarganda) `updateMeta()` ni chaqirishingiz kerak, masalan plagindan:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## Qachon `useI18nHead` dan foydalanish

`meta: true` (standart) boʻlganda, **sahifa boʻyicha** bekor qilishlar (maxsus hreflang, qoʻshimcha `og:title`, qisman oʻchirish) uchun [`useI18nHead`](/api/composables/use-i18n-head) ni afzal koʻring. `useLocaleHead` ni faqat `meta: false` boʻlganda yoki `useHead` ni oʻzingiz boshqarganingizda toʻgʻridan-toʻgʻri ishlating.
