# 🌍 `useLocaleHead` composable

`useLocaleHead` composable — bu `Nuxt I18n Micro` dagi lokalizatsiyalangan yo'nalishlar uchun SEO atributlari va HTML meta teglarini boshqarishga yordam beradigan yordamchi vosita. U HTML hujjatining `lang` va `dir` uchun atributlarni dinamik ravishda generatsiya qiladi va lokalizatsiyalangan kontentingiz SEO'sini yaxshilash uchun `meta` va `link` teglarini yaratadi.

## ⚙️ Opsiyalar

```ts
useLocaleHead(options: UseLocaleHeadOptions): { metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }, MetaObject | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

Joriy yo'nalish uchun SEO head teglari: har bir locale uchun `hreflang` muqobillari va `x-default`, canonical havola, `og:locale` hamda `<html>` da `lang`/`dir`.

Faqat `meta` o'chirilganda yoki standart qiymatlar sozlanishi kerak bo'lganda kerak — `meta: true` bilan modul o'sha teglarni o'zi ro'yxatdan o'tkazadi.

**Qaytaradi** — `useHead` ga uzatishga tayyor head obyektini o'z ichiga olgan ref

```ts
const head = useLocaleHead({ addSeoAttributes: true })
```

## 🛠️ Qaytariladigan qiymatlar

`useLocaleHead` composable manba ma'lumotlar o'zgarganda chaqirishingiz kerak bo'lgan reaktiv obyekt va yangilash funksiyasini qaytaradi. Ikkala shakl ham manbadan generatsiya qilingan yuqoridagi signaturada.

### `metaObject`

`useHead(metaObject)` uchun mos reaktiv head payload (html atributlari, meta, link).

- **Misol**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

Joriy yo'nalish, locale va konfiguratsiyaga asoslangan holda `metaObject` ni qayta hisoblaydi. Kirishlar o'zgarganda uni chaqiring — masalan, yo'nalish o'zgarganda.

- **Misol**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### `link` va `meta` ga kirish

`link` va `meta` massivlariga `metaObject.value` orqali kirish mumkin:

- **Misol**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ Foydalanish misollari

### Asosiy foydalanish

Standart opsiyalar bilan locale-o'ziga xos head atributlarini generatsiya qilish.

```js
const head = useLocaleHead()
```

### Identifikator atributini sozlash

Generatsiya qilingan teglar uchun maxsus identifikator atributidan foydalaning.

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### SEO atributlarini o'chirish

SEO bilan bog'liq meta va link teglarini qo'shmasdan head atributlarini generatsiya qilish.

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### Asosiy URL'ni ko'rsatish

Canonical va muqobil URL'lar uchun maxsus asosiy URL'ni o'rnating.

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 Qo'shimcha xususiyatlar

### SEO meta va link teglari

`addSeoAttributes` yoqilganda, composable avtomatik ravishda quyidagi teglarni generatsiya qiladi:

- Joriy locale uchun `og:locale` (`language_TERRITORY`, pastki chiziq). `locale.og` dan olinadi yoki iloji bo'lganda `locale.iso` dan konvertatsiya qilinadi.
- Sahifaning canonical URL uchun `og:url`.
- Muqobil til versiyalari uchun `og:locale:alternate`.
- SEO optimallashtirish uchun `rel="canonical"` va `rel="alternate"` havolalari.
- Standart locale URL'iga ishora qiluvchi `hreflang="x-default"` havolasi. Bu qidiruv tizimlariga aniqlangan locale'lardan biriga tili mos kelmaydigan foydalanuvchilarga qaysi URL'ni ko'rsatishni aytadi.

### Dinamik locale va yo'nalish

Composable joriy yo'nalish locale'iga asoslangan holda `lang` va `dir` atributlarini dinamik ravishda aniqlaydi va HTML hujjatingizning xalqaro foydalanuvchilar uchun to'g'ri sozlanganligini ta'minlaydi.

### Lokalizatsiyalangan yo'nalishlarni boshqarish

Agar yo'nalishlaringiz locale kodlari bilan prefikslangan bo'lsa (masalan, `/en/about`), composable URL'larni generatsiya qilish uchun to'liq yo'lni aqlli ravishda sozlaydi va SEO atributlari aniq va tegishli ekanligini ta'minlaydi.

Ushbu composable Nuxt ilovangizni xalqaro auditoriya uchun optimallashtirish jarayonini soddalashtiradi va saytingizning global qidiruv tizimlari va foydalanuvchilar uchun yaxshi tayyorlanganligini ta'minlaydi.

## 🛠️ Foydalanish misoli

Quyidagi misol Vue komponenti ichida standart sozlamalar bilan `useLocaleHead` composable'idan qanday foydalanishni ko'rsatadi:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### Kodni tushuntirish

- **`useLocaleHead` composable**: Ushbu composable `<script setup>` bo'limida chaqiriladi va `htmlAttrs`, `meta` va `link` ni o'z ichiga olgan obyektni qaytaradi.

- **`<html>` tegi**: HTML hujjati uchun `lang` va `dir` atributlari joriy locale asosida dinamik ravishda aniqlanadi va `<html>` tegiga qo'llaniladi.

- **`<head>` bo'limi**:
  - **Meta teglari**: SEO bilan bog'liq meta teglar generatsiya qilinadi, jumladan `og:locale`, `og:url` va sahifaning muqobil til versiyalarini ko'rsatuvchi `rel="canonical"` va `rel="alternate"` teglar.
  - **Link teglari**: Canonical havolalar, muqobil til versiyalariga havolalar va `hreflang="x-default"` havolasi (standart locale URL'iga ishora qiladi) kiritiladi.

- **`<body>` bo'limi**: Sahifaning asosiy kontenti bu yerda ko'rsatiladi. Ushbu misolda oddiy sarlavha va paragraf ishlatilgan.

### 📝 Eslatmalar

1. **Atributlar**: Ishlatilgan atributlar (`lang`, `dir`, `rel`, `href`, `hreflang`, `property`, `content`) `useLocaleHead` tomonidan qaytarilgan obyektdan olinadi.

2. **SEO teglar generatsiyasi**: Agar `addSeoAttributes` opsiyasi `true` ga o'rnatilgan bo'lsa, composable joriy locale uchun SEO teglarini avtomatik generatsiya qiladi.

3. **Asosiy URL**: Canonical va muqobil havolalarni to'g'ri generatsiya qilish uchun `baseUrl` opsiyasi yordamida o'zingizning maxsus asosiy URL'ingizni o'rnatishingiz mumkin.

Ushbu misol `useLocaleHead` ni ilovangiz komponentlariga to'g'ri SEO atributlarini ta'minlash va lokalizatsiyalangan sahifalarning qidiruv tizimi indekslashini yaxshilash uchun qanday oson integratsiya qilish mumkinligini namoyish etadi.

## 🧩 Sozlash va hayotiy sikl

- `useLocaleHead` o'zi o'zgarishlarga obuna bo'lmaydi. U `metaObject` va `updateMeta` ni qaytaradi.
- Kirishlar o'zgarganda `updateMeta()` ni chaqirishingiz kerak (odatda yo'nalish o'zgarganda), masalan, plagindan:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## Qachon `useI18nHead` ni o'rniga ishlatish kerak

`meta: true` (standart) bo'lganda, **sahifa bo'yicha** bekor qilishlar (maxsus hreflang, qo'shimcha `og:title`, qisman o'chirish) uchun [`useI18nHead`](/api/composables/use-i18n-head) ni afzal ko'ring. `useLocaleHead` ni to'g'ridan-to'g'ri faqat `meta: false` yoki `useHead` ni o'zingiz boshqarganda ishlating.
