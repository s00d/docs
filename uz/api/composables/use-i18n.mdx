# 🛠️ `useI18n` composable

`Nuxt I18n Micro` dagi `useI18n` composable komponentlar va skriptlarda ko'pchilik runtime i18n yordamchilariga kirish imkonini beradi. Metodlar **`$` prefiksi bilan va bo'lmasdan** mavjud (masalan, `$t` va `t`).

Ba'zi in'ektsiyalar — `$defineI18nRoute` va `$clearCache` — faqat `useNuxtApp()` da mavjud. [Metodlar — `$defineI18nRoute`](/api/methods#definei18nroute) va [`$clearCache`](/api/methods#clearcache) ga qarang.

## 📊 U nima qaytaradi

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Har bir runtime yordamchisi, oddiy obyekt sifatida.

Plagin `$t`, `$tc` va h.k. sifatida inyekt qiladigan bir xil funksiyalar, ham dollar-prefiksli nom, ham yalang'och taxallus ostida mavjud — shuning uchun `const \{ t \} = useI18n()` va
`const \{ $t \} = useI18n()` ikkalasi ham ishlaydi.

**Qaytaradi** — [metodlar ma'lumotnomasi](/api/methods) da tavsiflangan yordamchilar

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

U qaytaradigan har bir yordamchi — `$t`, `$tc`, `$has`, `$switchLocale` va boshqalar — o'z signatura va batafsil hujjatlashtirish bilan [Metodlar ma'lumotnomasi](/api/methods) da keltirilgan.

## Faqat `useNuxtApp()` API'lari

Bular `useI18n()` tomonidan qaytarilmaydi. Ularni `useNuxtApp()` dan import qiling:

| Metod                     | Maqsad                                                                         |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Sahifa bo'yicha locale yo'nalishlari, cheklovlar va `script setup` da inline tarjimalar |
| `$clearCache()`            | Xotiradagi tarjima keshini va yuklangan chunk'larni tozalaydi                            |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

To'liq signatura va misollar uchun [Metodlar](/api/methods) ga qarang.

## 🛠️ Foydalanish misollari

### Asosiy locale olish

Ilovaning joriy locale'ini oling.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Parametrlar bilan tarjima

Dinamik parametrlar va fallback standart qiymati bilan satrni tarjima qiling.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Locale'larni almashtirish

Ilovani boshqa locale'ga almashtiring.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Lokalizatsiyalangan yo'nalishni generatsiya qilish

Joriy yoki ko'rsatilgan locale'ga lokalizatsiyalangan yo'nalishni generatsiya qiling.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
