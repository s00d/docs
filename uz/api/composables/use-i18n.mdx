# 🛠️ `useI18n` composable

`Nuxt I18n Micro` dagi `useI18n` composable komponentlar va skriptlardagi runtime i18n yordamchilariga kirish imkonini beradi. Metodlar **`$` prefiksi bilan va usiz** mavjud (masalan, `$t` va `t`).

Baʼzi inyektsiyalar — `$defineI18nRoute` va `$clearCache` — faqat `useNuxtApp()` da mavjud. [Metodlar — `$defineI18nRoute`](/api/methods#definei18nroute) va [`$clearCache`](/api/methods#clearcache) ga qarang.

## 📊 U nima qaytaradi

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Har bir runtime yordamchisi, oddiy obyekt sifatida.

Plagin `$t`, `$tc` va h.k. sifatida inyektsiya qiladigan funksiyalar dollar-prefiksli nom bilan va yalangʻoch taxallus bilan ham mavjud, shuning uchun `const \{ t \} = useI18n()` va `const \{ $t \} = useI18n()` ikkalasi ham ishlaydi.

**Qaytaradi** — [metodlar havolasi](/api/methods) da tavsiflangan yordamchilar

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

U qaytaradigan har bir yordamchi — `$t`, `$tc`, `$has`, `$switchLocale` va boshqalar — [Metodlar havolasi](/api/methods) da imzosi bilan sanab oʻtilgan va toʻliq hujjatlashtirilgan.

## Faqat `useNuxtApp()` API’lari

Bular `useI18n()` tomonidan qaytarilmaydi. Ularni `useNuxtApp()` dan import qiling:

| Metod                     | Vazifasi                                                                         |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Sahifa boʻyicha locale marshrutlari, cheklovlar va `script setup` dagi inline tarjimalar |
| `$clearCache()`            | Xotiradagi tarjima keshini va yuklangan bloklarni tozalaydi                            |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Toʻliq imzolar va misollar uchun [Metodlar](/api/methods) ga qarang.

## 🛠️ Foydalanish misollari

### Asosiy locale olish

Ilovaning joriy locale’sini oling.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Parametrlar bilan tarjima

Dinamik parametrlar bilan satrni tarjima qiling, standart qiymat bilan.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Locale almashtirish

Ilovani boshqa locale’ga oʻtkazing.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Mahalliylashtirilgan marshrutni yaratish

Joriy yoki belgilangan locale’ga mahalliylashtirilgan marshrut yarating.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
