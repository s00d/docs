## API

| Xususiyat/Metod                                 | Tur                                | Tavsif                                                                          |
| ----------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| `locale`                                        | `Ref<string \| null>`               | Reaktiv locale holati (`useState('i18n-locale')`)                                    |
| `localeCookie`                                  | `Ref`                               | Locale cookie (`localeCookie` parametri yoqilganda)                                |
| `hashCookie`                                    | `Ref`                               | `hashMode` faol boʻlganda ishlatiladigan cookie                                                |
| `validLocales`                                  | `string[]`                          | Modul konfiguratsiyasidan yoqilgan locale kodlari (`disabled` ni chiqarib tashlaydi)                        |
| `getLocale()`                                   | `() => string \| null`              | Joriy locale: holat → cookie (yoki hash rejimida hash cookie)                         |
| `getPreferredLocale()`                          | `() => string \| null`              | Holat/cookie’dan `validLocales` ga qarshi **tasdiqlangan** locale, yoki `null`             |
| `getLocaleWithServerFallback(serverLocale?)`    | `(serverLocale?) => string \| null` | Holat → cookie → ixtiyoriy server konteksti (`no_prefix` init paytida ishlatiladi)              |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string`             | Tarjimalarni yuklash uchun locale: hash rejimi holatni afzal koʻradi; aks holda marshrutdan oʻqiydi |
| `resolveInitialLocale(options)`                 | `(options) => string`               | Locale ni hal qiladi: holat → `serverLocale` → marshrut; kerak boʻlganda holatni sinxronlashtiradi             |
| `setLocale(locale)`                             | `(locale: string \| null) => void`  | Locale’ni oʻrnatish va cookielarga sinxronlash                                                       |
| `syncLocale(locale)`                            | `(locale: string \| null) => void`  | Faqat cookielarni sinxronlash (holat yangilanmaydi)                                                  |
| `isValidLocale(locale)`                         | `(locale) => boolean`               | Satr `validLocales` da borligini tekshirish                                                 |

### `resolveInitialLocale` parametrlari

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

Ishga tushishda asosiy plagin tomonidan ichkarida ishlatiladi. Maxsus plaginlar muqobil aniqlash oqimlarini amalga oshirganda uni chaqirishi mumkin.

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

Berilgan marshrut obyekti uchun tarjimalarni yuklash va xabarlarni formatlash uchun ishlatiladigan locale’ni qaytaradi.

## Dasturiy locale oʻrnatish

`useState('i18n-locale')` ni toʻgʻridan-toʻgʻri ishlatish oʻrniga `useI18nLocale()` ni afzal koʻring:

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
`setLocale()` faqat locale afzalligini yangilaydi (holat + cookie). Mijozda faol tarjima kontekstini ham qayta yuklash uchun `useNuxtApp()` yoki `useI18n()` dan `$switchLocale()` dan foydalaning. Bu ayniqsa URL oʻzgarmaydigan `no_prefix` uchun muhim. [FAQ — URL ni oʻzgartirmasdan locale’ni almashtirish](/guides/faq#-switch-locale-without-changing-the-url) ga qarang.
</Tip>
