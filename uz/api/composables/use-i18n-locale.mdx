## API

| Xususiyat/Metod                                 | Tur                                | Tavsif                                                                          |
| ----------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| `locale`                                        | `Ref<string \| null>`               | Reaktiv locale holati (`useState('i18n-locale')`)                                    |
| `localeCookie`                                  | `Ref`                               | Locale cookie (agar `localeCookie` opsiyasi yoqilgan bo'lsa)                                |
| `hashCookie`                                    | `Ref`                               | `hashMode` faol bo'lganda ishlatiladigan cookie                                                |
| `validLocales`                                  | `string[]`                          | Modul konfiguratsiyasidan yoqilgan locale kodlari (`disabled` bo'lganlarni chiqarib tashlaydi)                        |
| `getLocale()`                                   | `() => string \| null`              | Joriy locale: state → cookie (yoki hash rejimida hash cookie)                         |
| `getPreferredLocale()`                          | `() => string \| null`              | State/cookie'dan `validLocales` ga qarshi **tekshirilgan** locale yoki `null`             |
| `getLocaleWithServerFallback(serverLocale?)`    | `(serverLocale?) => string \| null` | State → cookie → ixtiyoriy server konteksti (`no_prefix` ishga tushirilishida ishlatiladi)              |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string`             | Tarjimalarni yuklash uchun locale: hash rejimi state'ni afzal ko'radi; aks holda yo'nalishdan o'qiydi |
| `resolveInitialLocale(options)`                 | `(options) => string`               | Locale'ni hal qiladi: state → `serverLocale` → yo'nalish; kerak bo'lganda state'ni sinxronlaydi             |
| `setLocale(locale)`                             | `(locale: string \| null) => void`  | Locale'ni o'rnatadi va cookie'larga sinxronlaydi                                                       |
| `syncLocale(locale)`                            | `(locale: string \| null) => void`  | Faqat cookie'larni sinxronlaydi (state yangilanmaydi)                                                  |
| `isValidLocale(locale)`                         | `(locale) => boolean`               | Satr `validLocales` da ekanligini tekshiradi                                                |

### `resolveInitialLocale` opsiyalari

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

Ishga tushirishda asosiy plagin tomonidan ichki tarzda ishlatiladi. Maxsus plaginlar muqobil aniqlash oqimlarini amalga oshirishda uni chaqirishi mumkin.

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

Berilgan yo'nalish obyekti uchun tarjimalarni yuklash va xabarlarni formatlash uchun ishlatiladigan locale'ni qaytaradi.

## Dasturiy locale o'rnatish

To'g'ridan-to'g'ri `useState('i18n-locale')` ni ishlatishdan ko'ra `useI18nLocale()` ni afzal ko'ring:

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
`setLocale()` faqat locale afzalligini (state + cookie) yangilaydi. Client'da faol tarjima kontekstini ham qayta yuklash uchun `useNuxtApp()` yoki `useI18n()` dan `$switchLocale()` dan foydalaning. Bu ayniqsa URL o'zgarmaydigan `no_prefix` uchun muhim. [FAQ — URL'ni o'zgartirmasdan locale'ni almashtirish](/guides/faq#-switch-locale-without-changing-the-url) ga qarang.
</Tip>
