# API ma'lumotnomasi

## Runtime API

- [Metodlar](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, locale almashtirish, yo'naltirish yordamchilari
- [Hodisalar](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Tarjimalar va kesh](/api/cache) — `TranslationStorage`, payload yuklash, `$clearCache`

## Server middleware

Server handler'lari maxsus middleware'dan foydalanadi (client `$t` yordamchilari emas):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — API yo'nalishlari va server handler'larida tarjima qilish
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — aniqlangan locale va metadata'ni o'qish

Sozlash, locale aniqlash ustuvorligi va misollar uchun to'liq [Server tomonidagi tarjimalar qo'llanmasi](/guides/server-side-translations) ga qarang.
