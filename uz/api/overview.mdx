# API havolasi

## Runtime API

- [Metodlar](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, locale almashtirish, marshrutlash yordamchilari
- [Hodisalar](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Tarjimalar va kesh](/api/cache) — `TranslationStorage`, yukni yuklash, `$clearCache`

## Server middleware

Server obrabotchiklari maxsus middleware’dan foydalanadi (mijoz `$t` yordamchilaridan emas):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — API marshrutlar va server obrabotchiklarida tarjima qilish
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — aniqlangan locale va metadata’ni oʻqish

Sozlash, locale aniqlash ustunligi va misollar uchun toʻliq [Server tarafidagi tarjimalar qoʻllanmasi](/guides/server-side-translations) ga qarang.
