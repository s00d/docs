# 🌍 `<i18n-switcher>` komponenti

`Nuxt I18n Micro` dagi `<i18n-switcher>` komponenti ilovangizda turli locale'lar o'rtasida almashtirish uchun foydalanuvchiga qulay dropdown interfeysini taqdim etadi. Ushbu komponent yuqori darajada sozlanadigan bo'lib, ilovangizning dizayni va layout'iga muammosiz integratsiyalash imkonini beradi.

`disabled: true` bilan locale'lar dropdown'dan **o'tkazib yuboriladi** (ular SEO / head teglari uchun `$getLocales()` orqali mavjud bo'lib qoladi). Faqat almashtirilishi mumkin bo'lgan locale'lar `NuxtLink` + `hreflang` ni oladi.

## 🛠️ Foydalanish misollari

### Asosiy foydalanish

```vue
<template>
  <i18n-switcher />
</template>
```

Bu standart uslublash va xatti-harakat bilan locale switcher'ni render qiladi.

### Maxsus yorliqlar va inline uslublar

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Ushbu misol maxsus yorliqlar va inline uslublar bilan to'liq sozlangan locale switcher'ni namoyish etadi.

## 🔌 Slotlar

Switcher'ning har bir vizual qismini almashtirish mumkin. Slotlar yuqoridagi props jadvali bilan keltirilgan; har biri shablon kontentini oladi:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Nomi `-item`, `-link-content` bilan tugaydigan yoki `before-item` bilan boshlanuvchi slotlar tegishli `locale` obyektini oladi.

## 🎨 Uslublar sharhi

`<i18n-switcher>` komponenti props orqali maxsus uslublarni uzatib oson bekor qilish mumkin bo'lgan inline uslublar yordamida aniqlangan asosiy uslublarga ega. Standart uslublashning qisqacha sharhi:

- **Wrapper**: Dropdown'ning pozitsiyalashini boshqaradi.
- **Button**: Dropdown almashtirish tugmasini uslublashtiradi.
- **Dropdown**: Dropdown ro'yxatini uslublashtiradi.
- **Items**: Ro'yxatdagi har bir elementni uslublashtiradi.
- **Links**: Har bir element ichidagi havolalarni uslublashtiradi.
- **Icon**: Dropdown ko'rsatuvchi ikonani uslublashtiradi.

Ushbu uslublarni tegishli props orqali maxsus uslublarni uzatib sozlashingiz mumkin, bu locale switcher ilovangizning UI'siga muammosiz integratsiyalanishini ta'minlaydi.
