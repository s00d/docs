# 🌍 `<i18n-group>` komponenti

Nuxt I18n Micro’dagi `<i18n-group>` komponenti tarjimalarni umumiy prefiks ostida guruhlashning qulay usulini taqdim etadi. Bu takrorlanishni kamaytiradi va kodni tashkil etishni yaxshilaydi.

## ⚙️ Prop’lar

{/* generated:component:i18n-group — do not edit; run `pnpm run docs:generate` */}

| Prop | Tur | Standart | Tavsif |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | Slot ichidagi har bir qidiruv hal qilinadigan kalit prefiksi. |
| `groupClass` | `string` | `''` | Oʻrash elementiga qoʻshimcha klass. |

**\*** talab qilinadi.

### Slotlar

| Slot | Bogʻlashlar | Tavsif |
| --- | --- | --- |
| `default` | `prefix`, `t` | Prefiksni va unga bogʻlangan `t` funksiyasini oladi. |

{/* /generated:component:i18n-group */}

## 🎯 Slotlar

Standart slot `prefix` va unga bogʻlangan `t` funksiyasini oladi, shunda ichidagi kalitlar prefiksga nisbatan yoziladi:

```vue
<i18n-group prefix="checkout">
  <template #default="{ t }">
    <h2>{{ t('title') }}</h2>
    <p>{{ t('summary', { count: 3 }) }}</p>
  </template>
</i18n-group>
```

## 🛠️ Foydalanish misoli

### Asosiy foydalanish

```vue
<template>
  <i18n-group prefix="product.details">
    <template #default="{ t }">
      <h1>{{ t('title') }}</h1>
      <p>{{ t('description') }}</p>
      <div class="price">{{ t('price', { value: 99.99 }) }}</div>
    </template>
  </i18n-group>
</template>
```

Tarjima fayli:

```json
{
  "product": {
    "details": {
      "title": "Premium Product",
      "description": "This bu premium product",
      "price": "Price: ${value}"
    }
  }
}
```

### Maxsus klass bilan

```vue
<template>
  <i18n-group prefix="user.profile" group-class="profile-section">
    <template #default="{ t }">
      <div class="user-info">
        <h2>{{ t('title') }}</h2>
        <p>{{ t('bio') }}</p>
        <div class="stats">
          <span>{{ t('stats.followers') }}</span>
          <span>{{ t('stats.following') }}</span>
        </div>
      </div>
    </template>
  </i18n-group>
</template>
```

Tarjima fayli:

```json
{
  "user": {
    "profile": {
      "title": "User Profile",
      "bio": "User biography goes here",
      "stats": {
        "followers": "Followers: {count}",
        "following": "Following: {count}"
      }
    }
  }
}
```

### Dinamik kontent bilan

```vue
<template>
  <i18n-group prefix="blog.post">
    <template #default="{ t }">
      <article>
        <h1>{{ t('title') }}</h1>
        <div class="meta">
          {{ t('meta.author', { name: author }) }} |
          {{ t('meta.date', { date: publishDate }) }}
        </div>
        <div v-for="(section, index) in sections" :key="index">
          <h2>{{ t(`sections.${index}.title`) }}</h2>
          <p>{{ t(`sections.${index}.content`) }}</p>
        </div>
      </article>
    </template>
  </i18n-group>
</template>

<script setup>
const author = 'John Doe'
const publishDate = '2024-01-01'
const sections = ['intro', 'main', 'conclusion']
</script>
```

## 🎨 Uslub

Komponent oʻz kontentini `i18n-group` klassiga ega div bilan oʻraydi va `groupClass` propida belgilangan qoʻshimcha klasslarni qoʻshadi:

```css
.i18n-group {
  /* Your base styles */
}

.profile-section {
  /* Additional styles for profile sections */
}
```

## 🚀 Eng yaxshi amaliyotlar

1. **Izchil prefikslar**: ilovangiz tuzilishini aks ettiruvchi izchil va mantiqiy prefikslardan foydalaning

```vue
<i18n-group prefix="features.pricing">
<i18n-group prefix="features.security">
```

2. **Modul tashkiloti**: bogʻliq tarjimalarni maʼnodor prefikslar ostida birga guruhlash

```vue
<i18n-group prefix="checkout.payment">
<i18n-group prefix="checkout.shipping">
```

3. **Qayta ishlatiladigan komponentlar**: oʻz tarjima guruhlari bilan qayta ishlatiladigan komponentlar yarating

```vue
<!-- UserProfile.vue -->
<i18n-group prefix="user.profile">

<!-- UserSettings.vue -->
<i18n-group prefix="user.settings">
```

4. **Ichma-ich guruhlar**: aniqlikni saqlash uchun guruhlarni chuqur ichma-ich qilishdan qoching

```vue
<!-- Good -->
<i18n-group prefix="shop.product">

<!-- Avoid -->
<i18n-group prefix="shop.category.product.details.specs">
```
