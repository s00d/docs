# 🌍 `<i18n-t>` komponenti

`Nuxt I18n Micro` dagi `<i18n-t>` komponenti — bu slotlar orqali dinamik kontent joylashtirishni qoʻllab-quvvatlaydigan moslashuvchan tarjima komponentidir. U tarjimalarni maxsus Vue komponentlari yoki HTML kontenti bilan interpolyatsiya qilish imkonini beradi va ilgʻor mahalliylashtirish ssenariylarini yoqadi.

## ⚙️ Prop’lar

| --- | --- | --- | --- |
| `keypath` **\*** | `string` | — | Chiqariladigan tarjima kaliti. |
| `plural` | `number \| string` | — | Koʻplik shaklini tanlaydigan son. `$t` oʻrniga `$tc` dan foydalanish uchun oʻrnating. |
| `tag` | `string` | `'span'` | Chiqariladigan element. |
| `params` | `Record<string, string \| number \| boolean>` | `() => (\{\})` | Tarjimaga almashtiriladigan interpolatsiya qiymatlari. |
| `defaultValue` | `string` | `''` | `hideIfEmpty` boʻsh tarjimani bostirganda komponent oʻrniga chiqariladi. |
| `html` | `boolean` | `false` | Tarjimani matn oʻrniga HTML sifatida chiqarish. Faqat siz nazorat qiladigan kontent uchun. |
| `hideIfEmpty` | `boolean` | `false` | Tarjima boʻsh satrga hal qilinsa hech narsa chiqarmaslik. |

| `number` | `number \| string` | — | Qiymatni `$tn` bilan formatlaydi va tarjimaga `\{number\}` sifatida uzatadi. |
| `date` | `Date \| string \| number` | — | Qiymatni `$td` bilan formatlaydi va tarjimaga `\{date\}` sifatida uzatadi. |

{/* /generated:component:i18n-t */}

Bir vaqtda faqat `plural`, `number`, `date` va `relativeDate` dan bittasi qoʻllaniladi; bir nechtasi oʻrnatilganida, roʻyxatdagi birinchisi ustunlik qiladi.

### Prop boʻyicha misollar

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

## 🛠️ Foydalanish misollari

### Asosiy foydalanish

```vue
<i18n-t keypath="feedback.text" />
```

Bu `feedback.text` uchun tarjimani `<span>` tegi ichida chiqaradi.

### Dinamik kontent uchun slotlardan foydalanish

`<i18n-t>` komponenti tarjimaning muayyan qismlariga Vue komponentlari yoki boshqa kontentni dinamik joylashtirish uchun slotlardan foydalanishni qoʻllab-quvvatlaydi.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

Ushbu misolda `feedback.text` tarjima satridagi `\{link\}` placeholderi `<nuxt-link>` komponenti bilan almashtiriladi, uning ichida esa boshqa tarjima komponenti bor.

### Koʻplik

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

Bu `itemCount` qiymatiga asoslanib koʻplik qoidalarini avtomatik qoʻllaydi.

## 🚀 Qoʻshimcha xususiyatlar

### Standart slot

Maxsus slot berilmagan boʻlsa, tarjimani butun tarjima qilingan satrni taqdim etadigan standart slot orqali sozlash mumkin:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### Shartli renderlash

Tarjima satri boʻsh boʻlsa `hideIfEmpty` propidan foydalanib hech narsa chiqarmang.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### Maxsus koʻplik qoidasi

Koʻplikni boshqarish uchun maxsus funksiyadan foydalaning.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### Slotlar bilan ilgʻor misol

Tarjima kontenti qanday chiqarilishini sozlash uchun slotlardan foydalaning.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
