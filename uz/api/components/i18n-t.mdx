# 🌍 `<i18n-t>` komponenti

`Nuxt I18n Micro` dagi `<i18n-t>` komponenti — bu slotlar orqali dinamik kontent kiritishni qo'llab-quvvatlaydigan moslashuvchan tarjima komponenti. U tarjimalarni maxsus Vue komponentlari yoki HTML kontenti bilan interpolatsiya qilishga imkon beradi va kengaytirilgan lokalizatsiya stsenariylarini yoqadi.

## ⚙️ Props

{/* /generated:component:i18n-t */}

`plural`, `number`, `date` va `relativeDate` dan faqat bittasi bir vaqtning o'zida amal qiladi; bir nechtasi o'rnatilganda, o'sha ro'yxatdagi birinchisi g'olib chiqadi.

### Prop bo'yicha misollar

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

## 🛠️ Foydalanish misollari

### Asosiy foydalanish

```vue
<i18n-t keypath="feedback.text" />
```

Bu `feedback.text` uchun tarjimani `<span>` tegi ichida render qiladi.

### Dinamik kontent uchun slotlardan foydalanish

`<i18n-t>` komponenti tarjimaning muayyan qismlariga Vue komponentlari yoki boshqa kontentni dinamik ravishda kiritish uchun slotlardan foydalanishni qo'llab-quvvatlaydi.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

Bu misolda `feedback.text` tarjima satridagi `\{link\}` placeholder o'z ichida yana bir tarjima komponentini o'z ichiga olgan `<nuxt-link>` komponenti bilan almashtiriladi.

### Ko'plik

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

Bu `itemCount` qiymati asosida ko'plik qoidalarini avtomatik qo'llaydi.

## 🚀 Qo'shimcha xususiyatlar

### Standart slot

Agar muayyan slot taqdim etilmasa, tarjima to'liq tarjima qilingan satrni beradigan standart slot orqali sozlanishi mumkin:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### Shartli render qilish

`hideIfEmpty` prop yordamida tarjima satri bo'sh bo'lganda hech narsa render qilmaslik.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### Maxsus ko'plik qoidasi

Ko'plikni boshqarish uchun maxsus funksiyadan foydalaning.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### Slotlar bilan kengaytirilgan misol

Tarjima kontenti qanday render qilinishini sozlash uchun slotlardan foydalaning.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
