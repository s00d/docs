# 🌍 `<i18n-link>` komponenti

`Nuxt I18n Micro` dagi `<i18n-link>` komponenti — bu joriy locale asosida marshrutlarni avtomatik mahalliylashtiradigan koʻp qirrali havola komponentidir. U `<NuxtLink>` komponentining oʻramasi sifatida ishlaydi va faol havola uslubi, tashqi havolalarni qoʻllab-quvvatlash kabi qoʻshimcha imkoniyatlarni taqdim etadi.

## ⚙️ Prop’lar

{/* generated:component:i18n-link — do not edit; run `pnpm run docs:generate` */}

| Prop | Tur | Standart | Tavsif |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | Manzil marshruti. Avtomatik mahalliylashtiriladi; tashqi URL oʻzgartirilmasdan uzatiladi. |
| `activeStyle` | `Partial<CSSStyleValue>` | — | Havola joriy marshrutga ishora qilganda qoʻllaniladigan inline uslub. |

**\*** talab qilinadi.

### Slotlar

| Slot | Bogʻlashlar | Tavsif |
| --- | --- | --- |
| `default` | — | Havola kontenti. |

{/* /generated:component:i18n-link */}

`to` `NuxtLink` qabul qiladigan hamma narsani qabul qiladi — yoʻl, nomlangan marshrut yoki hal qilingan marshrut obyekti.
Absolyut URL aniqlanadi va mahalliylashtirilmasdan oddiy `<a target="_blank" rel="noopener noreferrer">` sifatida chiqariladi.

## 🛠️ Foydalanish misollari

### Asosiy foydalanish

```vue
<i18n-link to="/about">About Us</i18n-link>
```

Ushbu misol joriy locale’ga mahalliylashtirilgan `/about` sahifasiga havola yaratadi.

### Inline uslub bilan faol havola uslubi

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

Foydalanuvchi `/about` sahifasida boʻlganida havola qalin matnli boʻladi va faol havolani inline uslublar bilan bevosita uslublash imkonini beradi.

### Tashqi havolalarni boshqarish

Komponent tashqi havolalarni avtomatik aniqlaydi va xavfsizlik uchun kerakli atributlarni qoʻshadi.

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

Ushbu havola `https://example.com` ni yangi tabda `rel="noopener noreferrer"` bilan ochadi.

## 🎨 Uslublar

Komponent endi faol holat uchun klass oʻrniga inline uslublardan foydalanadi. Ushbu uslublarni `activeStyle` propi orqali sozlashingiz mumkin.

### Standart faol uslublar

- **Font Weight**: `bold`
- **Color**: brauzerning standart rangini meros qilib oladi (agar `activeStyle` da `color` belgilanmagan boʻlsa).

Ularni `activeStyle` propi orqali maxsus uslublar berish orqali bekor qilishingiz mumkin.

### Maxsus faol uslublar

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

Ushbu misolda havola faol boʻlganida qalin va yashil rangda boʻladi.

## 🚀 Qoʻshimcha xususiyatlar

### Maxsus kontent uchun slot

Slotlar yordamida havola ichiga maxsus kontent uzatishingiz mumkin, bu esa komponentni turli holatlar uchun moslashuvchan qiladi.

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### Foydalanish qulayligini yaxshilash

Komponent yanada ochiq tajribani taʼminlash uchun `aria-label` va boshqa foydalanish qulayligi atributlarini qoʻllab-quvvatlaydi.

```vue
<i18n-link to="/about" aria-label="Batafsil us">
  About Us
</i18n-link>
```
