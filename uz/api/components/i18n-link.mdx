# 🌍 `<i18n-link>` komponenti

`Nuxt I18n Micro` dagi `<i18n-link>` komponenti joriy locale asosida yo'nalishlarni avtomatik lokalizatsiya qiladigan ko'p qirrali havola komponentidir. U `<NuxtLink>` komponenti atrofidagi wrapper sifatida ishlaydi va faol havola uslublash va tashqi havolalarni qo'llab-quvvatlash kabi qo'shimcha xususiyatlarni taqdim etadi.

## ⚙️ Props

{/* generated:component:i18n-link — do not edit; run `pnpm run docs:generate` */}

| Prop | Tur | Standart | Tavsif |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | Maqsad yo'nalish. Avtomatik lokalizatsiya qilinadi; tashqi URL o'zgarmagan holda uzatiladi. |
| `activeStyle` | `Partial<CSSStyleValue>` | — | Havola joriy yo'nalishga ishora qilganda qo'llaniladigan inline uslub. |

**\*** talab qilinadi.

### Slotlar

| Slot | Bog'lanishlar | Tavsif |
| --- | --- | --- |
| `default` | — | Havola kontenti. |

{/* /generated:component:i18n-link */}

`to` `NuxtLink` qabul qiladigan har qanday narsani qabul qiladi — yo'l, nomli yo'nalish yoki hal qilingan yo'nalish obyekti.
Absolyut URL aniqlanadi va lokalizatsiya qilinish o'rniga oddiy `<a target="_blank" rel="noopener noreferrer">` sifatida render qilinadi.

## 🛠️ Foydalanish misollari

### Asosiy foydalanish

```vue
<i18n-link to="/about">About Us</i18n-link>
```

Bu misol joriy locale'ga lokalizatsiya qilingan `/about` sahifasiga havola yaratadi.

### Inline uslublash bilan faol havola uslublash

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

Foydalanuvchi `/about` sahifasida bo'lganda havola qalin matnga ega bo'ladi, bu esa faol havolani inline uslublar bilan bevosita uslublashga imkon beradi.

### Tashqi havolalarni boshqarish

Komponent avtomatik ravishda tashqi havolalarni aniqlaydi va xavfsizlik uchun zarur atributlarni qo'shadi.

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

Bu havola `https://example.com` ni `rel="noopener noreferrer"` qo'llangan holda yangi yorlig'da ochadi.

## 🎨 Uslublar

Komponent endi faol holat uchun sinf o'rniga inline uslublardan foydalanadi. Ushbu uslublarni `activeStyle` prop yordamida sozlashingiz mumkin.

### Standart faol uslublar

- **Shrift qalinligi**: `bold`
- **Rang**: Brauzerning standart rangini meros qilib oladi (agar `activeStyle` da `color` ko'rsatilmagan bo'lsa).

`activeStyle` prop orqali maxsus uslublarni taqdim etib ularni bekor qilishingiz mumkin.

### Maxsus faol uslublar

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

Bu misolda havola faol bo'lganda qalin va yashil bo'ladi.

## 🚀 Qo'shimcha xususiyatlar

### Maxsus kontent uchun slot

Slotlar yordamida havola ichida maxsus kontent uzata olasiz, bu komponentni turli foydalanish holatlariga moslashuvchan qiladi.

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### Foydalanish qulayligi yaxshilanishlari

Komponent qulayroq tajribani ta'minlash uchun `aria-label` va boshqa foydalanish qulayligi atributlarini qo'llab-quvvatlaydi.

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
