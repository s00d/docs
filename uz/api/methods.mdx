---
title: "Yordamchilar"
description: "Modul inject qiladigan har bir runtime yordamchisi — `$t`, `$tc`, `$localePath`, `$switchLocale` va boshqalar — signaturasi bilan."
---

Modul o'zining runtime yordamchilarini Nuxt ilovasiga inject qiladi: `$t`, `$tc`, `$localePath`, `$switchLocale` va boshqalar. Yordamchining signaturasi va xatti-harakatini bilish uchun ushbu sahifadan foydalaning. Signaturalar va tavsiflar `src/runtime/plugins/01.plugin.ts` ichidagi `PluginsInjections` va `NuxtAppOnlyInjections` interfeyslaridan olingan.

## Kirish {#access}

| Qayerda | Qanday |
| --- | --- |
| Shablon | `{{ $t('title') }}` — har bir yordamchi, `$` bilan |
| `<script setup>` | `const { t, localePath } = useI18n()` — `PluginsInjections`dagi har bir yordamchi, `$` bilan ham, usiz ham |
| Plagin, middleware, `<script setup>` | `const { $t, $defineI18nRoute } = useNuxtApp()` — hammasi, faqat `$` bilan |

`$defineI18nRoute` faqat `useNuxtApp()`da turlangan. [`useI18n`](/uz/composables/useI18n)ga qarang.

```vue
<script setup lang="ts">
const { t, localePath } = useI18n()
</script>

<template>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
</template>
```

## Lokal {#locale}

### `$getLocale` {#$getlocale}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric) => string
```

Faol lokal kodi. Marshrut tegishli bo'lgan lokalni o'qish uchun marshrutni uzating.

```ts
$getLocale() // 'de' on /de/about
```

### `$getLocaleName` {#$getlocalename}

```ts
() => string | null
```

Konfiguratsiyadagi faol lokalning `displayName`i yoki u bo'lmasa `null`.

### `$getLocales` {#$getlocales}

```ts
() => Locale[]
```

Barcha sozlangan lokallar, metama'lumotlari bilan.

Lokal obyektidagi maxsus xususiyatlar yozilganicha qaytadi; ularni `Locale`ning [modul kengaytmasi](/uz/api/module-options#locales) bilan turlang.

### `$defaultLocale` {#$defaultlocale}

```ts
() => string | undefined
```

Sozlangan standart lokal kodi.

### `$getI18nConfig` {#$geti18nconfig}

```ts
() => ResolvedI18nConfig
```

Runtime ko'rganidek, aniqlangan modul konfiguratsiyasi.

Qiymat [runtime'da qayta belgilashlarni](/uz/guide/runtime-overrides) (`defaultLocale`, `fallbackLocale`, o'chirilgan lokallar) o'z ichiga oladi.

```ts
const { strategy, localeCookie } = useNuxtApp().$getI18nConfig()
```

## Tarjima {#translation}

### `$t` {#$t}

```ts
TranslationFn<CleanTranslation>
```

Kalitni tarjima qiladi, unga `params`ni interpolyatsiya qilib. Kalit yetishmasa `defaultValue`ni,
standart qiymat berilmagan bo'lsa esa kalitning o'zini qaytaradi.

```ts
// { "welcome": "Welcome, {name}!" }
$t('welcome', { name: 'Ada' }) // 'Welcome, Ada!'
$t('missing.key', {}, 'Fallback') // 'Fallback'
```

Ichki obyektga ishora qiluvchi kalit satrni emas, o'sha obyektni qaytaradi. Shablonda u `[object Object]` sifatida render qilinadi; barg kalitdan foydalaning.

### `$ts` {#$ts}

```ts
TranslationFn<string>
```

`$t` kabi, lekin har doim satr qaytaradi: qiymat `toString()` orqali o'tadi, shuning uchun ichki
obyekt `'[object Object]'`ga aylanadi. Kalitni bargga yo'naltiring.

### `$_t` {#$_t}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<CleanTranslation>
```

Joriy sahifadan tashqarida tarjima qilish uchun `$t`ni ma'lum marshrutga bog'laydi — masalan,
boshqa marshrutga havola render qilayotgan layout uchun.

```ts
const route = useRoute()
const t = useNuxtApp().$_t(route)
t('page.title')
```

### `$_ts` {#$_ts}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<string>
```

`$ts`ni ma'lum marshrutga bog'laydi. `$_t`ga qarang.

### `$tc` {#$tc}

```ts
(key: TranslationKey, params: number | Params, defaultValue?: string) => string
```

Ko'plik shakli bilan tarjima qiladi. `params` sonning o'zi yoki `count`ni o'z ichiga olgan
obyekt bo'lishi mumkin.

Shakllar `|` bilan ajratiladi. O'rnatilgan qoida bilan manfiy bo'lmagan butun son `n` `n`-shaklni tanlaydi, oxirgi shakl bilan cheklangan holda; manfiy, kasr yoki `NaN` son oxirgi shaklni oladi. `{count}` va boshqa parametrlar tanlangan shaklga interpolyatsiya qilinadi.

Ko'plik shakllari songa bog'liq bo'lmagan tillar uchun shablonni `=0 ` bilan boshlang. Shunda birinchi shakl 0 uchun bo'ladi, qolganlari esa [`Intl.PluralRules`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/PluralRules) kategoriyasi bo'yicha, `zero, one, two, few, many, other` tartibida bo'ladi:

```json
{
  "apples": "=0 no apples | one apple | {count} apples",
  "files": "=0 no files | {count} one | {count} few | {count} many"
}
```

```ts
$tc('apples', 0) // 'no apples'
$tc('apples', 1) // 'one apple'
$tc('apples', 7) // '7 apples'

// In `uk` (categories `one, few, many, other`) the forms after the zero form follow those categories:
$tc('files', 21) // '21 one'
$tc('files', 22) // '22 few'
$tc('files', 25) // '25 many'
$tc('files', 2.5) // '2.5 many': no form for `other`, so the last one
```

- `=0 ` faqat qiymatning eng boshida, bo'sh joy bilan birga hisobga olinadi. `$t` uni matn sifatida ko'rsatadi: u ko'plik shakllariga tegishli.
- O'z shakli bo'lmagan kategoriya oxirgi shaklni oladi. Manfiy yoki kasr son ham oxirgi shaklni oladi.
- U istalgan lokalda ishlaydi: ingliz tilida `=0 none | one | {count} many`.
- Kategoriya lokalning `iso`sidan, aks holda uning kodidan olinadi. `Intl` bilmaydigan kod indeks qoidasiga qaytadi, belgi baribir olib tashlanadi, shuning uchun natija hech qachon mashinaga bog'liq bo'lmaydi.
- `<i18n-t :plural>` xuddi shu qoidaga amal qiladi. Maxsus [`plural`](/uz/api/module-options#plural) yoki `customPluralRule` xom qiymatni, belgi bilan birga, oladi va o'zi qaror qiladi; `null` qaytargan `plural` chaqiruvni belgini hisobga oladigan o'rnatilgan qoidaga qaytaradi.

Belgisiz shablon indeks qoidasida qoladi, faqat bir ma'noda o'qiladigan bitta istisno bundan mustasno: o'rinbosarsiz nol shakli, so'ngra har bir kategoriya uchun bitta shakl, bir nechta son baham ko'radigan har bir shaklda `{count}` bilan (`uk`da `no files | {count} one | {count} few | {count} many`).

O'z qoidalaringiz uchun [`plural`](/uz/api/module-options#plural)ni o'rnating.

```ts
// { "apples": "no apples | one apple | {count} apples" }
$tc('apples', 0) // 'no apples'
$tc('apples', 10) // '10 apples'
$tc('cart', { count: 2, name: 'Ada' }) // count and params in one object
```

Uchinchi argument — parametrlar emas, `defaultValue`.

### `$has` {#$has}

```ts
(key: string) => boolean
```

Kalit faol lokalda aniqlanadimi. Xom kalitni render qilish o'rniga ixtiyoriy matnga qarab
tarmoqlanish uchun undan foydalaning. `$t` kabi, u ham bir xil lokal ichidagi sahifa o'tishi
paytida chiqib ketayotgan sahifaning kalitlarini ko'radi.

```ts
if ($has('promo.banner')) show.value = true
```

## Formatlash {#formatting}

### `$tn` {#$tn}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Sonni faol lokalda `Intl.NumberFormat` bilan formatlaydi. Kalit konfiguratsiyadan nomlangan
formatni tanlaydi.

Nomlangan formatlar [`numberFormats`](/uz/api/module-options#numberformats)dan olinadi.

```ts
$tn(1234.5, { style: 'currency', currency: 'EUR' }) // '1.234,50 €' in de
$tn(1000, 'currency') // named format
$tn(1000, 'currency', 'de') // named format in another locale
```

### `$td` {#$td}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Sanani faol lokalda `Intl.DateTimeFormat` bilan formatlaydi. Kalit konfiguratsiyadan nomlangan
formatni tanlaydi.

Nomlangan formatlar [`datetimeFormats`](/uz/api/module-options#datetimeformats)dan olinadi.

```ts
$td(new Date(), { dateStyle: 'long' })
$td(post.createdAt, 'short')
```

### `$tdr` {#$tdr}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

Sanani `Intl.RelativeTimeFormat` bilan nisbiy vaqt ("3 kun oldin") sifatida formatlaydi.

```ts
$tdr(Date.now() - 5 * 60_000) // '5 minutes ago' in en
```

## Almashtirish va havolalar {#switching-and-links}

### `$switchLocale` {#$switchlocale}

```ts
(locale: string) => Promise<boolean>
```

Joriy sahifaning boshqa lokaldagi versiyasiga o'tadi. `no_prefix` va hash rejimida u navigatsiyadan
oldin lokal tarjimalarini yuklaydi; `no_prefix` ostida marshrut joyida almashtiriladi (yangi
tarix yozuvisiz). Noma'lum lokal e'tiborsiz qoldiriladi.
Chaqiruv asinxron: navigatsiyadan keyin kodni ishga tushirish uchun uni `await` qiling. Lokal
lug'ati faol bo'lganda u `true`, bo'lmaganda `false` bilan yakunlanadi: chunk yuklanmadi (joriy
lug'at qoladi; qayta urinish uchun uni yana chaqiring) yoki yangiroq almashtirish g'olib bo'ldi.

```ts
await $switchLocale('de')
```

### `$switchLocalePath` {#$switchlocalepath}

```ts
(locale: string) => string
```

Joriy sahifaning boshqa lokaldagi yo'li, navigatsiyasiz.

```vue
<NuxtLink :to="$switchLocalePath('de')">Deutsch</NuxtLink>
```

### `$switchLocaleRoute` {#$switchlocaleroute}

```ts
(locale: string) => RouteLocationRaw
```

Joriy sahifaning boshqa lokaldagi marshrut obyekti, navigatsiyasiz, yoki o'z `baseUrl`iga ega
lokal uchun URL satri. `trailingSlash` ostida obyektda qoidaga muvofiq `path` va `fullPath` bo'ladi,
`query` va `hash` esa o'z holicha, `router.push` yoki havola ularni saqlab qoladi.

### `$switchRoute` {#$switchroute}

```ts
(route: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, toLocale?: string) => Promise<void>
```

Faol lokalni saqlagan holda yoki `toLocale`ga almashtirib boshqa marshrutga o'tadi. `$switchLocale`
kabi asinxron.

```ts
$switchRoute('/about') // active locale
$switchRoute({ name: 'about' }, 'de') // switch to de
```

### `$localePath` {#$localepath}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => string
```

Yo'lni berilgan lokalda yoki faol lokalda aniqlaydi. `http(s):`, `mailto:` yoki `tel:` sxemali
satr o'z holicha qaytadi: foydalanuvchi kiritgan ma'lumotni tekshirmasdan havola maqsadi sifatida uzatmang.

Satr ko'rinishidagi yo'l u ko'rsatadigan sahifa sifatida o'qiladi, shuning uchun lokalning maxsus yo'li ham qo'llaniladi.

```ts
$localePath('/about') // '/about' in en, '/de/ueber-uns' in de with localeRoutes
$localePath({ name: 'about' }, 'fr') // '/fr/about'
```

### `$localeRoute` {#$localeroute}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => RouteLocationResolved
```

Marshrutni berilgan lokalda yoki faol lokalda aniqlaydi. Holatda saqlash xavfsiz bo'lgan oddiy obyekt. Parametrni
ekranlash kerak bo'lganda, unda `path`, `fullPath`, `query` va `hash` bo'ladi, lekin `name` yoki `params` bo'lmaydi: routerga
kodlangan URL'ni aynan yo'l beradi. Boshqa domendagi lokal uchun `path` va `fullPath` mutlaq bo'ladi, router esa ularni qabul qila olmaydi:
bunday havola `<i18n-link>` yoki `$localePath` orqali o'tadi.

### `$getRouteName` {#$getroutename}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric, locale?: string) => string
```

Lokal prefiksi olib tashlangan marshrut nomi — tarjimalar shu nom bo'yicha kalitlanadi.

```ts
$getRouteName() // 'about' on /de/about
```

## Sahifa konfiguratsiyasi {#page-config}

### `$defineI18nRoute` {#$definei18nroute}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Komponent ichidan har bir sahifa uchun lokal konfiguratsiyasi va tarjimalarini ro'yxatdan o'tkazadi.
Faol lokalga birlashtiradi va lokal o'zgarganda qayta qo'llaydi.

Uni sahifaning `<script setup>` ichida, har doim `useNuxtApp()`dan destrukturizatsiya qilib chaqiring. Build chaqiruvdan `locales`, `localeRoutes` va `disableMeta`ni o'qiydi; runtime'da faqat `locales` ahamiyatga ega (inline tarjimalar faol lokal uchun birlashtiriladi). To'liq qoidalar: [Sahifa konfiguratsiyasi](/uz/guide/per-component-translations).

```vue
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'de'],
  localeRoutes: { en: '/about', de: '/ueber-uns' },
})
</script>
```

### `$setI18nRouteParams` {#$seti18nrouteparams}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Joriy marshrut uchun har bir lokalga parametrlarni o'rnatadi, shunda dinamik segment har bir tilda farq qilishi mumkin.
Uni SSR paytida, head render qilinishidan oldin chaqiring.

Boshqa yo'lga navigatsiya amalga oshganda parametrlar tozalanadi, jumladan marshrut nomini saqlaydigan `/news/1`dan `/news/4`ga o'tishda ham. Tafsilotlar: [Lokallashtirilgan yo'llar](/uz/guide/custom-locale-routes).

```ts
$setI18nRouteParams({
  en: { slug: 'my-post' },
  de: { slug: 'mein-beitrag' },
})
```

## Runtime tarjimalari {#runtime-translations}

### `$mergeTranslations` {#$mergetranslations}

```ts
(newTranslations: Translations) => void
```

Tarjimalarni runtime'da faol lokalga birlashtiradi, yuklanganini qayta belgilagan holda.

Faol lokalning joriy sahifa chunk'iga chuqur birlashtiradi; u tilga olmagan kalitlar saqlanib qoladi.

```ts
$mergeTranslations({ banner: { title: 'Sale' } })
```

### `$setTranslation` {#$settranslation}

```ts
(key: string, value: unknown) => void
```

Faol lug'atdagi `key` qiymatini almashtiradi. Bu birlashtirish emas, almashtirish —
mavjud qo'shni kalitlar saqlanishi kerak bo'lsa, `$mergeTranslations`dan foydalaning.

```ts
$setTranslation('banner', { title: 'Sale' }) // drops other keys under banner
$setTranslation('banner.title', 'Sale') // dotted path
```

### `$loadPageTranslations` {#$loadpagetranslations}

```ts
(locale: string, routeName: string, translations: Translations) => Promise<void>
```

Kalitlari build vaqtida noma'lum bo'lgan kontent uchun sahifa tarjimalarini runtime'da yuklaydi.

Xotiradagi `(locale, routeName)` chunk'iga birlashtiradi va o'sha chunk faol bo'lganda ekran yangilanadi. Bu yerda hech qanday payload yuklab olinmaydi: hali yuklanmagan sahifa uchun tarjimalar kutib turadi va uning fayli yuklanganda ular uning ustida qoladi.

```ts
await $loadPageTranslations('en', 'about', { title: 'About us' })
```

### `$resolveTranslations` {#$resolvetranslations}

```ts
() => Translations
```

Faol lokal va marshrut uchun hozirda xotirada bo'lgan barcha tarjimalar, daraxt ko'rinishida.
`$t()` hozir aniqlay oladigan narsalarning faqat o'qish uchun ko'rinishi.

Natijaga faqat o'qish uchun deb qarang.

### `$setMissingHandler` {#$setmissinghandler}

```ts
(handler: MissingHandler | null) => void
```

Har bir aniqlanmagan kalit uchun chaqiriladigan callback'ni o'rnatadi. Uni olib tashlash uchun `null`ni uzating.

Ishlovchi dev ogohlantirishi o'rniga ishga tushadi.

```ts
$setMissingHandler((locale, key, routeName) => {
  console.error(`[i18n] missing ${key} in ${locale} (${routeName})`)
})
```

### `$clearCache` {#$clearcache}

```ts
() => void
```

Barcha keshlangan tarjima chunk'larini tashlab yuboradi va joriy sahifa lug'atini qayta yuklaydi. Yangilari
kelguncha sahifa joriy tarjimalarini ko'rsatishda davom etadi. Dev HMR uni har bir tarjima fayli
o'zgarganda chaqiradi.

```ts
const { clearCache } = useI18n()
clearCache()
```

Muvaffaqiyatsiz qayta yuklash joriy lug'atni saqlab qoladi.
