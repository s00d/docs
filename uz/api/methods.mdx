# 🛠️ Metodlar

## 🔍 Tarjima metodlari

Tarjimalarni olish va boshqarish uchun asosiy metodlar.

### `$t`

{/* generated:method:$t — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Kalitni tarjima qilish, unga `params` ni interpolyatsiya qilib. Kalit topilmaganda `defaultValue` ni qaytaradi, standart qiymat berilmagan boʻlsa, kalitning oʻzini qaytaradi.

{/* /generated:method:$t */}

```typescript
const welcomeMessage = $t('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

<Warning>
`$t` `CleanTranslation` ni qaytaradi, bu `string | number | boolean | Translations | PluralTranslations | null` degani. Agar kalit JSON dagi **ichma-ich obyektga** ishora qilsa (masalan, `$t('header')` JSON `\{ "header": \{ "title": "Hi" \} \}` ni oʻz ichiga olganda), qaytish qiymati oʻsha **obyekt** boʻladi, satr emas. Uni Vue shablonida (<code v-pre>\{\{ $t('header') \}\}</code>) toʻgʻridan-toʻgʻri ishlatish `[object Object]` sifatida chiqadi.

**Buni oldini olish uchun:**

- Aniqroq kalit ishlating: `$t('header.title')` → `"Hi"`
- Har doim satr qaytaradigan `$ts()` dan foydalaning (satr boʻlmaganlar uchun `.toString()` chaqiradi)
- Dasturiy foydalanish uchun sub-obyektlarga qasddan kirish uchun `$t` ni ichma-ich kalit bilan ishlating
</Warning>

### `$ts`

{/* generated:method:$ts — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string) => string
```

`$t` ga oʻxshash, lekin har doim satr qaytaradi: obyekt yoki massiv qiymati oʻz holicha qaytarilmasdan, satrga aylantiriladi.

{/* /generated:method:$ts */}

```typescript
const welcomeMessage = $ts('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

### `$_t` va `$_ts`

{/* generated:method:$_t — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

`$t` ni muayyan marshrutga bogʻlash, joriy sahifadan tashqarida tarjima qilish uchun. Masalan, boshqa marshrutga havolani renderlaydigan layout.

{/* /generated:method:$_t */}

{/* generated:method:$_ts — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => string
```

`$ts` ni muayyan marshrutga bogʻlash. `$_t` ga qarang.

{/* /generated:method:$_ts */}

`$t` va `$ts` ning marshrutga bogʻlangan variantlari. Ular avval **marshrut** ni oladi va oʻsha marshrutning locale va sahifa kontekstiga bogʻlangan tarjima funksiyasini qaytaradi.

- **Kirish**: `useNuxtApp()` (shuningdek `useI18n()` tomonidan `$_t` / `$_ts` sifatida qayta eksport qilinadi)

Ularni SSR yoki oʻtish paytida faol marshrut `router.currentRoute` dan farq qilganda ishlating. Masalan, `<i18n-t>`, `<i18n-group>` ichida yoki muayyan `route` obyekti uchun kontentni renderlaganda.

```typescript
import { useRoute, useNuxtApp } from '#imports'

const route = useRoute()
const { $_t, $_ts } = useNuxtApp()

const $t = $_t(route)
const title = $t('page.title')

// String-safe variant
const label = $_ts(route)('page.label')
```


### `$tc`

{/* generated:method:$tc — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params: number | Params, defaultValue?: string) => string
```

Koʻplik bilan tarjima qilish. `params` sonning oʻzi yoki `count` ni oʻz ichiga olgan obyekt boʻlishi mumkin.

{/* /generated:method:$tc */}

**Tarjima formati**: `|` bilan ajratilgan shakllar. Placeholderlarni **har bir** shaklda qoʻying:

```json
{
  "apples": "no apples | one apple | {count} apples",
  "cart": "no items for {name} | one item for {name} | {count} items for {name}"
}
```

```typescript
$tc('apples', 0) // "no apples"
$tc('apples', 1) // "one apple"
$tc('apples', 10) // "10 apples"

// count + other params (second argument must be an object)
$tc('cart', { count: 10, name: 'Alice' }) // "10 items for Alice"
```


**Komponent muqobili** — `<i18n-t keypath="cart" :plural="count" :params="\{ name \}" />` (`count` ni `params` bilan ichkarida birlashtiradi).

```ts
(newTranslations: Translations) => void
```

Ishlash paytida tarjimalarni faol locale’ga birlashtirish, yuklangan qiymatlarni almashtirib.

{/* /generated:method:$mergeTranslations */}

### `$resolveTranslations`

{/* generated:method:$resolveTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
() => Translations
```

Faol locale va marshrut uchun xotirada boʻlgan barcha tarjimalar, daraxt shaklida.
`$t()` hozir hal qila oladigan narsalarning faqat oʻqish uchun koʻrinishi.

{/* /generated:method:$resolveTranslations */}

```typescript
const tree = $resolveTranslations()
// { aaa: { bbb: 'ccc' }, ddd: 1111 } — the same dictionary $t() reads from
```

Xotiradagi toʻliq lugʻat kerak boʻlganda ushbu metoddan foydalaning (DevTools, testlar, runtime muharrirlari). Qaytish qiymatini faqat oʻqish uchun deb hisoblang; qiymatlarni `$setTranslation` orqali oʻzgartiring yoki `$mergeTranslations` bilan patchlarni birlashtiring.

### `$setTranslation`

{/* generated:method:$setTranslation — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, value: unknown) => void
```

Faol lugʻatdagi `key` qiymatini almashtirish. Bu almashtirish, birlashtirish emas.
Mavjud yondosh kalitlar saqlanishi kerak boʻlsa, `$mergeTranslations` dan foydalaning.

{/* /generated:method:$setTranslation */}

```typescript
$setTranslation('aaa', { fff: 'ggg' }) // replaces the whole `aaa` subtree
$setTranslation('aaa', 'text')          // replaces `aaa` with a string
$setTranslation('ddd', 1111)            // scalar at the top level
$setTranslation('aaa.bbb', 'nested')    // dotted path
```

Bu **almashtirish**, birlashtirish emas. Oʻsha kalit ostidagi mavjud yondosh kalitlar olib tashlanadi. Yondosh kalitlarni yoʻqotmasdan patchlash uchun `$mergeTranslations` dan foydalaning.

### `$setMissingHandler`

{/* generated:method:$setMissingHandler — do not edit; run `pnpm run docs:generate` */}

```ts
(handler: MissingHandler | null) => void
```

Har bir hal qilinmagan kalit uchun chaqiriladigan callback’ni oʻrnatish. Uni olib tashlash uchun `null` uzating.

{/* /generated:method:$setMissingHandler */}

**Tur taʼrifi**:

```typescript
type MissingHandler = (locale: string, key: string, routeName: string, instance?: unknown, type?: string) => void
```

```typescript
// Set a custom handler
$setMissingHandler((locale, key, routeName) => {
  console.error(`Missing translation: ${key} in ${locale} for route ${routeName}`)
  // Send to Sentry or other error tracking service
  // Sentry.captureMessage(`Missing translation: ${key}`)
})

// Remove the handler
$setMissingHandler(null)
```

**Foydalanish holatlari**:

- Yoʻqolgan tarjimalarni xatolarni kuzatish xizmatlariga (Sentry, LogRocket va h.k.) loglash
- Yoʻqolgan tarjimalar boʻyicha analitikani yigʻish
- Yoʻqolgan tarjima kalitlari uchun maxsus xatolarni boshqarish

## 🔢 Raqam va sana formatlash

Locale konvensiyalariga muvofiq raqamlar va sanalarni formatlash uchun metodlar.

### `$tn`

{/* generated:method:$tn — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Faol locale’da `Intl.NumberFormat` yordamida raqamni formatlash. Kalit konfiguratsiyadan nomlangan formatni tanlaydi.

{/* /generated:method:$tn */}

```typescript
// Inline options
const formattedNumber = $tn(1234567.89, { style: 'currency', currency: 'USD' })
// "$1,234,567.89"

// Named format (from nuxt.config i18n.numberFormats)
const price = $tn(1000, 'currency')
const priceDe = $tn(1000, 'currency', 'de')
const compact = $tn(1000, 'currency', { notation: 'compact' })
```

Nomaʼlum nomlangan format kalitlari standart `Intl.NumberFormat` parametrlariga qaytadi. Ishlab chiqishda (mijoz) `missingWarn` yoqilgan boʻlsa (standart), `console.warn` chiqariladi.

**Konfiguratsiya misoli**:

```ts
export default defineNuxtConfig({
  i18n: {
    numberFormats: {
      en: {
        currency: { style: 'currency', currency: 'USD' },
        decimal: { style: 'decimal', minimumFractionDigits: 2, maximumFractionDigits: 2 },
      },
      de: {
        currency: { style: 'currency', currency: 'EUR' },
      },
    },
  },
})
```

**Foydalanish holatlari**:

- Raqamlarni valyuta, foizlar yoki oʻnli sonlar sifatida mos locale formatida formatlash
- Nomlangan formatlarni ilova boʻylab qayta ishlatish (Vue I18n koʻchirish parity)

### `$td`

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

**Foydalanish holatlari**:

{/* generated:method:$switchRoute — do not edit; run `pnpm run docs:generate` */}


Boshqa marshrutga oʻtish, faol locale’ni saqlab yoki `toLocale` ga oʻzgartirib.

{/* /generated:method:$switchRoute */}

**Misollar**:

<CodeGroup>
```typescript String Path

```




## 🌐 Marshrut yaratish

Mahalliylashtirilgan marshrutlar va yoʻllarni yaratish uchun metodlar.

### `$localeRoute`

{/* generated:method:$localeRoute — do not edit; run `pnpm run docs:generate` */}



## 🚦 Marshrut konfiguratsiyasi

Marshrut xatti-harakatlarini va kirishni boshqarishni sozlash uchun metodlar.

### `$defineI18nRoute`

{/* generated:method:$defineI18nRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Komponent ichidan sahifa boʻyicha locale konfiguratsiyasi va tarjimalarni roʻyxatdan oʻtkazish.
Faol locale’ga birlashtiradi va locale oʻzgarganda qayta qoʻllaydi.

{/* /generated:method:$defineI18nRoute */}

> [!IMPORTANT]
> `$defineI18nRoute` **define plagini** tomonidan taqdim etiladi va faqat `useNuxtApp()` da mavjud. U `useI18n()` qaytish obyektining qismi **emas**.
> Uni har doim `script setup` ichida `useNuxtApp()` dan destructure qiling. `$defineI18nRoute(...)` ni yalangʻoch global sifatida chaqirsangiz, SSR/prerender paytida `"$defineI18nRoute is not defined"` xatosi paydo boʻladi.

**Parametrlar**:

- **locales**: `string[] | Record<string, Record<string, string>>` — marshrut uchun mavjud locale’lar
- **localeRoutes**: `Record<string, string>` — ixtiyoriy. Muayyan locale’lar uchun maxsus marshrutlar
- **disableMeta**: `boolean | string[]` — ixtiyoriy. Barcha yoki muayyan locale’lar uchun i18n meta teglarini oʻchiradi

**Asosiy misol**:

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr', 'de'],
  localeRoutes: {
    en: '/welcome',
    fr: '/bienvenue',
    de: '/willkommen',
  },
  disableMeta: false,
})
```

> 📖 **Batafsil foydalanish misollari, konfiguratsiya formatlari va eng yaxshi amaliyotlar uchun [Komponent boʻyicha tarjimalar qoʻllanmasi](/guides/per-component-translations) ga qarang.**

### `$setI18nRouteParams`

{/* generated:method:$setI18nRouteParams — do not edit; run `pnpm run docs:generate` */}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Joriy marshrut uchun locale boʻyicha parametrlarni oʻrnatish, shunda dinamik segment til boʻyicha farq qilishi mumkin.
Uni SSR paytida, head renderlanmasdan oldin chaqiring.

{/* /generated:method:$setI18nRouteParams */}

```typescript
// in pages/news/[id].vue
// for en/news/1-first-article
const { $switchLocaleRoute, $setI18nRouteParams, $defineI18nRoute } = useNuxtApp()
$defineI18nRoute({
  localeRoutes: {
    en: '/news/:id()',
    fr: '/nouvelles/:id()',
    de: '/Nachricht/:id()',
  },
})
const { data: news } = await useAsyncData(`news-${params.id}`, async () => {
  let response = await $fetch("/api/getNews", {
    query: {
      id: params.id,
    },
  });
  if (response?.localeSlugs) {
    response.localeSlugs = {
      en: {
        id: '1-first-article'
      }
      fr: {
        id: '1-premier-article'
      }
      de: {
        id: '1-erster-Artikel'
      }
    }
    $setI18nRouteParams(response?.localeSlugs);
  }
  return response;
});
$switchLocalePath('fr') // === 'fr/nouvelles/1-premier-article'
$switchLocalePath('de') // === 'de/Nachricht/1-erster-Artikel'
```

## 🧭 `useI18nLocale` composable’i

Locale holatini boshqarish uchun markazlashtirilgan composable. `useState('i18n-locale')` yoki `useCookie('user-locale')` ni toʻgʻridan-toʻgʻri boshqarish oʻrniga undan foydalaning.

```typescript
const {
  setLocale, // (locale: string) => void — updates state + cookie
  getLocale, // () => string | null — from state or cookie
  getPreferredLocale, // () => string | null — validated against locales list
  getEffectiveLocale, // (route, getLocaleFromRoute) => string
  resolveInitialLocale, // (options) => string
  isValidLocale, // (locale) => boolean
  locale, // Ref<string | null> — reactive state
  localeCookie, // CookieRef — reactive cookie
  syncLocale, // (locale) => void — sync to cookie only
  validLocales, // string[] — list of valid locale codes
} = useI18nLocale()
```

### Asosiy metodlar

| Metod                  | Tavsif                                                 |
| ----------------------- | ----------------------------------------------------------- |
| `setLocale(locale)`     | Locale’ni `useState` va cookie’da atomik ravishda oʻrnatadi        |
| `getLocale()`           | Holat yoki cookie dan joriy locale’ni qaytaradi                 |
| `getPreferredLocale()`  | `locales` roʻyxatiga qarshi tasdiqlangan locale’ni qaytaradi yoki `null`  |
| `isValidLocale(locale)` | Locale kodi sozlangan `locales` roʻyxatida borligini tekshiradi |
