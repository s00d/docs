[CLI qo'llanmasi](/uz/guide/cli) keng tarqalgan ish jarayonlarini ko'rsatadi. Bu sahifa hammasini sanab o'tadi va `--help` ni boshqaradigan o'sha jadvaldan yaratiladi.

## Umumiy flaglar {#common-flags}

| Flag | Standart qiymat | Tavsif |
| --- | --- | --- |
| `--cwd` | joriy katalog | Loyiha katalogi |
| `--logLevel` | `info` | Chiqish darajasi: silent, info |
| `--debug` | `false` | Buyruq muvaffaqiyatsiz tugaganda stack trace chiqarish |

## Tekshirish {#inspect}

### `info` {#info}

Loyihaning aniqlangan i18n konfiguratsiyasini chiqarish

| Flag | Standart qiymat | Tavsif |
| --- | --- | --- |
| `--json` | `false` | Matn o'rniga JSON chiqarish |

### `check` {#check}

CI darvozasi: yetishmayotgan, bo'sh, ortiqcha, aniqlanmagan yoki ishlatilmagan kalitlar va buzilgan o'rinbosarlar bo'lsa, xato bilan tugaydi

| Flag | Standart qiymat | Tavsif |
| --- | --- | --- |
| `--translationDir` | nuxt.config dagi `i18n.translationDir` | Tarjimalar katalogi, loyihaga nisbatan |
| `--only` | duplicates dan tashqari hammasi | Bajariladigan tekshiruvlar, vergul bilan ajratilgan: missing, empty, extra, placeholders, undefined, unused, duplicates. Bu yerda ko'rsatilgan `unused` ishga tusha olmasa, xato beradi |
| `--duplicates` | `false` | Turli kalitlar ostidagi bir xil matnni ham xabar qilish |
| `--ignore` | — | O'tkazib yuboriladigan manba fayllar globlari, vergul bilan ajratilgan, loyihaga nisbatan |
| `--json` | `false` | Matn o'rniga JSON chiqarish |

```bash
i18n-micro check
i18n-micro check --only missing,placeholders --json
```

### `stats` {#stats}

Har bir locale bo'yicha tarjimalar to'liqligini ko'rsatish

| Flag | Standart qiymat | Tavsif |
| --- | --- | --- |
| `--translationDir` | nuxt.config dagi `i18n.translationDir` | Tarjimalar katalogi, loyihaga nisbatan |
| `--html` | — | Qo'shimcha ravishda ushbu faylga HTML hisobot yozish |
| `--json` | `false` | Matn o'rniga JSON chiqarish |
| `--baseRef` | — | To'liqlikni solishtirish uchun Git ref, masalan HEAD~1 yoki main |

```bash
i18n-micro stats --baseRef main
i18n-micro stats --html reports/i18n.html
```

### `lint` {#lint}

Tarjimalar matnini tekshirish; muammolar qolsa, xato bilan tugaydi

| Flag | Standart qiymat | Tavsif |
| --- | --- | --- |
| `--translationDir` | nuxt.config dagi `i18n.translationDir` | Tarjimalar katalogi, loyihaga nisbatan |
| `--rules` | hammasi yoki .i18n-lintrc.json dagi `enabledRules` | Bajariladigan qoidalar, vergul bilan ajratilgan: no-trailing-spaces, no-multiple-spaces, no-empty-translation yoki maxsus qoida |
| `--fix` | `false` | Tuzatish mumkin bo'lganini tuzatish: bo'shliqlar va almashtirishga ega maxsus qoidalar |
| `--json` | `false` | Matn o'rniga JSON chiqarish |

```bash
i18n-micro lint --rules no-trailing-spaces --fix
```

### `search` {#search}

Kalitlar va qiymatlarni qidirish hamda har bir kalit qayerda ishlatilishini ko'rsatish

| Flag | Standart qiymat | Tavsif |
| --- | --- | --- |
| `--translationDir` | nuxt.config dagi `i18n.translationDir` | Tarjimalar katalogi, loyihaga nisbatan |
| `<query>` | — | Qidiriladigan matn yoki kalit |
| `--caseSensitive` | `false` | Harf registrini hisobga olish |
| `--onlyUnused` | `false` | Faqat `clean` o'chiradigan kalitlar; so'rov ixtiyoriy bo'ladi |
| `--scope` | `all` | Qayerda qidirish: global, pages, all |
| `--limit` | — | Ko'pi bilan shuncha kalit qaytarish |
| `--ignore` | — | O'tkazib yuboriladigan manba fayllar globlari, vergul bilan ajratilgan, loyihaga nisbatan |
| `--json` | `false` | Matn o'rniga JSON chiqarish |

```bash
i18n-micro search "Welcome"
i18n-micro search --onlyUnused
```

## Tarjima ish jarayoni {#translation-workflow}

### `extract` {#extract}

Manba fayllar ishlatadigan, lekin hali matni yo'q kalitlarni sanab chiqish va standart matnga ega bo'lganlarini standart locale'ga qo'shish

| Flag | Standart qiymat | Tavsif |
| --- | --- | --- |
| `--translationDir` | nuxt.config dagi `i18n.translationDir` | Tarjimalar katalogi, loyihaga nisbatan |
| `--ignore` | — | O'tkazib yuboriladigan manba fayllar globlari, vergul bilan ajratilgan, loyihaga nisbatan |

```bash
i18n-micro extract
```

### `translate` {#translate}

Yetishmayotgan tarjimalarni standart locale'dan tarjima xizmati orqali to'ldirish

| Flag | Standart qiymat | Tavsif |
| --- | --- | --- |
| `--translationDir` | nuxt.config dagi `i18n.translationDir` | Tarjimalar katalogi, loyihaga nisbatan |
| `--service` | — | Tarjima xizmati: ai, azure, deepl, google, libretranslate, yandexcloud |
| `--token` | — | API kaliti. I18N_TRANSLATE_TOKEN muhit o'zgaruvchisini afzal ko'ring: flaglar shell tarixiga tushadi |
| `--options` | — | Xizmat parametrlari key:value juftliklari ko'rinishida, vergul bilan ajratilgan |
| `--locale` | standartdan tashqari barcha locale'lar | To'ldiriladigan locale'lar, vergul bilan ajratilgan |
| `--replace` | `false` | Har bir kalitni qaytadan tarjima qilib, mavjud qiymatlarni almashtirish |
| `--dryRun` | `false` | Har bir locale uchun kalitlar va belgilarni sanash; hech narsa yubormaslik |
| `--chunkSize` | — | Har bir so'rovdagi satrlar soni; xizmat qabul qiladigan miqdor bilan cheklanadi |
| `--pluralSeparator` | `\|` | Xabarlardagi ko'plik shakllari ajratgichi |
| `--glossaryFile` | mavjud bo'lsa `.i18n-glossary.json` | Lug'at fayli, `ai` xizmati tomonidan ishlatiladi |

```bash
i18n-micro translate --dryRun
I18N_TRANSLATE_TOKEN=... i18n-micro translate --service deepl --locale de,fr
i18n-micro translate --service ai --options provider:openai,model:gpt-4o-mini
i18n-micro translate --service libretranslate --options baseUrl:https://translate.example.com
```

### `sync` {#sync}

Standart locale'da yo'q kalitlarni o'chirish; buning xavfsizligini isbotlab bo'lmasa, to'xtaydi. Yetishmayotgan kalitlar yetishmayotganicha qoladi

| Flag | Standart qiymat | Tavsif |
| --- | --- | --- |
| `--translationDir` | nuxt.config dagi `i18n.translationDir` | Tarjimalar katalogi, loyihaga nisbatan |
| `--ignore` | — | O'tkazib yuboriladigan manba fayllar globlari, vergul bilan ajratilgan, loyihaga nisbatan |
| `--dryRun` | `false` | Nima o'chirilishini sanab chiqish; hech narsa yozmaslik |
| `--force` | `false` | Xavfsizligini isbotlab bo'lmasa ham kalitlarni o'chirish |

```bash
i18n-micro sync --dryRun
```

### `clean` {#clean}

Loyihada hech narsa ishlatmaydigan kalitlarni o'chirish; buni isbotlab bo'lmasa, to'xtaydi

| Flag | Standart qiymat | Tavsif |
| --- | --- | --- |
| `--translationDir` | nuxt.config dagi `i18n.translationDir` | Tarjimalar katalogi, loyihaga nisbatan |
| `--include` | — | Muntazam ifoda: o'chirish uchun faqat mos keladigan kalitlarni ko'rib chiqish |
| `--exclude` | — | Muntazam ifoda: mos keladigan kalitlarni hech qachon o'chirmaslik |
| `--ignore` | — | O'tkazib yuboriladigan manba fayllar globlari, vergul bilan ajratilgan, loyihaga nisbatan |
| `--dryRun` | `false` | Nima o'chirilishini sanab chiqish; hech narsa yozmaslik |
| `--force` | `false` | Hammasi uchun foydalanishni isbotlab bo'lmasa ham kalitlarni o'chirish |

```bash
i18n-micro clean --dryRun
i18n-micro clean --exclude '^errors\.'
```

## Refaktoring {#refactoring}

### `text-to-i18n` {#text-to-i18n}

Vue shablonlaridagi qattiq yozilgan matnni tarjima chaqiruvlari bilan almashtirish va koddagi qattiq yozilgan matn haqida xabar berish

| Flag | Standart qiymat | Tavsif |
| --- | --- | --- |
| `--translationFile` | `<translationDir>/<defaultLocale>.json` | Yangi kalitlar yoziladigan fayl |
| `--path` | butun loyiha | Qayta ishlanadigan fayl yoki katalog |
| `--context` | — | Yaratilgan kalitlar uchun prefiks |
| `--ignore` | — | O'tkazib yuboriladigan manba fayllar globlari, vergul bilan ajratilgan, loyihaga nisbatan |
| `--dryRun` | `false` | Nima o'zgarishini ko'rsatish; hech narsa yozmaslik |
| `--interactive` | `false` | Har bir yaratilgan kalitni tasdiqlash yoki tahrirlash |

```bash
i18n-micro text-to-i18n --dryRun
i18n-micro text-to-i18n --path components --context ui
```

### `rename` {#rename}

Kalit yoki nom maydonini barcha locale'larda va manba fayllarda qayta nomlash

| Flag | Standart qiymat | Tavsif |
| --- | --- | --- |
| `--translationDir` | nuxt.config dagi `i18n.translationDir` | Tarjimalar katalogi, loyihaga nisbatan |
| `--from` **\*** | — | Joriy kalit yoki nom maydoni |
| `--to` **\*** | — | Yangi kalit yoki nom maydoni |
| `--ignore` | — | O'tkazib yuboriladigan manba fayllar globlari, vergul bilan ajratilgan, loyihaga nisbatan |
| `--dryRun` | `false` | O'zgarishlar haqida xabar berish; hech narsa yozmaslik |

**\*** majburiy.

```bash

```

| `--sourceLocale` | standart locale | O'qiladigan locale |

### `format` {#format}

Locale fayllarini saralangan kalitlar va bir xil chekinish bilan qayta yozish

| Flag | Standart qiymat | Tavsif |
| --- | --- | --- |
| `--translationDir` | nuxt.config dagi `i18n.translationDir` | Tarjimalar katalogi, loyihaga nisbatan |
| `--indent` | `2` | Chekinish bo'shliqlari soni |
| `--sortKeys` | `true` | Kalitlarni saralash; tartibini saqlash uchun --no-sortKeys dan foydalaning |
| `--check` | `false` | Fayl o'zgaradigan bo'lsa, xato berish; hech narsa yozmaslik |

```bash
i18n-micro format --check
```

## Almashinuv {#exchange}

### `export` {#export}

Locale fayllarini PO yoki CSV ga eksport qilish, standart locale matni manba sifatida

| Flag | Standart qiymat | Tavsif |
| --- | --- | --- |
| `--translationDir` | nuxt.config dagi `i18n.translationDir` | Tarjimalar katalogi, loyihaga nisbatan |
| `--format` | `po` | Fayl formati: po, csv |
| `--dir` | po uchun `pots`, csv uchun `csv_exports` | Chiqish katalogi, loyihaga nisbatan |
| `--force` | `false` | Oxirgi eksportdan beri o'zgargan va hech qachon import qilinmagan fayllarni qayta yozish |

```bash
i18n-micro export --format csv
```

### `import` {#import}

PO yoki CSV fayllarini locale fayllariga birlashtirish

| Flag | Standart qiymat | Tavsif |
| --- | --- | --- |
| `--translationDir` | nuxt.config dagi `i18n.translationDir` | Tarjimalar katalogi, loyihaga nisbatan |
| `--format` | `po` | Fayl formati: po, csv |
| `--dir` | po uchun `pots`, csv uchun `csv_exports` | Kirish katalogi, loyihaga nisbatan |
| `--dryRun` | `false` | Nima import qilinishi haqida xabar berish; hech narsa yozmaslik |

```bash
i18n-micro import --format csv --dryRun
```

### `sync-remote` {#sync-remote}

Global tarjimalarni .i18n-remote.json dagi HTTP endpoint'dan tortib olish yoki unga yuborish

| Flag | Standart qiymat | Tavsif |
| --- | --- | --- |
| `--translationDir` | nuxt.config dagi `i18n.translationDir` | Tarjimalar katalogi, loyihaga nisbatan |
| `--pull` | `true` | Masofaviy manbadan tortib olish |
| `--push` | `false` | Masofaviy manbaga yuborish |
| `--force` | `false` | Pull paytida masofaviy qiymatni olish; push paytida faqat masofaviy manbadagi matnni qayta yozish |
| `--dryRun` | `false` | Pull nimani o'zgartirishi haqida xabar berish; hech narsa yozmaslik va yubormaslik |

```bash
i18n-micro sync-remote --dryRun
i18n-micro sync-remote --no-pull --push
```

## Lint qoidalari {#lint-rules}

| Qoida | Nimani topadi | `--fix` bilan tuzatiladi |
| --- | --- | --- |
| `no-trailing-spaces` | Qiymat yoki qator oxiridagi bo'shliqlar | ha |
| `no-multiple-spaces` | Ketma-ket ikki yoki undan ortiq bo'shliq | ha |
| `no-empty-translation` | Bo'sh yoki faqat bo'shliqlardan iborat qiymat | yo'q |

## Chiqish kodlari {#exit-codes}

| Kod | Ma'nosi |
| --- | --- |
| `0` | Bajarildi, xabar qilinadigan narsa yo'q |
| `1` | Topilmalar: `check`, `lint` yoki `format --check` nimadir topdi, `clean` yoki `sync` o'chirish xavfsizligini isbotlay olmadi, `export` import qilinmagan ishni qayta yozadigan bo'ldi, `translate` kalitlarni tashlab ketdi, `import` yoki `sync-remote` ziddiyatga duch keldi, `sync-remote` push masofaviy matnni yo'qotadigan bo'ldi. `clean`, `sync` yoki `sync-remote` pull'ning `--dryRun` rejimi bular haqida xabar beradi va `0` bilan chiqadi |
| `2` | Muvaffaqiyatsizlik: noto'g'ri foydalanish, o'qib bo'lmaydigan loyiha, tarmoq yoki fayl xatosi |

## Konfiguratsiya fayllari {#configuration-files}

| Fayl | Kim ishlatadi |
| --- | --- |
| `.i18n-lintrc.json` | `lint`: `enabledRules`, `disabledRules`, `customRegexRules` (`name`, `pattern`, `flags`, `description`, `replacement`) |
| `.i18n-remote.json` | `sync-remote`: `url`, `path`, `token`, `auth` (`username`, `password`). `type` ni tashlab ketish mumkin; faqat `custom` mavjud |
| `.i18n-glossary.json` | `translate --service ai`: `source`, `target` va ixtiyoriy `from`, `to` dan iborat `entries` |

## Muhit o'zgaruvchilari {#environment-variables}

| Nomi | Nima uchun ishlatiladi |
| --- | --- |
| `I18N_TRANSLATE_TOKEN` | `translate` ning API kaliti. `.env` dan ham o'qiladi |
| `I18N_REMOTE_TOKEN` | `sync-remote` ning Bearer tokeni. `.env` dan ham o'qiladi |
| `AI_GATEWAY_API_KEY, OPENAI_API_KEY, ANTHROPIC_API_KEY` | `I18N_TRANSLATE_TOKEN` o'rnatilmaganda `ai` xizmatining kaliti |
| `DEFAULT_LOCALE` | Moduldagi kabi `defaultLocale` ni bekor qiladi |
