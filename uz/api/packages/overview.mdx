title: "Paket API'lari"
description: "Har bir @i18n-micro/* paketining eksport qilingan API'si, CI manba kodga nisbatan tekshiradigan API snapshotlaridan generatsiya qilingan."
---

Nuxt moduli kichik `@i18n-micro/*` paketlaridan qurilgan va ularning aksariyati mustaqil ishlaydi: `@i18n-micro/vue` Vue ilovasida, `@i18n-micro/core` esa istalgan joyda. Paket har bir kirish nuqtasi bo'yicha nimani eksport qilishini bilish uchun ushbu sahifalardan foydalaning. Har bir sahifa [`pnpm run api:surface`](https://s00d.github.io/nuxt-i18n-micro/contributing/maintenance-commands#api-surface) TypeScript manbalariga nisbatan tekshiradigan snapshotdan generatsiya qilinadi, shuning uchun eksport CI sezmasdan o'zgara olmaydi.
