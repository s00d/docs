**Sana**: 2025-10-30

**Versiya**: `v2.0.0`

![v2.0.0 release](/images/2.0.0.png)

Biz ishlab chiqish rejimida tarjima fayllari uchun server tomonidagi HMR’ni taqdim etmoqdamiz. JSON tarjima o‘zgarganda server keshi faqat ta’sirlangan kalitlarni bekor qiladi va keyingi so‘rovlar darhol yangi ma’lumotlarni oladi — qayta ishga tushirish talab qilinmaydi.

## Nima yangi? {#what’s-new}

- Tarjima fayllari uchun server tomonidagi HMR
- Har bir sahifa/lokal uchun keshni darhol bekor qilish
- Kontentni tahrirlash paytida uzluksiz DX

## Qanday ishlaydi {#how-it-works}

- `src/runtime/server/plugins/watcher.dev.ts` dagi kuzatuvchi `<rootDir>/<translationDir>/**/*.json` fayllarini kuzatadi
- Sahifa fayllari (masalan, `pages/<page>/<locale>.json`) `_locales:merged:<page>:<locale>` ni bekor qiladi
- Ildiz darajasidagi fayllar (masalan, `<locale>.json`) shu lokal uchun barcha birlashtirilgan kalitlarni bekor qiladi
- `experimental.hmr !== false` bo‘lganda dev rejimida `src/module.ts` dan avtomatik ro‘yxatdan o‘tkaziladi

## Konfiguratsiya {#configuration}

```ts
export default defineNuxtConfig({
  i18n: {
    experimental: { hmr: true }, // default in dev
  },
})
```
