`@i18n-micro/vue` — Nuxt I18n Micro tarjima yadrosiga ega Vue 3 plagini: reaktiv `t()`, global `$t`, to'rtta komponent va ixtiyoriy vue-router adapteri. Uni Nuxt bilan qurilmagan Vite yoki SSR Vue ilovasida ishlating. Nusxa modeli, router shartnomasi va komponent props'lari boshqa paketlar bilan umumiy bo'lib, [Freymvorklar](/uz/integrations/overview) sahifasida tasvirlangan.

## O'rnatish {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vue
```

```bash npm
npm install @i18n-micro/vue
```

```bash yarn
yarn add @i18n-micro/vue
```

</CodeGroup>

Peer bog'liqliklar: `vue` `^3.3.0`; `vue-router` `^4.5.1 || ^5.0.0` (ixtiyoriy, faqat `@i18n-micro/vue/router` uchun). E'lon qilingan tiplar `skipLibCheck: false` bilan Vue 3.5.5 yoki undan yangi versiyani talab qiladi; odatiy shablon sozlamasi bo'lgan `skipLibCheck: true` bilan eski versiyalar ham kompilyatsiya qilinadi.

## Sozlash {#setup}

```ts
// src/main.ts
import { createApp } from 'vue'
import { createI18n } from '@i18n-micro/vue'
import App from './App.vue'
import en from './locales/en.json'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales: [
    { code: 'en', iso: 'en-US', displayName: 'English' },
    { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
  ],
  defaultLocale: 'en',
})

createApp(App).use(i18n).mount('#app')
```

`useI18n()` uchun `locales` va `defaultLocale` majburiy: ularsiz u `I18nLocalesKey not provided` xatosini tashlaydi. Ularni `createI18n` ga (yuqoridagidek), `useI18n({ locales, defaultLocale })` ga yoki `app.provide(I18nLocalesKey, …)` va `app.provide(I18nDefaultLocaleKey, …)` orqali uzating.

Plagin `I18nT`, `I18nLink`, `I18nGroup` va `I18nSwitcher` ni global ro'yxatdan o'tkazadi hamda shablonlarga `$t`, `$ts`, `$tc`, `$tn`, `$td`, `$tdr`, `$has` va `$i18n` ni qo'shadi. Komponentlardan tashqarida nusxa — `i18n.global`. Boshqa parametrlar [nusxa](/uz/integrations/overview#the-instance) bo'limida; `routeMessages` Vue'da mavjud emas, `addRouteTranslations` dan foydalaning.

## Tarjima qilish {#translate}

```vue
<script setup lang="ts">
import { useI18n } from '@i18n-micro/vue'

const { t, tc, tn } = useI18n()
</script>

<template>
  <h1>{{ t('greeting', { name: 'Ada' }) }}</h1>
  <!-- Hello, Ada! -->
  <p>{{ tc('apples', 3) }}</p>
  <!-- 3 apples -->
  <p>{{ $t('nav.home') }} · {{ tn(1234.5) }}</p>
</template>
```

`useI18n()` tarjima metodlarini (`t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`), `locale` (yoziladigan computed), `getLocale`, `getLocales`, `defaultLocale()`, `getLocaleName`, `localePath`, `localeRoute`, `switchLocale`, `setRoute`, `getRoute`, `addTranslations`, `addRouteTranslations`, `mergeTranslations`, `resolveTranslations`, `setTranslation`, `clearCache` va `instance` ni qaytaradi.

Istalgan vaqtda qo'shimcha lug'atlarni yuklang; ularni o'qiydigan har bir komponent qayta render qilinadi:

```ts
const { addTranslations, addRouteTranslations, setRoute } = useI18n()

addTranslations('de', (await import('./locales/de.json')).default)
addRouteTranslations('en', 'about', { title: 'About us' })
setRoute('about') // t('title') now reads the 'about' dictionary first
```

## Locale'ni almashtirish {#switch-locale}

```ts
const { locale, switchLocale } = useI18n()

locale.value = 'de' // only the locale
switchLocale('de') // the locale, then router.push to the localized current path
```

Locale lug'atini almashtirishdan oldin yoki keyin yuklang; almashtirish hech narsani yuklab olmaydi.

`<I18nGroup>` o'z slot'iga prefiksli `t` beradi. `<I18nT>` ichidagi yoki oddiy `t()` dagi kalitlarga prefiks qo'shilmaydi:

```vue
<I18nGroup prefix="profile" v-slot="{ t }">
  <h2>{{ t('title') }}</h2>
  <!-- profile.title -->
</I18nGroup>
```

## Marshrutlash {#routing}

vue-router adapteri subpath'da joylashgan, shuning uchun asosiy kirish nuqtasi hech qachon `vue-router` ni import qilmaydi:

```ts
// src/main.ts
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import { createI18n } from '@i18n-micro/vue'
import { createVueRouterAdapter } from '@i18n-micro/vue/router'
import App from './App.vue'
import Home from './pages/Home.vue'
import About from './pages/About.vue'
import en from './locales/en.json'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English' },
  { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
]

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/:locale(de)?', component: Home },
    { path: '/:locale(de)?/about', component: About },
  ],
})

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales,
  defaultLocale: 'en',
  routingStrategy: createVueRouterAdapter(router, locales, 'en'),
})

createApp(App).use(router).use(i18n).mount('#app')
```

`createVueRouterAdapter(router, locales, defaultLocale)` standartdan tashqari har bir locale'ga prefiks qo'shadi (`/about`, `/de/about`) va `<I18nLink>` ni `RouterLink` sifatida render qiladi. Locale'ni marshrutdan o'zingiz o'qing, masalan `router.beforeEach` da, va `i18n.global.locale.value` ni o'rnating. Adapterni keyinroq `i18n.setRoutingStrategy(adapter)` bilan ham ulashingiz mumkin; maxsus adapter uchun [Router adapteri](/uz/integrations/overview#router-adapter) bo'limiga qarang.

## SSR {#ssr}

- Router, i18n nusxasi va ilovani har bir so'rov uchun render funksiyasi ichida yarating. Bitta umumiy nusxa bir tashrif buyuruvchining locale'ini boshqasiga oshkor qilib qo'yadi.
- Serverda `createMemoryHistory()` dan foydalaning, locale'ni URL'dan oling va `renderToString` dan oldin uning lug'atini (va fallback lug'atini) yuklang.
- Locale'ni klientga yuboring (masalan, `window.__STATE__` script'ida) va hydration mos kelishi uchun klient nusxasini o'sha `locale` bilan yarating.
- `<I18nSwitcher>` `window.location` ni faqat ochiladigan ro'yxat ochiq bo'lganda o'qiydi, shuning uchun u serverda render qilinadi.

`packages/vue/playground` da to'liq `entry-server.ts` / `entry-client.ts` jufti mavjud.

## SEO head {#seo-head}

`useLocaleHead(options)` locale'lar va router adapteridan `lang`/`dir`, canonical, `hreflang` va `og:locale` teglarini quradi. Marshrut o'zgarganda `updateMeta()` ni chaqiring va `metaObject` ni head menejeringizga uzating:

```ts
import { watch } from 'vue'
import { useRoute } from 'vue-router'
import { useHead } from '@unhead/vue'
import { useLocaleHead } from '@i18n-micro/vue'

const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
watch(() => route.fullPath, () => updateMeta(), { immediate: true })
useHead(metaObject)
```

Parametrlar: `baseUrl` (satr yoki funksiya), `addDirAttribute` (standart `true`), `addSeoAttributes` (standart `true`), `identifierAttribute` (standart `'id'`), `hreflangBaseLanguage` (standart `false`). `disabled: true` yoki `seo: false` bo'lgan locale'lar alternate havola olmaydi.
