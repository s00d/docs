`@i18n-micro/runtime` — frameworkdan mustaqil i18n instansiyasi: lug'atlar, `t()`, ko'plik shakllari, `Intl` formatlash va o'zgarishlarga obuna, `fs` siz va frameworksiz. Undan oddiy TypeScript'da, web worker'da, edge funksiyada yoki o'z bog'lamangizning asosi sifatida foydalaning. React, Preact, Node va Astro paketlari aynan shu klassni kengaytiradi.

## O'rnatish {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/runtime
```

```bash npm
npm install @i18n-micro/runtime
```

```bash yarn
yarn add @i18n-micro/runtime
```

</CodeGroup>

Peer bog'liqliklar yo'q. Diskdagi tarjima fayllari uchun [`@i18n-micro/node`](/uz/integrations/nodejs-package) dan foydalaning.

## Sozlash {#setup}

```ts
import { createI18n } from '@i18n-micro/runtime'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    en: { greeting: 'Hello, {name}!', apples: 'no apples | one apple | {count} apples' },
    de: { greeting: 'Hallo, {name}!' },
  },
  routeMessages: {
    about: { en: { title: 'About us' } },
  },
})
```

Barcha sozlamalar (`plural`, `missingWarn`, `missingHandler`, `numberFormats`, `datetimeFormats`) [instansiya](/uz/integrations/overview#the-instance) bo'limida keltirilgan.

## Tarjima qilish {#translate}

```ts
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.tc('apples', 5) // '5 apples'
i18n.tn(1234.5) // '1,234.5'

i18n.setRoute('about')
i18n.t('title') // 'About us' (route dictionary)
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!' (root, still visible)
```

Keyinroq qo'shimcha lug'atlarni yuklang:

```ts
i18n.loadMessages({ fr: { greeting: 'Bonjour, {name} !' } }, { about: { fr: { title: 'À propos' } } })
i18n.addTranslations('fr', { nav: { home: 'Accueil' } }) // deep merge; pass false to replace

await i18n.loadFromUrl('/locales/fr.json', { locale: 'fr' })
await i18n.loadFromUrl('/locales/pages/about/fr.json', { locale: 'fr', routeName: 'about' })
await i18n.loadFromUrls([
  { url: '/locales/en.json', locale: 'en' },
  { url: '/locales/de.json', locale: 'de' },
])
```

`loadFromUrl` `fetch` dan foydalanadi (sarlavhalar uchun `init` ni bering) va OK bo'lmagan javobda xato chiqaradi. `loadFromUrls` ularni birin-ketin yuklaydi.

## Lokalni almashtirish {#switch-locale}

```ts
i18n.locale = 'de'
i18n.t('greeting', { name: 'Ada' }) // 'Hallo, Ada!'
```

Lokal, marshrut va lug'at o'zgarishlari obunachilarga xabar beradi, framework bog'lamalari aynan shu tarzda qayta render qiladi:

```ts
const stop = i18n.subscribe(() => {
  document.querySelector('#greeting')!.textContent = i18n.t('greeting', { name: 'Ada' }) as string
})
i18n.locale = 'fr'
stop()
```

`getSnapshot()` har bir xabarnomada o'zgaradigan satrni qaytaradi (`useSyncExternalStore` uslubidagi store'lar uchun).

## So'rov bo'yicha {#per-request}

Instansiya bitta lokal va bitta marshrutni saqlaydi. Serverda umumiy instansiyani har bir so'rov uchun almashtirmang: ikkita parallel so'rov bir-birining lokalini ko'rib qoladi. `i18n.fork(locale)` so'rovga o'zinikini beradi: o'z lokali, zaxira lokali va marshruti; lug'atlar, formatlovchilar va qoidalar esa bir xil. Fork qilish lug'atlar soni qancha bo'lishidan qat'i nazar bir xil narxga tushadi. Fork o'zining birinchi yozuvigacha ota-instansiyaga yozilganlarni ko'radi, uning yozuvlari esa o'zida qoladi. [Node.js](/uz/integrations/nodejs-package#per-request) `run` ni qo'shadi.

## API {#api}

| A'zo | Izohlar |
| --- | --- |
| `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has` | [Tarjima va formatlash](/uz/integrations/overview#translate-and-format) ga qarang |
| `locale`, `fallbackLocale` | get/set |
| `currentRoute`, `setRoute(name)`, `getRoute()` | faol marshrut, standart `'index'` |
| `loadMessages(messages?, routeMessages?)` | ko'plab lokal va marshrutlarni bir vaqtda birlashtirish |
| `addTranslations(locale, tree, merge = true)`, `addRouteTranslations(locale, route, tree, merge = true)` | |
| `loadFromUrl(url, { locale?, routeName?, init? })`, `loadFromUrls(entries)` | `fetch` JSON |
| `hasTranslation(key)` | faol lokal, istalgan marshrut (faol marshrut va ildizni tekshiradigan `has` dan farqli) |
| `setTranslation(key, value)`, `resolveTranslations()` | bitta kalitni yozish; birlashtirilgan daraxtni o'qish |
| `clear()`, `clearCache()` | barcha lug'atlarni tashlab yuborish |
| `subscribe(cb)`, `getSnapshot()` | o'zgarish xabarnomalari |
| `storage` | `{ translations: Map<'locale:route', Translations> }` |

Til tegi bo'lmagan kod o'z ko'plik shakllarini `localeIso: { ua: 'uk-UA' }` dan oladi; `localeIsoMap(locales)` buni lokal ro'yxatining `iso` ga ega yozuvlaridan quradi.

Modul eksportlari: `createI18n`, `I18n`, `fetchJsonTranslations`, `FormatService`, `interpolate`, `localeIsoMap` va `I18nOptions`, `LoadFromUrlOptions`, `LoadFromUrlEntry`, `TranslationStorage`, `Translations`, `Locale`, `PluralFunc` tiplari. To'liq signaturalar: [paket ma'lumotnomasi](/uz/api/packages/runtime).
