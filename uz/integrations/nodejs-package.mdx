`@i18n-micro/node` — bu [runtime](/uz/integrations/runtime-package) nusxasi va tarjima papkasini diskdan o‘qiydigan yuklovchi. Undan Express yoki Fastify serverida, CLI’da, email yoki PDF generatorida yoki Nuxt ilovangiz bilan bir xil JSON fayllar kerak bo‘lgan har qanday skriptda foydalaning. Fayllarni bir marta yuklaysiz va so‘rovlar o‘rtasida o‘zgaruvchan holatni bo‘lishmasdan har bir so‘rov uchun tarjima qilasiz.

## O‘rnatish {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/node @i18n-micro/utils
```

```bash npm
npm install @i18n-micro/node @i18n-micro/utils
```

```bash yarn
yarn add @i18n-micro/node @i18n-micro/utils
```

</CodeGroup>

Peer bog‘liqliklar yo‘q; Node.js `>=20`. `@i18n-micro/utils` faqat quyidagi `Accept-Language` yordamchisi uchun kerak.

## Sozlash {#setup}

Yuklovchi [Nuxt papka tuzilishi](/uz/guide/translations) ni o‘qiydi: `locales/en.json` — ildiz lug‘at, `locales/pages/blog/post/en.json` esa `blog-post` marshrutiga tegishli.

```ts
import { createI18n } from '@i18n-micro/node'

const i18n = createI18n({ locale: 'en', fallbackLocale: 'en', translationDir: './locales' })
await i18n.loadTranslations()

i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.t('title', undefined, undefined, 'blog-post') // from locales/pages/blog/post/en.json
```

Opsiyalar runtime opsiyalari ([nusxa](/uz/integrations/overview#the-instance) ga qarang), shuningdek `translationDir` va `disablePageLocales` (`pages/**` fayllarini ildiz lug‘atlar sifatida ko‘rish). `i18n.reload()` ishlab chiqishdagi fayl kuzatuvchisi uchun har bir lug‘atni tozalaydi va papkani qayta o‘qiydi.

`loadTranslations(dir, disablePageLocales?)` alohida ham eksport qilinadi va `{ root, routes }` ni qaytaradi:

```ts
import { loadTranslations } from '@i18n-micro/node'

const { root, routes } = await loadTranslations('./locales')
// root:   { en: {...}, de: {...} }
// routes: { 'blog-post': { en: {...}, de: {...} } }
```

## Har bir so‘rov uchun {#per-request}

Nusxa bitta lokal va bitta marshrutni saqlaydi. So‘rov ishlovchisi ichida umumiy nusxada `i18n.locale` ni almashtirish parallel so‘rovlar bilan poyga holatini keltirib chiqaradi. `run` so‘rovga o‘zinikini beradi:

```ts
const i18n = createI18n({ locale: 'en', fallbackLocale: 'en', translationDir: './locales' })
await i18n.loadTranslations()

// `() => next()`: `run` hands its callback the fork, and Express reads an argument of `next` as an error
app.use((req, res, next) => i18n.run(pickLocale(req), () => next()))

app.get('/', (req, res) => {
  res.send(i18n.t('greeting')) // the request's locale, in everything it awaits
})
```

`run` ichida umumiy nusxa so‘rovning lokali va marshrutini o‘qiydi va o‘rnatadi (`AsyncLocalStorage`); fork joriy marshrutdan boshlanadi va callback ichidagi `i18n.setRoute(...)` shu so‘rovning marshrutini o‘zgartiradi. Callback so‘rovning fork’ini ham oladi: unga yozilgan lug‘atlar so‘rov ichida qoladi, umumiy nusxaga yozilgan lug‘atlar esa hammaga yetib boradi.

`AsyncLocalStorage` siz `i18n.fork(locale)` uzatish uchun xuddi shunday nusxani qaytaradi.

`reload()` katalogni qayta o‘qiydi; yangilari kelguncha eski lug‘atlar javob beradi.

## Lokalni tanlash {#pick-the-locale}

`detectLocaleFromAcceptLanguage(header, locales)` `q` vaznlarini hisobga oladi va `de-DE` ni `de` lokaliga (va `de` ni `de-DE` ga) moslaydi. Hech narsa mos kelmasa `null` qaytaradi.

```ts
import express from 'express'
import { detectLocaleFromAcceptLanguage } from '@i18n-micro/utils/accept-language'

const app = express()

app.get('/hello', (req, res) => {
  const locale = detectLocaleFromAcceptLanguage(req.headers['accept-language'], locales) ?? 'en'
  const i18n = byLocale.get(locale)!
  res.json({ message: i18n.t('greeting', { name: 'Ada' }) })
})
```

URL prefiksi, cookie va sarlavhani birgalikda ishlatish uchun `@i18n-micro/utils/resolve-locale` dagi `resolveLocale({ defaultLocale, validLocales, url, cookie, acceptLanguage, autoDetectLanguage: true })` modulning ustuvorlik tartibini qo‘llaydi: URL, keyin cookie, keyin `Accept-Language`, keyin standart. Noto‘g‘ri qiymatlar o‘tkazib yuboriladi.

Nuxt ilovasi ichida serverda bu paket kerak emas: modulning [server tomonidagi tarjimalari](/uz/guide/server-side-translations) dan foydalaning.

## API {#api}

| Eksport | Izohlar |
| --- | --- |
| `createI18n(options)`, `I18n` | runtime nusxasi + `translationDir`, `loadTranslations(dir?)`, `reload()` |
| `loadTranslations(dir, disablePageLocales?)` | `{ root, routes }` |
| `loadRootTranslations(dir, disablePageLocales?)` | faqat `root` |
| `FormatService`, `interpolate` | core’dan |
| Turlar: `I18nOptions`, `LoadedTranslations`, `Translations`, `Locale`, `PluralFunc`, `Params` | |

Nusxa metodlari [Runtime](/uz/integrations/runtime-package#api) sahifasida keltirilgan. To‘liq signaturalar: [paket ma’lumotnomasi](/uz/api/packages/node).
