Orol brauzerda ishlaydi, u yerda serverning i18n instansiyasi mavjud emas. `@i18n-micro/astro` sahifaga orolga kerakli kalitlarni tanlash, ularni bitta prop sifatida uzatish va orolda kichik framework adapteri orqali o'qish imkonini beradi. Siz Vue, React, Preact va Svelte orollarida `t`, `tc`, `tn`, `td`, `tdr` va `has` ni olasiz, HTML'da esa faqat tanlangan satrlar bo'ladi.

## Sozlash {#setup}

Avval [Astro integratsiyasi va middleware](/uz/integrations/astro-package#setup)ni sozlang, so'ng o'zingiz foydalanadigan framework integratsiyasini qo'shing (`@astrojs/vue`, `@astrojs/react`, `@astrojs/preact`, `@astrojs/svelte`). Orol adapterlari o'sha frameworkni peer sifatida talab qiladi: `vue` `^3.3.0`, `react` `^16.8.0 || ^17.0.0 || ^18.0.0 || ^19.0.0`, `preact` `^10.0.0 || ^11.0.0` yoki `svelte` `^4.0.0 || ^5.0.0`.

## Orolga tarjimalarni uzatish {#pass-translations-to-an-island}

```astro
---
// src/pages/index.astro
import { getI18nProps } from '@i18n-micro/astro'
import Counter from '../components/Counter.vue'

const i18n = getI18nProps(Astro, ['counter.title', 'counter.apples'])
---

<Counter client:load i18n={i18n} />
```

`getI18nProps(Astro, keys?)` `{ locale, fallbackLocale, currentRoute, translations }` ni qaytaradi (tipi `I18nClientProps`). Orol foydalanadigan kalitlarni bering: har biri serverda `t()` kabi hal qilinadi (marshrut, ildiz va zaxira lug'atlari) va HTML'ga faqat topilgan kalitlar kiradi. `keys` bo'lmasa, bu sahifada `t()` javob bera oladigan hamma narsa har bir orolda yuboriladi, shuning uchun 2000 ta ildiz kaliti har bir orol uchun taxminan 100 KB bo'ladi; dev rejimida 20 KB dan oshganda ogohlantirish chiqadi.

Orollar faqat o'sha obyektdan tarjima qiladi. `t` uzatilmagan har qanday narsa uchun kalitni qaytaradi va bog'langan xabarlar hal qilinmaydi.

## Vue {#vue}

Orolning ildiz komponentida `provideI18n(() => props.i18n)` ni, uning bolalarida esa `useAstroI18n()` ni chaqiring. Vue'ning `inject` i o'sha komponent taqdim etgan qiymatni ko'rmaydi, shuning uchun hook ildizda emas, bola komponentda ishlashi kerak:

```vue
<!-- src/components/Counter.vue -->
<script setup lang="ts">
import { provideI18n } from '@i18n-micro/astro/client/vue'
import type { I18nClientProps } from '@i18n-micro/astro'
import CounterBody from './CounterBody.vue'

const props = defineProps<{ i18n: I18nClientProps }>()
provideI18n(() => props.i18n)
</script>

<template><CounterBody /></template>
```

```vue
<!-- src/components/CounterBody.vue -->
<script setup lang="ts">
import { ref } from 'vue'
import { useAstroI18n } from '@i18n-micro/astro/client/vue'

const { t, tc } = useAstroI18n()
const count = ref(0)
</script>

<template>
  <h3>{{ t('counter.title') }}</h3>
  <button @click="count++">{{ tc('counter.apples', count) }}</button>
</template>
```

## React va Preact {#react-and-preact}

```tsx
// src/components/Counter.tsx
import { useState } from 'react'
import { I18nProvider, useAstroI18n } from '@i18n-micro/astro/client/react'
import type { I18nClientProps } from '@i18n-micro/astro'

function Body() {
  const { t, tc } = useAstroI18n()
  const [count, setCount] = useState(0)
  return <button onClick={() => setCount(count + 1)}>{t('counter.title')}: {tc('counter.apples', count)}</button>
}

export default function Counter({ i18n }: { i18n: I18nClientProps }) {
  return (
    <I18nProvider value={i18n}>
      <Body />
    </I18nProvider>
  )
}
```

Preact uchun `I18nProvider` va `useAstroI18n` ni `@i18n-micro/astro/client/preact` dan import qiling; API bir xil.

## Svelte {#svelte}

```svelte
<!-- src/components/Counter.svelte -->
<script lang="ts">
  import { createI18nStore, useAstroI18n } from '@i18n-micro/astro/client/svelte'
  import type { I18nClientProps } from '@i18n-micro/astro'

  export let i18n: I18nClientProps
  const { t, tc } = useAstroI18n(createI18nStore(i18n))
  let count = 0
</script>

<button on:click={() => count++}>{t('counter.title')}: {tc('counter.apples', count)}</button>
```

`useAstroI18n(store)` shablonda `$store` o'qishlari uchun `store` ni ham qaytaradi.

## Saqlanadigan orollar {#persisted-islands}

`transition:persist` ga ega orol navigatsiyadan so'ng yangi proplarni oladi. React, Preact va Vue (getter berilganda) ularga amal qiladi. Svelte'da store'ni saqlang va ularni uzating: `const store = createI18nStore(i18n)`, `const { t } = useAstroI18n(store)`, keyin `$: store.set(i18n)` (runes bilan `$effect(() => store.set(i18n))`).

## API {#api}

| Kirish nuqtasi | Eksportlar |
| --- | --- |
| `@i18n-micro/astro` | `getI18nProps`, tip `I18nClientProps` |
| `@i18n-micro/astro/client/vue` | `provideI18n(props \| () => props)`, `useAstroI18n()` |
| `@i18n-micro/astro/client/react` | `I18nProvider` (`value` prop), `useAstroI18n()` |
| `@i18n-micro/astro/client/preact` | `I18nProvider` (`value` prop), `useAstroI18n()` |
| `@i18n-micro/astro/client/svelte` | `createI18nStore(props)`, `useAstroI18n(store)` |
| `@i18n-micro/astro/client` | frameworksiz sof `translate`, `hasTranslation` |

Har bir `useAstroI18n` `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`, `setLocale`, `setRoute` va `locale` ni qaytaradi. Orolda bitta birlashtirilgan lug'at bor, shuning uchun uning `has` i `t` javob bera oladigan kalit uchun, jumladan zaxira lokaldan ham, true bo'ladi; serverda `has` faqat faol lokalga qaraydi.
