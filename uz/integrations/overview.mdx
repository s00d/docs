`@i18n-micro/*` paketlari Nuxt I18n Micro'ning tarjima yadrosini Vue, React, Preact, Solid, Astro, VitePress va oddiy JavaScript'ga olib keladi. Ulardan ilovangiz Nuxt ilovasi bo'lmaganda yoki Nuxt'dan tashqaridagi skript yoki serverga xuddi shu tarjima fayllari kerak bo'lganda foydalaning. Har bir paket bitta instance modeli, bitta router adapteri kontrakti va bir xil to'rtta komponentni baham ko'radi, ular shu sahifada bir marta tasvirlangan.

## Instance {#the-instance}

`createI18n(options)` lug'atlarni, joriy lokalni va joriy route'ni saqlaydigan bitta instance qaytaradi. Parametrlar har bir paketda bir xil:

| Parametr | Tip | Sukut bo'yicha | Izohlar |
| --- | --- | --- | --- |
| `locale` | `string` | majburiy | Faol lokal. |
| `fallbackLocale` | `string` | `locale` | Kalit `locale` da yo'q bo'lganda qidiriladi. |
| `messages` | `Record<locale, Translations>` | `{}` | Ildiz lug'atlari (`'index'` route). |
| `routeMessages` | `Record<route, Record<locale, Translations>>` | `{}` | Route lug'atlari. Faqat Runtime, React, Preact, Node va VitePress. |
| `plural` | `PluralFunc` | `defaultPlural` | Maxsus ko'plik qoidasi. |
| `missingWarn` | `boolean` | `true` | Yo'q kalit uchun brauzerda faqat dev rejimidagi `console.warn`. |
| `missingHandler` | `(locale, key, routeName) => void` | — | Ogohlantirish o'rniga chaqiriladi. |
| `numberFormats` | `Record<locale, Record<name, Intl.NumberFormatOptions>>` | — | Nomlangan formatlar: `tn(9.5, 'currency')`. |
| `datetimeFormats` | `Record<locale, Record<name, Intl.DateTimeFormatOptions>>` | — | Nomlangan formatlar: `td(date, 'short')`. |
| `timeZone` | `string` | runtime zonasi | `td` sanalari uchun IANA zonasi; `tdr` ga ta'sir qilmaydi. Server va brauzer bitta sanani render qilishi uchun uni o'rnating. |
| `now` | `() => number` | `Date.now` | `tdr` soati. Ikkalasi bitta matnni render qilishi uchun gidratatsiyaga server vaqtini uzating. |
| `localeIso` | `Record<code, string>` | — | Ko'plik qoidalari uchun ishlatiladigan BCP 47 tegi (`ua` → `uk-UA`). React, Preact va Solid uni provider'ning `locales` dagi `iso` dan oladi. |

Lug'atlar `i18n.storage.translations` da, `locale:route` (`en:index`, `en:about`) kalitli `Map` da saqlanadi.

Kalit avval joriy route lug'atida, keyin ildiz lug'atida, avval `locale` uchun, keyin `fallbackLocale` uchun qidiriladi. Yo'q kalit kalitning o'zini (yoki siz uzatgan `defaultValue` ni) qaytaradi.

```ts
i18n.addTranslations('en', { nav: { home: 'Home' } }) // root, deep-merged
i18n.addRouteTranslations('en', 'about', { title: 'About us' }) // route chunk
i18n.addTranslations('en', { nav: { home: 'Start' } }, false) // replace instead of merge
i18n.setRoute('about')
i18n.t('title') // 'About us'
i18n.t('nav.home') // 'Start' (root key, still visible on the route)
```

### Tarjima qilish va formatlash {#translate-and-format}

| Metod | Qaytaradi |
| --- | --- |
| `t(key, params?, defaultValue?, routeName?)` | `{param}` interpolyatsiya qilingan qiymat (satr, son, obyekt). |
| `ts(...)` | `t` bilan bir xil, satr sifatida. |
| `tc(key, count \| params, defaultValue?)` | Ko'plik shakli. |
| `tn(value, options \| name)` | Faol lokaldagi `Intl.NumberFormat`. |
| `td(value, options \| name)` | `Intl.DateTimeFormat`. |
| `tdr(value, options?)` | Nisbiy vaqt (`3 days ago`). |
| `has(key, routeName?)` | Faol lokalda kalit mavjud bo'lganda `true` (route yoki ildiz lug'ati; fallback tekshirilmaydi). |

`defaultPlural` qiymatni `|` bo'yicha bo'ladi va `count` indeksidagi shaklni tanlaydi, oxirgisi bilan cheklanadi; manfiy, kasr yoki `NaN` count oxirgi shaklni tanlaydi.

Maxsus `plural` `(key, count, params, locale, getter)` ni qabul qiladi. Qiymatni `getter(key)` orqali o'qing; kalitni bo'lmang:

```ts
import type { PluralFunc } from '@i18n-micro/vue'

const plural: PluralFunc = (key, count, params, _locale, getter) => {
  const value = getter(key)
  if (typeof value !== 'string') return null
  const forms = value.split('|').map((form) => form.trim())
  return (count === 1 ? forms[0] : forms[1] ?? forms[0])!.replace('{count}', String(count))
}
```

## Router adapteri {#router-adapter}

SPA paketlari routerga bog'liq emas. Router adapteri (`I18nRoutingStrategy`) ularga joriy yo'lni qanday o'qish, navigatsiya qilish va lokallashtirilgan yo'lni qanday qurishni aytadi. O'rnatilgan adapterlar `defaultLocale` dan tashqari har bir lokalga prefiks qo'shadi (`/about`, `/de/about`).

| A'zo | Majburiy | Kim foydalanadi |
| --- | --- | --- |
| `getCurrentPath(): string` | ha | faol havola tekshiruvi (sahifa bo'yicha, query va hash hisobga olinmaydi), `switchLocale` (ularni saqlaydi) |
| `push({ path }): void` | ha | `switchLocale`, `linkComponent` siz `<I18nLink>`, `<I18nSwitcher>` |
| `replace({ path }): void` | ha | — |
| `resolvePath(to, locale)` | yo'q | `localePath`, `localeRoute`, `<I18nLink>`; u bo'lmasa yo'llar o'z holicha qaytariladi |
| `linkComponent` | yo'q | `<I18nLink>` uni `<a>` o'rniga render qiladi (masalan, `RouterLink`) |
| `getRoute()` | yo'q | SEO yordamchilari uchun `{ fullPath, query }` |

`push` va `replace` Vue, React, Preact va Solid'da majburiy. Astro'ning ixtiyoriy `push`/`replace` ga ega o'z server tomonidagi adapteri bor ([Astro](/uz/integrations/astro-package#router-adapter) sahifasiga qarang).

Istalgan history asosidagi router uchun minimal adapter:

```ts
import type { I18nRoutingStrategy } from '@i18n-micro/react'

const locales = ['en', 'de']
const stripLocale = (path: string) => path.replace(/^\/(en|de)(?=\/|$)/, '') || '/'

export const historyAdapter: I18nRoutingStrategy = {
  getCurrentPath: () => window.location.pathname + window.location.search + window.location.hash,
  push: ({ path }) => window.history.pushState({}, '', path),
  replace: ({ path }) => window.history.replaceState({}, '', path),
  resolvePath: (to, locale) => {
    const path = stripLocale(typeof to === 'string' ? to : to.path || '/')
    return locale === 'en' ? path : `/${locale}${path === '/' ? '' : path}`
  },
}
```

## Komponentlar {#components}

Vue, React, Preact va Solid bir xil to'rtta komponentni taqdim etadi. Ularning prop'lari mos keladi; React, Preact va Solid boshqa prop'larni ildiz elementga uzatadi.

### `<I18nT>` {#&lt;i18nt&gt;}

| Prop | Tip | Izohlar |
| --- | --- | --- |
| `keypath` | `string` | majburiy |
| `params` | `object` | interpolyatsiya qiymatlari |
| `plural` | `number \| string` | `tc(keypath, count)` ni render qiladi |
| `number` | `number \| string` | `tn(number)` ni `{number}` sifatida uzatadi |
| `date` | `Date \| string \| number` | `td(date)` ni `{date}` sifatida uzatadi |
| `relativeDate` | `Date \| string \| number` | `tdr(relativeDate)` ni `{relativeDate}` sifatida uzatadi |
| `tag` | `string` | o'rovchi element, sukut bo'yicha `span` |
| `html` | `boolean` | tarjimani HTML sifatida render qiladi; u ishonchli bo'lishi kerak, parametrlar ekranlanadi |
| `defaultValue` | `string` | yo'q kalit o'rnini bosadi va `hideIfEmpty` bo'sh qiymatni yashirganda o'rovchisiz render qilinadi |
| `hideIfEmpty` | `boolean` | bo'sh tarjima uchun hech narsa render qilmaydi |
| `customPluralRule` | `PluralFunc` | shu element uchun ko'plik qoidasi |

Faqat bitta formatlash prop'i qo'llaniladi, quyidagi tartibda tekshiriladi: `number`, `date`, `relativeDate`, `plural`.

#### Boy matn {#rich-text}

`{placeholder}` element saqlashi mumkin. Vue'da bu nomlangan slot; React, Preact va Solid'da `components` prop'i elementlarni yoki element qaytaradigan funksiyalarni nomi bo'yicha beradi. Har ikki holatda ham u xuddi shu nomdagi parametrdan ustun keladi, har bir tarmoqda ishlaydi va placeholder'lar tartibini o'zgartiradigan lokalda ham saqlanib qoladi.

```tsx
// { "terms": "I accept the {link} of {company}" }
<I18nT keypath="terms" params={{ company: 'ACME' }} components={{ link: <a href="/terms">terms</a> }} />
```

Solid'da placeholder takrorlanganda funksiya uzating: bitta tugun faqat bitta joyda turadi. `children` matnni almashtiradi, funksiya sifatida esa Vue'ning sukut bo'yicha slotidek `{ translation }` ni oladi. `html` bularning barchasini e'tiborsiz qoldiradi.

### `<I18nLink>` {#&lt;i18nlink&gt;}

| Prop | Tip | Izohlar |
| --- | --- | --- |
| `to` | `string \| { path }` | adapterning `resolvePath` i orqali lokallashtiriladi |
| `activeStyle` | style obyekti | joriy sahifada `style` ustiga birlashtiriladi; React, Preact va Solid uni yuqoridagi bo'limga ham qo'llaydi |
| `localeRoute` | funksiya | shu havola uchun `resolvePath` ni qayta belgilaydi |

Tashqi URL'lar (`https://`, `mailto:`, `tel:`) `<a target="_blank" rel="noopener noreferrer">` sifatida render qilinadi; o'zingizning `target` yoki `rel` qiymatingiz ustun keladi. `onClick` har doim ishlaydi. Modifikatorli bosish, boshqa sichqoncha tugmasi yoki `target` brauzer ixtiyorida qoladi.

### `<I18nSwitcher>` {#&lt;i18nswitcher&gt;}

Ichki sukut bo'yicha uslublarga ega yoqilgan lokallarning ochiluvchi ro'yxati (`disabled: true` lokallar yashirinadi). Uning elementlari lokaldan olingan `lang`, `hreflang` va `dir` ga ega havolalardir. Sukut bo'yicha birini bosish lokalni o'rnatadi va adapterning `push` ini lokallashtirilgan joriy yo'l bilan chaqiradi; `switchLocale` prop'i bu amalni almashtiradi. `localeRoute` bo'lsa va router bo'lmasa, brauzer havolaga o'tadi. Escape yoki tashqariga bosish uni yopadi.

| Prop | Izohlar |
| --- | --- |
| `locales`, `currentLocale`, `getLocaleName` | taqdim etilgan qiymatlarni qayta belgilaydi |
| `switchLocale(code)` | o'rnatilgan almashtirishni almashtiradi |
| `localeRoute` | `resolvePath` ni almashtiradi |
| `customLabels` | `{ de: 'DE' }` |
| `customWrapperStyle`, `customButtonStyle`, `customDropdownStyle`, `customItemStyle`, `customLinkStyle`, `customActiveLinkStyle`, `customDisabledLinkStyle`, `customIconStyle` | uslublarni qayta belgilash |

### `<I18nGroup>` {#&lt;i18ngroup&gt;}

O'z bolalariga prefiksli `t` ni uzatadigan `<div class="i18n-group">`. U ichidagi `<I18nT>` yoki `t()` chaqiruvlariga prefiks **qo'shmaydi**; faqat u pastga uzatadigan `t` prefiksli bo'ladi.

| Prop | Izohlar |
| --- | --- |
| `prefix` | majburiy, masalan, `'profile'` |
| `groupClass` | o'rovchidagi qo'shimcha class |

Prefiksli `t` Vue'da scoped slot orqali (`v-slot="{ t }"`), React, Preact va Solid'da esa render-prop bola orqali (`{({ t }) => …}`) keladi.

## Tiplangan kalitlar {#typed-keys}

`t()` istalgan satrni qabul qiladi. Kalitlaringiz uchun avtomatik to'ldirishga ega bo'lish uchun [tiplar generatori](/uz/integrations/types-generator) yordamida deklaratsiya generatsiya qiling. Kalitlar majburlanmaydi, faqat taklif qilinadi va parametrlar tiplanmaydi.

## Nuxt moduli bilan taqqoslash {#compared-with-the-nuxt-module}

Paketlarda fayllarga asoslangan routing, server middleware va tarjima yuklovchisi yo'q: JSON'ni qachon yuklashni (`import`, `fetch` yoki serverda `@i18n-micro/node`) va qaysi router adapteridan foydalanishni o'zingiz hal qilasiz. Lokalni aniqlash, SEO meta va route generatsiyasi Nuxt imkoniyatlari; Astro'da aniqlash uchun o'z middleware'i va SEO uchun `useLocaleHead` bor.
