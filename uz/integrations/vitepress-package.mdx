`@i18n-micro/vitepress` VitePress saytiga runtime lug'atlarini qo'shadi: markdown ichida `$t` va `<I18nT>`, yo'l yordamchilari va SEO teglari, [`@i18n-micro/vue`](/uz/integrations/vue-package) asosida qurilgan. Undan bir xil UI satrlari ko'p sahifalarda paydo bo'lganda va ularni har bir lokal uchun takrorlashni istamaganingizda foydalaning. Lokal VitePress'ning o'z yo'l lokallariga (`/`, `/fr/`) amal qiladi.

## Qachon foydalanish kerak {#when-to-use-it}

| Ehtiyoj | Yechim |
|------|----------|
| Takroriy `.md`, URL prefikslari | VitePress `locales` |
| Runtime `$t` / komponentlar / yo'l sinxronizatsiyasi / SEO head | `@i18n-micro/vitepress` |
| Standart mavzu interfeysi yorliqlari (`docFooter`, qidiruv UI) | Har bir lokal uchun o'z `themeConfig` ingiz |

<Tip>

**Playground** — [`packages/vitepress/playground`](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/vitepress/playground) — `pnpm -C packages/vitepress/playground dev`

</Tip>

## O'rnatish {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vitepress
```

```bash npm
npm install @i18n-micro/vitepress
```

```bash yarn
yarn add @i18n-micro/vitepress
```

</CodeGroup>

Peer bog'liqliklar: `vitepress` `>=1.0.0 || >=2.0.0-alpha.0`, `vue` `^3.3.0`. Node skriptlari paket bilan birga o'rnatiladigan va `/node` orqali qayta eksport qilinadigan `@i18n-micro/node` dan foydalanadi. E'lon qilingan tiplar `skipLibCheck: false` bilan Vue 3.5.5 yoki undan keyingi versiyani talab qiladi; odatiy shablon sozlamasi bo'lgan `skipLibCheck: true` bilan eskiroq versiyalar ham kompilyatsiya qilinadi.

## Sozlash {#setup}

```
locales/en.json
locales/fr.json
locales/pages/guide/demo/en.json   # optional page-scoped
locales/pages/guide/demo/fr.json
```

Sahifa fayllari marshrut nomlariga Nuxt/Astro'dagi kabi moslanadi (`guide/demo` → `guide-demo`).

### 1. Konfiguratsiya — `@i18n-micro/vitepress/config` {#1-config-—-@i18n-micro/vitepress/config}

```ts
// .vitepress/config.mts
import { defineConfig } from 'vitepress'
import { withI18n, buildVitePressLocales } from '@i18n-micro/vitepress/config'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English', og: 'en_US' },
  { code: 'fr', iso: 'fr-FR', displayName: 'Français', og: 'fr_FR' },
]
const defaultLocale = 'en'

export default defineConfig(
  withI18n(
    {
      locales: buildVitePressLocales(locales, defaultLocale),
      // themeConfig.i18nRouting is injected automatically
    },
    {
      locale: defaultLocale,
      defaultLocale,
      locales,
      translationDir: 'locales',
      metaBaseUrl: 'https://example.com', // optional SEO head
    },
  ),
)
```

### 2. Mavzu — `@i18n-micro/vitepress/theme` {#2-theme-—-@i18n-micro/vitepress/theme}

```ts
// .vitepress/theme/index.ts
import DefaultTheme from 'vitepress/theme'
import { defineI18nTheme } from '@i18n-micro/vitepress/theme'

export default defineI18nTheme(DefaultTheme)
```

Boshlang'ich lokal o'rnatishdan oldin joriy yo'ldan olinadi (`/fr/…` da standart lokalning miltillashi bo'lmaydi).

### Kengaytirilgan: qo'lda `createI18n` {#advanced-manual-createi18n}

Klient uchun bitta fabrika: Vue plagini + yo'l metodlari + `enhanceApp` (alohida router yordamchi eksportlari yo'q).

```ts
import { createI18n, messagesFromGlob } from '@i18n-micro/vitepress'

const i18n = createI18n({
  locale: 'en',
  defaultLocale: 'en',
  locales: [{ code: 'en' }, { code: 'fr' }],
  messages: messagesFromGlob(import.meta.glob('../../locales/*.json', { eager: true })),
})

i18n.localizePath('/guide', 'fr')
// in theme enhanceApp:
i18n.enhanceApp({ app, router })
```

### Node skriptlari — `@i18n-micro/vitepress/node` {#node-scripts-—-@i18n-micro/vitepress/node}

`@i18n-micro/node` ning `createI18n` / `loadTranslations` dan foydalanadi (Astro va CLI dagi kabi), so'ng `BaseI18n.extend` bilan VitePress yo'l metodlarini biriktiradi:

```ts
import { createI18n } from '@i18n-micro/vitepress/node'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  translationDir: './locales',
  locales: ['en', 'fr'],
  defaultLocale: 'en',
})
await i18n.loadTranslations()
i18n.t('cta.readMore')
i18n.localizePath('/guide', 'fr')
```

Yo'llarsiz oddiy Node: `import { createI18n } from '@i18n-micro/node'`.

## Sahifa ichidagi tarjimalar {#in-page-translations}

Har bir VitePress markdown fayli Vue SFC hisoblanadi.

### Global komponentlar va `$t` (markdown'da tavsiya etiladi) {#global-components-and-$t-recommended-in-markdown}

`createI18n` / `defineI18nTheme` `@i18n-micro/vue` ni o'rnatadi, u `I18nT` / `I18nLink` / `I18nGroup` / `I18nSwitcher` va `$t` / `$tc` / `$ts` ni ro'yxatdan o'tkazadi.

```md
{{ $t('cta.readMore') }}

<I18nT keypath="greeting" :params="{ name: 'VitePress' }" />

<I18nLink to="/guide/demo">Demo</I18nLink>
```

### `<script setup>` ichida `useI18n` {#usei18n-in-<script-setup>}

```md
<script setup>
import { useI18n } from '@i18n-micro/vitepress'
const { t, tc, locale, localePath, switchLocale } = useI18n()
</script>

# {{ t('section.title') }}
```

## Til ochiluvchi menyusi {#language-dropdown}

`locales` da bittadan ortiq yozuv bo'lsa, VitePress o'zining til menyusini (`VPNavBarTranslations`) ko'rsatadi. `withI18n` `themeConfig.i18nRouting` ni ulaydi, shunda globus `<I18nSwitcher>` / yo'l yordamchilari bilan mos keladi.

`<I18nSwitcher>` dan faqat maxsus layoutlarda foydalaning, standart globus yonida emas.

## SSR bo'yicha eslatmalar {#ssr-notes}

- Prerender paytidagi lokal cookie'lardan emas, URL yo'lidan olinadi.
- Mavzu kodi import vaqtida `window` ga tegmasligi kerak.
- `defineI18nTheme` ni `/theme` dan import qiling, shunda Node konfiguratsiyasini hisoblash hech qachon `virtual:i18n-micro/*` ni yuklamaydi.

## API yuzasi {#api-surface}

| Eksport | Vazifasi |
|--------|------|
| `createI18n` (`.`) | Klient: Vue plagini + yo'l metodlari + `enhanceApp` |
| `getLocaleFromPath` / `stripSiteBase` / `routeNameFromPath` (`.`) | `syncWithVitePress: false` bo'lganda lokalni qo'lda sinxronlash |
| `createI18n` (`/node`) | Node: `@i18n-micro/node` + yo'l metodlari |
| `defineI18nTheme` (`/theme`) | Ortiqcha kodsiz mavzu |
| `withI18n` (`/config`) | Konfiguratsiya + virtual modullar + ixtiyoriy SEO |
| `buildVitePressLocales` (`/config`) | `Locale[]` dan VitePress `locales` ni qurish |
| `buildVitePressLocaleHead` (`/config`) | Qo'lda SEO head (`metaBaseUrl` ham undan foydalanadi) |
| `messagesFromGlob` | `createI18n` uchun ixtiyoriy glob → xabarlar xaritasi |
| `useI18n` / `I18nT` / … | `@i18n-micro/vue` dan qayta eksport qilingan |
| `BaseI18n.extend` (`@i18n-micro/core`) | Istalgan i18n instansiyasiga maxsus metodlarni biriktirish |

## OpenAPI uslubidagi saytlar (integratsiya qulflari) {#openapi-style-sites-integration-locks}

Regressiya to'plami: `packages/vitepress/tests/integration-openapi.test.ts` (chuqur yo'llar, `base=/openapi_docs/`, sinxronizatsiya o'chiq + qo'lda lokal, Node generatorlari, SEO).

| Pattern | Nima qilish kerak |
|---------|---------|
| Chuqur `/…/{spec}/{op}` sahifalar, faqat ildiz UI JSON | Standart `syncWithVitePress: true` ni afzal ko'ring (sahifa lug'ati bo'lmasa `setRoute('index')` ni saqlaydi) **yoki** `syncWithVitePress: false` + `getLocaleFromPath` |
| Sahifa lug'atlarisiz hech qachon `setRoute(deepName)` ni chaqirmang | Ildiz UI kalitlari `setRoute('index')` gacha yo'qoladi |
| Generatorlar / `getTranslation` | `/node` dan `createI18n` + `await loadTranslations()` + `i18n.t(key)` (`i18n.locale` ni o'rnating) |
| `transformPageData` da maxsus canonical | `withI18n` ga `meta: false` ni bering (teglar ikki marta chiqishining oldini oladi) |
| Sayt base bilan paket SEO'si | `metaBaseUrl` + VitePress `base` → mutlaq URL'lar base'ni o'z ichiga oladi |
| Eski paket buildlaridan nomini o'zgartirish | `withI18nMicro` → `withI18n`, `createVitePressI18n` → `createI18n`, `loadMessages` → node `createI18n` |
