`@i18n-micro/astro` Astro sahifalarini serverda tarjima qiladi: middleware lokalni URL'dan tanlaydi va har bir so'rov uchun instansiyani `Astro.locals`ga joylaydi, `useI18n(Astro)` esa uni o'qiydi. Undan lokal prefiksli URL'lar (`/about`, `/fr/about`) va umumiy JSON lug'atlar kerak bo'lgan Astro saytida foydalaning. Siz `.astro` komponentlari, bosh sahifadan tashrif buyuruvchi tiliga yo'naltirish, `hreflang` teglari va [orollar](/uz/integrations/astro-islands) uchun props'larni olasiz.

## O'rnatish {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/astro
```

```bash npm
npm install @i18n-micro/astro
```

```bash yarn
yarn add @i18n-micro/astro
```

</CodeGroup>

Peer bog'liqliklar: `astro` `^5.0.0 || ^6.0.0 || ^7.0.0`. Ixtiyoriy, faqat [orollar](/uz/integrations/astro-islands) uchun: `vue` `^3.3.0`, `react` `^16.8.0 || ^17.0.0 || ^18.0.0 || ^19.0.0`, `preact` `^10.0.0 || ^11.0.0`, `svelte` `^4.0.0 || ^5.0.0`.

## Sozlash {#setup}

Integratsiyani qo'shing. U lug'atlaringizni serverga bundle qiladi va middleware'ni o'rnatadi, shuning uchun `src/middleware.ts` kerak emas:

```ts
// astro.config.mjs
import { defineConfig } from 'astro/config'
import node from '@astrojs/node'
import { i18nIntegration } from '@i18n-micro/astro'

export default defineConfig({
  output: 'server',
  adapter: node({ mode: 'standalone' }),
  integrations: [
    i18nIntegration({
      locale: 'en',
      fallbackLocale: 'en',
      locales: [
        { code: 'en', iso: 'en-US', displayName: 'English' },
        { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
        { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
      ],
      translationDir: 'src/locales',
    }),
  ],
})
```

Lug'atlar build vaqtida kodga aylanadi: server diskdan hech narsa o'qimaydi, shuning uchun u edge'da ham (Cloudflare, Vercel Edge) ishlaydi. `astro dev`da faylga kiritilgan o'zgarish keyingi so'rovda qo'llaniladi.

### Integratsiya opsiyalari {#integration-options}

| Opsiya | Standart | Izohlar |
| --- | --- | --- |
| `locale` | majburiy | Standart lokal. |
| `fallbackLocale` | `locale` | |
| `locales` | `[]` | To'liq `Locale` obyektlari. `disabled` bo'lgani hech bir URL'ning lokali emas va yo'naltirish maqsadi emas. Kod til tegi bo'lmaganda (`ua` → `uk-UA`) ko'plik shakllari `iso` tegiga qarab aniqlanadi. |
| `translationDir` | yo'q | Serverga bundle qilinadigan papka, loyiha ildiziga nisbatan. |
| `disablePageLocales` | `false` | Sahifa fayllari ildiz tarjimalari hisoblanadi. |
| `autoDetect` | `true` | Bosh sahifadan yo'naltirish, [Lokalni aniqlash](#locale-detection)ga qarang. |
| `redirectToDefault` | `false` | Hech narsa boshqa lokalni afzal ko'rmaganda ham `/` yo'naltiradi. |
| `localeCookie` | `'i18n-locale'` | `null` cookie'ni o'chiradi. |
| `missingWarn` | `false` | |
| `middleware` | `true` | `false`: middleware'ni o'zingiz yozing, quyiga qarang. |

Runtime sozlamalari `virtual:i18n-micro/config`da (`config.base` — Astro'ning `base`i, `config.localeCodes` — yoqilgan kodlar), lug'atlar esa `virtual:i18n-micro/messages`da e'lon qilinadi.

### O'z middleware'ingiz {#your-own-middleware}

Ko'plik qoidasi, yetishmayotgan kalit ishlovchisi va router adapteri konfiguratsiya jarayonidan server bundle'iga o'ta olmaydi. Ular uchun `middleware: false`ni uzating va `src/middleware.ts`ni yozing. Shunda Astro'ning `i18n` konfiguratsiyasi siz uchun `routing: 'manual'` bilan o'rnatiladi, shuning uchun `Astro.currentLocale` va `astro:i18n` ishlaydi. Astro bu sozlamaga `src/middleware.ts`siz ruxsat bermaydi, shuning uchun integratsiyaning o'z middleware'i bilan ular ishlamaydi.

```ts
// src/middleware.ts
import { config } from 'virtual:i18n-micro/config'
import { messages } from 'virtual:i18n-micro/messages'
import { createAstroRouterAdapter, createI18n, createI18nMiddleware, localeIsoMap } from '@i18n-micro/astro'

const i18n = createI18n({
  locale: config.defaultLocale,
  fallbackLocale: config.fallbackLocale,
  localeIso: localeIsoMap(config.locales),
  messages: messages.root,
  routeMessages: messages.routes,
  plural: myPluralRule,
})

export const onRequest = createI18nMiddleware({
  i18n,
  defaultLocale: config.defaultLocale,
  locales: config.localeCodes,
  localeObjects: config.locales,
  autoDetect: config.autoDetect,
  redirectToDefault: config.redirectToDefault,
  localeCookie: config.localeCookie,
  base: config.base,
  routingStrategy: createAstroRouterAdapter(config.locales, config.defaultLocale),
})
```

Buning o'rniga papkani runtime'da o'qish uchun `loadTranslationsFromDir` va `loadTranslationsIntoI18n` `@i18n-micro/astro/node`da mavjud (faqat Node).

### Middleware opsiyalari {#middleware-options}

| Opsiya | Standart | Izohlar |
| --- | --- | --- |
| `i18n` | majburiy | Global instansiya; har bir so'rov `i18n.fork(locale)`ni oladi, uning narxi lug'atlar soniga bog'liq emas. |
| `defaultLocale` | majburiy | |
| `locales` | majburiy | Lokal kodlari. |
| `localeObjects` | `{ code }` ko'rinishidagi `locales` | Komponentlar va SEO uchun to'liq `Locale` obyektlari. |
| `autoDetect` | `true` | Bosh sahifadan yo'naltirish, [Lokalni aniqlash](#locale-detection)ga qarang. |
| `redirectToDefault` | `false` | Hech narsa boshqa lokalni afzal ko'rmaganda ham `/` yo'naltiradi — marshrutlash strategiyasi aniqlaganidek standart lokalning bosh sahifasiga. |
| `localeCookie` | `'i18n-locale'` | `null` cookie'ni o'chiradi. |
| `routingStrategy` | standartdan tashqari prefiks | Router adapteri. U qoldirgan metodlar standart adapterdan olinadi. |
| `base` | yo'q | Astro'ning `base`i: `config.base`. |

Sahifa fayllari (`src/locales/pages/blog/post/de.json`) — bu `blog-post` marshruti: sahifa yo'li `-` bilan birlashtirilgan.

## Tarjima qilish {#translate}

```astro
---
// src/pages/index.astro
import { useI18n } from '@i18n-micro/astro'
import I18nT from '@i18n-micro/astro/i18n-t'

const { t, tc, locale } = useI18n(Astro)
---

<h1>{t('greeting', { name: 'Ada' })}</h1>
<p>{tc('apples', 3)}</p>
<I18nT keypath="welcome" tag="p" />
<p>{locale}</p>
```

`useI18n(Astro)` `locale`, `defaultLocale`, `locales`, `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`, `getRoute`, `getRouteName(path?)`, `getLocaleFromPath(path?)`, `switchLocalePath(locale)`, `localizePath(path, locale?)`, `getBasePath(url?)`, `getI18n`, `addTranslations`, `addRouteTranslations`, `mergeTranslations` va `clearCache`ni qaytaradi. Middleware ishlamagan bo'lsa, u xato tashlaydi. `getI18n`, `getLocale`, `getDefaultLocale` va `getLocales` yordamchilari xuddi shu `Astro.locals`ni o'qiydi.

Marshrut nomi lokalsiz marshrutdan olinadi: `/fr/blog/post` → `blog-post`, `src/pages/blog/[slug].astro`ning har bir URL'i esa → `blog-slug`, shuning uchun bitta `locales/pages/blog-slug/` papkasi ularning barchasiga xizmat qiladi. `[...path]` — bu `path`. Astro'ning `base`i ostida yordamchilar sayt URL'larini qabul qiladi va qaytaradi: `switchLocalePath` va `localizePath` uni o'z ichiga oladi, `getBasePath` esa yo'q, chunki `Astro.rewrite` yo'lni usiz qabul qiladi.

### Komponentlar {#components}

Ularni `@i18n-micro/astro/<name>`dan (yoki `@i18n-micro/astro/components/<name>.astro`dan) import qiling:

| Komponent | Props |
| --- | --- |
| `i18n-t` | `keypath`, `params`, `plural`, `number`, `date`, `relativeDate`, `tag` (`span`, istalgan teg), `html`, `hideIfEmpty`, `defaultValue`; boshqa atributlar o'tkazib yuboriladi. `html` bilan har bir tarmoqning natijasi HTML sifatida render qilinadi va `params` ekranlanadi. Slotlar yo'q |
| `i18n-link` | `href`, `locale` (maqsad lokal, standart — joriy), `class`; boshqa atributlar o'tkazib yuboriladi. Tashqi URL'lar, `#hash` va `?query` yozilganicha qoladi; marshrut o'z query'si, hash'i va oxiridagi slash'ini saqlaydi |
| `i18n-switcher` | `class`, `activeClass` (`'active'`), `customLabels`; har bir yoqilgan lokaldagi joriy sahifaga uning query'si bilan havolalarni render qiladi |
| `i18n-group` | chiqishni o'zgartiradiganlari yo'q: slot atrofidagi `<div>`, prefikssiz |

## Lokal prefiksli marshrutlar {#locale-prefixed-routes}

Har bir marshrut uchun `src/pages/` ichida bitta sahifa saqlang va `src/pages/[locale]/` ostiga yupqa rewrite stub'larini qo'shing:

```
src/pages/
  index.astro
  about.astro
  [locale]/
    index.astro
    about.astro
```

```astro
---
// src/pages/[locale]/about.astro
import { prepareLocaleRewrite } from '@i18n-micro/astro'

const target = prepareLocaleRewrite(Astro)
if (target instanceof Response) return target
return Astro.rewrite(target)
---
```

`prepareLocaleRewrite` noma'lum `:locale` uchun `404` javobini qaytaradi, aks holda `Astro.locals`da lokalni o'rnatadi va prefikssiz yo'lni qaytaradi. Middleware `locals`da allaqachon mavjud lokalni saqlab qoladi, shuning uchun qayta yozilgan sahifa o'sha lokalda render qilinadi. Lokalni o'zingiz tekshirsangiz, `getLocaleRewritePath(Astro)` faqat yo'lni qaytaradi.

## Lokalni aniqlash {#locale-detection}

Sahifaning lokalini URL belgilaydi:

1. Lokal prefiksi (`/fr/about` → `fr`; `/en/about` ham `en`).
2. Aks holda router adapterining `getLocaleFromPath` qaytargani, agar u standart bo'lmasa.
3. Aks holda standart lokal. Cookie nima deyishidan qat'i nazar, `/about` har doim standart lokalning sahifasi.

`autoDetect` — faqat bosh sahifadagi yo'naltirish ishorasi:

- Cookie'si yoki `Accept-Language`i boshqa lokalni afzal ko'radigan `/` so'rovi o'sha lokalning bosh sahifasiga (`/de`) `302` oladi. q-og'irliklar hisobga olinadi; `de-DE` `de` lokaliga mos keladi, `de` esa `de-DE` lokaliga.
- `redirectToDefault` bilan `/` har doim yo'naltiradi: afzal ko'rilgan lokalning bosh sahifasiga, aks holda standart lokalnikiga.
- `/` javobi `Vary: Cookie, Accept-Language`ni olib yuradi (`localeCookie` `null` bo'lganda faqat `Accept-Language`).
- Oldindan render qilingan sahifalar hech qachon yo'naltirmaydi.

`detectLocale(pathname, cookies, headers, defaultLocale, locales, localeCookie?, routingStrategy?, autoDetect?)` o'z mantig'ingiz uchun xuddi shu afzal ko'rilgan lokalni qaytaradi.

Cookie tanlovni eslab qoladi. Boshqa lokaldagi bir xil origin sahifasidan kelgan sahifa ko'rishi — qaysi havola orqali kelganidan qat'i nazar — tashrif buyuruvchining tilni almashtirishi hisoblanadi: HTML javobi cookie'ni yangi lokalga o'rnatadi va `/` yo'naltirmaydi, shuning uchun almashtirgich standart lokalning bosh sahifasiga yetib boradi. Endpoint, rasm, 404, forma yuborish va prefetch hech narsani o'zgartirmaydi. "Bir xil origin" — brauzer `Sec-Fetch-Site`da aytgan narsa; bu sarlavha bo'lmasa, `Referer` hosti so'rovnikiga solishtiriladi, shuning uchun proksi ortida Astro'ning `security.allowedDomains`ini o'rnating.

[Server oroli](https://docs.astro.build/en/guides/server-islands/) yoki action'ning URL'ida lokal yo'q. U so'ragan sahifa uchun render qilinadi, bu `Referer`dan o'qiladi va faqat uning yo'li hisobga olinadi, shuning uchun server oldidagi proksi hech narsani o'zgartirmaydi va u hech qachon yo'naltirmaydi. Uning javobi `Vary: Referer`ni olib yuradi. `Referer` bo'lmasa (`no-referrer` siyosati), u standart lokalda bo'ladi, dinamik sahifada esa uning marshruti URL'dan olinadi, shuning uchun sahifa lug'atlari unga yetib bormaydi.

## Router adapteri {#router-adapter}

`createAstroRouterAdapter(locales, defaultLocale)` standartdan tashqari har bir lokalga prefiks qo'shadi. Astro adapteriga faqat `getCurrentPath` kerak; qolgan a'zolar ixtiyoriy va standart adapterga qaytadi: `getRouteName(path, locales, routePattern?)`, `getLocaleFromPath`, `switchLocalePath`, `localizePath`, `removeLocaleFromPath`, `resolvePath` (bosh sahifadan yo'naltirish maqsadi), `push`, `replace`, `getRoute`. Subdomen yoki suffiksli URL'lar uchun o'zingiznikini yozing va uni `createI18nMiddleware`ga uzating.

## SEO {#seo}

```astro
---
// src/layouts/Layout.astro
import { useLocaleHead } from '@i18n-micro/astro'

const head = useLocaleHead(Astro, { baseUrl: 'https://example.com' })
---

<html lang={head.htmlAttrs.lang} dir={head.htmlAttrs.dir}>
  <head>
    {head.link.map((l) => <link rel={l.rel} href={l.href} hreflang={l.hreflang} />)}
    {head.meta.map((m) => <meta property={m.property} content={m.content} />)}
  </head>
  <body><slot /></body>
</html>
```

U `htmlAttrs` (`iso`dan `lang`, `dir`), canonical havola (query'siz yo'l), `seo !== false` bo'lgan har bir yoqilgan lokal uchun `hreflang` muqobillari va `x-default`, `og:locale`, `og:locale:alternate` hamda `og:url`ni qaytaradi. Opsiyalar: `baseUrl` (Astro konfiguratsiyasidagi `site`, aks holda ildizga nisbiy URL'lar), `addDirAttribute` (`true`), `addSeoAttributes` (`true`), `hreflangBaseLanguage` (`false`).
