`@i18n-micro/types-generator` tarjimalar papkangizdagi har bir JSON faylni o'qiydi va barcha kalitlarni sanab o'tuvchi deklaratsiya yozadi. Muharriringiz `t()`, `$t()` va `<I18nT keypath>` ichida kalitlarni taklif qilishini xohlasangiz, uni qo'shing. U Nuxt moduli sifatida ham, Vite yoki Rollup plagini sifatida ham ishlaydi va fayl o'zgarganda qayta yaratadi.

## O'rnatish {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/types-generator
```

```bash npm
npm install -D @i18n-micro/types-generator
```

```bash yarn
yarn add -D @i18n-micro/types-generator
```

</CodeGroup>

Peer bog'liqlik: `@nuxt/kit` `^3.18.0 || ^4.0.0`. Uni faqat `/nuxt` kirish nuqtasi import qiladi; faqat Vite loyihasida peer ogohlantirishini e'tiborsiz qoldirish mumkin.

## Nuxt {#nuxt}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro', '@i18n-micro/types-generator/nuxt'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Modul `.nuxt/types/i18n-micro.d.ts` faylini yozadi va Nuxt uni turlar kontekstiga qo'shadi; qo'lda hech narsa qo'shish shart emas. U `i18nTypes.translationDir`ni o'qiydi, aks holda `nuxt-i18n-micro` tarjimalarni o'qiydigan joyni: har bir qatlamdagi `translationDir` (`i18n` yoki inline modul opsiyalaridan, standart `'locales'`) va `additionalTranslationDirs`. Ushbu papkadagi JSON faylni tahrirlash `nuxi dev`da turlarni qayta yaratadi. Nuxt'da `i18nTypes.outputFile` e'tiborsiz qoldiriladi (bu haqda ogohlantirish chiqadi).

## Vite {#vite}

`I18nTypesPlugin` — Vite plagini, uni Rollup ham qabul qiladi. Boshqa bundler uchun skriptda `generateTypes`ni chaqiring.

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { I18nTypesPlugin } from '@i18n-micro/types-generator'

export default defineConfig({
  plugins: [
    vue(),
    I18nTypesPlugin({
      srcDir: process.cwd(),
      translationDir: 'src/locales',
      outputFile: 'src/i18n-micro.d.ts',
    }),
  ],
})
```

| Opsiya | Majburiy | Izohlar |
| --- | --- | --- |
| `srcDir` | ha | Asosiy katalog; `translationDir` unga nisbatan aniqlanadi. |
| `translationDir` | ha | JSON fayllar joylashgan papka (`pages/` kabi ichki papkalar ham kiradi) yoki papkalar massivi. |
| `outputFile` | yo'q | Deklaratsiya qayerga yozilishi; standart `<srcDir>/i18n-micro.d.ts`. |

Plagin build boshlanishida bir marta yaratadi va dev serverda papkadagi o'zgarishdan 300 ms o'tgach qayta yaratadi. `tsconfig.json` faylingizdagi `include` chiqish faylini qamrab olishiga ishonch hosil qiling.

## Kalitlardan foydalanish {#use-the-keys}

Yaratilgan fayl `@i18n-micro/types` ichidagi `DefineLocaleMessage`ni kengaytiradi, bu esa `TranslationKey`ni sizning kalitlaringizga aylantiradi:

```ts
declare module '@i18n-micro/types' {
  export interface DefineLocaleMessage {
    nav: object
    'nav.home': string
    'profile.title': string
  }
}
```

Kalitlar — `t()` javob beradigan kalitlar, obyektlar ham, har bir lokal va har bir sahifa faylidan, o'z JSON qiymatining turi bilan. `TranslationKey` — ushbu kalitlar va istalgan satrning birlashmasi, shuning uchun siz xatolarni emas, avtoto'ldirishni olasiz: noto'g'ri yozilgan yoki dinamik kalit baribir kompilyatsiya qilinadi. Parametrlar va qaytariladigan qiymatlar turlanmagan.

Ma'lum prefiks ostidagi dinamik kalitlar uchun `ScopedKey<'prefix'>` mos kalitlarga toraytiradi:

```ts
import type { ScopedKey } from '@i18n-micro/types'

const statusText = (status: string) => t(`status.${status}` as ScopedKey<'status'>)
```

`TranslationKey` va `ScopedKey` `@i18n-micro/types`dan keladi (React, Preact va Solid `TranslationKey`ni qayta eksport qiladi; Vue esa yo'q).

## API {#api}

| Eksport | Kirish nuqtasi | Izohlar |
| --- | --- | --- |
| `I18nTypesPlugin(options)` | `@i18n-micro/types-generator` | Vite va Rollup plagini |
| `generateTypes(options)` | `@i18n-micro/types-generator` | faylni yozadi, uning yo'lini qaytaradi |
| `getTypesString(options)` | `@i18n-micro/types-generator` | deklaratsiyani yozmasdan qaytaradi |
| `formatKeyProperty(key)` | `@i18n-micro/types-generator` | yordamchi |
| Nuxt moduli (`configKey: 'i18nTypes'`) | `@i18n-micro/types-generator/nuxt` | `translationDir` opsiyasi |

To'liq signaturalar: [paket ma'lumotnomasi](/uz/api/packages/types-generator).
