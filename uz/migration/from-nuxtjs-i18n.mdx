# 🔄 `nuxt-i18n`'dan `Nuxt I18n Micro`'ga ko'chirish

## Sizga qaysi qo'llanma kerak?

| Siz ko'chirmoqchisiz…                | Qo'llanma                                            |
| -------------------------------------- | ------------------------------------------------ |
| `@nuxtjs/i18n` (vue-i18n asosidagi modul) | **Bu sahifa**                                    |
| `nuxt-i18n-micro` v2.x                 | [v2.x'dan v3.x'ga yangilash](/migration/v2-to-v3) |

## Nima uchun ko'chirish kerak?

- **Yaxshilangan ishlash**: bizning [benchmark fixture'larimizda](/guides/performance-results) `@nuxtjs/i18n` **v10.6** ga qarshi ~51% tezroq build va ~54% kamroq build xotira
- **Soddalashtirilgan konfiguratsiya**: Oqilona standart qiymatlar bilan soddalashtirilgan sozlash
- **Yaxshi resurs boshqaruvi**: Katta tarjima fayllarini optimallashtirilgan boshqaruv

## Asosiy farqlar

| Xususiyat                 | `nuxt-i18n`                      | `Nuxt I18n Micro`                         |
| ----------------------- | -------------------------------- | ----------------------------------------- |
| Tarjima fayllari       | JS/TS/JSON, `vueI18n` orqali yuklanadi | Faqat JSON, dev'da avtomatik generatsiya qilinadi          |
| Yo'nalish generatsiyasi        | Runtime                          | Build-time (`@i18n-micro/route-strategy`) |
| Tarjima yuklash     | JS'ga bundle qilinadi                  | Har bir sahifa uchun lazy-load JSON                 |
| Locale holati            | `vue-i18n` dan `useI18n()`      | `useI18nLocale()` composable              |
| `detectBrowserLanguage` | Qo'llab-quvvatlanadi                        | O'rniga `autoDetectLanguage` dan foydalaning          |

## Bosqichma-bosqich

### 1. O'rnatish

```bash
npm install nuxt-i18n-micro
```

### 2. Konfiguratsiyani yangilash

**Oldin (nuxt-i18n):**

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'fr', iso: 'fr-FR' },
    ],
    defaultLocale: 'en',
    vueI18n: './i18n.config.js',
    detectBrowserLanguage: { useCookie: true },
  },
})
```

**Keyin (Nuxt I18n Micro v3):**

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
    localeCookie: 'user-locale',
    autoDetectLanguage: true,
  },
})
```

### 3. Tarjima fayllarini qayta tashkil qilish

Tarjimalarni JSON formatida `locales` katalogiga ko'chiring. Bu yerda to'liq loyiha solishtirishi:

**Before (`nuxt-i18n`):**

```text
my-app/
├── i18n/
│   └── locales/          # langDir
│       ├── en.json       # all translations in one file
│       ├── ru.json
│       └── de.json
├── pages/
│   ├── index.vue
│   └── page.vue
├── server/
│   └── tsconfig.json
├── nuxt.config.ts        # config will change
└── package.json
```

**After (Nuxt I18n Micro):**

```text
my-app/
├── locales/              # translationDir
│   ├── en.json           # root-level translations
│   ├── ru.json
│   ├── de.json
│   └── pages/            # page-specific
│       ├── index/
│       │   ├── en.json
│       │   ├── ru.json
│       │   └── de.json
│       └── page/
│           ├── en.json
│           ├── ru.json
│           └── de.json
├── pages/
│   ├── index.vue         # API changes
│   └── page.vue
├── server/
│   └── tsconfig.json
├── nuxt.config.ts        # new config
└── package.json
```

<Tip>
Missing page-specific translation files are **auto-generated** in development mode — just run `nuxt dev` and the module will create empty JSON files for each page and locale.
</Tip>

### 4. Navigatsiyani yangilash

```diff
- <nuxt-link :to="{ name: 'index' }">Home</nuxt-link>
+ <NuxtLink :to="$localeRoute({ name: 'index' })">Home</NuxtLink>
+ <!-- or use the built-in component -->
+ <i18n-link :to="{ name: 'index' }">Home</i18n-link>
```

### 5. SEO'ni yangilash

`nuxt-i18n` dan har qanday qo'lda SEO konfiguratsiyalarini olib tashlang. Nuxt I18n Micro `meta: true` o'rnatilganda `hreflang`, canonical URL'lar va Open Graph teglarini avtomatik generatsiya qiladi.

### 6. Test qilish

Tarjimalar, locale almashtirish, redirect'lar va SEO meta teglarni sinchkovlik bilan test qiling.

## 🛡️ Umumiy muammolar va muammolarni bartaraf etish

### ❌ Tarjima fayllari yuklanmaydi

Tarjima fayllari to'g'ri katalogda ekanligiga va JSON formatiga rioya qilishiga ishonch hosil qiling. `translationDir` fayl joylashuvingizga mos kelishini tekshiring.

### ⚠️ Yo'nalish topilmadi xatolari

`locales` massividagi barcha locale kodlari to'g'ri va yo'nalishlar to'g'ri sozlanganligini tekshiring.

### 🏷️ SEO teglari yo'q

`meta: true` o'rnatilgan va har bir locale yaroqli `iso` kodiga ega ekanligini tekshiring.

### 🔄 Hydration mos kelmasligi

Agar `no_prefix` strategiyasidan foydalansangiz, server va client locale bo'yicha rozi bo'lishini ta'minlash uchun `order: -10` bilan server plaginida `useI18nLocale().setLocale()` yordamida locale'ni o'rnating. [Maxsus til aniqlash](/guides/custom-language-detection) ga qarang.

### 🍪 Redirect'lar ishlamayapti

Prefiks strategiyalari uchun `localeCookie: 'user-locale'` o'rnatilganligiga ishonch hosil qiling. Cookie'siz server redirect plagini foydalanuvchining afzal locale'ini sahifa qayta yuklashlar bo'ylab eslay olmaydi.
