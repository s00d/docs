## Talablar

- **Node.js**: 18 yoki undan yangi.
- **Nuxt**: 3.x yoki 4.x.

Modul ham Nuxt 3 loyiha tuzilishini (`pages/**/*.vue`), ham Nuxt 4 tuzilishini (`app/pages/**/*.vue`) qoʻllab-quvvatlaydi. Tarjimalar Nuxt 4 dagi `app/` katalogidan foydalanilganda ham konvensiya boʻyicha loyiha ildizida (`locales/`) joylashadi.

## Nuxt modulini oʻrnatish

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Uni `nuxt.config.ts` da roʻyxatdan oʻtkazing:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Toʻliq yoʻriqnoma uchun [Tezkor start](/quickstart) bilan tanishing yoki har bir parametr uchun [Sozlash havolasi](/guides/configuration) ga qarang.

## Loyiha tuzilishi

Standart holatda modul quyidagini kutadi:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Root darajadagi fayllar build vaqtida har bir sahifa boʻyicha faylga birlashtiriladi. Sahifa boʻyicha fayllar `nuxt dev` paytida topilmasa avtomatik yaratiladi.

## Nuxt 4 tuzilishi

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Tarjimalarni `app/` ostida birga joylashtirish uchun `translationDir: 'app/locales'` ni oʻrnating.

## TypeScript

Modul standart locale fayllaringizga asoslanib `useI18n`, `$t` va tegishli yordamchilar uchun ambient turlarni yaratadi. Bu standart holatda yoqilgan (`types: true`).

Tarjima kalitlarini kuchliroq tiplashtirish uchun [`@i18n-micro/types-generator`](/integrations/types-generator) ga qarang.
