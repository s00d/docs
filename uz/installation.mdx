## Talablar

- **Node.js**: 18 yoki undan yangi versiya.
- **Nuxt**: 3.x yoki 4.x.

Modul ham Nuxt 3 loyiha tuzilishini (`pages/**/*.vue`), ham Nuxt 4 tuzilishini (`app/pages/**/*.vue`) qo'llab-quvvatlaydi. Konvensiya bo'yicha tarjimalar loyiha ildizida (`locales/`) joylashadi, hatto Nuxt 4 `app/` katalogidan foydalanilganda ham.

## Nuxt modulini o'rnatish

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

`nuxt.config.ts` faylida ro'yxatdan o'tkazing:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

To'liq qo'llanma uchun [Tez boshlash](/quickstart) bo'limiga yoki har bir opsiya uchun [Konfiguratsiya ma'lumotnomasi](/guides/configuration) bo'limiga qarang.

## Loyiha tuzilishi

Standart holatda modul quyidagini kutadi:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Root darajasidagi fayllar build vaqtida har bir sahifaga tegishli faylga birlashtiriladi. Sahifaga tegishli fayllar `nuxt dev` davomida yo'q bo'lsa avtomatik yaratiladi.

## Nuxt 4 tuzilishi

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Tarjimalarni `app/` ostiga joylashtirish uchun `translationDir: 'app/locales'` qiymatini bering.

## TypeScript

Modul standart locale fayllaringiz asosida `useI18n`, `$t` va tegishli yordamchilar uchun ambient turlarini generatsiya qiladi. Bu standart yoqilgan (`types: true`).

Tarjima kalitlarining kuchliroq tiplashtirishi uchun [`@i18n-micro/types-generator`](/integrations/types-generator) bo'limiga qarang.
