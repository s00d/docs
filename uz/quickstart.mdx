## 🚀 Tezkor start

### Oʻrnatish

Modulni Nuxt ilovangizga oʻrnating:

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

### Asosiy sozlash

Modulni `nuxt.config.ts` faylingizga qoʻshing:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

<Tip>
- **Root darajadagi fayllar** (`locales/en.json` va h.k.) — butun ilova boʻyicha ulashilgan tarjimalar (menyular, footer, umumiy UI). `translationPayloads.mode: 'premerged'` (standart) bilan ular build vaqtida har bir sahifaga birlashtiriladi.
- **Sahifa boʻyicha fayllar** (`locales/pages/<route>/<locale>.json`) — muayyan sahifalarga tegishli tarjimalar, faqat sahifaga tashrif buyurilganda yuklanadi.
- **Dinamik marshrutlar** — `pages/articles/[id].vue` `locales/pages/articles-id/` bilan bogʻlanadi (qavslar tire bilan almashtiriladi).
- **Avtomatik yaratish** — `nuxt dev` ishlaganda mavjud boʻlmagan barcha tarjima fayllari avtomatik yaratiladi.
</Tip>

<Info>
Modul har ikkala tuzilishni qoʻllab-quvvatlaydi:

- **Sahifalar**: `pages/**/*.vue` (Nuxt 3) yoki `app/pages/**/*.vue` (Nuxt 4)
- **Tarjimalar**: `locales/` papkasini standart holatda **loyihaning ildizida** saqlang (tavsiya etilgan konvensiya), `app/` ichida emas

```tree
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   ├── en.json
│   └── pages/
└── nuxt.config.ts
```

Ixtiyoriy birga joylashtirish: `i18n: \{ translationDir: 'app/locales' \}` ([fixture `n3`](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/n3) ga qarang).

Ixtiyoriy CLI yordamchisi `text-to-i18n` uchun [`nuxt-i18n-micro-cli` ≥ 2.1.1](/guides/cli#-text-to-i18n-command) dan foydalaning, shunda `app/pages` va `app/components` loyiha ildizidan skanerlanadi.
</Info>

### Asosiy foydalanish

Komponentlaringizda tarjimalardan foydalaning:

```vue
<template>
  <div>
    <h1>{{ $t('welcome') }}</h1>
    <p>{{ $t('description', { name: 'World' }) }}</p>

    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" @click="$switchLocale(locale.code)">
        {{ locale.code }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useI18n } from '#imports'

const { $t, $getLocales, $switchLocale } = useI18n()
</script>
```
