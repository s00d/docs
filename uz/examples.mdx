# 📚 Nuxt I18n Micro misollari va foydalanish

Ushbu boʻlimda `Nuxt I18n Micro` ni Nuxt.js ilovangizda qanday ishlatishni koʻrsatuvchi turli misollar keltirilgan. Locale’ni almashtirish, `<i18n-link>`, `<i18n-switcher>` va `<i18n-t>` komponentlaridan foydalanish, hamda tarjima kalitlarini dinamik tarzda ishlatish usullarini koʻrasiz.

## 🛠️ Asosiy sozlash

`Nuxt I18n Micro` bilan ishlashni boshlash uchun asosiy sozlama:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Locale almashtirish

### Dasturiy ravishda locale almashtirish

Ushbu misolda tugmalar orqali dasturiy ravishda locale almashtirish koʻrsatilgan:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Locale almashtirish uchun JSON misoli

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### `<i18n-switcher>` komponentidan foydalanish

`<i18n-switcher>` komponenti sozlanadigan yorliqlar bilan locale almashtirish uchun ochiladigan menyu taqdim etadi:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 🌐 Mahalliylashtirilgan navigatsiya uchun `<i18n-link>` dan foydalanish

`<i18n-link>` komponenti locale’ga xos marshrutlashni avtomatik boshqaradi:

```vue
<template>
  <div>
    <i18n-link to="/about">{{ $t('about') }}</i18n-link>
    <i18n-link :to="{ name: 'index' }">{{ $t('home') }}</i18n-link>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Navigatsiya havolalari uchun JSON misoli

```json
{
  "about": "About Us",
  "home": "Home"
}
```

### Faol havola uslubi bilan misol

```vue
<template>
  <div>
    <i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
  </div>
</template>
```

### Faol havola uslubi uchun JSON misoli

Ushbu ssenariy uchun avvalgi misoldagi bilan bir xil JSON fayldan foydalanish mumkin.

## 📝 Tarjima fayllaridan dinamik kalitlarni chiqarish

Baʼzi holatlarda tarjima fayllaringizda saqlangan dinamik kalitlar boʻyicha iteratsiya qilib, ularning qiymatlarini shartli ravishda chiqarish kerak boʻlishi mumkin. Quyidagi misolda `Nuxt I18n Micro` yordamida buni qanday amalga oshirish koʻrsatilgan.

### Misol: dinamik kalitlarni chiqarish

Ushbu misol muayyan tarjima yoʻlidan (bu holda `dynamic`) kalitlar massivini oladi va ular boʻyicha iteratsiya qiladi. Har bir kalit `$has` yordamida mavjudligi tekshiriladi va soʻngra `$t` orqali qiymati chiqariladi.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Tarjima fayli misoli (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Misol: obyektdan dinamik kalitlarni chiqarish

Ushbu misolda tarjima faylida saqlangan obyekt bilan ishlaymiz. Obyekt kalitlarini olib, ular boʻyicha iteratsiya qilamiz va kalit nomlari hamda ular bilan bogʻliq qiymatlarni dinamik ravishda chiqaramiz.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Tarjima fayli misoli (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 Slotlar va interpolatsiya bilan tarjimalar uchun `<i18n-t>` dan foydalanish

`<i18n-t>` komponenti dinamik kontent va HTML teglari bilan tarjimalarni chiqarish uchun foydalidir:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### `<i18n-t>` uchun JSON misoli

```json
{
  "greeting": "Welcome to the page"
}
```

### Interpolatsiya bilan

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### Interpolatsiya uchun JSON misoli

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 Koʻplik shakli uchun `$tc` dan foydalanish

`Nuxt I18n Micro` dagi `$tc` funksiyasi son va locale sozlamalariga qarab koʻplikni boshqaradi. Bu, elementlar, bildirishnomalar yoki miqdori oʻzgaruvchi boshqa obyektlar kabi sonlarga bogʻliq xabarlarni dinamik ravishda sozlash uchun foydali.

### Misol: koʻplik uchun `$tc` dan foydalanish

Quyidagi misolda `$tc` yordamida olmalar sonini bildiruvchi xabar chiqariladi. Tarjima kaliti berilgan songa qarab bir nechta koʻplik shakllarini boshqaradi.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### Koʻplik uchun JSON misoli

Turli koʻplik shakllarini boshqarish uchun JSON faylingizda tarjimani quyidagicha aniqlashingiz mumkin:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Tushuntirish

- **`$tc('apples', 0)`**: son nolga teng boʻlganda birinchi shaklni qaytaradi (`"no apples"`).
- **`$tc('apples', 1)`**: son bittaga teng boʻlganda ikkinchi shaklni qaytaradi (`"one apple"`).
- **`$tc('apples', 10)`**: son ikki yoki undan koʻp boʻlganda son qiymati bilan uchinchi shaklni qaytaradi (`"10 apples"`).

### Murakkabroq koʻplik bilan qoʻshimcha misol

Agar ilovangiz koʻproq murakkab koʻplik qoidalarini boshqarishi kerak boʻlsa (masalan, nol, bir, ikki, bir necha, koʻp, boshqa uchun maxsus holatlar), tarjima satrlarini kengaytirishingiz mumkin:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: `"two apples"` ni qaytarishi mumkin.
- **`$tc('apples', 3)`**: son uchun aniqlangan qoidalarga qarab `"a few apples"` ni qaytarishi mumkin.

## 🌐 Raqamlarni formatlash uchun `$tn` dan foydalanish

`$tn` funksiyasi joriy locale asosida raqamlarni `Intl.NumberFormat` API yordamida formatlaydi. Bu foydalanuvchining hududiy sozlamalariga mos raqamlarni koʻrsatish uchun foydali. Masalan, valyuta, foizlar yoki boshqa raqam formatlari uchun.

### Misol: raqamlarni formatlash uchun `$tn` dan foydalanish

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ Sana va vaqtni formatlash uchun `$td` dan foydalanish

`$td` funksiyasi joriy locale asosida sana va vaqtlarni `Intl.DateTimeFormat` API yordamida formatlaydi. Bu foydalanuvchining locale sozlamalariga mos formatlarda sana va vaqtlarni koʻrsatish uchun foydali.

### Misol: sana va vaqtni formatlash uchun `$td` dan foydalanish

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ Nisbiy sana formatlash uchun `$tdr` dan foydalanish

`$tdr` funksiyasi joriy locale asosida sanalarni nisbiy vaqt sifatida formatlaydi (masalan, "5 daqiqa oldin", "2 kun oldin") va `Intl.RelativeTimeFormat` API dan foydalanadi. Bu joriy sana va vaqtga nisbatan vaqt farqlarini koʻrsatish uchun foydali.

### Misol: nisbiy sana formatlash uchun `$tdr` dan foydalanish

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
