# 📚 Nuxt I18n Micro misollari va foydalanish

Ushbu bo'lim `Nuxt I18n Micro` ni Nuxt.js ilovangizda qanday ishlatishni ko'rsatuvchi turli misollarni taqdim etadi. Locale'larni qanday almashtirishni, `<i18n-link>`, `<i18n-switcher>` va `<i18n-t>` komponentlaridan foydalanishni hamda tarjima kalitlarini dinamik boshqarishni ko'rasiz.

## 🛠️ Asosiy sozlash

`Nuxt I18n Micro` bilan boshlash uchun asosiy sozlash:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Locale almashtirish

### Dasturiy tarzda Locale'larni almashtirish

Ushbu misol tugmalar yordamida locale'larni dasturiy tarzda qanday almashtirishni ko'rsatadi:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Locale almashtirish uchun JSON namunasi

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### `<i18n-switcher>` komponentidan foydalanish

`<i18n-switcher>` komponenti sozlanadigan yorliqlar bilan locale almashtirish uchun dropdown taqdim etadi:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 🌐 Lokalizatsiyalangan navigatsiya uchun `<i18n-link>` dan foydalanish

```vue

```

### Navigatsiya havolalari uchun JSON namunasi

```json
{
  "about": "About Us",
  "home": "Home"

```

### Faol havola uslublash bilan misol

```vue
<template>

```

### Faol havola uslublash uchun JSON namunasi

Bu holat uchun oldingi misoldagi bir xil JSON faylidan foydalanish mumkin.

## 📝 Tarjima fayllaridan dinamik kalitlarni render qilish

Ba'zi holatlarda tarjima fayllaringiz ichida saqlangan dinamik kalitlar bo'yicha iteratsiya qilib, ularning qiymatlarini shartli tarzda render qilish kerak bo'lishi mumkin. Quyidagi misol `Nuxt I18n Micro` yordamida buni qanday amalga oshirishni ko'rsatadi.

### Misol: Dinamik kalitlarni render qilish

Bu misol muayyan tarjima yo'lidan (bu holda `dynamic`) kalitlar massivini oladi va ular bo'yicha iteratsiya qiladi. Har bir kalit `$t` bilan qiymati render qilinishidan oldin `$has` yordamida mavjudligi tekshiriladi.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Tarjima fayli namunasi (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Misol: Obyektdan dinamik kalitlarni render qilish

Bu misolda tarjima faylingiz ichida saqlangan obyekt bilan ishlaymiz. Obyekt kalitlarini olib, ular bo'yicha iteratsiya qilamiz va kalit nomlarini hamda ularga tegishli qiymatlarni dinamik ravishda render qilamiz.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Tarjima fayli namunasi (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 Slotlar va interpolatsiya bilan tarjimalar uchun `<i18n-t>` dan foydalanish

`<i18n-t>` komponenti dinamik kontent va HTML teglari bilan tarjimalarni render qilish uchun foydalidir:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### `<i18n-t>` uchun JSON namunasi

```json
{
  "greeting": "Welcome to the page"
}
```

### Interpolatsiya bilan

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### Interpolatsiya uchun JSON namunasi

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 Ko'plik uchun `$tc` dan foydalanish

`Nuxt I18n Micro` dagi `$tc` funksiyasi son va locale sozlamalari asosida ko'plikni boshqaradi. Bu elementlar, bildirishnomalar yoki sonlarga qarab o'zgaradigan boshqa obyektlar kabi son bilan bog'liq xabarlarni dinamik tarzda moslashtirish uchun foydalidir.

### Misol: Ko'plik uchun `$tc` dan foydalanish

Quyidagi misolda `$tc` yordamida olma sonini ko'rsatuvchi xabarni ekranga chiqaramiz. Tarjima kaliti taqdim etilgan son asosida bir nechta ko'plik shakllarini boshqaradi.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### Ko'plik uchun JSON namunasi

Turli ko'plik shakllarini boshqarish uchun JSON faylida tarjimani quyidagicha aniqlashingiz mumkin:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Tushuntirish

- **`$tc('apples', 0)`**: Birinchi shaklni qaytaradi, son nolga teng bo'lganda ishlatiladi (`"no apples"`).
- **`$tc('apples', 1)`**: Ikkinchi shaklni qaytaradi, son birga teng bo'lganda ishlatiladi (`"one apple"`).
- **`$tc('apples', 10)`**: Uchinchi shaklni son qiymati bilan qaytaradi, son ikki yoki undan ko'p bo'lganda ishlatiladi (`"10 apples"`).

### Murakkabroq ko'plik bilan qo'shimcha misol

Agar ilovangiz murakkabroq ko'plik qoidalarini (masalan, nol, bir, ikki, kam, ko'p, boshqa uchun maxsus holatlar) boshqarishi kerak bo'lsa, tarjima satrlarini mos ravishda kengaytirishingiz mumkin:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: `"two apples"` qaytaradigan qilib sozlanishi mumkin.
- **`$tc('apples', 3)`**: Son uchun aniqlangan qoidalarga qarab `"a few apples"` qaytarishi mumkin.

## 🌐 Sonlarni formatlash uchun `$tn` dan foydalanish

`$tn` funksiyasi `Intl.NumberFormat` API yordamida sonlarni joriy locale ga muvofiq formatlaydi. Bu foydalanuvchining mintaqaviy sozlamalariga mos ravishda valyuta, foizlar yoki boshqa son formatlarini ko'rsatish uchun foydalidir.

### Misol: Sonlarni formatlash uchun `$tn` dan foydalanish

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ Sana va vaqtni formatlash uchun `$td` dan foydalanish

`$td` funksiyasi `Intl.DateTimeFormat` API yordamida sana va vaqtlarni joriy locale ga muvofiq formatlaydi. Bu foydalanuvchiga locale sozlamalari asosida tanish bo'lgan formatlarda sana va vaqtlarni ko'rsatish uchun foydalidir.

### Misol: Sana va vaqtni formatlash uchun `$td` dan foydalanish

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ Nisbiy sanani formatlash uchun `$tdr` dan foydalanish

`$tdr` funksiyasi `Intl.RelativeTimeFormat` API yordamida sanalarni nisbiy vaqt sifatida (masalan, "5 daqiqa oldin", "2 kun oldin") joriy locale ga muvofiq formatlaydi. Bu joriy sana va vaqtga nisbatan vaqt farqlarini ko'rsatish uchun foydalidir.

### Misol: Nisbiy sanani formatlash uchun `$tdr` dan foydalanish

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
