## Cerințe

- **Node.js**: 18 sau mai nou.
- **Nuxt**: 3.x sau 4.x.

Modulul suportă atât structura de proiect Nuxt 3 (`pages/**/*.vue`), cât și structura Nuxt 4 (`app/pages/**/*.vue`). Traducerile stau la rădăcina proiectului prin convenție (`locales/`), chiar și atunci când folosești directorul `app/` din Nuxt 4.

## Instalează modulul Nuxt

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Înregistrează-l în `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Consultă [Ghidul rapid](/quickstart) pentru un tur complet sau [Referința de configurare](/guides/configuration) pentru fiecare opțiune.

## Structura proiectului

În mod implicit modulul așteaptă:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Fișierele la nivel de rădăcină sunt îmbinate în fiecare fișier specific paginii la build. Fișierele specifice paginii sunt create automat atunci când lipsesc, în timpul `nuxt dev`.

## Structura Nuxt 4

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Pentru a colocaliza traducerile sub `app/`, setează `translationDir: 'app/locales'`.

Pachetele interne partajate sunt aduse tranzitiv.

## TypeScript

Modulul generează tipuri ambientale pentru `useI18n`, `$t` și helper-ii înrudiți pe baza fișierelor tale de locale implicit. Aceasta este activată implicit (`types: true`).

Pentru tipare mai strictă a cheilor de traducere, vezi [`@i18n-micro/types-generator`](/integrations/types-generator).
