title: "Astro"
description: "Traduceri pe server, rute cu prefix de limbă, detectare pe pagina principală și tag-uri SEO pentru Astro cu @i18n-micro/astro."
---

`@i18n-micro/astro` traduce paginile Astro pe server: un middleware alege limba din URL și pune o instanță per cerere în `Astro.locals`, iar `useI18n(Astro)` o citește. Folosește-l într-un site Astro care are nevoie de URL-uri cu prefix de limbă (`/about`, `/fr/about`) și de dicționare JSON partajate. Primești componente `.astro`, o redirecționare a paginii principale către limba vizitatorului, tag-uri `hreflang` și props pentru [insule](/ro/integrations/astro-islands).

## Instalare {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/astro
```

```bash npm
npm install @i18n-micro/astro
```

```bash yarn
yarn add @i18n-micro/astro
```

</CodeGroup>

Dependențe peer: `astro` `^5.0.0 || ^6.0.0 || ^7.0.0`. Opționale, doar pentru [insule](/ro/integrations/astro-islands): `vue` `^3.3.0`, `react` `^16.8.0 || ^17.0.0 || ^18.0.0 || ^19.0.0`, `preact` `^10.0.0 || ^11.0.0`, `svelte` `^4.0.0 || ^5.0.0`.

## Configurare {#setup}

Adaugă integrarea. Aceasta include dicționarele tale în server și instalează middleware-ul, deci nu este nevoie de `src/middleware.ts`:

```ts
// astro.config.mjs
import { defineConfig } from 'astro/config'
import node from '@astrojs/node'
import { i18nIntegration } from '@i18n-micro/astro'

export default defineConfig({
  output: 'server',
  adapter: node({ mode: 'standalone' }),
  integrations: [
    i18nIntegration({
      locale: 'en',
      fallbackLocale: 'en',
      locales: [
        { code: 'en', iso: 'en-US', displayName: 'English' },
        { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
        { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
      ],
      translationDir: 'src/locales',
    }),
  ],
})
```

Dicționarele devin cod la momentul build-ului: serverul nu citește nimic de pe disc, așa că rulează și pe edge (Cloudflare, Vercel Edge). În `astro dev`, o modificare a unui fișier se aplică la următoarea cerere.

### Opțiunile integrării {#integration-options}

| Opțiune | Implicit | Note |
| --- | --- | --- |
| `locale` | obligatoriu | Limba implicită. |
| `fallbackLocale` | `locale` | |
| `locales` | `[]` | Obiecte `Locale` complete. Una `disabled` nu este limba niciunui URL și nici țintă de redirecționare. `iso` este eticheta după care se aleg pluralele când codul nu este unul valid (`ua` → `uk-UA`). |
| `translationDir` | niciuna | Folderul inclus în server, relativ la rădăcina proiectului. |
| `disablePageLocales` | `false` | Fișierele de pagină contează ca traduceri rădăcină. |
| `autoDetect` | `true` | Redirecționarea paginii principale, vezi [Detectarea limbii](#locale-detection). |
| `redirectToDefault` | `false` | `/` redirecționează și când nimic nu preferă altă limbă. |
| `localeCookie` | `'i18n-locale'` | `null` dezactivează cookie-ul. |
| `missingWarn` | `false` | |
| `middleware` | `true` | `false`: scrie tu middleware-ul, vezi mai jos. |

Setările runtime sunt publicate în `virtual:i18n-micro/config` (`config.base` este `base`-ul Astro, `config.localeCodes` codurile activate), iar dicționarele în `virtual:i18n-micro/messages`.

### Propriul middleware {#your-own-middleware}

O regulă de plural, un handler pentru chei lipsă și un adaptor de router nu pot trece din procesul de configurare în bundle-ul serverului. Pentru acestea, transmite `middleware: false` și scrie `src/middleware.ts`. Configurația `i18n` a Astro este atunci setată pentru tine cu `routing: 'manual'`, astfel încât `Astro.currentLocale` și `astro:i18n` funcționează. Astro nu permite această setare fără un `src/middleware.ts`, deci cu middleware-ul propriu al integrării acestea nu funcționează.

```ts
// src/middleware.ts
import { config } from 'virtual:i18n-micro/config'
import { messages } from 'virtual:i18n-micro/messages'
import { createAstroRouterAdapter, createI18n, createI18nMiddleware, localeIsoMap } from '@i18n-micro/astro'

const i18n = createI18n({
  locale: config.defaultLocale,
  fallbackLocale: config.fallbackLocale,
  localeIso: localeIsoMap(config.locales),
  messages: messages.root,
  routeMessages: messages.routes,
  plural: myPluralRule,
})

export const onRequest = createI18nMiddleware({
  i18n,
  defaultLocale: config.defaultLocale,
  locales: config.localeCodes,
  localeObjects: config.locales,
  autoDetect: config.autoDetect,
  redirectToDefault: config.redirectToDefault,
  localeCookie: config.localeCookie,
  base: config.base,
  routingStrategy: createAstroRouterAdapter(config.locales, config.defaultLocale),
})
```

Pentru a citi în schimb folderul la runtime, `loadTranslationsFromDir` și `loadTranslationsIntoI18n` se află în `@i18n-micro/astro/node` (doar Node).

### Opțiunile middleware-ului {#middleware-options}

| Opțiune | Implicit | Note |
| --- | --- | --- |
| `i18n` | obligatoriu | Instanța globală; fiecare cerere primește `i18n.fork(locale)`, care costă la fel indiferent de numărul de dicționare. |
| `defaultLocale` | obligatoriu | |
| `locales` | obligatoriu | Codurile limbilor. |
| `localeObjects` | `locales` ca `{ code }` | Obiecte `Locale` complete pentru componente și SEO. |
| `autoDetect` | `true` | Redirecționarea paginii principale, vezi [Detectarea limbii](#locale-detection). |
| `redirectToDefault` | `false` | `/` redirecționează și când nimic nu preferă altă limbă, către pagina principală a limbii implicite așa cum o rezolvă strategia de rutare. |
| `localeCookie` | `'i18n-locale'` | `null` dezactivează cookie-ul. |
| `routingStrategy` | prefix cu excepția limbii implicite | Adaptorul de router. Metodele pe care le omite provin din adaptorul implicit. |
| `base` | niciuna | `base`-ul Astro: `config.base`. |

Fișierele de pagină (`src/locales/pages/blog/post/de.json`) corespund rutei `blog-post`: calea paginii unită cu `-`.

## Traducere {#translate}

```astro
---
// src/pages/index.astro
import { useI18n } from '@i18n-micro/astro'
import I18nT from '@i18n-micro/astro/i18n-t'

const { t, tc, locale } = useI18n(Astro)
---

<h1>{t('greeting', { name: 'Ada' })}</h1>
<p>{tc('apples', 3)}</p>
<I18nT keypath="welcome" tag="p" />
<p>{locale}</p>
```

`useI18n(Astro)` returnează `locale`, `defaultLocale`, `locales`, `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`, `getRoute`, `getRouteName(path?)`, `getLocaleFromPath(path?)`, `switchLocalePath(locale)`, `localizePath(path, locale?)`, `getBasePath(url?)`, `getI18n`, `addTranslations`, `addRouteTranslations`, `mergeTranslations` și `clearCache`. Aruncă o eroare când middleware-ul nu a rulat. Helperii `getI18n`, `getLocale`, `getDefaultLocale` și `getLocales` citesc același `Astro.locals`.

Numele rutei provine din ruta fără limba ei: `/fr/blog/post` → `blog-post`, iar fiecare URL al `src/pages/blog/[slug].astro` → `blog-slug`, astfel încât un singur folder `locales/pages/blog-slug/` le servește pe toate. `[...path]` este `path`. Sub `base`-ul Astro, helperii primesc și returnează URL-uri ale site-ului: `switchLocalePath` și `localizePath` îl includ, `getBasePath` nu, deoarece `Astro.rewrite` primește calea fără el.

### Componente {#components}

Importă-le din `@i18n-micro/astro/<name>` (sau `@i18n-micro/astro/components/<name>.astro`):

| Componentă | Props |
| --- | --- |
| `i18n-t` | `keypath`, `params`, `plural`, `number`, `date`, `relativeDate`, `tag` (`span`, orice tag), `html`, `hideIfEmpty`, `defaultValue`; celelalte atribute sunt transmise mai departe. Cu `html`, rezultatul fiecărei ramuri este randat ca HTML, iar `params` sunt escapate. Nu există sloturi |
| `i18n-link` | `href`, `locale` (limba țintă, implicit cea curentă), `class`; celelalte atribute sunt transmise mai departe. URL-urile externe, `#hash` și `?query` rămân așa cum sunt scrise; o rută își păstrează query-ul, hash-ul și slash-ul final |
| `i18n-switcher` | `class`, `activeClass` (`'active'`), `customLabels`; randează linkuri către pagina curentă în fiecare limbă activată, cu query-ul ei |
| `i18n-group` | niciunul care să schimbe rezultatul: un `<div>` în jurul slotului său, fără prefix |

## Rute cu prefix de limbă {#locale-prefixed-routes}

Păstrează o pagină per rută în `src/pages/` și adaugă stub-uri subțiri de rewrite în `src/pages/[locale]/`:

```
src/pages/
  index.astro
  about.astro
  [locale]/
    index.astro
    about.astro
```

```astro
---
// src/pages/[locale]/about.astro
import { prepareLocaleRewrite } from '@i18n-micro/astro'

const target = prepareLocaleRewrite(Astro)
if (target instanceof Response) return target
return Astro.rewrite(target)
---
```

`prepareLocaleRewrite` returnează un răspuns `404` pentru un `:locale` necunoscut; altfel setează limba pe `Astro.locals` și returnează calea fără prefix. Middleware-ul păstrează o limbă deja prezentă în `locals`, așa că pagina rescrisă se randează în ea. `getLocaleRewritePath(Astro)` returnează doar calea, pentru când validezi tu limba.

## Detectarea limbii {#locale-detection}

URL-ul decide limba paginii:

1. Un prefix de limbă (`/fr/about` → `fr`; `/en/about` este tot `en`).
2. Altfel, ceea ce returnează `getLocaleFromPath` al adaptorului de router, dacă nu este limba implicită.
3. Altfel, limba implicită. `/about` este întotdeauna pagina limbii implicite, indiferent ce spune cookie-ul.

`autoDetect` este un indiciu de redirecționare doar pe pagina principală:

- O cerere pentru `/` al cărei cookie sau `Accept-Language` preferă altă limbă primește un `302` către pagina principală a acelei limbi (`/de`). Ponderile q sunt respectate; `de-DE` se potrivește cu o limbă `de`, iar `de` se potrivește cu una `de-DE`.
- Cu `redirectToDefault`, `/` redirecționează întotdeauna: către pagina principală a limbii preferate, altfel a celei implicite.
- Răspunsul pentru `/` conține `Vary: Cookie, Accept-Language` (doar `Accept-Language` când `localeCookie` este `null`).
- Paginile prerandate nu redirecționează niciodată.

`detectLocale(pathname, cookies, headers, defaultLocale, locales, localeCookie?, routingStrategy?, autoDetect?)` returnează aceeași limbă preferată pentru propria ta logică.

Cookie-ul reține o alegere. O vizualizare de pagină care vine de la o pagină de aceeași origine într-o altă limbă înseamnă că vizitatorul schimbă limba, indiferent de linkul care l-a adus acolo: răspunsul HTML setează cookie-ul la noua limbă, iar `/` nu redirecționează, astfel încât un selector ajunge la pagina principală a limbii implicite. Un endpoint, o imagine, un 404, un form post și un prefetch nu schimbă nimic. „Aceeași origine” este ceea ce spune browserul în `Sec-Fetch-Site`; fără acel header, host-ul din `Referer` este comparat cu cel al cererii, așa că în spatele unui proxy setează `security.allowedDomains` din Astro.

O [insulă de server](https://docs.astro.build/en/guides/server-islands/) sau o acțiune nu are limbă în URL. Este randată pentru pagina care a cerut-o, citită din `Referer`, din care contează doar calea, așa că un proxy în fața serverului nu schimbă nimic, și nu redirecționează niciodată. Răspunsul său conține `Vary: Referer`. Fără un `Referer` (o politică `no-referrer`) este în limba implicită, iar pe o pagină dinamică ruta sa provine din URL, așa că dicționarele de pagină nu ajung la ea.

## Adaptorul de router {#router-adapter}

`createAstroRouterAdapter(locales, defaultLocale)` adaugă prefix fiecărei limbi cu excepția celei implicite. Un adaptor Astro are nevoie doar de `getCurrentPath`; ceilalți membri sunt opționali și revin la adaptorul implicit: `getRouteName(path, locales, routePattern?)`, `getLocaleFromPath`, `switchLocalePath`, `localizePath`, `removeLocaleFromPath`, `resolvePath` (ținta redirecționării paginii principale), `push`, `replace`, `getRoute`. Scrie-ți propriul adaptor pentru URL-uri cu subdomeniu sau sufix și transmite-l lui `createI18nMiddleware`.

## SEO {#seo}

```astro
---
// src/layouts/Layout.astro
import { useLocaleHead } from '@i18n-micro/astro'

const head = useLocaleHead(Astro, { baseUrl: 'https://example.com' })
---

<html lang={head.htmlAttrs.lang} dir={head.htmlAttrs.dir}>
  <head>
    {head.link.map((l) => <link rel={l.rel} href={l.href} hreflang={l.hreflang} />)}
    {head.meta.map((m) => <meta property={m.property} content={m.content} />)}
  </head>
  <body><slot /></body>
</html>
```

Returnează `htmlAttrs` (`lang` din `iso`, `dir`), un link canonical (calea fără query), alternative `hreflang` pentru fiecare limbă activată cu `seo !== false` plus `x-default`, `og:locale`, `og:locale:alternate` și `og:url`. Opțiuni: `baseUrl` (`site` din configurația Astro, altfel URL-uri relative la rădăcină), `addDirAttribute` (`true`), `addSeoAttributes` (`true`), `hreflangBaseLanguage` (`false`).
