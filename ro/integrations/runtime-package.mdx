`@i18n-micro/runtime` este instanța i18n independentă de framework: dicționare, `t()`, plurale, formatare `Intl` și un abonament la modificări, fără `fs` și fără framework. Folosiți-o în TypeScript simplu, într-un web worker, într-o funcție edge sau ca bază pentru propria integrare. Pachetele React, Preact, Node și Astro extind aceeași clasă.

## Instalare {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/runtime
```

```bash npm
npm install @i18n-micro/runtime
```

```bash yarn
yarn add @i18n-micro/runtime
```

</CodeGroup>

Nu are dependențe peer. Pentru fișiere de traducere de pe disc, folosiți [`@i18n-micro/node`](/ro/integrations/nodejs-package).

## Configurare {#setup}

```ts
import { createI18n } from '@i18n-micro/runtime'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    en: { greeting: 'Hello, {name}!', apples: 'no apples | one apple | {count} apples' },
    de: { greeting: 'Hallo, {name}!' },
  },
  routeMessages: {
    about: { en: { title: 'About us' } },
  },
})
```

Toate opțiunile (`plural`, `missingWarn`, `missingHandler`, `numberFormats`, `datetimeFormats`) sunt enumerate în [instanța](/ro/integrations/overview#the-instance).

## Traducere {#translate}

```ts
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.tc('apples', 5) // '5 apples'
i18n.tn(1234.5) // '1,234.5'

i18n.setRoute('about')
i18n.t('title') // 'About us' (route dictionary)
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!' (root, still visible)
```

Încărcați mai multe dicționare ulterior:

```ts
i18n.loadMessages({ fr: { greeting: 'Bonjour, {name} !' } }, { about: { fr: { title: 'À propos' } } })
i18n.addTranslations('fr', { nav: { home: 'Accueil' } }) // deep merge; pass false to replace

await i18n.loadFromUrl('/locales/fr.json', { locale: 'fr' })
await i18n.loadFromUrl('/locales/pages/about/fr.json', { locale: 'fr', routeName: 'about' })
await i18n.loadFromUrls([
  { url: '/locales/en.json', locale: 'en' },
  { url: '/locales/de.json', locale: 'de' },
])
```

`loadFromUrl` folosește `fetch` (transmiteți `init` pentru antete) și aruncă o eroare la un răspuns care nu este OK. `loadFromUrls` le încarcă unul după altul.

## Schimbarea locale-ului {#switch-locale}

```ts
i18n.locale = 'de'
i18n.t('greeting', { name: 'Ada' }) // 'Hallo, Ada!'
```

Modificările de locale, rută și dicționar notifică abonații; așa se re-randează integrările pentru framework-uri:

```ts
const stop = i18n.subscribe(() => {
  document.querySelector('#greeting')!.textContent = i18n.t('greeting', { name: 'Ada' }) as string
})
i18n.locale = 'fr'
stop()
```

`getSnapshot()` returnează un șir care se schimbă la fiecare notificare (pentru store-uri de tip `useSyncExternalStore`).

## Per cerere {#per-request}

Instanța conține un singur locale și o singură rută. Pe un server, nu comutați o instanță partajată pentru fiecare cerere: două cereri concurente ar vedea fiecare locale-ul celeilalte. `i18n.fork(locale)` oferă unei cereri propria instanță: propriul locale, propriul locale de rezervă și propria rută; aceleași dicționare, formatoare și reguli. Un fork costă la fel indiferent de numărul de dicționare. Un fork vede scrierile în părintele său până la prima sa scriere proprie, iar scrierile sale rămân în el. [Node.js](/ro/integrations/nodejs-package#per-request) adaugă `run`.

## API {#api}

| Membru | Note |
| --- | --- |
| `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has` | vedeți [Traducere și formatare](/ro/integrations/overview#translate-and-format) |
| `locale`, `fallbackLocale` | get/set |
| `currentRoute`, `setRoute(name)`, `getRoute()` | ruta activă, implicit `'index'` |
| `loadMessages(messages?, routeMessages?)` | îmbină mai multe locale-uri și rute deodată |
| `addTranslations(locale, tree, merge = true)`, `addRouteTranslations(locale, route, tree, merge = true)` | |
| `loadFromUrl(url, { locale?, routeName?, init? })`, `loadFromUrls(entries)` | `fetch` JSON |
| `hasTranslation(key)` | locale-ul activ, orice rută (spre deosebire de `has`, care verifică ruta activă și rădăcina) |
| `setTranslation(key, value)`, `resolveTranslations()` | scrie o cheie; citește arborele îmbinat |
| `clear()`, `clearCache()` | elimină toate dicționarele |
| `subscribe(cb)`, `getSnapshot()` | notificări de modificare |
| `storage` | `{ translations: Map<'locale:route', Translations> }` |

Un cod care nu este o etichetă de limbă își primește pluralele din `localeIso: { ua: 'uk-UA' }`; `localeIsoMap(locales)` construiește acest lucru din intrările unei liste de locale-uri care au un `iso`.

Exporturile modulului: `createI18n`, `I18n`, `fetchJsonTranslations`, `FormatService`, `interpolate`, `localeIsoMap` și tipurile `I18nOptions`, `LoadFromUrlOptions`, `LoadFromUrlEntry`, `TranslationStorage`, `Translations`, `Locale`, `PluralFunc`. Semnăturile complete: [referința pachetului](/ro/api/packages/runtime).
