---
title: "Insule Astro"
description: "Traduceri în insulele Vue, React, Preact și Svelte cu @i18n-micro/astro."
---

O insulă rulează în browser, unde instanța i18n a serverului nu există. `@i18n-micro/astro` permite paginii să aleagă cheile de care are nevoie o insulă, să le transmită ca un singur prop și să le citească în insulă printr-un mic adaptor pentru framework. Primiți `t`, `tc`, `tn`, `td`, `tdr` și `has` în insulele Vue, React, Preact și Svelte, cu doar șirurile alese în HTML.

## Configurare {#setup}

Configurați mai întâi [integrarea Astro și middleware-ul](/ro/integrations/astro-package#setup), apoi adăugați integrarea pentru framework-ul pe care îl folosiți (`@astrojs/vue`, `@astrojs/react`, `@astrojs/preact`, `@astrojs/svelte`). Adaptoarele pentru insule au nevoie de acel framework ca peer: `vue` `^3.3.0`, `react` `^16.8.0 || ^17.0.0 || ^18.0.0 || ^19.0.0`, `preact` `^10.0.0 || ^11.0.0` sau `svelte` `^4.0.0 || ^5.0.0`.

## Transmiterea traducerilor către o insulă {#pass-translations-to-an-island}

```astro
---
// src/pages/index.astro
import { getI18nProps } from '@i18n-micro/astro'
import Counter from '../components/Counter.vue'

const i18n = getI18nProps(Astro, ['counter.title', 'counter.apples'])
---

<Counter client:load i18n={i18n} />
```

`getI18nProps(Astro, keys?)` returnează `{ locale, fallbackLocale, currentRoute, translations }` (tipul `I18nClientProps`). Transmiteți cheile pe care le folosește insula: fiecare este rezolvată pe server ca `t()` (dicționarele rutei, de la rădăcină și de rezervă) și doar cheile găsite ajung în HTML. Fără `keys`, tot ce poate rezolva `t()` pe această pagină este trimis, în fiecare insulă, deci 2000 de chei la rădăcină înseamnă aproximativ 100 KB per insulă; în modul de dezvoltare, un avertisment semnalează acest lucru peste 20 KB.

Insulele traduc doar din acel obiect. `t` returnează cheia pentru orice nu a fost transmis, iar mesajele legate nu sunt rezolvate.

## Vue {#vue}

Apelați `provideI18n(() => props.i18n)` în componenta rădăcină a insulei și `useAstroI18n()` în copiii acesteia. `inject` din Vue nu vede o valoare furnizată de aceeași componentă, deci hook-ul trebuie să ruleze într-un copil, nu în rădăcină:

```vue
<!-- src/components/Counter.vue -->
<script setup lang="ts">
import { provideI18n } from '@i18n-micro/astro/client/vue'
import type { I18nClientProps } from '@i18n-micro/astro'
import CounterBody from './CounterBody.vue'

const props = defineProps<{ i18n: I18nClientProps }>()
provideI18n(() => props.i18n)
</script>

<template><CounterBody /></template>
```

```vue
<!-- src/components/CounterBody.vue -->
<script setup lang="ts">
import { ref } from 'vue'
import { useAstroI18n } from '@i18n-micro/astro/client/vue'

const { t, tc } = useAstroI18n()
const count = ref(0)
</script>

<template>
  <h3>{{ t('counter.title') }}</h3>
  <button @click="count++">{{ tc('counter.apples', count) }}</button>
</template>
```

## React și Preact {#react-and-preact}

```tsx
// src/components/Counter.tsx
import { useState } from 'react'
import { I18nProvider, useAstroI18n } from '@i18n-micro/astro/client/react'
import type { I18nClientProps } from '@i18n-micro/astro'

function Body() {
  const { t, tc } = useAstroI18n()
  const [count, setCount] = useState(0)
  return <button onClick={() => setCount(count + 1)}>{t('counter.title')}: {tc('counter.apples', count)}</button>
}

export default function Counter({ i18n }: { i18n: I18nClientProps }) {
  return (
    <I18nProvider value={i18n}>
      <Body />
    </I18nProvider>
  )
}
```

Pentru Preact, importați `I18nProvider` și `useAstroI18n` din `@i18n-micro/astro/client/preact`; API-ul este același.

## Svelte {#svelte}

```svelte
<!-- src/components/Counter.svelte -->
<script lang="ts">
  import { createI18nStore, useAstroI18n } from '@i18n-micro/astro/client/svelte'
  import type { I18nClientProps } from '@i18n-micro/astro'

  export let i18n: I18nClientProps
  const { t, tc } = useAstroI18n(createI18nStore(i18n))
  let count = 0
</script>

<button on:click={() => count++}>{t('counter.title')}: {tc('counter.apples', count)}</button>
```

`useAstroI18n(store)` returnează și `store` pentru citiri `$store` în șablon.

## Insule persistente {#persisted-islands}

O insulă cu `transition:persist` primește props noi după o navigare. React, Preact și Vue (dacă primește un getter) le urmează. În Svelte, păstrați store-ul și transmiteți-le mai departe: `const store = createI18nStore(i18n)`, `const { t } = useAstroI18n(store)`, apoi `$: store.set(i18n)` (cu runes, `$effect(() => store.set(i18n))`).

## API {#api}

| Punct de intrare | Exporturi |
| --- | --- |
| `@i18n-micro/astro` | `getI18nProps`, tipul `I18nClientProps` |
| `@i18n-micro/astro/client/vue` | `provideI18n(props \| () => props)`, `useAstroI18n()` |
| `@i18n-micro/astro/client/react` | `I18nProvider` (prop-ul `value`), `useAstroI18n()` |
| `@i18n-micro/astro/client/preact` | `I18nProvider` (prop-ul `value`), `useAstroI18n()` |
| `@i18n-micro/astro/client/svelte` | `createI18nStore(props)`, `useAstroI18n(store)` |
| `@i18n-micro/astro/client` | funcțiile pure `translate`, `hasTranslation`, fără niciun framework |

Fiecare `useAstroI18n` returnează `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`, `setLocale`, `setRoute` și `locale`. O insulă are un singur dicționar îmbinat, deci `has` al ei este adevărat pentru o cheie pe care `t` o poate rezolva, inclusiv din locale-ul de rezervă; pe server, `has` se uită doar la locale-ul activ.
