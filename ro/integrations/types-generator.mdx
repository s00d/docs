---
title: "Generator de tipuri"
description: "Generează autocompletare TypeScript pentru cheile de traducere din fișierele tale JSON, în Nuxt sau în orice proiect Vite."
---

`@i18n-micro/types-generator` citește fiecare fișier JSON din folderul de traduceri și scrie o declarație care listează toate cheile. Adaugă-l când vrei ca editorul tău să sugereze chei în `t()`, `$t()` și `<I18nT keypath>`. Funcționează ca modul Nuxt și ca plugin Vite sau Rollup și se regenerează când un fișier se modifică.

## Instalare {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/types-generator
```

```bash npm
npm install -D @i18n-micro/types-generator
```

```bash yarn
yarn add -D @i18n-micro/types-generator
```

</CodeGroup>

Dependență peer: `@nuxt/kit` `^3.18.0 || ^4.0.0`. Doar punctul de intrare `/nuxt` o importă; într-un proiect doar cu Vite, avertismentul peer poate fi ignorat.

## Nuxt {#nuxt}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro', '@i18n-micro/types-generator/nuxt'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Modulul scrie `.nuxt/types/i18n-micro.d.ts`, iar Nuxt îl adaugă în contextul de tipuri; nu trebuie inclus nimic manual. Citește `i18nTypes.translationDir`, altfel locul de unde `nuxt-i18n-micro` citește traducerile: `translationDir` (din `i18n` sau din opțiunile inline ale modulului, implicit `'locales'`) în fiecare strat, plus `additionalTranslationDirs`. Editarea unui fișier JSON din acel folder regenerează tipurile în `nuxi dev`. `i18nTypes.outputFile` este ignorat în Nuxt (un avertisment semnalează acest lucru).

## Vite {#vite}

`I18nTypesPlugin` este un plugin Vite, pe care îl acceptă și Rollup. Pentru alt bundler, apelează `generateTypes` într-un script.

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { I18nTypesPlugin } from '@i18n-micro/types-generator'

export default defineConfig({
  plugins: [
    vue(),
    I18nTypesPlugin({
      srcDir: process.cwd(),
      translationDir: 'src/locales',
      outputFile: 'src/i18n-micro.d.ts',
    }),
  ],
})
```

| Opțiune | Obligatorie | Note |
| --- | --- | --- |
| `srcDir` | da | Directorul de bază; `translationDir` este rezolvat relativ la acesta. |
| `translationDir` | da | Folderul cu fișierele JSON (inclusiv subfoldere precum `pages/`) sau un array de foldere. |
| `outputFile` | nu | Unde se scrie declarația; implicit `<srcDir>/i18n-micro.d.ts`. |

Plugin-ul generează o dată la pornirea build-ului și, pe serverul de dezvoltare, regenerează la 300 ms după o modificare în folder. Asigură-te că `include` din `tsconfig.json` acoperă fișierul generat.

## Folosirea cheilor {#use-the-keys}

Fișierul generat extinde `DefineLocaleMessage` din `@i18n-micro/types`, ceea ce transformă `TranslationKey` în cheile tale:

```ts
declare module '@i18n-micro/types' {
  export interface DefineLocaleMessage {
    nav: object
    'nav.home': string
    'profile.title': string
  }
}
```

Cheile sunt cele la care răspunde `t()`, inclusiv obiectele, din fiecare limbă și fiecare fișier de pagină, cu tipul valorii lor JSON. `TranslationKey` este uniunea acestor chei plus orice șir, așa că primești autocompletare, nu erori: o cheie scrisă greșit sau dinamică se compilează în continuare. Parametrii și valorile returnate nu sunt tipizate.

Pentru chei dinamice sub un prefix cunoscut, `ScopedKey<'prefix'>` restrânge la cheile corespunzătoare:

```ts
import type { ScopedKey } from '@i18n-micro/types'

const statusText = (status: string) => t(`status.${status}` as ScopedKey<'status'>)
```

`TranslationKey` și `ScopedKey` provin din `@i18n-micro/types` (React, Preact și Solid re-exportă `TranslationKey`; Vue nu).

## API {#api}

| Export | Punct de intrare | Note |
| --- | --- | --- |
| `I18nTypesPlugin(options)` | `@i18n-micro/types-generator` | Plugin Vite și Rollup |
| `generateTypes(options)` | `@i18n-micro/types-generator` | scrie fișierul, returnează calea acestuia |
| `getTypesString(options)` | `@i18n-micro/types-generator` | returnează declarația fără a o scrie |
| `formatKeyProperty(key)` | `@i18n-micro/types-generator` | helper |
| Modul Nuxt (`configKey: 'i18nTypes'`) | `@i18n-micro/types-generator/nuxt` | opțiunea `translationDir` |

Semnăturile complete: [referința pachetului](/ro/api/packages/types-generator).
