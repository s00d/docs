# Integrări

Pachetele `@i18n-micro` sunt versiuni ușoare, specifice fiecărui framework, ale Nuxt I18n Micro, concepute pentru integrarea în diverse framework-uri și medii. Aceste pachete oferă funcționalitatea de internaționalizare de bază cu o amprentă minimă, concentrându-se pe funcțiile esențiale de traducere și pe componente de bază.

## Prezentare generală

Aceste pachete de integrare sunt **versiuni miniaturale** ale modulului complet Nuxt I18n Micro, conținând doar funcționalitatea esențială necesară pentru internaționalizare:

- **Funcții de traducere de bază** - Metode de traducere elementare, pluralizare și formatare
- **Componente esențiale** - Un set restrâns de componente UI pentru sarcini i18n obișnuite
- **Tipar Router Adapter** - Integrare flexibilă a rutării prin abstracția adapterului
- **Suport TypeScript** - Definiții complete de tipuri pentru dezvoltare type-safe

Spre deosebire de modulul Nuxt complet, aceste pachete:

- Nu includ logica de rutare specifică framework-ului
- Necesită să implementezi un router adapter pentru funcțiile de rutare
- Se concentrează pe funcționalitatea de traducere, nu pe integrarea cu framework-ul
- Sunt concepute să fie ușoare și, unde este posibil, agnostice față de framework

## Componente principale

Toate pachetele pentru framework-uri includ următoarele componente esențiale:

### `<I18nT>`

O componentă de traducere care randează text tradus, cu suport pentru:

- **Interpolare de parametri** - Înlocuiește placeholder-e cu valori dinamice
- **Pluralizare** - Selecție automată a formei de plural în funcție de count
- **Formatare numerică** - Formatează numere conform locale-ului
- **Formatare dată** - Formatează date și timpuri relative
- **Randare HTML** - Randare opțională de conținut HTML
- **Valori implicite** - Text de rezervă când traducerea lipsește

**Exemplu:**

```vue
<!-- Vue -->
<I18nT keypath="greeting" :params="{ name: 'World' }" />
```

```tsx
// React
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```tsx
// Solid
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```astro
<!-- Astro -->
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

### `<I18nLink>`

O componentă de link localizată care gestionează automat prefixele de locale în URL-uri. Caracteristici:

- **Localizare automată a căii** - Adaugă/elimină prefixele de locale în funcție de strategia de rutare
- **Detecție de stare activă** - Evidențiază ruta curentă
- **Suport pentru link-uri externe** - Detectează și gestionează automat URL-uri externe
- **Integrare router** - Folosește componenta de link a router-ului când este disponibilă
- **Stilizare personalizată** - Suportă stări active și hover

**Exemplu:**

```vue
<!-- Vue -->
<I18nLink to="/about" active-class="active">
  About Us
</I18nLink>
```

```tsx
// React
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```tsx
// Solid
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```astro
<!-- Astro -->
<I18nLink href="/about" class="nav-link">
  About Us
</I18nLink>
```

### `<I18nSwitcher>`

O componentă de comutare a limbii care oferă o interfață dropdown sau listă pentru schimbarea locale-urilor. Caracteristici:

- **Listă automată de locale** - Generează opțiuni din locale-urile configurate
- **Evidențierea locale-ului curent** - Indică vizual limba activă
- **Etichete personalizate** - Suportă nume de afișare personalizate per locale
- **Integrare router** - Navighează automat către căi localizate
- **Accesibilitate** - Atribute ARIA corecte și navigare cu tastatura

**Exemplu:**

```vue
<!-- Vue -->
<I18nSwitcher />
```

```tsx
// React
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```tsx
// Solid
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```astro
<!-- Astro -->
<I18nSwitcher />
```

### `<I18nGroup>`

O componentă pentru gruparea traducerilor sub un prefix comun, utilă pentru organizarea traducerilor per pagină sau funcționalitate. Caracteristici:

- **Aplicarea prefixului** - Adaugă automat prefix la toate cheile de traducere din grup
- **Grupuri imbricate** - Suportă grupuri de traduceri imbricate
- **Organizare curată** - Ajută la menținerea unei structuri organizate a traducerilor

**Exemplu:**

```vue
<!-- Vue -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

```tsx
// React
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```tsx
// Solid
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```astro
<!-- Astro -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

## Opțiuni comune `createI18n` \{#create-i18n-options\}

Fiecare pachet pentru framework este creat în același mod — doar tipul opțiunilor este denumit după
framework (`ReactI18nOptions`, `SolidI18nOptions` și așa mai departe). Opțiunile în sine
sunt identice:

| Proprietate      | Tip                                                        | Obligatoriu | Implicit          | Descriere                                          |
| ---------------- | ---------------------------------------------------------- | ----------- | ----------------- | -------------------------------------------------- |
| `locale`         | `string`                                                   | ✅          | -                 | Codul locale-ului curent (de ex. `'en'`)           |
| `fallbackLocale` | `string`                                                   | ❌          | La fel ca `locale`| Locale-ul fallback când traducerea lipsește        |
| `messages`       | `Record<string, Translations>`                             | ❌          | `\{\}`            | Mesajele inițiale de traducere                     |
| `plural`         | `PluralFunc`                                               | ❌          | `defaultPlural`   | Funcție personalizată de pluralizare               |
| `missingWarn`    | `boolean`                                                  | ❌          | `true`            | Afișează avertismente în consolă pentru traduceri lipsă |
| `missingHandler` | `(locale: string, key: string, routeName: string) => void` | ❌          | -                 | Handler personalizat pentru traduceri lipsă        |

Orice altceva este specific framework-ului și este documentat pe pagina pachetului respectiv.

## Abstracția Router Adapter

Toate pachetele pentru framework-uri folosesc un **tipar router adapter** pentru a decupla funcționalitatea i18n de implementările specifice de router. Acest design permite:

- **Flexibilitate** - Folosește orice bibliotecă de router sau niciun router
- **Independență față de framework** - Păstrează logica de rutare în aplicația ta, nu în pachetul i18n
- **Nucleu ușor** - Pachetul i18n rămâne mic și focalizat

### Implementarea unui router adapter

Pentru a folosi funcțiile de rutare, trebuie să implementezi interfața `I18nRoutingStrategy`:

```typescript
interface I18nRoutingStrategy {
  getCurrentPath: () => string
  linkComponent?: Component
  push: (target: { path: string }) => void
  replace: (target: { path: string }) => void
  resolvePath?: (to: string | { path?: string }, locale: string) => string | { path?: string }
  getRoute?: () => { fullPath: string; query: Record<string, unknown> }
}
```

Documentația fiecărui pachet include exemple complete de implementare a adapterelor pentru routere populare:

- **Vue**: exemplu de adapter Vue Router
- **React**: exemplu de adapter React Router
- **Solid**: exemplu de adapter Solid Router
- **Astro**: exemplu de adapter pentru rutare bazată pe fișiere

## Funcții principale

Toate pachetele partajează aceste funcții principale:

### Metode de traducere

- `t()` - Traducere de bază cu interpolare de parametri
- `ts()` - Traducere care returnează întotdeauna un șir
- `tc()` - Traducere cu conștientizare a pluralizării
- `tn()` - Formatare numerică
- `td()` - Formatare dată
- `tdr()` - Formatare timp relativ
- `has()` - Verifică dacă o cheie de traducere există

### Gestionarea locale-ului

- **Comutarea locale-ului** - Schimbă locale-ul curent programatic
- **Locale fallback** - Fallback automat când traducerea lipsește
- **Traduceri specifice rutei** - Organizarea traducerilor la nivel de pagină
- **Cache pentru traduceri** - Cache inteligent pentru performanță

### Suport TypeScript

Toate pachetele oferă:

- Definiții TypeScript complete
- Chei de traducere type-safe (cu types generator)
- Suport IntelliSense în IDE-uri
- Verificarea erorilor la compilare

## Cum să începi

3. **Citește documentația** - Fiecare pachet are instrucțiuni detaliate de configurare
