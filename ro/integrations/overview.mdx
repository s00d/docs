Pachetele `@i18n-micro/*` aduc nucleul de traducere al Nuxt I18n Micro în Vue, React, Preact, Solid, Astro, VitePress și JavaScript simplu. Folosiți-le când aplicația dumneavoastră nu este o aplicație Nuxt, sau când un script ori un server din afara Nuxt are nevoie de aceleași fișiere de traducere. Toate pachetele au în comun un model de instanță, un contract pentru adaptorul de router și aceleași patru componente, descrise o singură dată pe această pagină.

Intrarea pentru router este un import separat, astfel încât o aplicație fără router nu include niciodată unul în bundle.

`@i18n-micro/core`, `@i18n-micro/types` și `@i18n-micro/utils` sunt instalate împreună cu aceste pachete; rareori le importați direct. Semnăturile tuturor exporturilor se află în [referința pachetelor](/ro/api/packages/overview) generată.

Fiecare pachet are un playground în `packages/<name>/playground` din repository.

## Instanța {#the-instance}

`createI18n(options)` returnează o instanță care conține dicționarele, limba curentă și ruta curentă. Opțiunile sunt aceleași în fiecare pachet:

| Opțiune | Tip | Implicit | Note |
| --- | --- | --- | --- |
| `locale` | `string` | obligatoriu | Limba activă. |
| `fallbackLocale` | `string` | `locale` | Consultată când o cheie lipsește în `locale`. |
| `messages` | `Record<locale, Translations>` | `{}` | Dicționare rădăcină (ruta `'index'`). |
| `routeMessages` | `Record<route, Record<locale, Translations>>` | `{}` | Dicționare de rută. Doar Runtime, React, Preact, Node și VitePress. |
| `plural` | `PluralFunc` | `defaultPlural` | Regulă de plural personalizată. |
| `missingWarn` | `boolean` | `true` | `console.warn` în browser, doar în dezvoltare, pentru o cheie lipsă. |
| `missingHandler` | `(locale, key, routeName) => void` | — | Apelat în locul avertismentului. |
| `numberFormats` | `Record<locale, Record<name, Intl.NumberFormatOptions>>` | — | Formate denumite: `tn(9.5, 'currency')`. |
| `datetimeFormats` | `Record<locale, Record<name, Intl.DateTimeFormatOptions>>` | — | Formate denumite: `td(date, 'short')`. |
| `timeZone` | `string` | fusul runtime-ului | Fusul IANA pentru datele `td`; nu afectează `tdr`. Setați-l pentru ca serverul și browserul să randeze aceeași dată. |
| `now` | `() => number` | `Date.now` | Ceasul pentru `tdr`. Transmiteți la hidratare ora serverului, ca ambele să randeze același text. |
| `localeIso` | `Record<code, string>` | — | Tag-ul BCP 47 folosit pentru regulile de plural (`ua` → `uk-UA`). React, Preact și Solid îl preiau din `iso` din `locales`-ul provider-ului. |

Dicționarele se află în `i18n.storage.translations`, un `Map` cu chei `locale:route` (`en:index`, `en:about`).

O cheie este căutată în dicționarul rutei curente, apoi în dicționarul rădăcină, mai întâi pentru `locale`, apoi pentru `fallbackLocale`. O cheie lipsă returnează cheia însăși (sau `defaultValue`-ul pe care îl transmiteți).

```ts
i18n.addTranslations('en', { nav: { home: 'Home' } }) // root, deep-merged
i18n.addRouteTranslations('en', 'about', { title: 'About us' }) // route chunk
i18n.addTranslations('en', { nav: { home: 'Start' } }, false) // replace instead of merge
i18n.setRoute('about')
i18n.t('title') // 'About us'
i18n.t('nav.home') // 'Start' (root key, still visible on the route)
```

### Traducere și formatare {#translate-and-format}

| Metodă | Returnează |
| --- | --- |
| `t(key, params?, defaultValue?, routeName?)` | Valoarea (șir, număr, obiect) cu `{param}` interpolat. |
| `ts(...)` | La fel ca `t`, ca șir. |
| `tc(key, count \| params, defaultValue?)` | Forma de plural. |
| `tn(value, options \| name)` | `Intl.NumberFormat` în limba activă. |
| `td(value, options \| name)` | `Intl.DateTimeFormat`. |
| `tdr(value, options?)` | Timp relativ (`3 days ago`). |
| `has(key, routeName?)` | `true` când limba activă are cheia (în dicționarul rutei sau în cel rădăcină; fallback-ul nu este verificat). |

`defaultPlural` împarte valoarea după `|` și alege forma de la indexul `count`, limitat la ultima formă; un count negativ, fracționar sau `NaN` alege ultima formă.

Un `plural` personalizat primește `(key, count, params, locale, getter)`. Citiți valoarea prin `getter(key)`; nu împărțiți cheia:

```ts
import type { PluralFunc } from '@i18n-micro/vue'

const plural: PluralFunc = (key, count, params, _locale, getter) => {
  const value = getter(key)
  if (typeof value !== 'string') return null
  const forms = value.split('|').map((form) => form.trim())
  return (count === 1 ? forms[0] : forms[1] ?? forms[0])!.replace('{count}', String(count))
}
```

## Adaptorul de router {#router-adapter}

Pachetele SPA nu depind de un router. Un adaptor de router (`I18nRoutingStrategy`) le spune cum să citească calea curentă, cum să navigheze și cum să construiască o cale localizată. Adaptoarele încorporate adaugă prefix tuturor limbilor, cu excepția `defaultLocale` (`/about`, `/de/about`).

| Membru | Obligatoriu | Folosit de |
| --- | --- | --- |
| `getCurrentPath(): string` | da | verificarea link-ului activ (după pagină; query-ul și hash-ul nu contează), `switchLocale` (le păstrează) |
| `push({ path }): void` | da | `switchLocale`, `<I18nLink>` fără `linkComponent`, `<I18nSwitcher>` |
| `replace({ path }): void` | da | — |
| `resolvePath(to, locale)` | nu | `localePath`, `localeRoute`, `<I18nLink>`; fără el, căile sunt returnate neschimbate |
| `linkComponent` | nu | `<I18nLink>` îl randează (de ex. `RouterLink`) în locul lui `<a>` |
| `getRoute()` | nu | `{ fullPath, query }` pentru helperii SEO |

`push` și `replace` sunt obligatorii în Vue, React, Preact și Solid. Astro are propriul adaptor, pe server, cu `push`/`replace` opționale (consultați [Astro](/ro/integrations/astro-package#router-adapter)).

Un adaptor minimal pentru orice router bazat pe history:

```ts
import type { I18nRoutingStrategy } from '@i18n-micro/react'

const locales = ['en', 'de']
const stripLocale = (path: string) => path.replace(/^\/(en|de)(?=\/|$)/, '') || '/'

export const historyAdapter: I18nRoutingStrategy = {
  getCurrentPath: () => window.location.pathname + window.location.search + window.location.hash,
  push: ({ path }) => window.history.pushState({}, '', path),
  replace: ({ path }) => window.history.replaceState({}, '', path),
  resolvePath: (to, locale) => {
    const path = stripLocale(typeof to === 'string' ? to : to.path || '/')
    return locale === 'en' ? path : `/${locale}${path === '/' ? '' : path}`
  },
}
```

## Componente {#components}

Vue, React, Preact și Solid livrează aceleași patru componente. Proprietățile lor coincid; React, Preact și Solid transmit celelalte proprietăți elementului rădăcină.

### `<I18nT>` {#&lt;i18nt&gt;}

| Proprietate | Tip | Note |
| --- | --- | --- |
| `keypath` | `string` | obligatoriu |
| `params` | `object` | valori de interpolare |
| `plural` | `number \| string` | randează `tc(keypath, count)` |
| `number` | `number \| string` | transmite `tn(number)` ca `{number}` |
| `date` | `Date \| string \| number` | transmite `td(date)` ca `{date}` |
| `relativeDate` | `Date \| string \| number` | transmite `tdr(relativeDate)` ca `{relativeDate}` |
| `tag` | `string` | elementul wrapper, implicit `span` |
| `html` | `boolean` | randează traducerea ca HTML; aceasta trebuie să fie de încredere, parametrii sunt escapați |
| `defaultValue` | `string` | ține locul unei chei lipsă și este randat simplu când `hideIfEmpty` ascunde o valoare goală |
| `hideIfEmpty` | `boolean` | nu randează nimic pentru o traducere goală |
| `customPluralRule` | `PluralFunc` | regula de plural pentru acest element |

Se aplică o singură proprietate de formatare, verificată în această ordine: `number`, `date`, `relativeDate`, `plural`.

#### Text îmbogățit {#rich-text}

Un `{placeholder}` poate conține un element. În Vue este un slot denumit; în React, Preact și Solid, proprietatea `components` oferă elemente, sau funcții care returnează unul, după nume. În ambele cazuri are prioritate față de un parametru cu același nume, funcționează în fiecare ramură și rezistă unei limbi care reordonează placeholder-ele.

```tsx
// { "terms": "I accept the {link} of {company}" }
<I18nT keypath="terms" params={{ company: 'ACME' }} components={{ link: <a href="/terms">terms</a> }} />
```

În Solid, transmiteți o funcție când un placeholder se repetă: un nod ocupă un singur loc. `children` înlocuiesc textul; ca funcție, primesc `{ translation }`, precum slotul implicit din Vue. `html` le ignoră pe toate acestea.

### `<I18nLink>` {#&lt;i18nlink&gt;}

| Proprietate | Tip | Note |
| --- | --- | --- |
| `to` | `string \| { path }` | localizat prin `resolvePath`-ul adaptorului |
| `activeStyle` | obiect de stil | îmbinat peste `style` pe pagina curentă; React, Preact și Solid îl aplică și unei secțiuni de mai sus |
| `localeRoute` | funcție | suprascrie `resolvePath` pentru acest link |

URL-urile externe (`https://`, `mailto:`, `tel:`) sunt randate ca `<a target="_blank" rel="noopener noreferrer">`; un `target` sau `rel` propriu are prioritate. `onClick` rulează întotdeauna. Un clic cu taste modificatoare, cu alt buton al mouse-ului sau cu un `target` rămâne în grija browserului.

### `<I18nSwitcher>` {#&lt;i18nswitcher&gt;}

O listă derulantă a limbilor activate (limbile cu `disabled: true` sunt ascunse), cu stiluri implicite inline. Elementele sale sunt link-uri, cu `lang`, `hreflang` și `dir` din limbă. În mod implicit, un clic pe unul setează limba și apelează `push`-ul adaptorului cu calea curentă localizată; o proprietate `switchLocale` înlocuiește această acțiune. Cu un `localeRoute` și fără router, browserul urmează link-ul. Tasta Escape sau un clic în afară o închide.

| Proprietate | Note |
| --- | --- |
| `locales`, `currentLocale`, `getLocaleName` | suprascriu valorile furnizate |
| `switchLocale(code)` | înlocuiește schimbarea încorporată |
| `localeRoute` | înlocuiește `resolvePath` |
| `customLabels` | `{ de: 'DE' }` |
| `customWrapperStyle`, `customButtonStyle`, `customDropdownStyle`, `customItemStyle`, `customLinkStyle`, `customActiveLinkStyle`, `customDisabledLinkStyle`, `customIconStyle` | suprascrieri de stil |

### `<I18nGroup>` {#&lt;i18ngroup&gt;}

Un `<div class="i18n-group">` care transmite copiilor săi un `t` cu prefix. **Nu** adaugă prefix apelurilor `<I18nT>` sau `t()` din interiorul său; doar `t`-ul pe care îl transmite mai departe are prefix.

| Proprietate | Note |
| --- | --- |
| `prefix` | obligatoriu, de ex. `'profile'` |
| `groupClass` | clasă suplimentară pe wrapper |

`t`-ul cu prefix vine printr-un scoped slot în Vue (`v-slot="{ t }"`) și printr-un copil render-prop în React, Preact și Solid (`{({ t }) => …}`).

## Chei tipizate {#typed-keys}

`t()` acceptă orice șir. Pentru a obține autocompletare pentru cheile dumneavoastră, generați o declarație cu [generatorul de tipuri](/ro/integrations/types-generator). Cheile sunt sugerate, nu impuse, iar parametrii nu sunt tipizați.

## Comparație cu modulul Nuxt {#compared-with-the-nuxt-module}

Pachetele nu au rutare bazată pe fișiere, middleware de server sau loader de traduceri: dumneavoastră decideți când să încărcați JSON-ul (`import`, `fetch` sau `@i18n-micro/node` pe server) și ce adaptor de router să folosiți. Detectarea limbii, meta SEO și generarea rutelor sunt funcționalități Nuxt; Astro are propriul middleware pentru detectare și `useLocaleHead` pentru SEO.
