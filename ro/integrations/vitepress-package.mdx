title: "VitePress"

---

`@i18n-micro/vitepress` adaugă dicționare la runtime unui site VitePress: `$t` și `<I18nT>` în markdown, helperi pentru căi și etichete SEO, construite pe [`@i18n-micro/vue`](/ro/integrations/vue-package). Folosiți-l atunci când aceleași șiruri de interfață apar pe multe pagini și nu doriți să le duplicați pentru fiecare locale. Locale-ul urmează locale-urile de cale proprii VitePress (`/`, `/fr/`).

## Când să îl folosiți {#when-to-use-it}

| Nevoie | Soluție |
|------|----------|
| Fișiere `.md` duplicate, prefixe în URL | `locales` din VitePress |
| `$t` la runtime / componente / sincronizarea căilor / head SEO | `@i18n-micro/vitepress` |
| Etichetele elementelor temei implicite (`docFooter`, interfața de căutare) | Propriul `themeConfig` pentru fiecare locale |

<Tip>

**Playground** — [`packages/vitepress/playground`](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/vitepress/playground) — `pnpm -C packages/vitepress/playground dev`

</Tip>

## Instalare {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vitepress
```

```bash npm
npm install @i18n-micro/vitepress
```

```bash yarn
yarn add @i18n-micro/vitepress
```

</CodeGroup>

Dependențe peer: `vitepress` `>=1.0.0 || >=2.0.0-alpha.0`, `vue` `^3.3.0`. Scripturile Node folosesc `@i18n-micro/node`, instalat odată cu pachetul și reexportat prin `/node`. Tipurile publicate necesită Vue 3.5.5 sau mai nou cu `skipLibCheck: false`; cu `skipLibCheck: true`, setarea obișnuită din șabloane, se compilează și versiunile mai vechi.

## Configurare {#setup}

```
locales/en.json
locales/fr.json
locales/pages/guide/demo/en.json   # optional page-scoped
locales/pages/guide/demo/fr.json
```

Fișierele de pagină corespund numelor de rută la fel ca în Nuxt/Astro (`guide/demo` → `guide-demo`).

### 1. Configurație — `@i18n-micro/vitepress/config` {#1-config-—-@i18n-micro/vitepress/config}

```ts
// .vitepress/config.mts
import { defineConfig } from 'vitepress'
import { withI18n, buildVitePressLocales } from '@i18n-micro/vitepress/config'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English', og: 'en_US' },
  { code: 'fr', iso: 'fr-FR', displayName: 'Français', og: 'fr_FR' },
]
const defaultLocale = 'en'

export default defineConfig(
  withI18n(
    {
      locales: buildVitePressLocales(locales, defaultLocale),
      // themeConfig.i18nRouting is injected automatically
    },
    {
      locale: defaultLocale,
      defaultLocale,
      locales,
      translationDir: 'locales',
      metaBaseUrl: 'https://example.com', // optional SEO head
    },
  ),
)
```

### 2. Temă — `@i18n-micro/vitepress/theme` {#2-theme-—-@i18n-micro/vitepress/theme}

```ts
// .vitepress/theme/index.ts
import DefaultTheme from 'vitepress/theme'
import { defineI18nTheme } from '@i18n-micro/vitepress/theme'

export default defineI18nTheme(DefaultTheme)
```

Locale-ul inițial este preluat din calea curentă înainte de instalare (fără o afișare momentană a locale-ului implicit pe `/fr/…`).

### Avansat: `createI18n` manual {#advanced-manual-createi18n}

O singură fabrică pentru client: plugin Vue + metode pentru căi + `enhanceApp` (fără exporturi separate de helperi pentru router).

```ts
import { createI18n, messagesFromGlob } from '@i18n-micro/vitepress'

const i18n = createI18n({
  locale: 'en',
  defaultLocale: 'en',
  locales: [{ code: 'en' }, { code: 'fr' }],
  messages: messagesFromGlob(import.meta.glob('../../locales/*.json', { eager: true })),
})

i18n.localizePath('/guide', 'fr')
// in theme enhanceApp:
i18n.enhanceApp({ app, router })
```

### Scripturi Node — `@i18n-micro/vitepress/node` {#node-scripts-—-@i18n-micro/vitepress/node}

Folosește `createI18n` / `loadTranslations` din `@i18n-micro/node` (la fel ca Astro și CLI), apoi atașează metodele VitePress pentru căi cu `BaseI18n.extend`:

```ts
import { createI18n } from '@i18n-micro/vitepress/node'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  translationDir: './locales',
  locales: ['en', 'fr'],
  defaultLocale: 'en',
})
await i18n.loadTranslations()
i18n.t('cta.readMore')
i18n.localizePath('/guide', 'fr')
```

Node simplu, fără căi: `import { createI18n } from '@i18n-micro/node'`.

## Traduceri în pagină {#in-page-translations}

Fiecare fișier markdown VitePress este un SFC Vue.

### Componente globale și `$t` (recomandat în markdown) {#global-components-and-$t-recommended-in-markdown}

`createI18n` / `defineI18nTheme` instalează `@i18n-micro/vue`, care înregistrează `I18nT` / `I18nLink` / `I18nGroup` / `I18nSwitcher` și `$t` / `$tc` / `$ts`.

```md
{{ $t('cta.readMore') }}

<I18nT keypath="greeting" :params="{ name: 'VitePress' }" />

<I18nLink to="/guide/demo">Demo</I18nLink>
```

### `useI18n` în `<script setup>` {#usei18n-in-<script-setup>}

```md
<script setup>
import { useI18n } from '@i18n-micro/vitepress'
const { t, tc, locale, localePath, switchLocale } = useI18n()
</script>

# {{ t('section.title') }}
```

## Meniul de limbi {#language-dropdown}

Când `locales` are mai multe intrări, VitePress afișează propriul meniu de limbi (`VPNavBarTranslations`). `withI18n` configurează `themeConfig.i18nRouting` astfel încât globul să corespundă cu `<I18nSwitcher>` / helperii pentru căi.

Folosiți `<I18nSwitcher>` doar în layout-uri personalizate, nu lângă globul implicit.

## Note despre SSR {#ssr-notes}

- Locale-ul la prerandare provine din calea URL-ului, nu din cookie-uri.
- Codul temei nu trebuie să acceseze `window` la momentul importului.
- Importați `defineI18nTheme` din `/theme`, astfel încât evaluarea configurației în Node să nu încarce niciodată `virtual:i18n-micro/*`.

## Suprafața API {#api-surface}

| Export | Rol |
|--------|------|
| `createI18n` (`.`) | Client: plugin Vue + metode pentru căi + `enhanceApp` |
| `getLocaleFromPath` / `stripSiteBase` / `routeNameFromPath` (`.`) | Sincronizare manuală a locale-ului când `syncWithVitePress: false` |
| `createI18n` (`/node`) | Node: `@i18n-micro/node` + metode pentru căi |
| `defineI18nTheme` (`/theme`) | Temă fără cod boilerplate |
| `withI18n` (`/config`) | Configurație + module virtuale + SEO opțional |
| `buildVitePressLocales` (`/config`) | Construiește `locales` VitePress din `Locale[]` |
| `buildVitePressLocaleHead` (`/config`) | Head SEO manual (folosit și de `metaBaseUrl`) |
| `messagesFromGlob` | Glob opțional → mapă de mesaje pentru `createI18n` |
| `useI18n` / `I18nT` / … | Reexportate din `@i18n-micro/vue` |
| `BaseI18n.extend` (`@i18n-micro/core`) | Atașează metode personalizate pe orice instanță i18n |

## Site-uri de tip OpenAPI (garanții de integrare) {#openapi-style-sites-integration-locks}

Suita de regresie: `packages/vitepress/tests/integration-openapi.test.ts` (căi adânci, `base=/openapi_docs/`, sincronizare dezactivată + locale manual, generatoare Node, SEO).

| Model | Ce trebuie făcut |
|---------|---------|
| Pagini adânci `/…/{spec}/{op}`, doar JSON de interfață la rădăcină | Preferați valoarea implicită `syncWithVitePress: true` (păstrează `setRoute('index')` când nu există dicționar de pagină) **sau** `syncWithVitePress: false` + `getLocaleFromPath` |
| Nu apelați niciodată `setRoute(deepName)` fără dicționare de pagină | Cheile de interfață de la rădăcină dispar până la `setRoute('index')` |
| Generatoare / `getTranslation` | `createI18n` din `/node` + `await loadTranslations()` + `i18n.t(key)` (setați `i18n.locale`) |
| Canonical personalizat în `transformPageData` | Transmiteți `meta: false` către `withI18n` (evitați etichetele duble) |
| SEO din pachet cu bază de site | `metaBaseUrl` + `base` din VitePress → URL-urile absolute includ baza |
| Redenumiri față de versiunile mai vechi ale pachetului | `withI18nMicro` → `withI18n`, `createVitePressI18n` → `createI18n`, `loadMessages` → `createI18n` din node |
