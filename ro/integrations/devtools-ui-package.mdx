`@i18n-micro/devtools-ui` este editorul de traduceri din tab-ul Nuxt DevTools, împachetat ca web component cu un plugin Vite. Adăugați-l într-un proiect Vue, React, Preact, Solid sau Astro pentru a răsfoi și edita din browser, în timpul dezvoltării, fișierele JSON din directorul de traduceri. Aplicațiile Nuxt îl au deja în [Nuxt DevTools](/ro/guide/devtools).

![DevTools UI: un arbore de fișiere și un editor cu textul locale-ului implicit lângă fiecare cheie](/images/devtools/02-translations-editor-dark.webp)

## Instalare {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/devtools-ui
```

```bash npm
npm install -D @i18n-micro/devtools-ui
```

```bash yarn
yarn add -D @i18n-micro/devtools-ui
```

</CodeGroup>

Fără dependențe peer.

## Configurare {#setup}

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import { i18nDevToolsPlugin } from '@i18n-micro/devtools-ui/vite'

export default defineConfig({
  plugins: [i18nDevToolsPlugin({ translationDir: 'src/locales' })],
})
```

| Opțiune | Implicit | Note |
| --- | --- | --- |
| `translationDir` | `'src/locales'` | Directorul cu fișierele JSON, relativ la rădăcina Vite. |
| `base` | `'/__i18n_api'` | Calea de bază a endpoint-urilor API. |
| `injectButton` | `true` | Adaugă un buton flotant în paginile servite prin transformarea `index.html` a Vite. Astro nu are astfel de pagini: vedeți mai jos. |
| `defaultLocale` | primul fișier de locale din `translationDir` | Raportat de `/config`. |
| `fallbackLocale` | `defaultLocale` | Raportat de `/config`. |

Plugin-ul rulează doar pe serverul de dezvoltare (`apply: 'serve'`); un build de producție nu conține nimic din el. Butonul deschide `/__i18n_devtools.html`, care citește și salvează fișierele prin endpoint-urile plugin-ului:

| Endpoint | Ce face |
| --- | --- |
| `GET <base>/translations` | fiecare dicționar din `translationDir`, după calea relativă |
| `POST <base>/save` | corp `{ file, content }`; suprascrie un `.json` existent din `translationDir`, 403 pentru orice altceva. Nu creează niciodată un fișier |
| `GET <base>/config` | `{ defaultLocale, fallbackLocale, locales, translationDir }`; `locales` provin din fișierele de la rădăcina `translationDir` |

Endpoint-urile răspund doar paginii devtools: o cerere de la altă origine sau alt host primește `403`, iar `/save` acceptă doar `application/json` (`415`). Pagina află despre modificările fișierelor prin socket-ul HMR al Vite.

În Astro, adăugați integrarea în locul plugin-ului. Aceasta adaugă o aplicație în bara de instrumente de dezvoltare:

```ts
// astro.config.mjs
import { defineConfig } from 'astro/config'
import { i18nDevToolsIntegration } from '@i18n-micro/devtools-ui/vite'

export default defineConfig({
  integrations: [i18nDevToolsIntegration({ translationDir: 'src/locales' })],
})
```

Salvarea doar scrie fișierul. O aplicație care importă JSON-ul prin Vite îl primește prin HMR; pentru editări aplicate direct instanței care rulează, folosiți o punte.

## Punte către o instanță activă {#bridge-to-a-live-instance}

Pentru a încorpora editorul în propria pagină și a aplica imediat editările instanței care rulează, creați o punte dintr-un adaptor și transmiteți-o elementului `<i18n-devtools-ui>`:

```ts
import { createBridge, register } from '@i18n-micro/devtools-ui'
import { i18n, locales } from './i18n' // a runtime, React, Preact or Solid instance

register() // defines <i18n-devtools-ui> once

const bridge = createBridge({
  adapter: {
    getRouteCache: () => Object.fromEntries(i18n.storage.translations),
    addTranslations: (locale, content, merge) => i18n.addTranslations(locale, content, merge),
    addRouteTranslations: (locale, route, content, merge) => i18n.addRouteTranslations(locale, route, content, merge),
    subscribe: (cb) => i18n.subscribe(cb),
    getCurrentLocale: () => i18n.locale,
  },
  locales,
  defaultLocale: 'en',
  translationDir: 'src/locales',
})

const el = document.createElement('i18n-devtools-ui') as HTMLElement & { bridge: typeof bridge }
el.bridge = bridge
document.body.append(el)
```

`getRouteCache` trebuie să returneze dicționarele cu chei `locale:route` (`en:index`, `en:blog-post`), adică exact ce conține `i18n.storage.translations`. Pentru o instanță Vue folosiți `i18n.global.getRouteCache()` și `i18n.global.subscribeToChanges(cb)`.

`saveTranslation` actualizează mai întâi instanța, apoi face POST la `<base>/save`. Când nu există endpoint (un build static de previzualizare) sau serverul de dezvoltare nu poate fi accesat, editarea este păstrată în `localStorage`; orice altă eroare de salvare restaurează dicționarul anterior și aruncă o excepție.

## API {#api}

| Export | Punct de intrare |
| --- | --- |
| `i18nDevToolsPlugin(options)`, `i18nDevToolsIntegration(options)` | `@i18n-micro/devtools-ui/vite` |

| `createBridge(options)`, tipurile `BridgeAdapter`, `CreateBridgeOptions` | `@i18n-micro/devtools-ui` (și `/bridge/create`) |
| tipul `I18nDevToolsBridge` | `@i18n-micro/devtools-ui` (și `/bridge`) |
| `createRpcClient`, `setupRpcHost` | `@i18n-micro/devtools-ui` |
