`@i18n-micro/vue` este un plugin Vue 3 cu nucleul de traducere din Nuxt I18n Micro: `t()` reactiv, `$t` global, patru componente și un adaptor opțional pentru vue-router. Folosiți-l într-o aplicație Vue cu Vite sau SSR care nu este construită cu Nuxt. Modelul instanței, contractul router-ului și proprietățile componentelor sunt comune cu celelalte pachete și sunt descrise în [Framework-uri](/ro/integrations/overview).

## Instalare {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vue
```

```bash npm
npm install @i18n-micro/vue
```

```bash yarn
yarn add @i18n-micro/vue
```

</CodeGroup>

Dependențe peer: `vue` `^3.3.0`; `vue-router` `^4.5.1 || ^5.0.0` (opțional, doar pentru `@i18n-micro/vue/router`). Tipurile publicate necesită Vue 3.5.5 sau mai nou cu `skipLibCheck: false`; cu `skipLibCheck: true`, setarea obișnuită din template-uri, compilează și versiunile mai vechi.

## Configurare {#setup}

```ts
// src/main.ts
import { createApp } from 'vue'
import { createI18n } from '@i18n-micro/vue'
import App from './App.vue'
import en from './locales/en.json'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales: [
    { code: 'en', iso: 'en-US', displayName: 'English' },
    { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
  ],
  defaultLocale: 'en',
})

createApp(App).use(i18n).mount('#app')
```

`locales` și `defaultLocale` sunt obligatorii pentru `useI18n()`: fără ele aruncă `I18nLocalesKey not provided`. Transmiteți-le către `createI18n` (ca mai sus), către `useI18n({ locales, defaultLocale })` sau prin `app.provide(I18nLocalesKey, …)` și `app.provide(I18nDefaultLocaleKey, …)`.

Plugin-ul înregistrează global `I18nT`, `I18nLink`, `I18nGroup` și `I18nSwitcher` și adaugă `$t`, `$ts`, `$tc`, `$tn`, `$td`, `$tdr`, `$has` și `$i18n` în template-uri. În afara componentelor, instanța este `i18n.global`. Celelalte opțiuni sunt în [instanța](/ro/integrations/overview#the-instance); `routeMessages` nu este disponibil în Vue, folosiți `addRouteTranslations`.

## Traducere {#translate}

```vue
<script setup lang="ts">
import { useI18n } from '@i18n-micro/vue'

const { t, tc, tn } = useI18n()
</script>

<template>
  <h1>{{ t('greeting', { name: 'Ada' }) }}</h1>
  <!-- Hello, Ada! -->
  <p>{{ tc('apples', 3) }}</p>
  <!-- 3 apples -->
  <p>{{ $t('nav.home') }} · {{ tn(1234.5) }}</p>
</template>
```

`useI18n()` returnează metodele de traducere (`t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`), `locale` (un computed care poate fi scris), `getLocale`, `getLocales`, `defaultLocale()`, `getLocaleName`, `localePath`, `localeRoute`, `switchLocale`, `setRoute`, `getRoute`, `addTranslations`, `addRouteTranslations`, `mergeTranslations`, `resolveTranslations`, `setTranslation`, `clearCache` și `instance`.

Încărcați mai multe dicționare oricând; fiecare componentă care le citește se re-randează:

```ts
const { addTranslations, addRouteTranslations, setRoute } = useI18n()

addTranslations('de', (await import('./locales/de.json')).default)
addRouteTranslations('en', 'about', { title: 'About us' })
setRoute('about') // t('title') now reads the 'about' dictionary first
```

## Schimbarea locale-ului {#switch-locale}

```ts
const { locale, switchLocale } = useI18n()

locale.value = 'de' // only the locale
switchLocale('de') // the locale, then router.push to the localized current path
```

Încărcați dicționarul locale-ului înainte sau după schimbare; schimbarea nu descarcă nimic.

`<I18nGroup>` oferă slot-ului său un `t` cu prefix. Cheile din interiorul `<I18nT>` sau dintr-un `t()` simplu nu primesc prefix:

```vue
<I18nGroup prefix="profile" v-slot="{ t }">
  <h2>{{ t('title') }}</h2>
  <!-- profile.title -->
</I18nGroup>
```

## Rutare {#routing}

Adaptorul pentru vue-router se află într-un subpath, astfel încât punctul de intrare principal nu importă niciodată `vue-router`:

```ts
// src/main.ts
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import { createI18n } from '@i18n-micro/vue'
import { createVueRouterAdapter } from '@i18n-micro/vue/router'
import App from './App.vue'
import Home from './pages/Home.vue'
import About from './pages/About.vue'
import en from './locales/en.json'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English' },
  { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
]

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/:locale(de)?', component: Home },
    { path: '/:locale(de)?/about', component: About },
  ],
})

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales,
  defaultLocale: 'en',
  routingStrategy: createVueRouterAdapter(router, locales, 'en'),
})

createApp(App).use(router).use(i18n).mount('#app')
```

`createVueRouterAdapter(router, locales, defaultLocale)` adaugă prefix fiecărui locale, cu excepția celui implicit (`/about`, `/de/about`), și randează `<I18nLink>` ca `RouterLink`. Citiți singur locale-ul din rută, de exemplu în `router.beforeEach`, și setați `i18n.global.locale.value`. Puteți atașa un adaptor și mai târziu cu `i18n.setRoutingStrategy(adapter)`; pentru un adaptor personalizat consultați [Adaptorul de router](/ro/integrations/overview#router-adapter).

## SSR {#ssr}

- Creați router-ul, instanța i18n și aplicația în funcția de randare per cerere. O singură instanță partajată ar transmite locale-ul unui vizitator altuia.
- Folosiți `createMemoryHistory()` pe server, preluați locale-ul din URL și încărcați dicționarul acestuia (și pe cel de fallback) înainte de `renderToString`.
- Trimiteți locale-ul către client (de exemplu într-un script `window.__STATE__`) și creați instanța client cu același `locale`, astfel încât hidratarea să se potrivească.
- `<I18nSwitcher>` citește `window.location` doar când meniul derulant este deschis, așa că se randează pe server.

`packages/vue/playground` conține o pereche completă `entry-server.ts` / `entry-client.ts`.

## Head SEO {#seo-head}

`useLocaleHead(options)` construiește tag-urile `lang`/`dir`, canonical, `hreflang` și `og:locale` din locale-uri și adaptorul de router. Apelați `updateMeta()` când ruta se schimbă și transmiteți `metaObject` managerului de head:

```ts
import { watch } from 'vue'
import { useRoute } from 'vue-router'
import { useHead } from '@unhead/vue'
import { useLocaleHead } from '@i18n-micro/vue'

const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
watch(() => route.fullPath, () => updateMeta(), { immediate: true })
useHead(metaObject)
```

Opțiuni: `baseUrl` (șir sau funcție), `addDirAttribute` (implicit `true`), `addSeoAttributes` (implicit `true`), `identifierAttribute` (implicit `'id'`), `hreflangBaseLanguage` (implicit `false`). Locale-urile cu `disabled: true` sau `seo: false` nu primesc link alternativ.
