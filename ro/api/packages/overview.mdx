Modulul Nuxt este construit din pachete mici `@i18n-micro/*`, iar majoritatea funcționează și independent: `@i18n-micro/vue` într-o aplicație Vue, `@i18n-micro/core` oriunde. Folosește aceste pagini pentru a vedea ce exportă un pachet, pentru fiecare punct de intrare. Fiecare pagină este generată din snapshot-ul pe care [`pnpm run api:surface`](https://s00d.github.io/nuxt-i18n-micro/contributing/maintenance-commands#api-surface) îl verifică în raport cu sursele TypeScript, astfel încât un export nu se poate schimba fără ca CI să observe.
