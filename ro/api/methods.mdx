# 🛠️ Metode

Această pagină documentează toate metodele disponibile oferite de nuxt-i18n-micro. Metodele sunt organizate pe funcționalitate pentru navigare mai ușoară.

## 📊 Prezentare generală API

Fiecare helper injectat de plugin, citit din interfața `PluginsInjections`. Astfel această
listă nu poate diverge de ceea ce este disponibil în realitate.

`useNuxtApp()`, dar **nu** sunt returnate de composable-ul `useI18n()`, așa că lipsesc
din tabelul de mai sus. (`$getI18nConfig` **este** disponibil prin ambele.) Vezi secțiunile lor
mai jos.
</Info>

### `$getI18nConfig`

{/* generated:method:$getI18nConfig — do not edit; run `pnpm run docs:generate` */}

```ts
() => ModuleOptionsExtend
```

Configurația modulului rezolvată, așa cum o vede runtime-ul.

{/* /generated:method:$getI18nConfig */}

```typescript
const nuxtApp = useNuxtApp()
const { localeCookie, strategy, hooks } = nuxtApp.$getI18nConfig()
```

Pentru contexte de build sau non-Nuxt, folosește `getI18nConfig()` din `#build/i18n.strategy.mjs`.

<Info>
`serverTranslationPreload` este o opțiune privată de modul expusă doar în configurația privată de server (`#i18n-internal/config`). Nu face parte din API-ul public de runtime și se poate schimba fără notificare.
</Info>

## 🔍 Metode de traducere

Metode de bază pentru preluarea și gestionarea traducerilor.

### `$t`

{/* generated:method:$t — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Traduce o cheie, interpolând `params` în ea. Returnează `defaultValue` când cheia
lipsește, sau cheia însăși dacă nu este furnizată nicio valoare implicită.

{/* /generated:method:$t */}

```typescript
const welcomeMessage = $t('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

<Warning>
`$t` returnează `CleanTranslation` care este `string | number | boolean | Translations | PluralTranslations | null`. Dacă cheia indică un **obiect imbricat** în JSON-ul tău (de exemplu, `$t('header')` când JSON-ul conține `\{ "header": \{ "title": "Hi" \} \}`), valoarea returnată va fi acel **obiect**, nu un string. Folosindu-l direct într-un template Vue (<code v-pre>\{\{ $t('header') \}\}</code>) se va randa ca `[object Object]`.

**Cum să eviți acest lucru:**

- Folosește o cheie mai specifică: `$t('header.title')` → `"Hi"`
- Folosește `$ts()` care returnează întotdeauna un string (apelează `.toString()` pe non-string-uri)
- Folosește `$t` cu o cheie imbricată pentru a accesa intenționat sub-obiecte pentru utilizare programatică
</Warning>

### `$ts`

{/* generated:method:$ts — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string) => string
```

Ca `$t`, dar returnează întotdeauna un string: un obiect sau array este serializat în loc să fie
returnat ca atare.

{/* /generated:method:$ts */}

```typescript
const welcomeMessage = $ts('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

### `$_t` și `$_ts`

{/* generated:method:$_t — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Leagă `$t` de o rută specifică, pentru a traduce în afara paginii curente. De exemplu, un layout care randează
un link către o altă rută.

{/* /generated:method:$_t */}

{/* generated:method:$_ts — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => string
```

Leagă `$ts` de o rută specifică. Vezi `$_t`.

{/* /generated:method:$_ts */}

Variante ale `$t` și `$ts` legate de rută. Ele primesc mai întâi o **rută** și returnează o funcție de traducere fixată pe contextul locale/pagină al rutei respective.

- **Acces**: `useNuxtApp()` (de asemenea, re-exportate de `useI18n()` ca `$_t` / `$_ts`)

Folosește-le atunci când ruta activă în timpul SSR sau al tranzițiilor diferă de `router.currentRoute`. De exemplu, în interiorul `<i18n-t>`, `<i18n-group>` sau când randezi conținut pentru un obiect `route` specific.

```typescript
import { useRoute, useNuxtApp } from '#imports'

const route = useRoute()
const { $_t, $_ts } = useNuxtApp()

const $t = $_t(route)
const title = $t('page.title')

// String-safe variant
const label = $_ts(route)('page.label')
```


### `$tc`

{/* generated:method:$tc — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params: number | Params, defaultValue?: string) => string
```

Traduce cu pluralizare. `params` poate fi numărul în sine sau un obiect care conține
`count`.

{/* /generated:method:$tc */}

**Format de traducere**: forme separate prin `|`. Pune placeholder-e în **fiecare** formă:

```json
{
  "apples": "no apples | one apple | {count} apples",
  "cart": "no items for {name} | one item for {name} | {count} items for {name}"
}
```

```typescript
$tc('apples', 0) // "no apples"
$tc('apples', 1) // "one apple"
$tc('apples', 10) // "10 apples"

// count + other params (second argument must be an object)
$tc('cart', { count: 10, name: 'Alice' }) // "10 items for Alice"
```


**Alternativă cu componentă** — `<i18n-t keypath="cart" :plural="count" :params="\{ name \}" />` (îmbină `count` cu `params` intern).


### `$mergeTranslations`

{/* generated:method:$mergeTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
(newTranslations: Translations) => void
```

Îmbină traduceri în locale-ul activ la runtime, suprascriind ceea ce este încărcat.

{/* /generated:method:$mergeTranslations */}

```typescript
$mergeTranslations({
  welcome: 'Bienvenue, {username}!',
})
// Output: Updates the translation cache with the new French translation
```

### `$resolveTranslations`

{/* generated:method:$resolveTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
() => Translations
```

Fiecare traducere prezentă în memorie pentru locale-ul și ruta activă, sub formă de arbore.
Vedere doar pentru citire a ceea ce `$t()` poate rezolva chiar acum.

{/* /generated:method:$resolveTranslations */}

```typescript
const tree = $resolveTranslations()
// { aaa: { bbb: 'ccc' }, ddd: 1111 } — the same dictionary $t() reads from
```

Folosește acest lucru când ai nevoie de dicționarul complet din memorie (DevTools, teste, editori de runtime). Tratează valoarea returnată ca fiind doar pentru citire; modifică valorile prin `$setTranslation` sau aplică patch-uri de îmbinare cu `$mergeTranslations`.

### `$setTranslation`

{/* generated:method:$setTranslation — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, value: unknown) => void
```

Înlocuiește valoarea de la `key` în dicționarul activ. Aceasta este o înlocuire, nu o îmbinare.
Folosește `$mergeTranslations` când elementele existente adiacente trebuie să supraviețuiască.

{/* /generated:method:$setTranslation */}

```typescript
$setTranslation('aaa', { fff: 'ggg' }) // replaces the whole `aaa` subtree
$setTranslation('aaa', 'text')          // replaces `aaa` with a string
$setTranslation('ddd', 1111)            // scalar at the top level
$setTranslation('aaa.bbb', 'nested')    // dotted path
```

Aceasta este o **înlocuire**, nu o îmbinare. Elementele existente adiacente sub aceeași cheie sunt eliminate. Pentru a aplica un patch fără a pierde elementele adiacente, folosește `$mergeTranslations`.

### `$setMissingHandler`

{/* generated:method:$setMissingHandler — do not edit; run `pnpm run docs:generate` */}

```ts
(handler: MissingHandler | null) => void
```

Instalează un callback invocat pentru fiecare cheie nerezolvată. Trece `null` pentru a-l elimina.

{/* /generated:method:$setMissingHandler */}

**Definiție de tip**:

```typescript
type MissingHandler = (locale: string, key: string, routeName: string, instance?: unknown, type?: string) => void
```

```typescript
// Set a custom handler
$setMissingHandler((locale, key, routeName) => {
  console.error(`Missing translation: ${key} in ${locale} for route ${routeName}`)
  // Send to Sentry or other error tracking service
  // Sentry.captureMessage(`Missing translation: ${key}`)
})

// Remove the handler
$setMissingHandler(null)
```

**Cazuri de utilizare**:

- Logarea traducerilor lipsă către servicii de urmărire a erorilor (Sentry, LogRocket etc.)
- Colectarea de analitici despre traducerile lipsă
- Gestionarea personalizată a erorilor pentru chei de traducere lipsă

## 🔢 Formatarea numerelor și datelor

Metode pentru formatarea numerelor și datelor conform convențiilor locale.

### `$tn`

{/* generated:method:$tn — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Formatează un număr cu `Intl.NumberFormat` în locale-ul activ. O cheie selectează un format
cu nume din configurație.

{/* /generated:method:$tn */}

```typescript
// Inline options
const formattedNumber = $tn(1234567.89, { style: 'currency', currency: 'USD' })
// "$1,234,567.89"

// Named format (from nuxt.config i18n.numberFormats)
const price = $tn(1000, 'currency')
const priceDe = $tn(1000, 'currency', 'de')
const compact = $tn(1000, 'currency', { notation: 'compact' })
```

Cheile de formate cu nume necunoscute cad înapoi la opțiunile implicite `Intl.NumberFormat`. În dezvoltare (client), un `console.warn` este emis atunci când `missingWarn` este activat (implicit).

**Exemplu de configurare**:

```ts
export default defineNuxtConfig({
  i18n: {
    numberFormats: {
      en: {
        currency: { style: 'currency', currency: 'USD' },
        decimal: { style: 'decimal', minimumFractionDigits: 2, maximumFractionDigits: 2 },
      },
      de: {
        currency: { style: 'currency', currency: 'EUR' },
      },
    },
  },
})
```

**Cazuri de utilizare**:

- Formatarea numerelor ca monedă, procente sau zecimale în formatul de locale adecvat
- Reutilizarea formatelor cu nume în întreaga aplicație (paritate cu migrarea Vue I18n)

### `$td`

{/* generated:method:$td — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Formatează o dată cu `Intl.DateTimeFormat` în locale-ul activ. O cheie selectează un format
cu nume din configurație.

{/* /generated:method:$td */}

```typescript
const formattedDate = $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' })
// "Friday, September 1, 2023"

const short = $td(new Date(), 'short')
const longDe = $td(new Date(), 'long', 'de')
```

Cheile de formate cu nume necunoscute cad înapoi la opțiunile implicite `Intl.DateTimeFormat`. În dezvoltare (client), un `console.warn` este emis atunci când `missingWarn` este activat (implicit).

**Exemplu de configurare**:

```ts
export default defineNuxtConfig({
  i18n: {
    datetimeFormats: {
      en: {
        short: { year: 'numeric', month: 'short', day: 'numeric' },
        long: { year: 'numeric', month: 'long', day: 'numeric', weekday: 'long' },
      },
    },
  },
})
```

**Cazuri de utilizare**:

- Afișarea datelor într-un format care se aliniază cu locale-ul utilizatorului
- Partajarea de presetări short/long/date-time în întreaga aplicație

### `$tdr`

{/* generated:method:$tdr — do not edit; run `pnpm run docs:generate` */}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

Formatează o dată ca timp relativ („acum 3 zile") cu `Intl.RelativeTimeFormat`.

{/* /generated:method:$tdr */}

```typescript
const relativeDate = $tdr(new Date(Date.now() - 1000 * 60 * 5))
// Output: "5 minutes ago" in the 'en-US' locale
```

## 🔄 Schimbarea rutei și a locale-ului

Metode pentru comutarea între locale și rute.

### `$switchLocale`

{/* generated:method:$switchLocale — do not edit; run `pnpm run docs:generate` */}

```ts
(locale: string) => void
```

Navighează la pagina curentă în alt locale.

{/* /generated:method:$switchLocale */}

```typescript
$switchLocale('fr')
// Prefix strategies: navigates to the French version of the route
// no_prefix: updates locale and translations without changing the URL path
```

<Tip>
Vezi [FAQ — schimbă locale-ul fără a schimba URL-ul](/guides/faq#-switch-locale-without-changing-the-url). Pentru strategiile cu prefix, folosește `$switchLocalePath()` când ai nevoie doar de o țintă de link.
</Tip>

### `$switchLocaleRoute`

{/* generated:method:$switchLocaleRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(locale: string) => RouteLocationRaw
```

Obiectul de rută pentru pagina curentă în alt locale, fără a naviga.

{/* /generated:method:$switchLocaleRoute */}

```typescript
// on /en/news
const routeFr = $switchLocaleRoute('fr')
// Output: A route object with the new locale applied, e.g., { name: 'localized-news', params: { locale: 'fr' } }
```

### `$switchLocalePath`

{/* generated:method:$switchLocalePath — do not edit; run `pnpm run docs:generate` */}

```ts
(locale: string) => string
```

Calea paginii curente în alt locale, fără a naviga.

{/* /generated:method:$switchLocalePath */}

```typescript
// on /en/news
const routeFr = $switchLocalePath('fr')
window.location.href = routeFr
// Output: url with new locale applied, e.g., '/fr/nouvelles'
```

### `$switchRoute`

{/* generated:method:$switchRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, toLocale?: string) => void
```

Navighează la altă rută, păstrând locale-ul activ sau schimbând la `toLocale`.

{/* /generated:method:$switchRoute */}

**Exemple**:

<CodeGroup>
```typescript String Path
// Switches to the given path with the current locale
$switchRoute('/about')
```

```typescript String Path with Locale
// Switches to the given path with French locale
$switchRoute('/about', 'fr')
```

```typescript Named Route
// Switches to a named route with the current locale
$switchRoute({ name: 'page' })
```

```typescript Named Route with Locale
// Switches to a named route and changes the locale to Spanish
$switchRoute({ name: 'page' }, 'es')
```
</CodeGroup>

## 🚦 Configurarea rutei

Metode pentru configurarea comportamentului rutelor și a controlului accesului.

### `$defineI18nRoute`

{/* generated:method:$defineI18nRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Înregistrează configurația locale-ului per pagină și traducerile din interiorul unei componente.
Se îmbină în locale-ul activ și se reaplică atunci când locale-ul se schimbă.

{/* /generated:method:$defineI18nRoute */}

> [!IMPORTANT]
> `$defineI18nRoute` este furnizat de **plugin-ul define** și este disponibil doar pe `useNuxtApp()`. **Nu** face parte din obiectul returnat de `useI18n()`.
> Destructurează-l întotdeauna din `useNuxtApp()` în interiorul `script setup`. Apelarea `$defineI18nRoute(...)` ca variabilă globală simplă aruncă `"$defineI18nRoute is not defined"` în timpul SSR/prerender.

**Parametri**:

- **locales**: `string[] | Record<string, Record<string, string>>` — Localele disponibile pentru rută
- **localeRoutes**: `Record<string, string>` — Opțional. Rute personalizate pentru locale specifice
- **disableMeta**: `boolean | string[]` — Opțional. Dezactivează etichetele meta i18n pentru toate sau anumite locale

**Exemplu de bază**:

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr', 'de'],
  localeRoutes: {
    en: '/welcome',
    fr: '/bienvenue',
    de: '/willkommen',
  },
  disableMeta: false,
})
```

> 📖 **Pentru exemple detaliate de utilizare, formate de configurare și bune practici, vezi [Ghidul de traduceri per componentă](/guides/per-component-translations).**

### `$setI18nRouteParams`

{/* generated:method:$setI18nRouteParams — do not edit; run `pnpm run docs:generate` */}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Setează parametri per locale pentru ruta curentă, astfel încât un segment dinamic să difere pe limbă.
Apelează-l în timpul SSR, înainte ca head-ul să fie randat.

{/* /generated:method:$setI18nRouteParams */}

```typescript
// in pages/news/[id].vue
// for en/news/1-first-article
const { $switchLocaleRoute, $setI18nRouteParams, $defineI18nRoute } = useNuxtApp()
$defineI18nRoute({
  localeRoutes: {
    en: '/news/:id()',
    fr: '/nouvelles/:id()',
    de: '/Nachricht/:id()',
  },
})
const { data: news } = await useAsyncData(`news-${params.id}`, async () => {
  let response = await $fetch("/api/getNews", {
    query: {
      id: params.id,
    },
  });
  if (response?.localeSlugs) {
    response.localeSlugs = {
      en: {
        id: '1-first-article'
      }
      fr: {
        id: '1-premier-article'
      }
      de: {
        id: '1-erster-Artikel'
      }
    }
    $setI18nRouteParams(response?.localeSlugs);
  }
  return response;
});
$switchLocalePath('fr') // === 'fr/nouvelles/1-premier-article'
$switchLocalePath('de') // === 'de/Nachricht/1-erster-Artikel'
```

## 🔧 Metode de cache și utilitare

### `$has`

{/* generated:method:$has — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string) => boolean
```

Dacă o cheie se rezolvă în locale-ul activ. Folosește pentru ramificare pe copy opțional în loc
să randezi o cheie brută.

{/* /generated:method:$has */}

În timpul tranzițiilor între pagini cu același locale, v3 îmbină automat în profunzime traducerile din pagina care pleacă în acest dicționar până când tranziția se termină. Astfel, cheile din pagina anterioară pot returna în continuare `true` pentru scurt timp. Nu există o opțiune `previousPageFallback`; acest comportament este încorporat. Vezi [FAQ — tranziții între pagini](/guides/faq#-why-do-translations-break-during-page-transitions-especially-with-defineasynccomponent).

```typescript
if ($has('welcome')) {
  console.log($t('welcome'))
} else {
  console.log('Key not found')
}
```

## 🧭 Composable-ul `useI18nLocale`

Composable-ul centralizat pentru gestionarea stării locale-ului. Folosește-l în loc să manipulezi direct `useState('i18n-locale')` sau `useCookie('user-locale')`.

```typescript
const {
  setLocale, // (locale: string) => void — updates state + cookie
  getLocale, // () => string | null — from state or cookie
  getPreferredLocale, // () => string | null — validated against locales list
  getEffectiveLocale, // (route, getLocaleFromRoute) => string
  resolveInitialLocale, // (options) => string
  isValidLocale, // (locale) => boolean
  locale, // Ref<string | null> — reactive state
  localeCookie, // CookieRef — reactive cookie
  syncLocale, // (locale) => void — sync to cookie only
  validLocales, // string[] — list of valid locale codes
} = useI18nLocale()
```

### Metode cheie

| Metodă                  | Descriere                                                       |
| ----------------------- | --------------------------------------------------------------- |
| `setLocale(locale)`     | Setează locale-ul atomic atât în `useState`, cât și în cookie   |
| `getLocale()`           | Returnează locale-ul curent din state sau cookie                |
| `getPreferredLocale()`  | Returnează locale-ul validat față de lista `locales`, sau `null` |
| `isValidLocale(locale)` | Verifică dacă un cod de locale este în lista configurată `locales` |

### Utilizare în plugin-uri personalizate

```typescript
// plugins/i18n-loader.server.ts
export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,
  setup() {
    const { setLocale } = useI18nLocale()
    // Detect locale from headers, domain, etc.
    setLocale('de')
  },
})
```

Vezi [Detectare personalizată a limbii](/guides/custom-language-detection) pentru exemple detaliate.
