---
title: "Helperi"
description: "Fiecare helper runtime pe care îl injectează modulul — `$t`, `$tc`, `$localePath`, `$switchLocale` și ceilalți — cu semnătura sa."
---

Modulul își injectează helperii runtime în aplicația Nuxt: `$t`, `$tc`, `$localePath`, `$switchLocale` și ceilalți. Folosește această pagină pentru a căuta semnătura și comportamentul unui helper. Semnăturile și descrierile provin din interfețele `PluginsInjections` și `NuxtAppOnlyInjections` din `src/runtime/plugins/01.plugin.ts`.

## Acces {#access}

| Unde | Cum |
| --- | --- |
| Șablon | `{{ $t('title') }}` — fiecare helper, cu `$` |
| `<script setup>` | `const { t, localePath } = useI18n()` — fiecare helper din `PluginsInjections`, cu și fără `$` |
| Plugin, middleware, `<script setup>` | `const { $t, $defineI18nRoute } = useNuxtApp()` — totul, doar cu `$` |

`$defineI18nRoute` este tipizat doar pe `useNuxtApp()`. Vezi [`useI18n`](/ro/composables/useI18n).

```vue
<script setup lang="ts">
const { t, localePath } = useI18n()
</script>

<template>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
</template>
```

## Limbă {#locale}

### `$getLocale` {#$getlocale}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric) => string
```

Codul limbii active. Transmite o rută pentru a citi limba căreia îi aparține acea rută.

```ts
$getLocale() // 'de' on /de/about
```

### `$getLocaleName` {#$getlocalename}

```ts
() => string | null
```

`displayName`-ul limbii active din configurație sau `null` când nu are unul.

### `$getLocales` {#$getlocales}

```ts
() => Locale[]
```

Fiecare limbă configurată, cu metadatele sale.

Proprietățile personalizate ale unui obiect de limbă sunt returnate așa cum au fost scrise; tipizează-le prin [augmentarea modulului](/ro/api/module-options#locales) pentru `Locale`.

### `$defaultLocale` {#$defaultlocale}

```ts
() => string | undefined
```

Codul limbii implicite configurate.

### `$getI18nConfig` {#$geti18nconfig}

```ts
() => ResolvedI18nConfig
```

Configurația rezolvată a modulului, așa cum o vede runtime-ul.

Valoarea include [suprascrierile la runtime](/ro/guide/runtime-overrides) (`defaultLocale`, `fallbackLocale`, limbile dezactivate).

```ts
const { strategy, localeCookie } = useNuxtApp().$getI18nConfig()
```

## Traducere {#translation}

### `$t` {#$t}

```ts
TranslationFn<CleanTranslation>
```

Traduce o cheie, interpolând `params` în ea. Returnează `defaultValue` când cheia
lipsește sau cheia însăși când nu este dată nicio valoare implicită.

```ts
// { "welcome": "Welcome, {name}!" }
$t('welcome', { name: 'Ada' }) // 'Welcome, Ada!'
$t('missing.key', {}, 'Fallback') // 'Fallback'
```

O cheie care indică un obiect imbricat returnează acel obiect, nu un șir. Într-un șablon se randează ca `[object Object]`; folosește o cheie frunză.

### `$ts` {#$ts}

```ts
TranslationFn<string>
```

Ca `$t`, dar returnează întotdeauna un șir: valoarea trece prin `toString()`, așa că un obiect
imbricat devine `'[object Object]'`. Îndreaptă cheia către o frunză.

### `$_t` {#$_t}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<CleanTranslation>
```

Leagă `$t` de o rută anume, pentru a traduce în afara paginii curente — de exemplu, un layout care randează
un link către altă rută.

```ts
const route = useRoute()
const t = useNuxtApp().$_t(route)
t('page.title')
```

### `$_ts` {#$_ts}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<string>
```

Leagă `$ts` de o rută anume. Vezi `$_t`.

### `$tc` {#$tc}

```ts
(key: TranslationKey, params: number | Params, defaultValue?: string) => string
```

Traduce cu pluralizare. `params` poate fi numărul însuși sau un obiect care conține
`count`.

Formele sunt separate prin `|`. Cu regula încorporată, un număr întreg nenegativ `n` alege forma `n`, limitată la ultima formă; un număr negativ, fracționar sau `NaN` ia ultima formă. `{count}` și ceilalți parametri sunt interpolați în forma aleasă.

Pentru limbile ale căror plurale nu urmează numărul, începe șablonul cu `=0 `. Prima formă este atunci pentru 0, iar celelalte urmează categoriile [`Intl.PluralRules`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/PluralRules), în ordinea `zero, one, two, few, many, other`:

```json
{
  "apples": "=0 no apples | one apple | {count} apples",
  "files": "=0 no files | {count} one | {count} few | {count} many"
}
```

```ts
$tc('apples', 0) // 'no apples'
$tc('apples', 1) // 'one apple'
$tc('apples', 7) // '7 apples'

// In `uk` (categories `one, few, many, other`) the forms after the zero form follow those categories:
$tc('files', 21) // '21 one'
$tc('files', 22) // '22 few'
$tc('files', 25) // '25 many'
$tc('files', 2.5) // '2.5 many': no form for `other`, so the last one
```

- `=0 ` contează doar chiar la începutul valorii, cu spațiu. `$t` îl afișează ca text: aparține pluralelor.
- O categorie fără formă proprie ia ultima formă. Un număr negativ sau fracționar ia de asemenea ultima formă.
- Funcționează în orice limbă: `=0 none | one | {count} many` în engleză.
- Categoria provine din `iso`-ul limbii, altfel din codul ei. Un cod pe care `Intl` nu îl cunoaște revine la regula indexului, cu marcajul eliminat în continuare, astfel încât rezultatul nu depinde niciodată de mașină.
- `<i18n-t :plural>` urmează aceeași regulă. Un [`plural`](/ro/api/module-options#plural) personalizat sau `customPluralRule` primește valoarea brută, inclusiv marcajul, și decide singur; un `plural` care returnează `null` predă apelul înapoi regulii încorporate, care respectă marcajul.

Fără marcaj, un șablon rămâne pe regula indexului, cu o singură excepție care se poate citi doar într-un fel: o formă pentru zero fără placeholder, apoi câte o formă pentru fiecare categorie, cu `{count}` în fiecare formă pe care o împart mai multe numere (`no files | {count} one | {count} few | {count} many` în `uk`).

Pentru reguli proprii setează [`plural`](/ro/api/module-options#plural).

```ts
// { "apples": "no apples | one apple | {count} apples" }
$tc('apples', 0) // 'no apples'
$tc('apples', 10) // '10 apples'
$tc('cart', { count: 2, name: 'Ada' }) // count and params in one object
```

Al treilea argument este `defaultValue`, nu parametrii.

### `$has` {#$has}

```ts
(key: string) => boolean
```

Dacă o cheie se rezolvă în limba activă. Folosește-l pentru a ramifica după un text opțional în loc
să randezi o cheie brută. La fel ca `$t`, vede și cheile paginii care este părăsită în timpul unei tranziții
de pagină în aceeași limbă.

```ts
if ($has('promo.banner')) show.value = true
```

## Formatare {#formatting}

### `$tn` {#$tn}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Formatează un număr cu `Intl.NumberFormat` în limba activă. O cheie selectează un format denumit
din configurație.

Formatele denumite provin din [`numberFormats`](/ro/api/module-options#numberformats).

```ts
$tn(1234.5, { style: 'currency', currency: 'EUR' }) // '1.234,50 €' in de
$tn(1000, 'currency') // named format
$tn(1000, 'currency', 'de') // named format in another locale
```

### `$td` {#$td}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Formatează o dată cu `Intl.DateTimeFormat` în limba activă. O cheie selectează un format denumit
din configurație.

Formatele denumite provin din [`datetimeFormats`](/ro/api/module-options#datetimeformats).

```ts
$td(new Date(), { dateStyle: 'long' })
$td(post.createdAt, 'short')
```

### `$tdr` {#$tdr}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

Formatează o dată ca timp relativ („acum 3 zile”) cu `Intl.RelativeTimeFormat`.

```ts
$tdr(Date.now() - 5 * 60_000) // '5 minutes ago' in en
```

## Schimbarea limbii și linkuri {#switching-and-links}

### `$switchLocale` {#$switchlocale}

```ts
(locale: string) => Promise<boolean>
```

Navighează la pagina curentă într-o altă limbă. În `no_prefix` și în modul hash încarcă
traducerile limbii înainte de navigare; în `no_prefix` ruta este înlocuită pe loc (fără
o nouă intrare în istoric). O limbă necunoscută este ignorată.
Apelul este asincron: folosește `await` pentru a rula cod după navigare. Se rezolvă cu `true` când
dicționarul limbii este activ și cu `false` când nu este: chunk-ul nu s-a putut încărca (dicționarul
curent rămâne; apelează-l din nou pentru a reîncerca) sau o schimbare mai nouă a câștigat.

```ts
await $switchLocale('de')
```

### `$switchLocalePath` {#$switchlocalepath}

```ts
(locale: string) => string
```

Calea paginii curente într-o altă limbă, fără navigare.

```vue
<NuxtLink :to="$switchLocalePath('de')">Deutsch</NuxtLink>
```

### `$switchLocaleRoute` {#$switchlocaleroute}

```ts
(locale: string) => RouteLocationRaw
```

Obiectul de rută pentru pagina curentă într-o altă limbă, fără navigare, sau un șir URL
pentru o limbă pe propriul `baseUrl`. Cu `trailingSlash`, obiectul are `path` și `fullPath`
conform regulii, cu `query` și `hash` așa cum sunt, iar `router.push` sau un link le păstrează.

### `$switchRoute` {#$switchroute}

```ts
(route: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, toLocale?: string) => Promise<void>
```

Navighează la o altă rută, păstrând limba activă sau trecând la `toLocale`. Asincron ca
`$switchLocale`.

```ts
$switchRoute('/about') // active locale
$switchRoute({ name: 'about' }, 'de') // switch to de
```

### `$localePath` {#$localepath}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => string
```

Rezolvă o cale în limba dată sau în cea activă. Un șir cu schema `http(s):`, `mailto:`
sau `tel:` este returnat neschimbat: nu transmite date introduse de utilizator ca țintă a unui link fără verificare.

O cale de tip șir este interpretată ca pagina pe care o afișează, așa că se aplică și calea personalizată a unei limbi.

```ts
$localePath('/about') // '/about' in en, '/de/ueber-uns' in de with localeRoutes
$localePath({ name: 'about' }, 'fr') // '/fr/about'
```

### `$localeRoute` {#$localeroute}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => RouteLocationResolved
```

Rezolvă o rută în limba dată sau în cea activă. Un obiect simplu, sigur de păstrat în stare. Când un parametru trebuie
escapat, are `path`, `fullPath`, `query` și `hash`, dar nu are `name` sau `params`: calea este cea care îi dă routerului
URL-ul codificat. Pentru o limbă pe alt domeniu, `path` și `fullPath` sunt absolute, ceea ce routerul nu poate accepta:
un astfel de link trece prin `<i18n-link>` sau `$localePath`.

### `$getRouteName` {#$getroutename}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric, locale?: string) => string
```

Numele rutei fără prefixul de limbă — numele după care sunt indexate traducerile.

```ts
$getRouteName() // 'about' on /de/about
```

## Configurația paginii {#page-config}

### `$defineI18nRoute` {#$definei18nroute}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Înregistrează configurația de limbă și traducerile per pagină din interiorul unei componente.
Se îmbină în limba activă și se reaplică atunci când limba se schimbă.

Apelează-l în `<script setup>` al unei pagini, întotdeauna destructurat din `useNuxtApp()`. Build-ul citește `locales`, `localeRoutes` și `disableMeta` din apel; la runtime contează doar `locales` (traducerile inline sunt îmbinate pentru limba activă). Regulile complete: [Configurația paginii](/ro/guide/per-component-translations).

```vue
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'de'],
  localeRoutes: { en: '/about', de: '/ueber-uns' },
})
</script>
```

### `$setI18nRouteParams` {#$seti18nrouteparams}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Setează parametri per limbă pentru ruta curentă, astfel încât un segment dinamic să poată diferi în funcție de limbă.
Apelează-l în timpul SSR, înainte ca head-ul să fie randat.

Parametrii sunt șterși când se finalizează o navigare către altă cale, inclusiv de la `/news/1` la `/news/4`, care păstrează numele rutei. Detalii: [Căi localizate](/ro/guide/custom-locale-routes).

```ts
$setI18nRouteParams({
  en: { slug: 'my-post' },
  de: { slug: 'mein-beitrag' },
})
```

## Traduceri la runtime {#runtime-translations}

### `$mergeTranslations` {#$mergetranslations}

```ts
(newTranslations: Translations) => void
```

Îmbină traduceri în limba activă la runtime, suprascriind ceea ce este încărcat.

Face o îmbinare profundă în chunk-ul paginii curente al limbii active; cheile pe care nu le menționează rămân.

```ts
$mergeTranslations({ banner: { title: 'Sale' } })
```

### `$setTranslation` {#$settranslation}

```ts
(key: string, value: unknown) => void
```

Înlocuiește valoarea de la `key` în dicționarul activ. Aceasta este o înlocuire, nu o îmbinare —
folosește `$mergeTranslations` când elementele vecine existente trebuie să rămână.

```ts
$setTranslation('banner', { title: 'Sale' }) // drops other keys under banner
$setTranslation('banner.title', 'Sale') // dotted path
```

### `$loadPageTranslations` {#$loadpagetranslations}

```ts
(locale: string, routeName: string, translations: Translations) => Promise<void>
```

Încarcă traduceri pentru o pagină la runtime, pentru conținut ale cărui chei nu sunt cunoscute la build.

Se îmbină în chunk-ul `(locale, routeName)` din memorie, iar ecranul se actualizează când acel chunk este activ. Aici nu se descarcă niciun payload: pentru o pagină încă neîncărcată, traducerile așteaptă, iar când fișierul ei se încarcă, ele rămân deasupra acestuia.

```ts
await $loadPageTranslations('en', 'about', { title: 'About us' })
```

### `$resolveTranslations` {#$resolvetranslations}

```ts
() => Translations
```

Fiecare traducere aflată în prezent în memorie pentru limba și ruta activă, sub formă de arbore.
O vedere doar pentru citire a ceea ce poate rezolva `$t()` în acest moment.

Tratează rezultatul ca fiind doar pentru citire.

### `$setMissingHandler` {#$setmissinghandler}

```ts
(handler: MissingHandler | null) => void
```

Instalează un callback apelat pentru fiecare cheie nerezolvată. Transmite `null` pentru a-l elimina.

Handler-ul rulează în locul avertismentului din dezvoltare.

```ts
$setMissingHandler((locale, key, routeName) => {
  console.error(`[i18n] missing ${key} in ${locale} (${routeName})`)
})
```

### `$clearCache` {#$clearcache}

```ts
() => void
```

Elimină fiecare chunk de traduceri din cache și reîncarcă dicționarul paginii curente. Pagina
continuă să afișeze traducerile curente până când sosesc cele noi. HMR-ul din dezvoltare îl apelează la
fiecare modificare a unui fișier de traducere.

```ts
const { clearCache } = useI18n()
clearCache()
```

O reîncărcare eșuată păstrează dicționarul curent.
