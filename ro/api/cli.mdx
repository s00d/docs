[Ghidul CLI](/ro/guide/cli) prezintă fluxurile de lucru obișnuite. Această pagină le enumeră pe toate și este generată din același tabel care alimentează `--help`.

## Opțiuni comune {#common-flags}

| Opțiune | Implicit | Descriere |
| --- | --- | --- |
| `--cwd` | directorul curent | Directorul proiectului |
| `--logLevel` | `info` | Nivelul de ieșire: silent, info |
| `--debug` | `false` | Afișează un stack trace când o comandă eșuează |

## Inspectare {#inspect}

### `info` {#info}

Afișează configurația i18n rezolvată a proiectului

| Opțiune | Implicit | Descriere |
| --- | --- | --- |
| `--json` | `false` | Afișează JSON în loc de text |

### `check` {#check}

Poarta CI: eșuează la chei lipsă, goale, în plus, nedefinite sau nefolosite și la placeholdere defecte

| Opțiune | Implicit | Descriere |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` din nuxt.config | Directorul de traduceri, relativ la proiect |
| `--only` | toate, cu excepția duplicates | Verificările de rulat, separate prin virgulă: missing, empty, extra, placeholders, undefined, unused, duplicates. `unused` specificat aici eșuează când nu poate rula |
| `--duplicates` | `false` | Raportează și același text aflat sub chei diferite |
| `--ignore` | — | Globuri separate prin virgulă ale fișierelor sursă de ignorat, relative la proiect |
| `--json` | `false` | Afișează JSON în loc de text |

```bash
i18n-micro check
i18n-micro check --only missing,placeholders --json
```

### `stats` {#stats}

Afișează gradul de completare a traducerilor pentru fiecare locale

| Opțiune | Implicit | Descriere |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` din nuxt.config | Directorul de traduceri, relativ la proiect |
| `--html` | — | Scrie și un raport HTML în acest fișier |
| `--json` | `false` | Afișează JSON în loc de text |
| `--baseRef` | — | Ref Git cu care se compară gradul de completare, de ex. HEAD~1 sau main |

```bash
i18n-micro stats --baseRef main
i18n-micro stats --html reports/i18n.html
```

### `lint` {#lint}

Verifică textul traducerilor; eșuează când rămân probleme

| Opțiune | Implicit | Descriere |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` din nuxt.config | Directorul de traduceri, relativ la proiect |
| `--rules` | toate, sau `enabledRules` din .i18n-lintrc.json | Regulile de rulat, separate prin virgulă: no-trailing-spaces, no-multiple-spaces, no-empty-translation sau una personalizată |
| `--fix` | `false` | Corectează ce se poate corecta: spațiile și regulile personalizate care au o înlocuire |
| `--json` | `false` | Afișează JSON în loc de text |

```bash
i18n-micro lint --rules no-trailing-spaces --fix
```

### `search` {#search}

Caută chei și valori și arată unde este folosită fiecare cheie

| Opțiune | Implicit | Descriere |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` din nuxt.config | Directorul de traduceri, relativ la proiect |
| `<query>` | — | Textul sau cheia de căutat |
| `--caseSensitive` | `false` | Ține cont de majuscule/minuscule |
| `--onlyUnused` | `false` | Doar cheile pe care `clean` le-ar elimina; interogarea devine opțională |
| `--scope` | `all` | Unde se caută: global, pages, all |
| `--limit` | — | Returnează cel mult acest număr de chei |
| `--ignore` | — | Globuri separate prin virgulă ale fișierelor sursă de ignorat, relative la proiect |
| `--json` | `false` | Afișează JSON în loc de text |

```bash
i18n-micro search "Welcome"
i18n-micro search --onlyUnused
```

## Fluxul de traducere {#translation-workflow}

### `extract` {#extract}

Listează cheile folosite în fișierele sursă care nu au încă text și le adaugă cu un text implicit în locale-ul implicit

| Opțiune | Implicit | Descriere |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` din nuxt.config | Directorul de traduceri, relativ la proiect |
| `--ignore` | — | Globuri separate prin virgulă ale fișierelor sursă de ignorat, relative la proiect |

```bash
i18n-micro extract
```

### `translate` {#translate}

Completează traducerile lipsă pornind de la locale-ul implicit, printr-un serviciu de traducere

| Opțiune | Implicit | Descriere |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` din nuxt.config | Directorul de traduceri, relativ la proiect |
| `--service` | — | Serviciul de traducere: ai, azure, deepl, google, libretranslate, yandexcloud |
| `--token` | — | Cheia API. Preferați variabila de mediu I18N_TRANSLATE_TOKEN: opțiunile ajung în istoricul shell-ului |
| `--options` | — | Opțiunile serviciului ca perechi key:value, separate prin virgulă |
| `--locale` | toate locale-urile, cu excepția celui implicit | Locale-urile de completat, separate prin virgulă |
| `--replace` | `false` | Traduce din nou fiecare cheie, înlocuind valorile existente |
| `--dryRun` | `false` | Numără cheile și caracterele pentru fiecare locale; nu trimite nimic |
| `--chunkSize` | — | Șiruri per cerere; limitat la ce acceptă serviciul |
| `--pluralSeparator` | `\|` | Separatorul formelor de plural din mesaje |
| `--glossaryFile` | `.i18n-glossary.json` când există | Fișierul glosar, folosit de serviciul `ai` |

```bash
i18n-micro translate --dryRun
I18N_TRANSLATE_TOKEN=... i18n-micro translate --service deepl --locale de,fr
i18n-micro translate --service ai --options provider:openai,model:gpt-4o-mini
i18n-micro translate --service libretranslate --options baseUrl:https://translate.example.com
```

### `sync` {#sync}

Elimină cheile pe care locale-ul implicit nu le are; se oprește când nu se poate dovedi că operația este sigură. Cheile lipsă rămân lipsă

| Opțiune | Implicit | Descriere |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` din nuxt.config | Directorul de traduceri, relativ la proiect |
| `--ignore` | — | Globuri separate prin virgulă ale fișierelor sursă de ignorat, relative la proiect |
| `--dryRun` | `false` | Listează ce ar fi eliminat; nu scrie nimic |
| `--force` | `false` | Elimină cheile chiar dacă nu se poate dovedi că operația este sigură |

```bash
i18n-micro sync --dryRun
```

### `clean` {#clean}

Elimină cheile pe care nimic din proiect nu le folosește; se oprește când acest lucru nu poate fi dovedit

| Opțiune | Implicit | Descriere |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` din nuxt.config | Directorul de traduceri, relativ la proiect |
| `--include` | — | Expresie regulată: ia în considerare pentru eliminare doar cheile care se potrivesc |
| `--exclude` | — | Expresie regulată: nu elimină niciodată cheile care se potrivesc |
| `--ignore` | — | Globuri separate prin virgulă ale fișierelor sursă de ignorat, relative la proiect |
| `--dryRun` | `false` | Listează ce ar fi eliminat; nu scrie nimic |
| `--force` | `false` | Elimină cheile chiar dacă utilizarea nu poate fi dovedită pentru toate |

```bash
i18n-micro clean --dryRun
i18n-micro clean --exclude '^errors\.'
```

## Refactorizare {#refactoring}

### `text-to-i18n` {#text-to-i18n}

Înlocuiește textul hardcodat din template-urile Vue cu apeluri de traducere și raportează textul hardcodat din cod

| Opțiune | Implicit | Descriere |
| --- | --- | --- |
| `--translationFile` | `<translationDir>/<defaultLocale>.json` | Fișierul în care ajung cheile noi |
| `--path` | întregul proiect | Fișierul sau directorul de procesat |
| `--context` | — | Prefix pentru cheile generate |
| `--ignore` | — | Globuri separate prin virgulă ale fișierelor sursă de ignorat, relative la proiect |
| `--dryRun` | `false` | Arată ce s-ar schimba; nu scrie nimic |
| `--interactive` | `false` | Confirmați sau editați fiecare cheie generată |

```bash
i18n-micro text-to-i18n --dryRun
i18n-micro text-to-i18n --path components --context ui
```

### `rename` {#rename}

Redenumește o cheie sau un namespace în toate locale-urile și în fișierele sursă

| Opțiune | Implicit | Descriere |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` din nuxt.config | Directorul de traduceri, relativ la proiect |
| `--from` **\*** | — | Cheia sau namespace-ul curent |
| `--to` **\*** | — | Cheia sau namespace-ul nou |
| `--ignore` | — | Globuri separate prin virgulă ale fișierelor sursă de ignorat, relative la proiect |
| `--dryRun` | `false` | Raportează modificările; nu scrie nimic |

**\*** obligatoriu.

```bash
i18n-micro rename --from common.save --to actions.save
```

### `pseudo` {#pseudo}

Completează un locale cu pseudo-traduceri pentru a găsi probleme de layout și text hardcodat

| Opțiune | Implicit | Descriere |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` din nuxt.config | Directorul de traduceri, relativ la proiect |
| `--sourceLocale` | locale-ul implicit | Locale-ul de citit |
| `--targetLocale` **\*** | — | Locale-ul de completat |
| `--replace` | `false` | Suprascrie valorile existente |

**\*** obligatoriu.

### `format` {#format}

Rescrie fișierele de locale cu chei sortate și indentare uniformă

| Opțiune | Implicit | Descriere |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` din nuxt.config | Directorul de traduceri, relativ la proiect |
| `--indent` | `2` | Numărul de spații de indentare |
| `--sortKeys` | `true` | Sortează cheile; folosiți --no-sortKeys pentru a le păstra ordinea |
| `--check` | `false` | Eșuează dacă un fișier s-ar schimba; nu scrie nimic |

```bash
i18n-micro format --check
```

## Schimb {#exchange}

### `export` {#export}

Exportă fișierele de locale în PO sau CSV, cu textul locale-ului implicit ca sursă

| Opțiune | Implicit | Descriere |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` din nuxt.config | Directorul de traduceri, relativ la proiect |
| `--format` | `po` | Formatul fișierului: po, csv |
| `--dir` | `pots` pentru po, `csv_exports` pentru csv | Directorul de ieșire, relativ la proiect |
| `--force` | `false` | Suprascrie fișierele modificate de la ultimul export și niciodată importate |

```bash
i18n-micro export --format csv
```

### `import` {#import}

Îmbină fișierele PO sau CSV în fișierele de locale

| Opțiune | Implicit | Descriere |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` din nuxt.config | Directorul de traduceri, relativ la proiect |
| `--format` | `po` | Formatul fișierului: po, csv |
| `--dir` | `pots` pentru po, `csv_exports` pentru csv | Directorul de intrare, relativ la proiect |
| `--dryRun` | `false` | Raportează ce ar fi importat; nu scrie nimic |

```bash
i18n-micro import --format csv --dryRun
```

### `sync-remote` {#sync-remote}

Descarcă traducerile globale de la endpoint-ul HTTP din .i18n-remote.json sau le trimite către acesta

| Opțiune | Implicit | Descriere |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` din nuxt.config | Directorul de traduceri, relativ la proiect |
| `--pull` | `true` | Descarcă de la remote |
| `--push` | `false` | Trimite către remote |
| `--force` | `false` | La pull, preia valoarea de la remote; la push, suprascrie textul existent doar pe remote |
| `--dryRun` | `false` | Raportează ce ar schimba un pull; nu scrie și nu trimite nimic |

```bash
i18n-micro sync-remote --dryRun
i18n-micro sync-remote --no-pull --push
```

## Reguli de lint {#lint-rules}

| Regulă | Găsește | Corectată de `--fix` |
| --- | --- | --- |
| `no-trailing-spaces` | Spații la sfârșitul unei valori sau al unei linii | da |
| `no-multiple-spaces` | Două sau mai multe spații consecutive | da |
| `no-empty-translation` | O valoare goală sau formată doar din spații | nu |

## Coduri de ieșire {#exit-codes}

| Cod | Semnificație |
| --- | --- |
| `0` | Terminat, nimic de raportat |
| `1` | Constatări: `check`, `lint` sau `format --check` au găsit ceva, `clean` sau `sync` nu au putut dovedi că o eliminare este sigură, `export` ar suprascrie munca neimportată, `translate` a omis chei, `import` sau `sync-remote` au întâlnit un conflict, un push `sync-remote` ar elimina text de pe remote. Un `--dryRun` pentru `clean`, `sync` sau un pull `sync-remote` le raportează și iese cu `0` |
| `2` | Eșec: utilizare greșită, proiect ilizibil, eroare de rețea sau de fișier |

## Fișiere de configurare {#configuration-files}

| Fișier | Folosit de |
| --- | --- |
| `.i18n-lintrc.json` | `lint`: `enabledRules`, `disabledRules`, `customRegexRules` (`name`, `pattern`, `flags`, `description`, `replacement`) |
| `.i18n-remote.json` | `sync-remote`: `url`, `path`, `token`, `auth` (`username`, `password`). `type` poate fi omis; există doar `custom` |
| `.i18n-glossary.json` | `translate --service ai`: `entries` cu `source`, `target` și, opțional, `from`, `to` |

## Variabile de mediu {#environment-variables}

| Nume | Folosită pentru |
| --- | --- |
| `I18N_TRANSLATE_TOKEN` | Cheia API pentru `translate`. Citită și din `.env` |
| `I18N_REMOTE_TOKEN` | Tokenul Bearer pentru `sync-remote`. Citit și din `.env` |
| `AI_GATEWAY_API_KEY, OPENAI_API_KEY, ANTHROPIC_API_KEY` | Cheia serviciului `ai`, când `I18N_TRANSLATE_TOKEN` nu este setată |
| `DEFAULT_LOCALE` | Suprascrie `defaultLocale`, la fel ca în modul |
