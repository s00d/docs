Modulul apelează un singur hook runtime (al aplicației), `i18n:register`. Folosiți-l atunci când un plugin sau un modul adaugă traduceri care nu se află în fișierele din `locales/`. Callback-ul primește o funcție `register` care îmbină traducerile în pagina afișată.

## `i18n:register` {#i18nregister}

```ts
'i18n:register': (
  register: (translations: unknown, locale?: string) => void,
  locale: string,
) => HookResult
```

| Argument | Descriere |
| --- | --- |
| `register(translations, locale?)` | Îmbină în profunzime `translations` în fragmentul de pagină al rutei care se încarcă, pentru `locale` (implicit: `locale` al hook-ului). Cheile deja existente sunt suprascrise. |
| `locale` | Locale-ul rutei care se încarcă. |

Hook-ul este tipizat prin `RuntimeNuxtHooks`, deci `nuxtApp.hook('i18n:register', …)` nu necesită cast.

## Când se declanșează {#when-it-fires}

Plugin-ul de încărcare (`i18n-plugin-loader`) îl apelează:

1. o dată la pornire, după ce toate plugin-urile au rulat (`app:created`) și înainte ca aplicația să fie randată;
2. în `router.beforeEach`, după ce traducerile paginii țintă sunt încărcate, atunci când calea se schimbă — la fiecare navigare în cazul `no_prefix`.

Fiecare callback și fiecare apel `register` este așteptat (await) înainte ca aplicația să fie randată sau navigarea să continue, astfel încât pagina este randată cu cheile îmbinate. Cu [`hooks: false`](/ro/api/module-options#hooks), hook-ul nu este apelat niciodată.

## Exemplu {#example}

```ts
// plugins/i18n-extra.ts
export default defineNuxtPlugin((nuxtApp) => {
  nuxtApp.hook('i18n:register', async (register, locale) => {
    const extra = await $fetch<Record<string, unknown>>(`/api/cms-strings/${locale}`)
    register(extra, locale)
  })
})
```

Acesta este un hook runtime: înregistrați-l cu `nuxtApp.hook` într-un plugin, nu cu `nuxt.hook` în `nuxt.config` sau în `setup` al unui modul. Un modul adaugă un astfel de plugin cu `addPlugin`.
