# Referință opțiuni modul

Fiecare opțiune acceptată de `nuxt-i18n-micro`, citită la build time din interfața `ModuleOptions`
din
[`packages/types/src/index.ts`](https://github.com/s00d/nuxt-i18n-micro/blob/main/packages/types/src/index.ts).
Nimic aici nu este scris manual, deci nu poate rămâne în urma codului — tipurile, valorile implicite și
descrierile provin din declarația însăși.

Pentru ce *înseamnă* aceste opțiuni împreună — ce combinații au sens, ce se schimbă când
schimbi strategia, exemple concrete — citește [Configuration](/guides/configuration). Această
pagină este lista exhaustivă; cealaltă este explicația.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'de', iso: 'de-DE', dir: 'ltr' },
    ],
    defaultLocale: 'en',
  },
})
```

Opțiunile imbricate apar sub calea lor cu puncte, deci `translationPayloads.mode` este
cheia `mode` din obiectul `translationPayloads`.

## Locale și rutare

Ce limbi există și cum apar în URL.

| Opțiune | Tip | Implicit | Descriere |
| --- | --- | --- | --- |
| `locales` | `Locale[]` | `[]` | Lista locale-urilor suportate. Fiecare intrare definește un cod de locale plus metadate opționale (ISO, direcție, nume de afișare etc.). |
| `strategy` | `Strategies` | `'prefix_except_default'` | Strategia de rutare URL pentru prefixele de locale. - `'no_prefix'` — fără locale în URL; locale-ul este stocat în cookie. - `'prefix_except_default'` — prefixează toate locale-urile cu excepția celui implicit. - `'prefix'` — prefixează întotdeauna, inclusiv locale-ul implicit. - `'prefix_and_default'` — la fel ca `prefix`, dar locale-ul implicit este accesibil și fără prefix. |
| `defaultLocale` | `string` | `'en'` | Locale-ul folosit când nu poate fi determinat un locale din URL sau preferințele utilizatorului. Folosit și ca fallback pentru traducerile lipsă când `fallbackLocale` nu este setat. |
| `localeCookie` | `string \| null` | `null` | Numele cookie-ului pentru păstrarea preferinței de locale a utilizatorului între sesiuni. Setează la `null` pentru a dezactiva persistența bazată pe cookie. Setat automat la `'user-locale'` pentru strategia `no_prefix` dacă nu este furnizat. |
| `globalLocaleRoutes` | `GlobalLocaleRoutes` | `\{\}` | Configurare globală a locale-urilor la nivel de rută. Permite restricționarea sau personalizarea rutelor de locale pentru pagini specifice fără a modifica componentele lor. - `false` — exclude ruta din localizare. - `Record<LocaleCode, string>` — căi personalizate per locale. |
| `customRegexMatcher` | `string \| RegExp` | `undefined (folosește modelul intern bazat pe codurile de locale)` | Expresie regulată personalizată (sau sursa ei sub formă de șir) pentru potrivirea codurilor de locale în segmentele URL. Toate codurile de locale definite în `locales` trebuie să se potrivească cu acest model, altfel se emite un avertisment. |
| `noPrefixRedirect` | `boolean` | `false` | Pentru strategia `no_prefix`: activează redirecționarea de la un URL cu prefix de locale (de ex. `/en/about`) la versiunea fără prefix (`/about`). |
| `excludePatterns` | `(string \| RegExp)[]` | `undefined` | Modele URL (șiruri sau RegExp) de exclus complet din procesarea i18n. Rutele potrivite nu vor primi prefixe de locale, redirecționări sau încărcare de traduceri. Căile interne Nuxt (`/__nuxt_error`, etc.) sunt întotdeauna excluse automat. |
| `routeLocales` | `Record<string, string[]>` | — | Restricții de locale per rută, extrase din apelurile `defineI18nRoute()`. Mapează o cale de rută (de ex. `'/about'`) la un array de coduri de locale permise. Rutele nelistate nu au restricții (toate locale-urile sunt permise). |

## Traduceri

Unde se află fișierele de traducere și cum sunt rezolvate cheile.

| Opțiune | Tip | Implicit | Descriere |
| --- | --- | --- | --- |
| `translationDir` | `string` | `'locales'` | Calea către directorul care conține fișierele JSON de traducere, relativă la rădăcina proiectului. |
| `disableWatcher` | `boolean` | `false` | Dezactivează file watcher-ul care creează automat fișierele de traducere lipsă în modul de dezvoltare. |
| `routesLocaleLinks` | `\{ [key: string]: string \}` | `\{\}` | Mapează nume de rute la alte nume de rute pentru a partaja aceleași fișiere de traducere. De exemplu, `\{ 'about-us': 'about' \}` înseamnă că pagina `about-us` va folosi traducerile din pagina `about` în loc de cele proprii. |
| `plural` | `PluralFunc` | `pluralizare încorporată (indexul formei după count)` | Funcție personalizată de pluralizare. Primește `(key, count, params, locale, getter)` și trebuie să returneze forma de plural selectată ca șir sau `null`/`undefined` pentru a folosi logica implicită `defaultPlural` (astfel poți suprascrie doar unele locale). Pentru modulul Nuxt, funcția este serializată cu `.toString()` în `.nuxt/i18n.plural.mjs` — trebuie să fie autonomă (fără importuri / scope extern). Un șir cu calea unui fișier **nu** este suportat. |
| `disablePageLocales` | `boolean` | `false` | Dezactivează fișierele de traducere per pagină. Când este `true`, doar traducerile globale (`\{locale\}.json`) sunt încărcate; fișierele specifice paginii (`pages/\{page\}/\{locale\}.json`) nu sunt generate sau încărcate. |
| `fallbackLocale` | `string` | `undefined (fără fallback; returnează cheia brută)` | Cod global de locale fallback. Când o cheie de traducere lipsește în locale-ul activ, modulul o caută în acest locale înainte de a returna cheia însăși. |

## Payloads și cache

Cum ajung traducerile în browser. [Performance](/guides/performance) explică ce schimbă acestea la runtime.

| Opțiune | Tip | Implicit | Descriere |
| --- | --- | --- | --- |
| `serverTranslationPreload` | `boolean` | `false` | Preîncarcă traducerile paginii index în middleware-ul global Nitro (doar server, config privat). |
| `apiBaseUrl` | `string` | `'_locales'` | Segmentul de bază al URL-ului pentru ruta API de traduceri (folosit în data fetching SSR/SSG). Poate fi setat și prin variabila de mediu `NUXT_I18N_APP_BASE_URL`. |
| `apiBaseClientHost` | `string` | `undefined` | Suprascrie host-ul folosit pentru cererile de traducere din client. Util când clientul ajunge la server printr-un hostname diferit de cel văzut de Nuxt. Poate fi setat și prin variabila de mediu `NUXT_I18N_APP_BASE_CLIENT_HOST`. |
| `apiBaseServerHost` | `string` | `undefined` | Suprascrie host-ul folosit pentru cererile de traducere de pe server. Util în setup-uri container/microservicii unde serverul ajunge la sine printr-un hostname intern. Poate fi setat și prin variabila de mediu `NUXT_I18N_APP_BASE_SERVER_HOST`. |
| `translationPayloads` | `TranslationPayloadOptions` | — | Controlează cum sunt emise payloadurile de traducere (Node: `public/<apiBaseUrl>`; Edge: Nitro `serverAssets`). - **Node**: `serverAssets` înseamnă SSR local prin `readFile` sub `public/` (fără Rollup `raw:`). - **Edge**: `serverAssets` înregistrează Nitro `serverAssets` (`assets:i18n`); nu forțează o copie publică. Păstrează valorile implicite pentru setup-ul obișnuit all-in-one. Pentru cataloage mari pe Edge, preferă `mode: 'source'`. Pentru deploymenturi cu CDN, dezactivează ieșirile locale și setează `apiBaseClientHost` / `apiBaseServerHost`. |
| `translationPayloads.mode` | `'premerged' \| 'source'` | `'premerged'` | Strategia payloadului de traducere. - `premerged`: matrice `\{page\}/\{locale\}/data.json` la build-time (implicit) - `source`: fișiere sursă compacte îmbinate la runtime (preferat pe Edge / cataloage mari) |
| `translationPayloads.serverAssets` | `boolean` | `true` | Payloads SSR locale: Node citește `public/<apiBaseUrl>` (forțează copia publică); Edge integrează prin Nitro `serverAssets`. - **Node**: fără Nitro `serverAssets` (evită Rollup `raw:`). SSR citește   `public/<apiBaseUrl\|publicDir>` ca `\{page\}/\{locale\}/data.json`; când este `true`,   o copie publică este forțată chiar dacă `publicAssets` este false. - **Edge** (`nitro.node === false`): Nitro `serverAssets` (`assets:i18n`) cu aceeași   dispunere ca `mode`. Nu **forțează** o copie publică — setează `publicAssets: true` pentru CDN. |
| `translationPayloads.serverHandler` | `boolean` | `true` | Înregistrează ruta de server încorporată la `/\{apiBaseUrl\}/:page/:locale/data.json`. Dezactivează când payloadurile de traducere sunt servite de pe un host/CDN extern. |
| `translationPayloads.publicAssets` | `boolean` | `true în modul premerged, false în modul source` | Copiază payloadurile în ieșirea publică Nitro. Premerged → `\{page\}/\{locale\}/data.json` sub `apiBaseUrl`; source → arbore compact. Pe Node, acest arbore este și sursa SSR când `serverAssets` forțează o copie publică. |
| `translationPayloads.prerenderRoutes` | `boolean` | `false` | Optează pentru Nitro-prerender `/\{apiBaseUrl\}/.../data.json`. De obicei redundant când `publicAssets` premerged a scris deja acele fișiere. |
| `translationPayloads.publicDir` | `string` | — | Folderul de ieșire publică relativ la rădăcina publică Nitro. Implicit este `apiBaseUrl` (`_locales`). Astfel fișierele statice se potrivesc cu URL-urile de fetch din client (`/\{apiBaseUrl\}/\{page\}/\{locale\}/data.json`). |
| `translationPayloads.warnFileCount` | `number` | `500` | Avertizează în timpul build-ului când numărul de fișiere payload generate depășește acest prag. |
| `translationPayloads.warnSizeBytes` | `number` | `10485760 (10 MB)` | Avertizează în timpul build-ului când dimensiunea totală a payloadurilor generate depășește acest prag în octeți. |

## SEO

Meta tag-uri generate pentru fiecare pagină localizată.

| Opțiune | Tip | Implicit | Descriere |
| --- | --- | --- | --- |
| `meta` | `boolean` | `true` | Generează automat meta tag-uri SEO (`hreflang`, `canonical`, `og:url`, `og:locale`). |
| `metaBaseUrl` | `string` | `undefined` | URL de bază pentru meta tag-urile SEO (canonical, og:url, hreflang). - Un șir URL concret (de ex. `'https://example.com'`) — folosit ca atare (prioritate maximă). - `undefined` — recurge la `site.url` din `nuxt-site-config` când modulul respectiv este prezent, altfel origine-ul cererii curente   (`useRequestURL().origin` pe server, `window.location.origin` pe client). |
| `metaTrustForwardedHost` | `boolean` | `true` | Are încredere în header-ul `X-Forwarded-Host` la rezolvarea URL-ului de bază pentru meta tag-uri. Activează când aplicația rulează în spatele unui reverse proxy (nginx, Cloudflare, AWS ALB etc.) care setează acest header la hostname-ul real vizibil clientului. |
| `metaTrustForwardedProto` | `boolean` | `true` | Are încredere în header-ul `X-Forwarded-Proto` la rezolvarea protocolului pentru meta tag-uri. Activează când aplicația rulează în spatele unui proxy care termină TLS, astfel încât URL-urile canonice să folosească `https://` chiar dacă aplicația ascultă pe HTTP. |
| `canonicalQueryWhitelist` | `string[]` | `['page', 'sort', 'filter', 'search', 'q', 'query', 'tag']` | Lista numelor de parametri query păstrați în meta tag-urile canonical și `og:url`. Parametrii care nu sunt în această listă sunt eliminați din URL-ul canonic. |

## Detectare și redirecționări

Alegerea unui locale pentru un vizitator care nu a ales unul.

| Opțiune | Tip | Implicit | Descriere |
| --- | --- | --- | --- |
| `redirects` | `boolean` | `true` | Activează redirecționările automate bazate pe locale. Când este `true`, vizitatorii sunt redirecționați către locale-ul preferat (detectat din cookie, header-ul `Accept-Language` sau implicit) la prima vizită. |
| `autoDetectLanguage` | `boolean` | `true` | Detectează automat limba preferată a utilizatorului din header-ul HTTP `Accept-Language`. Folosit împreună cu `autoDetectPath` pentru a decide când are loc detectarea. |
| `autoDetectPath` | `string` | `'/'` | Unde pot rula redirecționările bazate pe preferința cookie / Accept-Language (când `redirects` este activat). - `'/'` — doar `/` (link-urile adânci în locale-ul implicit rămân accesibile; implicit) - `'no_prefix'` — doar căile fără prefix de locale - `'*'` — orice cale, inclusiv rescrierea unui prefix de locale explicit   (de ex. `/fr/about` → `/de/about` când cookie-ul preferă `de`) - orice alt șir — potrivire exactă a căii (de ex. `'/welcome'`) Curățarea strategiei prefixate (de ex. `/en` → `/` sub `prefix_except_default`) nu este restricționată. |

Părți ale modulului pe care le poți dezactiva.

| Opțiune | Tip | Implicit | Descriere |
| --- | --- | --- | --- |
| `define` | `boolean` | `true` | Înregistrează pluginul macro `defineI18nRoute()`, activând apelurile `defineI18nRoute()` per pagină. |
| `plugin` | `boolean` | `true` | Înregistrează pluginul i18n principal care oferă `$t()`, `$tc()`, `$getLocale()`, `$switchLocale()` și alte helpere runtime. |
| `hooks` | `boolean` | `true` | Înregistrează pluginul de hook-uri i18n care oferă `i18n:register` și hook-urile la nivel de aplicație `i18n:beforeLocaleSwitch` / `i18n:afterLocaleSwitch`. |
| `components` | `boolean` | `true` | Înregistrează componentele i18n încorporate (`<i18n-link>`, `<i18n-switcher>`, `<i18n-t>`, `<i18n-group>`). Setează la `false` pentru a dezactiva înregistrarea automată a componentelor (de ex. dacă nu le folosești și vrei să reduci amprenta modulului). |
| `types` | `boolean` | `true` | Generează declarații de tipuri TypeScript pentru `useI18n`, `$t` și helpere similare, bazate pe cheile de traducere din fișierele locale-ului implicit. |
| `debug` | `boolean` | `false` | Activează logging-ul verbose de debug pentru detectarea locale-ului, generarea rutelor și încărcarea traducerilor. |

| `routeDisableMeta` | `Record<string, boolean \| string[]>` | — | Dezactivarea meta tag-urilor per rută, extrasă din apelurile `defineI18nRoute()`. Mapează o cale de rută la `true` (dezactivează toate meta) sau la un array de coduri de locale pentru care meta ar trebui dezactivate. |
| `missingWarn` | `boolean` | `true` | Afișează avertismente în consolă când o cheie de traducere lipsește. |
| `hmr` | `boolean` | `true` | Activează Hot Module Replacement pentru fișierele de traducere în dezvoltare. Când este `true`, modificările fișierelor JSON de traducere declanșează o reîncărcare automată fără refresh complet al paginii. |
| `cacheMaxSize` | `number` | `0` | Numărul maxim de intrări în cache-ul de traduceri din memorie. `0` înseamnă fără limită. |
| `cacheTtl` | `number` | `0` | Time-to-live (în secunde) pentru intrările cache-uite de traducere. `0` înseamnă că intrările nu expiră niciodată. |
| `numberFormats` | `Record<string, Record<string, Intl.NumberFormatOptions>>` | — | Formate de numere denumite per locale (compatibile cu Vue I18n). Activează apeluri de tip `$tn(1000, 'currency')`. |
| `datetimeFormats` | `Record<string, Record<string, Intl.DateTimeFormatOptions>>` | — | Formate datetime denumite per locale (compatibile cu `datetimeFormats` din Vue I18n). Activează apeluri de tip `$td(date, 'short')`. |
| `httpCacheDuration` | `number` | `31536000` | `Cache-Control` HTTP max-age (secunde) pentru `/\{apiBaseUrl\}/:page/:locale/data.json`. Se aplică integral doar cât timp `dateBuild` invalidează URL-ul (`?v=...`), ceea ce este implicit: răspunsul devine `public, max-age=…, immutable` și sigur pentru browsere și CDN-uri. - `dateBuild: 0`/`''` — URL-ul este stabil, deci această durată *nu* este onorată; răspunsul   devine în schimb `public, max-age=0, must-revalidate`. Un `max-age` lung pe un URL   care nu se schimbă fixează primul payload pe care browserul l-a văzut vreodată. - `0` — nu setează deloc `Cache-Control` (util pentru debugging local) - Nu se aplică în dezvoltare (`import.meta.dev`), pentru ca HMR să nu fie combătut de cache-ul browserului - Ajunge doar la răspunsurile servite prin Nitro. Payloadurile copiate în `public/` și servite   de platforma de hosting preiau header-ele acelei platforme — vezi ghidul de Performance. Analog cu `httpCacheDuration` experimental din `@nuxtjs/i18n` (v10.2.0), dar ca header de răspuns explicit, nu ca maxAge Nitro `defineCachedEventHandler`. |
| `dateBuild` | `string \| number` | — | Valoare folosită pentru cache-busting-ul cererilor de traducere (`?v=...`). Când nu este furnizată, modulul recurge la `Date.now()` (nedeterminist). Pentru deploymenturi reproductibile/rolling, setează la o valoare stabilă (de ex. un SHA git sau un număr de build). |
| `experimental` | `Record<string, unknown>` | — | Container pentru opțiuni experimentale/instabile. Conținutul poate fi modificat sau eliminat fără avertisment între versiunile minore. |
