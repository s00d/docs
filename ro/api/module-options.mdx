# Referință opțiuni de modul

Fiecare opțiune acceptată de `nuxt-i18n-micro`, citită la build din interfața `ModuleOptions`
din
[`packages/types/src/index.ts`](https://github.com/s00d/nuxt-i18n-micro/blob/main/packages/types/src/index.ts).
Nimic de aici nu este scris de mână, așa că nu poate rămâne în urma codului. Tipurile, valorile implicite și
descrierile provin din declarația însăși.

Pentru ce *înseamnă* aceste opțiuni împreună — ce combinații au sens, ce se schimbă când
schimbi strategia, exemple lucrate — citește [Configurare](/guides/configuration). Această
pagină este lista exhaustivă; cealaltă este explicația.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'de', iso: 'de-DE', dir: 'ltr' },
    ],
    defaultLocale: 'en',
  },
})
```

Opțiunile imbricate apar sub calea lor cu punct, așa că `translationPayloads.mode` este cheia
`mode` din interiorul obiectului `translationPayloads`.

## Locale și rutare

Ce limbi există și cum apar în URL.

| Opțiune | Tip | Implicit | Descriere |
| --- | --- | --- | --- |
| `locales` | `Locale[]` | `[]` | Lista de locale suportate. Fiecare intrare definește un cod de locale plus metadate opționale (ISO, direcție, nume afișat etc.). |
| `strategy` | `Strategies` | `'prefix_except_default'` | Strategia de rutare URL pentru prefixe de locale. - `'no_prefix'` — fără locale în URL; locale-ul este stocat în cookie. - `'prefix_except_default'` — prefixează toate localele, cu excepția celui implicit. - `'prefix'` — prefixează întotdeauna, inclusiv locale-ul implicit. - `'prefix_and_default'` — ca `prefix`, dar locale-ul implicit este accesibil și fără prefix. |
| `defaultLocale` | `string` | `'en'` | Locale-ul care se folosește când niciun locale nu poate fi determinat din URL sau preferințe. Utilizat și ca fallback pentru traducerile lipsă atunci când `fallbackLocale` nu este setat. |
| `localeCookie` | `string \| null` | `null` | Numele cookie-ului pentru persistarea preferinței de locale a utilizatorului între sesiuni. Setează `null` pentru a dezactiva persistarea bazată pe cookie. Setat automat la `'user-locale'` pentru strategia `no_prefix` dacă nu este furnizat. |
| `globalLocaleRoutes` | `GlobalLocaleRoutes` | `\{\}` | Configurație globală de locale la nivel de rută. Permite restricționarea sau personalizarea rutelor per locale pentru anumite pagini fără a modifica componentele acestora. - `false` — exclude ruta din localizare. - `Record<LocaleCode, string>` — căi personalizate per locale. |
| `customRegexMatcher` | `string \| RegExp` | `undefined (uses built-in pattern based on locale codes)` | Expresie regulată personalizată (sau șirul sursă al acesteia) pentru potrivirea codurilor de locale în segmentele URL. Toate codurile de locale definite în `locales` trebuie să se potrivească acestui model, altfel se emite un avertisment. |
| `noPrefixRedirect` | `boolean` | `false` | Pentru strategia `no_prefix`: activează redirecționarea de la un URL cu prefix de locale (de exemplu, `/en/about`) la versiunea fără prefix (`/about`). |
| `excludePatterns` | `(string \| RegExp)[]` | `undefined` | Modele URL (string-uri sau RegExp) care sunt excluse complet din procesarea i18n. Rutele potrivite nu vor primi prefixe de locale, redirecționări sau încărcare de traduceri. Căile interne Nuxt (`/__nuxt_error` etc.) sunt întotdeauna excluse automat. |
| `routeLocales` | `Record<string, string[]>` | — | Restricții de locale per rută, extrase din apelurile `defineI18nRoute()`. Mapează o cale de rută (de exemplu, `'/about'`) la un array de coduri de locale permise. Rutele nelistate nu au restricții (toate localele sunt permise). |

## Traduceri

Unde locuiesc fișierele de traducere și cum sunt rezolvate cheile.

| Opțiune | Tip | Implicit | Descriere |
| --- | --- | --- | --- |
| `translationDir` | `string` | `'locales'` | Calea către directorul care conține fișierele JSON de traducere, relativă la rădăcina proiectului. |
| `disableWatcher` | `boolean` | `false` | Dezactivează watcher-ul de fișiere care creează automat fișierele de traducere lipsă în modul de dezvoltare. |
| `routesLocaleLinks` | `\{ [key: string]: string \}` | `\{\}` | Mapează numele rutelor la alte nume de rute pentru a partaja aceleași fișiere de traducere. De exemplu, `\{ 'about-us': 'about' \}` înseamnă că pagina `about-us` va folosi traducerile de la pagina `about` în loc de ale sale. |
| `plural` | `PluralFunc` | `built-in pluralization (form index by count)` | Funcție personalizată de pluralizare. Primește `(key, count, params, locale, getter)` și trebuie să returneze forma de plural selectată ca string, sau `null`/`undefined` pentru a reveni la logica încorporată `defaultPlural` (astfel poți suprascrie doar unele locale). Pentru modulul Nuxt, funcția este serializată cu `.toString()` în `.nuxt/i18n.plural.mjs`. Trebuie să fie autonomă (fără importuri / scope exterior). Un string cu cale de fișier **nu** este suportat. |
| `disablePageLocales` | `boolean` | `false` | Dezactivează fișierele de traducere per pagină. Când este `true`, se încarcă doar traducerile globale (`\{locale\}.json`); fișierele specifice paginii (`pages/\{page\}/\{locale\}.json`) nu sunt generate sau încărcate. |
| `fallbackLocale` | `string` | `undefined (no fallback; returns the raw key)` | Cod global de locale pentru fallback. Când o cheie de traducere lipsește în locale-ul activ, modulul o caută în acest locale înainte de a returna cheia însăși. |

## Payload-uri și cache

Cum ajung traducerile la browser. [Performanță](/guides/performance) explică ce schimbă acestea la runtime.

| Opțiune | Tip | Implicit | Descriere |
| --- | --- | --- | --- |
| `serverTranslationPreload` | `boolean` | `false` | Preîncarcă traducerile paginii index în middleware-ul global Nitro (doar server, configurație privată). |
| `apiBaseUrl` | `string` | `'_locales'` | Segmentul de cale URL de bază pentru ruta API a traducerilor (utilizat în preluarea datelor SSR/SSG). Poate fi setat și prin variabila de mediu `NUXT_I18N_APP_BASE_URL`. |
| `apiBaseClientHost` | `string` | `undefined` | Suprascrie host-ul folosit pentru cererile de preluare a traducerilor pe client. Util când clientul accesează serverul printr-un hostname diferit de cel pe care îl vede Nuxt. Poate fi setat și prin variabila de mediu `NUXT_I18N_APP_BASE_CLIENT_HOST`. |
| `apiBaseServerHost` | `string` | `undefined` | Suprascrie host-ul folosit pentru cererile de preluare a traducerilor pe server. Util în configurații cu container-e/microservicii, unde serverul se accesează pe sine printr-un hostname intern. Poate fi setat și prin variabila de mediu `NUXT_I18N_APP_BASE_SERVER_HOST`. |
| `translationPayloads` | `TranslationPayloadOptions` | — | Controlează modul în care sunt emise payload-urile de traducere (Node: `public/<apiBaseUrl>`; Edge: Nitro `serverAssets`). - **Node**: `serverAssets` înseamnă SSR local prin `readFile` sub `public/` (fără Rollup `raw:`). - **Edge**: `serverAssets` înregistrează Nitro `serverAssets` (`assets:i18n`); nu forțează o copie publică. Păstrează valorile implicite pentru configurația obișnuită all-in-one. Pentru cataloage mari Edge, preferă `mode: 'source'`. Pentru implementările cu CDN, dezactivează ieșirile locale și setează `apiBaseClientHost` / `apiBaseServerHost`. |
| `translationPayloads.mode` | `'premerged' \| 'source'` | `'premerged'` | Strategia de payload de traducere. - `premerged`: matricea `\{page\}/\{locale\}/data.json` la build (implicit) - `source`: fișiere sursă compacte îmbinate la runtime (de preferat pe Edge / cataloage mari) |
| `translationPayloads.serverAssets` | `boolean` | `true` | Payload-uri SSR locale: Node citește `public/<apiBaseUrl>` (forțează copia publică); Edge încorporează prin Nitro `serverAssets`. - **Node**: fără Nitro `serverAssets` (evită Rollup `raw:`). SSR citește   `public/<apiBaseUrl\|publicDir>` ca `\{page\}/\{locale\}/data.json`; când este `true`,   o copie publică este forțată chiar dacă `publicAssets` este `false`. - **Edge** (`nitro.node === false`): Nitro `serverAssets` (`assets:i18n`) cu același   layout ca `mode`. **Nu** forțează o copie publică — setează `publicAssets: true` pentru CDN. |
| `translationPayloads.serverHandler` | `boolean` | `true` | Înregistrează ruta server încorporată la `/\{apiBaseUrl\}/:page/:locale/data.json`. Dezactivează atunci când payload-urile de traducere sunt servite de un host/CDN extern. |
| `translationPayloads.publicAssets` | `boolean` | `true in premerged mode, false in source mode` | Copiază payload-urile în output-ul public Nitro. Premerged → `\{page\}/\{locale\}/data.json` sub `apiBaseUrl`; source → arbore compact. Pe Node, acest arbore este și sursa SSR atunci când `serverAssets` forțează o copie publică. |
| `translationPayloads.prerenderRoutes` | `boolean` | `false` | Activează prerender-ul Nitro pentru `/\{apiBaseUrl\}/.../data.json`. De obicei redundant când `publicAssets` din premerged deja a scris aceste fișiere. |
| `translationPayloads.publicDir` | `string` | — | Folder de output public relativ la rădăcina publică Nitro. Implicit `apiBaseUrl` (`_locales`). Astfel fișierele statice se potrivesc cu URL-urile de preluare de pe client (`/\{apiBaseUrl\}/\{page\}/\{locale\}/data.json`). |
| `translationPayloads.warnFileCount` | `number` | `500` | Avertizează în timpul build-ului când numărul de fișiere de payload generate depășește acest prag. |
| `translationPayloads.warnSizeBytes` | `number` | `10485760 (10 MB)` | Avertizează în timpul build-ului când dimensiunea totală a payload-urilor generate depășește acest prag în bytes. |

## SEO

Etichete meta generate pentru fiecare pagină localizată.

| Opțiune | Tip | Implicit | Descriere |
| --- | --- | --- | --- |
| `meta` | `boolean` | `true` | Generează automat etichete meta SEO (`hreflang`, `canonical`, `og:url`, `og:locale`). |
| `metaBaseUrl` | `string` | `undefined` | URL de bază pentru etichetele meta SEO (canonical, og:url, hreflang). - Un șir concret cu URL (de exemplu, `'https://example.com'`) — folosit ca atare (prioritate maximă). - `undefined` — se face fallback la `site.url` din `nuxt-site-config` atunci când acel modul este   prezent, altfel la originea cererii curente   (`useRequestURL().origin` pe server, `window.location.origin` pe client). |
| `metaTrustForwardedHost` | `boolean` | `true` | Consideră de încredere antetul `X-Forwarded-Host` la rezolvarea URL-ului de bază pentru etichetele meta. Activează când aplicația rulează în spatele unui proxy invers (nginx, Cloudflare, AWS ALB etc.) care setează acest antet la hostname-ul real vizibil clientului. |
| `metaTrustForwardedProto` | `boolean` | `true` | Consideră de încredere antetul `X-Forwarded-Proto` la rezolvarea protocolului pentru etichetele meta. Activează când aplicația rulează în spatele unui proxy care termină TLS, astfel încât URL-urile canonice să folosească `https://` chiar dacă aplicația ascultă pe HTTP. |
| `canonicalQueryWhitelist` | `string[]` | `['page', 'sort', 'filter', 'search', 'q', 'query', 'tag']` | Lista numelor de parametri de interogare păstrate în etichetele meta canonical și `og:url`. Parametrii care nu se află în această listă sunt eliminați din URL-ul canonic. |

## Detectare și redirecționări

Alegerea unui locale pentru un vizitator care nu a ales unul.

| Opțiune | Tip | Implicit | Descriere |
| --- | --- | --- | --- |
| `redirects` | `boolean` | `true` | Activează redirecționările automate bazate pe locale. Când este `true`, vizitatorii sunt redirecționați către locale-ul lor preferat (detectat din cookie, antetul `Accept-Language` sau cel implicit) la prima vizită. |
| `autoDetectLanguage` | `boolean` | `true` | Detectează automat limba preferată a utilizatorului din antetul HTTP `Accept-Language`. Utilizat împreună cu `autoDetectPath` pentru a decide când are loc detectarea. |
| `autoDetectPath` | `string` | `'/'` | Unde pot rula redirecționările bazate pe cookie / Accept-Language (când `redirects` este activat). - `'/'` — doar pe `/` (link-urile profunde în locale-ul implicit rămân accesibile; implicit) - `'no_prefix'` — doar căile fără prefix de locale - `'*'` — fiecare cale, inclusiv rescrierea unui prefix explicit de locale   (de exemplu, `/fr/about` → `/de/about` când cookie-ul preferă `de`) - orice alt șir — potrivire exactă a căii (de exemplu, `'/welcome'`) Curățarea strategiei prefixate (de exemplu, `/en` → `/` sub `prefix_except_default`) nu este blocată. |

## Înregistrare

Părți ale modulului pe care le poți dezactiva.

| Opțiune | Tip | Implicit | Descriere |
| --- | --- | --- | --- |
| `define` | `boolean` | `true` | Înregistrează plugin-ul de macro `defineI18nRoute()`, permițând apeluri `defineI18nRoute()` per pagină. |
| `plugin` | `boolean` | `true` | Înregistrează plugin-ul i18n de bază care oferă `$t()`, `$tc()`, `$getLocale()`, `$switchLocale()` și alți helper-i de runtime. |
| `hooks` | `boolean` | `true` | Înregistrează plugin-ul de hook-uri i18n care oferă hook-urile la nivel de aplicație `i18n:register` și `i18n:beforeLocaleSwitch` / `i18n:afterLocaleSwitch`. |
| `components` | `boolean` | `true` | Înregistrează componentele i18n încorporate (`<i18n-link>`, `<i18n-switcher>`, `<i18n-t>`, `<i18n-group>`). Setează la `false` pentru a dezactiva înregistrarea automată a componentelor (de exemplu, dacă nu le folosești și vrei să reduci amprenta modulului). |
| `types` | `boolean` | `true` | Generează declarații de tip TypeScript pentru `useI18n`, `$t` și helper-ii înrudiți pe baza cheilor de traducere din fișierele tale de locale implicit. |
| `debug` | `boolean` | `false` | Activează logarea de debug detaliată pentru detectarea locale-ului, generarea rutelor și încărcarea traducerilor. |

## Altele

| Opțiune | Tip | Implicit | Descriere |
| --- | --- | --- | --- |
| `hreflangBaseLanguage` | `boolean` | `false` | Emite, de asemenea, un `hreflang` cu limbă simplă derivat din `iso`-ul fiecărui locale (de exemplu, `es-ES` → și `es`). Primul locale regional din `locales` revendică tag-ul simplu pentru acea limbă. Codul de rutare `code` nu este folosit niciodată — doar `iso \|\| code`. |
| `vueDevtools` | `boolean` | `true` | Înregistrează inspectorul Vue DevTools și timeline-ul în dev (extensia de browser). Separat de tab-ul personalizat Nuxt DevTools. |
| `localizedRouteNamePrefix` | `string` | `'localized-'` | Prefix adăugat înaintea numelor rutelor localizate (de exemplu, `'localized-index'`). Utilizat intern pentru a distinge rutele originale de variantele de locale generate. |
| `routeDisableMeta` | `Record<string, boolean \| string[]>` | — | Dezactivarea etichetelor meta per rută, extrasă din apelurile `defineI18nRoute()`. Mapează o cale de rută la `true` (dezactivează toate meta) sau un array de coduri de locale pentru care meta ar trebui dezactivate. |
| `missingWarn` | `boolean` | `true` | Afișează avertismente în consolă atunci când o cheie de traducere lipsește. |
| `hmr` | `boolean` | `true` | Activează Hot Module Replacement pentru fișierele de traducere în dezvoltare. Când este `true`, modificările fișierelor JSON de traducere declanșează o reîncărcare automată fără reîmprospătarea completă a paginii. |
| `cacheMaxSize` | `number` | `0` | Numărul maxim de intrări în cache-ul de traduceri din memorie. `0` înseamnă fără limită. |
| `cacheTtl` | `number` | `0` | Timpul de viață (în secunde) pentru intrările din cache-ul de traduceri. `0` înseamnă că intrările nu expiră niciodată. |
| `numberFormats` | `Record<string, Record<string, Intl.NumberFormatOptions>>` | — | Formate numerice cu nume per locale (compatibile Vue I18n). Permite apeluri de tip `$tn(1000, 'currency')`. |
| `datetimeFormats` | `Record<string, Record<string, Intl.DateTimeFormatOptions>>` | — | Formate datetime cu nume per locale (compatibile Vue I18n `datetimeFormats`). Permite apeluri de tip `$td(date, 'short')`. |
| `httpCacheDuration` | `number` | `31536000` | `Cache-Control` HTTP max-age (secunde) pentru `/\{apiBaseUrl\}/:page/:locale/data.json`. Se aplică integral doar cât timp `dateBuild` invalidează URL-ul (`?v=...`), ceea ce este comportamentul implicit: răspunsul este atunci `public, max-age=…, immutable` și este sigur pentru browsere și CDN-uri. - `dateBuild: 0`/`''` — URL-ul este stabil, așa că această durată *nu* este onorată; răspunsul   devine `public, max-age=0, must-revalidate`. Un `max-age` mare pe un URL invariabil   fixează primul payload pe care browserul l-a văzut vreodată. - `0` — nu setează deloc `Cache-Control` (util în depanare locală) - Nu se aplică în dezvoltare (`import.meta.dev`) pentru ca HMR să nu fie contracarat de cache-ul browserului - Atinge doar răspunsurile servite prin Nitro. Payload-urile copiate în `public/` și servite   de platforma de hosting preiau antetele acelei platforme — vezi ghidul de performanță. Analog cu `httpCacheDuration` experimental din `@nuxtjs/i18n` (v10.2.0), dar ca antet de răspuns explicit și nu ca `maxAge` de `defineCachedEventHandler` din Nitro. |
| `dateBuild` | `string \| number` | — | Valoarea folosită pentru invalidarea cache-ului la cererile de traducere (`?v=...`). Când nu este furnizată, modulul face fallback la `Date.now()` (nedeterminist). Pentru implementări reproductibile/rolling, setează la o valoare stabilă (de exemplu, un git SHA sau un număr de build). |
| `experimental` | `Record<string, unknown>` | — | Grup pentru opțiuni experimentale/instabile. Conținutul se poate schimba sau poate fi eliminat fără notificare între versiunile minore. |
