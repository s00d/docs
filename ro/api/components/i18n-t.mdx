# 🌍 Componenta `<i18n-t>`

Componenta `<i18n-t>` din `Nuxt I18n Micro` este o componentă de traducere flexibilă care suportă inserarea de conținut dinamic prin slot-uri. Îți permite să interpolezi traduceri cu componente Vue personalizate sau conținut HTML, activând scenarii avansate de localizare.

## ⚙️ Props

| Prop | Tip | Implicit | Descriere |
| --- | --- | --- | --- |
| `keypath` **\*** | `string` | — | Cheia de traducere de randat. |
| `plural` | `number \| string` | — | Numărul care selectează forma de plural. Setează-l pentru a folosi `$tc` în loc de `$t`. |
| `tag` | `string` | `'span'` | Elementul de randat. |
| `params` | `Record<string, string \| number \| boolean>` | `() => (\{\})` | Valori de interpolare substituite în traducere. |
| `defaultValue` | `string` | `''` | Randat în loc de componentă când `hideIfEmpty` suprimă o traducere goală. |
| `html` | `boolean` | `false` | Randează traducerea ca HTML în loc de text. Doar pentru conținut pe care îl controlezi. |
| `hideIfEmpty` | `boolean` | `false` | Nu randează nimic când traducerea se rezolvă la un șir gol. |
| `customPluralRule` | `PluralFunc` | `null` | Regulă de plural doar pentru acest element, care o suprascrie pe cea configurată. |
| `number` | `number \| string` | — | Formatează valoarea cu `$tn` și o transmite traducerii ca `\{number\}`. |
| `date` | `Date \| string \| number` | — | Formatează valoarea cu `$td` și o transmite traducerii ca `\{date\}`. |
| `relativeDate` | `Date \| string \| number` | — | Formatează valoarea cu `$tdr` și o transmite traducerii ca `\{relativeDate\}`. |

**\*** obligatoriu.

{/* /generated:component:i18n-t */}

Doar unul dintre `plural`, `number`, `date` și `relativeDate` se aplică la un moment dat; când sunt
setate mai multe, câștigă primul din lista respectivă.

### Exemple pentru fiecare prop

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

## 🛠️ Exemple de utilizare

### Utilizare de bază

```vue
<i18n-t keypath="feedback.text" />
```

Aceasta randează traducerea pentru `feedback.text` în interiorul unui tag `<span>`.

### Utilizarea slot-urilor pentru conținut dinamic

Componenta `<i18n-t>` suportă utilizarea slot-urilor pentru a insera dinamic componente Vue sau alt conținut în părți specifice ale traducerii.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

În acest exemplu, placeholder-ul `\{link\}` din șirul de traducere `feedback.text` este înlocuit cu componenta `<nuxt-link>`, care conține la rândul său o altă componentă de traducere.

### Pluralizare

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

Aceasta aplică automat regulile de pluralizare pe baza valorii `itemCount`.

## 🚀 Funcții suplimentare

### Slot implicit

Dacă nu este furnizat niciun slot specific, traducerea poate fi personalizată prin slot-ul implicit, care oferă întregul șir tradus:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### Randare condiționată

Nu randează nimic dacă șirul de traducere este gol, folosind prop-ul `hideIfEmpty`.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### Regulă de pluralizare personalizată

Folosește o funcție personalizată pentru a gestiona pluralizarea.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### Exemplu avansat cu slot-uri

Utilizează slot-urile pentru a personaliza modul în care este randat conținutul traducerii.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
