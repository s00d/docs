# 🌍 Componenta `<i18n-link>`

Componenta `<i18n-link>` din `Nuxt I18n Micro` este o componentă versatilă de link care localizează automat rutele pe baza locale-ului curent. Aceasta acționează ca un wrapper în jurul componentei `<NuxtLink>`, oferind caracteristici suplimentare precum stilizarea link-urilor active și suport pentru link-uri externe.

## ⚙️ Props

{/* generated:component:i18n-link — do not edit; run `pnpm run docs:generate` */}

| Prop | Tip | Implicit | Descriere |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | Ruta țintă. Localizată automat; un URL extern este trecut nemodificat. |
| `activeStyle` | `Partial<CSSStyleValue>` | — | Stil inline aplicat atunci când link-ul indică ruta curentă. |

**\*** obligatoriu.

### Sloturi

| Slot | Legături | Descriere |
| --- | --- | --- |
| `default` | — | Conținutul link-ului. |

{/* /generated:component:i18n-link */}

`to` acceptă orice acceptă `NuxtLink`: o cale, o rută cu nume sau un obiect de rută rezolvat.
Un URL absolut este detectat și randat ca un simplu `<a target="_blank" rel="noopener noreferrer">`
în loc să fie localizat.

## 🛠️ Exemple de utilizare

### Utilizare de bază

```vue
<i18n-link to="/about">About Us</i18n-link>
```

Acest exemplu creează un link către pagina `/about`, localizat în locale-ul curent.

### Stilizarea link-ului activ cu stiluri inline

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

Link-ul va avea text îngroșat atunci când utilizatorul se află pe pagina `/about`, permițându-ți să stilizezi link-ul activ direct cu stiluri inline.

### Gestionarea link-urilor externe

Componenta detectează automat link-urile externe și adaugă atributele necesare pentru securitate.

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

Acest link va deschide `https://example.com` într-o filă nouă cu `rel="noopener noreferrer"` aplicat.

## 🎨 Stiluri

Componenta folosește acum stiluri inline pentru starea activă în loc de o clasă. Poți personaliza aceste stiluri folosind prop-ul `activeStyle`.

### Stiluri active implicite

- **Font Weight**: `bold`
- **Color**: Moștenește culoarea implicită a browserului (dacă nu este specificată o `color` în `activeStyle`).

Le poți suprascrie furnizând stiluri personalizate prin prop-ul `activeStyle`.

### Stiluri active personalizate

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

În acest exemplu, link-ul va fi îngroșat și verde când este activ.

## 🚀 Funcționalități suplimentare

### Slot pentru conținut personalizat

Poți transmite conținut personalizat în interiorul link-ului folosind sloturi, făcând componenta flexibilă pentru diferite cazuri de utilizare.

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### Îmbunătățiri de accesibilitate

Componenta suportă `aria-label` și alte atribute de accesibilitate pentru a asigura o experiență mai accesibilă.

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
