# 🌍 Componenta `<i18n-group>`

Componenta `<i18n-group>` din Nuxt I18n Micro oferă o modalitate convenabilă de a grupa traducerile sub un prefix comun, reducând repetarea și îmbunătățind organizarea codului.

## ⚙️ Props

{/* generated:component:i18n-group — do not edit; run `pnpm run docs:generate` */}

| Prop | Tip | Implicit | Descriere |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | Prefixul de cheie față de care este rezolvată fiecare căutare din interiorul slot-ului. |
| `groupClass` | `string` | `''` | Clasă suplimentară pe elementul wrapper. |

**\*** obligatoriu.

### Slots

| Slot | Bindings | Descriere |
| --- | --- | --- |
| `default` | `prefix`, `t` | Primește `prefix` și o funcție `t` limitată la acesta. |

## 🎯 Slots

Slot-ul implicit primește `prefix` și o funcție `t` limitată la acesta, astfel încât cheile din interior
să fie scrise relativ la prefix:

```vue
<i18n-group prefix="checkout">
  <template #default="{ t }">
    <h2>{{ t('title') }}</h2>
    <p>{{ t('summary', { count: 3 }) }}</p>
  </template>
</i18n-group>
```

## 🛠️ Exemplu de utilizare

### Utilizare de bază

```vue
<template>
  <i18n-group prefix="product.details">
    <template #default="{ t }">
      <h1>{{ t('title') }}</h1>
      <p>{{ t('description') }}</p>
      <div class="price">{{ t('price', { value: 99.99 }) }}</div>
    </template>
  </i18n-group>
</template>
```

Fișierul de traducere:

```json
{
  "product": {
    "details": {
      "title": "Premium Product",
      "description": "This is a premium product",
      "price": "Price: ${value}"
    }
  }
}
```

### Cu clasă personalizată

```vue
<template>
  <i18n-group prefix="user.profile" group-class="profile-section">
    <template #default="{ t }">
      <div class="user-info">
        <h2>{{ t('title') }}</h2>
        <p>{{ t('bio') }}</p>
        <div class="stats">
          <span>{{ t('stats.followers') }}</span>
          <span>{{ t('stats.following') }}</span>
        </div>
      </div>
    </template>
  </i18n-group>
</template>
```

Fișierul de traducere:

```json
{
  "user": {
    "profile": {
      "title": "User Profile",
      "bio": "User biography goes here",
      "stats": {
        "followers": "Followers: {count}",
        "following": "Following: {count}"
      }
    }
  }
}
```

### Cu conținut dinamic

```vue
<template>
  <i18n-group prefix="blog.post">
    <template #default="{ t }">
      <article>
        <h1>{{ t('title') }}</h1>
        <div class="meta">
          {{ t('meta.author', { name: author }) }} |
          {{ t('meta.date', { date: publishDate }) }}
        </div>
        <div v-for="(section, index) in sections" :key="index">
          <h2>{{ t(`sections.${index}.title`) }}</h2>
          <p>{{ t(`sections.${index}.content`) }}</p>
        </div>
      </article>
    </template>
  </i18n-group>
</template>

<script setup>
const author = 'John Doe'
const publishDate = '2024-01-01'
const sections = ['intro', 'main', 'conclusion']
</script>
```

## 🎨 Stilizare

Componenta încapsulează conținutul într-un div cu clasa `i18n-group` și orice clase suplimentare specificate în prop-ul `groupClass`:

```css
.i18n-group {
  /* Your base styles */
}

.profile-section {
  /* Additional styles for profile sections */
}
```

## 🚀 Bune practici

1. **Prefixe consistente**: Folosește prefixe consistente și logice care reflectă structura aplicației tale

```vue
<i18n-group prefix="features.pricing">
<i18n-group prefix="features.security">
```

2. **Organizare modulară**: Grupează traducerile înrudite sub prefixe semnificative

```vue
<i18n-group prefix="checkout.payment">
<i18n-group prefix="checkout.shipping">
```

3. **Componente reutilizabile**: Creează componente reutilizabile cu propriile grupuri de traduceri

```vue
<!-- UserProfile.vue -->
<i18n-group prefix="user.profile">

<!-- UserSettings.vue -->
<i18n-group prefix="user.settings">
```

4. **Grupuri imbricate**: Evită imbricarea profundă a grupurilor pentru a menține claritatea

```vue
<!-- Good -->
<i18n-group prefix="shop.product">

<!-- Avoid -->
<i18n-group prefix="shop.category.product.details.specs">
```
