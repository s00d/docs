# 🌍 Componenta `<i18n-switcher>`

Componenta `<i18n-switcher>` din `Nuxt I18n Micro` oferă o interfață dropdown ușor de utilizat pentru a comuta între diferite locale în aplicația ta. Această componentă este foarte personalizabilă, permițând o integrare fluidă cu designul și layout-ul aplicației.

Locale-urile cu `disabled: true` sunt **omise** din dropdown (rămân disponibile prin `$getLocales()` pentru tag-urile SEO / head). Doar locale-urile comutabile primesc `NuxtLink` + `hreflang`.

Toate părțile sunt nestilizate implicit: prop-urile `custom*Style` iau obiecte de stil inline, iar
slot-urile de mai jos înlocuiesc markup-ul complet când stilizarea nu este suficientă.

## 🛠️ Exemple de utilizare

### Utilizare de bază

```vue
<template>
  <i18n-switcher />
</template>
```

Aceasta randează un switcher de locale cu stilizare și comportament implicite.

### Etichete personalizate și stiluri inline

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Acest exemplu demonstrează un switcher de locale complet personalizat cu etichete personalizate și stiluri inline.

## 🔌 Slots

Fiecare parte vizuală a switcher-ului poate fi înlocuită. Slot-urile sunt listate cu tabelul de props
de mai sus; fiecare acceptă conținut din template:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Slot-urile al căror nume se termină cu `-item`, `-link-content` sau începe cu `before-item` primesc
obiectul `locale` corespunzător.

## 🎨 Prezentare generală a stilurilor

Componenta `<i18n-switcher>` vine cu stiluri de bază definite folosind stiluri inline care pot fi ușor suprascrise transmițând stiluri personalizate prin props. Iată o scurtă prezentare a stilizării implicite:

- **Wrapper**: Controlează poziționarea dropdown-ului.
- **Button**: Stilează butonul de comutare al dropdown-ului.
- **Dropdown**: Stilează lista dropdown.
- **Items**: Stilează fiecare item din listă.
- **Links**: Stilează link-urile din fiecare item.
- **Icon**: Stilează pictograma indicatorului dropdown-ului.

Poți personaliza aceste stiluri transmițând stiluri personalizate prin props-urile respective, asigurându-te că switcher-ul de locale se integrează fluid în UI-ul aplicației tale.
