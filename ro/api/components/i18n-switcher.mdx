# 🌍 Componenta `<i18n-switcher>`

Componenta `<i18n-switcher>` din `Nuxt I18n Micro` oferă o interfață dropdown prietenoasă pentru comutarea între diferitele locale din aplicația ta. Această componentă este foarte personalizabilă, permițând integrarea fluidă cu designul și layout-ul aplicației tale.

Localele cu `disabled: true` sunt **omise** din dropdown (rămân disponibile prin `$getLocales()` pentru etichetele SEO / head). Doar localele comutabile primesc `NuxtLink` + `hreflang`.

Fiecare parte este nestilizată implicit: prop-urile `custom*Style` primesc obiecte de stil inline, iar
sloturile de mai jos înlocuiesc marcajul complet atunci când stilizarea nu este suficientă.

## 🛠️ Exemple de utilizare

### Utilizare de bază

```vue
<template>
  <i18n-switcher />
</template>
```

Aceasta randează un switcher de locale cu stilizare și comportament implicit.

### Etichete personalizate și stiluri inline

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Acest exemplu demonstrează un switcher de locale complet personalizat, cu etichete personalizate și stiluri inline.

## 🔌 Sloturi

Fiecare parte vizuală a switcher-ului poate fi înlocuită. Sloturile sunt listate în tabelul prop-urilor de mai sus; fiecare primește conținut de template:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Sloturile al căror nume se termină cu `-item`, `-link-content` sau începe cu `before-item` primesc obiectul `locale` căruia îi aparțin.

## 🎨 Prezentare generală a stilurilor

Componenta `<i18n-switcher>` vine cu stiluri de bază definite folosind stiluri inline care pot fi suprascrise cu ușurință prin transmiterea de stiluri personalizate prin prop-uri. Iată o scurtă prezentare a stilizării implicite:

- **Wrapper**: Controlează poziționarea dropdown-ului.
- **Buton**: Stilizează butonul de comutare al dropdown-ului.
- **Dropdown**: Stilizează lista dropdown.
- **Elemente**: Stilizează fiecare element din listă.
- **Link-uri**: Stilizează link-urile din interiorul fiecărui element.
- **Iconiță**: Stilizează iconița indicatorului de dropdown.

Poți personaliza aceste stiluri transmițând stiluri personalizate prin prop-urile corespunzătoare, asigurându-te că switcher-ul de locale se integrează fluid în UI-ul aplicației tale.
