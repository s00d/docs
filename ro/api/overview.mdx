# Referință API

## API runtime

- [Metode](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, schimbare de locale, helpere de rutare
- [Evenimente](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Traduceri și cache](/api/cache) — `TranslationStorage`, încărcare payload, `$clearCache`

## Middleware de server

Handlerele de server folosesc middleware dedicat (nu helperele `$t` din client):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — traduce în rutele API și handlerele de server
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — citește locale-ul detectat și metadatele

Vezi ghidul complet [Server-Side Translations](/guides/server-side-translations) pentru configurare, prioritatea detectării locale și exemple.
