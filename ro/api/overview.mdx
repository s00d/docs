# Referință API

## API de runtime

- [Metode](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, schimbarea locale-ului, helper-i de rutare
- [Evenimente](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Traduceri și cache](/api/cache) — `TranslationStorage`, încărcarea payload-urilor, `$clearCache`

## Middleware server

Handler-ele de server folosesc middleware dedicat (nu helper-ii client `$t`):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — traduce în rutele API și în handler-ele de server
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — citește locale-ul detectat și metadatele

Vezi ghidul complet [Traduceri pe partea de server](/guides/server-side-translations) pentru configurare, prioritatea detectării locale-ului și exemple.

## Legate

- [Composables](/api/overview) — `useI18n`, `useI18nLocale`, `useLocaleHead`
- [Referință de configurare](/guides/configuration) — toate opțiunile modulului `i18n`
