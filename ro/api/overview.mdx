Această secțiune listează fiecare opțiune, helper, hook, composable și componentă a modulului Nuxt, plus API-ul exportat al fiecărui pachet `@i18n-micro/*`. Folosiți-o pentru a căuta o semnătură sau o valoare implicită; [Ghidul](/ro/guide/getting-started) explică modul de utilizare. Majoritatea tabelelor de aici sunt generate din codul sursă, deci corespund codului.

## Modulul Nuxt {#nuxt-module}

| Pagină | Acoperă |
| --- | --- |
| [Opțiunile modulului](/ro/api/module-options) | Fiecare cheie `i18n` din `nuxt.config`, cu tip și valoare implicită |
| [Helperi](/ro/api/methods) | `$t`, `$tc`, `$tn`, `$td`, `$localePath`, `$switchLocale`, `$defineI18nRoute` și restul |
| [Hook-uri](/ro/api/events) | Hook-ul de runtime `i18n:register` |

## Composables {#composables}

| Composable | Folosiți-l pentru |
| --- | --- |
| [`useI18n`](/ro/composables/useI18n) | Helperii în `<script setup>` |
| [`useI18nLocale`](/ro/composables/useI18nLocale) | Starea locale-ului și cookie-ul într-un plugin de detectare personalizat |
| [`useI18nHead`](/ro/composables/useI18nHead) | Suprascrieri per pagină ale tag-urilor SEO generate |
| [`useLocaleHead`](/ro/composables/useLocaleHead) | Tag-urile SEO ca obiect, pentru propriul `useHead` |

## Componente {#components}

| Componentă | Randează |
| --- | --- |
| [`<i18n-t>`](/ro/components/i18n-t) | O traducere, cu plural, formatare și interpolare prin sloturi |
| [`<i18n-link>`](/ro/components/i18n-link) | Un `NuxtLink` către ruta localizată |
| [`<i18n-switcher>`](/ro/components/i18n-switcher) | Un meniu derulant de locale-uri |
| [`<i18n-group>`](/ro/components/i18n-group) | Un bloc cu un prefix de cheie comun |

## Server {#server}

Handler-ele Nitro folosesc `useTranslationServerMiddleware` și `useLocaleServerMiddleware`, nu helperii de client. Vedeți [Rute de server](/ro/guide/server-side-translations).

## Pachete {#packages}

[API-urile pachetelor](/ro/api/packages/overview) listează exporturile fiecărui pachet `@i18n-micro/*`, câte o pagină generată pentru fiecare.
