# useI18nLocale

## Semnătură


Punct de intrare centralizat pentru gestionarea locale-ului i18n.
Combină useState('i18n-locale'), cookie-ul de locale și utilitarele de sincronizare.

## Utilizare

```vue
<script setup>
const {
  locale,
  localeCookie,
  hashCookie,
  validLocales,
  getPreferredLocale,
  getLocale,
  getLocaleWithServerFallback,
  getEffectiveLocale,
  resolveInitialLocale,
  setLocale,
  syncLocale,
  isValidLocale,
} = useI18nLocale()

// Set locale (updates state and cookies)

// Get current locale (state → cookie)

// Get valid preferred locale

</script>
```

## API

| Proprietate/Metodă                              | Tip                                 | Descriere                                                                            |
| ----------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| `locale`                                        | `Ref<string \| null>`               | Stare reactivă a locale-ului (`useState('i18n-locale')`)                             |
| `localeCookie`                                  | `Ref`                               | Cookie-ul de locale (când opțiunea `localeCookie` este activată)                     |
| `hashCookie`                                    | `Ref`                               | Cookie folosit când `hashMode` este activ                                            |
| `validLocales`                                  | `string[]`                          | Coduri de locale activate din configurația modulului (exclude `disabled`)            |
| `getLocale()`                                   | `() => string \| null`              | Locale curent: state → cookie (sau cookie hash în modul hash)                        |
| `getPreferredLocale()`                          | `() => string \| null`              | Locale din state/cookie **validat** față de `validLocales`, sau `null`               |
| `getLocaleWithServerFallback(serverLocale?)`    | `(serverLocale?) => string \| null` | State → cookie → context server opțional (folosit la init pentru `no_prefix`)        |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string`             | Locale pentru încărcarea traducerilor: modul hash preferă state; altfel citește din rută |
| `resolveInitialLocale(options)`                 | `(options) => string`               | Rezolvă locale-ul: state → `serverLocale` → rută; sincronizează state când e nevoie  |
| `setLocale(locale)`                             | `(locale: string \| null) => void`  | Setează locale și sincronizează cu cookie-urile                                      |
| `syncLocale(locale)`                            | `(locale: string \| null) => void`  | Sincronizează doar cookie-urile (fără actualizare de state)                          |
| `isValidLocale(locale)`                         | `(locale) => boolean`               | Verifică dacă string-ul este în `validLocales`                                       |

### Opțiuni `resolveInitialLocale`

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

Utilizat intern de plugin-ul principal la pornire. Plugin-urile personalizate îl pot apela când implementează fluxuri alternative de detectare.

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

Returnează locale-ul folosit pentru a încărca traducerile și a formata mesajele pentru un obiect de rută dat.

## Setare programatică a locale-ului

Preferă `useI18nLocale()` în locul utilizării directe a `useState('i18n-locale')`:

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
`setLocale()` actualizează doar preferința de locale (state + cookie). Pentru a reîncărca și contextul de traducere activ pe client, folosește `$switchLocale()` din `useNuxtApp()` sau `useI18n()`. Acest lucru contează în special pentru `no_prefix`, unde URL-ul nu se schimbă. Vezi [FAQ — schimbă locale-ul fără a schimba URL-ul](/guides/faq#-switch-locale-without-changing-the-url).
</Tip>
