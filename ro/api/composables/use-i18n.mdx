# 🛠️ Composable `useI18n`

Composable-ul `useI18n` din `Nuxt I18n Micro` oferă acces la majoritatea helperelor i18n de runtime în componente și scripturi. Metodele sunt disponibile **cu și fără prefixul `$`** (de exemplu `$t` și `t`).

Anumite injecții — `$defineI18nRoute` și `$clearCache` — sunt disponibile doar pe `useNuxtApp()`. Vezi [Methods — `$defineI18nRoute`](/api/methods#definei18nroute) și [`$clearCache`](/api/methods#clearcache).

## 📊 Ce returnează

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Fiecare helper runtime, ca un obiect simplu.

Aceleași funcții pe care pluginul le injectează ca `$t`, `$tc` și așa mai departe, disponibile atât sub
numele prefixat cu dolar, cât și sub un alias simplu — deci `const \{ t \} = useI18n()` și
`const \{ $t \} = useI18n()` funcționează amândouă.

**Returnează** — helperele descrise în [referința metodelor](/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

Fiecare helper returnat — `$t`, `$tc`, `$has`, `$switchLocale` și restul — este listat
cu semnătura sa și documentat integral în [referința Methods](/api/methods).

## API-uri disponibile doar prin `useNuxtApp()`

Acestea **nu** sunt returnate de `useI18n()`. Importă-le din `useNuxtApp()`:

| Metodă                     | Scop                                                                              |
| -------------------------- | --------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Rute de locale per pagină, restricții și traduceri inline în `script setup`       |
| `$clearCache()`            | Golește cache-ul de traduceri din memorie și chunk-urile încărcate                |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Vezi [Methods](/api/methods) pentru semnături complete și exemple.

## 🛠️ Exemple de utilizare

### Recuperarea de bază a locale-ului

Recuperează locale-ul curent al aplicației.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Traducere cu parametri

Traduce un șir cu parametri dinamici, cu o valoare implicită de rezervă.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Schimbarea locale-urilor

Comută aplicația la un locale diferit.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Generarea unei rute localizate

Generează o rută localizată la locale-ul curent sau specificat.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
