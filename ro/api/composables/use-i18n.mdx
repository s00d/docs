# 🛠️ Composable-ul `useI18n`

Composable-ul `useI18n` din `Nuxt I18n Micro` oferă acces la majoritatea helper-ilor i18n de runtime în componente și script-uri. Metodele sunt disponibile **cu și fără prefixul `$`** (de exemplu, `$t` și `t`).

Unele injecții — `$defineI18nRoute` și `$clearCache` — sunt disponibile doar pe `useNuxtApp()`. Vezi [Metode — `$defineI18nRoute`](/api/methods#definei18nroute) și [`$clearCache`](/api/methods#clearcache).

## 📊 Ce returnează

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Fiecare helper de runtime, ca un obiect simplu.

Aceleași funcții pe care plugin-ul le injectează ca `$t`, `$tc` și așa mai departe, disponibile sub
numele cu prefix dolar și sub un alias simplu. Astfel `const \{ t \} = useI18n()` și
`const \{ $t \} = useI18n()` funcționează amândouă.

**Returnează** — helper-ii descriși în [referința de metode](/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

Fiecare helper pe care îl returnează — `$t`, `$tc`, `$has`, `$switchLocale` și restul — este listat
cu semnătura sa și documentat complet în [Referința de metode](/api/methods).

## API-uri disponibile doar pe `useNuxtApp()`

Acestea **nu** sunt returnate de `useI18n()`. Importă-le din `useNuxtApp()`:

| Metodă                     | Scop                                                                        |
| -------------------------- | --------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Rute de locale per pagină, restricții și traduceri inline în `script setup` |
| `$clearCache()`            | Golește cache-ul de traduceri din memorie și chunk-urile încărcate          |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Vezi [Metode](/api/methods) pentru semnături complete și exemple.

## 🛠️ Exemple de utilizare

### Preluarea de bază a locale-ului

Preia locale-ul curent al aplicației.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Traducere cu parametri

Traduce un șir cu parametri dinamici, cu o valoare implicită de fallback.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Schimbarea locale-ului

Schimbă aplicația la un locale diferit.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Generarea unei rute localizate

Generează o rută localizată în locale-ul curent sau specificat.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
