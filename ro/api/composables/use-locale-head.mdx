# 🌍 Composable `useLocaleHead`

Composable-ul `useLocaleHead` este un utilitar din `Nuxt I18n Micro` care te ajută să gestionezi atributele SEO și meta tag-urile HTML pentru rutele localizate. Generează dinamic atributele pentru `lang` și `dir` ale documentului HTML și creează tag-uri `meta` și `link` pentru a îmbunătăți SEO-ul conținutului tău localizat.

## ⚙️ Opțiuni

{/* generated:symbol:useLocaleHead — do not edit; run `pnpm run docs:generate` */}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }, MetaObject | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

Tag-urile head SEO pentru ruta curentă: alternative `hreflang` pentru fiecare locale plus
`x-default`, un link canonic, `og:locale` și `lang`/`dir` pe `<html>`.

Este necesar doar când `meta` este dezactivat sau când valorile implicite trebuie ajustate — cu `meta: true`
modulul înregistrează aceleași tag-uri singur.

**Returnează** — un ref care conține obiectul head, gata de transmis către `useHead`

```ts
const head = useLocaleHead({ addSeoAttributes: true })
useHead(head)
```

## 🛠️ Valori returnate

Composable-ul `useLocaleHead` returnează un obiect reactiv și o funcție de actualizare pe care ar trebui să o
apelezi când datele sursă se schimbă. Ambele forme se află în semnătura de mai sus, generate din
sursă.

### `metaObject`

Payload head reactiv (html attrs, meta, link), potrivit pentru `useHead(metaObject)`.

- **Exemplu**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

Recalculează `metaObject` pe baza rutei curente, a locale-ului și a configurației. Apelează-o când inputurile
se schimbă — la o schimbare de rută, de exemplu.

- **Exemplu**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### Accesul la `link` și `meta`

Array-urile `link` și `meta` sunt accesibile prin `metaObject.value`:

- **Exemplu**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ Exemple de utilizare

### Utilizare de bază

Generează atribute head specifice locale-ului cu opțiuni implicite.

```js
const head = useLocaleHead()
```

### Personalizarea atributului identificator

Folosește un atribut identificator personalizat pentru tag-urile generate.

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### Dezactivarea atributelor SEO

Generează atribute head fără a adăuga meta tag-uri și link-uri legate de SEO.

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### Specifică un URL de bază

Setează un URL de bază personalizat pentru URL-urile canonice și alternative.

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 Funcții suplimentare

### Meta și link tag-uri SEO

Când `addSeoAttributes` este activat, composable-ul generează automat următoarele tag-uri:

- `og:locale` pentru locale-ul curent (`language_TERRITORY`, underscore). Derivat din `locale.og` sau convertit din `locale.iso` când e posibil.
- `og:url` pentru URL-ul canonic al paginii.
- `og:locale:alternate` pentru versiuni alternative de limbă.
- Link-uri `rel="canonical"` și `rel="alternate"` pentru optimizare SEO.
- Link `hreflang="x-default"` care indică URL-ul locale-ului implicit. Aceasta indică motoarelor de căutare ce URL să arate utilizatorilor a căror limbă nu corespunde niciunui locale definit.

### Locale și direcție dinamice

Composable-ul determină dinamic atributele `lang` și `dir` pe baza locale-ului rutei curente, asigurând că documentul HTML este configurat corect pentru utilizatorii internaționali.

### Gestionarea rutelor localizate

Dacă rutele tale sunt prefixate cu coduri de locale (de ex., `/en/about`), composable-ul ajustează inteligent calea completă pentru generarea URL-urilor, asigurând că atributele SEO sunt precise și relevante.

Acest composable simplifică procesul de optimizare a aplicației tale Nuxt pentru audiențele internaționale, asigurând că site-ul tău este bine pregătit pentru motoarele de căutare globale și utilizatori.

## 🛠️ Exemplu de utilizare

Exemplul următor demonstrează cum să folosești composable-ul `useLocaleHead` într-o componentă Vue cu setările implicite:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### Explicația codului

- **Composable `useLocaleHead`**: Acest composable este apelat în secțiunea `<script setup>` și returnează un obiect care conține `htmlAttrs`, `meta` și `link`.

- **Tag `<html>`**: Atributele `lang` și `dir` pentru documentul HTML sunt determinate dinamic pe baza locale-ului curent și sunt aplicate tag-ului `<html>`.

- **Secțiunea `<head>`**:
  - **Meta tag-uri**: Sunt generate meta tag-uri legate de SEO, inclusiv `og:locale`, `og:url` și tag-urile `rel="canonical"` și `rel="alternate"` pentru a specifica versiuni alternative de limbă ale paginii.
  - **Link tag-uri**: Sunt incluse link-uri canonice, link-uri către versiuni alternative de limbă și link-ul `hreflang="x-default"` (care indică URL-ul locale-ului implicit).

- **Secțiunea `<body>`**: Conținutul principal al paginii este afișat aici. În acest exemplu, sunt folosite un header și un paragraf simplu.

### 📝 Note

1. **Atribute**: Atributele folosite (`lang`, `dir`, `rel`, `href`, `hreflang`, `property`, `content`) sunt extrase din obiectul returnat de `useLocaleHead`.

2. **Generarea tag-urilor SEO**: Dacă opțiunea `addSeoAttributes` este setată la `true`, composable-ul generează automat tag-uri SEO pentru locale-ul curent.

3. **URL de bază**: Poți seta URL-ul tău de bază personalizat folosind opțiunea `baseUrl` pentru a genera corect link-uri canonice și alternative.

Acest exemplu demonstrează cât de ușor este să integrezi `useLocaleHead` în componentele aplicației tale pentru a asigura atribute SEO corecte și pentru a îmbunătăți indexarea de către motoarele de căutare a paginilor localizate.

## 🧩 Personalizare și ciclu de viață

- `useLocaleHead` nu se abonează singur la schimbări. Returnează `metaObject` și `updateMeta`.
- Ar trebui să apelezi `updateMeta()` când inputurile se schimbă (de obicei la schimbarea rutei), de exemplu dintr-un plugin:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## Când să folosești în schimb `useI18nHead`

Când `meta: true` (implicit), preferă [`useI18nHead`](/api/composables/use-i18n-head) pentru suprascrieri **per pagină** (hreflang personalizat, `og:title` suplimentar, dezactivare parțială). Folosește `useLocaleHead` direct doar când `meta: false` sau când gestionezi `useHead` singur.
