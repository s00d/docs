# 🌍 Composable-ul `useLocaleHead`

Composable-ul `useLocaleHead` este un utilitar din `Nuxt I18n Micro` care te ajută să gestionezi atributele SEO și etichetele meta HTML pentru rutele localizate. Generează dinamic atribute pentru `lang` și `dir` ale documentului HTML și creează etichete `meta` și `link` pentru a îmbunătăți SEO-ul conținutului tău localizat.

## ⚙️ Opțiuni

{/* generated:symbol:useLocaleHead — do not edit; run `pnpm run docs:generate` */}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }, MetaObject | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

Etichetele SEO pentru head pentru ruta curentă: alternative `hreflang` pentru fiecare locale plus
`x-default`, un link canonical, `og:locale` și `lang`/`dir` pe `<html>`.

Necesar doar când `meta` este dezactivat sau valorile implicite trebuie ajustate. Cu `meta: true`
modulul înregistrează el însuși aceleași etichete.

**Returnează** — un ref care conține obiectul head, gata de transmis către `useHead`

```ts
const head = useLocaleHead({ addSeoAttributes: true })
useHead(head)
```

## 🛠️ Valori returnate

Composable-ul `useLocaleHead` returnează un obiect reactiv și o funcție de actualizare pe care ar trebui să o
apelezi când se schimbă datele sursă. Ambele forme sunt în semnătura de mai sus, generate din
sursă.

### `metaObject`

Payload reactiv pentru head (html attrs, meta, link), potrivit pentru `useHead(metaObject)`.

- **Exemplu**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

Recalculează `metaObject` pe baza rutei curente, locale-ului și configurației. Apelează-l când intrările
se schimbă. De exemplu, la o schimbare de rută.

- **Exemplu**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### Accesarea `link` și `meta`

Array-urile `link` și `meta` sunt accesibile prin `metaObject.value`:

- **Exemplu**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ Exemple de utilizare

### Utilizare de bază

Generează atribute de head specifice locale-ului cu opțiuni implicite.

```js
const head = useLocaleHead()
```

### Personalizează atributul identificator

Folosește un atribut identificator personalizat pentru etichetele generate.

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### Dezactivează atributele SEO

Generează atribute de head fără a adăuga etichete meta și link legate de SEO.

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### Specifică un URL de bază

Setează un URL de bază personalizat pentru URL-urile canonice și alternative.

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 Funcționalități suplimentare

### Etichete meta și link SEO

Când `addSeoAttributes` este activat, composable-ul generează automat următoarele etichete:

- `og:locale` pentru locale-ul curent (`language_TERRITORY`, cu underscore). Derivat din `locale.og` sau convertit din `locale.iso` când este posibil.
- `og:url` pentru URL-ul canonic al paginii.
- `og:locale:alternate` pentru versiunile alternative de limbă.
- Link-uri `rel="canonical"` și `rel="alternate"` pentru optimizare SEO.
- Link `hreflang="x-default"` care indică URL-ul locale-ului implicit. Acesta le spune motoarelor de căutare ce URL să afișeze utilizatorilor a căror limbă nu se potrivește cu niciunul dintre localele definite.

### Locale și direcție dinamice

Composable-ul determină dinamic atributele `lang` și `dir` pe baza locale-ului rutei curente, asigurându-se că documentul tău HTML este configurat corect pentru utilizatorii internaționali.

### Gestionarea rutelor localizate

Dacă rutele tale sunt prefixate cu coduri de locale (de exemplu, `/en/about`), composable-ul ajustează inteligent calea completă pentru generarea URL-urilor, asigurându-se că atributele SEO sunt precise și relevante.

Acest composable simplifică procesul de optimizare a aplicației tale Nuxt pentru audiențe internaționale, asigurându-se că site-ul tău este bine pregătit pentru motoarele de căutare globale și utilizatori.

## 🛠️ Exemplu de utilizare

Următorul exemplu demonstrează cum să folosești composable-ul `useLocaleHead` într-o componentă Vue cu setările implicite:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### Explicația codului

- **Composable-ul `useLocaleHead`**: Acest composable este apelat în secțiunea `<script setup>` și returnează un obiect care conține `htmlAttrs`, `meta` și `link`.

- **Eticheta `<html>`**: Atributele `lang` și `dir` pentru documentul HTML sunt determinate dinamic pe baza locale-ului curent și sunt aplicate etichetei `<html>`.

- **Secțiunea `<head>`**:
  - **Etichete meta**: Sunt generate etichete meta legate de SEO, inclusiv `og:locale`, `og:url` și etichete `rel="canonical"` și `rel="alternate"` pentru a specifica versiunile alternative de limbă ale paginii.
  - **Etichete link**: Sunt incluse link-uri canonice, link-uri către versiunile alternative de limbă și link-ul `hreflang="x-default"` (care indică URL-ul locale-ului implicit).

- **Secțiunea `<body>`**: Conținutul principal al paginii este afișat aici. În acest exemplu, se folosește un antet și un paragraf simple.

### 📝 Note

1. **Atribute**: Atributele folosite (`lang`, `dir`, `rel`, `href`, `hreflang`, `property`, `content`) sunt extrase din obiectul returnat de `useLocaleHead`.

2. **Generarea etichetelor SEO**: Dacă opțiunea `addSeoAttributes` este setată la `true`, composable-ul generează automat etichete SEO pentru locale-ul curent.

3. **URL de bază**: Poți seta URL-ul tău de bază personalizat folosind opțiunea `baseUrl` pentru a genera corect link-urile canonice și alternative.

Acest exemplu demonstrează cât de ușor este să integrezi `useLocaleHead` în componentele aplicației tale pentru a asigura atribute SEO corecte și pentru a îmbunătăți indexarea de către motoarele de căutare a paginilor localizate.

## 🧩 Personalizare și ciclu de viață

- `useLocaleHead` nu se abonează la modificări de la sine. Returnează `metaObject` și `updateMeta`.
- Ar trebui să apelezi `updateMeta()` când intrările se schimbă (de obicei la schimbarea rutei), de exemplu dintr-un plugin:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## Când să folosești `useI18nHead` în loc

Când `meta: true` (valoarea implicită), preferă [`useI18nHead`](/api/composables/use-i18n-head) pentru suprascrieri **per pagină** (hreflang personalizat, `og:title` suplimentar, dezactivare parțială). Folosește `useLocaleHead` direct doar când `meta: false` sau când gestionezi `useHead` singur.
