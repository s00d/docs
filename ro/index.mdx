title: "Nuxt I18n Micro"
description: "i18n mic și rapid pentru Nuxt: traduceri JSON per pagină, rute localizate la build, etichete SEO gata configurate."
---

Nuxt I18n Micro este un modul i18n ușor și performant pentru Nuxt 3 și 4, conceput pentru proiecte mari. Menține timpii de build, consumul de memorie și dimensiunea bundle-ului la un nivel scăzut în comparație cu soluțiile i18n tradiționale precum `@nuxtjs/i18n`.

Rutele localizate sunt generate la build de `@i18n-micro/route-strategy` și rezolvate la runtime de `@i18n-micro/path-strategy`, astfel încât linkurile, comutatorul de limbă, `hreflang` și redirecționările sunt toate în acord cu router-ul. Traducerile sunt doar JSON, împărțite între fișiere rădăcină comune și fișiere per pagină pe care serverul de dezvoltare le creează pentru dumneavoastră, cu HMR integrat.

<CodeGroup>

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>
