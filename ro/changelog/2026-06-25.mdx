**Data**: 2026-06-25

**Versiunea**: `v3.21.0`

![v3.21.0 release](/images/3.21.0.png)

Această versiune adaugă **`useI18nHead`** — un composable la nivel de pagină pentru suprascrieri SEO i18n peste plugin-ul încorporat `02.meta`. Personalizează `hreflang`, canonical, `og:url` și tag-urile Open Graph pentru fiecare rută, fără un plugin meta personalizat sau `meta: false`.

## Ce este nou? {#what’s-new}

### Composable-ul `useI18nHead` {#usei18nhead-composable}

Apelează `useI18nHead` în orice pagină când `meta: true` (implicit). Modulul îmbină datele tale de intrare după `useLocaleHead` la fiecare actualizare a rutei:

```vue
<script setup lang="ts">
useI18nHead(() => ({
  meta: [{ property: 'og:title', content: article.value?.title }],
  replace: {
    canonical: article.value?.canonicalUrl,
    ogUrl: article.value?.canonicalUrl,
    hreflang: localeCodes.map((locale) => ({
      rel: 'alternate',
      hreflang: locale,
      href: article.value!.locales[locale]!,
    })),
    ogAlternates: localeCodes,
  },
}))
</script>
```

Suportă obiecte statice, getteri reactivi, adăugare prin `meta` / `link`, `replace` pentru grupurile încorporate și `disable` pentru a elimina tag-urile generate automat. Vezi [`useI18nHead`](/ro/composables/useI18nHead).

### Utilitarul `mergeI18nHead` (`@i18n-micro/utils`) {#mergei18nhead-utility-@i18n-micro/utils}

Logica de îmbinare independentă de framework se află în `@i18n-micro/utils/merge-i18n-head` — folosită de plugin-ul `02.meta` și testabilă izolat. Tipurile (`I18nHeadInput`, `I18nHeadLink`, `I18nHeadMeta`) sunt exportate din `@i18n-micro/types`.

### Integrarea cu plugin-urile {#plugin-integration}

- **`02.meta`** — îmbină rezultatul `useLocaleHead` cu starea paginii din `useI18nHead` prin `useHead`
- **`01.plugin`** — resetează suprascrierile paginii la schimbarea numelui rutei prin `resetPageHead()` (stare partajată cu composable-ul)

## Cazuri de utilizare tipice {#typical-use-cases}

| Scenariu                                     | Abordare                                                       |
| -------------------------------------------- | -------------------------------------------------------------- |
| Blog/CMS cu traduceri parțiale               | `replace.hreflang` + `replace.ogAlternates` din localele API   |
| Canonical personalizat din CMS               | `replace.canonical` + `replace.ogUrl`                          |
| Doar OG pentru pagina de destinație          | `meta: [{ property: 'og:title', ... }]` — păstrează hreflang-ul modulului |
| Fără hreflang pe o pagină                    | `disable: ['hreflang', 'x-default']`                           |
| Înlocuirea unui plugin personalizat (`i18nManualHreflang`) | `useI18nHead` pe fiecare pagină de conținut + `meta: true` |

**JSON-LD** rămâne în `useHead({ script: [...] })` — `useI18nHead` nu generează date structurate.

## Modificări incompatibile {#breaking-changes}

Niciuna pentru utilizarea standard a `nuxt.config`. Noul composable și subcalea utils sunt adiționale.

## De ce contează {#why-it-matters}

- **Fără plugin meta personalizat** pentru postări CMS, știri sau ghiduri cu URL-uri per limbă
- **Un singur flux** — valorile implicite ale modulului + suprascrierile paginii într-un singur apel `useHead`
- **Type-safe** — `I18nHeadInput` pentru helperi precum `buildArticleHead(content)`
