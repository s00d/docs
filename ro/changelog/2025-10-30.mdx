**Data**: 2025-10-30

**Versiunea**: `v2.0.0`

![v2.0.0 release](/images/2.0.0.png)

Introducem HMR pe server pentru fișierele de traducere în dezvoltare. Când o traducere JSON se modifică, cache-ul serverului invalidează doar cheile afectate, iar cererile următoare primesc imediat date proaspete — fără reporniri.

## Ce este nou? {#what’s-new}

- HMR pe server pentru fișierele de traducere
- Invalidare instantanee a cache-ului per pagină/limbă
- Experiență de dezvoltare fluidă în timpul editării conținutului

## Cum funcționează {#how-it-works}

- Watcher-ul din `src/runtime/server/plugins/watcher.dev.ts` urmărește `<rootDir>/<translationDir>/**/*.json`
- Fișierele de pagină (de ex. `pages/<page>/<locale>.json`) invalidează `_locales:merged:<page>:<locale>`
- Fișierele de la nivelul rădăcină (de ex. `<locale>.json`) invalidează toate cheile combinate pentru acea limbă
- Înregistrat automat din `src/module.ts` în dezvoltare când `experimental.hmr !== false`

## Configurare {#configuration}

```ts
export default defineNuxtConfig({
  i18n: {
    experimental: { hmr: true }, // default in dev
  },
})
```
