![v1.1.0 CLI text-to-i18n demo](/images/text-to-i18n.gif)

Suntem încântați să anunțăm noua comandă `text-to-i18n` din CLI-ul Nuxt I18n Micro! Această funcționalitate puternică automatizează procesul de extragere a șirurilor de text scrise direct în cod (hardcoded) și de conversie a acestora în chei de traducere i18n. Este concepută pentru a economisi timp, a reduce erorile și a simplifica fluxul de lucru pentru localizare.

## Beneficii principale {#key-benefits}

- **Extragere automată a textului**: scanează șabloanele Vue și fișierele JavaScript și TypeScript.
- **Generare fluidă a cheilor**: creează chei de traducere structurate pe baza căilor fișierelor și a conținutului.
- **Gestionare eficientă a traducerilor**: actualizează fișierele de traducere păstrând intrările existente.

## Cum funcționează {#how-it-works}

1. **Scanarea fișierelor**: procesează fișierele din directoarele principale, precum `pages`, `components` și `plugins`.
2. **Procesarea textului**: identifică și extrage șirurile traductibile, generând chei unice.
3. **Actualizarea traducerilor**: inserează automat cheile noi în fișierele de traducere și păstrează structura lor imbricată.

## Utilizare {#usage}

```bash
i18n-micro text-to-i18n [options]
```

Exemplu:

```bash
i18n-micro text-to-i18n --translationFile locales/en.json --context auth
```

## Exemple de transformări {#example-transformations}

### Înainte {#before}

```vue
<template>
  <div>
    <h1>Welcome to our site</h1>
    <p>Please sign in to continue</p>
  </div>
</template>
```

### După {#after}

```vue
<template>
  <div>
    <h1>{{ $t('pages.home.welcome_to_our_site') }}</h1>
    <p>{{ $t('pages.home.please_sign_in') }}</p>
  </div>
</template>
```

Pentru mai multe detalii, consultați [documentația](/ro/guide/cli#turn-hardcoded-text-into-keys).
