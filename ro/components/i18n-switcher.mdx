---
title: "<i18n-switcher>"
description: "Componenta <i18n-switcher> este un meniu derulant cu locale-urile activate, fiecare cu link către pagina curentă în acel locale."
---

`<i18n-switcher>` randează un buton cu locale-ul activ și un meniu derulant cu toate locale-urile activate, inclusiv cel activ. Folosiți-o pentru un meniu de limbi gata făcut; construiți-vă propriul meniu din [`$getLocales`](/ro/api/methods#$getlocales) și [`$switchLocalePath`](/ro/api/methods#$switchlocalepath) când aveți nevoie de alt markup. Fiecare intrare are link către pagina curentă în acel locale.

## Props și sloturi {#props-and-slots}

| Prop | Tip | Implicit | Descriere |
| --- | --- | --- | --- |
| `customLabels` | `Record<string, string>` | `() => ({})` | Numele afișat per cod de locale, suprascriind `displayName` din configurația locale-ului. |
| `customWrapperStyle` | `CSSProperties` | `() => ({})` | Stil inline pentru wrapper-ul exterior. |
| `customButtonStyle` | `CSSProperties` | `() => ({})` | Stil inline pentru butonul care deschide meniul derulant. |
| `customDropdownStyle` | `CSSProperties` | `() => ({})` | Stil inline pentru panoul meniului derulant. |
| `customItemStyle` | `CSSProperties` | `() => ({})` | Stil inline pentru fiecare element din meniul derulant. |
| `customLinkStyle` | `CSSProperties` | `() => ({})` | Stil inline pentru link-ul din interiorul unui element. |
| `customActiveLinkStyle` | `CSSProperties` | `() => ({})` | Stil inline pentru link-ul locale-ului activ în prezent. |
| `customDisabledLinkStyle` | `CSSProperties` | `() => ({})` | Stil inline pentru butonul locale-ului *curent* când acesta are `disabled: true` în configurație. |
| `customIconStyle` | `CSSProperties` | `() => ({})` | Stil inline pentru pictograma săgeată de pe buton. |

### Sloturi {#slots}

| Slot | Legături | Descriere |
| --- | --- | --- |
| `before-button` | — | Conținut înaintea butonului care deschide meniul derulant. |
| `before-selected-locale` | — | Conținut înaintea etichetei locale-ului activ din interiorul butonului. |
| `after-selected-locale` | — | Conținut după eticheta locale-ului activ din interiorul butonului. |
| `before-dropdown` | — | Conținut între buton și panoul meniului derulant. |
| `before-dropdown-items` | — | Conținut în partea de sus a meniului derulant, deasupra listei de locale-uri. |
| `before-item` | `locale` | Conținut înaintea fiecărei intrări de locale. |
| `before-link-content` | `locale` | Conținut înaintea etichetei unui locale în interiorul link-ului său. |
| `after-link-content` | `locale` | Conținut după eticheta unui locale în interiorul link-ului său. |
| `after-item` | `locale` | Conținut după fiecare intrare de locale. |
| `after-dropdown-items` | — | Conținut în partea de jos a meniului derulant, sub lista de locale-uri. |
| `after-dropdown` | — | Conținut după panoul meniului derulant. |

## Comportament {#behaviour}

- Listează fiecare locale fără `disabled: true`, inclusiv cel activ.
- Fiecare intrare este un `<a>` către `$switchLocalePath(code)`. O cale se rezolvă sub `app.baseURL`; un `baseUrl` al unui locale pe alt domeniu rămâne absolut. Are `hreflang` și `lang` setate la `iso || code`, `dir` când locale-ul are unul, `aria-current="page"` pe locale-ul curent și clasa `switcher-locale-<code>`. Un clic apelează `$switchLocale(code)` și închide meniul derulant; cu o tastă modificatoare, clicul este lăsat în seama browserului.
- Lista rămâne în HTML-ul de pe server, ascunsă, astfel încât crawlerele văd link-urile. Escape sau un clic în afară o închide.
- Etichetă: `customLabels[code]`, apoi `displayName` al locale-ului, apoi codul (cu un avertisment în dev).
- Stiluri: valori implicite inline minime (buton și panou albe, cu bordură, intrarea activă îngroșată și albastră). Fiecare prop `custom*Style` se aplică după stilul implicit al părții sale. Butonul are clasele `i18n-switcher-button` și `language-switcher`, wrapper-ul `i18n-switcher-wrapper`, lista `i18n-switcher-dropdown`. Pozițiile folosesc proprietăți CSS logice, deci `dir="rtl"` funcționează.

## Exemplu {#example}

```vue
<template>
  <i18n-switcher
    :custom-labels="{ en: 'English', de: 'Deutsch' }"
    :custom-button-style="{ borderRadius: '4px' }"
  >
    <template #before-link-content="{ locale }">
      <img :src="`/flags/${locale.code}.svg`" alt="" width="16" />
    </template>
  </i18n-switcher>
</template>
```
