---
title: "<i18n-t>"
description: "Componenta <i18n-t> randează o traducere, cu forme de plural, formatare de numere și date, interpolare HTML și prin sloturi."
---

`<i18n-t>` randează o traducere într-un element. Folosiți-o când o traducere are nevoie de componente în interior (un link într-o propoziție), de o formă de plural sau de un număr ori o dată formatată. Rezolvă cheia pentru ruta curentă, la fel ca `$t`.

## Props {#props}

| Prop | Tip | Implicit | Descriere |
| --- | --- | --- | --- |
| `keypath` **\*** | `string` | — | Cheia de traducere de randat. |
| `plural` | `number \| string \| null` | — | Numărul care selectează forma de plural. Setați-l pentru a folosi `$tc` în loc de `$t`. `null` înseamnă nesetat. |
| `tag` | `string` | `'span'` | Elementul de randat. |
| `params` | `Record<string, string \| number \| boolean>` | — | Valori de interpolare substituite în traducere. |
| `defaultValue` | `string` | `''` | Randat în locul componentei când `hideIfEmpty` suprimă o traducere goală. |
| `html` | `boolean` | `false` | Randează traducerea ca HTML în loc de text. Doar pentru traducerile pe care le controlați: `params` sunt escapate, traducerea nu. |
| `hideIfEmpty` | `boolean` | `false` | Nu randează nimic când traducerea se rezolvă la un șir gol. |
| `customPluralRule` | `PluralFunc` | `null` | Regulă de plural doar pentru acest element, care o suprascrie pe cea configurată. Rezultatul ei este folosit ca atare; `null` randează gol. |
| `number` | `number \| string \| null` | — | Formatează valoarea cu `$tn` și o transmite traducerii ca `{number}`, alături de `params`. |
| `date` | `Date \| string \| number \| null` | — | Formatează valoarea cu `$td` și o transmite traducerii ca `{date}`, alături de `params`. |
| `relativeDate` | `Date \| string \| number \| null` | — | Formatează valoarea cu `$tdr` și o transmite traducerii ca `{relativeDate}`, alături de `params`. |

**\*** obligatoriu.

## Reguli de randare {#rendering-rules}

Primul caz care se potrivește decide rezultatul:

1. `number` — traducerea cu `{ ...params, number: $tn(number) }`.
2. `date` — traducerea cu `{ ...params, date: $td(date) }`.
3. `relativeDate` — traducerea cu `{ ...params, relativeDate: $tdr(relativeDate) }`.
4. `plural` — forma aleasă de `$tc`, inclusiv [markerul `=0 `](/ro/api/methods#$tc), cu `{ ...params, count }`; sau `customPluralRule(keypath, count, params, locale, t)` când este setată, care citește valoarea brută, inclusiv markerul, și al cărei rezultat este folosit ca atare, `null` fiind gol.
5. Altfel, traducerea cu `params`.

`null` este considerat nesetat. În toate cazurile:

- `defaultValue` înlocuiește o cheie lipsă, în fiecare ramură.
- `hideIfEmpty` randează `defaultValue` în locul unui rezultat gol.
- `html` randează rezultatul ca HTML. `params` sunt escapate, traducerea nu; sloturile sunt ignorate.
- Un slot `default` primește `{ translation }`, iar sloturile numite sunt ignorate.
- Altfel, fiecare slot numit înlocuiește fiecare placeholder `{name}`, înaintea unui parametru cu același nume. O valoare de parametru care arată ca un placeholder rămâne text.

Rezultatul pentru `date` și `relativeDate` poartă `data-allow-mismatch="text"`, deoarece fusul orar și ceasul serverului nu sunt cele ale browserului. Setați [`timeZone`](/ro/api/module-options#timezone) pentru a randa aceeași dată calendaristică în ambele; `relativeDate` depinde de ceas, deci poate totuși să difere.

## Exemplu {#example}

```json
{
  "terms": "I accept the {link}.",
  "termsLink": "terms of use",
  "items": "no items | one item | {count} items"
}
```

```vue
<template>
  <i18n-t keypath="terms" tag="p">
    <template #link>
      <NuxtLink :to="$localePath('/terms')">{{ $t('termsLink') }}</NuxtLink>
    </template>
  </i18n-t>

  <i18n-t keypath="items" :plural="cart.length" />
</template>
```

`html` setează `innerHTML`: folosiți-l doar pentru traducerile pe care le controlați. `params` sunt escapate, deci datele utilizatorului sunt în siguranță acolo, la fel și o cheie pentru care nu s-a găsit nicio traducere.
