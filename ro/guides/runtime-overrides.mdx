# Suprascrieri i18n la runtime

Folosește acest ghid când ai nevoie ca un singur artefact de build să ruleze cu valori implicite de locale diferite per mediu (de exemplu, instanțe diferite de tenant).

## Ce poate fi suprascris la runtime

Modulul suportă suprascrieri sigure la runtime pentru:

- `defaultLocale`
- `fallbackLocale`
- `disabledLocales`

Aceste suprascrieri sunt aplicate peste configurația de build din `.nuxt/i18n.strategy.mjs` și `.nuxt/i18n.config.mjs`.

## Ce nu poate fi suprascris la runtime

`strategy` (`no_prefix`, `prefix`, `prefix_except_default`, `prefix_and_default`) este o preocupare de build deoarece afectează comportamentul rutelor generate.

Dacă transmiți o suprascriere de strategie la runtime, aceasta este ignorată și se emite un avertisment.

## Suprascrieri bazate pe RuntimeConfig

Furnizează valori de runtime sub `runtimeConfig.public.i18nRuntime`:

```ts
export default defineNuxtConfig({
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

## Suprascrieri prin variabile de mediu

Poți configura suprascrierile și prin variabile de mediu:

- `NUXT_I18N_DEFAULT_LOCALE`
- `NUXT_I18N_FALLBACK_LOCALE`
- `NUXT_I18N_DISABLED_LOCALES` (separate prin virgulă, de exemplu, `fr,it`)

Sunt suportate și alias-uri de fallback:

- `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES`

## Reguli de validare

La runtime, modulul validează suprascrierile pentru a evita o stare defectă:

- Nu poți dezactiva toate localele.
- `defaultLocale` trebuie să indice un locale activat.
- `fallbackLocale` trebuie să existe în localele declarate.

Dacă o suprascriere este invalidă, modulul păstrează o valoare sigură și înregistrează un avertisment.

## Note pentru implementările multi-instanță

Această funcție de runtime este concepută pentru activarea locale-urilor și a valorilor implicite per instanță fără rebuild.

Dacă instanțele necesită strategii de URL diferite (`no_prefix` vs `prefix`), folosește build-uri separate pentru fiecare strategie.

## Locale dezactivate și payload-uri statice

`runtimeConfig.public.i18nRuntime.disabledLocales` actualizează rutarea, switcher-ul și **handler-ul** de payload Nitro. Dar Nitro servește fișierele din `public/` **înainte** de acel handler.

Dacă `translationPayloads.publicAssets` (sau copia publică forțată a SSR-ului Node) a scris deja `/_locales/\{page\}/\{locale\}/data.json`, o dezactivare la runtime nu poate ascunde acel fișier. Preferă `locale.disabled: true` la build astfel încât premerge să nu emită payload-urile statice ale acelui locale.
