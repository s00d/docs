# 🛠️ DevTools în `nuxt-i18n-micro`

## Vue DevTools (extensie de browser)

În dezvoltare, modulul poate înregistra un inspector personalizat și un timeline pentru **Vue DevTools** prin `@vue/devtools-api`. Aceasta este separată de fila Nuxt DevTools de mai jos.

| Instrument | Cel mai potrivit pentru |
|------|----------|
| **Vue DevTools** | Locale live, cache de traduceri în memorie, timeline `$t` (`debug: true`), evenimente pentru chei lipsă |
| **Fila Nuxt DevTools** | Editarea fișierelor JSON pe disc, prezentare generală a configurării, import/export |

Plugin-ul vue-devtools este înregistrat doar în timpul `nuxt dev` (nu în build-urile de producție). Starea bridge-ului doar pentru dev, din plugin-ul principal, este eliminată prin dead-code elimination `import.meta.dev`.

Dezactivează integrarea de browser, păstrând fila Nuxt:

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

Evenimentele detaliate de timeline pentru `$t` necesită `debug: true`.

## 📖 Ce este Nuxt DevTools?

DevTools este un asistent puternic de dezvoltare, integrat perfect în modulul `nuxt-i18n-micro`. Oferă o interfață intuitivă pentru gestionarea sarcinilor de localizare și traducere, făcând fluxul tău de lucru mai rapid și mai eficient. Conceput pentru dezvoltatori care apreciază confortul, Nuxt DevTools acoperă distanța dintre codare și gestionarea la runtime.

## 🌟 Caracteristici cheie ale DevTools în `nuxt-i18n-micro`

### 1. **Gestionarea locale-urilor**

Răsfoiește, selectează și gestionează cu ușurință locale-urile în aplicația ta. Fie că lucrezi cu o singură limbă sau cu mai multe, DevTools oferă un hub centralizat pentru gestionarea tuturor setărilor de localizare.

### 2. **Editarea traducerilor**

Editează fișierele de traducere direct printr-un editor JSON integrat. Astfel se elimină nevoia de instrumente externe, permițând actualizări și modificări în timp real, fără a-ți întrerupe fluxul de lucru.

### 3. **Import și export de fișiere**

Simplifică procesul de gestionare a fișierelor de traducere:

- **Export**: Salvează traducerile ca fișier JSON pentru backup-uri sau utilizare externă.
- **Import**: Încarcă fișiere de traducere actualizate în proiect pentru a menține conținutul la zi.

### 4. **Previzualizări în timp real**

Vezi imediat modificările în mediul de dezvoltare. Această funcționalitate asigură că traducerile și configurările sunt corecte înainte de a fi puse în producție.

### 5. **Integrare Nuxt perfectă**

DevTools funcționează nativ cu `nuxt-i18n-micro`, îmbunătățindu-i capabilitățile fără a necesita configurare suplimentară. Se adaptează nevoilor tale de localizare, menținând în același timp structura modulară și flexibilă a Nuxt.

## 🛠️ De ce să folosești DevTools?

Nuxt DevTools este o completare indispensabilă pentru proiectele care necesită localizare. Îi ajută pe dezvoltatori prin:

- **Economisire de timp**: Automatizează sarcinile repetitive precum gestionarea fișierelor și validarea formatului.
- **Reducerea erorilor**: Oferă un mediu sigur și intuitiv pentru editarea traducerilor.
- **Îmbunătățirea colaborării**: Permite non-dezvoltatorilor să gestioneze cu ușurință traducerile.
- **Simplificarea fluxurilor de lucru**: Consolidează mai multe sarcini de localizare într-o singură interfață.

## 🚀 Preia controlul asupra localizării

Cu Nuxt DevTools integrat în `nuxt-i18n-micro`, gestionarea aplicațiilor multilingve devine simplă și eficientă. Fie că reglezi fin traducerile sau adaugi locale-uri noi, DevTools îți oferă instrumentele necesare pentru a livra experiențe rafinate și prietenoase cu utilizatorul.
