# 🛠️ DevTools în `nuxt-i18n-micro`

## Vue DevTools (extensia de browser)

În dezvoltare, modulul poate înregistra un inspector personalizat și un timeline **Vue DevTools** prin `@vue/devtools-api`. Aceasta este separată de tab-ul Nuxt DevTools de mai jos.

| Unealtă | Cel mai bun pentru |
|---------|--------------------|
| **Vue DevTools** | Locale live, cache de traduceri în memorie, timeline `$t` (`debug: true`), evenimente de chei lipsă |
| **Tab Nuxt DevTools** | Editarea fișierelor JSON pe disc, prezentare generală a configurației, import/export |

Plugin-ul vue-devtools este înregistrat doar în timpul `nuxt dev` (nu în build-urile de producție). Starea de bridge doar pentru dev din plugin-ul principal este eliminată prin dead-code elimination `import.meta.dev`.

Dezactivează integrarea cu browserul păstrând tab-ul Nuxt:

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

Evenimentele detaliate din timeline-ul `$t` necesită `debug: true`.

## 📖 Ce este Nuxt DevTools?

DevTools este un asistent de dezvoltare puternic, integrat fluid în modulul `nuxt-i18n-micro`. Oferă o interfață intuitivă pentru gestionarea sarcinilor de localizare și traducere, făcând fluxul tău de lucru mai rapid și mai eficient. Conceput pentru dezvoltatorii care apreciază confortul, Nuxt DevTools acoperă distanța dintre codare și managementul la runtime.

## 🌟 Caracteristici cheie ale DevTools în `nuxt-i18n-micro`

### 1. **Gestionarea locale-urilor**

Navighează, selectează și gestionează cu ușurință localele din aplicația ta. Fie că lucrezi cu o singură limbă sau cu mai multe, DevTools oferă un hub centralizat pentru gestionarea tuturor setărilor de localizare.

### 2. **Editarea traducerilor**

Editează fișierele de traducere direct printr-un editor JSON integrat. Aceasta elimină nevoia de unelte externe, permițând actualizări și schimbări în timp real fără a-ți întrerupe fluxul de lucru.

### 3. **Import și export de fișiere**

Simplifică procesul de gestionare a fișierelor de traducere:

- **Export**: Salvează traducerile ca fișier JSON pentru backup sau utilizare externă.
- **Import**: Încarcă fișierele de traducere actualizate în proiect pentru a menține conținutul la zi.

### 4. **Previzualizări în timp real**

Vezi modificările imediat în mediul de dezvoltare. Această caracteristică asigură că traducerile și configurațiile sunt precise înainte de a fi puse în producție.

### 5. **Integrare Nuxt fluidă**

DevTools funcționează nativ cu `nuxt-i18n-micro`, îmbunătățindu-i capacitățile fără a necesita configurare suplimentară. Se adaptează nevoilor tale de localizare, menținând în același timp structura modulară și flexibilă a Nuxt.

## 🛠️ De ce să folosești DevTools?

Nuxt DevTools este o completare indispensabilă pentru proiectele care necesită localizare. Ajută dezvoltatorii prin:

- **Economisirea timpului**: Automatizează sarcinile repetitive precum gestionarea fișierelor și validarea formatului.
- **Reducerea erorilor**: Oferă un mediu sigur și intuitiv pentru editarea traducerilor.
- **Îmbunătățirea colaborării**: Le permite persoanelor non-dezvoltatoare să gestioneze traducerile cu ușurință.
- **Simplificarea fluxurilor de lucru**: Consolidează mai multe sarcini de localizare într-o singură interfață.

## 🚀 Preia controlul localizării

Cu Nuxt DevTools integrat în `nuxt-i18n-micro`, gestionarea aplicațiilor multilingve devine directă și eficientă. Fie că reglezi fin traducerile sau adaugi locale noi, DevTools te echipează cu uneltele necesare pentru a oferi experiențe finisate și prietenoase pentru utilizator.
