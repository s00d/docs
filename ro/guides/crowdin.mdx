# 🌐 Ghid de integrare Crowdin

## 📖 Introducere

Integrarea Crowdin în proiectul tău simplifică procesul de localizare și traducere, făcând mai ușoară gestionarea traducerilor în mai multe limbi și platforme. Acest ghid oferă un tur pas cu pas al configurării Crowdin cu proiectul tău, incluzând configurarea, încărcarea surselor și descărcarea traducerilor.

## 🔧 Instalare și configurare

Pentru a începe cu Crowdin, va trebui să instalezi Crowdin CLI global pe mașina ta și să îl inițializezi în directorul proiectului tău.

### 📦 Instalarea Crowdin CLI

Mai întâi, instalează Crowdin CLI global folosind npm:

```bash
npm install -g @crowdin/cli
```

### 🛠 Inițializarea Crowdin în proiectul tău

Inițializează Crowdin în proiectul tău executând:

```bash
crowdin init
```

Această comandă te va ghida prin procesul de configurare, incluzând setarea ID-ului proiectului, a token-ului API și a altor detalii de configurare.

## 🗂️ Ghid de configurare

### 📄 Fișierul de configurare Crowdin (`crowdin.yml`)

Fișierul de configurare Crowdin (`crowdin.yml`) definește cum sunt mapate fișierele tale sursă și unde ar trebui plasate traducerile. Mai jos este un exemplu de configurare:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Parametri cheie de configurare

- **`project_id`**: ID-ul proiectului tău Crowdin. Acesta identifică proiectul în cadrul Crowdin unde sunt gestionate traducerile.
- **`api_token`**: Token-ul API folosit pentru autentificare. Asigură-te că acest token are permisiunile corecte pentru a încărca și descărca traduceri.
- **`base_path`**: Specifică directorul de bază pentru fișierele sursă. În acest exemplu, traducerile sunt stocate în directorul `./locales`.
- **`base_url`**: URL-ul de bază pentru API-ul Crowdin.
- **`preserve_hierarchy`**: Când este setat la `true`, Crowdin va menține structura de foldere a fișierelor tale sursă în proiect.

### 📂 Configurarea fișierelor

Secțiunea `files` mapează fișierele tale sursă la căile unde vor fi stocate traducerile. De exemplu:

- **Cale sursă**: Definește locația fișierelor originale de traducere.
- **Cale de traducere**: Specifică unde vor fi stocate fișierele traduse în Crowdin. Placeholder-i precum `%two_letters_code%` sunt folosiți pentru a seta dinamic codul limbii în căile fișierelor.

## ⬆️ Încărcarea fișierelor sursă în Crowdin

Odată ce configurarea Crowdin este pregătită, poți încărca fișierele sursă folosind următoarea comandă:

```bash
crowdin upload sources
```

Această comandă încarcă toate fișierele sursă specificate în configurația ta în Crowdin, făcându-le disponibile pentru traducere.

## ⬇️ Descărcarea traducerilor din Crowdin

După ce traducerile sunt finalizate sau actualizate în Crowdin, le poți descărca în proiectul tău folosind:

```bash
crowdin download
```

Această comandă preia cele mai recente traduceri din Crowdin și le salvează conform căilor specificate în fișierul tău de configurare.

## ⚙️ Bune practici

### 🔑 Denumire consistentă a cheilor

Asigură-te că cheile de traducere sunt consistente în toate fișierele pentru a evita confuzia și duplicarea.

### 🧹 Întreținere regulată

Verifică și curăță periodic cheile de traducere neutilizate, pentru a-ți menține fișierele organizate și ușor de gestionat.

### 🛠 Automatizează încărcările și descărcările

Integrează comenzile Crowdin CLI în pipeline-ul tău CI/CD pentru a automatiza încărcarea fișierelor sursă și descărcarea traducerilor, asigurându-te că traducerile tale sunt mereu actualizate.

Urmând acest ghid, vei putea integra Crowdin în proiectul tău fără probleme, asigurând o abordare eficientă și organizată în gestionarea eforturilor tale de internaționalizare.
