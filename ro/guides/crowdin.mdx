# 🌐 Ghid de integrare Crowdin

## 📖 Introducere

Integrarea Crowdin în proiectul tău simplifică procesul de localizare și traducere, făcând mai ușoară gestionarea traducerilor în mai multe limbi și platforme. Acest ghid oferă un tur pas cu pas pentru configurarea Crowdin cu proiectul tău, inclusiv configurarea, încărcarea surselor și descărcarea traducerilor.

## 🔧 Instalare și configurare

Pentru a începe cu Crowdin, va trebui să instalezi Crowdin CLI global pe mașina ta și să îl inițializezi în directorul proiectului.

### 📦 Instalarea Crowdin CLI

Mai întâi, instalează Crowdin CLI global folosind npm:

```bash
npm install -g @crowdin/cli
```

### 🛠 Inițializarea Crowdin în proiectul tău

Inițializează Crowdin în proiectul tău rulând:

```bash
crowdin init
```

Această comandă te va ghida prin procesul de configurare, inclusiv setarea ID-ului de proiect, a token-ului API și a altor detalii de configurare.

## 🗂️ Ghid de configurare

### 📄 Fișierul de configurare Crowdin (`crowdin.yml`)

Fișierul de configurare Crowdin (`crowdin.yml`) definește modul în care fișierele tale sursă sunt mapate și unde ar trebui plasate traducerile. Mai jos este un exemplu de configurare:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Parametri cheie de configurare

- **`project_id`**: ID-ul proiectului tău Crowdin. Acesta identifică proiectul din Crowdin în care sunt gestionate traducerile.
- **`api_token`**: Token-ul API folosit pentru autentificare. Asigură-te că acest token are permisiunile corecte pentru încărcarea și descărcarea traducerilor.
- **`base_path`**: Specifică directorul de bază pentru fișierele sursă. În acest exemplu, traducerile sunt stocate în directorul `./locales`.
- **`base_url`**: URL-ul de bază pentru API-ul Crowdin.
- **`preserve_hierarchy`**: Când este setat la `true`, Crowdin va menține structura de foldere a fișierelor tale sursă în proiect.

### 📂 Configurația fișierelor

Secțiunea `files` mapează fișierele tale sursă la căile unde vor fi stocate traducerile. De exemplu:

- **Cale sursă**: Definește locația fișierelor originale de traducere.
- **Cale de traducere**: Specifică unde vor fi stocate fișierele traduse în Crowdin. Placeholder-e precum `%two_letters_code%` sunt folosite pentru a seta dinamic codul limbii în căile fișierelor.

## ⬆️ Încărcarea fișierelor sursă pe Crowdin

Odată ce configurația Crowdin este setată, poți încărca fișierele sursă folosind următoarea comandă:

```bash
crowdin upload sources
```

Această comandă încarcă toate fișierele sursă specificate în configurația ta pe Crowdin, făcându-le disponibile pentru traducere.

## ⬇️ Descărcarea traducerilor de pe Crowdin

După ce traducerile sunt finalizate sau actualizate în Crowdin, le poți descărca în proiectul tău folosind:

```bash
crowdin download
```

Această comandă preia cele mai recente traduceri de pe Crowdin și le salvează conform căilor specificate în fișierul tău de configurare.

## ⚙️ Bune practici

### 🔑 Denumire consistentă a cheilor

Asigură-te că cheile de traducere sunt consistente în toate fișierele pentru a evita confuzia și duplicarea.

### 🧹 Mentenanță regulată

Revizuiește și curăță periodic cheile de traducere neutilizate pentru a-ți menține fișierele organizate și gestionabile.

### 🛠 Automatizează încărcările și descărcările

Integrează comenzile Crowdin CLI în pipeline-ul tău CI/CD pentru a automatiza încărcarea fișierelor sursă și descărcarea traducerilor, asigurându-te că traducerile tale sunt întotdeauna actualizate.

Urmând acest ghid, vei putea integra fără probleme Crowdin în proiectul tău, asigurând o abordare eficientă și organizată pentru gestionarea eforturilor tale de internaționalizare.
