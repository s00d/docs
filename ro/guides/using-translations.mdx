# Utilizarea traducerilor în componente

Odată ce modulul este instalat și configurat, poți afișa traducerile apelând `$t('your_key')` în template-urile și script-urile tale Vue.

## 1. Fișiere de traducere la nivel root și specifice paginii

1. Traducerile **la nivel root** se află direct sub folderul `/locales` (de exemplu, `/locales/en.json`, `/locales/fr.json`). La momentul build-ului, sunt îmbinate automat în fiecare fișier specific paginii, făcându-le disponibile pe toate paginile.
2. Traducerile **specifice paginii** se află sub `/locales/pages/...`, corespunzând structurii folderului tău de pagini Nuxt:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. Utilizare în template cu `$t`

În fișierele tale `.vue`, poți folosi direct `$t` în template:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
`$t` poate returna **obiecte** dacă cheia indică un nod JSON imbricat (de exemplu, `$t('header')` → `\{ title: "Hi" \}`). În template-uri, acest lucru se randează ca `[object Object]`. Folosește `$ts` când ai nevoie de un string garantat sau furnizează o cheie mai specifică precum `$t('header.title')`. Vezi [Referința API — $t vs $ts](/api/methods#t) pentru detalii.
</Tip>

## 3. Schimbarea locale-ului curent

Pentru a schimba limbile în aplicația ta, poți prelua `$locale` din `useI18n()` și îi poți atribui un nou cod:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. Chei imbricate și placeholder-i

- **Cheile imbricate** folosesc notația cu punct, de exemplu `nested.key.deeper`.
- **Placeholder-ii** îți permit să inserezi valori dinamice:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. Sfaturi și bune practici

- **Chei conflictuale**: Dacă un fișier specific paginii conține aceeași cheie ca un fișier la nivel root, versiunea specifică paginii are prioritate (traducerile root sunt îmbinate ca bază la momentul build-ului).
- **Dezactivarea fișierelor de pagină**: Dacă preferi să nu folosești traduceri specifice paginii, poți seta `disablePageLocales: true` în configurarea ta Nuxt. Astfel, se vor folosi doar fișierele `/locales/*.json`.
- **Fără import-uri directe**: Nu este nevoie să faci `import \{ useI18n \} from 'nuxt-i18n-micro'`; funcția de auto-injecție a modulului se ocupă de asta.

Asta e tot! Cu acești pași, poți **prelua rapid traduceri** din fișiere JSON de la nivel root sau specifice paginii și le poți **afișa** în aplicația ta Nuxt folosind `$t`.

## Resurse suplimentare

Pentru a explora funcționalități mai avansate, asigură-te că verifici:

1. **Componenta `<i18n-t>`**  
   Componenta `<i18n-t>` este o alternativă puternică la `$t`, utilă mai ales în situații care implică elemente imbricate, utilizarea avansată a placeholder-ilor și structuri de traducere mai complexe.

- **Documentație**: [i18n-t](/api/components/i18n-t)

2. **Composable-ul `useI18n`**  
   Composable-ul `useI18n` oferă un set complet de funcții și proprietăți reactive pentru gestionarea traducerilor, schimbarea locale-ului, formatare și multe altele.

- **Documentație**: [useI18n](/api/composables/use-i18n)
