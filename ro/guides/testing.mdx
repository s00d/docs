# 🧪 Testarea modulului `Nuxt I18n Micro`

## 📖 Introducere în testare

Testarea modulului `Nuxt I18n Micro` este crucială pentru a te asigura că funcționalitățile de localizare ale aplicației tale funcționează conform așteptărilor. Această documentație te va ghida prin configurarea mediului de testare, crearea de configurări mock pentru vitest și scrierea testelor pentru componentele tale. Pentru un exemplu practic, poți consulta [proiectul exemplu de pe GitHub](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/test-utils/example).

Vezi [Testarea strategiilor de rutare](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/testing-strategies.md) pentru a înțelege cum rulează acest repository propriile sale suite — proiectele Vitest `unit` / `integration` / `e2e`, fișierele per-strategie (`test/strategies-*.test.ts`) și regresiile de generare.

## 🛠️ Configurarea mediului de testare

### 1. Instalează `@i18n-micro/test-utils`

Mai întâi, trebuie să instalezi utilitățile de testare pentru `Nuxt I18n Micro`. Acest pachet oferă instrumentele necesare pentru a mock-ui și a testa configurările tale i18n.

```bash
npm install @i18n-micro/test-utils --save-dev
```

### 2. Creează un fișier de configurare mock

Apoi, creează un fișier pentru a configura configurația mock i18n. Acest fișier va fi folosit pentru a mock-ui funcțiile și utilitățile i18n în timpul testelor tale.

```typescript
// tests/unit-setup.ts

import { mockNuxtImport } from '@nuxt/test-utils/runtime'
import { vi } from 'vitest'
import { i18nUtils } from '@i18n-micro/test-utils'

export function createFakeI18n() {
  return {
    $getLocale: vi.fn(i18nUtils.getLocale),
    $t: vi.fn(i18nUtils.t),
    $tc: vi.fn(i18nUtils.tc),
    $setLocale: vi.fn(i18nUtils.setLocale),
    $getLocaleName: vi.fn(i18nUtils.getLocaleName),
    $setLocaleName: vi.fn(i18nUtils.setLocaleName),
    $getLocales: vi.fn(i18nUtils.getLocales),
    $setLocales: vi.fn(i18nUtils.setLocales),
    $defaultLocale: vi.fn(i18nUtils.defaultLocale),
    $setDefaultLocale: vi.fn(i18nUtils.setDefaultLocale),
    $getRouteName: vi.fn(i18nUtils.getRouteName),
    $settRouteName: vi.fn(i18nUtils.settRouteName),
    $ts: vi.fn(i18nUtils.ts),
    $tn: vi.fn(i18nUtils.tn),
    $td: vi.fn(i18nUtils.td),
    $has: vi.fn(i18nUtils.has),
    $resolveTranslations: vi.fn(i18nUtils.resolveTranslations),
    $setTranslation: vi.fn(i18nUtils.setTranslation),
    $mergeTranslations: vi.fn(i18nUtils.mergeTranslations),
    $switchLocaleRoute: vi.fn(i18nUtils.switchLocaleRoute),
    $switchLocalePath: vi.fn(i18nUtils.switchLocalePath),
    $switchLocale: vi.fn(i18nUtils.switchLocale),
    $switchRoute: vi.fn(i18nUtils.switchRoute),
    $localeRoute: vi.fn(i18nUtils.localeRoute),
    $localePath: vi.fn(i18nUtils.localePath),
    $setI18nRouteParams: vi.fn(i18nUtils.setI18nRouteParams),
  }
}

mockNuxtImport<() => ReturnType<typeof createFakeI18n>>('useI18n', () => vi.fn(() => createFakeI18n()))

export const setTranslationsFromJson = i18nUtils.setTranslationsFromJson
```

### 3. Configurează Vitest

Acum, configurează Vitest pentru a folosi fișierul de configurare mock și pentru a pregăti mediul de testare.

```typescript
// vitest.config.ts

import { defineVitestConfig } from '@nuxt/test-utils/config'

export default defineVitestConfig({
  test: {
    watch: false,
    setupFiles: ['./tests/unit-setup.ts'],
    include: ['./**/*.spec.ts'],
  },
})
```

## 🧪 Scrierea testelor

### Componentă-exemplu

Iată un exemplu de componentă simplă care folosește composable-ul `useI18n` pentru a traduce mesajele.

```vue
<script setup lang="ts">
const { $t } = useI18n()

const props = defineProps({
  message: {
    type: String,
    default: null,
  },
})

// Test to see that $t works in script setup as well as the template
const message = props.message || $t('defaultMessage')
</script>

<template>
  <div>
    <p>Test from component: {{ $t('welcome') }}</p>
    <p data-testid="message">Test message from props: {{ message }}</p>
  </div>
</template>
```

### Fișier de test

Acum, să scriem un test pentru această componentă.

```typescript
// tests/unit/example.spec.ts

import { describe, it, expect, beforeEach } from 'vitest'
import { mount } from '@vue/test-utils'
import ExampleComponent from '@/components/ExampleComponent.vue'
import fs from 'fs'
import path from 'path'
import { setTranslationsFromJson } from './unit-setup'

describe('ExampleComponent', () => {
  beforeEach(async () => {
    const fileContent = fs.readFileSync(path.join(__dirname, '../../locales/en-GB.json')).toString()
    await setTranslationsFromJson('en', JSON.parse(fileContent))
  })

  it('renders the welcome message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.text()).toContain('Test from component: Welcome')
  })

  it('renders the default message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Default Message')
  })

  it('renders the custom message correctly', () => {
    const wrapper = mount(ExampleComponent, {
      props: {
        message: 'Custom Message',
      },
    })
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Custom Message')
  })
})
```

## 📝 Bune practici pentru testare

- **🔧 Mock-uiește funcțiile i18n:** Mock-uiește întotdeauna funcțiile i18n folosind `@i18n-micro/test-utils` pentru a asigura rezultate de test consistente și previzibile.
- **⚙️ Folosește Vitest pentru teste unitare:** Vitest este un framework de testare puternic pentru aplicațiile Vue. Folosește-l pentru a scrie teste unitare pentru componentele tale.
- **📚 Documentează-ți testele:** Documentează clar scopul și rezultatele așteptate ale fiecărui test. Acest lucru va ajuta la menținerea clarității și va face mai ușor pentru alții (sau pentru tine, în viitor) să înțeleagă testele.

## 📊 Metode utilitare i18n

Mai jos este un tabel care descrie toate metodele utilitare oferite de `@i18n-micro/test-utils`.

| Metodă                                          | Descriere                                                                                                                                |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `t(key, params, defaultValue)`                  | Traduce o cheie cu parametri opționali și o valoare implicită.                                                                             |
| `tc(key, params, defaultValue)`                 | Traduce o cheie cu suport pentru pluralizare.                                                                                              |
| `setTranslationsFromJson(locale, translations)` | Încarcă traducerile dintr-un obiect JSON pentru un locale specific.                                                                        |
| `getLocale()`                                   | Returnează locale-ul curent.                                                                                                              |
| `setLocale(val)`                                | Setează locale-ul curent.                                                                                                                 |
| `getLocaleName()`                               | Returnează numele locale-ului curent.                                                                                                     |
| `setLocaleName(val)`                            | Setează numele locale-ului curent.                                                                                                        |
| `getLocales()`                                  | Returnează lista de locale-uri disponibile.                                                                                               |
| `setLocales(val)`                               | Setează lista de locale-uri disponibile.                                                                                                  |
| `defaultLocale()`                               | Returnează locale-ul implicit.                                                                                                            |
| `setDefaultLocale(val)`                         | Setează locale-ul implicit.                                                                                                               |
| `getRouteName()`                                | Returnează numele rutei curente.                                                                                                          |
| `settRouteName(val)`                            | Setează numele rutei curente.                                                                                                             |
| `ts(key, params, defaultValue)`                 | Traduce o cheie și returnează rezultatul ca string.                                                                                        |
| `tn(value, options?)`                           | Formatează un număr cu `Intl.NumberFormatOptions` inline. Formatele denumite necesită configurare de modul și nu sunt disponibile în acest helper standalone. |
| `td(value, options?)`                           | Formatează o dată cu `Intl.DateTimeFormatOptions` inline. Formatele denumite necesită configurare de modul și nu sunt disponibile în acest helper standalone. |
| `has(key)`                                      | Verifică dacă o cheie de traducere există.                                                                                                |
| `resolveTranslations()`                         | Returnează arborele de traduceri activ pentru locale-ul și ruta curente.                                                                  |
| `setTranslation(key, value)`                    | Înlocuiește valoarea de la `key` în dicționarul activ (înlocuire, nu îmbinare).                                                            |
| `mergeTranslations(newTranslations)`            | Îmbină traducerile în locale-ul activ la runtime.                                                                                          |

Urmând acești pași, poți testa eficient modulul `Nuxt I18n Micro` și te poți asigura că funcționalitățile de localizare ale aplicației tale funcționează conform așteptărilor.
