# 📚 Exemple și utilizare Nuxt I18n Micro

Această secțiune oferă diverse exemple care demonstrează cum să folosești `Nuxt I18n Micro` în aplicația ta Nuxt.js. Vei vedea cum să schimbi locale-uri, cum să folosești componentele `<i18n-link>`, `<i18n-switcher>` și `<i18n-t>` și cum să gestionezi dinamic cheile de traducere.

## 🛠️ Configurare de bază

Iată o configurare de bază pentru a începe cu `Nuxt I18n Micro`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Schimbarea locale-ului

### Schimbarea locale-urilor programatic

Acest exemplu demonstrează cum să schimbi locale-uri programatic folosind butoane:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Exemplu JSON pentru schimbarea locale-ului

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### Utilizarea componentei `<i18n-switcher>`

Componenta `<i18n-switcher>` oferă un dropdown pentru schimbarea locale-ului, cu etichete personalizabile:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

  </div>
</template>

<script setup>

## 📝 Randarea cheilor dinamice din fișierele de traducere

În unele scenarii, ai putea dori să iterezi peste chei dinamice stocate în fișierele tale de traducere și să le randezi valorile condițional. Exemplul de mai jos demonstrează cum să realizezi acest lucru folosind `Nuxt I18n Micro`.

### Exemplu: Randarea cheilor dinamice

Acest exemplu preia un array de chei dintr-o cale specifică de traducere (în acest caz, `dynamic`) și iterează peste ele. Fiecare cheie este verificată pentru existență folosind `$has` înainte de a-i randa valoarea cu `$t`.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Exemplu de fișier de traducere (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Exemplu: Randarea cheilor dinamice dintr-un obiect

În acest exemplu, gestionăm un obiect stocat în fișierul tău de traducere. Preluăm și iterăm peste cheile obiectului, randând dinamic atât numele cheilor, cât și valorile lor asociate.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Exemplu de fișier de traducere (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 Utilizarea `<i18n-t>` pentru traduceri cu slot-uri și interpolare

Componenta `<i18n-t>` este utilă pentru randarea traducerilor cu conținut dinamic și tag-uri HTML:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### Exemplu JSON pentru `<i18n-t>`

```json
{
  "greeting": "Welcome to the page"
}
```

### Cu interpolare

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### Exemplu JSON pentru interpolare

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 Utilizarea `$tc` pentru pluralizare

Funcția `$tc` din `Nuxt I18n Micro` gestionează pluralizarea pe baza numărului și a setărilor locale-ului. Este utilă pentru ajustarea dinamică a mesajelor care implică numere, precum articole, notificări sau alte entități care pot varia ca număr.

### Exemplu: Utilizarea `$tc` pentru pluralizare

În exemplul următor, afișăm un mesaj care indică numărul de mere folosind `$tc`. Cheia de traducere gestionează mai multe forme de plural pe baza numărului furnizat.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### Exemplu JSON pentru pluralizare

Iată cum poți defini traducerea în fișierul tău JSON pentru a gestiona diferite forme de plural:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Explicație

- **`$tc('apples', 0)`**: Returnează prima formă, folosită când numărul este zero (`"no apples"`).
- **`$tc('apples', 1)`**: Returnează a doua formă, folosită când numărul este unu (`"one apple"`).
- **`$tc('apples', 10)`**: Returnează a treia formă cu valoarea numărului, folosită când numărul este doi sau mai mulți (`"10 apples"`).

### Exemplu suplimentar cu pluralizare mai complexă

Dacă aplicația ta trebuie să gestioneze reguli de pluralizare mai complexe (de exemplu, cazuri specifice pentru zero, unu, doi, puțini, mulți, alții), poți extinde șirurile de traducere în consecință:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: Ar putea fi configurat să returneze `"two apples"`.
- **`$tc('apples', 3)`**: Ar putea returna `"a few apples"`, în funcție de regulile definite pentru număr.

## 🌐 Utilizarea `$tn` pentru formatarea numerelor

Funcția `$tn` formatează numere conform locale-ului curent folosind API-ul `Intl.NumberFormat`. Este utilă pentru afișarea numerelor într-un mod care corespunde setărilor regionale ale utilizatorului, precum valuta, procentele sau alte formate numerice.

### Exemplu: Utilizarea `$tn` pentru formatarea numerelor

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ Utilizarea `$td` pentru formatarea datei și orei

Funcția `$td` formatează date și ore conform locale-ului curent folosind API-ul `Intl.DateTimeFormat`. Este utilă pentru afișarea datelor și orelor în formate familiare utilizatorului pe baza setărilor sale de locale.

### Exemplu: Utilizarea `$td` pentru formatarea datei și orei

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ Utilizarea `$tdr` pentru formatarea datei relative

Funcția `$tdr` formatează datele ca timpi relativi (de exemplu, „acum 5 minute”, „acum 2 zile”) conform locale-ului curent folosind API-ul `Intl.RelativeTimeFormat`. Este utilă pentru afișarea diferențelor de timp raportate la data și ora curente.

### Exemplu: Utilizarea `$tdr` pentru formatarea datei relative

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
