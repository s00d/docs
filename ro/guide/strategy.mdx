---
title: "Strategii de rutare"
description: "Cele patru strategii de URL, rutele localizate pe care le generează și cum să creați un link către o pagină în orice locale."
---

Opțiunea `strategy` decide dacă un locale apare în URL și pentru care locale-uri. Alegeți-o o singură dată, înainte de a publica URL-uri: schimbarea ei ulterioară modifică fiecare link. Modulul generează apoi rutele localizate la build, iar `$localePath`, `<i18n-link>` și selectorul de limbă le citesc.

## Cele patru strategii {#the-four-strategies}

![The /about page in en (default) and de under each strategy; the same URLs are listed in the text below](/images/diagrams/strategies.svg)

**Tip** `Strategies` · **Implicit** `'prefix_except_default'`

Strategia de rutare a URL-urilor pentru prefixele de locale.

- `'no_prefix'` — niciun locale în URL; locale-ul este stocat într-un cookie.
- `'prefix_except_default'` — prefix pentru toate locale-urile, cu excepția celui implicit.
- `'prefix'` — întotdeauna prefix, inclusiv pentru locale-ul implicit.
- `'prefix_and_default'` — ca `prefix`, dar locale-ul implicit este accesibil și fără prefix.

URL-uri pentru o pagină `about` cu `defaultLocale: 'en'` și locale-urile `en`, `de`:

| Strategie | Engleză | Germană | Nu este servit |
| --- | --- | --- | --- |
| `prefix_except_default` (implicit) | `/about` | `/de/about` | `/en` și `/en/about` dau 404 |
| `prefix` | `/en/about` | `/de/about` | `/about` redirecționează către un URL cu prefix |
| `prefix_and_default` | `/about` și `/en/about` | `/de/about` | — |
| `no_prefix` | `/about` | `/about` | locale-ul nu este în URL |

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix',
  },
})
```

Strategia este fixată la build: o suprascriere a ei la runtime este ignorată, cu un avertisment ([Suprascrieri la runtime](/ro/guide/runtime-overrides)).

## Pe care să o alegeți {#which-one-to-choose}

- **`prefix_except_default`**: majoritatea site-urilor. URL-urile existente fără prefix continuă să funcționeze pentru limba implicită.
- **`prefix`**: toate limbile sunt egale; `/` duce întotdeauna la o pagină principală cu prefix.
- **`prefix_and_default`**: aveți nevoie ca atât `/en/...`, cât și URL-urile fără prefix să funcționeze, de exemplu în timpul trecerii de la unele la celelalte. URL-urile fără prefix nu sunt niciodată redirecționate.
- **`no_prefix`**: aplicații din spatele unei autentificări sau un singur URL per pagină pentru toate limbile. Locale-ul provine dintr-un cookie sau din `?locale=`. Motoarele de căutare văd o singură limbă per URL, deci nu sunt emise alternative `hreflang`.

Modul în care este ales locale-ul pentru un URL și momentul în care un vizitator este redirecționat sunt descrise în [Detectarea locale-ului](/ro/guide/locale-detection).

## Rute generate {#generated-routes}

La build, fiecare pagină primește înregistrările de rută de care are nevoie strategia sa. Fiecare înregistrare conține `meta.i18n = { name, locales }`: pagina pe care o afișează și locale-urile pe care le servește. Linkurile, comutările și redirecționările sunt toate rezolvate din aceste înregistrări, astfel încât un URL oferit de modul este întotdeauna unul servit de router.

Locale-urile care partajează calea paginii partajează o singură înregistrare, `/:locale(de|fr)/about`. Un locale cu propria cale primește propria înregistrare, numită `localized-<page>-<locale>`:

```ts
// nuxt.config.ts: German has its own path for the about page
i18n: {
  globalLocaleRoutes: { about: { de: '/ueber-uns' } },
}
// prefix_except_default, locales en (default), de, fr:
// about                 /about
// localized-about       /:locale(fr)/about
// localized-about-de    /:locale(de)/ueber-uns
```

Căile personalizate, listele de locale per pagină și excluderea unei pagini de la localizare sunt descrise în [Căi localizate](/ro/guide/custom-locale-routes) și [Configurația paginii](/ro/guide/per-component-translations). Prefixul `localized-` este [`localizedRouteNamePrefix`](/ro/api/module-options#localizedroutenameprefix).

<Warning>

**Numele rutelor sunt generate** — Nu scrieți direct nume `localized-…` în `router.push({ name })`. Transmiteți numele propriu al paginii către `$localeRoute` sau `<i18n-link>`; acestea aleg înregistrarea corectă.

</Warning>

## Link către o pagină într-un locale {#linking-to-a-page-in-a-locale}

```vue
<script setup lang="ts">
const { localePath, localeRoute, switchLocalePath } = useI18n()

localePath({ name: 'about' }) // '/de/ueber-uns' while the page is German
localePath({ name: 'about' }, 'en') // '/about'
localePath('/about', 'de') // '/de/ueber-uns': a path is read as the page it shows
localeRoute({ name: 'products-id', params: { id: '42' } }, 'de') // resolved route: name, params, fullPath
switchLocalePath('fr') // the current page in French
</script>

<template>
  <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
  <NuxtLink :to="$switchLocalePath('de')">Deutsch</NuxtLink>
</template>
```

- Funcționează atât rutele cu nume, cât și căile. O cale este comparată cu rutele generate, deci este acceptată forma ei din orice locale.
- Un locale care nu servește pagina (vedeți `locales` în [Configurația paginii](/ro/guide/per-component-translations)) duce la pagina principală a acelui locale, în locul unei pagini inexistente.
- Parametrii per locale (un slug tradus) trec prin `$setI18nRouteParams`, vedeți [Căi localizate](/ro/guide/custom-locale-routes).

Semnăturile se află în [Metode](/ro/api/methods).

## Detalii despre `no_prefix` {#no_prefix-details}

- [`localeCookie`](/ro/api/module-options#localecookie) are implicit valoarea `'user-locale'` în cazul `no_prefix`, deci alegerea supraviețuiește unei reîncărcări.
- `$switchLocale('de')` încarcă dicționarul german și înlocuiește intrarea curentă din istoric; URL-ul nu se schimbă.
- Căile personalizate per locale funcționează în continuare: cu `globalLocaleRoutes: { about: { de: '/ueber-uns' } }`, cititorii germani primesc `/ueber-uns`. Acel URL este întotdeauna randat în germană, indiferent de preferința vizitatorului, iar o pagină restricționată la anumite locale este randată într-unul dintre ele. O cale partajată de mai multe locale-uri (`en` și `de` ambele pe `/page/:id`) este randată în locale-ul preferat atunci când acesta este unul dintre ele. Preferința în sine rămâne: pagina următoare revine la ea.
- [`noPrefixRedirect: true`](/ro/api/module-options#noprefixredirect) redirecționează calea originală a unei pagini cu o cale personalizată în locale-ul implicit: către calea personalizată a locale-ului vizitatorului, altfel către cea a locale-ului implicit (`/about` → `/about-us` când `en` are `/about-us`, → `/ueber-uns` cu cookie-ul `de`). Un locale fără propria cale personalizată rămâne pe calea originală și este randat acolo. Paginile cu parametri nu sunt redirecționate.

## Aplicații fără `pages/` {#apps-without-pages/}

Cu `pages: false` nu există rute de pagină de localizat. Folosiți doar fișiere de traducere la rădăcină (`disablePageLocales: true`); detectarea, cookie-ul și `$switchLocale` funcționează în continuare. Varianta `pages-false` a `test/fixtures/basic` din repository este o configurație funcțională.
