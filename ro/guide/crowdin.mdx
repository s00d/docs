[Crowdin](https://crowdin.com/) este o platformă de traducere: încărcați fișierele limbii implicite, traducătorii lucrează în Crowdin, iar dumneavoastră descărcați înapoi celelalte limbi. Modulul citește fișiere JSON simple, așa că Crowdin CLI are nevoie doar de un `crowdin.yml` care mapează corect `locales/` și `locales/pages/`. Nu se schimbă nicio setare a modulului.

## Configurarea crowdin.yml {#configure-crowdin-yml}

```yml
# crowdin.yml
project_id_env: CROWDIN_PROJECT_ID
api_token_env: CROWDIN_PERSONAL_TOKEN
base_path: ./locales
preserve_hierarchy: true

files:
  - source: /en.json
    translation: /%two_letters_code%.json
  - source: /pages/**/en.json
    translation: /pages/**/%two_letters_code%.json
```

- `en` este limba dumneavoastră implicită; fișierele ei sunt sursele.
- `project_id_env` / `api_token_env` citesc ID-ul și token-ul din variabile de mediu, astfel încât niciun secret nu ajunge în commit.
- `preserve_hierarchy: true` păstrează folderele `pages/<page>/` așa cum sunt.
- Numele fișierului tradus trebuie să fie egal cu `code`-ul limbii din `nuxt.config.ts`. `%two_letters_code%` se potrivește pentru coduri precum `de`; pentru coduri precum `pt-BR` folosiți `%locale%`, sau mapați codurile Crowdin la ale dumneavoastră cu `languages_mapping`.

## Încărcare și descărcare {#upload-and-download}

```bash
npm install -g @crowdin/cli

export CROWDIN_PROJECT_ID=123456
export CROWDIN_PERSONAL_TOKEN=...   # from Crowdin account settings

crowdin upload sources   # push locales/en.json and locales/pages/**/en.json
crowdin download         # write locales/de.json, locales/pages/**/de.json, ...
```

Rulați ambele comenzi în CI pentru a menține fișierele la zi. Fișierele descărcate ajung în repository la fel ca cele editate manual; următorul build sau următoarea reîncărcare în dezvoltare le preia.

## Înainte de încărcare {#before-uploading}

Curățați mai întâi sursele, ca traducătorii să nu lucreze pe chei moarte: [`i18n-micro clean`](/ro/api/cli#clean) elimină cheile nefolosite, iar [`i18n-micro check`](/ro/api/cli#check) raportează golurile după o descărcare. CLI-ul nu are o integrare proprie cu Crowdin: această pagină descrie metoda suportată.
