---
title: "Excluderea căilor"
description: "Țineți pagini și fișiere în afara rutării pe locale cu excludePatterns și vedeți ce căi sunt deja excluse."
---

Unele căi nu trebuie să primească niciodată un prefix de locale sau o redirecționare de locale: o zonă de administrare, un health check, un feed generat. `excludePatterns` le marchează, iar o listă încorporată acoperă deja componentele interne Nuxt și fișierele statice obișnuite. O pagină exclusă păstrează exact calea pe care ați scris-o și este în continuare randată cu `$t`.

## Excluderea unei căi {#exclude-a-path}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    excludePatterns: [
      '/admin', // /admin and everything below it
      '/preview-*', // glob over the whole path
    ],
  },
})
```

Cu această configurație, `pages/admin/index.vue` răspunde doar la `/admin`; nu există `/de/admin`, iar `/admin` nu este niciodată redirecționat către `/de/admin`.

## Sintaxa modelelor {#pattern-syntax}

Modelele sunt comparate cu calea fără `app.baseURL`:

| Model | Se potrivește cu | Nu se potrivește cu |
| --- | --- | --- |
| `'/admin'` | `/admin`, `/admin/users` | `/administrator`, `/de/admin` |
| `'/preview-*'` | `/preview-1`, `/preview-a/b` | `/de/preview-1` |
| `'/file-?'` | `/file-a` | `/file-ab` |
| `/^\/v\d+\//` | `/v2/docs` | `/docs` |

Un șir fără `*` sau `?` se potrivește cu calea și cu segmentele întregi de sub ea. Cu `*` (orice secvență de caractere, inclusiv bare oblice) sau `?` (un singur caracter), trebuie să se potrivească cu întreaga cale. Începeți întotdeauna șirurile cu `/`.

## Ce este deja exclus {#what-is-excluded-already}

Acestea nu primesc niciodată rute de locale sau redirecționări, fără nicio configurație:

- `/api` și `/_nuxt`, precum și tot ce se află sub ele;
- ruta traducerilor, implicit `/_locales` ([`apiBaseUrl`](/ro/api/module-options#apibaseurl));
- orice cale cu un segment care începe cu `__` (`/__nuxt_content`, `/en/__og-image__`);
- `/sitemap*.xml`, `/robots.txt`, `/favicon.ico`, `/apple-touch-icon*.png`, `/manifest.json`, `/sw.js`, `/workbox-*.js`;
- orice cale al cărei ultim segment se termină cu o extensie de fișier static: `xml txt ico json js css png jpg jpeg gif svg webp avif pdf wasm map mp4 webm mp3 zip gz woff woff2 ttf eot`. Slug-urile de pagină cu puncte, precum `/user/john.doe`, și căile `.html` rămân pagini.

## Ce face o excludere {#what-an-exclusion-does}

- **Rute:** nu sunt generate variante localizate; pagina este păstrată așa cum a fost scrisă.
- **Redirecționări și 404:** plugin-ul de redirecționare de pe server și middleware-ul de redirecționare de pe client ignoră calea.
- **Prerandare:** căile care se potrivesc sunt eliminate din lista de rute de prerandat.

Excluderea nu împiedică middleware-ul i18n de pe server să detecteze un locale pentru cerere și nici nu împiedică pagina să folosească traduceri. Pentru a păstra o pagină localizată, dar fără etichete SEO, folosiți `disableMeta` ([Configurația paginii](/ro/guide/per-component-translations#turn-off-seo-tags)). Pentru a păstra o pagină nelocalizată, după cale, din `nuxt.config.ts`, `globalLocaleRoutes: { '/admin': false }` ([Căi localizate](/ro/guide/custom-locale-routes#in-nuxt-config)) face același lucru pentru rutare.
