În `nuxt dev`, modulul adaugă două instrumente de depanare: o filă **i18n Micro** în Nuxt DevTools pentru răsfoirea și editarea fișierelor de traduceri și un inspector Vue DevTools pentru locale-ul activ și dicționarele încărcate. Ambele există doar în development și nu adaugă nimic la build-urile de producție. Fila Nuxt necesită doar ca Nuxt DevTools să fie activat; inspectorul Vue necesită și extensia de browser Vue DevTools.

## Fila Nuxt DevTools {#nuxt-devtools-tab}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  devtools: { enabled: true }, // the tab is registered only when DevTools are on
})
```

Deschideți Nuxt DevTools (`Shift + Alt + D`) și alegeți **i18n Micro**. Fila afișează:

- fiecare fișier JSON din `locales/` (rădăcină și `pages/`) al fiecărui layer, plus fișierele rădăcină din `additionalTranslationDirs`;
- un editor pentru fiecare fișier; **Save** scrie fișierul înapoi pe disc, iar serverul de dezvoltare reîncarcă traducerile;
- **Export** / **Import** al unui fișier ca JSON și **Stats** cu numărul de chei și acoperirea traducerilor;
- o vizualizare a configurației cu opțiunile rezolvate ale modulului;
- **Translate**, care completează cheile lipsă cu un motor de traducere automată pe care îl configurați în setările filei.

Salvarea scrie doar fișiere `.json` existente din directoarele voastre de traduceri. Când un fișier există în mai multe layer-e, se scrie copia proiectului.

## Inspectorul Vue DevTools {#vue-devtools-inspector}

Cu extensia de browser Vue DevTools, modulul înregistrează un inspector i18n (locale-ul curent, chunk-ul rutei, cheile încărcate) și o cronologie cu schimbările de locale, încărcările de chunk-uri și cheile lipsă.

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    debug: true, // also log every $t / $ts / $tc call on the timeline
    // vueDevtools: false, // turn the inspector off, keep the Nuxt tab
  },
})
```

[`vueDevtools`](/ro/api/module-options) are implicit valoarea `true`. `debug: true` este detaliat; folosiți-l pentru sesiuni scurte.
