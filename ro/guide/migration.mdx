Această pagină pune în corespondență o aplicație `@nuxtjs/i18n` cu nuxt-i18n-micro: opțiuni, helperi și structura fișierelor. Folosiți-o când înlocuiți modulul într-o aplicație existentă. Vă păstrați URL-urile (numele strategiilor sunt aceleași) și mutați traducerile în fișiere JSON per pagină.

<Tip>

**Actualizați chiar nuxt-i18n-micro?** — Vedeți [Actualizare](/ro/guide/upgrade).

</Tip>

## Înlocuirea modulului {#swap-the-module}

```bash
npm uninstall @nuxtjs/i18n
npm install nuxt-i18n-micro
```

```ts
// nuxt.config.ts — before
export default defineNuxtConfig({
  modules: ['@nuxtjs/i18n'],
  i18n: {
    locales: [
      { code: 'en', language: 'en-US', file: 'en.json' },
      { code: 'de', language: 'de-DE', file: 'de.json' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    langDir: 'locales',
    detectBrowserLanguage: { useCookie: true, cookieKey: 'i18n_redirected', redirectOn: 'root' },
  },
})
```

```ts
// nuxt.config.ts — after
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    translationDir: 'locales',
    localeCookie: 'i18n_redirected',
    autoDetectPath: '/',
  },
})
```

## Opțiuni {#options}

| `@nuxtjs/i18n` | nuxt-i18n-micro |
| --- | --- |
| `locales[].code` | `locales[].code` |
| `locales[].language` (`iso` înainte de v9) | `locales[].iso` |
| `locales[].name` | `locales[].displayName` |
| `locales[].dir` | `locales[].dir` |
| `locales[].domain` | `locales[].baseUrl` (o origine cu schema ei) |
| `locales[].domainDefault` | `locales[].baseDefault` |
| `differentDomains`, `multiDomainLocales` | nu sunt necesare: `baseUrl` singur rutează după host, vedeți [Straturi și domenii](/ro/guide/layers#multiple-domains) |
| `locales[].file` / `files`, `langDir`, `lazy` | `translationDir`; fișierele sunt găsite după nume și încărcate mereu per pagină |
| `defaultLocale`, `strategy` | aceleași nume, aceleași patru valori |
| `baseUrl` | `metaBaseUrl` |
| `customRoutes: 'config'` + `pages` | `globalLocaleRoutes` |
| `detectBrowserLanguage: false` | `redirects: false` (fără redirecționări) sau `autoDetectLanguage: false` (ignoră header-ul) |
| `detectBrowserLanguage.useCookie` / `cookieKey` | `localeCookie: '<name>'` (`null` dezactivează cookie-ul) |
| `detectBrowserLanguage.redirectOn: 'root'` | `autoDetectPath: '/'` (implicit) |
| `detectBrowserLanguage.redirectOn: 'no prefix'` | `autoDetectPath: 'no_prefix'` |
| `detectBrowserLanguage.redirectOn: 'all'` | `autoDetectPath: '*'` |
| fișierul de configurare `vueI18n` (`fallbackLocale`, `numberFormats`, `datetimeFormats`) | `fallbackLocale`, `numberFormats`, `datetimeFormats` în `i18n` |

Nu există `alwaysRedirect`: cu un cookie setat, `/` îl urmează la fiecare vizită. Lista completă se află în [Opțiunile modulului](/ro/api/module-options); regulile de detectare sunt în [Detectarea limbii](/ro/guide/locale-detection).

## Helperi și composables {#helpers-and-composables}

| `@nuxtjs/i18n` / vue-i18n | nuxt-i18n-micro (șablon / `useI18n()`) |
| --- | --- |
| `const { t } = useI18n()` | `const { t } = useI18n()`, `$t` în șabloane |
| `t('key', count)`, `tc` | `$tc('key', count)` |
| `te('key')` | `$has('key')` |
| `n(value, 'currency')`, `d(date, 'short')` | `$tn(value, 'currency')`, `$td(date, 'short')` |
| — | `$tdr(date)`: timp relativ ("în 3 zile") |
| `locale.value` | `$getLocale()` |
| `locales.value` | `$getLocales()` |
| `setLocale('de')` | `$switchLocale('de')` |
| `useLocalePath()('about')` | `$localePath({ name: 'about' })` |
| `useLocaleRoute()` | `$localeRoute()` |
| `useSwitchLocalePath()('de')` | `$switchLocalePath('de')` |
| `useSetI18nParams()` | `$setI18nRouteParams()` |
| `useLocaleHead()` | automat cu `meta: true`; [`useLocaleHead`](/ro/composables/useLocaleHead) pentru head-uri personalizate |
| `defineI18nRoute({ paths: { de: '/ueber-uns' }, locales: [...] })` | `$defineI18nRoute({ localeRoutes: { de: '/ueber-uns' }, locales: [...] })` |
| `<NuxtLinkLocale to="about">` | `<i18n-link :to="{ name: 'about' }">` |
| `<i18n-t>` | `<i18n-t>` (sloturile completează placeholder-ele `{name}`) |
| `$i18n` în rutele de server | `useTranslationServerMiddleware(event)`, vedeți [Rute de server și API](/ro/guide/server-side-translations) |

`useI18n()` este importat automat. `$defineI18nRoute` trebuie să își păstreze `$`: build-ul citește acel apel. Toți helperii: [Metode](/ro/api/methods).

## Fișiere de traducere {#translation-files}

Mutați cheile dintr-un fișier mare per limbă într-un fișier rădăcină plus câte un fișier per pagină:

```text
locales/
├── en.json              # keys used on many pages (nav, footer)
├── de.json
└── pages/
    ├── index/en.json    # keys of pages/index.vue
    └── about/en.json    # keys of pages/about.vue
```

Păstrarea tuturor cheilor în fișierele rădăcină funcționează de asemenea și este cel mai rapid prim pas. Setați `disablePageLocales: true` până le împărțiți. Vedeți [Fișiere de traducere](/ro/guide/translations).

### Sintaxa mesajelor {#message-syntax}

| vue-i18n | nuxt-i18n-micro |
| --- | --- |
| interpolare numită `{name}` | la fel |
| `car \| cars` (2 forme: 1 → prima) | formele sunt alese după număr începând de la 0: scrieți `no cars \| one car \| {count} cars` |
| mesaje legate `@:other.key` | neacceptate: repetați textul sau compuneți în cod |
| modificatori `@.upper:` | neacceptați: formatați în cod sau folosiți `<i18n-t>` |
| escapări literale `{'@'}` | nu sunt necesare: doar token-urile `{word}` sunt înlocuite |
| fișiere de mesaje JS/TS | doar JSON |

Regula de plural poate fi înlocuită cu opțiunea [`plural`](/ro/api/module-options#plural).

## Verificări după înlocuire {#check-after-the-switch}

- Fiecare URL pe care îl aveați se rezolvă în continuare; numele strategiilor coincid, căile personalizate se mută în `globalLocaleRoutes` sau `$defineI18nRoute`.
- `hreflang`, canonical și `og:locale` vin gata configurate cu `meta: true`; eliminați-le pe cele scrise manual.
- O eroare de parsare JSON afișează calea fișierului; o cheie lipsă afișează un avertisment în consola browserului în dezvoltare.
