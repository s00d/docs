Această pagină duce o aplicație Nuxt de la zero i18n la o pagină tradusă cu un selector de limbă. Ai nevoie de ea o singură dată, la începutul unui proiect. La final vei avea URL-uri localizate (`/about`, `/de/about`), câte un fișier JSON pentru fiecare limbă și pagină și `$t` în șabloanele tale.

## Instalare {#install}

Modulul necesită Nuxt 3.18 sau mai nou (funcționează și Nuxt 4) și Node 20 sau mai nou.

<CodeGroup>

```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>

## Configurarea limbilor {#configure-the-locales}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', displayName: 'English' },
      { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
      { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
    ],
    defaultLocale: 'en',
  },
})
```

Aceasta este toată configurația de care are nevoie o primă aplicație. Valorile implicite îți oferă:

- `strategy: 'prefix_except_default'`: limba implicită nu are prefix (`/about`), celelalte au (`/de/about`). Vezi [Strategii de rutare](/ro/guide/strategy).
- `translationDir: 'locales'`: fișierele de traducere se află în `locales/` la rădăcina proiectului, inclusiv cu structura `app/` din Nuxt 4.
- `meta: true`: tag-uri `hreflang`, canonical și `og:locale`, plus `lang` și `dir` pe `<html>`. Vezi [SEO](/ro/guide/seo).
- Un vizitator care deschide `/` este trimis la limba cerută de browserul său (`Accept-Language`). Vezi [Detectarea limbii](/ro/guide/locale-detection).

`iso` este eticheta de limbă folosită în tag-urile SEO; `code` este ceea ce apare în URL. Fiecare opțiune este listată în [Opțiunile modulului](/ro/api/module-options).

## Adăugarea fișierelor de traducere {#add-translation-files}

Pornește serverul de dezvoltare cu `nuxt dev`. Când Nuxt rezolvă paginile, modulul creează un fișier gol `{}` pentru fiecare limbă și pagină care nu are unul (dezactivează acest lucru cu [`disableWatcher`](/ro/api/module-options#disablewatcher)):

```text
locales/
├── en.json            # root: keys every page can use
├── de.json
├── fr.json
└── pages/
    ├── index/         # pages/index.vue
    │   ├── en.json
    │   ├── de.json
    │   └── fr.json
    └── about/         # pages/about.vue
        ├── en.json
        ├── de.json
        └── fr.json
```

Completează fișierul rădăcină și un fișier de pagină:

```json
// locales/en.json
{ "nav": { "home": "Home", "about": "About" } }
```

```json
// locales/pages/index/en.json
{ "welcome": "Welcome, {name}!", "items": "no items | one item | {count} items" }
```

O pagină vede cheile rădăcină și propriile chei; în caz de conflict, propriul fișier are prioritate. Numele folderelor urmează numele rutei (`pages/articles/[id].vue` corespunde lui `locales/pages/articles-id/`). [Fișiere de traducere](/ro/guide/translations) acoperă structura, fallback-urile și încărcarea.

## Folosirea `$t` într-o pagină {#use-t-on-a-page}

```vue
<!-- pages/index.vue -->
<script setup lang="ts">
const { t, tc, getLocale } = useI18n()

const title = t('nav.home') // 'Home'
</script>

<template>
  <h1>{{ $t('welcome', { name: 'Ada' }) }}</h1>
  <!-- Welcome, Ada! -->
  <p>{{ $tc('items', 3) }}</p>
  <!-- 3 items -->
  <p>{{ getLocale() }}</p>
  <!-- en -->
</template>
```

- În șabloane, fiecare helper este disponibil cu `$` (`$t`, `$tc`, `$localePath`, …).
- În `<script setup>`, `useI18n()` returnează aceiași helperi, cu și fără `$` (`t` și `$t` sunt aceeași funcție). Este importat automat.
- Placeholder-ele `{name}` sunt completate din obiectul de parametri. Formele de plural sunt separate prin `|`; numărul alege forma (0, 1, apoi ultima pentru tot ce este mai mare).

Toți helperii sunt listați în [Metode](/ro/api/methods).

## Legături între pagini și schimbarea limbii {#link-between-pages-and-switch-locale}

```vue
<!-- components/AppHeader.vue -->
<template>
  <nav>
    <i18n-link :to="{ name: 'index' }">{{ $t('nav.home') }}</i18n-link>
    <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
    <i18n-switcher />
  </nav>
</template>
```

- [`<i18n-link>`](/ro/components/i18n-link) este un `NuxtLink` care indică pagina în limba curentă: pe `/de`, linkul about duce la `/de/about`.
- [`<i18n-switcher>`](/ro/components/i18n-switcher) este un meniu derulant cu limbile activate; îl păstrează pe vizitator pe aceeași pagină.
- Pentru propriile butoane, apelează `$switchLocale('de')`, care navighează la pagina curentă în germană și reține alegerea. Pentru un `NuxtLink` simplu, folosește `$localePath({ name: 'about' })` sau `$switchLocalePath('de')`.

## Verificare {#check-it}

Rulează `nuxt dev` și deschide:

| URL | Afișează |
| --- | --- |
| `/` | Pagina principală în engleză (sau o redirecționare către `/de` când browserul tău preferă germana) |
| `/de` | Pagina principală în germană |
| `/de/about` | Pagina about în germană |
| `/en/about` | 404: limba implicită nu are prefix în `prefix_except_default` |

Modificările fișierelor JSON se aplică în pagina deschisă fără reîncărcare.
