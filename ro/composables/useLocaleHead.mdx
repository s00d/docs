---
title: "useLocaleHead"
description: "useLocaleHead construiește tag-urile SEO i18n (lang, dir, canonical, hreflang, og:locale) ca obiect pe care îl transmiteți lui useHead."
---

`useLocaleHead()` construiește tag-urile i18n din head pentru ruta curentă: `lang` și `dir` pe `<html>`, un link canonical, alternative `hreflang` cu `x-default`, `og:url`, `og:locale` și `og:locale:alternate`. Folosiți-l când setați [`meta: false`](/ro/api/module-options#meta) și gestionați singur `useHead`; cu `meta: true`, modulul înregistrează deja aceste tag-uri, iar modificările pe pagină se fac prin [`useI18nHead`](/ro/composables/useI18nHead).

## Semnătură {#signature}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { build: () => LocaleHead; metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }, LocaleHead | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

Tag-urile SEO din head pentru ruta curentă: alternative `hreflang` pentru fiecare limbă plus
`x-default`, un link canonical, `og:locale` și `lang`/`dir` pe `<html>`.

Necesar doar când `meta` este dezactivat sau valorile implicite trebuie ajustate — cu `meta: true`
modulul înregistrează singur aceleași tag-uri.

| Parametru | Tip | Descriere |
| --- | --- | --- |
| `options` | `UseLocaleHeadOptions` |  |

**Returnează** — `metaObject`, un ref care conține obiectul head gata de transmis lui `useHead`; `updateMeta` îl reîmprospătează; `build` calculează obiectul head din ruta curentă (reactiv când este citit într-un getter, de ex. `useHead(() => build())`)

```ts
const { metaObject } = useLocaleHead({ addSeoAttributes: true })
useHead(metaObject)
```

## Opțiuni {#options}

| Opțiune | Implicit | Descriere |
| --- | --- | --- |
| `addDirAttribute` | `true` | Setează `dir` pe `<html>` din `dir`-ul limbii (`'auto'` când aceasta nu are unul). |
| `identifierAttribute` | `'id'` | Atributul care identifică fiecare tag (`i18n-can`, `i18n-og`, `i18n-alternate-<hreflang>`, …), astfel încât actualizările înlocuiesc tag-urile în loc să le adauge. |
| `addSeoAttributes` | `true` | Emite tag-urile canonical, `hreflang` și `og:`. `false` păstrează doar `htmlAttrs`. |
| `baseUrl` | `'/'` | Originea adăugată la fiecare URL. Păstrați `'/'` pentru URL-uri relative; transmiteți `'https://example.com'` pentru URL-uri absolute. |
| `autoUpdate` | `true` | Reconstruiește `metaObject` când se schimbă ruta sau starea `i18n-locale`. |

## Ce emite {#what-it-emits}

- Nimic pe o rută fără potrivire (404) sau cu `disableMeta` pentru limba activă.
- Canonical și `og:url`: `$switchLocalePath(<active locale>)`, cu query-ul redus la [`canonicalQueryWhitelist`](/ro/api/module-options#canonicalquerywhitelist) și cu [`trailingSlash`](/ro/api/module-options#trailingslash) aplicat.
- `hreflang`: câte un link pentru fiecare limbă activată în care există pagina, `hreflang = iso || code`, omițând limbile cu `seo: false`; cu `hreflangBaseLanguage: true`, prima limbă regională a unei limbi emite și tag-ul limbii de bază. Niciunul sub `no_prefix`.
- `x-default`: URL-ul limbii implicite, cu excepția cazului în care strategia este `no_prefix`, limba implicită are `seo: false` sau pagina nu există în ea.
- `og:locale` / `og:locale:alternate`: din `og`-ul limbii, sau din `iso`-ul ei convertit (`en-US` → `en_US`); omis cu un avertisment în dezvoltare când niciuna nu funcționează.

## Exemplu {#example}

```ts
// app.vue, with i18n.meta: false
const { metaObject } = useLocaleHead({ baseUrl: 'https://example.com' })
useHead(metaObject)
```

`build()` returnează același obiect fără ref: `useHead(() => build())` rămâne reactiv fără un watcher.
