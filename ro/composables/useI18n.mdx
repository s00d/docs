---
title: "useI18n"
description: "useI18n returnează helperii de rulare (`$t`, `$tc`, `$localePath`, …) ca obiect simplu, cu și fără prefixul `$`."
---

`useI18n()` returnează helperii de rulare ai modulului ca obiect simplu. Folosiți-l în `<script setup>`, composables și plugin-uri în loc să apelați `useNuxtApp()`. Fiecare helper este disponibil sub numele cu `$` și sub un alias simplu: `t` și `$t` sunt aceeași funcție.

## Semnătură {#signature}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Toți helperii de rulare, ca obiect simplu.

Aceleași funcții pe care plugin-ul le injectează ca `$t`, `$tc` și așa mai departe, disponibile atât sub
numele cu prefixul dolar, cât și sub un alias simplu — astfel încât atât `const { t } = useI18n()`, cât și
`const { $t } = useI18n()` funcționează.

**Returnează** — helperii descriși în [referința metodelor](/ro/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

Obiectul returnat conține fiecare helper din [`PluginsInjections`](/ro/api/methods). Fiecare este documentat pe pagina [Helperi](/ro/api/methods).

## Exemplu {#example}

```vue
<script setup lang="ts">
const { t, tc, localePath, switchLocale, getLocale } = useI18n()

const title = computed(() => t('page.title'))
</script>

<template>
  <h1>{{ title }}</h1>
  <p>{{ tc('items', 3) }}</p>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
  <button @click="switchLocale(getLocale() === 'en' ? 'de' : 'en')">{{ t('nav.switch') }}</button>
</template>
```

## Nu se află în tip {#not-in-the-type}

`$defineI18nRoute` este tipizat doar pe `useNuxtApp()`:

```ts
const { $defineI18nRoute } = useNuxtApp()
```
