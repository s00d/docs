---
title: "useI18nHead"
description: "useI18nHead suprascrie tag-urile SEO i18n generate pentru o singură pagină: înlocuiți sau eliminați tag-urile canonical, hreflang și og, ori adăugați-le pe ale dumneavoastră."
---

`useI18nHead()` modifică tag-urile SEO generate de modul, doar pentru o singură pagină. Folosiți-l când pagina știe mai bine decât router-ul: un articol din CMS care există doar în unele limbi, un URL canonical venit dintr-un API, tag-uri `og:` suplimentare. Primiți tag-urile generate, cu suprascrierile dumneavoastră îmbinate peste ele.

## Semnătură {#signature}

```ts
useI18nHead(input?: MaybeRefOrGetter<I18nHeadInput | null>): { pageHead: any; resetPageHead: () => void }
```

Înregistrează suprascrieri la nivel de pagină pentru tag-urile SEO i18n din head.
Sunt îmbinate peste rezultatul `useLocaleHead` de către plugin-ul `02.meta`.

Preferați un getter (`() => ({ … })`) când valorile provin din `$t` / `t`, astfel încât
să fie re-rezolvate la schimbarea limbii. Un obiect simplu este evaluat o singură dată și rămâne înghețat.

| Parametru | Tip | Descriere |
| --- | --- | --- |
| `input` *(opțional)* | `MaybeRefOrGetter<I18nHeadInput \| null>` |  |

Funcționează cu [`meta: true`](/ro/api/module-options#meta) (valoarea implicită): plugin-ul meta al modulului îmbină input-ul peste rezultatul [`useLocaleHead`](/ro/composables/useLocaleHead) la fiecare randare a head-ului. Cu `meta: false`, nimic nu îl citește.

Suprascrierea este resetată când se schimbă numele rutei. O pagină care setează `disableMeta` nu primește niciun tag i18n, inclusiv suprascrierile.

## Input {#input}

`I18nHeadInput` (din `@i18n-micro/types`):

| Cheie | Tip | Efect |
| --- | --- | --- |
| `htmlAttrs` | `Record<string, string>` | Îmbinat în atributele `<html>` (`lang`, `dir`). |
| `meta` | `I18nHeadMeta[]` | Adăugat după tag-urile generate; înlocuiește un tag cu același `id`, `property` sau `name`. |
| `link` | `I18nHeadLink[]` | Adăugat după link-urile generate; înlocuiește un link cu același `id`, sau `rel` + `hreflang`. |
| `replace.canonical` | `string \| false` | Înlocuiește `href`-ul canonical sau elimină link-ul. |
| `replace.hreflang` | `I18nHeadLink[] \| false` | Înlocuiește sau elimină **toate** link-urile `rel="alternate"`, inclusiv `x-default`. |
| `replace.xDefault` | `I18nHeadLink \| false` | Înlocuiește sau elimină link-ul `x-default`. |
| `replace.ogLocale` | `string \| false` | Înlocuiește sau elimină `og:locale`. |
| `replace.ogUrl` | `string \| false` | Înlocuiește sau elimină `og:url`. |
| `replace.ogAlternates` | `string[] \| false` | Reconstruiește `og:locale:alternate` din aceste coduri de limbă (prin `og` / `iso`), omițând limba curentă, codurile necunoscute și codurile fără valoare `og` sau `iso`, ori le elimină. |
| `disable` | `I18nHeadDisableGroup[]` | Elimină grupuri generate: `'hreflang'` (nu și `x-default`), `'x-default'`, `'canonical'`, `'og'` (`og:locale` + `og:url`), `'og-alternates'`, `'html'`. |

Ordinea de aplicare: `disable`, apoi `replace`, apoi `htmlAttrs`, `meta`, `link`.

## Exemplu {#example}

Un articol care există doar în unele limbi, cu URL-uri alternative venite din API:

```vue
<script setup lang="ts">
const route = useRoute()
const { t } = useI18n()
const { data: article } = await useFetch<{ title: string; urls: Record<string, string> }>(`/api/articles/${route.params.slug}`)

useI18nHead(() => {
  if (!article.value) return null
  const codes = Object.keys(article.value.urls)
  return {
    meta: [{ property: 'og:title', content: article.value.title || t('blog.title') }],
    replace: {
      hreflang: codes.map((code) => ({ rel: 'alternate', hreflang: code, href: article.value!.urls[code]! })),
      ogAlternates: codes,
    },
  }
})
</script>
```

Transmiteți un getter, ca aici, când valorile provin din `t()` sau din date asincrone: acesta rulează din nou la schimbarea limbii. Un obiect simplu este citit o singură dată.
