---
title: "useI18nLocale"
description: "useI18nLocale citește și scrie starea locale-ului și cookie-ul de locale — punctul de intrare pentru detectarea personalizată a locale-ului."
---

`useI18nLocale()` oferă acces la locale-ul ales de aplicație: starea `i18n-locale` și cookie-ul de locale. Folosiți-l într-un plugin care detectează singur locale-ul (domeniu, profil de utilizator, header) în loc să scrieți manual `useState('i18n-locale')` sau cookie-ul. Verificările sale de validitate folosesc locale-urile activate, inclusiv suprascrierile de la runtime.

## Semnătură {#signature}

```ts
useI18nLocale(): { getEffectiveLocale: (route: unknown, getLocaleFromRoute: GetLocaleFromRoute) => string; getLocale: () => string | null; getPreferredLocale: () => string | null; hashCookie: CookieRef; isValidLocale: (locale: string | null | undefined) => locale is string; locale: any; localeCookie: CookieRef; resolveInitialLocale: (options: ResolveInitialLocaleOptions) => string; setLocale: (locale: string | null) => void; syncLocale: (locale: string | null) => void; validLocales: string[] }
```

Punct de intrare centralizat pentru gestionarea locale-ului i18n.
Combină useState('i18n-locale'), cookie-ul de locale și utilitarele de sincronizare.

## Valori returnate {#returned-values}

| Membru | Tip | Descriere |
| --- | --- | --- |
| `locale` | `Ref<string \| null>` | Ref-ul `useState('i18n-locale')`. |
| `localeCookie` | `Ref<string \| null>` | Cookie-ul [`localeCookie`](/ro/api/module-options#localecookie); un simplu `{ value: null }` când opțiunea este `null`. |
| `hashCookie` | `Ref<string \| null>` | Cookie-ul `hash-locale` la rutarea cu hash; `{ value: null }` în caz contrar. |
| `validLocales` | `string[]` | Codurile locale-urilor activate. |
| `setLocale(locale)` | `(locale: string \| null) => void` | Scrie starea și cookie-urile. Nu validează și nu încarcă traduceri. |
| `syncLocale(locale)` | `(locale: string \| null) => void` | Scrie doar cookie-urile. |
| `getLocale()` | `() => string \| null` | Starea, apoi cookie-ul de preferință (cookie-ul hash la rutarea cu hash). Nevalidat. |
| `getPreferredLocale()` | `() => string \| null` | Prima valoare **validă** dintre stare și cookie-ul de preferință, sau `null`. |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string` | Starea la rutarea cu hash, când este setată; altfel `getLocaleFromRoute(route)`. |
| `resolveInitialLocale(options)` | `(options: ResolveInitialLocaleOptions) => string` | `options.urlLocale`, apoi o stare validă, apoi `options.serverLocale`, apoi locale-ul rutei. Stochează rezultatul în stare când starea nu este validă; pe client scrie și cookie-ul. |
| `isValidLocale(locale)` | `(locale) => locale is string` | Dacă `locale` se află în `validLocales`. |

Cookie-urile durează un an, cu `path: '/'` și `sameSite: 'lax'`.

## Exemplu {#example}

```ts
// plugins/locale-from-domain.server.ts
export default defineNuxtPlugin({
  name: 'locale-from-domain',
  enforce: 'pre',
  setup() {
    const { setLocale, isValidLocale } = useI18nLocale()
    const host = useRequestURL().hostname // e.g. de.example.com
    const code = host.split('.')[0]
    if (isValidLocale(code)) setLocale(code)
  },
})
```

Plugin-ul loader al modulului citește starea la pornire, așa că un plugin care o setează trebuie să ruleze primul (`enforce: 'pre'`). Cum concurează starea cu URL-ul, cookie-ul și `Accept-Language`: [Detectarea locale-ului](/ro/guide/locale-detection). Ghid complet: [Detectare personalizată](/ro/guide/custom-auto-detect).

`setLocale()` nu schimbă traducerile de pe ecran. Pentru a schimba locale-ul paginii curente, apelați [`$switchLocale()`](/ro/api/methods#$switchlocale).
