## 🚀 Ghid rapid

### Instalare

Instalează modulul în aplicația ta Nuxt:

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

### Configurare de bază

Adaugă modulul în `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

<Tip>
- **Fișiere la nivel de rădăcină** (`locales/en.json`, etc.) — traduceri partajate în întreaga aplicație (meniuri, footer, UI comun). Cu `translationPayloads.mode: 'premerged'` (implicit), ele sunt îmbinate în fiecare pagină la build.
- **Fișiere specifice paginii** (`locales/pages/<route>/<locale>.json`) — traduceri unice pentru pagini specifice, încărcate doar când pagina este vizitată.
- **Rute dinamice** — `pages/articles/[id].vue` se mapează la `locales/pages/articles-id/` (parantezele sunt înlocuite cu liniuțe).
- **Auto-generare** — toate fișierele de traducere lipsă sunt create automat în timpul `nuxt dev`.
</Tip>

<Info>
Modulul suportă ambele structuri:

- **Pagini**: `pages/**/*.vue` (Nuxt 3) sau `app/pages/**/*.vue` (Nuxt 4)
- **Traduceri**: păstrează `locales/` la **rădăcina proiectului** în mod implicit (convenție recomandată), nu în interiorul `app/`

```tree
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   ├── en.json
│   └── pages/
└── nuxt.config.ts
```

Colocație opțională: `i18n: \{ translationDir: 'app/locales' \}` (vezi [fixture `n3`](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/n3)).

Pentru helper-ul CLI opțional `text-to-i18n`, folosește [`nuxt-i18n-micro-cli` ≥ 2.1.1](/guides/cli#-text-to-i18n-command) astfel încât `app/pages` și `app/components` să fie scanate de la rădăcina proiectului.
</Info>

### Utilizare de bază

Folosește traducerile în componentele tale:

```vue
<template>
  <div>
    <h1>{{ $t('welcome') }}</h1>
    <p>{{ $t('description', { name: 'World' }) }}</p>

    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" @click="$switchLocale(locale.code)">
        {{ locale.code }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useI18n } from '#imports'

const { $t, $getLocales, $switchLocale } = useI18n()
</script>
```
