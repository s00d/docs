# 🌍 `useLocaleHead` コンポーザブル

`useLocaleHead` は `Nuxt I18n Micro` のユーティリティで、ローカライズされたルート向けの SEO 属性と HTML メタタグを管理するのに役立ちます。HTML ドキュメントの `lang` と `dir` 属性を動的に生成し、ローカライズされたコンテンツの SEO 向上のための `meta` および `link` タグを作成します。

## ⚙️ オプション

```ts
useLocaleHead(options: UseLocaleHeadOptions): { metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }, MetaObject | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

現在のルートに対する SEO head タグ: すべてのロケール用の `hreflang` 代替、`x-default`、canonical リンク、`og:locale`、および `<html>` の `lang` / `dir` を提供します。

`meta` が無効化されている、またはデフォルトを調整する必要がある場合にのみ使用します — `meta: true` の場合はモジュール自身が同じタグを登録します。

## 🛠️ 戻り値

`useLocaleHead` コンポーザブルは、リアクティブなオブジェクトと、ソースデータが変わった際に呼び出すべき更新関数を返します。両方の形状はソースから生成されたシグネチャに含まれています。

### `metaObject`

`useHead(metaObject)` に渡せる、リアクティブな head ペイロード（html 属性、meta、link）です。

- **例**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

現在のルート、ロケール、設定に基づいて `metaObject` を再計算します。入力が変わったとき（例: ルート変更時）に呼び出してください。

- **例**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### `link` と `meta` へのアクセス

`link` と `meta` の配列は `metaObject.value` からアクセスできます:

- **例**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ 使用例

### 基本的な利用

デフォルトオプションでロケール固有の head 属性を生成します。

```js
const head = useLocaleHead()
```

### 識別属性のカスタマイズ

生成されるタグに使う識別属性をカスタマイズします。

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### SEO 属性の無効化

SEO 関連の meta / link タグを含めずに head 属性を生成します。

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### ベース URL の指定

canonical と代替 URL に使うカスタムのベース URL を設定します。

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 追加機能

### SEO メタタグとリンクタグ

`addSeoAttributes` が有効な場合、このコンポーザブルは自動的に以下のタグを生成します:

- 現在のロケール用の `og:locale`（`language_TERRITORY` のアンダースコア形式）。`locale.og` から導出されるか、可能な場合は `locale.iso` から変換されます。
- ページの canonical URL 用の `og:url`。
- 代替言語版のための `og:locale:alternate`。
- SEO 最適化のための `rel="canonical"` および `rel="alternate"` リンク。
- デフォルトロケールの URL を指す `hreflang="x-default"` リンク。定義されたロケールのいずれとも一致しない言語のユーザーに、どの URL を提示すべきかを検索エンジンに伝えます。

### 動的なロケールと方向

このコンポーザブルは現在のルートのロケールに基づいて `lang` および `dir` 属性を動的に決定し、国際的なユーザー向けに HTML ドキュメントを正しく構成します。

### ローカライズされたルートの処理

ルートがロケールコードでプレフィックスされている場合（例: `/en/about`）、コンポーザブルは URL 生成のためにフルパスを賢く調整し、SEO 属性が正確で適切なものになるようにします。

このコンポーザブルは、国際的なオーディエンス向けに Nuxt アプリケーションを最適化するプロセスを簡素化し、グローバルな検索エンジンとユーザーの双方に対して十分に準備されたサイトを構築できます。

## 🛠️ 使用例

以下は、Vue コンポーネント内でデフォルト設定で `useLocaleHead` コンポーザブルを利用する例です:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### コードの解説

- **`useLocaleHead` コンポーザブル**: `<script setup>` セクション内で呼び出され、`htmlAttrs`、`meta`、`link` を含むオブジェクトを返します。

- **`<html>` タグ**: HTML ドキュメントの `lang` と `dir` 属性が現在のロケールに基づいて動的に決定され、`<html>` タグに適用されます。

- **`<head>` セクション**:
  - **メタタグ**: `og:locale`、`og:url`、ページの代替言語版を示す `rel="canonical"` と `rel="alternate"` を含む SEO 関連メタタグが生成されます。
  - **リンクタグ**: canonical リンク、代替言語版へのリンク、およびデフォルトロケール URL を指す `hreflang="x-default"` リンクが含まれます。

- **`<body>` セクション**: ページの主要コンテンツがここに表示されます。この例では、シンプルなヘッダーと段落を使用しています。

### 📝 メモ

1. **属性**: 使用される属性（`lang`、`dir`、`rel`、`href`、`hreflang`、`property`、`content`）は `useLocaleHead` が返すオブジェクトから取得されます。

2. **SEO タグの生成**: `addSeoAttributes` オプションが `true` に設定されている場合、コンポーザブルは現在のロケール用の SEO タグを自動生成します。

3. **ベース URL**: `baseUrl` オプションで独自のベース URL を設定でき、canonical と代替リンクを正しく生成できます。

この例は、`useLocaleHead` をアプリケーションのコンポーネントに統合して SEO 属性を正しく設定し、ローカライズページの検索エンジンによるインデックス化を向上させることが、どれほど簡単かを示しています。

## 🧩 カスタマイズとライフサイクル

- `useLocaleHead` は自身で変更を購読することはありません。`metaObject` と `updateMeta` を返します。
- 入力が変わったとき（通常はルート変更時）は、たとえばプラグインから `updateMeta()` を呼び出してください:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## 代わりに `useI18nHead` を使うべきタイミング

`meta: true`（デフォルト）の場合、**ページごとの** オーバーライド（カスタム hreflang、追加の `og:title`、部分無効化など）には [`useI18nHead`](/api/composables/use-i18n-head) を利用することを推奨します。`meta: false` の場合、または自身で `useHead` を管理している場合にのみ `useLocaleHead` を直接使用してください。
