# 🛠️ `useI18n` コンポーザブル

`Nuxt I18n Micro` の `useI18n` コンポーザブルは、コンポーネントやスクリプト内でほとんどのランタイム i18n ヘルパーへのアクセスを提供します。メソッドは **`$` プレフィックスの有無どちらでも** 利用できます（例: `$t` と `t`）。

一部の注入 — `$defineI18nRoute` と `$clearCache` — は `useNuxtApp()` からのみ利用できます。詳細は [メソッド — `$defineI18nRoute`](/api/methods#definei18nroute) および [`$clearCache`](/api/methods#clearcache) を参照してください。

## 📊 戻り値

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

すべてのランタイムヘルパーを、プレーンなオブジェクトとして返します。

プラグインが `$t`、`$tc` などとして注入するのと同じ関数群を、`$` 付きの名前とプレフィックスなしのエイリアスの両方で利用できます — つまり `const \{ t \} = useI18n()` と `const \{ $t \} = useI18n()` の両方が動作します。

**戻り値** — [メソッドリファレンス](/api/methods) で説明されているヘルパー群。

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

戻り値のすべてのヘルパー — `$t`、`$tc`、`$has`、`$switchLocale` など — は、シグネチャとともに [メソッドリファレンス](/api/methods) で完全に解説されています。

## `useNuxtApp()` 限定の API

これらは `useI18n()` からは **返されません**。`useNuxtApp()` からインポートしてください:

| メソッド                     | 用途                                                                         |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | ページごとのロケールルート、制限、`script setup` 内のインライン翻訳 |
| `$clearCache()`            | インメモリ翻訳キャッシュと読み込み済みチャンクを削除する                            |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

シグネチャと例の全容は [メソッド](/api/methods) を参照してください。

## 🛠️ 使用例

### 基本的なロケール取得

アプリケーションの現在のロケールを取得します。

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### パラメータ付きの翻訳

動的なパラメータとフォールバックのデフォルト値を伴って文字列を翻訳します。

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### ロケールの切り替え

アプリケーションを別のロケールに切り替えます。

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### ローカライズされたルートの生成

現在のロケールまたは指定されたロケール向けのルートを生成します。

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
