# useI18nLocale

## シグネチャ

```ts
useI18nLocale(): { getEffectiveLocale: (route: unknown, getLocaleFromRoute: GetLocaleFromRoute) => string; getLocale: () => string | null; getLocaleWithServerFallback: (serverLocale?: string | null) => string | null; getPreferredLocale: () => string | null; hashCookie: any; isValidLocale: (locale: string | null | undefined) => locale is string; locale: any; localeCookie: any; resolveInitialLocale: (options: ResolveInitialLocaleOptions) => string; setLocale: (locale: string | null) => void; syncLocale: (locale: string | null) => void; validLocales: string[] }
```

i18n ロケール管理の集中化されたエントリーポイント。
useState('i18n-locale')、ロケール Cookie、および同期ユーティリティを統合します。

## 使い方

```vue
<script setup>
const {
  locale,
  localeCookie,
  hashCookie,
  validLocales,
  getPreferredLocale,
  getLocale,
  getLocaleWithServerFallback,
  getEffectiveLocale,
  resolveInitialLocale,
  setLocale,
  syncLocale,
  isValidLocale,
} = useI18nLocale()

// Set locale (updates state and cookies)
setLocale('de')

// Get current locale (state → cookie)
const current = getLocale()

// Get valid preferred locale
const preferred = getPreferredLocale()
</script>
```

## API

| プロパティ / メソッド                                 | 型                                | 説明                                                                          |
| ----------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| `locale`                                        | `Ref<string \| null>`               | リアクティブなロケール状態（`useState('i18n-locale')`）                                    |
| `localeCookie`                                  | `Ref`                               | ロケール Cookie（`localeCookie` オプションが有効な場合）                                |
| `hashCookie`                                    | `Ref`                               | `hashMode` が有効なときに使われる Cookie                                                |
| `validLocales`                                  | `string[]`                          | モジュール設定から取得した有効なロケールコード（`disabled` は除外）                        |
| `getLocale()`                                   | `() => string \| null`              | 現在のロケール: state → cookie（ハッシュモードではハッシュ Cookie）                         |
| `getPreferredLocale()`                          | `() => string \| null`              | state / cookie のロケールを `validLocales` で **検証** した結果、無効なら `null`             |
| `getLocaleWithServerFallback(serverLocale?)`    | `(serverLocale?) => string \| null` | state → cookie → 任意のサーバーコンテキスト（`no_prefix` の初期化で使用）              |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string`             | 翻訳読み込みに使うロケール: ハッシュモードでは state を優先、それ以外はルートから取得 |
| `resolveInitialLocale(options)`                 | `(options) => string`               | ロケールを解決: state → `serverLocale` → route。必要に応じて state を同期します             |
| `setLocale(locale)`                             | `(locale: string \| null) => void`  | ロケールを設定し、Cookie に同期します                                                       |
| `syncLocale(locale)`                            | `(locale: string \| null) => void`  | Cookie のみ同期します（state は更新しません）                                                  |
| `isValidLocale(locale)`                         | `(locale) => boolean`               | 文字列が `validLocales` に含まれるかを確認します                                                 |

### `resolveInitialLocale` のオプション

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

起動時にメインプラグインが内部的に使用します。カスタムプラグインが独自の検出フローを実装する際にも呼び出せます。

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

指定したルートオブジェクトに対して、翻訳の読み込みとメッセージフォーマットに用いられるロケールを返します。

## プログラマティックなロケール設定

`useState('i18n-locale')` を直接扱うより、`useI18nLocale()` の利用を推奨します:

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
`setLocale()` はロケール設定（state + Cookie）のみを更新します。クライアントで現在の翻訳コンテキストも再読み込みするには、`useNuxtApp()` や `useI18n()` の `$switchLocale()` を使用してください。URL が変わらない `no_prefix` で特に重要です。[FAQ — URL を変えずにロケールを切り替える](/guides/faq#-switch-locale-without-changing-the-url) を参照してください。
</Tip>
