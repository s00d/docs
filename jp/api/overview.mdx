このセクションでは、Nuxt モジュールのすべてのオプション、ヘルパー、フック、コンポーザブル、コンポーネントに加え、各 `@i18n-micro/*` パッケージのエクスポートされた API を掲載しています。シグネチャやデフォルト値を調べるときに使用してください。使い方は[ガイド](/jp/guide/getting-started)で説明しています。ここにあるほとんどの表はソースから生成されているため、コードと一致しています。

## Nuxt モジュール {#nuxt-module}

| ページ | 内容 |
| --- | --- |
| [モジュールオプション](/jp/api/module-options) | `nuxt.config` のすべての `i18n` キー（型とデフォルト値付き） |
| [ヘルパー](/jp/api/methods) | `$t`、`$tc`、`$tn`、`$td`、`$localePath`、`$switchLocale`、`$defineI18nRoute` など |
| [フック](/jp/api/events) | `i18n:register` ランタイムフック |

## コンポーザブル {#composables}

| コンポーザブル | 用途 |
| --- | --- |
| [`useI18n`](/jp/composables/useI18n) | `<script setup>` 内でのヘルパー |
| [`useI18nLocale`](/jp/composables/useI18nLocale) | カスタム検出プラグインでのロケール状態と Cookie |
| [`useI18nHead`](/jp/composables/useI18nHead) | 生成された SEO タグのページごとの上書き |
| [`useLocaleHead`](/jp/composables/useLocaleHead) | 独自の `useHead` 用に、SEO タグをオブジェクトとして取得 |

## コンポーネント {#components}

| コンポーネント | レンダリング内容 |
| --- | --- |
| [`<i18n-t>`](/jp/components/i18n-t) | 複数形、フォーマット、スロット補間を備えた 1 つの翻訳 |
| [`<i18n-link>`](/jp/components/i18n-link) | ローカライズされたルートへの `NuxtLink` |
| [`<i18n-switcher>`](/jp/components/i18n-switcher) | ロケールのドロップダウン |
| [`<i18n-group>`](/jp/components/i18n-group) | キーのプレフィックスを共有するブロック |

## サーバー {#server}

Nitro ハンドラーでは、クライアントヘルパーではなく `useTranslationServerMiddleware` と `useLocaleServerMiddleware` を使用します。[サーバールート](/jp/guide/server-side-translations)を参照してください。

## パッケージ {#packages}

[パッケージ API](/jp/api/packages/overview) では、すべての `@i18n-micro/*` パッケージのエクスポートを、それぞれ生成された 1 ページずつで掲載しています。
