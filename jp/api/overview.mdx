# API リファレンス

## ランタイム API

- [メソッド](/api/methods) — `$t`、`$ts`、`$_t`、`$_ts`、ロケール切り替え、ルーティングヘルパー
- [イベント](/api/events) — `i18n:register`、`i18n:beforeLocaleSwitch`、`i18n:afterLocaleSwitch`
- [翻訳とキャッシュ](/api/cache) — `TranslationStorage`、ペイロード読み込み、`$clearCache`

## サーバーミドルウェア

サーバーハンドラーは、クライアントの `$t` ヘルパーではなく、専用のミドルウェアを使用します。

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — API ルートやサーバーハンドラーでの翻訳
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — 検出されたロケールとメタデータの読み取り

セットアップ、ロケール検出の優先度、サンプルについては [サーバーサイド翻訳ガイド](/guides/server-side-translations) 全体を参照してください。
