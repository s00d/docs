# API リファレンス

## ランタイム API

- [メソッド](/api/methods) — `$t`、`$ts`、`$_t`、`$_ts`、ロケール切り替え、ルーティングヘルパー
- [イベント](/api/events) — `i18n:register`、`i18n:beforeLocaleSwitch`、`i18n:afterLocaleSwitch`
- [翻訳とキャッシュ](/api/cache) — `TranslationStorage`、ペイロードの読み込み、`$clearCache`

## サーバーミドルウェア

サーバーハンドラーは（クライアントの `$t` ヘルパーではなく）専用のミドルウェアを利用します:

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — API ルートおよびサーバーハンドラーで翻訳する
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — 検出されたロケールとメタデータを取得する

セットアップ、ロケール検出の優先順位、および例については [サーバーサイド翻訳のガイド](/guides/server-side-translations) を参照してください。
