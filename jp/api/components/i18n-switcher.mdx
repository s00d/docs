# 🌍 `<i18n-switcher>` コンポーネント

`Nuxt I18n Micro` の `<i18n-switcher>` コンポーネントは、アプリケーション内のロケール切り替えのための使いやすいドロップダウンインターフェースを提供します。カスタマイズ性が高く、アプリケーションのデザインやレイアウトにシームレスに統合できます。

`disabled: true` のロケールはドロップダウンから **除外** されます（SEO / head タグ用に `$getLocales()` からは引き続き取得可能です）。切り替え可能なロケールのみ `NuxtLink` + `hreflang` を伴って表示されます。

すべての要素は既定ではスタイルなしです。`custom*Style` prop はインラインスタイルオブジェクトを受け取り、スタイリングでは足りない場合は下記のスロットでマークアップ自体を置き換えられます。

## 🛠️ 使用例

### 基本的な利用

```vue
<template>
  <i18n-switcher />
</template>
```

これはデフォルトのスタイルと挙動でロケール切り替えをレンダリングします。

### カスタムラベルとインラインスタイル

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

この例は、カスタムラベルとインラインスタイルを備えた、完全にカスタマイズされたロケール切り替えを示しています。

## 🔌 スロット

スイッチャーの視覚的な各要素はすべて差し替え可能です。スロットは上記の Props テーブルとともに一覧化されており、それぞれにテンプレートコンテンツを渡せます:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

`-item`、`-link-content` で終わる、または `before-item` で始まる名前のスロットは、対応する `locale` オブジェクトを受け取ります。

## 🎨 スタイルの概要

`<i18n-switcher>` コンポーネントには、インラインスタイルで定義された基本的なスタイルが用意されており、props 経由でカスタムスタイルを渡すことで簡単に上書きできます。デフォルトのスタイリングの概略:

- **Wrapper**: ドロップダウンの位置を制御します。
- **Button**: ドロップダウン開閉ボタンをスタイリングします。
- **Dropdown**: ドロップダウンリストをスタイリングします。
- **Items**: リスト内の各アイテムをスタイリングします。
- **Links**: 各アイテム内のリンクをスタイリングします。
- **Icon**: ドロップダウンインジケーターアイコンをスタイリングします。

対応する props にカスタムスタイルを渡すことでこれらをカスタマイズし、ロケール切り替えをアプリケーションの UI にシームレスに統合できます。
