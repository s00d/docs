# 🌍 `<i18n-link>` コンポーネント

`Nuxt I18n Micro` の `<i18n-link>` コンポーネントは、現在のロケールに基づいてルートを自動的にローカライズする汎用リンクコンポーネントです。`<NuxtLink>` コンポーネントのラッパーとして機能し、アクティブリンクのスタイリングや外部リンクのサポートといった追加機能を提供します。

## ⚙️ Props

{/* generated:component:i18n-link — do not edit; run `pnpm run docs:generate` */}

| Prop | 型 | デフォルト | 説明 |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | 遷移先ルート。自動的にローカライズされます。外部 URL の場合はそのまま渡されます。 |
| `activeStyle` | `Partial<CSSStyleValue>` | — | リンクが現在のルートを指している間に適用されるインラインスタイル。 |

**\*** は必須です。

### スロット

| スロット | バインディング | 説明 |
| --- | --- | --- |
| `default` | — | リンクの内容。 |

{/* /generated:component:i18n-link */}

`to` は `NuxtLink` が受け付けるもの — パス、名前付きルート、解決済みルートオブジェクト — をすべて受け付けます。絶対 URL は検出され、ローカライズされる代わりにプレーンな `<a target="_blank" rel="noopener noreferrer">` としてレンダリングされます。

## 🛠️ 使用例

### 基本的な利用

```vue
<i18n-link to="/about">About Us</i18n-link>
```

この例では、現在のロケールにローカライズされた `/about` ページへのリンクを生成します。

### インラインスタイルによるアクティブリンクのスタイリング

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

ユーザーが `/about` ページを表示しているときにリンクのテキストが太字になり、インラインスタイルで直接アクティブリンクを装飾できます。

### 外部リンクの取り扱い

コンポーネントは外部リンクを自動検出し、セキュリティのために必要な属性を付与します。

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

このリンクは、`rel="noopener noreferrer"` が適用された新しいタブで `https://example.com` を開きます。

## 🎨 スタイル

コンポーネントは、アクティブ状態にクラスではなくインラインスタイルを使用するようになりました。これらのスタイルは `activeStyle` prop でカスタマイズできます。

### デフォルトのアクティブスタイル

- **フォントウェイト**: `bold`
- **カラー**: ブラウザのデフォルト色を継承します（`activeStyle` に `color` を指定していない場合）。

`activeStyle` prop で任意のスタイルを渡すことでこれらを上書きできます。

### カスタムアクティブスタイル

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

この例では、リンクがアクティブなときに太字かつ緑になります。

## 🚀 追加機能

### カスタムコンテンツ用のスロット

スロットを使ってリンク内に任意のコンテンツを渡すことができ、さまざまなユースケースに柔軟に対応できます。

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### アクセシビリティの強化

コンポーネントは `aria-label` などのアクセシビリティ属性をサポートしており、よりアクセシブルな体験を実現できます。

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
