# 🌍 `<i18n-t>` コンポーネント

`Nuxt I18n Micro` の `<i18n-t>` コンポーネントは、スロットを介した動的なコンテンツ挿入をサポートする柔軟な翻訳コンポーネントです。翻訳内にカスタムの Vue コンポーネントや HTML を補間でき、高度なローカライズシナリオを実現できます。

## ⚙️ Props

| Prop | 型 | デフォルト | 説明 |
| --- | --- | --- | --- |
| `keypath` **\*** | `string` | — | レンダリングする翻訳キー。 |
| `plural` | `number \| string` | — | 複数形を選択するためのカウント。指定すると `$t` ではなく `$tc` が使用されます。 |
| `tag` | `string` | `'span'` | レンダリングする要素。 |
| `params` | `Record<string, string \| number \| boolean>` | `() => (\{\})` | 翻訳に差し込まれる補間値。 |
| `defaultValue` | `string` | `''` | `hideIfEmpty` が空の翻訳を非表示にした場合、コンポーネントの代わりにレンダリングされます。 |
| `html` | `boolean` | `false` | 翻訳をテキストではなく HTML としてレンダリングします。制御下にあるコンテンツにのみ使用してください。 |
| `hideIfEmpty` | `boolean` | `false` | 翻訳が空文字列に解決される場合、何もレンダリングしません。 |
| `customPluralRule` | `PluralFunc` | `null` | この要素のみに適用され、設定された複数形ルールを上書きします。 |
| `number` | `number \| string` | — | 値を `$tn` でフォーマットし、`\{number\}` として翻訳に渡します。 |
| `date` | `Date \| string \| number` | — | 値を `$td` でフォーマットし、`\{date\}` として翻訳に渡します。 |
| `relativeDate` | `Date \| string \| number` | — | 値を `$tdr` でフォーマットし、`\{relativeDate\}` として翻訳に渡します。 |

**\*** は必須です。

{/* /generated:component:i18n-t */}

`plural`、`number`、`date`、`relativeDate` のうち一度に適用されるのは 1 つだけです。複数を設定した場合はこの順序で最初のものが優先されます。

### Prop ごとの例

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

```json
{
  "items": "Nothing|You have {count} item|You have {count} items"
}
```

## 🛠️ 使用例

### 基本的な利用

```vue
<i18n-t keypath="feedback.text" />
```

これは `feedback.text` の翻訳を `<span>` タグ内にレンダリングします。

### 動的コンテンツのためのスロット利用

`<i18n-t>` コンポーネントは、スロットを利用して翻訳の特定部分に Vue コンポーネントやその他のコンテンツを動的に挿入できます。

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

この例では、`feedback.text` 翻訳文字列内の `\{link\}` プレースホルダが `<nuxt-link>` コンポーネントで置き換えられ、その中にさらに別の翻訳コンポーネントが含まれています。

### 複数形処理

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

これは `itemCount` の値に基づいて複数形ルールを自動適用します。

## 🚀 追加機能

### デフォルトスロット

特定のスロットが指定されていない場合、翻訳済み文字列全体を渡すデフォルトスロットで翻訳をカスタマイズできます:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### 条件付きレンダリング

`hideIfEmpty` prop を使うと、翻訳文字列が空の場合に何もレンダリングしないようにできます。

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### カスタム複数形ルール

カスタム関数で複数形処理を扱えます。

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### スロットを用いた応用例

スロットを活用して、翻訳内容のレンダリング方法をカスタマイズできます。

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
