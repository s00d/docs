# パッケージ API

`nuxt-i18n-micro` は小さなパッケージ群から構成されており、そのほとんどは単体でも使用可能です。たとえば `@i18n-micro/vue` はプレーンな Vue アプリで、`@i18n-micro/core` はどこでも使えます。

以下の各ページは、[`pnpm run api:surface`](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/maintenance-commands.md#api-surface) が TypeScript ソースと照合する API スナップショットから生成されているため、エクスポートが消えれば必ずこのリファレンスが変わるか、CI が失敗します。
