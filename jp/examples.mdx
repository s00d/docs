# 📚 Nuxt I18n Micro のサンプルと使い方

このセクションでは、Nuxt.js アプリケーションで `Nuxt I18n Micro` を使用する方法を示すさまざまなサンプルを紹介します。ロケールの切り替え、`<i18n-link>`、`<i18n-switcher>`、`<i18n-t>` コンポーネントの使用、動的な翻訳キーの扱い方を確認できます。

## 🛠️ 基本セットアップ

`Nuxt I18n Micro` を始めるための基本セットアップは以下のとおりです。

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 ロケール切り替え

### プログラム的なロケール切り替え

このサンプルでは、ボタンでロケールを切り替える方法を示します。

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### ロケール切り替え用のサンプル JSON

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### `<i18n-switcher>` コンポーネントの使用

`<i18n-switcher>` コンポーネントは、カスタマイズ可能なラベルを持つロケール切り替え用のドロップダウンを提供します。

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 📝 翻訳ファイルからの動的キーのレンダリング

翻訳ファイル内に格納された動的キーを反復処理し、その値を条件付きでレンダリングしたい場合があります。以下のサンプルは、`Nuxt I18n Micro` を使ってこれを実現する方法を示します。

### サンプル: 動的キーのレンダリング

このサンプルでは、特定の翻訳パス(この場合は `dynamic`)からキーの配列を取得し、それらを反復処理します。各キーは `$has` で存在確認をしてから、`$t` で値をレンダリングします。

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### 翻訳ファイルの例 (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### サンプル: オブジェクトから動的キーをレンダリング

このサンプルでは、翻訳ファイル内に格納されたオブジェクトを扱います。オブジェクトのキーを取得して反復処理し、キー名と関連する値の両方を動的にレンダリングします。

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### 翻訳ファイルの例 (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 スロットと補間を伴う翻訳のための `<i18n-t>` の使用

`<i18n-t>` コンポーネントは、動的コンテンツと HTML タグを含む翻訳をレンダリングするのに便利です。

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### `<i18n-t>` 用のサンプル JSON

```json
{
  "greeting": "Welcome to the page"
}
```

### 補間ありのサンプル

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### 補間用のサンプル JSON

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 複数形処理のための `$tc` の使用

`Nuxt I18n Micro` の `$tc` 関数は、カウントとロケール設定に基づいて複数形を処理します。これは、アイテム、通知、その他数によって変化するエンティティを含むメッセージを動的に調整するのに便利です。

### サンプル: 複数形処理のための `$tc` の使用

以下のサンプルでは、`$tc` を使ってリンゴの数を示すメッセージを表示します。翻訳キーは、指定されたカウントに基づいて複数の複数形フォームを処理します。

```vue
<template>
  <div>
    <!-- リンゴの数についての複数形メッセージを表示 -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- 出力: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- 出力: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- 出力: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### 複数形処理用のサンプル JSON

以下は、異なる複数形フォームを処理するために JSON ファイルで翻訳を定義する方法です。

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### 説明

- **`$tc('apples', 0)`**: カウントがゼロの場合に使用される最初のフォーム (`"no apples"`) を返します。
- **`$tc('apples', 1)`**: カウントが 1 の場合に使用される 2 番目のフォーム (`"one apple"`) を返します。
- **`$tc('apples', 10)`**: カウントが 2 以上の場合に使用される 3 番目のフォームをカウント値付きで返します (`"10 apples"`)。

### より複雑な複数形処理を含むサンプル

アプリケーションがより複雑な複数形ルール(たとえば zero、one、two、few、many、other の固有ケース)を扱う必要がある場合は、翻訳文字列を適宜拡張できます。

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: `"two apples"` を返すように設定できます。
- **`$tc('apples', 3)`**: カウントに対して定義されたルールに応じて、`"a few apples"` を返すことができます。

## 🌐 数値フォーマットのための `$tn` の使用

`$tn` 関数は、`Intl.NumberFormat` API を使って、現在のロケールに従って数値をフォーマットします。これは、通貨、パーセンテージ、その他の数値フォーマットなど、ユーザーの地域設定に合わせた形で数値を表示するのに便利です。

### サンプル: 数値フォーマットのための `$tn` の使用

```vue
<template>
  <div>
    <!-- 通貨として数値をフォーマット -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- 出力: 'en-US' ロケールで $1,234,567.89 -->

    <!-- カスタムオプションで数値をフォーマット -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- 出力: 'en-US' ロケールで 56.7% -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ 日時フォーマットのための `$td` の使用

`$td` 関数は、`Intl.DateTimeFormat` API を使って、現在のロケールに従って日時をフォーマットします。これは、ユーザーのロケール設定に基づき、なじみのある形式で日時を表示するのに便利です。

### サンプル: 日時フォーマットのための `$td` の使用

```vue
<template>
  <div>
    <!-- 全オプション付きで日付をフォーマット -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- 出力: 'en-US' ロケールで "Friday, September 1, 2023" -->

    <!-- 時刻付きで日付をフォーマット -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- 出力: 'en-US' ロケールで "10:15:30 AM" -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ 相対日付フォーマットのための `$tdr` の使用

`$tdr` 関数は、`Intl.RelativeTimeFormat` API を使って、現在のロケールに従って日付を相対時間(例: 「5 分前」、「2 日前」)としてフォーマットします。これは、現在の日時に対する時間差を表示するのに便利です。

### サンプル: 相対日付フォーマットのための `$tdr` の使用

```vue
<template>
  <div>
    <!-- 相対時間として日付をフォーマット -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- 出力: 'en-US' ロケールで "5 minutes ago" -->

    <!-- 未来の日付をフォーマット -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- 出力: 'en-US' ロケールで "in 1 day" -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
