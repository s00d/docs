# 📚 Nuxt I18n Micro のサンプルと使い方

このセクションでは、Nuxt.js アプリケーションで `Nuxt I18n Micro` を利用する方法を、さまざまな例で示します。ロケールを切り替える方法、`<i18n-link>`、`<i18n-switcher>`、`<i18n-t>` の各コンポーネントの使い方、そして翻訳キーを動的に扱う方法を確認できます。

## 🛠️ 基本セットアップ

`Nuxt I18n Micro` を始めるための基本セットアップは以下のとおりです:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 ロケールの切り替え

### プログラマティックなロケール切り替え

以下は、ボタンを使ってプログラマティックにロケールを切り替える例です:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### ロケール切り替え用の JSON 例

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### `<i18n-switcher>` コンポーネントの利用

`<i18n-switcher>` コンポーネントは、ラベルをカスタマイズできるドロップダウンでロケール切り替えを提供します:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 🌐 `<i18n-link>` によるローカライズされたナビゲーション

`<i18n-link>` コンポーネントは、ロケール固有のルーティングを自動的に処理します:

```vue
<template>
  <div>
    <i18n-link to="/about">{{ $t('about') }}</i18n-link>
    <i18n-link :to="{ name: 'index' }">{{ $t('home') }}</i18n-link>

```

### ナビゲーションリンク用の JSON 例

```json

  "about": "About Us",
```

## 📝 翻訳ファイルから動的なキーをレンダリングする

シナリオによっては、翻訳ファイルに格納された動的なキーを反復処理し、条件付きで値を表示したい場合があります。以下の例では、`Nuxt I18n Micro` でこれを実現する方法を示します。

### 例: 動的なキーのレンダリング

この例では、特定の翻訳パス（ここでは `dynamic`）からキーの配列を取得し、それを反復処理します。各キーは `$has` で存在確認を行った上で `$t` を使って値をレンダリングします。

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### 翻訳ファイル（`en.json`）の例

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### 例: オブジェクトから動的にキーをレンダリング

この例では、翻訳ファイル内に格納されたオブジェクトを扱います。オブジェクトのキーを取得して反復処理し、キー名と対応する値を動的にレンダリングします。

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### 翻訳ファイル（`en.json`）の例

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 `<i18n-t>` によるスロットと補間を使った翻訳

`<i18n-t>` コンポーネントは、動的なコンテンツや HTML タグを含む翻訳のレンダリングに便利です:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### `<i18n-t>` 用の JSON 例

```json
{
  "greeting": "Welcome to the page"
}
```

### 補間ありの場合

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### 補間用の JSON 例

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 `$tc` による複数形処理

`Nuxt I18n Micro` の `$tc` 関数は、件数とロケール設定に基づいて複数形処理を行います。件数によって文言が変化するメッセージ（アイテム数、通知、その他の数量に応じて変わるもの）を動的に切り替えたいときに便利です。

### 例: `$tc` を使った複数形処理

以下の例では、リンゴの数を表すメッセージを `$tc` で表示しています。翻訳キーは、渡された件数に応じて複数の複数形パターンを扱います。

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### 複数形処理用の JSON 例

異なる複数形パターンを扱うために、JSON ファイル内で翻訳を次のように定義できます:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### 解説

- **`$tc('apples', 0)`**: 件数がゼロのときに使われる最初の形式（`"no apples"`）を返します。
- **`$tc('apples', 1)`**: 件数が 1 のときに使われる 2 番目の形式（`"one apple"`）を返します。
- **`$tc('apples', 10)`**: 件数が 2 以上のときに使われる、件数付きの 3 番目の形式（`"10 apples"`）を返します。

### より複雑な複数形処理の追加例

アプリケーションで、より複雑な複数形ルール（zero、one、two、few、many、other など特定のケース）を扱う必要がある場合、翻訳文字列を次のように拡張できます:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: `"two apples"` を返すよう設定できます。
- **`$tc('apples', 3)`**: 件数に対して定義されたルールに応じて `"a few apples"` を返すよう設定できます。

## 🌐 `$tn` による数値フォーマット

`$tn` 関数は、`Intl.NumberFormat` API を用いて現在のロケールに応じた数値フォーマットを行います。ユーザーの地域設定に合わせて、通貨、パーセンテージ、その他の数値表現で数字を表示したい場合に便利です。

### 例: `$tn` を使った数値フォーマット

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ `$td` による日付・時刻フォーマット

`$td` 関数は、`Intl.DateTimeFormat` API を用いて現在のロケールに応じた日付と時刻のフォーマットを行います。ロケール設定に基づいて、ユーザーになじみのある形式で日付と時刻を表示するのに便利です。

### 例: `$td` を使った日付・時刻フォーマット

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ `$tdr` による相対日付フォーマット

`$tdr` 関数は、`Intl.RelativeTimeFormat` API を用いて、現在のロケールに応じた相対時間形式（例: 「5 分前」「2 日前」）で日付をフォーマットします。現在時刻を基準とした時間差を表示するのに便利です。

### 例: `$tdr` を使った相対日付フォーマット

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
