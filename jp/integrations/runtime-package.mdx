`@i18n-micro/runtime` はフレームワークに依存しない i18n インスタンスです: 辞書、`t()`、複数形、`Intl` フォーマット、変更の購読を提供し、`fs` もフレームワークも使いません。プレーンな TypeScript、Web ワーカー、エッジ関数で使用したり、独自のバインディングの基盤として使用したりできます。React、Preact、Node、Astro の各パッケージはこの同じクラスを拡張しています。

## インストール {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/runtime
```

```bash npm
npm install @i18n-micro/runtime
```

```bash yarn
yarn add @i18n-micro/runtime
```

</CodeGroup>

ピア依存関係はありません。ディスク上の翻訳ファイルには [`@i18n-micro/node`](/jp/integrations/nodejs-package) を使用してください。

## セットアップ {#setup}

```ts
import { createI18n } from '@i18n-micro/runtime'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    en: { greeting: 'Hello, {name}!', apples: 'no apples | one apple | {count} apples' },
    de: { greeting: 'Hallo, {name}!' },
  },
  routeMessages: {
    about: { en: { title: 'About us' } },
  },
})
```

すべてのオプション(`plural`、`missingWarn`、`missingHandler`、`numberFormats`、`datetimeFormats`)は[インスタンス](/jp/integrations/overview#the-instance)に記載されています。

## 翻訳する {#translate}

```ts
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.tc('apples', 5) // '5 apples'
i18n.tn(1234.5) // '1,234.5'

i18n.setRoute('about')
i18n.t('title') // 'About us' (route dictionary)
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!' (root, still visible)
```

後から辞書を追加で読み込む:

```ts
i18n.loadMessages({ fr: { greeting: 'Bonjour, {name} !' } }, { about: { fr: { title: 'À propos' } } })
i18n.addTranslations('fr', { nav: { home: 'Accueil' } }) // deep merge; pass false to replace

await i18n.loadFromUrl('/locales/fr.json', { locale: 'fr' })
await i18n.loadFromUrl('/locales/pages/about/fr.json', { locale: 'fr', routeName: 'about' })
await i18n.loadFromUrls([
  { url: '/locales/en.json', locale: 'en' },
  { url: '/locales/de.json', locale: 'de' },
])
```

`loadFromUrl` は `fetch` を使用し(ヘッダーには `init` を渡します)、OK でないレスポンスでは例外を投げます。`loadFromUrls` は 1 つずつ順に読み込みます。

## ロケールを切り替える {#switch-locale}

```ts
i18n.locale = 'de'
i18n.t('greeting', { name: 'Ada' }) // 'Hallo, Ada!'
```

ロケール、ルート、辞書の変更は購読者に通知されます。フレームワークバインディングはこれで再レンダリングします:

```ts
const stop = i18n.subscribe(() => {
  document.querySelector('#greeting')!.textContent = i18n.t('greeting', { name: 'Ada' }) as string
})
i18n.locale = 'fr'
stop()
```

`getSnapshot()` は通知のたびに変わる文字列を返します(`useSyncExternalStore` 形式のストア向け)。

## リクエストごと {#per-request}

インスタンスは 1 つのロケールと 1 つのルートを保持します。サーバー上では、共有インスタンスをリクエストごとに切り替えないでください。同時に 2 つのリクエストがあると、互いのロケールが見えてしまいます。`i18n.fork(locale)` はリクエストに独自のインスタンスを与えます: 独自のロケール、フォールバック、ルートを持ち、辞書、フォーマッター、ルールは共有します。フォークのコストは辞書の数にかかわらず同じです。フォークは自身が最初に書き込むまでは親への書き込みが見え、フォークでの書き込みはフォーク内に留まります。[Node.js](/jp/integrations/nodejs-package#per-request) では `run` が追加されます。

## API {#api}

| メンバー | 備考 |
| --- | --- |
| `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has` | [翻訳とフォーマット](/jp/integrations/overview#translate-and-format)を参照 |
| `locale`, `fallbackLocale` | get/set |
| `currentRoute`, `setRoute(name)`, `getRoute()` | アクティブなルート、デフォルトは `'index'` |
| `loadMessages(messages?, routeMessages?)` | 複数のロケールとルートを一度にマージ |
| `addTranslations(locale, tree, merge = true)`, `addRouteTranslations(locale, route, tree, merge = true)` | |
| `loadFromUrl(url, { locale?, routeName?, init? })`, `loadFromUrls(entries)` | JSON を `fetch` |
| `hasTranslation(key)` | アクティブなロケール、任意のルート(アクティブなルートとルート共通を確認する `has` とは異なる) |
| `setTranslation(key, value)`, `resolveTranslations()` | 1 つのキーを書き込む; マージされたツリーを読み取る |
| `clear()`, `clearCache()` | すべての辞書を破棄 |
| `subscribe(cb)`, `getSnapshot()` | 変更通知 |
| `storage` | `{ translations: Map<'locale:route', Translations> }` |

言語タグではないコードは、`localeIso: { ua: 'uk-UA' }` から複数形ルールを取得します。`localeIsoMap(locales)` は、ロケールリストのうち `iso` を持つエントリからそれを構築します。

モジュールのエクスポート: `createI18n`、`I18n`、`fetchJsonTranslations`、`FormatService`、`interpolate`、`localeIsoMap`、および型 `I18nOptions`、`LoadFromUrlOptions`、`LoadFromUrlEntry`、`TranslationStorage`、`Translations`、`Locale`、`PluralFunc`。完全なシグネチャ: [パッケージリファレンス](/jp/api/packages/runtime)。
