# 統合

`@i18n-micro` パッケージは、さまざまなフレームワークや環境への統合用に設計された、Nuxt I18n Micro の軽量・フレームワーク固有バージョンです。これらのパッケージは、必須の翻訳機能と基本コンポーネントに焦点を当てた、最小限のフットプリントでコアの国際化機能を提供します。

## 概要

これらの統合パッケージは完全版の Nuxt I18n Micro モジュールの**縮小版**であり、国際化に必要な必須機能のみを含みます。

- **コア翻訳機能** — 基本的な翻訳メソッド、複数形処理、フォーマット
- **必須コンポーネント** — 一般的な i18n タスク用の小さな UI コンポーネントセット
- **ルーターアダプターパターン** — アダプター抽象化による柔軟なルーティング統合
- **TypeScript サポート** — 型安全な開発のための完全な型定義

Nuxt モジュールの完全版とは異なり、これらのパッケージは以下のとおりです。

- フレームワーク固有のルーティングロジックを含みません。
- ルーティング機能にはルーターアダプターの実装が必要です。
- フレームワーク統合よりも翻訳機能に焦点を当てています。
- 可能な限り軽量でフレームワーク非依存になるよう設計されています。

## コアコンポーネント

すべてのフレームワークパッケージには、以下の必須コンポーネントが含まれます。

### `<I18nT>`

以下をサポートして翻訳テキストをレンダリングする翻訳コンポーネントです。

- **パラメーター補間** — プレースホルダーを動的な値で置換
- **複数形処理** — カウントに基づく自動的な複数形選択
- **数値フォーマット** — ロケールに従った数値フォーマット
- **日付フォーマット** — 日付と相対時間のフォーマット
- **HTML レンダリング** — オプションで HTML コンテンツをレンダリング
- **デフォルト値** — 翻訳が欠落している場合のフォールバックテキスト

**例:**

```vue
<!-- Vue -->
<I18nT keypath="greeting" :params="{ name: 'World' }" />
```

```tsx
// React
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```tsx
// Solid
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```astro
<!-- Astro -->
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

### `<I18nLink>`

URL のロケールプレフィックスを自動的に処理するローカライズリンクコンポーネントです。特徴:

- **自動パスローカライズ** — ルーティング戦略に基づいてロケールプレフィックスを追加/削除
- **アクティブ状態検出** — 現在のルートをハイライト
- **外部リンクサポート** — 外部 URL を自動的に検出して処理
- **ルーター統合** — 利用可能な場合はルーターアダプターのリンクコンポーネントを使用
- **カスタムスタイリング** — アクティブとホバー状態をサポート

**例:**

```vue
<!-- Vue -->
<I18nLink to="/about" active-class="active">
  About Us
</I18nLink>
```

```tsx
// React
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```tsx
// Solid
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```astro
<!-- Astro -->
<I18nLink href="/about" class="nav-link">
  About Us
</I18nLink>
```

### `<I18nSwitcher>`

ロケール変更用のドロップダウンまたはリストインターフェースを提供する言語切り替えコンポーネントです。特徴:

- **自動ロケールリスト** — 設定されたロケールからオプションを生成
- **現在のロケールのハイライト** — アクティブな言語を視覚的に示す
- **カスタムラベル** — ロケールごとのカスタム表示名をサポート
- **ルーター統合** — ローカライズされたパスに自動的に遷移
- **アクセシビリティ** — 適切な ARIA 属性とキーボードナビゲーション

**例:**

```vue
<!-- Vue -->
<I18nSwitcher />
```

```tsx
// React
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```tsx
// Solid
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```astro
<!-- Astro -->
<I18nSwitcher />
```

### `<I18nGroup>`

共通のプレフィックスで翻訳をグループ化するコンポーネントで、ページや機能ごとに翻訳を整理するのに便利です。特徴:

- **プレフィックススコープ** — グループ内のすべての翻訳キーに自動的にプレフィックスを付加
- **ネストされたグループ** — ネストされた翻訳グループをサポート
- **クリーンな整理** — 整理された翻訳構造の維持を支援

**例:**

```vue
<!-- Vue -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- "home.title" を使用 -->
  <I18nT keypath="description" /> <!-- "home.description" を使用 -->
</I18nGroup>
```

```tsx
// React
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* "home.title" を使用 */}
  <I18nT keypath="description" /> {/* "home.description" を使用 */}
</I18nGroup>
```

```tsx
// Solid
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* "home.title" を使用 */}
  <I18nT keypath="description" /> {/* "home.description" を使用 */}
</I18nGroup>
```

```astro
<!-- Astro -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- "home.title" を使用 -->
  <I18nT keypath="description" /> <!-- "home.description" を使用 -->
</I18nGroup>
```

## 共有の `createI18n` オプション \{#create-i18n-options\}

すべてのフレームワークパッケージは同じ方法で作成されます。オプションの型名のみがフレームワークにちなんで命名されます(`ReactI18nOptions`、`SolidI18nOptions` など)。オプション自体は同一です。

| プロパティ         | 型                                                       | 必須 | デフォルト          | 説明                                    |
| ---------------- | ---------------------------------------------------------- | -------- | ---------------- | ---------------------------------------------- |
| `locale`         | `string`                                                   | ✅       | -                | 現在のロケールコード(例: `'en'`)             |
| `fallbackLocale` | `string`                                                   | ❌       | `locale` と同じ | 翻訳が欠落している場合のフォールバックロケール    |
| `messages`       | `Record<string, Translations>`                             | ❌       | `\{\}`             | 初期翻訳メッセージ                   |
| `plural`         | `PluralFunc`                                               | ❌       | `defaultPlural`  | カスタム複数形処理関数                  |
| `missingWarn`    | `boolean`                                                  | ❌       | `true`           | 欠落翻訳に対してコンソール警告を表示 |
| `missingHandler` | `(locale: string, key: string, routeName: string) => void` | ❌       | -                | 欠落翻訳のカスタムハンドラー        |

これら以外はフレームワーク固有で、各パッケージのページで解説されます。

## ルーターアダプター抽象化

すべてのフレームワークパッケージは**ルーターアダプターパターン**を使用して、i18n 機能を特定のルーター実装から分離します。この設計により、以下が可能になります。

- **柔軟性** — 任意のルーターライブラリを使用、またはルーターなしで使用
- **フレームワーク独立性** — ルーティングロジックを i18n パッケージではなくアプリケーション側で維持
- **軽量なコア** — i18n パッケージは小さく、焦点を絞った状態を保つ

### ルーターアダプターの実装

ルーティング機能を使用するには、`I18nRoutingStrategy` インターフェースを実装する必要があります。

```typescript
interface I18nRoutingStrategy {
  getCurrentPath: () => string
  linkComponent?: Component
  push: (target: { path: string }) => void
  replace: (target: { path: string }) => void
  resolvePath?: (to: string | { path?: string }, locale: string) => string | { path?: string }
  getRoute?: () => { fullPath: string; query: Record<string, unknown> }
}
```

各パッケージのドキュメントには、人気のあるルーター用にアダプターを実装する完全な例が含まれています。

- **Vue**: Vue Router アダプターの例
- **React**: React Router アダプターの例
- **Solid**: Solid Router アダプターの例
- **Astro**: ファイルベースのルーティングアダプターの例

## コア機能

すべてのパッケージは以下のコア機能を共有します。

### 翻訳メソッド

- `t()` — パラメーター補間付きの基本的な翻訳
- `ts()` — 常に文字列を返す翻訳
- `tc()` — 複数形対応の翻訳
- `tn()` — 数値フォーマット
- `td()` — 日付フォーマット
- `tdr()` — 相対時間フォーマット
- `has()` — 翻訳キーが存在するか確認

### ロケール管理

- **ロケール切り替え** — プログラム的に現在のロケールを変更
- **フォールバックロケール** — 翻訳が欠落している場合の自動フォールバック
- **ルート固有の翻訳** — ページレベルでの翻訳の整理
- **翻訳キャッシュ** — パフォーマンスのためのインテリジェントなキャッシュ

### TypeScript サポート

すべてのパッケージは以下を提供します。

- 完全な TypeScript 定義
- 型安全な翻訳キー(types generator と組み合わせて)
- IDE での IntelliSense サポート
- コンパイル時のエラーチェック

## はじめに

1. **パッケージを選択** — フレームワークに合ったパッケージを選びます。
2. **パッケージをインストール** — お好みのパッケージマネージャーを使用します。
3. **ドキュメントを読む** — 各パッケージには詳細なセットアップ手順があります。
4. **ルーターアダプターの実装** — ルーティング機能が必要な場合、アダプターを実装します。
5. **翻訳を開始** — コンポーネントとメソッドを使って翻訳を追加します。

詳細なセットアップ手順については、特定のパッケージのドキュメントを参照してください。

- [React パッケージのドキュメント](/integrations/react)
- [Solid パッケージのドキュメント](/integrations/solid)
- [Astro パッケージのドキュメント](/integrations/astro)
