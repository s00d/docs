# 統合

`@i18n-micro` パッケージは、さまざまなフレームワークや環境への統合向けに設計された、Nuxt I18n Micro の軽量なフレームワーク固有バージョンです。これらのパッケージは、必要最小限のフットプリントで、翻訳機能と基本コンポーネントに焦点を絞ったコア国際化機能を提供します。

## 概要

これらの統合パッケージは、完全な Nuxt I18n Micro モジュールの **ミニチュア版** であり、国際化に必要な基本機能のみを含みます:

- **コア翻訳機能** - 基本的な翻訳メソッド、複数形処理、フォーマット
- **必須コンポーネント** - 一般的な i18n タスク向けの小規模な UI コンポーネント群
- **ルーターアダプターパターン** - アダプター抽象化を通じた柔軟なルーティング統合
- **TypeScript サポート** - 型安全な開発のための完全な型定義

完全な Nuxt モジュールと異なり、これらのパッケージは:

- フレームワーク固有のルーティングロジックを含みません
- ルーティング機能を使うにはルーターアダプターの実装が必要です
- フレームワーク統合よりも翻訳機能に焦点を当てています
- 可能な限り軽量でフレームワークに依存しないように設計されています

## コアコンポーネント

すべてのフレームワークパッケージには、以下の必須コンポーネントが含まれています:

### `<I18nT>`

翻訳済みテキストをレンダリングする翻訳コンポーネントで、以下をサポートします:

- **パラメータ補間** - プレースホルダを動的な値で置換
- **複数形処理** - カウントに基づき複数形を自動選択
- **数値フォーマット** - ロケールに沿った数値フォーマット
- **日付フォーマット** - 日付および相対時間のフォーマット
- **HTML レンダリング** - オプションで HTML コンテンツをレンダリング
- **デフォルト値** - 翻訳欠落時のフォールバックテキスト

**例:**

```vue
<!-- Vue -->
<I18nT keypath="greeting" :params="{ name: 'World' }" />
```

```tsx
// React
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```tsx
// Solid
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```astro
<!-- Astro -->
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

### `<I18nLink>`

URL 内のロケールプレフィックスを自動処理する、ローカライズされたリンクコンポーネントです。機能:

- **自動パスローカライズ** - ルーティング戦略に応じてロケールプレフィックスを追加 / 削除
- **アクティブ状態検出** - 現在のルートをハイライト
- **外部リンクサポート** - 外部 URL を自動検出して処理
- **ルーター統合** - 利用可能な場合、ルーターアダプターのリンクコンポーネントを使用
- **カスタムスタイリング** - アクティブ / ホバー状態をサポート

**例:**

```vue
<!-- Vue -->
<I18nLink to="/about" active-class="active">
  About Us
</I18nLink>
```

```tsx
// React
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```tsx
// Solid
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```astro
<!-- Astro -->
<I18nLink href="/about" class="nav-link">
  About Us
</I18nLink>
```

### `<I18nSwitcher>`

ロケール変更のためのドロップダウンまたはリスト形式のインターフェースを提供する言語スイッチャーコンポーネントです。機能:

- **自動ロケール一覧** - 設定済みロケールからオプションを生成
- **現在のロケールのハイライト** - アクティブな言語を視覚的に表示
- **カスタムラベル** - ロケールごとのカスタム表示名をサポート
- **ルーター統合** - ローカライズされたパスへ自動遷移
- **アクセシビリティ** - 適切な ARIA 属性とキーボードナビゲーション

**例:**

```vue
<!-- Vue -->
<I18nSwitcher />
```

```tsx
// React
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```tsx
// Solid
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```astro
<!-- Astro -->
<I18nSwitcher />
```

### `<I18nGroup>`

共通のプレフィックスで翻訳をグループ化するコンポーネントで、ページや機能単位で翻訳を整理するのに有用です。機能:

- **プレフィックススコープ** - グループ内のすべての翻訳キーに自動的にプレフィックスを付与
- **ネストされたグループ** - ネストされた翻訳グループをサポート
- **整った整理** - 整った翻訳構造の維持に役立ちます

**例:**

```vue
<!-- Vue -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

```tsx
// React
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```tsx
// Solid
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```astro
<!-- Astro -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

すべてのフレームワークパッケージは、`@i18n-micro/devtools-ui` の Vite プラグインを通じた DevTools 統合をサポートします。詳細は [DevTools UI パッケージのドキュメント](/integrations/devtools-ui) を参照してください。

## 共通の `createI18n` オプション \{#create-i18n-options\}

すべてのフレームワークパッケージは同じ方法で作成されます — オプション型の名前だけがフレームワークに合わせて変わります（`ReactI18nOptions`、`SolidI18nOptions` など）。オプション自体は同一です:

| プロパティ         | 型                                                       | 必須 | デフォルト          | 説明                                    |
| ---------------- | ---------------------------------------------------------- | -------- | ---------------- | ---------------------------------------------- |
| `locale`         | `string`                                                   | ✅       | -                | 現在のロケールコード（例: `'en'`）             |
| `fallbackLocale` | `string`                                                   | ❌       | `locale` と同じ | 翻訳欠落時のフォールバックロケール    |
| `messages`       | `Record<string, Translations>`                             | ❌       | `\{\}`             | 初期翻訳メッセージ                   |
| `plural`         | `PluralFunc`                                               | ❌       | `defaultPlural`  | カスタム複数形処理関数                  |
| `missingWarn`    | `boolean`                                                  | ❌       | `true`           | 翻訳欠落時にコンソール警告を表示 |
| `missingHandler` | `(locale: string, key: string, routeName: string) => void` | ❌       | -                | 翻訳欠落時のカスタムハンドラー        |

これ以外はフレームワーク固有であり、各パッケージのページにドキュメント化されています。

## ルーターアダプターの抽象化

すべてのフレームワークパッケージは、**ルーターアダプターパターン** を使って i18n 機能を特定のルーター実装から切り離します。この設計により:

- **柔軟性** - 任意のルーターライブラリを利用可能、あるいはルーターなしでも動作
- **フレームワーク非依存** - ルーティングロジックはアプリケーション側に残し、i18n パッケージには持ち込まない
- **軽量なコア** - i18n パッケージは小さく焦点を絞ったまま保たれる

### ルーターアダプターの実装

ルーティング機能を利用するには、`I18nRoutingStrategy` インターフェースを実装する必要があります:

```typescript
interface I18nRoutingStrategy {
  getCurrentPath: () => string
  linkComponent?: Component
  push: (target: { path: string }) => void
  replace: (target: { path: string }) => void
  resolvePath?: (to: string | { path?: string }, locale: string) => string | { path?: string }
  getRoute?: () => { fullPath: string; query: Record<string, unknown> }
}
```

各パッケージのドキュメントには、代表的なルーター向けアダプター実装の完全なサンプルが含まれています:

- **Vue**: Vue Router アダプターの例
- **React**: React Router アダプターの例
- **Solid**: Solid Router アダプターの例
- **Astro**: ファイルベースルーティングアダプターの例

## コア機能

すべてのパッケージは以下のコア機能を共有します:

### 翻訳メソッド

- `t()` - パラメータ補間付きの基本翻訳
- `ts()` - 常に文字列を返す翻訳
- `tc()` - 複数形対応の翻訳
- `tn()` - 数値フォーマット
- `td()` - 日付フォーマット
- `tdr()` - 相対時間フォーマット
- `has()` - 翻訳キーの存在確認

### ロケール管理

- **ロケール切り替え** - 現在のロケールをプログラマティックに変更
- **フォールバックロケール** - 翻訳欠落時の自動フォールバック
- **ルート固有の翻訳** - ページレベルでの翻訳整理
- **翻訳キャッシング** - パフォーマンス向上のための賢いキャッシング

### TypeScript サポート

すべてのパッケージが提供するもの:

- 完全な TypeScript 型定義
- 型安全な翻訳キー（types generator と併用）
- IDE での IntelliSense サポート
- コンパイル時のエラーチェック

## はじめに

1. **パッケージを選ぶ** - 利用フレームワーク向けのパッケージを選択
2. **パッケージをインストール** - 好みのパッケージマネージャーを利用
3. **ドキュメントを読む** - 各パッケージには詳細なセットアップ手順があります
4. **ルーターアダプターの実装** - ルーティング機能が必要ならアダプターを実装
5. **翻訳の開始** - コンポーネントとメソッドを使って翻訳を追加

セットアップ手順の詳細は、利用するパッケージのドキュメントを参照してください:

- [Vue パッケージのドキュメント](/integrations/vue)
- [React パッケージのドキュメント](/integrations/react)
- [Solid パッケージのドキュメント](/integrations/solid)
- [Astro パッケージのドキュメント](/integrations/astro)
