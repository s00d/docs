title: "<i18n-switcher>"

---

`<i18n-switcher>` は、アクティブなロケールを表示するボタンと、アクティブなものを含むすべての有効なロケールのドロップダウンをレンダリングします。既製の言語メニューとして使用してください。異なるマークアップが必要な場合は、[`$getLocales`](/jp/api/methods#$getlocales) と [`$switchLocalePath`](/jp/api/methods#$switchlocalepath) から独自に構築してください。各項目は、そのロケールでの現在のページにリンクします。

## Props とスロット {#props-and-slots}

| Prop | 型 | デフォルト | 説明 |
| --- | --- | --- | --- |
| `customLabels` | `Record<string, string>` | `() => ({})` | ロケールコードごとの表示名。ロケール設定の `displayName` を上書きします。 |
| `customWrapperStyle` | `CSSProperties` | `() => ({})` | 外側のラッパーのインラインスタイル。 |
| `customButtonStyle` | `CSSProperties` | `() => ({})` | ドロップダウンを開くボタンのインラインスタイル。 |
| `customDropdownStyle` | `CSSProperties` | `() => ({})` | ドロップダウンパネルのインラインスタイル。 |
| `customItemStyle` | `CSSProperties` | `() => ({})` | ドロップダウン内の各項目のインラインスタイル。 |
| `customLinkStyle` | `CSSProperties` | `() => ({})` | 項目内のリンクのインラインスタイル。 |
| `customActiveLinkStyle` | `CSSProperties` | `() => ({})` | 現在アクティブなロケールのリンクのインラインスタイル。 |
| `customDisabledLinkStyle` | `CSSProperties` | `() => ({})` | 設定で `disabled: true` になっている場合の、*現在の*ロケールのボタンのインラインスタイル。 |
| `customIconStyle` | `CSSProperties` | `() => ({})` | ボタン上のキャレットアイコンのインラインスタイル。 |

### スロット {#slots}

| スロット | バインディング | 説明 |
| --- | --- | --- |
| `before-button` | — | ドロップダウンを開くボタンの前のコンテンツ。 |
| `before-selected-locale` | — | ボタン内のアクティブなロケールのラベルの前のコンテンツ。 |
| `after-selected-locale` | — | ボタン内のアクティブなロケールのラベルの後のコンテンツ。 |
| `before-dropdown` | — | ボタンとドロップダウンパネルの間のコンテンツ。 |
| `before-dropdown-items` | — | ドロップダウンの上部、ロケールリストの上のコンテンツ。 |
| `before-item` | `locale` | 各ロケール項目の前のコンテンツ。 |
| `before-link-content` | `locale` | リンク内のロケールのラベルの前のコンテンツ。 |
| `after-link-content` | `locale` | リンク内のロケールのラベルの後のコンテンツ。 |
| `after-item` | `locale` | 各ロケール項目の後のコンテンツ。 |
| `after-dropdown-items` | — | ドロップダウンの下部、ロケールリストの下のコンテンツ。 |
| `after-dropdown` | — | ドロップダウンパネルの後のコンテンツ。 |

## 動作 {#behaviour}

- `disabled: true` でないすべてのロケールを、アクティブなものも含めて一覧表示します。
- 各項目は `$switchLocalePath(code)` への `<a>` です。パスは `app.baseURL` の下で解決され、別ドメインのロケール `baseUrl` は絶対 URL のままです。`hreflang` と `lang` には `iso || code` が設定され、ロケールに `dir` がある場合は `dir` が、現在のロケールには `aria-current="page"` が、そしてクラス `switcher-locale-<code>` が付与されます。クリックすると `$switchLocale(code)` が呼び出され、ドロップダウンが閉じます。修飾キーを押しながらクリックした場合はブラウザーに任せます。
- リストはサーバー HTML 内に非表示で残るため、クローラーはリンクを認識できます。Escape キーまたは外側のクリックで閉じます。
- ラベル: `customLabels[code]`、次にロケールの `displayName`、最後にコード（開発時の警告付き）。
- スタイル: 小さなインラインのデフォルト（枠線付きの白いボタンとパネル、アクティブな項目は太字で青）。各 `custom*Style` prop は、対応する部分のデフォルトの後に適用されます。ボタンにはクラス `i18n-switcher-button` と `language-switcher`、ラッパーには `i18n-switcher-wrapper`、リストには `i18n-switcher-dropdown` が付きます。位置指定には論理 CSS プロパティを使用しているため、`dir="rtl"` でも機能します。

## 例 {#example}

```vue
<template>
  <i18n-switcher
    :custom-labels="{ en: 'English', de: 'Deutsch' }"
    :custom-button-style="{ borderRadius: '4px' }"
  >
    <template #before-link-content="{ locale }">
      <img :src="`/flags/${locale.code}.svg`" alt="" width="16" />
    </template>
  </i18n-switcher>
</template>
```
