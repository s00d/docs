`<i18n-t>` は 1 つの翻訳を要素としてレンダリングします。翻訳の中にコンポーネント（文中のリンクなど）、複数形、またはフォーマットされた数値や日付が必要な場合に使用します。`$t` と同様に、現在のルートに対してキーを解決します。

## Props {#props}

| Prop | 型 | デフォルト | 説明 |
| --- | --- | --- | --- |
| `keypath` **\*** | `string` | — | レンダリングする翻訳キー。 |
| `plural` | `number \| string \| null` | — | 複数形を選択するカウント。設定すると `$t` の代わりに `$tc` が使われます。`null` は未設定を意味します。 |
| `tag` | `string` | `'span'` | レンダリングする要素。 |
| `params` | `Record<string, string \| number \| boolean>` | — | 翻訳に代入される補間値。 |
| `defaultValue` | `string` | `''` | `hideIfEmpty` が空の翻訳を抑制した場合に、コンポーネントの代わりにレンダリングされます。 |
| `html` | `boolean` | `false` | 翻訳をテキストではなく HTML としてレンダリングします。自分で管理している翻訳にのみ使用してください。`params` はエスケープされますが、翻訳はエスケープされません。 |
| `hideIfEmpty` | `boolean` | `false` | 翻訳が空文字列に解決された場合は何もレンダリングしません。 |
| `customPluralRule` | `PluralFunc` | `null` | この要素だけに適用される複数形ルールで、設定済みのルールを上書きします。その結果はそのまま使われ、`null` は空としてレンダリングされます。 |
| `number` | `number \| string \| null` | — | 値を `$tn` でフォーマットし、`params` とともに `{number}` として翻訳に渡します。 |
| `date` | `Date \| string \| number \| null` | — | 値を `$td` でフォーマットし、`params` とともに `{date}` として翻訳に渡します。 |
| `relativeDate` | `Date \| string \| number \| null` | — | 値を `$tdr` でフォーマットし、`params` とともに `{relativeDate}` として翻訳に渡します。 |

**\*** 必須。

## レンダリングルール {#rendering-rules}

最初に一致したケースが出力を決定します:

1. `number` — `{ ...params, number: $tn(number) }` を適用した翻訳。
2. `date` — `{ ...params, date: $td(date) }` を適用した翻訳。
3. `relativeDate` — `{ ...params, relativeDate: $tdr(relativeDate) }` を適用した翻訳。
4. `plural` — `$tc` が選ぶ形（[`=0 ` マーカー](/jp/api/methods#$tc)を含む）に `{ ...params, count }` を適用したもの。または設定されている場合は `customPluralRule(keypath, count, params, locale, t)` で、これはマーカーを含む生の値を読み取り、その結果はそのまま使われます（`null` は空）。
5. それ以外は `params` を適用した翻訳。

`null` は未設定として扱われます。すべてのケースで:

- `defaultValue` は、どの分岐でも存在しないキーの代わりになります。
- `hideIfEmpty` は空の結果の代わりに `defaultValue` をレンダリングします。
- `html` は結果を HTML としてレンダリングします。`params` はエスケープされますが、翻訳はエスケープされません。スロットは無視されます。
- `default` スロットは `{ translation }` を受け取り、名前付きスロットは無視されます。
- それ以外の場合、各名前付きスロットはすべての `{name}` プレースホルダーを、同じ名前のパラメーターより先に置き換えます。プレースホルダーのように見えるパラメーター値はテキストのままです。

`date` と `relativeDate` の出力には `data-allow-mismatch="text"` が付きます。サーバーのタイムゾーンと時計はブラウザーのものと異なるためです。[`timeZone`](/jp/api/module-options#timezone) を設定すると、両方で同じカレンダー日付がレンダリングされます。`relativeDate` は時計に依存するため、それでも異なる場合があります。

## 例 {#example}

```json
{
  "terms": "I accept the {link}.",
  "termsLink": "terms of use",
  "items": "no items | one item | {count} items"
}
```

```vue
<template>
  <i18n-t keypath="terms" tag="p">
    <template #link>
      <NuxtLink :to="$localePath('/terms')">{{ $t('termsLink') }}</NuxtLink>
    </template>
  </i18n-t>

  <i18n-t keypath="items" :plural="cart.length" />
</template>
```

`html` は `innerHTML` を設定します。自分で管理している翻訳にのみ使用してください。`params` はエスケープされるため、ユーザーデータはそこでは安全です。翻訳が見つからなかったキーも同様に安全です。
