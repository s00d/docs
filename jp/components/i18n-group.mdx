title: "<i18n-group>"

---

`<i18n-group>` はマークアップのブロックを 1 つのキープレフィックスにスコープします。セクション内の多くのキーが同じプレフィックスを共有しており、それを繰り返し書きたくない場合に使用します。デフォルトスロットは、プレフィックスを先頭に付加する `t` を受け取ります。

## Props とスロット {#props-and-slot}

| Prop | 型 | デフォルト | 説明 |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | スロット内のすべての参照が解決される基準となるキープレフィックス。 |
| `groupClass` | `string` | `''` | ラッパー要素に追加するクラス。 |

**\*** 必須。

### スロット {#slots}

| スロット | バインディング | 説明 |
| --- | --- | --- |
| `default` | `prefix`, `t` | `prefix` と、それにスコープされた `t` 関数を受け取ります。 |

## 動作 {#behaviour}

- スロットの周囲に `<div class="i18n-group {groupClass}">` をレンダリングします。
- `t(key, params)` は現在のルートに対する `$t(prefix + '.' + key, params)` です。
- スコープされるのはスロットの `t` だけです。グループ内の `$t` やネストされた `<i18n-t>` は引き続き完全なキーを受け取ります。

## 例 {#example}

```json
{
  "checkout": { "title": "Checkout", "items": "Items: {count}" }
}
```

```vue
<template>
  <i18n-group prefix="checkout" group-class="checkout">
    <template #default="{ t }">
      <h2>{{ t('title') }}</h2>
      <p>{{ t('items', { count: 3 }) }}</p>
    </template>
  </i18n-group>
</template>
```
