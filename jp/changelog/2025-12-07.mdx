![v2.14 リリース](/images/2.14.0.png)

**v2.14.1** をリリースしました。Node.js、Vue 3、Astro 向けのまったく新しいインテグレーションが加わりました！これらのパッケージは、同じ強力な i18n 機能をお気に入りのフレームワークにもたらし、一貫性とパフォーマンスのために同じコアロジックを共有しています。

## 新機能 {#what’s-new}

- **@i18n-micro/node** - 任意の Node.js アプリケーション、CLI ツール、バックエンドサービスで i18n の翻訳を使用できます
- **@i18n-micro/vue** - リアクティブな翻訳とルート固有のサポートを備えた、国際化のための Vue 3 プラグイン
- **@i18n-micro/astro** - 完全な TypeScript サポートを備えた、国際化のための Astro インテグレーション
- **@i18n-micro/types-generator** - 翻訳キーの TypeScript 型を自動生成し、完全な型安全性と IDE の自動補完を提供します

## 主な機能 {#key-features}

すべてのインテグレーションは同じコアのメリットを共有しています:

- 軽量で高パフォーマンス
- ルート固有の翻訳をサポート
- 組み込みの複数形処理
- 数値、日付、相対時間のフォーマット
- 完全な TypeScript サポート
- 同じ JSON 翻訳ファイル構造

**Types Generator** は、開発者体験をさらに向上させます:

- JSON 翻訳ファイルからの型の自動生成
- コンパイル時に検証される型安全な翻訳キー
- IDE の自動補完を完全にサポート
- 翻訳ファイルの変更時のホットリロード
- ランタイムのオーバーヘッドなし

詳しいドキュメントと例については、[リポジトリ](https://github.com/s00d/nuxt-i18n-micro)にアクセスするか、[ドキュメント](https://s00d.github.io/nuxt-i18n-micro/)をご覧ください。
