![v1.1.0 CLI text-to-i18n のデモ](/images/text-to-i18n.gif)

Nuxt I18n Micro CLI の新しい `text-to-i18n` コマンドを発表できることを嬉しく思います!この強力な機能は、コードベースからハードコードされたテキスト文字列を抽出し、i18n 翻訳キーに変換するプロセスを自動化します。時間を節約し、ミスを減らし、ローカライズのワークフローを効率化するよう設計されています。

## 主な利点 {#key-benefits}

- **テキストの自動抽出**: Vue テンプレート、JavaScript、TypeScript ファイルをスキャンします。
- **シームレスなキー生成**: ファイルパスと内容に基づいて構造化された翻訳キーを作成します。
- **効率的な翻訳管理**: 既存のエントリを保持しながら翻訳ファイルを更新します。

## 仕組み {#how-it-works}

1. **ファイルスキャン**: `pages`、`components`、`plugins` などの主要ディレクトリ内のファイルを処理します。
2. **テキスト処理**: 翻訳可能な文字列を識別・抽出し、一意のキーを生成します。
3. **翻訳の更新**: 新しいキーを翻訳ファイルに自動的に挿入し、ネスト構造を維持します。

## 使い方 {#usage}

```bash
i18n-micro text-to-i18n [options]
```

例:

```bash
i18n-micro text-to-i18n --translationFile locales/en.json --context auth
```

## 変換の例 {#example-transformations}

### 変換前 {#before}

```vue
<template>
  <div>
    <h1>Welcome to our site</h1>
    <p>Please sign in to continue</p>
  </div>
</template>
```

### 変換後 {#after}

```vue
<template>
  <div>
    <h1>{{ $t('pages.home.welcome_to_our_site') }}</h1>
    <p>{{ $t('pages.home.please_sign_in') }}</p>
  </div>
</template>
```
