# 🧪 `Nuxt I18n Micro` モジュールのテスト

## 📖 テストのはじめに

`Nuxt I18n Micro` モジュールのテストは、アプリケーションのローカライズ機能が期待通り動作することを保証するために重要です。このドキュメントでは、テスト環境のセットアップ、vitest 向けモック設定の作成、そしてコンポーネントに対するテスト作成の手順を解説します。実践的な例は、[GitHub のサンプルプロジェクト](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/test-utils/example) を参照してください。

このリポジトリ自身のテストスイートの実行方法 — `unit` / `integration` / `e2e` の Vitest プロジェクト、戦略ごとのファイル（`test/strategies-*.test.ts`）、リグレッション生成 — については [Testing routing strategies](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/testing-strategies.md) を参照してください。

## 🛠️ テスト環境のセットアップ

### 1. `@i18n-micro/test-utils` のインストール

まず、`Nuxt I18n Micro` 用のテストユーティリティをインストールします。このパッケージは、i18n 設定をモックしてテストするために必要なツールを提供します。

```bash
npm install @i18n-micro/test-utils --save-dev
```

### 2. モック設定ファイルの作成

次に、モックの i18n 設定をセットアップするファイルを作成します。このファイルは、テスト実行中に i18n の関数やユーティリティをモックするために利用されます。

```typescript
// tests/unit-setup.ts

import { mockNuxtImport } from '@nuxt/test-utils/runtime'
import { vi } from 'vitest'
import { i18nUtils } from '@i18n-micro/test-utils'

export function createFakeI18n() {
  return {
    $getLocale: vi.fn(i18nUtils.getLocale),
    $t: vi.fn(i18nUtils.t),
    $tc: vi.fn(i18nUtils.tc),
    $setLocale: vi.fn(i18nUtils.setLocale),
    $getLocaleName: vi.fn(i18nUtils.getLocaleName),
    $setLocaleName: vi.fn(i18nUtils.setLocaleName),
    $getLocales: vi.fn(i18nUtils.getLocales),
    $setLocales: vi.fn(i18nUtils.setLocales),
    $defaultLocale: vi.fn(i18nUtils.defaultLocale),
    $setDefaultLocale: vi.fn(i18nUtils.setDefaultLocale),
    $getRouteName: vi.fn(i18nUtils.getRouteName),
    $settRouteName: vi.fn(i18nUtils.settRouteName),
    $ts: vi.fn(i18nUtils.ts),
    $tn: vi.fn(i18nUtils.tn),
    $td: vi.fn(i18nUtils.td),
    $has: vi.fn(i18nUtils.has),
    $resolveTranslations: vi.fn(i18nUtils.resolveTranslations),
    $setTranslation: vi.fn(i18nUtils.setTranslation),
    $mergeTranslations: vi.fn(i18nUtils.mergeTranslations),
    $switchLocaleRoute: vi.fn(i18nUtils.switchLocaleRoute),
    $switchLocalePath: vi.fn(i18nUtils.switchLocalePath),
    $switchLocale: vi.fn(i18nUtils.switchLocale),
    $switchRoute: vi.fn(i18nUtils.switchRoute),
    $localeRoute: vi.fn(i18nUtils.localeRoute),
    $localePath: vi.fn(i18nUtils.localePath),
    $setI18nRouteParams: vi.fn(i18nUtils.setI18nRouteParams),
  }
}

mockNuxtImport<() => ReturnType<typeof createFakeI18n>>('useI18n', () => vi.fn(() => createFakeI18n()))

export const setTranslationsFromJson = i18nUtils.setTranslationsFromJson
```

### 3. Vitest の設定

続いて、モック設定ファイルを使うように Vitest を設定し、テスト環境を整えます。

```typescript
// vitest.config.ts

import { defineVitestConfig } from '@nuxt/test-utils/config'

export default defineVitestConfig({
  test: {
    watch: false,
    setupFiles: ['./tests/unit-setup.ts'],
    include: ['./**/*.spec.ts'],
  },
})
```

## 🧪 テストの作成

### コンポーネントの例

以下は、`useI18n` コンポーザブルを使ってメッセージを翻訳するシンプルなコンポーネントの例です。

```vue
<script setup lang="ts">
const { $t } = useI18n()

const props = defineProps({
  message: {
    type: String,
    default: null,
  },
})

// Test to see that $t works in script setup as well as the template
const message = props.message || $t('defaultMessage')
</script>

<template>
  <div>
    <p>Test from component: {{ $t('welcome') }}</p>
    <p data-testid="message">Test message from props: {{ message }}</p>
  </div>
</template>
```

### テストファイル

このコンポーネント向けのテストを書いてみましょう。

```typescript
// tests/unit/example.spec.ts

import { describe, it, expect, beforeEach } from 'vitest'
import { mount } from '@vue/test-utils'
import ExampleComponent from '@/components/ExampleComponent.vue'
import fs from 'fs'
import path from 'path'
import { setTranslationsFromJson } from './unit-setup'

describe('ExampleComponent', () => {
  beforeEach(async () => {
    const fileContent = fs.readFileSync(path.join(__dirname, '../../locales/en-GB.json')).toString()
    await setTranslationsFromJson('en', JSON.parse(fileContent))
  })

  it('renders the welcome message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.text()).toContain('Test from component: Welcome')
  })

  it('renders the default message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Default Message')
  })

  it('renders the custom message correctly', () => {
    const wrapper = mount(ExampleComponent, {
      props: {
        message: 'Custom Message',
      },
    })
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Custom Message')
  })
})
```

## 📝 テストのベストプラクティス

- **🔧 i18n 関数のモック化:** `@i18n-micro/test-utils` を使って i18n 関数を必ずモックし、一貫性がありかつ予測可能なテスト結果を確保しましょう。
- **⚙️ ユニットテストに Vitest を使う:** Vitest は Vue アプリケーション向けの強力なテスティングフレームワークです。コンポーネントのユニットテストに利用しましょう。
- **📚 テストをドキュメント化:** 各テストの目的と期待される結果を明確に記述しましょう。これは明確さを保ち、他のメンバー（あるいは未来の自分）がテストを理解しやすくします。

## 📊 i18n ユーティリティメソッド

以下は `@i18n-micro/test-utils` が提供するユーティリティメソッドの一覧です。

| メソッド                                          | 説明                                                                                                                                |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `t(key, params, defaultValue)`                  | オプションのパラメータとデフォルト値を伴い、キーを翻訳します。                                                                             |
| `tc(key, params, defaultValue)`                 | 複数形サポート付きでキーを翻訳します。                                                                                               |
| `setTranslationsFromJson(locale, translations)` | 特定ロケール用に JSON オブジェクトから翻訳を読み込みます。                                                                               |
| `getLocale()`                                   | 現在のロケールを返します。                                                                                                                |
| `setLocale(val)`                                | 現在のロケールを設定します。                                                                                                                   |
| `getLocaleName()`                               | 現在のロケール名を返します。                                                                                                           |
| `setLocaleName(val)`                            | 現在のロケール名を設定します。                                                                                                              |
| `getLocales()`                                  | 利用可能なロケール一覧を返します。                                                                                                     |
| `setLocales(val)`                               | 利用可能なロケール一覧を設定します。                                                                                                        |
| `defaultLocale()`                               | デフォルトロケールを返します。                                                                                                                |
| `setDefaultLocale(val)`                         | デフォルトロケールを設定します。                                                                                                                   |
| `getRouteName()`                                | 現在のルート名を返します。                                                                                                            |
| `settRouteName(val)`                            | 現在のルート名を設定します。                                                                                                               |
| `ts(key, params, defaultValue)`                 | キーを翻訳し、結果を文字列として返します。                                                                                       |
| `tn(value, options?)`                           | インラインの `Intl.NumberFormatOptions` で数値をフォーマットします。名前付きフォーマットはモジュール設定が必要で、このスタンドアロンヘルパーでは利用できません。 |
| `td(value, options?)`                           | インラインの `Intl.DateTimeFormatOptions` で日付をフォーマットします。名前付きフォーマットはモジュール設定が必要で、このスタンドアロンヘルパーでは利用できません。 |
| `has(key)`                                      | 翻訳キーが存在するかを確認します。                                                                                                        |
| `resolveTranslations()`                             | 現在のロケールとルートに対する、アクティブな翻訳ツリーを返します。                                                                      |
| `setTranslation(key, value)`                    | アクティブな辞書内の `key` の値を置き換えます（マージではなく置換）。                                                                 |
| `mergeTranslations(newTranslations)`              | ランタイムでアクティブロケールへ翻訳をマージします。                                                                                     |

これらの手順に従うことで、`Nuxt I18n Micro` モジュールを効果的にテストし、アプリケーションのローカライズ機能が期待通りに動作することを確認できます。
