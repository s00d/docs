# 🌐 Crowdin 統合ガイド

## 📖 はじめに

Crowdin をプロジェクトに統合すると、ローカライズと翻訳のプロセスが効率化され、複数の言語やプラットフォームにまたがる翻訳の管理が容易になります。このガイドでは、設定・ソースのアップロード・翻訳のダウンロードなど、プロジェクトでの Crowdin セットアップを段階的に解説します。

## 🔧 インストールとセットアップ

Crowdin を始めるには、Crowdin CLI をマシン上にグローバルインストールし、プロジェクトディレクトリで初期化する必要があります。

### 📦 Crowdin CLI のインストール

まず、npm で Crowdin CLI をグローバルインストールします:

```bash
npm install -g @crowdin/cli
```

### 🛠 プロジェクトで Crowdin を初期化する

プロジェクトで Crowdin を初期化するには次を実行します:

```bash
crowdin init
```

このコマンドは、プロジェクト ID、API トークン、その他の設定を含むセットアップ手順をガイドします。

## 🗂️ 設定ガイド

### 📄 Crowdin 設定ファイル（`crowdin.yml`）

Crowdin 設定ファイル（`crowdin.yml`）は、ソースファイルのマッピングと、翻訳の配置先を定義します。以下は設定例です:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 主な設定パラメータ

- **`project_id`**: Crowdin プロジェクト ID。翻訳が管理される Crowdin 上のプロジェクトを識別します。
- **`api_token`**: 認証に使用する API トークン。翻訳をアップロード・ダウンロードするための適切な権限があることを確認してください。
- **`base_path`**: ソースファイルのベースディレクトリを指定します。この例では、翻訳は `./locales` ディレクトリに保存されています。
- **`base_url`**: Crowdin API のベース URL。
- **`preserve_hierarchy`**: `true` に設定すると、Crowdin はソースファイルのフォルダ構造をプロジェクト内で維持します。

### 📂 Files 設定

`files` セクションは、ソースファイルを翻訳が保存されるパスにマッピングします。例:

- **ソースパス**: 元となる翻訳ファイルの場所を定義します。
- **翻訳パス**: 翻訳ファイルが Crowdin 上でどこに保存されるかを指定します。`%two_letters_code%` のようなプレースホルダを使って、ファイルパス内の言語コードを動的に設定できます。

## ⬆️ ソースファイルを Crowdin にアップロードする

Crowdin 設定が完了したら、次のコマンドでソースファイルをアップロードできます:

```bash
crowdin upload sources
```

このコマンドは、設定内で指定されたすべてのソースファイルを Crowdin にアップロードし、翻訳可能な状態にします。

## ⬇️ Crowdin から翻訳をダウンロードする

Crowdin で翻訳が完了または更新された後、以下でプロジェクトへダウンロードできます:

```bash
crowdin download
```

このコマンドは Crowdin から最新の翻訳を取得し、設定ファイルで指定されたパスに従って保存します。

## ⚙️ ベストプラクティス

### 🔑 一貫したキー命名

混乱と重複を避けるため、翻訳キーはすべてのファイル間で一貫させます。

### 🧹 定期的なメンテナンス

未使用の翻訳キーを定期的に見直して整理し、ファイルを整った状態に保ちます。

### 🛠 アップロード / ダウンロードの自動化

Crowdin CLI コマンドを CI/CD パイプラインに組み込み、ソースファイルのアップロードと翻訳のダウンロードを自動化することで、翻訳を常に最新の状態に保てます。

このガイドに従うことで、Crowdin をプロジェクトにシームレスに統合し、国際化業務を効率的かつ整った形で管理できます。
