# 🛠️ `nuxt-i18n-micro` の DevTools

## Vue DevTools（ブラウザ拡張）

開発時、モジュールは `@vue/devtools-api` を介して **Vue DevTools** のカスタムインスペクタとタイムラインを登録できます。これは以下の Nuxt DevTools タブとは別物です。

| ツール | 得意分野 |
|------|----------|
| **Vue DevTools** | 現在のロケール、インメモリ翻訳キャッシュ、`$t` タイムライン（`debug: true`）、欠落キーイベント |
| **Nuxt DevTools タブ** | ディスク上の JSON ファイル編集、設定の概要、インポート / エクスポート |

vue-devtools プラグインは `nuxt dev` 中のみ登録されます（本番ビルドには含まれません）。メインプラグイン内の開発専用ブリッジ状態は、`import.meta.dev` のデッドコード削除によって取り除かれます。

Nuxt タブを保持したままブラウザ統合を無効化するには:

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

詳細な `$t` タイムラインイベントは `debug: true` が必要です。

## 📖 Nuxt DevTools とは？

DevTools は、`nuxt-i18n-micro` モジュールにシームレスに統合された強力な開発支援機能です。ローカライズと翻訳タスクを管理するための直感的なインターフェースを提供し、ワークフローをより高速かつ効率的にします。利便性を重視する開発者向けに設計されており、Nuxt DevTools はコーディングとランタイム管理のギャップを埋めます。

## 🌟 `nuxt-i18n-micro` の DevTools の主な機能

### 1. **ロケール管理**

アプリケーションのロケールを簡単に閲覧、選択、管理できます。単一言語でも複数言語でも、DevTools はすべてのローカライズ設定を扱う中央ハブを提供します。

### 2. **翻訳の編集**

統合された JSON エディタで翻訳ファイルを直接編集できます。これにより外部ツールが不要になり、ワークフローを中断することなくリアルタイムで更新と変更が可能です。

### 3. **ファイルのインポートとエクスポート**

翻訳ファイル管理のプロセスを簡素化します:

- **エクスポート**: バックアップや外部利用のために翻訳を JSON ファイルとして保存。
- **インポート**: 更新された翻訳ファイルをプロジェクトに読み込み、コンテンツを最新に保つ。

### 4. **リアルタイムプレビュー

開発環境内で変更を即座に確認できます。本番リリース前に翻訳と設定が正確であることを保証します。

### 5. **シームレスな Nuxt 統合**

DevTools は `nuxt-i18n-micro` とネイティブに動作し、追加のセットアップなしに機能を拡張します。Nuxt のモジュラーで柔軟な構造を維持しながら、ローカライズニーズに適応します。

## 🛠️ なぜ DevTools を使うのか？

Nuxt DevTools は、ローカライズが必要なプロジェクトにとって欠かせない追加機能です。以下の点で開発者を支援します:

- **時間の節約**: ファイル管理やフォーマット検証などの繰り返し作業を自動化。
- **エラー削減**: 翻訳編集のための安全で直感的な環境を提供。
- **コラボレーションの改善**: 非開発者でも翻訳を簡単に管理可能。
- **ワークフローの効率化**: 複数のローカライズタスクを 1 つのインターフェースに集約。

---

## 🚀 ローカライズを掌握する

Nuxt DevTools を `nuxt-i18n-micro` に統合することで、多言語アプリケーションの管理が簡単かつ効率的になります。翻訳の微調整でも、新しいロケールの追加でも、DevTools は洗練されたユーザーフレンドリーな体験を提供するために必要なツールを備えています。
