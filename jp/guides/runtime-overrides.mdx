# ランタイム i18n オーバーライド

1 つのビルド成果物を、環境ごとに異なるロケールデフォルトで実行する必要がある場合（例: テナントごとの異なるインスタンス）に、このガイドを使用します。

## ランタイムで上書きできるもの

このモジュールは以下の項目について、安全なランタイムオーバーライドをサポートします:

- `defaultLocale`
- `fallbackLocale`
- `disabledLocales`

これらのオーバーライドは、`.nuxt/i18n.strategy.mjs` と `.nuxt/i18n.config.mjs` にあるビルド時設定の上に適用されます。

## ランタイムで上書きできないもの

`strategy`（`no_prefix`、`prefix`、`prefix_except_default`、`prefix_and_default`）は、生成されるルートの挙動に影響するため、ビルド時の関心事です。

ランタイムで戦略オーバーライドを渡した場合、それは無視され、警告が出力されます。

## RuntimeConfig ベースのオーバーライド

ランタイム値を `runtimeConfig.public.i18nRuntime` 配下に指定します:

```ts
export default defineNuxtConfig({
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

## 環境変数によるオーバーライド

環境変数からもオーバーライドを設定できます:

- `NUXT_I18N_DEFAULT_LOCALE`
- `NUXT_I18N_FALLBACK_LOCALE`
- `NUXT_I18N_DISABLED_LOCALES`（カンマ区切り、例: `fr,it`）

フォールバック用のエイリアスも利用できます:

- `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES`

## バリデーションルール

ランタイムで、モジュールは破綻した状態を避けるためにオーバーライドを検証します:

- すべてのロケールを無効化することはできません。
- `defaultLocale` は有効なロケールを指す必要があります。
- `fallbackLocale` は宣言されたロケールのいずれかである必要があります。

オーバーライドが無効な場合、モジュールは安全な値を維持し、警告をログ出力します。

## マルチインスタンスデプロイでの注意点

このランタイム機能は、再ビルドすることなく、インスタンスごとにロケールの有効化とデフォルトを切り替えるために設計されています。

インスタンスごとに URL 戦略（`no_prefix` と `prefix` など）が異なる場合は、戦略ごとに個別のビルドを用意してください。

## 無効化ロケールと静的ペイロード

`runtimeConfig.public.i18nRuntime.disabledLocales` はルーティング、スイッチャー、および Nitro ペイロードの **ハンドラー** を更新します — しかし Nitro はそのハンドラーの **前** に `public/` 配下のファイルを配信します。

`translationPayloads.publicAssets`（あるいは Node SSR が強制する public コピー）が既に `/_locales/\{page\}/\{locale\}/data.json` を書き出している場合、ランタイムの無効化ではそのファイルを隠せません。ビルド時に `locale.disabled: true` を指定し、premerge がそのロケールの静的ペイロードを出力しないようにするのが推奨です。
