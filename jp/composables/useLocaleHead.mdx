---
title: "useLocaleHead"
description: "useLocaleHead は i18n SEO タグ(lang、dir、canonical、hreflang、og:locale)を、useHead に渡すオブジェクトとして構築します。"
---

`useLocaleHead()` は現在のルートの i18n head タグを構築します: `<html>` の `lang` と `dir`、canonical リンク、`x-default` を含む `hreflang` の代替リンク、`og:url`、`og:locale`、`og:locale:alternate` です。[`meta: false`](/jp/api/module-options#meta) を設定して `useHead` を自分で管理する場合に使用してください。`meta: true` の場合はモジュールがすでにこれらのタグを登録しており、ページ単位の変更は [`useI18nHead`](/jp/composables/useI18nHead) で行います。

## シグネチャ {#signature}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { build: () => LocaleHead; metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }, LocaleHead | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

現在のルートの SEO head タグ: すべてのロケールの `hreflang` 代替リンクと
`x-default`、canonical リンク、`og:locale`、そして `<html>` の `lang`/`dir`。

`meta` が無効な場合、またはデフォルトを調整する必要がある場合にのみ必要です。`meta: true` の場合は
モジュール自身が同じタグを登録します。

| パラメーター | 型 | 説明 |
| --- | --- | --- |
| `options` | `UseLocaleHeadOptions` |  |

**戻り値** — `metaObject`(`useHead` にそのまま渡せる head オブジェクトを保持する ref)、`updateMeta`(それを更新する)、`build`(現在のルートから head オブジェクトを計算する。`useHead(() => build())` のようにゲッター内で読み取るとリアクティブ)

```ts
const { metaObject } = useLocaleHead({ addSeoAttributes: true })
useHead(metaObject)
```

## オプション {#options}

| オプション | デフォルト | 説明 |
| --- | --- | --- |
| `addDirAttribute` | `true` | ロケールの `dir` から `<html>` の `dir` を設定します(未設定の場合は `'auto'`)。 |
| `identifierAttribute` | `'id'` | 各タグのキーとなる属性(`i18n-can`、`i18n-og`、`i18n-alternate-<hreflang>` など)。これにより更新時にタグが追加されるのではなく置き換えられます。 |
| `addSeoAttributes` | `true` | canonical、`hreflang`、`og:` タグを出力します。`false` の場合は `htmlAttrs` のみを保持します。 |
| `baseUrl` | `'/'` | すべての URL に結合されるオリジン。相対 URL にするには `'/'` のままにし、絶対 URL にするには `'https://example.com'` を渡します。 |
| `autoUpdate` | `true` | ルートまたは `i18n-locale` の状態が変わったときに `metaObject` を再構築します。 |

## 出力される内容 {#what-it-emits}

- 一致しないルート(404)や、アクティブなロケールで `disableMeta` が設定されたルートでは何も出力しません。
- canonical と `og:url`: `$switchLocalePath(<active locale>)`。クエリは [`canonicalQueryWhitelist`](/jp/api/module-options#canonicalquerywhitelist) に絞り込まれ、[`trailingSlash`](/jp/api/module-options#trailingslash) が適用されます。
- `hreflang`: ページが存在する有効なロケールごとに 1 つのリンク。`hreflang = iso || code` で、`seo: false` のロケールはスキップされます。`hreflangBaseLanguage: true` の場合、ある言語の最初の地域ロケールはその言語のみのタグも出力します。`no_prefix` では出力されません。
- `x-default`: デフォルトロケールの URL。ただし戦略が `no_prefix` の場合、デフォルトロケールが `seo: false` の場合、またはページがデフォルトロケールに存在しない場合を除きます。
- `og:locale` / `og:locale:alternate`: ロケールの `og`、またはその `iso` を変換したもの(`en-US` → `en_US`)。どちらも使えない場合は開発時の警告とともにスキップされます。

## 例 {#example}

```ts
// app.vue, with i18n.meta: false
const { metaObject } = useLocaleHead({ baseUrl: 'https://example.com' })
useHead(metaObject)
```

`build()` は ref なしで同じオブジェクトを返します: `useHead(() => build())` はウォッチャーなしでリアクティブに保たれます。
