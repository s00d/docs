title: "useI18nHead"
description: "useI18nHead は 1 ページ分の生成済み i18n SEO タグを上書きします: canonical、hreflang、og タグの置き換えや削除、独自タグの追加が可能です。"
---

`useI18nHead()` は、モジュールが生成する SEO タグを 1 ページに限って変更します。ルーターよりもページの方が事情をよく知っている場合に使います。たとえば一部のロケールにしか存在しない CMS 記事、API から取得した canonical URL、追加の `og:` タグなどです。生成されたタグの上にあなたの上書きがマージされた結果が得られます。

## シグネチャ {#signature}

```ts
useI18nHead(input?: MaybeRefOrGetter<I18nHeadInput | null>): { pageHead: any; resetPageHead: () => void }
```

i18n SEO の head タグに対するページ単位の上書きを登録します。
`02.meta` プラグインによって `useLocaleHead` の出力の上にマージされます。

値が `$t` / `t` から来る場合は、ロケール変更時に再解決されるようゲッター(`() => ({ … })`)を
推奨します。プレーンなオブジェクトは一度だけ評価され、そのまま固定されます。

| パラメーター | 型 | 説明 |
| --- | --- | --- |
| `input` *(任意)* | `MaybeRefOrGetter<I18nHeadInput \| null>` |  |

[`meta: true`](/jp/api/module-options#meta)(デフォルト)で動作します。モジュールの meta プラグインが、head のレンダリングごとに入力を [`useLocaleHead`](/jp/composables/useLocaleHead) の出力にマージします。`meta: false` の場合は何も読み取りません。

上書きはルート名が変わるとリセットされます。`disableMeta` を設定したページでは、上書きを含め i18n タグは一切出力されません。

## 入力 {#input}

`I18nHeadInput`(`@i18n-micro/types` から):

| キー | 型 | 効果 |
| --- | --- | --- |
| `htmlAttrs` | `Record<string, string>` | `<html>` の属性(`lang`、`dir`)にマージされます。 |
| `meta` | `I18nHeadMeta[]` | 生成されたタグの後に追加されます。同じ `id`、`property`、`name` のタグを置き換えます。 |
| `link` | `I18nHeadLink[]` | 生成されたリンクの後に追加されます。同じ `id`、または `rel` + `hreflang` のリンクを置き換えます。 |
| `replace.canonical` | `string \| false` | canonical の `href` を置き換えるか、リンクを削除します。 |
| `replace.hreflang` | `I18nHeadLink[] \| false` | `x-default` を含む**すべての** `rel="alternate"` リンクを置き換えるか削除します。 |
| `replace.xDefault` | `I18nHeadLink \| false` | `x-default` リンクを置き換えるか削除します。 |
| `replace.ogLocale` | `string \| false` | `og:locale` を置き換えるか削除します。 |
| `replace.ogUrl` | `string \| false` | `og:url` を置き換えるか削除します。 |
| `replace.ogAlternates` | `string[] \| false` | これらのロケールコードから(`og` / `iso` を介して)`og:locale:alternate` を再構築します。現在のロケール、不明なコード、`og` や `iso` の値を持たないコードはスキップされます。または削除します。 |
| `disable` | `I18nHeadDisableGroup[]` | 生成されたグループを削除します: `'hreflang'`(`x-default` は含まない)、`'x-default'`、`'canonical'`、`'og'`(`og:locale` + `og:url`)、`'og-alternates'`、`'html'`。 |

適用順序: `disable`、次に `replace`、次に `htmlAttrs`、`meta`、`link`。

## 例 {#example}

一部のロケールにのみ存在し、代替 URL を API から取得する記事:

```vue
<script setup lang="ts">
const route = useRoute()
const { t } = useI18n()
const { data: article } = await useFetch<{ title: string; urls: Record<string, string> }>(`/api/articles/${route.params.slug}`)

useI18nHead(() => {
  if (!article.value) return null
  const codes = Object.keys(article.value.urls)
  return {
    meta: [{ property: 'og:title', content: article.value.title || t('blog.title') }],
    replace: {
      hreflang: codes.map((code) => ({ rel: 'alternate', hreflang: code, href: article.value!.urls[code]! })),
      ogAlternates: codes,
    },
  }
})
</script>
```

値が `t()` や非同期データから来る場合は、ここでのようにゲッターを渡してください。ロケール変更時に再実行されます。プレーンなオブジェクトは一度だけ読み取られます。
