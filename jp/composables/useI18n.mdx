title: "useI18n"
description: "useI18n はランタイムヘルパー(`$t`、`$tc`、`$localePath` など)を、`$` プレフィックスあり・なしの両方でプレーンなオブジェクトとして返します。"
---

`useI18n()` はモジュールのランタイムヘルパーをプレーンなオブジェクトとして返します。`useNuxtApp()` を使う代わりに、`<script setup>`、コンポーザブル、プラグインの中で使用してください。各ヘルパーは `$` 付きの名前と、プレフィックスなしのエイリアスの両方で提供されます。`t` と `$t` は同じ関数です。

## シグネチャ {#signature}

```ts
useI18n(): PluginsInjectionsWithAliases
```

すべてのランタイムヘルパーをプレーンなオブジェクトとして返します。

プラグインが `$t`、`$tc` などとして注入するのと同じ関数を、ドル記号付きの名前と
プレフィックスなしのエイリアスの両方で利用できます。そのため `const { t } = useI18n()` と
`const { $t } = useI18n()` のどちらも動作します。

**戻り値** — [メソッドリファレンス](/jp/api/methods)で説明されているヘルパー

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

返されるオブジェクトには [`PluginsInjections`](/jp/api/methods) のすべてのヘルパーが含まれます。それぞれについては[ヘルパー](/jp/api/methods)ページで説明しています。

## 例 {#example}

```vue
<script setup lang="ts">
const { t, tc, localePath, switchLocale, getLocale } = useI18n()

const title = computed(() => t('page.title'))
</script>

<template>
  <h1>{{ title }}</h1>
  <p>{{ tc('items', 3) }}</p>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
  <button @click="switchLocale(getLocale() === 'en' ? 'de' : 'en')">{{ t('nav.switch') }}</button>
</template>
```

## 型に含まれないもの {#not-in-the-type}

`$defineI18nRoute` は `useNuxtApp()` にのみ型付けされています:

```ts
const { $defineI18nRoute } = useNuxtApp()
```
