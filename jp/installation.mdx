## 動作要件

- **Node.js**: 18 以上。
- **Nuxt**: 3.x または 4.x。

このモジュールは、Nuxt 3 のプロジェクトレイアウト (`pages/**/*.vue`) と Nuxt 4 のレイアウト (`app/pages/**/*.vue`) の両方をサポートします。Nuxt 4 の `app/` ディレクトリを使う場合でも、翻訳は慣例としてプロジェクトルート (`locales/`) に配置します。

## Nuxt モジュールのインストール

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

`nuxt.config.ts` に登録します。

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

完全な手順は [クイックスタート](/quickstart)、すべてのオプションは [設定リファレンス](/guides/configuration) を参照してください。

## プロジェクトレイアウト

デフォルトでは、モジュールは次の構造を想定します。

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

ルートレベルのファイルは、ビルド時に各ページ固有のファイルへマージされます。ページ固有のファイルが存在しない場合、`nuxt dev` 実行時に自動生成されます。

## Nuxt 4 レイアウト

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

翻訳を `app/` の下に共存させたい場合は、`translationDir: 'app/locales'` を設定します。

## エコシステムパッケージ

| パッケージ | 用途 |
| --- | --- |
| [`@i18n-micro/vue`](/integrations/vue) | Vue 3 統合(Nuxt なしのスタンドアロン)。 |
| [`@i18n-micro/react`](/integrations/react) | React 統合。 |
| [`@i18n-micro/preact`](/integrations/preact) | Preact 統合。 |
| [`@i18n-micro/solid`](/integrations/solid) | SolidJS 統合。 |
| [`@i18n-micro/astro`](/integrations/astro) | Astro 統合。 |
| [`@i18n-micro/node`](/integrations/nodejs) | Node.js のサーバーサイドローダー。 |
| [`@i18n-micro/types-generator`](/integrations/types-generator) | 翻訳ファイルから TypeScript の型を生成。 |
| [`@i18n-micro/devtools-ui`](/integrations/devtools-ui) | フレームワーク非依存の DevTools パネル。 |

共有される内部パッケージは推移的に取り込まれます。

## TypeScript

このモジュールは、デフォルトロケールのファイルに基づいて `useI18n`、`$t`、および関連ヘルパーのアンビエント型を生成します。これはデフォルトで有効です (`types: true`)。

翻訳キーをより厳密に型付けするには、[`@i18n-micro/types-generator`](/integrations/types-generator) を参照してください。
