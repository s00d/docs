---
title: "パスの除外"
description: "excludePatterns でページやファイルをロケールルーティングから除外し、すでに除外されているパスを確認します。"
---

管理画面、ヘルスチェック、生成されたフィードなど、ロケールプレフィックスやロケールリダイレクトを決して付けてはいけないパスがあります。`excludePatterns` でそれらを指定でき、Nuxt の内部パスや一般的な静的ファイルは組み込みのリストですでにカバーされています。除外されたページは記述したとおりのパスを保ち、`$t` を使ったレンダリングも引き続き行われます。

## パスを除外する {#exclude-a-path}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    excludePatterns: [
      '/admin', // /admin and everything below it
      '/preview-*', // glob over the whole path
    ],
  },
})
```

この設定では、`pages/admin/index.vue` は `/admin` でのみ応答します。`/de/admin` は存在せず、`/admin` が `/de/admin` にリダイレクトされることもありません。

## パターンの構文 {#pattern-syntax}

パターンは `app.baseURL` を除いたパスと照合されます:

| パターン | 一致する | 一致しない |
| --- | --- | --- |
| `'/admin'` | `/admin`, `/admin/users` | `/administrator`, `/de/admin` |
| `'/preview-*'` | `/preview-1`, `/preview-a/b` | `/de/preview-1` |
| `'/file-?'` | `/file-a` | `/file-ab` |
| `/^\/v\d+\//` | `/v2/docs` | `/docs` |

`*` も `?` も含まない文字列は、そのパスとその配下のセグメント全体に一致します。`*`(スラッシュを含む任意の文字列)や `?`(1 文字)を含む場合は、パス全体に一致する必要があります。文字列は必ず `/` で始めてください。

## すでに除外されているもの {#what-is-excluded-already}

以下は設定なしで、ロケールルートやリダイレクトの対象になりません:

- `/api` と `/_nuxt`、およびその配下すべて;
- 翻訳ルート(デフォルトは `/_locales`、[`apiBaseUrl`](/jp/api/module-options#apibaseurl));
- `__` で始まるセグメントを含むパス(`/__nuxt_content`、`/en/__og-image__`);
- `/sitemap*.xml`、`/robots.txt`、`/favicon.ico`、`/apple-touch-icon*.png`、`/manifest.json`、`/sw.js`、`/workbox-*.js`;
- 最後のセグメントが静的ファイルの拡張子で終わるパス: `xml txt ico json js css png jpg jpeg gif svg webp avif pdf wasm map mp4 webm mp3 zip gz woff woff2 ttf eot`。`/user/john.doe` のようなドットを含むページスラッグや `.html` パスはページとして扱われます。

## 除外の効果 {#what-an-exclusion-does}

- **ルート:** ローカライズされたバリアントは生成されず、ページは記述どおりに保たれます。
- **リダイレクトと 404:** サーバーのリダイレクトプラグインとクライアントのリダイレクトミドルウェアはこのパスをスキップします。
- **プリレンダリング:** 一致するパスはプリレンダリングのルートリストから削除されます。

i18n サーバーミドルウェアがリクエストのロケールを検出することは止められず、ページが翻訳を使うことも止められません。ページをローカライズしたまま SEO タグだけを外すには、`disableMeta` を使用してください([ページ設定](/jp/guide/per-component-translations#turn-off-seo-tags))。`nuxt.config.ts` からパス指定で 1 つのページをローカライズしないようにするには、`globalLocaleRoutes: { '/admin': false }`([ローカライズされたパス](/jp/guide/custom-locale-routes#in-nuxt-config))がルーティングに対して同じ効果を持ちます。
