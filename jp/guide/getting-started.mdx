このページでは、i18n のない Nuxt アプリを、言語スイッチャー付きの翻訳ページを持つ状態まで導きます。プロジェクトの開始時に一度だけ必要です。最終的に、ローカライズされた URL(`/about`、`/de/about`)、ロケールとページごとに 1 つの JSON ファイル、そしてテンプレート内の `$t` が手に入ります。

## インストール {#install}

このモジュールには Nuxt 3.18 以降(Nuxt 4 も動作します)と Node 20 以降が必要です。

<CodeGroup>

```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>

## ロケールを設定する {#configure-the-locales}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', displayName: 'English' },
      { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
      { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
    ],
    defaultLocale: 'en',
  },
})
```

最初のアプリに必要な設定はこれだけです。デフォルトでは次のようになります:

- `strategy: 'prefix_except_default'`: デフォルトロケールにはプレフィックスがなく(`/about`)、その他のロケールにはあります(`/de/about`)。[ルーティング戦略](/jp/guide/strategy)を参照してください。
- `translationDir: 'locales'`: 翻訳ファイルはプロジェクトルートの `locales/` に置かれます。Nuxt 4 の `app/` レイアウトでも同様です。
- `meta: true`: `hreflang`、canonical、`og:locale` タグに加え、`<html>` に `lang` と `dir` が付きます。[SEO](/jp/guide/seo) を参照してください。
- `/` を開いた訪問者は、ブラウザーが要求する言語(`Accept-Language`)へ送られます。[ロケール検出](/jp/guide/locale-detection)を参照してください。

`iso` は SEO タグで使われる言語タグで、`code` は URL に表示されるものです。すべてのオプションは[モジュールオプション](/jp/api/module-options)に記載されています。

## 翻訳ファイルを追加する {#add-translation-files}

`nuxt dev` で開発サーバーを起動します。Nuxt がページを解決すると、モジュールはファイルがないロケールとページごとに空の `{}` ファイルを作成します([`disableWatcher`](/jp/api/module-options#disablewatcher) で無効にできます):

```text
locales/
├── en.json            # root: keys every page can use
├── de.json
├── fr.json
└── pages/
    ├── index/         # pages/index.vue
    │   ├── en.json
    │   ├── de.json
    │   └── fr.json
    └── about/         # pages/about.vue
        ├── en.json
        ├── de.json
        └── fr.json
```

ルートファイルとページファイルを埋めます:

```json
// locales/en.json
{ "nav": { "home": "Home", "about": "About" } }
```

```json
// locales/pages/index/en.json
{ "welcome": "Welcome, {name}!", "items": "no items | one item | {count} items" }
```

ページはルートのキーと自身のキーを参照でき、衝突した場合は自身のファイルが優先されます。フォルダー名はルート名に従います(`pages/articles/[id].vue` は `locales/pages/articles-id/`)。[翻訳ファイル](/jp/guide/translations)では、レイアウト、フォールバック、読み込みについて説明しています。

## ページで `$t` を使う {#use-$t-on-a-page}

```vue
<!-- pages/index.vue -->
<script setup lang="ts">
const { t, tc, getLocale } = useI18n()

const title = t('nav.home') // 'Home'
</script>

<template>
  <h1>{{ $t('welcome', { name: 'Ada' }) }}</h1>
  <!-- Welcome, Ada! -->
  <p>{{ $tc('items', 3) }}</p>
  <!-- 3 items -->
  <p>{{ getLocale() }}</p>
  <!-- en -->
</template>
```

- テンプレートでは、すべてのヘルパーが `$` 付きで使えます(`$t`、`$tc`、`$localePath` など)。
- `<script setup>` では、`useI18n()` が同じヘルパーを `$` あり・なしの両方で返します(`t` と `$t` は同じ関数です)。自動インポートされます。
- `{name}` プレースホルダーはパラメーターオブジェクトから埋められます。複数形は `|` で区切り、カウントによって形が選ばれます(0、1、それ以上はすべて最後の形)。

すべてのヘルパーは[メソッド](/jp/api/methods)に記載されています。

## ページ間をリンクし、ロケールを切り替える {#link-between-pages-and-switch-locale}

```vue
<!-- components/AppHeader.vue -->
<template>
  <nav>
    <i18n-link :to="{ name: 'index' }">{{ $t('nav.home') }}</i18n-link>
    <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
    <i18n-switcher />
  </nav>
</template>
```

- [`<i18n-link>`](/jp/components/i18n-link) は、現在のロケールのページを指す `NuxtLink` です。`/de` では about へのリンクが `/de/about` になります。
- [`<i18n-switcher>`](/jp/components/i18n-switcher) は有効なロケールのドロップダウンで、訪問者を同じページに留めます。
- 独自のボタンでは `$switchLocale('de')` を呼び出します。現在のページのドイツ語版へ遷移し、選択を記憶します。通常の `NuxtLink` には `$localePath({ name: 'about' })` または `$switchLocalePath('de')` を使います。

## 確認する {#check-it}

`nuxt dev` を実行して、次を開きます:

| URL | 表示内容 |
| --- | --- |
| `/` | 英語のホーム(ブラウザーがドイツ語を優先する場合は `/de` へリダイレクト) |
| `/de` | ドイツ語のホーム |
| `/de/about` | ドイツ語の about ページ |
| `/en/about` | 404: `prefix_except_default` ではデフォルトロケールにプレフィックスがありません |

JSON ファイルの編集は、リロードせずに開いているページへ反映されます。
