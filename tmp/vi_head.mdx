# 🔄 Chuyển từ `nuxt-i18n` sang `Nuxt I18n Micro`

## Bạn cần hướng dẫn nào?

| Bạn đang chuyển từ…                    | Hướng dẫn                                        |
| -------------------------------------- | ------------------------------------------------ |
| `@nuxtjs/i18n` (mô-đun dựa trên vue-i18n) | **Trang này**                                    |
| `nuxt-i18n-micro` v2.x                 | [Nâng cấp từ v2.x lên v3.x](/migration/v2-to-v3) |

## Vì sao nên chuyển?

- **Hiệu năng cải thiện**: build nhanh hơn ~51% và giảm ~54% bộ nhớ build so với `@nuxtjs/i18n` **v10.6** trong các [fixture đo hiệu năng](/guides/performance-results) của chúng tôi
- **Cấu hình đơn giản hơn**: thiết lập tinh gọn với các mặc định hợp lý
- **Quản lý tài nguyên tốt hơn**: xử lý tối ưu các tệp bản dịch lớn

## Khác biệt chính

| Tính năng               | `nuxt-i18n`                      | `Nuxt I18n Micro`                         |
| ----------------------- | -------------------------------- | ----------------------------------------- |
| Tệp bản dịch            | JS/TS/JSON, tải qua `vueI18n`    | Chỉ JSON, tự động tạo trong dev           |
| Tạo route               | Runtime                          | Thời điểm build (`@i18n-micro/route-strategy`) |
| Tải bản dịch            | Đóng gói vào JS                  | Tải lười JSON theo trang                  |
| Trạng thái ngôn ngữ     | `useI18n()` từ `vue-i18n`        | Composable `useI18nLocale()`              |
| `detectBrowserLanguage` | Được hỗ trợ                      | Hãy dùng `autoDetectLanguage` thay thế    |

## Từng bước

### 1. Cài đặt

```bash
npm install nuxt-i18n-micro
```

### 2. Cập nhật cấu hình

**Trước (nuxt-i18n):**

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'fr', iso: 'fr-FR' },
    ],
    defaultLocale: 'en',
    vueI18n: './i18n.config.js',
    detectBrowserLanguage: { useCookie: true },
  },
})
```

**Sau (Nuxt I18n Micro v3):**

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
    localeCookie: 'user-locale',
    autoDetectLanguage: true,
  },
})
```
