# 🔄 Migrare de la `nuxt-i18n` la `Nuxt I18n Micro`

## De ce ghid ai nevoie?

| Migrezi de la…                         | Ghid                                             |
| -------------------------------------- | ------------------------------------------------ |
| `@nuxtjs/i18n` (modul bazat pe vue-i18n) | **Această pagină**                              |
| `nuxt-i18n-micro` v2.x                 | [Upgrade de la v2.x la v3.x](/migration/v2-to-v3) |

## De ce să migrezi?

- **Performanță îmbunătățită**: build-uri cu ~51% mai rapide și cu ~54% mai puțină memorie de build față de `@nuxtjs/i18n` **v10.6** în [fixture-urile noastre de benchmark](/guides/performance-results)
- **Configurare simplificată**: Setup simplificat cu valori implicite rezonabile
- **Gestionare mai bună a resurselor**: Gestionare optimizată a fișierelor mari de traducere

## Diferențe cheie

| Funcționalitate         | `nuxt-i18n`                      | `Nuxt I18n Micro`                         |
| ----------------------- | -------------------------------- | ----------------------------------------- |
| Fișiere de traducere    | JS/TS/JSON, încărcate prin `vueI18n` | Doar JSON, auto-generate în dev          |
| Generarea rutelor       | La runtime                       | La build (`@i18n-micro/route-strategy`) |
| Încărcarea traducerilor | Împachetate în JS                | JSON încărcat leneș per pagină           |
| Starea locale-ului      | `useI18n()` din `vue-i18n`       | Composable-ul `useI18nLocale()`          |
| `detectBrowserLanguage` | Suportat                         | Folosește `autoDetectLanguage` în schimb |

## Pas cu pas

### 1. Instalare

```bash
npm install nuxt-i18n-micro
```

### 2. Actualizează configurația

**Înainte (nuxt-i18n):**

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'fr', iso: 'fr-FR' },
    ],
    defaultLocale: 'en',
    vueI18n: './i18n.config.js',
    detectBrowserLanguage: { useCookie: true },
  },
})
```

**După (Nuxt I18n Micro v3):**

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
    localeCookie: 'user-locale',
    autoDetectLanguage: true,
  },
})
```
