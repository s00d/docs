**גרסה**: `v3.21.0`

![v3.21.0 release](/images/3.21.0.png)

גרסה זו מוסיפה את **`useI18nHead`** — composable ברמת העמוד לדריסות SEO של i18n מעל הפלאגין המובנה `02.meta`. התאימו את תגיות `hreflang`, canonical, `og:url` ו-Open Graph לכל נתיב, בלי פלאגין meta מותאם אישית ובלי `meta: false`.

## מה חדש? {#what’s-new}

### ה-Composable `useI18nHead` {#usei18nhead-composable}

קראו ל-`useI18nHead` בכל עמוד כאשר `meta: true` (ברירת המחדל). המודול ממזג את הקלט שלכם אחרי `useLocaleHead` בכל עדכון נתיב:

```vue
<script setup lang="ts">
useI18nHead(() => ({
  meta: [{ property: 'og:title', content: article.value?.title }],
  replace: {
    canonical: article.value?.canonicalUrl,
    ogUrl: article.value?.canonicalUrl,
    hreflang: localeCodes.map((locale) => ({
      rel: 'alternate',
      hreflang: locale,
      href: article.value!.locales[locale]!,
    })),
    ogAlternates: localeCodes,
  },
}))
</script>
```

תומך באובייקטים סטטיים, getters ריאקטיביים, הוספה ל-`meta` / `link`, ‏`replace` עבור קבוצות מובנות, ו-`disable` להסרת תגיות שנוצרות אוטומטית. ראו [`useI18nHead`](/he/composables/useI18nHead).

### כלי העזר `mergeI18nHead` ‏(`@i18n-micro/utils`) {#mergei18nhead-utility-@i18n-micro/utils}

לוגיקת המיזוג, שאינה תלויה ב-framework, נמצאת ב-`@i18n-micro/utils/merge-i18n-head` — משמשת את הפלאגין `02.meta` וניתנת לבדיקה בנפרד. הטיפוסים (`I18nHeadInput`, `I18nHeadLink`, `I18nHeadMeta`) מיוצאים מ-`@i18n-micro/types`.

### שילוב בפלאגינים {#plugin-integration}

- **`02.meta`** — ממזג את הפלט של `useLocaleHead` עם מצב העמוד מ-`useI18nHead` באמצעות `useHead`
- **`01.plugin`** — מאפס את הדריסות של העמוד בשינוי שם הנתיב באמצעות `resetPageHead()` (מצב משותף עם ה-composable)

### תיעוד ובדיקות {#documentation-&-tests}

- מדריך חדש: [`useI18nHead`](/he/composables/useI18nHead) עם דוגמאות CMS/מאמרים
- עדכון של [SEO](/he/guide/seo) ושל [`useLocaleHead`](/he/composables/useLocaleHead) — מתי להשתמש באיזה API
- כיסוי Playwright + Vitest: ‏SSR, ניווט SPA, טעינה מחדש, `nuxi generate`, חלופות חלקיות, `x-default`, טעינה ריאקטיבית בצד הלקוח

## מקרי שימוש נפוצים {#typical-use-cases}

| תרחיש                                     | גישה                                                       |
| -------------------------------------------- | -------------------------------------------------------------- |
| בלוג/CMS עם תרגומים חלקיים           | `replace.hreflang` + `replace.ogAlternates` מתוך שפות ה-API   |
| canonical מותאם אישית מה-CMS                    | `replace.canonical` + `replace.ogUrl`                          |
| OG בלבד לעמוד נחיתה                         | `meta: [{ property: 'og:title', ... }]` — שמירה על ה-hreflang של המודול |
| ללא hreflang בעמוד                        | `disable: ['hreflang', 'x-default']`                           |
| החלפת פלאגין מותאם אישית (`i18nManualHreflang`) | `useI18nHead` לכל עמוד תוכן + `meta: true`                  |

**JSON-LD** נשאר ב-`useHead({ script: [...] })` — ‏`useI18nHead` אינו מייצר נתונים מובנים.

## שינויים שוברים {#breaking-changes}

אין, עבור שימוש סטנדרטי ב-`nuxt.config`. ה-composable החדש ונתיב המשנה של utils הם תוספות בלבד.

## למה זה חשוב {#why-it-matters}

- **אין צורך בפלאגין meta מותאם אישית** עבור פוסטים ב-CMS, חדשות או מדריכים עם כתובות URL לכל שפה
- **צינור עיבוד יחיד** — ברירות המחדל של המודול + דריסות העמוד בקריאה אחת ל-`useHead`
- **בטיחות טיפוסים** — `I18nHeadInput` עבור פונקציות עזר כמו `buildArticleHead(content)`

יומן השינויים המלא יפורסם עם הגרסה ב-[GitHub](https://github.com/s00d/nuxt-i18n-micro/blob/main/CHANGELOG.md).
