**תאריך**: 2025-10-30

**גרסה**: `v2.0.0`

![v2.0.0 release](/images/2.0.0.png)

אנו מציגים HMR בצד השרת עבור קובצי תרגום בסביבת הפיתוח. כאשר תרגום JSON משתנה, מטמון השרת מבטל רק את המפתחות המושפעים, ובקשות עוקבות מקבלות מיד נתונים עדכניים — ללא צורך בהפעלה מחדש.

## מה חדש? {#what’s-new}

- HMR בצד השרת עבור קובצי תרגום
- ביטול מטמון מיידי לכל עמוד/locale
- חוויית פיתוח חלקה בזמן עריכת תוכן

## איך זה עובד {#how-it-works}

- Watcher ב-`src/runtime/server/plugins/watcher.dev.ts` עוקב אחר `<rootDir>/<translationDir>/**/*.json`
- קובצי עמוד (למשל `pages/<page>/<locale>.json`) מבטלים את `_locales:merged:<page>:<locale>`
- קבצים ברמת השורש (למשל `<locale>.json`) מבטלים את כל המפתחות הממוזגים של אותו locale
- נרשם אוטומטית מתוך `src/module.ts` בסביבת הפיתוח כאשר `experimental.hmr !== false`

## תצורה {#configuration}

```ts
export default defineNuxtConfig({
  i18n: {
    experimental: { hmr: true }, // default in dev
  },
})
```
