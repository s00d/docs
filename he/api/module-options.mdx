# הפניית אפשרויות מודול

כל אפשרות ש־`nuxt-i18n-micro` מקבל, נקראת בזמן הבנייה מהממשק `ModuleOptions` ב־[`packages/types/src/index.ts`](https://github.com/s00d/nuxt-i18n-micro/blob/main/packages/types/src/index.ts). שום דבר כאן אינו נכתב ידנית, כך שהוא לא יכול לפגר מאחורי הקוד. הטיפוסים, ברירות המחדל והתיאורים באים מההצהרה עצמה.

עבור המשמעות של אפשרויות אלה *ביחד* — אילו שילובים הגיוניים, מה משתנה כאשר מחליפים אסטרטגיה, דוגמאות מפורטות — קרא את [תצורה](/guides/configuration). עמוד זה הוא הרשימה המקיפה. השני הוא ההסבר.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'de', iso: 'de-DE', dir: 'ltr' },
    ],
    defaultLocale: 'en',
  },
})
```

אפשרויות מקוננות מופיעות תחת הנתיב המנוקד שלהן, כך ש־`translationPayloads.mode` הוא מפתח `mode` בתוך האובייקט `translationPayloads`.

## שפות וניתוב

אילו שפות קיימות וכיצד הן מופיעות בכתובת ה־URL.

| אפשרות | טיפוס | ברירת מחדל | תיאור |
| --- | --- | --- | --- |
| `locales` | `Locale[]` | `[]` | רשימת שפות נתמכות. כל ערך מגדיר קוד שפה בתוספת מטא־נתונים אופציונליים ‏(ISO, כיוון, שם תצוגה וכו'). |
| `strategy` | `Strategies` | `'prefix_except_default'` | אסטרטגיית ניתוב URL עבור תחיליות שפה. ‏- `'no_prefix'` — ללא שפה ב־URL; שפה נשמרת בעוגייה. ‏- `'prefix_except_default'` — תחילית לכל השפות למעט ברירת המחדל. ‏- `'prefix'` — תמיד תחילית, כולל שפת ברירת המחדל. ‏- `'prefix_and_default'` — כמו `prefix`, אבל שפת ברירת המחדל נגישה גם ללא תחילית. |
| `defaultLocale` | `string` | `'en'` | השפה לשימוש כאשר לא ניתן לקבוע שפה מ־URL או מהעדפות משתמש. משמשת גם כשפת fallback לתרגומים חסרים כאשר `fallbackLocale` אינו מוגדר. |
| `localeCookie` | `string \| null` | `null` | שם עוגייה לשמירת העדפת השפה של המשתמש בין הפעלות. הגדר ל־`null` כדי לבטל התמדה מבוססת עוגייה. מוגדר אוטומטית ל־`'user-locale'` עבור אסטרטגיית `no_prefix` אם לא סופק. |
| `globalLocaleRoutes` | `GlobalLocaleRoutes` | `\{\}` | תצורת שפה גלובלית ברמת המסלול. מאפשרת הגבלה או התאמה אישית של מסלולי שפה לעמודים ספציפיים ללא שינוי הרכיבים שלהם. ‏- `false` — הוצא את המסלול מהמקומיזציה. ‏- `Record<LocaleCode, string>` — נתיבים מותאמים לכל שפה. |
| `customRegexMatcher` | `string \| RegExp` | `undefined (uses built-in pattern based on locale codes)` | ביטוי רגולרי מותאם (או מקור מחרוזתי שלו) להתאמת קודי שפה בקטעי URL. כל קודי השפה המוגדרים ב־`locales` חייבים להתאים לתבנית זו, אחרת תונפק אזהרה. |
| `noPrefixRedirect` | `boolean` | `false` | עבור אסטרטגיית `no_prefix`: הפעל הפניה מחדש מ־URL עם תחילית שפה (למשל `/en/about`) לגרסה ללא תחילית ‏(`/about`). |
| `excludePatterns` | `(string \| RegExp)[]` | `undefined` | תבניות URL (מחרוזות או RegExp) שיוצאו מעיבוד i18n לחלוטין. מסלולים תואמים לא יקבלו תחיליות שפה, הפניות מחדש או טעינת תרגומים. נתיבי Nuxt פנימיים ‏(`/__nuxt_error` וכו') תמיד מוצאים אוטומטית. |
| `routeLocales` | `Record<string, string[]>` | — | הגבלות שפה לכל מסלול, שהוצאו מקריאות `defineI18nRoute()`. ממפה נתיב מסלול (למשל `'/about'`) למערך של קודי שפה מותרים. מסלולים שאינם ברשימה אין להם הגבלות (כל השפות מותרות). |

## תרגומים

היכן שוכנים קובצי התרגום וכיצד מפתחות נפתרים.

| אפשרות | טיפוס | ברירת מחדל | תיאור |
| --- | --- | --- | --- |
| `translationDir` | `string` | `'locales'` | נתיב לתיקייה המכילה קובצי תרגום JSON, יחסי לשורש הפרויקט. |
| `disableWatcher` | `boolean` | `false` | השבת את מעקב הקבצים שיוצר אוטומטית קובצי תרגום חסרים במצב פיתוח. |
| `routesLocaleLinks` | `\{ [key: string]: string \}` | `\{\}` | מפה שמות מסלולים לשמות מסלולים אחרים כדי לחלוק את אותם קובצי תרגום. לדוגמה, ‏`\{ 'about-us': 'about' \}` פירושו שהעמוד `about-us` ישתמש בתרגומים מהעמוד `about` במקום בשלו. |
| `plural` | `PluralFunc` | `built-in pluralization (form index by count)` | פונקציית רבים מותאמת. מקבלת ‏`(key, count, params, locale, getter)` וצריכה להחזיר את צורת הרבים שנבחרה כמחרוזת, או `null`/`undefined` כדי ליפול חזרה ללוגיקה המובנית של `defaultPlural` (כך שתוכל לעקוף רק חלק מהשפות). עבור מודול Nuxt הפונקציה מוסדרת עם `.toString()` ל־`.nuxt/i18n.plural.mjs`. היא חייבת להיות עצמאית (ללא imports / scope חיצוני). מחרוזת נתיב קובץ **לא** נתמכת. |
| `disablePageLocales` | `boolean` | `false` | השבת קובצי תרגום לכל עמוד. כאשר `true`, נטענים רק תרגומים גלובליים ‏(`\{locale\}.json`); קבצים ספציפיים לעמוד ‏(`pages/\{page\}/\{locale\}.json`) אינם נוצרים או נטענים. |
| `fallbackLocale` | `string` | `undefined (no fallback; returns the raw key)` | קוד שפת fallback גלובלי. כאשר מפתח תרגום חסר בשפה הפעילה, המודול מחפש אותו בשפה זו לפני שהוא מחזיר את המפתח עצמו. |

## Payloads ומטמון

כיצד תרגומים מגיעים לדפדפן. [ביצועים](/guides/performance) מסביר מה אלה משנות בזמן ריצה.

| אפשרות | טיפוס | ברירת מחדל | תיאור |
| --- | --- | --- | --- |
| `serverTranslationPreload` | `boolean` | `false` | טען מראש תרגומי עמוד index במידלוור גלובלי של Nitro (בצד השרת בלבד, תצורה פרטית). |
| `apiBaseUrl` | `string` | `'_locales'` | קטע נתיב URL בסיסי עבור מסלול ה־API של התרגומים (משמש בהבאת נתוני SSR/SSG). ניתן להגדיר גם דרך משתנה סביבה `NUXT_I18N_APP_BASE_URL`. |
| `apiBaseClientHost` | `string` | `undefined` | עקוף את המארח המשמש בבקשות הבאת תרגומים בצד הלקוח. שימושי כאשר הלקוח מגיע לשרת דרך שם מארח שונה מזה שאותו רואה Nuxt. ניתן להגדיר גם דרך משתנה סביבה `NUXT_I18N_APP_BASE_CLIENT_HOST`. |
| `apiBaseServerHost` | `string` | `undefined` | עקוף את המארח המשמש בבקשות הבאת תרגומים בצד השרת. שימושי בהגדרות container/microservice שבהן השרת מגיע לעצמו דרך שם מארח פנימי. ניתן להגדיר גם דרך משתנה סביבה `NUXT_I18N_APP_BASE_SERVER_HOST`. |
| `translationPayloads` | `TranslationPayloadOptions` | — | שולט כיצד payloads של תרגומים נפלטים ‏(Node: `public/<apiBaseUrl>`; Edge: Nitro `serverAssets`). ‏- **Node**: ‏`serverAssets` פירושו SSR מקומי דרך `readFile` תחת `public/` (ללא Rollup `raw:`). ‏- **Edge**: ‏`serverAssets` רושם `serverAssets` של Nitro ‏(`assets:i18n`); הוא אינו כופה עותק ציבורי. השאר את ברירות המחדל להגדרת all-in-one הרגילה. עבור קטלוגי Edge גדולים העדף `mode: 'source'`. עבור פריסות מגובות CDN, השבת פלטים מקומיים והגדר `apiBaseClientHost` / `apiBaseServerHost`. |
| `translationPayloads.mode` | `'premerged' \| 'source'` | `'premerged'` | אסטרטגיית payload של תרגום. ‏- `premerged`: מטריצה `\{page\}/\{locale\}/data.json` בזמן בנייה (ברירת מחדל) ‏- `source`: קובצי מקור קומפקטיים ממוזגים בזמן ריצה (העדף ב־Edge / קטלוגים גדולים) |
| `translationPayloads.serverAssets` | `boolean` | `true` | ‏Payloads מקומיים של SSR: ‏Node קורא `public/<apiBaseUrl>` (כופה עותק ציבורי); ‏Edge מטמיע דרך Nitro `serverAssets`. ‏- **Node**: ‏אין `serverAssets` של Nitro (נמנע Rollup `raw:`). ‏SSR קורא `public/<apiBaseUrl\|publicDir>` בתור `\{page\}/\{locale\}/data.json`; כאשר זה `true`, נכפה עותק ציבורי גם אם `publicAssets` הוא false. ‏- **Edge** ‏(`nitro.node === false`): ‏`serverAssets` של Nitro ‏(`assets:i18n`) עם אותו פריסה כמו `mode`. **אינו** כופה עותק ציבורי — הגדר `publicAssets: true` עבור CDN. |
| `translationPayloads.serverHandler` | `boolean` | `true` | רשום את מסלול השרת המובנה ב־`/\{apiBaseUrl\}/:page/:locale/data.json`. השבת זאת כאשר payloads של תרגומים מוגשים ממארח/CDN חיצוני. |
| `translationPayloads.publicAssets` | `boolean` | `true in premerged mode, false in source mode` | העתק payloads לפלט הציבורי של Nitro. ‏Premerged → `\{page\}/\{locale\}/data.json` תחת `apiBaseUrl`; ‏source → עץ קומפקטי. ב־Node עץ זה הוא גם מקור ה־SSR כאשר `serverAssets` כופה עותק ציבורי. |
| `translationPayloads.prerenderRoutes` | `boolean` | `false` | הצטרפות ל־Nitro-prerender של `/\{apiBaseUrl\}/.../data.json`. בדרך כלל מיותר כאשר `publicAssets` של premerged כבר כתב את הקבצים האלה. |
| `translationPayloads.publicDir` | `string` | — | תיקיית פלט ציבורית יחסית לשורש הציבורי של Nitro. ברירת המחדל היא `apiBaseUrl` ‏(`_locales`). כך שקבצים סטטיים תואמים לכתובות URL של הבאה בצד הלקוח ‏(`/\{apiBaseUrl\}/\{page\}/\{locale\}/data.json`). |
| `translationPayloads.warnFileCount` | `number` | `500` | הזהר במהלך הבנייה כאשר מספר קובצי ה־payload שנוצרו חורג מסף זה. |
| `translationPayloads.warnSizeBytes` | `number` | `10485760 (10 MB)` | הזהר במהלך הבנייה כאשר גודל ה־payload הכולל שנוצר חורג מסף זה בבייטים. |

## SEO

תגי meta הנוצרים לכל עמוד מתורגם.

| אפשרות | טיפוס | ברירת מחדל | תיאור |
| --- | --- | --- | --- |
| `meta` | `boolean` | `true` | ייצר תגי meta של SEO ‏(`hreflang`, ‏`canonical`, ‏`og:url`, ‏`og:locale`) אוטומטית. |
| `metaBaseUrl` | `string` | `undefined` | כתובת URL בסיסית עבור תגי meta של SEO ‏(canonical, ‏og:url, ‏hreflang). ‏- מחרוזת URL קונקרטית (למשל `'https://example.com'`) — משמשת כפי שהיא (עדיפות עליונה). ‏- `undefined` — נופל חזרה ל־`site.url` מ־`nuxt-site-config` כאשר המודול הזה קיים, אחרת מקור הבקשה הנוכחית ‏(`useRequestURL().origin` בשרת, ‏`window.location.origin` בלקוח). |
| `metaTrustForwardedHost` | `boolean` | `true` | בטח בכותרת `X-Forwarded-Host` בפתרון כתובת ה־URL הבסיסית עבור תגי meta. הפעל כאשר האפליקציה רצה מאחורי reverse proxy ‏(nginx, ‏Cloudflare, ‏AWS ALB וכו') שמגדיר כותרת זו לשם המארח האמיתי הפונה ללקוח. |
| `metaTrustForwardedProto` | `boolean` | `true` | בטח בכותרת `X-Forwarded-Proto` בפתרון הפרוטוקול עבור תגי meta. הפעל כאשר האפליקציה רצה מאחורי proxy מסיים TLS כך שכתובות URL קנוניות משתמשות ב־`https://` למרות שהאפליקציה עצמה מאזינה על HTTP. |
| `canonicalQueryWhitelist` | `string[]` | `['page', 'sort', 'filter', 'search', 'q', 'query', 'tag']` | רשימת שמות פרמטרי query הנשמרים בתגי canonical ו־`og:url`. פרמטרים שאינם ברשימה זו מוסרים מכתובת ה־URL הקנונית. |

## זיהוי והפניות מחדש

בחירת שפה למבקר שלא בחר אחת.

| אפשרות | טיפוס | ברירת מחדל | תיאור |
| --- | --- | --- | --- |
| `redirects` | `boolean` | `true` | הפעל הפניות מחדש מבוססות שפה אוטומטיות. כאשר `true`, מבקרים מופנים לשפה המועדפת עליהם (שזוהתה מעוגייה, כותרת `Accept-Language` או ברירת המחדל) בביקור הראשון. |
| `autoDetectLanguage` | `boolean` | `true` | זהה אוטומטית את שפת המשתמש המועדפת מכותרת `Accept-Language` HTTP. משמש בשילוב עם `autoDetectPath` כדי להחליט מתי הזיהוי מתרחש. |
| `autoDetectPath` | `string` | `'/'` | היכן הפניות מחדש של העדפת עוגייה / ‏Accept-Language רשאיות לרוץ (כאשר `redirects` מופעל). ‏- `'/'` — רק `/` (קישורים עמוקים בשפת ברירת המחדל נשארים ניתנים להשגה; ברירת מחדל) ‏- `'no_prefix'` — רק נתיבים ללא תחילית שפה ‏- `'*'` — כל נתיב, כולל שכתוב של תחילית שפה מפורשת (למשל `/fr/about` → `/de/about` כאשר העוגייה מעדיפה `de`) ‏- כל מחרוזת אחרת — התאמת נתיב מדויק (למשל `'/welcome'`) ניקוי אסטרטגיה עם תחילית (למשל `/en` → `/` תחת `prefix_except_default`) אינו מוגבל. |

## רישום

חלקים מהמודול שאתה יכול לכבות.

| אפשרות | טיפוס | ברירת מחדל | תיאור |
| --- | --- | --- | --- |
| `define` | `boolean` | `true` | רשום את תוסף המקרו של ‏`defineI18nRoute()`, המאפשר קריאות `defineI18nRoute()` לכל עמוד. |
| `plugin` | `boolean` | `true` | רשום את תוסף ה־i18n המרכזי המספק את ‏`$t()`, ‏`$tc()`, ‏`$getLocale()`, ‏`$switchLocale()` ועוזרי זמן ריצה אחרים. |
| `hooks` | `boolean` | `true` | רשום את תוסף hooks של i18n המספק את הוקים ברמת האפליקציה ‏`i18n:register` ו־`i18n:beforeLocaleSwitch` / ‏`i18n:afterLocaleSwitch`. |
| `components` | `boolean` | `true` | רשום רכיבי i18n מובנים ‏(`<i18n-link>`, ‏`<i18n-switcher>`, ‏`<i18n-t>`, ‏`<i18n-group>`). הגדר ל־`false` כדי לבטל רישום רכיבים אוטומטי (למשל, אם אתה לא משתמש בהם ורוצה להקטין את טביעת הרגל של המודול). |
| `types` | `boolean` | `true` | ייצר הצהרות טיפוס TypeScript עבור `useI18n`, ‏`$t` ועוזרים קשורים בהתבסס על מפתחות התרגום בקובצי שפת ברירת המחדל שלך. |
| `debug` | `boolean` | `false` | הפעל רישום debug מפורט עבור זיהוי שפה, יצירת מסלולים וטעינת תרגומים. |
