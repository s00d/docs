[מדריך ה-CLI](/he/guide/cli) מציג את תהליכי העבודה הנפוצים. עמוד זה מפרט הכול, ונוצר מאותה טבלה שמפעילה את `--help`.

## דגלים משותפים {#common-flags}

| דגל | ברירת מחדל | תיאור |
| --- | --- | --- |
| `--cwd` | התיקייה הנוכחית | תיקיית הפרויקט |
| `--logLevel` | `info` | רמת הפלט: silent, info |
| `--debug` | `false` | הדפסת stack trace כאשר פקודה נכשלת |

## בדיקה {#inspect}

### `info` {#info}

הדפסת תצורת ה-i18n המחושבת של הפרויקט

| דגל | ברירת מחדל | תיאור |
| --- | --- | --- |
| `--json` | `false` | הדפסת JSON במקום טקסט |

### `check` {#check}

שער ה-CI: כישלון על מפתחות חסרים, ריקים, עודפים, לא מוגדרים או לא בשימוש, ועל placeholders שבורים

| דגל | ברירת מחדל | תיאור |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` של nuxt.config | תיקיית התרגומים, יחסית לפרויקט |
| `--only` | הכול מלבד duplicates | בדיקות להרצה, מופרדות בפסיקים: missing, empty, extra, placeholders, undefined, unused, duplicates. `unused` שצוין כאן נכשל כאשר אינו יכול לרוץ |
| `--duplicates` | `false` | דיווח גם על אותו טקסט תחת מפתחות שונים |
| `--ignore` | — | תבניות glob של קובצי מקור לדילוג, מופרדות בפסיקים, יחסית לפרויקט |
| `--json` | `false` | הדפסת JSON במקום טקסט |

```bash
i18n-micro check
i18n-micro check --only missing,placeholders --json
```

### `stats` {#stats}

הצגת שיעור השלמת התרגום לכל locale

| דגל | ברירת מחדל | תיאור |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` של nuxt.config | תיקיית התרגומים, יחסית לפרויקט |
| `--html` | — | כתיבת דוח HTML גם לקובץ זה |
| `--json` | `false` | הדפסת JSON במקום טקסט |
| `--baseRef` | — | Git ref להשוואת ההשלמה מולו, למשל HEAD~1 או main |

```bash
i18n-micro stats --baseRef main
i18n-micro stats --html reports/i18n.html
```

### `lint` {#lint}

בדיקת הטקסט של התרגומים; נכשל כאשר נותרות בעיות

| דגל | ברירת מחדל | תיאור |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` של nuxt.config | תיקיית התרגומים, יחסית לפרויקט |
| `--rules` | הכול, או `enabledRules` של .i18n-lintrc.json | כללים להרצה, מופרדים בפסיקים: no-trailing-spaces, no-multiple-spaces, no-empty-translation, או כלל מותאם אישית |
| `--fix` | `false` | תיקון מה שניתן לתקן: רווחים, וכללים מותאמים אישית עם החלפה |
| `--json` | `false` | הדפסת JSON במקום טקסט |

```bash
i18n-micro lint --rules no-trailing-spaces --fix
```

### `search` {#search}

חיפוש מפתחות וערכים, והצגת המקומות שבהם כל מפתח נמצא בשימוש

| דגל | ברירת מחדל | תיאור |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` של nuxt.config | תיקיית התרגומים, יחסית לפרויקט |
| `<query>` | — | טקסט או מפתח לחיפוש |
| `--caseSensitive` | `false` | התאמה לפי רישיות |
| `--onlyUnused` | `false` | רק מפתחות ש-`clean` היה מסיר; השאילתה הופכת לאופציונלית |
| `--scope` | `all` | היכן לחפש: global, pages, all |
| `--limit` | — | החזרת מספר מפתחות זה לכל היותר |
| `--ignore` | — | תבניות glob של קובצי מקור לדילוג, מופרדות בפסיקים, יחסית לפרויקט |
| `--json` | `false` | הדפסת JSON במקום טקסט |

```bash
i18n-micro search "Welcome"
i18n-micro search --onlyUnused
```

## תהליך עבודת התרגום {#translation-workflow}

### `extract` {#extract}

הצגת המפתחות שקובצי המקור משתמשים בהם ושעדיין אין להם טקסט, והוספת אלה שיש להם טקסט ברירת מחדל ל-locale ברירת המחדל

| דגל | ברירת מחדל | תיאור |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` של nuxt.config | תיקיית התרגומים, יחסית לפרויקט |
| `--ignore` | — | תבניות glob של קובצי מקור לדילוג, מופרדות בפסיקים, יחסית לפרויקט |

```bash
i18n-micro extract
```

### `translate` {#translate}

מילוי תרגומים חסרים מה-locale של ברירת המחדל באמצעות שירות תרגום

| דגל | ברירת מחדל | תיאור |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` של nuxt.config | תיקיית התרגומים, יחסית לפרויקט |
| `--service` | — | שירות התרגום: ai, azure, deepl, google, libretranslate, yandexcloud |
| `--token` | — | מפתח API. עדיף להשתמש במשתנה הסביבה I18N_TRANSLATE_TOKEN: דגלים נשמרים בהיסטוריית ה-shell |
| `--options` | — | אפשרויות השירות כזוגות key:value, מופרדים בפסיקים |
| `--locale` | כל ה-locales מלבד ברירת המחדל | locales למילוי, מופרדים בפסיקים |
| `--replace` | `false` | תרגום מחדש של כל מפתח, תוך החלפת ערכים קיימים |
| `--dryRun` | `false` | ספירת מפתחות ותווים לכל locale; שום דבר לא נשלח |
| `--chunkSize` | — | מחרוזות לבקשה; מוגבל למה שהשירות מקבל |
| `--pluralSeparator` | `\|` | מפריד צורות הריבוי בהודעות |
| `--glossaryFile` | `.i18n-glossary.json` כאשר הוא קיים | קובץ מילון מונחים, בשימוש שירות `ai` |

```bash
i18n-micro translate --dryRun
I18N_TRANSLATE_TOKEN=... i18n-micro translate --service deepl --locale de,fr
i18n-micro translate --service ai --options provider:openai,model:gpt-4o-mini
i18n-micro translate --service libretranslate --options baseUrl:https://translate.example.com
```

### `sync` {#sync}

הסרת מפתחות שאינם קיימים ב-locale של ברירת המחדל; נעצר כאשר לא ניתן להוכיח שהדבר בטוח. מפתחות חסרים נשארים חסרים

| דגל | ברירת מחדל | תיאור |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` של nuxt.config | תיקיית התרגומים, יחסית לפרויקט |
| `--ignore` | — | תבניות glob של קובצי מקור לדילוג, מופרדות בפסיקים, יחסית לפרויקט |
| `--dryRun` | `false` | הצגת מה שהיה מוסר; שום דבר לא נכתב |
| `--force` | `false` | הסרת מפתחות גם אם לא ניתן להוכיח שהדבר בטוח |

```bash
i18n-micro sync --dryRun
```

### `clean` {#clean}

הסרת מפתחות שאף דבר בפרויקט אינו משתמש בהם; נעצר כאשר לא ניתן להוכיח זאת

| דגל | ברירת מחדל | תיאור |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` של nuxt.config | תיקיית התרגומים, יחסית לפרויקט |
| `--include` | — | ביטוי רגולרי: רק מפתחות תואמים נשקלים להסרה |
| `--exclude` | — | ביטוי רגולרי: מפתחות תואמים לעולם אינם מוסרים |
| `--ignore` | — | תבניות glob של קובצי מקור לדילוג, מופרדות בפסיקים, יחסית לפרויקט |
| `--dryRun` | `false` | הצגת מה שהיה מוסר; שום דבר לא נכתב |
| `--force` | `false` | הסרת מפתחות גם אם לא ניתן להוכיח את השימוש בכולם |

```bash
i18n-micro clean --dryRun
i18n-micro clean --exclude '^errors\.'
```

## ריפקטורינג {#refactoring}

### `text-to-i18n` {#text-to-i18n}

החלפת טקסט מקודד בתבניות Vue בקריאות תרגום, ודיווח על טקסט מקודד בקוד

| דגל | ברירת מחדל | תיאור |
| --- | --- | --- |
| `--translationFile` | `<translationDir>/<defaultLocale>.json` | הקובץ שאליו נכנסים המפתחות החדשים |
| `--path` | הפרויקט כולו | קובץ או תיקייה לעיבוד |
| `--context` | — | קידומת למפתחות שנוצרים |
| `--ignore` | — | תבניות glob של קובצי מקור לדילוג, מופרדות בפסיקים, יחסית לפרויקט |
| `--dryRun` | `false` | הצגת מה שהיה משתנה; שום דבר לא נכתב |
| `--interactive` | `false` | אישור או עריכה של כל מפתח שנוצר |

```bash
i18n-micro text-to-i18n --dryRun
i18n-micro text-to-i18n --path components --context ui
```

### `rename` {#rename}

שינוי שם של מפתח או של namespace בכל ה-locales ובקובצי המקור

| דגל | ברירת מחדל | תיאור |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` של nuxt.config | תיקיית התרגומים, יחסית לפרויקט |
| `--from` **\*** | — | המפתח או ה-namespace הנוכחי |
| `--to` **\*** | — | המפתח או ה-namespace החדש |
| `--ignore` | — | תבניות glob של קובצי מקור לדילוג, מופרדות בפסיקים, יחסית לפרויקט |
| `--dryRun` | `false` | דיווח על השינויים; שום דבר לא נכתב |

**\*** חובה.

```bash
i18n-micro rename --from common.save --to actions.save
```

### `pseudo` {#pseudo}

מילוי locale בתרגומי דמה כדי לאתר בעיות פריסה וטקסט מקודד

| דגל | ברירת מחדל | תיאור |

| `--sourceLocale` | ה-locale של ברירת המחדל | ה-locale לקריאה |
| `--targetLocale` **\*** | — | ה-locale למילוי |
| `--replace` | `false` | דריסת ערכים קיימים |

**\*** חובה.

### `format` {#format}

כתיבה מחדש של קובצי ה-locale עם מפתחות ממוינים והזחה אחידה

| דגל | ברירת מחדל | תיאור |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` של nuxt.config | תיקיית התרגומים, יחסית לפרויקט |
| `--indent` | `2` | מספר רווחי ההזחה |
| `--sortKeys` | `true` | מיון המפתחות; השתמשו ב---no-sortKeys כדי לשמור על הסדר שלהם |
| `--check` | `false` | כישלון אם קובץ היה משתנה; שום דבר לא נכתב |


## החלפת קבצים {#exchange}

### `export` {#export}

ייצוא קובצי locale ל-PO או CSV, כאשר הטקסט של locale ברירת המחדל משמש כמקור

| דגל | ברירת מחדל | תיאור |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` של nuxt.config | תיקיית התרגומים, יחסית לפרויקט |
| `--format` | `po` | פורמט הקובץ: po, csv |
| `--dir` | `pots` עבור po, `csv_exports` עבור csv | תיקיית הפלט, יחסית לפרויקט |
| `--force` | `false` | דריסת קבצים ששונו מאז הייצוא האחרון ומעולם לא יובאו |

```bash
i18n-micro export --format csv
```

### `import` {#import}

מיזוג קובצי PO או CSV לתוך קובצי ה-locale

| דגל | ברירת מחדל | תיאור |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` של nuxt.config | תיקיית התרגומים, יחסית לפרויקט |
| `--format` | `po` | פורמט הקובץ: po, csv |
| `--dir` | `pots` עבור po, `csv_exports` עבור csv | תיקיית הקלט, יחסית לפרויקט |
| `--dryRun` | `false` | דיווח על מה שהיה מיובא; שום דבר לא נכתב |

```bash
i18n-micro import --format csv --dryRun
```

### `sync-remote` {#sync-remote}

משיכת תרגומים גלובליים מנקודת הקצה של HTTP שב-.i18n-remote.json, או דחיפתם אליה

| דגל | ברירת מחדל | תיאור |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` של nuxt.config | תיקיית התרגומים, יחסית לפרויקט |
| `--pull` | `true` | משיכה מהשרת המרוחק |
| `--push` | `false` | דחיפה לשרת המרוחק |
| `--force` | `false` | במשיכה, לקיחת הערך המרוחק; בדחיפה, דריסת טקסט שקיים רק בשרת המרוחק |
| `--dryRun` | `false` | דיווח על מה שמשיכה הייתה משנה; שום דבר לא נכתב ולא נדחף |

```bash
i18n-micro sync-remote --dryRun
i18n-micro sync-remote --no-pull --push
```

## כללי lint {#lint-rules}

| כלל | מאתר | מתוקן על ידי `--fix` |
| --- | --- | --- |
| `no-trailing-spaces` | רווחים בסוף ערך או שורה | כן |
| `no-multiple-spaces` | שני רווחים או יותר ברצף | כן |
| `no-empty-translation` | ערך ריק או לבן | לא |

## קודי יציאה {#exit-codes}

| קוד | משמעות |
| --- | --- |
| `0` | הסתיים, אין על מה לדווח |
| `1` | ממצאים: `check`, `lint` או `format --check` מצאו משהו, `clean` או `sync` לא יכלו להוכיח שהסרה בטוחה, `export` היה דורס עבודה שלא יובאה, `translate` השאיר מפתחות בחוץ, `import` או `sync-remote` נתקלו בהתנגשות, דחיפה של `sync-remote` הייתה מוחקת טקסט מרוחק. `--dryRun` של `clean`, `sync` או משיכה של `sync-remote` מדווח על אלה ויוצא עם `0` |
| `2` | כישלון: שימוש שגוי, פרויקט שאינו קריא, שגיאת רשת או קובץ |

## קובצי תצורה {#configuration-files}

| קובץ | בשימוש על ידי |
| --- | --- |
| `.i18n-lintrc.json` | `lint`: `enabledRules`, `disabledRules`, `customRegexRules` (`name`, `pattern`, `flags`, `description`, `replacement`) |
| `.i18n-remote.json` | `sync-remote`: `url`, `path`, `token`, `auth` (`username`, `password`). אפשר להשמיט את `type`; קיים רק `custom` |
| `.i18n-glossary.json` | `translate --service ai`: `entries` של `source`, `target`, ו-`from`, `to` אופציונליים |

## משתני סביבה {#environment-variables}

| שם | משמש עבור |
| --- | --- |
| `I18N_TRANSLATE_TOKEN` | מפתח ה-API של `translate`. נקרא גם מ-`.env` |
| `I18N_REMOTE_TOKEN` | Bearer token של `sync-remote`. נקרא גם מ-`.env` |
| `AI_GATEWAY_API_KEY, OPENAI_API_KEY, ANTHROPIC_API_KEY` | מפתח שירות `ai`, כאשר `I18N_TRANSLATE_TOKEN` אינו מוגדר |
| `DEFAULT_LOCALE` | דורס את `defaultLocale`, כמו במודול |
