# 🛠️ מתודות

## 🔍 מתודות תרגום

מתודות ליבה לאחזור וניהול תרגומים.

### `$t`

{/* generated:method:$t — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

תרגם מפתח, מאנטרפל `params` לתוכו. מחזיר `defaultValue` כאשר המפתח חסר, או את המפתח עצמו כאשר לא ניתן ברירת מחדל.

{/* /generated:method:$t */}

```typescript
const welcomeMessage = $t('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

<Warning>
`$t` מחזיר `CleanTranslation` שהוא `string | number | boolean | Translations | PluralTranslations | null`. אם המפתח מצביע ל**אובייקט מקונן** ב־JSON שלך (למשל `$t('header')` כאשר ה־JSON מכיל `\{ "header": \{ "title": "Hi" \} \}`), ערך ההחזרה יהיה אותו **אובייקט**, לא מחרוזת. שימוש בו ישירות בתבנית Vue (<code v-pre>\{\{ $t('header') \}\}</code>) יעבד כ־`[object Object]`.

**כיצד להימנע מכך:**

- השתמש במפתח יותר ספציפי: ‏`$t('header.title')` → `"Hi"`
- השתמש ב־`$ts()` שתמיד מחזיר מחרוזת (קורא ל־`.toString()` על לא־מחרוזות)
- השתמש ב־`$t` עם מפתח מקונן כדי לגשת בכוונה לתת־אובייקטים לשימוש תכנותי
</Warning>

### `$_t` ו־`$_ts`

{/* generated:method:$_t — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

קשור `$t` למסלול ספציפי, לתרגום מחוץ לעמוד הנוכחי — layout שמעבד קישור למסלול אחר, לדוגמה.

{/* /generated:method:$_t */}

{/* generated:method:$_ts — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => string
```

קשור `$ts` למסלול ספציפי. עיין ב־`$_t`.

{/* /generated:method:$_ts */}

וריאנטים הקשורים למסלול של `$t` ו־`$ts`. הם מקבלים **מסלול** תחילה ומחזירים פונקציית תרגום נעולה להקשר השפה והעמוד של אותו מסלול.

- **גישה**: ‏`useNuxtApp()` (גם מיוצא מחדש על ידי `useI18n()` בתור `$_t` / ‏`$_ts`)

השתמש באלה כאשר המסלול הפעיל במהלך SSR או מעברים שונה מ־`router.currentRoute` — לדוגמה בתוך `<i18n-t>`, ‏`<i18n-group>`, או בעת עיבוד תוכן עבור אובייקט `route` ספציפי.

```typescript
import { useRoute, useNuxtApp } from '#imports'

const route = useRoute()
const { $_t, $_ts } = useNuxtApp()

const $t = $_t(route)
const title = $t('page.title')

// String-safe variant
const label = $_ts(route)('page.label')
```


### `$tc`

{/* generated:method:$tc — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params: number | Params, defaultValue?: string) => string
```

תרגם עם רבים. `params` יכול להיות הספירה עצמה, או אובייקט המכיל `count`.

{/* /generated:method:$tc */}

**פורמט תרגום**: צורות מופרדות ב־`|`. שים placeholders ב**כל** צורה:

```json
{
  "apples": "no apples | one apple | {count} apples",
  "cart": "no items for {name} | one item for {name} | {count} items for {name}"
}
```

```typescript
$tc('apples', 0) // "no apples"
$tc('apples', 1) // "one apple"
$tc('apples', 10) // "10 apples"

// count + other params (second argument must be an object)
$tc('cart', { count: 10, name: 'Alice' }) // "10 items for Alice"
```


**חלופת רכיב** — ‏`<i18n-t keypath="cart" :plural="count" :params="\{ name \}" />` (ממזג `count` עם `params` פנימית).

### `$resolveTranslations`

{/* generated:method:$resolveTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
() => Translations
```

כל תרגום שנמצא כעת בזיכרון עבור השפה והמסלול הפעילים, כעץ. תצוגה קריאה בלבד של מה ש־`$t()` יכול לפתור כרגע.

{/* /generated:method:$resolveTranslations */}

```typescript

// { aaa: { bbb: 'ccc' }, ddd: 1111 } — the same dictionary $t() reads from
```

השתמש בזה כאשר אתה זקוק למילון המלא בזיכרון (DevTools, בדיקות, עורכי זמן ריצה). התייחס לערך ההחזרה כקריא בלבד; שנה ערכים דרך `$setTranslation` או מזג תיקונים עם `$mergeTranslations`.

### `$setTranslation`

{/* generated:method:$setTranslation — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, value: unknown) => void
```

החלף את הערך ב־`key` במילון הפעיל. זו החלפה, לא מיזוג. השתמש ב־`$mergeTranslations` כאשר יש לשמר אחים קיימים.

{/* /generated:method:$setTranslation */}

```typescript
$setTranslation('aaa', { fff: 'ggg' }) // replaces the whole `aaa` subtree
$setTranslation('aaa', 'text')          // replaces `aaa` with a string
$setTranslation('ddd', 1111)            // scalar at the top level
$setTranslation('aaa.bbb', 'nested')    // dotted path
```

זו **החלפה**, לא מיזוג. אחים קיימים תחת אותו מפתח מוסרים. כדי לתקן ללא איבוד אחים, השתמש ב־`$mergeTranslations`.

### `$setMissingHandler`

{/* generated:method:$setMissingHandler — do not edit; run `pnpm run docs:generate` */}

```ts
(handler: MissingHandler | null) => void
```

התקן callback שמופעל עבור כל מפתח לא פתור. העבר `null` כדי להסיר אותו.

{/* /generated:method:$setMissingHandler */}

**הגדרת טיפוס**:

```typescript
type MissingHandler = (locale: string, key: string, routeName: string, instance?: unknown, type?: string) => void
```

```typescript
// Set a custom handler
$setMissingHandler((locale, key, routeName) => {
  console.error(`Missing translation: ${key} in ${locale} for route ${routeName}`)
  // Send to Sentry or other error tracking service
  // Sentry.captureMessage(`Missing translation: ${key}`)
})

// Remove the handler
$setMissingHandler(null)
```

**מקרי שימוש**:

- רישום תרגומים חסרים לשירותי מעקב שגיאות ‏(Sentry, LogRocket וכו')
- איסוף אנליטיקה על תרגומים חסרים
- טיפול שגיאות מותאם עבור מפתחות תרגום חסרים

## 🔢 עיצוב מספרים ותאריכים

מתודות לעיצוב מספרים ותאריכים בהתאם למוסכמות השפה.

### `$tn`

{/* generated:method:$tn — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

עצב מספר עם `Intl.NumberFormat` בשפה הפעילה. מפתח בוחר פורמט בעל שם מהתצורה.

{/* /generated:method:$tn */}

```typescript
// Inline options
const formattedNumber = $tn(1234567.89, { style: 'currency', currency: 'USD' })
// "$1,234,567.89"

// Named format (from nuxt.config i18n.numberFormats)
const price = $tn(1000, 'currency')
const priceDe = $tn(1000, 'currency', 'de')
const compact = $tn(1000, 'currency', { notation: 'compact' })
```

מפתחות פורמט בעל שם לא ידועים נופלים חזרה לאפשרויות ברירת המחדל של `Intl.NumberFormat`. בפיתוח (לקוח), ‏`console.warn` מונפק כאשר `missingWarn` מופעל (ברירת המחדל).

**דוגמת תצורה**:

```ts
export default defineNuxtConfig({
  i18n: {
    numberFormats: {
      en: {
        currency: { style: 'currency', currency: 'USD' },
        decimal: { style: 'decimal', minimumFractionDigits: 2, maximumFractionDigits: 2 },
      },
      de: {
        currency: { style: 'currency', currency: 'EUR' },
      },
    },
  },
})
```

**מקרי שימוש**:

- עיצוב מספרים כמטבע, אחוזים או עשרונים בפורמט השפה המתאים
- שימוש חוזר בפורמטים בעלי שם ברחבי האפליקציה (שוויון עם הגירה של Vue I18n)

## 🚦 תצורת מסלול

מתודות לתצורת התנהגות מסלול ובקרת גישה.

### `$defineI18nRoute`

{/* generated:method:$defineI18nRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

רשום תצורת שפה לכל עמוד ותרגומים מתוך רכיב. ממזג לשפה הפעילה ומיישם מחדש כאשר השפה משתנה.

{/* /generated:method:$defineI18nRoute */}

> [!IMPORTANT]
> `$defineI18nRoute` מסופק על ידי **תוסף define** וזמין ב־`useNuxtApp()` בלבד. הוא **אינו** חלק מאובייקט ההחזרה של `useI18n()`.
> תמיד עשה destructure שלו מ־`useNuxtApp()` בתוך `script setup`. קריאה ל־`$defineI18nRoute(...)` כגלובלי חשוף זורקת `"$defineI18nRoute is not defined"` במהלך SSR/prerender.

**פרמטרים**:

- **locales**: `string[] | Record<string, Record<string, string>>` — שפות זמינות עבור המסלול
- **localeRoutes**: `Record<string, string>` — אופציונלי. מסלולים מותאמים עבור שפות ספציפיות
- **disableMeta**: `boolean | string[]` — אופציונלי. משבית תגי meta של i18n עבור כל השפות או עבור שפות ספציפיות

**דוגמה בסיסית**:

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr', 'de'],
  localeRoutes: {
    en: '/welcome',
    fr: '/bienvenue',
    de: '/willkommen',
  },
  disableMeta: false,
})
```

> 📖 **לדוגמאות שימוש מפורטות, פורמטי תצורה ושיטות עבודה מומלצות, עיין ב־[מדריך תרגומים לכל רכיב](/guides/per-component-translations).**

### `$setI18nRouteParams`

{/* generated:method:$setI18nRouteParams — do not edit; run `pnpm run docs:generate` */}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

הגדר פרמטרים לכל שפה עבור המסלול הנוכחי, כך שקטע דינמי יכול להיות שונה לכל שפה. קרא לו במהלך SSR, לפני שה־head מעובד.

{/* /generated:method:$setI18nRouteParams */}

```typescript
// in pages/news/[id].vue
// for en/news/1-first-article
const { $switchLocaleRoute, $setI18nRouteParams, $defineI18nRoute } = useNuxtApp()
$defineI18nRoute({
  localeRoutes: {
    en: '/news/:id()',
    fr: '/nouvelles/:id()',
    de: '/Nachricht/:id()',
  },
})
const { data: news } = await useAsyncData(`news-${params.id}`, async () => {
  let response = await $fetch("/api/getNews", {
    query: {
      id: params.id,
    },
  });
  if (response?.localeSlugs) {
    response.localeSlugs = {
      en: {
        id: '1-first-article'
      }
      fr: {
        id: '1-premier-article'
      }
      de: {
        id: '1-erster-Artikel'
      }
    }
    $setI18nRouteParams(response?.localeSlugs);
  }
  return response;
});
$switchLocalePath('fr') // === 'fr/nouvelles/1-premier-article'
$switchLocalePath('de') // === 'de/Nachricht/1-erster-Artikel'
```

## 🧭 Composable של `useI18nLocale`

ה־composable המרכזי לניהול מצב שפה. השתמש בזה במקום לתמרן ישירות ‏`useState('i18n-locale')` או `useCookie('user-locale')`.

```typescript
const {
  setLocale, // (locale: string) => void — updates state + cookie
  getLocale, // () => string | null — from state or cookie
  getPreferredLocale, // () => string | null — validated against locales list
  getEffectiveLocale, // (route, getLocaleFromRoute) => string
  resolveInitialLocale, // (options) => string
  isValidLocale, // (locale) => boolean
  locale, // Ref<string | null> — reactive state
  localeCookie, // CookieRef — reactive cookie
  syncLocale, // (locale) => void — sync to cookie only
  validLocales, // string[] — list of valid locale codes
} = useI18nLocale()
```

### מתודות מרכזיות

| מתודה                  | תיאור                                                 |
| ----------------------- | ----------------------------------------------------------- |
| `setLocale(locale)`     | מגדיר שפה גם ב־`useState` וגם בעוגייה באטומיות        |
| `getLocale()`           | מחזיר את השפה הנוכחית ממצב או עוגייה                 |
| `getPreferredLocale()`  | מחזיר שפה מאומתת מול רשימת `locales`, או `null`  |
| `isValidLocale(locale)` | בודק אם קוד שפה נמצא ברשימת ה־`locales` המוגדרת |

// plugins/i18n-loader.server.ts
export default defineNuxtPlugin({
