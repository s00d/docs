המודול מזריק את פונקציות העזר של זמן הריצה שלו לאפליקציית Nuxt: ‏`$t`, ‏`$tc`, ‏`$localePath`, ‏`$switchLocale` וכל השאר. השתמשו בעמוד זה כדי לבדוק את החתימה וההתנהגות של פונקציית עזר. החתימות והתיאורים מגיעים מהממשקים `PluginsInjections` ו-`NuxtAppOnlyInjections` בקובץ `src/runtime/plugins/01.plugin.ts`.

## גישה {#access}

| היכן | כיצד |
| --- | --- |
| תבנית | `{{ $t('title') }}` — כל פונקציית עזר, עם ה-`$` |
| `<script setup>` | `const { t, localePath } = useI18n()` — כל פונקציית עזר ב-`PluginsInjections`, עם ובלי ה-`$` |
| פלאגין, middleware, ‏`<script setup>` | `const { $t, $defineI18nRoute } = useNuxtApp()` — הכול, רק עם `$` |

`$defineI18nRoute` מוגדר בטיפוסים רק על `useNuxtApp()`. ראו [`useI18n`](/he/composables/useI18n).

```vue
<script setup lang="ts">
const { t, localePath } = useI18n()
</script>

<template>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
</template>
```

## שפה {#locale}

### `$getLocale` {#$getlocale}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric) => string
```

הקוד של השפה הפעילה. העבירו נתיב כדי לקרוא את השפה שאליה הנתיב שייך.

```ts
$getLocale() // 'de' on /de/about
```

### `$getLocaleName` {#$getlocalename}

```ts
() => string | null
```

ה-`displayName` של השפה הפעילה מהתצורה, או `null` כשאין לה כזה.

### `$getLocales` {#$getlocales}

```ts
() => Locale[]
```

כל שפה מוגדרת, עם המטא-נתונים שלה.

מאפיינים מותאמים אישית על אובייקט שפה חוזרים כפי שנכתבו; הגדירו להם טיפוסים עם [הרחבת מודול](/he/api/module-options#locales) של `Locale`.

### `$defaultLocale` {#$defaultlocale}

```ts
() => string | undefined
```

הקוד של שפת ברירת המחדל המוגדרת.

### `$getI18nConfig` {#$geti18nconfig}

```ts
() => ResolvedI18nConfig
```

תצורת המודול המחושבת, כפי שזמן הריצה רואה אותה.

הערך כולל [דריסות בזמן ריצה](/he/guide/runtime-overrides) (`defaultLocale`, `fallbackLocale`, שפות מושבתות).

```ts
const { strategy, localeCookie } = useNuxtApp().$getI18nConfig()
```

## תרגום {#translation}

### `$t` {#$t}

```ts
TranslationFn<CleanTranslation>
```

מתרגם מפתח, תוך שילוב `params` בתוכו. מחזיר את `defaultValue` כשהמפתח
חסר, או את המפתח עצמו כשלא ניתנה ברירת מחדל.

```ts
// { "welcome": "Welcome, {name}!" }
$t('welcome', { name: 'Ada' }) // 'Welcome, Ada!'
$t('missing.key', {}, 'Fallback') // 'Fallback'
```

מפתח שמצביע על אובייקט מקונן מחזיר את האובייקט הזה, לא מחרוזת. בתבנית הוא מוצג כ-`[object Object]`; השתמשו במפתח עלה.

### `$ts` {#$ts}

```ts
TranslationFn<string>
```

כמו `$t`, אבל תמיד מחזיר מחרוזת: הערך עובר דרך `toString()`, כך שאובייקט
מקונן הופך ל-`'[object Object]'`. הפנו את המפתח לעלה.

### `$_t` {#$_t}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<CleanTranslation>
```

קושר את `$t` לנתיב מסוים, לתרגום מחוץ לעמוד הנוכחי — למשל layout שמציג
קישור לנתיב אחר.

```ts
const route = useRoute()
const t = useNuxtApp().$_t(route)
t('page.title')
```

### `$_ts` {#$_ts}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<string>
```

קושר את `$ts` לנתיב מסוים. ראו `$_t`.

### `$tc` {#$tc}

```ts
(key: TranslationKey, params: number | Params, defaultValue?: string) => string
```

מתרגם עם צורות רבים. `params` יכול להיות המספר עצמו, או אובייקט שמכיל
`count`.

הצורות מופרדות ב-`|`. עם הכלל המובנה, מספר שלם אי-שלילי `n` בוחר את הצורה `n`, מוגבל לצורה האחרונה; מספר שלילי, שברי או `NaN` לוקח את הצורה האחרונה. `{count}` ושאר הפרמטרים משולבים בצורה שנבחרה.

עבור שפות שבהן צורות הרבים אינן עוקבות אחר המספר, התחילו את התבנית ב-`=0 `. הצורה הראשונה היא אז עבור 0, והשאר נקבעות לפי קטגוריית [`Intl.PluralRules`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/PluralRules), בסדר `zero, one, two, few, many, other`:

```json
{
  "apples": "=0 no apples | one apple | {count} apples",
  "files": "=0 no files | {count} one | {count} few | {count} many"
}
```

```ts
$tc('apples', 0) // 'no apples'
$tc('apples', 1) // 'one apple'
$tc('apples', 7) // '7 apples'

// In `uk` (categories `one, few, many, other`) the forms after the zero form follow those categories:
$tc('files', 21) // '21 one'
$tc('files', 22) // '22 few'
$tc('files', 25) // '25 many'
$tc('files', 2.5) // '2.5 many': no form for `other`, so the last one
```

- `=0 ` נחשב רק בתחילת הערך ממש, עם הרווח. `$t` מציג אותו כטקסט: הוא שייך לצורות רבים.
- קטגוריה ללא צורה משלה לוקחת את הצורה האחרונה. גם מספר שלילי או שברי לוקח את הצורה האחרונה.
- זה עובד בכל שפה: `=0 none | one | {count} many` באנגלית.
- הקטגוריה מגיעה מה-`iso` של השפה, ואחרת מהקוד שלה. קוד ש-`Intl` אינו מכיר נופל חזרה לכלל האינדקס, והסמן עדיין מוסר, כך שהתוצאה לעולם אינה תלויה במכונה.
- `<i18n-t :plural>` פועל לפי אותו כלל. [`plural`](/he/api/module-options#plural) מותאם אישית או `customPluralRule` מקבלים את הערך הגולמי, כולל הסמן, ומחליטים בעצמם; `plural` שמחזיר `null` מחזיר את הקריאה לכלל המובנה, שמכבד את הסמן.

ללא הסמן, תבנית נשארת בכלל האינדקס, למעט חריג אחד שניתן לקרוא רק בדרך אחת: צורת אפס ללא מציין מקום, ואחריה צורה אחת לכל קטגוריה, עם `{count}` בכל צורה שכמה מספרים חולקים (`no files | {count} one | {count} few | {count} many` ב-`uk`).

עבור כללים משלכם הגדירו את [`plural`](/he/api/module-options#plural).

```ts
// { "apples": "no apples | one apple | {count} apples" }
$tc('apples', 0) // 'no apples'
$tc('apples', 10) // '10 apples'
$tc('cart', { count: 2, name: 'Ada' }) // count and params in one object
```

הארגומנט השלישי הוא `defaultValue`, לא params.

### `$has` {#$has}

```ts
(key: string) => boolean
```

האם מפתח נפתר בשפה הפעילה. השתמשו בו כדי להסתעף לפי טקסט אופציונלי במקום
להציג מפתח גולמי. כמו `$t`, הוא רואה גם את המפתחות של העמוד שעוזבים במהלך מעבר עמוד
באותה שפה.

```ts
if ($has('promo.banner')) show.value = true
```

## עיצוב {#formatting}

### `$tn` {#$tn}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

מעצב מספר עם `Intl.NumberFormat` בשפה הפעילה. מפתח בוחר פורמט בעל שם
מהתצורה.

פורמטים בעלי שם מגיעים מ-[`numberFormats`](/he/api/module-options#numberformats).

```ts
$tn(1234.5, { style: 'currency', currency: 'EUR' }) // '1.234,50 €' in de
$tn(1000, 'currency') // named format
$tn(1000, 'currency', 'de') // named format in another locale
```

### `$td` {#$td}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

מעצב תאריך עם `Intl.DateTimeFormat` בשפה הפעילה. מפתח בוחר פורמט בעל שם
מהתצורה.

פורמטים בעלי שם מגיעים מ-[`datetimeFormats`](/he/api/module-options#datetimeformats).

```ts
$td(new Date(), { dateStyle: 'long' })
$td(post.createdAt, 'short')
```

### `$tdr` {#$tdr}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

מעצב תאריך כזמן יחסי ("לפני 3 ימים") עם `Intl.RelativeTimeFormat`.

```ts
$tdr(Date.now() - 5 * 60_000) // '5 minutes ago' in en
```

## החלפה וקישורים {#switching-and-links}

### `$switchLocale` {#$switchlocale}

```ts
(locale: string) => Promise<boolean>
```

מנווט לעמוד הנוכחי בשפה אחרת. תחת `no_prefix` ובמצב hash הוא טוען את
התרגומים של השפה לפני הניווט; תחת `no_prefix` הנתיב מוחלף במקום (ללא
רשומה חדשה בהיסטוריה). שפה לא מוכרת מתעלמים ממנה.
הקריאה אסינכרונית: השתמשו ב-`await` כדי להריץ קוד אחרי הניווט. היא נפתרת ל-`true` כאשר
המילון של השפה פעיל, ול-`false` כאשר לא: ה-chunk נכשל בטעינה (המילון הנוכחי
נשאר; קראו לה שוב כדי לנסות מחדש) או שהחלפה חדשה יותר גברה.

```ts
await $switchLocale('de')
```

### `$switchLocalePath` {#$switchlocalepath}

```ts
(locale: string) => string
```

הנתיב של העמוד הנוכחי בשפה אחרת, ללא ניווט.

```vue
<NuxtLink :to="$switchLocalePath('de')">Deutsch</NuxtLink>
```

### `$switchLocaleRoute` {#$switchlocaleroute}

```ts
(locale: string) => RouteLocationRaw
```

אובייקט הנתיב של העמוד הנוכחי בשפה אחרת, ללא ניווט, או מחרוזת URL
עבור שפה עם `baseUrl` משלה. תחת `trailingSlash` לאובייקט יש `path` ו-`fullPath`,
בהתאם לכלל, עם ה-`query` וה-`hash` כפי שהם, ו-`router.push` או קישור שומרים עליהם.

### `$switchRoute` {#$switchroute}

```ts
(route: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, toLocale?: string) => Promise<void>
```

מנווט לנתיב אחר, תוך שמירה על השפה הפעילה או מעבר ל-`toLocale`. אסינכרוני כמו
`$switchLocale`.

```ts
$switchRoute('/about') // active locale
$switchRoute({ name: 'about' }, 'de') // switch to de
```

### `$localePath` {#$localepath}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => string
```

מחשב נתיב בשפה הנתונה, או בשפה הפעילה. מחרוזת עם סכמה `http(s):`, ‏`mailto:`
או `tel:` חוזרת כפי שהיא: אל תעבירו קלט משתמש כיעד קישור ללא בדיקה.

נתיב מחרוזת נקרא כעמוד שהוא מציג, כך שגם הנתיב המותאם אישית של שפה מוחל.

```ts
$localePath('/about') // '/about' in en, '/de/ueber-uns' in de with localeRoutes
$localePath({ name: 'about' }, 'fr') // '/fr/about'
```

### `$localeRoute` {#$localeroute}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => RouteLocationResolved
```

מחשב נתיב (route) בשפה הנתונה, או בשפה הפעילה. אובייקט פשוט, בטוח לשמירה ב-state. כאשר פרמטר צריך
escaping, יש לו `path`, ‏`fullPath`, ‏`query` ו-`hash` אבל אין `name` או `params`: הנתיב הוא מה שנותן לנתב
את ה-URL המקודד. עבור שפה בדומיין אחר, `path` ו-`fullPath` הם מוחלטים, מה שהנתב אינו יכול לקבל:
קישור כזה עובר דרך `<i18n-link>`, או `$localePath`.

### `$getRouteName` {#$getroutename}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric, locale?: string) => string
```

שם הנתיב ללא קידומת השפה — השם שלפיו התרגומים ממופים.

```ts
$getRouteName() // 'about' on /de/about
```

## תצורת עמוד {#page-config}

### `$defineI18nRoute` {#$definei18nroute}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

רושם תצורת שפה ותרגומים לכל עמוד מתוך רכיב.
ממזג לתוך השפה הפעילה ומוחל מחדש כאשר השפה משתנה.

קראו לו ב-`<script setup>` של עמוד, תמיד בפירוק מתוך `useNuxtApp()`. הבנייה קוראת את `locales`, ‏`localeRoutes` ו-`disableMeta` מהקריאה; בזמן ריצה רק `locales` משנה (תרגומים מוטבעים ממוזגים עבור השפה הפעילה). הכללים המלאים: [תצורת עמוד](/he/guide/per-component-translations).

```vue
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'de'],
  localeRoutes: { en: '/about', de: '/ueber-uns' },
})
</script>
```

### `$setI18nRouteParams` {#$seti18nrouteparams}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

מגדיר פרמטרים לכל שפה עבור הנתיב הנוכחי, כך שמקטע דינמי יכול להשתנות לפי שפה.
קראו לו במהלך SSR, לפני שה-head מוצג.

הפרמטרים מתנקים כאשר ניווט לנתיב אחר מתבצע, כולל מ-`/news/1` ל-`/news/4`, ששומר על שם הנתיב. פרטים: [נתיבים מותאמי שפה](/he/guide/custom-locale-routes).

```ts
$setI18nRouteParams({
  en: { slug: 'my-post' },
  de: { slug: 'mein-beitrag' },
})
```

## תרגומים בזמן ריצה {#runtime-translations}

### `$mergeTranslations` {#$mergetranslations}

```ts
(newTranslations: Translations) => void
```

ממזג תרגומים לשפה הפעילה בזמן ריצה, ודורס את מה שנטען.

מבצע מיזוג עמוק לתוך ה-chunk של העמוד הנוכחי בשפה הפעילה; מפתחות שאינו מזכיר נשמרים.

```ts
$mergeTranslations({ banner: { title: 'Sale' } })
```

### `$setTranslation` {#$settranslation}

```ts
(key: string, value: unknown) => void
```

מחליף את הערך ב-`key` במילון הפעיל. זו החלפה, לא מיזוג —
השתמשו ב-`$mergeTranslations` כאשר אחים קיימים צריכים להישמר.

```ts
$setTranslation('banner', { title: 'Sale' }) // drops other keys under banner
$setTranslation('banner.title', 'Sale') // dotted path
```

### `$loadPageTranslations` {#$loadpagetranslations}

```ts
(locale: string, routeName: string, translations: Translations) => Promise<void>
```

טוען תרגומים לעמוד בזמן ריצה, עבור תוכן שהמפתחות שלו אינם ידועים בזמן הבנייה.

ממזג לתוך ה-chunk ‏`(locale, routeName)` שבזיכרון, והמסך מתעדכן כאשר ה-chunk הזה פעיל. לא נשלף כאן payload: עבור עמוד שעדיין לא נטען התרגומים ממתינים, וכאשר הקובץ שלו נטען הם נשארים מעליו.

```ts
await $loadPageTranslations('en', 'about', { title: 'About us' })
```

### `$resolveTranslations` {#$resolvetranslations}

```ts
() => Translations
```

כל תרגום שנמצא כרגע בזיכרון עבור השפה והנתיב הפעילים, כעץ.
תצוגה לקריאה בלבד של מה ש-`$t()` יכול לפתור כרגע.

התייחסו לתוצאה כלקריאה בלבד.

### `$setMissingHandler` {#$setmissinghandler}

```ts
(handler: MissingHandler | null) => void
```

מתקין callback שנקרא עבור כל מפתח שלא נפתר. העבירו `null` כדי להסיר אותו.

המטפל רץ במקום אזהרת הפיתוח.

```ts
$setMissingHandler((locale, key, routeName) => {
  console.error(`[i18n] missing ${key} in ${locale} (${routeName})`)
})
```

### `$clearCache` {#$clearcache}

```ts
() => void
```

מוחק כל chunk תרגום שבמטמון וטוען מחדש את המילון של העמוד הנוכחי. העמוד
ממשיך להציג את התרגומים הנוכחיים שלו עד שהחדשים מגיעים. ה-HMR של הפיתוח קורא לו בכל
שינוי בקובץ תרגום.

```ts
const { clearCache } = useI18n()
clearCache()
```

טעינה מחדש שנכשלה שומרת על המילון הנוכחי.
