description: "ה-API המיוצא של כל חבילת @i18n-micro/*, שנוצר מתמונות המצב של ה-API ש-CI בודק מול קוד המקור."
---

מודול ה-Nuxt בנוי מחבילות `@i18n-micro/*` קטנות, ורובן עובדות גם בפני עצמן: `@i18n-micro/vue` באפליקציית Vue, ‏`@i18n-micro/core` בכל מקום. השתמשו בעמודים אלה כדי לבדוק מה חבילה מייצאת, לפי נקודת כניסה. כל עמוד נוצר מתמונת המצב ש-[`pnpm run api:surface`](https://s00d.github.io/nuxt-i18n-micro/contributing/maintenance-commands#api-surface) בודק מול מקורות ה-TypeScript, כך שייצוא אינו יכול להשתנות בלי ש-CI ישים לב.
