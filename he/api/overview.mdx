# הפניית API

## API של זמן ריצה

- [מתודות](/api/methods) — ‏`$t`, ‏`$ts`, ‏`$_t`, ‏`$_ts`, החלפת שפה, עוזרי ניתוב
- [אירועים](/api/events) — ‏`i18n:register`, ‏`i18n:beforeLocaleSwitch`, ‏`i18n:afterLocaleSwitch`
- [תרגומים ומטמון](/api/cache) — ‏`TranslationStorage`, טעינת payload, ‏`$clearCache`

## מידלוור שרת

מטפלי שרת משתמשים במידלוור ייעודי (לא בעוזרי `$t` של הלקוח):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — לתרגם במסלולי API ובמטפלי שרת
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — קריאת השפה שזוהתה ומטא־נתונים

עיין במדריך המלא [תרגומים בצד השרת](/guides/server-side-translations) עבור הגדרה, סדר עדיפויות של זיהוי שפה ודוגמאות.
