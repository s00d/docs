---

מדור זה מפרט כל אפשרות, פונקציית עזר, hook, composable ורכיב של מודול Nuxt, וכן את ה-API המיוצא של כל חבילת `@i18n-micro/*`. השתמשו בו כדי לחפש חתימה או ערך ברירת מחדל; ה[מדריך](/he/guide/getting-started) מסביר כיצד להשתמש בהם. רוב הטבלאות כאן נוצרות מקוד המקור, כך שהן תואמות לקוד.

## מודול Nuxt {#nuxt-module}

| עמוד | מכסה |
| --- | --- |
| [אפשרויות מודול](/he/api/module-options) | כל מפתח `i18n` ב-`nuxt.config`, עם טיפוס וברירת מחדל |
| [פונקציות עזר](/he/api/methods) | `$t`, `$tc`, `$tn`, `$td`, `$localePath`, `$switchLocale`, `$defineI18nRoute` והשאר |
| [Hooks](/he/api/events) | ה-hook של זמן הריצה `i18n:register` |

## Composables {#composables}

| Composable | שימוש |
| --- | --- |
| [`useI18n`](/he/composables/useI18n) | פונקציות העזר בתוך `<script setup>` |
| [`useI18nLocale`](/he/composables/useI18nLocale) | מצב השפה וה-cookie בתוסף זיהוי מותאם אישית |
| [`useI18nHead`](/he/composables/useI18nHead) | דריסות ברמת העמוד של תגיות ה-SEO שנוצרות |
| [`useLocaleHead`](/he/composables/useLocaleHead) | תגיות ה-SEO כאובייקט, עבור `useHead` משלכם |

## רכיבים {#components}

| רכיב | מציג |
| --- | --- |
| [`<i18n-t>`](/he/components/i18n-t) | תרגום יחיד, עם ריבוי, עיצוב ואינטרפולציה של slots |
| [`<i18n-link>`](/he/components/i18n-link) | `NuxtLink` לנתיב המותאם לשפה |
| [`<i18n-switcher>`](/he/components/i18n-switcher) | תפריט נפתח לבחירת שפה |
| [`<i18n-group>`](/he/components/i18n-group) | בלוק עם קידומת מפתח משותפת |

## שרת {#server}

מטפלי Nitro משתמשים ב-`useTranslationServerMiddleware` וב-`useLocaleServerMiddleware`, ולא בפונקציות העזר של הלקוח. ראו [נתיבי שרת](/he/guide/server-side-translations).

## חבילות {#packages}

[ממשקי API של חבילות](/he/api/packages/overview) מפרט את הייצואים של כל חבילת `@i18n-micro/*`, עמוד שנוצר אוטומטית לכל אחת.
