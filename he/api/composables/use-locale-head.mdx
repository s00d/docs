# 🌍 Composable `useLocaleHead`

ה־composable ‏`useLocaleHead` הוא כלי ב־`Nuxt I18n Micro` שעוזר לך לנהל תכונות SEO ותגי meta של HTML עבור מסלולים מקומיים. הוא מייצר באופן דינמי תכונות עבור `lang` ו־`dir` של מסמך ה־HTML ויוצר תגי `meta` ו־`link` כדי לשפר את ה־SEO של התוכן המקומי שלך.

תגי ה־head של SEO עבור המסלול הנוכחי: חלופות `hreflang` לכל שפה בתוספת `x-default`, קישור canonical, ‏`og:locale` ו־`lang`/`dir` על `<html>`.

נדרש רק כאשר `meta` מושבת או שברירות המחדל צריכות התאמה — עם `meta: true` המודול רושם את אותם תגים בעצמו.

## 🛠️ ערכי החזרה

ה־composable ‏`useLocaleHead` מחזיר אובייקט ריאקטיבי ופונקציית מעדכן שאתה צריך לקרוא אליה כאשר נתוני מקור משתנים. שתי הצורות נמצאות בחתימה למעלה, שנוצרה מהמקור.

### `metaObject`

מטען head ריאקטיבי ‏(html attrs, ‏meta, ‏link) מתאים ל־`useHead(metaObject)`.

- **דוגמה**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

מחשב מחדש את `metaObject` בהתבסס על מסלול, שפה ותצורה נוכחיים. קרא לו כאשר קלטים משתנים — בשינוי מסלול, לדוגמה.

- **דוגמה**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### גישה ל־`link` ול־`meta`

המערכים `link` ו־`meta` נגישים דרך `metaObject.value`:

- **דוגמה**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ דוגמאות שימוש

### שימוש בסיסי

ייצר תכונות head ספציפיות לשפה עם אפשרויות ברירת מחדל.

```js
const head = useLocaleHead()
```

### התאם תכונת מזהה

השתמש בתכונת מזהה מותאמת עבור התגים שנוצרו.

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### השבת תכונות SEO

ייצר תכונות head ללא הוספת תגי meta וקישור הקשורים ל־SEO.

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### ציין כתובת URL בסיסית

הגדר כתובת URL בסיסית מותאמת עבור כתובות URL של canonical וחלופיות.

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 תכונות נוספות

### תגי SEO של Meta ו־Link

כאשר `addSeoAttributes` מופעל, ה־composable מייצר אוטומטית את התגים הבאים:

- `og:locale` עבור השפה הנוכחית ‏(`language_TERRITORY`, קו תחתי). נגזר מ־`locale.og` או מומר מ־`locale.iso` כאשר אפשר.
- `og:url` עבור כתובת ה־URL הקנונית של העמוד.
- `og:locale:alternate` עבור גרסאות שפה חלופיות.
- קישורי `rel="canonical"` ו־`rel="alternate"` לאופטימיזציית SEO.
- קישור `hreflang="x-default"` המצביע לכתובת ה־URL של שפת ברירת המחדל. זה אומר למנועי חיפוש איזו כתובת URL להציג למשתמשים ששפתם אינה תואמת לאף אחת מהשפות המוגדרות.

### שפה וכיוון דינמיים

ה־composable קובע באופן דינמי את התכונות `lang` ו־`dir` בהתבסס על השפה של המסלול הנוכחי, ומבטיח שמסמך ה־HTML שלך מוגדר נכון עבור משתמשים בין־לאומיים.

### טיפול במסלולים מקומיים

אם המסלולים שלך מקדימים בקודי שפה (למשל, `/en/about`), ה־composable מתאים בחוכמה את הנתיב המלא ליצירת כתובות URL, ומבטיח שתכונות SEO מדויקות ורלוונטיות.

Composable זה מפשט את תהליך האופטימיזציה של אפליקציית Nuxt שלך לקהלים בין־לאומיים, ומבטיח שהאתר שלך מוכן היטב עבור מנועי חיפוש ומשתמשים גלובליים.

## 🛠️ דוגמת שימוש

הדוגמה הבאה מדגימה כיצד להשתמש ב־composable ‏`useLocaleHead` בתוך רכיב Vue עם הגדרות ברירת מחדל:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### הסבר על הקוד

- **Composable `useLocaleHead`**: composable זה נקרא בקטע `<script setup>` ומחזיר אובייקט המכיל `htmlAttrs`, ‏`meta` ו־`link`.

- **תג `<html>`**: התכונות `lang` ו־`dir` עבור מסמך ה־HTML נקבעות באופן דינמי בהתבסס על השפה הנוכחית ומיושמות על תג `<html>`.

- **קטע `<head>`**:
  - **תגי Meta**: נוצרים תגי meta הקשורים ל־SEO, כולל `og:locale`, ‏`og:url` ותגי `rel="canonical"` ו־`rel="alternate"` כדי לציין גרסאות שפה חלופיות של העמוד.
  - **תגי Link**: קישורי canonical, קישורים לגרסאות שפה חלופיות והקישור `hreflang="x-default"` (המצביע לכתובת ה־URL של שפת ברירת המחדל) כלולים.

- **קטע `<body>`**: התוכן הראשי של העמוד מוצג כאן. בדוגמה זו, נעשה שימוש בכותרת פשוטה ובפסקה.

### 📝 הערות

1. **תכונות**: התכונות שבשימוש ‏(`lang`, ‏`dir`, ‏`rel`, ‏`href`, ‏`hreflang`, ‏`property`, ‏`content`) מחולצות מהאובייקט שמחזיר `useLocaleHead`.

2. **יצירת תגי SEO**: אם האפשרות `addSeoAttributes` מוגדרת ל־`true`, ה־composable מייצר אוטומטית תגי SEO עבור השפה הנוכחית.

3. **כתובת URL בסיסית**: תוכל להגדיר את כתובת ה־URL הבסיסית המותאמת שלך באמצעות האפשרות `baseUrl` כדי לייצר נכון קישורי canonical וחלופיים.

דוגמה זו מדגימה כמה קל לשלב את `useLocaleHead` ברכיבי האפליקציה שלך כדי להבטיח תכונות SEO נכונות ולשפר את אינדקס מנוע החיפוש של עמודים מקומיים.

## 🧩 התאמה וחיי מחזור

- `useLocaleHead` אינו נרשם לשינויים בעצמו. הוא מחזיר `metaObject` ו־`updateMeta`.
- עליך לקרוא ל־`updateMeta()` כאשר קלטים משתנים (בדרך כלל בשינוי מסלול), לדוגמה מתוסף:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## מתי להשתמש ב־`useI18nHead` במקום

כאשר `meta: true` (ברירת המחדל), העדף את [`useI18nHead`](/api/composables/use-i18n-head) עבור עקיפות **לכל עמוד** ‏(hreflang מותאם, ‏`og:title` נוסף, השבתה חלקית). השתמש ב־`useLocaleHead` ישירות רק כאשר `meta: false` או שאתה מנהל את `useHead` בעצמך.
