# useI18nLocale

## חתימה

{/* generated:symbol:useI18nLocale — do not edit; run `pnpm run docs:generate` */}

```ts
useI18nLocale(): { getEffectiveLocale: (route: unknown, getLocaleFromRoute: GetLocaleFromRoute) => string; getLocale: () => string | null; getLocaleWithServerFallback: (serverLocale?: string | null) => string | null; getPreferredLocale: () => string | null; hashCookie: any; isValidLocale: (locale: string | null | undefined) => locale is string; locale: any; localeCookie: any; resolveInitialLocale: (options: ResolveInitialLocaleOptions) => string; setLocale: (locale: string | null) => void; syncLocale: (locale: string | null) => void; validLocales: string[] }
```

נקודת כניסה מרכזית לניהול שפה של i18n. משלב ‏`useState('i18n-locale')`, עוגיית שפה וכלי סנכרון.

{/* /generated:symbol:useI18nLocale */}

## שימוש

```vue
<script setup>
const {
  locale,
  localeCookie,
  hashCookie,
  validLocales,
  getPreferredLocale,
  getLocale,
  getLocaleWithServerFallback,
  getEffectiveLocale,
  resolveInitialLocale,
  setLocale,
  syncLocale,
  isValidLocale,
} = useI18nLocale()

// Set locale (updates state and cookies)
setLocale('de')

// Get current locale (state → cookie)
const current = getLocale()

// Get valid preferred locale
const preferred = getPreferredLocale()
</script>
```

## API

| מאפיין/מתודה                                 | טיפוס                                | תיאור                                                                          |
| ----------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| `locale`                                        | `Ref<string \| null>`               | מצב שפה ריאקטיבי ‏(`useState('i18n-locale')`)                                    |
| `localeCookie`                                  | `Ref`                               | עוגיית שפה (כאשר אפשרות `localeCookie` מופעלת)                                |
| `hashCookie`                                    | `Ref`                               | עוגייה בשימוש כאשר `hashMode` פעיל                                                |
| `validLocales`                                  | `string[]`                          | קודי שפה מופעלים מתצורת המודול (לא כולל `disabled`)                        |
| `getLocale()`                                   | `() => string \| null`              | השפה הנוכחית: מצב → עוגייה (או עוגיית hash במצב hash)                         |
| `getPreferredLocale()`                          | `() => string \| null`              | שפה ממצב/עוגייה **מאומתת** מול `validLocales`, או `null`             |
| `getLocaleWithServerFallback(serverLocale?)`    | `(serverLocale?) => string \| null` | מצב → עוגייה → הקשר שרת אופציונלי (בשימוש במהלך אתחול `no_prefix`)              |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string`             | שפה לטעינת תרגומים: מצב hash מעדיף מצב; אחרת קורא ממסלול |
| `resolveInitialLocale(options)`                 | `(options) => string`               | פותר שפה: מצב → `serverLocale` → מסלול; מסנכרן מצב כאשר צריך             |
| `setLocale(locale)`                             | `(locale: string \| null) => void`  | הגדר שפה וסנכרן לעוגיות                                                       |
| `syncLocale(locale)`                            | `(locale: string \| null) => void`  | סנכרן עוגיות בלבד (ללא עדכון מצב)                                                  |
| `isValidLocale(locale)`                         | `(locale) => boolean`               | בדוק אם מחרוזת נמצאת ב־`validLocales`                                                 |

### אפשרויות `resolveInitialLocale`

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

בשימוש פנימי על ידי התוסף הראשי בהפעלה. תוספים מותאמים יכולים לקרוא לו בעת מימוש זרימות זיהוי חלופיות.

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

מחזיר את השפה המשמשת לטעינת תרגומים ולעיצוב הודעות עבור אובייקט מסלול נתון.

## הגדרת שפה תכנותית

העדף את `useI18nLocale()` על פני שימוש ישיר ב־`useState('i18n-locale')`:

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
`setLocale()` מעדכן העדפת שפה (מצב + עוגייה) בלבד. כדי גם לטעון מחדש את הקשר התרגום הפעיל בלקוח, השתמש ב־`$switchLocale()` מ־`useNuxtApp()` או `useI18n()`. זה חשוב במיוחד עבור `no_prefix`, שבו ה־URL אינו משתנה. עיין ב־[שאלות נפוצות — החלף שפה מבלי לשנות את ה־URL](/guides/faq#-switch-locale-without-changing-the-url).
</Tip>
