# 🛠️ Composable `useI18n`

ה־composable ‏`useI18n` ב־`Nuxt I18n Micro` מספק גישה לרוב עוזרי ה־i18n של זמן הריצה ברכיבים ובסקריפטים. מתודות זמינות **עם וללא התחילית `$`** (לדוגמה `$t` ו־`t`).

חלק מההזרקות — ‏`$defineI18nRoute` ו־`$clearCache` — זמינות רק ב־`useNuxtApp()`. עיין ב־[מתודות — ‏`$defineI18nRoute`](/api/methods#definei18nroute) וב־[`$clearCache`](/api/methods#clearcache).

## 📊 מה הוא מחזיר

```ts
useI18n(): PluginsInjectionsWithAliases
```

כל עוזר זמן ריצה, כאובייקט רגיל.

אותן פונקציות שהתוסף מזריק בתור `$t`, ‏`$tc` וכן הלאה, זמינות תחת שם עם תחילית דולר וכן תחת כינוי חשוף — כך ש־`const \{ t \} = useI18n()` ו־`const \{ $t \} = useI18n()` שניהם עובדים.

**מחזיר** — העוזרים המתוארים ב־[הפניית מתודות](/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

## APIs זמינים רק ב־`useNuxtApp()`

אלה **אינם** מוחזרים על ידי `useI18n()`. ייבא אותם מ־`useNuxtApp()`:

| מתודה                     | מטרה                                                                         |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | מסלולי שפה לכל עמוד, הגבלות ותרגומים inline ב־`script setup` |
| `$clearCache()`            | מנקה את מטמון התרגום בזיכרון ו־chunks טעונים                            |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

עיין ב־[מתודות](/api/methods) לחתימות מלאות ודוגמאות.

## 🛠️ דוגמאות שימוש

### שליפת שפה בסיסית

שלוף את השפה הנוכחית של האפליקציה.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### תרגום עם פרמטרים

תרגם מחרוזת עם פרמטרים דינמיים, עם ערך ברירת מחדל כ־fallback.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### החלפת שפות

החלף את האפליקציה לשפה אחרת.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### יצירת מסלול מקומי

צור מסלול מקומי לשפה הנוכחית או שצוינה.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
