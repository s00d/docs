# 🌍 רכיב `<i18n-group>`

הרכיב `<i18n-group>` ב־Nuxt I18n Micro מספק דרך נוחה לקיבוץ תרגומים תחת תחילית משותפת, ומצמצם חזרות ומשפר ארגון קוד.

## 🎯 Slots

Slot ברירת המחדל מקבל `prefix` ופונקציית `t` הממודלת אליו, כך שמפתחות בתוכו נכתבים יחסית לתחילית:

```vue
<i18n-group prefix="checkout">
  <template #default="{ t }">
    <h2>{{ t('title') }}</h2>
    <p>{{ t('summary', { count: 3 }) }}</p>
  </template>
</i18n-group>
```

## 🛠️ דוגמת שימוש

### שימוש בסיסי

```vue
<template>
  <i18n-group prefix="product.details">
    <template #default="{ t }">
      <h1>{{ t('title') }}</h1>
      <p>{{ t('description') }}</p>
      <div class="price">{{ t('price', { value: 99.99 }) }}</div>
    </template>
  </i18n-group>
</template>
```

קובץ תרגום:

```json
{
  "product": {
    "details": {
      "title": "Premium Product",
      "description": "This is a premium product",
      "price": "Price: ${value}"
    }
  }
}
```

### עם מחלקה מותאמת

```vue
<template>
  <i18n-group prefix="user.profile" group-class="profile-section">
    <template #default="{ t }">
      <div class="user-info">
        <h2>{{ t('title') }}</h2>
        <p>{{ t('bio') }}</p>
        <div class="stats">
          <span>{{ t('stats.followers') }}</span>
          <span>{{ t('stats.following') }}</span>
        </div>
      </div>
    </template>
  </i18n-group>
</template>
```

קובץ תרגום:

```json
{
  "user": {
    "profile": {
      "title": "User Profile",
      "bio": "User biography goes here",
      "stats": {
        "followers": "Followers: {count}",
        "following": "Following: {count}"
      }
    }
  }
}
```

### עם תוכן דינמי

```vue
<template>
  <i18n-group prefix="blog.post">
    <template #default="{ t }">
      <article>
        <h1>{{ t('title') }}</h1>
        <div class="meta">
          {{ t('meta.author', { name: author }) }} |
          {{ t('meta.date', { date: publishDate }) }}
        </div>
        <div v-for="(section, index) in sections" :key="index">
          <h2>{{ t(`sections.${index}.title`) }}</h2>
          <p>{{ t(`sections.${index}.content`) }}</p>
        </div>
      </article>
    </template>
  </i18n-group>
</template>

<script setup>
const author = 'John Doe'
const publishDate = '2024-01-01'
const sections = ['intro', 'main', 'conclusion']
</script>
```

## 🎨 עיצוב

הרכיב עוטף את התוכן שלו ב־div עם המחלקה `i18n-group` וכל מחלקה נוספת שצוינה ב־prop ‏`groupClass`:

```css
.i18n-group {
  /* Your base styles */
}

.profile-section {
  /* Additional styles for profile sections */
}
```

## 🚀 שיטות עבודה מומלצות

1. **תחיליות עקביות**: השתמש בתחיליות עקביות והגיוניות המשקפות את מבנה האפליקציה שלך

```vue
<i18n-group prefix="features.pricing">
<i18n-group prefix="features.security">
```

2. **ארגון מודולרי**: קבץ תרגומים קשורים תחת תחיליות בעלות משמעות

```vue
<i18n-group prefix="checkout.payment">
<i18n-group prefix="checkout.shipping">
```

3. **רכיבים לשימוש חוזר**: צור רכיבים לשימוש חוזר עם קבוצות תרגום משלהם

```vue
<!-- UserProfile.vue -->
<i18n-group prefix="user.profile">

<!-- UserSettings.vue -->
<i18n-group prefix="user.settings">
```

4. **קבוצות מקוננות**: הימנע מקיבוץ עמוק מדי כדי לשמור על בהירות

```vue
<!-- Good -->
<i18n-group prefix="shop.product">

<!-- Avoid -->
<i18n-group prefix="shop.category.product.details.specs">
```
