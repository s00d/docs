# 🌍 רכיב `<i18n-link>`

הרכיב `<i18n-link>` ב־`Nuxt I18n Micro` הוא רכיב קישור רב־תכליתי שמלכתחל אוטומטית מסלולים בהתבסס על השפה הנוכחית. הוא פועל כעטיפה סביב הרכיב `<NuxtLink>`, ומספק תכונות נוספות כגון עיצוב קישור פעיל ותמיכה בקישורים חיצוניים.

`to` מקבל כל מה ש־`NuxtLink` מקבל — נתיב, מסלול בעל שם או אובייקט מסלול פתור. ‏URL מוחלט מזוהה ומעובד כ־`<a target="_blank" rel="noopener noreferrer">` פשוט במקום להיות מקומי.

## 🛠️ דוגמאות שימוש

### שימוש בסיסי

```vue
<i18n-link to="/about">About Us</i18n-link>
```

דוגמה זו יוצרת קישור לעמוד `/about`, מקומי לשפה הנוכחית.

### עיצוב קישור פעיל עם סגנונות inline

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

לקישור יהיה טקסט מודגש כאשר המשתמש נמצא בעמוד `/about`, מה שמאפשר לך לעצב את הקישור הפעיל ישירות עם סגנונות inline.

### טיפול בקישורים חיצוניים

הרכיב מזהה אוטומטית קישורים חיצוניים ומוסיף את התכונות הנדרשות לאבטחה.

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

קישור זה יפתח את `https://example.com` בלשונית חדשה עם `rel="noopener noreferrer"` מוחל.

## 🎨 סגנונות

הרכיב משתמש כעת בסגנונות inline למצב הפעיל במקום במחלקה. תוכל להתאים אישית סגנונות אלה באמצעות ה־prop ‏`activeStyle`.

### סגנונות פעילים ברירת מחדל

- **משקל פונט**: `bold`
- **צבע**: יורש את צבע ברירת המחדל של הדפדפן (אם לא צוין `color` ב־`activeStyle`).

תוכל לעקוף אלה על ידי סיפוק סגנונות מותאמים דרך ה־prop ‏`activeStyle`.

### סגנונות פעילים מותאמים

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

בדוגמה זו, הקישור יהיה מודגש וירוק כאשר הוא פעיל.

## 🚀 תכונות נוספות

### Slot לתוכן מותאם

תוכל להעביר תוכן מותאם בתוך הקישור באמצעות slots, מה שהופך את הרכיב לגמיש למקרי שימוש שונים.

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### שיפורי נגישות

הרכיב תומך ב־`aria-label` ותכונות נגישות אחרות כדי להבטיח חוויה נגישה יותר.

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
