# 🌍 רכיב `<i18n-switcher>`

הרכיב `<i18n-switcher>` ב־`Nuxt I18n Micro` מספק ממשק נפתח ידידותי למשתמש למעבר בין שפות שונות באפליקציה שלך. הרכיב הזה ניתן להתאמה גבוהה, ומאפשר אינטגרציה חלקה עם עיצוב האפליקציה שלך.

שפות עם `disabled: true` **מושמטות** מהתפריט הנפתח (הן נשארות זמינות דרך `$getLocales()` עבור SEO / תגי head). רק שפות שניתן להחליף אליהן מקבלות `NuxtLink` + ‏`hreflang`.

## 🛠️ דוגמאות שימוש

### שימוש בסיסי

```vue
<template>
  <i18n-switcher />
</template>
```

זה מעבד switcher של שפה עם סגנון והתנהגות ברירת מחדל.

### תוויות מותאמות וסגנונות inline

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

דוגמה זו מדגימה switcher של שפה מותאם אישית באופן מלא עם תוויות מותאמות וסגנונות inline.

## 🔌 Slots

כל חלק חזותי של ה־switcher ניתן להחלפה. ה־slots מפורטים עם טבלת ה־props למעלה; כל אחד מקבל תוכן תבנית:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Slots ששמם מסתיים ב־`-item`, ‏`-link-content` או מתחיל ב־`before-item` מקבלים את אובייקט `locale` שאליו הם שייכים.

## 🎨 סקירת סגנונות

הרכיב `<i18n-switcher>` מגיע עם סגנונות בסיסיים המוגדרים באמצעות סגנונות inline שניתן לעקוף בקלות על ידי העברת סגנונות מותאמים דרך props. הנה סקירה קצרה של הסגנון ברירת המחדל:

- **Wrapper**: שולט במיקום התפריט הנפתח.
- **Button**: מעצב את כפתור הפעלת התפריט הנפתח.
- **Dropdown**: מעצב את רשימת התפריט הנפתח.
- **Items**: מעצב כל פריט ברשימה.
- **Links**: מעצב את הקישורים בתוך כל פריט.
- **Icon**: מעצב את אייקון מחוון התפריט הנפתח.

תוכל להתאים אישית סגנונות אלה על ידי העברת סגנונות מותאמים דרך ה־props המתאימים, ולהבטיח ש־switcher השפה משתלב בצורה חלקה בממשק המשתמש של האפליקציה שלך.
