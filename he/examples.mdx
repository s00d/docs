# 📚 דוגמאות ושימוש ב־Nuxt I18n Micro

חלק זה מספק דוגמאות שונות המדגימות כיצד להשתמש ב־`Nuxt I18n Micro` ביישום Nuxt.js שלך. תראה כיצד להחליף שפות, להשתמש ברכיבי `<i18n-link>`, ‏`<i18n-switcher>` ו־`<i18n-t>`, ולטפל במפתחות תרגום באופן דינמי.

## 🛠️ הגדרה בסיסית

הנה הגדרה בסיסית כדי להתחיל עם `Nuxt I18n Micro`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 החלפת שפה

### החלפת שפות באופן תכנותי

דוגמה זו מדגימה כיצד להחליף שפות באופן תכנותי באמצעות כפתורים:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### דוגמת JSON להחלפת שפה

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### שימוש ברכיב `<i18n-switcher>`

הרכיב `<i18n-switcher>` מספק תפריט נפתח להחלפת שפה עם תוויות מותאמות אישית:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 📝 עיבוד מפתחות דינמיים מקובצי תרגום

בתרחישים מסוימים, ייתכן שתרצה לעבור על מפתחות דינמיים המאוחסנים בתוך קובצי התרגום שלך ולהציג את הערכים שלהם באופן מותנה. הדוגמה שלהלן מדגימה כיצד להשיג זאת באמצעות `Nuxt I18n Micro`.

### דוגמה: עיבוד מפתחות דינמיים

דוגמה זו מביאה מערך של מפתחות מנתיב תרגום ספציפי (במקרה זה, `dynamic`) ועוברת עליהם. כל מפתח נבדק לקיומו באמצעות `$has` לפני עיבוד הערך שלו עם `$t`.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### דוגמת קובץ תרגום (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### דוגמה: עיבוד מפתחות דינמיים מאובייקט

בדוגמה זו, אנו מטפלים באובייקט המאוחסן בתוך קובץ התרגום שלך. אנו מביאים ועוברים על מפתחות האובייקט, ומעבדים באופן דינמי הן את שמות המפתחות והן את הערכים המשויכים אליהם.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### דוגמת קובץ תרגום (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 שימוש ב־`<i18n-t>` לתרגומים עם slots ואינטרפולציה

הרכיב `<i18n-t>` שימושי לעיבוד תרגומים עם תוכן דינמי ותגי HTML:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### דוגמת JSON עבור `<i18n-t>`

```json
{
  "greeting": "Welcome to the page"
}
```

### עם אינטרפולציה

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### דוגמת JSON לאינטרפולציה

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 שימוש ב־`$tc` לרבים

הפונקציה `$tc` ב־`Nuxt I18n Micro` מטפלת בצורות רבים בהתאם לספירה ולהגדרות השפה. הדבר שימושי להתאמה דינמית של הודעות הכוללות ספירות, כגון פריטים, התראות או ישויות אחרות שיכולות להשתנות במספר.

### דוגמה: שימוש ב־`$tc` לרבים

בדוגמה הבאה, אנו מציגים הודעה המציינת את מספר התפוחים באמצעות `$tc`. מפתח התרגום מטפל במספר צורות רבים בהתאם לספירה שסופקה.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### דוגמת JSON לרבים

כך תוכל להגדיר את התרגום בקובץ ה־JSON שלך כדי לטפל בצורות רבים שונות:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### הסבר

- **`$tc('apples', 0)`**: מחזיר את הצורה הראשונה, בשימוש כאשר הספירה היא אפס (`"no apples"`).
- **`$tc('apples', 1)`**: מחזיר את הצורה השנייה, בשימוש כאשר הספירה היא אחד (`"one apple"`).
- **`$tc('apples', 10)`**: מחזיר את הצורה השלישית עם ערך הספירה, בשימוש כאשר הספירה היא שתיים ומעלה (`"10 apples"`).

### דוגמה נוספת עם רבים מורכבים יותר

אם היישום שלך צריך לטפל בכללי רבים מורכבים יותר (למשל, מקרים ספציפיים עבור אפס, אחד, שניים, מעט, הרבה, אחר), תוכל להרחיב את מחרוזות התרגום בהתאם:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: יכול להיות מוגדר להחזיר `"two apples"`.
- **`$tc('apples', 3)`**: יכול להחזיר `"a few apples"`, בהתאם לכללים המוגדרים עבור הספירה.

## 🌐 שימוש ב־`$tn` לעיצוב מספרים

הפונקציה `$tn` מעצבת מספרים בהתאם לשפה הנוכחית באמצעות ה־API של `Intl.NumberFormat`. הדבר שימושי להצגת מספרים באופן שתואם את ההגדרות האזוריות של המשתמש, כגון מטבע, אחוזים או פורמטים אחרים של מספרים.

### דוגמה: שימוש ב־`$tn` לעיצוב מספרים

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ שימוש ב־`$td` לעיצוב תאריך ושעה

הפונקציה `$td` מעצבת תאריכים ושעות בהתאם לשפה הנוכחית באמצעות ה־API של `Intl.DateTimeFormat`. הדבר שימושי להצגת תאריכים ושעות בפורמטים המוכרים למשתמש על סמך הגדרות השפה שלו.

### דוגמה: שימוש ב־`$td` לעיצוב תאריך ושעה

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ שימוש ב־`$tdr` לעיצוב תאריך יחסי

הפונקציה `$tdr` מעצבת תאריכים כזמנים יחסיים (למשל, "לפני 5 דקות", "לפני 2 ימים") בהתאם לשפה הנוכחית באמצעות ה־API של `Intl.RelativeTimeFormat`. הדבר שימושי להצגת הפרשי זמן ביחס לתאריך ולזמן הנוכחיים.

### דוגמה: שימוש ב־`$tdr` לעיצוב תאריך יחסי

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
