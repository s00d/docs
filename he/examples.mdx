# 📚 דוגמאות ושימוש ב-Nuxt I18n Micro

חלק זה מספק דוגמאות שונות המדגימות כיצד להשתמש ב-`Nuxt I18n Micro` באפליקציית Nuxt.js שלכם. תראו כיצד להחליף locales, להשתמש בקומפוננטות `<i18n-link>`, `<i18n-switcher>` ו-`<i18n-t>`, ולטפל במפתחות תרגום באופן דינמי.

## 🛠️ הגדרה בסיסית

הנה הגדרה בסיסית כדי להתחיל עם `Nuxt I18n Micro`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 החלפת locale

### החלפת locales פרוגרמטית

דוגמה זו מדגימה כיצד להחליף locales באופן פרוגרמטי באמצעות כפתורים:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### דוגמת JSON להחלפת locale

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### שימוש בקומפוננטה `<i18n-switcher>`

הקומפוננטה `<i18n-switcher>` מספקת רשימה נפתחת להחלפת locale עם תוויות מותאמות אישית:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 🌐 שימוש ב-`<i18n-link>` לניווט מקומי

הקומפוננטה `<i18n-link>` מטפלת אוטומטית בניתוב ספציפי ל-locale:

```vue

  <div>
    <i18n-link to="/about">{{ $t('about') }}</i18n-link>

  </div>

<script setup>
import { useNuxtApp } from '#imports'

</script>
```

### דוגמת JSON לקישורי ניווט

## 📝 רינדור מפתחות דינמיים מקבצי תרגום

בתרחישים מסוימים ייתכן שתרצו לעבור על מפתחות דינמיים המאוחסנים בקבצי התרגום שלכם ולרנדר את הערכים שלהם באופן מותנה. הדוגמה שלמטה מדגימה כיצד להשיג זאת באמצעות `Nuxt I18n Micro`.

### דוגמה: רינדור מפתחות דינמיים

דוגמה זו מביאה מערך של מפתחות מנתיב תרגום ספציפי (במקרה זה, `dynamic`) ועוברת עליהם. כל מפתח נבדק לקיומו באמצעות `$has` לפני רינדור הערך שלו עם `$t`.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### קובץ תרגום לדוגמה (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### דוגמה: רינדור מפתחות דינמיים מאובייקט

בדוגמה זו, אנו מטפלים באובייקט המאוחסן בקובץ התרגום שלכם. אנו מביאים ועוברים על מפתחות האובייקט, ומרנדרים באופן דינמי הן את שמות המפתחות והן את הערכים המשויכים אליהם.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### קובץ תרגום לדוגמה (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 שימוש ב-`<i18n-t>` לתרגומים עם slots ואינטרפולציה

הקומפוננטה `<i18n-t>` שימושית לרינדור תרגומים עם תוכן דינמי ותגי HTML:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### דוגמת JSON עבור `<i18n-t>`

```json
{
  "greeting": "Welcome to the page"
}
```

### עם אינטרפולציה

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### דוגמת JSON לאינטרפולציה

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 שימוש ב-`$tc` לצורות רבים

הפונקציה `$tc` ב-`Nuxt I18n Micro` מטפלת בצורות רבים על בסיס הספירה והגדרות ה-locale. זה שימושי להתאמה דינמית של הודעות שכוללות מספרים, כגון פריטים, התראות, או ישויות אחרות שיכולות להשתנות בכמות.

### דוגמה: שימוש ב-`$tc` לצורות רבים

בדוגמה הבאה, אנו מציגים הודעה המציינת את מספר התפוחים באמצעות `$tc`. מפתח התרגום מטפל במספר צורות רבים על בסיס הספירה שסופקה.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### דוגמת JSON לצורות רבים

הנה כיצד ניתן להגדיר את התרגום בקובץ ה-JSON שלכם כדי לטפל בצורות רבים שונות:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### הסבר

- **`$tc('apples', 0)`**: מחזיר את הצורה הראשונה, בשימוש כאשר הספירה היא אפס (`"no apples"`).
- **`$tc('apples', 1)`**: מחזיר את הצורה השנייה, בשימוש כאשר הספירה היא אחד (`"one apple"`).
- **`$tc('apples', 10)`**: מחזיר את הצורה השלישית עם ערך הספירה, בשימוש כאשר הספירה היא שניים ומעלה (`"10 apples"`).

### דוגמה נוספת עם צורות רבים מורכבות יותר

אם האפליקציה שלכם צריכה לטפל בכללי רבים מורכבים יותר (למשל, מקרים ספציפיים עבור אפס, אחד, שניים, מעט, רבים, אחר), תוכלו להרחיב את מחרוזות התרגום בהתאם:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: ניתן להגדיר כך שיחזיר `"two apples"`.
- **`$tc('apples', 3)`**: יכול להחזיר `"a few apples"`, בהתאם לכללים המוגדרים עבור הספירה.

## 🌐 שימוש ב-`$tn` לעיצוב מספרים

הפונקציה `$tn` מעצבת מספרים בהתאם ל-locale הנוכחי באמצעות ה-API של `Intl.NumberFormat`. זה שימושי להצגת מספרים באופן שתואם להגדרות האזוריות של המשתמש, כגון מטבע, אחוזים או פורמטים אחרים של מספרים.

### דוגמה: שימוש ב-`$tn` לעיצוב מספרים

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ שימוש ב-`$td` לעיצוב תאריך ושעה

הפונקציה `$td` מעצבת תאריכים ושעות בהתאם ל-locale הנוכחי באמצעות ה-API של `Intl.DateTimeFormat`. זה שימושי להצגת תאריכים ושעות בפורמטים המוכרים למשתמש על בסיס הגדרות ה-locale שלו.

### דוגמה: שימוש ב-`$td` לעיצוב תאריך ושעה

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ שימוש ב-`$tdr` לעיצוב תאריך יחסי

הפונקציה `$tdr` מעצבת תאריכים כזמנים יחסיים (למשל, "5 minutes ago", "2 days ago") בהתאם ל-locale הנוכחי באמצעות ה-API של `Intl.RelativeTimeFormat`. זה שימושי להצגת הבדלי זמן ביחס לתאריך ולשעה הנוכחיים.

### דוגמה: שימוש ב-`$tdr` לעיצוב תאריך יחסי

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
