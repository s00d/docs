## דרישות

- **Node.js**: 18 ומעלה.
- **Nuxt**: 3.x או 4.x.

המודול תומך גם במבנה פרויקט Nuxt 3 ‏(`pages/**/*.vue`) וגם במבנה Nuxt 4 ‏(`app/pages/**/*.vue`). התרגומים ממוקמים בשורש הפרויקט לפי המוסכמה (`locales/`), גם בעת שימוש בתיקיית `app/` של Nuxt 4.

## התקנת מודול Nuxt

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

רשום אותו ב־`nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

עיין ב־[התחלה מהירה](/quickstart) להסבר מלא או ב־[הפניית תצורה](/guides/configuration) לכל האפשרויות.

## מבנה פרויקט

כברירת מחדל המודול מצפה ל:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

קבצים ברמת השורש ממוזגים לכל קובץ ספציפי לעמוד בזמן הבנייה. קבצים ספציפיים לעמוד נוצרים אוטומטית כאשר הם חסרים במהלך `nuxt dev`.

## מבנה Nuxt 4

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

כדי למקם את התרגומים תחת `app/`, הגדר `translationDir: 'app/locales'`.

## TypeScript

המודול מייצר טיפוסי ambient עבור `useI18n`, ‏`$t` ועוזרים קשורים בהתבסס על קובצי השפה המשמשים כברירת מחדל. הדבר מופעל כברירת מחדל (`types: true`).

לטיפוסיות חזקה יותר של מפתחות תרגום, עיין ב־[`@i18n-micro/types-generator`](/integrations/types-generator).
