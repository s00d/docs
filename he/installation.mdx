## דרישות

- **Node.js**: 18 ומעלה.
- **Nuxt**: 3.x או 4.x.

המודול תומך הן במבנה פרויקט Nuxt 3 (`pages/**/*.vue`) והן במבנה Nuxt 4 (`app/pages/**/*.vue`). התרגומים נמצאים בשורש הפרויקט לפי המוסכמה (`locales/`), גם בעת שימוש בתיקיית `app/` של Nuxt 4.

## התקנת מודול Nuxt

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

רשמו אותו ב-`nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

ראו [התחלה מהירה](/quickstart) להסבר מלא או [הפניית קונפיגורציה](/guides/configuration) לכל אפשרות.

## מבנה פרויקט

כברירת מחדל המודול מצפה ל:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

קבצי root ממוזגים לכל קובץ ספציפי לעמוד בזמן build. קבצים ספציפיים לעמוד נוצרים אוטומטית כאשר הם חסרים במהלך `nuxt dev`.

## מבנה Nuxt 4

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

כדי למקם את התרגומים תחת `app/`, הגדירו `translationDir: 'app/locales'`.

## TypeScript

המודול יוצר טיפוסים סביבתיים עבור `useI18n`, `$t` ועוזרים קשורים על בסיס קבצי ה-locale ברירת המחדל שלכם. זה מופעל כברירת מחדל (`types: true`).

לטיפוסים חזקים יותר של מפתחות תרגום, ראו [`@i18n-micro/types-generator`](/integrations/types-generator).
