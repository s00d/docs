## 🚀 התחלה מהירה

### התקנה

התקינו את המודול באפליקציית Nuxt שלכם:

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

### קונפיגורציה בסיסית

הוסיפו את המודול ל-`nuxt.config.ts` שלכם:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

<Tip>
- **קבצי root** (`locales/en.json` וכו') — תרגומים משותפים לכל האפליקציה (תפריטים, פוטר, ממשק משתמש נפוץ). עם `translationPayloads.mode: 'premerged'` (ברירת מחדל), הם ממוזגים לכל עמוד בזמן build.
- **קבצים ספציפיים לעמוד** (`locales/pages/<route>/<locale>.json`) — תרגומים ייחודיים לעמודים ספציפיים, נטענים רק כאשר מבקרים בעמוד.
- **Routes דינמיים** — `pages/articles/[id].vue` ממופה ל-`locales/pages/articles-id/` (סוגריים מרובעים מוחלפים במקפים)
- **יצירה אוטומטית** — כל קבצי התרגום נוצרים אוטומטית כאשר הם חסרים במהלך `nuxt dev`.
</Tip>

<Info>
המודול תומך בשני מבנים:

- **Pages**: `pages/**/*.vue` (Nuxt 3) או `app/pages/**/*.vue` (Nuxt 4)
- **Translations**: השאירו את `locales/` ב**שורש הפרויקט** כברירת מחדל (מוסכמה מומלצת), לא בתוך `app/`

```tree
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   ├── en.json
│   └── pages/
└── nuxt.config.ts
```

מיקום משותף אופציונלי: `i18n: \{ translationDir: 'app/locales' \}` (ראו [fixture `n3`](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/n3)).

עבור עוזר ה-CLI האופציונלי `text-to-i18n`, השתמשו ב-[`nuxt-i18n-micro-cli` ≥ 2.1.1](/guides/cli#-text-to-i18n-command) כך ש-`app/pages` ו-`app/components` נסרקים משורש הפרויקט.
</Info>

### שימוש בסיסי

השתמשו בתרגומים בקומפוננטות שלכם:

```vue
<template>
  <div>
    <h1>{{ $t('welcome') }}</h1>
    <p>{{ $t('description', { name: 'World' }) }}</p>

    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" @click="$switchLocale(locale.code)">
        {{ locale.code }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useI18n } from '#imports'

const { $t, $getLocales, $switchLocale } = useI18n()
</script>
```
