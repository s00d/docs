title: "<i18n-group>"
description: "הרכיב <i18n-group> מעניק ל-slot שלו פונקציית t התחומה לקידומת מפתח."
---

`<i18n-group>` תוחם בלוק של markup לקידומת מפתח אחת. השתמשו בו כאשר מפתחות רבים של מקטע חולקים קידומת ואינכם רוצים לחזור עליה. ה-slot המוגדר כברירת מחדל מקבל `t` שמוסיפה את הקידומת בהתחלה.

## Props ו-slot {#props-and-slot}

| Prop | סוג | ברירת מחדל | תיאור |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | קידומת המפתח שכל חיפוש בתוך ה-slot נפתר ביחס אליה. |
| `groupClass` | `string` | `''` | class נוסף על אלמנט העטיפה. |

**\*** חובה.

### Slots {#slots}

| Slot | Bindings | תיאור |
| --- | --- | --- |
| `default` | `prefix`, `t` | מקבל את `prefix` ופונקציית `t` התחומה אליו. |

## התנהגות {#behaviour}

- מרנדר `<div class="i18n-group {groupClass}">` סביב ה-slot.
- `t(key, params)` שקולה ל-`$t(prefix + '.' + key, params)` עבור ה-route הנוכחי.
- רק ה-`t` של ה-slot תחומה: `$t` ו-`<i18n-t>` מקוננים בתוך הקבוצה עדיין מקבלים מפתחות מלאים.

## דוגמה {#example}

```json
{
  "checkout": { "title": "Checkout", "items": "Items: {count}" }
}
```

```vue
<template>
  <i18n-group prefix="checkout" group-class="checkout">
    <template #default="{ t }">
      <h2>{{ t('title') }}</h2>
      <p>{{ t('items', { count: 3 }) }}</p>
    </template>
  </i18n-group>
</template>
```
