`<i18n-t>` מרנדר תרגום אחד לתוך אלמנט. השתמשו בו כאשר תרגום צריך רכיבים בתוכו (קישור בתוך משפט), צורת רבים, או מספר או תאריך מעוצבים. הוא פותר את המפתח עבור ה-route הנוכחי, כמו `$t`.

## Props {#props}

| Prop | סוג | ברירת מחדל | תיאור |
| --- | --- | --- | --- |
| `keypath` **\*** | `string` | — | מפתח התרגום לרינדור. |
| `plural` | `number \| string \| null` | — | ספירה שבוחרת את צורת הרבים. הגדירו אותו כדי להשתמש ב-`$tc` במקום `$t`. `null` פירושו לא מוגדר. |
| `tag` | `string` | `'span'` | האלמנט לרינדור. |
| `params` | `Record<string, string \| number \| boolean>` | — | ערכי אינטרפולציה שמוצבים בתרגום. |
| `defaultValue` | `string` | `''` | מרונדר במקום הרכיב כאשר `hideIfEmpty` מדכא תרגום ריק. |
| `html` | `boolean` | `false` | רינדור התרגום כ-HTML ולא כטקסט. רק עבור תרגומים שבשליטתכם: `params` עוברים escape, התרגום לא. |
| `hideIfEmpty` | `boolean` | `false` | לא לרנדר דבר כאשר התרגום נפתר למחרוזת ריקה. |
| `customPluralRule` | `PluralFunc` | `null` | כלל רבים עבור אלמנט זה בלבד, הדורס את הכלל המוגדר. התשובה שלו משמשת כמות שהיא; `null` מרנדר ריק. |
| `number` | `number \| string \| null` | — | מעצב את הערך עם `$tn` ומעביר אותו לתרגום כ-`{number}`, לצד `params`. |
| `date` | `Date \| string \| number \| null` | — | מעצב את הערך עם `$td` ומעביר אותו לתרגום כ-`{date}`, לצד `params`. |
| `relativeDate` | `Date \| string \| number \| null` | — | מעצב את הערך עם `$tdr` ומעביר אותו לתרגום כ-`{relativeDate}`, לצד `params`. |

**\*** חובה.

## כללי רינדור {#rendering-rules}

המקרה התואם הראשון קובע את הפלט:

1. `number` — התרגום עם `{ ...params, number: $tn(number) }`.
2. `date` — התרגום עם `{ ...params, date: $td(date) }`.
3. `relativeDate` — התרגום עם `{ ...params, relativeDate: $tdr(relativeDate) }`.
4. `plural` — הצורה ש-`$tc` בוחר, כולל [הסמן `=0 `](/he/api/methods#$tc), עם `{ ...params, count }`; או `customPluralRule(keypath, count, params, locale, t)` כאשר הוא מוגדר, שקורא את הערך הגולמי, כולל הסמן, והתשובה שלו משמשת כמות שהיא, כאשר `null` הוא ריק.
5. אחרת, התרגום עם `params`.

`null` נחשב כלא מוגדר. בכל המקרים:

- `defaultValue` מחליף מפתח חסר, בכל ענף.
- `hideIfEmpty` מרנדר את `defaultValue` במקום תוצאה ריקה.
- `html` מרנדר את התוצאה כ-HTML. `params` עוברים escape, התרגום לא; slots מתעלמים מהם.
- slot מסוג `default` מקבל `{ translation }`, ו-slots בעלי שם מתעלמים מהם.
- אחרת, כל slot בעל שם מחליף כל placeholder מסוג `{name}`, לפני param באותו שם. ערך param שנראה כמו placeholder נשאר טקסט.

הפלט של `date` ו-`relativeDate` נושא `data-allow-mismatch="text"`, מכיוון שאזור הזמן והשעון של השרת אינם אלה של הדפדפן. הגדירו [`timeZone`](/he/api/module-options#timezone) כדי לרנדר תאריך לוח שנה אחד בשניהם; `relativeDate` תלוי בשעון, ולכן עדיין עשוי להיות שונה.

## דוגמה {#example}

```json
{
  "terms": "I accept the {link}.",
  "termsLink": "terms of use",
  "items": "no items | one item | {count} items"
}
```

```vue
<template>
  <i18n-t keypath="terms" tag="p">
    <template #link>
      <NuxtLink :to="$localePath('/terms')">{{ $t('termsLink') }}</NuxtLink>
    </template>
  </i18n-t>

  <i18n-t keypath="items" :plural="cart.length" />
</template>
```

`html` מגדיר `innerHTML`: השתמשו בו רק עבור תרגומים שבשליטתכם. `params` עוברים escape, כך שנתוני משתמש בטוחים שם, וכך גם מפתח שלא נמצא לו תרגום.
