title: "<i18n-switcher>"
description: "הרכיב <i18n-switcher> הוא תפריט נפתח של השפות המופעלות, שכל אחת מהן מקשרת לעמוד הנוכחי באותה שפה."
---

`<i18n-switcher>` מציג כפתור עם השפה הפעילה ותפריט נפתח של כל השפות המופעלות, כולל הפעילה. השתמשו בו לתפריט שפות מוכן; בנו תפריט משלכם מ-[`$getLocales`](/he/api/methods#$getlocales) ו-[`$switchLocalePath`](/he/api/methods#$switchlocalepath) כשאתם צריכים markup שונה. כל פריט מקשר לעמוד הנוכחי באותה שפה.

## Props ו-slots {#props-and-slots}

| Prop | טיפוס | ברירת מחדל | תיאור |
| --- | --- | --- | --- |
| `customLabels` | `Record<string, string>` | `() => ({})` | שם תצוגה לכל קוד שפה, הדורס את `displayName` מתצורת השפה. |
| `customWrapperStyle` | `CSSProperties` | `() => ({})` | סגנון inline לעוטף החיצוני. |
| `customButtonStyle` | `CSSProperties` | `() => ({})` | סגנון inline לכפתור שפותח את התפריט הנפתח. |
| `customDropdownStyle` | `CSSProperties` | `() => ({})` | סגנון inline ללוח התפריט הנפתח. |
| `customItemStyle` | `CSSProperties` | `() => ({})` | סגנון inline לכל פריט בתפריט הנפתח. |
| `customLinkStyle` | `CSSProperties` | `() => ({})` | סגנון inline לקישור שבתוך פריט. |
| `customActiveLinkStyle` | `CSSProperties` | `() => ({})` | סגנון inline לקישור של השפה הפעילה כעת. |
| `customDisabledLinkStyle` | `CSSProperties` | `() => ({})` | סגנון inline לכפתור השפה *הנוכחית* כאשר היא מוגדרת `disabled: true` בתצורה. |
| `customIconStyle` | `CSSProperties` | `() => ({})` | סגנון inline לאייקון החץ שעל הכפתור. |

### Slots {#slots}

| Slot | Bindings | תיאור |
| --- | --- | --- |
| `before-button` | — | תוכן לפני הכפתור שפותח את התפריט הנפתח. |
| `before-selected-locale` | — | תוכן לפני תווית השפה הפעילה בתוך הכפתור. |
| `after-selected-locale` | — | תוכן אחרי תווית השפה הפעילה בתוך הכפתור. |
| `before-dropdown` | — | תוכן בין הכפתור ללוח התפריט הנפתח. |
| `before-dropdown-items` | — | תוכן בראש התפריט הנפתח, מעל רשימת השפות. |
| `before-item` | `locale` | תוכן לפני כל פריט שפה. |
| `before-link-content` | `locale` | תוכן לפני תווית השפה בתוך הקישור שלה. |
| `after-link-content` | `locale` | תוכן אחרי תווית השפה בתוך הקישור שלה. |
| `after-item` | `locale` | תוכן אחרי כל פריט שפה. |
| `after-dropdown-items` | — | תוכן בתחתית התפריט הנפתח, מתחת לרשימת השפות. |
| `after-dropdown` | — | תוכן אחרי לוח התפריט הנפתח. |

## התנהגות {#behaviour}

- מציג כל שפה שאין לה `disabled: true`, כולל הפעילה.
- כל פריט הוא `<a>` אל `$switchLocalePath(code)`. נתיב מתפרש תחת `app.baseURL`; `baseUrl` של שפה בדומיין אחר נשאר מוחלט. לקישור מוגדרים `hreflang` ו-`lang` לערך `iso || code`, `dir` כאשר לשפה יש כזה, `aria-current="page"` בשפה הנוכחית, והמחלקה `switcher-locale-<code>`. לחיצה קוראת ל-`$switchLocale(code)` וסוגרת את התפריט הנפתח; לחיצה עם מקש שינוי נשארת לטיפול הדפדפן.
- הרשימה נשארת ב-HTML של השרת, מוסתרת, כך שסורקים רואים את הקישורים. Escape או לחיצה מחוץ לרשימה סוגרים אותה.
- תווית: `customLabels[code]`, אחר כך `displayName` של השפה, ואחר כך הקוד (עם אזהרה בסביבת פיתוח).
- סגנונות: ברירות מחדל inline קטנות (כפתור ולוח לבנים עם מסגרת, הפריט הפעיל מודגש וכחול). כל prop מסוג `custom*Style` מוחל אחרי ברירת המחדל של החלק שלו. לכפתור יש המחלקות `i18n-switcher-button` ו-`language-switcher`, לעוטף `i18n-switcher-wrapper`, ולרשימה `i18n-switcher-dropdown`. המיקומים משתמשים במאפייני CSS לוגיים, כך ש-`dir="rtl"` עובד.

## דוגמה {#example}

```vue
<template>
  <i18n-switcher
    :custom-labels="{ en: 'English', de: 'Deutsch' }"
    :custom-button-style="{ borderRadius: '4px' }"
  >
    <template #before-link-content="{ locale }">
      <img :src="`/flags/${locale.code}.svg`" alt="" width="16" />
    </template>
  </i18n-switcher>
</template>
```
