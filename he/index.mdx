Nuxt I18n Micro הוא מודול i18n קל משקל ובעל ביצועים גבוהים עבור Nuxt 3 ו-4, המיועד לפרויקטים גדולים. הוא שומר על זמני build, שימוש בזיכרון וגודל bundle נמוכים בהשוואה לפתרונות i18n מסורתיים כמו `@nuxtjs/i18n`.

routes מתורגמים נוצרים בזמן ה-build על ידי `@i18n-micro/route-strategy` ונפתרים בזמן ריצה על ידי `@i18n-micro/path-strategy`, כך שקישורים, ה-switcher, `hreflang` והפניות תואמים כולם את ה-router. התרגומים הם JSON בלבד, מחולקים בין קובצי שורש משותפים לבין קבצים לכל עמוד ששרת הפיתוח יוצר עבורכם, עם HMR מובנה.

<CodeGroup>

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>
