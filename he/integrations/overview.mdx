חבילות `@i18n-micro/*` מביאות את ליבת התרגום של Nuxt I18n Micro ל-Vue, ‏React, ‏Preact, ‏Solid, ‏Astro, ‏VitePress ול-JavaScript רגיל. השתמשו בהן כשהאפליקציה שלכם אינה אפליקציית Nuxt, או כשסקריפט או שרת מחוץ ל-Nuxt צריכים את אותם קובצי תרגום. כל החבילות חולקות מודל מופע אחד, חוזה אחד למתאם נתב ואותן ארבע קומפוננטות, המתוארים פעם אחת בעמוד הזה.

לכל חבילה יש playground תחת `packages/<name>/playground` במאגר.

## המופע {#the-instance}

`createI18n(options)` מחזיר מופע אחד שמחזיק את המילונים, את ה-locale הנוכחי ואת הנתיב הנוכחי. האפשרויות זהות בכל חבילה:

| אפשרות | טיפוס | ברירת מחדל | הערות |
| --- | --- | --- | --- |
| `locale` | `string` | חובה | ה-locale הפעיל. |
| `fallbackLocale` | `string` | `locale` | נבדק כשמפתח חסר ב-`locale`. |
| `messages` | `Record<locale, Translations>` | `{}` | מילוני שורש (הנתיב `'index'`). |
| `routeMessages` | `Record<route, Record<locale, Translations>>` | `{}` | מילוני נתיבים. רק ב-Runtime, ‏React, ‏Preact, ‏Node ו-VitePress. |
| `plural` | `PluralFunc` | `defaultPlural` | כלל ריבוי מותאם אישית. |
| `missingWarn` | `boolean` | `true` | ‏`console.warn` בדפדפן, בפיתוח בלבד, עבור מפתח חסר. |
| `missingHandler` | `(locale, key, routeName) => void` | — | נקרא במקום האזהרה. |
| `numberFormats` | `Record<locale, Record<name, Intl.NumberFormatOptions>>` | — | פורמטים בעלי שם: `tn(9.5, 'currency')`. |
| `datetimeFormats` | `Record<locale, Record<name, Intl.DateTimeFormatOptions>>` | — | פורמטים בעלי שם: `td(date, 'short')`. |
| `timeZone` | `string` | אזור הזמן של סביבת הריצה | אזור IANA עבור תאריכי `td`; אינו משפיע על `tdr`. הגדירו אותו כדי שהשרת והדפדפן ירנדרו אותו תאריך. |
| `now` | `() => number` | `Date.now` | השעון של `tdr`. העבירו ל-hydration את הזמן של השרת כדי ששניהם ירנדרו אותו טקסט. |
| `localeIso` | `Record<code, string>` | — | תג BCP 47 שמשמש לכללי ריבוי (`ua` → `uk-UA`). ‏React, ‏Preact ו-Solid לוקחים אותו מ-`iso` ב-`locales` של ה-provider. |

המילונים נמצאים ב-`i18n.storage.translations`, ‏`Map` עם מפתחות מהצורה `locale:route` (`en:index`, `en:about`).

מפתח מחופש במילון של הנתיב הנוכחי, ואז במילון השורש, קודם עבור `locale` ואז עבור `fallbackLocale`. מפתח חסר מחזיר את המפתח עצמו (או את ה-`defaultValue` שהעברתם).

```ts
i18n.addTranslations('en', { nav: { home: 'Home' } }) // root, deep-merged
i18n.addRouteTranslations('en', 'about', { title: 'About us' }) // route chunk
i18n.addTranslations('en', { nav: { home: 'Start' } }, false) // replace instead of merge
i18n.setRoute('about')
i18n.t('title') // 'About us'
i18n.t('nav.home') // 'Start' (root key, still visible on the route)
```

### תרגום ועיצוב {#translate-and-format}

| מתודה | מחזירה |
| --- | --- |
| `t(key, params?, defaultValue?, routeName?)` | הערך (מחרוזת, מספר, אובייקט) עם `{param}` משובצים. |
| `ts(...)` | כמו `t`, כמחרוזת. |
| `tc(key, count \| params, defaultValue?)` | צורת ריבוי. |
| `tn(value, options \| name)` | `Intl.NumberFormat` ב-locale הפעיל. |
| `td(value, options \| name)` | `Intl.DateTimeFormat`. |
| `tdr(value, options?)` | זמן יחסי (`3 days ago`). |
| `has(key, routeName?)` | `true` כשל-locale הפעיל יש את המפתח (במילון הנתיב או השורש; ה-fallback לא נבדק). |

`defaultPlural` מפצל את הערך לפי `|` ובוחר את הצורה באינדקס `count`, מוגבל לאחרונה; ספירה שלילית, שברית או `NaN` בוחרת את הצורה האחרונה.

`plural` מותאם אישית מקבל `(key, count, params, locale, getter)`. קראו את הערך דרך `getter(key)`; אל תפצלו את המפתח:

```ts
import type { PluralFunc } from '@i18n-micro/vue'

const plural: PluralFunc = (key, count, params, _locale, getter) => {
  const value = getter(key)
  if (typeof value !== 'string') return null
  const forms = value.split('|').map((form) => form.trim())
  return (count === 1 ? forms[0] : forms[1] ?? forms[0])!.replace('{count}', String(count))
}
```

## מתאם נתב {#router-adapter}

חבילות ה-SPA אינן תלויות בנתב. מתאם נתב (`I18nRoutingStrategy`) אומר להן איך לקרוא את הנתיב הנוכחי, לנווט ולבנות נתיב מותאם ל-locale. המתאמים המובנים מוסיפים קידומת לכל locale מלבד `defaultLocale` (`/about`, `/de/about`).

| חבר | חובה | בשימוש על ידי |
| --- | --- | --- |
| `getCurrentPath(): string` | כן | בדיקת קישור פעיל (לפי עמוד; query ו-hash לא נחשבים), `switchLocale` (שומר אותם) |
| `push({ path }): void` | כן | `switchLocale`, ‏`<I18nLink>` ללא `linkComponent`, ‏`<I18nSwitcher>` |
| `replace({ path }): void` | כן | — |
| `resolvePath(to, locale)` | לא | `localePath`, ‏`localeRoute`, ‏`<I18nLink>`; בלעדיו הנתיבים מוחזרים כפי שהם |
| `linkComponent` | לא | `<I18nLink>` מרנדר אותו (למשל `RouterLink`) במקום `<a>` |
| `getRoute()` | לא | `{ fullPath, query }` עבור פונקציות עזר של SEO |

`push` ו-`replace` הם חובה ב-Vue, ‏React, ‏Preact ו-Solid. ל-Astro יש מתאם משלו בצד השרת עם `push`/`replace` אופציונליים (ראו [Astro](/he/integrations/astro-package#router-adapter)).

מתאם מינימלי לכל נתב מבוסס history:

```ts
import type { I18nRoutingStrategy } from '@i18n-micro/react'

const locales = ['en', 'de']
const stripLocale = (path: string) => path.replace(/^\/(en|de)(?=\/|$)/, '') || '/'

export const historyAdapter: I18nRoutingStrategy = {
  getCurrentPath: () => window.location.pathname + window.location.search + window.location.hash,
  push: ({ path }) => window.history.pushState({}, '', path),
  replace: ({ path }) => window.history.replaceState({}, '', path),
  resolvePath: (to, locale) => {
    const path = stripLocale(typeof to === 'string' ? to : to.path || '/')
    return locale === 'en' ? path : `/${locale}${path === '/' ? '' : path}`
  },
}
```

## קומפוננטות {#components}

Vue, ‏React, ‏Preact ו-Solid מגיעות עם אותן ארבע קומפוננטות. ה-props שלהן תואמים; React, ‏Preact ו-Solid מעבירות props אחרים לאלמנט השורש.

### `<I18nT>` {#&lt;i18nt&gt;}

| Prop | טיפוס | הערות |
| --- | --- | --- |
| `keypath` | `string` | חובה |
| `params` | `object` | ערכי שיבוץ |
| `plural` | `number \| string` | מרנדר `tc(keypath, count)` |
| `number` | `number \| string` | מעביר `tn(number)` בתור `{number}` |
| `date` | `Date \| string \| number` | מעביר `td(date)` בתור `{date}` |
| `relativeDate` | `Date \| string \| number` | מעביר `tdr(relativeDate)` בתור `{relativeDate}` |
| `tag` | `string` | אלמנט עוטף, ברירת מחדל `span` |
| `html` | `boolean` | מרנדר את התרגום כ-HTML; הוא חייב להיות מהימן, הפרמטרים עוברים escape |
| `defaultValue` | `string` | מחליף מפתח חסר, ומרונדר ללא עטיפה כש-`hideIfEmpty` מסתיר ערך ריק |
| `hideIfEmpty` | `boolean` | לא מרנדר כלום עבור תרגום ריק |
| `customPluralRule` | `PluralFunc` | כלל ריבוי עבור האלמנט הזה |

רק prop עיצוב אחד חל, והם נבדקים בסדר הזה: `number`, ‏`date`, ‏`relativeDate`, ‏`plural`.

#### טקסט עשיר {#rich-text}

`{placeholder}` יכול להכיל אלמנט. ב-Vue זה slot בעל שם; ב-React, ‏Preact ו-Solid ה-prop ‏`components` נותן אלמנטים, או פונקציות שמחזירות אלמנט, לפי שם. בכל מקרה הוא גובר על פרמטר בעל אותו שם, עובד בכל ענף, ושורד locale שמשנה את סדר ה-placeholders.

```tsx
// { "terms": "I accept the {link} of {company}" }
<I18nT keypath="terms" params={{ company: 'ACME' }} components={{ link: <a href="/terms">terms</a> }} />
```

ב-Solid העבירו פונקציה כש-placeholder חוזר: צומת אחד יכול לעמוד במקום אחד בלבד. ‏`children` מחליפים את הטקסט, וכפונקציה הם מקבלים `{ translation }`, כמו ה-slot ברירת המחדל של Vue. ‏`html` מתעלם מכל אלה.

### `<I18nLink>` {#&lt;i18nlink&gt;}

| Prop | טיפוס | הערות |
| --- | --- | --- |
| `to` | `string \| { path }` | מותאם ל-locale דרך `resolvePath` של המתאם |
| `activeStyle` | אובייקט סגנון | ממוזג מעל `style` בעמוד הנוכחי; React, ‏Preact ו-Solid מחילות אותו גם על מקטע שמעליו |
| `localeRoute` | פונקציה | דורס את `resolvePath` עבור הקישור הזה |

כתובות URL חיצוניות (`https://`, `mailto:`, `tel:`) מתרנדרות כ-`<a target="_blank" rel="noopener noreferrer">`; ‏`target` או `rel` משלכם גוברים. ‏`onClick` תמיד רץ. לחיצה עם מקש שינוי, כפתור עכבר אחר או `target` נשארים בטיפול הדפדפן.

### `<I18nSwitcher>` {#&lt;i18nswitcher&gt;}

רשימה נפתחת של ה-locales המופעלים (locales עם `disabled: true` מוסתרים) עם סגנונות ברירת מחדל מוטמעים. הפריטים שלה הם קישורים, עם `lang`, ‏`hreflang` ו-`dir` מה-locale. כברירת מחדל, לחיצה על אחד מהם מגדירה את ה-locale וקוראת ל-`push` של המתאם עם הנתיב הנוכחי המותאם ל-locale; prop ‏`switchLocale` מחליף את הפעולה הזו. עם `localeRoute` וללא נתב, הדפדפן עוקב אחרי הקישור. Escape או לחיצה מחוץ לרשימה סוגרים אותה.

| Prop | הערות |
| --- | --- |
| `locales`, `currentLocale`, `getLocaleName` | דורסים את הערכים שסופקו |
| `switchLocale(code)` | מחליף את ההחלפה המובנית |
| `localeRoute` | מחליף את `resolvePath` |
| `customLabels` | `{ de: 'DE' }` |
| `customWrapperStyle`, `customButtonStyle`, `customDropdownStyle`, `customItemStyle`, `customLinkStyle`, `customActiveLinkStyle`, `customDisabledLinkStyle`, `customIconStyle` | דריסות סגנון |

### `<I18nGroup>` {#&lt;i18ngroup&gt;}

`<div class="i18n-group">` שמעביר `t` עם קידומת לצאצאיו. הוא **לא** מוסיף קידומת לקריאות `<I18nT>` או `t()` שבתוכו; רק ה-`t` שהוא מעביר הלאה מקבל קידומת.

| Prop | הערות |
| --- | --- |
| `prefix` | חובה, למשל `'profile'` |
| `groupClass` | class נוסף על העוטף |

ה-`t` עם הקידומת מגיע דרך scoped slot ב-Vue ‏(`v-slot="{ t }"`) ודרך צאצא מסוג render-prop ב-React, ‏Preact ו-Solid ‏(`{({ t }) => …}`).

## מפתחות עם טיפוסים {#typed-keys}

`t()` מקבלת כל מחרוזת. כדי לקבל השלמה אוטומטית למפתחות שלכם, צרו קובץ הצהרות באמצעות [מחולל הטיפוסים](/he/integrations/types-generator). המפתחות מוצעים, לא נאכפים, והפרמטרים אינם מוגדרים בטיפוסים.

## השוואה למודול Nuxt {#compared-with-the-nuxt-module}

לחבילות אין ניתוב מבוסס קבצים, אין middleware של שרת ואין טוען תרגומים: אתם מחליטים מתי לטעון JSON ‏(`import`, ‏`fetch`, או `@i18n-micro/node` בשרת) ובאיזה מתאם נתב להשתמש. זיהוי locale, תגי meta של SEO ויצירת נתיבים הם יכולות של Nuxt; ל-Astro יש middleware משלו לזיהוי ו-`useLocaleHead` ל-SEO.
