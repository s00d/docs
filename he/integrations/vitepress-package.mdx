`@i18n-micro/vitepress` מוסיף מילונים בזמן ריצה לאתר VitePress: `$t` ו-`<I18nT>` בתוך markdown, פונקציות עזר לנתיבים ותגיות SEO, בנוי על [`@i18n-micro/vue`](/he/integrations/vue-package). השתמשו בו כאשר אותן מחרוזות ממשק מופיעות בדפים רבים ואינכם רוצים לשכפל אותן לכל locale. ה-locale עוקב אחר ה-locales מבוססי הנתיב של VitePress עצמו (`/`, `/fr/`).

## מתי להשתמש בו {#when-to-use-it}

| צורך | פתרון |
|------|----------|
| `.md` משוכפלים, קידומות URL | `locales` של VitePress |
| `$t` בזמן ריצה / רכיבים / סנכרון נתיבים / SEO ב-head | `@i18n-micro/vitepress` |
| תוויות המעטפת של ערכת הנושא המוגדרת כברירת מחדל (`docFooter`, ממשק החיפוש) | `themeConfig` משלכם לכל locale |

<Tip>

**Playground** — [`packages/vitepress/playground`](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/vitepress/playground) — `pnpm -C packages/vitepress/playground dev`

</Tip>

## התקנה {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vitepress
```

```bash npm
npm install @i18n-micro/vitepress
```

```bash yarn
yarn add @i18n-micro/vitepress
```

</CodeGroup>

תלויות peer: `vitepress` `>=1.0.0 || >=2.0.0-alpha.0`, `vue` `^3.3.0`. סקריפטים של Node משתמשים ב-`@i18n-micro/node`, המותקן עם החבילה ומיוצא מחדש דרך `/node`. הטיפוסים שפורסמו דורשים Vue 3.5.5 ומעלה עם `skipLibCheck: false`; עם `skipLibCheck: true`, ההגדרה הרגילה בתבנית, גם גרסאות ישנות יותר עוברות קומפילציה.

## הגדרה {#setup}

```
locales/en.json
locales/fr.json
locales/pages/guide/demo/en.json   # optional page-scoped
locales/pages/guide/demo/fr.json
```

קבצי דפים ממופים לשמות נתיבים באותה דרך כמו ב-Nuxt/Astro (`guide/demo` → `guide-demo`).

### 1. הגדרות — `@i18n-micro/vitepress/config` {#1-config-—-@i18n-micro/vitepress/config}

```ts
// .vitepress/config.mts
import { defineConfig } from 'vitepress'
import { withI18n, buildVitePressLocales } from '@i18n-micro/vitepress/config'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English', og: 'en_US' },
  { code: 'fr', iso: 'fr-FR', displayName: 'Français', og: 'fr_FR' },
]
const defaultLocale = 'en'

export default defineConfig(
  withI18n(
    {
      locales: buildVitePressLocales(locales, defaultLocale),
      // themeConfig.i18nRouting is injected automatically
    },
    {
      locale: defaultLocale,
      defaultLocale,
      locales,
      translationDir: 'locales',
      metaBaseUrl: 'https://example.com', // optional SEO head
    },
  ),
)
```

### 2. ערכת נושא — `@i18n-micro/vitepress/theme` {#2-theme-—-@i18n-micro/vitepress/theme}

```ts
// .vitepress/theme/index.ts
import DefaultTheme from 'vitepress/theme'
import { defineI18nTheme } from '@i18n-micro/vitepress/theme'

export default defineI18nTheme(DefaultTheme)
```

ה-locale ההתחלתי נלקח מהנתיב הנוכחי לפני ההתקנה (ללא הבהוב של ה-locale של ברירת המחדל ב-`/fr/…`).

### מתקדם: `createI18n` ידני {#advanced-manual-createi18n}

factory אחד עבור הלקוח: פלאגין Vue + מתודות נתיב + `enhanceApp` (ללא ייצואים נפרדים של פונקציות עזר לנתב).

```ts
import { createI18n, messagesFromGlob } from '@i18n-micro/vitepress'

const i18n = createI18n({
  locale: 'en',
  defaultLocale: 'en',
  locales: [{ code: 'en' }, { code: 'fr' }],
  messages: messagesFromGlob(import.meta.glob('../../locales/*.json', { eager: true })),
})

i18n.localizePath('/guide', 'fr')
// in theme enhanceApp:
i18n.enhanceApp({ app, router })
```

### סקריפטים של Node — `@i18n-micro/vitepress/node` {#node-scripts-—-@i18n-micro/vitepress/node}

משתמש ב-`createI18n` / `loadTranslations` של `@i18n-micro/node` (כמו ב-Astro וב-CLI), ואז מצמיד מתודות נתיב של VitePress עם `BaseI18n.extend`:

```ts
import { createI18n } from '@i18n-micro/vitepress/node'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  translationDir: './locales',
  locales: ['en', 'fr'],
  defaultLocale: 'en',
})
await i18n.loadTranslations()
i18n.t('cta.readMore')
i18n.localizePath('/guide', 'fr')
```

Node רגיל ללא נתיבים: `import { createI18n } from '@i18n-micro/node'`.

## תרגומים בתוך הדף {#in-page-translations}

כל קובץ markdown של VitePress הוא Vue SFC.

### רכיבים גלובליים ו-`$t` (מומלץ ב-markdown) {#global-components-and-$t-recommended-in-markdown}

`createI18n` / `defineI18nTheme` מתקינים את `@i18n-micro/vue`, שרושם את `I18nT` / `I18nLink` / `I18nGroup` / `I18nSwitcher` ואת `$t` / `$tc` / `$ts`.

```md
{{ $t('cta.readMore') }}

<I18nT keypath="greeting" :params="{ name: 'VitePress' }" />

<I18nLink to="/guide/demo">Demo</I18nLink>
```

### `useI18n` ב-`<script setup>` {#usei18n-in-<script-setup>}

```md
<script setup>
import { useI18n } from '@i18n-micro/vitepress'
const { t, tc, locale, localePath, switchLocale } = useI18n()
</script>

# {{ t('section.title') }}
```

## תפריט שפות נפתח {#language-dropdown}

כאשר ל-`locales` יש יותר מרשומה אחת, VitePress מציג תפריט שפות משלו (`VPNavBarTranslations`). `withI18n` מחבר את `themeConfig.i18nRouting` כך שהגלובוס תואם ל-`<I18nSwitcher>` / לפונקציות העזר לנתיבים.

השתמשו ב-`<I18nSwitcher>` רק ב-layouts מותאמים אישית, לא לצד הגלובוס של ברירת המחדל.

## הערות SSR {#ssr-notes}

- ה-locale בזמן prerender מגיע מנתיב ה-URL, לא מעוגיות.
- קוד ערכת הנושא אסור שייגע ב-`window` בזמן הייבוא.
- יבאו את `defineI18nTheme` מ-`/theme` כך שהערכת ההגדרות ב-Node לעולם לא תטען את `virtual:i18n-micro/*`.

## ממשק ה-API {#api-surface}

| ייצוא | תפקיד |
|--------|------|
| `createI18n` (`.`) | לקוח: פלאגין Vue + מתודות נתיב + `enhanceApp` |
| `getLocaleFromPath` / `stripSiteBase` / `routeNameFromPath` (`.`) | סנכרון locale ידני כאשר `syncWithVitePress: false` |
| `createI18n` (`/node`) | Node: `@i18n-micro/node` + מתודות נתיב |
| `defineI18nTheme` (`/theme`) | ערכת נושא ללא קוד boilerplate |
| `withI18n` (`/config`) | הגדרות + מודולים וירטואליים + SEO אופציונלי |
| `buildVitePressLocales` (`/config`) | בניית `locales` של VitePress מתוך `Locale[]` |
| `buildVitePressLocaleHead` (`/config`) | SEO head ידני (משמש גם את `metaBaseUrl`) |
| `messagesFromGlob` | מיפוי glob → messages אופציונלי עבור `createI18n` |
| `useI18n` / `I18nT` / … | מיוצאים מחדש מ-`@i18n-micro/vue` |
| `BaseI18n.extend` (`@i18n-micro/core`) | הצמדת מתודות מותאמות לכל מופע i18n |

## אתרים בסגנון OpenAPI (נעילות שילוב) {#openapi-style-sites-integration-locks}

חבילת בדיקות רגרסיה: `packages/vitepress/tests/integration-openapi.test.ts` (נתיבים עמוקים, `base=/openapi_docs/`, סנכרון כבוי + locale ידני, מחוללים ב-Node, SEO).

| דפוס | מה לעשות |
|---------|---------|
| דפי `/…/{spec}/{op}` עמוקים, רק JSON של ממשק בשורש | העדיפו את ברירת המחדל `syncWithVitePress: true` (שומר על `setRoute('index')` כשאין מילון דף) **או** `syncWithVitePress: false` + `getLocaleFromPath` |
| לעולם אל תקראו ל-`setRoute(deepName)` ללא מילוני דפים | מפתחות הממשק בשורש נעלמים עד `setRoute('index')` |
| מחוללים / `getTranslation` | `createI18n` מ-`/node` + `await loadTranslations()` + `i18n.t(key)` (הגדירו `i18n.locale`) |
| canonical מותאם ב-`transformPageData` | העבירו `meta: false` ל-`withI18n` (מניעת תגיות כפולות) |
| SEO של החבילה עם base של האתר | `metaBaseUrl` + `base` של VitePress → כתובות URL מוחלטות כוללות את ה-base |
| שינוי שם מגרסאות ישנות של החבילה | `withI18nMicro` → `withI18n`, `createVitePressI18n` → `createI18n`, `loadMessages` → `createI18n` של node |
