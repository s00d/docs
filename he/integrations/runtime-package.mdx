---

`@i18n-micro/runtime` הוא מופע ה-i18n שאינו תלוי ב-framework: מילונים, `t()`, צורות ריבוי, עיצוב `Intl` ומנוי לשינויים, ללא `fs` וללא framework. השתמשו בו ב-TypeScript רגיל, ב-web worker, בפונקציית edge, או כבסיס ל-binding משלכם. החבילות של React, Preact, Node ו-Astro מרחיבות את אותה מחלקה.

## התקנה {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/runtime
```

```bash npm
npm install @i18n-micro/runtime
```

```bash yarn
yarn add @i18n-micro/runtime
```

</CodeGroup>

אין תלויות peer. עבור קבצי תרגום בדיסק השתמשו ב-[`@i18n-micro/node`](/he/integrations/nodejs-package).

## הגדרה {#setup}

```ts
import { createI18n } from '@i18n-micro/runtime'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    en: { greeting: 'Hello, {name}!', apples: 'no apples | one apple | {count} apples' },
    de: { greeting: 'Hallo, {name}!' },
  },
  routeMessages: {
    about: { en: { title: 'About us' } },
  },
})
```

כל האפשרויות (`plural`, `missingWarn`, `missingHandler`, `numberFormats`, `datetimeFormats`) מפורטות ב[מופע](/he/integrations/overview#the-instance).

## תרגום {#translate}

```ts
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.tc('apples', 5) // '5 apples'
i18n.tn(1234.5) // '1,234.5'

i18n.setRoute('about')
i18n.t('title') // 'About us' (route dictionary)
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!' (root, still visible)
```

טענו מילונים נוספים מאוחר יותר:

```ts
i18n.loadMessages({ fr: { greeting: 'Bonjour, {name} !' } }, { about: { fr: { title: 'À propos' } } })
i18n.addTranslations('fr', { nav: { home: 'Accueil' } }) // deep merge; pass false to replace

await i18n.loadFromUrl('/locales/fr.json', { locale: 'fr' })
await i18n.loadFromUrl('/locales/pages/about/fr.json', { locale: 'fr', routeName: 'about' })
await i18n.loadFromUrls([
  { url: '/locales/en.json', locale: 'en' },
  { url: '/locales/de.json', locale: 'de' },
])
```

`loadFromUrl` משתמשת ב-`fetch` (העבירו `init` עבור כותרות) וזורקת שגיאה בתגובה שאינה OK. `loadFromUrls` טוענת אחד אחרי השני.

## החלפת locale {#switch-locale}

```ts
i18n.locale = 'de'
i18n.t('greeting', { name: 'Ada' }) // 'Hallo, Ada!'
```

שינויי locale, נתיב ומילון מודיעים למנויים, וכך ה-bindings של ה-frameworks מרנדרים מחדש:

```ts
const stop = i18n.subscribe(() => {
  document.querySelector('#greeting')!.textContent = i18n.t('greeting', { name: 'Ada' }) as string
})
i18n.locale = 'fr'
stop()
```

`getSnapshot()` מחזירה מחרוזת שמשתנה בכל הודעה (עבור stores בסגנון `useSyncExternalStore`).

## לכל בקשה {#per-request}

המופע מחזיק locale אחד ונתיב אחד. בשרת, אל תחליפו מופע משותף לכל בקשה: שתי בקשות במקביל יראו כל אחת את ה-locale של השנייה. `i18n.fork(locale)` נותן לבקשה מופע משלה: locale, fallback ונתיב משלה; אותם מילונים, מעצבים וכללים. העלות של fork זהה לא משנה כמה מילונים יש. Fork רואה כתיבות להורה שלו עד הכתיבה הראשונה שלו עצמו, והכתיבות שלו נשארות בו. [Node.js](/he/integrations/nodejs-package#per-request) מוסיף את `run`.

## API {#api}

| חבר | הערות |
| --- | --- |
| `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has` | ראו [תרגום ועיצוב](/he/integrations/overview#translate-and-format) |
| `locale`, `fallbackLocale` | קריאה/כתיבה |
| `currentRoute`, `setRoute(name)`, `getRoute()` | הנתיב הפעיל, ברירת מחדל `'index'` |
| `loadMessages(messages?, routeMessages?)` | מיזוג locales ונתיבים רבים בבת אחת |
| `addTranslations(locale, tree, merge = true)`, `addRouteTranslations(locale, route, tree, merge = true)` | |
| `loadFromUrl(url, { locale?, routeName?, init? })`, `loadFromUrls(entries)` | `fetch` של JSON |
| `hasTranslation(key)` | ה-locale הפעיל, כל נתיב (בניגוד ל-`has`, שבודק את הנתיב הפעיל ואת השורש) |
| `setTranslation(key, value)`, `resolveTranslations()` | כתיבת מפתח אחד; קריאת העץ הממוזג |
| `clear()`, `clearCache()` | מחיקת כל המילונים |
| `subscribe(cb)`, `getSnapshot()` | הודעות על שינויים |
| `storage` | `{ translations: Map<'locale:route', Translations> }` |

קוד שאינו תג שפה מקבל את צורות הריבוי שלו מ-`localeIso: { ua: 'uk-UA' }`; `localeIsoMap(locales)` בונה זאת מהרשומות ברשימת locales שיש להן `iso`.

ייצואי המודול: `createI18n`, `I18n`, `fetchJsonTranslations`, `FormatService`, `interpolate`, `localeIsoMap` והטיפוסים `I18nOptions`, `LoadFromUrlOptions`, `LoadFromUrlEntry`, `TranslationStorage`, `Translations`, `Locale`, `PluralFunc`. חתימות מלאות: [מדריך החבילה](/he/api/packages/runtime).
