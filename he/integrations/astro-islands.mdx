אי רץ בדפדפן, שם מופע ה-i18n של השרת אינו קיים. `@i18n-micro/astro` מאפשר לדף לבחור את המפתחות שאי צריך, להעביר אותם כ-prop אחד, ולקרוא אותם באי דרך מתאם framework קטן. תקבלו את `t`, `tc`, `tn`, `td`, `tdr` ו-`has` באיי Vue, React, Preact ו-Svelte, כאשר רק המחרוזות שנבחרו נמצאות ב-HTML.

## הגדרה {#setup}

הגדירו תחילה את [שילוב Astro וה-middleware](/he/integrations/astro-package#setup), ואז הוסיפו את שילוב ה-framework שבו אתם משתמשים (`@astrojs/vue`, `@astrojs/react`, `@astrojs/preact`, `@astrojs/svelte`). מתאמי האיים זקוקים לאותו framework כתלות peer: `vue` `^3.3.0`, `react` `^16.8.0 || ^17.0.0 || ^18.0.0 || ^19.0.0`, `preact` `^10.0.0 || ^11.0.0` או `svelte` `^4.0.0 || ^5.0.0`.

## העברת תרגומים לאי {#pass-translations-to-an-island}

```astro
---
// src/pages/index.astro
import { getI18nProps } from '@i18n-micro/astro'
import Counter from '../components/Counter.vue'

const i18n = getI18nProps(Astro, ['counter.title', 'counter.apples'])
---

<Counter client:load i18n={i18n} />
```

`getI18nProps(Astro, keys?)` מחזירה `{ locale, fallbackLocale, currentRoute, translations }` (טיפוס `I18nClientProps`). העבירו את המפתחות שהאי משתמש בהם: כל אחד נפתר בשרת כמו `t()` (מילוני הנתיב, השורש וה-fallback) ורק מפתחות שנמצאו נכנסים ל-HTML. ללא `keys`, כל מה ש-`t()` יכולה לענות עליו בדף הזה נשלח, בכל אי, כך ש-2000 מפתחות שורש הם בערך 100 KB לכל אי; בסביבת פיתוח מוצגת אזהרה על כך מעל 20 KB.

איים מתרגמים מתוך האובייקט הזה בלבד. `t` מחזירה את המפתח עבור כל דבר שלא הועבר, והודעות מקושרות אינן נפתרות.

## Vue {#vue}

קראו ל-`provideI18n(() => props.i18n)` ברכיב השורש של האי ול-`useAstroI18n()` בילדים שלו. ה-`inject` של Vue אינו רואה ערך שסופק על ידי אותו רכיב, ולכן ה-hook חייב לרוץ בילד, לא בשורש:

```vue
<!-- src/components/Counter.vue -->
<script setup lang="ts">
import { provideI18n } from '@i18n-micro/astro/client/vue'
import type { I18nClientProps } from '@i18n-micro/astro'
import CounterBody from './CounterBody.vue'

const props = defineProps<{ i18n: I18nClientProps }>()
provideI18n(() => props.i18n)
</script>

<template><CounterBody /></template>
```

```vue
<!-- src/components/CounterBody.vue -->
<script setup lang="ts">
import { ref } from 'vue'
import { useAstroI18n } from '@i18n-micro/astro/client/vue'

const { t, tc } = useAstroI18n()
const count = ref(0)
</script>

<template>
  <h3>{{ t('counter.title') }}</h3>
  <button @click="count++">{{ tc('counter.apples', count) }}</button>
</template>
```

## React ו-Preact {#react-and-preact}

```tsx
// src/components/Counter.tsx
import { useState } from 'react'
import { I18nProvider, useAstroI18n } from '@i18n-micro/astro/client/react'
import type { I18nClientProps } from '@i18n-micro/astro'

function Body() {
  const { t, tc } = useAstroI18n()
  const [count, setCount] = useState(0)
  return <button onClick={() => setCount(count + 1)}>{t('counter.title')}: {tc('counter.apples', count)}</button>
}

export default function Counter({ i18n }: { i18n: I18nClientProps }) {
  return (
    <I18nProvider value={i18n}>
      <Body />
    </I18nProvider>
  )
}
```

עבור Preact יבאו את `I18nProvider` ואת `useAstroI18n` מ-`@i18n-micro/astro/client/preact`; ה-API זהה.

## Svelte {#svelte}

```svelte
<!-- src/components/Counter.svelte -->
<script lang="ts">
  import { createI18nStore, useAstroI18n } from '@i18n-micro/astro/client/svelte'
  import type { I18nClientProps } from '@i18n-micro/astro'

  export let i18n: I18nClientProps
  const { t, tc } = useAstroI18n(createI18nStore(i18n))
  let count = 0
</script>

<button on:click={() => count++}>{t('counter.title')}: {tc('counter.apples', count)}</button>
```

`useAstroI18n(store)` מחזירה גם את ה-`store` לקריאות `$store` בתבנית.

## איים מתמידים {#persisted-islands}

אי עם `transition:persist` מקבל props חדשים לאחר ניווט. React, Preact ו-Vue (כאשר ניתן getter) עוקבים אחריהם. ב-Svelte, שמרו את ה-store והעבירו אותם הלאה: `const store = createI18nStore(i18n)`, `const { t } = useAstroI18n(store)`, ואז `$: store.set(i18n)` (עם runes, `$effect(() => store.set(i18n))`).

## API {#api}

| נקודת כניסה | ייצואים |
| --- | --- |
| `@i18n-micro/astro` | `getI18nProps`, טיפוס `I18nClientProps` |
| `@i18n-micro/astro/client/vue` | `provideI18n(props \| () => props)`, `useAstroI18n()` |
| `@i18n-micro/astro/client/react` | `I18nProvider` (prop `value`), `useAstroI18n()` |
| `@i18n-micro/astro/client/preact` | `I18nProvider` (prop `value`), `useAstroI18n()` |
| `@i18n-micro/astro/client/svelte` | `createI18nStore(props)`, `useAstroI18n(store)` |
| `@i18n-micro/astro/client` | `translate` ו-`hasTranslation` הטהורות, ללא framework |

כל `useAstroI18n` מחזירה את `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`, `setLocale`, `setRoute` ואת ה-`locale`. לאי יש מילון ממוזג אחד, ולכן ה-`has` שלו מחזיר true עבור מפתח ש-`t` יכולה לענות עליו, גם מה-locale של ה-fallback; בשרת `has` בודק רק את ה-locale הפעיל.
