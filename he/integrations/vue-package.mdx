`@i18n-micro/vue` הוא plugin ל-Vue 3 עם ליבת התרגום של Nuxt I18n Micro: `t()` ריאקטיבי, `$t` גלובלי, ארבעה רכיבים ו-adapter אופציונלי ל-vue-router. השתמשו בו באפליקציית Vue עם Vite או SSR שאינה בנויה עם Nuxt. מודל המופע, חוזה הנתב וה-props של הרכיבים משותפים עם החבילות האחרות ומתוארים ב-[פריימוורקים](/he/integrations/overview).

## התקנה {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vue
```

```bash npm
npm install @i18n-micro/vue
```

```bash yarn
yarn add @i18n-micro/vue
```

</CodeGroup>

תלויות peer: `vue` `^3.3.0`; `vue-router` `^4.5.1 || ^5.0.0` (אופציונלי, רק עבור `@i18n-micro/vue/router`). הטיפוסים שפורסמו דורשים Vue 3.5.5 ומעלה עם `skipLibCheck: false`; עם `skipLibCheck: true`, ההגדרה הרגילה בתבניות, גם גרסאות ישנות יותר מתקמפלות.

## הגדרה {#setup}

```ts
// src/main.ts
import { createApp } from 'vue'
import { createI18n } from '@i18n-micro/vue'
import App from './App.vue'
import en from './locales/en.json'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales: [
    { code: 'en', iso: 'en-US', displayName: 'English' },
    { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
  ],
  defaultLocale: 'en',
})

createApp(App).use(i18n).mount('#app')
```

`locales` ו-`defaultLocale` נדרשים עבור `useI18n()`: בלעדיהם הוא זורק `I18nLocalesKey not provided`. העבירו אותם ל-`createI18n` (כמו למעלה), ל-`useI18n({ locales, defaultLocale })`, או דרך `app.provide(I18nLocalesKey, …)` ו-`app.provide(I18nDefaultLocaleKey, …)`.

ה-plugin רושם את `I18nT`, `I18nLink`, `I18nGroup` ו-`I18nSwitcher` באופן גלובלי ומוסיף את `$t`, `$ts`, `$tc`, `$tn`, `$td`, `$tdr`, `$has` ו-`$i18n` לתבניות. מחוץ לרכיבים המופע הוא `i18n.global`. אפשרויות נוספות נמצאות ב-[המופע](/he/integrations/overview#the-instance); `routeMessages` אינו זמין ב-Vue, השתמשו ב-`addRouteTranslations`.

## תרגום {#translate}

```vue
<script setup lang="ts">
import { useI18n } from '@i18n-micro/vue'

const { t, tc, tn } = useI18n()
</script>

<template>
  <h1>{{ t('greeting', { name: 'Ada' }) }}</h1>
  <!-- Hello, Ada! -->
  <p>{{ tc('apples', 3) }}</p>
  <!-- 3 apples -->
  <p>{{ $t('nav.home') }} · {{ tn(1234.5) }}</p>
</template>
```

`useI18n()` מחזיר את מתודות התרגום (`t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`), את `locale` (computed הניתן לכתיבה), `getLocale`, `getLocales`, `defaultLocale()`, `getLocaleName`, `localePath`, `localeRoute`, `switchLocale`, `setRoute`, `getRoute`, `addTranslations`, `addRouteTranslations`, `mergeTranslations`, `resolveTranslations`, `setTranslation`, `clearCache` ו-`instance`.

טענו מילונים נוספים בכל עת; כל רכיב שקורא אותם מתרנדר מחדש:

```ts
const { addTranslations, addRouteTranslations, setRoute } = useI18n()

addTranslations('de', (await import('./locales/de.json')).default)
addRouteTranslations('en', 'about', { title: 'About us' })
setRoute('about') // t('title') now reads the 'about' dictionary first
```

## החלפת locale {#switch-locale}

```ts
const { locale, switchLocale } = useI18n()

locale.value = 'de' // only the locale
switchLocale('de') // the locale, then router.push to the localized current path
```

טענו את המילון של ה-locale לפני ההחלפה או אחריה; ההחלפה אינה מורידה דבר.

`<I18nGroup>` מעביר ל-slot שלו `t` עם קידומת. מפתחות בתוך `<I18nT>` או ב-`t()` רגיל אינם מקבלים קידומת:

```vue
<I18nGroup prefix="profile" v-slot="{ t }">
  <h2>{{ t('title') }}</h2>
  <!-- profile.title -->
</I18nGroup>
```

## ניתוב {#routing}

ה-adapter של vue-router נמצא ב-subpath, כך שנקודת הכניסה הראשית לעולם אינה מייבאת את `vue-router`:

```ts
// src/main.ts
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import { createI18n } from '@i18n-micro/vue'
import { createVueRouterAdapter } from '@i18n-micro/vue/router'
import App from './App.vue'
import Home from './pages/Home.vue'
import About from './pages/About.vue'
import en from './locales/en.json'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English' },
  { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
]

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/:locale(de)?', component: Home },
    { path: '/:locale(de)?/about', component: About },
  ],
})

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales,
  defaultLocale: 'en',
  routingStrategy: createVueRouterAdapter(router, locales, 'en'),
})

createApp(App).use(router).use(i18n).mount('#app')
```

`createVueRouterAdapter(router, locales, defaultLocale)` מוסיף קידומת לכל locale מלבד ברירת המחדל (`/about`, `/de/about`) ומרנדר את `<I18nLink>` כ-`RouterLink`. קראו את ה-locale מהנתיב בעצמכם, למשל ב-`router.beforeEach`, והגדירו את `i18n.global.locale.value`. ניתן גם לחבר adapter מאוחר יותר עם `i18n.setRoutingStrategy(adapter)`; ל-adapter מותאם אישית ראו [Router adapter](/he/integrations/overview#router-adapter).

## SSR {#ssr}

- צרו את הנתב, את מופע ה-i18n ואת האפליקציה בתוך פונקציית הרינדור של כל בקשה. מופע משותף יחיד ידליף את ה-locale של מבקר אחד למבקר אחר.
- השתמשו ב-`createMemoryHistory()` בשרת, קחו את ה-locale מה-URL, וטענו את המילון שלו (ואת זה של ה-fallback) לפני `renderToString`.
- שלחו את ה-locale ללקוח (למשל בסקריפט `window.__STATE__`) וצרו את מופע הלקוח עם אותו `locale` כדי שה-hydration יתאים.
- `<I18nSwitcher>` קורא את `window.location` רק כאשר התפריט הנפתח פתוח, ולכן הוא מתרנדר בשרת.

ב-`packages/vue/playground` יש זוג שלם של `entry-server.ts` / `entry-client.ts`.

## SEO head {#seo-head}

`useLocaleHead(options)` בונה את `lang`/`dir`, canonical, תגיות `hreflang` ו-`og:locale` מתוך ה-locales וה-adapter של הנתב. קראו ל-`updateMeta()` כאשר הנתיב משתנה והעבירו את `metaObject` למנהל ה-head שלכם:

```ts
import { watch } from 'vue'
import { useRoute } from 'vue-router'
import { useHead } from '@unhead/vue'
import { useLocaleHead } from '@i18n-micro/vue'

const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
watch(() => route.fullPath, () => updateMeta(), { immediate: true })
useHead(metaObject)
```

אפשרויות: `baseUrl` (מחרוזת או פונקציה), `addDirAttribute` (ברירת מחדל `true`), `addSeoAttributes` (ברירת מחדל `true`), `identifierAttribute` (ברירת מחדל `'id'`), `hreflangBaseLanguage` (ברירת מחדל `false`). locales עם `disabled: true` או `seo: false` אינם מקבלים קישור alternate.
