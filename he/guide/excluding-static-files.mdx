title: "החרגת נתיבים"
description: "השאירו דפים וקבצים מחוץ לניתוב ה-locale עם excludePatterns, וראו אילו נתיבים כבר מוחרגים."
---

יש נתיבים שלעולם אסור שיקבלו קידומת locale או הפניית locale: אזור ניהול, בדיקת תקינות, פיד שנוצר אוטומטית. `excludePatterns` מסמן אותם, ורשימה מובנית כבר מכסה את הרכיבים הפנימיים של Nuxt וקבצים סטטיים נפוצים. דף מוחרג שומר בדיוק על הנתיב שכתבתם ועדיין מרונדר עם `$t`.

## החרגת נתיב {#exclude-a-path}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    excludePatterns: [
      '/admin', // /admin and everything below it
      '/preview-*', // glob over the whole path
    ],
  },
})
```

עם הגדרה זו `pages/admin/index.vue` עונה רק בכתובת `/admin`; אין `/de/admin`, ו-`/admin` לעולם אינו מופנה אל `/de/admin`.

## תחביר התבניות {#pattern-syntax}

התבניות מותאמות מול הנתיב ללא `app.baseURL`:

| תבנית | מתאימה ל- | אינה מתאימה ל- |
| --- | --- | --- |
| `'/admin'` | `/admin`, `/admin/users` | `/administrator`, `/de/admin` |
| `'/preview-*'` | `/preview-1`, `/preview-a/b` | `/de/preview-1` |
| `'/file-?'` | `/file-a` | `/file-ab` |
| `/^\/v\d+\//` | `/v2/docs` | `/docs` |

מחרוזת ללא `*` או `?` מתאימה לנתיב ולמקטעים שלמים שמתחתיו. עם `*` (כל רצף תווים, כולל לוכסנים) או `?` (תו אחד) היא חייבת להתאים לנתיב כולו. התחילו תמיד מחרוזות ב-`/`.

## מה כבר מוחרג {#what-is-excluded-already}

אלה לעולם אינם מקבלים נתיבי locale או הפניות, ללא כל הגדרה:

- `/api` ו-`/_nuxt`, וכל מה שמתחתיהם;
- נתיב התרגומים, `/_locales` כברירת מחדל ([`apiBaseUrl`](/he/api/module-options#apibaseurl));
- כל נתיב עם מקטע שמתחיל ב-`__` (`/__nuxt_content`, `/en/__og-image__`);
- `/sitemap*.xml`, `/robots.txt`, `/favicon.ico`, `/apple-touch-icon*.png`, `/manifest.json`, `/sw.js`, `/workbox-*.js`;
- כל נתיב שהמקטע האחרון שלו מסתיים בסיומת של קובץ סטטי: `xml txt ico json js css png jpg jpeg gif svg webp avif pdf wasm map mp4 webm mp3 zip gz woff woff2 ttf eot`. מזהי דפים עם נקודות כמו `/user/john.doe` ונתיבי `.html` נשארים דפים.

## מה החרגה עושה {#what-an-exclusion-does}

- **נתיבים:** לא נוצרות גרסאות מותאמות locale; הדף נשמר כפי שנכתב.
- **הפניות ו-404:** פלאגין ההפניה בצד השרת ו-middleware ההפניה בצד הלקוח מדלגים על הנתיב.
- **Prerender:** נתיבים תואמים מוסרים מרשימת הנתיבים ל-prerender.

היא אינה מונעת מה-middleware של i18n בשרת לזהות locale עבור הבקשה, ואינה מונעת מהדף להשתמש בתרגומים. כדי להשאיר דף מותאם locale אך מחוץ לתגיות SEO, השתמשו ב-`disableMeta` ([הגדרות דף](/he/guide/per-component-translations#turn-off-seo-tags)). כדי להשאיר דף אחד ללא לוקליזציה מתוך `nuxt.config.ts` לפי נתיב, `globalLocaleRoutes: { '/admin': false }` ([נתיבים מותאמי locale](/he/guide/custom-locale-routes#in-nuxt-config)) עושה את אותו הדבר עבור הניתוב.
