רכיבים שקוראים ל-`useI18n()` צריכים מופע i18n בבדיקות יחידה. `@i18n-micro/test-utils` מספקת `useI18n()` מדומה עם לוגיקה אמיתית של תרגום, ריבוי ועיצוב, כך שתוכלו לטעון רכיב עם המילונים שלכם וללא שרת Nuxt. עבור ניתוב והפניות, הריצו את המודול האמיתי מקצה לקצה עם `@nuxt/test-utils`.

עמוד זה עוסק בבדיקת האפליקציה שלכם. האופן שבו מאגר זה בודק את המודול עצמו מתואר ב-[בדיקת המודול](https://s00d.github.io/nuxt-i18n-micro/contributing/testing).

## הדמיית useI18n {#mock-usei18n}

```ts
// tests/unit-setup.ts
import { setupNuxtI18nMock } from '@i18n-micro/test-utils'
import { mockNuxtImport } from '@nuxt/test-utils/runtime'
import { beforeEach, vi } from 'vitest'

export const { i18n, useI18n, setTranslationsFromJson } = setupNuxtI18nMock({
  spy: vi.fn, // every method becomes a vi.fn, so you can assert calls
  beforeEach, // reset state and reseed `translations` before each test
  translations: { welcome: 'Welcome' },
})

mockNuxtImport('useI18n', () => useI18n)
```

```ts
// vitest.config.ts
import { defineVitestConfig } from '@nuxt/test-utils/config'

export default defineVitestConfig({
  test: {
    environment: 'nuxt',
    setupFiles: ['./tests/unit-setup.ts'],
  },
})
```

השאירו את `mockNuxtImport` בקובץ ההגדרה: `@nuxt/test-utils` חייב לבצע עליו טרנספורמציה. `setupNuxtI18nMock` משתמש במטמון תרגומים פרטי, כך שקובצי בדיקה מקביליים אינם חולקים מצב.

## כתיבת בדיקה {#write-a-test}

```vue
<!-- components/Greeting.vue -->
<script setup lang="ts">
const { $t } = useI18n()
</script>

<template>
  <p>{{ $t('welcome') }}</p>
</template>
```

```ts
// tests/greeting.spec.ts
import { mountSuspended } from '@nuxt/test-utils/runtime'
import { expect, it } from 'vitest'
import Greeting from '~/components/Greeting.vue'
import de from '~/locales/de.json'
import { i18n, setTranslationsFromJson } from './unit-setup'

it('renders the German greeting', async () => {
  await setTranslationsFromJson('de', de)
  i18n.setLocale('de')

  const wrapper = await mountSuspended(Greeting)
  expect(wrapper.text()).toBe('Willkommen') // de.json: { "welcome": "Willkommen" }
})
```

המופע המדומה חושף את אותן מתודות כמו `useI18n()` האמיתי (`$t`, `$tc`, `$tn`, `$td`, `$has`, `$localePath`, …, עם וללא `$`) וכן פונקציות הגדרה לבדיקות: `setLocale`, `setLocales`, `setDefaultLocale`, `setRouteName`, `setTranslationsFromJson`, `loadPageTranslations`, `mergeTranslations`, `setMissingHandler`.

`$localePath` ו-`$switchLocalePath` הם תחליפים (stubs) שמוסיפים קידומת לנתיב בהתאם לאפשרות `strategy` (ללא נתב אמיתי). בדקו קישורים והפניות אמיתיים מקצה לקצה.

## פונקציות עזר ברמה נמוכה יותר {#lower-level-helpers}

| פונקציית עזר | שימוש |
| --- | --- |
| `createIsolatedFakeI18n(options)` | מופע מדומה מבודד ללא החיווט של `useI18n` של Nuxt, למשל עבור `mount` רגיל של `@vue/test-utils` עם `global.mocks`. |
| `createFakeI18n(options)` | מופע מדומה על מטמון המודול המשותף (קראו ל-`resetI18n()` ב-`beforeEach`), או מבודד עם `isolated: true`. |
| `createI18nTestContext(options)` | ההקשר שמאחורי שניהם, כשאתם צריכים כמה מופעים מדומים. |
| `t`, `tc`, `ts`, `tn`, `td`, `tdr`, `has` | קריאות ישירות על ההקשר המשותף, לבדיקת פונקציות רגילות. |

ההדמיה היא `BaseI18n`: `t`, `tc`, `tn`, `td`, `tdr` ו-`has` הם האמיתיים, על מילונים אמיתיים, כך שבדיקה רואה את מה שהאפליקציה מציגה.

פונקציות היצירה שלמעלה מקבלות `locale`, `defaultLocale`, `locales`, `routeName`, `strategy`, `translations` ו-`messages` (מילונים לכל שפה). פרויקט דוגמה מלא נמצא ב-[`packages/test-utils/example`](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/test-utils/example).

## בדיקות מקצה לקצה {#end-to-end-tests}

ניתוב, הפניות, תגיות SEO וטעינת מטענים דורשים את המודול האמיתי. הפעילו את האפליקציה שלכם עם `@nuxt/test-utils/e2e`:

```ts
// tests/e2e/locales.test.ts
import { $fetch, fetch, setup } from '@nuxt/test-utils/e2e'
import { describe, expect, it } from 'vitest'

describe('locales', async () => {
  await setup({ server: true })

  it('serves the German page', async () => {
    expect(await $fetch('/de')).toContain('lang="de-DE"')
  })

  it('redirects / for a German browser', async () => {
    const res = await fetch('/', { headers: { 'accept-language': 'de' }, redirect: 'manual' })
    expect(res.headers.get('location')).toBe('/de')
  })
})
```

הבדיקה השנייה מניחה `prefix` (או `prefix_except_default` עם שפת ברירת מחדל אחרת); ראו [זיהוי שפה](/he/guide/locale-detection) כדי לדעת מתי `/` מפנה.
