האפשרות `strategy` קובעת אם locale מופיע ב-URL ועבור אילו locales. בחרו בה פעם אחת, לפני שאתם מפרסמים כתובות URL: שינוי מאוחר יותר משנה כל קישור. לאחר מכן המודול יוצר את הנתיבים המותאמים locale בזמן הבנייה, ו-`$localePath`, `<i18n-link>` ובורר השפות קוראים אותם.

## ארבע האסטרטגיות {#the-four-strategies}

![הדף /about ב-en (ברירת מחדל) וב-de תחת כל אסטרטגיה; אותן כתובות URL מפורטות בטקסט שלהלן](/images/diagrams/strategies.svg)

**טיפוס** `Strategies` · **ברירת מחדל** `'prefix_except_default'`

אסטרטגיית ניתוב URL עבור קידומות locale.

- `'no_prefix'` — אין locale ב-URL; ה-locale נשמר בעוגייה.
- `'prefix_except_default'` — קידומת לכל ה-locales מלבד ברירת המחדל.
- `'prefix'` — תמיד קידומת, כולל ה-locale של ברירת המחדל.
- `'prefix_and_default'` — כמו `prefix`, אבל ה-locale של ברירת המחדל נגיש גם ללא קידומת.

כתובות URL עבור דף `about` עם `defaultLocale: 'en'` ו-locales `en`, `de`:

| אסטרטגיה | אנגלית | גרמנית | לא מוגש |
| --- | --- | --- | --- |
| `prefix_except_default` (ברירת מחדל) | `/about` | `/de/about` | `/en` ו-`/en/about` מחזירים 404 |
| `prefix` | `/en/about` | `/de/about` | `/about` מפנה לכתובת URL עם קידומת |
| `prefix_and_default` | `/about` ו-`/en/about` | `/de/about` | — |
| `no_prefix` | `/about` | `/about` | ה-locale אינו ב-URL |

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix',
  },
})
```

האסטרטגיה נקבעת בזמן הבנייה: דריסה שלה בזמן ריצה מתעלמת עם אזהרה ([דריסות בזמן ריצה](/he/guide/runtime-overrides)).

## באיזו לבחור {#which-one-to-choose}

- **`prefix_except_default`**: רוב האתרים. כתובות URL קיימות ללא קידומת ממשיכות לעבוד עבור שפת ברירת המחדל.
- **`prefix`**: כל השפות שוות; `/` תמיד מוביל לדף בית עם קידומת.
- **`prefix_and_default`**: אתם צריכים ש-`/en/...` וגם הכתובות ללא קידומת יעבדו, למשל בזמן מעבר מאחת לשנייה. כתובות URL ללא קידומת לעולם אינן מופנות.
- **`no_prefix`**: אפליקציות מאחורי התחברות, או כתובת URL אחת לכל דף עבור כל השפות. ה-locale מגיע מעוגייה או מ-`?locale=`. מנועי חיפוש רואים שפה אחת לכל URL, ולכן לא נפלטות חלופות `hreflang`.

איך נבחר ה-locale עבור URL, ומתי מבקר מופנה, מוסבר ב[זיהוי locale](/he/guide/locale-detection).

## נתיבים שנוצרים {#generated-routes}

בזמן הבנייה כל דף מקבל את רשומות הנתיב שהאסטרטגיה שלו צריכה. כל רשומה נושאת `meta.i18n = { name, locales }`: הדף שהיא מציגה וה-locales שהיא משרתת. קישורים, החלפות והפניות נענים כולם מתוך הרשומות האלה, כך ש-URL שהמודול מספק הוא תמיד כזה שהנתב משרת.

Locales שחולקים את הנתיב של הדף חולקים רשומה אחת, `/:locale(de|fr)/about`. Locale עם נתיב משלו מקבל רשומה משלו, בשם `localized-<page>-<locale>`:

```ts
// nuxt.config.ts: German has its own path for the about page
i18n: {
  globalLocaleRoutes: { about: { de: '/ueber-uns' } },
}
// prefix_except_default, locales en (default), de, fr:
// about                 /about
// localized-about       /:locale(fr)/about
// localized-about-de    /:locale(de)/ueber-uns
```

נתיבים מותאמים, רשימות locales לכל דף והחרגת דף מלוקליזציה מוסברים ב[נתיבים מותאמי locale](/he/guide/custom-locale-routes) וב[הגדרות דף](/he/guide/per-component-translations). הקידומת `localized-` היא [`localizedRouteNamePrefix`](/he/api/module-options#localizedroutenameprefix).

<Warning>

**שמות הנתיבים נוצרים אוטומטית** — אל תקודדו שמות `localized-…` ב-`router.push({ name })`. העבירו את השם של הדף עצמו ל-`$localeRoute` או ל-`<i18n-link>`; הם בוחרים את הרשומה הנכונה.

</Warning>

## קישור לדף ב-locale {#linking-to-a-page-in-a-locale}

```vue
<script setup lang="ts">
const { localePath, localeRoute, switchLocalePath } = useI18n()

localePath({ name: 'about' }) // '/de/ueber-uns' while the page is German
localePath({ name: 'about' }, 'en') // '/about'
localePath('/about', 'de') // '/de/ueber-uns': a path is read as the page it shows
localeRoute({ name: 'products-id', params: { id: '42' } }, 'de') // resolved route: name, params, fullPath
switchLocalePath('fr') // the current page in French
</script>

<template>
  <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
  <NuxtLink :to="$switchLocalePath('de')">Deutsch</NuxtLink>
</template>
```

- גם נתיבים בעלי שם וגם נתיבים רגילים עובדים. נתיב מותאם מול הנתיבים שנוצרו, כך שכל צורה שלו בכל locale מתקבלת.
- Locale שאינו משרת את הדף (ראו `locales` ב[הגדרות דף](/he/guide/per-component-translations)) מקשר לדף הבית של אותו locale במקום לדף חסר.
- פרמטרים לכל locale (slug מתורגם) עוברים דרך `$setI18nRouteParams`, ראו [נתיבים מותאמי locale](/he/guide/custom-locale-routes).

החתימות נמצאות ב[מתודות](/he/api/methods).

## פרטי `no_prefix` {#no_prefix-details}

- ברירת המחדל של [`localeCookie`](/he/api/module-options#localecookie) תחת `no_prefix` היא `'user-locale'`, כך שהבחירה שורדת טעינה מחדש.
- `$switchLocale('de')` טוען את המילון הגרמני ומחליף את רשומת ההיסטוריה הנוכחית; ה-URL אינו משתנה.
- נתיבים מותאמים לכל locale עדיין עובדים: עם `globalLocaleRoutes: { about: { de: '/ueber-uns' } }`, קוראים בגרמנית מקבלים `/ueber-uns`. כתובת URL זו תמיד מרונדרת בגרמנית, לא משנה מה המבקר מעדיף, ודף המוגבל לחלק מה-locales מרונדר באחד מהם. נתיב שכמה locales חולקים (`en` ו-`de` שניהם ב-`/page/:id`) מרונדר בהעדפה כאשר היא אחת מהם. ההעדפה עצמה נשמרת: הדף הבא חוזר אליה.
- [`noPrefixRedirect: true`](/he/api/module-options#noprefixredirect) מפנה את הנתיב המקורי של דף עם נתיב מותאם ב-locale של ברירת המחדל: לנתיב המותאם של ה-locale של המבקר, ואחרת לזה של ה-locale של ברירת המחדל (`/about` → `/about-us` כאשר ל-`en` יש `/about-us`, → `/ueber-uns` עם עוגייה `de`). Locale ללא נתיב מותאם משלו נשאר בנתיב המקורי ומרונדר שם. דפים עם פרמטרים אינם מופנים.

## אפליקציות ללא `pages/` {#apps-without-pages/}

עם `pages: false` אין נתיבי דפים ללוקליזציה. השתמשו רק בקבצי תרגום שורשיים (`disablePageLocales: true`); הזיהוי, העוגייה ו-`$switchLocale` עדיין עובדים. הגרסה `pages-false` של `test/fixtures/basic` במאגר היא הגדרה עובדת.
