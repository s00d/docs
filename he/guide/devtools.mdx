ב-`nuxt dev` המודול מוסיף שני כלי ניפוי באגים: לשונית **i18n Micro** ב-Nuxt DevTools לעיון ולעריכה של קובצי תרגום, ובודק (inspector) ב-Vue DevTools עבור השפה החיה והמילונים הטעונים. שניהם קיימים רק בסביבת פיתוח ואינם מוסיפים דבר לבניות ייצור. הלשונית של Nuxt דורשת רק ש-Nuxt DevTools יהיה מופעל; הבודק של Vue דורש גם את תוסף הדפדפן Vue DevTools.

## לשונית Nuxt DevTools {#nuxt-devtools-tab}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  devtools: { enabled: true }, // the tab is registered only when DevTools are on
})
```

פתחו את Nuxt DevTools (`Shift + Alt + D`) ובחרו **i18n Micro**. הלשונית מציגה:

- כל קובץ JSON תחת `locales/` (בשורש וב-`pages/`) של כל שכבה, וכן קובצי שורש מ-`additionalTranslationDirs`;
- עורך לכל קובץ; **Save** כותב את הקובץ בחזרה לדיסק, ושרת הפיתוח טוען מחדש את התרגומים;
- **Export** / **Import** של קובץ כ-JSON, ו-**Stats** עם ספירת מפתחות וכיסוי תרגום;
- תצוגת תצורה של אפשרויות המודול המפוענחות;
- **Translate**, שממלא מפתחות חסרים באמצעות מנוע תרגום מכונה שאתם מגדירים בהגדרות הלשונית.

השמירה כותבת רק לקובצי `.json` קיימים בתוך תיקיות התרגום שלכם. כאשר קובץ קיים בכמה שכבות, נכתב העותק של הפרויקט.

## בודק Vue DevTools {#vue-devtools-inspector}

עם תוסף הדפדפן Vue DevTools, המודול רושם בודק i18n (שפה נוכחית, מקטע נתיב, מפתחות טעונים) וציר זמן עם החלפות שפה, טעינות מקטעים ומפתחות חסרים.

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    debug: true, // also log every $t / $ts / $tc call on the timeline
    // vueDevtools: false, // turn the inspector off, keep the Nuxt tab
  },
})
```

[`vueDevtools`](/he/api/module-options) מוגדר כברירת מחדל ל-`true`. `debug: true` מפיק פלט רב; השתמשו בו לסשנים קצרים.

## מחוץ ל-Nuxt {#outside-nuxt}

אותו ממשק משתמש מפורסם כ-[`@i18n-micro/devtools-ui`](/he/integrations/devtools-ui-package) עבור אפליקציות Vite הבנויות על חבילות המסגרות; ראו את העמוד ההוא להגדרה.
