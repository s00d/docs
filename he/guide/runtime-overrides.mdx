title: "דריסות בזמן ריצה"
description: "שנו את locale ברירת המחדל, את locale הגיבוי או את ה-locales המושבתים לכל מופע של build אחד, באמצעות משתני סביבה או runtimeConfig."
---

דריסות בזמן ריצה מאפשרות לתוצר build אחד לרוץ עם הגדרות locale שונות לכל סביבה או tenant, ללא בנייה מחדש. ניתן לשנות את locale ברירת המחדל, את locale הגיבוי ואילו locales מושבתים. ניתוב, הפניות, רינדור ופונקציות עזר בשרת משתמשים בערכים הנדרסים, וכך גם הדפדפן בעמוד שרונדר בשרת.

## הגדרת דריסות עם משתני סביבה {#set-overrides-with-environment-variables}

```bash
NUXT_I18N_DEFAULT_LOCALE=de \
NUXT_I18N_FALLBACK_LOCALE=en \
NUXT_I18N_DISABLED_LOCALES=fr,it \
node .output/server/index.mjs
```

| משתנה | כינוי |
| --- | --- |
| `NUXT_I18N_DEFAULT_LOCALE` | `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE` |
| `NUXT_I18N_FALLBACK_LOCALE` | `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE` |
| `NUXT_I18N_DISABLED_LOCALES` (מופרדים בפסיקים) | `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES` |

השרת קורא אותם פעם אחת בהפעלה; הפעילו מחדש כדי להחיל שינוי. בעמוד שרונדר בשרת, הדפדפן מקבל את הערכים הפתורים מהשרת. עם `ssr: false` אין רינדור בשרת ולדפדפן אין סביבה: רק `runtimeConfig.public.i18nRuntime` חל שם, והדפדפן רושם ביומן את האזהרות שלהלן.

## הגדרת דריסות ב-runtimeConfig {#set-overrides-in-runtimeconfig}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

ערך שהוגדר ב-`runtimeConfig.public.i18nRuntime` גובר על משתנה `NUXT_I18N_*` עבור אותו שדה.

אין לבלבל עם המשתנה `DEFAULT_LOCALE` של זמן ה-build, שמחליף את `defaultLocale` בזמן הבנייה ואינו דורש תמיכה בזמן ריצה.

## מה ניתן ומה לא ניתן לשנות {#what-can-and-cannot-change}

| הגדרה | בזמן ריצה |
| --- | --- |
| `defaultLocale` | כן תחת `prefix` ו-`no_prefix`. תחת `prefix_except_default` ו-`prefix_and_default` הוא קבוע בזמן ה-build (העמודים שלו הם ה-routes ללא קידומת); דריסה מתעלמים ממנה עם אזהרה. |
| `fallbackLocale` | כן. |
| `disabledLocales` | מתווסף ל-locales שהושבתו ב-build; לעולם אינו מפעיל מחדש locale. לא ניתן להשבית את ברירת המחדל של ה-build תחת `prefix_except_default` / `prefix_and_default`. |
| `strategy` | לא. מתעלמים מאסטרטגיה בזמן ריצה עם אזהרה; בנו תוצר אחד לכל אסטרטגיה. |

ערכים לא תקינים לעולם אינם שוברים את האפליקציה. כל מקרה רושם אזהרה אחת לכל תהליך שרת:

- השבתת כל ה-locales מתעלמים ממנה;
- `defaultLocale` שאינו מופעל נופל חזרה ל-locale המופעל הראשון;
- `fallbackLocale` שאינו מופעל שומר על ערך ה-build אם הוא מופעל, אחרת אין גיבוי.

## קריאת התצורה האפקטיבית {#read-the-effective-config}

```vue
<script setup lang="ts">
const { $getI18nConfig } = useNuxtApp()
const config = $getI18nConfig() // build config with overrides applied
</script>
```

התייחסו אליה כקריאה בלבד: בשרת היא משותפת לכל הבקשות ומוקפאת בפיתוח; העותק בדפדפן אינו מוקפא. ייבוא התצורה מ-`#build/i18n.strategy.mjs` נותן את ערכי ה-build ללא דריסות.

## Locales מושבתים וקבצים סטטיים {#disabled-locales-and-static-files}

locale שהושבת בזמן ריצה עונה 404 על ה-routes שלו ועל route ה-payload שלו, אבל קובצי ה-payload שלו עדיין נמצאים ב-`.output/public/_locales/` ושרת קבצים סטטי מחזיר אותם. כאשר אסור שהקבצים האלה יהיו נגישים, השביתו את ה-locale בזמן ה-build עם `disabled: true`.
