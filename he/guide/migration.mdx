עמוד זה ממפה אפליקציית `@nuxtjs/i18n` אל nuxt-i18n-micro: אפשרויות, פונקציות עזר ומבנה קבצים. השתמשו בו כאשר אתם מחליפים את המודול באפליקציה קיימת. אתם שומרים על כתובות ה-URL שלכם (שמות האסטרטגיות זהים) ומעבירים את התרגומים לקובצי JSON לכל עמוד.

<Tip>

**משדרגים את nuxt-i18n-micro עצמו?** — ראו [שדרוג](/he/guide/upgrade).

</Tip>

## החלפת המודול {#swap-the-module}

```bash
npm uninstall @nuxtjs/i18n
npm install nuxt-i18n-micro
```

```ts
// nuxt.config.ts — before
export default defineNuxtConfig({
  modules: ['@nuxtjs/i18n'],
  i18n: {
    locales: [
      { code: 'en', language: 'en-US', file: 'en.json' },
      { code: 'de', language: 'de-DE', file: 'de.json' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    langDir: 'locales',
    detectBrowserLanguage: { useCookie: true, cookieKey: 'i18n_redirected', redirectOn: 'root' },
  },
})
```

```ts
// nuxt.config.ts — after
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    translationDir: 'locales',
    localeCookie: 'i18n_redirected',
    autoDetectPath: '/',
  },
})
```

## אפשרויות {#options}

| `@nuxtjs/i18n` | nuxt-i18n-micro |
| --- | --- |
| `locales[].code` | `locales[].code` |
| `locales[].language` (`iso` לפני v9) | `locales[].iso` |
| `locales[].name` | `locales[].displayName` |
| `locales[].dir` | `locales[].dir` |
| `locales[].domain` | `locales[].baseUrl` (origin עם ה-scheme שלו) |
| `locales[].domainDefault` | `locales[].baseDefault` |
| `differentDomains`, `multiDomainLocales` | לא נדרש: `baseUrl` לבדו מנתב לפי host, ראו [שכבות ודומיינים](/he/guide/layers#multiple-domains) |
| `locales[].file` / `files`, `langDir`, `lazy` | `translationDir`; קבצים נמצאים לפי שם ותמיד נטענים לכל עמוד |
| `defaultLocale`, `strategy` | אותם שמות, אותם ארבעה ערכים |
| `baseUrl` | `metaBaseUrl` |
| `customRoutes: 'config'` + `pages` | `globalLocaleRoutes` |
| `detectBrowserLanguage: false` | `redirects: false` (ללא הפניות) או `autoDetectLanguage: false` (התעלמות מהכותרת) |
| `detectBrowserLanguage.useCookie` / `cookieKey` | `localeCookie: '<name>'` (`null` מכבה את ה-cookie) |
| `detectBrowserLanguage.redirectOn: 'root'` | `autoDetectPath: '/'` (ברירת מחדל) |
| `detectBrowserLanguage.redirectOn: 'no prefix'` | `autoDetectPath: 'no_prefix'` |
| `detectBrowserLanguage.redirectOn: 'all'` | `autoDetectPath: '*'` |
| קובץ תצורה של `vueI18n` (`fallbackLocale`, `numberFormats`, `datetimeFormats`) | `fallbackLocale`, `numberFormats`, `datetimeFormats` בתוך `i18n` |

אין `alwaysRedirect`: כאשר cookie מוגדר, `/` עוקב אחריו בכל ביקור. הרשימה המלאה נמצאת ב-[אפשרויות המודול](/he/api/module-options); כללי הזיהוי נמצאים ב-[זיהוי locale](/he/guide/locale-detection).

## פונקציות עזר ו-composables {#helpers-and-composables}

| `@nuxtjs/i18n` / vue-i18n | nuxt-i18n-micro (תבנית / `useI18n()`) |
| --- | --- |
| `const { t } = useI18n()` | `const { t } = useI18n()`, `$t` בתבניות |
| `t('key', count)`, `tc` | `$tc('key', count)` |
| `te('key')` | `$has('key')` |
| `n(value, 'currency')`, `d(date, 'short')` | `$tn(value, 'currency')`, `$td(date, 'short')` |
| — | `$tdr(date)`: זמן יחסי ("in 3 days") |
| `locale.value` | `$getLocale()` |
| `locales.value` | `$getLocales()` |
| `setLocale('de')` | `$switchLocale('de')` |
| `useLocalePath()('about')` | `$localePath({ name: 'about' })` |
| `useLocaleRoute()` | `$localeRoute()` |
| `useSwitchLocalePath()('de')` | `$switchLocalePath('de')` |
| `useSetI18nParams()` | `$setI18nRouteParams()` |
| `useLocaleHead()` | אוטומטי עם `meta: true`; [`useLocaleHead`](/he/composables/useLocaleHead) עבור heads מותאמים אישית |
| `defineI18nRoute({ paths: { de: '/ueber-uns' }, locales: [...] })` | `$defineI18nRoute({ localeRoutes: { de: '/ueber-uns' }, locales: [...] })` |
| `<NuxtLinkLocale to="about">` | `<i18n-link :to="{ name: 'about' }">` |
| `<i18n-t>` | `<i18n-t>` (slots ממלאים placeholders מסוג `{name}`) |
| `$i18n` ב-server routes | `useTranslationServerMiddleware(event)`, ראו [Server routes ו-API](/he/guide/server-side-translations) |

`useI18n()` מיובא אוטומטית. `$defineI18nRoute` חייב לשמור על ה-`$` שלו: ה-build קורא את הקריאה הזו. כל פונקציות העזר: [מתודות](/he/api/methods).

## קובצי תרגום {#translation-files}

העבירו את המפתחות של קובץ גדול אחד לכל locale לקובץ שורש וקובץ אחד לכל עמוד:

```text
locales/
├── en.json              # keys used on many pages (nav, footer)
├── de.json
└── pages/
    ├── index/en.json    # keys of pages/index.vue
    └── about/en.json    # keys of pages/about.vue
```

שמירת הכול בקובצי השורש עובדת גם כן, וזה הצעד הראשון המהיר ביותר. הגדירו `disablePageLocales: true` עד שתפצלו אותם. ראו [קובצי תרגום](/he/guide/translations).

### תחביר הודעות {#message-syntax}

| vue-i18n | nuxt-i18n-micro |
| --- | --- |
| אינטרפולציה בעלת שם `{name}` | זהה |
| `car \| cars` (2 צורות: 1 → הראשונה) | הצורות נבחרות לפי ספירה מ-0: כתבו `no cars \| one car \| {count} cars` |
| הודעות מקושרות `@:other.key` | לא נתמך: חזרו על הטקסט או הרכיבו בקוד |
| modifiers מסוג `@.upper:` | לא נתמך: עצבו בקוד או השתמשו ב-`<i18n-t>` |
| escapes מילוליים `{'@'}` | לא נדרש: רק אסימוני `{word}` מוחלפים |
| קובצי הודעות JS/TS | JSON בלבד |

ניתן להחליף את כלל הרבים באמצעות האפשרות [`plural`](/he/api/module-options#plural).

## בדיקה אחרי המעבר {#check-after-the-switch}

- כל URL שהיה לכם עדיין נפתר; שמות האסטרטגיות תואמים, נתיבים מותאמים אישית עוברים ל-`globalLocaleRoutes` או ל-`$defineI18nRoute`.
- `hreflang`, canonical ו-`og:locale` מגיעים מוכנים מראש עם `meta: true`; הסירו את אלה שנכתבו ידנית.
- שגיאת ניתוח JSON רושמת ביומן את נתיב הקובץ; מפתח חסר רושם אזהרה בקונסולת הדפדפן בפיתוח.
