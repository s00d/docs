עמוד זה לוקח אפליקציית Nuxt ללא i18n והופך אותה לעמוד מתורגם עם מחליף שפות. תזדקקו לו פעם אחת, בתחילת הפרויקט. בסופו יהיו לכם כתובות URL מותאמות שפה (`/about`, `/de/about`), קובץ JSON אחד לכל שפה ועמוד, ו-`$t` בתבניות שלכם.

## התקנה {#install}

המודול דורש Nuxt 3.18 ומעלה (גם Nuxt 4 עובד) ו-Node 20 ומעלה.

<CodeGroup>

```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>

## הגדרת השפות {#configure-the-locales}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', displayName: 'English' },
      { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
      { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
    ],
    defaultLocale: 'en',
  },
})
```

זו כל התצורה שאפליקציה ראשונה צריכה. ברירות המחדל מספקות לכם:

- `strategy: 'prefix_except_default'`: לשפת ברירת המחדל אין קידומת (`/about`), לשאר יש (`/de/about`). ראו [אסטרטגיות ניתוב](/he/guide/strategy).
- `translationDir: 'locales'`: קובצי התרגום נמצאים ב-`locales/` בשורש הפרויקט, גם עם מבנה `app/` של Nuxt 4.
- `meta: true`: תגיות `hreflang`, canonical ו-`og:locale`, וגם `lang` ו-`dir` על `<html>`. ראו [SEO](/he/guide/seo).
- מבקר שפותח את `/` מועבר לשפה שהדפדפן שלו מבקש (`Accept-Language`). ראו [זיהוי שפה](/he/guide/locale-detection).

`iso` הוא תג השפה שמשמש בתגיות SEO; ‏`code` הוא מה שמופיע בכתובת ה-URL. כל האפשרויות מפורטות ב-[אפשרויות המודול](/he/api/module-options).

## הוספת קובצי תרגום {#add-translation-files}

הפעילו את שרת הפיתוח עם `nuxt dev`. כאשר Nuxt מזהה את העמודים, המודול יוצר קובץ `{}` ריק לכל שפה ועמוד שאין להם קובץ (ניתן לכבות זאת עם [`disableWatcher`](/he/api/module-options#disablewatcher)):

```text
locales/
├── en.json            # root: keys every page can use
├── de.json
├── fr.json
└── pages/
    ├── index/         # pages/index.vue
    │   ├── en.json
    │   ├── de.json
    │   └── fr.json
    └── about/         # pages/about.vue
        ├── en.json
        ├── de.json
        └── fr.json
```

מלאו את קובץ השורש וקובץ עמוד:

```json
// locales/en.json
{ "nav": { "home": "Home", "about": "About" } }
```

```json
// locales/pages/index/en.json
{ "welcome": "Welcome, {name}!", "items": "no items | one item | {count} items" }
```

עמוד רואה את מפתחות השורש ואת המפתחות שלו; במקרה של התנגשות, הקובץ של העמוד גובר. שמות התיקיות נקבעים לפי שם הנתיב (`pages/articles/[id].vue` הוא `locales/pages/articles-id/`). [קובצי תרגום](/he/guide/translations) מכסה את המבנה, ה-fallbacks והטעינה.

## שימוש ב-`$t` בעמוד {#use-$t-on-a-page}

```vue
<!-- pages/index.vue -->
<script setup lang="ts">
const { t, tc, getLocale } = useI18n()

const title = t('nav.home') // 'Home'
</script>

<template>
  <h1>{{ $t('welcome', { name: 'Ada' }) }}</h1>
  <!-- Welcome, Ada! -->
  <p>{{ $tc('items', 3) }}</p>
  <!-- 3 items -->
  <p>{{ getLocale() }}</p>
  <!-- en -->
</template>
```

- בתבניות, כל פונקציית עזר זמינה עם `$` (`$t`, `$tc`, `$localePath`, …).
- ב-`<script setup>`, ‏`useI18n()` מחזיר את אותן פונקציות עזר, עם ובלי `$` (`t` ו-`$t` הן אותה פונקציה). הוא מיובא אוטומטית.
- מצייני מקום מסוג `{name}` ממולאים מאובייקט הפרמטרים. צורות רבים מופרדות ב-`|`; המספר בוחר את הצורה (0, 1, ואז האחרונה לכל מה שמעל).

כל פונקציות העזר מפורטות ב-[מתודות](/he/api/methods).

## קישור בין עמודים והחלפת שפה {#link-between-pages-and-switch-locale}

```vue
<!-- components/AppHeader.vue -->
<template>
  <nav>
    <i18n-link :to="{ name: 'index' }">{{ $t('nav.home') }}</i18n-link>
    <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
    <i18n-switcher />
  </nav>
</template>
```

- [`<i18n-link>`](/he/components/i18n-link) הוא `NuxtLink` שמפנה לעמוד בשפה הנוכחית: ב-`/de` הקישור ל-about מוביל ל-`/de/about`.
- [`<i18n-switcher>`](/he/components/i18n-switcher) הוא תפריט נפתח של השפות הפעילות; הוא משאיר את המבקר באותו עמוד.
- עבור כפתורים משלכם קראו ל-`$switchLocale('de')`, שמנווט לעמוד הנוכחי בגרמנית וזוכר את הבחירה. עבור `NuxtLink` רגיל, השתמשו ב-`$localePath({ name: 'about' })` או ב-`$switchLocalePath('de')`.

## בדיקה {#check-it}

הריצו `nuxt dev` ופתחו:

| URL | מציג |
| --- | --- |
| `/` | דף הבית באנגלית (או הפניה ל-`/de` כשהדפדפן שלכם מעדיף גרמנית) |
| `/de` | דף הבית בגרמנית |
| `/de/about` | עמוד about בגרמנית |
| `/en/about` | 404: לשפת ברירת המחדל אין קידומת תחת `prefix_except_default` |

עריכות בקובצי ה-JSON מוחלות בעמוד הפתוח ללא טעינה מחדש.
