# 🛠️ DevTools ב־`nuxt-i18n-micro`

## Vue DevTools (הרחבת דפדפן)

בפיתוח, המודול יכול לרשום **מפקח וציר זמן** מותאמים של **Vue DevTools** דרך `@vue/devtools-api`. זה נפרד מהכרטיסייה של Nuxt DevTools למטה.

| כלי | הטוב ביותר עבור |
|------|----------|
| **Vue DevTools** | שפה חיה, מטמון תרגום בזיכרון, ציר זמן של `$t` ‏(`debug: true`), אירועי מפתח חסר |
| **כרטיסיית Nuxt DevTools** | עריכת קובצי JSON בדיסק, סקירת תצורה, ייבוא/ייצוא |

תוסף vue-devtools נרשם רק במהלך `nuxt dev` (לא בבניות ייצור). מצב bridge של פיתוח בלבד בתוסף הראשי מסולק על ידי סילוק קוד מת של `import.meta.dev`.

השבת את אינטגרציית הדפדפן תוך שמירה על הכרטיסייה של Nuxt:

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

אירועי ציר זמן מפורטים של `$t` דורשים `debug: true`.

---

## 📖 מהו Nuxt DevTools?

DevTools הוא עוזר פיתוח רב־עוצמה המשולב בצורה חלקה במודול `nuxt-i18n-micro`. הוא מספק ממשק אינטואיטיבי לניהול משימות לוקליזציה ותרגום, ומהיר את זרימת העבודה שלך והופך אותה ליעילה יותר. מיועד למפתחים שמעריכים נוחות, ‏Nuxt DevTools מגשר על הפער בין קידוד לניהול זמן ריצה.

## 🌟 תכונות מרכזיות של DevTools ב־`nuxt-i18n-micro`

### 1. **ניהול שפות**

עיין, בחר ונהל שפות באפליקציה שלך ללא מאמץ. בין אם אתה עובד עם שפה אחת או מספר שפות, ‏DevTools מספק hub מרכזי לטיפול בכל הגדרות הלוקליזציה.

### 2. **עריכת תרגומים**

ערוך קובצי תרגום ישירות דרך עורך JSON משולב. זה מבטל את הצורך בכלים חיצוניים, ומאפשר עדכונים ושינויים בזמן אמת מבלי להפריע לזרימת העבודה שלך.

### 3. **ייבוא וייצוא קבצים**

פשט את תהליך ניהול קובצי התרגום:

- **ייצוא**: שמור תרגומים כקובץ JSON לגיבויים או לשימוש חיצוני.
- **ייבוא**: טען קובצי תרגום מעודכנים לפרויקט כדי לשמור על תוכן מעודכן.

### 4. **תצוגות מקדימות בזמן אמת**

צפה בשינויים מיד בסביבת הפיתוח. תכונה זו מבטיחה שתרגומים ותצורות מדויקים לפני העלאה לפרודקשן.

### 5. **אינטגרציה חלקה של Nuxt**

DevTools עובד באופן טבעי עם `nuxt-i18n-micro`, ומשפר את היכולות שלו ללא צורך בהגדרה נוספת. הוא מסתגל לצרכי הלוקליזציה שלך תוך שמירה על מבנה מודולרי וגמיש של Nuxt.

## 🛠️ מדוע להשתמש ב־DevTools?

Nuxt DevTools הוא תוספת חיונית לפרויקטים הדורשים לוקליזציה. הוא עוזר למפתחים על ידי:

- **חיסכון בזמן**: אוטומציה של משימות חוזרות כמו ניהול קבצים ואימות פורמט.
- **הפחתת שגיאות**: מספק סביבה בטוחה ואינטואיטיבית לעריכת תרגומים.
- **שיפור שיתוף פעולה**: מאפשר לאנשים שאינם מפתחים לנהל תרגומים בקלות.
- **ייעול זרימות עבודה**: מאחד משימות לוקליזציה מרובות לממשק יחיד.

## 🚀 קח שליטה על הלוקליזציה

עם Nuxt DevTools משולב ב־`nuxt-i18n-micro`, ניהול אפליקציות רב־לשוניות הופך פשוט ויעיל. בין אם אתה מכוונן תרגומים או מוסיף שפות חדשות, ‏DevTools מציידת אותך בכלים הדרושים לספק חוויות מלוטשות וידידותיות למשתמש.
