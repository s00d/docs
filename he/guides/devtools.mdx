# 🛠️ DevTools ב-`nuxt-i18n-micro`

## Vue DevTools (הרחבת דפדפן)

בפיתוח, המודול יכול לרשום **Vue DevTools** custom inspector ו-timeline באמצעות `@vue/devtools-api`. זה נפרד מלשונית ה-Nuxt DevTools שלמטה.

| כלי | הכי מתאים ל |
|------|----------|
| **Vue DevTools** | locale חי, cache תרגום בזיכרון, timeline של `$t` (`debug: true`), אירועי מפתחות חסרים |
| **לשונית Nuxt DevTools** | עריכת קבצי JSON בדיסק, סקירת קונפיגורציה, ייבוא/ייצוא |

תוסף vue-devtools נרשם רק במהלך `nuxt dev` (לא בבנייה לייצור). מצב bridge לפיתוח בלבד בתוסף הראשי מנוקה על ידי dead-code elimination של `import.meta.dev`.

השבתת שילוב הדפדפן תוך שמירה על לשונית Nuxt:

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

אירועי timeline מפורטים של `$t` דורשים `debug: true`.

## 📖 מה זה Nuxt DevTools?

DevTools הוא עוזר פיתוח חזק המשולב בצורה חלקה במודול `nuxt-i18n-micro`. הוא מספק ממשק אינטואיטיבי לניהול משימות לוקליזציה ותרגום, מה שהופך את זרימת העבודה שלכם למהירה ויעילה יותר. מיועד למפתחים שמעריכים נוחות, Nuxt DevTools מגשר על הפער בין קידוד לניהול זמן ריצה.

## 🌟 תכונות עיקריות של DevTools ב-`nuxt-i18n-micro`

### 1. **ניהול locale**

עיינו, בחרו ונהלו locales באפליקציה שלכם ללא מאמץ. בין אם אתם עובדים עם שפה אחת או עם מספר שפות, DevTools מספק hub מרכזי לטיפול בכל הגדרות הלוקליזציה.

### 2. **עריכת תרגומים**

ערכו קבצי תרגום ישירות דרך עורך JSON משולב. זה מבטל את הצורך בכלים חיצוניים, ומאפשר עדכונים ושינויים בזמן אמת מבלי להפריע לזרימת העבודה שלכם.

### 3. **ייבוא וייצוא קבצים**

פשטו את התהליך של ניהול קבצי תרגום:

- **ייצוא**: שמרו תרגומים כקובץ JSON לגיבויים או לשימוש חיצוני.
- **ייבוא**: טענו קבצי תרגום מעודכנים לפרויקט כדי לשמור על תוכן עדכני.

### 4. **תצוגות מקדימות בזמן אמת**

צפו בשינויים מיד בתוך סביבת הפיתוח. תכונה זו מבטיחה שהתרגומים והקונפיגורציות מדויקים לפני הפצה.

### 5. **אינטגרציה חלקה עם Nuxt**

DevTools עובד באופן טבעי עם `nuxt-i18n-micro`, ומרחיב את יכולותיו ללא צורך בהגדרה נוספת. הוא מסתגל לצרכי הלוקליזציה שלכם תוך שמירה על המבנה המודולרי והגמיש של Nuxt.

---

## 🛠️ למה להשתמש ב-DevTools?

Nuxt DevTools הוא תוספת הכרחית לפרויקטים הדורשים לוקליזציה. הוא עוזר למפתחים על ידי:

- **חיסכון בזמן**: מבצע אוטומטית משימות חוזרות כמו ניהול קבצים ואימות פורמט.
- **הפחתת שגיאות**: מספק סביבה בטוחה ואינטואיטיבית לעריכת תרגומים.
- **שיפור שיתוף פעולה**: מאפשר לאנשים שאינם מפתחים לנהל תרגומים בקלות.
- **ייעול זרימות עבודה**: מאחד מספר משימות לוקליזציה לממשק אחד.

## 🚀 קחו שליטה על הלוקליזציה

עם Nuxt DevTools המשולב ב-`nuxt-i18n-micro`, ניהול אפליקציות רב-לשוניות הופך לפשוט ויעיל. בין אם אתם מכוונים תרגומים או מוסיפים locales חדשים, DevTools מציידים אתכם בכלים הדרושים לספק חוויות משתמש מלוטשות וידידותיות.
