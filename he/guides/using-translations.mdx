# שימוש בתרגומים ברכיבים

לאחר שהמודול הותקן והוגדר, תוכל להציג תרגומים על ידי קריאה ל־`$t('your_key')` בתוך תבניות ה־Vue והסקריפטים שלך.

## 1. קובצי תרגום ברמת השורש וספציפיים לעמוד

1. תרגומים **ברמת השורש** נמצאים ישירות תחת התיקייה `/locales` (למשל `/locales/en.json`, ‏`/locales/fr.json`). בזמן בנייה, הם ממוזגים אוטומטית לכל קובץ ספציפי לעמוד, מה שהופך אותם לזמינים בכל העמודים.
2. תרגומים **ספציפיים לעמוד** נמצאים תחת `/locales/pages/...`, תואמים למבנה תיקיית העמודים של Nuxt שלך:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. שימוש בתבנית עם `$t`

בקובצי `.vue` שלך, תוכל להשתמש ישירות ב־`$t` בתבנית:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
`$t` יכול להחזיר **אובייקטים** אם המפתח מצביע לצומת JSON מקונן (למשל `$t('header')` → `\{ title: "Hi" \}`). בתבניות זה מעובד כ־`[object Object]`. השתמש ב־`$ts` כאשר אתה זקוק למחרוזת מובטחת, או ספק מפתח ספציפי יותר כמו `$t('header.title')`. עיין ב־[הפניית API — ‏$t לעומת $ts](/api/methods#t) לפרטים.
</Tip>

## 3. החלפת השפה הנוכחית

כדי לשנות שפות באפליקציה שלך, תוכל לאחזר את `$locale` מ־`useI18n()` ולהקצות לו קוד חדש:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. מפתחות מקוננים ו־Placeholders

- **מפתחות מקוננים** משתמשים בסימון נקודות, למשל `nested.key.deeper`.
- **‏Placeholders** מאפשרים לך להכניס ערכים דינמיים:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. עצות ושיטות עבודה מומלצות

- **מפתחות סותרים**: אם קובץ ספציפי לעמוד מכיל את אותו מפתח כמו קובץ ברמת השורש, הגרסה הספציפית לעמוד גוברת (תרגומי השורש ממוזגים כבסיס בזמן בנייה).
- **השבתת קבצי עמוד**: אם אתה מעדיף לא להשתמש בתרגומים ספציפיים לעמוד, תוכל להגדיר `disablePageLocales: true` בתצורת Nuxt שלך. כך, רק קובצי `/locales/*.json` בשימוש.
- **ללא ייבוא ישיר**: אינך צריך לעשות `import \{ useI18n \} from 'nuxt-i18n-micro'`; תכונת ההזרקה האוטומטית של המודול מטפלת בזה עבורך.

זהו! עם שלבים אלה, אתה יכול במהירות **להתחיל לאחזר תרגומים** מקובצי JSON ברמת השורש או ספציפיים לעמוד ולה**ציג אותם** באפליקציית Nuxt שלך באמצעות `$t`.

## משאבים נוספים

לחקירת תכונות מתקדמות יותר, הקפד לבדוק:

1. **רכיב `<i18n-t>`**  
   הרכיב `<i18n-t>` הוא חלופה חזקה ל־`$t`, במיוחד שימושי למצבים הכוללים אלמנטים מקוננים, שימוש מתקדם ב־placeholders ומבני תרגום מורכבים יותר.

- **תיעוד**: [i18n-t](/api/components/i18n-t)

2. **Composable `useI18n`**  
   ה־composable ‏`useI18n` מציע קבוצה מלאה של פונקציות ומאפיינים ריאקטיביים לניהול תרגומים, טיפול בהחלפת שפה, עיצוב ועוד.

- **תיעוד**: [useI18n](/api/composables/use-i18n)
