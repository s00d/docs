# 🌐 מדריך אינטגרציה עם Crowdin

## 📖 מבוא

שילוב של Crowdin בפרויקט שלכם מייעל את תהליך הלוקליזציה והתרגום, ומקל על ניהול תרגומים בשפות ופלטפורמות מרובות. מדריך זה מספק הדרכה שלב אחר שלב על הגדרת Crowdin עם הפרויקט שלכם, כולל קונפיגורציה, העלאת מקורות והורדת תרגומים.

## 🔧 התקנה והגדרה

כדי להתחיל עם Crowdin, תצטרכו להתקין את Crowdin CLI באופן גלובלי במחשב שלכם ולאתחל אותו בתוך תיקיית הפרויקט.

### 📦 התקנת Crowdin CLI

ראשית, התקינו את Crowdin CLI באופן גלובלי באמצעות npm:

```bash
npm install -g @crowdin/cli
```

### 🛠 אתחול Crowdin בפרויקט שלכם

אתחלו את Crowdin בפרויקט שלכם על ידי הרצת:

```bash
crowdin init
```

הפקודה הזו תדריך אתכם בתהליך ההגדרה, כולל קביעת ה-Project ID, ה-API token ופרטי קונפיגורציה נוספים.

## 🗂️ מדריך קונפיגורציה

### 📄 קובץ קונפיגורציה של Crowdin (`crowdin.yml`)

קובץ הקונפיגורציה של Crowdin (`crowdin.yml`) מגדיר כיצד קבצי המקור שלכם ממופים והיכן יש למקם את התרגומים. להלן דוגמת קונפיגורציה:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 פרמטרי קונפיגורציה עיקריים

- **`project_id`**: ה-Project ID של Crowdin שלכם. זה מזהה את הפרויקט בתוך Crowdin שבו התרגומים מנוהלים.
- **`api_token`**: ה-API token שנמצא בשימוש עבור אימות. ודאו שלטוקן זה יש הרשאות נכונות להעלאה והורדה של תרגומים.
- **`base_path`**: מציין את התיקייה הבסיסית עבור קבצי מקור. בדוגמה זו, תרגומים מאוחסנים בתיקייה `./locales`.
- **`base_url`**: כתובת ה-URL הבסיסית של ה-API של Crowdin.
- **`preserve_hierarchy`**: כאשר מוגדר ל-`true`, Crowdin ישמור על מבנה התיקיות של קבצי המקור שלכם בפרויקט.

### 📂 קונפיגורציית קבצים

הסעיף `files` ממפה את קבצי המקור שלכם לנתיבים שבהם יאוחסנו התרגומים. לדוגמה:

- **נתיב מקור**: מגדיר את המיקום של קבצי התרגום המקוריים.
- **נתיב תרגום**: מציין היכן הקבצים המתורגמים יאוחסנו ב-Crowdin. Placeholders כמו `%two_letters_code%` נמצאים בשימוש כדי לקבוע באופן דינמי את קוד השפה בנתיבי הקבצים.

## ⬆️ העלאת קבצי מקור ל-Crowdin

לאחר שקונפיגורציית Crowdin שלכם מוגדרת, תוכלו להעלות את קבצי המקור שלכם באמצעות הפקודה הבאה:

```bash
crowdin upload sources
```

פקודה זו מעלה את כל קבצי המקור שצוינו בקונפיגורציה שלכם ל-Crowdin, וזמינים אותם לתרגום.

## ⬇️ הורדת תרגומים מ-Crowdin

לאחר שהתרגומים הושלמו או עודכנו ב-Crowdin, ניתן להוריד אותם לפרויקט שלכם באמצעות:

```bash
crowdin download
```

פקודה זו מביאה את התרגומים העדכניים ביותר מ-Crowdin ושומרת אותם לפי הנתיבים שצוינו בקובץ הקונפיגורציה שלכם.

## ⚙️ שיטות עבודה מומלצות

### 🔑 שמות מפתחות עקביים

ודאו שמפתחות התרגום עקביים בכל הקבצים כדי למנוע בלבול וכפילות.

### 🧹 תחזוקה שוטפת

סקרו ונקו באופן תקופתי מפתחות תרגום שאינם בשימוש כדי לשמור על קבצים מסודרים וניתנים לניהול.

### 🛠 אוטומציה של העלאות והורדות

שלבו את פקודות ה-Crowdin CLI בצינור ה-CI/CD שלכם כדי לבצע אוטומציה של העלאת קבצי מקור והורדת תרגומים, ולהבטיח שהתרגומים שלכם תמיד מעודכנים.

על ידי מעקב אחר מדריך זה, תוכלו לשלב את Crowdin בפרויקט שלכם באופן חלק, ולהבטיח גישה יעילה ומאורגנת לניהול מאמצי הבינאום שלכם.
