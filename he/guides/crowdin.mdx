# 🌐 מדריך אינטגרציה של Crowdin

## 📖 מבוא

שילוב של Crowdin בפרויקט שלך מפשט את תהליך הלוקליזציה והתרגום, ומקל על ניהול תרגומים במספר שפות ופלטפורמות. מדריך זה מספק הדרכה שלב אחר שלב על הגדרת Crowdin עם הפרויקט שלך, כולל תצורה, העלאת מקורות והורדת תרגומים.

## 🔧 התקנה והגדרה

כדי להתחיל עם Crowdin, תצטרך להתקין את Crowdin CLI באופן גלובלי במחשב שלך ולאתחל אותו בתוך תיקיית הפרויקט שלך.

### 📦 התקנת Crowdin CLI

תחילה, התקן את Crowdin CLI באופן גלובלי באמצעות npm:

```bash
npm install -g @crowdin/cli
```

### 🛠 אתחול Crowdin בפרויקט שלך

אתחל את Crowdin בפרויקט שלך על ידי הרצת:

```bash
crowdin init
```

פקודה זו תדריך אותך בתהליך ההגדרה, כולל הגדרת מזהה הפרויקט, טוקן API ופרטי תצורה אחרים.

## 🗂️ מדריך תצורה

### 📄 קובץ תצורת Crowdin ‏(`crowdin.yml`)

קובץ תצורת Crowdin ‏(`crowdin.yml`) מגדיר כיצד קובצי המקור שלך ממופים והיכן צריך למקם תרגומים. להלן דוגמת תצורה:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 פרמטרי תצורה מרכזיים

- **`project_id`**: מזהה הפרויקט שלך ב־Crowdin. זה מזהה את הפרויקט בתוך Crowdin שבו התרגומים מנוהלים.
- **`api_token`**: טוקן ה־API המשמש לאימות. ודא שלטוקן זה יש את ההרשאות הנכונות להעלאה והורדה של תרגומים.
- **`base_path`**: מציין את תיקיית הבסיס עבור קובצי מקור. בדוגמה זו, תרגומים מאוחסנים בתיקייה `./locales`.
- **`base_url`**: כתובת ה־URL הבסיסית עבור ה־API של Crowdin.
- **`preserve_hierarchy`**: כאשר מוגדר ל־`true`, ‏Crowdin ישמור על מבנה התיקיות של קובצי המקור שלך בפרויקט.

### 📂 תצורת קבצים

הקטע `files` ממפה את קובצי המקור שלך לנתיבים שבהם יאוחסנו תרגומים. לדוגמה:

- **נתיב מקור**: מגדיר את המיקום של קובצי התרגום המקוריים.
- **נתיב תרגום**: מציין היכן קובצי התרגום יאוחסנו ב־Crowdin. ‏Placeholders כמו `%two_letters_code%` משמשים להגדרה דינמית של קוד השפה בנתיבי הקבצים.

## ⬆️ העלאת קובצי מקור ל־Crowdin

לאחר שתצורת Crowdin שלך מוגדרת, תוכל להעלות את קובצי המקור שלך באמצעות הפקודה הבאה:

```bash
crowdin upload sources
```

פקודה זו מעלה את כל קובצי המקור שצוינו בתצורה שלך ל־Crowdin, ומאפשרת להם להיות זמינים לתרגום.

## ⬇️ הורדת תרגומים מ־Crowdin

לאחר שהתרגומים הושלמו או עודכנו ב־Crowdin, תוכל להוריד אותם לפרויקט שלך באמצעות:

```bash
crowdin download
```

פקודה זו מביאה את התרגומים האחרונים מ־Crowdin ושומרת אותם בהתאם לנתיבים שצוינו בקובץ התצורה שלך.

## ⚙️ שיטות עבודה מומלצות

### 🔑 מתן שמות מפתחות עקבי

ודא שמפתחות התרגום עקביים בכל הקבצים כדי להימנע מבלבול וכפילויות.

### 🧹 תחזוקה שוטפת

עיין ונקה מעת לעת מפתחות תרגום שאינם בשימוש כדי לשמור על הקבצים מאורגנים וניתנים לניהול.

### 🛠 אוטומט העלאות והורדות

שלב את פקודות Crowdin CLI ב־pipeline של CI/CD שלך כדי לאוטומט את העלאת קובצי המקור והורדת התרגומים, ולהבטיח שהתרגומים שלך תמיד מעודכנים.

באמצעות מדריך זה, תוכל לשלב את Crowdin בפרויקט שלך בצורה חלקה, ולהבטיח גישה יעילה ומאורגנת לניהול מאמצי הבין־לאומיזציה שלך.
