# עקיפות i18n בזמן ריצה

השתמש במדריך זה כאשר אתה צריך שאותו פריט בנייה יריץ עם ברירות מחדל שונות של שפה לכל סביבה (לדוגמה: instances שונים של דיירים).

## מה ניתן לעקוף בזמן ריצה

המודול תומך בעקיפות זמן ריצה בטוחות עבור:

- `defaultLocale`
- `fallbackLocale`
- `disabledLocales`

עקיפות אלה מוחלות על גבי תצורת זמן הבנייה מ־`.nuxt/i18n.strategy.mjs` ו־`.nuxt/i18n.config.mjs`.

## מה לא ניתן לעקוף בזמן ריצה

`strategy` ‏(`no_prefix`, ‏`prefix`, ‏`prefix_except_default`, ‏`prefix_and_default`) הוא עניין של זמן בנייה כי הוא משפיע על התנהגות המסלולים שנוצרו.

אם תעביר עקיפת אסטרטגיה בזמן ריצה, היא מתעלמת ואזהרה מונפקת.

## עקיפות מבוססות RuntimeConfig

ספק ערכי זמן ריצה תחת `runtimeConfig.public.i18nRuntime`:

```ts
export default defineNuxtConfig({
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

## עקיפות משתני סביבה

תוכל גם להגדיר עקיפות דרך משתני סביבה:

- `NUXT_I18N_DEFAULT_LOCALE`
- `NUXT_I18N_FALLBACK_LOCALE`
- `NUXT_I18N_DISABLED_LOCALES` (מופרד בפסיק, למשל `fr,it`)

גם כינויי fallback נתמכים:

- `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES`

## כללי אימות

בזמן ריצה, המודול מאמת עקיפות כדי להימנע ממצב שבור:

- לא ניתן להשבית את כל השפות.
- `defaultLocale` חייב להצביע לשפה מופעלת.
- `fallbackLocale` חייב להתקיים בשפות המוצהרות.

אם עקיפה אינה תקינה, המודול שומר ערך בטוח ומתעד אזהרה.

## הערות לפריסות רב־instances

תכונת זמן ריצה זו מיועדת להפעלת שפה וברירות מחדל לכל instance ללא בנייה מחדש.

אם instances דורשים אסטרטגיות URL שונות ‏(`no_prefix` לעומת `prefix`), השתמש בבניות נפרדות לכל אסטרטגיה.

## שפות מושבתות ו־payloads סטטיים

`runtimeConfig.public.i18nRuntime.disabledLocales` מעדכן ניתוב, ‏switcher וה־**handler** של payload ‏Nitro. אבל Nitro מגיש קבצים תחת `public/` **לפני** אותו handler.

אם `translationPayloads.publicAssets` (או עותק ציבורי נכפה של Node SSR) כבר כתב `/_locales/\{page\}/\{locale\}/data.json`, השבתה בזמן ריצה לא יכולה להסתיר את הקובץ הזה. העדף `locale.disabled: true` בזמן בנייה כך ש־premerge לא ינפיק payloads סטטיים של שפה זו.
