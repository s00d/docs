# עקיפות i18n בזמן ריצה

השתמשו במדריך זה כאשר אתם צריכים שאותה יחידת build תרוץ עם ברירות מחדל שונות של locale לפי סביבה (לדוגמה: מופעים שונים של דיירים).

## מה ניתן לעקוף בזמן ריצה

המודול תומך בעקיפות בטוחות בזמן ריצה עבור:

- `defaultLocale`
- `fallbackLocale`
- `disabledLocales`

עקיפות אלה מוחלות על גבי קונפיגורציית build-time מתוך `.nuxt/i18n.strategy.mjs` ו-`.nuxt/i18n.config.mjs`.

## מה לא ניתן לעקוף בזמן ריצה

`strategy` (`no_prefix`, `prefix`, `prefix_except_default`, `prefix_and_default`) הוא עניין של build-time כי הוא משפיע על התנהגות routes שנוצרו.

אם תעבירו עקיפת strategy בזמן ריצה, היא תתעלם ותופק אזהרה.

## עקיפות מבוססות RuntimeConfig

ספקו ערכי זמן ריצה תחת `runtimeConfig.public.i18nRuntime`:

```ts
export default defineNuxtConfig({
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

## עקיפות באמצעות משתני סביבה

ניתן להגדיר עקיפות גם באמצעות משתני סביבה:

- `NUXT_I18N_DEFAULT_LOCALE`
- `NUXT_I18N_FALLBACK_LOCALE`
- `NUXT_I18N_DISABLED_LOCALES` (מופרד בפסיקים, למשל `fr,it`)

גם כינויי fallback נתמכים:

- `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES`

## כללי אימות

בזמן ריצה, המודול מאמת עקיפות כדי למנוע מצב שבור:

- לא ניתן להשבית את כל ה-locales.
- `defaultLocale` חייב להצביע על locale מופעל.
- `fallbackLocale` חייב להתקיים ב-locales המוצהרים.

אם עקיפה אינה תקינה, המודול שומר על ערך בטוח ומדפיס אזהרה.

## הערות עבור פריסות מרובות מופעים

תכונת זמן ריצה זו מיועדת להפעלת locale לפי מופע ולברירות מחדל ללא בנייה מחדש.

אם מופעים דורשים אסטרטגיות URL שונות (`no_prefix` מול `prefix`), השתמשו ב-builds נפרדים עבור כל אסטרטגיה.

## Locales מושבתים ומטענים סטטיים

`runtimeConfig.public.i18nRuntime.disabledLocales` מעדכן את הניתוב, ה-switcher ואת **מטפל** ה-payload של Nitro — אבל Nitro מגיש קבצים תחת `public/` **לפני** אותו מטפל.

אם `translationPayloads.publicAssets` (או ההעתקה הכפויה לציבורי של Node SSR) כבר כתב `/_locales/\{page\}/\{locale\}/data.json`, השבתה בזמן ריצה לא תוכל להסתיר את הקובץ הזה. עדיפו `locale.disabled: true` ב-build כדי ש-premerge לא יפיק מטענים סטטיים של אותו locale.
