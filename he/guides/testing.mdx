# 🧪 בדיקת מודול `Nuxt I18n Micro`

## 📖 מבוא לבדיקה

בדיקת מודול `Nuxt I18n Micro` חיונית כדי להבטיח שתכונות הלוקליזציה של האפליקציה שלכם עובדות כצפוי. תיעוד זה ידריך אתכם דרך הגדרת סביבת הבדיקה, יצירת קונפיגורציות mock עבור vitest וכתיבת בדיקות לקומפוננטות שלכם. לדוגמה מעשית, ניתן לעיין ב[פרויקט לדוגמה ב-GitHub](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/test-utils/example).

ראו [בדיקת אסטרטגיות ניתוב](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/testing-strategies.md) לכיצד מאגר זה מריץ סוויטות משלו — פרויקטי Vitest של `unit` / `integration` / `e2e`, קבצים לפי אסטרטגיה (`test/strategies-*.test.ts`), ורגרסיות של generate.

## 🛠️ הגדרת סביבת הבדיקה

### 1. התקינו את `@i18n-micro/test-utils`

ראשית, עליכם להתקין את כלי הבדיקה עבור `Nuxt I18n Micro`. חבילה זו מספקת את הכלים הדרושים כדי לבצע mock ולבדוק את קונפיגורציות ה-i18n שלכם.

```bash
npm install @i18n-micro/test-utils --save-dev
```

### 2. צרו קובץ קונפיגורציית Mock

לאחר מכן, צרו קובץ כדי להגדיר את קונפיגורציית ה-i18n המדומה. קובץ זה ישמש כדי לבצע mock לפונקציות i18n ולכלים במהלך הבדיקות שלכם.

```typescript
// tests/unit-setup.ts

import { mockNuxtImport } from '@nuxt/test-utils/runtime'
import { vi } from 'vitest'
import { i18nUtils } from '@i18n-micro/test-utils'

export function createFakeI18n() {
  return {
    $getLocale: vi.fn(i18nUtils.getLocale),
    $t: vi.fn(i18nUtils.t),
    $tc: vi.fn(i18nUtils.tc),
    $setLocale: vi.fn(i18nUtils.setLocale),
    $getLocaleName: vi.fn(i18nUtils.getLocaleName),
    $setLocaleName: vi.fn(i18nUtils.setLocaleName),
    $getLocales: vi.fn(i18nUtils.getLocales),
    $setLocales: vi.fn(i18nUtils.setLocales),
    $defaultLocale: vi.fn(i18nUtils.defaultLocale),
    $setDefaultLocale: vi.fn(i18nUtils.setDefaultLocale),
    $getRouteName: vi.fn(i18nUtils.getRouteName),
    $settRouteName: vi.fn(i18nUtils.settRouteName),
    $ts: vi.fn(i18nUtils.ts),
    $tn: vi.fn(i18nUtils.tn),
    $td: vi.fn(i18nUtils.td),
    $has: vi.fn(i18nUtils.has),
    $resolveTranslations: vi.fn(i18nUtils.resolveTranslations),
    $setTranslation: vi.fn(i18nUtils.setTranslation),
    $mergeTranslations: vi.fn(i18nUtils.mergeTranslations),
    $switchLocaleRoute: vi.fn(i18nUtils.switchLocaleRoute),
    $switchLocalePath: vi.fn(i18nUtils.switchLocalePath),
    $switchLocale: vi.fn(i18nUtils.switchLocale),
    $switchRoute: vi.fn(i18nUtils.switchRoute),
    $localeRoute: vi.fn(i18nUtils.localeRoute),
    $localePath: vi.fn(i18nUtils.localePath),
    $setI18nRouteParams: vi.fn(i18nUtils.setI18nRouteParams),
  }
}

mockNuxtImport<() => ReturnType<typeof createFakeI18n>>('useI18n', () => vi.fn(() => createFakeI18n()))

export const setTranslationsFromJson = i18nUtils.setTranslationsFromJson
```

### 3. הגדירו את Vitest

כעת, הגדירו את Vitest לשימוש בקובץ קונפיגורציית ה-mock והגדירו את סביבת הבדיקה.

```typescript
// vitest.config.ts

import { defineVitestConfig } from '@nuxt/test-utils/config'

export default defineVitestConfig({
  test: {
    watch: false,
    setupFiles: ['./tests/unit-setup.ts'],
    include: ['./**/*.spec.ts'],
  },
})
```

## 🧪 כתיבת בדיקות

### קומפוננטה לדוגמה

הנה דוגמה לקומפוננטה פשוטה המשתמשת ב-composable `useI18n` כדי לתרגם הודעות.

```vue
<script setup lang="ts">
const { $t } = useI18n()

const props = defineProps({
  message: {
    type: String,
    default: null,
  },
})

// Test to see that $t works in script setup as well as the template
const message = props.message || $t('defaultMessage')
</script>

<template>
  <div>
    <p>Test from component: {{ $t('welcome') }}</p>
    <p data-testid="message">Test message from props: {{ message }}</p>
  </div>
</template>
```

### קובץ בדיקה

עכשיו, נכתוב בדיקה לקומפוננטה הזו.

```typescript
// tests/unit/example.spec.ts

import { describe, it, expect, beforeEach } from 'vitest'
import { mount } from '@vue/test-utils'
import ExampleComponent from '@/components/ExampleComponent.vue'
import fs from 'fs'
import path from 'path'
import { setTranslationsFromJson } from './unit-setup'

describe('ExampleComponent', () => {
  beforeEach(async () => {
    const fileContent = fs.readFileSync(path.join(__dirname, '../../locales/en-GB.json')).toString()
    await setTranslationsFromJson('en', JSON.parse(fileContent))
  })

  it('renders the welcome message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.text()).toContain('Test from component: Welcome')
  })

  it('renders the default message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Default Message')
  })

  it('renders the custom message correctly', () => {
    const wrapper = mount(ExampleComponent, {
      props: {
        message: 'Custom Message',
      },
    })
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Custom Message')
  })
})
```

## 📝 שיטות עבודה מומלצות לבדיקה

- **🔧 בצעו Mock לפונקציות i18n:** תמיד בצעו mock לפונקציות i18n באמצעות `@i18n-micro/test-utils` כדי להבטיח תוצאות בדיקה עקביות וצפויות.
- **⚙️ השתמשו ב-Vitest לבדיקות יחידה:** Vitest הוא framework בדיקה חזק לאפליקציות Vue. השתמשו בו כדי לכתוב בדיקות יחידה עבור הקומפוננטות שלכם.
- **📚 תעדו את הבדיקות שלכם:** תעדו בבירור את המטרה והתוצאות הצפויות של כל בדיקה. זה יעזור לשמור על בהירות ויקל על אחרים (או עליכם בעתיד) להבין את הבדיקות.

## 📊 מתודות עזר של i18n

להלן טבלה המתארת את כל מתודות העזר המסופקות על ידי `@i18n-micro/test-utils`.

| מתודה                                          | תיאור                                                                                                                                |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `t(key, params, defaultValue)`                  | מתרגם מפתח עם פרמטרים אופציונליים וערך ברירת מחדל.                                                                             |
| `tc(key, params, defaultValue)`                 | מתרגם מפתח עם תמיכה בצורות רבים.                                                                                               |
| `setTranslationsFromJson(locale, translations)` | טוען תרגומים מאובייקט JSON עבור locale ספציפי.                                                                               |
| `getLocale()`                                   | מחזיר את ה-locale הנוכחי.                                                                                                                |
| `setLocale(val)`                                | קובע את ה-locale הנוכחי.                                                                                                                   |
| `getLocaleName()`                               | מחזיר את שם ה-locale הנוכחי.                                                                                                           |
| `setLocaleName(val)`                            | קובע את שם ה-locale הנוכחי.                                                                                                              |
| `getLocales()`                                  | מחזיר את רשימת ה-locales הזמינים.                                                                                                     |
| `setLocales(val)`                               | קובע את רשימת ה-locales הזמינים.                                                                                                        |
| `defaultLocale()`                               | מחזיר את ה-locale ברירת המחדל.                                                                                                                |
| `setDefaultLocale(val)`                         | קובע את ה-locale ברירת המחדל.                                                                                                                   |
| `getRouteName()`                                | מחזיר את שם ה-route הנוכחי.                                                                                                            |
| `settRouteName(val)`                            | קובע את שם ה-route הנוכחי.                                                                                                               |
| `ts(key, params, defaultValue)`                 | מתרגם מפתח ומחזיר את התוצאה כמחרוזת.                                                                                       |
| `tn(value, options?)`                           | מעצב מספר עם `Intl.NumberFormatOptions` inline. פורמטים בשם דורשים קונפיגורציית מודול ואינם זמינים בעוזר עצמאי זה. |
| `td(value, options?)`                           | מעצב תאריך עם `Intl.DateTimeFormatOptions` inline. פורמטים בשם דורשים קונפיגורציית מודול ואינם זמינים בעוזר עצמאי זה. |
| `has(key)`                                      | בודק אם מפתח תרגום קיים.                                                                                                        |
| `resolveTranslations()`                             | מחזיר את עץ התרגום הפעיל עבור ה-locale וה-route הנוכחיים.                                                                      |
| `setTranslation(key, value)`                    | מחליף את הערך ב-`key` במילון הפעיל (החלפה, לא מיזוג).                                                                 |
| `mergeTranslations(newTranslations)`              | ממזג תרגומים ל-locale הפעיל בזמן ריצה.                                                                                     |

על ידי מעקב אחר שלבים אלה, תוכלו לבדוק ביעילות את מודול `Nuxt I18n Micro` ולהבטיח שתכונות הלוקליזציה של האפליקציה שלכם עובדות כצפוי.
