# החרגת קבצים סטטיים מניתוב i18n

## סקירה

כברירת מחדל, nuxt-i18n-micro מחריג באופן אוטומטי קבצים סטטיים נפוצים מעיבוד ניתוב i18n. עם זאת, ניתן גם להגדיר דפוסי החרגה מותאמים אישית כדי למנוע מנתיבים ספציפיים להיות מעובדים על ידי מערכת ה-i18n.

## החרגות מובנות

המודול מחריג באופן אוטומטי את סוגי הקבצים והדפוסים הבאים:

- **Sitemaps**: `/sitemap*.xml`, `/sitemap-en.xml` וכו'.
- **קבצי SEO**: `/robots.txt`, `/favicon.ico`
- **קבצי PWA**: `/manifest.json`, `/sw.js`, `/workbox-*.js`
- **נכסים סטטיים**: קבצים עם הרחבות כמו `.xml`, `.txt`, `.ico`, `.json`, `.js`, `.css`, `.png`, `.jpg`, `.jpeg`, `.gif`, `.svg`, `.woff`, `.woff2`, `.ttf`, `.eot`
- **נתיבי Nuxt פנימיים**: כל נתיב המתחיל ב-`__` (כמו `/__nuxt/`)

## דפוסי החרגה מותאמים אישית

תוכלו להגדיר דפוסי החרגה מותאמים אישית באמצעות האפשרות `excludePatterns`:

```typescript
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],

  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'it', iso: 'it-IT' },
    ],
    defaultLocale: 'en',

    // Custom exclusion patterns
    excludePatterns: [
      // String patterns (exact match or prefix)
      '/api/health',
      '/admin',

      // String patterns with wildcards
      '/api/*',
      '/admin/**',

      // Regular expressions
      /^\/api\/v\d+\//,
      /\.(pdf|doc|docx)$/,
    ],
  },
})
```

## סוגי דפוסים

### דפוסי מחרוזת

- **התאמה מדויקת**: `'/api/health'` — מתאים בדיוק ל-`/api/health`
- **התאמת קידומת**: `'/admin'` — מתאים ל-`/admin` ול-`/admin/dashboard`
- **Wildcards**: `'/api/*'` — מתאים ל-`/api/users` אך לא ל-`/api/users/123`
- **Wildcards עמוקים**: `'/admin/**'` — מתאים ל-`/admin/users` ול-`/admin/users/123`

### ביטויים רגולריים

השתמשו באובייקטי RegExp להתאמת דפוסים מורכבת:

```typescript
excludePatterns: [
  /^\/api\/v\d+\//, // API versioned routes
  /\.(pdf|doc|docx)$/, // Document files
  /^\/static\//, // Static directory
  /^\/[a-z]{2}\/api\//, // Localized API routes
]
```

## מקרי שימוש

### קבצי SEO

```typescript
excludePatterns: ['/sitemap.xml', '/sitemap-*.xml', '/robots.txt', '/favicon.ico']
```

### נתיבי API

```typescript
excludePatterns: ['/api/**', '/graphql', '/webhook/**']
```

### פאנלי אדמין

```typescript
excludePatterns: ['/admin', '/admin/**', '/dashboard']
```

### נכסים סטטיים

```typescript
excludePatterns: ['/assets/**', '/static/**', '/uploads/**']
```

## כיצד זה עובד

1. **Server Middleware**: middleware של Nitro פועל תחילה כדי לבדוק דפוסי החרגה
2. **עיבוד עמוד**: במהלך פתרון עמוד, נתיבים שהוחרגו מדולגים
3. **Catch-all Route**: ה-fallback route בודק החרגות לפני העיבוד
4. **Prerendering**: נתיבים שהוחרגו אינם נכללים ב-routes שעברו prerender

## השפעה על ביצועים

- בדיקות החרגה מיטובות ופועלות מוקדם במחזור החיים של הבקשה
- דפוסים מובנים משתמשים בהתאמת regex יעילה
- דפוסים מותאמים אישית מאוחסנים ב-cache וממוחזרים
- תקורת ביצועים מינימלית עבור נתיבים שהוחרגו

## פתרון בעיות

### קבצים סטטיים עדיין מיורטים

1. **בדקו תחביר דפוס**: ודאו שהדפוסים שלכם מתאימים למבנה הנתיב המדויק
2. **השתמשו ב-regex לדפוסים מורכבים**: ל-wildcards של מחרוזות יש מגבלות
3. **בדקו דפוסים**: השתמשו בכלי פיתוח של הדפדפן כדי לוודא את נתיב הבקשה בפועל
4. **בדקו סדר**: ודאו שדפוסי ההחרגה מוגדרים לפני קונפיגורציית i18n אחרת

### דפוס לא עובד

```typescript
// ❌ Wrong - this won't work
excludePatterns: ['sitemap.xml']

// ✅ Correct - include leading slash
excludePatterns: ['/sitemap.xml']

// ✅ Better - use regex for flexibility
excludePatterns: [/^\/sitemap.*\.xml$/]
```

### מצב Debug

הפעילו מצב debug כדי לראות עיבוד החרגה:

```typescript
i18n: {
  debug: true,
  excludePatterns: ['/api/**']
}
```

זה יתעד החלטות החרגה בקונסולה.

## הגירה מפתרונות עוקפים

אם השתמשתם בפתרונות עוקפים כמו route rules או middleware, כעת תוכלו להחליף אותם ב-`excludePatterns`:

```typescript
// ❌ Old workaround
export default defineNuxtConfig({
  routeRules: {
    '/sitemap*.xml': { headers: { 'content-type': 'application/xml' } },
  },
})

// ✅ New approach
export default defineNuxtConfig({
  i18n: {
    excludePatterns: ['/sitemap*.xml'],
  },
})
```

הגישה החדשה אמינה יותר ופועלת במספר רמות של מערכת הניתוב.
