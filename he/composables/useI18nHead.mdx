`useI18nHead()` משנה את תגי ה-SEO שהמודול יוצר, עבור עמוד אחד בלבד. השתמשו בו כשהעמוד יודע יותר טוב מהנתב: מאמר CMS שקיים רק בחלק מה-locales, כתובת canonical שמגיעה מ-API, תגי `og:` נוספים. תקבלו את התגים שנוצרו כשהדריסות שלכם ממוזגות מעליהם.

## חתימה {#signature}

```ts
useI18nHead(input?: MaybeRefOrGetter<I18nHeadInput | null>): { pageHead: any; resetPageHead: () => void }
```

רישום דריסות ברמת העמוד עבור תגי head של SEO ב-i18n.
ממוזגות מעל הפלט של `useLocaleHead` על ידי התוסף `02.meta`.

העדיפו getter ‏(`() => ({ … })`) כשהערכים מגיעים מ-`$t` / `t`, כדי שהם
ייפתרו מחדש בעת החלפת locale. אובייקט פשוט מוערך פעם אחת ונשאר קפוא.

| פרמטר | טיפוס | תיאור |
| --- | --- | --- |
| `input` *(אופציונלי)* | `MaybeRefOrGetter<I18nHeadInput \| null>` |  |

זה עובד עם [`meta: true`](/he/api/module-options#meta) (ברירת המחדל): תוסף ה-meta של המודול ממזג את הקלט מעל הפלט של [`useLocaleHead`](/he/composables/useLocaleHead) בכל רינדור של ה-head. עם `meta: false` אף אחד לא קורא אותו.

הדריסה מתאפסת כששם הנתיב משתנה. עמוד שמגדיר `disableMeta` לא מקבל תגי i18n כלל, כולל הדריסות.

## קלט {#input}

`I18nHeadInput` (מתוך `@i18n-micro/types`):

| מפתח | טיפוס | השפעה |
| --- | --- | --- |
| `htmlAttrs` | `Record<string, string>` | ממוזג לתוך המאפיינים של `<html>` ‏(`lang`, `dir`). |
| `meta` | `I18nHeadMeta[]` | מתווסף אחרי התגים שנוצרו; מחליף תג עם אותו `id`, `property` או `name`. |
| `link` | `I18nHeadLink[]` | מתווסף אחרי הקישורים שנוצרו; מחליף קישור עם אותו `id`, או אותם `rel` + `hreflang`. |
| `replace.canonical` | `string \| false` | מחליף את ה-`href` של ה-canonical, או מסיר את הקישור. |
| `replace.hreflang` | `I18nHeadLink[] \| false` | מחליף או מסיר **כל** קישור `rel="alternate"`, כולל `x-default`. |
| `replace.xDefault` | `I18nHeadLink \| false` | מחליף או מסיר את הקישור `x-default`. |
| `replace.ogLocale` | `string \| false` | מחליף או מסיר את `og:locale`. |
| `replace.ogUrl` | `string \| false` | מחליף או מסיר את `og:url`. |
| `replace.ogAlternates` | `string[] \| false` | בונה מחדש את `og:locale:alternate` מקודי ה-locale האלה (דרך `og` / `iso`), תוך דילוג על ה-locale הנוכחי, קודים לא מוכרים וקודים ללא ערך `og` או `iso`, או מסיר אותם. |
| `disable` | `I18nHeadDisableGroup[]` | מסיר קבוצות שנוצרו: `'hreflang'` (לא `x-default`), `'x-default'`, `'canonical'`, `'og'` ‏(`og:locale` + `og:url`), `'og-alternates'`, `'html'`. |

סדר ההחלה: `disable`, אחר כך `replace`, ואז `htmlAttrs`, `meta`, `link`.

## דוגמה {#example}

מאמר שקיים רק בחלק מה-locales, עם כתובות חלופיות מה-API:

```vue
<script setup lang="ts">
const route = useRoute()
const { t } = useI18n()
const { data: article } = await useFetch<{ title: string; urls: Record<string, string> }>(`/api/articles/${route.params.slug}`)

useI18nHead(() => {
  if (!article.value) return null
  const codes = Object.keys(article.value.urls)
  return {
    meta: [{ property: 'og:title', content: article.value.title || t('blog.title') }],
    replace: {
      hreflang: codes.map((code) => ({ rel: 'alternate', hreflang: code, href: article.value!.urls[code]! })),
      ogAlternates: codes,
    },
  }
})
</script>
```

העבירו getter, כמו כאן, כשהערכים מגיעים מ-`t()` או מנתונים אסינכרוניים: הוא רץ מחדש בעת החלפת locale. אובייקט פשוט נקרא פעם אחת.
