---

`useI18n()` מחזיר את פונקציות העזר של זמן הריצה של המודול כאובייקט פשוט. השתמשו בו ב-`<script setup>`, ב-composables ובתוספים (plugins) במקום לפנות ל-`useNuxtApp()`. כל פונקציית עזר זמינה תחת שמה עם `$` וגם תחת כינוי ללא הקידומת: `t` ו-`$t` הן אותה פונקציה.

## חתימה {#signature}

```ts
useI18n(): PluginsInjectionsWithAliases
```

כל פונקציות העזר של זמן הריצה, כאובייקט פשוט.

אותן פונקציות שהתוסף מזריק בתור `$t`, `$tc` וכן הלאה, זמינות גם תחת
השם עם קידומת הדולר וגם תחת כינוי ללא קידומת — כך ש-`const { t } = useI18n()` וגם
`const { $t } = useI18n()` עובדים.

**ערך מוחזר** — פונקציות העזר המתוארות ב[מדריך המתודות](/he/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

האובייקט המוחזר מכיל כל פונקציית עזר של [`PluginsInjections`](/he/api/methods). כל אחת מהן מתועדת בעמוד [פונקציות עזר](/he/api/methods).

## דוגמה {#example}

```vue
<script setup lang="ts">
const { t, tc, localePath, switchLocale, getLocale } = useI18n()

const title = computed(() => t('page.title'))
</script>

<template>
  <h1>{{ title }}</h1>
  <p>{{ tc('items', 3) }}</p>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
  <button @click="switchLocale(getLocale() === 'en' ? 'de' : 'en')">{{ t('nav.switch') }}</button>
</template>
```

## לא נכלל בטיפוס {#not-in-the-type}

`$defineI18nRoute` מוגדר בטיפוס של `useNuxtApp()` בלבד:

```ts
const { $defineI18nRoute } = useNuxtApp()
```
