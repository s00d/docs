---
title: "useLocaleHead"
description: "useLocaleHead בונה את תגי ה-SEO של i18n ‏(lang, ‏dir, ‏canonical, ‏hreflang, ‏og:locale) כאובייקט שמעבירים ל-useHead."
---

`useLocaleHead()` בונה את תגי ה-head של i18n עבור הנתיב הנוכחי: `lang` ו-`dir` על `<html>`, קישור canonical, חלופות `hreflang` עם `x-default`, ‏`og:url`, ‏`og:locale` ו-`og:locale:alternate`. השתמשו בו כשאתם מגדירים [`meta: false`](/he/api/module-options#meta) ומנהלים את `useHead` בעצמכם; עם `meta: true` המודול כבר רושם את התגים האלה, ושינויים ברמת העמוד עוברים דרך [`useI18nHead`](/he/composables/useI18nHead).

## חתימה {#signature}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { build: () => LocaleHead; metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }, LocaleHead | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

תגי ה-head של SEO עבור הנתיב הנוכחי: חלופות `hreflang` לכל locale ובנוסף
`x-default`, קישור canonical, ‏`og:locale`, ו-`lang`/`dir` על `<html>`.

נחוץ רק כש-`meta` מושבת או כשיש צורך להתאים את ברירות המחדל — עם `meta: true`
המודול רושם את אותם תגים בעצמו.

| פרמטר | טיפוס | תיאור |
| --- | --- | --- |
| `options` | `UseLocaleHeadOptions` |  |

**ערך מוחזר** — `metaObject`, ‏ref שמחזיק את אובייקט ה-head מוכן להעברה ל-`useHead`; ‏`updateMeta` מרענן אותו; ‏`build` מחשב את אובייקט ה-head מהנתיב הנוכחי (ריאקטיבי כשנקרא בתוך getter, למשל `useHead(() => build())`)

```ts
const { metaObject } = useLocaleHead({ addSeoAttributes: true })
useHead(metaObject)
```

## אפשרויות {#options}

| אפשרות | ברירת מחדל | תיאור |
| --- | --- | --- |
| `addDirAttribute` | `true` | מגדיר `dir` על `<html>` לפי ה-`dir` של ה-locale (`'auto'` כשאין לו). |
| `identifierAttribute` | `'id'` | המאפיין שמשמש כמפתח לכל תג (`i18n-can`, `i18n-og`, `i18n-alternate-<hreflang>`, …), כך שעדכונים מחליפים תגים במקום להוסיף אותם. |
| `addSeoAttributes` | `true` | פולט תגי canonical, ‏`hreflang` ו-`og:`. ‏`false` משאיר רק את `htmlAttrs`. |
| `baseUrl` | `'/'` | ה-origin שמצורף לכל כתובת URL. השאירו `'/'` עבור כתובות יחסיות; העבירו `'https://example.com'` עבור כתובות מוחלטות. |
| `autoUpdate` | `true` | בונה מחדש את `metaObject` כשהנתיב או המצב `i18n-locale` משתנים. |

## מה הוא פולט {#what-it-emits}

- כלום בנתיב ללא התאמה (404) או עם `disableMeta` עבור ה-locale הפעיל.
- canonical ו-`og:url`: ‏`$switchLocalePath(<active locale>)`, כשה-query מצומצם ל-[`canonicalQueryWhitelist`](/he/api/module-options#canonicalquerywhitelist) ו-[`trailingSlash`](/he/api/module-options#trailingslash) מוחל.
- `hreflang`: קישור אחד לכל locale מופעל שבו העמוד קיים, `hreflang = iso || code`, תוך דילוג על locales עם `seo: false`; עם `hreflangBaseLanguage: true` ה-locale האזורי הראשון של שפה פולט גם את התג של השפה הבסיסית. אף אחד תחת `no_prefix`.
- `x-default`: הכתובת של ה-locale ברירת המחדל, אלא אם האסטרטגיה היא `no_prefix`, ל-locale ברירת המחדל יש `seo: false`, או שהעמוד לא קיים בו.
- `og:locale` / `og:locale:alternate`: מתוך ה-`og` של ה-locale, או ה-`iso` שלו לאחר המרה (`en-US` → `en_US`); מדולג עם אזהרת פיתוח כששניהם לא עובדים.

## דוגמה {#example}

```ts
// app.vue, with i18n.meta: false
const { metaObject } = useLocaleHead({ baseUrl: 'https://example.com' })
useHead(metaObject)
```

`build()` מחזיר את אותו אובייקט ללא ה-ref: ‏`useHead(() => build())` נשאר ריאקטיבי ללא watcher.
