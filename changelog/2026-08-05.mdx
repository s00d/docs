Releases: **v3.22.0 → v3.26.0**.

## New features

- **Translation Memory API.** Read and patch the active locale dictionary at runtime with `$resolveTranslations()` and `$setTranslation(key, value)`. Useful for DevTools, tests, and in-app editors. See [Methods](/api/methods#resolvetranslations).
- **Named `numberFormats` and `datetimeFormats`.** Configure Vue I18n-compatible named formats per locale, then call `$tn(1000, 'currency')` or `$td(date, 'short')`. See [Module options](/api/module-options).
- **HTTP cache control on `/_locales` payloads.** New [`httpCacheDuration`](/api/module-options) sets `Cache-Control: public, max-age=…, immutable` on translation payloads. Defaults to one year, safely paired with `?v={dateBuild}` cache-busting.
- **Compressed translation payloads.** When `nitro.compressPublicAssets` is enabled, public translation payloads are compressed automatically. See the [Performance guide](/guides/performance).
- **`splitLocaleRoutes` utility.** Build both `pages` and `globalLocaleRoutes` from a single programmatic list (for `pages:extend` scenarios), keyed by route name. See [Custom locale routes](/guides/custom-locale-routes#programmatic-routes-pagesextend--244).
- **`site.url` fallback for SEO base.** When `metaBaseUrl` is unset, SEO tags fall back to `site.url` from `nuxt-site-config` if present, otherwise the request origin. See [`metaBaseUrl`](/api/module-options).

## Updates

- **Astro adapter.** Routing-context isolation, plus wiring for `numberFormats` and `datetimeFormats`.
- **React and Preact.** `I18nSwitcher` now sets correct `aria-haspopup` and `aria-expanded` attributes.
- **Benchmarks.** Performance benchmarks moved to a citty-based CLI.
- **Content fingerprint `dateBuild`.** Default `dateBuild` is now a content fingerprint, so payload `?v=` only changes when translations actually change.

## Fixes

- **Routing.**
  - Localized route matchers now handle dashed and nested paths and parameterized segments correctly.
  - Nested parents are kept when a child route is absolute.
  - `hreflang` is emitted from the locale `iso`, not the routing code.
  - Locale switching under `no_prefix` now replaces history instead of pushing.
- **Redirects.**
  - `autoDetectPath` is honored for cookie and `Accept-Language` preference redirects.
  - `localeRoutes` aliases are preserved under `autoDetectPath: '/'`.
- **Translations.**
  - Custom plural functions returning `null` now fall through to the default plural rule.
  - Translation layers merge without flattening dumps.
  - Disabled locales are omitted from premerged public payloads.
  - HMR skips no-op file writes and re-merges concurrently on root-locale changes.
- **Switcher.** Hides `disabled` locales and restores `customDisabledLinkStyle` and active-style precedence.
- **Module.** Bridged unplugin Vite 8 `Plugin` types for Nuxt Kit compatibility.
- **SSR.** Node SSR now reads from public payloads (no Rollup `raw:` import).

## Breaking changes (v3.22.0)

- SSR chunks moved from `useState('i18n-ssr-chunks')` to `nuxtApp.payload.data['i18n-ssr-chunks']`.
- `getAllTranslations()` was removed from `@i18n-micro/vue`. Use `resolveTranslations()`, `getStorage()`, or `getRouteCache()` instead.
- Default `dateBuild` is now a content fingerprint, so the payload `?v=` will change once on upgrade.
