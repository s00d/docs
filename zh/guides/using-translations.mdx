# 在组件中使用翻译

模块安装并配置完成后，你可以在 Vue 模板和脚本中通过调用 `$t('your_key')` 来显示翻译。

## 1. 根级与页面级翻译文件

1. **根级**翻译位于 `/locales` 目录下（例如 `/locales/en.json`、`/locales/fr.json`）。在构建时，它们会被自动合并到每个页面级文件中，从而在所有页面上都可用。
2. **页面级**翻译位于 `/locales/pages/...`，与你的 Nuxt pages 目录结构一一对应：

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. 在模板中使用 `$t`

在 `.vue` 文件中，你可以直接在模板中使用 `$t`：

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
如果键指向嵌套的 JSON 节点，`$t` 可能返回**对象**（例如 `$t('header')` → `\{ title: "Hi" \}`）。在模板中会渲染为 `[object Object]`。当你需要确保返回字符串时，请使用 `$ts`，或者提供更具体的键，例如 `$t('header.title')`。详情请参阅 [API 参考 — $t vs $ts](/api/methods#t)。
</Tip>

## 3. 切换当前区域

要在应用中切换语言，你可以从 `useI18n()` 中获取 `$locale` 并为其赋一个新的代码：

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. 嵌套键与占位符

- **嵌套键**使用点号表示法，例如 `nested.key.deeper`。
- **占位符**允许你插入动态值：
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. 提示与最佳实践

- **冲突的键**：如果页面级文件包含与根级文件相同的键，则页面级版本优先（根翻译会作为基础在构建时合并）。
- **禁用页面文件**：如果你不想使用页面级翻译，可以在 Nuxt 配置中设置 `disablePageLocales: true`。这样将仅使用 `/locales/*.json` 文件。
- **无需直接导入**：你不需要执行 `import \{ useI18n \} from 'nuxt-i18n-micro'`；模块的自动注入特性会为你处理。

以上就是全部内容！按照这些步骤，你就可以快速**从根级或页面级 JSON 文件中获取翻译**，并使用 `$t` 在你的 Nuxt 应用中**显示它们**。
