# 🛠️ `nuxt-i18n-micro` 中的 DevTools

## Vue DevTools（浏览器扩展）

在开发模式下，模块可以通过 `@vue/devtools-api` 注册一个 **Vue DevTools** 自定义检查器和时间线。这与下方的 Nuxt DevTools 面板是相互独立的。

| 工具 | 适用场景 |
|------|----------|
| **Vue DevTools** | 实时区域、内存中的翻译缓存、`$t` 时间线（`debug: true`）、缺失键事件 |
| **Nuxt DevTools 面板** | 编辑磁盘上的 JSON 文件、配置概览、导入/导出 |

vue-devtools 插件仅在 `nuxt dev` 期间注册（生产构建中不注册）。主插件中的仅开发桥接状态会通过 `import.meta.dev` 的死代码消除被移除。

在保留 Nuxt 面板的同时禁用浏览器集成：

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

详细的 `$t` 时间线事件需要设置 `debug: true`。

## 📖 什么是 Nuxt DevTools？

DevTools 是无缝集成到 `nuxt-i18n-micro` 模块中的强大开发辅助工具。它为管理本地化和翻译任务提供了直观的界面，让你的工作流更加快速和高效。Nuxt DevTools 面向注重便利的开发者，弥合了编码与运行时管理之间的差距。

## 🌟 `nuxt-i18n-micro` DevTools 的核心特性

### 1. **区域管理**

轻松浏览、选择和管理应用中的区域。无论使用一种语言还是多种语言，DevTools 都提供了处理所有本地化设置的集中式枢纽。

### 2. **翻译编辑**

通过集成的 JSON 编辑器直接编辑翻译文件。这消除了对外部工具的依赖，可在不打断工作流的情况下进行实时更新和修改。

### 3. **文件导入与导出**

简化翻译文件管理流程：

- **导出**：将翻译保存为 JSON 文件，用于备份或外部使用。
- **导入**：向项目中加载更新后的翻译文件，保持内容为最新。

### 4. **实时预览**

在开发环境中立即查看更改。此功能确保翻译和配置在上线前是准确的。

### 5. **无缝的 Nuxt 集成**

DevTools 与 `nuxt-i18n-micro` 原生协作，无需额外设置即可增强其能力。它可以在保持 Nuxt 模块化和灵活结构的同时适应你的本地化需求。

## 🛠️ 为何使用 DevTools？

对于需要本地化的项目而言，Nuxt DevTools 是不可或缺的补充。它通过以下方式帮助开发者：

- **节省时间**：自动化文件管理和格式校验等重复任务。
- **减少错误**：提供安全、直观的翻译编辑环境。
- **改善协作**：让非开发人员也能轻松管理翻译。
- **精简工作流**：将多项本地化任务整合到一个界面中。

---

## 🚀 掌控本地化

将 Nuxt DevTools 集成到 `nuxt-i18n-micro` 后，多语言应用管理变得轻松高效。无论是微调翻译还是添加新区域，DevTools 都能为你提供交付精致、用户友好体验所需的工具。
