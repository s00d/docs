# 集成

`@i18n-micro` 系列包是 Nuxt I18n Micro 的轻量级、面向特定框架的版本，专为集成到各种框架和环境中而设计。这些包以最小的占用空间提供核心国际化功能，聚焦于核心翻译特性和基础组件。

## 概述

这些集成包是完整 Nuxt I18n Micro 模块的**精简版**，仅包含国际化所需的核心功能：

- **核心翻译特性** - 基础翻译方法、复数处理和格式化
- **核心组件** - 用于常见 i18n 任务的一小组 UI 组件
- **Router Adapter 模式** - 通过 adapter 抽象实现灵活的路由集成
- **TypeScript 支持** - 完整的类型定义，支持类型安全开发

与完整的 Nuxt 模块不同，这些包：

- 不包含框架特定的路由逻辑
- 需要你实现 router adapter 才能获得路由特性
- 更关注翻译功能而非框架集成
- 尽可能保持轻量并与框架无关

## 核心组件

所有框架包都包含以下核心组件：

### `<I18nT>`

一个翻译组件，用于渲染翻译文本，支持：

- **参数插值** - 将占位符替换为动态值
- **复数处理** - 根据数量自动选择复数形式
- **数字格式化** - 按区域格式化数字
- **日期格式化** - 格式化日期和相对时间
- **HTML 渲染** - 可选的 HTML 内容渲染
- **默认值** - 翻译缺失时的后备文本

**示例：**

```vue
<!-- Vue -->
<I18nT keypath="greeting" :params="{ name: 'World' }" />
```

```tsx
// React
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```tsx
// Solid
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```astro
<!-- Astro -->
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

### `<I18nLink>`

一个本地化链接组件，自动处理 URL 中的区域前缀。功能包括：

- **自动路径本地化** - 根据路由策略添加/移除区域前缀
- **激活状态检测** - 高亮显示当前路由
- **外部链接支持** - 自动检测并处理外部 URL
- **路由集成** - 当可用时使用 router adapter 的 link 组件
- **自定义样式** - 支持激活和悬停状态

**示例：**

```vue
<!-- Vue -->
<I18nLink to="/about" active-class="active">
  About Us
</I18nLink>
```

```tsx
// React
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```tsx
// Solid
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```astro
<!-- Astro -->
<I18nLink href="/about" class="nav-link">
  About Us
</I18nLink>
```

### `<I18nSwitcher>`

一个语言切换组件，提供下拉框或列表界面用于切换区域。功能包括：

- **自动区域列表** - 从配置的区域生成选项
- **当前区域高亮** - 直观地标识当前活动语言
- **自定义标签** - 支持每个区域自定义显示名称
- **路由集成** - 自动导航到本地化路径
- **无障碍** - 恰当的 ARIA 属性和键盘导航

**示例：**

```vue
<!-- Vue -->
<I18nSwitcher />
```

```tsx
// React
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```tsx
// Solid
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```astro
<!-- Astro -->
<I18nSwitcher />
```

### `<I18nGroup>`

一个用于以公共前缀分组翻译的组件，可按页面或功能组织翻译。功能包括：

- **前缀作用域** - 自动为组内所有翻译键添加前缀
- **嵌套分组** - 支持嵌套翻译分组
- **清晰组织** - 帮助维护有序的翻译结构

**示例：**

```vue
<!-- Vue -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

```tsx
// React
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```tsx
// Solid
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```astro
<!-- Astro -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

## 共享的 `createI18n` 选项 \{#create-i18n-options\}

每个框架包的创建方式相同 — 仅选项类型以框架名命名（`ReactI18nOptions`、`SolidI18nOptions` 等）。选项本身完全一致：

| 属性         | 类型                                                       | 必需 | 默认          | 说明                                    |
| ---------------- | ---------------------------------------------------------- | -------- | ---------------- | ---------------------------------------------- |
| `locale`         | `string`                                                   | ✅       | -                | 当前区域代码（例如 `'en'`）             |
| `fallbackLocale` | `string`                                                   | ❌       | 同 `locale` | 翻译缺失时的回退区域    |
| `messages`       | `Record<string, Translations>`                             | ❌       | `\{\}`             | 初始翻译消息                   |
| `plural`         | `PluralFunc`                                               | ❌       | `defaultPlural`  | 自定义复数函数                  |
| `missingWarn`    | `boolean`                                                  | ❌       | `true`           | 为缺失翻译显示控制台警告 |
| `missingHandler` | `(locale: string, key: string, routeName: string) => void` | ❌       | -                | 缺失翻译的自定义处理器        |

除此之外的内容为框架特定，将在对应包的页面上说明。

## Router Adapter 抽象

所有框架包都使用 **router adapter 模式**将 i18n 功能与具体的路由实现解耦。这种设计允许：

- **灵活性** - 使用任意路由库或不使用路由
- **框架独立** - 将路由逻辑保留在应用中，而不是 i18n 包中
- **轻量核心** - 保持 i18n 包小巧、聚焦

### 实现 Router Adapter

要使用路由功能，你需要实现 `I18nRoutingStrategy` 接口：

```typescript
interface I18nRoutingStrategy {
  getCurrentPath: () => string
  linkComponent?: Component
  push: (target: { path: string }) => void
  replace: (target: { path: string }) => void
  resolvePath?: (to: string | { path?: string }, locale: string) => string | { path?: string }
  getRoute?: () => { fullPath: string; query: Record<string, unknown> }
}
```

每个包的文档都包含针对常见路由库实现 adapter 的完整示例：

- **Vue**：Vue Router adapter 示例
- **React**：React Router adapter 示例
- **Solid**：Solid Router adapter 示例
- **Astro**：基于文件的路由 adapter 示例

## 核心特性

所有包共享以下核心特性：

### 翻译方法

- `t()` - 基本翻译，支持参数插值
- `ts()` - 始终返回字符串的翻译
- `tc()` - 支持复数的翻译
- `tn()` - 数字格式化
- `td()` - 日期格式化
- `tdr()` - 相对时间格式化
- `has()` - 检查翻译键是否存在

### 区域管理

- **区域切换** - 通过编程方式切换当前区域
- **回退区域** - 翻译缺失时自动回退
- **路由特定翻译** - 页面级翻译组织
- **翻译缓存** - 智能缓存以提升性能

### TypeScript 支持

所有包都提供：

- 完整的 TypeScript 定义
- 类型安全的翻译键（配合类型生成器）
- IDE 中的 IntelliSense 支持
- 编译时错误检查
