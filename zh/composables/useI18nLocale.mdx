---
title: "useI18nLocale"
description: "useI18nLocale 读写语言环境状态和语言环境 cookie — 是自定义语言环境检测的入口。"
---

`useI18nLocale()` 提供对应用所选语言环境的访问：`i18n-locale` 状态和语言环境 cookie。在自行检测语言环境（域名、用户资料、请求头）的插件中使用它，而不是手动写入 `useState('i18n-locale')` 或 cookie。其有效性检查使用已启用的语言环境，包括运行时覆盖。

## 签名 {#signature}

```ts
useI18nLocale(): { getEffectiveLocale: (route: unknown, getLocaleFromRoute: GetLocaleFromRoute) => string; getLocale: () => string | null; getPreferredLocale: () => string | null; hashCookie: CookieRef; isValidLocale: (locale: string | null | undefined) => locale is string; locale: any; localeCookie: CookieRef; resolveInitialLocale: (options: ResolveInitialLocaleOptions) => string; setLocale: (locale: string | null) => void; syncLocale: (locale: string | null) => void; validLocales: string[] }
```

i18n 语言环境管理的集中入口。
整合了 useState('i18n-locale')、语言环境 cookie 和同步工具。

## 返回值 {#returned-values}

| 成员 | 类型 | 说明 |
| --- | --- | --- |
| `locale` | `Ref<string \| null>` | `useState('i18n-locale')` 的 ref。 |
| `localeCookie` | `Ref<string \| null>` | [`localeCookie`](/zh/api/module-options#localecookie) cookie；当该选项为 `null` 时为普通的 `{ value: null }`。 |
| `hashCookie` | `Ref<string \| null>` | 哈希路由下的 `hash-locale` cookie；否则为 `{ value: null }`。 |
| `validLocales` | `string[]` | 已启用语言环境的代码。 |
| `setLocale(locale)` | `(locale: string \| null) => void` | 写入状态和 cookie。不做校验，也不加载翻译。 |
| `syncLocale(locale)` | `(locale: string \| null) => void` | 仅写入 cookie。 |
| `getLocale()` | `() => string \| null` | 先取状态，再取偏好 cookie（哈希路由下为哈希 cookie）。不做校验。 |
| `getPreferredLocale()` | `() => string \| null` | 状态和偏好 cookie 中第一个**有效**的值，否则为 `null`。 |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string` | 哈希路由下若已设置状态则返回状态；否则返回 `getLocaleFromRoute(route)`。 |
| `resolveInitialLocale(options)` | `(options: ResolveInitialLocaleOptions) => string` | 依次为 `options.urlLocale`、有效的状态、`options.serverLocale`、路由的语言环境。当状态无效时将结果存入状态；在客户端还会写入 cookie。 |
| `isValidLocale(locale)` | `(locale) => locale is string` | `locale` 是否在 `validLocales` 中。 |

cookie 有效期为一年，带有 `path: '/'` 和 `sameSite: 'lax'`。

## 示例 {#example}

```ts
// plugins/locale-from-domain.server.ts
export default defineNuxtPlugin({
  name: 'locale-from-domain',
  enforce: 'pre',
  setup() {
    const { setLocale, isValidLocale } = useI18nLocale()
    const host = useRequestURL().hostname // e.g. de.example.com
    const code = host.split('.')[0]
    if (isValidLocale(code)) setLocale(code)
  },
})
```

模块的加载器插件在启动时读取该状态，因此设置状态的插件必须先运行（`enforce: 'pre'`）。状态如何与 URL、cookie 和 `Accept-Language` 竞争：参见[语言环境检测](/zh/guide/locale-detection)。完整演练：参见[自定义检测](/zh/guide/custom-auto-detect)。

`setLocale()` 不会切换屏幕上的翻译。要更改当前页面的语言环境，请调用 [`$switchLocale()`](/zh/api/methods#$switchlocale)。
