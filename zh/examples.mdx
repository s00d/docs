# 📚 Nuxt I18n Micro 示例与用法

本节提供多种示例，演示如何在 Nuxt.js 应用中使用 `Nuxt I18n Micro`。你将了解如何切换区域、使用 `<i18n-link>`、`<i18n-switcher>`、`<i18n-t>` 组件，以及动态处理翻译键。

## 🛠️ 基础设置

以下是开始使用 `Nuxt I18n Micro` 的基础设置：

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 切换区域

### 通过编程方式切换区域

以下示例演示了如何通过按钮以编程方式切换区域：

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### 用于切换区域的 JSON 示例

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### 使用 `<i18n-switcher>` 组件

`<i18n-switcher>` 组件提供了一个下拉框用于切换区域，并支持自定义标签：

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 📝 从翻译文件渲染动态键

在某些场景下，你可能需要遍历翻译文件中存储的动态键，并根据条件渲染其值。下面的示例演示了如何使用 `Nuxt I18n Micro` 实现这一点。

### 示例：渲染动态键

此示例从特定的翻译路径（此处为 `dynamic`）获取键数组并进行遍历。在使用 `$t` 渲染值之前，会通过 `$has` 检查每个键是否存在。

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### 翻译文件示例（`en.json`）

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### 示例：从对象渲染动态键

在此示例中，我们处理翻译文件中存储的一个对象。我们获取并遍历该对象的键，动态渲染键名及其对应的值。

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### 翻译文件示例（`en.json`）

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 使用 `<i18n-t>` 进行带插槽和插值的翻译

`<i18n-t>` 组件非常适合渲染带动态内容和 HTML 标签的翻译：

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### 用于 `<i18n-t>` 的 JSON 示例

```json
{
  "greeting": "Welcome to the page"
}
```

### 带插值

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### 用于插值的 JSON 示例

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 使用 `$tc` 处理复数

`Nuxt I18n Micro` 中的 `$tc` 函数会根据数量和区域设置处理复数形式。这在动态调整涉及数量的消息时非常有用，例如物品、通知或其他数量可变的实体。

### 示例：使用 `$tc` 处理复数

在下面的示例中，我们使用 `$tc` 显示表示苹果数量的消息。翻译键根据传入的数量处理多种复数形式。

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### 用于复数的 JSON 示例

下面展示了如何在 JSON 文件中定义翻译以处理不同的复数形式：

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### 说明

- **`$tc('apples', 0)`**：返回第一种形式，用于数量为零的情况（`"no apples"`）。
- **`$tc('apples', 1)`**：返回第二种形式，用于数量为一的情况（`"one apple"`）。
- **`$tc('apples', 10)`**：返回第三种形式并带上数量值，用于数量为二或以上的情况（`"10 apples"`）。

### 更复杂复数规则的附加示例

如果你的应用需要处理更复杂的复数规则（例如零、一、二、少量、多个、其他等特定情况），可以相应地扩展翻译字符串：

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**：可以设置为返回 `"two apples"`。
- **`$tc('apples', 3)`**：可以返回 `"a few apples"`，具体取决于为该数量定义的规则。

## 🌐 使用 `$tn` 进行数字格式化

`$tn` 函数使用 `Intl.NumberFormat` API 按当前区域格式化数字。这对于以符合用户地区设置的方式显示数字非常有用，例如货币、百分比或其他数字格式。

### 示例：使用 `$tn` 进行数字格式化

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ 使用 `$td` 进行日期和时间格式化

`$td` 函数使用 `Intl.DateTimeFormat` API 按当前区域格式化日期和时间。这对于以用户熟悉的区域格式显示日期和时间非常有用。

### 示例：使用 `$td` 进行日期和时间格式化

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ 使用 `$tdr` 进行相对日期格式化

`$tdr` 函数使用 `Intl.RelativeTimeFormat` API 按当前区域将日期格式化为相对时间（例如 "5 minutes ago"、"2 days ago"）。这对于显示相对于当前日期和时间的时间差非常有用。

### 示例：使用 `$tdr` 进行相对日期格式化

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
