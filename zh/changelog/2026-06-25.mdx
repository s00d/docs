**日期**：2026-06-25

**版本**：`v3.21.0`

![v3.21.0 release](/images/3.21.0.png)

本次发布新增了 **`useI18nHead`** —— 一个页面级 composable，用于在内置 `02.meta` 插件之上覆盖 i18n SEO 设置。无需自定义 meta 插件或 `meta: false`，即可按路由自定义 `hreflang`、canonical、`og:url` 和 Open Graph 标签。

## 有哪些新内容？ {#what’s-new}

### `useI18nHead` Composable {#usei18nhead-composable}

在 `meta: true`（默认）时，可在任意页面中调用 `useI18nHead`。模块会在每次路由更新时，在 `useLocaleHead` 之后合并你的输入：

```vue
<script setup lang="ts">
useI18nHead(() => ({
  meta: [{ property: 'og:title', content: article.value?.title }],
  replace: {
    canonical: article.value?.canonicalUrl,
    ogUrl: article.value?.canonicalUrl,
    hreflang: localeCodes.map((locale) => ({
      rel: 'alternate',
      hreflang: locale,
      href: article.value!.locales[locale]!,
    })),
    ogAlternates: localeCodes,
  },
}))
</script>
```

支持静态对象、响应式 getter、`meta` / `link` 追加、用于内置分组的 `replace`，以及用于移除自动生成标签的 `disable`。参见 [`useI18nHead`](/zh/composables/useI18nHead)。

### `mergeI18nHead` 工具函数（`@i18n-micro/utils`） {#mergei18nhead-utility-@i18n-micro/utils}

与框架无关的合并逻辑位于 `@i18n-micro/utils/merge-i18n-head` —— 由 `02.meta` 插件使用，并且可以单独测试。类型（`I18nHeadInput`、`I18nHeadLink`、`I18nHeadMeta`）从 `@i18n-micro/types` 导出。

### 插件集成 {#plugin-integration}

- **`02.meta`** —— 通过 `useHead` 将 `useLocaleHead` 的输出与来自 `useI18nHead` 的页面状态合并
- **`01.plugin`** —— 在路由名称变化时通过 `resetPageHead()` 重置页面覆盖（与 composable 共享状态）

### 文档与测试 {#documentation-&-tests}

- 新指南：[`useI18nHead`](/zh/composables/useI18nHead)，附 CMS/文章示例
- 更新了 [SEO](/zh/guide/seo) 和 [`useLocaleHead`](/zh/composables/useLocaleHead) —— 说明何时使用哪个 API
- Playwright + Vitest 覆盖：SSR、SPA 导航、重新加载、`nuxi generate`、部分 alternates、`x-default`、响应式客户端加载

## 典型用例 {#typical-use-cases}

| 场景                                         | 做法                                                           |
| -------------------------------------------- | -------------------------------------------------------------- |
| 部分翻译的博客/CMS                           | 使用来自 API locale 的 `replace.hreflang` + `replace.ogAlternates` |
| 来自 CMS 的自定义 canonical                  | `replace.canonical` + `replace.ogUrl`                          |
| 仅着陆页 OG                                  | `meta: [{ property: 'og:title', ... }]` —— 保留模块的 hreflang |
| 页面上不要 hreflang                          | `disable: ['hreflang', 'x-default']`                           |
| 替换自定义插件（`i18nManualHreflang`）       | 每个内容页使用 `useI18nHead` + `meta: true`                    |

**JSON-LD** 仍放在 `useHead({ script: [...] })` 中 —— `useI18nHead` 不生成结构化数据。

## 破坏性变更 {#breaking-changes}

对于标准的 `nuxt.config` 用法没有破坏性变更。新的 composable 和 utils 子路径均为新增内容。

## 为什么重要 {#why-it-matters}

- **无需自定义 meta 插件**，即可处理具有按 locale 区分 URL 的 CMS 文章、新闻或指南
- **单一管道** —— 模块默认值 + 页面覆盖在一次 `useHead` 调用中完成
- **类型安全** —— 可为 `buildArticleHead(content)` 之类的辅助函数使用 `I18nHeadInput`
