## 🚀 快速开始

### 安装

在你的 Nuxt 应用中安装模块：

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

### 基础配置

将模块添加到你的 `nuxt.config.ts`：

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

<Tip>
- **根级文件**（`locales/en.json` 等）— 应用全局共享的翻译（菜单、页脚、通用 UI）。启用默认 `translationPayloads.mode: 'premerged'` 时，它们会在构建时合并到每个页面中。
- **页面级文件**（`locales/pages/<route>/<locale>.json`）— 特定页面独有的翻译，仅在访问对应页面时加载。
- **动态路由** — `pages/articles/[id].vue` 会映射到 `locales/pages/articles-id/`（方括号会被替换为短横线）。
- **自动生成** — 缺失的翻译文件会在 `nuxt dev` 期间自动创建。
</Tip>

<Info>
该模块同时支持两种目录布局：

- **Pages**：`pages/**/*.vue`（Nuxt 3）或 `app/pages/**/*.vue`（Nuxt 4）
- **Translations**：默认将 `locales/` 保留在**项目根目录**下（推荐约定），而不是放在 `app/` 中。

```tree
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   ├── en.json
│   └── pages/
└── nuxt.config.ts
```

可选的同目录放置方式：`i18n: \{ translationDir: 'app/locales' \}`（参见 [fixture `n3`](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/n3)）。

若需使用可选的 CLI 辅助工具 `text-to-i18n`，请使用 [`nuxt-i18n-micro-cli` ≥ 2.1.1](/guides/cli#-text-to-i18n-command)，这样 `app/pages` 和 `app/components` 就会从项目根目录被扫描。
</Info>

### 基本用法

在组件中使用翻译：

```vue
<template>
  <div>
    <h1>{{ $t('welcome') }}</h1>
    <p>{{ $t('description', { name: 'World' }) }}</p>

    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" @click="$switchLocale(locale.code)">
        {{ locale.code }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useI18n } from '#imports'

const { $t, $getLocales, $switchLocale } = useI18n()
</script>
```
