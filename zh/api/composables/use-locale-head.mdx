# 🌍 `useLocaleHead` 组合式函数

`useLocaleHead` 组合式函数是 `Nuxt I18n Micro` 中的一个工具，帮助你管理本地化路由的 SEO 属性和 HTML meta 标签。它会动态生成 HTML 文档的 `lang` 和 `dir` 属性，并创建 `meta` 与 `link` 标签，以提升本地化内容的 SEO。

## 🛠️ 返回值

`useLocaleHead` 组合式函数返回一个响应式对象和一个更新函数，当源数据变化时你应该调用它。两者的形状都在上方由源代码生成的签名中。

### `metaObject`

响应式 head 载荷（html attrs、meta、link），适合传给 `useHead(metaObject)`。

- **示例**：
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

基于当前路由、区域和配置重新计算 `metaObject`。在输入变化时调用它（例如路由变化时）。

- **示例**：
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### 访问 `link` 与 `meta`

`link` 和 `meta` 数组可通过 `metaObject.value` 访问：

- **示例**：
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ 用法示例

### 基本用法

使用默认选项生成基于区域的 head 属性。

```js
const head = useLocaleHead()
```

### 自定义标识属性

为生成的标签使用自定义标识属性。

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### 禁用 SEO 属性

在不添加与 SEO 相关的 meta 和 link 标签的情况下生成 head 属性。

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### 指定 Base URL

为 canonical 和 alternate URL 设置自定义 base URL。

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 额外特性

### SEO meta 与 link 标签

当启用 `addSeoAttributes` 时，组合式函数会自动生成以下标签：

- 用于当前区域的 `og:locale`（`language_TERRITORY`，下划线格式）。由 `locale.og` 派生，或在可行时从 `locale.iso` 转换。
- 用于页面 canonical URL 的 `og:url`。
- 用于备用语言版本的 `og:locale:alternate`。
- 用于 SEO 优化的 `rel="canonical"` 和 `rel="alternate"` 链接。
- `hreflang="x-default"` 链接，指向默认区域的 URL。这告诉搜索引擎当用户语言不匹配任何已定义区域时应展示哪个 URL。

### 动态区域与方向

组合式函数会根据当前路由的区域动态确定 `lang` 和 `dir` 属性，确保 HTML 文档为国际用户正确配置。

### 处理本地化路由

如果你的路由带有区域代码前缀（例如 `/en/about`），组合式函数会智能调整完整路径以生成 URL，确保 SEO 属性准确且相关。

此组合式函数简化了将 Nuxt 应用为国际受众优化的过程，确保你的站点为全球搜索引擎和用户做好准备。

## 🛠️ 用法示例

以下示例演示如何在 Vue 组件中使用默认设置的 `useLocaleHead` 组合式函数：

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### 代码说明

- **`useLocaleHead` 组合式函数**：该函数在 `<script setup>` 部分调用，返回包含 `htmlAttrs`、`meta` 和 `link` 的对象。

- **`<html>` 标签**：HTML 文档的 `lang` 和 `dir` 属性会根据当前区域动态确定，并应用到 `<html>` 标签上。

- **`<head>` 部分**：
  - **Meta 标签**：会生成与 SEO 相关的 meta 标签，包括 `og:locale`、`og:url`，以及 `rel="canonical"` 和 `rel="alternate"` 标签，用于指定页面的备用语言版本。
  - **Link 标签**：包括 canonical 链接、指向备用语言版本的链接，以及指向默认区域 URL 的 `hreflang="x-default"` 链接。

- **`<body>` 部分**：页面主内容显示在此处。此示例中使用了简单的标题和段落。

### 📝 备注

1. **属性**：所使用的属性（`lang`、`dir`、`rel`、`href`、`hreflang`、`property`、`content`）从 `useLocaleHead` 返回的对象中提取。

2. **SEO 标签生成**：如果 `addSeoAttributes` 选项设置为 `true`，组合式函数会自动为当前区域生成 SEO 标签。

3. **Base URL**：你可以通过 `baseUrl` 选项设置自定义 base URL，以正确生成 canonical 和 alternate 链接。

此示例演示了将 `useLocaleHead` 集成到应用组件中以确保正确的 SEO 属性并改善本地化页面的搜索引擎索引是多么简单。

## 🧩 定制与生命周期

- `useLocaleHead` 本身不会订阅变化。它返回 `metaObject` 和 `updateMeta`。
- 你应当在输入变化时调用 `updateMeta()`（通常是路由变化时），例如从插件中调用：

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## 何时改用 `useI18nHead`

当 `meta: true`（默认）时，对于**按页面**的覆盖（自定义 hreflang、额外的 `og:title`、部分禁用）请优先使用 [`useI18nHead`](/api/composables/use-i18n-head)。仅在 `meta: false` 或你自己管理 `useHead` 时才直接使用 `useLocaleHead`。
