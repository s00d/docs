# 🌍 `useLocaleHead` 组合式函数

`useLocaleHead` 是 `Nuxt I18n Micro` 提供的一个工具组合式函数，帮助你为本地化路由管理 SEO 属性和 HTML meta 标签。它会动态生成 HTML 文档的 `lang` 和 `dir` 属性，并创建 `meta` 与 `link` 标签，从而改善本地化内容的 SEO。

## ⚙️ 选项

当前路由的 SEO head 标签：为每个语言生成 `hreflang` alternate 以及 `x-default`、一个 canonical 链接、`og:locale`，并在 `<html>` 上设置 `lang`/`dir`。

只在 `meta` 被禁用或需要调整默认行为时才用到 —— 使用 `meta: true` 时模块会自身注册相同的标签。

## 🛠️ 返回值

`useLocaleHead` 组合式函数返回一个响应式对象和一个更新函数，当源数据变化时你应调用它。这两者的形状都体现在上方由源代码生成的签名中。

### `metaObject`

响应式 head payload（html attrs、meta、link），可直接传给 `useHead(metaObject)`。

- **示例**：
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

基于当前路由、语言和配置重新计算 `metaObject`。当输入变化时调用它 —— 例如路由变更时。

- **示例**：
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### 访问 `link` 与 `meta`

可以通过 `metaObject.value` 访问 `link` 与 `meta` 数组：

- **示例**：
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ 使用示例

### 基本用法

使用默认选项生成按语言的 head 属性。

```js
const head = useLocaleHead()
```

### 自定义标识属性

为生成的标签使用自定义标识属性。

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### 禁用 SEO 属性

生成 head 属性但不添加与 SEO 相关的 meta 和 link 标签。

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### 指定基础 URL

为 canonical 和 alternate URL 设置自定义基础 URL。

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 其他特性

### SEO meta 与 link 标签

启用 `addSeoAttributes` 时，该组合式函数会自动生成以下标签：

- 当前语言的 `og:locale`（`language_TERRITORY`，下划线）。由 `locale.og` 派生，或在可能时由 `locale.iso` 转换得到。
- 页面 canonical URL 的 `og:url`。
- 备选语言版本的 `og:locale:alternate`。
- 用于 SEO 优化的 `rel="canonical"` 与 `rel="alternate"` 链接。
- 指向默认语言 URL 的 `hreflang="x-default"` 链接。它告诉搜索引擎：语言不匹配任何已定义语言的用户，应看到哪个 URL。

### 动态的语言与文字方向

该组合式函数会根据当前路由的语言动态确定 `lang` 与 `dir` 属性，从而确保 HTML 文档为国际用户正确配置。

### 处理本地化路由

如果你的路由带有语言前缀（例如 `/en/about`），该组合式函数会智能调整完整路径以生成 URL，从而确保 SEO 属性准确、有效。

该组合式函数简化了为国际受众优化 Nuxt 应用的过程，让你的站点更好地面向全球搜索引擎和用户。

## 🛠️ 使用示例

以下示例演示如何在 Vue 组件中使用默认设置调用 `useLocaleHead`：

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### 代码说明

- **`useLocaleHead` 组合式函数**：在 `<script setup>` 中调用，返回包含 `htmlAttrs`、`meta` 和 `link` 的对象。

- **`<html>` 标签**：`lang` 和 `dir` 会根据当前语言动态确定，并应用到 `<html>` 上。

- **`<head>` 部分**：
  - **Meta 标签**：生成与 SEO 相关的 meta 标签，包括 `og:locale`、`og:url` 以及 `rel="canonical"` 和 `rel="alternate"`，用于指定备选语言版本。
  - **Link 标签**：包含 canonical 链接、备选语言链接以及 `hreflang="x-default"`（指向默认语言 URL）。

- **`<body>` 部分**：这里显示页面主体。在该示例中，我们使用了一个简单的标题和段落。

### 📝 备注

1. **属性**：使用的属性（`lang`、`dir`、`rel`、`href`、`hreflang`、`property`、`content`）来自 `useLocaleHead` 返回的对象。

2. **SEO 标签生成**：当 `addSeoAttributes` 选项为 `true` 时，该组合式函数会自动为当前语言生成 SEO 标签。

3. **基础 URL**：你可以通过 `baseUrl` 选项设置自定义基础 URL，从而正确生成 canonical 与 alternate 链接。

这个示例展示了将 `useLocaleHead` 集成到应用组件中是多么简单，可以确保正确的 SEO 属性并提升本地化页面的搜索引擎索引效果。

## 🧩 定制与生命周期

- `useLocaleHead` 本身不会订阅变化。它返回 `metaObject` 与 `updateMeta`。
- 当输入变化时（通常是路由变更时），你需要调用 `updateMeta()`，例如在插件中：

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## 何时改用 `useI18nHead`

当 `meta: true`（默认）时，进行**按页面**的覆盖（自定义 hreflang、额外的 `og:title`、部分禁用）应优先使用 [`useI18nHead`](/api/composables/use-i18n-head)。只在 `meta: false` 或你自己管理 `useHead` 时才直接使用 `useLocaleHead`。
