# 🛠️ `useI18n` 组合式函数

`Nuxt I18n Micro` 中的 `useI18n` 组合式函数在组件和脚本中提供对大多数运行时 i18n 辅助方法的访问。方法**既有带 `$` 前缀的版本，也有不带前缀的版本**（例如 `$t` 和 `t`）。

部分注入项 — `$defineI18nRoute` 和 `$clearCache` — 仅能通过 `useNuxtApp()` 获取。参见[方法 — `$defineI18nRoute`](/api/methods#definei18nroute)和[`$clearCache`](/api/methods#clearcache)。

## 📊 它返回什么

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

以纯对象形式返回所有运行时辅助方法。

即插件注入为 `$t`、`$tc` 等的相同函数，同时提供带 `$` 前缀的名称和不带前缀的别名 — 因此 `const \{ t \} = useI18n()` 和 `const \{ $t \} = useI18n()` 都可以工作。

**返回** — 参见[方法参考](/api/methods)中描述的辅助方法

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

它返回的每个辅助方法 — `$t`、`$tc`、`$has`、`$switchLocale` 等 — 都在[方法参考](/api/methods)中列出了签名并进行了完整说明。

## 仅通过 `useNuxtApp()` 提供的 API

这些方法**不**会由 `useI18n()` 返回。请从 `useNuxtApp()` 中导入：

| 方法                     | 用途                                                                         |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | 按页面的区域路由、限制以及在 `script setup` 中的内联翻译 |
| `$clearCache()`            | 清理内存中的翻译缓存和已加载的 chunk                            |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

参见[方法](/api/methods)获取完整签名和示例。

## 🛠️ 用法示例

### 基本区域获取

获取应用的当前区域。

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### 带参数的翻译

使用动态参数翻译字符串，并提供回退默认值。

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### 切换区域

将应用切换到不同的区域。

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### 生成本地化路由

生成本地化到当前或指定区域的路由。

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
