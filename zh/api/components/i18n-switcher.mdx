# 🌍 `<i18n-switcher>` 组件

`Nuxt I18n Micro` 中的 `<i18n-switcher>` 组件提供了一个用户友好的下拉界面，用于在应用中的不同语言之间切换。该组件高度可定制，可与应用的设计和布局无缝集成。

设置了 `disabled: true` 的语言会从下拉菜单中**省略**（它们仍可通过 `$getLocales()` 用于 SEO / head 标签）。只有可切换的语言会得到 `NuxtLink` + `hreflang`。

各部分默认没有样式：`custom*Style` 属性接受内联样式对象，而当样式无法满足需求时，可通过下方的插槽完全替换 markup。

## 🛠️ 使用示例

### 基本用法

```vue
<template>
  <i18n-switcher />
</template>
```

这会渲染一个带默认样式和行为的语言切换器。

### 自定义标签与内联样式

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

该示例演示了一个包含自定义标签与内联样式的完全定制化语言切换器。

## 🔌 插槽

切换器的每个可视部分都可以被替换。这些插槽在上文属性表中已列出；每个都接受模板内容：

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

名称以 `-item`、`-link-content` 结尾或以 `before-item` 开头的插槽都会接收对应的 `locale` 对象。

## 🎨 样式概览

`<i18n-switcher>` 组件通过内联样式定义了基础样式，可以通过属性传入自定义样式轻松覆盖。以下是默认样式的简要概览：

- **Wrapper**：控制下拉菜单的定位。
- **Button**：定义下拉切换按钮的样式。
- **Dropdown**：定义下拉列表的样式。
- **Items**：定义列表中每项的样式。
- **Links**：定义每项内链接的样式。
- **Icon**：定义下拉指示图标的样式。

你可以通过对应属性传入自定义样式，让语言切换器无缝融入应用的 UI。
