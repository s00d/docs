# 🌍 `<i18n-switcher>` 组件

`Nuxt I18n Micro` 中的 `<i18n-switcher>` 组件提供一个用户友好的下拉界面，用于在应用中切换不同区域。该组件高度可定制，能够无缝融入你的应用设计与布局。

带有 `disabled: true` 的区域会从下拉框中**省略**（它们仍可通过 `$getLocales()` 用于 SEO / head 标签）。只有可切换的区域才会获得 `NuxtLink` + `hreflang`。

## 🛠️ 用法示例

### 基本用法

```vue
<template>
  <i18n-switcher />
</template>
```

这将渲染一个使用默认样式和行为的区域切换器。

### 自定义标签与内联样式

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

此示例展示了一个具有自定义标签和内联样式的完全定制化区域切换器。

## 🔌 插槽

切换器的每个可视部分都可以被替换。插槽已在上方 props 表下方列出；每个都可接收模板内容：

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

名字以 `-item`、`-link-content` 结尾，或以 `before-item` 开头的插槽会接收其对应的 `locale` 对象。

## 🎨 样式概览

`<i18n-switcher>` 组件带有以内联样式定义的基础样式，可以通过 props 传入自定义样式轻松覆盖。以下是默认样式的简要概述：

- **Wrapper**：控制下拉框的定位。
- **Button**：设置下拉切换按钮的样式。
- **Dropdown**：设置下拉列表的样式。
- **Items**：设置列表中每一项的样式。
- **Links**：设置每一项中链接的样式。
- **Icon**：设置下拉指示图标的样式。

你可以通过相应的 prop 传入自定义样式，确保区域切换器与你的应用 UI 无缝集成。
