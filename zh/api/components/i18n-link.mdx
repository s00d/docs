# 🌍 `<i18n-link>` 组件

`Nuxt I18n Micro` 中的 `<i18n-link>` 组件是一个通用的链接组件，会根据当前区域自动本地化路由。它作为 `<NuxtLink>` 组件的包装器，提供了额外的功能，如激活链接样式和对外部链接的支持。

## ⚙️ Props

| Prop | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | 目标路由。会自动本地化；外部 URL 会原样传递。 |
| `activeStyle` | `Partial<CSSStyleValue>` | — | 当链接指向当前路由时应用的内联样式。 |

**\*** 必填。

### 插槽

| 插槽 | 绑定 | 说明 |
| --- | --- | --- |
| `default` | — | 链接内容。 |

{/* /generated:component:i18n-link */}

`to` 接受 `NuxtLink` 支持的任何内容 — 路径、命名路由或已解析的路由对象。
绝对 URL 会被识别并以普通 `<a target="_blank" rel="noopener noreferrer">` 形式渲染，而不会被本地化。

## 🛠️ 用法示例

### 基本用法

```vue
<i18n-link to="/about">About Us</i18n-link>
```

该示例会创建一个指向 `/about` 页面的链接，并本地化到当前区域。

### 使用内联样式突出激活链接

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

当用户处于 `/about` 页面时，该链接会显示为加粗，允许你直接通过内联样式设置激活链接的样式。

### 外部链接处理

组件会自动检测外部链接并添加必要的安全属性。

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

该链接会在新标签页中打开 `https://example.com`，并应用 `rel="noopener noreferrer"`。

## 🎨 样式

组件现在为激活状态使用内联样式而不是类名。你可以通过 `activeStyle` prop 自定义这些样式。

### 默认激活样式

- **字体粗细**：`bold`
- **颜色**：继承浏览器默认颜色（若 `activeStyle` 中未指定 `color`）。

你可以通过 `activeStyle` prop 提供自定义样式来覆盖这些默认值。

### 自定义激活样式

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

在此示例中，激活时链接会显示为加粗且为绿色。

## 🚀 额外特性

### 用于自定义内容的插槽

你可以使用插槽在链接中传入自定义内容，使组件在不同场景下更具灵活性。

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### 无障碍增强

组件支持 `aria-label` 及其他无障碍属性，从而提供更加友好的无障碍体验。

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
