# API 参考

## 运行时 API

- [方法](/api/methods) — `$t`、`$ts`、`$_t`、`$_ts`、区域切换、路由辅助函数
- [事件](/api/events) — `i18n:register`、`i18n:beforeLocaleSwitch`、`i18n:afterLocaleSwitch`

## 服务端中间件

服务端 handler 使用专用的中间件（不是客户端的 `$t` 辅助函数）：

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — 在 API 路由和服务端 handler 中翻译
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — 读取检测到的区域和元数据

关于搭建、区域检测优先级和示例，请参见完整的[服务端翻译指南](/guides/server-side-translations)。
