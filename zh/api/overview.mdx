本节列出了 Nuxt 模块的每个选项、辅助函数、钩子、组合式函数和组件，以及每个 `@i18n-micro/*` 包导出的 API。可用它来查找签名或默认值；[指南](/zh/guide/getting-started)则讲解如何使用它们。这里的大多数表格都由源码生成，因此与代码保持一致。

## Nuxt 模块 {#nuxt-module}

| 页面 | 涵盖内容 |
| --- | --- |
| [模块选项](/zh/api/module-options) | `nuxt.config` 中的每个 `i18n` 键，包括类型和默认值 |
| [辅助函数](/zh/api/methods) | `$t`、`$tc`、`$tn`、`$td`、`$localePath`、`$switchLocale`、`$defineI18nRoute` 等 |
| [钩子](/zh/api/events) | `i18n:register` 运行时钩子 |

## 组合式函数 {#composables}

| 组合式函数 | 用途 |
| --- | --- |
| [`useI18n`](/zh/composables/useI18n) | 在 `<script setup>` 中使用辅助函数 |
| [`useI18nLocale`](/zh/composables/useI18nLocale) | 在自定义检测插件中使用 locale 状态和 cookie |
| [`useI18nHead`](/zh/composables/useI18nHead) | 按页面覆盖生成的 SEO 标签 |
| [`useLocaleHead`](/zh/composables/useLocaleHead) | 以对象形式获取 SEO 标签，供你自己的 `useHead` 使用 |

## 组件 {#components}

| 组件 | 渲染内容 |
| --- | --- |
| [`<i18n-t>`](/zh/components/i18n-t) | 一条翻译，支持复数、格式化和插槽插值 |
| [`<i18n-link>`](/zh/components/i18n-link) | 指向本地化路由的 `NuxtLink` |
| [`<i18n-switcher>`](/zh/components/i18n-switcher) | 一个 locale 下拉菜单 |
| [`<i18n-group>`](/zh/components/i18n-group) | 一个共享键前缀的区块 |

## 服务端 {#server}

Nitro 处理器使用 `useTranslationServerMiddleware` 和 `useLocaleServerMiddleware`，而不是客户端辅助函数。参见[服务端路由](/zh/guide/server-side-translations)。

## 包 {#packages}

[包 API](/zh/api/packages/overview) 列出了每个 `@i18n-micro/*` 包的导出内容，每个包一个生成的页面。
