## Prerequisites

- Node.js 18 or newer.
- An existing Nuxt 3 or Nuxt 4 project.

## Install the module

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

## Configure `nuxt.config.ts`

Add the module and declare the locales you want to support:

```typescript nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

Run `nuxt dev`. The module creates any missing translation files inside `translationDir` (default `locales/`) the first time you visit each page.

## Add root-level translations

Root-level files apply to every page. Create `locales/en.json`:

```json locales/en.json
{
  "menu": {
    "home": "Home",
    "about": "About"
  }
}
```

Add the same keys for other locales (`locales/fr.json`, `locales/ar.json`, and so on).

## Add page-specific translations

Page-specific files live under `locales/pages/<route>/<locale>.json` and mirror your Nuxt routes. Brackets in dynamic routes become dashes (`pages/articles/[id].vue` → `locales/pages/articles-id/`).

```json locales/pages/index/en.json
{
  "welcome": "Welcome to My App",
  "description": "A fast Nuxt application with i18n support."
}
```

## Use translations in a component

```vue pages/index.vue
<template>
  <div>
    <h1>{{ $t('welcome') }}</h1>
    <p>{{ $t('description') }}</p>

    <nav>
      <button v-for="locale in $getLocales()" :key="locale.code" @click="$switchLocale(locale.code)">
        {{ locale.code }}
      </button>
    </nav>
  </div>
</template>

<script setup>
const { $t, $getLocales, $switchLocale } = useI18n()
</script>
```

<Tip>
  `$t` returns the raw JSON value at the key — that can be a string, number, or an object. For a guaranteed string in templates, use `$ts` or point at a scalar key.
</Tip>

## Add locale-aware navigation

Wrap `NuxtLink` with the built-in `<i18n-link>` to keep the current locale when navigating:

```vue
<template>
  <nav>
    <i18n-link :to="{ name: 'index' }">{{ $t('menu.home') }}</i18n-link>
    <i18n-link :to="{ name: 'about' }">{{ $t('menu.about') }}</i18n-link>
    <i18n-switcher />
  </nav>
</template>
```
