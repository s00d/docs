---

`@i18n-micro/runtime` to niezależna od frameworka instancja i18n: słowniki, `t()`, liczba mnoga, formatowanie `Intl` i subskrypcja zmian, bez `fs` i bez frameworka. Używaj jej w czystym TypeScript, web workerze, funkcji edge lub jako podstawy własnego bindingu. Pakiety React, Preact, Node i Astro rozszerzają tę samą klasę.

## Instalacja {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/runtime
```

```bash npm
npm install @i18n-micro/runtime
```

```bash yarn
yarn add @i18n-micro/runtime
```

</CodeGroup>

Brak zależności peer. Do plików tłumaczeń na dysku użyj [`@i18n-micro/node`](/pl/integrations/nodejs-package).

## Konfiguracja {#setup}

```ts
import { createI18n } from '@i18n-micro/runtime'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    en: { greeting: 'Hello, {name}!', apples: 'no apples | one apple | {count} apples' },
    de: { greeting: 'Hallo, {name}!' },
  },
  routeMessages: {
    about: { en: { title: 'About us' } },
  },
})
```

Wszystkie opcje (`plural`, `missingWarn`, `missingHandler`, `numberFormats`, `datetimeFormats`) są wymienione w sekcji [Instancja](/pl/integrations/overview#the-instance).

## Tłumaczenie {#translate}

```ts
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.tc('apples', 5) // '5 apples'
i18n.tn(1234.5) // '1,234.5'

i18n.setRoute('about')
i18n.t('title') // 'About us' (route dictionary)
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!' (root, still visible)
```

Kolejne słowniki możesz załadować później:

```ts
i18n.loadMessages({ fr: { greeting: 'Bonjour, {name} !' } }, { about: { fr: { title: 'À propos' } } })
i18n.addTranslations('fr', { nav: { home: 'Accueil' } }) // deep merge; pass false to replace

await i18n.loadFromUrl('/locales/fr.json', { locale: 'fr' })
await i18n.loadFromUrl('/locales/pages/about/fr.json', { locale: 'fr', routeName: 'about' })
await i18n.loadFromUrls([
  { url: '/locales/en.json', locale: 'en' },
  { url: '/locales/de.json', locale: 'de' },
])
```

`loadFromUrl` używa `fetch` (przekaż `init`, aby ustawić nagłówki) i rzuca wyjątek przy odpowiedzi innej niż OK. `loadFromUrls` ładuje pliki jeden po drugim.

## Przełączanie locale {#switch-locale}

```ts
i18n.locale = 'de'
i18n.t('greeting', { name: 'Ada' }) // 'Hallo, Ada!'
```

Zmiany locale, trasy i słowników powiadamiają subskrybentów — w ten sposób bindingi frameworków ponownie renderują widok:

```ts
const stop = i18n.subscribe(() => {
  document.querySelector('#greeting')!.textContent = i18n.t('greeting', { name: 'Ada' }) as string
})
i18n.locale = 'fr'
stop()
```

`getSnapshot()` zwraca ciąg znaków, który zmienia się przy każdym powiadomieniu (dla store'ów w stylu `useSyncExternalStore`).

## Na żądanie {#per-request}

Instancja przechowuje jedno locale i jedną trasę. Na serwerze nie przełączaj współdzielonej instancji dla każdego żądania: dwa równoległe żądania widziałyby nawzajem swoje locale. `i18n.fork(locale)` daje żądaniu własną instancję: własne locale, locale zapasowe i trasę; te same słowniki, formatery i reguły. Koszt forka jest taki sam niezależnie od liczby słowników. Fork widzi zapisy do instancji nadrzędnej aż do swojego pierwszego własnego zapisu, a jego zapisy pozostają w nim. [Node.js](/pl/integrations/nodejs-package#per-request) dodaje `run`.

## API {#api}

| Składowa | Uwagi |
| --- | --- |
| `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has` | zobacz [Tłumaczenie i formatowanie](/pl/integrations/overview#translate-and-format) |
| `locale`, `fallbackLocale` | odczyt/zapis |
| `currentRoute`, `setRoute(name)`, `getRoute()` | aktywna trasa, domyślnie `'index'` |
| `loadMessages(messages?, routeMessages?)` | scala wiele locale i tras naraz |
| `addTranslations(locale, tree, merge = true)`, `addRouteTranslations(locale, route, tree, merge = true)` | |
| `loadFromUrl(url, { locale?, routeName?, init? })`, `loadFromUrls(entries)` | JSON przez `fetch` |
| `hasTranslation(key)` | aktywne locale, dowolna trasa (w przeciwieństwie do `has`, które sprawdza aktywną trasę i słownik główny) |
| `setTranslation(key, value)`, `resolveTranslations()` | zapis jednego klucza; odczyt scalonego drzewa |
| `clear()`, `clearCache()` | usuwa wszystkie słowniki |
| `subscribe(cb)`, `getSnapshot()` | powiadomienia o zmianach |
| `storage` | `{ translations: Map<'locale:route', Translations> }` |

Kod, który nie jest tagiem języka, dostaje reguły liczby mnogiej z `localeIso: { ua: 'uk-UA' }`; `localeIsoMap(locales)` buduje to z tych wpisów listy locale, które mają `iso`.

Eksporty modułu: `createI18n`, `I18n`, `fetchJsonTranslations`, `FormatService`, `interpolate`, `localeIsoMap` oraz typy `I18nOptions`, `LoadFromUrlOptions`, `LoadFromUrlEntry`, `TranslationStorage`, `Translations`, `Locale`, `PluralFunc`. Pełne sygnatury: [dokumentacja pakietu](/pl/api/packages/runtime).
