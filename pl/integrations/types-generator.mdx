title: "Generator typów"

---

`@i18n-micro/types-generator` odczytuje każdy plik JSON w folderze tłumaczeń i zapisuje deklarację zawierającą wszystkie klucze. Dodaj go, jeśli chcesz, aby edytor podpowiadał klucze w `t()`, `$t()` i `<I18nT keypath>`. Działa jako moduł Nuxt oraz jako plugin Vite lub Rollup i regeneruje typy, gdy plik się zmieni.

## Instalacja {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/types-generator
```

```bash npm
npm install -D @i18n-micro/types-generator
```

```bash yarn
yarn add -D @i18n-micro/types-generator
```

</CodeGroup>

Zależność peer: `@nuxt/kit` `^3.18.0 || ^4.0.0`. Importuje ją tylko wejście `/nuxt`; w projekcie wyłącznie z Vite ostrzeżenie o zależności peer można zignorować.

## Nuxt {#nuxt}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro', '@i18n-micro/types-generator/nuxt'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Moduł zapisuje `.nuxt/types/i18n-micro.d.ts`, a Nuxt dodaje go do kontekstu typów; nie trzeba niczego dołączać ręcznie. Odczytuje `i18nTypes.translationDir`, a w przeciwnym razie miejsca, z których `nuxt-i18n-micro` czyta tłumaczenia: `translationDir` (z `i18n` lub z opcji modułu podanych inline, domyślnie `'locales'`) w każdej warstwie oraz `additionalTranslationDirs`. Edycja pliku JSON w tym folderze regeneruje typy w `nuxi dev`. `i18nTypes.outputFile` jest ignorowane w Nuxt (informuje o tym ostrzeżenie).

## Vite {#vite}

`I18nTypesPlugin` to plugin Vite, który akceptuje także Rollup. W przypadku innego bundlera wywołaj `generateTypes` w skrypcie.

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { I18nTypesPlugin } from '@i18n-micro/types-generator'

export default defineConfig({
  plugins: [
    vue(),
    I18nTypesPlugin({
      srcDir: process.cwd(),
      translationDir: 'src/locales',
      outputFile: 'src/i18n-micro.d.ts',
    }),
  ],
})
```

| Opcja | Wymagana | Uwagi |
| --- | --- | --- |
| `srcDir` | tak | Katalog bazowy; `translationDir` jest rozwiązywany względem niego. |
| `translationDir` | tak | Folder z plikami JSON (łącznie z podfolderami, takimi jak `pages/`) lub tablica folderów. |
| `outputFile` | nie | Gdzie zapisać deklarację; domyślnie `<srcDir>/i18n-micro.d.ts`. |

Plugin generuje typy raz na początku budowania, a na serwerze deweloperskim regeneruje je 300 ms po zmianie w folderze. Upewnij się, że `include` w Twoim `tsconfig.json` obejmuje plik wyjściowy.

## Używanie kluczy {#use-the-keys}

Wygenerowany plik rozszerza `DefineLocaleMessage` w `@i18n-micro/types`, co zamienia `TranslationKey` w Twoje klucze:

```ts
declare module '@i18n-micro/types' {
  export interface DefineLocaleMessage {
    nav: object
    'nav.home': string
    'profile.title': string
  }
}
```

Klucze to te, na które odpowiada `t()`, także obiekty, ze wszystkich locale i wszystkich plików stron, z typem ich wartości JSON. `TranslationKey` to unia tych kluczy oraz dowolnego ciągu znaków, więc otrzymujesz autouzupełnianie, a nie błędy: klucz z literówką lub dynamiczny nadal się skompiluje. Parametry i wartości zwracane nie są typowane.

Dla kluczy dynamicznych pod znanym prefiksem `ScopedKey<'prefix'>` zawęża typ do pasujących kluczy:

```ts
import type { ScopedKey } from '@i18n-micro/types'

const statusText = (status: string) => t(`status.${status}` as ScopedKey<'status'>)
```

`TranslationKey` i `ScopedKey` pochodzą z `@i18n-micro/types` (React, Preact i Solid reeksportują `TranslationKey`; Vue nie).

## API {#api}

| Eksport | Wejście | Uwagi |
| --- | --- | --- |
| `I18nTypesPlugin(options)` | `@i18n-micro/types-generator` | Plugin Vite i Rollup |
| `generateTypes(options)` | `@i18n-micro/types-generator` | zapisuje plik, zwraca jego ścieżkę |
| `getTypesString(options)` | `@i18n-micro/types-generator` | zwraca deklarację bez zapisywania |
| `formatKeyProperty(key)` | `@i18n-micro/types-generator` | helper |
| Moduł Nuxt (`configKey: 'i18nTypes'`) | `@i18n-micro/types-generator/nuxt` | opcja `translationDir` |

Pełne sygnatury: [dokumentacja pakietu](/pl/api/packages/types-generator).
