# 📚 Przykłady i zastosowania Nuxt I18n Micro

Ta sekcja przedstawia różne przykłady demonstrujące, jak używać `Nuxt I18n Micro` w aplikacji Nuxt.js. Zobaczysz, jak przełączać lokalizacje, używać komponentów `<i18n-link>`, `<i18n-switcher>` i `<i18n-t>` oraz dynamicznie obsługiwać klucze tłumaczeń.

## 🛠️ Podstawowa konfiguracja

Oto podstawowa konfiguracja do rozpoczęcia pracy z `Nuxt I18n Micro`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Przełączanie lokalizacji

### Programowe przełączanie lokalizacji

Ten przykład pokazuje, jak przełączać lokalizacje programowo za pomocą przycisków:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Przykładowy JSON dla przełączania lokalizacji

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### Użycie komponentu `<i18n-switcher>`

Komponent `<i18n-switcher>` zapewnia listę rozwijaną do przełączania lokalizacji z możliwością dostosowania etykiet:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 🌐 Używanie `<i18n-link>` do nawigacji zlokalizowanej

Komponent `<i18n-link>` automatycznie obsługuje routing specyficzny dla lokalizacji:

```vue
<template>
  <div>
    <i18n-link to="/about">{{ $t('about') }}</i18n-link>
    <i18n-link :to="{ name: 'index' }">{{ $t('home') }}</i18n-link>
  </div>
</template>

<script setup>

</script>
```

### Przykładowy JSON dla linków nawigacyjnych

```json

  "about": "About Us",
  "home": "Home"
}
```

### Przykład ze stylizacją aktywnego linku

### Przykładowy JSON dla stylizacji aktywnego linku

W tym scenariuszu można użyć tego samego pliku JSON co w poprzednim przykładzie.

## 📝 Renderowanie kluczy dynamicznych z plików tłumaczeń

W pewnych scenariuszach możesz chcieć iterować po dynamicznych kluczach zapisanych w plikach tłumaczeń i renderować ich wartości warunkowo. Poniższy przykład pokazuje, jak to zrobić z użyciem `Nuxt I18n Micro`.

### Przykład: renderowanie kluczy dynamicznych

Ten przykład pobiera tablicę kluczy z określonej ścieżki tłumaczenia (w tym przypadku `dynamic`) i iteruje po nich. Istnienie każdego klucza jest sprawdzane przy użyciu `$has` przed wyrenderowaniem jego wartości za pomocą `$t`.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Przykładowy plik tłumaczeń (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Przykład: renderowanie kluczy dynamicznych z obiektu

W tym przykładzie obsługujemy obiekt zapisany w pliku tłumaczeń. Pobieramy i iterujemy po kluczach obiektu, dynamicznie renderując zarówno nazwy kluczy, jak i przypisane im wartości.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Przykładowy plik tłumaczeń (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 Używanie `<i18n-t>` do tłumaczeń ze slotami i interpolacją

Komponent `<i18n-t>` jest przydatny do renderowania tłumaczeń zawierających dynamiczną zawartość i znaczniki HTML:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### Przykładowy JSON dla `<i18n-t>`

```json
{
  "greeting": "Welcome to the page"
}
```

### Z interpolacją

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### Przykładowy JSON dla interpolacji

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 Używanie `$tc` do liczby mnogiej

Funkcja `$tc` w `Nuxt I18n Micro` obsługuje pluralizację w zależności od liczby i ustawień lokalizacji. Jest przydatna do dynamicznego dostosowywania wiadomości zawierających liczby, takich jak elementy, powiadomienia lub inne encje, których liczba może się zmieniać.

### Przykład: użycie `$tc` do pluralizacji

W poniższym przykładzie wyświetlamy wiadomość wskazującą liczbę jabłek za pomocą `$tc`. Klucz tłumaczenia obsługuje wiele form liczby mnogiej w zależności od podanej wartości.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### Przykładowy JSON dla pluralizacji

Oto jak można zdefiniować tłumaczenie w pliku JSON, aby obsłużyć różne formy liczby mnogiej:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Wyjaśnienie

- **`$tc('apples', 0)`**: zwraca pierwszą formę, używaną, gdy liczba wynosi zero (`"no apples"`).
- **`$tc('apples', 1)`**: zwraca drugą formę, używaną, gdy liczba wynosi jeden (`"one apple"`).
- **`$tc('apples', 10)`**: zwraca trzecią formę z wartością liczby, używaną, gdy liczba wynosi dwa lub więcej (`"10 apples"`).

### Dodatkowy przykład z bardziej złożoną pluralizacją

Jeśli Twoja aplikacja musi obsługiwać bardziej złożone reguły pluralizacji (np. specyficzne przypadki dla zero, jeden, dwa, kilka, wiele, inne), możesz odpowiednio rozszerzyć ciągi tłumaczeń:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: może zostać skonfigurowane tak, aby zwracało `"two apples"`.
- **`$tc('apples', 3)`**: może zwracać `"a few apples"`, w zależności od reguł zdefiniowanych dla liczby.

## 🌐 Używanie `$tn` do formatowania liczb

Funkcja `$tn` formatuje liczby zgodnie z bieżącą lokalizacją przy użyciu API `Intl.NumberFormat`. Jest przydatna do wyświetlania liczb w sposób dopasowany do ustawień regionalnych użytkownika, takich jak waluta, procenty lub inne formaty liczbowe.

### Przykład: użycie `$tn` do formatowania liczb

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ Używanie `$td` do formatowania daty i czasu

Funkcja `$td` formatuje daty i godziny zgodnie z bieżącą lokalizacją przy użyciu API `Intl.DateTimeFormat`. Jest przydatna do wyświetlania dat i godzin w formatach znanych użytkownikowi na podstawie jego ustawień lokalizacji.

### Przykład: użycie `$td` do formatowania daty i czasu

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ Używanie `$tdr` do formatowania dat względnych

Funkcja `$tdr` formatuje daty jako czasy względne (np. "5 minutes ago", "2 days ago") zgodnie z bieżącą lokalizacją przy użyciu API `Intl.RelativeTimeFormat`. Jest przydatna do wyświetlania różnic czasu względem bieżącej daty i godziny.

### Przykład: użycie `$tdr` do formatowania dat względnych

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
