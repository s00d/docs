# 📚 Przykłady i użycie Nuxt I18n Micro

Ta sekcja zawiera różne przykłady pokazujące, jak używać `Nuxt I18n Micro` w Twojej aplikacji Nuxt.js. Zobaczysz, jak przełączać locale, korzystać z komponentów `<i18n-link>`, `<i18n-switcher>` i `<i18n-t>` oraz dynamicznie obsługiwać klucze tłumaczeń.

## 🛠️ Podstawowa konfiguracja

Oto podstawowa konfiguracja, od której warto zacząć pracę z `Nuxt I18n Micro`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Przełączanie locale

### Programistyczne przełączanie locale

Ten przykład pokazuje, jak przełączać locale programistycznie za pomocą przycisków:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Przykładowy JSON dla przełączania locale

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### Używanie komponentu `<i18n-switcher>`

Komponent `<i18n-switcher>` udostępnia listę rozwijaną do przełączania locale z konfigurowalnymi etykietami:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 🌐 Używanie `<i18n-link>` do zlokalizowanej nawigacji

Komponent `<i18n-link>` automatycznie obsługuje routing zależny od locale:

```vue
<template>
  <div>
    <i18n-link to="/about">{{ $t('about') }}</i18n-link>
    <i18n-link :to="{ name: 'index' }">{{ $t('home') }}</i18n-link>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Przykładowy JSON dla linków nawigacyjnych

```json
{
  "about": "About Us",
  "home": "Home"
}
```

### Przykład ze stylizacją aktywnego linku

```vue
<template>

  </div>

```

W tym scenariuszu można użyć tego samego pliku JSON, co w poprzednim przykładzie.

## 📝 Renderowanie dynamicznych kluczy z plików tłumaczeń

W niektórych scenariuszach możesz chcieć iterować po dynamicznych kluczach przechowywanych w plikach tłumaczeń i warunkowo renderować ich wartości. Poniższy przykład pokazuje, jak to zrobić przy użyciu `Nuxt I18n Micro`.

### Przykład: renderowanie dynamicznych kluczy

Ten przykład pobiera tablicę kluczy z określonej ścieżki tłumaczeń (w tym przypadku `dynamic`) i iteruje po niej. Istnienie każdego klucza jest sprawdzane za pomocą `$has` przed wyrenderowaniem jego wartości za pomocą `$t`.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Przykładowy plik tłumaczeń (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Przykład: renderowanie dynamicznych kluczy z obiektu

W tym przykładzie obsługujemy obiekt przechowywany w pliku tłumaczeń. Pobieramy klucze obiektu i iterujemy po nich, dynamicznie renderując zarówno nazwy kluczy, jak i przypisane im wartości.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Przykładowy plik tłumaczeń (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 Używanie `<i18n-t>` dla tłumaczeń ze slotami i interpolacją

Komponent `<i18n-t>` jest przydatny do renderowania tłumaczeń z dynamiczną zawartością i znacznikami HTML:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### Przykładowy JSON dla `<i18n-t>`

```json
{
  "greeting": "Welcome to the page"
}
```

### Z interpolacją

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### Przykładowy JSON dla interpolacji

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 Używanie `$tc` dla liczby mnogiej

Funkcja `$tc` w `Nuxt I18n Micro` obsługuje liczbę mnogą na podstawie liczby i ustawień locale. Jest to przydatne do dynamicznego dostosowywania komunikatów zawierających liczebniki, takich jak liczba elementów, powiadomień lub innych rzeczy, które mogą różnić się liczebnością.

### Przykład: użycie `$tc` dla liczby mnogiej

W poniższym przykładzie wyświetlamy komunikat wskazujący liczbę jabłek za pomocą `$tc`. Klucz tłumaczenia obsługuje wiele form liczby mnogiej na podstawie podanej wartości.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### Przykładowy JSON dla liczby mnogiej

Oto jak można zdefiniować tłumaczenie w pliku JSON, aby obsłużyć różne formy liczby mnogiej:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Objaśnienie

- **`$tc('apples', 0)`**: Zwraca pierwszą formę, używaną, gdy liczba wynosi zero (`"no apples"`).
- **`$tc('apples', 1)`**: Zwraca drugą formę, używaną, gdy liczba wynosi jeden (`"one apple"`).
- **`$tc('apples', 10)`**: Zwraca trzecią formę z wartością liczby, używaną, gdy liczba wynosi dwa lub więcej (`"10 apples"`).

### Dodatkowy przykład ze złożoniejszą liczbą mnogą

Jeśli Twoja aplikacja musi obsługiwać bardziej złożone reguły liczby mnogiej (np. konkretne przypadki dla zero, one, two, few, many, other), możesz odpowiednio rozszerzyć ciągi tłumaczeń:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: Może zostać skonfigurowane tak, by zwracało `"two apples"`.
- **`$tc('apples', 3)`**: Może zwracać `"a few apples"`, w zależności od reguł zdefiniowanych dla danej liczby.

## 🌐 Używanie `$tn` do formatowania liczb

Funkcja `$tn` formatuje liczby zgodnie z bieżącym locale przy użyciu API `Intl.NumberFormat`. Jest to przydatne do wyświetlania liczb w sposób pasujący do regionalnych ustawień użytkownika, np. jako waluta, procenty lub inne formaty liczbowe.

### Przykład: użycie `$tn` do formatowania liczb

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ Używanie `$td` do formatowania daty i czasu

Funkcja `$td` formatuje daty i czas zgodnie z bieżącym locale przy użyciu API `Intl.DateTimeFormat`. Jest to przydatne do wyświetlania dat i czasu w formatach znanych użytkownikowi na podstawie jego ustawień locale.

### Przykład: użycie `$td` do formatowania daty i czasu

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ Używanie `$tdr` do formatowania dat względnych

Funkcja `$tdr` formatuje daty jako czasy względne (np. „5 minut temu”, „2 dni temu”) zgodnie z bieżącym locale przy użyciu API `Intl.RelativeTimeFormat`. Jest to przydatne do wyświetlania różnic czasowych względem bieżącej daty i godziny.

### Przykład: użycie `$tdr` do formatowania dat względnych

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
