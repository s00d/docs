## Wspólne flagi {#common-flags}

| Flaga | Domyślnie | Opis |
| --- | --- | --- |
| `--cwd` | bieżący katalog | Katalog projektu |
| `--logLevel` | `info` | Poziom wyjścia: silent, info |
| `--debug` | `false` | Wypisz ślad stosu, gdy polecenie się nie powiedzie |

## Inspekcja {#inspect}

### `info` {#info}

Wypisz rozwiązaną konfigurację i18n projektu

| Flaga | Domyślnie | Opis |
| --- | --- | --- |
| `--json` | `false` | Wypisz JSON zamiast tekstu |

### `check` {#check}

Bramka CI: niepowodzenie przy brakujących, pustych, nadmiarowych, niezdefiniowanych lub nieużywanych kluczach oraz uszkodzonych placeholderach

| Flaga | Domyślnie | Opis |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` z nuxt.config | Katalog tłumaczeń, względem projektu |
| `--only` | wszystkie oprócz duplicates | Lista sprawdzeń do uruchomienia, oddzielona przecinkami: missing, empty, extra, placeholders, undefined, unused, duplicates. Wskazane tu `unused` kończy się niepowodzeniem, gdy nie może zostać uruchomione |
| `--duplicates` | `false` | Zgłaszaj także ten sam tekst pod różnymi kluczami |
| `--ignore` | — | Oddzielone przecinkami wzorce glob plików źródłowych do pominięcia, względem projektu |
| `--json` | `false` | Wypisz JSON zamiast tekstu |

```bash
i18n-micro check
i18n-micro check --only missing,placeholders --json
```

### `stats` {#stats}

Pokaż stopień ukończenia tłumaczeń dla każdego locale

| Flaga | Domyślnie | Opis |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` z nuxt.config | Katalog tłumaczeń, względem projektu |
| `--html` | — | Zapisz dodatkowo raport HTML do tego pliku |
| `--json` | `false` | Wypisz JSON zamiast tekstu |
| `--baseRef` | — | Referencja Git, z którą porównać stopień ukończenia, np. HEAD~1 lub main |

```bash
i18n-micro stats --baseRef main
i18n-micro stats --html reports/i18n.html
```

### `lint` {#lint}

Sprawdź tekst tłumaczeń; kończy się niepowodzeniem, gdy pozostają problemy

| Flaga | Domyślnie | Opis |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` z nuxt.config | Katalog tłumaczeń, względem projektu |
| `--rules` | wszystkie lub `enabledRules` z .i18n-lintrc.json | Reguły do uruchomienia, oddzielone przecinkami: no-trailing-spaces, no-multiple-spaces, no-empty-translation lub własna |
| `--fix` | `false` | Napraw to, co da się naprawić: spacje oraz własne reguły z zamiennikiem |
| `--json` | `false` | Wypisz JSON zamiast tekstu |

```bash
i18n-micro lint --rules no-trailing-spaces --fix
```

### `search` {#search}

Przeszukaj klucze i wartości oraz pokaż, gdzie każdy klucz jest używany

| Flaga | Domyślnie | Opis |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` z nuxt.config | Katalog tłumaczeń, względem projektu |
| `<query>` | — | Tekst lub klucz do wyszukania |
| `--caseSensitive` | `false` | Uwzględniaj wielkość liter |
| `--onlyUnused` | `false` | Tylko klucze, które usunąłby `clean`; zapytanie staje się opcjonalne |
| `--scope` | `all` | Gdzie szukać: global, pages, all |
| `--limit` | — | Zwróć co najwyżej tyle kluczy |
| `--ignore` | — | Oddzielone przecinkami wzorce glob plików źródłowych do pominięcia, względem projektu |
| `--json` | `false` | Wypisz JSON zamiast tekstu |

```bash
i18n-micro search "Welcome"
i18n-micro search --onlyUnused
```

## Przepływ pracy z tłumaczeniami {#translation-workflow}

### `extract` {#extract}

Wypisz klucze używane w plikach źródłowych, które nie mają jeszcze tekstu, i dodaj te z tekstem domyślnym do domyślnego locale

| Flaga | Domyślnie | Opis |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` z nuxt.config | Katalog tłumaczeń, względem projektu |
| `--ignore` | — | Oddzielone przecinkami wzorce glob plików źródłowych do pominięcia, względem projektu |

```bash
i18n-micro extract
```

### `translate` {#translate}

Uzupełnij brakujące tłumaczenia z domyślnego locale za pomocą usługi tłumaczeniowej

| Flaga | Domyślnie | Opis |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` z nuxt.config | Katalog tłumaczeń, względem projektu |
| `--service` | — | Usługa tłumaczeniowa: ai, azure, deepl, google, libretranslate, yandexcloud |
| `--token` | — | Klucz API. Preferuj zmienną środowiskową I18N_TRANSLATE_TOKEN: flagi trafiają do historii powłoki |
| `--options` | — | Opcje usługi jako pary klucz:wartość, oddzielone przecinkami |
| `--locale` | każde locale oprócz domyślnego | Locale do uzupełnienia, oddzielone przecinkami |
| `--replace` | `false` | Przetłumacz ponownie każdy klucz, zastępując istniejące wartości |
| `--dryRun` | `false` | Policz klucze i znaki dla każdego locale; nic nie wysyłaj |
| `--chunkSize` | — | Liczba ciągów na żądanie; ograniczona do tego, co akceptuje usługa |
| `--pluralSeparator` | `\|` | Separator form liczby mnogiej w komunikatach |
| `--glossaryFile` | `.i18n-glossary.json`, gdy istnieje | Plik glosariusza, używany przez usługę `ai` |

```bash
i18n-micro translate --dryRun
I18N_TRANSLATE_TOKEN=... i18n-micro translate --service deepl --locale de,fr
i18n-micro translate --service ai --options provider:openai,model:gpt-4o-mini
i18n-micro translate --service libretranslate --options baseUrl:https://translate.example.com
```

### `sync` {#sync}

Usuń klucze, których nie ma domyślne locale; zatrzymuje się, gdy nie można udowodnić, że jest to bezpieczne. Brakujące klucze pozostają brakujące

| Flaga | Domyślnie | Opis |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` z nuxt.config | Katalog tłumaczeń, względem projektu |
| `--ignore` | — | Oddzielone przecinkami wzorce glob plików źródłowych do pominięcia, względem projektu |
| `--dryRun` | `false` | Wypisz, co zostałoby usunięte; nic nie zapisuj |
| `--force` | `false` | Usuń klucze, mimo że nie można udowodnić, że jest to bezpieczne |

```bash
i18n-micro sync --dryRun
```

### `clean` {#clean}

Usuń klucze, których nic w projekcie nie używa; zatrzymuje się, gdy nie można tego udowodnić

| Flaga | Domyślnie | Opis |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` z nuxt.config | Katalog tłumaczeń, względem projektu |
| `--include` | — | Wyrażenie regularne: rozważaj do usunięcia tylko pasujące klucze |
| `--exclude` | — | Wyrażenie regularne: nigdy nie usuwaj pasujących kluczy |
| `--ignore` | — | Oddzielone przecinkami wzorce glob plików źródłowych do pominięcia, względem projektu |
| `--dryRun` | `false` | Wypisz, co zostałoby usunięte; nic nie zapisuj |
| `--force` | `false` | Usuń klucze, mimo że nie można udowodnić użycia dla wszystkich z nich |

```bash
i18n-micro clean --dryRun
i18n-micro clean --exclude '^errors\.'
```

## Refaktoryzacja {#refactoring}

### `text-to-i18n` {#text-to-i18n}

Zastąp zakodowany na sztywno tekst w szablonach Vue wywołaniami tłumaczeń i zgłoś zakodowany na sztywno tekst w kodzie

| Flaga | Domyślnie | Opis |
| --- | --- | --- |
| `--translationFile` | `<translationDir>/<defaultLocale>.json` | Plik, do którego trafiają nowe klucze |
| `--path` | cały projekt | Plik lub katalog do przetworzenia |
| `--context` | — | Prefiks dla generowanych kluczy |
| `--ignore` | — | Oddzielone przecinkami wzorce glob plików źródłowych do pominięcia, względem projektu |
| `--dryRun` | `false` | Pokaż, co by się zmieniło; nic nie zapisuj |
| `--interactive` | `false` | Potwierdzaj lub edytuj każdy wygenerowany klucz |

```bash
i18n-micro text-to-i18n --dryRun

```

| Flaga | Domyślnie | Opis |
| --- | --- | --- |

| `--from` **\*** | — | Obecny klucz lub przestrzeń nazw |
| `--to` **\*** | — | Nowy klucz lub przestrzeń nazw |

### `format` {#format}

Przepisz pliki locale z posortowanymi kluczami i jednolitym wcięciem

| Flaga | Domyślnie | Opis |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` z nuxt.config | Katalog tłumaczeń, względem projektu |

## Wymiana {#exchange}

### `export` {#export}

Eksportuj pliki locale do PO lub CSV, z tekstem domyślnego locale jako źródłem

| Flaga | Domyślnie | Opis |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` z nuxt.config | Katalog tłumaczeń, względem projektu |
| `--format` | `po` | Format pliku: po, csv |
| `--dir` | `pots` dla po, `csv_exports` dla csv | Katalog wyjściowy, względem projektu |
| `--force` | `false` | Nadpisz pliki zmienione od ostatniego eksportu i nigdy nie zaimportowane |

```bash
i18n-micro export --format csv
```

### `import` {#import}

Scal pliki PO lub CSV z plikami locale

| Flaga | Domyślnie | Opis |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` z nuxt.config | Katalog tłumaczeń, względem projektu |
| `--format` | `po` | Format pliku: po, csv |
| `--dir` | `pots` dla po, `csv_exports` dla csv | Katalog wejściowy, względem projektu |
| `--dryRun` | `false` | Zgłoś, co zostałoby zaimportowane; nic nie zapisuj |

```bash
i18n-micro import --format csv --dryRun
```

### `sync-remote` {#sync-remote}

Pobierz globalne tłumaczenia z endpointu HTTP z .i18n-remote.json lub wyślij je do niego

| Flaga | Domyślnie | Opis |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` z nuxt.config | Katalog tłumaczeń, względem projektu |
| `--pull` | `true` | Pobierz ze zdalnego źródła |
| `--push` | `false` | Wyślij do zdalnego źródła |
| `--force` | `false` | Przy pobieraniu przyjmij wartość zdalną; przy wysyłaniu nadpisz tekst, który ma tylko zdalne źródło |
| `--dryRun` | `false` | Zgłoś, co zmieniłoby pobranie; nic nie zapisuj ani nie wysyłaj |

```bash
i18n-micro sync-remote --dryRun
i18n-micro sync-remote --no-pull --push
```

## Reguły lint {#lint-rules}

| Reguła | Wykrywa | Naprawiane przez `--fix` |
| --- | --- | --- |
| `no-trailing-spaces` | Spacje na końcu wartości lub wiersza | tak |
| `no-multiple-spaces` | Dwie lub więcej spacji z rzędu | tak |
| `no-empty-translation` | Pusta lub zawierająca same białe znaki wartość | nie |

## Kody wyjścia {#exit-codes}

| Kod | Znaczenie |
| --- | --- |
| `0` | Gotowe, nic do zgłoszenia |
| `1` | Znaleziska: `check`, `lint` lub `format --check` coś znalazły, `clean` lub `sync` nie mogły udowodnić, że usunięcie jest bezpieczne, `export` nadpisałby niezaimportowaną pracę, `translate` pominął klucze, `import` lub `sync-remote` napotkał konflikt, wysyłanie `sync-remote` usunęłoby zdalny tekst. `--dryRun` dla `clean`, `sync` lub pobierania `sync-remote` zgłasza te sytuacje i kończy się kodem `0` |
| `2` | Błąd: nieprawidłowe użycie, nieczytelny projekt, błąd sieci lub pliku |

## Pliki konfiguracyjne {#configuration-files}

| Plik | Używany przez |
| --- | --- |
| `.i18n-lintrc.json` | `lint`: `enabledRules`, `disabledRules`, `customRegexRules` (`name`, `pattern`, `flags`, `description`, `replacement`) |
| `.i18n-remote.json` | `sync-remote`: `url`, `path`, `token`, `auth` (`username`, `password`). `type` można pominąć; istnieje tylko `custom` |
| `.i18n-glossary.json` | `translate --service ai`: `entries` z `source`, `target` oraz opcjonalnymi `from`, `to` |

## Zmienne środowiskowe {#environment-variables}

| Nazwa | Zastosowanie |
| --- | --- |
| `I18N_TRANSLATE_TOKEN` | Klucz API dla `translate`. Odczytywany także z `.env` |
| `I18N_REMOTE_TOKEN` | Token Bearer dla `sync-remote`. Odczytywany także z `.env` |
| `AI_GATEWAY_API_KEY, OPENAI_API_KEY, ANTHROPIC_API_KEY` | Klucz usługi `ai`, gdy `I18N_TRANSLATE_TOKEN` nie jest ustawiony |
| `DEFAULT_LOCALE` | Nadpisuje `defaultLocale`, tak jak w module |
