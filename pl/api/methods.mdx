# 🛠️ Metody

Ta strona dokumentuje wszystkie dostępne metody dostarczane przez nuxt-i18n-micro. Metody są uporządkowane według funkcjonalności, aby ułatwić nawigację.

## 🔍 Metody tłumaczeń

Podstawowe metody do pobierania i zarządzania tłumaczeniami.

### `$t`

{/* generated:method:$t — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Przetłumacz klucz, interpolując `params` do niego. Zwraca `defaultValue`, gdy klucz jest niedostępny, lub sam klucz, gdy nie podano wartości domyślnej.

{/* /generated:method:$t */}

```typescript
const welcomeMessage = $t('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

<Warning>
`$t` zwraca `CleanTranslation`, czyli `string | number | boolean | Translations | PluralTranslations | null`. Jeśli klucz wskazuje na **zagnieżdżony obiekt** w Twoim JSON (np. `$t('header')`, gdy JSON zawiera `\{ "header": \{ "title": "Hi" \} \}`), wartością zwracaną będzie ten **obiekt**, a nie ciąg. Użycie go bezpośrednio w szablonie Vue (<code v-pre>\{\{ $t('header') \}\}</code>) wyrenderuje się jako `[object Object]`.

**Jak tego uniknąć:**

- Użyj bardziej szczegółowego klucza: `$t('header.title')` → `"Hi"`
- Użyj `$ts()`, które zawsze zwraca ciąg (wywołuje `.toString()` na wartościach nie-string)
- Używaj `$t` z zagnieżdżonym kluczem świadomie do dostępu do subobiektów w celach programistycznych
</Warning>

### `$ts`

{/* generated:method:$ts — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string) => string
```

Jak `$t`, ale zawsze zwraca ciąg: wartość obiektu lub tablicy jest stringifikowana, a nie zwracana bez zmian.

{/* /generated:method:$ts */}

```typescript
const welcomeMessage = $ts('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

### `$_t` i `$_ts`

{/* generated:method:$_t — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Powiąż `$t` z konkretną trasą, aby tłumaczyć poza bieżącą stroną — na przykład layout renderujący link do innej trasy.

{/* /generated:method:$_t */}

{/* generated:method:$_ts — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => string
```

Powiąż `$ts` z konkretną trasą. Zobacz `$_t`.

{/* /generated:method:$_ts */}

Warianty `$t` i `$ts` powiązane z trasą. Przyjmują najpierw **trasę** i zwracają funkcję tłumaczącą zablokowaną do lokalizacji i kontekstu strony tej trasy.

- **Dostęp**: `useNuxtApp()` (również re-eksportowane przez `useI18n()` jako `$_t` / `$_ts`)

Używaj ich, gdy aktywna trasa podczas SSR lub przejść różni się od `router.currentRoute` — na przykład wewnątrz `<i18n-t>`, `<i18n-group>` lub przy renderowaniu treści dla konkretnego obiektu `route`.

```typescript
import { useRoute, useNuxtApp } from '#imports'

const route = useRoute()
const { $_t, $_ts } = useNuxtApp()

const $t = $_t(route)
const title = $t('page.title')

// String-safe variant
const label = $_ts(route)('page.label')
```


### `$tc`

{/* generated:method:$tc — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params: number | Params, defaultValue?: string) => string
```

Tłumaczenie z pluralizacją. `params` mogą być samą liczbą lub obiektem zawierającym `count`.

{/* /generated:method:$tc */}

**Format tłumaczenia**: formy oddzielone przez `|`. Umieść placeholdery w **każdej** formie:

```json
{
  "apples": "no apples | one apple | {count} apples",
  "cart": "no items for {name} | one item for {name} | {count} items for {name}"
}
```

```typescript
$tc('apples', 0) // "no apples"
$tc('apples', 1) // "one apple"
$tc('apples', 10) // "10 apples"

// count + other params (second argument must be an object)
$tc('cart', { count: 10, name: 'Alice' }) // "10 items for Alice"
```


**Alternatywa komponentowa** — `<i18n-t keypath="cart" :plural="count" :params="\{ name \}" />` (scala `count` z `params` wewnętrznie).


### `$mergeTranslations`

{/* generated:method:$mergeTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
(newTranslations: Translations) => void
```

Scal tłumaczenia z aktywną lokalizacją w runtime, nadpisując to, co jest załadowane.

{/* /generated:method:$mergeTranslations */}

```typescript
$mergeTranslations({
  welcome: 'Bienvenue, {username}!',
})
// Output: Updates the translation cache with the new French translation
```

### `$resolveTranslations`

{/* generated:method:$resolveTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
() => Translations
```

Każde tłumaczenie aktualnie w pamięci dla aktywnej lokalizacji i trasy, w formie drzewa.
Widok tylko do odczytu tego, co `$t()` może teraz rozwiązać.

{/* /generated:method:$resolveTranslations */}

```typescript
const tree = $resolveTranslations()
// { aaa: { bbb: 'ccc' }, ddd: 1111 } — the same dictionary $t() reads from
```

Użyj tego, gdy potrzebujesz pełnego słownika w pamięci (DevTools, testy, edytory runtime). Traktuj wartość zwracaną jako tylko do odczytu; zmieniaj wartości przez `$setTranslation` lub scalaj łatki przez `$mergeTranslations`.

### `$setTranslation`

{/* generated:method:$setTranslation — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, value: unknown) => void
```

Zastąp wartość pod `key` w aktywnym słowniku. To jest zastąpienie, a nie scalenie —
użyj `$mergeTranslations`, gdy istniejące rodzeństwo powinno przetrwać.

{/* /generated:method:$setTranslation */}

```typescript
$setTranslation('aaa', { fff: 'ggg' }) // replaces the whole `aaa` subtree
$setTranslation('aaa', 'text')          // replaces `aaa` with a string
$setTranslation('ddd', 1111)            // scalar at the top level
$setTranslation('aaa.bbb', 'nested')    // dotted path
```

To jest **zastąpienie**, a nie scalenie. Istniejące rodzeństwo pod tym samym kluczem jest usuwane. Aby dokleić bez utraty rodzeństwa, użyj `$mergeTranslations`.

### `$setMissingHandler`

{/* generated:method:$setMissingHandler — do not edit; run `pnpm run docs:generate` */}

```ts
(handler: MissingHandler | null) => void
```

Zainstaluj callback wywoływany dla każdego nierozwiązanego klucza. Przekaż `null`, aby go usunąć.

{/* /generated:method:$setMissingHandler */}

**Definicja typu**:

```typescript
type MissingHandler = (locale: string, key: string, routeName: string, instance?: unknown, type?: string) => void
```

```typescript
// Set a custom handler
$setMissingHandler((locale, key, routeName) => {
  console.error(`Missing translation: ${key} in ${locale} for route ${routeName}`)
  // Send to Sentry or other error tracking service
  // Sentry.captureMessage(`Missing translation: ${key}`)
})

// Remove the handler
$setMissingHandler(null)
```

**Przypadki użycia**:

- Logowanie brakujących tłumaczeń do usług śledzenia błędów (Sentry, LogRocket itp.)
- Zbieranie statystyk brakujących tłumaczeń
- Niestandardowa obsługa błędów dla brakujących kluczy tłumaczeń

## 🔢 Formatowanie liczb i dat

Metody do formatowania liczb i dat zgodnie z konwencjami lokalizacji.

### `$tn`

{/* generated:method:$tn — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Sformatuj liczbę za pomocą `Intl.NumberFormat` w aktywnej lokalizacji. Klucz wybiera nazwany format z konfiguracji.

{/* /generated:method:$tn */}

```typescript
// Inline options
const formattedNumber = $tn(1234567.89, { style: 'currency', currency: 'USD' })
// "$1,234,567.89"

// Named format (from nuxt.config i18n.numberFormats)
const price = $tn(1000, 'currency')
const priceDe = $tn(1000, 'currency', 'de')
const compact = $tn(1000, 'currency', { notation: 'compact' })
```

Nieznane klucze nazwanych formatów wracają do domyślnych opcji `Intl.NumberFormat`. W trybie deweloperskim (klient) emitowany jest `console.warn`, gdy `missingWarn` jest włączone (domyślnie).

**Przykład konfiguracji**:

```ts
export default defineNuxtConfig({
  i18n: {
    numberFormats: {
      en: {
        currency: { style: 'currency', currency: 'USD' },
        decimal: { style: 'decimal', minimumFractionDigits: 2, maximumFractionDigits: 2 },
      },
      de: {
        currency: { style: 'currency', currency: 'EUR' },
      },
    },
  },
})
```

**Przypadki użycia**:

- Formatowanie liczb jako waluty, procentów lub liczb dziesiętnych w odpowiednim formacie lokalizacji
- Ponowne używanie nazwanych formatów w całej aplikacji (parytet migracji z Vue I18n)

### `$td`

{/* generated:method:$td — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Sformatuj datę za pomocą `Intl.DateTimeFormat` w aktywnej lokalizacji. Klucz wybiera nazwany format z konfiguracji.

{/* /generated:method:$td */}

```typescript
const formattedDate = $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' })
// "Friday, September 1, 2023"

const short = $td(new Date(), 'short')
const longDe = $td(new Date(), 'long', 'de')
```

Nieznane klucze nazwanych formatów wracają do domyślnych opcji `Intl.DateTimeFormat`. W trybie deweloperskim (klient) emitowany jest `console.warn`, gdy `missingWarn` jest włączone (domyślnie).

**Przykład konfiguracji**:

```ts
export default defineNuxtConfig({
  i18n: {
    datetimeFormats: {
      en: {
        short: { year: 'numeric', month: 'short', day: 'numeric' },
        long: { year: 'numeric', month: 'long', day: 'numeric', weekday: 'long' },
      },
    },
  },
})
```

**Przypadki użycia**:

- Wyświetlanie dat w formacie zgodnym z lokalizacją użytkownika
- Współdzielenie presetów krótki/długi/data-czas w całej aplikacji

### `$tdr`

{/* generated:method:$tdr — do not edit; run `pnpm run docs:generate` */}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

Sformatuj datę jako czas względny ("3 dni temu") za pomocą `Intl.RelativeTimeFormat`.

{/* /generated:method:$tdr */}

```typescript
const relativeDate = $tdr(new Date(Date.now() - 1000 * 60 * 5))
```

## 🔄 Przełączanie tras i lokalizacji

Metody do przełączania między lokalizacjami i trasami.

```ts
(locale: string) => void
```

Przejdź do bieżącej strony w innej lokalizacji.

{/* /generated:method:$switchLocale */}

```typescript
$switchLocale('fr')
// Prefix strategies: navigates to the French version of the route
```

</Tip>

### `$switchLocaleRoute`

{/* generated:method:$switchLocaleRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(locale: string) => RouteLocationRaw
```

Obiekt trasy dla bieżącej strony w innej lokalizacji, bez nawigacji.

{/* /generated:method:$switchLocaleRoute */}

```typescript
// on /en/news
const routeFr = $switchLocaleRoute('fr')
// Output: A route object with the new locale applied, e.g., { name: 'localized-news', params: { locale: 'fr' } }
```

### `$switchLocalePath`

{/* generated:method:$switchLocalePath — do not edit; run `pnpm run docs:generate` */}

```ts
(locale: string) => string
```

Ścieżka bieżącej strony w innej lokalizacji, bez nawigacji.

{/* /generated:method:$switchLocalePath */}

```typescript
// on /en/news
const routeFr = $switchLocalePath('fr')
window.location.href = routeFr
// Output: url with new locale applied, e.g., '/fr/nouvelles'
```

### `$switchRoute`

{/* generated:method:$switchRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, toLocale?: string) => void
```

Przejdź do innej trasy, zachowując aktywną lokalizację lub przełączając na `toLocale`.

{/* /generated:method:$switchRoute */}

**Przykłady**:

<CodeGroup>
```typescript String Path
// Switches to the given path with the current locale
$switchRoute('/about')
```

```typescript String Path with Locale
// Switches to the given path with French locale
$switchRoute('/about', 'fr')
```

```typescript Named Route
// Switches to a named route with the current locale
$switchRoute({ name: 'page' })
```

```typescript Named Route with Locale
// Switches to a named route and changes the locale to Spanish
$switchRoute({ name: 'page' }, 'es')
```
</CodeGroup>

## 🌐 Generowanie tras

Metody do generowania zlokalizowanych tras i ścieżek.

### `$localeRoute`

## 🚦 Konfiguracja tras

Metody do konfigurowania zachowania tras i kontroli dostępu.

### `$defineI18nRoute`

{/* generated:method:$defineI18nRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Zarejestruj konfigurację lokalizacji per strona oraz tłumaczenia z wnętrza komponentu.
Scala się z aktywną lokalizacją i ponownie stosuje, gdy zmienia się lokalizacja.

{/* /generated:method:$defineI18nRoute */}

> [!IMPORTANT]
> `$defineI18nRoute` jest dostarczane przez **plugin define** i jest dostępne tylko w `useNuxtApp()` — **nie** jest częścią obiektu zwracanego przez `useI18n()`.
> Zawsze destrukturyzuj je z `useNuxtApp()` wewnątrz `script setup`. Wywołanie `$defineI18nRoute(...)` jako gołego globala rzuca `"$defineI18nRoute is not defined"` podczas SSR/prerender.

**Parametry**:

- **locales**: `string[] | Record<string, Record<string, string>>` — Dostępne lokalizacje dla trasy
- **localeRoutes**: `Record<string, string>` — Opcjonalne. Niestandardowe trasy dla konkretnych lokalizacji
- **disableMeta**: `boolean | string[]` — Opcjonalne. Wyłącza tagi meta i18n dla wszystkich lub wybranych lokalizacji

**Podstawowy przykład**:

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr', 'de'],
  localeRoutes: {
    en: '/welcome',
    fr: '/bienvenue',
    de: '/willkommen',
  },
  disableMeta: false,
})
```

> 📖 **Szczegółowe przykłady użycia, formaty konfiguracji i najlepsze praktyki znajdziesz w [Przewodniku po tłumaczeniach per-komponent](/guides/per-component-translations).**

### `$setI18nRouteParams`

{/* generated:method:$setI18nRouteParams — do not edit; run `pnpm run docs:generate` */}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Ustaw parametry per lokalizacja dla bieżącej trasy, aby segment dynamiczny mógł różnić się w zależności od języka.
Wywołaj je podczas SSR, przed wyrenderowaniem head.

{/* /generated:method:$setI18nRouteParams */}

```typescript
// in pages/news/[id].vue
// for en/news/1-first-article
const { $switchLocaleRoute, $setI18nRouteParams, $defineI18nRoute } = useNuxtApp()
$defineI18nRoute({
  localeRoutes: {
    en: '/news/:id()',
    fr: '/nouvelles/:id()',
    de: '/Nachricht/:id()',
  },
})
const { data: news } = await useAsyncData(`news-${params.id}`, async () => {
  let response = await $fetch("/api/getNews", {
    query: {
      id: params.id,
    },
  });
  if (response?.localeSlugs) {
    response.localeSlugs = {
      en: {
        id: '1-first-article'
      }
      fr: {
        id: '1-premier-article'
      }
      de: {
        id: '1-erster-Artikel'
      }
    }
    $setI18nRouteParams(response?.localeSlugs);
  }
  return response;
});
$switchLocalePath('fr') // === 'fr/nouvelles/1-premier-article'
$switchLocalePath('de') // === 'de/Nachricht/1-erster-Artikel'
```

## 🧭 Composable `useI18nLocale`

Scentralizowany composable do zarządzania stanem lokalizacji. Używaj go zamiast bezpośredniego manipulowania `useState('i18n-locale')` czy `useCookie('user-locale')`.

```typescript
const {
  setLocale, // (locale: string) => void — updates state + cookie
  getLocale, // () => string | null — from state or cookie
  getPreferredLocale, // () => string | null — validated against locales list
  getEffectiveLocale, // (route, getLocaleFromRoute) => string
  resolveInitialLocale, // (options) => string
  isValidLocale, // (locale) => boolean
  locale, // Ref<string | null> — reactive state
  localeCookie, // CookieRef — reactive cookie
  syncLocale, // (locale) => void — sync to cookie only
  validLocales, // string[] — list of valid locale codes
} = useI18nLocale()
```

### Kluczowe metody

| Metoda                   | Opis                                                              |
| ------------------------ | ----------------------------------------------------------------- |
| `setLocale(locale)`      | Ustawia lokalizację jednocześnie w `useState` i w ciasteczku      |
| `getLocale()`            | Zwraca bieżącą lokalizację ze stanu lub ciasteczka                |
| `getPreferredLocale()`   | Zwraca lokalizację zwalidowaną względem listy `locales` lub `null` |
| `isValidLocale(locale)`  | Sprawdza, czy kod lokalizacji znajduje się na skonfigurowanej liście `locales` |

### Użycie w niestandardowych pluginach

```typescript
// plugins/i18n-loader.server.ts

  enforce: 'pre',
```
