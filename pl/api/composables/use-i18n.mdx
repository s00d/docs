# 🛠️ Kompozycja `useI18n`

Kompozycja `useI18n` w `Nuxt I18n Micro` zapewnia dostęp do większości helperów runtime i18n w komponentach i skryptach. Metody dostępne są **z prefiksem `$` i bez niego** (na przykład `$t` i `t`).

Niektóre wstrzyknięcia — `$defineI18nRoute` i `$clearCache` — są dostępne tylko na `useNuxtApp()`. Zobacz [Metody — `$defineI18nRoute`](/api/methods#definei18nroute) oraz [`$clearCache`](/api/methods#clearcache).

## 📊 Co zwraca

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Każdy helper runtime jako zwykły obiekt.

Te same funkcje, które wtyczka wstrzykuje jako `$t`, `$tc` itd., dostępne zarówno pod nazwą z prefiksem dolara, jak i pod gołym aliasem — więc `const \{ t \} = useI18n()` i
`const \{ $t \} = useI18n()` działają tak samo.

**Zwraca** — helpery opisane w [dokumentacji metod](/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

Każdy zwracany helper — `$t`, `$tc`, `$has`, `$switchLocale` i pozostałe — jest wymieniony wraz z sygnaturą i w pełni udokumentowany w [dokumentacji metod](/api/methods).

## API dostępne tylko przez `useNuxtApp()`

Te **nie** są zwracane przez `useI18n()`. Zaimportuj je z `useNuxtApp()`:

| Metoda                     | Przeznaczenie                                                                    |
| -------------------------- | -------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Trasy locale dla poszczególnych stron, ograniczenia i inline'owe tłumaczenia w `script setup` |
| `$clearCache()`            | Czyści pamięć podręczną tłumaczeń i załadowane chunki                            |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Zobacz [Metody](/api/methods), aby poznać pełne sygnatury i przykłady.

## 🛠️ Przykłady użycia

### Podstawowe pobranie locale

Pobierz bieżące locale aplikacji.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Tłumaczenie z parametrami

Przetłumacz string z dynamicznymi parametrami oraz zapasową wartością domyślną.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Przełączanie locale

Przełącz aplikację na inne locale.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Generowanie zlokalizowanej trasy

Wygeneruj trasę zlokalizowaną do bieżącego lub wskazanego locale.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
