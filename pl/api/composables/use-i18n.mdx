# 🛠️ Composable `useI18n`

Composable `useI18n` w `Nuxt I18n Micro` zapewnia dostęp do większości runtime'owych helperów i18n w komponentach i skryptach. Metody są dostępne **z i bez prefiksu `$`** (na przykład `$t` i `t`).

Niektóre injections — `$defineI18nRoute` i `$clearCache` — są dostępne tylko w `useNuxtApp()`. Zobacz [Metody — `$defineI18nRoute`](/api/methods#definei18nroute) oraz [`$clearCache`](/api/methods#clearcache).

## 📊 Co zwraca

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Każdy runtime'owy helper jako zwykły obiekt.

Te same funkcje, które plugin wstrzykuje jako `$t`, `$tc` itd., dostępne pod nazwą z prefiksem dolara oraz pod jej krótkim aliasem — więc zarówno `const \{ t \} = useI18n()`, jak i
`const \{ $t \} = useI18n()` działają.

**Zwraca** — helpery opisane w [dokumentacji metod](/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

Każdy helper, który zwraca — `$t`, `$tc`, `$has`, `$switchLocale` i pozostałe — jest wymieniony wraz z sygnaturą i w pełni udokumentowany w [Dokumentacji metod](/api/methods).

## API dostępne tylko przez `useNuxtApp()`

Te **nie** są zwracane przez `useI18n()`. Zaimportuj je z `useNuxtApp()`:

| Metoda                     | Zastosowanie                                                                        |
| -------------------------- | ------------------------------------------------------------------------------------ |
| `$defineI18nRoute(config)` | Trasy lokalizacji per strona, ograniczenia i inline'owe tłumaczenia w `script setup` |
| `$clearCache()`            | Czyści cache tłumaczeń w pamięci oraz załadowane chunki                              |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Zobacz [Metody](/api/methods), aby poznać pełne sygnatury i przykłady.

## 🛠️ Przykładowe użycia

### Podstawowe pobranie lokalizacji

Pobierz bieżącą lokalizację aplikacji.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Tłumaczenie z parametrami

Przetłumacz ciąg z dynamicznymi parametrami i wartością domyślną jako fallbackiem.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Przełączanie lokalizacji

Przełącz aplikację na inną lokalizację.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Generowanie zlokalizowanej trasy

Wygeneruj trasę zlokalizowaną do bieżącej lub określonej lokalizacji.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
