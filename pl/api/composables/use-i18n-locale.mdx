# useI18nLocale

Scentralizowany punkt wejścia do zarządzania locale i18n.
Łączy useState('i18n-locale'), ciasteczko locale oraz narzędzia synchronizacji.

## Użycie

```vue
<script setup>
const {
  locale,
  localeCookie,
  hashCookie,
  validLocales,
  getPreferredLocale,
  getLocale,
  getLocaleWithServerFallback,
  getEffectiveLocale,
  resolveInitialLocale,
  setLocale,
  syncLocale,
  isValidLocale,
} = useI18nLocale()

// Set locale (updates state and cookies)
setLocale('de')

// Get current locale (state → cookie)

// Get valid preferred locale
const preferred = getPreferredLocale()
</script>
```

## API

| Właściwość/Metoda                               | Typ                                 | Opis                                                                                 |
| ----------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| `locale`                                        | `Ref<string \| null>`               | Reaktywny stan locale (`useState('i18n-locale')`)                                    |
| `localeCookie`                                  | `Ref`                               | Ciasteczko locale (gdy opcja `localeCookie` jest włączona)                            |
| `hashCookie`                                    | `Ref`                               | Ciasteczko używane, gdy aktywne jest `hashMode`                                       |
| `validLocales`                                  | `string[]`                          | Włączone kody locale z konfiguracji modułu (wyklucza `disabled`)                      |
| `getLocale()`                                   | `() => string \| null`              | Bieżące locale: state → cookie (lub hash cookie w trybie hash)                        |
| `getPreferredLocale()`                          | `() => string \| null`              | Locale ze state/cookie **zwalidowane** względem `validLocales` lub `null`             |
| `getLocaleWithServerFallback(serverLocale?)`    | `(serverLocale?) => string \| null` | State → cookie → opcjonalny kontekst serwera (używane podczas inicjalizacji `no_prefix`) |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string`             | Locale do ładowania tłumaczeń: tryb hash preferuje state; w przeciwnym razie czyta z trasy |
| `resolveInitialLocale(options)`                 | `(options) => string`               | Rozstrzyga locale: state → `serverLocale` → route; synchronizuje state, gdy trzeba    |
| `setLocale(locale)`                             | `(locale: string \| null) => void`  | Ustawia locale i synchronizuje z ciasteczkami                                          |
| `syncLocale(locale)`                            | `(locale: string \| null) => void`  | Synchronizuje tylko ciasteczka (bez aktualizacji state)                                |
| `isValidLocale(locale)`                         | `(locale) => boolean`               | Sprawdza, czy string znajduje się w `validLocales`                                    |

### Opcje `resolveInitialLocale`

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

Używane wewnętrznie przez główną wtyczkę przy starcie. Niestandardowe wtyczki mogą to wywołać podczas implementacji alternatywnych ścieżek detekcji.

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

Zwraca locale używane do ładowania tłumaczeń i formatowania komunikatów dla podanego obiektu trasy.

## Programowe ustawianie locale

Preferuj `useI18nLocale()` zamiast bezpośredniego używania `useState('i18n-locale')`:

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
`setLocale()` aktualizuje tylko preferencję locale (state + cookie). Aby dodatkowo przeładować aktywny kontekst tłumaczeń na kliencie, użyj `$switchLocale()` z `useNuxtApp()` lub `useI18n()`. Ma to szczególne znaczenie dla `no_prefix`, gdzie URL się nie zmienia. Zobacz [FAQ — przełącz locale bez zmiany URL-a](/guides/faq#-switch-locale-without-changing-the-url).
</Tip>
