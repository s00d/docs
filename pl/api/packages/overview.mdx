Moduł Nuxt jest zbudowany z małych pakietów `@i18n-micro/*`, a większość z nich działa samodzielnie: `@i18n-micro/vue` w aplikacji Vue, `@i18n-micro/core` wszędzie. Korzystaj z tych stron, aby sprawdzić, co eksportuje pakiet, w podziale na punkty wejścia. Każda strona jest generowana z migawki, którą [`pnpm run api:surface`](https://s00d.github.io/nuxt-i18n-micro/contributing/maintenance-commands#api-surface) sprawdza względem źródeł TypeScript, więc eksport nie może się zmienić bez wiedzy CI.
