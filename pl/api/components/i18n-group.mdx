# 🌍 Komponent `<i18n-group>`

Komponent `<i18n-group>` w Nuxt I18n Micro zapewnia wygodny sposób grupowania tłumaczeń pod wspólnym prefiksem, ograniczając powtórzenia i poprawiając organizację kodu.

## ⚙️ Właściwości

{/* generated:component:i18n-group — do not edit; run `pnpm run docs:generate` */}

| Właściwość | Typ | Domyślnie | Opis |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | Prefiks klucza, względem którego rozwiązywane jest każde wyszukanie wewnątrz slotu. |
| `groupClass` | `string` | `''` | Dodatkowa klasa na elemencie opakowującym. |

**\*** wymagane.

### Sloty

| Slot | Powiązania | Opis |
| --- | --- | --- |
| `default` | `prefix`, `t` | Otrzymuje `prefix` oraz funkcję `t` ograniczoną do jego zakresu. |

{/* /generated:component:i18n-group */}

## 🎯 Sloty

Slot domyślny otrzymuje `prefix` oraz funkcję `t` ograniczoną do jego zakresu, więc klucze wewnątrz są
zapisywane względem prefiksu:

```vue
<i18n-group prefix="checkout">
  <template #default="{ t }">
    <h2>{{ t('title') }}</h2>
    <p>{{ t('summary', { count: 3 }) }}</p>
  </template>
</i18n-group>
```

## 🛠️ Przykładowe użycie

### Podstawowe użycie

```vue
<template>
  <i18n-group prefix="product.details">
    <template #default="{ t }">
      <h1>{{ t('title') }}</h1>
      <p>{{ t('description') }}</p>
      <div class="price">{{ t('price', { value: 99.99 }) }}</div>
    </template>
  </i18n-group>
</template>
```

Plik tłumaczeń:

```json
{
  "product": {
    "details": {
      "title": "Premium Product",
      "description": "This is a premium product",
      "price": "Price: ${value}"
    }
  }
}
```

### Z niestandardową klasą

```vue
<template>
  <i18n-group prefix="user.profile" group-class="profile-section">
    <template #default="{ t }">
      <div class="user-info">
        <h2>{{ t('title') }}</h2>
        <p>{{ t('bio') }}</p>
        <div class="stats">
          <span>{{ t('stats.followers') }}</span>
          <span>{{ t('stats.following') }}</span>
        </div>
      </div>
    </template>
  </i18n-group>
</template>
```

Plik tłumaczeń:

```json
{
  "user": {
    "profile": {
      "title": "User Profile",
      "bio": "User biography goes here",
      "stats": {
        "followers": "Followers: {count}",
        "following": "Following: {count}"
      }
    }
  }
}
```

### Z zawartością dynamiczną

```vue
<template>
  <i18n-group prefix="blog.post">
    <template #default="{ t }">
      <article>
        <h1>{{ t('title') }}</h1>
        <div class="meta">
          {{ t('meta.author', { name: author }) }} |
          {{ t('meta.date', { date: publishDate }) }}
        </div>
        <div v-for="(section, index) in sections" :key="index">
          <h2>{{ t(`sections.${index}.title`) }}</h2>
          <p>{{ t(`sections.${index}.content`) }}</p>
        </div>
      </article>
    </template>
  </i18n-group>
</template>

<script setup>
const author = 'John Doe'
const publishDate = '2024-01-01'
const sections = ['intro', 'main', 'conclusion']
</script>
```

## 🎨 Stylizacja

Komponent opakowuje swoją zawartość w element div z klasą `i18n-group` oraz dowolnymi dodatkowymi klasami określonymi we właściwości `groupClass`:

```css
.i18n-group {
  /* Your base styles */
}

.profile-section {
  /* Additional styles for profile sections */
}
```

## 🚀 Najlepsze praktyki

1. **Spójne prefiksy**: używaj spójnych i logicznych prefiksów, które odzwierciedlają strukturę Twojej aplikacji

```vue
<i18n-group prefix="features.pricing">
<i18n-group prefix="features.security">
```

2. **Modułowa organizacja**: grupuj powiązane tłumaczenia razem pod znaczącymi prefiksami

```vue
<i18n-group prefix="checkout.payment">
<i18n-group prefix="checkout.shipping">
```

3. **Komponenty wielokrotnego użytku**: twórz komponenty wielokrotnego użytku z własnymi grupami tłumaczeń

```vue
<!-- UserProfile.vue -->
<i18n-group prefix="user.profile">

<!-- UserSettings.vue -->
<i18n-group prefix="user.settings">
```

4. **Zagnieżdżone grupy**: unikaj zbyt głębokiego zagnieżdżania grup, aby zachować przejrzystość

```vue
<!-- Good -->
<i18n-group prefix="shop.product">

<!-- Avoid -->
<i18n-group prefix="shop.category.product.details.specs">
```
