# 🌍 Komponent `<i18n-switcher>`

Komponent `<i18n-switcher>` w `Nuxt I18n Micro` zapewnia przyjazny użytkownikowi interfejs listy rozwijanej do przełączania między różnymi lokalizacjami w Twojej aplikacji. Ten komponent jest wysoce konfigurowalny, co pozwala na płynną integrację z projektem i układem Twojej aplikacji.

Lokalizacje z `disabled: true` są **pomijane** w liście rozwijanej (pozostają dostępne przez `$getLocales()` dla SEO / tagów head). Tylko przełączalne lokalizacje otrzymują `NuxtLink` + `hreflang`.

## 🛠️ Przykładowe użycia

### Podstawowe użycie

```vue
<template>
  <i18n-switcher />
</template>
```

Renderuje przełącznik lokalizacji z domyślną stylizacją i zachowaniem.

### Niestandardowe etykiety i style inline

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Ten przykład pokazuje w pełni dostosowany przełącznik lokalizacji z niestandardowymi etykietami i stylami inline.

## 🔌 Sloty

Każdą część wizualną przełącznika można zastąpić. Sloty są wymienione wraz z tabelą właściwości powyżej; każdy przyjmuje zawartość szablonu:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Sloty, których nazwa kończy się na `-item`, `-link-content` lub zaczyna od `before-item`, otrzymują
obiekt `locale`, do którego należą.

## 🎨 Przegląd stylów

Komponent `<i18n-switcher>` ma podstawowe style zdefiniowane za pomocą stylów inline, które można łatwo nadpisać przekazując niestandardowe style przez właściwości. Oto krótki przegląd domyślnej stylizacji:

- **Wrapper**: kontroluje pozycjonowanie listy rozwijanej.
- **Button**: stylizuje przycisk przełączający listę.
- **Dropdown**: stylizuje listę rozwijaną.
- **Items**: stylizuje każdy element listy.
- **Links**: stylizuje linki wewnątrz każdego elementu.
- **Icon**: stylizuje ikonę wskaźnika rozwijania.

Możesz dostosować te style, przekazując niestandardowe style przez odpowiednie właściwości, dzięki czemu przełącznik lokalizacji będzie płynnie integrował się z interfejsem Twojej aplikacji.
