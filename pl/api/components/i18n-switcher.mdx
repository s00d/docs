# 🌍 Komponent `<i18n-switcher>`

Komponent `<i18n-switcher>` w `Nuxt I18n Micro` zapewnia przyjazny użytkownikowi interfejs listy rozwijanej do przełączania między różnymi locale w Twojej aplikacji. Jest wysoce konfigurowalny, co pozwala na płynną integrację z projektem i układem Twojej aplikacji.

Locale z `disabled: true` są **pomijane** w liście rozwijanej (pozostają dostępne przez `$getLocales()` dla SEO / tagów head). Tylko przełączalne locale otrzymują `NuxtLink` + `hreflang`.

## 🛠️ Przykłady użycia

### Podstawowe użycie

```vue
<template>
  <i18n-switcher />
</template>
```

Renderuje przełącznik locale z domyślną stylizacją i zachowaniem.

### Niestandardowe etykiety i inline styles

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Ten przykład pokazuje w pełni dostosowany przełącznik locale z niestandardowymi etykietami i inline styles.

## 🔌 Sloty

Każdą wizualną część przełącznika można zastąpić. Sloty wymienione są w tabeli właściwości powyżej; każdy przyjmuje zawartość szablonu:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Sloty, których nazwa kończy się na `-item`, `-link-content` lub zaczyna od `before-item`, otrzymują obiekt `locale`, do którego należą.

## 🎨 Przegląd stylów

Komponent `<i18n-switcher>` zawiera podstawowe style zdefiniowane jako inline styles, które można łatwo nadpisać, przekazując niestandardowe style przez właściwości. Oto krótki przegląd domyślnej stylizacji:

- **Wrapper**: Kontroluje pozycjonowanie dropdownu.
- **Button**: Stylizuje przycisk przełączania dropdownu.
- **Dropdown**: Stylizuje listę dropdownu.
- **Items**: Stylizuje każdy element listy.
- **Links**: Stylizuje linki wewnątrz każdego elementu.
- **Icon**: Stylizuje ikonę wskaźnika dropdownu.

Możesz dostosować te style, przekazując niestandardowe style przez odpowiednie właściwości, zapewniając płynną integrację przełącznika locale z UI Twojej aplikacji.
