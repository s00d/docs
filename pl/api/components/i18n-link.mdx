# 🌍 Komponent `<i18n-link>`

Komponent `<i18n-link>` w `Nuxt I18n Micro` to wszechstronny komponent link, który automatycznie lokalizuje trasy na podstawie bieżącego locale. Działa jako wrapper wokół komponentu `<NuxtLink>`, zapewniając dodatkowe funkcje, takie jak stylizacja aktywnego linku oraz obsługa linków zewnętrznych.

## ⚙️ Właściwości

{/* generated:component:i18n-link — do not edit; run `pnpm run docs:generate` */}

| Prop | Typ | Domyślnie | Opis |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | Trasa docelowa. Lokalizowana automatycznie; zewnętrzny URL jest przekazywany bez zmian. |
| `activeStyle` | `Partial<CSSStyleValue>` | — | Inline'owy styl stosowany, gdy link wskazuje bieżącą trasę. |

**\*** wymagany.

### Sloty

| Slot | Bindingi | Opis |
| --- | --- | --- |
| `default` | — | Zawartość linku. |

{/* /generated:component:i18n-link */}

`to` przyjmuje wszystko to, co `NuxtLink` — ścieżkę, nazwaną trasę lub rozwiązany obiekt trasy.
Absolutny URL jest wykrywany i renderowany jako zwykłe `<a target="_blank" rel="noopener noreferrer">`, zamiast być lokalizowany.

## 🛠️ Przykłady użycia

### Podstawowe użycie

```vue
<i18n-link to="/about">About Us</i18n-link>
```

Ten przykład tworzy link do strony `/about`, zlokalizowany do bieżącego locale.

### Stylizacja aktywnego linku z inline styles

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

Link będzie miał pogrubiony tekst, gdy użytkownik jest na stronie `/about`, co pozwala stylizować aktywny link bezpośrednio inline'owymi stylami.

### Obsługa linków zewnętrznych

Komponent automatycznie wykrywa linki zewnętrzne i dodaje niezbędne atrybuty bezpieczeństwa.

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

Ten link otworzy `https://example.com` w nowej karcie z zastosowanym `rel="noopener noreferrer"`.

## 🎨 Style

Komponent używa teraz inline styles dla stanu aktywnego zamiast klasy. Możesz je dostosować za pomocą właściwości `activeStyle`.

### Domyślne style aktywne

- **Grubość czcionki**: `bold`
- **Kolor**: Dziedziczy domyślny kolor przeglądarki (jeśli w `activeStyle` nie podano `color`).

Możesz je nadpisać, podając niestandardowe style przez właściwość `activeStyle`.

### Niestandardowe style aktywne

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

W tym przykładzie link będzie pogrubiony i zielony, gdy będzie aktywny.

## 🚀 Dodatkowe funkcje

### Slot dla niestandardowej zawartości

Możesz przekazać niestandardową zawartość wewnątrz linku za pomocą slotów, co czyni komponent elastycznym dla różnych zastosowań.

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### Ułatwienia dostępności

Komponent obsługuje `aria-label` oraz inne atrybuty dostępności, aby zapewnić bardziej dostępne doświadczenie.

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
