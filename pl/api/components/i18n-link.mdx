# 🌍 Komponent `<i18n-link>`

Komponent `<i18n-link>` w `Nuxt I18n Micro` to wszechstronny komponent linku, który automatycznie lokalizuje trasy w oparciu o bieżącą lokalizację. Działa jako opakowanie na komponencie `<NuxtLink>`, dostarczając dodatkowych funkcji, takich jak stylizacja aktywnego linku i obsługa linków zewnętrznych.

## ⚙️ Właściwości

{/* generated:component:i18n-link — do not edit; run `pnpm run docs:generate` */}

| Właściwość | Typ | Domyślnie | Opis |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | Docelowa trasa. Lokalizowana automatycznie; zewnętrzny URL jest przekazywany bez zmian. |
| `activeStyle` | `Partial<CSSStyleValue>` | — | Styl inline stosowany, gdy link wskazuje bieżącą trasę. |

**\*** wymagane.

### Sloty

| Slot | Powiązania | Opis |
| --- | --- | --- |
| `default` | — | Zawartość linku. |

{/* /generated:component:i18n-link */}

`to` akceptuje wszystko, co przyjmuje `NuxtLink` — ścieżkę, nazwaną trasę lub rozwiązany obiekt trasy.
Absolutny URL jest wykrywany i renderowany jako zwykły `<a target="_blank" rel="noopener noreferrer">`,
zamiast być lokalizowany.

## 🛠️ Przykładowe użycia

### Podstawowe użycie

```vue
<i18n-link to="/about">About Us</i18n-link>
```

Ten przykład tworzy link do strony `/about`, zlokalizowany do bieżącej lokalizacji.

### Stylizacja aktywnego linku ze stylami inline

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

Link będzie miał pogrubiony tekst, gdy użytkownik znajduje się na stronie `/about`, co pozwala stylizować aktywny link bezpośrednio za pomocą stylów inline.

### Obsługa linków zewnętrznych

Komponent automatycznie wykrywa linki zewnętrzne i dodaje niezbędne atrybuty bezpieczeństwa.

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

Ten link otworzy `https://example.com` w nowej karcie z zastosowanym `rel="noopener noreferrer"`.

## 🎨 Style

Komponent używa teraz stylów inline dla stanu aktywnego zamiast klasy. Możesz dostosować te style za pomocą właściwości `activeStyle`.

### Domyślne style aktywne

- **Grubość czcionki**: `bold`
- **Kolor**: dziedziczy domyślny kolor przeglądarki (jeśli w `activeStyle` nie określono `color`).

Możesz je nadpisać, dostarczając niestandardowe style poprzez właściwość `activeStyle`.

### Niestandardowe style aktywne

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

W tym przykładzie link będzie pogrubiony i zielony, gdy jest aktywny.

## 🚀 Dodatkowe funkcje

### Slot na niestandardową zawartość

Możesz przekazać niestandardową zawartość wewnątrz linku za pomocą slotów, co czyni komponent elastycznym dla różnych przypadków użycia.

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### Ulepszenia dostępności

Komponent wspiera `aria-label` i inne atrybuty dostępności, aby zapewnić bardziej dostępne doświadczenie.

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
