# 🌍 Komponent `<i18n-t>`

Komponent `<i18n-t>` w `Nuxt I18n Micro` to elastyczny komponent tłumaczeń obsługujący dynamiczne wstawianie zawartości poprzez sloty. Pozwala interpolować tłumaczenia niestandardowymi komponentami Vue lub zawartością HTML, umożliwiając zaawansowane scenariusze lokalizacji.

Naraz stosuje się tylko jedno z `plural`, `number`, `date` i `relativeDate`; gdy ustawionych jest kilka, wygrywa pierwsze z tej listy.

### Przykłady dla poszczególnych właściwości

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

## 🛠️ Przykłady użycia

### Podstawowe użycie

```vue
<i18n-t keypath="feedback.text" />
```

Renderuje tłumaczenie dla `feedback.text` w tagu `<span>`.

### Używanie slotów dla dynamicznej zawartości

Komponent `<i18n-t>` obsługuje sloty do dynamicznego wstawiania komponentów Vue lub innej zawartości w konkretne miejsca tłumaczenia.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

W tym przykładzie placeholder `\{link\}` w ciągu tłumaczenia `feedback.text` jest zastępowany komponentem `<nuxt-link>`, który sam zawiera kolejny komponent tłumaczeń.

### Liczba mnoga

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

Automatycznie stosuje reguły liczby mnogiej na podstawie wartości `itemCount`.

## 🚀 Dodatkowe funkcje

### Domyślny slot

Jeśli nie podano konkretnego slotu, tłumaczenie można dostosować za pomocą domyślnego slota, który udostępnia cały przetłumaczony string:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### Renderowanie warunkowe

Nie renderuj nic, gdy string tłumaczenia jest pusty, używając właściwości `hideIfEmpty`.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### Niestandardowa reguła liczby mnogiej

Użyj niestandardowej funkcji do obsługi liczby mnogiej.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### Zaawansowany przykład ze slotami

Wykorzystaj sloty, aby dostosować sposób renderowania zawartości tłumaczenia.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
