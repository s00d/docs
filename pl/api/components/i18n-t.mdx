# 🌍 Komponent `<i18n-t>`

Komponent `<i18n-t>` w `Nuxt I18n Micro` to elastyczny komponent tłumaczeń, który wspiera dynamiczne wstawianie zawartości poprzez sloty. Pozwala interpolować tłumaczenia z niestandardowymi komponentami Vue lub zawartością HTML, umożliwiając zaawansowane scenariusze lokalizacyjne.

## ⚙️ Właściwości

| Właściwość | Typ | Domyślnie | Opis |
| --- | --- | --- | --- |
| `keypath` **\*** | `string` | — | Klucz tłumaczenia do wyrenderowania. |
| `plural` | `number \| string` | — | Liczba wybierająca formę liczby mnogiej. Ustaw ją, aby używać `$tc` zamiast `$t`. |
| `tag` | `string` | `'span'` | Element do wyrenderowania. |
| `params` | `Record<string, string \| number \| boolean>` | `() => (\{\})` | Wartości interpolacji podstawiane w tłumaczeniu. |
| `defaultValue` | `string` | `''` | Renderowane zamiast komponentu, gdy `hideIfEmpty` blokuje puste tłumaczenie. |
| `html` | `boolean` | `false` | Renderuj tłumaczenie jako HTML, a nie tekst. Tylko dla zawartości, którą kontrolujesz. |
| `hideIfEmpty` | `boolean` | `false` | Nie renderuj nic, gdy tłumaczenie zwraca pusty ciąg. |
| `customPluralRule` | `PluralFunc` | `null` | Reguła liczby mnogiej wyłącznie dla tego elementu, nadpisująca skonfigurowaną. |
| `number` | `number \| string` | — | Formatuje wartość przez `$tn` i przekazuje ją do tłumaczenia jako `\{number\}`. |
| `date` | `Date \| string \| number` | — | Formatuje wartość przez `$td` i przekazuje ją do tłumaczenia jako `\{date\}`. |
| `relativeDate` | `Date \| string \| number` | — | Formatuje wartość przez `$tdr` i przekazuje ją do tłumaczenia jako `\{relativeDate\}`. |

**\*** wymagane.

{/* /generated:component:i18n-t */}

Jednocześnie działa tylko jedno z: `plural`, `number`, `date` i `relativeDate`; gdy ustawionych jest kilka, wygrywa pierwsze z tej listy.

### Przykłady dla każdej właściwości

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

## 🛠️ Przykładowe użycia

### Podstawowe użycie

```vue
<i18n-t keypath="feedback.text" />
```

Renderuje tłumaczenie dla `feedback.text` w tagu `<span>`.

### Używanie slotów dla dynamicznej zawartości

Komponent `<i18n-t>` wspiera używanie slotów do dynamicznego wstawiania komponentów Vue lub innej zawartości w konkretne części tłumaczenia.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

W tym przykładzie placeholder `\{link\}` w tłumaczeniu `feedback.text` zostaje zastąpiony komponentem `<nuxt-link>`, który sam zawiera kolejny komponent tłumaczenia.

### Pluralizacja

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

Automatycznie stosuje reguły pluralizacji w oparciu o wartość `itemCount`.

## 🚀 Dodatkowe funkcje

### Slot domyślny

Jeśli nie dostarczono konkretnego slotu, tłumaczenie można dostosować poprzez slot domyślny, który udostępnia cały przetłumaczony ciąg:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### Warunkowe renderowanie

Nie renderuj niczego, jeśli tłumaczenie jest pustym ciągiem, używając właściwości `hideIfEmpty`.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### Niestandardowa reguła pluralizacji

Użyj niestandardowej funkcji do obsługi pluralizacji.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### Zaawansowany przykład ze slotami

Wykorzystaj sloty, aby dostosować sposób renderowania zawartości tłumaczenia.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
