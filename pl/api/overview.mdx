# Dokumentacja API

## Runtime API

- [Metody](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, przełączanie locale, helpery routingu
- [Zdarzenia](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Tłumaczenia i pamięć podręczna](/api/cache) — `TranslationStorage`, ładowanie payloadów, `$clearCache`

## Middleware serwera

Handlery serwerowe używają dedykowanego middleware'u (nie klienckich helperów `$t`):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — tłumacz w trasach API i handlerach serwerowych
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — odczytuj wykryte locale i metadane

Zobacz pełny [przewodnik po tłumaczeniach po stronie serwera](/guides/server-side-translations), zawierający konfigurację, priorytet detekcji locale i przykłady.
