Ta sekcja wymienia każdą opcję, helper, hook, composable i komponent modułu Nuxt, a także eksportowane API każdego pakietu `@i18n-micro/*`. Korzystaj z niej, aby sprawdzić sygnaturę lub wartość domyślną; [Przewodnik](/pl/guide/getting-started) wyjaśnia, jak ich używać. Większość tabel jest generowana ze źródeł, więc odpowiada kodowi.

## Moduł Nuxt {#nuxt-module}

| Strona | Zakres |
| --- | --- |
| [Opcje modułu](/pl/api/module-options) | Każdy klucz `i18n` w `nuxt.config`, z typem i wartością domyślną |
| [Helpery](/pl/api/methods) | `$t`, `$tc`, `$tn`, `$td`, `$localePath`, `$switchLocale`, `$defineI18nRoute` i pozostałe |
| [Hooki](/pl/api/events) | Hook runtime `i18n:register` |

## Composables {#composables}

| Composable | Zastosowanie |
| --- | --- |
| [`useI18n`](/pl/composables/useI18n) | Helpery w `<script setup>` |
| [`useI18nLocale`](/pl/composables/useI18nLocale) | Stan locale i cookie we własnym pluginie wykrywania |
| [`useI18nHead`](/pl/composables/useI18nHead) | Nadpisywanie wygenerowanych tagów SEO dla poszczególnych stron |
| [`useLocaleHead`](/pl/composables/useLocaleHead) | Tagi SEO jako obiekt, do własnego `useHead` |

## Komponenty {#components}

| Komponent | Renderuje |
| --- | --- |
| [`<i18n-t>`](/pl/components/i18n-t) | Jedno tłumaczenie, z liczbą mnogą, formatowaniem i interpolacją slotów |
| [`<i18n-link>`](/pl/components/i18n-link) | `NuxtLink` do zlokalizowanej trasy |
| [`<i18n-switcher>`](/pl/components/i18n-switcher) | Rozwijaną listę locale |
| [`<i18n-group>`](/pl/components/i18n-group) | Blok ze wspólnym prefiksem kluczy |

## Serwer {#server}

Handlery Nitro używają `useTranslationServerMiddleware` i `useLocaleServerMiddleware`, a nie helperów klienckich. Zobacz [Trasy serwerowe](/pl/guide/server-side-translations).

## Pakiety {#packages}

[API pakietów](/pl/api/packages/overview) wymienia eksporty każdego pakietu `@i18n-micro/*`, po jednej wygenerowanej stronie na pakiet.
