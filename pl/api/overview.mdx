# Dokumentacja API

## API runtime

- [Metody](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, przełączanie lokalizacji, helpery routingu
- [Zdarzenia](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Tłumaczenia i cache](/api/cache) — `TranslationStorage`, ładowanie payloadu, `$clearCache`

## Middleware serwera

Handlery serwera używają dedykowanego middleware (nie klienckich helperów `$t`):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — tłumacz w trasach API i handlerach serwera
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — odczytuj wykrytą lokalizację i metadane

Zobacz pełny [Przewodnik po tłumaczeniach po stronie serwera](/guides/server-side-translations), aby poznać konfigurację, priorytet wykrywania lokalizacji i przykłady.
