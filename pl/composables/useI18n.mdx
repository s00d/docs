---
title: "useI18n"
description: "useI18n zwraca pomocniki runtime (`$t`, `$tc`, `$localePath`, …) jako zwykły obiekt, z prefiksem `$` i bez niego."
---

`useI18n()` zwraca pomocniki runtime modułu jako zwykły obiekt. Używaj go w `<script setup>`, composables i pluginach zamiast sięgać po `useNuxtApp()`. Każdy pomocnik jest dostępny pod nazwą z `$` oraz pod aliasem bez prefiksu: `t` i `$t` to ta sama funkcja.

## Sygnatura {#signature}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Wszystkie pomocniki runtime jako zwykły obiekt.

Te same funkcje, które plugin wstrzykuje jako `$t`, `$tc` itd., dostępne zarówno pod nazwą
z prefiksem dolara, jak i pod aliasem bez prefiksu — więc działają zarówno `const { t } = useI18n()`,
jak i `const { $t } = useI18n()`.

**Zwraca** — pomocniki opisane w [dokumentacji metod](/pl/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

Zwracany obiekt zawiera wszystkie pomocniki z [`PluginsInjections`](/pl/api/methods). Każdy z nich jest opisany na stronie [Pomocniki](/pl/api/methods).

## Przykład {#example}

```vue
<script setup lang="ts">
const { t, tc, localePath, switchLocale, getLocale } = useI18n()

const title = computed(() => t('page.title'))
</script>

<template>
  <h1>{{ title }}</h1>
  <p>{{ tc('items', 3) }}</p>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
  <button @click="switchLocale(getLocale() === 'en' ? 'de' : 'en')">{{ t('nav.switch') }}</button>
</template>
```

## Poza typem {#not-in-the-type}

`$defineI18nRoute` jest typowany tylko w `useNuxtApp()`:

```ts
const { $defineI18nRoute } = useNuxtApp()
```
