---
title: "Nuxt I18n Micro"
description: "Małe, szybkie i18n dla Nuxt: tłumaczenia JSON dla każdej strony, zlokalizowane trasy generowane podczas budowania, tagi SEO od razu po instalacji."
---

Nuxt I18n Micro to lekki, wydajny moduł i18n dla Nuxt 3 i 4, zaprojektowany z myślą o dużych projektach. W porównaniu z tradycyjnymi rozwiązaniami i18n, takimi jak `@nuxtjs/i18n`, utrzymuje niski czas budowania, zużycie pamięci i rozmiar paczki.

Zlokalizowane trasy są generowane podczas budowania przez `@i18n-micro/route-strategy` i rozwiązywane w czasie działania przez `@i18n-micro/path-strategy`, dzięki czemu linki, przełącznik, `hreflang` i przekierowania są zgodne z routerem. Tłumaczenia są wyłącznie w formacie JSON, podzielone na współdzielone pliki główne i pliki poszczególnych stron, które serwer deweloperski tworzy za Ciebie, z wbudowanym HMR.

<CodeGroup>

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>
