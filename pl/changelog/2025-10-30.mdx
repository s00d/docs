**Data**: 2025-10-30

**Wersja**: `v2.0.0`

![v2.0.0 release](/images/2.0.0.png)

Wprowadzamy po stronie serwera HMR dla plików tłumaczeń w trybie deweloperskim. Gdy plik JSON z tłumaczeniem się zmienia, pamięć podręczna serwera unieważnia tylko klucze, których to dotyczy, a kolejne żądania natychmiast otrzymują świeże dane — bez konieczności restartu.

## Co nowego? {#what’s-new}

- HMR po stronie serwera dla plików tłumaczeń
- Natychmiastowe unieważnianie pamięci podręcznej dla każdej strony/lokalizacji
- Płynna praca podczas edycji treści

## Jak to działa {#how-it-works}

- Obserwator w `src/runtime/server/plugins/watcher.dev.ts` śledzi `<rootDir>/<translationDir>/**/*.json`
- Pliki stron (np. `pages/<page>/<locale>.json`) unieważniają `_locales:merged:<page>:<locale>`
- Pliki na poziomie głównym (np. `<locale>.json`) unieważniają wszystkie scalone klucze dla danej lokalizacji
- Rejestrowany automatycznie z `src/module.ts` w trybie deweloperskim, gdy `experimental.hmr !== false`

## Konfiguracja {#configuration}

```ts
export default defineNuxtConfig({
  i18n: {
    experimental: { hmr: true }, // default in dev
  },
})
```
