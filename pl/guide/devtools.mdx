W `nuxt dev` moduł dodaje dwa narzędzia do debugowania: zakładkę **i18n Micro** w Nuxt DevTools do przeglądania i edycji plików tłumaczeń oraz inspektor Vue DevTools dla aktywnego locale i załadowanych słowników. Oba istnieją tylko w trybie deweloperskim i nic nie dodają do buildów produkcyjnych. Zakładka Nuxt wymaga jedynie włączonych Nuxt DevTools; inspektor Vue wymaga także rozszerzenia przeglądarki Vue DevTools.

## Zakładka Nuxt DevTools {#nuxt-devtools-tab}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  devtools: { enabled: true }, // the tab is registered only when DevTools are on
})
```

Otwórz Nuxt DevTools (`Shift + Alt + D`) i wybierz **i18n Micro**. Zakładka pokazuje:

- każdy plik JSON w `locales/` (główny i `pages/`) każdej warstwy, a także pliki główne z `additionalTranslationDirs`;
- edytor dla każdego pliku; **Save** zapisuje plik z powrotem na dysk, a serwer deweloperski przeładowuje tłumaczenia;
- **Export** / **Import** pliku jako JSON oraz **Stats** z liczbą kluczy i pokryciem tłumaczeń;
- widok konfiguracji z rozwiązanymi opcjami modułu;
- **Translate**, które uzupełnia brakujące klucze za pomocą silnika tłumaczenia maszynowego skonfigurowanego w ustawieniach zakładki.

Zapis dotyczy tylko istniejących plików `.json` w Twoich katalogach tłumaczeń. Gdy plik istnieje w kilku warstwach, zapisywana jest kopia projektu.

## Inspektor Vue DevTools {#vue-devtools-inspector}

Z rozszerzeniem przeglądarki Vue DevTools moduł rejestruje inspektor i18n (bieżące locale, fragment trasy, załadowane klucze) oraz oś czasu ze zmianami locale, ładowaniem fragmentów i brakującymi kluczami.

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    debug: true, // also log every $t / $ts / $tc call on the timeline
    // vueDevtools: false, // turn the inspector off, keep the Nuxt tab
  },
})
```

[`vueDevtools`](/pl/api/module-options) domyślnie ma wartość `true`. `debug: true` generuje dużo logów; używaj go w krótkich sesjach.

## Poza Nuxt {#outside-nuxt}
