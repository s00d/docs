---
title: "Wykluczanie ścieżek"
description: "Wyłącz strony i pliki z routingu locale za pomocą excludePatterns i sprawdź, które ścieżki są już wykluczone."
---

Niektóre ścieżki nigdy nie powinny dostawać prefiksu locale ani przekierowania locale: panel administracyjny, health check, generowany kanał. `excludePatterns` je oznacza, a wbudowana lista obejmuje już wewnętrzne ścieżki Nuxt i typowe pliki statyczne. Wykluczona strona zachowuje dokładnie tę ścieżkę, którą zapisałeś, i nadal renderuje się z `$t`.

## Wykluczanie ścieżki {#exclude-a-path}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    excludePatterns: [
      '/admin', // /admin and everything below it
      '/preview-*', // glob over the whole path
    ],
  },
})
```

Przy tej konfiguracji `pages/admin/index.vue` odpowiada tylko pod `/admin`; nie ma `/de/admin`, a `/admin` nigdy nie jest przekierowywane na `/de/admin`.

## Składnia wzorców {#pattern-syntax}

Wzorce są dopasowywane do ścieżki bez `app.baseURL`:

| Wzorzec | Pasuje | Nie pasuje |
| --- | --- | --- |
| `'/admin'` | `/admin`, `/admin/users` | `/administrator`, `/de/admin` |
| `'/preview-*'` | `/preview-1`, `/preview-a/b` | `/de/preview-1` |
| `'/file-?'` | `/file-a` | `/file-ab` |
| `/^\/v\d+\//` | `/v2/docs` | `/docs` |

Ciąg znaków bez `*` ani `?` pasuje do ścieżki i całych segmentów poniżej niej. Z `*` (dowolny ciąg znaków, łącznie z ukośnikami) lub `?` (jeden znak) musi pasować do całej ścieżki. Ciągi zawsze zaczynaj od `/`.

## Co jest już wykluczone {#what-is-excluded-already}

Te ścieżki nigdy nie dostają tras locale ani przekierowań, bez żadnej konfiguracji:

- `/api` i `/_nuxt` oraz wszystko poniżej nich;
- trasa tłumaczeń, domyślnie `/_locales` ([`apiBaseUrl`](/pl/api/module-options#apibaseurl));
- każda ścieżka z segmentem zaczynającym się od `__` (`/__nuxt_content`, `/en/__og-image__`);
- `/sitemap*.xml`, `/robots.txt`, `/favicon.ico`, `/apple-touch-icon*.png`, `/manifest.json`, `/sw.js`, `/workbox-*.js`;
- każda ścieżka, której ostatni segment kończy się rozszerzeniem pliku statycznego: `xml txt ico json js css png jpg jpeg gif svg webp avif pdf wasm map mp4 webm mp3 zip gz woff woff2 ttf eot`. Slugi stron z kropkami, takie jak `/user/john.doe`, oraz ścieżki `.html` pozostają stronami.

## Co robi wykluczenie {#what-an-exclusion-does}

- **Trasy:** nie są generowane zlokalizowane warianty; strona pozostaje taka, jak ją zapisano.
- **Przekierowania i błędy 404:** serwerowy plugin przekierowań i kliencki middleware przekierowań pomijają tę ścieżkę.
- **Prerender:** pasujące ścieżki są usuwane z listy tras do prerenderowania.

Nie powstrzymuje to serwerowego middleware i18n przed wykrywaniem locale dla żądania ani strony przed używaniem tłumaczeń. Aby strona pozostała zlokalizowana, ale bez tagów SEO, użyj `disableMeta` ([Konfiguracja strony](/pl/guide/per-component-translations#turn-off-seo-tags)). Aby wyłączyć lokalizację jednej strony po ścieżce z poziomu `nuxt.config.ts`, `globalLocaleRoutes: { '/admin': false }` ([Zlokalizowane ścieżki](/pl/guide/custom-locale-routes#in-nuxt-config)) robi to samo dla routingu.
