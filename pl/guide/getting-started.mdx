Ta strona przeprowadza aplikację Nuxt od braku i18n do przetłumaczonej strony z przełącznikiem języka. Potrzebujesz jej raz, na początku projektu. W efekcie otrzymasz zlokalizowane adresy URL (`/about`, `/de/about`), jeden plik JSON na każde locale i stronę oraz `$t` w szablonach.

## Instalacja {#install}

Moduł wymaga Nuxt 3.18 lub nowszego (Nuxt 4 również działa) oraz Node 20 lub nowszego.

<CodeGroup>

```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>

## Konfiguracja locale {#configure-the-locales}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', displayName: 'English' },
      { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
      { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
    ],
    defaultLocale: 'en',
  },
})
```

To cała konfiguracja, jakiej potrzebuje pierwsza aplikacja. Wartości domyślne zapewniają:

- `strategy: 'prefix_except_default'`: domyślne locale nie ma prefiksu (`/about`), pozostałe go mają (`/de/about`). Zobacz [Strategie routingu](/pl/guide/strategy).
- `translationDir: 'locales'`: pliki tłumaczeń znajdują się w `locales/` w katalogu głównym projektu, także przy układzie `app/` z Nuxt 4.
- `meta: true`: tagi `hreflang`, canonical i `og:locale` oraz `lang` i `dir` na `<html>`. Zobacz [SEO](/pl/guide/seo).
- Odwiedzający, który otworzy `/`, zostaje przekierowany na język, o który prosi jego przeglądarka (`Accept-Language`). Zobacz [Wykrywanie locale](/pl/guide/locale-detection).

`iso` to tag języka używany w tagach SEO; `code` to to, co pojawia się w adresie URL. Wszystkie opcje są wymienione w [Opcjach modułu](/pl/api/module-options).

## Dodawanie plików tłumaczeń {#add-translation-files}

Uruchom serwer deweloperski poleceniem `nuxt dev`. Gdy Nuxt rozwiązuje strony, moduł tworzy pusty plik `{}` dla każdego locale i strony, które go nie mają (wyłącz to za pomocą [`disableWatcher`](/pl/api/module-options#disablewatcher)):

```text
locales/
├── en.json            # root: keys every page can use
├── de.json
├── fr.json
└── pages/
    ├── index/         # pages/index.vue
    │   ├── en.json
    │   ├── de.json
    │   └── fr.json
    └── about/         # pages/about.vue
        ├── en.json
        ├── de.json
        └── fr.json
```

Uzupełnij plik główny i plik strony:

```json
// locales/en.json
{ "nav": { "home": "Home", "about": "About" } }
```

```json
// locales/pages/index/en.json
{ "welcome": "Welcome, {name}!", "items": "no items | one item | {count} items" }
```

Strona widzi klucze główne i własne klucze; w razie konfliktu wygrywa jej własny plik. Nazwy folderów odpowiadają nazwie trasy (`pages/articles/[id].vue` to `locales/pages/articles-id/`). [Pliki tłumaczeń](/pl/guide/translations) opisują układ, fallbacki i ładowanie.

## Użycie `$t` na stronie {#use-$t-on-a-page}

```vue
<!-- pages/index.vue -->
<script setup lang="ts">
const { t, tc, getLocale } = useI18n()

const title = t('nav.home') // 'Home'
</script>

<template>
  <h1>{{ $t('welcome', { name: 'Ada' }) }}</h1>
  <!-- Welcome, Ada! -->
  <p>{{ $tc('items', 3) }}</p>
  <!-- 3 items -->
  <p>{{ getLocale() }}</p>
  <!-- en -->
</template>
```

- W szablonach każdy helper jest dostępny z `$` (`$t`, `$tc`, `$localePath`, …).
- W `<script setup>` `useI18n()` zwraca te same helpery, z `$` i bez niego (`t` i `$t` to jedna funkcja). Jest importowany automatycznie.
- Placeholdery `{name}` są wypełniane z obiektu parametrów. Formy liczby mnogiej oddziela się znakiem `|`; liczba wybiera formę (0, 1, a następnie ostatnią dla wszystkiego powyżej).

Wszystkie helpery są wymienione w [Metodach](/pl/api/methods).

## Linkowanie między stronami i przełączanie locale {#link-between-pages-and-switch-locale}

```vue
<!-- components/AppHeader.vue -->
<template>
  <nav>
    <i18n-link :to="{ name: 'index' }">{{ $t('nav.home') }}</i18n-link>
    <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
    <i18n-switcher />
  </nav>
</template>
```

- [`<i18n-link>`](/pl/components/i18n-link) to `NuxtLink`, który wskazuje stronę w bieżącym locale: na `/de` link do strony about prowadzi do `/de/about`.
- [`<i18n-switcher>`](/pl/components/i18n-switcher) to lista rozwijana włączonych locale; pozostawia odwiedzającego na tej samej stronie.
- W przypadku własnych przycisków wywołaj `$switchLocale('de')`, co przechodzi do bieżącej strony w języku niemieckim i zapamiętuje wybór. Dla zwykłego `NuxtLink` użyj `$localePath({ name: 'about' })` lub `$switchLocalePath('de')`.

## Sprawdzenie {#check-it}

Uruchom `nuxt dev` i otwórz:

| URL | Wyświetla |
| --- | --- |
| `/` | Angielską stronę główną (lub przekierowanie do `/de`, gdy Twoja przeglądarka preferuje niemiecki) |
| `/de` | Niemiecką stronę główną |
| `/de/about` | Niemiecką stronę about |
| `/en/about` | 404: domyślne locale nie ma prefiksu przy `prefix_except_default` |

Zmiany w plikach JSON są stosowane na otwartej stronie bez przeładowania.
