[Crowdin](https://crowdin.com/) to platforma tłumaczeniowa: przesyłasz pliki domyślnej lokalizacji, tłumacze pracują w Crowdin, a Ty pobierasz z powrotem pozostałe lokalizacje. Moduł odczytuje zwykłe pliki JSON, więc Crowdin CLI potrzebuje jedynie pliku `crowdin.yml`, który poprawnie mapuje `locales/` i `locales/pages/`. Żadne ustawienie modułu się nie zmienia.

## Konfiguracja crowdin.yml {#configure-crowdin-yml}

```yml
# crowdin.yml
project_id_env: CROWDIN_PROJECT_ID
api_token_env: CROWDIN_PERSONAL_TOKEN
base_path: ./locales
preserve_hierarchy: true

files:
  - source: /en.json
    translation: /%two_letters_code%.json
  - source: /pages/**/en.json
    translation: /pages/**/%two_letters_code%.json
```

- `en` to Twoja domyślna lokalizacja; jej pliki są źródłami.
- `project_id_env` / `api_token_env` odczytują ID i token ze zmiennych środowiskowych, więc żaden sekret nie trafia do repozytorium.
- `preserve_hierarchy: true` zachowuje foldery `pages/<page>/` w niezmienionej postaci.
- Nazwa przetłumaczonego pliku musi być równa `code` lokalizacji w `nuxt.config.ts`. `%two_letters_code%` pasuje do kodów takich jak `de`; dla kodów takich jak `pt-BR` użyj `%locale%` albo zmapuj kody Crowdin na swoje za pomocą `languages_mapping`.

## Przesyłanie i pobieranie {#upload-and-download}

```bash
npm install -g @crowdin/cli

export CROWDIN_PROJECT_ID=123456
export CROWDIN_PERSONAL_TOKEN=...   # from Crowdin account settings

crowdin upload sources   # push locales/en.json and locales/pages/**/en.json
crowdin download         # write locales/de.json, locales/pages/**/de.json, ...
```

Uruchamiaj oba polecenia w CI, aby pliki były aktualne. Pobrane pliki trafiają do repozytorium tak jak edytowane ręcznie; następne budowanie lub przeładowanie w trybie dev je uwzględni.

## Przed przesłaniem {#before-uploading}

Najpierw wyczyść źródła, aby tłumacze nie pracowali nad martwymi kluczami: [`i18n-micro clean`](/pl/api/cli#clean) usuwa nieużywane klucze, [`i18n-micro check`](/pl/api/cli#check) zgłasza braki po pobraniu. CLI nie ma własnej integracji z Crowdin: ta strona opisuje wspierany sposób.
