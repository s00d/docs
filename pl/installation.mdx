## Wymagania

- **Node.js**: 18 lub nowszy.
- **Nuxt**: 3.x lub 4.x.

Moduł obsługuje zarówno układ projektu Nuxt 3 (`pages/**/*.vue`), jak i układ Nuxt 4 (`app/pages/**/*.vue`). Zgodnie z konwencją tłumaczenia znajdują się w katalogu głównym projektu (`locales/`), nawet gdy używasz katalogu `app/` w Nuxt 4.

## Instalacja modułu Nuxt

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Zarejestruj go w `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Zobacz [Szybki start](/quickstart), aby zapoznać się z pełnym przewodnikiem, lub [Dokumentację konfiguracji](/guides/configuration) opisującą każdą opcję.

## Układ projektu

Domyślnie moduł oczekuje:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Pliki z poziomu głównego są scalane z każdym plikiem dla konkretnej strony w czasie budowania. Brakujące pliki stron są tworzone automatycznie podczas `nuxt dev`.

## Układ Nuxt 4

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Aby umieścić tłumaczenia obok kodu w katalogu `app/`, ustaw `translationDir: 'app/locales'`.

## Pakiety ekosystemu

| Pakiet | Przeznaczenie |
| --- | --- |
| [`@i18n-micro/vue`](/integrations/vue) | Integracja z Vue 3 (samodzielna, bez Nuxt). |
| [`@i18n-micro/react`](/integrations/react) | Integracja z React. |
| [`@i18n-micro/preact`](/integrations/preact) | Integracja z Preact. |

| [`@i18n-micro/astro`](/integrations/astro) | Integracja z Astro. |

| [`@i18n-micro/devtools-ui`](/integrations/devtools-ui) | Panel DevTools niezależny od frameworka. |

Współdzielone pakiety wewnętrzne są dociągane tranzytywnie.

## TypeScript

Moduł generuje ambientne typy dla `useI18n`, `$t` i powiązanych helperów na podstawie plików Twojego domyślnego locale. Jest to włączone domyślnie (`types: true`).

Aby uzyskać silniejsze typowanie kluczy tłumaczeń, zobacz [`@i18n-micro/types-generator`](/integrations/types-generator).
