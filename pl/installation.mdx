## Wymagania

- **Node.js**: 18 lub nowszy.
- **Nuxt**: 3.x lub 4.x.

Moduł obsługuje zarówno układ projektu Nuxt 3 (`pages/**/*.vue`), jak i układ Nuxt 4 (`app/pages/**/*.vue`). Tłumaczenia zgodnie z konwencją znajdują się w katalogu głównym projektu (`locales/`), nawet gdy używasz katalogu `app/` w Nuxt 4.

## Instalacja modułu Nuxt

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Zarejestruj go w `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Zobacz [Szybki start](/quickstart), aby przejść pełny samouczek, lub [Dokumentację konfiguracji](/guides/configuration), gdzie znajdziesz wszystkie opcje.

## Układ projektu

Domyślnie moduł oczekuje:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Pliki z poziomu root są scalane z każdym plikiem specyficznym dla strony w czasie budowy. Pliki specyficzne dla strony są tworzone automatycznie, gdy ich brakuje podczas `nuxt dev`.

## Układ Nuxt 4

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Aby zlokalizować tłumaczenia razem z `app/`, ustaw `translationDir: 'app/locales'`.

## TypeScript

Moduł generuje otoczkowe typy dla `useI18n`, `$t` i powiązanych helperów na podstawie plików Twojej domyślnej lokalizacji. Jest to włączone domyślnie (`types: true`).

Aby uzyskać silniejsze typowanie kluczy tłumaczeń, zobacz [`@i18n-micro/types-generator`](/integrations/types-generator).
