## 🚀 Szybki start

### Instalacja

Zainstaluj moduł w swojej aplikacji Nuxt:

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

### Podstawowa konfiguracja

Dodaj moduł do `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

<Tip>
- **Pliki na poziomie root** (`locales/en.json` itd.) to tłumaczenia współdzielone w całej aplikacji (menu, stopka, wspólny interfejs). Z opcją `translationPayloads.mode: 'premerged'` (domyślną) są scalane z każdą stroną w czasie budowy.
- **Pliki specyficzne dla stron** (`locales/pages/<route>/<locale>.json`) zawierają tłumaczenia unikalne dla konkretnych stron i są ładowane wyłącznie podczas odwiedzin tej strony.
- **Trasy dynamiczne**: `pages/articles/[id].vue` mapuje się na `locales/pages/articles-id/` (nawiasy zastępowane myślnikami).
- **Automatyczne generowanie**: wszystkie pliki tłumaczeń są tworzone automatycznie, gdy ich brakuje podczas `nuxt dev`.
</Tip>

<Info>
Moduł obsługuje oba układy:

- **Strony**: `pages/**/*.vue` (Nuxt 3) lub `app/pages/**/*.vue` (Nuxt 4)
- **Tłumaczenia**: domyślnie trzymaj `locales/` w **głównym katalogu projektu** (zalecana konwencja), a nie wewnątrz `app/`

```tree
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   ├── en.json
│   └── pages/
└── nuxt.config.ts
```

Opcjonalna kolokacja: `i18n: \{ translationDir: 'app/locales' \}` (zobacz [fixture `n3`](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/n3)).

Do opcjonalnego helpera CLI `text-to-i18n` użyj [`nuxt-i18n-micro-cli` ≥ 2.1.1](/guides/cli#-text-to-i18n-command), aby `app/pages` i `app/components` były skanowane z katalogu głównego projektu.
</Info>

### Podstawowe użycie

Używaj tłumaczeń w swoich komponentach:

```vue
<template>
  <div>
    <h1>{{ $t('welcome') }}</h1>
    <p>{{ $t('description', { name: 'World' }) }}</p>

    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" @click="$switchLocale(locale.code)">
        {{ locale.code }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useI18n } from '#imports'

const { $t, $getLocales, $switchLocale } = useI18n()
</script>
```
