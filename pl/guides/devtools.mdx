# 🛠️ DevTools w `nuxt-i18n-micro`

## Vue DevTools (rozszerzenie przeglądarki)

W trybie deweloperskim moduł może zarejestrować **niestandardowy inspector Vue DevTools** oraz oś czasu przez `@vue/devtools-api`. Jest to odrębne od karty Nuxt DevTools poniżej.

| Narzędzie | Najlepsze do |
|-----------|--------------|
| **Vue DevTools** | Lokalizacja na żywo, cache tłumaczeń w pamięci, oś czasu `$t` (`debug: true`), zdarzenia brakujących kluczy |
| **Karta Nuxt DevTools** | Edycja plików JSON na dysku, przegląd konfiguracji, import/eksport |

Plugin vue-devtools jest rejestrowany tylko podczas `nuxt dev` (nie w buildach produkcyjnych). Stan pomostu tylko-dev w głównym pluginie jest usuwany przez dead-code elimination `import.meta.dev`.

Wyłącz integrację z przeglądarką, zachowując kartę Nuxt:

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

Szczegółowe zdarzenia osi czasu `$t` wymagają `debug: true`.

## 📖 Czym jest Nuxt DevTools?

DevTools to potężny asystent developmentu, płynnie zintegrowany z modułem `nuxt-i18n-micro`. Zapewnia intuicyjny interfejs do zarządzania lokalizacją i zadaniami tłumaczeniowymi, przyspieszając i usprawniając Twój workflow. Zaprojektowany dla developerów ceniących wygodę, Nuxt DevTools wypełnia lukę między kodowaniem a zarządzaniem w runtime.

## 🌟 Kluczowe funkcje DevTools w `nuxt-i18n-micro`

### 1. **Zarządzanie lokalizacjami**

Bez wysiłku przeglądaj, wybieraj i zarządzaj lokalizacjami w aplikacji. Niezależnie od tego, czy pracujesz z jednym językiem, czy wieloma, DevTools zapewnia scentralizowane miejsce do obsługi wszystkich ustawień lokalizacji.

### 2. **Edycja tłumaczeń**

Edytuj pliki tłumaczeń bezpośrednio przez zintegrowany edytor JSON. Eliminuje to potrzebę zewnętrznych narzędzi, umożliwiając aktualizacje i zmiany w czasie rzeczywistym bez przerywania workflow.

### 3. **Import i eksport plików**

Uprość zarządzanie plikami tłumaczeń:

- **Eksport**: zapisuj tłumaczenia jako plik JSON do kopii zapasowej lub zewnętrznego użytku.
- **Import**: ładuj zaktualizowane pliki tłumaczeń do projektu, aby utrzymywać zawartość aktualną.

### 4. **Podglądy w czasie rzeczywistym**

Zobacz zmiany natychmiast w środowisku developerskim. Ta funkcja gwarantuje, że tłumaczenia i konfiguracje są poprawne, zanim trafią na produkcję.

### 5. **Bezproblemowa integracja z Nuxt**

DevTools działa natywnie z `nuxt-i18n-micro`, poszerzając jego możliwości bez wymagania dodatkowej konfiguracji. Dostosowuje się do Twoich potrzeb lokalizacyjnych, zachowując modularną i elastyczną strukturę Nuxt.

## 🛠️ Dlaczego używać DevTools?

Nuxt DevTools jest nieocenionym dodatkiem dla projektów wymagających lokalizacji. Pomaga developerom przez:

- **Oszczędność czasu**: automatyzuje powtarzalne zadania, takie jak zarządzanie plikami i walidacja formatu.
- **Redukcję błędów**: zapewnia bezpieczne, intuicyjne środowisko do edycji tłumaczeń.
- **Poprawę współpracy**: pozwala osobom nietechnicznym łatwo zarządzać tłumaczeniami.
- **Usprawnienie workflow**: konsoliduje wiele zadań lokalizacyjnych w jednym interfejsie.

## 🚀 Przejmij kontrolę nad lokalizacją

Dzięki Nuxt DevTools zintegrowanym z `nuxt-i18n-micro` zarządzanie aplikacjami wielojęzycznymi staje się proste i wydajne. Niezależnie od tego, czy dopracowujesz tłumaczenia, czy dodajesz nowe lokalizacje, DevTools wyposaża Cię w narzędzia potrzebne do dostarczania dopracowanych, przyjaznych użytkownikowi doświadczeń.
