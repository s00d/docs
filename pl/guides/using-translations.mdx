# Używanie tłumaczeń w komponentach

Po zainstalowaniu i skonfigurowaniu modułu możesz wyświetlać tłumaczenia, wywołując `$t('your_key')` w szablonach i skryptach Vue.

## 1. Pliki tłumaczeń root-level i page-specific

1. Tłumaczenia **root-level** znajdują się bezpośrednio w folderze `/locales` (np. `/locales/en.json`, `/locales/fr.json`). W czasie budowania są automatycznie scalane z każdym plikiem specyficznym dla strony, dzięki czemu są dostępne na wszystkich stronach.
2. Tłumaczenia **page-specific** znajdują się w `/locales/pages/...`, dopasowując strukturę folderu stron Nuxt:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. Użycie w szablonie z `$t`

W plikach `.vue` możesz bezpośrednio używać `$t` w szablonie:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
`$t` może zwrócić **obiekty**, jeśli klucz wskazuje na zagnieżdżony węzeł JSON (np. `$t('header')` → `\{ title: "Hi" \}`). W szablonach renderuje się to jako `[object Object]`. Użyj `$ts`, gdy potrzebujesz gwarantowanego stringa, lub podaj bardziej szczegółowy klucz, np. `$t('header.title')`. Zobacz [Dokumentację API — $t vs $ts](/api/methods#t) po szczegóły.
</Tip>

## 3. Zmiana bieżącego locale

Aby zmienić język w aplikacji, możesz pobrać `$locale` z `useI18n()` i przypisać mu nowy kod:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. Zagnieżdżone klucze i placeholdery

- **Zagnieżdżone klucze** używają notacji z kropką, np. `nested.key.deeper`.
- **Placeholdery** pozwalają wstawiać wartości dynamiczne:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. Wskazówki i dobre praktyki

- **Konfliktowe klucze**: Jeśli plik page-specific zawiera ten sam klucz co plik root-level, wersja page-specific ma pierwszeństwo (tłumaczenia root są scalane jako baza w czasie buildu).
- **Wyłączenie plików stron**: Jeśli wolisz nie używać tłumaczeń page-specific, możesz ustawić `disablePageLocales: true` w konfiguracji Nuxt. W ten sposób używane będą tylko pliki `/locales/*.json`.
- **Brak bezpośrednich importów**: Nie musisz robić `import \{ useI18n \} from 'nuxt-i18n-micro'`; funkcja auto-injection modułu obsługuje to za Ciebie.

To wszystko! Dzięki tym krokom możesz szybko **zacząć pobierać tłumaczenia** z plików JSON root-level lub page-specific i **wyświetlać je** w aplikacji Nuxt za pomocą `$t`.

## Dodatkowe zasoby

Aby poznać bardziej zaawansowane funkcje, sprawdź:

1. **Komponent `<i18n-t>`**  
   Komponent `<i18n-t>` to potężna alternatywa dla `$t`, szczególnie przydatna w sytuacjach związanych z zagnieżdżonymi elementami, zaawansowanym użyciem placeholderów i bardziej złożonymi strukturami tłumaczeń.

- **Dokumentacja**: [i18n-t](/api/components/i18n-t)

2. **Kompozycja `useI18n`**  
   Kompozycja `useI18n` oferuje kompletny zestaw funkcji i reaktywnych właściwości do zarządzania tłumaczeniami, obsługi przełączania locale, formatowania i nie tylko.

- **Dokumentacja**: [useI18n](/api/composables/use-i18n)
