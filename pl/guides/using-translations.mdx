# Używanie tłumaczeń w komponentach

Gdy moduł jest zainstalowany i skonfigurowany, możesz wyświetlać tłumaczenia wywołując `$t('your_key')` w szablonach i skryptach Vue.

## 1. Pliki tłumaczeń root-level i page-specific

1. **Tłumaczenia root-level** znajdują się bezpośrednio w folderze `/locales` (np. `/locales/en.json`, `/locales/fr.json`). W czasie budowy są automatycznie scalane z każdym plikiem specyficznym dla strony, dzięki czemu są dostępne na wszystkich stronach.
2. **Tłumaczenia page-specific** znajdują się w `/locales/pages/...`, zgodnie ze strukturą folderu stron Nuxt:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. Użycie w szablonie z `$t`

W plikach `.vue` możesz używać `$t` bezpośrednio w szablonie:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
`$t` może zwracać **obiekty**, jeśli klucz wskazuje na zagnieżdżony węzeł JSON (np. `$t('header')` → `\{ title: "Hi" \}`). W szablonach renderuje się to jako `[object Object]`. Użyj `$ts`, gdy potrzebujesz gwarantowanego ciągu, lub podaj bardziej szczegółowy klucz, np. `$t('header.title')`. Zobacz [Dokumentację API — $t vs $ts](/api/methods#t), aby poznać szczegóły.
</Tip>

## 3. Przełączanie bieżącej lokalizacji

Aby zmienić język w aplikacji, możesz pobrać `$locale` z `useI18n()` i przypisać mu nowy kod:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. Zagnieżdżone klucze i placeholdery

- **Zagnieżdżone klucze** używają notacji kropkowej, np. `nested.key.deeper`.
- **Placeholdery** pozwalają wstawić wartości dynamiczne:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. Wskazówki i najlepsze praktyki

- **Konflikty kluczy**: jeśli plik page-specific zawiera ten sam klucz co plik root-level, wersja page-specific ma priorytet (tłumaczenia root są scalane jako baza w czasie budowy).
- **Wyłączanie plików stron**: jeśli wolisz nie używać tłumaczeń page-specific, możesz ustawić `disablePageLocales: true` w konfiguracji Nuxt. Wtedy używane będą tylko pliki `/locales/*.json`.
- **Bez bezpośrednich importów**: nie musisz robić `import \{ useI18n \} from 'nuxt-i18n-micro'`; funkcja auto-injection modułu robi to za Ciebie.

To wszystko! Dzięki tym krokom możesz szybko **zacząć pobierać tłumaczenia** z plików JSON root-level lub page-specific i **wyświetlać je** w aplikacji Nuxt za pomocą `$t`.

## Dodatkowe zasoby

Aby poznać bardziej zaawansowane funkcje, zapoznaj się z:

1. **Komponent `<i18n-t>`**  
   Komponent `<i18n-t>` to potężna alternatywa dla `$t`, szczególnie przydatna w sytuacjach obejmujących zagnieżdżone elementy, zaawansowane użycie placeholderów i bardziej złożone struktury tłumaczeń.

- **Dokumentacja**: [i18n-t](/api/components/i18n-t)

2. **Composable `useI18n`**  
   Composable `useI18n` oferuje pełny zestaw funkcji i reaktywnych właściwości do zarządzania tłumaczeniami, obsługi przełączania lokalizacji, formatowania i innych operacji.

- **Dokumentacja**: [useI18n](/api/composables/use-i18n)
