# Wykluczanie plików statycznych z routingu i18n

## Przegląd

Domyślnie nuxt-i18n-micro automatycznie wyklucza popularne pliki statyczne z przetwarzania routingu i18n. Możesz jednak także skonfigurować niestandardowe wzorce wykluczeń, aby zapobiec przetwarzaniu konkretnych ścieżek przez system i18n.

## Wbudowane wykluczenia

Moduł automatycznie wyklucza następujące typy plików i wzorce:

- **Sitemapy**: `/sitemap*.xml`, `/sitemap-en.xml` itd.
- **Pliki SEO**: `/robots.txt`, `/favicon.ico`
- **Pliki PWA**: `/manifest.json`, `/sw.js`, `/workbox-*.js`
- **Zasoby statyczne**: Pliki z rozszerzeniami takimi jak `.xml`, `.txt`, `.ico`, `.json`, `.js`, `.css`, `.png`, `.jpg`, `.jpeg`, `.gif`, `.svg`, `.woff`, `.woff2`, `.ttf`, `.eot`
- **Wewnętrzne ścieżki Nuxt**: Każda ścieżka zaczynająca się od `__` (jak `/__nuxt/`)

## Niestandardowe wzorce wykluczeń

Możesz zdefiniować niestandardowe wzorce wykluczeń, używając opcji `excludePatterns`:

```typescript
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],

  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'it', iso: 'it-IT' },
    ],
    defaultLocale: 'en',

    // Custom exclusion patterns
    excludePatterns: [
      // String patterns (exact match or prefix)
      '/api/health',
      '/admin',

      // String patterns with wildcards
      '/api/*',
      '/admin/**',

      // Regular expressions
      /^\/api\/v\d+\//,
      /\.(pdf|doc|docx)$/,
    ],
  },
})
```

## Typy wzorców

### Wzorce stringowe

- **Dokładne dopasowanie**: `'/api/health'` — dopasowuje dokładnie `/api/health`
- **Dopasowanie prefiksu**: `'/admin'` — dopasowuje `/admin` i `/admin/dashboard`
- **Wildcardy**: `'/api/*'` — dopasowuje `/api/users`, ale nie `/api/users/123`
- **Głębokie wildcardy**: `'/admin/**'` — dopasowuje `/admin/users` oraz `/admin/users/123`

### Wyrażenia regularne

Używaj obiektów RegExp do złożonego dopasowywania wzorców:

```typescript
excludePatterns: [
  /^\/api\/v\d+\//, // API versioned routes
  /\.(pdf|doc|docx)$/, // Document files
  /^\/static\//, // Static directory
  /^\/[a-z]{2}\/api\//, // Localized API routes
]
```

## Przypadki użycia

### Pliki SEO

```typescript
excludePatterns: ['/sitemap.xml', '/sitemap-*.xml', '/robots.txt', '/favicon.ico']
```

### Trasy API

```typescript
excludePatterns: ['/api/**', '/graphql', '/webhook/**']
```

### Panele administratora

```typescript
excludePatterns: ['/admin', '/admin/**', '/dashboard']
```

### Zasoby statyczne

```typescript
excludePatterns: ['/assets/**', '/static/**', '/uploads/**']
```

## Jak to działa

1. **Middleware serwera**: Middleware Nitro uruchamia się jako pierwszy, aby sprawdzić wzorce wykluczeń.
2. **Przetwarzanie stron**: Podczas rozstrzygania stron wykluczone ścieżki są pomijane.
3. **Trasa catch-all**: Trasa fallback sprawdza wykluczenia przed przetworzeniem.
4. **Prerendering**: Wykluczone ścieżki nie są uwzględniane w prerenderowanych trasach.

## Wpływ na wydajność

- Sprawdzenia wykluczeń są zoptymalizowane i wykonywane wcześnie w cyklu życia żądania.
- Wbudowane wzorce używają efektywnego dopasowywania regex.
- Niestandardowe wzorce są cachowane i ponownie wykorzystywane.
- Minimalny narzut wydajnościowy dla wykluczonych ścieżek.

## Rozwiązywanie problemów

### Pliki statyczne wciąż są przechwytywane

1. **Sprawdź składnię wzorca**: Upewnij się, że wzorce dopasowują dokładnie strukturę ścieżek.
2. **Używaj regex dla złożonych wzorców**: Wildcardy stringowe mają ograniczenia.
3. **Testuj wzorce**: Użyj narzędzi deweloperskich przeglądarki, aby zweryfikować faktyczną ścieżkę żądania.
4. **Sprawdź kolejność**: Upewnij się, że wzorce wykluczeń są zdefiniowane przed inną konfiguracją i18n.

### Wzorzec nie działa

```typescript
// ❌ Wrong - this won't work
excludePatterns: ['sitemap.xml']

// ✅ Correct - include leading slash
excludePatterns: ['/sitemap.xml']

// ✅ Better - use regex for flexibility
excludePatterns: [/^\/sitemap.*\.xml$/]
```

### Tryb debug

Włącz tryb debug, aby zobaczyć przetwarzanie wykluczeń:

```typescript
i18n: {
  debug: true,
  excludePatterns: ['/api/**']
}
```

Spowoduje to logowanie decyzji wykluczeń w konsoli.

## Migracja z obejść

Jeśli używałeś obejść, takich jak reguły tras czy middleware, możesz je teraz zastąpić przez `excludePatterns`:

```typescript
// ❌ Old workaround
export default defineNuxtConfig({
  routeRules: {
    '/sitemap*.xml': { headers: { 'content-type': 'application/xml' } },
  },
})

// ✅ New approach
export default defineNuxtConfig({
  i18n: {
    excludePatterns: ['/sitemap*.xml'],
  },
})
```

Nowe podejście jest bardziej niezawodne i działa na wielu poziomach systemu routingu.
