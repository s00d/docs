---
title: "<i18n-group>"
description: "Komponent <i18n-group> przekazuje do swojego slotu funkcję t ograniczoną do prefiksu klucza."
---

`<i18n-group>` ogranicza blok znaczników do jednego prefiksu klucza. Użyj go, gdy wiele kluczy w sekcji ma wspólny prefiks i nie chcesz go powtarzać. Domyślny slot otrzymuje funkcję `t`, która dodaje ten prefiks na początku.

## Właściwości i slot {#props-and-slot}

| Właściwość | Typ | Domyślnie | Opis |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | Prefiks klucza, względem którego rozwiązywane jest każde wyszukiwanie wewnątrz slotu. |
| `groupClass` | `string` | `''` | Dodatkowa klasa elementu opakowującego. |

**\*** wymagane.

### Sloty {#slots}

| Slot | Powiązania | Opis |
| --- | --- | --- |
| `default` | `prefix`, `t` | Otrzymuje `prefix` oraz funkcję `t` ograniczoną do niego. |

## Działanie {#behaviour}

- Renderuje `<div class="i18n-group {groupClass}">` wokół slotu.
- `t(key, params)` to `$t(prefix + '.' + key, params)` dla bieżącej trasy.
- Ograniczona jest tylko funkcja `t` ze slotu: `$t` i zagnieżdżone `<i18n-t>` wewnątrz grupy nadal przyjmują pełne klucze.

## Przykład {#example}

```json
{
  "checkout": { "title": "Checkout", "items": "Items: {count}" }
}
```

```vue
<template>
  <i18n-group prefix="checkout" group-class="checkout">
    <template #default="{ t }">
      <h2>{{ t('title') }}</h2>
      <p>{{ t('items', { count: 3 }) }}</p>
    </template>
  </i18n-group>
</template>
```
