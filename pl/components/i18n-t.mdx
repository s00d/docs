title: "<i18n-t>"

---

`<i18n-t>` renderuje jedno tłumaczenie wewnątrz elementu. Użyj go, gdy tłumaczenie wymaga komponentów w środku (link w zdaniu), formy liczby mnogiej albo sformatowanej liczby lub daty. Rozwiązuje klucz dla bieżącej trasy, tak jak `$t`.

## Właściwości {#props}

| Właściwość | Typ | Domyślnie | Opis |
| --- | --- | --- | --- |
| `keypath` **\*** | `string` | — | Klucz tłumaczenia do wyrenderowania. |
| `plural` | `number \| string \| null` | — | Liczba wybierająca formę liczby mnogiej. Ustaw ją, aby użyć `$tc` zamiast `$t`. `null` oznacza brak wartości. |
| `tag` | `string` | `'span'` | Element do wyrenderowania. |
| `params` | `Record<string, string \| number \| boolean>` | — | Wartości interpolacji wstawiane do tłumaczenia. |
| `defaultValue` | `string` | `''` | Renderowane zamiast komponentu, gdy `hideIfEmpty` ukrywa puste tłumaczenie. |
| `html` | `boolean` | `false` | Renderuje tłumaczenie jako HTML zamiast tekstu. Tylko dla tłumaczeń, które kontrolujesz: `params` są escapowane, tłumaczenie nie. |
| `hideIfEmpty` | `boolean` | `false` | Nie renderuje niczego, gdy tłumaczenie jest pustym ciągiem. |
| `customPluralRule` | `PluralFunc` | `null` | Reguła liczby mnogiej tylko dla tego elementu, nadpisująca skonfigurowaną. Jej wynik jest używany bez zmian; `null` renderuje pustą wartość. |
| `number` | `number \| string \| null` | — | Formatuje wartość za pomocą `$tn` i przekazuje ją do tłumaczenia jako `{number}`, obok `params`. |
| `date` | `Date \| string \| number \| null` | — | Formatuje wartość za pomocą `$td` i przekazuje ją do tłumaczenia jako `{date}`, obok `params`. |
| `relativeDate` | `Date \| string \| number \| null` | — | Formatuje wartość za pomocą `$tdr` i przekazuje ją do tłumaczenia jako `{relativeDate}`, obok `params`. |

**\*** wymagane.

## Zasady renderowania {#rendering-rules}

O wyniku decyduje pierwszy pasujący przypadek:

1. `number` — tłumaczenie z `{ ...params, number: $tn(number) }`.
2. `date` — tłumaczenie z `{ ...params, date: $td(date) }`.
3. `relativeDate` — tłumaczenie z `{ ...params, relativeDate: $tdr(relativeDate) }`.
4. `plural` — forma wybrana przez `$tc`, łącznie ze [znacznikiem `=0 `](/pl/api/methods#$tc), z `{ ...params, count }`; albo `customPluralRule(keypath, count, params, locale, t)`, jeśli jest ustawiona — odczytuje ona surową wartość, łącznie ze znacznikiem, a jej wynik jest używany bez zmian, przy czym `null` oznacza pustą wartość.
5. W przeciwnym razie tłumaczenie z `params`.

`null` jest traktowane jako brak wartości. W każdym przypadku:

- `defaultValue` zastępuje brakujący klucz, w każdej gałęzi.
- `hideIfEmpty` renderuje `defaultValue` zamiast pustego wyniku.
- `html` renderuje wynik jako HTML. `params` są escapowane, tłumaczenie nie; sloty są ignorowane.
- Slot `default` otrzymuje `{ translation }`, a nazwane sloty są ignorowane.
- W przeciwnym razie każdy nazwany slot zastępuje każdy placeholder `{name}`, przed parametrem o tej samej nazwie. Wartość parametru, która wygląda jak placeholder, pozostaje tekstem.

Wynik `date` i `relativeDate` ma atrybut `data-allow-mismatch="text"`, ponieważ strefa czasowa i zegar serwera nie są tymi z przeglądarki. Ustaw [`timeZone`](/pl/api/module-options#timezone), aby renderować tę samą datę kalendarzową w obu miejscach; `relativeDate` zależy od zegara, więc nadal może się różnić.

## Przykład {#example}

```json
{
  "terms": "I accept the {link}.",
  "termsLink": "terms of use",
  "items": "no items | one item | {count} items"
}
```

```vue
<template>
  <i18n-t keypath="terms" tag="p">
    <template #link>
      <NuxtLink :to="$localePath('/terms')">{{ $t('termsLink') }}</NuxtLink>
    </template>
  </i18n-t>

  <i18n-t keypath="items" :plural="cart.length" />
</template>
```

`html` ustawia `innerHTML`: używaj go tylko dla tłumaczeń, które kontrolujesz. `params` są escapowane, więc dane użytkownika są tam bezpieczne, podobnie jak klucz, dla którego nie znaleziono tłumaczenia.
