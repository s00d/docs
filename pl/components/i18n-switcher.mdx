---
title: "<i18n-switcher>"
description: "Komponent <i18n-switcher> to rozwijana lista włączonych locale, z których każde prowadzi do bieżącej strony w tym locale."
---

`<i18n-switcher>` renderuje przycisk z aktywnym locale oraz rozwijaną listę wszystkich włączonych locale, łącznie z aktywnym. Użyj go jako gotowego menu języków; zbuduj własne z [`$getLocales`](/pl/api/methods#$getlocales) i [`$switchLocalePath`](/pl/api/methods#$switchlocalepath), gdy potrzebujesz innego markupu. Każda pozycja prowadzi do bieżącej strony w danym locale.

## Propsy i sloty {#props-and-slots}

| Prop | Typ | Domyślnie | Opis |
| --- | --- | --- | --- |
| `customLabels` | `Record<string, string>` | `() => ({})` | Nazwa wyświetlana dla każdego kodu locale, nadpisująca `displayName` z konfiguracji locale. |
| `customWrapperStyle` | `CSSProperties` | `() => ({})` | Styl inline zewnętrznego wrappera. |
| `customButtonStyle` | `CSSProperties` | `() => ({})` | Styl inline przycisku otwierającego listę rozwijaną. |
| `customDropdownStyle` | `CSSProperties` | `() => ({})` | Styl inline panelu listy rozwijanej. |
| `customItemStyle` | `CSSProperties` | `() => ({})` | Styl inline każdej pozycji listy rozwijanej. |
| `customLinkStyle` | `CSSProperties` | `() => ({})` | Styl inline linku wewnątrz pozycji. |
| `customActiveLinkStyle` | `CSSProperties` | `() => ({})` | Styl inline linku aktualnie aktywnego locale. |
| `customDisabledLinkStyle` | `CSSProperties` | `() => ({})` | Styl inline przycisku *bieżącego* locale, gdy ma ono `disabled: true` w konfiguracji. |
| `customIconStyle` | `CSSProperties` | `() => ({})` | Styl inline ikony strzałki na przycisku. |

### Sloty {#slots}

| Slot | Powiązania | Opis |
| --- | --- | --- |
| `before-button` | — | Treść przed przyciskiem otwierającym listę rozwijaną. |
| `before-selected-locale` | — | Treść przed etykietą aktywnego locale wewnątrz przycisku. |
| `after-selected-locale` | — | Treść po etykiecie aktywnego locale wewnątrz przycisku. |
| `before-dropdown` | — | Treść między przyciskiem a panelem listy rozwijanej. |
| `before-dropdown-items` | — | Treść na górze listy rozwijanej, nad listą locale. |
| `before-item` | `locale` | Treść przed każdą pozycją locale. |
| `before-link-content` | `locale` | Treść przed etykietą locale wewnątrz jego linku. |
| `after-link-content` | `locale` | Treść po etykiecie locale wewnątrz jego linku. |
| `after-item` | `locale` | Treść po każdej pozycji locale. |
| `after-dropdown-items` | — | Treść na dole listy rozwijanej, pod listą locale. |
| `after-dropdown` | — | Treść po panelu listy rozwijanej. |

## Działanie {#behaviour}

- Wyświetla każde locale bez `disabled: true`, łącznie z aktywnym.
- Każda pozycja to `<a>` do `$switchLocalePath(code)`. Ścieżka jest rozwiązywana względem `app.baseURL`; `baseUrl` locale w innej domenie pozostaje absolutne. Ma ustawione `hreflang` i `lang` na `iso || code`, `dir`, gdy locale je ma, `aria-current="page"` na bieżącym locale oraz klasę `switcher-locale-<code>`. Kliknięcie wywołuje `$switchLocale(code)` i zamyka listę; kliknięcie z klawiszem modyfikującym jest pozostawione przeglądarce.
- Lista pozostaje w HTML z serwera, ukryta, więc crawlery widzą linki. Escape lub kliknięcie poza listą ją zamyka.
- Etykieta: `customLabels[code]`, następnie `displayName` locale, a na końcu kod (z ostrzeżeniem w trybie deweloperskim).
- Style: niewielkie domyślne style inline (biały przycisk i panel z obramowaniem, aktywna pozycja pogrubiona i niebieska). Każdy prop `custom*Style` jest stosowany po stylu domyślnym swojej części. Przycisk ma klasy `i18n-switcher-button` i `language-switcher`, wrapper `i18n-switcher-wrapper`, lista `i18n-switcher-dropdown`. Pozycjonowanie używa logicznych właściwości CSS, więc `dir="rtl"` działa.

## Przykład {#example}

```vue
<template>
  <i18n-switcher
    :custom-labels="{ en: 'English', de: 'Deutsch' }"
    :custom-button-style="{ borderRadius: '4px' }"
  >
    <template #before-link-content="{ locale }">
      <img :src="`/flags/${locale.code}.svg`" alt="" width="16" />
    </template>
  </i18n-switcher>
</template>
```
