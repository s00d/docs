# 📚 Esempi e utilizzo di Nuxt I18n Micro

Questa sezione fornisce vari esempi che mostrano come usare `Nuxt I18n Micro` nella tua applicazione Nuxt.js. Vedrai come cambiare locale, come usare i componenti `<i18n-link>`, `<i18n-switcher>` e `<i18n-t>` e come gestire dinamicamente le chiavi di traduzione.

## 🛠️ Configurazione di base

Ecco una configurazione di base per iniziare con `Nuxt I18n Micro`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Cambio locale

### Cambio locale programmatico

Questo esempio mostra come cambiare locale in modo programmatico usando pulsanti:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### JSON di esempio per il cambio locale

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### Uso del componente `<i18n-switcher>`

Il componente `<i18n-switcher>` fornisce un menu a discesa per il cambio locale con etichette personalizzabili:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 🌐 Uso di `<i18n-link>` per la navigazione localizzata

Il componente `<i18n-link>` gestisce automaticamente il routing specifico per la locale:

```vue
<template>
  <div>
    <i18n-link to="/about">{{ $t('about') }}</i18n-link>
    <i18n-link :to="{ name: 'index' }">{{ $t('home') }}</i18n-link>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### JSON di esempio per i link di navigazione

```json
{
  "about": "About Us",
  "home": "Home"
}
```

### Esempio con stile per link attivi

```vue
<template>
  <div>
    <i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
  </div>
</template>
```

### JSON di esempio per lo stile del link attivo

Per questo scenario può essere utilizzato lo stesso file JSON dell'esempio precedente.

## 📝 Rendering di chiavi dinamiche dai file di traduzione

In alcuni scenari potresti voler iterare su chiavi dinamiche memorizzate nei tuoi file di traduzione e renderizzare i loro valori in modo condizionale. L'esempio seguente mostra come farlo con `Nuxt I18n Micro`.

### Esempio: rendering di chiavi dinamiche

Questo esempio recupera un array di chiavi da un percorso di traduzione specifico (in questo caso `dynamic`) e itera su di esse. Ogni chiave viene controllata con `$has` per verificarne l'esistenza prima di renderizzarne il valore con `$t`.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### File di traduzione di esempio (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Esempio: rendering di chiavi dinamiche da un oggetto

In questo esempio gestiamo un oggetto memorizzato nel file di traduzione. Recuperiamo e iteriamo sulle chiavi dell'oggetto, renderizzando dinamicamente sia i nomi delle chiavi sia i valori associati.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### File di traduzione di esempio (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 Uso di `<i18n-t>` per traduzioni con slot e interpolazione

Il componente `<i18n-t>` è utile per renderizzare traduzioni con contenuti dinamici e tag HTML:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### JSON di esempio per `<i18n-t>`

```json
{
  "greeting": "Welcome to the page"
}
```

### Con interpolazione

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### JSON di esempio per l'interpolazione

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 Uso di `$tc` per la pluralizzazione

La funzione `$tc` in `Nuxt I18n Micro` gestisce la pluralizzazione in base al conteggio e alle impostazioni della locale. È utile per adattare dinamicamente messaggi che coinvolgono conteggi, come elementi, notifiche o altre entità che possono variare in numero.

### Esempio: uso di `$tc` per la pluralizzazione

Nell'esempio seguente mostriamo un messaggio che indica il numero di mele usando `$tc`. La chiave di traduzione gestisce più forme plurali in base al conteggio fornito.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### JSON di esempio per la pluralizzazione

Ecco come puoi definire la traduzione nel tuo file JSON per gestire diverse forme plurali:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Spiegazione

- **`$tc('apples', 0)`**: Restituisce la prima forma, usata quando il conteggio è zero (`"no apples"`).
- **`$tc('apples', 1)`**: Restituisce la seconda forma, usata quando il conteggio è uno (`"one apple"`).
- **`$tc('apples', 10)`**: Restituisce la terza forma con il valore del conteggio, usata quando il conteggio è due o più (`"10 apples"`).

### Esempio aggiuntivo con pluralizzazione più complessa

Se la tua applicazione deve gestire regole di pluralizzazione più complesse (ad esempio casi specifici per zero, uno, due, pochi, molti, altro), puoi estendere le stringhe di traduzione di conseguenza:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: Potrebbe essere impostata per restituire `"two apples"`.
- **`$tc('apples', 3)`**: Potrebbe restituire `"a few apples"`, in base alle regole definite per il conteggio.

## 🌐 Uso di `$tn` per la formattazione dei numeri

La funzione `$tn` formatta i numeri secondo la locale corrente usando l'API `Intl.NumberFormat`. È utile per visualizzare i numeri in modo conforme alle impostazioni regionali dell'utente, come valuta, percentuali o altri formati numerici.

### Esempio: uso di `$tn` per la formattazione dei numeri

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ Uso di `$td` per la formattazione di data e ora

La funzione `$td` formatta date e orari secondo la locale corrente usando l'API `Intl.DateTimeFormat`. È utile per mostrare date e orari in formati familiari all'utente in base alle sue impostazioni di locale.

### Esempio: uso di `$td` per la formattazione di data e ora

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ Uso di `$tdr` per la formattazione di date relative

La funzione `$tdr` formatta le date come tempi relativi (ad es., "5 minutes ago", "2 days ago") secondo la locale corrente usando l'API `Intl.RelativeTimeFormat`. È utile per mostrare differenze temporali rispetto alla data e ora correnti.

### Esempio: uso di `$tdr` per la formattazione di date relative

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
