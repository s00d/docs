## 🚀 Avvio rapido

### Installazione

Installa il modulo nella tua applicazione Nuxt:

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

### Configurazione di base

Aggiungi il modulo al tuo `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

<Tip>
- **File a livello root** (`locales/en.json`, ecc.) — traduzioni condivise nell'intera app (menu, footer, UI comune). Con `translationPayloads.mode: 'premerged'` (predefinito), vengono unite in ogni pagina in fase di build.
- **File specifici per pagina** (`locales/pages/<route>/<locale>.json`) — traduzioni uniche per pagine specifiche, caricate solo quando la pagina viene visitata
- **Route dinamiche** — `pages/articles/[id].vue` corrisponde a `locales/pages/articles-id/` (le parentesi vengono sostituite con trattini)
- **Generazione automatica** — tutti i file di traduzione vengono creati automaticamente se mancanti durante `nuxt dev`
</Tip>

<Info>
Il modulo supporta entrambi i layout:

- **Pagine**: `pages/**/*.vue` (Nuxt 3) o `app/pages/**/*.vue` (Nuxt 4)
- **Traduzioni**: mantieni `locales/` nella **root del progetto** per impostazione predefinita (convenzione consigliata), non dentro `app/`

```tree
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   ├── en.json
│   └── pages/
└── nuxt.config.ts
```

Colocazione opzionale: `i18n: \{ translationDir: 'app/locales' \}` (vedi [fixture `n3`](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/n3)).

Per l'helper CLI opzionale `text-to-i18n`, usa [`nuxt-i18n-micro-cli` ≥ 2.1.1](/guides/cli#-text-to-i18n-command) affinché `app/pages` e `app/components` vengano scansionati dalla root del progetto.
</Info>

### Utilizzo di base

Usa le traduzioni nei tuoi componenti:

```vue
<template>
  <div>
    <h1>{{ $t('welcome') }}</h1>
    <p>{{ $t('description', { name: 'World' }) }}</p>

    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" @click="$switchLocale(locale.code)">
        {{ locale.code }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useI18n } from '#imports'

const { $t, $getLocales, $switchLocale } = useI18n()
</script>
```
