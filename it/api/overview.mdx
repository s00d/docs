# Riferimento API

## API runtime

- [Metodi](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, cambio di locale, helper di routing
- [Eventi](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Traduzioni e cache](/api/cache) — `TranslationStorage`, caricamento payload, `$clearCache`

## Middleware del server

Gli handler server utilizzano middleware dedicati (non gli helper `$t` client):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — traduci nelle route API e negli handler server
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — leggi la locale rilevata e i metadati

Consulta la guida completa [Traduzioni lato server](/guides/server-side-translations) per setup, priorità di rilevamento della locale ed esempi.
