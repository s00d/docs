# Riferimento API

## API Runtime

- [Metodi](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, cambio locale, helper di routing
- [Eventi](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Traduzioni e cache](/api/cache) — `TranslationStorage`, caricamento payload, `$clearCache`

## Middleware server

Gli handler server usano middleware dedicati (non gli helper client `$t`):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — traduci nelle rotte API e negli handler server
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — leggi la locale rilevata e i metadati

Consulta la [guida completa sulle traduzioni lato server](/guides/server-side-translations) per configurazione, priorità di rilevamento della locale ed esempi.
