Questa sezione elenca ogni opzione, helper, hook, composable e componente del modulo Nuxt, oltre all'API esportata da ciascun pacchetto `@i18n-micro/*`. Usala per consultare una firma o un valore predefinito; la [Guida](/it/guide/getting-started) spiega come utilizzarli. La maggior parte delle tabelle qui è generata dal codice sorgente, quindi corrisponde al codice.

## Modulo Nuxt {#nuxt-module}

| Pagina | Contenuto |
| --- | --- |
| [Opzioni del modulo](/it/api/module-options) | Ogni chiave `i18n` in `nuxt.config`, con tipo e valore predefinito |
| [Helper](/it/api/methods) | `$t`, `$tc`, `$tn`, `$td`, `$localePath`, `$switchLocale`, `$defineI18nRoute` e il resto |
| [Hook](/it/api/events) | L'hook di runtime `i18n:register` |

## Composable {#composables}

| Composable | Usalo per |
| --- | --- |
| [`useI18n`](/it/composables/useI18n) | Gli helper in `<script setup>` |
| [`useI18nLocale`](/it/composables/useI18nLocale) | Stato del locale e cookie in un plugin di rilevamento personalizzato |
| [`useI18nHead`](/it/composables/useI18nHead) | Override per pagina dei tag SEO generati |
| [`useLocaleHead`](/it/composables/useLocaleHead) | I tag SEO come oggetto, per il tuo `useHead` |

## Componenti {#components}

| Componente | Visualizza |
| --- | --- |
| [`<i18n-t>`](/it/components/i18n-t) | Una traduzione, con plurale, formattazione e interpolazione tramite slot |
| [`<i18n-link>`](/it/components/i18n-link) | Un `NuxtLink` verso la route localizzata |
| [`<i18n-switcher>`](/it/components/i18n-switcher) | Un menu a tendina per i locale |
| [`<i18n-group>`](/it/components/i18n-group) | Un blocco con un prefisso di chiave condiviso |

## Server {#server}

Gli handler Nitro usano `useTranslationServerMiddleware` e `useLocaleServerMiddleware`, non gli helper client. Vedi [Route server](/it/guide/server-side-translations).

## Pacchetti {#packages}

[API dei pacchetti](/it/api/packages/overview) elenca gli export di ogni pacchetto `@i18n-micro/*`, con una pagina generata per ciascuno.
