## Flag comuni {#common-flags}

| Flag | Predefinito | Descrizione |
| --- | --- | --- |
| `--cwd` | directory corrente | Directory del progetto |
| `--logLevel` | `info` | Livello di output: silent, info |
| `--debug` | `false` | Stampa uno stack trace quando un comando fallisce |

## Ispezione {#inspect}

### `info` {#info}

Stampa la configurazione i18n risolta del progetto

| Flag | Predefinito | Descrizione |
| --- | --- | --- |
| `--json` | `false` | Stampa JSON invece di testo |

### `check` {#check}

Il gate di CI: fallisce in caso di chiavi mancanti, vuote, in eccesso, non definite o inutilizzate e di placeholder non validi

| Flag | Predefinito | Descrizione |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` di nuxt.config | Directory delle traduzioni, relativa al progetto |
| `--only` | tutti tranne duplicates | Controlli da eseguire, separati da virgole: missing, empty, extra, placeholders, undefined, unused, duplicates. `unused`, se indicato qui, fallisce quando non può essere eseguito |
| `--duplicates` | `false` | Segnala anche lo stesso testo sotto chiavi diverse |
| `--ignore` | — | Glob separati da virgole dei file sorgente da saltare, relativi al progetto |
| `--json` | `false` | Stampa JSON invece di testo |

```bash
i18n-micro check
i18n-micro check --only missing,placeholders --json
```

### `stats` {#stats}

Mostra il completamento delle traduzioni per locale

| Flag | Predefinito | Descrizione |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` di nuxt.config | Directory delle traduzioni, relativa al progetto |
| `--html` | — | Scrive anche un report HTML in questo file |
| `--json` | `false` | Stampa JSON invece di testo |
| `--baseRef` | — | Ref Git con cui confrontare il completamento, ad es. HEAD~1 o main |

```bash
i18n-micro stats --baseRef main
i18n-micro stats --html reports/i18n.html
```

### `lint` {#lint}

Controlla il testo delle traduzioni; fallisce quando restano problemi

| Flag | Predefinito | Descrizione |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` di nuxt.config | Directory delle traduzioni, relativa al progetto |
| `--rules` | tutte, oppure `enabledRules` di .i18n-lintrc.json | Regole da eseguire, separate da virgole: no-trailing-spaces, no-multiple-spaces, no-empty-translation o una regola personalizzata |
| `--fix` | `false` | Corregge ciò che è correggibile: spazi e regole personalizzate con una sostituzione |
| `--json` | `false` | Stampa JSON invece di testo |

```bash
i18n-micro lint --rules no-trailing-spaces --fix
```

### `search` {#search}

Cerca chiavi e valori e mostra dove viene usata ogni chiave

| Flag | Predefinito | Descrizione |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` di nuxt.config | Directory delle traduzioni, relativa al progetto |
| `<query>` | — | Testo o chiave da cercare |
| `--caseSensitive` | `false` | Distingue maiuscole e minuscole |
| `--onlyUnused` | `false` | Solo le chiavi che `clean` rimuoverebbe; la query diventa facoltativa |
| `--scope` | `all` | Dove cercare: global, pages, all |
| `--limit` | — | Restituisce al massimo questo numero di chiavi |
| `--ignore` | — | Glob separati da virgole dei file sorgente da saltare, relativi al progetto |
| `--json` | `false` | Stampa JSON invece di testo |

```bash
i18n-micro search "Welcome"
i18n-micro search --onlyUnused
```

## Flusso di traduzione {#translation-workflow}

### `extract` {#extract}

Elenca le chiavi usate dai file sorgente che non hanno ancora un testo e aggiunge quelle con un testo predefinito al locale predefinito

| Flag | Predefinito | Descrizione |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` di nuxt.config | Directory delle traduzioni, relativa al progetto |
| `--ignore` | — | Glob separati da virgole dei file sorgente da saltare, relativi al progetto |

```bash
i18n-micro extract
```

### `translate` {#translate}

Compila le traduzioni mancanti a partire dal locale predefinito tramite un servizio di traduzione

| Flag | Predefinito | Descrizione |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` di nuxt.config | Directory delle traduzioni, relativa al progetto |
| `--service` | — | Servizio di traduzione: ai, azure, deepl, google, libretranslate, yandexcloud |
| `--token` | — | Chiave API. Preferisci la variabile d'ambiente I18N_TRANSLATE_TOKEN: i flag finiscono nella cronologia della shell |
| `--options` | — | Opzioni del servizio come coppie key:value, separate da virgole |
| `--locale` | tutti i locale tranne quello predefinito | Locale da compilare, separati da virgole |
| `--replace` | `false` | Traduce di nuovo ogni chiave, sostituendo i valori esistenti |
| `--dryRun` | `false` | Conta chiavi e caratteri per locale; non invia nulla |
| `--chunkSize` | — | Stringhe per richiesta; limitato a quanto accetta il servizio |
| `--pluralSeparator` | `\|` | Separatore delle forme plurali nei messaggi |
| `--glossaryFile` | `.i18n-glossary.json` quando esiste | File di glossario, usato dal servizio `ai` |

```bash
i18n-micro translate --dryRun
I18N_TRANSLATE_TOKEN=... i18n-micro translate --service deepl --locale de,fr
i18n-micro translate --service ai --options provider:openai,model:gpt-4o-mini
i18n-micro translate --service libretranslate --options baseUrl:https://translate.example.com
```

### `sync` {#sync}

Rimuove le chiavi che il locale predefinito non ha; si ferma quando non si può dimostrare che sia sicuro. Le chiavi mancanti restano mancanti

| Flag | Predefinito | Descrizione |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` di nuxt.config | Directory delle traduzioni, relativa al progetto |
| `--ignore` | — | Glob separati da virgole dei file sorgente da saltare, relativi al progetto |
| `--dryRun` | `false` | Elenca ciò che verrebbe rimosso; non scrive nulla |
| `--force` | `false` | Rimuove le chiavi anche se non si può dimostrare che sia sicuro |

```bash
i18n-micro sync --dryRun
```

### `clean` {#clean}

Rimuove le chiavi che nulla nel progetto usa; si ferma quando non lo si può dimostrare

| Flag | Predefinito | Descrizione |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` di nuxt.config | Directory delle traduzioni, relativa al progetto |
| `--include` | — | Espressione regolare: considera per la rimozione solo le chiavi corrispondenti |
| `--exclude` | — | Espressione regolare: non rimuove mai le chiavi corrispondenti |
| `--ignore` | — | Glob separati da virgole dei file sorgente da saltare, relativi al progetto |
| `--dryRun` | `false` | Elenca ciò che verrebbe rimosso; non scrive nulla |
| `--force` | `false` | Rimuove le chiavi anche se l'utilizzo non può essere dimostrato per tutte |

```bash
i18n-micro clean --dryRun
i18n-micro clean --exclude '^errors\.'
```

## Refactoring {#refactoring}

### `text-to-i18n` {#text-to-i18n}

Sostituisce il testo hardcoded nei template Vue con chiamate di traduzione e segnala il testo hardcoded nel codice

| Flag | Predefinito | Descrizione |
| --- | --- | --- |
| `--translationFile` | `<translationDir>/<defaultLocale>.json` | File in cui finiscono le nuove chiavi |
| `--path` | l'intero progetto | File o directory da elaborare |
| `--context` | — | Prefisso per le chiavi generate |
| `--ignore` | — | Glob separati da virgole dei file sorgente da saltare, relativi al progetto |
| `--dryRun` | `false` | Mostra cosa cambierebbe; non scrive nulla |
| `--interactive` | `false` | Conferma o modifica ogni chiave generata |

```bash
i18n-micro text-to-i18n --dryRun
i18n-micro text-to-i18n --path components --context ui
```

### `rename` {#rename}

Rinomina una chiave o un namespace in ogni locale e nei file sorgente

| Flag | Predefinito | Descrizione |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` di nuxt.config | Directory delle traduzioni, relativa al progetto |
| `--from` **\*** | — | Chiave o namespace attuale |
| `--to` **\*** | — | Nuova chiave o namespace |
| `--ignore` | — | Glob separati da virgole dei file sorgente da saltare, relativi al progetto |
| `--dryRun` | `false` | Segnala le modifiche; non scrive nulla |

**\*** obbligatorio.

```bash
i18n-micro rename --from common.save --to actions.save
```

### `pseudo` {#pseudo}

Compila un locale con pseudo-traduzioni per trovare problemi di layout e di testo hardcoded

| Flag | Predefinito | Descrizione |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` di nuxt.config | Directory delle traduzioni, relativa al progetto |
| `--sourceLocale` | il locale predefinito | Locale da leggere |
| `--targetLocale` **\*** | — | Locale da compilare |
| `--replace` | `false` | Sovrascrive i valori esistenti |

**\*** obbligatorio.

### `format` {#format}

Riscrive i file di locale con chiavi ordinate e indentazione uniforme

| Flag | Predefinito | Descrizione |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` di nuxt.config | Directory delle traduzioni, relativa al progetto |
| `--indent` | `2` | Spazi di indentazione |
| `--sortKeys` | `true` | Ordina le chiavi; usa --no-sortKeys per mantenerne l'ordine |
| `--check` | `false` | Fallisce se un file cambierebbe; non scrive nulla |

```bash
i18n-micro format --check
```

## Scambio {#exchange}

### `export` {#export}

Esporta i file di locale in PO o CSV, con il testo del locale predefinito come sorgente

| Flag | Predefinito | Descrizione |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` di nuxt.config | Directory delle traduzioni, relativa al progetto |
| `--format` | `po` | Formato del file: po, csv |
| `--dir` | `pots` per po, `csv_exports` per csv | Directory di output, relativa al progetto |
| `--force` | `false` | Sovrascrive i file modificati dopo l'ultima esportazione e mai importati |

```bash
i18n-micro export --format csv
```

### `import` {#import}

Unisce i file PO o CSV nei file di locale

| Flag | Predefinito | Descrizione |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` di nuxt.config | Directory delle traduzioni, relativa al progetto |
| `--format` | `po` | Formato del file: po, csv |
| `--dir` | `pots` per po, `csv_exports` per csv | Directory di input, relativa al progetto |
| `--dryRun` | `false` | Segnala cosa verrebbe importato; non scrive nulla |

```bash
i18n-micro import --format csv --dryRun
```

### `sync-remote` {#sync-remote}

Scarica le traduzioni globali dall'endpoint HTTP in .i18n-remote.json, o le invia a esso

| Flag | Predefinito | Descrizione |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` di nuxt.config | Directory delle traduzioni, relativa al progetto |
| `--pull` | `true` | Scarica dal remoto |
| `--push` | `false` | Invia al remoto |
| `--force` | `false` | In un pull, prende il valore remoto; in un push, sovrascrive il testo presente solo sul remoto |
| `--dryRun` | `false` | Segnala cosa cambierebbe un pull; non scrive e non invia nulla |

```bash
i18n-micro sync-remote --dryRun
i18n-micro sync-remote --no-pull --push
```

## Regole di lint {#lint-rules}

| Regola | Trova | Corretta da `--fix` |
| --- | --- | --- |
| `no-trailing-spaces` | Spazi alla fine di un valore o di una riga | sì |
| `no-multiple-spaces` | Due o più spazi consecutivi | sì |
| `no-empty-translation` | Un valore vuoto o composto solo da spazi | no |

## Codici di uscita {#exit-codes}

| Codice | Significato |
| --- | --- |
| `0` | Completato, nulla da segnalare |
| `1` | Rilevamenti: `check`, `lint` o `format --check` hanno trovato qualcosa, `clean` o `sync` non hanno potuto dimostrare che una rimozione fosse sicura, `export` sovrascriverebbe lavoro non importato, `translate` ha tralasciato delle chiavi, `import` o `sync-remote` hanno incontrato un conflitto, un push di `sync-remote` eliminerebbe testo remoto. Un `--dryRun` di `clean`, `sync` o di un pull di `sync-remote` segnala questi casi ed esce con `0` |
| `2` | Errore: uso scorretto, progetto illeggibile, errore di rete o di file |

## File di configurazione {#configuration-files}

| File | Usato da |
| --- | --- |
| `.i18n-lintrc.json` | `lint`: `enabledRules`, `disabledRules`, `customRegexRules` (`name`, `pattern`, `flags`, `description`, `replacement`) |
| `.i18n-remote.json` | `sync-remote`: `url`, `path`, `token`, `auth` (`username`, `password`). `type` può essere omesso; esiste solo `custom` |
| `.i18n-glossary.json` | `translate --service ai`: `entries` con `source`, `target` e, facoltativi, `from`, `to` |

## Variabili d'ambiente {#environment-variables}

| Nome | Usata per |
| --- | --- |
| `I18N_TRANSLATE_TOKEN` | Chiave API di `translate`. Letta anche da `.env` |
| `I18N_REMOTE_TOKEN` | Bearer token di `sync-remote`. Letto anche da `.env` |
| `AI_GATEWAY_API_KEY, OPENAI_API_KEY, ANTHROPIC_API_KEY` | Chiave del servizio `ai`, quando `I18N_TRANSLATE_TOKEN` non è impostata |
| `DEFAULT_LOCALE` | Sovrascrive `defaultLocale`, come nel modulo |
