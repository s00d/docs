title: "API dei pacchetti"
description: "L'API esportata di ogni pacchetto @i18n-micro/*, generata dagli snapshot API che la CI verifica rispetto al codice sorgente."

Il modulo Nuxt è costruito a partire da piccoli pacchetti `@i18n-micro/*`, e la maggior parte di essi funziona anche da sola: `@i18n-micro/vue` in un'app Vue, `@i18n-micro/core` ovunque. Usa queste pagine per consultare cosa esporta un pacchetto, per ogni entry point. Ogni pagina è generata dallo snapshot che [`pnpm run api:surface`](https://s00d.github.io/nuxt-i18n-micro/contributing/maintenance-commands#api-surface) verifica rispetto ai sorgenti TypeScript, quindi un export non può cambiare senza che la CI se ne accorga.
