# 🛠️ Composable `useI18n`

Il composable `useI18n` in `Nuxt I18n Micro` fornisce accesso alla maggior parte degli helper i18n runtime in componenti e script. I metodi sono disponibili **con e senza il prefisso `$`** (ad esempio `$t` e `t`).

Alcune iniezioni — `$defineI18nRoute` e `$clearCache` — sono disponibili solo su `useNuxtApp()`. Consulta [Metodi — `$defineI18nRoute`](/api/methods#definei18nroute) e [`$clearCache`](/api/methods#clearcache).

## 📊 Cosa restituisce

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Ogni helper runtime, come oggetto semplice.

Le stesse funzioni che il plugin inietta come `$t`, `$tc` e così via, disponibili sia
con il nome prefissato dal dollaro sia con un alias senza prefisso, quindi `const \{ t \} = useI18n()` e
`const \{ $t \} = useI18n()` funzionano entrambi.

**Restituisce** — gli helper descritti nel [riferimento dei metodi](/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

Ogni helper restituito — `$t`, `$tc`, `$has`, `$switchLocale` e gli altri — è elencato
con la sua firma e documentato per intero nel [Riferimento dei metodi](/api/methods).

## API disponibili solo su `useNuxtApp()`

Queste **non** vengono restituite da `useI18n()`. Importale da `useNuxtApp()`:

| Metodo                     | Scopo                                                                           |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Route per pagina localizzate, restrizioni e traduzioni inline in `script setup` |
| `$clearCache()`            | Svuota la cache in-memory delle traduzioni e i chunk caricati                   |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Consulta [Metodi](/api/methods) per firme complete ed esempi.

## 🛠️ Esempi d'uso

### Recupero base della locale

Recupera la locale corrente dell'applicazione.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Traduzione con parametri

Traduci una stringa con parametri dinamici, con un valore di fallback predefinito.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Cambiare locale

Cambia l'applicazione su una locale diversa.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Generare una route localizzata

Genera una route localizzata nella locale corrente o specificata.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
