# 🌍 Componente `<i18n-switcher>`

Il componente `<i18n-switcher>` in `Nuxt I18n Micro` fornisce un'interfaccia dropdown user-friendly per passare tra diverse locale nella tua applicazione. Questo componente è altamente personalizzabile e consente un'integrazione fluida con il design e il layout della tua applicazione.

Le locale con `disabled: true` sono **omesse** dal dropdown (restano disponibili tramite `$getLocales()` per SEO / head tag). Solo le locale abilitate al cambio ricevono `NuxtLink` + `hreflang`.

Ogni parte è priva di stile per impostazione predefinita: le prop `custom*Style` accettano oggetti di stile inline, mentre
gli slot qui sotto sostituiscono interamente il markup quando lo stile non basta.

## 🛠️ Esempi d'uso

### Utilizzo di base

```vue
<template>
  <i18n-switcher />
</template>
```

Questo renderizza un selettore di locale con stile e comportamento predefiniti.

### Etichette personalizzate e stili inline

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Questo esempio mostra un selettore di locale completamente personalizzato con etichette custom e stili inline.

## 🔌 Slot

Ogni parte visiva dello switcher può essere sostituita. Gli slot sono elencati con la tabella
delle prop qui sopra; ciascuno accetta contenuto di template:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Gli slot il cui nome termina in `-item`, `-link-content` o inizia con `before-item` ricevono l'oggetto
`locale` a cui appartengono.

## 🎨 Panoramica degli stili

Il componente `<i18n-switcher>` include stili di base definiti tramite stili inline che possono essere facilmente sovrascritti passando stili personalizzati via prop. Ecco una breve panoramica dello stile predefinito:

- **Wrapper**: controlla il posizionamento del dropdown.
- **Pulsante**: stila il pulsante di apertura del dropdown.
- **Dropdown**: stila la lista del dropdown.
- **Elementi**: stila ogni elemento della lista.
- **Link**: stila i link all'interno di ogni elemento.
- **Icona**: stila l'icona che indica il dropdown.

Puoi personalizzare questi stili passando stili custom tramite le relative prop, garantendo che il selettore di locale si integri perfettamente nella UI della tua applicazione.
