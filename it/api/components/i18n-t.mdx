# 🌍 Componente `<i18n-t>`

Il componente `<i18n-t>` in `Nuxt I18n Micro` è un componente di traduzione flessibile che supporta l'inserimento di contenuto dinamico tramite slot. Ti permette di interpolare traduzioni con componenti Vue o contenuti HTML personalizzati, abilitando scenari di localizzazione avanzati.

## ⚙️ Props

| `keypath` **\*** | `string` | — | Chiave di traduzione da renderizzare. |
| `plural` | `number \| string` | — | Numero che seleziona la forma plurale. Impostalo per usare `$tc` invece di `$t`. |
| `tag` | `string` | `'span'` | Elemento da renderizzare. |
| `params` | `Record<string, string \| number \| boolean>` | `() => (\{\})` | Valori di interpolazione sostituiti nella traduzione. |
| `defaultValue` | `string` | `''` | Renderizzato al posto del componente quando `hideIfEmpty` sopprime una traduzione vuota. |
| `html` | `boolean` | `false` | Renderizza la traduzione come HTML anziché come testo. Solo per contenuti che controlli. |
| `hideIfEmpty` | `boolean` | `false` | Non renderizza nulla quando la traduzione risolve a stringa vuota. |
| `customPluralRule` | `PluralFunc` | `null` | Regola plurale per questo elemento soltanto, che sovrascrive quella configurata. |
| `number` | `number \| string` | — | Formatta il valore con `$tn` e lo passa alla traduzione come `\{number\}`. |
| `date` | `Date \| string \| number` | — | Formatta il valore con `$td` e lo passa alla traduzione come `\{date\}`. |
| `relativeDate` | `Date \| string \| number` | — | Formatta il valore con `$tdr` e lo passa alla traduzione come `\{relativeDate\}`. |

**\*** obbligatorio.

{/* /generated:component:i18n-t */}

Solo una tra `plural`, `number`, `date` e `relativeDate` si applica per volta; quando ne sono impostate
più di una, vince la prima in quell'ordine.

### Esempi per prop

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

## 🛠️ Esempi d'uso

### Utilizzo di base

```vue
<i18n-t keypath="feedback.text" />
```

Questo renderizza la traduzione per `feedback.text` all'interno di un tag `<span>`.

### Usare gli slot per contenuto dinamico

Il componente `<i18n-t>` supporta l'uso di slot per inserire dinamicamente componenti Vue o altro contenuto in parti specifiche della traduzione.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

In questo esempio, il placeholder `\{link\}` nella stringa di traduzione `feedback.text` viene sostituito dal componente `<nuxt-link>`, che a sua volta contiene un altro componente di traduzione.

### Pluralizzazione

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

Questo applica automaticamente le regole di pluralizzazione in base al valore di `itemCount`.

## 🚀 Funzionalità aggiuntive

### Slot predefinito

Se non viene fornito nessuno slot specifico, la traduzione può essere personalizzata tramite lo slot predefinito, che fornisce l'intera stringa tradotta:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### Rendering condizionale

Non renderizza nulla se la stringa di traduzione è vuota utilizzando la prop `hideIfEmpty`.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### Regola di pluralizzazione personalizzata

Usa una funzione personalizzata per gestire la pluralizzazione.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### Esempio avanzato con slot

Usa gli slot per personalizzare come il contenuto della traduzione viene renderizzato.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
