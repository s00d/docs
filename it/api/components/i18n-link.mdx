# 🌍 Componente `<i18n-link>`

Il componente `<i18n-link>` in `Nuxt I18n Micro` è un componente link versatile che localizza automaticamente le route in base alla locale corrente. Funziona come wrapper del componente `<NuxtLink>`, fornendo funzionalità aggiuntive come lo stile del link attivo e il supporto per link esterni.

## ⚙️ Props

| Prop | Tipo | Predefinito | Descrizione |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | Route di destinazione. Localizzata automaticamente; un URL esterno viene passato inalterato. |
| `activeStyle` | `Partial<CSSStyleValue>` | — | Stile inline applicato quando il link punta alla route corrente. |

**\*** obbligatorio.

### Slot

| Slot | Binding | Descrizione |
| --- | --- | --- |
| `default` | — | Contenuto del link. |

{/* /generated:component:i18n-link */}

`to` accetta qualsiasi cosa accetti `NuxtLink`: un path, una named route o un oggetto route risolto.
Un URL assoluto viene rilevato e renderizzato come un semplice `<a target="_blank" rel="noopener noreferrer">`,
invece di essere localizzato.

## 🛠️ Esempi d'uso

### Utilizzo di base

```vue
<i18n-link to="/about">About Us</i18n-link>
```

Questo esempio crea un link alla pagina `/about`, localizzato nella locale corrente.

### Stile del link attivo con stili inline

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

Il link avrà testo in grassetto quando l'utente si trova sulla pagina `/about`, permettendoti di applicare stili al link attivo direttamente con stili inline.

### Gestione dei link esterni

Il componente rileva automaticamente i link esterni e aggiunge gli attributi necessari per la sicurezza.

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

Questo link aprirà `https://example.com` in una nuova scheda con `rel="noopener noreferrer"` applicato.

## 🎨 Stili

Il componente ora utilizza stili inline per lo stato attivo invece di una classe. Puoi personalizzare questi stili usando la prop `activeStyle`.

### Stili attivi predefiniti

- **Font Weight**: `bold`
- **Colore**: eredita il colore predefinito del browser (se non è specificato alcun `color` in `activeStyle`).

Puoi sovrascriverli fornendo stili personalizzati tramite la prop `activeStyle`.

### Stili attivi personalizzati

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

In questo esempio, il link sarà in grassetto e verde quando è attivo.

## 🚀 Funzionalità aggiuntive

### Slot per contenuto personalizzato

Puoi passare contenuto personalizzato all'interno del link usando gli slot, rendendo il componente flessibile per diversi casi d'uso.

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### Miglioramenti di accessibilità

Il componente supporta `aria-label` e altri attributi di accessibilità per garantire un'esperienza più accessibile.

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
