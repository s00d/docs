# 🛠️ Metodi

Questa pagina documenta tutti i metodi disponibili forniti da nuxt-i18n-micro. I metodi sono organizzati per funzionalità per una navigazione più agevole.

## 🔍 Metodi di traduzione

Metodi principali per recuperare e gestire le traduzioni.

### `$t`

{/* generated:method:$t — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Traduci una chiave, interpolando `params` al suo interno. Restituisce `defaultValue` quando la chiave è
mancante, o la chiave stessa quando non è fornito alcun default.

{/* /generated:method:$t */}

```typescript
const welcomeMessage = $t('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

<Warning>
`$t` restituisce `CleanTranslation`, ovvero `string | number | boolean | Translations | PluralTranslations | null`. Se la chiave punta a un **oggetto annidato** nel tuo JSON (ad esempio `$t('header')` quando il JSON contiene `\{ "header": \{ "title": "Hi" \} \}`), il valore restituito sarà quell'**oggetto**, non una stringa. Usarlo direttamente in un template Vue (<code v-pre>\{\{ $t('header') \}\}</code>) verrà renderizzato come `[object Object]`.

**Come evitarlo:**

- Usa una chiave più specifica: `$t('header.title')` → `"Hi"`
- Usa `$ts()` che restituisce sempre una stringa (chiama `.toString()` sui non-stringa)
- Usa `$t` con una chiave annidata per accedere intenzionalmente a sotto-oggetti per uso programmatico
</Warning>

### `$ts`

{/* generated:method:$ts — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string) => string
```

Come `$t`, ma restituisce sempre una stringa: un valore oggetto o array viene stringificato invece
di essere restituito così com'è.

{/* /generated:method:$ts */}

```typescript
const welcomeMessage = $ts('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

### `$_t` e `$_ts`

{/* generated:method:$_t — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Lega `$t` a una route specifica, per tradurre fuori dalla pagina corrente. Ad esempio, un layout che rende
un link a un'altra route.

{/* /generated:method:$_t */}

{/* generated:method:$_ts — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => string
```

Lega `$ts` a una route specifica. Consulta `$_t`.

{/* /generated:method:$_ts */}

Varianti legate alla route di `$t` e `$ts`. Prendono per primo una **route** e restituiscono una funzione di traduzione bloccata sulla locale e sul contesto pagina di quella route.

- **Accesso**: `useNuxtApp()` (anche ri-esportate da `useI18n()` come `$_t` / `$_ts`)

Usali quando la route attiva durante SSR o le transizioni differisce da `router.currentRoute`. Ad esempio, all'interno di `<i18n-t>`, `<i18n-group>` o quando renderizzi contenuto per un oggetto `route` specifico.

```typescript
import { useRoute, useNuxtApp } from '#imports'

const route = useRoute()
const { $_t, $_ts } = useNuxtApp()

const $t = $_t(route)
const title = $t('page.title')

// String-safe variant
const label = $_ts(route)('page.label')
```


### `$tc`

{/* generated:method:$tc — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params: number | Params, defaultValue?: string) => string
```

Traduci con pluralizzazione. `params` può essere il conteggio stesso, o un oggetto contenente
`count`.

{/* /generated:method:$tc */}

**Formato di traduzione**: forme separate da `|`. Metti i placeholder in **ogni** forma:

```json
{
  "apples": "no apples | one apple | {count} apples",
  "cart": "no items for {name} | one item for {name} | {count} items for {name}"
}
```

```typescript
$tc('apples', 0) // "no apples"
$tc('apples', 1) // "one apple"
$tc('apples', 10) // "10 apples"

// count + other params (second argument must be an object)
$tc('cart', { count: 10, name: 'Alice' }) // "10 items for Alice"
```


**Alternativa con componente** — `<i18n-t keypath="cart" :plural="count" :params="\{ name \}" />` (unisce `count` con `params` internamente).


### `$mergeTranslations`

{/* generated:method:$mergeTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
(newTranslations: Translations) => void
```

Unisci le traduzioni nella locale attiva a runtime, sovrascrivendo ciò che è caricato.

{/* /generated:method:$mergeTranslations */}

```typescript
$mergeTranslations({
  welcome: 'Bienvenue, {username}!',
})
// Output: Updates the translation cache with the new French translation
```

### `$resolveTranslations`

{/* generated:method:$resolveTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
() => Translations
```

Ogni traduzione attualmente in memoria per la locale e la route attive, come albero.
Vista in sola lettura di ciò che `$t()` può risolvere in questo momento.

{/* /generated:method:$resolveTranslations */}

```typescript
const tree = $resolveTranslations()
// { aaa: { bbb: 'ccc' }, ddd: 1111 } — the same dictionary $t() reads from
```

Usa questo quando hai bisogno del dizionario completo in memoria (DevTools, test, editor runtime). Tratta il valore restituito come sola lettura; modifica i valori tramite `$setTranslation` o unisci patch con `$mergeTranslations`.

### `$setTranslation`

{/* generated:method:$setTranslation — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, value: unknown) => void
```

Sostituisci il valore in `key` nel dizionario attivo. Questo è un replace, non un merge.
Usa `$mergeTranslations` quando i sibling esistenti devono sopravvivere.

{/* /generated:method:$setTranslation */}

```typescript
$setTranslation('aaa', { fff: 'ggg' }) // replaces the whole `aaa` subtree
$setTranslation('aaa', 'text')          // replaces `aaa` with a string
$setTranslation('ddd', 1111)            // scalar at the top level
$setTranslation('aaa.bbb', 'nested')    // dotted path
```

Questo è un **replace**, non un merge. I sibling esistenti sotto la stessa chiave vengono rimossi. Per applicare una patch senza perdere i sibling, usa `$mergeTranslations`.

### `$setMissingHandler`

{/* generated:method:$setMissingHandler — do not edit; run `pnpm run docs:generate` */}

```ts
(handler: MissingHandler | null) => void
```

Installa una callback invocata per ogni chiave non risolta. Passa `null` per rimuoverla.

{/* /generated:method:$setMissingHandler */}

**Definizione del tipo**:

```typescript
type MissingHandler = (locale: string, key: string, routeName: string, instance?: unknown, type?: string) => void
```

```typescript
// Set a custom handler
$setMissingHandler((locale, key, routeName) => {
  console.error(`Missing translation: ${key} in ${locale} for route ${routeName}`)
  // Send to Sentry or other error tracking service
  // Sentry.captureMessage(`Missing translation: ${key}`)
})

// Remove the handler
$setMissingHandler(null)
```

**Casi d'uso**:

- Registrare traduzioni mancanti in servizi di tracciamento errori (Sentry, LogRocket, ecc.)
- Raccogliere analytics sulle traduzioni mancanti
- Gestione custom degli errori per chiavi di traduzione mancanti

## 🔢 Formattazione di numeri e date

Metodi per formattare numeri e date secondo le convenzioni della locale.

### `$tn`

{/* generated:method:$tn — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Formatta un numero con `Intl.NumberFormat` nella locale attiva. Una chiave seleziona un formato named
dalla config.

{/* /generated:method:$tn */}

```typescript
// Inline options
const formattedNumber = $tn(1234567.89, { style: 'currency', currency: 'USD' })
// "$1,234,567.89"

// Named format (from nuxt.config i18n.numberFormats)
const price = $tn(1000, 'currency')
const priceDe = $tn(1000, 'currency', 'de')
const compact = $tn(1000, 'currency', { notation: 'compact' })
```

Chiavi di formato named sconosciute ricadono sulle opzioni predefinite di `Intl.NumberFormat`. In sviluppo (client), viene emesso un `console.warn` quando `missingWarn` è abilitato (predefinito).

**Esempio di config**:

```ts
export default defineNuxtConfig({
  i18n: {
    numberFormats: {
      en: {
        currency: { style: 'currency', currency: 'USD' },
        decimal: { style: 'decimal', minimumFractionDigits: 2, maximumFractionDigits: 2 },
      },
      de: {
        currency: { style: 'currency', currency: 'EUR' },
      },
    },
  },
})
```

**Casi d'uso**:

- Formattare numeri come valuta, percentuali o decimali nel formato appropriato per la locale
- Riutilizzare formati named nell'app (parità con la migrazione da Vue I18n)

### `$td`

{/* generated:method:$td — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Formatta una data con `Intl.DateTimeFormat` nella locale attiva. Una chiave seleziona un formato named
dalla config.

{/* /generated:method:$td */}

```typescript
const formattedDate = $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' })
// "Friday, September 1, 2023"

const short = $td(new Date(), 'short')
const longDe = $td(new Date(), 'long', 'de')
```

Chiavi di formato named sconosciute ricadono sulle opzioni predefinite di `Intl.DateTimeFormat`. In sviluppo (client), viene emesso un `console.warn` quando `missingWarn` è abilitato (predefinito).

**Esempio di config**:

```ts
export default defineNuxtConfig({
  i18n: {
    datetimeFormats: {
      en: {
        short: { year: 'numeric', month: 'short', day: 'numeric' },
        long: { year: 'numeric', month: 'long', day: 'numeric', weekday: 'long' },
      },
    },
  },
})
```

**Casi d'uso**:

- Visualizzare date in un formato allineato con la locale dell'utente
- Condividere preset short/long/date-time in tutta l'app

### `$tdr`

{/* generated:method:$tdr — do not edit; run `pnpm run docs:generate` */}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

Formatta una data come tempo relativo ("3 giorni fa") con `Intl.RelativeTimeFormat`.

{/* /generated:method:$tdr */}

```typescript
const relativeDate = $tdr(new Date(Date.now() - 1000 * 60 * 5))
// Output: "5 minutes ago" in the 'en-US' locale
```

```ts

```

Naviga a un'altra route, mantenendo la locale attiva o passando a `toLocale`.

{/* /generated:method:$switchRoute */}

**Esempi**:

<CodeGroup>

## 🚦 Configurazione della route

Metodi per configurare il comportamento e il controllo degli accessi delle route.

### `$defineI18nRoute`

{/* generated:method:$defineI18nRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Registra la configurazione locale per pagina e le traduzioni dall'interno di un componente.
Si fonde nella locale attiva e viene applicato nuovamente quando la locale cambia.

{/* /generated:method:$defineI18nRoute */}

> [!IMPORTANT]
> `$defineI18nRoute` è fornito dal **define plugin** ed è disponibile solo su `useNuxtApp()`. **Non** fa parte dell'oggetto restituito da `useI18n()`.
> Fai sempre destructuring da `useNuxtApp()` all'interno di `script setup`. Chiamare `$defineI18nRoute(...)` come globale nudo lancia `"$defineI18nRoute is not defined"` durante SSR/prerender.

**Parametri**:

- **locales**: `string[] | Record<string, Record<string, string>>` — Locale disponibili per la route
- **localeRoutes**: `Record<string, string>` — Opzionale. Route personalizzate per locale specifiche
- **disableMeta**: `boolean | string[]` — Opzionale. Disabilita i meta tag i18n per tutte le locale o solo per alcune

**Esempio di base**:

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
```

### `$setI18nRouteParams`

{/* generated:method:$setI18nRouteParams — do not edit; run `pnpm run docs:generate` */}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Imposta parametri per locale per la route corrente, così un segmento dinamico può differire per lingua.
Chiamalo durante SSR, prima che l'head venga renderizzato.

{/* /generated:method:$setI18nRouteParams */}

```typescript
// in pages/news/[id].vue
// for en/news/1-first-article
const { $switchLocaleRoute, $setI18nRouteParams, $defineI18nRoute } = useNuxtApp()
$defineI18nRoute({
  localeRoutes: {
    en: '/news/:id()',
    fr: '/nouvelles/:id()',
    de: '/Nachricht/:id()',
  },
})
const { data: news } = await useAsyncData(`news-${params.id}`, async () => {
  let response = await $fetch("/api/getNews", {
    query: {
      id: params.id,
    },
  });
  if (response?.localeSlugs) {
    response.localeSlugs = {
      en: {
        id: '1-first-article'
      }
      fr: {
        id: '1-premier-article'
      }
      de: {
        id: '1-erster-Artikel'
      }
    }
    $setI18nRouteParams(response?.localeSlugs);
  }
  return response;
});
$switchLocalePath('fr') // === 'fr/nouvelles/1-premier-article'
$switchLocalePath('de') // === 'de/Nachricht/1-erster-Artikel'
```

## 🔧 Metodi di cache e utility

### `$has`

{/* generated:method:$has — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string) => boolean
```

Se una chiave si risolve nella locale attiva. Usalo per ramificare su testo opzionale invece di
renderizzare una chiave grezza.

{/* /generated:method:$has */}

Durante le transizioni di pagina nella stessa locale, la v3 esegue automaticamente un deep-merge delle traduzioni dalla pagina uscente in questo dizionario finché la transizione non termina. Le chiavi della pagina precedente possono quindi ancora restituire `true` brevemente. Non esiste un'opzione `previousPageFallback`; questo comportamento è integrato. Consulta [FAQ — transizioni di pagina](/guides/faq#-why-do-translations-break-during-page-transitions-especially-with-defineasynccomponent).

```typescript
if ($has('welcome')) {
  console.log($t('welcome'))
} else {
  console.log('Key not found')
}
```

### `$clearCache`

{/* generated:method:$clearCache — do not edit; run `pnpm run docs:generate` */}

```ts
() => void
```

Elimina ogni chunk in cache, sul client e nel dizionario attivo.

{/* /generated:method:$clearCache */}

## 🧭 Composable `useI18nLocale`

Il composable centralizzato per la gestione dello stato della locale. Usalo invece di manipolare direttamente `useState('i18n-locale')` o `useCookie('user-locale')`.

```typescript
const {
  setLocale, // (locale: string) => void — updates state + cookie
  getLocale, // () => string | null — from state or cookie
  getPreferredLocale, // () => string | null — validated against locales list
  getEffectiveLocale, // (route, getLocaleFromRoute) => string
  resolveInitialLocale, // (options) => string
  isValidLocale, // (locale) => boolean
  locale, // Ref<string | null> — reactive state
  localeCookie, // CookieRef — reactive cookie
  syncLocale, // (locale) => void — sync to cookie only
  validLocales, // string[] — list of valid locale codes
} = useI18nLocale()
```

### Metodi principali

| Metodo                  | Descrizione                                                 |
| ----------------------- | ----------------------------------------------------------- |
| `setLocale(locale)`     | Imposta la locale sia in `useState` sia nel cookie atomicamente |
| `getLocale()`           | Restituisce la locale corrente da state o cookie            |
| `getPreferredLocale()`  | Restituisce la locale validata rispetto alla lista `locales`, o `null` |
| `isValidLocale(locale)` | Verifica se un codice locale è nella lista `locales` configurata |

### Utilizzo in plugin custom

```typescript
// plugins/i18n-loader.server.ts
export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  },
})
```
