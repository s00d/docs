# Uso delle traduzioni nei componenti

Una volta installato e configurato il modulo, puoi mostrare le traduzioni chiamando `$t('your_key')` nei tuoi template e script Vue.

## 1. File di traduzione di root e specifici per pagina

1. Le traduzioni **di root** risiedono direttamente sotto la cartella `/locales` (ad es. `/locales/en.json`, `/locales/fr.json`). In fase di build vengono unite automaticamente in ogni file specifico per pagina, rendendole disponibili su tutte le pagine.
2. Le traduzioni **specifiche per pagina** risiedono sotto `/locales/pages/...`, rispecchiando la struttura della cartella pages di Nuxt:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. Uso nei template con `$t`

Nei tuoi file `.vue`, puoi usare `$t` direttamente nel template:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
`$t` può restituire **oggetti** se la chiave punta a un nodo JSON annidato (ad es. `$t('header')` → `\{ title: "Hi" \}`). Nei template ciò viene renderizzato come `[object Object]`. Usa `$ts` quando serve una stringa garantita, oppure fornisci una chiave più specifica come `$t('header.title')`. Vedi [Riferimento API — $t vs $ts](/api/methods#t) per i dettagli.
</Tip>

## 3. Cambio della locale corrente

Per cambiare lingua nella tua app, puoi ottenere `$locale` da `useI18n()` e assegnargli un nuovo codice:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. Chiavi annidate e segnaposto

- Le **chiavi annidate** usano la notazione con punto, ad es. `nested.key.deeper`.
- I **segnaposto** consentono di inserire valori dinamici:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. Suggerimenti e best practice

- **Chiavi in conflitto**: Se un file specifico per pagina contiene la stessa chiave di un file di root, la versione specifica per pagina ha la priorità (le traduzioni di root sono unite come base in fase di build).
- **Disabilitare i file per pagina**: Se preferisci non usare traduzioni specifiche per pagina, puoi impostare `disablePageLocales: true` nella configurazione Nuxt. In questo modo verranno usati solo i file `/locales/*.json`.
- **Nessun import diretto**: Non è necessario fare `import \{ useI18n \} from 'nuxt-i18n-micro'`; la funzione di auto-iniezione del modulo lo gestisce per te.

Questo è tutto! Con questi passaggi puoi rapidamente **iniziare a recuperare le traduzioni** da file JSON di root o specifici per pagina e **mostrarle** nella tua applicazione Nuxt usando `$t`.

## Risorse aggiuntive

Per esplorare funzionalità più avanzate, assicurati di consultare:

1. **Componente `<i18n-t>`**  
   Il componente `<i18n-t>` è una potente alternativa a `$t`, particolarmente utile in situazioni con elementi annidati, uso avanzato di segnaposto e strutture di traduzione più complesse.

- **Documentazione**: [i18n-t](/api/components/i18n-t)

2. **Composable `useI18n`**  
   Il composable `useI18n` offre un set completo di funzioni e proprietà reattive per gestire traduzioni, cambio locale, formattazione e altro.

- **Documentazione**: [useI18n](/api/composables/use-i18n)
