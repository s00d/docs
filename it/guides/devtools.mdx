# 🛠️ DevTools in `nuxt-i18n-micro`

## Vue DevTools (estensione del browser)

In sviluppo, il modulo può registrare un inspector personalizzato e una timeline in **Vue DevTools** tramite `@vue/devtools-api`. Questo è separato dalla scheda Nuxt DevTools qui sotto.

| Strumento | Ideale per |
|------|----------|
| **Vue DevTools** | Locale attiva, cache di traduzione in memoria, timeline `$t` (`debug: true`), eventi di chiavi mancanti |
| **Scheda Nuxt DevTools** | Modifica dei file JSON su disco, panoramica config, import/export |

Il plugin vue-devtools viene registrato solo durante `nuxt dev` (non nelle build di produzione). Lo stato del bridge solo-dev nel plugin principale viene rimosso dall'eliminazione del codice morto `import.meta.dev`.

Disabilita l'integrazione del browser mantenendo la scheda Nuxt:

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

Gli eventi verbosi della timeline `$t` richiedono `debug: true`.

## 📖 Cos'è Nuxt DevTools?

DevTools è un potente assistente di sviluppo integrato senza soluzione di continuità nel modulo `nuxt-i18n-micro`. Fornisce un'interfaccia intuitiva per gestire attività di localizzazione e traduzione, rendendo il tuo flusso di lavoro più veloce ed efficiente. Progettato per sviluppatori che apprezzano la comodità, Nuxt DevTools colma il divario tra la programmazione e la gestione a runtime.

## 🌟 Funzionalità principali di DevTools in `nuxt-i18n-micro`

### 1. **Gestione delle locale**

Sfoglia, seleziona e gestisci senza sforzo le locale nella tua applicazione. Che tu stia lavorando con una sola lingua o con più, DevTools offre un hub centralizzato per gestire tutte le impostazioni di localizzazione.

### 2. **Modifica delle traduzioni**

Modifica i file di traduzione direttamente attraverso un editor JSON integrato. Questo elimina la necessità di strumenti esterni, permettendo aggiornamenti e modifiche in tempo reale senza interrompere il tuo flusso di lavoro.

### 3. **Importazione ed esportazione di file**

Semplifica il processo di gestione dei file di traduzione:

- **Esporta**: salva le traduzioni come file JSON per backup o uso esterno.
- **Importa**: carica file di traduzione aggiornati nel progetto per mantenere il contenuto aggiornato.

### 4. **Anteprime in tempo reale**

Visualizza le modifiche immediatamente nell'ambiente di sviluppo. Questa funzionalità garantisce che le traduzioni e le configurazioni siano accurate prima di andare in produzione.

### 5. **Integrazione fluida con Nuxt**

DevTools funziona nativamente con `nuxt-i18n-micro`, migliorandone le capacità senza richiedere setup aggiuntivi. Si adatta alle tue esigenze di localizzazione mantenendo la struttura modulare e flessibile di Nuxt.

## 🛠️ Perché usare DevTools?

Nuxt DevTools è un'aggiunta indispensabile per i progetti che richiedono localizzazione. Aiuta gli sviluppatori:

- **Risparmiando tempo**: automatizza attività ripetitive come la gestione dei file e la validazione del formato.
- **Riducendo gli errori**: fornisce un ambiente sicuro e intuitivo per modificare le traduzioni.
- **Migliorando la collaborazione**: permette anche ai non sviluppatori di gestire facilmente le traduzioni.
- **Ottimizzando i flussi di lavoro**: consolida più attività di localizzazione in un'unica interfaccia.
