# 🛠️ DevTools in `nuxt-i18n-micro`

## Vue DevTools (estensione del browser)

In sviluppo, il modulo può registrare un ispettore personalizzato e una timeline di **Vue DevTools** tramite `@vue/devtools-api`. Questo è separato dalla scheda Nuxt DevTools descritta sotto.

| Strumento | Adatto per |
|------|----------|
| **Vue DevTools** | Locale attiva, cache di traduzione in memoria, timeline `$t` (`debug: true`), eventi di chiavi mancanti |
| **Scheda Nuxt DevTools** | Modifica dei file JSON su disco, panoramica della configurazione, import/export |

Il plugin vue-devtools viene registrato solo durante `nuxt dev` (non nelle build di produzione). Lo stato del bridge dev-only nel plugin principale viene rimosso dall'eliminazione del dead code di `import.meta.dev`.

Disattiva l'integrazione con il browser mantenendo la scheda Nuxt:

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

Gli eventi verbosi della timeline `$t` richiedono `debug: true`.

## 📖 Cos'è Nuxt DevTools?

DevTools è un potente assistente di sviluppo integrato in modo trasparente nel modulo `nuxt-i18n-micro`. Fornisce un'interfaccia intuitiva per gestire attività di localizzazione e traduzione, rendendo il tuo flusso di lavoro più veloce ed efficiente. Progettato per gli sviluppatori che apprezzano la comodità, Nuxt DevTools colma il divario tra codice e gestione a runtime.

## 🌟 Funzionalità principali di DevTools in `nuxt-i18n-micro`

### 1. **Gestione delle locale**

Sfoglia, seleziona e gestisci senza sforzo le locale della tua applicazione. Sia che tu lavori con una sola lingua o con più, DevTools fornisce un hub centralizzato per gestire tutte le impostazioni di localizzazione.

### 2. **Modifica delle traduzioni**

Modifica direttamente i file di traduzione attraverso un editor JSON integrato. Questo elimina la necessità di strumenti esterni, permettendo aggiornamenti e modifiche in tempo reale senza interrompere il flusso di lavoro.

### 3. **Import ed export di file**

Semplifica il processo di gestione dei file di traduzione:

- **Export**: Salva le traduzioni come file JSON per backup o uso esterno.
- **Import**: Carica file di traduzione aggiornati nel progetto per mantenere i contenuti aggiornati.

### 4. **Anteprime in tempo reale**

Visualizza immediatamente le modifiche all'interno dell'ambiente di sviluppo. Questa funzionalità garantisce che traduzioni e configurazioni siano accurate prima della pubblicazione.

### 5. **Integrazione trasparente con Nuxt**

DevTools funziona nativamente con `nuxt-i18n-micro`, potenziandone le capacità senza richiedere configurazioni aggiuntive. Si adatta alle tue esigenze di localizzazione mantenendo la struttura modulare e flessibile di Nuxt.

## 🛠️ Perché usare DevTools?

Nuxt DevTools è un'aggiunta indispensabile per i progetti che richiedono localizzazione. Aiuta gli sviluppatori nel:

- **Risparmio di tempo**: Automatizza attività ripetitive come la gestione dei file e la validazione del formato.
- **Riduzione degli errori**: Fornisce un ambiente sicuro e intuitivo per modificare le traduzioni.
- **Miglioramento della collaborazione**: Permette a chi non è sviluppatore di gestire facilmente le traduzioni.
- **Ottimizzazione dei flussi di lavoro**: Consolida molteplici attività di localizzazione in un'unica interfaccia.
