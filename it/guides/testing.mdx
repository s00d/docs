# 🧪 Testing del modulo `Nuxt I18n Micro`

## 📖 Introduzione al testing

Testare il modulo `Nuxt I18n Micro` è fondamentale per assicurarsi che le funzionalità di localizzazione della tua applicazione funzionino come previsto. Questa documentazione ti guiderà nella configurazione dell'ambiente di test, nella creazione di configurazioni mock per vitest e nella scrittura di test per i tuoi componenti. Per un esempio pratico puoi consultare il [progetto di esempio su GitHub](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/test-utils/example).

Consulta [Testing routing strategies](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/testing-strategies.md) per vedere come questo repository esegue le proprie suite — i progetti Vitest `unit` / `integration` / `e2e`, i file per strategia (`test/strategies-*.test.ts`) e le regressioni della generazione.

## 🛠️ Configurazione dell'ambiente di test

### 1. Installa `@i18n-micro/test-utils`

Innanzitutto, devi installare le utility di test per `Nuxt I18n Micro`. Questo pacchetto fornisce gli strumenti necessari per fare mock e testare le tue configurazioni i18n.

```bash
npm install @i18n-micro/test-utils --save-dev
```

### 2. Crea un file di configurazione mock

Successivamente, crea un file per impostare la configurazione i18n mock. Questo file verrà usato per fare mock delle funzioni e utility i18n durante i tuoi test.

```typescript
// tests/unit-setup.ts

import { mockNuxtImport } from '@nuxt/test-utils/runtime'
import { vi } from 'vitest'
import { i18nUtils } from '@i18n-micro/test-utils'

export function createFakeI18n() {
  return {
    $getLocale: vi.fn(i18nUtils.getLocale),
    $t: vi.fn(i18nUtils.t),
    $tc: vi.fn(i18nUtils.tc),
    $setLocale: vi.fn(i18nUtils.setLocale),
    $getLocaleName: vi.fn(i18nUtils.getLocaleName),
    $setLocaleName: vi.fn(i18nUtils.setLocaleName),
    $getLocales: vi.fn(i18nUtils.getLocales),
    $setLocales: vi.fn(i18nUtils.setLocales),
    $defaultLocale: vi.fn(i18nUtils.defaultLocale),
    $setDefaultLocale: vi.fn(i18nUtils.setDefaultLocale),
    $getRouteName: vi.fn(i18nUtils.getRouteName),
    $settRouteName: vi.fn(i18nUtils.settRouteName),
    $ts: vi.fn(i18nUtils.ts),
    $tn: vi.fn(i18nUtils.tn),
    $td: vi.fn(i18nUtils.td),
    $has: vi.fn(i18nUtils.has),
    $resolveTranslations: vi.fn(i18nUtils.resolveTranslations),
    $setTranslation: vi.fn(i18nUtils.setTranslation),
    $mergeTranslations: vi.fn(i18nUtils.mergeTranslations),
    $switchLocaleRoute: vi.fn(i18nUtils.switchLocaleRoute),
    $switchLocalePath: vi.fn(i18nUtils.switchLocalePath),
    $switchLocale: vi.fn(i18nUtils.switchLocale),
    $switchRoute: vi.fn(i18nUtils.switchRoute),
    $localeRoute: vi.fn(i18nUtils.localeRoute),
    $localePath: vi.fn(i18nUtils.localePath),
    $setI18nRouteParams: vi.fn(i18nUtils.setI18nRouteParams),
  }
}

mockNuxtImport<() => ReturnType<typeof createFakeI18n>>('useI18n', () => vi.fn(() => createFakeI18n()))

export const setTranslationsFromJson = i18nUtils.setTranslationsFromJson
```

### 3. Configura Vitest

Ora configura Vitest per usare il file di configurazione mock e impostare l'ambiente di test.

```typescript
// vitest.config.ts

import { defineVitestConfig } from '@nuxt/test-utils/config'

export default defineVitestConfig({
  test: {
    watch: false,
    setupFiles: ['./tests/unit-setup.ts'],
    include: ['./**/*.spec.ts'],
  },
})
```

## 🧪 Scrittura dei test

### Componente di esempio

Ecco un esempio di un componente semplice che usa il composable `useI18n` per tradurre i messaggi.

```vue
<script setup lang="ts">
const { $t } = useI18n()

const props = defineProps({
  message: {
    type: String,
    default: null,
  },
})

// Test to see that $t works in script setup as well as the template
const message = props.message || $t('defaultMessage')
</script>

<template>
  <div>
    <p>Test from component: {{ $t('welcome') }}</p>
    <p data-testid="message">Test message from props: {{ message }}</p>
  </div>
</template>
```

### File di test

Ora scriviamo un test per questo componente.

```typescript
// tests/unit/example.spec.ts

import { describe, it, expect, beforeEach } from 'vitest'
import { mount } from '@vue/test-utils'
import ExampleComponent from '@/components/ExampleComponent.vue'
import fs from 'fs'
import path from 'path'
import { setTranslationsFromJson } from './unit-setup'

describe('ExampleComponent', () => {
  beforeEach(async () => {
    const fileContent = fs.readFileSync(path.join(__dirname, '../../locales/en-GB.json')).toString()
    await setTranslationsFromJson('en', JSON.parse(fileContent))
  })

  it('renders the welcome message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.text()).toContain('Test from component: Welcome')
  })

  it('renders the default message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Default Message')
  })

  it('renders the custom message correctly', () => {
    const wrapper = mount(ExampleComponent, {
      props: {
        message: 'Custom Message',
      },
    })
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Custom Message')
  })
})
```

## 📝 Best practice per il testing

- **🔧 Fai mock delle funzioni i18n:** Fai sempre mock delle funzioni i18n usando `@i18n-micro/test-utils` per garantire risultati di test coerenti e prevedibili.
- **⚙️ Usa Vitest per gli unit test:** Vitest è un potente framework di test per applicazioni Vue. Usalo per scrivere unit test per i tuoi componenti.
- **📚 Documenta i tuoi test:** Documenta chiaramente lo scopo e i risultati attesi di ciascun test. Ciò aiuterà a mantenere la chiarezza e renderà più facile per gli altri (o il te stesso futuro) comprendere i test.

## 📊 Metodi di utilità i18n

Di seguito è riportata una tabella che descrive tutti i metodi di utilità forniti da `@i18n-micro/test-utils`.

| Metodo                                          | Descrizione                                                                                                                                |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `t(key, params, defaultValue)`                  | Traduce una chiave con parametri opzionali e un valore predefinito.                                                                        |
| `tc(key, params, defaultValue)`                 | Traduce una chiave con supporto alla pluralizzazione.                                                                                      |
| `setTranslationsFromJson(locale, translations)` | Carica le traduzioni da un oggetto JSON per una locale specifica.                                                                          |
| `getLocale()`                                   | Restituisce la locale corrente.                                                                                                            |
| `setLocale(val)`                                | Imposta la locale corrente.                                                                                                                |
| `getLocaleName()`                               | Restituisce il nome della locale corrente.                                                                                                 |
| `setLocaleName(val)`                            | Imposta il nome della locale corrente.                                                                                                     |
| `getLocales()`                                  | Restituisce l'elenco delle locale disponibili.                                                                                             |
| `setLocales(val)`                               | Imposta l'elenco delle locale disponibili.                                                                                                 |
| `defaultLocale()`                               | Restituisce la locale predefinita.                                                                                                         |
| `setDefaultLocale(val)`                         | Imposta la locale predefinita.                                                                                                             |
| `getRouteName()`                                | Restituisce il nome della rotta corrente.                                                                                                  |
| `settRouteName(val)`                            | Imposta il nome della rotta corrente.                                                                                                      |
| `ts(key, params, defaultValue)`                 | Traduce una chiave e restituisce il risultato come stringa.                                                                                |
| `tn(value, options?)`                           | Formatta un numero con `Intl.NumberFormatOptions` inline. I formati con nome richiedono la configurazione del modulo e non sono disponibili in questo helper standalone. |
| `td(value, options?)`                           | Formatta una data con `Intl.DateTimeFormatOptions` inline. I formati con nome richiedono la configurazione del modulo e non sono disponibili in questo helper standalone. |
| `has(key)`                                      | Verifica se una chiave di traduzione esiste.                                                                                               |
| `resolveTranslations()`                         | Restituisce l'albero delle traduzioni attivo per la locale e la rotta correnti.                                                            |
| `setTranslation(key, value)`                    | Sostituisce il valore presso `key` nel dizionario attivo (sostituzione, non merge).                                                        |
| `mergeTranslations(newTranslations)`            | Unisce le traduzioni nella locale attiva a runtime.                                                                                        |

Seguendo questi passaggi puoi testare efficacemente il modulo `Nuxt I18n Micro` e assicurarti che le funzionalità di localizzazione della tua applicazione funzionino come previsto.
