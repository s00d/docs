# 🌐 Guida all'integrazione di Crowdin

## 📖 Introduzione

Integrare Crowdin nel tuo progetto semplifica il processo di localizzazione e traduzione, rendendo più facile gestire le traduzioni su più lingue e piattaforme. Questa guida offre una procedura passo passo per configurare Crowdin nel tuo progetto, inclusa la configurazione, l'upload dei sorgenti e il download delle traduzioni.

## 🔧 Installazione e configurazione

Per iniziare con Crowdin, dovrai installare la CLI di Crowdin globalmente sulla tua macchina e inizializzarla nella directory del tuo progetto.

### 📦 Installare la CLI di Crowdin

Prima installa la CLI di Crowdin globalmente con npm:

```bash
npm install -g @crowdin/cli
```

### 🛠 Inizializzare Crowdin nel tuo progetto

Inizializza Crowdin nel tuo progetto eseguendo:

```bash
crowdin init
```

Questo comando ti guiderà attraverso il processo di configurazione, incluso l'impostazione dell'ID progetto, del token API e di altri dettagli di configurazione.

## 🗂️ Guida alla configurazione

### 📄 File di configurazione di Crowdin (`crowdin.yml`)

Il file di configurazione di Crowdin (`crowdin.yml`) definisce come i tuoi file sorgente vengono mappati e dove devono essere collocate le traduzioni. Ecco un esempio di configurazione:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Parametri principali di configurazione

- **`project_id`**: l'ID del tuo progetto Crowdin. Identifica il progetto in Crowdin in cui vengono gestite le traduzioni.
- **`api_token`**: il token API usato per l'autenticazione. Assicurati che questo token abbia i permessi corretti per caricare e scaricare le traduzioni.
- **`base_path`**: specifica la directory base per i file sorgente. In questo esempio, le traduzioni sono memorizzate nella directory `./locales`.
- **`base_url`**: l'URL base per l'API di Crowdin.
- **`preserve_hierarchy`**: se impostato a `true`, Crowdin manterrà la struttura di cartelle dei tuoi file sorgente nel progetto.

### 📂 Configurazione dei file

La sezione `files` mappa i tuoi file sorgente ai percorsi in cui le traduzioni verranno memorizzate. Ad esempio:

- **Percorso sorgente**: definisce la posizione dei file di traduzione originali.
- **Percorso di traduzione**: specifica dove i file tradotti verranno memorizzati in Crowdin. Placeholder come `%two_letters_code%` vengono usati per impostare dinamicamente il codice di lingua nei percorsi dei file.

## ⬆️ Caricare i file sorgente su Crowdin

Una volta configurato Crowdin, puoi caricare i tuoi file sorgente usando il seguente comando:

```bash
crowdin upload sources
```

Questo comando carica tutti i file sorgente specificati nella tua configurazione su Crowdin, rendendoli disponibili per la traduzione.

## ⬇️ Scaricare le traduzioni da Crowdin

Dopo che le traduzioni sono state completate o aggiornate in Crowdin, puoi scaricarle nel tuo progetto usando:

```bash
crowdin download
```

Questo comando recupera le traduzioni più recenti da Crowdin e le salva secondo i percorsi specificati nel tuo file di configurazione.

## ⚙️ Best practice

### 🔑 Denominazione coerente delle chiavi

Assicurati che le chiavi di traduzione siano coerenti in tutti i file per evitare confusione e duplicazioni.

### 🧹 Manutenzione regolare

Rivedi periodicamente e ripulisci le chiavi di traduzione non usate per mantenere i tuoi file organizzati e gestibili.

### 🛠 Automatizza upload e download

Integra i comandi della CLI di Crowdin nella tua pipeline CI/CD per automatizzare l'upload dei file sorgente e il download delle traduzioni, garantendo che le tue traduzioni siano sempre aggiornate.

Seguendo questa guida, potrai integrare senza problemi Crowdin nel tuo progetto, assicurando un approccio efficiente e organizzato alla gestione dei tuoi sforzi di internazionalizzazione.
