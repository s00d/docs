# 🌐 Guida all'integrazione con Crowdin

## 📖 Introduzione

Integrare Crowdin nel tuo progetto semplifica il processo di localizzazione e traduzione, rendendo più facile gestire le traduzioni tra più lingue e piattaforme. Questa guida fornisce una panoramica passo passo per configurare Crowdin con il tuo progetto, inclusa la configurazione, il caricamento dei sorgenti e il download delle traduzioni.

## 🔧 Installazione e configurazione

Per iniziare con Crowdin, dovrai installare la CLI di Crowdin globalmente sulla tua macchina e inizializzarla nella directory del progetto.

### 📦 Installazione della CLI di Crowdin

Per prima cosa, installa la CLI di Crowdin globalmente usando npm:

```bash
npm install -g @crowdin/cli
```

### 🛠 Inizializzazione di Crowdin nel progetto

Inizializza Crowdin nel tuo progetto eseguendo:

```bash
crowdin init
```

Questo comando ti guiderà nel processo di configurazione, inclusa l'impostazione dell'ID del progetto, del token API e di altri dettagli.

## 🗂️ Guida alla configurazione

### 📄 File di configurazione di Crowdin (`crowdin.yml`)

Il file di configurazione di Crowdin (`crowdin.yml`) definisce come vengono mappati i file sorgente e dove vengono posizionate le traduzioni. Di seguito un esempio di configurazione:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Parametri di configurazione principali

- **`project_id`**: L'ID del tuo progetto Crowdin. Identifica il progetto in Crowdin in cui vengono gestite le traduzioni.
- **`api_token`**: Il token API usato per l'autenticazione. Assicurati che questo token abbia i permessi corretti per caricare e scaricare traduzioni.
- **`base_path`**: Specifica la directory di base per i file sorgente. In questo esempio, le traduzioni sono memorizzate nella directory `./locales`.
- **`base_url`**: L'URL di base per l'API di Crowdin.
- **`preserve_hierarchy`**: Se impostato a `true`, Crowdin manterrà la struttura delle cartelle dei file sorgente nel progetto.

### 📂 Configurazione dei file

La sezione `files` mappa i file sorgente ai percorsi in cui verranno memorizzate le traduzioni. Ad esempio:

- **Percorso sorgente**: Definisce la posizione dei file di traduzione originali.
- **Percorso di traduzione**: Specifica dove verranno memorizzati i file tradotti in Crowdin. Segnaposto come `%two_letters_code%` vengono usati per impostare dinamicamente il codice della lingua nei percorsi dei file.

## ⬆️ Caricamento dei file sorgente su Crowdin

Una volta configurato Crowdin, puoi caricare i tuoi file sorgente usando il seguente comando:

```bash
crowdin upload sources
```

Questo comando carica tutti i file sorgente specificati nella tua configurazione su Crowdin, rendendoli disponibili per la traduzione.

## ⬇️ Download delle traduzioni da Crowdin

Dopo che le traduzioni sono state completate o aggiornate in Crowdin, puoi scaricarle nel tuo progetto usando:

```bash
crowdin download
```

Questo comando recupera le traduzioni più recenti da Crowdin e le salva secondo i percorsi specificati nel file di configurazione.

## ⚙️ Best practice

### 🔑 Denominazione coerente delle chiavi

Assicurati che le chiavi di traduzione siano coerenti in tutti i file per evitare confusione e duplicazioni.

### 🧹 Manutenzione regolare

Rivedi e pulisci periodicamente le chiavi di traduzione inutilizzate per mantenere i file organizzati e gestibili.

### 🛠 Automatizza upload e download

Integra i comandi CLI di Crowdin nella tua pipeline CI/CD per automatizzare il caricamento dei file sorgente e il download delle traduzioni, garantendo traduzioni sempre aggiornate.

Seguendo questa guida sarai in grado di integrare Crowdin in modo trasparente nel tuo progetto, garantendo un approccio efficiente e organizzato alla gestione degli sforzi di internazionalizzazione.
