# Risultati dei test di prestazioni

## Informazioni sul progetto

- **[plain-nuxt](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/plain-nuxt)**: ./test/fixtures/plain-nuxt
- **[i18n-micro](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/i18n-micro)**: ./test/fixtures/i18n-micro
- **[i18n](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/i18n)**: ./test/fixtures/i18n
- **[CLI](https://github.com/s00d/nuxt-i18n-micro/tree/main/scripts/src/commands/performance.ts)**: `pnpm -C scripts cli performance` / `pnpm test:performance`

### Descrizione

Confronta **plain Nuxt** (baseline senza modulo i18n), **i18n-micro** e **`@nuxtjs/i18n` v10.6** con lo stesso profilo di dizionario condiviso.

Focus: tempo di build, RSS di picco, **codice vs traduzioni vs totale** deployabile e comportamento del server sotto Artillery + Autocannon.

### Note metodologiche

- Le metriche sono **medie di 3 esecuzioni consecutive per fixture** (fixture A ×3, poi B ×3, poi C ×3 — non intercalate).
- Le **traduzioni** includono i JSON di locale sotto `locales/` / `_locales/` / `translations/`, tutto ciò che è sotto `chunks/raw/` e i chunk di locale corrispondenti. I report precedenti che mostravano `@nuxtjs/i18n` "translations: 0 B" e una colonna "code" enorme contavano i chunk dei messaggi come codice dell'app.
- **plain-nuxt** serve lo stesso volume di foglie sotto forma di JSON statici in `public/translations` (non import JS statici). Sotto Artillery quella baseline è I/O-heavy; non è "overhead di i18n", è il costo di recuperare grandi JSON per ogni richiesta.

### Esecuzioni

Tutte le metriche sotto sono **medie tra 3 esecuzioni**.

### Profilo della fixture

| Parametro | Valore |
|------|-------|
| Locale | **4** (`en`, `de`, `ru`, `fr`) |
| Pagine | **2** (`index`, `page`) |
| Albero dell'index | profondità **5**, branch **7** → **16.807** chiavi foglia / locale |
| Pagine secondarie | profondità **5**, branch **6** → **7.776** chiavi foglia / pagina / locale |
| Obiettivo | Profilo CLI predefinito (`--locales 4 --keys 10000`); alza i parametri per carichi di regressione |

I dizionari provengono da `test/fixtures/perf-shared/runtime.json` (scritto dalla CLI) in modo che tutte e tre le fixture restino allineate.
