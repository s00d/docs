Questa pagina porta un'app Nuxt da zero i18n a una pagina tradotta con un selettore di lingua. Ti serve una sola volta, all'inizio di un progetto. Alla fine avrai URL localizzati (`/about`, `/de/about`), un file JSON per lingua e pagina e `$t` nei tuoi template.

## Installazione {#install}

Il modulo richiede Nuxt 3.18 o successivo (funziona anche Nuxt 4) e Node 20 o successivo.

<CodeGroup>

```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>

## Configurare le lingue {#configure-the-locales}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', displayName: 'English' },
      { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
      { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
    ],
    defaultLocale: 'en',
  },
})
```

Questa è tutta la configurazione di cui ha bisogno una prima app. Le impostazioni predefinite ti offrono:

- `strategy: 'prefix_except_default'`: la lingua predefinita non ha prefisso (`/about`), le altre sì (`/de/about`). Vedi [Strategie di routing](/it/guide/strategy).
- `translationDir: 'locales'`: i file di traduzione si trovano in `locales/` nella radice del progetto, anche con il layout `app/` di Nuxt 4.
- `meta: true`: tag `hreflang`, canonical e `og:locale`, più `lang` e `dir` su `<html>`. Vedi [SEO](/it/guide/seo).
- Un visitatore che apre `/` viene indirizzato alla lingua richiesta dal suo browser (`Accept-Language`). Vedi [Rilevamento della lingua](/it/guide/locale-detection).

`iso` è il tag di lingua usato nei tag SEO; `code` è ciò che appare nell'URL. Tutte le opzioni sono elencate in [Opzioni del modulo](/it/api/module-options).

## Aggiungere i file di traduzione {#add-translation-files}

Avvia il server di sviluppo con `nuxt dev`. Quando Nuxt risolve le pagine, il modulo crea un file vuoto `{}` per ogni lingua e pagina che non ne ha uno (puoi disattivarlo con [`disableWatcher`](/it/api/module-options#disablewatcher)):

```text
locales/
├── en.json            # root: keys every page can use
├── de.json
├── fr.json
└── pages/
    ├── index/         # pages/index.vue
    │   ├── en.json
    │   ├── de.json
    │   └── fr.json
    └── about/         # pages/about.vue
        ├── en.json
        ├── de.json
        └── fr.json
```

Compila il file radice e un file di pagina:

```json
// locales/en.json
{ "nav": { "home": "Home", "about": "About" } }
```

```json
// locales/pages/index/en.json
{ "welcome": "Welcome, {name}!", "items": "no items | one item | {count} items" }
```

Una pagina vede le chiavi radice e le proprie chiavi; in caso di conflitto prevale il suo file. I nomi delle cartelle seguono il nome della rotta (`pages/articles/[id].vue` diventa `locales/pages/articles-id/`). [File di traduzione](/it/guide/translations) descrive il layout, i fallback e il caricamento.

## Usare `$t` in una pagina {#use-$t-on-a-page}

```vue
<!-- pages/index.vue -->
<script setup lang="ts">
const { t, tc, getLocale } = useI18n()

const title = t('nav.home') // 'Home'
</script>

<template>
  <h1>{{ $t('welcome', { name: 'Ada' }) }}</h1>
  <!-- Welcome, Ada! -->
  <p>{{ $tc('items', 3) }}</p>
  <!-- 3 items -->
  <p>{{ getLocale() }}</p>
  <!-- en -->
</template>
```

- Nei template ogni helper è disponibile con il `$` (`$t`, `$tc`, `$localePath`, …).
- In `<script setup>`, `useI18n()` restituisce gli stessi helper, con e senza `$` (`t` e `$t` sono la stessa funzione). Viene importato automaticamente.
- I segnaposto `{name}` vengono riempiti dall'oggetto dei parametri. Le forme plurali sono separate da `|`; il conteggio sceglie la forma (0, 1, poi l'ultima per tutti i valori superiori).

Tutti gli helper sono elencati in [Metodi](/it/api/methods).

## Collegare le pagine e cambiare lingua {#link-between-pages-and-switch-locale}

```vue
<!-- components/AppHeader.vue -->
<template>
  <nav>
    <i18n-link :to="{ name: 'index' }">{{ $t('nav.home') }}</i18n-link>
    <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
    <i18n-switcher />
  </nav>
</template>
```

- [`<i18n-link>`](/it/components/i18n-link) è un `NuxtLink` che punta alla pagina nella lingua corrente: su `/de` il link about porta a `/de/about`.
- [`<i18n-switcher>`](/it/components/i18n-switcher) è un menu a tendina delle lingue abilitate; mantiene il visitatore sulla stessa pagina.
- Per i tuoi pulsanti chiama `$switchLocale('de')`, che naviga alla pagina corrente in tedesco e ricorda la scelta. Per un semplice `NuxtLink`, usa `$localePath({ name: 'about' })` o `$switchLocalePath('de')`.

## Verifica {#check-it}

Esegui `nuxt dev` e apri:

| URL | Mostra |
| --- | --- |
| `/` | Home inglese (o un reindirizzamento a `/de` quando il tuo browser preferisce il tedesco) |
| `/de` | Home tedesca |
| `/de/about` | Pagina about tedesca |
| `/en/about` | 404: la lingua predefinita non ha prefisso con `prefix_except_default` |

Le modifiche ai file JSON si applicano alla pagina aperta senza ricaricarla.
