[Crowdin](https://crowdin.com/) è una piattaforma di traduzione: carichi i file della locale di default, i traduttori lavorano in Crowdin e tu scarichi le altre locale. Il modulo legge semplici file JSON, quindi la Crowdin CLI ha bisogno solo di un `crowdin.yml` che mappi correttamente `locales/` e `locales/pages/`. Nessuna impostazione del modulo cambia.

## Configurare crowdin.yml {#configure-crowdin-yml}

```yml
# crowdin.yml
project_id_env: CROWDIN_PROJECT_ID
api_token_env: CROWDIN_PERSONAL_TOKEN
base_path: ./locales
preserve_hierarchy: true

files:
  - source: /en.json
    translation: /%two_letters_code%.json
  - source: /pages/**/en.json
    translation: /pages/**/%two_letters_code%.json
```

- `en` è la tua locale di default; i suoi file sono le sorgenti.
- `project_id_env` / `api_token_env` leggono l'ID e il token dalle variabili d'ambiente, così nessun segreto finisce nel repository.
- `preserve_hierarchy: true` mantiene le cartelle `pages/<page>/` così come sono.
- Il nome del file tradotto deve essere uguale al `code` della locale in `nuxt.config.ts`. `%two_letters_code%` va bene per codici come `de`; per codici come `pt-BR` usa `%locale%`, oppure mappa i codici di Crowdin sui tuoi con `languages_mapping`.

## Caricamento e download {#upload-and-download}

```bash
npm install -g @crowdin/cli

export CROWDIN_PROJECT_ID=123456
export CROWDIN_PERSONAL_TOKEN=...   # from Crowdin account settings

crowdin upload sources   # push locales/en.json and locales/pages/**/en.json
crowdin download         # write locales/de.json, locales/pages/**/de.json, ...
```

Esegui entrambi i comandi in CI per mantenere i file aggiornati. I file scaricati arrivano nel tuo repository come quelli modificati a mano; la build successiva o il reload in sviluppo li recepisce.

## Prima del caricamento {#before-uploading}

Prima pulisci le sorgenti, così i traduttori non lavorano su chiavi inutilizzate: [`i18n-micro clean`](/it/api/cli#clean) rimuove le chiavi non usate, [`i18n-micro check`](/it/api/cli#check) segnala le lacune dopo un download. La CLI non ha un'integrazione propria con Crowdin: questa pagina descrive il metodo supportato.
