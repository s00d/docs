Risposte brevi ai problemi in cui ci si imbatte più spesso, per le domande a cui le pagine tematiche non rispondono direttamente. Ogni risposta rimanda alla pagina responsabile dell'argomento. Se la tua domanda non è qui, cerca nella documentazione o apri una [issue](https://github.com/s00d/nuxt-i18n-micro/issues).

## Traduzioni {#translations}

### `$t` non funziona in un plugin o in una funzione di utilità {#$t-fails-in-a-plugin-or-a-utility-function}

I composable hanno bisogno del contesto Nuxt. Fuori da `setup`, prendi l'helper dall'app, oppure eseguilo nel suo contesto dopo un `await`:

```ts
const nuxtApp = useNuxtApp()
const title = nuxtApp.$t('errors.unknown')
await nuxtApp.runWithContext(() => nuxtApp.$t('errors.unknown'))
```

Nei servizi che non hanno alcuna app, passa le chiavi e traducile nel componente.

### Una chiave appare come testo grezzo solo in una pagina {#a-key-shows-as-raw-text-on-one-page-only}

La chiave si trova nel file di un'altra pagina. Una pagina vede solo il file root e il proprio file `locales/pages/<route-name>/`; sposta le chiavi condivise nel file root. Vedi [File di traduzione](/it/guide/translations).

### Le chiavi lampeggiano durante una transizione di pagina {#keys-flash-while-a-page-transition-runs}

Non dovrebbero: le chiavi della pagina in uscita vengono risolte fino al termine della transizione. Se lampeggiano comunque, la chiave si trova solo nel file di una pagina che non appartiene a nessuna delle due (per esempio in un layout); spostala nel file root.

### Le traduzioni mancano durante l'SSR su Vercel, Netlify o Edge {#translations-are-missing-during-ssr-on-vercel-netlify-or-edge}

Lì la funzione server non può leggere `public/`, quindi i payload vengono incorporati nel bundle del server. Questo è il comportamento predefinito; verifica che `translationPayloads.serverAssets` non sia disattivato. Se il log riporta `public/ is not deployed next to the server`, imposta `nitro.serveStatic: false`. Vedi [Deployment](/it/guide/deployment).

### Come inserisco un link all'interno di una frase tradotta? {#how-do-i-put-a-link-inside-a-translated-sentence}

Usa `<i18n-t>`: ogni slot con nome riempie il `{placeholder}` con lo stesso nome.

```vue
<!-- "share": "Share your {link} with friends" -->
<i18n-t keypath="share">
  <template #link>
    <i18n-link :to="{ name: 'referral' }">{{ $t('referralLink') }}</i18n-link>
  </template>
</i18n-t>
```

Vedi [`<i18n-t>`](/it/components/i18n-t). I linked messages e i modificatori di vue-i18n non sono supportati; componi nel template in questo modo.

## Locale e URL {#locales-and-urls}

### `/en/about` restituisce 404 {#/en/about-is-a-404}

Con il valore predefinito `prefix_except_default`, il locale predefinito non ha prefisso: `/about` è in inglese. Usa `prefix` o `prefix_and_default` se vuoi `/en/...`. Vedi [Strategie di routing](/it/guide/strategy).

### I visitatori non vengono reindirizzati sui deep link {#visitors-are-not-redirected-on-deep-links}

Per impostazione predefinita solo `/` segue la lingua del browser o il cookie, così i link condivisi mantengono la loro lingua. Imposta `autoDetectPath: 'no_prefix'` o `'*'`. Vedi [Rilevamento del locale](/it/guide/locale-detection#autodetectpath).

### La lingua scelta viene dimenticata dopo un ricaricamento {#the-chosen-language-is-forgotten-after-a-reload}

Il cookie del locale è disattivato per le strategie con prefisso. Imposta `localeCookie: 'user-locale'`. Vedi [Rilevamento del locale](/it/guide/locale-detection#the-cookie).

### Posso cambiare locale senza cambiare l'URL? {#can-i-switch-locale-without-changing-the-url}

Solo con `strategy: 'no_prefix'`, dove `$switchLocale('de')` ricarica il dizionario sullo stesso percorso. Con le strategie con prefisso il locale fa parte dell'URL, quindi cambiarlo comporta una navigazione. Per un link anziché una chiamata, usa `$switchLocalePath('de')`.

### La pagina scorre in cima quando cambio locale {#the-page-scrolls-to-the-top-when-i-switch-locale}

È lo `scrollBehavior` di Nuxt per qualsiasi navigazione. Imposta `definePageMeta({ scrollToTop: false })` e ripristina tu stesso la posizione. [`SwitchLocalePreserve.vue`](https://github.com/s00d/nuxt-i18n-micro/blob/main/playground/components/SwitchLocalePreserve.vue) del playground è un wrapper da copiare ([pagina demo](https://github.com/s00d/nuxt-i18n-micro/blob/main/playground/pages/scroll-test.vue)).

## Build e integrazioni {#build-and-integrations}

### `nuxt-seo:defaults depends on nuxt-site-config:i18n but they are not registered` {#nuxt-seodefaults-depends-on-nuxt-site-configi18n-but-they-are-not-registered}

Una vecchia versione di `nuxt-site-config` conosce solo `@nuxtjs/i18n`. Aggiorna `@nuxtjs/seo` alla versione 3 o successiva ed elenca `nuxt-i18n-micro` prima di esso in `modules`. Vedi [SEO](/it/guide/seo).

### Errore di build relativo a `@unhead/vue` su Cloudflare {#build-error-about-@unhead/vue-on-cloudflare}

Installa `@unhead/vue` nell'app così che la fase di prerender lo trovi. Il modulo di per sé non ha bisogno di `nodejs_compat`: aggiungi `compatibility_flags = ["nodejs_compat"]` a `wrangler.toml` solo se qualcos'altro nell'app lo richiede.
