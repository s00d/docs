In `nuxt dev` il modulo aggiunge due strumenti di debug: una scheda **i18n Micro** in Nuxt DevTools per sfogliare e modificare i file di traduzione, e un inspector di Vue DevTools per il locale attivo e i dizionari caricati. Entrambi esistono solo in sviluppo e non aggiungono nulla alle build di produzione. La scheda di Nuxt richiede solo che Nuxt DevTools sia abilitato; l'inspector di Vue richiede anche l'estensione del browser Vue DevTools.

## Scheda di Nuxt DevTools {#nuxt-devtools-tab}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  devtools: { enabled: true }, // the tab is registered only when DevTools are on
})
```

Apri Nuxt DevTools (`Shift + Alt + D`) e scegli **i18n Micro**. La scheda mostra:

- ogni file JSON sotto `locales/` (radice e `pages/`) di ogni layer, più i file radice di `additionalTranslationDirs`;
- un editor per ogni file; **Save** riscrive il file su disco e il server di sviluppo ricarica le traduzioni;
- **Export** / **Import** di un file come JSON, e **Stats** con il numero di chiavi e la copertura delle traduzioni;
- una vista della configurazione con le opzioni del modulo risolte;
- **Translate**, che compila le chiavi mancanti con un motore di traduzione automatica configurato nelle impostazioni della scheda.

Il salvataggio scrive solo file `.json` esistenti all'interno delle tue directory di traduzione. Quando un file esiste in più layer, viene scritta la copia del progetto.

## Inspector di Vue DevTools {#vue-devtools-inspector}

Con l'estensione del browser Vue DevTools, il modulo registra un inspector i18n (locale corrente, chunk della route, chiavi caricate) e una timeline con i cambi di locale, i caricamenti dei chunk e le chiavi mancanti.

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    debug: true, // also log every $t / $ts / $tc call on the timeline
    // vueDevtools: false, // turn the inspector off, keep the Nuxt tab
  },
})
```

[`vueDevtools`](/it/api/module-options) ha come valore predefinito `true`. `debug: true` è prolisso; usalo per sessioni brevi.
