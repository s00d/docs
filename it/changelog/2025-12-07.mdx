**Data**: 2025-12-07

**Versione**: `v2.14.1`

![Rilascio v2.14](/images/2.14.0.png)

Siamo felici di annunciare la **v2.14.1** con integrazioni completamente nuove per Node.js, Vue 3 e Astro! Questi pacchetti portano le stesse potenti funzionalità i18n nei tuoi framework preferiti, condividendo la stessa logica di base per coerenza e prestazioni.

## Novità {#what’s-new}

- **@i18n-micro/node** - Usa le traduzioni i18n in qualsiasi applicazione Node.js, strumento CLI o servizio backend
- **@i18n-micro/vue** - Plugin Vue 3 per l'internazionalizzazione con traduzioni reattive e supporto per traduzioni specifiche per route
- **@i18n-micro/astro** - Integrazione Astro per l'internazionalizzazione con pieno supporto TypeScript
- **@i18n-micro/types-generator** - Generazione automatica dei tipi TypeScript per le chiavi di traduzione, con piena sicurezza dei tipi e autocompletamento nell'IDE

## Caratteristiche principali {#key-features}

Tutte le integrazioni condividono gli stessi vantaggi di base:

- Leggere e performanti
- Supporto per traduzioni specifiche per route
- Pluralizzazione integrata
- Formattazione di numeri, date e tempo relativo
- Pieno supporto TypeScript
- Stessa struttura dei file di traduzione JSON

**Types Generator** offre ulteriori miglioramenti all'esperienza di sviluppo:

- Generazione automatica dei tipi dai file di traduzione JSON
- Chiavi di traduzione type-safe con validazione in fase di compilazione
- Pieno supporto all'autocompletamento nell'IDE
- Hot reload alla modifica dei file di traduzione
- Zero overhead a runtime

Per documentazione dettagliata ed esempi, visita il [repository](https://github.com/s00d/nuxt-i18n-micro) o consulta la [documentazione](https://s00d.github.io/nuxt-i18n-micro/).
