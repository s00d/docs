Siamo entusiasti di annunciare il nuovo comando `text-to-i18n` nella CLI di Nuxt I18n Micro! Questa potente funzionalità automatizza l'estrazione delle stringhe di testo hardcoded dal tuo codice e la loro conversione in chiavi di traduzione i18n. È pensata per farti risparmiare tempo, ridurre gli errori e semplificare il flusso di lavoro di localizzazione.

## Vantaggi principali {#key-benefits}

- **Estrazione automatica del testo**: analizza template Vue e file JavaScript e TypeScript.
- **Generazione fluida delle chiavi**: crea chiavi di traduzione strutturate in base ai percorsi dei file e al contenuto.
- **Gestione efficiente delle traduzioni**: aggiorna i tuoi file di traduzione preservando le voci esistenti.

## Come funziona {#how-it-works}

1. **Scansione dei file**: elabora i file nelle directory principali come `pages`, `components` e `plugins`.
2. **Elaborazione del testo**: individua ed estrae le stringhe traducibili, generando chiavi univoche.
3. **Aggiornamento delle traduzioni**: inserisce automaticamente le nuove chiavi nei tuoi file di traduzione mantenendone la struttura annidata.

## Utilizzo {#usage}

```bash
i18n-micro text-to-i18n [options]
```

Esempio:

```bash
i18n-micro text-to-i18n --translationFile locales/en.json --context auth
```

## Esempi di trasformazione {#example-transformations}

### Prima {#before}

```vue
<template>
  <div>
    <h1>Welcome to our site</h1>
    <p>Please sign in to continue</p>
  </div>
</template>
```

### Dopo {#after}

```vue
<template>
  <div>
    <h1>{{ $t('pages.home.welcome_to_our_site') }}</h1>
    <p>{{ $t('pages.home.please_sign_in') }}</p>
  </div>
</template>
```

Per maggiori dettagli, consulta la [documentazione](/it/guide/cli#turn-hardcoded-text-into-keys).
