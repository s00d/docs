## Requisiti

- **Node.js**: 18 o superiore.
- **Nuxt**: 3.x o 4.x.

Il modulo supporta sia il layout di progetto Nuxt 3 (`pages/**/*.vue`) sia il layout Nuxt 4 (`app/pages/**/*.vue`). Le traduzioni per convenzione si trovano nella root del progetto (`locales/`), anche quando si utilizza la directory `app/` di Nuxt 4.

## Installa il modulo Nuxt

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Registralo in `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Consulta l'[Avvio rapido](/quickstart) per una guida completa oppure il [Riferimento di configurazione](/guides/configuration) per ogni opzione.

## Layout del progetto

Per impostazione predefinita il modulo si aspetta:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

I file a livello root vengono uniti in ogni file specifico per pagina in fase di build. I file specifici per pagina vengono creati automaticamente se mancanti durante `nuxt dev`.

## Layout Nuxt 4

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Per collocare le traduzioni all'interno di `app/`, imposta `translationDir: 'app/locales'`.

| Pacchetto | Scopo |

| [`@i18n-micro/devtools-ui`](/integrations/devtools-ui) | Pannello DevTools indipendente dal framework. |

I pacchetti interni condivisi vengono inclusi in modo transitivo.

## TypeScript

Il modulo genera tipi ambientali per `useI18n`, `$t` e helper correlati in base ai file della locale predefinita. Questa funzionalità è abilitata per impostazione predefinita (`types: true`).

Per una tipizzazione più rigorosa delle chiavi di traduzione, consulta [`@i18n-micro/types-generator`](/integrations/types-generator).
