## Requisiti

- **Node.js**: 18 o più recente.
- **Nuxt**: 3.x o 4.x.

Il modulo supporta sia il layout di progetto Nuxt 3 (`pages/**/*.vue`) sia il layout Nuxt 4 (`app/pages/**/*.vue`). Le traduzioni risiedono per convenzione nella root del progetto (`locales/`), anche quando si usa la directory `app/` di Nuxt 4.

## Installa il modulo Nuxt

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Registralo in `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Consulta la [Guida rapida](/quickstart) per una panoramica completa o il [Riferimento configurazione](/guides/configuration) per tutte le opzioni.

## Layout del progetto

Per impostazione predefinita il modulo si aspetta:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

I file di root vengono uniti in ogni file specifico per pagina in fase di build. I file specifici per pagina vengono creati automaticamente quando mancano durante `nuxt dev`.

## Layout Nuxt 4

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Per co-locare le traduzioni sotto `app/`, imposta `translationDir: 'app/locales'`.

## Pacchetti dell'ecosistema

| Pacchetto | Scopo |
| --- | --- |
| [`@i18n-micro/vue`](/integrations/vue) | Integrazione Vue 3 (autonoma, senza Nuxt). |
| [`@i18n-micro/react`](/integrations/react) | Integrazione React. |

| [`@i18n-micro/node`](/integrations/nodejs) | Loader lato server per Node.js. |

I pacchetti interni condivisi vengono inclusi in modo transitivo.

## TypeScript

Il modulo genera tipi ambient per `useI18n`, `$t` e helper correlati basati sui tuoi file di locale predefiniti. È attivo per impostazione predefinita (`types: true`).

Per una tipizzazione più forte delle chiavi di traduzione, vedi [`@i18n-micro/types-generator`](/integrations/types-generator).
