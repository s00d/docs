---
title: "useI18n"
description: "useI18n restituisce gli helper di runtime (`$t`, `$tc`, `$localePath`, …) come oggetto semplice, con e senza il prefisso `$`."
---

`useI18n()` restituisce gli helper di runtime del modulo come oggetto semplice. Usalo in `<script setup>`, nei composable e nei plugin invece di ricorrere a `useNuxtApp()`. Ogni helper è disponibile con il suo nome con `$` e con un alias senza prefisso: `t` e `$t` sono la stessa funzione.

## Firma {#signature}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Tutti gli helper di runtime, come oggetto semplice.

Le stesse funzioni che il plugin inietta come `$t`, `$tc` e così via, disponibili sia con
il nome con il prefisso del dollaro sia con un alias senza prefisso, quindi sia `const { t } = useI18n()` sia
`const { $t } = useI18n()` funzionano.

**Restituisce**: gli helper descritti nel [riferimento dei metodi](/it/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

L'oggetto restituito contiene tutti gli helper di [`PluginsInjections`](/it/api/methods). Ognuno è documentato nella pagina [Helper](/it/api/methods).

## Esempio {#example}

```vue
<script setup lang="ts">
const { t, tc, localePath, switchLocale, getLocale } = useI18n()

const title = computed(() => t('page.title'))
</script>

<template>
  <h1>{{ title }}</h1>
  <p>{{ tc('items', 3) }}</p>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
  <button @click="switchLocale(getLocale() === 'en' ? 'de' : 'en')">{{ t('nav.switch') }}</button>
</template>
```

## Non presente nel tipo {#not-in-the-type}

`$defineI18nRoute` è tipizzato solo su `useNuxtApp()`:

```ts
const { $defineI18nRoute } = useNuxtApp()
```
