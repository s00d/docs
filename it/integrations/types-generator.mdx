---
title: "Generatore di tipi"
description: "Genera l'autocompletamento TypeScript per le chiavi di traduzione dai tuoi file JSON, in Nuxt o in qualsiasi progetto Vite."
---

`@i18n-micro/types-generator` legge ogni file JSON nella tua cartella delle traduzioni e scrive una dichiarazione che elenca tutte le chiavi. Aggiungilo quando vuoi che il tuo editor suggerisca le chiavi in `t()`, `$t()` e `<I18nT keypath>`. Funziona come modulo Nuxt e come plugin Vite o Rollup, e rigenera i tipi quando un file cambia.

## Installazione {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/types-generator
```

```bash npm
npm install -D @i18n-micro/types-generator
```

```bash yarn
yarn add -D @i18n-micro/types-generator
```

</CodeGroup>

Dipendenza peer: `@nuxt/kit` `^3.18.0 || ^4.0.0`. Solo l'entry `/nuxt` la importa; in un progetto solo Vite l'avviso sulla dipendenza peer può essere ignorato.

## Nuxt {#nuxt}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro', '@i18n-micro/types-generator/nuxt'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Il modulo scrive `.nuxt/types/i18n-micro.d.ts` e Nuxt lo aggiunge al contesto dei tipi; non c'è nulla da includere a mano. Legge `i18nTypes.translationDir`, altrimenti i percorsi da cui `nuxt-i18n-micro` legge le traduzioni: `translationDir` (da `i18n` o dalle opzioni inline del modulo, predefinito `'locales'`) in ogni layer, e `additionalTranslationDirs`. Modificare un file JSON in quella cartella rigenera i tipi in `nuxi dev`. `i18nTypes.outputFile` viene ignorato in Nuxt (un avviso lo segnala).

## Vite {#vite}

`I18nTypesPlugin` è un plugin Vite, accettato anche da Rollup. Per un altro bundler, chiama `generateTypes` in uno script.

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { I18nTypesPlugin } from '@i18n-micro/types-generator'

export default defineConfig({
  plugins: [
    vue(),
    I18nTypesPlugin({
      srcDir: process.cwd(),
      translationDir: 'src/locales',
      outputFile: 'src/i18n-micro.d.ts',
    }),
  ],
})
```

| Opzione | Obbligatoria | Note |
| --- | --- | --- |
| `srcDir` | sì | Directory di base; `translationDir` viene risolto rispetto a essa. |
| `translationDir` | sì | Cartella con i file JSON (incluse sottocartelle come `pages/`), o un array di cartelle. |
| `outputFile` | no | Dove scrivere la dichiarazione; predefinito `<srcDir>/i18n-micro.d.ts`. |

Il plugin genera i tipi una volta all'avvio della build e, sul server di sviluppo, li rigenera 300 ms dopo una modifica nella cartella. Assicurati che `include` del tuo `tsconfig.json` copra il file di output.

## Usare le chiavi {#use-the-keys}

Il file generato estende `DefineLocaleMessage` in `@i18n-micro/types`, che trasforma `TranslationKey` nelle tue chiavi:

```ts
declare module '@i18n-micro/types' {
  export interface DefineLocaleMessage {
    nav: object
    'nav.home': string
    'profile.title': string
  }
}
```

Le chiavi sono quelle a cui risponde `t()`, compresi gli oggetti, da ogni lingua e ogni file di pagina, con il tipo del loro valore JSON. `TranslationKey` è l'unione di queste chiavi più qualsiasi stringa, quindi ottieni l'autocompletamento, non errori: una chiave scritta male o dinamica compila comunque. Parametri e valori di ritorno non sono tipizzati.

Per chiavi dinamiche sotto un prefisso noto, `ScopedKey<'prefix'>` restringe alle chiavi corrispondenti:

```ts
import type { ScopedKey } from '@i18n-micro/types'

const statusText = (status: string) => t(`status.${status}` as ScopedKey<'status'>)
```

`TranslationKey` e `ScopedKey` provengono da `@i18n-micro/types` (React, Preact e Solid riesportano `TranslationKey`; Vue no).

## API {#api}

| Export | Entry | Note |
| --- | --- | --- |
| `I18nTypesPlugin(options)` | `@i18n-micro/types-generator` | plugin Vite e Rollup |
| `generateTypes(options)` | `@i18n-micro/types-generator` | scrive il file, restituisce il suo percorso |
| `getTypesString(options)` | `@i18n-micro/types-generator` | restituisce la dichiarazione senza scriverla |
| `formatKeyProperty(key)` | `@i18n-micro/types-generator` | helper |
| Modulo Nuxt (`configKey: 'i18nTypes'`) | `@i18n-micro/types-generator/nuxt` | opzione `translationDir` |
