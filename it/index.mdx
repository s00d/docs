title: "Nuxt I18n Micro"
description: "i18n piccolo e veloce per Nuxt: traduzioni JSON per pagina, route localizzate al build, tag SEO pronti all'uso."
---

Nuxt I18n Micro è un modulo i18n leggero e ad alte prestazioni per Nuxt 3 e 4, progettato per progetti di grandi dimensioni. Mantiene bassi i tempi di build, l'uso di memoria e la dimensione del bundle rispetto alle soluzioni i18n tradizionali come `@nuxtjs/i18n`.

Le route localizzate vengono generate al build da `@i18n-micro/route-strategy` e risolte a runtime da `@i18n-micro/path-strategy`, così link, switcher, `hreflang` e redirect concordano sempre con il router. Le traduzioni sono solo JSON, suddivise tra file root condivisi e file per pagina che il server di sviluppo crea per te, con HMR integrato.

<CodeGroup>

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>
