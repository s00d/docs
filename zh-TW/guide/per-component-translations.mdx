---
title: "頁面設定"
description: "使用 $defineI18nRoute 將頁面限制於部分 locale、賦予自訂路徑、內嵌翻譯，或停用 SEO 標籤。"
---

`$defineI18nRoute` 可在頁面內部為該頁面設定 i18n 選項。當頁面只存在於部分 locale、需要自己的在地化路徑、帶有少量專屬翻譯，或不得產生 hreflang/canonical 標籤時，請使用它。模組會在建置時讀取此呼叫，並將其寫入產生的路由中。

## 將頁面限制於部分 locale {#restrict-a-page-to-some-locales}

```vue
<!-- pages/product/index.vue -->
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'de'],
})
</script>
```

在預設的 `prefix_except_default` 策略下，只會產生 `/product` 與 `/de/product`；該頁面在其他任何 locale 中都沒有路由。相同設定也可以在 `nuxt.config.ts` 中透過 [`routeLocales`](/zh-TW/api/module-options#routelocales) 完成。

`$defineI18nRoute` 是 Nuxt 應用程式的注入，而非編譯器巨集：請一律從 `useNuxtApp()` 取得，並以帶 `$` 的形式呼叫。建置步驟只會辨識 `$defineI18nRoute(`。

## 加入內嵌翻譯 {#add-inline-translations}

傳入物件而非陣列。其鍵為允許的 locale，其值會合併到目前 locale 的頁面字典中。

```vue
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: {
    en: { greeting: 'Hello' },
    de: { greeting: 'Hallo' },
    fr: {}, // allowed, no inline keys
  },
})
</script>

<template>
  <h1>{{ $t('greeting') }}</h1>
</template>
```

內嵌翻譯會為每個 locale 隨頁面元件一起發佈。超過幾個鍵的內容，建議使用[頁面翻譯檔案](/zh-TW/guide/translations)；內嵌鍵適合用於自成一體的頁面與元件。

## 設定在地化路徑 {#set-localized-paths}

```ts
$defineI18nRoute({
  locales: ['en', 'de'],
  localeRoutes: {
    en: '/welcome',
    de: '/willkommen',
  },
})
```

在 `prefix_except_default` 與 `defaultLocale: 'en'` 下，這會產生 `/welcome` 與 `/de/willkommen`。在內嵌 locale 物件中使用 `path` 也有相同效果：`locales: { de: { path: '/willkommen' } }`。動態參數、巢狀路由以及設定層級的替代方案，請參閱[在地化路徑](/zh-TW/guide/custom-locale-routes)。

## 停用 SEO 標籤 {#turn-off-seo-tags}

```ts
$defineI18nRoute({
  disableMeta: true, // no hreflang, canonical or og:locale tags on this page
})

$defineI18nRoute({
  disableMeta: ['de'], // only the de version has no tags
})
```

設定層級的替代方案是 [`routeDisableMeta`](/zh-TW/api/module-options#routedisablemeta)。這些標籤是什麼，請參閱 [SEO](/zh-TW/guide/seo) 頁面。

## 建置能讀取的內容 {#what-the-build-can-read}

建置步驟會在每個頁面檔案中找到此呼叫，並在不執行應用程式的情況下評估其參數。當設定符合以下情況時即可運作：

- 字面物件（字串、陣列、巢狀物件、樣板字面值、針對 `process.env.NODE_ENV` 的三元運算式）；
- 由同一個 `<script setup>` 中宣告的常數組成（`const locales = ['en', 'de']`，包含展開運算）；
- 帶有 `code` 欄位的物件陣列（`[{ code: 'en' }, { code: 'de' }]`）。

它無法讀取從其他模組匯入的值，或任何需要應用程式在執行階段才能取得的內容（composable、`await`、擷取的資料）。在這種情況下，建置會記錄 `Ignored the $defineI18nRoute() config in <file>`，而頁面會維持預設的 locale 與路由。

在執行階段，此呼叫只會合併目前 locale 的內嵌翻譯，並在 locale 變更時重新合併。`locales`、`localeRoutes` 與 `disableMeta` 僅透過建置生效，因此變更它們需要重新建置（開發伺服器會在存檔時重新建置）。
