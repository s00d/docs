在 `nuxt dev` 中，本模組會加入兩項除錯輔助工具：Nuxt DevTools 中的 **i18n Micro** 分頁，用於瀏覽與編輯翻譯檔；以及一個 Vue DevTools 檢查器，用於查看即時的 locale 與已載入的字典。兩者都只存在於開發模式，不會為正式環境建置增加任何內容。Nuxt 分頁只需要啟用 Nuxt DevTools；Vue 檢查器則另外需要 Vue DevTools 瀏覽器擴充功能。

## Nuxt DevTools 分頁 {#nuxt-devtools-tab}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  devtools: { enabled: true }, // the tab is registered only when DevTools are on
})
```

開啟 Nuxt DevTools（`Shift + Alt + D`）並選擇 **i18n Micro**。此分頁會顯示：

- 每個 layer 的 `locales/`（根目錄與 `pages/`）下的每個 JSON 檔，以及來自 `additionalTranslationDirs` 的根目錄檔案；
- 每個檔案各有一個編輯器；**Save** 會將檔案寫回磁碟，開發伺服器會重新載入翻譯；
- 以 JSON 格式**匯出**／**匯入**檔案，以及顯示鍵數與翻譯涵蓋率的 **Stats**；
- 已解析模組選項的設定檢視；
- **Translate**，可使用你在分頁設定中設定的機器翻譯引擎來填補缺少的鍵。

儲存時只會寫入翻譯目錄中既有的 `.json` 檔案。當某個檔案存在於多個 layer 時，會寫入專案中的那一份。

## Vue DevTools 檢查器 {#vue-devtools-inspector}

安裝 Vue DevTools 瀏覽器擴充功能後，本模組會註冊一個 i18n 檢查器（目前 locale、路由區塊、已載入的鍵），以及一條記錄 locale 切換、區塊載入與缺少鍵的時間軸。

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    debug: true, // also log every $t / $ts / $tc call on the timeline
    // vueDevtools: false, // turn the inspector off, keep the Nuxt tab
  },
})
```

[`vueDevtools`](/zh-TW/api/module-options) 預設為 `true`。`debug: true` 會產生大量輸出；請只在短時間的除錯中使用。

## 在 Nuxt 之外 {#outside-nuxt}

相同的 UI 也以 [`@i18n-micro/devtools-ui`](/zh-TW/integrations/devtools-ui-package) 發布，供以框架套件建置的 Vite 應用程式使用；設定方式請參閱該頁面。
