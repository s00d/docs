---
title: "排除路徑"
description: "使用 excludePatterns 讓頁面與檔案不參與 locale 路由，並查看哪些路徑已預設排除。"
---

有些路徑永遠不該加上 locale 前綴或進行 locale 重新導向：管理後台、健康檢查、產生的 feed。`excludePatterns` 用來標記這些路徑，而內建清單已涵蓋 Nuxt 內部路徑與常見的靜態檔案。被排除的頁面會完全保留你所寫的路徑，並且仍可使用 `$t` 渲染。

## 排除路徑 {#exclude-a-path}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    excludePatterns: [
      '/admin', // /admin and everything below it
      '/preview-*', // glob over the whole path
    ],
  },
})
```

使用此設定時，`pages/admin/index.vue` 只會在 `/admin` 回應；不會有 `/de/admin`，而且 `/admin` 永遠不會被重新導向到 `/de/admin`。

## 模式語法 {#pattern-syntax}

模式會與不含 `app.baseURL` 的路徑進行比對：

| 模式 | 符合 | 不符合 |
| --- | --- | --- |
| `'/admin'` | `/admin`, `/admin/users` | `/administrator`, `/de/admin` |
| `'/preview-*'` | `/preview-1`, `/preview-a/b` | `/de/preview-1` |
| `'/file-?'` | `/file-a` | `/file-ab` |
| `/^\/v\d+\//` | `/v2/docs` | `/docs` |

不含 `*` 或 `?` 的字串會符合該路徑及其下方的完整區段。含有 `*`（任意長度的字元，包含斜線）或 `?`（單一字元）時，則必須符合整個路徑。字串請一律以 `/` 開頭。

## 已預設排除的項目 {#what-is-excluded-already}

以下路徑無需任何設定，永遠不會產生 locale 路由或重新導向：

- `/api` 與 `/_nuxt`，以及其下的所有路徑；
- 翻譯路由，預設為 `/_locales`（[`apiBaseUrl`](/zh-TW/api/module-options#apibaseurl)）；
- 任何含有以 `__` 開頭之區段的路徑（`/__nuxt_content`、`/en/__og-image__`）；
- `/sitemap*.xml`、`/robots.txt`、`/favicon.ico`、`/apple-touch-icon*.png`、`/manifest.json`、`/sw.js`、`/workbox-*.js`；
- 最後一個區段以靜態檔案副檔名結尾的任何路徑：`xml txt ico json js css png jpg jpeg gif svg webp avif pdf wasm map mp4 webm mp3 zip gz woff woff2 ttf eot`。像 `/user/john.doe` 這樣含點的頁面 slug 以及 `.html` 路徑仍會被視為頁面。

## 排除的作用 {#what-an-exclusion-does}

- **路由：** 不會產生在地化的變體；頁面維持原樣。
- **重新導向與 404：** 伺服器重新導向外掛與用戶端重新導向 middleware 會略過該路徑。
- **預先渲染：** 符合的路徑會從預先渲染的路由清單中移除。

它不會阻止 i18n 伺服器 middleware 為請求偵測 locale，也不會阻止頁面使用翻譯。若要讓頁面保持在地化但不產生 SEO 標籤，請使用 `disableMeta`（[頁面設定](/zh-TW/guide/per-component-translations#turn-off-seo-tags)）。若要從 `nuxt.config.ts` 依路徑讓某個頁面不進行在地化，`globalLocaleRoutes: { '/admin': false }`（[在地化路徑](/zh-TW/guide/custom-locale-routes#in-nuxt-config)）在路由方面有相同效果。
