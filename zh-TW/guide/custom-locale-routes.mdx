---
title: "在地化路徑"
description: "透過 localeRoutes 或 globalLocaleRoutes 讓頁面在各語系擁有不同的 URL，包含動態參數與各語系專屬的 slug。"
---

預設情況下，每個語系都在相同路徑提供頁面：`/en/about`、`/de/about`。在地化路徑讓每個語系使用自己的字詞，例如 `/de/ueber-uns`，而頁面檔案維持不變。你可以在頁面中使用 `$defineI18nRoute` 設定，或在 `nuxt.config.ts` 中一次為多個頁面設定。

## 在頁面中 {#in-the-page}

```vue
<!-- pages/about.vue -->
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  localeRoutes: {
    de: '/ueber-uns',
    fr: '/a-propos',
  },
})
</script>
```

在 `prefix_except_default` 與 `defaultLocale: 'en'` 的設定下，此頁面會回應 `/about`、`/de/ueber-uns` 與 `/fr/a-propos`。沒有設定項目的語系會保留預設路徑。撰寫路徑時請不要包含語系代碼：前綴由 [策略](/zh-TW/guide/strategy) 加上，而以語系代碼開頭的路徑會記錄一則警告。此呼叫還接受哪些內容，請參閱 [頁面設定](/zh-TW/guide/per-component-translations)。

## 在 nuxt.config 中 {#in-nuxt-config}

[`globalLocaleRoutes`](/zh-TW/api/module-options#globallocaleroutes) 可對任何頁面做相同的事，以頁面路徑作為鍵（若不以斜線開頭，則以路由名稱作為鍵）：

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    globalLocaleRoutes: {
      '/about': { de: '/ueber-uns' },
      '/about/team': { de: '/ueber-uns/team' },
      '/admin': false, // not localized: one /admin route, no locale prefix
    },
  },
})
```

當頁面設定了 `localeRoutes`，而 `globalLocaleRoutes` 中也有相同的鍵時，以設定檔中的項目為準。

## 動態參數 {#dynamic-params}

參數可使用任何 Nuxt 形式撰寫：`[id]`、`[[page]]`、`[...slug]` 或 `:id()`。參數名稱必須與頁面檔案相符。

```ts
// pages/products/[...slug].vue
$defineI18nRoute({
  localeRoutes: {
    en: '/our-products/[...slug]',
    de: '/unsere-produkte/[...slug]',
  },
})
```

巢狀頁面可使用絕對的子路徑（`/ueber-uns/team`），或相對於父層在地化路徑的路徑（`team`）。

## 連結至在地化頁面 {#linking-to-localized-pages}

無論你傳入的是路由名稱還是一般路徑，連結都會解析為目標語系的在地化路徑：

```vue
<template>
  <i18n-link :to="{ name: 'about' }">About</i18n-link>
  <i18n-link to="/about">About</i18n-link>
  <!-- de: both render /de/ueber-uns -->
  <NuxtLink :to="$localePath('/about', 'de')">Deutsch</NuxtLink>
</template>
```

路由名稱來自檔案路徑（`pages/about/team.vue` 為 `about-team`），除非你透過 `definePageMeta({ name })` 自行設定。

## 各語系專屬的 slug {#per-locale-slugs}

當 slug 本身因語系而異時（`/our-products/red-shoe` 與 `/de/unsere-produkte/roter-schuh`），請在資料載入後使用 `$setI18nRouteParams` 告訴語言切換器要使用哪些參數：

```vue
<script setup lang="ts">
const { $setI18nRouteParams } = useNuxtApp()
const route = useRoute()

const { data: product } = await useFetch(`/api/products/${route.params.slug}`)

if (product.value) {
  $setI18nRouteParams({
    en: { slug: product.value.slugEn },
    de: { slug: product.value.slugDe },
  })
}
</script>
```

接著 `$switchLocalePath('de')` 與 `<i18n-switcher>` 就會連結至 `/de/unsere-produkte/roter-schuh`。鍵為語系代碼，值為依名稱指定的參數（與頁面檔案相同）。

版面配置中的切換器會在頁面的非同步 setup 執行到這裡之前就渲染，因此在渲染結束時，模組會改寫 `<i18n-switcher>` 的連結，不論它位於 `app.vue` 還是頁面中皆然。如此一來，伺服器 HTML、未啟用 JavaScript 的訪客以及第一次用戶端渲染的結果便會一致。為此請在 SSR 期間設定參數：若使用 `lazy` 或 `server: false`，連結只會在 hydration 之後才變更。Nuxt 的 SSR 串流會在參數確定之前就送出 HTML，因此在串流模式下，第一份 HTML 中的連結會保留 URL 本身的參數。

只有切換器自己的連結會被改寫。手動撰寫的 `$switchLocalePath` 連結必須在參數設定之後才渲染，因此請將它放在設定參數的頁面中，並同樣放在 `await` 之後。若放在版面配置中，它會先渲染：其伺服器 HTML 會保留 URL 的參數，而 hydration 會發出不一致的警告。在版面配置中請使用 `<i18n-switcher>`，並透過其 slots 與 `custom*Style` props 調整外觀。

參數屬於設定它們的頁面：

- 當導覽至其他路徑完成時，參數會被捨棄，因此每個頁面都需自行設定。被取消的導覽則會保留參數。
- 請在 `setup` 中從 `useNuxtApp()` 或 `useI18n()` 取得 `$setI18nRouteParams`，即使你之後才在 `useAsyncData` 處理函式中呼叫它也是如此。在 setup 中取得時，函式會知道它所屬的頁面：若訪客已離開，延遲的呼叫將不會有任何作用。
- 使用 `keepalive` 時，訪客返回頁面時，該頁面會取回先前設定的參數。`useI18nHead` 也是如此。

## 在 pages:extend 中新增的路由 {#routes-added-in-pagesextend}

你在 `pages:extend` hook 中推入的路由沒有可供讀取 `$defineI18nRoute` 的頁面檔案，而且其中數個路由經常共用同一個包裝元件。未指定 `name` 而推入的路由，會取得 Nuxt 依其路徑給予的名稱（`/a/:id()` 會變成 `a-id`），讓語言連結能找到它；除非已有其他路由使用該名稱，此時請明確指定 `name`。維護一份清單，並使用 `@i18n-micro/utils/split-locale-routes` 的 `splitLocaleRoutes`（請將此套件加入你的依賴項目）將它拆分為 pages 與以路由名稱為鍵的 `globalLocaleRoutes`：

```ts
// nuxt.config.ts
import { splitLocaleRoutes } from '@i18n-micro/utils/split-locale-routes'

const dynamic = splitLocaleRoutes([
  { name: 'products-tag', path: '/products/:tag', file: '~/pages/_dynamic.vue', paths: { de: '/produkte/:tag' } },
  { name: 'internal', path: '/internal', file: '~/pages/_dynamic.vue', paths: false }, // not localized
])

export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  hooks: {
    'pages:extend'(pages) {
      pages.push(...dynamic.pages)
    },
  },
  i18n: {
    globalLocaleRoutes: dynamic.globalLocaleRoutes,
  },
})
```

請勿將在地化路徑放在 `route.meta` 中：它們會被包含在用戶端的路由表中送出。
