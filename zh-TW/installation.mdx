## 系統需求

- **Node.js**：18 或更新版本。
- **Nuxt**：3.x 或 4.x。

此模組同時支援 Nuxt 3 專案結構（`pages/**/*.vue`）與 Nuxt 4 結構（`app/pages/**/*.vue`）。依照慣例，即使你使用 Nuxt 4 的 `app/` 目錄，翻譯檔案仍放在專案根目錄（`locales/`）。

## 安裝 Nuxt 模組

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

在 `nuxt.config.ts` 中註冊：

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

如需完整流程請見[快速開始](/quickstart)，各選項的說明請見[設定參考](/guides/configuration)。

## 專案結構

模組預設預期的結構為：

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

建置期會將根層檔案合併進每個頁面專屬檔案。頁面專屬檔案若缺失，會在 `nuxt dev` 執行時自動建立。

## Nuxt 4 結構

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

若要將翻譯檔集中放在 `app/` 下，請設定 `translationDir: 'app/locales'`。

## 生態系套件

| 套件 | 用途 |
| --- | --- |
| [`@i18n-micro/vue`](/integrations/vue) | Vue 3 整合（獨立使用，不依賴 Nuxt）。 |
| [`@i18n-micro/react`](/integrations/react) | React 整合。 |
| [`@i18n-micro/preact`](/integrations/preact) | Preact 整合。 |
| [`@i18n-micro/solid`](/integrations/solid) | SolidJS 整合。 |
| [`@i18n-micro/astro`](/integrations/astro) | Astro 整合。 |
| [`@i18n-micro/node`](/integrations/nodejs) | Node.js 伺服器端載入器。 |
| [`@i18n-micro/types-generator`](/integrations/types-generator) | 依據翻譯檔產生 TypeScript 型別。 |
| [`@i18n-micro/devtools-ui`](/integrations/devtools-ui) | 與框架無關的 DevTools 面板。 |

共用的內部套件會透過相依性自動引入。

## TypeScript

此模組會依照你的預設語系檔案為 `useI18n`、`$t` 以及相關輔助方法產生環境型別，預設即開啟（`types: true`）。

若要為翻譯鍵取得更強型別支援，請見 [`@i18n-micro/types-generator`](/integrations/types-generator)。
