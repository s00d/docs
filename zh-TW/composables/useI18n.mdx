`useI18n()` 以一般物件的形式回傳模組的執行階段輔助函式。請在 `<script setup>`、composables 與外掛中使用它，而不必透過 `useNuxtApp()` 取得。每個輔助函式都同時以 `$` 名稱與不帶前綴的別名提供：`t` 與 `$t` 是同一個函式。

## 簽章 {#signature}

```ts
useI18n(): PluginsInjectionsWithAliases
```

以一般物件形式提供的所有執行階段輔助函式。

與外掛注入為 `$t`、`$tc` 等的函式相同，同時以帶有錢字號前綴的名稱與不帶前綴的別名提供
— 因此 `const { t } = useI18n()` 與 `const { $t } = useI18n()` 都能使用。

**回傳值** — [方法參考](/zh-TW/api/methods) 中所述的輔助函式

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

回傳的物件包含 [`PluginsInjections`](/zh-TW/api/methods) 的所有輔助函式。每一個都記錄在 [輔助函式](/zh-TW/api/methods) 頁面中。

## 範例 {#example}

```vue
<script setup lang="ts">
const { t, tc, localePath, switchLocale, getLocale } = useI18n()

const title = computed(() => t('page.title'))
</script>

<template>
  <h1>{{ title }}</h1>
  <p>{{ tc('items', 3) }}</p>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
  <button @click="switchLocale(getLocale() === 'en' ? 'de' : 'en')">{{ t('nav.switch') }}</button>
</template>
```

## 不在型別中的項目 {#not-in-the-type}

`$defineI18nRoute` 僅在 `useNuxtApp()` 上有型別定義：

```ts
const { $defineI18nRoute } = useNuxtApp()
```
