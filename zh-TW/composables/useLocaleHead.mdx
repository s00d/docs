---
title: "useLocaleHead"
description: "useLocaleHead 會將 i18n SEO 標籤（lang、dir、canonical、hreflang、og:locale）建構成可傳給 useHead 的物件。"
---

`useLocaleHead()` 會為目前路由建構 i18n head 標籤：`<html>` 上的 `lang` 與 `dir`、canonical 連結、含 `x-default` 的 `hreflang` 替代連結、`og:url`、`og:locale` 與 `og:locale:alternate`。當你設定 [`meta: false`](/zh-TW/api/module-options#meta) 並自行管理 `useHead` 時使用它；若為 `meta: true`，模組已會註冊這些標籤，而各頁面的變更則透過 [`useI18nHead`](/zh-TW/composables/useI18nHead) 進行。

## 簽章 {#signature}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { build: () => LocaleHead; metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }, LocaleHead | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

目前路由的 SEO head 標籤：每個語系的 `hreflang` 替代連結加上
`x-default`、canonical 連結、`og:locale`，以及 `<html>` 上的 `lang`/`dir`。

只有在停用 `meta` 或需要調整預設值時才需要 — 若為 `meta: true`，
模組會自行註冊相同的標籤。

| 參數 | 型別 | 說明 |
| --- | --- | --- |
| `options` | `UseLocaleHeadOptions` |  |

**回傳值** — `metaObject`，一個保存可直接傳給 `useHead` 之 head 物件的 ref；`updateMeta` 會重新整理它；`build` 會依目前路由計算 head 物件（在 getter 中讀取時具反應性，例如 `useHead(() => build())`）

```ts
const { metaObject } = useLocaleHead({ addSeoAttributes: true })
useHead(metaObject)
```

## 選項 {#options}

| 選項 | 預設值 | 說明 |
| --- | --- | --- |
| `addDirAttribute` | `true` | 依語系的 `dir` 設定 `<html>` 上的 `dir`（若未設定則為 `'auto'`）。 |
| `identifierAttribute` | `'id'` | 用來識別每個標籤的屬性（`i18n-can`、`i18n-og`、`i18n-alternate-<hreflang>`、…），讓更新時取代標籤而非新增。 |
| `addSeoAttributes` | `true` | 輸出 canonical、`hreflang` 與 `og:` 標籤。設為 `false` 則僅保留 `htmlAttrs`。 |
| `baseUrl` | `'/'` | 接在每個 URL 前面的來源（origin）。相對 URL 請保留 `'/'`；絕對 URL 請傳入 `'https://example.com'`。 |
| `autoUpdate` | `true` | 當路由或 `i18n-locale` 狀態變更時重建 `metaObject`。 |

## 輸出內容 {#what-it-emits}

- 在沒有匹配的路由（404）上，或對目前語系設定了 `disableMeta` 時，不輸出任何內容。
- Canonical 與 `og:url`：`$switchLocalePath(<active locale>)`，查詢參數會縮減至 [`canonicalQueryWhitelist`](/zh-TW/api/module-options#canonicalquerywhitelist) 所列項目，並套用 [`trailingSlash`](/zh-TW/api/module-options#trailingslash)。
- `hreflang`：頁面所存在的每個已啟用語系各一個連結，`hreflang = iso || code`，略過設定 `seo: false` 的語系；若設定 `hreflangBaseLanguage: true`，某語言的第一個區域語系也會輸出其單純語言標籤。在 `no_prefix` 下不輸出。
- `x-default`：預設語系的 URL，除非策略為 `no_prefix`、預設語系設定了 `seo: false`，或頁面不存在於該語系中。
- `og:locale` / `og:locale:alternate`：取自語系的 `og`，或由其 `iso` 轉換而來（`en-US` → `en_US`）；兩者皆不可用時會略過，並顯示開發警告。

## 範例 {#example}

```ts
// app.vue, with i18n.meta: false
const { metaObject } = useLocaleHead({ baseUrl: 'https://example.com' })
useHead(metaObject)
```

`build()` 會回傳不含 ref 的相同物件：`useHead(() => build())` 無需 watcher 即可保持反應性。
