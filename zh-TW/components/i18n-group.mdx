title: "<i18n-group>"
description: "<i18n-group> 元件會為其 slot 提供一個限定於某個鍵前綴的 t 函式。"
---

`<i18n-group>` 會將一段標記限定在同一個鍵前綴下。當某個區塊中的許多鍵共用同一個前綴，而你不想重複撰寫時，就可以使用它。預設 slot 會收到一個會自動加上前綴的 `t`。

## Props 與 slot {#props-and-slot}

| Prop | 型別 | 預設值 | 說明 |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | slot 內每次查找所依據的鍵前綴。 |
| `groupClass` | `string` | `''` | 外層元素的額外 class。 |

**\*** 必填。

### Slots {#slots}

| Slot | 綁定 | 說明 |
| --- | --- | --- |
| `default` | `prefix`, `t` | 接收 `prefix` 以及限定於該前綴的 `t` 函式。 |

## 行為 {#behaviour}

- 在 slot 外層渲染 `<div class="i18n-group {groupClass}">`。
- 對目前路由而言，`t(key, params)` 等同於 `$t(prefix + '.' + key, params)`。
- 只有 slot 的 `t` 會被限定範圍：群組內的 `$t` 與巢狀的 `<i18n-t>` 仍然需要完整的鍵。

## 範例 {#example}

```json
{
  "checkout": { "title": "Checkout", "items": "Items: {count}" }
}
```

```vue
<template>
  <i18n-group prefix="checkout" group-class="checkout">
    <template #default="{ t }">
      <h2>{{ t('title') }}</h2>
      <p>{{ t('items', { count: 3 }) }}</p>
    </template>
  </i18n-group>
</template>
```
