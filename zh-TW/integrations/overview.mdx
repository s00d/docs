# 整合

`@i18n-micro` 套件是 Nuxt I18n Micro 的輕量、框架專屬版本，設計用於整合到各種框架與環境。這些套件以最小的足跡提供核心國際化功能，聚焦於必要的翻譯功能與基本元件。

## 總覽

這些整合套件是完整 Nuxt I18n Micro 模組的**迷你版本**，僅包含國際化所需的關鍵功能：

- **核心翻譯功能**：基本翻譯方法、複數形與格式化
- **必要元件**：一小組處理常見 i18n 任務的 UI 元件
- **路由介接模式**：透過介接抽象達成彈性的路由整合
- **TypeScript 支援**：完整型別定義，支援型別安全的開發

與完整 Nuxt 模組不同，這些套件：

- 不包含框架專屬的路由邏輯
- 若要使用路由功能，需自行實作路由 adapter
- 聚焦於翻譯功能而非框架整合
- 設計上盡可能輕量且與框架無關

## 核心元件

所有框架套件皆包含以下必要元件：

### `<I18nT>`

翻譯元件，可渲染已翻譯文字，支援：

- **參數插值**：以動態值取代 placeholder
- **複數形**：依 count 自動選擇複數形
- **數字格式化**：依語系格式化數字
- **日期格式化**：日期與相對時間
- **HTML 渲染**：可選擇性以 HTML 內容渲染
- **預設值**：翻譯缺失時提供 fallback 文字

**範例：**

```vue
<!-- Vue -->
<I18nT keypath="greeting" :params="{ name: 'World' }" />
```

```tsx
// React
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```tsx
// Solid
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```astro
<!-- Astro -->
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

### `<I18nLink>`

多語系連結元件，自動處理 URL 中的語系前綴。特色：

- **自動路徑在地化**：依路由策略加入／移除語系前綴
- **作用中狀態偵測**：標示目前所在路由
- **外部連結支援**：自動偵測並處理外部 URL
- **與 router 整合**：可用時使用 router adapter 的連結元件
- **自訂樣式**：支援作用中與 hover 狀態

**範例：**

```vue
<!-- Vue -->
<I18nLink to="/about" active-class="active">
  About Us
</I18nLink>
```

```tsx
// React
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```tsx
// Solid
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```astro
<!-- Astro -->
<I18nLink href="/about" class="nav-link">
  About Us
</I18nLink>
```

### `<I18nSwitcher>`

語言切換元件，提供下拉或清單介面切換語系。特色：

- **自動語系清單**：由已設定語系產生選項
- **標示目前語系**：以視覺方式標出作用中語言
- **自訂標籤**：可為每個語系設定自訂顯示名稱
- **與 router 整合**：自動導覽到在地化路徑
- **無障礙**：適當的 ARIA 屬性與鍵盤操作

**範例：**

```vue
<!-- Vue -->
<I18nSwitcher />
```

```tsx
// React
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```tsx
// Solid
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```astro
<!-- Astro -->
<I18nSwitcher />
```

### `<I18nGroup>`

將翻譯以共用前綴分組的元件，適合依頁面或功能組織翻譯。特色：

- **前綴 scope**：自動為群組內所有翻譯鍵加上前綴
- **巢狀群組**：支援巢狀翻譯群組
- **清晰的組織**：協助維持翻譯結構的組織性

**範例：**

```vue
<!-- Vue -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

```tsx
// React
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```tsx
// Solid
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```astro
<!-- Astro -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

## 共用的 `createI18n` 選項 \{#create-i18n-options\}

每個框架套件的建立方式相同，只有選項型別依框架命名（`ReactI18nOptions`、`SolidI18nOptions` 等）。選項本身完全相同：

| 屬性              | 型別                                                        | 必填 | 預設值           | 說明                                    |
| ---------------- | ---------------------------------------------------------- | ---- | ---------------- | -------------------------------------- |
| `locale`         | `string`                                                   | ✅   | -                | 目前語系代碼（例如 `'en'`）             |
| `fallbackLocale` | `string`                                                   | ❌   | 同 `locale`      | 翻譯缺失時的 fallback 語系                |
| `messages`       | `Record<string, Translations>`                             | ❌   | `\{\}`             | 初始翻譯訊息                             |
| `plural`         | `PluralFunc`                                               | ❌   | `defaultPlural`  | 自訂複數規則函式                         |
| `missingWarn`    | `boolean`                                                  | ❌   | `true`           | 對缺失翻譯顯示 console 警告               |
| `missingHandler` | `(locale: string, key: string, routeName: string) => void` | ❌   | -                | 自訂缺失翻譯處理器                       |

超出以上的選項屬於框架專屬，記錄於各套件頁面。

## Router Adapter 抽象

所有框架套件使用 **router adapter 模式**，將 i18n 功能與特定 router 實作解耦。此設計帶來：

- **彈性**：可使用任何 router 函式庫，或完全不使用 router
- **框架獨立**：路由邏輯留在你的應用中，不寫在 i18n 套件裡
- **輕量核心**：i18n 套件保持小巧、聚焦

### 實作 Router Adapter

若要使用路由功能，需實作 `I18nRoutingStrategy` 介面：

```typescript
interface I18nRoutingStrategy {
  getCurrentPath: () => string
  linkComponent?: Component
  push: (target: { path: string }) => void
  replace: (target: { path: string }) => void
  resolvePath?: (to: string | { path?: string }, locale: string) => string | { path?: string }
  getRoute?: () => { fullPath: string; query: Record<string, unknown> }
}
```

每個套件的文件都包含流行 router 的 adapter 實作完整範例：

- **Vue**：Vue Router adapter 範例
- **React**：React Router adapter 範例
- **Solid**：Solid Router adapter 範例
- **Astro**：檔案式路由 adapter 範例

## 核心功能

所有套件共用以下核心功能：

### 翻譯方法

- `t()`：帶參數插值的基本翻譯
- `ts()`：一律回傳字串的翻譯
- `tc()`：具複數形的翻譯
- `tn()`：數字格式化
- `td()`：日期格式化
- `tdr()`：相對時間格式化
- `has()`：檢查翻譯鍵是否存在

### 語系管理

- **語系切換**：以程式化方式變更目前語系
- **Fallback 語系**：翻譯缺失時自動 fallback
- **逐路由翻譯**：頁面層級的翻譯組織
- **翻譯快取**：智慧型快取以提升效能

### TypeScript 支援

所有套件皆提供：

- 完整 TypeScript 定義
- 型別安全的翻譯鍵（搭配 types generator）
- IDE 中的 IntelliSense 支援
- 建置時錯誤檢查

## 快速開始

1. **選擇套件**：為你的框架選擇對應套件
2. **安裝套件**：使用你偏好的套件管理器
3. **閱讀文件**：每個套件都有詳細設定說明
4. **實作 router adapter**：若需路由功能，實作 adapter
5. **開始翻譯**：使用元件與方法加入翻譯
