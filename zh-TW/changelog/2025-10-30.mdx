**日期**：2025-10-30

**版本**：`v2.0.0`

![v2.0.0 版本](/images/2.0.0.png)

我們在開發環境中為翻譯檔案導入伺服器端 HMR。當 JSON 翻譯檔變更時，伺服器快取只會讓受影響的鍵失效，之後的請求會立即取得最新資料，完全不需要重新啟動。

## 有哪些新功能？ {#what’s-new}

- 翻譯檔案的伺服器端 HMR
- 依頁面／locale 即時讓快取失效
- 編輯內容時提供流暢的開發體驗

## 運作方式 {#how-it-works}

- `src/runtime/server/plugins/watcher.dev.ts` 中的監看器會觀察 `<rootDir>/<translationDir>/**/*.json`
- 頁面檔案（例如 `pages/<page>/<locale>.json`）會讓 `_locales:merged:<page>:<locale>` 失效
- 根層級檔案（例如 `<locale>.json`）會讓該 locale 的所有合併鍵失效
- 在開發環境中當 `experimental.hmr !== false` 時，會由 `src/module.ts` 自動註冊

## 設定 {#configuration}

```ts
export default defineNuxtConfig({
  i18n: {
    experimental: { hmr: true }, // default in dev
  },
})
```
