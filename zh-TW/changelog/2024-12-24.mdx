**日期**：2024-12-24

**引入的 CLI 版本**：`v1.1.0`

![v1.1.0 CLI text-to-i18n 示範](/images/text-to-i18n.gif)

我們很高興宣布 Nuxt I18n Micro CLI 推出全新的 `text-to-i18n` 指令！這項強大的功能會自動從你的程式碼中擷取寫死的文字字串，並將其轉換為 i18n 翻譯鍵。它的設計目的是節省時間、減少錯誤，並簡化你的在地化工作流程。

## 主要優點 {#key-benefits}

- **自動擷取文字**：掃描 Vue 範本、JavaScript 與 TypeScript 檔案。
- **無縫產生鍵**：依據檔案路徑與內容建立結構化的翻譯鍵。
- **高效管理翻譯**：更新翻譯檔案的同時保留既有項目。

## 運作方式 {#how-it-works}

1. **掃描檔案**：處理 `pages`、`components` 與 `plugins` 等主要目錄中的檔案。
2. **處理文字**：辨識並擷取可翻譯的字串，產生唯一的鍵。
3. **更新翻譯**：自動將新鍵插入翻譯檔案，並維持其巢狀結構。

## 使用方式 {#usage}

```bash
i18n-micro text-to-i18n [options]
```

範例：

```bash
i18n-micro text-to-i18n --translationFile locales/en.json --context auth
```

## 轉換範例 {#example-transformations}

### 轉換前 {#before}

```vue
<template>
  <div>
    <h1>Welcome to our site</h1>
    <p>Please sign in to continue</p>
  </div>
</template>
```

### 轉換後 {#after}

```vue
<template>
  <div>
    <h1>{{ $t('pages.home.welcome_to_our_site') }}</h1>
    <p>{{ $t('pages.home.please_sign_in') }}</p>
  </div>
</template>
```
