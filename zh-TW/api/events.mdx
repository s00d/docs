本模組只會呼叫一個執行階段（app）hook：`i18n:register`。當外掛或模組要加入不在 `locales/` 檔案中的翻譯時，請使用它。你的回呼函式會取得一個 `register` 函式，用來將翻譯合併到正在顯示的頁面中。

## `i18n:register` {#i18nregister}

```ts
'i18n:register': (
  register: (translations: unknown, locale?: string) => void,
  locale: string,
) => HookResult
```

| 參數 | 說明 |
| --- | --- |
| `register(translations, locale?)` | 將 `translations` 深度合併到正在載入之路由的頁面區塊中，對應 `locale`（預設：hook 的 `locale`）。已存在的鍵會被覆寫。 |
| `locale` | 正在載入之路由的 locale。 |

此 hook 透過 `RuntimeNuxtHooks` 定義型別，因此 `nuxtApp.hook('i18n:register', …)` 不需要轉型。

## 觸發時機 {#when-it-fires}

載入器外掛（`i18n-plugin-loader`）會在以下時機呼叫它：

1. 啟動時一次，在所有外掛都執行完畢後（`app:created`）、應用程式渲染之前；
2. 在其 `router.beforeEach` 中，當路徑變更時、目標頁面的翻譯載入完成之後——在 `no_prefix` 下則是每次導覽時。

每個回呼與每次 `register` 呼叫都會在應用程式渲染或導覽繼續之前被 await，因此頁面渲染時就會帶有合併後的鍵。設定 [`hooks: false`](/zh-TW/api/module-options#hooks) 時，此 hook 永遠不會被呼叫。

## 範例 {#example}

```ts
// plugins/i18n-extra.ts
export default defineNuxtPlugin((nuxtApp) => {
  nuxtApp.hook('i18n:register', async (register, locale) => {
    const extra = await $fetch<Record<string, unknown>>(`/api/cms-strings/${locale}`)
    register(extra, locale)
  })
})
```

這是執行階段 hook：請在外掛中以 `nuxtApp.hook` 註冊，而不是在 `nuxt.config` 或模組的 `setup` 中以 `nuxt.hook` 註冊。模組可以透過 `addPlugin` 加入這樣的外掛。
