# 🌍 `<i18n-switcher>` 元件

`Nuxt I18n Micro` 中的 `<i18n-switcher>` 元件提供一個親民的下拉介面，可在應用中切換不同語系。此元件高度可自訂，能與應用的設計與版面順暢整合。

設為 `disabled: true` 的語系會從下拉選單中**被隱藏**（但仍能透過 `$getLocales()` 用於 SEO／head 標籤）。只有可切換的語系才會取得 `NuxtLink` 與 `hreflang`。

各部分預設不含樣式：`custom*Style` prop 接收 inline 樣式物件；當樣式不足以達成需求時，下方列出的 slot 可完全取代對應區塊的標籤內容。

## 🛠️ 用法範例

### 基本用法

```vue
<template>
  <i18n-switcher />
</template>
```

這會渲染一個具備預設樣式與行為的語系切換器。

### 自訂標籤與 inline 樣式

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

此範例展示帶有自訂標籤與 inline 樣式的完整自訂語系切換器。

## 🔌 Slots

切換器的每個視覺部分皆可替換。所有 slot 皆已列於上方 prop 表格中，可傳入樣板內容：

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

名稱以 `-item`、`-link-content` 結尾或以 `before-item` 開頭的 slot 會接收所屬的 `locale` 物件。

## 🎨 樣式概觀

`<i18n-switcher>` 元件內建以 inline 樣式定義的基本外觀，可輕鬆透過 prop 傳入自訂樣式覆寫。預設樣式概觀如下：

- **Wrapper**：控制下拉選單的定位。
- **Button**：下拉切換按鈕的樣式。
- **Dropdown**：下拉清單的樣式。
- **Items**：清單中每個項目的樣式。
- **Links**：各項目內連結的樣式。
- **Icon**：下拉指示圖示的樣式。

你可以透過對應 prop 傳入自訂樣式，讓語系切換器與應用的 UI 順暢整合。
