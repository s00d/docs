# 🌍 `<i18n-t>` 元件

`Nuxt I18n Micro` 中的 `<i18n-t>` 是一個彈性的翻譯元件，透過 slot 支援動態內容插入。你可以將自訂 Vue 元件或 HTML 內容插值到翻譯中，實現更進階的在地化情境。

## ⚙️ Props

| `keypath` **\*** | `string` | — | 要渲染的翻譯鍵。 |
| `plural` | `number \| string` | — | 用於選擇複數形的數量。設定後會改用 `$tc` 而非 `$t`。 |
| `tag` | `string` | `'span'` | 要渲染的元素。 |
| `params` | `Record<string, string \| number \| boolean>` | `() => (\{\})` | 要插值到翻譯中的參數值。 |
| `defaultValue` | `string` | `''` | 當 `hideIfEmpty` 因翻譯為空而抑制渲染時，改為渲染此內容。 |
| `html` | `boolean` | `false` | 將翻譯以 HTML 而非文字渲染。僅用於你能完全控制的內容。 |
| `hideIfEmpty` | `boolean` | `false` | 當翻譯結果為空字串時不渲染任何內容。 |
| `customPluralRule` | `PluralFunc` | `null` | 僅套用於此元素的複數規則，會覆寫設定中的規則。 |
| `number` | `number \| string` | — | 以 `$tn` 格式化該值，並以 `\{number\}` 名稱傳入翻譯。 |
| `date` | `Date \| string \| number` | — | 以 `$td` 格式化該值，並以 `\{date\}` 名稱傳入翻譯。 |
| `relativeDate` | `Date \| string \| number` | — | 以 `$tdr` 格式化該值，並以 `\{relativeDate\}` 名稱傳入翻譯。 |

**\*** 必填。

{/* /generated:component:i18n-t */}

`plural`、`number`、`date` 與 `relativeDate` 每次只能套用其一；若同時設定多個，會依上述順序取第一個。

### 各 prop 的範例

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

```json
{
  "items": "Nothing|You have {count} item|You have {count} items"
}
```

## 🛠️ 用法範例

### 基本用法

```vue
<i18n-t keypath="feedback.text" />
```

這會將 `feedback.text` 的翻譯渲染在 `<span>` 標籤中。

### 使用 Slot 呈現動態內容

`<i18n-t>` 元件支援 slot，可將 Vue 元件或其他內容動態插入翻譯的特定部分。

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

此範例中，`feedback.text` 翻譯字串中的 `\{link\}` placeholder 會被替換為 `<nuxt-link>` 元件，該元件內部又包含另一個翻譯元件。

### 複數形

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

這會依據 `itemCount` 值自動套用複數形規則。

## 🚀 進階功能

### 預設 slot

若未指定特定 slot，可透過預設 slot 自訂翻譯內容，該 slot 會提供整個翻譯字串：

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### 條件式渲染

使用 `hideIfEmpty` prop 可在翻譯字串為空時不渲染任何內容。

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### 自訂複數規則

使用自訂函式處理複數形。

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### 搭配 slot 的進階範例

利用 slot 自訂翻譯內容的呈現方式。

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
