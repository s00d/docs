[CLI 指南](/zh-TW/guide/cli)介紹常見的工作流程。本頁列出所有內容，並由驅動 `--help` 的同一份指令表產生。

## 通用旗標 {#common-flags}

| 旗標 | 預設值 | 說明 |
| --- | --- | --- |
| `--cwd` | 目前目錄 | 專案目錄 |
| `--logLevel` | `info` | 輸出等級：silent、info |
| `--debug` | `false` | 指令失敗時印出堆疊追蹤 |

## 檢視 {#inspect}

### `info` {#info}

印出專案解析後的 i18n 設定

| 旗標 | 預設值 | 說明 |
| --- | --- | --- |
| `--json` | `false` | 以 JSON 而非文字輸出 |

### `check` {#check}

CI 關卡：遇到缺少、空白、多餘、未定義或未使用的鍵，以及損壞的預留位置時即失敗

| 旗標 | 預設值 | 說明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config 的 `i18n.translationDir` | 翻譯目錄，相對於專案 |
| `--only` | 除 duplicates 以外全部 | 以逗號分隔要執行的檢查：missing、empty、extra、placeholders、undefined、unused、duplicates。在此指定的 `unused` 若無法執行則會失敗 |
| `--duplicates` | `false` | 同時回報不同鍵下的相同文字 |
| `--ignore` | — | 以逗號分隔要略過的原始檔 glob，相對於專案 |
| `--json` | `false` | 以 JSON 而非文字輸出 |

```bash
i18n-micro check
i18n-micro check --only missing,placeholders --json
```

### `stats` {#stats}

顯示每個 locale 的翻譯完成度

| 旗標 | 預設值 | 說明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config 的 `i18n.translationDir` | 翻譯目錄，相對於專案 |
| `--html` | — | 另外將 HTML 報告寫入此檔案 |
| `--json` | `false` | 以 JSON 而非文字輸出 |
| `--baseRef` | — | 用來比較完成度的 Git ref，例如 HEAD~1 或 main |

```bash
i18n-micro stats --baseRef main
i18n-micro stats --html reports/i18n.html
```

### `lint` {#lint}

檢查翻譯文字；仍有問題時即失敗

| 旗標 | 預設值 | 說明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config 的 `i18n.translationDir` | 翻譯目錄，相對於專案 |
| `--rules` | 全部，或 .i18n-lintrc.json 的 `enabledRules` | 以逗號分隔要執行的規則：no-trailing-spaces、no-multiple-spaces、no-empty-translation，或自訂規則 |
| `--fix` | `false` | 修正可修正的部分：空白，以及帶有替換值的自訂規則 |
| `--json` | `false` | 以 JSON 而非文字輸出 |

```bash
i18n-micro lint --rules no-trailing-spaces --fix
```

### `search` {#search}

搜尋鍵與值，並顯示每個鍵的使用位置

| 旗標 | 預設值 | 說明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config 的 `i18n.translationDir` | 翻譯目錄，相對於專案 |
| `<query>` | — | 要搜尋的文字或鍵 |
| `--caseSensitive` | `false` | 區分大小寫 |
| `--onlyUnused` | `false` | 僅列出 `clean` 會移除的鍵；此時查詢字串變為選填 |
| `--scope` | `all` | 搜尋範圍：global、pages、all |
| `--limit` | — | 最多回傳這麼多個鍵 |
| `--ignore` | — | 以逗號分隔要略過的原始檔 glob，相對於專案 |
| `--json` | `false` | 以 JSON 而非文字輸出 |

```bash
i18n-micro search "Welcome"
i18n-micro search --onlyUnused
```

## 翻譯工作流程 {#translation-workflow}

### `extract` {#extract}

列出原始檔中使用但尚無文字的鍵，並將帶有預設文字者加入預設 locale

| 旗標 | 預設值 | 說明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config 的 `i18n.translationDir` | 翻譯目錄，相對於專案 |
| `--ignore` | — | 以逗號分隔要略過的原始檔 glob，相對於專案 |

```bash
i18n-micro extract
```

### `translate` {#translate}

透過翻譯服務，以預設 locale 填補缺少的翻譯

| 旗標 | 預設值 | 說明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config 的 `i18n.translationDir` | 翻譯目錄，相對於專案 |
| `--service` | — | 翻譯服務：ai、azure、deepl、google、libretranslate、yandexcloud |
| `--token` | — | API 金鑰。建議改用 I18N_TRANSLATE_TOKEN 環境變數：旗標會留在 shell 歷史紀錄中 |
| `--options` | — | 服務選項，為以逗號分隔的 key:value 配對 |
| `--locale` | 除預設 locale 以外的所有 locale | 以逗號分隔要填補的 locale |
| `--replace` | `false` | 重新翻譯每個鍵，取代既有的值 |
| `--dryRun` | `false` | 計算每個 locale 的鍵數與字元數；不送出任何請求 |
| `--chunkSize` | — | 每次請求的字串數；上限為服務所能接受的數量 |
| `--pluralSeparator` | `\|` | 訊息中複數形式的分隔符號 |
| `--glossaryFile` | 存在時為 `.i18n-glossary.json` | 詞彙表檔案，供 `ai` 服務使用 |

```bash
i18n-micro translate --dryRun
I18N_TRANSLATE_TOKEN=... i18n-micro translate --service deepl --locale de,fr
i18n-micro translate --service ai --options provider:openai,model:gpt-4o-mini
i18n-micro translate --service libretranslate --options baseUrl:https://translate.example.com
```

### `sync` {#sync}

移除預設 locale 沒有的鍵；無法證明安全時即停止。缺少的鍵仍維持缺少

| 旗標 | 預設值 | 說明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config 的 `i18n.translationDir` | 翻譯目錄，相對於專案 |
| `--ignore` | — | 以逗號分隔要略過的原始檔 glob，相對於專案 |
| `--dryRun` | `false` | 列出將被移除的項目；不寫入任何內容 |
| `--force` | `false` | 即使無法證明安全也移除鍵 |

```bash
i18n-micro sync --dryRun
```

### `clean` {#clean}

移除專案中沒有任何地方使用的鍵；無法證明時即停止

| 旗標 | 預設值 | 說明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config 的 `i18n.translationDir` | 翻譯目錄，相對於專案 |
| `--include` | — | 正規表示式：僅考慮移除符合的鍵 |
| `--exclude` | — | 正規表示式：絕不移除符合的鍵 |
| `--ignore` | — | 以逗號分隔要略過的原始檔 glob，相對於專案 |
| `--dryRun` | `false` | 列出將被移除的項目；不寫入任何內容 |
| `--force` | `false` | 即使無法證明所有鍵的使用情形也移除鍵 |

```bash
i18n-micro clean --dryRun
i18n-micro clean --exclude '^errors\.'
```

## 重構 {#refactoring}

### `text-to-i18n` {#text-to-i18n}

將 Vue 範本中的寫死文字替換為翻譯呼叫，並回報程式碼中的寫死文字

| 旗標 | 預設值 | 說明 |
| --- | --- | --- |
| `--translationFile` | `<translationDir>/<defaultLocale>.json` | 新鍵寫入的檔案 |
| `--path` | 整個專案 | 要處理的檔案或目錄 |
| `--context` | — | 產生的鍵的前綴 |
| `--ignore` | — | 以逗號分隔要略過的原始檔 glob，相對於專案 |
| `--dryRun` | `false` | 顯示將會變更的內容；不寫入任何內容 |
| `--interactive` | `false` | 逐一確認或編輯每個產生的鍵 |

```bash
i18n-micro text-to-i18n --dryRun
i18n-micro text-to-i18n --path components --context ui
```

### `rename` {#rename}

在所有 locale 與原始檔中重新命名鍵或命名空間

| 旗標 | 預設值 | 說明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config 的 `i18n.translationDir` | 翻譯目錄，相對於專案 |
| `--from` **\*** | — | 目前的鍵或命名空間 |
| `--to` **\*** | — | 新的鍵或命名空間 |
| `--ignore` | — | 以逗號分隔要略過的原始檔 glob，相對於專案 |
| `--dryRun` | `false` | 回報變更內容；不寫入任何內容 |

**\*** 必填。

```bash
i18n-micro rename --from common.save --to actions.save
```

### `pseudo` {#pseudo}

以偽翻譯填滿某個 locale，以找出版面配置與寫死文字的問題

| 旗標 | 預設值 | 說明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config 的 `i18n.translationDir` | 翻譯目錄，相對於專案 |
| `--sourceLocale` | 預設 locale | 要讀取的 locale |
| `--targetLocale` **\*** | — | 要填滿的 locale |
| `--replace` | `false` | 覆寫既有的值 |

**\*** 必填。

### `format` {#format}

以排序後的鍵與一致的縮排重寫 locale 檔案

| 旗標 | 預設值 | 說明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config 的 `i18n.translationDir` | 翻譯目錄，相對於專案 |
| `--indent` | `2` | 縮排空格數 |
| `--sortKeys` | `true` | 排序鍵；使用 --no-sortKeys 以保留原有順序 |
| `--check` | `false` | 若檔案將會變更則失敗；不寫入任何內容 |

```bash
i18n-micro format --check
```

## 交換 {#exchange}

### `export` {#export}

將 locale 檔案匯出為 PO 或 CSV，並以預設 locale 的文字作為原文

| 旗標 | 預設值 | 說明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config 的 `i18n.translationDir` | 翻譯目錄，相對於專案 |
| `--format` | `po` | 檔案格式：po、csv |
| `--dir` | po 為 `pots`，csv 為 `csv_exports` | 輸出目錄，相對於專案 |
| `--force` | `false` | 覆寫自上次匯出後已變更且從未匯入的檔案 |

```bash
i18n-micro export --format csv
```

### `import` {#import}

將 PO 或 CSV 檔案合併到 locale 檔案中

| 旗標 | 預設值 | 說明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config 的 `i18n.translationDir` | 翻譯目錄，相對於專案 |
| `--format` | `po` | 檔案格式：po、csv |
| `--dir` | po 為 `pots`，csv 為 `csv_exports` | 輸入目錄，相對於專案 |
| `--dryRun` | `false` | 回報將會匯入的內容；不寫入任何內容 |

```bash
i18n-micro import --format csv --dryRun
```

### `sync-remote` {#sync-remote}

從 .i18n-remote.json 中的 HTTP 端點拉取全域翻譯，或將其推送至該端點

| 旗標 | 預設值 | 說明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config 的 `i18n.translationDir` | 翻譯目錄，相對於專案 |
| `--pull` | `true` | 從遠端拉取 |
| `--push` | `false` | 推送至遠端 |
| `--force` | `false` | 拉取時採用遠端的值；推送時覆寫僅存在於遠端的文字 |
| `--dryRun` | `false` | 回報拉取將會變更的內容；不寫入也不推送任何內容 |

```bash
i18n-micro sync-remote --dryRun
i18n-micro sync-remote --no-pull --push
```

## Lint 規則 {#lint-rules}

| 規則 | 偵測內容 | 可由 `--fix` 修正 |
| --- | --- | --- |
| `no-trailing-spaces` | 值或行尾的空白 | 是 |
| `no-multiple-spaces` | 連續兩個以上的空白 | 是 |
| `no-empty-translation` | 空的或空白的值 | 否 |

## 結束代碼 {#exit-codes}

| 代碼 | 意義 |
| --- | --- |
| `0` | 完成，無可回報的項目 |
| `1` | 有發現：`check`、`lint` 或 `format --check` 發現問題、`clean` 或 `sync` 無法證明移除是安全的、`export` 將覆寫尚未匯入的工作、`translate` 遺漏了某些鍵、`import` 或 `sync-remote` 遇到衝突、`sync-remote` 推送將捨棄遠端文字。`clean`、`sync` 或 `sync-remote` 拉取的 `--dryRun` 會回報這些情況並以 `0` 結束 |
| `2` | 失敗：用法錯誤、無法讀取專案、網路或檔案錯誤 |

## 設定檔 {#configuration-files}

| 檔案 | 使用者 |
| --- | --- |
| `.i18n-lintrc.json` | `lint`：`enabledRules`、`disabledRules`、`customRegexRules`（`name`、`pattern`、`flags`、`description`、`replacement`） |
| `.i18n-remote.json` | `sync-remote`：`url`、`path`、`token`、`auth`（`username`、`password`）。`type` 可省略；目前僅有 `custom` |
| `.i18n-glossary.json` | `translate --service ai`：由 `source`、`target` 及選填的 `from`、`to` 組成的 `entries` |

## 環境變數 {#environment-variables}

| 名稱 | 用途 |
| --- | --- |
| `I18N_TRANSLATE_TOKEN` | `translate` 的 API 金鑰。也會從 `.env` 讀取 |
| `I18N_REMOTE_TOKEN` | `sync-remote` 的 Bearer 權杖。也會從 `.env` 讀取 |
| `AI_GATEWAY_API_KEY, OPENAI_API_KEY, ANTHROPIC_API_KEY` | 未設定 `I18N_TRANSLATE_TOKEN` 時，`ai` 服務使用的金鑰 |
| `DEFAULT_LOCALE` | 覆寫 `defaultLocale`，與模組中相同 |
