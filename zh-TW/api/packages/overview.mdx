# 套件 API

`nuxt-i18n-micro` 由一組小型套件組成，大多可獨立使用—`@i18n-micro/vue` 可用於一般 Vue 應用，`@i18n-micro/core` 則可用於任何情境。

以下每個頁面都由 [`pnpm run api:surface`](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/maintenance-commands.md#api-surface) 針對 TypeScript 原始碼所比對的 API 快照產生，因此匯出項目若沒有出現在此參考中就必然會導致 CI 失敗，或反之。
