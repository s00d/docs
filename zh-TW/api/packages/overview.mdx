---
title: "套件 API"
description: "每個 @i18n-micro/* 套件的匯出 API，由 CI 依原始碼檢查的 API 快照產生。"
---

Nuxt 模組由多個小型的 `@i18n-micro/*` 套件組成，其中大多數都可以單獨使用：`@i18n-micro/vue` 可用於 Vue 應用程式，`@i18n-micro/core` 則可用於任何地方。請使用這些頁面，依進入點查詢套件匯出了哪些內容。每個頁面都由 [`pnpm run api:surface`](https://s00d.github.io/nuxt-i18n-micro/contributing/maintenance-commands#api-surface) 依 TypeScript 原始碼檢查的快照產生，因此任何匯出的變更都逃不過 CI 的檢查。
