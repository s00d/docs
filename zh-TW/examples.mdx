# 📚 Nuxt I18n Micro 範例與用法

本節提供多個示範，展示如何在 Nuxt.js 應用中使用 `Nuxt I18n Micro`。你會看到如何切換語系、如何使用 `<i18n-link>`、`<i18n-switcher>` 與 `<i18n-t>` 元件，以及如何動態處理翻譯鍵。

## 🛠️ 基本設定

以下是開始使用 `Nuxt I18n Micro` 的基本設定：

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 語系切換

### 以程式化方式切換語系

此範例展示如何透過按鈕切換語系：

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### 語系切換的 JSON 範例

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### 使用 `<i18n-switcher>` 元件

`<i18n-switcher>` 元件提供一個可自訂標籤的下拉選單用於語系切換：

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 🌐 使用 `<i18n-link>` 進行多語系導覽

`<i18n-link>` 元件會自動處理與特定語系相關的路由：

```vue
<template>
  <div>
```

## 📝 從翻譯檔渲染動態鍵

有些情境下你會想遍歷翻譯檔中儲存的動態鍵，並有條件地渲染其值。下面的範例示範如何使用 `Nuxt I18n Micro` 達成這個目的。

### 範例：渲染動態鍵

此範例從指定的翻譯路徑（本例為 `dynamic`）取得一組鍵陣列，並逐一遍歷。渲染前會先使用 `$has` 檢查每個鍵是否存在，接著再以 `$t` 顯示其值。

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### 翻譯檔範例（`en.json`）

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### 範例：從物件渲染動態鍵

此範例處理翻譯檔中儲存的物件。我們取得並遍歷物件的鍵，動態渲染鍵名與其對應的值。

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### 翻譯檔範例（`en.json`）

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 使用 `<i18n-t>` 搭配插槽與插值進行翻譯

`<i18n-t>` 元件適合用來渲染帶有動態內容與 HTML 標籤的翻譯：

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### `<i18n-t>` 的 JSON 範例

```json
{
  "greeting": "Welcome to the page"
}
```

### 搭配插值

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### 插值的 JSON 範例

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 使用 `$tc` 處理複數形

`Nuxt I18n Micro` 中的 `$tc` 函式會依據數量與語系設定處理複數形。這在動態調整涉及數量的訊息時非常實用，例如項目、通知或其他數量可能變化的實體。

### 範例：使用 `$tc` 處理複數形

在以下範例中，我們使用 `$tc` 顯示蘋果數量的訊息。翻譯鍵會依據所提供的數量處理多種複數形式。

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### 複數形的 JSON 範例

以下示範如何在 JSON 檔案中定義翻譯，以支援不同的複數形式：

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### 說明

- **`$tc('apples', 0)`**：回傳第一種形式，用於數量為零時（`"no apples"`）。
- **`$tc('apples', 1)`**：回傳第二種形式，用於數量為一時（`"one apple"`）。
- **`$tc('apples', 10)`**：回傳第三種形式並帶入數量值，用於數量為二以上時（`"10 apples"`）。

### 更複雜的複數形範例

若你的應用需要處理較複雜的複數規則（例如零、一、二、少數、多數、其他等特定情境），可以相應地擴充翻譯字串：

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**：可設定為回傳 `"two apples"`。
- **`$tc('apples', 3)`**：可依所定義的規則回傳 `"a few apples"`。

## 🌐 使用 `$tn` 格式化數字

`$tn` 函式會使用 `Intl.NumberFormat` API 依據目前語系格式化數字。這對於以符合使用者地區設定的方式顯示數字非常實用，例如貨幣、百分比或其他數字格式。

### 範例：使用 `$tn` 格式化數字

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ 使用 `$td` 格式化日期與時間

`$td` 函式會使用 `Intl.DateTimeFormat` API 依據目前語系格式化日期與時間。這有助於以使用者熟悉的地區格式呈現日期與時間。

### 範例：使用 `$td` 格式化日期與時間

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ 使用 `$tdr` 格式化相對時間

`$tdr` 函式會使用 `Intl.RelativeTimeFormat` API 依據目前語系將日期格式化為相對時間（例如「5 分鐘前」、「2 天前」）。這適合用於顯示相對於目前日期與時間的時間差。

### 範例：使用 `$tdr` 格式化相對時間

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
