# Nuxt I18n Micro — Mintlify docs

Public documentation for [Nuxt I18n Micro](https://github.com/s00d/nuxt-i18n-micro), built with [Mintlify](https://mintlify.com).

## Source of truth

The Nuxt Content docs in the [main module repository](https://github.com/s00d/nuxt-i18n-micro/tree/main/docs/content) are the primary source. Sync them with:

```bash
node scripts/sync-from-upstream.mjs <path to nuxt-i18n-micro>/docs/content
```

See [`AGENTS.md`](./AGENTS.md) for what the script owns. The site is English only.

## Local preview

```bash
npm i -g mint
mint dev
```

Open `http://localhost:3000`.

## Publishing

Push to `main`. Mintlify deploys via the GitHub app connected in the [Mintlify dashboard](https://dashboard.mintlify.com).

## Structure

- `docs.json` — navigation (generated tabs), theme colors, logos, redirects
- `index.mdx` — landing page (hand-maintained)
- `guide/`, `integrations/`, `api/`, `composables/`, `components/`, `changelog/`, `images/`, `v3.mdx` — generated by the sync script
- `scripts/sync-from-upstream.mjs` — the sync script
- `.mintlify/Assistant.md` — Mintlify AI assistant instructions

Maintainer-only docs (contributing, release smoke, maintenance commands) stay on the [main site](https://s00d.github.io/nuxt-i18n-micro/contributing). The git-style release log is [`CHANGELOG.md`](https://github.com/s00d/nuxt-i18n-micro/blob/main/CHANGELOG.md).
