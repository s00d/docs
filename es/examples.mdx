# 📚 Ejemplos y uso de Nuxt I18n Micro

Esta sección proporciona varios ejemplos que muestran cómo usar `Nuxt I18n Micro` en tu aplicación Nuxt.js. Verás cómo cambiar de locale, usar los componentes `<i18n-link>`, `<i18n-switcher>` e `<i18n-t>`, y gestionar claves de traducción de forma dinámica.

## 🛠️ Configuración básica

Esta es una configuración básica para empezar con `Nuxt I18n Micro`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Cambio de locale

### Cambio de locale programático

Este ejemplo muestra cómo cambiar de locale programáticamente usando botones:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### JSON de ejemplo para el cambio de locale

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### Uso del componente `<i18n-switcher>`

El componente `<i18n-switcher>` proporciona un desplegable para cambiar de locale con etiquetas personalizables:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 🌐 Uso de `<i18n-link>` para navegación localizada

El componente `<i18n-link>` gestiona automáticamente el enrutamiento específico por locale:

```vue
<template>
  <div>
    <i18n-link to="/about">{{ $t('about') }}</i18n-link>
    <i18n-link :to="{ name: 'index' }">{{ $t('home') }}</i18n-link>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### JSON de ejemplo para enlaces de navegación

```json
{
  "about": "About Us",
  "home": "Home"
}
```

### Ejemplo con estilo de enlace activo

```vue
<template>
  <div>
    <i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
  </div>
</template>
```

### JSON de ejemplo para el estilo de enlace activo

Para este caso puede usarse el mismo archivo JSON que en el ejemplo anterior.

## 📝 Renderizado de claves dinámicas desde archivos de traducción

En algunos escenarios, es posible que quieras iterar sobre claves dinámicas almacenadas en tus archivos de traducción y renderizar sus valores condicionalmente. El siguiente ejemplo muestra cómo lograrlo con `Nuxt I18n Micro`.

### Ejemplo: renderizado de claves dinámicas

Este ejemplo obtiene un array de claves desde una ruta de traducción específica (en este caso, `dynamic`) y las recorre. Se comprueba la existencia de cada clave con `$has` antes de renderizar su valor con `$t`.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Archivo de traducción de ejemplo (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Ejemplo: renderizado de claves dinámicas desde un objeto

En este ejemplo se maneja un objeto almacenado en tu archivo de traducción. Obtenemos e iteramos sobre las claves del objeto, renderizando dinámicamente tanto los nombres de las claves como sus valores asociados.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Archivo de traducción de ejemplo (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 Uso de `<i18n-t>` para traducciones con slots e interpolación

El componente `<i18n-t>` es útil para renderizar traducciones con contenido dinámico y etiquetas HTML:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### JSON de ejemplo para `<i18n-t>`

```json
{
  "greeting": "Welcome to the page"
}
```

### Con interpolación

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### JSON de ejemplo para interpolación

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 Uso de `$tc` para pluralización

La función `$tc` de `Nuxt I18n Micro` gestiona la pluralización según el recuento y la configuración regional del locale. Es útil para ajustar dinámicamente mensajes que involucran cantidades, como elementos, notificaciones u otras entidades que pueden variar en número.

### Ejemplo: uso de `$tc` para pluralización

En el siguiente ejemplo, mostramos un mensaje que indica el número de manzanas usando `$tc`. La clave de traducción gestiona varias formas plurales según el recuento proporcionado.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### JSON de ejemplo para pluralización

Así puedes definir la traducción en tu archivo JSON para manejar diferentes formas plurales:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Explicación

- **`$tc('apples', 0)`**: devuelve la primera forma, usada cuando el recuento es cero (`"no apples"`).
- **`$tc('apples', 1)`**: devuelve la segunda forma, usada cuando el recuento es uno (`"one apple"`).
- **`$tc('apples', 10)`**: devuelve la tercera forma con el valor del recuento, usada cuando el recuento es dos o más (`"10 apples"`).

### Ejemplo adicional con pluralización más compleja

Si tu aplicación necesita gestionar reglas de pluralización más complejas (por ejemplo, casos específicos para cero, uno, dos, pocos, muchos, otros), puedes ampliar las cadenas de traducción en consecuencia:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: podría configurarse para devolver `"two apples"`.
- **`$tc('apples', 3)`**: podría devolver `"a few apples"`, según las reglas definidas para el recuento.

## 🌐 Uso de `$tn` para formatear números

La función `$tn` formatea números según el locale actual utilizando la API `Intl.NumberFormat`. Es útil para mostrar números que coincidan con la configuración regional del usuario, como monedas, porcentajes u otros formatos numéricos.

### Ejemplo: uso de `$tn` para formatear números

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ Uso de `$td` para formatear fechas y horas

La función `$td` formatea fechas y horas según el locale actual utilizando la API `Intl.DateTimeFormat`. Es útil para mostrar fechas y horas en formatos familiares para el usuario según la configuración de su locale.

### Ejemplo: uso de `$td` para formatear fechas y horas

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ Uso de `$tdr` para formato de fecha relativa

La función `$tdr` formatea fechas como tiempos relativos (por ejemplo, «hace 5 minutos», «hace 2 días») según el locale actual utilizando la API `Intl.RelativeTimeFormat`. Es útil para mostrar diferencias de tiempo relativas a la fecha y hora actuales.

### Ejemplo: uso de `$tdr` para formato de fecha relativa

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
