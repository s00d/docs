# 📚 Ejemplos y uso de Nuxt I18n Micro

Esta sección ofrece varios ejemplos que muestran cómo usar `Nuxt I18n Micro` en tu aplicación Nuxt.js. Verás cómo cambiar idiomas, usar los componentes `<i18n-link>`, `<i18n-switcher>` e `<i18n-t>`, y manejar dinámicamente claves de traducción.

## 🛠️ Configuración básica

Aquí tienes una configuración básica para empezar con `Nuxt I18n Micro`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Cambio de idioma

### Cambiar idiomas programáticamente

Este ejemplo muestra cómo cambiar de idioma programáticamente con botones:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### JSON de ejemplo para el cambio de idioma

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### Uso del componente `<i18n-switcher>`

El componente `<i18n-switcher>` proporciona un desplegable para cambiar de idioma con etiquetas personalizables:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 🌐 Uso de `<i18n-link>` para navegación localizada

El componente `<i18n-link>` gestiona automáticamente el enrutamiento específico del idioma:

```vue
<template>
  <div>
    <i18n-link to="/about">{{ $t('about') }}</i18n-link>
    <i18n-link :to="{ name: 'index' }">{{ $t('home') }}</i18n-link>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

```

### JSON de ejemplo para enlaces de navegación

```json
  "about": "About Us",
  "home": "Home"
}
```

## 📝 Renderizado de claves dinámicas desde archivos de traducción

En algunos escenarios, puede que quieras iterar sobre claves dinámicas almacenadas dentro de tus archivos de traducción y renderizar sus valores de forma condicional. El siguiente ejemplo muestra cómo lograrlo con `Nuxt I18n Micro`.

### Ejemplo: renderizado de claves dinámicas

Este ejemplo obtiene un arreglo de claves desde una ruta específica de traducción (en este caso, `dynamic`) e itera sobre ellas. Cada clave se comprueba con `$has` antes de renderizar su valor con `$t`.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Archivo de traducción de ejemplo (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Ejemplo: renderizar claves dinámicas desde un objeto

En este ejemplo, manejamos un objeto almacenado en tu archivo de traducción. Obtenemos e iteramos sobre las claves del objeto, renderizando dinámicamente tanto los nombres de las claves como sus valores asociados.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Archivo de traducción de ejemplo (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 Uso de `<i18n-t>` para traducciones con slots e interpolación

El componente `<i18n-t>` es útil para renderizar traducciones con contenido dinámico y etiquetas HTML:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### JSON de ejemplo para `<i18n-t>`

```json
{
  "greeting": "Welcome to the page"
}
```

### Con interpolación

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### JSON de ejemplo para interpolación

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 Uso de `$tc` para pluralización

La función `$tc` en `Nuxt I18n Micro` gestiona la pluralización según el conteo y la configuración regional. Es útil para ajustar dinámicamente mensajes que involucran conteos, como elementos, notificaciones u otras entidades que pueden variar en número.

### Ejemplo: uso de `$tc` para pluralización

En el siguiente ejemplo, mostramos un mensaje que indica el número de manzanas usando `$tc`. La clave de traducción maneja múltiples formas plurales según el conteo proporcionado.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### JSON de ejemplo para pluralización

Así puedes definir la traducción en tu archivo JSON para manejar diferentes formas plurales:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Explicación

- **`$tc('apples', 0)`**: Devuelve la primera forma, usada cuando el conteo es cero (`"no apples"`).
- **`$tc('apples', 1)`**: Devuelve la segunda forma, usada cuando el conteo es uno (`"one apple"`).
- **`$tc('apples', 10)`**: Devuelve la tercera forma con el valor del conteo, usada cuando el conteo es dos o más (`"10 apples"`).

### Ejemplo adicional con pluralización más compleja

Si tu aplicación necesita manejar reglas de pluralización más complejas (por ejemplo, casos específicos para cero, uno, dos, pocos, muchos, otros), puedes extender las cadenas de traducción según corresponda:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: Podría configurarse para devolver `"two apples"`.
- **`$tc('apples', 3)`**: Podría devolver `"a few apples"`, según las reglas definidas para el conteo.

## 🌐 Uso de `$tn` para formatear números

La función `$tn` formatea números según el idioma actual usando la API `Intl.NumberFormat`. Es útil para mostrar números de forma que coincida con la configuración regional del usuario, como moneda, porcentajes u otros formatos numéricos.

### Ejemplo: uso de `$tn` para formatear números

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ Uso de `$td` para formatear fechas y horas

La función `$td` formatea fechas y horas según el idioma actual usando la API `Intl.DateTimeFormat`. Es útil para mostrar fechas y horas en formatos familiares al usuario según la configuración regional.

### Ejemplo: uso de `$td` para formatear fechas y horas

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ Uso de `$tdr` para formatear fechas relativas

La función `$tdr` formatea fechas como tiempos relativos (por ejemplo, "hace 5 minutos", "hace 2 días") según el idioma actual usando la API `Intl.RelativeTimeFormat`. Es útil para mostrar diferencias de tiempo relativas a la fecha y hora actuales.

### Ejemplo: uso de `$tdr` para formatear fechas relativas

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
