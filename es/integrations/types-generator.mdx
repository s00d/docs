---
title: "Generador de tipos"
description: "Genera autocompletado de TypeScript para las claves de traducción a partir de tus archivos JSON, en Nuxt o en cualquier proyecto Vite."
---

`@i18n-micro/types-generator` lee todos los archivos JSON de tu carpeta de traducciones y escribe una declaración que enumera todas las claves. Añádelo cuando quieras que tu editor sugiera claves en `t()`, `$t()` y `<I18nT keypath>`. Funciona como módulo de Nuxt y como plugin de Vite o Rollup, y se regenera cuando cambia un archivo.

## Instalación {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/types-generator
```

```bash npm
npm install -D @i18n-micro/types-generator
```

```bash yarn
yarn add -D @i18n-micro/types-generator
```

</CodeGroup>

Dependencia peer: `@nuxt/kit` `^3.18.0 || ^4.0.0`. Solo la entrada `/nuxt` la importa; en un proyecto solo con Vite se puede ignorar el aviso de la dependencia peer.

## Nuxt {#nuxt}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro', '@i18n-micro/types-generator/nuxt'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

El módulo escribe `.nuxt/types/i18n-micro.d.ts` y Nuxt lo añade al contexto de tipos; no hay nada que incluir a mano. Lee `i18nTypes.translationDir` o, en su defecto, el lugar donde `nuxt-i18n-micro` lee las traducciones: `translationDir` (de `i18n` o de las opciones del módulo en línea, por defecto `'locales'`) en cada capa, y `additionalTranslationDirs`. Editar un archivo JSON en esa carpeta regenera los tipos en `nuxi dev`. `i18nTypes.outputFile` se ignora en Nuxt (un aviso lo indica).

## Vite {#vite}

`I18nTypesPlugin` es un plugin de Vite, que Rollup también admite. Para otro bundler, llama a `generateTypes` en un script.

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { I18nTypesPlugin } from '@i18n-micro/types-generator'

export default defineConfig({
  plugins: [
    vue(),
    I18nTypesPlugin({
      srcDir: process.cwd(),
      translationDir: 'src/locales',
      outputFile: 'src/i18n-micro.d.ts',
    }),
  ],
})
```

| Opción | Obligatoria | Notas |
| --- | --- | --- |
| `srcDir` | sí | Directorio base; `translationDir` se resuelve respecto a él. |
| `translationDir` | sí | Carpeta con los archivos JSON (incluidas subcarpetas como `pages/`), o un array de carpetas. |
| `outputFile` | no | Dónde escribir la declaración; por defecto `<srcDir>/i18n-micro.d.ts`. |

El plugin genera una vez al inicio de la compilación y, en el servidor de desarrollo, regenera 300 ms después de un cambio en la carpeta. Asegúrate de que el `include` de tu `tsconfig.json` cubre el archivo de salida.

## Usar las claves {#use-the-keys}

El archivo generado aumenta `DefineLocaleMessage` en `@i18n-micro/types`, lo que convierte `TranslationKey` en tus claves:

```ts
declare module '@i18n-micro/types' {
  export interface DefineLocaleMessage {
    nav: object
    'nav.home': string
    'profile.title': string
  }
}
```

Las claves son las que responde `t()`, también objetos, de cada locale y cada archivo de página, con el tipo de su valor JSON. `TranslationKey` es la unión de esas claves más cualquier cadena, así que obtienes autocompletado, no errores: una clave mal escrita o dinámica sigue compilando. Los parámetros y los valores de retorno no están tipados.

Para claves dinámicas bajo un prefijo conocido, `ScopedKey<'prefix'>` restringe a las claves coincidentes:

```ts
import type { ScopedKey } from '@i18n-micro/types'

const statusText = (status: string) => t(`status.${status}` as ScopedKey<'status'>)
```

`TranslationKey` y `ScopedKey` provienen de `@i18n-micro/types` (React, Preact y Solid reexportan `TranslationKey`; Vue no).

## API {#api}

| Exportación | Entrada | Notas |
| --- | --- | --- |
| `I18nTypesPlugin(options)` | `@i18n-micro/types-generator` | Plugin de Vite y Rollup |
| `generateTypes(options)` | `@i18n-micro/types-generator` | escribe el archivo, devuelve su ruta |
| `getTypesString(options)` | `@i18n-micro/types-generator` | devuelve la declaración sin escribirla |
| `formatKeyProperty(key)` | `@i18n-micro/types-generator` | helper |
| Módulo de Nuxt (`configKey: 'i18nTypes'`) | `@i18n-micro/types-generator/nuxt` | opción `translationDir` |

Firmas completas: [referencia del paquete](/es/api/packages/types-generator).
