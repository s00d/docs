# Integraciones

Los paquetes `@i18n-micro` son versiones ligeras y específicas de framework de Nuxt I18n Micro diseñadas para integrarse en distintos frameworks y entornos. Estos paquetes proporcionan la funcionalidad principal de internacionalización con un footprint mínimo, centrándose en las funciones esenciales de traducción y componentes básicos.

## Descripción general

Estos paquetes de integración son **versiones en miniatura** del módulo completo Nuxt I18n Micro, conteniendo solo la funcionalidad esencial necesaria para la internacionalización:

- **Funciones principales de traducción**: métodos básicos de traducción, pluralización y formateo.
- **Componentes esenciales**: un pequeño conjunto de componentes UI para tareas i18n comunes.
- **Patrón de adaptador de router**: integración flexible de enrutamiento mediante abstracción de adaptador.
- **Soporte de TypeScript**: definiciones de tipos completas para desarrollo type-safe.

A diferencia del módulo Nuxt completo, estos paquetes:

- No incluyen lógica de enrutamiento específica de framework.
- Requieren que implementes un adaptador de router para funciones de enrutamiento.
- Se centran en funcionalidad de traducción en lugar de integración de framework.
- Están diseñados para ser ligeros y agnósticos al framework cuando es posible.

## Componentes principales

Todos los paquetes de framework incluyen los siguientes componentes esenciales:

### `<I18nT>`

Un componente de traducción que renderiza texto traducido con soporte para:

- **Interpolación de parámetros**: reemplaza placeholders con valores dinámicos.
- **Pluralización**: selección automática de la forma plural según el conteo.
- **Formateo de números**: formatea números según el idioma.
- **Formateo de fechas**: formatea fechas y tiempos relativos.
- **Renderizado HTML**: renderizado opcional de contenido HTML.
- **Valores por defecto**: texto de fallback cuando falta la traducción.

**Ejemplo:**

```vue
<!-- Vue -->
<I18nT keypath="greeting" :params="{ name: 'World' }" />
```

```tsx
// React
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```tsx
// Solid
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```astro
<!-- Astro -->
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

### `<I18nLink>`

Un componente de enlace localizado que gestiona automáticamente los prefijos de idioma en URLs. Características:

- **Localización automática de rutas**: añade/quita prefijos de idioma según la estrategia de enrutamiento.
- **Detección de estado activo**: resalta la ruta actual.
- **Soporte de enlaces externos**: detecta y maneja automáticamente URLs externas.
- **Integración con router**: usa el componente de enlace del adaptador de router cuando está disponible.
- **Estilo personalizado**: admite estados activo y hover.

**Ejemplo:**

```vue
<!-- Vue -->
<I18nLink to="/about" active-class="active">
  About Us
</I18nLink>
```

```tsx
// React
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```tsx
// Solid
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```astro
<!-- Astro -->
<I18nLink href="/about" class="nav-link">
  About Us
</I18nLink>
```

### `<I18nSwitcher>`

Un componente de cambio de idioma que proporciona una interfaz de desplegable o lista para cambiar idiomas. Características:

- **Lista de idiomas automática**: genera opciones desde los idiomas configurados.
- **Resaltado del idioma actual**: indica visualmente el idioma activo.
- **Etiquetas personalizadas**: soporte para nombres personalizados por idioma.
- **Integración con router**: navega automáticamente a rutas localizadas.
- **Accesibilidad**: atributos ARIA adecuados y navegación con teclado.

**Ejemplo:**

```vue
<!-- Vue -->
<I18nSwitcher />
```

```tsx
// React
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```tsx
// Solid
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```astro
<!-- Astro -->
<I18nSwitcher />
```

### `<I18nGroup>`

Un componente para agrupar traducciones con un prefijo común, útil para organizar traducciones por página o característica. Características:

- **Ámbito de prefijo**: antepone automáticamente el prefijo a todas las claves de traducción dentro del grupo.
- **Grupos anidados**: soporte para grupos de traducción anidados.
- **Organización limpia**: ayuda a mantener estructuras de traducción organizadas.

**Ejemplo:**

```vue
<!-- Vue -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

```tsx
// React
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```tsx
// Solid
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```astro
<!-- Astro -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

## Opciones compartidas de `createI18n` \{#create-i18n-options\}

Cada paquete de framework se crea de la misma manera. Solo el tipo de las opciones se nombra según el framework (`ReactI18nOptions`, `SolidI18nOptions`, etc.). Las opciones en sí son idénticas:

| Propiedad        | Tipo                                                       | Obligatorio | Predeterminado    | Descripción                                    |
| ---------------- | ---------------------------------------------------------- | ----------- | ----------------- | ---------------------------------------------- |
| `locale`         | `string`                                                   | ✅          | -                 | Código del idioma actual (por ejemplo, `'en'`).|
| `fallbackLocale` | `string`                                                   | ❌          | Igual que `locale`| Idioma de fallback cuando falta la traducción. |
| `messages`       | `Record<string, Translations>`                             | ❌          | `\{\}`             | Mensajes de traducción iniciales.              |
| `plural`         | `PluralFunc`                                               | ❌          | `defaultPlural`   | Función de pluralización personalizada.        |
| `missingWarn`    | `boolean`                                                  | ❌          | `true`            | Muestra avisos en consola por traducciones ausentes. |
| `missingHandler` | `(locale: string, key: string, routeName: string) => void` | ❌          | -                 | Handler personalizado para traducciones ausentes. |

Cualquier cosa más allá de esto es específica del framework y está documentada en la página de ese paquete.

## Abstracción de adaptador de router

Todos los paquetes de framework usan un **patrón de adaptador de router** para desacoplar la funcionalidad i18n de implementaciones de router específicas. Este diseño permite:

- **Flexibilidad**: usa cualquier librería de router o ninguno.
- **Independencia de framework**: mantén la lógica de enrutamiento en tu aplicación, no en el paquete i18n.
- **Núcleo ligero**: el paquete i18n permanece pequeño y enfocado.

### Implementar un adaptador de router

Para usar funciones de enrutamiento, necesitas implementar la interfaz `I18nRoutingStrategy`:

```typescript
interface I18nRoutingStrategy {
  getCurrentPath: () => string
  linkComponent?: Component
  push: (target: { path: string }) => void
  replace: (target: { path: string }) => void
  resolvePath?: (to: string | { path?: string }, locale: string) => string | { path?: string }
  getRoute?: () => { fullPath: string; query: Record<string, unknown> }
}
```

La documentación de cada paquete incluye ejemplos completos de implementación de adaptadores para routers populares:

- **Vue**: ejemplo de adaptador para Vue Router.
- **React**: ejemplo de adaptador para React Router.
- **Solid**: ejemplo de adaptador para Solid Router.
- **Astro**: ejemplo de adaptador para enrutamiento basado en archivos.

## Funciones principales

Todos los paquetes comparten estas funciones principales:

### Métodos de traducción

- `t()` — Traducción básica con interpolación de parámetros.
- `ts()` — Traducción que siempre devuelve una cadena.
- `tc()` — Traducción con pluralización.
- `tn()` — Formateo de números.
- `td()` — Formateo de fechas.
- `tdr()` — Formateo de tiempo relativo.
- `has()` — Comprueba si una clave de traducción existe.

### Gestión de idiomas

- **Cambio de idioma**: cambia el idioma actual programáticamente.
- **Idioma de fallback**: fallback automático cuando falta la traducción.
- **Traducciones específicas de ruta**: organización de traducciones a nivel de página.
- **Caché de traducciones**: caché inteligente para rendimiento.

### Soporte de TypeScript

Todos los paquetes proporcionan:

- Definiciones TypeScript completas.
- Claves de traducción type-safe (con el types generator).
- Soporte de IntelliSense en IDEs.
- Comprobación de errores en tiempo de compilación.

## Empezar

1. **Elige tu paquete**: selecciona el paquete para tu framework.
2. **Instala el paquete**: usa tu gestor de paquetes preferido.
3. **Lee la documentación**: cada paquete tiene instrucciones detalladas de configuración.
4. **Implementa el adaptador de router**: si necesitas funciones de enrutamiento, implementa el adaptador.
5. **Empieza a traducir**: usa componentes y métodos para añadir traducciones.
