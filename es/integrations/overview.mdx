# Integraciones

Los paquetes `@i18n-micro` son versiones ligeras y específicas por framework de Nuxt I18n Micro, diseñadas para integrarse en distintos frameworks y entornos. Estos paquetes proporcionan la funcionalidad principal de internacionalización con una huella mínima, centrándose en las capacidades esenciales de traducción y en los componentes básicos.

## Resumen

Estos paquetes de integración son **versiones en miniatura** del módulo completo de Nuxt I18n Micro, que contienen solo la funcionalidad esencial necesaria para la internacionalización:

- **Funciones principales de traducción**: métodos básicos de traducción, pluralización y formateo.
- **Componentes esenciales**: un pequeño conjunto de componentes de UI para tareas comunes de i18n.
- **Patrón de adaptador de router**: integración de enrutamiento flexible mediante una abstracción de adaptador.
- **Soporte TypeScript**: definiciones de tipos completas para un desarrollo con seguridad de tipos.

A diferencia del módulo completo de Nuxt, estos paquetes:

- No incluyen lógica de enrutamiento específica del framework.
- Requieren que implementes un adaptador de router para las funciones de enrutamiento.
- Se centran en la funcionalidad de traducción en lugar de en la integración con el framework.
- Están diseñados para ser ligeros e independientes del framework siempre que sea posible.

## Componentes principales

Todos los paquetes de framework incluyen los siguientes componentes esenciales:

### `<I18nT>`

Un componente de traducción que renderiza texto traducido con soporte para:

- **Interpolación de parámetros**: reemplaza marcadores por valores dinámicos.
- **Pluralización**: selección automática de la forma plural según el recuento.
- **Formato de números**: da formato a los números según el locale.
- **Formato de fechas**: da formato a fechas y tiempos relativos.
- **Renderizado HTML**: renderizado opcional de contenido HTML.
- **Valores por defecto**: texto de reserva cuando falta la traducción.

**Ejemplo:**

```vue
<!-- Vue -->
<I18nT keypath="greeting" :params="{ name: 'World' }" />
```

```tsx
// React
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```tsx
// Solid
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```astro
<!-- Astro -->
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

### `<I18nLink>`

Un componente de enlace localizado que gestiona automáticamente los prefijos de locale en las URLs. Características:

- **Localización de rutas automática**: añade/elimina prefijos de locale según la estrategia de enrutamiento.
- **Detección de estado activo**: resalta la ruta actual.
- **Soporte para enlaces externos**: detecta y gestiona automáticamente las URLs externas.
- **Integración con el router**: usa el componente de enlace del adaptador de router cuando está disponible.
- **Estilo personalizado**: admite estados activo y hover.

**Ejemplo:**

```vue
<!-- Vue -->
<I18nLink to="/about" active-class="active">
  About Us
</I18nLink>
```

```tsx
// React
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```tsx
// Solid
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```astro
<!-- Astro -->
<I18nLink href="/about" class="nav-link">
  About Us
</I18nLink>
```

### `<I18nSwitcher>`

Un componente selector de idioma que proporciona una interfaz de menú desplegable o lista para cambiar de locale. Características:

- **Lista automática de locales**: genera opciones a partir de los locales configurados.
- **Resaltado del locale actual**: indica visualmente el idioma activo.
- **Etiquetas personalizadas**: admite nombres para mostrar personalizados por locale.
- **Integración con el router**: navega automáticamente a las rutas localizadas.
- **Accesibilidad**: atributos ARIA adecuados y navegación por teclado.

**Ejemplo:**

```vue
<!-- Vue -->
<I18nSwitcher />
```

```tsx
// React
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```tsx
// Solid
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```astro
<!-- Astro -->
<I18nSwitcher />
```

### `<I18nGroup>`

Un componente para agrupar traducciones bajo un prefijo común, útil para organizar las traducciones por página o funcionalidad. Características:

- **Ámbito por prefijo**: antepone automáticamente el prefijo a todas las claves de traducción dentro del grupo.
- **Grupos anidados**: admite grupos de traducción anidados.
- **Organización limpia**: ayuda a mantener estructuras de traducción organizadas.

**Ejemplo:**

```vue
<!-- Vue -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

```tsx
// React
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```tsx
// Solid
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```astro
<!-- Astro -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

## Opciones compartidas de `createI18n` \{#create-i18n-options\}

Cada paquete de framework se crea de la misma manera; solo el tipo de opciones lleva el nombre del framework (`ReactI18nOptions`, `SolidI18nOptions`, etc.). Las opciones en sí son idénticas:

| Propiedad        | Tipo                                                       | Requerido | Predeterminado   | Descripción                                    |
| ---------------- | ---------------------------------------------------------- | -------- | ---------------- | ---------------------------------------------- |
| `locale`         | `string`                                                   | ✅       | -                | Código del locale actual (por ejemplo, `'en'`). |
| `fallbackLocale` | `string`                                                   | ❌       | Igual que `locale` | Locale de reserva cuando falta la traducción.  |
| `messages`       | `Record<string, Translations>`                             | ❌       | `\{\}`             | Mensajes de traducción iniciales.              |
| `plural`         | `PluralFunc`                                               | ❌       | `defaultPlural`  | Función personalizada de pluralización.        |
| `missingWarn`    | `boolean`                                                  | ❌       | `true`           | Muestra advertencias en consola para traducciones faltantes. |
| `missingHandler` | `(locale: string, key: string, routeName: string) => void` | ❌       | -                | Handler personalizado para traducciones faltantes. |

Cualquier cosa más allá de estas opciones es específica del framework y se documenta en la página de ese paquete.

## Abstracción de adaptador de router

Todos los paquetes de framework usan un **patrón de adaptador de router** para desacoplar la funcionalidad de i18n de las implementaciones específicas del router. Este diseño permite:

- **Flexibilidad**: usa cualquier biblioteca de router o ninguna.
- **Independencia del framework**: mantén la lógica de enrutamiento en tu aplicación, no en el paquete de i18n.
- **Núcleo ligero**: el paquete de i18n permanece pequeño y enfocado.

### Implementar un adaptador de router

Para usar las funciones de enrutamiento, necesitas implementar la interfaz `I18nRoutingStrategy`:

```typescript
interface I18nRoutingStrategy {
  getCurrentPath: () => string
  linkComponent?: Component
  push: (target: { path: string }) => void
  replace: (target: { path: string }) => void
  resolvePath?: (to: string | { path?: string }, locale: string) => string | { path?: string }
  getRoute?: () => { fullPath: string; query: Record<string, unknown> }
}
```

La documentación de cada paquete incluye ejemplos completos de implementación de adaptadores para routers populares:

- **Vue**: ejemplo de adaptador de Vue Router.
- **React**: ejemplo de adaptador de React Router.
- **Solid**: ejemplo de adaptador de Solid Router.
- **Astro**: ejemplo de adaptador con enrutamiento basado en archivos.

## Funciones principales

Todos los paquetes comparten estas funciones principales:

### Métodos de traducción

- `t()`: traducción básica con interpolación de parámetros.
- `ts()`: traducción que siempre devuelve una cadena.
- `tc()`: traducción con soporte de pluralización.
- `tn()`: formato de números.
- `td()`: formato de fechas.
- `tdr()`: formato de tiempo relativo.
- `has()`: comprueba si existe una clave de traducción.

### Gestión de locales

- **Cambio de locale**: cambia el locale actual de forma programática.
- **Locale de reserva**: reserva automática cuando falta la traducción.
- **Traducciones específicas por ruta**: organización de traducciones a nivel de página.
- **Caché de traducciones**: caché inteligente para rendimiento.

### Soporte de TypeScript

Todos los paquetes proporcionan:

- Definiciones de tipos completas de TypeScript.
- Claves de traducción con seguridad de tipos (con el generador de tipos).
- Soporte de IntelliSense en IDEs.
- Comprobación de errores en tiempo de compilación.

## Primeros pasos

1. **Elige tu paquete**: selecciona el paquete para tu framework.
2. **Instala el paquete**: usa tu gestor de paquetes preferido.
3. **Lee la documentación**: cada paquete tiene instrucciones detalladas de configuración.
4. **Implementa el adaptador de router**: si necesitas funciones de enrutamiento, implementa el adaptador.
5. **Comienza a traducir**: usa componentes y métodos para añadir traducciones.

Para instrucciones detalladas de configuración, consulta la documentación de tu paquete específico:
