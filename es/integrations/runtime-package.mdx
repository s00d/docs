`@i18n-micro/runtime` es la instancia de i18n independiente del framework: diccionarios, `t()`, plurales, formato con `Intl` y una suscripción a cambios, sin `fs` y sin framework. Úsala en TypeScript puro, en un web worker, en una función edge o como base de tu propio binding. Los paquetes de React, Preact, Node y Astro extienden esta misma clase.

## Instalación {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/runtime
```

```bash npm
npm install @i18n-micro/runtime
```

```bash yarn
yarn add @i18n-micro/runtime
```

</CodeGroup>

Sin dependencias peer. Para archivos de traducción en disco, usa [`@i18n-micro/node`](/es/integrations/nodejs-package).

## Configuración {#setup}

```ts
import { createI18n } from '@i18n-micro/runtime'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    en: { greeting: 'Hello, {name}!', apples: 'no apples | one apple | {count} apples' },
    de: { greeting: 'Hallo, {name}!' },
  },
  routeMessages: {
    about: { en: { title: 'About us' } },
  },
})
```

Todas las opciones (`plural`, `missingWarn`, `missingHandler`, `numberFormats`, `datetimeFormats`) se enumeran en [la instancia](/es/integrations/overview#the-instance).

## Traducir {#translate}

```ts
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.tc('apples', 5) // '5 apples'
i18n.tn(1234.5) // '1,234.5'

i18n.setRoute('about')
i18n.t('title') // 'About us' (route dictionary)
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!' (root, still visible)
```

Carga más diccionarios más tarde:

```ts
i18n.loadMessages({ fr: { greeting: 'Bonjour, {name} !' } }, { about: { fr: { title: 'À propos' } } })
i18n.addTranslations('fr', { nav: { home: 'Accueil' } }) // deep merge; pass false to replace

await i18n.loadFromUrl('/locales/fr.json', { locale: 'fr' })
await i18n.loadFromUrl('/locales/pages/about/fr.json', { locale: 'fr', routeName: 'about' })
await i18n.loadFromUrls([
  { url: '/locales/en.json', locale: 'en' },
  { url: '/locales/de.json', locale: 'de' },
])
```

`loadFromUrl` usa `fetch` (pasa `init` para las cabeceras) y lanza un error ante una respuesta no OK. `loadFromUrls` carga una tras otra.

## Cambiar de locale {#switch-locale}

```ts
i18n.locale = 'de'
i18n.t('greeting', { name: 'Ada' }) // 'Hallo, Ada!'
```

Los cambios de locale, de ruta y de diccionario notifican a los suscriptores, que es como los bindings de framework vuelven a renderizar:

```ts
const stop = i18n.subscribe(() => {
  document.querySelector('#greeting')!.textContent = i18n.t('greeting', { name: 'Ada' }) as string
})
i18n.locale = 'fr'
stop()
```

`getSnapshot()` devuelve una cadena que cambia con cada notificación (para stores al estilo de `useSyncExternalStore`).

## Por petición {#per-request}

La instancia mantiene un locale y una ruta. En un servidor, no cambies una instancia compartida en cada petición: dos peticiones concurrentes verían el locale de la otra. `i18n.fork(locale)` da a una petición la suya propia: locale, fallback y ruta propios; los mismos diccionarios, formateadores y reglas. Hacer un fork cuesta lo mismo sin importar cuántos diccionarios haya. Un fork ve las escrituras de su padre hasta su primera escritura propia, y sus escrituras se quedan en él. [Node.js](/es/integrations/nodejs-package#per-request) añade `run`.

## API {#api}

| Miembro | Notas |
| --- | --- |
| `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has` | consulta [Traducir y formatear](/es/integrations/overview#translate-and-format) |
| `locale`, `fallbackLocale` | get/set |
| `currentRoute`, `setRoute(name)`, `getRoute()` | ruta activa, por defecto `'index'` |
| `loadMessages(messages?, routeMessages?)` | fusiona muchos locales y rutas a la vez |
| `addTranslations(locale, tree, merge = true)`, `addRouteTranslations(locale, route, tree, merge = true)` | |
| `loadFromUrl(url, { locale?, routeName?, init? })`, `loadFromUrls(entries)` | JSON mediante `fetch` |
| `hasTranslation(key)` | locale activo, cualquier ruta (a diferencia de `has`, que comprueba la ruta activa y la raíz) |
| `setTranslation(key, value)`, `resolveTranslations()` | escribe una clave; lee el árbol fusionado |
| `clear()`, `clearCache()` | descarta todos los diccionarios |
| `subscribe(cb)`, `getSnapshot()` | notificaciones de cambios |
| `storage` | `{ translations: Map<'locale:route', Translations> }` |

Un código que no es una etiqueta de idioma obtiene sus plurales de `localeIso: { ua: 'uk-UA' }`; `localeIsoMap(locales)` lo construye a partir de las entradas de una lista de locales que tienen `iso`.

Exportaciones del módulo: `createI18n`, `I18n`, `fetchJsonTranslations`, `FormatService`, `interpolate`, `localeIsoMap` y los tipos `I18nOptions`, `LoadFromUrlOptions`, `LoadFromUrlEntry`, `TranslationStorage`, `Translations`, `Locale`, `PluralFunc`. Firmas completas: [referencia del paquete](/es/api/packages/runtime).
