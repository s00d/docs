`@i18n-micro/devtools-ui` es el editor de traducciones de la pestaña de Nuxt DevTools, empaquetado como un web component con un plugin de Vite. Añádelo a un proyecto Vue, React, Preact, Solid o Astro para explorar y editar desde el navegador, durante el desarrollo, los archivos JSON de tu carpeta de traducciones. Las aplicaciones Nuxt ya lo tienen en [Nuxt DevTools](/es/guide/devtools).

![La DevTools UI: un árbol de archivos y un editor con el texto del locale predeterminado junto a cada clave](/images/devtools/02-translations-editor-dark.webp)

## Instalación {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/devtools-ui
```

```bash npm
npm install -D @i18n-micro/devtools-ui
```

```bash yarn
yarn add -D @i18n-micro/devtools-ui
```

</CodeGroup>

Sin dependencias peer.

## Configuración {#setup}

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import { i18nDevToolsPlugin } from '@i18n-micro/devtools-ui/vite'

export default defineConfig({
  plugins: [i18nDevToolsPlugin({ translationDir: 'src/locales' })],
})
```

| Opción | Valor predeterminado | Notas |
| --- | --- | --- |
| `translationDir` | `'src/locales'` | Carpeta con los archivos JSON, relativa a la raíz de Vite. |
| `base` | `'/__i18n_api'` | Ruta base de los endpoints de la API. |
| `injectButton` | `true` | Añade un botón flotante a las páginas servidas mediante la transformación de `index.html` de Vite. Astro no tiene esas páginas: consulta más abajo. |
| `defaultLocale` | primer archivo de locale en `translationDir` | Lo devuelve `/config`. |
| `fallbackLocale` | `defaultLocale` | Lo devuelve `/config`. |

El plugin solo se ejecuta en el servidor de desarrollo (`apply: 'serve'`); una compilación de producción no contiene nada de él. El botón abre `/__i18n_devtools.html`, que lee y guarda archivos a través de los endpoints del plugin:

| Endpoint | Función |
| --- | --- |
| `GET <base>/translations` | todos los diccionarios de `translationDir`, por ruta relativa |
| `POST <base>/save` | cuerpo `{ file, content }`; sobrescribe un `.json` existente dentro de `translationDir`, 403 para cualquier otra cosa. Nunca crea un archivo |
| `GET <base>/config` | `{ defaultLocale, fallbackLocale, locales, translationDir }`; `locales` proceden de los archivos raíz de `translationDir` |

Los endpoints solo responden a la página de devtools: una solicitud desde otro origen u host recibe un `403`, y `/save` solo acepta `application/json` (`415`). La página se entera de los cambios en los archivos a través del socket HMR de Vite.

En Astro, añade la integración en lugar del plugin. Añade una aplicación a la barra de herramientas de desarrollo:

```ts
// astro.config.mjs
import { defineConfig } from 'astro/config'
import { i18nDevToolsIntegration } from '@i18n-micro/devtools-ui/vite'

export default defineConfig({
  integrations: [i18nDevToolsIntegration({ translationDir: 'src/locales' })],
})
```

Guardar solo escribe el archivo. Una aplicación que importa el JSON a través de Vite lo recibe mediante HMR; para que las ediciones se apliquen directamente a la instancia en ejecución, usa un puente.

## Puente a una instancia en ejecución {#bridge-to-a-live-instance}

Para integrar el editor en tu propia página y que las ediciones se apliquen al instante a la instancia en ejecución, crea un puente a partir de un adaptador y pásalo al elemento `<i18n-devtools-ui>`:

```ts
import { createBridge, register } from '@i18n-micro/devtools-ui'
import { i18n, locales } from './i18n' // a runtime, React, Preact or Solid instance

register() // defines <i18n-devtools-ui> once

const bridge = createBridge({
  adapter: {
    getRouteCache: () => Object.fromEntries(i18n.storage.translations),
    addTranslations: (locale, content, merge) => i18n.addTranslations(locale, content, merge),
    addRouteTranslations: (locale, route, content, merge) => i18n.addRouteTranslations(locale, route, content, merge),
    subscribe: (cb) => i18n.subscribe(cb),
    getCurrentLocale: () => i18n.locale,
  },
  locales,
  defaultLocale: 'en',
  translationDir: 'src/locales',
})

const el = document.createElement('i18n-devtools-ui') as HTMLElement & { bridge: typeof bridge }
el.bridge = bridge
document.body.append(el)
```

`getRouteCache` debe devolver los diccionarios con claves `locale:route` (`en:index`, `en:blog-post`), que es lo que contiene `i18n.storage.translations`. Para una instancia de Vue, usa `i18n.global.getRouteCache()` e `i18n.global.subscribeToChanges(cb)`.

`saveTranslation` actualiza primero la instancia y después hace un POST a `<base>/save`. Cuando no hay endpoint (una compilación de vista previa estática) o no se puede acceder al servidor de desarrollo, la edición se conserva en `localStorage`; cualquier otro error al guardar restaura el diccionario anterior y lanza una excepción.

## API {#api}

| Exportación | Entrada |
| --- | --- |
| `i18nDevToolsPlugin(options)`, `i18nDevToolsIntegration(options)` | `@i18n-micro/devtools-ui/vite` |
| `register()`, `I18nDevToolsElement` | `@i18n-micro/devtools-ui` |
| `createBridge(options)`, tipos `BridgeAdapter`, `CreateBridgeOptions` | `@i18n-micro/devtools-ui` (también `/bridge/create`) |
| tipo `I18nDevToolsBridge` | `@i18n-micro/devtools-ui` (también `/bridge`) |
| `createRpcClient`, `setupRpcHost` | `@i18n-micro/devtools-ui` |
