---
title: "Nuxt I18n Micro"
description: "i18n pequeño y rápido para Nuxt: traducciones JSON por página, rutas localizadas en tiempo de build y etiquetas SEO listas para usar."
---

Nuxt I18n Micro es un módulo i18n ligero y de alto rendimiento para Nuxt 3 y 4, diseñado para proyectos grandes. Mantiene bajos los tiempos de build, el uso de memoria y el tamaño del bundle en comparación con soluciones i18n tradicionales como `@nuxtjs/i18n`.

Las rutas localizadas se generan en tiempo de build con `@i18n-micro/route-strategy` y se resuelven en tiempo de ejecución con `@i18n-micro/path-strategy`, de modo que los enlaces, el selector de idioma, `hreflang` y las redirecciones coinciden siempre con el router. Las traducciones son solo JSON, repartidas entre archivos raíz compartidos y archivos por página que el servidor de desarrollo crea por ti, con HMR integrado.

<CodeGroup>

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>
