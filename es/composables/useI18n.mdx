---
title: "useI18n"
description: "useI18n devuelve los helpers de tiempo de ejecución (`$t`, `$tc`, `$localePath`, …) como un objeto plano, con y sin el prefijo `$`."
---

`useI18n()` devuelve los helpers de tiempo de ejecución del módulo como un objeto plano. Úsalo en `<script setup>`, composables y plugins en lugar de recurrir a `useNuxtApp()`. Cada helper está disponible con su nombre con `$` y con un alias sin prefijo: `t` y `$t` son la misma función.

## Firma {#signature}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Todos los helpers de tiempo de ejecución, como un objeto plano.

Las mismas funciones que el plugin inyecta como `$t`, `$tc`, etc., disponibles tanto con
el nombre con prefijo de dólar como con un alias sin prefijo, de modo que `const { t } = useI18n()` y
`const { $t } = useI18n()` funcionan ambos.

**Devuelve**: los helpers descritos en la [referencia de métodos](/es/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

El objeto devuelto contiene todos los helpers de [`PluginsInjections`](/es/api/methods). Cada uno está documentado en la página [Helpers](/es/api/methods).

## Ejemplo {#example}

```vue
<script setup lang="ts">
const { t, tc, localePath, switchLocale, getLocale } = useI18n()

const title = computed(() => t('page.title'))
</script>

<template>
  <h1>{{ title }}</h1>
  <p>{{ tc('items', 3) }}</p>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
  <button @click="switchLocale(getLocale() === 'en' ? 'de' : 'en')">{{ t('nav.switch') }}</button>
</template>
```

## Fuera del tipo {#not-in-the-type}

`$defineI18nRoute` solo está tipado en `useNuxtApp()`:

```ts
const { $defineI18nRoute } = useNuxtApp()
```
