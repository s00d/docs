---
title: "useLocaleHead"
description: "useLocaleHead construye las etiquetas SEO de i18n (lang, dir, canonical, hreflang, og:locale) como un objeto que pasas a useHead."
---

`useLocaleHead()` construye las etiquetas de head de i18n para la ruta actual: `lang` y `dir` en `<html>`, un enlace canónico, alternativas `hreflang` con `x-default`, `og:url`, `og:locale` y `og:locale:alternate`. Úsalo cuando estableces [`meta: false`](/es/api/module-options#meta) y gestionas `useHead` tú mismo; con `meta: true` el módulo ya registra estas etiquetas, y los cambios por página se hacen mediante [`useI18nHead`](/es/composables/useI18nHead).

## Firma {#signature}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { build: () => LocaleHead; metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }, LocaleHead | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

Las etiquetas SEO del head para la ruta actual: alternativas `hreflang` para cada locale más
`x-default`, un enlace canónico, `og:locale`, y `lang`/`dir` en `<html>`.

Solo es necesario cuando `meta` está desactivado o hay que ajustar los valores por defecto; con `meta: true`
el módulo registra las mismas etiquetas por sí mismo.

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| `options` | `UseLocaleHeadOptions` |  |

**Devuelve**: `metaObject`, una ref que contiene el objeto de head listo para pasar a `useHead`; `updateMeta` lo actualiza; `build` calcula el objeto de head a partir de la ruta actual (reactivo cuando se lee dentro de un getter, p. ej. `useHead(() => build())`)

```ts
const { metaObject } = useLocaleHead({ addSeoAttributes: true })
useHead(metaObject)
```

## Opciones {#options}

| Opción | Valor por defecto | Descripción |
| --- | --- | --- |
| `addDirAttribute` | `true` | Establece `dir` en `<html>` a partir del `dir` del locale (`'auto'` cuando no tiene). |
| `identifierAttribute` | `'id'` | Atributo que identifica cada etiqueta (`i18n-can`, `i18n-og`, `i18n-alternate-<hreflang>`, …), para que las actualizaciones reemplacen etiquetas en lugar de añadirlas. |
| `addSeoAttributes` | `true` | Emite las etiquetas canonical, `hreflang` y `og:`. `false` conserva solo `htmlAttrs`. |
| `baseUrl` | `'/'` | Origen que se antepone a cada URL. Deja `'/'` para URL relativas; pasa `'https://example.com'` para URL absolutas. |
| `autoUpdate` | `true` | Reconstruye `metaObject` cuando cambia la ruta o el estado `i18n-locale`. |

## Qué emite {#what-it-emits}

- Nada en una ruta sin coincidencia (404) o con `disableMeta` para el locale activo.
- Canonical y `og:url`: `$switchLocalePath(<active locale>)`, con la query reducida a [`canonicalQueryWhitelist`](/es/api/module-options#canonicalquerywhitelist) y [`trailingSlash`](/es/api/module-options#trailingslash) aplicado.
- `hreflang`: un enlace por cada locale habilitado en el que existe la página, `hreflang = iso || code`, omitiendo los locales con `seo: false`; con `hreflangBaseLanguage: true` el primer locale regional de un idioma también emite la etiqueta del idioma base. Ninguno con `no_prefix`.
- `x-default`: la URL del locale por defecto, salvo que la estrategia sea `no_prefix`, el locale por defecto tenga `seo: false` o la página no exista en él.
- `og:locale` / `og:locale:alternate`: a partir del `og` del locale, o de su `iso` convertido (`en-US` → `en_US`); se omite con un aviso en desarrollo cuando ninguno funciona.

## Ejemplo {#example}

```ts
// app.vue, with i18n.meta: false
const { metaObject } = useLocaleHead({ baseUrl: 'https://example.com' })
useHead(metaObject)
```

`build()` devuelve el mismo objeto sin la ref: `useHead(() => build())` sigue siendo reactivo sin un watcher.
