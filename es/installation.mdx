## Requisitos

- **Node.js**: 18 o superior.
- **Nuxt**: 3.x o 4.x.

El módulo admite tanto la disposición de proyecto de Nuxt 3 (`pages/**/*.vue`) como la de Nuxt 4 (`app/pages/**/*.vue`). Las traducciones residen en la raíz del proyecto por convención (`locales/`), incluso al usar el directorio `app/` de Nuxt 4.

## Instalar el módulo de Nuxt

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Regístralo en `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Consulta el [Inicio rápido](/quickstart) para un recorrido completo o la [Referencia de configuración](/guides/configuration) para conocer todas las opciones.

## Estructura del proyecto

Por defecto, el módulo espera:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Los archivos raíz se fusionan en cada archivo específico de página en tiempo de compilación. Los archivos específicos de página se crean automáticamente si faltan durante `nuxt dev`.

## Disposición de Nuxt 4

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Para colocar las traducciones dentro de `app/`, establece `translationDir: 'app/locales'`.

## Paquetes del ecosistema

| Paquete | Propósito |
| --- | --- |
| [`@i18n-micro/vue`](/integrations/vue) | Integración con Vue 3 (independiente, sin Nuxt). |
| [`@i18n-micro/react`](/integrations/react) | Integración con React. |
| [`@i18n-micro/preact`](/integrations/preact) | Integración con Preact. |
| [`@i18n-micro/solid`](/integrations/solid) | Integración con SolidJS. |
| [`@i18n-micro/astro`](/integrations/astro) | Integración con Astro. |
| [`@i18n-micro/node`](/integrations/nodejs) | Loader del lado del servidor para Node.js. |
| [`@i18n-micro/types-generator`](/integrations/types-generator) | Genera tipos TypeScript a partir de los archivos de traducción. |
| [`@i18n-micro/devtools-ui`](/integrations/devtools-ui) | Panel de DevTools agnóstico al framework. |

Los paquetes internos compartidos se instalan de forma transitiva.

## TypeScript

El módulo genera tipos ambientales para `useI18n`, `$t` y helpers relacionados basados en los archivos del idioma por defecto. Esto está activado por defecto (`types: true`).

Para un tipado más estricto de las claves de traducción, consulta [`@i18n-micro/types-generator`](/integrations/types-generator).
