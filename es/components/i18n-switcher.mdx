---
title: "<i18n-switcher>"
description: "El componente <i18n-switcher> es un desplegable con los locales habilitados, cada uno enlazado a la página actual en ese locale."
---

`<i18n-switcher>` renderiza un botón con el locale activo y un desplegable con todos los locales habilitados, incluido el activo. Úsalo como menú de idiomas listo para usar; crea el tuyo propio a partir de [`$getLocales`](/es/api/methods#$getlocales) y [`$switchLocalePath`](/es/api/methods#$switchlocalepath) cuando necesites un marcado diferente. Cada entrada enlaza a la página actual en ese locale.

## Props y slots {#props-and-slots}

| Prop | Tipo | Valor predeterminado | Descripción |
| --- | --- | --- | --- |
| `customLabels` | `Record<string, string>` | `() => ({})` | Nombre visible por código de locale, que sobrescribe el `displayName` de la configuración del locale. |
| `customWrapperStyle` | `CSSProperties` | `() => ({})` | Estilo en línea para el contenedor exterior. |
| `customButtonStyle` | `CSSProperties` | `() => ({})` | Estilo en línea para el botón que abre el desplegable. |
| `customDropdownStyle` | `CSSProperties` | `() => ({})` | Estilo en línea para el panel desplegable. |
| `customItemStyle` | `CSSProperties` | `() => ({})` | Estilo en línea para cada elemento del desplegable. |
| `customLinkStyle` | `CSSProperties` | `() => ({})` | Estilo en línea para el enlace dentro de un elemento. |
| `customActiveLinkStyle` | `CSSProperties` | `() => ({})` | Estilo en línea para el enlace del locale activo. |
| `customDisabledLinkStyle` | `CSSProperties` | `() => ({})` | Estilo en línea para el botón del locale *actual* cuando tiene `disabled: true` en la configuración. |
| `customIconStyle` | `CSSProperties` | `() => ({})` | Estilo en línea para el icono de flecha del botón. |

### Slots {#slots}

| Slot | Bindings | Descripción |
| --- | --- | --- |
| `before-button` | — | Contenido antes del botón que abre el desplegable. |
| `before-selected-locale` | — | Contenido antes de la etiqueta del locale activo dentro del botón. |
| `after-selected-locale` | — | Contenido después de la etiqueta del locale activo dentro del botón. |
| `before-dropdown` | — | Contenido entre el botón y el panel desplegable. |
| `before-dropdown-items` | — | Contenido en la parte superior del desplegable, encima de la lista de locales. |
| `before-item` | `locale` | Contenido antes de cada entrada de locale. |
| `before-link-content` | `locale` | Contenido antes de la etiqueta de un locale dentro de su enlace. |
| `after-link-content` | `locale` | Contenido después de la etiqueta de un locale dentro de su enlace. |
| `after-item` | `locale` | Contenido después de cada entrada de locale. |
| `after-dropdown-items` | — | Contenido en la parte inferior del desplegable, debajo de la lista de locales. |
| `after-dropdown` | — | Contenido después del panel desplegable. |

## Comportamiento {#behaviour}

- Muestra todos los locales sin `disabled: true`, incluido el activo.
- Cada entrada es un `<a>` hacia `$switchLocalePath(code)`. Una ruta se resuelve bajo `app.baseURL`; un `baseUrl` de locale en otro dominio se mantiene absoluto. Tiene `hreflang` y `lang` establecidos en `iso || code`, `dir` cuando el locale lo define, `aria-current="page"` en el locale actual y la clase `switcher-locale-<code>`. Un clic llama a `$switchLocale(code)` y cierra el desplegable; con una tecla modificadora, se deja en manos del navegador.
- La lista permanece en el HTML del servidor, oculta, para que los rastreadores vean los enlaces. Escape o un clic fuera la cierran.
- Etiqueta: `customLabels[code]`, después el `displayName` del locale y, por último, el código (con una advertencia en desarrollo).
- Estilos: pequeños valores en línea predeterminados (botón y panel blancos con borde, la entrada activa en negrita y azul). Cada prop `custom*Style` se aplica después del valor predeterminado de su parte. El botón tiene las clases `i18n-switcher-button` y `language-switcher`, el contenedor `i18n-switcher-wrapper` y la lista `i18n-switcher-dropdown`. Las posiciones usan propiedades CSS lógicas, por lo que `dir="rtl"` funciona.

## Ejemplo {#example}

```vue
<template>
  <i18n-switcher
    :custom-labels="{ en: 'English', de: 'Deutsch' }"
    :custom-button-style="{ borderRadius: '4px' }"
  >
    <template #before-link-content="{ locale }">
      <img :src="`/flags/${locale.code}.svg`" alt="" width="16" />
    </template>
  </i18n-switcher>
</template>
```
