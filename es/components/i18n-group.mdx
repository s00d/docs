---
title: "<i18n-group>"
description: "El componente <i18n-group> proporciona a su slot una función t limitada a un prefijo de clave."
---

`<i18n-group>` limita un bloque de marcado a un único prefijo de clave. Úsalo cuando muchas claves de una sección comparten un prefijo y no quieres repetirlo. El slot por defecto recibe un `t` que antepone el prefijo.

## Props y slot {#props-and-slot}

| Prop | Tipo | Por defecto | Descripción |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | Prefijo de clave con el que se resuelve cada búsqueda dentro del slot. |
| `groupClass` | `string` | `''` | Clase adicional en el elemento contenedor. |

**\*** obligatorio.

### Slots {#slots}

| Slot | Bindings | Descripción |
| --- | --- | --- |
| `default` | `prefix`, `t` | Recibe `prefix` y una función `t` limitada a él. |

## Comportamiento {#behaviour}

- Renderiza `<div class="i18n-group {groupClass}">` alrededor del slot.
- `t(key, params)` equivale a `$t(prefix + '.' + key, params)` para la ruta actual.
- Solo el `t` del slot está limitado: `$t` y los `<i18n-t>` anidados dentro del grupo siguen usando claves completas.

## Ejemplo {#example}

```json
{
  "checkout": { "title": "Checkout", "items": "Items: {count}" }
}
```

```vue
<template>
  <i18n-group prefix="checkout" group-class="checkout">
    <template #default="{ t }">
      <h2>{{ t('title') }}</h2>
      <p>{{ t('items', { count: 3 }) }}</p>
    </template>
  </i18n-group>
</template>
```
