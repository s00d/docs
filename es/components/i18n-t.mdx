title: "<i18n-t>"
description: "El componente <i18n-t> renderiza una traducción, con formas plurales, formato de números y fechas, e interpolación de HTML y slots."
---

`<i18n-t>` renderiza una traducción dentro de un elemento. Úsalo cuando una traducción necesita componentes en su interior (un enlace dentro de una frase), una forma plural o un número o fecha con formato. Resuelve la clave para la ruta actual, igual que `$t`.

## Props {#props}

| Prop | Tipo | Por defecto | Descripción |
| --- | --- | --- | --- |
| `keypath` **\*** | `string` | — | Clave de traducción que se renderiza. |
| `plural` | `number \| string \| null` | — | Cantidad que selecciona la forma plural. Defínela para usar `$tc` en lugar de `$t`. `null` significa sin definir. |
| `tag` | `string` | `'span'` | Elemento que se renderiza. |
| `params` | `Record<string, string \| number \| boolean>` | — | Valores de interpolación sustituidos en la traducción. |
| `defaultValue` | `string` | `''` | Se renderiza en lugar del componente cuando `hideIfEmpty` suprime una traducción vacía. |
| `html` | `boolean` | `false` | Renderiza la traducción como HTML en lugar de texto. Solo para traducciones que controlas: los `params` se escapan, la traducción no. |
| `hideIfEmpty` | `boolean` | `false` | No renderiza nada cuando la traducción se resuelve en una cadena vacía. |
| `customPluralRule` | `PluralFunc` | `null` | Regla de plural solo para este elemento, que sustituye a la configurada. Su respuesta se usa tal cual; `null` renderiza vacío. |
| `number` | `number \| string \| null` | — | Formatea el valor con `$tn` y lo pasa a la traducción como `{number}`, junto con `params`. |
| `date` | `Date \| string \| number \| null` | — | Formatea el valor con `$td` y lo pasa a la traducción como `{date}`, junto con `params`. |
| `relativeDate` | `Date \| string \| number \| null` | — | Formatea el valor con `$tdr` y lo pasa a la traducción como `{relativeDate}`, junto con `params`. |

**\*** obligatorio.

## Reglas de renderizado {#rendering-rules}

El primer caso que coincide decide el resultado:

1. `number` — la traducción con `{ ...params, number: $tn(number) }`.
2. `date` — la traducción con `{ ...params, date: $td(date) }`.
3. `relativeDate` — la traducción con `{ ...params, relativeDate: $tdr(relativeDate) }`.
4. `plural` — la forma que elige `$tc`, incluido el [marcador `=0 `](/es/api/methods#$tc), con `{ ...params, count }`; o `customPluralRule(keypath, count, params, locale, t)` cuando está definida, que lee el valor en bruto, marcador incluido, y cuya respuesta se usa tal cual, siendo `null` vacío.
5. En cualquier otro caso, la traducción con `params`.

`null` cuenta como no definido. En todos los casos:

- `defaultValue` sustituye a una clave inexistente, en todas las ramas.
- `hideIfEmpty` renderiza `defaultValue` en lugar de un resultado vacío.
- `html` renderiza el resultado como HTML. Los `params` se escapan, la traducción no; los slots se ignoran.
- Un slot `default` recibe `{ translation }`, y los slots con nombre se ignoran.
- En caso contrario, cada slot con nombre sustituye todos los marcadores `{name}`, antes que un param con ese nombre. Un valor de param que parezca un marcador se queda como texto.

La salida de `date` y `relativeDate` lleva `data-allow-mismatch="text"`, porque la zona horaria y el reloj del servidor no son los del navegador. Define [`timeZone`](/es/api/module-options#timezone) para renderizar la misma fecha de calendario en ambos; `relativeDate` depende del reloj, así que aún puede diferir.

## Ejemplo {#example}

```json
{
  "terms": "I accept the {link}.",
  "termsLink": "terms of use",
  "items": "no items | one item | {count} items"
}
```

```vue
<template>
  <i18n-t keypath="terms" tag="p">
    <template #link>
      <NuxtLink :to="$localePath('/terms')">{{ $t('termsLink') }}</NuxtLink>
    </template>
  </i18n-t>

  <i18n-t keypath="items" :plural="cart.length" />
</template>
```

`html` establece `innerHTML`: úsalo solo para traducciones que controlas. Los `params` se escapan, así que los datos de usuario son seguros ahí, igual que una clave que no encontró traducción.
