## 🚀 Inicio rápido

### Instalación

Instala el módulo en tu aplicación Nuxt:

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

### Configuración básica

Añade el módulo a tu `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

<Tip>
- **Archivos raíz** (`locales/en.json`, etc.) — traducciones compartidas en toda la app (menús, pie de página, UI común). Con `translationPayloads.mode: 'premerged'` (por defecto), se fusionan en cada página en tiempo de compilación.
- **Archivos por página** (`locales/pages/<route>/<locale>.json`) — traducciones únicas de páginas específicas, cargadas solo cuando se visita la página.
- **Rutas dinámicas** — `pages/articles/[id].vue` se corresponde con `locales/pages/articles-id/` (los corchetes se sustituyen por guiones).
- **Autogeneración** — todos los archivos de traducción se crean automáticamente si faltan durante `nuxt dev`.
</Tip>

<Info>
El módulo admite ambas disposiciones:

- **Páginas**: `pages/**/*.vue` (Nuxt 3) o `app/pages/**/*.vue` (Nuxt 4)
- **Traducciones**: mantén `locales/` en la **raíz del proyecto** por defecto (convención recomendada), no dentro de `app/`

```tree
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   ├── en.json
│   └── pages/
└── nuxt.config.ts
```

Colocación opcional: `i18n: \{ translationDir: 'app/locales' \}` (consulta la [fixture `n3`](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/n3)).

Para el helper CLI opcional `text-to-i18n`, usa [`nuxt-i18n-micro-cli` ≥ 2.1.1](/guides/cli#-text-to-i18n-command) para que `app/pages` y `app/components` se escaneen desde la raíz del proyecto.
</Info>

### Uso básico

Usa las traducciones en tus componentes:

```vue
<template>
  <div>
    <h1>{{ $t('welcome') }}</h1>
    <p>{{ $t('description', { name: 'World' }) }}</p>

    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" @click="$switchLocale(locale.code)">
        {{ locale.code }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useI18n } from '#imports'

const { $t, $getLocales, $switchLocale } = useI18n()
</script>
```
