**Fecha**: 2025-10-30

**Versión**: `v2.0.0`

![v2.0.0 release](/images/2.0.0.png)

Presentamos el HMR del lado del servidor para los archivos de traducción en desarrollo. Cuando cambia una traducción JSON, la caché del servidor invalida solo las claves afectadas y las siguientes peticiones reciben de inmediato los datos actualizados, sin necesidad de reiniciar.

## ¿Qué hay de nuevo? {#what’s-new}

- HMR del lado del servidor para los archivos de traducción
- Invalidación instantánea de la caché por página/idioma
- Experiencia de desarrollo fluida mientras editas el contenido

## Cómo funciona {#how-it-works}

- El watcher en `src/runtime/server/plugins/watcher.dev.ts` observa `<rootDir>/<translationDir>/**/*.json`
- Los archivos de página (p. ej., `pages/<page>/<locale>.json`) invalidan `_locales:merged:<page>:<locale>`
- Los archivos de nivel raíz (p. ej., `<locale>.json`) invalidan todas las claves combinadas de ese idioma
- Se registra automáticamente desde `src/module.ts` en desarrollo cuando `experimental.hmr !== false`

## Configuración {#configuration}

```ts
export default defineNuxtConfig({
  i18n: {
    experimental: { hmr: true }, // default in dev
  },
})
```
