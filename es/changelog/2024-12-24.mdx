**Fecha**: 2024-12-24

**Versión de la CLI en que se introdujo**: `v1.1.0`

![Demo de text-to-i18n de la CLI v1.1.0](/images/text-to-i18n.gif)

¡Nos complace anunciar el nuevo comando `text-to-i18n` en la CLI de Nuxt I18n Micro! Esta potente función automatiza el proceso de extraer cadenas de texto codificadas a mano de tu código y convertirlas en claves de traducción i18n. Está diseñada para ahorrar tiempo, reducir errores y agilizar tu flujo de trabajo de localización.

## Ventajas clave {#key-benefits}

- **Extracción automática de texto**: analiza plantillas Vue y archivos JavaScript y TypeScript.
- **Generación fluida de claves**: crea claves de traducción estructuradas a partir de las rutas de archivo y el contenido.
- **Gestión eficiente de traducciones**: actualiza tus archivos de traducción conservando las entradas existentes.

## Cómo funciona {#how-it-works}

1. **Escaneo de archivos**: procesa archivos en directorios clave como `pages`, `components` y `plugins`.
2. **Procesamiento de texto**: identifica y extrae las cadenas traducibles, generando claves únicas.
3. **Actualización de traducciones**: inserta automáticamente las nuevas claves en tus archivos de traducción y mantiene su estructura anidada.

## Uso {#usage}

```bash
i18n-micro text-to-i18n [options]
```

Ejemplo:

```bash
i18n-micro text-to-i18n --translationFile locales/en.json --context auth
```

## Ejemplos de transformación {#example-transformations}

### Antes {#before}

```vue
<template>
  <div>
    <h1>Welcome to our site</h1>
    <p>Please sign in to continue</p>
  </div>
</template>
```

### Después {#after}

```vue
<template>
  <div>
    <h1>{{ $t('pages.home.welcome_to_our_site') }}</h1>
    <p>{{ $t('pages.home.please_sign_in') }}</p>
  </div>
</template>
```
