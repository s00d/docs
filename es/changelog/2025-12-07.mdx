**Fecha**: 2025-12-07

**Versión**: `v2.14.1`

![Versión v2.14](/images/2.14.0.png)

¡Nos complace anunciar la **v2.14.1** con nuevas integraciones para Node.js, Vue 3 y Astro! Estos paquetes llevan las mismas potentes capacidades de i18n a tus frameworks favoritos y comparten la misma lógica principal para garantizar coherencia y rendimiento.

## ¿Qué hay de nuevo? {#what’s-new}

- **@i18n-micro/node** - Usa traducciones i18n en cualquier aplicación Node.js, herramienta CLI o servicio backend
- **@i18n-micro/vue** - Plugin de Vue 3 para internacionalización con traducciones reactivas y soporte específico por ruta
- **@i18n-micro/astro** - Integración de Astro para internacionalización con soporte completo de TypeScript
- **@i18n-micro/types-generator** - Generación automática de tipos TypeScript para las claves de traducción, con seguridad de tipos completa y autocompletado en el IDE

## Características principales {#key-features}

Todas las integraciones comparten las mismas ventajas principales:

- Ligeras y de alto rendimiento
- Soporte para traducciones específicas por ruta
- Pluralización integrada
- Formato de números, fechas y tiempo relativo
- Soporte completo de TypeScript
- La misma estructura de archivos de traducción JSON

**Types Generator** ofrece mejoras adicionales en la experiencia de desarrollo:

- Generación automática de tipos a partir de archivos de traducción JSON
- Claves de traducción con seguridad de tipos y validación en tiempo de compilación
- Soporte completo de autocompletado en el IDE
- Recarga en caliente cuando cambian los archivos de traducción
- Cero sobrecarga en tiempo de ejecución

Para ver documentación detallada y ejemplos, visita el [repositorio](https://github.com/s00d/nuxt-i18n-micro) o consulta la [documentación](https://s00d.github.io/nuxt-i18n-micro/).
