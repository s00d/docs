# 🛠️ DevTools en `nuxt-i18n-micro`

## Vue DevTools (extensión del navegador)

En desarrollo, el módulo puede registrar un inspector personalizado y una línea de tiempo de **Vue DevTools** mediante `@vue/devtools-api`. Esto es independiente de la pestaña de Nuxt DevTools que se describe más abajo.

| Herramienta | Ideal para |
|------|----------|
| **Vue DevTools** | Locale en vivo, caché de traducciones en memoria, línea de tiempo de `$t` (`debug: true`), eventos de claves faltantes |
| **Pestaña de Nuxt DevTools** | Edición de archivos JSON en disco, resumen de configuración, importar/exportar |

El plugin de vue-devtools se registra solo durante `nuxt dev` (no en compilaciones de producción). El estado del puente exclusivo de desarrollo en el plugin principal se elimina mediante eliminación de código muerto con `import.meta.dev`.

Deshabilita la integración con el navegador manteniendo la pestaña de Nuxt:

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

Los eventos detallados de la línea de tiempo de `$t` requieren `debug: true`.

## 📖 ¿Qué es Nuxt DevTools?

DevTools es un potente asistente de desarrollo integrado sin fisuras en el módulo `nuxt-i18n-micro`. Proporciona una interfaz intuitiva para gestionar tareas de localización y traducción, haciendo tu flujo de trabajo más rápido y eficiente. Diseñado para desarrolladores que valoran la comodidad, Nuxt DevTools cierra la brecha entre la programación y la gestión en tiempo de ejecución.

## 🌟 Funcionalidades clave de DevTools en `nuxt-i18n-micro`

### 1. **Gestión de locales**

Explora, selecciona y gestiona locales en tu aplicación sin esfuerzo. Tanto si trabajas con un solo idioma como con varios, DevTools proporciona un centro unificado para gestionar todos los ajustes de localización.

### 2. **Edición de traducciones**

Edita archivos de traducción directamente a través de un editor JSON integrado. Esto elimina la necesidad de herramientas externas, permitiendo actualizaciones y cambios en tiempo real sin interrumpir tu flujo de trabajo.

### 3. **Importación y exportación de archivos**

Simplifica la gestión de archivos de traducción:

- **Exportar**: guarda las traducciones como un archivo JSON para copias de seguridad o uso externo.
- **Importar**: carga archivos de traducción actualizados en el proyecto para mantener el contenido al día.

### 4. **Vistas previas en tiempo real**

Visualiza los cambios de inmediato dentro del entorno de desarrollo. Esta funcionalidad asegura que las traducciones y configuraciones sean correctas antes de salir a producción.

### 5. **Integración perfecta con Nuxt**

DevTools funciona de forma nativa con `nuxt-i18n-micro`, ampliando sus capacidades sin necesidad de configuración adicional. Se adapta a tus necesidades de localización mientras mantiene la estructura modular y flexible de Nuxt.

## 🛠️ ¿Por qué usar DevTools?

Nuxt DevTools es un complemento imprescindible para proyectos que requieren localización. Ayuda a los desarrolladores:

- **Ahorrando tiempo**: automatiza tareas repetitivas como la gestión de archivos y la validación de formatos.
- **Reduciendo errores**: proporciona un entorno seguro e intuitivo para editar traducciones.
- **Mejorando la colaboración**: permite que personas no desarrolladoras gestionen las traducciones fácilmente.
- **Optimizando flujos de trabajo**: consolida múltiples tareas de localización en una única interfaz.
