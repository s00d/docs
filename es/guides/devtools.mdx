# 🛠️ DevTools en `nuxt-i18n-micro`

## Vue DevTools (extensión de navegador)

En desarrollo, el módulo puede registrar un inspector personalizado y una línea de tiempo de **Vue DevTools** mediante `@vue/devtools-api`. Esto es independiente de la pestaña de Nuxt DevTools que se menciona abajo.

| Herramienta | Mejor para |
|------|----------|
| **Vue DevTools** | Idioma activo, caché de traducciones en memoria, línea de tiempo de `$t` (`debug: true`), eventos de claves ausentes. |
| **Pestaña Nuxt DevTools** | Editar archivos JSON en disco, resumen de configuración, importar/exportar. |

El plugin vue-devtools se registra solo durante `nuxt dev` (no en builds de producción). El estado del bridge solo de dev en el plugin principal se elimina por eliminación de código muerto de `import.meta.dev`.

Desactiva la integración con el navegador mientras mantienes la pestaña de Nuxt:

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

Los eventos verbosos de la línea de tiempo de `$t` requieren `debug: true`.

## 📖 ¿Qué son las Nuxt DevTools?

DevTools es un potente asistente de desarrollo integrado sin fisuras en el módulo `nuxt-i18n-micro`. Proporciona una interfaz intuitiva para gestionar tareas de localización y traducción, haciendo tu flujo de trabajo más rápido y eficiente. Diseñado para desarrolladores que valoran la comodidad, Nuxt DevTools cubre la brecha entre programar y gestionar en runtime.

## 🌟 Características clave de DevTools en `nuxt-i18n-micro`

### 1. **Gestión de idiomas**

Explora, selecciona y gestiona idiomas en tu aplicación sin esfuerzo. Ya trabajes con un solo idioma o con varios, DevTools proporciona un hub centralizado para manejar toda la configuración de localización.

### 2. **Edición de traducciones**

Edita archivos de traducción directamente mediante un editor JSON integrado. Esto elimina la necesidad de herramientas externas, permitiendo actualizaciones y cambios en tiempo real sin interrumpir tu flujo de trabajo.

### 3. **Importar y exportar archivos**

Simplifica el proceso de gestión de archivos de traducción:

- **Exportar**: Guarda las traducciones como archivo JSON para copias de seguridad o uso externo.
- **Importar**: Carga archivos de traducción actualizados en el proyecto para mantener el contenido al día.

### 4. **Vistas previas en tiempo real**

Visualiza los cambios inmediatamente en el entorno de desarrollo. Esta función asegura que las traducciones y configuraciones sean correctas antes de pasar a producción.

### 5. **Integración fluida con Nuxt**

DevTools funciona de forma nativa con `nuxt-i18n-micro`, mejorando sus capacidades sin requerir configuración adicional. Se adapta a tus necesidades de localización manteniendo la estructura modular y flexible de Nuxt.

## 🛠️ ¿Por qué usar DevTools?

Nuxt DevTools es un complemento indispensable para proyectos que requieren localización. Ayuda a los desarrolladores al:

- **Ahorrar tiempo**: Automatiza tareas repetitivas como la gestión de archivos y la validación de formatos.
- **Reducir errores**: Proporciona un entorno seguro e intuitivo para editar traducciones.
- **Mejorar la colaboración**: Permite a personas no técnicas gestionar traducciones fácilmente.
- **Agilizar los flujos de trabajo**: Consolida múltiples tareas de localización en una única interfaz.
