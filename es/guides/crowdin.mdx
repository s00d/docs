# 🌐 Guía de integración con Crowdin

## 📖 Introducción

Integrar Crowdin en tu proyecto agiliza el proceso de localización y traducción, facilitando la gestión de traducciones en múltiples idiomas y plataformas. Esta guía ofrece un recorrido paso a paso para configurar Crowdin con tu proyecto, incluyendo la configuración, la subida de fuentes y la descarga de traducciones.

## 🔧 Instalación y configuración

Para empezar con Crowdin, tendrás que instalar la CLI de Crowdin globalmente en tu máquina e inicializarla dentro del directorio de tu proyecto.

### 📦 Instalar la CLI de Crowdin

Primero, instala la CLI de Crowdin globalmente con npm:

```bash
npm install -g @crowdin/cli
```

### 🛠 Inicializar Crowdin en tu proyecto

Inicializa Crowdin en tu proyecto ejecutando:

```bash
crowdin init
```

Este comando te guiará por el proceso de configuración, incluyendo la definición del ID de proyecto, el token de API y otros detalles.

## 🗂️ Guía de configuración

### 📄 Archivo de configuración de Crowdin (`crowdin.yml`)

El archivo de configuración de Crowdin (`crowdin.yml`) define cómo se asignan tus archivos fuente y dónde deben colocarse las traducciones. Debajo tienes una configuración de ejemplo:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Parámetros clave de configuración

- **`project_id`**: El ID de tu proyecto en Crowdin. Identifica el proyecto dentro de Crowdin donde se gestionan las traducciones.
- **`api_token`**: El token de API usado para la autenticación. Asegúrate de que este token tiene los permisos correctos para subir y descargar traducciones.
- **`base_path`**: Especifica el directorio base para los archivos fuente. En este ejemplo, las traducciones se almacenan en el directorio `./locales`.
- **`base_url`**: La URL base para la API de Crowdin.
- **`preserve_hierarchy`**: Cuando se establece en `true`, Crowdin mantendrá la estructura de carpetas de tus archivos fuente en el proyecto.

### 📂 Configuración de archivos

La sección `files` asigna tus archivos fuente a las rutas donde se almacenarán las traducciones. Por ejemplo:

- **Ruta de origen**: Define la ubicación de los archivos de traducción originales.
- **Ruta de traducción**: Especifica dónde se almacenarán los archivos traducidos en Crowdin. Placeholders como `%two_letters_code%` se usan para establecer dinámicamente el código de idioma en las rutas.

## ⬆️ Subir archivos fuente a Crowdin

Una vez configurada tu Crowdin, puedes subir tus archivos fuente con el siguiente comando:

```bash
crowdin upload sources
```

Este comando sube todos los archivos fuente especificados en tu configuración a Crowdin, haciéndolos disponibles para la traducción.

## ⬇️ Descargar traducciones desde Crowdin

Después de que las traducciones se completen o actualicen en Crowdin, puedes descargarlas a tu proyecto con:

```bash
crowdin download
```

Este comando obtiene las últimas traducciones desde Crowdin y las guarda según las rutas especificadas en tu archivo de configuración.

## ⚙️ Buenas prácticas

### 🔑 Nomenclatura de claves consistente

Asegúrate de que las claves de traducción sean consistentes en todos los archivos para evitar confusión y duplicación.

### 🧹 Mantenimiento regular

Revisa y limpia periódicamente las claves de traducción no usadas para mantener tus archivos organizados y manejables.

### 🛠 Automatizar subidas y descargas

Integra los comandos de la CLI de Crowdin en tu pipeline de CI/CD para automatizar la subida de archivos fuente y la descarga de traducciones, asegurando que tus traducciones estén siempre al día.

Siguiendo esta guía, podrás integrar Crowdin en tu proyecto de forma fluida, asegurando un enfoque eficiente y organizado para gestionar tus esfuerzos de internacionalización.
