# 🌐 Guía de integración con Crowdin

## 📖 Introducción

Integrar Crowdin en tu proyecto agiliza el proceso de localización y traducción, facilitando la gestión de traducciones entre múltiples idiomas y plataformas. Esta guía ofrece un recorrido paso a paso para configurar Crowdin con tu proyecto, incluyendo la configuración, la carga de fuentes y la descarga de traducciones.

## 🔧 Instalación y configuración

Para empezar con Crowdin, necesitarás instalar globalmente el CLI de Crowdin en tu máquina e inicializarlo dentro del directorio de tu proyecto.

### 📦 Instalación del CLI de Crowdin

Primero, instala el CLI de Crowdin globalmente usando npm:

```bash
npm install -g @crowdin/cli
```

### 🛠 Inicialización de Crowdin en tu proyecto

Inicializa Crowdin en tu proyecto ejecutando:

```bash
crowdin init
```

Este comando te guiará por el proceso de configuración, incluyendo el establecimiento del ID de proyecto, el token de API y otros detalles de configuración.

## 🗂️ Guía de configuración

### 📄 Archivo de configuración de Crowdin (`crowdin.yml`)

El archivo de configuración de Crowdin (`crowdin.yml`) define cómo se mapean tus archivos fuente y dónde deben ubicarse las traducciones. A continuación se muestra una configuración de ejemplo:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Parámetros clave de configuración

- **`project_id`**: el ID de tu proyecto en Crowdin. Identifica el proyecto dentro de Crowdin donde se gestionan las traducciones.
- **`api_token`**: el token de API utilizado para la autenticación. Asegúrate de que este token tenga los permisos correctos para subir y descargar traducciones.
- **`base_path`**: especifica el directorio base para los archivos fuente. En este ejemplo, las traducciones se almacenan en el directorio `./locales`.
- **`base_url`**: la URL base de la API de Crowdin.
- **`preserve_hierarchy`**: cuando se establece en `true`, Crowdin mantendrá la estructura de carpetas de tus archivos fuente en el proyecto.

### 📂 Configuración de archivos

La sección `files` asigna tus archivos fuente a las rutas donde se almacenarán las traducciones. Por ejemplo:

- **Ruta fuente**: define la ubicación de los archivos de traducción originales.
- **Ruta de traducción**: especifica dónde se almacenarán los archivos traducidos en Crowdin. Se usan marcadores como `%two_letters_code%` para establecer dinámicamente el código de idioma en las rutas de los archivos.

## ⬆️ Subir archivos fuente a Crowdin

Una vez configurada tu configuración de Crowdin, puedes subir tus archivos fuente con el siguiente comando:

```bash
crowdin upload sources
```

Este comando sube a Crowdin todos los archivos fuente especificados en tu configuración, dejándolos disponibles para su traducción.

## ⬇️ Descargar traducciones desde Crowdin

Después de completar o actualizar las traducciones en Crowdin, puedes descargarlas a tu proyecto usando:

```bash
crowdin download
```

Este comando obtiene las últimas traducciones de Crowdin y las guarda según las rutas especificadas en tu archivo de configuración.

## ⚙️ Buenas prácticas

### 🔑 Nomenclatura de claves consistente

Asegúrate de que las claves de traducción sean coherentes en todos los archivos para evitar confusión y duplicación.

### 🧹 Mantenimiento regular

Revisa y limpia periódicamente las claves de traducción no utilizadas para mantener tus archivos organizados y manejables.

### 🛠 Automatiza subidas y descargas

Integra los comandos del CLI de Crowdin en tu pipeline de CI/CD para automatizar la subida de archivos fuente y la descarga de traducciones, garantizando que tus traducciones estén siempre actualizadas.

Siguiendo esta guía, podrás integrar Crowdin en tu proyecto sin problemas, asegurando un enfoque eficiente y organizado para gestionar tus esfuerzos de internacionalización.
