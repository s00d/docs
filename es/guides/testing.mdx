# 🧪 Pruebas del módulo `Nuxt I18n Micro`

## 📖 Introducción a las pruebas

Probar el módulo `Nuxt I18n Micro` es fundamental para asegurar que las funcionalidades de localización de tu aplicación funcionan como se espera. Esta documentación te guiará por la configuración del entorno de pruebas, la creación de configuraciones mock para vitest y la escritura de pruebas para tus componentes. Para un ejemplo práctico, puedes consultar el [proyecto de ejemplo en GitHub](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/test-utils/example).

Consulta [Testing routing strategies](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/testing-strategies.md) para ver cómo este repositorio ejecuta sus propias suites: los proyectos de Vitest `unit` / `integration` / `e2e`, los archivos por estrategia (`test/strategies-*.test.ts`) y las regresiones generadas.

## 🛠️ Configurar el entorno de pruebas

### 1. Instalar `@i18n-micro/test-utils`

Primero, necesitas instalar las utilidades de prueba para `Nuxt I18n Micro`. Este paquete proporciona las herramientas necesarias para simular (mock) y probar tus configuraciones de i18n.

```bash
npm install @i18n-micro/test-utils --save-dev
```

### 2. Crear un archivo de configuración mock

A continuación, crea un archivo para configurar la configuración mock de i18n. Este archivo se usará para simular las funciones y utilidades de i18n durante tus pruebas.

```typescript
// tests/unit-setup.ts

import { mockNuxtImport } from '@nuxt/test-utils/runtime'
import { vi } from 'vitest'
import { i18nUtils } from '@i18n-micro/test-utils'

export function createFakeI18n() {
  return {
    $getLocale: vi.fn(i18nUtils.getLocale),
    $t: vi.fn(i18nUtils.t),
    $tc: vi.fn(i18nUtils.tc),
    $setLocale: vi.fn(i18nUtils.setLocale),
    $getLocaleName: vi.fn(i18nUtils.getLocaleName),
    $setLocaleName: vi.fn(i18nUtils.setLocaleName),
    $getLocales: vi.fn(i18nUtils.getLocales),
    $setLocales: vi.fn(i18nUtils.setLocales),
    $defaultLocale: vi.fn(i18nUtils.defaultLocale),
    $setDefaultLocale: vi.fn(i18nUtils.setDefaultLocale),
    $getRouteName: vi.fn(i18nUtils.getRouteName),
    $settRouteName: vi.fn(i18nUtils.settRouteName),
    $ts: vi.fn(i18nUtils.ts),
    $tn: vi.fn(i18nUtils.tn),
    $td: vi.fn(i18nUtils.td),
    $has: vi.fn(i18nUtils.has),
    $resolveTranslations: vi.fn(i18nUtils.resolveTranslations),
    $setTranslation: vi.fn(i18nUtils.setTranslation),
    $mergeTranslations: vi.fn(i18nUtils.mergeTranslations),
    $switchLocaleRoute: vi.fn(i18nUtils.switchLocaleRoute),
    $switchLocalePath: vi.fn(i18nUtils.switchLocalePath),
    $switchLocale: vi.fn(i18nUtils.switchLocale),
    $switchRoute: vi.fn(i18nUtils.switchRoute),
    $localeRoute: vi.fn(i18nUtils.localeRoute),
    $localePath: vi.fn(i18nUtils.localePath),
    $setI18nRouteParams: vi.fn(i18nUtils.setI18nRouteParams),
  }
}

mockNuxtImport<() => ReturnType<typeof createFakeI18n>>('useI18n', () => vi.fn(() => createFakeI18n()))

export const setTranslationsFromJson = i18nUtils.setTranslationsFromJson
```

### 3. Configurar Vitest

Ahora, configura Vitest para usar el archivo de configuración mock y preparar el entorno de pruebas.

```typescript
// vitest.config.ts

import { defineVitestConfig } from '@nuxt/test-utils/config'

export default defineVitestConfig({
  test: {
    watch: false,
    setupFiles: ['./tests/unit-setup.ts'],
    include: ['./**/*.spec.ts'],
  },
})
```

## 🧪 Escribir pruebas

### Componente de ejemplo

Este es un ejemplo de un componente sencillo que usa el composable `useI18n` para traducir mensajes.

```vue
<script setup lang="ts">
const { $t } = useI18n()

const props = defineProps({
  message: {
    type: String,
    default: null,
  },
})

// Test to see that $t works in script setup as well as the template
const message = props.message || $t('defaultMessage')
</script>

<template>
  <div>
    <p>Test from component: {{ $t('welcome') }}</p>
    <p data-testid="message">Test message from props: {{ message }}</p>
  </div>
</template>
```

### Archivo de prueba

Ahora, escribamos una prueba para este componente.

```typescript
// tests/unit/example.spec.ts

import { describe, it, expect, beforeEach } from 'vitest'
import { mount } from '@vue/test-utils'
import ExampleComponent from '@/components/ExampleComponent.vue'
import fs from 'fs'
import path from 'path'
import { setTranslationsFromJson } from './unit-setup'

describe('ExampleComponent', () => {
  beforeEach(async () => {
    const fileContent = fs.readFileSync(path.join(__dirname, '../../locales/en-GB.json')).toString()
    await setTranslationsFromJson('en', JSON.parse(fileContent))
  })

  it('renders the welcome message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.text()).toContain('Test from component: Welcome')
  })

  it('renders the default message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Default Message')
  })

  it('renders the custom message correctly', () => {
    const wrapper = mount(ExampleComponent, {
      props: {
        message: 'Custom Message',
      },
    })
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Custom Message')
  })
})
```

## 📝 Buenas prácticas para las pruebas

- **🔧 Simula las funciones de i18n:** simula siempre las funciones de i18n con `@i18n-micro/test-utils` para asegurar resultados de prueba consistentes y predecibles.
- **⚙️ Usa Vitest para las pruebas unitarias:** Vitest es un potente framework de pruebas para aplicaciones Vue. Úsalo para escribir pruebas unitarias de tus componentes.
- **📚 Documenta tus pruebas:** documenta claramente el propósito y los resultados esperados de cada prueba. Esto ayudará a mantener la claridad y facilitará que otras personas (o tú en el futuro) entiendan las pruebas.

## 📊 Métodos utilitarios de i18n

A continuación se muestra una tabla que describe todos los métodos utilitarios proporcionados por `@i18n-micro/test-utils`.

| Método                                          | Descripción                                                                                                                                |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `t(key, params, defaultValue)`                  | Traduce una clave con parámetros opcionales y un valor por defecto.                                                                        |
| `tc(key, params, defaultValue)`                 | Traduce una clave con soporte para pluralización.                                                                                          |
| `setTranslationsFromJson(locale, translations)` | Carga traducciones desde un objeto JSON para un locale específico.                                                                         |
| `getLocale()`                                   | Devuelve el locale actual.                                                                                                                 |
| `setLocale(val)`                                | Establece el locale actual.                                                                                                                |
| `getLocaleName()`                               | Devuelve el nombre del locale actual.                                                                                                      |
| `setLocaleName(val)`                            | Establece el nombre del locale actual.                                                                                                     |
| `getLocales()`                                  | Devuelve la lista de locales disponibles.                                                                                                  |
| `setLocales(val)`                               | Establece la lista de locales disponibles.                                                                                                 |
| `defaultLocale()`                               | Devuelve el locale predeterminado.                                                                                                         |
| `setDefaultLocale(val)`                         | Establece el locale predeterminado.                                                                                                        |
| `getRouteName()`                                | Devuelve el nombre de la ruta actual.                                                                                                      |
| `settRouteName(val)`                            | Establece el nombre de la ruta actual.                                                                                                     |
| `ts(key, params, defaultValue)`                 | Traduce una clave y devuelve el resultado como una cadena.                                                                                 |
| `tn(value, options?)`                           | Formatea un número con `Intl.NumberFormatOptions` en línea. Los formatos con nombre requieren configuración del módulo y no están disponibles en este helper independiente. |
| `td(value, options?)`                           | Formatea una fecha con `Intl.DateTimeFormatOptions` en línea. Los formatos con nombre requieren configuración del módulo y no están disponibles en este helper independiente. |
| `has(key)`                                      | Comprueba si existe una clave de traducción.                                                                                               |
| `resolveTranslations()`                         | Devuelve el árbol de traducciones activo para el locale y la ruta actuales.                                                                |
| `setTranslation(key, value)`                    | Reemplaza el valor en `key` del diccionario activo (reemplazo, no fusión).                                                                 |
| `mergeTranslations(newTranslations)`            | Fusiona traducciones en el locale activo en tiempo de ejecución.                                                                           |

Siguiendo estos pasos, puedes probar de manera efectiva el módulo `Nuxt I18n Micro` y asegurarte de que las funcionalidades de localización de tu aplicación funcionan como se espera.
