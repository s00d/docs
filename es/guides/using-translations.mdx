# Usar traducciones en componentes

Una vez que el módulo está instalado y configurado, puedes mostrar traducciones llamando a `$t('your_key')` dentro de tus plantillas y scripts Vue.

## 1. Archivos de traducción raíz y por página

1. Las traducciones **raíz** residen directamente bajo la carpeta `/locales` (por ejemplo, `/locales/en.json`, `/locales/fr.json`). En tiempo de compilación se fusionan automáticamente en cada archivo específico de página, haciéndolas disponibles en todas las páginas.
2. Las traducciones **por página** viven bajo `/locales/pages/...`, siguiendo la estructura de carpetas de páginas de Nuxt:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. Uso en plantilla con `$t`

En tus archivos `.vue`, puedes usar directamente `$t` en la plantilla:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
`$t` puede devolver **objetos** si la clave apunta a un nodo JSON anidado (por ejemplo, `$t('header')` → `\{ title: "Hi" \}`). En las plantillas esto se renderiza como `[object Object]`. Usa `$ts` cuando necesites una cadena garantizada, o proporciona una clave más específica como `$t('header.title')`. Consulta [Referencia de la API — $t frente a $ts](/api/methods#t) para más detalles.
</Tip>

## 3. Cambiar el idioma actual

Para cambiar de idioma en tu app, puedes obtener `$locale` desde `useI18n()` y asignarle un nuevo código:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. Claves anidadas y placeholders

- **Claves anidadas**: usan notación con puntos, por ejemplo, `nested.key.deeper`.
- **Placeholders**: te permiten insertar valores dinámicos:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. Consejos y buenas prácticas

- **Claves en conflicto**: Si un archivo específico de página contiene la misma clave que un archivo raíz, la versión específica de página tiene prioridad (las traducciones raíz se fusionan como base en tiempo de compilación).
- **Desactivar archivos por página**: Si prefieres no usar traducciones específicas de página, puedes establecer `disablePageLocales: true` en tu configuración de Nuxt. De esta manera, solo se usan los archivos `/locales/*.json`.
- **Sin imports directos**: No necesitas hacer `import \{ useI18n \} from 'nuxt-i18n-micro'`; la función de autoinyección del módulo lo gestiona por ti.

¡Eso es todo! Con estos pasos puedes **empezar a obtener traducciones** rápidamente desde archivos JSON raíz o específicos de página, y **mostrarlas** en tu aplicación Nuxt usando `$t`.

## Recursos adicionales

Para explorar funciones más avanzadas, asegúrate de consultar:

1. **Componente `<i18n-t>`**  
   El componente `<i18n-t>` es una alternativa potente a `$t`, especialmente útil para situaciones que involucran elementos anidados, uso avanzado de placeholders y estructuras de traducción más complejas.

- **Documentación**: [i18n-t](/api/components/i18n-t)

2. **Composable `useI18n`**  
   El composable `useI18n` ofrece un conjunto completo de funciones y propiedades reactivas para gestionar traducciones, manejar el cambio de idioma, formateo y más.

- **Documentación**: [useI18n](/api/composables/use-i18n)
