En `nuxt dev`, el módulo añade dos ayudas de depuración: una pestaña **i18n Micro** en Nuxt DevTools para explorar y editar los archivos de traducción, y un inspector de Vue DevTools para el locale activo y los diccionarios cargados. Ambas existen solo en desarrollo y no añaden nada a las compilaciones de producción. La pestaña de Nuxt solo necesita que Nuxt DevTools esté habilitado; el inspector de Vue necesita además la extensión de navegador de Vue DevTools.

## Pestaña de Nuxt DevTools {#nuxt-devtools-tab}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  devtools: { enabled: true }, // the tab is registered only when DevTools are on
})
```

Abre Nuxt DevTools (`Shift + Alt + D`) y elige **i18n Micro**. La pestaña muestra:

- todos los archivos JSON bajo `locales/` (raíz y `pages/`) de cada capa, además de los archivos raíz de `additionalTranslationDirs`;
- un editor por archivo; **Save** escribe el archivo de nuevo en el disco y el servidor de desarrollo recarga las traducciones;
- **Export** / **Import** de un archivo como JSON, y **Stats** con el número de claves y la cobertura de traducción;
- una vista de configuración con las opciones del módulo resueltas;
- **Translate**, que rellena las claves que faltan con un motor de traducción automática que configuras en los ajustes de la pestaña.

Al guardar, solo se escriben archivos `.json` existentes dentro de tus directorios de traducción. Cuando un archivo existe en varias capas, se escribe la copia del proyecto.

## Inspector de Vue DevTools {#vue-devtools-inspector}

Con la extensión de navegador de Vue DevTools, el módulo registra un inspector de i18n (locale actual, chunk de la ruta, claves cargadas) y una línea de tiempo con los cambios de locale, las cargas de chunks y las claves que faltan.

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    debug: true, // also log every $t / $ts / $tc call on the timeline
    // vueDevtools: false, // turn the inspector off, keep the Nuxt tab
  },
})
```

[`vueDevtools`](/es/api/module-options) es `true` por defecto. `debug: true` genera mucha salida; úsalo solo en sesiones cortas.

## Fuera de Nuxt {#outside-nuxt}

La misma interfaz se publica como [`@i18n-micro/devtools-ui`](/es/integrations/devtools-ui-package) para aplicaciones Vite basadas en los paquetes de frameworks; consulta esa página para la configuración.
