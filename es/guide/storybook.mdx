title: "Storybook"
description: "Renderiza en Storybook para Nuxt componentes que usan $t sirviendo payloads de traducción precombinados como archivos estáticos."
---

Storybook para Nuxt (`@nuxtjs/storybook`) ejecuta tus componentes con la aplicación de Nuxt, pero sin el servidor Nitro que normalmente sirve los payloads de traducción. Para que `$t` funcione en las stories, escribe en una carpeta estática los payloads que Storybook solicitaría antes de que se inicie. Hay un proyecto completo en [s00d/nuxtjs-storybook-i18n-micro](https://github.com/s00d/nuxtjs-storybook-i18n-micro).

## Configuración de Nuxt {#nuxt-config}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro', '@nuxtjs/storybook'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', displayName: 'English' },
      { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
  },
})
```

## Escribir los payloads {#write-the-payloads}

El navegador carga `/_locales/<page>/<locale>/data.json`. Las stories no tienen una ruta de página, así que cargan el payload `index`. Genera uno por locale que contenga las claves de todas las páginas más las claves raíz:

```ts
// .storybook/main.ts
import fs from 'node:fs'
import path from 'node:path'
import type { StorybookConfig } from '@storybook-vue/nuxt'
import { deepMergeTranslationsRecursive } from '@i18n-micro/utils/deep-merge'

type Tree = Record<string, unknown>

const localesDir = path.join(__dirname, '../locales')
const outDir = path.join(__dirname, '../storybook_locales/_locales/index')

const readJson = (file: string): Tree => JSON.parse(fs.readFileSync(file, 'utf-8'))

/** Every `<locale>.json` below `dir`, deep-merged. */
function collect(dir: string, locale: string): Tree {
  if (!fs.existsSync(dir)) return {}
  return fs.readdirSync(dir, { withFileTypes: true }).reduce<Tree>((acc, entry) => {
    const full = path.join(dir, entry.name)
    if (entry.isDirectory()) return deepMergeTranslationsRecursive(acc, collect(full, locale))
    return entry.name === `${locale}.json` ? deepMergeTranslationsRecursive(acc, readJson(full)) : acc
  }, {})
}

for (const file of fs.readdirSync(localesDir).filter((f) => f.endsWith('.json'))) {
  const locale = path.basename(file, '.json')
  // root keys first, page keys win (as in the module's build)
  const merged = deepMergeTranslationsRecursive(readJson(path.join(localesDir, file)), collect(path.join(localesDir, 'pages'), locale))
  fs.mkdirSync(path.join(outDir, locale), { recursive: true })
  fs.writeFileSync(path.join(outDir, locale, 'data.json'), JSON.stringify(merged))
}

const config: StorybookConfig = {
  stories: ['../components/**/*.stories.@(ts|tsx|mdx)'],
  staticDirs: ['../storybook_locales'], // serves /_locales/index/<locale>/data.json
  framework: { name: '@storybook-vue/nuxt', options: {} },
}

export default config
```

`deepMergeTranslationsRecursive` proviene de `@i18n-micro/utils` (añádelo a tus dependencias de desarrollo); combina claves anidadas a cualquier profundidad, igual que la propia compilación del módulo. Añade `storybook_locales/` a `.gitignore`.
