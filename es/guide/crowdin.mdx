---
title: "Crowdin"
description: "Sincroniza locales/ con un proyecto de Crowdin usando la CLI de Crowdin y un crowdin.yml que coincida con la estructura de archivos del módulo."
---

[Crowdin](https://crowdin.com/) es una plataforma de traducción: subes los archivos del locale por defecto, los traductores trabajan en Crowdin y tú descargas los demás locales. El módulo lee archivos JSON simples, así que la CLI de Crowdin solo necesita un `crowdin.yml` que mapee `locales/` y `locales/pages/` correctamente. No cambia ningún ajuste del módulo.

## Configurar crowdin.yml {#configure-crowdin-yml}

```yml
# crowdin.yml
project_id_env: CROWDIN_PROJECT_ID
api_token_env: CROWDIN_PERSONAL_TOKEN
base_path: ./locales
preserve_hierarchy: true

files:
  - source: /en.json
    translation: /%two_letters_code%.json
  - source: /pages/**/en.json
    translation: /pages/**/%two_letters_code%.json
```

- `en` es tu locale por defecto; sus archivos son las fuentes.
- `project_id_env` / `api_token_env` leen el ID y el token de variables de entorno, para que no se haga commit de ningún secreto.
- `preserve_hierarchy: true` mantiene las carpetas `pages/<page>/` tal como están.
- El nombre del archivo traducido debe ser igual al `code` del locale en `nuxt.config.ts`. `%two_letters_code%` sirve para códigos como `de`; para códigos como `pt-BR` usa `%locale%`, o mapea los códigos de Crowdin a los tuyos con `languages_mapping`.

## Subir y descargar {#upload-and-download}

```bash
npm install -g @crowdin/cli

export CROWDIN_PROJECT_ID=123456
export CROWDIN_PERSONAL_TOKEN=...   # from Crowdin account settings

crowdin upload sources   # push locales/en.json and locales/pages/**/en.json
crowdin download         # write locales/de.json, locales/pages/**/de.json, ...
```

Ejecuta ambos en CI para mantener los archivos al día. Los archivos descargados llegan a tu repositorio como si se hubieran editado a mano; la siguiente compilación o recarga en desarrollo los recoge.

## Antes de subir {#before-uploading}

Limpia primero las fuentes para que los traductores no trabajen en claves muertas: [`i18n-micro clean`](/es/api/cli#clean) elimina las claves no usadas, [`i18n-micro check`](/es/api/cli#check) informa de los huecos tras una descarga. La CLI no tiene integración propia con Crowdin: esta página describe la forma soportada.
