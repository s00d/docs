Esta página lleva una aplicación Nuxt de no tener i18n a una página traducida con un selector de idioma. La necesitas una vez, al comienzo de un proyecto. Al final tendrás URL localizadas (`/about`, `/de/about`), un archivo JSON por locale y página, y `$t` en tus plantillas.

## Instalación {#install}

El módulo requiere Nuxt 3.18 o posterior (Nuxt 4 también funciona) y Node 20 o posterior.

<CodeGroup>

```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>

## Configurar los locales {#configure-the-locales}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', displayName: 'English' },
      { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
      { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
    ],
    defaultLocale: 'en',
  },
})
```

Esa es toda la configuración que necesita una primera aplicación. Los valores por defecto te ofrecen:

- `strategy: 'prefix_except_default'`: el locale por defecto no tiene prefijo (`/about`), los demás sí (`/de/about`). Consulta [Estrategias de enrutamiento](/es/guide/strategy).
- `translationDir: 'locales'`: los archivos de traducción están en `locales/` en la raíz del proyecto, también con el layout `app/` de Nuxt 4.
- `meta: true`: etiquetas `hreflang`, canonical y `og:locale`, además de `lang` y `dir` en `<html>`. Consulta [SEO](/es/guide/seo).
- Un visitante que abre `/` es enviado al idioma que pide su navegador (`Accept-Language`). Consulta [Detección de locale](/es/guide/locale-detection).

`iso` es la etiqueta de idioma que se usa en las etiquetas SEO; `code` es lo que aparece en la URL. Todas las opciones se enumeran en [Opciones del módulo](/es/api/module-options).

## Añadir archivos de traducción {#add-translation-files}

Inicia el servidor de desarrollo con `nuxt dev`. Cuando Nuxt resuelve las páginas, el módulo crea un archivo `{}` vacío para cada locale y página que no lo tenga (desactívalo con [`disableWatcher`](/es/api/module-options#disablewatcher)):

```text
locales/
├── en.json            # root: keys every page can use
├── de.json
├── fr.json
└── pages/
    ├── index/         # pages/index.vue
    │   ├── en.json
    │   ├── de.json
    │   └── fr.json
    └── about/         # pages/about.vue
        ├── en.json
        ├── de.json
        └── fr.json
```

Rellena el archivo raíz y un archivo de página:

```json
// locales/en.json
{ "nav": { "home": "Home", "about": "About" } }
```

```json
// locales/pages/index/en.json
{ "welcome": "Welcome, {name}!", "items": "no items | one item | {count} items" }
```

Una página ve las claves raíz y sus propias claves; su propio archivo prevalece en caso de conflicto. Los nombres de carpeta siguen el nombre de la ruta (`pages/articles/[id].vue` es `locales/pages/articles-id/`). [Archivos de traducción](/es/guide/translations) cubre la estructura, los fallbacks y la carga.

## Usar `$t` en una página {#use-$t-on-a-page}

```vue
<!-- pages/index.vue -->
<script setup lang="ts">
const { t, tc, getLocale } = useI18n()

const title = t('nav.home') // 'Home'
</script>

<template>
  <h1>{{ $t('welcome', { name: 'Ada' }) }}</h1>
  <!-- Welcome, Ada! -->
  <p>{{ $tc('items', 3) }}</p>
  <!-- 3 items -->
  <p>{{ getLocale() }}</p>
  <!-- en -->
</template>
```

- En las plantillas, todos los helpers están disponibles con `$` (`$t`, `$tc`, `$localePath`, …).
- En `<script setup>`, `useI18n()` devuelve los mismos helpers, con y sin el `$` (`t` y `$t` son la misma función). Se importa automáticamente.
- Los marcadores `{name}` se rellenan a partir del objeto de parámetros. Las formas de plural se separan con `|`; el recuento elige la forma (0, 1 y luego la última para todo lo superior).

Todos los helpers se enumeran en [Métodos](/es/api/methods).

## Enlazar entre páginas y cambiar de locale {#link-between-pages-and-switch-locale}

```vue
<!-- components/AppHeader.vue -->
<template>
  <nav>
    <i18n-link :to="{ name: 'index' }">{{ $t('nav.home') }}</i18n-link>
    <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
    <i18n-switcher />
  </nav>
</template>
```

- [`<i18n-link>`](/es/components/i18n-link) es un `NuxtLink` que apunta a la página en el locale actual: en `/de`, el enlace a about va a `/de/about`.
- [`<i18n-switcher>`](/es/components/i18n-switcher) es un desplegable con los locales habilitados; mantiene al visitante en la misma página.
- Para tus propios botones, llama a `$switchLocale('de')`, que navega a la página actual en alemán y recuerda la elección. Para un `NuxtLink` normal, usa `$localePath({ name: 'about' })` o `$switchLocalePath('de')`.

## Comprobarlo {#check-it}

Ejecuta `nuxt dev` y abre:

| URL | Muestra |
| --- | --- |
| `/` | Inicio en inglés (o una redirección a `/de` cuando tu navegador prefiere alemán) |
| `/de` | Inicio en alemán |
| `/de/about` | Página about en alemán |
| `/en/about` | 404: el locale por defecto no tiene prefijo con `prefix_except_default` |

Los cambios en los archivos JSON se aplican en la página abierta sin recargar.
