---
title: "Excluir rutas"
description: "Mantén páginas y archivos fuera del enrutamiento por locale con excludePatterns y consulta qué rutas ya están excluidas."
---

Algunas rutas nunca deben recibir un prefijo de locale ni una redirección de locale: un área de administración, un health check, un feed generado. `excludePatterns` las marca, y una lista integrada ya cubre los elementos internos de Nuxt y los archivos estáticos habituales. Una página excluida conserva exactamente la ruta que escribiste y sigue renderizándose con `$t`.

## Excluir una ruta {#exclude-a-path}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    excludePatterns: [
      '/admin', // /admin and everything below it
      '/preview-*', // glob over the whole path
    ],
  },
})
```

Con esta configuración, `pages/admin/index.vue` responde solo en `/admin`; no existe `/de/admin`, y `/admin` nunca se redirige a `/de/admin`.

## Sintaxis de los patrones {#pattern-syntax}

Los patrones se comparan con la ruta sin `app.baseURL`:

| Patrón | Coincide con | No coincide con |
| --- | --- | --- |
| `'/admin'` | `/admin`, `/admin/users` | `/administrator`, `/de/admin` |
| `'/preview-*'` | `/preview-1`, `/preview-a/b` | `/de/preview-1` |
| `'/file-?'` | `/file-a` | `/file-ab` |
| `/^\/v\d+\//` | `/v2/docs` | `/docs` |

Una cadena sin `*` ni `?` coincide con la ruta y con los segmentos completos que hay debajo. Con `*` (cualquier secuencia de caracteres, barras incluidas) o `?` (un carácter) debe coincidir con la ruta completa. Empieza siempre las cadenas con `/`.

## Qué está excluido ya {#what-is-excluded-already}

Estas rutas nunca reciben rutas de locale ni redirecciones, sin ninguna configuración:

- `/api` y `/_nuxt`, y todo lo que hay debajo;
- la ruta de traducciones, `/_locales` por defecto ([`apiBaseUrl`](/es/api/module-options#apibaseurl));
- cualquier ruta con un segmento que empiece por `__` (`/__nuxt_content`, `/en/__og-image__`);
- `/sitemap*.xml`, `/robots.txt`, `/favicon.ico`, `/apple-touch-icon*.png`, `/manifest.json`, `/sw.js`, `/workbox-*.js`;
- cualquier ruta cuyo último segmento termine en una extensión de archivo estático: `xml txt ico json js css png jpg jpeg gif svg webp avif pdf wasm map mp4 webm mp3 zip gz woff woff2 ttf eot`. Los slugs de página con puntos como `/user/john.doe` y las rutas `.html` siguen siendo páginas.

## Qué hace una exclusión {#what-an-exclusion-does}

- **Rutas:** no se generan variantes localizadas; la página se mantiene tal como está escrita.
- **Redirecciones y 404:** el plugin de redirección del servidor y el middleware de redirección del cliente omiten la ruta.
- **Prerenderizado:** las rutas coincidentes se eliminan de la lista de rutas a prerenderizar.

No impide que el middleware de servidor de i18n detecte un locale para la petición, ni que la página use traducciones. Para mantener una página localizada pero sin etiquetas SEO, usa `disableMeta` ([Configuración de página](/es/guide/per-component-translations#turn-off-seo-tags)). Para mantener una página sin localizar desde `nuxt.config.ts` por ruta, `globalLocaleRoutes: { '/admin': false }` ([Rutas localizadas](/es/guide/custom-locale-routes#in-nuxt-config)) hace lo mismo para el enrutamiento.
