---
title: "Configuración de página"
description: "Restringe una página a algunos locales, dale rutas personalizadas, traducciones en línea o desactiva sus etiquetas SEO con $defineI18nRoute."
---

`$defineI18nRoute` establece las opciones de i18n de una página desde la propia página. Úsalo cuando una página solo existe en algunos locales, necesita su propia ruta localizada, lleva algunas traducciones propias o no debe recibir etiquetas hreflang/canonical. El módulo lee la llamada en tiempo de compilación y la incorpora a las rutas generadas.

## Restringir una página a algunos locales {#restrict-a-page-to-some-locales}

```vue
<!-- pages/product/index.vue -->
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'de'],
})
</script>
```

Con la estrategia por defecto `prefix_except_default` solo se generan `/product` y `/de/product`; la página no tiene ruta en ningún otro locale. Lo mismo puede configurarse desde `nuxt.config.ts` con [`routeLocales`](/es/api/module-options#routelocales).

`$defineI18nRoute` es una inyección de la app de Nuxt, no una macro del compilador: obtenla siempre de `useNuxtApp()` y llámala con el `$`. El paso de compilación solo reconoce `$defineI18nRoute(`.

## Añadir traducciones en línea {#add-inline-translations}

Pasa un objeto en lugar de un array. Sus claves son los locales permitidos y sus valores se fusionan en el diccionario de la página para el locale activo.

```vue
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: {
    en: { greeting: 'Hello' },
    de: { greeting: 'Hallo' },
    fr: {}, // allowed, no inline keys
  },
})
</script>

<template>
  <h1>{{ $t('greeting') }}</h1>
</template>
```

Las traducciones en línea se incluyen dentro del componente de página para todos los locales. Prefiere los [archivos de traducción de página](/es/guide/translations) para cualquier cosa de más de unas pocas claves; reserva las claves en línea para páginas y componentes autocontenidos.

## Definir rutas localizadas {#set-localized-paths}

```ts
$defineI18nRoute({
  locales: ['en', 'de'],
  localeRoutes: {
    en: '/welcome',
    de: '/willkommen',
  },
})
```

Con `prefix_except_default` y `defaultLocale: 'en'` esto produce `/welcome` y `/de/willkommen`. Un `path` dentro de un objeto de locale en línea hace lo mismo: `locales: { de: { path: '/willkommen' } }`. Los parámetros dinámicos, las rutas anidadas y la alternativa a nivel de configuración se tratan en [Rutas localizadas](/es/guide/custom-locale-routes).

## Desactivar las etiquetas SEO {#turn-off-seo-tags}

```ts
$defineI18nRoute({
  disableMeta: true, // no hreflang, canonical or og:locale tags on this page
})

$defineI18nRoute({
  disableMeta: ['de'], // only the de version has no tags
})
```

La alternativa a nivel de configuración es [`routeDisableMeta`](/es/api/module-options#routedisablemeta). Qué son estas etiquetas se explica en la página de [SEO](/es/guide/seo).

## Qué puede leer la compilación {#what-the-build-can-read}

El paso de compilación encuentra la llamada en cada archivo de página y evalúa su argumento sin ejecutar tu app. Funciona cuando la configuración es:

- un objeto literal (cadenas, arrays, objetos anidados, template literals, ternarios sobre `process.env.NODE_ENV`);
- construida a partir de constantes declaradas en el mismo `<script setup>` (`const locales = ['en', 'de']`, spreads incluidos);
- un array de objetos con un campo `code` (`[{ code: 'en' }, { code: 'de' }]`).

No puede leer valores importados de otro módulo ni nada que necesite tu app en runtime (composables, `await`, datos obtenidos por fetch). En ese caso la compilación registra `Ignored the $defineI18nRoute() config in <file>` y la página conserva los locales y rutas por defecto.

En runtime, la llamada solo fusiona las traducciones en línea del locale actual y las vuelve a fusionar cuando cambia el locale. `locales`, `localeRoutes` y `disableMeta` solo tienen efecto a través de la compilación, así que cambiarlos requiere recompilar (el servidor de desarrollo recompila al guardar).
