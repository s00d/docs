---
title: "Sobrescrituras en tiempo de ejecución"
description: "Cambia el idioma por defecto, el idioma de respaldo o los idiomas desactivados por instancia de un mismo build, con variables de entorno o runtimeConfig."
---

Las sobrescrituras en tiempo de ejecución permiten que un mismo artefacto de build se ejecute con distintos ajustes de idioma por entorno o por cliente, sin volver a compilar. Puedes cambiar el idioma por defecto, el idioma de respaldo y qué idiomas están desactivados. El enrutamiento, las redirecciones, el renderizado y los helpers del servidor usan los valores sobrescritos, y también el navegador en una página renderizada en el servidor.

## Definir sobrescrituras con variables de entorno {#set-overrides-with-environment-variables}

```bash
NUXT_I18N_DEFAULT_LOCALE=de \
NUXT_I18N_FALLBACK_LOCALE=en \
NUXT_I18N_DISABLED_LOCALES=fr,it \
node .output/server/index.mjs
```

| Variable | Alias |
| --- | --- |
| `NUXT_I18N_DEFAULT_LOCALE` | `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE` |
| `NUXT_I18N_FALLBACK_LOCALE` | `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE` |
| `NUXT_I18N_DISABLED_LOCALES` (separados por comas) | `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES` |

El servidor las lee una sola vez al arrancar; reinícialo para aplicar un cambio. En una página renderizada en el servidor, el navegador recibe del servidor los valores resueltos. Con `ssr: false` no hay renderizado en el servidor y el navegador no tiene entorno: allí solo se aplica `runtimeConfig.public.i18nRuntime`, y el navegador registra las advertencias que se indican más abajo.

## Definir sobrescrituras en runtimeConfig {#set-overrides-in-runtimeconfig}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

Un valor definido en `runtimeConfig.public.i18nRuntime` tiene prioridad sobre la variable `NUXT_I18N_*` del mismo campo.

No debe confundirse con la variable `DEFAULT_LOCALE` de tiempo de build, que sustituye `defaultLocale` durante la compilación y no necesita soporte en tiempo de ejecución.

## Qué se puede cambiar y qué no {#what-can-and-cannot-change}

| Ajuste | En tiempo de ejecución |
| --- | --- |
| `defaultLocale` | Sí con `prefix` y `no_prefix`. Con `prefix_except_default` y `prefix_and_default` queda fijado en el build (sus páginas son las rutas sin prefijo); una sobrescritura se ignora con una advertencia. |
| `fallbackLocale` | Sí. |
| `disabledLocales` | Se suma a los idiomas desactivados en el build; nunca vuelve a activar uno. El idioma por defecto del build no se puede desactivar con `prefix_except_default` / `prefix_and_default`. |
| `strategy` | No. Una estrategia en tiempo de ejecución se ignora con una advertencia; genera un artefacto por estrategia. |

Los valores no válidos nunca rompen la app. Cada caso registra una advertencia por proceso del servidor:

- desactivar todos los idiomas se ignora;
- un `defaultLocale` que no está activado recurre al primer idioma activado;
- un `fallbackLocale` que no está activado conserva el valor del build si este está activado; en caso contrario, no hay respaldo.

## Leer la configuración efectiva {#read-the-effective-config}

```vue
<script setup lang="ts">
const { $getI18nConfig } = useNuxtApp()
const config = $getI18nConfig() // build config with overrides applied
</script>
```

Trátala como de solo lectura: en el servidor la comparten todas las peticiones y está congelada en desarrollo; la copia del navegador no está congelada. Importar la configuración desde `#build/i18n.strategy.mjs` proporciona los valores del build sin sobrescrituras.

## Idiomas desactivados y archivos estáticos {#disabled-locales-and-static-files}

Un idioma desactivado en tiempo de ejecución responde 404 en sus rutas y en su ruta de payload, pero sus archivos de payload siguen en `.output/public/_locales/` y un servidor de archivos estáticos los devuelve. Cuando esos archivos no deben ser accesibles, desactiva el idioma en tiempo de build con `disabled: true`.
