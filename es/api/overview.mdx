# Referencia de la API

## API de runtime

- [Métodos](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, cambio de idioma, helpers de enrutamiento
- [Eventos](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Traducciones y caché](/api/cache) — `TranslationStorage`, carga de payloads, `$clearCache`

## Middleware de servidor

Los handlers de servidor usan middleware dedicado (no los helpers `$t` del cliente):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — traducir en rutas de API y handlers de servidor
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — leer el idioma detectado y los metadatos

Consulta la [Guía completa de traducciones del lado del servidor](/guides/server-side-translations) para conocer la configuración, la prioridad de detección de idioma y ejemplos.
