# Referencia de la API

## API de runtime

- [Métodos](/api/methods): `$t`, `$ts`, `$_t`, `$_ts`, cambio de locale, helpers de enrutamiento.
- [Eventos](/api/events): `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`.
- [Traducciones y caché](/api/cache): `TranslationStorage`, carga del payload, `$clearCache`.

## Middleware de servidor

Los handlers de servidor usan middleware dedicado (no los helpers de `$t` del cliente):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers): traduce en rutas de API y handlers de servidor.
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers): lee el locale detectado y sus metadatos.

Consulta la [guía completa de traducciones en el servidor](/guides/server-side-translations) para la configuración, la prioridad de detección de locales y ejemplos.
