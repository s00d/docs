Esta sección enumera cada opción, helper, hook, composable y componente del módulo de Nuxt, además de la API exportada de cada paquete `@i18n-micro/*`. Úsala para consultar una firma o un valor predeterminado; la [Guía](/es/guide/getting-started) explica cómo usarlos. La mayoría de las tablas de aquí se generan a partir del código fuente, por lo que coinciden con el código.

## Módulo de Nuxt {#nuxt-module}

| Página | Contenido |
| --- | --- |
| [Opciones del módulo](/es/api/module-options) | Cada clave `i18n` de `nuxt.config`, con su tipo y valor predeterminado |
| [Helpers](/es/api/methods) | `$t`, `$tc`, `$tn`, `$td`, `$localePath`, `$switchLocale`, `$defineI18nRoute` y el resto |
| [Hooks](/es/api/events) | El hook de tiempo de ejecución `i18n:register` |

## Composables {#composables}

| Composable | Úsalo para |
| --- | --- |
| [`useI18n`](/es/composables/useI18n) | Los helpers en `<script setup>` |
| [`useI18nLocale`](/es/composables/useI18nLocale) | El estado del locale y la cookie en un plugin de detección personalizado |
| [`useI18nHead`](/es/composables/useI18nHead) | Sobrescrituras por página de las etiquetas SEO generadas |
| [`useLocaleHead`](/es/composables/useLocaleHead) | Las etiquetas SEO como objeto, para tu propio `useHead` |

## Componentes {#components}

| Componente | Renderiza |
| --- | --- |
| [`<i18n-t>`](/es/components/i18n-t) | Una traducción, con plurales, formato e interpolación mediante slots |
| [`<i18n-link>`](/es/components/i18n-link) | Un `NuxtLink` a la ruta localizada |
| [`<i18n-switcher>`](/es/components/i18n-switcher) | Un desplegable de locales |
| [`<i18n-group>`](/es/components/i18n-group) | Un bloque con un prefijo de clave compartido |

## Servidor {#server}

Los handlers de Nitro usan `useTranslationServerMiddleware` y `useLocaleServerMiddleware`, no los helpers del cliente. Consulta [Rutas del servidor](/es/guide/server-side-translations).

## Paquetes {#packages}

[APIs de los paquetes](/es/api/packages/overview) enumera las exportaciones de cada paquete `@i18n-micro/*`, con una página generada para cada uno.
