---

El módulo inyecta sus helpers de tiempo de ejecución en la aplicación Nuxt: `$t`, `$tc`, `$localePath`, `$switchLocale` y el resto. Usa esta página para consultar la firma y el comportamiento de un helper. Las firmas y descripciones provienen de las interfaces `PluginsInjections` y `NuxtAppOnlyInjections` en `src/runtime/plugins/01.plugin.ts`.

## Acceso {#access}

| Dónde | Cómo |
| --- | --- |
| Plantilla | `{{ $t('title') }}` — todos los helpers, con el `$` |
| `<script setup>` | `const { t, localePath } = useI18n()` — todos los helpers de `PluginsInjections`, con y sin el `$` |
| Plugin, middleware, `<script setup>` | `const { $t, $defineI18nRoute } = useNuxtApp()` — todo, solo con `$` |

`$defineI18nRoute` solo está tipado en `useNuxtApp()`. Consulta [`useI18n`](/es/composables/useI18n).

```vue
<script setup lang="ts">
const { t, localePath } = useI18n()
</script>

<template>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
</template>
```

## Locale {#locale}

### `$getLocale` {#$getlocale}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric) => string
```

Código del locale activo. Pasa una ruta para leer el locale al que pertenece esa ruta.

```ts
$getLocale() // 'de' on /de/about
```

### `$getLocaleName` {#$getlocalename}

```ts
() => string | null
```

El `displayName` del locale activo según la configuración, o `null` si no tiene.

### `$getLocales` {#$getlocales}

```ts
() => Locale[]
```

Todos los locales configurados, con sus metadatos.

Las propiedades personalizadas de un objeto locale se devuelven tal como se escribieron; tipéalas con [aumento de módulo](/es/api/module-options#locales) de `Locale`.

### `$defaultLocale` {#$defaultlocale}

```ts
() => string | undefined
```

Código del locale por defecto configurado.

### `$getI18nConfig` {#$geti18nconfig}

```ts
() => ResolvedI18nConfig
```

La configuración resuelta del módulo, tal como la ve el runtime.

El valor incluye las [sobrescrituras en tiempo de ejecución](/es/guide/runtime-overrides) (`defaultLocale`, `fallbackLocale`, locales deshabilitados).

```ts
const { strategy, localeCookie } = useNuxtApp().$getI18nConfig()
```

## Traducción {#translation}

### `$t` {#$t}

```ts
TranslationFn<CleanTranslation>
```

Traduce una clave, interpolando `params` en ella. Devuelve `defaultValue` cuando falta la
clave, o la propia clave cuando no se indica un valor por defecto.

```ts
// { "welcome": "Welcome, {name}!" }
$t('welcome', { name: 'Ada' }) // 'Welcome, Ada!'
$t('missing.key', {}, 'Fallback') // 'Fallback'
```

Una clave que apunta a un objeto anidado devuelve ese objeto, no una cadena. En una plantilla se renderiza como `[object Object]`; usa una clave hoja.

### `$ts` {#$ts}

```ts
TranslationFn<string>
```

Como `$t`, pero siempre devuelve una cadena: el valor pasa por `toString()`, así que un objeto
anidado se convierte en `'[object Object]'`. Haz que la clave apunte a una hoja.

### `$_t` {#$_t}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<CleanTranslation>
```

Vincula `$t` a una ruta concreta, para traducir fuera de la página actual — por ejemplo, un
layout que renderiza un enlace a otra ruta.

```ts
const route = useRoute()
const t = useNuxtApp().$_t(route)
t('page.title')
```

### `$_ts` {#$_ts}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<string>
```

Vincula `$ts` a una ruta concreta. Consulta `$_t`.

### `$tc` {#$tc}

```ts
(key: TranslationKey, params: number | Params, defaultValue?: string) => string
```

Traduce con pluralización. `params` puede ser el propio recuento, o un objeto que contenga
`count`.

Las formas se separan con `|`. Con la regla integrada, un recuento entero no negativo `n` elige la forma `n`, limitada a la última forma; un recuento negativo, fraccionario o `NaN` toma la última forma. `{count}` y los demás parámetros se interpolan en la forma elegida.

Para idiomas cuyos plurales no siguen el recuento, empieza la plantilla con `=0 `. La primera forma es entonces para 0, y las demás siguen la categoría de [`Intl.PluralRules`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/PluralRules), en el orden `zero, one, two, few, many, other`:

```json
{
  "apples": "=0 no apples | one apple | {count} apples",
  "files": "=0 no files | {count} one | {count} few | {count} many"
}
```

```ts
$tc('apples', 0) // 'no apples'
$tc('apples', 1) // 'one apple'
$tc('apples', 7) // '7 apples'

// In `uk` (categories `one, few, many, other`) the forms after the zero form follow those categories:
$tc('files', 21) // '21 one'
$tc('files', 22) // '22 few'
$tc('files', 25) // '25 many'
$tc('files', 2.5) // '2.5 many': no form for `other`, so the last one
```

- `=0 ` solo cuenta al principio del valor, con el espacio. `$t` lo muestra como texto: pertenece a los plurales.
- Una categoría sin forma propia toma la última forma. Un recuento negativo o fraccionario también toma la última forma.
- Funciona en cualquier locale: `=0 none | one | {count} many` en inglés.
- La categoría proviene del `iso` del locale, si no, de su código. Un código que `Intl` no conoce recurre a la regla de índice, con el marcador igualmente eliminado, de modo que el resultado nunca depende de la máquina.
- `<i18n-t :plural>` sigue la misma regla. Un [`plural`](/es/api/module-options#plural) personalizado o `customPluralRule` recibe el valor sin procesar, marcador incluido, y decide por sí mismo; si `plural` devuelve `null`, la llamada vuelve a la regla integrada, que respeta el marcador.

Sin el marcador, una plantilla se queda en la regla de índice, con una excepción que solo admite una lectura: una forma cero sin marcador de posición, luego una forma por categoría, con `{count}` en cada forma que comparten varios recuentos (`no files | {count} one | {count} few | {count} many` en `uk`).

Para reglas propias, establece [`plural`](/es/api/module-options#plural).

```ts
// { "apples": "no apples | one apple | {count} apples" }
$tc('apples', 0) // 'no apples'
$tc('apples', 10) // '10 apples'
$tc('cart', { count: 2, name: 'Ada' }) // count and params in one object
```

El tercer argumento es `defaultValue`, no params.

### `$has` {#$has}

```ts
(key: string) => boolean
```

Indica si una clave se resuelve en el locale activo. Úsalo para bifurcar en textos opcionales en lugar de
renderizar una clave sin traducir. Como `$t`, también ve las claves de la página que se abandona durante una transición
de página dentro del mismo locale.

```ts
if ($has('promo.banner')) show.value = true
```

## Formato {#formatting}

### `$tn` {#$tn}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Formatea un número con `Intl.NumberFormat` en el locale activo. Una clave selecciona un formato con nombre
de la configuración.

Los formatos con nombre provienen de [`numberFormats`](/es/api/module-options#numberformats).

```ts
$tn(1234.5, { style: 'currency', currency: 'EUR' }) // '1.234,50 €' in de
$tn(1000, 'currency') // named format
$tn(1000, 'currency', 'de') // named format in another locale
```

### `$td` {#$td}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Formatea una fecha con `Intl.DateTimeFormat` en el locale activo. Una clave selecciona un formato con nombre
de la configuración.

Los formatos con nombre provienen de [`datetimeFormats`](/es/api/module-options#datetimeformats).

```ts
$td(new Date(), { dateStyle: 'long' })
$td(post.createdAt, 'short')
```

### `$tdr` {#$tdr}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

Formatea una fecha como tiempo relativo ("hace 3 días") con `Intl.RelativeTimeFormat`.

```ts
$tdr(Date.now() - 5 * 60_000) // '5 minutes ago' in en
```

## Cambio de locale y enlaces {#switching-and-links}

### `$switchLocale` {#$switchlocale}

```ts
(locale: string) => Promise<boolean>
```

Navega a la página actual en otro locale. Con `no_prefix` y en modo hash, carga las
traducciones del locale antes de navegar; con `no_prefix` la ruta se reemplaza en el sitio (sin
nueva entrada en el historial). Un locale desconocido se ignora.
La llamada es asíncrona: usa `await` para ejecutar código después de la navegación. Se resuelve como `true` cuando el
diccionario del locale está activo, y `false` cuando no lo está: el fragmento no se pudo cargar (el diccionario
actual se mantiene; vuelve a llamarla para reintentar) o ganó un cambio más reciente.

```ts
await $switchLocale('de')
```

### `$switchLocalePath` {#$switchlocalepath}

```ts
(locale: string) => string
```

La ruta de la página actual en otro locale, sin navegar.

```vue
<NuxtLink :to="$switchLocalePath('de')">Deutsch</NuxtLink>
```

### `$switchLocaleRoute` {#$switchlocaleroute}

```ts
(locale: string) => RouteLocationRaw
```

El objeto de ruta de la página actual en otro locale, sin navegar, o una cadena URL
para un locale con su propio `baseUrl`. Con `trailingSlash`, el objeto tiene `path` y `fullPath`
según la regla, con `query` y `hash` tal cual, y `router.push` o un enlace los conservan.

### `$switchRoute` {#$switchroute}

```ts
(route: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, toLocale?: string) => Promise<void>
```

Navega a otra ruta, manteniendo el locale activo o cambiando a `toLocale`. Asíncrona como
`$switchLocale`.

```ts
$switchRoute('/about') // active locale
$switchRoute({ name: 'about' }, 'de') // switch to de
```

### `$localePath` {#$localepath}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => string
```

Resuelve una ruta en el locale indicado, o en el activo. Una cadena con esquema `http(s):`, `mailto:`
o `tel:` se devuelve tal cual: no pases entradas del usuario como destino de un enlace sin comprobarlas.

Una ruta en forma de cadena se interpreta como la página que muestra, de modo que también se aplica la ruta personalizada de un locale.

```ts
$localePath('/about') // '/about' in en, '/de/ueber-uns' in de with localeRoutes
$localePath({ name: 'about' }, 'fr') // '/fr/about'
```

### `$localeRoute` {#$localeroute}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => RouteLocationResolved
```

Resuelve un objeto de ruta en el locale indicado, o en el activo. Es un objeto plano, seguro para guardar en el estado. Cuando un parámetro necesita
escaparse, tiene `path`, `fullPath`, `query` y `hash` pero no `name` ni `params`: la ruta es lo que proporciona al router
la URL codificada. Para un locale en otro dominio, `path` y `fullPath` son absolutos, algo que el router no admite:
un enlace así pasa por `<i18n-link>`, o por `$localePath`.

### `$getRouteName` {#$getroutename}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric, locale?: string) => string
```

Nombre de la ruta sin el prefijo del locale — el nombre por el que se indexan las traducciones.

```ts
$getRouteName() // 'about' on /de/about
```

## Configuración de página {#page-config}

### `$defineI18nRoute` {#$definei18nroute}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Registra la configuración de locales y las traducciones por página desde dentro de un componente.
Se fusiona en el locale activo y se vuelve a aplicar cuando cambia el locale.

Llámalo en el `<script setup>` de una página, siempre desestructurado de `useNuxtApp()`. La compilación lee `locales`, `localeRoutes` y `disableMeta` de la llamada; en tiempo de ejecución solo importa `locales` (las traducciones en línea se fusionan para el locale activo). Reglas completas: [Configuración de página](/es/guide/per-component-translations).

```vue
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'de'],
  localeRoutes: { en: '/about', de: '/ueber-uns' },
})
</script>
```

### `$setI18nRouteParams` {#$seti18nrouteparams}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Establece parámetros por locale para la ruta actual, de modo que un segmento dinámico pueda variar según el idioma.
Llámalo durante el SSR, antes de que se renderice el head.

Los parámetros se borran cuando se confirma una navegación a otra ruta, incluido `/news/1` a `/news/4`, que mantiene el nombre de la ruta. Detalles: [Rutas localizadas](/es/guide/custom-locale-routes).

```ts
$setI18nRouteParams({
  en: { slug: 'my-post' },
  de: { slug: 'mein-beitrag' },
})
```

## Traducciones en tiempo de ejecución {#runtime-translations}

### `$mergeTranslations` {#$mergetranslations}

```ts
(newTranslations: Translations) => void
```

Fusiona traducciones en el locale activo en tiempo de ejecución, sobrescribiendo lo cargado.

Hace una fusión profunda en el fragmento de la página actual del locale activo; las claves que no menciona se conservan.

```ts
$mergeTranslations({ banner: { title: 'Sale' } })
```

### `$setTranslation` {#$settranslation}

```ts
(key: string, value: unknown) => void
```

Reemplaza el valor de `key` en el diccionario activo. Es un reemplazo, no una fusión:
usa `$mergeTranslations` cuando deban conservarse las claves hermanas existentes.

```ts
$setTranslation('banner', { title: 'Sale' }) // drops other keys under banner
$setTranslation('banner.title', 'Sale') // dotted path
```

### `$loadPageTranslations` {#$loadpagetranslations}

```ts
(locale: string, routeName: string, translations: Translations) => Promise<void>
```

Carga traducciones para una página en tiempo de ejecución, para contenido cuyas claves no se conocen en tiempo de compilación.

Se fusionan en el fragmento `(locale, routeName)` en memoria, y la pantalla se actualiza cuando ese fragmento está activo. Aquí no se descarga ningún payload: para una página aún no cargada, las traducciones esperan, y cuando se carga su archivo quedan por encima de él.

```ts
await $loadPageTranslations('en', 'about', { title: 'About us' })
```

### `$resolveTranslations` {#$resolvetranslations}

```ts
() => Translations
```

Todas las traducciones actualmente en memoria para el locale y la ruta activos, como un árbol.
Vista de solo lectura de lo que `$t()` puede resolver en este momento.

Trata el resultado como de solo lectura.

### `$setMissingHandler` {#$setmissinghandler}

```ts
(handler: MissingHandler | null) => void
```

Instala un callback que se invoca para cada clave no resuelta. Pasa `null` para eliminarlo.

El handler se ejecuta en lugar del aviso de desarrollo.

```ts
$setMissingHandler((locale, key, routeName) => {
  console.error(`[i18n] missing ${key} in ${locale} (${routeName})`)
})
```

### `$clearCache` {#$clearcache}

```ts
() => void
```

Descarta todos los fragmentos de traducción en caché y recarga el diccionario de la página actual. La página
sigue mostrando sus traducciones actuales hasta que llegan las nuevas. El HMR de desarrollo la llama en
cada cambio de un archivo de traducción.

```ts
const { clearCache } = useI18n()
clearCache()
```

Una recarga fallida mantiene el diccionario actual.
