# APIs de paquetes

`nuxt-i18n-micro` está construido a partir de un conjunto de paquetes pequeños, la mayoría de los cuales pueden usarse por separado: `@i18n-micro/vue` en una app Vue plana, `@i18n-micro/core` en cualquier lugar.

Cada página siguiente se genera a partir del snapshot de la API que
[`pnpm run api:surface`](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/maintenance-commands.md#api-surface) comprueba contra los fuentes TypeScript, por lo que un export no puede desaparecer sin que cambie esta referencia o CI falle.
