title: "API de los paquetes"
description: "La API exportada de cada paquete @i18n-micro/*, generada a partir de las instantáneas de la API que la CI comprueba contra el código fuente."
---

El módulo de Nuxt se construye a partir de pequeños paquetes `@i18n-micro/*`, y la mayoría funcionan por sí solos: `@i18n-micro/vue` en una aplicación Vue, `@i18n-micro/core` en cualquier lugar. Usa estas páginas para consultar lo que exporta un paquete, por punto de entrada. Cada página se genera a partir de la instantánea que [`pnpm run api:surface`](https://s00d.github.io/nuxt-i18n-micro/contributing/maintenance-commands#api-surface) comprueba contra el código fuente de TypeScript, de modo que una exportación no puede cambiar sin que la CI lo detecte.
