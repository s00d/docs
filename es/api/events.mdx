description: "El hook de runtime i18n:register: añade traducciones desde un plugin de Nuxt al cargar y al navegar."
---

El módulo llama a un único hook de runtime (de la app), `i18n:register`. Úsalo cuando un plugin o un módulo añade traducciones que no están en tus archivos de `locales/`. Tu callback recibe una función `register` que fusiona las traducciones en la página que se está mostrando.

## `i18n:register` {#i18nregister}

```ts
'i18n:register': (
  register: (translations: unknown, locale?: string) => void,
  locale: string,
) => HookResult
```

| Argumento | Descripción |
| --- | --- |
| `register(translations, locale?)` | Fusiona en profundidad `translations` en el chunk de página de la ruta que se está cargando, para `locale` (por defecto: el `locale` del hook). Las claves que ya existen se sobrescriben. |
| `locale` | El locale de la ruta que se está cargando. |

El hook está tipado mediante `RuntimeNuxtHooks`, así que `nuxtApp.hook('i18n:register', …)` no necesita ningún cast.

## Cuándo se dispara {#when-it-fires}

El plugin cargador (`i18n-plugin-loader`) lo llama:

1. una vez al arrancar, cuando todos los plugins se han ejecutado (`app:created`) y antes de que la app se renderice;
2. en su `router.beforeEach`, después de cargar las traducciones de la página de destino, cuando cambia la ruta — en cada navegación con `no_prefix`.

Cada callback y cada llamada a `register` se espera (await) antes de que la app se renderice o la navegación continúe, de modo que la página se renderiza con las claves fusionadas. Con [`hooks: false`](/es/api/module-options#hooks) el hook nunca se llama.

## Ejemplo {#example}

```ts
// plugins/i18n-extra.ts
export default defineNuxtPlugin((nuxtApp) => {
  nuxtApp.hook('i18n:register', async (register, locale) => {
    const extra = await $fetch<Record<string, unknown>>(`/api/cms-strings/${locale}`)
    register(extra, locale)
  })
})
```

Este es un hook de runtime: regístralo con `nuxtApp.hook` en un plugin, no con `nuxt.hook` en `nuxt.config` ni en el `setup` de un módulo. Un módulo añade un plugin así con `addPlugin`.
