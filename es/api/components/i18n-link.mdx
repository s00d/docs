# 🌍 Componente `<i18n-link>`

El componente `<i18n-link>` en `Nuxt I18n Micro` es un componente de enlace versátil que localiza automáticamente las rutas según el idioma actual. Actúa como envoltura del componente `<NuxtLink>`, proporcionando funciones adicionales como el estilo de enlace activo y el soporte para enlaces externos.

## ⚙️ Props

{/* generated:component:i18n-link — do not edit; run `pnpm run docs:generate` */}

| Prop | Tipo | Predeterminado | Descripción |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | Ruta destino. Se localiza automáticamente; una URL externa se pasa sin cambios. |
| `activeStyle` | `Partial<CSSStyleValue>` | — | Estilo en línea aplicado cuando el enlace apunta a la ruta actual. |

**\*** obligatorio.

### Slots

| Slot | Bindings | Descripción |
| --- | --- | --- |
| `default` | — | Contenido del enlace. |

{/* /generated:component:i18n-link */}

`to` acepta lo mismo que `NuxtLink`: una ruta, una ruta con nombre o un objeto de ruta resuelto. Una URL absoluta se detecta y se renderiza como un `<a target="_blank" rel="noopener noreferrer">` en lugar de localizarse.

## 🛠️ Ejemplos de uso

### Uso básico

```vue
<i18n-link to="/about">About Us</i18n-link>
```

Este ejemplo crea un enlace a la página `/about`, localizada al idioma actual.

### Estilo de enlace activo con estilos en línea

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

El enlace tendrá texto en negrita cuando el usuario esté en la página `/about`, permitiéndote dar estilo al enlace activo directamente con estilos en línea.

### Manejo de enlaces externos

El componente detecta automáticamente los enlaces externos y añade los atributos necesarios para la seguridad.

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

Este enlace abrirá `https://example.com` en una nueva pestaña con `rel="noopener noreferrer"` aplicado.

## 🎨 Estilos

El componente ahora usa estilos en línea para el estado activo en lugar de una clase. Puedes personalizar estos estilos usando la prop `activeStyle`.

### Estilos activos por defecto

- **Peso de fuente**: `bold`
- **Color**: Hereda el color por defecto del navegador (si no se especifica `color` en `activeStyle`).

Puedes anularlos proporcionando estilos personalizados mediante la prop `activeStyle`.

### Estilos activos personalizados

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

En este ejemplo, el enlace será negrita y verde cuando esté activo.

## 🚀 Funciones adicionales

### Slot para contenido personalizado

Puedes pasar contenido personalizado dentro del enlace usando slots, haciendo el componente flexible para diferentes casos de uso.

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### Mejoras de accesibilidad

El componente admite `aria-label` y otros atributos de accesibilidad para asegurar una experiencia más accesible.

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
