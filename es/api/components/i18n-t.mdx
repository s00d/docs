# 🌍 Componente `<i18n-t>`

El componente `<i18n-t>` en `Nuxt I18n Micro` es un componente de traducción flexible que admite la inserción dinámica de contenido mediante slots. Te permite interpolar traducciones con componentes personalizados de Vue o contenido HTML, permitiendo escenarios avanzados de localización.

## ⚙️ Props

| Prop | Tipo | Predeterminado | Descripción |
| --- | --- | --- | --- |
| `keypath` **\*** | `string` | — | Clave de traducción a renderizar. |
| `plural` | `number \| string` | — | Conteo que selecciona la forma plural. Establécelo para usar `$tc` en lugar de `$t`. |
| `tag` | `string` | `'span'` | Elemento a renderizar. |
| `params` | `Record<string, string \| number \| boolean>` | `() => (\{\})` | Valores de interpolación que se sustituyen en la traducción. |
| `defaultValue` | `string` | `''` | Se renderiza en lugar del componente cuando `hideIfEmpty` suprime una traducción vacía. |
| `html` | `boolean` | `false` | Renderiza la traducción como HTML en lugar de texto. Solo para contenido que controles. |
| `hideIfEmpty` | `boolean` | `false` | No renderiza nada cuando la traducción se resuelve en una cadena vacía. |
| `customPluralRule` | `PluralFunc` | `null` | Regla de plural solo para este elemento, que anula la configurada. |
| `number` | `number \| string` | — | Formatea el valor con `$tn` y lo pasa a la traducción como `\{number\}`. |
| `date` | `Date \| string \| number` | — | Formatea el valor con `$td` y lo pasa a la traducción como `\{date\}`. |
| `relativeDate` | `Date \| string \| number` | — | Formatea el valor con `$tdr` y lo pasa a la traducción como `\{relativeDate\}`. |

**\*** obligatorio.

{/* /generated:component:i18n-t */}

Solo se aplica una de `plural`, `number`, `date` y `relativeDate` a la vez; cuando se establecen varias, gana la primera en esa lista.

### Ejemplos por prop

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

## 🛠️ Ejemplos de uso

### Uso básico

```vue
<i18n-t keypath="feedback.text" />
```

Esto renderiza la traducción de `feedback.text` dentro de una etiqueta `<span>`.

### Uso de slots para contenido dinámico

El componente `<i18n-t>` admite el uso de slots para insertar dinámicamente componentes de Vue u otro contenido en partes específicas de la traducción.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

En este ejemplo, el placeholder `\{link\}` en la cadena de traducción de `feedback.text` se reemplaza por el componente `<nuxt-link>`, que a su vez contiene otro componente de traducción.

### Pluralización

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

Esto aplica automáticamente las reglas de pluralización según el valor de `itemCount`.

## 🚀 Funciones adicionales

### Slot por defecto

Si no se proporciona un slot específico, la traducción puede personalizarse mediante el slot por defecto, que proporciona la cadena traducida completa:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### Renderizado condicional

No renderiza nada si la cadena de traducción está vacía usando la prop `hideIfEmpty`.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### Regla de pluralización personalizada

Usa una función personalizada para manejar la pluralización.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### Ejemplo avanzado con slots

Usa slots para personalizar cómo se renderiza el contenido de la traducción.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
