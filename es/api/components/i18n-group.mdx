# 🌍 Componente `<i18n-group>`

El componente `<i18n-group>` en Nuxt I18n Micro proporciona una forma cómoda de agrupar traducciones bajo un prefijo común, reduciendo la repetición y mejorando la organización del código.

## ⚙️ Props

{/* generated:component:i18n-group — do not edit; run `pnpm run docs:generate` */}

| Prop | Tipo | Predeterminado | Descripción |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | Prefijo de clave contra el que se resuelve cada búsqueda dentro del slot. |
| `groupClass` | `string` | `''` | Clase adicional en el elemento contenedor. |

**\*** obligatorio.

### Slots

| Slot | Bindings | Descripción |
| --- | --- | --- |
| `default` | `prefix`, `t` | Recibe `prefix` y una función `t` con ámbito en él. |

## 🎯 Slots

El slot por defecto recibe `prefix` y una función `t` con ámbito en él, así que las claves internas se escriben relativas al prefijo:

```vue
<i18n-group prefix="checkout">
  <template #default="{ t }">
    <h2>{{ t('title') }}</h2>
    <p>{{ t('summary', { count: 3 }) }}</p>
  </template>
</i18n-group>
```

## 🛠️ Ejemplo de uso

### Uso básico

```vue
<template>
  <i18n-group prefix="product.details">
    <template #default="{ t }">
      <h1>{{ t('title') }}</h1>
      <p>{{ t('description') }}</p>
      <div class="price">{{ t('price', { value: 99.99 }) }}</div>
    </template>
  </i18n-group>
</template>
```

Archivo de traducción:

```json
{
  "product": {
    "details": {
      "title": "Premium Product",
      "description": "This is a premium product",
      "price": "Price: ${value}"
    }
  }
}
```

### Con clase personalizada

```vue
<template>
  <i18n-group prefix="user.profile" group-class="profile-section">
    <template #default="{ t }">
      <div class="user-info">
        <h2>{{ t('title') }}</h2>
        <p>{{ t('bio') }}</p>
        <div class="stats">
          <span>{{ t('stats.followers') }}</span>
          <span>{{ t('stats.following') }}</span>
        </div>
      </div>
    </template>
  </i18n-group>
</template>
```

Archivo de traducción:

```json
{
  "user": {
    "profile": {
      "title": "User Profile",
      "bio": "User biography goes here",
      "stats": {
        "followers": "Followers: {count}",
        "following": "Following: {count}"
      }
    }
  }
}
```

### Con contenido dinámico

```vue
<template>
  <i18n-group prefix="blog.post">
    <template #default="{ t }">
      <article>
        <h1>{{ t('title') }}</h1>
        <div class="meta">
          {{ t('meta.author', { name: author }) }} |
          {{ t('meta.date', { date: publishDate }) }}
        </div>
        <div v-for="(section, index) in sections" :key="index">
          <h2>{{ t(`sections.${index}.title`) }}</h2>
          <p>{{ t(`sections.${index}.content`) }}</p>
        </div>
      </article>
    </template>
  </i18n-group>
</template>

<script setup>
const author = 'John Doe'
const publishDate = '2024-01-01'
const sections = ['intro', 'main', 'conclusion']
</script>
```

## 🎨 Estilos

El componente envuelve su contenido en un div con la clase `i18n-group` y cualquier clase adicional especificada en la prop `groupClass`:

```css
.i18n-group {
  /* Your base styles */
}

.profile-section {
  /* Additional styles for profile sections */
}
```

## 🚀 Buenas prácticas

1. **Prefijos consistentes**: Usa prefijos consistentes y lógicos que reflejen la estructura de tu aplicación.

```vue
<i18n-group prefix="features.pricing">
<i18n-group prefix="features.security">
```

2. **Organización modular**: Agrupa traducciones relacionadas bajo prefijos con significado.

```vue
<i18n-group prefix="checkout.payment">
<i18n-group prefix="checkout.shipping">
```

3. **Componentes reutilizables**: Crea componentes reutilizables con sus propios grupos de traducciones.

```vue
<!-- UserProfile.vue -->
<i18n-group prefix="user.profile">

<!-- UserSettings.vue -->
<i18n-group prefix="user.settings">
```

4. **Grupos anidados**: Evita anidar profundamente los grupos para mantener la claridad.

```vue
<!-- Good -->
<i18n-group prefix="shop.product">

<!-- Avoid -->
<i18n-group prefix="shop.category.product.details.specs">
```
