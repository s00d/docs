# 🌍 Componente `<i18n-switcher>`

El componente `<i18n-switcher>` en `Nuxt I18n Micro` proporciona una interfaz desplegable amigable para cambiar entre distintos idiomas en tu aplicación. Este componente es altamente personalizable, permitiendo una integración fluida con el diseño y la disposición de tu aplicación.

Los idiomas con `disabled: true` se **omiten** del desplegable (siguen disponibles mediante `$getLocales()` para SEO / etiquetas del head). Solo los idiomas conmutables reciben `NuxtLink` + `hreflang`.

Cada parte carece de estilos por defecto: las props `custom*Style` reciben objetos de estilo en línea, y los slots que siguen reemplazan el markup por completo cuando el estilo no es suficiente.

## 🛠️ Ejemplos de uso

### Uso básico

```vue
<template>
  <i18n-switcher />
</template>
```

Esto renderiza un cambiador de idioma con el estilo y comportamiento por defecto.

### Etiquetas personalizadas y estilos en línea

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Este ejemplo muestra un cambiador de idioma totalmente personalizado con etiquetas personalizadas y estilos en línea.

## 🔌 Slots

Cada parte visual del cambiador puede reemplazarse. Los slots se listan con la tabla de props anterior; cada uno acepta contenido de plantilla:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Los slots cuyo nombre termina en `-item`, `-link-content` o empieza con `before-item` reciben el objeto `locale` al que pertenecen.

## 🎨 Descripción de los estilos

El componente `<i18n-switcher>` viene con estilos básicos definidos mediante estilos en línea que pueden anularse fácilmente pasando estilos personalizados vía props. Aquí tienes una breve descripción del estilo por defecto:

- **Wrapper**: Controla el posicionamiento del desplegable.
- **Botón**: Da estilo al botón que abre el desplegable.
- **Desplegable**: Da estilo a la lista desplegable.
- **Elementos**: Da estilo a cada elemento de la lista.
- **Enlaces**: Da estilo a los enlaces dentro de cada elemento.
- **Icono**: Da estilo al icono indicador del desplegable.

Puedes personalizar estos estilos pasando estilos personalizados mediante las props correspondientes, asegurándote de que el cambiador de idioma se integre perfectamente en la UI de tu aplicación.
