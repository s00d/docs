# 🌍 Componente `<i18n-switcher>`

El componente `<i18n-switcher>` en `Nuxt I18n Micro` proporciona una interfaz desplegable fácil de usar para cambiar entre distintos locales en tu aplicación. Este componente es altamente personalizable, permitiendo una integración perfecta con el diseño y la disposición de tu aplicación.

Los locales con `disabled: true` se **omiten** del desplegable (siguen disponibles a través de `$getLocales()` para SEO / etiquetas head). Solo los locales conmutables obtienen `NuxtLink` + `hreflang`.

Todas las partes están sin estilo por defecto: las props `custom*Style` toman objetos de estilo en línea, y los slots que se muestran a continuación reemplazan el marcado por completo cuando el estilo no es suficiente.

## 🛠️ Ejemplos de uso

### Uso básico

```vue
<template>
  <i18n-switcher />
</template>
```

Esto renderiza un selector de locale con estilo y comportamiento predeterminados.

### Etiquetas personalizadas y estilos en línea

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Este ejemplo muestra un selector de locale totalmente personalizado con etiquetas propias y estilos en línea.

## 🔌 Slots

Cualquier parte visual del selector puede reemplazarse. Los slots se enumeran junto con la tabla de props anterior; cada uno acepta contenido de plantilla:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Los slots cuyo nombre termina en `-item`, `-link-content` o comienza con `before-item` reciben el objeto `locale` al que pertenecen.

## 🎨 Resumen de estilos

El componente `<i18n-switcher>` viene con estilos básicos definidos mediante estilos en línea que pueden sobrescribirse fácilmente pasando estilos personalizados a través de las props. Aquí tienes un breve resumen del estilo predeterminado:

- **Wrapper**: controla el posicionamiento del desplegable.
- **Button**: aplica estilo al botón que abre el desplegable.
- **Dropdown**: aplica estilo a la lista desplegable.
- **Items**: aplica estilo a cada elemento de la lista.
- **Links**: aplica estilo a los enlaces dentro de cada elemento.
- **Icon**: aplica estilo al icono indicador del desplegable.

Puedes personalizar estos estilos pasando estilos propios a través de las props correspondientes, asegurando que el selector de locale se integre perfectamente en la interfaz de tu aplicación.
