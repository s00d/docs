# 🛠️ Composable `useI18n`

El composable `useI18n` en `Nuxt I18n Micro` proporciona acceso a la mayoría de helpers de runtime de i18n en componentes y scripts. Los métodos están disponibles **con y sin el prefijo `$`** (por ejemplo, `$t` y `t`).

Algunas inyecciones — `$defineI18nRoute` y `$clearCache` — están disponibles solo en `useNuxtApp()`. Consulta [Métodos — `$defineI18nRoute`](/api/methods#definei18nroute) y [`$clearCache`](/api/methods#clearcache).

## 📊 Qué devuelve

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Cada helper de runtime, como un objeto plano.

Las mismas funciones que el plugin inyecta como `$t`, `$tc`, etc., disponibles tanto con el nombre con prefijo de dólar como con un alias desnudo. Así que `const \{ t \} = useI18n()` y `const \{ $t \} = useI18n()` funcionan igual.

**Devuelve** — los helpers descritos en la [referencia de métodos](/api/methods).

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

Cada helper que devuelve — `$t`, `$tc`, `$has`, `$switchLocale` y el resto — se lista con su firma y se documenta por completo en la [Referencia de métodos](/api/methods).

## APIs solo de `useNuxtApp()`

Estas **no** las devuelve `useI18n()`. Impórtalas desde `useNuxtApp()`:

| Método                     | Propósito                                                                              |
| -------------------------- | -------------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Rutas de idioma por página, restricciones y traducciones en línea en `script setup`.   |
| `$clearCache()`            | Vacía la caché de traducciones en memoria y los chunks cargados.                       |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Consulta [Métodos](/api/methods) para las firmas completas y ejemplos.

## 🛠️ Ejemplos de uso

### Obtención básica de idioma

Obtén el idioma actual de la aplicación.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Traducción con parámetros

Traduce una cadena con parámetros dinámicos, con un valor por defecto de fallback.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Cambio de idioma

Cambia la aplicación a otro idioma.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Generar una ruta localizada

Genera una ruta localizada al idioma actual o al especificado.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
