# 🛠️ Composable `useI18n`

El composable `useI18n` en `Nuxt I18n Micro` proporciona acceso a la mayoría de los helpers i18n de runtime en componentes y scripts. Los métodos están disponibles **con y sin el prefijo `$`** (por ejemplo, `$t` y `t`).

Algunas inyecciones (`$defineI18nRoute` y `$clearCache`) solo están disponibles a través de `useNuxtApp()`. Consulta [Métodos — `$defineI18nRoute`](/api/methods#definei18nroute) y [`$clearCache`](/api/methods#clearcache).

## 📊 Qué devuelve

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Todos los helpers de runtime, como un objeto plano.

Las mismas funciones que el plugin inyecta como `$t`, `$tc`, etc., disponibles tanto bajo el nombre con prefijo dólar como bajo un alias simple, de modo que `const \{ t \} = useI18n()` y `const \{ $t \} = useI18n()` funcionan por igual.

**Devuelve**: los helpers descritos en la [referencia de métodos](/api/methods).

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

Todos los helpers que devuelve (`$t`, `$tc`, `$has`, `$switchLocale` y el resto) se listan con su firma y se documentan por completo en la [referencia de métodos](/api/methods).

## APIs solo disponibles en `useNuxtApp()`

Estas **no** las devuelve `useI18n()`. Impórtalas desde `useNuxtApp()`:

| Método                     | Propósito                                                                       |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Rutas de locale por página, restricciones y traducciones en línea en `script setup`. |
| `$clearCache()`            | Limpia la caché de traducciones en memoria y los chunks cargados.               |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Consulta [Métodos](/api/methods) para ver las firmas completas y ejemplos.

## 🛠️ Ejemplos de uso

### Obtención básica del locale

Obtén el locale actual de la aplicación.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Traducción con parámetros

Traduce una cadena con parámetros dinámicos y con un valor por defecto de reserva.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Cambio de locales

Cambia la aplicación a un locale distinto.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Generación de una ruta localizada

Genera una ruta localizada al locale actual o al especificado.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
