# 🌍 Composable `useLocaleHead`

El composable `useLocaleHead` es una utilidad en `Nuxt I18n Micro` que te ayuda a gestionar los atributos SEO y las etiquetas meta HTML para rutas localizadas. Genera dinámicamente los atributos `lang` y `dir` del documento HTML y crea etiquetas `meta` y `link` para mejorar el SEO de tu contenido localizado.

## ⚙️ Opciones

```ts
useLocaleHead(options: UseLocaleHeadOptions): { metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }, MetaObject | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

Las etiquetas head SEO para la ruta actual: `hreflang` alternates para cada idioma más `x-default`, un enlace canonical, `og:locale` y `lang`/`dir` en `<html>`.

Solo se necesita cuando `meta` está desactivado o los valores por defecto requieren ajustes. Con `meta: true`, el módulo registra las mismas etiquetas por sí mismo.

```ts
const head = useLocaleHead({ addSeoAttributes: true })
```

## 🛠️ Valores devueltos

El composable `useLocaleHead` devuelve un objeto reactivo y una función actualizadora que debes llamar cuando los datos de origen cambian. Ambas formas están en la firma anterior, generada desde el código fuente.

### `metaObject`

Payload head reactivo (html attrs, meta, link) adecuado para `useHead(metaObject)`.

- **Ejemplo**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

Recalcula `metaObject` según la ruta, el idioma y la configuración actuales. Llámalo cuando cambien las entradas. Por ejemplo, en un cambio de ruta.

- **Ejemplo**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### Acceder a `link` y `meta`

Los arreglos `link` y `meta` son accesibles vía `metaObject.value`:

- **Ejemplo**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ Ejemplos de uso

### Uso básico

Genera atributos head específicos del idioma con las opciones por defecto.

```js
const head = useLocaleHead()
```

### Personalizar atributo identificador

Usa un atributo identificador personalizado para las etiquetas generadas.

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### Desactivar atributos SEO

Genera atributos head sin añadir etiquetas meta y link relacionadas con SEO.

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### Especificar una URL base

Establece una URL base personalizada para URLs canónicas y alternativas.

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 Funciones adicionales

### Etiquetas meta y link SEO

Cuando `addSeoAttributes` está activo, el composable genera automáticamente las siguientes etiquetas:

- `og:locale` para el idioma actual (`language_TERRITORY`, guion bajo). Derivado de `locale.og` o convertido desde `locale.iso` cuando es posible.
- `og:url` para la URL canónica de la página.
- `og:locale:alternate` para versiones de idioma alternativas.
- Enlaces `rel="canonical"` y `rel="alternate"` para optimización SEO.
- Enlace `hreflang="x-default"` que apunta a la URL del idioma por defecto. Esto indica a los motores de búsqueda qué URL mostrar a usuarios cuyo idioma no coincide con ninguno de los definidos.

### Idioma y dirección dinámicos

El composable determina dinámicamente los atributos `lang` y `dir` según el idioma de la ruta actual, asegurando que tu documento HTML esté correctamente configurado para usuarios internacionales.

### Manejo de rutas localizadas

Si tus rutas están prefijadas con códigos de idioma (por ejemplo, `/en/about`), el composable ajusta inteligentemente la ruta completa para generar URLs, asegurando que los atributos SEO sean precisos y relevantes.

Este composable simplifica el proceso de optimizar tu aplicación Nuxt para audiencias internacionales, asegurando que tu sitio esté bien preparado para motores de búsqueda y usuarios globales.

## 🛠️ Ejemplo de uso

El siguiente ejemplo muestra cómo usar el composable `useLocaleHead` dentro de un componente Vue con la configuración por defecto:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### Explicación del código

- **Composable `useLocaleHead`**: Este composable se llama en la sección `<script setup>` y devuelve un objeto que contiene `htmlAttrs`, `meta` y `link`.

- **Etiqueta `<html>`**: Los atributos `lang` y `dir` del documento HTML se determinan dinámicamente según el idioma actual y se aplican a la etiqueta `<html>`.

- **Sección `<head>`**:
  - **Etiquetas meta**: Se generan etiquetas meta relacionadas con SEO, incluidas `og:locale`, `og:url` y etiquetas `rel="canonical"` y `rel="alternate"` para especificar versiones de idioma alternativas de la página.
  - **Etiquetas link**: Se incluyen enlaces canonical, enlaces a versiones de idioma alternativas y el enlace `hreflang="x-default"` (que apunta a la URL del idioma por defecto).

- **Sección `<body>`**: Aquí se muestra el contenido principal de la página. En este ejemplo, se usan un encabezado sencillo y un párrafo.

### 📝 Notas

1. **Atributos**: Los atributos usados (`lang`, `dir`, `rel`, `href`, `hreflang`, `property`, `content`) se extraen del objeto devuelto por `useLocaleHead`.

2. **Generación de etiquetas SEO**: Si la opción `addSeoAttributes` está en `true`, el composable genera automáticamente etiquetas SEO para el idioma actual.

3. **URL base**: Puedes establecer tu URL base personalizada usando la opción `baseUrl` para generar correctamente enlaces canónicos y alternativos.

Este ejemplo muestra lo fácil que es integrar `useLocaleHead` en los componentes de tu aplicación para asegurar atributos SEO correctos y mejorar la indexación por motores de búsqueda de las páginas localizadas.

## 🧩 Personalización y ciclo de vida

- `useLocaleHead` no se suscribe a los cambios por sí solo. Devuelve `metaObject` y `updateMeta`.
- Debes llamar a `updateMeta()` cuando cambien las entradas (típicamente en cambio de ruta), por ejemplo desde un plugin:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## Cuándo usar `useI18nHead` en su lugar

Cuando `meta: true` (por defecto), prefiere [`useI18nHead`](/api/composables/use-i18n-head) para anulaciones **por página** (hreflang personalizado, `og:title` adicional, desactivación parcial). Usa `useLocaleHead` directamente solo cuando `meta: false` o gestionas `useHead` tú mismo.
