# 🌍 Composable `useLocaleHead`

El composable `useLocaleHead` es una utilidad de `Nuxt I18n Micro` que te ayuda a gestionar atributos SEO y meta etiquetas HTML para rutas localizadas. Genera dinámicamente los atributos `lang` y `dir` del documento HTML y crea etiquetas `meta` y `link` para mejorar el SEO de tu contenido localizado.

## ⚙️ Opciones

```ts
useLocaleHead(options: UseLocaleHeadOptions): { metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }, MetaObject | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

Las etiquetas SEO de head para la ruta actual: alternativas `hreflang` para cada locale más `x-default`, un enlace canonical, `og:locale` y `lang`/`dir` en `<html>`.

Solo se necesita cuando `meta` está deshabilitado o cuando hay que ajustar los valores predeterminados; con `meta: true`, el módulo registra las mismas etiquetas por sí mismo.

**Devuelve**: una ref que contiene el objeto de head, lista para pasar a `useHead`.

```ts
const head = useLocaleHead({ addSeoAttributes: true })
```

## 🛠️ Valores devueltos

El composable `useLocaleHead` devuelve un objeto reactivo y una función de actualización que debes llamar cuando cambien los datos fuente. Ambas formas están en la firma superior, generadas a partir del código fuente.

### `metaObject`

Payload reactivo de head (atributos html, meta, link) apto para `useHead(metaObject)`.

- **Ejemplo**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

Recalcula `metaObject` basándose en la ruta, el locale y la configuración actuales. Llámalo cuando cambien las entradas, por ejemplo en un cambio de ruta.

- **Ejemplo**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### Acceso a `link` y `meta`

Los arrays `link` y `meta` son accesibles a través de `metaObject.value`:

- **Ejemplo**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ Ejemplos de uso

### Uso básico

Genera atributos de head específicos del locale con las opciones predeterminadas.

```js
const head = useLocaleHead()
```

### Personalizar el atributo identificador

Usa un atributo identificador personalizado para las etiquetas generadas.

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### Deshabilitar atributos SEO

Genera atributos de head sin añadir meta y link tags relacionadas con SEO.

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### Especificar una URL base

Establece una URL base personalizada para las URL canonical y alternate.

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 Funciones adicionales

### Meta y link tags de SEO

Cuando `addSeoAttributes` está habilitado, el composable genera automáticamente las siguientes etiquetas:

- `og:locale` para el locale actual (`language_TERRITORY`, con guion bajo). Se deriva de `locale.og` o se convierte desde `locale.iso` cuando es posible.
- `og:url` para la URL canónica de la página.
- `og:locale:alternate` para versiones de idioma alternativas.
- Enlaces `rel="canonical"` y `rel="alternate"` para la optimización SEO.
- Enlace `hreflang="x-default"` que apunta a la URL del locale predeterminado. Esto indica a los motores de búsqueda qué URL mostrar a los usuarios cuyo idioma no coincide con ninguno de los locales definidos.

### Locale y dirección dinámicos

El composable determina dinámicamente los atributos `lang` y `dir` según el locale de la ruta actual, asegurando que tu documento HTML esté configurado correctamente para usuarios internacionales.

### Gestión de rutas localizadas

Si tus rutas tienen prefijos con códigos de locale (por ejemplo, `/en/about`), el composable ajusta inteligentemente la ruta completa para generar URLs, asegurando que los atributos SEO sean precisos y relevantes.

Este composable simplifica el proceso de optimizar tu aplicación Nuxt para audiencias internacionales, garantizando que tu sitio esté bien preparado para los motores de búsqueda globales y los usuarios.

## 🛠️ Ejemplo de uso

El siguiente ejemplo muestra cómo usar el composable `useLocaleHead` dentro de un componente Vue con la configuración predeterminada:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### Explicación del código

- **Composable `useLocaleHead`**: se llama en la sección `<script setup>` y devuelve un objeto que contiene `htmlAttrs`, `meta` y `link`.

- **Etiqueta `<html>`**: los atributos `lang` y `dir` del documento HTML se determinan dinámicamente según el locale actual y se aplican a la etiqueta `<html>`.

- **Sección `<head>`**:
  - **Meta tags**: se generan meta tags relacionadas con SEO, incluidas `og:locale`, `og:url` y las etiquetas `rel="canonical"` y `rel="alternate"` para especificar versiones de idioma alternativas de la página.
  - **Link tags**: se incluyen enlaces canonical, enlaces a versiones de idioma alternativas y el enlace `hreflang="x-default"` (que apunta a la URL del locale predeterminado).

- **Sección `<body>`**: aquí se muestra el contenido principal de la página. En este ejemplo se usan un encabezado y un párrafo sencillos.

### 📝 Notas

1. **Atributos**: los atributos usados (`lang`, `dir`, `rel`, `href`, `hreflang`, `property`, `content`) se extraen del objeto devuelto por `useLocaleHead`.

2. **Generación de etiquetas SEO**: si la opción `addSeoAttributes` está establecida en `true`, el composable genera automáticamente etiquetas SEO para el locale actual.

3. **URL base**: puedes establecer tu URL base personalizada usando la opción `baseUrl` para generar correctamente los enlaces canonical y alternate.

Este ejemplo demuestra lo fácil que es integrar `useLocaleHead` en los componentes de tu aplicación para asegurar atributos SEO correctos y mejorar la indexación en motores de búsqueda de las páginas localizadas.

## 🧩 Personalización y ciclo de vida

- `useLocaleHead` no se suscribe a los cambios por sí mismo. Devuelve `metaObject` y `updateMeta`.
- Debes llamar a `updateMeta()` cuando cambien las entradas (normalmente en un cambio de ruta), por ejemplo desde un plugin:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## Cuándo usar `useI18nHead` en su lugar

Cuando `meta: true` (predeterminado), prefiere [`useI18nHead`](/api/composables/use-i18n-head) para sobrescrituras **por página** (hreflang personalizado, `og:title` extra, deshabilitación parcial). Usa `useLocaleHead` directamente solo cuando `meta: false` o gestiones `useHead` tú mismo.
