# useI18nLocale

## Firma

Punto de entrada centralizado para la gestión del idioma en i18n. Combina useState('i18n-locale'), la cookie de idioma y utilidades de sincronización.

## Uso

```vue
<script setup>
const {
  locale,
  localeCookie,
  hashCookie,
  validLocales,
  getPreferredLocale,
  getLocale,
  getLocaleWithServerFallback,
  getEffectiveLocale,
  resolveInitialLocale,
  setLocale,
  syncLocale,
  isValidLocale,
} = useI18nLocale()

// Set locale (updates state and cookies)
setLocale('de')

// Get current locale (state → cookie)
const current = getLocale()

// Get valid preferred locale
const preferred = getPreferredLocale()
</script>
```

## API

| Propiedad/Método                                | Tipo                                | Descripción                                                                          |
| ----------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| `locale`                                        | `Ref<string \| null>`               | Estado reactivo del idioma (`useState('i18n-locale')`).                              |
| `localeCookie`                                  | `Ref`                               | Cookie de idioma (cuando la opción `localeCookie` está activada).                    |
| `hashCookie`                                    | `Ref`                               | Cookie usada cuando `hashMode` está activo.                                          |
| `validLocales`                                  | `string[]`                          | Códigos de idioma activados desde la configuración del módulo (excluye `disabled`).  |
| `getLocale()`                                   | `() => string \| null`              | Idioma actual: estado → cookie (o cookie hash en modo hash).                         |
| `getPreferredLocale()`                          | `() => string \| null`              | Idioma desde estado/cookie **validado** contra `validLocales`, o `null`.             |
| `getLocaleWithServerFallback(serverLocale?)`    | `(serverLocale?) => string \| null` | Estado → cookie → contexto de servidor opcional (usado durante init `no_prefix`).    |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string`             | Idioma para cargar traducciones: modo hash prefiere el estado; si no, lee de la ruta. |
| `resolveInitialLocale(options)`                 | `(options) => string`               | Resuelve el idioma: estado → `serverLocale` → ruta; sincroniza el estado cuando es necesario. |
| `setLocale(locale)`                             | `(locale: string \| null) => void`  | Establece el idioma y sincroniza con cookies.                                        |
| `syncLocale(locale)`                            | `(locale: string \| null) => void`  | Sincroniza solo cookies (sin actualizar estado).                                     |
| `isValidLocale(locale)`                         | `(locale) => boolean`               | Comprueba si la cadena está en `validLocales`.                                       |

### Opciones de `resolveInitialLocale`

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

Usado internamente por el plugin principal en el arranque. Los plugins personalizados pueden llamarlo al implementar flujos de detección alternativos.

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

Devuelve el idioma usado para cargar traducciones y formatear mensajes para un objeto de ruta dado.

## Establecimiento programático de idioma

Prefiere `useI18nLocale()` en lugar del uso directo de `useState('i18n-locale')`:

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
`setLocale()` actualiza únicamente la preferencia de idioma (estado + cookie). Para recargar también el contexto de traducción activo en el cliente, usa `$switchLocale()` desde `useNuxtApp()` o `useI18n()`. Esto importa especialmente en `no_prefix`, donde la URL no cambia. Consulta [FAQ — cambiar idioma sin cambiar la URL](/guides/faq#-switch-locale-without-changing-the-url).
</Tip>
