La [guía de la CLI](/es/guide/cli) muestra los flujos de trabajo habituales. Esta página lo enumera todo y se genera a partir de la misma tabla que alimenta `--help`.

## Flags comunes {#common-flags}

| Flag | Valor predeterminado | Descripción |
| --- | --- | --- |
| `--cwd` | directorio actual | Directorio del proyecto |
| `--logLevel` | `info` | Nivel de salida: silent, info |
| `--debug` | `false` | Imprime una traza de la pila cuando un comando falla |

## Inspección {#inspect}

### `info` {#info}

Imprime la configuración i18n resuelta del proyecto

| Flag | Valor predeterminado | Descripción |
| --- | --- | --- |
| `--json` | `false` | Imprime JSON en lugar de texto |

### `check` {#check}

La puerta de CI: falla ante claves que faltan, vacías, sobrantes, no definidas o sin usar, y ante placeholders rotos

| Flag | Valor predeterminado | Descripción |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Directorio de traducciones, relativo al proyecto |
| `--only` | todas menos duplicates | Comprobaciones a ejecutar, separadas por comas: missing, empty, extra, placeholders, undefined, unused, duplicates. Si se indica `unused` aquí, falla cuando no puede ejecutarse |
| `--duplicates` | `false` | Informa también del mismo texto bajo claves distintas |
| `--ignore` | — | Globs de archivos fuente a omitir, separados por comas, relativos al proyecto |
| `--json` | `false` | Imprime JSON en lugar de texto |

```bash
i18n-micro check
i18n-micro check --only missing,placeholders --json
```

### `stats` {#stats}

Muestra el grado de completitud de las traducciones por locale

| Flag | Valor predeterminado | Descripción |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Directorio de traducciones, relativo al proyecto |
| `--html` | — | Escribe además un informe HTML en este archivo |
| `--json` | `false` | Imprime JSON en lugar de texto |
| `--baseRef` | — | Ref de Git con la que comparar la completitud, p. ej. HEAD~1 o main |

```bash
i18n-micro stats --baseRef main
i18n-micro stats --html reports/i18n.html
```

### `lint` {#lint}

Revisa el texto de las traducciones; falla cuando quedan problemas

| Flag | Valor predeterminado | Descripción |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Directorio de traducciones, relativo al proyecto |
| `--rules` | todas, o `enabledRules` de .i18n-lintrc.json | Reglas a ejecutar, separadas por comas: no-trailing-spaces, no-multiple-spaces, no-empty-translation, o una personalizada |
| `--fix` | `false` | Corrige lo que se pueda corregir: espacios y reglas personalizadas con reemplazo |
| `--json` | `false` | Imprime JSON en lugar de texto |

```bash
i18n-micro lint --rules no-trailing-spaces --fix
```

### `search` {#search}

Busca claves y valores, y muestra dónde se usa cada clave

| Flag | Valor predeterminado | Descripción |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Directorio de traducciones, relativo al proyecto |
| `<query>` | — | Texto o clave a buscar |
| `--caseSensitive` | `false` | Distingue mayúsculas y minúsculas |
| `--onlyUnused` | `false` | Solo las claves que `clean` eliminaría; la consulta pasa a ser opcional |
| `--scope` | `all` | Dónde buscar: global, pages, all |
| `--limit` | — | Devuelve como máximo este número de claves |
| `--ignore` | — | Globs de archivos fuente a omitir, separados por comas, relativos al proyecto |
| `--json` | `false` | Imprime JSON en lugar de texto |

```bash
i18n-micro search "Welcome"
i18n-micro search --onlyUnused
```

## Flujo de trabajo de traducción {#translation-workflow}

### `extract` {#extract}

Enumera las claves que usan los archivos fuente y que aún no tienen texto, y añade las que tienen un texto predeterminado al locale predeterminado

| Flag | Valor predeterminado | Descripción |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Directorio de traducciones, relativo al proyecto |
| `--ignore` | — | Globs de archivos fuente a omitir, separados por comas, relativos al proyecto |

```bash
i18n-micro extract
```

### `translate` {#translate}

Rellena las traducciones que faltan a partir del locale predeterminado mediante un servicio de traducción

| Flag | Valor predeterminado | Descripción |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Directorio de traducciones, relativo al proyecto |
| `--service` | — | Servicio de traducción: ai, azure, deepl, google, libretranslate, yandexcloud |
| `--token` | — | Clave de API. Es preferible la variable de entorno I18N_TRANSLATE_TOKEN: los flags acaban en el historial del shell |
| `--options` | — | Opciones del servicio como pares key:value, separados por comas |
| `--locale` | todos los locales menos el predeterminado | Locales a rellenar, separados por comas |
| `--replace` | `false` | Vuelve a traducir todas las claves, reemplazando los valores existentes |
| `--dryRun` | `false` | Cuenta claves y caracteres por locale; no envía nada |
| `--chunkSize` | — | Cadenas por solicitud; limitado a lo que acepta el servicio |
| `--pluralSeparator` | `\|` | Separador de las formas plurales en los mensajes |
| `--glossaryFile` | `.i18n-glossary.json` cuando existe | Archivo de glosario, usado por el servicio `ai` |

```bash
i18n-micro translate --dryRun
I18N_TRANSLATE_TOKEN=... i18n-micro translate --service deepl --locale de,fr
i18n-micro translate --service ai --options provider:openai,model:gpt-4o-mini
i18n-micro translate --service libretranslate --options baseUrl:https://translate.example.com
```

### `sync` {#sync}

Elimina las claves que el locale predeterminado no tiene; se detiene cuando no puede demostrar que es seguro. Las claves que faltan siguen faltando

| Flag | Valor predeterminado | Descripción |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Directorio de traducciones, relativo al proyecto |
| `--ignore` | — | Globs de archivos fuente a omitir, separados por comas, relativos al proyecto |
| `--dryRun` | `false` | Enumera lo que se eliminaría; no escribe nada |
| `--force` | `false` | Elimina claves aunque no se pueda demostrar que es seguro |

```bash
i18n-micro sync --dryRun
```

### `clean` {#clean}

Elimina las claves que nada en el proyecto usa; se detiene cuando no puede demostrarlo

| Flag | Valor predeterminado | Descripción |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Directorio de traducciones, relativo al proyecto |
| `--include` | — | Expresión regular: solo considera para eliminar las claves que coinciden |
| `--exclude` | — | Expresión regular: nunca elimina las claves que coinciden |
| `--ignore` | — | Globs de archivos fuente a omitir, separados por comas, relativos al proyecto |
| `--dryRun` | `false` | Enumera lo que se eliminaría; no escribe nada |
| `--force` | `false` | Elimina claves aunque no se pueda demostrar el uso de todas ellas |

```bash
i18n-micro clean --dryRun
i18n-micro clean --exclude '^errors\.'
```

## Refactorización {#refactoring}

### `text-to-i18n` {#text-to-i18n}

Reemplaza el texto codificado en las plantillas Vue por llamadas de traducción e informa del texto codificado en el código

| Flag | Valor predeterminado | Descripción |
| --- | --- | --- |
| `--translationFile` | `<translationDir>/<defaultLocale>.json` | Archivo al que van las claves nuevas |
| `--path` | todo el proyecto | Archivo o directorio a procesar |
| `--context` | — | Prefijo para las claves generadas |
| `--ignore` | — | Globs de archivos fuente a omitir, separados por comas, relativos al proyecto |
| `--dryRun` | `false` | Muestra lo que cambiaría; no escribe nada |
| `--interactive` | `false` | Confirma o edita cada clave generada |

```bash
i18n-micro text-to-i18n --dryRun
i18n-micro text-to-i18n --path components --context ui
```

### `rename` {#rename}

Renombra una clave o un espacio de nombres en todos los locales y en los archivos fuente

| Flag | Valor predeterminado | Descripción |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Directorio de traducciones, relativo al proyecto |
| `--from` **\*** | — | Clave o espacio de nombres actual |
| `--to` **\*** | — | Nueva clave o espacio de nombres |
| `--ignore` | — | Globs de archivos fuente a omitir, separados por comas, relativos al proyecto |
| `--dryRun` | `false` | Informa de los cambios; no escribe nada |

**\*** obligatorio.

```bash
i18n-micro rename --from common.save --to actions.save
```

### `pseudo` {#pseudo}

Rellena un locale con pseudotraducciones para encontrar problemas de maquetación y de texto codificado

| Flag | Valor predeterminado | Descripción |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Directorio de traducciones, relativo al proyecto |
| `--sourceLocale` | el locale predeterminado | Locale a leer |
| `--targetLocale` **\*** | — | Locale a rellenar |
| `--replace` | `false` | Sobrescribe los valores existentes |

**\*** obligatorio.

### `format` {#format}

Reescribe los archivos de locale con claves ordenadas y sangría uniforme

| Flag | Valor predeterminado | Descripción |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Directorio de traducciones, relativo al proyecto |
| `--indent` | `2` | Espacios de sangría |
| `--sortKeys` | `true` | Ordena las claves; usa --no-sortKeys para mantener su orden |
| `--check` | `false` | Falla si un archivo cambiaría; no escribe nada |

```bash
i18n-micro format --check
```

## Intercambio {#exchange}

### `export` {#export}

Exporta los archivos de locale a PO o CSV, con el texto del locale predeterminado como origen

| Flag | Valor predeterminado | Descripción |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Directorio de traducciones, relativo al proyecto |
| `--format` | `po` | Formato de archivo: po, csv |
| `--dir` | `pots` para po, `csv_exports` para csv | Directorio de salida, relativo al proyecto |
| `--force` | `false` | Sobrescribe archivos modificados desde la última exportación y nunca importados |

```bash
i18n-micro export --format csv
```

### `import` {#import}

Fusiona archivos PO o CSV en los archivos de locale

| Flag | Valor predeterminado | Descripción |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Directorio de traducciones, relativo al proyecto |
| `--format` | `po` | Formato de archivo: po, csv |
| `--dir` | `pots` para po, `csv_exports` para csv | Directorio de entrada, relativo al proyecto |
| `--dryRun` | `false` | Informa de lo que se importaría; no escribe nada |

```bash
i18n-micro import --format csv --dryRun
```

### `sync-remote` {#sync-remote}

Descarga las traducciones globales desde el endpoint HTTP de .i18n-remote.json, o las sube a él

| Flag | Valor predeterminado | Descripción |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Directorio de traducciones, relativo al proyecto |
| `--pull` | `true` | Descarga desde el remoto |
| `--push` | `false` | Sube al remoto |
| `--force` | `false` | Al descargar, toma el valor remoto; al subir, sobrescribe el texto que solo tiene el remoto |
| `--dryRun` | `false` | Informa de lo que cambiaría una descarga; no escribe ni sube nada |

```bash
i18n-micro sync-remote --dryRun
i18n-micro sync-remote --no-pull --push
```

## Reglas de lint {#lint-rules}

| Regla | Detecta | Corregida por `--fix` |
| --- | --- | --- |
| `no-trailing-spaces` | Espacios al final de un valor o de una línea | sí |
| `no-multiple-spaces` | Dos o más espacios seguidos | sí |
| `no-empty-translation` | Un valor vacío o en blanco | no |

## Códigos de salida {#exit-codes}

| Código | Significado |
| --- | --- |
| `0` | Hecho, nada que informar |
| `1` | Hallazgos: `check`, `lint` o `format --check` encontraron algo, `clean` o `sync` no pudieron demostrar que una eliminación era segura, `export` sobrescribiría trabajo no importado, `translate` dejó claves fuera, `import` o `sync-remote` encontraron un conflicto, una subida de `sync-remote` descartaría texto remoto. Un `--dryRun` de `clean`, `sync` o de una descarga de `sync-remote` informa de esto y sale con `0` |
| `2` | Fallo: uso incorrecto, proyecto ilegible, error de red o de archivo |

## Archivos de configuración {#configuration-files}

| Archivo | Usado por |
| --- | --- |
| `.i18n-lintrc.json` | `lint`: `enabledRules`, `disabledRules`, `customRegexRules` (`name`, `pattern`, `flags`, `description`, `replacement`) |
| `.i18n-remote.json` | `sync-remote`: `url`, `path`, `token`, `auth` (`username`, `password`). `type` puede omitirse; solo existe `custom` |
| `.i18n-glossary.json` | `translate --service ai`: `entries` de `source`, `target` y, opcionalmente, `from`, `to` |

## Variables de entorno {#environment-variables}

| Nombre | Uso |
| --- | --- |
| `I18N_TRANSLATE_TOKEN` | Clave de API de `translate`. También se lee de `.env` |
| `I18N_REMOTE_TOKEN` | Token Bearer de `sync-remote`. También se lee de `.env` |
| `AI_GATEWAY_API_KEY, OPENAI_API_KEY, ANTHROPIC_API_KEY` | Clave del servicio `ai`, cuando `I18N_TRANSLATE_TOKEN` no está definida |
| `DEFAULT_LOCALE` | Sobrescribe `defaultLocale`, como en el módulo |
