---
title: "Astro 岛屿"
description: "使用 @i18n-micro/astro 在 Vue、React、Preact 和 Svelte 岛屿中进行翻译。"
---

岛屿运行在浏览器中，而那里并不存在服务端的 i18n 实例。`@i18n-micro/astro` 让页面挑选岛屿所需的键，将它们作为一个 prop 传入，并在岛屿中通过一个小型框架适配器读取。你可以在 Vue、React、Preact 和 Svelte 岛屿中使用 `t`、`tc`、`tn`、`td`、`tdr` 和 `has`，且 HTML 中只包含所选的字符串。

## 设置 {#setup}

请先设置 [Astro 集成和中间件](/zh-CN/integrations/astro-package#setup)，然后添加你所用的框架集成（`@astrojs/vue`、`@astrojs/react`、`@astrojs/preact`、`@astrojs/svelte`）。岛屿适配器需要该框架作为 peer 依赖：`vue` `^3.3.0`、`react` `^16.8.0 || ^17.0.0 || ^18.0.0 || ^19.0.0`、`preact` `^10.0.0 || ^11.0.0` 或 `svelte` `^4.0.0 || ^5.0.0`。

## 向岛屿传递翻译 {#pass-translations-to-an-island}

```astro
---
// src/pages/index.astro
import { getI18nProps } from '@i18n-micro/astro'
import Counter from '../components/Counter.vue'

const i18n = getI18nProps(Astro, ['counter.title', 'counter.apples'])
---

<Counter client:load i18n={i18n} />
```

`getI18nProps(Astro, keys?)` 返回 `{ locale, fallbackLocale, currentRoute, translations }`（类型为 `I18nClientProps`）。请传入岛屿使用的键：每个键都会在服务端像 `t()` 一样解析（路由、根和回退词典），只有找到的键才会写入 HTML。如果不传 `keys`，则该页面上 `t()` 能解析的所有内容都会被发送到每个岛屿中，2000 个根键约为每个岛屿 100 KB；在开发环境中，超过 20 KB 时会给出警告。

岛屿只根据该对象进行翻译。对于未传入的内容，`t` 会返回键本身，并且链接消息不会被解析。

## Vue {#vue}

在岛屿的根组件中调用 `provideI18n(() => props.i18n)`，在其子组件中调用 `useAstroI18n()`。Vue 的 `inject` 看不到同一组件提供的值，因此该钩子必须在子组件中运行，而不是在根组件中：

```vue
<!-- src/components/Counter.vue -->
<script setup lang="ts">
import { provideI18n } from '@i18n-micro/astro/client/vue'
import type { I18nClientProps } from '@i18n-micro/astro'
import CounterBody from './CounterBody.vue'

const props = defineProps<{ i18n: I18nClientProps }>()
provideI18n(() => props.i18n)
</script>

<template><CounterBody /></template>
```

```vue
<!-- src/components/CounterBody.vue -->
<script setup lang="ts">
import { ref } from 'vue'
import { useAstroI18n } from '@i18n-micro/astro/client/vue'

const { t, tc } = useAstroI18n()
const count = ref(0)
</script>

<template>
  <h3>{{ t('counter.title') }}</h3>
  <button @click="count++">{{ tc('counter.apples', count) }}</button>
</template>
```

## React 和 Preact {#react-and-preact}

```tsx
// src/components/Counter.tsx
import { useState } from 'react'
import { I18nProvider, useAstroI18n } from '@i18n-micro/astro/client/react'
import type { I18nClientProps } from '@i18n-micro/astro'

function Body() {
  const { t, tc } = useAstroI18n()
  const [count, setCount] = useState(0)
  return <button onClick={() => setCount(count + 1)}>{t('counter.title')}: {tc('counter.apples', count)}</button>
}

export default function Counter({ i18n }: { i18n: I18nClientProps }) {
  return (
    <I18nProvider value={i18n}>
      <Body />
    </I18nProvider>
  )
}
```

对于 Preact，请从 `@i18n-micro/astro/client/preact` 导入 `I18nProvider` 和 `useAstroI18n`；API 完全相同。

## Svelte {#svelte}

```svelte
<!-- src/components/Counter.svelte -->
<script lang="ts">
  import { createI18nStore, useAstroI18n } from '@i18n-micro/astro/client/svelte'
  import type { I18nClientProps } from '@i18n-micro/astro'

  export let i18n: I18nClientProps
  const { t, tc } = useAstroI18n(createI18nStore(i18n))
  let count = 0
</script>

<button on:click={() => count++}>{t('counter.title')}: {tc('counter.apples', count)}</button>
```

`useAstroI18n(store)` 还会返回 `store`，用于在模板中通过 `$store` 读取。

## 持久化岛屿 {#persisted-islands}

带有 `transition:persist` 的岛屿会在导航后获得新的 props。React、Preact 和 Vue（传入 getter 时）会跟随这些 props 更新。在 Svelte 中，请保留 store 并将 props 传递下去：`const store = createI18nStore(i18n)`、`const { t } = useAstroI18n(store)`，然后 `$: store.set(i18n)`（使用 runes 时为 `$effect(() => store.set(i18n))`）。

## API {#api}

| 入口 | 导出 |
| --- | --- |
| `@i18n-micro/astro` | `getI18nProps`、类型 `I18nClientProps` |
| `@i18n-micro/astro/client/vue` | `provideI18n(props \| () => props)`、`useAstroI18n()` |
| `@i18n-micro/astro/client/react` | `I18nProvider`（`value` prop）、`useAstroI18n()` |
| `@i18n-micro/astro/client/preact` | `I18nProvider`（`value` prop）、`useAstroI18n()` |
| `@i18n-micro/astro/client/svelte` | `createI18nStore(props)`、`useAstroI18n(store)` |
| `@i18n-micro/astro/client` | 不依赖框架的纯函数 `translate`、`hasTranslation` |

每个 `useAstroI18n` 都返回 `t`、`ts`、`tc`、`tn`、`td`、`tdr`、`has`、`setLocale`、`setRoute` 以及 `locale`。岛屿只有一个合并后的词典，因此只要 `t` 能解析某个键（包括来自回退 locale 的键），其 `has` 就为 true；而在服务端，`has` 只检查当前 locale。
