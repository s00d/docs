# 📚 Nuxt I18n Micro 示例与用法

本节提供多个示例，演示如何在你的 Nuxt.js 应用中使用 `Nuxt I18n Micro`。你将看到如何切换语言、如何使用 `<i18n-link>`、`<i18n-switcher>` 和 `<i18n-t>` 组件，以及如何动态处理翻译键。

## 🛠️ 基础配置

以下是一个用于快速上手 `Nuxt I18n Micro` 的基础配置：

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 语言切换

### 以编程方式切换语言

该示例演示如何通过按钮以编程方式切换语言：

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### 语言切换所需的 JSON 示例

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### 使用 `<i18n-switcher>` 组件

`<i18n-switcher>` 组件提供一个语言切换下拉菜单，并支持自定义标签：

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 📝 渲染翻译文件中的动态键

在某些场景下，你可能想遍历翻译文件中存储的一组动态键，并按条件渲染它们的值。以下示例演示了如何借助 `Nuxt I18n Micro` 实现这一点。

### 示例：渲染动态键

该示例从翻译中的某个路径（此处为 `dynamic`）取出一个键数组，然后进行遍历。每个键在渲染前会先通过 `$has` 检查是否存在，然后再使用 `$t` 渲染。

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### 翻译文件示例（`en.json`）

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### 示例：渲染对象形式的动态键

在该示例中，我们处理翻译文件中存储的一个对象。我们遍历对象的键，同时动态渲染键名及其对应的值。

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### 翻译文件示例（`en.json`）

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 使用 `<i18n-t>` 结合插槽与插值

`<i18n-t>` 组件适合用于在翻译内容中渲染动态内容或 HTML 标签：

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### `<i18n-t>` 所需的 JSON 示例

```json
{
  "greeting": "Welcome to the page"
}
```

### 结合插值

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### 插值所需的 JSON 示例

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 使用 `$tc` 处理复数

`Nuxt I18n Micro` 中的 `$tc` 函数会根据数量与当前语言配置处理复数形式。这在需要根据数量动态调整消息时非常有用，例如条目、通知或其他数量会变化的实体。

### 示例：使用 `$tc` 处理复数

在下面的示例中，我们使用 `$tc` 显示苹果数量的消息。翻译键会根据提供的数量处理多种复数形式。

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### 复数处理所需的 JSON 示例

以下是可以在 JSON 文件中定义的翻译，用于处理不同的复数形式：

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### 说明

- **`$tc('apples', 0)`**：返回第一种形式，当数量为零时使用（`"no apples"`）。
- **`$tc('apples', 1)`**：返回第二种形式，当数量为一时使用（`"one apple"`）。
- **`$tc('apples', 10)`**：返回带数量值的第三种形式，当数量为二或更多时使用（`"10 apples"`）。

### 更复杂的复数示例

如果你的应用需要处理更复杂的复数规则（例如为零、一、二、少数、许多、其他分别指定不同形式），可以相应地扩展翻译字符串：

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**：可以配置为返回 `"two apples"`。
- **`$tc('apples', 3)`**：可以返回 `"a few apples"`，具体取决于为该数量定义的规则。

## 🌐 使用 `$tn` 进行数字格式化

`$tn` 函数会依据当前语言并借助 `Intl.NumberFormat` API 对数字进行格式化。这在需要按用户地区习惯显示数字时非常有用，例如货币、百分比或其他数字格式。

### 示例：使用 `$tn` 进行数字格式化

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ 使用 `$td` 进行日期和时间格式化

`$td` 函数会依据当前语言并借助 `Intl.DateTimeFormat` API 对日期与时间进行格式化。这在需要以用户熟悉的语言习惯显示日期时间时非常有用。

### 示例：使用 `$td` 进行日期和时间格式化

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ 使用 `$tdr` 进行相对日期格式化

`$tdr` 函数会依据当前语言并借助 `Intl.RelativeTimeFormat` API 将日期格式化为相对时间（例如 "5 minutes ago"、"2 days ago"）。这在需要显示相对于当前日期时间的时间差时非常有用。

### 示例：使用 `$tdr` 进行相对日期格式化

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
