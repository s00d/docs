在 `nuxt dev` 中，模块会添加两个调试辅助工具：Nuxt DevTools 中的 **i18n Micro** 标签页，用于浏览和编辑翻译文件；以及 Vue DevTools 检查器，用于查看实时语言和已加载的字典。两者都仅在开发环境中存在，不会给生产构建增加任何内容。Nuxt 标签页只需启用 Nuxt DevTools；Vue 检查器还需要安装 Vue DevTools 浏览器扩展。

## Nuxt DevTools 标签页 {#nuxt-devtools-tab}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  devtools: { enabled: true }, // the tab is registered only when DevTools are on
})
```

打开 Nuxt DevTools（`Shift + Alt + D`）并选择 **i18n Micro**。该标签页显示：

- 每一层 `locales/`（根目录和 `pages/`）下的所有 JSON 文件，以及来自 `additionalTranslationDirs` 的根文件；
- 每个文件的编辑器；**Save** 会将文件写回磁盘，开发服务器随即重新加载翻译；
- 以 JSON 形式 **Export** / **Import** 文件，以及显示键数量和翻译覆盖率的 **Stats**；
- 已解析模块选项的配置视图；
- **Translate**，使用你在标签页设置中配置的机器翻译引擎填充缺失的键。

保存操作只会写入翻译目录中已存在的 `.json` 文件。当同一文件存在于多个层中时，会写入项目自身的副本。

## Vue DevTools 检查器 {#vue-devtools-inspector}

安装 Vue DevTools 浏览器扩展后，模块会注册一个 i18n 检查器（当前语言、路由块、已加载的键），以及一条记录语言切换、块加载和缺失键的时间线。

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    debug: true, // also log every $t / $ts / $tc call on the timeline
    // vueDevtools: false, // turn the inspector off, keep the Nuxt tab
  },
})
```

[`vueDevtools`](/zh-CN/api/module-options) 默认为 `true`。`debug: true` 输出较为冗长，建议仅在短时间调试时使用。
