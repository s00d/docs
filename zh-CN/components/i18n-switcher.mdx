title: "<i18n-switcher>"
description: "<i18n-switcher> 组件是一个包含已启用语言的下拉菜单，每一项都链接到当前页面在该语言下的版本。"
---

`<i18n-switcher>` 渲染一个显示当前语言的按钮，以及一个包含所有已启用语言（包括当前语言）的下拉菜单。可将它作为现成的语言菜单使用；如果需要不同的标记结构，可以基于 [`$getLocales`](/zh-CN/api/methods#$getlocales) 和 [`$switchLocalePath`](/zh-CN/api/methods#$switchlocalepath) 自行构建。每一项都链接到当前页面在该语言下的版本。

## Props 与插槽 {#props-and-slots}

| Prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `customLabels` | `Record<string, string>` | `() => ({})` | 按语言代码设置的显示名称，会覆盖语言配置中的 `displayName`。 |
| `customWrapperStyle` | `CSSProperties` | `() => ({})` | 外层包裹元素的内联样式。 |
| `customButtonStyle` | `CSSProperties` | `() => ({})` | 打开下拉菜单的按钮的内联样式。 |
| `customDropdownStyle` | `CSSProperties` | `() => ({})` | 下拉面板的内联样式。 |
| `customItemStyle` | `CSSProperties` | `() => ({})` | 下拉菜单中每一项的内联样式。 |
| `customLinkStyle` | `CSSProperties` | `() => ({})` | 每一项内部链接的内联样式。 |
| `customActiveLinkStyle` | `CSSProperties` | `() => ({})` | 当前激活语言的链接的内联样式。 |
| `customDisabledLinkStyle` | `CSSProperties` | `() => ({})` | 当*当前*语言在配置中为 `disabled: true` 时，该语言按钮的内联样式。 |
| `customIconStyle` | `CSSProperties` | `() => ({})` | 按钮上插入符图标的内联样式。 |

### 插槽 {#slots}

| 插槽 | 绑定 | 说明 |
| --- | --- | --- |
| `before-button` | — | 打开下拉菜单的按钮之前的内容。 |
| `before-selected-locale` | — | 按钮内当前语言标签之前的内容。 |
| `after-selected-locale` | — | 按钮内当前语言标签之后的内容。 |
| `before-dropdown` | — | 按钮与下拉面板之间的内容。 |
| `before-dropdown-items` | — | 下拉菜单顶部、语言列表上方的内容。 |
| `before-item` | `locale` | 每个语言项之前的内容。 |
| `before-link-content` | `locale` | 链接内语言标签之前的内容。 |
| `after-link-content` | `locale` | 链接内语言标签之后的内容。 |
| `after-item` | `locale` | 每个语言项之后的内容。 |
| `after-dropdown-items` | — | 下拉菜单底部、语言列表下方的内容。 |
| `after-dropdown` | — | 下拉面板之后的内容。 |

## 行为 {#behaviour}

- 列出所有未设置 `disabled: true` 的语言，包括当前语言。
- 每一项都是指向 `$switchLocalePath(code)` 的 `<a>`。路径会在 `app.baseURL` 下解析；位于其他域名的语言 `baseUrl` 保持为绝对地址。它的 `hreflang` 和 `lang` 设置为 `iso || code`，当语言配置了 `dir` 时会设置 `dir`，当前语言带有 `aria-current="page"`，并带有类名 `switcher-locale-<code>`。点击时会调用 `$switchLocale(code)` 并关闭下拉菜单；按住修饰键点击时则交由浏览器处理。
- 列表保留在服务端 HTML 中并处于隐藏状态，因此爬虫可以看到这些链接。按 Escape 键或点击外部区域会关闭它。
- 标签：依次使用 `customLabels[code]`、语言的 `displayName`，最后是语言代码（并在开发环境中给出警告）。
- 样式：少量内联默认样式（带边框的白色按钮和面板，当前项为粗体蓝色）。每个 `custom*Style` prop 都会在其对应部分的默认样式之后应用。按钮带有类名 `i18n-switcher-button` 和 `language-switcher`，包裹元素为 `i18n-switcher-wrapper`，列表为 `i18n-switcher-dropdown`。定位使用 CSS 逻辑属性，因此 `dir="rtl"` 同样适用。

## 示例 {#example}

```vue
<template>
  <i18n-switcher
    :custom-labels="{ en: 'English', de: 'Deutsch' }"
    :custom-button-style="{ borderRadius: '4px' }"
  >
    <template #before-link-content="{ locale }">
      <img :src="`/flags/${locale.code}.svg`" alt="" width="16" />
    </template>
  </i18n-switcher>
</template>
```
