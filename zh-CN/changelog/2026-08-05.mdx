发布：**v3.22.0 → v3.26.0**。

## 新特性

- **Translation Memory API。** 通过 `$resolveTranslations()` 与 `$setTranslation(key, value)` 在运行时读取和修改活跃语言的字典。适合 DevTools、测试和应用内编辑器。参见[方法](/api/methods#resolvetranslations)。
- **命名的 `numberFormats` 与 `datetimeFormats`。** 按语言配置与 Vue I18n 兼容的命名格式，然后调用 `$tn(1000, 'currency')` 或 `$td(date, 'short')`。参见[模块选项](/api/module-options)。
- **`/_locales` payload 的 HTTP 缓存控制。** 新增的 [`httpCacheDuration`](/api/module-options) 会在翻译 payload 上设置 `Cache-Control: public, max-age=…, immutable`。默认一年，并可安全地与 `?v={dateBuild}` 缓存打破机制搭配。
- **压缩翻译 payload。** 当启用 `nitro.compressPublicAssets` 时，公共翻译 payload 会自动压缩。参见[性能指南](/guides/performance)。
- **`splitLocaleRoutes` 工具。** 从一个程序化列表同时构建 `pages` 与 `globalLocaleRoutes`（用于 `pages:extend` 场景），以路由名为键。参见[自定义本地化路由](/guides/custom-locale-routes#programmatic-routes-pagesextend--244)。
- **SEO 基础 URL 回退到 `site.url`。** 当未设置 `metaBaseUrl` 时，SEO 标签会回退到 `nuxt-site-config` 的 `site.url`（若存在），否则回退到请求来源。参见 [`metaBaseUrl`](/api/module-options)。

## 更新

- **Astro 适配器。** 路由上下文隔离，并接入 `numberFormats` 和 `datetimeFormats`。
- **React 与 Preact。** `I18nSwitcher` 现在会正确设置 `aria-haspopup` 与 `aria-expanded` 属性。
- **基准测试。** 性能基准测试改用基于 citty 的 CLI。
- **`dateBuild` 内容指纹。** 默认 `dateBuild` 现在是内容指纹，因此只有翻译实际发生变化时 payload 的 `?v=` 才会改变。

## 修复

- **路由。**
  - 本地化路由匹配现在能够正确处理带短横线、嵌套路径以及带参数段的路径。
  - 子路由为绝对路径时，会保留其嵌套父级。
  - `hreflang` 现在由语言的 `iso` 而不是路由 code 派生。
  - `no_prefix` 下的语言切换现在使用 replace 而不是 push 修改历史记录。
- **重定向。**
  - `autoDetectPath` 现在会作用于 cookie 与 `Accept-Language` 偏好的重定向。
  - `autoDetectPath: '/'` 下会保留 `localeRoutes` 别名。
- **翻译。**
  - 返回 `null` 的自定义复数函数现在会回退到默认复数规则。
  - 翻译 layer 合并时不再扁平化 dump。
  - 已禁用的语言不再出现在预合并的公共 payload 中。
  - HMR 会跳过无变化的文件写入，并在根级语言变更时并发重新合并。
- **切换器。** 会隐藏 `disabled` 的语言，并恢复 `customDisabledLinkStyle` 与激活样式的优先级。
- **模块。** 桥接了 unplugin 的 Vite 8 `Plugin` 类型，以兼容 Nuxt Kit。
- **SSR。** Node SSR 现在从 public payload 读取（不再使用 Rollup 的 `raw:` 导入）。

## 破坏性变更（v3.22.0）

- SSR chunk 已从 `useState('i18n-ssr-chunks')` 迁至 `nuxtApp.payload.data['i18n-ssr-chunks']`。
- `getAllTranslations()` 已从 `@i18n-micro/vue` 移除。请改用 `resolveTranslations()`、`getStorage()` 或 `getRouteCache()`。
- 默认 `dateBuild` 现在是内容指纹，因此升级后 payload 的 `?v=` 会变化一次。
