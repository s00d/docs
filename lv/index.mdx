Nuxt I18n Micro ir viegls, augstas veiktspējas i18n modulis Nuxt 3 un 4, kas paredzēts lieliem projektiem. Salīdzinājumā ar tradicionāliem i18n risinājumiem, piemēram, `@nuxtjs/i18n`, tas uztur zemu būvēšanas laiku, atmiņas patēriņu un pakotnes izmēru.

Lokalizētos maršrutus būvēšanas laikā ģenerē `@i18n-micro/route-strategy` un izpildlaikā atrisina `@i18n-micro/path-strategy`, tāpēc saites, pārslēdzējs, `hreflang` un novirzīšana pilnībā saskan ar maršrutētāju. Tulkojumi ir tikai JSON formātā, sadalīti starp koplietotiem saknes failiem un lapu failiem, kurus izstrādes serveris izveido jūsu vietā, ar iebūvētu HMR.

<CodeGroup>

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>
