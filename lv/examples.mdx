# 📚 Nuxt I18n Micro piemēri un lietojums

Šajā sadaļā ir sniegti dažādi piemēri, kas demonstrē, kā izmantot `Nuxt I18n Micro` tavā Nuxt.js lietotnē. Redzēsi, kā mainīt lokalizācijas, izmantot `<i18n-link>`, `<i18n-switcher>` un `<i18n-t>` komponentus, kā arī dinamiski apstrādāt tulkojumu atslēgas.

## 🛠️ Pamatiestatīšana

Šeit ir pamatiestatīšana, lai sāktu strādāt ar `Nuxt I18n Micro`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Lokalizācijas maiņa

### Lokalizāciju programmatiska maiņa

Šis piemērs demonstrē, kā programmatiski mainīt lokalizācijas, izmantojot pogas:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### JSON piemērs lokalizācijas maiņai

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### `<i18n-switcher>` komponenta izmantošana

Komponents `<i18n-switcher>` nodrošina nolaižamo sarakstu lokalizācijas maiņai ar pielāgojamiem uzrakstiem:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```


## 📝 Dinamisku atslēgu renderēšana no tulkojumu failiem

Dažos scenārijos vari vēlēties iterēt cauri dinamiskām atslēgām, kas saglabātas tavos tulkojumu failos, un nosacīti renderēt to vērtības. Zemāk redzamais piemērs demonstrē, kā to sasniegt, izmantojot `Nuxt I18n Micro`.

### Piemērs: Dinamisku atslēgu renderēšana

Šis piemērs ielādē atslēgu masīvu no konkrēta tulkojumu ceļa (šajā gadījumā `dynamic`) un iterē cauri tām. Katras atslēgas eksistence tiek pārbaudīta ar `$has`, pirms tās vērtība tiek renderēta ar `$t`.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Tulkojumu faila piemērs (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Piemērs: Dinamisku atslēgu renderēšana no objekta

Šajā piemērā mēs apstrādājam objektu, kas glabājas tavā tulkojumu failā. Mēs ielādējam un iterējam cauri objekta atslēgām, dinamiski renderējot gan atslēgu nosaukumus, gan saistītās vērtības.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Tulkojumu faila piemērs (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 `<i18n-t>` izmantošana tulkojumiem ar slotiem un interpolāciju

Komponents `<i18n-t>` ir noderīgs tulkojumu renderēšanai ar dinamisku saturu un HTML tagiem:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### JSON piemērs `<i18n-t>` komponentam

```json
{
  "greeting": "Welcome to the page"
}
```

### Ar interpolāciju

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### JSON piemērs interpolācijai

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 `$tc` izmantošana daudzskaitlim

Funkcija `$tc` no `Nuxt I18n Micro` apstrādā daudzskaitli, pamatojoties uz skaitu un lokalizācijas iestatījumiem. Tas ir noderīgi, lai dinamiski pielāgotu ziņojumus, kas ietver skaitļus, piemēram, priekšmetus, paziņojumus vai citas entītijas, kuru skaits var mainīties.

### Piemērs: `$tc` izmantošana daudzskaitlim

Šajā piemērā mēs parādām ziņojumu, kas norāda ābolu skaitu, izmantojot `$tc`. Tulkojuma atslēga apstrādā vairākas daudzskaitļa formas atkarībā no norādītā skaita.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### JSON piemērs daudzskaitlim

Šeit ir, kā vari definēt tulkojumu savā JSON failā, lai apstrādātu dažādas daudzskaitļa formas:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Skaidrojums

- **`$tc('apples', 0)`**: Atgriež pirmo formu, ko izmanto, kad skaits ir nulle (`"no apples"`).
- **`$tc('apples', 1)`**: Atgriež otro formu, ko izmanto, kad skaits ir viens (`"one apple"`).
- **`$tc('apples', 10)`**: Atgriež trešo formu ar skaita vērtību, ko izmanto, kad skaits ir divi vai vairāk (`"10 apples"`).

### Papildu piemērs ar sarežģītāku daudzskaitli

Ja tavai lietotnei jāapstrādā sarežģītāki daudzskaitļa noteikumi (piemēram, konkrēti gadījumi nullei, vienam, diviem, dažiem, daudziem, citiem), vari attiecīgi paplašināt tulkojuma virknes:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: Var tikt iestatīts, lai atgrieztu `"two apples"`.
- **`$tc('apples', 3)`**: Var atgriezt `"a few apples"` atkarībā no skaitam definētajiem noteikumiem.

## 🌐 `$tn` izmantošana skaitļu formatēšanai

Funkcija `$tn` formatē skaitļus atbilstoši pašreizējai lokalizācijai, izmantojot `Intl.NumberFormat` API. Tas ir noderīgi, lai attēlotu skaitļus veidā, kas atbilst lietotāja reģionālajiem iestatījumiem, piemēram, valūtai, procentiem vai citiem skaitļu formātiem.

### Piemērs: `$tn` izmantošana skaitļu formatēšanai

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ `$td` izmantošana datuma un laika formatēšanai

Funkcija `$td` formatē datumus un laikus atbilstoši pašreizējai lokalizācijai, izmantojot `Intl.DateTimeFormat` API. Tas ir noderīgi, lai attēlotu datumus un laikus formātos, kas lietotājam ir pazīstami, pamatojoties uz viņa lokalizācijas iestatījumiem.

### Piemērs: `$td` izmantošana datuma un laika formatēšanai

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ `$tdr` izmantošana relatīvā datuma formatēšanai

Funkcija `$tdr` formatē datumus kā relatīvos laikus (piemēram, "pirms 5 minūtēm", "pirms 2 dienām") atbilstoši pašreizējai lokalizācijai, izmantojot `Intl.RelativeTimeFormat` API. Tas ir noderīgi, lai attēlotu laika starpības attiecībā pret pašreizējo datumu un laiku.

### Piemērs: `$tdr` izmantošana relatīvā datuma formatēšanai

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
