# 📚 Nuxt I18n Micro piemēri un lietošana

Šī sadaļa sniedz dažādus piemērus, kas parāda, kā izmantot `Nuxt I18n Micro` jūsu Nuxt.js lietotnē. Jūs redzēsiet, kā pārslēgt lokāles, izmantot `<i18n-link>`, `<i18n-switcher>` un `<i18n-t>` komponentus un dinamiski apstrādāt tulkojumu atslēgas.

## 🛠️ Pamata iestatīšana

Šeit ir pamata iestatīšana, lai sāktu darbu ar `Nuxt I18n Micro`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Lokāles pārslēgšana

### Programmatiska lokāļu pārslēgšana

Šis piemērs parāda, kā programmatiski pārslēgt lokāles, izmantojot pogas:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### JSON piemērs lokāles pārslēgšanai

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### `<i18n-switcher>` komponenta izmantošana

Komponents `<i18n-switcher>` piedāvā nolaižamo izvēlni lokāles pārslēgšanai ar pielāgojamām etiķetēm:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 🌐 `<i18n-link>` lietošana lokalizētai navigācijai

```vue

    <i18n-link to="/about">{{ $t('about') }}</i18n-link>
    <i18n-link :to="{ name: 'index' }">{{ $t('home') }}</i18n-link>
```

### JSON piemērs navigācijas saitēm

```json

  "home": "Home"

```

### Piemērs ar aktīvās saites stilu

```vue
  </div>

```

### JSON piemērs aktīvās saites stilam

Šim scenārijam var izmantot to pašu JSON failu, kas iepriekšējā piemērā.

## 📝 Dinamisku atslēgu attēlošana no tulkojumu failiem

Dažos scenārijos varat vēlēties iterēt pa dinamiskām atslēgām, kas glabājas jūsu tulkojumu failos, un nosacīti attēlot to vērtības. Turpmākais piemērs parāda, kā to panākt, izmantojot `Nuxt I18n Micro`.

### Piemērs: dinamisku atslēgu attēlošana

Šis piemērs izgūst atslēgu masīvu no noteikta tulkojuma ceļa (šajā gadījumā `dynamic`) un iterē pa tām. Katras atslēgas eksistence tiek pārbaudīta, izmantojot `$has`, pirms tās vērtība tiek attēlota ar `$t`.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Tulkošanas faila piemērs (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Piemērs: dinamisku atslēgu attēlošana no objekta

Šajā piemērā mēs apstrādājam objektu, kas glabājas jūsu tulkojuma failā. Mēs izgūstam un iterējam pa objekta atslēgām, dinamiski attēlojot gan atslēgu nosaukumus, gan to saistītās vērtības.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Tulkošanas faila piemērs (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 `<i18n-t>` izmantošana tulkojumiem ar slotiem un interpolāciju

Komponents `<i18n-t>` ir noderīgs tulkojumu attēlošanai ar dinamisku saturu un HTML tagiem:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### JSON piemērs `<i18n-t>` komponentam

```json
{
  "greeting": "Welcome to the page"
}
```

### Ar interpolāciju

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### JSON piemērs interpolācijai

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 `$tc` izmantošana daudzskaitļa formām

Funkcija `$tc` modulī `Nuxt I18n Micro` apstrādā daudzskaitļa formas, balstoties uz skaitu un lokāles iestatījumiem. Tas ir noderīgi, lai dinamiski pielāgotu ziņojumus, kas ietver skaitus, piemēram, priekšmetus, paziņojumus vai citas entitātes, kuru skaits var mainīties.

### Piemērs: `$tc` izmantošana daudzskaitļa formām

Nākamajā piemērā mēs, izmantojot `$tc`, parādām ziņojumu, kas norāda ābolu skaitu. Tulkojuma atslēga apstrādā vairākas daudzskaitļa formas atkarībā no norādītā skaita.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### JSON piemērs daudzskaitļa formām

Lūk, kā jūs varat definēt tulkojumu savā JSON failā, lai apstrādātu dažādas daudzskaitļa formas:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Skaidrojums

- **`$tc('apples', 0)`**: atgriež pirmo formu, ko izmanto, kad skaits ir nulle (`"no apples"`).
- **`$tc('apples', 1)`**: atgriež otro formu, ko izmanto, kad skaits ir viens (`"one apple"`).
- **`$tc('apples', 10)`**: atgriež trešo formu ar skaita vērtību, ko izmanto, kad skaits ir divi vai vairāk (`"10 apples"`).

### Papildu piemērs ar sarežģītāku daudzskaitli

Ja jūsu lietotnei jāapstrādā sarežģītāki daudzskaitļa noteikumi (piemēram, konkrēti gadījumi nullei, vienam, diviem, dažiem, daudziem, citiem), attiecīgi varat paplašināt tulkojumu virknes:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: var iestatīt tā, lai atgrieztu `"two apples"`.
- **`$tc('apples', 3)`**: var atgriezt `"a few apples"`, atkarībā no skaita definētajiem noteikumiem.

## 🌐 `$tn` izmantošana skaitļu formatēšanai

Funkcija `$tn` formatē skaitļus atbilstoši pašreizējai lokālei, izmantojot `Intl.NumberFormat` API. Tas ir noderīgi, lai attēlotu skaitļus tā, lai tie atbilstu lietotāja reģionālajiem iestatījumiem, piemēram, valūtai, procentiem vai citiem skaitļu formātiem.

### Piemērs: `$tn` izmantošana skaitļu formatēšanai

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ `$td` izmantošana datuma un laika formatēšanai

Funkcija `$td` formatē datumus un laikus atbilstoši pašreizējai lokālei, izmantojot `Intl.DateTimeFormat` API. Tas ir noderīgi, lai attēlotu datumus un laikus formātos, kas lietotājam ir pazīstami, balstoties uz viņa lokāles iestatījumiem.

### Piemērs: `$td` izmantošana datuma un laika formatēšanai

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ `$tdr` izmantošana relatīvās datuma formatēšanai

Funkcija `$tdr` formatē datumus kā relatīvos laikus (piemēram, "pirms 5 minūtēm", "pirms 2 dienām") atbilstoši pašreizējai lokālei, izmantojot `Intl.RelativeTimeFormat` API. Tas ir noderīgi, lai attēlotu laika starpības attiecībā pret pašreizējo datumu un laiku.

### Piemērs: `$tdr` izmantošana relatīvās datuma formatēšanai

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
