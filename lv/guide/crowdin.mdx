[Crowdin](https://crowdin.com/) ir tulkošanas platforma: jūs augšupielādējat noklusējuma lokāles failus, tulkotāji strādā Crowdin, un jūs lejupielādējat pārējās lokāles atpakaļ. Modulis lasa vienkāršus JSON failus, tāpēc Crowdin CLI vajag tikai `crowdin.yml`, kas pareizi kartē `locales/` un `locales/pages/`. Moduļa iestatījumi nav jāmaina.

## crowdin.yml konfigurēšana {#configure-crowdin-yml}

```yml
# crowdin.yml
project_id_env: CROWDIN_PROJECT_ID
api_token_env: CROWDIN_PERSONAL_TOKEN
base_path: ./locales
preserve_hierarchy: true

files:
  - source: /en.json
    translation: /%two_letters_code%.json
  - source: /pages/**/en.json
    translation: /pages/**/%two_letters_code%.json
```

- `en` ir jūsu noklusējuma lokāle; tās faili ir avoti.
- `project_id_env` / `api_token_env` nolasa ID un marķieri no vides mainīgajiem, tāpēc neviens noslēpums netiek iekļauts repozitorijā.
- `preserve_hierarchy: true` saglabā `pages/<page>/` mapes nemainītas.
- Tulkotā faila nosaukumam jāsakrīt ar lokāles `code` failā `nuxt.config.ts`. `%two_letters_code%` der tādiem kodiem kā `de`; tādiem kodiem kā `pt-BR` izmantojiet `%locale%` vai kartējiet Crowdin kodus uz saviem ar `languages_mapping`.

## Augšupielāde un lejupielāde {#upload-and-download}

```bash
npm install -g @crowdin/cli

export CROWDIN_PROJECT_ID=123456
export CROWDIN_PERSONAL_TOKEN=...   # from Crowdin account settings

crowdin upload sources   # push locales/en.json and locales/pages/**/en.json
crowdin download         # write locales/de.json, locales/pages/**/de.json, ...
```

Palaidiet abas komandas CI, lai faili būtu aktuāli. Lejupielādētie faili nonāk jūsu repozitorijā tāpat kā manuāli rediģēti; nākamā būvēšana vai izstrādes pārlāde tos paņem.

## Pirms augšupielādes {#before-uploading}

Vispirms iztīriet avotus, lai tulkotāji nestrādātu ar nelietotām atslēgām: [`i18n-micro clean`](/lv/api/cli#clean) noņem neizmantotās atslēgas, [`i18n-micro check`](/lv/api/cli#check) pēc lejupielādes ziņo par trūkumiem. CLI nav savas Crowdin integrācijas: šī lapa apraksta atbalstīto veidu.
