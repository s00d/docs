---
title: "Lokalizēti ceļi"
description: "Piešķiriet lapai atšķirīgu URL katrai lokālei ar localeRoutes vai globalLocaleRoutes, ieskaitot dinamiskos parametrus un lokālei specifiskus slugus."
---

Pēc noklusējuma katra lokāle apkalpo lapu tajā pašā ceļā: `/en/about`, `/de/about`. Lokalizēti ceļi ļauj katrai lokālei izmantot savus vārdus, piemēram, `/de/ueber-uns`, kamēr lapas fails paliek tas pats. Tos iestata lapā ar `$defineI18nRoute` vai daudzām lapām uzreiz failā `nuxt.config.ts`.

## Lapā {#in-the-page}

```vue
<!-- pages/about.vue -->
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  localeRoutes: {
    de: '/ueber-uns',
    fr: '/a-propos',
  },
})
</script>
```

Ar `prefix_except_default` un `defaultLocale: 'en'` lapa atbild ceļos `/about`, `/de/ueber-uns` un `/fr/a-propos`. Lokāle bez ieraksta saglabā noklusējuma ceļu. Rakstiet ceļus bez lokāles koda: prefiksu pievieno [stratēģija](/lv/guide/strategy), un ceļš, kas sākas ar lokāles kodu, izraisa brīdinājumu. Ko vēl šis izsaukums pieņem, aprakstīts lapā [Lapas konfigurācija](/lv/guide/per-component-translations).

## nuxt.config failā {#in-nuxt-config}

[`globalLocaleRoutes`](/lv/api/module-options#globallocaleroutes) dara to pašu jebkurai lapai, izmantojot tās ceļu kā atslēgu (vai maršruta nosaukumu, ja rakstīts bez sākuma slīpsvītras):

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    globalLocaleRoutes: {
      '/about': { de: '/ueber-uns' },
      '/about/team': { de: '/ueber-uns/team' },
      '/admin': false, // not localized: one /admin route, no locale prefix
    },
  },
})
```

Ja lapa iestata `localeRoutes` un `globalLocaleRoutes` ir tāda pati atslēga, uzvar konfigurācijas ieraksts.

## Dinamiskie parametri {#dynamic-params}

Rakstiet parametrus jebkurā Nuxt formā: `[id]`, `[[page]]`, `[...slug]` vai `:id()`. Parametru nosaukumiem jāatbilst lapas failam.

```ts
// pages/products/[...slug].vue
$defineI18nRoute({
  localeRoutes: {
    en: '/our-products/[...slug]',
    de: '/unsere-produkte/[...slug]',
  },
})
```

Ligzdotās lapas pieņem absolūtu bērna ceļu (`/ueber-uns/team`) vai ceļu relatīvi pret vecāka lokalizēto ceļu (`team`).

## Saites uz lokalizētām lapām {#linking-to-localized-pages}

Saites tiek atrisinātas uz mērķa lokāles lokalizēto ceļu neatkarīgi no tā, vai nododat maršruta nosaukumu vai vienkāršu ceļu:

```vue
<template>
  <i18n-link :to="{ name: 'about' }">About</i18n-link>
  <i18n-link to="/about">About</i18n-link>
  <!-- de: both render /de/ueber-uns -->
  <NuxtLink :to="$localePath('/about', 'de')">Deutsch</NuxtLink>
</template>
```

Maršrutu nosaukumi tiek veidoti no faila ceļa (`pages/about/team.vue` ir `about-team`), ja vien neiestatāt to ar `definePageMeta({ name })`.

## Lokālei specifiski slugi {#per-locale-slugs}

Ja pats slugs atšķiras katrā lokālē (`/our-products/red-shoe` pret `/de/unsere-produkte/roter-schuh`), pēc datu ielādes norādiet valodu pārslēdzējam, kurus parametrus izmantot, ar `$setI18nRouteParams`:

```vue
<script setup lang="ts">
const { $setI18nRouteParams } = useNuxtApp()
const route = useRoute()

const { data: product } = await useFetch(`/api/products/${route.params.slug}`)

if (product.value) {
  $setI18nRouteParams({
    en: { slug: product.value.slugEn },
    de: { slug: product.value.slugDe },
  })
}
</script>
```

Tad `$switchLocalePath('de')` un `<i18n-switcher>` veido saiti uz `/de/unsere-produkte/roter-schuh`. Atslēgas ir lokāļu kodi, vērtības ir parametri pēc nosaukuma (kā lapas failā).

Pārslēdzējs izkārtojumā tiek renderēts pirms lapas asinhronais setup nonāk līdz šai vietai, tāpēc, kad renderēšana beidzas, modulis pārraksta `<i18n-switcher>` saites gan `app.vue`, gan lapā. Tad servera HTML, apmeklētājs bez JavaScript un pirmā klienta renderēšana sakrīt. Šim nolūkam iestatiet parametrus SSR laikā: ar `lazy` vai `server: false` saites mainās tikai pēc hidratācijas. Nuxt SSR straumēšana nosūta HTML, pirms parametri ir zināmi, tāpēc tās gadījumā saites pirmajā HTML saglabā paša URL parametrus.

Tiek pārrakstītas tikai paša pārslēdzēja saites. Manuāli rakstītai `$switchLocalePath` saitei jārenderējas pēc parametru iestatīšanas, tāpēc ievietojiet to lapā, kas tos iestata, arī pēc `await`. Izkārtojumā tā renderējas pirmā: tās servera HTML saglabā URL parametrus, un hidratācija brīdina par neatbilstību. Tur izmantojiet `<i18n-switcher>` ar tā slotiem un `custom*Style` props izskatam.

Parametri pieder lapai, kas tos iestatīja:

- Tie tiek atmesti, kad tiek apstiprināta navigācija uz citu ceļu, tāpēc katra lapa iestata savus. Atcelta navigācija tos atstāj vietā.
- Paņemiet `$setI18nRouteParams` no `useNuxtApp()` vai `useI18n()` funkcijā `setup`, arī tad, ja to izsaucat vēlāk `useAsyncData` apstrādātājā. Tur paņemta, funkcija zina savu lapu: ja apmeklētājs ir aizgājis, vēls izsaukums neko nedara.
- Ar `keepalive` lapa atgūst savus iestatītos parametrus, kad apmeklētājs atgriežas. `useI18nHead` dara to pašu.

## Maršruti, kas pievienoti pages:extend {#routes-added-in-pagesextend}

Maršrutiem, ko pievienojat `pages:extend` āķī, nav lapas faila, no kura nolasīt `$defineI18nRoute`, un vairāki no tiem bieži izmanto vienu ietinēja komponenti. Maršruts, kas pievienots bez `name`, saņem nosaukumu, ko Nuxt dotu tā ceļam (`/a/:id()` kļūst par `a-id`), tāpēc valodu saites to sasniedz, ja vien citam maršrutam jau nav šāda nosaukuma; tad piešķiriet tam skaidru `name`. Uzturiet vienu sarakstu un sadaliet to lapās un `globalLocaleRoutes` ar maršruta nosaukumu kā atslēgu, izmantojot `splitLocaleRoutes` no `@i18n-micro/utils/split-locale-routes` (pievienojiet pakotni savām atkarībām):

```ts
// nuxt.config.ts
import { splitLocaleRoutes } from '@i18n-micro/utils/split-locale-routes'

const dynamic = splitLocaleRoutes([
  { name: 'products-tag', path: '/products/:tag', file: '~/pages/_dynamic.vue', paths: { de: '/produkte/:tag' } },
  { name: 'internal', path: '/internal', file: '~/pages/_dynamic.vue', paths: false }, // not localized
])

export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  hooks: {
    'pages:extend'(pages) {
      pages.push(...dynamic.pages)
    },
  },
  i18n: {
    globalLocaleRoutes: dynamic.globalLocaleRoutes,
  },
})
```

Neievietojiet lokalizētus ceļus `route.meta`: tie nonāktu klienta maršrutu tabulā.
