Opcija `strategy` nosaka, vai lokalizācija parādās URL un kurām lokalizācijām. Izvēlieties to vienreiz, pirms publicējat URL: vēlāka maiņa maina katru saiti. Pēc tam modulis būvēšanas laikā ģenerē lokalizētos maršrutus, un `$localePath`, `<i18n-link>` un pārslēdzējs tos nolasa.

## Četras stratēģijas {#the-four-strategies}

![Lapa /about valodās en (noklusējums) un de katrā stratēģijā; tie paši URL ir uzskaitīti tekstā zemāk](/images/diagrams/strategies.svg)

**Tips** `Strategies` · **Noklusējums** `'prefix_except_default'`

URL maršrutēšanas stratēģija lokalizāciju prefiksiem.

- `'no_prefix'` — URL nav lokalizācijas; lokalizācija tiek glabāta sīkdatnē.
- `'prefix_except_default'` — prefikss visām lokalizācijām, izņemot noklusējuma.
- `'prefix'` — vienmēr prefikss, ieskaitot noklusējuma lokalizāciju.
- `'prefix_and_default'` — kā `prefix`, bet noklusējuma lokalizācija ir pieejama arī bez prefiksa.

URL lapai `about` ar `defaultLocale: 'en'` un lokalizācijām `en`, `de`:

| Stratēģija | Angļu | Vācu | Netiek apkalpots |
| --- | --- | --- | --- |
| `prefix_except_default` (noklusējums) | `/about` | `/de/about` | `/en` un `/en/about` ir 404 |
| `prefix` | `/en/about` | `/de/about` | `/about` pāradresē uz URL ar prefiksu |
| `prefix_and_default` | `/about` un `/en/about` | `/de/about` | — |
| `no_prefix` | `/about` | `/about` | lokalizācija nav URL |

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix',
  },
})
```

Stratēģija tiek fiksēta būvēšanas laikā: tās izpildlaika pārrakstīšana tiek ignorēta ar brīdinājumu ([Izpildlaika pārrakstīšana](/lv/guide/runtime-overrides)).

## Kuru izvēlēties {#which-one-to-choose}

- **`prefix_except_default`**: lielākajai daļai vietņu. Esošie URL bez prefiksa turpina darboties noklusējuma valodai.
- **`prefix`**: visas valodas ir līdzvērtīgas; `/` vienmēr ved uz sākumlapu ar prefiksu.
- **`prefix_and_default`**: jums vajag, lai darbotos gan `/en/...`, gan URL bez prefiksa, piemēram, pārejot no viena uz otru. URL bez prefiksa nekad netiek pāradresēti.
- **`no_prefix`**: lietotnēm aiz pieteikšanās vai vienam URL katrai lapai visās valodās. Lokalizācija nāk no sīkdatnes vai `?locale=`. Meklētājprogrammas redz vienu valodu katram URL, tāpēc `hreflang` alternatīvas netiek izvadītas.

Kā lokalizācija tiek izvēlēta URL un kad apmeklētājs tiek pāradresēts, aprakstīts sadaļā [Lokalizācijas noteikšana](/lv/guide/locale-detection).

## Ģenerētie maršruti {#generated-routes}

Būvēšanas laikā katra lapa saņem maršrutu ierakstus, kas vajadzīgi tās stratēģijai. Katrs ieraksts satur `meta.i18n = { name, locales }`: lapu, ko tas rāda, un lokalizācijas, ko tas apkalpo. Saites, pārslēgšanas un pāradresācijas tiek atbildētas no šiem ierakstiem, tāpēc URL, ko izsniedz modulis, vienmēr ir tāds, ko maršrutētājs apkalpo.

Lokalizācijām, kurām ir kopīgs lapas ceļš, ir viens kopīgs ieraksts, `/:locale(de|fr)/about`. Lokalizācija ar savu ceļu saņem savu ierakstu ar nosaukumu `localized-<page>-<locale>`:

```ts
// nuxt.config.ts: German has its own path for the about page
i18n: {
  globalLocaleRoutes: { about: { de: '/ueber-uns' } },
}
// prefix_except_default, locales en (default), de, fr:
// about                 /about
// localized-about       /:locale(fr)/about
// localized-about-de    /:locale(de)/ueber-uns
```

Pielāgotie ceļi, lokalizāciju saraksti katrai lapai un lapas izslēgšana no lokalizācijas aprakstīti sadaļās [Lokalizētie ceļi](/lv/guide/custom-locale-routes) un [Lapas konfigurācija](/lv/guide/per-component-translations). Prefikss `localized-` ir [`localizedRouteNamePrefix`](/lv/api/module-options#localizedroutenameprefix).

<Warning>

**Maršrutu nosaukumi tiek ģenerēti** — Neiekodējiet cieti `localized-…` nosaukumus izsaukumā `router.push({ name })`. Nododiet lapas pašas nosaukumu `$localeRoute` vai `<i18n-link>`; tie izvēlas pareizo ierakstu.

</Warning>

## Saite uz lapu kādā lokalizācijā {#linking-to-a-page-in-a-locale}

```vue
<script setup lang="ts">
const { localePath, localeRoute, switchLocalePath } = useI18n()

localePath({ name: 'about' }) // '/de/ueber-uns' while the page is German
localePath({ name: 'about' }, 'en') // '/about'
localePath('/about', 'de') // '/de/ueber-uns': a path is read as the page it shows
localeRoute({ name: 'products-id', params: { id: '42' } }, 'de') // resolved route: name, params, fullPath
switchLocalePath('fr') // the current page in French
</script>

<template>
  <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
  <NuxtLink :to="$switchLocalePath('de')">Deutsch</NuxtLink>
</template>
```

- Darbojas gan nosaukti maršruti, gan ceļi. Ceļš tiek salīdzināts ar ģenerētajiem maršrutiem, tāpēc tiek pieņemta jebkuras lokalizācijas tā forma.
- Lokalizācija, kas neapkalpo lapu (skatiet `locales` sadaļā [Lapas konfigurācija](/lv/guide/per-component-translations)), saista uz šīs lokalizācijas sākumlapu, nevis uz neesošu lapu.
- Parametri katrai lokalizācijai (tulkots identifikators) tiek nodoti caur `$setI18nRouteParams`, skatiet [Lokalizētie ceļi](/lv/guide/custom-locale-routes).

Signatūras ir sadaļā [Metodes](/lv/api/methods).

## `no_prefix` detaļas {#no_prefix-details}

- [`localeCookie`](/lv/api/module-options#localecookie) ar `no_prefix` pēc noklusējuma ir `'user-locale'`, tāpēc izvēle saglabājas pēc pārlādes.
- `$switchLocale('de')` ielādē vācu vārdnīcu un aizstāj pašreizējo vēstures ierakstu; URL nemainās.
- Pielāgotie ceļi katrai lokalizācijai joprojām darbojas: ar `globalLocaleRoutes: { about: { de: '/ueber-uns' } }` vācu lasītāji saņem `/ueber-uns`. Šis URL vienmēr tiek renderēts vāciski neatkarīgi no apmeklētāja preferences, un lapa, kas ierobežota līdz dažām lokalizācijām, tiek renderēta vienā no tām. Ceļš, kas ir kopīgs vairākām lokalizācijām (`en` un `de` abas uz `/page/:id`), tiek renderēts preferences valodā, ja tā ir viena no tām. Pati preference saglabājas: nākamā lapa atgriežas pie tās.
- [`noPrefixRedirect: true`](/lv/api/module-options#noprefixredirect) pāradresē tādas lapas sākotnējo ceļu, kurai ir pielāgots ceļš noklusējuma lokalizācijā: uz apmeklētāja lokalizācijas pielāgoto ceļu, citādi uz noklusējuma lokalizācijas ceļu (`/about` → `/about-us`, ja `en` ir `/about-us`, → `/ueber-uns` ar sīkdatni `de`). Lokalizācija bez sava pielāgotā ceļa paliek sākotnējā ceļā un tiek renderēta tur. Lapas ar parametriem netiek pāradresētas.

## Lietotnes bez `pages/` {#apps-without-pages/}

Ar `pages: false` nav lapu maršrutu, ko lokalizēt. Izmantojiet tikai saknes tulkojumu failus (`disablePageLocales: true`); noteikšana, sīkdatne un `$switchLocale` joprojām darbojas. Repozitorijā `test/fixtures/basic` variants `pages-false` ir strādājoša konfigurācija.
