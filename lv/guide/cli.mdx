`@i18n-micro/cli` pārvalda Nuxt projekta lokalizāciju failus. Tas nolasa `locales`, `defaultLocale`, `translationDir` un jūsu slāņus no `nuxt.config`, tāpēc tam nav vajadzīga sava konfigurācija.

![A terminal running i18n-micro check, which lists a missing, an undefined and four unused keys and fails, then extract, which adds the undefined key, then clean --dryRun, which lists the four keys it would remove](/images/cli/demo.gif)

| Komanda | Izmantojiet to, lai |
| --- | --- |
| `check` | Pārtrauktu būvi, ja lokalizāciju failos ir kas nepareizs |
| `translate` | Aizpildītu trūkstošās atslēgas ar tulkošanas servisu |
| `clean` | Noņemtu atslēgas, kuras nekas neizmanto |
| `rename` | Pārvietotu atslēgu vai visu nosaukumtelpu visur vienlaikus |

```bash
npm install -D @i18n-micro/cli
npx i18n-micro --help
```

Palaidiet to no lietotnes saknes vai norādiet uz to ar `--cwd`. Katrs katras komandas karodziņš ir aprakstīts [komandu atsaucē](/lv/api/cli).

<Tip>

**Pāriet no nuxt-i18n-micro-cli?** `@i18n-micro/cli` to aizstāj; izpildfaili `i18n-micro` un `i18n-micro-cli` paliek. Skatiet [veco komandu tabulu](#moving-from-nuxt-i18n-micro-cli).

</Tip>

## Izmantošana CI {#use-it-in-ci}

```bash
i18n-micro check
```

`check` ir vārti. Tas ziņo par:

| Pārbaude | Nozīme |
| --- | --- |
| `missing` | Noklusējuma lokalizācijas atslēga trūkst kādā lokalizācijā |
| `empty` | Vērtība ir `''`. Lietotne rāda tukšumu, nevis rezerves vērtību |
| `extra` | Lokalizācijai ir atslēga, kuras nav noklusējuma lokalizācijai |
| `placeholders` | `{name}` ir pazudis vai pievienots, vai daudzskaitlis zaudējis formas |
| `undefined` | Kods izmanto atslēgu, kuras nav noklusējuma lokalizācijai |
| `unused` | Nekas projektā neizmanto atslēgu |
| `duplicates` | Viens un tas pats teksts zem dažādām atslēgām. Pēc noklusējuma izslēgts: norādiet `--duplicates` |

- `--only missing,placeholders` palaiž dažas pārbaudes; `--only` nosaukta pārbaude, kuru nevarēja palaist, beidzas ar kļūdu.
- `--json` sniedz atskaiti rīkiem.
- `--ignore` izlaiž pirmkoda failus.
- Kamēr atslēgas tiek aprēķinātas izpildlaikā, `unused` tiek izlaists, un atskaitē norādīts, kāpēc.

Katra komanda beidzas ar vienu no trim kodiem, tāpēc konveijers var atšķirt problēmu ar jūsu tulkojumiem no problēmas ar rīku:

| Izejas kods | Nozīme |
| --- | --- |
| `0` | Nav par ko ziņot |
| `1` | Atradumi |
| `2` | Komandu nevarēja palaist: lietošanas kļūda, bojāts fails, neveiksmīgs pieprasījums |

Citas komandas, kas pelna CI soli:

```bash
i18n-micro format --check      # fails if a file is not formatted
i18n-micro lint                # stray spaces, empty values, your own regex rules
i18n-micro stats --baseRef main
```

## Lokalizāciju saskaņošana {#keep-locales-in-step}

| Komanda | Ko tā dara |
| --- | --- |
| `extract` | Uzskaita atslēgas, kuras kods izmanto, bet kurām vēl nav teksta. Noklusējuma teksts, kā `$t('key', {}, 'Welcome')`, nonāk noklusējuma lokalizācijā. |
| `sync` | Noņem atslēgas, kuru nav noklusējuma lokalizācijai. Vispirms izmēģiniet `--dryRun`. |
| `clean` | Noņem atslēgas, kuras nekas neizmanto. Vispirms izmēģiniet `--dryRun`. |
| `search` | Atrod atslēgas un vērtības un parāda, kur katra atslēga tiek izmantota. |
| `stats` | Pabeigtība katrai lokalizācijai; `--baseRef main` salīdzina ar git atsauci. |

`sync` apstājas tāpat kā `clean`, ja tas noņemtu atslēgu, kuras neizmantošanu nevar pierādīt, un arī tad, ja noklusējuma lokalizācijai nav ar ko salīdzināt. Ja nav ko noņemt, tas nekad neapstājas, tāpēc `$t(item.label)` vien nav iemesls `--force`.

<Note>

`extract` un `sync` nekad neieraksta `''` atslēgai bez tulkojuma. Atslēga paliek neesoša, tāpēc izpildlaikā darbojas `fallbackLocale` un `check` par to ziņo. Tukša virkne būtu definēta vērtība un rādītu tukšumu.

</Note>

### Ko komandas nolasa {#what-the-commands-read}

`check`, `extract`, `sync`, `clean`, `search` un `rename` nolasa pirmkodu visā projektā, nevis fiksētā mapju sarakstā:

- **Nolasa:** veidnes un skriptus ar parsētāju, `.html` un Pug kā tekstu, katru slāni un mapes ārpus saknes, uz kurām norāda aizstājvārds vai `components`.
- **Izlaiž:** `node_modules`, būves izvadi un lokalizāciju failus. Pievienojiet savus ar `--ignore 'legacy/**,*.stories.ts'`.
- **Testu kods** tiek uzskatīts par izmantošanu, tāpēc `clean` un `check --only unused` saglabā atslēgu, kuru nolasa tikai tests. Tas nekad nepievieno atslēgu: `extract` šādas atslēgas izlaiž, un `check` neziņo par tām kā nedefinētām.

Testu kods nozīmē saknes mapes `tests`, `test`, `__tests__`, `e2e`, `cypress` un `playwright`, kā arī `.spec` un `.test` JavaScript un TypeScript failus (`.ts`, `.tsx`, `.mts`, `.js`, `.jsx`, `.mjs` un līdzīgus) jebkurā vietā. No tālāk minētajām šaubām atbrīvotas ir tikai saknes mapes: `pages/tests/[id].vue` ir lapa kā jebkura cita, un tāpat arī `public/` un minificēti faili, kuru kods nav daļa no lietotnes.

Komandas atpazīst:

- `$t`, `$ts`, `$tc`, `$has` un `$_t(route)`;
- `t()` no `useI18n()` un `useTranslationServerMiddleware()`;
- `<i18n-t keypath>` veidnēs un JSX, un `<i18n-group prefix>`;
- aizstājvārdus, piemēram, `const { t: tr } = useI18n()`.

### Kā `clean` izlemj {#how-clean-decides}

`clean` labāk atstās mirušu atslēgu nekā noņems dzīvu. Atslēga paliek, ja ir patiess kaut viens no šiem nosacījumiem:

- izsaukums to izmanto, vai atslēgu zem vai virs tās;
- virkne kodā ir tai vienāda: `const key = 'menu.home'`, `<Item label="menu.home" />`;
- JSON, YAML vai Markdown fails projektā to satur;
- aprēķinātai atslēgai ir statisks sākums, kas to aptver: `` $t(`status.${state}`) `` saglabā visu zem `status.`;
- slānis to definē.

`clean` apstājas, neko nemainot, ja tas nevar zināt, un uzskaita iemeslus:

- atslēga ir pilnībā aprēķināta, kā `$t(name)`, `<i18n-t :keypath="name" />` vai `<i18n-t v-bind="props" />`;
- `$t` tiek nodots kā vērtība, kā `items.map($t)`;
- funkcija ar nosaukumu `t` saņem aprēķinātu argumentu un nāk no parametra, importa vai izsaukuma: tā var būt īstās funkcijas ietvars. Funkcija, ko definē tas pats fails, netiek skaitīta, jo ietvaram būtu savs izsaukums iekšienē;
- pirmkoda failu nevar parsēt;
- neviens fails vispār neizmanto nevienu atslēgu, kas parasti nozīmē, ka tas meklē nepareizā vietā;
- lokalizācijas fails ir simboliskā saite ārpus projekta, tāpēc to var nolasīt cita lietotne.

<Steps>

<Step title="Priekšskatījums">

Palaidiet `i18n-micro clean --dryRun` un pārskatiet, ko tas uzskaita.

</Step>

<Step title="Atslēgu aizsardzība">

Saglabājiet atslēgas, kas tikai izskatās neizmantotas, ar `--exclude '^errors\.'`.

</Step>

<Step title="Noņemšana">

Palaidiet to vēlreiz ar `--force`.

</Step>

</Steps>

## Trūkstošo atslēgu tulkošana {#translate-missing-keys}

```bash
i18n-micro translate --dryRun                     # keys and characters per locale, nothing sent
export I18N_TRANSLATE_TOKEN=...                   # or put it in .env
i18n-micro translate --service deepl --locale de,fr
```

- `translate` aizpilda atslēgas, kas trūkst vai ir tukšas; `--replace` pārtulko visu no jauna.
- Vietturi un daudzskaitļa formas ir aizsargātas. Tulkojums, kas zaudējis vietturi, netiek ierakstīts: atslēga tiek uzskaitīta, un komanda beidzas ar `1`.
- Katra partija tiek saglabāta pirms nākamā pieprasījuma nosūtīšanas, tāpēc kļūme maksā tikai neveiksmīgo pieprasījumu.

| `--service` | Serviss | `--token` | Noderīgas `--options` |
| --- | --- | --- | --- |
| `ai` | Vercel AI Gateway, OpenAI, Anthropic vai jebkurš ar OpenAI saderīgs serveris | API atslēga vai `AI_GATEWAY_API_KEY`, `OPENAI_API_KEY`, `ANTHROPIC_API_KEY` | `provider`, `model`, `baseUrl`, `maxTokens` |
| `azure` | Azure Translator | Abonementa atslēga | `region` |
| `deepl` | DeepL, ieskaitot Free atslēgas | Autentifikācijas atslēga | `formality`, `glossaryId`, `context` |
| `google` | Google Cloud Translation v2 | API atslēga | `model` |
| `libretranslate` | LibreTranslate | Neobligāts | `baseUrl` |
| `yandexcloud` | Yandex Cloud Translate | API atslēga vai IAM marķieris ar `authScheme:Bearer` | `folderId`, `model` |

Opcijas ir `key:value` pāri: `--options provider:openai,model:gpt-4o-mini`. Visi servisi pieņem arī `baseUrl`, `retries`, `retryDelayMs` un `timeoutMs`. Par tulkošanas pieprasījumu jau var būt izrakstīts rēķins, tāpēc tas tiek atkārtots tikai pēc `429` vai `503`, un ne tad, ja serviss lūdz gaidīt ilgāk par minūti.

<Warning>

Karodziņi ir redzami čaulas vēsturē un procesu sarakstos, tāpēc nododiet marķieri ar vides mainīgo. CLI maskē to, ko zina kā slepenu, visur, kur to izdrukā, ieskaitot `--debug`: marķierus, pakalpojumu sniedzēju atslēgas, Basic akreditācijas datus un jūsu konfigurētā URL vaicājumu un akreditācijas datus. Serveris, kas pārformatē atslēgu pirms tās atkārtošanas, ir ārpus tā sniedzamības, tāpēc ar neveiksmīgas palaišanas žurnāliem rīkojieties uzmanīgi.

</Warning>

Serviss `ai` ievēro glosāriju. Ja `.i18n-glossary.json` pastāv, tas tiek izmantots bez karodziņa; `--glossaryFile` izvēlas citu failu.

```json .i18n-glossary.json
{ "entries": [{ "source": "Cart", "target": "Warenkorb", "to": "de" }] }
```

## Cietkodēta teksta pārvēršana atslēgās {#turn-hardcoded-text-into-keys}

```bash
i18n-micro text-to-i18n --dryRun   # list what would change
i18n-micro text-to-i18n            # rewrite the templates
```

```vue
<!-- before -->
<h1>Welcome to our site</h1>
<!-- after -->
<h1>{{ $t('pages.index.welcome-to-our') }}</h1>
```

Tiek pārrakstītas tikai paša projekta `.vue` veidnes, nevis slāņa vai aizstājvārda mērķa veidnes. Katrs pārrakstītais fails pirms ierakstīšanas tiek parsēts vēlreiz. Šie gadījumi tiek uzskaitīti un saglabā savu tekstu:

- teksts `.ts` failos un skriptos, jo `$t` nav pieejams visur;
- teksts blakus marķējumam vai interpolācijai, piemēram, `<p>Hello <b>world</b> today</p>`: pusi teikuma nevar iztulkot atsevišķi;
- ģenerēta atslēga, kas sadurtos ar citu, kā tas var notikt vecāklapai un tās bērnam;
- zināma atslēga, ko nevar ievietot pēdiņās.

<Warning>

Vispirms veiciet commit un pārskatiet atšķirības.

</Warning>

## Atslēgas pārdēvēšana {#rename-a-key}

```bash
i18n-micro rename --from common.save --to actions.save
i18n-micro rename --from settings --to account.settings   # a whole namespace
```

`rename` rediģē sintakses koku, tāpēc komentāri un nesaistītas virknes paliek nemainītas, un tiek ievēroti aizstājvārdi un `:keypath`. Slāņa paša fails nekad netiek mainīts. Tas brīdina par to, ko nevar pārrakstīt, un atstāj to neskartu:

- aprēķināta atslēga zem vecā nosaukuma;
- katra vienkārša virkne, kas tam vienāda;
- Pug veidne;
- pirmkods slānī vai mapē ārpus projekta.

`--to` jābūt atslēgai, ko var uzrakstīt kodā: bez pēdiņām, bez atpakaļvērstās slīpsvītras, bez tukša segmenta, bez `__proto__`.

## Failu apmaiņa ar tulkotājiem {#exchange-files-with-translators}

```bash
i18n-micro export --format csv
i18n-micro import --format csv --dryRun
```

**`export`** ieraksta katru katras lokalizācijas atslēgu, ieskaitot netulkotās, ar noklusējuma lokalizācijas tekstu kā avotu: `Source` kolonna CSV, `#.` komentārs PO.

- Bez `--dir` PO nonāk `pots` un CSV — `csv_exports`.
- Tas reģistrē ierakstīto failā `.i18n-export.json` izvades mapē. Tas apstājas, ja fails kopš tā laika ir mainījies un satur tulkojumus, kuru nav lokalizāciju failos, ieskaitot fuzzy PO ierakstus; `--force` tos pārraksta. Parasti lokalizāciju failu labojumi to neaptur.

**`import`** apvieno, izlaiž tukšas šūnas un izlaiž PO ierakstus, kas atzīmēti kā `fuzzy`.

- Atslēga, kas pārrakstītu vērtību, vai vērtība virs veselas atslēgu grupas tiek uzskaitīta un izlaista, un komanda beidzas ar `1`.
- Tas apstājas ar izeju `2`, ja katalogs atrodas negaidītā vietā, ja lapas katalogu pēdējais eksports neierakstīja, ja CSV ir nevietā esoša pēdiņa vai ja lapas ieraksts ir ar `disablePageLocales`.

Tulkošanas platformai izmantojiet tās CLI: [Crowdin](/lv/guide/crowdin) iestatījums sinhronizē JSON failus, ieskaitot lapu failus.

## Sinhronizācija ar savu galapunktu {#sync-with-your-own-endpoint}

`sync-remote` apmainās ar globālajiem lokalizāciju failiem ar jūsu uzturētu HTTP galapunktu. Lapu faili paliek lokāli, un komanda to paziņo. Aprakstiet galapunktu failā `.i18n-remote.json`:

```json .i18n-remote.json
{ "url": "https://translations.example.com", "path": "translations" }
```

Galapunkts atbild uz `GET` un `PUT` ar `{ locale: messages }` objektu. Autentificējieties ar `auth: { username, password }` vai ievietojiet bearer marķieri `I18N_REMOTE_TOKEN`.

| | Pull | Push |
| --- | --- | --- |
| Kas tiek pārvietots | Aizpilda to, kā jums nav, un saglabā atslēgas, kas ir tikai jums | Nosūta projekta paša atslēgas, nevis slāņa atslēgas, un izlaiž jūsu tukšās vērtības |
| Konflikti | Atslēga, kas atšķiras abās pusēs: nekas netiek ierakstīts, izeja `1`; `--force` ņem attālo vērtību | PUT aizstāj dokumentu, tāpēc push vispirms nolasa galapunktu un apstājas ar izeju `1`, ja tas satur tekstu, kura jums nav; `--force` to pārraksta. Galapunktam, kas atbild ar `404`, nav ko zaudēt |
| `--dryRun` | Nolasa no galapunkta, uzskaita izmaiņas, neko neieraksta | Paziņo, kas tiktu nosūtīts, nesazinoties ar galapunktu |

Lokalizācija, kuru neesat konfigurējis, tiek izlaista, un tukša attālā vērtība neko nenotīra.

## Pāreja no nuxt-i18n-micro-cli {#moving-from-nuxt-i18n-micro-cli}

| Vecā komanda | Tagad |
| --- | --- |
| `validate` | `check` |
| `diff` | `check --only missing` |
| `check-duplicates` | `check --only duplicates` |
| `export-csv`, `import-csv` | `export --format csv`, `import --format csv` |
| `--potsDir`, `--csvDir` | `--dir` |
| `estimate` | `translate --dryRun` |
| `glossary` | Rediģējiet `.i18n-glossary.json`; `translate` to nolasa pats |
| `backup`, `restore` | Git, kas jau glabā jūsu lokalizāciju failus |
| `init` | `nuxi init`, pēc tam pievienojiet `nuxt-i18n-micro` sarakstam `modules` |
| `split` | Noņemts: modulis nenolasa sadalītus failus |
| `optimize` | `check --only duplicates` |
| `replace-values` | Jūsu redaktors vai `sed` |
| `stats --full` | `stats`; [DevTools](/lv/guide/devtools) ir sīkāka informācija |
| `search --hardcodedOnly` | `text-to-i18n --dryRun` |
| `search --preferUnused`, `--onlyVue` | Noņemts |
| `lint` noteikumi `no-html-tags`, `no-special-chars`, `no-mixed-case`, `no-missing-punctuation`, `no-inconsistent-pluralization` | Noņemti: tie atzīmēja parastu tekstu. Ja vajag, uzrakstiet `customRegexRules` ierakstu |
| `text-to-i18n --extractOnlyDirs`, `--extractOnlyPatterns`, `--verbose` | Noņemti: kods nekad netiek pārrakstīts |
| `--logLevel verbose` | Noņemts: tas neko nedarīja |

**Noņemtie servisi:** `googlefree`, `yandex` (izmantojiet `yandexcloud`), `ibm`, `lingvatranslate`, `modernmt`, `lilt`, `unbabel`, `reverso`, `baidu`, `papago`, `tencent`, `systran`, `mymemory`.

**Noņemtie `sync-remote` tipi:** `github`, `gitlab`, `crowdin`, `lokalise`, `tolgee`, `weblate`. Izmantojiet platformas CLI vai `custom`, kam vairs nav vajadzīgs `type`.

### Mainītā uzvedība {#changed-behaviour}

- `extract` un `sync` vairs neieraksta `''`. Atslēgas paliek neesošas, un `check` par tām ziņo. `extract` ieraksta atslēgu tikai tad, ja kods norāda tās tekstu.
- `extract` ieraksta lapu atslēgas `locales/pages/<route name>/`, kur modulis tās nolasa, un Nuxt 4 skenē `app/`. Pārvietojiet visu no tādām direktorijām kā `pages/_about` un `pages/blog_`, un izdzēsiet lieku `locales/pages/<locale>.json`.
- `translationDir` no `nuxt.config` tiek ievērots; iepriekš katra komanda klusi izmantoja `locales`.
- Bez `defaultLocale` noklusējums ir `en`, kā modulī, un tiek ievērots `DEFAULT_LOCALE`. Agrāk tā bija pirmā lokalizācija.
- `check` un `sync` izmanto noklusējuma lokalizāciju kā atskaites punktu un pārbauda lapu failus. `"a.b"` un `a: { b }` tiek uzskatīti par vienu atslēgu.
- `clean` saglabā atslēgu, kas izmantota jebkur, jebkurā tvērumā, un apstājas, ja izmantošanu nevar pierādīt. `--include` un `--exclude` izvēlas, ko drīkst noņemt.
- `sync` apstājas tāpat, un arī tad, ja noklusējuma lokalizācijai nav atslēgu, ar ko salīdzināt. `--force` to ignorē. Tas apstājas arī tad, ja `DEFAULT_LOCALE` izvēlējās citu atskaites punktu nekā `nuxt.config`.
- Gari karodziņi ar vienu domuzīmi un lieki argumenti ir kļūdas: `clean -dryRun` vairs nepalaiž `clean`.
- Tikai lasāmu failu vai failu, kas nav UTF-8, nevar saglabāt: komanda apstājas, pirms kaut ko maina. Šāda faila nolasīšana ir pieļaujama. Atkārtota atslēga, atslēga ar nosaukumu `__proto__` un vesels skaitlis virs 2^53 aptur komandu, jo saglabāšana tos zaudētu.
- Karodziņš, kam vajadzīga vērtība un kam seko cits karodziņš, ir kļūda; vērtībai, kas sākas ar domuzīmi, rakstiet `--flag=--value`. Būla karodziņš pieņem tikai `true` vai `false`.
- `export` apstājas, nevis pārraksta tulkojumus, kas nekad nav importēti.
- Izejas kodi ir `0`, `1` un `2`; agrāk kļūmes bija `1`, bet `diff` un `check-duplicates` vienmēr `0`.
- `lint --fix` vairs neatstāj `.bak` failus.
- Saglabāšana saglabā faila atkāpes, rindu beigas, beigu jaunās rindas zīmi, simbolisko saiti un cieto saiti, un neskar failus, kurus tā nemainīja.
- Kļūdaini uzrakstīts vai noņemts karodziņš tagad ir kļūda, nevis tiek klusi ignorēts.
- Ceļi, piemēram, `--dir`, ir relatīvi projektam, nevis čaulai.
- `ai` vairs neielādē `@ai-sdk/*` pakotnes: izmantojiet `provider` `gateway`, `openai` vai `anthropic`, vai `baseUrl` ar OpenAI saderīgam serverim.
