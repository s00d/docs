Šī lapa pārvērš Nuxt lietotni bez i18n par tulkotu lapu ar valodas pārslēdzēju. Tā ir vajadzīga vienreiz, projekta sākumā. Rezultātā jums būs lokalizēti URL (`/about`, `/de/about`), viens JSON fails katrai lokalei un lapai, un `$t` jūsu veidnēs.

## Instalēšana {#install}

Modulim nepieciešams Nuxt 3.18 vai jaunāks (darbojas arī Nuxt 4) un Node 20 vai jaunāks.

<CodeGroup>

```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>

## Konfigurējiet lokales {#configure-the-locales}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', displayName: 'English' },
      { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
      { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
    ],
    defaultLocale: 'en',
  },
})
```

Tā ir visa konfigurācija, kas vajadzīga pirmajai lietotnei. Noklusējuma vērtības nodrošina:

- `strategy: 'prefix_except_default'`: noklusējuma lokalei nav prefiksa (`/about`), pārējām ir (`/de/about`). Skatiet [Maršrutēšanas stratēģijas](/lv/guide/strategy).
- `translationDir: 'locales'`: tulkojumu faili atrodas `locales/` projekta saknē, arī ar Nuxt 4 `app/` struktūru.
- `meta: true`: `hreflang`, canonical un `og:locale` tagi, kā arī `lang` un `dir` uz `<html>`. Skatiet [SEO](/lv/guide/seo).
- Apmeklētājs, kas atver `/`, tiek novirzīts uz valodu, ko pieprasa viņa pārlūks (`Accept-Language`). Skatiet [Lokales noteikšana](/lv/guide/locale-detection).

`iso` ir valodas tags, ko izmanto SEO tagos; `code` ir tas, kas parādās URL. Visas opcijas ir uzskaitītas lapā [Moduļa opcijas](/lv/api/module-options).

## Pievienojiet tulkojumu failus {#add-translation-files}

Palaidiet izstrādes serveri ar `nuxt dev`. Kad Nuxt atrisina lapas, modulis izveido tukšu `{}` failu katrai lokalei un lapai, kurai tā nav (izslēdziet to ar [`disableWatcher`](/lv/api/module-options#disablewatcher)):

```text
locales/
├── en.json            # root: keys every page can use
├── de.json
├── fr.json
└── pages/
    ├── index/         # pages/index.vue
    │   ├── en.json
    │   ├── de.json
    │   └── fr.json
    └── about/         # pages/about.vue
        ├── en.json
        ├── de.json
        └── fr.json
```

Aizpildiet saknes failu un lapas failu:

```json
// locales/en.json
{ "nav": { "home": "Home", "about": "About" } }
```

```json
// locales/pages/index/en.json
{ "welcome": "Welcome, {name}!", "items": "no items | one item | {count} items" }
```

Lapa redz saknes atslēgas un savas atslēgas; konflikta gadījumā noteicošs ir tās pašas fails. Mapju nosaukumi seko maršruta nosaukumam (`pages/articles/[id].vue` ir `locales/pages/articles-id/`). [Tulkojumu faili](/lv/guide/translations) apraksta struktūru, rezerves vērtības un ielādi.

## Izmantojiet `$t` lapā {#use-$t-on-a-page}

```vue
<!-- pages/index.vue -->
<script setup lang="ts">
const { t, tc, getLocale } = useI18n()

const title = t('nav.home') // 'Home'
</script>

<template>
  <h1>{{ $t('welcome', { name: 'Ada' }) }}</h1>
  <!-- Welcome, Ada! -->
  <p>{{ $tc('items', 3) }}</p>
  <!-- 3 items -->
  <p>{{ getLocale() }}</p>
  <!-- en -->
</template>
```

- Veidnēs katra palīgfunkcija ir pieejama ar `$` (`$t`, `$tc`, `$localePath`, …).
- `<script setup>` iekšienē `useI18n()` atgriež tās pašas palīgfunkcijas ar `$` un bez tā (`t` un `$t` ir viena funkcija). Tā tiek importēta automātiski.
- `{name}` vietturi tiek aizpildīti no parametru objekta. Daudzskaitļa formas tiek atdalītas ar `|`; skaits izvēlas formu (0, 1, tad pēdējā visam, kas lielāks).

Visas palīgfunkcijas ir uzskaitītas lapā [Metodes](/lv/api/methods).

## Saites starp lapām un lokales pārslēgšana {#link-between-pages-and-switch-locale}

```vue
<!-- components/AppHeader.vue -->
<template>
  <nav>
    <i18n-link :to="{ name: 'index' }">{{ $t('nav.home') }}</i18n-link>
    <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
    <i18n-switcher />
  </nav>
</template>
```

- [`<i18n-link>`](/lv/components/i18n-link) ir `NuxtLink`, kas norāda uz lapu pašreizējā lokalē: lapā `/de` saite "about" ved uz `/de/about`.
- [`<i18n-switcher>`](/lv/components/i18n-switcher) ir iespējoto lokaļu nolaižamais saraksts; tas atstāj apmeklētāju tajā pašā lapā.
- Savām pogām izsauciet `$switchLocale('de')`, kas pāriet uz pašreizējo lapu vāciski un atceras izvēli. Parastam `NuxtLink` izmantojiet `$localePath({ name: 'about' })` vai `$switchLocalePath('de')`.

## Pārbaudiet {#check-it}

Palaidiet `nuxt dev` un atveriet:

| URL | Rāda |
| --- | --- |
| `/` | Angļu sākumlapu (vai novirzīšanu uz `/de`, ja jūsu pārlūks dod priekšroku vācu valodai) |
| `/de` | Vācu sākumlapu |
| `/de/about` | Vācu lapu "about" |
| `/en/about` | 404: ar `prefix_except_default` noklusējuma lokalei nav prefiksa |

JSON failu izmaiņas tiek piemērotas atvērtajā lapā bez pārlādes.
