title: "Pielāgota lokales noteikšana"
description: "Izvēlieties lokali paši — pēc domēna, galvenes vai lietotāja profila — ar servera spraudni un useI18nLocale().setLocale()."
---

Iebūvētā noteikšana nolasa URL, sīkfailu un `Accept-Language`. Ja lokale ir atkarīga no kaut kā cita — domēna, ģeogrāfiskas galvenes, ko iestata jūsu CDN, lietotāja profila —, iestatiet to paši spraudnī, kas darbojas pirms i18n spraudņa. Pēc tam modulis ielādē šīs lokales tulkojumus un izmanto to novirzīšanai tieši tā, it kā būtu to noteicis pats. Noteikumi, kas nosaka, kad izvēlētā lokale ir svarīgāka par URL, ir lapā [Lokales noteikšana](/lv/guide/locale-detection); šī lapa parāda, kā pievienot savu avotu.

## Iestatiet lokali servera spraudnī {#set-the-locale-in-a-server-plugin}

```ts
// plugins/i18n-locale.server.ts
export default defineNuxtPlugin({
  name: 'i18n-custom-locale',
  enforce: 'pre',
  order: -10, // before the i18n plugin (order -5)
  setup() {
    const { setLocale } = useI18nLocale()
    const host = (useRequestHeaders(['host']).host ?? '').split(':')[0]! // without the port

    if (host.endsWith('.de')) setLocale('de')
    else if (host.endsWith('.fr')) setLocale('fr')
  },
})
```

`setLocale(code)` ieraksta lokales stāvokli (`useState('i18n-locale')`) un, ja ir konfigurēts lokales sīkfails, arī sīkfailu. Izmantojiet to, nevis rakstiet `useState` vai `useCookie` paši. Nododiet tikai iespējotu lokaļu kodus.

Saglabājiet spraudni kā `.server.ts`, ja tas nolasa pieprasījuma galvenes: pārlūkā to nav. `.client.ts` spraudnis ir īstā vieta tikai pārlūka avotiem, piemēram, `localStorage`.

## Izslēdziet iebūvēto Accept-Language soli {#turn-off-the-built-in-accept-language-step}

Jūsu spraudnis un `Accept-Language` var nesakrist. Lai lemtu tikai jūsu kods (kā arī URL un sīkfails), izslēdziet galveni:

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    autoDetectLanguage: false,
  },
})
```

[`autoDetectLanguage`](/lv/api/module-options#autodetectlanguage) kontrolē tikai galvenes soli. URL un derīgs sīkfails joprojām tiek ņemti vērā.

## Kas notiek tālāk {#what-happens-next}

`setLocale` ietekme ir atkarīga no [stratēģijas](/lv/guide/strategy):

| Stratēģija | `setLocale('de')` ietekme spraudnī |
| --- | --- |
| `no_prefix` | Lapa tiek renderēta vāciski; URL nemainās. |
| `prefix`, `prefix_except_default` | Ceļā bez prefiksa, kur [`autoDetectPath`](/lv/api/module-options#autodetectpath) atļauj novirzīšanu (pēc noklusējuma tikai `/`), serveris atbild ar `302` uz vācisko URL. URL ar lokales prefiksu to saglabā. |
| `prefix_and_default` | Nav novirzīšanas: URL bez prefiksa ir derīga noklusējuma lokales lapa. |

Ar prefiksu stratēģijām lokale URL ir lietotāja izvēle, un jūsu spraudnis to nepārraksta. Izņēmums ir `autoDetectPath: '*'`: tad serveris pārvieto URL ar prefiksu pēc sīkfaila un `Accept-Language` un ignorē stāvokli, bet `setLocale()` arī ieraksta sīkfailu, ja tāds ir konfigurēts, tāpēc no nākamā pieprasījuma jūsu spraudņa izvēle var novirzīt URL ar prefiksu. Saglabājiet `'/'` vai izmantojiet `'no_prefix'`, ja skaidri norādītiem lokales URL jābūt noteicošiem. Izmantojiet spraudni, lai izvēlētos, kur apmeklētājs nonāk, nevis lai pārrakstītu saites, kurām viņš sekojis.

## Ievērojiet lietotāja izvēlēto lokali {#respect-a-locale-the-user-picked}

Kad lietotājs pārslēdz valodu, pārslēgšana ieraksta sīkfailu. Izlaidiet savu noteikšanu, ja jau ir derīga izvēle:

```ts
// plugins/i18n-locale.server.ts
import { detectLocaleFromAcceptLanguage } from '@i18n-micro/utils/accept-language'

export default defineNuxtPlugin({
  name: 'i18n-custom-locale',
  enforce: 'pre',
  order: -10,
  setup() {
    const { getPreferredLocale, setLocale, validLocales } = useI18nLocale()
    if (getPreferredLocale()) return // valid state or cookie: keep it

    const country = useRequestHeaders(['x-country'])['x-country']
    if (country === 'JP') return setLocale('ja')

    const header = useRequestHeaders(['accept-language'])['accept-language']
    setLocale(detectLocaleFromAcceptLanguage(header, validLocales))
  },
})
```

`getPreferredLocale()` atgriež stāvokli vai sīkfailu tikai tad, ja tā ir iespējota lokale, tāpēc novecojis sīkfails neaptur noteikšanu. `detectLocaleFromAcceptLanguage` ir salīdzinātājs, kas ņem vērā q-vērtības un ko izmanto pats modulis (instalējiet `@i18n-micro/utils`, lai to importētu); `setLocale(null)` neko nedara.

## Viens domēns katrai lokalei {#one-domain-per-locale}

Ja katram domēnam jāapkalpo savas lokales, spraudnis nav vajadzīgs: piešķiriet katrai lokalei `baseUrl`, iestatiet `baseDefault: true` katra domēna noklusējuma lokalei un būvējiet vienreiz (statiskai vietnei joprojām katram domēnam palaiž `nuxi generate`). Skatiet [Slāņi un domēni](/lv/guide/layers#multiple-domains).
