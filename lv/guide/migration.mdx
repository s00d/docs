Šajā lapā parādīts, kā `@nuxtjs/i18n` lietotne atbilst nuxt-i18n-micro: opcijas, palīgfunkcijas un failu struktūra. Izmantojiet to, kad nomaināt moduli esošā lietotnē. Jūs saglabājat savus URL (stratēģiju nosaukumi ir tie paši) un pārvietojat tulkojumus JSON failos katrai lapai.

<Tip>

**Jaunināt pašu nuxt-i18n-micro?** — Skatiet [Jaunināšana](/lv/guide/upgrade).

</Tip>

## Moduļa nomaiņa {#swap-the-module}

```bash
npm uninstall @nuxtjs/i18n
npm install nuxt-i18n-micro
```

```ts
// nuxt.config.ts — before
export default defineNuxtConfig({
  modules: ['@nuxtjs/i18n'],
  i18n: {
    locales: [
      { code: 'en', language: 'en-US', file: 'en.json' },
      { code: 'de', language: 'de-DE', file: 'de.json' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    langDir: 'locales',
    detectBrowserLanguage: { useCookie: true, cookieKey: 'i18n_redirected', redirectOn: 'root' },
  },
})
```

```ts
// nuxt.config.ts — after
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    translationDir: 'locales',
    localeCookie: 'i18n_redirected',
    autoDetectPath: '/',
  },
})
```

## Opcijas {#options}

| `@nuxtjs/i18n` | nuxt-i18n-micro |
| --- | --- |
| `locales[].code` | `locales[].code` |
| `locales[].language` (`iso` pirms v9) | `locales[].iso` |
| `locales[].name` | `locales[].displayName` |
| `locales[].dir` | `locales[].dir` |
| `locales[].domain` | `locales[].baseUrl` (izcelsme ar shēmu) |
| `locales[].domainDefault` | `locales[].baseDefault` |
| `differentDomains`, `multiDomainLocales` | nav vajadzīgi: `baseUrl` vien maršrutē pēc resursdatora, skatiet [Slāņi un domēni](/lv/guide/layers#multiple-domains) |
| `locales[].file` / `files`, `langDir`, `lazy` | `translationDir`; faili tiek atrasti pēc nosaukuma un vienmēr ielādēti katrai lapai |
| `defaultLocale`, `strategy` | tie paši nosaukumi, tās pašas četras vērtības |
| `baseUrl` | `metaBaseUrl` |
| `customRoutes: 'config'` + `pages` | `globalLocaleRoutes` |
| `detectBrowserLanguage: false` | `redirects: false` (bez novirzīšanas) vai `autoDetectLanguage: false` (ignorēt galveni) |
| `detectBrowserLanguage.useCookie` / `cookieKey` | `localeCookie: '<name>'` (`null` izslēdz sīkdatni) |
| `detectBrowserLanguage.redirectOn: 'root'` | `autoDetectPath: '/'` (noklusējums) |
| `detectBrowserLanguage.redirectOn: 'no prefix'` | `autoDetectPath: 'no_prefix'` |
| `detectBrowserLanguage.redirectOn: 'all'` | `autoDetectPath: '*'` |
| `vueI18n` konfigurācijas fails (`fallbackLocale`, `numberFormats`, `datetimeFormats`) | `fallbackLocale`, `numberFormats`, `datetimeFormats` sadaļā `i18n` |

Nav `alwaysRedirect`: ja sīkdatne ir iestatīta, `/` tai seko katrā apmeklējumā. Pilns saraksts ir [Moduļa opcijas](/lv/api/module-options); noteikšanas noteikumi ir lapā [Lokalizācijas noteikšana](/lv/guide/locale-detection).

## Palīgfunkcijas un kompozīcijas funkcijas {#helpers-and-composables}

| `@nuxtjs/i18n` / vue-i18n | nuxt-i18n-micro (veidne / `useI18n()`) |
| --- | --- |
| `const { t } = useI18n()` | `const { t } = useI18n()`, `$t` veidnēs |
| `t('key', count)`, `tc` | `$tc('key', count)` |
| `te('key')` | `$has('key')` |
| `n(value, 'currency')`, `d(date, 'short')` | `$tn(value, 'currency')`, `$td(date, 'short')` |
| — | `$tdr(date)`: relatīvais laiks ("pēc 3 dienām") |
| `locale.value` | `$getLocale()` |
| `locales.value` | `$getLocales()` |
| `setLocale('de')` | `$switchLocale('de')` |
| `useLocalePath()('about')` | `$localePath({ name: 'about' })` |
| `useLocaleRoute()` | `$localeRoute()` |
| `useSwitchLocalePath()('de')` | `$switchLocalePath('de')` |
| `useSetI18nParams()` | `$setI18nRouteParams()` |
| `useLocaleHead()` | automātiski ar `meta: true`; [`useLocaleHead`](/lv/composables/useLocaleHead) pielāgotām head sadaļām |
| `defineI18nRoute({ paths: { de: '/ueber-uns' }, locales: [...] })` | `$defineI18nRoute({ localeRoutes: { de: '/ueber-uns' }, locales: [...] })` |
| `<NuxtLinkLocale to="about">` | `<i18n-link :to="{ name: 'about' }">` |
| `<i18n-t>` | `<i18n-t>` (sloti aizpilda `{name}` vietturus) |
| `$i18n` servera maršrutos | `useTranslationServerMiddleware(event)`, skatiet [Servera maršruti un API](/lv/guide/server-side-translations) |

`useI18n()` tiek importēts automātiski. `$defineI18nRoute` jāsaglabā `$`: būve nolasa šo izsaukumu. Visas palīgfunkcijas: [Metodes](/lv/api/methods).

## Tulkojumu faili {#translation-files}

Pārvietojiet viena lielā faila atslēgas katrai lokalizācijai uz saknes failu un pa vienam failam katrai lapai:

```text
locales/
├── en.json              # keys used on many pages (nav, footer)
├── de.json
└── pages/
    ├── index/en.json    # keys of pages/index.vue
    └── about/en.json    # keys of pages/about.vue
```

Visu glabāšana saknes failos arī darbojas un ir ātrākais pirmais solis. Iestatiet `disablePageLocales: true`, līdz tos sadalāt. Skatiet [Tulkojumu faili](/lv/guide/translations).

### Ziņojumu sintakse {#message-syntax}

| vue-i18n | nuxt-i18n-micro |
| --- | --- |
| `{name}` nosaukta interpolācija | tāpat |
| `car \| cars` (2 formas: 1 → pirmā) | formas tiek izvēlētas pēc skaita no 0: rakstiet `no cars \| one car \| {count} cars` |
| `@:other.key` saistītie ziņojumi | netiek atbalstīti: atkārtojiet tekstu vai komponējiet kodā |
| `@.upper:` modifikatori | netiek atbalstīti: formatējiet kodā vai izmantojiet `<i18n-t>` |
| `{'@'}` burtiskās ekranēšanas | nav vajadzīgas: tiek aizstāti tikai `{word}` marķieri |
| JS/TS ziņojumu faili | tikai JSON |

Daudzskaitļa noteikumu var aizstāt ar opciju [`plural`](/lv/api/module-options#plural).

## Pārbaude pēc pārejas {#check-after-the-switch}

- Katrs jūsu iepriekšējais URL joprojām tiek atrisināts; stratēģiju nosaukumi sakrīt, pielāgotie ceļi pāriet uz `globalLocaleRoutes` vai `$defineI18nRoute`.
- `hreflang`, kanoniskais URL un `og:locale` ir pieejami uzreiz ar `meta: true`; noņemiet manuāli rakstītos.
- JSON parsēšanas kļūda reģistrē faila ceļu; trūkstoša atslēga izstrādes režīmā reģistrē brīdinājumu pārlūka konsolē.
