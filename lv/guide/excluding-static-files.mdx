---
title: "Ceļu izslēgšana"
description: "Izslēdziet lapas un failus no lokalizācijas maršrutēšanas ar excludePatterns un uzziniet, kuri ceļi jau ir izslēgti."
---

Dažiem ceļiem nekad nedrīkst būt lokalizācijas prefiksa vai lokalizācijas pāradresācijas: administrēšanas sadaļai, veselības pārbaudei, ģenerētai plūsmai. `excludePatterns` tos atzīmē, un iebūvētais saraksts jau aptver Nuxt iekšējos ceļus un izplatītākos statiskos failus. Izslēgta lapa saglabā tieši to ceļu, kuru jūs uzrakstījāt, un joprojām tiek renderēta ar `$t`.

## Ceļa izslēgšana {#exclude-a-path}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    excludePatterns: [
      '/admin', // /admin and everything below it
      '/preview-*', // glob over the whole path
    ],
  },
})
```

Ar šo konfigurāciju `pages/admin/index.vue` atbild tikai uz `/admin`; nav `/de/admin`, un `/admin` nekad netiek pāradresēts uz `/de/admin`.

## Šablonu sintakse {#pattern-syntax}

Šabloni tiek salīdzināti ar ceļu bez `app.baseURL`:

| Šablons | Atbilst | Neatbilst |
| --- | --- | --- |
| `'/admin'` | `/admin`, `/admin/users` | `/administrator`, `/de/admin` |
| `'/preview-*'` | `/preview-1`, `/preview-a/b` | `/de/preview-1` |
| `'/file-?'` | `/file-a` | `/file-ab` |
| `/^\/v\d+\//` | `/v2/docs` | `/docs` |

Virkne bez `*` vai `?` atbilst ceļam un veseliem segmentiem zem tā. Ar `*` (jebkura rakstzīmju virkne, ieskaitot slīpsvītras) vai `?` (viena rakstzīme) tai jāatbilst visam ceļam. Vienmēr sāciet virknes ar `/`.

## Kas jau ir izslēgts {#what-is-excluded-already}

Šie nekad nesaņem lokalizācijas maršrutus vai pāradresācijas, bez jebkādas konfigurācijas:

- `/api` un `/_nuxt`, kā arī viss zem tiem;
- tulkojumu maršruts, pēc noklusējuma `/_locales` ([`apiBaseUrl`](/lv/api/module-options#apibaseurl));
- jebkurš ceļš ar segmentu, kas sākas ar `__` (`/__nuxt_content`, `/en/__og-image__`);
- `/sitemap*.xml`, `/robots.txt`, `/favicon.ico`, `/apple-touch-icon*.png`, `/manifest.json`, `/sw.js`, `/workbox-*.js`;
- jebkurš ceļš, kura pēdējais segments beidzas ar statiska faila paplašinājumu: `xml txt ico json js css png jpg jpeg gif svg webp avif pdf wasm map mp4 webm mp3 zip gz woff woff2 ttf eot`. Lapu identifikatori ar punktiem, piemēram, `/user/john.doe`, un `.html` ceļi paliek lapas.

## Ko dara izslēgšana {#what-an-exclusion-does}

- **Maršruti:** lokalizēti varianti netiek ģenerēti; lapa tiek saglabāta, kā uzrakstīta.
- **Pāradresācijas un 404:** servera pāradresācijas spraudnis un klienta pāradresācijas starpprogrammatūra izlaiž šo ceļu.
- **Priekšrenderēšana:** atbilstošie ceļi tiek noņemti no priekšrenderēšanas maršrutu saraksta.

Tā neaptur i18n servera starpprogrammatūru noteikt pieprasījuma lokalizāciju un neaptur lapu izmantot tulkojumus. Lai lapa paliktu lokalizēta, bet bez SEO tagiem, izmantojiet `disableMeta` ([Lapas konfigurācija](/lv/guide/per-component-translations#turn-off-seo-tags)). Lai vienu lapu atstātu nelokalizētu no `nuxt.config.ts` pēc ceļa, `globalLocaleRoutes: { '/admin': false }` ([Lokalizētie ceļi](/lv/guide/custom-locale-routes#in-nuxt-config)) dara to pašu maršrutēšanai.
