description: "Mainiet noklusējuma lokalizāciju, rezerves lokalizāciju vai atspējotās lokalizācijas katrai vienas būves instancei, izmantojot vides mainīgos vai runtimeConfig."
---

Izpildlaika pārrakstījumi ļauj vienam būves artefaktam darboties ar atšķirīgiem lokalizāciju iestatījumiem katrā vidē vai katram nomniekam bez pārbūvēšanas. Varat mainīt noklusējuma lokalizāciju, rezerves lokalizāciju un to, kuras lokalizācijas ir atspējotas. Maršrutēšana, novirzīšana, atveidošana un servera palīgfunkcijas izmanto pārrakstītās vērtības, un tāpat dara arī pārlūks serverī atveidotā lapā.

## Pārrakstījumu iestatīšana ar vides mainīgajiem {#set-overrides-with-environment-variables}

```bash
NUXT_I18N_DEFAULT_LOCALE=de \
NUXT_I18N_FALLBACK_LOCALE=en \
NUXT_I18N_DISABLED_LOCALES=fr,it \
node .output/server/index.mjs
```

| Mainīgais | Aizstājvārds |
| --- | --- |
| `NUXT_I18N_DEFAULT_LOCALE` | `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE` |
| `NUXT_I18N_FALLBACK_LOCALE` | `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE` |
| `NUXT_I18N_DISABLED_LOCALES` (atdalīti ar komatiem) | `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES` |

Serveris tos nolasa vienreiz startēšanas brīdī; lai piemērotu izmaiņas, restartējiet to. Serverī atveidotā lapā pārlūks saņem atrisinātās vērtības no servera. Ar `ssr: false` servera atveidošanas nav un pārlūkam nav vides: tur darbojas tikai `runtimeConfig.public.i18nRuntime`, un pārlūks reģistrē tālāk aprakstītos brīdinājumus.

## Pārrakstījumu iestatīšana runtimeConfig {#set-overrides-in-runtimeconfig}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

Vērtība, kas iestatīta `runtimeConfig.public.i18nRuntime`, ir prioritāra pār `NUXT_I18N_*` mainīgo tam pašam laukam.

Nejauciet to ar būves laika mainīgo `DEFAULT_LOCALE`, kas būvēšanas laikā aizstāj `defaultLocale` un kam nav vajadzīgs izpildlaika atbalsts.

## Ko var un ko nevar mainīt {#what-can-and-cannot-change}

| Iestatījums | Izpildlaikā |
| --- | --- |
| `defaultLocale` | Jā ar `prefix` un `no_prefix`. Ar `prefix_except_default` un `prefix_and_default` tas tiek fiksēts būvēšanas laikā (tā lapas ir maršruti bez prefiksa); pārrakstījums tiek ignorēts ar brīdinājumu. |
| `fallbackLocale` | Jā. |
| `disabledLocales` | Papildina būvēšanas laikā atspējotās lokalizācijas; nekad neiespējo kādu no jauna. Būves noklusējumu nevar atspējot ar `prefix_except_default` / `prefix_and_default`. |
| `strategy` | Nē. Izpildlaika stratēģija tiek ignorēta ar brīdinājumu; būvējiet vienu artefaktu katrai stratēģijai. |

Nederīgas vērtības nekad nesabojā lietotni. Katrs gadījums reģistrē vienu brīdinājumu katram servera procesam:

- visu lokalizāciju atspējošana tiek ignorēta;
- `defaultLocale`, kas nav iespējota, pāriet uz pirmo iespējoto lokalizāciju;
- `fallbackLocale`, kas nav iespējota, saglabā būves vērtību, ja tā ir iespējota, citādi rezerves lokalizācijas nav.

## Faktiskās konfigurācijas nolasīšana {#read-the-effective-config}

```vue
<script setup lang="ts">
const { $getI18nConfig } = useNuxtApp()
const config = $getI18nConfig() // build config with overrides applied
</script>
```

Uzskatiet to par tikai lasāmu: serverī to koplieto visi pieprasījumi, un izstrādes režīmā tā ir iesaldēta; pārlūka kopija nav iesaldēta. Importējot konfigurāciju no `#build/i18n.strategy.mjs`, tiek iegūtas būves vērtības bez pārrakstījumiem.

## Atspējotās lokalizācijas un statiskie faili {#disabled-locales-and-static-files}

Izpildlaikā atspējota lokalizācija savos maršrutos un kravas maršrutā atbild ar 404, taču tās kravas faili joprojām atrodas `.output/public/_locales/`, un statisko failu serveris tos atgriež. Ja šiem failiem nedrīkst būt piekļuves, atspējojiet lokalizāciju būvēšanas laikā ar `disabled: true`.
