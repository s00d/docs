Režīmā `nuxt dev` modulis pievieno divus atkļūdošanas palīglīdzekļus: **i18n Micro** cilni Nuxt DevTools tulkojumu failu pārlūkošanai un rediģēšanai un Vue DevTools inspektoru dzīvajai lokalizācijai un ielādētajām vārdnīcām. Abi pastāv tikai izstrādes režīmā un neko nepievieno produkcijas būvēm. Nuxt cilnei pietiek ar ieslēgtiem Nuxt DevTools; Vue inspektoram vajadzīgs arī Vue DevTools pārlūka paplašinājums.

## Nuxt DevTools cilne {#nuxt-devtools-tab}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  devtools: { enabled: true }, // the tab is registered only when DevTools are on
})
```

Atveriet Nuxt DevTools (`Shift + Alt + D`) un izvēlieties **i18n Micro**. Cilne parāda:

- katru JSON failu zem `locales/` (saknē un `pages/`) katrā slānī, kā arī saknes failus no `additionalTranslationDirs`;
- redaktoru katram failam; **Save** ieraksta failu atpakaļ diskā, un izstrādes serveris pārlādē tulkojumus;
- faila **Export** / **Import** kā JSON un **Stats** ar atslēgu skaitu un tulkojumu pārklājumu;
- atrisināto moduļa opciju konfigurācijas skatu;
- **Translate**, kas aizpilda trūkstošās atslēgas ar mašīntulkošanas dzinēju, kuru konfigurējat cilnes iestatījumos.

Saglabāšana raksta tikai esošus `.json` failus jūsu tulkojumu direktorijās. Ja fails pastāv vairākos slāņos, tiek rakstīta projekta kopija.

## Vue DevTools inspektors {#vue-devtools-inspector}

Ar Vue DevTools pārlūka paplašinājumu modulis reģistrē i18n inspektoru (pašreizējā lokalizācija, maršruta gabals, ielādētās atslēgas) un laika joslu ar lokalizāciju pārslēgšanu, gabalu ielādi un trūkstošām atslēgām.

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    debug: true, // also log every $t / $ts / $tc call on the timeline
    // vueDevtools: false, // turn the inspector off, keep the Nuxt tab
  },
})
```

[`vueDevtools`](/lv/api/module-options) pēc noklusējuma ir `true`. `debug: true` ir daudzvārdīgs; izmantojiet to īsām sesijām.
