# 🔄 Migrācija no `nuxt-i18n` uz `Nuxt I18n Micro`

## Kurš ceļvedis jums nepieciešams?

| Jūs migrējat no…                | Ceļvedis                                            |
| -------------------------------------- | ------------------------------------------------ |
| `@nuxtjs/i18n` (uz vue-i18n balstīts modulis) | **Šī lapa**                                    |
| `nuxt-i18n-micro` v2.x                 | [Atjaunināšana no v2.x uz v3.x](/migration/v2-to-v3) |

## Kāpēc migrēt?

- **Uzlabota veiktspēja**: ~51% ātrāki būvējumi un ~54% mazāks būvēšanas atmiņas patēriņš pret `@nuxtjs/i18n` **v10.6** mūsu [etalonu fixture](/guides/performance-results)
- **Vienkāršota konfigurācija**: racionalizēta iestatīšana ar saprātīgiem noklusējumiem
- **Labāka resursu pārvaldība**: optimizēta lielu tulkojumu failu apstrāde

## Galvenās atšķirības

| Funkcija                 | `nuxt-i18n`                      | `Nuxt I18n Micro`                         |
| ----------------------- | -------------------------------- | ----------------------------------------- |
| Tulkojumu faili       | JS/TS/JSON, ielādēti caur `vueI18n` | Tikai JSON, automātiski ģenerēti izstrādes vidē          |
| Maršrutu ģenerēšana        | Izpildlaikā                          | Būvēšanas laikā (`@i18n-micro/route-strategy`) |
| Tulkojumu ielāde     | Iepakoti JS iekšpusē                  | Lēni ielādēts JSON uz katru lapu                 |
| Lokāles stāvoklis            | `useI18n()` no `vue-i18n`      | `useI18nLocale()` komponējamā funkcija              |
| `detectBrowserLanguage` | Atbalstīts                        | Tā vietā izmantojiet `autoDetectLanguage`          |

## Soli pa solim

### 1. Instalēšana

```bash
npm install nuxt-i18n-micro
```

### 2. Konfigurācijas atjaunināšana

**Pirms (nuxt-i18n):**

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'fr', iso: 'fr-FR' },
    ],
    defaultLocale: 'en',
    vueI18n: './i18n.config.js',
    detectBrowserLanguage: { useCookie: true },
  },
})
```

**Pēc (Nuxt I18n Micro v3):**

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
    localeCookie: 'user-locale',
    autoDetectLanguage: true,
  },
})
```

### 3. Pārkārtot tulkojumu failus

Pārvietojiet tulkojumus uz mapi `locales` JSON formātā. Šeit ir projekta struktūras paraugs:

```text
my-app/
├── locales/
│   ├── en.json
│   ├── ru.json
│   ├── de.json
│   └── pages/
│       ├── index/
│       │   ├── en.json
│       │   ├── ru.json
│       │   └── de.json
│       └── page/
│           ├── en.json
│           ├── ru.json
│           └── de.json
├── pages/
│   ├── index.vue
│   └── page.vue
├── server/
└── nuxt.config.ts
```

### 4. Navigācijas atjaunināšana

```diff
- <nuxt-link :to="{ name: 'index' }">Home</nuxt-link>
+ <NuxtLink :to="$localeRoute({ name: 'index' })">Home</NuxtLink>
+ <!-- or use the built-in component -->
+ <i18n-link :to="{ name: 'index' }">Home</i18n-link>
```

### 5. SEO atjaunināšana

Noņemiet jebkādas manuālas SEO konfigurācijas no `nuxt-i18n`. Nuxt I18n Micro automātiski ģenerē `hreflang`, kanoniskos URL un Open Graph tagus, kad ir iestatīts `meta: true`.

### 6. Testēšana

Rūpīgi testējiet tulkojumus, lokāles pārslēgšanu, pāradresācijas un SEO meta tagus.

## 🛡️ Biežas problēmas un problēmu novēršana

### ❌ Tulkojumu faili netiek ielādēti

Pārliecinieties, ka tulkojumu faili ir pareizajā mapē un atbilst JSON formātam. Pārbaudiet, ka `translationDir` atbilst jūsu failu atrašanās vietai.

### ⚠️ "Maršruts nav atrasts" kļūdas

Pārbaudiet, ka visi lokāles kodi masīvā `locales` ir pareizi un ka maršruti ir pareizi iestatīti.

### 🏷️ Trūkstoši SEO tagi

Pārbaudiet, ka ir iestatīts `meta: true` un katrai lokālei ir derīgs `iso` kods.

### 🔄 Hidratācijas nesakritības

Ja izmantojat `no_prefix` stratēģiju, iestatiet lokāli servera spraudnī ar `order: -10`, izmantojot `useI18nLocale().setLocale()`, lai nodrošinātu, ka serveris un klients saskan par lokāli. Skatiet [Pielāgota valodas noteikšana](/guides/custom-language-detection).

### 🍪 Pāradresācijas nedarbojas

Priedēkļa stratēģijām pārliecinieties, ka ir iestatīts `localeCookie: 'user-locale'`. Bez sīkfaila servera pāradresācijas spraudnim nav veida, kā atcerēties lietotāja vēlamo lokāli starp lapas pārlādēm.
