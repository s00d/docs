Šis laidiens pievieno **`useI18nHead`** — lapas līmeņa composable i18n SEO pārrakstīšanai papildus iebūvētajam `02.meta` spraudnim. Pielāgojiet `hreflang`, canonical, `og:url` un Open Graph tagus katram maršrutam bez pielāgota meta spraudņa vai `meta: false`.

## Kas jauns? {#what’s-new}

### `useI18nHead` composable {#usei18nhead-composable}

Izsauciet `useI18nHead` jebkurā lapā, ja `meta: true` (noklusējums). Modulis apvieno jūsu ievadi pēc `useLocaleHead` katrā maršruta atjauninājumā:

```vue
<script setup lang="ts">
useI18nHead(() => ({
  meta: [{ property: 'og:title', content: article.value?.title }],
  replace: {
    canonical: article.value?.canonicalUrl,
    ogUrl: article.value?.canonicalUrl,
    hreflang: localeCodes.map((locale) => ({
      rel: 'alternate',
      hreflang: locale,
      href: article.value!.locales[locale]!,
    })),
    ogAlternates: localeCodes,
  },
}))
</script>
```

Atbalsta statiskus objektus, reaktīvus getterus, `meta` / `link` pievienošanu, `replace` iebūvētajām grupām un `disable` automātiski ģenerēto tagu noņemšanai. Skatiet [`useI18nHead`](/lv/composables/useI18nHead).

### `mergeI18nHead` utilīta (`@i18n-micro/utils`) {#mergei18nhead-utility-@i18n-micro/utils}

No ietvara neatkarīgā apvienošanas loģika atrodas `@i18n-micro/utils/merge-i18n-head` — to izmanto `02.meta` spraudnis, un to var testēt izolēti. Tipi (`I18nHeadInput`, `I18nHeadLink`, `I18nHeadMeta`) tiek eksportēti no `@i18n-micro/types`.

### Spraudņu integrācija {#plugin-integration}

- **`02.meta`** — apvieno `useLocaleHead` izvadi ar lapas stāvokli no `useI18nHead`, izmantojot `useHead`
- **`01.plugin`** — atiestata lapas pārrakstījumus, mainoties maršruta nosaukumam, ar `resetPageHead()` (koplietots stāvoklis ar composable)

### Dokumentācija un testi {#documentation-&-tests}

- Jauns ceļvedis: [`useI18nHead`](/lv/composables/useI18nHead) ar CMS/rakstu piemēriem
- Atjaunināti [SEO](/lv/guide/seo) un [`useLocaleHead`](/lv/composables/useLocaleHead) — kad izmantot kuru API
- Playwright + Vitest pārklājums: SSR, SPA navigācija, pārlādēšana, `nuxi generate`, daļējas alternatīvas, `x-default`, reaktīva ielāde klientā

## Tipiski lietošanas gadījumi {#typical-use-cases}

| Scenārijs                                    | Pieeja                                                         |
| -------------------------------------------- | -------------------------------------------------------------- |
| Blogs/CMS ar daļējiem tulkojumiem            | `replace.hreflang` + `replace.ogAlternates` no API lokalēm     |
| Pielāgots canonical no CMS                   | `replace.canonical` + `replace.ogUrl`                          |
| Tikai OG mērķlapai                           | `meta: [{ property: 'og:title', ... }]` — saglabājiet moduļa hreflang |
| Lapā nav hreflang                            | `disable: ['hreflang', 'x-default']`                           |
| Aizstāt pielāgotu spraudni (`i18nManualHreflang`) | `useI18nHead` katrā satura lapā + `meta: true`            |

**JSON-LD** paliek `useHead({ script: [...] })` — `useI18nHead` neģenerē strukturētos datus.

## Nesaderīgas izmaiņas {#breaking-changes}

Nav standarta `nuxt.config` lietojumam. Jaunais composable un utils apakšceļš ir papildinājumi.

## Kāpēc tas ir svarīgi {#why-it-matters}

- **Nav vajadzīgs pielāgots meta spraudnis** CMS ierakstiem, ziņām vai ceļvežiem ar URL katrai lokalei
- **Viens konveijers** — moduļa noklusējumi + lapas pārrakstījumi vienā `useHead` izsaukumā
- **Tipdrošs** — `I18nHeadInput` palīgfunkcijām, piemēram, `buildArticleHead(content)`

Pilns izmaiņu žurnāls tiks publicēts kopā ar laidienu [GitHub](https://github.com/s00d/nuxt-i18n-micro/blob/main/CHANGELOG.md).
