**Datums**: 2025-10-30

**Versija**: `v2.0.0`

![v2.0.0 release](/images/2.0.0.png)

Mēs ieviešam servera puses HMR tulkojumu failiem izstrādes režīmā. Kad mainās JSON tulkojums, servera kešatmiņa atzīmē par nederīgām tikai ietekmētās atslēgas, un nākamie pieprasījumi uzreiz saņem svaigus datus — bez restartēšanas.

## Kas jauns? {#what’s-new}

- Servera puses HMR tulkojumu failiem
- Tūlītēja kešatmiņas invalidācija katrai lapai/lokalizācijai
- Nevainojama izstrādātāja pieredze, rediģējot saturu

## Kā tas darbojas {#how-it-works}

- Novērotājs `src/runtime/server/plugins/watcher.dev.ts` uzrauga `<rootDir>/<translationDir>/**/*.json`
- Lapu faili (piem., `pages/<page>/<locale>.json`) invalidē `_locales:merged:<page>:<locale>`
- Saknes līmeņa faili (piem., `<locale>.json`) invalidē visas apvienotās atslēgas attiecīgajai lokalizācijai
- Automātiski reģistrēts no `src/module.ts` izstrādes režīmā, kad `experimental.hmr !== false`

## Konfigurācija {#configuration}

```ts
export default defineNuxtConfig({
  i18n: {
    experimental: { hmr: true }, // default in dev
  },
})
```
