description: "Komponents <i18n-switcher> ir iespējoto lokalizāciju nolaižamā izvēlne, kurā katrs ieraksts ved uz pašreizējo lapu attiecīgajā lokalizācijā."
---

`<i18n-switcher>` attēlo pogu ar aktīvo lokalizāciju un visu iespējoto lokalizāciju nolaižamo izvēlni, ieskaitot aktīvo. Izmantojiet to kā gatavu valodu izvēlni; ja jums vajag citu marķējumu, izveidojiet savu no [`$getLocales`](/lv/api/methods#$getlocales) un [`$switchLocalePath`](/lv/api/methods#$switchlocalepath). Katrs ieraksts ved uz pašreizējo lapu attiecīgajā lokalizācijā.

## Rekvizīti un sloti {#props-and-slots}

| Rekvizīts | Tips | Noklusējums | Apraksts |
| --- | --- | --- | --- |
| `customLabels` | `Record<string, string>` | `() => ({})` | Attēlojamais nosaukums katram lokalizācijas kodam, kas pārraksta `displayName` no lokalizācijas konfigurācijas. |
| `customWrapperStyle` | `CSSProperties` | `() => ({})` | Iekļautais stils ārējam ietvaram. |
| `customButtonStyle` | `CSSProperties` | `() => ({})` | Iekļautais stils pogai, kas atver nolaižamo izvēlni. |
| `customDropdownStyle` | `CSSProperties` | `() => ({})` | Iekļautais stils nolaižamās izvēlnes panelim. |
| `customItemStyle` | `CSSProperties` | `() => ({})` | Iekļautais stils katram nolaižamās izvēlnes vienumam. |
| `customLinkStyle` | `CSSProperties` | `() => ({})` | Iekļautais stils saitei vienuma iekšpusē. |
| `customActiveLinkStyle` | `CSSProperties` | `() => ({})` | Iekļautais stils pašlaik aktīvās lokalizācijas saitei. |
| `customDisabledLinkStyle` | `CSSProperties` | `() => ({})` | Iekļautais stils *pašreizējās* lokalizācijas pogai, ja konfigurācijā tai ir `disabled: true`. |
| `customIconStyle` | `CSSProperties` | `() => ({})` | Iekļautais stils bultiņas ikonai uz pogas. |

### Sloti {#slots}

| Slots | Saistījumi | Apraksts |
| --- | --- | --- |
| `before-button` | — | Saturs pirms pogas, kas atver nolaižamo izvēlni. |
| `before-selected-locale` | — | Saturs pirms aktīvās lokalizācijas nosaukuma pogā. |
| `after-selected-locale` | — | Saturs pēc aktīvās lokalizācijas nosaukuma pogā. |
| `before-dropdown` | — | Saturs starp pogu un nolaižamās izvēlnes paneli. |
| `before-dropdown-items` | — | Saturs nolaižamās izvēlnes augšā, virs lokalizāciju saraksta. |
| `before-item` | `locale` | Saturs pirms katra lokalizācijas ieraksta. |
| `before-link-content` | `locale` | Saturs pirms lokalizācijas nosaukuma tās saitē. |
| `after-link-content` | `locale` | Saturs pēc lokalizācijas nosaukuma tās saitē. |
| `after-item` | `locale` | Saturs pēc katra lokalizācijas ieraksta. |
| `after-dropdown-items` | — | Saturs nolaižamās izvēlnes apakšā, zem lokalizāciju saraksta. |
| `after-dropdown` | — | Saturs pēc nolaižamās izvēlnes paneļa. |

## Darbība {#behaviour}

- Uzskaita katru lokalizāciju bez `disabled: true`, ieskaitot aktīvo.
- Katrs ieraksts ir `<a>` uz `$switchLocalePath(code)`. Ceļš tiek atrisināts zem `app.baseURL`; lokalizācijas `baseUrl` citā domēnā paliek absolūts. Tam ir iestatīti `hreflang` un `lang` uz `iso || code`, `dir`, ja lokalizācijai tāds ir, `aria-current="page"` pašreizējai lokalizācijai un klase `switcher-locale-<code>`. Klikšķis izsauc `$switchLocale(code)` un aizver nolaižamo izvēlni; ar modifikatora taustiņu tas tiek atstāts pārlūkam.
- Saraksts paliek servera HTML, paslēpts, tāpēc rāpuļprogrammas redz saites. Escape vai klikšķis ārpusē to aizver.
- Nosaukums: `customLabels[code]`, tad lokalizācijas `displayName`, tad kods (ar izstrādes brīdinājumu).
- Stili: nelieli iekļauti noklusējumi (balta poga un panelis ar apmali, aktīvais ieraksts treknrakstā un zils). Katrs `custom*Style` rekvizīts tiek piemērots pēc attiecīgās daļas noklusējuma. Pogai ir klases `i18n-switcher-button` un `language-switcher`, ietvaram `i18n-switcher-wrapper`, sarakstam `i18n-switcher-dropdown`. Pozīcijas izmanto loģiskās CSS īpašības, tāpēc `dir="rtl"` darbojas.

## Piemērs {#example}

```vue
<template>
  <i18n-switcher
    :custom-labels="{ en: 'English', de: 'Deutsch' }"
    :custom-button-style="{ borderRadius: '4px' }"
  >
    <template #before-link-content="{ locale }">
      <img :src="`/flags/${locale.code}.svg`" alt="" width="16" />
    </template>
  </i18n-switcher>
</template>
```
