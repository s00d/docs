# 🌐 Crowdin integrācijas ceļvedis

## 📖 Ievads

Crowdin integrēšana tavā projektā racionalizē lokalizācijas un tulkošanas procesu, atvieglojot tulkojumu pārvaldību vairākās valodās un platformās. Šis ceļvedis sniedz soli pa solim aprakstu par Crowdin iestatīšanu tavā projektā, tostarp konfigurāciju, avotu augšupielādi un tulkojumu lejupielādi.

## 🔧 Instalēšana un iestatīšana

Lai sāktu ar Crowdin, tev būs jāinstalē Crowdin CLI globāli savā datorā un jāinicializē tas tava projekta mapē.

### 📦 Crowdin CLI instalēšana

Vispirms instalē Crowdin CLI globāli, izmantojot npm:

```bash
npm install -g @crowdin/cli
```

### 🛠 Crowdin inicializēšana tavā projektā

Inicializē Crowdin savā projektā, palaidot:

```bash
crowdin init
```

Šī komanda tevi izvedīs cauri iestatīšanas procesam, tostarp iestatot tava projekta ID, API pilnvaru un citas konfigurācijas detaļas.

## 🗂️ Konfigurācijas ceļvedis

### 📄 Crowdin konfigurācijas fails (`crowdin.yml`)

Crowdin konfigurācijas fails (`crowdin.yml`) definē, kā tavi avota faili tiek kartēti un kur jāievieto tulkojumi. Zemāk ir konfigurācijas piemērs:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Galvenie konfigurācijas parametri

- **`project_id`**: tava Crowdin projekta ID. Tas identificē projektu Crowdin, kur tiek pārvaldīti tulkojumi.
- **`api_token`**: API pilnvara, ko izmanto autentifikācijai. Pārliecinies, ka šai pilnvarai ir pareizās atļaujas tulkojumu augšupielādei un lejupielādei.
- **`base_path`**: norāda avota failu bāzes mapi. Šajā piemērā tulkojumi tiek glabāti mapē `./locales`.
- **`base_url`**: Crowdin API bāzes URL.
- **`preserve_hierarchy`**: iestatot uz `true`, Crowdin projektā saglabās tavu avota failu mapju struktūru.

### 📂 Failu konfigurācija

Sadaļa `files` kartē tavus avota failus uz ceļiem, kur tiks glabāti tulkojumi. Piemēram:

- **Avota ceļš**: definē oriģinālo tulkojumu failu atrašanās vietu.
- **Tulkojuma ceļš**: norāda, kur tulkotie faili tiks glabāti Crowdin. Vietturi, piemēram, `%two_letters_code%`, tiek izmantoti, lai dinamiski iestatītu valodas kodu failu ceļos.

## ⬆️ Avota failu augšupielāde Crowdin

Kad tava Crowdin konfigurācija ir iestatīta, vari augšupielādēt savus avota failus, izmantojot šādu komandu:

```bash
crowdin upload sources
```

Šī komanda augšupielādē visus konfigurācijā norādītos avota failus uz Crowdin, padarot tos pieejamus tulkošanai.

## ⬇️ Tulkojumu lejupielāde no Crowdin

Pēc tam, kad tulkojumi ir pabeigti vai atjaunināti Crowdin, vari tos lejupielādēt savā projektā, izmantojot:

```bash
crowdin download
```

Šī komanda ielādē jaunākos tulkojumus no Crowdin un saglabā tos atbilstoši ceļiem, kas norādīti tavā konfigurācijas failā.

## ⚙️ Labākās prakses

### 🔑 Konsekventa atslēgu nosaukšana

Nodrošini, ka tulkojumu atslēgas ir konsekventas visos failos, lai izvairītos no neskaidrībām un dublēšanās.

### 🧹 Regulāra apkope

Periodiski pārskati un iztīri neizmantotās tulkojumu atslēgas, lai tavi faili būtu sakārtoti un pārvaldāmi.

### 🛠 Automatizē augšupielādes un lejupielādes

Integrē Crowdin CLI komandas savā CI/CD cauruļvadā, lai automatizētu avota failu augšupielādi un tulkojumu lejupielādi, nodrošinot, ka tavi tulkojumi vienmēr ir aktuāli.

Sekojot šim ceļvedim, tu varēsi vienmērīgi integrēt Crowdin savā projektā, nodrošinot efektīvu un organizētu pieeju savu internacionalizācijas centienu pārvaldībai.
