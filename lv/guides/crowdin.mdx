# 🌐 Crowdin integrācijas ceļvedis

## 📖 Ievads

Crowdin integrēšana projektā racionalizē lokalizācijas un tulkošanas procesu, atvieglojot tulkojumu pārvaldību vairākās valodās un platformās. Šis ceļvedis sniedz soli pa solim norādes par to, kā iestatīt Crowdin ar savu projektu, tostarp konfigurāciju, avotu augšupielādi un tulkojumu lejupielādi.

## 🔧 Instalēšana un iestatīšana

Lai sāktu darbu ar Crowdin, savā datorā globāli jāinstalē Crowdin CLI un jāinicializē tas jūsu projekta mapē.

### 📦 Crowdin CLI instalēšana

Vispirms globāli instalējiet Crowdin CLI, izmantojot npm:

```bash
npm install -g @crowdin/cli
```

### 🛠 Crowdin inicializēšana projektā

Inicializējiet Crowdin savā projektā, palaižot:

```bash
crowdin init
```

Šī komanda jūs izvedīs cauri iestatīšanas procesam, tostarp jūsu projekta ID, API talona un citu konfigurācijas datu iestatīšanai.

## 🗂️ Konfigurācijas ceļvedis

### 📄 Crowdin konfigurācijas fails (`crowdin.yml`)

Crowdin konfigurācijas fails (`crowdin.yml`) definē, kā avota faili tiek attēloti un kur jānovieto tulkojumi. Zemāk ir konfigurācijas piemērs:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Galvenie konfigurācijas parametri

- **`project_id`**: jūsu Crowdin projekta ID. Tas identificē projektu Crowdin platformā, kurā tiek pārvaldīti tulkojumi.
- **`api_token`**: API talons, ko izmanto autentifikācijai. Pārliecinieties, ka šim talonam ir pareizās atļaujas augšupielādēt un lejupielādēt tulkojumus.
- **`base_path`**: norāda avota failu bāzes mapi. Šajā piemērā tulkojumi tiek glabāti mapē `./locales`.
- **`base_url`**: Crowdin API bāzes URL.
- **`preserve_hierarchy`**: iestatīts uz `true`, Crowdin projektā saglabās jūsu avota failu mapju struktūru.

### 📂 Failu konfigurācija

Sadaļa `files` attēlo jūsu avota failus uz ceļiem, kuros tiks glabāti tulkojumi. Piemēram:

- **Avota ceļš**: definē oriģinālo tulkojumu failu atrašanās vietu.
- **Tulkojuma ceļš**: norāda, kur tulkotie faili tiks glabāti Crowdin. Vietturi, piemēram, `%two_letters_code%`, tiek izmantoti, lai dinamiski iestatītu valodas kodu failu ceļos.

## ⬆️ Avota failu augšupielāde uz Crowdin

Kad jūsu Crowdin konfigurācija ir iestatīta, avota failus varat augšupielādēt, izmantojot šādu komandu:

```bash
crowdin upload sources
```

Šī komanda augšupielādē visus konfigurācijā norādītos avota failus uz Crowdin, padarot tos pieejamus tulkošanai.

## ⬇️ Tulkojumu lejupielāde no Crowdin

Pēc tam, kad tulkojumi ir pabeigti vai atjaunināti Crowdin, tos var lejupielādēt savā projektā, izmantojot:

```bash
crowdin download
```

Šī komanda ienes jaunākos tulkojumus no Crowdin un saglabā tos atbilstoši konfigurācijas failā norādītajiem ceļiem.

## ⚙️ Labākā prakse

### 🔑 Konsekventa atslēgu nosaukšana

Nodrošiniet, ka tulkojumu atslēgas ir konsekventas visos failos, lai izvairītos no neskaidrībām un dublēšanās.

### 🧹 Regulāra uzturēšana

Periodiski pārskatiet un iztīriet neizmantotās tulkojumu atslēgas, lai jūsu faili paliktu organizēti un pārvaldāmi.

### 🛠 Augšupielāžu un lejupielāžu automatizēšana

Integrējiet Crowdin CLI komandas savā CI/CD konveijerā, lai automatizētu avota failu augšupielādi un tulkojumu lejupielādi, nodrošinot, ka jūsu tulkojumi vienmēr ir aktuāli.

Sekojot šim ceļvedim, jūs varēsiet nemanāmi integrēt Crowdin savā projektā, nodrošinot efektīvu un organizētu pieeju internacionalizācijas centienu pārvaldībai.
