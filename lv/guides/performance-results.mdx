# Veiktspējas testu rezultāti

- **[CLI](https://github.com/s00d/nuxt-i18n-micro/tree/main/scripts/src/commands/performance.ts)**: `pnpm -C scripts cli performance` / `pnpm test:performance`

### Apraksts

Salīdzina **plain Nuxt** (bāzlīniju bez i18n moduļa), **i18n-micro** un **`@nuxtjs/i18n` v10.6** ar vienu koplietotu vārdnīcas profilu.

Fokuss: būvēšanas laiks, RSS maksimums, izvietojamais **kods pret tulkojumiem pret kopējo**, un servera uzvedība ar Artillery + Autocannon.

### Metodoloģijas piezīmes

- Rādītāji ir **3 secīgu izpildījumu vidējie rādītāji uz fixture** (fixture A ×3, tad B ×3, tad C ×3 — bez pārmaiņām).
- **Tulkojumi** iekļauj lokāles JSON zem `locales/` / `_locales/` / `translations/`, visu zem `chunks/raw/` un atbilstošos lokāles gabalus. Vecāki pārskati, kas rādīja `@nuxtjs/i18n` “translations: 0 B” un milzīgu “code” kolonnu, ziņojumu gabalus skaitīja kā lietotnes kodu.
- **plain-nuxt** apkalpo to pašu lapu apjomu kā statiskus `public/translations` JSON (nevis statiskus JS importus). Zem Artillery šī bāzlīnija ir I/O smaga; tā nav “i18n papildslodze”, tā ir lielu JSON iegūšanas cena uz katru pieprasījumu.

### Izpildījumi

Visi zemāk esošie rādītāji ir **vidējie rādītāji 3 izpildījumos**.

## Piezīmes

- Koplietots profils: 4 lokāles × 2 lapas × ~16,8k index lapu atslēgas.
- Artillery: 6s iesildīšanās @6 VU/s + 60s galvenais @60 VU/s. Autocannon: 10 savienojumi × 10s.
- Palaist atkārtoti: `pnpm test:performance` vai `pnpm -C scripts cli performance --locales N --keys K --only all|micro|i18n|plain --runs N`.
