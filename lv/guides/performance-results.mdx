- **[CLI](https://github.com/s00d/nuxt-i18n-micro/tree/main/scripts/src/commands/performance.ts)**: `pnpm -C scripts cli performance` / `pnpm test:performance`

### Apraksts

Salīdzina **parasto Nuxt** (bāzes līniju bez i18n moduļa), **i18n-micro** un **`@nuxtjs/i18n` v10.6** zem viena koplietota vārdnīcas profila.

Fokuss: būvēšanas laiks, virsotnes RSS, izvietojamais **kods pret tulkojumiem pret kopējo** un servera uzvedība zem Artillery + Autocannon.

### Metodoloģijas piezīmes

- Metrikas ir **vidēji no 3 secīgiem palaidieniem katrai fixture** (fixture A ×3, tad B ×3, tad C ×3 — nav pārmaiņus).
- **Tulkojumi** ietver lokalizācijas JSON zem `locales/` / `_locales/` / `translations/`, visu zem `chunks/raw/` un atbilstošās lokalizācijas daļas. Vecāki ziņojumi, kas rādīja `@nuxtjs/i18n` "tulkojumi: 0 B" un milzīgu "koda" kolonnu, uzskaitīja ziņojumu daļas kā lietotnes kodu.
- **plain-nuxt** apkalpo to pašu lapu apjomu kā statisks `public/translations` JSON (nevis statiski JS importi). Zem Artillery šī bāzes līnija ir I/O smaga; tā nav "i18n slodze", tā ir liela JSON iegūšanas cena katrā pieprasījumā.

### Palaidieni

Visas zemāk esošās metrikas ir **vidēji no 3 palaidieniem**.

## Piezīmes

- Koplietots profils: 4 lokalizācijas × 2 lapas × ~16.8k indeksa lapas.
- Artillery: 6s uzsildīšana @6 VU/s + 60s galvenais @60 VU/s. Autocannon: 10 savienojumi × 10s.
- Palaid vēlreiz: `pnpm test:performance` vai `pnpm -C scripts cli performance --locales N --keys K --only all|micro|i18n|plain --runs N`.
