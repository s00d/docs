# Konfigurācijas atsauce

Pilnīga atsauce katrai opcijai zem `i18n` atslēgas failā `nuxt.config`. Tipi un noklusējumi atbilst [`ModuleOptions`](https://github.com/s00d/nuxt-i18n-micro/blob/main/packages/types/src/index.ts) pakotnē `@i18n-micro/types`.

## Ātrā atsauce

Katra opcija, ko modulis pieņem, no tipa `ModuleOptions`. Zemāk esošās sadaļas skaidro,
kā tās darbojas kopā;
[Moduļa opciju atsaucē](/api/module-options) ir pilnas aprakstīšanas.

# Opciju detaļas

Modulis piedāvā plašas konfigurācijas opcijas jūsu internacionalizācijas iestatījumu pielāgošanai.

### 🌍 Pamata lokāles iestatījumi

#### `locales`

{/* generated:option:locales — do not edit; run `pnpm run docs:generate` */}

**Type** `Locale[]` · **Default** `[]`

List of supported locales.
Each entry defines a locale code plus optional metadata (ISO, direction, display name, etc.).

{/* /generated:option:locales */}

Katrs lokāles objekts atbalsta:

| Īpašība         | Tips      | Obligāti | Apraksts                                           |
| ---------------- | --------- | -------- | ----------------------------------------------------- |
| `code`           | `string`  | ✅       | Unikāls identifikators (piemēram, `'en'`)                      |
| `displayName`    | `string`  | ❌       | Cilvēkiem lasāms nosaukums pārslēdzējiem (piemēram, `'English'`) |
| `iso`            | `string`  | ❌       | ISO kods (piemēram, `'en-US'`)                            |
| `dir`            | `string`  | ❌       | Teksta virziens (`'ltr'` vai `'rtl'`)                   |
| `disabled`       | `boolean` | ❌       | Atspējot nolaižamajā izvēlnē, ja `true`                         |
| `baseUrl`        | `string`  | ❌       | Bāzes URL lokālei specifiskiem domēniem                  |
| `baseDefault`    | `boolean` | ❌       | Noņemt lokāles priedēkli no URL                        |
| `fallbackLocale` | `string`  | ❌       | Lokāles specifiska rezerves opcija (pārraksta globālo)                |
| `[key: string]`  | `unknown` | ❌       | Jebkuras pielāgotās īpašības (skatiet zemāk)                     |

**Piemērs**:

```typescript
locales: [
  { code: 'en', iso: 'en-US', dir: 'ltr' },
  { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
  { code: 'ar', iso: 'ar-SA', dir: 'rtl', disabled: true },
  {
    code: 'de',
    iso: 'de-DE',
    dir: 'ltr',
    baseUrl: 'https://de.example.com',
    baseDefault: true,
  },
]
```

<Warning>
Using `baseUrl` can lead to duplication of internal routes as external links, complicating routing and maintenance. Consider creating external links directly for specific locales instead.
</Warning>

#### Custom Locale Properties

You can add any custom properties to locale objects. They are passed through to the runtime and accessible via `$getLocales()`:

```typescript
locales: [
  { code: 'en', iso: 'en-US', flag: '🇬🇧', currency: 'GBP' },
  { code: 'de', iso: 'de-DE', flag: '🇩🇪', currency: 'EUR' },
  { code: 'ru', iso: 'ru-RU', flag: '🇷🇺', currency: 'RUB' },
]
```

Piekļūstiet tām komponentos:

```vue
<template>
  <ul>
    <li v-for="locale in $getLocales()" :key="locale.code">{{ locale.flag }} {{ locale.displayName }} ({{ locale.currency }})</li>
  </ul>
</template>
```

Pēc noklusējuma pielāgotās īpašības tiek tipizētas kā `unknown`. Lai iegūtu pilnu TypeScript atbalstu, izmantojiet **moduļa augmentāciju**. Izveidojiet deklarācijas failu (piemēram, `app/i18n.d.ts` vai jebkuru `.d.ts`, kas iekļauts jūsu `tsconfig`):

```typescript
// app/i18n.d.ts
declare module '@i18n-micro/types' {
  interface Locale {
    flag?: string
    currency?: string
  }
}
```

Pēc tam visas pielāgotās īpašības ir pilnībā tipizētas:

```typescript
const locales = $getLocales()
locales[0].flag // string | undefined ✅
locales[0].currency // string | undefined ✅
```

#### `strategy`

{/* generated:option:strategy — do not edit; run `pnpm run docs:generate` */}

**Type** `Strategies` · **Default** `'prefix_except_default'`

URL routing strategy for locale prefixes.

- `'no_prefix'` — no locale in URL; locale stored in cookie.
- `'prefix_except_default'` — prefix all locales except the default.
- `'prefix'` — always prefix, including the default locale.
- `'prefix_and_default'` — like `prefix`, but the default locale is also accessible without prefix.

{/* /generated:option:strategy */}

<CodeGroup>
```typescript no_prefix
strategy: 'no_prefix'
// Routes: /about, /contact
// Locale detection via browser/cookies
```

```typescript prefix_except_default
strategy: 'prefix_except_default'
// Default locale: /about, /contact
// Other locales: /fr/about, /de/contact
```

```typescript prefix
strategy: 'prefix'
// All locales: /en/about, /fr/about, /de/about
```

```typescript prefix_and_default
strategy: 'prefix_and_default'
// Both prefixed and non-prefixed versions for default locale
```
</CodeGroup>

{/* generated:option:disablePageLocales — do not edit; run `pnpm run docs:generate` */}

**Type** `boolean` · **Default** `false`

Disable per-page translation files.

{/* /generated:option:disablePageLocales */}

Kad iespējots, tiek izmantoti tikai saknes līmeņa tulkojumu faili:

```tree
locales/
├── en.json
├── fr.json
└── ar.json
```

{/* generated:option:fallbackLocale — do not edit; run `pnpm run docs:generate` */}

**Type** `string` · **Default** `undefined (no fallback; returns the raw key)`

Global fallback locale code.
When a translation key is missing in the active locale, the module looks it up
in this locale before returning the key itself.

{/* /generated:option:fallbackLocale */}

```typescript
fallbackLocale: 'en' // Global fallback
```
#### `types`

{/* generated:option:types — do not edit; run `pnpm run docs:generate` */}

**Type** `boolean` · **Default** `true`

#### `routeLocales`

{/* generated:option:routeLocales — do not edit; run `pnpm run docs:generate` */}

**Type** `Record<string, string[]>` · **Default** —

Per-route locale restrictions, extracted from `defineI18nRoute()` calls.
Maps a route path (e.g. `'/about'`) to an array of allowed locale codes.

{/* /generated:option:routeLocales */}

#### `metaBaseUrl`

{/* generated:option:metaBaseUrl — do not edit; run `pnpm run docs:generate` */}

**Type** `string` · **Default** `undefined`

Base URL for SEO meta tags (canonical, og:url, hreflang).

- A concrete URL string (e.g. `'https://example.com'`) — used as-is (highest priority).
- `undefined` — falls back to `site.url` from `nuxt-site-config` when that module is
  present, otherwise the current request origin
  (`useRequestURL().origin` on server, `window.location.origin` on client).

{/* /generated:option:metaBaseUrl */}

Prioritāte, kad nav iestatīts: `site.url` no `nuxt-site-config` (ja instalēts) → pieprasījuma izcelsme
(`useRequestURL().origin` serverī ar `X-Forwarded-Host` / `X-Forwarded-Proto`,
`window.location.origin` klientā). Ideāli **SEO stackiem**, kas jau iestata `site.url`,
un **vairāku domēnu** izvietošanai, kad `site.url` ir izlaists.

- Jebkura cita virkne — izmantota kā statisks bāzes URL (uzvar pār `site.url`).

```typescript
// Prefer sharing the SEO stack origin — omit metaBaseUrl when site.url is set
site: { url: 'https://example.com' }

// Or pin an explicit override
metaBaseUrl: 'https://example.com'
```

### 🔄 Padziļinātas funkcijas
#### `globalLocaleRoutes`

{/* generated:option:globalLocaleRoutes — do not edit; run `pnpm run docs:generate` */}

**Type** `GlobalLocaleRoutes` · **Default** `\{\}`

Global route-level locale configuration.
Allows restricting or customizing locale routes for specific pages without
modifying their components.

- `false` — exclude the route from localization.
- `Record<LocaleCode, string>` — custom per-locale paths.

{/* /generated:option:globalLocaleRoutes */}

```typescript
    fr: '/a-propos',

```

<Tip>
Maršrutiem, kas pievienoti `pages:extend` iekšpusē (īpaši, kad daudzi koplieto vienu ietinošo SFC), veidojiet gan `pages`, gan `globalLocaleRoutes` no viena saraksta ar [`splitLocaleRoutes`](/guides/custom-locale-routes#programmatic-routes-pagesextend--244) — atslēdzot pēc maršruta **nosaukuma**, nevis faila ceļa.
</Tip>

translations from the `about` page instead of its own.

{/* /generated:option:routesLocaleLinks */}

#### `customRegexMatcher`

{/* generated:option:customRegexMatcher — do not edit; run `pnpm run docs:generate` */}

**Type** `string \| RegExp` · **Default** `undefined (uses built-in pattern based on locale codes)`

Custom regular expression (or its string source) for matching locale codes in URL segments.
All locale codes defined in `locales` must match this pattern, or a warning is emitted.

{/* /generated:option:customRegexMatcher */}

<Danger>
Būvēšanas laikā modulis **validē**, ka katrs lokāles kods jūsu `locales` sarakstā atbilst `customRegexMatcher` modelim. Ja kāds lokāles kods neatbilst, **būvēšana neizdosies** ar kļūdu:

> `Nuxt-i18n-micro: Some locale codes does not match customRegexMatcher`

Vienmēr pirms izvietošanas pārbaudiet savu regex pret visiem jūsu lokāles kodiem.

### 🔢 Pielāgošana
#### `plural`

{/* generated:option:plural — do not edit; run `pnpm run docs:generate` */}

**Type** `PluralFunc` · **Default** `built-in pluralization (form index by count)`

Custom pluralization function.
Receives `(key, count, params, locale, getter)` and should return the selected
plural form as a string, or `null`/`undefined` to fall back to the built-in
`defaultPlural` logic (so you can override only some locales).

For the Nuxt module the function is serialized with `.toString()` into
`.nuxt/i18n.plural.mjs` — it must be self-contained (no imports / outer scope).
A file path string is **not** supported.

{/* /generated:option:plural */}

##### Kā tas darbojas

Tulkojumi izmanto `|`, lai atdalītu daudzskaitļa formas:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

Izmantojiet `$tc('apples', count)` vai `$tc('cart', \{ count, name \})`, kad formai nepieciešams vairāk nekā `\{count\}` — nododiet **`count` un citus parametrus otrā argumenta objektā**, nevis kā trešo argumentu (trešais ir tikai `defaultValue`).

`$tc` izsaukums izsauc `plural` funkciju, kas:

1. Izsauc `t(key)`, lai iegūtu neapstrādāto tulkojuma virkni (piemēram, `"no apples | one apple | \{count\} apples"`)
2. Sadala pēc `|`, lai iegūtu formu masīvu
3. Izvēlas formu, balstoties uz `count`
4. Aizvieto `\{count\}` ar faktisko skaitli

**Noklusējuma** realizācija izvēlas pēc indeksa: `count < forms.length ? forms[count] : forms[last]`. Tas darbojas vienkāršiem gadījumiem (0 → pirmā forma, 1 → otrā, 2+ → pēdējā).

##### Pielāgota daudzskaitļa funkcija

Valodām ar sarežģītiem daudzskaitļa noteikumiem (piemēram, krievu, arābu, poļu) pārrakstiet opciju `plural`.

<Danger>
Funkcija tiek serializēta caur `.toString()` un būvēšanas laikā injicēta virtuālā modulī. Tas nozīmē:

- **Jāizmanto `function` atslēgvārds** — NEVIS saīsinātā metožu sintakse, NEVIS bultiņu funkcijas ar ārējām atsaucēm
- **Nav importu vai ārēju atsauču** — funkcijai jābūt pilnībā pašpietiekamai (faila ceļš, piemēram, `plural: '~/i18n/plural.ts'`, **nav** atbalstīts)
- **Nav tikai TypeScript specifiskas sintakses**, kas neizdzīvo `.toString()` (tipu anotācijas ir kārtībā `nuxt.config.ts` iekšpusē, jo Nuxt tās noņem)
- `null` / `undefined` atgriešana atkāpjas uz iebūvēto `defaultPlural` (noderīgi pa lokālēm pārrakstīšanas veikšanai)
</Danger>

**Piemērs: krievu daudzskaitļa formas** (4 formas: nulle, viena, dažas, daudzas):

```typescript
// nuxt.config.ts
export default defineNuxtConfig({
  i18n: {
    plural: function (key, count, _params, _locale, t) {
      const translation = t(key)
      if (!translation) return key

      const forms = translation
        .toString()
        .split('|')
        .map(function (s) {
          return s.trim()
        })
      let idx

      if (count === 0) {
        idx = 0
      } else {
        const mod10 = count % 10
        const mod100 = count % 100
        if (mod10 === 1 && mod100 !== 11) {
          idx = 1
        } else if (mod10 >= 2 && mod10 <= 4 && (mod100 < 10 || mod100 >= 20)) {
          idx = 2
        } else {
          idx = 3
        }
      }

      if (idx >= forms.length) idx = forms.length - 1
      return (forms[idx] || '').replace('{count}', String(count))
    },
  },
})
```

Ar šo tulkojumu:

```json
{
  "apples": "нет яблок | {count} яблоко | {count} яблока | {count} яблок"
}
```

Rezultāti:

- `$tc('apples', 0)` → `"нет яблок"`
- `$tc('apples', 1)` → `"1 яблоко"`
- `$tc('apples', 3)` → `"3 яблока"`
- `$tc('apples', 5)` → `"5 яблок"`
- `$tc('apples', 21)` → `"21 яблоко"`

**Piemērs: vienkārša angļu valoda (noklusējuma uzvedība)**:

```typescript
// This is the built-in default — you don't need to set it explicitly
plural: function (key, count, params, _locale, t) {
  const translation = t(key, params)
  if (!translation) return null

  const forms = translation.toString().split('|')
  if (forms.length === 0) return null
  const form = count < forms.length ? forms[count] : forms[forms.length - 1]
  if (!form) return null
  return form.trim().replace('{count}', count.toString())
}
```

#### `translationPayloads`

{/* generated:option:translationPayloads — do not edit; run `pnpm run docs:generate` */}

**Type** `TranslationPayloadOptions` · **Default** —

Controls how translation payloads are emitted (Node: `public/<apiBaseUrl>`; Edge: Nitro `serverAssets`).

- **Node**: `serverAssets` means local SSR via `readFile` under `public/` (no Rollup `raw:`).
- **Edge**: `serverAssets` registers Nitro `serverAssets` (`assets:i18n`); it does not force a public copy.

Keep the defaults for the usual all-in-one setup. For large Edge catalogs prefer `mode: 'source'`.
For CDN-backed deployments, disable local outputs and set `apiBaseClientHost` / `apiBaseServerHost`.

{/* /generated:option:translationPayloads */}

```typescript
{
  mode?: 'premerged' | 'source'
  serverAssets?: boolean
  serverHandler?: boolean
  publicAssets?: boolean
  prerenderRoutes?: boolean
  publicDir?: string
  warnFileCount?: number
  warnSizeBytes?: number
}
```

**Noklusējums** (`mode: 'premerged'`):

```typescript
{
  mode: 'premerged',
  serverAssets: true,
  serverHandler: true,
  publicAssets: true,
  prerenderRoutes: false
}
```

SSR uz **Node** nolasa to pašu koku, kas kopēts uz `public/<apiBaseUrl>/` (`readFile`). Uz **Edge** Nitro `serverAssets` to iestrādā (nav piespiedu publiskās kopijas — iestatiet `publicAssets: true` CDN vajadzībām). `mode: 'premerged'` → `\{page\}/\{locale\}/data.json` uz lapu/lokāli; `mode: 'source'` → kompakts avots + izpildlaika sapludināšana.

`serverAssets: true` uz **Node** piespiež publisko kopiju arī tad, ja `publicAssets` ir false. Uz **Edge** tas tikai reģistrē Nitro iestrādājumu. Uz Edge lieliem katalogiem priekšroku dodiet `mode: 'source'`. Bez lokālajiem payload un bez `apiBaseServerHost` būvēšana neizdodas.

Lokālais `/\{apiBaseUrl\}/:page/:locale/data.json` apstrādātājs, iepriekšējas renderēšanas maršruti un publisko aktīvu kopijas paliek kā izvēles izvades.

Kompaktām **publiskām** / Edge payload:

```typescript
i18n: {
  translationPayloads: {
    mode: 'source',
  },
}
```

`mode: 'source'` uztur slāņu failus kompaktus un sapludina sakni/lapu/rezervi izpildlaikā caur iebūvēto maršrutu `/_locales` (vai Edge `assets:i18n`). Pēc noklusējuma tas atspējo publisko aktīvu kopijas un iepriekš renderētus payload maršrutus.

<Warning>
Ar `mode: 'source'` `publicAssets` pēc noklusējuma ir `false` (`prerenderRoutes` vienmēr ir izslēgts, ja vien to nepieteicat). Tāpēc tīri statiska mitināšana bez Nitro/edge izpildlaika nevar ielādēt tulkojumus klienta pusē, ja vien neiespējojat vienu no šīm izvadēm, `serverHandler` paliek pieejams izpildlaikā vai payload tiek mitināti ārēji.

Ar noklusējuma `mode: 'premerged'` un `publicAssets: true` statiskie faili jau nonāk `public/<apiBaseUrl>/\{page\}/\{locale\}/data.json` — atbilstoši klienta `$fetch` URL — tāpēc statisks hosts tos var apkalpot bez Nitro.
</Warning>

<Warning>
Kad `apiBaseServerHost` vai `apiBaseClientHost` ir iestatīts, modulis izgūst jau sapludinātu JSON no šīs izcelsmes. Ārējiem hostiem jāapkalpo tie paši `/\{apiBaseUrl\}/:page/:locale/data.json` atbildes kā iebūvētajam maršrutam. `mode: 'source'` attiecas uz lokālajām payload mapēm, nevis uz ārēju CDN, ja vien šis CDN arī neapkalpo izpildlaikā sapludinātas payload.
</Warning>

Jūs varat manuāli atspējot arī dublējošās lokālās izvades un apkalpot tulkojumu payload no CDN vai objektu krātuves:

```typescript
i18n: {
  apiBaseClientHost: 'https://cdn.example.com',
  apiBaseServerHost: 'https://cdn.example.com',
  translationPayloads: {
    serverHandler: false,
    publicAssets: false,
    prerenderRoutes: false
  }
}
```

Ja vēlaties tikai izvairīties no payload rakstīšanas publiskajā izvadē, saglabājot iebūvēto servera maršrutu SSR/izpildlaika pieprasījumiem, atspējojiet abas publiskās izvades:

```typescript
i18n: {
  translationPayloads: {
    publicAssets: false,
    prerenderRoutes: false
  }
}
```

Uz **Node** `serverAssets: true` joprojām piespiež publisko kopiju priekš SSR, pat kad `publicAssets` ir false — iestatiet `serverAssets: false` un `apiBaseServerHost`, ja vēlaties nulli lokālu payload failu.

Izmantojiet `publicDir`, lai mainītu publisko izvades mapi, kad payload tiek kopēti. Pēc noklusējuma tas ir `apiBaseUrl` (`_locales`). Premerged režīmā `publicAssets` tur raksta `\{page\}/\{locale\}/data.json` (tie paši ceļi, ko klients izgūst). `prerenderRoutes` ir izvēles Nitro iepriekšēja apstrādātāja maršrutu renderēšana — parasti lieka, kad šis koks jau ir kopēts.

Ja atspējojat visas lokālās payload izvades, jums jākonfigurē gan `apiBaseServerHost` (SSR), gan `apiBaseClientHost` (klienta navigācija). Pretējā gadījumā tulkojumi atrisināsies uz tukšiem objektiem, un UI atslēgas var izskatīties netulkotas.

`warnFileCount` un `warnSizeBytes` kontrolē būvēšanas laika brīdinājumus, kad iepriekš sapludinātā payload izvade kļūst liela (noklusējumi: 500 faili un 10 MB).

#### `dateBuild`

{/* generated:option:dateBuild — do not edit; run `pnpm run docs:generate` */}

**Type** `string \| number` · **Default** —

Value used for cache-busting translation requests (`?v=...`).

When not provided, the module falls back to `Date.now()` (non-deterministic).
For reproducible/rolling deployments, set this to a stable value
(e.g. a git SHA or build number).

{/* /generated:option:dateBuild */}

Pēc noklusējuma modulis piešķir pirkstu nospiedumu jūsu tulkojumu avotiem (SHA-256 pār katru
`<layer>/<translationDir>/**/*.json`, slāņu secībā) un izmanto to. Vērtība mainās tikai tad, kad
tulkojums patiešām mainās, tāpēc pārbūvēšana vai atkārtota izvietošana ar neskartiem tulkojumiem
atstāj pārlūka un CDN kešatmiņas neskartas — ar `httpCacheDuration`, kas iestatīts uz gadu,
būvējuma laikspiedols tā vietā piespiestu katru klientu katrā izvietošanā atkārtoti lejupielādēt visu vārdnīcu.

Tas atkāpjas uz `Date.now()` tikai tad, kad nav tulkojumu failu, ko šifrēt.

Iestatiet to skaidri, lai pārņemtu kontroli (piemēram, lai piesaistītu payload URL laidienam, nevis saturam):

```ts
export default defineNuxtConfig({
  i18n: {
    // Any stable string/number: git SHA, CI build number, release tag, etc.
    dateBuild: process.env.GIT_SHA ?? 'local-dev',
  },
})
```
#### `httpCacheDuration`

{/* generated:option:httpCacheDuration — do not edit; run `pnpm run docs:generate` */}

**Type** `number` · **Default** `31536000`

HTTP `Cache-Control` max-age (seconds) for `/\{apiBaseUrl\}/:page/:locale/data.json`.

Applies in full only while `dateBuild` busts the URL (`?v=...`), which is the default:
the response is then `public, max-age=…, immutable` and safe for browsers and CDNs.

- `dateBuild: 0`/`''` — the URL is stable, so this duration is *not* honoured; the
  response becomes `public, max-age=0, must-revalidate` instead. A long `max-age` on an
  unchanging URL pins the first payload a browser ever saw.

- `0` — do not set `Cache-Control` at all (useful in local debugging)
- Not applied in development (`import.meta.dev`) so HMR is not fought by the browser cache
- Reaches only responses served through Nitro. Payloads copied into `public/` and served
  by the hosting platform take that platform's headers — see the Performance guide.

Analogous to `@nuxtjs/i18n` experimental `httpCacheDuration` (v10.2.0), but as an
explicit response header rather than Nitro `defineCachedEventHandler` maxAge.

{/* /generated:option:httpCacheDuration */}

```ts
export default defineNuxtConfig({
  i18n: {
    // Per-build fallback (Date.now()) so immutable payloads never go stale when GIT_SHA is missing.
    dateBuild: process.env.GIT_SHA ?? String(Date.now()),
    httpCacheDuration: 86400, // 24 hours
    // httpCacheDuration: 0, // disable Cache-Control header
  },
})
```

<Tip>
Vairumam projektu noklusējums (neierobežots, bez derīguma termiņa) ir kārtībā — tulkojumi ir mazi un galīgi. Tomēr, ja jūsu projektam ir **tūkstoši lapu** ar `disablePageLocales: false` un **daudz lokāļu**, servera kešs var būtiski pieaugt. Ilgstoši darbojošos Node.js serveros tas var izraisīt pārmērīgu atmiņas patēriņu.

- **`cacheMaxSize`** — ierobežo kešoto ierakstu skaitu. Noderīgs atmiņas ierobežošanai.
- **`cacheTtl`** — nodrošina, ka novecojušie tulkojumi galu galā tiek atkārtoti ielādēti no krātuves. Noderīgs bezservera vidēs vai kad tulkojumi mainās izpildlaikā.

**Formula maksimālā ierakstu skaita novērtēšanai**: `lokāļu_skaits × (lapu_skaits + 1)`. Piemēram, 10 lokāles × 500 lapas = ~5010 ieraksti.
</Tip>
