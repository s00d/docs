# 🧪 `Nuxt I18n Micro` moduļa testēšana

## 📖 Ievads testēšanā

`Nuxt I18n Micro` moduļa testēšana ir būtiska, lai nodrošinātu, ka tavas lietotnes lokalizācijas funkcijas darbojas kā gaidīts. Šī dokumentācija tevi izvedīs cauri testēšanas vides iestatīšanai, mock konfigurāciju izveidei vitest un testu rakstīšanai savām komponentēm. Praktiskam piemēram vari atsaukties uz [piemēra projektu GitHub](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/test-utils/example).

Skati [Maršrutēšanas stratēģiju testēšana](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/testing-strategies.md) par to, kā šis repozitorijs palaiž savus komplektus — `unit` / `integration` / `e2e` Vitest projektus, katrai stratēģijai specifiskos failus (`test/strategies-*.test.ts`) un ģenerē regresijas.

## 🛠️ Testēšanas vides iestatīšana

### 1. Instalē `@i18n-micro/test-utils`

Vispirms tev jāinstalē `Nuxt I18n Micro` testēšanas utilītas. Šī pakete nodrošina nepieciešamos rīkus, lai mock un testētu tavas i18n konfigurācijas.

```bash
npm install @i18n-micro/test-utils --save-dev
```

### 2. Izveido mock konfigurācijas failu

Tālāk izveido failu, lai iestatītu mock i18n konfigurāciju. Šis fails tiks izmantots, lai mock i18n funkcijas un utilītas tavu testu laikā.

```typescript
// tests/unit-setup.ts

import { mockNuxtImport } from '@nuxt/test-utils/runtime'
import { vi } from 'vitest'
import { i18nUtils } from '@i18n-micro/test-utils'

export function createFakeI18n() {
  return {
    $getLocale: vi.fn(i18nUtils.getLocale),
    $t: vi.fn(i18nUtils.t),
    $tc: vi.fn(i18nUtils.tc),
    $setLocale: vi.fn(i18nUtils.setLocale),
    $getLocaleName: vi.fn(i18nUtils.getLocaleName),
    $setLocaleName: vi.fn(i18nUtils.setLocaleName),
    $getLocales: vi.fn(i18nUtils.getLocales),
    $setLocales: vi.fn(i18nUtils.setLocales),
    $defaultLocale: vi.fn(i18nUtils.defaultLocale),
    $setDefaultLocale: vi.fn(i18nUtils.setDefaultLocale),
    $getRouteName: vi.fn(i18nUtils.getRouteName),
    $settRouteName: vi.fn(i18nUtils.settRouteName),
    $ts: vi.fn(i18nUtils.ts),
    $tn: vi.fn(i18nUtils.tn),
    $td: vi.fn(i18nUtils.td),
    $has: vi.fn(i18nUtils.has),
    $resolveTranslations: vi.fn(i18nUtils.resolveTranslations),
    $setTranslation: vi.fn(i18nUtils.setTranslation),
    $mergeTranslations: vi.fn(i18nUtils.mergeTranslations),
    $switchLocaleRoute: vi.fn(i18nUtils.switchLocaleRoute),
    $switchLocalePath: vi.fn(i18nUtils.switchLocalePath),
    $switchLocale: vi.fn(i18nUtils.switchLocale),
    $switchRoute: vi.fn(i18nUtils.switchRoute),
    $localeRoute: vi.fn(i18nUtils.localeRoute),
    $localePath: vi.fn(i18nUtils.localePath),
    $setI18nRouteParams: vi.fn(i18nUtils.setI18nRouteParams),
  }
}

mockNuxtImport<() => ReturnType<typeof createFakeI18n>>('useI18n', () => vi.fn(() => createFakeI18n()))

export const setTranslationsFromJson = i18nUtils.setTranslationsFromJson
```

### 3. Konfigurē Vitest

Tagad konfigurē Vitest izmantot mock konfigurācijas failu un iestati testēšanas vidi.

```typescript
// vitest.config.ts

import { defineVitestConfig } from '@nuxt/test-utils/config'

export default defineVitestConfig({
  test: {
    watch: false,
    setupFiles: ['./tests/unit-setup.ts'],
    include: ['./**/*.spec.ts'],
  },
})
```

## 🧪 Testu rakstīšana

### Piemēra komponents

Šeit ir vienkārša komponenta piemērs, kas izmanto kompozītu `useI18n`, lai tulkotu ziņojumus.

```vue
<script setup lang="ts">
const { $t } = useI18n()

const props = defineProps({
  message: {
    type: String,
    default: null,
  },
})

// Test to see that $t works in script setup as well as the template
const message = props.message || $t('defaultMessage')
</script>

<template>
  <div>
    <p>Test from component: {{ $t('welcome') }}</p>
    <p data-testid="message">Test message from props: {{ message }}</p>
  </div>
</template>
```

### Testu fails

Tagad uzrakstīsim testu šim komponentam.

```typescript
// tests/unit/example.spec.ts

import { describe, it, expect, beforeEach } from 'vitest'
import { mount } from '@vue/test-utils'
import ExampleComponent from '@/components/ExampleComponent.vue'
import fs from 'fs'
import path from 'path'
import { setTranslationsFromJson } from './unit-setup'

describe('ExampleComponent', () => {
  beforeEach(async () => {
    const fileContent = fs.readFileSync(path.join(__dirname, '../../locales/en-GB.json')).toString()
    await setTranslationsFromJson('en', JSON.parse(fileContent))
  })

  it('renders the welcome message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.text()).toContain('Test from component: Welcome')
  })

  it('renders the default message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Default Message')
  })

  it('renders the custom message correctly', () => {
    const wrapper = mount(ExampleComponent, {
      props: {
        message: 'Custom Message',
      },
    })
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Custom Message')
  })
})
```

## 📝 Testēšanas labākās prakses

- **🔧 Mock i18n funkcijas:** vienmēr mock i18n funkcijas, izmantojot `@i18n-micro/test-utils`, lai nodrošinātu konsekventus un paredzamus testu rezultātus.
- **⚙️ Izmanto Vitest vienībtestiem:** Vitest ir jaudīgs testēšanas ietvars Vue lietotnēm. Izmanto to, lai rakstītu vienībtestus savām komponentēm.
- **📚 Dokumentē savus testus:** skaidri dokumentē katra testa mērķi un gaidītos rezultātus. Tas palīdzēs saglabāt skaidrību un atvieglos citiem (vai nākotnes tev) testu izpratni.

## 📊 i18n utilītas metodes

Zemāk ir tabula, kas apraksta visas utilītas metodes, ko nodrošina `@i18n-micro/test-utils`.

| Metode                                          | Apraksts                                                                                                                                |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `t(key, params, defaultValue)`                  | Tulko atslēgu ar neobligātiem parametriem un noklusējuma vērtību.                                                                             |
| `tc(key, params, defaultValue)`                 | Tulko atslēgu ar daudzskaitļa atbalstu.                                                                                               |
| `setTranslationsFromJson(locale, translations)` | Ielādē tulkojumus no JSON objekta konkrētai lokalizācijai.                                                                               |
| `getLocale()`                                   | Atgriež pašreizējo lokalizāciju.                                                                                                                |
| `setLocale(val)`                                | Iestata pašreizējo lokalizāciju.                                                                                                                   |
| `getLocaleName()`                               | Atgriež pašreizējās lokalizācijas nosaukumu.                                                                                                           |
| `setLocaleName(val)`                            | Iestata pašreizējās lokalizācijas nosaukumu.                                                                                                              |
| `getLocales()`                                  | Atgriež pieejamo lokalizāciju sarakstu.                                                                                                     |
| `setLocales(val)`                               | Iestata pieejamo lokalizāciju sarakstu.                                                                                                        |
| `defaultLocale()`                               | Atgriež noklusējuma lokalizāciju.                                                                                                                |
| `setDefaultLocale(val)`                         | Iestata noklusējuma lokalizāciju.                                                                                                                   |
| `getRouteName()`                                | Atgriež pašreizējā maršruta nosaukumu.                                                                                                            |
| `settRouteName(val)`                            | Iestata pašreizējā maršruta nosaukumu.                                                                                                               |
| `ts(key, params, defaultValue)`                 | Tulko atslēgu un atgriež rezultātu kā virkni.                                                                                       |
| `tn(value, options?)`                           | Formatē skaitli ar iekļautajām `Intl.NumberFormatOptions`. Nosauktiem formātiem nepieciešama moduļa konfigurācija, un tie nav pieejami šajā atsevišķajā palīgā. |
| `td(value, options?)`                           | Formatē datumu ar iekļautajām `Intl.DateTimeFormatOptions`. Nosauktiem formātiem nepieciešama moduļa konfigurācija, un tie nav pieejami šajā atsevišķajā palīgā. |
| `has(key)`                                      | Pārbauda, vai tulkojuma atslēga eksistē.                                                                                                        |
| `resolveTranslations()`                             | Atgriež aktīvo tulkojumu koku pašreizējai lokalizācijai un maršrutam.                                                                      |
| `setTranslation(key, value)`                    | Aizvieto vērtību atslēgai `key` aktīvajā vārdnīcā (aizvieto, nesapludina).                                                                 |
| `mergeTranslations(newTranslations)`              | Sapludina tulkojumus aktīvajā lokalizācijā izpildlaikā.                                                                                     |

Sekojot šiem soļiem, tu vari efektīvi testēt `Nuxt I18n Micro` moduli un nodrošināt, ka tavas lietotnes lokalizācijas funkcijas darbojas kā gaidīts.
