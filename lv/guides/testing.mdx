# 🧪 Moduļa `Nuxt I18n Micro` testēšana

## 📖 Ievads testēšanā

Moduļa `Nuxt I18n Micro` testēšana ir būtiska, lai nodrošinātu, ka jūsu lietotnes lokalizācijas funkcijas darbojas kā paredzēts. Šī dokumentācija palīdzēs jums iestatīt testēšanas vidi, izveidot vitest imitācijas konfigurācijas un rakstīt testus jūsu komponentiem. Praktisku piemēru meklējiet [piemēru projektā GitHub](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/test-utils/example).

Skatiet [Maršrutēšanas stratēģiju testēšana](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/testing-strategies.md), lai uzzinātu, kā šis repozitorijs palaiž savus testu komplektus — `unit` / `integration` / `e2e` Vitest projektus, katras stratēģijas failus (`test/strategies-*.test.ts`) un ģenerē regresijas testus.

## 🛠️ Testēšanas vides iestatīšana

### 1. Instalējiet `@i18n-micro/test-utils`

Vispirms jāinstalē testēšanas utilītas modulim `Nuxt I18n Micro`. Šī pakotne nodrošina nepieciešamos rīkus jūsu i18n konfigurāciju imitēšanai un testēšanai.

```bash
npm install @i18n-micro/test-utils --save-dev
```

### 2. Izveidojiet imitācijas konfigurācijas failu

Pēc tam izveidojiet failu, lai iestatītu imitācijas i18n konfigurāciju. Šis fails testu laikā tiks izmantots, lai imitētu i18n funkcijas un utilītas.

```typescript
// tests/unit-setup.ts

import { mockNuxtImport } from '@nuxt/test-utils/runtime'
import { vi } from 'vitest'
import { i18nUtils } from '@i18n-micro/test-utils'

export function createFakeI18n() {
  return {
    $getLocale: vi.fn(i18nUtils.getLocale),
    $t: vi.fn(i18nUtils.t),
    $tc: vi.fn(i18nUtils.tc),
    $setLocale: vi.fn(i18nUtils.setLocale),
    $getLocaleName: vi.fn(i18nUtils.getLocaleName),
    $setLocaleName: vi.fn(i18nUtils.setLocaleName),
    $getLocales: vi.fn(i18nUtils.getLocales),
    $setLocales: vi.fn(i18nUtils.setLocales),
    $defaultLocale: vi.fn(i18nUtils.defaultLocale),
    $setDefaultLocale: vi.fn(i18nUtils.setDefaultLocale),
    $getRouteName: vi.fn(i18nUtils.getRouteName),
    $settRouteName: vi.fn(i18nUtils.settRouteName),
    $ts: vi.fn(i18nUtils.ts),
    $tn: vi.fn(i18nUtils.tn),
    $td: vi.fn(i18nUtils.td),
    $has: vi.fn(i18nUtils.has),
    $resolveTranslations: vi.fn(i18nUtils.resolveTranslations),
    $setTranslation: vi.fn(i18nUtils.setTranslation),
    $mergeTranslations: vi.fn(i18nUtils.mergeTranslations),
    $switchLocaleRoute: vi.fn(i18nUtils.switchLocaleRoute),
    $switchLocalePath: vi.fn(i18nUtils.switchLocalePath),
    $switchLocale: vi.fn(i18nUtils.switchLocale),
    $switchRoute: vi.fn(i18nUtils.switchRoute),
    $localeRoute: vi.fn(i18nUtils.localeRoute),
    $localePath: vi.fn(i18nUtils.localePath),
    $setI18nRouteParams: vi.fn(i18nUtils.setI18nRouteParams),
  }
}

mockNuxtImport<() => ReturnType<typeof createFakeI18n>>('useI18n', () => vi.fn(() => createFakeI18n()))

export const setTranslationsFromJson = i18nUtils.setTranslationsFromJson
```

### 3. Konfigurējiet Vitest

Tagad konfigurējiet Vitest, lai tas izmantotu imitācijas konfigurācijas failu un iestatītu testēšanas vidi.

```typescript
// vitest.config.ts

import { defineVitestConfig } from '@nuxt/test-utils/config'

export default defineVitestConfig({
  test: {
    watch: false,
    setupFiles: ['./tests/unit-setup.ts'],
    include: ['./**/*.spec.ts'],
  },
})
```

## 🧪 Testu rakstīšana

### Piemēra komponents

Šeit ir vienkārša komponenta piemērs, kas izmanto `useI18n` komponējamo funkciju ziņojumu tulkošanai.

```vue
<script setup lang="ts">
const { $t } = useI18n()

const props = defineProps({
  message: {
    type: String,
    default: null,
  },
})

// Test to see that $t works in script setup as well as the template
const message = props.message || $t('defaultMessage')
</script>

<template>
  <div>
    <p>Test from component: {{ $t('welcome') }}</p>
    <p data-testid="message">Test message from props: {{ message }}</p>
  </div>
</template>
```

### Testu fails

Tagad uzrakstīsim šī komponenta testu.

```typescript
// tests/unit/example.spec.ts

import { describe, it, expect, beforeEach } from 'vitest'
import { mount } from '@vue/test-utils'
import ExampleComponent from '@/components/ExampleComponent.vue'
import fs from 'fs'
import path from 'path'
import { setTranslationsFromJson } from './unit-setup'

describe('ExampleComponent', () => {
  beforeEach(async () => {
    const fileContent = fs.readFileSync(path.join(__dirname, '../../locales/en-GB.json')).toString()
    await setTranslationsFromJson('en', JSON.parse(fileContent))
  })

  it('renders the welcome message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.text()).toContain('Test from component: Welcome')
  })

  it('renders the default message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Default Message')
  })

  it('renders the custom message correctly', () => {
    const wrapper = mount(ExampleComponent, {
      props: {
        message: 'Custom Message',
      },
    })
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Custom Message')
  })
})
```

## 📝 Testēšanas labākā prakse

- **🔧 Imitējiet i18n funkcijas:** vienmēr imitējiet i18n funkcijas, izmantojot `@i18n-micro/test-utils`, lai nodrošinātu konsekventus un paredzamus testu rezultātus.
- **⚙️ Izmantojiet Vitest vienību testiem:** Vitest ir jaudīgs testēšanas ietvars Vue lietotnēm. Izmantojiet to, lai rakstītu vienību testus saviem komponentiem.
- **📚 Dokumentējiet savus testus:** skaidri dokumentējiet katra testa mērķi un paredzamos rezultātus. Tas palīdzēs saglabāt skaidrību un atvieglos testu izpratni citiem (vai jums nākotnē).

## 📊 i18n utilītmetodes

Zemāk esošajā tabulā ir aprakstītas visas `@i18n-micro/test-utils` piedāvātās utilītmetodes.

| Metode                                          | Apraksts                                                                                                                                |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `t(key, params, defaultValue)`                  | Tulko atslēgu ar izvēles parametriem un noklusējuma vērtību.                                                                             |
| `tc(key, params, defaultValue)`                 | Tulko atslēgu ar daudzskaitļa formu atbalstu.                                                                                               |
| `setTranslationsFromJson(locale, translations)` | Ielādē tulkojumus no JSON objekta konkrētai lokālei.                                                                               |
| `getLocale()`                                   | Atgriež pašreizējo lokāli.                                                                                                                |
| `setLocale(val)`                                | Iestata pašreizējo lokāli.                                                                                                                   |
| `getLocaleName()`                               | Atgriež pašreizējo lokāles nosaukumu.                                                                                                           |
| `setLocaleName(val)`                            | Iestata pašreizējo lokāles nosaukumu.                                                                                                              |
| `getLocales()`                                  | Atgriež pieejamo lokāļu sarakstu.                                                                                                     |
| `setLocales(val)`                               | Iestata pieejamo lokāļu sarakstu.                                                                                                        |
| `defaultLocale()`                               | Atgriež noklusējuma lokāli.                                                                                                                |
| `setDefaultLocale(val)`                         | Iestata noklusējuma lokāli.                                                                                                                   |
| `getRouteName()`                                | Atgriež pašreizējā maršruta nosaukumu.                                                                                                            |
| `settRouteName(val)`                            | Iestata pašreizējā maršruta nosaukumu.                                                                                                               |
| `ts(key, params, defaultValue)`                 | Tulko atslēgu un atgriež rezultātu kā virkni.                                                                                       |
| `tn(value, options?)`                           | Formatē skaitli ar iekļautām `Intl.NumberFormatOptions`. Nosauktiem formātiem nepieciešama moduļa konfigurācija, un tie šajā autonomajā palīgā nav pieejami. |
| `td(value, options?)`                           | Formatē datumu ar iekļautām `Intl.DateTimeFormatOptions`. Nosauktiem formātiem nepieciešama moduļa konfigurācija, un tie šajā autonomajā palīgā nav pieejami. |
| `has(key)`                                      | Pārbauda, vai tulkojuma atslēga eksistē.                                                                                                        |
| `resolveTranslations()`                             | Atgriež aktīvo tulkojumu koku pašreizējai lokālei un maršrutam.                                                                      |
| `setTranslation(key, value)`                    | Aizvieto vērtību pie `key` aktīvajā vārdnīcā (aizvieto, nevis sapludina).                                                                 |
| `mergeTranslations(newTranslations)`              | Izpildlaikā sapludina tulkojumus aktīvajā lokālē.                                                                                     |

Sekojot šiem soļiem, jūs varat efektīvi testēt moduli `Nuxt I18n Micro` un nodrošināt, ka jūsu lietotnes lokalizācijas funkcijas darbojas kā paredzēts.
