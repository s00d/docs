# Statisko failu izslēgšana no i18n maršrutēšanas

## Pārskats

Pēc noklusējuma nuxt-i18n-micro automātiski izslēdz izplatītus statiskos failus no i18n maršrutēšanas apstrādes. Tomēr vari arī konfigurēt pielāgotus izslēgšanas modeļus, lai novērstu, ka konkrētus ceļus apstrādā i18n sistēma.

## Iebūvētās izslēgšanas

Modulis automātiski izslēdz šādus failu tipus un modeļus:

- **Sitemap faili**: `/sitemap*.xml`, `/sitemap-en.xml` un citi.
- **SEO faili**: `/robots.txt`, `/favicon.ico`.
- **PWA faili**: `/manifest.json`, `/sw.js`, `/workbox-*.js`.
- **Statiskie līdzekļi**: faili ar paplašinājumiem, piemēram, `.xml`, `.txt`, `.ico`, `.json`, `.js`, `.css`, `.png`, `.jpg`, `.jpeg`, `.gif`, `.svg`, `.woff`, `.woff2`, `.ttf`, `.eot`.
- **Iekšējie Nuxt ceļi**: jebkurš ceļš, kas sākas ar `__` (piemēram, `/__nuxt/`).

## Pielāgoti izslēgšanas modeļi

Vari definēt pielāgotus izslēgšanas modeļus, izmantojot opciju `excludePatterns`:

```typescript
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],

  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'it', iso: 'it-IT' },
    ],
    defaultLocale: 'en',

    // Custom exclusion patterns
    excludePatterns: [
      // String patterns (exact match or prefix)
      '/api/health',
      '/admin',

      // String patterns with wildcards
      '/api/*',
      '/admin/**',

      // Regular expressions
      /^\/api\/v\d+\//,
      /\.(pdf|doc|docx)$/,
    ],
  },
})
```

## Modeļu tipi

### Virkņu modeļi

- **Precīza atbilstība**: `'/api/health'` — atbilst tieši `/api/health`.
- **Prefiksa atbilstība**: `'/admin'` — atbilst `/admin` un `/admin/dashboard`.
- **Aizvietotājzīmes**: `'/api/*'` — atbilst `/api/users`, bet ne `/api/users/123`.
- **Dziļās aizvietotājzīmes**: `'/admin/**'` — atbilst `/admin/users` un `/admin/users/123`.

### Regulārās izteiksmes

Izmanto RegExp objektus sarežģītai modeļa atbilstībai:

```typescript
excludePatterns: [
  /^\/api\/v\d+\//, // API versioned routes
  /\.(pdf|doc|docx)$/, // Document files
  /^\/static\//, // Static directory
  /^\/[a-z]{2}\/api\//, // Localized API routes
]
```

## Lietošanas gadījumi

### SEO faili

```typescript
excludePatterns: ['/sitemap.xml', '/sitemap-*.xml', '/robots.txt', '/favicon.ico']
```

### API maršruti

```typescript
excludePatterns: ['/api/**', '/graphql', '/webhook/**']
```

### Administratora paneļi

```typescript
excludePatterns: ['/admin', '/admin/**', '/dashboard']
```

### Statiskie līdzekļi

```typescript
excludePatterns: ['/assets/**', '/static/**', '/uploads/**']
```

## Kā tas darbojas

1. **Servera starpprogrammatūra**: Nitro starpprogrammatūra darbojas vispirms, lai pārbaudītu izslēgšanas modeļus.
2. **Lapas apstrāde**: lapas atrisināšanas laikā izslēgtie ceļi tiek izlaisti.
3. **Catch-all maršruts**: atkāpšanās maršruts pārbauda izslēgumus pirms apstrādes.
4. **Pirmsrenderēšana**: izslēgtie ceļi netiek iekļauti pirmsrenderētajos maršrutos.

## Ietekme uz veiktspēju

- Izslēgšanas pārbaudes ir optimizētas un darbojas agri pieprasījuma dzīves ciklā.
- Iebūvētie modeļi izmanto efektīvu regex atbilstību.
- Pielāgotie modeļi tiek kešoti un atkārtoti izmantoti.
- Minimāla veiktspējas slodze izslēgtajiem ceļiem.

## Problēmu novēršana

### Statiskie faili joprojām tiek pārtverti

1. **Pārbaudi modeļa sintaksi**: pārliecinies, ka tavi modeļi atbilst precīzai ceļa struktūrai.
2. **Izmanto regex sarežģītiem modeļiem**: virkņu aizvietotājzīmēm ir ierobežojumi.
3. **Testē modeļus**: izmanto pārlūka izstrādes rīkus, lai pārbaudītu faktisko pieprasījuma ceļu.
4. **Pārbaudi kārtību**: pārliecinies, ka izslēgšanas modeļi ir definēti pirms citas i18n konfigurācijas.

### Modelis nedarbojas

```typescript
// ❌ Wrong - this won't work
excludePatterns: ['sitemap.xml']

// ✅ Correct - include leading slash
excludePatterns: ['/sitemap.xml']

// ✅ Better - use regex for flexibility
excludePatterns: [/^\/sitemap.*\.xml$/]
```

### Atkļūdošanas režīms

Iespējo atkļūdošanas režīmu, lai redzētu izslēgšanas apstrādi:

```typescript
i18n: {
  debug: true,
  excludePatterns: ['/api/**']
}
```

Tas reģistrēs izslēgšanas lēmumus konsolē.

## Migrācija no risinājumiem

Ja tu izmantoji risinājumus, piemēram, maršruta noteikumus vai starpprogrammatūru, tos tagad vari aizvietot ar `excludePatterns`:

```typescript
// ❌ Old workaround
export default defineNuxtConfig({
  routeRules: {
    '/sitemap*.xml': { headers: { 'content-type': 'application/xml' } },
  },
})

// ✅ New approach
export default defineNuxtConfig({
  i18n: {
    excludePatterns: ['/sitemap*.xml'],
  },
})
```

Jaunā pieeja ir uzticamāka un darbojas vairākos maršrutēšanas sistēmas līmeņos.
