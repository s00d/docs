# Statisko failu izslēgšana no i18n maršrutēšanas

## Pārskats

Pēc noklusējuma nuxt-i18n-micro automātiski izslēdz izplatītākos statiskos failus no i18n maršrutēšanas apstrādes. Tomēr varat konfigurēt arī pielāgotus izslēgšanas modeļus, lai novērstu, ka konkrētus ceļus apstrādā i18n sistēma.

## Iebūvētās izslēgšanas

Modulis automātiski izslēdz šādus failu tipus un modeļus:

- **Sitemapi**: `/sitemap*.xml`, `/sitemap-en.xml` u.c.
- **SEO faili**: `/robots.txt`, `/favicon.ico`
- **PWA faili**: `/manifest.json`, `/sw.js`, `/workbox-*.js`
- **Statiskie resursi**: faili ar paplašinājumiem, piemēram, `.xml`, `.txt`, `.ico`, `.json`, `.js`, `.css`, `.png`, `.jpg`, `.jpeg`, `.gif`, `.svg`, `.woff`, `.woff2`, `.ttf`, `.eot`
- **Iekšējie Nuxt ceļi**: jebkurš ceļš, kas sākas ar `__` (piemēram, `/__nuxt/`)

## Pielāgoti izslēgšanas modeļi

Pielāgotus izslēgšanas modeļus var definēt, izmantojot opciju `excludePatterns`:

```typescript
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],

  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'it', iso: 'it-IT' },
    ],
    defaultLocale: 'en',

    // Custom exclusion patterns
    excludePatterns: [
      // String patterns (exact match or prefix)
      '/api/health',
      '/admin',

      // String patterns with wildcards
      '/api/*',
      '/admin/**',

      // Regular expressions
      /^\/api\/v\d+\//,
      /\.(pdf|doc|docx)$/,
    ],
  },
})
```

## Modeļu tipi

### Virkņu modeļi

- **Precīza atbilstība**: `'/api/health'` — precīzi atbilst `/api/health`
- **Priedēkļa atbilstība**: `'/admin'` — atbilst `/admin` un `/admin/dashboard`
- **Aizstājējzīmes**: `'/api/*'` — atbilst `/api/users`, bet ne `/api/users/123`
- **Dziļās aizstājējzīmes**: `'/admin/**'` — atbilst `/admin/users` un `/admin/users/123`

### Regulārās izteiksmes

Izmantojiet RegExp objektus sarežģītai modeļu atbilstībai:

```typescript
excludePatterns: [
  /^\/api\/v\d+\//, // API versioned routes
  /\.(pdf|doc|docx)$/, // Document files
  /^\/static\//, // Static directory
  /^\/[a-z]{2}\/api\//, // Localized API routes
]
```

## Lietošanas gadījumi

### SEO faili

```typescript
excludePatterns: ['/sitemap.xml', '/sitemap-*.xml', '/robots.txt', '/favicon.ico']
```

### API maršruti

```typescript
excludePatterns: ['/api/**', '/graphql', '/webhook/**']
```

### Administratora paneļi

```typescript
excludePatterns: ['/admin', '/admin/**', '/dashboard']
```

### Statiskie resursi

```typescript
excludePatterns: ['/assets/**', '/static/**', '/uploads/**']
```

## Kā tas darbojas

1. **Servera starpprogrammatūra**: vispirms tiek palaista Nitro starpprogrammatūra, lai pārbaudītu izslēgšanas modeļus.
2. **Lapas apstrāde**: lapas atrisināšanas laikā izslēgtie ceļi tiek izlaisti.
3. **Universālais (catch-all) maršruts**: rezerves maršruts pārbauda izslēgumus pirms apstrādes.
4. **Iepriekšēja renderēšana**: izslēgtie ceļi netiek iekļauti iepriekš renderētajos maršrutos.

## Ietekme uz veiktspēju

- Izslēgšanas pārbaudes ir optimizētas un tiek veiktas pieprasījuma dzīves cikla sākumā
- Iebūvētie modeļi izmanto efektīvu regex atbilstību
- Pielāgotie modeļi tiek kešoti un atkārtoti izmantoti
- Minimāla veiktspējas papildslodze izslēgtajiem ceļiem

## Problēmu novēršana

### Statiskie faili joprojām tiek pārtverti

1. **Pārbaudiet modeļa sintaksi**: nodrošiniet, ka jūsu modeļi atbilst precīzai ceļa struktūrai.
2. **Izmantojiet regex sarežģītiem modeļiem**: virkņu aizstājējzīmēm ir ierobežojumi.
3. **Testējiet modeļus**: izmantojiet pārlūka izstrādātāju rīkus, lai pārbaudītu faktisko pieprasījuma ceļu.
4. **Pārbaudiet secību**: nodrošiniet, ka izslēgšanas modeļi ir definēti pirms citas i18n konfigurācijas.

### Modelis nedarbojas

```typescript
// ❌ Wrong - this won't work
excludePatterns: ['sitemap.xml']

// ✅ Correct - include leading slash
excludePatterns: ['/sitemap.xml']

// ✅ Better - use regex for flexibility
excludePatterns: [/^\/sitemap.*\.xml$/]
```

### Atkļūdošanas režīms

Iespējojiet atkļūdošanas režīmu, lai redzētu izslēgšanas apstrādi:

```typescript
i18n: {
  debug: true,
  excludePatterns: ['/api/**']
}
```

Tas konsolē reģistrēs izslēgšanas lēmumus.

## Migrācija no risinājumiem apkārtceļiem

Ja jūs izmantojāt apkārtceļus, piemēram, maršrutu noteikumus vai starpprogrammatūru, tagad tos varat aizstāt ar `excludePatterns`:

```typescript
// ❌ Old workaround
export default defineNuxtConfig({
  routeRules: {
    '/sitemap*.xml': { headers: { 'content-type': 'application/xml' } },
  },
})

// ✅ New approach
export default defineNuxtConfig({
  i18n: {
    excludePatterns: ['/sitemap*.xml'],
  },
})
```

Jaunā pieeja ir uzticamāka un darbojas vairākos maršrutēšanas sistēmas līmeņos.
