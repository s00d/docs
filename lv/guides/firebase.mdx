# 🔥 Firebase AppHosting izvietošana

## 📖 Ievads

Firebase AppHosting ir jaudīga platforma Nuxt lietotņu izvietošanai ar bezservera infrastruktūru. Tomēr, izvietojot lietotnes ar `nuxt-i18n-micro`, vari saskarties ar specifiskām problēmām, kas saistītas ar to, kā tiek apkalpoti tulkojumu JSON faili. Šis ceļvedis nodrošina visaptverošus risinājumus, lai nodrošinātu, ka tavi tulkojumi ražošanā darbojas pareizi.

## ⚠️ Izplatītas problēmas

### Tulkojumu faili netiek piemēroti

**Simptomi:**

- ✅ Tulkojumi lieliski darbojas izstrādes režīmā (`nuxt dev`).
- ❌ Pēc izvietošanas uz Firebase AppHosting JSON faili tiek ielādēti, bet tulkojumi netiek piemēroti.
- ❌ Konsolē neparādās kļūdas.
- ❌ Tulkojumu faili ir redzami tīkla cilnē, bet tiem ir nepareizs `Content-Type: text/html`, nevis `application/json`.

**Sakņu cēlonis:**

Firebase AppHosting (un citas platformas, kas izmanto Nitro pirmsrenderēšanu) var apkalpot pirmsrenderētus JSON failus ar nepareiziem MIME veidiem. Kad pārlūks saņem JSON failus ar `Content-Type: text/html`, tas nevar tos pareizi parsēt, izraisot tulkojumu klusu neizdošanos.

## ✅ Risinājumi

### 1. risinājums: maršruta noteikumu konfigurācija (ieteikts)

Vienkāršākais risinājums ir pievienot skaidras galvenes tulkojumu maršrutiem tavā `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],

  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'de', iso: 'de-DE', dir: 'ltr' },
      // ... other locales
    ],
    strategy: 'prefix_except_default',
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
    metaBaseUrl: 'https://your-domain.com',
  },

  // Add route rules for translation files
  routeRules: {
    '/_locales/**': {
      headers: {
        'Content-Type': 'application/json',
        'Cache-Control': 'public, max-age=3600, s-maxage=3600',
      },
    },
  },
})
```

**Priekšrocības:**

- ✨ Vienkārša konfigurācija.
- 🚀 Uzlabo veiktspēju ar pareizu kešošanu.
- 🔒 Darbojas visās izvietošanas platformās.

### 2. risinājums: pielāgots API bāzes URL

Ja tu izmanto pielāgotu `apiBaseUrl` (tikai ceļa prefiksu), attiecīgi pielāgo maršruta noteikumus:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],

  i18n: {
    apiBaseUrl: '/api/translations', // Path prefix only, not a full URL
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
  },

  routeRules: {
    '/api/translations/**': {
      headers: {
        'Content-Type': 'application/json',
        'Cache-Control': 'public, max-age=3600',
      },
    },
  },
})
```

### 3. risinājums: Firebase specifiska konfigurācija

Izveido vai atjaunini savu `firebase.json` failu projekta saknē:

```json
{
  "hosting": {
    "public": ".output/public",
    "cleanUrls": true,
    "rewrites": [
      {
        "source": "**",
        "function": "server"
      }
    ],
    "headers": [
      {
        "source": "/_locales/**/*.json",
        "headers": [
          {
            "key": "Content-Type",
            "value": "application/json"
          },
          {
            "key": "Cache-Control",
            "value": "public, max-age=3600, immutable"
          },
          {
            "key": "Access-Control-Allow-Origin",
            "value": "*"
          }
        ]
      }
    ]
  },
  "functions": {
    "source": ".output/server"
  }
}
```


### 4. risinājums: Firebase Functions konfigurācija

Firebase Functions izvietošanai pārliecinies, ka tavs `functions/package.json` ietver nepieciešamās atkarības:

```json
{
  "name": "functions",
  "type": "module",
  "engines": {
    "node": "18"
  },
  "dependencies": {
    "firebase-admin": "^12.0.0",
    "firebase-functions": "^5.0.0"
  }
}
```

## 🔍 Atkļūdošana

### Iespējo atkļūdošanas režīmu

Pievieno atkļūdošanas reģistrēšanu, lai identificētu problēmas:

```typescript
export default defineNuxtConfig({
  i18n: {
    debug: true,
    // Your other config...
  },
})
```

Tas izvadīs detalizētus žurnālus par:

- 📝 Tulkojumu failu ielādi.
- 🔄 Kešatmiņas operācijām.
- ⚠️ Ielādes kļūdām.

### Pārbaudi tīkla cilni

1. Atver DevTools → tīkla cilne.
2. Filtrē pēc "data.json".
3. Noklikšķini uz tulkojumu faila pieprasījuma.
4. Pārbaudi **atbildes galvenes**:
   - ✅ `Content-Type: application/json` (pareizi).
   - ❌ `Content-Type: text/html` (nepareizi — nepieciešams labojums).

### Pārbaudi pirmsrenderēšanas izvadi

Pēc būvēšanas pārbaudi, vai tiek ģenerēti tulkojumu faili:

```bash
pnpm build

# Check public payload copy (premerged layout)
ls -la .output/public/_locales/index/en/
# → data.json
```

Katrai lokalizācijai zem katras lapas jāredz `data.json`.

## 🚀 Būvēšanas konfigurācija

### Nitro iepriekšstatītais iestatījums

Firebase AppHosting nodrošini, ka izmanto pareizo iepriekšstatīto iestatījumu:

```typescript
export default defineNuxtConfig({
  nitro: {
    preset: 'firebase-app-hosting',
    firebase: {
      gen: 2,
      httpsOptions: {
        region: 'us-central1',
        maxInstances: 3,
      },
    },
  },
})
```

### Pirmsrenderēšanas konfigurācija

Konfigurē pirmsrenderēšanu optimālai veiktspējai:

```typescript
export default defineNuxtConfig({
  nitro: {
    prerender: {
      crawlLinks: true,
      routes: ['/'],
      ignore: ['/api/**', '/admin/**'],
    },
  },
})
```

## ✅ Verifikācijas kontrolsaraksts

Pēc labojumu piemērošanas pārbaudi, vai viss darbojas:

- [ ] Būvējums pabeidzas bez kļūdām.
- [ ] Tulkojumu JSON faili atrodas `.output/public/_locales/\{page\}/\{locale\}/data.json`.
- [ ] Tīkla cilnē tulkojumu failiem redzams `Content-Type: application/json`.
- [ ] Tulkojumi pareizi tiek attēloti pirmajā lapas ielādē.
- [ ] Konsolē nav hidratācijas neatbilstību.
- [ ] Valodas pārslēgšana darbojas pareizi.
- [ ] SEO meta tagi tiek ģenerēti pareizi.

## 🔄 Izvietošanas darbplūsma

### 1. Sagatavo būvējumu

```bash
# Install dependencies
pnpm install

# Build for production
pnpm build

# Verify public payload copy
ls -la .output/public/_locales/index/en/data.json
```

### 2. Izvieto uz Firebase

```bash
# Install Firebase CLI if not already installed
npm install -g firebase-tools

# Login to Firebase
firebase login

# Initialize Firebase (first time only)
firebase init hosting

# Deploy
firebase deploy --only hosting,functions
```

### 3. Pārbaudi izvietojumu

1. Apmeklē savu izvietoto vietni.
2. Atver DevTools → tīkla cilne.
3. Navigē uz lapu.
4. Pārbaudi, vai `/_locales/index/en/data.json` (vai tava noklusējuma lokalizācija) tiek ielādēts ar:
   - Statuss: 200.
   - Content-Type: application/json.
   - Atbilde satur derīgu JSON.

## 🔧 Problēmu novēršana

### Problēma: 404 kļūdas tulkojumu failiem

**Risinājums:** pārliecinies, ka tulkojumu faili tiek kopēti izvades mapē:

```typescript
// nuxt.config.ts
export default defineNuxtConfig({
  nitro: {
    publicAssets: [
      {
        dir: 'locales',
        maxAge: 60 * 60 * 24 * 365, // 1 year
      },
    ],
  },
})
```

### Problēma: tulkojumi darbojas dažās lapās, bet ne citās

**Risinājums:** pārbaudi, vai lapām specifiskie tulkojumi tiek ģenerēti:

```bash
# Should show data.json for each page/locale
ls -la .output/public/_locales/index/en/
ls -la .output/public/_locales/about/en/

```

Ja trūkst lapām specifisku tulkojumu, pārliecinies, ka `disablePageLocales` nav iestatīts uz `true`:

```typescript
i18n: {
  disablePageLocales: false, // Ensure this is false
}
```

### Problēma: lēna tulkojumu ielāde

**Risinājums:** optimizē kešošanu un iepriekšielādi:

```typescript
routeRules: {
  '/_locales/**': {
    headers: {
      'Content-Type': 'application/json',
      'Cache-Control': 'public, max-age=31536000, immutable',
      'X-Content-Type-Options': 'nosniff'
    },
    prerender: true
  }
}
```

## ⚡ Veiktspējas optimizācija

### Iespējo saspiešanu

Firebase automātiski apstrādā Gzip/Brotli saspiešanu, bet pārliecinies, ka tavs būvējums ir optimizēts:

```typescript
export default defineNuxtConfig({
  vite: {
    build: {
      minify: 'terser',
      terserOptions: {
        compress: {
          drop_console: true,
        },
      },
    },
  },
})
```

### Slinka tulkojumu ielāde

`Nuxt I18n Micro` automātiski slinki ielādē tulkojumus pēc lapām. Tulkojumi tiek ielādēti tikai tad, kad tie nepieciešami, samazinot sākotnējo bandulīša izmēru. Šī ir iebūvēta funkcionalitāte — papildu konfigurācija nav nepieciešama.

Lai vēl vairāk optimizētu:

- Izmanto `disablePageLocales: false` (noklusējums), lai iespējotu lapām specifiskus tulkojumus.
- Uzturi saknes līmeņa tulkojumus minimālus.
- Izmanto maršrutam specifiskus tulkojumu failus lapas saturam.

<Tip>
Modulis automātiski iestata pareizas `Content-Type` galvenes, sākot no versijas **v3.0.0+**. Ja tu piedzīvo problēmas, jaunini uz jaunāko versiju:

```bash
pnpm update nuxt-i18n-micro@latest
```
</Tip>
