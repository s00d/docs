# 🛠️ DevTools modulī `nuxt-i18n-micro`

## Vue DevTools (pārlūka paplašinājums)

Izstrādes režīmā modulis var reģistrēt **Vue DevTools** pielāgotu inspektoru un laika joslu caur `@vue/devtools-api`. Tas ir atsevišķi no zemāk esošās Nuxt DevTools cilnes.

| Rīks | Piemērots |
|------|----------|
| **Vue DevTools** | Aktīvai lokalizācijai, atmiņā esošai tulkojumu kešatmiņai, `$t` laika joslai (`debug: true`), trūkstošo atslēgu notikumiem. |
| **Nuxt DevTools cilne** | JSON failu rediģēšanai diskā, konfigurācijas pārskatam, importam/eksportam. |

Vue-devtools spraudnis tiek reģistrēts tikai `nuxt dev` darbības laikā (ne ražošanas būvējumos). Tikai izstrādei paredzētais tilta stāvoklis galvenajā spraudnī tiek noņemts ar `import.meta.dev` nedzīva koda likvidēšanu.

Atspējo pārlūka integrāciju, saglabājot Nuxt cilni:

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

Detalizētiem `$t` laika joslas notikumiem nepieciešams `debug: true`.

## 📖 Kas ir Nuxt DevTools?

DevTools ir jaudīgs izstrādes palīgs, kas vienmērīgi integrēts modulī `nuxt-i18n-micro`. Tas nodrošina intuitīvu saskarni lokalizācijas un tulkošanas uzdevumu pārvaldībai, padarot tavu darbplūsmu ātrāku un efektīvāku. Paredzēts izstrādātājiem, kuri novērtē ērtību, Nuxt DevTools mazina plaisu starp kodēšanu un izpildlaika pārvaldību.

## 🌟 Galvenās DevTools funkcijas modulī `nuxt-i18n-micro`

### 1. **Lokalizācijas pārvaldība**

Bez piepūles pārlūko, izvēlies un pārvaldi lokalizācijas savā lietotnē. Vai tu strādā ar vienu valodu vai vairākām, DevTools nodrošina centralizētu centru visu lokalizācijas iestatījumu apstrādei.

### 2. **Tulkojumu rediģēšana**

Rediģē tulkojumu failus tieši caur integrētu JSON redaktoru. Tas novērš nepieciešamību pēc ārējiem rīkiem, ļaujot reāllaika atjauninājumus un izmaiņas, nepārtraucot tavu darbplūsmu.

### 3. **Failu imports un eksports**

Vienkāršo tulkojumu failu pārvaldības procesu:

- **Eksports**: saglabā tulkojumus kā JSON failu dublējumkopijām vai ārējai lietošanai.
- **Imports**: ielādē atjauninātus tulkojumu failus projektā, lai saturs būtu aktuāls.

### 4. **Reāllaika priekšskatījumi**

Skati izmaiņas nekavējoties izstrādes vidē. Šī funkcija nodrošina, ka tulkojumi un konfigurācijas ir precīzas, pirms tās nonāk publiskajā apritē.

### 5. **Vienmērīga Nuxt integrācija**

DevTools darbojas natīvi ar `nuxt-i18n-micro`, uzlabojot tā iespējas, nepieprasot papildu iestatīšanu. Tas pielāgojas tavām lokalizācijas vajadzībām, saglabājot Nuxt modulāro un elastīgo struktūru.

---

## 🛠️ Kāpēc izmantot DevTools?

Nuxt DevTools ir neaizvietojams papildinājums projektiem, kas prasa lokalizāciju. Tas palīdz izstrādātājiem:

- **Ietaupot laiku**: automatizē atkārtojošus uzdevumus, piemēram, failu pārvaldību un formāta validāciju.
- **Samazinot kļūdas**: nodrošina drošu, intuitīvu vidi tulkojumu rediģēšanai.
- **Uzlabojot sadarbību**: ļauj izstrādātājiem un ne-izstrādātājiem viegli pārvaldīt tulkojumus.
- **Racionalizējot darbplūsmas**: konsolidē vairākus lokalizācijas uzdevumus vienā saskarnē.

## 🚀 Pārņem kontroli pār lokalizāciju

Ar Nuxt DevTools, kas integrēts modulī `nuxt-i18n-micro`, daudzvalodu lietotņu pārvaldība kļūst vienkārša un efektīva. Vai tu precīzi noskaņo tulkojumus vai pievieno jaunas lokalizācijas, DevTools nodrošina tevi ar rīkiem, kas nepieciešami, lai piegādātu izsmalcinātu, lietotājam draudzīgu pieredzi.
