# 🛠️ DevTools modulī `nuxt-i18n-micro`

## Vue DevTools (pārlūka paplašinājums)

Izstrādes laikā modulis, izmantojot `@vue/devtools-api`, var reģistrēt **Vue DevTools** pielāgotu inspektoru un laika joslu. Tas ir atsevišķi no zemāk aprakstītā Nuxt DevTools cilnes.

| Rīks | Piemērots |
|------|----------|
| **Vue DevTools** | Aktīvā lokāle, atmiņā esošs tulkojumu kešs, `$t` laika josla (`debug: true`), trūkstošu atslēgu notikumi |
| **Nuxt DevTools cilne** | JSON failu rediģēšana diskā, konfigurācijas pārskats, imports/eksports |

vue-devtools spraudnis tiek reģistrēts tikai `nuxt dev` laikā (nevis produkcijas būvējumos). Izstrādes tilta stāvokli galvenajā spraudnī noņem `import.meta.dev` mirušā koda elimināciju.

Atspējojiet pārlūka integrāciju, saglabājot Nuxt cilni:

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

Detalizēti `$t` laika joslas notikumi prasa `debug: true`.

## 📖 Kas ir Nuxt DevTools?

DevTools ir jaudīgs izstrādes palīgs, kas nemanāmi integrēts modulī `nuxt-i18n-micro`. Tas piedāvā intuitīvu saskarni lokalizācijas un tulkošanas uzdevumu pārvaldībai, padarot jūsu darbplūsmu ātrāku un efektīvāku. Izstrādāts izstrādātājiem, kuri novērtē ērtību, Nuxt DevTools mazina plaisu starp kodēšanu un izpildlaika pārvaldību.

## 🌟 Galvenās DevTools funkcijas modulī `nuxt-i18n-micro`

### 1. **Lokāles pārvaldība**

Bez piepūles pārlūkojiet, atlasiet un pārvaldiet lokāles savā lietotnē. Neatkarīgi no tā, vai strādājat ar vienu vai vairākām valodām, DevTools nodrošina centralizētu punktu visu lokalizācijas iestatījumu apstrādei.

### 2. **Tulkojumu rediģēšana**

Rediģējiet tulkojumu failus tieši, izmantojot integrētu JSON redaktoru. Tas novērš nepieciešamību pēc ārējiem rīkiem, ļaujot veikt atjauninājumus un izmaiņas reāllaikā, nepārtraucot jūsu darbplūsmu.

### 3. **Failu imports un eksports**

Vienkāršojiet tulkojumu failu pārvaldības procesu:

- **Eksports**: saglabājiet tulkojumus kā JSON failu dublējumkopijām vai ārējai izmantošanai.
- **Imports**: ielādējiet atjauninātus tulkojumu failus projektā, lai saturs būtu aktuāls.

### 4. **Reāllaika priekšskatījumi**

Skatiet izmaiņas nekavējoties izstrādes vidē. Šī funkcija nodrošina, ka tulkojumi un konfigurācijas ir precīzas pirms nonākšanas produkcijā.

### 5. **Nemanāma Nuxt integrācija**

DevTools darbojas dabiski ar `nuxt-i18n-micro`, uzlabojot tā iespējas bez nepieciešamības pēc papildu iestatīšanas. Tas pielāgojas jūsu lokalizācijas vajadzībām, saglabājot Nuxt moduļa un elastīgo struktūru.

## 🛠️ Kāpēc izmantot DevTools?

Nuxt DevTools ir neaizstājams papildinājums projektiem, kuriem nepieciešama lokalizācija. Tas palīdz izstrādātājiem, nodrošinot:

- **Laika ietaupīšanu**: automatizē atkārtotus uzdevumus, piemēram, failu pārvaldību un formāta validāciju.
- **Kļūdu samazināšanu**: piedāvā drošu, intuitīvu vidi tulkojumu rediģēšanai.
- **Sadarbības uzlabošanu**: ļauj tulkojumus viegli pārvaldīt personām, kas nav izstrādātāji.
- **Darbplūsmu racionalizēšanu**: apvieno vairākus lokalizācijas uzdevumus vienā saskarnē.

## 🚀 Pārņemiet lokalizācijas kontroli

Ar Nuxt DevTools, kas integrēts modulī `nuxt-i18n-micro`, daudzvalodu lietotņu pārvaldība kļūst vienkārša un efektīva. Neatkarīgi no tā, vai jūs precīzi noregulējat tulkojumus vai pievienojat jaunas lokāles, DevTools sniedz jums visu nepieciešamo, lai piegādātu izsmalcinātu un lietotājam draudzīgu pieredzi.
