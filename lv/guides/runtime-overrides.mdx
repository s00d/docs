# i18n izpildlaika pārrakstīšanas

Izmantojiet šo ceļvedi, kad viens būvējuma artefakts jāpalaiž ar dažādiem lokāles noklusējumiem atkarībā no vides (piemēram, dažādām nomnieku instancēm).

## Ko var pārrakstīt izpildlaikā

Modulis atbalsta drošas izpildlaika pārrakstīšanas šādiem parametriem:

- `defaultLocale`
- `fallbackLocale`
- `disabledLocales`

Šīs pārrakstīšanas tiek piemērotas virs būvēšanas laika konfigurācijas no `.nuxt/i18n.strategy.mjs` un `.nuxt/i18n.config.mjs`.

## Ko nevar pārrakstīt izpildlaikā

`strategy` (`no_prefix`, `prefix`, `prefix_except_default`, `prefix_and_default`) ir būvēšanas laika jautājums, jo tā ietekmē ģenerēto maršrutu darbību.

Ja jūs padodat izpildlaika strategy pārrakstīšanu, tā tiek ignorēta un tiek izdots brīdinājums.

## RuntimeConfig balstītas pārrakstīšanas

Sniedziet izpildlaika vērtības zem `runtimeConfig.public.i18nRuntime`:

```ts
export default defineNuxtConfig({
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

## Vides mainīgo pārrakstīšanas

Pārrakstīšanas var konfigurēt arī ar vides mainīgajiem:

- `NUXT_I18N_DEFAULT_LOCALE`
- `NUXT_I18N_FALLBACK_LOCALE`
- `NUXT_I18N_DISABLED_LOCALES` (atdalīti ar komatiem, piem., `fr,it`)

Tiek atbalstīti arī rezerves aizstājējnosaukumi:

- `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES`

## Validācijas noteikumi

Izpildlaikā modulis validē pārrakstīšanas, lai izvairītos no bojāta stāvokļa:

- Jūs nevarat atspējot visas lokāles.
- `defaultLocale` jānorāda uz iespējotu lokāli.
- `fallbackLocale` jāeksistē deklarēto lokāļu sarakstā.

Ja pārrakstīšana ir nederīga, modulis saglabā drošu vērtību un reģistrē brīdinājumu.

## Piezīmes par vairāku instanču izvietošanu

Šī izpildlaika funkcija ir paredzēta, lai aktivizētu lokāles un noklusējumus pa instancēm bez atkārtotas būvēšanas.

Ja instancēm nepieciešamas dažādas URL stratēģijas (`no_prefix` pret `prefix`), izmantojiet atsevišķus būvējumus katrai stratēģijai.

## Atspējotās lokāles un statiskās payload

`runtimeConfig.public.i18nRuntime.disabledLocales` atjaunina maršrutēšanu, pārslēdzēju un Nitro payload **apstrādātāju** — bet Nitro pasniedz failus zem `public/` **pirms** šī apstrādātāja.

Ja `translationPayloads.publicAssets` (vai Node SSR piespiedu publiskā kopēšana) jau ir uzrakstījusi `/_locales/\{page\}/\{locale\}/data.json`, izpildlaika atspējošana šo failu nevar paslēpt. Priekšroku dodiet `locale.disabled: true` būvēšanas laikā, lai premerge neizstarotu šīs lokāles statiskās payload.
