# Izpildlaika i18n pārrakstījumi

Izmanto šo ceļvedi, kad tev nepieciešams, lai viens būvējuma artefakts darbotos ar atšķirīgiem lokalizācijas noklusējumiem katrā vidē (piemēram: dažādi nomnieku eksemplāri).

## Ko var pārrakstīt izpildlaikā

Modulis atbalsta drošus izpildlaika pārrakstījumus:

- `defaultLocale`
- `fallbackLocale`
- `disabledLocales`

Šie pārrakstījumi tiek piemēroti virs būvēšanas laika konfigurācijas no `.nuxt/i18n.strategy.mjs` un `.nuxt/i18n.config.mjs`.

## Ko nevar pārrakstīt izpildlaikā

`strategy` (`no_prefix`, `prefix`, `prefix_except_default`, `prefix_and_default`) ir būvēšanas laika jautājums, jo tas ietekmē ģenerēto maršrutu uzvedību.

Ja tu nodod izpildlaika stratēģijas pārrakstījumu, tas tiek ignorēts un tiek izsaukts brīdinājums.

## RuntimeConfig balstīti pārrakstījumi

Nodrošini izpildlaika vērtības zem `runtimeConfig.public.i18nRuntime`:

```ts
export default defineNuxtConfig({
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

## Vides mainīgo pārrakstījumi

Pārrakstījumus vari konfigurēt arī caur vides mainīgajiem:

- `NUXT_I18N_DEFAULT_LOCALE`
- `NUXT_I18N_FALLBACK_LOCALE`
- `NUXT_I18N_DISABLED_LOCALES` (atdalīti ar komatiem, piemēram, `fr,it`).

Tiek atbalstīti arī atkāpšanās aizstājvārdi:

- `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES`

## Validācijas noteikumi

Izpildlaikā modulis validē pārrakstījumus, lai izvairītos no salauzta stāvokļa:

- Nevari atspējot visas lokalizācijas.
- `defaultLocale` jānorāda uz iespējotu lokalizāciju.
- `fallbackLocale` jāeksistē deklarētajās lokalizācijās.

Ja pārrakstījums ir nederīgs, modulis saglabā drošu vērtību un reģistrē brīdinājumu.

## Piezīmes daudzu eksemplāru izvietojumiem

Šī izpildlaika funkcija ir izstrādāta lokalizācijas aktivizēšanai un noklusējumiem pēc eksemplāra bez atkārtotas būvēšanas.

Ja eksemplāriem nepieciešamas atšķirīgas URL stratēģijas (`no_prefix` pret `prefix`), izmanto atsevišķus būvējumus katrai stratēģijai.

## Atspējotās lokalizācijas un statiskās slodzes

`runtimeConfig.public.i18nRuntime.disabledLocales` atjaunina maršrutēšanu, pārslēdzēju un Nitro slodzes **apstrādātāju** — bet Nitro apkalpo failus zem `public/` **pirms** šī apstrādātāja.

Ja `translationPayloads.publicAssets` (vai Node SSR piespiedu publiskā kopija) jau ir ierakstījis `/_locales/\{page\}/\{locale\}/data.json`, izpildlaika atspējošana nevar noslēpt šo failu. Dod priekšroku `locale.disabled: true` būvēšanas laikā, lai premerge nemitē šīs lokalizācijas statiskās slodzes.
