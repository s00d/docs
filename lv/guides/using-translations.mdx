# Tulkojumu izmantošana komponentos

Kad modulis ir instalēts un konfigurēts, tu vari attēlot tulkojumus, izsaucot `$t('your_key')` savās Vue veidnēs un skriptos.

## 1. Saknes līmeņa un lapām specifiskie tulkojumu faili

1. **Saknes līmeņa** tulkojumi atrodas tieši zem mapes `/locales` (piemēram, `/locales/en.json`, `/locales/fr.json`). Būvēšanas laikā tie tiek automātiski sapludināti ar katru lapām specifisko failu, padarot tos pieejamus visās lapās.
2. **Lapām specifiskie** tulkojumi atrodas zem `/locales/pages/...`, atbilstot tavai Nuxt lapu mapju struktūrai:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. Veidnes lietojums ar `$t`

Savos `.vue` failos vari tieši izmantot `$t` veidnē:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
`$t` var atgriezt **objektus**, ja atslēga norāda uz ligzdotu JSON mezglu (piemēram, `$t('header')` → `\{ title: "Hi" \}`). Veidnēs tas tiek renderēts kā `[object Object]`. Izmanto `$ts`, kad tev nepieciešama garantēta virkne, vai norādi konkrētāku atslēgu, piemēram, `$t('header.title')`. Detaļas skati [API atsaucē — $t pret $ts](/api/methods#t).
</Tip>

## 3. Pašreizējās lokalizācijas maiņa

Lai savā lietotnē mainītu valodas, vari iegūt `$locale` no `useI18n()` un piešķirt tam jaunu kodu:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. Ligzdotās atslēgas un vietturi

- **Ligzdotās atslēgas** izmanto punktu notāciju, piemēram, `nested.key.deeper`.
- **Vietturi** ļauj tev ievietot dinamiskas vērtības:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. Padomi un labākās prakses

- **Konfliktējošas atslēgas**: ja lapām specifiskais fails satur to pašu atslēgu, kas saknes līmeņa fails, priekšroka tiek dota lapām specifiskajai versijai (saknes tulkojumi būvēšanas laikā tiek sapludināti kā bāze).
- **Lapas failu atspējošana**: ja tu drīzāk nevēlies izmantot lapām specifiskus tulkojumus, savā Nuxt konfigurācijā vari iestatīt `disablePageLocales: true`. Šādā veidā tiek izmantoti tikai `/locales/*.json` faili.
- **Nav tiešu importu**: tev nav jāraksta `import \{ useI18n \} from 'nuxt-i18n-micro'`; moduļa automātiskās iestrādes funkcija to izdara tavā vietā.

Tas ir viss! Ar šiem soļiem tu vari ātri **sākt iegūt tulkojumus** no saknes līmeņa vai lapām specifiskiem JSON failiem un **attēlot** tos savā Nuxt lietotnē, izmantojot `$t`.

## Papildu resursi

Lai izpētītu vairāk uzlabotu funkciju, noteikti apskati:

1. **`<i18n-t>` komponents**
   Komponents `<i18n-t>` ir jaudīga alternatīva `$t`, īpaši noderīga situācijās, kas ietver ligzdotus elementus, uzlabotu vietturu lietojumu un sarežģītākas tulkojumu struktūras.

- **Dokumentācija**: [i18n-t](/api/components/i18n-t).

2. **`useI18n` kompozīts**
   Kompozīts `useI18n` piedāvā pilnu funkciju un reaktīvo īpašību komplektu tulkojumu pārvaldībai, lokalizācijas maiņas apstrādei, formatēšanai un citiem darbiem.

- **Dokumentācija**: [useI18n](/api/composables/use-i18n).
