# Tulkojumu izmantošana komponentos

Kad modulis ir instalēts un konfigurēts, tulkojumus varat parādīt, savos Vue veidnēs un skriptos izsaucot `$t('your_key')`.

## 1. Saknes līmeņa un lapas specifiskie tulkojumu faili

1. **Saknes līmeņa** tulkojumi atrodas tieši mapē `/locales` (piemēram, `/locales/en.json`, `/locales/fr.json`). Būvēšanas laikā tie tiek automātiski sapludināti katrā lapas specifiskajā failā, padarot tos pieejamus visās lapās.
2. **Lapas specifiskie** tulkojumi atrodas mapē `/locales/pages/...`, atbilstot jūsu Nuxt lapu mapes struktūrai:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. Veidnes lietošana ar `$t`

Savos `.vue` failos veidnē varat tieši izmantot `$t`:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
`$t` var atgriezt **objektus**, ja atslēga norāda uz ligzdotu JSON mezglu (piemēram, `$t('header')` → `\{ title: "Hi" \}`). Veidnēs tas tiek attēlots kā `[object Object]`. Ja jums nepieciešams garantēts virknes rezultāts, izmantojiet `$ts` vai norādiet konkrētāku atslēgu, piemēram, `$t('header.title')`. Detaļas skatiet [API atsauce — $t vs $ts](/api/methods#t).
</Tip>

## 3. Pašreizējās lokāles pārslēgšana

Lai savā lietotnē mainītu valodas, no `useI18n()` varat iegūt `$locale` un piešķirt tam jaunu kodu:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. Ligzdotas atslēgas un vietturi

- **Ligzdotas atslēgas** izmanto punkta notāciju, piemēram, `nested.key.deeper`.
- **Vietturi** ļauj ievietot dinamiskas vērtības:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. Padomi un labākā prakse

- **Konfliktējošas atslēgas**: ja lapas specifiskais fails satur to pašu atslēgu, kas saknes līmeņa fails, priekšroka tiek dota lapas specifiskajai versijai (saknes tulkojumi būvēšanas laikā tiek sapludināti kā pamats).
- **Lapas failu atspējošana**: ja nevēlaties izmantot lapas specifiskus tulkojumus, savā Nuxt konfigurācijā varat iestatīt `disablePageLocales: true`. Šādā veidā tiks izmantoti tikai `/locales/*.json` faili.
- **Nav tiešu importu**: nav nepieciešams veikt `import \{ useI18n \} from 'nuxt-i18n-micro'`; to par jums paveic moduļa automātiskās injekcijas funkcija.

Tas arī viss! Ar šiem soļiem jūs varat ātri **sākt izgūt tulkojumus** no saknes līmeņa vai lapas specifiskiem JSON failiem un **attēlot tos** savā Nuxt lietotnē, izmantojot `$t`.

## Papildu resursi

Lai izpētītu vairāk padziļinātu funkciju, noteikti apskatiet:

1. **`<i18n-t>` komponents**  
   Komponents `<i18n-t>` ir jaudīga alternatīva `$t`, īpaši noderīga situācijās, kas ietver ligzdotus elementus, padziļinātu vietturu lietošanu un sarežģītākas tulkojumu struktūras.

- **Dokumentācija**: [i18n-t](/api/components/i18n-t)

2. **`useI18n` komponējamā funkcija**  
   Komponējamā funkcija `useI18n` piedāvā pilnu funkciju un reaktīvo īpašību komplektu tulkojumu pārvaldībai, lokāles pārslēgšanai, formatēšanai un citām darbībām.

- **Dokumentācija**: [useI18n](/api/composables/use-i18n)
