# 🌍 `useLocaleHead` kompozīts

Kompozīts `useLocaleHead` ir utilīta modulī `Nuxt I18n Micro`, kas palīdz tev pārvaldīt SEO atribūtus un HTML meta tagus lokalizētiem maršrutiem. Tas dinamiski ģenerē atribūtus HTML dokumenta `lang` un `dir` un veido `meta` un `link` tagus, lai uzlabotu tava lokalizētā satura SEO.

## ⚙️ Opcijas

```ts
useLocaleHead(options: UseLocaleHeadOptions): { metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }, MetaObject | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

SEO galvas tagi pašreizējam maršrutam: `hreflang` alternatīvie tagi katrai lokalizācijai plus `x-default`, canonical saite, `og:locale` un `lang`/`dir` uz `<html>`.

Nepieciešams tikai tad, kad `meta` ir atspējots vai noklusējumus vajag pielāgot — ar `meta: true` modulis pats reģistrē tos pašus tagus.

**Atgriež** — ref, kas satur galvas objektu, gatavu nodošanai `useHead`.

```ts
const head = useLocaleHead({ addSeoAttributes: true })
useHead(head)
```

## 🛠️ Atgrieztās vērtības

Kompozīts `useLocaleHead` atgriež reaktīvu objektu un atjaunināšanas funkciju, kas tev jāizsauc, kad mainās avota dati. Abas formas ir iepriekš minētajā parakstā, kas ģenerēts no avota.

### `metaObject`

Reaktīva galvas slodze (html atribūti, meta, link), kas piemērota `useHead(metaObject)`.

- **Piemērs**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

Pārrēķina `metaObject`, pamatojoties uz pašreizējo maršrutu, lokalizāciju un konfigurāciju. Izsauc to, kad mainās ievades — piemēram, maršruta maiņas laikā.

- **Piemērs**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### Piekļuve `link` un `meta`

Masīvi `link` un `meta` ir pieejami caur `metaObject.value`:

- **Piemērs**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ Lietošanas piemēri

### Pamata lietošana

Ģenerē lokalizācijai specifiskus galvas atribūtus ar noklusējuma opcijām.

```js
const head = useLocaleHead()
```

### Pielāgot identifikatora atribūtu

Izmanto pielāgotu identifikatora atribūtu ģenerētajiem tagiem.

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### Atspējot SEO atribūtus

Ģenerē galvas atribūtus, nepievienojot SEO saistītus meta un link tagus.

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### Norādīt bāzes URL

Iestati pielāgotu bāzes URL canonical un alternatīviem URL.

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 Papildu funkcijas

### SEO meta un link tagi

Kad `addSeoAttributes` ir iespējots, kompozīts automātiski ģenerē šādus tagus:

- `og:locale` pašreizējai lokalizācijai (`language_TERRITORY`, apakšsvītra). Atvasināts no `locale.og` vai pārveidots no `locale.iso`, kad iespējams.
- `og:url` lapas canonical URL.
- `og:locale:alternate` alternatīvo valodu versijām.
- `rel="canonical"` un `rel="alternate"` saites SEO optimizācijai.
- `hreflang="x-default"` saite, kas norāda uz noklusējuma lokalizācijas URL. Tas norāda meklētājprogrammām, kuru URL rādīt lietotājiem, kuru valoda neatbilst nevienai no definētajām lokalizācijām.

### Dinamiska lokalizācija un virziens

Kompozīts dinamiski nosaka `lang` un `dir` atribūtus, pamatojoties uz pašreizējā maršruta lokalizāciju, nodrošinot, ka tavs HTML dokuments ir pareizi konfigurēts starptautiskiem lietotājiem.

### Lokalizētu maršrutu apstrāde

Ja tavi maršruti ir ar lokalizācijas kodu prefiksiem (piemēram, `/en/about`), kompozīts inteliģenti pielāgo pilnu ceļu URL ģenerēšanai, nodrošinot, ka SEO atribūti ir precīzi un atbilstoši.

Šis kompozīts vienkāršo procesu, kā optimizēt tavu Nuxt lietotni starptautiskai auditorijai, nodrošinot, ka tava vietne ir labi sagatavota globālām meklētājprogrammām un lietotājiem.

## 🛠️ Lietošanas piemērs

Šis piemērs demonstrē, kā izmantot kompozītu `useLocaleHead` Vue komponentā ar noklusējuma iestatījumiem:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### Koda skaidrojums

- **`useLocaleHead` kompozīts**: Šis kompozīts tiek izsaukts `<script setup>` sadaļā un atgriež objektu, kas satur `htmlAttrs`, `meta` un `link`.

- **`<html>` tags**: `lang` un `dir` atribūti HTML dokumentam tiek dinamiski noteikti, pamatojoties uz pašreizējo lokalizāciju, un tiek piemēroti `<html>` tagam.

- **`<head>` sadaļa**:
  - **Meta tagi**: Tiek ģenerēti SEO saistīti meta tagi, tostarp `og:locale`, `og:url` un `rel="canonical"` un `rel="alternate"` tagi, lai norādītu lapas alternatīvās valodas versijas.
  - **Link tagi**: Ir iekļauti canonical saites, saites uz alternatīvām valodas versijām un `hreflang="x-default"` saite (norādot uz noklusējuma lokalizācijas URL).

- **`<body>` sadaļa**: Šeit tiek attēlots lapas galvenais saturs. Šajā piemērā tiek izmantota vienkārša galvene un rindkopa.

### 📝 Piezīmes

1. **Atribūti**: Izmantotie atribūti (`lang`, `dir`, `rel`, `href`, `hreflang`, `property`, `content`) tiek iegūti no objekta, ko atgriež `useLocaleHead`.

2. **SEO tagu ģenerēšana**: Ja opcija `addSeoAttributes` ir iestatīta uz `true`, kompozīts automātiski ģenerē SEO tagus pašreizējai lokalizācijai.

3. **Bāzes URL**: Vari iestatīt savu pielāgoto bāzes URL, izmantojot opciju `baseUrl`, lai pareizi ģenerētu canonical un alternatīvos linkus.

Šis piemērs demonstrē, cik viegli ir integrēt `useLocaleHead` tavas lietotnes komponentos, lai nodrošinātu pareizus SEO atribūtus un uzlabotu lokalizēto lapu meklētājprogrammu indeksēšanu.

## 🧩 Pielāgošana un dzīves cikls

- `useLocaleHead` pats neabonē izmaiņas. Tas atgriež `metaObject` un `updateMeta`.
- Tev jāizsauc `updateMeta()`, kad mainās ievades (parasti maršruta maiņas laikā), piemēram, no spraudņa:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## Kad tā vietā izmantot `useI18nHead`

Kad `meta: true` (noklusējums), dod priekšroku [`useI18nHead`](/api/composables/use-i18n-head) **pēc lapas** noteiktiem pārrakstījumiem (pielāgots hreflang, papildu `og:title`, daļēja atspējošana). Izmanto `useLocaleHead` tieši tikai tad, kad `meta: false` vai tu pats pārvaldi `useHead`.
