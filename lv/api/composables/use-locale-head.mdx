# 🌍 `useLocaleHead` komponējamā funkcija

Komponējamā funkcija `useLocaleHead` ir utilīta modulī `Nuxt I18n Micro`, kas palīdz jums pārvaldīt SEO atribūtus un HTML meta tagus lokalizētiem maršrutiem. Tā dinamiski ģenerē HTML dokumenta atribūtus `lang` un `dir` un izveido `meta` un `link` tagus, lai uzlabotu jūsu lokalizētā satura SEO.

## ⚙️ Opcijas

```ts
useLocaleHead(options: UseLocaleHeadOptions): { metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }, MetaObject | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

SEO head tagi pašreizējam maršrutam: `hreflang` alternatīvie tagi katrai lokālei plus
`x-default`, kanoniskā saite, `og:locale` un `lang`/`dir` uz `<html>`.

Nepieciešams tikai tad, kad `meta` ir atspējots vai noklusējumi jāpielāgo — ar `meta: true`
modulis reģistrē tos pašus tagus pats.

## 🛠️ Atgriešanas vērtības

Komponējamā funkcija `useLocaleHead` atgriež reaktīvu objektu un atjaunināšanas funkciju, kas jums jāizsauc,
kad avota dati mainās. Abas formas ir augstāk esošajā parakstā, kas ģenerēts no
avota.

### `metaObject`

Reaktīvs head payload (html atribūti, meta, link), kas piemērots `useHead(metaObject)`.

- **Piemērs**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

Pārrēķina `metaObject`, balstoties uz pašreizējo maršrutu, lokāli un konfigurāciju. Izsauciet to, kad ievades mainās —
piemēram, maršruta izmaiņā.

- **Piemērs**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### Piekļuve `link` un `meta`

Masīvi `link` un `meta` ir pieejami caur `metaObject.value`:

- **Piemērs**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ Lietošanas piemēri

### Pamata lietošana

Ģenerējiet lokālei specifiskus head atribūtus ar noklusējuma opcijām.

```js
const head = useLocaleHead()
```

### Identifikatora atribūta pielāgošana

Ģenerētajiem tagiem izmantojiet pielāgotu identifikatora atribūtu.

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### SEO atribūtu atspējošana

Ģenerējiet head atribūtus, nepievienojot ar SEO saistītos meta un link tagus.

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### Bāzes URL norādīšana

Iestatiet pielāgotu bāzes URL kanoniskajiem un alternatīvajiem URL.

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 Papildu funkcijas

### SEO meta un link tagi

Kad `addSeoAttributes` ir iespējots, komponējamā funkcija automātiski ģenerē šādus tagus:

- `og:locale` pašreizējai lokālei (`language_TERRITORY`, pasvītrojums). Iegūts no `locale.og` vai konvertēts no `locale.iso`, kad iespējams.
- `og:url` lapas kanoniskajam URL.
- `og:locale:alternate` alternatīvām valodu versijām.
- `rel="canonical"` un `rel="alternate"` saites SEO optimizācijai.
- `hreflang="x-default"` saite, kas norāda uz noklusējuma lokāles URL. Tas norāda meklētājprogrammām, kuru URL rādīt lietotājiem, kuru valoda neatbilst nevienai no definētajām lokālēm.

### Dinamiska lokāle un virziens

Komponējamā funkcija dinamiski nosaka `lang` un `dir` atribūtus, balstoties uz pašreizējā maršruta lokāli, nodrošinot, ka jūsu HTML dokuments ir pareizi konfigurēts starptautiskiem lietotājiem.

### Lokalizētu maršrutu apstrāde

Ja jūsu maršruti ir priedēkļoti ar lokāles kodiem (piemēram, `/en/about`), komponējamā funkcija inteliģenti pielāgo pilno ceļu URL ģenerēšanai, nodrošinot, ka SEO atribūti ir precīzi un atbilstoši.

Šī komponējamā funkcija vienkāršo jūsu Nuxt lietotnes optimizēšanas procesu starptautiskām auditorijām, nodrošinot, ka jūsu vietne ir labi sagatavota globālām meklētājprogrammām un lietotājiem.

## 🛠️ Lietošanas piemērs

Šis piemērs parāda, kā izmantot komponējamo funkciju `useLocaleHead` Vue komponentā ar noklusējuma iestatījumiem:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### Koda skaidrojums

- **`useLocaleHead` komponējamā funkcija**: šī komponējamā funkcija tiek izsaukta `<script setup>` sadaļā un atgriež objektu, kas satur `htmlAttrs`, `meta` un `link`.

- **`<html>` tags**: `lang` un `dir` atribūti HTML dokumentam tiek dinamiski noteikti, balstoties uz pašreizējo lokāli, un tiek piemēroti `<html>` tagam.

- **`<head>` sadaļa**:
  - **Meta tagi**: tiek ģenerēti ar SEO saistītie meta tagi, tostarp `og:locale`, `og:url` un `rel="canonical"` un `rel="alternate"` tagi, lai norādītu alternatīvās valodu versijas lapai.
  - **Link tagi**: iekļautas kanoniskās saites, saites uz alternatīvām valodu versijām un `hreflang="x-default"` saite (kas norāda uz noklusējuma lokāles URL).

- **`<body>` sadaļa**: šeit tiek attēlots galvenais lapas saturs. Šajā piemērā tiek izmantots vienkāršs virsraksts un rindkopa.

### 📝 Piezīmes

1. **Atribūti**: izmantotie atribūti (`lang`, `dir`, `rel`, `href`, `hreflang`, `property`, `content`) tiek izgūti no objekta, ko atgriež `useLocaleHead`.

2. **SEO tagu ģenerēšana**: ja opcija `addSeoAttributes` ir iestatīta uz `true`, komponējamā funkcija automātiski ģenerē SEO tagus pašreizējai lokālei.

3. **Bāzes URL**: jūs varat iestatīt pielāgotu bāzes URL, izmantojot opciju `baseUrl`, lai pareizi ģenerētu kanoniskās un alternatīvās saites.

Šis piemērs parāda, cik viegli ir integrēt `useLocaleHead` savas lietotnes komponentos, lai nodrošinātu pareizus SEO atribūtus un uzlabotu lokalizēto lapu meklētājprogrammu indeksāciju.

## 🧩 Pielāgošana un dzīves cikls

- `useLocaleHead` pati neabonē izmaiņām. Tā atgriež `metaObject` un `updateMeta`.
- Jums jāizsauc `updateMeta()`, kad ievades mainās (parasti pie maršruta izmaiņas), piemēram, no spraudņa:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## Kad tā vietā izmantot `useI18nHead`

Kad `meta: true` (noklusējums), priekšroku dodiet [`useI18nHead`](/api/composables/use-i18n-head) **lapas specifiskām** pārrakstīšanām (pielāgots hreflang, papildu `og:title`, daļēja atspējošana). `useLocaleHead` tieši izmantojiet tikai tad, kad `meta: false` vai jūs pats pārvaldāt `useHead`.
