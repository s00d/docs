# useI18nLocale

## Paraksts

{/* generated:symbol:useI18nLocale — do not edit; run `pnpm run docs:generate` */}

```ts
useI18nLocale(): { getEffectiveLocale: (route: unknown, getLocaleFromRoute: GetLocaleFromRoute) => string; getLocale: () => string | null; getLocaleWithServerFallback: (serverLocale?: string | null) => string | null; getPreferredLocale: () => string | null; hashCookie: any; isValidLocale: (locale: string | null | undefined) => locale is string; locale: any; localeCookie: any; resolveInitialLocale: (options: ResolveInitialLocaleOptions) => string; setLocale: (locale: string | null) => void; syncLocale: (locale: string | null) => void; validLocales: string[] }
```

Centralizēts ieejas punkts i18n lokalizācijas pārvaldībai. Apvieno useState('i18n-locale'), lokalizācijas sīkdatni un sinhronizācijas utilītas.

{/* /generated:symbol:useI18nLocale */}

## Lietošana

```vue
<script setup>
const {
  locale,
  localeCookie,
  hashCookie,
  validLocales,
  getPreferredLocale,
  getLocale,
  getLocaleWithServerFallback,
  getEffectiveLocale,
  resolveInitialLocale,
  setLocale,
  syncLocale,
  isValidLocale,
} = useI18nLocale()

// Set locale (updates state and cookies)
setLocale('de')

// Get current locale (state → cookie)
const current = getLocale()

// Get valid preferred locale
const preferred = getPreferredLocale()
</script>
```

## API

| Rekvizīts/metode                                 | Tips                                | Apraksts                                                                          |
| ----------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| `locale`                                        | `Ref<string \| null>`               | Reaktīvs lokalizācijas stāvoklis (`useState('i18n-locale')`).                                    |
| `localeCookie`                                  | `Ref`                               | Lokalizācijas sīkdatne (kad opcija `localeCookie` ir iespējota).                                |
| `hashCookie`                                    | `Ref`                               | Sīkdatne, ko izmanto, kad ir aktīvs `hashMode`.                                                |
| `validLocales`                                  | `string[]`                          | Iespējotie lokalizācijas kodi no moduļa konfigurācijas (izslēdz `disabled`).                        |
| `getLocale()`                                   | `() => string \| null`              | Pašreizējā lokalizācija: stāvoklis → sīkdatne (vai hash sīkdatne hash režīmā).                         |
| `getPreferredLocale()`                          | `() => string \| null`              | Lokalizācija no stāvokļa/sīkdatnes, **validēta** pret `validLocales`, vai `null`.             |
| `getLocaleWithServerFallback(serverLocale?)`    | `(serverLocale?) => string \| null` | Stāvoklis → sīkdatne → neobligāts servera konteksts (izmanto `no_prefix` inicializācijas laikā).              |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string`             | Lokalizācija tulkojumu ielādei: hash režīmā priekšroka stāvoklim; pretējā gadījumā nolasa no maršruta. |
| `resolveInitialLocale(options)`                 | `(options) => string`               | Atrisina lokalizāciju: stāvoklis → `serverLocale` → maršruts; sinhronizē stāvokli, kad nepieciešams.             |
| `setLocale(locale)`                             | `(locale: string \| null) => void`  | Iestata lokalizāciju un sinhronizē sīkdatnes.                                                       |
| `syncLocale(locale)`                            | `(locale: string \| null) => void`  | Sinhronizē tikai sīkdatnes (bez stāvokļa atjaunināšanas).                                                  |
| `isValidLocale(locale)`                         | `(locale) => boolean`               | Pārbauda, vai virkne ir iekš `validLocales`.                                                 |

### `resolveInitialLocale` opcijas

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

Iekšēji izmanto galvenais spraudnis startēšanas laikā. Pielāgoti spraudņi to var izsaukt, ieviešot alternatīvas noteikšanas plūsmas.

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

Atgriež lokalizāciju, ko izmanto tulkojumu ielādei un ziņojumu formatēšanai norādītajam maršruta objektam.

## Programmatiska lokalizācijas iestatīšana

Dod priekšroku `useI18nLocale()`, nevis tiešai `useState('i18n-locale')` izmantošanai:

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
`setLocale()` atjaunina tikai lokalizācijas preferenci (stāvoklis + sīkdatne). Lai arī pārlādētu aktīvo tulkojumu kontekstu klientā, izmanto `$switchLocale()` no `useNuxtApp()` vai `useI18n()`. Tas ir īpaši svarīgi `no_prefix` gadījumā, kur URL nemainās. Skati [FAQ — pārslēgt lokalizāciju, nemainot URL](/guides/faq#-switch-locale-without-changing-the-url).
</Tip>
