# useI18nLocale

## Paraksts

Centralizēts sākuma punkts i18n lokāles pārvaldībai.
Apvieno useState('i18n-locale'), lokāles sīkfailu un sinhronizācijas utilītas.

## Lietošana

```vue
<script setup>
const {
  locale,
  localeCookie,
  hashCookie,
  validLocales,
  getPreferredLocale,
  getLocale,
  getLocaleWithServerFallback,
  getEffectiveLocale,
  resolveInitialLocale,
  setLocale,
  syncLocale,
  isValidLocale,
} = useI18nLocale()

// Set locale (updates state and cookies)
setLocale('de')

// Get current locale (state → cookie)
const current = getLocale()

// Get valid preferred locale
const preferred = getPreferredLocale()
</script>
```

## API

| Īpašība/metode                                 | Tips                                | Apraksts                                                                          |
| ----------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| `locale`                                        | `Ref<string \| null>`               | Reaktīvs lokāles stāvoklis (`useState('i18n-locale')`)                                    |
| `localeCookie`                                  | `Ref`                               | Lokāles sīkfails (kad ir iespējota opcija `localeCookie`)                                |
| `hashCookie`                                    | `Ref`                               | Sīkfails, ko izmanto, kad ir aktīvs `hashMode`                                                |
| `validLocales`                                  | `string[]`                          | Iespējotie lokāles kodi no moduļa konfigurācijas (izslēdz `disabled`)                        |
| `getLocale()`                                   | `() => string \| null`              | Pašreizējā lokāle: stāvoklis → sīkfails (vai hash sīkfails hash režīmā)                         |
| `getPreferredLocale()`                          | `() => string \| null`              | Lokāle no stāvokļa/sīkfaila **validēta** pret `validLocales` vai `null`             |
| `getLocaleWithServerFallback(serverLocale?)`    | `(serverLocale?) => string \| null` | Stāvoklis → sīkfails → izvēles servera konteksts (izmanto `no_prefix` inicializācijas laikā)              |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string`             | Lokāle tulkojumu ielādei: hash režīms dod priekšroku stāvoklim; pretējā gadījumā nolasa no maršruta |
| `resolveInitialLocale(options)`                 | `(options) => string`               | Atrisina lokāli: stāvoklis → `serverLocale` → maršruts; sinhronizē stāvokli pēc nepieciešamības             |
| `setLocale(locale)`                             | `(locale: string \| null) => void`  | Iestata lokāli un sinhronizē ar sīkfailiem                                                       |
| `syncLocale(locale)`                            | `(locale: string \| null) => void`  | Sinhronizē tikai sīkfailus (bez stāvokļa atjaunināšanas)                                                  |
| `isValidLocale(locale)`                         | `(locale) => boolean`               | Pārbauda, vai virkne ir iekš `validLocales`                                                 |

### `resolveInitialLocale` opcijas

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

Iekšēji izmanto galvenais spraudnis startā. Pielāgoti spraudņi to var izsaukt, ieviešot alternatīvas noteikšanas plūsmas.

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

Atgriež lokāli, ko izmanto tulkojumu ielādei un ziņojumu formatēšanai konkrētam maršruta objektam.

## Programmatiska lokāles iestatīšana

Priekšroku dodiet `useI18nLocale()`, nevis tiešai `useState('i18n-locale')` lietošanai:

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
`setLocale()` atjaunina tikai lokāles izvēli (stāvokli + sīkfailu). Lai klienta pusē atkārtoti ielādētu arī aktīvo tulkojumu kontekstu, izmantojiet `$switchLocale()` no `useNuxtApp()` vai `useI18n()`. Tas ir īpaši svarīgi `no_prefix` gadījumā, kur URL nemainās. Skatiet [BUJ — pārslēgt lokāli, nemainot URL](/guides/faq#-switch-locale-without-changing-the-url).
</Tip>
