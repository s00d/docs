# 🛠️ `useI18n` komponējamā funkcija

Komponējamā funkcija `useI18n` modulī `Nuxt I18n Micro` nodrošina piekļuvi vairumam izpildlaika i18n palīgu komponentos un skriptos. Metodes ir pieejamas **gan ar, gan bez `$` priedēkļa** (piemēram, `$t` un `t`).

Dažas injekcijas — `$defineI18nRoute` un `$clearCache` — ir pieejamas tikai uz `useNuxtApp()`. Skatiet [Metodes — `$defineI18nRoute`](/api/methods#definei18nroute) un [`$clearCache`](/api/methods#clearcache).

## 📊 Ko tā atgriež

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Katrs izpildlaika palīgs kā vienkāršs objekts.

Tās pašas funkcijas, ko spraudnis injicē kā `$t`, `$tc` un tā tālāk, pieejamas gan
zem dolāra priedēkļa nosaukuma, gan tīra aizstājējnosaukuma — tāpēc gan `const \{ t \} = useI18n()`, gan
`const \{ $t \} = useI18n()` darbojas.

**Atgriež** — palīgus, kas aprakstīti [metožu atsaucē](/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

Katrs palīgs, ko tā atgriež — `$t`, `$tc`, `$has`, `$switchLocale` un pārējie — ir uzskaitīts
ar tā parakstu un pilnībā dokumentēts [Metožu atsaucē](/api/methods).

## Tikai `useNuxtApp()` API

Šos **neatgriež** `useI18n()`. Importējiet tos no `useNuxtApp()`:

| Metode                     | Nolūks                                                                         |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Lapas specifiskie lokāles maršruti, ierobežojumi un iekļautie tulkojumi `script setup` iekšpusē |
| `$clearCache()`            | Notīra atmiņā esošo tulkojumu kešu un ielādētos gabalus                            |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Pilnus parakstus un piemērus skatiet [Metodes](/api/methods).

## 🛠️ Lietošanas piemēri

### Pamata lokāles iegūšana

Iegūstiet lietotnes pašreizējo lokāli.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Tulkošana ar parametriem

Tulkojiet virkni ar dinamiskiem parametriem un rezerves noklusējuma vērtību.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Lokāļu pārslēgšana

Pārslēdziet lietotni uz citu lokāli.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Lokalizēta maršruta ģenerēšana

Ģenerējiet maršrutu, kas lokalizēts uz pašreizējo vai norādīto lokāli.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
