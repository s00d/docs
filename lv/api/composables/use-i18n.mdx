# 🛠️ `useI18n` kompozīts

Kompozīts `useI18n` modulī `Nuxt I18n Micro` nodrošina piekļuvi lielākajai daļai izpildlaika i18n palīgu komponentos un skriptos. Metodes ir pieejamas **ar un bez `$` prefiksa** (piemēram, `$t` un `t`).

Dažas iestrādes — `$defineI18nRoute` un `$clearCache` — ir pieejamas tikai uz `useNuxtApp()`. Skati [Metodes — `$defineI18nRoute`](/api/methods#definei18nroute) un [`$clearCache`](/api/methods#clearcache).

## 📊 Ko tas atgriež

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Katrs izpildlaika palīgs kā parasts objekts.

Tās pašas funkcijas, ko spraudnis iestrādā kā `$t`, `$tc` un tā tālāk, pieejamas gan zem dolāra prefiksētā nosaukuma, gan tukšas aizstājvārda — tāpēc `const \{ t \} = useI18n()` un `const \{ $t \} = useI18n()` abi darbojas.

**Atgriež** — palīgus, kas aprakstīti [metožu atsaucē](/api/methods).

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

Katrs palīgs, ko tas atgriež — `$t`, `$tc`, `$has`, `$switchLocale` un pārējie — ir uzskaitīts ar savu parakstu un pilnībā dokumentēts [Metožu atsaucē](/api/methods).

## Tikai uz `useNuxtApp()` pieejamie API

Šos `useI18n()` **neatgriež**. Importē tos no `useNuxtApp()`:

| Metode                     | Mērķis                                                                         |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Pēc lapas noteikti lokalizācijas maršruti, ierobežojumi un iekļauti tulkojumi `script setup` iekšpusē. |
| `$clearCache()`            | Iztīra atmiņā esošo tulkojumu kešatmiņu un ielādētās daļas.                            |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Pilnus parakstus un piemērus skati [Metodēs](/api/methods).

## 🛠️ Lietošanas piemēri

### Pamata lokalizācijas iegūšana

Iegūsti lietotnes pašreizējo lokalizāciju.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Tulkošana ar parametriem

Tulko virkni ar dinamiskiem parametriem un noklusējuma vērtību atkāpšanās gadījumam.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Lokalizāciju maiņa

Pārslēdz lietotni uz citu lokalizāciju.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Lokalizēta maršruta ģenerēšana

Ģenerē maršrutu, lokalizētu uz pašreizējo vai norādīto lokalizāciju.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
