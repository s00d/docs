# 🌍 `<i18n-switcher>` komponents

Komponents `<i18n-switcher>` modulī `Nuxt I18n Micro` nodrošina lietotājam draudzīgu nolaižamās izvēlnes saskarni dažādu lokāļu pārslēgšanai jūsu lietotnē. Šis komponents ir ļoti pielāgojams, ļaujot nemanāmi integrēt to jūsu lietotnes dizainā un izkārtojumā.

Lokāles ar `disabled: true` tiek **izlaistas** no nolaižamās izvēlnes (tās paliek pieejamas caur `$getLocales()` SEO / head tagiem). Tikai pārslēdzamām lokālēm tiek pievienots `NuxtLink` + `hreflang`.

Katra daļa pēc noklusējuma ir bez stila: `custom*Style` propi pieņem iekļautu stilu objektus, un
zemāk esošie sloti pilnībā aizvieto marķējumu, kad ar stilēšanu vien nepietiek.

## 🛠️ Lietošanas piemēri

### Pamata lietošana

```vue
<template>
  <i18n-switcher />
</template>
```

Tas renderē lokāles pārslēdzēju ar noklusējuma stilēšanu un uzvedību.

### Pielāgotas etiķetes un iekļautie stili

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Šis piemērs demonstrē pilnībā pielāgotu lokāles pārslēdzēju ar pielāgotām etiķetēm un iekļautiem stiliem.

## 🔌 Sloti

Katru pārslēdzēja vizuālo daļu var aizvietot. Sloti ir uzskaitīti kopā ar prop
tabulu augstāk; katrs pieņem veidnes saturu:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Sloti, kuru nosaukums beidzas ar `-item`, `-link-content` vai sākas ar `before-item`, saņem
`locale` objektu, kuram tie pieder.

## 🎨 Stilu pārskats

Komponents `<i18n-switcher>` nāk ar pamata stiliem, kas definēti, izmantojot iekļautus stilus, kurus var viegli pārrakstīt, nododot pielāgotus stilus caur propiem. Šeit ir īss noklusējuma stilēšanas pārskats:

- **Ietinošais elements**: kontrolē nolaižamās izvēlnes pozicionēšanu.
- **Poga**: stilē nolaižamās izvēlnes pārslēgšanas pogu.
- **Nolaižamā izvēlne**: stilē nolaižamo sarakstu.
- **Elementi**: stilē katru saraksta elementu.
- **Saites**: stilē saites katra elementa iekšpusē.
- **Ikona**: stilē nolaižamās izvēlnes indikatora ikonu.

Šos stilus varat pielāgot, nododot pielāgotus stilus caur attiecīgajiem propiem, nodrošinot, ka lokāles pārslēdzējs nemanāmi integrējas jūsu lietotnes UI.
