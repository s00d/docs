# 🌍 `<i18n-switcher>` komponents

Komponents `<i18n-switcher>` modulī `Nuxt I18n Micro` nodrošina lietotājdraudzīgu nolaižamo saraksta saskarni, lai pārslēgtos starp dažādām lokalizācijām tavā lietotnē. Šis komponents ir ļoti pielāgojams, ļaujot vienmērīgi integrēties ar tavas lietotnes dizainu un izkārtojumu.

Lokalizācijas ar `disabled: true` **tiek izlaistas** no nolaižamā saraksta (tās paliek pieejamas caur `$getLocales()` SEO / galvas tagiem). Tikai pārslēdzamām lokalizācijām tiek dota `NuxtLink` + `hreflang`.

Katra daļa pēc noklusējuma nav stilizēta: rekvizīti `custom*Style` pieņem iekļautus stilu objektus, un zemāk esošie sloti pilnībā aizstāj marķējumu, kad ar stilizāciju vien nepietiek.

## 🛠️ Lietošanas piemēri

### Pamata lietošana

```vue
<template>
  <i18n-switcher />
</template>
```

Šis renderē lokalizācijas pārslēdzēju ar noklusējuma stilizāciju un uzvedību.

### Pielāgoti uzraksti un iekļautie stili

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Šis piemērs demonstrē pilnīgi pielāgotu lokalizācijas pārslēdzēju ar pielāgotiem uzrakstiem un iekļautajiem stiliem.

## 🔌 Sloti

Katru pārslēdzēja vizuālo daļu var aizstāt. Sloti ir uzskaitīti kopā ar rekvizītu tabulu iepriekš; katrs no tiem pieņem veidnes saturu:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Sloti, kuru nosaukums beidzas ar `-item`, `-link-content` vai sākas ar `before-item`, saņem `locale` objektu, kuram tie pieder.

## 🎨 Stilu pārskats

Komponents `<i18n-switcher>` nāk ar pamata stiliem, kas definēti, izmantojot iekļautos stilus, kurus var viegli pārrakstīt, nododot pielāgotus stilus caur rekvizītiem. Šeit ir īss noklusējuma stilizācijas pārskats:

- **Ietinums**: kontrolē nolaižamā saraksta pozicionēšanu.
- **Poga**: stilizē nolaižamā saraksta pārslēgšanas pogu.
- **Nolaižamais saraksts**: stilizē nolaižamā saraksta sarakstu.
- **Elementi**: stilizē katru elementu sarakstā.
- **Saites**: stilizē saites katra elementa iekšpusē.
- **Ikona**: stilizē nolaižamā saraksta indikatora ikonu.

Šos stilus vari pielāgot, nododot pielāgotus stilus caur attiecīgajiem rekvizītiem, nodrošinot, ka lokalizācijas pārslēdzējs vienmērīgi integrējas tavas lietotnes UI.
