# 🌍 `<i18n-t>` komponents

Komponents `<i18n-t>` modulī `Nuxt I18n Micro` ir elastīgs tulkošanas komponents, kas atbalsta dinamisku satura ievietošanu caur slotiem. Tas ļauj interpolēt tulkojumus ar pielāgotiem Vue komponentiem vai HTML saturu, iespējojot padziļinātus lokalizācijas scenārijus.

## ⚙️ Prop parametri

| Prop | Tips | Noklusējums | Apraksts |
| --- | --- | --- | --- |
| `keypath` **\*** | `string` | — | Tulkojuma atslēga, ko renderēt. |
| `plural` | `number \| string` | — | Skaits, kas izvēlas daudzskaitļa formu. Iestatiet to, lai izmantotu `$tc`, nevis `$t`. |
| `tag` | `string` | `'span'` | Elements, ko renderēt. |
| `params` | `Record<string, string \| number \| boolean>` | `() => (\{\})` | Interpolācijas vērtības, kas aizstātas tulkojumā. |
| `defaultValue` | `string` | `''` | Renderē komponenta vietā, kad `hideIfEmpty` nomāc tukšu tulkojumu. |
| `html` | `boolean` | `false` | Renderēt tulkojumu kā HTML, nevis tekstu. Tikai saturam, ko jūs kontrolējat. |
| `hideIfEmpty` | `boolean` | `false` | Neko nerenderēt, kad tulkojums atrisinās uz tukšu virkni. |
| `customPluralRule` | `PluralFunc` | `null` | Daudzskaitļa noteikums tikai šim elementam, kas pārraksta konfigurēto. |
| `number` | `number \| string` | — | Formatē vērtību ar `$tn` un nodod to tulkojumam kā `\{number\}`. |
| `date` | `Date \| string \| number` | — | Formatē vērtību ar `$td` un nodod to tulkojumam kā `\{date\}`. |
| `relativeDate` | `Date \| string \| number` | — | Formatē vērtību ar `$tdr` un nodod to tulkojumam kā `\{relativeDate\}`. |

**\*** obligāti.

{/* /generated:component:i18n-t */}

Vienlaikus tiek piemērots tikai viens no `plural`, `number`, `date` un `relativeDate`; kad iestatīti vairāki,
uzvar pirmais no šī saraksta.

### Piemēri katram propam

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

{

}

## 🛠️ Lietošanas piemēri

### Pamata lietošana

```vue
<i18n-t keypath="feedback.text" />
```

Tas renderē `feedback.text` tulkojumu `<span>` taga iekšpusē.

### Slotu izmantošana dinamiskam saturam

Komponents `<i18n-t>` atbalsta slotu izmantošanu, lai dinamiski ievietotu Vue komponentus vai citu saturu noteiktās tulkojuma daļās.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

Šajā piemērā `\{link\}` viettura vietā tulkojumu virknē `feedback.text` tiek ievietots komponents `<nuxt-link>`, kas pats satur citu tulkošanas komponentu.

### Daudzskaitļa formas

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

Tas automātiski piemēro daudzskaitļa noteikumus, balstoties uz `itemCount` vērtību.

## 🚀 Papildu funkcijas

### Noklusējuma slots

Ja nav sniegts konkrēts slots, tulkojumu var pielāgot caur noklusējuma slotu, kas nodrošina visu tulkoto virkni:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### Nosacīta renderēšana

Nerenderēt neko, ja tulkojumu virkne ir tukša, izmantojot prop `hideIfEmpty`.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### Pielāgots daudzskaitļa formas noteikums

Izmantojiet pielāgotu funkciju, lai apstrādātu daudzskaitļa formas.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### Padziļināts piemērs ar slotiem

Izmantojiet slotus, lai pielāgotu, kā tulkojuma saturs tiek renderēts.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
