# 🌍 `<i18n-t>` komponents

Komponents `<i18n-t>` modulī `Nuxt I18n Micro` ir elastīgs tulkošanas komponents, kas atbalsta dinamisku satura ievietošanu caur slotiem. Tas ļauj tev interpolēt tulkojumus ar pielāgotiem Vue komponentiem vai HTML saturu, iespējojot uzlabotus lokalizācijas scenārijus.

## ⚙️ Rekvizīti

| Rekvizīts | Tips | Noklusējums | Apraksts |
| --- | --- | --- | --- |
| `keypath` **\*** | `string` | — | Renderējamā tulkojuma atslēga. |
| `plural` | `number \| string` | — | Skaits, kas izvēlas daudzskaitļa formu. Iestati to, lai izmantotu `$tc`, nevis `$t`. |
| `tag` | `string` | `'span'` | Elements, ko renderēt. |
| `params` | `Record<string, string \| number \| boolean>` | `() => (\{\})` | Interpolācijas vērtības, kas aizvieto tulkojumā. |
| `defaultValue` | `string` | `''` | Renderēts, nevis komponents, kad `hideIfEmpty` slāpē tukšu tulkojumu. |
| `html` | `boolean` | `false` | Renderē tulkojumu kā HTML, nevis tekstu. Tikai saturam, ko tu kontrolē. |
| `hideIfEmpty` | `boolean` | `false` | Nerenderē neko, kad tulkojums atrisinās uz tukšu virkni. |
| `customPluralRule` | `PluralFunc` | `null` | Daudzskaitļa noteikums tikai šim elementam, pārrakstot konfigurēto. |
| `number` | `number \| string` | — | Formatē vērtību ar `$tn` un nodod to tulkojumam kā `\{number\}`. |
| `date` | `Date \| string \| number` | — | Formatē vērtību ar `$td` un nodod to tulkojumam kā `\{date\}`. |
| `relativeDate` | `Date \| string \| number` | — | Formatē vērtību ar `$tdr` un nodod to tulkojumam kā `\{relativeDate\}`. |

**\*** obligāts.

{/* /generated:component:i18n-t */}

Vienlaikus tiek piemērots tikai viens no `plural`, `number`, `date` un `relativeDate`; kad iestatīti vairāki, uzvar pirmais šajā sarakstā.

### Piemēri katram rekvizītam

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

```json
{
  "items": "Nothing|You have {count} item|You have {count} items"
}
```

\u0001\u0001\u0001## 🛠️ Lietošanas piemēri

### Pamata lietošana

```vue
<i18n-t keypath="feedback.text" />
```

Šis renderē tulkojumu atslēgai `feedback.text` `<span>` taga iekšpusē.

### Slotu izmantošana dinamiskam saturam

Komponents `<i18n-t>` atbalsta slotu izmantošanu, lai dinamiski ievietotu Vue komponentus vai citu saturu konkrētās tulkojuma daļās.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

Šajā piemērā vietturis `\{link\}` `feedback.text` tulkojuma virknē tiek aizstāts ar komponentu `<nuxt-link>`, kas pats satur citu tulkošanas komponentu.

### Daudzskaitlis

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

Tas automātiski piemēro daudzskaitļa noteikumus, pamatojoties uz `itemCount` vērtību.

## 🚀 Papildu funkcijas

### Noklusējuma slots

Ja nav norādīts konkrēts slots, tulkojumu var pielāgot caur noklusējuma slotu, kas nodrošina visu tulkoto virkni:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### Nosacīta renderēšana

Nerenderēt neko, ja tulkojuma virkne ir tukša, izmantojot rekvizītu `hideIfEmpty`.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### Pielāgots daudzskaitļa noteikums

Izmanto pielāgotu funkciju, lai apstrādātu daudzskaitli.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### Uzlabots piemērs ar slotiem

Izmanto slotus, lai pielāgotu, kā tulkojuma saturs tiek renderēts.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
