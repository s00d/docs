# 🌍 `<i18n-link>` komponents

Komponents `<i18n-link>` modulī `Nuxt I18n Micro` ir daudzpusīgs saites komponents, kas automātiski lokalizē maršrutus, pamatojoties uz pašreizējo lokalizāciju. Tas darbojas kā ietinums ap komponentu `<NuxtLink>`, nodrošinot papildu funkcijas, piemēram, aktīvās saites stilizāciju un atbalstu ārējām saitēm.

## ⚙️ Rekvizīti

{/* generated:component:i18n-link — do not edit; run `pnpm run docs:generate` */}

| Rekvizīts | Tips | Noklusējums | Apraksts |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | Mērķa maršruts. Tiek lokalizēts automātiski; ārējs URL tiek nodots nemainīts. |
| `activeStyle` | `Partial<CSSStyleValue>` | — | Iekļautais stils, kas tiek piemērots, kamēr saite norāda uz pašreizējo maršrutu. |

**\*** obligāts.

### Sloti

| Slots | Sasaistes | Apraksts |
| --- | --- | --- |
| `default` | — | Saites saturs. |

{/* /generated:component:i18n-link */}

`to` pieņem visu, ko pieņem `NuxtLink` — ceļu, nosauktu maršrutu vai atrisinātu maršruta objektu. Absolūts URL tiek atklāts un renderēts kā vienkāršs `<a target="_blank" rel="noopener noreferrer">`, nevis lokalizēts.

## 🛠️ Lietošanas piemēri

### Pamata lietošana

```vue
<i18n-link to="/about">About Us</i18n-link>
```

Šis piemērs izveido saiti uz lapu `/about`, lokalizētu pašreizējai lokalizācijai.

### Aktīvās saites stilizācija ar iekļautajiem stiliem

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

Saitei būs treknraksts, kad lietotājs atrodas lapā `/about`, ļaujot tev stilizēt aktīvo saiti tieši ar iekļautajiem stiliem.

### Ārējo saišu apstrāde

Komponents automātiski atklāj ārējas saites un pievieno nepieciešamos atribūtus drošībai.

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

Šī saite atvērs `https://example.com` jaunā cilnē ar piemēroto `rel="noopener noreferrer"`.

## 🎨 Stili

Komponents tagad izmanto iekļautos stilus aktīvajam stāvoklim, nevis klasi. Šos stilus vari pielāgot, izmantojot rekvizītu `activeStyle`.

### Noklusējuma aktīvie stili

- **Fonta biezums**: `bold`.
- **Krāsa**: manto pārlūka noklusējuma krāsu (ja `activeStyle` nav norādīts `color`).

Šos vari pārrakstīt, nodrošinot pielāgotus stilus caur rekvizītu `activeStyle`.

### Pielāgoti aktīvie stili

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

Šajā piemērā saite būs trekna un zaļa, kad aktīva.

## 🚀 Papildu funkcijas

### Slots pielāgotam saturam

Vari nodot pielāgotu saturu saites iekšpusē, izmantojot slotus, padarot komponentu elastīgu dažādiem lietošanas gadījumiem.

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### Pieejamības uzlabojumi

Komponents atbalsta `aria-label` un citus pieejamības atribūtus, lai nodrošinātu pieejamāku pieredzi.

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
