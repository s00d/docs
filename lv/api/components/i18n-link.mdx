# 🌍 `<i18n-link>` komponents

Komponents `<i18n-link>` modulī `Nuxt I18n Micro` ir daudzpusīgs saites komponents, kas automātiski lokalizē maršrutus, balstoties uz pašreizējo lokāli. Tas darbojas kā ietinošais komponents ap `<NuxtLink>`, piedāvājot papildu funkcijas, piemēram, aktīvas saites stilus un atbalstu ārējām saitēm.

## ⚙️ Prop parametri

{/* generated:component:i18n-link — do not edit; run `pnpm run docs:generate` */}

| Prop | Tips | Noklusējums | Apraksts |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | Mērķa maršruts. Automātiski lokalizēts; ārējs URL tiek nodots nemainīts. |
| `activeStyle` | `Partial<CSSStyleValue>` | — | Iekļautais stils, kas tiek piemērots, kamēr saite norāda uz pašreizējo maršrutu. |

**\*** obligāti.

### Sloti

| Slots | Sasaistes | Apraksts |
| --- | --- | --- |
| `default` | — | Saites saturs. |

{/* /generated:component:i18n-link */}

`to` pieņem visu, ko pieņem `NuxtLink` — ceļu, nosauktu maršrutu vai atrisināta maršruta objektu.
Absolūts URL tiek noteikts un renderēts kā parasts `<a target="_blank" rel="noopener noreferrer">`,
nevis lokalizēts.

## 🛠️ Lietošanas piemēri

### Pamata lietošana

```vue
<i18n-link to="/about">About Us</i18n-link>
```

Šis piemērs izveido saiti uz lapu `/about`, lokalizētu uz pašreizējo lokāli.

### Aktīvas saites stilēšana ar iekļautiem stiliem

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

Saitei būs treknraksts, kad lietotājs atrodas lapā `/about`, ļaujot jums stilēt aktīvo saiti tieši ar iekļautiem stiliem.

### Ārējo saišu apstrāde

Komponents automātiski nosaka ārējās saites un pievieno nepieciešamos atribūtus drošībai.

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

Šī saite atvērs `https://example.com` jaunā cilnē ar piemēroto `rel="noopener noreferrer"`.

## 🎨 Stili

Komponents tagad aktīvajam stāvoklim izmanto iekļautos stilus, nevis klasi. Šos stilus varat pielāgot, izmantojot prop `activeStyle`.

### Noklusējuma aktīvie stili

- **Fonta biezums**: `bold`
- **Krāsa**: manto pārlūka noklusējuma krāsu (ja `activeStyle` nav norādīta `color`).

Šos varat pārrakstīt, izmantojot pielāgotus stilus caur `activeStyle` prop.

### Pielāgoti aktīvie stili

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

Šajā piemērā saite būs treknraksta un zaļa, kad aktīva.

## 🚀 Papildu funkcijas

### Slots pielāgotam saturam

Jūs varat nodot pielāgotu saturu saites iekšpusē, izmantojot slotus, padarot komponentu elastīgu dažādiem lietošanas gadījumiem.

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### Piekļūstamības uzlabojumi

Komponents atbalsta `aria-label` un citus piekļūstamības atribūtus, lai nodrošinātu pieejamāku pieredzi.

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
