# 🌍 `<i18n-group>` komponents

Komponents `<i18n-group>` modulī Nuxt I18n Micro nodrošina ērtu veidu, kā grupēt tulkojumus zem kopīga prefiksa, samazinot atkārtošanos un uzlabojot koda organizāciju.

## ⚙️ Rekvizīti

{/* generated:component:i18n-group — do not edit; run `pnpm run docs:generate` */}

| Rekvizīts | Tips | Noklusējums | Apraksts |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | Atslēgas prefikss, pret kuru tiek atrisināta katra meklēšana slotā. |
| `groupClass` | `string` | `''` | Papildu klase ietinuma elementā. |

**\*** obligāts.

### Sloti

| Slots | Sasaistes | Apraksts |
| --- | --- | --- |
| `default` | `prefix`, `t` | Saņem `prefix` un tam piesaistītu `t` funkciju. |

## 🎯 Sloti

Noklusējuma slots saņem `prefix` un tam piesaistītu `t` funkciju, tāpēc atslēgas iekšpusē tiek rakstītas relatīvi prefiksam:

```vue
<i18n-group prefix="checkout">
  <template #default="{ t }">
    <h2>{{ t('title') }}</h2>
    <p>{{ t('summary', { count: 3 }) }}</p>
  </template>
</i18n-group>
```

## 🛠️ Lietošanas piemērs

### Pamata lietošana

```vue
<template>
  <i18n-group prefix="product.details">
    <template #default="{ t }">
      <h1>{{ t('title') }}</h1>
      <p>{{ t('description') }}</p>
      <div class="price">{{ t('price', { value: 99.99 }) }}</div>
    </template>
  </i18n-group>
</template>
```

Tulkojumu fails:

```json
{
  "product": {
    "details": {
      "title": "Premium Product",
      "description": "This is a premium product",
      "price": "Price: ${value}"
    }
  }
}
```

### Ar pielāgotu klasi

```vue
<template>
  <i18n-group prefix="user.profile" group-class="profile-section">
    <template #default="{ t }">
      <div class="user-info">
        <h2>{{ t('title') }}</h2>
        <p>{{ t('bio') }}</p>
        <div class="stats">
          <span>{{ t('stats.followers') }}</span>
          <span>{{ t('stats.following') }}</span>
        </div>
      </div>
    </template>
  </i18n-group>
</template>
```

Tulkojumu fails:

```json
{
  "user": {
    "profile": {
      "title": "User Profile",
      "bio": "User biography goes here",
      "stats": {
        "followers": "Followers: {count}",
        "following": "Following: {count}"
      }
    }
  }
}
```

### Ar dinamisku saturu

```vue
<template>
  <i18n-group prefix="blog.post">
    <template #default="{ t }">
      <article>
        <h1>{{ t('title') }}</h1>
        <div class="meta">
          {{ t('meta.author', { name: author }) }} |
\u0001\u0001\u0001          {{ t('meta.date', { date: publishDate }) }}
        </div>
        <div v-for="(section, index) in sections" :key="index">
          <h2>{{ t(`sections.${index}.title`) }}</h2>
          <p>{{ t(`sections.${index}.content`) }}</p>
        </div>
      </article>
    </template>
  </i18n-group>
</template>

<script setup>
const author = 'John Doe'
const publishDate = '2024-01-01'
const sections = ['intro', 'main', 'conclusion']
</script>
```

## 🎨 Stilizācija

Komponents ietin savu saturu div elementā ar klasi `i18n-group` un jebkurām papildu klasēm, kas norādītas rekvizītā `groupClass`:

```css
.i18n-group {
  /* Your base styles */
}

.profile-section {
  /* Additional styles for profile sections */
}
```

## 🚀 Labākās prakses

1. **Konsekventi prefiksi**: izmanto konsekventus un loģiskus prefiksus, kas atspoguļo tavas lietotnes struktūru.

```vue
<i18n-group prefix="features.pricing">
<i18n-group prefix="features.security">
```

2. **Modulāra organizācija**: grupē saistītos tulkojumus kopā zem jēgpilniem prefiksiem.

```vue
<i18n-group prefix="checkout.payment">
<i18n-group prefix="checkout.shipping">
```

3. **Atkārtoti izmantojami komponenti**: veido atkārtoti izmantojamus komponentus ar savām tulkojumu grupām.

```vue
<!-- UserProfile.vue -->
<i18n-group prefix="user.profile">

<!-- UserSettings.vue -->
<i18n-group prefix="user.settings">
```

4. **Ligzdotas grupas**: izvairies no dziļas grupu ligzdošanas, lai saglabātu skaidrību.

```vue
<!-- Good -->
<i18n-group prefix="shop.product">

<!-- Avoid -->
<i18n-group prefix="shop.category.product.details.specs">
```
