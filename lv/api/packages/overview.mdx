title: "Pakotņu API"
description: "Katras @i18n-micro/* pakotnes eksportētais API, ģenerēts no API momentuzņēmumiem, kurus CI pārbauda pret pirmkodu."
---

Nuxt modulis ir veidots no nelielām `@i18n-micro/*` pakotnēm, un lielākā daļa no tām darbojas arī patstāvīgi: `@i18n-micro/vue` Vue lietotnē, `@i18n-micro/core` jebkur. Izmantojiet šīs lapas, lai uzzinātu, ko pakotne eksportē katrā ieejas punktā. Katra lapa ir ģenerēta no momentuzņēmuma, ko [`pnpm run api:surface`](https://s00d.github.io/nuxt-i18n-micro/contributing/maintenance-commands#api-surface) pārbauda pret TypeScript pirmkodu, tāpēc eksports nevar mainīties, CI to nepamanot.
