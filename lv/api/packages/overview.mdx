# Pakešu API

`nuxt-i18n-micro` ir izveidots no neliela pakešu kopuma, no kurām lielākā daļa ir lietojama patstāvīgi — `@i18n-micro/vue` parastā Vue lietotnē, `@i18n-micro/core` jebkur.

Katra zemāk esošā lapa tiek ģenerēta no API momentuzņēmuma, ko [`pnpm run api:surface`](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/maintenance-commands.md#api-surface) pārbauda pret TypeScript avotiem, tāpēc eksports nevar pazust bez tā, lai vai nu šī atsauce mainītos, vai CI izgāztos.
