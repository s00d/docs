# API atsauce

## Izpildlaika API

- [Metodes](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, lokalizācijas maiņa, maršrutēšanas palīgi.
- [Notikumi](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`.
- [Tulkojumi un kešatmiņa](/api/cache) — `TranslationStorage`, slodzes ielāde, `$clearCache`.

## Servera starpprogrammatūra

Servera apstrādātāji izmanto īpašu starpprogrammatūru (nevis klienta `$t` palīgus):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — tulko API maršrutos un servera apstrādātājos.
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — nolasa noteikto lokalizāciju un metadatus.

Pilnu iestatīšanu, lokalizācijas noteikšanas prioritāti un piemērus skati pilnajā [Servera puses tulkojumu ceļvedī](/guides/server-side-translations).

## Saistītais

- [Kompozīti](/api/overview) — `useI18n`, `useI18nLocale`, `useLocaleHead`.
- [Konfigurācijas atsauce](/guides/configuration) — visas `i18n` moduļa opcijas.
