Šajā sadaļā ir uzskaitīta katra Nuxt moduļa opcija, palīgfunkcija, āķis, kompozīcijas funkcija un komponents, kā arī katras `@i18n-micro/*` pakotnes eksportētais API. Izmantojiet to, lai uzzinātu signatūru vai noklusējuma vērtību; [Rokasgrāmatā](/lv/guide/getting-started) ir paskaidrots, kā tos lietot. Lielākā daļa šeit esošo tabulu ir ģenerētas no pirmkoda, tāpēc tās atbilst kodam.

## Nuxt modulis {#nuxt-module}

| Lapa | Aptver |
| --- | --- |
| [Moduļa opcijas](/lv/api/module-options) | Katra `i18n` atslēga failā `nuxt.config` ar tipu un noklusējuma vērtību |
| [Palīgfunkcijas](/lv/api/methods) | `$t`, `$tc`, `$tn`, `$td`, `$localePath`, `$switchLocale`, `$defineI18nRoute` un pārējās |
| [Āķi](/lv/api/events) | Izpildlaika āķis `i18n:register` |

## Kompozīcijas funkcijas {#composables}

| Kompozīcijas funkcija | Izmantojiet to |
| --- | --- |
| [`useI18n`](/lv/composables/useI18n) | Palīgfunkcijām blokā `<script setup>` |
| [`useI18nLocale`](/lv/composables/useI18nLocale) | Lokalizācijas stāvoklim un sīkdatnei pielāgotā noteikšanas spraudnī |
| [`useI18nHead`](/lv/composables/useI18nHead) | Ģenerēto SEO tagu pārrakstīšanai atsevišķās lapās |
| [`useLocaleHead`](/lv/composables/useLocaleHead) | SEO tagiem kā objektam jūsu paša `useHead` |

## Komponenti {#components}

| Komponents | Attēlo |
| --- | --- |
| [`<i18n-t>`](/lv/components/i18n-t) | Vienu tulkojumu ar daudzskaitli, formatēšanu un slotu interpolāciju |
| [`<i18n-link>`](/lv/components/i18n-link) | `NuxtLink` uz lokalizēto maršrutu |
| [`<i18n-switcher>`](/lv/components/i18n-switcher) | Lokalizāciju nolaižamo izvēlni |
| [`<i18n-group>`](/lv/components/i18n-group) | Bloku ar kopīgu atslēgu prefiksu |

## Serveris {#server}

Nitro apstrādātāji izmanto `useTranslationServerMiddleware` un `useLocaleServerMiddleware`, nevis klienta palīgfunkcijas. Skatiet [Servera maršruti](/lv/guide/server-side-translations).

## Pakotnes {#packages}

[Pakotņu API](/lv/api/packages/overview) uzskaita katras `@i18n-micro/*` pakotnes eksportus, katrai pa vienai ģenerētai lapai.
