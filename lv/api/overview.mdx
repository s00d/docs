# API atsauce

## Izpildlaika API

- [Metodes](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, lokāles pārslēgšana, maršrutēšanas palīgi
- [Notikumi](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Tulkojumi un kešs](/api/cache) — `TranslationStorage`, payload ielāde, `$clearCache`

## Servera starpprogrammatūra

Servera apstrādātāji izmanto veltītu starpprogrammatūru (nevis klienta `$t` palīgus):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — tulkot API maršrutos un servera apstrādātājos
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — nolasīt noteikto lokāli un metadatus

Pilnu iestatīšanu, lokāles noteikšanas prioritāti un piemērus skatiet [Servera puses tulkojumu ceļvedī](/guides/server-side-translations).
