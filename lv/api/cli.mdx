[CLI ceļvedis](/lv/guide/cli) parāda biežākās darbplūsmas. Šajā lapā ir uzskaitīts viss, un tā ir ģenerēta no tās pašas tabulas, kas nodrošina `--help`.

## Kopīgie karodziņi {#common-flags}

| Karodziņš | Noklusējums | Apraksts |
| --- | --- | --- |
| `--cwd` | pašreizējā direktorija | Projekta direktorija |
| `--logLevel` | `info` | Izvades līmenis: silent, info |
| `--debug` | `false` | Izdrukāt steka izsekojumu, ja komanda neizdodas |

## Pārbaude {#inspect}

### `info` {#info}

Izdrukāt projekta atrisināto i18n konfigurāciju

| Karodziņš | Noklusējums | Apraksts |
| --- | --- | --- |
| `--json` | `false` | Izdrukāt JSON teksta vietā |

### `check` {#check}

CI vārti: neizdoties trūkstošu, tukšu, lieku, nedefinētu vai neizmantotu atslēgu un bojātu vietturu gadījumā

| Karodziņš | Noklusējums | Apraksts |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` no nuxt.config | Tulkojumu direktorija, relatīvi pret projektu |
| `--only` | visas, izņemot duplicates | Ar komatiem atdalītas izpildāmās pārbaudes: missing, empty, extra, placeholders, undefined, unused, duplicates. Šeit norādīta `unused` neizdodas, ja to nevar izpildīt |
| `--duplicates` | `false` | Ziņot arī par vienu un to pašu tekstu dažādās atslēgās |
| `--ignore` | — | Ar komatiem atdalīti izlaižamo avota failu glob šabloni, relatīvi pret projektu |
| `--json` | `false` | Izdrukāt JSON teksta vietā |

```bash
i18n-micro check
i18n-micro check --only missing,placeholders --json
```

### `stats` {#stats}

Parādīt tulkojumu pabeigtību katrai lokalizācijai

| Karodziņš | Noklusējums | Apraksts |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` no nuxt.config | Tulkojumu direktorija, relatīvi pret projektu |
| `--html` | — | Papildus ierakstīt HTML atskaiti šajā failā |
| `--json` | `false` | Izdrukāt JSON teksta vietā |
| `--baseRef` | — | Git atsauce, ar kuru salīdzināt pabeigtību, piem., HEAD~1 vai main |

```bash
i18n-micro stats --baseRef main
i18n-micro stats --html reports/i18n.html
```

### `lint` {#lint}

Pārbaudīt tulkojumu tekstu; neizdodas, ja paliek problēmas

| Karodziņš | Noklusējums | Apraksts |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` no nuxt.config | Tulkojumu direktorija, relatīvi pret projektu |
| `--rules` | visi vai `enabledRules` no .i18n-lintrc.json | Ar komatiem atdalīti izpildāmie noteikumi: no-trailing-spaces, no-multiple-spaces, no-empty-translation vai pielāgots noteikums |
| `--fix` | `false` | Labot to, ko var labot: atstarpes un pielāgotos noteikumus ar aizstājēju |
| `--json` | `false` | Izdrukāt JSON teksta vietā |

```bash
i18n-micro lint --rules no-trailing-spaces --fix
```

### `search` {#search}

Meklēt atslēgas un vērtības un parādīt, kur katra atslēga tiek izmantota

| Karodziņš | Noklusējums | Apraksts |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` no nuxt.config | Tulkojumu direktorija, relatīvi pret projektu |
| `<query>` | — | Meklējamais teksts vai atslēga |
| `--caseSensitive` | `false` | Ievērot reģistru |
| `--onlyUnused` | `false` | Tikai atslēgas, kuras noņemtu `clean`; vaicājums kļūst neobligāts |
| `--scope` | `all` | Kur meklēt: global, pages, all |
| `--limit` | — | Atgriezt ne vairāk kā šo atslēgu skaitu |
| `--ignore` | — | Ar komatiem atdalīti izlaižamo avota failu glob šabloni, relatīvi pret projektu |
| `--json` | `false` | Izdrukāt JSON teksta vietā |

```bash
i18n-micro search "Welcome"
i18n-micro search --onlyUnused
```

## Tulkošanas darbplūsma {#translation-workflow}

### `extract` {#extract}

Uzskaitīt atslēgas, ko izmanto avota faili un kurām vēl nav teksta, un pievienot tās ar noklusējuma tekstu noklusējuma lokalizācijai

| Karodziņš | Noklusējums | Apraksts |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` no nuxt.config | Tulkojumu direktorija, relatīvi pret projektu |
| `--ignore` | — | Ar komatiem atdalīti izlaižamo avota failu glob šabloni, relatīvi pret projektu |

```bash
i18n-micro extract
```

### `translate` {#translate}

Aizpildīt trūkstošos tulkojumus no noklusējuma lokalizācijas, izmantojot tulkošanas pakalpojumu

| Karodziņš | Noklusējums | Apraksts |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` no nuxt.config | Tulkojumu direktorija, relatīvi pret projektu |
| `--service` | — | Tulkošanas pakalpojums: ai, azure, deepl, google, libretranslate, yandexcloud |
| `--token` | — | API atslēga. Ieteicams izmantot vides mainīgo I18N_TRANSLATE_TOKEN: karodziņi nonāk čaulas vēsturē |
| `--options` | — | Pakalpojuma opcijas kā key:value pāri, atdalīti ar komatiem |
| `--locale` | visas lokalizācijas, izņemot noklusējuma | Ar komatiem atdalītas aizpildāmās lokalizācijas |
| `--replace` | `false` | Tulkot katru atslēgu no jauna, aizstājot esošās vērtības |
| `--dryRun` | `false` | Saskaitīt atslēgas un rakstzīmes katrai lokalizācijai; neko nesūtīt |
| `--chunkSize` | — | Virknes vienā pieprasījumā; ierobežots līdz tam, ko pakalpojums pieņem |
| `--pluralSeparator` | `\|` | Daudzskaitļa formu atdalītājs ziņojumos |
| `--glossaryFile` | `.i18n-glossary.json`, ja tas pastāv | Glosārija fails, ko izmanto pakalpojums `ai` |

```bash
i18n-micro translate --dryRun
I18N_TRANSLATE_TOKEN=... i18n-micro translate --service deepl --locale de,fr
i18n-micro translate --service ai --options provider:openai,model:gpt-4o-mini
i18n-micro translate --service libretranslate --options baseUrl:https://translate.example.com
```

### `sync` {#sync}

Noņemt atslēgas, kuru nav noklusējuma lokalizācijā; apstājas, ja nevar pierādīt, ka tas ir droši. Trūkstošās atslēgas paliek trūkstošas

| Karodziņš | Noklusējums | Apraksts |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` no nuxt.config | Tulkojumu direktorija, relatīvi pret projektu |
| `--ignore` | — | Ar komatiem atdalīti izlaižamo avota failu glob šabloni, relatīvi pret projektu |
| `--dryRun` | `false` | Uzskaitīt, kas tiktu noņemts; neko nerakstīt |
| `--force` | `false` | Noņemt atslēgas, pat ja nevar pierādīt, ka tas ir droši |

```bash
i18n-micro sync --dryRun
```

### `clean` {#clean}

Noņemt atslēgas, kuras nekas projektā neizmanto; apstājas, ja to nevar pierādīt

| Karodziņš | Noklusējums | Apraksts |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` no nuxt.config | Tulkojumu direktorija, relatīvi pret projektu |
| `--include` | — | Regulārā izteiksme: noņemšanai apsvērt tikai atbilstošās atslēgas |
| `--exclude` | — | Regulārā izteiksme: nekad nenoņemt atbilstošās atslēgas |
| `--ignore` | — | Ar komatiem atdalīti izlaižamo avota failu glob šabloni, relatīvi pret projektu |
| `--dryRun` | `false` | Uzskaitīt, kas tiktu noņemts; neko nerakstīt |
| `--force` | `false` | Noņemt atslēgas, pat ja ne visām var pierādīt izmantojumu |

```bash
i18n-micro clean --dryRun
i18n-micro clean --exclude '^errors\.'
```

## Refaktorēšana {#refactoring}

### `text-to-i18n` {#text-to-i18n}

Aizstāt iekodētu tekstu Vue veidnēs ar tulkošanas izsaukumiem un ziņot par iekodētu tekstu kodā

| Karodziņš | Noklusējums | Apraksts |
| --- | --- | --- |
| `--translationFile` | `<translationDir>/<defaultLocale>.json` | Fails, kurā nonāk jaunās atslēgas |
| `--path` | viss projekts | Apstrādājamais fails vai direktorija |
| `--context` | — | Prefikss ģenerētajām atslēgām |
| `--ignore` | — | Ar komatiem atdalīti izlaižamo avota failu glob šabloni, relatīvi pret projektu |
| `--dryRun` | `false` | Parādīt, kas mainītos; neko nerakstīt |
| `--interactive` | `false` | Apstiprināt vai rediģēt katru ģenerēto atslēgu |

```bash
i18n-micro text-to-i18n --dryRun
i18n-micro text-to-i18n --path components --context ui
```

### `rename` {#rename}

Pārdēvēt atslēgu vai nosaukumvietu visās lokalizācijās un avota failos

| Karodziņš | Noklusējums | Apraksts |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` no nuxt.config | Tulkojumu direktorija, relatīvi pret projektu |
| `--from` **\*** | — | Pašreizējā atslēga vai nosaukumvieta |
| `--to` **\*** | — | Jaunā atslēga vai nosaukumvieta |
| `--ignore` | — | Ar komatiem atdalīti izlaižamo avota failu glob šabloni, relatīvi pret projektu |
| `--dryRun` | `false` | Ziņot par izmaiņām; neko nerakstīt |

**\*** obligāts.

```bash

```

### `pseudo` {#pseudo}

Aizpildīt lokalizāciju ar pseidotulkojumiem, lai atrastu izkārtojuma un iekodēta teksta problēmas

### `format` {#format}

Pārrakstīt lokalizāciju failus ar sakārtotām atslēgām un vienotu atkāpi

| Karodziņš | Noklusējums | Apraksts |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` no nuxt.config | Tulkojumu direktorija, relatīvi pret projektu |
| `--indent` | `2` | Atkāpes atstarpju skaits |
| `--sortKeys` | `true` | Kārtot atslēgas; izmantojiet --no-sortKeys, lai saglabātu to secību |
| `--check` | `false` | Neizdoties, ja fails mainītos; neko nerakstīt |


## Apmaiņa {#exchange}

### `export` {#export}

Eksportēt lokalizāciju failus PO vai CSV formātā, kā avotu izmantojot noklusējuma lokalizācijas tekstu

| Karodziņš | Noklusējums | Apraksts |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` no nuxt.config | Tulkojumu direktorija, relatīvi pret projektu |
| `--format` | `po` | Faila formāts: po, csv |
| `--dir` | `pots` formātam po, `csv_exports` formātam csv | Izvades direktorija, relatīvi pret projektu |
| `--force` | `false` | Pārrakstīt failus, kas mainīti kopš pēdējā eksporta un nekad nav importēti |

```bash
i18n-micro export --format csv
```

### `import` {#import}

Apvienot PO vai CSV failus ar lokalizāciju failiem

| Karodziņš | Noklusējums | Apraksts |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` no nuxt.config | Tulkojumu direktorija, relatīvi pret projektu |
| `--format` | `po` | Faila formāts: po, csv |
| `--dir` | `pots` formātam po, `csv_exports` formātam csv | Ievades direktorija, relatīvi pret projektu |
| `--dryRun` | `false` | Ziņot, kas tiktu importēts; neko nerakstīt |

```bash
i18n-micro import --format csv --dryRun
```

### `sync-remote` {#sync-remote}

Lejupielādēt globālos tulkojumus no HTTP galapunkta, kas norādīts .i18n-remote.json, vai augšupielādēt tos uz to

| Karodziņš | Noklusējums | Apraksts |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` no nuxt.config | Tulkojumu direktorija, relatīvi pret projektu |
| `--pull` | `true` | Lejupielādēt no attālā avota |
| `--push` | `false` | Augšupielādēt uz attālo avotu |
| `--force` | `false` | Lejupielādējot ņemt attālo vērtību; augšupielādējot pārrakstīt tekstu, kas ir tikai attālajā avotā |
| `--dryRun` | `false` | Ziņot, ko mainītu lejupielāde; neko nerakstīt un neaugšupielādēt |

```bash
i18n-micro sync-remote --dryRun
i18n-micro sync-remote --no-pull --push
```

## Lint noteikumi {#lint-rules}

| Noteikums | Atrod | Labo `--fix` |
| --- | --- | --- |
| `no-trailing-spaces` | Atstarpes vērtības vai rindas beigās | jā |
| `no-multiple-spaces` | Divas vai vairāk atstarpes pēc kārtas | jā |
| `no-empty-translation` | Tukša vai neaizpildīta vērtība | nē |

## Izejas kodi {#exit-codes}

| Kods | Nozīme |
| --- | --- |
| `0` | Pabeigts, nav par ko ziņot |
| `1` | Atradumi: `check`, `lint` vai `format --check` kaut ko atrada, `clean` vai `sync` nevarēja pierādīt, ka noņemšana ir droša, `export` pārrakstītu neimportētu darbu, `translate` izlaida atslēgas, `import` vai `sync-remote` sastapa konfliktu, `sync-remote` augšupielāde izmestu attālo tekstu. `clean`, `sync` vai `sync-remote` lejupielādes `--dryRun` par tiem ziņo un beidzas ar `0` |
| `2` | Kļūme: nepareiza lietošana, nenolasāms projekts, tīkla vai faila kļūda |

## Konfigurācijas faili {#configuration-files}

| Fails | Izmanto |
| --- | --- |
| `.i18n-lintrc.json` | `lint`: `enabledRules`, `disabledRules`, `customRegexRules` (`name`, `pattern`, `flags`, `description`, `replacement`) |
| `.i18n-remote.json` | `sync-remote`: `url`, `path`, `token`, `auth` (`username`, `password`). `type` var izlaist; pastāv tikai `custom` |
| `.i18n-glossary.json` | `translate --service ai`: `entries` ar `source`, `target` un neobligātiem `from`, `to` |

## Vides mainīgie {#environment-variables}

| Nosaukums | Izmanto |
| --- | --- |
| `I18N_TRANSLATE_TOKEN` | `translate` API atslēga. Tiek nolasīts arī no `.env` |
| `I18N_REMOTE_TOKEN` | `sync-remote` Bearer marķieris. Tiek nolasīts arī no `.env` |
| `AI_GATEWAY_API_KEY, OPENAI_API_KEY, ANTHROPIC_API_KEY` | Pakalpojuma `ai` atslēga, ja `I18N_TRANSLATE_TOKEN` nav iestatīts |
| `DEFAULT_LOCALE` | Pārraksta `defaultLocale`, tāpat kā modulī |
