Modulis izsauc vienu izpildlaika (lietotnes) āķi — `i18n:register`. Izmantojiet to, ja spraudnis vai modulis pievieno tulkojumus, kuru nav jūsu `locales/` failos. Jūsu atzvanīšanas funkcija saņem funkciju `register`, kas sapludina tulkojumus attēlojamajā lapā.

## `i18n:register` {#i18nregister}

```ts
'i18n:register': (
  register: (translations: unknown, locale?: string) => void,
  locale: string,
) => HookResult
```

| Arguments | Apraksts |
| --- | --- |
| `register(translations, locale?)` | Dziļi sapludina `translations` ielādējamā maršruta lapas daļā lokalizācijai `locale` (pēc noklusējuma — āķa `locale`). Jau esošās atslēgas tiek pārrakstītas. |
| `locale` | Ielādējamā maršruta lokalizācija. |

Āķis ir tipizēts ar `RuntimeNuxtHooks`, tāpēc `nuxtApp.hook('i18n:register', …)` nav nepieciešama tipa pārveidošana.

## Kad tas tiek izsaukts {#when-it-fires}

To izsauc ielādes spraudnis (`i18n-plugin-loader`):

1. vienreiz startēšanas laikā, kad visi spraudņi ir izpildījušies (`app:created`) un pirms lietotne tiek renderēta;
2. savā `router.beforeEach`, kad mērķa lapas tulkojumi ir ielādēti un ceļš mainās — ar `no_prefix` katras navigācijas laikā.

Katra atzvanīšanas funkcija un katrs `register` izsaukums tiek sagaidīts, pirms lietotne tiek renderēta vai navigācija turpinās, tāpēc lapa tiek renderēta ar sapludinātajām atslēgām. Ar [`hooks: false`](/lv/api/module-options#hooks) āķis netiek izsaukts nekad.

## Piemērs {#example}

```ts
// plugins/i18n-extra.ts
export default defineNuxtPlugin((nuxtApp) => {
  nuxtApp.hook('i18n:register', async (register, locale) => {
    const extra = await $fetch<Record<string, unknown>>(`/api/cms-strings/${locale}`)
    register(extra, locale)
  })
})
```

Šis ir izpildlaika āķis: reģistrējiet to ar `nuxtApp.hook` spraudnī, nevis ar `nuxt.hook` failā `nuxt.config` vai moduļa `setup`. Modulis šādu spraudni pievieno ar `addPlugin`.
