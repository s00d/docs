title: "Palīgfunkcijas"
description: "Katra izpildlaika palīgfunkcija, ko modulis injicē — `$t`, `$tc`, `$localePath`, `$switchLocale` un pārējās — ar tās signatūru."
---

Modulis injicē savas izpildlaika palīgfunkcijas Nuxt lietotnē: `$t`, `$tc`, `$localePath`, `$switchLocale` un pārējās. Izmantojiet šo lapu, lai uzzinātu palīgfunkcijas signatūru un uzvedību. Signatūras un apraksti ņemti no `PluginsInjections` un `NuxtAppOnlyInjections` interfeisiem failā `src/runtime/plugins/01.plugin.ts`.

## Piekļuve {#access}

| Kur | Kā |
| --- | --- |
| Veidne | `{{ $t('title') }}` — katra palīgfunkcija, ar `$` |
| `<script setup>` | `const { t, localePath } = useI18n()` — katra palīgfunkcija no `PluginsInjections`, ar `$` un bez tā |
| Spraudnis, starpprogrammatūra, `<script setup>` | `const { $t, $defineI18nRoute } = useNuxtApp()` — viss, tikai ar `$` |

`$defineI18nRoute` ir tipizēts tikai uz `useNuxtApp()`. Skatiet [`useI18n`](/lv/composables/useI18n).

```vue
<script setup lang="ts">
const { t, localePath } = useI18n()
</script>

<template>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
</template>
```

## Lokale {#locale}

### `$getLocale` {#$getlocale}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric) => string
```

Aktīvās lokales kods. Nododiet maršrutu, lai nolasītu lokali, kurai šis maršruts pieder.

```ts
$getLocale() // 'de' on /de/about
```

### `$getLocaleName` {#$getlocalename}

```ts
() => string | null
```

Aktīvās lokales `displayName` no konfigurācijas vai `null`, ja tāda nav.

### `$getLocales` {#$getlocales}

```ts
() => Locale[]
```

Visas konfigurētās lokales ar to metadatiem.

Pielāgotās lokales objekta īpašības tiek atgrieztas tādas, kā uzrakstītas; tipizējiet tās ar `Locale` [moduļa paplašināšanu](/lv/api/module-options#locales).

### `$defaultLocale` {#$defaultlocale}

```ts
() => string | undefined
```

Konfigurētās noklusējuma lokales kods.

### `$getI18nConfig` {#$geti18nconfig}

```ts
() => ResolvedI18nConfig
```

Atrisinātā moduļa konfigurācija tāda, kādu to redz izpildlaiks.

Vērtība ietver [izpildlaika pārrakstījumus](/lv/guide/runtime-overrides) (`defaultLocale`, `fallbackLocale`, atspējotās lokales).

```ts
const { strategy, localeCookie } = useNuxtApp().$getI18nConfig()
```

## Tulkošana {#translation}

### `$t` {#$t}

```ts
TranslationFn<CleanTranslation>
```

Iztulkot atslēgu, ievietojot tajā `params`. Atgriež `defaultValue`, ja atslēgas
nav, vai pašu atslēgu, ja noklusējuma vērtība nav norādīta.

```ts
// { "welcome": "Welcome, {name}!" }
$t('welcome', { name: 'Ada' }) // 'Welcome, Ada!'
$t('missing.key', {}, 'Fallback') // 'Fallback'
```

Atslēga, kas norāda uz ligzdotu objektu, atgriež šo objektu, nevis virkni. Veidnē tas tiek attēlots kā `[object Object]`; izmantojiet lapas (gala) atslēgu.

### `$ts` {#$ts}

```ts
TranslationFn<string>
```

Kā `$t`, bet vienmēr atgriež virkni: vērtība iziet caur `toString()`, tāpēc ligzdots
objekts kļūst par `'[object Object]'`. Norādiet atslēgu uz gala elementu.

### `$_t` {#$_t}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<CleanTranslation>
```

Piesaistīt `$t` konkrētam maršrutam, lai tulkotu ārpus pašreizējās lapas — piemēram, izkārtojumā,
kas attēlo saiti uz citu maršrutu.

```ts
const route = useRoute()
const t = useNuxtApp().$_t(route)
t('page.title')
```

### `$_ts` {#$_ts}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<string>
```

Piesaistīt `$ts` konkrētam maršrutam. Skatiet `$_t`.

### `$tc` {#$tc}

```ts
(key: TranslationKey, params: number | Params, defaultValue?: string) => string
```

Tulkot ar daudzskaitļa formām. `params` var būt pats skaits vai objekts, kas satur
`count`.

Formas tiek atdalītas ar `|`. Ar iebūvēto noteikumu nenegatīvs vesels skaits `n` izvēlas formu `n`, ierobežojot līdz pēdējai formai; negatīvs, daļskaitlis vai `NaN` skaits ņem pēdējo formu. `{count}` un pārējie parametri tiek ievietoti izvēlētajā formā.

Valodām, kuru daudzskaitlis neseko skaitam, sāciet veidni ar `=0 `. Tad pirmā forma ir paredzēta 0, bet pārējās seko [`Intl.PluralRules`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/PluralRules) kategorijām secībā `zero, one, two, few, many, other`:

```json
{
  "apples": "=0 no apples | one apple | {count} apples",
  "files": "=0 no files | {count} one | {count} few | {count} many"
}
```

```ts
$tc('apples', 0) // 'no apples'
$tc('apples', 1) // 'one apple'
$tc('apples', 7) // '7 apples'

// In `uk` (categories `one, few, many, other`) the forms after the zero form follow those categories:
$tc('files', 21) // '21 one'
$tc('files', 22) // '22 few'
$tc('files', 25) // '25 many'
$tc('files', 2.5) // '2.5 many': no form for `other`, so the last one
```

- `=0 ` tiek ņemts vērā tikai pašā vērtības sākumā, kopā ar atstarpi. `$t` to rāda kā tekstu: tas attiecas uz daudzskaitli.
- Kategorija bez savas formas ņem pēdējo formu. Arī negatīvs vai daļskaitļa skaits ņem pēdējo formu.
- Tas darbojas jebkurā lokalē: angļu valodā `=0 none | one | {count} many`.
- Kategorija nāk no lokales `iso`, citādi no tās koda. Kods, ko `Intl` nepazīst, atgriežas pie indeksa noteikuma, marķieris joprojām tiek noņemts, tāpēc rezultāts nekad nav atkarīgs no datora.
- `<i18n-t :plural>` seko tam pašam noteikumam. Pielāgots [`plural`](/lv/api/module-options#plural) vai `customPluralRule` saņem neapstrādāto vērtību, ieskaitot marķieri, un izlemj pats; ja `plural` atgriež `null`, izsaukums tiek nodots atpakaļ iebūvētajam noteikumam, kas ievēro marķieri.

Bez marķiera veidne paliek pie indeksa noteikuma ar vienu izņēmumu, ko var nolasīt tikai vienā veidā: nulles forma bez vietturiem, tad viena forma katrai kategorijai, ar `{count}` katrā formā, kuru izmanto vairāki skaiti (`no files | {count} one | {count} few | {count} many` valodā `uk`).

Saviem noteikumiem iestatiet [`plural`](/lv/api/module-options#plural).

```ts
// { "apples": "no apples | one apple | {count} apples" }
$tc('apples', 0) // 'no apples'
$tc('apples', 10) // '10 apples'
$tc('cart', { count: 2, name: 'Ada' }) // count and params in one object
```

Trešais arguments ir `defaultValue`, nevis parametri.

### `$has` {#$has}

```ts
(key: string) => boolean
```

Vai atslēga tiek atrisināta aktīvajā lokalē. Izmantojiet to, lai sazarotu pēc neobligāta teksta, nevis
attēlotu neapstrādātu atslēgu. Tāpat kā `$t`, tā redz arī aizejošās lapas atslēgas pārejas laikā
starp lapām tajā pašā lokalē.

```ts
if ($has('promo.banner')) show.value = true
```

## Formatēšana {#formatting}

### `$tn` {#$tn}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Formatēt skaitli ar `Intl.NumberFormat` aktīvajā lokalē. Atslēga izvēlas nosauktu formātu
no konfigurācijas.

Nosauktie formāti nāk no [`numberFormats`](/lv/api/module-options#numberformats).

```ts
$tn(1234.5, { style: 'currency', currency: 'EUR' }) // '1.234,50 €' in de
$tn(1000, 'currency') // named format
$tn(1000, 'currency', 'de') // named format in another locale
```

### `$td` {#$td}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Formatēt datumu ar `Intl.DateTimeFormat` aktīvajā lokalē. Atslēga izvēlas nosauktu formātu
no konfigurācijas.

Nosauktie formāti nāk no [`datetimeFormats`](/lv/api/module-options#datetimeformats).

```ts
$td(new Date(), { dateStyle: 'long' })
$td(post.createdAt, 'short')
```

### `$tdr` {#$tdr}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

Formatēt datumu kā relatīvu laiku ("pirms 3 dienām") ar `Intl.RelativeTimeFormat`.

```ts
$tdr(Date.now() - 5 * 60_000) // '5 minutes ago' in en
```

## Pārslēgšana un saites {#switching-and-links}

### `$switchLocale` {#$switchlocale}

```ts
(locale: string) => Promise<boolean>
```

Pāriet uz pašreizējo lapu citā lokalē. Ar `no_prefix` un hash režīmā tā ielādē
lokales tulkojumus pirms pārejas; ar `no_prefix` maršruts tiek aizstāts uz vietas (bez
jauna vēstures ieraksta). Nezināma lokale tiek ignorēta.
Izsaukums ir asinhrons: izmantojiet `await`, lai izpildītu kodu pēc pārejas. Tas atgriež `true`, ja
lokales vārdnīca ir aktīva, un `false`, ja nav: fragmentu neizdevās ielādēt (pašreizējā
vārdnīca paliek; izsauciet vēlreiz, lai mēģinātu atkārtoti) vai uzvarēja jaunāka pārslēgšana.

```ts
await $switchLocale('de')
```

### `$switchLocalePath` {#$switchlocalepath}

```ts
(locale: string) => string
```

Pašreizējās lapas ceļš citā lokalē, nepārejot uz to.

```vue
<NuxtLink :to="$switchLocalePath('de')">Deutsch</NuxtLink>
```

### `$switchLocaleRoute` {#$switchlocaleroute}

```ts
(locale: string) => RouteLocationRaw
```

Pašreizējās lapas maršruta objekts citā lokalē, nepārejot uz to, vai URL virkne
lokalei ar savu `baseUrl`. Ar `trailingSlash` objektam ir `path` un `fullPath`,
kas seko noteikumam, ar `query` un `hash` tādiem, kādi tie ir, un `router.push` vai saite tos saglabā.

### `$switchRoute` {#$switchroute}

```ts
(route: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, toLocale?: string) => Promise<void>
```

Pāriet uz citu maršrutu, saglabājot aktīvo lokali vai pārslēdzoties uz `toLocale`. Asinhrona tāpat kā
`$switchLocale`.

```ts
$switchRoute('/about') // active locale
$switchRoute({ name: 'about' }, 'de') // switch to de
```

### `$localePath` {#$localepath}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => string
```

Atrisināt ceļu norādītajā lokalē vai aktīvajā. Virkne ar `http(s):`, `mailto:`
vai `tel:` shēmu tiek atgriezta nemainīta: nenododiet lietotāja ievadi kā saites mērķi bez pārbaudes.

Virknes ceļš tiek nolasīts kā lapa, ko tas attēlo, tāpēc tiek piemērots arī lokales pielāgotais ceļš.

```ts
$localePath('/about') // '/about' in en, '/de/ueber-uns' in de with localeRoutes
$localePath({ name: 'about' }, 'fr') // '/fr/about'
```

### `$localeRoute` {#$localeroute}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => RouteLocationResolved
```

Atrisināt maršrutu norādītajā lokalē vai aktīvajā. Vienkāršs objekts, ko droši var glabāt stāvoklī. Ja parametram vajadzīga
ekranēšana, objektam ir `path`, `fullPath`, `query` un `hash`, bet nav `name` vai `params`: tieši ceļš nodod maršrutētājam
kodēto URL. Lokalei citā domēnā `path` un `fullPath` ir absolūti, ko maršrutētājs nevar pieņemt:
šāda saite iet caur `<i18n-link>` vai `$localePath`.

### `$getRouteName` {#$getroutename}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric, locale?: string) => string
```

Maršruta nosaukums bez lokales prefiksa — nosaukums, pēc kura tiek veidotas tulkojumu atslēgas.

```ts
$getRouteName() // 'about' on /de/about
```

## Lapas konfigurācija {#page-config}

### `$defineI18nRoute` {#$definei18nroute}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Reģistrēt lapas lokales konfigurāciju un tulkojumus no komponenta iekšpuses.
Apvieno ar aktīvo lokali un piemēro atkārtoti, kad lokale mainās.

Izsauciet to lapas `<script setup>`, vienmēr destrukturējot no `useNuxtApp()`. Būvēšana no izsaukuma nolasa `locales`, `localeRoutes` un `disableMeta`; izpildlaikā nozīme ir tikai `locales` (iekļautie tulkojumi tiek apvienoti aktīvajai lokalei). Pilni noteikumi: [Lapas konfigurācija](/lv/guide/per-component-translations).

```vue
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'de'],
  localeRoutes: { en: '/about', de: '/ueber-uns' },
})
</script>
```

### `$setI18nRouteParams` {#$seti18nrouteparams}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Iestatīt pašreizējā maršruta parametrus katrai lokalei, lai dinamiskais segments varētu atšķirties katrā valodā.
Izsauciet to SSR laikā, pirms galvene tiek renderēta.

Parametri tiek notīrīti, kad tiek apstiprināta pāreja uz citu ceļu, ieskaitot `/news/1` uz `/news/4`, kas saglabā maršruta nosaukumu. Sīkāk: [Lokalizēti ceļi](/lv/guide/custom-locale-routes).

```ts
$setI18nRouteParams({
  en: { slug: 'my-post' },
  de: { slug: 'mein-beitrag' },
})
```

## Izpildlaika tulkojumi {#runtime-translations}

### `$mergeTranslations` {#$mergetranslations}

```ts
(newTranslations: Translations) => void
```

Apvienot tulkojumus aktīvajā lokalē izpildlaikā, pārrakstot ielādēto.

Dziļi apvieno ar aktīvās lokales pašreizējās lapas fragmentu; atslēgas, kas nav minētas, saglabājas.

```ts
$mergeTranslations({ banner: { title: 'Sale' } })
```

### `$setTranslation` {#$settranslation}

```ts
(key: string, value: unknown) => void
```

Aizstāt vērtību `key` vietā aktīvajā vārdnīcā. Tā ir aizstāšana, nevis apvienošana —
izmantojiet `$mergeTranslations`, ja esošajiem blakus elementiem jāsaglabājas.

```ts
$setTranslation('banner', { title: 'Sale' }) // drops other keys under banner
$setTranslation('banner.title', 'Sale') // dotted path
```

### `$loadPageTranslations` {#$loadpagetranslations}

```ts
(locale: string, routeName: string, translations: Translations) => Promise<void>
```

Ielādēt lapas tulkojumus izpildlaikā saturam, kura atslēgas nav zināmas būvēšanas laikā.

Apvieno ar atmiņā esošo `(locale, routeName)` fragmentu, un ekrāns atjaunojas, kad šis fragments ir aktīvs. Šeit netiek ielādēts payload: lapai, kas vēl nav ielādēta, tulkojumi gaida, un, kad tās fails ielādējas, tie paliek virs tā.

```ts
await $loadPageTranslations('en', 'about', { title: 'About us' })
```

### `$resolveTranslations` {#$resolvetranslations}

```ts
() => Translations
```

Visi tulkojumi, kas pašlaik atmiņā aktīvajai lokalei un maršrutam, koka veidā.
Tikai lasāms skats uz to, ko `$t()` var atrisināt šobrīd.

Uzskatiet rezultātu par tikai lasāmu.

### `$setMissingHandler` {#$setmissinghandler}

```ts
(handler: MissingHandler | null) => void
```

Uzstādīt atsauces funkciju, kas tiek izsaukta katrai neatrisinātai atslēgai. Nododiet `null`, lai to noņemtu.

Apstrādātājs darbojas izstrādes brīdinājuma vietā.

```ts
$setMissingHandler((locale, key, routeName) => {
  console.error(`[i18n] missing ${key} in ${locale} (${routeName})`)
})
```

### `$clearCache` {#$clearcache}

```ts
() => void
```

Atmest visus kešotos tulkojumu fragmentus un pārlādēt pašreizējās lapas vārdnīcu. Lapa
turpina rādīt pašreizējos tulkojumus, līdz pienāk jaunie. Izstrādes HMR to izsauc pie
katras tulkojumu faila izmaiņas.

```ts
const { clearCache } = useI18n()
clearCache()
```

Neveiksmīga pārlāde saglabā pašreizējo vārdnīcu.
