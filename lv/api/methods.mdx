# 🛠️ Metodes

## 🔍 Tulkojumu metodes

Galvenās metodes tulkojumu iegūšanai un pārvaldīšanai.

### `$t`

{/* generated:method:$t — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Tulko atslēgu, interpolējot tajā `params`. Atgriež `defaultValue`, kad atslēga nav atrasta, vai pašu atslēgu, kad noklusējums nav norādīts.

{/* /generated:method:$t */}

```typescript
const welcomeMessage = $t('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

<Warning>
`$t` atgriež `CleanTranslation`, kas ir `string | number | boolean | Translations | PluralTranslations | null`. Ja atslēga norāda uz **ligzdotu objektu** tavā JSON (piemēram, `$t('header')`, kad JSON satur `\{ "header": \{ "title": "Hi" \} \}`), atgrieztā vērtība būs šis **objekts**, nevis virkne. Izmantojot to tieši Vue veidnē (<code v-pre>\{\{ $t('header') \}\}</code>), tiks renderēts kā `[object Object]`.

**Kā no tā izvairīties:**

- Izmanto konkrētāku atslēgu: `$t('header.title')` → `"Hi"`.
- Izmanto `$ts()`, kas vienmēr atgriež virkni (izsauc `.toString()` uz virkni neietilpstošām vērtībām).
- Izmanto `$t` ar ligzdotu atslēgu, lai apzināti piekļūtu apakšobjektiem programmatiskai izmantošanai.
</Warning>

### `$ts`

{/* generated:method:$ts — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string) => string
```

Tāpat kā `$t`, bet vienmēr atgriež virkni: objekta vai masīva vērtība tiek pārvērsta virknē, nevis atgriezta tāda, kāda ir.

{/* /generated:method:$ts */}

```typescript
const welcomeMessage = $ts('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

### `$_t` un `$_ts`

{/* generated:method:$_t — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Sasaisti `$t` ar konkrētu maršrutu, lai tulkotu ārpus pašreizējās lapas — piemēram, izkārtojums, kas renderē saiti uz citu maršrutu.

{/* /generated:method:$_t */}

{/* generated:method:$_ts — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => string
```

Sasaisti `$ts` ar konkrētu maršrutu. Skati `$_t`.

{/* /generated:method:$_ts */}

`$t` un `$ts` maršrutā piesaistīti varianti. Tie vispirms pieņem **maršrutu** un atgriež tulkošanas funkciju, kas ir piesaistīta šī maršruta lokalizācijai un lapas kontekstam.

- **Piekļuve**: `useNuxtApp()` (arī atkārtoti eksportēts no `useI18n()` kā `$_t` / `$_ts`).

Izmanto šos, kad aktīvais maršruts SSR vai pāreju laikā atšķiras no `router.currentRoute` — piemēram, iekš `<i18n-t>`, `<i18n-group>` vai renderējot saturu konkrētam `route` objektam.

```typescript
import { useRoute, useNuxtApp } from '#imports'

const route = useRoute()
const { $_t, $_ts } = useNuxtApp()

const $t = $_t(route)
const title = $t('page.title')

// String-safe variant
const label = $_ts(route)('page.label')
```


### `$tc`

{/* generated:method:$tc — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params: number | Params, defaultValue?: string) => string
```

Tulko ar daudzskaitli. `params` var būt pats skaits vai objekts, kas satur `count`.

{/* /generated:method:$tc */}

**Tulkojuma formāts**: formas, kas atdalītas ar `|`. Ievieto vietturus **katrā** formā:

```json
{
  "apples": "no apples | one apple | {count} apples",
  "cart": "no items for {name} | one item for {name} | {count} items for {name}"
}
```

```typescript
$tc('apples', 0) // "no apples"
$tc('apples', 1) // "one apple"
$tc('apples', 10) // "10 apples"

// count + other params (second argument must be an object)
$tc('cart', { count: 10, name: 'Alice' }) // "10 items for Alice"
```


**Komponenta alternatīva** — `<i18n-t keypath="cart" :plural="count" :params="\{ name \}" />` (iekšēji sapludina `count` ar `params`).


### `$mergeTranslations`

{/* generated:method:$mergeTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
(newTranslations: Translations) => void
```

Sapludina tulkojumus aktīvajā lokalizācijā izpildlaikā, pārrakstot ielādēto.

{/* /generated:method:$mergeTranslations */}

```typescript

```

### `$resolveTranslations`

{/* generated:method:$resolveTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
() => Translations
```

Katrs tulkojums, kas pašlaik ir atmiņā aktīvajai lokalizācijai un maršrutam, kā koks. Tikai lasāms skats uz to, ko `$t()` var atrisināt tieši tagad.

{/* /generated:method:$resolveTranslations */}

```typescript
const tree = $resolveTranslations()
// { aaa: { bbb: 'ccc' }, ddd: 1111 } — the same dictionary $t() reads from
```

Izmanto to, kad tev nepieciešama pilna atmiņā esošā vārdnīca (DevTools, testi, izpildlaika redaktori). Uzskati atgriezto vērtību par tikai lasāmu; maini vērtības caur `$setTranslation` vai sapludini plāksterus ar `$mergeTranslations`.

### `$setTranslation`

{/* generated:method:$setTranslation — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, value: unknown) => void
```

Aizstāj vērtību ar atslēgu `key` aktīvajā vārdnīcā. Šī ir aizvietošana, nevis sapludināšana — izmanto `$mergeTranslations`, kad esošajiem brāļiem un māsām jāizdzīvo.

{/* /generated:method:$setTranslation */}

```typescript
$setTranslation('aaa', { fff: 'ggg' }) // replaces the whole `aaa` subtree
$setTranslation('aaa', 'text')          // replaces `aaa` with a string
$setTranslation('ddd', 1111)            // scalar at the top level
$setTranslation('aaa.bbb', 'nested')    // dotted path
```

Šī ir **aizvietošana**, nevis sapludināšana. Esošie brāļi un māsas zem tās pašas atslēgas tiek noņemti. Lai plāksterotu, nezaudējot brāļus un māsas, izmanto `$mergeTranslations`.

### `$setMissingHandler`

{/* generated:method:$setMissingHandler — do not edit; run `pnpm run docs:generate` */}

```ts
(handler: MissingHandler | null) => void
```

Instalē atzvanu, kas tiek izsaukts katrai neatrisinātai atslēgai. Nodod `null`, lai to noņemtu.

{/* /generated:method:$setMissingHandler */}

**Tipa definīcija**:

```typescript
type MissingHandler = (locale: string, key: string, routeName: string, instance?: unknown, type?: string) => void
```

```typescript
// Set a custom handler
$setMissingHandler((locale, key, routeName) => {
  console.error(`Missing translation: ${key} in ${locale} for route ${routeName}`)
  // Send to Sentry or other error tracking service
  // Sentry.captureMessage(`Missing translation: ${key}`)
})

// Remove the handler
$setMissingHandler(null)
```

**Lietošanas gadījumi**:

- Trūkstošo tulkojumu reģistrēšana kļūdu izsekošanas servisos (Sentry, LogRocket un citos).
- Analītikas apkopošana par trūkstošajiem tulkojumiem.
- Pielāgota kļūdu apstrāde trūkstošām tulkojumu atslēgām.

## 🔢 Skaitļu un datumu formatēšana

Metodes skaitļu un datumu formatēšanai atbilstoši lokalizācijas konvencijām.

### `$tn`

{/* generated:method:$tn — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Formatē skaitli ar `Intl.NumberFormat` aktīvajā lokalizācijā. Atslēga izvēlas nosauktu formātu no konfigurācijas.

{/* /generated:method:$tn */}

```typescript
// Inline options
const formattedNumber = $tn(1234567.89, { style: 'currency', currency: 'USD' })
// "$1,234,567.89"

// Named format (from nuxt.config i18n.numberFormats)
const price = $tn(1000, 'currency')
const priceDe = $tn(1000, 'currency', 'de')
const compact = $tn(1000, 'currency', { notation: 'compact' })
```

Nezināmas nosaukto formātu atslēgas atgriežas pie noklusējuma `Intl.NumberFormat` opcijām. Izstrādes režīmā (klients) tiek izsaukts `console.warn`, kad `missingWarn` ir iespējots (noklusējums).

**Konfigurācijas piemērs**:

```ts
export default defineNuxtConfig({
  i18n: {
    numberFormats: {
      en: {
        currency: { style: 'currency', currency: 'USD' },
        decimal: { style: 'decimal', minimumFractionDigits: 2, maximumFractionDigits: 2 },
      },
      de: {
        currency: { style: 'currency', currency: 'EUR' },
      },
    },
  },
})
```

**Lietošanas gadījumi**:

- Skaitļu formatēšana kā valūta, procenti vai decimāldaļas atbilstošā lokalizācijas formātā.
- Nosaukto formātu atkārtota izmantošana visā lietotnē (Vue I18n migrācijas paritāte).

### `$td`

{/* generated:method:$td — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Formatē datumu ar `Intl.DateTimeFormat` aktīvajā lokalizācijā. Atslēga izvēlas nosauktu formātu no konfigurācijas.

{/* /generated:method:$td */}

```typescript
const formattedDate = $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' })
// "Friday, September 1, 2023"

const short = $td(new Date(), 'short')
const longDe = $td(new Date(), 'long', 'de')
```

Nezināmas nosaukto formātu atslēgas atgriežas pie noklusējuma `Intl.DateTimeFormat` opcijām. Izstrādes režīmā (klients) tiek izsaukts `console.warn`, kad `missingWarn` ir iespējots (noklusējums).

**Konfigurācijas piemērs**:

```ts
export default defineNuxtConfig({
  i18n: {
    datetimeFormats: {
      en: {
        short: { year: 'numeric', month: 'short', day: 'numeric' },
        long: { year: 'numeric', month: 'long', day: 'numeric', weekday: 'long' },
      },
    },
  },
})
```

**Lietošanas gadījumi**:

- Datumu attēlošana formātā, kas atbilst lietotāja lokalizācijai.
- Īsu/garu/datuma-laika iepriekšstatītu iestatījumu koplietošana visā lietotnē.

{/* generated:method:$tdr — do not edit; run `pnpm run docs:generate` */}

```

Pārvieto uz citu maršrutu, saglabājot aktīvo lokalizāciju vai pārslēdzot uz `toLocale`.

{/* /generated:method:$switchRoute */}

**Piemēri**:

<CodeGroup>

```

## 🚦 Maršruta konfigurācija

Metodes maršruta uzvedības un piekļuves kontroles konfigurēšanai.

### `$defineI18nRoute`

{/* generated:method:$defineI18nRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Reģistrē pēc lapas noteiktu lokalizācijas konfigurāciju un tulkojumus no komponenta iekšpuses. Sapludina aktīvajā lokalizācijā un atkārtoti pielieto, kad mainās lokalizācija.

{/* /generated:method:$defineI18nRoute */}

> [!IMPORTANT]
> `$defineI18nRoute` sniedz **define spraudnis** un tas ir pieejams tikai uz `useNuxtApp()` — tas **nav** daļa no `useI18n()` atgriešanas objekta.
> Vienmēr destrukturē to no `useNuxtApp()` iekš `script setup`. Izsaucot `$defineI18nRoute(...)` kā tukšu globālo, SSR/prerenderēšanas laikā tiek izmests `"$defineI18nRoute is not defined"`.

**Parametri**:

- **locales**: `string[] | Record<string, Record<string, string>>` — Pieejamās lokalizācijas šim maršrutam.
- **localeRoutes**: `Record<string, string>` — Neobligāti. Pielāgoti maršruti konkrētām lokalizācijām.
- **disableMeta**: `boolean | string[]` — Neobligāti. Atspējo i18n meta tagus visām vai konkrētām lokalizācijām.

**Pamata piemērs**:

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr', 'de'],
  localeRoutes: {
    en: '/welcome',
    fr: '/bienvenue',
    de: '/willkommen',
  },
  disableMeta: false,
})
```

> 📖 **Detalizētiem lietošanas piemēriem, konfigurācijas formātiem un labākajām praksēm skati [Tulkojumu pēc komponentiem ceļvedi](/guides/per-component-translations).**

### `$setI18nRouteParams`

{/* generated:method:$setI18nRouteParams — do not edit; run `pnpm run docs:generate` */}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Iestata pašreizējā maršruta parametrus katrai lokalizācijai, lai dinamiskais segments varētu atšķirties atkarībā no valodas. Izsauc to SSR laikā, pirms tiek renderēta galva.

{/* /generated:method:$setI18nRouteParams */}

```typescript
// in pages/news/[id].vue
// for en/news/1-first-article
const { $switchLocaleRoute, $setI18nRouteParams, $defineI18nRoute } = useNuxtApp()
$defineI18nRoute({
  localeRoutes: {
    en: '/news/:id()',
    fr: '/nouvelles/:id()',
    de: '/Nachricht/:id()',
  },
})
const { data: news } = await useAsyncData(`news-${params.id}`, async () => {
  let response = await $fetch("/api/getNews", {
    query: {
      id: params.id,
    },
  });
  if (response?.localeSlugs) {
    response.localeSlugs = {
      en: {
        id: '1-first-article'
      }
      fr: {
        id: '1-premier-article'
      }
      de: {
        id: '1-erster-Artikel'
      }
    }
    $setI18nRouteParams(response?.localeSlugs);
  }
  return response;
});
$switchLocalePath('fr') // === 'fr/nouvelles/1-premier-article'
$switchLocalePath('de') // === 'de/Nachricht/1-erster-Artikel'
```

### `$has`

{/* generated:method:$has — do not edit; run `pnpm run docs:generate` */}

## 🧭 `useI18nLocale` kompozīts

Centralizētais kompozīts lokalizācijas stāvokļa pārvaldībai. Izmanto to, nevis tieši manipulē `useState('i18n-locale')` vai `useCookie('user-locale')`.

```typescript
const {
  setLocale, // (locale: string) => void — updates state + cookie
  getLocale, // () => string | null — from state or cookie
  getPreferredLocale, // () => string | null — validated against locales list
  getEffectiveLocale, // (route, getLocaleFromRoute) => string
  resolveInitialLocale, // (options) => string
  isValidLocale, // (locale) => boolean
  locale, // Ref<string | null> — reactive state
  localeCookie, // CookieRef — reactive cookie
  syncLocale, // (locale) => void — sync to cookie only
  validLocales, // string[] — list of valid locale codes
} = useI18nLocale()
```

### Galvenās metodes

| Metode                  | Apraksts                                                 |
| ----------------------- | ----------------------------------------------------------- |
| `setLocale(locale)`     | Iestata lokalizāciju gan `useState`, gan sīkdatnē atomāri.        |
| `getLocale()`           | Atgriež pašreizējo lokalizāciju no stāvokļa vai sīkdatnes.                 |
| `getPreferredLocale()`  | Atgriež lokalizāciju, kas validēta pret `locales` sarakstu, vai `null`.  |
| `isValidLocale(locale)` | Pārbauda, vai lokalizācijas kods ir konfigurētajā `locales` sarakstā. |
