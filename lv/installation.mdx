## Prasības

- **Node.js**: 18 vai jaunāka.
- **Nuxt**: 3.x vai 4.x.

Modulis atbalsta gan Nuxt 3 projekta izkārtojumu (`pages/**/*.vue`), gan Nuxt 4 izkārtojumu (`app/pages/**/*.vue`). Tulkojumi pēc konvencijas atrodas projekta saknē (`locales/`), pat ja tiek izmantota Nuxt 4 `app/` mape.

## Nuxt moduļa instalēšana

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Reģistrē to failā `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Skati [Ātro startu](/quickstart), lai iepazītos ar pilnu ceļvedi, vai [Konfigurācijas atsauci](/guides/configuration), lai uzzinātu par katru opciju.

## Projekta izkārtojums

Pēc noklusējuma modulis sagaida:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Saknes līmeņa faili būvēšanas laikā tiek sapludināti ar katru lapām specifisko failu. Lapām specifiskie faili tiek automātiski izveidoti, ja to trūkst, `nuxt dev` darbības laikā.

## Nuxt 4 izkārtojums

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Lai tulkojumus izvietotu blakus zem `app/`, iestati `translationDir: 'app/locales'`.

## Ekosistēmas paketes

| Pakete | Mērķis |
| --- | --- |
| [`@i18n-micro/vue`](/integrations/vue) | Vue 3 integrācija (atsevišķa, bez Nuxt). |
| [`@i18n-micro/react`](/integrations/react) | React integrācija. |
| [`@i18n-micro/preact`](/integrations/preact) | Preact integrācija. |
| [`@i18n-micro/solid`](/integrations/solid) | SolidJS integrācija. |
| [`@i18n-micro/astro`](/integrations/astro) | Astro integrācija. |
| [`@i18n-micro/node`](/integrations/nodejs) | Node.js servera puses ielādētājs. |
| [`@i18n-micro/types-generator`](/integrations/types-generator) | Ģenerē TypeScript tipus no tulkojumu failiem. |
| [`@i18n-micro/devtools-ui`](/integrations/devtools-ui) | Ietvaram neatkarīgs DevTools panelis. |

Koplietotās iekšējās paketes tiek ievilktas tranzitīvi.

## TypeScript

Modulis ģenerē vides tipus `useI18n`, `$t` un saistītajiem palīgiem, pamatojoties uz taviem noklusējuma lokalizācijas failiem. Tas ir iespējots pēc noklusējuma (`types: true`).

Stingrākai tulkojumu atslēgu tipizācijai skati [`@i18n-micro/types-generator`](/integrations/types-generator).
