## Prasības

- **Node.js**: 18 vai jaunāka.
- **Nuxt**: 3.x vai 4.x.

Modulis atbalsta gan Nuxt 3 projekta izkārtojumu (`pages/**/*.vue`), gan Nuxt 4 izkārtojumu (`app/pages/**/*.vue`). Tulkojumi pēc konvencijas atrodas projekta saknē (`locales/`), pat lietojot Nuxt 4 `app/` mapi.

## Instalējiet Nuxt moduli

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Reģistrējiet to failā `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Pilnu apskatu skatiet sadaļā [Ātrā uzsākšana](/quickstart) vai katru opciju sadaļā [Konfigurācijas atsauce](/guides/configuration).

## Projekta izkārtojums

Pēc noklusējuma modulis sagaida:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Saknes līmeņa faili būvēšanas laikā tiek sapludināti katrā lapas specifiskajā failā. Lapas specifiskie faili tiek automātiski izveidoti, ja tie trūkst, `nuxt dev` laikā.

## Nuxt 4 izkārtojums

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Lai tulkojumus izvietotu blakus zem `app/`, iestatiet `translationDir: 'app/locales'`.

## TypeScript

Modulis ģenerē apkārtējos (ambient) tipus `useI18n`, `$t` un saistītajiem palīgiem, balstoties uz jūsu noklusējuma lokāles failiem. Tas ir iespējots pēc noklusējuma (`types: true`).

Spēcīgākai tulkojumu atslēgu tipizēšanai skatiet [`@i18n-micro/types-generator`](/integrations/types-generator).
