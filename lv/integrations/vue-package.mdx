`@i18n-micro/vue` ir Vue 3 spraudnis ar Nuxt I18n Micro tulkošanas kodolu: reaktīvs `t()`, globāls `$t`, četri komponenti un neobligāts vue-router adapteris. Izmantojiet to Vite vai SSR Vue lietotnē, kas nav būvēta ar Nuxt. Instances modelis, maršrutētāja līgums un komponentu props ir kopīgi ar pārējām pakotnēm un aprakstīti sadaļā [Ietvari](/lv/integrations/overview).

## Instalēšana {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vue
```

```bash npm
npm install @i18n-micro/vue
```

```bash yarn
yarn add @i18n-micro/vue
```

</CodeGroup>

Vienādranga atkarības: `vue` `^3.3.0`; `vue-router` `^4.5.1 || ^5.0.0` (neobligāta, tikai `@i18n-micro/vue/router`). Publicētajiem tipiem vajadzīgs Vue 3.5.5 vai jaunāks ar `skipLibCheck: false`; ar `skipLibCheck: true`, kas ir ierastais veidnes iestatījums, kompilējas arī vecākas versijas.

## Iestatīšana {#setup}

```ts
// src/main.ts
import { createApp } from 'vue'
import { createI18n } from '@i18n-micro/vue'
import App from './App.vue'
import en from './locales/en.json'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales: [
    { code: 'en', iso: 'en-US', displayName: 'English' },
    { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
  ],
  defaultLocale: 'en',
})

createApp(App).use(i18n).mount('#app')
```

`locales` un `defaultLocale` ir obligāti funkcijai `useI18n()`: bez tiem tā izmet `I18nLocalesKey not provided`. Nododiet tos `createI18n` (kā iepriekš), `useI18n({ locales, defaultLocale })` vai caur `app.provide(I18nLocalesKey, …)` un `app.provide(I18nDefaultLocaleKey, …)`.

Spraudnis globāli reģistrē `I18nT`, `I18nLink`, `I18nGroup` un `I18nSwitcher` un pievieno veidnēm `$t`, `$ts`, `$tc`, `$tn`, `$td`, `$tdr`, `$has` un `$i18n`. Ārpus komponentiem instance ir `i18n.global`. Pārējās opcijas ir sadaļā [instance](/lv/integrations/overview#the-instance); `routeMessages` Vue nav pieejams, izmantojiet `addRouteTranslations`.

## Tulkošana {#translate}

```vue
<script setup lang="ts">
import { useI18n } from '@i18n-micro/vue'

const { t, tc, tn } = useI18n()
</script>

<template>
  <h1>{{ t('greeting', { name: 'Ada' }) }}</h1>
  <!-- Hello, Ada! -->
  <p>{{ tc('apples', 3) }}</p>
  <!-- 3 apples -->
  <p>{{ $t('nav.home') }} · {{ tn(1234.5) }}</p>
</template>
```

`useI18n()` atgriež tulkošanas metodes (`t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`), `locale` (rakstāms computed), `getLocale`, `getLocales`, `defaultLocale()`, `getLocaleName`, `localePath`, `localeRoute`, `switchLocale`, `setRoute`, `getRoute`, `addTranslations`, `addRouteTranslations`, `mergeTranslations`, `resolveTranslations`, `setTranslation`, `clearCache` un `instance`.

Papildu vārdnīcas var ielādēt jebkurā laikā; katrs komponents, kas tās lasa, tiek renderēts no jauna:

```ts
const { addTranslations, addRouteTranslations, setRoute } = useI18n()

addTranslations('de', (await import('./locales/de.json')).default)
addRouteTranslations('en', 'about', { title: 'About us' })
setRoute('about') // t('title') now reads the 'about' dictionary first
```

## Lokalizācijas pārslēgšana {#switch-locale}

```ts
const { locale, switchLocale } = useI18n()

locale.value = 'de' // only the locale
switchLocale('de') // the locale, then router.push to the localized current path
```

Ielādējiet lokalizācijas vārdnīcu pirms vai pēc pārslēgšanas; pārslēgšana neko neielādē.

`<I18nGroup>` savam slotam nodod `t` ar prefiksu. Atslēgām `<I18nT>` iekšienē vai vienkāršā `t()` prefikss netiek pievienots:

```vue
<I18nGroup prefix="profile" v-slot="{ t }">
  <h2>{{ t('title') }}</h2>
  <!-- profile.title -->
</I18nGroup>
```

## Maršrutēšana {#routing}

vue-router adapteris atrodas apakšceļā, lai galvenais ieejas punkts nekad neimportētu `vue-router`:

```ts
// src/main.ts
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import { createI18n } from '@i18n-micro/vue'
import { createVueRouterAdapter } from '@i18n-micro/vue/router'
import App from './App.vue'
import Home from './pages/Home.vue'
import About from './pages/About.vue'
import en from './locales/en.json'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English' },
  { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
]

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/:locale(de)?', component: Home },
    { path: '/:locale(de)?/about', component: About },
  ],
})

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales,
  defaultLocale: 'en',
  routingStrategy: createVueRouterAdapter(router, locales, 'en'),
})

createApp(App).use(router).use(i18n).mount('#app')
```

`createVueRouterAdapter(router, locales, defaultLocale)` pievieno prefiksu katrai lokalizācijai, izņemot noklusējuma (`/about`, `/de/about`), un renderē `<I18nLink>` kā `RouterLink`. Lokalizāciju no maršruta nolasiet paši, piemēram, `router.beforeEach`, un iestatiet `i18n.global.locale.value`. Adapteri var pievienot arī vēlāk ar `i18n.setRoutingStrategy(adapter)`; par pielāgotu adapteri skatiet [Maršrutētāja adapteris](/lv/integrations/overview#router-adapter).

## SSR {#ssr}

- Izveidojiet maršrutētāju, i18n instanci un lietotni renderēšanas funkcijā, kas tiek izsaukta katram pieprasījumam. Viena kopīga instance nopludinātu viena apmeklētāja lokalizāciju citam.
- Serverī izmantojiet `createMemoryHistory()`, ņemiet lokalizāciju no URL un ielādējiet tās vārdnīcu (un rezerves lokalizācijas vārdnīcu) pirms `renderToString`.
- Nosūtiet lokalizāciju klientam (piemēram, `window.__STATE__` skriptā) un izveidojiet klienta instanci ar to pašu `locale`, lai hidratācija sakristu.
- `<I18nSwitcher>` nolasa `window.location` tikai tad, kad nolaižamais saraksts ir atvērts, tāpēc tas renderējas serverī.

`packages/vue/playground` ir pilns `entry-server.ts` / `entry-client.ts` pāris.

## SEO galvene {#seo-head}

`useLocaleHead(options)` veido `lang`/`dir`, canonical, `hreflang` un `og:locale` tagus no lokalizācijām un maršrutētāja adaptera. Izsauciet `updateMeta()`, kad mainās maršruts, un nododiet `metaObject` savam galvenes pārvaldniekam:

```ts
import { watch } from 'vue'
import { useRoute } from 'vue-router'
import { useHead } from '@unhead/vue'
import { useLocaleHead } from '@i18n-micro/vue'

const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
watch(() => route.fullPath, () => updateMeta(), { immediate: true })
useHead(metaObject)
```

Opcijas: `baseUrl` (virkne vai funkcija), `addDirAttribute` (noklusējums `true`), `addSeoAttributes` (noklusējums `true`), `identifierAttribute` (noklusējums `'id'`), `hreflangBaseLanguage` (noklusējums `false`). Lokalizācijas ar `disabled: true` vai `seo: false` alternatīvo saiti nesaņem.
