`@i18n-micro/vitepress` pievieno VitePress vietnei izpildlaika vārdnīcas: `$t` un `<I18nT>` markdown failos, ceļu palīgfunkcijas un SEO tagus, veidots uz [`@i18n-micro/vue`](/lv/integrations/vue-package). Izmantojiet to, ja vienas un tās pašas lietotāja saskarnes virknes parādās daudzās lapās un nevēlaties tās dublēt katrai lokalizācijai. Lokalizācija seko pašas VitePress ceļu lokalizācijām (`/`, `/fr/`).

## Kad to izmantot {#when-to-use-it}

| Vajadzība | Risinājums |
|------|----------|
| Dublēti `.md`, URL prefiksi | VitePress `locales` |
| Izpildlaika `$t` / komponenti / ceļu sinhronizācija / SEO head | `@i18n-micro/vitepress` |
| Noklusējuma motīva saskarnes etiķetes (`docFooter`, meklēšanas saskarne) | Jūsu pašu `themeConfig` katrai lokalizācijai |

<Tip>

**Eksperimentu vide** — [`packages/vitepress/playground`](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/vitepress/playground) — `pnpm -C packages/vitepress/playground dev`

</Tip>

## Instalēšana {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vitepress
```

```bash npm
npm install @i18n-micro/vitepress
```

```bash yarn
yarn add @i18n-micro/vitepress
```

</CodeGroup>

Vienādranga atkarības: `vitepress` `>=1.0.0 || >=2.0.0-alpha.0`, `vue` `^3.3.0`. Node skripti izmanto `@i18n-micro/node`, kas tiek instalēts kopā ar pakotni un atkārtoti eksportēts caur `/node`. Publicētajiem tipiem ar `skipLibCheck: false` vajadzīgs Vue 3.5.5 vai jaunāks; ar `skipLibCheck: true`, kas ir ierastais veidnes iestatījums, kompilējas arī vecākas versijas.

## Iestatīšana {#setup}

```
locales/en.json
locales/fr.json
locales/pages/guide/demo/en.json   # optional page-scoped
locales/pages/guide/demo/fr.json
```

Lapu faili tiek piesaistīti maršrutu nosaukumiem tāpat kā Nuxt/Astro (`guide/demo` → `guide-demo`).

### 1. Konfigurācija — `@i18n-micro/vitepress/config` {#1-config-—-@i18n-micro/vitepress/config}

```ts
// .vitepress/config.mts
import { defineConfig } from 'vitepress'
import { withI18n, buildVitePressLocales } from '@i18n-micro/vitepress/config'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English', og: 'en_US' },
  { code: 'fr', iso: 'fr-FR', displayName: 'Français', og: 'fr_FR' },
]
const defaultLocale = 'en'

export default defineConfig(
  withI18n(
    {
      locales: buildVitePressLocales(locales, defaultLocale),
      // themeConfig.i18nRouting is injected automatically
    },
    {
      locale: defaultLocale,
      defaultLocale,
      locales,
      translationDir: 'locales',
      metaBaseUrl: 'https://example.com', // optional SEO head
    },
  ),
)
```

### 2. Motīvs — `@i18n-micro/vitepress/theme` {#2-theme-—-@i18n-micro/vitepress/theme}

```ts
// .vitepress/theme/index.ts
import DefaultTheme from 'vitepress/theme'
import { defineI18nTheme } from '@i18n-micro/vitepress/theme'

export default defineI18nTheme(DefaultTheme)
```

Sākotnējā lokalizācija tiek ņemta no pašreizējā ceļa pirms instalēšanas (nav noklusējuma lokalizācijas uzzibsnījuma uz `/fr/…`).

### Papildu: manuāls `createI18n` {#advanced-manual-createi18n}

Viena rūpnīca klientam: Vue spraudnis + ceļu metodes + `enhanceApp` (nav atsevišķu maršrutētāja palīgfunkciju eksportu).

```ts
import { createI18n, messagesFromGlob } from '@i18n-micro/vitepress'

const i18n = createI18n({
  locale: 'en',
  defaultLocale: 'en',
  locales: [{ code: 'en' }, { code: 'fr' }],
  messages: messagesFromGlob(import.meta.glob('../../locales/*.json', { eager: true })),
})

i18n.localizePath('/guide', 'fr')
// in theme enhanceApp:
i18n.enhanceApp({ app, router })
```

### Node skripti — `@i18n-micro/vitepress/node` {#node-scripts-—-@i18n-micro/vitepress/node}

Izmanto `@i18n-micro/node` `createI18n` / `loadTranslations` (tāpat kā Astro un CLI), pēc tam pievieno VitePress ceļu metodes ar `BaseI18n.extend`:

```ts
import { createI18n } from '@i18n-micro/vitepress/node'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  translationDir: './locales',
  locales: ['en', 'fr'],
  defaultLocale: 'en',
})
await i18n.loadTranslations()
i18n.t('cta.readMore')
i18n.localizePath('/guide', 'fr')
```

Tīrs Node bez ceļiem: `import { createI18n } from '@i18n-micro/node'`.

## Tulkojumi lapā {#in-page-translations}

Katrs VitePress markdown fails ir Vue SFC.

### Globālie komponenti un `$t` (ieteicams markdown failos) {#global-components-and-$t-recommended-in-markdown}

`createI18n` / `defineI18nTheme` instalē `@i18n-micro/vue`, kas reģistrē `I18nT` / `I18nLink` / `I18nGroup` / `I18nSwitcher` un `$t` / `$tc` / `$ts`.

```md
{{ $t('cta.readMore') }}

<I18nT keypath="greeting" :params="{ name: 'VitePress' }" />

<I18nLink to="/guide/demo">Demo</I18nLink>
```

### `useI18n` blokā `<script setup>` {#usei18n-in-<script-setup>}

```md
<script setup>
import { useI18n } from '@i18n-micro/vitepress'
const { t, tc, locale, localePath, switchLocale } = useI18n()
</script>

# {{ t('section.title') }}
```

## Valodu nolaižamā izvēlne {#language-dropdown}

Ja `locales` ir vairāk nekā viens ieraksts, VitePress rāda savu valodu izvēlni (`VPNavBarTranslations`). `withI18n` sasaista `themeConfig.i18nRouting`, lai globuss atbilstu `<I18nSwitcher>` / ceļu palīgfunkcijām.

Izmantojiet `<I18nSwitcher>` tikai pielāgotos izkārtojumos, nevis blakus noklusējuma globusam.

## Piezīmes par SSR {#ssr-notes}

- Lokalizācija priekšrenderēšanas laikā nāk no URL ceļa, nevis no sīkdatnēm.
- Motīva kods importēšanas laikā nedrīkst piekļūt `window`.
- Importējiet `defineI18nTheme` no `/theme`, lai Node konfigurācijas novērtēšana nekad neielādētu `virtual:i18n-micro/*`.

## API virsma {#api-surface}

| Eksports | Loma |
|--------|------|
| `createI18n` (`.`) | Klients: Vue spraudnis + ceļu metodes + `enhanceApp` |
| `getLocaleFromPath` / `stripSiteBase` / `routeNameFromPath` (`.`) | Manuāla lokalizācijas sinhronizācija, ja `syncWithVitePress: false` |
| `createI18n` (`/node`) | Node: `@i18n-micro/node` + ceļu metodes |
| `defineI18nTheme` (`/theme`) | Motīvs bez šablona koda |
| `withI18n` (`/config`) | Konfigurācija + virtuālie moduļi + neobligāts SEO |
| `buildVitePressLocales` (`/config`) | Izveido VitePress `locales` no `Locale[]` |
| `buildVitePressLocaleHead` (`/config`) | Manuāls SEO head (izmanto arī `metaBaseUrl`) |
| `messagesFromGlob` | Neobligāta glob → ziņojumu karte priekš `createI18n` |
| `useI18n` / `I18nT` / … | Atkārtoti eksportēti no `@i18n-micro/vue` |
| `BaseI18n.extend` (`@i18n-micro/core`) | Pievieno pielāgotas metodes jebkurai i18n instancei |

## OpenAPI stila vietnes (integrācijas fiksācijas) {#openapi-style-sites-integration-locks}

Regresijas testu kopa: `packages/vitepress/tests/integration-openapi.test.ts` (dziļi ceļi, `base=/openapi_docs/`, izslēgta sinhronizācija + manuāla lokalizācija, Node ģeneratori, SEO).

| Paraugs | Rīcība |
|---------|---------|
| Dziļas `/…/{spec}/{op}` lapas, tikai saknes saskarnes JSON | Dodiet priekšroku noklusējuma `syncWithVitePress: true` (saglabā `setRoute('index')`, ja nav lapas vārdnīcas) **vai** `syncWithVitePress: false` + `getLocaleFromPath` |
| Nekad neizsauciet `setRoute(deepName)` bez lapu vārdnīcām | Saknes saskarnes atslēgas pazūd līdz `setRoute('index')` |
| Ģeneratori / `getTranslation` | `createI18n` no `/node` + `await loadTranslations()` + `i18n.t(key)` (iestatiet `i18n.locale`) |
| Pielāgots canonical sadaļā `transformPageData` | Nododiet `meta: false` funkcijai `withI18n` (izvairieties no dubultiem tagiem) |
| Pakotnes SEO ar vietnes bāzi | `metaBaseUrl` + VitePress `base` → absolūtie URL ietver bāzi |
| Pārdēvēšana no vecākām pakotnes versijām | `withI18nMicro` → `withI18n`, `createVitePressI18n` → `createI18n`, `loadMessages` → node `createI18n` |
