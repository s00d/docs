`@i18n-micro/node` ir [runtime](/lv/integrations/runtime-package) instance kopā ar ielādētāju, kas nolasa tulkojumu mapi no diska. Izmantojiet to Express vai Fastify serverī, CLI, e-pasta vai PDF ģeneratorā vai jebkurā skriptā, kam vajadzīgi tie paši JSON faili, kas jūsu Nuxt lietotnei. Jūs ielādējat failus vienreiz un tulkojat katram pieprasījumam, nekoplietojot maināmu stāvokli starp pieprasījumiem.

## Instalēšana {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/node @i18n-micro/utils
```

```bash npm
npm install @i18n-micro/node @i18n-micro/utils
```

```bash yarn
yarn add @i18n-micro/node @i18n-micro/utils
```

</CodeGroup>

Nav vienādranga atkarību; Node.js `>=20`. `@i18n-micro/utils` ir vajadzīgs tikai tālāk aprakstītajai `Accept-Language` palīgfunkcijai.

## Iestatīšana {#setup}

Ielādētājs nolasa [Nuxt mapju struktūru](/lv/guide/translations): `locales/en.json` ir saknes vārdnīca, `locales/pages/blog/post/en.json` pieder maršrutam `blog-post`.

```ts
import { createI18n } from '@i18n-micro/node'

const i18n = createI18n({ locale: 'en', fallbackLocale: 'en', translationDir: './locales' })
await i18n.loadTranslations()

i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.t('title', undefined, undefined, 'blog-post') // from locales/pages/blog/post/en.json
```

Opcijas ir tās pašas, kas runtime (skatiet [instanci](/lv/integrations/overview#the-instance)), kā arī `translationDir` un `disablePageLocales` (uzskatīt `pages/**` failus par saknes vārdnīcām). `i18n.reload()` notīra visas vārdnīcas un nolasa mapi no jauna — failu novērotājam izstrādes režīmā.

`loadTranslations(dir, disablePageLocales?)` tiek eksportēts arī atsevišķi un atgriež `{ root, routes }`:

```ts
import { loadTranslations } from '@i18n-micro/node'

const { root, routes } = await loadTranslations('./locales')
// root:   { en: {...}, de: {...} }
// routes: { 'blog-post': { en: {...}, de: {...} } }
```

## Katram pieprasījumam {#per-request}

Instance glabā vienu lokalizāciju un vienu maršrutu. `i18n.locale` pārslēgšana koplietotā instancē pieprasījuma apstrādātājā rada sacensību ar vienlaicīgiem pieprasījumiem. `run` piešķir pieprasījumam savu instanci:

```ts
const i18n = createI18n({ locale: 'en', fallbackLocale: 'en', translationDir: './locales' })
await i18n.loadTranslations()

// `() => next()`: `run` hands its callback the fork, and Express reads an argument of `next` as an error
app.use((req, res, next) => i18n.run(pickLocale(req), () => next()))

app.get('/', (req, res) => {
  res.send(i18n.t('greeting')) // the request's locale, in everything it awaits
})
```

`run` iekšienē koplietotā instance nolasa un iestata pieprasījuma lokalizāciju un maršrutu (`AsyncLocalStorage`); atzarojums sākas pašreizējā maršrutā, un `i18n.setRoute(...)` atzvanīšanas funkcijā maina šī pieprasījuma maršrutu. Atzvanīšanas funkcija saņem arī pieprasījuma atzarojumu: tajā ierakstītās vārdnīcas paliek pieprasījumā, bet koplietotajā instancē ierakstītās vārdnīcas sasniedz visus.

Bez `AsyncLocalStorage` `i18n.fork(locale)` atgriež tāda paša veida instanci, ko nodot tālāk.

`reload()` nolasa direktoriju no jauna; vecās vārdnīcas atbild, līdz jaunās ir ielādētas.

## Lokalizācijas izvēle {#pick-the-locale}

`detectLocaleFromAcceptLanguage(header, locales)` ievēro `q` svarus un saskaņo `de-DE` ar `de` lokalizāciju (un `de` ar `de-DE`). Ja nekas neatbilst, tas atgriež `null`.

```ts
import express from 'express'
import { detectLocaleFromAcceptLanguage } from '@i18n-micro/utils/accept-language'

const app = express()

app.get('/hello', (req, res) => {
  const locale = detectLocaleFromAcceptLanguage(req.headers['accept-language'], locales) ?? 'en'
  const i18n = byLocale.get(locale)!
  res.json({ message: i18n.t('greeting', { name: 'Ada' }) })
})
```

URL prefiksam, sīkdatnei un galvenei kopā `resolveLocale({ defaultLocale, validLocales, url, cookie, acceptLanguage, autoDetectLanguage: true })` no `@i18n-micro/utils/resolve-locale` piemēro moduļa prioritāti: URL, tad sīkdatne, tad `Accept-Language`, tad noklusējums. Nederīgas vērtības tiek izlaistas.

Nuxt lietotnē šī pakotne serverī nav vajadzīga: izmantojiet moduļa [servera puses tulkojumus](/lv/guide/server-side-translations).

## API {#api}

| Eksports | Piezīmes |
| --- | --- |
| `createI18n(options)`, `I18n` | runtime instance + `translationDir`, `loadTranslations(dir?)`, `reload()` |
| `loadTranslations(dir, disablePageLocales?)` | `{ root, routes }` |
| `loadRootTranslations(dir, disablePageLocales?)` | tikai `root` |
| `FormatService`, `interpolate` | no kodola |
| Tipi: `I18nOptions`, `LoadedTranslations`, `Translations`, `Locale`, `PluralFunc`, `Params` | |

Instances metodes ir uzskaitītas lapā [Runtime](/lv/integrations/runtime-package#api). Pilni paraksti: [pakotnes atsauce](/lv/api/packages/node).
