`@i18n-micro/devtools-ui` ir tulkojumu redaktors no Nuxt DevTools cilnes, iepakots kā tīmekļa komponents ar Vite spraudni. Pievienojiet to Vue, React, Preact, Solid vai Astro projektam, lai izstrādes laikā pārlūkprogrammā pārlūkotu un rediģētu JSON failus savā tulkojumu mapē. Nuxt lietotnēs tas jau ir pieejams [Nuxt DevTools](/lv/guide/devtools).

![DevTools UI: failu koks un redaktors ar noklusējuma lokalizācijas tekstu blakus katrai atslēgai](/images/devtools/02-translations-editor-dark.webp)

## Instalēšana {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/devtools-ui
```

```bash npm
npm install -D @i18n-micro/devtools-ui
```

```bash yarn
yarn add -D @i18n-micro/devtools-ui
```

</CodeGroup>

Nav vienādranga atkarību.

## Iestatīšana {#setup}

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import { i18nDevToolsPlugin } from '@i18n-micro/devtools-ui/vite'

export default defineConfig({
  plugins: [i18nDevToolsPlugin({ translationDir: 'src/locales' })],
})
```

| Opcija | Noklusējums | Piezīmes |
| --- | --- | --- |
| `translationDir` | `'src/locales'` | Mape ar JSON failiem, relatīvi pret Vite sakni. |
| `base` | `'/__i18n_api'` | API galapunktu bāzes ceļš. |
| `injectButton` | `true` | Pievienot peldošu pogu lapām, kas tiek pasniegtas caur Vite `index.html` transformāciju. Astro šādu lapu nav: skatiet tālāk. |
| `defaultLocale` | pirmais lokalizācijas fails mapē `translationDir` | Atgriež `/config`. |
| `fallbackLocale` | `defaultLocale` | Atgriež `/config`. |

Spraudnis darbojas tikai izstrādes serverī (`apply: 'serve'`); produkcijas būvējumā no tā nekā nav. Poga atver `/__i18n_devtools.html`, kas nolasa un saglabā failus caur spraudņa galapunktiem:

| Galapunkts | Darbība |
| --- | --- |
| `GET <base>/translations` | katra vārdnīca mapē `translationDir`, pēc relatīvā ceļa |
| `POST <base>/save` | ķermenis `{ file, content }`; pārraksta esošu `.json` mapē `translationDir`, jebkam citam 403. Tas nekad neizveido failu |
| `GET <base>/config` | `{ defaultLocale, fallbackLocale, locales, translationDir }`; `locales` nāk no saknes failiem mapē `translationDir` |

Galapunkti atbild tikai devtools lapai: pieprasījums no citas izcelsmes vai resursdatora saņem `403`, un `/save` pieņem tikai `application/json` (`415`). Lapa uzzina par failu izmaiņām caur Vite HMR ligzdu.

Astro gadījumā spraudņa vietā pievienojiet integrāciju. Tā pievieno lietotni izstrādes rīkjoslai:

```ts
// astro.config.mjs
import { defineConfig } from 'astro/config'
import { i18nDevToolsIntegration } from '@i18n-micro/devtools-ui/vite'

export default defineConfig({
  integrations: [i18nDevToolsIntegration({ translationDir: 'src/locales' })],
})
```

Saglabāšana tikai ieraksta failu. Lietotne, kas importē JSON caur Vite, to saņem caur HMR; lai labojumi tiktu piemēroti tieši darbojošajai instancei, izmantojiet tiltu.

## Tilts uz darbojošos instanci {#bridge-to-a-live-instance}

Lai iegultu redaktoru savā lapā un labojumi uzreiz tiktu piemēroti darbojošajai instancei, izveidojiet tiltu no adaptera un nododiet to elementam `<i18n-devtools-ui>`:

```ts
import { createBridge, register } from '@i18n-micro/devtools-ui'
import { i18n, locales } from './i18n' // a runtime, React, Preact or Solid instance

register() // defines <i18n-devtools-ui> once

const bridge = createBridge({
  adapter: {
    getRouteCache: () => Object.fromEntries(i18n.storage.translations),
    addTranslations: (locale, content, merge) => i18n.addTranslations(locale, content, merge),
    addRouteTranslations: (locale, route, content, merge) => i18n.addRouteTranslations(locale, route, content, merge),
    subscribe: (cb) => i18n.subscribe(cb),
    getCurrentLocale: () => i18n.locale,
  },
  locales,
  defaultLocale: 'en',
  translationDir: 'src/locales',
})

const el = document.createElement('i18n-devtools-ui') as HTMLElement & { bridge: typeof bridge }
el.bridge = bridge
document.body.append(el)
```

`getRouteCache` jāatgriež vārdnīcas ar atslēgām `locale:route` (`en:index`, `en:blog-post`), kas ir tieši tas, ko glabā `i18n.storage.translations`. Vue instancei izmantojiet `i18n.global.getRouteCache()` un `i18n.global.subscribeToChanges(cb)`.

`saveTranslation` vispirms atjaunina instanci, pēc tam veic POST uz `<base>/save`. Ja galapunkta nav (statisks priekšskatījuma būvējums) vai izstrādes serveris nav sasniedzams, labojums tiek saglabāts `localStorage`; jebkura cita saglabāšanas kļūda atjauno iepriekšējo vārdnīcu un izmet izņēmumu.

## API {#api}

| Eksports | Ieejas punkts |
| --- | --- |
| `i18nDevToolsPlugin(options)`, `i18nDevToolsIntegration(options)` | `@i18n-micro/devtools-ui/vite` |
| `register()`, `I18nDevToolsElement` | `@i18n-micro/devtools-ui` |
| `createBridge(options)`, tipi `BridgeAdapter`, `CreateBridgeOptions` | `@i18n-micro/devtools-ui` (arī `/bridge/create`) |
| tips `I18nDevToolsBridge` | `@i18n-micro/devtools-ui` (arī `/bridge`) |
| `createRpcClient`, `setupRpcHost` | `@i18n-micro/devtools-ui` |

Pilnas signatūras: [pakotnes atsauce](/lv/api/packages/devtools-ui).
