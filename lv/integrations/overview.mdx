# Integrācijas

`@i18n-micro` pakotnes ir vieglas, ietvaram specifiskas Nuxt I18n Micro versijas, kas paredzētas integrācijai dažādos ietvaros un vidēs. Šīs pakotnes nodrošina galveno internacionalizācijas funkcionalitāti ar minimālu ietekmi, koncentrējoties uz būtiskām tulkošanas funkcijām un pamata komponentiem.

## Pārskats

Šīs integrācijas pakotnes ir **miniatūras versijas** pilnajam Nuxt I18n Micro modulim, saturot tikai internacionalizācijai nepieciešamo pamata funkcionalitāti:

- **Pamata tulkošanas funkcijas** — pamata tulkošanas metodes, daudzskaitļa formas un formatēšana
- **Būtiski komponenti** — neliels UI komponentu komplekts izplatītiem i18n uzdevumiem
- **Maršrutētāja adaptera modelis** — elastīga maršrutēšanas integrācija caur adaptera abstrakciju
- **TypeScript atbalsts** — pilnas tipu definīcijas drošai izstrādei

Atšķirībā no pilnā Nuxt moduļa, šīs pakotnes:

- Neietver ietvaram specifisku maršrutēšanas loģiku
- Prasa jums realizēt maršrutētāja adapteri maršrutēšanas funkcijām
- Koncentrējas uz tulkošanas funkcionalitāti, nevis ietvara integrāciju
- Ir izstrādātas tā, lai būtu vieglas un no ietvara neatkarīgas, kur iespējams

## Pamata komponenti

Visas ietvaru pakotnes iekļauj šādus būtiskos komponentus:

### `<I18nT>`

Tulkošanas komponents, kas renderē tulkoto tekstu ar atbalstu:

- **Parametru interpolācijai** — aizvieto vietturus ar dinamiskām vērtībām
- **Daudzskaitļa formām** — automātiska daudzskaitļa formas izvēle, balstoties uz skaitu
- **Skaitļu formatēšanai** — formatē skaitļus atbilstoši lokālei
- **Datumu formatēšanai** — formatē datumus un relatīvos laikus
- **HTML renderēšanai** — izvēles HTML satura renderēšana
- **Noklusējuma vērtībām** — rezerves teksts, kad tulkojums trūkst

**Piemērs:**

```vue
<!-- Vue -->
<I18nT keypath="greeting" :params="{ name: 'World' }" />
```

```tsx
// React
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```tsx
// Solid
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```astro
<!-- Astro -->
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

### `<I18nLink>`

Lokalizēta saites komponents, kas automātiski apstrādā lokāles priedēkļus URL. Iespējas:

- **Automātiska ceļa lokalizēšana** — pievieno/noņem lokāles priedēkļus, balstoties uz maršrutēšanas stratēģiju
- **Aktīvā stāvokļa noteikšana** — izceļ pašreizējo maršrutu
- **Ārējo saišu atbalsts** — automātiski nosaka un apstrādā ārējos URL
- **Maršrutētāja integrācija** — izmanto maršrutētāja adaptera saites komponentu, kad tas ir pieejams
- **Pielāgota stilēšana** — atbalsta aktīvos un peles pārvietošanas stāvokļus

**Piemērs:**

```vue
<!-- Vue -->
<I18nLink to="/about" active-class="active">
  About Us
</I18nLink>
```

```tsx
// React
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```tsx
// Solid
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```astro
<!-- Astro -->
<I18nLink href="/about" class="nav-link">
  About Us
</I18nLink>
```

### `<I18nSwitcher>`

Valodas pārslēdzēja komponents, kas nodrošina nolaižamo vai saraksta saskarni lokāļu maiņai. Iespējas:

- **Automātisks lokāļu saraksts** — ģenerē opcijas no konfigurētajām lokālēm
- **Pašreizējās lokāles izcelšana** — vizuāli norāda aktīvo valodu
- **Pielāgotas etiķetes** — atbalsta pielāgotus attēlojamos nosaukumus katrai lokālei
- **Maršrutētāja integrācija** — automātiski pārvietojas uz lokalizētiem ceļiem
- **Piekļūstamība** — pareizi ARIA atribūti un tastatūras navigācija

**Piemērs:**

```vue
<!-- Vue -->
<I18nSwitcher />
```

```tsx
// React
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```tsx
// Solid
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```astro
<!-- Astro -->
<I18nSwitcher />
```

### `<I18nGroup>`

Komponents tulkojumu grupēšanai ar kopīgu priedēkli, noderīgs tulkojumu organizēšanai pēc lapas vai funkcijas. Iespējas:

- **Priedēkļa mērogošana** — automātiski pievieno priedēkli visām grupā esošajām tulkojumu atslēgām
- **Ligzdotas grupas** — atbalsta ligzdotas tulkojumu grupas
- **Tīra organizācija** — palīdz uzturēt organizētas tulkojumu struktūras

**Piemērs:**

```vue
<!-- Vue -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

```tsx
// React
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```tsx
// Solid
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```astro
<!-- Astro -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

## Koplietotās `createI18n` opcijas \{#create-i18n-options\}

Katra ietvara pakotne tiek izveidota tāpat — tikai opciju tips ir nosaukts pēc
ietvara (`ReactI18nOptions`, `SolidI18nOptions` un tā tālāk). Pašas opcijas
ir identiskas:

| Īpašība         | Tips                                                       | Obligāti | Noklusējums          | Apraksts                                    |
| ---------------- | ---------------------------------------------------------- | -------- | ---------------- | ---------------------------------------------- |
| `locale`         | `string`                                                   | ✅       | -                | Pašreizējais lokāles kods (piemēram, `'en'`)             |
| `fallbackLocale` | `string`                                                   | ❌       | Tāds pats kā `locale` | Rezerves lokāle, kad tulkojums trūkst    |
| `messages`       | `Record<string, Translations>`                             | ❌       | `\{\}`             | Sākotnējie tulkojumu ziņojumi                   |
| `plural`         | `PluralFunc`                                               | ❌       | `defaultPlural`  | Pielāgota daudzskaitļa formu funkcija                  |
| `missingWarn`    | `boolean`                                                  | ❌       | `true`           | Rādīt konsoles brīdinājumus par trūkstošiem tulkojumiem |
| `missingHandler` | `(locale: string, key: string, routeName: string) => void` | ❌       | -                | Pielāgots apstrādātājs trūkstošiem tulkojumiem        |

Viss ārpus šiem ir ietvaram specifisks un dokumentēts šīs pakotnes lapā.

## Maršrutētāja adaptera abstrakcija

Visas ietvara pakotnes izmanto **maršrutētāja adaptera modeli**, lai atsaistītu i18n funkcionalitāti no konkrētām maršrutētāja realizācijām. Šis dizains ļauj:

- **Elastību** — izmantot jebkuru maršrutētāja bibliotēku vai maršrutētāju vispār neizmantot
- **Neatkarību no ietvara** — saglabāt maršrutēšanas loģiku savā lietotnē, nevis i18n pakotnē
- **Vieglu kodolu** — i18n pakotne paliek maza un fokusēta

### Maršrutētāja adaptera ieviešana

Lai izmantotu maršrutēšanas funkcijas, jums jārealizē `I18nRoutingStrategy` interfeiss:

```typescript
interface I18nRoutingStrategy {
  getCurrentPath: () => string
  linkComponent?: Component
  push: (target: { path: string }) => void
  replace: (target: { path: string }) => void
  resolvePath?: (to: string | { path?: string }, locale: string) => string | { path?: string }
  getRoute?: () => { fullPath: string; query: Record<string, unknown> }
}
```

Katras pakotnes dokumentācija iekļauj pilnīgus adapteru realizēšanas piemērus populāriem maršrutētājiem:

- **Vue**: Vue Router adaptera piemērs
- **React**: React Router adaptera piemērs
- **Solid**: Solid Router adaptera piemērs
- **Astro**: uz failiem balstīts maršrutēšanas adaptera piemērs

## Pamata funkcijas

Visas pakotnes koplieto šīs pamata funkcijas:

### Tulkošanas metodes

- `t()` — pamata tulkošana ar parametru interpolāciju
- `ts()` — tulkošana, kas vienmēr atgriež virkni
- `tc()` — tulkošana ar daudzskaitļa formu apzināšanu
- `tn()` — skaitļu formatēšana
- `td()` — datumu formatēšana
- `tdr()` — relatīvās laika formatēšana
- `has()` — pārbaudīt, vai tulkojuma atslēga eksistē

### Lokāles pārvaldība

- **Lokāles pārslēgšana** — programmatiski mainīt pašreizējo lokāli
- **Rezerves lokāle** — automātiska rezerves opcija, kad tulkojums trūkst
- **Maršrutam specifiski tulkojumi** — lapas līmeņa tulkojumu organizācija
- **Tulkojumu kešošana** — inteliģenta kešošana veiktspējai

### TypeScript atbalsts

Visas pakotnes nodrošina:

- Pilnas TypeScript definīcijas
- Tipam drošas tulkojumu atslēgas (ar tipu ģeneratoru)
- IntelliSense atbalstu IDE
- Kompilēšanas laika kļūdu pārbaudi

## Darba sākšana

1. **Izvēlieties savu pakotni** — atlasiet pakotni savam ietvaram
2. **Instalējiet pakotni** — izmantojiet savu vēlamo pakotņu pārvaldnieku
