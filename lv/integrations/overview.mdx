`@i18n-micro/*` pakotnes ienes Nuxt I18n Micro tulkošanas kodolu Vue, React, Preact, Solid, Astro, VitePress un vienkāršā JavaScript. Izmantojiet tās, ja jūsu lietotne nav Nuxt lietotne vai ja skriptam vai serverim ārpus Nuxt vajag tos pašus tulkojumu failus. Visām pakotnēm ir kopīgs viens instances modelis, viens maršrutētāja adaptera līgums un tās pašas četras komponentes, kas vienreiz aprakstītas šajā lapā.

## Instance {#the-instance}

`createI18n(options)` atgriež vienu instanci, kas satur vārdnīcas, pašreizējo lokāli un pašreizējo maršrutu. Opcijas ir vienādas katrā pakotnē:

| Opcija | Tips | Noklusējums | Piezīmes |
| --- | --- | --- | --- |
| `locale` | `string` | obligāts | Aktīvā lokāle. |
| `fallbackLocale` | `string` | `locale` | Tiek meklēta, ja atslēgas trūkst `locale`. |
| `messages` | `Record<locale, Translations>` | `{}` | Saknes vārdnīcas (`'index'` maršruts). |
| `routeMessages` | `Record<route, Record<locale, Translations>>` | `{}` | Maršrutu vārdnīcas. Tikai Runtime, React, Preact, Node un VitePress. |
| `plural` | `PluralFunc` | `defaultPlural` | Pielāgots daudzskaitļa noteikums. |
| `missingWarn` | `boolean` | `true` | Tikai izstrādē: `console.warn` pārlūkā par trūkstošu atslēgu. |
| `missingHandler` | `(locale, key, routeName) => void` | — | Tiek izsaukts brīdinājuma vietā. |
| `numberFormats` | `Record<locale, Record<name, Intl.NumberFormatOptions>>` | — | Nosaukti formāti: `tn(9.5, 'currency')`. |
| `datetimeFormats` | `Record<locale, Record<name, Intl.DateTimeFormatOptions>>` | — | Nosaukti formāti: `td(date, 'short')`. |
| `timeZone` | `string` | izpildvides zona | IANA zona `td` datumiem; tā neietekmē `tdr`. Iestatiet to, lai serveris un pārlūks renderētu vienu datumu. |
| `now` | `() => number` | `Date.now` | `tdr` pulkstenis. Nododiet hidratācijai servera laiku, lai abi renderētu vienu tekstu. |
| `localeIso` | `Record<code, string>` | — | BCP 47 tags, ko izmanto daudzskaitļa noteikumiem (`ua` → `uk-UA`). React, Preact un Solid to ņem no `iso` nodrošinātāja `locales`. |

Vārdnīcas atrodas `i18n.storage.translations` — `Map` ar atslēgām `locale:route` (`en:index`, `en:about`).

Atslēga tiek meklēta pašreizējā maršruta vārdnīcā, tad saknes vārdnīcā, vispirms `locale`, tad `fallbackLocale`. Trūkstoša atslēga atgriež pašu atslēgu (vai nodoto `defaultValue`).

```ts
i18n.addTranslations('en', { nav: { home: 'Home' } }) // root, deep-merged
i18n.addRouteTranslations('en', 'about', { title: 'About us' }) // route chunk
i18n.addTranslations('en', { nav: { home: 'Start' } }, false) // replace instead of merge
i18n.setRoute('about')
i18n.t('title') // 'About us'
i18n.t('nav.home') // 'Start' (root key, still visible on the route)
```

### Tulkošana un formatēšana {#translate-and-format}

| Metode | Atgriež |
| --- | --- |
| `t(key, params?, defaultValue?, routeName?)` | Vērtību (virkne, skaitlis, objekts) ar interpolētiem `{param}`. |
| `ts(...)` | Tas pats, kas `t`, kā virkni. |
| `tc(key, count \| params, defaultValue?)` | Daudzskaitļa formu. |
| `tn(value, options \| name)` | `Intl.NumberFormat` aktīvajā lokālē. |
| `td(value, options \| name)` | `Intl.DateTimeFormat`. |
| `tdr(value, options?)` | Relatīvo laiku (`3 days ago`). |
| `has(key, routeName?)` | `true`, ja aktīvajai lokālei ir atslēga (maršruta vai saknes vārdnīcā; rezerves lokāle netiek pārbaudīta). |

`defaultPlural` sadala vērtību pēc `|` un izvēlas formu ar indeksu `count`, ierobežotu līdz pēdējai; negatīvs, daļskaitlis vai `NaN` skaits izvēlas pēdējo formu.

Pielāgots `plural` saņem `(key, count, params, locale, getter)`. Nolasiet vērtību caur `getter(key)`; nesadaliet atslēgu:

```ts
import type { PluralFunc } from '@i18n-micro/vue'

const plural: PluralFunc = (key, count, params, _locale, getter) => {
  const value = getter(key)
  if (typeof value !== 'string') return null
  const forms = value.split('|').map((form) => form.trim())
  return (count === 1 ? forms[0] : forms[1] ?? forms[0])!.replace('{count}', String(count))
}
```

## Maršrutētāja adapteris {#router-adapter}

SPA pakotnes nav atkarīgas no maršrutētāja. Maršrutētāja adapteris (`I18nRoutingStrategy`) norāda tām, kā nolasīt pašreizējo ceļu, navigēt un izveidot lokalizētu ceļu. Iebūvētie adapteri pievieno prefiksu katrai lokālei, izņemot `defaultLocale` (`/about`, `/de/about`).

| Loceklis | Obligāts | Izmanto |
| --- | --- | --- |
| `getCurrentPath(): string` | jā | aktīvās saites pārbaude (pēc lapas, vaicājums un hash netiek ņemti vērā), `switchLocale` (tos saglabā) |
| `push({ path }): void` | jā | `switchLocale`, `<I18nLink>` bez `linkComponent`, `<I18nSwitcher>` |
| `replace({ path }): void` | jā | — |
| `resolvePath(to, locale)` | nē | `localePath`, `localeRoute`, `<I18nLink>`; bez tā ceļi tiek atgriezti nemainīti |
| `linkComponent` | nē | `<I18nLink>` to renderē (piem., `RouterLink`) `<a>` vietā |
| `getRoute()` | nē | `{ fullPath, query }` SEO palīgfunkcijām |

`push` un `replace` ir obligāti Vue, React, Preact un Solid. Astro ir savs servera puses adapteris ar neobligātiem `push`/`replace` (skatiet [Astro](/lv/integrations/astro-package#router-adapter)).

Minimāls adapteris jebkuram uz vēsturi balstītam maršrutētājam:

```ts
import type { I18nRoutingStrategy } from '@i18n-micro/react'

const locales = ['en', 'de']
const stripLocale = (path: string) => path.replace(/^\/(en|de)(?=\/|$)/, '') || '/'

export const historyAdapter: I18nRoutingStrategy = {
  getCurrentPath: () => window.location.pathname + window.location.search + window.location.hash,
  push: ({ path }) => window.history.pushState({}, '', path),
  replace: ({ path }) => window.history.replaceState({}, '', path),
  resolvePath: (to, locale) => {
    const path = stripLocale(typeof to === 'string' ? to : to.path || '/')
    return locale === 'en' ? path : `/${locale}${path === '/' ? '' : path}`
  },
}
```

## Komponentes {#components}

Vue, React, Preact un Solid piedāvā tās pašas četras komponentes. To props sakrīt; React, Preact un Solid nodod citus props saknes elementam.

### `<I18nT>` {#&lt;i18nt&gt;}

| Prop | Tips | Piezīmes |
| --- | --- | --- |
| `keypath` | `string` | obligāts |
| `params` | `object` | interpolācijas vērtības |
| `plural` | `number \| string` | renderē `tc(keypath, count)` |
| `number` | `number \| string` | nodod `tn(number)` kā `{number}` |
| `date` | `Date \| string \| number` | nodod `td(date)` kā `{date}` |
| `relativeDate` | `Date \| string \| number` | nodod `tdr(relativeDate)` kā `{relativeDate}` |
| `tag` | `string` | ietinošais elements, noklusējums `span` |
| `html` | `boolean` | renderē tulkojumu kā HTML; tam jābūt uzticamam, parametri tiek ekranēti |
| `defaultValue` | `string` | aizstāj trūkstošu atslēgu un tiek renderēts bez ietinēja, ja `hideIfEmpty` paslēpj tukšu vērtību |
| `hideIfEmpty` | `boolean` | tukšam tulkojumam neko nerenderē |
| `customPluralRule` | `PluralFunc` | daudzskaitļa noteikums šim elementam |

Tiek piemērots tikai viens formatēšanas prop, pārbaudot šādā secībā: `number`, `date`, `relativeDate`, `plural`.

#### Bagātināts teksts {#rich-text}

`{placeholder}` var saturēt elementu. Vue tas ir nosaukts slots; React, Preact un Solid `components` prop pēc nosaukuma dod elementus vai funkcijas, kas tos atgriež. Jebkurā gadījumā tas pārspēj tāda paša nosaukuma parametru, darbojas katrā zarā un iztur lokāli, kas pārkārto vietturus.

```tsx
// { "terms": "I accept the {link} of {company}" }
<I18nT keypath="terms" params={{ company: 'ACME' }} components={{ link: <a href="/terms">terms</a> }} />
```

Solid nododiet funkciju, ja vietturis atkārtojas: viens mezgls var atrasties tikai vienā vietā. `children` aizstāj tekstu; kā funkcija tie saņem `{ translation }`, līdzīgi kā Vue noklusējuma slots. `html` ignorē visu iepriekšminēto.

### `<I18nLink>` {#&lt;i18nlink&gt;}

| Prop | Tips | Piezīmes |
| --- | --- | --- |
| `to` | `string \| { path }` | lokalizēts ar adaptera `resolvePath` |
| `activeStyle` | stila objekts | apvienots virs `style` pašreizējā lapā; React, Preact un Solid to piemēro arī augstākai sadaļai |
| `localeRoute` | funkcija | pārraksta `resolvePath` šai saitei |

Ārējie URL (`https://`, `mailto:`, `tel:`) tiek renderēti kā `<a target="_blank" rel="noopener noreferrer">`; jūsu paša `target` vai `rel` uzvar. `onClick` vienmēr izpildās. Modificēts klikšķis, cita peles poga vai `target` paliek pārlūka ziņā.

### `<I18nSwitcher>` {#&lt;i18nswitcher&gt;}

Iespējoto lokāļu nolaižamais saraksts (`disabled: true` lokāles ir paslēptas) ar iekļautiem noklusējuma stiliem. Tā vienumi ir saites ar `lang`, `hreflang` un `dir` no lokāles. Pēc noklusējuma klikšķis uz vienuma iestata lokāli un izsauc adaptera `push` ar lokalizētu pašreizējo ceļu; `switchLocale` prop aizstāj šo darbību. Ar `localeRoute` un bez maršrutētāja pārlūks seko saitei. Escape vai klikšķis ārpusē to aizver.

| Prop | Piezīmes |
| --- | --- |
| `locales`, `currentLocale`, `getLocaleName` | pārraksta nodrošinātās vērtības |
| `switchLocale(code)` | aizstāj iebūvēto pārslēgšanu |
| `localeRoute` | aizstāj `resolvePath` |
| `customLabels` | `{ de: 'DE' }` |
| `customWrapperStyle`, `customButtonStyle`, `customDropdownStyle`, `customItemStyle`, `customLinkStyle`, `customActiveLinkStyle`, `customDisabledLinkStyle`, `customIconStyle` | stilu pārrakstījumi |

### `<I18nGroup>` {#&lt;i18ngroup&gt;}

`<div class="i18n-group">`, kas nodod saviem bērniem `t` ar prefiksu. Tas **nepievieno** prefiksu `<I18nT>` vai `t()` izsaukumiem sevī; prefikss ir tikai tam `t`, ko tas nodod tālāk.

| Prop | Piezīmes |
| --- | --- |
| `prefix` | obligāts, piem., `'profile'` |
| `groupClass` | papildu klase ietinējam |

`t` ar prefiksu tiek nodots caur scoped slot Vue (`v-slot="{ t }"`) un render-prop bērnu React, Preact un Solid (`{({ t }) => …}`).

## Tipizētas atslēgas {#typed-keys}

`t()` pieņem jebkuru virkni. Lai iegūtu automātisko pabeigšanu savām atslēgām, ģenerējiet deklarāciju ar [tipu ģeneratoru](/lv/integrations/types-generator). Atslēgas tiek ieteiktas, nevis piespiestas, un parametri nav tipizēti.

## Salīdzinājumā ar Nuxt moduli {#compared-with-the-nuxt-module}

Pakotnēm nav uz failiem balstītas maršrutēšanas, servera starpprogrammatūras un tulkojumu ielādētāja: jūs izlemjat, kad ielādēt JSON (`import`, `fetch` vai `@i18n-micro/node` serverī) un kuru maršrutētāja adapteri izmantot. Lokāles noteikšana, SEO meta un maršrutu ģenerēšana ir Nuxt funkcijas; Astro ir sava starpprogrammatūra noteikšanai un `useLocaleHead` SEO.
