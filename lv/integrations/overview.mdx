# Integrācijas

`@i18n-micro` paketes ir vieglas, ietvaram specifiskas Nuxt I18n Micro versijas, kas izstrādātas integrācijai dažādos ietvaros un vidēs. Šīs paketes nodrošina galveno internacionalizācijas funkcionalitāti ar minimālu nospiedumu, koncentrējoties uz būtiskām tulkošanas funkcijām un pamata komponentiem.

## Pārskats

Šīs integrācijas paketes ir **pilnās Nuxt I18n Micro moduļa miniatūras versijas**, kas satur tikai internacionalizācijai nepieciešamo būtisko funkcionalitāti:

- **Galvenās tulkošanas funkcijas** — pamata tulkošanas metodes, daudzskaitlis un formatēšana.
- **Būtiskie komponenti** — neliels UI komponentu komplekts izplatītiem i18n uzdevumiem.
- **Maršrutētāja adaptera modelis** — elastīga maršrutēšanas integrācija caur adaptera abstrakciju.
- **TypeScript atbalsts** — pilnas tipu definīcijas tipa drošai izstrādei.

Atšķirībā no pilnā Nuxt moduļa, šīs paketes:

- Neietver ietvaram specifisku maršrutēšanas loģiku.
- Prasa tev ieviest maršrutētāja adapteri maršrutēšanas funkcijām.
- Koncentrējas uz tulkošanas funkcionalitāti, nevis ietvara integrāciju.
- Ir izstrādātas, lai būtu vieglas un pēc iespējas neatkarīgas no ietvara.

## Galvenie komponenti

Visas ietvara paketes ietver šādus būtiskus komponentus:

### `<I18nT>`

Tulkošanas komponents, kas renderē tulkoto tekstu ar atbalstu:

- **Parametru interpolācija** — aizvieto vietturus ar dinamiskām vērtībām.
- **Daudzskaitlis** — automātiska daudzskaitļa formas izvēle, pamatojoties uz skaitu.
- **Skaitļu formatēšana** — formatē skaitļus atbilstoši lokalizācijai.
- **Datuma formatēšana** — formatē datumus un relatīvos laikus.
- **HTML renderēšana** — neobligāta HTML satura renderēšana.
- **Noklusējuma vērtības** — atkāpšanās teksts, kad trūkst tulkojuma.

**Piemērs:**

```vue
<!-- Vue -->
<I18nT keypath="greeting" :params="{ name: 'World' }" />
```

```tsx
// React
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```tsx
// Solid
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```astro
<!-- Astro -->
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

### `<I18nLink>`

Lokalizēts saites komponents, kas automātiski apstrādā lokalizācijas prefiksus URL. Funkcijas:

- **Automātiska ceļa lokalizācija** — pievieno/noņem lokalizācijas prefiksus, pamatojoties uz maršrutēšanas stratēģiju.
- **Aktīvā stāvokļa noteikšana** — izceļ pašreizējo maršrutu.
- **Ārējo saišu atbalsts** — automātiski atklāj un apstrādā ārējos URL.
- **Maršrutētāja integrācija** — izmanto maršrutētāja adaptera saites komponentu, kad tas ir pieejams.
- **Pielāgota stilizācija** — atbalsta aktīvo un peldēšanas stāvokli.

**Piemērs:**

```vue
<!-- Vue -->
<I18nLink to="/about" active-class="active">
  About Us
</I18nLink>
```

```tsx
// React
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```tsx
// Solid
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```astro
<!-- Astro -->
<I18nLink href="/about" class="nav-link">
  About Us
</I18nLink>
```

### `<I18nSwitcher>`

Valodas pārslēdzēja komponents, kas nodrošina nolaižamā saraksta vai saraksta saskarni lokalizāciju maiņai. Funkcijas:

- **Automātisks lokalizāciju saraksts** — ģenerē opcijas no konfigurētajām lokalizācijām.
- **Pašreizējās lokalizācijas izcelšana** — vizuāli norāda aktīvo valodu.
- **Pielāgoti uzraksti** — atbalsts pielāgotiem attēlojamiem nosaukumiem katrai lokalizācijai.
- **Maršrutētāja integrācija** — automātiski navigē uz lokalizētiem ceļiem.
- **Pieejamība** — pareizi ARIA atribūti un tastatūras navigācija.

**Piemērs:**

```vue
<!-- Vue -->
<I18nSwitcher />
```

```tsx
// React
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```tsx
// Solid
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```astro
<!-- Astro -->
<I18nSwitcher />
```

### `<I18nGroup>`

Komponents tulkojumu grupēšanai ar kopīgu prefiksu, noderīgs tulkojumu organizēšanai pēc lapas vai funkcijas. Funkcijas:

- **Prefiksa tvērums** — automātiski pievieno prefiksu visām tulkojumu atslēgām grupas iekšpusē.
- **Ligzdotas grupas** — atbalsts ligzdotām tulkojumu grupām.
- **Tīra organizācija** — palīdz uzturēt sakārtotas tulkojumu struktūras.

**Piemērs:**

```vue
<!-- Vue -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

```tsx
// React
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```tsx
// Solid
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```astro
<!-- Astro -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

## Koplietotās `createI18n` opcijas \{#create-i18n-options\}

Katra ietvara pakete tiek izveidota tāpat — atšķiras tikai opciju tipa nosaukums, kas nosaukts pēc ietvara (`ReactI18nOptions`, `SolidI18nOptions` un tā tālāk). Pašas opcijas ir identiskas:

| Īpašība         | Tips                                                       | Obligāta | Noklusējums          | Apraksts                                    |
| ---------------- | ---------------------------------------------------------- | -------- | ---------------- | ---------------------------------------------- |
| `locale`         | `string`                                                   | ✅       | -                | Pašreizējais lokalizācijas kods (piemēram, `'en'`).             |
| `fallbackLocale` | `string`                                                   | ❌       | Tas pats, kas `locale`. | Atkāpšanās lokalizācija, kad trūkst tulkojuma.    |
| `messages`       | `Record<string, Translations>`                             | ❌       | `\{\}`             | Sākotnējie tulkojumu ziņojumi.                   |
| `plural`         | `PluralFunc`                                               | ❌       | `defaultPlural`  | Pielāgota daudzskaitļa funkcija.                  |
| `missingWarn`    | `boolean`                                                  | ❌       | `true`           | Rāda konsoles brīdinājumus par trūkstošiem tulkojumiem. |
| `missingHandler` | `(locale: string, key: string, routeName: string) => void` | ❌       | -                | Pielāgots apstrādātājs trūkstošiem tulkojumiem.        |

Viss papildus tam ir ietvaram specifisks un dokumentēts šīs paketes lapā.

## Maršrutētāja adaptera abstrakcija

Visas ietvara paketes izmanto **maršrutētāja adaptera modeli**, lai atsaistītu i18n funkcionalitāti no specifiskām maršrutētāja implementācijām. Šis dizains ļauj:

- **Elastību** — izmantot jebkuru maršrutētāja bibliotēku vai vispār bez maršrutētāja.
- **Ietvara neatkarību** — paturēt maršrutēšanas loģiku tavā lietotnē, nevis i18n paketē.
- **Vieglu kodolu** — i18n pakete paliek maza un mērķtiecīga.

### Maršrutētāja adaptera ieviešana

Lai izmantotu maršrutēšanas funkcijas, tev jāievieš `I18nRoutingStrategy` saskarne:

```typescript
interface I18nRoutingStrategy {
  getCurrentPath: () => string
  linkComponent?: Component
  push: (target: { path: string }) => void
  replace: (target: { path: string }) => void
  resolvePath?: (to: string | { path?: string }, locale: string) => string | { path?: string }
  getRoute?: () => { fullPath: string; query: Record<string, unknown> }
}
```

Katras paketes dokumentācija ietver pilnus adaptera ieviešanas piemērus populārajiem maršrutētājiem:

- **Vue**: Vue Router adaptera piemērs.
- **React**: React Router adaptera piemērs.
- **Solid**: Solid Router adaptera piemērs.
- **Astro**: uz failiem balstīta maršrutēšanas adaptera piemērs.

## Galvenās funkcijas

Visas paketes koplieto šīs galvenās funkcijas:

### Tulkošanas metodes

- `t()` — pamata tulkošana ar parametru interpolāciju.
- `ts()` — tulkošana, kas vienmēr atgriež virkni.
- `tc()` — uz daudzskaitli vērsta tulkošana.
- `tn()` — skaitļu formatēšana.
- `td()` — datuma formatēšana.
- `tdr()` — relatīvā laika formatēšana.
- `has()` — pārbaudīt, vai tulkojuma atslēga eksistē.

### Lokalizācijas pārvaldība

- **Lokalizācijas maiņa** — programmatiski mainīt pašreizējo lokalizāciju.
- **Atkāpšanās lokalizācija** — automātiska atkāpšanās, kad trūkst tulkojuma.
- **Maršrutam specifiski tulkojumi** — tulkojumu organizācija lapas līmenī.
- **Tulkojumu kešošana** — inteliģenta kešošana veiktspējai.

### TypeScript atbalsts

Visas paketes nodrošina:

- Pilnas TypeScript definīcijas.
- Tipa drošas tulkojumu atslēgas (ar tipu ģeneratoru).
- IntelliSense atbalsts IDE.
- Kompilācijas laika kļūdu pārbaude.
