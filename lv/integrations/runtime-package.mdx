`@i18n-micro/runtime` ir no ietvara neatkarīga i18n instance: vārdnīcas, `t()`, daudzskaitļi, `Intl` formatēšana un izmaiņu abonēšana, bez `fs` un bez ietvara. Izmantojiet to tīrā TypeScript, web worker, edge funkcijā vai kā pamatu savai saistei. React, Preact, Node un Astro pakotnes paplašina šo pašu klasi.

## Instalēšana {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/runtime
```

```bash npm
npm install @i18n-micro/runtime
```

```bash yarn
yarn add @i18n-micro/runtime
```

</CodeGroup>

Nav vienādranga atkarību. Tulkojumu failiem diskā izmantojiet [`@i18n-micro/node`](/lv/integrations/nodejs-package).

## Iestatīšana {#setup}

```ts
import { createI18n } from '@i18n-micro/runtime'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    en: { greeting: 'Hello, {name}!', apples: 'no apples | one apple | {count} apples' },
    de: { greeting: 'Hallo, {name}!' },
  },
  routeMessages: {
    about: { en: { title: 'About us' } },
  },
})
```

Visas opcijas (`plural`, `missingWarn`, `missingHandler`, `numberFormats`, `datetimeFormats`) ir uzskaitītas sadaļā [Instance](/lv/integrations/overview#the-instance).

## Tulkošana {#translate}

```ts
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.tc('apples', 5) // '5 apples'
i18n.tn(1234.5) // '1,234.5'

i18n.setRoute('about')
i18n.t('title') // 'About us' (route dictionary)
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!' (root, still visible)
```

Vēlāk ielādējiet vairāk vārdnīcu:

```ts
i18n.loadMessages({ fr: { greeting: 'Bonjour, {name} !' } }, { about: { fr: { title: 'À propos' } } })
i18n.addTranslations('fr', { nav: { home: 'Accueil' } }) // deep merge; pass false to replace

await i18n.loadFromUrl('/locales/fr.json', { locale: 'fr' })
await i18n.loadFromUrl('/locales/pages/about/fr.json', { locale: 'fr', routeName: 'about' })
await i18n.loadFromUrls([
  { url: '/locales/en.json', locale: 'en' },
  { url: '/locales/de.json', locale: 'de' },
])
```

`loadFromUrl` izmanto `fetch` (nododiet `init` galvenēm) un izmet kļūdu, ja atbilde nav OK. `loadFromUrls` ielādē vienu pēc otras.

## Lokalizācijas pārslēgšana {#switch-locale}

```ts
i18n.locale = 'de'
i18n.t('greeting', { name: 'Ada' }) // 'Hallo, Ada!'
```

Lokalizācijas, maršruta un vārdnīcu izmaiņas paziņo abonentiem — tā ietvaru saistes veic atkārtotu renderēšanu:

```ts
const stop = i18n.subscribe(() => {
  document.querySelector('#greeting')!.textContent = i18n.t('greeting', { name: 'Ada' }) as string
})
i18n.locale = 'fr'
stop()
```

`getSnapshot()` atgriež virkni, kas mainās ar katru paziņojumu (krātuvēm `useSyncExternalStore` stilā).

## Katram pieprasījumam {#per-request}

Instance glabā vienu lokalizāciju un vienu maršrutu. Serverī nepārslēdziet koplietotu instanci katram pieprasījumam: divi vienlaicīgi pieprasījumi redzētu viens otra lokalizāciju. `i18n.fork(locale)` dod pieprasījumam savu instanci: savu lokalizāciju, rezerves lokalizāciju un maršrutu; tās pašas vārdnīcas, formatētājus un noteikumus. Atzarošana maksā vienādi neatkarīgi no vārdnīcu skaita. Atzars redz ierakstus savā vecākā līdz savam pirmajam ierakstam, un tā ieraksti paliek tajā. [Node.js](/lv/integrations/nodejs-package#per-request) pievieno `run`.

## API {#api}

| Loceklis | Piezīmes |
| --- | --- |
| `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has` | skatiet [Tulkošana un formatēšana](/lv/integrations/overview#translate-and-format) |
| `locale`, `fallbackLocale` | iegūt/iestatīt |
| `currentRoute`, `setRoute(name)`, `getRoute()` | aktīvais maršruts, noklusējums `'index'` |
| `loadMessages(messages?, routeMessages?)` | sapludina daudzas lokalizācijas un maršrutus vienlaikus |
| `addTranslations(locale, tree, merge = true)`, `addRouteTranslations(locale, route, tree, merge = true)` | |
| `loadFromUrl(url, { locale?, routeName?, init? })`, `loadFromUrls(entries)` | `fetch` JSON |
| `hasTranslation(key)` | aktīvā lokalizācija, jebkurš maršruts (atšķirībā no `has`, kas pārbauda aktīvo maršrutu un sakni) |
| `setTranslation(key, value)`, `resolveTranslations()` | ieraksta vienu atslēgu; nolasa sapludināto koku |
| `clear()`, `clearCache()` | izmet visas vārdnīcas |
| `subscribe(cb)`, `getSnapshot()` | izmaiņu paziņojumi |
| `storage` | `{ translations: Map<'locale:route', Translations> }` |

Kods, kas nav valodas tags, savus daudzskaitļus saņem no `localeIso: { ua: 'uk-UA' }`; `localeIsoMap(locales)` to izveido no lokalizāciju saraksta ierakstiem, kuriem ir `iso`.

Moduļa eksporti: `createI18n`, `I18n`, `fetchJsonTranslations`, `FormatService`, `interpolate`, `localeIsoMap` un tipi `I18nOptions`, `LoadFromUrlOptions`, `LoadFromUrlEntry`, `TranslationStorage`, `Translations`, `Locale`, `PluralFunc`. Pilnas signatūras: [pakotnes atsauce](/lv/api/packages/runtime).
