`@i18n-micro/astro` tulko Astro lapas serverī: starpprogrammatūra izvēlas lokali no URL un ievieto katra pieprasījuma instanci `Astro.locals`, bet `useI18n(Astro)` to nolasa. Izmantojiet to Astro vietnē, kurai vajadzīgi URL ar lokales prefiksu (`/about`, `/fr/about`) un koplietotas JSON vārdnīcas. Jūs iegūstat `.astro` komponentus, sākumlapas novirzīšanu uz apmeklētāja valodu, `hreflang` tagus un rekvizītus [salām](/lv/integrations/astro-islands).

## Instalēšana {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/astro
```

```bash npm
npm install @i18n-micro/astro
```

```bash yarn
yarn add @i18n-micro/astro
```

</CodeGroup>

Vienādranga atkarības: `astro` `^5.0.0 || ^6.0.0 || ^7.0.0`. Neobligātas, tikai [salām](/lv/integrations/astro-islands): `vue` `^3.3.0`, `react` `^16.8.0 || ^17.0.0 || ^18.0.0 || ^19.0.0`, `preact` `^10.0.0 || ^11.0.0`, `svelte` `^4.0.0 || ^5.0.0`.

## Iestatīšana {#setup}

Pievienojiet integrāciju. Tā iekļauj jūsu vārdnīcas servera pakotnē un instalē starpprogrammatūru, tāpēc `src/middleware.ts` nav vajadzīgs:

```ts
// astro.config.mjs
import { defineConfig } from 'astro/config'
import node from '@astrojs/node'
import { i18nIntegration } from '@i18n-micro/astro'

export default defineConfig({
  output: 'server',
  adapter: node({ mode: 'standalone' }),
  integrations: [
    i18nIntegration({
      locale: 'en',
      fallbackLocale: 'en',
      locales: [
        { code: 'en', iso: 'en-US', displayName: 'English' },
        { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
        { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
      ],
      translationDir: 'src/locales',
    }),
  ],
})
```

Vārdnīcas būvēšanas laikā kļūst par kodu: serveris neko nelasa no diska, tāpēc tas darbojas arī edge vidē (Cloudflare, Vercel Edge). `astro dev` režīmā faila izmaiņas tiek piemērotas nākamajā pieprasījumā.

### Integrācijas opcijas {#integration-options}

| Opcija | Noklusējums | Piezīmes |
| --- | --- | --- |
| `locale` | obligāta | Noklusējuma lokale. |
| `fallbackLocale` | `locale` | |
| `locales` | `[]` | Pilni `Locale` objekti. `disabled` lokale nav neviena URL lokale un nav novirzīšanas mērķis. `iso` ir tags, pēc kura veido daudzskaitli, ja kods tāds nav (`ua` → `uk-UA`). |
| `translationDir` | nav | Mape, kas tiek iekļauta servera pakotnē, relatīvi pret projekta sakni. |
| `disablePageLocales` | `false` | Lapu faili tiek uzskatīti par saknes tulkojumiem. |
| `autoDetect` | `true` | Sākumlapas novirzīšana, skatiet [Lokales noteikšana](#locale-detection). |
| `redirectToDefault` | `false` | `/` novirza arī tad, ja nekas nedod priekšroku citai lokalei. |
| `localeCookie` | `'i18n-locale'` | `null` atspējo sīkfailu. |
| `missingWarn` | `false` | |
| `middleware` | `true` | `false`: uzrakstiet starpprogrammatūru paši, skatiet tālāk. |

Izpildlaika iestatījumi tiek publicēti `virtual:i18n-micro/config` (`config.base` ir Astro `base`, `config.localeCodes` — iespējotie kodi), vārdnīcas — `virtual:i18n-micro/messages`.

### Jūsu pašu starpprogrammatūra {#your-own-middleware}

Daudzskaitļa noteikums, trūkstošo atslēgu apstrādātājs un maršrutētāja adapteris nevar pāriet no konfigurācijas procesa uz servera pakotni. Šiem gadījumiem nododiet `middleware: false` un uzrakstiet `src/middleware.ts`. Tad Astro `i18n` konfigurācija tiek iestatīta jūsu vietā ar `routing: 'manual'`, tāpēc `Astro.currentLocale` un `astro:i18n` darbojas. Astro neatļauj šo iestatījumu bez `src/middleware.ts`, tāpēc ar integrācijas pašas starpprogrammatūru tie nedarbojas.

```ts
// src/middleware.ts
import { config } from 'virtual:i18n-micro/config'
import { messages } from 'virtual:i18n-micro/messages'
import { createAstroRouterAdapter, createI18n, createI18nMiddleware, localeIsoMap } from '@i18n-micro/astro'

const i18n = createI18n({
  locale: config.defaultLocale,
  fallbackLocale: config.fallbackLocale,
  localeIso: localeIsoMap(config.locales),
  messages: messages.root,
  routeMessages: messages.routes,
  plural: myPluralRule,
})

export const onRequest = createI18nMiddleware({
  i18n,
  defaultLocale: config.defaultLocale,
  locales: config.localeCodes,
  localeObjects: config.locales,
  autoDetect: config.autoDetect,
  redirectToDefault: config.redirectToDefault,
  localeCookie: config.localeCookie,
  base: config.base,
  routingStrategy: createAstroRouterAdapter(config.locales, config.defaultLocale),
})
```

Lai tā vietā nolasītu mapi izpildlaikā, `loadTranslationsFromDir` un `loadTranslationsIntoI18n` atrodas `@i18n-micro/astro/node` (tikai Node).

### Starpprogrammatūras opcijas {#middleware-options}

| Opcija | Noklusējums | Piezīmes |
| --- | --- | --- |
| `i18n` | obligāta | Globālā instance; katrs pieprasījums saņem `i18n.fork(locale)`, kas maksā vienādi neatkarīgi no vārdnīcu skaita. |
| `defaultLocale` | obligāta | |
| `locales` | obligāta | Lokaļu kodi. |
| `localeObjects` | `locales` kā `{ code }` | Pilni `Locale` objekti komponentiem un SEO. |
| `autoDetect` | `true` | Sākumlapas novirzīšana, skatiet [Lokales noteikšana](#locale-detection). |
| `redirectToDefault` | `false` | `/` novirza arī tad, ja nekas nedod priekšroku citai lokalei, — uz noklusējuma lokales sākumlapu tā, kā to atrisina maršrutēšanas stratēģija. |
| `localeCookie` | `'i18n-locale'` | `null` atspējo sīkfailu. |
| `routingStrategy` | prefikss, izņemot noklusējumu | Maršrutētāja adapteris. Metodes, kuras tas izlaiž, nāk no noklusējuma adaptera. |
| `base` | nav | Astro `base`: `config.base`. |

Lapu faili (`src/locales/pages/blog/post/de.json`) ir maršruts `blog-post`: lapas ceļš, savienots ar `-`.

## Tulkošana {#translate}

```astro
---
// src/pages/index.astro
import { useI18n } from '@i18n-micro/astro'
import I18nT from '@i18n-micro/astro/i18n-t'

const { t, tc, locale } = useI18n(Astro)
---

<h1>{t('greeting', { name: 'Ada' })}</h1>
<p>{tc('apples', 3)}</p>
<I18nT keypath="welcome" tag="p" />
<p>{locale}</p>
```

`useI18n(Astro)` atgriež `locale`, `defaultLocale`, `locales`, `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`, `getRoute`, `getRouteName(path?)`, `getLocaleFromPath(path?)`, `switchLocalePath(locale)`, `localizePath(path, locale?)`, `getBasePath(url?)`, `getI18n`, `addTranslations`, `addRouteTranslations`, `mergeTranslations` un `clearCache`. Tas izmet kļūdu, ja starpprogrammatūra nav izpildījusies. Palīgfunkcijas `getI18n`, `getLocale`, `getDefaultLocale` un `getLocales` nolasa to pašu `Astro.locals`.

Maršruta nosaukums nāk no maršruta bez tā lokales: `/fr/blog/post` → `blog-post`, un katrs `src/pages/blog/[slug].astro` URL → `blog-slug`, tāpēc viena mape `locales/pages/blog-slug/` apkalpo tos visus. `[...path]` ir `path`. Ar Astro `base` palīgfunkcijas pieņem un atgriež vietnes URL: `switchLocalePath` un `localizePath` to ietver, `getBasePath` neietver, jo `Astro.rewrite` pieņem ceļu bez tā.

### Komponenti {#components}

Importējiet tos no `@i18n-micro/astro/<name>` (vai `@i18n-micro/astro/components/<name>.astro`):

| Komponents | Rekvizīti |
| --- | --- |
| `i18n-t` | `keypath`, `params`, `plural`, `number`, `date`, `relativeDate`, `tag` (`span`, jebkurš tags), `html`, `hideIfEmpty`, `defaultValue`; citi atribūti tiek nodoti tālāk. Ar `html` katra zara rezultāts tiek renderēts kā HTML, un `params` tiek ekranēti. Slotu nav |
| `i18n-link` | `href`, `locale` (mērķa lokale, noklusējums — pašreizējā), `class`; citi atribūti tiek nodoti tālāk. Ārējie URL, `#hash` un `?query` paliek tādi, kā uzrakstīti; maršruts saglabā savu query, hash un beigu slīpsvītru |
| `i18n-switcher` | `class`, `activeClass` (`'active'`), `customLabels`; renderē saites uz pašreizējo lapu katrā iespējotajā lokalē, ar tās query |
| `i18n-group` | nav tādu, kas maina izvadi: `<div>` ap tā slotu, bez prefiksa |

## Maršruti ar lokales prefiksu {#locale-prefixed-routes}

Saglabājiet vienu lapu katram maršrutam `src/pages/` un pievienojiet plānus pārrakstīšanas aizstājējus zem `src/pages/[locale]/`:

```
src/pages/
  index.astro
  about.astro
  [locale]/
    index.astro
    about.astro
```

```astro
---
// src/pages/[locale]/about.astro
import { prepareLocaleRewrite } from '@i18n-micro/astro'

const target = prepareLocaleRewrite(Astro)
if (target instanceof Response) return target
return Astro.rewrite(target)
---
```

`prepareLocaleRewrite` atgriež `404` atbildi nezināmai `:locale`, citādi iestata lokali `Astro.locals` un atgriež ceļu bez prefiksa. Starpprogrammatūra saglabā lokali, kas jau ir `locals`, tāpēc pārrakstītā lapa tiek renderēta tajā. `getLocaleRewritePath(Astro)` atgriež tikai ceļu — gadījumiem, kad lokali validējat paši.

## Lokales noteikšana {#locale-detection}

Lapas lokali nosaka URL:

1. Lokales prefikss (`/fr/about` → `fr`; arī `/en/about` ir `en`).
2. Citādi tas, ko atgriež maršrutētāja adaptera `getLocaleFromPath`, ja tā nav noklusējuma lokale.
3. Citādi noklusējuma lokale. `/about` vienmēr ir noklusējuma lokales lapa, neatkarīgi no sīkfaila.

`autoDetect` ir novirzīšanas norāde tikai sākumlapā:

- Pieprasījums uz `/`, kura sīkfails vai `Accept-Language` dod priekšroku citai lokalei, saņem `302` uz šīs lokales sākumlapu (`/de`). q-svari tiek ievēroti; `de-DE` atbilst `de` lokalei, un `de` atbilst `de-DE` lokalei.
- Ar `redirectToDefault` `/` vienmēr novirza: uz vēlamās lokales sākumlapu, citādi uz noklusējuma lokales sākumlapu.
- `/` atbilde satur `Vary: Cookie, Accept-Language` (tikai `Accept-Language`, ja `localeCookie` ir `null`).
- Iepriekš renderētas lapas nekad nenovirza.

`detectLocale(pathname, cookies, headers, defaultLocale, locales, localeCookie?, routingStrategy?, autoDetect?)` atgriež to pašu vēlamo lokali jūsu pašu loģikai.

Sīkfails atceras izvēli. Lapas skatījums, kas nāk no tās pašas izcelsmes citas lokales lapas, nozīmē, ka apmeklētājs pārslēdzas, neatkarīgi no tā, kura saite viņu tur atveda: HTML atbilde iestata sīkfailu uz jauno lokali, un `/` nenovirza, tāpēc pārslēdzējs nonāk noklusējuma lokales sākumlapā. Galapunkts, attēls, 404, formas iesniegšana un iepriekšēja ielāde neko nemaina. "Tā pati izcelsme" ir tas, ko pārlūks norāda `Sec-Fetch-Site`; bez šīs galvenes `Referer` resursdators tiek salīdzināts ar pieprasījuma resursdatoru, tāpēc aiz starpniekservera iestatiet Astro `security.allowedDomains`.

[Servera salai](https://docs.astro.build/en/guides/server-islands/) vai darbībai URL nav lokales. Tā tiek renderēta lapai, kas to pieprasīja, nolasot no `Referer`, kura ceļš ir vienīgais, kas ir svarīgs, tāpēc starpniekserveris servera priekšā neko nemaina, un tā nekad nenovirza. Tās atbilde satur `Vary: Referer`. Bez `Referer` (`no-referrer` politika) tā ir noklusējuma lokalē, un dinamiskā lapā tās maršruts nāk no URL, tāpēc lapu vārdnīcas to nesasniedz.

## Maršrutētāja adapteris {#router-adapter}

`createAstroRouterAdapter(locales, defaultLocale)` pievieno prefiksu katrai lokalei, izņemot noklusējuma. Astro adapterim vajadzīgs tikai `getCurrentPath`; pārējie locekļi ir neobligāti un atgriežas pie noklusējuma adaptera: `getRouteName(path, locales, routePattern?)`, `getLocaleFromPath`, `switchLocalePath`, `localizePath`, `removeLocaleFromPath`, `resolvePath` (sākumlapas novirzīšanas mērķis), `push`, `replace`, `getRoute`. Uzrakstiet savu apakšdomēnu vai sufiksu URL gadījumam un nododiet to `createI18nMiddleware`.

## SEO {#seo}

```astro
---
// src/layouts/Layout.astro
import { useLocaleHead } from '@i18n-micro/astro'

const head = useLocaleHead(Astro, { baseUrl: 'https://example.com' })
---

<html lang={head.htmlAttrs.lang} dir={head.htmlAttrs.dir}>
  <head>
    {head.link.map((l) => <link rel={l.rel} href={l.href} hreflang={l.hreflang} />)}
    {head.meta.map((m) => <meta property={m.property} content={m.content} />)}
  </head>
  <body><slot /></body>
</html>
```

Tas atgriež `htmlAttrs` (`lang` no `iso`, `dir`), canonical saiti (ceļš bez query), `hreflang` alternatīvas katrai iespējotajai lokalei ar `seo !== false` plus `x-default`, `og:locale`, `og:locale:alternate` un `og:url`. Opcijas: `baseUrl` (`site` no Astro konfigurācijas, citādi saknes relatīvi URL), `addDirAttribute` (`true`), `addSeoAttributes` (`true`), `hreflangBaseLanguage` (`false`).
