---

Sala darbojas pārlūkprogrammā, kur servera i18n instance neeksistē. `@i18n-micro/astro` ļauj lapai izvēlēties atslēgas, kas salai vajadzīgas, nodot tās kā vienu rekvizītu un nolasīt tās salā ar nelielu ietvara adapteri. Jūs saņemat `t`, `tc`, `tn`, `td`, `tdr` un `has` Vue, React, Preact un Svelte salās, un HTML ir tikai izvēlētās virknes.

## Iestatīšana {#setup}

Vispirms iestatiet [Astro integrāciju un starpprogrammatūru](/lv/integrations/astro-package#setup), pēc tam pievienojiet izmantotā ietvara integrāciju (`@astrojs/vue`, `@astrojs/react`, `@astrojs/preact`, `@astrojs/svelte`). Salu adapteriem šis ietvars vajadzīgs kā vienādranga atkarība: `vue` `^3.3.0`, `react` `^16.8.0 || ^17.0.0 || ^18.0.0 || ^19.0.0`, `preact` `^10.0.0 || ^11.0.0` vai `svelte` `^4.0.0 || ^5.0.0`.

## Tulkojumu nodošana salai {#pass-translations-to-an-island}

```astro
---
// src/pages/index.astro
import { getI18nProps } from '@i18n-micro/astro'
import Counter from '../components/Counter.vue'

const i18n = getI18nProps(Astro, ['counter.title', 'counter.apples'])
---

<Counter client:load i18n={i18n} />
```

`getI18nProps(Astro, keys?)` atgriež `{ locale, fallbackLocale, currentRoute, translations }` (tips `I18nClientProps`). Nododiet atslēgas, ko sala izmanto: katra tiek atrisināta serverī kā `t()` (maršruta, saknes un rezerves vārdnīcas), un HTML nonāk tikai atrastās atslēgas. Bez `keys` tiek nosūtīts viss, uz ko `t()` šajā lapā var atbildēt, katrā salā, tāpēc 2000 saknes atslēgas ir aptuveni 100 KB katrai salai; izstrādes režīmā virs 20 KB par to brīdina.

Salas tulko tikai no šī objekta. `t` atgriež atslēgu visam, kas netika nodots, un saistītie ziņojumi netiek atrisināti.

## Vue {#vue}

Izsauciet `provideI18n(() => props.i18n)` salas saknes komponentā un `useAstroI18n()` tās bērnos. Vue `inject` neredz vērtību, ko nodrošina tas pats komponents, tāpēc āķim jāizpildās bērnā, nevis saknē:

```vue
<!-- src/components/Counter.vue -->
<script setup lang="ts">
import { provideI18n } from '@i18n-micro/astro/client/vue'
import type { I18nClientProps } from '@i18n-micro/astro'
import CounterBody from './CounterBody.vue'

const props = defineProps<{ i18n: I18nClientProps }>()
provideI18n(() => props.i18n)
</script>

<template><CounterBody /></template>
```

```vue
<!-- src/components/CounterBody.vue -->
<script setup lang="ts">
import { ref } from 'vue'
import { useAstroI18n } from '@i18n-micro/astro/client/vue'

const { t, tc } = useAstroI18n()
const count = ref(0)
</script>

<template>
  <h3>{{ t('counter.title') }}</h3>
  <button @click="count++">{{ tc('counter.apples', count) }}</button>
</template>
```

## React un Preact {#react-and-preact}

```tsx
// src/components/Counter.tsx
import { useState } from 'react'
import { I18nProvider, useAstroI18n } from '@i18n-micro/astro/client/react'
import type { I18nClientProps } from '@i18n-micro/astro'

function Body() {
  const { t, tc } = useAstroI18n()
  const [count, setCount] = useState(0)
  return <button onClick={() => setCount(count + 1)}>{t('counter.title')}: {tc('counter.apples', count)}</button>
}

export default function Counter({ i18n }: { i18n: I18nClientProps }) {
  return (
    <I18nProvider value={i18n}>
      <Body />
    </I18nProvider>
  )
}
```

Preact gadījumā importējiet `I18nProvider` un `useAstroI18n` no `@i18n-micro/astro/client/preact`; API ir tāds pats.

## Svelte {#svelte}

```svelte
<!-- src/components/Counter.svelte -->
<script lang="ts">
  import { createI18nStore, useAstroI18n } from '@i18n-micro/astro/client/svelte'
  import type { I18nClientProps } from '@i18n-micro/astro'

  export let i18n: I18nClientProps
  const { t, tc } = useAstroI18n(createI18nStore(i18n))
  let count = 0
</script>

<button on:click={() => count++}>{t('counter.title')}: {tc('counter.apples', count)}</button>
```

`useAstroI18n(store)` atgriež arī `store` nolasīšanai ar `$store` veidnē.

## Saglabātās salas {#persisted-islands}

Sala ar `transition:persist` pēc navigācijas saņem jaunus rekvizītus. React, Preact un Vue (ja nodots ieguvējs) tiem seko. Svelte gadījumā paturiet krātuvi un nododiet tos tālāk: `const store = createI18nStore(i18n)`, `const { t } = useAstroI18n(store)`, tad `$: store.set(i18n)` (ar runes — `$effect(() => store.set(i18n))`).

## API {#api}

| Ieeja | Eksporti |
| --- | --- |
| `@i18n-micro/astro` | `getI18nProps`, tips `I18nClientProps` |
| `@i18n-micro/astro/client/vue` | `provideI18n(props \| () => props)`, `useAstroI18n()` |
| `@i18n-micro/astro/client/react` | `I18nProvider` (rekvizīts `value`), `useAstroI18n()` |
| `@i18n-micro/astro/client/preact` | `I18nProvider` (rekvizīts `value`), `useAstroI18n()` |
| `@i18n-micro/astro/client/svelte` | `createI18nStore(props)`, `useAstroI18n(store)` |
| `@i18n-micro/astro/client` | tīrās `translate`, `hasTranslation`, bez ietvara |

Katrs `useAstroI18n` atgriež `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`, `setLocale`, `setRoute` un `locale`. Salai ir viena sapludināta vārdnīca, tāpēc tās `has` ir patiess atslēgai, uz kuru `t` var atbildēt, arī no rezerves lokalizācijas; serverī `has` skatās tikai aktīvo lokalizāciju.
