`@i18n-micro/types-generator` nolasa katru JSON failu jūsu tulkojumu mapē un ieraksta deklarāciju, kurā uzskaitītas visas atslēgas. Pievienojiet to, ja vēlaties, lai redaktors ieteiktu atslēgas `t()`, `$t()` un `<I18nT keypath>`. Tas darbojas kā Nuxt modulis un kā Vite vai Rollup spraudnis un ģenerē atkārtoti, kad fails mainās.

## Instalēšana {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/types-generator
```

```bash npm
npm install -D @i18n-micro/types-generator
```

```bash yarn
yarn add -D @i18n-micro/types-generator
```

</CodeGroup>

Vienādranga atkarība: `@nuxt/kit` `^3.18.0 || ^4.0.0`. To importē tikai `/nuxt` ieejas punkts; projektā, kas izmanto tikai Vite, vienādranga atkarības brīdinājumu var ignorēt.

## Nuxt {#nuxt}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro', '@i18n-micro/types-generator/nuxt'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Modulis ieraksta `.nuxt/types/i18n-micro.d.ts`, un Nuxt to pievieno tipu kontekstam; nekas nav jāiekļauj manuāli. Tas nolasa `i18nTypes.translationDir`, citādi — vietas, no kurām tulkojumus nolasa `nuxt-i18n-micro`: `translationDir` (no `i18n` vai iekļautajām moduļa opcijām, noklusējums `'locales'`) katrā slānī, un `additionalTranslationDirs`. JSON faila rediģēšana šajā mapē atkārtoti ģenerē tipus `nuxi dev` režīmā. `i18nTypes.outputFile` Nuxt tiek ignorēts (par to brīdina paziņojums).

## Vite {#vite}

`I18nTypesPlugin` ir Vite spraudnis, ko pieņem arī Rollup. Citam pakotājam izsauciet `generateTypes` skriptā.

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { I18nTypesPlugin } from '@i18n-micro/types-generator'

export default defineConfig({
  plugins: [
    vue(),
    I18nTypesPlugin({
      srcDir: process.cwd(),
      translationDir: 'src/locales',
      outputFile: 'src/i18n-micro.d.ts',
    }),
  ],
})
```

| Opcija | Obligāta | Piezīmes |
| --- | --- | --- |
| `srcDir` | jā | Bāzes direktorija; `translationDir` tiek atrisināts attiecībā pret to. |
| `translationDir` | jā | Mape ar JSON failiem (ieskaitot apakšmapes, piemēram, `pages/`) vai mapju masīvs. |
| `outputFile` | nē | Kur ierakstīt deklarāciju; noklusējums `<srcDir>/i18n-micro.d.ts`. |

Spraudnis ģenerē vienreiz būvēšanas sākumā un izstrādes serverī atkārtoti ģenerē 300 ms pēc izmaiņām mapē. Pārliecinieties, ka jūsu `tsconfig.json` `include` aptver izvades failu.

## Atslēgu izmantošana {#use-the-keys}

Ģenerētais fails paplašina `DefineLocaleMessage` pakotnē `@i18n-micro/types`, kas pārvērš `TranslationKey` par jūsu atslēgām:

```ts
declare module '@i18n-micro/types' {
  export interface DefineLocaleMessage {
    nav: object
    'nav.home': string
    'profile.title': string
  }
}
```

Atslēgas ir tās, uz kurām atbild `t()`, ieskaitot objektus, no katras lokales un katra lapas faila, ar to JSON vērtības tipu. `TranslationKey` ir šo atslēgu un jebkuras virknes apvienojums, tāpēc jūs iegūstat automātisko pabeigšanu, nevis kļūdas: kļūdaini uzrakstīta vai dinamiska atslēga joprojām kompilējas. Parametri un atgriežamās vērtības netiek tipizētas.

Dinamiskām atslēgām ar zināmu prefiksu `ScopedKey<'prefix'>` sašaurina līdz atbilstošajām atslēgām:

```ts
import type { ScopedKey } from '@i18n-micro/types'

const statusText = (status: string) => t(`status.${status}` as ScopedKey<'status'>)
```

`TranslationKey` un `ScopedKey` nāk no `@i18n-micro/types` (React, Preact un Solid reeksportē `TranslationKey`; Vue to nedara).

## API {#api}

| Eksports | Ieejas punkts | Piezīmes |
| --- | --- | --- |
| `I18nTypesPlugin(options)` | `@i18n-micro/types-generator` | Vite un Rollup spraudnis |
| `generateTypes(options)` | `@i18n-micro/types-generator` | ieraksta failu, atgriež tā ceļu |
| `getTypesString(options)` | `@i18n-micro/types-generator` | atgriež deklarāciju, neierakstot |
| `formatKeyProperty(key)` | `@i18n-micro/types-generator` | palīgfunkcija |
| Nuxt modulis (`configKey: 'i18nTypes'`) | `@i18n-micro/types-generator/nuxt` | opcija `translationDir` |

Pilnas signatūras: [pakotnes atsauce](/lv/api/packages/types-generator).
