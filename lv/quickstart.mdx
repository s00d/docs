## 🚀 Ātrā uzsākšana

### Instalēšana

Instalējiet moduli savā Nuxt lietotnē:

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

### Pamata konfigurācija

Pievienojiet moduli savā `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

<Tip>
- **Saknes līmeņa faili** (`locales/en.json` u.c.) — tulkojumi, kas tiek koplietoti visā lietotnē (izvēlnes, kājene, kopīgais lietotāja interfeiss). Ar `translationPayloads.mode: 'premerged'` (noklusējums) tie tiek sapludināti katrā lapā būvēšanas laikā.
- **Lapas specifiskie faili** (`locales/pages/<route>/<locale>.json`) — tulkojumi, kas ir unikāli konkrētām lapām, tiek ielādēti tikai tad, kad lapa tiek apmeklēta.
- **Dinamiskie maršruti** — `pages/articles/[id].vue` tiek attēlots uz `locales/pages/articles-id/` (kvadrātiekavas tiek aizstātas ar defisēm).
- **Automātiskā ģenerēšana** — visi tulkošanas faili tiek automātiski izveidoti, ja tie trūkst, `nuxt dev` laikā.
</Tip>

<Info>
Modulis atbalsta abus izkārtojumus:

- **Lapas**: `pages/**/*.vue` (Nuxt 3) vai `app/pages/**/*.vue` (Nuxt 4)
- **Tulkojumi**: pēc noklusējuma `locales/` glabājiet **projekta saknē** (ieteicamā konvencija), nevis `app/` iekšpusē.

```tree
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   ├── en.json
│   └── pages/
└── nuxt.config.ts
```

Izvēles kolokācija: `i18n: \{ translationDir: 'app/locales' \}` (skatiet [fixture `n3`](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/n3)).

Izvēles CLI palīgam `text-to-i18n` izmantojiet [`nuxt-i18n-micro-cli` ≥ 2.1.1](/guides/cli#-text-to-i18n-command), lai `app/pages` un `app/components` tiktu skenēti no projekta saknes.
</Info>

### Pamata lietošana

Izmantojiet tulkojumus savos komponentos:

```vue
<template>
  <div>
    <h1>{{ $t('welcome') }}</h1>
    <p>{{ $t('description', { name: 'World' }) }}</p>

    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" @click="$switchLocale(locale.code)">
        {{ locale.code }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useI18n } from '#imports'

const { $t, $getLocales, $switchLocale } = useI18n()
</script>
```
