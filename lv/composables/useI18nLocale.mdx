---
title: "useI18nLocale"
description: "useI18nLocale nolasa un ieraksta lokalizācijas stāvokli un lokalizācijas sīkdatni — ieejas punkts pielāgotai lokalizācijas noteikšanai."
---

`useI18nLocale()` sniedz piekļuvi lokalizācijai, ko lietotne ir izvēlējusies: `i18n-locale` stāvoklim un lokalizācijas sīkdatnei. Izmantojiet to spraudnī, kas pats nosaka lokalizāciju (domēns, lietotāja profils, galvene), nevis rakstiet `useState('i18n-locale')` vai sīkdatni ar roku. Tās derīguma pārbaudes izmanto iespējotās lokalizācijas, ieskaitot izpildlaika pārrakstījumus.

## Signatūra {#signature}

```ts
useI18nLocale(): { getEffectiveLocale: (route: unknown, getLocaleFromRoute: GetLocaleFromRoute) => string; getLocale: () => string | null; getPreferredLocale: () => string | null; hashCookie: CookieRef; isValidLocale: (locale: string | null | undefined) => locale is string; locale: any; localeCookie: CookieRef; resolveInitialLocale: (options: ResolveInitialLocaleOptions) => string; setLocale: (locale: string | null) => void; syncLocale: (locale: string | null) => void; validLocales: string[] }
```

Centralizēts ieejas punkts i18n lokalizācijas pārvaldībai.
Apvieno useState('i18n-locale'), lokalizācijas sīkdatni un sinhronizācijas utilītas.

## Atgrieztās vērtības {#returned-values}

| Loceklis | Tips | Apraksts |
| --- | --- | --- |
| `locale` | `Ref<string \| null>` | `useState('i18n-locale')` ref. |
| `localeCookie` | `Ref<string \| null>` | Sīkdatne [`localeCookie`](/lv/api/module-options#localecookie); vienkāršs `{ value: null }`, ja opcija ir `null`. |
| `hashCookie` | `Ref<string \| null>` | Sīkdatne `hash-locale` jaucējfragmenta maršrutēšanā; citādi `{ value: null }`. |
| `validLocales` | `string[]` | Iespējoto lokalizāciju kodi. |
| `setLocale(locale)` | `(locale: string \| null) => void` | Ieraksta stāvokli un sīkdatnes. Nepārbauda derīgumu un neielādē tulkojumus. |
| `syncLocale(locale)` | `(locale: string \| null) => void` | Ieraksta tikai sīkdatnes. |
| `getLocale()` | `() => string \| null` | Stāvoklis, pēc tam izvēles sīkdatne (jaucējfragmenta maršrutēšanā — hash sīkdatne). Netiek pārbaudīts derīgums. |
| `getPreferredLocale()` | `() => string \| null` | Pirmā **derīgā** no stāvokļa un izvēles sīkdatnes vai `null`. |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string` | Stāvoklis jaucējfragmenta maršrutēšanā, ja iestatīts; citādi `getLocaleFromRoute(route)`. |
| `resolveInitialLocale(options)` | `(options: ResolveInitialLocaleOptions) => string` | `options.urlLocale`, pēc tam derīgs stāvoklis, pēc tam `options.serverLocale`, pēc tam maršruta lokalizācija. Saglabā rezultātu stāvoklī, ja stāvoklis nav derīgs; klientā tas ieraksta arī sīkdatni. |
| `isValidLocale(locale)` | `(locale) => locale is string` | Vai `locale` ir sarakstā `validLocales`. |

Sīkdatnes ir derīgas vienu gadu, ar `path: '/'` un `sameSite: 'lax'`.

## Piemērs {#example}

```ts
// plugins/locale-from-domain.server.ts
export default defineNuxtPlugin({
  name: 'locale-from-domain',
  enforce: 'pre',
  setup() {
    const { setLocale, isValidLocale } = useI18nLocale()
    const host = useRequestURL().hostname // e.g. de.example.com
    const code = host.split('.')[0]
    if (isValidLocale(code)) setLocale(code)
  },
})
```

Moduļa ielādētāja spraudnis nolasa stāvokli, kad tas startē, tāpēc spraudnim, kas to iestata, jāizpildās pirmajam (`enforce: 'pre'`). Kā stāvoklis konkurē ar URL, sīkdatni un `Accept-Language`: [Lokalizācijas noteikšana](/lv/guide/locale-detection). Pilns apraksts: [Pielāgota noteikšana](/lv/guide/custom-auto-detect).

`setLocale()` nepārslēdz ekrānā redzamos tulkojumus. Lai mainītu pašreizējās lapas lokalizāciju, izsauciet [`$switchLocale()`](/lv/api/methods#$switchlocale).
