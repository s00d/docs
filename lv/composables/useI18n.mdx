---
title: "useI18n"
description: "useI18n atgriež izpildlaika palīgfunkcijas (`$t`, `$tc`, `$localePath`, …) kā vienkāršu objektu — ar `$` prefiksu un bez tā."
---

`useI18n()` atgriež moduļa izpildlaika palīgfunkcijas kā vienkāršu objektu. Izmantojiet to `<script setup>`, composables un spraudņos, nevis `useNuxtApp()`. Katra palīgfunkcija ir pieejama ar savu `$` nosaukumu un ar aizstājvārdu bez prefiksa: `t` un `$t` ir viena un tā pati funkcija.

## Signatūra {#signature}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Visas izpildlaika palīgfunkcijas vienkārša objekta veidā.

Tās pašas funkcijas, ko spraudnis injicē kā `$t`, `$tc` utt., pieejamas gan ar
dolāra prefiksa nosaukumu, gan ar aizstājvārdu bez prefiksa — tāpēc darbojas gan `const { t } = useI18n()`, gan
`const { $t } = useI18n()`.

**Atgriež** — palīgfunkcijas, kas aprakstītas [metožu atsaucē](/lv/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

Atgrieztais objekts satur visas [`PluginsInjections`](/lv/api/methods) palīgfunkcijas. Katra no tām ir dokumentēta lapā [Palīgfunkcijas](/lv/api/methods).

## Piemērs {#example}

```vue
<script setup lang="ts">
const { t, tc, localePath, switchLocale, getLocale } = useI18n()

const title = computed(() => t('page.title'))
</script>

<template>
  <h1>{{ title }}</h1>
  <p>{{ tc('items', 3) }}</p>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
  <button @click="switchLocale(getLocale() === 'en' ? 'de' : 'en')">{{ t('nav.switch') }}</button>
</template>
```

## Nav tipā {#not-in-the-type}

`$defineI18nRoute` ir tipizēts tikai `useNuxtApp()`:

```ts
const { $defineI18nRoute } = useNuxtApp()
```
