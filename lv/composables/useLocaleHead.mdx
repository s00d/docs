---
title: "useLocaleHead"
description: "useLocaleHead veido i18n SEO tagus (lang, dir, canonical, hreflang, og:locale) kā objektu, ko nodot useHead."
---

`useLocaleHead()` veido i18n head tagus pašreizējam maršrutam: `lang` un `dir` elementā `<html>`, canonical saiti, `hreflang` alternatīvas ar `x-default`, `og:url`, `og:locale` un `og:locale:alternate`. Izmantojiet to, ja iestatāt [`meta: false`](/lv/api/module-options#meta) un pārvaldāt `useHead` paši; ar `meta: true` modulis šos tagus jau reģistrē, un izmaiņas atsevišķām lapām tiek veiktas ar [`useI18nHead`](/lv/composables/useI18nHead).

## Signatūra {#signature}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { build: () => LocaleHead; metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }, LocaleHead | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

SEO head tagi pašreizējam maršrutam: `hreflang` alternatīvas katrai lokālei plus
`x-default`, canonical saite, `og:locale` un `lang`/`dir` elementā `<html>`.

Nepieciešams tikai tad, ja `meta` ir atspējots vai noklusējumi jāpielāgo — ar `meta: true`
modulis pats reģistrē tos pašus tagus.

| Parametrs | Tips | Apraksts |
| --- | --- | --- |
| `options` | `UseLocaleHeadOptions` |  |

**Atgriež** — `metaObject`, ref, kas satur head objektu, gatavu nodošanai `useHead`; `updateMeta` to atsvaidzina; `build` aprēķina head objektu no pašreizējā maršruta (reaktīvs, ja nolasīts getterī, piem., `useHead(() => build())`)

```ts
const { metaObject } = useLocaleHead({ addSeoAttributes: true })
useHead(metaObject)
```

## Opcijas {#options}

| Opcija | Noklusējums | Apraksts |
| --- | --- | --- |
| `addDirAttribute` | `true` | Iestata `dir` elementā `<html>` no lokāles `dir` (`'auto'`, ja tās nav). |
| `identifierAttribute` | `'id'` | Atribūts, kas identificē katru tagu (`i18n-can`, `i18n-og`, `i18n-alternate-<hreflang>`, …), lai atjauninājumi aizstātu tagus, nevis tos pievienotu. |
| `addSeoAttributes` | `true` | Izvada canonical, `hreflang` un `og:` tagus. `false` saglabā tikai `htmlAttrs`. |
| `baseUrl` | `'/'` | Izcelsme (origin), kas pievienota katram URL. Atstājiet `'/'` relatīviem URL; nododiet `'https://example.com'` absolūtiem. |
| `autoUpdate` | `true` | Pārbūvē `metaObject`, kad mainās maršruts vai `i18n-locale` stāvoklis. |

## Ko tas izvada {#what-it-emits}

- Neko maršrutā bez atbilstības (404) vai ar `disableMeta` aktīvajai lokālei.
- Canonical un `og:url`: `$switchLocalePath(<active locale>)`, vaicājums samazināts līdz [`canonicalQueryWhitelist`](/lv/api/module-options#canonicalquerywhitelist), piemērots [`trailingSlash`](/lv/api/module-options#trailingslash).
- `hreflang`: viena saite katrai iespējotajai lokālei, kurā lapa eksistē, `hreflang = iso || code`, izlaižot lokāles ar `seo: false`; ar `hreflangBaseLanguage: true` pirmā valodas reģionālā lokāle izvada arī valodas pamata tagu. Ar `no_prefix` nekas netiek izvadīts.
- `x-default`: noklusējuma lokāles URL, ja vien stratēģija nav `no_prefix`, noklusējuma lokālei nav `seo: false` vai lapa tajā neeksistē.
- `og:locale` / `og:locale:alternate`: no lokāles `og` vai konvertēta tās `iso` (`en-US` → `en_US`); izlaists ar izstrādes brīdinājumu, ja neviens nedarbojas.

## Piemērs {#example}

```ts
// app.vue, with i18n.meta: false
const { metaObject } = useLocaleHead({ baseUrl: 'https://example.com' })
useHead(metaObject)
```

`build()` atgriež to pašu objektu bez ref: `useHead(() => build())` paliek reaktīvs bez novērotāja.
