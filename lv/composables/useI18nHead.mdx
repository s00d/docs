title: "useI18nHead"
description: "useI18nHead pārraksta ģenerētos i18n SEO tagus vienai lapai: aizstājiet vai noņemiet canonical, hreflang un og tagus vai pievienojiet savus."
---

`useI18nHead()` maina moduļa ģenerētos SEO tagus tikai vienai lapai. Izmantojiet to, kad lapa zina labāk nekā maršrutētājs: CMS raksts, kas pieejams tikai dažās lokālēs, canonical URL no API, papildu `og:` tagi. Jūs saņemat ģenerētos tagus ar jūsu pārrakstījumiem, kas apvienoti virsū.

## Signatūra {#signature}

```ts
useI18nHead(input?: MaybeRefOrGetter<I18nHeadInput | null>): { pageHead: any; resetPageHead: () => void }
```

Reģistrē lapas līmeņa pārrakstījumus i18n SEO head tagiem.
`02.meta` spraudnis tos apvieno virs `useLocaleHead` izvades.

Dodiet priekšroku getterim (`() => ({ … })`), ja vērtības nāk no `$t` / `t`, lai tās
tiktu atkārtoti aprēķinātas, mainoties lokālei. Vienkāršs objekts tiek novērtēts vienreiz un paliek nemainīgs.

| Parametrs | Tips | Apraksts |
| --- | --- | --- |
| `input` *(neobligāts)* | `MaybeRefOrGetter<I18nHeadInput \| null>` |  |

Tas darbojas ar [`meta: true`](/lv/api/module-options#meta) (noklusējums): moduļa meta spraudnis apvieno ievadi virs [`useLocaleHead`](/lv/composables/useLocaleHead) izvades katrā head renderēšanā. Ar `meta: false` to neviens nenolasa.

Pārrakstījums tiek atiestatīts, kad mainās maršruta nosaukums. Lapa, kas iestata `disableMeta`, nesaņem nekādus i18n tagus, ieskaitot pārrakstījumus.

## Ievade {#input}

`I18nHeadInput` (no `@i18n-micro/types`):

| Atslēga | Tips | Efekts |
| --- | --- | --- |
| `htmlAttrs` | `Record<string, string>` | Apvienots ar `<html>` atribūtiem (`lang`, `dir`). |
| `meta` | `I18nHeadMeta[]` | Pievienots pēc ģenerētajiem tagiem; aizstāj tagu ar tādu pašu `id`, `property` vai `name`. |
| `link` | `I18nHeadLink[]` | Pievienots pēc ģenerētajām saitēm; aizstāj saiti ar tādu pašu `id` vai `rel` + `hreflang`. |
| `replace.canonical` | `string \| false` | Aizstāj canonical `href` vai noņem saiti. |
| `replace.hreflang` | `I18nHeadLink[] \| false` | Aizstāj vai noņem **visas** `rel="alternate"` saites, ieskaitot `x-default`. |
| `replace.xDefault` | `I18nHeadLink \| false` | Aizstāj vai noņem `x-default` saiti. |
| `replace.ogLocale` | `string \| false` | Aizstāj vai noņem `og:locale`. |
| `replace.ogUrl` | `string \| false` | Aizstāj vai noņem `og:url`. |
| `replace.ogAlternates` | `string[] \| false` | Pārbūvē `og:locale:alternate` no šiem lokāļu kodiem (izmantojot `og` / `iso`), izlaižot pašreizējo lokāli, nezināmus kodus un kodus bez `og` vai `iso` vērtības, vai tos noņem. |
| `disable` | `I18nHeadDisableGroup[]` | Atmet ģenerētās grupas: `'hreflang'` (ne `x-default`), `'x-default'`, `'canonical'`, `'og'` (`og:locale` + `og:url`), `'og-alternates'`, `'html'`. |

Piemērošanas secība: `disable`, tad `replace`, tad `htmlAttrs`, `meta`, `link`.

## Piemērs {#example}

Raksts, kas pieejams tikai dažās lokālēs, ar alternatīvajiem URL no API:

```vue
<script setup lang="ts">
const route = useRoute()
const { t } = useI18n()
const { data: article } = await useFetch<{ title: string; urls: Record<string, string> }>(`/api/articles/${route.params.slug}`)

useI18nHead(() => {
  if (!article.value) return null
  const codes = Object.keys(article.value.urls)
  return {
    meta: [{ property: 'og:title', content: article.value.title || t('blog.title') }],
    replace: {
      hreflang: codes.map((code) => ({ rel: 'alternate', hreflang: code, href: article.value!.urls[code]! })),
      ogAlternates: codes,
    },
  }
})
</script>
```

Nododiet getteri, kā šeit, ja vērtības nāk no `t()` vai asinhroniem datiem: tas tiek palaists atkārtoti, mainoties lokālei. Vienkāršs objekts tiek nolasīts vienreiz.
