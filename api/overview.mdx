## Where each method lives

Almost every helper is available two ways:

```ts
// via useI18n() — recommended in components
const { $t, $tc, $switchLocale, $getLocale } = useI18n()

// via useNuxtApp() — same helpers, plus a couple extra
const { $t, $tc, $defineI18nRoute, $clearCache } = useNuxtApp()
```

Two helpers live **only** on `useNuxtApp()` and are absent from the object `useI18n()` returns:

- `$defineI18nRoute`: the per-page route macro (declared in the `define` plugin).
- `$clearCache`: the cache flush (declared in `NuxtAppOnlyInjections`).

Everything else in the [methods reference](/api/methods) is reachable through either.

## Where to start

- If you are configuring the module, start with [module options](/api/module-options).
- If you are writing components, jump to [methods](/api/methods) or [`useI18n`](/api/composables/use-i18n).
- If you need to plug in a custom detection or dynamic translation loader, see [events](/api/events).
