# API Reference

## Runtime API

- [Methods](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, locale switching, routing helpers
- [Events](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Translations and Cache](/api/cache) — `TranslationStorage`, payload loading, `$clearCache`

## Server middleware

Server handlers use dedicated middleware (not the client `$t` helpers):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — translate in API routes and server handlers
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — read detected locale and metadata

See the full [Server-Side Translations guide](/guides/server-side-translations) for setup, locale detection priority, and examples.
