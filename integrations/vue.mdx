`@i18n-micro/vue` is a Vue 3 plugin built on the same core as Nuxt I18n Micro. It gives you reactive translations, pluralization, number and date formatting, route-scoped messages, and optional Vue Router integration through a small adapter.

<Note>
  This is a standalone Vue 3 package, not a Nuxt module. See [the overview](/integrations/overview) for how it fits in the wider `@i18n-micro` ecosystem.
</Note>

### Peer dependencies

The package requires Vue 3, and optionally Vue Router if you want router-driven locale switching.

```json
{
  "peerDependencies": {
    "vue": "^3.3.0",
    "vue-router": "^4.6.3 || ^5.0.0"
  }
}
```

## Quick start

### Without a router

```typescript
import { createApp } from 'vue'
import { createI18n } from '@i18n-micro/vue'
import App from './App.vue'

const app = createApp(App)

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  locales: [
    { code: 'en', displayName: 'English', iso: 'en-US' },
    { code: 'fr', displayName: 'Français', iso: 'fr-FR' },
  ],
  defaultLocale: 'en',
  messages: {
    en: {
      greeting: 'Hello, {name}!',
      apples: 'no apples | one apple | {count} apples',
    },
    fr: {
      greeting: 'Bonjour, {name}!',
      apples: 'pas de pommes | une pomme | {count} pommes',
    },
  },
})

app.use(i18n)
app.mount('#app')
```

When you pass `locales` and `defaultLocale` directly to `createI18n`, they are automatically provided to your app. `useI18n` picks them up without any additional configuration.

### Using it in a component

```vue
<template>
  <div>
    <p>{{ t('greeting', { name: 'World' }) }}</p>
    <p>{{ tc('apples', 5) }}</p>
    <button @click="locale = 'fr'">Français</button>
  </div>
</template>

<script setup lang="ts">
import { useI18n } from '@i18n-micro/vue'

const { t, tc, locale } = useI18n()
</script>
```

### With Vue Router

```typescript
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import { createI18n, createVueRouterAdapter } from '@i18n-micro/vue'
import App from './App.vue'
import { routes, localesConfig, defaultLocale } from './app-config'

const router = createRouter({
  history: createWebHistory(),
  routes,
})

const routingStrategy = createVueRouterAdapter(router, localesConfig, defaultLocale)

const i18n = createI18n({
  locale: defaultLocale,
  fallbackLocale: defaultLocale,
  locales: localesConfig,
  defaultLocale,
  messages: { [defaultLocale]: {} },
  routingStrategy,
})

const app = createApp(App)
app.use(router)
app.use(i18n)
app.mount('#app')
```

## `createI18n` options

`createI18n` accepts the [shared options](/integrations/overview#shared-createi18n-options) plus a few Vue-specific extras.

| Property          | Type                                                       | Required | Default          | Description                                        |
| ----------------- | ---------------------------------------------------------- | -------- | ---------------- | -------------------------------------------------- |
| `locale`          | `string`                                                   | Yes      | —                | Initial locale.                                    |
| `fallbackLocale`  | `string`                                                   | No       | Same as `locale` | Fallback when a translation is missing.            |
| `messages`        | `Record<string, Translations>`                             | No       | `{}`             | Initial translations by locale.                    |
| `plural`          | `PluralFunc`                                               | No       | `defaultPlural`  | Custom pluralization function.                     |
| `missingWarn`     | `boolean`                                                  | No       | `true`           | Log a warning when a key is missing.               |
| `missingHandler`  | `(locale, key, routeName) => void`                         | No       | —                | Custom handler for missing translations.           |
| `locales`         | `Locale[]`                                                 | No       | —                | Locale list, auto-provided to `useI18n`.           |
| `defaultLocale`   | `string`                                                   | No       | —                | Default locale, auto-provided to `useI18n`.        |
| `routingStrategy` | `I18nRoutingStrategy`                                      | No       | —                | Router adapter for locale-aware routing.           |

`createI18n` returns an `I18nPlugin`:

- `plugin.global` is the underlying `VueI18n` instance.
- `plugin.install(app)` is the Vue plugin hook.
- `plugin.setRoutingStrategy(strategy)` attaches or replaces the router adapter after creation.

## Providing locales manually

If you need to provide locales outside of `createI18n` (for example when they are loaded async), use the injection keys directly.

```typescript
import { I18nLocalesKey, I18nDefaultLocaleKey } from '@i18n-micro/vue'

app.provide(I18nLocalesKey, locales)
app.provide(I18nDefaultLocaleKey, 'en')
```

## Router integration

### `I18nRoutingStrategy` interface

```typescript
import type { Component } from 'vue'

interface I18nRoutingStrategy {
  getCurrentPath: () => string
  linkComponent?: string | Component
  push: (target: { path: string }) => void
  replace: (target: { path: string }) => void
  resolvePath?: (to: string | { path?: string }, locale: string) => string | { path?: string }
  getRoute?: () => { fullPath: string; query: Record<string, unknown> }
}
```

### Built-in Vue Router adapter

`createVueRouterAdapter(router, locales, defaultLocale)` returns a strategy that:

- Uses `RouterLink` as `linkComponent`, so `I18nLink` renders proper Vue Router links.
- Reads `router.currentRoute.value.path` for active-state detection.
- Adds a `/<locale>` prefix for every locale except the default.
- Exposes `getRoute()` so `useLocaleHead` can emit hreflang tags.

```typescript
import { createVueRouterAdapter } from '@i18n-micro/vue'

const routingStrategy = createVueRouterAdapter(router, locales, defaultLocale)
```

### Attaching a strategy after creation

```typescript
const i18n = createI18n({ locale: 'en' })

// Later, once the router is ready
i18n.setRoutingStrategy(createVueRouterAdapter(router, locales, defaultLocale))
```

### Custom router adapter

The strategy is a plain object, so you can hand-roll adapters for any router.

```typescript
import type { I18nRoutingStrategy } from '@i18n-micro/vue'

function createCustomAdapter(customRouter): I18nRoutingStrategy {
  return {
    getCurrentPath: () => customRouter.getCurrentPath(),
    push: (target) => customRouter.navigate(target.path),
    replace: (target) => customRouter.replace(target.path),
    resolvePath: (to, locale) => {
      const path = typeof to === 'string' ? to : to.path || '/'
      return locale === 'en' ? path : `/${locale}${path}`
    },
  }
}
```

## `useI18n` composable

`useI18n()` returns the reactive translation API for use inside `setup()`.

```typescript
const {
  instance,           // Direct VueI18n instance
  locale,             // ComputedRef<string>
  getLocales,         // () => Locale[]
  defaultLocale,      // () => string
  getLocaleName,      // () => string | null

  localeRoute,        // (to, localeCode?) => string | { path?: string }
  localePath,         // (to, locale?) => string
  switchLocale,       // (newLocale) => void

  t, ts, tc, tn, td, tdr, has,
  resolveTranslations,
  setTranslation,

  setRoute, getRoute, getLocale,

  addTranslations, addRouteTranslations, mergeTranslations,
  clearCache,
} = useI18n()
```

### Translation methods

| Method   | Signature                                                                                    | Description                                          |
| -------- | -------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| `t`      | `(key, params?, defaultValue?, routeName?) => CleanTranslation`                              | Translate a key, may return non-string trees.        |
| `ts`     | `(key, params?, defaultValue?, routeName?) => string`                                        | Same as `t` but always returns a string.             |
| `tc`     | `(key, count \| params, defaultValue?) => string`                                            | Pluralization-aware translation.                     |
| `tn`     | `(value, options?: Intl.NumberFormatOptions) => string`                                      | Locale-aware number formatting.                      |
| `td`     | `(value: Date \| number \| string, options?: Intl.DateTimeFormatOptions) => string`          | Locale-aware date formatting.                        |
| `tdr`    | `(value: Date \| number \| string, options?: Intl.RelativeTimeFormatOptions) => string`      | Relative time formatting.                            |
| `has`    | `(key, routeName?) => boolean`                                                               | Check whether a key exists.                          |

```vue
<template>
  <div>
    <p>{{ t('greeting', { name: 'World' }) }}</p>
    <p>{{ tc('apples', count) }}</p>
    <p>{{ tn(1234.56, { style: 'currency', currency: 'USD' }) }}</p>
    <p>{{ td(new Date(), { dateStyle: 'full' }) }}</p>
    <p>{{ tdr(oneHourAgo, { numeric: 'auto' }) }}</p>
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue'
import { useI18n } from '@i18n-micro/vue'

const { t, tc, tn, td, tdr } = useI18n()
const count = ref(5)
const oneHourAgo = new Date(Date.now() - 3600000)
</script>
```

### Switching locales

```typescript
const { locale, switchLocale } = useI18n()

// Direct assignment updates the ref and re-renders consumers.
locale.value = 'fr'

// switchLocale also navigates through the router adapter if one is attached.
switchLocale('fr')
```

## `useLocaleHead`

`useLocaleHead` generates canonical URLs, `hreflang` alternate links, `hreflang="x-default"`, and Open Graph locale meta tags for the current route.

```typescript
interface UseLocaleHeadOptions {
  addDirAttribute?: boolean
  identifierAttribute?: string
  addSeoAttributes?: boolean
  baseUrl?: string | (() => string)
}
```

```vue
<script setup lang="ts">
import { onMounted, watch } from 'vue'
import { useRoute } from 'vue-router'
import { useLocaleHead } from '@i18n-micro/vue'

const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })

watch(() => route.path, () => updateMeta())
onMounted(() => updateMeta())
</script>
```

## Components

### `<I18nT>`

Renders a translated string with optional pluralization and formatting.

| Prop               | Type                                          | Default  | Description                             |
| ------------------ | --------------------------------------------- | -------- | --------------------------------------- |
| `keypath`          | `TranslationKey`                              | —        | Translation key (required).             |
| `plural`           | `number \| string`                            | —        | Count for pluralization.                |
| `tag`              | `string`                                      | `'span'` | Wrapping HTML tag.                      |
| `params`           | `Record<string, string \| number \| boolean>` | `{}`     | Interpolation parameters.               |
| `defaultValue`     | `string`                                      | `''`     | Fallback if key is missing.             |
| `html`             | `boolean`                                     | `false`  | Render translation as HTML.             |
| `hideIfEmpty`      | `boolean`                                     | `false`  | Hide when the translation is empty.     |
| `customPluralRule` | `PluralFunc`                                  | —        | Per-instance pluralization function.    |
| `number`           | `number \| string`                            | —        | Number to format and interpolate.       |
| `date`             | `Date \| string \| number`                    | —        | Date to format and interpolate.         |
| `relativeDate`     | `Date \| string \| number`                    | —        | Relative time to format and interpolate.|

```vue
<template>
  <I18nT keypath="welcome" tag="h1" />
  <I18nT keypath="greeting" :params="{ name: 'Vue' }" />
  <I18nT keypath="apples" :plural="5" />
  <I18nT keypath="price" :number="1234.56" />
  <I18nT keypath="date" :date="new Date()" />
  <I18nT keypath="htmlContent" html tag="div" />

  <I18nT keypath="message">
    <template #default="{ translation }">
      <strong>{{ translation }}</strong>
    </template>
  </I18nT>
</template>
```

### `<I18nLink>`

Renders a localized link. When a router adapter is attached, `I18nLink` uses its `linkComponent` (typically `RouterLink`); otherwise it falls back to a plain `<a>`.

| Prop          | Type                                                                                | Default | Description                          |
| ------------- | ----------------------------------------------------------------------------------- | ------- | ------------------------------------ |
| `to`          | `string \| { path?: string }`                                                       | —       | Target path or route object.         |
| `activeStyle` | `CSSProperties`                                                                     | `{}`    | Style applied when the link is active.|
| `localeRoute` | `(to, locale?) => string \| { path?: string }`                                      | —       | Custom locale route resolver.        |

```vue
<template>
  <I18nLink to="/">Home</I18nLink>
  <I18nLink to="/about" :active-style="{ fontWeight: 'bold' }">About</I18nLink>
  <I18nLink to="https://example.com">External</I18nLink>
</template>
```

### `<I18nSwitcher>`

Language switcher with a built-in dropdown UI. All props are optional. When omitted, values come from the injected locales and the current `useI18n` context.

Common props:

| Prop            | Type                                        | Description                                   |
| --------------- | ------------------------------------------- | --------------------------------------------- |
| `locales`       | `Locale[]`                                  | Override the injected locale list.            |
| `currentLocale` | `string \| (() => string)`                  | Override the current locale.                  |
| `getLocaleName` | `() => string \| null`                      | Display name for the current locale.          |
| `switchLocale`  | `(locale: string) => void`                  | Custom switch function.                       |
| `localeRoute`   | `(to, locale?) => string \| { path?: string }` | Custom locale route resolver.              |
| `customLabels`  | `Record<string, string>`                    | Per-locale display overrides.                 |

The component also accepts several `customButtonStyle`, `customDropdownStyle`, and `customItemStyle` props for inline styling, plus slots for `before-button`, `before-selected-locale`, `before-item`, `after-item`, and more.

```vue
<template>
  <I18nSwitcher />

  <I18nSwitcher :custom-labels="{ en: 'English', fr: 'Français' }">
    <template #before-button>
      <span>🌐 </span>
    </template>
    <template #after-item="{ locale }">
      <span class="flag">{{ getFlag(locale.code) }}</span>
    </template>
  </I18nSwitcher>
</template>
```

### `<I18nGroup>`

Groups translations under a common prefix. The default slot receives a scoped `t` that automatically prepends `prefix.`.

| Prop         | Type     | Default | Description                    |
| ------------ | -------- | ------- | ------------------------------ |
| `prefix`     | `string` | —       | Translation key prefix.        |
| `groupClass` | `string` | `''`    | CSS class on the wrapper div.  |

```vue
<template>
  <I18nGroup prefix="home">
    <template #default="{ t: groupT }">
      <h1>{{ groupT('title') }}</h1>
      <p>{{ groupT('description') }}</p>
      <p>{{ groupT('greeting', { name: 'User' }) }}</p>
    </template>
  </I18nGroup>
</template>
```

## Advanced patterns

### Route-specific translations

You can attach translations to a named route and switch the active route.

```typescript
i18n.global.addRouteTranslations('en', 'home', {
  title: 'Home Page',
  description: 'Welcome to our home page',
})

i18n.global.setRoute('home')
i18n.global.t('title') // "Home Page"
i18n.global.t('title', {}, null, 'about') // Reads from the 'about' route dictionary
```

### Dynamic translation loading

```typescript
async function loadLocaleTranslations(locale: string) {
  const messages = await import(`./locales/${locale}.json`)
  i18n.global.addTranslations(locale, messages.default, true)
}

await loadLocaleTranslations('fr')
```

### Custom pluralization

```typescript
import { createI18n } from '@i18n-micro/vue'

const i18n = createI18n({
  locale: 'ru',
  plural: (key, count) => {
    const forms = key.split(' | ')
    if (count % 10 === 1 && count % 100 !== 11) return forms[0]
    if (count % 10 >= 2 && count % 10 <= 4 && (count % 100 < 10 || count % 100 >= 20)) return forms[1]
    return forms[2] || key
  },
})
```

### Missing translation handling

```typescript
const i18n = createI18n({
  locale: 'en',
  missingWarn: true,
  missingHandler: (locale, key, routeName) => {
    // Ship to your error tracker
    console.error(`Missing: ${key} in ${locale} for route ${routeName}`)
  },
})
```

### TypeScript

All translation types come from `@i18n-micro/types` and are re-exported from `@i18n-micro/vue`.

```typescript
import type {
```

## SSR

`@i18n-micro/vue` works with any SSR setup, including Vue's official `createSSRApp` flow. The pattern is:

1. Create the app, router, and i18n instance in the server entry.
2. Resolve the current locale from the URL and pass it as `locale` to `createI18n`.
3. Attach the Vue Router adapter to the strategy so `getRoute()` works during rendering.
4. Serialize the state to `window.__INITIAL_STATE__` and rehydrate on the client with the same locale.

```typescript
// entry-server.ts
import { renderToString } from 'vue/server-renderer'
import { createSSRApp } from 'vue'
import { createMemoryHistory, createRouter } from 'vue-router'
import { createI18n, createVueRouterAdapter } from '@i18n-micro/vue'
import App from './App.vue'
import { routes, localesConfig, defaultLocale } from './app-config'

export async function render(url: string) {
  const router = createRouter({ history: createMemoryHistory(), routes })
  router.push(url)
  await router.isReady()

  const localeParam = router.currentRoute.value.params.locale as string | undefined
  const codes = localesConfig.map((l) => l.code)
  const currentLocale = localeParam && codes.includes(localeParam) ? localeParam : defaultLocale

  const routingStrategy = createVueRouterAdapter(router, localesConfig, defaultLocale)

  const i18n = createI18n({
    locale: currentLocale,
    fallbackLocale: defaultLocale,
    locales: localesConfig,
    defaultLocale,
    messages: { [currentLocale]: {} },
    routingStrategy,
  })

  const app = createSSRApp(App)
  app.use(router)
  app.use(i18n)

  const html = await renderToString(app)
  return { html, state: { locale: i18n.global.locale.value } }
}
```
