`@i18n-micro/solid` is a SolidJS binding for the `@i18n-micro/core` runtime. It exposes an `I18nProvider`, a `useI18n` primitive, and localized components that use SolidJS signals for fine-grained reactivity.

<Note>
  This package is standalone and works with `@solidjs/router`, custom routers, or no router at all. See [the overview](/integrations/overview) for how it fits in the wider `@i18n-micro` ecosystem.
</Note>

## Quick start

### Without a router

```tsx
import { render } from 'solid-js/web'
import { createI18n, I18nProvider, useI18n } from '@i18n-micro/solid'
import type { Component } from 'solid-js'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    en: {
      greeting: 'Hello, {name}!',
      apples: 'no apples | one apple | {count} apples',
    },
    fr: {
      greeting: 'Bonjour, {name}!',
      apples: 'pas de pommes | une pomme | {count} pommes',
    },
  },
})

const App: Component = () => {
  const { t, tc } = useI18n()
  return (
    <div>
      <p>{t('greeting', { name: 'World' })}</p>
      <p>{tc('apples', 5)}</p>
    </div>
  )
}

const locales = [
  { code: 'en', displayName: 'English', iso: 'en-US' },
  { code: 'fr', displayName: 'Français', iso: 'fr-FR' },
]

render(
  () => (
    <I18nProvider i18n={i18n} locales={locales} defaultLocale="en">
      <App />
    </I18nProvider>
  ),
  document.getElementById('root')!,
)
```

### With `@solidjs/router`

`createSolidRouterAdapter` uses `createSignal` and `createEffect`, so it must be called **inside a component**, not at module scope.

```tsx
import { render } from 'solid-js/web'
import { Router, Route, useNavigate, useLocation } from '@solidjs/router'
import { createI18n, I18nProvider, createSolidRouterAdapter } from '@i18n-micro/solid'
import type { Component } from 'solid-js'
import type { Locale } from '@i18n-micro/types'

const locales: Locale[] = [
  { code: 'en', displayName: 'English' },
  { code: 'fr', displayName: 'Français' },
]
const defaultLocale = 'en'

const i18n = createI18n({
  locale: defaultLocale,
  fallbackLocale: defaultLocale,
  messages: { [defaultLocale]: {} },
})

const RouterRoot: Component<{ children?: unknown }> = (props) => {
  const navigate = useNavigate()
  const location = useLocation()
  const routingStrategy = createSolidRouterAdapter(locales, defaultLocale, navigate, location)

  return (
    <I18nProvider
      i18n={i18n}
      locales={locales}
      defaultLocale={defaultLocale}
      routingStrategy={routingStrategy}
    >
      {props.children as unknown}
    </I18nProvider>
  )
}

render(
  () => (
    <Router root={RouterRoot}>
      <Route path="/" component={Home} />
      <Route path="/about" component={About} />
    </Router>
  ),
  document.getElementById('root')!,
)
```

## Core API

### `createI18n(options)`

Creates a `SolidI18n` instance. Accepts the [shared `createI18n` options](/integrations/overview#shared-createi18n-options).

```tsx
import { createI18n } from '@i18n-micro/solid'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    en: { welcome: 'Welcome', greeting: 'Hello, {name}!' },
    fr: { welcome: 'Bienvenue', greeting: 'Bonjour, {name}!' },
  },
  missingWarn: true,
  missingHandler: (locale, key, routeName) => {
    console.warn(`Missing: ${key} in ${locale} (${routeName})`)
  },
})
```

### `SolidI18n` instance

The instance exposes both getter/setter APIs and reactive accessors:

- `locale` — string getter/setter.
- `localeAccessor: Accessor<string>` — reactive accessor for the current locale.
- `fallbackLocale`, `currentRoute` — getters.
- `routeAccessor: Accessor<string>` — reactive accessor for the current route.
- `cacheStore: { root, route }` — reactive translation store.

Translation and management methods match the rest of the ecosystem:

```tsx
i18n.t('welcome')
i18n.t('greeting', { name: 'John' })
i18n.tc('apples', 5)
i18n.tn(1234.56, { style: 'currency', currency: 'USD' })
i18n.td(new Date(), { dateStyle: 'full' })
i18n.tdr(Date.now() - 3600000)
i18n.has('welcome')

i18n.addTranslations('en', { newKey: 'New' })
i18n.addRouteTranslations('en', 'home', { title: 'Home' })
i18n.setRoute('home')
i18n.clearCache()
i18n.destroy() // Dispose the reactive root, useful in tests
```

## `<I18nProvider>`

Provides the i18n instance, locales, default locale, and (optionally) the routing strategy to all descendants.

| Prop              | Type                  | Required | Description                                     |
| ----------------- | --------------------- | -------- | ----------------------------------------------- |
| `i18n`            | `SolidI18n`           | Yes      | Instance created with `createI18n`.             |
| `locales`         | `Locale[]`            | Yes      | Locale list injected into `useI18n`.            |
| `defaultLocale`   | `string`              | Yes      | Default locale.                                 |
| `routingStrategy` | `I18nRoutingStrategy` | No       | Router adapter for routing features.            |
| `children`        | `JSX.Element`         | Yes      | Descendants that consume the context.           |

Both `locales` and `defaultLocale` are required because `useI18n` reads them through the SolidJS context.

## `useI18n` primitive

```tsx
const {
  instance,        // SolidI18n
  locale,          // Accessor<string>
  getLocales,      // () => Locale[]
  defaultLocale,   // () => string
  getLocaleName,   // () => string | null

  localeRoute,     // (to, localeCode?) => string | { path?: string }
  localePath,      // (to, locale?) => string
  switchLocale,    // (newLocale: string) => void

  t, ts, tc, tn, td, tdr, has,
  setRoute, getRoute, getLocale,
  addTranslations, addRouteTranslations, clearCache,
} = useI18n()
```

`locale` is a SolidJS `Accessor<string>`, so read it as `locale()` inside JSX or reactive scopes.

```tsx
const MyComponent: Component = () => {
  const { t, tc, locale, switchLocale } = useI18n()

  return (
    <div>
      <p>Current locale: {locale()}</p>
      <p>{t('greeting', { name: 'World' })}</p>
      <p>{tc('apples', 5)}</p>
      <button onClick={() => switchLocale('fr')}>Français</button>
    </div>
  )
}
```

## Components

### `<I18nT>`

Renders translated text with pluralization and formatting.

| Prop               | Type                                          | Default  | Description                             |
| ------------------ | --------------------------------------------- | -------- | --------------------------------------- |
| `keypath`          | `TranslationKey`                              | —        | Translation key (required).             |
| `plural`           | `number \| string`                            | —        | Count for pluralization.                |
| `tag`              | `string`                                      | `'span'` | Wrapping HTML tag.                      |
| `params`           | `Record<string, string \| number \| boolean>` | `{}`     | Interpolation parameters.               |
| `defaultValue`     | `string`                                      | `''`     | Fallback if key is missing.             |
| `html`             | `boolean`                                     | `false`  | Render translation as HTML.             |
| `hideIfEmpty`      | `boolean`                                     | `false`  | Hide when the translation is empty.     |
| `customPluralRule` | `PluralFunc`                                  | —        | Per-instance pluralization function.    |
| `number`           | `number \| string`                            | —        | Number to format and interpolate.       |
| `date`             | `Date \| string \| number`                    | —        | Date to format and interpolate.         |
| `relativeDate`     | `Date \| string \| number`                    | —        | Relative time to format.                |

```tsx
import { I18nT } from '@i18n-micro/solid'
import { createMemo } from 'solid-js'

<I18nT keypath="welcome" tag="h1" />
<I18nT keypath="greeting" params={{ name: 'SolidJS' }} />
<I18nT keypath="apples" plural={5} />
<I18nT keypath="price" number={1234.56} />
<I18nT keypath="date" date={new Date()} />

const oneHourAgo = createMemo(() => new Date(Date.now() - 3600000))
<I18nT keypath="relativeDate" relativeDate={oneHourAgo()} />
```

### `<I18nLink>`

Localized link. Uses the routing strategy's `linkComponent` when available; otherwise falls back to a plain anchor.

| Prop          | Type                                                     | Default | Description                          |
| ------------- | -------------------------------------------------------- | ------- | ------------------------------------ |
| `to`          | `string \| { path?: string }`                            | —       | Target path or route object.         |
| `activeStyle` | `JSX.CSSProperties`                                      | `{}`    | Style applied when the link is active.|
| `localeRoute` | `(to, locale?) => string \| { path?: string }`           | —       | Custom locale route resolver.        |

```tsx
import { I18nLink, useI18n } from '@i18n-micro/solid'

const Nav: Component = () => {
  const { localeRoute } = useI18n()
  return (
    <>
      <I18nLink to="/">Home</I18nLink>
      <I18nLink to="/about" activeStyle={{ color: 'red', fontWeight: 'bold' }}>
        About
      </I18nLink>
      <I18nLink to="https://example.com">External</I18nLink>
      <I18nLink to="/products" localeRoute={localeRoute}>Products</I18nLink>
    </>
  )
}
```

### `<I18nSwitcher>`

Locale switcher with a built-in dropdown. All props are optional; when omitted, values come from the injected locales and current `useI18n` context.

| Prop            | Type                                             | Description                                             |
| --------------- | ------------------------------------------------ | ------------------------------------------------------- |
| `locales`       | `Locale[]`                                       | Override the injected locale list.                      |
| `currentLocale` | `string \| (() => string)`                       | Override the current locale.                            |
| `getLocaleName` | `() => string \| null`                           | Display name for the current locale.                    |
| `switchLocale`  | `(locale: string) => void`                       | Custom switch function.                                 |
| `localeRoute`   | `(to, locale?) => string \| { path?: string }`   | Custom locale route resolver.                           |
| `customLabels`  | `Record<string, string>`                         | Per-locale display overrides.                           |

```tsx
<I18nSwitcher />

<I18nSwitcher customLabels={{ en: 'English', fr: 'Français' }} />
```

### `<I18nGroup>`

Groups translation keys under a common prefix. Child `I18nT` components automatically resolve `keypath` as `prefix.keypath`.

| Prop         | Type              | Default | Description                    |
| ------------ | ----------------- | ------- | ------------------------------ |
| `prefix`     | `string`          | —       | Translation key prefix.        |
| `groupClass` | `string`          | `''`    | CSS class on the wrapper div.  |

```tsx
<I18nGroup prefix="home">
  <I18nT keypath="title" />        {/* Reads home.title */}
  <I18nT keypath="description" />  {/* Reads home.description */}
</I18nGroup>
```

## Router integration

### `I18nRoutingStrategy` interface

```typescript
import type { Accessor, Component } from 'solid-js'

interface I18nRoutingStrategy {
  getCurrentPath: () => string
  getCurrentPathAccessor?: () => Accessor<string>
  linkComponent?: string | Component
  push: (target: { path: string }) => void
  replace: (target: { path: string }) => void
  resolvePath?: (to: string | { path?: string }, locale: string) => string | { path?: string }
  getRoute?: () => { fullPath: string; query: Record<string, unknown> }
}
```

<Warning>
  In SolidJS, always implement `getCurrentPathAccessor` alongside `getCurrentPath`. Without a reactive accessor, active link states and any path-dependent UI will not update when navigation happens. `createSolidRouterAdapter` already provides it.
</Warning>

### `createSolidRouterAdapter`

The package ships an adapter for `@solidjs/router`. Call it inside a component so `createSignal` and `createEffect` bind to a reactive scope.

```tsx
import { useNavigate, useLocation } from '@solidjs/router'
import { createSolidRouterAdapter } from '@i18n-micro/solid'

const RouterRoot: Component<{ children?: unknown }> = (props) => {
  const navigate = useNavigate()
  const location = useLocation()
  const routingStrategy = createSolidRouterAdapter(locales, defaultLocale, navigate, location)

  return (
    <I18nProvider
      i18n={i18n}
      locales={locales}
      defaultLocale={defaultLocale}
      routingStrategy={routingStrategy}
    >
      {props.children as unknown}
    </I18nProvider>
  )
}
```

### Custom router adapter with signals

```tsx
import { createSignal, type Accessor } from 'solid-js'
import type { I18nRoutingStrategy } from '@i18n-micro/solid'
import type { Locale } from '@i18n-micro/types'

interface CustomRouter {
  getCurrentPath(): string
  navigate(path: string): void
  replace(path: string): void
  subscribe(callback: () => void): () => void
}

export function createCustomAdapter(
  customRouter: CustomRouter,
  locales: Locale[],
  defaultLocale: string,
): I18nRoutingStrategy & { getCurrentPathAccessor: Accessor<string> } {
  const localeCodes = locales.map((l) => l.code)
  const [pathname, setPathname] = createSignal(customRouter.getCurrentPath())

  customRouter.subscribe(() => setPathname(customRouter.getCurrentPath()))

  const resolvePath = (to: string | { path?: string }, locale: string) => {
    const path = typeof to === 'string' ? to : to.path || '/'
    const segments = path.split('/').filter(Boolean)
    if (segments.length > 0 && localeCodes.includes(segments[0])) segments.shift()
    const clean = '/' + segments.join('/')
    return locale === defaultLocale ? clean : `/${locale}${clean === '/' ? '' : clean}`
  }

  return {
    getCurrentPath: () => pathname(),
    getCurrentPathAccessor: pathname,
    push: (t) => customRouter.navigate(t.path),
    replace: (t) => customRouter.replace(t.path),
    resolvePath,
    getRoute: () => {
      const url = new URL(pathname(), 'http://localhost')
      return {
        fullPath: pathname() + url.search,
        query: Object.fromEntries(url.searchParams),
      }
    },
  }
}
```

### Query-parameter locale routing

```tsx
import { createSignal, createEffect, type Accessor } from 'solid-js'
import type { I18nRoutingStrategy } from '@i18n-micro/solid'
import type { Locale } from '@i18n-micro/types'

export function createQueryParamAdapter(
  locales: Locale[],
  defaultLocale: string,
  paramName = 'locale',
): I18nRoutingStrategy & { getCurrentPathAccessor: Accessor<string> } {
  const getCurrentPath = () => (typeof window !== 'undefined' ? window.location.pathname : '/')
  const [pathname, setPathname] = createSignal(getCurrentPath())

  if (typeof window !== 'undefined') {
    createEffect(() => {
      const update = () => setPathname(window.location.pathname)
      window.addEventListener('popstate', update)
      return () => window.removeEventListener('popstate', update)
    })
  }

  const resolvePath = (to: string | { path?: string }, locale: string) => {
    const path = typeof to === 'string' ? to : to.path || '/'
    const url = new URL(path, 'http://localhost')
    if (locale !== defaultLocale) url.searchParams.set(paramName, locale)
    else url.searchParams.delete(paramName)
    return url.pathname + url.search
  }

  return {
    getCurrentPath,
    getCurrentPathAccessor: pathname,
    push: (t) => {
      if (typeof window !== 'undefined') {
        window.history.pushState({}, '', t.path)
        window.dispatchEvent(new Event('popstate'))
      }
    },
    replace: (t) => {
      if (typeof window !== 'undefined') {
        window.history.replaceState({}, '', t.path)
        window.dispatchEvent(new Event('popstate'))
      }
    },
    resolvePath,
  }
}
```

<Tip>
  Reactive UI patterns like active links must read the path through a signal. If active states stop updating, check that your adapter provides `getCurrentPathAccessor`, and that consuming components read the accessor inside `createMemo`, `createEffect`, or JSX.
</Tip>

## Advanced patterns

### Route-scoped translations

```tsx
i18n.addRouteTranslations('en', 'home', {
  title: 'Home Page',
  description: 'Welcome to our home page',
})

i18n.setRoute('home')
i18n.t('title') // "Home Page"
```

### Dynamic loading

```tsx
async function loadLocale(locale: string) {
  const module = await import(`./locales/${locale}.json`)
  i18n.addTranslations(locale, module.default, true)
}
```

### Custom pluralization

```tsx
const i18n = createI18n({
  locale: 'ru',
  plural: (key, count) => {
    const forms = key.split(' | ')
    if (count % 10 === 1 && count % 100 !== 11) return forms[0]
    if (count % 10 >= 2 && count % 10 <= 4 && (count % 100 < 10 || count % 100 >= 20)) return forms[1]
    return forms[2] || key
  },
})
```
