title: "React"
description: "Use @i18n-micro/react to add lightweight, reactive i18n to any React 16.8+ application."
---

`@i18n-micro/react` is a React binding for the `@i18n-micro/core` runtime. It provides an `I18nProvider`, a `useI18n` hook, and localized components. Reactivity is powered by `useSyncExternalStore`, so translations and locale changes trigger the right re-renders with no extra work.

<Note>
  This package is standalone and works with React 16.8+, React Router, Next.js, TanStack Router, or no router at all. See [the overview](/integrations/overview) for how it fits in the wider `@i18n-micro` ecosystem.
</Note>

## Quick start

### Without a router

```tsx
import React from 'react'
import ReactDOM from 'react-dom/client'
import { createI18n, I18nProvider } from '@i18n-micro/react'
import App from './App'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    en: {
      greeting: 'Hello, {name}!',
      apples: 'no apples | one apple | {count} apples',
    },
    fr: {
      greeting: 'Bonjour, {name}!',
      apples: 'pas de pommes | une pomme | {count} pommes',
    },
  },
})

const localesConfig = [
  { code: 'en', displayName: 'English', iso: 'en-US' },
  { code: 'fr', displayName: 'Français', iso: 'fr-FR' },
]

const root = ReactDOM.createRoot(document.getElementById('app')!)
root.render(
  <React.StrictMode>
    <I18nProvider i18n={i18n} locales={localesConfig} defaultLocale="en">
      <App />
    </I18nProvider>
  </React.StrictMode>,
)
```

### Using it in a component

```tsx
import { useI18n } from '@i18n-micro/react'

function Home() {
  const { t, tc, tn, locale, setLocale } = useI18n()

  return (
    <div>
      <p>{t('greeting', { name: 'World' })}</p>
      <p>{tc('apples', 5)}</p>
      <p>{tn(1234.56, { style: 'currency', currency: 'USD' })}</p>
      <button onClick={() => setLocale('fr')}>Français</button>
    </div>
  )
}
```

### With React Router

React Router hooks (`useLocation`, `useNavigate`) can only run inside a component, so create the adapter inside a `RouterRoot` component that lives under `<BrowserRouter>`.

```tsx
import React from 'react'
import ReactDOM from 'react-dom/client'
import { BrowserRouter, useLocation, useNavigate } from 'react-router-dom'
import { createI18n, I18nProvider, createReactRouterAdapter } from '@i18n-micro/react'
import App from './App'
import type { Locale } from '@i18n-micro/types'

const localesConfig: Locale[] = [
  { code: 'en', displayName: 'English', iso: 'en-US' },
  { code: 'fr', displayName: 'Français', iso: 'fr-FR' },
]
const defaultLocale = 'en'

const i18n = createI18n({
  locale: defaultLocale,
  fallbackLocale: defaultLocale,
  messages: { en: {} },
})

function RouterRoot({ children }: { children?: React.ReactNode }) {
  const location = useLocation()
  const navigate = useNavigate()
  const routingStrategy = createReactRouterAdapter(localesConfig, defaultLocale, location, navigate)

  return (
    <I18nProvider
      i18n={i18n}
      locales={localesConfig}
      defaultLocale={defaultLocale}
      routingStrategy={routingStrategy}
    >
      {children}
    </I18nProvider>
  )
}

const root = ReactDOM.createRoot(document.getElementById('app')!)
root.render(
  <React.StrictMode>
    <BrowserRouter>
      <RouterRoot>
        <App />
      </RouterRoot>
    </BrowserRouter>
  </React.StrictMode>,
)
```

## Core API

### `createI18n(options)`

Creates a `ReactI18n` instance. Accepts the [shared `createI18n` options](/integrations/overview#shared-createi18n-options).

```tsx
import { createI18n } from '@i18n-micro/react'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    en: { welcome: 'Welcome', greeting: 'Hello, {name}!' },
    fr: { welcome: 'Bienvenue', greeting: 'Bonjour, {name}!' },
  },
  missingWarn: true,
  missingHandler: (locale, key, routeName) => {
    console.warn(`Missing: ${key} in ${locale} (${routeName})`)
  },
})
```

### `ReactI18n` instance

You rarely touch the instance directly. When you do, it exposes the same methods available through `useI18n`:

- `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`.
- `addTranslations`, `addRouteTranslations`, `mergeTranslations`, `clearCache`.
- `setRoute`, `getRoute`.
- `locale` and `fallbackLocale` as getters/setters. Writing to `locale` triggers a re-render for every subscribed component.

```tsx
i18n.t('welcome')                          // "Welcome"
i18n.t('greeting', { name: 'John' })       // "Hello, John!"
i18n.tc('apples', 5)                       // "5 apples"
i18n.tn(1234.56, { style: 'currency', currency: 'USD' })
i18n.td(new Date(), { dateStyle: 'full' })
i18n.tdr(Date.now() - 3600000)             // "1 hour ago"
i18n.has('welcome')                        // true
```

## `<I18nProvider>`

Wraps your app and exposes the i18n instance, locales, default locale, and (optionally) the routing strategy to all descendants.

| Prop              | Type                  | Required | Description                                     |
| ----------------- | --------------------- | -------- | ----------------------------------------------- |
| `i18n`            | `ReactI18n`           | Yes      | Instance created with `createI18n`.             |
| `locales`         | `Locale[]`            | No       | Locale list injected into `useI18n`.            |
| `defaultLocale`   | `string`              | No       | Default locale.                                 |
| `routingStrategy` | `I18nRoutingStrategy` | No       | Router adapter for routing features.            |
| `children`        | `React.ReactNode`     | Yes      | Descendants that consume the context.           |

## `useI18n` hook

`useI18n()` returns a stable object with translation methods and locale controls. It subscribes to the underlying store via `useSyncExternalStore`, so components re-render only when the values they read change.

```tsx
const {
  // State (reactive)
  locale, fallbackLocale, currentRoute,

  // Translation
  t, ts, tc, tn, td, tdr, has,

  // Locale management
  setLocale,

  // Route management
  setRoute, getRoute,

  // Routing helpers (only when a routing strategy is provided)
  switchLocale, localeRoute, localePath,

  // Translation management
  addTranslations, addRouteTranslations, clearCache,
} = useI18n()
```

### Reading and switching locale

```tsx
function LocaleControls() {
  const { locale, setLocale } = useI18n()

  return (
    <select value={locale} onChange={(e) => setLocale(e.target.value)}>
      <option value="en">English</option>
      <option value="fr">Français</option>
    </select>
  )
}
```

`setLocale` only updates the locale. If you also want to navigate to the localized path, use `switchLocale`.

### Routing helpers

When `I18nProvider` receives a `routingStrategy`, the hook exposes:

- `switchLocale(locale)` — updates the locale and navigates via the router.
- `localeRoute(to, locale?)` — returns a localized path or route object.
- `localePath(to, locale?)` — same as `localeRoute` but always returns a string.

```tsx
function Nav() {
  const { t, switchLocale, localePath } = useI18n()

  return (
    <nav>
      <a href={localePath('/')}>{t('nav.home')}</a>
      <a href={localePath('/about')}>{t('nav.about')}</a>
      <button onClick={() => switchLocale('fr')}>Français</button>
    </nav>
  )
}
```

### Complete example

```tsx
function HomePage() {
  const { t, tc, tn, td, tdr, locale, setLocale } = useI18n()

  return (
    <div>
      <h1>{t('home.title')}</h1>
      <p>{t('greeting', { name: 'World' })}</p>
      <p>{tc('apples', 5)}</p>
      <p>{t('number', { number: tn(1234.56) })}</p>
      <p>{t('date', { date: td(new Date()) })}</p>
      <p>{t('relativeDate', { relativeDate: tdr(Date.now() - 86400000) })}</p>

      <button onClick={() => setLocale(locale === 'en' ? 'fr' : 'en')}>
        Toggle locale
      </button>
    </div>
  )
}
```

## Components

### `<I18nT>`

Renders translated text with pluralization and formatting.

| Prop           | Type                       | Default  | Description                        |
| -------------- | -------------------------- | -------- | ---------------------------------- |
| `keypath`      | `string`                   | —        | Translation key (required).        |
| `params`       | `Params`                   | `{}`     | Interpolation parameters.          |
| `plural`       | `number \| string`         | —        | Count for pluralization.           |
| `defaultValue` | `string`                   | `''`     | Fallback if key is missing.        |
| `tag`          | `string`                   | `'span'` | Wrapping HTML tag.                 |
| `html`         | `boolean`                  | `false`  | Render translation as HTML.        |
| `number`       | `number \| string`         | —        | Number to format and interpolate.  |
| `date`         | `Date \| string \| number` | —        | Date to format and interpolate.    |
| `relativeDate` | `Date \| string \| number` | —        | Relative time to format.           |

```tsx
import { I18nT } from '@i18n-micro/react'

<I18nT keypath="welcome" tag="h1" />
<I18nT keypath="greeting" params={{ name: 'React' }} />
<I18nT keypath="apples" plural={5} />
<I18nT keypath="price" number={1234.56} />
<I18nT keypath="date" date={new Date()} />
<I18nT keypath="htmlContent" html />
```

### `<I18nLink>`

Localized link. When a routing strategy provides a `linkComponent`, `I18nLink` uses it (for example, `Link` from `react-router-dom`). Otherwise it renders a plain `<a>` with an `onClick` handler that calls `push`.

| Prop           | Type                                                     | Description                                            |
| -------------- | -------------------------------------------------------- | ------------------------------------------------------ |
| `to`           | `string \| { path?: string }`                            | Target path or route object (required).                |
| `activeStyle`  | `React.CSSProperties`                                    | Style applied when the link matches the active path.   |
| `localeRoute`  | `(to, locale?) => string \| { path?: string }`           | Custom locale route resolver.                          |
| `...restProps` | `React.AnchorHTMLAttributes<HTMLAnchorElement>`          | Any other anchor attributes.                           |

```tsx
<I18nLink to="/about">About</I18nLink>

<I18nLink
  to="/"
  activeStyle={{ fontWeight: 'bold', backgroundColor: '#e8f5e9' }}
>
  Home
</I18nLink>

<I18nLink to="https://example.com">External</I18nLink>
```

### `<I18nSwitcher>`

Locale switcher. Uses the injected locales and current locale by default, and can be fully customized through props.

| Prop            | Type                                             | Description                                             |
| --------------- | ------------------------------------------------ | ------------------------------------------------------- |
| `locales`       | `Locale[]`                                       | Override the injected locale list.                      |
| `currentLocale` | `string \| (() => string)`                       | Override the current locale.                            |
| `getLocaleName` | `() => string \| null`                           | Display name for the current locale.                    |
| `switchLocale`  | `(locale: string) => void`                       | Custom switch function.                                 |
| `localeRoute`   | `(to, locale?) => string \| { path?: string }`   | Custom locale route resolver.                           |
| `customLabels`  | `Record<string, string>`                         | Per-locale display overrides.                           |
| `...restProps`  | `React.HTMLAttributes<HTMLDivElement>`           | Any other div attributes.                               |

```tsx
<I18nSwitcher />

<I18nSwitcher
  customLabels={{ en: 'English', fr: 'Français', de: 'Deutsch' }}
/>
```

### `<I18nGroup>`

Groups translation keys under a common prefix. Child `I18nT` components resolve their `keypath` as `prefix.keypath`.

| Prop         | Type              | Default | Description                    |
| ------------ | ----------------- | ------- | ------------------------------ |
| `prefix`     | `string`          | —       | Translation key prefix.        |
| `groupClass` | `string`          | `''`    | CSS class on the wrapper div.  |
| `children`   | `React.ReactNode` | —       | Children that use the prefix.  |

```tsx
<I18nGroup prefix="home">
  <I18nT keypath="title" />        {/* Reads home.title */}
  <I18nT keypath="description" />  {/* Reads home.description */}
</I18nGroup>
```

## Router integration

### `I18nRoutingStrategy` interface

```typescript
import type React from 'react'

interface I18nRoutingStrategy {
  getCurrentPath: () => string
  linkComponent?: string | React.ComponentType<{
    href: string
    children?: React.ReactNode
    style?: React.CSSProperties
    className?: string
    [key: string]: unknown
  }>
  push: (target: { path: string }) => void
  replace: (target: { path: string }) => void
  resolvePath?: (to: string | { path?: string }, locale: string) => string | { path?: string }
  getRoute?: () => { fullPath: string; query: Record<string, unknown> }
}
```

### `createReactRouterAdapter`

The package ships an adapter for `react-router-dom`. Call it inside a component so `useLocation` and `useNavigate` work.

```tsx
import { useLocation, useNavigate } from 'react-router-dom'
import { createReactRouterAdapter } from '@i18n-micro/react'

function RouterRoot({ children }: { children?: React.ReactNode }) {
  const location = useLocation()
  const navigate = useNavigate()
  const routingStrategy = createReactRouterAdapter(localesConfig, defaultLocale, location, navigate)

  return (
    <I18nProvider i18n={i18n} locales={localesConfig} defaultLocale={defaultLocale} routingStrategy={routingStrategy}>
      {children}
    </I18nProvider>
  )
}
```

### Next.js App Router adapter

```tsx
'use client'

import React from 'react'
import Link from 'next/link'
import { usePathname, useRouter } from 'next/navigation'
import type { I18nRoutingStrategy } from '@i18n-micro/react'
import type { Locale } from '@i18n-micro/types'

export function createNextJsRouterAdapter(
  locales: Locale[],
  defaultLocale: string,
  pathname: string,
  router: ReturnType<typeof useRouter>,
): I18nRoutingStrategy {
  const localeCodes = locales.map((l) => l.code)

  const resolvePath = (to: string | { path?: string }, locale: string) => {
    const path = typeof to === 'string' ? to : to.path || '/'
    const segments = path.split('/').filter(Boolean)
    if (segments.length > 0 && localeCodes.includes(segments[0])) segments.shift()
    const clean = '/' + segments.join('/')
    return locale === defaultLocale ? clean : `/${locale}${clean === '/' ? '' : clean}`
  }

  return {
    linkComponent: (props) => {
      const { href, children, className, style, ...rest } = props
      return React.createElement(Link, { href, className, style, ...rest }, children)
    },
    getCurrentPath: () => pathname,
    push: (target) => router.push(target.path),
    replace: (target) => router.replace(target.path),
    resolvePath,
    getRoute: () => {
      const url = new URL(pathname, 'http://localhost')
      return { fullPath: pathname, query: Object.fromEntries(url.searchParams) }
    },
  }
}
```

Use it in a client layout:

```tsx
'use client'

function RouterRoot({ children }: { children: React.ReactNode }) {
  const pathname = usePathname()
  const router = useRouter()
  const routingStrategy = createNextJsRouterAdapter(localesConfig, defaultLocale, pathname, router)

  return (
    <I18nProvider i18n={i18n} locales={localesConfig} defaultLocale={defaultLocale} routingStrategy={routingStrategy}>
      {children}
    </I18nProvider>
  )
}
```

### TanStack Router adapter

```tsx
import React from 'react'
import { Link, useLocation, useRouter } from '@tanstack/react-router'
import type { I18nRoutingStrategy } from '@i18n-micro/react'
import type { Locale } from '@i18n-micro/types'

export function createTanStackRouterAdapter(
  locales: Locale[],
  defaultLocale: string,
  router: ReturnType<typeof useRouter>,
  location: ReturnType<typeof useLocation>,
): I18nRoutingStrategy {
  const localeCodes = locales.map((l) => l.code)

  const resolvePath = (to: string | { path?: string }, locale: string) => {
    const path = typeof to === 'string' ? to : to.path || '/'
    const segments = path.split('/').filter(Boolean)
    if (segments.length > 0 && localeCodes.includes(segments[0])) segments.shift()
    const clean = '/' + segments.join('/')
    return locale === defaultLocale ? clean : `/${locale}${clean === '/' ? '' : clean}`
  }

  return {
    linkComponent: (props) => {
      const { href, children, className, style, ...rest } = props
      return React.createElement(Link, { to: href, className, style, ...rest }, children)
    },
    getCurrentPath: () => location.pathname,
    push: (target) => router.navigate({ to: target.path }),
    replace: (target) => router.navigate({ to: target.path, replace: true }),
    resolvePath,
    getRoute: () => ({
      fullPath: location.pathname + location.search,
      query: Object.fromEntries(new URLSearchParams(location.search)),
    }),
  }
}
```

### Query-parameter locale routing

```tsx
export function createQueryParamAdapter(
  locales: Locale[],
  defaultLocale: string,
  getCurrentPath: () => string,
  navigate: (path: string, opts?: { replace?: boolean }) => void,
  paramName = 'locale',
): I18nRoutingStrategy {
  const resolvePath = (to: string | { path?: string }, locale: string) => {
    const path = typeof to === 'string' ? to : to.path || '/'
    const url = new URL(path, 'http://localhost')
    if (locale !== defaultLocale) url.searchParams.set(paramName, locale)
    else url.searchParams.delete(paramName)
    return url.pathname + url.search
  }

  return {
    getCurrentPath,
    push: (t) => navigate(t.path),
    replace: (t) => navigate(t.path, { replace: true }),
    resolvePath,
  }
}
```

### Custom adapter tips

- The only strictly required method is `getCurrentPath`. Everything else is optional but recommended.
- Preserve query strings and hash fragments in `resolvePath`.
- Decide up front whether the default locale appears in the URL. The built-in adapters treat it as prefix-less.
- Test edge cases: empty paths, locale-shaped segments in your routes, and locale codes with region tags (like `pt-BR`).

## Advanced patterns

### Route-scoped translations

```tsx
i18n.addRouteTranslations('en', 'home', {
  title: 'Home Page',
  description: 'Welcome to our home page',
})

i18n.setRoute('home')
i18n.t('title') // "Home Page"
```

### Dynamic loading

```tsx
async function loadLocale(locale: string) {
  const module = await import(`./locales/${locale}.json`)
  i18n.addTranslations(locale, module.default, true)
}
```

### Custom pluralization

```tsx
const i18n = createI18n({
  locale: 'ru',
  plural: (key, count) => {
    const forms = key.split(' | ')
    if (count % 10 === 1 && count % 100 !== 11) return forms[0]
    if (count % 10 >= 2 && count % 10 <= 4 && (count % 100 < 10 || count % 100 >= 20)) return forms[1]
    return forms[2] || key
  },
})
```
