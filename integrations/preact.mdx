---

`@i18n-micro/preact` brings the Nuxt I18n Micro core to standalone Preact applications. It ships a reactive `useI18n` hook, ready-made components (`<I18nLink>`, `<I18nT>`, `<I18nSwitcher>`, `<I18nGroup>`), and a small router-adapter interface so you can plug in any Preact router or none at all.

- **Router-agnostic**: works with `wouter-preact`, `preact-router`, or the History API.
- **Reactive**: hook-based updates when the locale or messages change.
- **Full core**: pluralization, number/date/relative formatting, route-specific translations.

## Quick start

Wrap your app with `<I18nProvider>` and pass an instance created with `createI18n`:

```tsx src/main.tsx
import { render, h } from 'preact'
import { createI18n, I18nProvider } from '@i18n-micro/preact'
import App from './App'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    en: {
      greeting: 'Hello, {name}!',
      apples: 'no apples | one apple | {count} apples',
    },
    fr: {
      greeting: 'Bonjour, {name}!',
      apples: 'pas de pommes | une pomme | {count} pommes',
    },
  },
})

const locales = [
  { code: 'en', displayName: 'English', iso: 'en-US' },
  { code: 'fr', displayName: 'Français', iso: 'fr-FR' },
]

render(
  h(
    I18nProvider,
    { i18n, locales, defaultLocale: 'en' },
    h(App),
  ),
  document.getElementById('app')!,
)
```

Use translations from any child component:

```tsx src/App.tsx
import { h } from 'preact'
import { useI18n } from '@i18n-micro/preact'

export default function App() {
  const { t, tc, tn, locale, setLocale } = useI18n()

  return h(
    'div',
    null,
    h('p', null, t('greeting', { name: 'World' })),
    h('p', null, tc('apples', 5)),
    h('p', null, tn(1234.56)),
    h('button', { onClick: () => setLocale(locale === 'en' ? 'fr' : 'en') }, 'Toggle locale'),
  )
}
```

<Tip>
The examples use `h()` calls to stay compatible with any JSX runtime. If you configure Preact's JSX pragma, you can write standard JSX instead.
</Tip>

## createI18n

```typescript
import { createI18n } from '@i18n-micro/preact'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en: { welcome: 'Welcome' }, fr: { welcome: 'Bienvenue' } },
  missingWarn: true,
  missingHandler: (locale, key, routeName) => {
    console.warn(`Missing translation: ${key} in ${locale} for route ${routeName}`)
  },
})
```

The returned `PreactI18n` instance exposes the full translation API (`t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`, `addTranslations`, `addRouteTranslations`, `setRoute`, `getRoute`, `clearCache`) and mutable `locale` and `fallbackLocale` properties.

See [the shared API methods](/api/methods) for behavior details.

## I18nProvider

`<I18nProvider>` publishes the i18n instance, the locale list, the default locale, and an optional routing strategy through Preact context.

| Prop              | Type                       | Required | Description                                 |
| ----------------- | -------------------------- | -------- | ------------------------------------------- |
| `i18n`            | `PreactI18n`               | Yes      | Instance returned from `createI18n`         |
| `locales`         | `Locale[]`                 | No       | Locale metadata used by `<I18nSwitcher>`    |
| `defaultLocale`   | `string`                   | No       | Locale that stays prefix-less in URLs       |
| `routingStrategy` | `I18nRoutingStrategy`      | No       | Router adapter for `<I18nLink>` and routing |
| `children`        | `preact.ComponentChildren` | Yes      | Your app tree                               |

## useI18n hook

`useI18n()` returns a live snapshot that re-renders when the locale or translations change:

```tsx
import { useI18n } from '@i18n-micro/preact'

function Greeting() {
  const {
    // Reactive properties
    locale,
    fallbackLocale,
    currentRoute,

    // Translation methods
    t, ts, tc, tn, td, tdr, has,

    // Locale + route management
    setLocale, setRoute, getRoute,

    // Router helpers (only when routingStrategy is provided)
    switchLocale, localeRoute, localePath,

    // Translation management
    addTranslations, addRouteTranslations, clearCache,
  } = useI18n()

  return <span>{t('greeting', { name: 'World' })}</span>
}
```

<Note>
`t` returns `CleanTranslation`, which may be a string, number, or object depending on the JSON value. Use `ts` when you need a guaranteed string.
</Note>

### Switching locales

```tsx
function LocaleToggle() {
  const { locale, setLocale } = useI18n()
  return (
    <button onClick={() => setLocale(locale === 'en' ? 'fr' : 'en')}>
      {locale}
    </button>
  )
}
```

When a routing strategy is present, use `switchLocale` instead to navigate to the localized URL:

```tsx
const { switchLocale } = useI18n()
switchLocale('fr') // navigates to /fr/current-path
```

## Components

### I18nT

Translate inline with pluralization, formatting, and HTML support.

| Prop           | Type                       | Default  | Description                     |
| -------------- | -------------------------- | -------- | ------------------------------- |
| `keypath`      | `string`                   | required | Translation key                 |
| `params`       | `Params`                   | `{}`     | Interpolation values            |
| `plural`       | `number \| string`         | -        | Count used for pluralization    |
| `defaultValue` | `string`                   | `''`     | Fallback when the key is missing |
| `tag`          | `string`                   | `'span'` | Wrapper element                 |
| `html`         | `boolean`                  | `false`  | Render translation as HTML      |
| `number`       | `number \| string`         | -        | Formats and injects a number    |
| `date`         | `Date \| string \| number` | -        | Formats and injects a date      |
| `relativeDate` | `Date \| string \| number` | -        | Formats and injects relative time |

```tsx
import { h } from 'preact'
import { I18nT } from '@i18n-micro/preact'

h(I18nT, { keypath: 'greeting', params: { name: 'John' } })
h(I18nT, { keypath: 'apples', plural: 5 })
h(I18nT, { keypath: 'price', number: 1234.56 })
h(I18nT, { keypath: 'html', html: true, tag: 'p' })
```

### I18nLink

Localized anchor that automatically prepends the current locale prefix.

```tsx
import { h } from 'preact'
import { I18nLink } from '@i18n-micro/preact'

h(I18nLink, { to: '/about' }, 'About')

h(
  I18nLink,
  {
    to: '/',
    activeStyle: { fontWeight: 'bold' },
  },
  'Home',
)
```

If the injected `routingStrategy` exposes a `linkComponent` (for example `Link` from `wouter-preact`), `<I18nLink>` renders it. Otherwise it falls back to a native `<a>` that calls `push()`.

### I18nSwitcher

Renders a dropdown of every available locale using the injected `locales` and routing strategy.

```tsx
import { h } from 'preact'
import { I18nSwitcher } from '@i18n-micro/preact'

h(I18nSwitcher)

h(I18nSwitcher, {
  customLabels: { en: 'English', fr: 'Français' },
})
```

You can override any prop individually (`locales`, `currentLocale`, `switchLocale`, `localeRoute`, `getLocaleName`).

### I18nGroup

Groups children under a shared key prefix.

```tsx
import { h } from 'preact'
import { I18nGroup, I18nT } from '@i18n-micro/preact'

h(
  I18nGroup,
  { prefix: 'home' },
  h(I18nT, { keypath: 'title' }),        // resolves to home.title
  h(I18nT, { keypath: 'description' }),  // resolves to home.description
)
```

## Router integration

The `I18nRoutingStrategy` interface decouples i18n from any specific router:

```typescript
interface I18nRoutingStrategy {
  getCurrentPath: () => string
  linkComponent?: string | ComponentType<{ href: string; [key: string]: unknown }>
  push: (target: { path: string }) => void
  replace: (target: { path: string }) => void
  resolvePath?: (to: string | { path?: string }, locale: string) => string | { path?: string }
  getRoute?: () => { fullPath: string; query: Record<string, unknown> }
}
```

### Built-in History adapter

`createPreactRouterAdapter` (also exported as `createBrowserHistoryAdapter`) uses the native History API and works with any router that responds to `popstate` events:

```tsx
import { render, h } from 'preact'
import {
  createI18n,
  I18nProvider,
  createPreactRouterAdapter,
} from '@i18n-micro/preact'

const locales = [
  { code: 'en', displayName: 'English', iso: 'en-US' },
  { code: 'fr', displayName: 'Français', iso: 'fr-FR' },
]

const i18n = createI18n({ locale: 'en', fallbackLocale: 'en', messages: { en: {} } })
const routingStrategy = createPreactRouterAdapter(locales, 'en')

render(
  h(
    I18nProvider,
    { i18n, locales, defaultLocale: 'en', routingStrategy },
    h(App),
  ),
  document.getElementById('app')!,
)
```

### Wouter adapter

Build the adapter from `useLocation()` so `getCurrentPath` and `push` react to `wouter-preact`:

```tsx
import { Router, useLocation, Link } from 'wouter-preact'
import type { I18nRoutingStrategy } from '@i18n-micro/preact'
import type { Locale } from '@i18n-micro/types'

function createWouterAdapter(
  locales: Locale[],
  defaultLocale: string,
  path: string,
  navigate: (to: string, options?: { replace?: boolean }) => void,
): I18nRoutingStrategy {
  const codes = locales.map((l) => l.code)
  const resolve = (to: string | { path?: string }, locale: string) => {
    const raw = typeof to === 'string' ? to : to.path || '/'
    const segments = raw.split('/').filter(Boolean)
    if (segments[0] && codes.includes(segments[0])) segments.shift()
    const clean = '/' + segments.join('/')
    return locale === defaultLocale ? clean : `/${locale}${clean === '/' ? '' : clean}`
  }

  return {
    linkComponent: Link as never,
    getCurrentPath: () => path,
    push: (t) => navigate(t.path),
    replace: (t) => navigate(t.path, { replace: true }),
    resolvePath: resolve,
    getRoute: () => ({
      fullPath: path,
      query: Object.fromEntries(new URLSearchParams(window.location.search)),
    }),
  }
}
```

Wire it into `<I18nProvider>` inside a `<Router>` boundary so `useLocation` is available.

## Signals and hooks integration

`useI18n` uses `useState` + `useEffect` internally to trigger re-renders. That means it composes with Preact's built-in hooks (`useMemo`, `useCallback`, `useEffect`) and with `@preact/signals` derivations:

```tsx
import { useMemo } from 'preact/hooks'
import { computed } from '@preact/signals'
import { useI18n } from '@i18n-micro/preact'

function ProductCard({ price }: { price: number }) {
  const { t, tn, locale } = useI18n()

  // Recomputes when locale changes because `tn` closes over the current locale
  const formatted = useMemo(() => tn(price, { style: 'currency', currency: 'USD' }), [price, locale])

  return <p>{t('product.price', { price: formatted })}</p>
}
```

For DevTools integration, pair the Vite plugin from [`@i18n-micro/devtools-ui`](/integrations/devtools-ui) with any adapter that mirrors the same API surface.
