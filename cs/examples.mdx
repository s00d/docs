# 📚 Příklady a použití Nuxt I18n Micro

Tato sekce nabízí různé příklady demonstrující, jak ve své Nuxt.js aplikaci používat `Nuxt I18n Micro`. Uvidíte, jak přepínat locale, používat komponenty `<i18n-link>`, `<i18n-switcher>` a `<i18n-t>` a dynamicky pracovat s klíči překladů.

## 🛠️ Základní nastavení

Zde je základní nastavení pro začátek s `Nuxt I18n Micro`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Přepínání locale

### Programové přepínání locale

Tento příklad ukazuje, jak programově přepínat locale pomocí tlačítek:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Ukázkový JSON pro přepínání locale

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### Použití komponenty `<i18n-switcher>`

Komponenta `<i18n-switcher>` poskytuje rozbalovací nabídku pro přepínání locale s možností nastavit vlastní popisky:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 🌐 Použití `<i18n-link>` pro lokalizovanou navigaci

Komponenta `<i18n-link>` automaticky řeší routování specifické pro dané locale:

```vue
<template>
  <div>
    <i18n-link to="/about">{{ $t('about') }}</i18n-link>
    <i18n-link :to="{ name: 'index' }">{{ $t('home') }}</i18n-link>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Ukázkový JSON pro navigační odkazy

```json
{
  "about": "About Us",
  "home": "Home"
}
```

### Příklad se stylováním aktivního odkazu

```vue
  </div>
</template>
```

### Ukázkový JSON pro stylování aktivního odkazu

Pro tento scénář lze použít stejný JSON soubor jako v předchozím příkladu.

## 📝 Vykreslování dynamických klíčů ze souborů s překlady

V některých případech můžete chtít iterovat přes dynamické klíče uložené v souborech s překlady a podmíněně vykreslovat jejich hodnoty. Následující příklad ukazuje, jak toho dosáhnout pomocí `Nuxt I18n Micro`.

### Příklad: Vykreslování dynamických klíčů

Tento příklad načítá pole klíčů z konkrétní cesty překladu (v tomto případě `dynamic`) a iteruje přes ně. Existence každého klíče se kontroluje pomocí `$has` před vykreslením jeho hodnoty pomocí `$t`.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Ukázkový soubor s překlady (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Příklad: Vykreslování dynamických klíčů z objektu

V tomto příkladu pracujeme s objektem uloženým v souboru s překlady. Načteme a iterujeme přes klíče objektu a dynamicky vykreslíme jak názvy klíčů, tak jejich přidružené hodnoty.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Ukázkový soubor s překlady (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 Použití `<i18n-t>` pro překlady se sloty a interpolací

Komponenta `<i18n-t>` je užitečná pro vykreslování překladů s dynamickým obsahem a HTML tagy:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### Ukázkový JSON pro `<i18n-t>`

```json
{
  "greeting": "Welcome to the page"
}
```

### S interpolací

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### Ukázkový JSON pro interpolaci

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 Použití `$tc` pro pluralizaci

Funkce `$tc` v `Nuxt I18n Micro` zpracovává pluralizaci na základě počtu a nastavení locale. Hodí se pro dynamické přizpůsobení zpráv obsahujících počty, například položek, oznámení nebo dalších entit, jejichž počet se mění.

### Příklad: Použití `$tc` pro pluralizaci

V následujícím příkladu zobrazíme zprávu s počtem jablek pomocí `$tc`. Klíč překladu ošetří několik plurálních forem v závislosti na zadaném počtu.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### Ukázkový JSON pro pluralizaci

Takto můžete definovat překlad v JSON souboru, aby zpracoval různé plurálové formy:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Vysvětlení

- **`$tc('apples', 0)`**: Vrací první tvar, používá se, když je počet nula (`"no apples"`).
- **`$tc('apples', 1)`**: Vrací druhý tvar, používá se, když je počet jedna (`"one apple"`).
- **`$tc('apples', 10)`**: Vrací třetí tvar s hodnotou počtu, používá se, když je počet dvě nebo více (`"10 apples"`).

### Další příklad se složitější pluralizací

Pokud vaše aplikace potřebuje zpracovávat složitější pravidla pluralizace (například specifické případy pro nulu, jednu, dvě, několik, mnoho a ostatní), můžete odpovídajícím způsobem rozšířit řetězce překladů:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: Lze nastavit tak, aby vracelo `"two apples"`.
- **`$tc('apples', 3)`**: Může vracet `"a few apples"`, podle pravidel definovaných pro počet.

## 🌐 Použití `$tn` pro formátování čísel

Funkce `$tn` formátuje čísla podle aktuálního locale pomocí API `Intl.NumberFormat`. Hodí se pro zobrazování čísel ve formátu odpovídajícím regionálnímu nastavení uživatele, například měn, procent či dalších číselných formátů.

### Příklad: Použití `$tn` pro formátování čísel

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ Použití `$td` pro formátování data a času

Funkce `$td` formátuje data a časy podle aktuálního locale pomocí API `Intl.DateTimeFormat`. Hodí se pro zobrazení dat a časů ve formátech, které jsou uživateli známé podle jeho nastavení locale.

### Příklad: Použití `$td` pro formátování data a času

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ Použití `$tdr` pro relativní formátování data

Funkce `$tdr` formátuje data jako relativní čas (například „před 5 minutami“, „před 2 dny“) podle aktuálního locale pomocí API `Intl.RelativeTimeFormat`. Hodí se pro zobrazení časových rozdílů vzhledem k aktuálnímu datu a času.

### Příklad: Použití `$tdr` pro relativní formátování data

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
