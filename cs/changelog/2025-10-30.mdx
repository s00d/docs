**Datum**: 2025-10-30

**Verze**: `v2.0.0`

![Vydání v2.0.0](/images/2.0.0.png)

Představujeme serverové HMR pro soubory překladů ve vývoji. Když se změní JSON překlad, serverová cache zneplatní pouze dotčené klíče a následující požadavky okamžitě dostanou čerstvá data — bez nutnosti restartu.

## Co je nového? {#what’s-new}

- Serverové HMR pro soubory překladů
- Okamžité zneplatnění cache pro stránku/locale
- Plynulý vývojářský zážitek při úpravách obsahu

## Jak to funguje {#how-it-works}

- Watcher v `src/runtime/server/plugins/watcher.dev.ts` sleduje `<rootDir>/<translationDir>/**/*.json`
- Soubory stránek (např. `pages/<page>/<locale>.json`) zneplatní `_locales:merged:<page>:<locale>`
- Kořenové soubory (např. `<locale>.json`) zneplatní všechny sloučené klíče daného locale
- Automaticky registrováno z `src/module.ts` ve vývoji, když `experimental.hmr !== false`

## Konfigurace {#configuration}

```ts
export default defineNuxtConfig({
  i18n: {
    experimental: { hmr: true }, // default in dev
  },
})
```
