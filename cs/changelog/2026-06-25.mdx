Toto vydání přidává **`useI18nHead`** — composable na úrovni stránky pro přepsání i18n SEO nad rámec vestavěného pluginu `02.meta`. Upravte `hreflang`, canonical, `og:url` a tagy Open Graph pro každou routu bez vlastního meta pluginu nebo `meta: false`.

## Co je nového? {#what’s-new}

### Composable `useI18nHead` {#usei18nhead-composable}

Zavolejte `useI18nHead` na libovolné stránce, když je `meta: true` (výchozí). Modul sloučí váš vstup po `useLocaleHead` při každé aktualizaci routy:

```vue
<script setup lang="ts">
useI18nHead(() => ({
  meta: [{ property: 'og:title', content: article.value?.title }],
  replace: {
    canonical: article.value?.canonicalUrl,
    ogUrl: article.value?.canonicalUrl,
    hreflang: localeCodes.map((locale) => ({
      rel: 'alternate',
      hreflang: locale,
      href: article.value!.locales[locale]!,
    })),
    ogAlternates: localeCodes,
  },
}))
</script>
```

Podporuje statické objekty, reaktivní gettery, připojení `meta` / `link`, `replace` pro vestavěné skupiny a `disable` pro odstranění automaticky generovaných tagů. Viz [`useI18nHead`](/cs/composables/useI18nHead).

### Utilita `mergeI18nHead` (`@i18n-micro/utils`) {#mergei18nhead-utility-@i18n-micro/utils}

Logika slučování nezávislá na frameworku je v `@i18n-micro/utils/merge-i18n-head` — používá ji plugin `02.meta` a lze ji testovat izolovaně. Typy (`I18nHeadInput`, `I18nHeadLink`, `I18nHeadMeta`) jsou exportovány z `@i18n-micro/types`.

### Integrace pluginů {#plugin-integration}

- **`02.meta`** — slučuje výstup `useLocaleHead` se stavem stránky z `useI18nHead` přes `useHead`
- **`01.plugin`** — při změně názvu routy resetuje přepsání stránky přes `resetPageHead()` (sdílený stav s composablem)

### Dokumentace a testy {#documentation-&-tests}

- Nový průvodce: [`useI18nHead`](/cs/composables/useI18nHead) s příklady pro CMS/články
- Aktualizované [SEO](/cs/guide/seo) a [`useLocaleHead`](/cs/composables/useLocaleHead) — kdy použít které API
- Pokrytí testy Playwright + Vitest: SSR, SPA navigace, reload, `nuxi generate`, částečné alternativy, `x-default`, reaktivní načtení na klientu

## Typické případy použití {#typical-use-cases}

| Scénář                                       | Přístup                                                        |
| -------------------------------------------- | -------------------------------------------------------------- |
| Blog/CMS s částečnými překlady               | `replace.hreflang` + `replace.ogAlternates` z lokalizací API   |
| Vlastní canonical z CMS                      | `replace.canonical` + `replace.ogUrl`                          |
| Pouze OG na landing page                     | `meta: [{ property: 'og:title', ... }]` — ponechat hreflang modulu |
| Žádný hreflang na stránce                    | `disable: ['hreflang', 'x-default']`                           |
| Nahrazení vlastního pluginu (`i18nManualHreflang`) | `useI18nHead` na každé obsahové stránce + `meta: true`   |

**JSON-LD** zůstává v `useHead({ script: [...] })` — `useI18nHead` negeneruje strukturovaná data.

## Zpětně nekompatibilní změny {#breaking-changes}

Žádné pro standardní použití `nuxt.config`. Nový composable a podcesta utils jsou pouze doplňkové.

## Proč na tom záleží {#why-it-matters}

- **Žádný vlastní meta plugin** pro příspěvky z CMS, novinky nebo průvodce s URL pro jednotlivé lokalizace
- **Jediný pipeline** — výchozí hodnoty modulu + přepsání stránky v jednom volání `useHead`
- **Typová bezpečnost** — `I18nHeadInput` pro helpery jako `buildArticleHead(content)`
