---
title: "useLocaleHead"
description: "useLocaleHead sestaví i18n SEO tagy (lang, dir, canonical, hreflang, og:locale) jako objekt, který předáte do useHead."
---

`useLocaleHead()` sestaví i18n tagy hlavičky pro aktuální routu: `lang` a `dir` na `<html>`, kanonický odkaz, alternativy `hreflang` s `x-default`, `og:url`, `og:locale` a `og:locale:alternate`. Použijte ho, když nastavíte [`meta: false`](/cs/api/module-options#meta) a `useHead` spravujete sami; s `meta: true` modul tyto tagy registruje už sám a změny pro jednotlivé stránky se provádějí přes [`useI18nHead`](/cs/composables/useI18nHead).

## Signatura {#signature}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { build: () => LocaleHead; metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }, LocaleHead | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

SEO tagy hlavičky pro aktuální routu: alternativy `hreflang` pro každé locale plus
`x-default`, kanonický odkaz, `og:locale` a `lang`/`dir` na `<html>`.

Potřebné jen tehdy, když je `meta` vypnuté nebo je třeba upravit výchozí hodnoty — s `meta: true`
modul registruje stejné tagy sám.

| Parametr | Typ | Popis |
| --- | --- | --- |
| `options` | `UseLocaleHeadOptions` |  |

**Vrací** — `metaObject`, ref s objektem hlavičky připraveným k předání do `useHead`; `updateMeta` ho obnoví; `build` vypočítá objekt hlavičky z aktuální routy (reaktivní při čtení v getteru, např. `useHead(() => build())`)

```ts
const { metaObject } = useLocaleHead({ addSeoAttributes: true })
useHead(metaObject)
```

## Možnosti {#options}

| Možnost | Výchozí | Popis |
| --- | --- | --- |
| `addDirAttribute` | `true` | Nastaví `dir` na `<html>` podle `dir` daného locale (`'auto'`, pokud ho nemá). |
| `identifierAttribute` | `'id'` | Atribut, který slouží jako klíč každého tagu (`i18n-can`, `i18n-og`, `i18n-alternate-<hreflang>`, …), aby aktualizace tagy nahrazovaly, a ne přidávaly. |
| `addSeoAttributes` | `true` | Vygeneruje tagy canonical, `hreflang` a `og:`. `false` ponechá pouze `htmlAttrs`. |
| `baseUrl` | `'/'` | Origin připojený ke každé URL. Pro relativní URL ponechte `'/'`; pro absolutní předejte `'https://example.com'`. |
| `autoUpdate` | `true` | Znovu sestaví `metaObject`, když se změní routa nebo stav `i18n-locale`. |

## Co generuje {#what-it-emits}

- Nic na routě bez shody (404) nebo s `disableMeta` pro aktivní locale.
- Canonical a `og:url`: `$switchLocalePath(<active locale>)`, query zredukované na [`canonicalQueryWhitelist`](/cs/api/module-options#canonicalquerywhitelist), použito [`trailingSlash`](/cs/api/module-options#trailingslash).
- `hreflang`: jeden odkaz pro každé povolené locale, ve kterém stránka existuje, `hreflang = iso || code`, přičemž se přeskakují locale se `seo: false`; s `hreflangBaseLanguage: true` první regionální locale daného jazyka vygeneruje i tag holého jazyka. Pod `no_prefix` žádné.
- `x-default`: URL výchozího locale, pokud strategie není `no_prefix`, výchozí locale nemá `seo: false` a stránka v něm existuje.
- `og:locale` / `og:locale:alternate`: z `og` daného locale, nebo z převedeného `iso` (`en-US` → `en_US`); pokud nefunguje ani jedno, přeskočí se s varováním ve vývojovém režimu.

## Příklad {#example}

```ts
// app.vue, with i18n.meta: false
const { metaObject } = useLocaleHead({ baseUrl: 'https://example.com' })
useHead(metaObject)
```

`build()` vrací stejný objekt bez refu: `useHead(() => build())` zůstává reaktivní bez watcheru.
