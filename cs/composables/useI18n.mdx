---
title: "useI18n"
description: "useI18n vrací pomocné funkce pro běh (`$t`, `$tc`, `$localePath`, …) jako prostý objekt, s prefixem `$` i bez něj."
---

`useI18n()` vrací pomocné funkce modulu pro běh jako prostý objekt. Používejte ho v `<script setup>`, composables a pluginech místo sahání po `useNuxtApp()`. Každá pomocná funkce je dostupná pod svým názvem s `$` i pod holým aliasem: `t` a `$t` jsou stejná funkce.

## Signatura {#signature}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Všechny pomocné funkce pro běh jako prostý objekt.

Stejné funkce, které plugin vkládá jako `$t`, `$tc` a tak dále, dostupné pod názvem
s prefixem dolaru i pod holým aliasem — takže funguje `const { t } = useI18n()` i
`const { $t } = useI18n()`.

**Vrací** — pomocné funkce popsané v [referenci metod](/cs/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

Vrácený objekt obsahuje všechny pomocné funkce z [`PluginsInjections`](/cs/api/methods). Každá z nich je popsána na stránce [Pomocné funkce](/cs/api/methods).

## Příklad {#example}

```vue
<script setup lang="ts">
const { t, tc, localePath, switchLocale, getLocale } = useI18n()

const title = computed(() => t('page.title'))
</script>

<template>
  <h1>{{ title }}</h1>
  <p>{{ tc('items', 3) }}</p>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
  <button @click="switchLocale(getLocale() === 'en' ? 'de' : 'en')">{{ t('nav.switch') }}</button>
</template>
```

## Mimo typ {#not-in-the-type}

`$defineI18nRoute` je typován pouze na `useNuxtApp()`:

```ts
const { $defineI18nRoute } = useNuxtApp()
```
