---
title: "useI18nHead"
description: "useI18nHead přepisuje vygenerované i18n SEO tagy pro jednu stránku: nahraďte nebo odstraňte canonical, hreflang a og tagy, nebo přidejte vlastní."
---

`useI18nHead()` mění SEO tagy, které modul generuje, a to jen pro jednu stránku. Použijte ho, když stránka ví víc než router: článek z CMS, který existuje jen v některých locale, kanonická URL z API, další tagy `og:`. Dostanete vygenerované tagy, přes které jsou sloučena vaše přepsání.

## Signatura {#signature}

```ts
useI18nHead(input?: MaybeRefOrGetter<I18nHeadInput | null>): { pageHead: any; resetPageHead: () => void }
```

Zaregistruje přepsání i18n SEO tagů v hlavičce na úrovni stránky.
Plugin `02.meta` je slučuje přes výstup `useLocaleHead`.

Pokud hodnoty pocházejí z `$t` / `t`, dejte přednost getteru (`() => ({ … })`), aby se
při změně locale znovu vyhodnotily. Prostý objekt se vyhodnotí jednou a zůstane zmrazený.

| Parametr | Typ | Popis |
| --- | --- | --- |
| `input` *(volitelný)* | `MaybeRefOrGetter<I18nHeadInput \| null>` |  |

Funguje s [`meta: true`](/cs/api/module-options#meta) (výchozí): meta plugin modulu při každém vykreslení hlavičky sloučí vstup přes výstup [`useLocaleHead`](/cs/composables/useLocaleHead). S `meta: false` ho nic nečte.

Přepsání se resetuje, když se změní název routy. Stránka, která nastaví `disableMeta`, nedostane žádné i18n tagy, a to ani přepsání.

## Vstup {#input}

`I18nHeadInput` (z `@i18n-micro/types`):

| Klíč | Typ | Účinek |
| --- | --- | --- |
| `htmlAttrs` | `Record<string, string>` | Sloučí se do atributů `<html>` (`lang`, `dir`). |
| `meta` | `I18nHeadMeta[]` | Přidá se za vygenerované tagy; nahradí tag se stejným `id`, `property` nebo `name`. |
| `link` | `I18nHeadLink[]` | Přidá se za vygenerované odkazy; nahradí odkaz se stejným `id`, nebo `rel` + `hreflang`. |
| `replace.canonical` | `string \| false` | Nahradí kanonický `href`, nebo odkaz odstraní. |
| `replace.hreflang` | `I18nHeadLink[] \| false` | Nahradí nebo odstraní **všechny** odkazy `rel="alternate"`, včetně `x-default`. |
| `replace.xDefault` | `I18nHeadLink \| false` | Nahradí nebo odstraní odkaz `x-default`. |
| `replace.ogLocale` | `string \| false` | Nahradí nebo odstraní `og:locale`. |
| `replace.ogUrl` | `string \| false` | Nahradí nebo odstraní `og:url`. |
| `replace.ogAlternates` | `string[] \| false` | Znovu sestaví `og:locale:alternate` z těchto kódů locale (přes `og` / `iso`), přičemž přeskočí aktuální locale, neznámé kódy a kódy bez hodnoty `og` nebo `iso`; nebo je odstraní. |
| `disable` | `I18nHeadDisableGroup[]` | Vypustí vygenerované skupiny: `'hreflang'` (ne `x-default`), `'x-default'`, `'canonical'`, `'og'` (`og:locale` + `og:url`), `'og-alternates'`, `'html'`. |

Pořadí použití: `disable`, pak `replace`, pak `htmlAttrs`, `meta`, `link`.

## Příklad {#example}

Článek, který existuje jen v některých locale, s alternativními URL z API:

```vue
<script setup lang="ts">
const route = useRoute()
const { t } = useI18n()
const { data: article } = await useFetch<{ title: string; urls: Record<string, string> }>(`/api/articles/${route.params.slug}`)

useI18nHead(() => {
  if (!article.value) return null
  const codes = Object.keys(article.value.urls)
  return {
    meta: [{ property: 'og:title', content: article.value.title || t('blog.title') }],
    replace: {
      hreflang: codes.map((code) => ({ rel: 'alternate', hreflang: code, href: article.value!.urls[code]! })),
      ogAlternates: codes,
    },
  }
})
</script>
```

Když hodnoty pocházejí z `t()` nebo z asynchronních dat, předejte getter jako zde: při změně locale se spustí znovu. Prostý objekt se přečte jen jednou.
