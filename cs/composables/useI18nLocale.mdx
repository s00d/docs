---
title: "useI18nLocale"
description: "useI18nLocale čte a zapisuje stav locale a cookie s locale — vstupní bod pro vlastní detekci locale."
---

`useI18nLocale()` dává přístup k locale, kterou aplikace zvolila: ke stavu `i18n-locale` a k cookie s locale. Použijte jej v pluginu, který locale detekuje sám (doména, uživatelský profil, hlavička), místo ručního zapisování `useState('i18n-locale')` nebo cookie. Jeho kontroly platnosti používají povolené locale včetně běhových přepisů.

## Signatura {#signature}

```ts
useI18nLocale(): { getEffectiveLocale: (route: unknown, getLocaleFromRoute: GetLocaleFromRoute) => string; getLocale: () => string | null; getPreferredLocale: () => string | null; hashCookie: CookieRef; isValidLocale: (locale: string | null | undefined) => locale is string; locale: any; localeCookie: CookieRef; resolveInitialLocale: (options: ResolveInitialLocaleOptions) => string; setLocale: (locale: string | null) => void; syncLocale: (locale: string | null) => void; validLocales: string[] }
```

Centralizovaný vstupní bod pro správu locale i18n.
Kombinuje useState('i18n-locale'), cookie s locale a synchronizační nástroje.

## Vrácené hodnoty {#returned-values}

| Člen | Typ | Popis |
| --- | --- | --- |
| `locale` | `Ref<string \| null>` | Ref `useState('i18n-locale')`. |
| `localeCookie` | `Ref<string \| null>` | Cookie [`localeCookie`](/cs/api/module-options#localecookie); prosté `{ value: null }`, když je volba `null`. |
| `hashCookie` | `Ref<string \| null>` | Cookie `hash-locale` při hash routingu; jinak `{ value: null }`. |
| `validLocales` | `string[]` | Kódy povolených locale. |
| `setLocale(locale)` | `(locale: string \| null) => void` | Zapíše stav a cookies. Neprovádí validaci a nenačítá překlady. |
| `syncLocale(locale)` | `(locale: string \| null) => void` | Zapíše pouze cookies. |
| `getLocale()` | `() => string \| null` | Stav, poté preferenční cookie (při hash routingu hash cookie). Bez validace. |
| `getPreferredLocale()` | `() => string \| null` | První **platná** hodnota ze stavu a preferenční cookie, nebo `null`. |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string` | Stav při hash routingu, pokud je nastaven; jinak `getLocaleFromRoute(route)`. |
| `resolveInitialLocale(options)` | `(options: ResolveInitialLocaleOptions) => string` | `options.urlLocale`, poté platný stav, poté `options.serverLocale`, poté locale trasy. Výsledek uloží do stavu, pokud stav není platný; na klientovi zapíše také cookie. |
| `isValidLocale(locale)` | `(locale) => locale is string` | Zda je `locale` v `validLocales`. |

Cookies platí jeden rok, s `path: '/'` a `sameSite: 'lax'`.

## Příklad {#example}

```ts
// plugins/locale-from-domain.server.ts
export default defineNuxtPlugin({
  name: 'locale-from-domain',
  enforce: 'pre',
  setup() {
    const { setLocale, isValidLocale } = useI18nLocale()
    const host = useRequestURL().hostname // e.g. de.example.com
    const code = host.split('.')[0]
    if (isValidLocale(code)) setLocale(code)
  },
})
```

Loader plugin modulu čte stav při svém startu, takže plugin, který jej nastavuje, musí běžet dříve (`enforce: 'pre'`). Jak stav soupeří s URL, cookie a `Accept-Language`: [Detekce locale](/cs/guide/locale-detection). Kompletní návod: [Vlastní detekce](/cs/guide/custom-auto-detect).

`setLocale()` nepřepíná překlady na obrazovce. Chcete-li změnit locale aktuální stránky, zavolejte [`$switchLocale()`](/cs/api/methods#$switchlocale).
