---
title: "Vyloučení cest"
description: "Vyřaďte stránky a soubory z lokalizovaného routování pomocí excludePatterns a podívejte se, které cesty jsou vyloučené už teď."
---

Některé cesty nesmí nikdy dostat prefix lokalizace ani přesměrování podle lokalizace: administrace, health check, generovaný feed. `excludePatterns` je označí a vestavěný seznam už pokrývá interní části Nuxtu a běžné statické soubory. Vyloučená stránka si ponechá přesně tu cestu, kterou jste napsali, a stále se vykresluje s `$t`.

## Vyloučení cesty {#exclude-a-path}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    excludePatterns: [
      '/admin', // /admin and everything below it
      '/preview-*', // glob over the whole path
    ],
  },
})
```

S touto konfigurací odpovídá `pages/admin/index.vue` jen na `/admin`; žádné `/de/admin` neexistuje a `/admin` se nikdy nepřesměruje na `/de/admin`.

## Syntaxe vzorů {#pattern-syntax}

Vzory se porovnávají s cestou bez `app.baseURL`:

| Vzor | Odpovídá | Neodpovídá |
| --- | --- | --- |
| `'/admin'` | `/admin`, `/admin/users` | `/administrator`, `/de/admin` |
| `'/preview-*'` | `/preview-1`, `/preview-a/b` | `/de/preview-1` |
| `'/file-?'` | `/file-a` | `/file-ab` |
| `/^\/v\d+\//` | `/v2/docs` | `/docs` |

Řetězec bez `*` nebo `?` odpovídá cestě a celým segmentům pod ní. S `*` (libovolná posloupnost znaků včetně lomítek) nebo `?` (jeden znak) musí odpovídat celé cestě. Řetězce vždy začínejte znakem `/`.

## Co je vyloučeno už teď {#what-is-excluded-already}

Tyto cesty nikdy nedostanou lokalizované trasy ani přesměrování, a to bez jakékoli konfigurace:

- `/api` a `/_nuxt` a vše pod nimi;
- trasa překladů, ve výchozím stavu `/_locales` ([`apiBaseUrl`](/cs/api/module-options#apibaseurl));
- jakákoli cesta se segmentem začínajícím `__` (`/__nuxt_content`, `/en/__og-image__`);
- `/sitemap*.xml`, `/robots.txt`, `/favicon.ico`, `/apple-touch-icon*.png`, `/manifest.json`, `/sw.js`, `/workbox-*.js`;
- jakákoli cesta, jejíž poslední segment končí příponou statického souboru: `xml txt ico json js css png jpg jpeg gif svg webp avif pdf wasm map mp4 webm mp3 zip gz woff woff2 ttf eot`. Slugy stránek s tečkou jako `/user/john.doe` a cesty `.html` zůstávají stránkami.

## Co vyloučení dělá {#what-an-exclusion-does}

- **Trasy:** negenerují se žádné lokalizované varianty; stránka zůstane tak, jak je napsaná.
- **Přesměrování a 404:** serverový plugin pro přesměrování i klientský middleware pro přesměrování cestu přeskočí.
- **Prerender:** odpovídající cesty se odstraní ze seznamu tras pro prerender.

Nebrání to serverovému middlewaru i18n v detekci lokalizace pro požadavek a nebrání to stránce používat překlady. Chcete-li stránku ponechat lokalizovanou, ale bez SEO tagů, použijte `disableMeta` ([Konfigurace stránky](/cs/guide/per-component-translations#turn-off-seo-tags)). Chcete-li jednu stránku ponechat nelokalizovanou podle cesty z `nuxt.config.ts`, udělá totéž pro routování `globalLocaleRoutes: { '/admin': false }` ([Lokalizované cesty](/cs/guide/custom-locale-routes#in-nuxt-config)).
