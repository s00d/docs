---
title: "Runtime přepisy"
description: "Změňte výchozí locale, záložní locale nebo zakázaná locale pro každou instanci jednoho buildu pomocí proměnných prostředí nebo runtimeConfig."
---

Runtime přepisy umožňují spustit jeden artefakt buildu s různým nastavením locale pro každé prostředí nebo tenanta, bez nového buildu. Můžete změnit výchozí locale, záložní locale a to, která locale jsou zakázaná. Routování, přesměrování, vykreslování i serverové helpery používají přepsané hodnoty, stejně jako prohlížeč na stránce vykreslené serverem.

## Nastavení přepisů proměnnými prostředí {#set-overrides-with-environment-variables}

```bash
NUXT_I18N_DEFAULT_LOCALE=de \
NUXT_I18N_FALLBACK_LOCALE=en \
NUXT_I18N_DISABLED_LOCALES=fr,it \
node .output/server/index.mjs
```

| Proměnná | Alias |
| --- | --- |
| `NUXT_I18N_DEFAULT_LOCALE` | `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE` |
| `NUXT_I18N_FALLBACK_LOCALE` | `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE` |
| `NUXT_I18N_DISABLED_LOCALES` (oddělené čárkami) | `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES` |

Server je načte jednou při startu; změnu uplatníte restartem. Na stránce vykreslené serverem dostane prohlížeč rozpoznané hodnoty od serveru. S `ssr: false` neprobíhá serverové vykreslení a prohlížeč nemá žádné prostředí: platí tam jen `runtimeConfig.public.i18nRuntime` a prohlížeč zaloguje níže uvedená varování.

## Nastavení přepisů v runtimeConfig {#set-overrides-in-runtimeconfig}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

Hodnota nastavená v `runtimeConfig.public.i18nRuntime` má přednost před proměnnou `NUXT_I18N_*` pro stejné pole.

Nezaměňujte s proměnnou `DEFAULT_LOCALE` pro dobu buildu, která při buildu nahrazuje `defaultLocale` a nepotřebuje žádnou runtime podporu.

## Co se může a nemůže změnit {#what-can-and-cannot-change}

| Nastavení | Za běhu |
| --- | --- |
| `defaultLocale` | Ano při `prefix` a `no_prefix`. Při `prefix_except_default` a `prefix_and_default` je pevně dané při buildu (jeho stránky jsou routy bez prefixu); přepis se s varováním ignoruje. |
| `fallbackLocale` | Ano. |
| `disabledLocales` | Přidává se k locale zakázaným při buildu; nikdy žádné znovu nepovolí. Výchozí locale buildu nelze zakázat při `prefix_except_default` / `prefix_and_default`. |
| `strategy` | Ne. Runtime strategie se s varováním ignoruje; sestavte jeden artefakt pro každou strategii. |

Neplatné hodnoty aplikaci nikdy nerozbijí. Každý případ zaloguje jedno varování na serverový proces:

- zakázání všech locale se ignoruje;
- `defaultLocale`, které není povolené, se vrátí na první povolené locale;
- `fallbackLocale`, které není povolené, ponechá hodnotu z buildu, pokud je povolená, jinak žádné záložní locale není.

## Čtení efektivní konfigurace {#read-the-effective-config}

```vue
<script setup lang="ts">
const { $getI18nConfig } = useNuxtApp()
const config = $getI18nConfig() // build config with overrides applied
</script>
```

Považujte ji za pouze ke čtení: na serveru ji sdílejí všechny požadavky a ve vývoji je zmrazená; kopie v prohlížeči zmrazená není. Import konfigurace z `#build/i18n.strategy.mjs` vrátí hodnoty z buildu bez přepisů.

## Zakázaná locale a statické soubory {#disabled-locales-and-static-files}

Locale zakázané za běhu vrací 404 na svých routách i na routě payloadu, ale jeho soubory payloadu jsou stále v `.output/public/_locales/` a statický souborový server je vrátí. Pokud tyto soubory nesmí být dostupné, zakažte locale při buildu pomocí `disabled: true`.
