---
title: "Migrace z @nuxtjs/i18n"
description: "Převod možností, composables a souborů překladů z @nuxtjs/i18n na nuxt-i18n-micro."
---

Tato stránka převádí aplikaci s `@nuxtjs/i18n` na nuxt-i18n-micro: možnosti, helpery a strukturu souborů. Použijte ji, když v existující aplikaci vyměňujete modul. URL zůstanou zachované (názvy strategií jsou stejné) a překlady přesunete do JSON souborů pro jednotlivé stránky.

<Tip>

**Aktualizujete samotný nuxt-i18n-micro?** — Viz [Upgrade](/cs/guide/upgrade).

</Tip>

## Výměna modulu {#swap-the-module}

```bash
npm uninstall @nuxtjs/i18n
npm install nuxt-i18n-micro
```

```ts
// nuxt.config.ts — before
export default defineNuxtConfig({
  modules: ['@nuxtjs/i18n'],
  i18n: {
    locales: [
      { code: 'en', language: 'en-US', file: 'en.json' },
      { code: 'de', language: 'de-DE', file: 'de.json' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    langDir: 'locales',
    detectBrowserLanguage: { useCookie: true, cookieKey: 'i18n_redirected', redirectOn: 'root' },
  },
})
```

```ts
// nuxt.config.ts — after
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    translationDir: 'locales',
    localeCookie: 'i18n_redirected',
    autoDetectPath: '/',
  },
})
```

## Možnosti {#options}

| `@nuxtjs/i18n` | nuxt-i18n-micro |
| --- | --- |
| `locales[].code` | `locales[].code` |
| `locales[].language` (`iso` před v9) | `locales[].iso` |
| `locales[].name` | `locales[].displayName` |
| `locales[].dir` | `locales[].dir` |
| `locales[].domain` | `locales[].baseUrl` (origin včetně schématu) |
| `locales[].domainDefault` | `locales[].baseDefault` |
| `differentDomains`, `multiDomainLocales` | není potřeba: samotné `baseUrl` směruje podle hostitele, viz [Vrstvy a domény](/cs/guide/layers#multiple-domains) |
| `locales[].file` / `files`, `langDir`, `lazy` | `translationDir`; soubory se hledají podle názvu a vždy se načítají pro jednotlivé stránky |
| `defaultLocale`, `strategy` | stejné názvy, stejné čtyři hodnoty |
| `baseUrl` | `metaBaseUrl` |
| `customRoutes: 'config'` + `pages` | `globalLocaleRoutes` |
| `detectBrowserLanguage: false` | `redirects: false` (žádná přesměrování) nebo `autoDetectLanguage: false` (ignorovat hlavičku) |
| `detectBrowserLanguage.useCookie` / `cookieKey` | `localeCookie: '<name>'` (`null` cookie vypne) |
| `detectBrowserLanguage.redirectOn: 'root'` | `autoDetectPath: '/'` (výchozí) |
| `detectBrowserLanguage.redirectOn: 'no prefix'` | `autoDetectPath: 'no_prefix'` |
| `detectBrowserLanguage.redirectOn: 'all'` | `autoDetectPath: '*'` |
| konfigurační soubor `vueI18n` (`fallbackLocale`, `numberFormats`, `datetimeFormats`) | `fallbackLocale`, `numberFormats`, `datetimeFormats` v `i18n` |

Neexistuje žádné `alwaysRedirect`: je-li nastavená cookie, `/` se jí řídí při každé návštěvě. Úplný seznam najdete v [Možnostech modulu](/cs/api/module-options); pravidla detekce jsou na stránce [Detekce locale](/cs/guide/locale-detection).

## Helpery a composables {#helpers-and-composables}

| `@nuxtjs/i18n` / vue-i18n | nuxt-i18n-micro (šablona / `useI18n()`) |
| --- | --- |
| `const { t } = useI18n()` | `const { t } = useI18n()`, `$t` v šablonách |
| `t('key', count)`, `tc` | `$tc('key', count)` |
| `te('key')` | `$has('key')` |
| `n(value, 'currency')`, `d(date, 'short')` | `$tn(value, 'currency')`, `$td(date, 'short')` |
| — | `$tdr(date)`: relativní čas ("za 3 dny") |
| `locale.value` | `$getLocale()` |
| `locales.value` | `$getLocales()` |
| `setLocale('de')` | `$switchLocale('de')` |
| `useLocalePath()('about')` | `$localePath({ name: 'about' })` |
| `useLocaleRoute()` | `$localeRoute()` |
| `useSwitchLocalePath()('de')` | `$switchLocalePath('de')` |
| `useSetI18nParams()` | `$setI18nRouteParams()` |
| `useLocaleHead()` | automaticky s `meta: true`; [`useLocaleHead`](/cs/composables/useLocaleHead) pro vlastní head |
| `defineI18nRoute({ paths: { de: '/ueber-uns' }, locales: [...] })` | `$defineI18nRoute({ localeRoutes: { de: '/ueber-uns' }, locales: [...] })` |
| `<NuxtLinkLocale to="about">` | `<i18n-link :to="{ name: 'about' }">` |
| `<i18n-t>` | `<i18n-t>` (sloty vyplňují zástupné symboly `{name}`) |
| `$i18n` v serverových routách | `useTranslationServerMiddleware(event)`, viz [Serverové routy a API](/cs/guide/server-side-translations) |

`useI18n()` se importuje automaticky. `$defineI18nRoute` si musí ponechat `$`: build toto volání čte. Všechny helpery: [Metody](/cs/api/methods).

## Soubory překladů {#translation-files}

Klíče z jednoho velkého souboru pro každé locale přesuňte do kořenového souboru a jednoho souboru pro každou stránku:

```text
locales/
├── en.json              # keys used on many pages (nav, footer)
├── de.json
└── pages/
    ├── index/en.json    # keys of pages/index.vue
    └── about/en.json    # keys of pages/about.vue
```

Ponechat vše v kořenových souborech funguje také a je to nejrychlejší první krok. Dokud je nerozdělíte, nastavte `disablePageLocales: true`. Viz [Soubory překladů](/cs/guide/translations).

### Syntaxe zpráv {#message-syntax}

| vue-i18n | nuxt-i18n-micro |
| --- | --- |
| pojmenovaná interpolace `{name}` | stejné |
| `car \| cars` (2 tvary: 1 → první) | tvary se vybírají podle počtu od 0: pište `no cars \| one car \| {count} cars` |
| propojené zprávy `@:other.key` | nepodporováno: zopakujte text nebo ho složte v kódu |
| modifikátory `@.upper:` | nepodporováno: formátujte v kódu nebo použijte `<i18n-t>` |
| doslovné escapování `{'@'}` | není potřeba: nahrazují se jen tokeny `{word}` |
| soubory zpráv v JS/TS | pouze JSON |

Pravidlo množného čísla lze nahradit možností [`plural`](/cs/api/module-options#plural).

## Kontrola po přechodu {#check-after-the-switch}

- Každá URL, kterou jste měli, se stále rozpozná; názvy strategií se shodují, vlastní cesty se přesouvají do `globalLocaleRoutes` nebo `$defineI18nRoute`.
- `hreflang`, canonical a `og:locale` jsou s `meta: true` k dispozici hned; ručně psané odstraňte.
- Chyba parsování JSON zaloguje cestu k souboru; chybějící klíč ve vývoji zaloguje varování do konzole prohlížeče.
