Serverové handlery v `server/api/` a `server/routes/` mohou překládat řetězce a číst locale požadavku pomocí dvou automaticky importovaných pomocných funkcí. Používejte je pro odpovědi API, e-maily, feedy nebo cokoli vykreslovaného mimo stránku Vue. Čtou stejné soubory s překlady jako vaše stránky a detekují locale z požadavku.

## Překlad v handleru {#translate-in-a-handler}

```ts
// server/api/greeting.get.ts
export default defineEventHandler(async (event) => {
  const t = await useTranslationServerMiddleware(event)
  return { message: t('greeting', { name: 'Ada' }) }
})
```

```bash
curl 'http://localhost:3000/api/greeting?locale=de'
# {"message":"Hallo, Ada!"}
```

`useTranslationServerMiddleware(event, defaultLocale?, locale?)` je asynchronní a vrací `t(key, params?, defaultValue?)`. `t` vrací řetězec, interpoluje parametry `{name}` a když klíč chybí, vrátí neprázdnou `defaultValue`, jinak samotný klíč.

`t` vidí pouze chunk `index`: kořenové soubory (`locales/<locale>.json`) plus `locales/pages/index/`, pokud existuje (s `disablePageLocales` pouze kořenové soubory). Klíče ostatních stránek se nenačítají. Pro ně si chunk načtěte sami:

```ts
const { data } = await loadTranslationsFromServer('de', 'about') // Translations object of the about page
```

## Čtení locale požadavku {#read-the-request-locale}

```ts
// server/api/locale.get.ts
export default defineEventHandler((event) => {
  const { current, isDefault, locale } = useLocaleServerMiddleware(event)
  return { current, isDefault, dir: locale?.dir ?? 'ltr' }
})
```

`useLocaleServerMiddleware(event, defaultLocale?, locale?)` je synchronní a vrací:

```ts
interface LocaleInfo {
  current: string // detected locale code
  default: string // defaultLocale, runtime overrides included (fixed at build under prefix_except_default / prefix_and_default)
  fallback: string // fallbackLocale, else the default
  available: string[] // enabled locale codes
  locale: Locale | null // the config entry of `current`
  isDefault: boolean
  isFallback: boolean
}
```

## Jak se locale volí {#how-the-locale-is-chosen}

Obě pomocné funkce používají na každé serverové routě, ať `/api`, nebo ne, stejné pořadí:

1. query `?locale=` (při opakování první hodnota);
2. parametr routy `[locale]` nebo prefix locale v cestě (`/de/...`);
3. cookie s locale, pokud je nastaveno [`localeCookie`](/cs/api/module-options#localecookie) (`hash-locale` při `hashMode`);
4. `Accept-Language`, pokud je zapnuto `autoDetectLanguage` (respektují se q-hodnoty);
5. `defaultLocale`.

Neplatné a vypnuté kódy se v každém kroku přeskakují. Toto je pořadí pro API; vykreslení stránky při prefixových strategiích `?locale=` ignoruje. Obě pořadí jsou porovnána na stránce [Detekce locale](/cs/guide/locale-detection).

## Vynucení locale {#force-a-locale}

Předejte třetí argument, chcete-li detekci přeskočit, například v úloze, která posílá e-maily v jazyce uživatele:

```ts
export default defineEventHandler(async (event) => {
  const user = await getUser(event) // your code
  const t = await useTranslationServerMiddleware(event, undefined, user.locale)
  return sendMail(user.email, t('mail.welcome.subject'))
})
```

Druhý argument nahrazuje `defaultLocale` pro detekci v rámci tohoto volání, takže když je locale vynuceno, nemá žádný účinek. Slovníky se ukládají do cache pro každý požadavek a každé locale a napříč požadavky v serverové cache překladů, takže opakované volání pomocné funkce je levné.

## Serverové komponenty {#server-components}

Serverová komponenta (`.server.vue`, `<NuxtIsland>`) se vykresluje ze své vlastní URL, `/__nuxt_island/...`, takže nevidí URL stránky a Nuxt jí předává jen její props. Předejte locale jako prop `locale`. Komponenta se pak vykreslí v daném locale a přepnutí ji načte znovu, protože props jsou součástí URL a klíče cache islandu. Název je rezervovaný: jakýkoli kód povoleného locale v propu s názvem `locale` nastaví locale vykreslení, takže prop, který znamená něco jiného, například formát čísel, pojmenujte jinak:

```vue
<!-- components/Greeting.server.vue -->
<template><p>{{ $t('greeting') }}</p></template>
<script setup lang="ts">
defineProps<{ locale?: string }>()
</script>
```

```vue
<template>
  <Greeting :locale="$getLocale()" />
  <NuxtIsland name="Greeting" :props="{ locale: $getLocale() }" />
</template>
```

Bez tohoto propu se vykreslí v locale z cookie, jinak ve výchozím locale, bez ohledu na URL, a nereaguje na přepnutí. Její `$t` vidí chunk `index`: kořenové soubory plus `locales/pages/index/`.
