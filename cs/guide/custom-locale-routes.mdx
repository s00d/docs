---
title: "Lokalizované cesty"
description: "Přiřaďte stránce pro každé locale jinou URL pomocí localeRoutes nebo globalLocaleRoutes, včetně dynamických parametrů a slugů pro jednotlivá locale."
---

Ve výchozím nastavení každé locale obsluhuje stránku na stejné cestě: `/en/about`, `/de/about`. Lokalizované cesty umožňují, aby každé locale používalo vlastní slova, například `/de/ueber-uns`, zatímco soubor stránky zůstává stejný. Nastavíte je ve stránce pomocí `$defineI18nRoute`, nebo pro mnoho stránek najednou v `nuxt.config.ts`.

## Ve stránce {#in-the-page}

```vue
<!-- pages/about.vue -->
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  localeRoutes: {
    de: '/ueber-uns',
    fr: '/a-propos',
  },
})
</script>
```

Se strategií `prefix_except_default` a `defaultLocale: 'en'` stránka odpovídá na `/about`, `/de/ueber-uns` a `/fr/a-propos`. Locale bez záznamu si ponechá výchozí cestu. Cesty pište bez kódu locale: prefix přidává [strategie](/cs/guide/strategy) a cesta začínající kódem locale zaloguje varování. Co dalšího volání přijímá, najdete na stránce [Konfigurace stránky](/cs/guide/per-component-translations).

## V nuxt.config {#in-nuxt-config}

[`globalLocaleRoutes`](/cs/api/module-options#globallocaleroutes) dělá totéž pro libovolnou stránku, s klíčem podle její cesty (nebo podle názvu routy, pokud je zapsán bez úvodního lomítka):

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    globalLocaleRoutes: {
      '/about': { de: '/ueber-uns' },
      '/about/team': { de: '/ueber-uns/team' },
      '/admin': false, // not localized: one /admin route, no locale prefix
    },
  },
})
```

Když stránka nastaví `localeRoutes` a `globalLocaleRoutes` má stejný klíč, vyhrává záznam z konfigurace.

## Dynamické parametry {#dynamic-params}

Parametry pište v libovolném tvaru Nuxtu: `[id]`, `[[page]]`, `[...slug]` nebo `:id()`. Názvy parametrů se musí shodovat se souborem stránky.

```ts
// pages/products/[...slug].vue
$defineI18nRoute({
  localeRoutes: {
    en: '/our-products/[...slug]',
    de: '/unsere-produkte/[...slug]',
  },
})
```

Vnořené stránky přijímají absolutní cestu potomka (`/ueber-uns/team`) nebo cestu relativní k lokalizované cestě rodiče (`team`).

## Odkazování na lokalizované stránky {#linking-to-localized-pages}

Odkazy se rozlišují na lokalizovanou cestu cílového locale, ať předáte název routy, nebo prostou cestu:

```vue
<template>
  <i18n-link :to="{ name: 'about' }">About</i18n-link>
  <i18n-link to="/about">About</i18n-link>
  <!-- de: both render /de/ueber-uns -->
  <NuxtLink :to="$localePath('/about', 'de')">Deutsch</NuxtLink>
</template>
```

Názvy rout vycházejí z cesty k souboru (`pages/about/team.vue` je `about-team`), pokud nějaký nenastavíte pomocí `definePageMeta({ name })`.

## Slugy pro jednotlivá locale {#per-locale-slugs}

Když se samotný slug liší podle locale (`/our-products/red-shoe` vs `/de/unsere-produkte/roter-schuh`), sdělte přepínači jazyků, které parametry má použít, pomocí `$setI18nRouteParams`, jakmile jsou data načtena:

```vue
<script setup lang="ts">
const { $setI18nRouteParams } = useNuxtApp()
const route = useRoute()

const { data: product } = await useFetch(`/api/products/${route.params.slug}`)

if (product.value) {
  $setI18nRouteParams({
    en: { slug: product.value.slugEn },
    de: { slug: product.value.slugDe },
  })
}
</script>
```

`$switchLocalePath('de')` a `<i18n-switcher>` pak odkazují na `/de/unsere-produkte/roter-schuh`. Klíče jsou kódy locale, hodnoty jsou parametry podle názvu (jako v souboru stránky).

Přepínač v layoutu se vykreslí dřív, než se sem dostane asynchronní setup stránky, takže po skončení vykreslování modul přepíše odkazy `<i18n-switcher>`, a to v `app.vue` i ve stránce. Serverové HTML, návštěvník bez JavaScriptu i první vykreslení na klientovi se pak shodují. Parametry k tomu nastavte během SSR: s `lazy` nebo `server: false` se odkazy změní až po hydrataci. SSR streaming v Nuxtu odešle HTML dřív, než jsou parametry známé, takže při něm odkazy v prvním HTML ponechají vlastní parametry URL.

Přepisují se pouze vlastní odkazy přepínače. Ručně napsaný odkaz s `$switchLocalePath` se musí vykreslit až po nastavení parametrů, takže ho umístěte do stránky, která je nastavuje, a to i za `await`. V layoutu se vykreslí jako první: jeho serverové HTML ponechá parametry URL a hydratace upozorní na nesoulad. Tam použijte `<i18n-switcher>` s jeho sloty a props `custom*Style` pro vzhled.

Parametry patří stránce, která je nastavila:

- Zahodí se, když se potvrdí navigace na jinou cestu, takže každá stránka si nastavuje vlastní. Zrušená navigace je ponechá na místě.
- Získejte `$setI18nRouteParams` z `useNuxtApp()` nebo `useI18n()` v `setup`, i když ji voláte později v handleru `useAsyncData`. Takto získaná funkce zná svou stránku: pokud návštěvník odešel, pozdní volání nic neudělá.
- S `keepalive` stránka dostane zpět parametry, které nastavila, když se návštěvník vrátí. `useI18nHead` se chová stejně.

## Routy přidané v pages:extend {#routes-added-in-pagesextend}

Routy, které přidáte v hooku `pages:extend`, nemají soubor stránky, ze kterého by se dalo číst `$defineI18nRoute`, a několik z nich často sdílí jednu obalovou komponentu. Routa přidaná bez `name` dostane název, který by Nuxt dal její cestě (`/a/:id()` se stane `a-id`), takže na ni vedou jazykové odkazy, pokud už tento název nemá jiná routa; pak jí dejte explicitní `name`. Udržujte jeden seznam a rozdělte ho na stránky a `globalLocaleRoutes` s klíči podle názvu routy pomocí `splitLocaleRoutes` z `@i18n-micro/utils/split-locale-routes` (přidejte balíček do svých závislostí):

```ts
// nuxt.config.ts
import { splitLocaleRoutes } from '@i18n-micro/utils/split-locale-routes'

const dynamic = splitLocaleRoutes([
  { name: 'products-tag', path: '/products/:tag', file: '~/pages/_dynamic.vue', paths: { de: '/produkte/:tag' } },
  { name: 'internal', path: '/internal', file: '~/pages/_dynamic.vue', paths: false }, // not localized
])

export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  hooks: {
    'pages:extend'(pages) {
      pages.push(...dynamic.pages)
    },
  },
  i18n: {
    globalLocaleRoutes: dynamic.globalLocaleRoutes,
  },
})
```

Lokalizované cesty nedávejte do `route.meta`: dostaly by se do klientské tabulky rout.
