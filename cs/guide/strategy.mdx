Možnost `strategy` určuje, zda se lokalizace objeví v URL a pro které lokalizace. Zvolte ji jednou, ještě než URL zveřejníte: pozdější změna změní každý odkaz. Modul pak při buildu vygeneruje lokalizované trasy a `$localePath`, `<i18n-link>` i přepínač je čtou.

## Čtyři strategie {#the-four-strategies}

![Stránka /about v en (výchozí) a de při každé strategii; tytéž URL jsou uvedeny v textu níže](/images/diagrams/strategies.svg)

**Typ** `Strategies` · **Výchozí** `'prefix_except_default'`

Strategie routování URL pro prefixy lokalizací.

- `'no_prefix'` — žádná lokalizace v URL; lokalizace je uložena v cookie.
- `'prefix_except_default'` — prefix u všech lokalizací kromě výchozí.
- `'prefix'` — vždy prefix, včetně výchozí lokalizace.
- `'prefix_and_default'` — jako `prefix`, ale výchozí lokalizace je dostupná i bez prefixu.

URL pro stránku `about` s `defaultLocale: 'en'` a lokalizacemi `en`, `de`:

| Strategie | Angličtina | Němčina | Neobsluhováno |
| --- | --- | --- | --- |
| `prefix_except_default` (výchozí) | `/about` | `/de/about` | `/en` a `/en/about` vrací 404 |
| `prefix` | `/en/about` | `/de/about` | `/about` přesměruje na URL s prefixem |
| `prefix_and_default` | `/about` a `/en/about` | `/de/about` | — |
| `no_prefix` | `/about` | `/about` | lokalizace není v URL |

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix',
  },
})
```

Strategie je pevně daná při buildu: její přepsání za běhu se ignoruje s varováním ([Přepsání za běhu](/cs/guide/runtime-overrides)).

## Kterou zvolit {#which-one-to-choose}

- **`prefix_except_default`**: většina webů. Existující URL bez prefixu dál fungují pro výchozí jazyk.
- **`prefix`**: všechny jazyky jsou si rovné; `/` vždy vede na domovskou stránku s prefixem.
- **`prefix_and_default`**: potřebujete, aby fungovaly jak `/en/...`, tak URL bez prefixu, například při přechodu z jednoho na druhé. URL bez prefixu se nikdy nepřesměrovávají.
- **`no_prefix`**: aplikace za přihlášením nebo jedna URL na stránku pro všechny jazyky. Lokalizace pochází z cookie nebo z `?locale=`. Vyhledávače vidí jeden jazyk na URL, takže se negenerují žádné alternativy `hreflang`.

Jak se pro URL vybírá lokalizace a kdy je návštěvník přesměrován, popisuje stránka [Detekce lokalizace](/cs/guide/locale-detection).

## Generované trasy {#generated-routes}

Při buildu dostane každá stránka záznamy tras, které její strategie potřebuje. Každý záznam nese `meta.i18n = { name, locales }`: stránku, kterou zobrazuje, a lokalizace, které obsluhuje. Odkazy, přepínání i přesměrování se řeší z těchto záznamů, takže URL, kterou modul vydá, je vždy taková, kterou router obsluhuje.

Lokalizace, které sdílejí cestu stránky, sdílejí jeden záznam, `/:locale(de|fr)/about`. Lokalizace s vlastní cestou dostane vlastní záznam pojmenovaný `localized-<page>-<locale>`:

```ts
// nuxt.config.ts: German has its own path for the about page
i18n: {
  globalLocaleRoutes: { about: { de: '/ueber-uns' } },
}
// prefix_except_default, locales en (default), de, fr:
// about                 /about
// localized-about       /:locale(fr)/about
// localized-about-de    /:locale(de)/ueber-uns
```

Vlastní cesty, seznamy lokalizací pro jednotlivé stránky a vyloučení stránky z lokalizace popisují stránky [Lokalizované cesty](/cs/guide/custom-locale-routes) a [Konfigurace stránky](/cs/guide/per-component-translations). Prefix `localized-` určuje [`localizedRouteNamePrefix`](/cs/api/module-options#localizedroutenameprefix).

<Warning>

**Názvy tras jsou generované** — Nezapisujte názvy `localized-…` natvrdo do `router.push({ name })`. Předejte vlastní název stránky do `$localeRoute` nebo `<i18n-link>`; ty vyberou správný záznam.

</Warning>

## Odkaz na stránku v určité lokalizaci {#linking-to-a-page-in-a-locale}

```vue
<script setup lang="ts">
const { localePath, localeRoute, switchLocalePath } = useI18n()

localePath({ name: 'about' }) // '/de/ueber-uns' while the page is German
localePath({ name: 'about' }, 'en') // '/about'
localePath('/about', 'de') // '/de/ueber-uns': a path is read as the page it shows
localeRoute({ name: 'products-id', params: { id: '42' } }, 'de') // resolved route: name, params, fullPath
switchLocalePath('fr') // the current page in French
</script>

<template>
  <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
  <NuxtLink :to="$switchLocalePath('de')">Deutsch</NuxtLink>
</template>
```

- Fungují pojmenované trasy i cesty. Cesta se porovnává s generovanými trasami, takže je přijat její tvar v libovolné lokalizaci.
- Lokalizace, která stránku neobsluhuje (viz `locales` v části [Konfigurace stránky](/cs/guide/per-component-translations)), odkazuje místo na chybějící stránku na domovskou stránku dané lokalizace.
- Parametry pro jednotlivé lokalizace (přeložený slug) se nastavují přes `$setI18nRouteParams`, viz [Lokalizované cesty](/cs/guide/custom-locale-routes).

Signatury najdete v části [Metody](/cs/api/methods).

## Podrobnosti o `no_prefix` {#no_prefix-details}

- [`localeCookie`](/cs/api/module-options#localecookie) má při `no_prefix` výchozí hodnotu `'user-locale'`, takže volba přežije opětovné načtení.
- `$switchLocale('de')` načte německý slovník a nahradí aktuální záznam historie; URL se nemění.
- Vlastní cesty pro jednotlivé lokalizace stále fungují: s `globalLocaleRoutes: { about: { de: '/ueber-uns' } }` dostanou němečtí čtenáři `/ueber-uns`. Tato URL se vždy vykreslí německy, ať návštěvník preferuje cokoli, a stránka omezená na některé lokalizace se vykreslí v jedné z nich. Cesta sdílená několika lokalizacemi (`en` i `de` na `/page/:id`) vykreslí preferenci, pokud je jednou z nich. Samotná preference zůstává: další stránka se k ní vrátí.
- [`noPrefixRedirect: true`](/cs/api/module-options#noprefixredirect) přesměruje původní cestu stránky s vlastní cestou ve výchozí lokalizaci: na vlastní cestu lokalizace návštěvníka, jinak na cestu výchozí lokalizace (`/about` → `/about-us`, když má `en` `/about-us`, → `/ueber-uns` s cookie `de`). Lokalizace bez vlastní cesty zůstane na původní cestě a vykreslí se tam. Stránky s parametry se nepřesměrovávají.

## Aplikace bez `pages/` {#apps-without-pages/}

S `pages: false` neexistují žádné trasy stránek k lokalizaci. Používejte pouze kořenové soubory s překlady (`disablePageLocales: true`); detekce, cookie i `$switchLocale` stále fungují. Funkční nastavení najdete ve variantě `pages-false` fixture `test/fixtures/basic` v repozitáři.
