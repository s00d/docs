---
title: "Vlastní detekce lokalizace"
description: "Zvolte lokalizaci sami — podle domény, hlavičky nebo uživatelského profilu — pomocí serverového pluginu a useI18nLocale().setLocale()."
---

Vestavěná detekce čte URL, cookie a `Accept-Language`. Když lokalizace závisí na něčem jiném — na doméně, geo hlavičce nastavené vaším CDN, uživatelském profilu — nastavte ji sami v pluginu, který běží před i18n pluginem. Modul pak načte překlady této lokalizace a použije ji pro přesměrování přesně tak, jako by ji sám detekoval. Pravidla, která rozhodují, kdy zvolená lokalizace vítězí nad URL, jsou na stránce [Detekce lokalizace](/cs/guide/locale-detection); tato stránka ukazuje, jak připojit vlastní zdroj.

## Nastavení lokalizace v serverovém pluginu {#set-the-locale-in-a-server-plugin}

```ts
// plugins/i18n-locale.server.ts
export default defineNuxtPlugin({
  name: 'i18n-custom-locale',
  enforce: 'pre',
  order: -10, // before the i18n plugin (order -5)
  setup() {
    const { setLocale } = useI18nLocale()
    const host = (useRequestHeaders(['host']).host ?? '').split(':')[0]! // without the port

    if (host.endsWith('.de')) setLocale('de')
    else if (host.endsWith('.fr')) setLocale('fr')
  },
})
```

`setLocale(code)` zapíše stav lokalizace (`useState('i18n-locale')`) a, pokud je nakonfigurována cookie lokalizace, i cookie. Použijte ho místo vlastního zápisu do `useState` nebo `useCookie`. Předávejte pouze kódy povolených lokalizací.

Ponechte plugin jako `.server.ts`, pokud čte hlavičky požadavku: v prohlížeči neexistují. Plugin `.client.ts` je místem pro zdroje dostupné jen v prohlížeči, jako je `localStorage`.

## Vypnutí vestavěného kroku Accept-Language {#turn-off-the-built-in-accept-language-step}

Váš plugin a `Accept-Language` se mohou rozcházet. Chcete-li, aby rozhodoval pouze váš kód (plus URL a cookie), vypněte hlavičku:

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    autoDetectLanguage: false,
  },
})
```

[`autoDetectLanguage`](/cs/api/module-options#autodetectlanguage) řídí pouze krok s hlavičkou. URL a platná cookie se stále počítají.

## Co se stane dál {#what-happens-next}

Účinek `setLocale` závisí na [strategii](/cs/guide/strategy):

| Strategie | Účinek `setLocale('de')` v pluginu |
| --- | --- |
| `no_prefix` | Stránka se vykreslí v němčině; URL se nezmění. |
| `prefix`, `prefix_except_default` | Na cestě bez prefixu, kde [`autoDetectPath`](/cs/api/module-options#autodetectpath) povoluje přesměrování (ve výchozím stavu pouze `/`), server odpoví `302` na německou URL. URL s prefixem lokalizace si ho ponechá. |
| `prefix_and_default` | Žádné přesměrování: URL bez prefixu je platná stránka výchozí lokalizace. |

U strategií s prefixem je lokalizace v URL volbou uživatele a váš plugin ji nepřepisuje. Výjimkou je `autoDetectPath: '*'`: server pak přesouvá URL s prefixem podle cookie a `Accept-Language` a stav ignoruje, ale `setLocale()` také zapisuje cookie, pokud je nakonfigurována, takže od dalšího požadavku může volba vašeho pluginu přesměrovat URL s prefixem. Ponechte `'/'` nebo použijte `'no_prefix'`, pokud musí explicitní URL lokalizací vítězit. Pomocí pluginu volte, kam návštěvník přistane, nikoli k přepisování odkazů, po kterých přišel.

## Respektování lokalizace zvolené uživatelem {#respect-a-locale-the-user-picked}

Jakmile uživatel přepne jazyk, přepnutí zapíše cookie. Pokud už existuje platná preference, vlastní detekci přeskočte:

```ts
// plugins/i18n-locale.server.ts
import { detectLocaleFromAcceptLanguage } from '@i18n-micro/utils/accept-language'

export default defineNuxtPlugin({
  name: 'i18n-custom-locale',
  enforce: 'pre',
  order: -10,
  setup() {
    const { getPreferredLocale, setLocale, validLocales } = useI18nLocale()
    if (getPreferredLocale()) return // valid state or cookie: keep it

    const country = useRequestHeaders(['x-country'])['x-country']
    if (country === 'JP') return setLocale('ja')

    const header = useRequestHeaders(['accept-language'])['accept-language']
    setLocale(detectLocaleFromAcceptLanguage(header, validLocales))
  },
})
```

`getPreferredLocale()` vrací stav nebo cookie pouze tehdy, je-li to povolená lokalizace, takže zastaralá cookie detekci nezastaví. `detectLocaleFromAcceptLanguage` je matcher zohledňující q-hodnoty, který používá sám modul (pro import nainstalujte `@i18n-micro/utils`); `setLocale(null)` nedělá nic.

## Jedna doména na lokalizaci {#one-domain-per-locale}

Pokud má každá doména obsluhovat vlastní lokalizace, plugin nepotřebujete: dejte každé lokalizaci `baseUrl`, nastavte `baseDefault: true` u výchozí lokalizace každé domény a sestavte jednou (statický web stále spouští `nuxi generate` pro každou doménu). Viz [Vrstvy a domény](/cs/guide/layers#multiple-domains).
