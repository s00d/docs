V `nuxt dev` modul přidává dvě pomůcky pro ladění: záložku **i18n Micro** v Nuxt DevTools pro procházení a úpravu souborů s překlady a inspektor ve Vue DevTools pro živé locale a načtené slovníky. Obě existují pouze ve vývoji a do produkčních sestavení nic nepřidávají. Záložka v Nuxtu vyžaduje jen zapnuté Nuxt DevTools; inspektor ve Vue navíc vyžaduje rozšíření prohlížeče Vue DevTools.

## Záložka Nuxt DevTools {#nuxt-devtools-tab}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  devtools: { enabled: true }, // the tab is registered only when DevTools are on
})
```

Otevřete Nuxt DevTools (`Shift + Alt + D`) a vyberte **i18n Micro**. Záložka zobrazuje:

- každý JSON soubor v `locales/` (kořen a `pages/`) každé vrstvy a navíc kořenové soubory z `additionalTranslationDirs`;
- editor pro každý soubor; **Save** zapíše soubor zpět na disk a vývojový server znovu načte překlady;
- **Export** / **Import** souboru jako JSON a **Stats** s počty klíčů a pokrytím překladů;
- zobrazení konfigurace s vyhodnocenými možnostmi modulu;
- **Translate**, které doplní chybějící klíče pomocí strojového překladače, jenž nakonfigurujete v nastavení záložky.

Ukládání zapisuje pouze existující soubory `.json` uvnitř vašich adresářů s překlady. Pokud soubor existuje ve více vrstvách, zapíše se kopie projektu.

## Inspektor ve Vue DevTools {#vue-devtools-inspector}

S rozšířením prohlížeče Vue DevTools modul registruje inspektor i18n (aktuální locale, chunk routy, načtené klíče) a časovou osu s přepnutími locale, načtením chunků a chybějícími klíči.

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    debug: true, // also log every $t / $ts / $tc call on the timeline
    // vueDevtools: false, // turn the inspector off, keep the Nuxt tab
  },
})
```

[`vueDevtools`](/cs/api/module-options) má výchozí hodnotu `true`. `debug: true` je velmi upovídané; používejte ho jen v krátkých relacích.
