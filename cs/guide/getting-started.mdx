Tato stránka provede aplikaci Nuxt od stavu bez i18n k přeložené stránce s přepínačem jazyků. Potřebujete ji jednou, na začátku projektu. Výsledkem jsou lokalizované URL (`/about`, `/de/about`), jeden JSON soubor pro každou lokalizaci a stránku a `$t` ve vašich šablonách.

## Instalace {#install}

Modul vyžaduje Nuxt 3.18 nebo novější (funguje i Nuxt 4) a Node 20 nebo novější.

<CodeGroup>

```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>

## Konfigurace lokalizací {#configure-the-locales}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', displayName: 'English' },
      { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
      { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
    ],
    defaultLocale: 'en',
  },
})
```

To je veškerá konfigurace, kterou první aplikace potřebuje. Výchozí hodnoty vám dávají:

- `strategy: 'prefix_except_default'`: výchozí lokalizace nemá prefix (`/about`), ostatní ano (`/de/about`). Viz [Strategie routování](/cs/guide/strategy).
- `translationDir: 'locales'`: soubory s překlady jsou v `locales/` v kořeni projektu, i při layoutu `app/` z Nuxt 4.
- `meta: true`: tagy `hreflang`, canonical a `og:locale` a také `lang` a `dir` na `<html>`. Viz [SEO](/cs/guide/seo).
- Návštěvník, který otevře `/`, je přesměrován na jazyk, který požaduje jeho prohlížeč (`Accept-Language`). Viz [Detekce lokalizace](/cs/guide/locale-detection).

`iso` je jazykový tag používaný v SEO tazích; `code` je to, co se objeví v URL. Všechny možnosti jsou uvedeny v [Možnostech modulu](/cs/api/module-options).

## Přidání souborů s překlady {#add-translation-files}

Spusťte vývojový server pomocí `nuxt dev`. Když Nuxt vyhodnotí stránky, modul vytvoří prázdný soubor `{}` pro každou lokalizaci a stránku, která ho nemá (vypnete to pomocí [`disableWatcher`](/cs/api/module-options#disablewatcher)):

```text
locales/
├── en.json            # root: keys every page can use
├── de.json
├── fr.json
└── pages/
    ├── index/         # pages/index.vue
    │   ├── en.json
    │   ├── de.json
    │   └── fr.json
    └── about/         # pages/about.vue
        ├── en.json
        ├── de.json
        └── fr.json
```

Vyplňte kořenový soubor a soubor stránky:

```json
// locales/en.json
{ "nav": { "home": "Home", "about": "About" } }
```

```json
// locales/pages/index/en.json
{ "welcome": "Welcome, {name}!", "items": "no items | one item | {count} items" }
```

Stránka vidí kořenové klíče i své vlastní klíče; při konfliktu vítězí její vlastní soubor. Názvy složek odpovídají názvu routy (`pages/articles/[id].vue` je `locales/pages/articles-id/`). Stránka [Soubory s překlady](/cs/guide/translations) popisuje strukturu, záložní hodnoty a načítání.

## Použití `$t` na stránce {#use-$t-on-a-page}

```vue
<!-- pages/index.vue -->
<script setup lang="ts">
const { t, tc, getLocale } = useI18n()

const title = t('nav.home') // 'Home'
</script>

<template>
  <h1>{{ $t('welcome', { name: 'Ada' }) }}</h1>
  <!-- Welcome, Ada! -->
  <p>{{ $tc('items', 3) }}</p>
  <!-- 3 items -->
  <p>{{ getLocale() }}</p>
  <!-- en -->
</template>
```

- V šablonách je každý helper dostupný s `$` (`$t`, `$tc`, `$localePath`, …).
- V `<script setup>` vrací `useI18n()` stejné helpery, s `$` i bez něj (`t` a `$t` jsou jedna funkce). Importuje se automaticky.
- Zástupné symboly `{name}` se vyplní z objektu parametrů. Tvary plurálu se oddělují znakem `|`; počet vybírá tvar (0, 1, pak poslední pro vše vyšší).

Všechny helpery jsou uvedeny v [Metodách](/cs/api/methods).

## Odkazy mezi stránkami a přepínání lokalizace {#link-between-pages-and-switch-locale}

```vue
<!-- components/AppHeader.vue -->
<template>
  <nav>
    <i18n-link :to="{ name: 'index' }">{{ $t('nav.home') }}</i18n-link>
    <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
    <i18n-switcher />
  </nav>
</template>
```

- [`<i18n-link>`](/cs/components/i18n-link) je `NuxtLink`, který ukazuje na stránku v aktuální lokalizaci: na `/de` vede odkaz about na `/de/about`.
- [`<i18n-switcher>`](/cs/components/i18n-switcher) je rozbalovací seznam povolených lokalizací; návštěvníka ponechá na stejné stránce.
- Pro vlastní tlačítka volejte `$switchLocale('de')`, které přejde na aktuální stránku v němčině a zapamatuje si volbu. Pro obyčejný `NuxtLink` použijte `$localePath({ name: 'about' })` nebo `$switchLocalePath('de')`.

## Ověření {#check-it}

Spusťte `nuxt dev` a otevřete:

| URL | Zobrazí |
| --- | --- |
| `/` | Anglickou domovskou stránku (nebo přesměrování na `/de`, pokud váš prohlížeč preferuje němčinu) |
| `/de` | Německou domovskou stránku |
| `/de/about` | Německou stránku about |
| `/en/about` | 404: výchozí lokalizace nemá při `prefix_except_default` prefix |

Úpravy JSON souborů se projeví na otevřené stránce bez znovunačtení.
