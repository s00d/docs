### Popis {#description}

Porovnává **čistý Nuxt**, **i18n-micro** a **`@nuxtjs/i18n`** při jednom sdíleném profilu slovníků pomocí `untestutils/perf`.

Zaměření: doba buildu, špičkové RSS, nasaditelný **kód vs. překlady (asset) vs. celkem** a zátěž (Artillery).

### Poznámky k metodice {#methodology-notes}

- Metriky jsou **průměry 3 po sobě jdoucích běhů na fixturu** (nikoli prokládaně).
- **Artefakt**: Nitro node-server `.output/server/index.mjs` po vynuceném `nuxi build`; `nuxt-i18n-micro` je **sestavený dist modulu** (nikoli jiti stub z `dev:prepare`). Viz [metodika benchmarků](https://s00d.github.io/nuxt-i18n-micro/contributing/performance-methodology).
- **Překlady** = `bundle.asset` (JSON lokalizací, `chunks/raw/`, odpovídající části lokalizací přes `isTranslationFile`).
- **Kód** nezahrnuje source mapy (`*.map`): fixtury linkují modul z repozitáře, takže pro něj Nitro zapisuje úplné mapy a pro npm závislosti žádné.
- **plain-nuxt** servíruje stejný objem listů jako statický JSON — při zátěži náročné na I/O, nikoli „režie i18n“.
- Profil zátěže `--load full`: zahřátí 6s@6 + hlavní 60s@60 bez omezení (historický).
- Prodlevy `--cool fast` (viz dokument o metodice).
- Každý z buildů `runs` je **vynucený** (žádné nulování doby buildu díky teplé cache).
- **Error rate** z Artillery v tabulkách jsou chyby HTTP stavů z metrik zátěže. Grafy vykreslují také `vusers.failed` (timeouty klienta při saturaci); ty mohou být vysoké, zatímco chybovost HTTP zůstává 0 %.

## Poznámky {#notes}

- Sdílený profil: 4 lokalizace × 2 stránky × ~16,8k listů indexu.
- Zátěž: pouze programové Artillery — zahřátí **6s@6** + hlavní **60s@60**, neomezené VU (historická metodika YAML). Cesty z runtime profilu — viz `scripts/src/perf/load.ts`.
- Prodlevy: 2 s po buildu, 3 s mezi běhy, 5 s mezi fixturami. Buildy jsou vynucené při každém běhu, takže průměry nejsou zkreslené zásahy do cache.
- Běžné opakované spuštění: `pnpm test:performance` (`--load short --cool fast`).
- Přegenerování této stránky: `pnpm -C scripts cli performance --load full --only all --runs 3`.
- Přepínače: `--locales N --keys K --only all|micro|i18n|plain --runs N --skip-load --cool fast|strict`.
