[Crowdin](https://crowdin.com/) je překladatelská platforma: nahrajete soubory výchozího locale, překladatelé pracují v Crowdinu a ostatní locale si stáhnete zpět. Modul čte prosté soubory JSON, takže Crowdin CLI potřebuje jen `crowdin.yml`, který správně mapuje `locales/` a `locales/pages/`. Žádné nastavení modulu se nemění.

## Konfigurace crowdin.yml {#configure-crowdin-yml}

```yml
# crowdin.yml
project_id_env: CROWDIN_PROJECT_ID
api_token_env: CROWDIN_PERSONAL_TOKEN
base_path: ./locales
preserve_hierarchy: true

files:
  - source: /en.json
    translation: /%two_letters_code%.json
  - source: /pages/**/en.json
    translation: /pages/**/%two_letters_code%.json
```

- `en` je vaše výchozí locale; jeho soubory jsou zdrojové.
- `project_id_env` / `api_token_env` čtou ID a token z proměnných prostředí, takže se necommituje žádné tajemství.
- `preserve_hierarchy: true` zachová složky `pages/<page>/` tak, jak jsou.
- Název přeloženého souboru se musí shodovat s `code` daného locale v `nuxt.config.ts`. `%two_letters_code%` vyhovuje kódům jako `de`; pro kódy jako `pt-BR` použijte `%locale%`, nebo namapujte kódy Crowdinu na své pomocí `languages_mapping`.

## Nahrání a stažení {#upload-and-download}

```bash
npm install -g @crowdin/cli

export CROWDIN_PROJECT_ID=123456
export CROWDIN_PERSONAL_TOKEN=...   # from Crowdin account settings

crowdin upload sources   # push locales/en.json and locales/pages/**/en.json
crowdin download         # write locales/de.json, locales/pages/**/de.json, ...
```

Spouštějte obojí v CI, aby soubory zůstaly aktuální. Stažené soubory skončí ve vašem repozitáři stejně jako ručně upravené; další sestavení nebo reload ve vývojovém režimu je načte.

## Před nahráním {#before-uploading}

Nejprve vyčistěte zdrojové soubory, aby překladatelé nepracovali na mrtvých klíčích: [`i18n-micro clean`](/cs/api/cli#clean) odstraní nepoužívané klíče, [`i18n-micro check`](/cs/api/cli#check) po stažení nahlásí mezery. CLI nemá vlastní integraci s Crowdinem: tato stránka popisuje podporovaný postup.
