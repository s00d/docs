---

Modul pro Nuxt je sestaven z malých balíčků `@i18n-micro/*` a většina z nich funguje i samostatně: `@i18n-micro/vue` ve Vue aplikaci, `@i18n-micro/core` kdekoli. Na těchto stránkách zjistíte, co balíček exportuje, a to pro každý vstupní bod. Každá stránka je generována ze snímku, který [`pnpm run api:surface`](https://s00d.github.io/nuxt-i18n-micro/contributing/maintenance-commands#api-surface) kontroluje vůči zdrojům v TypeScriptu, takže se žádný export nemůže změnit, aniž by si toho CI všimlo.
