Modul volá jeden runtime hook (hook aplikace), `i18n:register`. Použijte ho, když plugin nebo modul přidává překlady, které nejsou ve vašich souborech `locales/`. Váš callback dostane funkci `register`, která sloučí překlady do právě zobrazované stránky.

## `i18n:register` {#i18nregister}

```ts
'i18n:register': (
  register: (translations: unknown, locale?: string) => void,
  locale: string,
) => HookResult
```

| Argument | Popis |
| --- | --- |
| `register(translations, locale?)` | Hloubkově sloučí `translations` do chunku stránky načítané trasy pro `locale` (výchozí: `locale` hooku). Již existující klíče se přepíší. |
| `locale` | Lokalizace načítané trasy. |

Hook je typovaný přes `RuntimeNuxtHooks`, takže `nuxtApp.hook('i18n:register', …)` nepotřebuje přetypování.

## Kdy se spouští {#when-it-fires}

Volá ho plugin loaderu (`i18n-plugin-loader`):

1. jednou při spuštění, když proběhly všechny pluginy (`app:created`), a před vykreslením aplikace;
2. ve svém `router.beforeEach`, po načtení překladů cílové stránky, když se změní cesta — při každé navigaci v režimu `no_prefix`.

Na každý callback a každé volání `register` se čeká, než se aplikace vykreslí nebo navigace pokračuje, takže se stránka vykreslí se sloučenými klíči. S [`hooks: false`](/cs/api/module-options#hooks) se hook nikdy nevolá.

## Příklad {#example}

```ts
// plugins/i18n-extra.ts
export default defineNuxtPlugin((nuxtApp) => {
  nuxtApp.hook('i18n:register', async (register, locale) => {
    const extra = await $fetch<Record<string, unknown>>(`/api/cms-strings/${locale}`)
    register(extra, locale)
  })
})
```

Jde o runtime hook: registrujte ho pomocí `nuxtApp.hook` v pluginu, nikoli pomocí `nuxt.hook` v `nuxt.config` nebo v `setup` modulu. Modul takový plugin přidá pomocí `addPlugin`.
