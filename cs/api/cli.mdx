## Společné přepínače {#common-flags}

| Přepínač | Výchozí | Popis |
| --- | --- | --- |
| `--cwd` | aktuální adresář | Adresář projektu |
| `--logLevel` | `info` | Úroveň výstupu: silent, info |
| `--debug` | `false` | Vypsat stack trace, když příkaz selže |

## Kontrola {#inspect}

### `info` {#info}

Vypíše vyhodnocenou konfiguraci i18n projektu

| Přepínač | Výchozí | Popis |
| --- | --- | --- |
| `--json` | `false` | Vypsat JSON místo textu |

### `check` {#check}

Brána pro CI: selže při chybějících, prázdných, nadbytečných, nedefinovaných nebo nepoužívaných klíčích a poškozených zástupných symbolech

| Přepínač | Výchozí | Popis |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` z nuxt.config | Adresář s překlady, relativně k projektu |
| `--only` | vše kromě duplicit | Čárkami oddělené kontroly ke spuštění: missing, empty, extra, placeholders, undefined, unused, duplicates. Pokud je zde uvedeno `unused` a nelze jej spustit, příkaz selže |
| `--duplicates` | `false` | Hlásit také stejný text pod různými klíči |
| `--ignore` | — | Čárkami oddělené globy zdrojových souborů k přeskočení, relativně k projektu |
| `--json` | `false` | Vypsat JSON místo textu |

```bash
i18n-micro check
i18n-micro check --only missing,placeholders --json
```

### `stats` {#stats}

Zobrazí dokončenost překladů pro každou locale

| Přepínač | Výchozí | Popis |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` z nuxt.config | Adresář s překlady, relativně k projektu |
| `--html` | — | Zapsat také HTML report do tohoto souboru |
| `--json` | `false` | Vypsat JSON místo textu |
| `--baseRef` | — | Git ref, se kterým se dokončenost porovná, např. HEAD~1 nebo main |

```bash
i18n-micro stats --baseRef main
i18n-micro stats --html reports/i18n.html
```

### `lint` {#lint}

Zkontroluje text překladů; selže, pokud zůstanou problémy

| Přepínač | Výchozí | Popis |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` z nuxt.config | Adresář s překlady, relativně k projektu |
| `--rules` | všechna, nebo `enabledRules` z .i18n-lintrc.json | Čárkami oddělená pravidla ke spuštění: no-trailing-spaces, no-multiple-spaces, no-empty-translation nebo vlastní pravidlo |
| `--fix` | `false` | Opravit, co lze opravit: mezery a vlastní pravidla s náhradou |
| `--json` | `false` | Vypsat JSON místo textu |

```bash
i18n-micro lint --rules no-trailing-spaces --fix
```

### `search` {#search}

Vyhledá klíče a hodnoty a ukáže, kde se každý klíč používá

| Přepínač | Výchozí | Popis |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` z nuxt.config | Adresář s překlady, relativně k projektu |
| `<query>` | — | Text nebo klíč k vyhledání |
| `--caseSensitive` | `false` | Rozlišovat velikost písmen |
| `--onlyUnused` | `false` | Pouze klíče, které by odstranil `clean`; dotaz se stává volitelným |
| `--scope` | `all` | Kde hledat: global, pages, all |
| `--limit` | — | Vrátit nejvýše tento počet klíčů |
| `--ignore` | — | Čárkami oddělené globy zdrojových souborů k přeskočení, relativně k projektu |
| `--json` | `false` | Vypsat JSON místo textu |

```bash
i18n-micro search "Welcome"
i18n-micro search --onlyUnused
```

## Pracovní postup překladu {#translation-workflow}

### `extract` {#extract}

Vypíše klíče používané ve zdrojových souborech, které zatím nemají text, a ty s výchozím textem přidá do výchozí locale

| Přepínač | Výchozí | Popis |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` z nuxt.config | Adresář s překlady, relativně k projektu |
| `--ignore` | — | Čárkami oddělené globy zdrojových souborů k přeskočení, relativně k projektu |

```bash
i18n-micro extract
```

### `translate` {#translate}

Doplní chybějící překlady z výchozí locale pomocí překladové služby

| Přepínač | Výchozí | Popis |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` z nuxt.config | Adresář s překlady, relativně k projektu |
| `--service` | — | Překladová služba: ai, azure, deepl, google, libretranslate, yandexcloud |
| `--token` | — | API klíč. Upřednostněte proměnnou prostředí I18N_TRANSLATE_TOKEN: přepínače končí v historii shellu |
| `--options` | — | Volby služby jako páry key:value oddělené čárkami |
| `--locale` | každá locale kromě výchozí | Čárkami oddělené locale k doplnění |
| `--replace` | `false` | Přeložit znovu každý klíč a nahradit stávající hodnoty |
| `--dryRun` | `false` | Spočítat klíče a znaky pro každou locale; nic neodesílat |
| `--chunkSize` | — | Počet řetězců na požadavek; omezeno tím, co služba přijme |
| `--pluralSeparator` | `\|` | Oddělovač tvarů množného čísla ve zprávách |
| `--glossaryFile` | `.i18n-glossary.json`, pokud existuje | Soubor glosáře, používaný službou `ai` |

```bash
i18n-micro translate --dryRun
I18N_TRANSLATE_TOKEN=... i18n-micro translate --service deepl --locale de,fr
i18n-micro translate --service ai --options provider:openai,model:gpt-4o-mini
i18n-micro translate --service libretranslate --options baseUrl:https://translate.example.com
```

### `sync` {#sync}

Odstraní klíče, které výchozí locale nemá; zastaví se, pokud nelze prokázat, že je to bezpečné. Chybějící klíče zůstanou chybějící

| Přepínač | Výchozí | Popis |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` z nuxt.config | Adresář s překlady, relativně k projektu |
| `--ignore` | — | Čárkami oddělené globy zdrojových souborů k přeskočení, relativně k projektu |
| `--dryRun` | `false` | Vypsat, co by bylo odstraněno; nic nezapisovat |
| `--force` | `false` | Odstranit klíče, i když nelze prokázat, že je to bezpečné |

```bash
i18n-micro sync --dryRun
```

### `clean` {#clean}

Odstraní klíče, které nic v projektu nepoužívá; zastaví se, pokud to nelze prokázat

| Přepínač | Výchozí | Popis |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` z nuxt.config | Adresář s překlady, relativně k projektu |
| `--include` | — | Regulární výraz: k odstranění zvažovat pouze odpovídající klíče |
| `--exclude` | — | Regulární výraz: odpovídající klíče nikdy neodstraňovat |
| `--ignore` | — | Čárkami oddělené globy zdrojových souborů k přeskočení, relativně k projektu |
| `--dryRun` | `false` | Vypsat, co by bylo odstraněno; nic nezapisovat |
| `--force` | `false` | Odstranit klíče, i když nelze prokázat použití u všech z nich |

```bash
i18n-micro clean --dryRun
i18n-micro clean --exclude '^errors\.'
```

## Refaktoring {#refactoring}

### `text-to-i18n` {#text-to-i18n}

Nahradí napevno zapsaný text ve Vue šablonách voláními překladu a nahlásí napevno zapsaný text v kódu

| Přepínač | Výchozí | Popis |
| --- | --- | --- |
| `--translationFile` | `<translationDir>/<defaultLocale>.json` | Soubor, do kterého jdou nové klíče |
| `--path` | celý projekt | Soubor nebo adresář ke zpracování |
| `--context` | — | Prefix generovaných klíčů |
| `--ignore` | — | Čárkami oddělené globy zdrojových souborů k přeskočení, relativně k projektu |
| `--dryRun` | `false` | Ukázat, co by se změnilo; nic nezapisovat |
| `--interactive` | `false` | Potvrdit nebo upravit každý vygenerovaný klíč |

```bash
i18n-micro text-to-i18n --dryRun
i18n-micro text-to-i18n --path components --context ui
```

### `rename` {#rename}

Přejmenuje klíč nebo jmenný prostor ve všech locale a ve zdrojových souborech

| Přepínač | Výchozí | Popis |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` z nuxt.config | Adresář s překlady, relativně k projektu |
| `--from` **\*** | — | Aktuální klíč nebo jmenný prostor |
| `--to` **\*** | — | Nový klíč nebo jmenný prostor |
| `--ignore` | — | Čárkami oddělené globy zdrojových souborů k přeskočení, relativně k projektu |
| `--dryRun` | `false` | Nahlásit změny; nic nezapisovat |

**\*** povinné.

```bash
i18n-micro rename --from common.save --to actions.save
```

### `pseudo` {#pseudo}

Naplní locale pseudo-překlady pro nalezení problémů s rozvržením a napevno zapsaným textem

| Přepínač | Výchozí | Popis |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` z nuxt.config | Adresář s překlady, relativně k projektu |
| `--sourceLocale` | výchozí locale | Locale ke čtení |
| `--targetLocale` **\*** | — | Locale k naplnění |
| `--replace` | `false` | Přepsat stávající hodnoty |

**\*** povinné.

### `format` {#format}

Přepíše soubory locale se seřazenými klíči a jednotným odsazením

| Přepínač | Výchozí | Popis |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` z nuxt.config | Adresář s překlady, relativně k projektu |
| `--indent` | `2` | Počet mezer odsazení |
| `--sortKeys` | `true` | Seřadit klíče; pro zachování jejich pořadí použijte --no-sortKeys |
| `--check` | `false` | Selhat, pokud by se soubor změnil; nic nezapisovat |

```bash
i18n-micro format --check
```

## Výměna {#exchange}

### `export` {#export}

Exportuje soubory locale do PO nebo CSV s textem výchozí locale jako zdrojem

| Přepínač | Výchozí | Popis |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` z nuxt.config | Adresář s překlady, relativně k projektu |
| `--format` | `po` | Formát souboru: po, csv |
| `--dir` | `pots` pro po, `csv_exports` pro csv | Výstupní adresář, relativně k projektu |
| `--force` | `false` | Přepsat soubory změněné od posledního exportu, které nebyly nikdy importovány |

```bash
i18n-micro export --format csv
```

### `import` {#import}

Sloučí soubory PO nebo CSV do souborů locale

| Přepínač | Výchozí | Popis |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` z nuxt.config | Adresář s překlady, relativně k projektu |
| `--format` | `po` | Formát souboru: po, csv |
| `--dir` | `pots` pro po, `csv_exports` pro csv | Vstupní adresář, relativně k projektu |
| `--dryRun` | `false` | Nahlásit, co by bylo importováno; nic nezapisovat |

```bash
i18n-micro import --format csv --dryRun
```

### `sync-remote` {#sync-remote}

Stáhne globální překlady z HTTP endpointu v .i18n-remote.json, nebo je na něj odešle

| Přepínač | Výchozí | Popis |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` z nuxt.config | Adresář s překlady, relativně k projektu |
| `--pull` | `true` | Stáhnout ze vzdáleného úložiště |
| `--push` | `false` | Odeslat do vzdáleného úložiště |
| `--force` | `false` | Při stahování převzít vzdálenou hodnotu; při odesílání přepsat text, který má pouze vzdálené úložiště |
| `--dryRun` | `false` | Nahlásit, co by stažení změnilo; nic nezapisovat ani neodesílat |

```bash
i18n-micro sync-remote --dryRun
i18n-micro sync-remote --no-pull --push
```

## Pravidla lintu {#lint-rules}

| Pravidlo | Najde | Opraveno pomocí `--fix` |
| --- | --- | --- |
| `no-trailing-spaces` | Mezery na konci hodnoty nebo řádku | ano |
| `no-multiple-spaces` | Dvě nebo více mezer za sebou | ano |
| `no-empty-translation` | Prázdnou hodnotu nebo hodnotu jen z bílých znaků | ne |

## Návratové kódy {#exit-codes}

| Kód | Význam |
| --- | --- |
| `0` | Hotovo, nic k nahlášení |
| `1` | Nálezy: `check`, `lint` nebo `format --check` něco našly, `clean` nebo `sync` nemohly prokázat, že je odstranění bezpečné, `export` by přepsal neimportovanou práci, `translate` vynechal klíče, `import` nebo `sync-remote` narazily na konflikt, odeslání `sync-remote` by zahodilo vzdálený text. `--dryRun` u `clean`, `sync` nebo stahování `sync-remote` tyto nálezy nahlásí a skončí s kódem `0` |
| `2` | Selhání: chybné použití, nečitelný projekt, chyba sítě nebo souboru |

## Konfigurační soubory {#configuration-files}

| Soubor | Používá |
| --- | --- |
| `.i18n-lintrc.json` | `lint`: `enabledRules`, `disabledRules`, `customRegexRules` (`name`, `pattern`, `flags`, `description`, `replacement`) |
| `.i18n-remote.json` | `sync-remote`: `url`, `path`, `token`, `auth` (`username`, `password`). `type` lze vynechat; existuje pouze `custom` |
| `.i18n-glossary.json` | `translate --service ai`: `entries` s `source`, `target` a volitelnými `from`, `to` |

## Proměnné prostředí {#environment-variables}

| Název | Použití |
| --- | --- |
| `I18N_TRANSLATE_TOKEN` | API klíč pro `translate`. Čte se také z `.env` |
| `I18N_REMOTE_TOKEN` | Bearer token pro `sync-remote`. Čte se také z `.env` |
| `AI_GATEWAY_API_KEY, OPENAI_API_KEY, ANTHROPIC_API_KEY` | Klíč služby `ai`, pokud není nastaven `I18N_TRANSLATE_TOKEN` |
| `DEFAULT_LOCALE` | Přepisuje `defaultLocale`, stejně jako v modulu |
