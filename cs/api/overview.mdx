# Referenční příručka API

## Runtime API

- [Metody](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, přepínání locale, pomocníci pro routování
- [Události](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Překlady a cache](/api/cache) — `TranslationStorage`, načítání payloadu, `$clearCache`

## Serverový middleware

Serverové handlery používají vyhrazený middleware (nikoli klientské pomocníky `$t`):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — překlady v API routách a serverových handlerech
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — čtení detekovaného locale a metadat

Kompletní nastavení, prioritu detekce locale a příklady najdete v příručce [Překlady na straně serveru](/guides/server-side-translations).
