Tato sekce uvádí všechny možnosti, pomocné funkce, hooky, composables a komponenty modulu pro Nuxt a také exportované API každého balíčku `@i18n-micro/*`. Použijte ji k vyhledání signatury nebo výchozí hodnoty; [Průvodce](/cs/guide/getting-started) vysvětluje, jak je používat. Většina tabulek je zde generována ze zdrojového kódu, takže odpovídají kódu.

## Modul pro Nuxt {#nuxt-module}

| Stránka | Obsah |
| --- | --- |
| [Možnosti modulu](/cs/api/module-options) | Každý klíč `i18n` v `nuxt.config` s typem a výchozí hodnotou |
| [Pomocné funkce](/cs/api/methods) | `$t`, `$tc`, `$tn`, `$td`, `$localePath`, `$switchLocale`, `$defineI18nRoute` a další |
| [Hooky](/cs/api/events) | Runtime hook `i18n:register` |

## Composables {#composables}

| Composable | Použití |
| --- | --- |
| [`useI18n`](/cs/composables/useI18n) | Pomocné funkce v `<script setup>` |
| [`useI18nLocale`](/cs/composables/useI18nLocale) | Stav locale a cookie ve vlastním pluginu pro detekci |
| [`useI18nHead`](/cs/composables/useI18nHead) | Přepsání generovaných SEO tagů pro jednotlivé stránky |
| [`useLocaleHead`](/cs/composables/useLocaleHead) | SEO tagy jako objekt pro vlastní `useHead` |

## Komponenty {#components}

| Komponenta | Vykresluje |
| --- | --- |
| [`<i18n-t>`](/cs/components/i18n-t) | Jeden překlad s pluralizací, formátováním a interpolací slotů |
| [`<i18n-link>`](/cs/components/i18n-link) | `NuxtLink` na lokalizovanou routu |
| [`<i18n-switcher>`](/cs/components/i18n-switcher) | Rozbalovací nabídku locale |
| [`<i18n-group>`](/cs/components/i18n-group) | Blok se sdíleným prefixem klíčů |

## Server {#server}

Handlery Nitro používají `useTranslationServerMiddleware` a `useLocaleServerMiddleware`, nikoli klientské pomocné funkce. Viz [Serverové routy](/cs/guide/server-side-translations).

## Balíčky {#packages}

[API balíčků](/cs/api/packages/overview) uvádí exporty každého balíčku `@i18n-micro/*`, pro každý jednu generovanou stránku.
