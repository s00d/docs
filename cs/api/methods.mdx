# 🛠️ Metody

Tato stránka dokumentuje všechny dostupné metody poskytované modulem nuxt-i18n-micro. Metody jsou pro snadnější orientaci uspořádané podle funkčnosti.

## 🔍 Metody překladu

Základní metody pro získávání a správu překladů.

### `$t`

{/* generated:method:$t — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Přeloží klíč a interpoluje do něj `params`. Vrátí `defaultValue`, když klíč chybí, nebo samotný klíč, pokud není zadána výchozí hodnota.

{/* /generated:method:$t */}

```typescript
const welcomeMessage = $t('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

<Warning>
`$t` vrací `CleanTranslation`, což je `string | number | boolean | Translations | PluralTranslations | null`. Pokud klíč odkazuje na **vnořený objekt** ve vašem JSON (např. `$t('header')`, když JSON obsahuje `\{ "header": \{ "title": "Hi" \} \}`), návratovou hodnotou bude tento **objekt**, nikoli řetězec. Přímé použití ve Vue šabloně (<code v-pre>\{\{ $t('header') \}\}</code>) se vykreslí jako `[object Object]`.

**Jak se tomu vyhnout:**

- Použijte konkrétnější klíč: `$t('header.title')` → `"Hi"`
- Použijte `$ts()`, které vždy vrací řetězec (na neřetězcových hodnotách volá `.toString()`)
- Použijte `$t` s vnořeným klíčem pro záměrný přístup k pod-objektům pro programové použití
</Warning>

### `$ts`

{/* generated:method:$ts — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string) => string
```

Jako `$t`, ale vždy vrací řetězec: objektová nebo polová hodnota se konvertuje na řetězec místo vrácení tak, jak je.

{/* /generated:method:$ts */}

```typescript
const welcomeMessage = $ts('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

### `$_t` a `$_ts`

{/* generated:method:$_t — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Naváže `$t` na konkrétní routu, pro překlady mimo aktuální stránku. Například layout vykreslující odkaz na jinou routu.

{/* /generated:method:$_t */}

{/* generated:method:$_ts — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => string
```

Naváže `$ts` na konkrétní routu. Viz `$_t`.

{/* /generated:method:$_ts */}

Varianty `$t` a `$ts` navázané na routu. Přijímají nejprve **routu** a vracejí funkci překladu uzamčenou na locale a kontext stránky této routy.

- **Přístup**: `useNuxtApp()` (reexportováno také přes `useI18n()` jako `$_t` / `$_ts`)

Používejte je, když se aktivní routa během SSR nebo přechodů liší od `router.currentRoute`, například uvnitř `<i18n-t>`, `<i18n-group>` nebo při vykreslování obsahu pro konkrétní objekt `route`.

```typescript
import { useRoute, useNuxtApp } from '#imports'

const route = useRoute()
const { $_t, $_ts } = useNuxtApp()

const $t = $_t(route)
const title = $t('page.title')

// String-safe variant
const label = $_ts(route)('page.label')
```


### `$tc`

{/* generated:method:$tc — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params: number | Params, defaultValue?: string) => string
```

Přeloží s pluralizací. `params` může být samotný počet, nebo objekt obsahující `count`.

{/* /generated:method:$tc */}

**Formát překladu**: tvary oddělené `|`. Placeholdery umístěte do **každého** tvaru:

```json
{
  "apples": "no apples | one apple | {count} apples",
  "cart": "no items for {name} | one item for {name} | {count} items for {name}"
}
```

```typescript
$tc('apples', 0) // "no apples"
$tc('apples', 1) // "one apple"
$tc('apples', 10) // "10 apples"

// count + other params (second argument must be an object)
$tc('cart', { count: 10, name: 'Alice' }) // "10 items for Alice"
```


**Alternativa komponenty**: `<i18n-t keypath="cart" :plural="count" :params="\{ name \}" />` (interně sloučí `count` s `params`).


### `$mergeTranslations`

{/* generated:method:$mergeTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
(newTranslations: Translations) => void
```

Sloučí překlady do aktivního locale za běhu a přepíše to, co je načtené.

{/* /generated:method:$mergeTranslations */}

```typescript
$mergeTranslations({
  welcome: 'Bienvenue, {username}!',
})
// Output: Updates the translation cache with the new French translation
```

### `$resolveTranslations`

{/* generated:method:$resolveTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
() => Translations
```

Všechny překlady aktuálně v paměti pro aktivní locale a routu, jako strom. Pohled read-only na to, co může `$t()` právě teď vyřešit.

{/* /generated:method:$resolveTranslations */}

```typescript
const tree = $resolveTranslations()
// { aaa: { bbb: 'ccc' }, ddd: 1111 } — the same dictionary $t() reads from
```

Použijte tuto metodu, když potřebujete kompletní in-memory slovník (DevTools, testy, runtime editory). K návratové hodnotě přistupujte jako k read-only. Hodnoty měňte přes `$setTranslation` nebo slučte patche pomocí `$mergeTranslations`.

### `$setTranslation`

{/* generated:method:$setTranslation — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, value: unknown) => void
```

Nahradí hodnotu na `key` v aktivním slovníku. Jde o nahrazení, ne o sloučení. Když by měli přežít existující sourozenci, použijte `$mergeTranslations`.

{/* /generated:method:$setTranslation */}

```typescript
$setTranslation('aaa', { fff: 'ggg' }) // replaces the whole `aaa` subtree
$setTranslation('aaa', 'text')          // replaces `aaa` with a string
$setTranslation('ddd', 1111)            // scalar at the top level
$setTranslation('aaa.bbb', 'nested')    // dotted path
```

Jde o **nahrazení**, ne o sloučení. Existující sourozenci pod stejným klíčem se odstraní. Pokud chcete patchovat bez ztráty sourozenců, použijte `$mergeTranslations`.

### `$setMissingHandler`

{/* generated:method:$setMissingHandler — do not edit; run `pnpm run docs:generate` */}

```ts
(handler: MissingHandler | null) => void
```

Nainstaluje callback vyvolaný pro každý nevyřešený klíč. Předáním `null` jej odstraníte.

{/* /generated:method:$setMissingHandler */}

**Definice typu**:

```typescript
type MissingHandler = (locale: string, key: string, routeName: string, instance?: unknown, type?: string) => void
```

```typescript
// Set a custom handler
$setMissingHandler((locale, key, routeName) => {
  console.error(`Missing translation: ${key} in ${locale} for route ${routeName}`)
  // Send to Sentry or other error tracking service
  // Sentry.captureMessage(`Missing translation: ${key}`)
})

// Remove the handler
$setMissingHandler(null)
```

**Případy použití**:

- Logování chybějících překladů do služeb sledování chyb (Sentry, LogRocket a další)
- Sběr analytiky ohledně chybějících překladů
- Vlastní ošetření chyb pro chybějící klíče překladů

## 🔢 Formátování čísel a dat

Metody pro formátování čísel a dat podle konvencí locale.

### `$tn`

{/* generated:method:$tn — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Naformátuje číslo pomocí `Intl.NumberFormat` v aktivním locale. Klíč vybírá pojmenovaný formát z konfigurace.

{/* /generated:method:$tn */}

```typescript
// Inline options
const formattedNumber = $tn(1234567.89, { style: 'currency', currency: 'USD' })
// "$1,234,567.89"

// Named format (from nuxt.config i18n.numberFormats)
const price = $tn(1000, 'currency')
const priceDe = $tn(1000, 'currency', 'de')
const compact = $tn(1000, 'currency', { notation: 'compact' })
```

Neznámé klíče pojmenovaných formátů se vrátí k výchozím možnostem `Intl.NumberFormat`. Ve vývoji (na klientu) se při zapnutém `missingWarn` (výchozí) vypíše `console.warn`.

**Příklad konfigurace**:

```ts
export default defineNuxtConfig({
  i18n: {
    numberFormats: {
      en: {
        currency: { style: 'currency', currency: 'USD' },
        decimal: { style: 'decimal', minimumFractionDigits: 2, maximumFractionDigits: 2 },
      },
      de: {
        currency: { style: 'currency', currency: 'EUR' },
      },
    },
  },
})
```

**Případy použití**:

- Formátování čísel jako měny, procent nebo desetinných hodnot ve formátu odpovídajícím danému locale
- Znovupoužití pojmenovaných formátů v celé aplikaci (parita s migrací z Vue I18n)

### `$td`

{/* generated:method:$td — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Naformátuje datum pomocí `Intl.DateTimeFormat` v aktivním locale. Klíč vybírá pojmenovaný formát z konfigurace.

{/* /generated:method:$td */}

```typescript
const formattedDate = $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' })
// "Friday, September 1, 2023"

const short = $td(new Date(), 'short')
const longDe = $td(new Date(), 'long', 'de')
```

Neznámé klíče pojmenovaných formátů se vrátí k výchozím možnostem `Intl.DateTimeFormat`. Ve vývoji (na klientu) se při zapnutém `missingWarn` (výchozí) vypíše `console.warn`.

**Příklad konfigurace**:

```ts
export default defineNuxtConfig({
  i18n: {
    datetimeFormats: {
      en: {
        short: { year: 'numeric', month: 'short', day: 'numeric' },
        long: { year: 'numeric', month: 'long', day: 'numeric', weekday: 'long' },
      },
    },
  },
})
```

**Případy použití**:

- Zobrazování dat ve formátu odpovídajícím locale uživatele
- Sdílení předvoleb short/long/date-time napříč aplikací

### `$tdr`

{/* generated:method:$tdr — do not edit; run `pnpm run docs:generate` */}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

Naformátuje datum jako relativní čas („před 3 dny“) pomocí `Intl.RelativeTimeFormat`.

{/* /generated:method:$tdr */}

```typescript
const relativeDate = $tdr(new Date(Date.now() - 1000 * 60 * 5))
// Output: "5 minutes ago" in the 'en-US' locale
```

## 🔄 Přepínání route a locale

Metody pro přepínání mezi locale a routami.

### `$switchLocale`

{/* generated:method:$switchLocale — do not edit; run `pnpm run docs:generate` */}

```ts
(locale: string) => void
```

Přejde na aktuální stránku v jiném locale.

{/* /generated:method:$switchLocale */}

```typescript
$switchLocale('fr')
// Prefix strategies: navigates to the French version of the route
// no_prefix: updates locale and translations without changing the URL path
```

<Tip>
Viz [FAQ: přepnutí locale beze změny URL](/guides/faq#-switch-locale-without-changing-the-url). Pro prefixové strategie použijte `$switchLocalePath()`, pokud potřebujete jen cíl odkazu.
</Tip>

### `$switchLocaleRoute`

{/* generated:method:$switchLocaleRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(locale: string) => RouteLocationRaw
```

Route objekt pro aktuální stránku v jiném locale, bez navigace.

{/* /generated:method:$switchLocaleRoute */}

```typescript
// on /en/news
const routeFr = $switchLocaleRoute('fr')
// Output: A route object with the new locale applied, e.g., { name: 'localized-news', params: { locale: 'fr' } }
```

### `$switchLocalePath`

{/* generated:method:$switchLocalePath — do not edit; run `pnpm run docs:generate` */}

```ts
(locale: string) => string
```

Cesta aktuální stránky v jiném locale, bez navigace.

{/* /generated:method:$switchLocalePath */}

```typescript
// on /en/news
const routeFr = $switchLocalePath('fr')
window.location.href = routeFr
// Output: url with new locale applied, e.g., '/fr/nouvelles'
```

### `$switchRoute`

{/* generated:method:$switchRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, toLocale?: string) => void
```

Přejde na jinou routu, přičemž zachová aktivní locale nebo přepne na `toLocale`.

{/* /generated:method:$switchRoute */}

**Příklady**:

<CodeGroup>
```typescript String Path
// Switches to the given path with the current locale
$switchRoute('/about')
```

```typescript String Path with Locale
// Switches to the given path with French locale
$switchRoute('/about', 'fr')
```

```typescript Named Route
// Switches to a named route with the current locale
$switchRoute({ name: 'page' })
```

```typescript Named Route with Locale
// Switches to a named route and changes the locale to Spanish
$switchRoute({ name: 'page' }, 'es')
```
</CodeGroup>

## 🚦 Konfigurace route

Metody pro konfiguraci chování route a řízení přístupu.

### `$defineI18nRoute`

{/* generated:method:$defineI18nRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Zaregistruje konfiguraci locale pro jednotlivé stránky a překlady zevnitř komponenty. Sloučí do aktivního locale a znovu aplikuje při změně locale.

{/* /generated:method:$defineI18nRoute */}

> [!IMPORTANT]
> `$defineI18nRoute` poskytuje **define plugin** a je dostupný pouze na `useNuxtApp()`. Není součástí návratového objektu `useI18n()`.
> Vždy jej destrukturujte z `useNuxtApp()` uvnitř `script setup`. Volání `$defineI18nRoute(...)` jako globálního způsobí `"$defineI18nRoute is not defined"` během SSR/prerenderu.

**Parametry**:

- **locales**: `string[] | Record<string, Record<string, string>>` — Dostupné locale pro routu
- **localeRoutes**: `Record<string, string>` — Volitelný. Vlastní routy pro konkrétní locale
- **disableMeta**: `boolean | string[]` — Volitelný. Zakáže i18n meta tagy pro všechny nebo konkrétní locale

**Základní příklad**:

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr', 'de'],
  localeRoutes: {
    en: '/welcome',
    fr: '/bienvenue',
    de: '/willkommen',
  },
  disableMeta: false,
})
```

> 📖 **Podrobné příklady použití, formáty konfigurace a osvědčené postupy najdete v [Průvodci překlady na úrovni komponenty](/guides/per-component-translations).**

### `$setI18nRouteParams`

{/* generated:method:$setI18nRouteParams — do not edit; run `pnpm run docs:generate` */}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Nastaví parametry pro jednotlivé locale pro aktuální routu. Dynamický segment se pak může mezi jazyky lišit. Volejte během SSR před renderem head.

{/* /generated:method:$setI18nRouteParams */}

```typescript
// in pages/news/[id].vue
// for en/news/1-first-article
const { $switchLocaleRoute, $setI18nRouteParams, $defineI18nRoute } = useNuxtApp()
$defineI18nRoute({
  localeRoutes: {
    en: '/news/:id()',
    fr: '/nouvelles/:id()',
    de: '/Nachricht/:id()',
  },
})
const { data: news } = await useAsyncData(`news-${params.id}`, async () => {
  let response = await $fetch("/api/getNews", {
    query: {
      id: params.id,
    },
  });
  if (response?.localeSlugs) {
    response.localeSlugs = {
      en: {
        id: '1-first-article'
      }
      fr: {
        id: '1-premier-article'
      }
      de: {
        id: '1-erster-Artikel'
      }
    }
    $setI18nRouteParams(response?.localeSlugs);
  }
  return response;
});
$switchLocalePath('fr') // === 'fr/nouvelles/1-premier-article'
$switchLocalePath('de') // === 'de/Nachricht/1-erster-Artikel'
```

## 🧭 Composable `useI18nLocale`

Centralizovaný composable pro správu stavu locale. Používejte jej místo přímé manipulace s `useState('i18n-locale')` nebo `useCookie('user-locale')`.

```typescript
const {
  setLocale, // (locale: string) => void — updates state + cookie
  getLocale, // () => string | null — from state or cookie
  getPreferredLocale, // () => string | null — validated against locales list
  getEffectiveLocale, // (route, getLocaleFromRoute) => string
  resolveInitialLocale, // (options) => string
  isValidLocale, // (locale) => boolean
  locale, // Ref<string | null> — reactive state
  localeCookie, // CookieRef — reactive cookie
  syncLocale, // (locale) => void — sync to cookie only
  validLocales, // string[] — list of valid locale codes
} = useI18nLocale()
```

### Klíčové metody

| Metoda                  | Popis                                                       |
| ----------------------- | ----------------------------------------------------------- |
| `setLocale(locale)`     | Nastaví locale současně v `useState` i v cookie             |
| `getLocale()`           | Vrátí aktuální locale ze stavu nebo z cookie                |
| `getPreferredLocale()`  | Vrátí locale ověřený proti seznamu `locales`, nebo `null`   |
| `isValidLocale(locale)` | Zkontroluje, zda je kód locale v nakonfigurovaném seznamu `locales` |

### Použití ve vlastních pluginech

```typescript
// plugins/i18n-loader.server.ts
export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,
  setup() {
    const { setLocale } = useI18nLocale()
    // Detect locale from headers, domain, etc.
    setLocale('de')
  },
})
```
