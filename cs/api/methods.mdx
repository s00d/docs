Modul vkládá do aplikace Nuxt své runtime helpery: `$t`, `$tc`, `$localePath`, `$switchLocale` a další. Na této stránce najdete signaturu a chování každého helperu. Signatury a popisy pocházejí z rozhraní `PluginsInjections` a `NuxtAppOnlyInjections` v `src/runtime/plugins/01.plugin.ts`.

## Přístup {#access}

| Kde | Jak |
| --- | --- |
| Šablona | `{{ $t('title') }}` — každý helper, s `$` |
| `<script setup>` | `const { t, localePath } = useI18n()` — každý helper z `PluginsInjections`, s `$` i bez něj |
| Plugin, middleware, `<script setup>` | `const { $t, $defineI18nRoute } = useNuxtApp()` — vše, pouze s `$` |

`$defineI18nRoute` je typován pouze na `useNuxtApp()`. Viz [`useI18n`](/cs/composables/useI18n).

```vue
<script setup lang="ts">
const { t, localePath } = useI18n()
</script>

<template>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
</template>
```

## Lokalizace {#locale}

### `$getLocale` {#$getlocale}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric) => string
```

Kód aktivní lokalizace. Předejte routu, chcete-li zjistit lokalizaci, ke které daná routa patří.

```ts
$getLocale() // 'de' on /de/about
```

### `$getLocaleName` {#$getlocalename}

```ts
() => string | null
```

`displayName` aktivní lokalizace z konfigurace, nebo `null`, pokud ho nemá.

### `$getLocales` {#$getlocales}

```ts
() => Locale[]
```

Všechny nakonfigurované lokalizace včetně jejich metadat.

Vlastní vlastnosti objektu lokalizace se vrátí tak, jak byly zapsány; otypujte je pomocí [rozšíření modulu](/cs/api/module-options#locales) typu `Locale`.

### `$defaultLocale` {#$defaultlocale}

```ts
() => string | undefined
```

Kód nakonfigurované výchozí lokalizace.

### `$getI18nConfig` {#$geti18nconfig}

```ts
() => ResolvedI18nConfig
```

Vyhodnocená konfigurace modulu tak, jak ji vidí runtime.

Hodnota zahrnuje [runtime přepsání](/cs/guide/runtime-overrides) (`defaultLocale`, `fallbackLocale`, vypnuté lokalizace).

```ts
const { strategy, localeCookie } = useNuxtApp().$getI18nConfig()
```

## Překlad {#translation}

### `$t` {#$t}

```ts
TranslationFn<CleanTranslation>
```

Přeloží klíč a interpoluje do něj `params`. Vrací `defaultValue`, pokud klíč
chybí, nebo samotný klíč, pokud není zadána výchozí hodnota.

```ts
// { "welcome": "Welcome, {name}!" }
$t('welcome', { name: 'Ada' }) // 'Welcome, Ada!'
$t('missing.key', {}, 'Fallback') // 'Fallback'
```

Klíč, který ukazuje na vnořený objekt, vrací tento objekt, nikoli řetězec. V šabloně se vykreslí jako `[object Object]`; použijte listový klíč.

### `$ts` {#$ts}

```ts
TranslationFn<string>
```

Jako `$t`, ale vždy vrací řetězec: hodnota projde přes `toString()`, takže z vnořeného
objektu se stane `'[object Object]'`. Nasměrujte klíč na list.

### `$_t` {#$_t}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<CleanTranslation>
```

Naváže `$t` na konkrétní routu pro překlad mimo aktuální stránku — například layout vykreslující
odkaz na jinou routu.

```ts
const route = useRoute()
const t = useNuxtApp().$_t(route)
t('page.title')
```

### `$_ts` {#$_ts}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<string>
```

Naváže `$ts` na konkrétní routu. Viz `$_t`.

### `$tc` {#$tc}

```ts
(key: TranslationKey, params: number | Params, defaultValue?: string) => string
```

Přeloží s pluralizací. `params` může být samotný počet, nebo objekt obsahující
`count`.

Tvary se oddělují znakem `|`. Při vestavěném pravidle vybere nezáporný celočíselný počet `n` tvar `n`, omezený na poslední tvar; záporný, desetinný nebo `NaN` počet vezme poslední tvar. `{count}` a ostatní parametry se interpolují do vybraného tvaru.

Pro jazyky, jejichž plurály se neřídí počtem, začněte šablonu výrazem `=0 `. První tvar je pak pro 0 a ostatní se řídí kategorií [`Intl.PluralRules`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/PluralRules) v pořadí `zero, one, two, few, many, other`:

```json
{
  "apples": "=0 no apples | one apple | {count} apples",
  "files": "=0 no files | {count} one | {count} few | {count} many"
}
```

```ts
$tc('apples', 0) // 'no apples'
$tc('apples', 1) // 'one apple'
$tc('apples', 7) // '7 apples'

// In `uk` (categories `one, few, many, other`) the forms after the zero form follow those categories:
$tc('files', 21) // '21 one'
$tc('files', 22) // '22 few'
$tc('files', 25) // '25 many'
$tc('files', 2.5) // '2.5 many': no form for `other`, so the last one
```

- `=0 ` se počítá pouze na úplném začátku hodnoty, včetně mezery. `$t` ho zobrazí jako text: patří k plurálům.
- Kategorie bez vlastního tvaru vezme poslední tvar. Záporný nebo desetinný počet také vezme poslední tvar.
- Funguje v jakékoli lokalizaci: `=0 none | one | {count} many` v angličtině.
- Kategorie se určuje z `iso` lokalizace, jinak z jejího kódu. Kód, který `Intl` nezná, se vrátí k pravidlu indexu, přičemž značka je i tak odstraněna, takže výsledek nikdy nezávisí na stroji.
- `<i18n-t :plural>` se řídí stejným pravidlem. Vlastní [`plural`](/cs/api/module-options#plural) nebo `customPluralRule` dostane surovou hodnotu včetně značky a rozhodne sám; když `plural` vrátí `null`, předá volání zpět vestavěnému pravidlu, které značku respektuje.

Bez značky zůstává šablona u pravidla indexu, s jedinou výjimkou, kterou lze číst jen jedním způsobem: nulový tvar bez zástupného symbolu, poté jeden tvar pro každou kategorii, s `{count}` v každém tvaru, který sdílí více počtů (`no files | {count} one | {count} few | {count} many` v `uk`).

Pro vlastní pravidla nastavte [`plural`](/cs/api/module-options#plural).

```ts
// { "apples": "no apples | one apple | {count} apples" }
$tc('apples', 0) // 'no apples'
$tc('apples', 10) // '10 apples'
$tc('cart', { count: 2, name: 'Ada' }) // count and params in one object
```

Třetí argument je `defaultValue`, nikoli parametry.

### `$has` {#$has}

```ts
(key: string) => boolean
```

Zda se klíč v aktivní lokalizaci vyhodnotí. Použijte ho k větvení podle volitelného textu místo
vykreslení surového klíče. Stejně jako `$t` vidí během přechodu mezi stránkami ve stejné lokalizaci
i klíče opouštěné stránky.

```ts
if ($has('promo.banner')) show.value = true
```

## Formátování {#formatting}

### `$tn` {#$tn}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Naformátuje číslo pomocí `Intl.NumberFormat` v aktivní lokalizaci. Klíč vybírá pojmenovaný formát
z konfigurace.

Pojmenované formáty pocházejí z [`numberFormats`](/cs/api/module-options#numberformats).

```ts
$tn(1234.5, { style: 'currency', currency: 'EUR' }) // '1.234,50 €' in de
$tn(1000, 'currency') // named format
$tn(1000, 'currency', 'de') // named format in another locale
```

### `$td` {#$td}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Naformátuje datum pomocí `Intl.DateTimeFormat` v aktivní lokalizaci. Klíč vybírá pojmenovaný formát
z konfigurace.

Pojmenované formáty pocházejí z [`datetimeFormats`](/cs/api/module-options#datetimeformats).

```ts
$td(new Date(), { dateStyle: 'long' })
$td(post.createdAt, 'short')
```

### `$tdr` {#$tdr}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

Naformátuje datum jako relativní čas („před 3 dny“) pomocí `Intl.RelativeTimeFormat`.

```ts
$tdr(Date.now() - 5 * 60_000) // '5 minutes ago' in en
```

## Přepínání a odkazy {#switching-and-links}

### `$switchLocale` {#$switchlocale}

```ts
(locale: string) => Promise<boolean>
```

Přejde na aktuální stránku v jiné lokalizaci. Při `no_prefix` a v hash režimu načte
překlady lokalizace před navigací; při `no_prefix` se routa nahradí na místě (bez
nového záznamu v historii). Neznámá lokalizace je ignorována.
Volání je asynchronní: použijte `await`, chcete-li spustit kód po navigaci. Vrací `true`, když je
slovník lokalizace aktivní, `false`, když není: část se nepodařilo načíst (aktuální
slovník zůstane; pro nový pokus zavolejte znovu) nebo zvítězilo novější přepnutí.

```ts
await $switchLocale('de')
```

### `$switchLocalePath` {#$switchlocalepath}

```ts
(locale: string) => string
```

Cesta aktuální stránky v jiné lokalizaci, bez navigace.

```vue
<NuxtLink :to="$switchLocalePath('de')">Deutsch</NuxtLink>
```

### `$switchLocaleRoute` {#$switchlocaleroute}

```ts
(locale: string) => RouteLocationRaw
```

Objekt routy aktuální stránky v jiné lokalizaci, bez navigace, nebo URL řetězec
pro lokalizaci s vlastním `baseUrl`. Při `trailingSlash` má objekt `path` a `fullPath`
podle pravidla, s `query` a `hash` beze změny, a `router.push` i odkaz je zachovají.

### `$switchRoute` {#$switchroute}

```ts
(route: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, toLocale?: string) => Promise<void>
```

Přejde na jinou routu, ponechá aktivní lokalizaci nebo přepne na `toLocale`. Asynchronní stejně jako
`$switchLocale`.

```ts
$switchRoute('/about') // active locale
$switchRoute({ name: 'about' }, 'de') // switch to de
```

### `$localePath` {#$localepath}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => string
```

Vyhodnotí cestu v dané lokalizaci, nebo v aktivní. Řetězec se schématem `http(s):`, `mailto:`
nebo `tel:` se vrátí beze změny: nepředávejte uživatelský vstup jako cíl odkazu bez kontroly.

Řetězcová cesta se čte jako stránka, kterou zobrazuje, takže se použije i vlastní cesta lokalizace.

```ts
$localePath('/about') // '/about' in en, '/de/ueber-uns' in de with localeRoutes
$localePath({ name: 'about' }, 'fr') // '/fr/about'
```

### `$localeRoute` {#$localeroute}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => RouteLocationResolved
```

Vyhodnotí routu v dané lokalizaci, nebo v aktivní. Prostý objekt, který lze bezpečně uchovat ve stavu. Když parametr potřebuje
escapování, má `path`, `fullPath`, `query` a `hash`, ale žádné `name` ani `params`: routeru předává
zakódovanou URL právě cesta. Pro lokalizaci na jiné doméně jsou `path` a `fullPath` absolutní, což router nepřijme:
takový odkaz jde přes `<i18n-link>` nebo `$localePath`.

### `$getRouteName` {#$getroutename}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric, locale?: string) => string
```

Název routy bez prefixu lokalizace — název, podle kterého jsou klíčovány překlady.

```ts
$getRouteName() // 'about' on /de/about
```

## Konfigurace stránky {#page-config}

### `$defineI18nRoute` {#$definei18nroute}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Zaregistruje konfiguraci lokalizací a překlady pro stránku zevnitř komponenty.
Sloučí se do aktivní lokalizace a znovu se použije při změně lokalizace.

Volejte ho v `<script setup>` stránky, vždy destrukturovaný z `useNuxtApp()`. Build čte z volání `locales`, `localeRoutes` a `disableMeta`; za běhu záleží pouze na `locales` (vložené překlady se sloučí pro aktivní lokalizaci). Úplná pravidla: [Konfigurace stránky](/cs/guide/per-component-translations).

```vue
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'de'],
  localeRoutes: { en: '/about', de: '/ueber-uns' },
})
</script>
```

### `$setI18nRouteParams` {#$seti18nrouteparams}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Nastaví parametry aktuální routy pro jednotlivé lokalizace, aby se dynamický segment mohl lišit podle jazyka.
Volejte ho během SSR, před vykreslením head.

Parametry se vymažou, když se potvrdí navigace na jinou cestu, včetně `/news/1` na `/news/4`, která zachovává název routy. Podrobnosti: [Lokalizované cesty](/cs/guide/custom-locale-routes).

```ts
$setI18nRouteParams({
  en: { slug: 'my-post' },
  de: { slug: 'mein-beitrag' },
})
```

## Překlady za běhu {#runtime-translations}

### `$mergeTranslations` {#$mergetranslations}

```ts
(newTranslations: Translations) => void
```

Za běhu sloučí překlady do aktivní lokalizace a přepíše to, co je načteno.

Hluboce slučuje do části aktuální stránky aktivní lokalizace; klíče, které nezmiňuje, zůstanou zachovány.

```ts
$mergeTranslations({ banner: { title: 'Sale' } })
```

### `$setTranslation` {#$settranslation}

```ts
(key: string, value: unknown) => void
```

Nahradí hodnotu na `key` v aktivním slovníku. Jde o nahrazení, nikoli sloučení —
použijte `$mergeTranslations`, pokud mají existující sourozenci zůstat zachováni.

```ts
$setTranslation('banner', { title: 'Sale' }) // drops other keys under banner
$setTranslation('banner.title', 'Sale') // dotted path
```

### `$loadPageTranslations` {#$loadpagetranslations}

```ts
(locale: string, routeName: string, translations: Translations) => Promise<void>
```

Načte překlady pro stránku za běhu, pro obsah, jehož klíče nejsou známy v době buildu.

Sloučí se do části `(locale, routeName)` v paměti a obrazovka se aktualizuje, když je tato část aktivní. Nic se zde nestahuje: pro stránku, která ještě není načtená, překlady počkají, a když se její soubor načte, zůstanou nad ním.

```ts
await $loadPageTranslations('en', 'about', { title: 'About us' })
```

### `$resolveTranslations` {#$resolvetranslations}

```ts
() => Translations
```

Všechny překlady aktuálně v paměti pro aktivní lokalizaci a routu, jako strom.
Pohled pouze pro čtení na to, co `$t()` dokáže právě teď vyhodnotit.

S výsledkem zacházejte jako s hodnotou pouze pro čtení.

### `$setMissingHandler` {#$setmissinghandler}

```ts
(handler: MissingHandler | null) => void
```

Nainstaluje callback volaný pro každý nevyhodnocený klíč. Předejte `null` pro jeho odstranění.

Handler se spustí místo varování ve vývojovém režimu.

```ts
$setMissingHandler((locale, key, routeName) => {
  console.error(`[i18n] missing ${key} in ${locale} (${routeName})`)
})
```

### `$clearCache` {#$clearcache}

```ts
() => void
```

Zahodí všechny cachované části překladů a znovu načte slovník aktuální stránky. Stránka
dál zobrazuje své aktuální překlady, dokud nedorazí nové. Vývojové HMR ho volá při
každé změně souboru s překlady.

```ts
const { clearCache } = useI18n()
clearCache()
```

Neúspěšné znovunačtení zachová aktuální slovník.
