# 🛠️ Composable `useI18n`

Composable `useI18n` v `Nuxt I18n Micro` poskytuje přístup k většině runtime i18n pomocníků v komponentách a skriptech. Metody jsou dostupné **s prefixem `$` i bez něj** (například `$t` a `t`).

Některé injekce — `$defineI18nRoute` a `$clearCache` — jsou dostupné pouze z `useNuxtApp()`. Viz [Metody — `$defineI18nRoute`](/api/methods#definei18nroute) a [`$clearCache`](/api/methods#clearcache).

## 📊 Co vrací

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Každý runtime pomocník jako prostý objekt.

Stejné funkce, které plugin injektuje jako `$t`, `$tc` a tak dále, dostupné pod
názvem s prefixem dolaru i pod bare aliasem — takže `const \{ t \} = useI18n()` i
`const \{ $t \} = useI18n()` fungují.

**Vrací** — pomocníky popsané v [referenční příručce metod](/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

Každý pomocník, který vrací — `$t`, `$tc`, `$has`, `$switchLocale` a další — je uveden
s podpisem a plně zdokumentován v [Referenční příručce metod](/api/methods).

## API dostupná pouze přes `useNuxtApp()`

Tato **nejsou** vracena `useI18n()`. Importujte je z `useNuxtApp()`:

| Metoda                     | Účel                                                                            |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Per-page locale routy, omezení a inline překlady v `script setup`               |
| `$clearCache()`            | Vyčistí in-memory cache překladů a načtené chunky                               |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Kompletní signatury a příklady viz [Metody](/api/methods).

## 🛠️ Ukázky použití

### Základní získání locale

Získat aktuální locale aplikace.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Překlad s parametry

Přeložit řetězec s dynamickými parametry a záložní výchozí hodnotou.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Přepínání locale

Přepnout aplikaci na jiný locale.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Generování lokalizované routy

Vygenerovat routu lokalizovanou na aktuální nebo zadaný locale.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
