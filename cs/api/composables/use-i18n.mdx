# 🛠️ Composable `useI18n`

Composable `useI18n` v `Nuxt I18n Micro` poskytuje přístup k většině runtime i18n pomocníků v komponentách a skriptech. Metody jsou dostupné **s i bez prefixu `$`** (například `$t` a `t`).

Některé injektované funkce, konkrétně `$defineI18nRoute` a `$clearCache`, jsou dostupné pouze přes `useNuxtApp()`. Viz [Metody: `$defineI18nRoute`](/api/methods#definei18nroute) a [`$clearCache`](/api/methods#clearcache).

## 📊 Co vrací

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Každý runtime pomocník jako běžný objekt.

Stejné funkce, které plugin injektuje jako `$t`, `$tc` a další, dostupné pod jménem s prefixem dolar i pod holým aliasem. Funguje tedy jak `const \{ t \} = useI18n()`, tak `const \{ $t \} = useI18n()`.

**Vrací**: pomocníky popsané v [referenci metod](/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

Každý pomocník, který vrací: `$t`, `$tc`, `$has`, `$switchLocale` a další, je uveden se svou signaturou a plně zdokumentován v [Referenci metod](/api/methods).

## API dostupné jen přes `useNuxtApp()`

Tyto **nejsou** vraceny z `useI18n()`. Importujte je z `useNuxtApp()`:

| Metoda                     | Účel                                                                            |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Routy locale pro jednotlivé stránky, omezení a inline překlady v `script setup` |
| `$clearCache()`            | Vymaže in-memory cache překladů a načtené chunky                                |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Kompletní signatury a příklady najdete v [Metodách](/api/methods).

## 🛠️ Příklady použití

### Základní získání locale

Získejte aktuální locale aplikace.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Překlad s parametry

Přeložte řetězec s dynamickými parametry a záložní výchozí hodnotou.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Přepínání locale

Přepněte aplikaci na jiný locale.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Generování lokalizované routy

Vygenerujte routu lokalizovanou pro aktuální nebo zadaný locale.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
