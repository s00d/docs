# useI18nLocale

## Signatura

{/* generated:symbol:useI18nLocale — do not edit; run `pnpm run docs:generate` */}

```ts
useI18nLocale(): { getEffectiveLocale: (route: unknown, getLocaleFromRoute: GetLocaleFromRoute) => string; getLocale: () => string | null; getLocaleWithServerFallback: (serverLocale?: string | null) => string | null; getPreferredLocale: () => string | null; hashCookie: any; isValidLocale: (locale: string | null | undefined) => locale is string; locale: any; localeCookie: any; resolveInitialLocale: (options: ResolveInitialLocaleOptions) => string; setLocale: (locale: string | null) => void; syncLocale: (locale: string | null) => void; validLocales: string[] }
```

Centralizovaný vstupní bod pro správu i18n locale. Kombinuje useState('i18n-locale'), locale cookie a synchronizační nástroje.

{/* /generated:symbol:useI18nLocale */}

## Použití

```vue
<script setup>
const {
  locale,
  localeCookie,
  hashCookie,
  validLocales,
  getPreferredLocale,
  getLocale,
  getLocaleWithServerFallback,
  getEffectiveLocale,
  resolveInitialLocale,
  setLocale,
  syncLocale,
  isValidLocale,
} = useI18nLocale()

// Set locale (updates state and cookies)
setLocale('de')

// Get current locale (state → cookie)
const current = getLocale()

// Get valid preferred locale
const preferred = getPreferredLocale()
</script>
```

## API

| Vlastnost/Metoda                                | Typ                                 | Popis                                                                                |
| ----------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| `locale`                                        | `Ref<string \| null>`               | Reaktivní stav locale (`useState('i18n-locale')`)                                    |
| `localeCookie`                                  | `Ref`                               | Cookie locale (když je volba `localeCookie` zapnutá)                                 |
| `hashCookie`                                    | `Ref`                               | Cookie použitá, když je aktivní `hashMode`                                           |
| `validLocales`                                  | `string[]`                          | Povolené kódy locale z konfigurace modulu (vylučuje `disabled`)                      |
| `getLocale()`                                   | `() => string \| null`              | Aktuální locale: state → cookie (nebo hash cookie v hash módu)                       |
| `getPreferredLocale()`                          | `() => string \| null`              | Locale ze state/cookie **ověřený** proti `validLocales`, nebo `null`                 |
| `getLocaleWithServerFallback(serverLocale?)`    | `(serverLocale?) => string \| null` | State → cookie → volitelný serverový kontext (používaný během inicializace `no_prefix`) |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string`             | Locale pro načtení překladů: hash mode preferuje state; jinak čte z routy            |
| `resolveInitialLocale(options)`                 | `(options) => string`               | Rozhodne locale: state → `serverLocale` → route; podle potřeby synchronizuje state   |
| `setLocale(locale)`                             | `(locale: string \| null) => void`  | Nastaví locale a synchronizuje do cookies                                            |
| `syncLocale(locale)`                            | `(locale: string \| null) => void`  | Synchronizuje pouze cookies (bez aktualizace state)                                  |
| `isValidLocale(locale)`                         | `(locale) => boolean`               | Zkontroluje, zda je řetězec ve `validLocales`                                        |

### Volby `resolveInitialLocale`

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

Používá interně hlavní plugin při startu. Vlastní pluginy jej mohou volat při implementaci alternativních detekčních toků.

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

Vrací locale používaný pro načtení překladů a formátování zpráv pro daný objekt route.

## Programové nastavení locale

Preferujte `useI18nLocale()` před přímým použitím `useState('i18n-locale')`:

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
`setLocale()` aktualizuje pouze preferenci locale (state + cookie). Chcete-li také znovu načíst aktivní kontext překladů na klientovi, použijte `$switchLocale()` z `useNuxtApp()` nebo `useI18n()`. Zvláště důležité je to u `no_prefix`, kde se URL nemění. Viz [FAQ: přepnutí locale beze změny URL](/guides/faq#-switch-locale-without-changing-the-url).
</Tip>
