# 🌍 Composable `useLocaleHead`

Composable `useLocaleHead` je nástroj v `Nuxt I18n Micro`, který vám pomáhá spravovat SEO atributy a HTML meta tagy pro lokalizované routy. Dynamicky generuje atributy `lang` a `dir` HTML dokumentu a vytváří tagy `meta` a `link` pro zlepšení SEO vašeho lokalizovaného obsahu.

## ⚙️ Volby

```ts
useLocaleHead(options: UseLocaleHeadOptions): { metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }, MetaObject | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

SEO head tagy pro aktuální routu: alternativy `hreflang` pro každý locale plus `x-default`, canonical link, `og:locale` a `lang`/`dir` na `<html>`.

Potřeba jen když je `meta` vypnuté, nebo když je nutné upravit výchozí hodnoty. Při `meta: true` modul stejné tagy registruje sám.

## 🛠️ Návratové hodnoty

Composable `useLocaleHead` vrací reaktivní objekt a updater funkci, kterou byste měli volat při změně zdrojových dat. Oba tvary jsou v signatuře výše, generované ze zdrojového kódu.

### `metaObject`

Reaktivní payload head (html attrs, meta, link) vhodný pro `useHead(metaObject)`.

- **Příklad**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

Přepočítá `metaObject` na základě aktuální routy, locale a konfigurace. Zavolejte při změně vstupů, například při změně routy.

- **Příklad**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### Přístup k `link` a `meta`

Pole `link` a `meta` jsou přístupná přes `metaObject.value`:

- **Příklad**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ Příklady použití

### Základní použití

Vygenerujte head atributy specifické pro locale s výchozími volbami.

```js
const head = useLocaleHead()
```

### Přizpůsobení identifikačního atributu

Použijte vlastní identifikační atribut pro generované tagy.

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### Vypnutí SEO atributů

Vygenerujte head atributy bez přidávání meta a link tagů souvisejících se SEO.

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### Zadání základní URL

Nastavte vlastní základní URL pro canonical a alternativní URL.

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 Další funkce

### SEO meta a link tagy

Když je `addSeoAttributes` zapnuto, composable automaticky generuje následující tagy:

- `og:locale` pro aktuální locale (`language_TERRITORY`, s podtržítkem). Odvozený z `locale.og`, případně převedený z `locale.iso`, když je to možné.
- `og:url` pro canonical URL stránky.
- `og:locale:alternate` pro alternativní jazykové verze.
- `rel="canonical"` a `rel="alternate"` odkazy pro SEO optimalizaci.
- `hreflang="x-default"` odkaz směřující na URL výchozího locale. Ten sděluje vyhledávačům, kterou URL zobrazit uživatelům, jejichž jazyk neodpovídá žádnému z definovaných locale.

### Dynamický locale a směr

Composable dynamicky určuje atributy `lang` a `dir` na základě locale aktuální routy a zajišťuje, že je váš HTML dokument správně nakonfigurován pro mezinárodní uživatele.

### Práce s lokalizovanými routami

Pokud jsou vaše routy prefixované kódy locale (např. `/en/about`), composable inteligentně upraví plnou cestu pro generování URL a zajistí, aby byly SEO atributy přesné a relevantní.

Tento composable zjednodušuje proces optimalizace vaší Nuxt aplikace pro mezinárodní publikum a zajišťuje, že váš web je dobře připravený pro globální vyhledávače a uživatele.

## 🛠️ Příklad použití

Následující příklad ukazuje použití composablu `useLocaleHead` uvnitř Vue komponenty s výchozím nastavením:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### Vysvětlení kódu

- **Composable `useLocaleHead`**: Tento composable se volá v sekci `<script setup>` a vrací objekt obsahující `htmlAttrs`, `meta` a `link`.

- **Tag `<html>`**: Atributy `lang` a `dir` HTML dokumentu se dynamicky určují na základě aktuálního locale a aplikují se na tag `<html>`.

- **Sekce `<head>`**:
  - **Meta tagy**: Generují se meta tagy související se SEO, včetně `og:locale`, `og:url` a tagů `rel="canonical"` a `rel="alternate"` pro určení alternativních jazykových verzí stránky.
  - **Link tagy**: Zahrnují se canonical odkazy, odkazy na alternativní jazykové verze a odkaz `hreflang="x-default"` (směřující na URL výchozího locale).

- **Sekce `<body>`**: Zde se zobrazuje hlavní obsah stránky. V tomto příkladu je použit jednoduchý nadpis a odstavec.

### 📝 Poznámky

1. **Atributy**: Použité atributy (`lang`, `dir`, `rel`, `href`, `hreflang`, `property`, `content`) se získávají z objektu vraceného composablem `useLocaleHead`.

2. **Generování SEO tagů**: Pokud je volba `addSeoAttributes` nastavena na `true`, composable automaticky generuje SEO tagy pro aktuální locale.

3. **Základní URL**: Vlastní základní URL pro správné generování canonical a alternativních odkazů můžete nastavit pomocí volby `baseUrl`.

Tento příklad ukazuje, jak snadné je integrovat `useLocaleHead` do komponent vaší aplikace, aby se zajistily správné SEO atributy a zlepšila indexace lokalizovaných stránek ve vyhledávačích.

## 🧩 Přizpůsobení a životní cyklus

- `useLocaleHead` sám o sobě nesleduje změny. Vrací `metaObject` a `updateMeta`.
- Měli byste volat `updateMeta()` při změně vstupů (typicky při změně routy), například z pluginu:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## Kdy použít místo toho `useI18nHead`

Když je `meta: true` (výchozí), preferujte pro **per-page** přepisy [`useI18nHead`](/api/composables/use-i18n-head) (vlastní hreflang, extra `og:title`, částečné vypnutí). Použijte `useLocaleHead` přímo, jen když je `meta: false` nebo si `useHead` spravujete sami.
