# 🌍 Komponenta `<i18n-link>`

Komponenta `<i18n-link>` v `Nuxt I18n Micro` je univerzální komponenta pro odkazy, která automaticky lokalizuje routy podle aktuálního locale. Funguje jako obal komponenty `<NuxtLink>` a poskytuje další funkce, například stylování aktivního odkazu a podporu externích odkazů.

`to` přijímá cokoli, co přijímá `NuxtLink`: cestu, pojmenovanou routu nebo vyřešený objekt route. Absolutní URL je detekována a vykreslena jako běžný `<a target="_blank" rel="noopener noreferrer">` místo lokalizace.

## 🛠️ Příklady použití

### Základní použití

```vue
<i18n-link to="/about">About Us</i18n-link>
```

Tento příklad vytvoří odkaz na stránku `/about` lokalizovaný na aktuální locale.

### Stylování aktivního odkazu inline styly

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

Odkaz bude mít tučný text, když je uživatel na stránce `/about`. Aktivní odkaz můžete stylovat přímo pomocí inline stylů.

### Zpracování externích odkazů

Komponenta automaticky detekuje externí odkazy a přidává potřebné atributy pro bezpečnost.

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

Tento odkaz otevře `https://example.com` v novém tabu s aplikovaným `rel="noopener noreferrer"`.

## 🎨 Styly

Komponenta nyní pro aktivní stav používá místo třídy inline styly. Tyto styly můžete přizpůsobit pomocí propu `activeStyle`.

### Výchozí aktivní styly

- **Font Weight**: `bold`
- **Color**: dědí výchozí barvu prohlížeče (pokud v `activeStyle` není zadána `color`).

Můžete je přepsat poskytnutím vlastních stylů přes prop `activeStyle`.

### Vlastní aktivní styly

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

V tomto příkladu bude odkaz při aktivním stavu tučný a zelený.

## 🚀 Další funkce

### Slot pro vlastní obsah

Do odkazu můžete pomocí slotů předat vlastní obsah a komponenta tak bude flexibilní pro různé případy použití.

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### Rozšíření přístupnosti

Komponenta podporuje `aria-label` a další atributy přístupnosti pro zajištění lepší uživatelské zkušenosti.

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
