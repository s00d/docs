# 🌍 Komponenta `<i18n-switcher>`

Komponenta `<i18n-switcher>` v `Nuxt I18n Micro` poskytuje uživatelsky přívětivé rozbalovací rozhraní pro přepínání mezi různými locale ve vaší aplikaci. Tato komponenta je vysoce přizpůsobitelná a umožňuje bezproblémovou integraci s designem a rozvržením vaší aplikace.

Locale s `disabled: true` jsou z rozbalovací nabídky **vynechány** (nadále jsou dostupné přes `$getLocales()` pro SEO / head tagy). Odkaz `NuxtLink` a `hreflang` dostanou pouze přepínatelné locale.

Každá část je ve výchozím stavu nestylovaná: props `custom*Style` přijímají objekty inline stylů a sloty níže markup zcela nahradí, pokud stylování nestačí.

## 🛠️ Příklady použití

### Základní použití

```vue
<template>
  <i18n-switcher />
</template>
```

Vykreslí přepínač locale s výchozím stylováním a chováním.

### Vlastní popisky a inline styly

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Tento příklad ukazuje plně přizpůsobený přepínač locale s vlastními popisky a inline styly.

## 🔌 Sloty

Každou vizuální část přepínače lze nahradit. Sloty jsou uvedeny v tabulce props výše; každý přijímá obsah šablony:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Sloty, jejichž jméno končí na `-item`, `-link-content` nebo začíná `before-item`, dostávají objekt `locale`, ke kterému patří.

## 🎨 Přehled stylů

Komponenta `<i18n-switcher>` má základní styly definované pomocí inline stylů, které lze snadno přepsat předáním vlastních stylů přes props. Zde je stručný přehled výchozího stylování:

- **Obal**: Řídí polohu rozbalovací nabídky.
- **Tlačítko**: Stylizuje přepínací tlačítko.
- **Rozbalovací nabídka**: Stylizuje seznam nabídky.
- **Položky**: Stylizuje každou položku seznamu.
- **Odkazy**: Stylizuje odkazy uvnitř každé položky.
- **Ikona**: Stylizuje ikonu indikátoru rozbalení.

Tyto styly můžete přizpůsobit předáním vlastních stylů přes odpovídající props, aby se přepínač locale hladce začlenil do UI vaší aplikace.
