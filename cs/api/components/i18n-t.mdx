# 🌍 Komponenta `<i18n-t>`

Komponenta `<i18n-t>` v `Nuxt I18n Micro` je flexibilní komponenta pro překlady, která podporuje vkládání dynamického obsahu přes sloty. Umožňuje interpolovat překlady s vlastními Vue komponentami nebo HTML obsahem, čímž otevírá pokročilé scénáře lokalizace.

Naráz se aplikuje jen jeden z `plural`, `number`, `date` a `relativeDate`; když je nastaveno více, vyhrává první v tomto pořadí.

### Příklady pro jednotlivé props

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

## 🛠️ Příklady použití

### Základní použití

```vue
<i18n-t keypath="feedback.text" />
```

Vykreslí překlad `feedback.text` uvnitř tagu `<span>`.

### Použití slotů pro dynamický obsah

Komponenta `<i18n-t>` podporuje sloty pro dynamické vkládání Vue komponent nebo jiného obsahu do konkrétních částí překladu.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

V tomto příkladu je placeholder `\{link\}` v překladovém řetězci `feedback.text` nahrazen komponentou `<nuxt-link>`, která sama obsahuje další komponentu překladu.

### Pluralizace

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

Automaticky aplikuje pravidla pluralizace na základě hodnoty `itemCount`.

## 🚀 Další funkce

### Výchozí slot

Pokud není poskytnut konkrétní slot, překlad lze přizpůsobit přes výchozí slot, který poskytuje celý přeložený řetězec:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### Podmíněné vykreslování

Nastavením propu `hideIfEmpty` nevykreslíte nic, když je překlad prázdný.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### Vlastní pravidlo pluralizace

Použijte vlastní funkci pro zpracování pluralizace.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### Pokročilý příklad se sloty

Využijte sloty k přizpůsobení, jak se obsah překladu vykreslí.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
