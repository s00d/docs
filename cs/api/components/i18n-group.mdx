# 🌍 Komponenta `<i18n-group>`

Komponenta `<i18n-group>` v Nuxt I18n Micro poskytuje pohodlný způsob, jak seskupovat překlady pod společný prefix. Snižuje opakování a zlepšuje organizaci kódu.

## ⚙️ Props

{/* generated:component:i18n-group — do not edit; run `pnpm run docs:generate` */}

| Prop | Typ | Výchozí | Popis |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | Prefix klíče, vůči kterému se rozhoduje každý lookup uvnitř slotu. |
| `groupClass` | `string` | `''` | Doplňková třída na obalový element. |

**\*** povinné.

### Sloty

| Slot | Bindings | Popis |
| --- | --- | --- |
| `default` | `prefix`, `t` | Přijímá `prefix` a funkci `t` omezenou na daný prefix. |

## 🎯 Sloty

Výchozí slot přijímá `prefix` a funkci `t` omezenou na daný prefix, takže klíče uvnitř se zapisují relativně k prefixu:

```vue
<i18n-group prefix="checkout">
  <template #default="{ t }">
    <h2>{{ t('title') }}</h2>
    <p>{{ t('summary', { count: 3 }) }}</p>
  </template>
</i18n-group>
```

## 🛠️ Příklady použití

### Základní použití

```vue
<template>
  <i18n-group prefix="product.details">
    <template #default="{ t }">
      <h1>{{ t('title') }}</h1>
      <p>{{ t('description') }}</p>
      <div class="price">{{ t('price', { value: 99.99 }) }}</div>
    </template>
  </i18n-group>
</template>
```

Soubor s překlady:

```json
{
  "product": {
    "details": {
      "title": "Premium Product",
      "description": "This is a premium product",
      "price": "Price: ${value}"
    }
  }
}
```

### S vlastní třídou

```vue
<template>
  <i18n-group prefix="user.profile" group-class="profile-section">
    <template #default="{ t }">
      <div class="user-info">
        <h2>{{ t('title') }}</h2>
        <p>{{ t('bio') }}</p>
        <div class="stats">
          <span>{{ t('stats.followers') }}</span>
          <span>{{ t('stats.following') }}</span>
        </div>
      </div>
    </template>
  </i18n-group>
</template>
```

Soubor s překlady:

```json
{
  "user": {
    "profile": {
      "title": "User Profile",
      "bio": "User biography goes here",
      "stats": {
        "followers": "Followers: {count}",
        "following": "Following: {count}"
      }
    }
  }
}
```

### S dynamickým obsahem

```vue
<template>
  <i18n-group prefix="blog.post">
    <template #default="{ t }">
      <article>
        <h1>{{ t('title') }}</h1>
        <div class="meta">
          {{ t('meta.author', { name: author }) }} |
          {{ t('meta.date', { date: publishDate }) }}
        </div>
        <div v-for="(section, index) in sections" :key="index">
          <h2>{{ t(`sections.${index}.title`) }}</h2>
          <p>{{ t(`sections.${index}.content`) }}</p>
        </div>
      </article>
    </template>
  </i18n-group>
</template>

<script setup>
const author = 'John Doe'
const publishDate = '2024-01-01'
const sections = ['intro', 'main', 'conclusion']
</script>
```

## 🎨 Stylování

Komponenta obaluje svůj obsah do divu s třídou `i18n-group` a libovolnými dalšími třídami zadanými v propu `groupClass`:

```css
.i18n-group {
  /* Your base styles */
}

.profile-section {
  /* Additional styles for profile sections */
}
```

## 🚀 Osvědčené postupy

1. **Konzistentní prefixy**: Používejte konzistentní a logické prefixy, které odrážejí strukturu vaší aplikace

```vue
<i18n-group prefix="features.pricing">
<i18n-group prefix="features.security">
```

2. **Modulární organizace**: Seskupujte související překlady pod smysluplné prefixy

```vue
<i18n-group prefix="checkout.payment">
<i18n-group prefix="checkout.shipping">
```

3. **Znovupoužitelné komponenty**: Vytvářejte znovupoužitelné komponenty s vlastními skupinami překladů

```vue
<!-- UserProfile.vue -->
<i18n-group prefix="user.profile">

<!-- UserSettings.vue -->
<i18n-group prefix="user.settings">
```

4. **Vnořené skupiny**: Vyhněte se hlubokému vnořování skupin, ať zůstane přehlednost

```vue
<!-- Good -->
<i18n-group prefix="shop.product">

<!-- Avoid -->
<i18n-group prefix="shop.category.product.details.specs">
```
