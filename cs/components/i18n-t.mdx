title: "<i18n-t>"
description: "Komponenta <i18n-t> vykreslí jeden překlad s množnými tvary, formátováním čísel a dat, HTML a interpolací slotů."
---

`<i18n-t>` vykreslí jeden překlad do elementu. Použijte ji, když překlad potřebuje uvnitř komponenty (odkaz ve větě), množný tvar nebo formátované číslo či datum. Klíč rozpoznává pro aktuální routu, stejně jako `$t`.

## Props {#props}

| Prop | Typ | Výchozí | Popis |
| --- | --- | --- | --- |
| `keypath` **\*** | `string` | — | Klíč překladu k vykreslení. |
| `plural` | `number \| string \| null` | — | Počet, podle kterého se vybere množný tvar. Nastavením se místo `$t` použije `$tc`. `null` znamená nenastaveno. |
| `tag` | `string` | `'span'` | Element k vykreslení. |
| `params` | `Record<string, string \| number \| boolean>` | — | Hodnoty interpolace dosazené do překladu. |
| `defaultValue` | `string` | `''` | Vykreslí se místo komponenty, když `hideIfEmpty` potlačí prázdný překlad. |
| `html` | `boolean` | `false` | Vykreslí překlad jako HTML místo textu. Pouze pro překlady, které máte pod kontrolou: `params` se escapují, překlad ne. |
| `hideIfEmpty` | `boolean` | `false` | Nevykreslí nic, když se překlad rozpozná jako prázdný řetězec. |
| `customPluralRule` | `PluralFunc` | `null` | Pravidlo množného čísla jen pro tento element, přepisuje nakonfigurované. Jeho odpověď se použije tak, jak je; `null` vykreslí prázdný výsledek. |
| `number` | `number \| string \| null` | — | Naformátuje hodnotu pomocí `$tn` a předá ji překladu jako `{number}` vedle `params`. |
| `date` | `Date \| string \| number \| null` | — | Naformátuje hodnotu pomocí `$td` a předá ji překladu jako `{date}` vedle `params`. |
| `relativeDate` | `Date \| string \| number \| null` | — | Naformátuje hodnotu pomocí `$tdr` a předá ji překladu jako `{relativeDate}` vedle `params`. |

**\*** povinné.

## Pravidla vykreslování {#rendering-rules}

O výstupu rozhoduje první odpovídající případ:

1. `number` — překlad s `{ ...params, number: $tn(number) }`.
2. `date` — překlad s `{ ...params, date: $td(date) }`.
3. `relativeDate` — překlad s `{ ...params, relativeDate: $tdr(relativeDate) }`.
4. `plural` — tvar, který vybere `$tc`, včetně [značky `=0 `](/cs/api/methods#$tc), s `{ ...params, count }`; nebo `customPluralRule(keypath, count, params, locale, t)`, pokud je nastaveno, které čte surovou hodnotu včetně značky a jehož odpověď se použije tak, jak je, přičemž `null` znamená prázdný výsledek.
5. Jinak překlad s `params`.

`null` se považuje za nenastavené. Ve všech případech:

- `defaultValue` zastupuje chybějící klíč, v každé větvi.
- `hideIfEmpty` místo prázdného výsledku vykreslí `defaultValue`.
- `html` vykreslí výsledek jako HTML. `params` se escapují, překlad ne; sloty se ignorují.
- Slot `default` dostane `{ translation }` a pojmenované sloty se ignorují.
- Jinak každý pojmenovaný slot nahradí každý zástupný symbol `{name}`, a to dříve než parametr stejného jména. Hodnota parametru, která vypadá jako zástupný symbol, zůstane textem.

Výstup `date` a `relativeDate` nese `data-allow-mismatch="text"`, protože časové pásmo a hodiny serveru nejsou stejné jako v prohlížeči. Nastavte [`timeZone`](/cs/api/module-options#timezone), aby se na obou stranách vykreslilo stejné kalendářní datum; `relativeDate` závisí na hodinách, takže se stále může lišit.

## Příklad {#example}

```json
{
  "terms": "I accept the {link}.",
  "termsLink": "terms of use",
  "items": "no items | one item | {count} items"
}
```

```vue
<template>
  <i18n-t keypath="terms" tag="p">
    <template #link>
      <NuxtLink :to="$localePath('/terms')">{{ $t('termsLink') }}</NuxtLink>
    </template>
  </i18n-t>

  <i18n-t keypath="items" :plural="cart.length" />
</template>
```

`html` nastavuje `innerHTML`: používejte ho pouze pro překlady, které máte pod kontrolou. `params` se escapují, takže uživatelská data jsou tam v bezpečí, stejně jako klíč, pro který se nenašel překlad.
