# 🛠️ DevTools v `nuxt-i18n-micro`

## Vue DevTools (rozšíření prohlížeče)

Ve vývoji může modul zaregistrovat vlastní inspektor a timeline pro **Vue DevTools** přes `@vue/devtools-api`. To je odděleno od karty Nuxt DevTools níže.

| Nástroj | Nejlepší pro |
|------|----------|
| **Vue DevTools** | Aktivní locale, in-memory cache překladů, timeline `$t` (`debug: true`), události chybějících klíčů |
| **Karta Nuxt DevTools** | Úpravy JSON souborů na disku, přehled konfigurace, import/export |

Plugin vue-devtools se registruje jen během `nuxt dev` (ne v produkčních buildech). Dev-only bridge state v hlavním pluginu je odstraněn dead-code eliminací přes `import.meta.dev`.

Chcete-li vypnout integraci s prohlížečem, ale zachovat kartu Nuxt:

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

Podrobné události timeline `$t` vyžadují `debug: true`.

## 📖 Co je Nuxt DevTools?

DevTools je výkonný vývojářský asistent hladce integrovaný v modulu `nuxt-i18n-micro`. Poskytuje intuitivní rozhraní pro správu úloh lokalizace a překladu, čímž zrychluje a zefektivňuje váš workflow. Nuxt DevTools je navržen pro vývojáře, kteří oceňují pohodlí, a překlenuje propast mezi psaním kódu a runtime správou.

## 🌟 Klíčové funkce DevTools v `nuxt-i18n-micro`

### 1. **Správa locale**

Bez námahy procházejte, vybírejte a spravujte locale ve vaší aplikaci. Ať už pracujete s jedním jazykem nebo s více, DevTools poskytuje centralizovaný hub pro veškerá nastavení lokalizace.

### 2. **Úpravy překladů**

Upravujte soubory překladů přímo přes integrovaný JSON editor. Odpadá potřeba externích nástrojů a můžete provádět aktualizace a změny v reálném čase bez přerušení workflow.

### 3. **Import a export souborů**

Zjednodušte proces správy souborů s překlady:

- **Export**: Uložte překlady jako JSON soubor pro zálohy nebo externí použití.
- **Import**: Načtěte aktualizované soubory překladů do projektu, aby byl obsah aktuální.

### 4. **Náhledy v reálném čase**

Zobrazte změny okamžitě v rámci vývojového prostředí. Tato funkce zajišťuje, že překlady a konfigurace jsou přesné, ještě než se dostanou do produkce.

### 5. **Bezešvá integrace s Nuxtem**

DevTools funguje nativně s `nuxt-i18n-micro` a rozšiřuje jeho možnosti bez nutnosti dalšího nastavení. Přizpůsobuje se vašim potřebám lokalizace a zároveň zachovává modulární a flexibilní strukturu Nuxtu.

## 🛠️ Proč používat DevTools?

Nuxt DevTools je nepostradatelným doplňkem pro projekty vyžadující lokalizaci. Pomáhá vývojářům:

- **Šetří čas**: Automatizuje opakující se úlohy jako správa souborů a validace formátu.
- **Snižuje chyby**: Poskytuje bezpečné a intuitivní prostředí pro úpravy překladů.
- **Zlepšuje spolupráci**: Umožňuje ne-vývojářům snadno spravovat překlady.
- **Zefektivňuje workflow**: Konsoliduje více úloh lokalizace do jednoho rozhraní.

## 🚀 Převezměte kontrolu nad lokalizací

S Nuxt DevTools integrovanými v `nuxt-i18n-micro` se správa vícejazyčných aplikací stává přímočarou a efektivní. Ať už dolaďujete překlady nebo přidáváte nové locale, DevTools vás vybaví nástroji potřebnými k dodání dokonalých a uživatelsky přívětivých zážitků.
