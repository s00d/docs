# 🛠️ DevTools v `nuxt-i18n-micro`

## Vue DevTools (rozšíření prohlížeče)

V developmentu může modul zaregistrovat vlastní inspektor a timeline **Vue DevTools** přes `@vue/devtools-api`. Toto je odděleno od záložky Nuxt DevTools níže.

| Nástroj | Nejlepší pro |
|------|----------|
| **Vue DevTools** | Živé locale, in-memory cache překladů, timeline `$t` (`debug: true`), události chybějících klíčů |
| **Záložka Nuxt DevTools** | Editaci JSON souborů na disku, přehled konfigurace, import/export |

Plugin vue-devtools je registrován pouze během `nuxt dev` (ne v produkčních buildech). Dev-only stav bridge v hlavním pluginu je odstraněn dead-code eliminací pomocí `import.meta.dev`.

Zakázat integraci do prohlížeče a zároveň zachovat záložku Nuxt:

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

Podrobné události timeline `$t` vyžadují `debug: true`.

## 📖 Co jsou Nuxt DevTools?

DevTools je výkonný vývojářský asistent bezproblémově integrovaný do modulu `nuxt-i18n-micro`. Poskytuje intuitivní rozhraní pro správu lokalizace a překladových úloh, což činí váš pracovní postup rychlejším a efektivnějším. Navržen pro vývojáře, kteří oceňují pohodlí, Nuxt DevTools překlenuje propast mezi psaním kódu a správou za běhu.

## 🌟 Klíčové vlastnosti DevTools v `nuxt-i18n-micro`

### 1. **Správa locale**

Bez námahy procházejte, vybírejte a spravujte locale ve své aplikaci. Ať pracujete s jedním jazykem nebo s více, DevTools poskytuje centralizovaný hub pro zpracování všech nastavení lokalizace.

### 2. **Editace překladů**

Editujte překladové soubory přímo přes integrovaný JSON editor. Odpadá tak potřeba externích nástrojů a umožňuje aktualizace a změny v reálném čase bez přerušení pracovního postupu.

### 3. **Import a export souborů**

Zjednodušte proces správy překladových souborů:

- **Export**: Uložte překlady jako JSON soubor pro zálohy nebo externí použití.
- **Import**: Načtěte aktualizované překladové soubory do projektu, aby byl obsah aktuální.

### 4. **Náhledy v reálném čase**

Zobrazte změny okamžitě ve vývojovém prostředí. Tato funkce zajišťuje, že překlady a konfigurace jsou před nasazením správné.

### 5. **Bezproblémová integrace s Nuxt**

DevTools funguje nativně s `nuxt-i18n-micro`, což rozšiřuje jeho možnosti bez potřeby dodatečného nastavení. Přizpůsobuje se vašim lokalizačním potřebám a přitom zachovává modulární a flexibilní strukturu Nuxt.

## 🛠️ Proč používat DevTools?

Nuxt DevTools jsou nepostradatelným doplňkem pro projekty vyžadující lokalizaci. Pomáhá vývojářům tím, že:

- **Šetří čas**: Automatizuje opakující se úlohy, jako je správa souborů a validace formátu.
- **Snižuje počet chyb**: Poskytuje bezpečné, intuitivní prostředí pro editaci překladů.
- **Zlepšuje spolupráci**: Umožňuje ne-vývojářům snadno spravovat překlady.
- **Zjednodušuje pracovní postupy**: Konsoliduje více lokalizačních úloh do jediného rozhraní.

## 🚀 Získejte kontrolu nad lokalizací

S Nuxt DevTools integrovanými do `nuxt-i18n-micro` se správa vícejazyčných aplikací stává přímočarou a efektivní. Ať už dolaďujete překlady nebo přidáváte nové locale, DevTools vás vybaví nástroji potřebnými k poskytování vyladěných, uživatelsky přívětivých zážitků.
