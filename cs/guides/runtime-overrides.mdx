# Runtime i18n přepisy

Tento průvodce použijte, když potřebujete jeden artefakt buildu spustit s různými výchozími locale pro různá prostředí (například pro různé tenant instance).

## Co lze přepsat za běhu

Modul podporuje bezpečné runtime přepisy pro:

- `defaultLocale`
- `fallbackLocale`
- `disabledLocales`

Tyto přepisy se aplikují nad konfiguraci z doby buildu z `.nuxt/i18n.strategy.mjs` a `.nuxt/i18n.config.mjs`.

## Co za běhu přepsat nelze

`strategy` (`no_prefix`, `prefix`, `prefix_except_default`, `prefix_and_default`) je záležitost buildu, protože ovlivňuje chování generovaných rout.

Pokud předáte runtime přepis strategie, je ignorován a je vypsáno varování.

## Přepisy přes RuntimeConfig

Runtime hodnoty poskytněte pod `runtimeConfig.public.i18nRuntime`:

```ts
export default defineNuxtConfig({
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

## Přepisy přes proměnné prostředí

Přepisy můžete konfigurovat také přes proměnné prostředí:

- `NUXT_I18N_DEFAULT_LOCALE`
- `NUXT_I18N_FALLBACK_LOCALE`
- `NUXT_I18N_DISABLED_LOCALES` (oddělené čárkou, např. `fr,it`)

Podporovány jsou také fallback aliasy:

- `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES`

## Pravidla validace

Za běhu modul přepisy validuje, aby se předešlo rozbitému stavu:

- Nelze vypnout všechny locale.
- `defaultLocale` musí ukazovat na povolený locale.
- `fallbackLocale` musí existovat v deklarovaných locale.

Pokud je přepis neplatný, modul ponechá bezpečnou hodnotu a zaloguje varování.

## Poznámky pro nasazení s více instancemi

Tato runtime funkce je navržena pro aktivaci locale a výchozí hodnoty pro jednotlivé instance bez nutnosti rebuildu.

Pokud instance vyžadují různé URL strategie (`no_prefix` vs `prefix`), použijte pro každou strategii samostatný build.

## Vypnutá locale a statické payloady

`runtimeConfig.public.i18nRuntime.disabledLocales` aktualizuje routování, switcher a Nitro **handler** payloadu, ale Nitro podává soubory pod `public/` **dříve** než tento handler.

Pokud `translationPayloads.publicAssets` (nebo vynucená veřejná kopie Node SSR) už zapsal `/_locales/\{page\}/\{locale\}/data.json`, runtime disable ten soubor skrýt nedokáže. Preferujte `locale.disabled: true` v době buildu, aby premerge tyto statické payloady daného locale nevydával.
