# Runtime přepisy i18n

Použijte tohoto průvodce, když potřebujete, aby jeden build artefakt běžel s různými výchozími hodnotami locale pro jednotlivá prostředí (například: různé tenant instance).

## Co lze přepsat za běhu

Modul podporuje bezpečné runtime přepisy pro:

- `defaultLocale`
- `fallbackLocale`
- `disabledLocales`

Tyto přepisy se aplikují nad build-time konfiguraci z `.nuxt/i18n.strategy.mjs` a `.nuxt/i18n.config.mjs`.

## Co nelze přepsat za běhu

`strategy` (`no_prefix`, `prefix`, `prefix_except_default`, `prefix_and_default`) je záležitost build-time, protože ovlivňuje chování generovaných rout.

Pokud předáte runtime přepis strategie, je ignorován a vydáno varování.

## Přepisy pomocí RuntimeConfig

Poskytněte runtime hodnoty pod `runtimeConfig.public.i18nRuntime`:

```ts
export default defineNuxtConfig({
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

## Přepisy pomocí proměnných prostředí

Přepisy můžete konfigurovat také přes proměnné prostředí:

- `NUXT_I18N_DEFAULT_LOCALE`
- `NUXT_I18N_FALLBACK_LOCALE`
- `NUXT_I18N_DISABLED_LOCALES` (oddělené čárkou, např. `fr,it`)

Podporovány jsou také záložní aliasy:

- `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES`

## Pravidla validace

Za běhu modul validuje přepisy, aby se předešlo nefunkčnímu stavu:

- Nemůžete zakázat všechny locale.
- `defaultLocale` musí ukazovat na povolené locale.
- `fallbackLocale` musí existovat v deklarovaných locale.

Pokud je přepis neplatný, modul zachová bezpečnou hodnotu a zaloguje varování.

## Poznámky k multi-instance nasazení

Tato runtime funkce je navržena pro aktivaci locale a výchozí hodnoty specifické pro jednotlivé instance bez nutnosti přebuildu.

Pokud instance vyžadují různé URL strategie (`no_prefix` vs `prefix`), použijte pro každou strategii samostatný build.

## Zakázané locale a statické payloady

`runtimeConfig.public.i18nRuntime.disabledLocales` aktualizuje routování, switcher a Nitro payload **handler** — ale Nitro servíruje soubory pod `public/` **před** tímto handlerem.

Pokud `translationPayloads.publicAssets` (nebo vynucená veřejná kopie u Node SSR) již zapsala `/_locales/\{page\}/\{locale\}/data.json`, runtime zakázání nemůže tento soubor skrýt. Preferujte `locale.disabled: true` při buildu, aby premerge negeneroval statické payloady pro daný locale.
