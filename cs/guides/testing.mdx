# 🧪 Testování modulu `Nuxt I18n Micro`

## 📖 Úvod do testování

Testování modulu `Nuxt I18n Micro` je klíčové, aby bylo zajištěno, že lokalizační funkce vaší aplikace fungují podle očekávání. Tato dokumentace vás provede nastavením testovacího prostředí, vytvořením mock konfigurace pro vitest a psaním testů pro vaše komponenty. Praktický příklad naleznete v [ukázkovém projektu na GitHubu](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/test-utils/example).

Viz [Testování strategií routování](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/testing-strategies.md) pro to, jak tento repozitář spouští své vlastní testovací sady — Vitest projekty `unit` / `integration` / `e2e`, per-strategie soubory (`test/strategies-*.test.ts`) a generovací regrese.

## 🛠️ Nastavení testovacího prostředí

### 1. Instalace `@i18n-micro/test-utils`

Nejprve musíte nainstalovat testovací utility pro `Nuxt I18n Micro`. Tento balíček poskytuje nezbytné nástroje pro mockování a testování vašich i18n konfigurací.

```bash
npm install @i18n-micro/test-utils --save-dev
```

### 2. Vytvoření mock konfiguračního souboru

Dále vytvořte soubor pro nastavení mock i18n konfigurace. Tento soubor bude použit k mockování i18n funkcí a utilit během vašich testů.

```typescript
// tests/unit-setup.ts

import { mockNuxtImport } from '@nuxt/test-utils/runtime'
import { vi } from 'vitest'
import { i18nUtils } from '@i18n-micro/test-utils'

export function createFakeI18n() {
  return {
    $getLocale: vi.fn(i18nUtils.getLocale),
    $t: vi.fn(i18nUtils.t),
    $tc: vi.fn(i18nUtils.tc),
    $setLocale: vi.fn(i18nUtils.setLocale),
    $getLocaleName: vi.fn(i18nUtils.getLocaleName),
    $setLocaleName: vi.fn(i18nUtils.setLocaleName),
    $getLocales: vi.fn(i18nUtils.getLocales),
    $setLocales: vi.fn(i18nUtils.setLocales),
    $defaultLocale: vi.fn(i18nUtils.defaultLocale),
    $setDefaultLocale: vi.fn(i18nUtils.setDefaultLocale),
    $getRouteName: vi.fn(i18nUtils.getRouteName),
    $settRouteName: vi.fn(i18nUtils.settRouteName),
    $ts: vi.fn(i18nUtils.ts),
    $tn: vi.fn(i18nUtils.tn),
    $td: vi.fn(i18nUtils.td),
    $has: vi.fn(i18nUtils.has),
    $resolveTranslations: vi.fn(i18nUtils.resolveTranslations),
    $setTranslation: vi.fn(i18nUtils.setTranslation),
    $mergeTranslations: vi.fn(i18nUtils.mergeTranslations),
    $switchLocaleRoute: vi.fn(i18nUtils.switchLocaleRoute),
    $switchLocalePath: vi.fn(i18nUtils.switchLocalePath),
    $switchLocale: vi.fn(i18nUtils.switchLocale),
    $switchRoute: vi.fn(i18nUtils.switchRoute),
    $localeRoute: vi.fn(i18nUtils.localeRoute),
    $localePath: vi.fn(i18nUtils.localePath),
    $setI18nRouteParams: vi.fn(i18nUtils.setI18nRouteParams),
  }
}

mockNuxtImport<() => ReturnType<typeof createFakeI18n>>('useI18n', () => vi.fn(() => createFakeI18n()))

export const setTranslationsFromJson = i18nUtils.setTranslationsFromJson
```

### 3. Konfigurace Vitest

Nyní nakonfigurujte Vitest tak, aby používal mock konfigurační soubor a nastavte testovací prostředí.

```typescript
// vitest.config.ts

import { defineVitestConfig } from '@nuxt/test-utils/config'

export default defineVitestConfig({
  test: {
    watch: false,
    setupFiles: ['./tests/unit-setup.ts'],
    include: ['./**/*.spec.ts'],
  },
})
```

## 🧪 Psaní testů

### Ukázková komponenta

Zde je příklad jednoduché komponenty, která používá composable `useI18n` k překladu zpráv.

```vue
<script setup lang="ts">
const { $t } = useI18n()

const props = defineProps({
  message: {
    type: String,
    default: null,
  },
})

// Test to see that $t works in script setup as well as the template
const message = props.message || $t('defaultMessage')
</script>

<template>
  <div>
    <p>Test from component: {{ $t('welcome') }}</p>
    <p data-testid="message">Test message from props: {{ message }}</p>
  </div>
</template>
```

### Testovací soubor

Nyní pojďme napsat test pro tuto komponentu.

```typescript
// tests/unit/example.spec.ts

import { describe, it, expect, beforeEach } from 'vitest'
import { mount } from '@vue/test-utils'
import ExampleComponent from '@/components/ExampleComponent.vue'
import fs from 'fs'
import path from 'path'
import { setTranslationsFromJson } from './unit-setup'

describe('ExampleComponent', () => {
  beforeEach(async () => {
    const fileContent = fs.readFileSync(path.join(__dirname, '../../locales/en-GB.json')).toString()
    await setTranslationsFromJson('en', JSON.parse(fileContent))
  })

  it('renders the welcome message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.text()).toContain('Test from component: Welcome')
  })

  it('renders the default message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Default Message')
  })

  it('renders the custom message correctly', () => {
    const wrapper = mount(ExampleComponent, {
      props: {
        message: 'Custom Message',
      },
    })
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Custom Message')
  })
})
```

## 📝 Osvědčené postupy pro testování

- **🔧 Mockujte i18n funkce:** Vždy mockujte i18n funkce pomocí `@i18n-micro/test-utils`, abyste zajistili konzistentní a předvídatelné výsledky testů.
- **⚙️ Používejte Vitest pro unit testy:** Vitest je výkonný testovací framework pro Vue aplikace. Používejte jej k psaní unit testů pro vaše komponenty.
- **📚 Dokumentujte své testy:** Jasně dokumentujte účel a očekávané výsledky každého testu. To pomůže udržet přehlednost a usnadní ostatním (nebo budoucímu vám) porozumění testům.

## 📊 Utility metody i18n

Níže je tabulka popisující všechny utility metody poskytované `@i18n-micro/test-utils`.

| Metoda                                          | Popis                                                                                                                                        |
| ----------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `t(key, params, defaultValue)`                  | Přeloží klíč s volitelnými parametry a výchozí hodnotou.                                                                                     |
| `tc(key, params, defaultValue)`                 | Přeloží klíč s podporou pluralizace.                                                                                                         |
| `setTranslationsFromJson(locale, translations)` | Načte překlady z JSON objektu pro konkrétní locale.                                                                                          |
| `getLocale()`                                   | Vrátí aktuální locale.                                                                                                                       |
| `setLocale(val)`                                | Nastaví aktuální locale.                                                                                                                     |
| `getLocaleName()`                               | Vrátí název aktuálního locale.                                                                                                               |
| `setLocaleName(val)`                            | Nastaví název aktuálního locale.                                                                                                             |
| `getLocales()`                                  | Vrátí seznam dostupných locale.                                                                                                              |
| `setLocales(val)`                               | Nastaví seznam dostupných locale.                                                                                                            |
| `defaultLocale()`                               | Vrátí výchozí locale.                                                                                                                        |
| `setDefaultLocale(val)`                         | Nastaví výchozí locale.                                                                                                                      |
| `getRouteName()`                                | Vrátí název aktuální routy.                                                                                                                  |
| `settRouteName(val)`                            | Nastaví název aktuální routy.                                                                                                                |
| `ts(key, params, defaultValue)`                 | Přeloží klíč a vrátí výsledek jako řetězec.                                                                                                  |
| `tn(value, options?)`                           | Formátuje číslo s inline `Intl.NumberFormatOptions`. Pojmenované formáty vyžadují konfiguraci modulu a nejsou v tomto samostatném pomocníkovi dostupné. |
| `td(value, options?)`                           | Formátuje datum s inline `Intl.DateTimeFormatOptions`. Pojmenované formáty vyžadují konfiguraci modulu a nejsou v tomto samostatném pomocníkovi dostupné. |
| `has(key)`                                      | Zkontroluje, zda překladový klíč existuje.                                                                                                   |
| `resolveTranslations()`                             | Vrátí aktivní překladový strom pro aktuální locale a routu.                                                                                  |
| `setTranslation(key, value)`                    | Nahradí hodnotu na klíči `key` v aktivním slovníku (nahrazení, ne slučování).                                                                |
| `mergeTranslations(newTranslations)`              | Sloučí překlady do aktivního locale za běhu.                                                                                                 |

Postupováním podle těchto kroků můžete efektivně otestovat modul `Nuxt I18n Micro` a zajistit, aby lokalizační funkce vaší aplikace fungovaly podle očekávání.
