# 🌐 Průvodce integrací s Crowdin

## 📖 Úvod

Integrace Crowdin do vašeho projektu zefektivňuje proces lokalizace a překladu a usnadňuje správu překladů napříč více jazyky a platformami. Tento průvodce vás krok za krokem provede nastavením Crowdin s vaším projektem, včetně konfigurace, nahrávání zdrojů a stahování překladů.

## 🔧 Instalace a nastavení

Chcete-li začít s Crowdin, budete potřebovat globálně nainstalovat Crowdin CLI a inicializovat ho v adresáři projektu.

### 📦 Instalace Crowdin CLI

Nejprve nainstalujte Crowdin CLI globálně pomocí npm:

```bash
npm install -g @crowdin/cli
```

### 🛠 Inicializace Crowdin ve vašem projektu

Inicializujte Crowdin ve svém projektu spuštěním:

```bash
crowdin init
```

Tento příkaz vás provede procesem nastavení, včetně nastavení ID projektu, API tokenu a dalších detailů konfigurace.

## 🗂️ Průvodce konfigurací

### 📄 Konfigurační soubor Crowdin (`crowdin.yml`)

Konfigurační soubor Crowdin (`crowdin.yml`) definuje, jak jsou vaše zdrojové soubory mapovány a kde by měly být překlady umístěny. Níže je ukázka konfigurace:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Klíčové konfigurační parametry

- **`project_id`**: ID vašeho Crowdin projektu. Identifikuje projekt v Crowdinu, kde jsou překlady spravovány.
- **`api_token`**: API token používaný pro autentizaci. Ujistěte se, že má správná oprávnění pro nahrávání a stahování překladů.
- **`base_path`**: Určuje základní adresář pro zdrojové soubory. V tomto příkladu jsou překlady uloženy v adresáři `./locales`.
- **`base_url`**: Základní URL pro Crowdin API.
- **`preserve_hierarchy`**: Když je nastaveno na `true`, Crowdin zachová strukturu složek vašich zdrojových souborů v projektu.

### 📂 Konfigurace souborů

Sekce `files` mapuje vaše zdrojové soubory na cesty, kam budou překlady uloženy. Například:

- **Zdrojová cesta**: Definuje umístění původních souborů překladů.
- **Cesta překladu**: Určuje, kde budou v Crowdinu uloženy přeložené soubory. Placeholdery jako `%two_letters_code%` slouží k dynamickému nastavení kódu jazyka v cestách souborů.

## ⬆️ Nahrání zdrojových souborů do Crowdinu

Jakmile je konfigurace Crowdin nastavená, můžete své zdrojové soubory nahrát pomocí následujícího příkazu:

```bash
crowdin upload sources
```

Tento příkaz nahraje všechny zdrojové soubory zadané v konfiguraci do Crowdinu, kde jsou dostupné pro překlad.

## ⬇️ Stažení překladů z Crowdinu

Po dokončení nebo aktualizaci překladů v Crowdinu je můžete stáhnout do svého projektu pomocí:

```bash
crowdin download
```

Tento příkaz načte nejnovější překlady z Crowdinu a uloží je podle cest zadaných v konfiguračním souboru.

## ⚙️ Osvědčené postupy

### 🔑 Konzistentní pojmenování klíčů

Zajistěte konzistentní klíče překladů napříč všemi soubory, aby se předešlo zmatku a duplicitám.

### 🧹 Pravidelná údržba

Pravidelně kontrolujte a čistěte nepoužívané klíče překladů, aby vaše soubory zůstaly organizované a spravovatelné.

### 🛠 Automatizace nahrávání a stahování

Integrujte příkazy Crowdin CLI do vaší CI/CD pipeline pro automatizaci nahrávání zdrojových souborů a stahování překladů. Tím zajistíte, že jsou vaše překlady vždy aktuální.

Postupem podle tohoto průvodce budete schopni Crowdin do svého projektu hladce integrovat a zajistit efektivní a organizovaný přístup ke správě internacionalizačního úsilí.
