# 🌐 Průvodce integrací s Crowdin

## 📖 Úvod

Integrace Crowdin do vašeho projektu zjednodušuje proces lokalizace a překladu, což usnadňuje správu překladů napříč více jazyky a platformami. Tento průvodce poskytuje krok za krokem návod na nastavení Crowdin s vaším projektem, včetně konfigurace, nahrávání zdrojových souborů a stahování překladů.

## 🔧 Instalace a nastavení

Abyste mohli začít s Crowdin, budete muset globálně nainstalovat Crowdin CLI a inicializovat jej v adresáři vašeho projektu.

### 📦 Instalace Crowdin CLI

Nejprve globálně nainstalujte Crowdin CLI pomocí npm:

```bash
npm install -g @crowdin/cli
```

### 🛠 Inicializace Crowdin ve vašem projektu

Inicializujte Crowdin ve vašem projektu spuštěním:

```bash
crowdin init
```

Tento příkaz vás provede procesem nastavení, včetně nastavení ID projektu, API tokenu a dalších konfiguračních detailů.

## 🗂️ Průvodce konfigurací

### 📄 Konfigurační soubor Crowdin (`crowdin.yml`)

Konfigurační soubor Crowdin (`crowdin.yml`) definuje, jak jsou vaše zdrojové soubory namapovány a kam by měly být umístěny překlady. Níže je příklad konfigurace:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Klíčové konfigurační parametry

- **`project_id`**: Vaše ID projektu v Crowdin. Identifikuje projekt v rámci Crowdin, kde jsou překlady spravovány.
- **`api_token`**: API token používaný pro autentizaci. Ujistěte se, že tento token má správná oprávnění pro nahrávání a stahování překladů.
- **`base_path`**: Určuje základní adresář pro zdrojové soubory. V tomto příkladu jsou překlady uloženy v adresáři `./locales`.
- **`base_url`**: Základní URL pro Crowdin API.
- **`preserve_hierarchy`**: Když je nastaveno na `true`, Crowdin zachová v projektu strukturu složek vašich zdrojových souborů.

### 📂 Konfigurace souborů

Sekce `files` mapuje vaše zdrojové soubory na cesty, kam budou překlady uloženy. Například:

- **Zdrojová cesta**: Definuje umístění původních překladových souborů.
- **Cesta překladu**: Určuje, kde budou přeložené soubory v Crowdin uloženy. Zástupné symboly jako `%two_letters_code%` se používají k dynamickému nastavení kódu jazyka v cestách souborů.

## ⬆️ Nahrávání zdrojových souborů do Crowdin

Jakmile je vaše konfigurace Crowdin nastavena, můžete nahrát zdrojové soubory pomocí následujícího příkazu:

```bash
crowdin upload sources
```

Tento příkaz nahraje všechny specifikované zdrojové soubory ve vaší konfiguraci do Crowdin, čímž je zpřístupní pro překlad.

## ⬇️ Stahování překladů z Crowdin

Poté, co jsou překlady v Crowdin dokončeny nebo aktualizovány, můžete je stáhnout do svého projektu pomocí:

```bash
crowdin download
```

Tento příkaz načte nejnovější překlady z Crowdin a uloží je podle cest specifikovaných ve vašem konfiguračním souboru.

## ⚙️ Osvědčené postupy

### 🔑 Konzistentní pojmenování klíčů

Zajistěte, aby překladové klíče byly konzistentní napříč všemi soubory, aby se předešlo zmatku a duplikaci.

### 🧹 Pravidelná údržba

Pravidelně kontrolujte a čistěte nepoužívané překladové klíče, abyste udrželi soubory organizované a spravovatelné.

### 🛠 Automatizace nahrávání a stahování

Integrujte příkazy Crowdin CLI do vaší CI/CD pipeline pro automatizaci nahrávání zdrojových souborů a stahování překladů, čímž zajistíte, že vaše překlady budou vždy aktuální.

Podle tohoto průvodce budete schopni bezproblémově integrovat Crowdin do svého projektu a zajistit efektivní a organizovaný přístup ke správě vašich internacionalizačních snah.
