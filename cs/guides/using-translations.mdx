# Použití překladů v komponentách

Jakmile je modul nainstalován a nakonfigurován, můžete zobrazovat překlady voláním `$t('your_key')` uvnitř svých Vue šablon a skriptů.

## 1. Překladové soubory na kořenové úrovni a specifické pro stránky

1. **Překlady na kořenové úrovni** se nacházejí přímo pod složkou `/locales` (např. `/locales/en.json`, `/locales/fr.json`). Při buildu jsou automaticky sloučeny do každého souboru specifického pro stránku, díky čemuž jsou dostupné na všech stránkách.
2. **Překlady specifické pro stránky** žijí pod `/locales/pages/...` a odpovídají struktuře složky pages ve vašem Nuxt projektu:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. Použití v šabloně pomocí `$t`

Ve svých `.vue` souborech můžete přímo použít `$t` v šabloně:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
`$t` může vrátit **objekty**, pokud klíč ukazuje na vnořený JSON uzel (např. `$t('header')` → `\{ title: "Hi" \}`). V šablonách se to vykreslí jako `[object Object]`. Použijte `$ts`, když potřebujete zaručený řetězec, nebo poskytněte specifičtější klíč jako `$t('header.title')`. Podrobnosti viz [Referenční příručka API — $t vs $ts](/api/methods#t).
</Tip>

## 3. Přepínání aktuálního locale

Chcete-li ve své aplikaci změnit jazyky, můžete získat `$locale` z `useI18n()` a přiřadit mu nový kód:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. Vnořené klíče a zástupné symboly

- **Vnořené klíče** používají tečkovou notaci, např. `nested.key.deeper`.
- **Zástupné symboly** umožňují vkládat dynamické hodnoty:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. Tipy a osvědčené postupy

- **Konfliktní klíče**: Pokud soubor specifický pro stránku obsahuje stejný klíč jako soubor na kořenové úrovni, verze specifická pro stránku má prioritu (překlady na kořenové úrovni jsou při buildu sloučeny jako základ).
- **Zakázání souborů pro stránky**: Pokud raději nechcete používat překlady specifické pro stránky, můžete ve své Nuxt konfiguraci nastavit `disablePageLocales: true`. Tímto způsobem se používají pouze soubory `/locales/*.json`.
- **Bez přímých importů**: Nemusíte dělat `import \{ useI18n \} from 'nuxt-i18n-micro'`; funkce automatické injektáže modulu se o to postará za vás.

To je vše! S těmito kroky můžete rychle **začít získávat překlady** ze souborů JSON na kořenové úrovni nebo specifických pro stránky a **zobrazovat je** ve své Nuxt aplikaci pomocí `$t`.

## Další zdroje

Pro prozkoumání pokročilejších funkcí se ujistěte, že si prohlédnete:

1. **Komponenta `<i18n-t>`**  
   Komponenta `<i18n-t>` je mocnou alternativou k `$t`, obzvláště užitečná pro situace zahrnující vnořené prvky, pokročilé použití zástupných symbolů a složitější překladové struktury.

- **Dokumentace**: [i18n-t](/api/components/i18n-t)

2. **Composable `useI18n`**  
   Composable `useI18n` nabízí kompletní sadu funkcí a reaktivních vlastností pro správu překladů, přepínání locale, formátování a další.

- **Dokumentace**: [useI18n](/api/composables/use-i18n)
