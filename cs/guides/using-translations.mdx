# Použití překladů v komponentách

Jakmile je modul nainstalovaný a nakonfigurovaný, můžete překlady zobrazit voláním `$t('your_key')` uvnitř Vue šablon a skriptů.

## 1. Kořenové a stránkově specifické soubory překladů

1. **Kořenové** překlady leží přímo ve složce `/locales` (například `/locales/en.json`, `/locales/fr.json`). V době buildu se automaticky slučují do každého stránkově specifického souboru a jsou tak dostupné na všech stránkách.
2. **Stránkově specifické** překlady leží pod `/locales/pages/...` a odpovídají struktuře složky pages ve vašem Nuxt projektu:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. Použití v šabloně s `$t`

Ve svých `.vue` souborech můžete `$t` přímo použít v šabloně:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
`$t` může vracet **objekty**, pokud klíč ukazuje na vnořený JSON uzel (např. `$t('header')` → `\{ title: "Hi" \}`). V šablonách se to vykreslí jako `[object Object]`. Použijte `$ts`, když potřebujete zaručený řetězec, nebo zadejte konkrétnější klíč jako `$t('header.title')`. Podrobnosti najdete v [Referenci API: $t vs $ts](/api/methods#t).
</Tip>

## 3. Přepnutí aktuálního locale

Chcete-li ve své aplikaci změnit jazyky, získejte z `useI18n()` `$locale` a přiřaďte mu nový kód:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. Vnořené klíče a placeholdery

- **Vnořené klíče** používají tečkovou notaci, například `nested.key.deeper`.
- **Placeholdery** umožňují vkládat dynamické hodnoty:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. Tipy a osvědčené postupy

- **Konfliktní klíče**: Pokud stránkově specifický soubor obsahuje stejný klíč jako kořenový, má přednost stránkově specifická verze (kořenové překlady se v době buildu slučují jako základ).
- **Vypnutí stránkových souborů**: Pokud raději nechcete používat stránkově specifické překlady, můžete v Nuxt konfiguraci nastavit `disablePageLocales: true`. Použijí se pak jen soubory `/locales/*.json`.
- **Žádné přímé importy**: Nemusíte psát `import \{ useI18n \} from 'nuxt-i18n-micro'`; modul se o auto-injection postará za vás.

A je to! S těmito kroky můžete rychle **začít získávat překlady** z kořenových nebo stránkově specifických JSON souborů a **zobrazovat je** ve své Nuxt aplikaci pomocí `$t`.

## Další zdroje

Chcete-li prozkoumat pokročilejší funkce, podívejte se určitě na:

1. **Komponentu `<i18n-t>`**  
   Komponenta `<i18n-t>` je výkonná alternativa k `$t`, obzvláště užitečná v situacích s vnořenými elementy, pokročilým použitím placeholderů a složitějšími strukturami překladů.

- **Dokumentace**: [i18n-t](/api/components/i18n-t)

2. **Composable `useI18n`**  
   Composable `useI18n` nabízí kompletní sadu funkcí a reaktivních vlastností pro správu překladů, přepínání locale, formátování a další.

- **Dokumentace**: [useI18n](/api/composables/use-i18n)
