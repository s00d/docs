# Výsledky výkonnostních testů

## Informace o projektu

- **[plain-nuxt](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/plain-nuxt)**: ./test/fixtures/plain-nuxt
- **[i18n-micro](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/i18n-micro)**: ./test/fixtures/i18n-micro
- **[i18n](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/i18n)**: ./test/fixtures/i18n
- **[CLI](https://github.com/s00d/nuxt-i18n-micro/tree/main/scripts/src/commands/performance.ts)**: `pnpm -C scripts cli performance` / `pnpm test:performance`

### Popis

Srovnává **plain Nuxt** (baseline bez i18n modulu), **i18n-micro** a **`@nuxtjs/i18n` v10.6** pod jedním sdíleným profilem slovníku.

Zaměření: doba buildu, špičkový RSS, deployable **code vs translations vs total** a chování serveru pod Artillery + Autocannon.

### Poznámky k metodologii

- Metriky jsou **průměry 3 po sobě jdoucích běhů na fixture** (fixture A ×3, pak B ×3, pak C ×3, nikoli prokládaně).
- **Translations** zahrnují locale JSON pod `locales/` / `_locales/` / `translations/`, vše pod `chunks/raw/` a odpovídající locale chunky. Starší reporty, které u `@nuxtjs/i18n` ukazovaly „translations: 0 B“ a obrovský sloupec „code“, počítaly message chunky jako kód aplikace.
- **plain-nuxt** servíruje stejný objem listových klíčů jako statický `public/translations` JSON (nikoli statické JS importy). Pod Artillery je tato baseline náročná na I/O; není to „i18n režie“, ale cena stažení velkého JSON na request.

### Běhy

Všechny metriky níže jsou **průměry napříč 3 běhy**.

## Poznámky

- Sdílený profil: 4 locale × 2 stránky × ~16.8k listových klíčů indexu.
- Artillery: 6s warm-up @6 VU/s + 60s main @60 VU/s. Autocannon: 10 spojení × 10s.
- Znovu spustit: `pnpm test:performance` nebo `pnpm -C scripts cli performance --locales N --keys K --only all|micro|i18n|plain --runs N`.
