## 🚀 Rychlý start

### Instalace

Nainstalujte modul do své Nuxt aplikace:

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

### Základní konfigurace

Přidejte modul do svého `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

<Tip>
- **Soubory na kořenové úrovni** (`locales/en.json`, atd.) — překlady sdílené napříč celou aplikací (menu, patička, běžné UI). S `translationPayloads.mode: 'premerged'` (výchozí) se sloučí do každé stránky při buildu.
- **Soubory specifické pro stránky** (`locales/pages/<route>/<locale>.json`) — překlady jedinečné pro konkrétní stránky, načítané pouze při návštěvě dané stránky
- **Dynamické routy** — `pages/articles/[id].vue` se mapuje na `locales/pages/articles-id/` (hranaté závorky nahrazeny pomlčkami)
- **Automatické generování** — všechny překladové soubory se automaticky vytvoří, pokud chybí, během `nuxt dev`
</Tip>

<Info>
Modul podporuje obě rozložení:

- **Stránky**: `pages/**/*.vue` (Nuxt 3) nebo `app/pages/**/*.vue` (Nuxt 4)
- **Překlady**: standardně ponechejte `locales/` v **kořenovém adresáři projektu** (doporučená konvence), ne uvnitř `app/`

```tree
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   ├── en.json
│   └── pages/
└── nuxt.config.ts
```

Volitelná kolokace: `i18n: \{ translationDir: 'app/locales' \}` (viz [fixture `n3`](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/n3)).

Pro volitelného CLI pomocníka `text-to-i18n` použijte [`nuxt-i18n-micro-cli` ≥ 2.1.1](/guides/cli#-text-to-i18n-command), aby se `app/pages` a `app/components` skenovaly z kořenového adresáře projektu.
</Info>

### Základní použití

Použijte překlady ve svých komponentách:

```vue
<template>
  <div>
    <h1>{{ $t('welcome') }}</h1>
    <p>{{ $t('description', { name: 'World' }) }}</p>

    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" @click="$switchLocale(locale.code)">
        {{ locale.code }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useI18n } from '#imports'

const { $t, $getLocales, $switchLocale } = useI18n()
</script>
```
