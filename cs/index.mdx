---

Nuxt I18n Micro je lehký a vysoce výkonný i18n modul pro Nuxt 3 a 4 navržený pro velké projekty. Ve srovnání s tradičními i18n řešeními, jako je `@nuxtjs/i18n`, udržuje nízkou dobu buildu, spotřebu paměti i velikost bundlu.

Lokalizované routy generuje při buildu `@i18n-micro/route-strategy` a za běhu je rozpoznává `@i18n-micro/path-strategy`, takže odkazy, přepínač, `hreflang` i přesměrování jsou vždy v souladu s routerem. Překlady jsou pouze v JSON, rozdělené mezi sdílené kořenové soubory a soubory pro jednotlivé stránky, které za vás vytvoří vývojový server, a HMR je součástí.

<CodeGroup>

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>
