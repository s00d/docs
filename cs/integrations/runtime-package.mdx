`@i18n-micro/runtime` je instance i18n nezávislá na frameworku: slovníky, `t()`, plurály, formátování přes `Intl` a odběr změn, bez `fs` a bez frameworku. Použijte ji v čistém TypeScriptu, ve web workeru, v edge funkci nebo jako základ vlastního bindingu. Balíčky pro React, Preact, Node a Astro rozšiřují právě tuto třídu.

## Instalace {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/runtime
```

```bash npm
npm install @i18n-micro/runtime
```

```bash yarn
yarn add @i18n-micro/runtime
```

</CodeGroup>

Žádné peer závislosti. Pro soubory s překlady na disku použijte [`@i18n-micro/node`](/cs/integrations/nodejs-package).

## Nastavení {#setup}

```ts
import { createI18n } from '@i18n-micro/runtime'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    en: { greeting: 'Hello, {name}!', apples: 'no apples | one apple | {count} apples' },
    de: { greeting: 'Hallo, {name}!' },
  },
  routeMessages: {
    about: { en: { title: 'About us' } },
  },
})
```

Všechny možnosti (`plural`, `missingWarn`, `missingHandler`, `numberFormats`, `datetimeFormats`) jsou uvedeny v části [Instance](/cs/integrations/overview#the-instance).

## Překlad {#translate}

```ts
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.tc('apples', 5) // '5 apples'
i18n.tn(1234.5) // '1,234.5'

i18n.setRoute('about')
i18n.t('title') // 'About us' (route dictionary)
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!' (root, still visible)
```

Další slovníky načtěte později:

```ts
i18n.loadMessages({ fr: { greeting: 'Bonjour, {name} !' } }, { about: { fr: { title: 'À propos' } } })
i18n.addTranslations('fr', { nav: { home: 'Accueil' } }) // deep merge; pass false to replace

await i18n.loadFromUrl('/locales/fr.json', { locale: 'fr' })
await i18n.loadFromUrl('/locales/pages/about/fr.json', { locale: 'fr', routeName: 'about' })
await i18n.loadFromUrls([
  { url: '/locales/en.json', locale: 'en' },
  { url: '/locales/de.json', locale: 'de' },
])
```

`loadFromUrl` používá `fetch` (pro hlavičky předejte `init`) a při odpovědi, která není OK, vyhodí výjimku. `loadFromUrls` načítá jeden soubor po druhém.

## Přepnutí lokalizace {#switch-locale}

```ts
i18n.locale = 'de'
i18n.t('greeting', { name: 'Ada' }) // 'Hallo, Ada!'
```

Změny lokalizace, trasy a slovníků upozorní odběratele; právě tak se bindingy frameworků překreslují:

```ts
const stop = i18n.subscribe(() => {
  document.querySelector('#greeting')!.textContent = i18n.t('greeting', { name: 'Ada' }) as string
})
i18n.locale = 'fr'
stop()
```

`getSnapshot()` vrací řetězec, který se mění při každém upozornění (pro store ve stylu `useSyncExternalStore`).

## Pro každý požadavek {#per-request}

Instance drží jednu lokalizaci a jednu trasu. Na serveru nepřepínejte sdílenou instanci pro každý požadavek: dva souběžné požadavky by viděly lokalizaci toho druhého. `i18n.fork(locale)` dá požadavku vlastní instanci: vlastní lokalizaci, záložní lokalizaci a trasu; tytéž slovníky, formátovače a pravidla. Fork stojí stejně bez ohledu na počet slovníků. Fork vidí zápisy do rodiče až do svého prvního vlastního zápisu a jeho zápisy zůstávají v něm. [Node.js](/cs/integrations/nodejs-package#per-request) přidává `run`.

## API {#api}

| Člen | Poznámky |
| --- | --- |
| `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has` | viz [Překlad a formátování](/cs/integrations/overview#translate-and-format) |
| `locale`, `fallbackLocale` | čtení/zápis |
| `currentRoute`, `setRoute(name)`, `getRoute()` | aktivní trasa, výchozí `'index'` |
| `loadMessages(messages?, routeMessages?)` | sloučí mnoho lokalizací a tras najednou |
| `addTranslations(locale, tree, merge = true)`, `addRouteTranslations(locale, route, tree, merge = true)` | |
| `loadFromUrl(url, { locale?, routeName?, init? })`, `loadFromUrls(entries)` | JSON přes `fetch` |
| `hasTranslation(key)` | aktivní lokalizace, libovolná trasa (na rozdíl od `has`, které kontroluje aktivní trasu a kořen) |
| `setTranslation(key, value)`, `resolveTranslations()` | zapíše jeden klíč; přečte sloučený strom |
| `clear()`, `clearCache()` | zahodí všechny slovníky |
| `subscribe(cb)`, `getSnapshot()` | upozornění na změny |
| `storage` | `{ translations: Map<'locale:route', Translations> }` |

Kód, který není jazykovým tagem, získá plurály z `localeIso: { ua: 'uk-UA' }`; `localeIsoMap(locales)` to sestaví z položek seznamu lokalizací, které mají `iso`.

Exporty modulu: `createI18n`, `I18n`, `fetchJsonTranslations`, `FormatService`, `interpolate`, `localeIsoMap` a typy `I18nOptions`, `LoadFromUrlOptions`, `LoadFromUrlEntry`, `TranslationStorage`, `Translations`, `Locale`, `PluralFunc`. Úplné signatury: [reference balíčku](/cs/api/packages/runtime).
