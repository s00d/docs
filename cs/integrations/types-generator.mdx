---
title: "Generátor typů"
description: "Generujte automatické doplňování TypeScriptu pro klíče překladů z vašich JSON souborů, v Nuxtu nebo v jakémkoli projektu s Vite."
---

`@i18n-micro/types-generator` přečte každý JSON soubor ve vaší složce s překlady a zapíše deklaraci, která vypisuje všechny klíče. Přidejte ho, chcete-li, aby vám editor navrhoval klíče v `t()`, `$t()` a `<I18nT keypath>`. Funguje jako modul pro Nuxt i jako plugin pro Vite nebo Rollup a při změně souboru se znovu vygeneruje.

## Instalace {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/types-generator
```

```bash npm
npm install -D @i18n-micro/types-generator
```

```bash yarn
yarn add -D @i18n-micro/types-generator
```

</CodeGroup>

Peer závislost: `@nuxt/kit` `^3.18.0 || ^4.0.0`. Importuje ji pouze vstup `/nuxt`; v projektu pouze s Vite lze varování o peer závislosti ignorovat.

## Nuxt {#nuxt}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro', '@i18n-micro/types-generator/nuxt'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Modul zapíše `.nuxt/types/i18n-micro.d.ts` a Nuxt ho přidá do typového kontextu; ručně není třeba nic zahrnovat. Čte `i18nTypes.translationDir`, jinak tam, kde čte překlady `nuxt-i18n-micro`: `translationDir` (z `i18n` nebo z vložených možností modulu, výchozí `'locales'`) v každé vrstvě a `additionalTranslationDirs`. Úprava JSON souboru v této složce znovu vygeneruje typy v `nuxi dev`. `i18nTypes.outputFile` je v Nuxtu ignorován (upozorní na to varování).

## Vite {#vite}

`I18nTypesPlugin` je plugin pro Vite, který přijme i Rollup. Pro jiný bundler volejte `generateTypes` ve skriptu.

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { I18nTypesPlugin } from '@i18n-micro/types-generator'

export default defineConfig({
  plugins: [
    vue(),
    I18nTypesPlugin({
      srcDir: process.cwd(),
      translationDir: 'src/locales',
      outputFile: 'src/i18n-micro.d.ts',
    }),
  ],
})
```

| Možnost | Povinná | Poznámky |
| --- | --- | --- |
| `srcDir` | ano | Základní adresář; `translationDir` se vyhodnocuje vůči němu. |
| `translationDir` | ano | Složka s JSON soubory (včetně podsložek jako `pages/`), nebo pole složek. |
| `outputFile` | ne | Kam zapsat deklaraci; výchozí `<srcDir>/i18n-micro.d.ts`. |

Plugin generuje jednou na začátku buildu a na vývojovém serveru generuje znovu 300 ms po změně ve složce. Ujistěte se, že `include` ve vašem `tsconfig.json` pokrývá výstupní soubor.

## Použití klíčů {#use-the-keys}

Vygenerovaný soubor rozšiřuje `DefineLocaleMessage` v `@i18n-micro/types`, čímž se `TranslationKey` změní na vaše klíče:

```ts
declare module '@i18n-micro/types' {
  export interface DefineLocaleMessage {
    nav: object
    'nav.home': string
    'profile.title': string
  }
}
```

Klíče jsou ty, na které odpovídá `t()`, včetně objektů, ze všech lokalizací a všech souborů stránek, s typem jejich JSON hodnoty. `TranslationKey` je sjednocením těchto klíčů a libovolného řetězce, takže získáte automatické doplňování, nikoli chyby: překlep nebo dynamický klíč se stále zkompiluje. Parametry a návratové hodnoty typovány nejsou.

Pro dynamické klíče pod známým prefixem zúží `ScopedKey<'prefix'>` výběr na odpovídající klíče:

```ts
import type { ScopedKey } from '@i18n-micro/types'

const statusText = (status: string) => t(`status.${status}` as ScopedKey<'status'>)
```

`TranslationKey` a `ScopedKey` pocházejí z `@i18n-micro/types` (React, Preact a Solid re-exportují `TranslationKey`; Vue ne).

## API {#api}

| Export | Vstup | Poznámky |
| --- | --- | --- |
| `I18nTypesPlugin(options)` | `@i18n-micro/types-generator` | plugin pro Vite a Rollup |
| `generateTypes(options)` | `@i18n-micro/types-generator` | zapíše soubor, vrátí jeho cestu |
| `getTypesString(options)` | `@i18n-micro/types-generator` | vrátí deklaraci bez zápisu |
| `formatKeyProperty(key)` | `@i18n-micro/types-generator` | helper |
| Modul pro Nuxt (`configKey: 'i18nTypes'`) | `@i18n-micro/types-generator/nuxt` | možnost `translationDir` |

Úplné signatury: [reference balíčku](/cs/api/packages/types-generator).
