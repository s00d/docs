`@i18n-micro/devtools-ui` je editor překladů ze záložky Nuxt DevTools, zabalený jako webová komponenta s pluginem pro Vite. Přidejte jej do projektu ve Vue, Reactu, Preactu, Solidu nebo Astru, abyste mohli během vývoje procházet a upravovat soubory JSON ve složce s překlady přímo v prohlížeči. Aplikace v Nuxtu jej už mají v [Nuxt DevTools](/cs/guide/devtools).

![The DevTools UI: a file tree and an editor with the default-locale text next to each key](/images/devtools/02-translations-editor-dark.webp)

## Nastavení {#setup}

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import { i18nDevToolsPlugin } from '@i18n-micro/devtools-ui/vite'

export default defineConfig({
  plugins: [i18nDevToolsPlugin({ translationDir: 'src/locales' })],
})
```

| Volba | Výchozí | Poznámky |
| --- | --- | --- |
| `translationDir` | `'src/locales'` | Složka se soubory JSON, relativně ke kořeni Vite. |
| `base` | `'/__i18n_api'` | Základní cesta endpointů API. |
| `injectButton` | `true` | Přidá plovoucí tlačítko na stránky obsluhované přes transformaci `index.html` ve Vite. Astro takové stránky nemá: viz níže. |
| `defaultLocale` | první soubor locale v `translationDir` | Vrací ho `/config`. |
| `fallbackLocale` | `defaultLocale` | Vrací ho `/config`. |

Plugin běží pouze na vývojovém serveru (`apply: 'serve'`); produkční build z něj nic neobsahuje. Tlačítko otevře `/__i18n_devtools.html`, která čte a ukládá soubory přes endpointy pluginu:

| Endpoint | Co dělá |
| --- | --- |
| `GET <base>/translations` | všechny slovníky v `translationDir` podle relativní cesty |
| `POST <base>/save` | tělo `{ file, content }`; přepíše existující `.json` uvnitř `translationDir`, pro cokoli jiného vrátí 403. Nikdy nevytváří soubor |
| `GET <base>/config` | `{ defaultLocale, fallbackLocale, locales, translationDir }`; `locales` pocházejí z kořenových souborů v `translationDir` |

Endpointy odpovídají pouze stránce devtools: požadavek z jiného originu nebo hostitele dostane `403` a `/save` přijímá pouze `application/json` (`415`). Stránka se o změnách souborů dozvídá přes HMR socket Vite.

V Astru místo pluginu přidejte integraci. Ta přidá aplikaci do vývojové lišty:

```ts
// astro.config.mjs
import { defineConfig } from 'astro/config'
import { i18nDevToolsIntegration } from '@i18n-micro/devtools-ui/vite'

export default defineConfig({
  integrations: [i18nDevToolsIntegration({ translationDir: 'src/locales' })],
})
```

Uložení pouze zapíše soubor. Aplikace, která importuje JSON přes Vite, jej dostane přes HMR; pro úpravy aplikované přímo na běžící instanci použijte most.

## Most k živé instanci {#bridge-to-a-live-instance}

Chcete-li editor vložit do vlastní stránky a mít úpravy okamžitě aplikované na běžící instanci, vytvořte most z adaptéru a předejte jej elementu `<i18n-devtools-ui>`:

```ts
import { createBridge, register } from '@i18n-micro/devtools-ui'
import { i18n, locales } from './i18n' // a runtime, React, Preact or Solid instance

register() // defines <i18n-devtools-ui> once

const bridge = createBridge({
  adapter: {
    getRouteCache: () => Object.fromEntries(i18n.storage.translations),
    addTranslations: (locale, content, merge) => i18n.addTranslations(locale, content, merge),
    addRouteTranslations: (locale, route, content, merge) => i18n.addRouteTranslations(locale, route, content, merge),
    subscribe: (cb) => i18n.subscribe(cb),
    getCurrentLocale: () => i18n.locale,
  },
  locales,
  defaultLocale: 'en',
  translationDir: 'src/locales',
})

const el = document.createElement('i18n-devtools-ui') as HTMLElement & { bridge: typeof bridge }
el.bridge = bridge
document.body.append(el)
```

`getRouteCache` musí vracet slovníky s klíči `locale:route` (`en:index`, `en:blog-post`), což je přesně obsah `i18n.storage.translations`. Pro instanci Vue použijte `i18n.global.getRouteCache()` a `i18n.global.subscribeToChanges(cb)`.

`saveTranslation` nejprve aktualizuje instanci a poté odešle POST na `<base>/save`. Pokud endpoint neexistuje (statický náhledový build) nebo vývojový server není dostupný, úprava se uchová v `localStorage`; jakákoli jiná chyba ukládání obnoví předchozí slovník a vyhodí výjimku.

## API {#api}

| --- | --- |

| typ `I18nDevToolsBridge` | `@i18n-micro/devtools-ui` (také `/bridge`) |
| `createRpcClient`, `setupRpcHost` | `@i18n-micro/devtools-ui` |
