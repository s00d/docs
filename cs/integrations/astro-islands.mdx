---

Ostrov běží v prohlížeči, kde serverová instance i18n neexistuje. `@i18n-micro/astro` umožňuje stránce vybrat klíče, které ostrov potřebuje, předat je jako jednu prop a číst je v ostrově přes malý adaptér pro daný framework. V ostrovech Vue, React, Preact a Svelte získáte `t`, `tc`, `tn`, `td`, `tdr` a `has`, přičemž v HTML jsou jen vybrané řetězce.

## Nastavení {#setup}

Nejprve nastavte [integraci a middleware pro Astro](/cs/integrations/astro-package#setup), pak přidejte integraci frameworku, který používáte (`@astrojs/vue`, `@astrojs/react`, `@astrojs/preact`, `@astrojs/svelte`). Adaptéry ostrovů potřebují daný framework jako peer závislost: `vue` `^3.3.0`, `react` `^16.8.0 || ^17.0.0 || ^18.0.0 || ^19.0.0`, `preact` `^10.0.0 || ^11.0.0` nebo `svelte` `^4.0.0 || ^5.0.0`.

## Předání překladů ostrovu {#pass-translations-to-an-island}

```astro
---
// src/pages/index.astro
import { getI18nProps } from '@i18n-micro/astro'
import Counter from '../components/Counter.vue'

const i18n = getI18nProps(Astro, ['counter.title', 'counter.apples'])
---

<Counter client:load i18n={i18n} />
```

`getI18nProps(Astro, keys?)` vrací `{ locale, fallbackLocale, currentRoute, translations }` (typ `I18nClientProps`). Předejte klíče, které ostrov používá: každý se na serveru vyhodnotí jako `t()` (slovníky trasy, kořenový a záložní) a do HTML se dostanou jen nalezené klíče. Bez `keys` se do každého ostrova pošle vše, na co `t()` na této stránce umí odpovědět, takže 2000 kořenových klíčů představuje asi 100 KB na ostrov; ve vývojovém režimu na to nad 20 KB upozorní varování.

Ostrovy překládají jen z tohoto objektu. `t` vrací klíč pro cokoli, co nebylo předáno, a odkazované zprávy (linked messages) se nevyhodnocují.

## Vue {#vue}

Zavolejte `provideI18n(() => props.i18n)` v kořenové komponentě ostrova a `useAstroI18n()` v jejích potomcích. Vue `inject` nevidí hodnotu poskytnutou toutéž komponentou, takže hook musí běžet v potomkovi, ne v kořeni:

```vue
<!-- src/components/Counter.vue -->
<script setup lang="ts">
import { provideI18n } from '@i18n-micro/astro/client/vue'
import type { I18nClientProps } from '@i18n-micro/astro'
import CounterBody from './CounterBody.vue'

const props = defineProps<{ i18n: I18nClientProps }>()
provideI18n(() => props.i18n)
</script>

<template><CounterBody /></template>
```

```vue
<!-- src/components/CounterBody.vue -->
<script setup lang="ts">
import { ref } from 'vue'
import { useAstroI18n } from '@i18n-micro/astro/client/vue'

const { t, tc } = useAstroI18n()
const count = ref(0)
</script>

<template>
  <h3>{{ t('counter.title') }}</h3>
  <button @click="count++">{{ tc('counter.apples', count) }}</button>
</template>
```

## React a Preact {#react-and-preact}

```tsx
// src/components/Counter.tsx
import { useState } from 'react'
import { I18nProvider, useAstroI18n } from '@i18n-micro/astro/client/react'
import type { I18nClientProps } from '@i18n-micro/astro'

function Body() {
  const { t, tc } = useAstroI18n()
  const [count, setCount] = useState(0)
  return <button onClick={() => setCount(count + 1)}>{t('counter.title')}: {tc('counter.apples', count)}</button>
}

export default function Counter({ i18n }: { i18n: I18nClientProps }) {
  return (
    <I18nProvider value={i18n}>
      <Body />
    </I18nProvider>
  )
}
```

Pro Preact importujte `I18nProvider` a `useAstroI18n` z `@i18n-micro/astro/client/preact`; API je stejné.

## Svelte {#svelte}

```svelte
<!-- src/components/Counter.svelte -->
<script lang="ts">
  import { createI18nStore, useAstroI18n } from '@i18n-micro/astro/client/svelte'
  import type { I18nClientProps } from '@i18n-micro/astro'

  export let i18n: I18nClientProps
  const { t, tc } = useAstroI18n(createI18nStore(i18n))
  let count = 0
</script>

<button on:click={() => count++}>{t('counter.title')}: {tc('counter.apples', count)}</button>
```

`useAstroI18n(store)` vrací také `store` pro čtení `$store` v šabloně.

## Perzistentní ostrovy {#persisted-islands}

Ostrov s `transition:persist` dostane po navigaci nové props. React, Preact i Vue (pokud dostane getter) je sledují. Ve Svelte si ponechte store a předávejte je dál: `const store = createI18nStore(i18n)`, `const { t } = useAstroI18n(store)`, pak `$: store.set(i18n)` (s runes `$effect(() => store.set(i18n))`).

## API {#api}

| Vstupní bod | Exporty |
| --- | --- |
| `@i18n-micro/astro` | `getI18nProps`, typ `I18nClientProps` |
| `@i18n-micro/astro/client/vue` | `provideI18n(props \| () => props)`, `useAstroI18n()` |
| `@i18n-micro/astro/client/react` | `I18nProvider` (prop `value`), `useAstroI18n()` |
| `@i18n-micro/astro/client/preact` | `I18nProvider` (prop `value`), `useAstroI18n()` |
| `@i18n-micro/astro/client/svelte` | `createI18nStore(props)`, `useAstroI18n(store)` |
| `@i18n-micro/astro/client` | čisté funkce `translate`, `hasTranslation`, bez frameworku |

Každé `useAstroI18n` vrací `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`, `setLocale`, `setRoute` a `locale`. Ostrov má jeden sloučený slovník, takže jeho `has` je true pro klíč, na který umí `t` odpovědět, i ze záložní lokalizace; na serveru se `has` dívá jen na aktivní lokalizaci.
