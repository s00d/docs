`@i18n-micro/vue` je plugin pro Vue 3 s překladovým jádrem Nuxt I18n Micro: reaktivní `t()`, globální `$t`, čtyři komponenty a volitelný adaptér pro vue-router. Použijte jej ve Vue aplikaci postavené na Vite nebo SSR, která není sestavena pomocí Nuxtu. Model instance, kontrakt routeru a props komponent jsou společné s ostatními balíčky a popsané ve [Frameworky](/cs/integrations/overview).

## Instalace {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vue
```

```bash npm
npm install @i18n-micro/vue
```

```bash yarn
yarn add @i18n-micro/vue
```

</CodeGroup>

Peer závislosti: `vue` `^3.3.0`; `vue-router` `^4.5.1 || ^5.0.0` (volitelné, pouze pro `@i18n-micro/vue/router`). Publikované typy vyžadují Vue 3.5.5 nebo novější při `skipLibCheck: false`; při `skipLibCheck: true`, což je obvyklé nastavení šablon, se zkompilují i starší verze.

## Nastavení {#setup}

```ts
// src/main.ts
import { createApp } from 'vue'
import { createI18n } from '@i18n-micro/vue'
import App from './App.vue'
import en from './locales/en.json'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales: [
    { code: 'en', iso: 'en-US', displayName: 'English' },
    { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
  ],
  defaultLocale: 'en',
})

createApp(App).use(i18n).mount('#app')
```

`locales` a `defaultLocale` jsou pro `useI18n()` povinné: bez nich vyhodí `I18nLocalesKey not provided`. Předejte je do `createI18n` (jako výše), do `useI18n({ locales, defaultLocale })` nebo přes `app.provide(I18nLocalesKey, …)` a `app.provide(I18nDefaultLocaleKey, …)`.

Plugin globálně registruje `I18nT`, `I18nLink`, `I18nGroup` a `I18nSwitcher` a do šablon přidává `$t`, `$ts`, `$tc`, `$tn`, `$td`, `$tdr`, `$has` a `$i18n`. Mimo komponenty je instance dostupná jako `i18n.global`. Další volby najdete v části [instance](/cs/integrations/overview#the-instance); `routeMessages` není ve Vue k dispozici, použijte `addRouteTranslations`.

## Překlad {#translate}

```vue
<script setup lang="ts">
import { useI18n } from '@i18n-micro/vue'

const { t, tc, tn } = useI18n()
</script>

<template>
  <h1>{{ t('greeting', { name: 'Ada' }) }}</h1>
  <!-- Hello, Ada! -->
  <p>{{ tc('apples', 3) }}</p>
  <!-- 3 apples -->
  <p>{{ $t('nav.home') }} · {{ tn(1234.5) }}</p>
</template>
```

`useI18n()` vrací překladové metody (`t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`), `locale` (zapisovatelný computed), `getLocale`, `getLocales`, `defaultLocale()`, `getLocaleName`, `localePath`, `localeRoute`, `switchLocale`, `setRoute`, `getRoute`, `addTranslations`, `addRouteTranslations`, `mergeTranslations`, `resolveTranslations`, `setTranslation`, `clearCache` a `instance`.

Další slovníky můžete načíst kdykoli; každá komponenta, která je čte, se znovu vykreslí:

```ts
const { addTranslations, addRouteTranslations, setRoute } = useI18n()

addTranslations('de', (await import('./locales/de.json')).default)
addRouteTranslations('en', 'about', { title: 'About us' })
setRoute('about') // t('title') now reads the 'about' dictionary first
```

## Přepnutí locale {#switch-locale}

```ts
const { locale, switchLocale } = useI18n()

locale.value = 'de' // only the locale
switchLocale('de') // the locale, then router.push to the localized current path
```

Slovník dané locale načtěte před přepnutím nebo po něm; samotné přepnutí nic nestahuje.

`<I18nGroup>` předává svému slotu `t` s prefixem. Klíče uvnitř `<I18nT>` nebo v obyčejném `t()` prefix nemají:

```vue
<I18nGroup prefix="profile" v-slot="{ t }">
  <h2>{{ t('title') }}</h2>
  <!-- profile.title -->
</I18nGroup>
```

## Směrování {#routing}

Adaptér pro vue-router je v podcestě, takže hlavní vstupní bod nikdy neimportuje `vue-router`:

```ts
// src/main.ts
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import { createI18n } from '@i18n-micro/vue'
import { createVueRouterAdapter } from '@i18n-micro/vue/router'
import App from './App.vue'
import Home from './pages/Home.vue'
import About from './pages/About.vue'
import en from './locales/en.json'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English' },
  { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
]

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/:locale(de)?', component: Home },
    { path: '/:locale(de)?/about', component: About },
  ],
})

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales,
  defaultLocale: 'en',
  routingStrategy: createVueRouterAdapter(router, locales, 'en'),
})

createApp(App).use(router).use(i18n).mount('#app')
```

`createVueRouterAdapter(router, locales, defaultLocale)` přidává prefix každé locale kromě výchozí (`/about`, `/de/about`) a vykresluje `<I18nLink>` jako `RouterLink`. Locale z trasy si čtěte sami, například v `router.beforeEach`, a nastavte `i18n.global.locale.value`. Adaptér můžete připojit i později pomocí `i18n.setRoutingStrategy(adapter)`; vlastní adaptér popisuje [Adaptér routeru](/cs/integrations/overview#router-adapter).

## SSR {#ssr}

- Router, instanci i18n i aplikaci vytvářejte uvnitř renderovací funkce pro každý požadavek. Jedna sdílená instance by prozradila locale jednoho návštěvníka jinému.
- Na serveru použijte `createMemoryHistory()`, převezměte locale z URL a před `renderToString` načtěte její slovník (i slovník záložní locale).
- Pošlete locale klientovi (například ve skriptu `window.__STATE__`) a vytvořte klientskou instanci se stejnou `locale`, aby hydratace odpovídala.
- `<I18nSwitcher>` čte `window.location` jen tehdy, když je rozbalovací nabídka otevřená, takže se vykreslí i na serveru.

`packages/vue/playground` obsahuje kompletní dvojici `entry-server.ts` / `entry-client.ts`.

## SEO hlavička {#seo-head}

`useLocaleHead(options)` sestaví z locale a adaptéru routeru `lang`/`dir`, canonical, značky `hreflang` a `og:locale`. Při změně trasy zavolejte `updateMeta()` a předejte `metaObject` svému správci hlavičky:

```ts
import { watch } from 'vue'
import { useRoute } from 'vue-router'
import { useHead } from '@unhead/vue'
import { useLocaleHead } from '@i18n-micro/vue'

const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
watch(() => route.fullPath, () => updateMeta(), { immediate: true })
useHead(metaObject)
```

Volby: `baseUrl` (řetězec nebo funkce), `addDirAttribute` (výchozí `true`), `addSeoAttributes` (výchozí `true`), `identifierAttribute` (výchozí `'id'`), `hreflangBaseLanguage` (výchozí `false`). Locale s `disabled: true` nebo `seo: false` nedostanou alternativní odkaz.
