# Integrace

Balíčky `@i18n-micro` jsou odlehčené framework-specifické verze Nuxt I18n Micro navržené pro integraci do různých frameworků a prostředí. Tyto balíčky poskytují základní funkčnost internacionalizace s minimální stopou a soustředí se na základní překladové funkce a komponenty.

## Přehled

Tyto integrační balíčky jsou **miniaturní verze** plného Nuxt I18n Micro modulu, obsahující pouze nezbytnou funkčnost potřebnou pro internacionalizaci:

- **Základní překladové funkce**: Základní překladové metody, pluralizace a formátování
- **Nezbytné komponenty**: Malá sada UI komponent pro běžné i18n úlohy
- **Vzor Router Adapter**: Flexibilní routovací integrace přes abstrakci adaptéru
- **Podpora TypeScriptu**: Kompletní typové definice pro type-safe vývoj

Na rozdíl od plného Nuxt modulu tyto balíčky:

- Neobsahují framework-specifickou routovací logiku
- Vyžadují implementaci router adaptéru pro routovací funkce
- Zaměřují se na překladovou funkčnost místo frameworkové integrace
- Jsou navržené jako odlehčené a v rámci možností framework-agnostické

## Základní komponenty

Všechny frameworkové balíčky obsahují následující nezbytné komponenty:

### `<I18nT>`

Překladová komponenta, která vykresluje přeložený text s podporou:

- **Interpolace parametrů**: nahrazení placeholderů dynamickými hodnotami
- **Pluralizace**: automatický výběr plurálního tvaru podle počtu
- **Formátování čísel**: formátování čísel podle locale
- **Formátování dat**: formátování data a relativních časů
- **Vykreslování HTML**: volitelné vykreslování HTML obsahu
- **Výchozí hodnoty**: záložní text, když překlad chybí

**Příklad:**

```vue
<!-- Vue -->
<I18nT keypath="greeting" :params="{ name: 'World' }" />
```

```tsx
// React
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```tsx
// Solid
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```astro
<!-- Astro -->
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

### `<I18nLink>`

Lokalizovaná komponenta odkazu, která automaticky řeší prefixy locale v URL. Funkce:

- **Automatická lokalizace cesty**: přidává/odebírá prefixy locale podle routovací strategie
- **Detekce aktivního stavu**: zvýrazňuje aktuální routu
- **Podpora externích odkazů**: automaticky detekuje a zpracovává externí URL
- **Integrace s routerem**: používá odkazovou komponentu router adaptéru, když je k dispozici
- **Vlastní stylování**: podporuje aktivní a hover stavy

**Příklad:**

```vue
<!-- Vue -->
<I18nLink to="/about" active-class="active">
  About Us
</I18nLink>
```

```tsx
// React
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```tsx
// Solid
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```astro
<!-- Astro -->
<I18nLink href="/about" class="nav-link">
  About Us
</I18nLink>
```

### `<I18nSwitcher>`

Přepínač jazyka, který poskytuje rozbalovací nabídku nebo seznam pro změnu locale. Funkce:

- **Automatický seznam locale**: generuje volby z nakonfigurovaných locale
- **Zvýraznění aktuálního locale**: vizuálně indikuje aktivní jazyk
- **Vlastní popisky**: podpora vlastních zobrazovaných jmen pro každý locale
- **Integrace s routerem**: automaticky naviguje na lokalizované cesty
- **Přístupnost**: správné ARIA atributy a klávesová navigace

**Příklad:**

```vue
<!-- Vue -->
<I18nSwitcher />
```

```tsx
// React
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```tsx
// Solid
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```astro
<!-- Astro -->
<I18nSwitcher />
```

### `<I18nGroup>`

Komponenta pro seskupování překladů se společným prefixem, užitečná pro organizaci překladů podle stránky nebo funkce. Funkce:

- **Scoping prefixu**: automaticky přidává prefix ke všem klíčům překladů uvnitř skupiny
- **Vnořené skupiny**: podpora vnořených skupin překladů
- **Čistá organizace**: pomáhá udržovat organizované struktury překladů

**Příklad:**

```vue
<!-- Vue -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

```tsx
// React
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```tsx
// Solid
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```astro
<!-- Astro -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

## Sdílené volby `createI18n` \{#create-i18n-options\}

Každý frameworkový balíček se vytváří stejným způsobem. Liší se jen název typu voleb podle frameworku (`ReactI18nOptions`, `SolidI18nOptions` a další). Samotné volby jsou identické:

| Vlastnost        | Typ                                                        | Povinná  | Výchozí          | Popis                                          |
| ---------------- | ---------------------------------------------------------- | -------- | ---------------- | ---------------------------------------------- |
| `locale`         | `string`                                                   | ✅       | -                | Aktuální kód locale (například `'en'`)         |
| `fallbackLocale` | `string`                                                   | ❌       | Stejný jako `locale` | Fallback locale, když překlad chybí          |
| `messages`       | `Record<string, Translations>`                             | ❌       | `\{\}`             | Počáteční překladové zprávy                    |
| `plural`         | `PluralFunc`                                               | ❌       | `defaultPlural`  | Vlastní pluralizační funkce                    |
| `missingWarn`    | `boolean`                                                  | ❌       | `true`           | Zobrazovat konzolová varování pro chybějící překlady |
| `missingHandler` | `(locale: string, key: string, routeName: string) => void` | ❌       | -                | Vlastní handler pro chybějící překlady         |

Cokoli nad rámec těchto voleb je framework-specifické a dokumentované na stránce příslušného balíčku.

## Abstrakce Router adaptéru

Všechny frameworkové balíčky používají vzor **router adaptéru** pro oddělení i18n funkčnosti od konkrétních implementací routeru. Tento návrh umožňuje:

- **Flexibilita**: použití jakékoli router knihovny nebo žádného routeru
- **Frameworková nezávislost**: routovací logika zůstává ve vaší aplikaci, ne v i18n balíčku
- **Odlehčené jádro**: i18n balíček zůstává malý a zaměřený

### Implementace router adaptéru

Pro použití routovacích funkcí musíte implementovat rozhraní `I18nRoutingStrategy`:

```typescript
interface I18nRoutingStrategy {
  getCurrentPath: () => string
  linkComponent?: Component
  push: (target: { path: string }) => void
  replace: (target: { path: string }) => void
  resolvePath?: (to: string | { path?: string }, locale: string) => string | { path?: string }
  getRoute?: () => { fullPath: string; query: Record<string, unknown> }
}
```

Dokumentace každého balíčku obsahuje kompletní příklady implementace adaptérů pro populární routery:

- **Vue**: příklad adaptéru pro Vue Router
- **React**: příklad adaptéru pro React Router
- **Solid**: příklad adaptéru pro Solid Router
- **Astro**: příklad adaptéru pro file-based routing

## Základní funkce

Všechny balíčky sdílejí tyto základní funkce:

### Překladové metody

- `t()`: základní překlad s interpolací parametrů
- `ts()`: překlad, který vždy vrací řetězec
- `tc()`: překlad s podporou pluralizace
- `tn()`: formátování čísel
- `td()`: formátování data
- `tdr()`: formátování relativního času
- `has()`: kontrola existence klíče překladu

### Správa locale

- **Přepínání locale**: programová změna aktuálního locale
- **Fallback locale**: automatický fallback, když překlad chybí
- **Route-specifické překlady**: organizace překladů na úrovni stránky
- **Cachování překladů**: inteligentní cachování pro výkon

### Podpora TypeScriptu

Všechny balíčky poskytují:

- Kompletní TypeScript definice
- Type-safe klíče překladů (s types generatorem)
- IntelliSense podporu v IDE
- Kontrolu chyb v době kompilace
