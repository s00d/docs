Balíčky `@i18n-micro/*` přinášejí překladové jádro Nuxt I18n Micro do Vue, Reactu, Preactu, Solidu, Astra, VitePressu a čistého JavaScriptu. Použijte je, když vaše aplikace není aplikace Nuxt, nebo když stejné soubory s překlady potřebuje skript či server mimo Nuxt. Všechny balíčky sdílejí jeden model instance, jeden kontrakt adaptéru routeru a stejné čtyři komponenty, popsané jednou na této stránce.

## Balíčky {#packages}

| Stack | Balíček | Vstup routeru |
| --- | --- | --- |
| [Vue 3 SPA](/cs/integrations/vue-package) | `@i18n-micro/vue` | `@i18n-micro/vue/router` |
| [React](/cs/integrations/react-package) | `@i18n-micro/react` | `@i18n-micro/react/router` |
| [Preact](/cs/integrations/react-package#preact) | `@i18n-micro/preact` | — |
| [SolidJS](/cs/integrations/solid-package) | `@i18n-micro/solid` | `@i18n-micro/solid/router` |
| [Astro](/cs/integrations/astro-package): SSR a [islands](/cs/integrations/astro-islands) | `@i18n-micro/astro` | — |
| [VitePress](/cs/integrations/vitepress-package) | `@i18n-micro/vitepress` | — |
| [Prohlížeč nebo edge](/cs/integrations/runtime-package), bez frameworku | `@i18n-micro/runtime` | — |
| [Node.js](/cs/integrations/nodejs-package) server, CLI | `@i18n-micro/node` | — |

Vstup routeru je samostatný import, takže aplikace bez routeru žádný nebalí.

`@i18n-micro/core`, `@i18n-micro/types` a `@i18n-micro/utils` se instalují spolu s těmito balíčky; přímo je importujete jen zřídka. Signatury všech exportů najdete ve vygenerované [referenci balíčků](/cs/api/packages/overview).

Každý balíček má v repozitáři playground v `packages/<name>/playground`.

## Instance {#the-instance}

`createI18n(options)` vrací jednu instanci, která drží slovníky, aktuální locale a aktuální routu. Možnosti jsou ve všech balíčcích stejné:

| Možnost | Typ | Výchozí | Poznámky |
| --- | --- | --- | --- |
| `locale` | `string` | povinné | Aktivní locale. |
| `fallbackLocale` | `string` | `locale` | Prohledá se, když klíč v `locale` chybí. |
| `messages` | `Record<locale, Translations>` | `{}` | Kořenové slovníky (routa `'index'`). |
| `routeMessages` | `Record<route, Record<locale, Translations>>` | `{}` | Slovníky rout. Pouze Runtime, React, Preact, Node a VitePress. |
| `plural` | `PluralFunc` | `defaultPlural` | Vlastní pravidlo plurálu. |
| `missingWarn` | `boolean` | `true` | `console.warn` v prohlížeči pro chybějící klíč, pouze při vývoji. |
| `missingHandler` | `(locale, key, routeName) => void` | — | Volá se místo varování. |
| `numberFormats` | `Record<locale, Record<name, Intl.NumberFormatOptions>>` | — | Pojmenované formáty: `tn(9.5, 'currency')`. |
| `datetimeFormats` | `Record<locale, Record<name, Intl.DateTimeFormatOptions>>` | — | Pojmenované formáty: `td(date, 'short')`. |
| `timeZone` | `string` | zóna běhového prostředí | Zóna IANA pro data v `td`; neovlivňuje `tdr`. Nastavte ji, aby server i prohlížeč vykreslily stejné datum. |
| `now` | `() => number` | `Date.now` | Hodiny pro `tdr`. Předejte hydrataci čas serveru, aby obě strany vykreslily stejný text. |
| `localeIso` | `Record<code, string>` | — | Tag BCP 47 používaný pro pravidla plurálu (`ua` → `uk-UA`). React, Preact a Solid ho berou z `iso` v `locales` providera. |

Slovníky sídlí v `i18n.storage.translations`, což je `Map` s klíči `locale:route` (`en:index`, `en:about`).

Klíč se hledá ve slovníku aktuální routy, pak v kořenovém slovníku, nejprve pro `locale`, potom pro `fallbackLocale`. Chybějící klíč vrací samotný klíč (nebo `defaultValue`, kterou předáte).

```ts
i18n.addTranslations('en', { nav: { home: 'Home' } }) // root, deep-merged
i18n.addRouteTranslations('en', 'about', { title: 'About us' }) // route chunk
i18n.addTranslations('en', { nav: { home: 'Start' } }, false) // replace instead of merge
i18n.setRoute('about')
i18n.t('title') // 'About us'
i18n.t('nav.home') // 'Start' (root key, still visible on the route)
```

### Překlad a formátování {#translate-and-format}

| Metoda | Vrací |
| --- | --- |
| `t(key, params?, defaultValue?, routeName?)` | Hodnotu (řetězec, číslo, objekt) s interpolovanými `{param}`. |
| `ts(...)` | Totéž co `t`, jako řetězec. |
| `tc(key, count \| params, defaultValue?)` | Tvar plurálu. |
| `tn(value, options \| name)` | `Intl.NumberFormat` v aktivním locale. |
| `td(value, options \| name)` | `Intl.DateTimeFormat`. |
| `tdr(value, options?)` | Relativní čas (`3 days ago`). |
| `has(key, routeName?)` | `true`, pokud aktivní locale klíč obsahuje (slovník routy nebo kořenový; fallback se nekontroluje). |

`defaultPlural` rozdělí hodnotu podle `|` a vybere tvar na indexu `count`, omezeno na poslední tvar; záporný, desetinný nebo `NaN` počet vybere poslední tvar.

Vlastní `plural` dostává `(key, count, params, locale, getter)`. Hodnotu čtěte přes `getter(key)`; klíč nerozdělujte:

```ts
import type { PluralFunc } from '@i18n-micro/vue'

const plural: PluralFunc = (key, count, params, _locale, getter) => {
  const value = getter(key)
  if (typeof value !== 'string') return null
  const forms = value.split('|').map((form) => form.trim())
  return (count === 1 ? forms[0] : forms[1] ?? forms[0])!.replace('{count}', String(count))
}
```

## Adaptér routeru {#router-adapter}

Balíčky pro SPA nezávisejí na žádném routeru. Adaptér routeru (`I18nRoutingStrategy`) jim říká, jak číst aktuální cestu, navigovat a sestavit lokalizovanou cestu. Vestavěné adaptéry přidávají prefix každému locale kromě `defaultLocale` (`/about`, `/de/about`).

| Člen | Povinný | Používá |
| --- | --- | --- |
| `getCurrentPath(): string` | ano | kontrola aktivního odkazu (podle stránky, query a hash se nepočítají), `switchLocale` (zachovává je) |
| `push({ path }): void` | ano | `switchLocale`, `<I18nLink>` bez `linkComponent`, `<I18nSwitcher>` |
| `replace({ path }): void` | ano | — |
| `resolvePath(to, locale)` | ne | `localePath`, `localeRoute`, `<I18nLink>`; bez něj se cesty vracejí tak, jak jsou |
| `linkComponent` | ne | `<I18nLink>` ho vykreslí (např. `RouterLink`) místo `<a>` |
| `getRoute()` | ne | `{ fullPath, query }` pro SEO pomocné funkce |

`push` a `replace` jsou ve Vue, Reactu, Preactu a Solidu povinné. Astro má vlastní serverový adaptér s volitelnými `push`/`replace` (viz [Astro](/cs/integrations/astro-package#router-adapter)).

Minimální adaptér pro libovolný router založený na history:

```ts
import type { I18nRoutingStrategy } from '@i18n-micro/react'

const locales = ['en', 'de']
const stripLocale = (path: string) => path.replace(/^\/(en|de)(?=\/|$)/, '') || '/'

export const historyAdapter: I18nRoutingStrategy = {
  getCurrentPath: () => window.location.pathname + window.location.search + window.location.hash,
  push: ({ path }) => window.history.pushState({}, '', path),
  replace: ({ path }) => window.history.replaceState({}, '', path),
  resolvePath: (to, locale) => {
    const path = stripLocale(typeof to === 'string' ? to : to.path || '/')
    return locale === 'en' ? path : `/${locale}${path === '/' ? '' : path}`
  },
}
```

## Komponenty {#components}

Vue, React, Preact a Solid dodávají stejné čtyři komponenty. Jejich props se shodují; React, Preact a Solid předávají ostatní props dál kořenovému elementu.

### `<I18nT>` {#&lt;i18nt&gt;}

| Prop | Typ | Poznámky |
| --- | --- | --- |
| `keypath` | `string` | povinný |
| `params` | `object` | hodnoty pro interpolaci |
| `plural` | `number \| string` | vykreslí `tc(keypath, count)` |
| `number` | `number \| string` | předá `tn(number)` jako `{number}` |
| `date` | `Date \| string \| number` | předá `td(date)` jako `{date}` |
| `relativeDate` | `Date \| string \| number` | předá `tdr(relativeDate)` jako `{relativeDate}` |
| `tag` | `string` | obalový element, výchozí `span` |
| `html` | `boolean` | vykreslí překlad jako HTML; musí být důvěryhodný, parametry se escapují |
| `defaultValue` | `string` | zastupuje chybějící klíč a vykreslí se holý, když `hideIfEmpty` skryje prázdnou hodnotu |
| `hideIfEmpty` | `boolean` | pro prázdný překlad nevykreslí nic |
| `customPluralRule` | `PluralFunc` | pravidlo plurálu pro tento element |

Uplatní se jen jeden formátovací prop, kontrolované v tomto pořadí: `number`, `date`, `relativeDate`, `plural`.

#### Formátovaný text {#rich-text}

`{placeholder}` může obsahovat element. Ve Vue je to pojmenovaný slot; v Reactu, Preactu a Solidu prop `components` předává podle názvu elementy nebo funkce, které element vracejí. V obou případech má přednost před parametrem stejného názvu, funguje v každé větvi a přežije i locale, které placeholdery přeuspořádá.

```tsx
// { "terms": "I accept the {link} of {company}" }
<I18nT keypath="terms" params={{ company: 'ACME' }} components={{ link: <a href="/terms">terms</a> }} />
```

V Solidu předejte funkci, když se placeholder opakuje: jeden uzel může stát jen na jednom místě. `children` nahrazují text; jako funkce dostanou `{ translation }`, podobně jako výchozí slot ve Vue. `html` všechno toto ignoruje.

### `<I18nLink>` {#&lt;i18nlink&gt;}

| Prop | Typ | Poznámky |
| --- | --- | --- |
| `to` | `string \| { path }` | lokalizováno přes `resolvePath` adaptéru |
| `activeStyle` | objekt stylu | na aktuální stránce sloučen přes `style`; React, Preact a Solid ho uplatní i na sekci výše |
| `localeRoute` | funkce | přepisuje `resolvePath` pro tento odkaz |

Externí URL (`https://`, `mailto:`, `tel:`) se vykreslí jako `<a target="_blank" rel="noopener noreferrer">`; vaše vlastní `target` nebo `rel` mají přednost. `onClick` se spustí vždy. Kliknutí s modifikátorem, jiným tlačítkem myši nebo s `target` zůstává na prohlížeči.

### `<I18nSwitcher>` {#&lt;i18nswitcher&gt;}

Rozbalovací seznam povolených locale (locale s `disabled: true` jsou skrytá) s vloženými výchozími styly. Jeho položky jsou odkazy s `lang`, `hreflang` a `dir` z daného locale. Ve výchozím stavu kliknutí na položku nastaví locale a zavolá `push` adaptéru s lokalizovanou aktuální cestou; prop `switchLocale` tuto akci nahrazuje. S `localeRoute` a bez routeru prohlížeč odkaz následuje. Klávesa Escape nebo kliknutí mimo seznam ho zavře.

| Prop | Poznámky |
| --- | --- |
| `locales`, `currentLocale`, `getLocaleName` | přepisují poskytnuté hodnoty |
| `switchLocale(code)` | nahrazuje vestavěné přepnutí |
| `localeRoute` | nahrazuje `resolvePath` |
| `customLabels` | `{ de: 'DE' }` |
| `customWrapperStyle`, `customButtonStyle`, `customDropdownStyle`, `customItemStyle`, `customLinkStyle`, `customActiveLinkStyle`, `customDisabledLinkStyle`, `customIconStyle` | přepsání stylů |

### `<I18nGroup>` {#&lt;i18ngroup&gt;}

`<div class="i18n-group">`, který svým potomkům předává `t` s prefixem. **Nepřidává** prefix volání `<I18nT>` ani `t()` uvnitř; prefix má jen `t`, které předává dál.

| Prop | Poznámky |
| --- | --- |
| `prefix` | povinný, např. `'profile'` |
| `groupClass` | další třída na obalu |

`t` s prefixem přichází ve Vue přes scoped slot (`v-slot="{ t }"`) a v Reactu, Preactu a Solidu přes potomka typu render-prop (`{({ t }) => …}`).

## Typované klíče {#typed-keys}

`t()` přijímá libovolný řetězec. Chcete-li automatické doplňování svých klíčů, vygenerujte deklaraci pomocí [generátoru typů](/cs/integrations/types-generator). Klíče jsou navrhovány, nikoli vynucovány, a parametry typované nejsou.

## Srovnání s modulem pro Nuxt {#compared-with-the-nuxt-module}

Balíčky nemají routování založené na souborech, serverový middleware ani loader překladů: sami rozhodujete, kdy načíst JSON (`import`, `fetch` nebo `@i18n-micro/node` na serveru) a který adaptér routeru použít. Detekce locale, SEO meta a generování rout jsou funkce Nuxtu; Astro má vlastní middleware pro detekci a `useLocaleHead` pro SEO.
