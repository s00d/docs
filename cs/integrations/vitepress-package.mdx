`@i18n-micro/vitepress` přidává do webu ve VitePressu runtime slovníky: `$t` a `<I18nT>` uvnitř markdownu, pomocné funkce pro cesty a SEO tagy, postavené na [`@i18n-micro/vue`](/cs/integrations/vue-package). Použijte ho, když se tytéž řetězce UI objevují na mnoha stránkách a nechcete je duplikovat pro každou lokalizaci. Lokalizace se řídí vlastními lokalizacemi cest VitePressu (`/`, `/fr/`).

## Kdy ho použít {#when-to-use-it}

| Potřeba | Řešení |
|------|----------|
| Duplicitní `.md`, prefixy URL | `locales` ve VitePressu |
| Runtime `$t` / komponenty / synchronizace cest / SEO head | `@i18n-micro/vitepress` |
| Popisky prvků výchozího tématu (`docFooter`, UI vyhledávání) | Vlastní `themeConfig` pro každou lokalizaci |

<Tip>

**Playground** — [`packages/vitepress/playground`](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/vitepress/playground) — `pnpm -C packages/vitepress/playground dev`

</Tip>

## Instalace {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vitepress
```

```bash npm
npm install @i18n-micro/vitepress
```

```bash yarn
yarn add @i18n-micro/vitepress
```

</CodeGroup>

Peer závislosti: `vitepress` `>=1.0.0 || >=2.0.0-alpha.0`, `vue` `^3.3.0`. Skripty pro Node používají `@i18n-micro/node`, který se nainstaluje s balíčkem a je znovu exportován přes `/node`. Publikované typy vyžadují Vue 3.5.5 nebo novější se `skipLibCheck: false`; se `skipLibCheck: true`, což je obvyklé nastavení šablon, se zkompilují i starší verze.

## Nastavení {#setup}

```
locales/en.json
locales/fr.json
locales/pages/guide/demo/en.json   # optional page-scoped
locales/pages/guide/demo/fr.json
```

Soubory stránek se mapují na názvy tras stejně jako v Nuxtu/Astru (`guide/demo` → `guide-demo`).

### 1. Konfigurace — `@i18n-micro/vitepress/config` {#1-config-—-@i18n-micro/vitepress/config}

```ts
// .vitepress/config.mts
import { defineConfig } from 'vitepress'
import { withI18n, buildVitePressLocales } from '@i18n-micro/vitepress/config'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English', og: 'en_US' },
  { code: 'fr', iso: 'fr-FR', displayName: 'Français', og: 'fr_FR' },
]
const defaultLocale = 'en'

export default defineConfig(
  withI18n(
    {
      locales: buildVitePressLocales(locales, defaultLocale),
      // themeConfig.i18nRouting is injected automatically
    },
    {
      locale: defaultLocale,
      defaultLocale,
      locales,
      translationDir: 'locales',
      metaBaseUrl: 'https://example.com', // optional SEO head
    },
  ),
)
```

### 2. Téma — `@i18n-micro/vitepress/theme` {#2-theme-—-@i18n-micro/vitepress/theme}

```ts
// .vitepress/theme/index.ts
import DefaultTheme from 'vitepress/theme'
import { defineI18nTheme } from '@i18n-micro/vitepress/theme'

export default defineI18nTheme(DefaultTheme)
```

Počáteční lokalizace se před instalací převezme z aktuální cesty (na `/fr/…` žádné probliknutí výchozí lokalizace).

### Pokročilé: ruční `createI18n` {#advanced-manual-createi18n}

Jedna továrna pro klienta: Vue plugin + metody pro cesty + `enhanceApp` (žádné samostatné exporty pomocných funkcí routeru).

```ts
import { createI18n, messagesFromGlob } from '@i18n-micro/vitepress'

const i18n = createI18n({
  locale: 'en',
  defaultLocale: 'en',
  locales: [{ code: 'en' }, { code: 'fr' }],
  messages: messagesFromGlob(import.meta.glob('../../locales/*.json', { eager: true })),
})

i18n.localizePath('/guide', 'fr')
// in theme enhanceApp:
i18n.enhanceApp({ app, router })
```

### Skripty pro Node — `@i18n-micro/vitepress/node` {#node-scripts-—-@i18n-micro/vitepress/node}

Používá `createI18n` / `loadTranslations` z `@i18n-micro/node` (stejně jako Astro a CLI) a pak připojí metody pro cesty VitePressu pomocí `BaseI18n.extend`:

```ts
import { createI18n } from '@i18n-micro/vitepress/node'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  translationDir: './locales',
  locales: ['en', 'fr'],
  defaultLocale: 'en',
})
await i18n.loadTranslations()
i18n.t('cta.readMore')
i18n.localizePath('/guide', 'fr')
```

Čistý Node bez cest: `import { createI18n } from '@i18n-micro/node'`.

## Překlady ve stránce {#in-page-translations}

Každý markdownový soubor VitePressu je Vue SFC.

### Globální komponenty a `$t` (doporučeno v markdownu) {#global-components-and-$t-recommended-in-markdown}

`createI18n` / `defineI18nTheme` instalují `@i18n-micro/vue`, který registruje `I18nT` / `I18nLink` / `I18nGroup` / `I18nSwitcher` a `$t` / `$tc` / `$ts`.

```md
{{ $t('cta.readMore') }}

<I18nT keypath="greeting" :params="{ name: 'VitePress' }" />

<I18nLink to="/guide/demo">Demo</I18nLink>
```

### `useI18n` v `<script setup>` {#usei18n-in-<script-setup>}

```md
<script setup>
import { useI18n } from '@i18n-micro/vitepress'
const { t, tc, locale, localePath, switchLocale } = useI18n()
</script>

# {{ t('section.title') }}
```

## Rozbalovací nabídka jazyků {#language-dropdown}

Když má `locales` více než jednu položku, VitePress zobrazí vlastní jazykové menu (`VPNavBarTranslations`). `withI18n` propojí `themeConfig.i18nRouting`, takže glóbus odpovídá `<I18nSwitcher>` / pomocným funkcím pro cesty.

`<I18nSwitcher>` používejte jen ve vlastních layoutech, ne vedle výchozího glóbu.

## Poznámky k SSR {#ssr-notes}

- Lokalizace při prerenderu pochází z cesty URL, ne z cookies.
- Kód tématu nesmí při importu sahat na `window`.
- Importujte `defineI18nTheme` z `/theme`, aby vyhodnocení konfigurace v Node nikdy nenačetlo `virtual:i18n-micro/*`.

## Přehled API {#api-surface}

| Export | Role |
|--------|------|
| `createI18n` (`.`) | Klient: Vue plugin + metody pro cesty + `enhanceApp` |
| `getLocaleFromPath` / `stripSiteBase` / `routeNameFromPath` (`.`) | Ruční synchronizace lokalizace při `syncWithVitePress: false` |
| `createI18n` (`/node`) | Node: `@i18n-micro/node` + metody pro cesty |
| `defineI18nTheme` (`/theme`) | Téma bez boilerplatu |
| `withI18n` (`/config`) | Konfigurace + virtuální moduly + volitelné SEO |
| `buildVitePressLocales` (`/config`) | Sestaví `locales` pro VitePress z `Locale[]` |
| `buildVitePressLocaleHead` (`/config`) | Ruční SEO head (používá ho i `metaBaseUrl`) |
| `messagesFromGlob` | Volitelný převod glob → mapa zpráv pro `createI18n` |
| `useI18n` / `I18nT` / … | Znovu exportováno z `@i18n-micro/vue` |
| `BaseI18n.extend` (`@i18n-micro/core`) | Připojí vlastní metody k libovolné instanci i18n |

## Weby ve stylu OpenAPI (integrační zámky) {#openapi-style-sites-integration-locks}

Regresní sada: `packages/vitepress/tests/integration-openapi.test.ts` (hluboké cesty, `base=/openapi_docs/`, vypnutá synchronizace + ruční lokalizace, generátory v Node, SEO).

| Vzor | Co dělat |
|---------|---------|
| Hluboké stránky `/…/{spec}/{op}`, jen kořenový UI JSON | Dejte přednost výchozímu `syncWithVitePress: true` (ponechá `setRoute('index')`, když chybí slovník stránky) **nebo** `syncWithVitePress: false` + `getLocaleFromPath` |
| Nikdy nevolejte `setRoute(deepName)` bez slovníků stránek | Kořenové UI klíče zmizí až do `setRoute('index')` |
| Generátory / `getTranslation` | `createI18n` z `/node` + `await loadTranslations()` + `i18n.t(key)` (nastavte `i18n.locale`) |
| Vlastní canonical v `transformPageData` | Předejte `meta: false` do `withI18n` (zabráníte zdvojeným tagům) |
| SEO balíčku s base webu | `metaBaseUrl` + `base` VitePressu → absolutní URL obsahují base |
| Přejmenování ze starších buildů balíčku | `withI18nMicro` → `withI18n`, `createVitePressI18n` → `createI18n`, `loadMessages` → `createI18n` z node |
