`@i18n-micro/node` je instance [runtime](/cs/integrations/runtime-package) doplněná o loader, který čte složku s překlady z disku. Použijte ho v serveru Express nebo Fastify, v CLI, v generátoru e-mailů či PDF nebo v jakémkoli skriptu, který potřebuje stejné JSON soubory jako vaše Nuxt aplikace. Soubory načtete jednou a překládáte pro každý požadavek, aniž by požadavky sdílely měnitelný stav.

## Instalace {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/node @i18n-micro/utils
```

```bash npm
npm install @i18n-micro/node @i18n-micro/utils
```

```bash yarn
yarn add @i18n-micro/node @i18n-micro/utils
```

</CodeGroup>

Žádné peer závislosti; Node.js `>=20`. `@i18n-micro/utils` je potřeba jen pro níže uvedený helper `Accept-Language`.

## Nastavení {#setup}

Loader čte [strukturu složek Nuxtu](/cs/guide/translations): `locales/en.json` je kořenový slovník, `locales/pages/blog/post/en.json` patří k routě `blog-post`.

```ts
import { createI18n } from '@i18n-micro/node'

const i18n = createI18n({ locale: 'en', fallbackLocale: 'en', translationDir: './locales' })
await i18n.loadTranslations()

i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.t('title', undefined, undefined, 'blog-post') // from locales/pages/blog/post/en.json
```

Možnosti jsou stejné jako u runtime (viz [instance](/cs/integrations/overview#the-instance)) plus `translationDir` a `disablePageLocales` (soubory `pages/**` se berou jako kořenové slovníky). `i18n.reload()` vymaže všechny slovníky a znovu načte složku, což se hodí pro sledování souborů ve vývoji.

`loadTranslations(dir, disablePageLocales?)` se exportuje i samostatně a vrací `{ root, routes }`:

```ts
import { loadTranslations } from '@i18n-micro/node'

const { root, routes } = await loadTranslations('./locales')
// root:   { en: {...}, de: {...} }
// routes: { 'blog-post': { en: {...}, de: {...} } }
```

## Pro každý požadavek {#per-request}

Instance drží jedno locale a jednu routu. Přepínání `i18n.locale` na sdílené instanci uvnitř handleru požadavku vede k souběhu se souběžnými požadavky. `run` dá požadavku vlastní:

```ts
const i18n = createI18n({ locale: 'en', fallbackLocale: 'en', translationDir: './locales' })
await i18n.loadTranslations()

// `() => next()`: `run` hands its callback the fork, and Express reads an argument of `next` as an error
app.use((req, res, next) => i18n.run(pickLocale(req), () => next()))

app.get('/', (req, res) => {
  res.send(i18n.t('greeting')) // the request's locale, in everything it awaits
})
```

Uvnitř `run` sdílená instance čte a nastavuje locale a routu požadavku (`AsyncLocalStorage`); fork začíná na aktuální routě a `i18n.setRoute(...)` uvnitř callbacku změní routu daného požadavku. Callback dostane také fork požadavku: slovníky zapsané do něj zůstanou v požadavku, slovníky zapsané do sdílené instance se dostanou ke všem.

Bez `AsyncLocalStorage` vrací `i18n.fork(locale)` stejný druh instance, kterou můžete předávat dál.

`reload()` znovu načte adresář; staré slovníky odpovídají, dokud nejsou načtené nové.

## Výběr locale {#pick-the-locale}

`detectLocaleFromAcceptLanguage(header, locales)` respektuje váhy `q` a přiřadí `de-DE` k locale `de` (a `de` k `de-DE`). Když nic neodpovídá, vrátí `null`.

```ts
import express from 'express'
import { detectLocaleFromAcceptLanguage } from '@i18n-micro/utils/accept-language'

const app = express()

app.get('/hello', (req, res) => {
  const locale = detectLocaleFromAcceptLanguage(req.headers['accept-language'], locales) ?? 'en'
  const i18n = byLocale.get(locale)!
  res.json({ message: i18n.t('greeting', { name: 'Ada' }) })
})
```

Pro kombinaci prefixu URL, cookie a hlavičky uplatní `resolveLocale({ defaultLocale, validLocales, url, cookie, acceptLanguage, autoDetectLanguage: true })` z `@i18n-micro/utils/resolve-locale` stejné pořadí priorit jako modul: URL, pak cookie, pak `Accept-Language`, pak výchozí. Neplatné hodnoty se přeskočí.

V Nuxt aplikaci tento balíček na serveru nepotřebujete: použijte [serverové překlady](/cs/guide/server-side-translations) modulu.

## API {#api}

| Export | Poznámky |
| --- | --- |
| `createI18n(options)`, `I18n` | runtime instance + `translationDir`, `loadTranslations(dir?)`, `reload()` |
| `loadTranslations(dir, disablePageLocales?)` | `{ root, routes }` |
| `loadRootTranslations(dir, disablePageLocales?)` | pouze `root` |
| `FormatService`, `interpolate` | z core |
| Typy: `I18nOptions`, `LoadedTranslations`, `Translations`, `Locale`, `PluralFunc`, `Params` | |

Metody instance jsou uvedené na stránce [Runtime](/cs/integrations/runtime-package#api). Úplné signatury: [reference balíčku](/cs/api/packages/node).
