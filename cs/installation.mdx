## Požadavky

- **Node.js**: 18 nebo novější.
- **Nuxt**: 3.x nebo 4.x.

Modul podporuje jak rozvržení projektu Nuxt 3 (`pages/**/*.vue`), tak rozvržení Nuxt 4 (`app/pages/**/*.vue`). Překlady dle konvence žijí v kořenu projektu (`locales/`), i když používáte adresář `app/` z Nuxt 4.

## Instalace Nuxt modulu

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Zaregistrujte jej v `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Kompletní návod najdete v [Rychlém startu](/quickstart), všechny volby pak v [Referenci konfigurace](/guides/configuration).

## Rozvržení projektu

Modul ve výchozím stavu očekává:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Kořenové soubory se v době buildu slučují do každého souboru specifického pro stránku. Soubory specifické pro stránku se při chybějícím obsahu automaticky vytváří během `nuxt dev`.

## Rozvržení Nuxt 4

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Chcete-li překlady kolokovat pod `app/`, nastavte `translationDir: 'app/locales'`.

## TypeScript

Modul generuje ambient typy pro `useI18n`, `$t` a související pomocníky na základě souborů výchozího locale. Toto je ve výchozím stavu zapnuto (`types: true`).

Pro silnější typování klíčů překladů se podívejte na [`@i18n-micro/types-generator`](/integrations/types-generator).
