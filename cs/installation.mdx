## Požadavky

- **Node.js**: 18 nebo novější.
- **Nuxt**: 3.x nebo 4.x.

Modul podporuje jak rozložení projektu Nuxt 3 (`pages/**/*.vue`), tak rozložení Nuxt 4 (`app/pages/**/*.vue`). Překlady jsou dle konvence umístěny v kořenovém adresáři projektu (`locales/`), i když používáte adresář `app/` v Nuxt 4.

## Instalace Nuxt modulu

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Zaregistrujte jej v `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Kompletní návod najdete v [Rychlém startu](/quickstart) nebo v [Referenční příručce konfigurace](/guides/configuration) pro všechny volby.

## Rozložení projektu

Ve výchozím nastavení modul očekává:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Soubory na kořenové úrovni se při buildu slučují do každého souboru specifického pro stránku. Soubory specifické pro stránku se automaticky vytvoří, pokud chybí, během `nuxt dev`.

## Rozložení Nuxt 4

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Chcete-li překlady kolokovat pod `app/`, nastavte `translationDir: 'app/locales'`.

## TypeScript

Modul generuje ambientní typy pro `useI18n`, `$t` a související pomocníky na základě vašich souborů výchozí locale. Toto je ve výchozím nastavení zapnuto (`types: true`).

Pro silnější typování překladových klíčů viz [`@i18n-micro/types-generator`](/integrations/types-generator).
