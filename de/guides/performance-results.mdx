### Beschreibung

Vergleicht **plain Nuxt** (Basislinie ohne i18n-Modul), **i18n-micro** und **`@nuxtjs/i18n` v10.6** unter einem gemeinsamen Wörterbuchprofil.

Fokus: Build-Zeit, Peak RSS, deploybares Verhältnis **Code vs. Übersetzungen vs. Gesamt** und Serververhalten unter Artillery und Autocannon.

### Anmerkungen zur Methodik

- Metriken sind **Mittelwerte aus 3 aufeinanderfolgenden Läufen je Fixture** (Fixture A ×3, dann B ×3, dann C ×3, nicht verschachtelt).
- Zu den **Übersetzungen** zählen Locale-JSON unter `locales/`, `_locales/` und `translations/`, alles unter `chunks/raw/` sowie zugehörige Locale-Chunks. Ältere Reports, die für `@nuxtjs/i18n` „translations: 0 B“ und eine riesige „code“-Spalte zeigten, haben Message-Chunks als App-Code gewertet.
- **plain-nuxt** liefert dasselbe Blattvolumen als statisches `public/translations` JSON (nicht als statische JS-Imports). Unter Artillery ist diese Basislinie I/O-lastig. Das ist kein „i18n-Overhead“, sondern der Preis dafür, pro Request großes JSON zu holen.

### Läufe

Alle Metriken unten sind **Mittelwerte aus 3 Läufen**.

### Fixture-Profil

| Stellrad | Wert |
|------|-------|
| Locales | **4** (`en`, `de`, `ru`, `fr`) |
| Seiten | **2** (`index`, `page`) |
| Index-Baum | Tiefe **5**, Verzweigung **7** → **16.807** Blattschlüssel je Locale |
| Sekundäre Seiten | Tiefe **5**, Verzweigung **6** → **7.776** Blattschlüssel je Seite je Locale |
| Ziel | Standard-CLI-Profil (`--locales 4 --keys 10000`); Stellräder hochdrehen für Regressions-Radar-Lasten |

Die Wörterbücher kommen aus `test/fixtures/perf-shared/runtime.json` (vom CLI erzeugt), damit alle drei Fixtures gleichgerichtet bleiben.

- **Max / Avg CPU**: 207.10% / 166.29%
- **Max / Avg Memory**: 810.26 MB / 585.14 MB

## Zusammenfassung Build-Performance (Mittelwert aus 3 Läufen)

| Projekt | Build Time | Code Bundle | Translations | Total |
|---------|------------|-------------|--------------|-------|
| **plain-nuxt** (baseline) | 5.32s | 1.53 MB | 6.8 MB | 8.33 MB |

## Hinweise

- Gemeinsames Profil: 4 Locales × 2 Seiten × ~16,8k Index-Blätter.
- Artillery: 6s Warm-up @6 VU/s + 60s Hauptlauf @60 VU/s. Autocannon: 10 Verbindungen × 10s.
- Erneut ausführen: `pnpm test:performance` oder `pnpm -C scripts cli performance --locales N --keys K --only all|micro|i18n|plain --runs N`.
