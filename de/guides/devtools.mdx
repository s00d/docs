# 🛠️ DevTools in `nuxt-i18n-micro`

## Vue DevTools (Browser-Erweiterung)

Im Entwicklungsmodus kann das Modul einen **Vue-DevTools**-Custom-Inspector und eine Timeline über `@vue/devtools-api` registrieren. Das ist unabhängig vom Nuxt-DevTools-Tab unten.

| Tool | Am besten für |
|------|----------|
| **Vue DevTools** | Live-Locale, In-Memory-Übersetzungscache, `$t`-Timeline (`debug: true`), Ereignisse für fehlende Schlüssel |
| **Nuxt-DevTools-Tab** | Bearbeiten der JSON-Dateien auf der Platte, Konfigurationsüberblick, Import und Export |

Das Vue-DevTools-Plugin wird nur bei `nuxt dev` registriert (nicht in Production-Builds). Dev-only Bridge-Status im Haupt-Plugin wird per Dead-Code-Elimination über `import.meta.dev` entfernt.

Die Browser-Integration deaktivieren, den Nuxt-Tab aber behalten:

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

Ausführliche `$t`-Timeline-Ereignisse setzen `debug: true` voraus.

## 📖 Was ist Nuxt DevTools?

DevTools ist ein leistungsstarker Entwicklungshelfer, nahtlos integriert in das Modul `nuxt-i18n-micro`. Es bietet eine intuitive Oberfläche zum Verwalten von Lokalisierungs- und Übersetzungsaufgaben und macht deinen Workflow schneller und effizienter. Nuxt DevTools ist auf Bequemlichkeit ausgerichtet und schlägt die Brücke zwischen Coding und Runtime-Verwaltung.

## 🌟 Wichtige DevTools-Funktionen in `nuxt-i18n-micro`

### 1. **Locale-Management**

Locales in deiner Anwendung mühelos durchsuchen, auswählen und verwalten. Egal ob du mit einer einzigen Sprache oder mehreren arbeitest, DevTools bündelt alle Lokalisierungseinstellungen zentral.

### 2. **Übersetzungen bearbeiten**

Bearbeite Übersetzungsdateien direkt über einen integrierten JSON-Editor. So brauchst du keine externen Tools und kannst Änderungen in Echtzeit vornehmen, ohne deinen Workflow zu unterbrechen.

### 3. **Dateien importieren und exportieren**

Erleichtert das Verwalten von Übersetzungsdateien:

- **Export**: Übersetzungen als JSON-Datei zum Backup oder zur externen Nutzung speichern.
- **Import**: Aktualisierte Übersetzungsdateien ins Projekt laden, damit Inhalte aktuell bleiben.

### 4. **Echtzeit-Vorschau**

Änderungen sofort in der Entwicklungsumgebung sehen. So stellst du sicher, dass Übersetzungen und Konfigurationen vor dem Livegang stimmen.

### 5. **Nahtlose Nuxt-Integration**

DevTools funktioniert nativ mit `nuxt-i18n-micro` und erweitert dessen Möglichkeiten ohne zusätzliche Einrichtung. Es passt sich deinen Lokalisierungsanforderungen an und bleibt Nuxts modularer, flexibler Struktur treu.

## 🛠️ Warum DevTools verwenden?

Nuxt DevTools ist eine unverzichtbare Ergänzung für Projekte mit Lokalisierung. Es hilft Entwicklerinnen und Entwicklern, indem es:

- **Zeit spart**: Automatisiert wiederkehrende Aufgaben wie Dateiverwaltung und Formatvalidierung.
- **Fehler reduziert**: Bietet eine sichere, intuitive Umgebung zum Bearbeiten von Übersetzungen.
- **Zusammenarbeit verbessert**: Ermöglicht auch Nicht-Entwicklerinnen, Übersetzungen einfach zu verwalten.
- **Workflows strafft**: Bündelt mehrere Lokalisierungsaufgaben in einer einzigen Oberfläche.
