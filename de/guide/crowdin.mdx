title: "Crowdin"

---

[Crowdin](https://crowdin.com/) ist eine Übersetzungsplattform: Sie laden die Dateien der Standard-Locale hoch, Übersetzer arbeiten in Crowdin, und Sie laden die übrigen Locales wieder herunter. Das Modul liest einfache JSON-Dateien, daher benötigt die Crowdin CLI nur eine `crowdin.yml`, die `locales/` und `locales/pages/` korrekt abbildet. Es sind keine Änderungen an den Moduleinstellungen nötig.

## crowdin.yml konfigurieren {#configure-crowdin-yml}

```yml
# crowdin.yml
project_id_env: CROWDIN_PROJECT_ID
api_token_env: CROWDIN_PERSONAL_TOKEN
base_path: ./locales
preserve_hierarchy: true

files:
  - source: /en.json
    translation: /%two_letters_code%.json
  - source: /pages/**/en.json
    translation: /pages/**/%two_letters_code%.json
```

- `en` ist Ihre Standard-Locale; ihre Dateien sind die Quellen.
- `project_id_env` / `api_token_env` lesen ID und Token aus Umgebungsvariablen, sodass kein Geheimnis committet wird.
- `preserve_hierarchy: true` behält die Ordner `pages/<page>/` unverändert bei.
- Der Name der übersetzten Datei muss dem `code` der Locale in `nuxt.config.ts` entsprechen. `%two_letters_code%` passt zu Codes wie `de`; für Codes wie `pt-BR` verwenden Sie `%locale%` oder ordnen die Crowdin-Codes Ihren eigenen über `languages_mapping` zu.

## Hochladen und herunterladen {#upload-and-download}

```bash
npm install -g @crowdin/cli

export CROWDIN_PROJECT_ID=123456
export CROWDIN_PERSONAL_TOKEN=...   # from Crowdin account settings

crowdin upload sources   # push locales/en.json and locales/pages/**/en.json
crowdin download         # write locales/de.json, locales/pages/**/de.json, ...
```

Führen Sie beides in der CI aus, um die Dateien aktuell zu halten. Heruntergeladene Dateien landen wie von Hand bearbeitete in Ihrem Repository; der nächste Build oder Dev-Reload übernimmt sie.

## Vor dem Hochladen {#before-uploading}

Bereinigen Sie zuerst die Quellen, damit Übersetzer nicht an toten Schlüsseln arbeiten: [`i18n-micro clean`](/de/api/cli#clean) entfernt ungenutzte Schlüssel, [`i18n-micro check`](/de/api/cli#check) meldet Lücken nach einem Download. Die CLI hat keine eigene Crowdin-Integration: Diese Seite beschreibt den unterstützten Weg.
