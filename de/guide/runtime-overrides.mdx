---
title: "Laufzeit-Overrides"
description: "Ändern Sie die Standard-Locale, die Fallback-Locale oder deaktivierte Locales pro Instanz eines Builds, mit Umgebungsvariablen oder runtimeConfig."
---

Mit Laufzeit-Overrides kann ein einziges Build-Artefakt pro Umgebung oder Mandant mit unterschiedlichen Locale-Einstellungen laufen, ohne neu zu bauen. Sie können die Standard-Locale, die Fallback-Locale und die deaktivierten Locales ändern. Routing, Redirects, Rendering und Server-Helfer verwenden die überschriebenen Werte, ebenso der Browser auf einer serverseitig gerenderten Seite.

## Overrides mit Umgebungsvariablen setzen {#set-overrides-with-environment-variables}

```bash
NUXT_I18N_DEFAULT_LOCALE=de \
NUXT_I18N_FALLBACK_LOCALE=en \
NUXT_I18N_DISABLED_LOCALES=fr,it \
node .output/server/index.mjs
```

| Variable | Alias |
| --- | --- |
| `NUXT_I18N_DEFAULT_LOCALE` | `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE` |
| `NUXT_I18N_FALLBACK_LOCALE` | `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE` |
| `NUXT_I18N_DISABLED_LOCALES` (kommagetrennt) | `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES` |

Der Server liest sie einmalig beim Start; starten Sie neu, um eine Änderung anzuwenden. Auf einer serverseitig gerenderten Seite erhält der Browser die aufgelösten Werte vom Server. Mit `ssr: false` gibt es kein Server-Rendering und der Browser hat keine Umgebung: Dort gilt nur `runtimeConfig.public.i18nRuntime`, und der Browser protokolliert die unten genannten Warnungen.

## Overrides in runtimeConfig setzen {#set-overrides-in-runtimeconfig}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

Ein in `runtimeConfig.public.i18nRuntime` gesetzter Wert hat Vorrang vor der `NUXT_I18N_*`-Variable für dasselbe Feld.

Nicht zu verwechseln mit der Build-Zeit-Variable `DEFAULT_LOCALE`, die `defaultLocale` während des Builds ersetzt und keine Laufzeitunterstützung benötigt.

## Was sich ändern lässt und was nicht {#what-can-and-cannot-change}

| Einstellung | Zur Laufzeit |
| --- | --- |
| `defaultLocale` | Ja bei `prefix` und `no_prefix`. Bei `prefix_except_default` und `prefix_and_default` ist sie beim Build festgelegt (ihre Seiten sind die Routen ohne Präfix); ein Override wird mit einer Warnung ignoriert. |
| `fallbackLocale` | Ja. |
| `disabledLocales` | Ergänzt die beim Build deaktivierten Locales; aktiviert nie eine wieder. Der Build-Standard kann bei `prefix_except_default` / `prefix_and_default` nicht deaktiviert werden. |
| `strategy` | Nein. Eine Laufzeit-Strategie wird mit einer Warnung ignoriert; bauen Sie ein Artefakt pro Strategie. |

Ungültige Werte bringen die App nie zum Absturz. Jeder Fall protokolliert eine Warnung pro Serverprozess:

- das Deaktivieren aller Locales wird ignoriert;
- eine `defaultLocale`, die nicht aktiviert ist, fällt auf die erste aktivierte Locale zurück;
- eine `fallbackLocale`, die nicht aktiviert ist, behält den Build-Wert, sofern dieser aktiviert ist, andernfalls gibt es keinen Fallback.

## Die wirksame Konfiguration lesen {#read-the-effective-config}

```vue
<script setup lang="ts">
const { $getI18nConfig } = useNuxtApp()
const config = $getI18nConfig() // build config with overrides applied
</script>
```

Behandeln Sie sie als schreibgeschützt: Auf dem Server wird sie von allen Anfragen geteilt und ist in der Entwicklung eingefroren; die Browser-Kopie ist nicht eingefroren. Wenn Sie die Konfiguration aus `#build/i18n.strategy.mjs` importieren, erhalten Sie die Build-Werte ohne Overrides.

## Deaktivierte Locales und statische Dateien {#disabled-locales-and-static-files}

Eine zur Laufzeit deaktivierte Locale antwortet auf ihren Routen und ihrer Payload-Route mit 404, aber ihre Payload-Dateien liegen weiterhin in `.output/public/_locales/` und ein Server für statische Dateien liefert sie aus. Wenn diese Dateien nicht erreichbar sein dürfen, deaktivieren Sie die Locale zur Build-Zeit mit `disabled: true`.
