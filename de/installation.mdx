## Voraussetzungen

- **Node.js**: 18 oder neuer.
- **Nuxt**: 3.x oder 4.x.

Das Modul unterstützt sowohl das Nuxt-3-Projektlayout (`pages/**/*.vue`) als auch das Nuxt-4-Layout (`app/pages/**/*.vue`). Übersetzungen liegen konventionsgemäß im Projektstammverzeichnis (`locales/`) – auch bei Verwendung des Nuxt-4-Verzeichnisses `app/`.

## Nuxt-Modul installieren

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Registrieren Sie es in `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Eine vollständige Anleitung finden Sie im [Schnellstart](/quickstart), alle Optionen in der [Konfigurationsreferenz](/guides/configuration).

## Projektlayout

Standardmäßig erwartet das Modul:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Dateien auf Root-Ebene werden zur Build-Zeit in jede seitenspezifische Datei eingemischt. Seitenspezifische Dateien werden während `nuxt dev` automatisch erstellt, sofern sie fehlen.

## Nuxt-4-Layout

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Um Übersetzungen unter `app/` zu platzieren, setzen Sie `translationDir: 'app/locales'`.

## TypeScript

Das Modul erzeugt basierend auf Ihren Standard-Locale-Dateien Ambient-Typen für `useI18n`, `$t` und verwandte Helfer. Dies ist standardmäßig aktiviert (`types: true`).

Für eine strengere Typisierung von Übersetzungsschlüsseln siehe [`@i18n-micro/types-generator`](/integrations/types-generator).
