## Voraussetzungen

- **Node.js**: 18 oder neuer.
- **Nuxt**: 3.x oder 4.x.

Das Modul unterstützt sowohl das Nuxt-3-Projektlayout (`pages/**/*.vue`) als auch das Nuxt-4-Layout (`app/pages/**/*.vue`). Übersetzungen liegen per Konvention im Projektstamm (`locales/`), auch wenn du das `app/`-Verzeichnis von Nuxt 4 verwendest.

## Nuxt-Modul installieren

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Registriere es in `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Siehe den [Schnellstart](/quickstart) für eine vollständige Anleitung oder die [Konfigurationsreferenz](/guides/configuration) für alle Optionen.

## Projektlayout

Standardmäßig erwartet das Modul:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Root-Level-Dateien werden zur Build-Zeit in jede seitenspezifische Datei eingebunden. Seitenspezifische Dateien werden bei fehlenden Werten automatisch während `nuxt dev` erstellt.

## Nuxt-4-Layout

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Um Übersetzungen unterhalb von `app/` zu platzieren, setze `translationDir: 'app/locales'`.

## Ökosystem-Pakete

| Paket | Zweck |
| --- | --- |
| [`@i18n-micro/vue`](/integrations/vue) | Vue-3-Integration (eigenständig, ohne Nuxt). |
| [`@i18n-micro/react`](/integrations/react) | React-Integration. |

| [`@i18n-micro/astro`](/integrations/astro) | Astro-Integration. |
| [`@i18n-micro/node`](/integrations/nodejs) | Node.js-Loader für die Serverseite. |

| [`@i18n-micro/devtools-ui`](/integrations/devtools-ui) | Framework-unabhängiges DevTools-Panel. |

Gemeinsam genutzte interne Pakete werden transitiv mit eingebunden.

## TypeScript

Das Modul generiert Ambient-Typen für `useI18n`, `$t` und verwandte Helfer auf Basis deiner Dateien für die Standardsprache. Diese Funktion ist standardmäßig aktiv (`types: true`).

Für eine strengere Typisierung der Übersetzungsschlüssel siehe [`@i18n-micro/types-generator`](/integrations/types-generator).
