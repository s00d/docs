## 🚀 Schnellstart

### Installation

Installieren Sie das Modul in Ihrer Nuxt-Anwendung:

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

### Grundkonfiguration

Fügen Sie das Modul in Ihrer `nuxt.config.ts` hinzu:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

<Tip>
- **Root-Level-Dateien** (`locales/en.json` usw.) — Übersetzungen, die in der gesamten App geteilt werden (Menüs, Footer, gemeinsame UI). Bei `translationPayloads.mode: 'premerged'` (Standard) werden sie zur Build-Zeit in jede Seite eingemischt.
- **Seitenspezifische Dateien** (`locales/pages/<route>/<locale>.json`) — Übersetzungen, die nur für bestimmte Seiten gelten und ausschließlich beim Aufruf dieser Seite geladen werden.
- **Dynamische Routen** — `pages/articles/[id].vue` entspricht `locales/pages/articles-id/` (eckige Klammern werden durch Bindestriche ersetzt).
- **Automatische Generierung** — alle Übersetzungsdateien werden bei Bedarf während `nuxt dev` automatisch erstellt.
</Tip>

<Info>
Das Modul unterstützt beide Layouts:

- **Pages**: `pages/**/*.vue` (Nuxt 3) oder `app/pages/**/*.vue` (Nuxt 4)
- **Übersetzungen**: `locales/` standardmäßig im **Projektstamm** belassen (empfohlene Konvention), nicht innerhalb von `app/`

```tree
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   ├── en.json
│   └── pages/
└── nuxt.config.ts
```

Optionale Ko-Lokation: `i18n: \{ translationDir: 'app/locales' \}` (siehe [Fixture `n3`](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/n3)).

Für den optionalen CLI-Helfer `text-to-i18n` verwenden Sie [`nuxt-i18n-micro-cli` ≥ 2.1.1](/guides/cli#-text-to-i18n-command), damit `app/pages` und `app/components` vom Projektstamm aus gescannt werden.
</Info>

### Grundlegende Verwendung

Verwenden Sie Übersetzungen in Ihren Komponenten:

```vue
<template>
  <div>
    <h1>{{ $t('welcome') }}</h1>
    <p>{{ $t('description', { name: 'World' }) }}</p>

    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" @click="$switchLocale(locale.code)">
        {{ locale.code }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useI18n } from '#imports'

const { $t, $getLocales, $switchLocale } = useI18n()
</script>
```
