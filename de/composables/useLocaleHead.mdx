---
title: "useLocaleHead"
description: "useLocaleHead erzeugt die i18n-SEO-Tags (lang, dir, canonical, hreflang, og:locale) als Objekt, das Sie an useHead übergeben."
---

`useLocaleHead()` erzeugt die i18n-Head-Tags für die aktuelle Route: `lang` und `dir` auf `<html>`, einen Canonical-Link, `hreflang`-Alternativen mit `x-default`, `og:url`, `og:locale` und `og:locale:alternate`. Verwenden Sie es, wenn Sie [`meta: false`](/de/api/module-options#meta) setzen und `useHead` selbst verwalten; mit `meta: true` registriert das Modul diese Tags bereits, und Änderungen pro Seite erfolgen über [`useI18nHead`](/de/composables/useI18nHead).

## Signatur {#signature}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { build: () => LocaleHead; metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }, LocaleHead | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

Die SEO-Head-Tags für die aktuelle Route: `hreflang`-Alternativen für jede Locale sowie
`x-default`, ein Canonical-Link, `og:locale` und `lang`/`dir` auf `<html>`.

Nur nötig, wenn `meta` deaktiviert ist oder die Standardwerte angepasst werden müssen — mit `meta: true`
registriert das Modul dieselben Tags selbst.

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| `options` | `UseLocaleHeadOptions` |  |

**Rückgabewert** — `metaObject`, ein Ref mit dem Head-Objekt, das direkt an `useHead` übergeben werden kann; `updateMeta` aktualisiert es; `build` berechnet das Head-Objekt aus der aktuellen Route (reaktiv, wenn es in einem Getter gelesen wird, z. B. `useHead(() => build())`)

```ts
const { metaObject } = useLocaleHead({ addSeoAttributes: true })
useHead(metaObject)
```

## Optionen {#options}

| Option | Standard | Beschreibung |
| --- | --- | --- |
| `addDirAttribute` | `true` | Setzt `dir` auf `<html>` anhand des `dir` der Locale (`'auto'`, wenn keines gesetzt ist). |
| `identifierAttribute` | `'id'` | Attribut, das jedes Tag kennzeichnet (`i18n-can`, `i18n-og`, `i18n-alternate-<hreflang>`, …), damit Aktualisierungen Tags ersetzen, statt neue hinzuzufügen. |
| `addSeoAttributes` | `true` | Gibt Canonical-, `hreflang`- und `og:`-Tags aus. `false` behält nur `htmlAttrs`. |
| `baseUrl` | `'/'` | Origin, der jeder URL vorangestellt wird. Behalten Sie `'/'` für relative URLs bei; übergeben Sie `'https://example.com'` für absolute URLs. |
| `autoUpdate` | `true` | Baut `metaObject` neu auf, wenn sich die Route oder der Status `i18n-locale` ändert. |

## Was ausgegeben wird {#what-it-emits}

- Nichts auf einer Route ohne Treffer (404) oder mit `disableMeta` für die aktive Locale.
- Canonical und `og:url`: `$switchLocalePath(<active locale>)`, Query auf [`canonicalQueryWhitelist`](/de/api/module-options#canonicalquerywhitelist) reduziert, [`trailingSlash`](/de/api/module-options#trailingslash) angewendet.
- `hreflang`: ein Link pro aktivierter Locale, in der die Seite existiert, `hreflang = iso || code`, wobei Locales mit `seo: false` übersprungen werden; mit `hreflangBaseLanguage: true` gibt die erste regionale Locale einer Sprache zusätzlich ihr Tag für die reine Sprache aus. Keine unter `no_prefix`.
- `x-default`: die URL der Standard-Locale, es sei denn, die Strategie ist `no_prefix`, die Standard-Locale hat `seo: false` oder die Seite existiert in ihr nicht.
- `og:locale` / `og:locale:alternate`: aus dem `og` der Locale oder ihrem umgewandelten `iso` (`en-US` → `en_US`); wird mit einer Dev-Warnung übersprungen, wenn beides nicht funktioniert.

## Beispiel {#example}

```ts
// app.vue, with i18n.meta: false
const { metaObject } = useLocaleHead({ baseUrl: 'https://example.com' })
useHead(metaObject)
```

`build()` gibt dasselbe Objekt ohne Ref zurück: `useHead(() => build())` bleibt ohne Watcher reaktiv.
