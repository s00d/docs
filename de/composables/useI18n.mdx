---
title: "useI18n"
description: "useI18n gibt die Laufzeit-Helfer (`$t`, `$tc`, `$localePath`, …) als einfaches Objekt zurück, mit und ohne `$`-Präfix."
---

`useI18n()` gibt die Laufzeit-Helfer des Moduls als einfaches Objekt zurück. Verwenden Sie es in `<script setup>`, Composables und Plugins, anstatt auf `useNuxtApp()` zurückzugreifen. Jeder Helfer ist unter seinem `$`-Namen und einem Alias ohne Präfix verfügbar: `t` und `$t` sind dieselbe Funktion.

## Signatur {#signature}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Alle Laufzeit-Helfer als einfaches Objekt.

Dieselben Funktionen, die das Plugin als `$t`, `$tc` usw. injiziert, verfügbar sowohl
unter dem Namen mit Dollar-Präfix als auch unter einem Alias ohne Präfix — sowohl `const { t } = useI18n()` als auch
`const { $t } = useI18n()` funktionieren.

**Rückgabewert** — die in der [Methodenreferenz](/de/api/methods) beschriebenen Helfer

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

Das zurückgegebene Objekt enthält jeden Helfer aus [`PluginsInjections`](/de/api/methods). Jeder einzelne ist auf der Seite [Helfer](/de/api/methods) dokumentiert.

## Beispiel {#example}

```vue
<script setup lang="ts">
const { t, tc, localePath, switchLocale, getLocale } = useI18n()

const title = computed(() => t('page.title'))
</script>

<template>
  <h1>{{ title }}</h1>
  <p>{{ tc('items', 3) }}</p>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
  <button @click="switchLocale(getLocale() === 'en' ? 'de' : 'en')">{{ t('nav.switch') }}</button>
</template>
```

## Nicht im Typ enthalten {#not-in-the-type}

`$defineI18nRoute` ist nur auf `useNuxtApp()` typisiert:

```ts
const { $defineI18nRoute } = useNuxtApp()
```
