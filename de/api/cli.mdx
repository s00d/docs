Der [CLI-Leitfaden](/de/guide/cli) zeigt die gängigen Workflows. Diese Seite listet alles auf und wird aus derselben Tabelle generiert, die auch `--help` speist.

## Gemeinsame Flags {#common-flags}

| Flag | Standard | Beschreibung |
| --- | --- | --- |
| `--cwd` | aktuelles Verzeichnis | Projektverzeichnis |
| `--logLevel` | `info` | Ausgabestufe: silent, info |
| `--debug` | `false` | Bei einem Fehlschlag eines Befehls einen Stacktrace ausgeben |

## Prüfen {#inspect}

### `info` {#info}

Die aufgelöste i18n-Konfiguration des Projekts ausgeben

| Flag | Standard | Beschreibung |
| --- | --- | --- |
| `--json` | `false` | JSON statt Text ausgeben |

### `check` {#check}

Das CI-Gate: schlägt fehl bei fehlenden, leeren, überzähligen, undefinierten oder ungenutzten Schlüsseln und defekten Platzhaltern

| Flag | Standard | Beschreibung |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` aus nuxt.config | Übersetzungsverzeichnis, relativ zum Projekt |
| `--only` | alle außer duplicates | Kommagetrennte Liste der auszuführenden Prüfungen: missing, empty, extra, placeholders, undefined, unused, duplicates. Ist `unused` hier angegeben, schlägt der Befehl fehl, wenn diese Prüfung nicht laufen kann |
| `--duplicates` | `false` | Auch denselben Text unter verschiedenen Schlüsseln melden |
| `--ignore` | — | Kommagetrennte Globs von Quelldateien, die übersprungen werden, relativ zum Projekt |
| `--json` | `false` | JSON statt Text ausgeben |

```bash
i18n-micro check
i18n-micro check --only missing,placeholders --json
```

### `stats` {#stats}

Übersetzungsfortschritt pro Locale anzeigen

| Flag | Standard | Beschreibung |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` aus nuxt.config | Übersetzungsverzeichnis, relativ zum Projekt |
| `--html` | — | Zusätzlich einen HTML-Bericht in diese Datei schreiben |
| `--json` | `false` | JSON statt Text ausgeben |
| `--baseRef` | — | Git-Ref, mit dem der Fortschritt verglichen wird, z. B. HEAD~1 oder main |

```bash
i18n-micro stats --baseRef main
i18n-micro stats --html reports/i18n.html
```

### `lint` {#lint}

Den Text der Übersetzungen prüfen; schlägt fehl, wenn Probleme bestehen bleiben

| Flag | Standard | Beschreibung |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` aus nuxt.config | Übersetzungsverzeichnis, relativ zum Projekt |
| `--rules` | alle, oder `enabledRules` aus .i18n-lintrc.json | Kommagetrennte Liste der auszuführenden Regeln: no-trailing-spaces, no-multiple-spaces, no-empty-translation oder eine eigene |
| `--fix` | `false` | Beheben, was sich beheben lässt: Leerzeichen und eigene Regeln mit einer Ersetzung |
| `--json` | `false` | JSON statt Text ausgeben |

```bash
i18n-micro lint --rules no-trailing-spaces --fix
```

### `search` {#search}

Schlüssel und Werte durchsuchen und anzeigen, wo jeder Schlüssel verwendet wird

| Flag | Standard | Beschreibung |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` aus nuxt.config | Übersetzungsverzeichnis, relativ zum Projekt |
| `<query>` | — | Zu suchender Text oder Schlüssel |
| `--caseSensitive` | `false` | Groß-/Kleinschreibung beachten |
| `--onlyUnused` | `false` | Nur Schlüssel, die `clean` entfernen würde; die Abfrage wird optional |
| `--scope` | `all` | Wo gesucht wird: global, pages, all |
| `--limit` | — | Höchstens so viele Schlüssel zurückgeben |
| `--ignore` | — | Kommagetrennte Globs von Quelldateien, die übersprungen werden, relativ zum Projekt |
| `--json` | `false` | JSON statt Text ausgeben |

```bash
i18n-micro search "Welcome"
i18n-micro search --onlyUnused
```

## Übersetzungs-Workflow {#translation-workflow}

### `extract` {#extract}

Die in Quelldateien verwendeten Schlüssel auflisten, die noch keinen Text haben, und solche mit einem Standardtext zur Standard-Locale hinzufügen

| Flag | Standard | Beschreibung |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` aus nuxt.config | Übersetzungsverzeichnis, relativ zum Projekt |
| `--ignore` | — | Kommagetrennte Globs von Quelldateien, die übersprungen werden, relativ zum Projekt |

```bash
i18n-micro extract
```

### `translate` {#translate}

Fehlende Übersetzungen aus der Standard-Locale über einen Übersetzungsdienst ergänzen

| Flag | Standard | Beschreibung |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` aus nuxt.config | Übersetzungsverzeichnis, relativ zum Projekt |
| `--service` | — | Übersetzungsdienst: ai, azure, deepl, google, libretranslate, yandexcloud |
| `--token` | — | API-Schlüssel. Verwenden Sie besser die Umgebungsvariable I18N_TRANSLATE_TOKEN: Flags landen in der Shell-Historie |
| `--options` | — | Dienstoptionen als key:value-Paare, durch Kommas getrennt |
| `--locale` | alle Locales außer der Standard-Locale | Kommagetrennte Liste der zu ergänzenden Locales |
| `--replace` | `false` | Jeden Schlüssel erneut übersetzen und vorhandene Werte ersetzen |
| `--dryRun` | `false` | Schlüssel und Zeichen pro Locale zählen; nichts senden |
| `--chunkSize` | — | Strings pro Anfrage; begrenzt auf das, was der Dienst akzeptiert |
| `--pluralSeparator` | `\|` | Trennzeichen der Pluralformen in Nachrichten |
| `--glossaryFile` | `.i18n-glossary.json`, falls vorhanden | Glossardatei, verwendet vom Dienst `ai` |

```bash
i18n-micro translate --dryRun
I18N_TRANSLATE_TOKEN=... i18n-micro translate --service deepl --locale de,fr
i18n-micro translate --service ai --options provider:openai,model:gpt-4o-mini
i18n-micro translate --service libretranslate --options baseUrl:https://translate.example.com
```

### `sync` {#sync}

Schlüssel entfernen, die die Standard-Locale nicht hat; bricht ab, wenn sich nicht nachweisen lässt, dass dies sicher ist. Fehlende Schlüssel bleiben fehlend

| Flag | Standard | Beschreibung |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` aus nuxt.config | Übersetzungsverzeichnis, relativ zum Projekt |
| `--ignore` | — | Kommagetrennte Globs von Quelldateien, die übersprungen werden, relativ zum Projekt |
| `--dryRun` | `false` | Auflisten, was entfernt würde; nichts schreiben |
| `--force` | `false` | Schlüssel entfernen, auch wenn sich nicht nachweisen lässt, dass dies sicher ist |

```bash
i18n-micro sync --dryRun
```

### `clean` {#clean}

Schlüssel entfernen, die nichts im Projekt verwendet; bricht ab, wenn sich das nicht nachweisen lässt

| Flag | Standard | Beschreibung |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` aus nuxt.config | Übersetzungsverzeichnis, relativ zum Projekt |
| `--include` | — | Regulärer Ausdruck: nur passende Schlüssel für das Entfernen in Betracht ziehen |
| `--exclude` | — | Regulärer Ausdruck: passende Schlüssel niemals entfernen |
| `--ignore` | — | Kommagetrennte Globs von Quelldateien, die übersprungen werden, relativ zum Projekt |
| `--dryRun` | `false` | Auflisten, was entfernt würde; nichts schreiben |
| `--force` | `false` | Schlüssel entfernen, auch wenn die Verwendung nicht für alle nachgewiesen werden kann |

```bash
i18n-micro clean --dryRun
i18n-micro clean --exclude '^errors\.'
```

## Refactoring {#refactoring}

### `text-to-i18n` {#text-to-i18n}

Hartcodierten Text in Vue-Templates durch Übersetzungsaufrufe ersetzen und hartcodierten Text im Code melden

| Flag | Standard | Beschreibung |
| --- | --- | --- |
| `--translationFile` | `<translationDir>/<defaultLocale>.json` | Datei, in die die neuen Schlüssel geschrieben werden |
| `--path` | das gesamte Projekt | Zu verarbeitende Datei oder zu verarbeitendes Verzeichnis |
| `--context` | — | Präfix für generierte Schlüssel |
| `--ignore` | — | Kommagetrennte Globs von Quelldateien, die übersprungen werden, relativ zum Projekt |
| `--dryRun` | `false` | Anzeigen, was sich ändern würde; nichts schreiben |
| `--interactive` | `false` | Jeden generierten Schlüssel bestätigen oder bearbeiten |

```bash
i18n-micro text-to-i18n --dryRun
i18n-micro text-to-i18n --path components --context ui
```

### `rename` {#rename}

Einen Schlüssel oder einen Namespace in jeder Locale und in den Quelldateien umbenennen

| Flag | Standard | Beschreibung |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` aus nuxt.config | Übersetzungsverzeichnis, relativ zum Projekt |
| `--from` **\*** | — | Aktueller Schlüssel oder Namespace |
| `--to` **\*** | — | Neuer Schlüssel oder Namespace |
| `--ignore` | — | Kommagetrennte Globs von Quelldateien, die übersprungen werden, relativ zum Projekt |
| `--dryRun` | `false` | Die Änderungen melden; nichts schreiben |

**\*** erforderlich.

```bash
i18n-micro rename --from common.save --to actions.save
```

### `pseudo` {#pseudo}

Eine Locale mit Pseudo-Übersetzungen füllen, um Layout-Probleme und hartcodierten Text zu finden

| Flag | Standard | Beschreibung |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` aus nuxt.config | Übersetzungsverzeichnis, relativ zum Projekt |
| `--sourceLocale` | die Standard-Locale | Zu lesende Locale |
| `--targetLocale` **\*** | — | Zu füllende Locale |
| `--replace` | `false` | Vorhandene Werte überschreiben |

**\*** erforderlich.

### `format` {#format}

Locale-Dateien mit sortierten Schlüsseln und einheitlicher Einrückung neu schreiben

| Flag | Standard | Beschreibung |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` aus nuxt.config | Übersetzungsverzeichnis, relativ zum Projekt |
| `--indent` | `2` | Leerzeichen für die Einrückung |
| `--sortKeys` | `true` | Schlüssel sortieren; mit --no-sortKeys bleibt ihre Reihenfolge erhalten |
| `--check` | `false` | Fehlschlagen, wenn sich eine Datei ändern würde; nichts schreiben |

```bash
i18n-micro format --check
```

## Austausch {#exchange}

### `export` {#export}

Locale-Dateien nach PO oder CSV exportieren, mit dem Text der Standard-Locale als Quelle

| Flag | Standard | Beschreibung |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` aus nuxt.config | Übersetzungsverzeichnis, relativ zum Projekt |
| `--format` | `po` | Dateiformat: po, csv |
| `--dir` | `pots` für po, `csv_exports` für csv | Ausgabeverzeichnis, relativ zum Projekt |
| `--force` | `false` | Dateien überschreiben, die seit dem letzten Export geändert und nie importiert wurden |

```bash
i18n-micro export --format csv
```

### `import` {#import}

PO- oder CSV-Dateien in die Locale-Dateien zusammenführen

| Flag | Standard | Beschreibung |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` aus nuxt.config | Übersetzungsverzeichnis, relativ zum Projekt |
| `--format` | `po` | Dateiformat: po, csv |
| `--dir` | `pots` für po, `csv_exports` für csv | Eingabeverzeichnis, relativ zum Projekt |
| `--dryRun` | `false` | Melden, was importiert würde; nichts schreiben |

```bash
i18n-micro import --format csv --dryRun
```

### `sync-remote` {#sync-remote}

Globale Übersetzungen vom HTTP-Endpunkt in .i18n-remote.json abrufen oder dorthin übertragen

| Flag | Standard | Beschreibung |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` aus nuxt.config | Übersetzungsverzeichnis, relativ zum Projekt |
| `--pull` | `true` | Vom Remote abrufen |
| `--push` | `false` | Zum Remote übertragen |
| `--force` | `false` | Beim Pull den Remote-Wert übernehmen; beim Push Text überschreiben, den nur der Remote hat |
| `--dryRun` | `false` | Melden, was ein Pull ändern würde; nichts schreiben und nichts übertragen |

```bash
i18n-micro sync-remote --dryRun
i18n-micro sync-remote --no-pull --push
```

## Lint-Regeln {#lint-rules}

| Regel | Findet | Behoben durch `--fix` |
| --- | --- | --- |
| `no-trailing-spaces` | Leerzeichen am Ende eines Werts oder einer Zeile | ja |
| `no-multiple-spaces` | Zwei oder mehr aufeinanderfolgende Leerzeichen | ja |
| `no-empty-translation` | Ein leerer oder nur aus Leerraum bestehender Wert | nein |

## Exit-Codes {#exit-codes}

| Code | Bedeutung |
| --- | --- |
| `0` | Fertig, nichts zu melden |
| `1` | Befunde: `check`, `lint` oder `format --check` haben etwas gefunden, `clean` oder `sync` konnten nicht nachweisen, dass ein Entfernen sicher ist, `export` würde nicht importierte Arbeit überschreiben, `translate` hat Schlüssel ausgelassen, `import` oder `sync-remote` sind auf einen Konflikt gestoßen, ein `sync-remote`-Push würde Remote-Text verwerfen. Ein `--dryRun` von `clean`, `sync` oder einem `sync-remote`-Pull meldet diese und endet mit `0` |
| `2` | Fehler: falsche Verwendung, nicht lesbares Projekt, Netzwerk- oder Dateifehler |

## Konfigurationsdateien {#configuration-files}

| Datei | Verwendet von |
| --- | --- |
| `.i18n-lintrc.json` | `lint`: `enabledRules`, `disabledRules`, `customRegexRules` (`name`, `pattern`, `flags`, `description`, `replacement`) |
| `.i18n-remote.json` | `sync-remote`: `url`, `path`, `token`, `auth` (`username`, `password`). `type` kann weggelassen werden; es gibt nur `custom` |
| `.i18n-glossary.json` | `translate --service ai`: `entries` aus `source`, `target` und optional `from`, `to` |

## Umgebungsvariablen {#environment-variables}

| Name | Verwendet für |
| --- | --- |
| `I18N_TRANSLATE_TOKEN` | API-Schlüssel von `translate`. Wird auch aus `.env` gelesen |
| `I18N_REMOTE_TOKEN` | Bearer-Token von `sync-remote`. Wird auch aus `.env` gelesen |
| `AI_GATEWAY_API_KEY, OPENAI_API_KEY, ANTHROPIC_API_KEY` | Schlüssel des Dienstes `ai`, wenn `I18N_TRANSLATE_TOKEN` nicht gesetzt ist |
| `DEFAULT_LOCALE` | Überschreibt `defaultLocale`, wie im Modul |
