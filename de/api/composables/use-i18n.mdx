# 🛠️ Composable `useI18n`

Das Composable `useI18n` in `Nuxt I18n Micro` liefert Zugriff auf die meisten Runtime-i18n-Helfer in Komponenten und Skripten. Methoden sind **mit und ohne das Präfix `$`** verfügbar (zum Beispiel `$t` und `t`).

Einige Injections wie `$defineI18nRoute` und `$clearCache` sind nur über `useNuxtApp()` verfügbar. Siehe [Methods, `$defineI18nRoute`](/api/methods#definei18nroute) und [`$clearCache`](/api/methods#clearcache).

## 📊 Was es liefert

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Jeder Runtime-Helfer als einfaches Objekt.

Dieselben Funktionen, die das Plugin als `$t`, `$tc` und so weiter injiziert, sind sowohl unter dem Namen mit Dollar-Präfix als auch unter einem einfachen Alias verfügbar. Sowohl `const \{ t \} = useI18n()` als auch `const \{ $t \} = useI18n()` funktionieren.

**Rückgabewert**: die in der [Methoden-Referenz](/api/methods) beschriebenen Helfer.

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

Jeder zurückgegebene Helfer, also `$t`, `$tc`, `$has`, `$switchLocale` und die anderen, ist mit seiner Signatur ausführlich in der [Methoden-Referenz](/api/methods) dokumentiert.

## APIs nur über `useNuxtApp()`

Diese sind **nicht** im Rückgabewert von `useI18n()` enthalten. Importiere sie aus `useNuxtApp()`:

| Methode                    | Zweck                                                                              |
| -------------------------- | ---------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Seitenweise Locale-Routen, Einschränkungen und Inline-Übersetzungen in `script setup` |
| `$clearCache()`            | Leert den In-Memory-Übersetzungscache und die geladenen Chunks                     |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Vollständige Signaturen und Beispiele findest du unter [Methods](/api/methods).

## 🛠️ Beispielverwendungen

### Locale ermitteln

Ermittle die aktuelle Locale der Anwendung.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Übersetzung mit Parametern

Übersetze einen String mit dynamischen Parametern und einem Fallback-Standardwert.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Locale wechseln

Wechsle die Anwendung auf eine andere Locale.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Lokalisierte Route erzeugen

Erzeuge eine für die aktuelle oder eine angegebene Locale lokalisierte Route.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
