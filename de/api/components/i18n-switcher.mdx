# 🌍 Komponente `<i18n-switcher>`

Die Komponente `<i18n-switcher>` in `Nuxt I18n Micro` bietet ein benutzerfreundliches Dropdown zum Wechseln zwischen verschiedenen Locales in deiner Anwendung. Sie ist hochgradig anpassbar und lässt sich nahtlos in Design und Layout deiner Anwendung integrieren.

Locales mit `disabled: true` werden im Dropdown **ausgelassen** (sie bleiben über `$getLocales()` für SEO- und Head-Tags verfügbar). Nur umschaltbare Locales erhalten `NuxtLink` und `hreflang`.

Standardmäßig ist jeder Teil unstyled: Die `custom*Style`-Props akzeptieren Inline-Style-Objekte, und die unten aufgeführten Slots ersetzen das Markup vollständig, wenn Styling allein nicht reicht.

## 🛠️ Beispielverwendungen

### Einfache Verwendung

```vue
<template>
  <i18n-switcher />
</template>
```

Das rendert einen Locale-Switcher mit Standardstyling und Standardverhalten.

### Eigene Labels und Inline-Styles

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Dieses Beispiel zeigt einen vollständig angepassten Locale-Switcher mit eigenen Labels und Inline-Styles.

## 🔌 Slots

Jeder sichtbare Teil des Switchers lässt sich ersetzen. Die Slots sind zusammen mit der Props-Tabelle oben aufgeführt. Jeder nimmt Template-Inhalt entgegen:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Slots, deren Name auf `-item` oder `-link-content` endet oder mit `before-item` beginnt, erhalten das zugehörige `locale`-Objekt.

## 🎨 Überblick zu Styles

Die Komponente `<i18n-switcher>` bringt einfache Styles über Inline-Styles mit, die sich leicht mit eigenen Styles per Props überschreiben lassen. Kurzer Überblick über das Standardstyling:

- **Wrapper**: Steuert die Positionierung des Dropdowns.
- **Button**: Gestaltet den Button, der das Dropdown öffnet.
- **Dropdown**: Gestaltet die Dropdown-Liste.
- **Items**: Gestaltet jeden Eintrag in der Liste.
- **Links**: Gestaltet die Links innerhalb jedes Eintrags.
- **Icon**: Gestaltet das Indikator-Icon des Dropdowns.

Diese Styles kannst du über die jeweiligen Props anpassen, sodass sich der Locale-Switcher nahtlos in die UI deiner Anwendung einfügt.
