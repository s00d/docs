# 🌍 Komponente `<i18n-group>`

Die Komponente `<i18n-group>` in Nuxt I18n Micro bietet eine bequeme Möglichkeit, Übersetzungen unter einem gemeinsamen Präfix zu gruppieren. Das reduziert Wiederholungen und verbessert die Code-Organisation.

## ⚙️ Props

{/* generated:component:i18n-group — do not edit; run `pnpm run docs:generate` */}

| Prop | Typ | Standard | Beschreibung |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | Schlüsselpräfix, gegen das jede Suche innerhalb des Slots aufgelöst wird. |
| `groupClass` | `string` | `''` | Zusätzliche Klasse am Wrapper-Element. |

**\*** erforderlich.

### Slots

| Slot | Bindings | Beschreibung |
| --- | --- | --- |
| `default` | `prefix`, `t` | Erhält `prefix` und eine darauf begrenzte `t`-Funktion. |

{/* /generated:component:i18n-group */}

## 🎯 Slots

Der Default-Slot erhält `prefix` sowie eine darauf begrenzte `t`-Funktion, sodass Schlüssel darin relativ zum Präfix geschrieben werden:

```vue
<i18n-group prefix="checkout">
  <template #default="{ t }">
    <h2>{{ t('title') }}</h2>
    <p>{{ t('summary', { count: 3 }) }}</p>
  </template>
</i18n-group>
```

## 🛠️ Beispielverwendung

### Einfache Verwendung

```vue
<template>
  <i18n-group prefix="product.details">
    <template #default="{ t }">
      <h1>{{ t('title') }}</h1>
      <p>{{ t('description') }}</p>
      <div class="price">{{ t('price', { value: 99.99 }) }}</div>
    </template>
  </i18n-group>
</template>
```

Übersetzungsdatei:

```json
{
  "product": {
    "details": {
      "title": "Premium Product",
      "description": "This is a premium product",
      "price": "Price: ${value}"
    }
  }
}
```

### Mit eigener Klasse

```vue
<template>
  <i18n-group prefix="user.profile" group-class="profile-section">
    <template #default="{ t }">
      <div class="user-info">
        <h2>{{ t('title') }}</h2>
        <p>{{ t('bio') }}</p>
        <div class="stats">
          <span>{{ t('stats.followers') }}</span>
          <span>{{ t('stats.following') }}</span>
        </div>
      </div>
    </template>
  </i18n-group>
</template>
```

Übersetzungsdatei:

```json
{
  "user": {
    "profile": {
      "title": "User Profile",
      "bio": "User biography goes here",
      "stats": {
        "followers": "Followers: {count}",
        "following": "Following: {count}"
      }
    }
  }
}
```

### Mit dynamischen Inhalten

```vue
<template>
  <i18n-group prefix="blog.post">
    <template #default="{ t }">
      <article>
        <h1>{{ t('title') }}</h1>
        <div class="meta">
          {{ t('meta.author', { name: author }) }} |
          {{ t('meta.date', { date: publishDate }) }}
        </div>
        <div v-for="(section, index) in sections" :key="index">
          <h2>{{ t(`sections.${index}.title`) }}</h2>
          <p>{{ t(`sections.${index}.content`) }}</p>
        </div>
      </article>
    </template>
  </i18n-group>
</template>

<script setup>
const author = 'John Doe'
const publishDate = '2024-01-01'
const sections = ['intro', 'main', 'conclusion']
</script>
```

## 🎨 Styling

Die Komponente umschließt ihren Inhalt mit einem `div` mit der Klasse `i18n-group` sowie allen zusätzlichen Klassen, die im Prop `groupClass` angegeben sind:

```css
.i18n-group {
  /* Deine Basis-Styles */
}

.profile-section {
  /* Zusätzliche Styles für Profilabschnitte */
}
```

## 🚀 Best Practices

1. **Konsistente Präfixe**: Verwende konsistente und logische Präfixe, die die Struktur deiner Anwendung widerspiegeln.

```vue
<i18n-group prefix="features.pricing">
<i18n-group prefix="features.security">
```

2. **Modulare Organisation**: Fasse zusammengehörige Übersetzungen unter aussagekräftigen Präfixen zusammen.

```vue
<i18n-group prefix="checkout.payment">
<i18n-group prefix="checkout.shipping">
```

3. **Wiederverwendbare Komponenten**: Erstelle wiederverwendbare Komponenten mit eigenen Übersetzungsgruppen.

```vue
<!-- UserProfile.vue -->
<i18n-group prefix="user.profile">

<!-- UserSettings.vue -->
<i18n-group prefix="user.settings">
```

4. **Verschachtelte Gruppen**: Vermeide tief verschachtelte Gruppen, um die Übersichtlichkeit zu wahren.

```vue
<!-- Gut -->
<i18n-group prefix="shop.product">

<!-- Vermeiden -->
<i18n-group prefix="shop.category.product.details.specs">
```
