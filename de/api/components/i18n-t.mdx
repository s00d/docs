# 🌍 Komponente `<i18n-t>`

Die Komponente `<i18n-t>` in `Nuxt I18n Micro` ist eine flexible Übersetzungskomponente mit dynamischer Inhaltsplatzierung über Slots. Damit kannst du Übersetzungen mit eigenen Vue-Komponenten oder HTML-Inhalten interpolieren und so anspruchsvolle Lokalisierungs-Szenarien umsetzen.

{/* /generated:component:i18n-t */}

Es gilt jeweils nur eines von `plural`, `number`, `date` und `relativeDate`. Sind mehrere gesetzt, gewinnt das erste in dieser Reihenfolge.

### Beispiele je Prop

```vue
<!-- keypath: die zu rendernde Übersetzung -->
<i18n-t keypath="feedback.text" />

<!-- plural: wählt die Pluralform aus -->
<i18n-t keypath="items" :plural="10" />

<!-- params: werden in die Übersetzung interpoliert -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: das zu rendernde Element -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatiert und dann interpoliert -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty mit Fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

## 🛠️ Beispielverwendungen

### Einfache Verwendung

```vue
<i18n-t keypath="feedback.text" />
```

Das rendert die Übersetzung für `feedback.text` innerhalb eines `<span>`-Tags.

### Slots für dynamische Inhalte

Die Komponente `<i18n-t>` unterstützt Slots, um Vue-Komponenten oder andere Inhalte dynamisch an bestimmten Stellen der Übersetzung einzufügen.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

In diesem Beispiel wird der Platzhalter `\{link\}` in der Übersetzung `feedback.text` durch die Komponente `<nuxt-link>` ersetzt, die selbst eine weitere Übersetzungskomponente enthält.

### Pluralisierung

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

Damit werden die Pluralisierungsregeln automatisch anhand des Werts von `itemCount` angewendet.

## 🚀 Zusätzliche Funktionen

### Default-Slot

Wenn kein bestimmter Slot angegeben ist, lässt sich die Übersetzung über den Default-Slot anpassen. Er liefert den kompletten übersetzten String:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### Bedingtes Rendern

Mit dem Prop `hideIfEmpty` wird nichts gerendert, wenn der Übersetzungs-String leer ist.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### Eigene Pluralregel

Nutze eine eigene Funktion für die Pluralisierung.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### Fortgeschrittenes Beispiel mit Slots

Mit Slots kannst du das Rendering des Übersetzungsinhalts anpassen.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
