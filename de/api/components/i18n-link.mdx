# 🌍 Komponente `<i18n-link>`

Die Komponente `<i18n-link>` in `Nuxt I18n Micro` ist eine vielseitige Link-Komponente, die Routen automatisch anhand der aktuellen Locale lokalisiert. Sie fungiert als Wrapper um die `<NuxtLink>`-Komponente und bietet zusätzliche Funktionen wie Styling für aktive Links und Unterstützung externer Links.

## ⚙️ Props

| Prop | Typ | Standard | Beschreibung |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | Zielroute. Wird automatisch lokalisiert. Eine externe URL wird unverändert durchgereicht. |
| `activeStyle` | `Partial<CSSStyleValue>` | — | Inline-Style, das gesetzt wird, während der Link auf die aktuelle Route zeigt. |

**\*** erforderlich.

### Slots

| Slot | Bindings | Beschreibung |
| --- | --- | --- |
| `default` | — | Inhalt des Links. |

{/* /generated:component:i18n-link */}

`to` akzeptiert alles, was `NuxtLink` auch akzeptiert: einen Pfad, eine benannte Route oder ein aufgelöstes Routen-Objekt. Eine absolute URL wird erkannt und als reines `<a target="_blank" rel="noopener noreferrer">` gerendert, statt lokalisiert zu werden.

## 🛠️ Beispielverwendungen

### Einfache Verwendung

```vue
<i18n-link to="/about">About Us</i18n-link>
```

Dieses Beispiel erzeugt einen Link zur Seite `/about`, lokalisiert auf die aktuelle Locale.

### Aktives Link-Styling mit Inline-Styles

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

Der Link erscheint fett, wenn du dich auf der Seite `/about` befindest. So kannst du den aktiven Link direkt per Inline-Style gestalten.

### Umgang mit externen Links

Die Komponente erkennt externe Links automatisch und ergänzt die nötigen Sicherheits-Attribute.

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

Dieser Link öffnet `https://example.com` in einem neuen Tab, mit `rel="noopener noreferrer"`.

## 🎨 Styles

Die Komponente nutzt jetzt Inline-Styles für den Aktivzustand statt einer Klasse. Diese Styles kannst du über das Prop `activeStyle` anpassen.

### Standard-Styles für den Aktivzustand

- **Font Weight**: `bold`
- **Color**: Erbt die Standardfarbe des Browsers (wenn in `activeStyle` keine `color` angegeben ist).

Diese Werte kannst du überschreiben, indem du eigene Styles über das Prop `activeStyle` übergibst.

### Eigene Styles für den Aktivzustand

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

In diesem Beispiel wird der Link im aktiven Zustand fett und grün.

## 🚀 Zusätzliche Funktionen

### Slot für eigene Inhalte

Über Slots kannst du eigene Inhalte innerhalb des Links platzieren. Das macht die Komponente für verschiedene Anwendungsfälle flexibel.

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### Verbesserungen für Barrierefreiheit

Die Komponente unterstützt `aria-label` und weitere Accessibility-Attribute für ein zugänglicheres Nutzungserlebnis.

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
