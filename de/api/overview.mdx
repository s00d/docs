Dieser Abschnitt listet jede Option, jeden Helfer, Hook, jedes Composable und jede Komponente des Nuxt-Moduls auf, dazu die exportierte API jedes `@i18n-micro/*`-Pakets. Nutzen Sie ihn, um eine Signatur oder einen Standardwert nachzuschlagen; der [Leitfaden](/de/guide/getting-started) erklärt, wie man sie verwendet. Die meisten Tabellen hier werden aus dem Quellcode generiert und stimmen daher mit dem Code überein.

## Nuxt-Modul {#nuxt-module}

| Seite | Inhalt |
| --- | --- |
| [Moduloptionen](/de/api/module-options) | Jeder `i18n`-Schlüssel in `nuxt.config`, mit Typ und Standardwert |
| [Helfer](/de/api/methods) | `$t`, `$tc`, `$tn`, `$td`, `$localePath`, `$switchLocale`, `$defineI18nRoute` und der Rest |
| [Hooks](/de/api/events) | Der Laufzeit-Hook `i18n:register` |

## Composables {#composables}

| Composable | Verwenden Sie es für |
| --- | --- |
| [`useI18n`](/de/composables/useI18n) | Die Helfer in `<script setup>` |
| [`useI18nLocale`](/de/composables/useI18nLocale) | Locale-Zustand und Cookie in einem eigenen Erkennungs-Plugin |
| [`useI18nHead`](/de/composables/useI18nHead) | Seitenspezifische Überschreibungen der generierten SEO-Tags |
| [`useLocaleHead`](/de/composables/useLocaleHead) | Die SEO-Tags als Objekt, für Ihr eigenes `useHead` |

## Komponenten {#components}

| Komponente | Rendert |
| --- | --- |
| [`<i18n-t>`](/de/components/i18n-t) | Eine Übersetzung, mit Pluralisierung, Formatierung und Slot-Interpolation |
| [`<i18n-link>`](/de/components/i18n-link) | Einen `NuxtLink` zur lokalisierten Route |
| [`<i18n-switcher>`](/de/components/i18n-switcher) | Ein Locale-Dropdown |
| [`<i18n-group>`](/de/components/i18n-group) | Einen Block mit gemeinsamem Schlüsselpräfix |

## Server {#server}

Nitro-Handler verwenden `useTranslationServerMiddleware` und `useLocaleServerMiddleware`, nicht die Client-Helfer. Siehe [Server-Routen](/de/guide/server-side-translations).

## Pakete {#packages}

[Paket-APIs](/de/api/packages/overview) listet die Exporte jedes `@i18n-micro/*`-Pakets auf, jeweils eine generierte Seite.
