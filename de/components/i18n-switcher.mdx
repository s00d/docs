---
title: "<i18n-switcher>"
description: "Die Komponente <i18n-switcher> ist ein Dropdown der aktivierten Locales, von denen jede auf die aktuelle Seite in dieser Locale verlinkt."
---

`<i18n-switcher>` rendert einen Button mit der aktiven Locale und ein Dropdown aller aktivierten Locales, einschließlich der aktiven. Verwenden Sie die Komponente für ein fertiges Sprachmenü; bauen Sie Ihr eigenes aus [`$getLocales`](/de/api/methods#$getlocales) und [`$switchLocalePath`](/de/api/methods#$switchlocalepath), wenn Sie anderes Markup benötigen. Jeder Eintrag verlinkt auf die aktuelle Seite in der jeweiligen Locale.

## Props und Slots {#props-and-slots}

| Prop | Typ | Standard | Beschreibung |
| --- | --- | --- | --- |
| `customLabels` | `Record<string, string>` | `() => ({})` | Anzeigename pro Locale-Code; überschreibt den `displayName` aus der Locale-Konfiguration. |
| `customWrapperStyle` | `CSSProperties` | `() => ({})` | Inline-Stil für den äußeren Wrapper. |
| `customButtonStyle` | `CSSProperties` | `() => ({})` | Inline-Stil für den Button, der das Dropdown öffnet. |
| `customDropdownStyle` | `CSSProperties` | `() => ({})` | Inline-Stil für das Dropdown-Panel. |
| `customItemStyle` | `CSSProperties` | `() => ({})` | Inline-Stil für jeden Eintrag im Dropdown. |
| `customLinkStyle` | `CSSProperties` | `() => ({})` | Inline-Stil für den Link innerhalb eines Eintrags. |
| `customActiveLinkStyle` | `CSSProperties` | `() => ({})` | Inline-Stil für den Link der aktuell aktiven Locale. |
| `customDisabledLinkStyle` | `CSSProperties` | `() => ({})` | Inline-Stil für den Button der *aktuellen* Locale, wenn sie in der Konfiguration `disabled: true` ist. |
| `customIconStyle` | `CSSProperties` | `() => ({})` | Inline-Stil für das Pfeilsymbol auf dem Button. |

### Slots {#slots}

| Slot | Bindings | Beschreibung |
| --- | --- | --- |
| `before-button` | — | Inhalt vor dem Button, der das Dropdown öffnet. |
| `before-selected-locale` | — | Inhalt vor der Beschriftung der aktiven Locale im Button. |
| `after-selected-locale` | — | Inhalt nach der Beschriftung der aktiven Locale im Button. |
| `before-dropdown` | — | Inhalt zwischen dem Button und dem Dropdown-Panel. |
| `before-dropdown-items` | — | Inhalt oben im Dropdown, über der Locale-Liste. |
| `before-item` | `locale` | Inhalt vor jedem Locale-Eintrag. |
| `before-link-content` | `locale` | Inhalt vor der Beschriftung einer Locale innerhalb ihres Links. |
| `after-link-content` | `locale` | Inhalt nach der Beschriftung einer Locale innerhalb ihres Links. |
| `after-item` | `locale` | Inhalt nach jedem Locale-Eintrag. |
| `after-dropdown-items` | — | Inhalt unten im Dropdown, unter der Locale-Liste. |
| `after-dropdown` | — | Inhalt nach dem Dropdown-Panel. |

## Verhalten {#behaviour}

- Listet jede Locale ohne `disabled: true` auf, einschließlich der aktiven.
- Jeder Eintrag ist ein `<a>` auf `$switchLocalePath(code)`. Ein Pfad wird unter `app.baseURL` aufgelöst; eine Locale-`baseUrl` auf einer anderen Domain bleibt absolut. Der Link hat `hreflang` und `lang` auf `iso || code` gesetzt, `dir`, wenn die Locale eines hat, `aria-current="page"` bei der aktuellen Locale und die Klasse `switcher-locale-<code>`. Ein Klick ruft `$switchLocale(code)` auf und schließt das Dropdown; mit einer Modifikatortaste wird er dem Browser überlassen.
- Die Liste bleibt versteckt im Server-HTML, sodass Crawler die Links sehen. Escape oder ein Klick außerhalb schließt sie.
- Beschriftung: `customLabels[code]`, dann der `displayName` der Locale, dann der Code (mit einer Warnung in der Entwicklung).
- Stile: kleine Inline-Standardwerte (umrandeter weißer Button und Panel, der aktive Eintrag fett und blau). Jede `custom*Style`-Prop wird nach dem Standardwert ihres Teils angewendet. Der Button hat die Klassen `i18n-switcher-button` und `language-switcher`, der Wrapper `i18n-switcher-wrapper`, die Liste `i18n-switcher-dropdown`. Positionen verwenden logische CSS-Eigenschaften, daher funktioniert `dir="rtl"`.

## Beispiel {#example}

```vue
<template>
  <i18n-switcher
    :custom-labels="{ en: 'English', de: 'Deutsch' }"
    :custom-button-style="{ borderRadius: '4px' }"
  >
    <template #before-link-content="{ locale }">
      <img :src="`/flags/${locale.code}.svg`" alt="" width="16" />
    </template>
  </i18n-switcher>
</template>
```
