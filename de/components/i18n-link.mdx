---
title: "<i18n-link>"
description: "Die Komponente <i18n-link> ist ein NuxtLink zur Route in der aktiven Locale; externe URLs öffnen sich in einem neuen Tab."
---

`<i18n-link>` rendert einen `NuxtLink` zu `to` in der aktiven Locale. Verwenden Sie sie in Templates anstelle von `<NuxtLink :to="$localePath(...)">`. Eine externe URL wird zu einem einfachen `<a target="_blank" rel="noopener noreferrer">`.

## Props {#props}

| Prop | Typ | Standard | Beschreibung |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | Zielroute. Wird automatisch lokalisiert; eine externe URL wird unverändert durchgereicht. |
| `activeStyle` | `CSSProperties` | — | Inline-Style, der angewendet wird, solange der Link auf die aktuelle Route zeigt. |

**\*** erforderlich.

### Slots {#slots}

| Slot | Bindings | Beschreibung |
| --- | --- | --- |
| `default` | — | Link-Inhalt. |

## Verhalten {#behaviour}

- `to` durchläuft [`$localePath`](/de/api/methods#$localepath): ein Pfad, eine benannte Route oder ein Route-Objekt, wobei benutzerdefinierte Locale-Pfade angewendet werden.
- Extern: ein String, der mit `http://`, `https://` oder `//` beginnt, eine reine Domain (`example.com`) oder ein `tel:`- / `mailto:`-Link. Eine reine Domain erhält `https://`, und jeder String ohne Schrägstrich, der Punkte enthält, zählt als solche: Schreiben Sie eine lokale Datei als `/report.pdf`, nicht als `report.pdf`.
- Aktiv: Wenn der aktuelle `route.path` dem lokalisierten Pfad entspricht (Query und Hash werden ignoriert), wird `activeStyle` angewendet. Es gibt keine Active-Klasse und keinen Standard-Active-Style.
- Andere Attribute (`class`, `aria-*`) werden an den Link durchgereicht.

## Beispiel {#example}

```vue
<template>
  <i18n-link to="/about" :active-style="{ fontWeight: 'bold' }">{{ $t('nav.about') }}</i18n-link>
  <i18n-link :to="{ name: 'blog-slug', params: { slug: 'hello' } }">{{ $t('nav.post') }}</i18n-link>
  <i18n-link to="https://github.com/s00d/nuxt-i18n-micro">GitHub</i18n-link>
</template>
```
