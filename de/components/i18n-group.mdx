---
title: "<i18n-group>"
description: "Die Komponente <i18n-group> stellt ihrem Slot eine t-Funktion bereit, die auf ein Schlüsselpräfix beschränkt ist."
---

`<i18n-group>` beschränkt einen Markup-Block auf ein Schlüsselpräfix. Verwenden Sie sie, wenn viele Schlüssel eines Abschnitts dasselbe Präfix teilen und Sie es nicht wiederholen möchten. Der Default-Slot erhält ein `t`, das das Präfix voranstellt.

## Props und Slot {#props-and-slot}

| Prop | Typ | Standard | Beschreibung |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | Schlüsselpräfix, gegen das jede Suche innerhalb des Slots aufgelöst wird. |
| `groupClass` | `string` | `''` | Zusätzliche Klasse am Wrapper-Element. |

**\*** erforderlich.

### Slots {#slots}

| Slot | Bindings | Beschreibung |
| --- | --- | --- |
| `default` | `prefix`, `t` | Erhält `prefix` und eine darauf beschränkte `t`-Funktion. |

## Verhalten {#behaviour}

- Rendert `<div class="i18n-group {groupClass}">` um den Slot.
- `t(key, params)` entspricht `$t(prefix + '.' + key, params)` für die aktuelle Route.
- Nur das `t` des Slots ist beschränkt: `$t` und verschachtelte `<i18n-t>` innerhalb der Gruppe erwarten weiterhin vollständige Schlüssel.

## Beispiel {#example}

```json
{
  "checkout": { "title": "Checkout", "items": "Items: {count}" }
}
```

```vue
<template>
  <i18n-group prefix="checkout" group-class="checkout">
    <template #default="{ t }">
      <h2>{{ t('title') }}</h2>
      <p>{{ t('items', { count: 3 }) }}</p>
    </template>
  </i18n-group>
</template>
```
