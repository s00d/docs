# 📚 Beispiele und Verwendung von Nuxt I18n Micro

Dieser Abschnitt enthält verschiedene Beispiele, die zeigen, wie Sie `Nuxt I18n Micro` in Ihrer Nuxt.js-Anwendung einsetzen können. Sie erfahren, wie Sie Locales wechseln, die Komponenten `<i18n-link>`, `<i18n-switcher>` und `<i18n-t>` verwenden und Übersetzungsschlüssel dynamisch handhaben.

## 🛠️ Grundlegende Einrichtung

Hier ist eine grundlegende Einrichtung, um mit `Nuxt I18n Micro` zu starten:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Locale-Wechsel

### Locales programmatisch wechseln

Dieses Beispiel zeigt, wie Locales programmatisch über Schaltflächen gewechselt werden können:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Beispiel-JSON für Locale-Wechsel

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### Verwendung der Komponente `<i18n-switcher>`

Die Komponente `<i18n-switcher>` bietet ein Dropdown zum Wechseln der Locale mit anpassbaren Beschriftungen:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 🌐 `<i18n-link>` für lokalisierte Navigation verwenden

Die Komponente `<i18n-link>` verarbeitet locale-spezifisches Routing automatisch:

```vue
<template>
  <div>
    <i18n-link to="/about">{{ $t('about') }}</i18n-link>
    <i18n-link :to="{ name: 'index' }">{{ $t('home') }}</i18n-link>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Beispiel-JSON für Navigationslinks

```json
{
  "about": "About Us",
  "home": "Home"
}
```

### Beispiel mit Styling für aktive Links

```vue
<template>
  <div>
    <i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
  </div>
</template>
```

### Beispiel-JSON für Styling aktiver Links

Für dieses Szenario kann dieselbe JSON-Datei wie im vorherigen Beispiel verwendet werden.

## 📝 Dynamische Schlüssel aus Übersetzungsdateien rendern

In manchen Fällen möchten Sie dynamische Schlüssel, die in Ihren Übersetzungsdateien gespeichert sind, iterieren und deren Werte bedingt rendern. Das folgende Beispiel zeigt, wie das mit `Nuxt I18n Micro` gelingt.

### Beispiel: Dynamische Schlüssel rendern

Dieses Beispiel holt ein Array von Schlüsseln aus einem bestimmten Übersetzungspfad (hier `dynamic`) und iteriert darüber. Vor dem Rendern des Werts mit `$t` wird die Existenz jedes Schlüssels über `$has` geprüft.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Beispielhafte Übersetzungsdatei (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Beispiel: Dynamische Schlüssel aus einem Objekt rendern

In diesem Beispiel behandeln wir ein Objekt, das in Ihrer Übersetzungsdatei gespeichert ist. Wir iterieren über die Schlüssel des Objekts und rendern sowohl die Schlüsselnamen als auch die zugehörigen Werte dynamisch.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Beispielhafte Übersetzungsdatei (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 `<i18n-t>` für Übersetzungen mit Slots und Interpolation verwenden

Die Komponente `<i18n-t>` eignet sich hervorragend, um Übersetzungen mit dynamischen Inhalten und HTML-Tags zu rendern:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### Beispiel-JSON für `<i18n-t>`

```json
{
  "greeting": "Welcome to the page"
}
```

### Mit Interpolation

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### Beispiel-JSON für Interpolation

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 `$tc` für Pluralisierung verwenden

Die Funktion `$tc` in `Nuxt I18n Micro` behandelt Pluralisierung basierend auf Anzahl und Locale-Einstellungen. Das ist nützlich, um Meldungen dynamisch anzupassen, die Mengenangaben enthalten – etwa Artikel, Benachrichtigungen oder andere zählbare Einheiten.

### Beispiel: `$tc` für Pluralisierung

Im folgenden Beispiel zeigen wir eine Meldung, die die Anzahl der Äpfel angibt. Der Übersetzungsschlüssel unterstützt mehrere Pluralformen abhängig von der übergebenen Anzahl.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### Beispiel-JSON für Pluralisierung

So können Sie die Übersetzung in Ihrer JSON-Datei definieren, um unterschiedliche Pluralformen zu unterstützen:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Erläuterung

- **`$tc('apples', 0)`**: Gibt die erste Form zurück, verwendet für die Anzahl null (`"no apples"`).
- **`$tc('apples', 1)`**: Gibt die zweite Form zurück, verwendet für die Anzahl eins (`"one apple"`).
- **`$tc('apples', 10)`**: Gibt die dritte Form mit dem Zählwert zurück, verwendet für zwei oder mehr (`"10 apples"`).

### Zusätzliches Beispiel mit komplexerer Pluralisierung

Wenn Ihre Anwendung komplexere Pluralregeln unterstützen muss (z. B. spezielle Fälle für null, eins, zwei, wenige, viele, andere), können Sie die Übersetzungs-Strings entsprechend erweitern:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: Könnte so eingerichtet werden, dass `"two apples"` zurückgegeben wird.
- **`$tc('apples', 3)`**: Könnte `"a few apples"` zurückgeben, je nach den definierten Regeln.

## 🌐 `$tn` für Zahlenformatierung verwenden

Die Funktion `$tn` formatiert Zahlen gemäß der aktuellen Locale mithilfe der `Intl.NumberFormat`-API. Das ist nützlich, um Zahlen so darzustellen, wie es den regionalen Einstellungen des Nutzers entspricht – etwa Währungen, Prozentsätze oder andere Zahlenformate.

### Beispiel: `$tn` für Zahlenformatierung

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ `$td` für Datums- und Uhrzeitformatierung verwenden

Die Funktion `$td` formatiert Datums- und Uhrzeitangaben gemäß der aktuellen Locale mithilfe der `Intl.DateTimeFormat`-API. Das ist praktisch, um Daten und Zeiten in Formaten anzuzeigen, die dem Nutzer je nach Locale vertraut sind.

### Beispiel: `$td` für Datums- und Uhrzeitformatierung

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ `$tdr` für relative Datumsformatierung verwenden

Die Funktion `$tdr` formatiert Daten als relative Zeitangaben (z. B. „vor 5 Minuten“, „vor 2 Tagen“) gemäß der aktuellen Locale mithilfe der `Intl.RelativeTimeFormat`-API. Das ist nützlich, um Zeitunterschiede relativ zum aktuellen Datum und Uhrzeit darzustellen.

### Beispiel: `$tdr` für relative Datumsformatierung

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
