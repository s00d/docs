# 📚 Beispiele und Verwendung von Nuxt I18n Micro

Dieser Abschnitt enthält verschiedene Beispiele, die zeigen, wie du `Nuxt I18n Micro` in deiner Nuxt.js-Anwendung einsetzt. Du siehst, wie du Locales wechselst, die Komponenten `<i18n-link>`, `<i18n-switcher>` und `<i18n-t>` verwendest und Übersetzungsschlüssel dynamisch handhabst.

## 🛠️ Grundkonfiguration

Hier ist eine grundlegende Konfiguration, um mit `Nuxt I18n Micro` zu starten:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Sprachwechsel

### Locales programmatisch wechseln

Dieses Beispiel zeigt, wie du Locales programmatisch über Schaltflächen wechselst:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Beispiel-JSON für den Sprachwechsel

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### Verwendung der Komponente `<i18n-switcher>`

Die Komponente `<i18n-switcher>` stellt ein Dropdown zum Sprachwechsel mit anpassbaren Beschriftungen bereit:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 🌐 `<i18n-link>` für lokalisierte Navigation verwenden

Die Komponente `<i18n-link>` übernimmt automatisch das locale-spezifische Routing:

```vue
<template>
  <div>
    <i18n-link to="/about">{{ $t('about') }}</i18n-link>
    <i18n-link :to="{ name: 'index' }">{{ $t('home') }}</i18n-link>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Beispiel-JSON für Navigationslinks

```json
{
  "about": "About Us",
  "home": "Home"
}
```

### Beispiel mit Styling für aktive Links

```vue
<template>
  <div>
    <i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
  </div>
</template>
```

### Beispiel-JSON für Styling aktiver Links

Für dieses Szenario kann dieselbe JSON-Datei wie im vorherigen Beispiel verwendet werden.

## 📝 Dynamische Schlüssel aus Übersetzungsdateien rendern

In manchen Fällen möchtest du über dynamische Schlüssel in deinen Übersetzungsdateien iterieren und deren Werte bedingt rendern. Das folgende Beispiel zeigt, wie du das mit `Nuxt I18n Micro` erreichst.

### Beispiel: Dynamische Schlüssel rendern

Dieses Beispiel holt ein Array von Schlüsseln aus einem bestimmten Übersetzungspfad (in diesem Fall `dynamic`) und iteriert darüber. Die Existenz jedes Schlüssels wird mit `$has` geprüft, bevor sein Wert mit `$t` gerendert wird.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Beispiel-Übersetzungsdatei (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Beispiel: Dynamische Schlüssel aus einem Objekt rendern

In diesem Beispiel behandeln wir ein Objekt, das in deiner Übersetzungsdatei gespeichert ist. Wir holen die Schlüssel des Objekts und iterieren darüber, wobei sowohl die Namen der Schlüssel als auch deren zugehörige Werte dynamisch gerendert werden.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Beispiel-Übersetzungsdatei (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 `<i18n-t>` für Übersetzungen mit Slots und Interpolation verwenden

Die Komponente `<i18n-t>` eignet sich zum Rendern von Übersetzungen mit dynamischem Inhalt und HTML-Tags:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### Beispiel-JSON für `<i18n-t>`

```json
{
  "greeting": "Welcome to the page"
}
```

### Mit Interpolation

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### Beispiel-JSON für Interpolation

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 `$tc` für Pluralisierung verwenden

Die Funktion `$tc` in `Nuxt I18n Micro` übernimmt die Pluralisierung basierend auf Anzahl und Locale-Einstellungen. Das ist nützlich, um Meldungen, die Anzahlen enthalten, dynamisch anzupassen, etwa Elemente, Benachrichtigungen oder andere Entitäten, deren Anzahl variieren kann.

### Beispiel: `$tc` für Pluralisierung

Im folgenden Beispiel geben wir eine Nachricht aus, die die Anzahl der Äpfel mithilfe von `$tc` angibt. Der Übersetzungsschlüssel behandelt mehrere Pluralformen abhängig von der übergebenen Anzahl.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### Beispiel-JSON für Pluralisierung

So kannst du die Übersetzung in deiner JSON-Datei definieren, um verschiedene Pluralformen abzudecken:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Erklärung

- **`$tc('apples', 0)`**: Gibt die erste Form zurück, verwendet bei Anzahl null (`"no apples"`).
- **`$tc('apples', 1)`**: Gibt die zweite Form zurück, verwendet bei Anzahl eins (`"one apple"`).
- **`$tc('apples', 10)`**: Gibt die dritte Form zusammen mit dem Wert zurück, verwendet bei Anzahl zwei oder mehr (`"10 apples"`).

### Weiteres Beispiel mit komplexeren Pluralregeln

Wenn deine Anwendung komplexere Pluralregeln behandeln muss (z. B. spezifische Fälle für null, eins, zwei, wenige, viele, andere), kannst du die Übersetzungs-Strings entsprechend erweitern:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: Könnte so eingerichtet werden, dass `"two apples"` zurückgegeben wird.
- **`$tc('apples', 3)`**: Könnte `"a few apples"` zurückgeben, je nach den für die Anzahl definierten Regeln.

## 🌐 `$tn` für Zahlenformatierung verwenden

Die Funktion `$tn` formatiert Zahlen entsprechend der aktuellen Locale über die API `Intl.NumberFormat`. Das ist nützlich, um Zahlen so anzuzeigen, dass sie den regionalen Einstellungen des Nutzers entsprechen, etwa Währungen, Prozentsätze oder andere Zahlenformate.

### Beispiel: `$tn` für Zahlenformatierung

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ `$td` für Datums- und Zeitformatierung verwenden

Die Funktion `$td` formatiert Datums- und Zeitangaben entsprechend der aktuellen Locale über die API `Intl.DateTimeFormat`. Das ist nützlich, um Datums- und Zeitangaben in Formaten anzuzeigen, die dem Nutzer basierend auf seinen Locale-Einstellungen vertraut sind.

### Beispiel: `$td` für Datums- und Zeitformatierung

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ `$tdr` für relative Datumsformatierung verwenden

Die Funktion `$tdr` formatiert Datumsangaben als relative Zeiten (z. B. „vor 5 Minuten", „vor 2 Tagen") entsprechend der aktuellen Locale über die API `Intl.RelativeTimeFormat`. Das ist nützlich, um Zeitdifferenzen relativ zum aktuellen Datum und zur aktuellen Uhrzeit anzuzeigen.

### Beispiel: `$tdr` für relative Datumsformatierung

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
