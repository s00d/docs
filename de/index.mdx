---
title: "Nuxt I18n Micro"
description: "Kleines, schnelles i18n für Nuxt: JSON-Übersetzungen pro Seite, zur Build-Zeit lokalisierte Routen, SEO-Tags ab Werk."
---

Nuxt I18n Micro ist ein leichtgewichtiges, hochperformantes i18n-Modul für Nuxt 3 und 4, das für große Projekte konzipiert ist. Im Vergleich zu traditionellen i18n-Lösungen wie `@nuxtjs/i18n` hält es Build-Zeiten, Speicherverbrauch und Bundle-Größe gering.

Lokalisierte Routen werden zur Build-Zeit von `@i18n-micro/route-strategy` erzeugt und zur Laufzeit von `@i18n-micro/path-strategy` aufgelöst, sodass Links, der Switcher, `hreflang` und Redirects alle mit dem Router übereinstimmen. Übersetzungen sind ausschließlich JSON, aufgeteilt in gemeinsame Root-Dateien und seitenbezogene Dateien, die der Dev-Server für Sie anlegt, mit integriertem HMR.

<CodeGroup>

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>
