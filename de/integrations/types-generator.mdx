---
title: "Typgenerator"
description: "TypeScript-Autovervollständigung für Übersetzungsschlüssel aus deinen JSON-Dateien erzeugen, in Nuxt oder jedem Vite-Projekt."
---

`@i18n-micro/types-generator` liest jede JSON-Datei in deinem Übersetzungsordner und schreibt eine Deklaration, die alle Schlüssel auflistet. Füge es hinzu, wenn dein Editor Schlüssel in `t()`, `$t()` und `<I18nT keypath>` vorschlagen soll. Es funktioniert als Nuxt-Modul sowie als Vite- oder Rollup-Plugin und generiert neu, wenn sich eine Datei ändert.

## Installation {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/types-generator
```

```bash npm
npm install -D @i18n-micro/types-generator
```

```bash yarn
yarn add -D @i18n-micro/types-generator
```

</CodeGroup>

Peer-Abhängigkeit: `@nuxt/kit` `^3.18.0 || ^4.0.0`. Nur der Einstiegspunkt `/nuxt` importiert sie; in einem reinen Vite-Projekt kann die Peer-Warnung ignoriert werden.

## Nuxt {#nuxt}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro', '@i18n-micro/types-generator/nuxt'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Das Modul schreibt `.nuxt/types/i18n-micro.d.ts`, und Nuxt fügt die Datei dem Typkontext hinzu; manuell einbinden musst du nichts. Es liest `i18nTypes.translationDir`, ansonsten dort, wo `nuxt-i18n-micro` Übersetzungen liest: `translationDir` (aus `i18n` oder Inline-Moduloptionen, Standard `'locales'`) in jedem Layer sowie `additionalTranslationDirs`. Das Bearbeiten einer JSON-Datei in diesem Ordner generiert die Typen in `nuxi dev` neu. `i18nTypes.outputFile` wird in Nuxt ignoriert (eine Warnung weist darauf hin).

## Vite {#vite}

`I18nTypesPlugin` ist ein Vite-Plugin, das auch Rollup akzeptiert. Für einen anderen Bundler rufe `generateTypes` in einem Skript auf.

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { I18nTypesPlugin } from '@i18n-micro/types-generator'

export default defineConfig({
  plugins: [
    vue(),
    I18nTypesPlugin({
      srcDir: process.cwd(),
      translationDir: 'src/locales',
      outputFile: 'src/i18n-micro.d.ts',
    }),
  ],
})
```

| Option | Erforderlich | Hinweise |
| --- | --- | --- |
| `srcDir` | ja | Basisverzeichnis; `translationDir` wird relativ dazu aufgelöst. |
| `translationDir` | ja | Ordner mit den JSON-Dateien (inklusive Unterordnern wie `pages/`) oder ein Array von Ordnern. |
| `outputFile` | nein | Wohin die Deklaration geschrieben wird; Standard `<srcDir>/i18n-micro.d.ts`. |

Das Plugin generiert einmal beim Build-Start und auf dem Dev-Server 300 ms nach einer Änderung im Ordner neu. Stelle sicher, dass `include` in deiner `tsconfig.json` die Ausgabedatei abdeckt.

## Schlüssel verwenden {#use-the-keys}

Die generierte Datei erweitert `DefineLocaleMessage` in `@i18n-micro/types`, wodurch `TranslationKey` zu deinen Schlüsseln wird:

```ts
declare module '@i18n-micro/types' {
  export interface DefineLocaleMessage {
    nav: object
    'nav.home': string
    'profile.title': string
  }
}
```

Die Schlüssel sind diejenigen, auf die `t()` antwortet, auch Objekte, aus jeder Locale und jeder Seitendatei, mit dem Typ ihres JSON-Werts. `TranslationKey` ist die Vereinigung dieser Schlüssel plus jeden Strings. Du bekommst also Autovervollständigung, keine Fehler: Ein falsch geschriebener oder dynamischer Schlüssel kompiliert trotzdem. Parameter und Rückgabewerte sind nicht typisiert.

Für dynamische Schlüssel unter einem bekannten Präfix schränkt `ScopedKey<'prefix'>` auf die passenden Schlüssel ein:

```ts
import type { ScopedKey } from '@i18n-micro/types'

const statusText = (status: string) => t(`status.${status}` as ScopedKey<'status'>)
```

`TranslationKey` und `ScopedKey` stammen aus `@i18n-micro/types` (React, Preact und Solid re-exportieren `TranslationKey`; Vue nicht).

## API {#api}

| Export | Einstiegspunkt | Hinweise |
| --- | --- | --- |
| `I18nTypesPlugin(options)` | `@i18n-micro/types-generator` | Vite- und Rollup-Plugin |
| `generateTypes(options)` | `@i18n-micro/types-generator` | schreibt die Datei, gibt ihren Pfad zurück |
| `getTypesString(options)` | `@i18n-micro/types-generator` | gibt die Deklaration zurück, ohne zu schreiben |
| `formatKeyProperty(key)` | `@i18n-micro/types-generator` | Hilfsfunktion |
| Nuxt-Modul (`configKey: 'i18nTypes'`) | `@i18n-micro/types-generator/nuxt` | Option `translationDir` |

Vollständige Signaturen: [Paketreferenz](/de/api/packages/types-generator).
