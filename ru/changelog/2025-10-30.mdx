**Дата**: 2025-10-30

**Версия**: `v2.0.0`

![Выпуск v2.0.0](/images/2.0.0.png)

Мы представляем серверный HMR для файлов переводов в режиме разработки. Когда JSON-файл перевода меняется, серверный кэш инвалидирует только затронутые ключи, и последующие запросы сразу получают свежие данные — без перезапусков.

## Что нового? {#what’s-new}

- Серверный HMR для файлов переводов
- Мгновенная инвалидация кэша для каждой страницы/локали
- Комфортная работа при редактировании контента

## Как это работает {#how-it-works}

- Наблюдатель в `src/runtime/server/plugins/watcher.dev.ts` отслеживает `<rootDir>/<translationDir>/**/*.json`
- Файлы страниц (например, `pages/<page>/<locale>.json`) инвалидируют `_locales:merged:<page>:<locale>`
- Файлы корневого уровня (например, `<locale>.json`) инвалидируют все объединённые ключи этой локали
- Регистрируется автоматически из `src/module.ts` в режиме разработки, когда `experimental.hmr !== false`

## Конфигурация {#configuration}

```ts
export default defineNuxtConfig({
  i18n: {
    experimental: { hmr: true }, // default in dev
  },
})
```
