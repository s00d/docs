Релизы: **v3.22.0 → v3.26.0**.

## Новые возможности

- **API памяти переводов.** Считывайте и патчьте словарь активной локали в рантайме через `$resolveTranslations()` и `$setTranslation(key, value)`. Полезно для DevTools, тестов и встроенных редакторов. См. [Методы](/api/methods#resolvetranslations).
- **Именованные `numberFormats` и `datetimeFormats`.** Настраивайте совместимые с Vue I18n именованные форматы для каждой локали, а затем вызывайте `$tn(1000, 'currency')` или `$td(date, 'short')`. См. [Опции модуля](/api/module-options).
- **HTTP cache control для payload'ов `/_locales`.** Новая опция [`httpCacheDuration`](/api/module-options) устанавливает `Cache-Control: public, max-age=…, immutable` для payload'ов переводов. По умолчанию год, безопасно сочетается с cache-busting через `?v={dateBuild}`.
- **Сжатие payload'ов переводов.** Когда включена `nitro.compressPublicAssets`, публичные payload'ы переводов сжимаются автоматически. См. [Руководство по производительности](/guides/performance).
- **Утилита `splitLocaleRoutes`.** Собирайте `pages` и `globalLocaleRoutes` из единого программного списка (для сценариев `pages:extend`), с ключами по имени маршрута. См. [Пользовательские маршруты локалей](/guides/custom-locale-routes#programmatic-routes-pagesextend--244).
- **Fallback `site.url` для базового URL SEO.** Если `metaBaseUrl` не задан, SEO-теги подставляют `site.url` из `nuxt-site-config`, если он присутствует, иначе — origin запроса. См. [`metaBaseUrl`](/api/module-options).

## Обновления

- **Адаптер Astro.** Изоляция routing-контекста и подключение `numberFormats` и `datetimeFormats`.
- **React и Preact.** `I18nSwitcher` теперь корректно выставляет атрибуты `aria-haspopup` и `aria-expanded`.
- **Бенчмарки.** Бенчмарки производительности перенесены в CLI на базе citty.
- **Контентный отпечаток `dateBuild`.** По умолчанию `dateBuild` теперь является контентным отпечатком, поэтому `?v=` у payload'а меняется только при реальных изменениях переводов.

## Исправления

- **Роутинг.**
  - Матчеры локализованных маршрутов теперь корректно обрабатывают пути с дефисами, вложенные пути и параметризованные сегменты.
  - Вложенные родители сохраняются, когда дочерний маршрут абсолютный.
  - `hreflang` выставляется из `iso` локали, а не из кода роутинга.
  - Переключение локали при `no_prefix` теперь заменяет запись в истории вместо push.
- **Редиректы.**
  - `autoDetectPath` учитывается для редиректов по cookie и по предпочтению `Accept-Language`.
  - Алиасы `localeRoutes` сохраняются при `autoDetectPath: '/'`.
- **Переводы.**
  - Пользовательские функции множественного числа, возвращающие `null`, теперь корректно откатываются на правило по умолчанию.
  - Слои переводов сливаются без разворачивания дампов.
  - Отключённые локали не попадают в предварительно смёрженные публичные payload'ы.
  - HMR пропускает бесполезные записи файлов и параллельно пересобирает merge при изменении корневой локали.
- **Switcher.** Скрывает `disabled` локали и восстанавливает приоритет `customDisabledLinkStyle` и active-style.
- **Модуль.** Пробросил типы `Plugin` из unplugin Vite 8 для совместимости с Nuxt Kit.
- **SSR.** Node SSR теперь читает из публичных payload'ов (без Rollup-импорта `raw:`).

## Ломающие изменения (v3.22.0)

- SSR-чанки перенесены из `useState('i18n-ssr-chunks')` в `nuxtApp.payload.data['i18n-ssr-chunks']`.
- `getAllTranslations()` удалён из `@i18n-micro/vue`. Используйте `resolveTranslations()`, `getStorage()` или `getRouteCache()`.
- По умолчанию `dateBuild` теперь контентный отпечаток, так что при апгрейде `?v=` у payload'а изменится один раз.
