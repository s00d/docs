В этом выпуске появился **`useI18nHead`** — composable уровня страницы для переопределения i18n SEO поверх встроенного плагина `02.meta`. Настраивайте `hreflang`, canonical, `og:url` и теги Open Graph для каждого маршрута без собственного meta-плагина и без `meta: false`.

## Что нового? {#what’s-new}

### Composable `useI18nHead` {#usei18nhead-composable}

Вызывайте `useI18nHead` на любой странице, когда `meta: true` (по умолчанию). Модуль объединяет ваши данные с результатом `useLocaleHead` при каждом обновлении маршрута:

```vue
<script setup lang="ts">
useI18nHead(() => ({
  meta: [{ property: 'og:title', content: article.value?.title }],
  replace: {
    canonical: article.value?.canonicalUrl,
    ogUrl: article.value?.canonicalUrl,
    hreflang: localeCodes.map((locale) => ({
      rel: 'alternate',
      hreflang: locale,
      href: article.value!.locales[locale]!,
    })),
    ogAlternates: localeCodes,
  },
}))
</script>
```

Поддерживаются статические объекты, реактивные геттеры, добавление `meta` / `link`, `replace` для встроенных групп и `disable` для удаления автоматически сгенерированных тегов. См. [`useI18nHead`](/ru/composables/useI18nHead).

### Утилита `mergeI18nHead` (`@i18n-micro/utils`) {#mergei18nhead-utility-@i18n-micro/utils}

Независимая от фреймворка логика слияния находится в `@i18n-micro/utils/merge-i18n-head` — её использует плагин `02.meta`, и её можно тестировать изолированно. Типы (`I18nHeadInput`, `I18nHeadLink`, `I18nHeadMeta`) экспортируются из `@i18n-micro/types`.

### Интеграция с плагинами {#plugin-integration}

- **`02.meta`** — объединяет результат `useLocaleHead` с состоянием страницы из `useI18nHead` через `useHead`
- **`01.plugin`** — сбрасывает переопределения страницы при смене имени маршрута через `resetPageHead()` (общее состояние с composable)

## Типичные сценарии использования {#typical-use-cases}

| Сценарий                                     | Подход                                                         |
| -------------------------------------------- | -------------------------------------------------------------- |
| Блог/CMS с частичными переводами             | `replace.hreflang` + `replace.ogAlternates` из локалей API     |
| Собственный canonical из CMS                 | `replace.canonical` + `replace.ogUrl`                          |
| Только OG для лендинга                       | `meta: [{ property: 'og:title', ... }]` — hreflang модуля сохраняется |
| Без hreflang на странице                     | `disable: ['hreflang', 'x-default']`                           |
| Замена собственного плагина (`i18nManualHreflang`) | `useI18nHead` на каждой странице контента + `meta: true` |

**JSON-LD** остаётся в `useHead({ script: [...] })` — `useI18nHead` не генерирует структурированные данные.

## Критические изменения {#breaking-changes}

Нет для стандартного использования `nuxt.config`. Новый composable и подпуть utils только добавляют функциональность.

## Почему это важно {#why-it-matters}

- **Без собственного meta-плагина** для записей CMS, новостей или руководств с URL для каждой локали
- **Единый конвейер** — значения модуля по умолчанию и переопределения страницы в одном вызове `useHead`
- **Типобезопасность** — `I18nHeadInput` для хелперов вроде `buildArticleHead(content)`

Полный список изменений будет опубликован вместе с выпуском на [GitHub](https://github.com/s00d/nuxt-i18n-micro/blob/main/CHANGELOG.md).
