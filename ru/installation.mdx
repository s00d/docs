## Требования

- **Node.js**: 18 или новее.
- **Nuxt**: 3.x или 4.x.

Модуль поддерживает раскладку проекта Nuxt 3 (`pages/**/*.vue`) и раскладку Nuxt 4 (`app/pages/**/*.vue`). Переводы по договорённости располагаются в корне проекта (`locales/`), даже если вы используете каталог `app/` из Nuxt 4.

## Установка модуля Nuxt

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Зарегистрируйте его в `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Полный разбор см. в [Быстром старте](/quickstart), а перечень всех опций — в [Справочнике по конфигурации](/guides/configuration).

## Структура проекта

По умолчанию модуль ожидает следующую структуру:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Корневые файлы объединяются с файлами конкретных страниц на этапе сборки. Файлы для отдельных страниц автоматически создаются во время `nuxt dev`, если их нет.

## Раскладка Nuxt 4

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Чтобы разместить переводы внутри `app/`, задайте `translationDir: 'app/locales'`.

## Пакеты экосистемы

| Пакет | Назначение |
| --- | --- |
| [`@i18n-micro/vue`](/integrations/vue) | Интеграция с Vue 3 (отдельно, без Nuxt). |
| [`@i18n-micro/react`](/integrations/react) | Интеграция с React. |
| [`@i18n-micro/preact`](/integrations/preact) | Интеграция с Preact. |
| [`@i18n-micro/solid`](/integrations/solid) | Интеграция с SolidJS. |
| [`@i18n-micro/astro`](/integrations/astro) | Интеграция с Astro. |
| [`@i18n-micro/node`](/integrations/nodejs) | Серверный загрузчик для Node.js. |
| [`@i18n-micro/types-generator`](/integrations/types-generator) | Генерация типов TypeScript из файлов переводов. |
| [`@i18n-micro/devtools-ui`](/integrations/devtools-ui) | Панель DevTools, не зависящая от фреймворка. |

Общие внутренние пакеты подтягиваются транзитивно.

## TypeScript

Модуль генерирует ambient-типы для `useI18n`, `$t` и связанных хелперов на основе файлов локали по умолчанию. Это включено по умолчанию (`types: true`).

Для более строгой типизации ключей переводов см. [`@i18n-micro/types-generator`](/integrations/types-generator).
