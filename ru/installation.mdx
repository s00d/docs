## Требования

- **Node.js**: 18 или новее.
- **Nuxt**: 3.x или 4.x.

Модуль поддерживает как структуру проекта Nuxt 3 (`pages/**/*.vue`), так и структуру Nuxt 4 (`app/pages/**/*.vue`). По соглашению переводы располагаются в корне проекта (`locales/`), даже при использовании директории `app/` в Nuxt 4.

## Установка модуля Nuxt

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Зарегистрируйте его в `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Полное пошаговое руководство смотрите в разделе [Быстрый старт](/quickstart), а описание всех параметров — в [Справочнике по конфигурации](/guides/configuration).

## Структура проекта

По умолчанию модуль ожидает следующую структуру:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Файлы корневого уровня объединяются с каждым файлом конкретной страницы на этапе сборки. Файлы, относящиеся к странице, создаются автоматически при их отсутствии во время `nuxt dev`.

## Структура Nuxt 4

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Чтобы разместить переводы внутри `app/`, установите `translationDir: 'app/locales'`.

## Пакеты экосистемы

| Пакет | Назначение |
| --- | --- |
| [`@i18n-micro/vue`](/integrations/vue) | Интеграция с Vue 3 (автономная, без Nuxt). |
| [`@i18n-micro/react`](/integrations/react) | Интеграция с React. |
| [`@i18n-micro/preact`](/integrations/preact) | Интеграция с Preact. |
| [`@i18n-micro/solid`](/integrations/solid) | Интеграция с SolidJS. |
| [`@i18n-micro/astro`](/integrations/astro) | Интеграция с Astro. |
| [`@i18n-micro/node`](/integrations/nodejs) | Серверный загрузчик для Node.js. |
| [`@i18n-micro/types-generator`](/integrations/types-generator) | Генерация типов TypeScript из файлов переводов. |
| [`@i18n-micro/devtools-ui`](/integrations/devtools-ui) | Панель DevTools, не зависящая от фреймворка. |

Общие внутренние пакеты подключаются транзитивно.

## TypeScript

Модуль генерирует внешние типы для `useI18n`, `$t` и связанных хелперов на основе файлов вашей локали по умолчанию. Эта функция включена по умолчанию (`types: true`).

Для более строгой типизации ключей переводов см. [`@i18n-micro/types-generator`](/integrations/types-generator).
