## Общие флаги {#common-flags}

| Флаг | По умолчанию | Описание |
| --- | --- | --- |
| `--cwd` | текущий каталог | Каталог проекта |
| `--logLevel` | `info` | Уровень вывода: silent, info |
| `--debug` | `false` | Выводить трассировку стека при сбое команды |

## Анализ {#inspect}

### `info` {#info}

Вывести итоговую конфигурацию i18n проекта

| Флаг | По умолчанию | Описание |
| --- | --- | --- |
| `--json` | `false` | Выводить JSON вместо текста |

### `check` {#check}

Проверка для CI: завершается с ошибкой при отсутствующих, пустых, лишних, неопределённых или неиспользуемых ключах и сломанных плейсхолдерах

| Флаг | По умолчанию | Описание |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` из nuxt.config | Каталог переводов относительно проекта |
| `--only` | все, кроме duplicates | Проверки для запуска через запятую: missing, empty, extra, placeholders, undefined, unused, duplicates. Явно указанная `unused` завершается с ошибкой, если не может быть выполнена |
| `--duplicates` | `false` | Также сообщать об одинаковом тексте под разными ключами |
| `--ignore` | — | Glob-шаблоны исходных файлов для пропуска через запятую, относительно проекта |
| `--json` | `false` | Выводить JSON вместо текста |

```bash
i18n-micro check
i18n-micro check --only missing,placeholders --json
```

### `stats` {#stats}

Показать степень готовности переводов по локалям

| Флаг | По умолчанию | Описание |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` из nuxt.config | Каталог переводов относительно проекта |
| `--html` | — | Также записать HTML-отчёт в этот файл |
| `--json` | `false` | Выводить JSON вместо текста |
| `--baseRef` | — | Git-ссылка для сравнения готовности, например HEAD~1 или main |

```bash
i18n-micro stats --baseRef main
i18n-micro stats --html reports/i18n.html
```

### `lint` {#lint}

Проверить текст переводов; завершается с ошибкой, если проблемы остались

| Флаг | По умолчанию | Описание |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` из nuxt.config | Каталог переводов относительно проекта |
| `--rules` | все или `enabledRules` из .i18n-lintrc.json | Правила для запуска через запятую: no-trailing-spaces, no-multiple-spaces, no-empty-translation или пользовательское |
| `--fix` | `false` | Исправить то, что можно: пробелы и пользовательские правила с заменой |
| `--json` | `false` | Выводить JSON вместо текста |

```bash
i18n-micro lint --rules no-trailing-spaces --fix
```

### `search` {#search}

Искать по ключам и значениям и показывать, где используется каждый ключ

| Флаг | По умолчанию | Описание |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` из nuxt.config | Каталог переводов относительно проекта |
| `<query>` | — | Текст или ключ для поиска |
| `--caseSensitive` | `false` | Учитывать регистр |
| `--onlyUnused` | `false` | Только ключи, которые удалила бы `clean`; запрос становится необязательным |
| `--scope` | `all` | Где искать: global, pages, all |
| `--limit` | — | Вернуть не более указанного числа ключей |
| `--ignore` | — | Glob-шаблоны исходных файлов для пропуска через запятую, относительно проекта |
| `--json` | `false` | Выводить JSON вместо текста |

```bash
i18n-micro search "Welcome"
i18n-micro search --onlyUnused
```

## Работа с переводами {#translation-workflow}

### `extract` {#extract}

Перечислить ключи, которые используются в исходных файлах, но ещё не имеют текста, и добавить ключи с текстом по умолчанию в локаль по умолчанию

| Флаг | По умолчанию | Описание |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` из nuxt.config | Каталог переводов относительно проекта |
| `--ignore` | — | Glob-шаблоны исходных файлов для пропуска через запятую, относительно проекта |

```bash
i18n-micro extract
```

### `translate` {#translate}

Заполнить отсутствующие переводы из локали по умолчанию через сервис перевода

| Флаг | По умолчанию | Описание |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` из nuxt.config | Каталог переводов относительно проекта |
| `--service` | — | Сервис перевода: ai, azure, deepl, google, libretranslate, yandexcloud |
| `--token` | — | API-ключ. Лучше используйте переменную окружения I18N_TRANSLATE_TOKEN: флаги попадают в историю оболочки |
| `--options` | — | Параметры сервиса в виде пар key:value через запятую |
| `--locale` | все локали, кроме локали по умолчанию | Локали для заполнения через запятую |
| `--replace` | `false` | Перевести все ключи заново, заменяя существующие значения |
| `--dryRun` | `false` | Подсчитать ключи и символы по локалям; ничего не отправлять |
| `--chunkSize` | — | Строк на запрос; ограничено тем, что принимает сервис |
| `--pluralSeparator` | `\|` | Разделитель форм множественного числа в сообщениях |
| `--glossaryFile` | `.i18n-glossary.json`, если существует | Файл глоссария, используется сервисом `ai` |

```bash
i18n-micro translate --dryRun
I18N_TRANSLATE_TOKEN=... i18n-micro translate --service deepl --locale de,fr
i18n-micro translate --service ai --options provider:openai,model:gpt-4o-mini
i18n-micro translate --service libretranslate --options baseUrl:https://translate.example.com
```

### `sync` {#sync}

Удалить ключи, которых нет в локали по умолчанию; останавливается, если безопасность этого нельзя доказать. Отсутствующие ключи остаются отсутствующими

| Флаг | По умолчанию | Описание |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` из nuxt.config | Каталог переводов относительно проекта |
| `--ignore` | — | Glob-шаблоны исходных файлов для пропуска через запятую, относительно проекта |
| `--dryRun` | `false` | Перечислить, что будет удалено; ничего не записывать |
| `--force` | `false` | Удалить ключи, даже если безопасность нельзя доказать |

```bash
i18n-micro sync --dryRun
```

### `clean` {#clean}

Удалить ключи, которые нигде в проекте не используются; останавливается, если это нельзя доказать

| Флаг | По умолчанию | Описание |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` из nuxt.config | Каталог переводов относительно проекта |
| `--include` | — | Регулярное выражение: рассматривать для удаления только совпадающие ключи |
| `--exclude` | — | Регулярное выражение: никогда не удалять совпадающие ключи |
| `--ignore` | — | Glob-шаблоны исходных файлов для пропуска через запятую, относительно проекта |
| `--dryRun` | `false` | Перечислить, что будет удалено; ничего не записывать |
| `--force` | `false` | Удалить ключи, даже если использование нельзя доказать для всех из них |

```bash
i18n-micro clean --dryRun
i18n-micro clean --exclude '^errors\.'
```

## Рефакторинг {#refactoring}

### `text-to-i18n` {#text-to-i18n}

Заменить жёстко заданный текст в шаблонах Vue вызовами перевода и сообщить о жёстко заданном тексте в коде

| Флаг | По умолчанию | Описание |
| --- | --- | --- |
| `--translationFile` | `<translationDir>/<defaultLocale>.json` | Файл, в который попадают новые ключи |
| `--path` | весь проект | Файл или каталог для обработки |
| `--context` | — | Префикс для генерируемых ключей |
| `--ignore` | — | Glob-шаблоны исходных файлов для пропуска через запятую, относительно проекта |
| `--dryRun` | `false` | Показать, что изменится; ничего не записывать |
| `--interactive` | `false` | Подтверждать или редактировать каждый сгенерированный ключ |

```bash
i18n-micro text-to-i18n --dryRun
i18n-micro text-to-i18n --path components --context ui
```

### `rename` {#rename}

Переименовать ключ или пространство имён во всех локалях и исходных файлах

| Флаг | По умолчанию | Описание |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` из nuxt.config | Каталог переводов относительно проекта |
| `--from` **\*** | — | Текущий ключ или пространство имён |
| `--to` **\*** | — | Новый ключ или пространство имён |
| `--ignore` | — | Glob-шаблоны исходных файлов для пропуска через запятую, относительно проекта |
| `--dryRun` | `false` | Сообщить об изменениях; ничего не записывать |

**\*** обязательный.

```bash
i18n-micro rename --from common.save --to actions.save
```

### `pseudo` {#pseudo}

Заполнить локаль псевдопереводами, чтобы найти проблемы вёрстки и жёстко заданного текста

| Флаг | По умолчанию | Описание |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` из nuxt.config | Каталог переводов относительно проекта |
| `--sourceLocale` | локаль по умолчанию | Локаль для чтения |
| `--targetLocale` **\*** | — | Локаль для заполнения |
| `--replace` | `false` | Перезаписать существующие значения |

**\*** обязательный.

### `format` {#format}

Переписать файлы локалей с отсортированными ключами и единообразными отступами

| Флаг | По умолчанию | Описание |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` из nuxt.config | Каталог переводов относительно проекта |
| `--indent` | `2` | Количество пробелов в отступе |
| `--sortKeys` | `true` | Сортировать ключи; используйте --no-sortKeys, чтобы сохранить их порядок |
| `--check` | `false` | Завершиться с ошибкой, если файл изменится; ничего не записывать |

```bash
i18n-micro format --check
```

## Обмен {#exchange}

### `export` {#export}

Экспортировать файлы локалей в PO или CSV с текстом локали по умолчанию в качестве исходного

| Флаг | По умолчанию | Описание |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` из nuxt.config | Каталог переводов относительно проекта |
| `--format` | `po` | Формат файла: po, csv |
| `--dir` | `pots` для po, `csv_exports` для csv | Выходной каталог относительно проекта |
| `--force` | `false` | Перезаписать файлы, изменённые после последнего экспорта и так и не импортированные |

```bash
i18n-micro export --format csv
```

### `import` {#import}

Объединить файлы PO или CSV с файлами локалей

| Флаг | По умолчанию | Описание |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` из nuxt.config | Каталог переводов относительно проекта |
| `--format` | `po` | Формат файла: po, csv |
| `--dir` | `pots` для po, `csv_exports` для csv | Входной каталог относительно проекта |
| `--dryRun` | `false` | Сообщить, что будет импортировано; ничего не записывать |

```bash
i18n-micro import --format csv --dryRun
```

### `sync-remote` {#sync-remote}

Загрузить глобальные переводы с HTTP-эндпоинта из .i18n-remote.json или отправить их туда

| Флаг | По умолчанию | Описание |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` из nuxt.config | Каталог переводов относительно проекта |
| `--pull` | `true` | Загрузить с удалённого сервера |
| `--push` | `false` | Отправить на удалённый сервер |
| `--force` | `false` | При загрузке взять удалённое значение; при отправке перезаписать текст, который есть только на удалённом сервере |
| `--dryRun` | `false` | Сообщить, что изменит загрузка; ничего не записывать и не отправлять |

```bash
i18n-micro sync-remote --dryRun
i18n-micro sync-remote --no-pull --push
```

## Правила линтинга {#lint-rules}

| Правило | Находит | Исправляется через `--fix` |
| --- | --- | --- |
| `no-trailing-spaces` | Пробелы в конце значения или строки | да |
| `no-multiple-spaces` | Два или более пробела подряд | да |
| `no-empty-translation` | Пустое или состоящее из пробелов значение | нет |

## Коды выхода {#exit-codes}

| Код | Значение |
| --- | --- |
| `0` | Готово, сообщать не о чем |
| `1` | Находки: `check`, `lint` или `format --check` что-то нашли, `clean` или `sync` не смогли доказать безопасность удаления, `export` перезаписал бы неимпортированную работу, `translate` пропустил ключи, `import` или `sync-remote` столкнулись с конфликтом, отправка `sync-remote` удалила бы удалённый текст. `--dryRun` для `clean`, `sync` или загрузки `sync-remote` сообщает об этом и завершается с кодом `0` |
| `2` | Сбой: неверное использование, нечитаемый проект, ошибка сети или файла |

## Файлы конфигурации {#configuration-files}

| Файл | Используется |
| --- | --- |
| `.i18n-lintrc.json` | `lint`: `enabledRules`, `disabledRules`, `customRegexRules` (`name`, `pattern`, `flags`, `description`, `replacement`) |
| `.i18n-remote.json` | `sync-remote`: `url`, `path`, `token`, `auth` (`username`, `password`). `type` можно не указывать; существует только `custom` |
| `.i18n-glossary.json` | `translate --service ai`: `entries` из `source`, `target` и необязательных `from`, `to` |

## Переменные окружения {#environment-variables}

| Имя | Назначение |
| --- | --- |
| `I18N_TRANSLATE_TOKEN` | API-ключ для `translate`. Также читается из `.env` |
| `I18N_REMOTE_TOKEN` | Bearer-токен для `sync-remote`. Также читается из `.env` |
| `AI_GATEWAY_API_KEY, OPENAI_API_KEY, ANTHROPIC_API_KEY` | Ключ сервиса `ai`, если `I18N_TRANSLATE_TOKEN` не задан |
| `DEFAULT_LOCALE` | Переопределяет `defaultLocale`, как в модуле |
