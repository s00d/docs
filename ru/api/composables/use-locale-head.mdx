# 🌍 Композабл `useLocaleHead`

Композабл `useLocaleHead` — утилита в `Nuxt I18n Micro`, помогающая управлять SEO-атрибутами и HTML-метатегами для локализованных маршрутов. Он динамически формирует атрибуты `lang` и `dir` для HTML-документа и создаёт теги `meta` и `link`, улучшающие SEO вашего локализованного контента.

## ⚙️ Опции

```ts

```

SEO-теги для текущего маршрута: альтернативы `hreflang` для каждой локали плюс `x-default`, canonical-ссылка, `og:locale` и `lang`/`dir` на `<html>`.

Нужен только когда `meta` отключено или значения по умолчанию нужно скорректировать. При `meta: true` модуль сам регистрирует те же теги.

```ts
const head = useLocaleHead({ addSeoAttributes: true })
```

## 🛠️ Возвращаемые значения

Композабл `useLocaleHead` возвращает реактивный объект и функцию-обновитель, которую нужно вызывать при изменении исходных данных. Обе сигнатуры приведены выше — они сгенерированы из исходников.

### `metaObject`

Реактивный payload head (html attrs, meta, link), пригодный для `useHead(metaObject)`.

- **Пример**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

Пересчитывает `metaObject` на основе текущего маршрута, локали и конфигурации. Вызывайте её при изменении входов — например, при смене маршрута.

- **Пример**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### Доступ к `link` и `meta`

Массивы `link` и `meta` доступны через `metaObject.value`:

- **Пример**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ Примеры использования

### Базовое использование

Сгенерируйте head-атрибуты локали со значениями по умолчанию.

```js
const head = useLocaleHead()
```

### Пользовательский идентифицирующий атрибут

Используйте свой атрибут-идентификатор для сгенерированных тегов.

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### Отключение SEO-атрибутов

Сгенерируйте head-атрибуты без SEO-мета и link-тегов.

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### Указание базового URL

Задайте свой базовый URL для canonical и alternate URL.

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 Дополнительные возможности

### SEO-теги meta и link

Когда включено `addSeoAttributes`, композабл автоматически создаёт следующие теги:

- `og:locale` для текущей локали (`language_TERRITORY`, с подчёркиванием). Берётся из `locale.og` или конвертируется из `locale.iso`, когда возможно.
- `og:url` для canonical URL страницы.
- `og:locale:alternate` для альтернативных языковых версий.
- Ссылки `rel="canonical"` и `rel="alternate"` для SEO-оптимизации.
- Ссылку `hreflang="x-default"`, указывающую на URL локали по умолчанию. Она сообщает поисковикам, какой URL показывать пользователям, чей язык не совпадает ни с одной из определённых локалей.

### Динамическая локаль и направление

Композабл динамически определяет атрибуты `lang` и `dir` на основе локали текущего маршрута, гарантируя, что HTML-документ корректно настроен для международных пользователей.

### Обработка локализованных маршрутов

Если ваши маршруты имеют префиксы с кодами локалей (например, `/en/about`), композабл корректно подстраивает полный путь при генерации URL, гарантируя точность и релевантность SEO-атрибутов.

Этот композабл упрощает оптимизацию Nuxt-приложения для международной аудитории, помогая быть готовым к глобальным поисковикам и пользователям.

## 🛠️ Пример использования

Следующий пример показывает использование `useLocaleHead` внутри Vue-компонента с настройками по умолчанию:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### Пояснение к коду

- **Композабл `useLocaleHead`**: Вызывается в секции `<script setup>` и возвращает объект с `htmlAttrs`, `meta` и `link`.

- **Тег `<html>`**: Атрибуты `lang` и `dir` HTML-документа динамически определяются по текущей локали и применяются к `<html>`.

- **Секция `<head>`**:
  - **Meta-теги**: Формируются SEO-теги, включая `og:locale`, `og:url` и `rel="canonical"`/`rel="alternate"` для указания альтернативных языковых версий страницы.
  - **Link-теги**: Включаются canonical-ссылки, ссылки на альтернативные языковые версии и `hreflang="x-default"` (указывающая на URL локали по умолчанию).

- **Секция `<body>`**: Здесь отображается основной контент страницы. В этом примере используется простой заголовок и абзац.

### 📝 Заметки

1. **Атрибуты**: Используемые атрибуты (`lang`, `dir`, `rel`, `href`, `hreflang`, `property`, `content`) извлекаются из объекта, возвращённого `useLocaleHead`.

2. **Генерация SEO-тегов**: Если опция `addSeoAttributes` установлена в `true`, композабл автоматически генерирует SEO-теги для текущей локали.

3. **Базовый URL**: Свой базовый URL можно задать опцией `baseUrl`, чтобы корректно формировать canonical и alternate ссылки.

Этот пример показывает, как просто встроить `useLocaleHead` в компоненты приложения, чтобы обеспечить корректные SEO-атрибуты и улучшить индексацию локализованных страниц поисковиками.

## 🧩 Настройка и жизненный цикл

- `useLocaleHead` сам не подписывается на изменения. Он возвращает `metaObject` и `updateMeta`.
- Вызывайте `updateMeta()` при изменении входов (как правило, при смене маршрута), например из плагина:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## Когда лучше использовать `useI18nHead`

При `meta: true` (по умолчанию) предпочитайте [`useI18nHead`](/api/composables/use-i18n-head) для **постраничных** переопределений (свои hreflang, дополнительный `og:title`, частичное отключение). Используйте `useLocaleHead` напрямую только при `meta: false` или когда вы сами управляете `useHead`.
