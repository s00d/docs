# 🌍 Composable `useLocaleHead`

Composable `useLocaleHead` — это утилита в `Nuxt I18n Micro`, помогающая управлять SEO-атрибутами и HTML мета-тегами для локализованных маршрутов. Он динамически генерирует атрибуты `lang` и `dir` HTML-документа и создаёт `meta`- и `link`-теги для улучшения SEO вашего локализованного контента.

SEO head-теги для текущего маршрута: альтернативы `hreflang` для каждой локали плюс
`x-default`, канонический link, `og:locale` и `lang`/`dir` на `<html>`.

Нужен только когда `meta` отключён или значения по умолчанию нужно скорректировать — при `meta: true`
модуль регистрирует те же теги сам.

## 🛠️ Возвращаемые значения

Composable `useLocaleHead` возвращает реактивный объект и функцию-обновитель, которую нужно вызывать
при изменении исходных данных. Обе структуры находятся в сигнатуре выше, сгенерированной из
исходного кода.

### `metaObject`

Реактивный head-payload (html-атрибуты, meta, link), подходящий для `useHead(metaObject)`.

- **Пример**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

Пересчитывает `metaObject` на основе текущего маршрута, локали и конфигурации. Вызывайте его при изменении входных данных —
например, при смене маршрута.

- **Пример**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### Доступ к `link` и `meta`

Массивы `link` и `meta` доступны через `metaObject.value`:

- **Пример**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ Примеры использования

### Базовое использование

Сгенерируйте head-атрибуты, специфичные для локали, со стандартными опциями.

```js
const head = useLocaleHead()
```

### Настройка атрибута идентификатора

Используйте пользовательский атрибут-идентификатор для сгенерированных тегов.

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### Отключение SEO-атрибутов

Сгенерируйте head-атрибуты без добавления SEO-мета и link-тегов.

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### Указание базового URL

Задайте пользовательский базовый URL для канонических и альтернативных URL.

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 Дополнительные возможности

### SEO мета- и link-теги

При включённом `addSeoAttributes` composable автоматически генерирует следующие теги:

- `og:locale` для текущей локали (`language_TERRITORY`, через нижнее подчёркивание). Формируется из `locale.og` или конвертируется из `locale.iso`, когда это возможно.
- `og:url` для канонического URL страницы.
- `og:locale:alternate` для альтернативных языковых версий.
- Ссылки `rel="canonical"` и `rel="alternate"` для SEO-оптимизации.
- Ссылка `hreflang="x-default"`, указывающая на URL локали по умолчанию. Она сообщает поисковым системам, какой URL показывать пользователям, чей язык не совпадает ни с одной из определённых локалей.

### Динамическая локаль и направление

Composable динамически определяет атрибуты `lang` и `dir` на основе локали текущего маршрута, гарантируя, что ваш HTML-документ корректно настроен для международных пользователей.

### Обработка локализованных маршрутов

Если ваши маршруты имеют префиксы кодов локалей (например, `/en/about`), composable разумно корректирует полный путь для генерации URL, обеспечивая точность и релевантность SEO-атрибутов.

Этот composable упрощает процесс оптимизации вашего приложения Nuxt для международной аудитории, гарантируя, что сайт хорошо подготовлен для глобальных поисковых систем и пользователей.

## 🛠️ Пример использования

Следующий пример демонстрирует, как использовать composable `useLocaleHead` внутри компонента Vue со стандартными настройками:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### Пояснение кода

- **Composable `useLocaleHead`**: этот composable вызывается в секции `<script setup>` и возвращает объект, содержащий `htmlAttrs`, `meta` и `link`.

- **Тег `<html>`**: атрибуты `lang` и `dir` HTML-документа динамически определяются на основе текущей локали и применяются к тегу `<html>`.

- **Секция `<head>`**:
  - **Мета-теги**: генерируются SEO-мета-теги, включая `og:locale`, `og:url`, а также теги `rel="canonical"` и `rel="alternate"` для указания альтернативных языковых версий страницы.
  - **Link-теги**: включаются канонические ссылки, ссылки на альтернативные языковые версии и ссылка `hreflang="x-default"` (указывающая на URL локали по умолчанию).

- **Секция `<body>`**: здесь отображается основное содержимое страницы. В этом примере используются простой заголовок и абзац.

### 📝 Замечания

1. **Атрибуты**: используемые атрибуты (`lang`, `dir`, `rel`, `href`, `hreflang`, `property`, `content`) извлекаются из объекта, возвращаемого `useLocaleHead`.

2. **Генерация SEO-тегов**: если опция `addSeoAttributes` установлена в `true`, composable автоматически генерирует SEO-теги для текущей локали.

3. **Базовый URL**: вы можете задать свой базовый URL с помощью опции `baseUrl` для корректной генерации канонических и альтернативных ссылок.

Этот пример показывает, насколько легко интегрировать `useLocaleHead` в компоненты вашего приложения, чтобы обеспечить правильные SEO-атрибуты и улучшить индексацию локализованных страниц в поисковых системах.

## 🧩 Настройка и жизненный цикл

- `useLocaleHead` не подписывается на изменения сам. Он возвращает `metaObject` и `updateMeta`.
- Вы должны вызывать `updateMeta()` при изменении входных данных (обычно при смене маршрута), например, из плагина:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## Когда использовать `useI18nHead` вместо этого

Когда `meta: true` (по умолчанию), предпочитайте [`useI18nHead`](/api/composables/use-i18n-head) для **переопределений на уровне страницы** (пользовательский hreflang, дополнительный `og:title`, частичное отключение). Используйте `useLocaleHead` напрямую только когда `meta: false` или вы сами управляете `useHead`.
