# 🛠️ Композабл `useI18n`

Композабл `useI18n` в `Nuxt I18n Micro` даёт доступ к большинству runtime-хелперов i18n в компонентах и скриптах. Методы доступны **и с префиксом `$`, и без него** (например, `$t` и `t`).

Некоторые инъекции — `$defineI18nRoute` и `$clearCache` — доступны только через `useNuxtApp()`. См. [Методы — `$defineI18nRoute`](/api/methods#definei18nroute) и [`$clearCache`](/api/methods#clearcache).

## 📊 Что возвращает

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Все runtime-хелперы в виде обычного объекта.

Те же функции, которые плагин внедряет как `$t`, `$tc` и т. д., доступны и под именем с префиксом-долларом, и под голым алиасом. Поэтому `const \{ t \} = useI18n()` и
`const \{ $t \} = useI18n()` оба работают.

**Возвращает** — хелперы, описанные в [справочнике методов](/api/methods).

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

Каждый возвращаемый хелпер — `$t`, `$tc`, `$has`, `$switchLocale` и остальные — перечислен с сигнатурой и полностью задокументирован в [справочнике методов](/api/methods).

## API, доступные только через `useNuxtApp()`

Они **не** возвращаются из `useI18n()`. Импортируйте их из `useNuxtApp()`:

| Метод                      | Назначение                                                                              |
| -------------------------- | -------------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Постраничные маршруты по локалям, ограничения и инлайн-переводы в `script setup` |
| `$clearCache()`            | Очищает in-memory кэш переводов и загруженные чанки                                     |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Полные сигнатуры и примеры см. в разделе [Методы](/api/methods).

## 🛠️ Примеры использования

### Получение текущей локали

Получите текущую локаль приложения.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Перевод с параметрами

Переведите строку с динамическими параметрами и значением по умолчанию.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Переключение локалей

Переключите приложение на другую локаль.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Генерация локализованного маршрута

Сгенерируйте маршрут, локализованный под текущую или указанную локаль.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
