# 🌍 Компонент `<i18n-t>`

Компонент `<i18n-t>` в `Nuxt I18n Micro` — это гибкий компонент перевода, который поддерживает динамическую вставку контента через слоты. Он позволяет интерполировать переводы с пользовательскими компонентами Vue или HTML-содержимым, обеспечивая продвинутые сценарии локализации.

## ⚙️ Props

| `hideIfEmpty` | `boolean` | `false` | Ничего не рендерить, когда перевод разрешается в пустую строку. |
| `customPluralRule` | `PluralFunc` | `null` | Правило плюрализации только для этого элемента, переопределяющее заданное. |
| `number` | `number \| string` | — | Форматирует значение через `$tn` и передаёт в перевод как `\{number\}`. |
| `date` | `Date \| string \| number` | — | Форматирует значение через `$td` и передаёт в перевод как `\{date\}`. |
| `relativeDate` | `Date \| string \| number` | — | Форматирует значение через `$tdr` и передаёт в перевод как `\{relativeDate\}`. |

{/* /generated:component:i18n-t */}

Одновременно применяется только один из `plural`, `number`, `date` и `relativeDate`; если задано несколько,
выигрывает первый из перечисленных.

### Примеры для каждого prop

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

## 🛠️ Примеры использования

### Базовое использование

```vue
<i18n-t keypath="feedback.text" />
```

Это рендерит перевод для `feedback.text` внутри тега `<span>`.

### Использование слотов для динамического содержимого

Компонент `<i18n-t>` поддерживает использование слотов для динамической вставки компонентов Vue или другого содержимого в конкретные части перевода.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

В этом примере плейсхолдер `\{link\}` в строке перевода `feedback.text` заменяется компонентом `<nuxt-link>`, который сам содержит другой компонент перевода.

### Плюрализация

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

Это автоматически применяет правила плюрализации на основе значения `itemCount`.

## 🚀 Дополнительные возможности

### Слот по умолчанию

Если не указан конкретный слот, перевод можно настроить через слот по умолчанию, который предоставляет всю переведённую строку:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### Условный рендеринг

Ничего не рендерить, если строка перевода пуста, используя prop `hideIfEmpty`.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### Пользовательское правило плюрализации

Используйте пользовательскую функцию для обработки плюрализации.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### Продвинутый пример со слотами

Используйте слоты для настройки того, как рендерится содержимое перевода.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
