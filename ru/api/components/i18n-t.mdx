# 🌍 Компонент `<i18n-t>`

Компонент `<i18n-t>` в `Nuxt I18n Micro` — гибкий компонент перевода, поддерживающий динамическую вставку содержимого через слоты. Он позволяет интерполировать переводы пользовательскими Vue-компонентами или HTML-содержимым, реализуя продвинутые сценарии локализации.

## ⚙️ Пропсы

| Пропс | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `keypath` **\*** | `string` | — | Ключ перевода для рендеринга. |
| `plural` | `number \| string` | — | Значение количества для выбора формы множественного числа. Задайте, чтобы использовать `$tc` вместо `$t`. |
| `tag` | `string` | `'span'` | Тег элемента для рендеринга. |
| `params` | `Record<string, string \| number \| boolean>` | `() => (\{\})` | Значения интерполяции, подставляемые в перевод. |
| `defaultValue` | `string` | `''` | Рендерится вместо компонента, когда `hideIfEmpty` подавляет пустой перевод. |
| `html` | `boolean` | `false` | Рендерить перевод как HTML, а не как текст. Только для контента, который вы контролируете. |
| `hideIfEmpty` | `boolean` | `false` | Ничего не рендерить, если перевод разрешился в пустую строку. |
| `customPluralRule` | `PluralFunc` | `null` | Правило множественного числа только для этого элемента, перекрывающее настроенное. |
| `number` | `number \| string` | — | Форматирует значение через `$tn` и передаёт его в перевод как `\{number\}`. |
| `date` | `Date \| string \| number` | — | Форматирует значение через `$td` и передаёт его в перевод как `\{date\}`. |
| `relativeDate` | `Date \| string \| number` | — | Форматирует значение через `$tdr` и передаёт его в перевод как `\{relativeDate\}`. |

**\*** обязательный.

{/* /generated:component:i18n-t */}

Одновременно применяется только один из `plural`, `number`, `date` и `relativeDate`; если задано несколько, побеждает первый в этом списке.

### Примеры для каждого пропа

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

## 🛠️ Примеры использования

### Базовое использование

```vue
<i18n-t keypath="feedback.text" />
```

Это отрендерит перевод для `feedback.text` внутри тега `<span>`.

### Использование слотов для динамического контента

Компонент `<i18n-t>` поддерживает слоты, чтобы динамически вставлять компоненты Vue или другое содержимое в конкретные части перевода.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

В этом примере плейсхолдер `\{link\}` в строке перевода `feedback.text` заменяется компонентом `<nuxt-link>`, который сам содержит другой компонент перевода.

### Множественные формы

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

Правила множественного числа применяются автоматически в зависимости от значения `itemCount`.

## 🚀 Дополнительные возможности

### Слот по умолчанию

Если конкретный слот не указан, перевод можно настроить через слот по умолчанию, в который приходит вся переведённая строка:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### Условный рендеринг

Не рендерить ничего, если строка перевода пустая, — с помощью `hideIfEmpty`.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### Пользовательское правило множественного числа

Используйте свою функцию для обработки множественного числа.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### Продвинутый пример со слотами

Настройте вывод перевода через слоты.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
