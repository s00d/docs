# 🌍 Компонент `<i18n-group>`

Компонент `<i18n-group>` в Nuxt I18n Micro предоставляет удобный способ группировать переводы под общим префиксом, уменьшая повторения и улучшая организацию кода.

## ⚙️ Props

{/* generated:component:i18n-group — do not edit; run `pnpm run docs:generate` */}

| Prop | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | Префикс ключей, относительно которого разрешается каждый поиск внутри слота. |
| `groupClass` | `string` | `''` | Дополнительный класс на элементе-обёртке. |

**\*** обязательный.

### Слоты

| Слот | Bindings | Описание |
| --- | --- | --- |
| `default` | `prefix`, `t` | Получает `prefix` и функцию `t`, ограниченную его областью. |

{/* /generated:component:i18n-group */}

## 🎯 Слоты

Слот по умолчанию получает `prefix` и функцию `t`, ограниченную его областью, поэтому ключи внутри
пишутся относительно префикса:

```vue
<i18n-group prefix="checkout">
  <template #default="{ t }">
    <h2>{{ t('title') }}</h2>
    <p>{{ t('summary', { count: 3 }) }}</p>
  </template>
</i18n-group>
```

## 🛠️ Пример использования

### Базовое использование

```vue
<template>
  <i18n-group prefix="product.details">
    <template #default="{ t }">
      <h1>{{ t('title') }}</h1>
      <p>{{ t('description') }}</p>
      <div class="price">{{ t('price', { value: 99.99 }) }}</div>
    </template>
  </i18n-group>
</template>
```

Файл переводов:

```json
{
  "product": {
    "details": {
      "title": "Premium Product",
      "description": "This is a premium product",
      "price": "Price: ${value}"
    }
  }
}
```

### С пользовательским классом

```vue
<template>
  <i18n-group prefix="user.profile" group-class="profile-section">
    <template #default="{ t }">
      <div class="user-info">
        <h2>{{ t('title') }}</h2>
        <p>{{ t('bio') }}</p>
        <div class="stats">
          <span>{{ t('stats.followers') }}</span>
          <span>{{ t('stats.following') }}</span>
        </div>
      </div>
    </template>
  </i18n-group>
</template>
```

Файл переводов:

```json
{
  "user": {
    "profile": {
      "title": "User Profile",
      "bio": "User biography goes here",
      "stats": {
        "followers": "Followers: {count}",
        "following": "Following: {count}"
      }
    }
  }
}
```

### С динамическим содержимым

```vue
<template>
  <i18n-group prefix="blog.post">
    <template #default="{ t }">
      <article>
        <h1>{{ t('title') }}</h1>
        <div class="meta">
          {{ t('meta.author', { name: author }) }} |
          {{ t('meta.date', { date: publishDate }) }}
        </div>
        <div v-for="(section, index) in sections" :key="index">
          <h2>{{ t(`sections.${index}.title`) }}</h2>
          <p>{{ t(`sections.${index}.content`) }}</p>
        </div>
      </article>
    </template>
  </i18n-group>
</template>

<script setup>
const author = 'John Doe'
const publishDate = '2024-01-01'
const sections = ['intro', 'main', 'conclusion']
</script>
```

## 🎨 Стилизация

Компонент оборачивает своё содержимое в div с классом `i18n-group` и любыми дополнительными классами, указанными в prop `groupClass`:

```css
.i18n-group {
  /* Your base styles */
}

.profile-section {
  /* Additional styles for profile sections */
}
```

## 🚀 Лучшие практики

1. **Согласованные префиксы**: используйте согласованные и логичные префиксы, отражающие структуру приложения

```vue
<i18n-group prefix="features.pricing">
<i18n-group prefix="features.security">
```

2. **Модульная организация**: группируйте связанные переводы под осмысленными префиксами

```vue
<i18n-group prefix="checkout.payment">
<i18n-group prefix="checkout.shipping">
```

3. **Переиспользуемые компоненты**: создавайте переиспользуемые компоненты с собственными группами переводов

```vue
<!-- UserProfile.vue -->
<i18n-group prefix="user.profile">

<!-- UserSettings.vue -->
<i18n-group prefix="user.settings">
```

4. **Вложенные группы**: избегайте глубокой вложенности групп для сохранения ясности

```vue
<!-- Good -->
<i18n-group prefix="shop.product">

<!-- Avoid -->
<i18n-group prefix="shop.category.product.details.specs">
```
