# 🌍 Компонент `<i18n-link>`

Компонент `<i18n-link>` в `Nuxt I18n Micro` — универсальный компонент ссылки, который автоматически локализует маршруты на основе текущей локали. Он выступает обёрткой над компонентом `<NuxtLink>`, предоставляя дополнительные возможности, такие как стилизация активной ссылки и поддержку внешних ссылок.

## ⚙️ Props

| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | Целевой маршрут. Автоматически локализуется; внешний URL передаётся без изменений. |
| `activeStyle` | `Partial<CSSStyleValue>` | — | Inline-стиль, применяемый, пока ссылка указывает на текущий маршрут. |

**\*** обязательный.

### Слоты

| Слот | Bindings | Описание |
| --- | --- | --- |
| `default` | — | Содержимое ссылки. |

{/* /generated:component:i18n-link */}

`to` принимает всё, что принимает `NuxtLink` — путь, именованный маршрут или разрешённый объект маршрута.
Абсолютный URL определяется автоматически и отображается как обычный `<a target="_blank" rel="noopener noreferrer">`,
а не локализуется.

## 🛠️ Примеры использования

### Базовое использование

```vue
<i18n-link to="/about">About Us</i18n-link>
```

В этом примере создаётся ссылка на страницу `/about`, локализованная под текущую локаль.

### Стилизация активной ссылки с inline-стилями

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

Ссылка будет иметь жирный текст, когда пользователь находится на странице `/about`, позволяя вам стилизовать активную ссылку прямо через inline-стили.

### Обработка внешних ссылок

Компонент автоматически определяет внешние ссылки и добавляет необходимые атрибуты для безопасности.

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

Эта ссылка откроет `https://example.com` в новой вкладке с применённым `rel="noopener noreferrer"`.

## 🎨 Стили

Компонент теперь использует inline-стили для активного состояния вместо класса. Вы можете настроить эти стили с помощью prop `activeStyle`.

### Стили активного состояния по умолчанию

- **Font Weight**: `bold`
- **Цвет**: наследует цвет по умолчанию браузера (если в `activeStyle` не указан `color`).

Вы можете переопределить их, передав пользовательские стили через prop `activeStyle`.

### Пользовательские стили активного состояния

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

В этом примере ссылка будет жирной и зелёной, когда активна.

## 🚀 Дополнительные возможности

### Слот для пользовательского содержимого

Вы можете передавать пользовательское содержимое внутри ссылки с помощью слотов, что делает компонент гибким для разных сценариев использования.

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### Улучшения доступности

Компонент поддерживает `aria-label` и другие атрибуты доступности, обеспечивая более доступный опыт.

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
