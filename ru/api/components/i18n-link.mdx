# 🌍 Компонент `<i18n-link>`

Компонент `<i18n-link>` в `Nuxt I18n Micro` — это универсальный компонент ссылки, который автоматически локализует маршруты в соответствии с текущей локалью. Он работает как обёртка над `<NuxtLink>`, предоставляя дополнительные возможности, такие как стилизация активных ссылок и поддержка внешних URL.

## ⚙️ Пропсы

| Пропс | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | Целевой маршрут. Локализуется автоматически; внешний URL передаётся без изменений. |
| `activeStyle` | `Partial<CSSStyleValue>` | — | Inline-стиль, применяемый, когда ссылка указывает на текущий маршрут. |

**\*** обязательный.

### Слоты

| Слот | Биндинги | Описание |
| --- | --- | --- |
| `default` | — | Содержимое ссылки. |

{/* /generated:component:i18n-link */}

`to` принимает всё то же, что и `NuxtLink`: путь, именованный маршрут или объект разрешённого маршрута.
Абсолютный URL распознаётся и рендерится как обычный `<a target="_blank" rel="noopener noreferrer">`, а не локализуется.

## 🛠️ Примеры использования

### Базовое использование

```vue
<i18n-link to="/about">About Us</i18n-link>
```

Этот пример создаёт ссылку на страницу `/about`, локализованную под текущую локаль.

### Стилизация активной ссылки inline-стилями

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

Текст ссылки станет жирным, когда пользователь находится на странице `/about`. Это позволяет стилизовать активную ссылку напрямую inline-стилями.

### Обработка внешних ссылок

Компонент автоматически определяет внешние ссылки и добавляет необходимые атрибуты безопасности.

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

Эта ссылка откроет `https://example.com` в новой вкладке с атрибутом `rel="noopener noreferrer"`.

## 🎨 Стили

Компонент теперь использует inline-стили для активного состояния вместо класса. Их можно настроить через проп `activeStyle`.

### Стили активной ссылки по умолчанию

- **Font Weight**: `bold`
- **Color**: Наследует цвет по умолчанию из браузера (если `color` не указан в `activeStyle`).

Их можно переопределить, передав собственные стили через `activeStyle`.

### Пользовательские активные стили

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

В этом примере активная ссылка будет жирной и зелёной.

## 🚀 Дополнительные возможности

### Слот для пользовательского содержимого

Внутрь ссылки можно передавать произвольное содержимое через слоты, что делает компонент гибким для разных сценариев.

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### Улучшения доступности

Компонент поддерживает `aria-label` и другие атрибуты доступности, обеспечивая более удобный интерфейс.

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
