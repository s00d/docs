# 🌍 Компонент `<i18n-switcher>`

Компонент `<i18n-switcher>` в `Nuxt I18n Micro` предоставляет удобный выпадающий интерфейс для переключения между локалями в приложении. Компонент широко настраивается, что позволяет органично встраивать его в дизайн и раскладку вашего приложения.

Локали с `disabled: true` **исключаются** из выпадающего списка (они остаются доступны через `$getLocales()` для SEO и head-тегов). Только переключаемые локали получают `NuxtLink` и `hreflang`.

По умолчанию все части нестилизованы: пропсы `custom*Style` принимают объекты inline-стилей, а слоты ниже полностью заменяют разметку, когда стилей недостаточно.

## 🛠️ Примеры использования

### Базовое использование

```vue
<template>
  <i18n-switcher />
</template>
```

Это отрисовывает переключатель локалей со стилями и поведением по умолчанию.

### Пользовательские подписи и inline-стили

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Этот пример демонстрирует полностью настраиваемый переключатель локалей с собственными подписями и inline-стилями.

## 🔌 Слоты

Любую визуальную часть переключателя можно заменить. Слоты перечислены рядом с таблицей пропсов; каждый принимает шаблонное содержимое:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Слоты, имена которых заканчиваются на `-item`, `-link-content` или начинаются с `before-item`, получают объект `locale`, к которому они относятся.

## 🎨 Обзор стилей

Компонент `<i18n-switcher>` поставляется с базовыми inline-стилями, которые можно легко переопределить через пропсы. Краткий обзор стилей по умолчанию:

- **Wrapper**: Определяет позиционирование выпадающего списка.
- **Button**: Стилизует кнопку-переключатель.
- **Dropdown**: Стилизует список выпадающего меню.
- **Items**: Стилизует каждый элемент списка.
- **Links**: Стилизует ссылки внутри элементов.
- **Icon**: Стилизует иконку-индикатор выпадающего меню.

Эти стили можно кастомизировать через соответствующие пропсы, чтобы переключатель локалей органично встраивался в интерфейс приложения.
