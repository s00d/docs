# 🌍 Компонент `<i18n-switcher>`

Компонент `<i18n-switcher>` в `Nuxt I18n Micro` предоставляет удобный интерфейс выпадающего списка для переключения между разными локалями в вашем приложении. Этот компонент очень настраиваем, что позволяет плавно интегрировать его в дизайн и макет приложения.

Локали с `disabled: true` **исключаются** из выпадающего списка (они остаются доступны через `$getLocales()` для SEO / head-тегов). Только переключаемые локали получают `NuxtLink` + `hreflang`.

Каждая часть по умолчанию не стилизована: prop'ы `custom*Style` принимают объекты inline-стилей, а

## 🛠️ Примеры использования

### Базовое использование

```vue
<template>
  <i18n-switcher />
</template>
```

Это рендерит переключатель локалей со стандартным оформлением и поведением.

### Пользовательские подписи и inline-стили

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Этот пример демонстрирует полностью настроенный переключатель локалей с пользовательскими подписями и inline-стилями.

## 🔌 Слоты

Каждую визуальную часть переключателя можно заменить. Слоты перечислены в таблице props выше;
каждый принимает содержимое шаблона:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Слоты, имена которых заканчиваются на `-item`, `-link-content` или начинаются с `before-item`, получают
объект `locale`, к которому они относятся.

## 🎨 Обзор стилей

Компонент `<i18n-switcher>` поставляется с базовыми стилями, определёнными через inline-стили, которые можно легко переопределить, передав пользовательские стили через props. Ниже — краткий обзор оформления по умолчанию:

- **Wrapper**: контролирует позиционирование выпадающего списка.
- **Button**: стилизует кнопку-переключатель.
- **Dropdown**: стилизует список выпадающего меню.
- **Items**: стилизует каждый пункт в списке.
- **Links**: стилизует ссылки внутри каждого пункта.
- **Icon**: стилизует иконку индикатора выпадающего списка.

Вы можете настроить эти стили, передав пользовательские стили через соответствующие props, обеспечивая плавную интеграцию переключателя локалей в UI вашего приложения.
