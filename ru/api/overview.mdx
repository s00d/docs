# Справочник API

## Runtime API

- [Методы](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, переключение локалей, хелперы роутинга
- [События](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Переводы и кэш](/api/cache) — `TranslationStorage`, загрузка payload'ов, `$clearCache`

## Серверное middleware

Серверные обработчики используют выделенное middleware (не клиентские хелперы `$t`):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — перевод в API-маршрутах и серверных обработчиках
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — чтение определённой локали и метаданных

Полное руководство по настройке, приоритетам определения локали и примерам см. в [Server-Side Translations](/guides/server-side-translations).
