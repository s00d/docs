В этом разделе перечислены все опции, хелперы, хуки, композаблы и компоненты модуля Nuxt, а также экспортируемый API каждого пакета `@i18n-micro/*`. Используйте его, чтобы найти сигнатуру или значение по умолчанию; в [руководстве](/ru/guide/getting-started) объясняется, как всем этим пользоваться. Большинство таблиц здесь сгенерированы из исходного кода, поэтому они соответствуют коду.

## Модуль Nuxt {#nuxt-module}

| Страница | Содержание |
| --- | --- |
| [Опции модуля](/ru/api/module-options) | Каждый ключ `i18n` в `nuxt.config` с типом и значением по умолчанию |
| [Хелперы](/ru/api/methods) | `$t`, `$tc`, `$tn`, `$td`, `$localePath`, `$switchLocale`, `$defineI18nRoute` и остальные |
| [Хуки](/ru/api/events) | Runtime-хук `i18n:register` |

## Композаблы {#composables}

| Композабл | Для чего |
| --- | --- |
| [`useI18n`](/ru/composables/useI18n) | Хелперы в `<script setup>` |
| [`useI18nLocale`](/ru/composables/useI18nLocale) | Состояние локали и cookie в собственном плагине определения локали |
| [`useI18nHead`](/ru/composables/useI18nHead) | Постраничное переопределение генерируемых SEO-тегов |
| [`useLocaleHead`](/ru/composables/useLocaleHead) | SEO-теги в виде объекта для вашего собственного `useHead` |

## Компоненты {#components}

| Компонент | Отображает |
| --- | --- |
| [`<i18n-t>`](/ru/components/i18n-t) | Один перевод с плюрализацией, форматированием и интерполяцией слотов |
| [`<i18n-link>`](/ru/components/i18n-link) | `NuxtLink` на локализованный маршрут |
| [`<i18n-switcher>`](/ru/components/i18n-switcher) | Выпадающий список локалей |
| [`<i18n-group>`](/ru/components/i18n-group) | Блок с общим префиксом ключей |

## Сервер {#server}

Обработчики Nitro используют `useTranslationServerMiddleware` и `useLocaleServerMiddleware`, а не клиентские хелперы. См. [Серверные маршруты](/ru/guide/server-side-translations).

## Пакеты {#packages}

В разделе [API пакетов](/ru/api/packages/overview) перечислены экспорты каждого пакета `@i18n-micro/*` — по одной сгенерированной странице на пакет.
