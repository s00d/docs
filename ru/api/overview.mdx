# Справочник API

## Runtime API

- [Методы](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, переключение локалей, вспомогательные функции маршрутизации
- [События](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Переводы и кэш](/api/cache) — `TranslationStorage`, загрузка payload'ов, `$clearCache`

## Серверный middleware

Серверные обработчики используют выделенный middleware (не клиентские хелперы `$t`):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — переводы в API-маршрутах и серверных обработчиках
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — чтение обнаруженной локали и метаданных

Полное руководство по настройке, приоритетам определения локали и примерам см. в [Серверные переводы](/guides/server-side-translations).
