# API пакетов

`nuxt-i18n-micro` состоит из набора небольших пакетов, большинство из которых можно использовать
самостоятельно — `@i18n-micro/vue` в обычном приложении Vue, `@i18n-micro/core` где угодно.

Каждая страница ниже сгенерирована из снапшота API, который
[`pnpm run api:surface`](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/maintenance-commands.md#api-surface) сверяет с
исходниками TypeScript, поэтому ни один экспорт не может исчезнуть без изменения этого справочника
или падения CI.
