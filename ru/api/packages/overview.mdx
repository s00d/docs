---

Модуль Nuxt собран из небольших пакетов `@i18n-micro/*`, и большинство из них работают самостоятельно: `@i18n-micro/vue` в приложении Vue, `@i18n-micro/core` где угодно. На этих страницах можно посмотреть, что экспортирует пакет, для каждой точки входа. Каждая страница генерируется из снимка, который [`pnpm run api:surface`](https://s00d.github.io/nuxt-i18n-micro/contributing/maintenance-commands#api-surface) сверяет с исходниками TypeScript, поэтому экспорт не может измениться незаметно для CI.
