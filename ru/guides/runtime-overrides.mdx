# Переопределения i18n в рантайме

Используйте это руководство, когда нужен один билд-артефакт, работающий с разными настройками локали по умолчанию в разных окружениях (например, разные инстансы для разных тенантов).

## Что можно переопределить в рантайме

Модуль поддерживает безопасные переопределения в рантайме для:

- `defaultLocale`
- `fallbackLocale`
- `disabledLocales`

Эти переопределения применяются поверх build-time конфигурации из `.nuxt/i18n.strategy.mjs` и `.nuxt/i18n.config.mjs`.

## Что нельзя переопределить в рантайме

`strategy` (`no_prefix`, `prefix`, `prefix_except_default`, `prefix_and_default`) — это build-time настройка, потому что она влияет на поведение сгенерированных маршрутов.

Если вы передадите переопределение стратегии в рантайме, оно будет проигнорировано и выведено предупреждение.

## Переопределения через runtimeConfig

Передайте значения рантайма под `runtimeConfig.public.i18nRuntime`:

```ts
export default defineNuxtConfig({
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

## Переопределения через переменные окружения

Также можно настроить переопределения через переменные окружения:

- `NUXT_I18N_DEFAULT_LOCALE`
- `NUXT_I18N_FALLBACK_LOCALE`
- `NUXT_I18N_DISABLED_LOCALES` (через запятую, например `fr,it`)

Поддерживаются также резервные алиасы:

- `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES`

## Правила валидации

В рантайме модуль валидирует переопределения, чтобы избежать некорректного состояния:

- Нельзя отключить все локали.
- `defaultLocale` должен указывать на включённую локаль.
- `fallbackLocale` должна быть в объявленных локалях.

Если переопределение некорректно, модуль сохраняет безопасное значение и записывает предупреждение.

## Заметки для многоинстансовых деплоев

Эта возможность рантайма предназначена для активации локалей и значений по умолчанию на каждом инстансе без пересборки.

Если инстансам нужны разные URL-стратегии (`no_prefix` против `prefix`), используйте отдельные билды для каждой стратегии.

## Отключённые локали и статические payload'ы

`runtimeConfig.public.i18nRuntime.disabledLocales` обновляет роутинг, switcher и Nitro-**хендлер** payload'а. Но Nitro отдаёт файлы из `public/` **до** этого хендлера.

Если `translationPayloads.publicAssets` (или принудительное копирование в public у Node SSR) уже записал `/_locales/\{page\}/\{locale\}/data.json`, отключение в рантайме этот файл не скроет. Лучше задавать `locale.disabled: true` на этапе сборки, чтобы premerge не создавал статические payload'ы для этой локали.
