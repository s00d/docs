# Runtime-переопределения i18n

Используйте это руководство, когда вам нужно, чтобы один артефакт сборки запускался с разными значениями локали по умолчанию в разных окружениях (например, для разных инстансов арендаторов).

## Что можно переопределить во время выполнения

Модуль поддерживает безопасные runtime-переопределения для:

- `defaultLocale`
- `fallbackLocale`
- `disabledLocales`

Эти переопределения применяются поверх конфигурации из `.nuxt/i18n.strategy.mjs` и `.nuxt/i18n.config.mjs`, задаваемой на этапе сборки.

## Что нельзя переопределить во время выполнения

`strategy` (`no_prefix`, `prefix`, `prefix_except_default`, `prefix_and_default`) относится к этапу сборки, так как влияет на поведение сгенерированных маршрутов.

Если вы передадите runtime-переопределение стратегии, оно будет проигнорировано, а в логах появится предупреждение.

## Переопределения через RuntimeConfig

Укажите runtime-значения в `runtimeConfig.public.i18nRuntime`:

```ts
export default defineNuxtConfig({
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

## Переопределения через переменные окружения

Переопределения также можно настроить через переменные окружения:

- `NUXT_I18N_DEFAULT_LOCALE`
- `NUXT_I18N_FALLBACK_LOCALE`
- `NUXT_I18N_DISABLED_LOCALES` (через запятую, например `fr,it`)

Также поддерживаются альтернативные имена:

- `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES`

## Правила валидации

Во время выполнения модуль валидирует переопределения, чтобы избежать некорректного состояния:

- Нельзя отключить все локали.
- `defaultLocale` должна указывать на включённую локаль.
- `fallbackLocale` должна существовать среди объявленных локалей.

Если переопределение некорректно, модуль сохраняет безопасное значение и выводит предупреждение.

## Замечания для развёртываний с несколькими инстансами

Эта runtime-функция предназначена для активации локалей и значений по умолчанию для каждого инстанса без пересборки.

Если инстансам требуются разные URL-стратегии (`no_prefix` и `prefix`), используйте отдельные сборки для каждой стратегии.

## Отключённые локали и статические payload'ы

`runtimeConfig.public.i18nRuntime.disabledLocales` обновляет маршрутизацию, переключатель и **обработчик** payload'ов Nitro, но Nitro раздаёт файлы из `public/` **до** этого обработчика.

Если `translationPayloads.publicAssets` (или принудительное копирование в public для Node SSR) уже записал `/_locales/\{page\}/\{locale\}/data.json`, отключение во время выполнения не сможет скрыть этот файл. Предпочтительнее использовать `locale.disabled: true` на этапе сборки, чтобы предварительное слияние не создавало статические payload'ы для этой локали.
