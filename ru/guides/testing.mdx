# 🧪 Тестирование модуля `Nuxt I18n Micro`

## 📖 Введение в тестирование

Тестирование модуля `Nuxt I18n Micro` важно, чтобы убедиться, что функции локализации приложения работают как ожидается. Эта документация проведёт вас через настройку тестового окружения, создание моковых конфигураций для vitest и написание тестов для ваших компонентов. Практический пример смотрите в [проекте-примере на GitHub](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/test-utils/example).

О том, как этот репозиторий прогоняет собственные наборы тестов — Vitest-проекты `unit` / `integration` / `e2e`, файлы по стратегиям (`test/strategies-*.test.ts`) и регрессии — смотрите [Testing routing strategies](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/testing-strategies.md).

## 🛠️ Настройка тестового окружения

### 1. Установите `@i18n-micro/test-utils`

Сначала установите тестовые утилиты для `Nuxt I18n Micro`. Этот пакет предоставляет всё необходимое для мокирования и тестирования i18n-конфигураций.

```bash
npm install @i18n-micro/test-utils --save-dev
```

### 2. Создайте файл моковой конфигурации

Далее создайте файл для настройки моков i18n. Он будет использоваться для мокирования i18n-функций и утилит во время тестов.

```typescript
// tests/unit-setup.ts

import { mockNuxtImport } from '@nuxt/test-utils/runtime'
import { vi } from 'vitest'
import { i18nUtils } from '@i18n-micro/test-utils'

export function createFakeI18n() {
  return {
    $getLocale: vi.fn(i18nUtils.getLocale),
    $t: vi.fn(i18nUtils.t),
    $tc: vi.fn(i18nUtils.tc),
    $setLocale: vi.fn(i18nUtils.setLocale),
    $getLocaleName: vi.fn(i18nUtils.getLocaleName),
    $setLocaleName: vi.fn(i18nUtils.setLocaleName),
    $getLocales: vi.fn(i18nUtils.getLocales),
    $setLocales: vi.fn(i18nUtils.setLocales),
    $defaultLocale: vi.fn(i18nUtils.defaultLocale),
    $setDefaultLocale: vi.fn(i18nUtils.setDefaultLocale),
    $getRouteName: vi.fn(i18nUtils.getRouteName),
    $settRouteName: vi.fn(i18nUtils.settRouteName),
    $ts: vi.fn(i18nUtils.ts),
    $tn: vi.fn(i18nUtils.tn),
    $td: vi.fn(i18nUtils.td),
    $has: vi.fn(i18nUtils.has),
    $resolveTranslations: vi.fn(i18nUtils.resolveTranslations),
    $setTranslation: vi.fn(i18nUtils.setTranslation),
    $mergeTranslations: vi.fn(i18nUtils.mergeTranslations),
    $switchLocaleRoute: vi.fn(i18nUtils.switchLocaleRoute),
    $switchLocalePath: vi.fn(i18nUtils.switchLocalePath),
    $switchLocale: vi.fn(i18nUtils.switchLocale),
    $switchRoute: vi.fn(i18nUtils.switchRoute),
    $localeRoute: vi.fn(i18nUtils.localeRoute),
    $localePath: vi.fn(i18nUtils.localePath),
    $setI18nRouteParams: vi.fn(i18nUtils.setI18nRouteParams),
  }
}

mockNuxtImport<() => ReturnType<typeof createFakeI18n>>('useI18n', () => vi.fn(() => createFakeI18n()))

export const setTranslationsFromJson = i18nUtils.setTranslationsFromJson
```

### 3. Настройте Vitest

Теперь настройте Vitest на использование моковой конфигурации и подготовьте тестовое окружение.

```typescript
// vitest.config.ts

import { defineVitestConfig } from '@nuxt/test-utils/config'

export default defineVitestConfig({
  test: {
    watch: false,
    setupFiles: ['./tests/unit-setup.ts'],
    include: ['./**/*.spec.ts'],
  },
})
```

## 🧪 Написание тестов

### Пример компонента

Ниже — простой компонент, использующий композабл `useI18n` для перевода сообщений.

```vue
<script setup lang="ts">
const { $t } = useI18n()

const props = defineProps({
  message: {
    type: String,
    default: null,
  },
})

// Test to see that $t works in script setup as well as the template
const message = props.message || $t('defaultMessage')
</script>

<template>
  <div>
    <p>Test from component: {{ $t('welcome') }}</p>
    <p data-testid="message">Test message from props: {{ message }}</p>
  </div>
</template>
```

### Файл теста

Теперь напишем тест для этого компонента.

```typescript
// tests/unit/example.spec.ts

import { describe, it, expect, beforeEach } from 'vitest'
import { mount } from '@vue/test-utils'
import ExampleComponent from '@/components/ExampleComponent.vue'
import fs from 'fs'
import path from 'path'
import { setTranslationsFromJson } from './unit-setup'

describe('ExampleComponent', () => {
  beforeEach(async () => {
    const fileContent = fs.readFileSync(path.join(__dirname, '../../locales/en-GB.json')).toString()
    await setTranslationsFromJson('en', JSON.parse(fileContent))
  })

  it('renders the welcome message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.text()).toContain('Test from component: Welcome')
  })

  it('renders the default message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Default Message')
  })

  it('renders the custom message correctly', () => {
    const wrapper = mount(ExampleComponent, {
      props: {
        message: 'Custom Message',
      },
    })
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Custom Message')
  })
})
```

## 📝 Лучшие практики тестирования

- **🔧 Мокайте i18n-функции:** Всегда мокайте i18n-функции через `@i18n-micro/test-utils`, чтобы получать стабильные и предсказуемые результаты тестов.
- **⚙️ Используйте Vitest для юнит-тестов:** Vitest — мощный фреймворк тестирования Vue-приложений. Используйте его для юнит-тестов компонентов.
- **📚 Документируйте тесты:** Чётко фиксируйте назначение и ожидаемые результаты каждого теста. Это поможет поддерживать ясность и упростит понимание тестов другими (или вами в будущем).

## 📊 Утилитарные методы i18n

Ниже — таблица со всеми утилитарными методами, предоставляемыми `@i18n-micro/test-utils`.

| Метод                                           | Описание                                                                                                                                    |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `t(key, params, defaultValue)`                  | Переводит ключ с опциональными параметрами и значением по умолчанию.                                                                       |
| `tc(key, params, defaultValue)`                 | Переводит ключ с поддержкой множественного числа.                                                                                          |
| `setTranslationsFromJson(locale, translations)` | Загружает переводы из JSON-объекта для указанной локали.                                                                                   |
| `getLocale()`                                   | Возвращает текущую локаль.                                                                                                                 |
| `setLocale(val)`                                | Устанавливает текущую локаль.                                                                                                              |
| `getLocaleName()`                               | Возвращает имя текущей локали.                                                                                                             |
| `setLocaleName(val)`                            | Устанавливает имя текущей локали.                                                                                                          |
| `getLocales()`                                  | Возвращает список доступных локалей.                                                                                                       |
| `setLocales(val)`                               | Устанавливает список доступных локалей.                                                                                                    |
| `defaultLocale()`                               | Возвращает локаль по умолчанию.                                                                                                            |
| `setDefaultLocale(val)`                         | Устанавливает локаль по умолчанию.                                                                                                         |
| `getRouteName()`                                | Возвращает имя текущего маршрута.                                                                                                          |
| `settRouteName(val)`                            | Устанавливает имя текущего маршрута.                                                                                                       |
| `ts(key, params, defaultValue)`                 | Переводит ключ и возвращает результат как строку.                                                                                          |
| `tn(value, options?)`                           | Форматирует число с инлайновыми `Intl.NumberFormatOptions`. Именованные форматы требуют конфигурацию модуля и в этом отдельном хелпере недоступны. |
| `td(value, options?)`                           | Форматирует дату с инлайновыми `Intl.DateTimeFormatOptions`. Именованные форматы требуют конфигурацию модуля и в этом отдельном хелпере недоступны. |
| `has(key)`                                      | Проверяет наличие ключа перевода.                                                                                                          |
| `resolveTranslations()`                             | Возвращает активное дерево переводов для текущей локали и маршрута.                                                                    |
| `setTranslation(key, value)`                    | Заменяет значение по ключу `key` в активном словаре (замена, не merge).                                                                    |
| `mergeTranslations(newTranslations)`              | Мёржит переводы в активную локаль в рантайме.                                                                                              |

Следуя этим шагам, вы сможете эффективно тестировать модуль `Nuxt I18n Micro` и убедиться, что функции локализации приложения работают как ожидается.
