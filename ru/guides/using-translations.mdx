# Использование переводов в компонентах

После установки и настройки модуля вы можете отображать переводы, вызывая `$t('your_key')` в шаблонах и скриптах Vue.

## 1. Файлы переводов корневого уровня и для конкретных страниц

1. **Переводы корневого уровня** располагаются непосредственно в папке `/locales` (например, `/locales/en.json`, `/locales/fr.json`). На этапе сборки они автоматически объединяются с каждым файлом конкретной страницы, что делает их доступными на всех страницах.
2. **Переводы для конкретных страниц** находятся в `/locales/pages/...` и соответствуют структуре папок ваших страниц Nuxt:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. Использование в шаблонах с `$t`

В `.vue` файлах вы можете напрямую использовать `$t` в шаблоне:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
`$t` может возвращать **объекты**, если ключ указывает на вложенный JSON-узел (например, `$t('header')` → `\{ title: "Hi" \}`). В шаблонах это отобразится как `[object Object]`. Используйте `$ts`, когда нужно гарантированно получить строку, или указывайте более конкретный ключ, например `$t('header.title')`. Подробности см. в [Справочнике API — $t vs $ts](/api/methods#t).
</Tip>

## 3. Переключение текущей локали

Чтобы изменить язык в вашем приложении, вы можете получить `$locale` из `useI18n()` и присвоить ему новый код:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. Вложенные ключи и плейсхолдеры

- **Вложенные ключи** используют точечную нотацию, например `nested.key.deeper`.
- **Плейсхолдеры** позволяют вставлять динамические значения:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. Советы и лучшие практики

- **Конфликтующие ключи**: если файл конкретной страницы содержит тот же ключ, что и файл корневого уровня, приоритет отдаётся версии страницы (переводы корневого уровня объединяются как база на этапе сборки).
- **Отключение файлов страниц**: если вы предпочитаете не использовать переводы для отдельных страниц, установите `disablePageLocales: true` в конфигурации Nuxt. В этом случае будут использоваться только файлы `/locales/*.json`.
- **Никаких прямых импортов**: вам не нужно писать `import \{ useI18n \} from 'nuxt-i18n-micro'`; функция автоинжекции модуля делает это за вас.

Вот и всё! Выполнив эти шаги, вы можете быстро **начать получать переводы** из JSON-файлов корневого уровня или конкретных страниц и **отображать их** в вашем приложении Nuxt с помощью `$t`.

## Дополнительные ресурсы

Чтобы изучить более продвинутые возможности, обязательно ознакомьтесь с:

1. **Компонент `<i18n-t>`**  
   Компонент `<i18n-t>` — мощная альтернатива `$t`, особенно полезная в случаях с вложенными элементами, продвинутым использованием плейсхолдеров и более сложными структурами переводов.

- **Документация**: [i18n-t](/api/components/i18n-t)

2. **Composable `useI18n`**  
   Composable `useI18n` предлагает полный набор функций и реактивных свойств для управления переводами, переключения локалей, форматирования и многого другого.

- **Документация**: [useI18n](/api/composables/use-i18n)
