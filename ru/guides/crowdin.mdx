# 🌐 Руководство по интеграции с Crowdin

## 📖 Введение

Интеграция Crowdin в ваш проект упрощает процесс локализации и перевода, облегчая управление переводами на нескольких языках и платформах. Это руководство содержит пошаговые инструкции по настройке Crowdin в вашем проекте, включая конфигурацию, загрузку исходных файлов и скачивание переводов.

## 🔧 Установка и настройка

Чтобы начать работу с Crowdin, необходимо установить Crowdin CLI глобально на вашей машине и инициализировать его в директории проекта.

### 📦 Установка Crowdin CLI

Сначала установите Crowdin CLI глобально через npm:

```bash
npm install -g @crowdin/cli
```

### 🛠 Инициализация Crowdin в вашем проекте

Инициализируйте Crowdin в вашем проекте, выполнив команду:

```bash
crowdin init
```

Эта команда проведёт вас через процесс настройки, включая установку идентификатора проекта, API-токена и других параметров конфигурации.

## 🗂️ Руководство по конфигурации

### 📄 Файл конфигурации Crowdin (`crowdin.yml`)

Файл конфигурации Crowdin (`crowdin.yml`) определяет, как сопоставляются ваши исходные файлы и куда должны помещаться переводы. Ниже приведён пример конфигурации:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Ключевые параметры конфигурации

- **`project_id`**: идентификатор вашего проекта Crowdin. Определяет проект в Crowdin, где управляются переводы.
- **`api_token`**: API-токен для аутентификации. Убедитесь, что у токена есть соответствующие права на загрузку и скачивание переводов.
- **`base_path`**: указывает базовую директорию для исходных файлов. В этом примере переводы хранятся в директории `./locales`.
- **`base_url`**: базовый URL для API Crowdin.
- **`preserve_hierarchy`**: если установлено `true`, Crowdin сохранит структуру папок ваших исходных файлов в проекте.

### 📂 Конфигурация файлов

Секция `files` сопоставляет ваши исходные файлы с путями, где будут храниться переводы. Например:

- **Путь к источнику**: определяет расположение оригинальных файлов переводов.
- **Путь перевода**: указывает, где будут храниться переведённые файлы в Crowdin. Плейсхолдеры вроде `%two_letters_code%` используются для динамической подстановки кода языка в пути к файлам.

## ⬆️ Загрузка исходных файлов в Crowdin

После настройки конфигурации Crowdin вы можете загрузить исходные файлы следующей командой:

```bash
crowdin upload sources
```

Эта команда загружает все указанные в конфигурации исходные файлы в Crowdin, делая их доступными для перевода.

## ⬇️ Скачивание переводов из Crowdin

После завершения или обновления переводов в Crowdin вы можете скачать их в проект командой:

```bash
crowdin download
```

Эта команда получает актуальные переводы из Crowdin и сохраняет их в соответствии с путями, указанными в вашем файле конфигурации.

## ⚙️ Лучшие практики

### 🔑 Согласованное именование ключей

Используйте согласованные ключи переводов во всех файлах, чтобы избежать путаницы и дублирования.

### 🧹 Регулярное обслуживание

Периодически проверяйте и очищайте неиспользуемые ключи переводов, чтобы файлы оставались упорядоченными и удобными в управлении.

### 🛠 Автоматизируйте загрузку и скачивание

Интегрируйте команды Crowdin CLI в ваш конвейер CI/CD, чтобы автоматизировать загрузку исходных файлов и скачивание переводов, обеспечивая актуальность переводов.

Следуя этому руководству, вы сможете плавно интегрировать Crowdin в свой проект, обеспечив эффективный и упорядоченный подход к управлению интернационализацией.
