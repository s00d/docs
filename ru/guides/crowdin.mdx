# 🌐 Руководство по интеграции с Crowdin

## 📖 Введение

Интеграция Crowdin в ваш проект упрощает процесс локализации и перевода, облегчая управление переводами на разных языках и платформах. Это руководство даёт пошаговую инструкцию по настройке Crowdin для вашего проекта, включая конфигурацию, загрузку исходных файлов и скачивание переводов.

## 🔧 Установка и настройка

Чтобы начать работу с Crowdin, установите Crowdin CLI глобально и инициализируйте его в каталоге проекта.

### 📦 Установка Crowdin CLI

Сначала установите Crowdin CLI глобально через npm:

```bash
npm install -g @crowdin/cli
```

### 🛠 Инициализация Crowdin в проекте

Инициализируйте Crowdin в проекте командой:

```bash
crowdin init
```

Эта команда проведёт вас через процесс настройки, включая указание ID проекта, API-токена и других параметров конфигурации.

## 🗂️ Руководство по конфигурации

### 📄 Файл конфигурации Crowdin (`crowdin.yml`)

Файл конфигурации Crowdin (`crowdin.yml`) описывает, как сопоставляются исходные файлы и куда должны попадать переводы. Ниже пример конфигурации:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Ключевые параметры конфигурации

- **`project_id`**: ID вашего проекта Crowdin. Идентифицирует проект в Crowdin, где ведутся переводы.
- **`api_token`**: API-токен, используемый для аутентификации. Убедитесь, что у токена есть права на загрузку и скачивание переводов.
- **`base_path`**: Указывает базовый каталог для исходных файлов. В примере переводы находятся в `./locales`.
- **`base_url`**: Базовый URL Crowdin API.
- **`preserve_hierarchy`**: Если `true`, Crowdin сохранит структуру папок исходных файлов в проекте.

### 📂 Настройка файлов

Секция `files` сопоставляет исходные файлы с путями, по которым будут храниться переводы. Например:

- **Source Path**: Задаёт расположение оригинальных файлов переводов.
- **Translation Path**: Указывает, куда Crowdin будет сохранять переведённые файлы. Плейсхолдеры вроде `%two_letters_code%` используются для динамической подстановки кода языка в пути.

## ⬆️ Загрузка исходных файлов в Crowdin

Когда конфигурация Crowdin готова, вы можете загрузить исходные файлы командой:

```bash
crowdin upload sources
```

Эта команда загружает все указанные в конфигурации исходные файлы в Crowdin, делая их доступными для перевода.

## ⬇️ Скачивание переводов из Crowdin

Когда переводы в Crowdin завершены или обновлены, скачайте их в проект:

```bash
crowdin download
```

Эта команда получает актуальные переводы из Crowdin и сохраняет их согласно путям, указанным в файле конфигурации.

## ⚙️ Лучшие практики

### 🔑 Единообразное именование ключей

Убедитесь, что ключи переводов согласованы между всеми файлами, чтобы избежать путаницы и дублирования.

### 🧹 Регулярное обслуживание

Периодически проверяйте и удаляйте неиспользуемые ключи, чтобы файлы оставались упорядоченными и удобными в сопровождении.

### 🛠 Автоматизация загрузки и скачивания

Встройте команды Crowdin CLI в ваш CI/CD-пайплайн, чтобы автоматизировать загрузку исходных файлов и скачивание переводов и всегда держать переводы актуальными.

Следуя этому руководству, вы сможете органично интегрировать Crowdin в проект, обеспечив эффективный и упорядоченный подход к управлению интернационализацией.
