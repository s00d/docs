# 🛠️ DevTools в `nuxt-i18n-micro`

## Vue DevTools (расширение браузера)

В режиме разработки модуль может регистрировать пользовательский инспектор и таймлайн **Vue DevTools** через `@vue/devtools-api`. Это отдельное решение от вкладки Nuxt DevTools, описанной ниже.

| Инструмент | Лучше всего подходит для |
|------|----------|
| **Vue DevTools** | Активная локаль, in-memory кэш переводов, таймлайн `$t` (`debug: true`), события пропущенных ключей |
| **Вкладка Nuxt DevTools** | Правка JSON-файлов на диске, обзор конфигурации, импорт/экспорт |

Плагин vue-devtools регистрируется только во время `nuxt dev` (не в production-сборках). Dev-only состояние моста в основном плагине удаляется благодаря dead-code elimination через `import.meta.dev`.

Отключить браузерную интеграцию, оставив вкладку Nuxt:

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

Подробные события таймлайна `$t` требуют `debug: true`.

## 📖 Что такое Nuxt DevTools?

DevTools — это мощный помощник разработчика, органично встроенный в модуль `nuxt-i18n-micro`. Он предоставляет интуитивно понятный интерфейс для управления локализацией и задачами перевода, ускоряя и упрощая вашу работу. Nuxt DevTools рассчитан на разработчиков, которые ценят удобство, и стирает границу между написанием кода и управлением рантаймом.

## 🌟 Ключевые возможности DevTools в `nuxt-i18n-micro`

### 1. **Управление локалями**

Легко просматривайте, выбирайте и управляйте локалями в приложении. Работаете ли вы с одним языком или с несколькими, DevTools предоставляет единый центр управления настройками локализации.

### 2. **Редактирование переводов**

Правьте файлы переводов прямо во встроенном редакторе JSON. Это избавляет от необходимости во внешних инструментах и позволяет вносить изменения в реальном времени, не прерывая рабочий процесс.

### 3. **Импорт и экспорт файлов**

Упростите работу с файлами переводов:

- **Экспорт**: Сохраните переводы в JSON для резервных копий или внешнего использования.
- **Импорт**: Загружайте обновлённые файлы переводов в проект, чтобы поддерживать актуальность содержимого.

### 4. **Предпросмотр в реальном времени**

Смотрите изменения прямо в среде разработки. Это гарантирует, что переводы и настройки корректны ещё до выхода в продакшн.

### 5. **Плотная интеграция с Nuxt**

DevTools работает нативно с `nuxt-i18n-micro`, расширяя его возможности без дополнительной настройки. Он подстраивается под ваши задачи локализации, сохраняя модульную и гибкую структуру Nuxt.

## 🛠️ Зачем использовать DevTools?

Nuxt DevTools — незаменимое дополнение для проектов, где нужна локализация. Он помогает разработчикам:

- **Экономить время**: Автоматизирует рутинные задачи вроде управления файлами и проверки формата.
- **Уменьшать количество ошибок**: Предоставляет безопасное и понятное окружение для правки переводов.
- **Улучшать совместную работу**: Позволяет не-разработчикам управлять переводами.
- **Оптимизировать процессы**: Объединяет разные задачи локализации в едином интерфейсе.

## 🚀 Возьмите локализацию под контроль

С Nuxt DevTools в связке с `nuxt-i18n-micro` управление многоязычными приложениями становится простым и эффективным. Подстраиваете ли вы переводы или добавляете новые локали, DevTools даёт всё необходимое, чтобы создавать отточенные и удобные для пользователя интерфейсы.
