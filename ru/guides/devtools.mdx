# 🛠️ DevTools в `nuxt-i18n-micro`

## Vue DevTools (расширение браузера)

В режиме разработки модуль может регистрировать пользовательский инспектор и таймлайн **Vue DevTools** через `@vue/devtools-api`. Это отдельная функция, независимая от вкладки Nuxt DevTools, описанной ниже.

| Инструмент | Лучше всего подходит для |
|------|----------|
| **Vue DevTools** | Текущая локаль, кэш переводов в памяти, таймлайн `$t` (`debug: true`), события отсутствующих ключей |
| **Вкладка Nuxt DevTools** | Редактирование JSON-файлов на диске, обзор конфигурации, импорт/экспорт |

Плагин vue-devtools регистрируется только во время `nuxt dev` (не в production-сборках). Состояние моста только для разработки в основном плагине удаляется благодаря устранению мёртвого кода `import.meta.dev`.

Отключить интеграцию с браузером, сохранив вкладку Nuxt:

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

Подробные события таймлайна `$t` требуют `debug: true`.

## 📖 Что такое Nuxt DevTools?

DevTools — это мощный помощник разработчика, легко интегрированный в модуль `nuxt-i18n-micro`. Он предоставляет интуитивно понятный интерфейс для управления задачами локализации и перевода, делая ваш рабочий процесс быстрее и эффективнее. Разработанный для тех, кто ценит удобство, Nuxt DevTools устраняет разрыв между написанием кода и управлением во время выполнения.

## 🌟 Ключевые возможности DevTools в `nuxt-i18n-micro`

### 1. **Управление локалями**

Легко просматривайте, выбирайте и управляйте локалями в вашем приложении. Работаете ли вы с одним языком или несколькими — DevTools предоставляет централизованный интерфейс для всех настроек локализации.

### 2. **Редактирование переводов**

Редактируйте файлы переводов прямо через встроенный JSON-редактор. Это устраняет необходимость во внешних инструментах, позволяя выполнять обновления и изменения в реальном времени, не прерывая рабочий процесс.

### 3. **Импорт и экспорт файлов**

Упростите процесс управления файлами переводов:

- **Экспорт**: сохраняйте переводы в JSON для резервных копий или внешнего использования.
- **Импорт**: загружайте обновлённые файлы переводов в проект, чтобы контент оставался актуальным.

### 4. **Предпросмотр в реальном времени**

Просматривайте изменения сразу же в среде разработки. Эта функция гарантирует, что переводы и конфигурации будут точными перед публикацией.

### 5. **Бесшовная интеграция с Nuxt**

DevTools работает нативно с `nuxt-i18n-micro`, расширяя его возможности без дополнительной настройки. Он адаптируется к вашим потребностям локализации, сохраняя модульную и гибкую структуру Nuxt.

## 🛠️ Зачем использовать DevTools?

Nuxt DevTools — незаменимое дополнение для проектов, требующих локализации. Он помогает разработчикам:

- **Экономить время**: автоматизирует повторяющиеся задачи, такие как управление файлами и проверка формата.
- **Уменьшать количество ошибок**: предоставляет безопасную и интуитивную среду для редактирования переводов.
- **Улучшать совместную работу**: позволяет специалистам, не являющимся разработчиками, легко управлять переводами.
- **Оптимизировать рабочие процессы**: объединяет несколько задач локализации в едином интерфейсе.
