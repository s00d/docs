Nuxt I18n Micro — это лёгкий и производительный модуль i18n для Nuxt, разработанный для крупных проектов. Он сокращает время сборки, потребление памяти и размер бандла по сравнению с традиционными решениями i18n, такими как `@nuxtjs/i18n`.

Ядро — это один модуль Nuxt плюс небольшой набор runtime-плагинов. Префиксы локалей обрабатываются пакетами `@i18n-micro/route-strategy` (на этапе сборки) и `@i18n-micro/path-strategy` (во время выполнения). Переводы хранятся только в JSON и разделены на общие корневые файлы и файлы для каждой страницы, которые автоматически генерируются в режиме разработки.

## Когда использовать Nuxt I18n Micro

- Вам нужны лениво загружаемые переводы для каждой страницы без раздувания payload Nitro.
- Вы хотите маршрутизацию на основе стратегий без накладных расходов на генерацию маршрутов во время выполнения.
- Вам нужно, чтобы SSR и edge-развёртывания оставались быстрыми под нагрузкой.
- Вы переходите с `@nuxtjs/i18n` и хотите меньший runtime с похожей эргономикой.
