Nuxt I18n Micro — лёгкий высокопроизводительный модуль i18n для Nuxt 3 и 4, созданный для крупных проектов. По сравнению с традиционными решениями i18n, такими как `@nuxtjs/i18n`, он сохраняет низкими время сборки, потребление памяти и размер бандла.

Локализованные маршруты генерируются на этапе сборки пакетом `@i18n-micro/route-strategy` и разрешаются во время выполнения пакетом `@i18n-micro/path-strategy`, поэтому ссылки, переключатель, `hreflang` и редиректы согласованы с роутером. Переводы хранятся только в JSON и разделены на общие корневые файлы и файлы отдельных страниц, которые сервер разработки создаёт за вас; HMR встроен.

<CodeGroup>

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>
