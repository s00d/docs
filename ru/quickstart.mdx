## 🚀 Быстрый старт

### Установка

Установите модуль в ваше приложение Nuxt:

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

### Базовая конфигурация

Добавьте модуль в `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

<Tip>
- **Корневые файлы** (`locales/en.json` и т. п.) — переводы, общие для всего приложения (меню, подвал, общий UI). При `translationPayloads.mode: 'premerged'` (по умолчанию) они объединяются в каждую страницу на этапе сборки.
- **Файлы для конкретных страниц** (`locales/pages/<route>/<locale>.json`) — переводы, уникальные для отдельных страниц, загружаются только при посещении страницы.
- **Динамические маршруты** — `pages/articles/[id].vue` соответствует каталогу `locales/pages/articles-id/` (скобки заменяются на дефисы).
- **Автогенерация** — все недостающие файлы переводов автоматически создаются во время `nuxt dev`.
</Tip>

<Info>
Модуль поддерживает обе раскладки:

- **Страницы**: `pages/**/*.vue` (Nuxt 3) или `app/pages/**/*.vue` (Nuxt 4)
- **Переводы**: по умолчанию храните `locales/` в **корне проекта** (рекомендуемая договорённость), а не внутри `app/`

```tree
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   ├── en.json
│   └── pages/
└── nuxt.config.ts
```

Опциональное совместное размещение: `i18n: \{ translationDir: 'app/locales' \}` (см. [фикстуру `n3`](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/n3)).

Для опционального CLI-помощника `text-to-i18n` используйте [`nuxt-i18n-micro-cli` ≥ 2.1.1](/guides/cli#-text-to-i18n-command), чтобы `app/pages` и `app/components` сканировались из корня проекта.
</Info>

### Базовое использование

Используйте переводы в компонентах:

```vue
<template>
  <div>
    <h1>{{ $t('welcome') }}</h1>
    <p>{{ $t('description', { name: 'World' }) }}</p>

    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" @click="$switchLocale(locale.code)">
        {{ locale.code }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useI18n } from '#imports'

const { $t, $getLocales, $switchLocale } = useI18n()
</script>
```
