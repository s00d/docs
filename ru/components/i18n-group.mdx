---
title: "<i18n-group>"
description: "Компонент <i18n-group> передаёт в свой слот функцию t, привязанную к префиксу ключей."
---

`<i18n-group>` привязывает блок разметки к одному префиксу ключей. Используйте его, когда многие ключи раздела имеют общий префикс и вы не хотите его повторять. Слот по умолчанию получает `t`, которая добавляет этот префикс.

## Свойства и слот {#props-and-slot}

| Свойство | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | Префикс ключей, относительно которого разрешается каждый поиск внутри слота. |
| `groupClass` | `string` | `''` | Дополнительный класс для элемента-обёртки. |

**\*** обязательно.

### Слоты {#slots}

| Слот | Привязки | Описание |
| --- | --- | --- |
| `default` | `prefix`, `t` | Получает `prefix` и функцию `t`, привязанную к нему. |

## Поведение {#behaviour}

- Оборачивает слот в `<div class="i18n-group {groupClass}">`.
- `t(key, params)` — это `$t(prefix + '.' + key, params)` для текущего маршрута.
- Привязана только `t` слота: `$t` и вложенные `<i18n-t>` внутри группы по-прежнему принимают полные ключи.

## Пример {#example}

```json
{
  "checkout": { "title": "Checkout", "items": "Items: {count}" }
}
```

```vue
<template>
  <i18n-group prefix="checkout" group-class="checkout">
    <template #default="{ t }">
      <h2>{{ t('title') }}</h2>
      <p>{{ t('items', { count: 3 }) }}</p>
    </template>
  </i18n-group>
</template>
```
