title: "<i18n-switcher>"
description: "Компонент <i18n-switcher> — выпадающий список включённых локалей, каждая из которых ведёт на текущую страницу в этой локали."
---

`<i18n-switcher>` отображает кнопку с активной локалью и выпадающий список всех включённых локалей, включая активную. Используйте его как готовое языковое меню; если нужна другая разметка, соберите собственное меню из [`$getLocales`](/ru/api/methods#$getlocales) и [`$switchLocalePath`](/ru/api/methods#$switchlocalepath). Каждый пункт ведёт на текущую страницу в соответствующей локали.

## Пропсы и слоты {#props-and-slots}

| Проп | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `customLabels` | `Record<string, string>` | `() => ({})` | Отображаемое имя для каждого кода локали; переопределяет `displayName` из конфигурации локали. |
| `customWrapperStyle` | `CSSProperties` | `() => ({})` | Inline-стиль для внешней обёртки. |
| `customButtonStyle` | `CSSProperties` | `() => ({})` | Inline-стиль для кнопки, открывающей выпадающий список. |
| `customDropdownStyle` | `CSSProperties` | `() => ({})` | Inline-стиль для панели выпадающего списка. |
| `customItemStyle` | `CSSProperties` | `() => ({})` | Inline-стиль для каждого пункта выпадающего списка. |
| `customLinkStyle` | `CSSProperties` | `() => ({})` | Inline-стиль для ссылки внутри пункта. |
| `customActiveLinkStyle` | `CSSProperties` | `() => ({})` | Inline-стиль для ссылки текущей активной локали. |
| `customDisabledLinkStyle` | `CSSProperties` | `() => ({})` | Inline-стиль для кнопки *текущей* локали, когда в конфигурации у неё указано `disabled: true`. |
| `customIconStyle` | `CSSProperties` | `() => ({})` | Inline-стиль для значка-стрелки на кнопке. |

### Слоты {#slots}

| Слот | Привязки | Описание |
| --- | --- | --- |
| `before-button` | — | Содержимое перед кнопкой, открывающей выпадающий список. |
| `before-selected-locale` | — | Содержимое перед подписью активной локали внутри кнопки. |
| `after-selected-locale` | — | Содержимое после подписи активной локали внутри кнопки. |
| `before-dropdown` | — | Содержимое между кнопкой и панелью выпадающего списка. |
| `before-dropdown-items` | — | Содержимое в верхней части выпадающего списка, над списком локалей. |
| `before-item` | `locale` | Содержимое перед каждым пунктом локали. |
| `before-link-content` | `locale` | Содержимое перед подписью локали внутри её ссылки. |
| `after-link-content` | `locale` | Содержимое после подписи локали внутри её ссылки. |
| `after-item` | `locale` | Содержимое после каждого пункта локали. |
| `after-dropdown-items` | — | Содержимое в нижней части выпадающего списка, под списком локалей. |
| `after-dropdown` | — | Содержимое после панели выпадающего списка. |

## Поведение {#behaviour}

- Перечисляет все локали без `disabled: true`, включая активную.
- Каждый пункт — это `<a>`, ведущий на `$switchLocalePath(code)`. Путь разрешается относительно `app.baseURL`; `baseUrl` локали на другом домене остаётся абсолютным. У ссылки заданы `hreflang` и `lang` со значением `iso || code`, `dir`, если он есть у локали, `aria-current="page"` у текущей локали и класс `switcher-locale-<code>`. Клик вызывает `$switchLocale(code)` и закрывает выпадающий список; клик с клавишей-модификатором обрабатывается браузером.
- Список остаётся в серверном HTML в скрытом виде, поэтому поисковые роботы видят ссылки. Escape или клик вне списка закрывает его.
- Подпись: `customLabels[code]`, затем `displayName` локали, затем код (с предупреждением в режиме разработки).
- Стили: небольшие inline-стили по умолчанию (белые кнопка и панель с рамкой, активный пункт выделен жирным и синим). Каждый проп `custom*Style` применяется после стиля по умолчанию для своей части. У кнопки есть классы `i18n-switcher-button` и `language-switcher`, у обёртки — `i18n-switcher-wrapper`, у списка — `i18n-switcher-dropdown`. Позиционирование использует логические CSS-свойства, поэтому `dir="rtl"` работает.

## Пример {#example}

```vue
<template>
  <i18n-switcher
    :custom-labels="{ en: 'English', de: 'Deutsch' }"
    :custom-button-style="{ borderRadius: '4px' }"
  >
    <template #before-link-content="{ locale }">
      <img :src="`/flags/${locale.code}.svg`" alt="" width="16" />
    </template>
  </i18n-switcher>
</template>
```
