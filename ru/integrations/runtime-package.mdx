---

`@i18n-micro/runtime` — это независимый от фреймворка экземпляр i18n: словари, `t()`, множественные формы, форматирование через `Intl` и подписка на изменения, без `fs` и без фреймворка. Используйте его в обычном TypeScript, в веб-воркере, в edge-функции или как основу для собственной привязки. Пакеты для React, Preact, Node и Astro расширяют этот же класс.

## Установка {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/runtime
```

```bash npm
npm install @i18n-micro/runtime
```

```bash yarn
yarn add @i18n-micro/runtime
```

</CodeGroup>

Peer-зависимостей нет. Для файлов переводов на диске используйте [`@i18n-micro/node`](/ru/integrations/nodejs-package).

## Настройка {#setup}

```ts
import { createI18n } from '@i18n-micro/runtime'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    en: { greeting: 'Hello, {name}!', apples: 'no apples | one apple | {count} apples' },
    de: { greeting: 'Hallo, {name}!' },
  },
  routeMessages: {
    about: { en: { title: 'About us' } },
  },
})
```

Все опции (`plural`, `missingWarn`, `missingHandler`, `numberFormats`, `datetimeFormats`) перечислены в разделе [Экземпляр](/ru/integrations/overview#the-instance).

## Перевод {#translate}

```ts
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.tc('apples', 5) // '5 apples'
i18n.tn(1234.5) // '1,234.5'

i18n.setRoute('about')
i18n.t('title') // 'About us' (route dictionary)
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!' (root, still visible)
```

Дополнительные словари можно загрузить позже:

```ts
i18n.loadMessages({ fr: { greeting: 'Bonjour, {name} !' } }, { about: { fr: { title: 'À propos' } } })
i18n.addTranslations('fr', { nav: { home: 'Accueil' } }) // deep merge; pass false to replace

await i18n.loadFromUrl('/locales/fr.json', { locale: 'fr' })
await i18n.loadFromUrl('/locales/pages/about/fr.json', { locale: 'fr', routeName: 'about' })
await i18n.loadFromUrls([
  { url: '/locales/en.json', locale: 'en' },
  { url: '/locales/de.json', locale: 'de' },
])
```

`loadFromUrl` использует `fetch` (передайте `init` для заголовков) и выбрасывает ошибку при ответе с не-OK статусом. `loadFromUrls` загружает файлы один за другим.

## Смена локали {#switch-locale}

```ts
i18n.locale = 'de'
i18n.t('greeting', { name: 'Ada' }) // 'Hallo, Ada!'
```

Изменения локали, маршрута и словарей уведомляют подписчиков — так привязки к фреймворкам выполняют повторный рендеринг:

```ts
const stop = i18n.subscribe(() => {
  document.querySelector('#greeting')!.textContent = i18n.t('greeting', { name: 'Ada' }) as string
})
i18n.locale = 'fr'
stop()
```

`getSnapshot()` возвращает строку, которая меняется при каждом уведомлении (для хранилищ в стиле `useSyncExternalStore`).

## На каждый запрос {#per-request}

Экземпляр хранит одну локаль и один маршрут. На сервере не переключайте общий экземпляр для каждого запроса: два одновременных запроса увидят локали друг друга. `i18n.fork(locale)` даёт запросу собственный экземпляр: свои локаль, резервную локаль и маршрут; те же словари, форматтеры и правила. Стоимость форка не зависит от количества словарей. Форк видит записи в родительский экземпляр до своей первой собственной записи, а его записи остаются в нём. [Node.js](/ru/integrations/nodejs-package#per-request) добавляет `run`.

## API {#api}

| Член | Примечания |
| --- | --- |
| `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has` | см. [Перевод и форматирование](/ru/integrations/overview#translate-and-format) |
| `locale`, `fallbackLocale` | чтение/запись |
| `currentRoute`, `setRoute(name)`, `getRoute()` | активный маршрут, по умолчанию `'index'` |
| `loadMessages(messages?, routeMessages?)` | объединение многих локалей и маршрутов за один раз |
| `addTranslations(locale, tree, merge = true)`, `addRouteTranslations(locale, route, tree, merge = true)` | |
| `loadFromUrl(url, { locale?, routeName?, init? })`, `loadFromUrls(entries)` | JSON через `fetch` |
| `hasTranslation(key)` | активная локаль, любой маршрут (в отличие от `has`, который проверяет активный маршрут и корень) |
| `setTranslation(key, value)`, `resolveTranslations()` | запись одного ключа; чтение объединённого дерева |
| `clear()`, `clearCache()` | удаление всех словарей |
| `subscribe(cb)`, `getSnapshot()` | уведомления об изменениях |
| `storage` | `{ translations: Map<'locale:route', Translations> }` |

Код, не являющийся языковым тегом, получает правила множественного числа из `localeIso: { ua: 'uk-UA' }`; `localeIsoMap(locales)` строит такое соответствие из тех элементов списка локалей, у которых есть `iso`.

Экспорты модуля: `createI18n`, `I18n`, `fetchJsonTranslations`, `FormatService`, `interpolate`, `localeIsoMap` и типы `I18nOptions`, `LoadFromUrlOptions`, `LoadFromUrlEntry`, `TranslationStorage`, `Translations`, `Locale`, `PluralFunc`. Полные сигнатуры: [справочник пакета](/ru/api/packages/runtime).
