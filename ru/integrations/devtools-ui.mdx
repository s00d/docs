# Пакет DevTools UI (`@i18n-micro/devtools-ui`)

Пакет `@i18n-micro/devtools-ui` предоставляет самостоятельный интерфейс инструментов разработчика для управления переводами. Он включает Vite-плагин для автоматической интеграции и универсальную систему bridge для поддержки i18n в любом фреймворке.

## Обзор

`@i18n-micro/devtools-ui` — самодостаточный пакет, предоставляющий:

- **Vite-плагин** — автоматическая инъекция кнопки и API-эндпоинтов.
- **Универсальный Bridge** — независимая от фреймворка сборка bridge для любой реализации i18n.
- **Web Component** — кастомный элемент для DevTools UI.
- **Работа с файлами** — список, загрузка и сохранение файлов переводов через API.

## Быстрый старт

### Настройка Vite-плагина

Самый простой способ использовать DevTools — через Vite-плагин, который автоматически внедряет плавающую кнопку и предоставляет нужные API-эндпоинты:

```typescript
import { defineConfig } from 'vite'
import { i18nDevToolsPlugin } from '@i18n-micro/devtools-ui/vite'

export default defineConfig({
  plugins: [
    // ... other plugins
    i18nDevToolsPlugin({
      base: '/__i18n_api', // Optional: API endpoint base path (default: '/__i18n_api')
      translationDir: 'src/locales', // Optional: translation files directory
      injectButton: true, // Optional: automatically inject floating button (default: true)
    }),
  ],
})
```

### Опции плагина

```typescript
interface DevToolsPluginOptions {
  base?: string // API endpoint base path (default: '/__i18n_api')
  translationDir?: string // Translation files directory (default: 'src/locales')
  injectButton?: boolean // Automatically inject floating button (default: true)
}
```

## Возможности

### Автоматическая инъекция кнопки

Плагин автоматически добавляет плавающую кнопку в правый нижний угол приложения:

- **Умное скрытие** — кнопка прячется, когда курсор далеко (>200px).
- **Частичная видимость** — даже в свёрнутом виде остаётся видна небольшая часть для удобного доступа.
- **Плавные анимации** — переходы и hover-эффекты ради удобного UX.
- **Автопоказ при наведении** — кнопка полностью проявляется при наведении на видимую часть.

### API-эндпоинты

Плагин предоставляет следующие API-эндпоинты:

#### `GET /__i18n_api/files`

Получить список всех файлов переводов и структуру каталогов.

**Ответ:**

```json
{
  "files": ["en.json", "fr.json", "pages/home/en.json"],
  "structure": {
    "en.json": "en.json",
    "fr.json": "fr.json",
    "pages": {
      "home": {
        "en.json": "pages/home/en.json"
      }
    }
  }
}
```

#### `GET /__i18n_api/file?path=...`

Загрузить конкретный файл перевода.

**Query-параметры:**

- `path` — относительный путь к файлу перевода (например, `en.json` или `pages/home/en.json`).

**Ответ:**

```json
{
  "success": true,
  "content": {
    "welcome": "Welcome",
    "hello": "Hello"
  },
  "path": "en.json"
}
```

#### `POST /__i18n_api/save`

Сохранить содержимое перевода в файл.

**Тело запроса:**

```json
{
  "file": "en.json",
  "content": {
    "welcome": "Welcome",
    "hello": "Hello"
  }
}
```

**Ответ:**

```json
{
  "success": true
}
```

#### `GET /__i18n_api/config`

Получить конфигурацию i18n.

**Ответ:**

```json
{
  "defaultLocale": "en",
  "fallbackLocale": "en",
  "locales": [{ "code": "en", "displayName": "English", "iso": "en-US" }],
  "translationDir": "src/locales"
}
```

## Универсальный Bridge

Пакет предоставляет универсальную функцию создания bridge, работающую с любой реализацией i18n:

```typescript
import { createBridge } from '@i18n-micro/devtools-ui'
import type { BridgeAdapter } from '@i18n-micro/devtools-ui'

// Create an adapter for your i18n instance
const adapter: BridgeAdapter = {
  getRouteCache: () => i18nInstance.cache.route,
  addTranslations: (locale, content, merge) => {
    i18nInstance.addTranslations(locale, content, merge)
  },
  addRouteTranslations: (locale, routeName, content, merge) => {
    i18nInstance.addRouteTranslations(locale, routeName, content, merge)
  },
  subscribe: (callback) => {
    return i18nInstance.subscribe(callback)
  },
  getCurrentLocale: () => i18nInstance.locale,
  getFallbackLocale: () => i18nInstance.fallbackLocale,
}

// Create bridge
const bridge = createBridge({
  adapter,
  locales: localesConfig,
  defaultLocale: 'en',
  translationDir: 'src/locales',
})
```

### Интерфейс BridgeAdapter

```typescript
interface BridgeAdapter {
  // Get translations cache
  // Keys are in format "locale:routeName" (e.g., "en:index", "en:home")
  getRouteCache: () => Record<string, TranslationContent>

  // Add or update translations for a locale
  addTranslations: (locale: string, content: TranslationContent, merge: boolean) => void

  // Add or update route-specific translations
  addRouteTranslations: (locale: string, routeName: string, content: TranslationContent, merge: boolean) => void

  // Subscribe to changes in translations
  subscribe: (callback: () => void) => () => void

  // Get current locale (optional)
  getCurrentLocale?: () => string

  // Get fallback locale (optional)
  getFallbackLocale?: () => string
}
```

## Web Component

Пакет экспортирует кастомный элемент, которым можно пользоваться напрямую:

```typescript
import { register } from '@i18n-micro/devtools-ui'

// Register the custom element
register()

// Create and use the element
const element = document.createElement('i18n-devtools-ui')
element.bridge = bridge
document.body.appendChild(element)
```

## Безопасность

Плагин предусматривает меры безопасности:

- **Защита от path traversal** — все пути к файлам валидируются, чтобы оставаться в корне проекта.
- **Проверка расширения файла** — сохранять можно только `.json`.
- **Валидация корня проекта** — доступ к файлам возможен только внутри настроенного корня.

## Development vs Production

- **Только в разработке** — плагин работает только в режиме разработки (`apply: 'serve'`).
- **Не влияет на production** — плагин автоматически исключается из production-сборок.
- **Нулевые рантайм-расходы** — в production-бандлы код не попадает.

## Примеры

### Своя реализация Bridge

```typescript
import { createBridge } from '@i18n-micro/devtools-ui'
import type { BridgeAdapter } from '@i18n-micro/devtools-ui'

class CustomI18n {
  private cache = {
    root: {},
    route: {},
  }

  addTranslations(locale: string, content: Record<string, unknown>) {
    this.cache.root[locale] = content
  }

  subscribe(callback: () => void) {
    // Your subscription logic
    return () => {} // unsubscribe
  }
}

const customI18n = new CustomI18n()

const adapter: BridgeAdapter = {
  getRouteCache: () => customI18n.cache.route,
  addTranslations: (locale, content) => {
    customI18n.addTranslations(locale, content)
  },
  addRouteTranslations: () => {}, // Not implemented
  subscribe: (callback) => customI18n.subscribe(callback),
}

const bridge = createBridge({
  adapter,
  locales: [{ code: 'en', displayName: 'English' }],
  defaultLocale: 'en',
})
```
