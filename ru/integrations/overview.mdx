Пакеты `@i18n-micro/*` переносят ядро переводов Nuxt I18n Micro в Vue, React, Preact, Solid, Astro, VitePress и обычный JavaScript. Используйте их, когда ваше приложение не на Nuxt или когда скрипту либо серверу вне Nuxt нужны те же файлы переводов. Все пакеты используют одну модель экземпляра, один контракт адаптера роутера и одни и те же четыре компонента, которые описаны один раз на этой странице.

Точка входа роутера — отдельный импорт, поэтому приложение без роутера никогда его не включает в бандл.

`@i18n-micro/core`, `@i18n-micro/types` и `@i18n-micro/utils` устанавливаются вместе с этими пакетами; напрямую импортировать их приходится редко. Сигнатуры всех экспортов приведены в сгенерированном [справочнике пакетов](/ru/api/packages/overview).

У каждого пакета есть песочница в репозитории в `packages/<name>/playground`.

## Экземпляр {#the-instance}

`createI18n(options)` возвращает один экземпляр, который хранит словари, текущую локаль и текущий маршрут. Опции одинаковы во всех пакетах:

| Опция | Тип | По умолчанию | Примечания |
| --- | --- | --- | --- |
| `locale` | `string` | обязательна | Активная локаль. |
| `fallbackLocale` | `string` | `locale` | Используется, когда ключ отсутствует в `locale`. |
| `messages` | `Record<locale, Translations>` | `{}` | Корневые словари (маршрут `'index'`). |
| `routeMessages` | `Record<route, Record<locale, Translations>>` | `{}` | Словари маршрутов. Только Runtime, React, Preact, Node и VitePress. |
| `plural` | `PluralFunc` | `defaultPlural` | Собственное правило множественного числа. |
| `missingWarn` | `boolean` | `true` | `console.warn` в браузере для отсутствующего ключа, только в режиме разработки. |
| `missingHandler` | `(locale, key, routeName) => void` | — | Вызывается вместо предупреждения. |
| `numberFormats` | `Record<locale, Record<name, Intl.NumberFormatOptions>>` | — | Именованные форматы: `tn(9.5, 'currency')`. |
| `datetimeFormats` | `Record<locale, Record<name, Intl.DateTimeFormatOptions>>` | — | Именованные форматы: `td(date, 'short')`. |
| `timeZone` | `string` | зона среды выполнения | Часовой пояс IANA для дат `td`; на `tdr` не влияет. Задайте его, чтобы сервер и браузер рендерили одну и ту же дату. |
| `now` | `() => number` | `Date.now` | Часы для `tdr`. Передайте при гидратации время сервера, чтобы обе стороны рендерили один текст. |
| `localeIso` | `Record<code, string>` | — | Тег BCP 47 для правил множественного числа (`ua` → `uk-UA`). React, Preact и Solid берут его из `iso` в `locales` провайдера. |

Словари хранятся в `i18n.storage.translations` — `Map` с ключами `locale:route` (`en:index`, `en:about`).

Ключ ищется в словаре текущего маршрута, затем в корневом словаре, сначала для `locale`, затем для `fallbackLocale`. Отсутствующий ключ возвращает сам ключ (или переданный вами `defaultValue`).

```ts
i18n.addTranslations('en', { nav: { home: 'Home' } }) // root, deep-merged
i18n.addRouteTranslations('en', 'about', { title: 'About us' }) // route chunk
i18n.addTranslations('en', { nav: { home: 'Start' } }, false) // replace instead of merge
i18n.setRoute('about')
i18n.t('title') // 'About us'
i18n.t('nav.home') // 'Start' (root key, still visible on the route)
```

### Перевод и форматирование {#translate-and-format}

| Метод | Возвращает |
| --- | --- |
| `t(key, params?, defaultValue?, routeName?)` | Значение (строка, число, объект) с подставленными `{param}`. |
| `ts(...)` | То же, что `t`, в виде строки. |
| `tc(key, count \| params, defaultValue?)` | Форма множественного числа. |
| `tn(value, options \| name)` | `Intl.NumberFormat` в активной локали. |
| `td(value, options \| name)` | `Intl.DateTimeFormat`. |
| `tdr(value, options?)` | Относительное время (`3 days ago`). |
| `has(key, routeName?)` | `true`, если ключ есть в активной локали (в словаре маршрута или корневом; fallback не проверяется). |

`defaultPlural` разбивает значение по `|` и выбирает форму с индексом `count`, ограниченным последней формой; отрицательное, дробное или `NaN` значение `count` выбирает последнюю форму.

Собственная функция `plural` получает `(key, count, params, locale, getter)`. Читайте значение через `getter(key)`; не разбивайте ключ:

```ts
import type { PluralFunc } from '@i18n-micro/vue'

const plural: PluralFunc = (key, count, params, _locale, getter) => {
  const value = getter(key)
  if (typeof value !== 'string') return null
  const forms = value.split('|').map((form) => form.trim())
  return (count === 1 ? forms[0] : forms[1] ?? forms[0])!.replace('{count}', String(count))
}
```

## Адаптер роутера {#router-adapter}

SPA-пакеты не зависят от роутера. Адаптер роутера (`I18nRoutingStrategy`) сообщает им, как читать текущий путь, выполнять навигацию и строить локализованный путь. Встроенные адаптеры добавляют префикс ко всем локалям, кроме `defaultLocale` (`/about`, `/de/about`).

| Член | Обязателен | Где используется |
| --- | --- | --- |
| `getCurrentPath(): string` | да | проверка активной ссылки (по странице, query и hash не учитываются), `switchLocale` (сохраняет их) |
| `push({ path }): void` | да | `switchLocale`, `<I18nLink>` без `linkComponent`, `<I18nSwitcher>` |
| `replace({ path }): void` | да | — |
| `resolvePath(to, locale)` | нет | `localePath`, `localeRoute`, `<I18nLink>`; без него пути возвращаются как есть |
| `linkComponent` | нет | `<I18nLink>` рендерит его (например, `RouterLink`) вместо `<a>` |
| `getRoute()` | нет | `{ fullPath, query }` для SEO-хелперов |

`push` и `replace` обязательны в Vue, React, Preact и Solid. У Astro свой серверный адаптер с необязательными `push`/`replace` (см. [Astro](/ru/integrations/astro-package#router-adapter)).

Минимальный адаптер для любого роутера на основе history:

```ts
import type { I18nRoutingStrategy } from '@i18n-micro/react'

const locales = ['en', 'de']
const stripLocale = (path: string) => path.replace(/^\/(en|de)(?=\/|$)/, '') || '/'

export const historyAdapter: I18nRoutingStrategy = {
  getCurrentPath: () => window.location.pathname + window.location.search + window.location.hash,
  push: ({ path }) => window.history.pushState({}, '', path),
  replace: ({ path }) => window.history.replaceState({}, '', path),
  resolvePath: (to, locale) => {
    const path = stripLocale(typeof to === 'string' ? to : to.path || '/')
    return locale === 'en' ? path : `/${locale}${path === '/' ? '' : path}`
  },
}
```

## Компоненты {#components}

Vue, React, Preact и Solid поставляют одни и те же четыре компонента. Их пропсы совпадают; React, Preact и Solid передают остальные пропсы корневому элементу.

### `<I18nT>` {#&lt;i18nt&gt;}

| Проп | Тип | Примечания |
| --- | --- | --- |
| `keypath` | `string` | обязателен |
| `params` | `object` | значения для подстановки |
| `plural` | `number \| string` | рендерит `tc(keypath, count)` |
| `number` | `number \| string` | передаёт `tn(number)` как `{number}` |
| `date` | `Date \| string \| number` | передаёт `td(date)` как `{date}` |
| `relativeDate` | `Date \| string \| number` | передаёт `tdr(relativeDate)` как `{relativeDate}` |
| `tag` | `string` | элемент-обёртка, по умолчанию `span` |
| `html` | `boolean` | рендерить перевод как HTML; он должен быть доверенным, параметры экранируются |
| `defaultValue` | `string` | заменяет отсутствующий ключ и рендерится без обёртки, когда `hideIfEmpty` скрывает пустое значение |
| `hideIfEmpty` | `boolean` | ничего не рендерить для пустого перевода |
| `customPluralRule` | `PluralFunc` | правило множественного числа для этого элемента |

Применяется только один проп форматирования, проверяемый в таком порядке: `number`, `date`, `relativeDate`, `plural`.

#### Форматированный текст {#rich-text}

`{placeholder}` может содержать элемент. Во Vue это именованный слот; в React, Preact и Solid проп `components` задаёт по имени элементы или функции, возвращающие элемент. В любом случае он побеждает параметр с тем же именем, работает в каждой ветке и выдерживает локаль, в которой плейсхолдеры переставлены.

```tsx
// { "terms": "I accept the {link} of {company}" }
<I18nT keypath="terms" params={{ company: 'ACME' }} components={{ link: <a href="/terms">terms</a> }} />
```

В Solid передавайте функцию, если плейсхолдер повторяется: один узел может стоять только в одном месте. `children` заменяют текст, а в виде функции получают `{ translation }`, как слот по умолчанию во Vue. `html` игнорирует всё это.

### `<I18nLink>` {#&lt;i18nlink&gt;}

| Проп | Тип | Примечания |
| --- | --- | --- |
| `to` | `string \| { path }` | локализуется через `resolvePath` адаптера |
| `activeStyle` | объект стилей | накладывается поверх `style` на текущей странице; React, Preact и Solid применяют его также к разделу уровнем выше |
| `localeRoute` | функция | переопределяет `resolvePath` для этой ссылки |

Внешние URL (`https://`, `mailto:`, `tel:`) рендерятся как `<a target="_blank" rel="noopener noreferrer">`; ваши собственные `target` или `rel` побеждают. `onClick` выполняется всегда. Клик с модификатором, другой кнопкой мыши или при наличии `target` остаётся за браузером.

### `<I18nSwitcher>` {#&lt;i18nswitcher&gt;}

Выпадающий список включённых локалей (локали с `disabled: true` скрыты) со встроенными стилями по умолчанию. Его элементы — ссылки с `lang`, `hreflang` и `dir` из локали. По умолчанию клик по элементу устанавливает локаль и вызывает `push` адаптера с локализованным текущим путём; проп `switchLocale` заменяет это действие. При наличии `localeRoute` и без роутера браузер переходит по ссылке. Escape или клик снаружи закрывает список.

| Проп | Примечания |
| --- | --- |
| `locales`, `currentLocale`, `getLocaleName` | переопределяют предоставленные значения |
| `switchLocale(code)` | заменяет встроенное переключение |
| `localeRoute` | заменяет `resolvePath` |
| `customLabels` | `{ de: 'DE' }` |
| `customWrapperStyle`, `customButtonStyle`, `customDropdownStyle`, `customItemStyle`, `customLinkStyle`, `customActiveLinkStyle`, `customDisabledLinkStyle`, `customIconStyle` | переопределения стилей |

### `<I18nGroup>` {#&lt;i18ngroup&gt;}

`<div class="i18n-group">`, который передаёт дочерним элементам `t` с префиксом. Он **не** добавляет префикс к `<I18nT>` или вызовам `t()` внутри себя; префикс есть только у передаваемой вниз `t`.

| Проп | Примечания |
| --- | --- |
| `prefix` | обязателен, например `'profile'` |
| `groupClass` | дополнительный класс на обёртке |

`t` с префиксом приходит через scoped-слот во Vue (`v-slot="{ t }"`) и через дочерний render-prop в React, Preact и Solid (`{({ t }) => …}`).

## Типизированные ключи {#typed-keys}

`t()` принимает любую строку. Чтобы получить автодополнение ключей, сгенерируйте объявление с помощью [генератора типов](/ru/integrations/types-generator). Ключи подсказываются, но не проверяются принудительно, а параметры не типизируются.

## Сравнение с модулем Nuxt {#compared-with-the-nuxt-module}

У пакетов нет файловой маршрутизации, серверного middleware и загрузчика переводов: вы сами решаете, когда загружать JSON (`import`, `fetch` или `@i18n-micro/node` на сервере) и какой адаптер роутера использовать. Определение локали, SEO-meta и генерация маршрутов — возможности Nuxt; у Astro есть собственный middleware для определения локали и `useLocaleHead` для SEO.
