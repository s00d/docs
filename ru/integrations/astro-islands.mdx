---
title: "Острова Astro"
description: "Переводы внутри островов Vue, React, Preact и Svelte с @i18n-micro/astro."
---

Остров выполняется в браузере, где серверного экземпляра i18n нет. `@i18n-micro/astro` позволяет странице выбрать ключи, нужные острову, передать их одним prop и читать их в острове через небольшой адаптер для фреймворка. Вы получаете `t`, `tc`, `tn`, `td`, `tdr` и `has` в островах Vue, React, Preact и Svelte, а в HTML попадают только выбранные строки.

## Настройка {#setup}

Сначала настройте [интеграцию Astro и middleware](/ru/integrations/astro-package#setup), затем добавьте интеграцию нужного фреймворка (`@astrojs/vue`, `@astrojs/react`, `@astrojs/preact`, `@astrojs/svelte`). Адаптерам островов этот фреймворк нужен как peer-зависимость: `vue` `^3.3.0`, `react` `^16.8.0 || ^17.0.0 || ^18.0.0 || ^19.0.0`, `preact` `^10.0.0 || ^11.0.0` или `svelte` `^4.0.0 || ^5.0.0`.

## Передача переводов в остров {#pass-translations-to-an-island}

```astro
---
// src/pages/index.astro
import { getI18nProps } from '@i18n-micro/astro'
import Counter from '../components/Counter.vue'

const i18n = getI18nProps(Astro, ['counter.title', 'counter.apples'])
---

<Counter client:load i18n={i18n} />
```

`getI18nProps(Astro, keys?)` возвращает `{ locale, fallbackLocale, currentRoute, translations }` (тип `I18nClientProps`). Передайте ключи, которые использует остров: каждый из них разрешается на сервере так же, как в `t()` (словари маршрута, корневой и резервный), и в HTML попадают только найденные ключи. Без `keys` в каждый остров отправляется всё, на что `t()` может ответить на этой странице, так что 2000 корневых ключей — это около 100 КБ на остров; в режиме разработки при превышении 20 КБ выводится предупреждение.

Острова переводят только из этого объекта. `t` возвращает сам ключ для всего, что не было передано, а связанные сообщения не разрешаются.

## Vue {#vue}

Вызовите `provideI18n(() => props.i18n)` в корневом компоненте острова и `useAstroI18n()` в его дочерних компонентах. `inject` во Vue не видит значение, предоставленное тем же компонентом, поэтому хук должен выполняться в дочернем компоненте, а не в корневом:

```vue
<!-- src/components/Counter.vue -->
<script setup lang="ts">
import { provideI18n } from '@i18n-micro/astro/client/vue'
import type { I18nClientProps } from '@i18n-micro/astro'
import CounterBody from './CounterBody.vue'

const props = defineProps<{ i18n: I18nClientProps }>()
provideI18n(() => props.i18n)
</script>

<template><CounterBody /></template>
```

```vue
<!-- src/components/CounterBody.vue -->
<script setup lang="ts">
import { ref } from 'vue'
import { useAstroI18n } from '@i18n-micro/astro/client/vue'

const { t, tc } = useAstroI18n()
const count = ref(0)
</script>

<template>
  <h3>{{ t('counter.title') }}</h3>
  <button @click="count++">{{ tc('counter.apples', count) }}</button>
</template>
```

## React и Preact {#react-and-preact}

```tsx
// src/components/Counter.tsx
import { useState } from 'react'
import { I18nProvider, useAstroI18n } from '@i18n-micro/astro/client/react'
import type { I18nClientProps } from '@i18n-micro/astro'

function Body() {
  const { t, tc } = useAstroI18n()
  const [count, setCount] = useState(0)
  return <button onClick={() => setCount(count + 1)}>{t('counter.title')}: {tc('counter.apples', count)}</button>
}

export default function Counter({ i18n }: { i18n: I18nClientProps }) {
  return (
    <I18nProvider value={i18n}>
      <Body />
    </I18nProvider>
  )
}
```

Для Preact импортируйте `I18nProvider` и `useAstroI18n` из `@i18n-micro/astro/client/preact`; API тот же.

## Svelte {#svelte}

```svelte
<!-- src/components/Counter.svelte -->
<script lang="ts">
  import { createI18nStore, useAstroI18n } from '@i18n-micro/astro/client/svelte'
  import type { I18nClientProps } from '@i18n-micro/astro'

  export let i18n: I18nClientProps
  const { t, tc } = useAstroI18n(createI18nStore(i18n))
  let count = 0
</script>

<button on:click={() => count++}>{t('counter.title')}: {tc('counter.apples', count)}</button>
```

`useAstroI18n(store)` также возвращает `store` для чтения `$store` в шаблоне.

## Сохраняемые острова {#persisted-islands}

Остров с `transition:persist` получает новые props после навигации. React, Preact и Vue (если передан геттер) следуют за ними. В Svelte сохраните store и передавайте их в него: `const store = createI18nStore(i18n)`, `const { t } = useAstroI18n(store)`, затем `$: store.set(i18n)` (с рунами — `$effect(() => store.set(i18n))`).

## API {#api}

| Точка входа | Экспорты |
| --- | --- |
| `@i18n-micro/astro` | `getI18nProps`, тип `I18nClientProps` |
| `@i18n-micro/astro/client/vue` | `provideI18n(props \| () => props)`, `useAstroI18n()` |
| `@i18n-micro/astro/client/react` | `I18nProvider` (prop `value`), `useAstroI18n()` |
| `@i18n-micro/astro/client/preact` | `I18nProvider` (prop `value`), `useAstroI18n()` |
| `@i18n-micro/astro/client/svelte` | `createI18nStore(props)`, `useAstroI18n(store)` |
| `@i18n-micro/astro/client` | чистые `translate`, `hasTranslation`, без фреймворка |

Каждый `useAstroI18n` возвращает `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`, `setLocale`, `setRoute` и `locale`. У острова один объединённый словарь, поэтому его `has` возвращает true для ключа, на который может ответить `t`, в том числе из резервной локали; на сервере `has` проверяет только активную локаль.
