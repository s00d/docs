---
title: "Генератор типов"
description: "Генерируйте автодополнение TypeScript для ключей переводов из ваших JSON-файлов в Nuxt или любом проекте на Vite."
---

`@i18n-micro/types-generator` читает каждый JSON-файл в папке переводов и записывает объявление со списком всех ключей. Добавьте его, если хотите, чтобы редактор подсказывал ключи в `t()`, `$t()` и `<I18nT keypath>`. Он работает как модуль Nuxt и как плагин Vite или Rollup и перегенерирует типы при изменении файла.

## Установка {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/types-generator
```

```bash npm
npm install -D @i18n-micro/types-generator
```

```bash yarn
yarn add -D @i18n-micro/types-generator
```

</CodeGroup>

Peer-зависимость: `@nuxt/kit` `^3.18.0 || ^4.0.0`. Её импортирует только точка входа `/nuxt`; в проекте только на Vite предупреждение о peer-зависимости можно игнорировать.

## Nuxt {#nuxt}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro', '@i18n-micro/types-generator/nuxt'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Модуль записывает `.nuxt/types/i18n-micro.d.ts`, и Nuxt добавляет его в контекст типов; вручную ничего подключать не нужно. Он читает `i18nTypes.translationDir`, а иначе — то, откуда переводы читает `nuxt-i18n-micro`: `translationDir` (из `i18n` или встроенных параметров модуля, по умолчанию `'locales'`) в каждом слое, а также `additionalTranslationDirs`. Изменение JSON-файла в этой папке перегенерирует типы в `nuxi dev`. `i18nTypes.outputFile` в Nuxt игнорируется (об этом сообщает предупреждение).

## Vite {#vite}

`I18nTypesPlugin` — плагин Vite, который также принимает Rollup. Для другого сборщика вызывайте `generateTypes` в скрипте.

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { I18nTypesPlugin } from '@i18n-micro/types-generator'

export default defineConfig({
  plugins: [
    vue(),
    I18nTypesPlugin({
      srcDir: process.cwd(),
      translationDir: 'src/locales',
      outputFile: 'src/i18n-micro.d.ts',
    }),
  ],
})
```

| Параметр | Обязателен | Примечания |
| --- | --- | --- |
| `srcDir` | да | Базовый каталог; `translationDir` разрешается относительно него. |
| `translationDir` | да | Папка с JSON-файлами (включая подпапки, например `pages/`) или массив папок. |
| `outputFile` | нет | Куда записывать объявление; по умолчанию `<srcDir>/i18n-micro.d.ts`. |

Плагин генерирует типы один раз при старте сборки, а на dev-сервере перегенерирует их через 300 ms после изменения в папке. Убедитесь, что `include` в вашем `tsconfig.json` охватывает выходной файл.

## Использование ключей {#use-the-keys}

Сгенерированный файл расширяет `DefineLocaleMessage` в `@i18n-micro/types`, что превращает `TranslationKey` в ваши ключи:

```ts
declare module '@i18n-micro/types' {
  export interface DefineLocaleMessage {
    nav: object
    'nav.home': string
    'profile.title': string
  }
}
```

Ключи — это те, на которые отвечает `t()`, включая объекты, из каждой локали и каждого файла страницы, с типом их JSON-значения. `TranslationKey` — это объединение этих ключей и любой строки, поэтому вы получаете автодополнение, а не ошибки: ключ с опечаткой или динамический ключ всё равно компилируется. Параметры и возвращаемые значения не типизируются.

Для динамических ключей с известным префиксом `ScopedKey<'prefix'>` сужает тип до подходящих ключей:

```ts
import type { ScopedKey } from '@i18n-micro/types'

const statusText = (status: string) => t(`status.${status}` as ScopedKey<'status'>)
```

`TranslationKey` и `ScopedKey` берутся из `@i18n-micro/types` (React, Preact и Solid реэкспортируют `TranslationKey`; Vue — нет).

## API {#api}

| Экспорт | Точка входа | Примечания |
| --- | --- | --- |
| `I18nTypesPlugin(options)` | `@i18n-micro/types-generator` | Плагин Vite и Rollup |
| `generateTypes(options)` | `@i18n-micro/types-generator` | записывает файл, возвращает его путь |
| `getTypesString(options)` | `@i18n-micro/types-generator` | возвращает объявление без записи |
| `formatKeyProperty(key)` | `@i18n-micro/types-generator` | хелпер |
| Модуль Nuxt (`configKey: 'i18nTypes'`) | `@i18n-micro/types-generator/nuxt` | параметр `translationDir` |

Полные сигнатуры: [справочник пакета](/ru/api/packages/types-generator).
