# 📚 Примеры и использование Nuxt I18n Micro

В этом разделе представлены различные примеры, демонстрирующие использование `Nuxt I18n Micro` в вашем приложении Nuxt.js. Вы увидите, как переключать локали, использовать компоненты `<i18n-link>`, `<i18n-switcher>` и `<i18n-t>`, а также динамически работать с ключами переводов.

## 🛠️ Базовая настройка

Базовая настройка для начала работы с `Nuxt I18n Micro`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Переключение локалей

### Программное переключение локалей

В этом примере показано, как программно переключать локали с помощью кнопок:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Пример JSON для переключения локалей

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### Использование компонента `<i18n-switcher>`

Компонент `<i18n-switcher>` предоставляет выпадающий список для переключения локалей с настраиваемыми подписями:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 📝 Отображение динамических ключей из файлов переводов

В некоторых сценариях может потребоваться перебирать динамические ключи, хранящиеся в файлах переводов, и условно отображать их значения. Пример ниже демонстрирует, как это сделать с помощью `Nuxt I18n Micro`.

### Пример: отображение динамических ключей

Этот пример получает массив ключей из определённого пути перевода (в данном случае `dynamic`) и перебирает их. Каждый ключ проверяется на существование с помощью `$has` перед отображением его значения с помощью `$t`.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Пример файла перевода (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Пример: отображение динамических ключей из объекта

В этом примере мы работаем с объектом, хранящимся в вашем файле переводов. Мы получаем и перебираем ключи объекта, динамически отображая как имена ключей, так и связанные с ними значения.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Пример файла перевода (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 Использование `<i18n-t>` для переводов со слотами и интерполяцией

Компонент `<i18n-t>` полезен для отображения переводов с динамическим содержимым и HTML-тегами:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### Пример JSON для `<i18n-t>`

```json
{
  "greeting": "Welcome to the page"
}
```

### С интерполяцией

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### Пример JSON для интерполяции

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 Использование `$tc` для плюрализации

Функция `$tc` в `Nuxt I18n Micro` обрабатывает плюрализацию на основе количества и настроек локали. Это полезно для динамической корректировки сообщений, связанных с количеством, например, элементов, уведомлений или других сущностей, число которых может меняться.

### Пример: использование `$tc` для плюрализации

В следующем примере мы отображаем сообщение с указанием количества яблок с помощью `$tc`. Ключ перевода обрабатывает несколько форм множественного числа в зависимости от переданного значения.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### Пример JSON для плюрализации

Вот как можно определить перевод в вашем JSON-файле для обработки различных форм множественного числа:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Пояснение

- **`$tc('apples', 0)`**: Возвращает первую форму, используется, когда количество равно нулю (`"no apples"`).
- **`$tc('apples', 1)`**: Возвращает вторую форму, используется, когда количество равно одному (`"one apple"`).
- **`$tc('apples', 10)`**: Возвращает третью форму со значением количества, используется, когда количество равно двум или более (`"10 apples"`).

### Дополнительный пример с более сложной плюрализацией

Если вашему приложению нужны более сложные правила плюрализации (например, отдельные случаи для zero, one, two, few, many, other), вы можете расширить строки перевода соответствующим образом:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: Может быть настроен для возврата `"two apples"`.
- **`$tc('apples', 3)`**: Может вернуть `"a few apples"`, в зависимости от правил, определённых для количества.

## 🌐 Использование `$tn` для форматирования чисел

Функция `$tn` форматирует числа в соответствии с текущей локалью, используя API `Intl.NumberFormat`. Это полезно для отображения чисел в формате, соответствующем региональным настройкам пользователя, например, валюты, процентов или других числовых форматов.

### Пример: использование `$tn` для форматирования чисел

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ Использование `$td` для форматирования даты и времени

Функция `$td` форматирует даты и время в соответствии с текущей локалью, используя API `Intl.DateTimeFormat`. Это полезно для отображения дат и времени в форматах, привычных пользователю согласно его настройкам локали.

### Пример: использование `$td` для форматирования даты и времени

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ Использование `$tdr` для форматирования относительных дат

Функция `$tdr` форматирует даты как относительные значения времени (например, "5 minutes ago", "2 days ago") в соответствии с текущей локалью, используя API `Intl.RelativeTimeFormat`. Это полезно для отображения разницы во времени относительно текущей даты и времени.

### Пример: использование `$tdr` для форматирования относительных дат

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
