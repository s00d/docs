`useI18nHead()` изменяет SEO-теги, которые генерирует модуль, только для одной страницы. Используйте его, когда страница знает больше, чем роутер: статья из CMS, существующая лишь в некоторых локалях, canonical URL из API, дополнительные теги `og:`. Вы получаете сгенерированные теги с наложенными поверх вашими переопределениями.

## Сигнатура {#signature}

```ts
useI18nHead(input?: MaybeRefOrGetter<I18nHeadInput | null>): { pageHead: any; resetPageHead: () => void }
```

Регистрирует переопределения i18n SEO-тегов head на уровне страницы.
Плагин `02.meta` накладывает их поверх результата `useLocaleHead`.

Предпочитайте геттер (`() => ({ … })`), когда значения берутся из `$t` / `t`, чтобы они
пересчитывались при смене локали. Простой объект вычисляется один раз и остаётся неизменным.

| Параметр | Тип | Описание |
| --- | --- | --- |
| `input` *(необязательный)* | `MaybeRefOrGetter<I18nHeadInput \| null>` |  |

Он работает с [`meta: true`](/ru/api/module-options#meta) (по умолчанию): meta-плагин модуля накладывает входные данные поверх результата [`useLocaleHead`](/ru/composables/useLocaleHead) при каждом рендеринге head. При `meta: false` их никто не читает.

Переопределение сбрасывается при смене имени маршрута. Страница, задающая `disableMeta`, вообще не получает i18n-тегов, включая переопределения.

## Входные данные {#input}

`I18nHeadInput` (из `@i18n-micro/types`):

| Ключ | Тип | Эффект |
| --- | --- | --- |
| `htmlAttrs` | `Record<string, string>` | Объединяется с атрибутами `<html>` (`lang`, `dir`). |
| `meta` | `I18nHeadMeta[]` | Добавляется после сгенерированных тегов; заменяет тег с тем же `id`, `property` или `name`. |
| `link` | `I18nHeadLink[]` | Добавляется после сгенерированных ссылок; заменяет ссылку с тем же `id` или `rel` + `hreflang`. |
| `replace.canonical` | `string \| false` | Заменить `href` canonical или удалить ссылку. |
| `replace.hreflang` | `I18nHeadLink[] \| false` | Заменить или удалить **все** ссылки `rel="alternate"`, включая `x-default`. |
| `replace.xDefault` | `I18nHeadLink \| false` | Заменить или удалить ссылку `x-default`. |
| `replace.ogLocale` | `string \| false` | Заменить или удалить `og:locale`. |
| `replace.ogUrl` | `string \| false` | Заменить или удалить `og:url`. |
| `replace.ogAlternates` | `string[] \| false` | Перестроить `og:locale:alternate` из этих кодов локалей (через `og` / `iso`), пропуская текущую локаль, неизвестные коды и коды без значения `og` или `iso`, либо удалить их. |
| `disable` | `I18nHeadDisableGroup[]` | Отбросить сгенерированные группы: `'hreflang'` (не `x-default`), `'x-default'`, `'canonical'`, `'og'` (`og:locale` + `og:url`), `'og-alternates'`, `'html'`. |

Порядок применения: `disable`, затем `replace`, затем `htmlAttrs`, `meta`, `link`.

## Пример {#example}

Статья, существующая только в некоторых локалях, с альтернативными URL из API:

```vue
<script setup lang="ts">
const route = useRoute()
const { t } = useI18n()
const { data: article } = await useFetch<{ title: string; urls: Record<string, string> }>(`/api/articles/${route.params.slug}`)

useI18nHead(() => {
  if (!article.value) return null
  const codes = Object.keys(article.value.urls)
  return {
    meta: [{ property: 'og:title', content: article.value.title || t('blog.title') }],
    replace: {
      hreflang: codes.map((code) => ({ rel: 'alternate', hreflang: code, href: article.value!.urls[code]! })),
      ogAlternates: codes,
    },
  }
})
</script>
```

Передавайте геттер, как здесь, когда значения берутся из `t()` или асинхронных данных: он перезапускается при смене локали. Простой объект читается один раз.
