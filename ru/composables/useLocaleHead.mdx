---
title: "useLocaleHead"
description: "useLocaleHead строит i18n SEO-теги (lang, dir, canonical, hreflang, og:locale) в виде объекта, который вы передаёте в useHead."
---

`useLocaleHead()` строит i18n-теги head для текущего маршрута: `lang` и `dir` на `<html>`, ссылку canonical, альтернативы `hreflang` с `x-default`, `og:url`, `og:locale` и `og:locale:alternate`. Используйте его, когда вы задали [`meta: false`](/ru/api/module-options#meta) и управляете `useHead` сами; при `meta: true` модуль уже регистрирует эти теги, а изменения для отдельных страниц делаются через [`useI18nHead`](/ru/composables/useI18nHead).

## Сигнатура {#signature}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { build: () => LocaleHead; metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }, LocaleHead | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

SEO-теги head для текущего маршрута: альтернативы `hreflang` для каждой локали плюс
`x-default`, ссылка canonical, `og:locale`, а также `lang`/`dir` на `<html>`.

Нужен только тогда, когда `meta` отключён или значения по умолчанию требуют корректировки — при `meta: true`
модуль сам регистрирует те же теги.

| Параметр | Тип | Описание |
| --- | --- | --- |
| `options` | `UseLocaleHeadOptions` |  |

**Возвращает** — `metaObject`, ref с объектом head, готовым к передаче в `useHead`; `updateMeta` обновляет его; `build` вычисляет объект head по текущему маршруту (реактивно при чтении в геттере, например `useHead(() => build())`)

```ts
const { metaObject } = useLocaleHead({ addSeoAttributes: true })
useHead(metaObject)
```

## Опции {#options}

| Опция | По умолчанию | Описание |
| --- | --- | --- |
| `addDirAttribute` | `true` | Устанавливать `dir` на `<html>` из `dir` локали (`'auto'`, если он не задан). |
| `identifierAttribute` | `'id'` | Атрибут-ключ каждого тега (`i18n-can`, `i18n-og`, `i18n-alternate-<hreflang>`, …), чтобы обновления заменяли теги, а не добавляли новые. |
| `addSeoAttributes` | `true` | Выводить теги canonical, `hreflang` и `og:`. `false` оставляет только `htmlAttrs`. |
| `baseUrl` | `'/'` | Origin, добавляемый к каждому URL. Оставьте `'/'` для относительных URL; передайте `'https://example.com'` для абсолютных. |
| `autoUpdate` | `true` | Перестраивать `metaObject` при изменении маршрута или состояния `i18n-locale`. |

## Что выводится {#what-it-emits}

- Ничего на маршруте без совпадения (404) или с `disableMeta` для активной локали.
- Canonical и `og:url`: `$switchLocalePath(<active locale>)`, query сокращается до [`canonicalQueryWhitelist`](/ru/api/module-options#canonicalquerywhitelist), применяется [`trailingSlash`](/ru/api/module-options#trailingslash).
- `hreflang`: по одной ссылке на каждую включённую локаль, в которой существует страница, `hreflang = iso || code`, локали с `seo: false` пропускаются; при `hreflangBaseLanguage: true` первая региональная локаль языка также выводит тег базового языка. При `no_prefix` ничего не выводится.
- `x-default`: URL локали по умолчанию, кроме случаев, когда стратегия — `no_prefix`, у локали по умолчанию задано `seo: false` или страница в ней не существует.
- `og:locale` / `og:locale:alternate`: из `og` локали или из её `iso` после преобразования (`en-US` → `en_US`); пропускается с предупреждением в режиме разработки, если не подходит ни то, ни другое.

## Пример {#example}

```ts
// app.vue, with i18n.meta: false
const { metaObject } = useLocaleHead({ baseUrl: 'https://example.com' })
useHead(metaObject)
```

`build()` возвращает тот же объект без ref: `useHead(() => build())` остаётся реактивным без наблюдателя.
