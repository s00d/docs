title: "useI18n"
description: "useI18n возвращает хелперы времени выполнения (`$t`, `$tc`, `$localePath`, …) в виде простого объекта, с префиксом `$` и без него."
---

`useI18n()` возвращает хелперы времени выполнения модуля в виде простого объекта. Используйте его в `<script setup>`, composables и плагинах вместо обращения к `useNuxtApp()`. Каждый хелпер доступен под именем с `$` и под псевдонимом без него: `t` и `$t` — одна и та же функция.

## Сигнатура {#signature}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Все хелперы времени выполнения в виде простого объекта.

Те же функции, которые плагин внедряет как `$t`, `$tc` и т. д., доступны как под именем
с префиксом доллара, так и под псевдонимом без него — поэтому работают и `const { t } = useI18n()`,
и `const { $t } = useI18n()`.

**Возвращает** — хелперы, описанные в [справочнике методов](/ru/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

Возвращаемый объект содержит все хелперы [`PluginsInjections`](/ru/api/methods). Каждый из них описан на странице [Хелперы](/ru/api/methods).

## Пример {#example}

```vue
<script setup lang="ts">
const { t, tc, localePath, switchLocale, getLocale } = useI18n()

const title = computed(() => t('page.title'))
</script>

<template>
  <h1>{{ title }}</h1>
  <p>{{ tc('items', 3) }}</p>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
  <button @click="switchLocale(getLocale() === 'en' ? 'de' : 'en')">{{ t('nav.switch') }}</button>
</template>
```

## Не входит в тип {#not-in-the-type}

`$defineI18nRoute` типизирован только в `useNuxtApp()`:

```ts
const { $defineI18nRoute } = useNuxtApp()
```
