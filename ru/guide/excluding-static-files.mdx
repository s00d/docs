---
title: "Исключение путей"
description: "Как исключить страницы и файлы из маршрутизации по локалям с помощью excludePatterns и какие пути исключены уже по умолчанию."
---

Некоторые пути никогда не должны получать префикс локали или перенаправление на локаль: админка, health check, генерируемая лента. `excludePatterns` помечает такие пути, а встроенный список уже охватывает внутренние пути Nuxt и распространённые статические файлы. Исключённая страница сохраняет ровно тот путь, который вы указали, и по-прежнему рендерится с `$t`.

## Исключение пути {#exclude-a-path}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    excludePatterns: [
      '/admin', // /admin and everything below it
      '/preview-*', // glob over the whole path
    ],
  },
})
```

С этой конфигурацией `pages/admin/index.vue` отвечает только по адресу `/admin`; пути `/de/admin` нет, и `/admin` никогда не перенаправляется на `/de/admin`.

## Синтаксис шаблонов {#pattern-syntax}

Шаблоны сопоставляются с путём без `app.baseURL`:

| Шаблон | Совпадает | Не совпадает |
| --- | --- | --- |
| `'/admin'` | `/admin`, `/admin/users` | `/administrator`, `/de/admin` |
| `'/preview-*'` | `/preview-1`, `/preview-a/b` | `/de/preview-1` |
| `'/file-?'` | `/file-a` | `/file-ab` |
| `/^\/v\d+\//` | `/v2/docs` | `/docs` |

Строка без `*` или `?` совпадает с самим путём и целыми сегментами под ним. С `*` (любая последовательность символов, включая слеши) или `?` (один символ) она должна совпадать со всем путём. Всегда начинайте строки с `/`.

## Что уже исключено {#what-is-excluded-already}

Эти пути никогда не получают маршрутов локалей или перенаправлений, без какой-либо настройки:

- `/api` и `/_nuxt`, а также всё, что под ними;
- маршрут переводов, по умолчанию `/_locales` ([`apiBaseUrl`](/ru/api/module-options#apibaseurl));
- любой путь с сегментом, начинающимся с `__` (`/__nuxt_content`, `/en/__og-image__`);
- `/sitemap*.xml`, `/robots.txt`, `/favicon.ico`, `/apple-touch-icon*.png`, `/manifest.json`, `/sw.js`, `/workbox-*.js`;
- любой путь, последний сегмент которого оканчивается расширением статического файла: `xml txt ico json js css png jpg jpeg gif svg webp avif pdf wasm map mp4 webm mp3 zip gz woff woff2 ttf eot`. Слаги страниц с точками, например `/user/john.doe`, и пути `.html` остаются страницами.

## Что делает исключение {#what-an-exclusion-does}

- **Маршруты:** локализованные варианты не генерируются; страница остаётся такой, как написана.
- **Перенаправления и 404:** серверный плагин перенаправлений и клиентский middleware перенаправлений пропускают этот путь.
- **Пререндеринг:** совпадающие пути удаляются из списка маршрутов для пререндеринга.

Исключение не мешает серверному middleware i18n определять локаль для запроса и не мешает странице использовать переводы. Чтобы оставить страницу локализованной, но без SEO-тегов, используйте `disableMeta` ([Конфигурация страницы](/ru/guide/per-component-translations#turn-off-seo-tags)). Чтобы оставить одну страницу нелокализованной по пути из `nuxt.config.ts`, `globalLocaleRoutes: { '/admin': false }` ([Локализованные пути](/ru/guide/custom-locale-routes#in-nuxt-config)) делает то же самое для маршрутизации.
