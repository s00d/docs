[Crowdin](https://crowdin.com/) — это платформа для переводов: вы загружаете файлы локали по умолчанию, переводчики работают в Crowdin, а вы скачиваете остальные локали обратно. Модуль читает обычные JSON-файлы, поэтому Crowdin CLI нужен лишь `crowdin.yml`, который правильно сопоставляет `locales/` и `locales/pages/`. Настройки модуля менять не нужно.

## Настройка crowdin.yml {#configure-crowdin-yml}

```yml
# crowdin.yml
project_id_env: CROWDIN_PROJECT_ID
api_token_env: CROWDIN_PERSONAL_TOKEN
base_path: ./locales
preserve_hierarchy: true

files:
  - source: /en.json
    translation: /%two_letters_code%.json
  - source: /pages/**/en.json
    translation: /pages/**/%two_letters_code%.json
```

- `en` — ваша локаль по умолчанию; её файлы являются исходными.
- `project_id_env` / `api_token_env` читают ID и токен из переменных окружения, поэтому секреты не попадают в коммиты.
- `preserve_hierarchy: true` сохраняет папки `pages/<page>/` как есть.
- Имя переведённого файла должно совпадать с `code` локали в `nuxt.config.ts`. `%two_letters_code%` подходит для кодов вроде `de`; для кодов вроде `pt-BR` используйте `%locale%` или сопоставьте коды Crowdin со своими через `languages_mapping`.

## Загрузка и скачивание {#upload-and-download}

```bash
npm install -g @crowdin/cli

export CROWDIN_PROJECT_ID=123456
export CROWDIN_PERSONAL_TOKEN=...   # from Crowdin account settings

crowdin upload sources   # push locales/en.json and locales/pages/**/en.json
crowdin download         # write locales/de.json, locales/pages/**/de.json, ...
```

Запускайте обе команды в CI, чтобы файлы оставались актуальными. Скачанные файлы попадают в репозиторий так же, как отредактированные вручную; следующая сборка или перезагрузка в режиме разработки подхватит их.

## Перед загрузкой {#before-uploading}

Сначала очистите исходные файлы, чтобы переводчики не работали над неиспользуемыми ключами: [`i18n-micro clean`](/ru/api/cli#clean) удаляет неиспользуемые ключи, [`i18n-micro check`](/ru/api/cli#check) сообщает о пробелах после скачивания. У CLI нет собственной интеграции с Crowdin: эта страница описывает поддерживаемый способ.
