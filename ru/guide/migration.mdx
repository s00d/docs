На этой странице показано, как перенести приложение с `@nuxtjs/i18n` на nuxt-i18n-micro: опции, вспомогательные функции и структура файлов. Используйте её, когда заменяете модуль в существующем приложении. Ваши URL сохраняются (названия стратегий те же), а переводы переносятся в JSON-файлы для каждой страницы.

<Tip>

**Обновляете сам nuxt-i18n-micro?** — См. [Обновление](/ru/guide/upgrade).

</Tip>

## Замена модуля {#swap-the-module}

```bash
npm uninstall @nuxtjs/i18n
npm install nuxt-i18n-micro
```

```ts
// nuxt.config.ts — before
export default defineNuxtConfig({
  modules: ['@nuxtjs/i18n'],
  i18n: {
    locales: [
      { code: 'en', language: 'en-US', file: 'en.json' },
      { code: 'de', language: 'de-DE', file: 'de.json' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    langDir: 'locales',
    detectBrowserLanguage: { useCookie: true, cookieKey: 'i18n_redirected', redirectOn: 'root' },
  },
})
```

```ts
// nuxt.config.ts — after
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    translationDir: 'locales',
    localeCookie: 'i18n_redirected',
    autoDetectPath: '/',
  },
})
```

## Опции {#options}

| `@nuxtjs/i18n` | nuxt-i18n-micro |
| --- | --- |
| `locales[].code` | `locales[].code` |
| `locales[].language` (`iso` до v9) | `locales[].iso` |
| `locales[].name` | `locales[].displayName` |
| `locales[].dir` | `locales[].dir` |
| `locales[].domain` | `locales[].baseUrl` (origin со схемой) |
| `locales[].domainDefault` | `locales[].baseDefault` |
| `differentDomains`, `multiDomainLocales` | не нужны: одного `baseUrl` достаточно для маршрутизации по хосту, см. [Слои и домены](/ru/guide/layers#multiple-domains) |
| `locales[].file` / `files`, `langDir`, `lazy` | `translationDir`; файлы находятся по имени и всегда загружаются постранично |
| `defaultLocale`, `strategy` | те же названия, те же четыре значения |
| `baseUrl` | `metaBaseUrl` |
| `customRoutes: 'config'` + `pages` | `globalLocaleRoutes` |
| `detectBrowserLanguage: false` | `redirects: false` (без редиректов) или `autoDetectLanguage: false` (игнорировать заголовок) |
| `detectBrowserLanguage.useCookie` / `cookieKey` | `localeCookie: '<name>'` (`null` отключает cookie) |
| `detectBrowserLanguage.redirectOn: 'root'` | `autoDetectPath: '/'` (по умолчанию) |
| `detectBrowserLanguage.redirectOn: 'no prefix'` | `autoDetectPath: 'no_prefix'` |
| `detectBrowserLanguage.redirectOn: 'all'` | `autoDetectPath: '*'` |
| Файл конфигурации `vueI18n` (`fallbackLocale`, `numberFormats`, `datetimeFormats`) | `fallbackLocale`, `numberFormats`, `datetimeFormats` в `i18n` |

`alwaysRedirect` нет: если cookie установлен, `/` следует ему при каждом посещении. Полный список — в [Опциях модуля](/ru/api/module-options); правила определения — на странице [Определение локали](/ru/guide/locale-detection).

## Вспомогательные функции и composables {#helpers-and-composables}

| `@nuxtjs/i18n` / vue-i18n | nuxt-i18n-micro (шаблон / `useI18n()`) |
| --- | --- |
| `const { t } = useI18n()` | `const { t } = useI18n()`, `$t` в шаблонах |
| `t('key', count)`, `tc` | `$tc('key', count)` |
| `te('key')` | `$has('key')` |
| `n(value, 'currency')`, `d(date, 'short')` | `$tn(value, 'currency')`, `$td(date, 'short')` |
| — | `$tdr(date)`: относительное время («через 3 дня») |
| `locale.value` | `$getLocale()` |
| `locales.value` | `$getLocales()` |
| `setLocale('de')` | `$switchLocale('de')` |
| `useLocalePath()('about')` | `$localePath({ name: 'about' })` |
| `useLocaleRoute()` | `$localeRoute()` |
| `useSwitchLocalePath()('de')` | `$switchLocalePath('de')` |
| `useSetI18nParams()` | `$setI18nRouteParams()` |
| `useLocaleHead()` | автоматически при `meta: true`; [`useLocaleHead`](/ru/composables/useLocaleHead) для собственных head |
| `defineI18nRoute({ paths: { de: '/ueber-uns' }, locales: [...] })` | `$defineI18nRoute({ localeRoutes: { de: '/ueber-uns' }, locales: [...] })` |
| `<NuxtLinkLocale to="about">` | `<i18n-link :to="{ name: 'about' }">` |
| `<i18n-t>` | `<i18n-t>` (слоты заполняют плейсхолдеры `{name}`) |
| `$i18n` в серверных маршрутах | `useTranslationServerMiddleware(event)`, см. [Серверные маршруты и API](/ru/guide/server-side-translations) |

`useI18n()` импортируется автоматически. `$defineI18nRoute` должен сохранять свой `$`: сборка читает именно этот вызов. Все вспомогательные функции: [Методы](/ru/api/methods).

## Файлы переводов {#translation-files}

Перенесите ключи из одного большого файла на локаль в корневой файл плюс по одному файлу на страницу:

```text
locales/
├── en.json              # keys used on many pages (nav, footer)
├── de.json
└── pages/
    ├── index/en.json    # keys of pages/index.vue
    └── about/en.json    # keys of pages/about.vue
```

Хранить всё в корневых файлах тоже можно, и это самый быстрый первый шаг. Задайте `disablePageLocales: true`, пока не разделите их. См. [Файлы переводов](/ru/guide/translations).

### Синтаксис сообщений {#message-syntax}

| vue-i18n | nuxt-i18n-micro |
| --- | --- |
| Именованная интерполяция `{name}` | то же самое |
| `car \| cars` (2 формы: 1 → первая) | формы выбираются по количеству начиная с 0: пишите `no cars \| one car \| {count} cars` |
| Связанные сообщения `@:other.key` | не поддерживаются: повторите текст или собирайте в коде |
| Модификаторы `@.upper:` | не поддерживаются: форматируйте в коде или используйте `<i18n-t>` |
| Экранирование литералов `{'@'}` | не нужно: заменяются только токены `{word}` |
| Файлы сообщений на JS/TS | только JSON |

Правило множественного числа можно заменить опцией [`plural`](/ru/api/module-options#plural).

## Проверка после перехода {#check-after-the-switch}

- Все прежние URL по-прежнему разрешаются; названия стратегий совпадают, пользовательские пути переносятся в `globalLocaleRoutes` или `$defineI18nRoute`.
- `hreflang`, canonical и `og:locale` выводятся из коробки при `meta: true`; удалите написанные вручную.
- Ошибка разбора JSON выводит в лог путь к файлу; отсутствующий ключ в режиме разработки выводит предупреждение в консоль браузера.
