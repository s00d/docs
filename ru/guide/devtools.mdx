В `nuxt dev` модуль добавляет два средства отладки: вкладку **i18n Micro** в Nuxt DevTools для просмотра и редактирования файлов переводов и инспектор Vue DevTools для текущей локали и загруженных словарей. Оба существуют только в режиме разработки и ничего не добавляют в продакшен-сборки. Для вкладки Nuxt достаточно включённых Nuxt DevTools; для инспектора Vue также нужно браузерное расширение Vue DevTools.

## Вкладка Nuxt DevTools {#nuxt-devtools-tab}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  devtools: { enabled: true }, // the tab is registered only when DevTools are on
})
```

Откройте Nuxt DevTools (`Shift + Alt + D`) и выберите **i18n Micro**. Вкладка показывает:

- все JSON-файлы в `locales/` (корневые и в `pages/`) каждого слоя, а также корневые файлы из `additionalTranslationDirs`;
- редактор для каждого файла; **Save** записывает файл обратно на диск, и dev-сервер перезагружает переводы;
- **Export** / **Import** файла в формате JSON и **Stats** с количеством ключей и покрытием переводов;
- просмотр итоговой конфигурации опций модуля;
- **Translate**, который заполняет недостающие ключи с помощью движка машинного перевода, настраиваемого в параметрах вкладки.

Сохранение записывает только существующие файлы `.json` внутри ваших директорий переводов. Если файл существует в нескольких слоях, записывается копия проекта.

## Инспектор Vue DevTools {#vue-devtools-inspector}

При наличии браузерного расширения Vue DevTools модуль регистрирует инспектор i18n (текущая локаль, чанк маршрута, загруженные ключи) и таймлайн с переключениями локали, загрузками чанков и недостающими ключами.

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    debug: true, // also log every $t / $ts / $tc call on the timeline
    // vueDevtools: false, // turn the inspector off, keep the Nuxt tab
  },
})
```

[`vueDevtools`](/ru/api/module-options) по умолчанию равен `true`. `debug: true` выводит много информации; используйте его только в коротких сессиях.
