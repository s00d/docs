Эта страница проводит приложение Nuxt от отсутствия i18n до переведённой страницы с переключателем языка. Она нужна один раз, в начале проекта. В результате у вас будут локализованные URL (`/about`, `/de/about`), по одному JSON-файлу на локаль и страницу и `$t` в шаблонах.

## Установка {#install}

Модулю нужен Nuxt 3.18 или новее (Nuxt 4 тоже подходит) и Node 20 или новее.

<CodeGroup>

```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>

## Настройте локали {#configure-the-locales}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', displayName: 'English' },
      { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
      { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
    ],
    defaultLocale: 'en',
  },
})
```

Это вся конфигурация, которая нужна первому приложению. Значения по умолчанию дают вам:

- `strategy: 'prefix_except_default'`: у локали по умолчанию нет префикса (`/about`), у остальных есть (`/de/about`). См. [Стратегии маршрутизации](/ru/guide/strategy).
- `translationDir: 'locales'`: файлы переводов лежат в `locales/` в корне проекта, в том числе при структуре Nuxt 4 с `app/`.
- `meta: true`: теги `hreflang`, canonical и `og:locale`, а также `lang` и `dir` на `<html>`. См. [SEO](/ru/guide/seo).
- Посетитель, открывший `/`, перенаправляется на язык, который запрашивает его браузер (`Accept-Language`). См. [Определение локали](/ru/guide/locale-detection).

`iso` — языковой тег, используемый в SEO-тегах; `code` — то, что появляется в URL. Все параметры перечислены в разделе [Параметры модуля](/ru/api/module-options).

## Добавьте файлы переводов {#add-translation-files}

Запустите dev-сервер командой `nuxt dev`. Когда Nuxt разрешает страницы, модуль создаёт пустой файл `{}` для каждой локали и страницы, у которых его нет (это можно отключить с помощью [`disableWatcher`](/ru/api/module-options#disablewatcher)):

```text
locales/
├── en.json            # root: keys every page can use
├── de.json
├── fr.json
└── pages/
    ├── index/         # pages/index.vue
    │   ├── en.json
    │   ├── de.json
    │   └── fr.json
    └── about/         # pages/about.vue
        ├── en.json
        ├── de.json
        └── fr.json
```

Заполните корневой файл и файл страницы:

```json
// locales/en.json
{ "nav": { "home": "Home", "about": "About" } }
```

```json
// locales/pages/index/en.json
{ "welcome": "Welcome, {name}!", "items": "no items | one item | {count} items" }
```

Страница видит корневые ключи и свои собственные; при конфликте побеждает её собственный файл. Имена папок следуют имени маршрута (`pages/articles/[id].vue` — это `locales/pages/articles-id/`). Структура, резервные значения и загрузка описаны в разделе [Файлы переводов](/ru/guide/translations).

## Используйте `$t` на странице {#use-t-on-a-page}

```vue
<!-- pages/index.vue -->
<script setup lang="ts">
const { t, tc, getLocale } = useI18n()

const title = t('nav.home') // 'Home'
</script>

<template>
  <h1>{{ $t('welcome', { name: 'Ada' }) }}</h1>
  <!-- Welcome, Ada! -->
  <p>{{ $tc('items', 3) }}</p>
  <!-- 3 items -->
  <p>{{ getLocale() }}</p>
  <!-- en -->
</template>
```

- В шаблонах каждый хелпер доступен с `$` (`$t`, `$tc`, `$localePath`, …).
- В `<script setup>` `useI18n()` возвращает те же хелперы, с `$` и без него (`t` и `$t` — одна функция). Он импортируется автоматически.
- Плейсхолдеры `{name}` заполняются из объекта параметров. Формы множественного числа разделяются символом `|`; число выбирает форму (0, 1, затем последняя для всех больших значений).

Все хелперы перечислены в разделе [Методы](/ru/api/methods).

## Ссылки между страницами и переключение локали {#link-between-pages-and-switch-locale}

```vue
<!-- components/AppHeader.vue -->
<template>
  <nav>
    <i18n-link :to="{ name: 'index' }">{{ $t('nav.home') }}</i18n-link>
    <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
    <i18n-switcher />
  </nav>
</template>
```

- [`<i18n-link>`](/ru/components/i18n-link) — это `NuxtLink`, указывающий на страницу в текущей локали: на `/de` ссылка about ведёт на `/de/about`.
- [`<i18n-switcher>`](/ru/components/i18n-switcher) — выпадающий список включённых локалей; он оставляет посетителя на той же странице.
- Для собственных кнопок вызывайте `$switchLocale('de')`: он переходит на текущую страницу на немецком и запоминает выбор. Для обычного `NuxtLink` используйте `$localePath({ name: 'about' })` или `$switchLocalePath('de')`.

## Проверьте результат {#check-it}

Запустите `nuxt dev` и откройте:

| URL | Что показывает |
| --- | --- |
| `/` | Главная на английском (или редирект на `/de`, если браузер предпочитает немецкий) |
| `/de` | Главная на немецком |
| `/de/about` | Страница about на немецком |
| `/en/about` | 404: в `prefix_except_default` у локали по умолчанию нет префикса |

Изменения JSON-файлов применяются на открытой странице без перезагрузки.
