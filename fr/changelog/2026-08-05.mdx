Versions : **v3.22.0 → v3.26.0**.

## Nouvelles fonctionnalités

- **API Translation Memory.** Lisez et modifiez le dictionnaire de la locale active à l'exécution avec `$resolveTranslations()` et `$setTranslation(key, value)`. Utile pour les DevTools, les tests et les éditeurs intégrés à l'app. Voir [Méthodes](/api/methods#resolvetranslations).
- **`numberFormats` et `datetimeFormats` nommés.** Configurez des formats nommés compatibles Vue I18n par locale, puis appelez `$tn(1000, 'currency')` ou `$td(date, 'short')`. Voir [Options du module](/api/module-options).
- **Contrôle du cache HTTP sur les payloads `/_locales`.** Le nouveau [`httpCacheDuration`](/api/module-options) définit `Cache-Control: public, max-age=…, immutable` sur les payloads de traduction. Par défaut d'un an, associé en toute sécurité au cache-busting `?v={dateBuild}`.
- **Payloads de traduction compressés.** Quand `nitro.compressPublicAssets` est activé, les payloads publics de traduction sont compressés automatiquement. Voir le [guide Performance](/guides/performance).
- **Utilitaire `splitLocaleRoutes`.** Construisez à la fois `pages` et `globalLocaleRoutes` depuis une seule liste programmatique (pour les scénarios `pages:extend`), indexée par nom de route. Voir [Routes de locale personnalisées](/guides/custom-locale-routes#programmatic-routes-pagesextend--244).
- **Repli sur `site.url` pour la base SEO.** Quand `metaBaseUrl` n'est pas défini, les balises SEO se replient sur `site.url` de `nuxt-site-config` s'il est présent, sinon sur l'origine de la requête. Voir [`metaBaseUrl`](/api/module-options).

## Mises à jour

- **Adaptateur Astro.** Isolation du contexte de routage, plus le câblage pour `numberFormats` et `datetimeFormats`.
- **React et Preact.** `I18nSwitcher` définit désormais correctement les attributs `aria-haspopup` et `aria-expanded`.
- **Benchmarks.** Les benchmarks de performance ont migré vers une CLI basée sur citty.
- **Empreinte de contenu `dateBuild`.** La valeur par défaut de `dateBuild` est désormais une empreinte de contenu, si bien que le `?v=` du payload ne change que lorsque les traductions changent réellement.

## Corrections

- **Routage.**
  - Les matchers de routes localisées gèrent désormais correctement les chemins avec tirets, imbriqués et les segments paramétrés.
  - Les parents imbriqués sont conservés lorsqu'une route enfant est absolue.
  - `hreflang` est émis depuis l'`iso` de la locale, pas depuis le code de routage.
  - Le changement de locale sous `no_prefix` remplace désormais l'historique au lieu de pousser une entrée.
- **Redirections.**
  - `autoDetectPath` est respecté pour les redirections basées sur le cookie et la préférence `Accept-Language`.
  - Les alias `localeRoutes` sont préservés sous `autoDetectPath: '/'`.
- **Traductions.**
  - Les fonctions plurielles personnalisées renvoyant `null` retombent désormais sur la règle plurielle par défaut.
  - Les couches de traduction fusionnent sans dumps aplatis.
  - Les locales désactivées sont omises des payloads publics premerged.
  - Le HMR ignore les écritures de fichiers sans effet et refusionne en parallèle lors des changements de locale racine.
- **Switcher.** Masque les locales `disabled` et rétablit `customDisabledLinkStyle` ainsi que la priorité du style actif.
- **Module.** Ponts pour les types `Plugin` d'unplugin Vite 8 pour la compatibilité Nuxt Kit.
- **SSR.** Le SSR Node lit désormais depuis les payloads publics (pas d'import Rollup `raw:`).

## Changements incompatibles (v3.22.0)

- Les fragments SSR ont migré de `useState('i18n-ssr-chunks')` vers `nuxtApp.payload.data['i18n-ssr-chunks']`.
- `getAllTranslations()` a été retiré de `@i18n-micro/vue`. Utilisez `resolveTranslations()`, `getStorage()` ou `getRouteCache()` à la place.
- La valeur par défaut de `dateBuild` est désormais une empreinte de contenu, donc le `?v=` du payload changera une fois lors de la mise à niveau.
