**Date** : 2025-10-30

**Version** : `v2.0.0`

![Version v2.0.0](/images/2.0.0.png)

Nous introduisons le HMR côté serveur pour les fichiers de traduction en développement. Lorsqu’une traduction JSON change, le cache du serveur invalide uniquement les clés concernées, et les requêtes suivantes reçoivent immédiatement des données à jour, sans aucun redémarrage.

## Quoi de neuf ? {#what’s-new}

- HMR côté serveur pour les fichiers de traduction
- Invalidation instantanée du cache par page/locale
- Une expérience de développement fluide pendant l’édition du contenu

## Fonctionnement {#how-it-works}

- Le watcher dans `src/runtime/server/plugins/watcher.dev.ts` observe `<rootDir>/<translationDir>/**/*.json`
- Les fichiers de page (par ex. `pages/<page>/<locale>.json`) invalident `_locales:merged:<page>:<locale>`
- Les fichiers à la racine (par ex. `<locale>.json`) invalident toutes les clés fusionnées de cette locale
- Enregistré automatiquement depuis `src/module.ts` en développement lorsque `experimental.hmr !== false`

## Configuration {#configuration}

```ts
export default defineNuxtConfig({
  i18n: {
    experimental: { hmr: true }, // default in dev
  },
})
```
