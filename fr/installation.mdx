## Prérequis

- **Node.js** : 18 ou plus récent.
- **Nuxt** : 3.x ou 4.x.

Le module prend en charge à la fois l'organisation de projet Nuxt 3 (`pages/**/*.vue`) et celle de Nuxt 4 (`app/pages/**/*.vue`). Les traductions résident à la racine du projet par convention (`locales/`), même lorsque vous utilisez le répertoire `app/` de Nuxt 4.

## Installer le module Nuxt

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Enregistrez-le dans `nuxt.config.ts` :

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Consultez le [Démarrage rapide](/quickstart) pour une visite complète ou la [Référence de configuration](/guides/configuration) pour toutes les options.

## Organisation du projet

Par défaut, le module attend :

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Les fichiers au niveau racine sont fusionnés dans chaque fichier spécifique à une page au moment du build. Les fichiers spécifiques à une page sont créés automatiquement lorsqu'ils manquent lors de `nuxt dev`.

## Organisation Nuxt 4

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Pour colocaliser les traductions sous `app/`, définissez `translationDir: 'app/locales'`.

Les paquets internes partagés sont inclus de manière transitive.

## TypeScript

Le module génère des types ambiants pour `useI18n`, `$t` et les aides associées à partir de vos fichiers de locale par défaut. Ceci est activé par défaut (`types: true`).

Pour un typage plus fort des clés de traduction, voir [`@i18n-micro/types-generator`](/integrations/types-generator).
