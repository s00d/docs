# Utiliser les traductions dans les composants

Une fois le module installé et configuré, vous pouvez afficher les traductions en appelant `$t('your_key')` dans vos templates et scripts Vue.

## 1. Fichiers de traduction au niveau racine et spécifiques à une page

1. Les traductions **au niveau racine** résident directement sous le dossier `/locales` (par exemple `/locales/en.json`, `/locales/fr.json`). Au moment du build, elles sont automatiquement fusionnées dans chaque fichier spécifique à une page, ce qui les rend disponibles sur toutes les pages.
2. Les traductions **spécifiques à une page** résident sous `/locales/pages/...`, en suivant la structure du dossier `pages` de Nuxt :

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. Utilisation dans un template avec `$t`

Dans vos fichiers `.vue`, vous pouvez utiliser `$t` directement dans le template :

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
`$t` peut renvoyer des **objets** si la clé pointe vers un nœud JSON imbriqué (par exemple `$t('header')` → `\{ title: "Hi" \}`). Dans les templates, cela s'affiche comme `[object Object]`. Utilisez `$ts` lorsque vous avez besoin d'une chaîne garantie, ou fournissez une clé plus spécifique comme `$t('header.title')`. Voir [Référence de l'API — $t vs $ts](/api/methods#t) pour les détails.
</Tip>

## 3. Changer la locale courante

Pour changer de langue dans votre app, vous pouvez récupérer `$locale` depuis `useI18n()` et lui attribuer un nouveau code :

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. Clés imbriquées et placeholders

- Les **clés imbriquées** utilisent la notation par points, par exemple `nested.key.deeper`.
- Les **placeholders** vous permettent d'insérer des valeurs dynamiques :
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. Astuces et bonnes pratiques

- **Clés en conflit** : si un fichier spécifique à une page contient la même clé qu'un fichier au niveau racine, la version spécifique à la page l'emporte (les traductions racines sont fusionnées comme base au moment du build).
- **Désactiver les fichiers par page** : si vous préférez ne pas utiliser les traductions spécifiques aux pages, vous pouvez définir `disablePageLocales: true` dans votre config Nuxt. Ainsi, seuls les fichiers `/locales/*.json` seront utilisés.
- **Pas d'imports directs** : vous n'avez pas besoin de faire `import \{ useI18n \} from 'nuxt-i18n-micro'` ; la fonctionnalité d'auto-injection du module s'en charge pour vous.

C'est tout ! Avec ces étapes, vous pouvez rapidement **commencer à récupérer les traductions** depuis des fichiers JSON racine ou spécifiques à une page et **les afficher** dans votre application Nuxt avec `$t`.

## Ressources supplémentaires

Pour explorer les fonctionnalités plus avancées, consultez :

1. **Composant `<i18n-t>`**  
   Le composant `<i18n-t>` est une alternative puissante à `$t`, particulièrement utile pour les cas d'éléments imbriqués, d'usages avancés de placeholders et de structures de traduction plus complexes.

- **Documentation** : [i18n-t](/api/components/i18n-t)

2. **Composable `useI18n`**  
   Le composable `useI18n` offre un ensemble complet de fonctions et de propriétés réactives pour gérer les traductions, le changement de locale, le formatage et plus encore.

- **Documentation** : [useI18n](/api/composables/use-i18n)
