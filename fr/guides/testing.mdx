# 🧪 Tester le module `Nuxt I18n Micro`

## 📖 Introduction aux tests

Tester le module `Nuxt I18n Micro` est essentiel pour garantir que les fonctionnalités de localisation de votre application fonctionnent comme prévu. Cette documentation vous guidera dans la configuration de l'environnement de test, la création de configurations mock pour vitest et l'écriture de tests pour vos composants. Pour un exemple pratique, vous pouvez consulter le [projet d'exemple sur GitHub](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/test-utils/example).

Consultez [Tester les stratégies de routage](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/testing-strategies.md) pour découvrir comment ce dépôt exécute ses propres suites de tests — les projets Vitest `unit` / `integration` / `e2e`, les fichiers par stratégie (`test/strategies-*.test.ts`) et les régressions de génération.

## 🛠️ Configurer l'environnement de test

### 1. Installer `@i18n-micro/test-utils`

D'abord, vous devez installer les utilitaires de test pour `Nuxt I18n Micro`. Ce paquet fournit les outils nécessaires pour mocker et tester vos configurations i18n.

```bash
npm install @i18n-micro/test-utils --save-dev
```

### 2. Créer un fichier de configuration mock

Ensuite, créez un fichier pour configurer la configuration i18n mock. Ce fichier sera utilisé pour mocker les fonctions et utilitaires i18n pendant vos tests.

```typescript
// tests/unit-setup.ts

import { mockNuxtImport } from '@nuxt/test-utils/runtime'
import { vi } from 'vitest'
import { i18nUtils } from '@i18n-micro/test-utils'

export function createFakeI18n() {
  return {
    $getLocale: vi.fn(i18nUtils.getLocale),
    $t: vi.fn(i18nUtils.t),
    $tc: vi.fn(i18nUtils.tc),
    $setLocale: vi.fn(i18nUtils.setLocale),
    $getLocaleName: vi.fn(i18nUtils.getLocaleName),
    $setLocaleName: vi.fn(i18nUtils.setLocaleName),
    $getLocales: vi.fn(i18nUtils.getLocales),
    $setLocales: vi.fn(i18nUtils.setLocales),
    $defaultLocale: vi.fn(i18nUtils.defaultLocale),
    $setDefaultLocale: vi.fn(i18nUtils.setDefaultLocale),
    $getRouteName: vi.fn(i18nUtils.getRouteName),
    $settRouteName: vi.fn(i18nUtils.settRouteName),
    $ts: vi.fn(i18nUtils.ts),
    $tn: vi.fn(i18nUtils.tn),
    $td: vi.fn(i18nUtils.td),
    $has: vi.fn(i18nUtils.has),
    $resolveTranslations: vi.fn(i18nUtils.resolveTranslations),
    $setTranslation: vi.fn(i18nUtils.setTranslation),
    $mergeTranslations: vi.fn(i18nUtils.mergeTranslations),
    $switchLocaleRoute: vi.fn(i18nUtils.switchLocaleRoute),
    $switchLocalePath: vi.fn(i18nUtils.switchLocalePath),
    $switchLocale: vi.fn(i18nUtils.switchLocale),
    $switchRoute: vi.fn(i18nUtils.switchRoute),
    $localeRoute: vi.fn(i18nUtils.localeRoute),
    $localePath: vi.fn(i18nUtils.localePath),
    $setI18nRouteParams: vi.fn(i18nUtils.setI18nRouteParams),
  }
}

mockNuxtImport<() => ReturnType<typeof createFakeI18n>>('useI18n', () => vi.fn(() => createFakeI18n()))

export const setTranslationsFromJson = i18nUtils.setTranslationsFromJson
```

### 3. Configurer Vitest

Maintenant, configurez Vitest pour utiliser le fichier de configuration mock et mettre en place l'environnement de test.

```typescript
// vitest.config.ts

import { defineVitestConfig } from '@nuxt/test-utils/config'

export default defineVitestConfig({
  test: {
    watch: false,
    setupFiles: ['./tests/unit-setup.ts'],
    include: ['./**/*.spec.ts'],
  },
})
```

## 🧪 Écrire des tests

### Composant d'exemple

Voici un exemple de composant simple qui utilise le composable `useI18n` pour traduire des messages.

```vue
<script setup lang="ts">
const { $t } = useI18n()

const props = defineProps({
  message: {
    type: String,
    default: null,
  },
})

// Test to see that $t works in script setup as well as the template
const message = props.message || $t('defaultMessage')
</script>

<template>
  <div>
    <p>Test from component: {{ $t('welcome') }}</p>
    <p data-testid="message">Test message from props: {{ message }}</p>
  </div>
</template>
```

### Fichier de test

Écrivons maintenant un test pour ce composant.

```typescript
// tests/unit/example.spec.ts

import { describe, it, expect, beforeEach } from 'vitest'
import { mount } from '@vue/test-utils'
import ExampleComponent from '@/components/ExampleComponent.vue'
import fs from 'fs'
import path from 'path'
import { setTranslationsFromJson } from './unit-setup'

describe('ExampleComponent', () => {
  beforeEach(async () => {
    const fileContent = fs.readFileSync(path.join(__dirname, '../../locales/en-GB.json')).toString()
    await setTranslationsFromJson('en', JSON.parse(fileContent))
  })

  it('renders the welcome message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.text()).toContain('Test from component: Welcome')
  })

  it('renders the default message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Default Message')
  })

  it('renders the custom message correctly', () => {
    const wrapper = mount(ExampleComponent, {
      props: {
        message: 'Custom Message',
      },
    })
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Custom Message')
  })
})
```

## 📝 Bonnes pratiques pour les tests

- **🔧 Mockez les fonctions i18n :** Mockez toujours les fonctions i18n avec `@i18n-micro/test-utils` pour garantir des résultats de test cohérents et prévisibles.
- **⚙️ Utilisez Vitest pour les tests unitaires :** Vitest est un framework de test puissant pour les applications Vue. Utilisez-le pour écrire des tests unitaires pour vos composants.
- **📚 Documentez vos tests :** Documentez clairement l'objectif et les résultats attendus de chaque test. Cela contribuera à maintenir la clarté et facilitera la compréhension des tests par les autres (ou par votre futur vous).

## 📊 Méthodes utilitaires i18n

Vous trouverez ci-dessous un tableau décrivant toutes les méthodes utilitaires fournies par `@i18n-micro/test-utils`.

| Méthode                                        | Description                                                                                                                                |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `t(key, params, defaultValue)`                  | Traduit une clé avec des paramètres optionnels et une valeur par défaut.                                                                   |
| `tc(key, params, defaultValue)`                 | Traduit une clé avec prise en charge de la pluralisation.                                                                                  |
| `setTranslationsFromJson(locale, translations)` | Charge des traductions depuis un objet JSON pour une locale spécifique.                                                                    |
| `getLocale()`                                   | Renvoie la locale actuelle.                                                                                                                |
| `setLocale(val)`                                | Définit la locale actuelle.                                                                                                                |
| `getLocaleName()`                               | Renvoie le nom de la locale actuelle.                                                                                                      |
| `setLocaleName(val)`                            | Définit le nom de la locale actuelle.                                                                                                      |
| `getLocales()`                                  | Renvoie la liste des locales disponibles.                                                                                                  |
| `setLocales(val)`                               | Définit la liste des locales disponibles.                                                                                                  |
| `defaultLocale()`                               | Renvoie la locale par défaut.                                                                                                              |
| `setDefaultLocale(val)`                         | Définit la locale par défaut.                                                                                                              |
| `getRouteName()`                                | Renvoie le nom de la route actuelle.                                                                                                       |
| `settRouteName(val)`                            | Définit le nom de la route actuelle.                                                                                                       |
| `ts(key, params, defaultValue)`                 | Traduit une clé et renvoie le résultat sous forme de chaîne.                                                                               |
| `tn(value, options?)`                           | Formate un nombre avec des `Intl.NumberFormatOptions` en ligne. Les formats nommés nécessitent la config du module et ne sont pas disponibles dans ce helper autonome. |
| `td(value, options?)`                           | Formate une date avec des `Intl.DateTimeFormatOptions` en ligne. Les formats nommés nécessitent la config du module et ne sont pas disponibles dans ce helper autonome. |
| `has(key)`                                      | Vérifie si une clé de traduction existe.                                                                                                   |
| `resolveTranslations()`                         | Renvoie l'arbre de traduction actif pour la locale et la route actuelles.                                                                  |
| `setTranslation(key, value)`                    | Remplace la valeur à `key` dans le dictionnaire actif (remplacement, pas fusion).                                                          |
| `mergeTranslations(newTranslations)`            | Fusionne des traductions dans la locale active à l'exécution.                                                                              |

En suivant ces étapes, vous pouvez tester efficacement le module `Nuxt I18n Micro` et garantir que les fonctionnalités de localisation de votre application fonctionnent comme prévu.
