# 🌐 Guide d'intégration Crowdin

## 📖 Introduction

Intégrer Crowdin à votre projet simplifie le processus de localisation et de traduction, facilitant la gestion des traductions dans plusieurs langues et plateformes. Ce guide propose une procédure pas à pas pour configurer Crowdin avec votre projet, incluant la configuration, le téléversement des sources et le téléchargement des traductions.

## 🔧 Installation et configuration

Pour démarrer avec Crowdin, vous devez installer le CLI Crowdin globalement sur votre machine et l'initialiser dans votre répertoire de projet.

### 📦 Installer le CLI Crowdin

Tout d'abord, installez le CLI Crowdin globalement avec npm :

```bash
npm install -g @crowdin/cli
```

### 🛠 Initialiser Crowdin dans votre projet

Initialisez Crowdin dans votre projet en exécutant :

```bash
crowdin init
```

Cette commande vous guidera à travers le processus de configuration, incluant la définition de votre ID de projet, du jeton API et d'autres détails de configuration.

## 🗂️ Guide de configuration

### 📄 Fichier de configuration Crowdin (`crowdin.yml`)

Le fichier de configuration Crowdin (`crowdin.yml`) définit comment vos fichiers sources sont mis en correspondance et où les traductions doivent être placées. Voici un exemple de configuration :

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Paramètres de configuration clés

- **`project_id`** : L'ID de votre projet Crowdin. Il identifie le projet dans Crowdin où les traductions sont gérées.
- **`api_token`** : Le jeton API utilisé pour l'authentification. Assurez-vous que ce jeton a les permissions correctes pour téléverser et télécharger des traductions.
- **`base_path`** : Spécifie le répertoire de base pour les fichiers sources. Dans cet exemple, les traductions sont stockées dans le répertoire `./locales`.
- **`base_url`** : L'URL de base pour l'API Crowdin.
- **`preserve_hierarchy`** : Lorsqu'il est défini sur `true`, Crowdin conservera la structure de dossiers de vos fichiers sources dans le projet.

### 📂 Configuration des fichiers

La section `files` associe vos fichiers sources aux chemins où les traductions seront stockées. Par exemple :

- **Chemin source** : Définit l'emplacement des fichiers de traduction d'origine.
- **Chemin de traduction** : Spécifie où les fichiers traduits seront stockés dans Crowdin. Des espaces réservés comme `%two_letters_code%` sont utilisés pour définir dynamiquement le code de langue dans les chemins de fichiers.

## ⬆️ Téléverser les fichiers sources vers Crowdin

Une fois votre configuration Crowdin définie, vous pouvez téléverser vos fichiers sources avec la commande suivante :

```bash
crowdin upload sources
```

Cette commande téléverse tous les fichiers sources spécifiés dans votre configuration vers Crowdin, les rendant disponibles pour la traduction.

## ⬇️ Télécharger les traductions depuis Crowdin

Une fois les traductions terminées ou mises à jour dans Crowdin, vous pouvez les télécharger dans votre projet avec :

```bash
crowdin download
```

Cette commande récupère les dernières traductions de Crowdin et les enregistre selon les chemins spécifiés dans votre fichier de configuration.

## ⚙️ Bonnes pratiques

### 🔑 Nommage cohérent des clés

Assurez-vous que les clés de traduction sont cohérentes dans tous les fichiers pour éviter la confusion et la duplication.

### 🧹 Maintenance régulière

Passez périodiquement en revue et nettoyez les clés de traduction inutilisées pour garder vos fichiers organisés et gérables.

### 🛠 Automatiser les téléversements et téléchargements

Intégrez les commandes du CLI Crowdin à votre pipeline CI/CD pour automatiser le téléversement des fichiers sources et le téléchargement des traductions, afin que vos traductions soient toujours à jour.

En suivant ce guide, vous serez en mesure d'intégrer Crowdin à votre projet de manière fluide, garantissant une approche efficace et organisée pour gérer vos efforts d'internationalisation.
