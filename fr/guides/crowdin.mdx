# 🌐 Guide d'intégration Crowdin

## 📖 Introduction

Intégrer Crowdin à votre projet rationalise le processus de localisation et de traduction, en facilitant la gestion des traductions dans plusieurs langues et plateformes. Ce guide fournit une procédure étape par étape pour mettre en place Crowdin avec votre projet, y compris la configuration, le téléversement des sources et le téléchargement des traductions.

## 🔧 Installation et configuration

Pour démarrer avec Crowdin, vous devez installer le CLI Crowdin de manière globale sur votre machine et l'initialiser dans le dossier de votre projet.

### 📦 Installer le CLI Crowdin

Installez d'abord le CLI Crowdin globalement avec npm :

```bash
npm install -g @crowdin/cli
```

### 🛠 Initialiser Crowdin dans votre projet

Initialisez Crowdin dans votre projet en exécutant :

```bash
crowdin init
```

Cette commande vous guidera à travers le processus de configuration, y compris la définition de votre ID de projet, du token API et d'autres détails de configuration.

## 🗂️ Guide de configuration

### 📄 Fichier de configuration Crowdin (`crowdin.yml`)

Le fichier de configuration Crowdin (`crowdin.yml`) définit la manière dont vos fichiers source sont mappés et où les traductions doivent être placées. Voici un exemple de configuration :

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Paramètres clés de la configuration

- **`project_id`** : votre ID de projet Crowdin. Identifie le projet dans Crowdin où les traductions sont gérées.
- **`api_token`** : le token API utilisé pour l'authentification. Assurez-vous que ce token dispose des permissions correctes pour téléverser et télécharger des traductions.
- **`base_path`** : indique le répertoire de base des fichiers source. Dans cet exemple, les traductions sont stockées dans le dossier `./locales`.
- **`base_url`** : l'URL de base de l'API Crowdin.
- **`preserve_hierarchy`** : quand `true`, Crowdin conserve la structure de dossiers de vos fichiers source dans le projet.

### 📂 Configuration des fichiers

La section `files` mappe vos fichiers source vers les chemins où les traductions seront stockées. Par exemple :

- **Chemin source** : définit l'emplacement des fichiers de traduction d'origine.
- **Chemin de traduction** : spécifie où les fichiers traduits seront stockés dans Crowdin. Des placeholders comme `%two_letters_code%` servent à définir dynamiquement le code de langue dans les chemins de fichiers.

## ⬆️ Téléverser les fichiers source vers Crowdin

Une fois votre configuration Crowdin en place, vous pouvez téléverser vos fichiers source avec la commande suivante :

```bash
crowdin upload sources
```

Cette commande téléverse tous les fichiers source spécifiés dans votre configuration vers Crowdin, les rendant disponibles pour la traduction.

## ⬇️ Télécharger les traductions depuis Crowdin

Après que les traductions ont été effectuées ou mises à jour dans Crowdin, vous pouvez les télécharger dans votre projet avec :

```bash
crowdin download
```

Cette commande récupère les dernières traductions depuis Crowdin et les enregistre selon les chemins spécifiés dans votre fichier de configuration.

## ⚙️ Bonnes pratiques

### 🔑 Nommage cohérent des clés

Assurez-vous que les clés de traduction sont cohérentes dans tous les fichiers pour éviter confusion et duplication.

### 🧹 Maintenance régulière

Passez périodiquement en revue et nettoyez les clés de traduction inutilisées pour garder vos fichiers organisés et faciles à gérer.

### 🛠 Automatiser les téléversements et téléchargements

Intégrez les commandes du CLI Crowdin dans votre pipeline CI/CD pour automatiser le téléversement des fichiers source et le téléchargement des traductions, garantissant que vos traductions sont toujours à jour.

En suivant ce guide, vous serez en mesure d'intégrer Crowdin à votre projet de manière transparente et d'assurer une approche efficace et organisée pour gérer vos efforts d'internationalisation.
