# 🛠️ DevTools dans `nuxt-i18n-micro`

## Vue DevTools (extension navigateur)

En développement, le module peut enregistrer un inspecteur et une timeline personnalisés **Vue DevTools** via `@vue/devtools-api`. Ceci est distinct de l'onglet Nuxt DevTools décrit ci-dessous.

| Outil | Idéal pour |
|------|----------|
| **Vue DevTools** | Locale active, cache de traduction en mémoire, timeline `$t` (`debug: true`), événements de clés manquantes |
| **Onglet Nuxt DevTools** | Édition des fichiers JSON sur disque, vue d'ensemble de la configuration, import/export |

Le plugin vue-devtools n'est enregistré que pendant `nuxt dev` (pas dans les builds de production). L'état du pont réservé au développement dans le plugin principal est retiré par l'élimination de code mort via `import.meta.dev`.

Désactivez l'intégration navigateur tout en conservant l'onglet Nuxt :

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

Les événements verbeux de timeline `$t` nécessitent `debug: true`.

## 📖 Qu'est-ce que Nuxt DevTools ?

DevTools est un assistant de développement puissant intégré de manière transparente au module `nuxt-i18n-micro`. Il offre une interface intuitive pour gérer les tâches de localisation et de traduction, rendant votre flux de travail plus rapide et plus efficace. Conçu pour les développeurs qui valorisent la commodité, Nuxt DevTools comble le fossé entre le codage et la gestion à l'exécution.

## 🌟 Fonctionnalités clés de DevTools dans `nuxt-i18n-micro`

### 1. **Gestion des locales**

Parcourez, sélectionnez et gérez sans effort les locales de votre application. Que vous travailliez avec une seule langue ou plusieurs, DevTools fournit un hub centralisé pour gérer tous les paramètres de localisation.

### 2. **Édition des traductions**

Éditez les fichiers de traduction directement via un éditeur JSON intégré. Cela élimine le besoin d'outils externes, permettant des mises à jour et modifications en temps réel sans interrompre votre flux de travail.

### 3. **Import et export de fichiers**

Simplifiez la gestion des fichiers de traduction :

- **Exporter** : Enregistrez les traductions en tant que fichier JSON pour des sauvegardes ou une utilisation externe.
- **Importer** : Chargez des fichiers de traduction mis à jour dans le projet pour garder le contenu à jour.

### 4. **Aperçus en temps réel**

Visualisez les changements immédiatement dans l'environnement de développement. Cette fonctionnalité garantit que les traductions et les configurations sont précises avant la mise en production.

### 5. **Intégration Nuxt fluide**

DevTools fonctionne nativement avec `nuxt-i18n-micro`, améliorant ses capacités sans nécessiter de configuration supplémentaire. Il s'adapte à vos besoins de localisation tout en préservant la structure modulaire et flexible de Nuxt.

## 🛠️ Pourquoi utiliser DevTools ?

Nuxt DevTools est un ajout indispensable pour les projets nécessitant de la localisation. Il aide les développeurs en :

- **Gagnant du temps** : Automatise les tâches répétitives comme la gestion des fichiers et la validation des formats.
- **Réduisant les erreurs** : Fournit un environnement sûr et intuitif pour éditer les traductions.
- **Améliorant la collaboration** : Permet aux non-développeurs de gérer facilement les traductions.
- **Rationalisant les flux de travail** : Consolide plusieurs tâches de localisation dans une seule interface.
