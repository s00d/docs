# 🛠️ DevTools dans `nuxt-i18n-micro`

## Vue DevTools (extension navigateur)

En développement, le module peut enregistrer un inspecteur personnalisé et une timeline **Vue DevTools** via `@vue/devtools-api`. C'est distinct de l'onglet Nuxt DevTools ci-dessous.

| Outil | Idéal pour |
|------|----------|
| **Vue DevTools** | Locale en direct, cache de traductions en mémoire, timeline `$t` (`debug: true`), événements de clés manquantes |
| **Onglet Nuxt DevTools** | Édition des fichiers JSON sur disque, vue d'ensemble de la config, import/export |

Le plugin vue-devtools n'est enregistré que pendant `nuxt dev` (pas dans les builds de production). L'état de bridge réservé au dev dans le plugin principal est retiré par l'élimination de code mort `import.meta.dev`.

Désactivez l'intégration navigateur tout en conservant l'onglet Nuxt :

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

Les événements verbeux de la timeline `$t` nécessitent `debug: true`.

## 📖 Qu'est-ce que Nuxt DevTools ?

DevTools est un puissant assistant de développement intégré de manière transparente au module `nuxt-i18n-micro`. Il fournit une interface intuitive pour gérer les tâches de localisation et de traduction, en rendant votre flux de travail plus rapide et plus efficace. Conçu pour les développeurs qui apprécient le confort, Nuxt DevTools comble l'écart entre le code et la gestion au runtime.

## 🌟 Fonctionnalités clés des DevTools dans `nuxt-i18n-micro`

### 1. **Gestion des locales**

Parcourez, sélectionnez et gérez les locales de votre application sans effort. Que vous travailliez avec une seule langue ou plusieurs, DevTools fournit un point central pour gérer tous les paramètres de localisation.

### 2. **Édition des traductions**

Éditez les fichiers de traduction directement via un éditeur JSON intégré. Cela supprime le besoin d'outils externes et permet des mises à jour et modifications en temps réel sans interrompre votre flux de travail.

### 3. **Import et export de fichiers**

Simplifiez la gestion des fichiers de traduction :

- **Export** : sauvegardez les traductions dans un fichier JSON pour des sauvegardes ou un usage externe.
- **Import** : chargez des fichiers de traduction mis à jour dans le projet pour tenir le contenu à jour.

### 4. **Aperçus en temps réel**

Visualisez les modifications immédiatement dans l'environnement de développement. Cette fonctionnalité garantit que les traductions et les configurations sont correctes avant la mise en production.

### 5. **Intégration Nuxt transparente**

DevTools fonctionne nativement avec `nuxt-i18n-micro`, étendant ses capacités sans nécessiter de configuration supplémentaire. Il s'adapte à vos besoins de localisation tout en préservant la structure modulaire et flexible de Nuxt.

## 🛠️ Pourquoi utiliser DevTools ?

Nuxt DevTools est un ajout indispensable pour les projets nécessitant de la localisation. Il aide les développeurs à :

- **Gagner du temps** : automatise les tâches répétitives comme la gestion des fichiers et la validation des formats.
- **Réduire les erreurs** : fournit un environnement sûr et intuitif pour éditer les traductions.
- **Améliorer la collaboration** : permet aux non-développeurs de gérer facilement les traductions.
- **Rationaliser les workflows** : consolide plusieurs tâches de localisation dans une seule interface.

Avec Nuxt DevTools intégré à `nuxt-i18n-micro`, la gestion des applications multilingues devient simple et efficace. Que vous peaufiniez des traductions ou ajoutiez de nouvelles locales, DevTools vous fournit les outils nécessaires pour offrir des expériences polies et conviviales.
