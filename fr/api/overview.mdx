# Référence de l'API

## API runtime

- [Méthodes](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, changement de locale, aides de routage
- [Événements](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Traductions et cache](/api/cache) — `TranslationStorage`, chargement des payloads, `$clearCache`

## Middleware serveur

Les handlers serveur utilisent un middleware dédié (et non les aides client `$t`) :

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — traduisez dans les routes d'API et les handlers serveur
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — lisez la locale détectée et ses métadonnées

Consultez le [guide complet Traductions côté serveur](/guides/server-side-translations) pour la mise en place, l'ordre de priorité de détection de la locale et des exemples.
