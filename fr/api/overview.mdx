Cette section répertorie chaque option, helper, hook, composable et composant du module Nuxt, ainsi que l'API exportée de chaque package `@i18n-micro/*`. Utilisez-la pour retrouver une signature ou une valeur par défaut ; le [Guide](/fr/guide/getting-started) explique comment les utiliser. La plupart des tableaux de cette section sont générés à partir du code source et correspondent donc au code.

## Module Nuxt {#nuxt-module}

| Page | Contenu |
| --- | --- |
| [Options du module](/fr/api/module-options) | Chaque clé `i18n` de `nuxt.config`, avec son type et sa valeur par défaut |
| [Helpers](/fr/api/methods) | `$t`, `$tc`, `$tn`, `$td`, `$localePath`, `$switchLocale`, `$defineI18nRoute` et les autres |
| [Hooks](/fr/api/events) | Le hook d'exécution `i18n:register` |

## Composables {#composables}

| Composable | À utiliser pour |
| --- | --- |
| [`useI18n`](/fr/composables/useI18n) | Les helpers dans `<script setup>` |
| [`useI18nLocale`](/fr/composables/useI18nLocale) | L'état de la locale et le cookie dans un plugin de détection personnalisé |
| [`useI18nHead`](/fr/composables/useI18nHead) | Les surcharges par page des balises SEO générées |
| [`useLocaleHead`](/fr/composables/useLocaleHead) | Les balises SEO sous forme d'objet, pour votre propre `useHead` |

## Composants {#components}

| Composant | Affiche |
| --- | --- |
| [`<i18n-t>`](/fr/components/i18n-t) | Une traduction, avec pluriel, formatage et interpolation par slots |
| [`<i18n-link>`](/fr/components/i18n-link) | Un `NuxtLink` vers la route localisée |
| [`<i18n-switcher>`](/fr/components/i18n-switcher) | Un menu déroulant de locales |
| [`<i18n-group>`](/fr/components/i18n-group) | Un bloc avec un préfixe de clé partagé |

## Serveur {#server}

Les handlers Nitro utilisent `useTranslationServerMiddleware` et `useLocaleServerMiddleware`, et non les helpers client. Voir [Routes serveur](/fr/guide/server-side-translations).

## Packages {#packages}

[API des packages](/fr/api/packages/overview) répertorie les exports de chaque package `@i18n-micro/*`, avec une page générée pour chacun.
