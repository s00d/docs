# Référence de l'API

## API d'exécution

- [Méthodes](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, changement de locale, helpers de routage
- [Événements](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Traductions et cache](/api/cache) — `TranslationStorage`, chargement du payload, `$clearCache`

## Middleware serveur

Les gestionnaires côté serveur utilisent un middleware dédié (et non les helpers client `$t`) :

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — traduire dans les routes d'API et gestionnaires serveur
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — lire la locale détectée et ses métadonnées

Consultez le [guide complet sur les traductions côté serveur](/guides/server-side-translations) pour la configuration, la priorité de détection des locales et des exemples.
