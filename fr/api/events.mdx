Le module appelle un seul hook d'exécution (hook d'application), `i18n:register`. Utilisez-le lorsqu'un plugin ou un module ajoute des traductions qui ne figurent pas dans vos fichiers `locales/`. Votre callback reçoit une fonction `register` qui fusionne les traductions dans la page en cours d'affichage.

## `i18n:register` {#i18nregister}

```ts
'i18n:register': (
  register: (translations: unknown, locale?: string) => void,
  locale: string,
) => HookResult
```

| Argument | Description |
| --- | --- |
| `register(translations, locale?)` | Fusionne en profondeur `translations` dans le chunk de page de la route en cours de chargement, pour `locale` (par défaut : la `locale` du hook). Les clés déjà présentes sont écrasées. |
| `locale` | La locale de la route en cours de chargement. |

Le hook est typé via `RuntimeNuxtHooks`, donc `nuxtApp.hook('i18n:register', …)` ne nécessite aucun cast.

## Quand il se déclenche {#when-it-fires}

Le plugin de chargement (`i18n-plugin-loader`) l'appelle :

1. une fois au démarrage, lorsque tous les plugins se sont exécutés (`app:created`) et avant le rendu de l'application ;
2. dans son `router.beforeEach`, après le chargement des traductions de la page cible, lorsque le chemin change — à chaque navigation sous `no_prefix`.

Chaque callback et chaque appel à `register` est attendu avant que l'application ne s'affiche ou que la navigation ne se poursuive, de sorte que la page s'affiche avec les clés fusionnées. Avec [`hooks: false`](/fr/api/module-options#hooks), le hook n'est jamais appelé.

## Exemple {#example}

```ts
// plugins/i18n-extra.ts
export default defineNuxtPlugin((nuxtApp) => {
  nuxtApp.hook('i18n:register', async (register, locale) => {
    const extra = await $fetch<Record<string, unknown>>(`/api/cms-strings/${locale}`)
    register(extra, locale)
  })
})
```

Il s'agit d'un hook d'exécution : enregistrez-le avec `nuxtApp.hook` dans un plugin, et non avec `nuxt.hook` dans `nuxt.config` ou dans le `setup` d'un module. Un module ajoute un tel plugin avec `addPlugin`.
