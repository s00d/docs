# 🛠️ Composable `useI18n`

Le composable `useI18n` de `Nuxt I18n Micro` donne accès à la plupart des aides i18n runtime dans les composants et les scripts. Les méthodes sont disponibles **avec et sans le préfixe `$`** (par exemple `$t` et `t`).

Certaines injections — `$defineI18nRoute` et `$clearCache` — ne sont disponibles que sur `useNuxtApp()`. Voir [Méthodes — `$defineI18nRoute`](/api/methods#definei18nroute) et [`$clearCache`](/api/methods#clearcache).

## 📊 Ce qu'il renvoie

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Chaque aide runtime, sous forme d'un objet simple.

Les mêmes fonctions que le plugin injecte en tant que `$t`, `$tc`, etc., disponibles à la fois sous le nom préfixé par le dollar et sous un alias nu. Ainsi, `const \{ t \} = useI18n()` et `const \{ $t \} = useI18n()` fonctionnent tous les deux.

**Retourne** — les aides décrites dans la [référence des méthodes](/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

Chaque aide qu'il renvoie — `$t`, `$tc`, `$has`, `$switchLocale`, et les autres — est listée avec sa signature et documentée entièrement dans la [référence des méthodes](/api/methods).

## API uniquement sur `useNuxtApp()`

Celles-ci ne sont **pas** renvoyées par `useI18n()`. Importez-les depuis `useNuxtApp()` :

| Méthode                    | Objectif                                                                        |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Routes de locale, restrictions et traductions en ligne par page dans `script setup` |
| `$clearCache()`            | Vide le cache de traductions en mémoire et les chunks chargés                   |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Consultez [Méthodes](/api/methods) pour les signatures complètes et des exemples.

## 🛠️ Exemples d'utilisation

### Récupération basique de la locale

Récupérez la locale courante de l'application.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Traduction avec paramètres

Traduisez une chaîne avec des paramètres dynamiques et une valeur par défaut de repli.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Changement de locale

Basculez l'application vers une autre locale.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Génération d'une route localisée

Générez une route localisée pour la locale courante ou pour une locale spécifiée.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
