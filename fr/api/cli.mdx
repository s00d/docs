Le [guide de la CLI](/fr/guide/cli) présente les workflows courants. Cette page liste tout, et elle est générée à partir de la même table que celle qui alimente `--help`.

## Options communes {#common-flags}

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--cwd` | répertoire courant | Répertoire du projet |
| `--logLevel` | `info` | Niveau de sortie : silent, info |
| `--debug` | `false` | Affiche une trace de pile lorsqu'une commande échoue |

## Inspection {#inspect}

### `info` {#info}

Affiche la configuration i18n résolue du projet

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--json` | `false` | Affiche du JSON au lieu de texte |

### `check` {#check}

Le garde-fou de la CI : échoue en cas de clés manquantes, vides, en trop, non définies ou inutilisées, et de placeholders cassés

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Répertoire des traductions, relatif au projet |
| `--only` | toutes sauf duplicates | Vérifications à exécuter, séparées par des virgules : missing, empty, extra, placeholders, undefined, unused, duplicates. `unused` nommé ici échoue lorsqu'il ne peut pas s'exécuter |
| `--duplicates` | `false` | Signale aussi le même texte sous des clés différentes |
| `--ignore` | — | Globs de fichiers source à ignorer, séparés par des virgules, relatifs au projet |
| `--json` | `false` | Affiche du JSON au lieu de texte |

```bash
i18n-micro check
i18n-micro check --only missing,placeholders --json
```

### `stats` {#stats}

Affiche le taux de complétion des traductions par locale

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Répertoire des traductions, relatif au projet |
| `--html` | — | Écrit aussi un rapport HTML dans ce fichier |
| `--json` | `false` | Affiche du JSON au lieu de texte |
| `--baseRef` | — | Référence Git avec laquelle comparer la complétion, par ex. HEAD~1 ou main |

```bash
i18n-micro stats --baseRef main
i18n-micro stats --html reports/i18n.html
```

### `lint` {#lint}

Vérifie le texte des traductions ; échoue s'il reste des problèmes

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Répertoire des traductions, relatif au projet |
| `--rules` | toutes, ou `enabledRules` de .i18n-lintrc.json | Règles à exécuter, séparées par des virgules : no-trailing-spaces, no-multiple-spaces, no-empty-translation, ou une règle personnalisée |
| `--fix` | `false` | Corrige ce qui peut l'être : les espaces, et les règles personnalisées avec un remplacement |
| `--json` | `false` | Affiche du JSON au lieu de texte |

```bash
i18n-micro lint --rules no-trailing-spaces --fix
```

### `search` {#search}

Recherche des clés et des valeurs, et indique où chaque clé est utilisée

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Répertoire des traductions, relatif au projet |
| `<query>` | — | Texte ou clé à rechercher |
| `--caseSensitive` | `false` | Respecte la casse |
| `--onlyUnused` | `false` | Uniquement les clés que `clean` supprimerait ; la requête devient facultative |
| `--scope` | `all` | Où chercher : global, pages, all |
| `--limit` | — | Renvoie au plus ce nombre de clés |
| `--ignore` | — | Globs de fichiers source à ignorer, séparés par des virgules, relatifs au projet |
| `--json` | `false` | Affiche du JSON au lieu de texte |

```bash
i18n-micro search "Welcome"
i18n-micro search --onlyUnused
```

## Workflow de traduction {#translation-workflow}

### `extract` {#extract}

Liste les clés utilisées par les fichiers source qui n'ont pas encore de texte, et ajoute celles qui ont un texte par défaut à la locale par défaut

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Répertoire des traductions, relatif au projet |
| `--ignore` | — | Globs de fichiers source à ignorer, séparés par des virgules, relatifs au projet |

```bash
i18n-micro extract
```

### `translate` {#translate}

Complète les traductions manquantes à partir de la locale par défaut via un service de traduction

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Répertoire des traductions, relatif au projet |
| `--service` | — | Service de traduction : ai, azure, deepl, google, libretranslate, yandexcloud |
| `--token` | — | Clé d'API. Préférez la variable d'environnement I18N_TRANSLATE_TOKEN : les options finissent dans l'historique du shell |
| `--options` | — | Options du service sous forme de paires clé:valeur, séparées par des virgules |
| `--locale` | toutes les locales sauf celle par défaut | Locales à compléter, séparées par des virgules |
| `--replace` | `false` | Retraduit toutes les clés, en remplaçant les valeurs existantes |
| `--dryRun` | `false` | Compte les clés et les caractères par locale ; n'envoie rien |
| `--chunkSize` | — | Chaînes par requête ; plafonné à ce que le service accepte |
| `--pluralSeparator` | `\|` | Séparateur des formes plurielles dans les messages |
| `--glossaryFile` | `.i18n-glossary.json` s'il existe | Fichier de glossaire, utilisé par le service `ai` |

```bash
i18n-micro translate --dryRun
I18N_TRANSLATE_TOKEN=... i18n-micro translate --service deepl --locale de,fr
i18n-micro translate --service ai --options provider:openai,model:gpt-4o-mini
i18n-micro translate --service libretranslate --options baseUrl:https://translate.example.com
```

### `sync` {#sync}

Supprime les clés que la locale par défaut n'a pas ; s'arrête lorsque l'opération ne peut pas être prouvée sûre. Les clés manquantes restent manquantes

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Répertoire des traductions, relatif au projet |
| `--ignore` | — | Globs de fichiers source à ignorer, séparés par des virgules, relatifs au projet |
| `--dryRun` | `false` | Liste ce qui serait supprimé ; n'écrit rien |
| `--force` | `false` | Supprime les clés même si l'opération ne peut pas être prouvée sûre |

```bash
i18n-micro sync --dryRun
```

### `clean` {#clean}

Supprime les clés que rien n'utilise dans le projet ; s'arrête lorsque cela ne peut pas être prouvé

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Répertoire des traductions, relatif au projet |
| `--include` | — | Expression régulière : ne considère que les clés correspondantes pour la suppression |
| `--exclude` | — | Expression régulière : ne supprime jamais les clés correspondantes |
| `--ignore` | — | Globs de fichiers source à ignorer, séparés par des virgules, relatifs au projet |
| `--dryRun` | `false` | Liste ce qui serait supprimé ; n'écrit rien |
| `--force` | `false` | Supprime les clés même si leur utilisation ne peut pas être prouvée pour toutes |

```bash
i18n-micro clean --dryRun
i18n-micro clean --exclude '^errors\.'
```

## Refactorisation {#refactoring}

### `text-to-i18n` {#text-to-i18n}

Remplace le texte codé en dur dans les templates Vue par des appels de traduction, et signale le texte codé en dur dans le code

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--translationFile` | `<translationDir>/<defaultLocale>.json` | Fichier dans lequel vont les nouvelles clés |
| `--path` | tout le projet | Fichier ou répertoire à traiter |
| `--context` | — | Préfixe des clés générées |
| `--ignore` | — | Globs de fichiers source à ignorer, séparés par des virgules, relatifs au projet |
| `--dryRun` | `false` | Montre ce qui changerait ; n'écrit rien |
| `--interactive` | `false` | Confirmer ou modifier chaque clé générée |

```bash
i18n-micro text-to-i18n --dryRun
i18n-micro text-to-i18n --path components --context ui
```

### `rename` {#rename}

Renomme une clé ou un namespace dans toutes les locales et dans les fichiers source

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Répertoire des traductions, relatif au projet |
| `--from` **\*** | — | Clé ou namespace actuel |
| `--to` **\*** | — | Nouvelle clé ou nouveau namespace |
| `--ignore` | — | Globs de fichiers source à ignorer, séparés par des virgules, relatifs au projet |
| `--dryRun` | `false` | Signale les modifications ; n'écrit rien |

**\*** obligatoire.

```bash
i18n-micro rename --from common.save --to actions.save
```

### `pseudo` {#pseudo}

Remplit une locale de pseudo-traductions pour détecter les problèmes de mise en page et de texte codé en dur

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Répertoire des traductions, relatif au projet |
| `--sourceLocale` | la locale par défaut | Locale à lire |
| `--targetLocale` **\*** | — | Locale à remplir |
| `--replace` | `false` | Écrase les valeurs existantes |

**\*** obligatoire.

### `format` {#format}

Réécrit les fichiers de locale avec des clés triées et une indentation uniforme

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Répertoire des traductions, relatif au projet |
| `--indent` | `2` | Espaces d'indentation |
| `--sortKeys` | `true` | Trie les clés ; utilisez --no-sortKeys pour conserver leur ordre |
| `--check` | `false` | Échoue si un fichier changerait ; n'écrit rien |

```bash
i18n-micro format --check
```

## Échange {#exchange}

### `export` {#export}

Exporte les fichiers de locale en PO ou CSV, avec le texte de la locale par défaut comme source

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Répertoire des traductions, relatif au projet |
| `--format` | `po` | Format de fichier : po, csv |
| `--dir` | `pots` pour po, `csv_exports` pour csv | Répertoire de sortie, relatif au projet |
| `--force` | `false` | Écrase les fichiers modifiés depuis le dernier export et jamais importés |

```bash
i18n-micro export --format csv
```

### `import` {#import}

Fusionne des fichiers PO ou CSV dans les fichiers de locale

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Répertoire des traductions, relatif au projet |
| `--format` | `po` | Format de fichier : po, csv |
| `--dir` | `pots` pour po, `csv_exports` pour csv | Répertoire d'entrée, relatif au projet |
| `--dryRun` | `false` | Signale ce qui serait importé ; n'écrit rien |

```bash
i18n-micro import --format csv --dryRun
```

### `sync-remote` {#sync-remote}

Récupère les traductions globales depuis l'endpoint HTTP défini dans .i18n-remote.json, ou les y envoie

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Répertoire des traductions, relatif au projet |
| `--pull` | `true` | Récupère depuis le distant |
| `--push` | `false` | Envoie vers le distant |
| `--force` | `false` | Lors d'un pull, prend la valeur distante ; lors d'un push, écrase le texte que seul le distant possède |
| `--dryRun` | `false` | Signale ce qu'un pull changerait ; n'écrit et n'envoie rien |

```bash
i18n-micro sync-remote --dryRun
i18n-micro sync-remote --no-pull --push
```

## Règles de lint {#lint-rules}

| Règle | Détecte | Corrigée par `--fix` |
| --- | --- | --- |
| `no-trailing-spaces` | Des espaces à la fin d'une valeur ou d'une ligne | oui |
| `no-multiple-spaces` | Deux espaces ou plus à la suite | oui |
| `no-empty-translation` | Une valeur vide ou blanche | non |

## Codes de sortie {#exit-codes}

| Code | Signification |
| --- | --- |
| `0` | Terminé, rien à signaler |
| `1` | Constats : `check`, `lint` ou `format --check` a trouvé quelque chose, `clean` ou `sync` n'a pas pu prouver qu'une suppression était sûre, `export` écraserait du travail non importé, `translate` a laissé des clés de côté, `import` ou `sync-remote` a rencontré un conflit, un push `sync-remote` supprimerait du texte distant. Un `--dryRun` de `clean`, `sync` ou d'un pull `sync-remote` signale ces cas et se termine avec `0` |
| `2` | Échec : mauvaise utilisation, projet illisible, erreur réseau ou de fichier |

## Fichiers de configuration {#configuration-files}

| Fichier | Utilisé par |
| --- | --- |
| `.i18n-lintrc.json` | `lint` : `enabledRules`, `disabledRules`, `customRegexRules` (`name`, `pattern`, `flags`, `description`, `replacement`) |
| `.i18n-remote.json` | `sync-remote` : `url`, `path`, `token`, `auth` (`username`, `password`). `type` peut être omis ; seul `custom` existe |
| `.i18n-glossary.json` | `translate --service ai` : `entries` composées de `source`, `target`, et facultativement `from`, `to` |

## Variables d'environnement {#environment-variables}

| Nom | Utilisée pour |
| --- | --- |
| `I18N_TRANSLATE_TOKEN` | Clé d'API de `translate`. Lue aussi depuis `.env` |
| `I18N_REMOTE_TOKEN` | Jeton Bearer de `sync-remote`. Lu aussi depuis `.env` |
| `AI_GATEWAY_API_KEY, OPENAI_API_KEY, ANTHROPIC_API_KEY` | Clé du service `ai`, lorsque `I18N_TRANSLATE_TOKEN` n'est pas définie |
| `DEFAULT_LOCALE` | Remplace `defaultLocale`, comme dans le module |
