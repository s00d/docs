# 🌍 Composant `<i18n-switcher>`

Le composant `<i18n-switcher>` dans `Nuxt I18n Micro` fournit une interface de menu déroulant conviviale pour basculer entre différentes locales dans votre application. Ce composant est hautement personnalisable, permettant une intégration transparente avec le design et la mise en page de votre application.

Les locales avec `disabled: true` sont **omises** du menu déroulant (elles restent disponibles via `$getLocales()` pour le SEO / les balises head). Seules les locales commutables reçoivent `NuxtLink` + `hreflang`.

Chaque partie est sans style par défaut : les props `custom*Style` acceptent des objets de style en ligne, et les slots ci-dessous remplacent entièrement le balisage lorsque le style ne suffit pas.

## 🛠️ Exemples d'utilisation

### Utilisation de base

```vue
<template>
  <i18n-switcher />
</template>
```

Cela affiche un sélecteur de locale avec le style et le comportement par défaut.

### Libellés et styles en ligne personnalisés

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Cet exemple démontre un sélecteur de locale entièrement personnalisé avec des libellés personnalisés et des styles en ligne.

## 🔌 Slots

Chaque partie visuelle du sélecteur peut être remplacée. Les slots sont listés avec le tableau des props ci-dessus ; chacun prend du contenu de template :

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Les slots dont le nom se termine par `-item`, `-link-content` ou commence par `before-item` reçoivent l'objet `locale` auquel ils appartiennent.

## 🎨 Aperçu des styles

Le composant `<i18n-switcher>` est livré avec des styles de base définis à l'aide de styles en ligne pouvant être facilement remplacés en passant des styles personnalisés via les props. Voici un bref aperçu du style par défaut :

- **Wrapper** : Contrôle le positionnement du menu déroulant.
- **Bouton** : Style le bouton d'ouverture du menu déroulant.
- **Menu déroulant** : Style la liste déroulante.
- **Éléments** : Style chaque élément de la liste.
- **Liens** : Style les liens à l'intérieur de chaque élément.
- **Icône** : Style l'icône indicateur du menu déroulant.

Vous pouvez personnaliser ces styles en passant des styles personnalisés via les props respectives, garantissant que le sélecteur de locale s'intègre parfaitement à l'interface utilisateur de votre application.
