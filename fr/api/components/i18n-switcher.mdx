# 🌍 Composant `<i18n-switcher>`

Le composant `<i18n-switcher>` de `Nuxt I18n Micro` fournit une interface déroulante conviviale pour changer de locale dans votre application. Ce composant est hautement personnalisable, permettant une intégration harmonieuse avec le design et la mise en page de votre application.

Les locales avec `disabled: true` sont **omises** de la liste déroulante (elles restent disponibles via `$getLocales()` pour les balises SEO / head). Seules les locales pouvant être activées reçoivent `NuxtLink` + `hreflang`.

Chaque partie est sans style par défaut : les props `custom*Style` prennent des objets de style en ligne, et les slots ci-dessous remplacent totalement le balisage lorsque le style seul ne suffit pas.

## 🛠️ Exemples d'utilisation

### Utilisation de base

```vue
<template>
  <i18n-switcher />
</template>
```

Cela affiche un sélecteur de locale avec un style et un comportement par défaut.

### Libellés personnalisés et styles en ligne

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Cet exemple présente un sélecteur de locale entièrement personnalisé avec des libellés et des styles en ligne.

## 🔌 Slots

Chaque partie visuelle du sélecteur peut être remplacée. Les slots sont listés avec le tableau des props ci-dessus ; chacun accepte un contenu de template :

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Les slots dont le nom se termine par `-item`, `-link-content` ou commence par `before-item` reçoivent l'objet `locale` auquel ils correspondent.

## 🎨 Vue d'ensemble des styles

Le composant `<i18n-switcher>` est fourni avec des styles de base définis via des styles en ligne qui peuvent être facilement surchargés en passant des styles personnalisés via les props. Voici un rapide aperçu du style par défaut :

- **Wrapper** : contrôle le positionnement du menu déroulant.
- **Bouton** : stylise le bouton de bascule du menu déroulant.
- **Dropdown** : stylise la liste déroulante.
- **Items** : stylise chaque élément de la liste.
- **Links** : stylise les liens à l'intérieur de chaque élément.
- **Icône** : stylise l'icône d'indicateur du menu déroulant.

Vous pouvez personnaliser ces styles en passant des styles personnalisés via les props correspondantes, ce qui garantit une intégration harmonieuse du sélecteur de locale dans l'interface utilisateur de votre application.
