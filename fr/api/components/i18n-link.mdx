# 🌍 Composant `<i18n-link>`

Le composant `<i18n-link>` de `Nuxt I18n Micro` est un composant de lien polyvalent qui localise automatiquement les routes en fonction de la locale actuelle. Il agit comme un wrapper autour du composant `<NuxtLink>` et offre des fonctionnalités supplémentaires telles que le style des liens actifs et le support des liens externes.

## ⚙️ Props

| `activeStyle` | `Partial<CSSStyleValue>` | — | Style en ligne appliqué lorsque le lien pointe sur la route courante. |

### Slots

| Slot | Liaisons | Description |
| --- | --- | --- |
| `default` | — | Contenu du lien. |

`to` accepte tout ce que `NuxtLink` accepte : un chemin, une route nommée ou un objet de route résolu. Une URL absolue est détectée et rendue sous forme d'un simple `<a target="_blank" rel="noopener noreferrer">` plutôt que d'être localisée.

## 🛠️ Exemples d'utilisation

### Utilisation de base

```vue
<i18n-link to="/about">About Us</i18n-link>
```

Cet exemple crée un lien vers la page `/about`, localisé selon la locale courante.

### Style de lien actif avec styles en ligne

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

Le lien aura un texte en gras lorsque l'utilisateur est sur la page `/about`, ce qui vous permet de styliser le lien actif directement avec des styles en ligne.

### Gestion des liens externes

Le composant détecte automatiquement les liens externes et ajoute les attributs de sécurité nécessaires.

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

Ce lien ouvrira `https://example.com` dans un nouvel onglet avec `rel="noopener noreferrer"` appliqué.

## 🎨 Styles

Le composant utilise désormais des styles en ligne pour l'état actif plutôt qu'une classe. Vous pouvez personnaliser ces styles via la prop `activeStyle`.

### Styles actifs par défaut

- **Épaisseur de la police** : `bold`
- **Couleur** : hérite de la couleur par défaut du navigateur (si aucune `color` n'est spécifiée dans `activeStyle`).

Vous pouvez surcharger ces valeurs en fournissant des styles personnalisés via la prop `activeStyle`.

### Styles actifs personnalisés

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

Dans cet exemple, le lien est en gras et vert lorsqu'il est actif.

## 🚀 Fonctionnalités supplémentaires

### Slot pour un contenu personnalisé

Vous pouvez passer du contenu personnalisé à l'intérieur du lien via les slots, ce qui rend le composant flexible pour différents cas d'usage.

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### Améliorations d'accessibilité

Le composant prend en charge `aria-label` et d'autres attributs d'accessibilité pour garantir une expérience plus accessible.

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
