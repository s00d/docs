# 🌍 Composant `<i18n-t>`

Le composant `<i18n-t>` de `Nuxt I18n Micro` est un composant de traduction flexible qui prend en charge l'insertion de contenu dynamique via des slots. Il vous permet d'interpoler des traductions avec des composants Vue personnalisés ou du contenu HTML, autorisant des scénarios de localisation avancés.

| `hideIfEmpty` | `boolean` | `false` | N'affiche rien lorsque la traduction se résout à une chaîne vide. |

| `number` | `number \| string` | — | Formate la valeur avec `$tn` et la passe à la traduction sous la forme `\{number\}`. |
| `date` | `Date \| string \| number` | — | Formate la valeur avec `$td` et la passe à la traduction sous la forme `\{date\}`. |
| `relativeDate` | `Date \| string \| number` | — | Formate la valeur avec `$tdr` et la passe à la traduction sous la forme `\{relativeDate\}`. |

{/* /generated:component:i18n-t */}

Une seule des props `plural`, `number`, `date` et `relativeDate` s'applique à la fois ; lorsque plusieurs sont définies, c'est la première de cette liste qui l'emporte.

### Exemples par prop

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

## 🛠️ Exemples d'utilisation

### Utilisation de base

```vue
<i18n-t keypath="feedback.text" />
```

Cela rend la traduction pour `feedback.text` à l'intérieur d'une balise `<span>`.

### Utiliser des slots pour du contenu dynamique

Le composant `<i18n-t>` prend en charge l'utilisation de slots pour insérer dynamiquement des composants Vue ou d'autres contenus à des endroits précis de la traduction.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

Dans cet exemple, le placeholder `\{link\}` dans la chaîne de traduction `feedback.text` est remplacé par le composant `<nuxt-link>`, qui contient lui-même un autre composant de traduction.

### Pluralisation

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

Cela applique automatiquement des règles de pluralisation en fonction de la valeur `itemCount`.

## 🚀 Fonctionnalités supplémentaires

### Slot par défaut

Si aucun slot spécifique n'est fourni, la traduction peut être personnalisée via le slot par défaut, qui fournit la chaîne traduite complète :

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### Rendu conditionnel

N'affichez rien si la chaîne de traduction est vide grâce à la prop `hideIfEmpty`.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### Règle de pluralisation personnalisée

Utilisez une fonction personnalisée pour gérer la pluralisation.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### Exemple avancé avec des slots

Utilisez les slots pour personnaliser la façon dont le contenu de la traduction est rendu.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
