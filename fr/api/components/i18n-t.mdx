# 🌍 Composant `<i18n-t>`

Le composant `<i18n-t>` dans `Nuxt I18n Micro` est un composant de traduction flexible qui prend en charge l'insertion dynamique de contenu via des slots. Il vous permet d'interpoler les traductions avec des composants Vue personnalisés ou du contenu HTML, activant des scénarios de localisation avancés.

| `plural` | `number \| string` | — | Nombre sélectionnant la forme plurielle. Définissez-le pour utiliser `$tc` au lieu de `$t`. |
| `tag` | `string` | `'span'` | Élément à rendre. |
| `params` | `Record<string, string \| number \| boolean>` | `() => (\{\})` | Valeurs d'interpolation substituées dans la traduction. |
| `defaultValue` | `string` | `''` | Rendu à la place du composant lorsque `hideIfEmpty` supprime une traduction vide. |
| `html` | `boolean` | `false` | Rendre la traduction en HTML plutôt qu'en texte. Uniquement pour du contenu que vous contrôlez. |
| `hideIfEmpty` | `boolean` | `false` | Ne rien rendre lorsque la traduction se résout en une chaîne vide. |
| `customPluralRule` | `PluralFunc` | `null` | Règle de pluralisation pour cet élément uniquement, remplaçant celle configurée. |
| `number` | `number \| string` | — | Formate la valeur avec `$tn` et la passe à la traduction en tant que `\{number\}`. |
| `date` | `Date \| string \| number` | — | Formate la valeur avec `$td` et la passe à la traduction en tant que `\{date\}`. |
| `relativeDate` | `Date \| string \| number` | — | Formate la valeur avec `$tdr` et la passe à la traduction en tant que `\{relativeDate\}`. |

**\*** obligatoire.

{/* /generated:component:i18n-t */}

Une seule des props `plural`, `number`, `date` et `relativeDate` s'applique à la fois ; lorsque plusieurs sont définies, la première dans cette liste l'emporte.

### Exemples par prop

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

}

## 🛠️ Exemples d'utilisation

### Utilisation de base

```vue
<i18n-t keypath="feedback.text" />
```

Cela rend la traduction pour `feedback.text` dans une balise `<span>`.

### Utiliser des slots pour du contenu dynamique

Le composant `<i18n-t>` prend en charge l'utilisation de slots pour insérer dynamiquement des composants Vue ou d'autres contenus dans des parties spécifiques de la traduction.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

Dans cet exemple, l'espace réservé `\{link\}` dans la chaîne de traduction `feedback.text` est remplacé par le composant `<nuxt-link>`, qui contient lui-même un autre composant de traduction.

### Pluralisation

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

Cela applique automatiquement les règles de pluralisation selon la valeur de `itemCount`.

## 🚀 Fonctionnalités supplémentaires

### Slot par défaut

Si aucun slot spécifique n'est fourni, la traduction peut être personnalisée via le slot par défaut, qui fournit toute la chaîne traduite :

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### Rendu conditionnel

Ne rien rendre si la chaîne de traduction est vide en utilisant la prop `hideIfEmpty`.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### Règle de pluralisation personnalisée

Utilisez une fonction personnalisée pour gérer la pluralisation.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### Exemple avancé avec des slots

Utilisez les slots pour personnaliser la façon dont le contenu de traduction est rendu.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
