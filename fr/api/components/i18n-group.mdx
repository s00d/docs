# 🌍 Composant `<i18n-group>`

Le composant `<i18n-group>` de Nuxt I18n Micro offre un moyen pratique de regrouper les traductions sous un préfixe commun, réduisant les répétitions et améliorant l'organisation du code.

## ⚙️ Props

{/* generated:component:i18n-group — do not edit; run `pnpm run docs:generate` */}

| Prop | Type | Défaut | Description |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | Préfixe de clé auquel toutes les recherches à l'intérieur du slot sont résolues. |
| `groupClass` | `string` | `''` | Classe supplémentaire sur l'élément conteneur. |

**\*** requis.

### Slots

| Slot | Liaisons | Description |
| --- | --- | --- |
| `default` | `prefix`, `t` | Reçoit `prefix` et une fonction `t` cadrée dessus. |

{/* /generated:component:i18n-group */}

## 🎯 Slots

Le slot par défaut reçoit `prefix` et une fonction `t` cadrée dessus, si bien que les clés à l'intérieur sont écrites relativement au préfixe :

```vue
<i18n-group prefix="checkout">
  <template #default="{ t }">
    <h2>{{ t('title') }}</h2>
    <p>{{ t('summary', { count: 3 }) }}</p>
  </template>
</i18n-group>
```

## 🛠️ Exemples d'utilisation

### Utilisation de base

```vue
<template>
  <i18n-group prefix="product.details">
    <template #default="{ t }">
      <h1>{{ t('title') }}</h1>
      <p>{{ t('description') }}</p>
      <div class="price">{{ t('price', { value: 99.99 }) }}</div>
    </template>
  </i18n-group>
</template>
```

Fichier de traduction :

```json
{
  "product": {
    "details": {
      "title": "Premium Product",
      "description": "This is a premium product",
      "price": "Price: ${value}"
    }
  }
}
```

### Avec une classe personnalisée

```vue
<template>
  <i18n-group prefix="user.profile" group-class="profile-section">
    <template #default="{ t }">
      <div class="user-info">
        <h2>{{ t('title') }}</h2>
        <p>{{ t('bio') }}</p>
        <div class="stats">
          <span>{{ t('stats.followers') }}</span>
          <span>{{ t('stats.following') }}</span>
        </div>
      </div>
    </template>
  </i18n-group>
</template>
```

Fichier de traduction :

```json
{
  "user": {
    "profile": {
      "title": "User Profile",
      "bio": "User biography goes here",
      "stats": {
        "followers": "Followers: {count}",
        "following": "Following: {count}"
      }
    }
  }
}
```

### Avec du contenu dynamique

```vue
<template>
  <i18n-group prefix="blog.post">
    <template #default="{ t }">
      <article>
        <h1>{{ t('title') }}</h1>
        <div class="meta">
          {{ t('meta.author', { name: author }) }} |
          {{ t('meta.date', { date: publishDate }) }}
        </div>
        <div v-for="(section, index) in sections" :key="index">
          <h2>{{ t(`sections.${index}.title`) }}</h2>
          <p>{{ t(`sections.${index}.content`) }}</p>
        </div>
      </article>
    </template>
  </i18n-group>
</template>

<script setup>
const author = 'John Doe'
const publishDate = '2024-01-01'
const sections = ['intro', 'main', 'conclusion']
</script>
```

## 🎨 Styles

Le composant encapsule son contenu dans une div portant la classe `i18n-group` ainsi que toute classe supplémentaire spécifiée dans la prop `groupClass` :

```css
.i18n-group {
  /* Your base styles */
}

.profile-section {
  /* Additional styles for profile sections */
}
```

## 🚀 Bonnes pratiques

1. **Préfixes cohérents** : utilisez des préfixes cohérents et logiques qui reflètent la structure de votre application.

```vue
<i18n-group prefix="features.pricing">
<i18n-group prefix="features.security">
```

2. **Organisation modulaire** : regroupez les traductions liées sous des préfixes explicites.

```vue
<i18n-group prefix="checkout.payment">
<i18n-group prefix="checkout.shipping">
```

3. **Composants réutilisables** : créez des composants réutilisables avec leurs propres groupes de traductions.

```vue
<!-- UserProfile.vue -->
<i18n-group prefix="user.profile">

<!-- UserSettings.vue -->
<i18n-group prefix="user.settings">
```

4. **Groupes imbriqués** : évitez d'imbriquer trop profondément les groupes pour préserver la clarté.

```vue
<!-- Good -->
<i18n-group prefix="shop.product">

<!-- Avoid -->
<i18n-group prefix="shop.category.product.details.specs">
```
