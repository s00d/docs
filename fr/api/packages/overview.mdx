# APIs des paquets

`nuxt-i18n-micro` est construit à partir d'un ensemble de petits paquets, dont la plupart peuvent être utilisés seuls — `@i18n-micro/vue` dans une simple application Vue, `@i18n-micro/core` n'importe où.

Chaque page ci-dessous est générée à partir du snapshot d'API que [`pnpm run api:surface`](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/maintenance-commands.md#api-surface) vérifie face aux sources TypeScript, de sorte qu'un export ne peut pas disparaître sans que cette référence ne change ou que la CI n'échoue.
