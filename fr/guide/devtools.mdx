Avec `nuxt dev`, le module ajoute deux outils de débogage : un onglet **i18n Micro** dans Nuxt DevTools pour parcourir et modifier les fichiers de traduction, et un inspecteur Vue DevTools pour la locale active et les dictionnaires chargés. Les deux n'existent qu'en développement et n'ajoutent rien aux builds de production. L'onglet Nuxt nécessite seulement que Nuxt DevTools soit activé ; l'inspecteur Vue nécessite en plus l'extension de navigateur Vue DevTools.

## Onglet Nuxt DevTools {#nuxt-devtools-tab}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  devtools: { enabled: true }, // the tab is registered only when DevTools are on
})
```

Ouvrez Nuxt DevTools (`Shift + Alt + D`) et choisissez **i18n Micro**. L'onglet affiche :

- chaque fichier JSON sous `locales/` (racine et `pages/`) de chaque layer, ainsi que les fichiers racine de `additionalTranslationDirs` ;
- un éditeur par fichier ; **Save** réécrit le fichier sur le disque et le serveur de développement recharge les traductions ;
- l'**export** / l'**import** d'un fichier au format JSON, et des **statistiques** avec le nombre de clés et la couverture des traductions ;
- une vue de configuration des options résolues du module ;
- **Translate**, qui remplit les clés manquantes avec un moteur de traduction automatique que vous configurez dans les paramètres de l'onglet.

L'enregistrement n'écrit que des fichiers `.json` existants à l'intérieur de vos répertoires de traduction. Lorsqu'un fichier existe dans plusieurs layers, c'est la copie du projet qui est écrite.

## Inspecteur Vue DevTools {#vue-devtools-inspector}

Avec l'extension de navigateur Vue DevTools, le module enregistre un inspecteur i18n (locale courante, chunk de route, clés chargées) et une timeline avec les changements de locale, les chargements de chunks et les clés manquantes.

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    debug: true, // also log every $t / $ts / $tc call on the timeline
    // vueDevtools: false, // turn the inspector off, keep the Nuxt tab
  },
})
```

[`vueDevtools`](/fr/api/module-options) vaut `true` par défaut. `debug: true` est très verbeux ; réservez-le à de courtes sessions.

## En dehors de Nuxt {#outside-nuxt}

La même interface est publiée sous le nom [`@i18n-micro/devtools-ui`](/fr/integrations/devtools-ui-package) pour les applications Vite construites avec les packages pour frameworks ; consultez cette page pour la mise en place.
