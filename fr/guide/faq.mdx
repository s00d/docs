Des réponses courtes aux problèmes les plus fréquents, pour les questions auxquelles les pages thématiques ne répondent pas directement. Chaque réponse renvoie à la page qui traite le sujet. Si votre question n’y figure pas, faites une recherche dans la documentation ou ouvrez une [issue](https://github.com/s00d/nuxt-i18n-micro/issues).

## Traductions {#translations}

### `$t` échoue dans un plugin ou une fonction utilitaire {#$t-fails-in-a-plugin-or-a-utility-function}

Les composables ont besoin du contexte Nuxt. En dehors de `setup`, récupérez le helper depuis l’application, ou exécutez-le dans son contexte après un `await` :

```ts
const nuxtApp = useNuxtApp()
const title = nuxtApp.$t('errors.unknown')
await nuxtApp.runWithContext(() => nuxtApp.$t('errors.unknown'))
```

Dans les services qui n’ont pas du tout accès à l’application, transmettez les clés et traduisez-les dans le composant.

### Une clé s’affiche en texte brut sur une seule page {#a-key-shows-as-raw-text-on-one-page-only}

La clé se trouve dans le fichier d’une autre page. Une page ne voit que le fichier racine et son propre fichier `locales/pages/<route-name>/` ; déplacez les clés partagées dans le fichier racine. Voir [Fichiers de traduction](/fr/guide/translations).

### Les clés clignotent pendant une transition de page {#keys-flash-while-a-page-transition-runs}

Cela ne devrait pas arriver : les clés de la page quittée restent résolues jusqu’à la fin de la transition. Si elles clignotent quand même, la clé ne se trouve que dans un fichier de page qui n’appartient à aucune des deux pages (par exemple dans un layout) ; déplacez-la dans le fichier racine.

### Des traductions manquent pendant le SSR sur Vercel, Netlify ou Edge {#translations-are-missing-during-ssr-on-vercel-netlify-or-edge}

La fonction serveur ne peut pas y lire `public/`, les payloads sont donc intégrés au bundle serveur. C’est le comportement par défaut ; vérifiez que `translationPayloads.serverAssets` n’est pas désactivé. Si le journal indique `public/ is not deployed next to the server`, définissez `nitro.serveStatic: false`. Voir [Déploiement](/fr/guide/deployment).

### Comment insérer un lien dans une phrase traduite ? {#how-do-i-put-a-link-inside-a-translated-sentence}

Utilisez `<i18n-t>` : chaque slot nommé remplit le `{placeholder}` du même nom.

```vue
<!-- "share": "Share your {link} with friends" -->
<i18n-t keypath="share">
  <template #link>
    <i18n-link :to="{ name: 'referral' }">{{ $t('referralLink') }}</i18n-link>
  </template>
</i18n-t>
```

Voir [`<i18n-t>`](/fr/components/i18n-t). Les messages liés et les modificateurs de vue-i18n ne sont pas pris en charge ; composez dans le template comme ci-dessus.

## Locales et URL {#locales-and-urls}

### `/en/about` renvoie une 404 {#/en/about-is-a-404}

Avec la stratégie par défaut `prefix_except_default`, la locale par défaut n’a pas de préfixe : `/about` est en anglais. Utilisez `prefix` ou `prefix_and_default` si vous voulez `/en/...`. Voir [Stratégies de routage](/fr/guide/strategy).

### Les visiteurs ne sont pas redirigés sur les liens profonds {#visitors-are-not-redirected-on-deep-links}

Par défaut, seule `/` suit la langue du navigateur ou le cookie, afin que les liens partagés conservent leur langue. Définissez `autoDetectPath: 'no_prefix'` ou `'*'`. Voir [Détection de la locale](/fr/guide/locale-detection#autodetectpath).

### La langue choisie est oubliée après un rechargement {#the-chosen-language-is-forgotten-after-a-reload}

Le cookie de locale est désactivé pour les stratégies à préfixe. Définissez `localeCookie: 'user-locale'`. Voir [Détection de la locale](/fr/guide/locale-detection#the-cookie).

### Puis-je changer de locale sans changer l’URL ? {#can-i-switch-locale-without-changing-the-url?}

Uniquement avec `strategy: 'no_prefix'`, où `$switchLocale('de')` recharge le dictionnaire sur le même chemin. Avec les stratégies à préfixe, la locale fait partie de l’URL, donc changer de locale déclenche une navigation. Pour un lien plutôt qu’un appel, utilisez `$switchLocalePath('de')`.

### La page remonte en haut quand je change de locale {#the-page-scrolls-to-the-top-when-i-switch-locale}

C’est le `scrollBehavior` de Nuxt, appliqué à toute navigation. Définissez `definePageMeta({ scrollToTop: false })` et restaurez la position vous-même. Le fichier [`SwitchLocalePreserve.vue`](https://github.com/s00d/nuxt-i18n-micro/blob/main/playground/components/SwitchLocalePreserve.vue) du playground est un wrapper prêt à copier ([page de démo](https://github.com/s00d/nuxt-i18n-micro/blob/main/playground/pages/scroll-test.vue)).

## Build et intégrations {#build-and-integrations}

### `nuxt-seo:defaults depends on nuxt-site-config:i18n but they are not registered` {#nuxt-seodefaults-depends-on-nuxt-site-configi18n-but-they-are-not-registered}

Une ancienne version de `nuxt-site-config` ne connaît que `@nuxtjs/i18n`. Mettez à niveau `@nuxtjs/seo` vers la version 3 ou plus récente et placez `nuxt-i18n-micro` avant lui dans `modules`. Voir [SEO](/fr/guide/seo).

### Erreur de build concernant `@unhead/vue` sur Cloudflare {#build-error-about-@unhead/vue-on-cloudflare}

Installez `@unhead/vue` dans l’application pour que l’étape de prerender le trouve. Le module lui-même n’a pas besoin de `nodejs_compat` : ajoutez `compatibility_flags = ["nodejs_compat"]` à `wrangler.toml` uniquement si un autre élément de l’application en a besoin.
