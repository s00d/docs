---
title: "useI18n"
description: "useI18n renvoie les helpers d'exécution (`$t`, `$tc`, `$localePath`, …) sous forme d'objet simple, avec et sans le préfixe `$`."
---

`useI18n()` renvoie les helpers d'exécution du module sous forme d'objet simple. Utilisez-le dans `<script setup>`, les composables et les plugins au lieu de passer par `useNuxtApp()`. Chaque helper est disponible sous son nom avec `$` et sous un alias sans préfixe : `t` et `$t` sont la même fonction.

## Signature {#signature}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Tous les helpers d'exécution, sous forme d'objet simple.

Les mêmes fonctions que le plugin injecte en tant que `$t`, `$tc`, etc., disponibles à la fois
sous le nom préfixé par le dollar et sous un alias sans préfixe — ainsi `const { t } = useI18n()` et
`const { $t } = useI18n()` fonctionnent tous les deux.

**Renvoie** — les helpers décrits dans la [référence des méthodes](/fr/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

L'objet renvoyé contient tous les helpers de [`PluginsInjections`](/fr/api/methods). Chacun d'eux est documenté sur la page [Helpers](/fr/api/methods).

## Exemple {#example}

```vue
<script setup lang="ts">
const { t, tc, localePath, switchLocale, getLocale } = useI18n()

const title = computed(() => t('page.title'))
</script>

<template>
  <h1>{{ title }}</h1>
  <p>{{ tc('items', 3) }}</p>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
  <button @click="switchLocale(getLocale() === 'en' ? 'de' : 'en')">{{ t('nav.switch') }}</button>
</template>
```

## Absent du type {#not-in-the-type}

`$defineI18nRoute` n'est typé que sur `useNuxtApp()` :

```ts
const { $defineI18nRoute } = useNuxtApp()
```
