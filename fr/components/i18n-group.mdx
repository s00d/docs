---
title: "<i18n-group>"
description: "Le composant <i18n-group> fournit à son slot une fonction t limitée à un préfixe de clé."
---

`<i18n-group>` limite un bloc de balisage à un préfixe de clé. Utilisez-le lorsque de nombreuses clés d’une section partagent un préfixe et que vous ne voulez pas le répéter. Le slot par défaut reçoit un `t` qui ajoute le préfixe devant la clé.

## Props et slot {#props-and-slot}

| Prop | Type | Valeur par défaut | Description |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | Préfixe de clé par rapport auquel chaque recherche dans le slot est résolue. |
| `groupClass` | `string` | `''` | Classe supplémentaire sur l’élément conteneur. |

**\*** obligatoire.

### Slots {#slots}

| Slot | Liaisons | Description |
| --- | --- | --- |
| `default` | `prefix`, `t` | Reçoit `prefix` et une fonction `t` limitée à ce préfixe. |

## Comportement {#behaviour}

- Affiche `<div class="i18n-group {groupClass}">` autour du slot.
- `t(key, params)` équivaut à `$t(prefix + '.' + key, params)` pour la route courante.
- Seul le `t` du slot est limité au préfixe : `$t` et les `<i18n-t>` imbriqués dans le groupe prennent toujours des clés complètes.

## Exemple {#example}

```json
{
  "checkout": { "title": "Checkout", "items": "Items: {count}" }
}
```

```vue
<template>
  <i18n-group prefix="checkout" group-class="checkout">
    <template #default="{ t }">
      <h2>{{ t('title') }}</h2>
      <p>{{ t('items', { count: 3 }) }}</p>
    </template>
  </i18n-group>
</template>
```
