---
title: "<i18n-link>"
description: "Le composant <i18n-link> est un NuxtLink vers la route dans la locale active ; les URL externes s’ouvrent dans un nouvel onglet."
---

`<i18n-link>` affiche un `NuxtLink` vers `to` dans la locale active. Utilisez-le à la place de `<NuxtLink :to="$localePath(...)">` dans les templates. Une URL externe devient un simple `<a target="_blank" rel="noopener noreferrer">`.

## Props {#props}

| Prop | Type | Valeur par défaut | Description |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | Route cible. Localisée automatiquement ; une URL externe est transmise telle quelle. |
| `activeStyle` | `CSSProperties` | — | Style en ligne appliqué tant que le lien pointe vers la route courante. |

**\*** obligatoire.

### Slots {#slots}

| Slot | Liaisons | Description |
| --- | --- | --- |
| `default` | — | Contenu du lien. |

## Comportement {#behaviour}

- `to` passe par [`$localePath`](/fr/api/methods#$localepath) : un chemin, une route nommée ou un objet route, avec les chemins de locale personnalisés appliqués.
- Externe : une chaîne commençant par `http://`, `https://` ou `//`, un domaine nu (`example.com`), ou un lien `tel:` / `mailto:`. Un domaine nu reçoit `https://`, et toute chaîne sans barre oblique contenant un point est considérée comme tel : écrivez un fichier local sous la forme `/report.pdf`, et non `report.pdf`.
- Actif : lorsque le `route.path` courant est égal au chemin localisé (query et hash ignorés), `activeStyle` est appliqué. Il n’y a pas de classe active ni de style actif par défaut.
- Les autres attributs (`class`, `aria-*`) sont transmis au lien.

## Exemple {#example}

```vue
<template>
  <i18n-link to="/about" :active-style="{ fontWeight: 'bold' }">{{ $t('nav.about') }}</i18n-link>
  <i18n-link :to="{ name: 'blog-slug', params: { slug: 'hello' } }">{{ $t('nav.post') }}</i18n-link>
  <i18n-link to="https://github.com/s00d/nuxt-i18n-micro">GitHub</i18n-link>
</template>
```
