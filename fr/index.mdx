---
title: "Nuxt I18n Micro"
description: "Une i18n légère et rapide pour Nuxt : traductions JSON par page, routes localisées générées au build, balises SEO prêtes à l’emploi."
---

Nuxt I18n Micro est un module i18n léger et performant pour Nuxt 3 et 4, conçu pour les grands projets. Il réduit les temps de build, la consommation mémoire et la taille du bundle par rapport aux solutions i18n traditionnelles comme `@nuxtjs/i18n`.

Les routes localisées sont générées au build par `@i18n-micro/route-strategy` et résolues à l’exécution par `@i18n-micro/path-strategy`, de sorte que les liens, le sélecteur de langue, `hreflang` et les redirections concordent tous avec le routeur. Les traductions sont uniquement en JSON, réparties entre des fichiers racine partagés et des fichiers par page que le serveur de développement crée pour vous, avec le HMR intégré.

<CodeGroup>

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>
