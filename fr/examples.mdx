# 📚 Exemples et utilisation de Nuxt I18n Micro

Cette section propose divers exemples démontrant comment utiliser `Nuxt I18n Micro` dans votre application Nuxt.js. Vous verrez comment changer de locale, utiliser les composants `<i18n-link>`, `<i18n-switcher>` et `<i18n-t>`, et gérer dynamiquement les clés de traduction.

## 🛠️ Configuration de base

Voici une configuration de base pour démarrer avec `Nuxt I18n Micro` :

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Changement de locale

### Changer de locale par programmation

Cet exemple montre comment changer de locale par programmation en utilisant des boutons :

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Exemple JSON pour le changement de locale

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### Utiliser le composant `<i18n-switcher>`

Le composant `<i18n-switcher>` fournit un menu déroulant pour changer de locale avec des libellés personnalisables :

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 📝 Rendu de clés dynamiques à partir de fichiers de traduction

Dans certains cas, vous pouvez vouloir itérer sur des clés dynamiques stockées dans vos fichiers de traduction et afficher leurs valeurs de manière conditionnelle. L'exemple ci-dessous montre comment y parvenir avec `Nuxt I18n Micro`.

### Exemple : rendu de clés dynamiques

Cet exemple récupère un tableau de clés depuis un chemin de traduction spécifique (dans ce cas, `dynamic`) et itère dessus. L'existence de chaque clé est vérifiée à l'aide de `$has` avant d'afficher sa valeur avec `$t`.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Exemple de fichier de traduction (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Exemple : rendu de clés dynamiques à partir d'un objet

Dans cet exemple, nous manipulons un objet stocké dans votre fichier de traduction. Nous récupérons et itérons sur les clés de l'objet, en affichant dynamiquement à la fois les noms de clés et leurs valeurs associées.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Exemple de fichier de traduction (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 Utiliser `<i18n-t>` pour les traductions avec slots et interpolation

Le composant `<i18n-t>` est utile pour rendre des traductions avec du contenu dynamique et des balises HTML :

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### Exemple JSON pour `<i18n-t>`

```json
{
  "greeting": "Welcome to the page"
}
```

### Avec interpolation

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### Exemple JSON pour l'interpolation

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 Utiliser `$tc` pour la pluralisation

La fonction `$tc` dans `Nuxt I18n Micro` gère la pluralisation en fonction du nombre et des paramètres de locale. Cela est utile pour ajuster dynamiquement des messages impliquant des nombres, comme des éléments, des notifications ou d'autres entités qui peuvent varier en quantité.

### Exemple : utiliser `$tc` pour la pluralisation

Dans l'exemple suivant, nous affichons un message indiquant le nombre de pommes en utilisant `$tc`. La clé de traduction gère plusieurs formes plurielles en fonction du nombre fourni.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### Exemple JSON pour la pluralisation

Voici comment définir la traduction dans votre fichier JSON pour gérer différentes formes plurielles :

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Explication

- **`$tc('apples', 0)`** : Renvoie la première forme, utilisée lorsque le nombre est zéro (`"no apples"`).
- **`$tc('apples', 1)`** : Renvoie la deuxième forme, utilisée lorsque le nombre est un (`"one apple"`).
- **`$tc('apples', 10)`** : Renvoie la troisième forme avec la valeur du nombre, utilisée lorsque le nombre est deux ou plus (`"10 apples"`).

### Exemple supplémentaire avec une pluralisation plus complexe

Si votre application doit gérer des règles de pluralisation plus complexes (par exemple, des cas spécifiques pour zéro, un, deux, quelques-uns, beaucoup, autre), vous pouvez étendre les chaînes de traduction en conséquence :

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`** : Peut être configuré pour renvoyer `"two apples"`.
- **`$tc('apples', 3)`** : Peut renvoyer `"a few apples"`, selon les règles définies pour le nombre.

## 🌐 Utiliser `$tn` pour le formatage des nombres

La fonction `$tn` formate les nombres selon la locale actuelle à l'aide de l'API `Intl.NumberFormat`. Cela est utile pour afficher des nombres d'une manière qui correspond aux paramètres régionaux de l'utilisateur, comme les devises, les pourcentages ou d'autres formats numériques.

### Exemple : utiliser `$tn` pour le formatage des nombres

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ Utiliser `$td` pour le formatage des dates et heures

La fonction `$td` formate les dates et les heures selon la locale actuelle à l'aide de l'API `Intl.DateTimeFormat`. Cela est utile pour afficher les dates et les heures dans des formats familiers à l'utilisateur en fonction de ses paramètres de locale.

### Exemple : utiliser `$td` pour le formatage des dates et heures

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ Utiliser `$tdr` pour le formatage de dates relatives

La fonction `$tdr` formate les dates comme des temps relatifs (par exemple, « il y a 5 minutes », « il y a 2 jours ») selon la locale actuelle à l'aide de l'API `Intl.RelativeTimeFormat`. Cela est utile pour afficher les différences de temps par rapport à la date et à l'heure actuelles.

### Exemple : utiliser `$tdr` pour le formatage de dates relatives

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
