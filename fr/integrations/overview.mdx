# Intégrations

Les paquets `@i18n-micro` sont des versions légères, spécifiques à un framework, de Nuxt I18n Micro, conçues pour l'intégration dans divers frameworks et environnements. Ces paquets fournissent les fonctionnalités d'internationalisation de base avec une empreinte minimale, en se concentrant sur les fonctionnalités essentielles de traduction et les composants de base.

## Vue d'ensemble

Ces paquets d'intégration sont des **versions miniatures** du module complet Nuxt I18n Micro, ne contenant que les fonctionnalités essentielles pour l'internationalisation :

- **Fonctionnalités de traduction de base** - Méthodes de traduction de base, pluralisation et formatage
- **Composants essentiels** - Un petit ensemble de composants UI pour les tâches i18n courantes
- **Modèle d'adaptateur de routeur** - Intégration flexible du routage via abstraction d'adaptateur
- **Prise en charge de TypeScript** - Définitions de types complètes pour un développement typé

Contrairement au module Nuxt complet, ces paquets :

- N'incluent pas de logique de routage spécifique au framework
- Vous demandent d'implémenter un adaptateur de routeur pour les fonctionnalités de routage
- Se concentrent sur la fonctionnalité de traduction plutôt que sur l'intégration au framework
- Sont conçus pour être légers et indépendants du framework lorsque possible

## Composants de base

Tous les paquets de framework incluent les composants essentiels suivants :

### `<I18nT>`

Un composant de traduction qui rend du texte traduit avec la prise en charge de :

- **Interpolation de paramètres** - Remplacer les espaces réservés par des valeurs dynamiques
- **Pluralisation** - Sélection automatique de la forme plurielle selon le nombre
- **Formatage des nombres** - Formater les nombres selon la locale
- **Formatage des dates** - Formater les dates et les temps relatifs
- **Rendu HTML** - Rendu optionnel de contenu HTML
- **Valeurs par défaut** - Texte de repli lorsque la traduction est manquante

**Exemple :**

```vue
<!-- Vue -->
<I18nT keypath="greeting" :params="{ name: 'World' }" />
```

```tsx
// React
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```tsx
// Solid
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```astro
<!-- Astro -->
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

### `<I18nLink>`

Un composant de lien localisé qui gère automatiquement les préfixes de locale dans les URLs. Fonctionnalités :

- **Localisation automatique des chemins** - Ajoute/supprime les préfixes de locale selon la stratégie de routage
- **Détection de l'état actif** - Met en évidence la route actuelle
- **Prise en charge des liens externes** - Détecte et gère automatiquement les URLs externes
- **Intégration au routeur** - Utilise le composant de lien de l'adaptateur de routeur lorsqu'il est disponible
- **Style personnalisé** - Prend en charge les états actif et survol

**Exemple :**

```vue
<!-- Vue -->
<I18nLink to="/about" active-class="active">
  About Us
</I18nLink>
```

```tsx
// React
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```tsx
// Solid
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```astro
<!-- Astro -->
<I18nLink href="/about" class="nav-link">
  About Us
</I18nLink>
```

### `<I18nSwitcher>`

Un composant de sélecteur de langue qui fournit une interface de menu déroulant ou de liste pour changer de locale. Fonctionnalités :

- **Liste automatique des locales** - Génère les options depuis les locales configurées
- **Mise en évidence de la locale actuelle** - Indique visuellement la langue active
- **Libellés personnalisés** - Prise en charge des noms d'affichage personnalisés par locale
- **Intégration au routeur** - Navigue automatiquement vers les chemins localisés
- **Accessibilité** - Attributs ARIA appropriés et navigation au clavier

**Exemple :**

```vue
<!-- Vue -->
<I18nSwitcher />
```

```tsx
// React
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```tsx
// Solid
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```astro
<!-- Astro -->
<I18nSwitcher />
```

### `<I18nGroup>`

Un composant pour regrouper les traductions avec un préfixe commun, utile pour organiser les traductions par page ou fonctionnalité. Fonctionnalités :

- **Portée par préfixe** - Ajoute automatiquement le préfixe à toutes les clés de traduction dans le groupe
- **Groupes imbriqués** - Prise en charge des groupes de traduction imbriqués
- **Organisation propre** - Aide à maintenir des structures de traduction organisées

**Exemple :**

```vue
<!-- Vue -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

```tsx
// React
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```tsx
// Solid
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```astro
<!-- Astro -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

## Options partagées de `createI18n` \{#create-i18n-options\}

Chaque paquet de framework est créé de la même manière — seul le type des options est nommé d'après le framework (`ReactI18nOptions`, `SolidI18nOptions`, etc.). Les options elles-mêmes sont identiques :

| Propriété        | Type                                                       | Obligatoire | Valeur par défaut | Description                                    |
| ---------------- | ---------------------------------------------------------- | -------- | ---------------- | ---------------------------------------------- |
| `locale`         | `string`                                                   | ✅       | -                | Code de locale actuel (par ex. `'en'`)         |
| `fallbackLocale` | `string`                                                   | ❌       | Identique à `locale` | Locale de repli lorsque la traduction est manquante |
| `messages`       | `Record<string, Translations>`                             | ❌       | `\{\}`             | Messages de traduction initiaux                |
| `plural`         | `PluralFunc`                                               | ❌       | `defaultPlural`  | Fonction de pluralisation personnalisée        |
| `missingWarn`    | `boolean`                                                  | ❌       | `true`           | Afficher des avertissements console pour les traductions manquantes |
| `missingHandler` | `(locale: string, key: string, routeName: string) => void` | ❌       | -                | Gestionnaire personnalisé pour les traductions manquantes |

Tout ce qui va au-delà est spécifique au framework et documenté sur la page de ce paquet.

## Abstraction d'adaptateur de routeur

Tous les paquets de framework utilisent un **modèle d'adaptateur de routeur** pour découpler la fonctionnalité i18n des implémentations spécifiques de routeur. Cette conception permet :

- **Flexibilité** - Utiliser n'importe quelle bibliothèque de routeur ou aucun routeur du tout
- **Indépendance du framework** - Conserver la logique de routage dans votre application, pas dans le paquet i18n
- **Cœur léger** - Le paquet i18n reste petit et ciblé

### Implémenter un adaptateur de routeur

Pour utiliser les fonctionnalités de routage, vous devez implémenter l'interface `I18nRoutingStrategy` :

```typescript
interface I18nRoutingStrategy {
  getCurrentPath: () => string
  linkComponent?: Component
  push: (target: { path: string }) => void
  replace: (target: { path: string }) => void
  resolvePath?: (to: string | { path?: string }, locale: string) => string | { path?: string }
  getRoute?: () => { fullPath: string; query: Record<string, unknown> }
}
```

La documentation de chaque paquet inclut des exemples complets d'implémentation d'adaptateurs pour les routeurs populaires :

- **Vue** : Exemple d'adaptateur Vue Router
- **React** : Exemple d'adaptateur React Router
- **Solid** : Exemple d'adaptateur Solid Router
- **Astro** : Exemple d'adaptateur de routage basé sur les fichiers

## Fonctionnalités de base

Tous les paquets partagent ces fonctionnalités de base :

### Méthodes de traduction

- `t()` - Traduction de base avec interpolation de paramètres
- `ts()` - Traduction qui renvoie toujours une chaîne
- `tc()` - Traduction avec prise en charge de la pluralisation
- `tn()` - Formatage des nombres
- `td()` - Formatage des dates
- `tdr()` - Formatage des temps relatifs
- `has()` - Vérifier si une clé de traduction existe

### Gestion des locales

- **Changement de locale** - Changer la locale actuelle par programmation
- **Locale de repli** - Repli automatique lorsque la traduction est manquante
- **Traductions spécifiques aux routes** - Organisation des traductions au niveau des pages
- **Mise en cache des traductions** - Mise en cache intelligente pour les performances

### Prise en charge de TypeScript

Tous les paquets fournissent :

- Définitions TypeScript complètes
- Clés de traduction typées (avec le générateur de types)
- Prise en charge IntelliSense dans les IDEs
- Vérification des erreurs à la compilation

## Pour commencer

1. **Choisissez votre paquet** - Sélectionnez le paquet pour votre framework
2. **Installez le paquet** - Utilisez votre gestionnaire de paquets préféré
3. **Lisez la documentation** - Chaque paquet a des instructions de configuration détaillées
4. **Implémentez l'adaptateur de routeur** - Si vous avez besoin de fonctionnalités de routage, implémentez l'adaptateur
5. **Commencez à traduire** - Utilisez les composants et les méthodes pour ajouter des traductions

Pour des instructions détaillées, consultez la documentation de votre paquet spécifique :

- [Documentation du paquet Vue](/integrations/vue)
- [Documentation du paquet React](/integrations/react)
- [Documentation du paquet Solid](/integrations/solid)
