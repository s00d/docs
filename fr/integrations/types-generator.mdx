---
title: "Générateur de types"
description: "Générez l’autocomplétion TypeScript des clés de traduction à partir de vos fichiers JSON, dans Nuxt ou n’importe quel projet Vite."
---

`@i18n-micro/types-generator` lit chaque fichier JSON de votre dossier de traductions et écrit une déclaration qui liste toutes les clés. Ajoutez-le si vous voulez que votre éditeur suggère les clés dans `t()`, `$t()` et `<I18nT keypath>`. Il fonctionne comme module Nuxt et comme plugin Vite ou Rollup, et régénère les types lorsqu’un fichier change.

## Installation {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/types-generator
```

```bash npm
npm install -D @i18n-micro/types-generator
```

```bash yarn
yarn add -D @i18n-micro/types-generator
```

</CodeGroup>

Dépendance peer : `@nuxt/kit` `^3.18.0 || ^4.0.0`. Seule l’entrée `/nuxt` l’importe ; dans un projet uniquement Vite, l’avertissement de dépendance peer peut être ignoré.

## Nuxt {#nuxt}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro', '@i18n-micro/types-generator/nuxt'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Le module écrit `.nuxt/types/i18n-micro.d.ts` et Nuxt l’ajoute au contexte de types ; rien à inclure à la main. Il lit `i18nTypes.translationDir`, sinon l’emplacement où `nuxt-i18n-micro` lit les traductions : `translationDir` (depuis `i18n` ou les options du module en ligne, par défaut `'locales'`) dans chaque layer, ainsi que `additionalTranslationDirs`. Modifier un fichier JSON dans ce dossier régénère les types dans `nuxi dev`. `i18nTypes.outputFile` est ignoré dans Nuxt (un avertissement le signale).

## Vite {#vite}

`I18nTypesPlugin` est un plugin Vite, que Rollup accepte également. Pour un autre bundler, appelez `generateTypes` dans un script.

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { I18nTypesPlugin } from '@i18n-micro/types-generator'

export default defineConfig({
  plugins: [
    vue(),
    I18nTypesPlugin({
      srcDir: process.cwd(),
      translationDir: 'src/locales',
      outputFile: 'src/i18n-micro.d.ts',
    }),
  ],
})
```

| Option | Requise | Remarques |
| --- | --- | --- |
| `srcDir` | oui | Répertoire de base ; `translationDir` est résolu par rapport à lui. |
| `translationDir` | oui | Dossier contenant les fichiers JSON (sous-dossiers comme `pages/` inclus), ou tableau de dossiers. |
| `outputFile` | non | Où écrire la déclaration ; par défaut `<srcDir>/i18n-micro.d.ts`. |

Le plugin génère une fois au démarrage du build et, sur le serveur de développement, régénère 300 ms après une modification dans le dossier. Assurez-vous que l’`include` de votre `tsconfig.json` couvre le fichier de sortie.

## Utiliser les clés {#use-the-keys}

Le fichier généré augmente `DefineLocaleMessage` dans `@i18n-micro/types`, ce qui transforme `TranslationKey` en vos clés :

```ts
declare module '@i18n-micro/types' {
  export interface DefineLocaleMessage {
    nav: object
    'nav.home': string
    'profile.title': string
  }
}
```

Les clés sont celles auxquelles `t()` répond, objets compris, issues de chaque locale et de chaque fichier de page, avec le type de leur valeur JSON. `TranslationKey` est l’union de ces clés et de n’importe quelle chaîne : vous obtenez donc l’autocomplétion, pas des erreurs ; une clé mal orthographiée ou dynamique compile toujours. Les paramètres et les valeurs de retour ne sont pas typés.

Pour des clés dynamiques sous un préfixe connu, `ScopedKey<'prefix'>` restreint aux clés correspondantes :

```ts
import type { ScopedKey } from '@i18n-micro/types'

const statusText = (status: string) => t(`status.${status}` as ScopedKey<'status'>)
```

`TranslationKey` et `ScopedKey` proviennent de `@i18n-micro/types` (React, Preact et Solid réexportent `TranslationKey` ; Vue non).

## API {#api}

| Export | Entrée | Remarques |
| --- | --- | --- |
| `I18nTypesPlugin(options)` | `@i18n-micro/types-generator` | Plugin Vite et Rollup |
| `generateTypes(options)` | `@i18n-micro/types-generator` | écrit le fichier, renvoie son chemin |
| `getTypesString(options)` | `@i18n-micro/types-generator` | renvoie la déclaration sans l’écrire |
| `formatKeyProperty(key)` | `@i18n-micro/types-generator` | helper |
| Module Nuxt (`configKey: 'i18nTypes'`) | `@i18n-micro/types-generator/nuxt` | option `translationDir` |

Signatures complètes : [référence du paquet](/fr/api/packages/types-generator).
