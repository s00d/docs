版本：**v3.22.0 → v3.26.0**。

## 新功能

- **Translation Memory API**：在執行時透過 `$resolveTranslations()` 與 `$setTranslation(key, value)` 讀寫目前語系字典。對 DevTools、測試以及應用內編輯器很有幫助。詳見[方法](/api/methods#resolvetranslations)。
- **命名 `numberFormats` 與 `datetimeFormats`**：可為每個語系設定與 Vue I18n 相容的命名格式，接著使用 `$tn(1000, 'currency')` 或 `$td(date, 'short')`。詳見[模組選項](/api/module-options)。
- **`/_locales` payload 的 HTTP 快取控制**：新的 [`httpCacheDuration`](/api/module-options) 會在翻譯 payload 上設定 `Cache-Control: public, max-age=…, immutable`。預設為一年，並安全地搭配 `?v={dateBuild}` 進行快取破除。
- **壓縮的翻譯 payload**：啟用 `nitro.compressPublicAssets` 時，公開翻譯 payload 會自動被壓縮。請見[效能指南](/guides/performance)。
- **`splitLocaleRoutes` 工具**：可從單一程式化清單（`pages:extend` 情境）同時建立 `pages` 與 `globalLocaleRoutes`，以路由名稱作為鍵。詳見[自訂語系路由](/guides/custom-locale-routes#programmatic-routes-pagesextend--244)。
- **SEO 基底使用 `site.url` fallback**：當未設定 `metaBaseUrl` 時，若有 `nuxt-site-config` 就使用其 `site.url`；否則使用請求 origin。詳見 [`metaBaseUrl`](/api/module-options)。

## 更新

- **Astro adapter**：完成路由 context 隔離，並支援 `numberFormats` 與 `datetimeFormats` 的接線。
- **React 與 Preact**：`I18nSwitcher` 現在會正確設定 `aria-haspopup` 與 `aria-expanded` 屬性。
- **效能基準**：效能 benchmark 已改為以 citty 為基礎的 CLI。
- **內容指紋 `dateBuild`**：預設 `dateBuild` 現在改為內容指紋，因此 payload 的 `?v=` 只在翻譯實際變更時才會改變。

## 修正

- **路由**：
  - 在地化路由 matcher 現在能正確處理帶連字號、巢狀路徑與帶參數的片段。
  - 當子路由為絕對路徑時，會保留巢狀 parent。
  - `hreflang` 現在改由語系的 `iso` 產生，而非路由代碼。
  - `no_prefix` 下的語系切換現在會取代 history，而非 push。
- **重新導向**：
  - cookie 與 `Accept-Language` 偏好重新導向現在會遵循 `autoDetectPath`。
  - `autoDetectPath: '/'` 下會保留 `localeRoutes` 別名。
- **翻譯**：
  - 自訂複數函式回傳 `null` 時，現在會退回預設複數規則。
  - 翻譯 layer 合併時不再打平內容。
  - 停用的語系不會出現在 premerged public payload 中。
  - HMR 現在會略過無變化的檔案寫入，並在根層語系變更時併發重新合併。
- **Switcher**：隱藏 `disabled` 的語系，並恢復 `customDisabledLinkStyle` 與 active-style 的優先權。
- **模組**：橋接 unplugin Vite 8 的 `Plugin` 型別，以相容 Nuxt Kit。
- **SSR**：Node SSR 現在改由 public payload 讀取（不再使用 Rollup `raw:` 匯入）。

## 破壞性變更（v3.22.0）

- SSR chunk 從 `useState('i18n-ssr-chunks')` 改為 `nuxtApp.payload.data['i18n-ssr-chunks']`。
- `@i18n-micro/vue` 已移除 `getAllTranslations()`，請改用 `resolveTranslations()`、`getStorage()` 或 `getRouteCache()`。
- 預設 `dateBuild` 現在為內容指紋，因此升級後 payload 的 `?v=` 會改變一次。
