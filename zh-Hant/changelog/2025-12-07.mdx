**日期**：2025-12-07

**版本**：`v2.14.1`

![v2.14 發行](/images/2.14.0.png)

我們很高興宣布 **v2.14.1**，帶來適用於 Node.js、Vue 3 與 Astro 的全新整合！這些套件將同樣強大的 i18n 功能帶到您喜愛的框架中，並共用相同的核心邏輯，以確保一致性與效能。

## 有什麼新功能？ {#what’s-new}

- **@i18n-micro/node** - 在任何 Node.js 應用程式、CLI 工具或後端服務中使用 i18n 翻譯
- **@i18n-micro/vue** - Vue 3 國際化外掛，提供響應式翻譯與路由專屬支援
- **@i18n-micro/astro** - Astro 國際化整合，具備完整的 TypeScript 支援
- **@i18n-micro/types-generator** - 自動為翻譯鍵產生 TypeScript 型別，提供完整的型別安全與 IDE 自動完成

## 主要功能 {#key-features}

所有整合都具備相同的核心優點：

- 輕量且高效能
- 支援路由專屬翻譯
- 內建複數處理
- 數字、日期與相對時間格式化
- 完整的 TypeScript 支援
- 相同的 JSON 翻譯檔案結構

**Types Generator** 進一步提升開發者體驗：

- 從 JSON 翻譯檔案自動產生型別
- 具編譯期驗證的型別安全翻譯鍵
- 完整的 IDE 自動完成支援
- 翻譯檔案變更時熱重載
- 零執行期開銷
