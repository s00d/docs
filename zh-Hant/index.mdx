description: "輕巧、快速的 Nuxt i18n：每頁獨立的 JSON 翻譯、建置期產生的在地化路由，以及開箱即用的 SEO 標籤。"
---

Nuxt I18n Micro 是專為大型專案設計、適用於 Nuxt 3 與 4 的輕量、高效能 i18n 模組。與 `@nuxtjs/i18n` 等傳統 i18n 解決方案相比，它能讓建置時間、記憶體用量與 bundle 大小維持在較低水準。

在地化路由在建置時由 `@i18n-micro/route-strategy` 產生，並在執行期由 `@i18n-micro/path-strategy` 解析，因此連結、語言切換器、`hreflang` 與重新導向都與路由器保持一致。翻譯僅使用 JSON，分為共用的根檔案與開發伺服器會自動為你建立的各頁面檔案，並內建 HMR。

<CodeGroup>

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>
