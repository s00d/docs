## 🔍 翻譯方法

用於取得與管理翻譯的核心方法。

### `$t`

{/* generated:method:$t — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

翻譯指定鍵並將 `params` 插值到結果中。當找不到鍵時會回傳 `defaultValue`；若未提供預設值則回傳鍵本身。

{/* /generated:method:$t */}

```typescript
const welcomeMessage = $t('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

<Warning>
`$t` 回傳 `CleanTranslation`，型別為 `string | number | boolean | Translations | PluralTranslations | null`。若鍵指向 JSON 中的**巢狀物件**（例如 JSON 為 `\{ "header": \{ "title": "Hi" \} \}` 而你呼叫 `$t('header')`），回傳值會是該**物件**，而不是字串。若直接在 Vue 樣板中使用（<code v-pre>\{\{ $t('header') \}\}</code>）會呈現為 `[object Object]`。

**避免方式：**

- 使用更精確的鍵：`$t('header.title')` → `"Hi"`
- 使用 `$ts()`，它一律回傳字串（對非字串會呼叫 `.toString()`）
- 若刻意要以巢狀鍵存取子物件供程式邏輯使用，才使用 `$t`
</Warning>

### `$ts`

{/* generated:method:$ts — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string) => string
```

類似 `$t`，但一律回傳字串：物件或陣列會被字串化，而不會原樣回傳。

{/* /generated:method:$ts */}

```typescript
const welcomeMessage = $ts('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

### `$_t` 與 `$_ts`

{/* generated:method:$_t — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

將 `$t` 綁定到特定路由，用於翻譯目前頁面以外的內容，例如 layout 內渲染指向其他路由的連結。

{/* /generated:method:$_t */}

{/* generated:method:$_ts — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => string
```

將 `$ts` 綁定到特定路由。請參考 `$_t`。

{/* /generated:method:$_ts */}

`$t` 與 `$ts` 的路由綁定版本。它們先接收 **route**，然後回傳一個鎖定該 route 語系與頁面 context 的翻譯函式。

- **取得方式**：`useNuxtApp()`（也由 `useI18n()` 以 `$_t` / `$_ts` 重新導出）

當 SSR 或轉場期間目前 route 與 `router.currentRoute` 不同時使用它們，例如在 `<i18n-t>`、`<i18n-group>` 內，或針對特定 `route` 物件渲染內容。

```typescript
import { useRoute, useNuxtApp } from '#imports'

const route = useRoute()
const { $_t, $_ts } = useNuxtApp()

const $t = $_t(route)
const title = $t('page.title')

// String-safe variant
const label = $_ts(route)('page.label')
```


### `$tc`

{/* generated:method:$tc — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params: number | Params, defaultValue?: string) => string
```

帶複數形式的翻譯。`params` 可以是數量本身，或包含 `count` 的物件。

{/* /generated:method:$tc */}

**翻譯格式**：以 `|` 分隔各種形式。**每一種**形式都要放入 placeholder：

```json
{
  "apples": "no apples | one apple | {count} apples",
  "cart": "no items for {name} | one item for {name} | {count} items for {name}"
}
```

```typescript
$tc('apples', 0) // "no apples"
$tc('apples', 1) // "one apple"
$tc('apples', 10) // "10 apples"

// count + other params (second argument must be an object)
$tc('cart', { count: 10, name: 'Alice' }) // "10 items for Alice"
```


**元件替代方案**：`<i18n-t keypath="cart" :plural="count" :params="\{ name \}" />`（內部會將 `count` 與 `params` 合併）。


### `$mergeTranslations`

{/* generated:method:$mergeTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
(newTranslations: Translations) => void
```

在執行時將翻譯合併進目前語系，覆蓋已載入內容。

{/* /generated:method:$mergeTranslations */}

```typescript
$mergeTranslations({
  welcome: 'Bienvenue, {username}!',
})
// Output: Updates the translation cache with the new French translation
```

### `$resolveTranslations`

{/* generated:method:$resolveTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
() => Translations
```

目前語系與路由記憶體中所有翻譯的樹狀結構。此為 `$t()` 現在能解析內容的唯讀檢視。

{/* /generated:method:$resolveTranslations */}

```typescript
const tree = $resolveTranslations()
// { aaa: { bbb: 'ccc' }, ddd: 1111 } — the same dictionary $t() reads from
```

當你需要完整的記憶體字典（DevTools、測試、執行時編輯器）時使用此方法。回傳值應視為唯讀，若要變更值請使用 `$setTranslation`，或透過 `$mergeTranslations` 合併補丁。

### `$setTranslation`

{/* generated:method:$setTranslation — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, value: unknown) => void
```

取代目前字典中 `key` 對應的值。這是取代而非合併。若希望保留相同鍵下的既有兄弟項目，請使用 `$mergeTranslations`。

{/* /generated:method:$setTranslation */}

```typescript
$setTranslation('aaa', { fff: 'ggg' }) // replaces the whole `aaa` subtree
$setTranslation('aaa', 'text')          // replaces `aaa` with a string
$setTranslation('ddd', 1111)            // scalar at the top level
$setTranslation('aaa.bbb', 'nested')    // dotted path
```

這是**取代**而非合併。相同鍵下的既有兄弟項目會被移除。若要在不遺失兄弟項目的情況下更新，請使用 `$mergeTranslations`。

### `$setMissingHandler`

{/* generated:method:$setMissingHandler — do not edit; run `pnpm run docs:generate` */}

```ts
(handler: MissingHandler | null) => void
```

安裝一個對每個未解析鍵都會被呼叫的 callback。傳入 `null` 可移除它。

{/* /generated:method:$setMissingHandler */}

**型別定義**：

```typescript
type MissingHandler = (locale: string, key: string, routeName: string, instance?: unknown, type?: string) => void
```

```typescript
// Set a custom handler
$setMissingHandler((locale, key, routeName) => {
  console.error(`Missing translation: ${key} in ${locale} for route ${routeName}`)
  // Send to Sentry or other error tracking service
  // Sentry.captureMessage(`Missing translation: ${key}`)
})

// Remove the handler
$setMissingHandler(null)
```

**使用情境**：

- 將缺失翻譯記錄到錯誤追蹤服務（Sentry、LogRocket 等）
- 收集缺失翻譯的統計資料
- 為缺失的翻譯鍵進行自訂錯誤處理

## 🔢 數字與日期格式化

依語系慣例格式化數字與日期的方法。

### `$tn`

{/* generated:method:$tn — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

以目前語系使用 `Intl.NumberFormat` 格式化數字。傳入鍵可從設定中選擇已命名的格式。

{/* /generated:method:$tn */}

```typescript
// Inline options
const formattedNumber = $tn(1234567.89, { style: 'currency', currency: 'USD' })
// "$1,234,567.89"

// Named format (from nuxt.config i18n.numberFormats)
const price = $tn(1000, 'currency')
const priceDe = $tn(1000, 'currency', 'de')
const compact = $tn(1000, 'currency', { notation: 'compact' })
```

未知的命名格式鍵會回退到預設的 `Intl.NumberFormat` 選項。在開發模式的用戶端環境中，當 `missingWarn` 啟用（預設）時會發出 `console.warn`。

**設定範例**：

```ts
export default defineNuxtConfig({
  i18n: {
    numberFormats: {
      en: {
        currency: { style: 'currency', currency: 'USD' },
        decimal: { style: 'decimal', minimumFractionDigits: 2, maximumFractionDigits: 2 },
      },
      de: {
        currency: { style: 'currency', currency: 'EUR' },
      },
    },
  },
})
```

**使用情境**：

- 依目前語系格式化貨幣、百分比或小數等數字
- 在整個應用中重複使用命名格式（與 Vue I18n 遷移對齊）

### `$td`

{/* generated:method:$td — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

以目前語系使用 `Intl.DateTimeFormat` 格式化日期。傳入鍵可從設定中選擇已命名的格式。

{/* /generated:method:$td */}

```typescript
const formattedDate = $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' })
// "Friday, September 1, 2023"

const short = $td(new Date(), 'short')
const longDe = $td(new Date(), 'long', 'de')
```

未知的命名格式鍵會回退到預設的 `Intl.DateTimeFormat` 選項。在開發模式的用戶端環境中，當 `missingWarn` 啟用（預設）時會發出 `console.warn`。

**設定範例**：

```ts
export default defineNuxtConfig({
  i18n: {
    datetimeFormats: {
      en: {
        short: { year: 'numeric', month: 'short', day: 'numeric' },
        long: { year: 'numeric', month: 'long', day: 'numeric', weekday: 'long' },
      },
    },
  },
})
```

**使用情境**：

- 以符合使用者語系的格式顯示日期
- 在整個應用中共用 short／long／date-time 預設格式

### `$tdr`

{/* generated:method:$tdr — do not edit; run `pnpm run docs:generate` */}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

使用 `Intl.RelativeTimeFormat` 將日期格式化為相對時間（例如「3 天前」）。

{/* /generated:method:$tdr */}

```typescript
const relativeDate = $tdr(new Date(Date.now() - 1000 * 60 * 5))
// Output: "5 minutes ago" in the 'en-US' locale
```

### `$localePath`

## 🚦 路由設定

設定路由行為與存取控制的方法。

### `$defineI18nRoute`

{/* generated:method:$defineI18nRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

從元件內註冊逐頁的語系設定與翻譯。翻譯會被合併進目前語系，並在語系變更時重新套用。

{/* /generated:method:$defineI18nRoute */}

> [!IMPORTANT]
> `$defineI18nRoute` 由 **define 外掛**提供，且僅可透過 `useNuxtApp()` 取得，**不會**是 `useI18n()` 回傳物件的一部分。
> 請一律在 `script setup` 內從 `useNuxtApp()` 解構取得。若把 `$defineI18nRoute(...)` 當作全域直接呼叫，會在 SSR／prerender 期間拋出 `"$defineI18nRoute is not defined"`。

**參數**：

- **locales**：`string[] | Record<string, Record<string, string>>`：該路由可用的語系
- **localeRoutes**：`Record<string, string>`：選填。特定語系的自訂路徑
- **disableMeta**：`boolean | string[]`：選填。停用所有或特定語系的 i18n meta 標籤

**基本範例**：

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr', 'de'],
  localeRoutes: {
    en: '/welcome',
    fr: '/bienvenue',
    de: '/willkommen',
  },
  disableMeta: false,
})
```

> 📖 **詳細用法範例、設定格式與最佳實務請見[逐元件翻譯指南](/guides/per-component-translations)。**

### `$setI18nRouteParams`

{/* generated:method:$setI18nRouteParams — do not edit; run `pnpm run docs:generate` */}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

為目前路由設定各語系參數，讓動態片段可依語言而異。請在 SSR 期間、於 head 渲染之前呼叫。

{/* /generated:method:$setI18nRouteParams */}

```typescript
// in pages/news/[id].vue
// for en/news/1-first-article
const { $switchLocaleRoute, $setI18nRouteParams, $defineI18nRoute } = useNuxtApp()
$defineI18nRoute({
  localeRoutes: {
    en: '/news/:id()',
    fr: '/nouvelles/:id()',
    de: '/Nachricht/:id()',
  },
})
const { data: news } = await useAsyncData(`news-${params.id}`, async () => {
  let response = await $fetch("/api/getNews", {
    query: {
      id: params.id,
    },
  });
  if (response?.localeSlugs) {
    response.localeSlugs = {
      en: {
        id: '1-first-article'
      }
      fr: {
        id: '1-premier-article'
      }
      de: {
        id: '1-erster-Artikel'
      }
    }
    $setI18nRouteParams(response?.localeSlugs);
  }
  return response;
});
$switchLocalePath('fr') // === 'fr/nouvelles/1-premier-article'
$switchLocalePath('de') // === 'de/Nachricht/1-erster-Artikel'
```

## 🔧 快取與工具方法

### `$has`

{/* generated:method:$has — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string) => boolean
```

目前語系中該鍵是否能被解析。可用於針對可選文案分支處理，避免直接顯示原始鍵。

{/* /generated:method:$has */}

在同一語系的頁面轉場期間，v3 會自動將離開頁面的翻譯深度合併進此字典，直到轉場結束，因此前一頁的鍵可能會短暫地仍回傳 `true`。此行為為內建設計，並沒有 `previousPageFallback` 選項。詳見 [FAQ — 頁面轉場](/guides/faq#-why-do-translations-break-during-page-transitions-especially-with-defineasynccomponent)。

```typescript
if ($has('welcome')) {
  console.log($t('welcome'))
} else {
  console.log('Key not found')
}
```

### `$clearCache`

{/* generated:method:$clearCache — do not edit; run `pnpm run docs:generate` */}

```ts
() => void
```

在用戶端與目前字典中丟棄所有已快取的 chunk。

{/* /generated:method:$clearCache */}

**取得方式**：`useNuxtApp().$clearCache`。宣告在 `NuxtAppOnlyInjections` 而非 `PluginsInjections` 中，因此雖然具有型別，但刻意不出現在 `useI18n()` 的輔助物件中：


## 🧭 `useI18nLocale` composable

用於集中管理語系狀態的 composable。請優先使用它，而不要直接操作 `useState('i18n-locale')` 或 `useCookie('user-locale')`。

```typescript
const {
  setLocale, // (locale: string) => void — updates state + cookie
  getLocale, // () => string | null — from state or cookie
  getPreferredLocale, // () => string | null — validated against locales list
  getEffectiveLocale, // (route, getLocaleFromRoute) => string
  resolveInitialLocale, // (options) => string
  isValidLocale, // (locale) => boolean
  locale, // Ref<string | null> — reactive state
  localeCookie, // CookieRef — reactive cookie
  syncLocale, // (locale) => void — sync to cookie only
  validLocales, // string[] — list of valid locale codes
} = useI18nLocale()
```

### 主要方法

| 方法                    | 說明                                                          |
| ----------------------- | ------------------------------------------------------------- |
| `setLocale(locale)`     | 以原子操作同時更新 `useState` 與 cookie 中的語系              |
| `getLocale()`           | 從 state 或 cookie 取得目前語系                                |
| `getPreferredLocale()`  | 依 `locales` 清單驗證後回傳語系，若無效則回傳 `null`            |
| `isValidLocale(locale)` | 檢查語系代碼是否存在於設定的 `locales` 清單中                    |

### 在自訂外掛中使用

```typescript
// plugins/i18n-loader.server.ts
export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,
  setup() {
    const { setLocale } = useI18nLocale()
    // Detect locale from headers, domain, etc.
    setLocale('de')
  },
})
```

詳細範例請見[自訂語言偵測](/guides/custom-language-detection)。
