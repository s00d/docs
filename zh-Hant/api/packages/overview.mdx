# 套件 API

`nuxt-i18n-micro` 由一組小型套件組成,大多數皆可獨立使用 ——
`@i18n-micro/vue` 適用純 Vue 應用、`@i18n-micro/core` 可用於任何地方。

以下每頁皆由 [`pnpm run api:surface`](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/maintenance-commands.md#api-surface) 對 TypeScript 原始碼比對的 API snapshot 產生,因此若匯出被移除,若非本參考更新,就會導致 CI 失敗。
