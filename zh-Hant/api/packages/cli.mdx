共 6 個匯出，分布於 1 個進入點。
本頁由 API 快照產生，[`pnpm run api:surface`](https://s00d.github.io/nuxt-i18n-micro/contributing/maintenance-commands#api-surface)
會將該快照與 TypeScript 原始碼進行比對。

## `@i18n-micro/cli` {#@i18n-micro/cli}

```ts
import { /* … */ } from '@i18n-micro/cli'
```

| 匯出 | 種類 | 簽章 |
| --- | --- | --- |
| `ArgSpec` | interface | 8 個成員 |
| `COMMAND_GROUPS` | const | `readonly ["Inspect", "Translation workflow", "Refactoring", "Exchange"]` |
| `CommandGroup` | type | `(typeof COMMAND_GROUPS)[number]` |
| `commands` | const | `Record<string, CommandSpec>` |
| `CommandSpec` | interface | 5 個成員 |
| `runCli` | function | `(rawArgs: string[]) => Promise<void>` |

<Accordion title="`ArgSpec` — 8 個成員">

| `description` | `string` |
| `numeric?` | `"number" \| "int" \| undefined` |
| `required?` | `boolean \| undefined` |
| `type` | `"string" \| "boolean" \| "positional"` |
| `values?` | `readonly string[] \| undefined` |

</Accordion>
