共 7 個匯出，分布於 2 個進入點。
由 API 快照產生，[`pnpm run api:surface`](https://s00d.github.io/nuxt-i18n-micro/contributing/maintenance-commands#api-surface)
會將該快照與 TypeScript 原始碼進行比對檢查。

## `@i18n-micro/types-generator` {#@i18n-micro/types-generator}

```ts
import { /* … */ } from '@i18n-micro/types-generator'
```

| 匯出 | 類型 | 簽章 |
| --- | --- | --- |
| `formatKeyProperty` | 函式 | `(key: string) => string` |
| `generateTypes` | 函式 | `(options: GeneratorOptions) => string` |
| `GeneratorOptions` | 介面 | 4 個成員 |
| `getTypesString` | 函式 | `(options: GeneratorOptions) => string` |
| `I18nTypesPlugin` | 函式 | `(options: GeneratorOptions) => Plugin` |

<Accordion title="`GeneratorOptions` — 4 個成員">

| 成員 | 型別 |
| --- | --- |
| `additionalDirs?` | `string[] \| undefined` |
| `outputFile?` | `string \| undefined` |
| `srcDir` | `string` |
| `translationDir` | `string \| string[]` |

</Accordion>
