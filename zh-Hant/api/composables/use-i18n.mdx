# 🛠️ `useI18n` Composable

`Nuxt I18n Micro` 中的 `useI18n` composable 在元件與 script 中提供大多數執行時 i18n 輔助函式的存取。方法**同時提供帶 `$` 前綴與不帶前綴的形式**(例如 `$t` 與 `t`)。

某些注入 —— `$defineI18nRoute` 與 `$clearCache` —— 僅在 `useNuxtApp()` 上可用。請見 [Methods — `$defineI18nRoute`](/api/methods#definei18nroute) 與 [`$clearCache`](/api/methods#clearcache)。

## 📊 回傳內容

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

每個執行時輔助函式,以一般物件形式回傳。

外掛以 `$t`、`$tc` 等注入的相同函式,可透過帶 `$` 前綴的名稱或裸別名取得 —— 因此 `const \{ t \} = useI18n()` 與 `const \{ $t \} = useI18n()` 都可運作。

**回傳** —— [方法參考](/api/methods)中所述的輔助函式

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

它回傳的每個輔助函式 —— `$t`、`$tc`、`$has`、`$switchLocale` 等 —— 都列於[方法參考](/api/methods),並附上簽章與完整說明。

## 僅在 `useNuxtApp()` 上可用的 API

這些**不會**由 `useI18n()` 回傳。請從 `useNuxtApp()` 取得:

| 方法                       | 用途                                                                              |
| -------------------------- | --------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | 頁面層級的語系路由、限制,以及 `script setup` 中的內嵌翻譯                        |
| `$clearCache()`            | 清除記憶體翻譯快取與已載入 chunks                                                 |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

完整簽章與範例請見[方法](/api/methods)。

## 🛠️ 使用範例

### 基本語系取得

取得應用當前的語系。

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### 具參數的翻譯

以動態參數翻譯字串,並提供 fallback 預設值。

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### 切換語系

將應用切換到不同語系。

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### 產生在地化路由

產生對應當前或指定語系的路由。

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
