# 🛠️ `useI18n` composable

`Nuxt I18n Micro` 的 `useI18n` composable 讓你在元件與 script 中取得大部分執行時 i18n 輔助方法。方法**同時提供帶 `$` 前綴與不帶前綴的版本**（例如 `$t` 與 `t`）。

部分注入的方法—如 `$defineI18nRoute` 與 `$clearCache`—僅能透過 `useNuxtApp()` 取得。請見[方法—`$defineI18nRoute`](/api/methods#definei18nroute)與[`$clearCache`](/api/methods#clearcache)。

## 📊 回傳內容

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

以純物件形式回傳所有執行時輔助方法。

外掛所注入的函式（`$t`、`$tc` 等）以帶 `$` 前綴與不帶前綴的別名同時提供，因此 `const \{ t \} = useI18n()` 與 `const \{ $t \} = useI18n()` 都可行。

**回傳值**：[方法參考](/api/methods)所描述的所有輔助方法

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

它回傳的每個輔助方法—`$t`、`$tc`、`$has`、`$switchLocale` 等—都在[方法參考](/api/methods)中列出其型別簽章並附有完整說明。

## 僅存在於 `useNuxtApp()` 的 API

以下方法**不會**由 `useI18n()` 回傳，請從 `useNuxtApp()` 匯入：

| 方法                       | 用途                                                                            |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | 在 `script setup` 中設定逐頁語系路由、限制與 inline 翻譯                          |
| `$clearCache()`            | 清除記憶體翻譯快取與已載入的 chunk                                                |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

完整型別簽章與範例請見[方法](/api/methods)。

## 🛠️ 用法範例

### 基本語系取得

取得應用目前的語系。

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### 帶參數的翻譯

以動態參數翻譯字串，並提供 fallback 預設值。

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### 切換語系

將應用切換到不同語系。

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### 產生在地化路由

依目前或指定的語系產生在地化路由。

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
