# useI18nLocale

```vue
<script setup>
const {
  locale,
  localeCookie,
```

## API

| 屬性 / 方法                                     | 型別                                | 說明                                                                                 |
| ----------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| `locale`                                        | `Ref<string \| null>`               | 響應式語系狀態(`useState('i18n-locale')`)                                          |
| `localeCookie`                                  | `Ref`                               | 語系 cookie(當啟用 `localeCookie` 選項時)                                          |
| `hashCookie`                                    | `Ref`                               | 當 `hashMode` 啟用時使用的 cookie                                                    |
| `validLocales`                                  | `string[]`                          | 模組設定中已啟用的語系代碼(排除 `disabled`)                                        |
| `getLocale()`                                   | `() => string \| null`              | 當前語系:state → cookie(hash 模式下為 hash cookie)                                |
| `getPreferredLocale()`                          | `() => string \| null`              | 從 state/cookie 取得並**對照 `validLocales` 驗證**的語系,或 `null`                  |
| `getLocaleWithServerFallback(serverLocale?)`    | `(serverLocale?) => string \| null` | State → cookie → 選用的伺服器上下文(於 `no_prefix` 初始化時使用)                    |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string`             | 用於載入翻譯的語系:hash 模式偏好 state;否則由路由讀取                              |
| `resolveInitialLocale(options)`                 | `(options) => string`               | 解析語系:state → `serverLocale` → route;必要時同步 state                            |
| `setLocale(locale)`                             | `(locale: string \| null) => void`  | 設定語系並同步至 cookies                                                             |
| `syncLocale(locale)`                            | `(locale: string \| null) => void`  | 只同步 cookies(不更新 state)                                                        |
| `isValidLocale(locale)`                         | `(locale) => boolean`               | 檢查字串是否在 `validLocales` 中                                                     |

### `resolveInitialLocale` 選項

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

主要外掛在啟動時內部使用。自訂外掛在實作替代偵測流程時可呼叫。

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

回傳為給定路由物件用於載入翻譯與格式化訊息的語系。

## 以程式方式設定語系

相較於直接使用 `useState('i18n-locale')`,建議使用 `useI18nLocale()`:

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
`setLocale()` 只更新語系偏好(state + cookie)。若要在客戶端同時重新載入作用中的翻譯上下文,請使用 `useNuxtApp()` 或 `useI18n()` 中的 `$switchLocale()`。這在 `no_prefix` 情境下特別重要,因為 URL 不會改變。請見 [FAQ — 不改變 URL 就切換語系](/guides/faq#-switch-locale-without-changing-the-url)。
</Tip>
