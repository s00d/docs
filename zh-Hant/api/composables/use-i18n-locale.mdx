# useI18nLocale

## 型別簽章

{/* generated:symbol:useI18nLocale — do not edit; run `pnpm run docs:generate` */}

```ts
useI18nLocale(): { getEffectiveLocale: (route: unknown, getLocaleFromRoute: GetLocaleFromRoute) => string; getLocale: () => string | null; getLocaleWithServerFallback: (serverLocale?: string | null) => string | null; getPreferredLocale: () => string | null; hashCookie: any; isValidLocale: (locale: string | null | undefined) => locale is string; locale: any; localeCookie: any; resolveInitialLocale: (options: ResolveInitialLocaleOptions) => string; setLocale: (locale: string | null) => void; syncLocale: (locale: string | null) => void; validLocales: string[] }
```

用於管理 i18n 語系的集中入口。
結合 useState('i18n-locale')、語系 cookie 與同步工具。

{/* /generated:symbol:useI18nLocale */}

## 用法

```vue
<script setup>
const {
  locale,
  localeCookie,
  hashCookie,
  validLocales,
  getPreferredLocale,
  getLocale,
  getLocaleWithServerFallback,
  getEffectiveLocale,
  resolveInitialLocale,
  setLocale,
  syncLocale,
  isValidLocale,
} = useI18nLocale()

// Set locale (updates state and cookies)
setLocale('de')

// Get current locale (state → cookie)
const current = getLocale()

// Get valid preferred locale
const preferred = getPreferredLocale()
</script>
```

## API

| 屬性／方法                                       | 型別                                | 說明                                                                                    |
| ----------------------------------------------- | ----------------------------------- | --------------------------------------------------------------------------------------- |
| `locale`                                        | `Ref<string \| null>`               | 可反應的語系狀態（`useState('i18n-locale')`）                                             |
| `localeCookie`                                  | `Ref`                               | 語系 cookie（當啟用 `localeCookie` 選項時）                                                |
| `hashCookie`                                    | `Ref`                               | `hashMode` 啟用時使用的 cookie                                                            |
| `validLocales`                                  | `string[]`                          | 模組設定中啟用的語系代碼（排除 `disabled`）                                                 |
| `getLocale()`                                   | `() => string \| null`              | 目前語系：state → cookie（hash 模式下為 hash cookie）                                       |
| `getPreferredLocale()`                          | `() => string \| null`              | 由 state／cookie 取得並**依 `validLocales` 驗證**後的語系，若無效則為 `null`                 |
| `getLocaleWithServerFallback(serverLocale?)`    | `(serverLocale?) => string \| null` | state → cookie → 選填的伺服器 context（用於 `no_prefix` 初始化）                            |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string`             | 載入翻譯所使用的語系：hash 模式下優先取 state；否則從 route 讀取                              |
| `resolveInitialLocale(options)`                 | `(options) => string`               | 解析語系：state → `serverLocale` → route；必要時同步 state                                   |
| `setLocale(locale)`                             | `(locale: string \| null) => void`  | 設定語系並同步至 cookie                                                                    |
| `syncLocale(locale)`                            | `(locale: string \| null) => void`  | 僅同步 cookie（不更新 state）                                                              |
| `isValidLocale(locale)`                         | `(locale) => boolean`               | 檢查字串是否屬於 `validLocales`                                                            |

### `resolveInitialLocale` 選項

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

主要外掛會在啟動時內部使用它。自訂外掛在實作替代偵測流程時也可呼叫。

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

回傳為特定 route 物件載入翻譯與格式化訊息所使用的語系。

## 以程式化方式設定語系

請優先使用 `useI18nLocale()`，勿直接操作 `useState('i18n-locale')`：

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
`setLocale()` 只會更新語系偏好（state + cookie）。若要在用戶端同時重新載入目前的翻譯 context，請使用 `useNuxtApp()` 或 `useI18n()` 的 `$switchLocale()`。這對 `no_prefix` 特別重要，因為 URL 不會變更。詳見 [FAQ — 在不更動 URL 的情況下切換語系](/guides/faq#-switch-locale-without-changing-the-url)。
</Tip>
