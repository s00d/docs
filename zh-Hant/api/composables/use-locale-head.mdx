# 🌍 `useLocaleHead` Composable

`useLocaleHead` composable 是 `Nuxt I18n Micro` 中的工具,協助你管理在地化路由的 SEO 屬性與 HTML meta 標籤。它會動態產生 HTML 文件的 `lang` 與 `dir` 屬性,並建立 `meta` 與 `link` 標籤,以提升在地化內容的 SEO。

## 🛠️ 回傳值

`useLocaleHead` composable 回傳一個響應式物件與一個 updater 函式,當來源資料改變時應呼叫它。兩者的型別都在上方由原始碼產生的簽章中。

### `metaObject`

響應式 head payload(html attrs、meta、link),適合傳入 `useHead(metaObject)`。

- **範例**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

依當前路由、語系與設定重新計算 `metaObject`。輸入改變時呼叫 —— 例如路由變更時。

- **範例**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### 存取 `link` 與 `meta`

`link` 與 `meta` 陣列可透過 `metaObject.value` 存取:

- **範例**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ 使用範例

### 基本用法

以預設選項產生語系相關的 head 屬性。

```js
const head = useLocaleHead()
```

### 自訂識別屬性

為產生的標籤使用自訂識別屬性。

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### 停用 SEO 屬性

產生 head 屬性但不新增 SEO 相關的 meta 與 link 標籤。

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### 指定基底 URL

為 canonical 與 alternate URL 設定自訂基底 URL。

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 其他功能

### SEO Meta 與 Link 標籤

啟用 `addSeoAttributes` 時,composable 會自動產生下列標籤:

- 當前語系的 `og:locale`(`language_TERRITORY`,底線)。由 `locale.og` 衍生,或在可能時從 `locale.iso` 轉換。
- 頁面 canonical URL 的 `og:url`。
- 替代語言版本的 `og:locale:alternate`。
- 用於 SEO 最佳化的 `rel="canonical"` 與 `rel="alternate"` 連結。
- 指向預設語系 URL 的 `hreflang="x-default"` 連結。這告訴搜尋引擎,對於語言不符任何已定義語系的使用者,應顯示哪個 URL。

### 動態語系與方向

Composable 會依當前路由的語系動態決定 `lang` 與 `dir` 屬性,確保 HTML 文件對國際使用者有正確設定。

### 處理在地化路由

若你的路由帶有語系代碼前綴(例如 `/en/about`),composable 會智慧調整完整路徑以產生 URL,確保 SEO 屬性準確且相關。

此 composable 簡化了為國際受眾最佳化 Nuxt 應用的過程,確保網站為全球搜尋引擎與使用者做好準備。

## 🛠️ 範例用法

以下範例示範如何以預設設定於 Vue 元件中使用 `useLocaleHead` composable:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### 程式碼說明

- **`useLocaleHead` Composable**:於 `<script setup>` 呼叫此 composable,回傳包含 `htmlAttrs`、`meta` 與 `link` 的物件。

- **`<html>` 標籤**:HTML 文件的 `lang` 與 `dir` 屬性會依當前語系動態決定,並套用到 `<html>` 標籤。

- **`<head>` 區段**:
  - **Meta 標籤**:產生 SEO 相關 meta 標籤,包含 `og:locale`、`og:url`,以及指定替代語言版本的 `rel="canonical"` 與 `rel="alternate"` 標籤。
  - **Link 標籤**:包含 canonical 連結、替代語言版本連結,以及指向預設語系 URL 的 `hreflang="x-default"` 連結。

- **`<body>` 區段**:此處顯示頁面主要內容。範例中僅使用簡單的標題與段落。

### 📝 說明

1. **屬性**:所用屬性(`lang`、`dir`、`rel`、`href`、`hreflang`、`property`、`content`)由 `useLocaleHead` 所回傳的物件中取得。

2. **SEO 標籤產生**:若 `addSeoAttributes` 設為 `true`,composable 會自動為當前語系產生 SEO 標籤。

3. **基底 URL**:可透過 `baseUrl` 選項設定自訂基底 URL,以正確產生 canonical 與 alternate 連結。

此範例示範將 `useLocaleHead` 整合到應用元件是多麼容易,並可確保正確的 SEO 屬性,提升在地化頁面被搜尋引擎索引的效果。

## 🧩 客製化與生命週期

- `useLocaleHead` 不會自己訂閱變更。它回傳 `metaObject` 與 `updateMeta`。
- 輸入改變時(通常在路由變更時),你應該呼叫 `updateMeta()`,例如從外掛中:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## 何時改用 `useI18nHead`

當 `meta: true`(預設)時,對於**單一頁面**的覆寫(自訂 hreflang、額外的 `og:title`、部分停用),建議使用 [`useI18nHead`](/api/composables/use-i18n-head)。只有在 `meta: false` 或你自行管理 `useHead` 時,才直接使用 `useLocaleHead`。
