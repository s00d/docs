# 🌍 `useLocaleHead` composable

`useLocaleHead` composable 是 `Nuxt I18n Micro` 中的一個工具，協助你為多語系路由管理 SEO 屬性與 HTML meta 標籤。它會動態產生 HTML 文件的 `lang` 與 `dir` 屬性，並建立 `meta` 與 `link` 標籤，以提升多語系內容的 SEO。

目前路由的 SEO head 標籤：所有語系的 `hreflang` 替代與 `x-default`、canonical 連結、`og:locale`，以及 `<html>` 上的 `lang`／`dir`。

只有在 `meta` 停用或需要調整預設值時才需要它，當 `meta: true` 時，模組會自行註冊相同標籤。

## 🛠️ 回傳值

`useLocaleHead` composable 會回傳一個響應式物件，以及在來源資料變動時應呼叫的更新函式。兩者的結構皆列於上方型別簽章中，由原始碼產生。

### `metaObject`

響應式的 head payload（html attrs、meta、link），可直接傳給 `useHead(metaObject)`。

- **範例**：
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

依目前路由、語系與設定重新計算 `metaObject`。輸入變動時（例如路由變更）請呼叫它。

- **範例**：
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### 存取 `link` 與 `meta`

可透過 `metaObject.value` 取得 `link` 與 `meta` 陣列：

- **範例**：
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ 用法範例

### 基本用法

以預設選項產生逐語系的 head 屬性。

```js
const head = useLocaleHead()
```

### 自訂識別屬性

為產生的標籤使用自訂識別屬性。

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### 停用 SEO 屬性

產生 head 屬性但不加入 SEO 相關的 meta 與 link 標籤。

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### 指定基底 URL

為 canonical 與替代 URL 設定自訂基底 URL。

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 進階功能

### SEO Meta 與 Link 標籤

當 `addSeoAttributes` 啟用時，此 composable 會自動產生以下標籤：

- 目前語系的 `og:locale`（`language_TERRITORY`，使用底線）。由 `locale.og` 或可能時由 `locale.iso` 轉換而來。
- 頁面 canonical URL 的 `og:url`。
- 其他語言版本的 `og:locale:alternate`。
- `rel="canonical"` 與 `rel="alternate"` 連結，用於 SEO 最佳化。
- `hreflang="x-default"` 連結，指向預設語系的 URL。可告訴搜尋引擎，若使用者語言不符任何定義中的語系，該顯示哪一個 URL。

### 動態語系與方向

此 composable 會依目前路由的語系動態決定 `lang` 與 `dir` 屬性，確保 HTML 文件正確配置以服務國際使用者。

### 處理在地化路由

若你的路由以語系代碼作為前綴（例如 `/en/about`），此 composable 會智慧地調整完整路徑以產生 URL，確保 SEO 屬性精確且相關。

此 composable 簡化了為國際使用者最佳化 Nuxt 應用的流程，讓你的站點更能面向全球搜尋引擎與使用者。

## 🛠️ 用法範例

以下範例示範如何以預設設定在 Vue 元件中使用 `useLocaleHead` composable：

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### 程式碼說明

- **`useLocaleHead` composable**：在 `<script setup>` 中呼叫，回傳一個含有 `htmlAttrs`、`meta` 與 `link` 的物件。

- **`<html>` 標籤**：HTML 文件的 `lang` 與 `dir` 屬性會依目前語系動態決定並套用到 `<html>`。

- **`<head>` 區塊**：
  - **Meta 標籤**：會產生 SEO 相關 meta 標籤，包括 `og:locale`、`og:url`，以及指定其他語系版本的 `rel="canonical"` 與 `rel="alternate"` 標籤。
  - **Link 標籤**：包含 canonical 連結、指向其他語系版本的連結，以及指向預設語系 URL 的 `hreflang="x-default"` 連結。

- **`<body>` 區塊**：呈現頁面的主要內容。此範例僅使用簡單的標題與段落。

### 📝 備註

1. **屬性**：所使用的屬性（`lang`、`dir`、`rel`、`href`、`hreflang`、`property`、`content`）皆來自 `useLocaleHead` 回傳的物件。

2. **SEO 標籤產生**：若 `addSeoAttributes` 選項設為 `true`，composable 會自動為目前語系產生 SEO 標籤。

3. **基底 URL**：可透過 `baseUrl` 選項設定自訂基底 URL，以正確產生 canonical 與替代連結。

此範例示範將 `useLocaleHead` 整合進應用元件的方式，可確保正確的 SEO 屬性並提升多語系頁面的搜尋引擎索引成效。

## 🧩 自訂與生命週期

- `useLocaleHead` 本身不會訂閱任何變更。它回傳 `metaObject` 與 `updateMeta`。
- 當輸入變動（通常是路由變更）時，你應呼叫 `updateMeta()`，例如在外掛中：

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## 何時該改用 `useI18nHead`

當 `meta: true`（預設）時，建議改用 [`useI18nHead`](/api/composables/use-i18n-head) 進行**逐頁**覆寫（自訂 hreflang、額外 `og:title`、部分停用）。只有在 `meta: false` 或你自行管理 `useHead` 時，才直接使用 `useLocaleHead`。
