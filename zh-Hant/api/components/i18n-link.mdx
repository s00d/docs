# 🌍 `<i18n-link>` 元件

`Nuxt I18n Micro` 中的 `<i18n-link>` 是一個多用途連結元件，會依目前語系自動在地化路由。它是 `<NuxtLink>` 的包裝元件，額外提供作用中連結樣式與外部連結支援等功能。

## ⚙️ Props

| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | 目標路由。會自動在地化；若為外部 URL 則原封傳遞。 |
| `activeStyle` | `Partial<CSSStyleValue>` | — | 連結指向目前路由時套用的 inline 樣式。 |

**\*** 必填。

| Slot | 綁定值 | 說明 |
| --- | --- | --- |

`to` 接受 `NuxtLink` 支援的任何值：路徑、具名路由或已解析的 route 物件。若偵測到絕對 URL，會渲染為單純的 `<a target="_blank" rel="noopener noreferrer">`，而不會執行在地化。

## 🛠️ 用法範例

### 基本用法

```vue
<i18n-link to="/about">About Us</i18n-link>
```

此範例會建立指向 `/about` 頁面的連結，並在地化為目前語系。

### 使用 inline 樣式標示作用中連結

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

當使用者位於 `/about` 頁面時，連結的文字會加粗；你可以直接以 inline 樣式設定作用中連結。

### 外部連結處理

元件會自動偵測外部連結，並加入必要的安全屬性。

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

此連結會在新分頁開啟 `https://example.com`，並附上 `rel="noopener noreferrer"`。

## 🎨 樣式

元件目前使用 inline 樣式（而非 class）來呈現作用中狀態。可透過 `activeStyle` prop 自訂這些樣式。

### 預設作用中樣式

- **Font Weight**：`bold`
- **Color**：繼承瀏覽器的預設顏色（若未在 `activeStyle` 指定 `color`）。

你可以透過 `activeStyle` prop 覆寫這些預設樣式。

### 自訂作用中樣式

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

在此範例中，連結作用中時會呈現為粗體綠色。

## 🚀 進階功能

### 透過 Slot 傳入自訂內容

可透過 slot 傳入自訂內容，讓元件在不同情境中更彈性。

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### 無障礙強化

此元件支援 `aria-label` 與其他無障礙屬性，確保更具可及性的體驗。

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
