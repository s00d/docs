# 🌍 `<i18n-link>` 元件

`Nuxt I18n Micro` 中的 `<i18n-link>` 元件是多用途的連結元件,會依當前語系自動在地化路由。它作為 `<NuxtLink>` 的包裝,提供如 active 連結樣式與外部連結支援等額外功能。

## ⚙️ Props

| Prop | 型別 | 預設 | 說明 |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | 目標路由。會自動在地化;若為外部 URL 則原樣傳遞。 |
| `activeStyle` | `Partial<CSSStyleValue>` | — | 當連結指向當前路由時套用的行內樣式。 |

**\*** 必填。

### 插槽

| 插槽 | 綁定 | 說明 |
| --- | --- | --- |
| `default` | — | 連結內容。 |

{/* /generated:component:i18n-link */}

`to` 接受 `NuxtLink` 所接受的任何值 —— 路徑、具名路由或已解析的路由物件。
偵測到絕對 URL 時,會渲染為單純的 `<a target="_blank" rel="noopener noreferrer">`,而非進行在地化。

## 🛠️ 使用範例

### 基本用法

```vue
<i18n-link to="/about">About Us</i18n-link>
```

此範例會建立一個連向 `/about` 頁面的連結,並依當前語系在地化。

### 使用行內樣式的 Active 連結樣式

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

使用者位於 `/about` 頁面時,此連結會以粗體顯示,讓你能直接以行內樣式為 active 連結設定樣式。

### 外部連結處理

元件會自動偵測外部連結,並加入必要的安全屬性。

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

此連結會在新分頁開啟 `https://example.com`,並套用 `rel="noopener noreferrer"`。

## 🎨 樣式

元件現在以行內樣式取代 class 來設定 active 狀態。你可以透過 `activeStyle` prop 客製化這些樣式。

### 預設 Active 樣式

- **Font Weight**:`bold`
- **Color**:繼承瀏覽器預設顏色(若未在 `activeStyle` 指定 `color`)。

你可以透過 `activeStyle` prop 提供自訂樣式來覆寫這些。

### 自訂 Active 樣式

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

在此範例中,連結被啟用時會呈現粗體與綠色。

## 🚀 其他功能

### 使用插槽自訂內容

你可以透過插槽在連結內傳入自訂內容,讓元件在不同情境下更具彈性。

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### 無障礙強化

元件支援 `aria-label` 及其他無障礙屬性,以確保更佳的無障礙體驗。

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
