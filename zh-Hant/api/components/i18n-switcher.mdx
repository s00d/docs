# 🌍 `<i18n-switcher>` 元件

`Nuxt I18n Micro` 中的 `<i18n-switcher>` 元件為使用者提供友善的下拉式介面,可切換應用中的不同語系。此元件高度可自訂,能與應用設計與佈局無縫整合。

`disabled: true` 的語系會**從**下拉式選單中被**省略**(仍可透過 `$getLocales()` 用於 SEO / head 標籤)。只有可切換的語系會取得 `NuxtLink` + `hreflang`。

每個部分預設都沒有樣式:`custom*Style` prop 接受行內樣式物件,而以下插槽可在僅靠樣式不夠時完全替換標記。

## 🛠️ 使用範例

### 基本用法

```vue
<template>
  <i18n-switcher />
</template>
```

這會以預設樣式與行為渲染一個語系切換器。

### 自訂標籤與行內樣式

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

此範例示範具有自訂標籤與行內樣式的完全客製化語系切換器。

## 🔌 插槽

切換器的每個視覺部分都能被替換。插槽已與上方 props 表格一併列出;每個插槽可接受範本內容:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

名稱以 `-item`、`-link-content` 結尾,或以 `before-item` 開頭的插槽,會取得對應的 `locale` 物件。

## 🎨 樣式概觀

`<i18n-switcher>` 元件以行內樣式定義基本外觀,可透過 props 傳入自訂樣式輕易覆寫。以下是預設樣式的簡要概觀:

- **Wrapper**:控制下拉選單的定位。
- **Button**:設定下拉切換按鈕的樣式。
- **Dropdown**:設定下拉清單的樣式。
- **Items**:設定清單中每個項目的樣式。
- **Links**:設定每個項目內連結的樣式。
- **Icon**:設定下拉指示圖示的樣式。

你可透過對應 prop 傳入自訂樣式,以確保語系切換器與應用 UI 完美整合。
