# 🌍 `<i18n-t>` 元件

`Nuxt I18n Micro` 中的 `<i18n-t>` 元件是彈性的翻譯元件,透過插槽支援動態內容插入。它可讓你以自訂 Vue 元件或 HTML 內容為翻譯進行插值,支援進階在地化情境。

## ⚙️ Props

| --- | --- | --- | --- |
| `keypath` **\*** | `string` | — | 要渲染的翻譯鍵。 |
| `plural` | `number \| string` | — | 選擇複數形式的計數。設定後會改用 `$tc` 而非 `$t`。 |
| `tag` | `string` | `'span'` | 要渲染的元素。 |
| `params` | `Record<string, string \| number \| boolean>` | `() => (\{\})` | 帶入翻譯的插值。 |
| `defaultValue` | `string` | `''` | 當 `hideIfEmpty` 抑制空翻譯時,以此值取代該元件渲染。 |
| `html` | `boolean` | `false` | 將翻譯以 HTML(而非文字)渲染。僅適用於你信任的內容。 |
| `hideIfEmpty` | `boolean` | `false` | 當翻譯解析為空字串時不渲染任何內容。 |
| `customPluralRule` | `PluralFunc` | `null` | 僅為此元素套用的複數規則,覆寫已設定的規則。 |
| `number` | `number \| string` | — | 以 `$tn` 格式化該值,並以 `\{number\}` 帶入翻譯。 |
| `date` | `Date \| string \| number` | — | 以 `$td` 格式化該值,並以 `\{date\}` 帶入翻譯。 |
| `relativeDate` | `Date \| string \| number` | — | 以 `$tdr` 格式化該值,並以 `\{relativeDate\}` 帶入翻譯。 |

**\*** 必填。

{/* /generated:component:i18n-t */}

一次僅套用 `plural`、`number`、`date` 與 `relativeDate` 之一;若同時設定多個,依此清單順序取第一個。

### 各 Prop 範例

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

```json
{

}
```

## 🛠️ 使用範例

### 基本用法

```vue
<i18n-t keypath="feedback.text" />
```

這會將 `feedback.text` 的翻譯渲染於 `<span>` 標籤內。

### 使用插槽動態插入內容

`<i18n-t>` 元件支援使用插槽,將 Vue 元件或其他內容動態插入翻譯的特定部分。

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

在此範例中,`feedback.text` 翻譯字串中的 `\{link\}` 佔位符被替換為 `<nuxt-link>` 元件,而該元件本身又包含另一個翻譯元件。

### 複數化

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

這會依 `itemCount` 值自動套用複數規則。

## 🚀 其他功能

### 預設插槽

若未提供特定插槽,可透過預設插槽自訂翻譯,該插槽提供完整的翻譯字串:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### 條件式渲染

使用 `hideIfEmpty` prop,當翻譯字串為空時不渲染任何內容。

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### 自訂複數規則

使用自訂函式處理複數化。

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### 使用插槽的進階範例

透過插槽自訂翻譯內容的渲染方式。

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
