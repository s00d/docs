# API 參考

## 執行時 API

- [方法](/api/methods)：`$t`、`$ts`、`$_t`、`$_ts`、語系切換與路由輔助方法
- [事件](/api/events)：`i18n:register`、`i18n:beforeLocaleSwitch`、`i18n:afterLocaleSwitch`
- [翻譯與快取](/api/cache)：`TranslationStorage`、payload 載入、`$clearCache`

## 伺服器中介層

伺服器處理器需使用專屬的中介層（而非用戶端的 `$t` 輔助方法）：

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers)：在 API 路由與伺服器處理器中進行翻譯
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers)：讀取偵測到的語系與相關中繼資料

如需完整說明、語系偵測的優先順序與範例，請見[伺服器端翻譯指南](/guides/server-side-translations)。
