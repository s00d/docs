本節列出 Nuxt 模組的每一個選項、輔助函式、hook、composable 與元件，以及每個 `@i18n-micro/*` 套件匯出的 API。可用來查詢簽章或預設值；[指南](/zh-Hant/guide/getting-started)則說明如何使用它們。這裡的大多數表格都是從原始碼產生的，因此與程式碼一致。

## Nuxt 模組 {#nuxt-module}

| 頁面 | 涵蓋內容 |
| --- | --- |
| [模組選項](/zh-Hant/api/module-options) | `nuxt.config` 中每個 `i18n` 鍵，含型別與預設值 |
| [輔助函式](/zh-Hant/api/methods) | `$t`、`$tc`、`$tn`、`$td`、`$localePath`、`$switchLocale`、`$defineI18nRoute` 等 |
| [Hooks](/zh-Hant/api/events) | `i18n:register` 執行階段 hook |

## Composables {#composables}

| Composable | 用途 |
| --- | --- |
| [`useI18n`](/zh-Hant/composables/useI18n) | 在 `<script setup>` 中使用輔助函式 |
| [`useI18nLocale`](/zh-Hant/composables/useI18nLocale) | 在自訂偵測外掛中使用 locale 狀態與 cookie |
| [`useI18nHead`](/zh-Hant/composables/useI18nHead) | 逐頁覆寫產生的 SEO 標籤 |
| [`useLocaleHead`](/zh-Hant/composables/useLocaleHead) | 以物件形式取得 SEO 標籤，供您自己的 `useHead` 使用 |

## 元件 {#components}

| 元件 | 渲染內容 |
| --- | --- |
| [`<i18n-t>`](/zh-Hant/components/i18n-t) | 單一翻譯，支援複數、格式化與 slot 插值 |
| [`<i18n-link>`](/zh-Hant/components/i18n-link) | 指向在地化路由的 `NuxtLink` |
| [`<i18n-switcher>`](/zh-Hant/components/i18n-switcher) | locale 下拉選單 |
| [`<i18n-group>`](/zh-Hant/components/i18n-group) | 共用鍵前綴的區塊 |

## 伺服器 {#server}

Nitro 處理器使用 `useTranslationServerMiddleware` 與 `useLocaleServerMiddleware`，而非用戶端輔助函式。請參閱[伺服器路由](/zh-Hant/guide/server-side-translations)。

## 套件 {#packages}

[套件 API](/zh-Hant/api/packages/overview) 列出每個 `@i18n-micro/*` 套件的匯出項目，每個套件一個自動產生的頁面。
