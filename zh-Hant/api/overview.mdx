## 伺服器中介層

伺服器處理器使用專屬中介層(而非客戶端 `$t` 輔助函式):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) —— 在 API 路由與伺服器處理器中翻譯
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) —— 讀取偵測到的語系與中繼資料

完整說明、語系偵測優先順序與範例,請見 [伺服器端翻譯指南](/guides/server-side-translations)。
