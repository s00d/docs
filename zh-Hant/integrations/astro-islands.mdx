---

island 在瀏覽器中執行，而伺服器的 i18n 實例在那裡並不存在。`@i18n-micro/astro` 讓頁面挑選 island 所需的鍵，將它們作為單一 prop 傳入，並在 island 中透過小型框架轉接器讀取。你可以在 Vue、React、Preact 與 Svelte islands 中使用 `t`、`tc`、`tn`、`td`、`tdr` 與 `has`，而 HTML 中只會包含所選的字串。

## 設定 {#setup}

請先設定 [Astro 整合與 middleware](/zh-Hant/integrations/astro-package#setup)，再加入你所使用的框架整合（`@astrojs/vue`、`@astrojs/react`、`@astrojs/preact`、`@astrojs/svelte`）。island 轉接器需要該框架作為 peer 相依套件：`vue` `^3.3.0`、`react` `^16.8.0 || ^17.0.0 || ^18.0.0 || ^19.0.0`、`preact` `^10.0.0 || ^11.0.0` 或 `svelte` `^4.0.0 || ^5.0.0`。

## 將翻譯傳給 island {#pass-translations-to-an-island}

```astro
---
// src/pages/index.astro
import { getI18nProps } from '@i18n-micro/astro'
import Counter from '../components/Counter.vue'

const i18n = getI18nProps(Astro, ['counter.title', 'counter.apples'])
---

<Counter client:load i18n={i18n} />
```

`getI18nProps(Astro, keys?)` 會回傳 `{ locale, fallbackLocale, currentRoute, translations }`（型別為 `I18nClientProps`）。請傳入 island 使用的鍵：每個鍵都會在伺服器上像 `t()` 一樣解析（路由、根與 fallback 字典），只有找到的鍵會寫入 HTML。若未傳入 `keys`，則此頁面上 `t()` 能解析的所有內容都會傳送到每個 island，因此 2000 個根鍵每個 island 約需 100 KB；在開發模式下超過 20 KB 時會顯示警告。

islands 只會從該物件進行翻譯。對於未傳入的內容，`t` 會回傳鍵本身，且連結訊息不會被解析。

## Vue {#vue}

在 island 的根元件中呼叫 `provideI18n(() => props.i18n)`，並在其子元件中呼叫 `useAstroI18n()`。Vue 的 `inject` 看不到同一個元件所提供的值，因此此 hook 必須在子元件中執行，而非在根元件中：

```vue
<!-- src/components/Counter.vue -->
<script setup lang="ts">
import { provideI18n } from '@i18n-micro/astro/client/vue'
import type { I18nClientProps } from '@i18n-micro/astro'
import CounterBody from './CounterBody.vue'

const props = defineProps<{ i18n: I18nClientProps }>()
provideI18n(() => props.i18n)
</script>

<template><CounterBody /></template>
```

```vue
<!-- src/components/CounterBody.vue -->
<script setup lang="ts">
import { ref } from 'vue'
import { useAstroI18n } from '@i18n-micro/astro/client/vue'

const { t, tc } = useAstroI18n()
const count = ref(0)
</script>

<template>
  <h3>{{ t('counter.title') }}</h3>
  <button @click="count++">{{ tc('counter.apples', count) }}</button>
</template>
```

## React 與 Preact {#react-and-preact}

```tsx
// src/components/Counter.tsx
import { useState } from 'react'
import { I18nProvider, useAstroI18n } from '@i18n-micro/astro/client/react'
import type { I18nClientProps } from '@i18n-micro/astro'

function Body() {
  const { t, tc } = useAstroI18n()
  const [count, setCount] = useState(0)
  return <button onClick={() => setCount(count + 1)}>{t('counter.title')}: {tc('counter.apples', count)}</button>
}

export default function Counter({ i18n }: { i18n: I18nClientProps }) {
  return (
    <I18nProvider value={i18n}>
      <Body />
    </I18nProvider>
  )
}
```

若使用 Preact，請從 `@i18n-micro/astro/client/preact` 匯入 `I18nProvider` 與 `useAstroI18n`；API 完全相同。

## Svelte {#svelte}

```svelte
<!-- src/components/Counter.svelte -->
<script lang="ts">
  import { createI18nStore, useAstroI18n } from '@i18n-micro/astro/client/svelte'
  import type { I18nClientProps } from '@i18n-micro/astro'

  export let i18n: I18nClientProps
  const { t, tc } = useAstroI18n(createI18nStore(i18n))
  let count = 0
</script>

<button on:click={() => count++}>{t('counter.title')}: {tc('counter.apples', count)}</button>
```

`useAstroI18n(store)` 也會回傳 `store`，供範本中以 `$store` 讀取。

## 持久化的 islands {#persisted-islands}

帶有 `transition:persist` 的 island 會在導覽後取得新的 props。React、Preact 與 Vue（提供 getter 時）會跟著更新。在 Svelte 中，請保留 store 並將新 props 傳給它：`const store = createI18nStore(i18n)`、`const { t } = useAstroI18n(store)`，然後 `$: store.set(i18n)`（使用 runes 時為 `$effect(() => store.set(i18n))`）。

## API {#api}

| 進入點 | 匯出 |
| --- | --- |
| `@i18n-micro/astro` | `getI18nProps`、型別 `I18nClientProps` |
| `@i18n-micro/astro/client/vue` | `provideI18n(props \| () => props)`、`useAstroI18n()` |
| `@i18n-micro/astro/client/react` | `I18nProvider`（`value` prop）、`useAstroI18n()` |
| `@i18n-micro/astro/client/preact` | `I18nProvider`（`value` prop）、`useAstroI18n()` |
| `@i18n-micro/astro/client/svelte` | `createI18nStore(props)`、`useAstroI18n(store)` |
| `@i18n-micro/astro/client` | 純函式 `translate`、`hasTranslation`，不依賴任何框架 |

每個 `useAstroI18n` 都會回傳 `t`、`ts`、`tc`、`tn`、`td`、`tdr`、`has`、`setLocale`、`setRoute` 以及 `locale`。island 只有一份合併後的字典，因此只要 `t` 能解析某個鍵（包括來自 fallback locale 的鍵），其 `has` 就會回傳 true；在伺服器上，`has` 只會檢查目前啟用的 locale。
