---

`@i18n-micro/vitepress` 為 VitePress 網站加入執行階段字典：markdown 中的 `$t` 與 `<I18nT>`、路徑輔助函式與 SEO 標籤，建構於 [`@i18n-micro/vue`](/zh-Hant/integrations/vue-package) 之上。當相同的 UI 字串出現在許多頁面上，而你不想為每個 locale 重複撰寫時，請使用它。locale 會跟隨 VitePress 本身的路徑 locale（`/`、`/fr/`）。

## 使用時機 {#when-to-use-it}

| 需求 | 解決方案 |
|------|----------|
| 重複的 `.md`、URL 前綴 | VitePress `locales` |
| 執行階段 `$t` / 元件 / 路徑同步 / SEO head | `@i18n-micro/vitepress` |
| 預設主題介面標籤（`docFooter`、搜尋 UI） | 每個 locale 自行設定 `themeConfig` |

<Tip>

**Playground** — [`packages/vitepress/playground`](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/vitepress/playground) — `pnpm -C packages/vitepress/playground dev`

</Tip>

## 安裝 {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vitepress
```

```bash npm
npm install @i18n-micro/vitepress
```

```bash yarn
yarn add @i18n-micro/vitepress
```

</CodeGroup>

Peer 相依套件：`vitepress` `>=1.0.0 || >=2.0.0-alpha.0`、`vue` `^3.3.0`。Node 腳本使用 `@i18n-micro/node`，它會隨此套件一起安裝，並透過 `/node` 重新匯出。已發布的型別在 `skipLibCheck: false` 時需要 Vue 3.5.5 或更新版本；在範本常用的 `skipLibCheck: true` 設定下，較舊的版本也能編譯。

## 設定 {#setup}

```
locales/en.json
locales/fr.json
locales/pages/guide/demo/en.json   # optional page-scoped
locales/pages/guide/demo/fr.json
```

頁面檔案對應到路由名稱的方式與 Nuxt/Astro 相同（`guide/demo` → `guide-demo`）。

### 1. 設定 — `@i18n-micro/vitepress/config` {#1-config-—-@i18n-micro/vitepress/config}

```ts
// .vitepress/config.mts
import { defineConfig } from 'vitepress'
import { withI18n, buildVitePressLocales } from '@i18n-micro/vitepress/config'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English', og: 'en_US' },
  { code: 'fr', iso: 'fr-FR', displayName: 'Français', og: 'fr_FR' },
]
const defaultLocale = 'en'

export default defineConfig(
  withI18n(
    {
      locales: buildVitePressLocales(locales, defaultLocale),
      // themeConfig.i18nRouting is injected automatically
    },
    {
      locale: defaultLocale,
      defaultLocale,
      locales,
      translationDir: 'locales',
      metaBaseUrl: 'https://example.com', // optional SEO head
    },
  ),
)
```

### 2. 主題 — `@i18n-micro/vitepress/theme` {#2-theme-—-@i18n-micro/vitepress/theme}

```ts
// .vitepress/theme/index.ts
import DefaultTheme from 'vitepress/theme'
import { defineI18nTheme } from '@i18n-micro/vitepress/theme'

export default defineI18nTheme(DefaultTheme)
```

初始 locale 會在安裝前從目前路徑取得（在 `/fr/…` 上不會閃現預設 locale）。

### 進階：手動 `createI18n` {#advanced-manual-createi18n}

用戶端只有一個工廠函式：Vue 外掛 + 路徑方法 + `enhanceApp`（沒有另外匯出路由器輔助函式）。

```ts
import { createI18n, messagesFromGlob } from '@i18n-micro/vitepress'

const i18n = createI18n({
  locale: 'en',
  defaultLocale: 'en',
  locales: [{ code: 'en' }, { code: 'fr' }],
  messages: messagesFromGlob(import.meta.glob('../../locales/*.json', { eager: true })),
})

i18n.localizePath('/guide', 'fr')
// in theme enhanceApp:
i18n.enhanceApp({ app, router })
```

### Node 腳本 — `@i18n-micro/vitepress/node` {#node-scripts-—-@i18n-micro/vitepress/node}

使用 `@i18n-micro/node` 的 `createI18n` / `loadTranslations`（與 Astro 及 CLI 相同），再透過 `BaseI18n.extend` 附加 VitePress 路徑方法：

```ts
import { createI18n } from '@i18n-micro/vitepress/node'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  translationDir: './locales',
  locales: ['en', 'fr'],
  defaultLocale: 'en',
})
await i18n.loadTranslations()
i18n.t('cta.readMore')
i18n.localizePath('/guide', 'fr')
```

不需要路徑的純 Node：`import { createI18n } from '@i18n-micro/node'`。

## 頁面內翻譯 {#in-page-translations}

每個 VitePress markdown 檔案都是一個 Vue SFC。

### 全域元件與 `$t`（建議在 markdown 中使用） {#global-components-and-$t-recommended-in-markdown}

`createI18n` / `defineI18nTheme` 會安裝 `@i18n-micro/vue`，它會註冊 `I18nT` / `I18nLink` / `I18nGroup` / `I18nSwitcher` 以及 `$t` / `$tc` / `$ts`。

```md
{{ $t('cta.readMore') }}

<I18nT keypath="greeting" :params="{ name: 'VitePress' }" />

<I18nLink to="/guide/demo">Demo</I18nLink>
```

### 在 `<script setup>` 中使用 `useI18n` {#usei18n-in-<script-setup>}

```md
<script setup>
import { useI18n } from '@i18n-micro/vitepress'
const { t, tc, locale, localePath, switchLocale } = useI18n()
</script>

# {{ t('section.title') }}
```

## 語言下拉選單 {#language-dropdown}

當 `locales` 有多個項目時，VitePress 會顯示自己的語言選單（`VPNavBarTranslations`）。`withI18n` 會設定 `themeConfig.i18nRouting`，讓地球圖示選單與 `<I18nSwitcher>` / 路徑輔助函式保持一致。

請只在自訂版面配置中使用 `<I18nSwitcher>`，不要與預設的地球圖示選單並列。

## SSR 注意事項 {#ssr-notes}

- 預渲染時的 locale 來自 URL 路徑，而非 cookie。
- 主題程式碼在匯入時不得存取 `window`。
- 請從 `/theme` 匯入 `defineI18nTheme`，讓 Node 設定求值時永遠不會載入 `virtual:i18n-micro/*`。

## API 介面 {#api-surface}

| 匯出 | 角色 |
|--------|------|
| `createI18n` (`.`) | 用戶端：Vue 外掛 + 路徑方法 + `enhanceApp` |
| `getLocaleFromPath` / `stripSiteBase` / `routeNameFromPath` (`.`) | 在 `syncWithVitePress: false` 時手動同步 locale |
| `createI18n` (`/node`) | Node：`@i18n-micro/node` + 路徑方法 |
| `defineI18nTheme` (`/theme`) | 零樣板程式碼的主題 |
| `withI18n` (`/config`) | 設定 + 虛擬模組 + 選用的 SEO |
| `buildVitePressLocales` (`/config`) | 從 `Locale[]` 建立 VitePress `locales` |
| `buildVitePressLocaleHead` (`/config`) | 手動 SEO head（`metaBaseUrl` 也會使用） |
| `messagesFromGlob` | 選用：將 glob 轉為 `createI18n` 的 messages 對應 |
| `useI18n` / `I18nT` / … | 從 `@i18n-micro/vue` 重新匯出 |
| `BaseI18n.extend` (`@i18n-micro/core`) | 在任何 i18n 實例上附加自訂方法 |

## OpenAPI 風格網站（整合鎖定） {#openapi-style-sites-integration-locks}

回歸測試套件：`packages/vitepress/tests/integration-openapi.test.ts`（深層路徑、`base=/openapi_docs/`、關閉同步 + 手動 locale、Node 產生器、SEO）。

| 模式 | 做法 |
|---------|---------|
| 深層 `/…/{spec}/{op}` 頁面，只有根 UI JSON | 建議使用預設的 `syncWithVitePress: true`（沒有頁面字典時會保持 `setRoute('index')`）**或** `syncWithVitePress: false` + `getLocaleFromPath` |
| 沒有頁面字典時，絕不要呼叫 `setRoute(deepName)` | 根 UI 鍵會消失，直到呼叫 `setRoute('index')` |
| 產生器 / `getTranslation` | 從 `/node` 使用 `createI18n` + `await loadTranslations()` + `i18n.t(key)`（設定 `i18n.locale`） |
| 在 `transformPageData` 中自訂 canonical | 將 `meta: false` 傳給 `withI18n`（避免重複標籤） |
| 搭配網站 base 的套件 SEO | `metaBaseUrl` + VitePress `base` → 絕對 URL 會包含 base |
| 從舊版套件建置重新命名 | `withI18nMicro` → `withI18n`、`createVitePressI18n` → `createI18n`、`loadMessages` → node `createI18n` |
