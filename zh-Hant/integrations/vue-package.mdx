`@i18n-micro/vue` 是一個 Vue 3 外掛，內含 Nuxt I18n Micro 的翻譯核心：響應式的 `t()`、全域的 `$t`、四個元件，以及可選的 vue-router 配接器。請在未使用 Nuxt 建置的 Vite 或 SSR Vue 應用程式中使用它。實例模型、路由器約定與元件 props 與其他套件共用，相關說明請見[框架](/zh-Hant/integrations/overview)。

## 安裝 {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vue
```

```bash npm
npm install @i18n-micro/vue
```

```bash yarn
yarn add @i18n-micro/vue
```

</CodeGroup>

Peer 相依套件：`vue` `^3.3.0`；`vue-router` `^4.5.1 || ^5.0.0`（選用，僅用於 `@i18n-micro/vue/router`）。發布的型別在 `skipLibCheck: false` 時需要 Vue 3.5.5 或更新版本；若使用一般範本設定 `skipLibCheck: true`，較舊的版本也能編譯。

## 設定 {#setup}

```ts
// src/main.ts
import { createApp } from 'vue'
import { createI18n } from '@i18n-micro/vue'
import App from './App.vue'
import en from './locales/en.json'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales: [
    { code: 'en', iso: 'en-US', displayName: 'English' },
    { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
  ],
  defaultLocale: 'en',
})

createApp(App).use(i18n).mount('#app')
```

`useI18n()` 需要 `locales` 與 `defaultLocale`：缺少時會拋出 `I18nLocalesKey not provided`。可將它們傳給 `createI18n`（如上所示）、傳給 `useI18n({ locales, defaultLocale })`，或透過 `app.provide(I18nLocalesKey, …)` 與 `app.provide(I18nDefaultLocaleKey, …)` 提供。

此外掛會全域註冊 `I18nT`、`I18nLink`、`I18nGroup` 與 `I18nSwitcher`，並在範本中加入 `$t`、`$ts`、`$tc`、`$tn`、`$td`、`$tdr`、`$has` 與 `$i18n`。在元件之外，實例為 `i18n.global`。其他選項請見[實例](/zh-Hant/integrations/overview#the-instance)；Vue 不支援 `routeMessages`，請使用 `addRouteTranslations`。

## 翻譯 {#translate}

```vue
<script setup lang="ts">
import { useI18n } from '@i18n-micro/vue'

const { t, tc, tn } = useI18n()
</script>

<template>
  <h1>{{ t('greeting', { name: 'Ada' }) }}</h1>
  <!-- Hello, Ada! -->
  <p>{{ tc('apples', 3) }}</p>
  <!-- 3 apples -->
  <p>{{ $t('nav.home') }} · {{ tn(1234.5) }}</p>
</template>
```

`useI18n()` 會回傳翻譯方法（`t`、`ts`、`tc`、`tn`、`td`、`tdr`、`has`）、`locale`（可寫入的 computed）、`getLocale`、`getLocales`、`defaultLocale()`、`getLocaleName`、`localePath`、`localeRoute`、`switchLocale`、`setRoute`、`getRoute`、`addTranslations`、`addRouteTranslations`、`mergeTranslations`、`resolveTranslations`、`setTranslation`、`clearCache` 與 `instance`。

你可以隨時載入更多字典；所有讀取這些字典的元件都會重新渲染：

```ts
const { addTranslations, addRouteTranslations, setRoute } = useI18n()

addTranslations('de', (await import('./locales/de.json')).default)
addRouteTranslations('en', 'about', { title: 'About us' })
setRoute('about') // t('title') now reads the 'about' dictionary first
```

## 切換語系 {#switch-locale}

```ts
const { locale, switchLocale } = useI18n()

locale.value = 'de' // only the locale
switchLocale('de') // the locale, then router.push to the localized current path
```

請在切換之前或之後載入該語系的字典；切換本身不會請求任何資料。

`<I18nGroup>` 會為其插槽提供帶前綴的 `t`。`<I18nT>` 內的鍵或一般的 `t()` 不會加上前綴：

```vue
<I18nGroup prefix="profile" v-slot="{ t }">
  <h2>{{ t('title') }}</h2>
  <!-- profile.title -->
</I18nGroup>
```

## 路由 {#routing}

vue-router 配接器位於子路徑中，因此主要進入點永遠不會匯入 `vue-router`：

```ts
// src/main.ts
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import { createI18n } from '@i18n-micro/vue'
import { createVueRouterAdapter } from '@i18n-micro/vue/router'
import App from './App.vue'
import Home from './pages/Home.vue'
import About from './pages/About.vue'
import en from './locales/en.json'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English' },
  { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
]

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/:locale(de)?', component: Home },
    { path: '/:locale(de)?/about', component: About },
  ],
})

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales,
  defaultLocale: 'en',
  routingStrategy: createVueRouterAdapter(router, locales, 'en'),
})

createApp(App).use(router).use(i18n).mount('#app')
```

`createVueRouterAdapter(router, locales, defaultLocale)` 會為預設語系以外的每個語系加上前綴（`/about`、`/de/about`），並將 `<I18nLink>` 渲染為 `RouterLink`。請自行從路由讀取語系，例如在 `router.beforeEach` 中，並設定 `i18n.global.locale.value`。你也可以稍後透過 `i18n.setRoutingStrategy(adapter)` 附加配接器；自訂配接器請參閱[路由器配接器](/zh-Hant/integrations/overview#router-adapter)。

## SSR {#ssr}

- 在每個請求的渲染函式內建立路由器、i18n 實例與應用程式。共用單一實例會讓某位訪客的語系洩漏給另一位訪客。
- 在伺服器上使用 `createMemoryHistory()`，從 URL 取得語系，並在 `renderToString` 之前載入其字典（以及備援語系的字典）。
- 將語系傳送給用戶端（例如放在 `window.__STATE__` script 中），並以相同的 `locale` 建立用戶端實例，讓 hydration 一致。
- `<I18nSwitcher>` 只在下拉選單開啟時才讀取 `window.location`，因此可以在伺服器上渲染。

`packages/vue/playground` 中有一組完整的 `entry-server.ts` / `entry-client.ts`。

## SEO head {#seo-head}

`useLocaleHead(options)` 會根據語系與路由器配接器建構 `lang`/`dir`、canonical、`hreflang` 與 `og:locale` 標籤。在路由變更時呼叫 `updateMeta()`，並將 `metaObject` 傳給你的 head 管理工具：

```ts
import { watch } from 'vue'
import { useRoute } from 'vue-router'
import { useHead } from '@unhead/vue'
import { useLocaleHead } from '@i18n-micro/vue'

const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
watch(() => route.fullPath, () => updateMeta(), { immediate: true })
useHead(metaObject)
```

選項：`baseUrl`（字串或函式）、`addDirAttribute`（預設為 `true`）、`addSeoAttributes`（預設為 `true`）、`identifierAttribute`（預設為 `'id'`）、`hreflangBaseLanguage`（預設為 `false`）。設定 `disabled: true` 或 `seo: false` 的語系不會產生 alternate 連結。

## API {#api}

| 匯出 | 進入點 |
| --- | --- |
| `createI18n`、`useI18n`、`useLocaleHead` | `@i18n-micro/vue` |
| `I18nT`、`I18nLink`、`I18nSwitcher`、`I18nGroup` | `@i18n-micro/vue` |
| `VueI18n`（實例類別）、`I18nInjectionKey`、`I18nLocalesKey`、`I18nDefaultLocaleKey` | `@i18n-micro/vue` |
| `defaultPlural`、`FormatService`、`interpolate` | `@i18n-micro/vue` |
| 型別：`I18nRoutingStrategy`、`Locale`、`Translations`、`PluralFunc`、`Params`、`Getter`、`CleanTranslation`、`LocaleCode`、`VueI18nOptions`、`UseI18nOptions`、`UseLocaleHeadOptions`、`I18nPlugin` | `@i18n-micro/vue` |
| `createVueRouterAdapter` | `@i18n-micro/vue/router` |

`TranslationKey` 不會從 `@i18n-micro/vue` 重新匯出；請從 `@i18n-micro/types` 匯入。完整簽章：[套件參考](/zh-Hant/api/packages/vue)。
