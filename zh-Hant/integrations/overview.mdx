`@i18n-micro/*` 套件將 Nuxt I18n Micro 的翻譯核心帶到 Vue、React、Preact、Solid、Astro、VitePress 與純 JavaScript。當您的應用程式不是 Nuxt 應用程式，或 Nuxt 之外的腳本或伺服器需要相同的翻譯檔案時，請使用它們。每個套件都共用同一種實例模型、同一份路由器轉接器契約，以及相同的四個元件，這些都在本頁統一說明。

路由器進入點是獨立的匯入，因此沒有使用路由器的應用程式永遠不會打包它。

每個套件在儲存庫中的 `packages/<name>/playground` 下都有一個 playground。

## 實例 {#the-instance}

`createI18n(options)` 會回傳一個實例，其中保存字典、目前的 locale 與目前的路由。各套件的選項都相同：

| 選項 | 型別 | 預設值 | 備註 |
| --- | --- | --- | --- |
| `locale` | `string` | 必填 | 作用中的 locale。 |
| `fallbackLocale` | `string` | `locale` | 當 `locale` 中缺少某個鍵時查詢。 |
| `messages` | `Record<locale, Translations>` | `{}` | 根層級字典（`'index'` 路由）。 |
| `routeMessages` | `Record<route, Record<locale, Translations>>` | `{}` | 路由字典。僅限 Runtime、React、Preact、Node 與 VitePress。 |
| `plural` | `PluralFunc` | `defaultPlural` | 自訂複數規則。 |
| `missingWarn` | `boolean` | `true` | 僅在開發環境中，於瀏覽器針對缺少的鍵發出 `console.warn`。 |
| `missingHandler` | `(locale, key, routeName) => void` | — | 取代警告而被呼叫。 |
| `numberFormats` | `Record<locale, Record<name, Intl.NumberFormatOptions>>` | — | 具名格式：`tn(9.5, 'currency')`。 |
| `datetimeFormats` | `Record<locale, Record<name, Intl.DateTimeFormatOptions>>` | — | 具名格式：`td(date, 'short')`。 |
| `timeZone` | `string` | 執行環境的時區 | `td` 日期所用的 IANA 時區；不影響 `tdr`。設定它可讓伺服器與瀏覽器算繪出相同的日期。 |
| `now` | `() => number` | `Date.now` | `tdr` 使用的時鐘。在 hydration 時傳入伺服器的時間，讓兩端算繪出相同的文字。 |
| `localeIso` | `Record<code, string>` | — | 用於複數規則的 BCP 47 標籤（`ua` → `uk-UA`）。React、Preact 與 Solid 會從 provider 的 `locales` 中的 `iso` 取得。 |

字典存放在 `i18n.storage.translations` 中，這是一個以 `locale:route`（`en:index`、`en:about`）為鍵的 `Map`。

鍵會先在目前路由的字典中查詢，再到根層級字典查詢，先針對 `locale`，再針對 `fallbackLocale`。缺少的鍵會回傳鍵本身（或您傳入的 `defaultValue`）。

```ts
i18n.addTranslations('en', { nav: { home: 'Home' } }) // root, deep-merged
i18n.addRouteTranslations('en', 'about', { title: 'About us' }) // route chunk
i18n.addTranslations('en', { nav: { home: 'Start' } }, false) // replace instead of merge
i18n.setRoute('about')
i18n.t('title') // 'About us'
i18n.t('nav.home') // 'Start' (root key, still visible on the route)
```

### 翻譯與格式化 {#translate-and-format}

| 方法 | 回傳值 |
| --- | --- |
| `t(key, params?, defaultValue?, routeName?)` | 插入 `{param}` 後的值（字串、數字、物件）。 |
| `ts(...)` | 與 `t` 相同，但以字串形式回傳。 |
| `tc(key, count \| params, defaultValue?)` | 複數形式。 |
| `tn(value, options \| name)` | 以作用中 locale 套用 `Intl.NumberFormat`。 |
| `td(value, options \| name)` | `Intl.DateTimeFormat`。 |
| `tdr(value, options?)` | 相對時間（`3 days ago`）。 |
| `has(key, routeName?)` | 當作用中 locale 擁有該鍵時為 `true`（路由或根層級字典；不檢查備援）。 |

`defaultPlural` 會以 `|` 分割值，並選取索引為 `count` 的形式，超出時取最後一個；負數、小數或 `NaN` 的 count 會選取最後一個形式。

自訂的 `plural` 會收到 `(key, count, params, locale, getter)`。請透過 `getter(key)` 讀取值；不要分割鍵：

```ts
import type { PluralFunc } from '@i18n-micro/vue'

const plural: PluralFunc = (key, count, params, _locale, getter) => {
  const value = getter(key)
  if (typeof value !== 'string') return null
  const forms = value.split('|').map((form) => form.trim())
  return (count === 1 ? forms[0] : forms[1] ?? forms[0])!.replace('{count}', String(count))
}
```

## 路由器轉接器 {#router-adapter}

SPA 套件不依賴任何路由器。路由器轉接器（`I18nRoutingStrategy`）會告訴它們如何讀取目前路徑、進行導覽以及建構在地化路徑。內建的轉接器會為除了 `defaultLocale` 以外的每個 locale 加上前綴（`/about`、`/de/about`）。

| 成員 | 必要 | 使用者 |
| --- | --- | --- |
| `getCurrentPath(): string` | 是 | 作用中連結檢查（依頁面判斷，查詢參數與 hash 不計入）、`switchLocale`（會保留它們） |
| `push({ path }): void` | 是 | `switchLocale`、未設定 `linkComponent` 的 `<I18nLink>`、`<I18nSwitcher>` |
| `replace({ path }): void` | 是 | — |
| `resolvePath(to, locale)` | 否 | `localePath`、`localeRoute`、`<I18nLink>`；若未提供，路徑會原樣回傳 |
| `linkComponent` | 否 | `<I18nLink>` 會算繪它（例如 `RouterLink`）而非 `<a>` |
| `getRoute()` | 否 | 供 SEO 輔助函式使用的 `{ fullPath, query }` |

在 Vue、React、Preact 與 Solid 中，`push` 與 `replace` 為必要項目。Astro 有自己的伺服器端轉接器，其中 `push`／`replace` 為選用（請參閱 [Astro](/zh-Hant/integrations/astro-package#router-adapter)）。

適用於任何基於 history 之路由器的最小轉接器：

```ts
import type { I18nRoutingStrategy } from '@i18n-micro/react'

const locales = ['en', 'de']
const stripLocale = (path: string) => path.replace(/^\/(en|de)(?=\/|$)/, '') || '/'

export const historyAdapter: I18nRoutingStrategy = {
  getCurrentPath: () => window.location.pathname + window.location.search + window.location.hash,
  push: ({ path }) => window.history.pushState({}, '', path),
  replace: ({ path }) => window.history.replaceState({}, '', path),
  resolvePath: (to, locale) => {
    const path = stripLocale(typeof to === 'string' ? to : to.path || '/')
    return locale === 'en' ? path : `/${locale}${path === '/' ? '' : path}`
  },
}
```

## 元件 {#components}

Vue、React、Preact 與 Solid 提供相同的四個元件。它們的 props 一致；React、Preact 與 Solid 會將其他 props 傳遞給根元素。

### `<I18nT>` {#&lt;i18nt&gt;}

| Prop | 型別 | 備註 |
| --- | --- | --- |
| `keypath` | `string` | 必填 |
| `params` | `object` | 插值的值 |
| `plural` | `number \| string` | 算繪 `tc(keypath, count)` |
| `number` | `number \| string` | 將 `tn(number)` 作為 `{number}` 傳入 |
| `date` | `Date \| string \| number` | 將 `td(date)` 作為 `{date}` 傳入 |
| `relativeDate` | `Date \| string \| number` | 將 `tdr(relativeDate)` 作為 `{relativeDate}` 傳入 |
| `tag` | `string` | 包裝元素，預設為 `span` |
| `html` | `boolean` | 將翻譯以 HTML 算繪；翻譯內容必須是可信任的，參數會被跳脫 |
| `defaultValue` | `string` | 代替缺少的鍵，且當 `hideIfEmpty` 隱藏空值時會直接算繪 |
| `hideIfEmpty` | `boolean` | 翻譯為空時不算繪任何內容 |
| `customPluralRule` | `PluralFunc` | 此元素的複數規則 |

只有一個格式化 prop 會生效，依此順序檢查：`number`、`date`、`relativeDate`、`plural`。

#### 豐富文字 {#rich-text}

`{placeholder}` 可以放入元素。在 Vue 中它是具名插槽；在 React、Preact 與 Solid 中，`components` prop 會依名稱提供元素，或回傳元素的函式。無論哪種方式，它都優先於同名的參數、在每個分支中皆可運作，且在重新排列預留位置順序的 locale 中依然有效。

```tsx
// { "terms": "I accept the {link} of {company}" }
<I18nT keypath="terms" params={{ company: 'ACME' }} components={{ link: <a href="/terms">terms</a> }} />
```

在 Solid 中，當預留位置重複出現時請傳入函式：一個節點只能放在一個位置。`children` 會取代文字，若為函式則會收到 `{ translation }`，就像 Vue 的預設插槽。`html` 會忽略以上所有內容。

### `<I18nLink>` {#&lt;i18nlink&gt;}

| Prop | 型別 | 備註 |
| --- | --- | --- |
| `to` | `string \| { path }` | 透過轉接器的 `resolvePath` 進行在地化 |
| `activeStyle` | 樣式物件 | 在目前頁面時合併到 `style` 之上；React、Preact 與 Solid 也會在上層區段套用它 |
| `localeRoute` | 函式 | 為此連結覆寫 `resolvePath` |

外部 URL（`https://`、`mailto:`、`tel:`）會算繪為 `<a target="_blank" rel="noopener noreferrer">`；您自己設定的 `target` 或 `rel` 優先。`onClick` 一律會執行。帶有修飾鍵的點擊、其他滑鼠按鍵或設定了 `target` 的情況，則交由瀏覽器處理。

### `<I18nSwitcher>` {#&lt;i18nswitcher&gt;}

一個列出已啟用 locale（`disabled: true` 的 locale 會被隱藏）的下拉選單，附有內嵌預設樣式。其項目是連結，帶有來自 locale 的 `lang`、`hreflang` 與 `dir`。預設情況下，點擊項目會設定 locale，並以在地化後的目前路徑呼叫轉接器的 `push`；`switchLocale` prop 可取代此動作。若有 `localeRoute` 但沒有路由器，瀏覽器會跟隨該連結。按下 Escape 或點擊外部會關閉選單。

| Prop | 備註 |
| --- | --- |
| `locales`、`currentLocale`、`getLocaleName` | 覆寫所提供的值 |
| `switchLocale(code)` | 取代內建的切換 |
| `localeRoute` | 取代 `resolvePath` |
| `customLabels` | `{ de: 'DE' }` |
| `customWrapperStyle`、`customButtonStyle`、`customDropdownStyle`、`customItemStyle`、`customLinkStyle`、`customActiveLinkStyle`、`customDisabledLinkStyle`、`customIconStyle` | 樣式覆寫 |

### `<I18nGroup>` {#&lt;i18ngroup&gt;}

一個 `<div class="i18n-group">`，會將加上前綴的 `t` 傳給其子元素。它**不會**為其中的 `<I18nT>` 或 `t()` 呼叫加上前綴；只有它向下傳遞的 `t` 會帶有前綴。

| Prop | 備註 |
| --- | --- |
| `prefix` | 必填，例如 `'profile'` |
| `groupClass` | 包裝元素上的額外 class |

加上前綴的 `t` 在 Vue 中透過作用域插槽（`v-slot="{ t }"`）提供，在 React、Preact 與 Solid 中則透過 render-prop 子元素（`{({ t }) => …}`）提供。

## 型別化的鍵 {#typed-keys}

`t()` 接受任何字串。若要為您的鍵取得自動完成，請使用[型別產生器](/zh-Hant/integrations/types-generator)產生宣告。鍵只會被建議而非強制，且參數沒有型別。

## 與 Nuxt 模組比較 {#compared-with-the-nuxt-module}

這些套件沒有基於檔案的路由、沒有伺服器中介軟體，也沒有翻譯載入器：由您決定何時載入 JSON（`import`、`fetch`，或在伺服器上使用 `@i18n-micro/node`）以及要使用哪個路由器轉接器。Locale 偵測、SEO meta 與路由產生是 Nuxt 的功能；Astro 有自己的偵測中介軟體，以及用於 SEO 的 `useLocaleHead`。
