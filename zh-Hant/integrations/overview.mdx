# 整合

`@i18n-micro` 套件是為各種框架與環境整合而設計的、Nuxt I18n Micro 的輕量框架專屬版本。它們以極小的體積提供核心國際化功能,聚焦於基本翻譯功能與基礎元件。

## 概觀

這些整合套件是完整 Nuxt I18n Micro 模組的**縮小版**,僅包含國際化所需的核心功能:

- **核心翻譯功能** —— 基本翻譯方法、複數化與格式化
- **必要元件** —— 一小組用於常見 i18n 任務的 UI 元件
- **Router Adapter 模式** —— 透過 adapter 抽象進行彈性的路由整合
- **TypeScript 支援** —— 完整型別定義以支援型別安全的開發

與完整的 Nuxt 模組不同,這些套件:

- 不包含框架專屬的路由邏輯
- 需要你實作 router adapter 才能使用路由功能
- 聚焦於翻譯功能,而非框架整合
- 在可能情況下,設計為輕量且與框架無關

## 核心元件

所有框架套件皆包含以下必要元件:

### `<I18nT>`

用於渲染翻譯文字的翻譯元件,支援:

- **參數插值** —— 將佔位符替換為動態值
- **複數化** —— 依計數自動選擇複數形式
- **數字格式化** —— 依語系格式化數字
- **日期格式化** —— 格式化日期與相對時間
- **HTML 渲染** —— 可選的 HTML 內容渲染
- **預設值** —— 翻譯缺失時的 fallback 文字

**範例:**

```vue
<!-- Vue -->
<I18nT keypath="greeting" :params="{ name: 'World' }" />
```

```tsx
// React
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```tsx
// Solid
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```astro
<!-- Astro -->
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

### `<I18nLink>`

一個在地化連結元件,可自動處理 URL 中的語系前綴。特色:

- **自動路徑在地化** —— 依路由策略新增/移除語系前綴
- **Active 狀態偵測** —— 標示當前路由
- **外部連結支援** —— 自動偵測並處理外部 URL
- **路由整合** —— 若可用,使用 router adapter 的連結元件
- **自訂樣式** —— 支援 active 與 hover 狀態

**範例:**

```vue
<!-- Vue -->
<I18nLink to="/about" active-class="active">
  About Us
</I18nLink>
```

```tsx
// React
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```tsx
// Solid
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```astro
<!-- Astro -->
<I18nLink href="/about" class="nav-link">
  About Us
</I18nLink>
```

### `<I18nSwitcher>`

一個語言切換器元件,提供用於切換語系的下拉式或列表介面。特色:

- **自動語系清單** —— 由已設定的語系產生選項
- **當前語系標示** —— 視覺上標示作用中的語言
- **自訂標籤** —— 支援每個語系的自訂顯示名稱
- **路由整合** —— 自動導覽到在地化路徑
- **無障礙** —— 適當的 ARIA 屬性與鍵盤操作

**範例:**

```vue
<!-- Vue -->
<I18nSwitcher />
```

```tsx
// React
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```tsx
// Solid
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```astro
<!-- Astro -->
<I18nSwitcher />
```

### `<I18nGroup>`

用於將翻譯以共同前綴分組的元件,方便依頁面或功能組織翻譯。特色:

- **前綴作用域** —— 自動為群組內所有翻譯鍵加上前綴
- **巢狀群組** —— 支援翻譯群組的巢狀
- **整潔組織** —— 有助維持翻譯結構井然有序

**範例:**

```vue
<!-- Vue -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

```tsx
// React
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```tsx
// Solid
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```astro
<!-- Astro -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

## 共用的 `createI18n` 選項 \{#create-i18n-options\}

每個框架套件建立方式相同 —— 只有選項型別以框架命名(`ReactI18nOptions`、`SolidI18nOptions` 等)。選項本身完全相同:

| 屬性             | 型別                                                       | 必要 | 預設              | 說明                                              |
| ---------------- | ---------------------------------------------------------- | ---- | ----------------- | ------------------------------------------------- |
| `locale`         | `string`                                                   | ✅   | -                 | 當前語系代碼(例如 `'en'`)                       |
| `fallbackLocale` | `string`                                                   | ❌   | 與 `locale` 相同  | 翻譯缺失時的 fallback 語系                        |
| `messages`       | `Record<string, Translations>`                             | ❌   | `\{\}`             | 初始翻譯訊息                                       |
| `plural`         | `PluralFunc`                                               | ❌   | `defaultPlural`   | 自訂複數化函式                                    |
| `missingWarn`    | `boolean`                                                  | ❌   | `true`            | 為缺失翻譯顯示主控台警告                          |
| `missingHandler` | `(locale: string, key: string, routeName: string) => void` | ❌   | -                 | 缺失翻譯的自訂處理器                              |

除此以外皆為框架專屬,並記載於各套件頁面。

## Router Adapter 抽象

所有框架套件皆使用 **router adapter 模式**,將 i18n 功能與特定路由實作解耦。此設計可帶來:

- **彈性** —— 可使用任何路由函式庫,甚至不使用路由
- **框架獨立** —— 將路由邏輯保留在你的應用中,而非 i18n 套件中
- **輕量核心** —— i18n 套件保持精簡且聚焦

### 實作 Router Adapter

要使用路由功能,你需要實作 `I18nRoutingStrategy` 介面:

```typescript
interface I18nRoutingStrategy {
  getCurrentPath: () => string
  linkComponent?: Component
  push: (target: { path: string }) => void
  replace: (target: { path: string }) => void
  resolvePath?: (to: string | { path?: string }, locale: string) => string | { path?: string }
  getRoute?: () => { fullPath: string; query: Record<string, unknown> }
}
```

各套件文件皆包含為熱門路由實作 adapter 的完整範例:

- **Vue**:Vue Router adapter 範例
- **React**:React Router adapter 範例
- **Solid**:Solid Router adapter 範例
- **Astro**:檔案式路由 adapter 範例

## 核心功能

所有套件皆共享以下核心功能:

### 翻譯方法

- `t()` —— 具參數插值的基本翻譯
- `ts()` —— 一律回傳字串的翻譯
- `tc()` —— 支援複數化的翻譯
- `tn()` —— 數字格式化
- `td()` —— 日期格式化
- `tdr()` —— 相對時間格式化
- `has()` —— 檢查翻譯鍵是否存在

### 語系管理

- **語系切換** —— 以程式切換目前語系
- **Fallback 語系** —— 翻譯缺失時自動 fallback
- **路由專屬翻譯** —— 頁面層級的翻譯組織
- **翻譯快取** —— 智慧快取以提升效能

### TypeScript 支援

所有套件皆提供:

- 完整 TypeScript 定義
- 型別安全的翻譯鍵(需搭配 types generator)
- IDE 的 IntelliSense 支援
- 編譯期錯誤檢查
