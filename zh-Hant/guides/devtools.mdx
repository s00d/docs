# 🛠️ `nuxt-i18n-micro` 中的 DevTools

## Vue DevTools(瀏覽器擴充功能)

在開發模式下,模組可透過 `@vue/devtools-api` 註冊 **Vue DevTools** 的自訂檢視器與時間軸。這與下方的 Nuxt DevTools 頁籤是分開的。

| 工具 | 適合用於 |
|------|----------|
| **Vue DevTools** | 即時語系、記憶體內翻譯快取、`$t` 時間軸(`debug: true`)、缺失鍵事件 |
| **Nuxt DevTools 頁籤** | 在硬碟上編輯 JSON 檔、設定總覽、匯入/匯出 |

vue-devtools 外掛僅在 `nuxt dev` 期間註冊(不會出現在生產建置中)。主外掛中僅用於開發的橋接狀態,會透過 `import.meta.dev` 的死碼消除被移除。

在保留 Nuxt 頁籤的同時停用瀏覽器整合:

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

詳細的 `$t` 時間軸事件需搭配 `debug: true`。

## 📖 什麼是 Nuxt DevTools?

DevTools 是無縫整合到 `nuxt-i18n-micro` 模組中的強大開發助手。它提供直覺的介面來管理在地化與翻譯工作,讓你的工作流程更快、更有效率。它是為重視便利性的開發者所設計,連結了編碼與執行時管理之間的落差。

## 🌟 `nuxt-i18n-micro` 中 DevTools 的主要功能

### 1. **語系管理**

輕鬆瀏覽、選取並管理應用中的語系。無論你使用單一或多種語言,DevTools 都提供集中式的介面來處理所有在地化設定。

### 2. **翻譯編輯**

透過內建 JSON 編輯器直接編輯翻譯檔。無需外部工具,即可即時更新變更,不打斷工作流程。

### 3. **檔案匯入與匯出**

簡化翻譯檔管理流程:

- **匯出**:將翻譯儲存為 JSON 檔以進行備份或外部使用。
- **匯入**:將更新後的翻譯檔載入專案,保持內容最新。

### 4. **即時預覽**

在開發環境中立即查看變更。此功能可確保翻譯與設定在上線前是正確的。

### 5. **無縫的 Nuxt 整合**

DevTools 與 `nuxt-i18n-micro` 原生協作,不需額外設定即可強化其能力。它可在維持 Nuxt 模組化與彈性結構的同時,配合你的在地化需求。

---

## 🛠️ 為什麼使用 DevTools?

Nuxt DevTools 對於需要在地化的專案是不可或缺的補強。它可幫助開發者:

- **節省時間**:自動化檔案管理與格式驗證等重複性工作。
- **減少錯誤**:提供安全、直覺的翻譯編輯環境。
- **改善協作**:讓非開發人員也能輕鬆管理翻譯。
- **精簡流程**:將多項在地化工作整合於單一介面。

---

## 🚀 掌握在地化工作

有了整合於 `nuxt-i18n-micro` 中的 Nuxt DevTools,管理多語應用變得直觀且高效。無論是微調翻譯或新增語系,DevTools 都能提供你打造精緻、使用者友善體驗所需的工具。
