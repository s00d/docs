# 🛠️ `nuxt-i18n-micro` 中的 DevTools

## Vue DevTools（瀏覽器擴充功能）

在開發模式下，模組可透過 `@vue/devtools-api` 註冊 **Vue DevTools** 自訂 inspector 與 timeline。這與下方的 Nuxt DevTools 分頁分開。

| 工具 | 適用情境 |
|------|----------|
| **Vue DevTools** | 目前作用中的語系、記憶體翻譯快取、`$t` timeline（`debug: true`）、缺失鍵事件 |
| **Nuxt DevTools 分頁** | 編輯磁碟上的 JSON 檔案、設定總覽、匯入／匯出 |

vue-devtools 外掛僅在 `nuxt dev` 期間註冊（正式建置不會）。主外掛中僅用於開發的 bridge state 會被 `import.meta.dev` 死程式碼消除機制移除。

若要停用瀏覽器整合、但保留 Nuxt 分頁：

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

詳細的 `$t` timeline 事件需要 `debug: true`。

## 📖 什麼是 Nuxt DevTools？

DevTools 是一款強大的開發輔助工具，已無縫整合進 `nuxt-i18n-micro` 模組。它為在地化與翻譯任務提供直覺介面，讓你的工作流程更快、更有效率。它專為重視便利性的開發者設計，是程式撰寫與執行時管理之間的橋樑。

## 🌟 `nuxt-i18n-micro` 的 DevTools 主要功能

### 1. **語系管理**

輕鬆瀏覽、選擇並管理應用中的語系。無論你使用單一語言或多語系，DevTools 都提供集中式的中樞管理所有在地化設定。

### 2. **翻譯編輯**

透過整合的 JSON 編輯器直接編輯翻譯檔。這免除了對外部工具的依賴，讓你能即時更新，不會打斷工作流程。

### 3. **檔案匯入與匯出**

簡化翻譯檔的管理流程：

- **匯出**：將翻譯儲存為 JSON 檔以進行備份或外部使用。
- **匯入**：將更新後的翻譯檔載入專案，讓內容保持最新。

### 4. **即時預覽**

在開發環境中即時檢視變更。此功能可讓你在上線前確認翻譯與設定的正確性。

### 5. **與 Nuxt 無縫整合**

DevTools 原生支援 `nuxt-i18n-micro`，無需額外設定即可強化模組能力。它會依你的在地化需求調整，同時保留 Nuxt 的模組化與彈性架構。

## 🛠️ 為什麼要使用 DevTools？

對於需要在地化的專案而言，Nuxt DevTools 是不可或缺的擴充。它為開發者帶來：

- **節省時間**：自動化檔案管理與格式驗證等重複任務。
- **降低錯誤**：提供安全且直覺的翻譯編輯環境。
- **改善協作**：讓非開發者也能輕鬆管理翻譯。
- **精簡流程**：將多個在地化任務整合到單一介面。

## 🚀 掌握你的在地化

有了整合進 `nuxt-i18n-micro` 的 Nuxt DevTools，管理多語系應用變得直覺又有效率。無論是微調翻譯或新增語系，DevTools 都能提供所需的工具，協助你打造精緻、友善的使用者體驗。
