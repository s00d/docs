# 在元件中使用翻譯

一旦模組安裝並設定完成,你便可以在 Vue 範本與 script 中呼叫 `$t('your_key')` 來顯示翻譯。

## 1. 根層級與頁面專屬翻譯檔

1. **根層級**翻譯直接位於 `/locales` 資料夾下(例如 `/locales/en.json`、`/locales/fr.json`)。在建置期,它們會自動合併到每個頁面專屬檔中,讓所有頁面都可使用。
2. **頁面專屬**翻譯位於 `/locales/pages/...`,對應你的 Nuxt pages 資料夾結構:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. 在範本中使用 `$t`

在你的 `.vue` 檔中,可以直接在範本中使用 `$t`:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
若鍵指向巢狀 JSON 節點,`$t` 可能會回傳**物件**(例如 `$t('header')` → `\{ title: "Hi" \}`)。在範本中會呈現為 `[object Object]`。若需要保證是字串,請使用 `$ts`;或提供更明確的鍵,例如 `$t('header.title')`。詳情請見 [API 參考 —— $t vs $ts](/api/methods#t)。
</Tip>

## 3. 切換當前語系

要在應用中切換語言,可從 `useI18n()` 取得 `$locale` 並指派新的代碼:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. 巢狀鍵與佔位符

- **巢狀鍵**使用點記號,例如 `nested.key.deeper`。
- **佔位符**可讓你插入動態值:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. 提示與最佳實務

- **衝突的鍵**:若頁面專屬檔與根層級檔含有相同的鍵,以頁面專屬版本為優先(根翻譯在建置期作為基底合併)。
- **停用頁面檔**:若你不希望使用頁面專屬翻譯,可在 Nuxt 設定中設定 `disablePageLocales: true`,只使用 `/locales/*.json` 檔。
- **無需直接 import**:不需執行 `import \{ useI18n \} from 'nuxt-i18n-micro'`;模組的自動注入功能會為你處理。

就這樣!透過以上步驟,你可以快速**從根層級或頁面專屬 JSON 檔取得翻譯**,並使用 `$t` 在你的 Nuxt 應用中**顯示它們**。

## 其他資源

要探索更進階的功能,請務必參考:

1. **`<i18n-t>` 元件**  
   `<i18n-t>` 元件是 `$t` 的強大替代品,特別適合涉及巢狀元素、進階佔位符,以及更複雜翻譯結構的情境。

- **文件**:[i18n-t](/api/components/i18n-t)

2. **`useI18n` Composable**  
   `useI18n` composable 提供了完整的函式與響應式屬性,用來管理翻譯、處理語系切換、格式化等。

- **文件**:[useI18n](/api/composables/use-i18n)
