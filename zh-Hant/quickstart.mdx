## 🚀 快速開始

### 安裝

在你的 Nuxt 應用中安裝此模組：

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

### 基本設定

將模組加入你的 `nuxt.config.ts`：

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

<Tip>
- **根層檔案**（`locales/en.json` 等）用於整個應用共享的翻譯（選單、頁尾、通用 UI）。當 `translationPayloads.mode: 'premerged'`（預設）啟用時，這些檔案會在建置期被合併進每個頁面。
- **頁面專屬檔案**（`locales/pages/<route>/<locale>.json`）僅屬於特定頁面的翻譯，只在造訪該頁面時載入。
- **動態路由**：`pages/articles/[id].vue` 會對應到 `locales/pages/articles-id/`（方括號會被換成連字號）。
- **自動產生**：所有翻譯檔案在 `nuxt dev` 期間若缺失都會自動建立。
</Tip>

<Info>
此模組同時支援兩種目錄結構：

- **頁面**：`pages/**/*.vue`（Nuxt 3）或 `app/pages/**/*.vue`（Nuxt 4）
- **翻譯檔**：預設將 `locales/` 放在**專案根目錄**（建議慣例），不要放在 `app/` 內

```tree
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   ├── en.json
│   └── pages/
└── nuxt.config.ts
```

也可以選擇集中放置：`i18n: \{ translationDir: 'app/locales' \}`（請參考 [fixture `n3`](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/n3)）。

若要使用選用的 CLI 輔助工具 `text-to-i18n`，請使用 [`nuxt-i18n-micro-cli` ≥ 2.1.1](/guides/cli#-text-to-i18n-command)，如此才能從專案根目錄掃描 `app/pages` 與 `app/components`。
</Info>

### 基本用法

在你的元件中使用翻譯：

```vue
<template>
  <div>
    <h1>{{ $t('welcome') }}</h1>
    <p>{{ $t('description', { name: 'World' }) }}</p>

    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" @click="$switchLocale(locale.code)">
        {{ locale.code }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useI18n } from '#imports'

const { $t, $getLocales, $switchLocale } = useI18n()
</script>
```
