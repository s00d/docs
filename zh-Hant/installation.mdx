## 需求

- **Node.js**:18 或更新版本。
- **Nuxt**:3.x 或 4.x。

此模組同時支援 Nuxt 3 專案佈局(`pages/**/*.vue`)與 Nuxt 4 佈局(`app/pages/**/*.vue`)。依照慣例,翻譯放在專案根目錄(`locales/`),即使使用 Nuxt 4 的 `app/` 目錄也一樣。

## 安裝 Nuxt 模組

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

在 `nuxt.config.ts` 中註冊:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

完整說明請參閱[快速開始](/quickstart),或查看[設定參考](/guides/configuration)了解所有選項。

## 專案佈局

預設情況下,此模組預期的結構為:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

根層級檔案會在建置期合併到每個頁面專屬的檔案。在 `nuxt dev` 期間,缺失的頁面專屬檔案會自動建立。

## Nuxt 4 佈局

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

若要將翻譯同置於 `app/` 下,設定 `translationDir: 'app/locales'`。

## 生態系套件

| 套件 | 用途 |
| --- | --- |
| [`@i18n-micro/vue`](/integrations/vue) | Vue 3 整合(獨立使用,不需 Nuxt)。 |
| [`@i18n-micro/react`](/integrations/react) | React 整合。 |
| [`@i18n-micro/preact`](/integrations/preact) | Preact 整合。 |
| [`@i18n-micro/solid`](/integrations/solid) | SolidJS 整合。 |
| [`@i18n-micro/astro`](/integrations/astro) | Astro 整合。 |
| [`@i18n-micro/node`](/integrations/nodejs) | Node.js 伺服器端載入器。 |
| [`@i18n-micro/types-generator`](/integrations/types-generator) | 由翻譯檔產生 TypeScript 型別。 |
| [`@i18n-micro/devtools-ui`](/integrations/devtools-ui) | 框架無關的 DevTools 面板。 |

共用的內部套件會經由相依關係一併引入。

## TypeScript

此模組會根據你的預設語系檔案,為 `useI18n`、`$t` 及相關輔助函式產生環境型別。此功能預設啟用(`types: true`)。

若要對翻譯鍵有更強的型別,請參閱 [`@i18n-micro/types-generator`](/integrations/types-generator)。
