description: "useI18nHead 可為單一頁面覆寫產生的 i18n SEO 標籤：取代或移除 canonical、hreflang 與 og 標籤，或加入您自己的標籤。"
---

`useI18nHead()` 會變更模組所產生的 SEO 標籤，且僅作用於單一頁面。當頁面比路由器更清楚狀況時使用它：只存在於部分 locale 的 CMS 文章、來自 API 的 canonical URL、額外的 `og:` 標籤。您會得到產生的標籤，並在其上合併您的覆寫內容。

## 簽章 {#signature}

```ts
useI18nHead(input?: MaybeRefOrGetter<I18nHeadInput | null>): { pageHead: any; resetPageHead: () => void }
```

為 i18n SEO head 標籤註冊頁面層級的覆寫。
由 `02.meta` 外掛合併在 `useLocaleHead` 的輸出之上。

當值來自 `$t`／`t` 時，建議使用 getter（`() => ({ … })`），以便在 locale 變更時重新解析。一般物件只會被求值一次，之後保持固定不變。

| 參數 | 型別 | 說明 |
| --- | --- | --- |
| `input` *（選用）* | `MaybeRefOrGetter<I18nHeadInput \| null>` |  |

它可搭配 [`meta: true`](/zh-Hant/api/module-options#meta)（預設值）運作：模組的 meta 外掛會在每次算繪 head 時，將輸入合併到 [`useLocaleHead`](/zh-Hant/composables/useLocaleHead) 的輸出之上。設定 `meta: false` 時則不會有任何東西讀取它。

當路由名稱變更時，覆寫內容會被重設。設定了 `disableMeta` 的頁面完全不會有 i18n 標籤，覆寫內容也包括在內。

## 輸入 {#input}

`I18nHeadInput`（來自 `@i18n-micro/types`）：

| 鍵 | 型別 | 效果 |
| --- | --- | --- |
| `htmlAttrs` | `Record<string, string>` | 合併至 `<html>` 屬性（`lang`、`dir`）。 |
| `meta` | `I18nHeadMeta[]` | 加在產生的標籤之後；會取代具有相同 `id`、`property` 或 `name` 的標籤。 |
| `link` | `I18nHeadLink[]` | 加在產生的連結之後；會取代具有相同 `id`，或相同 `rel` + `hreflang` 的連結。 |
| `replace.canonical` | `string \| false` | 取代 canonical 的 `href`，或移除該連結。 |
| `replace.hreflang` | `I18nHeadLink[] \| false` | 取代或移除**所有** `rel="alternate"` 連結，包括 `x-default`。 |
| `replace.xDefault` | `I18nHeadLink \| false` | 取代或移除 `x-default` 連結。 |
| `replace.ogLocale` | `string \| false` | 取代或移除 `og:locale`。 |
| `replace.ogUrl` | `string \| false` | 取代或移除 `og:url`。 |
| `replace.ogAlternates` | `string[] \| false` | 依這些 locale 代碼（透過 `og`／`iso`）重建 `og:locale:alternate`，略過目前的 locale、未知代碼，以及沒有 `og` 或 `iso` 值的代碼；或將其移除。 |
| `disable` | `I18nHeadDisableGroup[]` | 移除產生的群組：`'hreflang'`（不含 `x-default`）、`'x-default'`、`'canonical'`、`'og'`（`og:locale` + `og:url`）、`'og-alternates'`、`'html'`。 |

套用順序：先 `disable`，再 `replace`，然後是 `htmlAttrs`、`meta`、`link`。

## 範例 {#example}

一篇只存在於部分 locale 的文章，替代 URL 來自 API：

```vue
<script setup lang="ts">
const route = useRoute()
const { t } = useI18n()
const { data: article } = await useFetch<{ title: string; urls: Record<string, string> }>(`/api/articles/${route.params.slug}`)

useI18nHead(() => {
  if (!article.value) return null
  const codes = Object.keys(article.value.urls)
  return {
    meta: [{ property: 'og:title', content: article.value.title || t('blog.title') }],
    replace: {
      hreflang: codes.map((code) => ({ rel: 'alternate', hreflang: code, href: article.value!.urls[code]! })),
      ogAlternates: codes,
    },
  }
})
</script>
```

當值來自 `t()` 或非同步資料時，請像這裡一樣傳入 getter：它會在 locale 變更時重新執行。一般物件只會被讀取一次。
