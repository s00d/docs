---
title: "useLocaleHead"
description: "useLocaleHead 以物件形式建構 i18n SEO 標籤（lang、dir、canonical、hreflang、og:locale），供您傳給 useHead。"
---

`useLocaleHead()` 會為目前的路由建構 i18n head 標籤：`<html>` 上的 `lang` 與 `dir`、canonical 連結、含 `x-default` 的 `hreflang` 替代連結、`og:url`、`og:locale` 與 `og:locale:alternate`。當您設定 [`meta: false`](/zh-Hant/api/module-options#meta) 並自行管理 `useHead` 時使用它；在 `meta: true` 時，模組已經會註冊這些標籤，而個別頁面的變更則透過 [`useI18nHead`](/zh-Hant/composables/useI18nHead) 進行。

## 簽章 {#signature}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { build: () => LocaleHead; metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }, LocaleHead | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

目前路由的 SEO head 標籤：每個 locale 的 `hreflang` 替代連結加上 `x-default`、canonical 連結、`og:locale`，以及 `<html>` 上的 `lang`／`dir`。

只有在停用 `meta` 或需要調整預設值時才需要 — 在 `meta: true` 時，模組會自行註冊相同的標籤。

| 參數 | 型別 | 說明 |
| --- | --- | --- |
| `options` | `UseLocaleHeadOptions` |  |

**回傳值** — `metaObject`，一個持有可直接傳給 `useHead` 的 head 物件的 ref；`updateMeta` 會重新整理它；`build` 會依目前路由計算 head 物件（在 getter 中讀取時具反應性，例如 `useHead(() => build())`）

```ts
const { metaObject } = useLocaleHead({ addSeoAttributes: true })
useHead(metaObject)
```

## 選項 {#options}

| 選項 | 預設值 | 說明 |
| --- | --- | --- |
| `addDirAttribute` | `true` | 依 locale 的 `dir` 在 `<html>` 上設定 `dir`（若未設定則為 `'auto'`）。 |
| `identifierAttribute` | `'id'` | 用來識別每個標籤的屬性（`i18n-can`、`i18n-og`、`i18n-alternate-<hreflang>`、…），讓更新時會取代標籤而非新增標籤。 |
| `addSeoAttributes` | `true` | 輸出 canonical、`hreflang` 與 `og:` 標籤。設為 `false` 時只保留 `htmlAttrs`。 |
| `baseUrl` | `'/'` | 與每個 URL 結合的來源（origin）。相對 URL 請保留 `'/'`；絕對 URL 請傳入 `'https://example.com'`。 |
| `autoUpdate` | `true` | 當路由或 `i18n-locale` 狀態變更時重建 `metaObject`。 |

## 會輸出什麼 {#what-it-emits}

- 在沒有符合的路由（404）上，或作用中 locale 設定了 `disableMeta` 時，不輸出任何內容。
- Canonical 與 `og:url`：`$switchLocalePath(<active locale>)`，查詢參數會縮減為 [`canonicalQueryWhitelist`](/zh-Hant/api/module-options#canonicalquerywhitelist) 中的項目，並套用 [`trailingSlash`](/zh-Hant/api/module-options#trailingslash)。
- `hreflang`：頁面所存在的每個已啟用 locale 各一個連結，`hreflang = iso || code`，略過設定 `seo: false` 的 locale；設定 `hreflangBaseLanguage: true` 時，某語言的第一個地區 locale 也會輸出其純語言標籤。在 `no_prefix` 下不會輸出。
- `x-default`：預設 locale 的 URL，除非策略為 `no_prefix`、預設 locale 設定了 `seo: false`，或頁面不存在於該 locale 中。
- `og:locale`／`og:locale:alternate`：取自 locale 的 `og`，或由其 `iso` 轉換而來（`en-US` → `en_US`）；兩者皆不可用時會略過並顯示開發警告。

## 範例 {#example}

```ts
// app.vue, with i18n.meta: false
const { metaObject } = useLocaleHead({ baseUrl: 'https://example.com' })
useHead(metaObject)
```

`build()` 會回傳相同的物件但不包在 ref 中：`useHead(() => build())` 無需監看器即可保持反應性。
