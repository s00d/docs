---
title: "useI18nLocale"
description: "useI18nLocale 讀取並寫入語系狀態與語系 cookie — 是自訂語系偵測的進入點。"
---

`useI18nLocale()` 讓你存取應用程式所選定的語系：`i18n-locale` 狀態與語系 cookie。當外掛需要自行偵測語系（網域、使用者設定檔、標頭）時，請使用它，而不是手動寫入 `useState('i18n-locale')` 或 cookie。其有效性檢查會使用已啟用的語系，包含執行階段的覆寫。

## 簽章 {#signature}

```ts
useI18nLocale(): { getEffectiveLocale: (route: unknown, getLocaleFromRoute: GetLocaleFromRoute) => string; getLocale: () => string | null; getPreferredLocale: () => string | null; hashCookie: CookieRef; isValidLocale: (locale: string | null | undefined) => locale is string; locale: any; localeCookie: CookieRef; resolveInitialLocale: (options: ResolveInitialLocaleOptions) => string; setLocale: (locale: string | null) => void; syncLocale: (locale: string | null) => void; validLocales: string[] }
```

i18n 語系管理的集中式進入點。
結合了 useState('i18n-locale')、語系 cookie 與同步工具。

## 回傳值 {#returned-values}

| 成員 | 型別 | 說明 |
| --- | --- | --- |
| `locale` | `Ref<string \| null>` | `useState('i18n-locale')` 的 ref。 |
| `localeCookie` | `Ref<string \| null>` | [`localeCookie`](/zh-Hant/api/module-options#localecookie) cookie；當該選項為 `null` 時，為單純的 `{ value: null }`。 |
| `hashCookie` | `Ref<string \| null>` | hash 路由下的 `hash-locale` cookie；否則為 `{ value: null }`。 |
| `validLocales` | `string[]` | 已啟用語系的代碼。 |
| `setLocale(locale)` | `(locale: string \| null) => void` | 寫入狀態與 cookie。不會驗證，也不會載入翻譯。 |
| `syncLocale(locale)` | `(locale: string \| null) => void` | 僅寫入 cookie。 |
| `getLocale()` | `() => string \| null` | 先取狀態，再取偏好 cookie（hash 路由下為 hash cookie）。不會驗證。 |
| `getPreferredLocale()` | `() => string \| null` | 狀態與偏好 cookie 中第一個**有效**的值，或 `null`。 |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string` | 在 hash 路由下若已設定則為狀態；否則為 `getLocaleFromRoute(route)`。 |
| `resolveInitialLocale(options)` | `(options: ResolveInitialLocaleOptions) => string` | 依序為 `options.urlLocale`、有效的狀態、`options.serverLocale`，最後是路由的語系。當狀態無效時，會將結果存入狀態；在用戶端也會寫入 cookie。 |
| `isValidLocale(locale)` | `(locale) => locale is string` | `locale` 是否在 `validLocales` 中。 |

cookie 有效期為一年，並使用 `path: '/'` 與 `sameSite: 'lax'`。

## 範例 {#example}

```ts
// plugins/locale-from-domain.server.ts
export default defineNuxtPlugin({
  name: 'locale-from-domain',
  enforce: 'pre',
  setup() {
    const { setLocale, isValidLocale } = useI18nLocale()
    const host = useRequestURL().hostname // e.g. de.example.com
    const code = host.split('.')[0]
    if (isValidLocale(code)) setLocale(code)
  },
})
```

模組的載入器外掛會在啟動時讀取狀態，因此設定狀態的外掛必須先執行（`enforce: 'pre'`）。狀態如何與 URL、cookie 及 `Accept-Language` 競爭：[語系偵測](/zh-Hant/guide/locale-detection)。完整教學：[自訂偵測](/zh-Hant/guide/custom-auto-detect)。

`setLocale()` 不會切換畫面上的翻譯。若要變更目前頁面的語系，請呼叫 [`$switchLocale()`](/zh-Hant/api/methods#$switchlocale)。
