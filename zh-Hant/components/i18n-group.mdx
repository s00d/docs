---
title: "<i18n-group>"
description: "<i18n-group> 元件會為其插槽提供一個限定於鍵前綴範圍的 t 函式。"
---

`<i18n-group>` 會將一段標記限定在同一個鍵前綴之下。當某個區塊中的許多鍵共用同一前綴、而你不想重複撰寫時，就可以使用它。預設插槽會收到一個會自動加上前綴的 `t`。

## Props 與插槽 {#props-and-slot}

| Prop | 型別 | 預設值 | 說明 |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | 插槽內每次查詢所依據的鍵前綴。 |
| `groupClass` | `string` | `''` | 外層包裝元素的額外 class。 |

**\*** 必填。

### 插槽 {#slots}

| 插槽 | 繫結 | 說明 |
| --- | --- | --- |
| `default` | `prefix`, `t` | 接收 `prefix` 以及限定於該前綴的 `t` 函式。 |

## 行為 {#behaviour}

- 在插槽外層渲染 `<div class="i18n-group {groupClass}">`。
- `t(key, params)` 等同於針對目前路由的 `$t(prefix + '.' + key, params)`。
- 只有插槽的 `t` 受前綴限定：群組內的 `$t` 與巢狀 `<i18n-t>` 仍需使用完整的鍵。

## 範例 {#example}

```json
{
  "checkout": { "title": "Checkout", "items": "Items: {count}" }
}
```

```vue
<template>
  <i18n-group prefix="checkout" group-class="checkout">
    <template #default="{ t }">
      <h2>{{ t('title') }}</h2>
      <p>{{ t('items', { count: 3 }) }}</p>
    </template>
  </i18n-group>
</template>
```
