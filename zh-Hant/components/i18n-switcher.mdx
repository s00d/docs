title: "<i18n-switcher>"

---

`<i18n-switcher>` 會渲染一個顯示目前 locale 的按鈕，以及一個包含所有已啟用 locale（含目前 locale）的下拉選單。需要現成的語言選單時可使用它；若需要不同的標記結構，請使用 [`$getLocales`](/zh-Hant/api/methods#$getlocales) 與 [`$switchLocalePath`](/zh-Hant/api/methods#$switchlocalepath) 自行建構。每個項目都連結到目前頁面在該 locale 下的版本。

## Props 與 slots {#props-and-slots}

| Prop | 型別 | 預設值 | 說明 |
| --- | --- | --- | --- |
| `customLabels` | `Record<string, string>` | `() => ({})` | 每個 locale 代碼的顯示名稱，會覆寫 locale 設定中的 `displayName`。 |
| `customWrapperStyle` | `CSSProperties` | `() => ({})` | 外層容器的行內樣式。 |
| `customButtonStyle` | `CSSProperties` | `() => ({})` | 開啟下拉選單之按鈕的行內樣式。 |
| `customDropdownStyle` | `CSSProperties` | `() => ({})` | 下拉面板的行內樣式。 |
| `customItemStyle` | `CSSProperties` | `() => ({})` | 下拉選單中每個項目的行內樣式。 |
| `customLinkStyle` | `CSSProperties` | `() => ({})` | 項目內連結的行內樣式。 |
| `customActiveLinkStyle` | `CSSProperties` | `() => ({})` | 目前作用中 locale 之連結的行內樣式。 |
| `customDisabledLinkStyle` | `CSSProperties` | `() => ({})` | 當*目前* locale 在設定中為 `disabled: true` 時，該 locale 按鈕的行內樣式。 |
| `customIconStyle` | `CSSProperties` | `() => ({})` | 按鈕上插入符號圖示的行內樣式。 |

### Slots {#slots}

| Slot | 綁定 | 說明 |
| --- | --- | --- |
| `before-button` | — | 開啟下拉選單之按鈕前的內容。 |
| `before-selected-locale` | — | 按鈕內目前 locale 標籤前的內容。 |
| `after-selected-locale` | — | 按鈕內目前 locale 標籤後的內容。 |
| `before-dropdown` | — | 按鈕與下拉面板之間的內容。 |
| `before-dropdown-items` | — | 下拉選單頂端、locale 清單上方的內容。 |
| `before-item` | `locale` | 每個 locale 項目前的內容。 |
| `before-link-content` | `locale` | 連結內 locale 標籤前的內容。 |
| `after-link-content` | `locale` | 連結內 locale 標籤後的內容。 |
| `after-item` | `locale` | 每個 locale 項目後的內容。 |
| `after-dropdown-items` | — | 下拉選單底部、locale 清單下方的內容。 |
| `after-dropdown` | — | 下拉面板後的內容。 |

## 行為 {#behaviour}

- 列出所有未設定 `disabled: true` 的 locale，包含目前作用中的 locale。
- 每個項目都是指向 `$switchLocalePath(code)` 的 `<a>`。路徑會在 `app.baseURL` 下解析；位於其他網域的 locale `baseUrl` 則保持為絕對網址。連結的 `hreflang` 與 `lang` 設為 `iso || code`，locale 有設定時會帶有 `dir`，目前 locale 帶有 `aria-current="page"`，並具有 class `switcher-locale-<code>`。點擊會呼叫 `$switchLocale(code)` 並關閉下拉選單；若按住修飾鍵，則交由瀏覽器處理。
- 清單會以隱藏狀態保留在伺服器 HTML 中，讓爬蟲可以看到連結。按下 Escape 或點擊外部即可關閉。
- 標籤：依序為 `customLabels[code]`、locale 的 `displayName`，最後是代碼本身（並發出開發警告）。
- 樣式：精簡的行內預設樣式（有邊框的白色按鈕與面板，作用中項目為粗體藍色）。每個 `custom*Style` prop 會套用在其對應部分的預設樣式之後。按鈕具有 `i18n-switcher-button` 與 `language-switcher` class，容器為 `i18n-switcher-wrapper`，清單為 `i18n-switcher-dropdown`。定位使用邏輯 CSS 屬性，因此 `dir="rtl"` 可正常運作。

## 範例 {#example}

```vue
<template>
  <i18n-switcher
    :custom-labels="{ en: 'English', de: 'Deutsch' }"
    :custom-button-style="{ borderRadius: '4px' }"
  >
    <template #before-link-content="{ locale }">
      <img :src="`/flags/${locale.code}.svg`" alt="" width="16" />
    </template>
  </i18n-switcher>
</template>
```
