---
title: "執行期覆寫"
description: "透過環境變數或 runtimeConfig，為同一個建置的每個執行個體變更預設語系、後備語系或停用的語系。"
---

執行期覆寫讓同一個建置產物能在不同環境或租戶中以不同的語系設定執行，而無需重新建置。你可以變更預設語系、後備語系，以及哪些語系被停用。路由、重新導向、渲染與伺服器輔助函式都會使用覆寫後的值，伺服器渲染頁面上的瀏覽器也是如此。

## 使用環境變數設定覆寫 {#set-overrides-with-environment-variables}

```bash
NUXT_I18N_DEFAULT_LOCALE=de \
NUXT_I18N_FALLBACK_LOCALE=en \
NUXT_I18N_DISABLED_LOCALES=fr,it \
node .output/server/index.mjs
```

| 變數 | 別名 |
| --- | --- |
| `NUXT_I18N_DEFAULT_LOCALE` | `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE` |
| `NUXT_I18N_FALLBACK_LOCALE` | `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE` |
| `NUXT_I18N_DISABLED_LOCALES`（以逗號分隔） | `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES` |

伺服器會在啟動時讀取一次這些變數；變更後需重新啟動才會生效。在伺服器渲染的頁面上，瀏覽器會從伺服器取得解析後的值。使用 `ssr: false` 時沒有伺服器渲染，瀏覽器也沒有環境變數：此時只有 `runtimeConfig.public.i18nRuntime` 會生效，且瀏覽器會記錄下方的警告。

## 在 runtimeConfig 中設定覆寫 {#set-overrides-in-runtimeconfig}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

在 `runtimeConfig.public.i18nRuntime` 中設定的值，優先於同一欄位的 `NUXT_I18N_*` 變數。

請勿與建置期的 `DEFAULT_LOCALE` 變數混淆，後者會在建置時取代 `defaultLocale`，不需要執行期支援。

## 哪些可以變更、哪些不行 {#what-can-and-cannot-change}

| 設定 | 執行期 |
| --- | --- |
| `defaultLocale` | 在 `prefix` 與 `no_prefix` 下可以。在 `prefix_except_default` 與 `prefix_and_default` 下，它在建置時就已固定（其頁面即為無前綴的路由）；覆寫會被忽略並發出警告。 |
| `fallbackLocale` | 可以。 |
| `disabledLocales` | 會加到建置時已停用的語系中；永遠不會重新啟用任何語系。在 `prefix_except_default`／`prefix_and_default` 下，無法停用建置時的預設語系。 |
| `strategy` | 不行。執行期的策略會被忽略並發出警告；請為每種策略各建置一個產物。 |

無效的值絕不會讓應用程式壞掉。每種情況在每個伺服器程序中只會記錄一次警告：

- 停用所有語系會被忽略；
- 未啟用的 `defaultLocale` 會退回第一個已啟用的語系；
- 未啟用的 `fallbackLocale` 若建置時的值已啟用則保留該值，否則就沒有後備語系。

## 讀取實際生效的設定 {#read-the-effective-config}

```vue
<script setup lang="ts">
const { $getI18nConfig } = useNuxtApp()
const config = $getI18nConfig() // build config with overrides applied
</script>
```

請將它視為唯讀：在伺服器上它由所有請求共用，且在開發環境中會被凍結；瀏覽器端的副本則不會被凍結。從 `#build/i18n.strategy.mjs` 匯入設定會取得未套用覆寫的建置值。

## 停用的語系與靜態檔案 {#disabled-locales-and-static-files}

在執行期停用的語系，其路由與 payload 路由會回傳 404，但其 payload 檔案仍存在於 `.output/public/_locales/` 中，靜態檔案伺服器仍會回傳它們。若這些檔案必須無法被存取，請在建置時以 `disabled: true` 停用該語系。
