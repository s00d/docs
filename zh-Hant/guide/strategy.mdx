`strategy` 選項決定 locale 是否出現在 URL 中，以及對哪些 locale 生效。請在發布 URL 之前選定一次：之後再變更會改變所有連結。接著模組會在建置時產生在地化路由，而 `$localePath`、`<i18n-link>` 與切換器都會讀取這些路由。

## 四種策略 {#the-four-strategies}

![在各策略下 en（預設）與 de 的 /about 頁面；相同的 URL 列於下方文字中](/images/diagrams/strategies.svg)

**型別** `Strategies` · **預設值** `'prefix_except_default'`

用於 locale 前綴的 URL 路由策略。

- `'no_prefix'` — URL 中不含 locale；locale 儲存於 cookie。
- `'prefix_except_default'` — 除預設 locale 外，所有 locale 都加上前綴。
- `'prefix'` — 一律加上前綴，包含預設 locale。
- `'prefix_and_default'` — 與 `prefix` 相同，但預設 locale 也可以不帶前綴存取。

在 `defaultLocale: 'en'` 且 locale 為 `en`、`de` 時，`about` 頁面的 URL：

| 策略 | 英文 | 德文 | 不提供 |
| --- | --- | --- | --- |
| `prefix_except_default`（預設） | `/about` | `/de/about` | `/en` 與 `/en/about` 回傳 404 |
| `prefix` | `/en/about` | `/de/about` | `/about` 會重新導向至帶前綴的 URL |
| `prefix_and_default` | `/about` 與 `/en/about` | `/de/about` | — |
| `no_prefix` | `/about` | `/about` | locale 不在 URL 中 |

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix',
  },
})
```

策略在建置時即已固定：在執行階段覆寫它會被忽略並顯示警告（[執行階段覆寫](/zh-Hant/guide/runtime-overrides)）。

## 該選擇哪一種 {#which-one-to-choose}

- **`prefix_except_default`**：適用於大多數網站。既有的無前綴 URL 對預設語言仍可正常運作。
- **`prefix`**：所有語言地位相同；`/` 一律導向帶前綴的首頁。
- **`prefix_and_default`**：你需要 `/en/...` 與無前綴的 URL 同時可用，例如在兩者之間遷移時。無前綴的 URL 永遠不會被重新導向。
- **`no_prefix`**：需要登入的應用程式，或每個頁面在所有語言下只使用一個 URL。locale 來自 cookie 或 `?locale=`。搜尋引擎在每個 URL 只會看到一種語言，因此不會輸出 `hreflang` 替代連結。

如何為 URL 選擇 locale，以及訪客何時會被重新導向，請參閱 [Locale 偵測](/zh-Hant/guide/locale-detection)。

## 產生的路由 {#generated-routes}

在建置時，每個頁面都會取得其策略所需的路由紀錄。每筆紀錄都帶有 `meta.i18n = { name, locales }`：即它所顯示的頁面與所服務的 locale。連結、切換與重新導向都依據這些紀錄來決定，因此模組提供的 URL 一定是路由器會服務的 URL。

與頁面共用相同路徑的 locale 會共用一筆紀錄，例如 `/:locale(de|fr)/about`。擁有自己路徑的 locale 會取得自己的紀錄，命名為 `localized-<page>-<locale>`：

```ts
// nuxt.config.ts: German has its own path for the about page
i18n: {
  globalLocaleRoutes: { about: { de: '/ueber-uns' } },
}
// prefix_except_default, locales en (default), de, fr:
// about                 /about
// localized-about       /:locale(fr)/about
// localized-about-de    /:locale(de)/ueber-uns
```

自訂路徑、每頁的 locale 清單以及將頁面排除於在地化之外，請參閱[在地化路徑](/zh-Hant/guide/custom-locale-routes)與[頁面設定](/zh-Hant/guide/per-component-translations)。`localized-` 前綴由 [`localizedRouteNamePrefix`](/zh-Hant/api/module-options#localizedroutenameprefix) 設定。

<Warning>

**路由名稱是自動產生的** — 請勿在 `router.push({ name })` 中寫死 `localized-…` 名稱。請將頁面本身的名稱傳給 `$localeRoute` 或 `<i18n-link>`；它們會選出正確的紀錄。

</Warning>

## 連結到特定 locale 的頁面 {#linking-to-a-page-in-a-locale}

```vue
<script setup lang="ts">
const { localePath, localeRoute, switchLocalePath } = useI18n()

localePath({ name: 'about' }) // '/de/ueber-uns' while the page is German
localePath({ name: 'about' }, 'en') // '/about'
localePath('/about', 'de') // '/de/ueber-uns': a path is read as the page it shows
localeRoute({ name: 'products-id', params: { id: '42' } }, 'de') // resolved route: name, params, fullPath
switchLocalePath('fr') // the current page in French
</script>

<template>
  <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
  <NuxtLink :to="$switchLocalePath('de')">Deutsch</NuxtLink>
</template>
```

- 具名路由與路徑皆可使用。路徑會與產生的路由進行比對，因此任何 locale 形式的路徑都能被接受。
- 不提供該頁面的 locale（請參閱[頁面設定](/zh-Hant/guide/per-component-translations)中的 `locales`）會連結到該 locale 的首頁，而不是不存在的頁面。
- 每個 locale 專屬的參數（翻譯後的 slug）透過 `$setI18nRouteParams` 處理，請參閱[在地化路徑](/zh-Hant/guide/custom-locale-routes)。

函式簽章請見[方法](/zh-Hant/api/methods)。

## `no_prefix` 詳細說明 {#no_prefix-details}

- 在 `no_prefix` 下，[`localeCookie`](/zh-Hant/api/module-options#localecookie) 預設為 `'user-locale'`，因此重新載入後仍會保留選擇。
- `$switchLocale('de')` 會載入德文字典並取代目前的歷史紀錄項目；URL 不會改變。
- 每個 locale 的自訂路徑仍然有效：設定 `globalLocaleRoutes: { about: { de: '/ueber-uns' } }` 時，德文讀者會取得 `/ueber-uns`。無論訪客偏好為何，該 URL 一律以德文渲染；而限制於部分 locale 的頁面會以其中一種 locale 渲染。多個 locale 共用的路徑（`en` 與 `de` 都在 `/page/:id`）若偏好是其中之一，就會以偏好的 locale 渲染。偏好本身會保留：下一個頁面會恢復為該偏好。
- [`noPrefixRedirect: true`](/zh-Hant/api/module-options#noprefixredirect) 會將在預設 locale 中具有自訂路徑之頁面的原始路徑重新導向：導向訪客 locale 的自訂路徑，否則導向預設 locale 的自訂路徑（當 `en` 有 `/about-us` 時 `/about` → `/about-us`，cookie 為 `de` 時 → `/ueber-uns`）。沒有自己自訂路徑的 locale 會留在原始路徑並在該處渲染。含有參數的頁面不會被重新導向。

## 沒有 `pages/` 的應用程式 {#apps-without-pages/}

設定 `pages: false` 時，沒有可在地化的頁面路由。請只使用根翻譯檔案（`disablePageLocales: true`）；偵測、cookie 與 `$switchLocale` 仍然可以運作。儲存庫中 `test/fixtures/basic` 的 `pages-false` 變體是一個可運作的設定範例。
