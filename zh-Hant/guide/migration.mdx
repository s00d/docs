本頁說明如何將 `@nuxtjs/i18n` 應用程式對應到 nuxt-i18n-micro：包括選項、輔助函式與檔案結構。當你要在現有應用程式中替換模組時，請參考本頁。你的 URL 會保持不變（策略名稱相同），而翻譯則改放到每個頁面的 JSON 檔案中。

<Tip>

**要升級 nuxt-i18n-micro 本身嗎？** — 請參閱[升級](/zh-Hant/guide/upgrade)。

</Tip>

## 替換模組 {#swap-the-module}

```bash
npm uninstall @nuxtjs/i18n
npm install nuxt-i18n-micro
```

```ts
// nuxt.config.ts — before
export default defineNuxtConfig({
  modules: ['@nuxtjs/i18n'],
  i18n: {
    locales: [
      { code: 'en', language: 'en-US', file: 'en.json' },
      { code: 'de', language: 'de-DE', file: 'de.json' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    langDir: 'locales',
    detectBrowserLanguage: { useCookie: true, cookieKey: 'i18n_redirected', redirectOn: 'root' },
  },
})
```

```ts
// nuxt.config.ts — after
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    translationDir: 'locales',
    localeCookie: 'i18n_redirected',
    autoDetectPath: '/',
  },
})
```

## 選項 {#options}

| `@nuxtjs/i18n` | nuxt-i18n-micro |
| --- | --- |
| `locales[].code` | `locales[].code` |
| `locales[].language`（v9 之前為 `iso`） | `locales[].iso` |
| `locales[].name` | `locales[].displayName` |
| `locales[].dir` | `locales[].dir` |
| `locales[].domain` | `locales[].baseUrl`（包含協定的 origin） |
| `locales[].domainDefault` | `locales[].baseDefault` |
| `differentDomains`, `multiDomainLocales` | 不需要：只要 `baseUrl` 就能依主機路由，請參閱 [Layer 與網域](/zh-Hant/guide/layers#multiple-domains) |
| `locales[].file` / `files`, `langDir`, `lazy` | `translationDir`；檔案依名稱尋找，且一律依頁面載入 |
| `defaultLocale`, `strategy` | 名稱相同，四個值也相同 |
| `baseUrl` | `metaBaseUrl` |
| `customRoutes: 'config'` + `pages` | `globalLocaleRoutes` |
| `detectBrowserLanguage: false` | `redirects: false`（不重新導向）或 `autoDetectLanguage: false`（忽略標頭） |
| `detectBrowserLanguage.useCookie` / `cookieKey` | `localeCookie: '<name>'`（`null` 會關閉 cookie） |
| `detectBrowserLanguage.redirectOn: 'root'` | `autoDetectPath: '/'`（預設） |
| `detectBrowserLanguage.redirectOn: 'no prefix'` | `autoDetectPath: 'no_prefix'` |
| `detectBrowserLanguage.redirectOn: 'all'` | `autoDetectPath: '*'` |
| `vueI18n` 設定檔（`fallbackLocale`、`numberFormats`、`datetimeFormats`） | `i18n` 中的 `fallbackLocale`、`numberFormats`、`datetimeFormats` |

沒有 `alwaysRedirect`：設定 cookie 後，每次造訪 `/` 都會依照它導向。完整清單請見[模組選項](/zh-Hant/api/module-options)；偵測規則請見[語系偵測](/zh-Hant/guide/locale-detection)。

## 輔助函式與 composable {#helpers-and-composables}

| `@nuxtjs/i18n` / vue-i18n | nuxt-i18n-micro（範本／`useI18n()`） |
| --- | --- |
| `const { t } = useI18n()` | `const { t } = useI18n()`，範本中使用 `$t` |
| `t('key', count)`, `tc` | `$tc('key', count)` |
| `te('key')` | `$has('key')` |
| `n(value, 'currency')`, `d(date, 'short')` | `$tn(value, 'currency')`, `$td(date, 'short')` |
| — | `$tdr(date)`：相對時間（「3 天後」） |
| `locale.value` | `$getLocale()` |
| `locales.value` | `$getLocales()` |
| `setLocale('de')` | `$switchLocale('de')` |
| `useLocalePath()('about')` | `$localePath({ name: 'about' })` |
| `useLocaleRoute()` | `$localeRoute()` |
| `useSwitchLocalePath()('de')` | `$switchLocalePath('de')` |
| `useSetI18nParams()` | `$setI18nRouteParams()` |
| `useLocaleHead()` | 使用 `meta: true` 時自動處理；自訂 head 請用 [`useLocaleHead`](/zh-Hant/composables/useLocaleHead) |
| `defineI18nRoute({ paths: { de: '/ueber-uns' }, locales: [...] })` | `$defineI18nRoute({ localeRoutes: { de: '/ueber-uns' }, locales: [...] })` |
| `<NuxtLinkLocale to="about">` | `<i18n-link :to="{ name: 'about' }">` |
| `<i18n-t>` | `<i18n-t>`（插槽會填入 `{name}` 佔位符） |
| 伺服器路由中的 `$i18n` | `useTranslationServerMiddleware(event)`，請參閱[伺服器路由與 API](/zh-Hant/guide/server-side-translations) |

`useI18n()` 會自動匯入。`$defineI18nRoute` 必須保留 `$`：建置時會讀取這個呼叫。所有輔助函式：[方法](/zh-Hant/api/methods)。

## 翻譯檔案 {#translation-files}

將每個語系一個大檔案中的鍵，搬移到一個根檔案加上每個頁面各一個檔案：

```text
locales/
├── en.json              # keys used on many pages (nav, footer)
├── de.json
└── pages/
    ├── index/en.json    # keys of pages/index.vue
    └── about/en.json    # keys of pages/about.vue
```

將所有內容保留在根檔案中也可行，而且是最快的第一步。在拆分之前，請設定 `disablePageLocales: true`。請參閱[翻譯檔案](/zh-Hant/guide/translations)。

### 訊息語法 {#message-syntax}

| vue-i18n | nuxt-i18n-micro |
| --- | --- |
| `{name}` 具名插值 | 相同 |
| `car \| cars`（2 種形式：1 → 第一種） | 形式依數量從 0 開始選擇：請寫成 `no cars \| one car \| {count} cars` |
| `@:other.key` 連結訊息 | 不支援：請重複文字或在程式碼中組合 |
| `@.upper:` 修飾符 | 不支援：請在程式碼中格式化或使用 `<i18n-t>` |
| `{'@'}` 字面跳脫 | 不需要：只有 `{word}` 標記會被取代 |
| JS/TS 訊息檔案 | 僅限 JSON |

複數規則可透過 [`plural`](/zh-Hant/api/module-options#plural) 選項替換。

## 切換後的檢查 {#check-after-the-switch}

- 你原有的每個 URL 仍可解析；策略名稱一致，自訂路徑則移到 `globalLocaleRoutes` 或 `$defineI18nRoute`。
- 使用 `meta: true` 時，`hreflang`、canonical 與 `og:locale` 都是開箱即用；請移除手寫的版本。
- JSON 解析錯誤會記錄檔案路徑；在開發環境中，缺少的鍵會在瀏覽器主控台中記錄警告。
