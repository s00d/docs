本頁將帶領一個尚未使用 i18n 的 Nuxt 應用程式，完成具備語言切換器的翻譯頁面。您只需在專案開始時進行一次。最終您會得到在地化的 URL（`/about`、`/de/about`）、每個語系與頁面各一個 JSON 檔案，以及可在範本中使用的 `$t`。

## 安裝 {#install}

此模組需要 Nuxt 3.18 或更新版本（Nuxt 4 亦可）以及 Node 20 或更新版本。

<CodeGroup>

```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>

## 設定語系 {#configure-the-locales}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', displayName: 'English' },
      { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
      { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
    ],
    defaultLocale: 'en',
  },
})
```

這就是第一個應用程式所需的全部設定。預設值會提供：

- `strategy: 'prefix_except_default'`：預設語系沒有前綴（`/about`），其他語系則有（`/de/about`）。請參閱[路由策略](/zh-Hant/guide/strategy)。
- `translationDir: 'locales'`：翻譯檔案位於專案根目錄的 `locales/` 中，使用 Nuxt 4 的 `app/` 結構時亦同。
- `meta: true`：`hreflang`、canonical 與 `og:locale` 標籤，以及 `<html>` 上的 `lang` 與 `dir`。請參閱 [SEO](/zh-Hant/guide/seo)。
- 開啟 `/` 的訪客會被導向其瀏覽器要求的語言（`Accept-Language`）。請參閱[語系偵測](/zh-Hant/guide/locale-detection)。

`iso` 是用於 SEO 標籤的語言標記；`code` 則是出現在 URL 中的內容。所有選項都列於[模組選項](/zh-Hant/api/module-options)。

## 新增翻譯檔案 {#add-translation-files}

以 `nuxt dev` 啟動開發伺服器。當 Nuxt 解析頁面時，模組會為每個尚無檔案的語系與頁面建立一個空的 `{}` 檔案（可透過 [`disableWatcher`](/zh-Hant/api/module-options#disablewatcher) 關閉）：

```text
locales/
├── en.json            # root: keys every page can use
├── de.json
├── fr.json
└── pages/
    ├── index/         # pages/index.vue
    │   ├── en.json
    │   ├── de.json
    │   └── fr.json
    └── about/         # pages/about.vue
        ├── en.json
        ├── de.json
        └── fr.json
```

填寫根檔案與一個頁面檔案：

```json
// locales/en.json
{ "nav": { "home": "Home", "about": "About" } }
```

```json
// locales/pages/index/en.json
{ "welcome": "Welcome, {name}!", "items": "no items | one item | {count} items" }
```

頁面可以使用根鍵值與其自身的鍵值；發生衝突時以頁面自身的檔案為準。資料夾名稱依循路由名稱（`pages/articles/[id].vue` 對應 `locales/pages/articles-id/`）。[翻譯檔案](/zh-Hant/guide/translations)涵蓋了結構、後備機制與載入方式。

## 在頁面上使用 `$t` {#use-$t-on-a-page}

```vue
<!-- pages/index.vue -->
<script setup lang="ts">
const { t, tc, getLocale } = useI18n()

const title = t('nav.home') // 'Home'
</script>

<template>
  <h1>{{ $t('welcome', { name: 'Ada' }) }}</h1>
  <!-- Welcome, Ada! -->
  <p>{{ $tc('items', 3) }}</p>
  <!-- 3 items -->
  <p>{{ getLocale() }}</p>
  <!-- en -->
</template>
```

- 在範本中，每個輔助函式都可加上 `$` 使用（`$t`、`$tc`、`$localePath`……）。
- 在 `<script setup>` 中，`useI18n()` 會回傳相同的輔助函式，帶或不帶 `$` 皆可（`t` 與 `$t` 是同一個函式）。它會被自動匯入。
- `{name}` 預留位置會由參數物件填入。複數形式以 `|` 分隔；由數量決定使用哪個形式（0、1，以及其餘所有更大的數量使用最後一個）。

所有輔助函式都列於[方法](/zh-Hant/api/methods)。

## 在頁面之間連結並切換語系 {#link-between-pages-and-switch-locale}

```vue
<!-- components/AppHeader.vue -->
<template>
  <nav>
    <i18n-link :to="{ name: 'index' }">{{ $t('nav.home') }}</i18n-link>
    <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
    <i18n-switcher />
  </nav>
</template>
```

- [`<i18n-link>`](/zh-Hant/components/i18n-link) 是指向目前語系頁面的 `NuxtLink`：在 `/de` 上，about 連結會前往 `/de/about`。
- [`<i18n-switcher>`](/zh-Hant/components/i18n-switcher) 是列出已啟用語系的下拉選單；它會讓訪客停留在同一頁面。
- 若是您自己的按鈕，請呼叫 `$switchLocale('de')`，它會導覽至目前頁面的德文版本並記住此選擇。若是一般的 `NuxtLink`，請使用 `$localePath({ name: 'about' })` 或 `$switchLocalePath('de')`。

## 檢查結果 {#check-it}

執行 `nuxt dev` 並開啟：

| URL | 顯示內容 |
| --- | --- |
| `/` | 英文首頁（若您的瀏覽器偏好德文，則重新導向至 `/de`） |
| `/de` | 德文首頁 |
| `/de/about` | 德文 about 頁面 |
| `/en/about` | 404：在 `prefix_except_default` 下，預設語系沒有前綴 |

對 JSON 檔案的編輯會直接套用至已開啟的頁面，無需重新載入。
