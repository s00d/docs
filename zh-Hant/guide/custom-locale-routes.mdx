---
title: "在地化路徑"
description: "使用 localeRoutes 或 globalLocaleRoutes 為頁面設定各 locale 不同的 URL，包括動態參數與各 locale 專屬的 slug。"
---

預設情況下，每個 locale 都在相同的路徑提供頁面：`/en/about`、`/de/about`。在地化路徑讓每個 locale 使用自己的用詞，例如 `/de/ueber-uns`，而頁面檔案保持不變。您可以在頁面中使用 `$defineI18nRoute` 設定，或在 `nuxt.config.ts` 中一次為多個頁面設定。

## 在頁面中 {#in-the-page}

```vue
<!-- pages/about.vue -->
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  localeRoutes: {
    de: '/ueber-uns',
    fr: '/a-propos',
  },
})
</script>
```

在 `prefix_except_default` 且 `defaultLocale: 'en'` 的情況下，頁面會回應 `/about`、`/de/ueber-uns` 與 `/fr/a-propos`。沒有對應項目的 locale 會保留預設路徑。撰寫路徑時請勿包含 locale 代碼：前綴由[策略](/zh-Hant/guide/strategy)加上，而以 locale 代碼開頭的路徑會記錄一則警告。此呼叫還接受哪些內容，請參閱[頁面設定](/zh-Hant/guide/per-component-translations)。

## 在 nuxt.config 中 {#in-nuxt-config}

[`globalLocaleRoutes`](/zh-Hant/api/module-options#globallocaleroutes) 可對任何頁面做相同的事，以頁面路徑為鍵（若不以斜線開頭，則以路由名稱為鍵）：

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    globalLocaleRoutes: {
      '/about': { de: '/ueber-uns' },
      '/about/team': { de: '/ueber-uns/team' },
      '/admin': false, // not localized: one /admin route, no locale prefix
    },
  },
})
```

當頁面設定了 `localeRoutes`，而 `globalLocaleRoutes` 中也有相同的鍵時，以設定檔中的項目為準。

## 動態參數 {#dynamic-params}

參數可使用任何 Nuxt 格式撰寫：`[id]`、`[[page]]`、`[...slug]` 或 `:id()`。參數名稱必須與頁面檔案相符。

```ts
// pages/products/[...slug].vue
$defineI18nRoute({
  localeRoutes: {
    en: '/our-products/[...slug]',
    de: '/unsere-produkte/[...slug]',
  },
})
```

巢狀頁面可使用絕對子路徑（`/ueber-uns/team`），或相對於父頁面在地化路徑的路徑（`team`）。

## 連結到在地化頁面 {#linking-to-localized-pages}

無論您傳入路由名稱或一般路徑，連結都會解析為目標 locale 的在地化路徑：

```vue
<template>
  <i18n-link :to="{ name: 'about' }">About</i18n-link>
  <i18n-link to="/about">About</i18n-link>
  <!-- de: both render /de/ueber-uns -->
  <NuxtLink :to="$localePath('/about', 'de')">Deutsch</NuxtLink>
</template>
```

路由名稱來自檔案路徑（`pages/about/team.vue` 為 `about-team`），除非您透過 `definePageMeta({ name })` 自行設定。

## 各 locale 專屬的 slug {#per-locale-slugs}

當 slug 本身在各 locale 間不同時（`/our-products/red-shoe` 與 `/de/unsere-produkte/roter-schuh`），請在資料載入後透過 `$setI18nRouteParams` 告訴語言切換器要使用哪些參數：

```vue
<script setup lang="ts">
const { $setI18nRouteParams } = useNuxtApp()
const route = useRoute()

const { data: product } = await useFetch(`/api/products/${route.params.slug}`)

if (product.value) {
  $setI18nRouteParams({
    en: { slug: product.value.slugEn },
    de: { slug: product.value.slugDe },
  })
}
</script>
```

之後 `$switchLocalePath('de')` 與 `<i18n-switcher>` 就會連結到 `/de/unsere-produkte/roter-schuh`。鍵為 locale 代碼，值為依名稱指定的參數（與頁面檔案中相同）。

版面配置中的切換器會在頁面的非同步 setup 執行到這裡之前就完成算繪，因此在算繪結束時，模組會改寫 `<i18n-switcher>` 的連結，無論它位於 `app.vue` 或頁面中皆然。如此一來，伺服器 HTML、沒有 JavaScript 的訪客以及第一次用戶端算繪的結果都會一致。為此請在 SSR 期間設定參數：若使用 `lazy` 或 `server: false`，連結只會在 hydration 之後才變更。Nuxt 的 SSR 串流會在參數確定之前送出 HTML，因此在這種情況下，第一份 HTML 中的連結會保留 URL 本身的參數。

只有切換器本身的連結會被改寫。手動撰寫的 `$switchLocalePath` 連結必須在參數設定之後才算繪，因此請將它放在設定參數的頁面中，同樣放在 `await` 之後。若放在版面配置中，它會先被算繪：其伺服器 HTML 會保留 URL 的參數，而 hydration 會發出不一致的警告。在那裡請使用 `<i18n-switcher>`，並透過其插槽與 `custom*Style` 屬性調整外觀。

參數屬於設定它們的頁面：

- 當前往其他路徑的導覽完成時，參數會被捨棄，因此每個頁面都要設定自己的參數。被取消的導覽則會保留它們。
- 請在 `setup` 中從 `useNuxtApp()` 或 `useI18n()` 取得 `$setI18nRouteParams`，即使您稍後才在 `useAsyncData` 處理函式中呼叫它也一樣。在那裡取得的函式會知道它所屬的頁面：如果訪客已經離開，延遲的呼叫就不會有任何作用。
- 使用 `keepalive` 時，訪客返回頁面時，頁面會取回它先前設定的參數。`useI18nHead` 也是如此。

## 在 pages:extend 中加入的路由 {#routes-added-in-pagesextend}

您在 `pages:extend` hook 中加入的路由沒有可供讀取 `$defineI18nRoute` 的頁面檔案，而且其中數個路由往往共用同一個包裝元件。未指定 `name` 而加入的路由會得到 Nuxt 依其路徑所給的名稱（`/a/:id()` 會變成 `a-id`），讓語言連結能找到它，除非已有其他路由使用該名稱；此時請為它指定明確的 `name`。請維護一份清單，並使用 `@i18n-micro/utils/split-locale-routes` 中的 `splitLocaleRoutes` 將它拆分為頁面以及以路由名稱為鍵的 `globalLocaleRoutes`（請將此套件加入您的相依套件）：

```ts
// nuxt.config.ts
import { splitLocaleRoutes } from '@i18n-micro/utils/split-locale-routes'

const dynamic = splitLocaleRoutes([
  { name: 'products-tag', path: '/products/:tag', file: '~/pages/_dynamic.vue', paths: { de: '/produkte/:tag' } },
  { name: 'internal', path: '/internal', file: '~/pages/_dynamic.vue', paths: false }, // not localized
])

export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  hooks: {
    'pages:extend'(pages) {
      pages.push(...dynamic.pages)
    },
  },
  i18n: {
    globalLocaleRoutes: dynamic.globalLocaleRoutes,
  },
})
```

請勿將在地化路徑放在 `route.meta` 中：它們會被包含在用戶端的路由表中送出。
