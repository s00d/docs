## 翻譯 {#translations}

### `$t` 在外掛或工具函式中失效 {#$t-fails-in-a-plugin-or-a-utility-function}

Composable 需要 Nuxt 上下文。在 `setup` 之外，請從 app 取得輔助函式，或在 `await` 之後於其上下文中執行：

```ts
const nuxtApp = useNuxtApp()
const title = nuxtApp.$t('errors.unknown')
await nuxtApp.runWithContext(() => nuxtApp.$t('errors.unknown'))
```

在完全沒有 app 的服務中，請傳遞鍵，並在元件中進行翻譯。

### 某個鍵只在單一頁面上顯示為原始文字 {#a-key-shows-as-raw-text-on-one-page-only}

該鍵位於另一個頁面的檔案中。每個頁面只能看到根檔案以及它自己的 `locales/pages/<route-name>/` 檔案；請將共用的鍵移到根檔案。請參閱[翻譯檔案](/zh-Hant/guide/translations)。

### 頁面轉場期間鍵會閃現 {#keys-flash-while-a-page-transition-runs}

這不應該發生：離開中頁面的鍵會持續解析，直到轉場結束。如果仍然閃現，表示該鍵只存在於兩個頁面都不擁有的頁面檔案中（例如在 layout 中）；請將它移到根檔案。

### 在 Vercel、Netlify 或 Edge 上 SSR 時缺少翻譯 {#translations-are-missing-during-ssr-on-vercel-netlify-or-edge}

在這些平台上，伺服器函式無法讀取 `public/`，因此 payload 會嵌入伺服器 bundle 中。這是預設行為；請確認 `translationPayloads.serverAssets` 沒有被關閉。如果記錄中出現 `public/ is not deployed next to the server`，請設定 `nitro.serveStatic: false`。請參閱[部署](/zh-Hant/guide/deployment)。

### 如何在翻譯的句子中放入連結？ {#how-do-i-put-a-link-inside-a-translated-sentence}

使用 `<i18n-t>`：每個具名插槽會填入同名的 `{placeholder}`。

```vue
<!-- "share": "Share your {link} with friends" -->
<i18n-t keypath="share">
  <template #link>
    <i18n-link :to="{ name: 'referral' }">{{ $t('referralLink') }}</i18n-link>
  </template>
</i18n-t>
```

請參閱 [`<i18n-t>`](/zh-Hant/components/i18n-t)。不支援 vue-i18n 的連結訊息與修飾符；請像這樣在範本中組合。

## 語系與 URL {#locales-and-urls}

### `/en/about` 回傳 404 {#/en/about-is-a-404}

在預設的 `prefix_except_default` 下，預設語系沒有前綴：`/about` 就是英文。如果你想要 `/en/...`，請使用 `prefix` 或 `prefix_and_default`。請參閱[路由策略](/zh-Hant/guide/strategy)。

### 訪客透過深層連結進入時沒有被重新導向 {#visitors-are-not-redirected-on-deep-links}

預設情況下，只有 `/` 會依照瀏覽器語言或 cookie 導向，因此分享出去的連結會保留其語言。請設定 `autoDetectPath: 'no_prefix'` 或 `'*'`。請參閱[語系偵測](/zh-Hant/guide/locale-detection#autodetectpath)。

### 重新載入後選擇的語言被遺忘 {#the-chosen-language-is-forgotten-after-a-reload}

在前綴策略下，語系 cookie 預設為關閉。請設定 `localeCookie: 'user-locale'`。請參閱[語系偵測](/zh-Hant/guide/locale-detection#the-cookie)。

### 可以在不改變 URL 的情況下切換語系嗎？ {#can-i-switch-locale-without-changing-the-url}

只有在 `strategy: 'no_prefix'` 下可以，此時 `$switchLocale('de')` 會在相同路徑上重新載入字典。在前綴策略下，語系是 URL 的一部分，因此切換就是導覽。若要使用連結而非函式呼叫，請使用 `$switchLocalePath('de')`。

### 切換語系時頁面會捲動到頂端 {#the-page-scrolls-to-the-top-when-i-switch-locale}

這是 Nuxt 對任何導覽所套用的 `scrollBehavior`。請設定 `definePageMeta({ scrollToTop: false })`，並自行還原捲動位置。playground 中的 [`SwitchLocalePreserve.vue`](https://github.com/s00d/nuxt-i18n-micro/blob/main/playground/components/SwitchLocalePreserve.vue) 是可直接複製使用的包裝元件（[示範頁面](https://github.com/s00d/nuxt-i18n-micro/blob/main/playground/pages/scroll-test.vue)）。

## 建置與整合 {#build-and-integrations}

### `nuxt-seo:defaults depends on nuxt-site-config:i18n but they are not registered` {#nuxt-seodefaults-depends-on-nuxt-site-configi18n-but-they-are-not-registered}

舊版的 `nuxt-site-config` 只認得 `@nuxtjs/i18n`。請將 `@nuxtjs/seo` 升級到 3 或更新版本，並在 `modules` 中將 `nuxt-i18n-micro` 列在它之前。請參閱 [SEO](/zh-Hant/guide/seo)。

### 在 Cloudflare 上出現與 `@unhead/vue` 相關的建置錯誤 {#build-error-about-@unhead/vue-on-cloudflare}

請在 app 中安裝 `@unhead/vue`，讓預先渲染步驟能找到它。模組本身不需要 `nodejs_compat`：只有在 app 中其他部分需要時，才在 `wrangler.toml` 中加入 `compatibility_flags = ["nodejs_compat"]`。
