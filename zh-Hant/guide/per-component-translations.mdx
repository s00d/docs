---
title: "頁面設定"
description: "使用 $defineI18nRoute 將頁面限制於部分 locale、設定自訂路徑、內嵌翻譯或停用 SEO 標籤。"
---

`$defineI18nRoute` 可在頁面內部為單一頁面設定 i18n 選項。當頁面只存在於部分 locale、需要自己的在地化路徑、帶有少量專屬翻譯，或不得產生 hreflang/canonical 標籤時，請使用它。模組會在建置時讀取此呼叫，並將其寫入產生的路由中。

## 將頁面限制於部分 locale {#restrict-a-page-to-some-locales}

```vue
<!-- pages/product/index.vue -->
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'de'],
})
</script>
```

在預設的 `prefix_except_default` 策略下，只會產生 `/product` 與 `/de/product`；此頁面在其他任何 locale 中都沒有路由。同樣的設定也可以在 `nuxt.config.ts` 中透過 [`routeLocales`](/zh-Hant/api/module-options#routelocales) 完成。

`$defineI18nRoute` 是 Nuxt 應用程式注入（injection），而非編譯器巨集：請一律從 `useNuxtApp()` 取得，並以帶有 `$` 的形式呼叫。建置步驟只會辨識 `$defineI18nRoute(`。

## 加入內嵌翻譯 {#add-inline-translations}

傳入物件而非陣列。其鍵為允許的 locale，其值會合併到該頁面在目前 locale 下的字典中。

```vue
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: {
    en: { greeting: 'Hello' },
    de: { greeting: 'Hallo' },
    fr: {}, // allowed, no inline keys
  },
})
</script>

<template>
  <h1>{{ $t('greeting') }}</h1>
</template>
```

內嵌翻譯會針對每個 locale 隨頁面元件一起發送。超過少數幾個鍵時，建議改用[頁面翻譯檔案](/zh-Hant/guide/translations)；內嵌鍵適合保留給自成一體的頁面與元件。

## 設定在地化路徑 {#set-localized-paths}

```ts
$defineI18nRoute({
  locales: ['en', 'de'],
  localeRoutes: {
    en: '/welcome',
    de: '/willkommen',
  },
})
```

在 `prefix_except_default` 與 `defaultLocale: 'en'` 下，這會產生 `/welcome` 與 `/de/willkommen`。在內嵌 locale 物件中設定 `path` 也有相同效果：`locales: { de: { path: '/willkommen' } }`。動態參數、巢狀路由以及設定層級的替代方式，請參閱[在地化路徑](/zh-Hant/guide/custom-locale-routes)。

## 停用 SEO 標籤 {#turn-off-seo-tags}

```ts
$defineI18nRoute({
  disableMeta: true, // no hreflang, canonical or og:locale tags on this page
})

$defineI18nRoute({
  disableMeta: ['de'], // only the de version has no tags
})
```

設定層級的替代方式為 [`routeDisableMeta`](/zh-Hant/api/module-options#routedisablemeta)。這些標籤的說明請見 [SEO](/zh-Hant/guide/seo) 頁面。

## 建置步驟能讀取的內容 {#what-the-build-can-read}

建置步驟會在每個頁面檔案中找到此呼叫，並在不執行應用程式的情況下對其參數求值。以下情況的設定可以正常運作：

- 字面值物件（字串、陣列、巢狀物件、樣板字面值、針對 `process.env.NODE_ENV` 的三元運算式）；
- 由同一個 `<script setup>` 中宣告的常數組成（`const locales = ['en', 'de']`，包含展開運算）；
- 含有 `code` 欄位的物件陣列（`[{ code: 'en' }, { code: 'de' }]`）。

它無法讀取從其他模組匯入的值，也無法讀取任何需要在執行階段執行應用程式才能取得的內容（composables、`await`、擷取的資料）。在這種情況下，建置會記錄 `Ignored the $defineI18nRoute() config in <file>`，而頁面會保留預設的 locale 與路由。

在執行階段，此呼叫只會合併目前 locale 的內嵌翻譯，並在 locale 變更時重新合併。`locales`、`localeRoutes` 與 `disableMeta` 只會透過建置生效，因此變更它們需要重新建置（開發伺服器會在儲存時重新建置）。
