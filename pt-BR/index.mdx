---
title: "Nuxt I18n Micro"
description: "i18n pequeno e rápido para Nuxt: traduções JSON por página, rotas localizadas em tempo de build e tags de SEO prontas para uso."
---

Nuxt I18n Micro é um módulo de i18n leve e de alto desempenho para Nuxt 3 e 4, pensado para projetos grandes. Ele mantém baixos o tempo de build, o uso de memória e o tamanho do bundle em comparação com soluções de i18n tradicionais como `@nuxtjs/i18n`.

As rotas localizadas são geradas em tempo de build por `@i18n-micro/route-strategy` e resolvidas em tempo de execução por `@i18n-micro/path-strategy`, então links, o seletor de idioma, `hreflang` e redirecionamentos concordam com o router. As traduções são apenas JSON, divididas entre arquivos raiz compartilhados e arquivos por página que o servidor de desenvolvimento cria para você, com HMR integrado.

<CodeGroup>

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>
