## 🚀 Início rápido

### Instalação

Instale o módulo na sua aplicação Nuxt:

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

### Configuração básica

Adicione o módulo ao seu `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

<Tip>
- **Arquivos raiz** (`locales/en.json`, etc.) — traduções compartilhadas por toda a aplicação (menus, rodapé, UI comum). Com `translationPayloads.mode: 'premerged'` (padrão), elas são mescladas em cada página em tempo de build.
- **Arquivos por página** (`locales/pages/<route>/<locale>.json`) — traduções específicas de determinadas páginas, carregadas apenas quando a página é visitada.
- **Rotas dinâmicas** — `pages/articles/[id].vue` mapeia para `locales/pages/articles-id/` (colchetes substituídos por hifens).
- **Geração automática** — todos os arquivos de tradução são criados automaticamente quando ausentes durante `nuxt dev`.
</Tip>

<Info>
O módulo suporta ambos os layouts:

- **Páginas**: `pages/**/*.vue` (Nuxt 3) ou `app/pages/**/*.vue` (Nuxt 4)
- **Traduções**: mantenha `locales/` na **raiz do projeto** por padrão (convenção recomendada), não dentro de `app/`

```tree
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   ├── en.json
│   └── pages/
└── nuxt.config.ts
```

Colocação opcional: `i18n: \{ translationDir: 'app/locales' \}` (veja a [fixture `n3`](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/n3)).

Para o helper opcional de CLI `text-to-i18n`, use [`nuxt-i18n-micro-cli` ≥ 2.1.1](/guides/cli#-text-to-i18n-command) para que `app/pages` e `app/components` sejam escaneados a partir da raiz do projeto.
</Info>

### Uso básico

Use traduções em seus componentes:

```vue
<template>
  <div>
    <h1>{{ $t('welcome') }}</h1>
    <p>{{ $t('description', { name: 'World' }) }}</p>

    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" @click="$switchLocale(locale.code)">
        {{ locale.code }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useI18n } from '#imports'

const { $t, $getLocales, $switchLocale } = useI18n()
</script>
```
