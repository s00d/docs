# 📚 Exemplos e uso do Nuxt I18n Micro

Esta seção fornece diversos exemplos que demonstram como usar o `Nuxt I18n Micro` em sua aplicação Nuxt.js. Você verá como trocar de locale, usar os componentes `<i18n-link>`, `<i18n-switcher>` e `<i18n-t>` e lidar dinamicamente com chaves de tradução.

## 🛠️ Configuração básica

Aqui está uma configuração básica para começar com o `Nuxt I18n Micro`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Troca de locale

### Trocando locales programaticamente

Este exemplo demonstra como trocar de locale programaticamente usando botões:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Exemplo de JSON para troca de locale

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### Usando o componente `<i18n-switcher>`

O componente `<i18n-switcher>` fornece um dropdown para troca de locale com rótulos personalizáveis:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 🌐 Usando `<i18n-link>` para navegação localizada


## 📝 Renderizando chaves dinâmicas a partir de arquivos de tradução

Em alguns cenários você pode querer iterar sobre chaves dinâmicas armazenadas em seus arquivos de tradução e renderizar seus valores condicionalmente. O exemplo abaixo demonstra como fazer isso usando o `Nuxt I18n Micro`.

### Exemplo: renderizando chaves dinâmicas

Este exemplo obtém um array de chaves a partir de um caminho específico da tradução (neste caso, `dynamic`) e itera sobre elas. Cada chave é verificada quanto à sua existência com `$has` antes de renderizar seu valor com `$t`.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Exemplo de arquivo de tradução (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Exemplo: renderizando chaves dinâmicas a partir de um objeto

Neste exemplo, lidamos com um objeto armazenado em seu arquivo de tradução. Obtemos e iteramos sobre as chaves do objeto, renderizando dinamicamente os nomes das chaves e seus valores associados.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Exemplo de arquivo de tradução (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 Usando `<i18n-t>` para traduções com slots e interpolação

O componente `<i18n-t>` é útil para renderizar traduções com conteúdo dinâmico e tags HTML:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### Exemplo de JSON para `<i18n-t>`

```json
{
  "greeting": "Welcome to the page"
}
```

### Com interpolação

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### Exemplo de JSON para interpolação

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 Usando `$tc` para pluralização

A função `$tc` no `Nuxt I18n Micro` lida com pluralização baseada na contagem e nas configurações do locale. Isso é útil para ajustar dinamicamente mensagens que envolvem contagens, como itens, notificações ou outras entidades que podem variar em número.

### Exemplo: usando `$tc` para pluralização

No exemplo a seguir, exibimos uma mensagem indicando o número de maçãs usando `$tc`. A chave de tradução lida com múltiplas formas plurais com base na contagem fornecida.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### Exemplo de JSON para pluralização

Veja como definir a tradução em seu arquivo JSON para lidar com diferentes formas plurais:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Explicação

- **`$tc('apples', 0)`**: retorna a primeira forma, usada quando a contagem é zero (`"no apples"`).
- **`$tc('apples', 1)`**: retorna a segunda forma, usada quando a contagem é um (`"one apple"`).
- **`$tc('apples', 10)`**: retorna a terceira forma com o valor da contagem, usada quando a contagem é dois ou mais (`"10 apples"`).

### Exemplo adicional com pluralização mais complexa

Se sua aplicação precisa lidar com regras de pluralização mais complexas (por exemplo, casos específicos para zero, um, dois, poucos, muitos, outros), você pode estender as strings de tradução de acordo:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: pode ser configurado para retornar `"two apples"`.
- **`$tc('apples', 3)`**: pode retornar `"a few apples"`, dependendo das regras definidas para a contagem.

## 🌐 Usando `$tn` para formatação de números

A função `$tn` formata números de acordo com o locale atual usando a API `Intl.NumberFormat`. Isso é útil para exibir números em um formato que corresponda às configurações regionais do usuário, como moeda, porcentagens ou outros formatos numéricos.

### Exemplo: usando `$tn` para formatação de números

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ Usando `$td` para formatação de data e hora

A função `$td` formata datas e horas de acordo com o locale atual usando a API `Intl.DateTimeFormat`. Isso é útil para exibir datas e horas em formatos familiares ao usuário com base em suas configurações de locale.

### Exemplo: usando `$td` para formatação de data e hora

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ Usando `$tdr` para formatação relativa de data

A função `$tdr` formata datas como tempos relativos (por exemplo, "5 minutos atrás", "2 dias atrás") de acordo com o locale atual usando a API `Intl.RelativeTimeFormat`. Isso é útil para exibir diferenças de tempo em relação à data e hora atuais.

### Exemplo: usando `$tdr` para formatação relativa de data

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
