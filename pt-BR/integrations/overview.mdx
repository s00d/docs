# Integrações

Os pacotes `@i18n-micro` são versões leves e específicas por framework do Nuxt I18n Micro, projetadas para integração com diferentes frameworks e ambientes. Esses pacotes fornecem funcionalidade essencial de internacionalização com um footprint mínimo, focando em recursos essenciais de tradução e componentes básicos.

## Visão geral

Esses pacotes de integração são **versões em miniatura** do módulo completo Nuxt I18n Micro, contendo apenas a funcionalidade essencial necessária para internacionalização:

- **Recursos essenciais de tradução** - Métodos básicos de tradução, pluralização e formatação
- **Componentes essenciais** - Um pequeno conjunto de componentes de UI para tarefas comuns de i18n
- **Padrão de adaptador de router** - Integração flexível de roteamento por meio de abstração via adapter
- **Suporte a TypeScript** - Definições de tipo completas para desenvolvimento type-safe

Diferente do módulo Nuxt completo, esses pacotes:

- Não incluem lógica de roteamento específica de framework
- Exigem que você implemente um adaptador de router para recursos de roteamento
- Focam em funcionalidade de tradução em vez de integração com framework
- São projetados para serem leves e agnósticos a framework sempre que possível

## Componentes principais

Todos os pacotes de framework incluem os seguintes componentes essenciais:

### `<I18nT>`

Um componente de tradução que renderiza texto traduzido com suporte a:

- **Interpolação de parâmetros** - Substitui placeholders por valores dinâmicos
- **Pluralização** - Seleção automática da forma plural com base na contagem
- **Formatação de números** - Formata números de acordo com o locale
- **Formatação de datas** - Formata datas e tempos relativos
- **Renderização HTML** - Renderização opcional de conteúdo HTML
- **Valores padrão** - Texto de fallback quando a tradução está ausente

**Exemplo:**

```vue
<!-- Vue -->
<I18nT keypath="greeting" :params="{ name: 'World' }" />
```

```tsx
// React
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```tsx
// Solid
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```astro
<!-- Astro -->
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

### `<I18nLink>`

Um componente de link localizado que lida automaticamente com prefixos de locale nas URLs. Recursos:

- **Localização automática de caminho** - Adiciona/remove prefixos de locale com base na estratégia de roteamento
- **Detecção de estado ativo** - Destaca a rota atual
- **Suporte a links externos** - Detecta e trata URLs externas automaticamente
- **Integração com router** - Usa o componente de link do adapter do router quando disponível
- **Estilização customizada** - Suporta estados active e hover

**Exemplo:**

```vue
<!-- Vue -->
<I18nLink to="/about" active-class="active">
  About Us
</I18nLink>
```

```tsx
// React
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```tsx
// Solid
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```astro
<!-- Astro -->
<I18nLink href="/about" class="nav-link">
  About Us
</I18nLink>
```

### `<I18nSwitcher>`

Um componente de troca de idioma que fornece uma interface dropdown ou lista para trocar de locale. Recursos:

- **Lista de locales automática** - Gera opções a partir dos locales configurados
- **Destaque do locale atual** - Indica visualmente o idioma ativo
- **Rótulos personalizados** - Suporte a nomes de exibição personalizados por locale
- **Integração com router** - Navega automaticamente para caminhos localizados
- **Acessibilidade** - Atributos ARIA adequados e navegação por teclado

**Exemplo:**

```vue
<!-- Vue -->
<I18nSwitcher />
```

```tsx
// React
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```tsx
// Solid
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```astro
<!-- Astro -->
<I18nSwitcher />
```

### `<I18nGroup>`

Um componente para agrupar traduções com um prefixo comum, útil para organizar traduções por página ou funcionalidade. Recursos:

- **Escopo por prefixo** - Prepend automaticamente o prefixo a todas as chaves de tradução dentro do grupo
- **Grupos aninhados** - Suporte a grupos de tradução aninhados
- **Organização limpa** - Ajuda a manter estruturas de tradução organizadas

**Exemplo:**

```vue
<!-- Vue -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

```tsx
// React
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```tsx
// Solid
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```astro
<!-- Astro -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

## Opções compartilhadas de `createI18n` \{#create-i18n-options\}

Todo pacote de framework é criado do mesmo modo — apenas o nome do tipo das opções muda conforme o framework (`ReactI18nOptions`, `SolidI18nOptions`, e assim por diante). As opções em si são idênticas:

| Propriedade         | Tipo                                                       | Obrigatório | Padrão          | Descrição                                    |
| ---------------- | ---------------------------------------------------------- | -------- | ---------------- | ---------------------------------------------- |
| `locale`         | `string`                                                   | ✅       | -                | Código do locale atual (ex.: `'en'`)             |
| `fallbackLocale` | `string`                                                   | ❌       | Igual a `locale` | Locale de fallback quando a tradução está ausente    |
| `messages`       | `Record<string, Translations>`                             | ❌       | `\{\}`             | Mensagens de tradução iniciais                   |
| `plural`         | `PluralFunc`                                               | ❌       | `defaultPlural`  | Função personalizada de pluralização                  |
| `missingWarn`    | `boolean`                                                  | ❌       | `true`           | Mostra avisos no console para traduções ausentes |
| `missingHandler` | `(locale: string, key: string, routeName: string) => void` | ❌       | -                | Handler personalizado para traduções ausentes        |

Qualquer coisa além disso é específica de framework e está documentada na página do respectivo pacote.

## Abstração do adaptador de router

Todos os pacotes de framework usam um **padrão de adaptador de router** para desacoplar a funcionalidade de i18n de implementações específicas de router. Esse design permite:

- **Flexibilidade** - Use qualquer biblioteca de router ou nenhum router
- **Independência de framework** - Mantenha a lógica de roteamento na sua aplicação, não no pacote de i18n
- **Núcleo enxuto** - O pacote de i18n permanece pequeno e focado

### Implementando um adapter de router

Para usar recursos de roteamento, você precisa implementar a interface `I18nRoutingStrategy`:

```typescript
interface I18nRoutingStrategy {
  getCurrentPath: () => string
  linkComponent?: Component
  push: (target: { path: string }) => void
  replace: (target: { path: string }) => void
  resolvePath?: (to: string | { path?: string }, locale: string) => string | { path?: string }
  getRoute?: () => { fullPath: string; query: Record<string, unknown> }
}
```

A documentação de cada pacote inclui exemplos completos de implementação de adapters para routers populares:

- **Vue**: exemplo de adapter para Vue Router
- **React**: exemplo de adapter para React Router
- **Solid**: exemplo de adapter para Solid Router
- **Astro**: exemplo de adapter para roteamento por arquivos

## Recursos principais

Todos os pacotes compartilham esses recursos principais:

### Métodos de tradução

- `t()` - Tradução básica com interpolação de parâmetros
- `ts()` - Tradução que sempre retorna uma string
- `tc()` - Tradução com suporte a pluralização
- `tn()` - Formatação de números
- `td()` - Formatação de datas
- `tdr()` - Formatação de tempo relativo
- `has()` - Verifica se a chave de tradução existe

### Gerenciamento de locale

- **Troca de locale** - Muda o locale atual programaticamente
- **Locale de fallback** - Fallback automático quando a tradução está ausente
- **Traduções específicas de rota** - Organização de tradução no nível de página
- **Cache de traduções** - Cache inteligente para performance

### Suporte a TypeScript

Todos os pacotes fornecem:

- Definições TypeScript completas
- Chaves de tradução type-safe (com o types generator)
- Suporte a IntelliSense em IDEs
- Verificação de erros em tempo de compilação
