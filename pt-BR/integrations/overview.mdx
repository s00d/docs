Os pacotes `@i18n-micro/*` levam o núcleo de tradução do Nuxt I18n Micro para Vue, React, Preact, Solid, Astro, VitePress e JavaScript puro. Use-os quando o seu app não for um app Nuxt, ou quando um script ou servidor fora do Nuxt precisar dos mesmos arquivos de tradução. Todos os pacotes compartilham um mesmo modelo de instância, um mesmo contrato de adaptador de router e os mesmos quatro componentes, descritos uma única vez nesta página.

A entrada do router é um import separado, então um app sem router nunca inclui um no bundle.

`@i18n-micro/core`, `@i18n-micro/types` e `@i18n-micro/utils` são instalados junto com esses pacotes; raramente você os importa diretamente. As assinaturas de todas as exportações estão na [referência de pacotes](/pt-BR/api/packages/overview) gerada.

Cada pacote tem um playground em `packages/<name>/playground` no repositório.

## A instância {#the-instance}

`createI18n(options)` retorna uma instância que guarda os dicionários, o locale atual e a rota atual. As opções são as mesmas em todos os pacotes:

| Opção | Tipo | Padrão | Observações |
| --- | --- | --- | --- |
| `locale` | `string` | obrigatório | Locale ativo. |
| `fallbackLocale` | `string` | `locale` | Consultado quando uma chave não existe em `locale`. |
| `messages` | `Record<locale, Translations>` | `{}` | Dicionários raiz (rota `'index'`). |
| `routeMessages` | `Record<route, Record<locale, Translations>>` | `{}` | Dicionários de rota. Apenas Runtime, React, Preact, Node e VitePress. |
| `plural` | `PluralFunc` | `defaultPlural` | Regra de plural personalizada. |
| `missingWarn` | `boolean` | `true` | `console.warn` no navegador, apenas em dev, para uma chave ausente. |
| `missingHandler` | `(locale, key, routeName) => void` | — | Chamado no lugar do aviso. |
| `numberFormats` | `Record<locale, Record<name, Intl.NumberFormatOptions>>` | — | Formatos nomeados: `tn(9.5, 'currency')`. |
| `datetimeFormats` | `Record<locale, Record<name, Intl.DateTimeFormatOptions>>` | — | Formatos nomeados: `td(date, 'short')`. |
| `timeZone` | `string` | fuso do runtime | Fuso IANA para datas de `td`; não afeta `tdr`. Defina-o para que servidor e navegador renderizem a mesma data. |
| `now` | `() => number` | `Date.now` | O relógio de `tdr`. Passe o horário do servidor para a hidratação para que ambos renderizem o mesmo texto. |
| `localeIso` | `Record<code, string>` | — | Tag BCP 47 usada nas regras de plural (`ua` → `uk-UA`). React, Preact e Solid a obtêm de `iso` nos `locales` do provider. |

Os dicionários ficam em `i18n.storage.translations`, um `Map` com chaves `locale:route` (`en:index`, `en:about`).

Uma chave é buscada no dicionário da rota atual e depois no dicionário raiz, primeiro para `locale` e depois para `fallbackLocale`. Uma chave ausente retorna a própria chave (ou o `defaultValue` que você passar).

```ts
i18n.addTranslations('en', { nav: { home: 'Home' } }) // root, deep-merged
i18n.addRouteTranslations('en', 'about', { title: 'About us' }) // route chunk
i18n.addTranslations('en', { nav: { home: 'Start' } }, false) // replace instead of merge
i18n.setRoute('about')
i18n.t('title') // 'About us'
i18n.t('nav.home') // 'Start' (root key, still visible on the route)
```

### Traduzir e formatar {#translate-and-format}

| Método | Retorna |
| --- | --- |
| `t(key, params?, defaultValue?, routeName?)` | O valor (string, número, objeto) com `{param}` interpolado. |
| `ts(...)` | O mesmo que `t`, como string. |
| `tc(key, count \| params, defaultValue?)` | Forma plural. |
| `tn(value, options \| name)` | `Intl.NumberFormat` no locale ativo. |
| `td(value, options \| name)` | `Intl.DateTimeFormat`. |
| `tdr(value, options?)` | Tempo relativo (`3 days ago`). |
| `has(key, routeName?)` | `true` quando o locale ativo tem a chave (dicionário da rota ou raiz; o fallback não é verificado). |

`defaultPlural` divide o valor em `|` e escolhe a forma no índice `count`, limitado à última; um `count` negativo, fracionário ou `NaN` escolhe a última forma.

Um `plural` personalizado recebe `(key, count, params, locale, getter)`. Leia o valor por meio de `getter(key)`; não divida a chave:

```ts
import type { PluralFunc } from '@i18n-micro/vue'

const plural: PluralFunc = (key, count, params, _locale, getter) => {
  const value = getter(key)
  if (typeof value !== 'string') return null
  const forms = value.split('|').map((form) => form.trim())
  return (count === 1 ? forms[0] : forms[1] ?? forms[0])!.replace('{count}', String(count))
}
```

## Adaptador de router {#router-adapter}

Os pacotes SPA não dependem de um router. Um adaptador de router (`I18nRoutingStrategy`) informa a eles como ler o caminho atual, navegar e montar um caminho localizado. Os adaptadores embutidos adicionam prefixo a todos os locales, exceto `defaultLocale` (`/about`, `/de/about`).

| Membro | Obrigatório | Usado por |
| --- | --- | --- |
| `getCurrentPath(): string` | sim | verificação de link ativo (por página; query e hash não contam), `switchLocale` (os mantém) |
| `push({ path }): void` | sim | `switchLocale`, `<I18nLink>` sem `linkComponent`, `<I18nSwitcher>` |
| `replace({ path }): void` | sim | — |
| `resolvePath(to, locale)` | não | `localePath`, `localeRoute`, `<I18nLink>`; sem ele, os caminhos são retornados como estão |
| `linkComponent` | não | `<I18nLink>` o renderiza (por exemplo, `RouterLink`) em vez de `<a>` |
| `getRoute()` | não | `{ fullPath, query }` para helpers de SEO |

`push` e `replace` são obrigatórios em Vue, React, Preact e Solid. O Astro tem o seu próprio adaptador, do lado do servidor, com `push`/`replace` opcionais (veja [Astro](/pt-BR/integrations/astro-package#router-adapter)).

Um adaptador mínimo para qualquer router baseado em history:

```ts
import type { I18nRoutingStrategy } from '@i18n-micro/react'

const locales = ['en', 'de']
const stripLocale = (path: string) => path.replace(/^\/(en|de)(?=\/|$)/, '') || '/'

export const historyAdapter: I18nRoutingStrategy = {
  getCurrentPath: () => window.location.pathname + window.location.search + window.location.hash,
  push: ({ path }) => window.history.pushState({}, '', path),
  replace: ({ path }) => window.history.replaceState({}, '', path),
  resolvePath: (to, locale) => {
    const path = stripLocale(typeof to === 'string' ? to : to.path || '/')
    return locale === 'en' ? path : `/${locale}${path === '/' ? '' : path}`
  },
}
```

## Componentes {#components}

Vue, React, Preact e Solid trazem os mesmos quatro componentes. As props deles coincidem; React, Preact e Solid repassam as demais props para o elemento raiz.

### `<I18nT>` {#&lt;i18nt&gt;}

| Prop | Tipo | Observações |
| --- | --- | --- |
| `keypath` | `string` | obrigatório |
| `params` | `object` | valores de interpolação |
| `plural` | `number \| string` | renderiza `tc(keypath, count)` |
| `number` | `number \| string` | passa `tn(number)` como `{number}` |
| `date` | `Date \| string \| number` | passa `td(date)` como `{date}` |
| `relativeDate` | `Date \| string \| number` | passa `tdr(relativeDate)` como `{relativeDate}` |
| `tag` | `string` | elemento wrapper, padrão `span` |
| `html` | `boolean` | renderiza a tradução como HTML; ela precisa ser confiável, os params são escapados |
| `defaultValue` | `string` | substitui uma chave ausente e é renderizado sem wrapper quando `hideIfEmpty` oculta um valor vazio |
| `hideIfEmpty` | `boolean` | não renderiza nada para uma tradução vazia |
| `customPluralRule` | `PluralFunc` | regra de plural para este elemento |

Apenas uma prop de formatação se aplica, verificada nesta ordem: `number`, `date`, `relativeDate`, `plural`.

#### Rich text {#rich-text}

Um `{placeholder}` pode conter um elemento. No Vue, é um slot nomeado; em React, Preact e Solid, a prop `components` fornece elementos, ou funções que retornam um, por nome. De qualquer forma, ele prevalece sobre um param de mesmo nome, funciona em todos os ramos e resiste a um locale que reordena os placeholders.

```tsx
// { "terms": "I accept the {link} of {company}" }
<I18nT keypath="terms" params={{ company: 'ACME' }} components={{ link: <a href="/terms">terms</a> }} />
```

No Solid, passe uma função quando um placeholder se repetir: um nó ocupa um único lugar. `children` substituem o texto; como função, recebem `{ translation }`, como o slot padrão do Vue. `html` ignora tudo isso.

### `<I18nLink>` {#&lt;i18nlink&gt;}

| Prop | Tipo | Observações |
| --- | --- | --- |
| `to` | `string \| { path }` | localizado pelo `resolvePath` do adaptador |
| `activeStyle` | objeto de estilo | mesclado sobre `style` na página atual; React, Preact e Solid também o aplicam a uma seção acima |
| `localeRoute` | função | sobrescreve `resolvePath` para este link |

URLs externas (`https://`, `mailto:`, `tel:`) são renderizadas como `<a target="_blank" rel="noopener noreferrer">`; um `target` ou `rel` seu prevalece. `onClick` sempre é executado. Um clique com modificador, outro botão do mouse ou um `target` fica a cargo do navegador.

### `<I18nSwitcher>` {#&lt;i18nswitcher&gt;}

Um dropdown com os locales habilitados (locales com `disabled: true` ficam ocultos) e estilos padrão inline. Os itens são links, com `lang`, `hreflang` e `dir` vindos do locale. Por padrão, clicar em um deles define o locale e chama o `push` do adaptador com o caminho atual localizado; uma prop `switchLocale` substitui essa ação. Com um `localeRoute` e sem router, o navegador segue o link. Escape ou um clique fora o fecha.

| Prop | Observações |
| --- | --- |
| `locales`, `currentLocale`, `getLocaleName` | sobrescrevem os valores fornecidos |
| `switchLocale(code)` | substitui a troca embutida |
| `localeRoute` | substitui `resolvePath` |
| `customLabels` | `{ de: 'DE' }` |
| `customWrapperStyle`, `customButtonStyle`, `customDropdownStyle`, `customItemStyle`, `customLinkStyle`, `customActiveLinkStyle`, `customDisabledLinkStyle`, `customIconStyle` | sobrescritas de estilo |

### `<I18nGroup>` {#&lt;i18ngroup&gt;}

Um `<div class="i18n-group">` que entrega um `t` com prefixo aos seus filhos. Ele **não** adiciona prefixo a `<I18nT>` ou a chamadas `t()` dentro dele; apenas o `t` que ele repassa tem prefixo.

| Prop | Observações |
| --- | --- |
| `prefix` | obrigatório, por exemplo `'profile'` |
| `groupClass` | classe extra no wrapper |

O `t` com prefixo chega por um scoped slot no Vue (`v-slot="{ t }"`) e por um filho render-prop em React, Preact e Solid (`{({ t }) => …}`).

## Chaves tipadas {#typed-keys}

`t()` aceita qualquer string. Para ter autocomplete das suas chaves, gere uma declaração com o [gerador de tipos](/pt-BR/integrations/types-generator). As chaves são sugeridas, não impostas, e os params não são tipados.

## Comparação com o módulo Nuxt {#compared-with-the-nuxt-module}

Os pacotes não têm roteamento baseado em arquivos, middleware de servidor nem loader de traduções: você decide quando carregar o JSON (`import`, `fetch` ou `@i18n-micro/node` no servidor) e qual adaptador de router usar. Detecção de locale, meta de SEO e geração de rotas são recursos do Nuxt; o Astro tem o seu próprio middleware para detecção e `useLocaleHead` para SEO.
