`@i18n-micro/runtime` é a instância de i18n independente de framework: dicionários, `t()`, plurais, formatação com `Intl` e uma assinatura de mudanças, sem `fs` e sem framework. Use-a em TypeScript puro, em um web worker, em uma função de edge ou como base para o seu próprio binding. Os pacotes de React, Preact, Node e Astro estendem esta mesma classe.

## Instalação {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/runtime
```

```bash npm
npm install @i18n-micro/runtime
```

```bash yarn
yarn add @i18n-micro/runtime
```

</CodeGroup>

Sem dependências peer. Para arquivos de tradução em disco, use [`@i18n-micro/node`](/pt-BR/integrations/nodejs-package).

## Configuração {#setup}

```ts
import { createI18n } from '@i18n-micro/runtime'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    en: { greeting: 'Hello, {name}!', apples: 'no apples | one apple | {count} apples' },
    de: { greeting: 'Hallo, {name}!' },
  },
  routeMessages: {
    about: { en: { title: 'About us' } },
  },
})
```

Todas as opções (`plural`, `missingWarn`, `missingHandler`, `numberFormats`, `datetimeFormats`) estão listadas em [a instância](/pt-BR/integrations/overview#the-instance).

## Traduzir {#translate}

```ts
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.tc('apples', 5) // '5 apples'
i18n.tn(1234.5) // '1,234.5'

i18n.setRoute('about')
i18n.t('title') // 'About us' (route dictionary)
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!' (root, still visible)
```

Carregue mais dicionários depois:

```ts
i18n.loadMessages({ fr: { greeting: 'Bonjour, {name} !' } }, { about: { fr: { title: 'À propos' } } })
i18n.addTranslations('fr', { nav: { home: 'Accueil' } }) // deep merge; pass false to replace

await i18n.loadFromUrl('/locales/fr.json', { locale: 'fr' })
await i18n.loadFromUrl('/locales/pages/about/fr.json', { locale: 'fr', routeName: 'about' })
await i18n.loadFromUrls([
  { url: '/locales/en.json', locale: 'en' },
  { url: '/locales/de.json', locale: 'de' },
])
```

`loadFromUrl` usa `fetch` (passe `init` para cabeçalhos) e lança um erro em uma resposta que não seja OK. `loadFromUrls` carrega um após o outro.

## Trocar o locale {#switch-locale}

```ts
i18n.locale = 'de'
i18n.t('greeting', { name: 'Ada' }) // 'Hallo, Ada!'
```

Mudanças de locale, de rota e de dicionário notificam os assinantes, que é como os bindings de framework re-renderizam:

```ts
const stop = i18n.subscribe(() => {
  document.querySelector('#greeting')!.textContent = i18n.t('greeting', { name: 'Ada' }) as string
})
i18n.locale = 'fr'
stop()
```

`getSnapshot()` retorna uma string que muda a cada notificação (para stores no estilo `useSyncExternalStore`).

## Por requisição {#per-request}

A instância mantém um locale e uma rota. Em um servidor, não troque o locale de uma instância compartilhada a cada requisição: duas requisições simultâneas veriam o locale uma da outra. `i18n.fork(locale)` dá a uma requisição a sua própria: locale, fallback e rota próprios; os mesmos dicionários, formatadores e regras. Fazer um fork custa o mesmo independentemente de quantos dicionários existam. Um fork enxerga as escritas no seu pai até a sua primeira escrita própria, e as escritas dele ficam nele. [Node.js](/pt-BR/integrations/nodejs-package#per-request) adiciona `run`.

## API {#api}

| Membro | Observações |
| --- | --- |
| `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has` | veja [Traduzir e formatar](/pt-BR/integrations/overview#translate-and-format) |
| `locale`, `fallbackLocale` | get/set |
| `currentRoute`, `setRoute(name)`, `getRoute()` | rota ativa, padrão `'index'` |
| `loadMessages(messages?, routeMessages?)` | mescla vários locales e rotas de uma vez |
| `addTranslations(locale, tree, merge = true)`, `addRouteTranslations(locale, route, tree, merge = true)` | |
| `loadFromUrl(url, { locale?, routeName?, init? })`, `loadFromUrls(entries)` | `fetch` de JSON |
| `hasTranslation(key)` | locale ativo, qualquer rota (diferente de `has`, que verifica a rota ativa e a raiz) |
| `setTranslation(key, value)`, `resolveTranslations()` | grava uma chave; lê a árvore mesclada |
| `clear()`, `clearCache()` | descarta todos os dicionários |
| `subscribe(cb)`, `getSnapshot()` | notificações de mudança |
| `storage` | `{ translations: Map<'locale:route', Translations> }` |

Um código que não é uma tag de idioma obtém seus plurais de `localeIso: { ua: 'uk-UA' }`; `localeIsoMap(locales)` monta isso a partir das entradas de uma lista de locales que têm um `iso`.

Exportações do módulo: `createI18n`, `I18n`, `fetchJsonTranslations`, `FormatService`, `interpolate`, `localeIsoMap` e os tipos `I18nOptions`, `LoadFromUrlOptions`, `LoadFromUrlEntry`, `TranslationStorage`, `Translations`, `Locale`, `PluralFunc`. Assinaturas completas: [referência do pacote](/pt-BR/api/packages/runtime).
