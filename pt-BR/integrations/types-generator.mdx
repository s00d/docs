---
title: "Gerador de tipos"
description: "Gere autocompletar TypeScript para chaves de tradução a partir dos seus arquivos JSON, no Nuxt ou em qualquer projeto Vite."
---

`@i18n-micro/types-generator` lê todos os arquivos JSON da sua pasta de traduções e escreve uma declaração que lista todas as chaves. Adicione-o quando quiser que seu editor sugira chaves em `t()`, `$t()` e `<I18nT keypath>`. Ele funciona como módulo Nuxt e como plugin Vite ou Rollup, e regenera os tipos quando um arquivo muda.

## Instalação {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/types-generator
```

```bash npm
npm install -D @i18n-micro/types-generator
```

```bash yarn
yarn add -D @i18n-micro/types-generator
```

</CodeGroup>

Dependência peer: `@nuxt/kit` `^3.18.0 || ^4.0.0`. Apenas o ponto de entrada `/nuxt` a importa; em um projeto somente Vite, o aviso de peer pode ser ignorado.

## Nuxt {#nuxt}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro', '@i18n-micro/types-generator/nuxt'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

O módulo escreve `.nuxt/types/i18n-micro.d.ts` e o Nuxt o adiciona ao contexto de tipos; não é preciso incluir nada manualmente. Ele lê `i18nTypes.translationDir` ou, na falta dele, os locais de onde o `nuxt-i18n-micro` lê traduções: `translationDir` (de `i18n` ou das opções inline do módulo, padrão `'locales'`) em cada camada, e `additionalTranslationDirs`. Editar um arquivo JSON nessa pasta regenera os tipos no `nuxi dev`. `i18nTypes.outputFile` é ignorado no Nuxt (um aviso informa isso).

## Vite {#vite}

`I18nTypesPlugin` é um plugin Vite, que o Rollup também aceita. Para outro bundler, chame `generateTypes` em um script.

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { I18nTypesPlugin } from '@i18n-micro/types-generator'

export default defineConfig({
  plugins: [
    vue(),
    I18nTypesPlugin({
      srcDir: process.cwd(),
      translationDir: 'src/locales',
      outputFile: 'src/i18n-micro.d.ts',
    }),
  ],
})
```

| Opção | Obrigatória | Observações |
| --- | --- | --- |
| `srcDir` | sim | Diretório base; `translationDir` é resolvido em relação a ele. |
| `translationDir` | sim | Pasta com os arquivos JSON (incluindo subpastas como `pages/`), ou um array de pastas. |
| `outputFile` | não | Onde escrever a declaração; padrão `<srcDir>/i18n-micro.d.ts`. |

O plugin gera os tipos uma vez no início do build e, no servidor de desenvolvimento, regenera 300 ms após uma mudança na pasta. Certifique-se de que o `include` do seu `tsconfig.json` cubra o arquivo de saída.

## Use as chaves {#use-the-keys}

O arquivo gerado estende `DefineLocaleMessage` em `@i18n-micro/types`, o que transforma `TranslationKey` nas suas chaves:

```ts
declare module '@i18n-micro/types' {
  export interface DefineLocaleMessage {
    nav: object
    'nav.home': string
    'profile.title': string
  }
}
```

As chaves são aquelas que `t()` responde, incluindo objetos, de todos os locales e todos os arquivos de página, com o tipo do seu valor JSON. `TranslationKey` é a união dessas chaves com qualquer string, então você obtém autocompletar, não erros: uma chave com erro de digitação ou dinâmica ainda compila. Parâmetros e valores de retorno não são tipados.

Para chaves dinâmicas sob um prefixo conhecido, `ScopedKey<'prefix'>` restringe às chaves correspondentes:

```ts
import type { ScopedKey } from '@i18n-micro/types'

const statusText = (status: string) => t(`status.${status}` as ScopedKey<'status'>)
```

`TranslationKey` e `ScopedKey` vêm de `@i18n-micro/types` (React, Preact e Solid reexportam `TranslationKey`; Vue não).

## API {#api}

| Exportação | Ponto de entrada | Observações |
| --- | --- | --- |
| `I18nTypesPlugin(options)` | `@i18n-micro/types-generator` | Plugin Vite e Rollup |
| `generateTypes(options)` | `@i18n-micro/types-generator` | escreve o arquivo, retorna seu caminho |
| `getTypesString(options)` | `@i18n-micro/types-generator` | retorna a declaração sem escrever |
| `formatKeyProperty(key)` | `@i18n-micro/types-generator` | helper |
| Módulo Nuxt (`configKey: 'i18nTypes'`) | `@i18n-micro/types-generator/nuxt` | opção `translationDir` |

Assinaturas completas: [referência do pacote](/pt-BR/api/packages/types-generator).
