## Requisitos

- **Node.js**: 18 ou superior.
- **Nuxt**: 3.x ou 4.x.

O módulo suporta tanto o layout de projeto do Nuxt 3 (`pages/**/*.vue`) quanto o layout do Nuxt 4 (`app/pages/**/*.vue`). As traduções ficam na raiz do projeto por convenção (`locales/`), mesmo ao usar o diretório `app/` do Nuxt 4.

## Instale o módulo Nuxt

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Registre-o em `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Veja o [Início rápido](/quickstart) para um guia completo ou a [Referência de configuração](/guides/configuration) para todas as opções.

## Layout do projeto

Por padrão, o módulo espera:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Os arquivos de nível raiz são mesclados em cada arquivo específico de página em tempo de build. Os arquivos específicos de página são criados automaticamente quando ausentes durante `nuxt dev`.

<Info>

</Info>

## Layout do Nuxt 4

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Para colocar as traduções sob `app/`, defina `translationDir: 'app/locales'`.

## Pacotes do ecossistema

| Pacote | Objetivo |
| --- | --- |
| [`@i18n-micro/vue`](/integrations/vue) | Integração com Vue 3 (independente, sem Nuxt). |
| [`@i18n-micro/react`](/integrations/react) | Integração com React. |
| [`@i18n-micro/preact`](/integrations/preact) | Integração com Preact. |
| [`@i18n-micro/solid`](/integrations/solid) | Integração com SolidJS. |
| [`@i18n-micro/astro`](/integrations/astro) | Integração com Astro. |
| [`@i18n-micro/node`](/integrations/nodejs) | Loader server-side para Node.js. |
| [`@i18n-micro/types-generator`](/integrations/types-generator) | Gera tipos TypeScript a partir dos arquivos de tradução. |
| [`@i18n-micro/devtools-ui`](/integrations/devtools-ui) | Painel de DevTools agnóstico de framework. |

Pacotes internos compartilhados são incluídos transitivamente.

## TypeScript

O módulo gera tipos ambient para `useI18n`, `$t` e helpers relacionados com base nos arquivos do seu locale padrão. Esse recurso é habilitado por padrão (`types: true`).

Para uma tipagem mais forte das chaves de tradução, veja [`@i18n-micro/types-generator`](/integrations/types-generator).
