## Requisitos

- **Node.js**: 18 ou mais recente.
- **Nuxt**: 3.x ou 4.x.

O módulo suporta tanto o layout de projeto Nuxt 3 (`pages/**/*.vue`) quanto o layout do Nuxt 4 (`app/pages/**/*.vue`). As traduções ficam na raiz do projeto por convenção (`locales/`), mesmo ao usar o diretório `app/` do Nuxt 4.

## Instalar o módulo Nuxt

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Registre-o em `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Veja o [Guia rápido](/quickstart) para um passo a passo completo ou a [Referência de configuração](/guides/configuration) para todas as opções.

## Layout do projeto

Por padrão, o módulo espera:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Arquivos raiz são mesclados a cada arquivo específico de página em tempo de build. Arquivos específicos de página são criados automaticamente quando ausentes durante `nuxt dev`.

## Layout do Nuxt 4

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Para colocar as traduções em `app/`, defina `translationDir: 'app/locales'`.

Os pacotes internos compartilhados são trazidos transitivamente.

## TypeScript

O módulo gera tipos ambientes para `useI18n`, `$t` e helpers relacionados com base nos seus arquivos de locale padrão. Isso está habilitado por padrão (`types: true`).

Para tipagem mais rigorosa das chaves de tradução, veja [`@i18n-micro/types-generator`](/integrations/types-generator).
