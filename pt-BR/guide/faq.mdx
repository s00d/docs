Respostas curtas para os problemas mais comuns, para perguntas que as páginas de cada tópico não respondem diretamente. Cada resposta aponta para a página responsável pelo tópico. Se a sua não estiver aqui, pesquise na documentação ou abra uma [issue](https://github.com/s00d/nuxt-i18n-micro/issues).

## Traduções {#translations}

### `$t` falha em um plugin ou em uma função utilitária {#$t-fails-in-a-plugin-or-a-utility-function}

Composables precisam do contexto do Nuxt. Fora do `setup`, pegue o helper da aplicação, ou execute dentro do contexto dela após um `await`:

```ts
const nuxtApp = useNuxtApp()
const title = nuxtApp.$t('errors.unknown')
await nuxtApp.runWithContext(() => nuxtApp.$t('errors.unknown'))
```

Em serviços que não têm nenhuma aplicação, passe as chaves e traduza-as no componente.

### Uma chave aparece como texto bruto em apenas uma página {#a-key-shows-as-raw-text-on-one-page-only}

A chave está no arquivo de outra página. Uma página enxerga apenas o arquivo raiz e o seu próprio arquivo `locales/pages/<route-name>/`; mova as chaves compartilhadas para o arquivo raiz. Veja [Arquivos de tradução](/pt-BR/guide/translations).

### Chaves piscam durante uma transição de página {#keys-flash-while-a-page-transition-runs}

Isso não deveria acontecer: as chaves da página que está saindo são resolvidas até o fim da transição. Se ainda piscarem, a chave está apenas em um arquivo de página que não pertence a nenhuma das duas páginas (por exemplo, em um layout); mova-a para o arquivo raiz.

### Traduções ausentes durante o SSR na Vercel, Netlify ou Edge {#translations-are-missing-during-ssr-on-vercel-netlify-or-edge}

A função do servidor não consegue ler `public/` nesses ambientes, então os payloads são embutidos no bundle do servidor. Esse é o padrão; verifique se `translationPayloads.serverAssets` não está desativado. Se o log disser `public/ is not deployed next to the server`, defina `nitro.serveStatic: false`. Veja [Deploy](/pt-BR/guide/deployment).

### Como coloco um link dentro de uma frase traduzida? {#how-do-i-put-a-link-inside-a-translated-sentence}

Use `<i18n-t>`: cada slot nomeado preenche o `{placeholder}` de mesmo nome.

```vue
<!-- "share": "Share your {link} with friends" -->
<i18n-t keypath="share">
  <template #link>
    <i18n-link :to="{ name: 'referral' }">{{ $t('referralLink') }}</i18n-link>
  </template>
</i18n-t>
```

Veja [`<i18n-t>`](/pt-BR/components/i18n-t). As mensagens vinculadas e os modificadores do vue-i18n não são suportados; componha no template dessa forma.

## Locales e URLs {#locales-and-urls}

### `/en/about` retorna 404 {#/en/about-is-a-404}

Com o padrão `prefix_except_default`, o locale padrão não tem prefixo: `/about` é inglês. Use `prefix` ou `prefix_and_default` se quiser `/en/...`. Veja [Estratégias de roteamento](/pt-BR/guide/strategy).

### Visitantes não são redirecionados em links diretos {#visitors-are-not-redirected-on-deep-links}

Por padrão, apenas `/` segue o idioma do navegador ou o cookie, então links compartilhados mantêm seu idioma. Defina `autoDetectPath: 'no_prefix'` ou `'*'`. Veja [Detecção de locale](/pt-BR/guide/locale-detection#autodetectpath).

### O idioma escolhido é esquecido após recarregar a página {#the-chosen-language-is-forgotten-after-a-reload}

O cookie de locale fica desativado nas estratégias com prefixo. Defina `localeCookie: 'user-locale'`. Veja [Detecção de locale](/pt-BR/guide/locale-detection#the-cookie).

### Posso trocar de locale sem mudar a URL? {#can-i-switch-locale-without-changing-the-url}

Apenas com `strategy: 'no_prefix'`, em que `$switchLocale('de')` recarrega o dicionário no mesmo caminho. Nas estratégias com prefixo, o locale faz parte da URL, então trocar significa navegar. Para um link em vez de uma chamada, use `$switchLocalePath('de')`.

### A página rola para o topo quando troco de locale {#the-page-scrolls-to-the-top-when-i-switch-locale}

Esse é o `scrollBehavior` do Nuxt para qualquer navegação. Defina `definePageMeta({ scrollToTop: false })` e restaure a posição você mesmo. O [`SwitchLocalePreserve.vue`](https://github.com/s00d/nuxt-i18n-micro/blob/main/playground/components/SwitchLocalePreserve.vue) do playground é um wrapper que pode ser copiado ([página de demonstração](https://github.com/s00d/nuxt-i18n-micro/blob/main/playground/pages/scroll-test.vue)).

## Build e integrações {#build-and-integrations}

### `nuxt-seo:defaults depends on nuxt-site-config:i18n but they are not registered` {#nuxt-seodefaults-depends-on-nuxt-site-configi18n-but-they-are-not-registered}

Um `nuxt-site-config` antigo só conhece `@nuxtjs/i18n`. Atualize `@nuxtjs/seo` para a versão 3 ou mais recente e liste `nuxt-i18n-micro` antes dele em `modules`. Veja [SEO](/pt-BR/guide/seo).

### Erro de build sobre `@unhead/vue` na Cloudflare {#build-error-about-@unhead/vue-on-cloudflare}

Instale `@unhead/vue` na aplicação para que a etapa de prerender o encontre. O módulo em si não precisa de `nodejs_compat`: adicione `compatibility_flags = ["nodejs_compat"]` ao `wrangler.toml` apenas se outra parte da aplicação precisar.
