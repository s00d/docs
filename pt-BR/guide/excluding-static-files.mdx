---
title: "Excluindo caminhos"
description: "Mantenha páginas e arquivos fora do roteamento por locale com excludePatterns e veja quais caminhos já são excluídos."
---

Alguns caminhos nunca devem receber um prefixo de locale nem um redirecionamento de locale: uma área administrativa, um health check, um feed gerado. `excludePatterns` os marca, e uma lista embutida já cobre os internos do Nuxt e arquivos estáticos comuns. Uma página excluída mantém exatamente o caminho que você escreveu e continua renderizando com `$t`.

## Excluir um caminho {#exclude-a-path}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    excludePatterns: [
      '/admin', // /admin and everything below it
      '/preview-*', // glob over the whole path
    ],
  },
})
```

Com esta configuração, `pages/admin/index.vue` responde apenas em `/admin`; não existe `/de/admin`, e `/admin` nunca é redirecionado para `/de/admin`.

## Sintaxe dos padrões {#pattern-syntax}

Os padrões são comparados com o caminho sem `app.baseURL`:

| Padrão | Corresponde a | Não corresponde a |
| --- | --- | --- |
| `'/admin'` | `/admin`, `/admin/users` | `/administrator`, `/de/admin` |
| `'/preview-*'` | `/preview-1`, `/preview-a/b` | `/de/preview-1` |
| `'/file-?'` | `/file-a` | `/file-ab` |
| `/^\/v\d+\//` | `/v2/docs` | `/docs` |

Uma string sem `*` ou `?` corresponde ao caminho e a segmentos inteiros abaixo dele. Com `*` (qualquer sequência de caracteres, incluindo barras) ou `?` (um caractere), ela precisa corresponder ao caminho inteiro. Sempre comece as strings com `/`.

## O que já é excluído {#what-is-excluded-already}

Estes caminhos nunca recebem rotas ou redirecionamentos de locale, sem nenhuma configuração:

- `/api` e `/_nuxt`, e tudo abaixo deles;
- a rota de traduções, `/_locales` por padrão ([`apiBaseUrl`](/pt-BR/api/module-options#apibaseurl));
- qualquer caminho com um segmento que comece com `__` (`/__nuxt_content`, `/en/__og-image__`);
- `/sitemap*.xml`, `/robots.txt`, `/favicon.ico`, `/apple-touch-icon*.png`, `/manifest.json`, `/sw.js`, `/workbox-*.js`;
- qualquer caminho cujo último segmento termine em uma extensão de arquivo estático: `xml txt ico json js css png jpg jpeg gif svg webp avif pdf wasm map mp4 webm mp3 zip gz woff woff2 ttf eot`. Slugs de página com ponto, como `/user/john.doe`, e caminhos `.html` continuam sendo páginas.

## O que uma exclusão faz {#what-an-exclusion-does}

- **Rotas:** nenhuma variante localizada é gerada; a página é mantida como foi escrita.
- **Redirecionamentos e 404s:** o plugin de redirecionamento do servidor e o middleware de redirecionamento do cliente ignoram o caminho.
- **Pré-renderização:** os caminhos correspondentes são removidos da lista de rotas de pré-renderização.

Isso não impede que o middleware de servidor do i18n detecte um locale para a requisição, nem impede que a página use traduções. Para manter uma página localizada, mas fora das tags de SEO, use `disableMeta` ([Configuração da página](/pt-BR/guide/per-component-translations#turn-off-seo-tags)). Para manter uma página sem localização a partir do `nuxt.config.ts` pelo caminho, `globalLocaleRoutes: { '/admin': false }` ([Caminhos localizados](/pt-BR/guide/custom-locale-routes#in-nuxt-config)) faz o mesmo para o roteamento.
