Esta página leva um app Nuxt de nenhum i18n até uma página traduzida com um seletor de idioma. Você precisa dela uma vez, no início de um projeto. No final, você terá URLs localizadas (`/about`, `/de/about`), um arquivo JSON por locale e página, e `$t` nos seus templates.

## Instalação {#install}

O módulo requer Nuxt 3.18 ou mais recente (Nuxt 4 também funciona) e Node 20 ou mais recente.

<CodeGroup>

```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>

## Configure os locales {#configure-the-locales}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', displayName: 'English' },
      { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
      { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
    ],
    defaultLocale: 'en',
  },
})
```

Essa é toda a configuração de que um primeiro app precisa. Os padrões oferecem:

- `strategy: 'prefix_except_default'`: o locale padrão não tem prefixo (`/about`), os outros têm (`/de/about`). Veja [Estratégias de roteamento](/pt-BR/guide/strategy).
- `translationDir: 'locales'`: os arquivos de tradução ficam em `locales/` na raiz do projeto, também com o layout `app/` do Nuxt 4.
- `meta: true`: tags `hreflang`, canonical e `og:locale`, além de `lang` e `dir` em `<html>`. Veja [SEO](/pt-BR/guide/seo).
- Um visitante que abre `/` é enviado para o idioma que o navegador dele solicita (`Accept-Language`). Veja [Detecção de locale](/pt-BR/guide/locale-detection).

`iso` é a tag de idioma usada nas tags de SEO; `code` é o que aparece na URL. Todas as opções estão listadas em [Opções do módulo](/pt-BR/api/module-options).

## Adicione arquivos de tradução {#add-translation-files}

Inicie o servidor de desenvolvimento com `nuxt dev`. Quando o Nuxt resolve as páginas, o módulo cria um arquivo vazio `{}` para cada locale e página que não tem um (desative isso com [`disableWatcher`](/pt-BR/api/module-options#disablewatcher)):

```text
locales/
├── en.json            # root: keys every page can use
├── de.json
├── fr.json
└── pages/
    ├── index/         # pages/index.vue
    │   ├── en.json
    │   ├── de.json
    │   └── fr.json
    └── about/         # pages/about.vue
        ├── en.json
        ├── de.json
        └── fr.json
```

Preencha o arquivo raiz e um arquivo de página:

```json
// locales/en.json
{ "nav": { "home": "Home", "about": "About" } }
```

```json
// locales/pages/index/en.json
{ "welcome": "Welcome, {name}!", "items": "no items | one item | {count} items" }
```

Uma página vê as chaves raiz e as suas próprias; o arquivo próprio da página prevalece em caso de conflito. Os nomes das pastas seguem o nome da rota (`pages/articles/[id].vue` é `locales/pages/articles-id/`). [Arquivos de tradução](/pt-BR/guide/translations) aborda o layout, os fallbacks e o carregamento.

## Use `$t` em uma página {#use-$t-on-a-page}

```vue
<!-- pages/index.vue -->
<script setup lang="ts">
const { t, tc, getLocale } = useI18n()

const title = t('nav.home') // 'Home'
</script>

<template>
  <h1>{{ $t('welcome', { name: 'Ada' }) }}</h1>
  <!-- Welcome, Ada! -->
  <p>{{ $tc('items', 3) }}</p>
  <!-- 3 items -->
  <p>{{ getLocale() }}</p>
  <!-- en -->
</template>
```

- Nos templates, todo helper está disponível com um `$` (`$t`, `$tc`, `$localePath`, …).
- Em `<script setup>`, `useI18n()` retorna os mesmos helpers, com e sem o `$` (`t` e `$t` são uma única função). Ele é importado automaticamente.
- Os placeholders `{name}` são preenchidos a partir do objeto de parâmetros. As formas de plural são separadas por `|`; a contagem escolhe a forma (0, 1 e depois a última para tudo acima disso).

Todos os helpers estão listados em [Métodos](/pt-BR/api/methods).

## Crie links entre páginas e troque o locale {#link-between-pages-and-switch-locale}

```vue
<!-- components/AppHeader.vue -->
<template>
  <nav>
    <i18n-link :to="{ name: 'index' }">{{ $t('nav.home') }}</i18n-link>
    <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
    <i18n-switcher />
  </nav>
</template>
```

- [`<i18n-link>`](/pt-BR/components/i18n-link) é um `NuxtLink` que aponta para a página no locale atual: em `/de`, o link about vai para `/de/about`.
- [`<i18n-switcher>`](/pt-BR/components/i18n-switcher) é um dropdown dos locales habilitados; ele mantém o visitante na mesma página.
- Para seus próprios botões, chame `$switchLocale('de')`, que navega para a página atual em alemão e lembra a escolha. Para um `NuxtLink` simples, use `$localePath({ name: 'about' })` ou `$switchLocalePath('de')`.

## Verifique {#check-it}

Execute `nuxt dev` e abra:

| URL | Exibe |
| --- | --- |
| `/` | Página inicial em inglês (ou um redirecionamento para `/de` quando seu navegador prefere alemão) |
| `/de` | Página inicial em alemão |
| `/de/about` | Página about em alemão |
| `/en/about` | 404: o locale padrão não tem prefixo em `prefix_except_default` |

Edições nos arquivos JSON são aplicadas na página aberta sem recarregar.
