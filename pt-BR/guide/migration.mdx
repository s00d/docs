Esta página mapeia uma aplicação `@nuxtjs/i18n` para o nuxt-i18n-micro: opções, helpers e estrutura de arquivos. Use-a ao trocar o módulo em uma aplicação existente. Você mantém suas URLs (os nomes das estratégias são os mesmos) e move as traduções para arquivos JSON por página.

<Tip>

**Atualizando o próprio nuxt-i18n-micro?** — Veja [Atualização](/pt-BR/guide/upgrade).

</Tip>

## Trocar o módulo {#swap-the-module}

```bash
npm uninstall @nuxtjs/i18n
npm install nuxt-i18n-micro
```

```ts
// nuxt.config.ts — before
export default defineNuxtConfig({
  modules: ['@nuxtjs/i18n'],
  i18n: {
    locales: [
      { code: 'en', language: 'en-US', file: 'en.json' },
      { code: 'de', language: 'de-DE', file: 'de.json' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    langDir: 'locales',
    detectBrowserLanguage: { useCookie: true, cookieKey: 'i18n_redirected', redirectOn: 'root' },
  },
})
```

```ts
// nuxt.config.ts — after
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    translationDir: 'locales',
    localeCookie: 'i18n_redirected',
    autoDetectPath: '/',
  },
})
```

## Opções {#options}

| `@nuxtjs/i18n` | nuxt-i18n-micro |
| --- | --- |
| `locales[].code` | `locales[].code` |
| `locales[].language` (`iso` antes da v9) | `locales[].iso` |
| `locales[].name` | `locales[].displayName` |
| `locales[].dir` | `locales[].dir` |
| `locales[].domain` | `locales[].baseUrl` (uma origem com o esquema) |
| `locales[].domainDefault` | `locales[].baseDefault` |
| `differentDomains`, `multiDomainLocales` | desnecessários: `baseUrl` sozinho roteia pelo host, veja [Camadas e domínios](/pt-BR/guide/layers#multiple-domains) |
| `locales[].file` / `files`, `langDir`, `lazy` | `translationDir`; os arquivos são encontrados pelo nome e sempre carregados por página |
| `defaultLocale`, `strategy` | mesmos nomes, mesmos quatro valores |
| `baseUrl` | `metaBaseUrl` |
| `customRoutes: 'config'` + `pages` | `globalLocaleRoutes` |
| `detectBrowserLanguage: false` | `redirects: false` (sem redirecionamentos) ou `autoDetectLanguage: false` (ignorar o cabeçalho) |
| `detectBrowserLanguage.useCookie` / `cookieKey` | `localeCookie: '<name>'` (`null` desativa o cookie) |
| `detectBrowserLanguage.redirectOn: 'root'` | `autoDetectPath: '/'` (padrão) |
| `detectBrowserLanguage.redirectOn: 'no prefix'` | `autoDetectPath: 'no_prefix'` |
| `detectBrowserLanguage.redirectOn: 'all'` | `autoDetectPath: '*'` |
| arquivo de configuração `vueI18n` (`fallbackLocale`, `numberFormats`, `datetimeFormats`) | `fallbackLocale`, `numberFormats`, `datetimeFormats` em `i18n` |

Não existe `alwaysRedirect`: com um cookie definido, `/` o segue em todas as visitas. A lista completa está em [Opções do módulo](/pt-BR/api/module-options); as regras de detecção estão em [Detecção de locale](/pt-BR/guide/locale-detection).

## Helpers e composables {#helpers-and-composables}

| `@nuxtjs/i18n` / vue-i18n | nuxt-i18n-micro (template / `useI18n()`) |
| --- | --- |
| `const { t } = useI18n()` | `const { t } = useI18n()`, `$t` nos templates |
| `t('key', count)`, `tc` | `$tc('key', count)` |
| `te('key')` | `$has('key')` |
| `n(value, 'currency')`, `d(date, 'short')` | `$tn(value, 'currency')`, `$td(date, 'short')` |
| — | `$tdr(date)`: tempo relativo ("em 3 dias") |
| `locale.value` | `$getLocale()` |
| `locales.value` | `$getLocales()` |
| `setLocale('de')` | `$switchLocale('de')` |
| `useLocalePath()('about')` | `$localePath({ name: 'about' })` |
| `useLocaleRoute()` | `$localeRoute()` |
| `useSwitchLocalePath()('de')` | `$switchLocalePath('de')` |
| `useSetI18nParams()` | `$setI18nRouteParams()` |
| `useLocaleHead()` | automático com `meta: true`; [`useLocaleHead`](/pt-BR/composables/useLocaleHead) para heads personalizados |
| `defineI18nRoute({ paths: { de: '/ueber-uns' }, locales: [...] })` | `$defineI18nRoute({ localeRoutes: { de: '/ueber-uns' }, locales: [...] })` |
| `<NuxtLinkLocale to="about">` | `<i18n-link :to="{ name: 'about' }">` |
| `<i18n-t>` | `<i18n-t>` (os slots preenchem placeholders `{name}`) |
| `$i18n` em rotas do servidor | `useTranslationServerMiddleware(event)`, veja [Rotas do servidor e API](/pt-BR/guide/server-side-translations) |

`useI18n()` é importado automaticamente. `$defineI18nRoute` deve manter o `$`: o build lê essa chamada. Todos os helpers: [Métodos](/pt-BR/api/methods).

## Arquivos de tradução {#translation-files}

Mova as chaves de um único arquivo grande por locale para um arquivo raiz mais um arquivo por página:

```text
locales/
├── en.json              # keys used on many pages (nav, footer)
├── de.json
└── pages/
    ├── index/en.json    # keys of pages/index.vue
    └── about/en.json    # keys of pages/about.vue
```

Manter tudo nos arquivos raiz também funciona, e é o primeiro passo mais rápido. Defina `disablePageLocales: true` até dividi-los. Veja [Arquivos de tradução](/pt-BR/guide/translations).

### Sintaxe das mensagens {#message-syntax}

| vue-i18n | nuxt-i18n-micro |
| --- | --- |
| interpolação nomeada `{name}` | igual |
| `car \| cars` (2 formas: 1 → primeira) | as formas são escolhidas pela contagem a partir de 0: escreva `no cars \| one car \| {count} cars` |
| mensagens vinculadas `@:other.key` | não suportado: repita o texto ou componha no código |
| modificadores `@.upper:` | não suportado: formate no código ou use `<i18n-t>` |
| escapes literais `{'@'}` | desnecessários: apenas tokens `{word}` são substituídos |
| arquivos de mensagens JS/TS | apenas JSON |

A regra de plural pode ser substituída com a opção [`plural`](/pt-BR/api/module-options#plural).

## Verificar após a troca {#check-after-the-switch}

- Todas as URLs que você tinha continuam resolvendo; os nomes das estratégias coincidem, e os caminhos personalizados vão para `globalLocaleRoutes` ou `$defineI18nRoute`.
- `hreflang`, canonical e `og:locale` vêm prontos com `meta: true`; remova os escritos à mão.
- Um erro de parse de JSON registra o caminho do arquivo; uma chave ausente registra um aviso no console do navegador em desenvolvimento.
