No `nuxt dev`, o módulo adiciona dois recursos de depuração: uma aba **i18n Micro** no Nuxt DevTools para navegar e editar arquivos de tradução, e um inspetor no Vue DevTools para o locale ativo e os dicionários carregados. Ambos existem apenas em desenvolvimento e não acrescentam nada aos builds de produção. A aba do Nuxt precisa apenas do Nuxt DevTools ativado; o inspetor do Vue também precisa da extensão de navegador do Vue DevTools.

## Aba do Nuxt DevTools {#nuxt-devtools-tab}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  devtools: { enabled: true }, // the tab is registered only when DevTools are on
})
```

Abra o Nuxt DevTools (`Shift + Alt + D`) e escolha **i18n Micro**. A aba mostra:

- todos os arquivos JSON em `locales/` (raiz e `pages/`) de todas as camadas, além dos arquivos raiz de `additionalTranslationDirs`;
- um editor por arquivo; **Save** grava o arquivo de volta no disco, e o servidor de desenvolvimento recarrega as traduções;
- **Export** / **Import** de um arquivo como JSON, e **Stats** com contagens de chaves e cobertura de tradução;
- uma visualização das opções do módulo resolvidas;
- **Translate**, que preenche as chaves ausentes com um mecanismo de tradução automática que você configura nas configurações da aba.

Salvar grava apenas arquivos `.json` existentes dentro dos seus diretórios de tradução. Quando um arquivo existe em várias camadas, a cópia do projeto é a que é gravada.

## Inspetor do Vue DevTools {#vue-devtools-inspector}

Com a extensão de navegador do Vue DevTools, o módulo registra um inspetor de i18n (locale atual, chunk da rota, chaves carregadas) e uma linha do tempo com trocas de locale, carregamentos de chunks e chaves ausentes.

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    debug: true, // also log every $t / $ts / $tc call on the timeline
    // vueDevtools: false, // turn the inspector off, keep the Nuxt tab
  },
})
```

[`vueDevtools`](/pt-BR/api/module-options) tem como padrão `true`. `debug: true` é verboso; use-o apenas em sessões curtas.

## Fora do Nuxt {#outside-nuxt}

A mesma interface é publicada como [`@i18n-micro/devtools-ui`](/pt-BR/integrations/devtools-ui-package) para aplicações Vite construídas com os pacotes de frameworks; veja essa página para a configuração.
