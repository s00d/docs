O [Crowdin](https://crowdin.com/) é uma plataforma de tradução: você envia os arquivos do locale padrão, os tradutores trabalham no Crowdin e você baixa os outros locales de volta. O módulo lê arquivos JSON simples, então o Crowdin CLI só precisa de um `crowdin.yml` que mapeie `locales/` e `locales/pages/` corretamente. Nenhuma configuração do módulo muda.

## Configurar o crowdin.yml {#configure-crowdin-yml}

```yml
# crowdin.yml
project_id_env: CROWDIN_PROJECT_ID
api_token_env: CROWDIN_PERSONAL_TOKEN
base_path: ./locales
preserve_hierarchy: true

files:
  - source: /en.json
    translation: /%two_letters_code%.json
  - source: /pages/**/en.json
    translation: /pages/**/%two_letters_code%.json
```

- `en` é o seu locale padrão; os arquivos dele são as fontes.
- `project_id_env` / `api_token_env` leem o ID e o token de variáveis de ambiente, então nenhum segredo é commitado.
- `preserve_hierarchy: true` mantém as pastas `pages/<page>/` como estão.
- O nome do arquivo traduzido deve ser igual ao `code` do locale em `nuxt.config.ts`. `%two_letters_code%` serve para códigos como `de`; para códigos como `pt-BR`, use `%locale%` ou mapeie os códigos do Crowdin para os seus com `languages_mapping`.

## Envio e download {#upload-and-download}

```bash
npm install -g @crowdin/cli

export CROWDIN_PROJECT_ID=123456
export CROWDIN_PERSONAL_TOKEN=...   # from Crowdin account settings

crowdin upload sources   # push locales/en.json and locales/pages/**/en.json
crowdin download         # write locales/de.json, locales/pages/**/de.json, ...
```

Execute ambos no CI para manter os arquivos atualizados. Os arquivos baixados chegam ao seu repositório como se tivessem sido editados à mão; o próximo build ou recarregamento em dev os detecta.

## Antes de enviar {#before-uploading}

Limpe as fontes antes para que os tradutores não trabalhem em chaves mortas: [`i18n-micro clean`](/pt-BR/api/cli#clean) remove chaves não utilizadas, e [`i18n-micro check`](/pt-BR/api/cli#check) aponta lacunas após um download. O CLI não tem integração própria com o Crowdin: esta página descreve a forma suportada.
