O módulo Nuxt é construído a partir de pequenos pacotes `@i18n-micro/*`, e a maioria deles funciona de forma independente: `@i18n-micro/vue` em um app Vue, `@i18n-micro/core` em qualquer lugar. Use estas páginas para consultar o que um pacote exporta, por ponto de entrada. Cada página é gerada a partir do snapshot que [`pnpm run api:surface`](https://s00d.github.io/nuxt-i18n-micro/contributing/maintenance-commands#api-surface) verifica em relação aos fontes TypeScript, de modo que uma exportação não pode mudar sem que o CI perceba.
