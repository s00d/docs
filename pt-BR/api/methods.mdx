# 🛠️ Métodos

Esta página documenta todos os métodos disponíveis fornecidos pelo nuxt-i18n-micro. Os métodos estão organizados por funcionalidade para facilitar a navegação.

### `$getI18nConfig`

## 🔍 Métodos de tradução

Métodos principais para recuperar e gerenciar traduções.

### `$t`

{/* generated:method:$t — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Traduz uma chave, interpolando `params` nela. Retorna `defaultValue` quando a chave está ausente, ou a própria chave quando nenhum valor padrão é dado.

{/* /generated:method:$t */}

```typescript
const welcomeMessage = $t('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

<Warning>
`$t` retorna `CleanTranslation`, que é `string | number | boolean | Translations | PluralTranslations | null`. Se a chave apontar para um **objeto aninhado** em seu JSON (por exemplo, `$t('header')` quando o JSON contém `\{ "header": \{ "title": "Hi" \} \}`), o valor de retorno será esse **objeto**, não uma string. Usá-lo diretamente em um template Vue (<code v-pre>\{\{ $t('header') \}\}</code>) renderizará como `[object Object]`.

**Como evitar isso:**

- Use uma chave mais específica: `$t('header.title')` → `"Hi"`
- Use `$ts()`, que sempre retorna uma string (chama `.toString()` em valores não-string)
- Use `$t` com uma chave aninhada para acessar intencionalmente sub-objetos para uso programático
</Warning>

### `$ts`

{/* generated:method:$ts — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string) => string
```

Como `$t`, mas sempre retorna string: um valor de objeto ou array é convertido para string em vez de retornado como está.

{/* /generated:method:$ts */}

```typescript
const welcomeMessage = $ts('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

### `$_t` e `$_ts`

{/* generated:method:$_t — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Vincula `$t` a uma rota específica, para traduzir fora da página atual. Um layout renderizando um link para outra rota, por exemplo.

{/* /generated:method:$_t */}

{/* generated:method:$_ts — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => string
```

Vincula `$ts` a uma rota específica. Consulte `$_t`.

{/* /generated:method:$_ts */}

Variantes vinculadas a rota de `$t` e `$ts`. Elas recebem uma **rota** primeiro e retornam uma função de tradução travada no locale e contexto de página daquela rota.

- **Acesso**: `useNuxtApp()` (também re-exportado por `useI18n()` como `$_t` / `$_ts`)

Use-as quando a rota ativa durante SSR ou transições diferir de `router.currentRoute`. Por exemplo, dentro de `<i18n-t>`, `<i18n-group>` ou ao renderizar conteúdo para um objeto `route` específico.

```typescript
import { useRoute, useNuxtApp } from '#imports'

const route = useRoute()
const { $_t, $_ts } = useNuxtApp()

const $t = $_t(route)
const title = $t('page.title')

// String-safe variant
const label = $_ts(route)('page.label')
```


### `$tc`

{/* generated:method:$tc — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params: number | Params, defaultValue?: string) => string
```

Traduz com pluralização. `params` pode ser a própria contagem ou um objeto contendo `count`.

{/* /generated:method:$tc */}

**Formato da tradução**: formas separadas por `|`. Coloque placeholders em **cada** forma:

```json
{
  "apples": "no apples | one apple | {count} apples",
  "cart": "no items for {name} | one item for {name} | {count} items for {name}"
}
```

```typescript
$tc('apples', 0) // "no apples"
$tc('apples', 1) // "one apple"
$tc('apples', 10) // "10 apples"

// count + other params (second argument must be an object)
$tc('cart', { count: 10, name: 'Alice' }) // "10 items for Alice"
```


**Alternativa em componente** `<i18n-t keypath="cart" :plural="count" :params="\{ name \}" />` (mescla `count` com `params` internamente).


### `$mergeTranslations`

{/* generated:method:$mergeTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
(newTranslations: Translations) => void
```

Mescla traduções no locale ativo em runtime, sobrescrevendo o que está carregado.

{/* /generated:method:$mergeTranslations */}

```typescript
$mergeTranslations({
  welcome: 'Bienvenue, {username}!',
})
// Output: Updates the translation cache with the new French translation
```

### `$resolveTranslations`

{/* generated:method:$resolveTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
() => Translations
```

Cada tradução atualmente em memória para o locale e rota ativos, como uma árvore. Visão somente leitura do que `$t()` pode resolver agora.

{/* /generated:method:$resolveTranslations */}

```typescript
const tree = $resolveTranslations()
// { aaa: { bbb: 'ccc' }, ddd: 1111 } — the same dictionary $t() reads from
```

Use isto quando precisar do dicionário completo em memória (DevTools, testes, editores em runtime). Trate o valor de retorno como somente leitura; altere valores via `$setTranslation` ou aplique patches com `$mergeTranslations`.

### `$setTranslation`

{/* generated:method:$setTranslation — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, value: unknown) => void
```

Substitui o valor em `key` no dicionário ativo. Isto é uma substituição, não uma mesclagem. Use `$mergeTranslations` quando irmãos existentes devam sobreviver.

{/* /generated:method:$setTranslation */}

```typescript
$setTranslation('aaa', { fff: 'ggg' }) // replaces the whole `aaa` subtree
$setTranslation('aaa', 'text')          // replaces `aaa` with a string
$setTranslation('ddd', 1111)            // scalar at the top level
$setTranslation('aaa.bbb', 'nested')    // dotted path
```

Isto é uma **substituição**, não uma mesclagem. Irmãos existentes sob a mesma chave são removidos. Para aplicar patch sem perder irmãos, use `$mergeTranslations`.

### `$setMissingHandler`

{/* generated:method:$setMissingHandler — do not edit; run `pnpm run docs:generate` */}

```ts
(handler: MissingHandler | null) => void
```

Instala um callback invocado para cada chave não resolvida. Passe `null` para removê-lo.

{/* /generated:method:$setMissingHandler */}

**Definição de tipo**:

```typescript
type MissingHandler = (locale: string, key: string, routeName: string, instance?: unknown, type?: string) => void
```

```typescript
// Set a custom handler
$setMissingHandler((locale, key, routeName) => {
  console.error(`Missing translation: ${key} in ${locale} for route ${routeName}`)
  // Send to Sentry or other error tracking service
  // Sentry.captureMessage(`Missing translation: ${key}`)
})

// Remove the handler
$setMissingHandler(null)
```

**Casos de uso**:

- Registrar traduções ausentes em serviços de rastreamento de erros (Sentry, LogRocket, etc.)
- Coletar analytics sobre traduções ausentes
- Tratamento personalizado de erros para chaves de tradução ausentes

## 🔢 Formatação de números e datas

Métodos para formatar números e datas de acordo com as convenções do locale.

### `$tn`

{/* generated:method:$tn — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Formata um número com `Intl.NumberFormat` no locale ativo. Uma chave seleciona um formato nomeado da config.

{/* /generated:method:$tn */}

```typescript
// Inline options
const formattedNumber = $tn(1234567.89, { style: 'currency', currency: 'USD' })
// "$1,234,567.89"

// Named format (from nuxt.config i18n.numberFormats)
const price = $tn(1000, 'currency')
const priceDe = $tn(1000, 'currency', 'de')
const compact = $tn(1000, 'currency', { notation: 'compact' })
```

Chaves de formato nomeadas desconhecidas recorrem às opções padrão de `Intl.NumberFormat`. Em desenvolvimento (cliente), um `console.warn` é emitido quando `missingWarn` está habilitado (padrão).

**Exemplo de config**:

```ts
export default defineNuxtConfig({
  i18n: {
    numberFormats: {
      en: {
        currency: { style: 'currency', currency: 'USD' },
        decimal: { style: 'decimal', minimumFractionDigits: 2, maximumFractionDigits: 2 },
      },
      de: {
        currency: { style: 'currency', currency: 'EUR' },
      },
    },
  },
})
```

**Casos de uso**:

- Formatar números como moeda, porcentagens ou decimais no formato apropriado do locale
- Reutilizar formatos nomeados por todo o app (paridade com migração do Vue I18n)

### `$td`

{/* generated:method:$td — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Formata uma data com `Intl.DateTimeFormat` no locale ativo. Uma chave seleciona um formato nomeado da config.

{/* /generated:method:$td */}

```typescript
const formattedDate = $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' })
// "Friday, September 1, 2023"

const short = $td(new Date(), 'short')
const longDe = $td(new Date(), 'long', 'de')
```

Chaves de formato nomeadas desconhecidas recorrem às opções padrão de `Intl.DateTimeFormat`. Em desenvolvimento (cliente), um `console.warn` é emitido quando `missingWarn` está habilitado (padrão).

**Exemplo de config**:

```ts
export default defineNuxtConfig({
  i18n: {
    datetimeFormats: {
      en: {
        short: { year: 'numeric', month: 'short', day: 'numeric' },
        long: { year: 'numeric', month: 'long', day: 'numeric', weekday: 'long' },
      },
    },
  },
})
```

**Casos de uso**:

- Exibir datas em um formato alinhado com o locale do usuário
- Compartilhar presets short/long/date-time em toda a aplicação

### `$tdr`

{/* generated:method:$tdr — do not edit; run `pnpm run docs:generate` */}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

Formata uma data como tempo relativo ("3 dias atrás") com `Intl.RelativeTimeFormat`.

{/* /generated:method:$tdr */}

```typescript
const relativeDate = $tdr(new Date(Date.now() - 1000 * 60 * 5))
// Output: "5 minutes ago" in the 'en-US' locale
```

{/* generated:method:$switchLocale — do not edit; run `pnpm run docs:generate` */}


Navega para a página atual em outro locale.

{/* /generated:method:$switchLocale */}

{/* generated:method:$switchLocalePath — do not edit; run `pnpm run docs:generate` */}

```ts

```

O path da página atual em outro locale, sem navegar.

{/* /generated:method:$switchLocalePath */}

```typescript
// on /en/news

// Output: url with new locale applied, e.g., '/fr/nouvelles'
```

### `$switchRoute`

{/* generated:method:$switchRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, toLocale?: string) => void
```

Navega para outra rota, mantendo o locale ativo ou trocando para `toLocale`.

{/* /generated:method:$switchRoute */}

**Exemplos**:

<CodeGroup>
```typescript String Path

```

```typescript String Path with Locale

```

```typescript Named Route
// Switches to a named route with the current locale
$switchRoute({ name: 'page' })
```

```typescript Named Route with Locale
// Switches to a named route and changes the locale to Spanish

```
</CodeGroup>

## 🚦 Configuração de rota

Métodos para configurar o comportamento da rota e o controle de acesso.

### `$defineI18nRoute`

{/* generated:method:$defineI18nRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Registra configuração de locale por página e traduções a partir de um componente. Mescla no locale ativo e reaplica quando o locale muda.

{/* /generated:method:$defineI18nRoute */}

> [!IMPORTANT]
> `$defineI18nRoute` é fornecido pelo **plugin define** e está disponível apenas em `useNuxtApp()`. **Não** faz parte do objeto retornado por `useI18n()`.
> Sempre desestruture-o de `useNuxtApp()` dentro de `script setup`. Chamar `$defineI18nRoute(...)` como um global puro lança `"$defineI18nRoute is not defined"` durante SSR/prerender.

**Parâmetros**:

- **locales**: `string[] | Record<string, Record<string, string>>` locales disponíveis para a rota
- **localeRoutes**: `Record<string, string>` opcional. Rotas personalizadas para locales específicos
- **disableMeta**: `boolean | string[]` opcional. Desabilita meta tags de i18n para todos ou locales específicos

**Exemplo básico**:

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr', 'de'],
  localeRoutes: {
    en: '/welcome',
    fr: '/bienvenue',
    de: '/willkommen',
  },
  disableMeta: false,
})
```

### `$setI18nRouteParams`

{/* generated:method:$setI18nRouteParams — do not edit; run `pnpm run docs:generate` */}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Define parâmetros por locale para a rota atual, para que um segmento dinâmico possa diferir por idioma. Chame-o durante o SSR, antes do head ser renderizado.

{/* /generated:method:$setI18nRouteParams */}

```typescript
// in pages/news/[id].vue
// for en/news/1-first-article
const { $switchLocaleRoute, $setI18nRouteParams, $defineI18nRoute } = useNuxtApp()
$defineI18nRoute({
  localeRoutes: {
    en: '/news/:id()',
    fr: '/nouvelles/:id()',
    de: '/Nachricht/:id()',
  },
})
const { data: news } = await useAsyncData(`news-${params.id}`, async () => {
  let response = await $fetch("/api/getNews", {
    query: {
      id: params.id,
    },
  });
  if (response?.localeSlugs) {
    response.localeSlugs = {
      en: {
        id: '1-first-article'
      }
      fr: {
        id: '1-premier-article'
      }
      de: {
        id: '1-erster-Artikel'
      }
    }
    $setI18nRouteParams(response?.localeSlugs);
  }
  return response;
});
$switchLocalePath('fr') // === 'fr/nouvelles/1-premier-article'
$switchLocalePath('de') // === 'de/Nachricht/1-erster-Artikel'
```

## 🔧 Métodos de cache e utilitários

### `$has`

{/* generated:method:$has — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string) => boolean
```

Se uma chave resolve no locale ativo. Use-o para ramificar em conteúdo opcional em vez de renderizar uma chave crua.

{/* /generated:method:$has */}

Durante transições de página no mesmo locale, a v3 automaticamente mescla profundamente as traduções da página que está saindo neste dicionário até que a transição termine. Portanto, chaves da página anterior ainda podem retornar `true` brevemente. Não há opção `previousPageFallback`; esse comportamento é embutido. Consulte [FAQ — transições de página](/guides/faq#-why-do-translations-break-during-page-transitions-especially-with-defineasynccomponent).

```typescript
  console.log($t('welcome'))
} else {
  console.log('Key not found')
}
```

## 🧭 Composable `useI18nLocale`

O composable centralizado para gerenciamento de estado do locale. Use-o em vez de manipular diretamente `useState('i18n-locale')` ou `useCookie('user-locale')`.

```typescript
const {
  setLocale, // (locale: string) => void — updates state + cookie
  getLocale, // () => string | null — from state or cookie
  getPreferredLocale, // () => string | null — validated against locales list
  getEffectiveLocale, // (route, getLocaleFromRoute) => string
  resolveInitialLocale, // (options) => string
  isValidLocale, // (locale) => boolean
  locale, // Ref<string | null> — reactive state
  localeCookie, // CookieRef — reactive cookie
  syncLocale, // (locale) => void — sync to cookie only
  validLocales, // string[] — list of valid locale codes
} = useI18nLocale()
```

### Métodos principais

| Método                  | Descrição                                                   |
| ----------------------- | ----------------------------------------------------------- |
| `setLocale(locale)`     | Define o locale em `useState` e no cookie atomicamente      |
| `getLocale()`           | Retorna o locale atual do estado ou do cookie               |
| `getPreferredLocale()`  | Retorna o locale validado contra a lista `locales`, ou `null` |
| `isValidLocale(locale)` | Verifica se um código de locale está na lista `locales` configurada |

### Uso em plugins personalizados

```typescript
// plugins/i18n-loader.server.ts
export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,
  setup() {
    const { setLocale } = useI18nLocale()
    // Detect locale from headers, domain, etc.
    setLocale('de')
  },
})
```
