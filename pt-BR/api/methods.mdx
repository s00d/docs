O módulo injeta seus helpers de runtime no app Nuxt: `$t`, `$tc`, `$localePath`, `$switchLocale` e os demais. Use esta página para consultar a assinatura e o comportamento de um helper. As assinaturas e descrições vêm das interfaces `PluginsInjections` e `NuxtAppOnlyInjections` em `src/runtime/plugins/01.plugin.ts`.

## Acesso {#access}

| Onde | Como |
| --- | --- |
| Template | `{{ $t('title') }}` — todos os helpers, com o `$` |
| `<script setup>` | `const { t, localePath } = useI18n()` — todos os helpers de `PluginsInjections`, com e sem o `$` |
| Plugin, middleware, `<script setup>` | `const { $t, $defineI18nRoute } = useNuxtApp()` — tudo, somente com `$` |

`$defineI18nRoute` é tipado apenas em `useNuxtApp()`. Veja [`useI18n`](/pt-BR/composables/useI18n).

```vue
<script setup lang="ts">
const { t, localePath } = useI18n()
</script>

<template>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
</template>
```

## Locale {#locale}

### `$getLocale` {#$getlocale}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric) => string
```

Código do locale ativo. Passe uma rota para ler o locale ao qual essa rota pertence.

```ts
$getLocale() // 'de' on /de/about
```

### `$getLocaleName` {#$getlocalename}

```ts
() => string | null
```

O `displayName` do locale ativo na configuração, ou `null` quando ele não tem um.

### `$getLocales` {#$getlocales}

```ts
() => Locale[]
```

Todos os locales configurados, com seus metadados.

Propriedades personalizadas em um objeto de locale retornam como foram escritas; tipe-as com [module augmentation](/pt-BR/api/module-options#locales) de `Locale`.

### `$defaultLocale` {#$defaultlocale}

```ts
() => string | undefined
```

Código do locale padrão configurado.

### `$getI18nConfig` {#$geti18nconfig}

```ts
() => ResolvedI18nConfig
```

A configuração resolvida do módulo, como o runtime a vê.

O valor inclui [sobrescritas em runtime](/pt-BR/guide/runtime-overrides) (`defaultLocale`, `fallbackLocale`, locales desativados).

```ts
const { strategy, localeCookie } = useNuxtApp().$getI18nConfig()
```

## Tradução {#translation}

### `$t` {#$t}

```ts
TranslationFn<CleanTranslation>
```

Traduz uma chave, interpolando `params` nela. Retorna `defaultValue` quando a chave está
ausente, ou a própria chave quando nenhum padrão é informado.

```ts
// { "welcome": "Welcome, {name}!" }
$t('welcome', { name: 'Ada' }) // 'Welcome, Ada!'
$t('missing.key', {}, 'Fallback') // 'Fallback'
```

Uma chave que aponta para um objeto aninhado retorna esse objeto, não uma string. Em um template, ele é renderizado como `[object Object]`; use uma chave folha.

### `$ts` {#$ts}

```ts
TranslationFn<string>
```

Como `$t`, mas sempre retorna uma string: o valor passa por `toString()`, então um objeto
aninhado se torna `'[object Object]'`. Aponte a chave para uma folha.

### `$_t` {#$_t}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<CleanTranslation>
```

Vincula `$t` a uma rota específica, para traduzir fora da página atual — um layout que renderiza
um link para outra rota, por exemplo.

```ts
const route = useRoute()
const t = useNuxtApp().$_t(route)
t('page.title')
```

### `$_ts` {#$_ts}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<string>
```

Vincula `$ts` a uma rota específica. Veja `$_t`.

### `$tc` {#$tc}

```ts
(key: TranslationKey, params: number | Params, defaultValue?: string) => string
```

Traduz com pluralização. `params` pode ser a própria contagem, ou um objeto contendo
`count`.

As formas são separadas por `|`. Com a regra integrada, uma contagem inteira não negativa `n` escolhe a forma `n`, limitada à última forma; uma contagem negativa, fracionária ou `NaN` usa a última forma. `{count}` e os demais parâmetros são interpolados na forma escolhida.

Para idiomas cujos plurais não seguem a contagem, comece o template com `=0 `. A primeira forma passa a ser para 0, e as demais seguem a categoria de [`Intl.PluralRules`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/PluralRules), na ordem `zero, one, two, few, many, other`:

```json
{
  "apples": "=0 no apples | one apple | {count} apples",
  "files": "=0 no files | {count} one | {count} few | {count} many"
}
```

```ts
$tc('apples', 0) // 'no apples'
$tc('apples', 1) // 'one apple'
$tc('apples', 7) // '7 apples'

// In `uk` (categories `one, few, many, other`) the forms after the zero form follow those categories:
$tc('files', 21) // '21 one'
$tc('files', 22) // '22 few'
$tc('files', 25) // '25 many'
$tc('files', 2.5) // '2.5 many': no form for `other`, so the last one
```

- `=0 ` só conta bem no início do valor, com o espaço. `$t` o exibe como texto: ele pertence aos plurais.
- Uma categoria sem forma própria usa a última forma. Uma contagem negativa ou fracionária também usa a última forma.
- Funciona em qualquer locale: `=0 none | one | {count} many` em inglês.
- A categoria vem do `iso` do locale ou, caso contrário, do seu código. Um código que o `Intl` não conhece recorre à regra de índice, com o marcador ainda removido, de modo que o resultado nunca depende da máquina.
- `<i18n-t :plural>` segue a mesma regra. Um [`plural`](/pt-BR/api/module-options#plural) personalizado ou `customPluralRule` recebe o valor bruto, marcador incluído, e decide por conta própria; um `plural` que retorna `null` devolve a chamada para a regra integrada, que respeita o marcador.

Sem o marcador, um template permanece na regra de índice, com uma exceção que só pode ser lida de uma forma: uma forma zero sem placeholder, seguida de uma forma por categoria, com `{count}` em cada forma compartilhada por várias contagens (`no files | {count} one | {count} few | {count} many` em `uk`).

Para regras próprias, defina [`plural`](/pt-BR/api/module-options#plural).

```ts
// { "apples": "no apples | one apple | {count} apples" }
$tc('apples', 0) // 'no apples'
$tc('apples', 10) // '10 apples'
$tc('cart', { count: 2, name: 'Ada' }) // count and params in one object
```

O terceiro argumento é `defaultValue`, não params.

### `$has` {#$has}

```ts
(key: string) => boolean
```

Se uma chave é resolvida no locale ativo. Use-o para ramificar em textos opcionais em vez de
renderizar uma chave bruta. Assim como `$t`, ele também vê as chaves da página que está saindo durante uma
transição de página no mesmo locale.

```ts
if ($has('promo.banner')) show.value = true
```

## Formatação {#formatting}

### `$tn` {#$tn}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Formata um número com `Intl.NumberFormat` no locale ativo. Uma chave seleciona um formato nomeado
da configuração.

Os formatos nomeados vêm de [`numberFormats`](/pt-BR/api/module-options#numberformats).

```ts
$tn(1234.5, { style: 'currency', currency: 'EUR' }) // '1.234,50 €' in de
$tn(1000, 'currency') // named format
$tn(1000, 'currency', 'de') // named format in another locale
```

### `$td` {#$td}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Formata uma data com `Intl.DateTimeFormat` no locale ativo. Uma chave seleciona um formato nomeado
da configuração.

Os formatos nomeados vêm de [`datetimeFormats`](/pt-BR/api/module-options#datetimeformats).

```ts
$td(new Date(), { dateStyle: 'long' })
$td(post.createdAt, 'short')
```

### `$tdr` {#$tdr}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

Formata uma data como tempo relativo ("há 3 dias") com `Intl.RelativeTimeFormat`.

```ts
$tdr(Date.now() - 5 * 60_000) // '5 minutes ago' in en
```

## Troca de locale e links {#switching-and-links}

### `$switchLocale` {#$switchlocale}

```ts
(locale: string) => Promise<boolean>
```

Navega para a página atual em outro locale. Em `no_prefix` e no modo hash, ele carrega as
traduções do locale antes de navegar; em `no_prefix`, a rota é substituída no lugar (sem
nova entrada no histórico). Um locale desconhecido é ignorado.
A chamada é assíncrona: use `await` para executar código após a navegação. Ela resolve `true` quando o
dicionário do locale está ativo, e `false` quando não está: o chunk falhou ao carregar (o dicionário
atual permanece; chame novamente para tentar de novo) ou uma troca mais recente venceu.

```ts
await $switchLocale('de')
```

### `$switchLocalePath` {#$switchlocalepath}

```ts
(locale: string) => string
```

O caminho da página atual em outro locale, sem navegar.

```vue
<NuxtLink :to="$switchLocalePath('de')">Deutsch</NuxtLink>
```

### `$switchLocaleRoute` {#$switchlocaleroute}

```ts
(locale: string) => RouteLocationRaw
```

O objeto de rota da página atual em outro locale, sem navegar, ou uma string de URL
para um locale com seu próprio `baseUrl`. Com `trailingSlash`, o objeto tem `path` e `fullPath`
seguindo a regra, com `query` e `hash` como estão, e `router.push` ou um link os mantêm.

### `$switchRoute` {#$switchroute}

```ts
(route: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, toLocale?: string) => Promise<void>
```

Navega para outra rota, mantendo o locale ativo ou trocando para `toLocale`. Assíncrono como
`$switchLocale`.

```ts
$switchRoute('/about') // active locale
$switchRoute({ name: 'about' }, 'de') // switch to de
```

### `$localePath` {#$localepath}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => string
```

Resolve um caminho no locale informado, ou no ativo. Uma string com esquema `http(s):`, `mailto:`
ou `tel:` retorna como está: não passe entrada do usuário como destino de link sem verificação.

Um caminho em string é lido como a página que ele exibe, então o caminho personalizado de um locale também é aplicado.

```ts
$localePath('/about') // '/about' in en, '/de/ueber-uns' in de with localeRoutes
$localePath({ name: 'about' }, 'fr') // '/fr/about'
```

### `$localeRoute` {#$localeroute}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => RouteLocationResolved
```

Resolve uma rota no locale informado, ou no ativo. Um objeto simples, seguro para manter em estado. Quando um parâmetro precisa
de escape, ele tem `path`, `fullPath`, `query` e `hash`, mas não `name` nem `params`: é o caminho que fornece ao roteador
a URL codificada. Para um locale em outro domínio, `path` e `fullPath` são absolutos, o que o roteador não aceita:
esse tipo de link passa por `<i18n-link>` ou `$localePath`.

### `$getRouteName` {#$getroutename}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric, locale?: string) => string
```

Nome da rota sem o prefixo de locale — o nome pelo qual as traduções são indexadas.

```ts
$getRouteName() // 'about' on /de/about
```

## Configuração da página {#page-config}

### `$defineI18nRoute` {#$definei18nroute}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Registra configuração de locale e traduções por página de dentro de um componente.
Mescla no locale ativo e reaplica quando o locale muda.

Chame-o no `<script setup>` de uma página, sempre desestruturado de `useNuxtApp()`. O build lê `locales`, `localeRoutes` e `disableMeta` da chamada; em runtime apenas `locales` importa (as traduções inline são mescladas para o locale ativo). Regras completas: [Configuração da página](/pt-BR/guide/per-component-translations).

```vue
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'de'],
  localeRoutes: { en: '/about', de: '/ueber-uns' },
})
</script>
```

### `$setI18nRouteParams` {#$seti18nrouteparams}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Define parâmetros por locale para a rota atual, para que um segmento dinâmico possa variar por idioma.
Chame-o durante o SSR, antes de o head ser renderizado.

Os parâmetros são limpos quando uma navegação para outro caminho é confirmada, incluindo de `/news/1` para `/news/4`, que mantém o nome da rota. Detalhes: [Caminhos localizados](/pt-BR/guide/custom-locale-routes).

```ts
$setI18nRouteParams({
  en: { slug: 'my-post' },
  de: { slug: 'mein-beitrag' },
})
```

## Traduções em runtime {#runtime-translations}

### `$mergeTranslations` {#$mergetranslations}

```ts
(newTranslations: Translations) => void
```

Mescla traduções no locale ativo em runtime, sobrescrevendo o que está carregado.

Faz uma mesclagem profunda no chunk da página atual do locale ativo; as chaves que ele não menciona são preservadas.

```ts
$mergeTranslations({ banner: { title: 'Sale' } })
```

### `$setTranslation` {#$settranslation}

```ts
(key: string, value: unknown) => void
```

Substitui o valor em `key` no dicionário ativo. Isto é uma substituição, não uma mesclagem —
use `$mergeTranslations` quando os irmãos existentes devem ser preservados.

```ts
$setTranslation('banner', { title: 'Sale' }) // drops other keys under banner
$setTranslation('banner.title', 'Sale') // dotted path
```

### `$loadPageTranslations` {#$loadpagetranslations}

```ts
(locale: string, routeName: string, translations: Translations) => Promise<void>
```

Carrega traduções para uma página em runtime, para conteúdo cujas chaves não são conhecidas em tempo de build.

Mescla no chunk em memória `(locale, routeName)`, e a tela é atualizada quando esse chunk está ativo. Nenhum payload é buscado aqui: para uma página ainda não carregada, as traduções aguardam, e quando seu arquivo carrega elas permanecem por cima dele.

```ts
await $loadPageTranslations('en', 'about', { title: 'About us' })
```

### `$resolveTranslations` {#$resolvetranslations}

```ts
() => Translations
```

Todas as traduções atualmente em memória para o locale e a rota ativos, como uma árvore.
Visão somente leitura do que `$t()` consegue resolver neste momento.

Trate o resultado como somente leitura.

### `$setMissingHandler` {#$setmissinghandler}

```ts
(handler: MissingHandler | null) => void
```

Instala um callback invocado para cada chave não resolvida. Passe `null` para removê-lo.

O handler é executado no lugar do aviso de desenvolvimento.

```ts
$setMissingHandler((locale, key, routeName) => {
  console.error(`[i18n] missing ${key} in ${locale} (${routeName})`)
})
```

### `$clearCache` {#$clearcache}

```ts
() => void
```

Descarta todos os chunks de tradução em cache e recarrega o dicionário da página atual. A página
continua exibindo suas traduções atuais até que as novas cheguem. O HMR de desenvolvimento o chama a
cada alteração em um arquivo de tradução.

```ts
const { clearCache } = useI18n()
clearCache()
```

Uma recarga com falha mantém o dicionário atual.
