O [guia da CLI](/pt-BR/guide/cli) mostra os fluxos de trabalho comuns. Esta página lista tudo e é gerada a partir da mesma tabela que alimenta o `--help`.

## Flags comuns {#common-flags}

| Flag | Padrão | Descrição |
| --- | --- | --- |
| `--cwd` | diretório atual | Diretório do projeto |
| `--logLevel` | `info` | Nível de saída: silent, info |
| `--debug` | `false` | Exibe um stack trace quando um comando falha |

## Inspeção {#inspect}

### `info` {#info}

Exibe a configuração de i18n resolvida do projeto

| Flag | Padrão | Descrição |
| --- | --- | --- |
| `--json` | `false` | Exibe JSON em vez de texto |

### `check` {#check}

O portão de CI: falha com chaves ausentes, vazias, extras, não definidas ou não utilizadas e com placeholders quebrados

| Flag | Padrão | Descrição |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` do nuxt.config | Diretório de traduções, relativo ao projeto |
| `--only` | todas, exceto duplicates | Verificações a executar, separadas por vírgula: missing, empty, extra, placeholders, undefined, unused, duplicates. `unused` indicada aqui falha quando não pode ser executada |
| `--duplicates` | `false` | Também relata o mesmo texto sob chaves diferentes |
| `--ignore` | — | Globs separados por vírgula de arquivos-fonte a ignorar, relativos ao projeto |
| `--json` | `false` | Exibe JSON em vez de texto |

```bash
i18n-micro check
i18n-micro check --only missing,placeholders --json
```

### `stats` {#stats}

Mostra o progresso da tradução por locale

| Flag | Padrão | Descrição |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` do nuxt.config | Diretório de traduções, relativo ao projeto |
| `--html` | — | Também grava um relatório HTML neste arquivo |
| `--json` | `false` | Exibe JSON em vez de texto |
| `--baseRef` | — | Ref do Git com a qual comparar o progresso, por exemplo HEAD~1 ou main |

```bash
i18n-micro stats --baseRef main
i18n-micro stats --html reports/i18n.html
```

### `lint` {#lint}

Verifica o texto das traduções; falha quando restam problemas

| Flag | Padrão | Descrição |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` do nuxt.config | Diretório de traduções, relativo ao projeto |
| `--rules` | todas, ou `enabledRules` do .i18n-lintrc.json | Regras a executar, separadas por vírgula: no-trailing-spaces, no-multiple-spaces, no-empty-translation ou uma personalizada |
| `--fix` | `false` | Corrige o que pode ser corrigido: espaços e regras personalizadas com substituição |
| `--json` | `false` | Exibe JSON em vez de texto |

```bash
i18n-micro lint --rules no-trailing-spaces --fix
```

### `search` {#search}

Pesquisa chaves e valores e mostra onde cada chave é usada

| Flag | Padrão | Descrição |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` do nuxt.config | Diretório de traduções, relativo ao projeto |
| `<query>` | — | Texto ou chave a pesquisar |
| `--caseSensitive` | `false` | Diferencia maiúsculas e minúsculas |
| `--onlyUnused` | `false` | Apenas chaves que `clean` removeria; a consulta passa a ser opcional |
| `--scope` | `all` | Onde pesquisar: global, pages, all |
| `--limit` | — | Retorna no máximo esta quantidade de chaves |
| `--ignore` | — | Globs separados por vírgula de arquivos-fonte a ignorar, relativos ao projeto |
| `--json` | `false` | Exibe JSON em vez de texto |

```bash
i18n-micro search "Welcome"
i18n-micro search --onlyUnused
```

## Fluxo de tradução {#translation-workflow}

### `extract` {#extract}

Lista as chaves usadas pelos arquivos-fonte que ainda não têm texto e adiciona as que têm um texto padrão ao locale padrão

| Flag | Padrão | Descrição |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` do nuxt.config | Diretório de traduções, relativo ao projeto |
| `--ignore` | — | Globs separados por vírgula de arquivos-fonte a ignorar, relativos ao projeto |

```bash
i18n-micro extract
```

### `translate` {#translate}

Preenche as traduções ausentes a partir do locale padrão por meio de um serviço de tradução

| Flag | Padrão | Descrição |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` do nuxt.config | Diretório de traduções, relativo ao projeto |
| `--service` | — | Serviço de tradução: ai, azure, deepl, google, libretranslate, yandexcloud |
| `--token` | — | Chave de API. Prefira a variável de ambiente I18N_TRANSLATE_TOKEN: flags acabam no histórico do shell |
| `--options` | — | Opções do serviço como pares key:value, separados por vírgulas |
| `--locale` | todos os locales, exceto o padrão | Locales a preencher, separados por vírgula |
| `--replace` | `false` | Traduz todas as chaves novamente, substituindo os valores existentes |
| `--dryRun` | `false` | Conta chaves e caracteres por locale; não envia nada |
| `--chunkSize` | — | Strings por requisição; limitado ao que o serviço aceita |
| `--pluralSeparator` | `\|` | Separador das formas de plural nas mensagens |
| `--glossaryFile` | `.i18n-glossary.json` quando existir | Arquivo de glossário, usado pelo serviço `ai` |

```bash
i18n-micro translate --dryRun
I18N_TRANSLATE_TOKEN=... i18n-micro translate --service deepl --locale de,fr
i18n-micro translate --service ai --options provider:openai,model:gpt-4o-mini
i18n-micro translate --service libretranslate --options baseUrl:https://translate.example.com
```

### `sync` {#sync}

Remove chaves que o locale padrão não possui; para quando não é possível provar que isso é seguro. Chaves ausentes continuam ausentes

| Flag | Padrão | Descrição |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` do nuxt.config | Diretório de traduções, relativo ao projeto |
| `--ignore` | — | Globs separados por vírgula de arquivos-fonte a ignorar, relativos ao projeto |
| `--dryRun` | `false` | Lista o que seria removido; não grava nada |
| `--force` | `false` | Remove as chaves mesmo que não seja possível provar que é seguro |

```bash
i18n-micro sync --dryRun
```

### `clean` {#clean}

Remove chaves que nada no projeto usa; para quando isso não pode ser provado

| Flag | Padrão | Descrição |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` do nuxt.config | Diretório de traduções, relativo ao projeto |
| `--include` | — | Expressão regular: considera para remoção apenas as chaves correspondentes |
| `--exclude` | — | Expressão regular: nunca remove as chaves correspondentes |
| `--ignore` | — | Globs separados por vírgula de arquivos-fonte a ignorar, relativos ao projeto |
| `--dryRun` | `false` | Lista o que seria removido; não grava nada |
| `--force` | `false` | Remove as chaves mesmo que o uso não possa ser provado para todas elas |

```bash
i18n-micro clean --dryRun
i18n-micro clean --exclude '^errors\.'
```

## Refatoração {#refactoring}

### `text-to-i18n` {#text-to-i18n}

Substitui texto fixo em templates Vue por chamadas de tradução e relata texto fixo no código

| Flag | Padrão | Descrição |
| --- | --- | --- |
| `--translationFile` | `<translationDir>/<defaultLocale>.json` | Arquivo para onde vão as novas chaves |
| `--path` | o projeto inteiro | Arquivo ou diretório a processar |
| `--context` | — | Prefixo para as chaves geradas |
| `--ignore` | — | Globs separados por vírgula de arquivos-fonte a ignorar, relativos ao projeto |
| `--dryRun` | `false` | Mostra o que mudaria; não grava nada |
| `--interactive` | `false` | Confirma ou edita cada chave gerada |

```bash
i18n-micro text-to-i18n --dryRun
i18n-micro text-to-i18n --path components --context ui
```

### `rename` {#rename}

Renomeia uma chave ou um namespace em todos os locales e nos arquivos-fonte

| Flag | Padrão | Descrição |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` do nuxt.config | Diretório de traduções, relativo ao projeto |
| `--from` **\*** | — | Chave ou namespace atual |
| `--to` **\*** | — | Nova chave ou namespace |
| `--ignore` | — | Globs separados por vírgula de arquivos-fonte a ignorar, relativos ao projeto |
| `--dryRun` | `false` | Relata as mudanças; não grava nada |

**\*** obrigatório.

```bash
i18n-micro rename --from common.save --to actions.save
```

### `pseudo` {#pseudo}

Preenche um locale com pseudotraduções para encontrar problemas de layout e de texto fixo

| Flag | Padrão | Descrição |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` do nuxt.config | Diretório de traduções, relativo ao projeto |
| `--sourceLocale` | o locale padrão | Locale a ler |
| `--targetLocale` **\*** | — | Locale a preencher |
| `--replace` | `false` | Sobrescreve os valores existentes |

**\*** obrigatório.

### `format` {#format}

Reescreve os arquivos de locale com chaves ordenadas e indentação uniforme

| Flag | Padrão | Descrição |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` do nuxt.config | Diretório de traduções, relativo ao projeto |
| `--indent` | `2` | Espaços de indentação |
| `--sortKeys` | `true` | Ordena as chaves; use --no-sortKeys para manter a ordem delas |
| `--check` | `false` | Falha se um arquivo fosse mudar; não grava nada |

```bash
i18n-micro format --check
```

## Intercâmbio {#exchange}

### `export` {#export}

Exporta os arquivos de locale para PO ou CSV, com o texto do locale padrão como origem

| Flag | Padrão | Descrição |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` do nuxt.config | Diretório de traduções, relativo ao projeto |
| `--format` | `po` | Formato de arquivo: po, csv |
| `--dir` | `pots` para po, `csv_exports` para csv | Diretório de saída, relativo ao projeto |
| `--force` | `false` | Sobrescreve arquivos alterados desde a última exportação e nunca importados |

```bash
i18n-micro export --format csv
```

### `import` {#import}

Mescla arquivos PO ou CSV nos arquivos de locale

| Flag | Padrão | Descrição |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` do nuxt.config | Diretório de traduções, relativo ao projeto |
| `--format` | `po` | Formato de arquivo: po, csv |
| `--dir` | `pots` para po, `csv_exports` para csv | Diretório de entrada, relativo ao projeto |
| `--dryRun` | `false` | Relata o que seria importado; não grava nada |

```bash
i18n-micro import --format csv --dryRun
```

### `sync-remote` {#sync-remote}

Baixa as traduções globais do endpoint HTTP definido em .i18n-remote.json ou as envia para ele

| Flag | Padrão | Descrição |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` do nuxt.config | Diretório de traduções, relativo ao projeto |
| `--pull` | `true` | Baixa do remoto |
| `--push` | `false` | Envia para o remoto |
| `--force` | `false` | Em um pull, adota o valor remoto; em um push, sobrescreve o texto que só o remoto possui |
| `--dryRun` | `false` | Relata o que um pull mudaria; não grava nem envia nada |

```bash
i18n-micro sync-remote --dryRun
i18n-micro sync-remote --no-pull --push
```

## Regras de lint {#lint-rules}

| Regra | Encontra | Corrigida por `--fix` |
| --- | --- | --- |
| `no-trailing-spaces` | Espaços no fim de um valor ou de uma linha | sim |
| `no-multiple-spaces` | Dois ou mais espaços seguidos | sim |
| `no-empty-translation` | Um valor vazio ou em branco | não |

## Códigos de saída {#exit-codes}

| Código | Significado |
| --- | --- |
| `0` | Concluído, nada a relatar |
| `1` | Achados: `check`, `lint` ou `format --check` encontraram algo, `clean` ou `sync` não conseguiram provar que uma remoção é segura, `export` sobrescreveria trabalho não importado, `translate` deixou chaves de fora, `import` ou `sync-remote` encontraram um conflito, um push de `sync-remote` descartaria texto remoto. Um `--dryRun` de `clean`, `sync` ou de um pull de `sync-remote` relata isso e sai com `0` |
| `2` | Falha: uso incorreto, projeto ilegível, erro de rede ou de arquivo |

## Arquivos de configuração {#configuration-files}

| Arquivo | Usado por |
| --- | --- |
| `.i18n-lintrc.json` | `lint`: `enabledRules`, `disabledRules`, `customRegexRules` (`name`, `pattern`, `flags`, `description`, `replacement`) |
| `.i18n-remote.json` | `sync-remote`: `url`, `path`, `token`, `auth` (`username`, `password`). `type` pode ser omitido; só existe `custom` |
| `.i18n-glossary.json` | `translate --service ai`: `entries` com `source`, `target` e, opcionalmente, `from`, `to` |

## Variáveis de ambiente {#environment-variables}

| Nome | Usada para |
| --- | --- |
| `I18N_TRANSLATE_TOKEN` | Chave de API do `translate`. Também lida do `.env` |
| `I18N_REMOTE_TOKEN` | Bearer token do `sync-remote`. Também lido do `.env` |
| `AI_GATEWAY_API_KEY, OPENAI_API_KEY, ANTHROPIC_API_KEY` | Chave do serviço `ai`, quando `I18N_TRANSLATE_TOKEN` não está definida |
| `DEFAULT_LOCALE` | Substitui `defaultLocale`, como no módulo |
