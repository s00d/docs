Esta seção lista todas as opções, helpers, hooks, composables e componentes do módulo Nuxt, além da API exportada de cada pacote `@i18n-micro/*`. Use-a para consultar uma assinatura ou um valor padrão; o [Guia](/pt-BR/guide/getting-started) explica como usá-los. A maioria das tabelas aqui é gerada a partir do código-fonte, portanto elas correspondem ao código.

## Módulo Nuxt {#nuxt-module}

| Página | Abrange |
| --- | --- |
| [Opções do módulo](/pt-BR/api/module-options) | Todas as chaves `i18n` no `nuxt.config`, com tipo e valor padrão |
| [Helpers](/pt-BR/api/methods) | `$t`, `$tc`, `$tn`, `$td`, `$localePath`, `$switchLocale`, `$defineI18nRoute` e os demais |
| [Hooks](/pt-BR/api/events) | O hook de runtime `i18n:register` |

## Composables {#composables}

| Composable | Use para |
| --- | --- |
| [`useI18n`](/pt-BR/composables/useI18n) | Os helpers em `<script setup>` |
| [`useI18nLocale`](/pt-BR/composables/useI18nLocale) | Estado do locale e cookie em um plugin de detecção personalizado |
| [`useI18nHead`](/pt-BR/composables/useI18nHead) | Substituições por página das tags de SEO geradas |
| [`useLocaleHead`](/pt-BR/composables/useLocaleHead) | As tags de SEO como objeto, para o seu próprio `useHead` |

## Componentes {#components}

| Componente | Renderiza |
| --- | --- |
| [`<i18n-t>`](/pt-BR/components/i18n-t) | Uma tradução, com plural, formatação e interpolação de slots |
| [`<i18n-link>`](/pt-BR/components/i18n-link) | Um `NuxtLink` para a rota localizada |
| [`<i18n-switcher>`](/pt-BR/components/i18n-switcher) | Um dropdown de locales |
| [`<i18n-group>`](/pt-BR/components/i18n-group) | Um bloco com um prefixo de chave compartilhado |

## Servidor {#server}

Os handlers do Nitro usam `useTranslationServerMiddleware` e `useLocaleServerMiddleware`, não os helpers do cliente. Veja [Rotas de servidor](/pt-BR/guide/server-side-translations).

## Pacotes {#packages}

[APIs dos pacotes](/pt-BR/api/packages/overview) lista as exportações de cada pacote `@i18n-micro/*`, uma página gerada para cada.
