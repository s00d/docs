# Referência da API

## API de runtime

- [Métodos](/api/methods) `$t`, `$ts`, `$_t`, `$_ts`, troca de locale, helpers de roteamento
- [Eventos](/api/events) `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Traduções e cache](/api/cache) `TranslationStorage`, carregamento de payloads, `$clearCache`

## Middleware de servidor

Os handlers de servidor usam middleware dedicado (não os helpers `$t` do cliente):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) traduza em rotas de API e handlers de servidor
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) leia o locale detectado e seus metadados

Consulte o [guia completo de traduções server-side](/guides/server-side-translations) para configuração, prioridade de detecção de locale e exemplos.
