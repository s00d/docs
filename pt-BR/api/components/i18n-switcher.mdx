# 🌍 Componente `<i18n-switcher>`

O componente `<i18n-switcher>` do `Nuxt I18n Micro` fornece uma interface dropdown amigável para alternar entre diferentes locales na sua aplicação. Esse componente é altamente personalizável, permitindo integração transparente com o design e layout da sua aplicação.

Locales com `disabled: true` são **omitidos** do dropdown (eles permanecem disponíveis via `$getLocales()` para SEO / head tags). Apenas os locales alternáveis recebem `NuxtLink` + `hreflang`.

Toda parte é sem estilo por padrão: as props `custom*Style` recebem objetos de estilo inline, e os slots abaixo substituem inteiramente a marcação quando a estilização não for suficiente.

## 🛠️ Exemplos de uso

### Uso básico

```vue
<template>
  <i18n-switcher />
</template>
```

Isso renderiza um switcher de locale com estilização e comportamento padrão.

### Rótulos e estilos inline personalizados

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Este exemplo demonstra um switcher de locale totalmente personalizado com rótulos customizados e estilos inline.

## 🔌 Slots

Toda parte visual do switcher pode ser substituída. Os slots estão listados junto com a tabela de props acima; cada um recebe conteúdo de template:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Slots cujo nome termina em `-item`, `-link-content` ou começa com `before-item` recebem o objeto `locale` ao qual pertencem.

## 🎨 Visão geral dos estilos

O componente `<i18n-switcher>` vem com estilos básicos definidos usando estilos inline que podem ser facilmente sobrescritos passando estilos personalizados via props. Segue uma breve visão geral da estilização padrão:

- **Wrapper**: Controla o posicionamento do dropdown.
- **Button**: Estiliza o botão que abre o dropdown.
- **Dropdown**: Estiliza a lista de dropdown.
- **Items**: Estiliza cada item na lista.
- **Links**: Estiliza os links dentro de cada item.
- **Icon**: Estiliza o ícone indicador do dropdown.

Você pode personalizar esses estilos passando estilos personalizados via as respectivas props, garantindo que o switcher de locale se integre perfeitamente à UI da sua aplicação.
