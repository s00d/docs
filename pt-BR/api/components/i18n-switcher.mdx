# 🌍 Componente `<i18n-switcher>`

O componente `<i18n-switcher>` no `Nuxt I18n Micro` oferece uma interface dropdown amigável para trocar entre diferentes locales em sua aplicação. Este componente é altamente personalizável, permitindo integração perfeita com o design e o layout da sua aplicação.

Locales com `disabled: true` são **omitidos** do dropdown (eles permanecem disponíveis via `$getLocales()` para SEO / tags de head). Apenas locales alternáveis recebem `NuxtLink` + `hreflang`.

Todas as partes ficam sem estilo por padrão: as props `custom*Style` recebem objetos de estilo inline, e os slots abaixo substituem a marcação inteira quando o estilo não é suficiente.

## 🛠️ Exemplos de uso

### Uso básico

```vue
<template>
  <i18n-switcher />
</template>
```

Isso renderiza um seletor de locale com estilo e comportamento padrão.

### Rótulos personalizados e estilos inline

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Este exemplo demonstra um seletor de locale totalmente personalizado com rótulos e estilos inline personalizados.

## 🔌 Slots

Todas as partes visuais do seletor podem ser substituídas. Os slots estão listados na tabela de props acima; cada um recebe conteúdo de template:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Slots cujo nome termina com `-item`, `-link-content` ou começa com `before-item` recebem o objeto `locale` ao qual pertencem.

## 🎨 Visão geral de estilos

O componente `<i18n-switcher>` vem com estilos básicos definidos usando estilos inline que podem ser facilmente sobrescritos passando estilos personalizados via props. Aqui está uma visão geral do estilo padrão:

- **Wrapper**: controla o posicionamento do dropdown.
- **Botão**: estiliza o botão de toggle do dropdown.
- **Dropdown**: estiliza a lista do dropdown.
- **Itens**: estiliza cada item na lista.
- **Links**: estiliza os links dentro de cada item.
- **Ícone**: estiliza o ícone indicador do dropdown.

Você pode personalizar esses estilos passando estilos personalizados pelas props correspondentes, garantindo que o seletor de locale se integre perfeitamente à UI da sua aplicação.
