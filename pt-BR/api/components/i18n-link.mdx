# 🌍 Componente `<i18n-link>`

O componente `<i18n-link>` no `Nuxt I18n Micro` é um componente de link versátil que localiza rotas automaticamente com base no locale atual. Ele atua como um wrapper do componente `<NuxtLink>`, oferecendo recursos adicionais como estilização de link ativo e suporte a links externos.

## ⚙️ Props

| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | Rota de destino. Localizada automaticamente; uma URL externa é repassada sem alteração. |
| `activeStyle` | `Partial<CSSStyleValue>` | — | Estilo inline aplicado enquanto o link aponta para a rota atual. |

**\*** obrigatório.

### Slots

| Slot | Bindings | Descrição |
| --- | --- | --- |
| `default` | — | Conteúdo do link. |

{/* /generated:component:i18n-link */}

`to` aceita qualquer coisa que o `NuxtLink` aceita: um caminho, uma rota nomeada ou um objeto de rota resolvido. Uma URL absoluta é detectada e renderizada como um `<a target="_blank" rel="noopener noreferrer">` simples em vez de ser localizada.

## 🛠️ Exemplos de uso

### Uso básico

```vue
<i18n-link to="/about">About Us</i18n-link>
```

Este exemplo cria um link para a página `/about`, localizado no locale atual.

### Estilização de link ativo com estilos inline

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

O link terá texto em negrito quando o usuário estiver na página `/about`, permitindo estilizar o link ativo diretamente com estilos inline.

### Tratamento de links externos

O componente detecta automaticamente links externos e adiciona os atributos necessários para segurança.

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

Este link abrirá `https://example.com` em uma nova aba com `rel="noopener noreferrer"` aplicado.

## 🎨 Estilos

Agora o componente usa estilos inline para o estado ativo em vez de uma classe. Você pode personalizar esses estilos usando a prop `activeStyle`.

### Estilos ativos padrão

- **Font Weight**: `bold`
- **Cor**: herda a cor padrão do navegador (se nenhuma `color` for especificada em `activeStyle`).

Você pode sobrescrevê-los fornecendo estilos personalizados via prop `activeStyle`.

### Estilos ativos personalizados

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

Neste exemplo, o link ficará em negrito e verde quando ativo.

## 🚀 Recursos adicionais

### Slot para conteúdo personalizado

Você pode passar conteúdo personalizado dentro do link usando slots, tornando o componente flexível para diferentes casos de uso.

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### Aprimoramentos de acessibilidade

O componente suporta `aria-label` e outros atributos de acessibilidade para garantir uma experiência mais acessível.

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
