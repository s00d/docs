# 🌍 Componente `<i18n-t>`

O componente `<i18n-t>` no `Nuxt I18n Micro` é um componente de tradução flexível que suporta inserção de conteúdo dinâmico via slots. Ele permite interpolar traduções com componentes Vue personalizados ou conteúdo HTML, habilitando cenários avançados de localização.

| `plural` | `number \| string` | — | Contagem selecionando a forma plural. Defina para usar `$tc` em vez de `$t`. |
| `tag` | `string` | `'span'` | Elemento a renderizar. |
| `params` | `Record<string, string \| number \| boolean>` | `() => (\{\})` | Valores de interpolação substituídos na tradução. |
| `defaultValue` | `string` | `''` | Renderizado em vez do componente quando `hideIfEmpty` suprime uma tradução vazia. |
| `html` | `boolean` | `false` | Renderiza a tradução como HTML em vez de texto. Apenas para conteúdo que você controla. |
| `hideIfEmpty` | `boolean` | `false` | Não renderiza nada quando a tradução resolve para uma string vazia. |
| `customPluralRule` | `PluralFunc` | `null` | Regra plural apenas para este elemento, substituindo a configurada. |
| `number` | `number \| string` | — | Formata o valor com `$tn` e o passa para a tradução como `\{number\}`. |
| `date` | `Date \| string \| number` | — | Formata o valor com `$td` e o passa para a tradução como `\{date\}`. |
| `relativeDate` | `Date \| string \| number` | — | Formata o valor com `$tdr` e o passa para a tradução como `\{relativeDate\}`. |

**\*** obrigatório.

{/* /generated:component:i18n-t */}

Apenas um entre `plural`, `number`, `date` e `relativeDate` se aplica por vez; quando vários são definidos, o primeiro dessa lista vence.

### Exemplos por prop

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

## 🛠️ Exemplos de uso

### Uso básico

```vue
<i18n-t keypath="feedback.text" />
```

Isso renderiza a tradução de `feedback.text` dentro de uma tag `<span>`.

### Usando slots para conteúdo dinâmico

O componente `<i18n-t>` suporta o uso de slots para inserir dinamicamente componentes Vue ou outro conteúdo em partes específicas da tradução.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

Neste exemplo, o placeholder `\{link\}` na string de tradução `feedback.text` é substituído pelo componente `<nuxt-link>`, que por sua vez contém outro componente de tradução.

### Pluralização

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

Isso aplica automaticamente regras de pluralização com base no valor de `itemCount`.

## 🚀 Recursos adicionais

### Slot padrão

Se nenhum slot específico for fornecido, a tradução pode ser personalizada através do slot padrão, que fornece toda a string traduzida:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### Renderização condicional

Não renderize nada se a string de tradução estiver vazia usando a prop `hideIfEmpty`.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### Regra plural personalizada

Use uma função personalizada para lidar com a pluralização.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### Exemplo avançado com slots

Use slots para personalizar como o conteúdo da tradução é renderizado.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
