O módulo chama um hook de runtime (do app), `i18n:register`. Use-o quando um plugin ou um módulo adiciona traduções que não estão nos seus arquivos de `locales/`. Seu callback recebe uma função `register` que mescla traduções na página que está sendo exibida.

## `i18n:register` {#i18nregister}

```ts
'i18n:register': (
  register: (translations: unknown, locale?: string) => void,
  locale: string,
) => HookResult
```

| Argumento | Descrição |
| --- | --- |
| `register(translations, locale?)` | Mescla profundamente `translations` no chunk de página da rota que está sendo carregada, para `locale` (padrão: o `locale` do hook). Chaves já existentes são sobrescritas. |
| `locale` | O locale da rota que está sendo carregada. |

O hook é tipado por meio de `RuntimeNuxtHooks`, então `nuxtApp.hook('i18n:register', …)` não precisa de cast.

## Quando ele é disparado {#when-it-fires}

O plugin de carregamento (`i18n-plugin-loader`) o chama:

1. uma vez na inicialização, quando todos os plugins já foram executados (`app:created`) e antes de o app renderizar;
2. no seu `router.beforeEach`, depois que as traduções da página de destino são carregadas, quando o caminho muda — em toda navegação com `no_prefix`.

Todo callback e toda chamada de `register` são aguardados antes de o app renderizar ou de a navegação prosseguir, então a página é renderizada com as chaves mescladas. Com [`hooks: false`](/pt-BR/api/module-options#hooks) o hook nunca é chamado.

## Exemplo {#example}

```ts
// plugins/i18n-extra.ts
export default defineNuxtPlugin((nuxtApp) => {
  nuxtApp.hook('i18n:register', async (register, locale) => {
    const extra = await $fetch<Record<string, unknown>>(`/api/cms-strings/${locale}`)
    register(extra, locale)
  })
})
```

Este é um hook de runtime: registre-o com `nuxtApp.hook` em um plugin, não com `nuxt.hook` no `nuxt.config` ou no `setup` de um módulo. Um módulo adiciona esse tipo de plugin com `addPlugin`.
