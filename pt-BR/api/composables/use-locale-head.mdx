# 🌍 Composable `useLocaleHead`

O composable `useLocaleHead` é um utilitário do `Nuxt I18n Micro` que ajuda a gerenciar atributos de SEO e meta tags HTML para rotas localizadas. Ele gera dinamicamente atributos para `lang` e `dir` do documento HTML e cria tags `meta` e `link` para melhorar o SEO do seu conteúdo localizado.

## ⚙️ Opções

As tags de head de SEO para a rota atual: alternates `hreflang` para todo locale mais
`x-default`, um link canonical, `og:locale` e `lang`/`dir` no `<html>`.

Necessário apenas quando `meta` está desabilitado ou os padrões precisam de ajuste — com `meta: true` o módulo registra essas mesmas tags por conta própria.

## 🛠️ Valores retornados

O composable `useLocaleHead` retorna um objeto reativo e uma função de atualização que você deve chamar quando os dados de origem mudarem. Ambos os formatos estão na assinatura acima, gerada a partir do código-fonte.

### `metaObject`

Payload reativo de head (html attrs, meta, link) adequado para `useHead(metaObject)`.

- **Exemplo**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

Recalcula `metaObject` com base na rota, locale e config atuais. Chame-a quando as entradas mudarem — em uma mudança de rota, por exemplo.

- **Exemplo**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### Acessando `link` e `meta`

Os arrays `link` e `meta` estão acessíveis via `metaObject.value`:

- **Exemplo**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ Exemplos de uso

### Uso básico

Gere atributos de head específicos de locale com opções padrão.

```js
const head = useLocaleHead()
```

### Personalizar atributo identificador

Use um atributo identificador personalizado para as tags geradas.

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### Desabilitar atributos de SEO

Gere atributos de head sem adicionar meta e link tags relacionadas a SEO.

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### Especifique uma URL base

Defina uma URL base personalizada para URLs canônicas e alternadas.

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 Recursos adicionais

### Meta e link tags de SEO

Quando `addSeoAttributes` está habilitado, o composable gera automaticamente as seguintes tags:

- `og:locale` para o locale atual (`language_TERRITORY`, sublinhado). Derivado de `locale.og` ou convertido de `locale.iso` quando possível.
- `og:url` para a URL canônica da página.
- `og:locale:alternate` para versões de idioma alternativas.
- Links `rel="canonical"` e `rel="alternate"` para otimização de SEO.
- Link `hreflang="x-default"` apontando para a URL do locale padrão. Isso indica aos motores de busca qual URL mostrar a usuários cujo idioma não corresponde a nenhum dos locales definidos.

### Locale e direção dinâmicos

O composable determina dinamicamente os atributos `lang` e `dir` com base no locale da rota atual, garantindo que seu documento HTML esteja corretamente configurado para usuários internacionais.

### Tratando rotas localizadas

Se suas rotas são prefixadas com códigos de locale (ex.: `/en/about`), o composable ajusta inteligentemente o caminho completo para gerar URLs, garantindo que os atributos de SEO sejam precisos e relevantes.

Este composable simplifica o processo de otimizar sua aplicação Nuxt para audiências internacionais, garantindo que seu site esteja bem preparado para motores de busca e usuários globais.

## 🛠️ Exemplo de uso

O exemplo a seguir demonstra como usar o composable `useLocaleHead` dentro de um componente Vue com configurações padrão:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### Explicação do código

- **Composable `useLocaleHead`**: Este composable é chamado na seção `<script setup>` e retorna um objeto contendo `htmlAttrs`, `meta` e `link`.

- **Tag `<html>`**: Os atributos `lang` e `dir` do documento HTML são determinados dinamicamente com base no locale atual e são aplicados à tag `<html>`.

- **Seção `<head>`**:
  - **Meta tags**: Meta tags relacionadas a SEO são geradas, incluindo `og:locale`, `og:url` e tags `rel="canonical"` e `rel="alternate"` para especificar versões alternativas de idioma da página.
  - **Link tags**: Links canônicos, links para versões alternativas de idioma e o link `hreflang="x-default"` (apontando para a URL do locale padrão) são incluídos.

- **Seção `<body>`**: O conteúdo principal da página é exibido aqui. Neste exemplo, um cabeçalho e parágrafo simples são usados.

### 📝 Notas

1. **Atributos**: Os atributos usados (`lang`, `dir`, `rel`, `href`, `hreflang`, `property`, `content`) são extraídos do objeto retornado por `useLocaleHead`.

2. **Geração de tags de SEO**: Se a opção `addSeoAttributes` estiver definida como `true`, o composable gera automaticamente tags de SEO para o locale atual.

3. **URL base**: Você pode definir sua URL base personalizada usando a opção `baseUrl` para gerar corretamente links canônicos e alternativos.

Este exemplo demonstra como é fácil integrar `useLocaleHead` aos componentes da sua aplicação para garantir atributos de SEO corretos e melhorar a indexação de páginas localizadas por motores de busca.

## 🧩 Personalização e ciclo de vida

- `useLocaleHead` não se inscreve em mudanças por si só. Ele retorna `metaObject` e `updateMeta`.
- Você deve chamar `updateMeta()` quando as entradas mudarem (tipicamente em mudança de rota), por exemplo em um plugin:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## Quando usar `useI18nHead`

Quando `meta: true` (o padrão), prefira [`useI18nHead`](/api/composables/use-i18n-head) para overrides **por página** (hreflang customizado, `og:title` extra, desabilitação parcial). Use `useLocaleHead` diretamente apenas quando `meta: false` ou você gerencia `useHead` por conta própria.
