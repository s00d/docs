# 🌍 Composable `useLocaleHead`

O composable `useLocaleHead` é um utilitário do `Nuxt I18n Micro` que ajuda você a gerenciar atributos SEO e meta tags HTML para rotas localizadas. Ele gera dinamicamente atributos para `lang` e `dir` do documento HTML e cria tags `meta` e `link` para melhorar o SEO do seu conteúdo localizado.

## ⚙️ Opções

```ts
useLocaleHead(options: UseLocaleHeadOptions): { metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }, MetaObject | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

As tags SEO de head para a rota atual: alternates `hreflang` para cada locale mais `x-default`, um link canônico, `og:locale` e `lang`/`dir` em `<html>`.

Necessário apenas quando `meta` está desabilitado ou os padrões precisam ser ajustados. Com `meta: true`, o próprio módulo registra as mesmas tags.

## 🛠️ Valores retornados

O composable `useLocaleHead` retorna um objeto reativo e uma função updater que você deve chamar quando os dados de origem mudarem. Ambos os formatos estão na assinatura acima, gerada a partir do código-fonte.

### `metaObject`

Payload de head reativo (html attrs, meta, link) adequado para `useHead(metaObject)`.

- **Exemplo**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

Recomputa `metaObject` com base na rota atual, no locale e na configuração. Chame-o quando as entradas mudarem. Em uma troca de rota, por exemplo.

- **Exemplo**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### Acessando `link` e `meta`

Os arrays `link` e `meta` são acessíveis via `metaObject.value`:

- **Exemplo**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ Exemplos de uso

### Uso básico

Gere atributos de head específicos do locale com opções padrão.

```js
const head = useLocaleHead()
```

### Personalizar o atributo identificador

Use um atributo identificador personalizado para as tags geradas.

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### Desabilitar atributos SEO

Gere atributos de head sem adicionar meta e link tags relacionados a SEO.

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### Especificar uma URL base

Defina uma URL base personalizada para URLs canônicas e alternativas.

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 Recursos adicionais

### Tags de SEO Meta e Link

Quando `addSeoAttributes` está habilitado, o composable gera automaticamente as seguintes tags:

- `og:locale` para o locale atual (`language_TERRITORY`, com underscore). Derivada de `locale.og` ou convertida de `locale.iso` quando possível.
- `og:url` para a URL canônica da página.
- `og:locale:alternate` para versões em idiomas alternativos.
- Links `rel="canonical"` e `rel="alternate"` para otimização de SEO.
- Link `hreflang="x-default"` apontando para a URL do locale padrão. Isso indica aos mecanismos de busca qual URL exibir aos usuários cujo idioma não corresponde a nenhum dos locales definidos.

### Locale e direção dinâmicos

O composable determina dinamicamente os atributos `lang` e `dir` com base no locale da rota atual, garantindo que seu documento HTML esteja corretamente configurado para usuários internacionais.

### Lidando com rotas localizadas

Se suas rotas são prefixadas com códigos de locale (por exemplo, `/en/about`), o composable ajusta inteligentemente o path completo ao gerar URLs, garantindo que os atributos de SEO sejam precisos e relevantes.

Este composable simplifica o processo de otimizar sua aplicação Nuxt para audiências internacionais, garantindo que seu site esteja bem preparado para mecanismos de busca e usuários globais.

## 🛠️ Exemplo de uso

O exemplo a seguir demonstra como usar o composable `useLocaleHead` dentro de um componente Vue com configurações padrão:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### Explicação do código

- **Composable `useLocaleHead`**: este composable é chamado na seção `<script setup>` e retorna um objeto contendo `htmlAttrs`, `meta` e `link`.

- **Tag `<html>`**: os atributos `lang` e `dir` do documento HTML são determinados dinamicamente com base no locale atual e são aplicados à tag `<html>`.

- **Seção `<head>`**:
  - **Meta tags**: meta tags relacionadas a SEO são geradas, incluindo `og:locale`, `og:url` e tags `rel="canonical"` e `rel="alternate"` para especificar versões em idiomas alternativos da página.
  - **Link tags**: links canônicos, links para versões em idiomas alternativos e o link `hreflang="x-default"` (apontando para a URL do locale padrão) são incluídos.

- **Seção `<body>`**: o conteúdo principal da página é exibido aqui. Neste exemplo, são usados um cabeçalho e um parágrafo simples.

### 📝 Notas

1. **Atributos**: os atributos usados (`lang`, `dir`, `rel`, `href`, `hreflang`, `property`, `content`) são extraídos do objeto retornado por `useLocaleHead`.

2. **Geração de tags SEO**: se a opção `addSeoAttributes` estiver definida como `true`, o composable gera automaticamente tags de SEO para o locale atual.

3. **URL base**: você pode definir sua URL base personalizada usando a opção `baseUrl` para gerar corretamente links canônicos e alternativos.

Este exemplo demonstra como é fácil integrar `useLocaleHead` nos componentes da sua aplicação para garantir atributos SEO corretos e melhorar a indexação de páginas localizadas nos mecanismos de busca.

## 🧩 Personalização e ciclo de vida

- `useLocaleHead` não se inscreve em mudanças por si só. Ele retorna `metaObject` e `updateMeta`.
- Você deve chamar `updateMeta()` quando as entradas mudarem (normalmente em trocas de rota), por exemplo a partir de um plugin:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## Quando usar `useI18nHead` em vez disso

Quando `meta: true` (o padrão), prefira [`useI18nHead`](/api/composables/use-i18n-head) para sobrescritas **por página** (hreflang personalizado, `og:title` extra, desabilitação parcial). Use `useLocaleHead` diretamente somente quando `meta: false` ou você mesmo gerencia `useHead`.
