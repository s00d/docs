# useI18nLocale

## Assinatura

Ponto de entrada centralizado para gerenciamento de locale de i18n.
Combina `useState('i18n-locale')`, o cookie de locale e utilitários de sincronização.

## Uso

```vue
<script setup>
const {
  locale,
  localeCookie,
  hashCookie,
  validLocales,

  getLocaleWithServerFallback,

  resolveInitialLocale,

  isValidLocale,
```

## API

| Propriedade/Método                                 | Tipo                                | Descrição                                                                          |
| ----------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| `locale`                                        | `Ref<string \| null>`               | Estado reativo do locale (`useState('i18n-locale')`)                                    |
| `localeCookie`                                  | `Ref`                               | Cookie de locale (quando a opção `localeCookie` está habilitada)                                |
| `hashCookie`                                    | `Ref`                               | Cookie usado quando `hashMode` está ativo                                                |
| `validLocales`                                  | `string[]`                          | Códigos de locale habilitados na config do módulo (exclui `disabled`)                        |
| `getLocale()`                                   | `() => string \| null`              | Locale atual: state → cookie (ou hash cookie em modo hash)                         |
| `getPreferredLocale()`                          | `() => string \| null`              | Locale de state/cookie **validado** contra `validLocales`, ou `null`             |
| `getLocaleWithServerFallback(serverLocale?)`    | `(serverLocale?) => string \| null` | State → cookie → contexto de servidor opcional (usado durante init em `no_prefix`)              |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string`             | Locale para carregar traduções: modo hash prefere state; caso contrário, lê da rota |
| `resolveInitialLocale(options)`                 | `(options) => string`               | Resolve o locale: state → `serverLocale` → route; sincroniza o state quando necessário             |
| `setLocale(locale)`                             | `(locale: string \| null) => void`  | Define o locale e sincroniza com cookies                                                       |
| `syncLocale(locale)`                            | `(locale: string \| null) => void`  | Sincroniza apenas cookies (sem atualização de state)                                                  |
| `isValidLocale(locale)`                         | `(locale) => boolean`               | Verifica se a string está em `validLocales`                                                 |

### Opções de `resolveInitialLocale`

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

Usado internamente pelo plugin principal na inicialização. Plugins customizados podem chamá-lo ao implementar fluxos de detecção alternativos.

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

Retorna o locale usado para carregar traduções e formatar mensagens para um dado objeto de rota.

## Definição programática de locale

Prefira `useI18nLocale()` em vez do uso direto de `useState('i18n-locale')`:

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
`setLocale()` atualiza apenas a preferência de locale (state + cookie). Para também recarregar o contexto de tradução ativo no cliente, use `$switchLocale()` de `useNuxtApp()` ou `useI18n()`. Isso importa especialmente para `no_prefix`, onde a URL não muda. Veja [FAQ — trocar locale sem mudar a URL](/guides/faq#-switch-locale-without-changing-the-url).
</Tip>
