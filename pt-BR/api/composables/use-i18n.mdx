# 🛠️ Composable `useI18n`

O composable `useI18n` do `Nuxt I18n Micro` dá acesso à maioria dos helpers de runtime de i18n em componentes e scripts. Os métodos estão disponíveis **com e sem o prefixo `$`** (por exemplo, `$t` e `t`).

Algumas injeções — `$defineI18nRoute` e `$clearCache` — estão disponíveis apenas em `useNuxtApp()`. Veja [Métodos — `$defineI18nRoute`](/api/methods#definei18nroute) e [`$clearCache`](/api/methods#clearcache).

## 📊 O que retorna

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Todos os helpers de runtime, como um objeto simples.

As mesmas funções que o plugin injeta como `$t`, `$tc` e assim por diante, disponíveis tanto sob o nome com prefixo `$` quanto com um alias sem prefixo — então `const \{ t \} = useI18n()` e
`const \{ $t \} = useI18n()` ambos funcionam.

**Retorna** — os helpers descritos na [referência de métodos](/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

Cada helper que ele retorna — `$t`, `$tc`, `$has`, `$switchLocale` e os demais — está listado com sua assinatura e documentado por completo na [referência de métodos](/api/methods).

## APIs disponíveis apenas em `useNuxtApp()`

Estas **não** são retornadas por `useI18n()`. Importe-as de `useNuxtApp()`:

| Método                     | Objetivo                                                                         |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Rotas de locale por página, restrições e traduções inline em `script setup` |
| `$clearCache()`            | Limpa o cache de traduções em memória e os chunks carregados                            |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Veja [Métodos](/api/methods) para assinaturas completas e exemplos.

## 🛠️ Exemplos de uso

### Obtenção básica de locale

Obtenha o locale atual da aplicação.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Tradução com parâmetros

Traduza uma string com parâmetros dinâmicos, com um valor padrão de fallback.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Trocando locales

Troca a aplicação para um locale diferente.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Gerando uma rota localizada

Gera uma rota localizada para o locale atual ou especificado.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
