---
title: "useLocaleHead"
description: "useLocaleHead monta as tags de SEO i18n (lang, dir, canonical, hreflang, og:locale) como um objeto que você passa para useHead."
---

`useLocaleHead()` monta as tags de head i18n para a rota atual: `lang` e `dir` em `<html>`, um link canônico, alternativas `hreflang` com `x-default`, `og:url`, `og:locale` e `og:locale:alternate`. Use-o quando você define [`meta: false`](/pt-BR/api/module-options#meta) e gerencia o `useHead` por conta própria; com `meta: true` o módulo já registra essas tags, e as alterações por página passam por [`useI18nHead`](/pt-BR/composables/useI18nHead).

## Assinatura {#signature}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { build: () => LocaleHead; metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }, LocaleHead | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

As tags de head de SEO para a rota atual: alternativas `hreflang` para cada locale mais
`x-default`, um link canônico, `og:locale` e `lang`/`dir` em `<html>`.

Necessário apenas quando `meta` está desativado ou os padrões precisam de ajuste — com `meta: true`
o módulo registra as mesmas tags por conta própria.

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| `options` | `UseLocaleHeadOptions` |  |

**Retorna** — `metaObject`, um ref com o objeto de head pronto para passar ao `useHead`; `updateMeta` o atualiza; `build` calcula o objeto de head a partir da rota atual (reativo quando lido dentro de um getter, por exemplo `useHead(() => build())`)

```ts
const { metaObject } = useLocaleHead({ addSeoAttributes: true })
useHead(metaObject)
```

## Opções {#options}

| Opção | Padrão | Descrição |
| --- | --- | --- |
| `addDirAttribute` | `true` | Define `dir` em `<html>` a partir do `dir` do locale (`'auto'` quando ele não tem um). |
| `identifierAttribute` | `'id'` | Atributo que identifica cada tag (`i18n-can`, `i18n-og`, `i18n-alternate-<hreflang>`, …), para que as atualizações substituam as tags em vez de adicioná-las. |
| `addSeoAttributes` | `true` | Emite as tags canonical, `hreflang` e `og:`. `false` mantém apenas `htmlAttrs`. |
| `baseUrl` | `'/'` | Origem adicionada a cada URL. Mantenha `'/'` para URLs relativas; passe `'https://example.com'` para URLs absolutas. |
| `autoUpdate` | `true` | Reconstrói `metaObject` quando a rota ou o estado `i18n-locale` muda. |

## O que ele emite {#what-it-emits}

- Nada em uma rota sem correspondência (404) ou com `disableMeta` para o locale ativo.
- Canonical e `og:url`: `$switchLocalePath(<active locale>)`, com a query reduzida a [`canonicalQueryWhitelist`](/pt-BR/api/module-options#canonicalquerywhitelist) e [`trailingSlash`](/pt-BR/api/module-options#trailingslash) aplicado.
- `hreflang`: um link por locale habilitado em que a página existe, `hreflang = iso || code`, ignorando locales com `seo: false`; com `hreflangBaseLanguage: true`, o primeiro locale regional de um idioma também emite a tag do idioma base. Nenhum com `no_prefix`.
- `x-default`: a URL do locale padrão, a menos que a estratégia seja `no_prefix`, o locale padrão tenha `seo: false` ou a página não exista nele.
- `og:locale` / `og:locale:alternate`: a partir do `og` do locale, ou do seu `iso` convertido (`en-US` → `en_US`); ignorado com um aviso em dev quando nenhum dos dois funciona.

## Exemplo {#example}

```ts
// app.vue, with i18n.meta: false
const { metaObject } = useLocaleHead({ baseUrl: 'https://example.com' })
useHead(metaObject)
```

`build()` retorna o mesmo objeto sem o ref: `useHead(() => build())` continua reativo sem um watcher.
