---
title: "useI18n"
description: "useI18n retorna os helpers de runtime (`$t`, `$tc`, `$localePath`, …) como um objeto simples, com e sem o prefixo `$`."
---

`useI18n()` retorna os helpers de runtime do módulo como um objeto simples. Use-o em `<script setup>`, composables e plugins em vez de recorrer a `useNuxtApp()`. Cada helper aparece com seu nome com `$` e com um alias sem prefixo: `t` e `$t` são a mesma função.

## Assinatura {#signature}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Todos os helpers de runtime, como um objeto simples.

As mesmas funções que o plugin injeta como `$t`, `$tc` e assim por diante, disponíveis tanto
pelo nome com prefixo de cifrão quanto por um alias sem prefixo — então `const { t } = useI18n()` e
`const { $t } = useI18n()` funcionam igualmente.

**Retorna** — os helpers descritos na [referência de métodos](/pt-BR/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

O objeto retornado contém todos os helpers de [`PluginsInjections`](/pt-BR/api/methods). Cada um está documentado na página [Helpers](/pt-BR/api/methods).

## Exemplo {#example}

```vue
<script setup lang="ts">
const { t, tc, localePath, switchLocale, getLocale } = useI18n()

const title = computed(() => t('page.title'))
</script>

<template>
  <h1>{{ title }}</h1>
  <p>{{ tc('items', 3) }}</p>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
  <button @click="switchLocale(getLocale() === 'en' ? 'de' : 'en')">{{ t('nav.switch') }}</button>
</template>
```

## Fora do tipo {#not-in-the-type}

`$defineI18nRoute` é tipado apenas em `useNuxtApp()`:

```ts
const { $defineI18nRoute } = useNuxtApp()
```
