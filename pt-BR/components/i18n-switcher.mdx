---
title: "<i18n-switcher>"
description: "O componente <i18n-switcher> é um dropdown dos locales ativados, cada um com link para a página atual naquele locale."
---

`<i18n-switcher>` renderiza um botão com o locale ativo e um dropdown com todos os locales ativados, incluindo o ativo. Use-o para ter um menu de idiomas pronto; crie o seu próprio a partir de [`$getLocales`](/pt-BR/api/methods#$getlocales) e [`$switchLocalePath`](/pt-BR/api/methods#$switchlocalepath) quando precisar de uma marcação diferente. Cada item aponta para a página atual naquele locale.

## Props e slots {#props-and-slots}

| Prop | Tipo | Padrão | Descrição |
| --- | --- | --- | --- |
| `customLabels` | `Record<string, string>` | `() => ({})` | Nome de exibição por código de locale, substituindo o `displayName` da configuração do locale. |
| `customWrapperStyle` | `CSSProperties` | `() => ({})` | Estilo inline para o wrapper externo. |
| `customButtonStyle` | `CSSProperties` | `() => ({})` | Estilo inline para o botão que abre o dropdown. |
| `customDropdownStyle` | `CSSProperties` | `() => ({})` | Estilo inline para o painel do dropdown. |
| `customItemStyle` | `CSSProperties` | `() => ({})` | Estilo inline para cada item do dropdown. |
| `customLinkStyle` | `CSSProperties` | `() => ({})` | Estilo inline para o link dentro de um item. |
| `customActiveLinkStyle` | `CSSProperties` | `() => ({})` | Estilo inline para o link do locale atualmente ativo. |
| `customDisabledLinkStyle` | `CSSProperties` | `() => ({})` | Estilo inline para o botão do locale *atual* quando ele está com `disabled: true` na configuração. |
| `customIconStyle` | `CSSProperties` | `() => ({})` | Estilo inline para o ícone de seta no botão. |

### Slots {#slots}

| Slot | Bindings | Descrição |
| --- | --- | --- |
| `before-button` | — | Conteúdo antes do botão que abre o dropdown. |
| `before-selected-locale` | — | Conteúdo antes do rótulo do locale ativo dentro do botão. |
| `after-selected-locale` | — | Conteúdo depois do rótulo do locale ativo dentro do botão. |
| `before-dropdown` | — | Conteúdo entre o botão e o painel do dropdown. |
| `before-dropdown-items` | — | Conteúdo no topo do dropdown, acima da lista de locales. |
| `before-item` | `locale` | Conteúdo antes de cada item de locale. |
| `before-link-content` | `locale` | Conteúdo antes do rótulo de um locale dentro do seu link. |
| `after-link-content` | `locale` | Conteúdo depois do rótulo de um locale dentro do seu link. |
| `after-item` | `locale` | Conteúdo depois de cada item de locale. |
| `after-dropdown-items` | — | Conteúdo na parte inferior do dropdown, abaixo da lista de locales. |
| `after-dropdown` | — | Conteúdo depois do painel do dropdown. |

## Comportamento {#behaviour}

- Lista todos os locales sem `disabled: true`, incluindo o ativo.
- Cada item é um `<a>` para `$switchLocalePath(code)`. Um caminho é resolvido sob `app.baseURL`; um `baseUrl` de locale em outro domínio permanece absoluto. Ele tem `hreflang` e `lang` definidos como `iso || code`, `dir` quando o locale tem um, `aria-current="page"` no locale atual e a classe `switcher-locale-<code>`. Um clique chama `$switchLocale(code)` e fecha o dropdown; com uma tecla modificadora, o comportamento fica a cargo do navegador.
- A lista permanece no HTML do servidor, oculta, para que os crawlers vejam os links. Escape ou um clique fora a fecham.
- Rótulo: `customLabels[code]`, depois o `displayName` do locale, depois o código (com um aviso em dev).
- Estilos: pequenos padrões inline (botão e painel brancos com borda, o item ativo em negrito e azul). Cada prop `custom*Style` é aplicada após o padrão da sua parte. O botão tem as classes `i18n-switcher-button` e `language-switcher`, o wrapper `i18n-switcher-wrapper` e a lista `i18n-switcher-dropdown`. As posições usam propriedades CSS lógicas, então `dir="rtl"` funciona.

## Exemplo {#example}

```vue
<template>
  <i18n-switcher
    :custom-labels="{ en: 'English', de: 'Deutsch' }"
    :custom-button-style="{ borderRadius: '4px' }"
  >
    <template #before-link-content="{ locale }">
      <img :src="`/flags/${locale.code}.svg`" alt="" width="16" />
    </template>
  </i18n-switcher>
</template>
```
