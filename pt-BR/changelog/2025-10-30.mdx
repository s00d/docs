**Data**: 2025-10-30

**Versão**: `v2.0.0`

![Versão v2.0.0](/images/2.0.0.png)

Estamos introduzindo HMR no lado do servidor para arquivos de tradução em desenvolvimento. Quando um JSON de tradução muda, o cache do servidor invalida apenas as chaves afetadas, e as requisições seguintes recebem dados atualizados imediatamente — sem necessidade de reiniciar.

## O que há de novo? {#what’s-new}

- HMR no lado do servidor para arquivos de tradução
- Invalidação instantânea do cache por página/locale
- Experiência de desenvolvimento fluida ao editar conteúdo

## Como funciona {#how-it-works}

- O watcher em `src/runtime/server/plugins/watcher.dev.ts` observa `<rootDir>/<translationDir>/**/*.json`
- Arquivos de página (por exemplo, `pages/<page>/<locale>.json`) invalidam `_locales:merged:<page>:<locale>`
- Arquivos no nível raiz (por exemplo, `<locale>.json`) invalidam todas as chaves mescladas desse locale
- Registrado automaticamente a partir de `src/module.ts` em desenvolvimento quando `experimental.hmr !== false`

## Configuração {#configuration}

```ts
export default defineNuxtConfig({
  i18n: {
    experimental: { hmr: true }, // default in dev
  },
})
```
