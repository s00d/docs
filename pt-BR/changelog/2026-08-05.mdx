Releases: **v3.22.0 → v3.26.0**.

## Novos recursos

- **API de memória de tradução.** Leia e aplique patches no dicionário ativo do locale em runtime com `$resolveTranslations()` e `$setTranslation(key, value)`. Útil para DevTools, testes e editores in-app. Consulte [Métodos](/api/methods#resolvetranslations).
- **`numberFormats` e `datetimeFormats` nomeados.** Configure formatos nomeados compatíveis com Vue I18n por locale e chame `$tn(1000, 'currency')` ou `$td(date, 'short')`. Consulte [Opções do módulo](/api/module-options).
- **Controle de cache HTTP em payloads `/_locales`.** A nova opção [`httpCacheDuration`](/api/module-options) define `Cache-Control: public, max-age=…, immutable` nos payloads de tradução. O padrão é um ano, combinado de forma segura com o cache-busting `?v={dateBuild}`.
- **Payloads de tradução comprimidos.** Quando `nitro.compressPublicAssets` está habilitado, os payloads públicos de tradução são comprimidos automaticamente. Consulte o [guia de desempenho](/guides/performance).
- **Utilitário `splitLocaleRoutes`.** Construa tanto `pages` quanto `globalLocaleRoutes` a partir de uma única lista programática (para cenários de `pages:extend`), indexada por nome de rota. Consulte [Rotas de locale personalizadas](/guides/custom-locale-routes#programmatic-routes-pagesextend--244).
- **Fallback `site.url` para a base de SEO.** Quando `metaBaseUrl` não está definida, as tags SEO recorrem a `site.url` do `nuxt-site-config` se presente, ou à origem da requisição. Consulte [`metaBaseUrl`](/api/module-options).

## Atualizações

- **Adaptador Astro.** Isolamento de contexto de roteamento, além do encaixe para `numberFormats` e `datetimeFormats`.
- **React e Preact.** O `I18nSwitcher` agora define corretamente os atributos `aria-haspopup` e `aria-expanded`.
- **Benchmarks.** Os benchmarks de desempenho foram migrados para uma CLI baseada em citty.
- **Content fingerprint `dateBuild`.** O `dateBuild` padrão agora é um fingerprint de conteúdo, portanto `?v=` no payload só muda quando as traduções realmente mudam.

## Correções

- **Roteamento.**
  - Os matchers de rotas localizadas agora lidam corretamente com paths com hifens, aninhados e segmentos parametrizados.
  - Pais aninhados são mantidos quando uma rota filha é absoluta.
  - O `hreflang` é emitido a partir do `iso` do locale, não do código de roteamento.
  - A troca de locale em `no_prefix` agora substitui o histórico em vez de fazer push.
- **Redirecionamentos.**
  - `autoDetectPath` é respeitado para redirecionamentos de preferência via cookie e `Accept-Language`.
  - Aliases `localeRoutes` são preservados em `autoDetectPath: '/'`.
- **Traduções.**
  - Funções de plural personalizadas que retornam `null` agora recorrem à regra plural padrão.
  - Camadas de tradução se mesclam sem achatar dumps.
  - Locales desabilitados são omitidos dos payloads públicos premerged.
  - O HMR ignora gravações de arquivo no-op e re-mescla concorrentemente em mudanças no locale raiz.
- **Switcher.** Oculta locales `disabled` e restaura a precedência de `customDisabledLinkStyle` e do estilo ativo.
- **Módulo.** Fez a ponte com os tipos `Plugin` do unplugin Vite 8 para compatibilidade com o Nuxt Kit.
- **SSR.** O SSR no Node agora lê dos payloads públicos (sem import Rollup `raw:`).

## Breaking changes (v3.22.0)

- Chunks de SSR movidos de `useState('i18n-ssr-chunks')` para `nuxtApp.payload.data['i18n-ssr-chunks']`.
- `getAllTranslations()` foi removido do `@i18n-micro/vue`. Use `resolveTranslations()`, `getStorage()` ou `getRouteCache()`.
- O `dateBuild` padrão agora é um fingerprint de conteúdo, portanto o `?v=` do payload mudará uma vez ao fazer upgrade.
