# 🛠️ DevTools no `nuxt-i18n-micro`

## Vue DevTools (extensão de navegador)

Em desenvolvimento, o módulo pode registrar um inspector customizado e uma timeline no **Vue DevTools** via `@vue/devtools-api`. Isso é separado da aba do Nuxt DevTools descrita abaixo.

| Ferramenta | Ideal para |
|------|----------|
| **Vue DevTools** | Locale ativo, cache de traduções em memória, timeline de `$t` (`debug: true`), eventos de chaves ausentes |
| **Aba do Nuxt DevTools** | Edição de arquivos JSON em disco, visão geral de configuração, import/export |

O plugin do vue-devtools é registrado apenas durante `nuxt dev` (não em builds de produção). O estado da ponte apenas em dev no plugin principal é eliminado por dead-code elimination via `import.meta.dev`.

Desabilite a integração com o navegador mantendo a aba do Nuxt:

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

Eventos detalhados de timeline do `$t` exigem `debug: true`.

## 📖 O que é o Nuxt DevTools?

O DevTools é um assistente de desenvolvimento poderoso integrado de forma transparente ao módulo `nuxt-i18n-micro`. Ele oferece uma interface intuitiva para gerenciar tarefas de localização e tradução, tornando seu fluxo de trabalho mais rápido e eficiente. Projetado para desenvolvedores que valorizam praticidade, o Nuxt DevTools preenche a lacuna entre codificação e gerenciamento em runtime.

## 🌟 Principais recursos do DevTools no `nuxt-i18n-micro`

### 1. **Gerenciamento de locales**

Navegue, selecione e gerencie locales na sua aplicação com facilidade. Seja trabalhando com um único idioma ou vários, o DevTools oferece um hub centralizado para lidar com todas as configurações de localização.

### 2. **Edição de traduções**

Edite arquivos de tradução diretamente através de um editor JSON integrado. Isso elimina a necessidade de ferramentas externas, permitindo atualizações e mudanças em tempo real sem interromper o seu fluxo de trabalho.

### 3. **Importação e exportação de arquivos**

Simplifique o processo de gerenciamento de arquivos de tradução:

- **Exportação**: Salve traduções como um arquivo JSON para backups ou uso externo.
- **Importação**: Carregue arquivos de tradução atualizados no projeto para manter o conteúdo em dia.

### 4. **Prévias em tempo real**

Veja as mudanças imediatamente no ambiente de desenvolvimento. Esse recurso garante que traduções e configurações estejam corretas antes de irem para produção.

### 5. **Integração transparente com o Nuxt**

O DevTools funciona nativamente com o `nuxt-i18n-micro`, ampliando suas capacidades sem exigir configuração adicional. Ele se adapta às suas necessidades de localização mantendo a estrutura modular e flexível do Nuxt.

## 🛠️ Por que usar o DevTools?

O Nuxt DevTools é uma adição indispensável para projetos que exigem localização. Ele ajuda desenvolvedores ao:

- **Economizar tempo**: Automatiza tarefas repetitivas como gerenciamento de arquivos e validação de formato.
- **Reduzir erros**: Oferece um ambiente seguro e intuitivo para editar traduções.
- **Melhorar a colaboração**: Permite que não desenvolvedores gerenciem traduções facilmente.
- **Otimizar fluxos de trabalho**: Consolida várias tarefas de localização em uma única interface.

Com o Nuxt DevTools integrado ao `nuxt-i18n-micro`, gerenciar aplicações multilíngues se torna simples e eficiente. Seja para ajustar traduções ou adicionar novos locales, o DevTools oferece as ferramentas necessárias para entregar experiências polidas e amigáveis ao usuário.
