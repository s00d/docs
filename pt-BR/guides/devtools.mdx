# 🛠️ DevTools no `nuxt-i18n-micro`

## Vue DevTools (extensão do navegador)

Em desenvolvimento, o módulo pode registrar um inspector e timeline personalizados do **Vue DevTools** via `@vue/devtools-api`. Isso é separado da aba do Nuxt DevTools abaixo.

| Ferramenta | Ideal para |
|------|----------|
| **Vue DevTools** | Locale ao vivo, cache de traduções em memória, timeline de `$t` (`debug: true`), eventos de chave ausente |
| **Aba do Nuxt DevTools** | Edição de arquivos JSON em disco, visão geral da config, import/export |

O plugin do vue-devtools é registrado apenas durante `nuxt dev` (não em builds de produção). O estado de bridge apenas em dev no plugin principal é removido pela eliminação de código morto de `import.meta.dev`.

Desabilite a integração com o navegador mantendo a aba do Nuxt:

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

Eventos verbose da timeline de `$t` exigem `debug: true`.

## 📖 O que é o Nuxt DevTools?

O DevTools é um assistente de desenvolvimento poderoso integrado ao módulo `nuxt-i18n-micro`. Ele oferece uma interface intuitiva para gerenciar tarefas de localização e tradução, tornando seu fluxo de trabalho mais rápido e eficiente. Projetado para desenvolvedores que valorizam praticidade, o Nuxt DevTools une o desenvolvimento e a gestão em runtime.

## 🌟 Principais recursos do DevTools no `nuxt-i18n-micro`

### 1. **Gerenciamento de locale**

Navegue, selecione e gerencie locales em sua aplicação sem esforço. Trabalhando com um único idioma ou vários, o DevTools oferece um hub centralizado para lidar com todas as configurações de localização.

### 2. **Edição de traduções**

Edite arquivos de tradução diretamente por um editor JSON integrado. Isso elimina a necessidade de ferramentas externas, permitindo atualizações e mudanças em tempo real sem interromper seu fluxo de trabalho.

### 3. **Importação e exportação de arquivos**

Simplifique o processo de gerenciar arquivos de tradução:

- **Exportar**: salve traduções como JSON para backups ou uso externo.
- **Importar**: carregue arquivos de tradução atualizados no projeto para manter o conteúdo em dia.

### 4. **Previews em tempo real**

Veja as mudanças imediatamente dentro do ambiente de desenvolvimento. Esse recurso garante que traduções e configurações estejam corretas antes de ir para produção.

### 5. **Integração perfeita com Nuxt**

O DevTools funciona nativamente com o `nuxt-i18n-micro`, aprimorando suas capacidades sem exigir configuração adicional. Ele se adapta às suas necessidades de localização mantendo a estrutura modular e flexível do Nuxt.

## 🛠️ Por que usar o DevTools?

O Nuxt DevTools é uma adição indispensável para projetos que exigem localização. Ele ajuda os desenvolvedores:

- **Economizando tempo**: automatiza tarefas repetitivas como gerenciamento de arquivos e validação de formato.
- **Reduzindo erros**: oferece um ambiente seguro e intuitivo para editar traduções.
- **Melhorando a colaboração**: permite que não-desenvolvedores gerenciem traduções facilmente.
- **Simplificando fluxos**: consolida múltiplas tarefas de localização em uma única interface.
