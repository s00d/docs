# Usando traduções em componentes

Uma vez que o módulo esteja instalado e configurado, você pode exibir traduções chamando `$t('sua_chave')` nos seus templates e scripts Vue.

## 1. Arquivos de tradução raiz e específicos de página

1. As traduções **de nível raiz** ficam diretamente sob a pasta `/locales` (ex.: `/locales/en.json`, `/locales/fr.json`). Em tempo de build, elas são mescladas automaticamente em cada arquivo específico de página, tornando-as disponíveis em todas as páginas.
2. As traduções **específicas de página** ficam sob `/locales/pages/...`, correspondendo à estrutura de pastas das suas páginas Nuxt:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. Uso no template com `$t`

Nos seus arquivos `.vue`, você pode usar `$t` diretamente no template:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
`$t` pode retornar **objetos** se a chave apontar para um nó JSON aninhado (por exemplo, `$t('header')` → `\{ title: "Hi" \}`). Em templates isso é renderizado como `[object Object]`. Use `$ts` quando precisar de uma string garantida, ou informe uma chave mais específica como `$t('header.title')`. Veja [Referência da API — $t vs $ts](/api/methods#t) para detalhes.
</Tip>

## 3. Trocando o locale atual

Para mudar de idioma no seu app, você pode obter `$locale` do `useI18n()` e atribuir um novo código:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. Chaves aninhadas e placeholders

- **Chaves aninhadas** usam notação por ponto, ex.: `nested.key.deeper`.
- **Placeholders** permitem inserir valores dinâmicos:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. Dicas e boas práticas

- **Chaves conflitantes**: Se um arquivo específico de página contiver a mesma chave que um arquivo de nível raiz, a versão específica de página tem prioridade (as traduções raiz são mescladas como base em tempo de build).
- **Desabilitando arquivos por página**: Se preferir não usar traduções específicas de página, você pode definir `disablePageLocales: true` na configuração do Nuxt. Assim, apenas os arquivos `/locales/*.json` são usados.
- **Sem imports diretos**: Você não precisa fazer `import \{ useI18n \} from 'nuxt-i18n-micro'`; o recurso de auto-injeção do módulo cuida disso para você.

É isso! Com esses passos, você já pode **começar a obter traduções** de arquivos JSON de nível raiz ou específicos de página e **exibi-las** na sua aplicação Nuxt usando `$t`.

## Recursos adicionais

Para explorar recursos mais avançados, não deixe de conferir:

1. **Componente `<i18n-t>`**  
   O componente `<i18n-t>` é uma alternativa poderosa ao `$t`, especialmente útil em situações que envolvem elementos aninhados, uso avançado de placeholders e estruturas de tradução mais complexas.

- **Documentação**: [i18n-t](/api/components/i18n-t)

2. **Composable `useI18n`**  
   O composable `useI18n` oferece um conjunto completo de funções e propriedades reativas para gerenciar traduções, tratar troca de locale, formatação e muito mais.

- **Documentação**: [useI18n](/api/composables/use-i18n)
