# 🧪 Testando o módulo `Nuxt I18n Micro`

## 📖 Introdução aos testes

Testar o módulo `Nuxt I18n Micro` é crucial para garantir que os recursos de localização da sua aplicação funcionem como esperado. Esta documentação guiará você na configuração do ambiente de testes, na criação de configurações mock para o vitest e na escrita de testes para seus componentes. Para um exemplo prático, você pode consultar o [projeto de exemplo no GitHub](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/test-utils/example).

Veja [Testando estratégias de roteamento](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/testing-strategies.md) para como este repositório executa suas próprias suítes — os projetos Vitest `unit` / `integration` / `e2e`, os arquivos por estratégia (`test/strategies-*.test.ts`) e regressões de generate.

## 🛠️ Configurando o ambiente de testes

### 1. Instale `@i18n-micro/test-utils`

Primeiro, você precisa instalar os utilitários de teste para o `Nuxt I18n Micro`. Esse pacote fornece as ferramentas necessárias para mockar e testar suas configurações de i18n.

```bash
npm install @i18n-micro/test-utils --save-dev
```

### 2. Crie um arquivo de configuração mock

Em seguida, crie um arquivo para configurar a configuração mock de i18n. Este arquivo será usado para mockar as funções e utilitários de i18n durante seus testes.

```typescript
// tests/unit-setup.ts

import { mockNuxtImport } from '@nuxt/test-utils/runtime'
import { vi } from 'vitest'
import { i18nUtils } from '@i18n-micro/test-utils'

export function createFakeI18n() {
  return {
    $getLocale: vi.fn(i18nUtils.getLocale),
    $t: vi.fn(i18nUtils.t),
    $tc: vi.fn(i18nUtils.tc),
    $setLocale: vi.fn(i18nUtils.setLocale),
    $getLocaleName: vi.fn(i18nUtils.getLocaleName),
    $setLocaleName: vi.fn(i18nUtils.setLocaleName),
    $getLocales: vi.fn(i18nUtils.getLocales),
    $setLocales: vi.fn(i18nUtils.setLocales),
    $defaultLocale: vi.fn(i18nUtils.defaultLocale),
    $setDefaultLocale: vi.fn(i18nUtils.setDefaultLocale),
    $getRouteName: vi.fn(i18nUtils.getRouteName),
    $settRouteName: vi.fn(i18nUtils.settRouteName),
    $ts: vi.fn(i18nUtils.ts),
    $tn: vi.fn(i18nUtils.tn),
    $td: vi.fn(i18nUtils.td),
    $has: vi.fn(i18nUtils.has),
    $resolveTranslations: vi.fn(i18nUtils.resolveTranslations),
    $setTranslation: vi.fn(i18nUtils.setTranslation),
    $mergeTranslations: vi.fn(i18nUtils.mergeTranslations),
    $switchLocaleRoute: vi.fn(i18nUtils.switchLocaleRoute),
    $switchLocalePath: vi.fn(i18nUtils.switchLocalePath),
    $switchLocale: vi.fn(i18nUtils.switchLocale),
    $switchRoute: vi.fn(i18nUtils.switchRoute),
    $localeRoute: vi.fn(i18nUtils.localeRoute),
    $localePath: vi.fn(i18nUtils.localePath),
    $setI18nRouteParams: vi.fn(i18nUtils.setI18nRouteParams),
  }
}

mockNuxtImport<() => ReturnType<typeof createFakeI18n>>('useI18n', () => vi.fn(() => createFakeI18n()))

export const setTranslationsFromJson = i18nUtils.setTranslationsFromJson
```

### 3. Configure o Vitest

Agora, configure o Vitest para usar o arquivo de configuração mock e preparar o ambiente de testes.

```typescript
// vitest.config.ts

import { defineVitestConfig } from '@nuxt/test-utils/config'

export default defineVitestConfig({
  test: {
    watch: false,
    setupFiles: ['./tests/unit-setup.ts'],
    include: ['./**/*.spec.ts'],
  },
})
```

## 🧪 Escrevendo testes

### Componente de exemplo

Aqui está um exemplo de um componente simples que usa o composable `useI18n` para traduzir mensagens.

```vue
<script setup lang="ts">
const { $t } = useI18n()

const props = defineProps({
  message: {
    type: String,
    default: null,
  },
})

// Test to see that $t works in script setup as well as the template
const message = props.message || $t('defaultMessage')
</script>

<template>
  <div>
    <p>Test from component: {{ $t('welcome') }}</p>
    <p data-testid="message">Test message from props: {{ message }}</p>
  </div>
</template>
```

### Arquivo de teste

Agora, vamos escrever um teste para esse componente.

```typescript
// tests/unit/example.spec.ts

import { describe, it, expect, beforeEach } from 'vitest'
import { mount } from '@vue/test-utils'
import ExampleComponent from '@/components/ExampleComponent.vue'
import fs from 'fs'
import path from 'path'
import { setTranslationsFromJson } from './unit-setup'

describe('ExampleComponent', () => {
  beforeEach(async () => {
    const fileContent = fs.readFileSync(path.join(__dirname, '../../locales/en-GB.json')).toString()
    await setTranslationsFromJson('en', JSON.parse(fileContent))
  })

  it('renders the welcome message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.text()).toContain('Test from component: Welcome')
  })

  it('renders the default message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Default Message')
  })

  it('renders the custom message correctly', () => {
    const wrapper = mount(ExampleComponent, {
      props: {
        message: 'Custom Message',
      },
    })
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Custom Message')
  })
})
```

## 📝 Boas práticas para testes

- **🔧 Mocke as funções de i18n:** Sempre mocke as funções de i18n usando `@i18n-micro/test-utils` para garantir resultados de teste consistentes e previsíveis.
- **⚙️ Use Vitest para testes unitários:** O Vitest é um framework de testes poderoso para aplicações Vue. Use-o para escrever testes unitários para seus componentes.
- **📚 Documente seus testes:** Documente claramente o propósito e os resultados esperados de cada teste. Isso ajuda a manter clareza e facilita para outros (ou o seu eu futuro) entenderem os testes.

## 📊 Métodos utilitários de i18n

Abaixo está uma tabela descrevendo todos os métodos utilitários fornecidos por `@i18n-micro/test-utils`.

| Método                                          | Descrição                                                                                                                                |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `t(key, params, defaultValue)`                  | Traduz uma chave com parâmetros opcionais e um valor padrão.                                                                             |
| `tc(key, params, defaultValue)`                 | Traduz uma chave com suporte a pluralização.                                                                                               |
| `setTranslationsFromJson(locale, translations)` | Carrega traduções de um objeto JSON para um locale específico.                                                                               |
| `getLocale()`                                   | Retorna o locale atual.                                                                                                                |
| `setLocale(val)`                                | Define o locale atual.                                                                                                                   |
| `getLocaleName()`                               | Retorna o nome do locale atual.                                                                                                           |
| `setLocaleName(val)`                            | Define o nome do locale atual.                                                                                                              |
| `getLocales()`                                  | Retorna a lista de locales disponíveis.                                                                                                     |
| `setLocales(val)`                               | Define a lista de locales disponíveis.                                                                                                        |
| `defaultLocale()`                               | Retorna o locale padrão.                                                                                                                |
| `setDefaultLocale(val)`                         | Define o locale padrão.                                                                                                                   |
| `getRouteName()`                                | Retorna o nome da rota atual.                                                                                                            |
| `settRouteName(val)`                            | Define o nome da rota atual.                                                                                                               |
| `ts(key, params, defaultValue)`                 | Traduz uma chave e retorna o resultado como string.                                                                                       |
| `tn(value, options?)`                           | Formata um número com `Intl.NumberFormatOptions` inline. Formatos nomeados precisam de configuração do módulo e não estão disponíveis neste helper standalone. |
| `td(value, options?)`                           | Formata uma data com `Intl.DateTimeFormatOptions` inline. Formatos nomeados precisam de configuração do módulo e não estão disponíveis neste helper standalone. |
| `has(key)`                                      | Verifica se uma chave de tradução existe.                                                                                                        |
| `resolveTranslations()`                             | Retorna a árvore de traduções ativa para o locale e rota atuais.                                                                      |
| `setTranslation(key, value)`                    | Substitui o valor em `key` no dicionário ativo (substitui, não mescla).                                                                 |
| `mergeTranslations(newTranslations)`              | Mescla traduções no locale ativo em runtime.                                                                                     |

Seguindo esses passos, você pode testar efetivamente o módulo `Nuxt I18n Micro` e garantir que os recursos de localização da sua aplicação funcionem como esperado.
