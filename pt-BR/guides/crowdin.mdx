# 🌐 Guia de integração com o Crowdin

## 📖 Introdução

Integrar o Crowdin ao seu projeto simplifica o processo de localização e tradução, tornando mais fácil gerenciar traduções em múltiplos idiomas e plataformas. Este guia oferece um passo a passo para configurar o Crowdin com seu projeto, incluindo configuração, upload de fontes e download de traduções.

## 🔧 Instalação e configuração

Para começar com o Crowdin, você precisará instalar a Crowdin CLI globalmente em sua máquina e inicializá-la no diretório do seu projeto.

### 📦 Instalando a Crowdin CLI

Primeiro, instale a Crowdin CLI globalmente usando o npm:

```bash
npm install -g @crowdin/cli
```

### 🛠 Inicializando o Crowdin no seu projeto

Inicialize o Crowdin no seu projeto executando:

```bash
crowdin init
```

Esse comando o guiará pelo processo de configuração, incluindo definir o ID do projeto, o token de API e outros detalhes.

## 🗂️ Guia de configuração

### 📄 Arquivo de configuração do Crowdin (`crowdin.yml`)

O arquivo de configuração do Crowdin (`crowdin.yml`) define como seus arquivos-fonte são mapeados e onde as traduções devem ser colocadas. Abaixo há um exemplo de configuração:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Parâmetros de configuração principais

- **`project_id`**: o ID do seu projeto no Crowdin. Identifica o projeto no Crowdin onde as traduções são gerenciadas.
- **`api_token`**: o token de API usado para autenticação. Garanta que esse token tenha as permissões corretas para fazer upload e download de traduções.
- **`base_path`**: especifica o diretório base para os arquivos-fonte. Neste exemplo, as traduções são armazenadas no diretório `./locales`.
- **`base_url`**: a URL base da API do Crowdin.
- **`preserve_hierarchy`**: quando definido como `true`, o Crowdin manterá a estrutura de pastas dos seus arquivos-fonte no projeto.

### 📂 Configuração de arquivos

A seção `files` mapeia seus arquivos-fonte para os caminhos onde as traduções serão armazenadas. Por exemplo:

- **Caminho-fonte**: define a localização dos arquivos de tradução originais.
- **Caminho de tradução**: especifica onde os arquivos traduzidos serão armazenados no Crowdin. Placeholders como `%two_letters_code%` são usados para definir dinamicamente o código do idioma nos caminhos dos arquivos.

## ⬆️ Fazendo upload dos arquivos-fonte para o Crowdin

Com a configuração do Crowdin pronta, você pode enviar seus arquivos-fonte usando o seguinte comando:

```bash
crowdin upload sources
```

Esse comando envia todos os arquivos-fonte especificados na sua configuração para o Crowdin, tornando-os disponíveis para tradução.

## ⬇️ Baixando traduções do Crowdin

Após as traduções serem concluídas ou atualizadas no Crowdin, você pode baixá-las para o seu projeto usando:

```bash
crowdin download
```

Esse comando busca as traduções mais recentes do Crowdin e as salva de acordo com os caminhos especificados no seu arquivo de configuração.

## ⚙️ Boas práticas

### 🔑 Nomenclatura de chaves consistente

Garanta que as chaves de tradução sejam consistentes em todos os arquivos para evitar confusão e duplicação.

### 🧹 Manutenção regular

Revise e limpe periodicamente chaves de tradução não utilizadas para manter seus arquivos organizados e gerenciáveis.

### 🛠 Automatize uploads e downloads

Integre os comandos da Crowdin CLI ao seu pipeline de CI/CD para automatizar o upload de arquivos-fonte e o download de traduções, garantindo que suas traduções estejam sempre atualizadas.

Seguindo este guia, você conseguirá integrar o Crowdin ao seu projeto de forma tranquila, garantindo uma abordagem eficiente e organizada para gerenciar seus esforços de internacionalização.
