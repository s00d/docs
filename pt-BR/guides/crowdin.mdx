# 🌐 Guia de integração com o Crowdin

## 📖 Introdução

Integrar o Crowdin ao seu projeto simplifica o processo de localização e tradução, facilitando o gerenciamento de traduções em múltiplos idiomas e plataformas. Este guia fornece um passo a passo sobre como configurar o Crowdin em seu projeto, incluindo configuração, envio de fontes e download de traduções.

## 🔧 Instalação e configuração

Para começar com o Crowdin, você precisará instalar o Crowdin CLI globalmente na sua máquina e inicializá-lo no diretório do seu projeto.

### 📦 Instalando o Crowdin CLI

Primeiro, instale o Crowdin CLI globalmente usando npm:

```bash
npm install -g @crowdin/cli
```

### 🛠 Inicializando o Crowdin no seu projeto

Inicialize o Crowdin no seu projeto executando:

```bash
crowdin init
```

Esse comando irá guiá-lo pelo processo de configuração, incluindo a definição do seu project ID, API token e outros detalhes de configuração.

## 🗂️ Guia de configuração

### 📄 Arquivo de configuração do Crowdin (`crowdin.yml`)

O arquivo de configuração do Crowdin (`crowdin.yml`) define como seus arquivos fonte são mapeados e onde as traduções devem ser colocadas. Abaixo há um exemplo de configuração:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Principais parâmetros de configuração

- **`project_id`**: O ID do seu projeto Crowdin. Ele identifica o projeto no Crowdin onde as traduções são gerenciadas.
- **`api_token`**: O token de API usado para autenticação. Garanta que este token tenha as permissões corretas para enviar e baixar traduções.
- **`base_path`**: Especifica o diretório base para arquivos fonte. Neste exemplo, as traduções ficam armazenadas no diretório `./locales`.
- **`base_url`**: A URL base da API do Crowdin.
- **`preserve_hierarchy`**: Quando definido como `true`, o Crowdin manterá a estrutura de pastas dos seus arquivos fonte no projeto.

### 📂 Configuração de arquivos

A seção `files` mapeia seus arquivos fonte para os caminhos onde as traduções serão armazenadas. Por exemplo:

- **Caminho da fonte**: Define a localização dos arquivos de tradução originais.
- **Caminho da tradução**: Especifica onde os arquivos traduzidos serão armazenados no Crowdin. Placeholders como `%two_letters_code%` são usados para definir dinamicamente o código de idioma nos caminhos dos arquivos.

## ⬆️ Enviando arquivos fonte para o Crowdin

Uma vez que a configuração do Crowdin esteja pronta, você pode enviar seus arquivos fonte usando o seguinte comando:

```bash
crowdin upload sources
```

Esse comando envia todos os arquivos fonte especificados na sua configuração para o Crowdin, tornando-os disponíveis para tradução.

## ⬇️ Baixando traduções do Crowdin

Após as traduções serem concluídas ou atualizadas no Crowdin, você pode baixá-las para o seu projeto usando:

```bash
crowdin download
```

Esse comando obtém as traduções mais recentes do Crowdin e as salva conforme os caminhos especificados no seu arquivo de configuração.

## ⚙️ Boas práticas

### 🔑 Nomenclatura consistente de chaves

Garanta que as chaves de tradução sejam consistentes em todos os arquivos para evitar confusão e duplicação.

### 🧹 Manutenção regular

Revise periodicamente e remova chaves de tradução não utilizadas para manter seus arquivos organizados e gerenciáveis.

### 🛠 Automatize uploads e downloads

Integre os comandos do Crowdin CLI ao seu pipeline de CI/CD para automatizar o envio de arquivos fonte e o download de traduções, garantindo que suas traduções estejam sempre atualizadas.

Seguindo este guia, você conseguirá integrar o Crowdin ao seu projeto de forma transparente, garantindo uma abordagem eficiente e organizada para gerenciar seus esforços de internacionalização.
