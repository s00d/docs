# 📚 Nuxt I18n Micro voorbeelden en gebruik

Deze sectie bevat verschillende voorbeelden die laten zien hoe je `Nuxt I18n Micro` in je Nuxt.js-applicatie kunt gebruiken. Je ziet hoe je locales kunt wisselen, de componenten `<i18n-link>`, `<i18n-switcher>` en `<i18n-t>` kunt gebruiken en dynamisch met vertaalsleutels kunt werken.

## 🛠️ Basisopzet

Hier is een basisopzet om aan de slag te gaan met `Nuxt I18n Micro`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Locales wisselen

### Locales programmatisch wisselen

Dit voorbeeld laat zien hoe je programmatisch locales kunt wisselen met knoppen:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Voorbeeld-JSON voor localewisseling

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### `<i18n-switcher>`-component gebruiken

Het `<i18n-switcher>`-component biedt een dropdown voor localewisseling met aanpasbare labels:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 📝 Dynamische sleutels renderen uit vertaalbestanden

In sommige scenario's wil je itereren over dynamische sleutels die opgeslagen zijn in je vertaalbestanden en hun waarden voorwaardelijk renderen. Onderstaand voorbeeld laat zien hoe dit kan met `Nuxt I18n Micro`.

### Voorbeeld: dynamische sleutels renderen

Dit voorbeeld haalt een array van sleutels op uit een specifiek vertaalpad (in dit geval `dynamic`) en itereert daarover. Elke sleutel wordt gecontroleerd op bestaan via `$has` voordat de waarde wordt gerenderd met `$t`.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Voorbeeld-vertaalbestand (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Voorbeeld: dynamische sleutels renderen uit een object

In dit voorbeeld behandelen we een object dat in je vertaalbestand staat. We halen de sleutels van het object op en itereren erover, waarbij zowel de sleutelnamen als de bijbehorende waarden dynamisch worden gerenderd.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Voorbeeld-vertaalbestand (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 `<i18n-t>` gebruiken voor vertalingen met slots en interpolatie

Het `<i18n-t>`-component is handig voor het renderen van vertalingen met dynamische inhoud en HTML-tags:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### Voorbeeld-JSON voor `<i18n-t>`

```json
{
  "greeting": "Welcome to the page"
}
```

### Met interpolatie

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### Voorbeeld-JSON voor interpolatie

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 `$tc` gebruiken voor pluralisatie

De functie `$tc` in `Nuxt I18n Micro` verwerkt pluralisatie op basis van het aantal en de locale-instellingen. Dit is handig om berichten met tellingen dynamisch aan te passen, zoals items, meldingen of andere entiteiten waarvan het aantal kan variëren.

### Voorbeeld: `$tc` gebruiken voor pluralisatie

In het volgende voorbeeld tonen we een bericht dat het aantal appels aangeeft met `$tc`. De vertaalsleutel verwerkt meerdere meervoudsvormen op basis van de opgegeven telling.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### Voorbeeld-JSON voor pluralisatie

Zo definieer je de vertaling in je JSON-bestand om verschillende meervoudsvormen te verwerken:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Uitleg

- **`$tc('apples', 0)`**: Retourneert de eerste vorm, gebruikt wanneer de telling nul is (`"no apples"`).
- **`$tc('apples', 1)`**: Retourneert de tweede vorm, gebruikt wanneer de telling één is (`"one apple"`).
- **`$tc('apples', 10)`**: Retourneert de derde vorm met de tellingwaarde, gebruikt wanneer de telling twee of meer is (`"10 apples"`).

### Aanvullend voorbeeld met complexere pluralisatie

Als je applicatie complexere pluralisatieregels nodig heeft (bijvoorbeeld specifieke gevallen voor nul, één, twee, weinig, veel, overige), kun je de vertaalstrings dienovereenkomstig uitbreiden:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: Kan zo worden ingesteld dat het `"two apples"` retourneert.
- **`$tc('apples', 3)`**: Kan `"a few apples"` retourneren, afhankelijk van de regels die voor de telling zijn gedefinieerd.

## 🌐 `$tn` gebruiken voor getalopmaak

De functie `$tn` formatteert getallen volgens de huidige locale met de `Intl.NumberFormat`-API. Dit is handig voor het weergeven van getallen op een manier die past bij de regionale instellingen van de gebruiker, zoals valuta, percentages of andere getalindelingen.

### Voorbeeld: `$tn` gebruiken voor getalopmaak

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ `$td` gebruiken voor datum- en tijdopmaak

De functie `$td` formatteert datums en tijden volgens de huidige locale met de `Intl.DateTimeFormat`-API. Dit is handig om datums en tijden weer te geven in formaten die vertrouwd zijn voor de gebruiker op basis van hun locale-instellingen.

### Voorbeeld: `$td` gebruiken voor datum- en tijdopmaak

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ `$tdr` gebruiken voor relatieve datumopmaak

De functie `$tdr` formatteert datums als relatieve tijden (bijv. "5 minuten geleden", "2 dagen geleden") volgens de huidige locale met de `Intl.RelativeTimeFormat`-API. Dit is handig om tijdverschillen ten opzichte van de huidige datum en tijd weer te geven.

### Voorbeeld: `$tdr` gebruiken voor relatieve datumopmaak

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
