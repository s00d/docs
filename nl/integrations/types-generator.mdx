title: "Typegenerator"
description: "Genereer TypeScript-autocomplete voor vertaalsleutels uit je JSON-bestanden, in Nuxt of elk Vite-project."
---

`@i18n-micro/types-generator` leest elk JSON-bestand in je vertaalmap en schrijft een declaratie die alle sleutels opsomt. Voeg het toe wanneer je wilt dat je editor sleutels voorstelt in `t()`, `$t()` en `<I18nT keypath>`. Het werkt als Nuxt-module en als Vite- of Rollup-plugin, en genereert opnieuw wanneer een bestand verandert.

## Installeren {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/types-generator
```

```bash npm
npm install -D @i18n-micro/types-generator
```

```bash yarn
yarn add -D @i18n-micro/types-generator
```

</CodeGroup>

Peer dependency: `@nuxt/kit` `^3.18.0 || ^4.0.0`. Alleen het `/nuxt`-entry importeert het; in een project met alleen Vite kun je de peer-waarschuwing negeren.

## Nuxt {#nuxt}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro', '@i18n-micro/types-generator/nuxt'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

De module schrijft `.nuxt/types/i18n-micro.d.ts` en Nuxt voegt het toe aan de typecontext; je hoeft niets handmatig op te nemen. Hij leest `i18nTypes.translationDir`, en anders de plek waar `nuxt-i18n-micro` vertalingen leest: `translationDir` (uit `i18n` of inline module-opties, standaard `'locales'`) in elke layer, en `additionalTranslationDirs`. Het bewerken van een JSON-bestand in die map genereert de types opnieuw in `nuxi dev`. `i18nTypes.outputFile` wordt in Nuxt genegeerd (een waarschuwing meldt dat).

## Vite {#vite}

`I18nTypesPlugin` is een Vite-plugin, die Rollup ook accepteert. Roep voor een andere bundler `generateTypes` aan in een script.

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { I18nTypesPlugin } from '@i18n-micro/types-generator'

export default defineConfig({
  plugins: [
    vue(),
    I18nTypesPlugin({
      srcDir: process.cwd(),
      translationDir: 'src/locales',
      outputFile: 'src/i18n-micro.d.ts',
    }),
  ],
})
```

| Optie | Verplicht | Opmerkingen |
| --- | --- | --- |
| `srcDir` | ja | Basismap; `translationDir` wordt daartegen opgelost. |
| `translationDir` | ja | Map met de JSON-bestanden (inclusief submappen zoals `pages/`), of een array van mappen. |
| `outputFile` | nee | Waar de declaratie wordt geschreven; standaard `<srcDir>/i18n-micro.d.ts`. |

De plugin genereert één keer bij de start van de build en genereert op de dev-server opnieuw 300 ms na een wijziging in de map. Zorg ervoor dat `include` in je `tsconfig.json` het uitvoerbestand omvat.

## De sleutels gebruiken {#use-the-keys}

Het gegenereerde bestand breidt `DefineLocaleMessage` in `@i18n-micro/types` uit, waardoor `TranslationKey` jouw sleutels wordt:

```ts
declare module '@i18n-micro/types' {
  export interface DefineLocaleMessage {
    nav: object
    'nav.home': string
    'profile.title': string
  }
}
```

De sleutels zijn degene waarop `t()` antwoordt, ook objecten, uit elke locale en elk paginabestand, met het type van hun JSON-waarde. `TranslationKey` is de unie van die sleutels plus elke string, dus je krijgt autocomplete, geen fouten: een verkeerd gespelde of dynamische sleutel compileert nog steeds. Params en returnwaarden worden niet getypeerd.

Voor dynamische sleutels onder een bekend prefix beperkt `ScopedKey<'prefix'>` zich tot de overeenkomende sleutels:

```ts
import type { ScopedKey } from '@i18n-micro/types'

const statusText = (status: string) => t(`status.${status}` as ScopedKey<'status'>)
```

`TranslationKey` en `ScopedKey` komen uit `@i18n-micro/types` (React, Preact en Solid her-exporteren `TranslationKey`; Vue niet).

## API {#api}

| Export | Entry | Opmerkingen |
| --- | --- | --- |
| `I18nTypesPlugin(options)` | `@i18n-micro/types-generator` | Vite- en Rollup-plugin |
| `generateTypes(options)` | `@i18n-micro/types-generator` | schrijft het bestand, geeft het pad terug |
| `getTypesString(options)` | `@i18n-micro/types-generator` | geeft de declaratie terug zonder te schrijven |
| `formatKeyProperty(key)` | `@i18n-micro/types-generator` | hulpfunctie |
| Nuxt-module (`configKey: 'i18nTypes'`) | `@i18n-micro/types-generator/nuxt` | optie `translationDir` |

Volledige signaturen: [pakketreferentie](/nl/api/packages/types-generator).
