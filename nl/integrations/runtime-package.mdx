`@i18n-micro/runtime` is de framework-onafhankelijke i18n-instantie: woordenboeken, `t()`, meervoudsvormen, `Intl`-opmaak en een abonnement op wijzigingen, zonder `fs` en zonder framework. Gebruik het in gewone TypeScript, een web worker, een edge-functie of als basis voor je eigen binding. De packages voor React, Preact, Node en Astro breiden dezelfde klasse uit.

## Installeren {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/runtime
```

```bash npm
npm install @i18n-micro/runtime
```

```bash yarn
yarn add @i18n-micro/runtime
```

</CodeGroup>

Geen peer dependencies. Gebruik voor vertaalbestanden op schijf [`@i18n-micro/node`](/nl/integrations/nodejs-package).

## Installatie {#setup}

```ts
import { createI18n } from '@i18n-micro/runtime'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    en: { greeting: 'Hello, {name}!', apples: 'no apples | one apple | {count} apples' },
    de: { greeting: 'Hallo, {name}!' },
  },
  routeMessages: {
    about: { en: { title: 'About us' } },
  },
})
```

Alle opties (`plural`, `missingWarn`, `missingHandler`, `numberFormats`, `datetimeFormats`) staan in [de instantie](/nl/integrations/overview#the-instance).

## Vertalen {#translate}

```ts
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.tc('apples', 5) // '5 apples'
i18n.tn(1234.5) // '1,234.5'

i18n.setRoute('about')
i18n.t('title') // 'About us' (route dictionary)
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!' (root, still visible)
```

Laad later meer woordenboeken:

```ts
i18n.loadMessages({ fr: { greeting: 'Bonjour, {name} !' } }, { about: { fr: { title: 'À propos' } } })
i18n.addTranslations('fr', { nav: { home: 'Accueil' } }) // deep merge; pass false to replace

await i18n.loadFromUrl('/locales/fr.json', { locale: 'fr' })
await i18n.loadFromUrl('/locales/pages/about/fr.json', { locale: 'fr', routeName: 'about' })
await i18n.loadFromUrls([
  { url: '/locales/en.json', locale: 'en' },
  { url: '/locales/de.json', locale: 'de' },
])
```

`loadFromUrl` gebruikt `fetch` (geef `init` door voor headers) en gooit een fout bij een antwoord dat niet OK is. `loadFromUrls` laadt ze na elkaar.

## Van locale wisselen {#switch-locale}

```ts
i18n.locale = 'de'
i18n.t('greeting', { name: 'Ada' }) // 'Hallo, Ada!'
```

Wijzigingen van locale, route en woordenboek worden aan abonnees gemeld; zo renderen framework-bindings opnieuw:

```ts
const stop = i18n.subscribe(() => {
  document.querySelector('#greeting')!.textContent = i18n.t('greeting', { name: 'Ada' }) as string
})
i18n.locale = 'fr'
stop()
```

`getSnapshot()` retourneert een string die bij elke melding verandert (voor stores in de stijl van `useSyncExternalStore`).

## Per verzoek {#per-request}

De instantie bevat één locale en één route. Wissel op een server niet per verzoek een gedeelde instantie: twee gelijktijdige verzoeken zouden elkaars locale zien. `i18n.fork(locale)` geeft een verzoek een eigen instantie: eigen locale, fallback en route; dezelfde woordenboeken, formatters en regels. Een fork kost hetzelfde, hoeveel woordenboeken er ook zijn. Een fork ziet schrijfacties naar zijn ouder tot zijn eerste eigen schrijfactie, en zijn schrijfacties blijven in de fork. [Node.js](/nl/integrations/nodejs-package#per-request) voegt `run` toe.

## API {#api}

| Lid | Opmerkingen |
| --- | --- |
| `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has` | zie [Vertalen en opmaken](/nl/integrations/overview#translate-and-format) |
| `locale`, `fallbackLocale` | lezen/schrijven |
| `currentRoute`, `setRoute(name)`, `getRoute()` | actieve route, standaard `'index'` |
| `loadMessages(messages?, routeMessages?)` | veel locales en routes tegelijk samenvoegen |
| `addTranslations(locale, tree, merge = true)`, `addRouteTranslations(locale, route, tree, merge = true)` | |
| `loadFromUrl(url, { locale?, routeName?, init? })`, `loadFromUrls(entries)` | JSON via `fetch` |
| `hasTranslation(key)` | actieve locale, elke route (anders dan `has`, dat de actieve route en root controleert) |
| `setTranslation(key, value)`, `resolveTranslations()` | één sleutel schrijven; de samengevoegde boom lezen |
| `clear()`, `clearCache()` | alle woordenboeken verwijderen |
| `subscribe(cb)`, `getSnapshot()` | wijzigingsmeldingen |
| `storage` | `{ translations: Map<'locale:route', Translations> }` |

Een code die geen taaltag is, krijgt zijn meervoudsvormen uit `localeIso: { ua: 'uk-UA' }`; `localeIsoMap(locales)` bouwt dat op uit de items van een locale-lijst die een `iso` hebben.

Module-exports: `createI18n`, `I18n`, `fetchJsonTranslations`, `FormatService`, `interpolate`, `localeIsoMap` en de types `I18nOptions`, `LoadFromUrlOptions`, `LoadFromUrlEntry`, `TranslationStorage`, `Translations`, `Locale`, `PluralFunc`. Volledige signaturen: [package-referentie](/nl/api/packages/runtime).
