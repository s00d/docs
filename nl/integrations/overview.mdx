# Integraties

De `@i18n-micro`-pakketten zijn lichte, framework-specifieke versies van Nuxt I18n Micro, ontworpen voor integratie in verschillende frameworks en omgevingen. Deze pakketten bieden kern-internationalisatiefunctionaliteit met een minimale footprint en richten zich op essentiële vertaalfuncties en basiscomponenten.

## Overzicht

Deze integratiepakketten zijn **miniatuurversies** van de volledige Nuxt I18n Micro-module en bevatten alleen de essentiële functionaliteit die nodig is voor internationalisatie:

- **Kernvertaalfuncties** - Basisvertaalmethoden, meervoudsvorming en formattering.
- **Essentiële componenten** - Een kleine set UI-componenten voor gangbare i18n-taken.
- **Router-adapter-patroon** - Flexibele routeringsintegratie via adapter-abstractie.
- **TypeScript-ondersteuning** - Volledige typedefinities voor type-veilige ontwikkeling.

In tegenstelling tot de volledige Nuxt-module:

- Bevatten deze pakketten geen framework-specifieke routeringslogica.
- Moet je een router-adapter implementeren voor routeringsfuncties.
- Richten ze zich op vertaalfunctionaliteit in plaats van framework-integratie.
- Zijn ze ontworpen om waar mogelijk lichtgewicht en framework-onafhankelijk te zijn.

## Kerncomponenten

Alle framework-pakketten bevatten de volgende essentiële componenten:

### `<I18nT>`

Een vertaalcomponent die vertaalde tekst rendert met ondersteuning voor:

- **Parameter-interpolatie** - Vervang placeholders door dynamische waarden.
- **Meervoudsvorming** - Automatische selectie van de meervoudsvorm op basis van count.
- **Getalformattering** - Formatteer getallen volgens de locale.
- **Datumformattering** - Formatteer datums en relatieve tijden.
- **HTML-rendering** - Optionele HTML-content-rendering.
- **Standaardwaarden** - Fallback-tekst wanneer een vertaling ontbreekt.

**Voorbeeld:**

```vue
<!-- Vue -->
<I18nT keypath="greeting" :params="{ name: 'World' }" />
```

```tsx
// React
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```tsx
// Solid
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```astro
<!-- Astro -->
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

### `<I18nLink>`

Een gelokaliseerde linkcomponent die locale-prefixen in URL's automatisch afhandelt. Functies:

- **Automatische padlokalisatie** - Voegt locale-prefixen toe of verwijdert ze op basis van de routeringsstrategie.
- **Detectie van actieve status** - Markeert de huidige route.
- **Ondersteuning voor externe links** - Detecteert externe URL's automatisch en handelt die af.
- **Router-integratie** - Gebruikt de linkcomponent van de router-adapter wanneer beschikbaar.
- **Aangepaste styling** - Ondersteunt actieve en hover-states.

**Voorbeeld:**

```vue
<!-- Vue -->
<I18nLink to="/about" active-class="active">
  About Us
</I18nLink>
```

```tsx
// React
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```tsx
// Solid
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```astro
<!-- Astro -->
<I18nLink href="/about" class="nav-link">
  About Us
</I18nLink>
```

### `<I18nSwitcher>`

Een taalwisselcomponent die een dropdown- of lijstinterface biedt om van locale te wisselen. Functies:

- **Automatische locale-lijst** - Genereert opties uit de geconfigureerde locales.
- **Markering van de huidige locale** - Toont visueel de actieve taal.
- **Aangepaste labels** - Ondersteuning voor aangepaste weergavenamen per locale.
- **Router-integratie** - Navigeert automatisch naar gelokaliseerde paden.
- **Toegankelijkheid** - Correcte ARIA-attributen en toetsenbordnavigatie.

**Voorbeeld:**

```vue
<!-- Vue -->
<I18nSwitcher />
```

```tsx
// React
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```tsx
// Solid
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```astro
<!-- Astro -->
<I18nSwitcher />
```

### `<I18nGroup>`

Een component voor het groeperen van vertalingen met een gemeenschappelijk voorvoegsel, handig om vertalingen per pagina of feature te organiseren. Functies:

- **Prefix-scoping** - Voegt automatisch het voorvoegsel toe aan alle vertaalsleutels binnen de groep.
- **Geneste groepen** - Ondersteuning voor geneste vertaalgroepen.
- **Overzichtelijke organisatie** - Helpt vertaalstructuren georganiseerd te houden.

**Voorbeeld:**

```vue
<!-- Vue -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Gebruikt "home.title" -->
  <I18nT keypath="description" /> <!-- Gebruikt "home.description" -->
</I18nGroup>
```

```tsx
// React
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Gebruikt "home.title" */}
  <I18nT keypath="description" /> {/* Gebruikt "home.description" */}
</I18nGroup>
```

```tsx
// Solid
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Gebruikt "home.title" */}
  <I18nT keypath="description" /> {/* Gebruikt "home.description" */}
</I18nGroup>
```

```astro
<!-- Astro -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Gebruikt "home.title" -->
  <I18nT keypath="description" /> <!-- Gebruikt "home.description" -->
</I18nGroup>
```

## Gedeelde `createI18n`-opties \{#create-i18n-options\}

Elk framework-pakket wordt op dezelfde manier aangemaakt — alleen het type van de opties is genoemd naar het framework (`ReactI18nOptions`, `SolidI18nOptions`, enzovoort). De opties zelf zijn identiek:

| Eigenschap       | Type                                                       | Verplicht | Standaard        | Beschrijving                                       |
| ---------------- | ---------------------------------------------------------- | --------- | ---------------- | -------------------------------------------------- |
| `locale`         | `string`                                                   | ✅        | -                | Huidige locale-code (bijvoorbeeld `'en'`)          |
| `fallbackLocale` | `string`                                                   | ❌        | Hetzelfde als `locale` | Fallback-locale wanneer een vertaling ontbreekt |
| `messages`       | `Record<string, Translations>`                             | ❌        | `\{\}`             | Initiële vertaalberichten                          |
| `plural`         | `PluralFunc`                                               | ❌        | `defaultPlural`  | Aangepaste meervoudsfunctie                        |
| `missingWarn`    | `boolean`                                                  | ❌        | `true`           | Toon console-waarschuwingen voor ontbrekende vertalingen |
| `missingHandler` | `(locale: string, key: string, routeName: string) => void` | ❌        | -                | Aangepaste handler voor ontbrekende vertalingen    |

Alles daarbuiten is framework-specifiek en wordt gedocumenteerd op de pagina van dat pakket.

## Router-adapter-abstractie

Alle framework-pakketten gebruiken een **router-adapter-patroon** om i18n-functionaliteit los te koppelen van specifieke router-implementaties. Dit ontwerp biedt:

- **Flexibiliteit** - Gebruik elke router-library of helemaal geen router.
- **Framework-onafhankelijkheid** - Houd routeringslogica in je applicatie, niet in het i18n-pakket.
- **Lichte kern** - Het i18n-pakket blijft klein en gericht.

### Een router-adapter implementeren

Om routeringsfuncties te gebruiken, moet je de `I18nRoutingStrategy`-interface implementeren:

```typescript
interface I18nRoutingStrategy {
  getCurrentPath: () => string
  linkComponent?: Component
  push: (target: { path: string }) => void
  replace: (target: { path: string }) => void
  resolvePath?: (to: string | { path?: string }, locale: string) => string | { path?: string }
  getRoute?: () => { fullPath: string; query: Record<string, unknown> }
}
```

Elke pakketdocumentatie bevat volledige voorbeelden voor het implementeren van adapters voor populaire routers:

- **Vue**: voorbeeld met Vue Router-adapter
- **React**: voorbeeld met React Router-adapter
- **Solid**: voorbeeld met Solid Router-adapter
- **Astro**: voorbeeld met bestand-gebaseerde routering-adapter

## Kernfuncties

Alle pakketten delen deze kernfuncties:

### Vertaalmethoden

- `t()` - Basisvertaling met parameter-interpolatie
- `ts()` - Vertaling die altijd een string retourneert
- `tc()` - Vertaling met meervoudsvorming
- `tn()` - Getalformattering
- `td()` - Datumformattering
- `tdr()` - Relatieve tijdformattering
- `has()` - Controleren of een vertaalsleutel bestaat

### Localebeheer

- **Localewisseling** - Wijzig de huidige locale programmatisch.
- **Fallback-locale** - Automatische fallback wanneer een vertaling ontbreekt.
- **Route-specifieke vertalingen** - Vertalingen op paginaniveau organiseren.
- **Vertaal-caching** - Slimme caching voor performance.

### TypeScript-ondersteuning

Alle pakketten bieden:

- Volledige TypeScript-definities.
- Type-veilige vertaalsleutels (met de types generator).
- IntelliSense-ondersteuning in IDE's.
- Compile-time-foutcontrole.

## Aan de slag

1. **Kies je pakket** - Selecteer het pakket voor je framework.
2. **Installeer het pakket** - Gebruik je favoriete package-manager.
3. **Lees de documentatie** - Elk pakket heeft gedetailleerde setup-instructies.
4. **Implementeer de router-adapter** - Als je routeringsfuncties nodig hebt, implementeer de adapter.
5. **Begin met vertalen** - Gebruik componenten en methoden om vertalingen toe te voegen.

Voor gedetailleerde setup-instructies raadpleeg je de documentatie van je specifieke pakket:
