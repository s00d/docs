De `@i18n-micro/*`-pakketten brengen de vertaalkern van Nuxt I18n Micro naar Vue, React, Preact, Solid, Astro, VitePress en gewoon JavaScript. Gebruik ze wanneer je app geen Nuxt-app is, of wanneer een script of server buiten Nuxt dezelfde vertaalbestanden nodig heeft. Elk pakket deelt één instancemodel, één contract voor router-adapters en dezelfde vier componenten, die eenmalig op deze pagina worden beschreven.

De router-entry is een aparte import, zodat een app zonder router er nooit een bundelt.

`@i18n-micro/core`, `@i18n-micro/types` en `@i18n-micro/utils` worden met deze pakketten geïnstalleerd; je importeert ze zelden rechtstreeks. De signaturen van elke export staan in de gegenereerde [pakketreferentie](/nl/api/packages/overview).

Elk pakket heeft een playground onder `packages/<name>/playground` in de repository.

## De instance {#the-instance}

`createI18n(options)` retourneert één instance die de woordenboeken, de huidige locale en de huidige route bevat. De opties zijn in elk pakket hetzelfde:

| Optie | Type | Standaard | Opmerkingen |
| --- | --- | --- | --- |
| `locale` | `string` | verplicht | Actieve locale. |
| `fallbackLocale` | `string` | `locale` | Wordt geraadpleegd wanneer een sleutel in `locale` ontbreekt. |
| `messages` | `Record<locale, Translations>` | `{}` | Rootwoordenboeken (route `'index'`). |
| `routeMessages` | `Record<route, Record<locale, Translations>>` | `{}` | Routewoordenboeken. Alleen Runtime, React, Preact, Node en VitePress. |
| `plural` | `PluralFunc` | `defaultPlural` | Eigen meervoudsregel. |
| `missingWarn` | `boolean` | `true` | `console.warn` in de browser voor een ontbrekende sleutel, alleen in dev. |
| `missingHandler` | `(locale, key, routeName) => void` | — | Wordt aangeroepen in plaats van de waarschuwing. |
| `numberFormats` | `Record<locale, Record<name, Intl.NumberFormatOptions>>` | — | Benoemde formaten: `tn(9.5, 'currency')`. |
| `datetimeFormats` | `Record<locale, Record<name, Intl.DateTimeFormatOptions>>` | — | Benoemde formaten: `td(date, 'short')`. |
| `timeZone` | `string` | zone van de runtime | IANA-zone voor `td`-datums; heeft geen invloed op `tdr`. Stel het in zodat server en browser dezelfde datum renderen. |
| `now` | `() => number` | `Date.now` | De klok van `tdr`. Geef de hydratatie de tijd van de server mee, zodat beide dezelfde tekst renderen. |
| `localeIso` | `Record<code, string>` | — | BCP 47-tag voor meervoudsregels (`ua` → `uk-UA`). React, Preact en Solid halen deze uit `iso` in de `locales` van de provider. |

De woordenboeken staan in `i18n.storage.translations`, een `Map` met sleutels `locale:route` (`en:index`, `en:about`).

Een sleutel wordt opgezocht in het woordenboek van de huidige route en daarna in het rootwoordenboek, eerst voor `locale` en dan voor `fallbackLocale`. Een ontbrekende sleutel geeft de sleutel zelf terug (of de `defaultValue` die je meegeeft).

```ts
i18n.addTranslations('en', { nav: { home: 'Home' } }) // root, deep-merged
i18n.addRouteTranslations('en', 'about', { title: 'About us' }) // route chunk
i18n.addTranslations('en', { nav: { home: 'Start' } }, false) // replace instead of merge
i18n.setRoute('about')
i18n.t('title') // 'About us'
i18n.t('nav.home') // 'Start' (root key, still visible on the route)
```

### Vertalen en formatteren {#translate-and-format}

| Methode | Retourneert |
| --- | --- |
| `t(key, params?, defaultValue?, routeName?)` | De waarde (string, getal, object) met geïnterpoleerde `{param}`. |
| `ts(...)` | Hetzelfde als `t`, als string. |
| `tc(key, count \| params, defaultValue?)` | Meervoudsvorm. |
| `tn(value, options \| name)` | `Intl.NumberFormat` in de actieve locale. |
| `td(value, options \| name)` | `Intl.DateTimeFormat`. |
| `tdr(value, options?)` | Relatieve tijd (`3 days ago`). |
| `has(key, routeName?)` | `true` wanneer de actieve locale de sleutel heeft (route- of rootwoordenboek; de fallback wordt niet gecontroleerd). |

`defaultPlural` splitst de waarde op `|` en kiest de vorm op index `count`, begrensd tot de laatste; een negatieve, gebroken of `NaN`-count kiest de laatste vorm.

Een eigen `plural` ontvangt `(key, count, params, locale, getter)`. Lees de waarde via `getter(key)`; splits de sleutel niet:

```ts
import type { PluralFunc } from '@i18n-micro/vue'

const plural: PluralFunc = (key, count, params, _locale, getter) => {
  const value = getter(key)
  if (typeof value !== 'string') return null
  const forms = value.split('|').map((form) => form.trim())
  return (count === 1 ? forms[0] : forms[1] ?? forms[0])!.replace('{count}', String(count))
}
```

## Router-adapter {#router-adapter}

De SPA-pakketten zijn niet afhankelijk van een router. Een router-adapter (`I18nRoutingStrategy`) vertelt ze hoe ze het huidige pad lezen, navigeren en een gelokaliseerd pad bouwen. De ingebouwde adapters zetten een prefix voor elke locale behalve `defaultLocale` (`/about`, `/de/about`).

| Lid | Verplicht | Gebruikt door |
| --- | --- | --- |
| `getCurrentPath(): string` | ja | controle op actieve link (per pagina, query en hash tellen niet mee), `switchLocale` (behoudt ze) |
| `push({ path }): void` | ja | `switchLocale`, `<I18nLink>` zonder `linkComponent`, `<I18nSwitcher>` |
| `replace({ path }): void` | ja | — |
| `resolvePath(to, locale)` | nee | `localePath`, `localeRoute`, `<I18nLink>`; zonder deze worden paden ongewijzigd teruggegeven |
| `linkComponent` | nee | `<I18nLink>` rendert dit (bijv. `RouterLink`) in plaats van `<a>` |
| `getRoute()` | nee | `{ fullPath, query }` voor SEO-helpers |

`push` en `replace` zijn verplicht in Vue, React, Preact en Solid. Astro heeft een eigen server-side adapter met optionele `push`/`replace` (zie [Astro](/nl/integrations/astro-package#router-adapter)).

Een minimale adapter voor elke op history gebaseerde router:

```ts
import type { I18nRoutingStrategy } from '@i18n-micro/react'

const locales = ['en', 'de']
const stripLocale = (path: string) => path.replace(/^\/(en|de)(?=\/|$)/, '') || '/'

export const historyAdapter: I18nRoutingStrategy = {
  getCurrentPath: () => window.location.pathname + window.location.search + window.location.hash,
  push: ({ path }) => window.history.pushState({}, '', path),
  replace: ({ path }) => window.history.replaceState({}, '', path),
  resolvePath: (to, locale) => {
    const path = stripLocale(typeof to === 'string' ? to : to.path || '/')
    return locale === 'en' ? path : `/${locale}${path === '/' ? '' : path}`
  },
}
```

## Componenten {#components}

Vue, React, Preact en Solid leveren dezelfde vier componenten. Hun props komen overeen; React, Preact en Solid geven andere props door aan het rootelement.

### `<I18nT>` {#&lt;i18nt&gt;}

| Prop | Type | Opmerkingen |
| --- | --- | --- |
| `keypath` | `string` | verplicht |
| `params` | `object` | interpolatiewaarden |
| `plural` | `number \| string` | rendert `tc(keypath, count)` |
| `number` | `number \| string` | geeft `tn(number)` door als `{number}` |
| `date` | `Date \| string \| number` | geeft `td(date)` door als `{date}` |
| `relativeDate` | `Date \| string \| number` | geeft `tdr(relativeDate)` door als `{relativeDate}` |
| `tag` | `string` | wrapperelement, standaard `span` |
| `html` | `boolean` | render de vertaling als HTML; deze moet vertrouwd zijn, params worden ge-escaped |
| `defaultValue` | `string` | vervangt een ontbrekende sleutel, en wordt kaal gerenderd wanneer `hideIfEmpty` een lege waarde verbergt |
| `hideIfEmpty` | `boolean` | render niets voor een lege vertaling |
| `customPluralRule` | `PluralFunc` | meervoudsregel voor dit element |

Slechts één formatteringsprop is van toepassing, gecontroleerd in deze volgorde: `number`, `date`, `relativeDate`, `plural`.

#### Rich text {#rich-text}

Een `{placeholder}` kan een element bevatten. In Vue is dat een benoemd slot; in React, Preact en Solid geeft de prop `components` elementen, of functies die er een retourneren, op naam. Hoe dan ook wint dit van een param met dezelfde naam, werkt het in elke tak en blijft het werken bij een locale die de placeholders anders ordent.

```tsx
// { "terms": "I accept the {link} of {company}" }
<I18nT keypath="terms" params={{ company: 'ACME' }} components={{ link: <a href="/terms">terms</a> }} />
```

Geef in Solid een functie mee wanneer een placeholder herhaald wordt: één node kan maar op één plek staan. `children` vervangen de tekst; als functie krijgen ze `{ translation }`, zoals het standaardslot van Vue. `html` negeert dit allemaal.

### `<I18nLink>` {#&lt;i18nlink&gt;}

| Prop | Type | Opmerkingen |
| --- | --- | --- |
| `to` | `string \| { path }` | gelokaliseerd via `resolvePath` van de adapter |
| `activeStyle` | style-object | op de huidige pagina samengevoegd over `style`; React, Preact en Solid passen het ook toe op een bovenliggende sectie |
| `localeRoute` | functie | overschrijft `resolvePath` voor deze link |

Externe URL's (`https://`, `mailto:`, `tel:`) worden gerenderd als `<a target="_blank" rel="noopener noreferrer">`; een eigen `target` of `rel` wint. `onClick` wordt altijd uitgevoerd. Een klik met modifier, een andere muisknop of een `target` wordt aan de browser overgelaten.

### `<I18nSwitcher>` {#&lt;i18nswitcher&gt;}

Een dropdown met ingeschakelde locales (locales met `disabled: true` zijn verborgen) met inline standaardstijlen. De items zijn links, met `lang`, `hreflang` en `dir` uit de locale. Standaard stelt een klik op een item de locale in en roept het `push` van de adapter aan met het gelokaliseerde huidige pad; een prop `switchLocale` vervangt die actie. Met een `localeRoute` en zonder router volgt de browser de link. Escape of een klik erbuiten sluit hem.

| Prop | Opmerkingen |
| --- | --- |
| `locales`, `currentLocale`, `getLocaleName` | overschrijven de aangeleverde waarden |
| `switchLocale(code)` | vervangt de ingebouwde wissel |
| `localeRoute` | vervangt `resolvePath` |
| `customLabels` | `{ de: 'DE' }` |
| `customWrapperStyle`, `customButtonStyle`, `customDropdownStyle`, `customItemStyle`, `customLinkStyle`, `customActiveLinkStyle`, `customDisabledLinkStyle`, `customIconStyle` | stijloverschrijvingen |

### `<I18nGroup>` {#&lt;i18ngroup&gt;}

Een `<div class="i18n-group">` die een `t` met prefix aan zijn kinderen doorgeeft. Het zet **geen** prefix voor `<I18nT>`- of `t()`-aanroepen erbinnen; alleen de `t` die het doorgeeft heeft een prefix.

| Prop | Opmerkingen |
| --- | --- |
| `prefix` | verplicht, bijv. `'profile'` |
| `groupClass` | extra class op de wrapper |

De `t` met prefix komt via een scoped slot in Vue (`v-slot="{ t }"`) en een render-prop-kind in React, Preact en Solid (`{({ t }) => …}`).

## Getypeerde sleutels {#typed-keys}

`t()` accepteert elke string. Om autocomplete voor je sleutels te krijgen, genereer je een declaratie met de [types generator](/nl/integrations/types-generator). Sleutels worden voorgesteld, niet afgedwongen, en params zijn niet getypeerd.

## Vergeleken met de Nuxt-module {#compared-with-the-nuxt-module}

De pakketten hebben geen bestandsgebaseerde routing, geen server-middleware en geen vertaalloader: jij bepaalt wanneer JSON wordt geladen (`import`, `fetch`, of `@i18n-micro/node` op de server) en welke router-adapter je gebruikt. Locale-detectie, SEO-meta en routegeneratie zijn Nuxt-functies; Astro heeft eigen middleware voor detectie en `useLocaleHead` voor SEO.
