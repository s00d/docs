# Integraties

De `@i18n-micro`-pakketten zijn lichtgewicht, framework-specifieke versies van Nuxt I18n Micro, ontworpen voor integratie in verschillende frameworks en omgevingen. Deze pakketten bieden kern-internationalisatiefunctionaliteit met minimale footprint, met focus op essentiële vertaalfuncties en basiscomponenten.

## Overzicht

Deze integratiepakketten zijn **miniatuurversies** van de volledige Nuxt I18n Micro-module en bevatten alleen de essentiële functionaliteit die nodig is voor internationalisatie:

- **Kernvertaalfuncties** - Basis vertaalmethodes, pluralisatie en opmaak
- **Essentiële componenten** - Een kleine set UI-componenten voor veelvoorkomende i18n-taken
- **Router-adapterpatroon** - Flexibele routing-integratie via adapterabstractie
- **TypeScript-ondersteuning** - Volledige typedefinities voor type-safe ontwikkeling

In tegenstelling tot de volledige Nuxt-module bevatten deze pakketten:

- Geen framework-specifieke routinglogica
- Vereisen dat je een router-adapter implementeert voor routingfuncties
- Focussen op vertaalfunctionaliteit in plaats van framework-integratie
- Ontworpen om lichtgewicht en waar mogelijk framework-onafhankelijk te zijn

## Kerncomponenten

Alle framework-pakketten bevatten de volgende essentiële componenten:

### `<I18nT>`

Een vertaalcomponent dat vertaalde tekst rendert, met ondersteuning voor:

- **Parameterinterpolatie** - Vervang placeholders door dynamische waarden
- **Pluralisatie** - Automatische meervoudsvormselectie op basis van telling
- **Getalopmaak** - Formatteer getallen volgens locale
- **Datumopmaak** - Formatteer datums en relatieve tijden
- **HTML-rendering** - Optionele HTML-inhoudsrendering
- **Standaardwaarden** - Fallback-tekst wanneer vertaling ontbreekt

**Voorbeeld:**

```vue
<!-- Vue -->
<I18nT keypath="greeting" :params="{ name: 'World' }" />
```

```tsx
// React
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```tsx
// Solid
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```astro
<!-- Astro -->
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

### `<I18nLink>`

Een gelokaliseerd link-component dat automatisch localeprefixes in URL's afhandelt. Functies:

- **Automatische padlokalisatie** - Voegt localeprefixes toe of verwijdert ze op basis van routingstrategie
- **Detectie van actieve staat** - Highlight de huidige route
- **Ondersteuning voor externe links** - Detecteert en behandelt externe URL's automatisch
- **Router-integratie** - Gebruikt de link-component van de router-adapter indien beschikbaar
- **Aangepaste styling** - Ondersteunt actieve en hover-staten

**Voorbeeld:**

```vue
<!-- Vue -->
<I18nLink to="/about" active-class="active">
  About Us
</I18nLink>
```

```tsx
// React
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```tsx
// Solid
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```astro
<!-- Astro -->
<I18nLink href="/about" class="nav-link">
  About Us
</I18nLink>
```

### `<I18nSwitcher>`

Een taalwisselaar-component dat een dropdown- of lijstinterface biedt voor het wijzigen van locales. Functies:

- **Automatische localelijst** - Genereert opties uit geconfigureerde locales
- **Highlighting van huidige locale** - Visueel indiceren van de actieve taal
- **Aangepaste labels** - Ondersteuning voor aangepaste weergavenamen per locale
- **Router-integratie** - Navigeert automatisch naar gelokaliseerde paden
- **Toegankelijkheid** - Correcte ARIA-attributen en toetsenbordnavigatie

**Voorbeeld:**

```vue
<!-- Vue -->
<I18nSwitcher />
```

```tsx
// React
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```tsx
// Solid
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```astro
<!-- Astro -->
<I18nSwitcher />
```

### `<I18nGroup>`

Een component om vertalingen te groeperen met een gemeenschappelijke prefix, handig om vertalingen per pagina of feature te organiseren. Functies:

- **Prefix-scoping** - Voegt automatisch een prefix toe aan alle vertaalsleutels binnen de groep
- **Geneste groepen** - Ondersteuning voor geneste vertaalgroepen
- **Schone organisatie** - Helpt om georganiseerde vertaalstructuren te behouden

**Voorbeeld:**

```vue
<!-- Vue -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

```tsx
// React
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```tsx
// Solid
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```astro
<!-- Astro -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

## Gedeelde `createI18n`-opties \{#create-i18n-options\}

Elk framework-pakket wordt op dezelfde manier gecreëerd — alleen het optietype is genoemd naar
het framework (`ReactI18nOptions`, `SolidI18nOptions`, enzovoort). De opties zelf
zijn identiek:

| Eigenschap         | Type                                                       | Vereist | Standaard          | Beschrijving                                    |
| ---------------- | ---------------------------------------------------------- | -------- | ---------------- | ---------------------------------------------- |
| `locale`         | `string`                                                   | ✅       | -                | Huidige localecode (bijv. `'en'`)             |
| `fallbackLocale` | `string`                                                   | ❌       | Zelfde als `locale` | Fallback-locale wanneer vertaling ontbreekt    |
| `messages`       | `Record<string, Translations>`                             | ❌       | `\{\}`             | Initiële vertaalberichten                   |
| `plural`         | `PluralFunc`                                               | ❌       | `defaultPlural`  | Aangepaste pluralisatiefunctie                  |
| `missingWarn`    | `boolean`                                                  | ❌       | `true`           | Toon consolewaarschuwingen voor ontbrekende vertalingen |
| `missingHandler` | `(locale: string, key: string, routeName: string) => void` | ❌       | -                | Aangepaste handler voor ontbrekende vertalingen        |

Alles buiten deze opties is framework-specifiek en gedocumenteerd op de pagina van dat pakket.

## Router-adapterabstractie

Alle framework-pakketten gebruiken een **router-adapterpatroon** om i18n-functionaliteit los te koppelen van specifieke router-implementaties. Dit ontwerp maakt mogelijk:

- **Flexibiliteit** - Gebruik elke router-bibliotheek of helemaal geen router
- **Framework-onafhankelijkheid** - Houd routinglogica in je applicatie, niet in het i18n-pakket
- **Lichtgewicht kern** - Het i18n-pakket blijft klein en gefocust

### Een router-adapter implementeren

Om routingfuncties te gebruiken, moet je de `I18nRoutingStrategy`-interface implementeren:

```typescript
interface I18nRoutingStrategy {
  getCurrentPath: () => string
  linkComponent?: Component
  push: (target: { path: string }) => void
  replace: (target: { path: string }) => void
  resolvePath?: (to: string | { path?: string }, locale: string) => string | { path?: string }
  getRoute?: () => { fullPath: string; query: Record<string, unknown> }
}
```

Elke pakketdocumentatie bevat volledige voorbeelden van adapterimplementaties voor populaire routers:

- **Vue**: Vue Router-adaptervoorbeeld
- **React**: React Router-adaptervoorbeeld
- **Solid**: Solid Router-adaptervoorbeeld
- **Astro**: Voorbeeld van bestandsgebaseerde routing-adapter

## Kernfuncties

Alle pakketten delen deze kernfuncties:

### Vertaalmethodes

- `t()` - Basisvertaling met parameterinterpolatie
- `ts()` - Vertaling die altijd een string retourneert
- `tc()` - Pluralisatie-bewuste vertaling
- `tn()` - Getalopmaak
- `td()` - Datumopmaak
- `tdr()` - Relatieve tijdopmaak
- `has()` - Controleren of een vertaalsleutel bestaat

### Localebeheer

- **Localewisseling** - Wissel programmatisch van huidige locale
- **Fallback-locale** - Automatische fallback wanneer vertaling ontbreekt
- **Route-specifieke vertalingen** - Vertaalorganisatie op paginaniveau
- **Vertaalcaching** - Intelligente caching voor prestaties

### TypeScript-ondersteuning

Alle pakketten bieden:

- Volledige TypeScript-definities
- Type-safe vertaalsleutels (met types-generator)
- IntelliSense-ondersteuning in IDE's
- Compile-time foutcontrole
