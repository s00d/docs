# Pakket-API's

`nuxt-i18n-micro` is opgebouwd uit een set kleine pakketten, waarvan de meeste zelfstandig
bruikbaar zijn — `@i18n-micro/vue` in een gewone Vue-app, `@i18n-micro/core` overal.

Elke pagina hieronder wordt gegenereerd uit de API-snapshot die
[`pnpm run api:surface`](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/maintenance-commands.md#api-surface) vergelijkt met de
TypeScript-bronnen, zodat een export niet kan verdwijnen zonder dat óf deze referentie verandert
óf CI faalt.
