# 🌍 `useLocaleHead`-composable

De `useLocaleHead`-composable is een utility in `Nuxt I18n Micro` waarmee je SEO-attributen en HTML-metatags voor gelokaliseerde routes beheert. Deze composable genereert dynamisch attributen voor `lang` en `dir` van het HTML-document en maakt `meta`- en `link`-tags om de SEO van je gelokaliseerde inhoud te verbeteren.

## ⚙️ Opties

```ts
useLocaleHead(options: UseLocaleHeadOptions): { metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }, MetaObject | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

De SEO-head-tags voor de huidige route: `hreflang`-alternates voor elke locale plus `x-default`, een canonical link, `og:locale` en `lang`/`dir` op `<html>`.

Alleen nodig wanneer `meta` is uitgeschakeld of de standaardwaarden aangepast moeten worden. Met `meta: true` registreert de module dezelfde tags zelf.

## 🛠️ Retourwaarden

De `useLocaleHead`-composable retourneert een reactief object en een updater-functie die je moet aanroepen wanneer brondata verandert. Beide vormen staan in de signature hierboven, gegenereerd uit de broncode.

### `metaObject`

Reactieve head-payload (html-attrs, meta, link) geschikt voor `useHead(metaObject)`.

- **Voorbeeld**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

Herberekent `metaObject` op basis van de huidige route, locale en configuratie. Roep het aan wanneer de invoer verandert, bijvoorbeeld bij een route-wijziging.

- **Voorbeeld**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### Toegang tot `link` en `meta`

De arrays `link` en `meta` zijn beschikbaar via `metaObject.value`:

- **Voorbeeld**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Uitvoer: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Uitvoer: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ Voorbeeldgebruik

### Basisgebruik

Genereer locale-specifieke head-attributen met standaardopties.

```js
const head = useLocaleHead()
```

### Aangepast identifier-attribuut

Gebruik een aangepast identifier-attribuut voor de gegenereerde tags.

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### SEO-attributen uitschakelen

Genereer head-attributen zonder SEO-gerelateerde meta- en link-tags toe te voegen.

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### Een basis-URL opgeven

Stel een aangepaste basis-URL in voor canonical- en alternate-URL's.

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 Aanvullende functies

### SEO-meta- en linktags

Wanneer `addSeoAttributes` is ingeschakeld, genereert de composable automatisch de volgende tags:

- `og:locale` voor de huidige locale (`language_TERRITORY`, underscore). Afgeleid van `locale.og` of geconverteerd van `locale.iso` wanneer mogelijk.
- `og:url` voor de canonieke URL van de pagina.
- `og:locale:alternate` voor alternatieve taalversies.
- `rel="canonical"`- en `rel="alternate"`-links voor SEO-optimalisatie.
- `hreflang="x-default"`-link die verwijst naar de URL van de standaardlocale. Dit vertelt zoekmachines welke URL getoond moet worden aan gebruikers wier taal niet overeenkomt met een van de gedefinieerde locales.

### Dynamische locale en richting

De composable bepaalt de `lang`- en `dir`-attributen dynamisch op basis van de locale van de huidige route, zodat je HTML-document correct is geconfigureerd voor internationale gebruikers.

### Gelokaliseerde routes verwerken

Als je routes voorafgegaan zijn door locale-codes (bijvoorbeeld `/en/about`), past de composable het volledige pad slim aan bij het genereren van URL's, zodat SEO-attributen accuraat en relevant zijn.

Deze composable vereenvoudigt het optimaliseren van je Nuxt-applicatie voor een internationaal publiek en zorgt dat je site goed voorbereid is voor wereldwijde zoekmachines en gebruikers.

## 🛠️ Voorbeeldgebruik

Het volgende voorbeeld laat zien hoe je de `useLocaleHead`-composable in een Vue-component gebruikt met standaardinstellingen:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### Uitleg van de code

- **`useLocaleHead`-composable**: Deze composable wordt aangeroepen in de sectie `<script setup>` en retourneert een object met `htmlAttrs`, `meta` en `link`.

- **`<html>`-tag**: De `lang`- en `dir`-attributen voor het HTML-document worden dynamisch bepaald op basis van de huidige locale en worden op de `<html>`-tag toegepast.

- **`<head>`-sectie**:
  - **Metatags**: SEO-gerelateerde metatags worden gegenereerd, waaronder `og:locale`, `og:url` en `rel="canonical"`- en `rel="alternate"`-tags om alternatieve taalversies van de pagina op te geven.
  - **Linktags**: Canonieke links, links naar alternatieve taalversies en de `hreflang="x-default"`-link (die verwijst naar de URL van de standaardlocale) worden meegenomen.

- **`<body>`-sectie**: De hoofdinhoud van de pagina wordt hier weergegeven. In dit voorbeeld worden een eenvoudige header en alinea gebruikt.

### 📝 Opmerkingen

1. **Attributen**: De gebruikte attributen (`lang`, `dir`, `rel`, `href`, `hreflang`, `property`, `content`) worden geëxtraheerd uit het object dat `useLocaleHead` retourneert.

2. **Genereren van SEO-tags**: Als de optie `addSeoAttributes` op `true` staat, genereert de composable automatisch SEO-tags voor de huidige locale.

3. **Basis-URL**: Je kunt je aangepaste basis-URL instellen via de optie `baseUrl` om canonieke en alternatieve links correct te genereren.

Dit voorbeeld toont hoe eenvoudig het is om `useLocaleHead` te integreren in de componenten van je applicatie voor correcte SEO-attributen en betere indexering van gelokaliseerde pagina's door zoekmachines.

## 🧩 Aanpassing en levenscyclus

- `useLocaleHead` abonneert zich niet zelf op wijzigingen. De composable retourneert `metaObject` en `updateMeta`.
- Roep `updateMeta()` aan wanneer de invoer verandert (meestal bij een route-wijziging), bijvoorbeeld vanuit een plugin:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## Wanneer je in plaats daarvan `useI18nHead` moet gebruiken

Wanneer `meta: true` (de standaard), geef je de voorkeur aan [`useI18nHead`](/api/composables/use-i18n-head) voor **per-pagina** overrides (aangepaste hreflang, extra `og:title`, gedeeltelijk uitschakelen). Gebruik `useLocaleHead` alleen direct wanneer `meta: false` of wanneer je `useHead` zelf beheert.
