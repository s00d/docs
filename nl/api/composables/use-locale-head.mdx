# 🌍 `useLocaleHead`-composable

De `useLocaleHead`-composable is een hulpprogramma in `Nuxt I18n Micro` dat je helpt SEO-attributen en HTML-metatags voor gelokaliseerde routes te beheren. Het genereert dynamisch attributen voor de `lang` en `dir` van het HTML-document en creëert `meta`- en `link`-tags om de SEO van je gelokaliseerde content te verbeteren.

De SEO-head-tags voor de huidige route: `hreflang`-alternates voor elke locale plus
`x-default`, een canonieke link, `og:locale`, en `lang`/`dir` op `<html>`.

Alleen nodig wanneer `meta` is uitgeschakeld of de standaardwaarden aanpassing nodig hebben — met `meta: true`
registreert de module dezelfde tags zelf.

## 🛠️ Retourwaarden

De `useLocaleHead`-composable retourneert een reactief object en een updater-functie die je moet
aanroepen wanneer bronwaarden veranderen. Beide vormen staan in de bovenstaande signature, gegenereerd uit
de bron.

### `metaObject`

Reactieve head-payload (html-attrs, meta, link) geschikt voor `useHead(metaObject)`.

- **Voorbeeld**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

Herberekent `metaObject` op basis van huidige route, locale en config. Roep het aan wanneer inputs
veranderen — bijvoorbeeld bij een routewijziging.

- **Voorbeeld**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### Toegang tot `link` en `meta`

De `link`- en `meta`-arrays zijn toegankelijk via `metaObject.value`:

- **Voorbeeld**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ Voorbeeldgebruik

### Basisgebruik

Genereer locale-specifieke head-attributen met standaardopties.

```js
const head = useLocaleHead()
```

### Identifier-attribuut aanpassen

Gebruik een aangepast identifier-attribuut voor de gegenereerde tags.

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### SEO-attributen uitschakelen

Genereer head-attributen zonder SEO-gerelateerde meta- en linktags toe te voegen.

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### Een base-URL opgeven

Stel een aangepaste base-URL in voor canonieke en alternate-URL's.

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 Aanvullende features

### SEO-meta- en linktags

Wanneer `addSeoAttributes` is ingeschakeld, genereert de composable automatisch de volgende tags:

- `og:locale` voor de huidige locale (`language_TERRITORY`, underscore). Afgeleid uit `locale.og` of geconverteerd uit `locale.iso` indien mogelijk.
- `og:url` voor de canonieke URL van de pagina.
- `og:locale:alternate` voor alternatieve taalversies.
- `rel="canonical"`- en `rel="alternate"`-links voor SEO-optimalisatie.
- `hreflang="x-default"`-link die naar de URL van de standaardlocale wijst. Dit vertelt zoekmachines welke URL ze moeten tonen aan gebruikers wiens taal niet overeenkomt met een van de gedefinieerde locales.

### Dynamische locale en richting

De composable bepaalt dynamisch de `lang`- en `dir`-attributen op basis van de locale van de huidige route, zodat je HTML-document correct is geconfigureerd voor internationale gebruikers.

### Omgang met gelokaliseerde routes

Als je routes zijn geprefixt met localecodes (bijv. `/en/about`), past de composable het volledige pad intelligent aan voor het genereren van URL's, zodat SEO-attributen accuraat en relevant zijn.

Deze composable vereenvoudigt het proces van het optimaliseren van je Nuxt-applicatie voor internationaal publiek en zorgt ervoor dat je site goed is voorbereid op wereldwijde zoekmachines en gebruikers.

## 🛠️ Voorbeeldgebruik

Het volgende voorbeeld laat zien hoe je de `useLocaleHead`-composable gebruikt in een Vue-component met standaardinstellingen:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### Uitleg van de code

- **`useLocaleHead`-composable**: Deze composable wordt aangeroepen in de `<script setup>`-sectie en retourneert een object met `htmlAttrs`, `meta` en `link`.

- **`<html>`-tag**: De `lang`- en `dir`-attributen voor het HTML-document worden dynamisch bepaald op basis van de huidige locale en worden toegepast op de `<html>`-tag.

- **`<head>`-sectie**:
  - **Metatags**: SEO-gerelateerde metatags worden gegenereerd, waaronder `og:locale`, `og:url` en `rel="canonical"`- en `rel="alternate"`-tags om alternatieve taalversies van de pagina te specificeren.
  - **Linktags**: Canonieke links, links naar alternatieve taalversies en de `hreflang="x-default"`-link (die naar de URL van de standaardlocale wijst) zijn opgenomen.

- **`<body>`-sectie**: De hoofdinhoud van de pagina wordt hier weergegeven. In dit voorbeeld worden een eenvoudige header en paragraaf gebruikt.

### 📝 Opmerkingen

1. **Attributen**: De gebruikte attributen (`lang`, `dir`, `rel`, `href`, `hreflang`, `property`, `content`) worden uit het object gehaald dat door `useLocaleHead` wordt geretourneerd.

2. **SEO-tag-generatie**: Als de optie `addSeoAttributes` is ingesteld op `true`, genereert de composable automatisch SEO-tags voor de huidige locale.

3. **Base-URL**: Je kunt je aangepaste base-URL instellen met de optie `baseUrl` om canonieke en alternate-links correct te genereren.

Dit voorbeeld laat zien hoe eenvoudig het is om `useLocaleHead` in de componenten van je applicatie te integreren om correcte SEO-attributen en verbeterde indexering van gelokaliseerde pagina's door zoekmachines te garanderen.

## 🧩 Aanpassing & levenscyclus

- `useLocaleHead` abonneert zich niet zelf op wijzigingen. Het retourneert `metaObject` en `updateMeta`.
- Roep `updateMeta()` aan wanneer inputs veranderen (meestal bij een routewijziging), bijvoorbeeld vanuit een plugin:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## Wanneer `useI18nHead` gebruiken

Bij `meta: true` (de standaard) geef je de voorkeur aan [`useI18nHead`](/api/composables/use-i18n-head) voor **per-pagina** overrides (aangepaste hreflang, extra `og:title`, gedeeltelijke uitschakeling). Gebruik `useLocaleHead` alleen direct wanneer `meta: false` of je `useHead` zelf beheert.
