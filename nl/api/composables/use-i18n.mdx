# 🛠️ `useI18n`-composable

De `useI18n`-composable in `Nuxt I18n Micro` biedt toegang tot de meeste runtime-i18n-helpers in componenten en scripts. Methodes zijn beschikbaar **met en zonder de `$`-prefix** (bijvoorbeeld `$t` en `t`).

Sommige injecties — `$defineI18nRoute` en `$clearCache` — zijn alleen beschikbaar op `useNuxtApp()`. Zie [Methodes — `$defineI18nRoute`](/api/methods#definei18nroute) en [`$clearCache`](/api/methods#clearcache).

## 📊 Wat het retourneert

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Elke runtime-helper, als een gewoon object.

Dezelfde functies die de plugin injecteert als `$t`, `$tc` enzovoort, beschikbaar onder zowel
de dollar-geprefixte naam als een kale alias — dus `const \{ t \} = useI18n()` en
`const \{ $t \} = useI18n()` werken beide.

**Retourneert** — de helpers beschreven in de [methodenreferentie](/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

Elke helper die het retourneert — `$t`, `$tc`, `$has`, `$switchLocale` en de rest — wordt opgesomd
met signature en volledig gedocumenteerd in de [Methodenreferentie](/api/methods).

## Alleen op `useNuxtApp()` beschikbare API's

Deze worden **niet** geretourneerd door `useI18n()`. Importeer ze uit `useNuxtApp()`:

| Methode                     | Doel                                                                         |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Localeroutes per pagina, beperkingen en inline-vertalingen in `script setup` |
| `$clearCache()`            | Wist de in-memory vertaalcache en geladen chunks                            |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Zie [Methodes](/api/methods) voor volledige signatures en voorbeelden.

## 🛠️ Voorbeeldgebruik

### Basis locale-ophaling

Haal de huidige locale van de applicatie op.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Vertaling met parameters

Vertaal een string met dynamische parameters, met een fallback-standaardwaarde.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Locales wisselen

Wissel de applicatie naar een andere locale.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Een gelokaliseerde route genereren

Genereer een route gelokaliseerd naar de huidige of opgegeven locale.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
