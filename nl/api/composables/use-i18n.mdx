# 🛠️ `useI18n`-composable

De `useI18n`-composable in `Nuxt I18n Micro` biedt toegang tot de meeste runtime-i18n-helpers in componenten en scripts. De methoden zijn beschikbaar **met en zonder het `$`-prefix** (bijvoorbeeld `$t` en `t`).

Sommige injecties — `$defineI18nRoute` en `$clearCache` — zijn uitsluitend beschikbaar op `useNuxtApp()`. Zie [Methoden — `$defineI18nRoute`](/api/methods#definei18nroute) en [`$clearCache`](/api/methods#clearcache).

## 📊 Wat het retourneert

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Elke runtime-helper, als eenvoudig object.

Dezelfde functies die de plugin injecteert als `$t`, `$tc` enzovoort, beschikbaar onder zowel de naam met dollar-prefix als een kale alias. Zowel `const \{ t \} = useI18n()` als `const \{ $t \} = useI18n()` werken dus.

**Retourneert** — de helpers die worden beschreven in de [methodenreferentie](/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

Elke helper die wordt geretourneerd — `$t`, `$tc`, `$has`, `$switchLocale` en de rest — staat met signature vermeld en wordt volledig gedocumenteerd in de [methodenreferentie](/api/methods).

## API's die alleen op `useNuxtApp()` staan

Deze worden **niet** door `useI18n()` geretourneerd. Importeer ze via `useNuxtApp()`:

| Methode                    | Doel                                                                            |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Locale-routes per pagina, beperkingen en inline vertalingen in `script setup`   |
| `$clearCache()`            | Wist de in-memory vertaalcache en de geladen chunks                             |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Zie [Methoden](/api/methods) voor volledige signatures en voorbeelden.

## 🛠️ Voorbeeldgebruik

### Basis: de locale ophalen

Haal de huidige locale van de applicatie op.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Vertalen met parameters

Vertaal een tekenreeks met dynamische parameters en een fallback-standaardwaarde.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welkom!')
```

### Wisselen van locale

Zet de applicatie over naar een andere locale.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Een gelokaliseerde route genereren

Genereer een route die gelokaliseerd is naar de huidige of opgegeven locale.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
