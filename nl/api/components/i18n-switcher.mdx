# 🌍 `<i18n-switcher>`-component

De `<i18n-switcher>`-component in `Nuxt I18n Micro` biedt een gebruiksvriendelijke dropdown-interface om tussen verschillende locales in je applicatie te wisselen. Deze component is zeer aanpasbaar en integreert naadloos met het ontwerp en de lay-out van je applicatie.

Locales met `disabled: true` worden **weggelaten** uit de dropdown (ze blijven beschikbaar via `$getLocales()` voor SEO- en head-tags). Alleen wisselbare locales krijgen `NuxtLink` en `hreflang`.

Elk onderdeel is standaard zonder styling: de `custom*Style`-props accepteren inline-stijlobjecten en de onderstaande slots vervangen de opmaak volledig wanneer styling alleen niet volstaat.

## 🛠️ Voorbeeldgebruik

### Basisgebruik

```vue
<template>
  <i18n-switcher />
</template>
```

Dit rendert een localeswitcher met standaardstyling en -gedrag.

### Aangepaste labels en inline-stijlen

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Dit voorbeeld toont een volledig aangepaste localeswitcher met aangepaste labels en inline-stijlen.

## 🔌 Slots

Elk visueel onderdeel van de switcher kan worden vervangen. De slots staan opgesomd bij de props-tabel hierboven; elke slot accepteert template-inhoud:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Mist er een taal?</a>
  </template>
</i18n-switcher>
```

Slots waarvan de naam eindigt op `-item`, `-link-content` of begint met `before-item` ontvangen het bijbehorende `locale`-object.

## 🎨 Overzicht van stijlen

De `<i18n-switcher>`-component heeft basisstijlen die zijn gedefinieerd met inline-stijlen. Deze kunnen eenvoudig worden overschreven door aangepaste stijlen via props door te geven. Hier is een kort overzicht van de standaardstyling:

- **Wrapper**: Regelt de positionering van de dropdown.
- **Knop**: Stijlt de knop die de dropdown wisselt.
- **Dropdown**: Stijlt de dropdown-lijst.
- **Items**: Stijlt elk item in de lijst.
- **Links**: Stijlt de links binnen elk item.
- **Pictogram**: Stijlt het pictogram dat de dropdown aangeeft.

Je kunt deze stijlen aanpassen door aangepaste stijlen door te geven via de bijbehorende props, zodat de localeswitcher naadloos integreert in de UI van je applicatie.
