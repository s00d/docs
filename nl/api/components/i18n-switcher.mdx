# 🌍 `<i18n-switcher>`-component

Het `<i18n-switcher>`-component in `Nuxt I18n Micro` biedt een gebruiksvriendelijke dropdown-interface om tussen verschillende locales in je applicatie te schakelen. Dit component is zeer aanpasbaar, waardoor het naadloos integreert met het ontwerp en de layout van je applicatie.

Locales met `disabled: true` worden **weggelaten** uit de dropdown (ze blijven beschikbaar via `$getLocales()` voor SEO- / head-tags). Alleen wisselbare locales krijgen `NuxtLink` + `hreflang`.

Elk onderdeel is standaard ongestyled: de `custom*Style`-props nemen inline-stijlobjecten aan, en
de onderstaande slots vervangen de markup volledig wanneer styling niet volstaat.

## 🛠️ Voorbeeldgebruik

### Basisgebruik

```vue
<template>
  <i18n-switcher />
</template>
```

Dit rendert een localewisselaar met standaardstyling en -gedrag.

### Aangepaste labels en inline-stijlen

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Dit voorbeeld demonstreert een volledig aangepaste localewisselaar met aangepaste labels en inline-stijlen.

## 🔌 Slots

Elk visueel onderdeel van de switcher kan worden vervangen. De slots staan in de props-tabel hierboven; elke slot neemt template-inhoud:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Slots waarvan de naam eindigt op `-item`, `-link-content` of begint met `before-item` ontvangen het
`locale`-object waartoe ze behoren.

## 🎨 Stijlenoverzicht

Het `<i18n-switcher>`-component wordt geleverd met basisstijlen gedefinieerd via inline-stijlen die eenvoudig kunnen worden overschreven door aangepaste stijlen via props door te geven. Hier is een kort overzicht van de standaardstyling:

- **Wrapper**: Bepaalt de positionering van de dropdown.
- **Button**: Style de dropdown-toggle-knop.
- **Dropdown**: Style de dropdown-lijst.
- **Items**: Style elk item in de lijst.
- **Links**: Style de links binnen elk item.
- **Icon**: Style het dropdown-indicator-icoon.

Je kunt deze stijlen aanpassen door aangepaste stijlen door te geven via de respectievelijke props, zodat de localewisselaar naadloos in de UI van je applicatie integreert.
