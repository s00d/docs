# 🌍 `<i18n-link>`-component

Het `<i18n-link>`-component in `Nuxt I18n Micro` is een veelzijdig link-component dat routes automatisch lokaliseert op basis van de huidige locale. Het fungeert als een wrapper rond het `<NuxtLink>`-component en biedt aanvullende functies zoals actieve-link-styling en ondersteuning voor externe links.

### Slots

| Slot | Bindings | Beschrijving |
| --- | --- | --- |
| `default` | — | Link-inhoud. |

{/* /generated:component:i18n-link */}

`to` accepteert alles wat `NuxtLink` accepteert — een pad, een benoemde route of een opgeloste route-object.
Een absolute URL wordt gedetecteerd en gerenderd als een gewone `<a target="_blank" rel="noopener noreferrer">`
in plaats van gelokaliseerd te worden.

## 🛠️ Voorbeeldgebruik

### Basisgebruik

```vue
<i18n-link to="/about">About Us</i18n-link>
```

Dit voorbeeld maakt een link naar de `/about`-pagina, gelokaliseerd naar de huidige locale.

### Actieve-link-styling met inline-stijlen

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

De link heeft vette tekst wanneer de gebruiker op de `/about`-pagina is, zodat je de actieve link direct kunt stylen met inline-stijlen.

### Afhandeling van externe links

Het component detecteert automatisch externe links en voegt de nodige attributen toe voor beveiliging.

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

Deze link opent `https://example.com` in een nieuw tabblad met `rel="noopener noreferrer"` toegepast.

## 🎨 Stijlen

Het component gebruikt nu inline-stijlen voor de actieve staat in plaats van een class. Je kunt deze stijlen aanpassen via de prop `activeStyle`.

### Standaard actieve stijlen

- **Font Weight**: `bold`
- **Color**: Erft de standaardkleur van de browser (als er geen `color` is opgegeven in `activeStyle`).

Je kunt deze overschrijven door aangepaste stijlen door te geven via de prop `activeStyle`.

### Aangepaste actieve stijlen

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

In dit voorbeeld is de link vet en groen wanneer actief.

## 🚀 Aanvullende features

### Slot voor aangepaste inhoud

Je kunt aangepaste inhoud in de link doorgeven via slots, waardoor het component flexibel is voor verschillende use-cases.

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### Toegankelijkheidsverbeteringen

Het component ondersteunt `aria-label` en andere toegankelijkheidsattributen voor een toegankelijkere ervaring.

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
