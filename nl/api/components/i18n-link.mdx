# 🌍 `<i18n-link>`-component

De `<i18n-link>`-component in `Nuxt I18n Micro` is een veelzijdige linkcomponent die routes automatisch lokaliseert op basis van de huidige locale. De component fungeert als wrapper rond de `<NuxtLink>`-component en biedt aanvullende functies zoals actieve-linkstyling en ondersteuning voor externe links.

`to` accepteert alles wat `NuxtLink` ook accepteert: een pad, een genoemde route of een opgelost route-object.
Een absolute URL wordt gedetecteerd en gerenderd als een gewone `<a target="_blank" rel="noopener noreferrer">`
in plaats van gelokaliseerd te worden.

## 🛠️ Voorbeeldgebruik

### Basisgebruik

```vue
<i18n-link to="/about">Over ons</i18n-link>
```

Dit voorbeeld maakt een link naar de pagina `/about`, gelokaliseerd naar de huidige locale.

### Actieve-linkstyling met inline-stijlen

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">Over ons</i18n-link>
```

De link zal vetgedrukt zijn wanneer de gebruiker zich op de pagina `/about` bevindt. Zo kun je de actieve link direct met inline-stijlen opmaken.

### Omgaan met externe links

De component detecteert externe links automatisch en voegt de vereiste attributen voor beveiliging toe.

```vue
<i18n-link to="https://example.com">Bezoek Example</i18n-link>
```

Deze link opent `https://example.com` in een nieuw tabblad met `rel="noopener noreferrer"` toegepast.

## 🎨 Stijlen

De component gebruikt nu inline-stijlen voor de actieve status in plaats van een class. Je kunt deze stijlen aanpassen via de prop `activeStyle`.

### Standaard actieve stijlen

- **Font Weight**: `bold`
- **Kleur**: Erft de standaardkleur van de browser (als er geen `color` is opgegeven in `activeStyle`).

Je kunt deze overschrijven door aangepaste stijlen op te geven via de prop `activeStyle`.

### Aangepaste actieve stijlen

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">Over ons</i18n-link>
```

In dit voorbeeld is de link vet en groen wanneer deze actief is.

## 🚀 Aanvullende functies

### Slot voor aangepaste inhoud

Je kunt aangepaste inhoud in de link plaatsen via slots, waardoor de component flexibel is voor verschillende toepassingen.

```vue
<i18n-link to="/about">
  <span>Over ons</span>
</i18n-link>
```

### Toegankelijkheidsverbeteringen

De component ondersteunt `aria-label` en andere toegankelijkheidsattributen om een betere toegankelijke ervaring te garanderen.

```vue
<i18n-link to="/about" aria-label="Leer meer over ons">
  Over ons
</i18n-link>
```
