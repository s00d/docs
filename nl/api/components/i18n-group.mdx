# 🌍 `<i18n-group>`-component

De `<i18n-group>`-component in Nuxt I18n Micro biedt een handige manier om vertalingen onder een gemeenschappelijk voorvoegsel te groeperen. Zo verminder je herhaling en verbeter je de organisatie van je code.

## 🎯 Slots

De default-slot ontvangt `prefix` en een `t`-functie die daarop is gescoped, zodat sleutels binnenin relatief ten opzichte van het voorvoegsel worden geschreven:

```vue
<i18n-group prefix="checkout">
  <template #default="{ t }">
    <h2>{{ t('title') }}</h2>
    <p>{{ t('summary', { count: 3 }) }}</p>
  </template>
</i18n-group>
```

## 🛠️ Voorbeeldgebruik

### Basisgebruik

```vue
<template>
  <i18n-group prefix="product.details">
    <template #default="{ t }">
      <h1>{{ t('title') }}</h1>
      <p>{{ t('description') }}</p>
      <div class="price">{{ t('price', { value: 99.99 }) }}</div>
    </template>
  </i18n-group>
</template>
```

Vertaalbestand:

```json
{
  "product": {
    "details": {
      "title": "Premium Product",
      "description": "This is a premium product",
      "price": "Price: ${value}"
    }
  }
}
```

### Met aangepaste class

```vue
<template>
  <i18n-group prefix="user.profile" group-class="profile-section">
    <template #default="{ t }">
      <div class="user-info">
        <h2>{{ t('title') }}</h2>
        <p>{{ t('bio') }}</p>
        <div class="stats">
          <span>{{ t('stats.followers') }}</span>
          <span>{{ t('stats.following') }}</span>
        </div>
      </div>
    </template>
  </i18n-group>
</template>
```

Vertaalbestand:

```json
{
  "user": {
    "profile": {
      "title": "User Profile",
      "bio": "User biography goes here",
      "stats": {
        "followers": "Followers: {count}",
        "following": "Following: {count}"
      }
    }
  }
}
```

### Met dynamische inhoud

```vue
<template>
  <i18n-group prefix="blog.post">
    <template #default="{ t }">
      <article>
        <h1>{{ t('title') }}</h1>
        <div class="meta">
          {{ t('meta.author', { name: author }) }} |
          {{ t('meta.date', { date: publishDate }) }}
        </div>
        <div v-for="(section, index) in sections" :key="index">
          <h2>{{ t(`sections.${index}.title`) }}</h2>
          <p>{{ t(`sections.${index}.content`) }}</p>
        </div>
      </article>
    </template>
  </i18n-group>
</template>

<script setup>
const author = 'John Doe'
const publishDate = '2024-01-01'
const sections = ['intro', 'main', 'conclusion']
</script>
```

## 🎨 Styling

De component omhult zijn inhoud in een div met de class `i18n-group` en eventuele extra classes die zijn opgegeven in de prop `groupClass`:

```css
.i18n-group {
  /* Je basisstijlen */
}

.profile-section {
  /* Aanvullende stijlen voor profielsecties */
}
```

## 🚀 Best practices

1. **Consistente prefixen**: Gebruik consistente en logische prefixen die de structuur van je applicatie weerspiegelen.

```vue
<i18n-group prefix="features.pricing">
<i18n-group prefix="features.security">
```

2. **Modulaire organisatie**: Groepeer gerelateerde vertalingen samen onder betekenisvolle prefixen.

```vue
<i18n-group prefix="checkout.payment">
<i18n-group prefix="checkout.shipping">
```

3. **Herbruikbare componenten**: Maak herbruikbare componenten met hun eigen vertalingsgroepen.

```vue
<!-- UserProfile.vue -->
<i18n-group prefix="user.profile">

<!-- UserSettings.vue -->
<i18n-group prefix="user.settings">
```

4. **Geneste groepen**: Vermijd te diep nesten van groepen om duidelijkheid te behouden.

```vue
<!-- Goed -->
<i18n-group prefix="shop.product">

<!-- Vermijd -->
<i18n-group prefix="shop.category.product.details.specs">
```
