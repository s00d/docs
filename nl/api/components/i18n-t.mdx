# 🌍 `<i18n-t>`-component

De `<i18n-t>`-component in `Nuxt I18n Micro` is een flexibele vertaalcomponent die dynamische invoeging van inhoud via slots ondersteunt. Je kunt vertalingen interpoleren met eigen Vue-componenten of HTML-inhoud, waardoor geavanceerde lokalisatiescenario's mogelijk zijn.

Slechts één van `plural`, `number`, `date` en `relativeDate` is tegelijk actief. Wanneer meerdere zijn ingesteld, wint de eerste in deze volgorde.

### Voorbeelden per prop

```vue
<!-- keypath: de vertaling om te renderen -->
<i18n-t keypath="feedback.text" />

<!-- plural: bepaalt de meervoudsvorm -->
<i18n-t keypath="items" :plural="10" />

<!-- params: geïnterpoleerd in de vertaling -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: het element om te renderen -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: geformatteerd, daarna geïnterpoleerd -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty met fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Niets om te tonen" />
```

## 🛠️ Voorbeeldgebruik

### Basisgebruik

```vue
<i18n-t keypath="feedback.text" />
```

Dit rendert de vertaling voor `feedback.text` binnen een `<span>`-tag.

### Slots gebruiken voor dynamische inhoud

De `<i18n-t>`-component ondersteunt het gebruik van slots om Vue-componenten of andere inhoud dynamisch in specifieke delen van de vertaling in te voegen.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

In dit voorbeeld wordt de placeholder `\{link\}` in de vertaalstring `feedback.text` vervangen door de `<nuxt-link>`-component, die zelf weer een andere vertaalcomponent bevat.

### Meervoudsvormen

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

Dit past automatisch meervoudsregels toe op basis van de waarde van `itemCount`.

## 🚀 Aanvullende functies

### Standaard-slot

Als er geen specifieke slot wordt meegegeven, kan de vertaling worden aangepast via de default-slot, die de volledige vertaalde string biedt:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### Voorwaardelijk renderen

Render niets als de vertaalstring leeg is met de prop `hideIfEmpty`.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### Aangepaste meervoudsregel

Gebruik een aangepaste functie om meervoudsvormen af te handelen.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### Geavanceerd voorbeeld met slots

Gebruik slots om aan te passen hoe de vertaalinhoud wordt gerenderd.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
