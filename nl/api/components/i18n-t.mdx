# 🌍 `<i18n-t>`-component

Het `<i18n-t>`-component in `Nuxt I18n Micro` is een flexibel vertaalcomponent dat dynamische content-invoeging via slots ondersteunt. Het stelt je in staat om vertalingen te interpoleren met aangepaste Vue-componenten of HTML-inhoud, wat geavanceerde lokalisatiescenario's mogelijk maakt.

Slechts één van `plural`, `number`, `date` en `relativeDate` is tegelijk van toepassing; wanneer meerdere
zijn ingesteld, wint de eerste in die lijst.

### Voorbeelden per prop

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

## 🛠️ Voorbeeldgebruik

### Basisgebruik

```vue
<i18n-t keypath="feedback.text" />
```

Dit rendert de vertaling voor `feedback.text` binnen een `<span>`-tag.

### Slots gebruiken voor dynamische inhoud

Het `<i18n-t>`-component ondersteunt het gebruik van slots om dynamisch Vue-componenten of andere inhoud in specifieke delen van de vertaling in te voegen.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

In dit voorbeeld wordt de `\{link\}`-placeholder in de vertaalstring `feedback.text` vervangen door het `<nuxt-link>`-component, dat op zijn beurt weer een vertaalcomponent bevat.

### Pluralisatie

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

Dit past automatisch pluralisatieregels toe op basis van de waarde `itemCount`.

## 🚀 Aanvullende features

### Standaardslot

Als er geen specifieke slot wordt geleverd, kan de vertaling worden aangepast via het standaardslot, dat de volledige vertaalde string levert:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### Voorwaardelijke rendering

Rendert niets als de vertaalstring leeg is met behulp van de prop `hideIfEmpty`.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### Aangepaste pluralisatieregel

Gebruik een aangepaste functie om pluralisatie te verwerken.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### Geavanceerd voorbeeld met slots

Gebruik slots om aan te passen hoe de vertaalinhoud wordt gerenderd.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
