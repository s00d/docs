De module roept één runtime-hook (app-hook) aan: `i18n:register`. Gebruik deze wanneer een plugin of module vertalingen toevoegt die niet in je `locales/`-bestanden staan. Je callback krijgt een `register`-functie die vertalingen samenvoegt in de pagina die wordt weergegeven.

## `i18n:register` {#i18nregister}

```ts
'i18n:register': (
  register: (translations: unknown, locale?: string) => void,
  locale: string,
) => HookResult
```

| Argument | Beschrijving |
| --- | --- |
| `register(translations, locale?)` | Voegt `translations` diep samen in de paginachunk van de route die wordt geladen, voor `locale` (standaard: de `locale` van de hook). Bestaande sleutels worden overschreven. |
| `locale` | De locale van de route die wordt geladen. |

De hook is getypeerd via `RuntimeNuxtHooks`, dus `nuxtApp.hook('i18n:register', …)` heeft geen cast nodig.

## Wanneer de hook wordt aangeroepen {#when-it-fires}

De loader-plugin (`i18n-plugin-loader`) roept hem aan:

1. één keer bij het opstarten, wanneer alle plugins zijn uitgevoerd (`app:created`) en voordat de app rendert;
2. in zijn `router.beforeEach`, nadat de vertalingen van de doelpagina zijn geladen, wanneer het pad verandert — bij elke navigatie onder `no_prefix`.

Op elke callback en elke `register`-aanroep wordt gewacht voordat de app rendert of de navigatie doorgaat, zodat de pagina met de samengevoegde sleutels rendert. Met [`hooks: false`](/nl/api/module-options#hooks) wordt de hook nooit aangeroepen.

## Voorbeeld {#example}

```ts
// plugins/i18n-extra.ts
export default defineNuxtPlugin((nuxtApp) => {
  nuxtApp.hook('i18n:register', async (register, locale) => {
    const extra = await $fetch<Record<string, unknown>>(`/api/cms-strings/${locale}`)
    register(extra, locale)
  })
})
```

Dit is een runtime-hook: registreer hem met `nuxtApp.hook` in een plugin, niet met `nuxt.hook` in `nuxt.config` of in de `setup` van een module. Een module voegt zo'n plugin toe met `addPlugin`.
