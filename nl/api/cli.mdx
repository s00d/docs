## Algemene flags {#common-flags}

| Flag | Standaard | Beschrijving |
| --- | --- | --- |
| `--cwd` | huidige map | Projectmap |
| `--logLevel` | `info` | Uitvoerniveau: silent, info |
| `--debug` | `false` | Een stacktrace tonen wanneer een commando mislukt |

## Inspecteren {#inspect}

### `info` {#info}

De opgeloste i18n-configuratie van het project tonen

| Flag | Standaard | Beschrijving |
| --- | --- | --- |
| `--json` | `false` | JSON tonen in plaats van tekst |

### `check` {#check}

De CI-poort: faalt bij ontbrekende, lege, extra, ongedefinieerde of ongebruikte keys en kapotte placeholders

| Flag | Standaard | Beschrijving |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` van nuxt.config | Vertalingsmap, relatief ten opzichte van het project |
| `--only` | alles behalve duplicates | Kommagescheiden controles om uit te voeren: missing, empty, extra, placeholders, undefined, unused, duplicates. Als `unused` hier genoemd wordt, faalt het wanneer het niet kan worden uitgevoerd |
| `--duplicates` | `false` | Ook dezelfde tekst onder verschillende keys melden |
| `--ignore` | — | Kommagescheiden globs van bronbestanden om over te slaan, relatief ten opzichte van het project |
| `--json` | `false` | JSON tonen in plaats van tekst |

```bash
i18n-micro check
i18n-micro check --only missing,placeholders --json
```

### `stats` {#stats}

Voltooiing van vertalingen per locale tonen

| Flag | Standaard | Beschrijving |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` van nuxt.config | Vertalingsmap, relatief ten opzichte van het project |
| `--html` | — | Ook een HTML-rapport naar dit bestand schrijven |
| `--json` | `false` | JSON tonen in plaats van tekst |
| `--baseRef` | — | Git-ref om de voltooiing mee te vergelijken, bijv. HEAD~1 of main |

```bash
i18n-micro stats --baseRef main
i18n-micro stats --html reports/i18n.html
```

### `lint` {#lint}

De tekst van vertalingen controleren; faalt wanneer er problemen overblijven

| Flag | Standaard | Beschrijving |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` van nuxt.config | Vertalingsmap, relatief ten opzichte van het project |
| `--rules` | alle, of `enabledRules` van .i18n-lintrc.json | Kommagescheiden regels om uit te voeren: no-trailing-spaces, no-multiple-spaces, no-empty-translation, of een aangepaste regel |
| `--fix` | `false` | Herstellen wat herstelbaar is: spaties, en aangepaste regels met een vervanging |
| `--json` | `false` | JSON tonen in plaats van tekst |

```bash
i18n-micro lint --rules no-trailing-spaces --fix
```

### `search` {#search}

Keys en waarden doorzoeken en tonen waar elke key wordt gebruikt

| Flag | Standaard | Beschrijving |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` van nuxt.config | Vertalingsmap, relatief ten opzichte van het project |
| `<query>` | — | Tekst of key om naar te zoeken |
| `--caseSensitive` | `false` | Hoofdlettergevoelig zoeken |
| `--onlyUnused` | `false` | Alleen keys die `clean` zou verwijderen; de query wordt optioneel |
| `--scope` | `all` | Waar te zoeken: global, pages, all |
| `--limit` | — | Maximaal dit aantal keys teruggeven |
| `--ignore` | — | Kommagescheiden globs van bronbestanden om over te slaan, relatief ten opzichte van het project |
| `--json` | `false` | JSON tonen in plaats van tekst |

```bash
i18n-micro search "Welcome"
i18n-micro search --onlyUnused
```

## Vertaalworkflow {#translation-workflow}

### `extract` {#extract}

De keys opsommen die bronbestanden gebruiken en nog geen tekst hebben, en die met een standaardtekst toevoegen aan de standaardlocale

| Flag | Standaard | Beschrijving |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` van nuxt.config | Vertalingsmap, relatief ten opzichte van het project |
| `--ignore` | — | Kommagescheiden globs van bronbestanden om over te slaan, relatief ten opzichte van het project |

```bash
i18n-micro extract
```

### `translate` {#translate}

Ontbrekende vertalingen vanuit de standaardlocale aanvullen via een vertaalservice

| Flag | Standaard | Beschrijving |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` van nuxt.config | Vertalingsmap, relatief ten opzichte van het project |
| `--service` | — | Vertaalservice: ai, azure, deepl, google, libretranslate, yandexcloud |
| `--token` | — | API-sleutel. Gebruik bij voorkeur de omgevingsvariabele I18N_TRANSLATE_TOKEN: flags belanden in de shellgeschiedenis |
| `--options` | — | Serviceopties als key:value-paren, gescheiden door komma's |
| `--locale` | elke locale behalve de standaardlocale | Kommagescheiden locales om aan te vullen |
| `--replace` | `false` | Elke key opnieuw vertalen en bestaande waarden vervangen |
| `--dryRun` | `false` | Keys en tekens per locale tellen; niets versturen |
| `--chunkSize` | — | Strings per verzoek; begrensd tot wat de service accepteert |
| `--pluralSeparator` | `\|` | Scheidingsteken van meervoudsvormen in berichten |
| `--glossaryFile` | `.i18n-glossary.json` als het bestaat | Woordenlijstbestand, gebruikt door de `ai`-service |

```bash
i18n-micro translate --dryRun
I18N_TRANSLATE_TOKEN=... i18n-micro translate --service deepl --locale de,fr
i18n-micro translate --service ai --options provider:openai,model:gpt-4o-mini
i18n-micro translate --service libretranslate --options baseUrl:https://translate.example.com
```

### `sync` {#sync}

Keys verwijderen die de standaardlocale niet heeft; stopt wanneer niet kan worden aangetoond dat dit veilig is. Ontbrekende keys blijven ontbreken

| Flag | Standaard | Beschrijving |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` van nuxt.config | Vertalingsmap, relatief ten opzichte van het project |
| `--ignore` | — | Kommagescheiden globs van bronbestanden om over te slaan, relatief ten opzichte van het project |
| `--dryRun` | `false` | Opsommen wat verwijderd zou worden; niets schrijven |
| `--force` | `false` | Keys verwijderen, ook al kan niet worden aangetoond dat het veilig is |

```bash
i18n-micro sync --dryRun
```

### `clean` {#clean}

Keys verwijderen die nergens in het project worden gebruikt; stopt wanneer dat niet kan worden aangetoond

| Flag | Standaard | Beschrijving |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` van nuxt.config | Vertalingsmap, relatief ten opzichte van het project |
| `--include` | — | Reguliere expressie: alleen overeenkomende keys in aanmerking nemen voor verwijdering |
| `--exclude` | — | Reguliere expressie: overeenkomende keys nooit verwijderen |
| `--ignore` | — | Kommagescheiden globs van bronbestanden om over te slaan, relatief ten opzichte van het project |
| `--dryRun` | `false` | Opsommen wat verwijderd zou worden; niets schrijven |
| `--force` | `false` | Keys verwijderen, ook al kan het gebruik niet voor allemaal worden aangetoond |

```bash
i18n-micro clean --dryRun
i18n-micro clean --exclude '^errors\.'
```

## Refactoring {#refactoring}

### `text-to-i18n` {#text-to-i18n}

Hardgecodeerde tekst in Vue-templates vervangen door vertaalaanroepen, en hardgecodeerde tekst in code melden

| Flag | Standaard | Beschrijving |
| --- | --- | --- |
| `--translationFile` | `<translationDir>/<defaultLocale>.json` | Bestand waar de nieuwe keys naartoe gaan |
| `--path` | het hele project | Bestand of map om te verwerken |
| `--context` | — | Prefix voor gegenereerde keys |
| `--ignore` | — | Kommagescheiden globs van bronbestanden om over te slaan, relatief ten opzichte van het project |
| `--dryRun` | `false` | Tonen wat er zou veranderen; niets schrijven |
| `--interactive` | `false` | Elke gegenereerde key bevestigen of bewerken |

```bash
i18n-micro text-to-i18n --dryRun
i18n-micro text-to-i18n --path components --context ui
```

### `rename` {#rename}

Een key of namespace hernoemen in elke locale en in bronbestanden

| Flag | Standaard | Beschrijving |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` van nuxt.config | Vertalingsmap, relatief ten opzichte van het project |
| `--from` **\*** | — | Huidige key of namespace |
| `--to` **\*** | — | Nieuwe key of namespace |
| `--ignore` | — | Kommagescheiden globs van bronbestanden om over te slaan, relatief ten opzichte van het project |
| `--dryRun` | `false` | De wijzigingen melden; niets schrijven |

**\*** verplicht.

```bash
i18n-micro rename --from common.save --to actions.save
```

Localebestanden herschrijven met gesorteerde keys en uniforme inspringing

| Flag | Standaard | Beschrijving |

## Uitwisseling {#exchange}

### `export` {#export}

Localebestanden exporteren naar PO of CSV, met de tekst van de standaardlocale als bron

| Flag | Standaard | Beschrijving |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` van nuxt.config | Vertalingsmap, relatief ten opzichte van het project |
| `--format` | `po` | Bestandsformaat: po, csv |
| `--dir` | `pots` voor po, `csv_exports` voor csv | Uitvoermap, relatief ten opzichte van het project |
| `--force` | `false` | Bestanden overschrijven die sinds de laatste export zijn gewijzigd en nooit zijn geïmporteerd |

```bash
i18n-micro export --format csv
```

### `import` {#import}

PO- of CSV-bestanden samenvoegen in de localebestanden

| Flag | Standaard | Beschrijving |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` van nuxt.config | Vertalingsmap, relatief ten opzichte van het project |
| `--format` | `po` | Bestandsformaat: po, csv |
| `--dir` | `pots` voor po, `csv_exports` voor csv | Invoermap, relatief ten opzichte van het project |
| `--dryRun` | `false` | Melden wat er geïmporteerd zou worden; niets schrijven |

```bash
i18n-micro import --format csv --dryRun
```

### `sync-remote` {#sync-remote}

Globale vertalingen ophalen van, of pushen naar, het HTTP-endpoint in .i18n-remote.json

| Flag | Standaard | Beschrijving |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` van nuxt.config | Vertalingsmap, relatief ten opzichte van het project |
| `--pull` | `true` | Ophalen van de remote |
| `--push` | `false` | Pushen naar de remote |
| `--force` | `false` | Bij een pull de remote waarde nemen; bij een push tekst overschrijven die alleen de remote heeft |
| `--dryRun` | `false` | Melden wat een pull zou veranderen; niets schrijven of pushen |

```bash
i18n-micro sync-remote --dryRun
i18n-micro sync-remote --no-pull --push
```

## Lintregels {#lint-rules}

| Regel | Vindt | Hersteld door `--fix` |
| --- | --- | --- |
| `no-trailing-spaces` | Spaties aan het einde van een waarde of regel | ja |
| `no-multiple-spaces` | Twee of meer spaties achter elkaar | ja |
| `no-empty-translation` | Een lege of blanco waarde | nee |

## Exitcodes {#exit-codes}

| Code | Betekenis |
| --- | --- |
| `0` | Klaar, niets te melden |
| `1` | Bevindingen: `check`, `lint` of `format --check` heeft iets gevonden, `clean` of `sync` kon niet aantonen dat een verwijdering veilig is, `export` zou niet-geïmporteerd werk overschrijven, `translate` heeft keys overgeslagen, `import` of `sync-remote` stuitte op een conflict, een `sync-remote`-push zou remote tekst laten vallen. Een `--dryRun` van `clean`, `sync` of een `sync-remote`-pull meldt deze en eindigt met `0` |
| `2` | Fout: onjuist gebruik, onleesbaar project, netwerk- of bestandsfout |

## Configuratiebestanden {#configuration-files}

| Bestand | Gebruikt door |
| --- | --- |
| `.i18n-lintrc.json` | `lint`: `enabledRules`, `disabledRules`, `customRegexRules` (`name`, `pattern`, `flags`, `description`, `replacement`) |
| `.i18n-remote.json` | `sync-remote`: `url`, `path`, `token`, `auth` (`username`, `password`). `type` mag worden weggelaten; alleen `custom` bestaat |
| `.i18n-glossary.json` | `translate --service ai`: `entries` van `source`, `target`, en optioneel `from`, `to` |

## Omgevingsvariabelen {#environment-variables}

| Naam | Gebruikt voor |
| --- | --- |
| `I18N_TRANSLATE_TOKEN` | API-sleutel van `translate`. Wordt ook uit `.env` gelezen |
| `I18N_REMOTE_TOKEN` | Bearer-token van `sync-remote`. Wordt ook uit `.env` gelezen |
| `AI_GATEWAY_API_KEY, OPENAI_API_KEY, ANTHROPIC_API_KEY` | Sleutel van de `ai`-service, wanneer `I18N_TRANSLATE_TOKEN` niet is ingesteld |
| `DEFAULT_LOCALE` | Overschrijft `defaultLocale`, net als in de module |
