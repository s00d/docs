---

De module injecteert zijn runtime-helpers in de Nuxt-app: `$t`, `$tc`, `$localePath`, `$switchLocale` en de rest. Gebruik deze pagina om de signatuur en het gedrag van een helper op te zoeken. Signaturen en beschrijvingen komen uit de interfaces `PluginsInjections` en `NuxtAppOnlyInjections` in `src/runtime/plugins/01.plugin.ts`.

## Toegang {#access}

| Waar | Hoe |
| --- | --- |
| Template | `{{ $t('title') }}` — elke helper, met de `$` |
| `<script setup>` | `const { t, localePath } = useI18n()` — elke helper in `PluginsInjections`, met en zonder de `$` |
| Plugin, middleware, `<script setup>` | `const { $t, $defineI18nRoute } = useNuxtApp()` — alles, alleen met `$` |

`$defineI18nRoute` is alleen getypeerd op `useNuxtApp()`. Zie [`useI18n`](/nl/composables/useI18n).

```vue
<script setup lang="ts">
const { t, localePath } = useI18n()
</script>

<template>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
</template>
```

## Locale {#locale}

### `$getLocale` {#$getlocale}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric) => string
```

Code van de actieve locale. Geef een route mee om de locale te lezen waartoe die route behoort.

```ts
$getLocale() // 'de' on /de/about
```

### `$getLocaleName` {#$getlocalename}

```ts
() => string | null
```

De `displayName` van de actieve locale uit de config, of `null` als die er geen heeft.

### `$getLocales` {#$getlocales}

```ts
() => Locale[]
```

Elke geconfigureerde locale, met zijn metadata.

Aangepaste eigenschappen op een locale-object komen terug zoals ze geschreven zijn; typeer ze met [module augmentation](/nl/api/module-options#locales) van `Locale`.

### `$defaultLocale` {#$defaultlocale}

```ts
() => string | undefined
```

Code van de geconfigureerde standaardlocale.

### `$getI18nConfig` {#$geti18nconfig}

```ts
() => ResolvedI18nConfig
```

De opgeloste moduleconfiguratie, zoals de runtime die ziet.

De waarde bevat [runtime-overrides](/nl/guide/runtime-overrides) (`defaultLocale`, `fallbackLocale`, uitgeschakelde locales).

```ts
const { strategy, localeCookie } = useNuxtApp().$getI18nConfig()
```

## Vertaling {#translation}

### `$t` {#$t}

```ts
TranslationFn<CleanTranslation>
```

Vertaal een sleutel en interpoleer `params` erin. Geeft `defaultValue` terug wanneer de sleutel
ontbreekt, of de sleutel zelf wanneer er geen standaardwaarde is opgegeven.

```ts
// { "welcome": "Welcome, {name}!" }
$t('welcome', { name: 'Ada' }) // 'Welcome, Ada!'
$t('missing.key', {}, 'Fallback') // 'Fallback'
```

Een sleutel die naar een genest object wijst, geeft dat object terug, geen string. In een template wordt dat weergegeven als `[object Object]`; gebruik een bladsleutel.

### `$ts` {#$ts}

```ts
TranslationFn<string>
```

Zoals `$t`, maar geeft altijd een string terug: de waarde gaat door `toString()`, dus een genest
object wordt `'[object Object]'`. Laat de sleutel naar een blad wijzen.

### `$_t` {#$_t}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<CleanTranslation>
```

Koppel `$t` aan een specifieke route, om buiten de huidige pagina te vertalen — bijvoorbeeld een layout
die een link naar een andere route rendert.

```ts
const route = useRoute()
const t = useNuxtApp().$_t(route)
t('page.title')
```

### `$_ts` {#$_ts}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<string>
```

Koppel `$ts` aan een specifieke route. Zie `$_t`.

### `$tc` {#$tc}

```ts
(key: TranslationKey, params: number | Params, defaultValue?: string) => string
```

Vertaal met meervoudsvorming. `params` kan de telling zelf zijn, of een object dat
`count` bevat.

Vormen worden gescheiden door `|`. Met de ingebouwde regel kiest een niet-negatieve gehele telling `n` vorm `n`, begrensd tot de laatste vorm; een negatieve, fractionele of `NaN`-telling neemt de laatste vorm. `{count}` en de andere params worden in de gekozen vorm geïnterpoleerd.

Voor talen waarvan de meervouden de telling niet volgen, begin je de template met `=0 `. De eerste vorm is dan voor 0, en de andere volgen de categorie van [`Intl.PluralRules`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/PluralRules), in de volgorde `zero, one, two, few, many, other`:

```json
{
  "apples": "=0 no apples | one apple | {count} apples",
  "files": "=0 no files | {count} one | {count} few | {count} many"
}
```

```ts
$tc('apples', 0) // 'no apples'
$tc('apples', 1) // 'one apple'
$tc('apples', 7) // '7 apples'

// In `uk` (categories `one, few, many, other`) the forms after the zero form follow those categories:
$tc('files', 21) // '21 one'
$tc('files', 22) // '22 few'
$tc('files', 25) // '25 many'
$tc('files', 2.5) // '2.5 many': no form for `other`, so the last one
```

- `=0 ` telt alleen helemaal aan het begin van de waarde, met de spatie. `$t` toont het als tekst: het hoort bij meervouden.
- Een categorie zonder eigen vorm neemt de laatste vorm. Een negatieve of fractionele telling neemt ook de laatste vorm.
- Het werkt in elke locale: `=0 none | one | {count} many` in het Engels.
- De categorie komt van de `iso` van de locale, anders van zijn code. Een code die `Intl` niet kent, valt terug op de indexregel, waarbij de markering nog steeds wordt verwijderd, zodat het resultaat nooit van de machine afhangt.
- `<i18n-t :plural>` volgt dezelfde regel. Een eigen [`plural`](/nl/api/module-options#plural) of `customPluralRule` krijgt de ruwe waarde, inclusief markering, en beslist zelf; een `plural` die `null` teruggeeft, geeft de aanroep terug aan de ingebouwde regel, die de markering respecteert.

Zonder de markering blijft een template op de indexregel, met één uitzondering die maar op één manier te lezen is: een nulvorm zonder placeholder, daarna één vorm per categorie, met `{count}` in elke vorm die door meerdere tellingen wordt gedeeld (`no files | {count} one | {count} few | {count} many` in `uk`).

Stel voor eigen regels [`plural`](/nl/api/module-options#plural) in.

```ts
// { "apples": "no apples | one apple | {count} apples" }
$tc('apples', 0) // 'no apples'
$tc('apples', 10) // '10 apples'
$tc('cart', { count: 2, name: 'Ada' }) // count and params in one object
```

Het derde argument is `defaultValue`, niet params.

### `$has` {#$has}

```ts
(key: string) => boolean
```

Of een sleutel in de actieve locale wordt opgelost. Gebruik het om te vertakken op optionele tekst in plaats van
een ruwe sleutel te renderen. Net als `$t` ziet het tijdens een paginatransitie binnen dezelfde locale ook de sleutels
van de pagina die wordt verlaten.

```ts
if ($has('promo.banner')) show.value = true
```

## Formattering {#formatting}

### `$tn` {#$tn}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Formatteer een getal met `Intl.NumberFormat` in de actieve locale. Een sleutel selecteert een benoemd formaat
uit de config.

Benoemde formaten komen uit [`numberFormats`](/nl/api/module-options#numberformats).

```ts
$tn(1234.5, { style: 'currency', currency: 'EUR' }) // '1.234,50 €' in de
$tn(1000, 'currency') // named format
$tn(1000, 'currency', 'de') // named format in another locale
```

### `$td` {#$td}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Formatteer een datum met `Intl.DateTimeFormat` in de actieve locale. Een sleutel selecteert een benoemd formaat
uit de config.

Benoemde formaten komen uit [`datetimeFormats`](/nl/api/module-options#datetimeformats).

```ts
$td(new Date(), { dateStyle: 'long' })
$td(post.createdAt, 'short')
```

### `$tdr` {#$tdr}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

Formatteer een datum als relatieve tijd ("3 dagen geleden") met `Intl.RelativeTimeFormat`.

```ts
$tdr(Date.now() - 5 * 60_000) // '5 minutes ago' in en
```

## Wisselen en links {#switching-and-links}

### `$switchLocale` {#$switchlocale}

```ts
(locale: string) => Promise<boolean>
```

Navigeer naar de huidige pagina in een andere locale. Onder `no_prefix` en hash-modus laadt het de
vertalingen van de locale vóór het navigeren; onder `no_prefix` wordt de route ter plekke vervangen (geen
nieuwe geschiedenisvermelding). Een onbekende locale wordt genegeerd.
De aanroep is async: gebruik `await` om code na de navigatie uit te voeren. Het resulteert in `true` wanneer het
woordenboek van de locale actief is, `false` wanneer dat niet zo is: het chunk kon niet worden geladen (het huidige
woordenboek blijft; roep het opnieuw aan om het nog eens te proberen) of een nieuwere wissel heeft gewonnen.

```ts
await $switchLocale('de')
```

### `$switchLocalePath` {#$switchlocalepath}

```ts
(locale: string) => string
```

Het pad van de huidige pagina in een andere locale, zonder te navigeren.

```vue
<NuxtLink :to="$switchLocalePath('de')">Deutsch</NuxtLink>
```

### `$switchLocaleRoute` {#$switchlocaleroute}

```ts
(locale: string) => RouteLocationRaw
```

Het route-object voor de huidige pagina in een andere locale, zonder te navigeren, of een URL-string
voor een locale op een eigen `baseUrl`. Onder `trailingSlash` heeft het object `path` en `fullPath`,
volgens de regel, met `query` en `hash` zoals ze zijn, en `router.push` of een link behouden ze.

### `$switchRoute` {#$switchroute}

```ts
(route: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, toLocale?: string) => Promise<void>
```

Navigeer naar een andere route, met behoud van de actieve locale of door over te schakelen naar `toLocale`. Async, net als
`$switchLocale`.

```ts
$switchRoute('/about') // active locale
$switchRoute({ name: 'about' }, 'de') // switch to de
```

### `$localePath` {#$localepath}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => string
```

Los een pad op in de opgegeven locale, of in de actieve. Een string met een `http(s):`-, `mailto:`-
of `tel:`-schema komt ongewijzigd terug: geef gebruikersinvoer niet ongecontroleerd door als linkdoel.

Een stringpad wordt gelezen als de pagina die het toont, dus het aangepaste pad van een locale wordt ook toegepast.

```ts
$localePath('/about') // '/about' in en, '/de/ueber-uns' in de with localeRoutes
$localePath({ name: 'about' }, 'fr') // '/fr/about'
```

### `$localeRoute` {#$localeroute}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => RouteLocationResolved
```

Los een route op in de opgegeven locale, of in de actieve. Een gewoon object, veilig om in state te bewaren. Wanneer een param
escaping nodig heeft, heeft het `path`, `fullPath`, `query` en `hash`, maar geen `name` of `params`: het pad geeft de router
de gecodeerde URL. Voor een locale op een ander domein zijn `path` en `fullPath` absoluut, wat de router niet aankan:
zo'n link loopt via `<i18n-link>`, of `$localePath`.

### `$getRouteName` {#$getroutename}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric, locale?: string) => string
```

Routenaam zonder het locale-prefix — de naam waarop vertalingen zijn gesleuteld.

```ts
$getRouteName() // 'about' on /de/about
```

## Paginaconfiguratie {#page-config}

### `$defineI18nRoute` {#$definei18nroute}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Registreer locale-configuratie en vertalingen per pagina vanuit een component.
Wordt samengevoegd in de actieve locale en opnieuw toegepast wanneer de locale verandert.

Roep het aan in de `<script setup>` van een pagina, altijd gedestructureerd uit `useNuxtApp()`. De build leest `locales`, `localeRoutes` en `disableMeta` uit de aanroep; tijdens runtime telt alleen `locales` (inline vertalingen worden samengevoegd voor de actieve locale). Volledige regels: [Paginaconfiguratie](/nl/guide/per-component-translations).

```vue
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'de'],
  localeRoutes: { en: '/about', de: '/ueber-uns' },
})
</script>
```

### `$setI18nRouteParams` {#$seti18nrouteparams}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Stel params per locale in voor de huidige route, zodat een dynamisch segment per taal kan verschillen.
Roep het aan tijdens SSR, voordat de head wordt gerenderd.

De params worden gewist wanneer een navigatie naar een ander pad wordt doorgevoerd, ook van `/news/1` naar `/news/4`, waarbij de routenaam gelijk blijft. Details: [Gelokaliseerde paden](/nl/guide/custom-locale-routes).

```ts
$setI18nRouteParams({
  en: { slug: 'my-post' },
  de: { slug: 'mein-beitrag' },
})
```

## Runtime-vertalingen {#runtime-translations}

### `$mergeTranslations` {#$mergetranslations}

```ts
(newTranslations: Translations) => void
```

Voeg tijdens runtime vertalingen samen in de actieve locale, waarbij wat geladen is wordt overschreven.

Voegt diep samen in het huidige paginachunk van de actieve locale; sleutels die niet worden genoemd, blijven bestaan.

```ts
$mergeTranslations({ banner: { title: 'Sale' } })
```

### `$setTranslation` {#$settranslation}

```ts
(key: string, value: unknown) => void
```

Vervang de waarde op `key` in het actieve woordenboek. Dit is vervangen, niet samenvoegen —
gebruik `$mergeTranslations` wanneer bestaande naastgelegen sleutels moeten blijven bestaan.

```ts
$setTranslation('banner', { title: 'Sale' }) // drops other keys under banner
$setTranslation('banner.title', 'Sale') // dotted path
```

### `$loadPageTranslations` {#$loadpagetranslations}

```ts
(locale: string, routeName: string, translations: Translations) => Promise<void>
```

Laad vertalingen voor een pagina tijdens runtime, voor content waarvan de sleutels bij het builden niet bekend zijn.

Wordt samengevoegd in het `(locale, routeName)`-chunk in het geheugen, en het scherm wordt bijgewerkt wanneer dat chunk actief is. Er wordt hier geen payload opgehaald: voor een pagina die nog niet is geladen wachten de vertalingen, en wanneer het bestand ervan laadt, blijven ze erbovenop liggen.

```ts
await $loadPageTranslations('en', 'about', { title: 'About us' })
```

### `$resolveTranslations` {#$resolvetranslations}

```ts
() => Translations
```

Elke vertaling die momenteel in het geheugen staat voor de actieve locale en route, als boom.
Alleen-lezen weergave van wat `$t()` op dit moment kan oplossen.

Behandel het resultaat als alleen-lezen.

### `$setMissingHandler` {#$setmissinghandler}

```ts
(handler: MissingHandler | null) => void
```

Installeer een callback die wordt aangeroepen voor elke onopgeloste sleutel. Geef `null` mee om hem te verwijderen.

De handler wordt uitgevoerd in plaats van de dev-waarschuwing.

```ts
$setMissingHandler((locale, key, routeName) => {
  console.error(`[i18n] missing ${key} in ${locale} (${routeName})`)
})
```

### `$clearCache` {#$clearcache}

```ts
() => void
```

Verwijder elk gecachet vertaalchunk en laad het woordenboek van de huidige pagina opnieuw. De pagina
blijft haar huidige vertalingen tonen totdat de nieuwe binnen zijn. Dev-HMR roept het aan bij
elke wijziging van een vertaalbestand.

```ts
const { clearCache } = useI18n()
clearCache()
```

Een mislukte herlaadpoging behoudt het huidige woordenboek.
