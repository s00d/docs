Deze sectie somt elke optie, helper, hook, composable en component van de Nuxt-module op, plus de geëxporteerde API van elk `@i18n-micro/*`-package. Gebruik haar om een signatuur of standaardwaarde op te zoeken; de [Gids](/nl/guide/getting-started) legt uit hoe je ze gebruikt. De meeste tabellen hier worden uit de broncode gegenereerd, dus ze komen overeen met de code.

## Nuxt-module {#nuxt-module}

| Pagina | Behandelt |
| --- | --- |
| [Moduleopties](/nl/api/module-options) | Elke `i18n`-sleutel in `nuxt.config`, met type en standaardwaarde |
| [Helpers](/nl/api/methods) | `$t`, `$tc`, `$tn`, `$td`, `$localePath`, `$switchLocale`, `$defineI18nRoute` en de rest |
| [Hooks](/nl/api/events) | De runtime-hook `i18n:register` |

## Composables {#composables}

| Composable | Gebruik het voor |
| --- | --- |
| [`useI18n`](/nl/composables/useI18n) | De helpers in `<script setup>` |
| [`useI18nLocale`](/nl/composables/useI18nLocale) | Locale-status en cookie in een eigen detectieplugin |
| [`useI18nHead`](/nl/composables/useI18nHead) | Overschrijvingen per pagina van de gegenereerde SEO-tags |
| [`useLocaleHead`](/nl/composables/useLocaleHead) | De SEO-tags als object, voor je eigen `useHead` |

## Componenten {#components}

| Component | Rendert |
| --- | --- |
| [`<i18n-t>`](/nl/components/i18n-t) | Eén vertaling, met meervoud, opmaak en slot-interpolatie |
| [`<i18n-link>`](/nl/components/i18n-link) | Een `NuxtLink` naar de gelokaliseerde route |
| [`<i18n-switcher>`](/nl/components/i18n-switcher) | Een locale-dropdown |
| [`<i18n-group>`](/nl/components/i18n-group) | Een blok met een gedeeld sleutelprefix |

## Server {#server}

Nitro-handlers gebruiken `useTranslationServerMiddleware` en `useLocaleServerMiddleware`, niet de client-helpers. Zie [Serverroutes](/nl/guide/server-side-translations).

## Packages {#packages}

[Package-API's](/nl/api/packages/overview) somt de exports van elk `@i18n-micro/*`-package op, met één gegenereerde pagina per package.
