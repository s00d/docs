# API-referentie

## Runtime-API

- [Methoden](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, localewisseling, routeringhelpers
- [Events](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Vertalingen en cache](/api/cache) — `TranslationStorage`, payload-laden, `$clearCache`

## Server-middleware

Server-handlers gebruiken specifieke middleware (niet de client-side `$t`-helpers):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — vertaal in API-routes en server-handlers
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — lees gedetecteerde locale en metadata

Zie de volledige [gids Server-side vertalingen](/guides/server-side-translations) voor setup, prioriteit van localedetectie en voorbeelden.
