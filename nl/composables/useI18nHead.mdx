title: "useI18nHead"

---

`useI18nHead()` wijzigt de SEO-tags die de module genereert, voor slechts één pagina. Gebruik het wanneer een pagina het beter weet dan de router: een CMS-artikel dat maar in enkele locales bestaat, een canonical URL uit een API, extra `og:`-tags. Je krijgt de gegenereerde tags met jouw overschrijvingen eroverheen samengevoegd.

## Signatuur {#signature}

```ts
useI18nHead(input?: MaybeRefOrGetter<I18nHeadInput | null>): { pageHead: any; resetPageHead: () => void }
```

Registreer overschrijvingen op paginaniveau voor i18n-SEO-headtags.
Wordt door de plugin `02.meta` samengevoegd over de uitvoer van `useLocaleHead`.

Gebruik bij voorkeur een getter (`() => ({ … })`) wanneer waarden uit `$t` / `t` komen, zodat ze
opnieuw worden bepaald bij een locale-wissel. Een gewoon object wordt één keer geëvalueerd en blijft daarna bevroren.

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| `input` *(optioneel)* | `MaybeRefOrGetter<I18nHeadInput \| null>` |  |

Het werkt met [`meta: true`](/nl/api/module-options#meta) (de standaard): de meta-plugin van de module voegt de invoer bij elke head-render samen over de uitvoer van [`useLocaleHead`](/nl/composables/useLocaleHead). Met `meta: false` leest niets de invoer.

De overschrijving wordt gereset wanneer de routenaam verandert. Een pagina die `disableMeta` instelt, krijgt helemaal geen i18n-tags, overschrijvingen inbegrepen.

## Invoer {#input}

`I18nHeadInput` (uit `@i18n-micro/types`):

| Sleutel | Type | Effect |
| --- | --- | --- |
| `htmlAttrs` | `Record<string, string>` | Samengevoegd in de attributen van `<html>` (`lang`, `dir`). |
| `meta` | `I18nHeadMeta[]` | Toegevoegd na de gegenereerde tags; vervangt een tag met dezelfde `id`, `property` of `name`. |
| `link` | `I18nHeadLink[]` | Toegevoegd na de gegenereerde links; vervangt een link met dezelfde `id`, of `rel` + `hreflang`. |
| `replace.canonical` | `string \| false` | Vervang de canonical `href`, of verwijder de link. |
| `replace.hreflang` | `I18nHeadLink[] \| false` | Vervang of verwijder **elke** `rel="alternate"`-link, `x-default` inbegrepen. |
| `replace.xDefault` | `I18nHeadLink \| false` | Vervang of verwijder de `x-default`-link. |
| `replace.ogLocale` | `string \| false` | Vervang of verwijder `og:locale`. |
| `replace.ogUrl` | `string \| false` | Vervang of verwijder `og:url`. |
| `replace.ogAlternates` | `string[] \| false` | Bouw `og:locale:alternate` opnieuw op uit deze locale-codes (via `og` / `iso`), waarbij de huidige locale, onbekende codes en codes zonder `og`- of `iso`-waarde worden overgeslagen, of verwijder ze. |
| `disable` | `I18nHeadDisableGroup[]` | Laat gegenereerde groepen weg: `'hreflang'` (niet `x-default`), `'x-default'`, `'canonical'`, `'og'` (`og:locale` + `og:url`), `'og-alternates'`, `'html'`. |

Volgorde van toepassing: `disable`, dan `replace`, dan `htmlAttrs`, `meta`, `link`.

## Voorbeeld {#example}

Een artikel dat maar in enkele locales bestaat, met alternatieve URL's uit de API:

```vue
<script setup lang="ts">
const route = useRoute()
const { t } = useI18n()
const { data: article } = await useFetch<{ title: string; urls: Record<string, string> }>(`/api/articles/${route.params.slug}`)

useI18nHead(() => {
  if (!article.value) return null
  const codes = Object.keys(article.value.urls)
  return {
    meta: [{ property: 'og:title', content: article.value.title || t('blog.title') }],
    replace: {
      hreflang: codes.map((code) => ({ rel: 'alternate', hreflang: code, href: article.value!.urls[code]! })),
      ogAlternates: codes,
    },
  }
})
</script>
```

Geef een getter mee, zoals hier, wanneer waarden uit `t()` of asynchrone data komen: die wordt opnieuw uitgevoerd bij een locale-wissel. Een gewoon object wordt één keer gelezen.
