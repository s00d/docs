---
title: "useI18n"
description: "useI18n geeft de runtime-helpers (`$t`, `$tc`, `$localePath`, …) terug als een gewoon object, met en zonder `$`-prefix."
---

`useI18n()` geeft de runtime-helpers van de module terug als een gewoon object. Gebruik het in `<script setup>`, composables en plugins in plaats van `useNuxtApp()` aan te roepen. Elke helper is beschikbaar onder zijn `$`-naam en een alias zonder prefix: `t` en `$t` zijn dezelfde functie.

## Signatuur {#signature}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Elke runtime-helper, als een gewoon object.

Dezelfde functies die de plugin injecteert als `$t`, `$tc` enzovoort, beschikbaar onder zowel
de naam met dollarteken als een alias zonder prefix — dus `const { t } = useI18n()` en
`const { $t } = useI18n()` werken allebei.

**Retourneert** — de helpers die beschreven staan in de [referentie van methoden](/nl/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

Het teruggegeven object bevat elke helper van [`PluginsInjections`](/nl/api/methods). Elke helper is gedocumenteerd op de pagina [Helpers](/nl/api/methods).

## Voorbeeld {#example}

```vue
<script setup lang="ts">
const { t, tc, localePath, switchLocale, getLocale } = useI18n()

const title = computed(() => t('page.title'))
</script>

<template>
  <h1>{{ title }}</h1>
  <p>{{ tc('items', 3) }}</p>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
  <button @click="switchLocale(getLocale() === 'en' ? 'de' : 'en')">{{ t('nav.switch') }}</button>
</template>
```

## Niet in het type {#not-in-the-type}

`$defineI18nRoute` is alleen getypeerd op `useNuxtApp()`:

```ts
const { $defineI18nRoute } = useNuxtApp()
```
