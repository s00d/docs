---
title: "useLocaleHead"
description: "useLocaleHead bouwt de i18n-SEO-tags (lang, dir, canonical, hreflang, og:locale) als een object dat je aan useHead doorgeeft."
---

`useLocaleHead()` bouwt de i18n-headtags voor de huidige route: `lang` en `dir` op `<html>`, een canonical link, `hreflang`-alternatieven met `x-default`, `og:url`, `og:locale` en `og:locale:alternate`. Gebruik het wanneer je [`meta: false`](/nl/api/module-options#meta) instelt en `useHead` zelf beheert; met `meta: true` registreert de module deze tags al, en wijzigingen per pagina lopen via [`useI18nHead`](/nl/composables/useI18nHead).

## Signatuur {#signature}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { build: () => LocaleHead; metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }, LocaleHead | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

De SEO-headtags voor de huidige route: `hreflang`-alternatieven voor elke locale plus
`x-default`, een canonical link, `og:locale`, en `lang`/`dir` op `<html>`.

Alleen nodig wanneer `meta` is uitgeschakeld of de standaardwaarden aangepast moeten worden — met `meta: true`
registreert de module dezelfde tags zelf.

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| `options` | `UseLocaleHeadOptions` |  |

**Retourneert** — `metaObject`, een ref met het head-object dat klaar is om aan `useHead` door te geven; `updateMeta` ververst het; `build` berekent het head-object op basis van de huidige route (reactief wanneer het in een getter wordt gelezen, bijv. `useHead(() => build())`)

```ts
const { metaObject } = useLocaleHead({ addSeoAttributes: true })
useHead(metaObject)
```

## Opties {#options}

| Optie | Standaard | Beschrijving |
| --- | --- | --- |
| `addDirAttribute` | `true` | Stel `dir` op `<html>` in op basis van de `dir` van de locale (`'auto'` als die er geen heeft). |
| `identifierAttribute` | `'id'` | Attribuut dat elke tag een sleutel geeft (`i18n-can`, `i18n-og`, `i18n-alternate-<hreflang>`, …), zodat updates tags vervangen in plaats van ze toe te voegen. |
| `addSeoAttributes` | `true` | Genereer canonical-, `hreflang`- en `og:`-tags. `false` behoudt alleen `htmlAttrs`. |
| `baseUrl` | `'/'` | Origin die aan elke URL wordt gekoppeld. Houd `'/'` aan voor relatieve URL's; geef `'https://example.com'` mee voor absolute URL's. |
| `autoUpdate` | `true` | Bouw `metaObject` opnieuw op wanneer de route of de status `i18n-locale` verandert. |

## Wat het genereert {#what-it-emits}

- Niets op een route zonder match (404) of met `disableMeta` voor de actieve locale.
- Canonical en `og:url`: `$switchLocalePath(<active locale>)`, query beperkt tot [`canonicalQueryWhitelist`](/nl/api/module-options#canonicalquerywhitelist), [`trailingSlash`](/nl/api/module-options#trailingslash) toegepast.
- `hreflang`: één link per ingeschakelde locale waarin de pagina bestaat, `hreflang = iso || code`, waarbij locales met `seo: false` worden overgeslagen; met `hreflangBaseLanguage: true` genereert de eerste regionale locale van een taal ook de tag voor alleen de taal. Geen onder `no_prefix`.
- `x-default`: de URL van de standaardlocale, tenzij de strategie `no_prefix` is, de standaardlocale `seo: false` heeft, of de pagina daarin niet bestaat.
- `og:locale` / `og:locale:alternate`: uit de `og` van de locale, of de omgezette `iso` (`en-US` → `en_US`); overgeslagen met een dev-waarschuwing wanneer geen van beide werkt.

## Voorbeeld {#example}

```ts
// app.vue, with i18n.meta: false
const { metaObject } = useLocaleHead({ baseUrl: 'https://example.com' })
useHead(metaObject)
```

`build()` geeft hetzelfde object terug zonder de ref: `useHead(() => build())` blijft reactief zonder watcher.
