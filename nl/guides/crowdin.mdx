# 🌐 Gids: integratie met Crowdin

## 📖 Inleiding

Door Crowdin te integreren in je project stroomlijn je het lokalisatie- en vertaalproces, waardoor het eenvoudiger wordt om vertalingen over meerdere talen en platforms te beheren. Deze gids biedt een stapsgewijze uitleg over het opzetten van Crowdin in je project, inclusief configuratie, het uploaden van bronnen en het downloaden van vertalingen.

## 🔧 Installatie en setup

Om met Crowdin aan de slag te gaan, installeer je de Crowdin CLI globaal op je machine en initialiseer je die in je projectmap.

### 📦 De Crowdin CLI installeren

Installeer eerst de Crowdin CLI globaal via npm:

```bash
npm install -g @crowdin/cli
```

### 🛠 Crowdin in je project initialiseren

Initialiseer Crowdin in je project door dit uit te voeren:

```bash
crowdin init
```

Deze opdracht begeleidt je door de setup, inclusief het instellen van je project-ID, API-token en andere configuratiedetails.

## 🗂️ Configuratiegids

### 📄 Het Crowdin-configuratiebestand (`crowdin.yml`)

Het Crowdin-configuratiebestand (`crowdin.yml`) beschrijft hoe je bronbestanden worden gemapt en waar vertalingen moeten worden geplaatst. Hieronder een voorbeeldconfiguratie:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Belangrijke configuratieparameters

- **`project_id`**: Je Crowdin-project-ID. Hiermee wordt het project in Crowdin geïdentificeerd waar vertalingen worden beheerd.
- **`api_token`**: Het API-token dat wordt gebruikt voor authenticatie. Zorg dat dit token de juiste rechten heeft om vertalingen te uploaden en downloaden.
- **`base_path`**: Specificeert de basismap voor bronbestanden. In dit voorbeeld worden vertalingen in de map `./locales` opgeslagen.
- **`base_url`**: De basis-URL voor de Crowdin-API.
- **`preserve_hierarchy`**: Wanneer op `true` gezet, behoudt Crowdin de mapstructuur van je bronbestanden in het project.

### 📂 Bestandsconfiguratie

De `files`-sectie mapt je bronbestanden aan de paden waar vertalingen worden opgeslagen. Bijvoorbeeld:

- **Bronpad**: Definieert de locatie van de oorspronkelijke vertaalbestanden.
- **Vertaalpad**: Geeft aan waar de vertaalde bestanden in Crowdin worden opgeslagen. Placeholders zoals `%two_letters_code%` worden gebruikt om de taalcode dynamisch in de bestandspaden te plaatsen.

## ⬆️ Bronbestanden uploaden naar Crowdin

Zodra je Crowdin-configuratie is ingesteld, kun je je bronbestanden uploaden met deze opdracht:

```bash
crowdin upload sources
```

Deze opdracht uploadt alle bronbestanden die in je configuratie zijn opgegeven naar Crowdin, waardoor ze beschikbaar worden voor vertaling.

## ⬇️ Vertalingen downloaden vanuit Crowdin

Nadat vertalingen in Crowdin zijn voltooid of bijgewerkt, kun je ze naar je project downloaden met:

```bash
crowdin download
```

Deze opdracht haalt de laatste vertalingen uit Crowdin op en slaat ze op volgens de paden in je configuratiebestand.

## ⚙️ Best practices

### 🔑 Consistente naamgeving van sleutels

Zorg dat vertaalsleutels consistent zijn over alle bestanden om verwarring en duplicatie te voorkomen.

### 🧹 Regelmatig onderhoud

Bekijk en ruim periodiek ongebruikte vertaalsleutels op om je bestanden georganiseerd en beheersbaar te houden.

### 🛠 Uploads en downloads automatiseren

Integreer de Crowdin CLI-opdrachten in je CI/CD-pipeline om het uploaden van bronbestanden en het downloaden van vertalingen te automatiseren, zodat je vertalingen altijd up-to-date zijn.

Door deze gids te volgen, kun je Crowdin naadloos in je project integreren en zorg je voor een efficiënte en georganiseerde aanpak voor je internationaliseringsinspanningen.
