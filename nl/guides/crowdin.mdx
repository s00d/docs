# 🌐 Crowdin-integratiegids

## 📖 Inleiding

Het integreren van Crowdin in je project stroomlijnt het lokalisatie- en vertaalproces, waardoor het makkelijker wordt om vertalingen te beheren voor meerdere talen en platforms. Deze gids biedt een stap-voor-stap-handleiding voor het opzetten van Crowdin binnen je project, inclusief configuratie, uploaden van bronbestanden en downloaden van vertalingen.

## 🔧 Installatie en configuratie

Om met Crowdin aan de slag te gaan, installeer je de Crowdin CLI globaal op je machine en initialiseer je deze binnen je projectmap.

### 📦 Crowdin CLI installeren

Installeer eerst de Crowdin CLI globaal via npm:

```bash
npm install -g @crowdin/cli
```

### 🛠 Crowdin initialiseren in je project

Initialiseer Crowdin in je project met:

```bash
crowdin init
```

Deze opdracht begeleidt je door het configuratieproces, inclusief het instellen van je project-ID, API-token en andere configuratiedetails.

## 🗂️ Configuratiegids

### 📄 Crowdin-configuratiebestand (`crowdin.yml`)

Het Crowdin-configuratiebestand (`crowdin.yml`) definieert hoe je bronbestanden worden gemapt en waar vertalingen moeten worden geplaatst. Hieronder een voorbeeldconfiguratie:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Belangrijke configuratieparameters

- **`project_id`**: Je Crowdin-project-ID. Dit identificeert het project binnen Crowdin waar vertalingen worden beheerd.
- **`api_token`**: Het API-token dat wordt gebruikt voor authenticatie. Zorg ervoor dat dit token de juiste rechten heeft om vertalingen te uploaden en te downloaden.
- **`base_path`**: Specificeert de basisdirectory voor bronbestanden. In dit voorbeeld worden vertalingen opgeslagen in de map `./locales`.
- **`base_url`**: De basis-URL voor de Crowdin-API.
- **`preserve_hierarchy`**: Wanneer ingesteld op `true`, behoudt Crowdin de mapstructuur van je bronbestanden in het project.

### 📂 Configuratie van bestanden

De sectie `files` mapt je bronbestanden naar de paden waar vertalingen worden opgeslagen. Bijvoorbeeld:

- **Bronpad**: Definieert de locatie van de originele vertaalbestanden.
- **Vertaalpad**: Specificeert waar de vertaalde bestanden in Crowdin worden opgeslagen. Placeholders zoals `%two_letters_code%` worden gebruikt om de taalcode dynamisch in de bestandspaden in te stellen.

## ⬆️ Bronbestanden uploaden naar Crowdin

Zodra je Crowdin-configuratie is ingesteld, kun je je bronbestanden uploaden met de volgende opdracht:

```bash
crowdin upload sources
```

Deze opdracht uploadt alle opgegeven bronbestanden in je configuratie naar Crowdin, zodat ze beschikbaar zijn voor vertaling.

## ⬇️ Vertalingen downloaden van Crowdin

Nadat vertalingen zijn voltooid of bijgewerkt in Crowdin, kun je ze naar je project downloaden met:

```bash
crowdin download
```

Deze opdracht haalt de laatste vertalingen op uit Crowdin en slaat ze op volgens de paden die in je configuratiebestand zijn opgegeven.

## ⚙️ Best practices

### 🔑 Consistente sleutelbenaming

Zorg ervoor dat vertaalsleutels consistent zijn in alle bestanden om verwarring en duplicatie te voorkomen.

### 🧹 Regelmatig onderhoud

Bekijk en verwijder periodiek ongebruikte vertaalsleutels om je bestanden georganiseerd en beheersbaar te houden.

### 🛠 Automatiseer uploads en downloads

Integreer de Crowdin CLI-opdrachten in je CI/CD-pipeline om het uploaden van bronbestanden en downloaden van vertalingen te automatiseren, zodat je vertalingen altijd up-to-date zijn.

Door deze gids te volgen kun je Crowdin naadloos in je project integreren, waardoor een efficiënte en georganiseerde aanpak van je internationalisatie-inspanningen wordt gewaarborgd.
