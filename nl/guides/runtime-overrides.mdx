# Runtime-i18n-overrides

Gebruik deze gids wanneer je één buildartefact met verschillende locale-standaarden per omgeving wilt draaien (bijvoorbeeld verschillende tenant-instanties).

## Wat tijdens runtime kan worden overschreven

De module ondersteunt veilige runtime-overrides voor:

- `defaultLocale`
- `fallbackLocale`
- `disabledLocales`

Deze overrides worden toegepast bovenop de build-time-configuratie uit `.nuxt/i18n.strategy.mjs` en `.nuxt/i18n.config.mjs`.

## Wat tijdens runtime niet kan worden overschreven

`strategy` (`no_prefix`, `prefix`, `prefix_except_default`, `prefix_and_default`) is een build-time-aangelegenheid, omdat het het gegenereerde routegedrag beïnvloedt.

Als je een runtime-override voor strategie meegeeft, wordt deze genegeerd en wordt er een waarschuwing uitgezonden.

## Overrides via RuntimeConfig

Geef runtime-waarden op onder `runtimeConfig.public.i18nRuntime`:

```ts
export default defineNuxtConfig({
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

## Overrides via omgevingsvariabelen

Je kunt overrides ook configureren via omgevingsvariabelen:

- `NUXT_I18N_DEFAULT_LOCALE`
- `NUXT_I18N_FALLBACK_LOCALE`
- `NUXT_I18N_DISABLED_LOCALES` (kommagescheiden, bijvoorbeeld `fr,it`)

Fallback-aliassen worden ook ondersteund:

- `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES`

## Validatieregels

Tijdens runtime valideert de module overrides om een kapotte staat te voorkomen:

- Je kunt niet alle locales uitschakelen.
- `defaultLocale` moet naar een ingeschakelde locale wijzen.
- `fallbackLocale` moet bestaan in de gedeclareerde locales.

Als een override ongeldig is, behoudt de module een veilige waarde en logt een waarschuwing.

## Opmerkingen voor multi-instantie-deployments

Deze runtime-functie is ontworpen voor per-instantie locale-activering en -standaarden zonder rebuild.

Wanneer instanties verschillende URL-strategieën vereisen (`no_prefix` versus `prefix`), gebruik dan aparte builds voor elke strategie.

## Uitgeschakelde locales en statische payloads

`runtimeConfig.public.i18nRuntime.disabledLocales` werkt de routering, de switcher en de Nitro-payload-**handler** bij, maar Nitro serveert bestanden onder `public/` **vóór** die handler.

Als `translationPayloads.publicAssets` (of de geforceerde publieke kopie van Node-SSR) al `/_locales/\{page\}/\{locale\}/data.json` heeft geschreven, kan een runtime-disable dat bestand niet verbergen. Geef de voorkeur aan `locale.disabled: true` tijdens de build, zodat premerge geen statische payloads voor die locale uitzendt.
