# 🧪 De `Nuxt I18n Micro`-module testen

## 📖 Inleiding tot testen

Het testen van de `Nuxt I18n Micro`-module is cruciaal om ervoor te zorgen dat de lokalisatiefuncties van je applicatie werken zoals verwacht. Deze documentatie leidt je door het opzetten van de testomgeving, het maken van mock-configuraties voor vitest en het schrijven van tests voor je componenten. Voor een praktisch voorbeeld kun je het [voorbeeldproject op GitHub](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/test-utils/example) raadplegen.

Zie [Routingstrategieën testen](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/testing-strategies.md) voor hoe deze repository zijn eigen tests uitvoert — de Vitest-projecten `unit` / `integration` / `e2e`, de bestanden per strategie (`test/strategies-*.test.ts`) en generate-regressies.

## 🛠️ De testomgeving opzetten

### 1. Installeer `@i18n-micro/test-utils`

Installeer eerst de testutilities voor `Nuxt I18n Micro`. Dit pakket biedt de tools die nodig zijn om je i18n-configuraties te mocken en te testen.

```bash
npm install @i18n-micro/test-utils --save-dev
```

### 2. Maak een mock-configuratiebestand

Maak vervolgens een bestand om de mock-i18n-configuratie op te zetten. Dit bestand wordt gebruikt om de i18n-functies en -utilities tijdens je tests te mocken.

```typescript
// tests/unit-setup.ts

import { mockNuxtImport } from '@nuxt/test-utils/runtime'
import { vi } from 'vitest'
import { i18nUtils } from '@i18n-micro/test-utils'

export function createFakeI18n() {
  return {
    $getLocale: vi.fn(i18nUtils.getLocale),
    $t: vi.fn(i18nUtils.t),
    $tc: vi.fn(i18nUtils.tc),
    $setLocale: vi.fn(i18nUtils.setLocale),
    $getLocaleName: vi.fn(i18nUtils.getLocaleName),
    $setLocaleName: vi.fn(i18nUtils.setLocaleName),
    $getLocales: vi.fn(i18nUtils.getLocales),
    $setLocales: vi.fn(i18nUtils.setLocales),
    $defaultLocale: vi.fn(i18nUtils.defaultLocale),
    $setDefaultLocale: vi.fn(i18nUtils.setDefaultLocale),
    $getRouteName: vi.fn(i18nUtils.getRouteName),
    $settRouteName: vi.fn(i18nUtils.settRouteName),
    $ts: vi.fn(i18nUtils.ts),
    $tn: vi.fn(i18nUtils.tn),
    $td: vi.fn(i18nUtils.td),
    $has: vi.fn(i18nUtils.has),
    $resolveTranslations: vi.fn(i18nUtils.resolveTranslations),
    $setTranslation: vi.fn(i18nUtils.setTranslation),
    $mergeTranslations: vi.fn(i18nUtils.mergeTranslations),
    $switchLocaleRoute: vi.fn(i18nUtils.switchLocaleRoute),
    $switchLocalePath: vi.fn(i18nUtils.switchLocalePath),
    $switchLocale: vi.fn(i18nUtils.switchLocale),
    $switchRoute: vi.fn(i18nUtils.switchRoute),
    $localeRoute: vi.fn(i18nUtils.localeRoute),
    $localePath: vi.fn(i18nUtils.localePath),
    $setI18nRouteParams: vi.fn(i18nUtils.setI18nRouteParams),
  }
}

mockNuxtImport<() => ReturnType<typeof createFakeI18n>>('useI18n', () => vi.fn(() => createFakeI18n()))

export const setTranslationsFromJson = i18nUtils.setTranslationsFromJson
```

### 3. Configureer Vitest

Configureer nu Vitest om het mock-configuratiebestand te gebruiken en de testomgeving op te zetten.

```typescript
// vitest.config.ts

import { defineVitestConfig } from '@nuxt/test-utils/config'

export default defineVitestConfig({
  test: {
    watch: false,
    setupFiles: ['./tests/unit-setup.ts'],
    include: ['./**/*.spec.ts'],
  },
})
```

## 🧪 Tests schrijven

### Voorbeeldcomponent

Hier is een voorbeeld van een eenvoudig component dat de `useI18n`-composable gebruikt om berichten te vertalen.

```vue
<script setup lang="ts">
const { $t } = useI18n()

const props = defineProps({
  message: {
    type: String,
    default: null,
  },
})

// Test to see that $t works in script setup as well as the template
const message = props.message || $t('defaultMessage')
</script>

<template>
  <div>
    <p>Test from component: {{ $t('welcome') }}</p>
    <p data-testid="message">Test message from props: {{ message }}</p>
  </div>
</template>
```

### Testbestand

Laten we nu een test voor dit component schrijven.

```typescript
// tests/unit/example.spec.ts

import { describe, it, expect, beforeEach } from 'vitest'
import { mount } from '@vue/test-utils'
import ExampleComponent from '@/components/ExampleComponent.vue'
import fs from 'fs'
import path from 'path'
import { setTranslationsFromJson } from './unit-setup'

describe('ExampleComponent', () => {
  beforeEach(async () => {
    const fileContent = fs.readFileSync(path.join(__dirname, '../../locales/en-GB.json')).toString()
    await setTranslationsFromJson('en', JSON.parse(fileContent))
  })

  it('renders the welcome message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.text()).toContain('Test from component: Welcome')
  })

  it('renders the default message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Default Message')
  })

  it('renders the custom message correctly', () => {
    const wrapper = mount(ExampleComponent, {
      props: {
        message: 'Custom Message',
      },
    })
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Custom Message')
  })
})
```

## 📝 Best practices voor testen

- **🔧 Mock i18n-functies:** Mock i18n-functies altijd met `@i18n-micro/test-utils` om consistente en voorspelbare testresultaten te garanderen.
- **⚙️ Gebruik Vitest voor unit tests:** Vitest is een krachtig testframework voor Vue-applicaties. Gebruik het om unit tests voor je componenten te schrijven.
- **📚 Documenteer je tests:** Documenteer duidelijk het doel en de verwachte uitkomsten van elke test. Dit helpt bij het behouden van duidelijkheid en maakt het voor anderen (of jezelf in de toekomst) makkelijker om de tests te begrijpen.

## 📊 i18n-hulpprogrammamethodes

Hieronder staat een tabel met alle hulpprogrammamethodes van `@i18n-micro/test-utils`.

| Methode                                          | Beschrijving                                                                                                                                |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `t(key, params, defaultValue)`                  | Vertaalt een sleutel met optionele parameters en een standaardwaarde.                                                                             |
| `tc(key, params, defaultValue)`                 | Vertaalt een sleutel met ondersteuning voor pluralisatie.                                                                                               |
| `setTranslationsFromJson(locale, translations)` | Laadt vertalingen uit een JSON-object voor een specifieke locale.                                                                               |
| `getLocale()`                                   | Retourneert de huidige locale.                                                                                                                |
| `setLocale(val)`                                | Stelt de huidige locale in.                                                                                                                   |
| `getLocaleName()`                               | Retourneert de huidige localenaam.                                                                                                           |
| `setLocaleName(val)`                            | Stelt de huidige localenaam in.                                                                                                              |
| `getLocales()`                                  | Retourneert de lijst met beschikbare locales.                                                                                                     |
| `setLocales(val)`                               | Stelt de lijst met beschikbare locales in.                                                                                                        |
| `defaultLocale()`                               | Retourneert de standaardlocale.                                                                                                                |
| `setDefaultLocale(val)`                         | Stelt de standaardlocale in.                                                                                                                   |
| `getRouteName()`                                | Retourneert de huidige routenaam.                                                                                                            |
| `settRouteName(val)`                            | Stelt de huidige routenaam in.                                                                                                               |
| `ts(key, params, defaultValue)`                 | Vertaalt een sleutel en retourneert het resultaat als string.                                                                                       |
| `tn(value, options?)`                           | Formatteert een getal met inline `Intl.NumberFormatOptions`. Benoemde formaten vereisen moduleconfiguratie en zijn niet beschikbaar in deze standalone helper. |
| `td(value, options?)`                           | Formatteert een datum met inline `Intl.DateTimeFormatOptions`. Benoemde formaten vereisen moduleconfiguratie en zijn niet beschikbaar in deze standalone helper. |
| `has(key)`                                      | Controleert of een vertaalsleutel bestaat.                                                                                                        |
| `resolveTranslations()`                             | Retourneert de actieve vertaalboom voor de huidige locale en route.                                                                      |
| `setTranslation(key, value)`                    | Vervangt de waarde bij `key` in het actieve woordenboek (vervangen, niet samenvoegen).                                                                 |
| `mergeTranslations(newTranslations)`              | Voegt vertalingen samen in de actieve locale tijdens runtime.                                                                                     |

Door deze stappen te volgen, kun je de `Nuxt I18n Micro`-module effectief testen en ervoor zorgen dat de lokalisatiefuncties van je applicatie werken zoals verwacht.
