# Vertalingen gebruiken in componenten

Zodra de module is geïnstalleerd en geconfigureerd, kun je vertalingen tonen door `$t('your_key')` aan te roepen binnen je Vue-templates en -scripts.

## 1. Root- en paginaspecifieke vertaalbestanden

1. **Root-vertalingen** staan direct onder de map `/locales` (bijvoorbeeld `/locales/en.json`, `/locales/fr.json`). Tijdens de build worden ze automatisch samengevoegd met elk paginaspecifiek bestand, zodat ze op alle pagina's beschikbaar zijn.
2. **Paginaspecifieke vertalingen** staan onder `/locales/pages/...`, overeenkomstig de mapstructuur van je Nuxt-pagina's:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. Templategebruik met `$t`

In je `.vue`-bestanden kun je `$t` direct in de template gebruiken:

```vue
<template>
  <div>
    <!-- Root-vertaling (op alle pagina's beschikbaar) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Toont: Hello World! -->

    <!-- Paginaspecifieke vertaling (wanneer deze pagina /dir1 is) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Toont: This is a page-specific translation for /dir1. -->

    <!-- Geneste sleutel -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Toont: Nested translation here -->

    <!-- Placeholder-gebruik -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Toont: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// Je hoeft niets te importeren uit 'nuxt-i18n-micro'.
// De plugin biedt `useI18n` en `$t` automatisch aan.
const { $t } = useI18n()

// Je kunt $t nu in je script gebruiken, bijvoorbeeld:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
`$t` kan **objecten** retourneren als de sleutel naar een geneste JSON-node wijst (bijvoorbeeld `$t('header')` → `\{ title: "Hi" \}`). In templates rendert dit als `[object Object]`. Gebruik `$ts` wanneer je een gegarandeerde string nodig hebt, of geef een specifiekere sleutel zoals `$t('header.title')`. Zie [API-referentie — $t vs $ts](/api/methods#t) voor details.
</Tip>

## 3. De huidige locale wisselen

Om van taal te wisselen in je app haal je `$locale` uit `useI18n()` en wijs je er een nieuwe code aan toe:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// De plugin injecteert deze referenties automatisch
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. Geneste sleutels en placeholders

- **Geneste sleutels** gebruiken dot-notatie, bijvoorbeeld `nested.key.deeper`.
- **Placeholders** maken het invoegen van dynamische waarden mogelijk:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Toont: Hello, Alice! -->
  ```

## 5. Tips en best practices

- **Conflicterende sleutels**: Als een paginaspecifiek bestand dezelfde sleutel bevat als een root-bestand, wint de paginaspecifieke versie (root-vertalingen worden tijdens de build als basis samengevoegd).
- **Pagina-bestanden uitschakelen**: Als je liever geen paginaspecifieke vertalingen gebruikt, stel je `disablePageLocales: true` in je Nuxt-configuratie in. Dan worden alleen de `/locales/*.json`-bestanden gebruikt.
- **Geen directe imports**: Je hoeft geen `import \{ useI18n \} from 'nuxt-i18n-micro'` te doen; de auto-injectiefunctie van de module regelt dit voor je.

Dat is alles! Met deze stappen kun je snel **vertalingen ophalen** uit root- of paginaspecifieke JSON-bestanden en ze **tonen** in je Nuxt-applicatie via `$t`.

## Aanvullende bronnen

Voor het verkennen van meer geavanceerde functies, bekijk vooral:

1. **`<i18n-t>`-component**  
   De `<i18n-t>`-component is een krachtig alternatief voor `$t`, vooral nuttig bij geneste elementen, geavanceerd placeholder-gebruik en complexere vertaalstructuren.

- **Documentatie**: [i18n-t](/api/components/i18n-t)

2. **`useI18n`-composable**  
   De `useI18n`-composable biedt een complete set functies en reactieve eigenschappen voor het beheren van vertalingen, het wisselen van locale, formatteren en meer.

- **Documentatie**: [useI18n](/api/composables/use-i18n)
