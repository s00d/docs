# Vertalingen gebruiken in componenten

Zodra de module is geïnstalleerd en geconfigureerd, kun je vertalingen weergeven door `$t('your_key')` aan te roepen binnen je Vue-templates en -scripts.

## 1. Vertaalbestanden op rootniveau en pagina-specifiek

1. **Root-level**-vertalingen staan direct in de `/locales`-map (bijv. `/locales/en.json`, `/locales/fr.json`). Bij het builden worden ze automatisch samengevoegd in elk pagina-specifiek bestand, zodat ze op alle pagina's beschikbaar zijn.
2. **Pagina-specifieke** vertalingen staan onder `/locales/pages/...` en volgen de structuur van je Nuxt-pages-map:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. Gebruik in templates met `$t`

In je `.vue`-bestanden kun je `$t` direct in de template gebruiken:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
`$t` kan **objecten** retourneren als de sleutel naar een geneste JSON-node verwijst (bijv. `$t('header')` → `\{ title: "Hi" \}`). In templates wordt dit weergegeven als `[object Object]`. Gebruik `$ts` als je een gegarandeerde string nodig hebt, of geef een specifiekere sleutel op zoals `$t('header.title')`. Zie [API-referentie — $t vs $ts](/api/methods#t) voor details.
</Tip>

## 3. De huidige locale wisselen

Om talen in je app te wijzigen, kun je `$locale` uit `useI18n()` ophalen en er een nieuwe code aan toewijzen:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. Geneste sleutels en placeholders

- **Geneste sleutels** gebruiken puntnotatie, bijv. `nested.key.deeper`.
- **Placeholders** stellen je in staat dynamische waarden in te voegen:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. Tips en best practices

- **Conflicterende sleutels**: Als een pagina-specifiek bestand dezelfde sleutel bevat als een root-level bestand, heeft de pagina-specifieke versie voorrang (root-vertalingen worden bij het builden als basis samengevoegd).
- **Paginabestanden uitschakelen**: Als je liever geen pagina-specifieke vertalingen gebruikt, kun je `disablePageLocales: true` in je Nuxt-config zetten. Dan worden alleen de `/locales/*.json`-bestanden gebruikt.
- **Geen directe imports**: Je hoeft geen `import \{ useI18n \} from 'nuxt-i18n-micro'` uit te voeren; de auto-injectiefunctie van de module regelt dit voor je.

Dat is het! Met deze stappen kun je snel **vertalingen ophalen** uit root-level of pagina-specifieke JSON-bestanden en ze in je Nuxt-applicatie **weergeven** met `$t`.

## Aanvullende bronnen

Om meer geavanceerde functies te verkennen, bekijk zeker:

1. **`<i18n-t>`-component**  
   Het `<i18n-t>`-component is een krachtig alternatief voor `$t`, vooral handig in situaties met geneste elementen, geavanceerd placeholder-gebruik en complexere vertaalstructuren.

- **Documentatie**: [i18n-t](/api/components/i18n-t)

2. **`useI18n`-composable**  
   De `useI18n`-composable biedt een complete set functies en reactieve eigenschappen voor het beheren van vertalingen, localewisseling, opmaak en meer.

- **Documentatie**: [useI18n](/api/composables/use-i18n)
