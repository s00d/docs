# 🔄 Migreren van `nuxt-i18n` naar `Nuxt I18n Micro`

## Welke gids heb je nodig?

| Je migreert van…                | Gids                                            |
| -------------------------------------- | ------------------------------------------------ |
| `@nuxtjs/i18n` (vue-i18n-gebaseerde module) | **Deze pagina**                                    |
| `nuxt-i18n-micro` v2.x                 | [Upgrading van v2.x naar v3.x](/migration/v2-to-v3) |

## Waarom migreren?

- **Verbeterde prestaties**: ~51% snellere builds en ~54% minder buildgeheugen vs. `@nuxtjs/i18n` **v10.6** in onze [benchmark-fixtures](/guides/performance-results)
- **Vereenvoudigde configuratie**: Gestroomlijnde setup met verstandige standaardwaarden
- **Beter resourcebeheer**: Geoptimaliseerde afhandeling van grote vertaalbestanden

## Belangrijkste verschillen

| Feature                 | `nuxt-i18n`                      | `Nuxt I18n Micro`                         |
| ----------------------- | -------------------------------- | ----------------------------------------- |
| Vertaalbestanden       | JS/TS/JSON, geladen via `vueI18n` | Alleen JSON, automatisch gegenereerd in dev          |
| Routegeneratie        | Runtime                          | Build-time (`@i18n-micro/route-strategy`) |
| Vertaling laden     | Gebundeld in JS                  | Lazy-loaded JSON per pagina                 |
| Locale-state            | `useI18n()` van `vue-i18n`      | `useI18nLocale()`-composable              |
| `detectBrowserLanguage` | Ondersteund                        | Gebruik in plaats daarvan `autoDetectLanguage`          |

## Stap-voor-stap

### 1. Installeer

```bash
npm install nuxt-i18n-micro
```

### 2. Update de configuratie

**Voor (nuxt-i18n):**

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'fr', iso: 'fr-FR' },
    ],
    defaultLocale: 'en',
    vueI18n: './i18n.config.js',
    detectBrowserLanguage: { useCookie: true },
  },
})
```

**Na (Nuxt I18n Micro v3):**

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
    localeCookie: 'user-locale',
    autoDetectLanguage: true,
  },
})
```

### 3. Reorganiseer vertaalbestanden

Verplaats vertalingen naar de map `locales` in JSON-formaat. Hier is een volledige projectvergelijking:

**Before (`nuxt-i18n`):**

```text
my-app/
├── i18n/
│   └── locales/          # langDir
│       ├── en.json       # all translations in one file
│       ├── ru.json
│       └── de.json
├── pages/
│   ├── index.vue
│   └── page.vue
├── server/
│   └── tsconfig.json
├── nuxt.config.ts        # config will change
└── package.json
```

**After (Nuxt I18n Micro):**

```text
my-app/
├── locales/              # translationDir
│   ├── en.json           # root-level translations
│   ├── ru.json
│   ├── de.json
│   └── pages/            # page-specific
│       ├── index/
│       │   ├── en.json
│       │   ├── ru.json
│       │   └── de.json
│       └── page/
│           ├── en.json
│           ├── ru.json
│           └── de.json
├── pages/
│   ├── index.vue         # API changes
│   └── page.vue
├── server/
│   └── tsconfig.json
├── nuxt.config.ts        # new config
└── package.json
```

<Tip>
Missing page-specific translation files are **auto-generated** in development mode — just run `nuxt dev` and the module will create empty JSON files for each page and locale.
</Tip>

### 4. Update navigatie

```diff
- <nuxt-link :to="{ name: 'index' }">Home</nuxt-link>
+ <NuxtLink :to="$localeRoute({ name: 'index' })">Home</NuxtLink>
+ <!-- or use the built-in component -->
+ <i18n-link :to="{ name: 'index' }">Home</i18n-link>
```

### 5. Update SEO

Verwijder eventuele handmatige SEO-configuraties van `nuxt-i18n`. Nuxt I18n Micro genereert `hreflang`, canonieke URL's en Open Graph-tags automatisch wanneer `meta: true` is ingesteld.

### 6. Test

Test grondig vertalingen, localewisseling, redirects en SEO-metatags.

## 🛡️ Veelvoorkomende problemen en troubleshooting

### ❌ Vertaalbestanden laden niet

Zorg ervoor dat vertaalbestanden in de juiste map staan en het JSON-formaat volgen. Verifieer dat `translationDir` overeenkomt met je bestandslocatie.

### ⚠️ Fouten "route niet gevonden"

Controleer of alle localecodes in de `locales`-array correct zijn en of routes juist zijn opgezet.

### 🏷️ Ontbrekende SEO-tags

Verifieer dat `meta: true` is ingesteld en dat elke locale een geldige `iso`-code heeft.

### 🔄 Hydratie-mismatches

Als je de `no_prefix`-strategie gebruikt, stel de locale in via een serverplugin met `order: -10` en `useI18nLocale().setLocale()` om ervoor te zorgen dat server en client het eens zijn over de locale. Zie [Aangepaste taaldetectie](/guides/custom-language-detection).

### 🍪 Redirects werken niet

Zorg bij prefix-strategieën dat `localeCookie: 'user-locale'` is ingesteld. Zonder cookie heeft de server-redirectplugin geen manier om de voorkeurslocale van de gebruiker te onthouden over paginalaadbeurten heen.
