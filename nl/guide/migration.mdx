Deze pagina zet een `@nuxtjs/i18n`-app om naar nuxt-i18n-micro: opties, helpers en bestandsindeling. Gebruik haar wanneer je de module in een bestaande app vervangt. Je behoudt je URL's (de strategienamen zijn hetzelfde) en verplaatst vertalingen naar JSON-bestanden per pagina.

<Tip>

**Upgrade je nuxt-i18n-micro zelf?** — Zie [Upgraden](/nl/guide/upgrade).

</Tip>

## De module vervangen {#swap-the-module}

```bash
npm uninstall @nuxtjs/i18n
npm install nuxt-i18n-micro
```

```ts
// nuxt.config.ts — before
export default defineNuxtConfig({
  modules: ['@nuxtjs/i18n'],
  i18n: {
    locales: [
      { code: 'en', language: 'en-US', file: 'en.json' },
      { code: 'de', language: 'de-DE', file: 'de.json' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    langDir: 'locales',
    detectBrowserLanguage: { useCookie: true, cookieKey: 'i18n_redirected', redirectOn: 'root' },
  },
})
```

```ts
// nuxt.config.ts — after
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    translationDir: 'locales',
    localeCookie: 'i18n_redirected',
    autoDetectPath: '/',
  },
})
```

## Opties {#options}

| `@nuxtjs/i18n` | nuxt-i18n-micro |
| --- | --- |
| `locales[].code` | `locales[].code` |
| `locales[].language` (`iso` vóór v9) | `locales[].iso` |
| `locales[].name` | `locales[].displayName` |
| `locales[].dir` | `locales[].dir` |
| `locales[].domain` | `locales[].baseUrl` (een origin met schema) |
| `locales[].domainDefault` | `locales[].baseDefault` |
| `differentDomains`, `multiDomainLocales` | niet nodig: `baseUrl` alleen routeert al op host, zie [Layers en domeinen](/nl/guide/layers#multiple-domains) |
| `locales[].file` / `files`, `langDir`, `lazy` | `translationDir`; bestanden worden op naam gevonden en altijd per pagina geladen |
| `defaultLocale`, `strategy` | dezelfde namen, dezelfde vier waarden |
| `baseUrl` | `metaBaseUrl` |
| `customRoutes: 'config'` + `pages` | `globalLocaleRoutes` |
| `detectBrowserLanguage: false` | `redirects: false` (geen redirects) of `autoDetectLanguage: false` (de header negeren) |
| `detectBrowserLanguage.useCookie` / `cookieKey` | `localeCookie: '<name>'` (`null` zet de cookie uit) |
| `detectBrowserLanguage.redirectOn: 'root'` | `autoDetectPath: '/'` (standaard) |
| `detectBrowserLanguage.redirectOn: 'no prefix'` | `autoDetectPath: 'no_prefix'` |
| `detectBrowserLanguage.redirectOn: 'all'` | `autoDetectPath: '*'` |
| `vueI18n`-configbestand (`fallbackLocale`, `numberFormats`, `datetimeFormats`) | `fallbackLocale`, `numberFormats`, `datetimeFormats` in `i18n` |

Er is geen `alwaysRedirect`: met een gezette cookie volgt `/` die bij elk bezoek. De volledige lijst staat in [Module-opties](/nl/api/module-options); detectieregels staan op [Locale-detectie](/nl/guide/locale-detection).

## Helpers en composables {#helpers-and-composables}

| `@nuxtjs/i18n` / vue-i18n | nuxt-i18n-micro (template / `useI18n()`) |
| --- | --- |
| `const { t } = useI18n()` | `const { t } = useI18n()`, `$t` in templates |
| `t('key', count)`, `tc` | `$tc('key', count)` |
| `te('key')` | `$has('key')` |
| `n(value, 'currency')`, `d(date, 'short')` | `$tn(value, 'currency')`, `$td(date, 'short')` |
| — | `$tdr(date)`: relatieve tijd ("in 3 days") |
| `locale.value` | `$getLocale()` |
| `locales.value` | `$getLocales()` |
| `setLocale('de')` | `$switchLocale('de')` |
| `useLocalePath()('about')` | `$localePath({ name: 'about' })` |
| `useLocaleRoute()` | `$localeRoute()` |
| `useSwitchLocalePath()('de')` | `$switchLocalePath('de')` |
| `useSetI18nParams()` | `$setI18nRouteParams()` |
| `useLocaleHead()` | automatisch met `meta: true`; [`useLocaleHead`](/nl/composables/useLocaleHead) voor aangepaste heads |
| `defineI18nRoute({ paths: { de: '/ueber-uns' }, locales: [...] })` | `$defineI18nRoute({ localeRoutes: { de: '/ueber-uns' }, locales: [...] })` |
| `<NuxtLinkLocale to="about">` | `<i18n-link :to="{ name: 'about' }">` |
| `<i18n-t>` | `<i18n-t>` (slots vullen `{name}`-placeholders) |
| `$i18n` in serverroutes | `useTranslationServerMiddleware(event)`, zie [Serverroutes en API](/nl/guide/server-side-translations) |

`useI18n()` wordt automatisch geïmporteerd. `$defineI18nRoute` moet zijn `$` behouden: de build leest die aanroep. Alle helpers: [Methoden](/nl/api/methods).

## Vertaalbestanden {#translation-files}

Verplaats de sleutels van één groot bestand per locale naar een rootbestand plus één bestand per pagina:

```text
locales/
├── en.json              # keys used on many pages (nav, footer)
├── de.json
└── pages/
    ├── index/en.json    # keys of pages/index.vue
    └── about/en.json    # keys of pages/about.vue
```

Alles in de rootbestanden houden werkt ook, en is de snelste eerste stap. Zet `disablePageLocales: true` tot je ze opsplitst. Zie [Vertaalbestanden](/nl/guide/translations).

### Berichtsyntaxis {#message-syntax}

| vue-i18n | nuxt-i18n-micro |
| --- | --- |
| `{name}` benoemde interpolatie | hetzelfde |
| `car \| cars` (2 vormen: 1 → eerste) | vormen worden op count gekozen vanaf 0: schrijf `no cars \| one car \| {count} cars` |
| `@:other.key` linked messages | niet ondersteund: herhaal de tekst of stel samen in code |
| `@.upper:`-modifiers | niet ondersteund: formatteer in code of gebruik `<i18n-t>` |
| `{'@'}` letterlijke escapes | niet nodig: alleen `{word}`-tokens worden vervangen |
| JS/TS-berichtbestanden | alleen JSON |

De meervoudsregel is vervangbaar met de optie [`plural`](/nl/api/module-options#plural).

## Controleren na de overstap {#check-after-the-switch}

- Elke URL die je had, lost nog steeds op; de strategienamen komen overeen, aangepaste paden verhuizen naar `globalLocaleRoutes` of `$defineI18nRoute`.
- `hreflang`, canonical en `og:locale` werken direct met `meta: true`; verwijder handgeschreven exemplaren.
- Een JSON-parsefout logt het bestandspad; een ontbrekende sleutel logt in dev een waarschuwing in de browserconsole.
