Deze pagina brengt een Nuxt-app van geen i18n naar een vertaalde pagina met een taalwisselaar. Je hebt dit één keer nodig, aan het begin van een project. Je eindigt met gelokaliseerde URL's (`/about`, `/de/about`), één JSON-bestand per locale en pagina, en `$t` in je templates.

## Installeren {#install}

De module vereist Nuxt 3.18 of nieuwer (Nuxt 4 werkt ook) en Node 20 of nieuwer.

<CodeGroup>

```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>

## De locales configureren {#configure-the-locales}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', displayName: 'English' },
      { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
      { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
    ],
    defaultLocale: 'en',
  },
})
```

Dat is alle configuratie die een eerste app nodig heeft. De standaardwaarden geven je:

- `strategy: 'prefix_except_default'`: de standaardlocale heeft geen prefix (`/about`), de andere wel (`/de/about`). Zie [Routeringsstrategieën](/nl/guide/strategy).
- `translationDir: 'locales'`: vertaalbestanden staan in `locales/` in de projectroot, ook met de `app/`-indeling van Nuxt 4.
- `meta: true`: `hreflang`-, canonical- en `og:locale`-tags, plus `lang` en `dir` op `<html>`. Zie [SEO](/nl/guide/seo).
- Een bezoeker die `/` opent, wordt doorgestuurd naar de taal waar zijn browser om vraagt (`Accept-Language`). Zie [Localedetectie](/nl/guide/locale-detection).

`iso` is de taaltag die in SEO-tags wordt gebruikt; `code` is wat in de URL verschijnt. Elke optie staat in [Module-opties](/nl/api/module-options).

## Vertaalbestanden toevoegen {#add-translation-files}

Start de dev-server met `nuxt dev`. Wanneer Nuxt de pagina's oplost, maakt de module een leeg `{}`-bestand aan voor elke locale en pagina die er nog geen heeft (schakel dit uit met [`disableWatcher`](/nl/api/module-options#disablewatcher)):

```text
locales/
├── en.json            # root: keys every page can use
├── de.json
├── fr.json
└── pages/
    ├── index/         # pages/index.vue
    │   ├── en.json
    │   ├── de.json
    │   └── fr.json
    └── about/         # pages/about.vue
        ├── en.json
        ├── de.json
        └── fr.json
```

Vul het rootbestand en een paginabestand in:

```json
// locales/en.json
{ "nav": { "home": "Home", "about": "About" } }
```

```json
// locales/pages/index/en.json
{ "welcome": "Welcome, {name}!", "items": "no items | one item | {count} items" }
```

Een pagina ziet de rootsleutels en haar eigen sleutels; bij een conflict wint haar eigen bestand. Mapnamen volgen de routenaam (`pages/articles/[id].vue` is `locales/pages/articles-id/`). [Vertaalbestanden](/nl/guide/translations) behandelt de indeling, fallbacks en het laden.

## `$t` gebruiken op een pagina {#use-$t-on-a-page}

```vue
<!-- pages/index.vue -->
<script setup lang="ts">
const { t, tc, getLocale } = useI18n()

const title = t('nav.home') // 'Home'
</script>

<template>
  <h1>{{ $t('welcome', { name: 'Ada' }) }}</h1>
  <!-- Welcome, Ada! -->
  <p>{{ $tc('items', 3) }}</p>
  <!-- 3 items -->
  <p>{{ getLocale() }}</p>
  <!-- en -->
</template>
```

- In templates is elke helper beschikbaar met een `$` (`$t`, `$tc`, `$localePath`, …).
- In `<script setup>` geeft `useI18n()` dezelfde helpers terug, met en zonder de `$` (`t` en `$t` zijn één functie). Het wordt automatisch geïmporteerd.
- `{name}`-placeholders worden gevuld vanuit het params-object. Meervoudsvormen worden gescheiden door `|`; de telling kiest de vorm (0, 1, en daarna de laatste voor alles daarboven).

Alle helpers staan in [Methoden](/nl/api/methods).

## Linken tussen pagina's en van locale wisselen {#link-between-pages-and-switch-locale}

```vue
<!-- components/AppHeader.vue -->
<template>
  <nav>
    <i18n-link :to="{ name: 'index' }">{{ $t('nav.home') }}</i18n-link>
    <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
    <i18n-switcher />
  </nav>
</template>
```

- [`<i18n-link>`](/nl/components/i18n-link) is een `NuxtLink` die naar de pagina in de huidige locale wijst: op `/de` gaat de about-link naar `/de/about`.
- [`<i18n-switcher>`](/nl/components/i18n-switcher) is een dropdown met de ingeschakelde locales; de bezoeker blijft op dezelfde pagina.
- Roep voor je eigen knoppen `$switchLocale('de')` aan, dat naar de huidige pagina in het Duits navigeert en de keuze onthoudt. Gebruik voor een gewone `NuxtLink` `$localePath({ name: 'about' })` of `$switchLocalePath('de')`.

## Controleren {#check-it}

Draai `nuxt dev` en open:

| URL | Toont |
| --- | --- |
| `/` | Engelse homepage (of een redirect naar `/de` wanneer je browser de voorkeur geeft aan Duits) |
| `/de` | Duitse homepage |
| `/de/about` | Duitse about-pagina |
| `/en/about` | 404: de standaardlocale heeft geen prefix onder `prefix_except_default` |

Wijzigingen in de JSON-bestanden worden toegepast in de geopende pagina zonder herladen.
