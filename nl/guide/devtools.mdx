In `nuxt dev` voegt de module twee hulpmiddelen voor debugging toe: een tabblad **i18n Micro** in Nuxt DevTools om vertaalbestanden te bekijken en te bewerken, en een Vue DevTools-inspector voor de live locale en de geladen woordenboeken. Beide bestaan alleen in development en voegen niets toe aan productiebuilds. Het Nuxt-tabblad heeft alleen ingeschakelde Nuxt DevTools nodig; de Vue-inspector heeft ook de Vue DevTools-browserextensie nodig.

## Nuxt DevTools-tabblad {#nuxt-devtools-tab}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  devtools: { enabled: true }, // the tab is registered only when DevTools are on
})
```

Open Nuxt DevTools (`Shift + Alt + D`) en kies **i18n Micro**. Het tabblad toont:

- elk JSON-bestand onder `locales/` (root en `pages/`) van elke laag, plus rootbestanden uit `additionalTranslationDirs`;
- een editor per bestand; **Save** schrijft het bestand terug naar schijf, en de dev-server herlaadt de vertalingen;
- **Export** / **Import** van een bestand als JSON, en **Stats** met aantallen sleutels en vertaaldekking;
- een configuratieweergave van de opgeloste moduleopties;
- **Translate**, dat ontbrekende sleutels invult met een machinevertaalengine die je in de instellingen van het tabblad configureert.

Opslaan schrijft alleen bestaande `.json`-bestanden binnen je vertaalmappen. Wanneer een bestand in meerdere lagen bestaat, wordt de kopie van het project geschreven.

## Vue DevTools-inspector {#vue-devtools-inspector}

Met de Vue DevTools-browserextensie registreert de module een i18n-inspector (huidige locale, route-chunk, geladen sleutels) en een tijdlijn met locale-wissels, geladen chunks en ontbrekende sleutels.

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    debug: true, // also log every $t / $ts / $tc call on the timeline
    // vueDevtools: false, // turn the inspector off, keep the Nuxt tab
  },
})
```

[`vueDevtools`](/nl/api/module-options) is standaard `true`. `debug: true` is uitgebreid; gebruik het alleen voor korte sessies.

## Buiten Nuxt {#outside-nuxt}

Dezelfde UI is gepubliceerd als [`@i18n-micro/devtools-ui`](/nl/integrations/devtools-ui-package) voor Vite-apps die op de framework-packages zijn gebouwd; zie die pagina voor de setup.
