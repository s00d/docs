[Crowdin](https://crowdin.com/) is een vertaalplatform: je uploadt de bestanden van de standaardlocale, vertalers werken in Crowdin en je downloadt de andere locales weer terug. De module leest gewone JSON-bestanden, dus de Crowdin CLI heeft alleen een `crowdin.yml` nodig die `locales/` en `locales/pages/` correct toewijst. Er hoeven geen module-instellingen te veranderen.

## crowdin.yml configureren {#configure-crowdin-yml}

```yml
# crowdin.yml
project_id_env: CROWDIN_PROJECT_ID
api_token_env: CROWDIN_PERSONAL_TOKEN
base_path: ./locales
preserve_hierarchy: true

files:
  - source: /en.json
    translation: /%two_letters_code%.json
  - source: /pages/**/en.json
    translation: /pages/**/%two_letters_code%.json
```

- `en` is je standaardlocale; de bestanden daarvan zijn de bronnen.
- `project_id_env` / `api_token_env` lezen het ID en het token uit omgevingsvariabelen, zodat er geen geheim wordt gecommit.
- `preserve_hierarchy: true` laat de mappen `pages/<page>/` intact.
- De naam van het vertaalde bestand moet gelijk zijn aan de locale-`code` in `nuxt.config.ts`. `%two_letters_code%` past bij codes zoals `de`; gebruik voor codes zoals `pt-BR` `%locale%`, of koppel de codes van Crowdin aan de jouwe met `languages_mapping`.

## Uploaden en downloaden {#upload-and-download}

```bash
npm install -g @crowdin/cli

export CROWDIN_PROJECT_ID=123456
export CROWDIN_PERSONAL_TOKEN=...   # from Crowdin account settings

crowdin upload sources   # push locales/en.json and locales/pages/**/en.json
crowdin download         # write locales/de.json, locales/pages/**/de.json, ...
```

Voer beide uit in CI om de bestanden actueel te houden. Gedownloade bestanden komen in je repository terecht zoals handmatig bewerkte bestanden; de volgende build of dev-reload pikt ze op.

## Voor het uploaden {#before-uploading}

Ruim eerst de bronnen op, zodat vertalers niet aan dode sleutels werken: [`i18n-micro clean`](/nl/api/cli#clean) verwijdert ongebruikte sleutels, [`i18n-micro check`](/nl/api/cli#check) meldt ontbrekende vertalingen na een download. De CLI heeft zelf geen Crowdin-integratie: deze pagina beschrijft de ondersteunde werkwijze.
