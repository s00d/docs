**Datum**: 2025-10-30

**Versie**: `v2.0.0`

![v2.0.0-release](/images/2.0.0.png)

We introduceren server-side HMR voor vertaalbestanden in development. Wanneer een JSON-vertaling verandert, invalideert de servercache alleen de betrokken sleutels, en volgende requests krijgen meteen verse data—zonder herstarts.

## Wat is er nieuw? {#what’s-new}

- Server-side HMR voor vertaalbestanden
- Directe cache-invalidatie per pagina/locale
- Naadloze DX tijdens het bewerken van content

## Hoe het werkt {#how-it-works}

- Een watcher in `src/runtime/server/plugins/watcher.dev.ts` observeert `<rootDir>/<translationDir>/**/*.json`
- Paginabestanden (bijv. `pages/<page>/<locale>.json`) invalideren `_locales:merged:<page>:<locale>`
- Bestanden op rootniveau (bijv. `<locale>.json`) invalideren alle samengevoegde sleutels voor die locale
- Automatisch geregistreerd vanuit `src/module.ts` in dev wanneer `experimental.hmr !== false`

## Configuratie {#configuration}

```ts
export default defineNuxtConfig({
  i18n: {
    experimental: { hmr: true }, // default in dev
  },
})
```
