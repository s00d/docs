**Datum**: 2026-06-25

**Versie**: `v3.21.0`

![v3.21.0 release](/images/3.21.0.png)

Deze release voegt **`useI18nHead`** toe — een composable op paginaniveau voor i18n-SEO-overrides bovenop de ingebouwde `02.meta`-plugin. Pas `hreflang`, canonical, `og:url` en Open Graph-tags per route aan zonder een eigen meta-plugin of `meta: false`.

## Wat is er nieuw? {#what’s-new}

### `useI18nHead`-composable {#usei18nhead-composable}

Roep `useI18nHead` aan in een willekeurige pagina wanneer `meta: true` (standaard) is. De module voegt je invoer samen na `useLocaleHead` bij elke route-update:

```vue
<script setup lang="ts">
useI18nHead(() => ({
  meta: [{ property: 'og:title', content: article.value?.title }],
  replace: {
    canonical: article.value?.canonicalUrl,
    ogUrl: article.value?.canonicalUrl,
    hreflang: localeCodes.map((locale) => ({
      rel: 'alternate',
      hreflang: locale,
      href: article.value!.locales[locale]!,
    })),
    ogAlternates: localeCodes,
  },
}))
</script>
```

Ondersteunt statische objecten, reactieve getters, `meta` / `link` toevoegen, `replace` voor ingebouwde groepen en `disable` om automatisch gegenereerde tags te verwijderen. Zie [`useI18nHead`](/nl/composables/useI18nHead).

### `mergeI18nHead`-hulpfunctie (`@i18n-micro/utils`) {#mergei18nhead-utility-@i18n-micro/utils}

Framework-onafhankelijke samenvoeglogica staat in `@i18n-micro/utils/merge-i18n-head` — gebruikt door de `02.meta`-plugin en los te testen. Types (`I18nHeadInput`, `I18nHeadLink`, `I18nHeadMeta`) worden geëxporteerd vanuit `@i18n-micro/types`.

### Plugin-integratie {#plugin-integration}

- **`02.meta`** — voegt de uitvoer van `useLocaleHead` samen met de paginastatus van `useI18nHead` via `useHead`
- **`01.plugin`** — reset pagina-overrides bij een wijziging van de routenaam via `resetPageHead()` (gedeelde status met de composable)

### Documentatie & tests {#documentation-&-tests}

- Nieuwe gids: [`useI18nHead`](/nl/composables/useI18nHead) met CMS-/artikelvoorbeelden
- Bijgewerkt: [SEO](/nl/guide/seo) en [`useLocaleHead`](/nl/composables/useLocaleHead) — wanneer je welke API gebruikt
- Playwright- + Vitest-dekking: SSR, SPA-navigatie, herladen, `nuxi generate`, gedeeltelijke alternates, `x-default`, reactief laden op de client

## Typische use cases {#typical-use-cases}

| Scenario                                     | Aanpak                                                         |
| -------------------------------------------- | -------------------------------------------------------------- |
| Blog/CMS met gedeeltelijke vertalingen       | `replace.hreflang` + `replace.ogAlternates` uit API-locales    |
| Eigen canonical uit CMS                      | `replace.canonical` + `replace.ogUrl`                          |
| Alleen OG op een landingspagina              | `meta: [{ property: 'og:title', ... }]` — behoud hreflang van de module |
| Geen hreflang op een pagina                  | `disable: ['hreflang', 'x-default']`                           |
| Eigen plugin vervangen (`i18nManualHreflang`) | `useI18nHead` per contentpagina + `meta: true`                |

**JSON-LD** blijft in `useHead({ script: [...] })` — `useI18nHead` genereert geen gestructureerde data.

## Breaking changes {#breaking-changes}

Geen bij standaardgebruik van `nuxt.config`. De nieuwe composable en het utils-subpad zijn puur aanvullend.

## Waarom het ertoe doet {#why-it-matters}

- **Geen eigen meta-plugin** nodig voor CMS-berichten, nieuws of gidsen met URL's per locale
- **Eén pipeline** — moduledefaults + pagina-overrides in één `useHead`-aanroep
- **Type-safe** — `I18nHeadInput` voor helpers zoals `buildArticleHead(content)`

De volledige changelog wordt bij de release gepubliceerd op [GitHub](https://github.com/s00d/nuxt-i18n-micro/blob/main/CHANGELOG.md).
