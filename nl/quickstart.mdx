## 🚀 Snelstart

### Installatie

Installeer de module in je Nuxt-applicatie:

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

### Basisconfiguratie

Voeg de module toe aan je `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

<Tip>
- **Bestanden op rootniveau** (`locales/en.json`, enzovoort) — vertalingen die gedeeld worden door de hele app (menu's, footer, algemene UI). Met `translationPayloads.mode: 'premerged'` (standaard) worden ze tijdens de build samengevoegd met elke pagina.
- **Paginaspecifieke bestanden** (`locales/pages/<route>/<locale>.json`) — vertalingen die uniek zijn voor specifieke pagina's, alleen geladen wanneer de pagina wordt bezocht.
- **Dynamische routes** — `pages/articles/[id].vue` wijst naar `locales/pages/articles-id/` (haakjes vervangen door streepjes).
- **Automatische generatie** — alle vertaalbestanden worden automatisch aangemaakt wanneer ze ontbreken tijdens `nuxt dev`.
</Tip>

<Info>
De module ondersteunt beide indelingen:

- **Pagina's**: `pages/**/*.vue` (Nuxt 3) of `app/pages/**/*.vue` (Nuxt 4)
- **Vertalingen**: houd `locales/` standaard in de **projectroot** (aanbevolen conventie), niet binnen `app/`

```tree
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   ├── en.json
│   └── pages/
└── nuxt.config.ts
```

Optionele colocatie: `i18n: \{ translationDir: 'app/locales' \}` (zie [fixture `n3`](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/n3)).

Voor de optionele CLI-helper `text-to-i18n` gebruik je [`nuxt-i18n-micro-cli` ≥ 2.1.1](/guides/cli#-text-to-i18n-command), zodat `app/pages` en `app/components` vanuit de projectroot worden gescand.
</Info>

### Basisgebruik

Gebruik vertalingen in je componenten:

```vue
<template>
  <div>
    <h1>{{ $t('welcome') }}</h1>
    <p>{{ $t('description', { name: 'World' }) }}</p>

    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" @click="$switchLocale(locale.code)">
        {{ locale.code }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useI18n } from '#imports'

const { $t, $getLocales, $switchLocale } = useI18n()
</script>
```
