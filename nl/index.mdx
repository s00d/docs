---

Nuxt I18n Micro is een lichtgewicht, krachtige i18n-module voor Nuxt 3 en 4, ontworpen voor grote projecten. Hij houdt buildtijden, geheugengebruik en bundelgrootte laag vergeleken met traditionele i18n-oplossingen zoals `@nuxtjs/i18n`.

Gelokaliseerde routes worden tijdens de build gegenereerd door `@i18n-micro/route-strategy` en tijdens runtime opgelost door `@i18n-micro/path-strategy`, zodat links, de switcher, `hreflang` en redirects allemaal overeenkomen met de router. Vertalingen zijn alleen JSON, verdeeld over gedeelde rootbestanden en bestanden per pagina die de dev-server voor je aanmaakt, met ingebouwde HMR.

<CodeGroup>

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>
