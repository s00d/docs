## Vereisten

- **Node.js**: 18 of nieuwer.
- **Nuxt**: 3.x of 4.x.

De module ondersteunt zowel de Nuxt 3-projectindeling (`pages/**/*.vue`) als de Nuxt 4-indeling (`app/pages/**/*.vue`). Vertalingen staan volgens conventie in de rootmap van het project (`locales/`), ook wanneer je de Nuxt 4 `app/`-map gebruikt.

## Installeer de Nuxt-module

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Registreer de module in `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Zie de [Snelstart](/quickstart) voor een volledige uitleg of de [Configuratiereferentie](/guides/configuration) voor alle opties.

## Projectindeling

Standaard verwacht de module:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Bestanden op rootniveau worden tijdens de build samengevoegd met elk paginaspecifiek bestand. Paginaspecifieke bestanden worden automatisch aangemaakt wanneer ze ontbreken tijdens `nuxt dev`.

## Nuxt 4-indeling

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Om vertalingen te bundelen onder `app/`, stel je `translationDir: 'app/locales'` in.

## TypeScript

De module genereert ambient types voor `useI18n`, `$t` en gerelateerde helpers op basis van je standaard localebestanden. Dit staat standaard aan (`types: true`).

Voor sterkere typering van vertaalsleutels, zie [`@i18n-micro/types-generator`](/integrations/types-generator).
