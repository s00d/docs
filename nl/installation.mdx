## Vereisten

- **Node.js**: 18 of nieuwer.
- **Nuxt**: 3.x of 4.x.

De module ondersteunt zowel de Nuxt 3-projectlayout (`pages/**/*.vue`) als de Nuxt 4-layout (`app/pages/**/*.vue`). Vertalingen staan conventioneel in de projectroot (`locales/`), zelfs bij gebruik van de Nuxt 4 `app/`-map.

## Installeer de Nuxt-module

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Registreer het in `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Zie de [Snelstart](/quickstart) voor een volledige walkthrough of de [Configuratiereferentie](/guides/configuration) voor elke optie.

## Projectindeling

Standaard verwacht de module:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Bestanden op rootniveau worden bij het builden samengevoegd met elk pagina-specifiek bestand. Pagina-specifieke bestanden worden automatisch aangemaakt wanneer ze ontbreken tijdens `nuxt dev`.

## Nuxt 4-layout

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Om vertalingen onder `app/` te plaatsen, stel je `translationDir: 'app/locales'` in.

## TypeScript

De module genereert ambient types voor `useI18n`, `$t` en gerelateerde helpers op basis van je standaard localebestanden. Dit staat standaard aan (`types: true`).

Voor sterkere typering van vertaalsleutels, zie [`@i18n-micro/types-generator`](/integrations/types-generator).
