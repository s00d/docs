---
title: "<i18n-switcher>"
description: "Het component <i18n-switcher> is een dropdown met de ingeschakelde locales, die elk naar de huidige pagina in die locale linken."
---

`<i18n-switcher>` rendert een knop met de actieve locale en een dropdown met alle ingeschakelde locales, inclusief de actieve. Gebruik het voor een kant-en-klaar taalmenu; bouw je eigen menu met [`$getLocales`](/nl/api/methods#$getlocales) en [`$switchLocalePath`](/nl/api/methods#$switchlocalepath) wanneer je andere markup nodig hebt. Elk item linkt naar de huidige pagina in die locale.

## Props en slots {#props-and-slots}

| Prop | Type | Standaard | Beschrijving |
| --- | --- | --- | --- |
| `customLabels` | `Record<string, string>` | `() => ({})` | Weergavenaam per locale-code, die de `displayName` uit de locale-config overschrijft. |
| `customWrapperStyle` | `CSSProperties` | `() => ({})` | Inline stijl voor de buitenste wrapper. |
| `customButtonStyle` | `CSSProperties` | `() => ({})` | Inline stijl voor de knop die de dropdown opent. |
| `customDropdownStyle` | `CSSProperties` | `() => ({})` | Inline stijl voor het dropdownpaneel. |
| `customItemStyle` | `CSSProperties` | `() => ({})` | Inline stijl voor elk item in de dropdown. |
| `customLinkStyle` | `CSSProperties` | `() => ({})` | Inline stijl voor de link binnen een item. |
| `customActiveLinkStyle` | `CSSProperties` | `() => ({})` | Inline stijl voor de link van de momenteel actieve locale. |
| `customDisabledLinkStyle` | `CSSProperties` | `() => ({})` | Inline stijl voor de knop van de *huidige* locale wanneer die in de config `disabled: true` heeft. |
| `customIconStyle` | `CSSProperties` | `() => ({})` | Inline stijl voor het caret-icoon op de knop. |

### Slots {#slots}

| Slot | Bindings | Beschrijving |
| --- | --- | --- |
| `before-button` | — | Inhoud vóór de knop die de dropdown opent. |
| `before-selected-locale` | — | Inhoud vóór het label van de actieve locale in de knop. |
| `after-selected-locale` | — | Inhoud na het label van de actieve locale in de knop. |
| `before-dropdown` | — | Inhoud tussen de knop en het dropdownpaneel. |
| `before-dropdown-items` | — | Inhoud bovenaan de dropdown, boven de lijst met locales. |
| `before-item` | `locale` | Inhoud vóór elk locale-item. |
| `before-link-content` | `locale` | Inhoud vóór het label van een locale in de bijbehorende link. |
| `after-link-content` | `locale` | Inhoud na het label van een locale in de bijbehorende link. |
| `after-item` | `locale` | Inhoud na elk locale-item. |
| `after-dropdown-items` | — | Inhoud onderaan de dropdown, onder de lijst met locales. |
| `after-dropdown` | — | Inhoud na het dropdownpaneel. |

## Gedrag {#behaviour}

- Toont elke locale zonder `disabled: true`, inclusief de actieve.
- Elk item is een `<a>` naar `$switchLocalePath(code)`. Een pad wordt opgelost onder `app.baseURL`; een locale-`baseUrl` op een ander domein blijft absoluut. Het heeft `hreflang` en `lang` ingesteld op `iso || code`, `dir` wanneer de locale er een heeft, `aria-current="page"` op de huidige locale en de class `switcher-locale-<code>`. Een klik roept `$switchLocale(code)` aan en sluit de dropdown; met een modifier-toets wordt het aan de browser overgelaten.
- De lijst blijft verborgen in de server-HTML staan, zodat crawlers de links zien. Escape of een klik erbuiten sluit hem.
- Label: `customLabels[code]`, dan de `displayName` van de locale, dan de code (met een waarschuwing in development).
- Stijlen: kleine inline standaardwaarden (witte knop en paneel met rand, het actieve item vet en blauw). Elke `custom*Style`-prop wordt na de standaardwaarde van het betreffende onderdeel toegepast. De knop heeft de classes `i18n-switcher-button` en `language-switcher`, de wrapper `i18n-switcher-wrapper`, de lijst `i18n-switcher-dropdown`. Posities gebruiken logische CSS-eigenschappen, dus `dir="rtl"` werkt.

## Voorbeeld {#example}

```vue
<template>
  <i18n-switcher
    :custom-labels="{ en: 'English', de: 'Deutsch' }"
    :custom-button-style="{ borderRadius: '4px' }"
  >
    <template #before-link-content="{ locale }">
      <img :src="`/flags/${locale.code}.svg`" alt="" width="16" />
    </template>
  </i18n-switcher>
</template>
```
