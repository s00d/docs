---

`<i18n-group>` beperkt een blok markup tot één sleutelprefix. Gebruik het wanneer veel sleutels van een sectie een prefix delen en je die niet wilt herhalen. De default-slot ontvangt een `t` die de prefix ervoor plaatst.

## Props en slot {#props-and-slot}

| Prop | Type | Standaard | Beschrijving |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | Sleutelprefix waartegen elke lookup in de slot wordt opgelost. |
| `groupClass` | `string` | `''` | Extra class op het wrapper-element. |

**\*** verplicht.

### Slots {#slots}

| Slot | Bindings | Beschrijving |
| --- | --- | --- |
| `default` | `prefix`, `t` | Ontvangt `prefix` en een `t`-functie die daartoe beperkt is. |

## Gedrag {#behaviour}

- Rendert `<div class="i18n-group {groupClass}">` rond de slot.
- `t(key, params)` is `$t(prefix + '.' + key, params)` voor de huidige route.
- Alleen de `t` van de slot is beperkt: `$t` en geneste `<i18n-t>` binnen de groep nemen nog steeds volledige sleutels.

## Voorbeeld {#example}

```json
{
  "checkout": { "title": "Checkout", "items": "Items: {count}" }
}
```

```vue
<template>
  <i18n-group prefix="checkout" group-class="checkout">
    <template #default="{ t }">
      <h2>{{ t('title') }}</h2>
      <p>{{ t('items', { count: 3 }) }}</p>
    </template>
  </i18n-group>
</template>
```
