# Yapılandırma Referansı

`nuxt.config` içindeki `i18n` anahtarı altındaki her seçeneğin tam referansı. Türler ve varsayılanlar, `@i18n-micro/types` içindeki [`ModuleOptions`](https://github.com/s00d/nuxt-i18n-micro/blob/main/packages/types/src/index.ts) ile eşleşir.

## Hızlı referans

Modülün kabul ettiği tüm seçenekler `ModuleOptions` türünden alınmıştır. Aşağıdaki bölümler bunların birlikte nasıl çalıştığını açıklar; tam açıklamalar için [Modül Seçenekleri referansına](/api/module-options) bakın.

# Seçenek ayrıntıları

Modül, uluslararasılaştırma kurulumunuzu özelleştirmek için kapsamlı yapılandırma seçenekleri sunar.

### 🌍 Çekirdek Yerel Ayar Ayarları

#### `locales`

{/* generated:option:locales — do not edit; run `pnpm run docs:generate` */}

**Tür** `Locale[]` · **Varsayılan** `[]`

Desteklenen yerel ayarların listesi.
Her giriş bir yerel ayar kodu ile isteğe bağlı meta verileri (ISO, yön, görünen ad vb.) tanımlar.

{/* /generated:option:locales */}

Her yerel ayar nesnesi şunları destekler:

| Özellik          | Tür       | Zorunlu  | Açıklama                                              |
| ---------------- | --------- | -------- | ----------------------------------------------------- |
| `code`           | `string`  | ✅       | Benzersiz tanımlayıcı (örn. `'en'`)                   |
| `displayName`    | `string`  | ❌       | Değiştiriciler için okunabilir ad (örn. `'English'`)  |
| `iso`            | `string`  | ❌       | ISO kodu (örn. `'en-US'`)                             |
| `dir`            | `string`  | ❌       | Metin yönü (`'ltr'` veya `'rtl'`)                     |
| `disabled`       | `boolean` | ❌       | `true` ise açılır menüde devre dışı bırakır           |
| `baseUrl`        | `string`  | ❌       | Yerel ayara özel etki alanları için taban URL         |
| `baseDefault`    | `boolean` | ❌       | URL'lerden yerel ayar önekini kaldırır                |
| `fallbackLocale` | `string`  | ❌       | Yerel ayar başına yedek (globali geçersiz kılar)      |
| `[key: string]`  | `unknown` | ❌       | Herhangi bir özel özellik (aşağıya bakın)             |

**Örnek**:

```typescript
locales: [
  { code: 'en', iso: 'en-US', dir: 'ltr' },
  { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
  { code: 'ar', iso: 'ar-SA', dir: 'rtl', disabled: true },
  {
    code: 'de',
    iso: 'de-DE',
    dir: 'ltr',
    baseUrl: 'https://de.example.com',
    baseDefault: true,
  },
]
```

<Warning>
`baseUrl` kullanmak, dahili rotaların dış bağlantılar olarak çoğaltılmasına yol açabilir, bu da yönlendirmeyi ve bakımı zorlaştırır. Bunun yerine belirli yerel ayarlar için doğrudan dış bağlantılar oluşturmayı düşünün.
</Warning>

#### Özel Yerel Ayar Özellikleri

Yerel ayar nesnelerine herhangi bir özel özellik ekleyebilirsiniz. Bunlar çalışma zamanına iletilir ve `$getLocales()` aracılığıyla erişilebilir:

```typescript
locales: [
  { code: 'en', iso: 'en-US', flag: '🇬🇧', currency: 'GBP' },
  { code: 'de', iso: 'de-DE', flag: '🇩🇪', currency: 'EUR' },
  { code: 'ru', iso: 'ru-RU', flag: '🇷🇺', currency: 'RUB' },
]
```

Bileşenlerde bunlara erişin:

```vue
<template>
  <ul>
    <li v-for="locale in $getLocales()" :key="locale.code">{{ locale.flag }} {{ locale.displayName }} ({{ locale.currency }})</li>
  </ul>
</template>
```

Varsayılan olarak, özel özellikler `unknown` olarak yazılmıştır. Tam TypeScript desteği elde etmek için **modül genişletme** kullanın. Bir bildirim dosyası oluşturun (örn. `app/i18n.d.ts` veya `tsconfig`'inizde bulunan herhangi bir `.d.ts`):

```typescript
// app/i18n.d.ts
declare module '@i18n-micro/types' {
  interface Locale {
    flag?: string
    currency?: string
  }
}
```

Bundan sonra tüm özel özellikler tam olarak yazılır:

```typescript
const locales = $getLocales()
locales[0].flag // string | undefined ✅
locales[0].currency // string | undefined ✅
```

#### `defaultLocale`

{/* generated:option:defaultLocale — do not edit; run `pnpm run docs:generate` */}

**Tür** `string` · **Varsayılan** `'en'`

URL veya kullanıcı tercihlerinden yerel ayar belirlenemediğinde kullanılacak yerel ayar.
Ayrıca `fallbackLocale` ayarlanmadığında eksik çeviriler için yedek yerel ayar olarak kullanılır.

{/* /generated:option:defaultLocale */}

```typescript
defaultLocale: 'en'
```
#### `strategy`

{/* generated:option:strategy — do not edit; run `pnpm run docs:generate` */}

**Tür** `Strategies` · **Varsayılan** `'prefix_except_default'`

Yerel ayar önekleri için URL yönlendirme stratejisi.

- `'no_prefix'` — URL'de yerel ayar yok; yerel ayar çerezde saklanır.
- `'prefix_except_default'` — varsayılan hariç tüm yerel ayarları öneklendirin.
- `'prefix'` — varsayılan yerel ayar dahil her zaman öneklendirin.
- `'prefix_and_default'` — `prefix` gibidir, ancak varsayılan yerel ayara öneksiz de erişilebilir.

{/* /generated:option:strategy */}

<CodeGroup>
```typescript no_prefix
strategy: 'no_prefix'
// Routes: /about, /contact
// Locale detection via browser/cookies
```

```typescript prefix_except_default
strategy: 'prefix_except_default'
// Default locale: /about, /contact
// Other locales: /fr/about, /de/contact
```

```typescript prefix
strategy: 'prefix'
// All locales: /en/about, /fr/about, /de/about
```

```typescript prefix_and_default
strategy: 'prefix_and_default'
// Both prefixed and non-prefixed versions for default locale
```
</CodeGroup>

### 📂 Çeviri Yönetimi
#### `translationDir`

{/* generated:option:translationDir — do not edit; run `pnpm run docs:generate` */}

**Tür** `string` · **Varsayılan** `'locales'`

Çeviri JSON dosyalarını içeren dizinin, proje köküne göre yolu.

{/* /generated:option:translationDir */}

```typescript
translationDir: 'i18n' // Custom directory
// Nuxt 4 colocation example:
// translationDir: 'app/locales'
```

Yollar `app/` klasöründen değil, Nuxt **proje kökünden** (`rootDir`) çözümlenir. Nuxt 4 ile olağan kurulum, rotalar için `app/pages/` ve JSON dosyaları için `locales/`'dır (veya `translationDir` ayarlarsanız `app/locales`).
#### `disablePageLocales`

{/* generated:option:disablePageLocales — do not edit; run `pnpm run docs:generate` */}

**Tür** `boolean` · **Varsayılan** `false`

Sayfa başına çeviri dosyalarını devre dışı bırakın.
`true` olduğunda, yalnızca global çeviriler (`\{locale\}.json`) yüklenir;
sayfaya özel dosyalar (`pages/\{page\}/\{locale\}.json`) oluşturulmaz veya yüklenmez.

{/* /generated:option:disablePageLocales */}

Etkinleştirildiğinde, yalnızca kök seviyesindeki çeviri dosyaları kullanılır:

```tree
locales/
├── en.json
├── fr.json
└── ar.json
```
#### `fallbackLocale`

{/* generated:option:fallbackLocale — do not edit; run `pnpm run docs:generate` */}

**Tür** `string` · **Varsayılan** `undefined (yedek yok; ham anahtarı döndürür)`

Global yedek yerel ayar kodu.
Aktif yerel ayarda bir çeviri anahtarı eksik olduğunda, modül anahtarın kendisini döndürmeden önce
bu yerel ayarda arar.

{/* /generated:option:fallbackLocale */}

```typescript
fallbackLocale: 'en' // Global fallback
```
#### `types`

{/* generated:option:types — do not edit; run `pnpm run docs:generate` */}

**Tür** `boolean` · **Varsayılan** `true`

Varsayılan yerel ayar dosyalarınızdaki çeviri anahtarlarına dayalı olarak `useI18n`, `$t` ve ilgili yardımcılar için
TypeScript tür bildirimleri oluşturun.

{/* /generated:option:types */}

Etkinleştirildiğinde, modül derleme sırasında yazılı çeviri anahtarlarıyla `.nuxt/i18n.d.ts` dosyasını yayınlar. Yazılmamış yardımcıları tercih ediyorsanız veya harici bir jeneratör kullanıyorsanız `false` olarak ayarlayın.

Bu yerleşik jeneratör, monorepolar ve CI için daha katı veya bağımsız tür dosyaları üretebilen isteğe bağlı [`@i18n-micro/types-generator`](/integrations/types-generator) paketinden ayrıdır.

```typescript
types: false // Disable built-in key typing
```
#### `routeLocales`

{/* generated:option:routeLocales — do not edit; run `pnpm run docs:generate` */}

**Tür** `Record<string, string[]>` · **Varsayılan** —

`defineI18nRoute()` çağrılarından çıkarılan rota başına yerel ayar kısıtlamaları.
Bir rota yolunu (örn. `'/about'`) izin verilen yerel ayar kodları dizisiyle eşler.
Listelenmeyen rotaların kısıtlamaları yoktur (tüm yerel ayarlara izin verilir).

{/* /generated:option:routeLocales */}

Bir rota yolunu (örn. `'/about'`) izin verilen yerel ayar kodlarıyla eşler. Listelenmeyen rotalar, yapılandırılan tüm yerel ayarlara izin verir.

Normalde bunu `nuxt.config` yerine sayfalarda [`defineI18nRoute`](/guides/custom-locale-routes) aracılığıyla yapılandırırsınız. Modül, derleme sırasında sayfa düzeyi bildirimlerini bu haritaya birleştirir.
#### `routeDisableMeta`

{/* generated:option:routeDisableMeta — do not edit; run `pnpm run docs:generate` */}

**Tür** `Record<string, boolean \| string[]>` · **Varsayılan** —

`defineI18nRoute()` çağrılarından çıkarılan rota başına meta etiket devre dışı bırakma.
Bir rota yolunu `true`'ya (tüm metayı devre dışı bırak) veya meta'nın devre dışı bırakılması gereken

### 🔢 Özelleştirme
#### `plural`

{/* generated:option:plural — do not edit; run `pnpm run docs:generate` */}

**Tür** `PluralFunc` · **Varsayılan** `yerleşik çoğullaştırma (sayı ile form indeksi)`

Özel çoğullaştırma işlevi.
`(key, count, params, locale, getter)` alır ve seçilen çoğul formu bir dize olarak
döndürmelidir veya yerleşik `defaultPlural` mantığına geri dönmek için `null`/`undefined`
döndürmelidir (böylece yalnızca bazı yerel ayarları geçersiz kılabilirsiniz).

Nuxt modülü için işlev, `.toString()` ile `.nuxt/i18n.plural.mjs` içine serileştirilir —
kendi kendine yeterli olmalıdır (dış içe aktarma / dış kapsam yok).
Bir dosya yolu dizesi **desteklenmez**.

{/* /generated:option:plural */}

##### Nasıl çalışır

Çeviriler çoğul formları ayırmak için `|` kullanır:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

Bir form `\{count\}`'tan fazlasına ihtiyaç duyduğunda `$tc('apples', count)` veya `$tc('cart', \{ count, name \})` kullanın — **`count` ve diğer parametreleri üçüncü argüman olarak değil, ikinci argüman nesnesinde geçirin** (üçüncü yalnızca `defaultValue`'dur).

`$tc` çağrısı, `plural` işlevini çağırır ve:

1. Ham çeviri dizesini almak için `t(key)` çağırır (örn. `"no apples | one apple | \{count\} apples"`)
2. Formlar dizisini almak için `|` ile böler
3. `count`'a göre bir form seçer
4. `\{count\}`'u gerçek sayıyla değiştirir

**Varsayılan** uygulama indekse göre seçer: `count < forms.length ? forms[count] : forms[last]`. Bu, basit durumlar için çalışır (0 → ilk form, 1 → ikinci, 2+ → son).

##### Özel çoğul işlev

Karmaşık çoğullaştırma kurallarına sahip diller (örneğin Rusça, Arapça, Lehçe) için `plural` seçeneğini geçersiz kılın.

<Danger>
İşlev `.toString()` aracılığıyla serileştirilir ve derleme zamanında sanal bir modüle enjekte edilir. Bu şu anlama gelir:

- **`function` anahtar kelimesi kullanmalıdır** — kısayol yöntem sözdizimi DEĞİL, harici referanslar olan ok işlevleri DEĞİL
- **İçe aktarma veya harici referans yok** — işlev tamamen kendi kendine yeterli olmalıdır (`plural: '~/i18n/plural.ts'` gibi bir dosya yolu **desteklenmez**)
- **`.toString()`'dan kurtulmayan TypeScript'e özgü sözdizimi yok** (Nuxt bunları çıkardığı için `nuxt.config.ts` içindeki tür ek açıklamaları uygundur)
- `null` / `undefined` döndürmek, yerleşik `defaultPlural`'a geri döner (yerel ayara özel geçersiz kılmalar için kullanışlıdır)
</Danger>

**Örnek: Rusça çoğullaştırma** (4 form: sıfır, bir, birkaç, çok):

```typescript
// nuxt.config.ts
export default defineNuxtConfig({
  i18n: {
    plural: function (key, count, _params, _locale, t) {
      const translation = t(key)
      if (!translation) return key

      const forms = translation
        .toString()
        .split('|')
        .map(function (s) {
          return s.trim()
        })
      let idx

      if (count === 0) {
        idx = 0
      } else {
        const mod10 = count % 10
        const mod100 = count % 100
        if (mod10 === 1 && mod100 !== 11) {
          idx = 1
        } else if (mod10 >= 2 && mod10 <= 4 && (mod100 < 10 || mod100 >= 20)) {
          idx = 2
        } else {
          idx = 3
        }
      }

      if (idx >= forms.length) idx = forms.length - 1
      return (forms[idx] || '').replace('{count}', String(count))
    },
  },
})
```

Bu çeviri ile:

```json
{
  "apples": "нет яблок | {count} яблоко | {count} яблока | {count} яблок"
}
```

Sonuçlar:

- `$tc('apples', 0)` → `"нет яблок"`
- `$tc('apples', 1)` → `"1 яблоко"`
- `$tc('apples', 3)` → `"3 яблока"`
- `$tc('apples', 5)` → `"5 яблок"`
- `$tc('apples', 21)` → `"21 яблоко"`

**Örnek: Basit İngilizce (varsayılan davranış)**:

```typescript
// This is the built-in default — you don't need to set it explicitly
plural: function (key, count, params, _locale, t) {
  const translation = t(key, params)
  if (!translation) return null

  const forms = translation.toString().split('|')
  if (forms.length === 0) return null
  const form = count < forms.length ? forms[count] : forms[forms.length - 1]
  if (!form) return null
  return form.trim().replace('{count}', count.toString())
}
```

##### Yerel ayar başına çoğullaştırma

Farklı yerel ayarların farklı çoğul kurallara ihtiyacı varsa, `locale` üzerinde dallanın ve özelleştirmediğiniz yerel ayarlar için `null` döndürün — geri kalanı yerleşik `defaultPlural` işler:

```typescript

  // Only override Slavic locales; en/de/… keep the built-in rules

  if (!translation) return null

    else idx = 3

  if (idx >= forms.length) idx = forms.length - 1

}
```

#### `translationPayloads`

{/* generated:option:translationPayloads — do not edit; run `pnpm run docs:generate` */}

**Tür** `TranslationPayloadOptions` · **Varsayılan** —

Çeviri yüklerinin nasıl yayınlandığını kontrol eder (Node: `public/<apiBaseUrl>`; Edge: Nitro `serverAssets`).

- **Node**: `serverAssets`, Rollup `raw:` olmadan `public/` altındaki `readFile` aracılığıyla yerel SSR anlamına gelir.
- **Edge**: `serverAssets`, Nitro `serverAssets`'i (`assets:i18n`) kaydeder; genel bir kopyayı zorlamaz.

Olağan hepsi bir arada kurulum için varsayılanları koruyun. Büyük Edge katalogları için `mode: 'source'` tercih edin.
CDN destekli dağıtımlar için yerel çıktıları devre dışı bırakın ve `apiBaseClientHost` / `apiBaseServerHost` ayarlayın.

{/* /generated:option:translationPayloads */}

```typescript
{
  mode?: 'premerged' | 'source'
  serverAssets?: boolean
  serverHandler?: boolean
  publicAssets?: boolean
  prerenderRoutes?: boolean
  publicDir?: string
  warnFileCount?: number
  warnSizeBytes?: number
}
```

**Varsayılan** (`mode: 'premerged'`):

```typescript
{
  mode: 'premerged',
  serverAssets: true,
  serverHandler: true,
  publicAssets: true,
  prerenderRoutes: false
}
```

**Node** üzerinde SSR, `public/<apiBaseUrl>/` konumuna kopyalanan aynı ağacı okur (`readFile`). **Edge** üzerinde Nitro `serverAssets` bunu gömer (zorunlu genel kopya yok — CDN için `publicAssets: true` ayarlayın). `mode: 'premerged'` → sayfa/yerel ayar başına `\{page\}/\{locale\}/data.json`; `mode: 'source'` → kompakt kaynak + çalışma zamanı birleştirme.

**Node**'da `serverAssets: true`, `publicAssets` false olsa bile genel kopyayı zorlar. **Edge**'de yalnızca Nitro gömme işlemini kaydeder. Büyük kataloglar için Edge'de `mode: 'source'`'u tercih edin. Yerel yükler ve `apiBaseServerHost` olmadan, derleme başarısız olur.

Yerel `/\{apiBaseUrl\}/:page/:locale/data.json` işleyicisi, önceden render rotaları ve genel varlık kopyaları isteğe bağlı çıktılar olarak kalır.

Kompakt **genel** / Edge yükleri için:

```typescript
i18n: {
  translationPayloads: {
    mode: 'source',
  },
}
```

`mode: 'source'` katman dosyalarını kompakt tutar ve yerleşik `/_locales` rotası (veya Edge `assets:i18n`) aracılığıyla çalışma zamanında kök/sayfa/yedek birleştirir. Varsayılan olarak genel varlık kopyalarını ve önceden render edilmiş yük rotalarını devre dışı bırakır.

<Warning>
`mode: 'source'` ile `publicAssets` varsayılan olarak `false`'dur (siz etkinleştirmediğiniz sürece `prerenderRoutes` her zaman kapalıdır). Nitro/edge çalışma zamanı olmayan saf statik barındırma bu nedenle bu çıktılardan birini etkinleştirmediğiniz sürece, çalışma zamanında `serverHandler`'ı kullanılabilir tutmadığınız sürece veya yükleri harici olarak barındırmadığınız sürece istemcide çevirileri yükleyemez.

Varsayılan `mode: 'premerged'` ve `publicAssets: true` ile statik dosyalar zaten `public/<apiBaseUrl>/\{page\}/\{locale\}/data.json` konumuna iner — istemci `$fetch` URL'leriyle eşleşir — böylece statik bir barındırıcı bunları Nitro olmadan sunabilir.
</Warning>

<Warning>
`apiBaseServerHost` veya `apiBaseClientHost` ayarlandığında, modül bu kaynaktan zaten birleştirilmiş JSON'u getirir. Harici ana bilgisayarların yerleşik rota ile aynı `/\{apiBaseUrl\}/:page/:locale/data.json` yanıtlarını sunması gerekir. `mode: 'source'`, o CDN de çalışma zamanında birleştirilen yükleri sunmadığı sürece harici bir CDN'ye değil, yerel yük dizinlerine uygulanır.
</Warning>

Ayrıca çoğaltılmış yerel çıktıları manuel olarak devre dışı bırakabilir ve çeviri yüklerini bir CDN'den veya nesne depolamasından sunabilirsiniz:

```typescript
i18n: {
  apiBaseClientHost: 'https://cdn.example.com',
  apiBaseServerHost: 'https://cdn.example.com',
  translationPayloads: {
    serverHandler: false,
    publicAssets: false,
    prerenderRoutes: false
  }
}
```

Yalnızca yüklerin genel çıktıya yazılmasını önlemek ve SSR/çalışma zamanı istekleri için yerleşik sunucu rotasını korumak istiyorsanız, her iki genel çıktıyı da devre dışı bırakın:

```typescript
i18n: {
  translationPayloads: {
    publicAssets: false,
    prerenderRoutes: false
  }
}
```

**Node** üzerinde, `serverAssets: true`, `publicAssets` false olsa bile SSR için hâlâ genel kopyayı zorlar — sıfır yerel yük dosyası istiyorsanız `serverAssets: false` ve `apiBaseServerHost` ayarlayın.

Yükler kopyalandığında genel çıktı klasörünü değiştirmek için `publicDir`'i kullanın. Varsayılan olarak `apiBaseUrl` (`_locales`) değerindedir. Premerged modda `publicAssets` orada `\{page\}/\{locale\}/data.json`'u yazar (istemcinin getirdiği yollarla aynı). `prerenderRoutes`, işleyici rotalarının isteğe bağlı bir Nitro ön işlemesidir — o ağaç zaten kopyalandığında genellikle gereksizdir.

Tüm yerel yük çıktılarını devre dışı bırakırsanız, hem `apiBaseServerHost`'u (SSR) hem de `apiBaseClientHost`'u (istemci gezintisi) yapılandırmanız gerekir. Aksi takdirde çeviriler boş nesnelere çözümlenir ve UI anahtarları çevrilmemiş görünebilir.

`warnFileCount` ve `warnSizeBytes`, önceden birleştirilmiş yük çıktısı büyüdüğünde derleme zamanı uyarılarını kontrol eder (varsayılanlar: 500 dosya ve 10 MB).

{/* generated:option:dateBuild — do not edit; run `pnpm run docs:generate` */}

Varsayılan olarak modül, çeviri kaynaklarınızı parmak izler (katman sırasına göre her

Kontrolü ele almak için açıkça ayarlayın (örneğin yük URL'lerini içeriğe değil bir sürüme bağlamak için):

```ts
export default defineNuxtConfig({
  i18n: {
    // Any stable string/number: git SHA, CI build number, release tag, etc.
    dateBuild: process.env.GIT_SHA ?? 'local-dev',
  },
})
```

#### `httpCacheDuration`

{/* generated:option:httpCacheDuration — do not edit; run `pnpm run docs:generate` */}

**Tür** `number` · **Varsayılan** `31536000`

`/\{apiBaseUrl\}/:page/:locale/data.json` için HTTP `Cache-Control` max-age (saniye).

Yalnızca `dateBuild` URL'yi bozarken (`?v=...`) tam olarak uygulanır ki bu varsayılandır:
yanıt daha sonra `public, max-age=…, immutable` olur ve tarayıcılar ve CDN'ler için güvenlidir.

- `dateBuild: 0`/`''` — URL kararlıdır, bu nedenle bu süre *onurlandırılmaz*;
  yanıt bunun yerine `public, max-age=0, must-revalidate` olur. Değişmeyen bir URL'de uzun bir `max-age`,
  tarayıcının gördüğü ilk yükü sabitler.

- `0` — `Cache-Control`'ü hiç ayarlama (yerel hata ayıklama için kullanışlıdır)
- Geliştirmede (`import.meta.dev`) uygulanmaz, böylece HMR tarayıcı önbelleği tarafından savaşmaz
- Yalnızca Nitro aracılığıyla sunulan yanıtlara ulaşır. `public/` içine kopyalanan yükler ve barındırma platformu tarafından sunulanlar o platformun başlıklarını alır — Performans kılavuzuna bakın.

`@nuxtjs/i18n` deneysel `httpCacheDuration`'ına (v10.2.0) benzer, ancak Nitro `defineCachedEventHandler` maxAge yerine
açık bir yanıt başlığı olarak.

{/* /generated:option:httpCacheDuration */}

```ts
export default defineNuxtConfig({
  i18n: {
    // Per-build fallback (Date.now()) so immutable payloads never go stale when GIT_SHA is missing.
    dateBuild: process.env.GIT_SHA ?? String(Date.now()),
    httpCacheDuration: 86400, // 24 hours
    // httpCacheDuration: 0, // disable Cache-Control header
  },
})
```
