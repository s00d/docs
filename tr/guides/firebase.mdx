# 🔥 Firebase AppHosting Dağıtımı

## 📖 Giriş

Firebase AppHosting, sunucusuz altyapıya sahip Nuxt uygulamalarını dağıtmak için güçlü bir platformdur. Ancak, `nuxt-i18n-micro` ile uygulamaları dağıtırken, çeviri JSON dosyalarının nasıl sunulduğuyla ilgili belirli sorunlarla karşılaşabilirsiniz. Bu kılavuz, çevirilerinizin üretimde doğru çalışmasını sağlamak için kapsamlı çözümler sunar.

## ⚠️ Yaygın Sorunlar

### Çeviri Dosyaları Uygulanmıyor

**Belirtiler:**

- ✅ Çeviriler geliştirmede (`nuxt dev`) mükemmel çalışır
- ❌ Firebase AppHosting'e dağıtımdan sonra, JSON dosyaları yüklenir ancak çeviriler uygulanmaz
- ❌ Konsolda hata görünmez
- ❌ Çeviri dosyaları Network sekmesinde görünür ancak `application/json` yerine yanlış `Content-Type: text/html` var

**Ana Neden:**

Firebase AppHosting (ve Nitro ön işleme kullanan diğer platformlar), önceden render edilmiş JSON dosyalarını yanlış MIME türleriyle sunabilir. Tarayıcı `Content-Type: text/html` ile JSON dosyaları aldığında, bunları düzgün bir şekilde ayrıştıramaz ve çevirilerin sessizce başarısız olmasına neden olur.

## ✅ Çözümler

### Çözüm 1: Rota Kuralları Yapılandırması (Önerilen)

En basit çözüm, `nuxt.config.ts` içinde çeviri rotaları için açık başlıklar eklemektir:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],

  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'de', iso: 'de-DE', dir: 'ltr' },
      // ... other locales
    ],
    strategy: 'prefix_except_default',
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
    metaBaseUrl: 'https://your-domain.com',
  },

  // Add route rules for translation files
  routeRules: {
    '/_locales/**': {
      headers: {
        'Content-Type': 'application/json',
        'Cache-Control': 'public, max-age=3600, s-maxage=3600',
      },
    },
  },
})
```

**Faydalar:**

- ✨ Basit yapılandırma
- 🚀 Uygun önbelleklemeyle performansı artırır
- 🔒 Tüm dağıtım platformlarında çalışır

### Çözüm 2: Özel API Taban URL'si

Özel bir `apiBaseUrl` (yalnızca yol öneki) kullanıyorsanız, rota kurallarını buna göre ayarlayın:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],

  i18n: {
    apiBaseUrl: '/api/translations', // Path prefix only, not a full URL
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
  },

  routeRules: {
    '/api/translations/**': {
      headers: {
        'Content-Type': 'application/json',
        'Cache-Control': 'public, max-age=3600',
      },
    },
  },
})
```

### Çözüm 3: Firebase'e Özgü Yapılandırma

Proje kökünde `firebase.json` dosyasını oluşturun veya güncelleyin:

```json
{
  "hosting": {
    "public": ".output/public",
    "cleanUrls": true,
    "rewrites": [
      {
        "source": "**",
        "function": "server"
      }
    ],
    "headers": [
      {
        "source": "/_locales/**/*.json",
        "headers": [
          {
            "key": "Content-Type",
            "value": "application/json"
          },
          {
            "key": "Cache-Control",
            "value": "public, max-age=3600, immutable"
          },
          {
            "key": "Access-Control-Allow-Origin",
            "value": "*"
          }
        ]
      }
    ]
  },
  "functions": {
    "source": ".output/server"
  }
}
```

## 🔍 Hata Ayıklama

### Hata Ayıklama Modunu Etkinleştir

Sorunları belirlemek için hata ayıklama günlüklerini ekleyin:

```typescript
export default defineNuxtConfig({
  i18n: {
    debug: true,
    // Your other config...
  },
})
```

Bu, aşağıdakiler hakkında ayrıntılı günlükler çıkarır:

- 📝 Çeviri dosyası yükleme
- 🔄 Önbellek işlemleri
- ⚠️ Yükleme hataları

### Network Sekmesini Kontrol Edin

1. DevTools → Network sekmesini açın
2. "data.json" ile filtreleyin
3. Bir çeviri dosyası isteğine tıklayın
4. **Yanıt Başlıklarını** doğrulayın:
   - ✅ `Content-Type: application/json` (doğru)
   - ❌ `Content-Type: text/html` (yanlış - düzeltilmesi gerekiyor)

### Ön İşleme Çıktısını Doğrulayın

Derlemeden sonra, çeviri dosyalarının oluşturulduğunu kontrol edin:

```bash
pnpm build

# Check public payload copy (premerged layout)
ls -la .output/public/_locales/index/en/
# → data.json
```

Her sayfa altında her yerel ayar için `data.json` görmeniz gerekir.

## 🚀 Derleme Yapılandırması

### Nitro Preset

Firebase AppHosting için doğru preset'i kullandığınızdan emin olun:

```typescript
export default defineNuxtConfig({
  nitro: {
    preset: 'firebase-app-hosting',
    firebase: {
      gen: 2,
      httpsOptions: {
        region: 'us-central1',
        maxInstances: 3,
      },
    },
  },
})
```

### Ön İşleme Yapılandırması

Optimal performans için ön işlemeyi yapılandırın:

```typescript
export default defineNuxtConfig({
  nitro: {
    prerender: {
      crawlLinks: true,
      routes: ['/'],
      ignore: ['/api/**', '/admin/**'],
    },
  },
})
```

## 📋 Eksiksiz Örnek Yapılandırma

İşte Firebase AppHosting için eksiksiz çalışan bir yapılandırma:

```typescript
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],

  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'de', iso: 'de-DE', dir: 'ltr' },
      { code: 'es', iso: 'es-ES', dir: 'ltr' },
      { code: 'it', iso: 'it-IT', dir: 'ltr' },
      { code: 'pt', iso: 'pt-PT', dir: 'ltr' },
      { code: 'ru', iso: 'ru-RU', dir: 'ltr' },
      { code: 'zh', iso: 'zh-CN', dir: 'ltr' },
      { code: 'ko', iso: 'ko-KR', dir: 'ltr' },
    ],
    strategy: 'prefix_except_default',
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
    metaBaseUrl: 'https://your-domain.com',
    debug: false, // Enable in development if needed
  },

  routeRules: {
    '/_locales/**': {
      headers: {
        'Content-Type': 'application/json',
        'Cache-Control': 'public, max-age=3600, s-maxage=3600',
      },
    },
  },

  nitro: {
    preset: 'firebase-app-hosting',
    prerender: {
      crawlLinks: true,
      routes: ['/'],
    },
  },
})
```

## ✅ Doğrulama Kontrol Listesi

Düzeltmeleri uyguladıktan sonra her şeyin çalıştığını doğrulayın:

- [ ] Derleme hatasız tamamlanır
- [ ] Çeviri JSON dosyaları `.output/public/_locales/\{page\}/\{locale\}/data.json` konumundadır
- [ ] Network sekmesi çeviri dosyaları için `Content-Type: application/json` gösterir
- [ ] Çeviriler ilk sayfa yüklemesinde doğru görüntülenir
- [ ] Konsolda hidrasyon uyumsuzlukları yoktur
- [ ] Dil değiştirme doğru çalışır
- [ ] SEO meta etiketleri düzgün oluşturulur

## 🔄 Dağıtım İş Akışı

### 1. Derlemeyi Hazırla

```bash
# Install dependencies
pnpm install

# Build for production
pnpm build

# Verify public payload copy
ls -la .output/public/_locales/index/en/data.json
```

### 2. Firebase'e Dağıt

```bash
# Install Firebase CLI if not already installed
npm install -g firebase-tools

# Login to Firebase
firebase login

# Initialize Firebase (first time only)
firebase init hosting

# Deploy
firebase deploy --only hosting,functions
```

### 3. Dağıtımı Doğrula

1. Dağıtılan sitenizi ziyaret edin
2. DevTools → Network sekmesini açın
3. Bir sayfaya gidin
4. `/_locales/index/en/data.json`'un (veya varsayılan yerel ayarınızın) şu şekilde yüklendiğini kontrol edin:
   - Durum: 200
   - Content-Type: application/json
   - Yanıt geçerli JSON içerir

## 🔧 Sorun Giderme

### Sorun: Çeviri Dosyaları için 404 Hataları

**Çözüm:** Çeviri dosyalarının çıktı dizinine kopyalandığından emin olun:

```typescript
// nuxt.config.ts
export default defineNuxtConfig({
  nitro: {
    publicAssets: [
      {
        dir: 'locales',
        maxAge: 60 * 60 * 24 * 365, // 1 year
      },
    ],
  },
})
```

### Sorun: Çeviriler Bazı Sayfalarda Çalışıyor Ancak Diğerlerinde Çalışmıyor

**Çözüm:** Sayfaya özel çevirilerin oluşturulup oluşturulmadığını kontrol edin:

```bash
# Should show data.json for each page/locale
ls -la .output/public/_locales/index/en/
ls -la .output/public/_locales/about/en/
```

Sayfaya özel çeviriler eksikse, `disablePageLocales`'in `true` olarak ayarlanmadığından emin olun:

```typescript
i18n: {
  disablePageLocales: false, // Ensure this is false
}
```

### Sorun: Yavaş Çeviri Yükleme

**Çözüm:** Önbellekleme ve ön yüklemeyi optimize edin:

```typescript
routeRules: {
  '/_locales/**': {
    headers: {
      'Content-Type': 'application/json',
      'Cache-Control': 'public, max-age=31536000, immutable',
      'X-Content-Type-Options': 'nosniff'
    },
    prerender: true
  }
}
```

## ⚡ Performans Optimizasyonu

### Sıkıştırmayı Etkinleştir

Firebase, Gzip/Brotli sıkıştırmasını otomatik olarak işler, ancak derlemenizin optimize edildiğinden emin olun:

```typescript
export default defineNuxtConfig({
  vite: {
    build: {
      minify: 'terser',
      terserOptions: {
        compress: {
          drop_console: true,
        },
      },
    },
  },
})
```

### Çevirileri Tembel Yükle

`Nuxt I18n Micro`, çevirileri sayfa başına otomatik olarak tembel yükler. Çeviriler yalnızca gerektiğinde yüklenir ve ilk paket boyutunu azaltır. Bu yerleşik işlevselliktir - ek yapılandırma gerekmez.

Daha fazla optimize etmek için:

- Sayfaya özel çevirileri etkinleştirmek için `disablePageLocales: false` (varsayılan) kullanın
- Kök seviyesi çevirileri minimum tutun
- Sayfa içeriği için rotaya özel çeviri dosyaları kullanın

<Tip>
Modül, **v3.0.0+** sürümünden itibaren uygun `Content-Type` başlıklarını otomatik olarak ayarlar. Sorunlar yaşıyorsanız, en son sürüme güncelleyin:

```bash
pnpm update nuxt-i18n-micro@latest
```
</Tip>
