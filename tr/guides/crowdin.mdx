# 🌐 Crowdin entegrasyon kılavuzu

## 📖 Giriş

Crowdin'i projene entegre etmek, yerelleştirme ve çeviri sürecini sadeleştirir; birden çok dil ve platformda çevirileri yönetmeyi kolaylaştırır. Bu kılavuz; yapılandırma, kaynak yükleme ve çeviri indirme dahil olmak üzere Crowdin'i projenle nasıl kuracağın için adım adım rehber sunar.

## 🔧 Kurulum ve yapılandırma

Crowdin'i kullanmaya başlamak için Crowdin CLI'yi makinene küresel olarak yüklemen ve proje dizininde başlatman gerekir.

### 📦 Crowdin CLI'yi yükleme

Önce Crowdin CLI'yi npm ile küresel olarak yükle:

```bash
npm install -g @crowdin/cli
```

### 🛠 Projende Crowdin'i başlatma

Projende Crowdin'i şu komutla başlat:

```bash
crowdin init
```

Bu komut; proje kimliğini, API belirtecini ve diğer yapılandırma ayrıntılarını belirlemek dahil olmak üzere kurulum sürecinde sana rehberlik eder.

## 🗂️ Yapılandırma kılavuzu

### 📄 Crowdin yapılandırma dosyası (`crowdin.yml`)

Crowdin yapılandırma dosyası (`crowdin.yml`) kaynak dosyalarının nasıl eşleneceğini ve çevirilerin nereye yerleştirileceğini tanımlar. Örnek bir yapılandırma:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Temel yapılandırma parametreleri

- **`project_id`**: Crowdin proje kimliğin. Çevirilerin yönetildiği projeyi Crowdin içinde tanımlar.
- **`api_token`**: Kimlik doğrulama için kullanılan API belirteci. Bu belirtecin çeviri yükleme ve indirme için doğru izinlere sahip olduğundan emin ol.
- **`base_path`**: Kaynak dosyalar için temel dizini belirtir. Bu örnekte çeviriler `./locales` dizininde saklanır.
- **`base_url`**: Crowdin API için temel URL.
- **`preserve_hierarchy`**: `true` olarak ayarlandığında Crowdin, kaynak dosyalarının klasör yapısını projede korur.

### 📂 Dosya yapılandırması

`files` bölümü, kaynak dosyalarını çevirilerin saklanacağı yollarla eşler. Örneğin:

- **Kaynak yolu**: Orijinal çeviri dosyalarının konumunu tanımlar.
- **Çeviri yolu**: Çevirilmiş dosyaların Crowdin'de nerede saklanacağını belirtir. Dosya yollarında dil kodunu dinamik olarak ayarlamak için `%two_letters_code%` gibi yer tutucular kullanılır.

## ⬆️ Kaynak dosyalarını Crowdin'e yükleme

Crowdin yapılandırman kurulduktan sonra, aşağıdaki komutla kaynak dosyalarını yükleyebilirsin:

```bash
crowdin upload sources
```

Bu komut; yapılandırmanda belirtilen tüm kaynak dosyalarını Crowdin'e yükler ve çeviri için kullanılabilir hale getirir.

## ⬇️ Crowdin'den çevirileri indirme

Crowdin'de çeviriler tamamlandıktan veya güncellendikten sonra, şu komutla bunları projene indirebilirsin:

```bash
crowdin download
```

Bu komut; en son çevirileri Crowdin'den alır ve yapılandırma dosyanda belirtilen yollara göre kaydeder.

## ⚙️ En iyi uygulamalar

### 🔑 Tutarlı anahtar adlandırma

Karışıklık ve çoğaltmayı önlemek için çeviri anahtarlarının tüm dosyalarda tutarlı olduğundan emin ol.

### 🧹 Düzenli bakım

Dosyalarını düzenli ve yönetilebilir tutmak için kullanılmayan çeviri anahtarlarını periyodik olarak gözden geçir ve temizle.

### 🛠 Yüklemeleri ve indirmeleri otomatikleştir

Kaynak dosyaların yüklenmesini ve çevirilerin indirilmesini otomatikleştirmek için Crowdin CLI komutlarını CI/CD boru hattına entegre et; böylece çevirilerin her zaman güncel kalır.

Bu kılavuzu izleyerek Crowdin'i projene sorunsuzca entegre edebilir ve uluslararasılaştırma çalışmalarını verimli ve düzenli bir şekilde yönetebilirsin.
