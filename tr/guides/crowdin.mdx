# 🌐 Crowdin Entegrasyon Kılavuzu

## 📖 Giriş

Crowdin'i projenize entegre etmek, birden fazla dil ve platform üzerinde çevirileri yönetmeyi kolaylaştırarak yerelleştirme ve çeviri sürecini kolaylaştırır. Bu kılavuz, yapılandırma, kaynak yükleme ve çeviri indirme dahil olmak üzere Crowdin'i projenizle kurma konusunda adım adım bir yol gösterir.

## 🔧 Kurulum ve Yapılandırma

Crowdin ile başlamak için Crowdin CLI'yi makinenize global olarak yüklemeniz ve proje dizininizde başlatmanız gerekir.

### 📦 Crowdin CLI'yi Kurma

Öncelikle Crowdin CLI'yi npm kullanarak global olarak kurun:

```bash
npm install -g @crowdin/cli
```

### 🛠 Projenizde Crowdin'i Başlatma

Projenizde Crowdin'i başlatmak için şunu çalıştırın:

```bash
crowdin init
```

Bu komut, proje kimliğinizi, API belirtecinizi ve diğer yapılandırma ayrıntılarını ayarlama dahil olmak üzere kurulum sürecinde size rehberlik edecektir.

## 🗂️ Yapılandırma Kılavuzu

### 📄 Crowdin Yapılandırma Dosyası (`crowdin.yml`)

Crowdin yapılandırma dosyası (`crowdin.yml`), kaynak dosyalarınızın nasıl eşleneceğini ve çevirilerin nereye yerleştirileceğini tanımlar. Aşağıda örnek bir yapılandırma bulunmaktadır:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Ana Yapılandırma Parametreleri

- **`project_id`**: Crowdin proje kimliğiniz. Bu, çevirilerin yönetildiği Crowdin içindeki projeyi tanımlar.
- **`api_token`**: Kimlik doğrulama için kullanılan API belirteci. Bu belirtecin çevirileri yükleme ve indirme için doğru izinlere sahip olduğundan emin olun.
- **`base_path`**: Kaynak dosyaları için taban dizini belirtir. Bu örnekte, çeviriler `./locales` dizininde saklanır.
- **`base_url`**: Crowdin API için taban URL.
- **`preserve_hierarchy`**: `true` olarak ayarlandığında, Crowdin projedeki kaynak dosyalarınızın klasör yapısını korur.

### 📂 Dosyalar Yapılandırması

`files` bölümü, kaynak dosyalarınızı çevirilerin saklanacağı yollara eşler. Örneğin:

- **Kaynak Yolu**: Orijinal çeviri dosyalarının konumunu tanımlar.
- **Çeviri Yolu**: Çevrilen dosyaların Crowdin'de nerede saklanacağını belirtir. `%two_letters_code%` gibi yer tutucular, dosya yollarında dil kodunu dinamik olarak ayarlamak için kullanılır.

## ⬆️ Kaynak Dosyaları Crowdin'e Yükleme

Crowdin yapılandırmanız ayarlandıktan sonra, kaynak dosyalarınızı aşağıdaki komutu kullanarak yükleyebilirsiniz:

```bash
crowdin upload sources
```

Bu komut, yapılandırmanızda belirtilen tüm kaynak dosyaları Crowdin'e yükler ve bunları çeviri için kullanılabilir hale getirir.

## ⬇️ Crowdin'den Çevirileri İndirme

Crowdin'de çeviriler tamamlandıktan veya güncellendikten sonra, bunları projenize indirebilirsiniz:

```bash
crowdin download
```

Bu komut, Crowdin'den en son çevirileri alır ve yapılandırma dosyanızda belirtilen yollara göre kaydeder.

## ⚙️ En İyi Uygulamalar

### 🔑 Tutarlı Anahtar Adlandırma

Karışıklık ve yinelenmeyi önlemek için çeviri anahtarlarının tüm dosyalar arasında tutarlı olduğundan emin olun.

### 🧹 Düzenli Bakım

Dosyalarınızı düzenli ve yönetilebilir tutmak için periyodik olarak kullanılmayan çeviri anahtarlarını gözden geçirin ve temizleyin.

### 🛠 Yükleme ve İndirmeleri Otomatikleştirme

Kaynak dosyaların yüklenmesini ve çevirilerin indirilmesini otomatikleştirmek için Crowdin CLI komutlarını CI/CD boru hattınıza entegre edin, böylece çevirilerinizin her zaman güncel olduğundan emin olun.

Bu kılavuzu izleyerek, Crowdin'i projenize sorunsuz bir şekilde entegre edebilecek ve uluslararasılaştırma çabalarınızı yönetme konusunda verimli ve organize bir yaklaşım sağlayabileceksiniz.
