# Bileşenlerde Çevirileri Kullanma

Modül kurulduktan ve yapılandırıldıktan sonra, Vue şablonlarınız ve komut dosyalarınızda `$t('your_key')` çağırarak çevirileri görüntüleyebilirsiniz.

## 1. Kök Seviyesi ve Sayfaya Özel Çeviri Dosyaları

1. **Kök seviyesi** çeviriler doğrudan `/locales` klasörü altında bulunur (örn. `/locales/en.json`, `/locales/fr.json`). Derleme zamanında, otomatik olarak her sayfaya özel dosyaya birleştirilir ve tüm sayfalarda kullanılabilir hale gelir.
2. **Sayfaya özel** çeviriler, Nuxt sayfa klasör yapınızla eşleşen `/locales/pages/...` altında bulunur:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. `$t` ile Şablon Kullanımı

`.vue` dosyalarınızda, `$t`'yi doğrudan şablonda kullanabilirsiniz:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
`$t`, anahtar iç içe geçmiş bir JSON düğümünü gösteriyorsa **nesneler** döndürebilir (örn. `$t('header')` → `\{ title: "Hi" \}`). Şablonlarda bu, `[object Object]` olarak render edilir. Garantili bir dize istediğinizde `$ts` kullanın veya `$t('header.title')` gibi daha spesifik bir anahtar sağlayın. Ayrıntılar için [API Referansı — $t vs $ts](/api/methods#t) bölümüne bakın.
</Tip>

## 3. Geçerli Yerel Ayarı Değiştirme

Uygulamanızdaki dilleri değiştirmek için `useI18n()`'den `$locale`'ı alabilir ve ona yeni bir kod atayabilirsiniz:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. İç İçe Anahtarlar ve Yer Tutucular

- **İç içe anahtarlar** nokta gösterimi kullanır, örn. `nested.key.deeper`.
- **Yer tutucular**, dinamik değerler eklemenize olanak tanır:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. İpuçları ve En İyi Uygulamalar

- **Çakışan Anahtarlar**: Sayfaya özel bir dosya, kök seviyesi bir dosyayla aynı anahtarı içeriyorsa, sayfaya özel sürüm öncelik alır (kök çeviriler derleme sırasında temel olarak birleştirilir).
- **Sayfa Dosyalarını Devre Dışı Bırakma**: Sayfaya özel çevirileri kullanmak istemiyorsanız, Nuxt yapılandırmanızda `disablePageLocales: true` ayarlayabilirsiniz. Bu şekilde, yalnızca `/locales/*.json` dosyaları kullanılır.
- **Doğrudan İçe Aktarma Yok**: `import \{ useI18n \} from 'nuxt-i18n-micro'` yapmanız gerekmez; modülün otomatik enjeksiyon özelliği bunu sizin için işler.

İşte bu kadar! Bu adımlarla, kök seviyesi veya sayfaya özel JSON dosyalarından **çevirileri hızlıca almaya** ve `$t` kullanarak bunları Nuxt uygulamanızda **görüntülemeye** başlayabilirsiniz.

## Ek Kaynaklar

Daha gelişmiş özellikleri keşfetmek için mutlaka şunları kontrol edin:

1. **`<i18n-t>` Bileşeni**  
   `<i18n-t>` bileşeni, özellikle iç içe öğeler, gelişmiş yer tutucu kullanımı ve daha karmaşık çeviri yapıları içeren durumlar için `$t`'ye güçlü bir alternatiftir.

- **Belgeler**: [i18n-t](/api/components/i18n-t)

2. **`useI18n` Composable**  
   `useI18n` composable, çevirileri yönetmek, yerel ayar değiştirmeyi, biçimlendirmeyi ve daha fazlasını işlemek için eksiksiz bir işlev ve reaktif özellik seti sunar.

- **Belgeler**: [useI18n](/api/composables/use-i18n)
