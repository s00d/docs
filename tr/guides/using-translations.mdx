# Bileşenlerde çevirileri kullanma

Modül kurulup yapılandırıldıktan sonra, Vue şablonların ve script'lerin içinde `$t('your_key')` çağırarak çevirileri gösterebilirsin.

## 1. Kök seviyesi ve sayfaya özel çeviri dosyaları

1. **Kök seviyesindeki** çeviriler doğrudan `/locales` klasörü altında bulunur (örn. `/locales/en.json`, `/locales/fr.json`). Derleme zamanında otomatik olarak her sayfaya özel dosyayla birleştirilir ve tüm sayfalarda kullanılabilir hale gelir.
2. **Sayfaya özel** çeviriler `/locales/pages/...` altında, Nuxt sayfa klasörü yapına uyacak şekilde yer alır:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. `$t` ile şablon kullanımı

`.vue` dosyalarında `$t`'yi doğrudan şablonda kullanabilirsin:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
Anahtar, iç içe bir JSON düğümüne işaret ediyorsa `$t` **nesneler** döndürebilir (örn. `$t('header')` → `\{ title: "Hi" \}`). Şablonlarda bu `[object Object]` olarak render edilir. Garantili bir string'e ihtiyacın varsa `$ts`'yi kullan veya `$t('header.title')` gibi daha spesifik bir anahtar sağla. Ayrıntılar için [API referansı — $t ve $ts](/api/methods#t) sayfasına bak.
</Tip>

## 3. Geçerli yerel ayarı değiştirme

Uygulamandaki dilleri değiştirmek için `useI18n()`'den `$locale`'yi alıp yeni bir kod atayabilirsin:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. İç içe anahtarlar ve yer tutucular

- **İç içe anahtarlar** nokta gösterimi kullanır, örn. `nested.key.deeper`.
- **Yer tutucular** dinamik değerler eklemene olanak tanır:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. İpuçları ve en iyi uygulamalar

- **Çakışan anahtarlar**: Sayfaya özel dosya, kök seviyesindeki dosyayla aynı anahtarı içeriyorsa, sayfaya özel sürüm önceliklidir (kök çeviriler derleme zamanında temel olarak birleştirilir).
- **Sayfa dosyalarını devre dışı bırakma**: Sayfaya özel çevirileri kullanmak istemezsen, Nuxt yapılandırmanda `disablePageLocales: true` olarak ayarlayabilirsin. Bu durumda yalnızca `/locales/*.json` dosyaları kullanılır.
- **Doğrudan içe aktarma yok**: `import \{ useI18n \} from 'nuxt-i18n-micro'` yapmana gerek yoktur; modülün otomatik enjeksiyon özelliği bunu senin için halleder.

Bu kadar. Bu adımlarla kök seviyesi veya sayfaya özel JSON dosyalarından çevirileri **hızlıca almaya** ve `$t` ile Nuxt uygulamanda **göstermeye** başlayabilirsin.

## Ek kaynaklar

Daha gelişmiş özellikleri keşfetmek için şunlara mutlaka göz at:

1. **`<i18n-t>` bileşeni**  
   `<i18n-t>` bileşeni, özellikle iç içe eleman içeren durumlar, gelişmiş yer tutucu kullanımı ve daha karmaşık çeviri yapıları için `$t`'ye güçlü bir alternatiftir.

- **Belgeler**: [i18n-t](/api/components/i18n-t)

2. **`useI18n` composable'ı**  
   `useI18n` composable'ı; çevirileri yönetmek, yerel ayar değiştirmeyi, biçimlendirmeyi ve daha fazlasını işlemek için eksiksiz bir fonksiyon ve reaktif özellik seti sunar.

- **Belgeler**: [useI18n](/api/composables/use-i18n)
