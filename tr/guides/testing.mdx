# 🧪 `Nuxt I18n Micro` Modülünü Test Etme

## 📖 Test Etmeye Giriş

`Nuxt I18n Micro` modülünü test etmek, uygulamanızın yerelleştirme özelliklerinin beklendiği gibi çalıştığından emin olmak için çok önemlidir. Bu belgeler, test ortamını kurma, vitest için sahte yapılandırmalar oluşturma ve bileşenleriniz için testler yazma konusunda size rehberlik edecektir. Pratik bir örnek için, [GitHub'daki örnek projeye](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/test-utils/example) başvurabilirsiniz.

Bu deponun kendi paketlerini nasıl çalıştırdığı hakkında bilgi için [Yönlendirme stratejilerini test etme](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/testing-strategies.md) bölümüne bakın — `unit` / `integration` / `e2e` Vitest projeleri, strateji başına dosyalar (`test/strategies-*.test.ts`) ve regresyon oluşturma.

## 🛠️ Test Ortamını Kurma

### 1. `@i18n-micro/test-utils`'ı Kurun

Öncelikle, `Nuxt I18n Micro` için test yardımcı programlarını kurmanız gerekir. Bu paket, i18n yapılandırmalarınızı sahtelemek ve test etmek için gerekli araçları sağlar.

```bash
npm install @i18n-micro/test-utils --save-dev
```

### 2. Bir Sahte Yapılandırma Dosyası Oluşturun

Ardından, sahte i18n yapılandırmasını kurmak için bir dosya oluşturun. Bu dosya, testleriniz sırasında i18n işlevlerini ve yardımcı programlarını sahtelemek için kullanılacaktır.

```typescript
// tests/unit-setup.ts

import { mockNuxtImport } from '@nuxt/test-utils/runtime'
import { vi } from 'vitest'
import { i18nUtils } from '@i18n-micro/test-utils'

export function createFakeI18n() {
  return {
    $getLocale: vi.fn(i18nUtils.getLocale),
    $t: vi.fn(i18nUtils.t),
    $tc: vi.fn(i18nUtils.tc),
    $setLocale: vi.fn(i18nUtils.setLocale),
    $getLocaleName: vi.fn(i18nUtils.getLocaleName),
    $setLocaleName: vi.fn(i18nUtils.setLocaleName),
    $getLocales: vi.fn(i18nUtils.getLocales),
    $setLocales: vi.fn(i18nUtils.setLocales),
    $defaultLocale: vi.fn(i18nUtils.defaultLocale),
    $setDefaultLocale: vi.fn(i18nUtils.setDefaultLocale),
    $getRouteName: vi.fn(i18nUtils.getRouteName),
    $settRouteName: vi.fn(i18nUtils.settRouteName),
    $ts: vi.fn(i18nUtils.ts),
    $tn: vi.fn(i18nUtils.tn),
    $td: vi.fn(i18nUtils.td),
    $has: vi.fn(i18nUtils.has),
    $resolveTranslations: vi.fn(i18nUtils.resolveTranslations),
    $setTranslation: vi.fn(i18nUtils.setTranslation),
    $mergeTranslations: vi.fn(i18nUtils.mergeTranslations),
    $switchLocaleRoute: vi.fn(i18nUtils.switchLocaleRoute),
    $switchLocalePath: vi.fn(i18nUtils.switchLocalePath),
    $switchLocale: vi.fn(i18nUtils.switchLocale),
    $switchRoute: vi.fn(i18nUtils.switchRoute),
    $localeRoute: vi.fn(i18nUtils.localeRoute),
    $localePath: vi.fn(i18nUtils.localePath),
    $setI18nRouteParams: vi.fn(i18nUtils.setI18nRouteParams),
  }
}

mockNuxtImport<() => ReturnType<typeof createFakeI18n>>('useI18n', () => vi.fn(() => createFakeI18n()))

export const setTranslationsFromJson = i18nUtils.setTranslationsFromJson
```

### 3. Vitest'i Yapılandırın

Şimdi, sahte yapılandırma dosyasını kullanmak ve test ortamını kurmak için Vitest'i yapılandırın.

```typescript
// vitest.config.ts

import { defineVitestConfig } from '@nuxt/test-utils/config'

export default defineVitestConfig({
  test: {
    watch: false,
    setupFiles: ['./tests/unit-setup.ts'],
    include: ['./**/*.spec.ts'],
  },
})
```

## 🧪 Testler Yazma

### Örnek Bileşen

Mesajları çevirmek için `useI18n` composable'ı kullanan basit bir bileşen örneği:

```vue
<script setup lang="ts">
const { $t } = useI18n()

const props = defineProps({
  message: {
    type: String,
    default: null,
  },
})

// Test to see that $t works in script setup as well as the template
const message = props.message || $t('defaultMessage')
</script>

<template>
  <div>
    <p>Test from component: {{ $t('welcome') }}</p>
    <p data-testid="message">Test message from props: {{ message }}</p>
  </div>
</template>
```

### Test Dosyası

Şimdi, bu bileşen için bir test yazalım.

```typescript
// tests/unit/example.spec.ts

import { describe, it, expect, beforeEach } from 'vitest'
import { mount } from '@vue/test-utils'
import ExampleComponent from '@/components/ExampleComponent.vue'
import fs from 'fs'
import path from 'path'
import { setTranslationsFromJson } from './unit-setup'

describe('ExampleComponent', () => {
  beforeEach(async () => {
    const fileContent = fs.readFileSync(path.join(__dirname, '../../locales/en-GB.json')).toString()
    await setTranslationsFromJson('en', JSON.parse(fileContent))
  })

  it('renders the welcome message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.text()).toContain('Test from component: Welcome')
  })

  it('renders the default message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Default Message')
  })

  it('renders the custom message correctly', () => {
    const wrapper = mount(ExampleComponent, {
      props: {
        message: 'Custom Message',
      },
    })
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Custom Message')
  })
})
```

## 📝 Test Etme için En İyi Uygulamalar

- **🔧 i18n İşlevlerini Sahteleyin:** Tutarlı ve tahmin edilebilir test sonuçları sağlamak için her zaman `@i18n-micro/test-utils` kullanarak i18n işlevlerini sahteleyin.
- **⚙️ Birim Testleri için Vitest Kullanın:** Vitest, Vue uygulamaları için güçlü bir test çerçevesidir. Bileşenleriniz için birim testleri yazmak üzere kullanın.
- **📚 Testlerinizi Belgeleyin:** Her testin amacını ve beklenen sonuçlarını açıkça belgeleyin. Bu, netliği korumaya yardımcı olacak ve başkalarının (veya gelecekteki sizin) testleri anlamasını kolaylaştıracaktır.

## 📊 i18n Yardımcı Yöntemler

Aşağıda `@i18n-micro/test-utils` tarafından sağlanan tüm yardımcı yöntemleri açıklayan bir tablo bulunmaktadır.

| Yöntem                                          | Açıklama                                                                                                                                    |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `t(key, params, defaultValue)`                  | İsteğe bağlı parametreler ve varsayılan bir değerle bir anahtarı çevirir.                                                                   |
| `tc(key, params, defaultValue)`                 | Çoğullaştırma desteği ile bir anahtarı çevirir.                                                                                             |
| `setTranslationsFromJson(locale, translations)` | Belirli bir yerel ayar için bir JSON nesnesinden çevirileri yükler.                                                                         |
| `getLocale()`                                   | Geçerli yerel ayarı döndürür.                                                                                                               |
| `setLocale(val)`                                | Geçerli yerel ayarı belirler.                                                                                                               |
| `getLocaleName()`                               | Geçerli yerel ayar adını döndürür.                                                                                                          |
| `setLocaleName(val)`                            | Geçerli yerel ayar adını belirler.                                                                                                          |
| `getLocales()`                                  | Kullanılabilir yerel ayarların listesini döndürür.                                                                                          |
| `setLocales(val)`                               | Kullanılabilir yerel ayarların listesini belirler.                                                                                          |
| `defaultLocale()`                               | Varsayılan yerel ayarı döndürür.                                                                                                            |
| `setDefaultLocale(val)`                         | Varsayılan yerel ayarı belirler.                                                                                                            |
| `getRouteName()`                                | Geçerli rota adını döndürür.                                                                                                                |
| `settRouteName(val)`                            | Geçerli rota adını belirler.                                                                                                                |
| `ts(key, params, defaultValue)`                 | Bir anahtarı çevirir ve sonucu bir dize olarak döndürür.                                                                                    |
| `tn(value, options?)`                           | Satır içi `Intl.NumberFormatOptions` ile bir sayıyı biçimlendirir. Adlandırılmış formatlar modül yapılandırması gerektirir ve bu bağımsız yardımcıda mevcut değildir. |
| `td(value, options?)`                           | Satır içi `Intl.DateTimeFormatOptions` ile bir tarihi biçimlendirir. Adlandırılmış formatlar modül yapılandırması gerektirir ve bu bağımsız yardımcıda mevcut değildir. |
| `has(key)`                                      | Bir çeviri anahtarının var olup olmadığını kontrol eder.                                                                                    |
| `resolveTranslations()`                         | Geçerli yerel ayar ve rota için aktif çeviri ağacını döndürür.                                                                              |
| `setTranslation(key, value)`                    | Aktif sözlükteki `key`'deki değeri değiştirir (birleştirme değil, değiştirme).                                                              |
| `mergeTranslations(newTranslations)`            | Çevirileri çalışma zamanında aktif yerel ayara birleştirir.                                                                                 |

Bu adımları izleyerek, `Nuxt I18n Micro` modülünü etkin bir şekilde test edebilir ve uygulamanızın yerelleştirme özelliklerinin beklendiği gibi çalıştığından emin olabilirsiniz.
