# Statik dosyaları i18n yönlendirmesinden hariç tutma

## Genel bakış

Varsayılan olarak nuxt-i18n-micro, yaygın statik dosyaları i18n yönlendirme işlemesinden otomatik olarak hariç tutar. Bununla birlikte, belirli yolların i18n sistemi tarafından işlenmesini önlemek için özel dışlama desenleri de yapılandırabilirsin.

## Yerleşik dışlamalar

Modül aşağıdaki dosya türlerini ve desenleri otomatik olarak hariç tutar:

- **Site haritaları**: `/sitemap*.xml`, `/sitemap-en.xml` vb.
- **SEO dosyaları**: `/robots.txt`, `/favicon.ico`
- **PWA dosyaları**: `/manifest.json`, `/sw.js`, `/workbox-*.js`
- **Statik varlıklar**: Şu uzantılara sahip dosyalar: `.xml`, `.txt`, `.ico`, `.json`, `.js`, `.css`, `.png`, `.jpg`, `.jpeg`, `.gif`, `.svg`, `.woff`, `.woff2`, `.ttf`, `.eot`
- **Dahili Nuxt yolları**: `__` ile başlayan tüm yollar (`/__nuxt/` gibi)

## Özel dışlama desenleri

`excludePatterns` seçeneğini kullanarak özel dışlama desenleri tanımlayabilirsin:

```typescript
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],

  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'it', iso: 'it-IT' },
    ],
    defaultLocale: 'en',

    // Custom exclusion patterns
    excludePatterns: [
      // String patterns (exact match or prefix)
      '/api/health',
      '/admin',

      // String patterns with wildcards
      '/api/*',
      '/admin/**',

      // Regular expressions
      /^\/api\/v\d+\//,
      /\.(pdf|doc|docx)$/,
    ],
  },
})
```

## Desen türleri

### String desenleri

- **Tam eşleşme**: `'/api/health'`: tam olarak `/api/health` ile eşleşir
- **Önek eşleşmesi**: `'/admin'`: `/admin` ve `/admin/dashboard` ile eşleşir
- **Joker karakterler**: `'/api/*'`: `/api/users` ile eşleşir ama `/api/users/123` ile eşleşmez
- **Derin jokerler**: `'/admin/**'`: `/admin/users` ve `/admin/users/123` ile eşleşir

### Düzenli ifadeler

Karmaşık desen eşleşmesi için RegExp nesneleri kullan:

```typescript
excludePatterns: [
  /^\/api\/v\d+\//, // API versioned routes
  /\.(pdf|doc|docx)$/, // Document files
  /^\/static\//, // Static directory
  /^\/[a-z]{2}\/api\//, // Localized API routes
]
```

## Kullanım senaryoları

### SEO dosyaları

```typescript
excludePatterns: ['/sitemap.xml', '/sitemap-*.xml', '/robots.txt', '/favicon.ico']
```

### API rotaları

```typescript
excludePatterns: ['/api/**', '/graphql', '/webhook/**']
```

### Yönetim panelleri

```typescript
excludePatterns: ['/admin', '/admin/**', '/dashboard']
```

### Statik varlıklar

```typescript
excludePatterns: ['/assets/**', '/static/**', '/uploads/**']
```

## Nasıl çalışır

1. **Sunucu ara yazılımı**: Bir Nitro ara yazılımı önce çalışır ve dışlama desenlerini kontrol eder
2. **Sayfa işleme**: Sayfa çözümlemesi sırasında hariç tutulan yollar atlanır
3. **Yakala hepsi rotası**: Yedek rota, işlemeden önce dışlamaları kontrol eder
4. **Ön oluşturma**: Hariç tutulan yollar önceden oluşturulan rotalara dahil edilmez

## Performans etkisi

- Dışlama kontrolleri optimize edilmiştir ve istek yaşam döngüsünün erken evresinde çalışır
- Yerleşik desenler verimli regex eşleştirme kullanır
- Özel desenler önbelleklenir ve yeniden kullanılır
- Hariç tutulan yollar için minimum performans yükü

## Sorun giderme

### Statik dosyalar hâlâ ele geçiriliyor

1. **Desen sözdizimini kontrol et**: Desenlerinin tam yol yapısıyla eşleştiğinden emin ol
2. **Karmaşık desenler için regex kullan**: String jokerlerinin sınırlamaları vardır
3. **Desenleri test et**: Gerçek istek yolunu doğrulamak için tarayıcı geliştirici araçlarını kullan
4. **Sırayı kontrol et**: Dışlama desenlerinin diğer i18n yapılandırmasından önce tanımlandığından emin ol

### Desen çalışmıyor

```typescript
// ❌ Wrong - this won't work
excludePatterns: ['sitemap.xml']

// ✅ Correct - include leading slash
excludePatterns: ['/sitemap.xml']

// ✅ Better - use regex for flexibility
excludePatterns: [/^\/sitemap.*\.xml$/]
```

### Hata ayıklama modu

Dışlama işlemesini görmek için hata ayıklama modunu etkinleştir:

```typescript
i18n: {
  debug: true,
  excludePatterns: ['/api/**']
}
```

Bu, konsola dışlama kararlarını kaydeder.

## Geçici çözümlerden geçiş

Rota kuralları veya ara yazılım gibi geçici çözümler kullanıyorduysan, artık bunları `excludePatterns` ile değiştirebilirsin:

```typescript
// ❌ Old workaround
export default defineNuxtConfig({
  routeRules: {
    '/sitemap*.xml': { headers: { 'content-type': 'application/xml' } },
  },
})

// ✅ New approach
export default defineNuxtConfig({
  i18n: {
    excludePatterns: ['/sitemap*.xml'],
  },
})
```

Yeni yaklaşım daha güvenilirdir ve yönlendirme sisteminin birden fazla katmanında çalışır.
