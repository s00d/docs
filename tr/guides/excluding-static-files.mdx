# Statik Dosyaları i18n Yönlendirmesinden Hariç Tutma

## Genel Bakış

Varsayılan olarak, nuxt-i18n-micro yaygın statik dosyaları i18n yönlendirme işleminden otomatik olarak hariç tutar. Ancak, belirli yolların i18n sistemi tarafından işlenmesini önlemek için özel hariç tutma kalıpları da yapılandırabilirsiniz.

## Yerleşik Hariç Tutmalar

Modül aşağıdaki dosya türlerini ve kalıplarını otomatik olarak hariç tutar:

- **Site haritaları**: `/sitemap*.xml`, `/sitemap-en.xml` vb.
- **SEO dosyaları**: `/robots.txt`, `/favicon.ico`
- **PWA dosyaları**: `/manifest.json`, `/sw.js`, `/workbox-*.js`
- **Statik varlıklar**: `.xml`, `.txt`, `.ico`, `.json`, `.js`, `.css`, `.png`, `.jpg`, `.jpeg`, `.gif`, `.svg`, `.woff`, `.woff2`, `.ttf`, `.eot` gibi uzantılara sahip dosyalar
- **Dahili Nuxt yolları**: `__` ile başlayan herhangi bir yol (`/__nuxt/` gibi)

## Özel Hariç Tutma Kalıpları

`excludePatterns` seçeneğini kullanarak özel hariç tutma kalıpları tanımlayabilirsiniz:

```typescript
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],

  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'it', iso: 'it-IT' },
    ],
    defaultLocale: 'en',

    // Custom exclusion patterns
    excludePatterns: [
      // String patterns (exact match or prefix)
      '/api/health',
      '/admin',

      // String patterns with wildcards
      '/api/*',
      '/admin/**',

      // Regular expressions
      /^\/api\/v\d+\//,
      /\.(pdf|doc|docx)$/,
    ],
  },
})
```

## Kalıp Türleri

### Dize Kalıpları

- **Tam eşleşme**: `'/api/health'` - tam olarak `/api/health` ile eşleşir
- **Önek eşleşmesi**: `'/admin'` - `/admin` ve `/admin/dashboard` ile eşleşir
- **Joker karakterler**: `'/api/*'` - `/api/users` ile eşleşir ancak `/api/users/123` ile eşleşmez
- **Derin joker karakterler**: `'/admin/**'` - `/admin/users` ve `/admin/users/123` ile eşleşir

### Düzenli İfadeler

Karmaşık kalıp eşleştirmesi için RegExp nesnelerini kullanın:

```typescript
excludePatterns: [
  /^\/api\/v\d+\//, // API versioned routes
  /\.(pdf|doc|docx)$/, // Document files
  /^\/static\//, // Static directory
  /^\/[a-z]{2}\/api\//, // Localized API routes
]
```

## Kullanım Durumları

### SEO Dosyaları

```typescript
excludePatterns: ['/sitemap.xml', '/sitemap-*.xml', '/robots.txt', '/favicon.ico']
```

### API Rotaları

```typescript
excludePatterns: ['/api/**', '/graphql', '/webhook/**']
```

### Yönetim Panelleri

```typescript
excludePatterns: ['/admin', '/admin/**', '/dashboard']
```

### Statik Varlıklar

```typescript
excludePatterns: ['/assets/**', '/static/**', '/uploads/**']
```

## Nasıl Çalışır

1. **Sunucu Ara Yazılımı**: Hariç tutma kalıplarını kontrol etmek için önce bir Nitro ara yazılımı çalışır
2. **Sayfa İşleme**: Sayfa çözümlemesi sırasında hariç tutulan yollar atlanır
3. **Yakala-Tümü Rotası**: Yedek rota, işlemden önce hariç tutmaları kontrol eder
4. **Ön İşleme**: Hariç tutulan yollar, önceden render edilmiş rotalara dahil edilmez

## Performans Etkisi

- Hariç tutma kontrolleri optimize edilmiştir ve istek yaşam döngüsünde erken çalışır
- Yerleşik kalıplar verimli regex eşleştirmesi kullanır
- Özel kalıplar önbelleğe alınır ve yeniden kullanılır
- Hariç tutulan yollar için minimum performans yükü

## Sorun Giderme

### Statik Dosyalar Hâlâ Yakalanıyor

1. **Kalıp sözdizimini kontrol edin**: Kalıplarınızın tam yol yapısıyla eşleştiğinden emin olun
2. **Karmaşık kalıplar için regex kullanın**: Dize joker karakterlerinin sınırlamaları vardır
3. **Kalıpları test edin**: Gerçek istek yolunu doğrulamak için tarayıcı geliştirici araçlarını kullanın
4. **Sırayı kontrol edin**: Hariç tutma kalıplarının diğer i18n yapılandırmasından önce tanımlandığından emin olun

### Kalıp Çalışmıyor

```typescript
// ❌ Wrong - this won't work
excludePatterns: ['sitemap.xml']

// ✅ Correct - include leading slash
excludePatterns: ['/sitemap.xml']

// ✅ Better - use regex for flexibility
excludePatterns: [/^\/sitemap.*\.xml$/]
```

### Hata Ayıklama Modu

Hariç tutma işlemini görmek için hata ayıklama modunu etkinleştirin:

```typescript
i18n: {
  debug: true,
  excludePatterns: ['/api/**']
}
```

Bu, hariç tutma kararlarını konsola günlüğe kaydeder.

## Geçici Çözümlerden Geçiş

Rota kuralları veya ara yazılım gibi geçici çözümler kullanıyorduysanız, bunları artık `excludePatterns` ile değiştirebilirsiniz:

```typescript
// ❌ Old workaround
export default defineNuxtConfig({
  routeRules: {
    '/sitemap*.xml': { headers: { 'content-type': 'application/xml' } },
  },
})

// ✅ New approach
export default defineNuxtConfig({
  i18n: {
    excludePatterns: ['/sitemap*.xml'],
  },
})
```

Yeni yaklaşım daha güvenilirdir ve yönlendirme sisteminin birden fazla düzeyinde çalışır.
