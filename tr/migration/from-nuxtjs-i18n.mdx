# 🔄 `nuxt-i18n`'den `Nuxt I18n Micro`'ya Geçiş

## Hangi kılavuza ihtiyacınız var?

| Şuradan geçiyorsunuz…                  | Kılavuz                                          |
| -------------------------------------- | ------------------------------------------------ |
| `@nuxtjs/i18n` (vue-i18n tabanlı modül) | **Bu sayfa**                                     |
| `nuxt-i18n-micro` v2.x                 | [v2.x'ten v3.x'e Yükseltme](/migration/v2-to-v3) |

## Neden Geçmeli?

- **Gelişmiş performans**: [kıyaslama fixtürlerimizde](/guides/performance-results) `@nuxtjs/i18n` **v10.6**'ya karşı ~51% daha hızlı derleme ve ~54% daha az derleme belleği
- **Basitleştirilmiş yapılandırma**: Mantıklı varsayılanlarla sadeleştirilmiş kurulum
- **Daha iyi kaynak yönetimi**: Büyük çeviri dosyalarının optimize edilmiş işlenmesi

## Ana Farklılıklar

| Özellik                 | `nuxt-i18n`                      | `Nuxt I18n Micro`                         |
| ----------------------- | -------------------------------- | ----------------------------------------- |
| Çeviri dosyaları        | `vueI18n` aracılığıyla yüklenen JS/TS/JSON | Yalnızca JSON, geliştirmede otomatik oluşturulur |
| Rota oluşturma          | Çalışma zamanı                   | Derleme zamanı (`@i18n-micro/route-strategy`) |
| Çeviri yükleme          | JS'ye paketlenmiş                | Sayfa başına tembel yüklenen JSON         |
| Yerel ayar durumu       | `vue-i18n`'den `useI18n()`       | `useI18nLocale()` composable              |
| `detectBrowserLanguage` | Desteklenir                      | Bunun yerine `autoDetectLanguage` kullanın |

## Adım Adım

### 1. Kurulum

```bash
npm install nuxt-i18n-micro
```

### 2. Yapılandırmayı Güncelleyin

**Önce (nuxt-i18n):**

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'fr', iso: 'fr-FR' },
    ],
    defaultLocale: 'en',
    vueI18n: './i18n.config.js',
    detectBrowserLanguage: { useCookie: true },
  },
})
```

**Sonra (Nuxt I18n Micro v3):**

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
    localeCookie: 'user-locale',
    autoDetectLanguage: true,
  },
})
```

### 3. Çeviri Dosyalarını Yeniden Düzenleyin

Çevirileri JSON formatında `locales` dizinine taşıyın. İşte tam bir proje karşılaştırması:

**Before (`nuxt-i18n`):**

```text
my-app/
├── i18n/
│   └── locales/          # langDir
│       ├── en.json       # all translations in one file
│       ├── ru.json
│       └── de.json
├── pages/
│   ├── index.vue
│   └── page.vue
├── server/
│   └── tsconfig.json
├── nuxt.config.ts        # config will change
└── package.json
```

**After (Nuxt I18n Micro):**

```text
my-app/
├── locales/              # translationDir
│   ├── en.json           # root-level translations
│   ├── ru.json
│   ├── de.json
│   └── pages/            # page-specific
│       ├── index/
│       │   ├── en.json
│       │   ├── ru.json
│       │   └── de.json
│       └── page/
│           ├── en.json
│           ├── ru.json
│           └── de.json
├── pages/
│   ├── index.vue         # API changes
│   └── page.vue
├── server/
│   └── tsconfig.json
├── nuxt.config.ts        # new config
└── package.json
```

<Tip>
Missing page-specific translation files are **auto-generated** in development mode — just run `nuxt dev` and the module will create empty JSON files for each page and locale.
</Tip>

### 4. Gezinmeyi Güncelleyin

```diff
- <nuxt-link :to="{ name: 'index' }">Home</nuxt-link>
+ <NuxtLink :to="$localeRoute({ name: 'index' })">Home</NuxtLink>
+ <!-- or use the built-in component -->
+ <i18n-link :to="{ name: 'index' }">Home</i18n-link>
```

### 5. SEO'yu Güncelleyin

`nuxt-i18n`'den manuel SEO yapılandırmalarını kaldırın. Nuxt I18n Micro, `meta: true` ayarlandığında `hreflang`, canonical URL'ler ve Open Graph etiketlerini otomatik olarak oluşturur.

### 6. Test Edin

Çevirileri, yerel ayar değiştirmeyi, yönlendirmeleri ve SEO meta etiketlerini kapsamlı bir şekilde test edin.

## 🛡️ Yaygın Sorunlar ve Sorun Giderme

### ❌ Çeviri Dosyaları Yüklenmiyor

Çeviri dosyalarının doğru dizinde olduğundan ve JSON formatını izlediğinden emin olun. `translationDir`'in dosya konumunuzla eşleştiğini doğrulayın.

### ⚠️ Rota Bulunamadı Hataları

`locales` dizisindeki tüm yerel ayar kodlarının doğru olduğunu ve rotaların düzgün kurulduğunu kontrol edin.

### 🏷️ Eksik SEO Etiketleri

`meta: true`'nun ayarlandığını ve her yerel ayarın geçerli bir `iso` koduna sahip olduğunu doğrulayın.

### 🔄 Hidrasyon Uyumsuzlukları

`no_prefix` stratejisi kullanılıyorsa, sunucu ve istemcinin yerel ayarda anlaşmasını sağlamak için `useI18nLocale().setLocale()` kullanarak `order: -10` olan bir sunucu eklentisinde yerel ayarı ayarlayın. [Özel Dil Algılama](/guides/custom-language-detection) bölümüne bakın.

### 🍪 Yönlendirmeler Çalışmıyor

Önek stratejileri için `localeCookie: 'user-locale'`'nin ayarlandığından emin olun. Bir çerez olmadan, sunucu yönlendirme eklentisinin sayfa yeniden yükloads.
