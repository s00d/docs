`nuxt dev` ortamında modül iki hata ayıklama yardımcısı ekler: çeviri dosyalarına göz atmak ve bunları düzenlemek için Nuxt DevTools'ta bir **i18n Micro** sekmesi ve canlı locale ile yüklenmiş sözlükler için bir Vue DevTools denetçisi. Her ikisi de yalnızca geliştirme ortamında bulunur ve üretim derlemelerine hiçbir şey eklemez. Nuxt sekmesi yalnızca Nuxt DevTools'un etkin olmasını gerektirir; Vue denetçisi ayrıca Vue DevTools tarayıcı eklentisine ihtiyaç duyar.

## Nuxt DevTools sekmesi {#nuxt-devtools-tab}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  devtools: { enabled: true }, // the tab is registered only when DevTools are on
})
```

Nuxt DevTools'u açın (`Shift + Alt + D`) ve **i18n Micro** sekmesini seçin. Sekme şunları gösterir:

- her katmanın `locales/` (kök ve `pages/`) altındaki her JSON dosyası ile `additionalTranslationDirs` içindeki kök dosyalar;
- dosya başına bir düzenleyici; **Save** dosyayı diske geri yazar ve geliştirme sunucusu çevirileri yeniden yükler;
- bir dosyanın JSON olarak **Export** / **Import** işlemleri ve anahtar sayıları ile çeviri kapsamını gösteren **Stats**;
- çözümlenmiş modül seçeneklerinin bir yapılandırma görünümü;
- eksik anahtarları, sekmenin ayarlarında yapılandırdığınız bir makine çevirisi motoruyla dolduran **Translate**.

Kaydetme yalnızca çeviri dizinlerinizdeki mevcut `.json` dosyalarına yazar. Bir dosya birden fazla katmanda bulunduğunda projenin kopyası yazılır.

## Vue DevTools denetçisi {#vue-devtools-inspector}

Vue DevTools tarayıcı eklentisiyle modül bir i18n denetçisi (mevcut locale, rota parçası, yüklenmiş anahtarlar) ve locale değişiklikleri, parça yüklemeleri ve eksik anahtarları içeren bir zaman çizelgesi kaydeder.

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    debug: true, // also log every $t / $ts / $tc call on the timeline
    // vueDevtools: false, // turn the inspector off, keep the Nuxt tab
  },
})
```

[`vueDevtools`](/tr/api/module-options) varsayılan olarak `true` değerindedir. `debug: true` ayrıntılı çıktı üretir; kısa oturumlar için kullanın.

## Nuxt dışında {#outside-nuxt}

Aynı arayüz, framework paketleri üzerine kurulu Vite uygulamaları için [`@i18n-micro/devtools-ui`](/tr/integrations/devtools-ui-package) olarak yayımlanır; kurulum için o sayfaya bakın.
