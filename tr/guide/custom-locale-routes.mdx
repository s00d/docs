title: "Yerelleştirilmiş yollar"
description: "localeRoutes veya globalLocaleRoutes ile bir sayfaya, dinamik parametreler ve locale bazlı slug'lar dahil olmak üzere her locale için farklı bir URL verin."
---

Varsayılan olarak her locale bir sayfayı aynı yolda sunar: `/en/about`, `/de/about`. Yerelleştirilmiş yollar, sayfa dosyası aynı kalırken her locale'in kendi kelimelerini kullanmasına olanak tanır; örneğin `/de/ueber-uns`. Bunları sayfanın içinde `$defineI18nRoute` ile veya birçok sayfa için tek seferde `nuxt.config.ts` içinde ayarlarsınız.

## Sayfanın içinde {#in-the-page}

```vue
<!-- pages/about.vue -->
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  localeRoutes: {
    de: '/ueber-uns',
    fr: '/a-propos',
  },
})
</script>
```

`prefix_except_default` ve `defaultLocale: 'en'` ile sayfa `/about`, `/de/ueber-uns` ve `/fr/a-propos` adreslerinde yanıt verir. Girdisi olmayan bir locale varsayılan yolu korur. Yolları locale kodu olmadan yazın: önek [strateji](/tr/guide/strategy) tarafından eklenir ve locale koduyla başlayan bir yol uyarı kaydeder. Çağrının kabul ettiği diğer şeyler [Sayfa yapılandırması](/tr/guide/per-component-translations) sayfasındadır.

## nuxt.config içinde {#in-nuxt-config}

[`globalLocaleRoutes`](/tr/api/module-options#globallocaleroutes) aynı işi herhangi bir sayfa için yapar; anahtar olarak sayfanın yolu (veya başında eğik çizgi olmadan yazıldığında rota adı) kullanılır:

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    globalLocaleRoutes: {
      '/about': { de: '/ueber-uns' },
      '/about/team': { de: '/ueber-uns/team' },
      '/admin': false, // not localized: one /admin route, no locale prefix
    },
  },
})
```

Bir sayfa `localeRoutes` ayarladığında ve `globalLocaleRoutes` aynı anahtara sahip olduğunda, yapılandırmadaki girdi geçerli olur.

## Dinamik parametreler {#dynamic-params}

Parametreleri herhangi bir Nuxt biçiminde yazın: `[id]`, `[[page]]`, `[...slug]` veya `:id()`. Parametre adları sayfa dosyasıyla eşleşmelidir.

```ts
// pages/products/[...slug].vue
$defineI18nRoute({
  localeRoutes: {
    en: '/our-products/[...slug]',
    de: '/unsere-produkte/[...slug]',
  },
})
```

İç içe sayfalar mutlak bir alt yol (`/ueber-uns/team`) veya üst sayfanın yerelleştirilmiş yoluna göreli bir yol (`team`) alır.

## Yerelleştirilmiş sayfalara bağlantı verme {#linking-to-localized-pages}

Bağlantılar, ister bir rota adı ister düz bir yol verin, hedef locale'in yerelleştirilmiş yoluna çözümlenir:

```vue
<template>
  <i18n-link :to="{ name: 'about' }">About</i18n-link>
  <i18n-link to="/about">About</i18n-link>
  <!-- de: both render /de/ueber-uns -->
  <NuxtLink :to="$localePath('/about', 'de')">Deutsch</NuxtLink>
</template>
```

Rota adları, `definePageMeta({ name })` ile bir ad belirlemediğiniz sürece dosya yolundan gelir (`pages/about/team.vue`, `about-team` olur).

## Locale bazlı slug'lar {#per-locale-slugs}

Slug'ın kendisi locale'e göre farklı olduğunda (`/our-products/red-shoe` ve `/de/unsere-produkte/roter-schuh`), veriler yüklendikten sonra dil değiştiriciye hangi parametreleri kullanacağını `$setI18nRouteParams` ile bildirin:

```vue
<script setup lang="ts">
const { $setI18nRouteParams } = useNuxtApp()
const route = useRoute()

const { data: product } = await useFetch(`/api/products/${route.params.slug}`)

if (product.value) {
  $setI18nRouteParams({
    en: { slug: product.value.slugEn },
    de: { slug: product.value.slugDe },
  })
}
</script>
```

Ardından `$switchLocalePath('de')` ve `<i18n-switcher>`, `/de/unsere-produkte/roter-schuh` adresine bağlantı verir. Anahtarlar locale kodlarıdır, değerler ise ada göre parametrelerdir (sayfa dosyasındaki gibi).

Layout içindeki bir değiştirici, sayfanın asenkron setup'ı bu noktaya gelmeden önce render edilir; bu nedenle render bittiğinde modül `<i18n-switcher>` bağlantılarını hem `app.vue` içinde hem de sayfada yeniden yazar. Böylece sunucu HTML'i, JavaScript'i olmayan bir ziyaretçi ve ilk istemci render'ı aynı sonucu verir. Bunun için parametreleri SSR sırasında ayarlayın: `lazy` veya `server: false` ile bağlantılar yalnızca hydration'dan sonra değişir. Nuxt'ın SSR streaming özelliği HTML'i parametreler bilinmeden önce gönderir, bu nedenle bu durumda ilk HTML'deki bağlantılar URL'nin kendi parametrelerini korur.

Yalnızca değiştiricinin kendi bağlantıları yeniden yazılır. Elle yazılmış bir `$switchLocalePath` bağlantısı, parametreler ayarlandıktan sonra render edilmelidir; bu yüzden onu parametreleri ayarlayan sayfaya, yine bir `await` sonrasına koyun. Bir layout içinde önce render edilir: sunucu HTML'i URL'nin parametrelerini korur ve hydration bir uyumsuzluk uyarısı verir. Orada görünüm için slot'ları ve `custom*Style` prop'larıyla birlikte `<i18n-switcher>` kullanın.

Parametreler onları ayarlayan sayfaya aittir:

- Başka bir yola yapılan gezinme tamamlandığında kaldırılırlar, bu nedenle her sayfa kendi parametrelerini ayarlar. İptal edilen bir gezinme onları yerinde bırakır.
- `$setI18nRouteParams` fonksiyonunu, daha sonra bir `useAsyncData` işleyicisinde çağırsanız bile, `setup` içinde `useNuxtApp()` veya `useI18n()` üzerinden alın. Orada alındığında fonksiyon kendi sayfasını bilir: ziyaretçi sayfadan ayrıldıysa geç yapılan bir çağrı hiçbir şey yapmaz.
- `keepalive` ile bir sayfa, ziyaretçi geri döndüğünde ayarladığı parametreleri geri alır. `useI18nHead` de aynısını yapar.

## pages:extend içinde eklenen rotalar {#routes-added-in-pages-extend}

`pages:extend` hook'unda eklediğiniz rotaların `$defineI18nRoute` okunacak bir sayfa dosyası yoktur ve bunların birçoğu genellikle tek bir sarmalayıcı bileşeni paylaşır. `name` olmadan eklenen bir rota, Nuxt'ın yoluna vereceği adı alır (`/a/:id()`, `a-id` olur); böylece dil bağlantıları ona ulaşır, ancak başka bir rota zaten bu ada sahipse bu durumda ona açık bir `name` verin. Tek bir liste tutun ve onu `@i18n-micro/utils/split-locale-routes` içindeki `splitLocaleRoutes` ile sayfalara ve rota adına göre anahtarlanmış `globalLocaleRoutes` yapısına ayırın (paketi bağımlılıklarınıza ekleyin):

```ts
// nuxt.config.ts
import { splitLocaleRoutes } from '@i18n-micro/utils/split-locale-routes'

const dynamic = splitLocaleRoutes([
  { name: 'products-tag', path: '/products/:tag', file: '~/pages/_dynamic.vue', paths: { de: '/produkte/:tag' } },
  { name: 'internal', path: '/internal', file: '~/pages/_dynamic.vue', paths: false }, // not localized
])

export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  hooks: {
    'pages:extend'(pages) {
      pages.push(...dynamic.pages)
    },
  },
  i18n: {
    globalLocaleRoutes: dynamic.globalLocaleRoutes,
  },
})
```

Yerelleştirilmiş yolları `route.meta` içine koymayın: istemci rota tablosuyla birlikte gönderilirler.
