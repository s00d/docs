Bu sayfa bir `@nuxtjs/i18n` uygulamasını nuxt-i18n-micro'ya eşler: seçenekler, yardımcılar ve dosya düzeni. Mevcut bir uygulamada modülü değiştirirken kullanın. URL'lerinizi korursunuz (strateji adları aynıdır) ve çevirileri sayfa başına JSON dosyalarına taşırsınız.

<Tip>

**nuxt-i18n-micro'nun kendisini mi yükseltiyorsunuz?** — Bkz. [Yükseltme](/tr/guide/upgrade).

</Tip>

## Modülü değiştirin {#swap-the-module}

```bash
npm uninstall @nuxtjs/i18n
npm install nuxt-i18n-micro
```

```ts
// nuxt.config.ts — before
export default defineNuxtConfig({
  modules: ['@nuxtjs/i18n'],
  i18n: {
    locales: [
      { code: 'en', language: 'en-US', file: 'en.json' },
      { code: 'de', language: 'de-DE', file: 'de.json' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    langDir: 'locales',
    detectBrowserLanguage: { useCookie: true, cookieKey: 'i18n_redirected', redirectOn: 'root' },
  },
})
```

```ts
// nuxt.config.ts — after
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    translationDir: 'locales',
    localeCookie: 'i18n_redirected',
    autoDetectPath: '/',
  },
})
```

## Seçenekler {#options}

| `@nuxtjs/i18n` | nuxt-i18n-micro |
| --- | --- |
| `locales[].code` | `locales[].code` |
| `locales[].language` (v9 öncesinde `iso`) | `locales[].iso` |
| `locales[].name` | `locales[].displayName` |
| `locales[].dir` | `locales[].dir` |
| `locales[].domain` | `locales[].baseUrl` (şemasıyla birlikte bir origin) |
| `locales[].domainDefault` | `locales[].baseDefault` |
| `differentDomains`, `multiDomainLocales` | gerekli değil: tek başına `baseUrl` host'a göre yönlendirir, bkz. [Katmanlar ve alan adları](/tr/guide/layers#multiple-domains) |
| `locales[].file` / `files`, `langDir`, `lazy` | `translationDir`; dosyalar adlarına göre bulunur ve her zaman sayfa başına yüklenir |
| `defaultLocale`, `strategy` | aynı adlar, aynı dört değer |
| `baseUrl` | `metaBaseUrl` |
| `customRoutes: 'config'` + `pages` | `globalLocaleRoutes` |
| `detectBrowserLanguage: false` | `redirects: false` (yönlendirme yok) veya `autoDetectLanguage: false` (başlığı yok say) |
| `detectBrowserLanguage.useCookie` / `cookieKey` | `localeCookie: '<name>'` (`null` çerezi kapatır) |
| `detectBrowserLanguage.redirectOn: 'root'` | `autoDetectPath: '/'` (varsayılan) |
| `detectBrowserLanguage.redirectOn: 'no prefix'` | `autoDetectPath: 'no_prefix'` |
| `detectBrowserLanguage.redirectOn: 'all'` | `autoDetectPath: '*'` |
| `vueI18n` yapılandırma dosyası (`fallbackLocale`, `numberFormats`, `datetimeFormats`) | `i18n` içinde `fallbackLocale`, `numberFormats`, `datetimeFormats` |

`alwaysRedirect` yoktur: bir çerez ayarlandığında `/` her ziyarette onu takip eder. Tam liste [Modül seçenekleri](/tr/api/module-options) sayfasındadır; algılama kuralları [Yerel ayar algılama](/tr/guide/locale-detection) sayfasındadır.

## Yardımcılar ve composable'lar {#helpers-and-composables}

| `@nuxtjs/i18n` / vue-i18n | nuxt-i18n-micro (şablon / `useI18n()`) |
| --- | --- |
| `const { t } = useI18n()` | `const { t } = useI18n()`, şablonlarda `$t` |
| `t('key', count)`, `tc` | `$tc('key', count)` |
| `te('key')` | `$has('key')` |
| `n(value, 'currency')`, `d(date, 'short')` | `$tn(value, 'currency')`, `$td(date, 'short')` |
| — | `$tdr(date)`: göreli zaman ("3 gün içinde") |
| `locale.value` | `$getLocale()` |
| `locales.value` | `$getLocales()` |
| `setLocale('de')` | `$switchLocale('de')` |
| `useLocalePath()('about')` | `$localePath({ name: 'about' })` |
| `useLocaleRoute()` | `$localeRoute()` |
| `useSwitchLocalePath()('de')` | `$switchLocalePath('de')` |
| `useSetI18nParams()` | `$setI18nRouteParams()` |
| `useLocaleHead()` | `meta: true` ile otomatik; özel head'ler için [`useLocaleHead`](/tr/composables/useLocaleHead) |
| `defineI18nRoute({ paths: { de: '/ueber-uns' }, locales: [...] })` | `$defineI18nRoute({ localeRoutes: { de: '/ueber-uns' }, locales: [...] })` |
| `<NuxtLinkLocale to="about">` | `<i18n-link :to="{ name: 'about' }">` |
| `<i18n-t>` | `<i18n-t>` (slot'lar `{name}` yer tutucularını doldurur) |
| sunucu rotalarında `$i18n` | `useTranslationServerMiddleware(event)`, bkz. [Sunucu rotaları ve API](/tr/guide/server-side-translations) |

`useI18n()` otomatik olarak içe aktarılır. `$defineI18nRoute` `$` işaretini korumalıdır: derleme bu çağrıyı okur. Tüm yardımcılar: [Metotlar](/tr/api/methods).

## Çeviri dosyaları {#translation-files}

Yerel ayar başına tek büyük dosyadaki anahtarları bir kök dosyaya ve sayfa başına bir dosyaya taşıyın:

```text
locales/
├── en.json              # keys used on many pages (nav, footer)
├── de.json
└── pages/
    ├── index/en.json    # keys of pages/index.vue
    └── about/en.json    # keys of pages/about.vue
```

Her şeyi kök dosyalarda tutmak da işe yarar ve en hızlı ilk adımdır. Onları bölene kadar `disablePageLocales: true` ayarlayın. Bkz. [Çeviri dosyaları](/tr/guide/translations).

### Mesaj sözdizimi {#message-syntax}

| vue-i18n | nuxt-i18n-micro |
| --- | --- |
| `{name}` adlandırılmış interpolasyon | aynı |
| `car \| cars` (2 biçim: 1 → ilki) | biçimler 0'dan başlayarak sayıya göre seçilir: `no cars \| one car \| {count} cars` yazın |
| `@:other.key` bağlantılı mesajlar | desteklenmez: metni tekrarlayın veya kodda birleştirin |
| `@.upper:` değiştiricileri | desteklenmez: kodda biçimlendirin veya `<i18n-t>` kullanın |
| `{'@'}` literal kaçışları | gerekli değil: yalnızca `{word}` token'ları değiştirilir |
| JS/TS mesaj dosyaları | yalnızca JSON |

Çoğul kuralı [`plural`](/tr/api/module-options#plural) seçeneğiyle değiştirilebilir.

## Geçişten sonra kontrol edin {#check-after-the-switch}

- Sahip olduğunuz her URL hâlâ çözümleniyor; strateji adları eşleşir, özel yollar `globalLocaleRoutes` veya `$defineI18nRoute`'a taşınır.
- `hreflang`, canonical ve `og:locale`, `meta: true` ile kutudan çıktığı gibi gelir; elle yazılanları kaldırın.
- Bir JSON ayrıştırma hatası dosya yolunu günlüğe yazar; eksik bir anahtar geliştirme ortamında tarayıcı konsolunda bir uyarı yazar.
