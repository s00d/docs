Bu sayfa, i18n içermeyen bir Nuxt uygulamasını dil değiştiricisi olan çevrilmiş bir sayfaya taşır. Buna bir projenin başında yalnızca bir kez ihtiyacınız olur. Sonunda yerelleştirilmiş URL'lere (`/about`, `/de/about`), her locale ve sayfa için bir JSON dosyasına ve şablonlarınızda `$t`'ye sahip olursunuz.

## Kurulum {#install}

Modül Nuxt 3.18 veya daha yenisini (Nuxt 4 de çalışır) ve Node 20 veya daha yenisini gerektirir.

<CodeGroup>

```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>

## Locale'leri yapılandırın {#configure-the-locales}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', displayName: 'English' },
      { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
      { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
    ],
    defaultLocale: 'en',
  },
})
```

İlk uygulamanın ihtiyaç duyduğu yapılandırmanın tamamı budur. Varsayılanlar size şunları sağlar:

- `strategy: 'prefix_except_default'`: varsayılan locale'in öneki yoktur (`/about`), diğerlerinin vardır (`/de/about`). Bkz. [Yönlendirme stratejileri](/tr/guide/strategy).
- `translationDir: 'locales'`: çeviri dosyaları, Nuxt 4 `app/` düzeninde de proje kökündeki `locales/` dizininde bulunur.
- `meta: true`: `hreflang`, canonical ve `og:locale` etiketleri, ayrıca `<html>` üzerinde `lang` ve `dir`. Bkz. [SEO](/tr/guide/seo).
- `/` adresini açan bir ziyaretçi, tarayıcısının istediği dile (`Accept-Language`) gönderilir. Bkz. [Locale algılama](/tr/guide/locale-detection).

`iso`, SEO etiketlerinde kullanılan dil etiketidir; `code` ise URL'de görünen değerdir. Tüm seçenekler [Modül seçenekleri](/tr/api/module-options) sayfasında listelenmiştir.

## Çeviri dosyaları ekleyin {#add-translation-files}

Geliştirme sunucusunu `nuxt dev` ile başlatın. Nuxt sayfaları çözümlediğinde modül, dosyası olmayan her locale ve sayfa için boş bir `{}` dosyası oluşturur (bunu [`disableWatcher`](/tr/api/module-options#disablewatcher) ile kapatabilirsiniz):

```text
locales/
├── en.json            # root: keys every page can use
├── de.json
├── fr.json
└── pages/
    ├── index/         # pages/index.vue
    │   ├── en.json
    │   ├── de.json
    │   └── fr.json
    └── about/         # pages/about.vue
        ├── en.json
        ├── de.json
        └── fr.json
```

Kök dosyayı ve bir sayfa dosyasını doldurun:

```json
// locales/en.json
{ "nav": { "home": "Home", "about": "About" } }
```

```json
// locales/pages/index/en.json
{ "welcome": "Welcome, {name}!", "items": "no items | one item | {count} items" }
```

Bir sayfa kök anahtarları ve kendi anahtarlarını görür; çakışma durumunda kendi dosyası kazanır. Klasör adları rota adını izler (`pages/articles/[id].vue` için `locales/pages/articles-id/`). [Çeviri dosyaları](/tr/guide/translations) düzeni, yedekleri ve yüklemeyi ele alır.

## Bir sayfada `$t` kullanın {#use-$t-on-a-page}

```vue
<!-- pages/index.vue -->
<script setup lang="ts">
const { t, tc, getLocale } = useI18n()

const title = t('nav.home') // 'Home'
</script>

<template>
  <h1>{{ $t('welcome', { name: 'Ada' }) }}</h1>
  <!-- Welcome, Ada! -->
  <p>{{ $tc('items', 3) }}</p>
  <!-- 3 items -->
  <p>{{ getLocale() }}</p>
  <!-- en -->
</template>
```

- Şablonlarda her yardımcı `$` ile kullanılabilir (`$t`, `$tc`, `$localePath`, …).
- `<script setup>` içinde `useI18n()` aynı yardımcıları `$` ile ve `$` olmadan döndürür (`t` ve `$t` aynı fonksiyondur). Otomatik olarak içe aktarılır.
- `{name}` yer tutucuları params nesnesinden doldurulur. Çoğul biçimler `|` ile ayrılır; sayı biçimi seçer (0, 1, ardından daha büyük her şey için sonuncusu).

Tüm yardımcılar [Metotlar](/tr/api/methods) sayfasında listelenmiştir.

## Sayfalar arasında bağlantı kurun ve locale değiştirin {#link-between-pages-and-switch-locale}

```vue
<!-- components/AppHeader.vue -->
<template>
  <nav>
    <i18n-link :to="{ name: 'index' }">{{ $t('nav.home') }}</i18n-link>
    <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
    <i18n-switcher />
  </nav>
</template>
```

- [`<i18n-link>`](/tr/components/i18n-link), geçerli locale'deki sayfayı gösteren bir `NuxtLink`'tir: `/de` üzerindeyken about bağlantısı `/de/about` adresine gider.
- [`<i18n-switcher>`](/tr/components/i18n-switcher), etkin locale'lerin açılır listesidir; ziyaretçiyi aynı sayfada tutar.
- Kendi düğmeleriniz için `$switchLocale('de')` çağırın; bu, geçerli sayfanın Almanca sürümüne gider ve seçimi hatırlar. Düz bir `NuxtLink` için `$localePath({ name: 'about' })` veya `$switchLocalePath('de')` kullanın.

## Kontrol edin {#check-it}

`nuxt dev` çalıştırın ve şunları açın:

| URL | Gösterilen |
| --- | --- |
| `/` | İngilizce ana sayfa (veya tarayıcınız Almancayı tercih ediyorsa `/de` adresine yönlendirme) |
| `/de` | Almanca ana sayfa |
| `/de/about` | Almanca about sayfası |
| `/en/about` | 404: `prefix_except_default` altında varsayılan locale'in öneki yoktur |

JSON dosyalarındaki düzenlemeler, açık sayfada yeniden yükleme olmadan uygulanır.
