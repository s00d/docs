`useI18n()` çağıran bileşenler, birim testlerinde bir i18n örneğine ihtiyaç duyar. `@i18n-micro/test-utils`, gerçek çeviri, çoğullama ve biçimlendirme mantığına sahip sahte bir `useI18n()` sağlar; böylece bir bileşeni kendi sözlüklerinizle ve Nuxt sunucusu olmadan bağlayabilirsiniz. Yönlendirme ve yönlendirmeler (redirect) için gerçek modülü `@nuxt/test-utils` ile uçtan uca çalıştırın.

Bu sayfa uygulamanızı test etmekle ilgilidir. Bu deponun modülün kendisini nasıl test ettiği [Modülü test etme](https://s00d.github.io/nuxt-i18n-micro/contributing/testing) sayfasında anlatılır.

## Kurulum {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/test-utils @nuxt/test-utils vitest @vue/test-utils happy-dom
```

```bash npm
npm install -D @i18n-micro/test-utils @nuxt/test-utils vitest @vue/test-utils happy-dom
```

</CodeGroup>

## useI18n'i taklit etme {#mock-usei18n}

```ts
// tests/unit-setup.ts
import { setupNuxtI18nMock } from '@i18n-micro/test-utils'
import { mockNuxtImport } from '@nuxt/test-utils/runtime'
import { beforeEach, vi } from 'vitest'

export const { i18n, useI18n, setTranslationsFromJson } = setupNuxtI18nMock({
  spy: vi.fn, // every method becomes a vi.fn, so you can assert calls
  beforeEach, // reset state and reseed `translations` before each test
  translations: { welcome: 'Welcome' },
})

mockNuxtImport('useI18n', () => useI18n)
```

```ts
// vitest.config.ts
import { defineVitestConfig } from '@nuxt/test-utils/config'

export default defineVitestConfig({
  test: {
    environment: 'nuxt',
    setupFiles: ['./tests/unit-setup.ts'],
  },
})
```

`mockNuxtImport` çağrısını kurulum dosyasında tutun: `@nuxt/test-utils` onu dönüştürmek zorundadır. `setupNuxtI18nMock` özel bir çeviri önbelleği kullanır, bu nedenle paralel test dosyaları durumu paylaşmaz.

## Test yazma {#write-a-test}

```vue
<!-- components/Greeting.vue -->
<script setup lang="ts">
const { $t } = useI18n()
</script>

<template>
  <p>{{ $t('welcome') }}</p>
</template>
```

```ts
// tests/greeting.spec.ts
import { mountSuspended } from '@nuxt/test-utils/runtime'
import { expect, it } from 'vitest'
import Greeting from '~/components/Greeting.vue'
import de from '~/locales/de.json'
import { i18n, setTranslationsFromJson } from './unit-setup'

it('renders the German greeting', async () => {
  await setTranslationsFromJson('de', de)
  i18n.setLocale('de')

  const wrapper = await mountSuspended(Greeting)
  expect(wrapper.text()).toBe('Willkommen') // de.json: { "welcome": "Willkommen" }
})
```

Sahte nesne, gerçek `useI18n()` ile aynı yöntemleri (`$t`, `$tc`, `$tn`, `$td`, `$has`, `$localePath`, …, `$` ile ve `$` olmadan) ve testler için ayarlayıcıları sunar: `setLocale`, `setLocales`, `setDefaultLocale`, `setRouteName`, `setTranslationsFromJson`, `loadPageTranslations`, `mergeTranslations`, `setMissingHandler`.

`$localePath` ve `$switchLocalePath`, yolu `strategy` seçeneğine göre önekleyen taslaklardır (gerçek bir router yoktur). Gerçek bağlantıları ve yönlendirmeleri uçtan uca test edin.

## Alt düzey yardımcılar {#lower-level-helpers}

| Yardımcı | Kullanım amacı |
| --- | --- |
| `createIsolatedFakeI18n(options)` | Nuxt `useI18n` bağlantısı olmayan yalıtılmış bir sahte nesne; ör. `global.mocks` ile düz `@vue/test-utils` `mount` için. |
| `createFakeI18n(options)` | Paylaşılan modül önbelleği üzerinde bir sahte nesne (`beforeEach` içinde `resetI18n()` çağırın) veya `isolated: true` ile yalıtılmış. |
| `createI18nTestContext(options)` | Birden fazla sahte nesneye ihtiyaç duyduğunuzda, her ikisinin arkasındaki bağlam. |
| `t`, `tc`, `ts`, `tn`, `td`, `tdr`, `has` | Düz fonksiyonları test etmek için paylaşılan bağlam üzerinde doğrudan çağrılar. |

Mock bir `BaseI18n` nesnesidir: `t`, `tc`, `tn`, `td`, `tdr` ve `has` gerçek sözlükler üzerinde çalışan gerçek fonksiyonlardır; böylece bir test, uygulamanın gösterdiğini görür.

Yukarıdaki fabrika yardımcıları `locale`, `defaultLocale`, `locales`, `routeName`, `strategy`, `translations` ve `messages` (locale başına sözlükler) kabul eder. Eksiksiz bir örnek proje [`packages/test-utils/example`](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/test-utils/example) konumundadır.

## Uçtan uca testler {#end-to-end-tests}

Yönlendirme, yönlendirmeler (redirect), SEO etiketleri ve yük yükleme gerçek modülü gerektirir. Uygulamanızı `@nuxt/test-utils/e2e` ile başlatın:

```ts
// tests/e2e/locales.test.ts
import { $fetch, fetch, setup } from '@nuxt/test-utils/e2e'
import { describe, expect, it } from 'vitest'

describe('locales', async () => {
  await setup({ server: true })

  it('serves the German page', async () => {
    expect(await $fetch('/de')).toContain('lang="de-DE"')
  })

  it('redirects / for a German browser', async () => {
    const res = await fetch('/', { headers: { 'accept-language': 'de' }, redirect: 'manual' })
    expect(res.headers.get('location')).toBe('/de')
  })
})
```

İkinci test `prefix` (veya başka bir varsayılan locale ile `prefix_except_default`) varsayar; `/` adresinin ne zaman yönlendirdiği için bkz. [Locale algılama](/tr/guide/locale-detection).
