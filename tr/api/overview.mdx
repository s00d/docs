# API referansı

## Çalışma zamanı API'si

- [Metotlar](/api/methods): `$t`, `$ts`, `$_t`, `$_ts`, yerel ayar değiştirme, yönlendirme yardımcıları
- [Olaylar](/api/events): `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Çeviriler ve önbellek](/api/cache): `TranslationStorage`, yük yükleme, `$clearCache`

## Sunucu ara yazılımı

Sunucu işleyicileri, istemci `$t` yardımcıları yerine özel ara yazılım kullanır:

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers): API rotalarında ve sunucu işleyicilerinde çeviri yap
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers): Algılanan yerel ayarı ve meta verileri oku

Kurulum, yerel ayar algılama önceliği ve örnekler için tam [Sunucu tarafı çeviriler kılavuzuna](/guides/server-side-translations) göz at.
