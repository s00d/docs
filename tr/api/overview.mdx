# API Referansı

## Çalışma Zamanı API'si

- [Yöntemler](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, yerel ayar değiştirme, yönlendirme yardımcıları
- [Olaylar](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Çeviriler ve Önbellek](/api/cache) — `TranslationStorage`, yük yükleme, `$clearCache`

## Sunucu ara yazılımı

Sunucu işleyicileri, özel ara yazılım kullanır (istemci `$t` yardımcıları değil):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — API rotalarında ve sunucu işleyicilerinde çeviri yapın
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — algılanan yerel ayarı ve meta veriyi okuyun

Kurulum, yerel ayar algılama önceliği ve örnekler için tam [Sunucu Tarafı Çeviriler kılavuzuna](/guides/server-side-translations) bakın.
