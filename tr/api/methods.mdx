### `$getI18nConfig`

{/* generated:method:$getI18nConfig — do not edit; run `pnpm run docs:generate` */}

```ts
() => ModuleOptionsExtend
```

Çalışma zamanının gördüğü şekliyle çözümlenmiş modül yapılandırması.

{/* /generated:method:$getI18nConfig */}

const nuxtApp = useNuxtApp()
const { localeCookie, strategy, hooks } = nuxtApp.$getI18nConfig()

## 🔍 Çeviri metotları

Çevirileri almak ve yönetmek için temel metotlar.

### `$t`

{/* generated:method:$t — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Bir anahtarı çevir, içine `params` değerlerini enterpole eder. Anahtar bulunmazsa `defaultValue`'yu, varsayılan verilmediyse anahtarın kendisini döner.

{/* /generated:method:$t */}

```typescript
const welcomeMessage = $t('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

<Warning>
`$t`, `CleanTranslation` yani `string | number | boolean | Translations | PluralTranslations | null` döner. Anahtar JSON içinde iç içe bir **nesneye** işaret ediyorsa (örn. JSON `\{ "header": \{ "title": "Hi" \} \}` iken `$t('header')`), dönüş değeri bir string değil, o **nesne** olur. Bunu doğrudan bir Vue şablonunda kullanmak (<code v-pre>\{\{ $t('header') \}\}</code>) `[object Object]` olarak render edilir.

**Bunu nasıl önlersin:**

- Daha spesifik bir anahtar kullan: `$t('header.title')` → `"Hi"`
- Her zaman string döndüren `$ts()` fonksiyonunu kullan (string olmayanlar için `.toString()` çağırır)
- Programatik kullanım için alt nesnelere kasıtlı olarak erişmek istiyorsan iç içe anahtarla `$t` kullan.
</Warning>

### `$ts`

{/* generated:method:$ts — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string) => string
```

`$t` gibidir ama her zaman string döner: nesne veya dizi değeri olduğu gibi döndürülmek yerine string'e dönüştürülür.

{/* /generated:method:$ts */}

```typescript
const welcomeMessage = $ts('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

### `$_t` ve `$_ts`

{/* generated:method:$_t — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

`$t`'yi belirli bir rotaya bağla; geçerli sayfa dışında çeviri yapmak için (örneğin başka bir rotaya bağlantı üreten bir düzen).

{/* /generated:method:$_t */}

{/* generated:method:$_ts — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => string
```

`$ts`'yi belirli bir rotaya bağla. `$_t`'ye bak.

{/* /generated:method:$_ts */}

`$t` ve `$ts`'nin rota-bağlı varyantları. Önce bir **rota** alır ve o rotanın yerel ayar ve sayfa bağlamına kilitlenmiş bir çeviri fonksiyonu döner.

- **Erişim**: `useNuxtApp()` (ayrıca `useI18n()` tarafından `$_t` / `$_ts` olarak yeniden dışa aktarılır)

Bunları, SSR veya geçişler sırasında aktif rotanın `router.currentRoute`'dan farklı olduğu durumlarda kullan. Örneğin, `<i18n-t>`, `<i18n-group>` içinde veya belirli bir `route` nesnesi için içerik oluştururken.

```typescript
import { useRoute, useNuxtApp } from '#imports'

const route = useRoute()
const { $_t, $_ts } = useNuxtApp()

const $t = $_t(route)
const title = $t('page.title')

// String-safe variant
const label = $_ts(route)('page.label')
```


### `$tc`

{/* generated:method:$tc — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params: number | Params, defaultValue?: string) => string
```

Çoğullaştırma ile çevir. `params`, sayının kendisi ya da `count` içeren bir nesne olabilir.

{/* /generated:method:$tc */}

**Çeviri biçimi**: biçimler `|` ile ayrılır. Yer tutucuları **her** biçime koy:

```json
{
  "apples": "no apples | one apple | {count} apples",
  "cart": "no items for {name} | one item for {name} | {count} items for {name}"
}
```

```typescript
$tc('apples', 0) // "no apples"
$tc('apples', 1) // "one apple"
$tc('apples', 10) // "10 apples"

// count + other params (second argument must be an object)
$tc('cart', { count: 10, name: 'Alice' }) // "10 items for Alice"
```


**Bileşen alternatifi**: `<i18n-t keypath="cart" :plural="count" :params="\{ name \}" />` (dahili olarak `count`'u `params` ile birleştirir).


### `$mergeTranslations`

{/* generated:method:$mergeTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
(newTranslations: Translations) => void
```

Çalışma zamanında aktif yerel ayara çevirileri birleştir; yüklenenlerin üzerine yazar.

{/* /generated:method:$mergeTranslations */}

```typescript
$mergeTranslations({
  welcome: 'Bienvenue, {username}!',
})
// Output: Updates the translation cache with the new French translation
```

### `$resolveTranslations`

{/* generated:method:$resolveTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
() => Translations
```

Aktif yerel ayar ve rota için bellekteki tüm çeviriler, ağaç biçiminde. `$t()`'nin şu anda çözümleyebildiği şeyin salt okunur bir görünümüdür.

{/* /generated:method:$resolveTranslations */}

```typescript
const tree = $resolveTranslations()
// { aaa: { bbb: 'ccc' }, ddd: 1111 } — the same dictionary $t() reads from
```

Bunu tüm bellek içi sözlüğe ihtiyacın olduğunda kullan (DevTools, testler, çalışma zamanı düzenleyicileri). Dönüş değerini salt okunur olarak ele al; değerleri `$setTranslation` ile değiştir veya `$mergeTranslations` ile yamalar birleştir.

### `$setTranslation`

{/* generated:method:$setTranslation — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, value: unknown) => void
```

Aktif sözlükte `key` konumundaki değeri değiştir. Bu bir birleştirme değil, değiştirmedir. Mevcut kardeşlerin hayatta kalması gerekiyorsa `$mergeTranslations` kullan.

{/* /generated:method:$setTranslation */}

```typescript
$setTranslation('aaa', { fff: 'ggg' }) // replaces the whole `aaa` subtree
$setTranslation('aaa', 'text')          // replaces `aaa` with a string
$setTranslation('ddd', 1111)            // scalar at the top level
$setTranslation('aaa.bbb', 'nested')    // dotted path
```

Bu bir **değiştirmedir**, birleştirme değil. Aynı anahtar altındaki mevcut kardeşler kaldırılır. Kardeşleri kaybetmeden yama uygulamak için `$mergeTranslations` kullan.

### `$setMissingHandler`

{/* generated:method:$setMissingHandler — do not edit; run `pnpm run docs:generate` */}

```ts
(handler: MissingHandler | null) => void
```

Her çözümlenemeyen anahtar için çağrılan bir geri çağırma yükle. Kaldırmak için `null` ilet.

{/* /generated:method:$setMissingHandler */}

**Tür tanımı**:

```typescript
type MissingHandler = (locale: string, key: string, routeName: string, instance?: unknown, type?: string) => void
```

```typescript
// Set a custom handler
$setMissingHandler((locale, key, routeName) => {
  console.error(`Missing translation: ${key} in ${locale} for route ${routeName}`)
  // Send to Sentry or other error tracking service
  // Sentry.captureMessage(`Missing translation: ${key}`)
})

// Remove the handler
$setMissingHandler(null)
```

**Kullanım senaryoları**:

- Eksik çevirileri hata izleme servislerine (Sentry, LogRocket vb.) kaydetme
- Eksik çeviriler için analitik toplama
- Eksik çeviri anahtarları için özel hata işleme

## 🔢 Sayı ve tarih biçimlendirme

Sayı ve tarihleri yerel ayar kurallarına göre biçimlendiren metotlar.

### `$tn`

{/* generated:method:$tn — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Aktif yerel ayarda `Intl.NumberFormat` ile bir sayıyı biçimlendir. Bir anahtar, yapılandırmadan adlandırılmış bir biçim seçer.

{/* /generated:method:$tn */}

```typescript
// Inline options
const formattedNumber = $tn(1234567.89, { style: 'currency', currency: 'USD' })
// "$1,234,567.89"

// Named format (from nuxt.config i18n.numberFormats)
const price = $tn(1000, 'currency')
const priceDe = $tn(1000, 'currency', 'de')
const compact = $tn(1000, 'currency', { notation: 'compact' })
```

Bilinmeyen adlandırılmış biçim anahtarları varsayılan `Intl.NumberFormat` seçeneklerine geri düşer. Geliştirmede (istemci), `missingWarn` etkinken (varsayılan) bir `console.warn` yayılır.

**Yapılandırma örneği**:

```ts
export default defineNuxtConfig({
  i18n: {
    numberFormats: {
      en: {
        currency: { style: 'currency', currency: 'USD' },
        decimal: { style: 'decimal', minimumFractionDigits: 2, maximumFractionDigits: 2 },
      },
      de: {
        currency: { style: 'currency', currency: 'EUR' },
      },
    },
  },
})
```

**Kullanım senaryoları**:

- Sayıları uygun yerel ayar biçiminde para birimi, yüzde veya ondalık olarak biçimlendirmek
- Adlandırılmış biçimleri uygulama genelinde yeniden kullanmak (Vue I18n geçiş uyumluluğu)

### `$td`

{/* generated:method:$td — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Aktif yerel ayarda `Intl.DateTimeFormat` ile bir tarihi biçimlendir. Bir anahtar, yapılandırmadan adlandırılmış bir biçim seçer.

{/* /generated:method:$td */}

```typescript
const formattedDate = $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' })
// "Friday, September 1, 2023"

const short = $td(new Date(), 'short')
const longDe = $td(new Date(), 'long', 'de')
```

Bilinmeyen adlandırılmış biçim anahtarları varsayılan `Intl.DateTimeFormat` seçeneklerine geri düşer. Geliştirmede (istemci), `missingWarn` etkinken (varsayılan) bir `console.warn` yayılır.

**Yapılandırma örneği**:

```ts
export default defineNuxtConfig({
  i18n: {
    datetimeFormats: {
      en: {
        short: { year: 'numeric', month: 'short', day: 'numeric' },
        long: { year: 'numeric', month: 'long', day: 'numeric', weekday: 'long' },
      },
    },
  },
})
```

**Kullanım senaryoları**:

- Kullanıcının yerel ayarıyla uyumlu bir biçimde tarih görüntüleme
- Kısa/uzun/tarih-saat ön ayarlarını uygulama genelinde paylaşma

### `$tdr`

{/* generated:method:$tdr — do not edit; run `pnpm run docs:generate` */}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

Bir tarihi `Intl.RelativeTimeFormat` ile göreli zaman ("3 gün önce") olarak biçimlendir.

{/* /generated:method:$tdr */}

```typescript
const relativeDate = $tdr(new Date(Date.now() - 1000 * 60 * 5))
// Output: "5 minutes ago" in the 'en-US' locale
```

## 🔄 Rota ve yerel ayar değişimi

Yerel ayarlar ve rotalar arasında geçiş yapmak için metotlar.

### `$switchLocale`

{/* generated:method:$switchLocale — do not edit; run `pnpm run docs:generate` */}

```ts
(locale: string) => void
```

Geçerli sayfaya başka bir yerel ayarda git.

{/* /generated:method:$switchLocale */}

```typescript
$switchLocale('fr')
// Prefix strategies: navigates to the French version of the route
// no_prefix: updates locale and translations without changing the URL path
```

<Tip>
[SSS — URL'yi değiştirmeden yerel ayarı değiştir](/guides/faq#-switch-locale-without-changing-the-url) sayfasına bak. Ön ekli stratejilerde yalnızca bir bağlantı hedefi gerekiyorsa `$switchLocalePath()` kullan.
</Tip>

### `$switchLocaleRoute`

{/* generated:method:$switchLocaleRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(locale: string) => RouteLocationRaw
```

Geçerli sayfanın başka bir yerel ayardaki rota nesnesi, gitmeden.

{/* /generated:method:$switchLocaleRoute */}

```typescript
// on /en/news
const routeFr = $switchLocaleRoute('fr')
// Output: A route object with the new locale applied, e.g., { name: 'localized-news', params: { locale: 'fr' } }
```

### `$switchLocalePath`

{/* generated:method:$switchLocalePath — do not edit; run `pnpm run docs:generate` */}

```ts
(locale: string) => string
```

Geçerli sayfanın başka bir yerel ayardaki yolu, gitmeden.

{/* /generated:method:$switchLocalePath */}

```typescript
// on /en/news
const routeFr = $switchLocalePath('fr')
window.location.href = routeFr
// Output: url with new locale applied, e.g., '/fr/nouvelles'
```

### `$switchRoute`

{/* generated:method:$switchRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, toLocale?: string) => void
```

Başka bir rotaya git; aktif yerel ayarı koru veya `toLocale`'e geç.

{/* /generated:method:$switchRoute */}

**Örnekler**:

<CodeGroup>
```typescript String Path
// Switches to the given path with the current locale
$switchRoute('/about')
```

```typescript String Path with Locale
// Switches to the given path with French locale
$switchRoute('/about', 'fr')
```

```typescript Named Route
// Switches to a named route with the current locale
$switchRoute({ name: 'page' })
```

```typescript Named Route with Locale
// Switches to a named route and changes the locale to Spanish
$switchRoute({ name: 'page' }, 'es')
```

## 🚦 Rota yapılandırması

Rota davranışını ve erişim denetimini yapılandırmak için metotlar.

### `$defineI18nRoute`

{/* generated:method:$defineI18nRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Sayfa başına yerel ayar yapılandırmasını ve çevirileri bir bileşen içinden kaydeder. Aktif yerel ayara birleştirilir ve yerel ayar değiştikçe yeniden uygulanır.

{/* /generated:method:$defineI18nRoute */}

> [!IMPORTANT]
> `$defineI18nRoute`, **define eklentisi** tarafından sağlanır ve yalnızca `useNuxtApp()` üzerinde bulunur. `useI18n()` dönüş nesnesinin **parçası değildir**.
> Onu her zaman `script setup` içinde `useNuxtApp()`'ten destructure et. `$defineI18nRoute(...)` çağrısını çıplak bir global olarak yapmak SSR/prerender sırasında `"$defineI18nRoute is not defined"` fırlatır.

**Parametreler**:

- **locales**: `string[] | Record<string, Record<string, string>>`: Rota için mevcut yerel ayarlar
- **localeRoutes**: `Record<string, string>`: Opsiyonel. Belirli yerel ayarlar için özel rotalar
- **disableMeta**: `boolean | string[]`: Opsiyonel. Tüm veya belirli yerel ayarlar için i18n meta etiketlerini devre dışı bırakır

**Temel örnek**:

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr', 'de'],
  localeRoutes: {
    en: '/welcome',
    fr: '/bienvenue',
    de: '/willkommen',
  },
  disableMeta: false,
})
```

> 📖 **Ayrıntılı kullanım örnekleri, yapılandırma biçimleri ve en iyi uygulamalar için [Bileşen başına çeviriler kılavuzuna](/guides/per-component-translations) bak.**

### `$setI18nRouteParams`

{/* generated:method:$setI18nRouteParams — do not edit; run `pnpm run docs:generate` */}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Geçerli rota için yerel ayara özgü parametreleri ayarla; böylece bir dinamik segment dile göre farklılaşabilir. Bunu SSR sırasında, head render edilmeden önce çağır.

{/* /generated:method:$setI18nRouteParams */}

```typescript
// in pages/news/[id].vue
// for en/news/1-first-article
const { $switchLocaleRoute, $setI18nRouteParams, $defineI18nRoute } = useNuxtApp()
$defineI18nRoute({
  localeRoutes: {
    en: '/news/:id()',
    fr: '/nouvelles/:id()',
    de: '/Nachricht/:id()',
  },
})
const { data: news } = await useAsyncData(`news-${params.id}`, async () => {
  let response = await $fetch("/api/getNews", {
    query: {
      id: params.id,
    },
  });
  if (response?.localeSlugs) {
    response.localeSlugs = {
      en: {
        id: '1-first-article'
      }
      fr: {
        id: '1-premier-article'
      }
      de: {
        id: '1-erster-Artikel'
      }
    }
    $setI18nRouteParams(response?.localeSlugs);
  }
  return response;
});
$switchLocalePath('fr') // === 'fr/nouvelles/1-premier-article'
$switchLocalePath('de') // === 'de/Nachricht/1-erster-Artikel'
```

## 🧭 `useI18nLocale` composable

Yerel ayar durumu yönetimi için merkezi composable. `useState('i18n-locale')` veya `useCookie('user-locale')`'ı doğrudan yönetmek yerine bunu kullan.

```typescript
const {
  setLocale, // (locale: string) => void — updates state + cookie
  getLocale, // () => string | null — from state or cookie
  getPreferredLocale, // () => string | null — validated against locales list
  getEffectiveLocale, // (route, getLocaleFromRoute) => string
  resolveInitialLocale, // (options) => string
  isValidLocale, // (locale) => boolean
  locale, // Ref<string | null> — reactive state
  localeCookie, // CookieRef — reactive cookie
  syncLocale, // (locale) => void — sync to cookie only
  validLocales, // string[] — list of valid locale codes
} = useI18nLocale()
```

### Ana metotlar

| Metot                   | Açıklama                                                     |
| ----------------------- | ------------------------------------------------------------ |
| `setLocale(locale)`     | Yerel ayarı hem `useState` hem de çerezde atomik olarak ayarlar |
| `getLocale()`           | Geçerli yerel ayarı state veya çerezden döner                |
| `getPreferredLocale()`  | `locales` listesine göre doğrulanmış yerel ayarı veya `null` döner |
| `isValidLocale(locale)` | Bir yerel ayar kodunun yapılandırılmış `locales` listesinde olup olmadığını kontrol eder |

  order: -10,
