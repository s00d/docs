Modül, çalışma zamanı yardımcılarını Nuxt uygulamasına enjekte eder: `$t`, `$tc`, `$localePath`, `$switchLocale` ve diğerleri. Bir yardımcının imzasına ve davranışına bakmak için bu sayfayı kullanın. İmzalar ve açıklamalar, `src/runtime/plugins/01.plugin.ts` içindeki `PluginsInjections` ve `NuxtAppOnlyInjections` arayüzlerinden gelir.

## Erişim {#access}

| Nerede | Nasıl |
| --- | --- |
| Şablon | `{{ $t('title') }}` — her yardımcı, `$` ile |
| `<script setup>` | `const { t, localePath } = useI18n()` — `PluginsInjections` içindeki her yardımcı, `$` ile ve `$` olmadan |
| Eklenti, middleware, `<script setup>` | `const { $t, $defineI18nRoute } = useNuxtApp()` — her şey, yalnızca `$` ile |

`$defineI18nRoute` yalnızca `useNuxtApp()` üzerinde tiplendirilmiştir. Bkz. [`useI18n`](/tr/composables/useI18n).

```vue
<script setup lang="ts">
const { t, localePath } = useI18n()
</script>

<template>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
</template>
```

## Locale {#locale}

### `$getLocale` {#$getlocale}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric) => string
```

Etkin locale'in kodu. Bir rotanın ait olduğu locale'i okumak için o rotayı iletin.

```ts
$getLocale() // 'de' on /de/about
```

### `$getLocaleName` {#$getlocalename}

```ts
() => string | null
```

Yapılandırmadaki etkin locale'in `displayName` değeri veya yoksa `null`.

### `$getLocales` {#$getlocales}

```ts
() => Locale[]
```

Yapılandırılmış her locale, meta verileriyle birlikte.

Bir locale nesnesindeki özel özellikler yazıldığı gibi geri gelir; bunları `Locale`'in [modül genişletmesi](/tr/api/module-options#locales) ile tiplendirin.

### `$defaultLocale` {#$defaultlocale}

```ts
() => string | undefined
```

Yapılandırılmış varsayılan locale'in kodu.

### `$getI18nConfig` {#$geti18nconfig}

```ts
() => ResolvedI18nConfig
```

Çalışma zamanının gördüğü şekliyle çözümlenmiş modül yapılandırması.

Değer [çalışma zamanı geçersiz kılmalarını](/tr/guide/runtime-overrides) (`defaultLocale`, `fallbackLocale`, devre dışı locale'ler) içerir.

```ts
const { strategy, localeCookie } = useNuxtApp().$getI18nConfig()
```

## Çeviri {#translation}

### `$t` {#$t}

```ts
TranslationFn<CleanTranslation>
```

Bir anahtarı çevirir ve içine `params` değerlerini yerleştirir. Anahtar eksik olduğunda
`defaultValue` değerini, varsayılan verilmemişse anahtarın kendisini döndürür.

```ts
// { "welcome": "Welcome, {name}!" }
$t('welcome', { name: 'Ada' }) // 'Welcome, Ada!'
$t('missing.key', {}, 'Fallback') // 'Fallback'
```

İç içe bir nesneyi gösteren bir anahtar string değil o nesneyi döndürür. Şablonda `[object Object]` olarak işlenir; bir yaprak anahtar kullanın.

### `$ts` {#$ts}

```ts
TranslationFn<string>
```

`$t` gibidir ancak her zaman bir string döndürür: değer `toString()`'den geçer, bu nedenle iç içe
bir nesne `'[object Object]'` olur. Anahtarı bir yaprağa yönlendirin.

### `$_t` {#$_t}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<CleanTranslation>
```

`$t`'yi belirli bir rotaya bağlar; geçerli sayfanın dışında çeviri yapmak için — örneğin başka bir
rotaya bağlantı işleyen bir layout.

```ts
const route = useRoute()
const t = useNuxtApp().$_t(route)
t('page.title')
```

### `$_ts` {#$_ts}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<string>
```

`$ts`'yi belirli bir rotaya bağlar. Bkz. `$_t`.

### `$tc` {#$tc}

```ts
(key: TranslationKey, params: number | Params, defaultValue?: string) => string
```

Çoğullaştırma ile çevirir. `params` sayının kendisi veya `count` içeren bir nesne
olabilir.

Biçimler `|` ile ayrılır. Yerleşik kuralda negatif olmayan bir tamsayı `n`, son biçimle sınırlanarak `n` numaralı biçimi seçer; negatif, kesirli veya `NaN` bir sayı son biçimi alır. `{count}` ve diğer parametreler seçilen biçime yerleştirilir.

Çoğulları sayıyı takip etmeyen diller için şablonu `=0 ` ile başlatın. Bu durumda ilk biçim 0 içindir ve diğerleri [`Intl.PluralRules`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/PluralRules) kategorisine göre, `zero, one, two, few, many, other` sırasıyla gider:

```json
{
  "apples": "=0 no apples | one apple | {count} apples",
  "files": "=0 no files | {count} one | {count} few | {count} many"
}
```

```ts
$tc('apples', 0) // 'no apples'
$tc('apples', 1) // 'one apple'
$tc('apples', 7) // '7 apples'

// In `uk` (categories `one, few, many, other`) the forms after the zero form follow those categories:
$tc('files', 21) // '21 one'
$tc('files', 22) // '22 few'
$tc('files', 25) // '25 many'
$tc('files', 2.5) // '2.5 many': no form for `other`, so the last one
```

- `=0 ` yalnızca değerin en başında, boşlukla birlikte dikkate alınır. `$t` onu metin olarak gösterir: çoğullara aittir.
- Kendi biçimi olmayan bir kategori son biçimi alır. Negatif veya kesirli bir sayı da son biçimi alır.
- Her locale'de çalışır: İngilizcede `=0 none | one | {count} many`.
- Kategori locale'in `iso` değerinden, yoksa kodundan gelir. `Intl`'in tanımadığı bir kod, işaret yine kaldırılarak indeks kuralına geri döner; böylece sonuç asla makineye bağlı olmaz.
- `<i18n-t :plural>` aynı kuralı izler. Özel bir [`plural`](/tr/api/module-options#plural) veya `customPluralRule` ham değeri, işaret dahil alır ve kendisi karar verir; `null` döndüren `plural` çağrıyı işareti dikkate alan yerleşik kurala geri verir.

İşaret olmadan bir şablon indeks kuralında kalır; yalnızca tek bir şekilde okunabilen bir istisna dışında: yer tutucusu olmayan bir sıfır biçimi, ardından kategori başına bir biçim ve birden çok sayının paylaştığı her biçimde `{count}` (`uk` için `no files | {count} one | {count} few | {count} many`).

Kendi kurallarınız için [`plural`](/tr/api/module-options#plural) ayarlayın.

```ts
// { "apples": "no apples | one apple | {count} apples" }
$tc('apples', 0) // 'no apples'
$tc('apples', 10) // '10 apples'
$tc('cart', { count: 2, name: 'Ada' }) // count and params in one object
```

Üçüncü argüman params değil `defaultValue`'dur.

### `$has` {#$has}

```ts
(key: string) => boolean
```

Bir anahtarın etkin locale'de çözümlenip çözümlenmediği. Ham bir anahtar işlemek yerine isteğe bağlı
metinde dallanmak için kullanın. `$t` gibi, aynı locale'deki bir sayfa geçişi sırasında ayrılan
sayfanın anahtarlarını da görür.

```ts
if ($has('promo.banner')) show.value = true
```

## Biçimlendirme {#formatting}

### `$tn` {#$tn}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Bir sayıyı etkin locale'de `Intl.NumberFormat` ile biçimlendirir. Bir anahtar, yapılandırmadan
adlandırılmış bir biçim seçer.

Adlandırılmış biçimler [`numberFormats`](/tr/api/module-options#numberformats) seçeneğinden gelir.

```ts
$tn(1234.5, { style: 'currency', currency: 'EUR' }) // '1.234,50 €' in de
$tn(1000, 'currency') // named format
$tn(1000, 'currency', 'de') // named format in another locale
```

### `$td` {#$td}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Bir tarihi etkin locale'de `Intl.DateTimeFormat` ile biçimlendirir. Bir anahtar, yapılandırmadan
adlandırılmış bir biçim seçer.

Adlandırılmış biçimler [`datetimeFormats`](/tr/api/module-options#datetimeformats) seçeneğinden gelir.

```ts
$td(new Date(), { dateStyle: 'long' })
$td(post.createdAt, 'short')
```

### `$tdr` {#$tdr}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

Bir tarihi `Intl.RelativeTimeFormat` ile göreli zaman ("3 gün önce") olarak biçimlendirir.

```ts
$tdr(Date.now() - 5 * 60_000) // '5 minutes ago' in en
```

## Geçiş ve bağlantılar {#switching-and-links}

### `$switchLocale` {#$switchlocale}

```ts
(locale: string) => Promise<boolean>
```

Geçerli sayfanın başka bir locale'deki sürümüne gider. `no_prefix` ve hash modunda gezinmeden önce
locale'in çevirilerini yükler; `no_prefix` altında rota yerinde değiştirilir (yeni
geçmiş kaydı oluşmaz). Bilinmeyen bir locale yok sayılır.
Çağrı asenkrondur: gezinmeden sonra kod çalıştırmak için `await` edin. Locale'in sözlüğü
etkin olduğunda `true`, olmadığında `false` ile çözümlenir: chunk yüklenemedi (geçerli
sözlük kalır; yeniden denemek için tekrar çağırın) veya daha yeni bir geçiş kazandı.

```ts
await $switchLocale('de')
```

### `$switchLocalePath` {#$switchlocalepath}

```ts
(locale: string) => string
```

Gezinmeden, geçerli sayfanın başka bir locale'deki yolu.

```vue
<NuxtLink :to="$switchLocalePath('de')">Deutsch</NuxtLink>
```

### `$switchLocaleRoute` {#$switchlocaleroute}

```ts
(locale: string) => RouteLocationRaw
```

Gezinmeden, geçerli sayfanın başka bir locale'deki rota nesnesi veya kendi `baseUrl`'i olan
bir locale için bir URL string'i. `trailingSlash` altında nesne, kurala uyan `path` ve `fullPath`
değerlerine ve olduğu gibi `query` ile `hash`'e sahiptir; `router.push` veya bir bağlantı bunları korur.

### `$switchRoute` {#$switchroute}

```ts
(route: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, toLocale?: string) => Promise<void>
```

Etkin locale'i koruyarak veya `toLocale`'e geçerek başka bir rotaya gider. `$switchLocale` gibi
asenkrondur.

```ts
$switchRoute('/about') // active locale
$switchRoute({ name: 'about' }, 'de') // switch to de
```

### `$localePath` {#$localepath}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => string
```

Bir yolu verilen locale'de veya etkin olanda çözümler. `http(s):`, `mailto:`
veya `tel:` şemasına sahip bir string olduğu gibi geri döner: kullanıcı girdisini denetlemeden bağlantı hedefi olarak iletmeyin.

Bir string yol gösterdiği sayfa olarak okunur, bu nedenle bir locale'in özel yolu da uygulanır.

```ts
$localePath('/about') // '/about' in en, '/de/ueber-uns' in de with localeRoutes
$localePath({ name: 'about' }, 'fr') // '/fr/about'
```

### `$localeRoute` {#$localeroute}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => RouteLocationResolved
```

Bir rotayı verilen locale'de veya etkin olanda çözümler. Durumda saklanması güvenli, düz bir nesnedir. Bir parametrenin
kaçışlanması gerektiğinde `path`, `fullPath`, `query` ve `hash` içerir ancak `name` veya `params` içermez: router'a
kodlanmış URL'yi veren yoldur. Başka bir alan adındaki bir locale için `path` ve `fullPath` mutlaktır ve router bunları alamaz:
böyle bir bağlantı `<i18n-link>` veya `$localePath` üzerinden geçer.

### `$getRouteName` {#$getroutename}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric, locale?: string) => string
```

Locale öneki çıkarılmış rota adı — çevirilerin anahtarlandığı ad.

```ts
$getRouteName() // 'about' on /de/about
```

## Sayfa yapılandırması {#page-config}

### `$defineI18nRoute` {#$definei18nroute}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Bir bileşenin içinden sayfa başına locale yapılandırmasını ve çevirileri kaydeder.
Etkin locale'e birleştirir ve locale değiştiğinde yeniden uygular.

Bunu bir sayfanın `<script setup>` bloğunda, her zaman `useNuxtApp()`'ten ayrıştırarak çağırın. Derleme, çağrıdan `locales`, `localeRoutes` ve `disableMeta` değerlerini okur; çalışma zamanında yalnızca `locales` önemlidir (satır içi çeviriler etkin locale için birleştirilir). Tüm kurallar: [Sayfa yapılandırması](/tr/guide/per-component-translations).

```vue
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'de'],
  localeRoutes: { en: '/about', de: '/ueber-uns' },
})
</script>
```

### `$setI18nRouteParams` {#$seti18nrouteparams}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Geçerli rota için locale başına parametreleri ayarlar; böylece dinamik bir segment dile göre farklı olabilir.
Bunu SSR sırasında, head işlenmeden önce çağırın.

Parametreler, başka bir yola yapılan gezinme tamamlandığında temizlenir; rota adını koruyan `/news/1`'den `/news/4`'e geçiş de buna dahildir. Ayrıntılar: [Yerelleştirilmiş yollar](/tr/guide/custom-locale-routes).

```ts
$setI18nRouteParams({
  en: { slug: 'my-post' },
  de: { slug: 'mein-beitrag' },
})
```

## Çalışma zamanı çevirileri {#runtime-translations}

### `$mergeTranslations` {#$mergetranslations}

```ts
(newTranslations: Translations) => void
```

Çevirileri çalışma zamanında etkin locale'e birleştirir ve yüklenmiş olanı geçersiz kılar.

Etkin locale'in geçerli sayfa chunk'ına derinlemesine birleştirir; belirtilmeyen anahtarlar korunur.

```ts
$mergeTranslations({ banner: { title: 'Sale' } })
```

### `$setTranslation` {#$settranslation}

```ts
(key: string, value: unknown) => void
```

Etkin sözlükte `key` konumundaki değeri değiştirir. Bu bir birleştirme değil, değiştirmedir —
mevcut kardeş anahtarların korunması gerektiğinde `$mergeTranslations` kullanın.

```ts
$setTranslation('banner', { title: 'Sale' }) // drops other keys under banner
$setTranslation('banner.title', 'Sale') // dotted path
```

### `$loadPageTranslations` {#$loadpagetranslations}

```ts
(locale: string, routeName: string, translations: Translations) => Promise<void>
```

Anahtarları derleme zamanında bilinmeyen içerik için bir sayfanın çevirilerini çalışma zamanında yükler.

Bellekteki `(locale, routeName)` chunk'ına birleştirir ve o chunk etkin olduğunda ekran güncellenir. Burada hiçbir payload getirilmez: henüz yüklenmemiş bir sayfa için çeviriler bekler ve dosyası yüklendiğinde onun üzerinde kalır.

```ts
await $loadPageTranslations('en', 'about', { title: 'About us' })
```

### `$resolveTranslations` {#$resolvetranslations}

```ts
() => Translations
```

Etkin locale ve rota için şu anda bellekte bulunan her çeviri, bir ağaç olarak.
`$t()`'nin şu anda çözümleyebileceklerinin salt okunur görünümü.

Sonucu salt okunur olarak değerlendirin.

### `$setMissingHandler` {#$setmissinghandler}

```ts
(handler: MissingHandler | null) => void
```

Çözümlenmeyen her anahtar için çağrılan bir callback kurar. Kaldırmak için `null` iletin.

İşleyici, geliştirme uyarısının yerine çalışır.

```ts
$setMissingHandler((locale, key, routeName) => {
  console.error(`[i18n] missing ${key} in ${locale} (${routeName})`)
})
```

### `$clearCache` {#$clearcache}

```ts
() => void
```

Önbelleğe alınmış tüm çeviri chunk'larını atar ve geçerli sayfanın sözlüğünü yeniden yükler. Sayfa,
yenileri gelene kadar mevcut çevirilerini göstermeye devam eder. Geliştirme HMR'ı bunu her
çeviri dosyası değişikliğinde çağırır.

```ts
const { clearCache } = useI18n()
clearCache()
```

Başarısız bir yeniden yükleme mevcut sözlüğü korur.
