# 🌍 `<i18n-t>` bileşeni

`Nuxt I18n Micro`'daki `<i18n-t>` bileşeni; yuvalar aracılığıyla dinamik içerik eklemeyi destekleyen esnek bir çeviri bileşenidir. Çevirileri özel Vue bileşenleri veya HTML içerikleriyle enterpole etmeni sağlar; gelişmiş yerelleştirme senaryolarına imkân tanır.

Aynı anda yalnızca `plural`, `number`, `date` ve `relativeDate`'ten biri geçerlidir; birden fazlası ayarlandığında listede önce gelen kazanır.

### Prop başına örnekler

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

## 🛠️ Örnek kullanımlar

### Temel kullanım

```vue
<i18n-t keypath="feedback.text" />
```

Bu, `feedback.text` çevirisini bir `<span>` etiketinde render eder.

### Dinamik içerik için yuvaları kullanma

`<i18n-t>` bileşeni, çevirinin belirli bölümlerine dinamik olarak Vue bileşenleri veya başka içerik eklemek için yuvaların kullanımını destekler.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

Bu örnekte, `feedback.text` çeviri dizesindeki `\{link\}` yer tutucusu, kendisi başka bir çeviri bileşeni içeren `<nuxt-link>` bileşeniyle değiştirilir.

### Çoğullaştırma

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

Bu, `itemCount` değerine göre çoğullaştırma kurallarını otomatik olarak uygular.

## 🚀 Ek özellikler

### Varsayılan yuva

Belirli bir yuva sağlanmazsa çeviri, tüm çevrilmiş dizeyi sağlayan varsayılan yuva üzerinden özelleştirilebilir:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### Koşullu render

Çeviri dizesi boşsa `hideIfEmpty` prop'unu kullanarak hiçbir şey render etme.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### Özel çoğullaştırma kuralı

Çoğullaştırmayı işlemek için özel bir fonksiyon kullan.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### Yuvalarla gelişmiş örnek

Çeviri içeriğinin nasıl render edileceğini özelleştirmek için yuvaları kullan.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
