# 🌍 `<i18n-group>` bileşeni

Nuxt I18n Micro'daki `<i18n-group>` bileşeni, çevirileri ortak bir önek altında gruplandırmanın uygun bir yolunu sağlar; tekrarı azaltır ve kod düzenini iyileştirir.

## ⚙️ Prop'lar

{/* generated:component:i18n-group — do not edit; run `pnpm run docs:generate` */}

| Prop | Tür | Varsayılan | Açıklama |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | Yuva içindeki her aramanın çözümleneceği anahtar öneki. |
| `groupClass` | `string` | `''` | Sarmalayıcı elemana eklenecek ek sınıf. |

**\*** zorunludur.

### Yuvalar

| Yuva | Bağlamalar | Açıklama |
| --- | --- | --- |
| `default` | `prefix`, `t` | `prefix` ve buna kapsamlanmış bir `t` fonksiyonu alır. |

{/* /generated:component:i18n-group */}

## 🎯 Yuvalar

Varsayılan yuva, `prefix` ve buna kapsamlanmış bir `t` fonksiyonu alır; böylece içerideki anahtarlar önek göreli olarak yazılır:

```vue
<i18n-group prefix="checkout">
  <template #default="{ t }">
    <h2>{{ t('title') }}</h2>
    <p>{{ t('summary', { count: 3 }) }}</p>
  </template>
</i18n-group>
```

## 🛠️ Örnek kullanım

### Temel kullanım

```vue
<template>
  <i18n-group prefix="product.details">
    <template #default="{ t }">
      <h1>{{ t('title') }}</h1>
      <p>{{ t('description') }}</p>
      <div class="price">{{ t('price', { value: 99.99 }) }}</div>
    </template>
  </i18n-group>
</template>
```

Çeviri dosyası:

```json
{
  "product": {
    "details": {
      "title": "Premium Product",
      "description": "This is a premium product",
      "price": "Price: ${value}"
    }
  }
}
```

### Özel sınıfla

```vue
<template>
  <i18n-group prefix="user.profile" group-class="profile-section">
    <template #default="{ t }">
      <div class="user-info">
        <h2>{{ t('title') }}</h2>
        <p>{{ t('bio') }}</p>
        <div class="stats">
          <span>{{ t('stats.followers') }}</span>
          <span>{{ t('stats.following') }}</span>
        </div>
      </div>
    </template>
  </i18n-group>
</template>
```

Çeviri dosyası:

```json
{
  "user": {
    "profile": {
      "title": "User Profile",
      "bio": "User biography goes here",
      "stats": {
        "followers": "Followers: {count}",
        "following": "Following: {count}"
      }
    }
  }
}
```

### Dinamik içerikle

```vue
<template>
  <i18n-group prefix="blog.post">
    <template #default="{ t }">
      <article>
        <h1>{{ t('title') }}</h1>
        <div class="meta">
          {{ t('meta.author', { name: author }) }} |
          {{ t('meta.date', { date: publishDate }) }}
        </div>
        <div v-for="(section, index) in sections" :key="index">
          <h2>{{ t(`sections.${index}.title`) }}</h2>
          <p>{{ t(`sections.${index}.content`) }}</p>
        </div>
      </article>
    </template>
  </i18n-group>
</template>

<script setup>
const author = 'John Doe'
const publishDate = '2024-01-01'
const sections = ['intro', 'main', 'conclusion']
</script>
```

## 🎨 Biçimlendirme

Bileşen, içeriğini `i18n-group` sınıfına sahip bir div ve `groupClass` prop'unda belirtilen ek sınıflarla sarar:

```css
.i18n-group {
  /* Your base styles */
}

.profile-section {
  /* Additional styles for profile sections */
}
```

## 🚀 En iyi uygulamalar

1. **Tutarlı önekler**: Uygulamanın yapısını yansıtan tutarlı ve mantıklı önekler kullan.

```vue
<i18n-group prefix="features.pricing">
<i18n-group prefix="features.security">
```

2. **Modüler organizasyon**: İlişkili çevirileri anlamlı önekler altında bir arada gruplandır.

```vue
<i18n-group prefix="checkout.payment">
<i18n-group prefix="checkout.shipping">
```

3. **Yeniden kullanılabilir bileşenler**: Kendi çeviri gruplarına sahip yeniden kullanılabilir bileşenler oluştur.

```vue
<!-- UserProfile.vue -->
<i18n-group prefix="user.profile">

<!-- UserSettings.vue -->
<i18n-group prefix="user.settings">
```

4. **İç içe gruplar**: Netliği korumak için grupları çok derin iç içe yerleştirmekten kaçın.

```vue
<!-- Good -->
<i18n-group prefix="shop.product">

<!-- Avoid -->
<i18n-group prefix="shop.category.product.details.specs">
```
