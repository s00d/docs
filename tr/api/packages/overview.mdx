# Paket API'leri

`nuxt-i18n-micro`, çoğu kendi başına kullanılabilen küçük paketlerden oluşturulmuştur —
düz bir Vue uygulamasında `@i18n-micro/vue`, herhangi bir yerde `@i18n-micro/core`.

Aşağıdaki her sayfa, [`pnpm run api:surface`](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/maintenance-commands.md#api-surface)'ın
TypeScript kaynaklarına karşı kontrol ettiği API anlık görüntüsünden oluşturulmuştur, bu nedenle bir dışa aktarma
bu referans değişmeden veya CI başarısız olmadan kaybolamaz.
