# 🌍 `useLocaleHead` composable'ı

`useLocaleHead` composable'ı, `Nuxt I18n Micro`'da yerelleştirilmiş rotalar için SEO niteliklerini ve HTML meta etiketlerini yönetmene yardım eden bir yardımcıdır. HTML belgesinin `lang` ve `dir` nitelikleri için dinamik olarak öznitelikler oluşturur ve yerelleştirilmiş içeriğinin SEO'sunu iyileştirmek için `meta` ve `link` etiketleri üretir.

## ⚙️ Seçenekler

{/* generated:symbol:useLocaleHead — do not edit; run `pnpm run docs:generate` */}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }, MetaObject | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

Geçerli rota için SEO head etiketleri: her yerel ayar için `hreflang` alternatifleri artı `x-default`, bir canonical bağlantı, `og:locale` ve `<html>` üzerinde `lang`/`dir`.

Yalnızca `meta` devre dışı bırakıldığında veya varsayılanların ayarlanması gerektiğinde gereklidir. `meta: true` ile modül aynı etiketleri kendisi kaydeder.

```ts
const head = useLocaleHead({ addSeoAttributes: true })
```

## 🛠️ Dönüş değerleri

`useLocaleHead` composable'ı, kaynak veriler değiştiğinde çağırman gereken reaktif bir nesne ve bir güncelleyici fonksiyon döner. Her iki şekil de yukarıdaki imzada kaynaktan oluşturulmuştur.

### `metaObject`

`useHead(metaObject)`'e uygun reaktif head yükü (html attrs, meta, link).

- **Örnek**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

Geçerli rota, yerel ayar ve yapılandırmaya göre `metaObject`'i yeniden hesaplar. Girdiler değiştiğinde (örneğin rota değiştiğinde) çağır.

- **Örnek**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### `link` ve `meta`'ya erişim

`link` ve `meta` dizilerine `metaObject.value` üzerinden erişilebilir:

- **Örnek**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ Örnek kullanımlar

### Temel kullanım

Varsayılan seçeneklerle yerel ayara özel head nitelikleri üret.

```js
const head = useLocaleHead()
```

### Tanımlayıcı niteliğini özelleştir

Üretilen etiketler için özel bir tanımlayıcı niteliği kullan.

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### SEO niteliklerini devre dışı bırak

SEO ile ilgili meta ve link etiketleri eklemeden head nitelikleri üret.

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### Temel URL belirt

Canonical ve alternatif URL'ler için özel bir temel URL ayarla.

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 Ek özellikler

### SEO meta ve link etiketleri

`addSeoAttributes` etkinken composable, aşağıdaki etiketleri otomatik olarak üretir:

- Geçerli yerel ayar için `og:locale` (`language_TERRITORY`, alt çizgi). `locale.og`'den türetilir veya mümkün olduğunda `locale.iso`'dan dönüştürülür.
- Sayfanın canonical URL'si için `og:url`.
- Alternatif dil sürümleri için `og:locale:alternate`.
- SEO optimizasyonu için `rel="canonical"` ve `rel="alternate"` bağlantıları.
- Varsayılan yerel ayarın URL'sine işaret eden `hreflang="x-default"` bağlantısı. Bu, arama motorlarına, dilinin tanımlı yerel ayarlarla eşleşmediği kullanıcılara hangi URL'yi göstereceklerini söyler.

### Dinamik yerel ayar ve yön

Composable, `lang` ve `dir` niteliklerini geçerli rotanın yerel ayarına göre dinamik olarak belirler; böylece HTML belgen uluslararası kullanıcılar için doğru şekilde yapılandırılır.

### Yerelleştirilmiş rotaların işlenmesi

Rotaların önünde yerel ayar kodları varsa (örn. `/en/about`), composable URL'leri üretmek için tam yolu akıllıca ayarlar ve SEO niteliklerinin doğru ve alakalı olmasını sağlar.

Bu composable, Nuxt uygulamanı uluslararası kitleler için optimize etme sürecini basitleştirir ve sitenin global arama motorları ve kullanıcılar için iyi hazırlanmasını sağlar.

## 🛠️ Örnek kullanım

Aşağıdaki örnek, varsayılan ayarlarla bir Vue bileşeninde `useLocaleHead` composable'ının nasıl kullanılacağını gösterir:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### Kodun açıklaması

- **`useLocaleHead` composable'ı**: Bu composable, `<script setup>` bölümünde çağrılır ve `htmlAttrs`, `meta` ve `link` içeren bir nesne döner.

- **`<html>` etiketi**: HTML belgesi için `lang` ve `dir` nitelikleri geçerli yerel ayara göre dinamik olarak belirlenir ve `<html>` etiketine uygulanır.

- **`<head>` bölümü**:
  - **Meta etiketler**: SEO ile ilgili meta etiketler üretilir; sayfanın alternatif dil sürümlerini belirtmek için `og:locale`, `og:url` ile `rel="canonical"` ve `rel="alternate"` etiketleri dahil.
  - **Link etiketler**: Canonical bağlantılar, alternatif dil sürümlerine bağlantılar ve varsayılan yerel ayar URL'sine işaret eden `hreflang="x-default"` bağlantısı dahil edilir.

- **`<body>` bölümü**: Sayfanın ana içeriği burada gösterilir. Bu örnekte basit bir başlık ve paragraf kullanılır.

### 📝 Notlar

1. **Nitelikler**: Kullanılan nitelikler (`lang`, `dir`, `rel`, `href`, `hreflang`, `property`, `content`) `useLocaleHead` tarafından döndürülen nesneden çıkarılır.

2. **SEO etiketleri üretimi**: `addSeoAttributes` seçeneği `true` olarak ayarlanırsa composable, geçerli yerel ayar için SEO etiketlerini otomatik olarak üretir.

3. **Temel URL**: Canonical ve alternatif bağlantıları doğru şekilde üretmek için `baseUrl` seçeneğiyle özel temel URL'ni ayarlayabilirsin.

Bu örnek, uygulamanın bileşenlerine `useLocaleHead`'i entegre etmenin, doğru SEO niteliklerini sağlamanın ve yerelleştirilmiş sayfaların arama motoru dizinlemesini iyileştirmenin ne kadar kolay olduğunu gösterir.

## 🧩 Özelleştirme ve yaşam döngüsü

- `useLocaleHead` kendi başına değişikliklere abone olmaz. `metaObject` ve `updateMeta` döner.
- Girdiler değiştiğinde (tipik olarak rota değiştiğinde) `updateMeta()`'yı çağırmalısın; örneğin bir eklentiden:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## `useI18nHead`'i ne zaman kullanmalı

`meta: true` (varsayılan) olduğunda, **sayfa başına** geçersiz kılmalar (özel hreflang, ek `og:title`, kısmi devre dışı bırakma) için [`useI18nHead`](/api/composables/use-i18n-head)'i tercih et. `useLocaleHead`'i yalnızca `meta: false` olduğunda veya `useHead`'i kendin yönettiğinde doğrudan kullan.
