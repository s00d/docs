# 🛠️ `useI18n` composable'ı

`Nuxt I18n Micro`'daki `useI18n` composable'ı, bileşenler ve script'lerde çoğu çalışma zamanı i18n yardımcısına erişim sağlar. Metotlar hem `$` önekiyle hem de öneksiz kullanılabilir (örneğin `$t` ve `t`).

Bazı enjeksiyonlar (`$defineI18nRoute` ve `$clearCache`) yalnızca `useNuxtApp()` üzerinden erişilebilir. [Metotlar — `$defineI18nRoute`](/api/methods#definei18nroute) ve [`$clearCache`](/api/methods#clearcache) sayfasına bak.

## 📊 Ne döndürür

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Her çalışma zamanı yardımcısı, düz bir nesne olarak.

Eklentinin `$t`, `$tc` gibi enjekte ettiği aynı fonksiyonlar; hem dolar önekli adla hem de çıplak takma adla mevcuttur. Böylece `const \{ t \} = useI18n()` ve `const \{ $t \} = useI18n()` her ikisi de çalışır.

**Döner**: [Metotlar referansındaki](/api/methods) yardımcılar

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

Döndürdüğü her yardımcı (`$t`, `$tc`, `$has`, `$switchLocale` ve diğerleri) imzasıyla listelenir ve [Metotlar referansında](/api/methods) tam olarak belgelenmiştir.

## Yalnızca `useNuxtApp()` API'leri

Bunlar `useI18n()` tarafından **döndürülmez**. `useNuxtApp()`'ten içe aktar:

| Metot                      | Amaç                                                                            |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | `script setup` içinde sayfa başına yerel ayar rotaları, kısıtlamalar ve satır içi çeviriler |
| `$clearCache()`            | Bellek içi çeviri önbelleğini ve yüklenen parçaları temizler                    |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Tam imzalar ve örnekler için [Metotlar](/api/methods) sayfasına bak.

## 🛠️ Örnek kullanımlar

### Temel yerel ayar getirme

Uygulamanın geçerli yerel ayarını al.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Parametrelerle çeviri

Dinamik parametrelerle ve varsayılan bir yedek değerle bir dizeyi çevir.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Yerel ayar değiştirme

Uygulamayı farklı bir yerel ayara geçir.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Yerelleştirilmiş rota üretme

Geçerli veya belirtilen yerel ayara yerelleştirilmiş bir rota üret.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
