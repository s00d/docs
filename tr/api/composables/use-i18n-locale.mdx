# useI18nLocale

## İmza

{/* generated:symbol:useI18nLocale — do not edit; run `pnpm run docs:generate` */}

```ts
useI18nLocale(): { getEffectiveLocale: (route: unknown, getLocaleFromRoute: GetLocaleFromRoute) => string; getLocale: () => string | null; getLocaleWithServerFallback: (serverLocale?: string | null) => string | null; getPreferredLocale: () => string | null; hashCookie: any; isValidLocale: (locale: string | null | undefined) => locale is string; locale: any; localeCookie: any; resolveInitialLocale: (options: ResolveInitialLocaleOptions) => string; setLocale: (locale: string | null) => void; syncLocale: (locale: string | null) => void; validLocales: string[] }
```

i18n yerel ayar yönetimi için merkezi giriş noktası. useState('i18n-locale')'ı, yerel ayar çerezini ve senkronizasyon yardımcılarını birleştirir.

{/* /generated:symbol:useI18nLocale */}

## Kullanım

```vue
<script setup>
const {
  locale,
  localeCookie,
  hashCookie,
  validLocales,
  getPreferredLocale,
  getLocale,
  getLocaleWithServerFallback,
  getEffectiveLocale,
  resolveInitialLocale,
  setLocale,
  syncLocale,
  isValidLocale,
} = useI18nLocale()

// Set locale (updates state and cookies)
setLocale('de')

// Get current locale (state → cookie)
const current = getLocale()

// Get valid preferred locale
const preferred = getPreferredLocale()
</script>
```

## API

| Özellik/Metot                                   | Tür                                 | Açıklama                                                                             |
| ----------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| `locale`                                        | `Ref<string \| null>`               | Reaktif yerel ayar durumu (`useState('i18n-locale')`)                                |
| `localeCookie`                                  | `Ref`                               | Yerel ayar çerezi (`localeCookie` seçeneği etkinken)                                 |
| `hashCookie`                                    | `Ref`                               | `hashMode` etkinken kullanılan çerez                                                 |
| `validLocales`                                  | `string[]`                          | Modül yapılandırmasından etkin yerel ayar kodları (`disabled` olanlar hariç)         |
| `getLocale()`                                   | `() => string \| null`              | Geçerli yerel ayar: state → çerez (veya hash modunda hash çerezi)                    |
| `getPreferredLocale()`                          | `() => string \| null`              | State/çerezdeki yerel ayar `validLocales` ile **doğrulanmış** ya da `null`           |
| `getLocaleWithServerFallback(serverLocale?)`    | `(serverLocale?) => string \| null` | State → çerez → opsiyonel sunucu bağlamı (`no_prefix` başlatma sırasında kullanılır) |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string`             | Çevirileri yüklemek için yerel ayar: hash modu state'i tercih eder; aksi halde rotadan okur |
| `resolveInitialLocale(options)`                 | `(options) => string`               | Yerel ayarı çözer: state → `serverLocale` → rota; gerektiğinde state'i senkronize eder |
| `setLocale(locale)`                             | `(locale: string \| null) => void`  | Yerel ayarı ayarlar ve çerezlere senkronize eder                                     |
| `syncLocale(locale)`                            | `(locale: string \| null) => void`  | Yalnızca çerezleri senkronize eder (state güncellemesi yok)                          |
| `isValidLocale(locale)`                         | `(locale) => boolean`               | Bir string'in `validLocales` içinde olup olmadığını kontrol eder                     |

### `resolveInitialLocale` seçenekleri

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

Ana eklenti tarafından başlangıçta dahili olarak kullanılır. Alternatif algılama akışları uygulayan özel eklentiler bunu çağırabilir.

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

Belirli bir rota nesnesi için çevirileri yüklemek ve mesajları biçimlendirmek üzere kullanılan yerel ayarı döner.

## Programatik yerel ayar ayarlama

Doğrudan `useState('i18n-locale')` kullanımı yerine `useI18nLocale()` tercih edilir:

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
`setLocale()` yalnızca yerel ayar tercihini (state + çerez) günceller. İstemcide aktif çeviri bağlamını da yeniden yüklemek için `useNuxtApp()` veya `useI18n()` üzerinden `$switchLocale()` kullan. Bu özellikle URL'nin değişmediği `no_prefix` için önemlidir. [SSS — URL'yi değiştirmeden yerel ayarı değiştir](/guides/faq#-switch-locale-without-changing-the-url) sayfasına bak.
</Tip>
