[CLI kılavuzu](/tr/guide/cli) yaygın iş akışlarını gösterir. Bu sayfa her şeyi listeler ve `--help` çıktısını oluşturan aynı tablodan üretilir.

## Ortak bayraklar {#common-flags}

| Bayrak | Varsayılan | Açıklama |
| --- | --- | --- |
| `--cwd` | geçerli dizin | Proje dizini |
| `--logLevel` | `info` | Çıktı düzeyi: silent, info |
| `--debug` | `false` | Bir komut başarısız olduğunda yığın izini yazdırır |

## İnceleme {#inspect}

### `info` {#info}

Projenin çözümlenmiş i18n yapılandırmasını yazdırır

| Bayrak | Varsayılan | Açıklama |
| --- | --- | --- |
| `--json` | `false` | Metin yerine JSON yazdırır |

### `check` {#check}

CI kapısı: eksik, boş, fazla, tanımsız veya kullanılmayan anahtarlarda ve bozuk yer tutucularda başarısız olur

| Bayrak | Varsayılan | Açıklama |
| --- | --- | --- |
| `--translationDir` | nuxt.config içindeki `i18n.translationDir` | Projeye göreli çeviri dizini |
| `--only` | duplicates dışında hepsi | Çalıştırılacak denetimler, virgülle ayrılmış: missing, empty, extra, placeholders, undefined, unused, duplicates. Burada belirtilen `unused` çalıştırılamadığında başarısız olur |
| `--duplicates` | `false` | Farklı anahtarlar altındaki aynı metni de raporlar |
| `--ignore` | — | Atlanacak kaynak dosyaların virgülle ayrılmış, projeye göreli glob desenleri |
| `--json` | `false` | Metin yerine JSON yazdırır |

```bash
i18n-micro check
i18n-micro check --only missing,placeholders --json
```

### `stats` {#stats}

Her locale için çeviri tamamlanma oranını gösterir

| Bayrak | Varsayılan | Açıklama |
| --- | --- | --- |
| `--translationDir` | nuxt.config içindeki `i18n.translationDir` | Projeye göreli çeviri dizini |
| `--html` | — | Bu dosyaya ayrıca bir HTML raporu yazar |
| `--json` | `false` | Metin yerine JSON yazdırır |
| `--baseRef` | — | Tamamlanma oranının karşılaştırılacağı Git ref'i, örn. HEAD~1 veya main |

```bash
i18n-micro stats --baseRef main
i18n-micro stats --html reports/i18n.html
```

### `lint` {#lint}

Çevirilerin metnini denetler; sorunlar kalırsa başarısız olur

| Bayrak | Varsayılan | Açıklama |
| --- | --- | --- |
| `--translationDir` | nuxt.config içindeki `i18n.translationDir` | Projeye göreli çeviri dizini |
| `--rules` | hepsi veya .i18n-lintrc.json içindeki `enabledRules` | Çalıştırılacak kurallar, virgülle ayrılmış: no-trailing-spaces, no-multiple-spaces, no-empty-translation veya özel bir kural |
| `--fix` | `false` | Düzeltilebilecekleri düzeltir: boşluklar ve değiştirme metni olan özel kurallar |
| `--json` | `false` | Metin yerine JSON yazdırır |

```bash
i18n-micro lint --rules no-trailing-spaces --fix
```

### `search` {#search}

Anahtarlarda ve değerlerde arama yapar ve her anahtarın nerede kullanıldığını gösterir

| Bayrak | Varsayılan | Açıklama |
| --- | --- | --- |
| `--translationDir` | nuxt.config içindeki `i18n.translationDir` | Projeye göreli çeviri dizini |
| `<query>` | — | Aranacak metin veya anahtar |
| `--caseSensitive` | `false` | Büyük/küçük harfe duyarlı eşleştirir |
| `--onlyUnused` | `false` | Yalnızca `clean` komutunun kaldıracağı anahtarlar; sorgu isteğe bağlı hâle gelir |
| `--scope` | `all` | Aranacak yer: global, pages, all |
| `--limit` | — | En fazla bu kadar anahtar döndürür |
| `--ignore` | — | Atlanacak kaynak dosyaların virgülle ayrılmış, projeye göreli glob desenleri |
| `--json` | `false` | Metin yerine JSON yazdırır |

```bash
i18n-micro search "Welcome"
i18n-micro search --onlyUnused
```

## Çeviri iş akışı {#translation-workflow}

### `extract` {#extract}

Kaynak dosyaların kullandığı ancak henüz metni olmayan anahtarları listeler ve varsayılan metni olanları varsayılan locale'e ekler

| Bayrak | Varsayılan | Açıklama |
| --- | --- | --- |
| `--translationDir` | nuxt.config içindeki `i18n.translationDir` | Projeye göreli çeviri dizini |
| `--ignore` | — | Atlanacak kaynak dosyaların virgülle ayrılmış, projeye göreli glob desenleri |

```bash
i18n-micro extract
```

### `translate` {#translate}

Eksik çevirileri bir çeviri hizmeti aracılığıyla varsayılan locale'den doldurur

| Bayrak | Varsayılan | Açıklama |
| --- | --- | --- |
| `--translationDir` | nuxt.config içindeki `i18n.translationDir` | Projeye göreli çeviri dizini |
| `--service` | — | Çeviri hizmeti: ai, azure, deepl, google, libretranslate, yandexcloud |
| `--token` | — | API anahtarı. I18N_TRANSLATE_TOKEN ortam değişkenini tercih edin: bayraklar kabuk geçmişine kaydedilir |
| `--options` | — | Virgülle ayrılmış key:value çiftleri biçiminde hizmet seçenekleri |
| `--locale` | varsayılan dışındaki tüm locale'ler | Doldurulacak locale'ler, virgülle ayrılmış |
| `--replace` | `false` | Her anahtarı yeniden çevirir, mevcut değerlerin yerine yazar |
| `--dryRun` | `false` | Her locale için anahtarları ve karakterleri sayar; hiçbir şey göndermez |
| `--chunkSize` | — | İstek başına dize sayısı; hizmetin kabul ettiği sınırla kısıtlanır |
| `--pluralSeparator` | `\|` | Mesajlardaki çoğul biçimlerin ayırıcısı |
| `--glossaryFile` | varsa `.i18n-glossary.json` | `ai` hizmetinin kullandığı sözlük dosyası |

```bash
i18n-micro translate --dryRun
I18N_TRANSLATE_TOKEN=... i18n-micro translate --service deepl --locale de,fr
i18n-micro translate --service ai --options provider:openai,model:gpt-4o-mini
i18n-micro translate --service libretranslate --options baseUrl:https://translate.example.com
```

### `sync` {#sync}

Varsayılan locale'de olmayan anahtarları kaldırır; bunun güvenli olduğu kanıtlanamazsa durur. Eksik anahtarlar eksik kalır

| Bayrak | Varsayılan | Açıklama |
| --- | --- | --- |
| `--translationDir` | nuxt.config içindeki `i18n.translationDir` | Projeye göreli çeviri dizini |
| `--ignore` | — | Atlanacak kaynak dosyaların virgülle ayrılmış, projeye göreli glob desenleri |
| `--dryRun` | `false` | Kaldırılacakları listeler; hiçbir şey yazmaz |
| `--force` | `false` | Güvenli olduğu kanıtlanamasa da anahtarları kaldırır |

```bash
i18n-micro sync --dryRun
```

### `clean` {#clean}

Projede hiçbir şeyin kullanmadığı anahtarları kaldırır; bu kanıtlanamazsa durur

| Bayrak | Varsayılan | Açıklama |
| --- | --- | --- |
| `--translationDir` | nuxt.config içindeki `i18n.translationDir` | Projeye göreli çeviri dizini |
| `--include` | — | Düzenli ifade: kaldırma için yalnızca eşleşen anahtarları dikkate alır |
| `--exclude` | — | Düzenli ifade: eşleşen anahtarları asla kaldırmaz |
| `--ignore` | — | Atlanacak kaynak dosyaların virgülle ayrılmış, projeye göreli glob desenleri |
| `--dryRun` | `false` | Kaldırılacakları listeler; hiçbir şey yazmaz |
| `--force` | `false` | Hepsinin kullanımı kanıtlanamasa da anahtarları kaldırır |

```bash
i18n-micro clean --dryRun
i18n-micro clean --exclude '^errors\.'
```

## Yeniden düzenleme {#refactoring}

### `text-to-i18n` {#text-to-i18n}

Vue şablonlarındaki sabit kodlanmış metni çeviri çağrılarıyla değiştirir ve koddaki sabit kodlanmış metni raporlar

| Bayrak | Varsayılan | Açıklama |
| --- | --- | --- |
| `--translationFile` | `<translationDir>/<defaultLocale>.json` | Yeni anahtarların yazılacağı dosya |
| `--path` | tüm proje | İşlenecek dosya veya dizin |
| `--context` | — | Üretilen anahtarlar için önek |
| `--ignore` | — | Atlanacak kaynak dosyaların virgülle ayrılmış, projeye göreli glob desenleri |
| `--dryRun` | `false` | Nelerin değişeceğini gösterir; hiçbir şey yazmaz |
| `--interactive` | `false` | Üretilen her anahtarı onaylatır veya düzenletir |

```bash
i18n-micro text-to-i18n --dryRun
i18n-micro text-to-i18n --path components --context ui
```

### `rename` {#rename}

Bir anahtarı veya ad alanını tüm locale'lerde ve kaynak dosyalarda yeniden adlandırır

| Bayrak | Varsayılan | Açıklama |
| --- | --- | --- |
| `--translationDir` | nuxt.config içindeki `i18n.translationDir` | Projeye göreli çeviri dizini |
| `--from` **\*** | — | Mevcut anahtar veya ad alanı |
| `--to` **\*** | — | Yeni anahtar veya ad alanı |
| `--ignore` | — | Atlanacak kaynak dosyaların virgülle ayrılmış, projeye göreli glob desenleri |
| `--dryRun` | `false` | Değişiklikleri raporlar; hiçbir şey yazmaz |

**\*** zorunlu.

```bash
i18n-micro rename --from common.save --to actions.save
```

### `pseudo` {#pseudo}

Düzen sorunlarını ve sabit kodlanmış metin sorunlarını bulmak için bir locale'i sözde çevirilerle doldurur

| --- | --- | --- |
| `--translationDir` | nuxt.config içindeki `i18n.translationDir` | Projeye göreli çeviri dizini |
| `--sourceLocale` | varsayılan locale | Okunacak locale |
| `--targetLocale` **\*** | — | Doldurulacak locale |
| `--replace` | `false` | Mevcut değerlerin üzerine yazar |

**\*** zorunlu.

### `format` {#format}

Locale dosyalarını sıralı anahtarlar ve tek tip girintiyle yeniden yazar

| Bayrak | Varsayılan | Açıklama |
| --- | --- | --- |
| `--translationDir` | nuxt.config içindeki `i18n.translationDir` | Projeye göreli çeviri dizini |
| `--indent` | `2` | Girinti boşluk sayısı |
| `--sortKeys` | `true` | Anahtarları sıralar; sıralarını korumak için --no-sortKeys kullanın |
| `--check` | `false` | Bir dosya değişecekse başarısız olur; hiçbir şey yazmaz |

```bash
i18n-micro format --check
```

## Veri alışverişi {#exchange}

### `export` {#export}

Locale dosyalarını, kaynak olarak varsayılan locale metniyle PO veya CSV biçimine aktarır

| Bayrak | Varsayılan | Açıklama |
| --- | --- | --- |
| `--translationDir` | nuxt.config içindeki `i18n.translationDir` | Projeye göreli çeviri dizini |
| `--format` | `po` | Dosya biçimi: po, csv |
| `--dir` | po için `pots`, csv için `csv_exports` | Projeye göreli çıktı dizini |
| `--force` | `false` | Son dışa aktarımdan bu yana değişmiş ve hiç içe aktarılmamış dosyaların üzerine yazar |

```bash
i18n-micro export --format csv
```

### `import` {#import}

PO veya CSV dosyalarını locale dosyalarıyla birleştirir

| Bayrak | Varsayılan | Açıklama |
| --- | --- | --- |
| `--translationDir` | nuxt.config içindeki `i18n.translationDir` | Projeye göreli çeviri dizini |
| `--format` | `po` | Dosya biçimi: po, csv |
| `--dir` | po için `pots`, csv için `csv_exports` | Projeye göreli girdi dizini |
| `--dryRun` | `false` | Nelerin içe aktarılacağını raporlar; hiçbir şey yazmaz |

```bash
i18n-micro import --format csv --dryRun
```

### `sync-remote` {#sync-remote}

Global çevirileri .i18n-remote.json içindeki HTTP uç noktasından çeker veya oraya gönderir

| Bayrak | Varsayılan | Açıklama |
| --- | --- | --- |
| `--translationDir` | nuxt.config içindeki `i18n.translationDir` | Projeye göreli çeviri dizini |
| `--pull` | `true` | Uzak kaynaktan çeker |
| `--push` | `false` | Uzak kaynağa gönderir |
| `--force` | `false` | Çekmede uzak değeri alır; göndermede yalnızca uzak kaynakta bulunan metnin üzerine yazar |
| `--dryRun` | `false` | Bir çekmenin neyi değiştireceğini raporlar; hiçbir şey yazmaz ve göndermez |

```bash
i18n-micro sync-remote --dryRun
i18n-micro sync-remote --no-pull --push
```

## Lint kuralları {#lint-rules}

| Kural | Bulduğu | `--fix` ile düzeltilir |
| --- | --- | --- |
| `no-trailing-spaces` | Bir değerin veya satırın sonundaki boşluklar | evet |
| `no-multiple-spaces` | Art arda iki veya daha fazla boşluk | evet |
| `no-empty-translation` | Boş veya yalnızca boşluk içeren bir değer | hayır |

## Çıkış kodları {#exit-codes}

| Kod | Anlamı |
| --- | --- |
| `0` | Tamamlandı, raporlanacak bir şey yok |
| `1` | Bulgular: `check`, `lint` veya `format --check` bir şey buldu, `clean` veya `sync` bir kaldırmanın güvenli olduğunu kanıtlayamadı, `export` içe aktarılmamış çalışmanın üzerine yazacaktı, `translate` bazı anahtarları dışarıda bıraktı, `import` veya `sync-remote` bir çakışmayla karşılaştı, bir `sync-remote` gönderimi uzak metni silecekti. `clean`, `sync` veya bir `sync-remote` çekmesinin `--dryRun` çalıştırması bunları raporlar ve `0` ile çıkar |
| `2` | Hata: hatalı kullanım, okunamayan proje, ağ veya dosya hatası |

## Yapılandırma dosyaları {#configuration-files}

| Dosya | Kullanan |
| --- | --- |
| `.i18n-lintrc.json` | `lint`: `enabledRules`, `disabledRules`, `customRegexRules` (`name`, `pattern`, `flags`, `description`, `replacement`) |
| `.i18n-remote.json` | `sync-remote`: `url`, `path`, `token`, `auth` (`username`, `password`). `type` atlanabilir; yalnızca `custom` mevcuttur |
| `.i18n-glossary.json` | `translate --service ai`: `source`, `target` ve isteğe bağlı `from`, `to` içeren `entries` |

## Ortam değişkenleri {#environment-variables}

| Ad | Kullanım amacı |
| --- | --- |
| `I18N_TRANSLATE_TOKEN` | `translate` için API anahtarı. `.env` dosyasından da okunur |
| `I18N_REMOTE_TOKEN` | `sync-remote` için Bearer token. `.env` dosyasından da okunur |
| `AI_GATEWAY_API_KEY, OPENAI_API_KEY, ANTHROPIC_API_KEY` | `I18N_TRANSLATE_TOKEN` ayarlanmadığında `ai` hizmetinin anahtarı |
| `DEFAULT_LOCALE` | Modülde olduğu gibi `defaultLocale` değerini geçersiz kılar |
