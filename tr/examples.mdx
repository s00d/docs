# 📚 Nuxt I18n Micro örnekleri ve kullanımı

Bu bölüm, Nuxt.js uygulamanda `Nuxt I18n Micro`'nun nasıl kullanılacağını gösteren çeşitli örnekler sunar. Yerel ayarları nasıl değiştireceğini, `<i18n-link>`, `<i18n-switcher>` ve `<i18n-t>` bileşenlerinin nasıl kullanılacağını ve çeviri anahtarlarını dinamik olarak nasıl işleyeceğini göreceksin.

## 🛠️ Temel kurulum

`Nuxt I18n Micro` ile başlamak için temel bir kurulum:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Yerel ayar değiştirme

### Yerel ayarları programatik olarak değiştirme

Bu örnek, düğmeler kullanarak yerel ayarları programatik olarak nasıl değiştireceğini gösterir:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Yerel ayar değişimi için örnek JSON

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### `<i18n-switcher>` bileşenini kullanma

`<i18n-switcher>` bileşeni, özelleştirilebilir etiketlerle yerel ayar değişimi için bir açılır menü sağlar:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 🌐 Yerelleştirilmiş gezinme için `<i18n-link>` kullanımı

`<i18n-link>` bileşeni, yerel ayar özelinde yönlendirmeyi otomatik olarak yönetir:

```vue
<template>
  <div>
    <i18n-link to="/about">{{ $t('about') }}</i18n-link>
    <i18n-link :to="{ name: 'index' }">{{ $t('home') }}</i18n-link>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Gezinme bağlantıları için örnek JSON

```json
{
  "about": "About Us",
  "home": "Home"
}
```

### Aktif bağlantı stili örneği

```vue
<template>
  <div>
    <i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
  </div>
</template>
```

## 📝 Çeviri dosyalarından dinamik anahtar oluşturma

Bazı durumlarda, çeviri dosyalarında saklanan dinamik anahtarlar üzerinde iterasyon yapmak ve değerlerini koşullu olarak oluşturmak isteyebilirsin. Aşağıdaki örnek, bunu `Nuxt I18n Micro` ile nasıl yapacağını gösterir.

### Örnek: Dinamik anahtarları oluşturma

Bu örnek, belirli bir çeviri yolundan (bu durumda `dynamic`) bir anahtar dizisi çeker ve üzerinde iterasyon yapar. Her anahtar, değeri `$t` ile oluşturulmadan önce varlığı `$has` kullanılarak kontrol edilir.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Örnek çeviri dosyası (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Örnek: Bir nesneden dinamik anahtarları oluşturma

Bu örnekte, çeviri dosyanda saklanan bir nesneyi ele alıyoruz. Nesnenin anahtarlarını çekip üzerinde iterasyon yapıyoruz; hem anahtar adlarını hem de ilgili değerleri dinamik olarak oluşturuyoruz.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Örnek çeviri dosyası (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 Yuvalar ve enterpolasyon ile çeviriler için `<i18n-t>` kullanımı

`<i18n-t>` bileşeni, dinamik içerik ve HTML etiketleriyle çeviri oluşturmak için kullanışlıdır:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### `<i18n-t>` için örnek JSON

```json
{
  "greeting": "Welcome to the page"
}
```

### Enterpolasyon ile

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### Enterpolasyon için örnek JSON

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 Çoğullaştırma için `$tc` kullanımı

`Nuxt I18n Micro`'daki `$tc` fonksiyonu, sayıya ve yerel ayarlara göre çoğullaştırmayı yönetir. Bu; öğeler, bildirimler veya sayısı değişebilen diğer varlıklar gibi sayı içeren mesajları dinamik olarak ayarlamak için kullanışlıdır.

### Örnek: Çoğullaştırma için `$tc` kullanımı

Aşağıdaki örnekte, `$tc` kullanarak elma sayısını belirten bir mesaj gösteriyoruz. Çeviri anahtarı, verilen sayıya göre birden çok çoğul biçimi işler.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### Çoğullaştırma için örnek JSON

Farklı çoğul biçimleri işlemek için JSON dosyanda çeviriyi şu şekilde tanımlayabilirsin:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Açıklama

- **`$tc('apples', 0)`**: Sayı sıfır olduğunda kullanılan birinci biçimi döner (`"no apples"`).
- **`$tc('apples', 1)`**: Sayı bir olduğunda kullanılan ikinci biçimi döner (`"one apple"`).
- **`$tc('apples', 10)`**: Sayı iki veya daha fazla olduğunda kullanılan, sayı değerini içeren üçüncü biçimi döner (`"10 apples"`).

### Daha karmaşık çoğullaştırma için ek örnek

Uygulamanın daha karmaşık çoğullaştırma kurallarını işlemesi gerekiyorsa (örneğin sıfır, bir, iki, birkaç, çok, diğer için özel durumlar), çeviri dizelerini buna göre genişletebilirsin:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: `"two apples"` dönecek şekilde ayarlanabilir.
- **`$tc('apples', 3)`**: Sayı için tanımlanan kurallara bağlı olarak `"a few apples"` dönebilir.

## 🌐 Sayı biçimlendirme için `$tn` kullanımı

`$tn` fonksiyonu, `Intl.NumberFormat` API'si kullanarak sayıları geçerli yerel ayara göre biçimlendirir. Bu; kullanıcının bölgesel ayarlarına uyan biçimlerde para birimi, yüzde veya diğer sayı biçimlerini göstermek için kullanışlıdır.

### Örnek: Sayı biçimlendirme için `$tn` kullanımı

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ Tarih ve saat biçimlendirme için `$td` kullanımı

`$td` fonksiyonu, `Intl.DateTimeFormat` API'si kullanarak tarih ve saatleri geçerli yerel ayara göre biçimlendirir. Bu, kullanıcıya yerel ayarına göre tanıdık biçimlerde tarih ve saat göstermek için kullanışlıdır.

### Örnek: Tarih ve saat biçimlendirme için `$td` kullanımı

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ Göreli tarih biçimlendirme için `$tdr` kullanımı

`$tdr` fonksiyonu, `Intl.RelativeTimeFormat` API'si kullanarak tarihleri geçerli yerel ayara göre göreli zamanlar (örn. "5 dakika önce", "2 gün önce") olarak biçimlendirir. Bu, geçerli tarih ve saate göre zaman farklarını göstermek için kullanışlıdır.

### Örnek: Göreli tarih biçimlendirme için `$tdr` kullanımı

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
