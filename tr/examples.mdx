# 📚 Nuxt I18n Micro Örnekleri ve Kullanımı

Bu bölüm, Nuxt.js uygulamanızda `Nuxt I18n Micro`'nun nasıl kullanılacağını gösteren çeşitli örnekler sunar. Yerel ayarları değiştirme, `<i18n-link>`, `<i18n-switcher>` ve `<i18n-t>` bileşenlerini kullanma ve çeviri anahtarlarını dinamik olarak işleme yollarını göreceksiniz.

## 🛠️ Temel Kurulum

`Nuxt I18n Micro` ile başlamak için temel bir kurulum:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Yerel Ayar Değiştirme

### Yerel Ayarları Programatik Olarak Değiştirme

Bu örnek, düğmeler kullanarak yerel ayarların programatik olarak nasıl değiştirileceğini gösterir:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Yerel Ayar Değiştirme için Örnek JSON

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### `<i18n-switcher>` Bileşenini Kullanma

`<i18n-switcher>` bileşeni, özelleştirilebilir etiketlerle yerel ayar değiştirmek için bir açılır menü sağlar:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 🌐 Yerelleştirilmiş Gezinme için `<i18n-link>` Kullanımı

`<i18n-link>` bileşeni, yerel ayara özgü yönlendirmeyi otomatik olarak ele alır:

```vue
<template>
  <div>
    <i18n-link to="/about">{{ $t('about') }}</i18n-link>
    <i18n-link :to="{ name: 'index' }">{{ $t('home') }}</i18n-link>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

```

### Gezinme Bağlantıları için Örnek JSON

```json
  "home": "Home"
}
```

## 📝 Çeviri Dosyalarından Dinamik Anahtarları Oluşturma

Bazı senaryolarda, çeviri dosyalarınızda depolanan dinamik anahtarlar üzerinde yineleme yapmak ve değerlerini koşullu olarak render etmek isteyebilirsiniz. Aşağıdaki örnek, bunu `Nuxt I18n Micro` ile nasıl yapacağınızı gösterir.

### Örnek: Dinamik Anahtarları Oluşturma

Bu örnek, belirli bir çeviri yolundan (bu durumda `dynamic`) bir anahtar dizisi alır ve üzerinde yineleme yapar. Her anahtarın varlığı `$has` ile kontrol edildikten sonra değeri `$t` ile render edilir.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Örnek Çeviri Dosyası (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Örnek: Bir Nesneden Dinamik Anahtarları Oluşturma

Bu örnekte, çeviri dosyanızda depolanan bir nesneyi ele alıyoruz. Nesnenin anahtarlarını alıp üzerinde yineleme yaparak hem anahtar adlarını hem de ilişkili değerlerini dinamik olarak render ediyoruz.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Örnek Çeviri Dosyası (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 Yuvalar ve İnterpolasyon ile Çeviriler için `<i18n-t>` Kullanımı

`<i18n-t>` bileşeni, dinamik içerik ve HTML etiketleri ile çeviriler render etmek için kullanışlıdır:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### `<i18n-t>` için Örnek JSON

```json
{
  "greeting": "Welcome to the page"
}
```

### İnterpolasyon ile

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### İnterpolasyon için Örnek JSON

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 Çoğullaştırma için `$tc` Kullanımı

`Nuxt I18n Micro` içindeki `$tc` işlevi, sayıya ve yerel ayar ayarlarına dayalı olarak çoğullaştırmayı işler. Bu, öğeler, bildirimler veya sayıya göre değişebilen diğer varlıklar gibi sayıları içeren mesajları dinamik olarak ayarlamak için kullanışlıdır.

### Örnek: Çoğullaştırma için `$tc` Kullanımı

Aşağıdaki örnekte, `$tc` kullanarak elma sayısını belirten bir mesaj gösteriyoruz. Çeviri anahtarı, sağlanan sayıya göre birden fazla çoğul formu ele alır.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### Çoğullaştırma için Örnek JSON

Farklı çoğul formlarını işlemek için çeviriyi JSON dosyanızda şu şekilde tanımlayabilirsiniz:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Açıklama

- **`$tc('apples', 0)`**: Sayı sıfır olduğunda kullanılan ilk formu döndürür (`"no apples"`).
- **`$tc('apples', 1)`**: Sayı bir olduğunda kullanılan ikinci formu döndürür (`"one apple"`).
- **`$tc('apples', 10)`**: Sayı iki veya daha fazla olduğunda sayı değeriyle birlikte üçüncü formu döndürür (`"10 apples"`).

### Daha Karmaşık Çoğullaştırmayla Ek Örnek

Uygulamanızın daha karmaşık çoğullaştırma kurallarını (örneğin, sıfır, bir, iki, birkaç, çok, diğer için özel durumlar) işlemesi gerekiyorsa, çeviri dizelerini buna göre genişletebilirsiniz:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: `"two apples"` döndürecek şekilde ayarlanabilir.
- **`$tc('apples', 3)`**: Sayı için tanımlanan kurallara bağlı olarak `"a few apples"` döndürebilir.

## 🌐 Sayı Biçimlendirme için `$tn` Kullanımı

`$tn` işlevi, `Intl.NumberFormat` API'sini kullanarak sayıları geçerli yerel ayara göre biçimlendirir. Bu, sayıları para birimi, yüzde veya diğer sayı biçimleri gibi kullanıcının bölgesel ayarlarıyla uyumlu bir şekilde görüntülemek için kullanışlıdır.

### Örnek: Sayı Biçimlendirme için `$tn` Kullanımı

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ Tarih ve Saat Biçimlendirme için `$td` Kullanımı

`$td` işlevi, `Intl.DateTimeFormat` API'sini kullanarak tarih ve saatleri geçerli yerel ayara göre biçimlendirir. Bu, tarih ve saatleri kullanıcının yerel ayarlarına göre tanıdık biçimlerde göstermek için kullanışlıdır.

### Örnek: Tarih ve Saat Biçimlendirme için `$td` Kullanımı

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ Göreli Tarih Biçimlendirme için `$tdr` Kullanımı

`$tdr` işlevi, `Intl.RelativeTimeFormat` API'sini kullanarak tarihleri göreli zamanlar olarak (örneğin, "5 dakika önce", "2 gün önce") geçerli yerel ayara göre biçimlendirir. Bu, geçerli tarih ve saate göre zaman farklarını görüntülemek için kullanışlıdır.

### Örnek: Göreli Tarih Biçimlendirme için `$tdr` Kullanımı

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
