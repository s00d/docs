Nuxt I18n Micro, büyük projeler için tasarlanmış, Nuxt 3 ve 4 için hafif ve yüksek performanslı bir i18n modülüdür. `@nuxtjs/i18n` gibi geleneksel i18n çözümlerine kıyasla derleme sürelerini, bellek kullanımını ve paket boyutunu düşük tutar.

Yerelleştirilmiş rotalar derleme zamanında `@i18n-micro/route-strategy` tarafından oluşturulur ve çalışma zamanında `@i18n-micro/path-strategy` tarafından çözümlenir; böylece bağlantılar, dil değiştirici, `hreflang` ve yönlendirmeler router ile her zaman uyumlu olur. Çeviriler yalnızca JSON formatındadır; paylaşılan kök dosyalar ile geliştirme sunucusunun sizin için oluşturduğu sayfa bazlı dosyalar arasında bölünür ve HMR yerleşik olarak gelir.

<CodeGroup>

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>
