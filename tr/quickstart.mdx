## 🚀 Hızlı başlangıç

### Kurulum

Modülü Nuxt uygulamana yükle:

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

### Temel yapılandırma

Modülü `nuxt.config.ts` dosyana ekle:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

<Tip>
- **Kök seviyesindeki dosyalar** (`locales/en.json` vb.) tüm uygulamada paylaşılan çevirilerdir (menüler, altbilgi, ortak arayüz). `translationPayloads.mode: 'premerged'` (varsayılan) ile bunlar derleme zamanında her sayfaya birleştirilir.
- **Sayfaya özel dosyalar** (`locales/pages/<route>/<locale>.json`) belirli sayfalara özgü çevirilerdir ve yalnızca ilgili sayfa ziyaret edildiğinde yüklenir.
- **Dinamik rotalar**: `pages/articles/[id].vue`, `locales/pages/articles-id/` yoluna eşlenir (köşeli parantezler tirelerle değiştirilir).
- **Otomatik üretim**: eksik çeviri dosyalarının tümü `nuxt dev` sırasında otomatik olarak oluşturulur.
</Tip>

<Info>
Modül her iki düzeni de destekler:

- **Sayfalar**: `pages/**/*.vue` (Nuxt 3) veya `app/pages/**/*.vue` (Nuxt 4)
- **Çeviriler**: varsayılan olarak `locales/` klasörünü **proje kökünde** tut (önerilen yaklaşım), `app/` içinde değil.

```tree
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   ├── en.json
│   └── pages/
└── nuxt.config.ts
```

Opsiyonel yan yana yerleşim: `i18n: \{ translationDir: 'app/locales' \}` (bkz. [fikstür `n3`](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/n3)).

Opsiyonel CLI yardımcısı `text-to-i18n` için, `app/pages` ve `app/components` proje kökünden taransın diye [`nuxt-i18n-micro-cli` ≥ 2.1.1](/guides/cli#-text-to-i18n-command) sürümünü kullan.
</Info>

### Temel kullanım

Bileşenlerinde çevirileri kullan:

```vue
<template>
  <div>
    <h1>{{ $t('welcome') }}</h1>
    <p>{{ $t('description', { name: 'World' }) }}</p>

    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" @click="$switchLocale(locale.code)">
        {{ locale.code }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useI18n } from '#imports'

const { $t, $getLocales, $switchLocale } = useI18n()
</script>
```
