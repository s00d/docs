---
title: "useI18n"
description: "useI18n, çalışma zamanı yardımcılarını (`$t`, `$tc`, `$localePath`, …) `$` önekli ve öneksiz olarak düz bir nesne hâlinde döndürür."
---

`useI18n()`, modülün çalışma zamanı yardımcılarını düz bir nesne olarak döndürür. `useNuxtApp()`'e başvurmak yerine bunu `<script setup>`, composable'lar ve eklentiler içinde kullanın. Her yardımcı hem `$` önekli adıyla hem de öneksiz bir takma adla gelir: `t` ve `$t` aynı fonksiyondur.

## İmza {#signature}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Tüm çalışma zamanı yardımcıları, düz bir nesne olarak.

Eklentinin `$t`, `$tc` vb. olarak enjekte ettiği fonksiyonların aynısı, hem dolar önekli
adla hem de öneksiz bir takma adla kullanılabilir — bu nedenle hem `const { t } = useI18n()` hem de
`const { $t } = useI18n()` çalışır.

**Döndürür** — [metotlar referansında](/tr/api/methods) açıklanan yardımcılar

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

Döndürülen nesne [`PluginsInjections`](/tr/api/methods) içindeki tüm yardımcıları barındırır. Her biri [Yardımcılar](/tr/api/methods) sayfasında belgelenmiştir.

## Örnek {#example}

```vue
<script setup lang="ts">
const { t, tc, localePath, switchLocale, getLocale } = useI18n()

const title = computed(() => t('page.title'))
</script>

<template>
  <h1>{{ title }}</h1>
  <p>{{ tc('items', 3) }}</p>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
  <button @click="switchLocale(getLocale() === 'en' ? 'de' : 'en')">{{ t('nav.switch') }}</button>
</template>
```

## Tipte bulunmayanlar {#not-in-the-type}

`$defineI18nRoute` yalnızca `useNuxtApp()` üzerinde tiplenmiştir:

```ts
const { $defineI18nRoute } = useNuxtApp()
```
