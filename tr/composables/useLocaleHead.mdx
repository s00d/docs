---
title: "useLocaleHead"
description: "useLocaleHead, i18n SEO etiketlerini (lang, dir, canonical, hreflang, og:locale) useHead'e aktaracağınız bir nesne olarak oluşturur."
---

`useLocaleHead()`, geçerli rota için i18n head etiketlerini oluşturur: `<html>` üzerinde `lang` ve `dir`, bir canonical bağlantı, `x-default` ile birlikte `hreflang` alternatifleri, `og:url`, `og:locale` ve `og:locale:alternate`. [`meta: false`](/tr/api/module-options#meta) ayarlayıp `useHead`'i kendiniz yönettiğinizde bunu kullanın; `meta: true` olduğunda modül bu etiketleri zaten kaydeder ve sayfa bazlı değişiklikler [`useI18nHead`](/tr/composables/useI18nHead) üzerinden yapılır.

## İmza {#signature}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { build: () => LocaleHead; metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }, LocaleHead | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

Geçerli rota için SEO head etiketleri: her locale için `hreflang` alternatifleri ve
`x-default`, bir canonical bağlantı, `og:locale` ve `<html>` üzerinde `lang`/`dir`.

Yalnızca `meta` devre dışı bırakıldığında veya varsayılanların ayarlanması gerektiğinde gereklidir — `meta: true`
olduğunda modül aynı etiketleri kendisi kaydeder.

| Parametre | Tip | Açıklama |
| --- | --- | --- |
| `options` | `UseLocaleHeadOptions` |  |

**Döndürür** — `metaObject`, `useHead`'e aktarılmaya hazır head nesnesini tutan bir ref; `updateMeta` onu yeniler; `build` head nesnesini geçerli rotadan hesaplar (bir getter içinde okunduğunda reaktiftir, ör. `useHead(() => build())`)

```ts
const { metaObject } = useLocaleHead({ addSeoAttributes: true })
useHead(metaObject)
```

## Seçenekler {#options}

| Seçenek | Varsayılan | Açıklama |
| --- | --- | --- |
| `addDirAttribute` | `true` | `<html>` üzerindeki `dir` değerini locale'in `dir` değerinden ayarlar (yoksa `'auto'`). |
| `identifierAttribute` | `'id'` | Her etiketi anahtarlayan öznitelik (`i18n-can`, `i18n-og`, `i18n-alternate-<hreflang>`, …); böylece güncellemeler etiket eklemek yerine mevcut etiketlerin yerini alır. |
| `addSeoAttributes` | `true` | Canonical, `hreflang` ve `og:` etiketlerini üretir. `false` yalnızca `htmlAttrs`'ı tutar. |
| `baseUrl` | `'/'` | Her URL'ye eklenen origin. Göreli URL'ler için `'/'` olarak bırakın; mutlak URL'ler için `'https://example.com'` verin. |
| `autoUpdate` | `true` | Rota veya `i18n-locale` durumu değiştiğinde `metaObject`'i yeniden oluşturur. |

## Ne üretir {#what-it-emits}

- Eşleşmesi olmayan bir rotada (404) veya etkin locale için `disableMeta` ayarlı bir rotada hiçbir şey.
- Canonical ve `og:url`: `$switchLocalePath(<active locale>)`, sorgu [`canonicalQueryWhitelist`](/tr/api/module-options#canonicalquerywhitelist) ile sınırlandırılmış, [`trailingSlash`](/tr/api/module-options#trailingslash) uygulanmış.
- `hreflang`: sayfanın bulunduğu her etkin locale için bir bağlantı, `hreflang = iso || code`, `seo: false` olan locale'ler atlanır; `hreflangBaseLanguage: true` ile bir dilin ilk bölgesel locale'i yalın dil etiketini de üretir. `no_prefix` altında hiçbiri üretilmez.
- `x-default`: varsayılan locale'in URL'si; strateji `no_prefix` ise, varsayılan locale `seo: false` ise veya sayfa o locale'de yoksa üretilmez.
- `og:locale` / `og:locale:alternate`: locale'in `og` değerinden veya dönüştürülmüş `iso` değerinden (`en-US` → `en_US`); ikisi de işe yaramazsa bir geliştirme uyarısıyla atlanır.

## Örnek {#example}

```ts
// app.vue, with i18n.meta: false
const { metaObject } = useLocaleHead({ baseUrl: 'https://example.com' })
useHead(metaObject)
```

`build()` aynı nesneyi ref olmadan döndürür: `useHead(() => build())` bir watcher olmadan reaktif kalır.
