title: "useI18nHead"
description: "useI18nHead, tek bir sayfa için oluşturulan i18n SEO etiketlerini geçersiz kılar: canonical, hreflang ve og etiketlerini değiştirin veya kaldırın ya da kendi etiketlerinizi ekleyin."
---

`useI18nHead()`, modülün oluşturduğu SEO etiketlerini yalnızca tek bir sayfa için değiştirir. Sayfanın yönlendiriciden daha iyi bildiği durumlarda kullanın: yalnızca bazı locale'lerde bulunan bir CMS makalesi, bir API'den gelen canonical URL, ek `og:` etiketleri. Oluşturulan etiketleri, geçersiz kılmalarınız üzerlerine birleştirilmiş olarak alırsınız.

## İmza {#signature}

```ts
useI18nHead(input?: MaybeRefOrGetter<I18nHeadInput | null>): { pageHead: any; resetPageHead: () => void }
```

i18n SEO head etiketleri için sayfa düzeyinde geçersiz kılmalar kaydeder.
`02.meta` eklentisi tarafından `useLocaleHead` çıktısının üzerine birleştirilir.

Değerler `$t` / `t` kaynaklı olduğunda bir getter (`() => ({ … })`) tercih edin; böylece
locale değiştiğinde yeniden çözümlenirler. Düz bir nesne bir kez değerlendirilir ve sabit kalır.

| Parametre | Tip | Açıklama |
| --- | --- | --- |
| `input` *(isteğe bağlı)* | `MaybeRefOrGetter<I18nHeadInput \| null>` |  |

[`meta: true`](/tr/api/module-options#meta) (varsayılan) ile çalışır: modülün meta eklentisi her head render'ında girdiyi [`useLocaleHead`](/tr/composables/useLocaleHead) çıktısının üzerine birleştirir. `meta: false` ile hiçbir şey onu okumaz.

Geçersiz kılma, rota adı değiştiğinde sıfırlanır. `disableMeta` ayarlayan bir sayfa, geçersiz kılmalar dahil hiçbir i18n etiketi almaz.

## Girdi {#input}

`I18nHeadInput` (`@i18n-micro/types` içinden):

| Anahtar | Tip | Etki |
| --- | --- | --- |
| `htmlAttrs` | `Record<string, string>` | `<html>` özniteliklerine (`lang`, `dir`) birleştirilir. |
| `meta` | `I18nHeadMeta[]` | Oluşturulan etiketlerin ardından eklenir; aynı `id`, `property` veya `name` değerine sahip etiketin yerini alır. |
| `link` | `I18nHeadLink[]` | Oluşturulan bağlantıların ardından eklenir; aynı `id` veya `rel` + `hreflang` değerine sahip bağlantının yerini alır. |
| `replace.canonical` | `string \| false` | Canonical `href` değerini değiştirir veya bağlantıyı kaldırır. |
| `replace.hreflang` | `I18nHeadLink[] \| false` | `x-default` dahil **tüm** `rel="alternate"` bağlantılarını değiştirir veya kaldırır. |
| `replace.xDefault` | `I18nHeadLink \| false` | `x-default` bağlantısını değiştirir veya kaldırır. |
| `replace.ogLocale` | `string \| false` | `og:locale` değerini değiştirir veya kaldırır. |
| `replace.ogUrl` | `string \| false` | `og:url` değerini değiştirir veya kaldırır. |
| `replace.ogAlternates` | `string[] \| false` | `og:locale:alternate` etiketlerini bu locale kodlarından (`og` / `iso` aracılığıyla) yeniden oluşturur; geçerli locale'i, bilinmeyen kodları ve `og` ya da `iso` değeri olmayan kodları atlar; veya onları kaldırır. |
| `disable` | `I18nHeadDisableGroup[]` | Oluşturulan grupları kaldırır: `'hreflang'` (`x-default` hariç), `'x-default'`, `'canonical'`, `'og'` (`og:locale` + `og:url`), `'og-alternates'`, `'html'`. |

Uygulanma sırası: `disable`, ardından `replace`, ardından `htmlAttrs`, `meta`, `link`.

## Örnek {#example}

Yalnızca bazı locale'lerde bulunan ve alternatif URL'leri API'den gelen bir makale:

```vue
<script setup lang="ts">
const route = useRoute()
const { t } = useI18n()
const { data: article } = await useFetch<{ title: string; urls: Record<string, string> }>(`/api/articles/${route.params.slug}`)

useI18nHead(() => {
  if (!article.value) return null
  const codes = Object.keys(article.value.urls)
  return {
    meta: [{ property: 'og:title', content: article.value.title || t('blog.title') }],
    replace: {
      hreflang: codes.map((code) => ({ rel: 'alternate', hreflang: code, href: article.value!.urls[code]! })),
      ogAlternates: codes,
    },
  }
})
</script>
```

Değerler `t()` veya asenkron verilerden geldiğinde, burada olduğu gibi bir getter verin: locale değiştiğinde yeniden çalışır. Düz bir nesne bir kez okunur.
