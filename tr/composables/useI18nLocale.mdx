---
title: "useI18nLocale"
description: "useI18nLocale, locale state'ini ve locale çerezini okur ve yazar — özel locale algılamanın giriş noktasıdır."
---

`useI18nLocale()`, uygulamanın seçtiği locale'e erişim sağlar: `i18n-locale` state'i ve locale çerezi. `useState('i18n-locale')` veya çerezi elle yazmak yerine, locale'i kendisi algılayan (alan adı, kullanıcı profili, header) bir eklentide bunu kullanın. Geçerlilik denetimleri, çalışma zamanı geçersiz kılmaları da dahil olmak üzere etkin locale'leri kullanır.

## İmza {#signature}

```ts
useI18nLocale(): { getEffectiveLocale: (route: unknown, getLocaleFromRoute: GetLocaleFromRoute) => string; getLocale: () => string | null; getPreferredLocale: () => string | null; hashCookie: CookieRef; isValidLocale: (locale: string | null | undefined) => locale is string; locale: any; localeCookie: CookieRef; resolveInitialLocale: (options: ResolveInitialLocaleOptions) => string; setLocale: (locale: string | null) => void; syncLocale: (locale: string | null) => void; validLocales: string[] }
```

i18n locale yönetimi için merkezi giriş noktası.
useState('i18n-locale'), locale çerezi ve senkronizasyon yardımcılarını bir araya getirir.

## Döndürülen değerler {#returned-values}

| Üye | Tip | Açıklama |
| --- | --- | --- |
| `locale` | `Ref<string \| null>` | `useState('i18n-locale')` ref'i. |
| `localeCookie` | `Ref<string \| null>` | [`localeCookie`](/tr/api/module-options#localecookie) çerezi; seçenek `null` olduğunda düz bir `{ value: null }`. |
| `hashCookie` | `Ref<string \| null>` | Hash yönlendirmesinde `hash-locale` çerezi; aksi hâlde `{ value: null }`. |
| `validLocales` | `string[]` | Etkin locale'lerin kodları. |
| `setLocale(locale)` | `(locale: string \| null) => void` | State'i ve çerezleri yazar. Doğrulama yapmaz ve çevirileri yüklemez. |
| `syncLocale(locale)` | `(locale: string \| null) => void` | Yalnızca çerezleri yazar. |
| `getLocale()` | `() => string \| null` | Önce state, ardından tercih çerezi (hash yönlendirmesinde hash çerezi). Doğrulanmaz. |
| `getPreferredLocale()` | `() => string \| null` | State ve tercih çerezinden ilk **geçerli** olan veya `null`. |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string` | Hash yönlendirmesinde ayarlanmışsa state; aksi hâlde `getLocaleFromRoute(route)`. |
| `resolveInitialLocale(options)` | `(options: ResolveInitialLocaleOptions) => string` | Önce `options.urlLocale`, sonra geçerli bir state, sonra `options.serverLocale`, sonra route'un locale'i. State geçerli olmadığında sonucu state'e kaydeder; istemcide ayrıca çerezi de yazar. |
| `isValidLocale(locale)` | `(locale) => locale is string` | `locale` değerinin `validLocales` içinde olup olmadığı. |

Çerezler bir yıl geçerlidir; `path: '/'` ve `sameSite: 'lax'` ile ayarlanır.

## Örnek {#example}

```ts
// plugins/locale-from-domain.server.ts
export default defineNuxtPlugin({
  name: 'locale-from-domain',
  enforce: 'pre',
  setup() {
    const { setLocale, isValidLocale } = useI18nLocale()
    const host = useRequestURL().hostname // e.g. de.example.com
    const code = host.split('.')[0]
    if (isValidLocale(code)) setLocale(code)
  },
})
```

Modülün yükleyici eklentisi başlarken state'i okur; bu nedenle onu ayarlayan bir eklenti önce çalışmalıdır (`enforce: 'pre'`). State'in URL, çerez ve `Accept-Language` ile nasıl yarıştığı: [Locale algılama](/tr/guide/locale-detection). Tam adım adım anlatım: [Özel algılama](/tr/guide/custom-auto-detect).

`setLocale()` ekrandaki çevirileri değiştirmez. Geçerli sayfanın locale'ini değiştirmek için [`$switchLocale()`](/tr/api/methods#$switchlocale) çağırın.
