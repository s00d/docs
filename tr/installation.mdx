## Gereksinimler

- **Node.js**: 18 veya daha yenisi.
- **Nuxt**: 3.x veya 4.x.

Modül hem Nuxt 3 proje düzenini (`pages/**/*.vue`) hem de Nuxt 4 düzenini (`app/pages/**/*.vue`) destekler. Çeviriler geleneksel olarak, Nuxt 4 `app/` dizini kullanılırken bile proje kökünde (`locales/`) bulunur.

## Nuxt modülünü yükle

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

`nuxt.config.ts` içinde kaydet:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Tam bir gezinti için [Hızlı başlangıç](/quickstart) sayfasına veya tüm seçenekler için [Yapılandırma referansına](/guides/configuration) göz at.

## Proje düzeni

Modül varsayılan olarak şunu bekler:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Kök seviyesindeki dosyalar, derleme zamanında her sayfaya özel dosyayla birleştirilir. Sayfaya özel dosyalar `nuxt dev` sırasında eksik olduklarında otomatik oluşturulur.

## Nuxt 4 düzeni

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Çevirileri `app/` altına yerleştirmek için `translationDir: 'app/locales'` olarak ayarla.

## TypeScript

Modül; varsayılan yerel ayar dosyalarına göre `useI18n`, `$t` ve ilgili yardımcılar için ortam türleri üretir. Bu, varsayılan olarak etkindir (`types: true`).

Çeviri anahtarlarını daha güçlü türlemek için [`@i18n-micro/types-generator`](/integrations/types-generator) paketine bak.
