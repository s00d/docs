## Gereksinimler

- **Node.js**: 18 veya daha yeni.
- **Nuxt**: 3.x veya 4.x.

Modül hem Nuxt 3 proje düzenini (`pages/**/*.vue`) hem de Nuxt 4 düzenini (`app/pages/**/*.vue`) destekler. Çeviriler, Nuxt 4 `app/` dizini kullanılırken bile geleneksel olarak proje kökünde (`locales/`) bulunur.

## Nuxt modülünü kurun

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

`nuxt.config.ts` dosyasında kaydedin:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Tam bir adım adım rehber için [Hızlı başlangıç](/quickstart) bölümüne veya tüm seçenekler için [Yapılandırma referansı](/guides/configuration) bölümüne bakın.

## Proje düzeni

Modül varsayılan olarak şunu bekler:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Kök seviyesindeki dosyalar, derleme sırasında her sayfaya özel dosyayla birleşir. Sayfaya özel dosyalar, `nuxt dev` sırasında eksik olduğunda otomatik olarak oluşturulur.

## Nuxt 4 düzeni

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Çevirileri `app/` altında bir arada tutmak için `translationDir: 'app/locales'` olarak ayarlayın.

## TypeScript

Modül, varsayılan yerel ayar dosyalarınıza dayalı olarak `useI18n`, `$t` ve ilgili yardımcılar için ortam türleri üretir. Bu varsayılan olarak etkindir (`types: true`).

Çeviri anahtarlarının daha güçlü bir şekilde tiplendirilmesi için [`@i18n-micro/types-generator`](/integrations/types-generator) sayfasına bakın.
