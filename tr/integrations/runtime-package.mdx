`@i18n-micro/runtime`, framework'ten bağımsız i18n örneğidir: sözlükler, `t()`, çoğullar, `Intl` biçimlendirme ve bir değişiklik aboneliği; `fs` ve framework yoktur. Bunu düz TypeScript'te, bir web worker'da, bir edge fonksiyonunda veya kendi bağlamanızın temeli olarak kullanın. React, Preact, Node ve Astro paketleri bu aynı sınıfı genişletir.

## Kurulum {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/runtime
```

```bash npm
npm install @i18n-micro/runtime
```

```bash yarn
yarn add @i18n-micro/runtime
```

</CodeGroup>

Peer bağımlılık yoktur. Diskteki çeviri dosyaları için [`@i18n-micro/node`](/tr/integrations/nodejs-package) kullanın.

## Yapılandırma {#setup}

```ts
import { createI18n } from '@i18n-micro/runtime'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    en: { greeting: 'Hello, {name}!', apples: 'no apples | one apple | {count} apples' },
    de: { greeting: 'Hallo, {name}!' },
  },
  routeMessages: {
    about: { en: { title: 'About us' } },
  },
})
```

Tüm seçenekler (`plural`, `missingWarn`, `missingHandler`, `numberFormats`, `datetimeFormats`) [örnek](/tr/integrations/overview#the-instance) bölümünde listelenmiştir.

## Çeviri {#translate}

```ts
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.tc('apples', 5) // '5 apples'
i18n.tn(1234.5) // '1,234.5'

i18n.setRoute('about')
i18n.t('title') // 'About us' (route dictionary)
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!' (root, still visible)
```

Daha sonra başka sözlükler yükleyin:

```ts
i18n.loadMessages({ fr: { greeting: 'Bonjour, {name} !' } }, { about: { fr: { title: 'À propos' } } })
i18n.addTranslations('fr', { nav: { home: 'Accueil' } }) // deep merge; pass false to replace

await i18n.loadFromUrl('/locales/fr.json', { locale: 'fr' })
await i18n.loadFromUrl('/locales/pages/about/fr.json', { locale: 'fr', routeName: 'about' })
await i18n.loadFromUrls([
  { url: '/locales/en.json', locale: 'en' },
  { url: '/locales/de.json', locale: 'de' },
])
```

`loadFromUrl`, `fetch` kullanır (başlıklar için `init` geçirin) ve başarılı olmayan bir yanıtta hata fırlatır. `loadFromUrls` dosyaları birbiri ardına yükler.

## Locale değiştirme {#switch-locale}

```ts
i18n.locale = 'de'
i18n.t('greeting', { name: 'Ada' }) // 'Hallo, Ada!'
```

Locale, rota ve sözlük değişiklikleri abonelere bildirilir; framework bağlamaları yeniden render işlemini bu şekilde yapar:

```ts
const stop = i18n.subscribe(() => {
  document.querySelector('#greeting')!.textContent = i18n.t('greeting', { name: 'Ada' }) as string
})
i18n.locale = 'fr'
stop()
```

`getSnapshot()`, her bildirimde değişen bir dize döndürür (`useSyncExternalStore` tarzı store'lar için).

## İstek başına {#per-request}

Örnek tek bir locale ve tek bir rota tutar. Bir sunucuda paylaşılan bir örneği istek başına değiştirmeyin: eşzamanlı iki istek birbirinin locale'ini görür. `i18n.fork(locale)` bir isteğe kendine ait bir örnek verir: kendi locale'i, yedeği ve rotası; aynı sözlükler, biçimlendiriciler ve kurallar. Fork işleminin maliyeti, kaç sözlük olursa olsun aynıdır. Bir fork, kendi ilk yazma işlemine kadar ebeveynine yapılan yazmaları görür ve kendi yazmaları kendisinde kalır. [Node.js](/tr/integrations/nodejs-package#per-request) `run` ekler.

## API {#api}

| Üye | Notlar |
| --- | --- |
| `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has` | bkz. [Çeviri ve biçimlendirme](/tr/integrations/overview#translate-and-format) |
| `locale`, `fallbackLocale` | get/set |
| `currentRoute`, `setRoute(name)`, `getRoute()` | etkin rota, varsayılan `'index'` |
| `loadMessages(messages?, routeMessages?)` | birçok locale'i ve rotayı tek seferde birleştirir |
| `addTranslations(locale, tree, merge = true)`, `addRouteTranslations(locale, route, tree, merge = true)` | |
| `loadFromUrl(url, { locale?, routeName?, init? })`, `loadFromUrls(entries)` | JSON `fetch` eder |
| `hasTranslation(key)` | etkin locale, herhangi bir rota (etkin rotayı ve kökü denetleyen `has`'ten farklı olarak) |
| `setTranslation(key, value)`, `resolveTranslations()` | tek bir anahtar yazar; birleştirilmiş ağacı okur |
| `clear()`, `clearCache()` | tüm sözlükleri bırakır |
| `subscribe(cb)`, `getSnapshot()` | değişiklik bildirimleri |
| `storage` | `{ translations: Map<'locale:route', Translations> }` |

Dil etiketi olmayan bir kod, çoğullarını `localeIso: { ua: 'uk-UA' }` üzerinden alır; `localeIsoMap(locales)` bunu bir locale listesinin `iso` içeren girdilerinden oluşturur.

Modül dışa aktarımları: `createI18n`, `I18n`, `fetchJsonTranslations`, `FormatService`, `interpolate`, `localeIsoMap` ve `I18nOptions`, `LoadFromUrlOptions`, `LoadFromUrlEntry`, `TranslationStorage`, `Translations`, `Locale`, `PluralFunc` tipleri. Tam imzalar: [paket referansı](/tr/api/packages/runtime).
