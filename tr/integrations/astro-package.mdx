`@i18n-micro/astro`, Astro sayfalarını sunucuda çevirir: bir middleware URL'den locale'i seçer ve istek başına bir örneği `Astro.locals` içine koyar; `useI18n(Astro)` da onu okur. Locale önekli URL'lere (`/about`, `/fr/about`) ve paylaşılan JSON sözlüklerine ihtiyaç duyan bir Astro sitesinde kullanın. `.astro` bileşenleri, ziyaretçinin diline ana sayfa yönlendirmesi, `hreflang` etiketleri ve [adalar](/tr/integrations/astro-islands) için prop'lar elde edersiniz.

## Kurulum {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/astro
```

```bash npm
npm install @i18n-micro/astro
```

```bash yarn
yarn add @i18n-micro/astro
```

</CodeGroup>

Eş bağımlılıklar: `astro` `^5.0.0 || ^6.0.0 || ^7.0.0`. İsteğe bağlı, yalnızca [adalar](/tr/integrations/astro-islands) için: `vue` `^3.3.0`, `react` `^16.8.0 || ^17.0.0 || ^18.0.0 || ^19.0.0`, `preact` `^10.0.0 || ^11.0.0`, `svelte` `^4.0.0 || ^5.0.0`.

## Yapılandırma {#setup}

Entegrasyonu ekleyin. Sözlüklerinizi sunucuya paketler ve middleware'i kurar, bu nedenle `src/middleware.ts` gerekmez:

```ts
// astro.config.mjs
import { defineConfig } from 'astro/config'
import node from '@astrojs/node'
import { i18nIntegration } from '@i18n-micro/astro'

export default defineConfig({
  output: 'server',
  adapter: node({ mode: 'standalone' }),
  integrations: [
    i18nIntegration({
      locale: 'en',
      fallbackLocale: 'en',
      locales: [
        { code: 'en', iso: 'en-US', displayName: 'English' },
        { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
        { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
      ],
      translationDir: 'src/locales',
    }),
  ],
})
```

Sözlükler derleme zamanında koda dönüşür: sunucu diskten okuma yapmaz, bu yüzden edge üzerinde de (Cloudflare, Vercel Edge) çalışır. `astro dev` içinde bir dosyadaki düzenleme bir sonraki istekte uygulanır.

### Entegrasyon seçenekleri {#integration-options}

| Seçenek | Varsayılan | Notlar |
| --- | --- | --- |
| `locale` | zorunlu | Varsayılan locale. |
| `fallbackLocale` | `locale` | |
| `locales` | `[]` | Tam `Locale` nesneleri. `disabled` olan bir locale hiçbir URL'nin locale'i ve hiçbir yönlendirmenin hedefi değildir. `iso`, kod geçerli bir etiket olmadığında çoğul kurallarının dayandığı etikettir (`ua` → `uk-UA`). |
| `translationDir` | yok | Sunucuya paketlenen klasör, proje köküne göreli. |
| `disablePageLocales` | `false` | Sayfa dosyaları kök çeviriler olarak sayılır. |
| `autoDetect` | `true` | Ana sayfa yönlendirmesi, bkz. [Locale algılama](#locale-detection). |
| `redirectToDefault` | `false` | Başka bir locale'i tercih eden bir şey olmadığında da `/` yönlendirir. |
| `localeCookie` | `'i18n-locale'` | `null` çerezi devre dışı bırakır. |
| `missingWarn` | `false` | |
| `middleware` | `true` | `false`: middleware'i kendiniz yazın, aşağıya bakın. |

Çalışma zamanı ayarları `virtual:i18n-micro/config` içinde (`config.base` Astro'nun `base` değeri, `config.localeCodes` etkin kodlar), sözlükler ise `virtual:i18n-micro/messages` içinde yayınlanır.

### Kendi middleware'iniz {#your-own-middleware}

Bir çoğul kuralı, eksik anahtar işleyicisi ve router adaptörü yapılandırma sürecinden sunucu paketine geçemez. Bunlar için `middleware: false` iletin ve `src/middleware.ts` yazın. Bu durumda Astro'nun `i18n` yapılandırması sizin için `routing: 'manual'` ile ayarlanır, böylece `Astro.currentLocale` ve `astro:i18n` çalışır. Astro bu ayara `src/middleware.ts` olmadan izin vermez, bu nedenle entegrasyonun kendi middleware'i ile bunlar çalışmaz.

```ts
// src/middleware.ts
import { config } from 'virtual:i18n-micro/config'
import { messages } from 'virtual:i18n-micro/messages'
import { createAstroRouterAdapter, createI18n, createI18nMiddleware, localeIsoMap } from '@i18n-micro/astro'

const i18n = createI18n({
  locale: config.defaultLocale,
  fallbackLocale: config.fallbackLocale,
  localeIso: localeIsoMap(config.locales),
  messages: messages.root,
  routeMessages: messages.routes,
  plural: myPluralRule,
})

export const onRequest = createI18nMiddleware({
  i18n,
  defaultLocale: config.defaultLocale,
  locales: config.localeCodes,
  localeObjects: config.locales,
  autoDetect: config.autoDetect,
  redirectToDefault: config.redirectToDefault,
  localeCookie: config.localeCookie,
  base: config.base,
  routingStrategy: createAstroRouterAdapter(config.locales, config.defaultLocale),
})
```

Bunun yerine klasörü çalışma zamanında okumak için `loadTranslationsFromDir` ve `loadTranslationsIntoI18n`, `@i18n-micro/astro/node` içindedir (yalnızca Node).

### Middleware seçenekleri {#middleware-options}

| Seçenek | Varsayılan | Notlar |
| --- | --- | --- |
| `i18n` | zorunlu | Global örnek; her istek `i18n.fork(locale)` alır ve bunun maliyeti sözlük sayısından bağımsız olarak aynıdır. |
| `defaultLocale` | zorunlu | |
| `locales` | zorunlu | Locale kodları. |
| `localeObjects` | `{ code }` olarak `locales` | Bileşenler ve SEO için tam `Locale` nesneleri. |
| `autoDetect` | `true` | Ana sayfa yönlendirmesi, bkz. [Locale algılama](#locale-detection). |
| `redirectToDefault` | `false` | Başka bir locale'i tercih eden bir şey olmadığında da `/`, yönlendirme stratejisinin çözümlediği şekilde varsayılan locale'in ana sayfasına yönlendirir. |
| `localeCookie` | `'i18n-locale'` | `null` çerezi devre dışı bırakır. |
| `routingStrategy` | varsayılan hariç önek | Router adaptörü. Dışarıda bıraktığı metotlar varsayılan adaptörden gelir. |
| `base` | yok | Astro'nun `base` değeri: `config.base`. |

Sayfa dosyaları (`src/locales/pages/blog/post/de.json`) `blog-post` rotasıdır: sayfa yolunun `-` ile birleştirilmiş hâli.

## Çeviri {#translate}

```astro
---
// src/pages/index.astro
import { useI18n } from '@i18n-micro/astro'
import I18nT from '@i18n-micro/astro/i18n-t'

const { t, tc, locale } = useI18n(Astro)
---

<h1>{t('greeting', { name: 'Ada' })}</h1>
<p>{tc('apples', 3)}</p>
<I18nT keypath="welcome" tag="p" />
<p>{locale}</p>
```

`useI18n(Astro)` şunları döndürür: `locale`, `defaultLocale`, `locales`, `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`, `getRoute`, `getRouteName(path?)`, `getLocaleFromPath(path?)`, `switchLocalePath(locale)`, `localizePath(path, locale?)`, `getBasePath(url?)`, `getI18n`, `addTranslations`, `addRouteTranslations`, `mergeTranslations` ve `clearCache`. Middleware çalışmadıysa hata fırlatır. `getI18n`, `getLocale`, `getDefaultLocale` ve `getLocales` yardımcıları aynı `Astro.locals`'ı okur.

Rota adı, locale'i olmadan rotadan gelir: `/fr/blog/post` → `blog-post` ve `src/pages/blog/[slug].astro` sayfasının her URL'si → `blog-slug`; böylece tek bir `locales/pages/blog-slug/` klasörü hepsine hizmet eder. `[...path]` ise `path` olur. Astro'nun `base` değeri altında yardımcılar sitenin URL'lerini alır ve döndürür: `switchLocalePath` ve `localizePath` onu içerir, `getBasePath` içermez, çünkü `Astro.rewrite` yolu onsuz alır.

### Bileşenler {#components}

Bunları `@i18n-micro/astro/<name>` (veya `@i18n-micro/astro/components/<name>.astro`) üzerinden içe aktarın:

| Bileşen | Prop'lar |
| --- | --- |
| `i18n-t` | `keypath`, `params`, `plural`, `number`, `date`, `relativeDate`, `tag` (`span`, herhangi bir etiket), `html`, `hideIfEmpty`, `defaultValue`; diğer öznitelikler aynen aktarılır. `html` ile her dalın sonucu HTML olarak işlenir ve `params` kaçışlanır. Slot yoktur |
| `i18n-link` | `href`, `locale` (hedef locale, varsayılan geçerli olan), `class`; diğer öznitelikler aynen aktarılır. Harici URL'ler, `#hash` ve `?query` yazıldığı gibi kalır; bir rota sorgusunu, hash'ini ve sondaki eğik çizgisini korur |
| `i18n-switcher` | `class`, `activeClass` (`'active'`), `customLabels`; geçerli sayfanın her etkin locale'deki bağlantılarını sorgusuyla birlikte işler |
| `i18n-group` | çıktıyı değiştiren yok: slot'unun etrafında bir `<div>`, önek yok |

## Locale önekli rotalar {#locale-prefixed-routes}

`src/pages/` içinde her rota için bir sayfa tutun ve `src/pages/[locale]/` altına ince yeniden yazma taslakları ekleyin:

```
src/pages/
  index.astro
  about.astro
  [locale]/
    index.astro
    about.astro
```

```astro
---
// src/pages/[locale]/about.astro
import { prepareLocaleRewrite } from '@i18n-micro/astro'

const target = prepareLocaleRewrite(Astro)
if (target instanceof Response) return target
return Astro.rewrite(target)
---
```

`prepareLocaleRewrite`, bilinmeyen bir `:locale` için `404` yanıtı döndürür; aksi takdirde locale'i `Astro.locals` üzerinde ayarlar ve öneksiz yolu döndürür. Middleware `locals` içinde zaten bulunan bir locale'i korur, böylece yeniden yazılan sayfa o locale'de işlenir. Locale'i kendiniz doğruladığınızda `getLocaleRewritePath(Astro)` yalnızca yolu döndürür.

## Locale algılama {#locale-detection}

Sayfanın locale'ine URL karar verir:

1. Bir locale öneki (`/fr/about` → `fr`; `/en/about` da `en`'dir).
2. Aksi halde, varsayılan değilse router adaptörünün `getLocaleFromPath` fonksiyonunun döndürdüğü değer.
3. Aksi halde varsayılan locale. `/about`, çerez ne derse desin her zaman varsayılan locale'in sayfasıdır.

`autoDetect` yalnızca ana sayfada bir yönlendirme ipucudur:

- Çerezi veya `Accept-Language`'i başka bir locale'i tercih eden bir `/` isteği, o locale'in ana sayfasına (`/de`) `302` alır. q-ağırlıkları dikkate alınır; `de-DE` bir `de` locale'iyle, `de` de bir `de-DE` locale'iyle eşleşir.
- `redirectToDefault` ile `/` her zaman yönlendirir: tercih edilen locale'in ana sayfasına, yoksa varsayılan locale'inkine.
- `/` yanıtı `Vary: Cookie, Accept-Language` taşır (`localeCookie` `null` olduğunda yalnızca `Accept-Language`).
- Önceden işlenmiş sayfalar asla yönlendirmez.

`detectLocale(pathname, cookies, headers, defaultLocale, locales, localeCookie?, routingStrategy?, autoDetect?)`, kendi mantığınız için aynı tercih edilen locale'i döndürür.

Çerez bir seçimi hatırlar. Başka bir locale'deki aynı kökenli bir sayfadan gelen sayfa görüntüleme, onları oraya hangi bağlantı götürmüş olursa olsun, dil değiştiren bir ziyaretçidir: HTML yanıtı çerezi yeni locale'e ayarlar ve `/` yönlendirmez, böylece bir değiştirici varsayılan locale'in ana sayfasına ulaşır. Bir endpoint, bir görsel, bir 404, bir form gönderimi ve bir prefetch hiçbir şeyi değiştirmez. "Aynı köken", tarayıcının `Sec-Fetch-Site` içinde söylediği şeydir; bu başlık yoksa `Referer`'ın host'u isteğinkiyle karşılaştırılır, bu nedenle bir proxy arkasında Astro'nun `security.allowedDomains` ayarını yapın.

Bir [sunucu adası](https://docs.astro.build/en/guides/server-islands/) veya bir action'ın URL'sinde locale yoktur. Onu isteyen sayfa için işlenir; bu sayfa `Referer`'dan okunur ve yalnızca yolu dikkate alınır, bu yüzden sunucunun önündeki bir proxy hiçbir şeyi değiştirmez ve asla yönlendirmez. Yanıtı `Vary: Referer` taşır. `Referer` olmadan (bir `no-referrer` politikası) varsayılan locale'dedir ve dinamik bir sayfada rotası URL'den gelir, bu nedenle sayfa sözlükleri ona ulaşmaz.

## Router adaptörü {#router-adapter}

`createAstroRouterAdapter(locales, defaultLocale)`, varsayılan hariç her locale'e önek ekler. Bir Astro adaptörünün yalnızca `getCurrentPath`'e ihtiyacı vardır; diğer üyeler isteğe bağlıdır ve varsayılan adaptöre geri döner: `getRouteName(path, locales, routePattern?)`, `getLocaleFromPath`, `switchLocalePath`, `localizePath`, `removeLocaleFromPath`, `resolvePath` (ana sayfa yönlendirme hedefi), `push`, `replace`, `getRoute`. Alt alan adı veya sonek URL'leri için kendinizinkini yazın ve `createI18nMiddleware`'e iletin.

## SEO {#seo}

```astro
---
// src/layouts/Layout.astro
import { useLocaleHead } from '@i18n-micro/astro'

const head = useLocaleHead(Astro, { baseUrl: 'https://example.com' })
---

<html lang={head.htmlAttrs.lang} dir={head.htmlAttrs.dir}>
  <head>
    {head.link.map((l) => <link rel={l.rel} href={l.href} hreflang={l.hreflang} />)}
    {head.meta.map((m) => <meta property={m.property} content={m.content} />)}
  </head>
  <body><slot /></body>
</html>
```

`htmlAttrs` (`iso`'dan `lang`, `dir`), bir canonical bağlantı (sorgusuz yol), `seo !== false` olan her etkin locale için `hreflang` alternatifleri artı `x-default`, `og:locale`, `og:locale:alternate` ve `og:url` döndürür. Seçenekler: `baseUrl` (Astro yapılandırmasındaki `site`, yoksa köke göreli URL'ler), `addDirAttribute` (`true`), `addSeoAttributes` (`true`), `hreflangBaseLanguage` (`false`).
