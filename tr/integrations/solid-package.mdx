`@i18n-micro/solid`, SolidJS uygulamalarına sinyal tabanlı bir i18n örneği, bir provider, `useI18n()` ve dört bileşen sağlar. Nuxt ile oluşturulmamış bir Solid uygulamasında kullanın. JSX veya effect'ler içindeki `t()` okumaları yerel ayarı, rotayı ve sözlükleri izler; ortak model [Framework'ler](/tr/integrations/overview) sayfasında anlatılır.

## Kurulum {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/solid
```

```bash npm
npm install @i18n-micro/solid
```

```bash yarn
yarn add @i18n-micro/solid
```

</CodeGroup>

Peer bağımlılıkları: `solid-js` `^1.8.0`; `@solidjs/router` `^0.15.4 || ^1.0.0` (isteğe bağlı, yalnızca `@i18n-micro/solid/router` için). Solid 2 henüz desteklenmiyor.

## Yapılandırma {#setup}

```tsx
// src/index.tsx
import { render } from 'solid-js/web'
import { createI18n, I18nProvider } from '@i18n-micro/solid'
import App from './App'
import en from './locales/en.json'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English' },
  { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
]

const i18n = createI18n({ locale: 'en', fallbackLocale: 'en', messages: { en } })

render(
  () => (
    <I18nProvider i18n={i18n} locales={locales} defaultLocale="en">
      <App />
    </I18nProvider>
  ),
  document.getElementById('root')!,
)
```

`<I18nProvider>`, `i18n`, `locales`, `defaultLocale` ve `routingStrategy` alır; belirtilmeyen bir prop, örnek dahil, dıştaki provider'ın değerini korur. `getLocaleName()` ve `<I18nSwitcher>` `locales` değerini okur; o olmadan listeleyecek hiçbir şeyleri olmaz. Seçenekler [örnek](/tr/integrations/overview#the-instance) bölümündedir. Örnek, [runtime](/tr/integrations/runtime-package) örneğidir ve deposunun üzerinde tek bir sinyal bulunur.

## Çeviri {#translate}

```tsx
import { useI18n } from '@i18n-micro/solid'

export function Greeting() {
  const { t, tc, tn } = useI18n()
  return (
    <>
      <h1>{t('greeting', { name: 'Ada' }) as string}</h1> {/* Hello, Ada! */}
      <p>{tc('apples', 3)}</p> {/* 3 apples */}
      <p>{tn(1234.5)}</p>
    </>
  )
}
```

Solid'in onları izleyebilmesi için metotları JSX veya bir effect içinde çağırın; `localePath` ve `getLocale` için de aynısı geçerlidir. Bileşen gövdesinde bir kez okunan bir değer güncellenmez. Örnek üzerinde `i18n.locale` ve `i18n.currentRoute` ile izleyin: `i18n.getLocale()` düz kalır, çünkü yazma işlemleri onu okur. Yerel ayarın okunması yalnızca yerel ayar değiştiğinde tetiklenir, bu nedenle onu okuyup bir sözlük yükleyen bir effect bir kez çalışır. Prop'ları destructure etmeyin ve `t('key')` sonuçlarını düz değişkenlerde tutmayın.

`useI18n()` şunları döndürür: `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`, `locale` (bir accessor: `locale()`), `getLocale`, `getLocales`, `defaultLocale()`, `getLocaleName`, `switchLocale`, `localePath`, `localeRoute`, `setRoute`, `getRoute`, `addTranslations`, `addRouteTranslations`, `resolveTranslations`, `setTranslation`, `clearCache` ve `instance`.

```ts
const { addTranslations, addRouteTranslations, setRoute } = useI18n()

addTranslations('de', (await import('./locales/de.json')).default)
addRouteTranslations('en', 'about', { title: 'About us' })
setRoute('about') // t('title') now reads the 'about' dictionary first
```

## Yerel ayarı değiştirme {#switch-locale}

```ts
const { instance, switchLocale } = useI18n()

instance.locale = 'de' // only the locale
switchLocale('de') // the locale, then the adapter's push to the localized current path
```

Değiştirmek hiçbir şey yüklemez; önce yerel ayarın sözlüğünü ekleyin.

`<I18nGroup>`, fonksiyon olan bir alt öğeye önekli bir `t` iletir. İçindeki `<I18nT>` ve `t()` öneklenmez:

```tsx
<I18nGroup prefix="profile">{({ t }) => <h2>{t('title')}</h2> /* profile.title */}</I18nGroup>
```

## Yönlendirme {#routing}

`@solidjs/router` adaptörü bir alt yolda bulunur, böylece ana giriş noktası router'ı asla içe aktarmaz. Onu router'ın altında, genellikle `useNavigate` ve `useLocation`'ın çalıştığı router'ın `root` bileşeninde çağırın:

```tsx
// src/App.tsx
import { Route, Router, useLocation, useNavigate, type RouteSectionProps } from '@solidjs/router'
import { I18nLink, I18nProvider, I18nSwitcher } from '@i18n-micro/solid'
import { createSolidRouterAdapter } from '@i18n-micro/solid/router'
import { i18n, locales } from './i18n'
import { About, Home } from './pages'

function Root(props: RouteSectionProps) {
  const routingStrategy = createSolidRouterAdapter(locales, 'en', useNavigate(), useLocation())
  return (
    <I18nProvider i18n={i18n} locales={locales} defaultLocale="en" routingStrategy={routingStrategy}>
      <I18nLink to="/about">About</I18nLink>
      <I18nSwitcher />
      {props.children}
    </I18nProvider>
  )
}

export default function App() {
  return (
    <Router root={Root}>
      <Route path="/:locale?" component={Home} />
      <Route path="/:locale?/about" component={About} />
    </Router>
  )
}
```

Adaptör, varsayılan dışındaki her yerel ayara önek ekler (`/about`, `/de/about`) ve `<I18nLink>` bileşenini router'ın `<A>` bileşeni olarak oluşturur. `getCurrentPath` router'ın reaktif konumunu okur, böylece aktif bağlantılar ve dil değiştirici onu takip eder; özel bir strateji de orada bir sinyal okuyarak aynısını elde eder. Argüman sırasına dikkat edin: `(locales, defaultLocale, navigate, location)`. Diğer router'lar için `getCurrentPath`, `push` ve `replace` (hepsi zorunlu) içeren bir adaptör yazın — bkz. [Router adaptörü](/tr/integrations/overview#router-adapter).

## SSR {#ssr}

Sunucu tarafı oluşturma için `vite-plugin-solid` ile derleyin: paketin `solid` export koşulu ona kaynak kodu verir, böylece sunucu için derlenir. Önceden derlenmiş `dist` yalnızca tarayıcı içindir. Örneğin `destroy()` metodu yoktur; uygulama başına bir tane veya sunucuda istek başına bir tane oluşturun ve çöp toplayıcının temizlemesine izin verin.
