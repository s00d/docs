`@i18n-micro/types-generator`, çeviri klasörünüzdeki her JSON dosyasını okur ve tüm anahtarları listeleyen bir bildirim yazar. Düzenleyicinizin `t()`, `$t()` ve `<I18nT keypath>` içinde anahtar önermesini istediğinizde ekleyin. Bir Nuxt modülü olarak ve bir Vite veya Rollup eklentisi olarak çalışır ve bir dosya değiştiğinde yeniden oluşturur.

## Kurulum {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/types-generator
```

```bash npm
npm install -D @i18n-micro/types-generator
```

```bash yarn
yarn add -D @i18n-micro/types-generator
```

</CodeGroup>

Eş bağımlılık: `@nuxt/kit` `^3.18.0 || ^4.0.0`. Bunu yalnızca `/nuxt` giriş noktası içe aktarır; yalnızca Vite kullanan bir projede eş bağımlılık uyarısı yok sayılabilir.

## Nuxt {#nuxt}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro', '@i18n-micro/types-generator/nuxt'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Modül `.nuxt/types/i18n-micro.d.ts` dosyasını yazar ve Nuxt bunu tip bağlamına ekler; elle dahil edilecek bir şey yoktur. `i18nTypes.translationDir` değerini okur; yoksa `nuxt-i18n-micro`'nun çevirileri okuduğu yerleri kullanır: her katmandaki `translationDir` (`i18n`'den veya satır içi modül seçeneklerinden, varsayılan `'locales'`) ve `additionalTranslationDirs`. Bu klasör altındaki bir JSON dosyasını düzenlemek, `nuxi dev` içinde tipleri yeniden oluşturur. `i18nTypes.outputFile` Nuxt'ta yok sayılır (bir uyarı bunu belirtir).

## Vite {#vite}

`I18nTypesPlugin` bir Vite eklentisidir ve Rollup da onu kabul eder. Başka bir paketleyici için bir betikte `generateTypes` çağırın.

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { I18nTypesPlugin } from '@i18n-micro/types-generator'

export default defineConfig({
  plugins: [
    vue(),
    I18nTypesPlugin({
      srcDir: process.cwd(),
      translationDir: 'src/locales',
      outputFile: 'src/i18n-micro.d.ts',
    }),
  ],
})
```

| Seçenek | Zorunlu | Notlar |
| --- | --- | --- |
| `srcDir` | evet | Temel dizin; `translationDir` buna göre çözümlenir. |
| `translationDir` | evet | JSON dosyalarını içeren klasör (`pages/` gibi alt klasörler dahil) veya bir klasör dizisi. |
| `outputFile` | hayır | Bildirimin yazılacağı yer; varsayılan `<srcDir>/i18n-micro.d.ts`. |

Eklenti derleme başlangıcında bir kez oluşturur ve geliştirme sunucusunda klasördeki bir değişiklikten 300 ms sonra yeniden oluşturur. `tsconfig.json` dosyanızdaki `include` alanının çıktı dosyasını kapsadığından emin olun.

## Anahtarları kullanın {#use-the-keys}

Oluşturulan dosya, `@i18n-micro/types` içindeki `DefineLocaleMessage`'ı genişletir ve bu da `TranslationKey`'i sizin anahtarlarınıza dönüştürür:

```ts
declare module '@i18n-micro/types' {
  export interface DefineLocaleMessage {
    nav: object
    'nav.home': string
    'profile.title': string
  }
}
```

Anahtarlar, her locale'den ve her sayfa dosyasından `t()`'nin yanıt verdiği anahtarlardır (nesneler de dahil) ve JSON değerlerinin tipine sahiptir. `TranslationKey`, bu anahtarların ve herhangi bir string'in birleşimidir; bu yüzden hata değil otomatik tamamlama alırsınız: yanlış yazılmış veya dinamik bir anahtar yine de derlenir. Parametreler ve dönüş değerleri tiplendirilmez.

Bilinen bir önek altındaki dinamik anahtarlar için `ScopedKey<'prefix'>` eşleşen anahtarlara daraltır:

```ts
import type { ScopedKey } from '@i18n-micro/types'

const statusText = (status: string) => t(`status.${status}` as ScopedKey<'status'>)
```

`TranslationKey` ve `ScopedKey`, `@i18n-micro/types` paketinden gelir (React, Preact ve Solid `TranslationKey`'i yeniden dışa aktarır; Vue aktarmaz).

## API {#api}

| Dışa aktarım | Giriş noktası | Notlar |
| --- | --- | --- |
| `I18nTypesPlugin(options)` | `@i18n-micro/types-generator` | Vite ve Rollup eklentisi |
| `generateTypes(options)` | `@i18n-micro/types-generator` | dosyayı yazar, yolunu döndürür |
| `getTypesString(options)` | `@i18n-micro/types-generator` | bildirimi yazmadan döndürür |
| `formatKeyProperty(key)` | `@i18n-micro/types-generator` | yardımcı |
| Nuxt modülü (`configKey: 'i18nTypes'`) | `@i18n-micro/types-generator/nuxt` | `translationDir` seçeneği |

Tam imzalar: [paket referansı](/tr/api/packages/types-generator).
