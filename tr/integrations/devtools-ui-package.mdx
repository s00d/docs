`@i18n-micro/devtools-ui`, Nuxt DevTools sekmesindeki çeviri düzenleyicisinin bir Vite eklentisiyle birlikte web bileşeni olarak paketlenmiş hâlidir. Geliştirme sırasında çeviri klasörünüzdeki JSON dosyalarına tarayıcıdan göz atmak ve onları düzenlemek için bir Vue, React, Preact, Solid veya Astro projesine ekleyin. Nuxt uygulamalarında bu zaten [Nuxt DevTools](/tr/guide/devtools) içinde bulunur.

![DevTools UI: bir dosya ağacı ve her anahtarın yanında varsayılan locale metnini gösteren bir düzenleyici](/images/devtools/02-translations-editor-dark.webp)

## Kurulum {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/devtools-ui
```

```bash npm
npm install -D @i18n-micro/devtools-ui
```

```bash yarn
yarn add -D @i18n-micro/devtools-ui
```

</CodeGroup>

Peer bağımlılığı yoktur.

## Yapılandırma {#setup}

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import { i18nDevToolsPlugin } from '@i18n-micro/devtools-ui/vite'

export default defineConfig({
  plugins: [i18nDevToolsPlugin({ translationDir: 'src/locales' })],
})
```

| Seçenek | Varsayılan | Notlar |
| --- | --- | --- |
| `translationDir` | `'src/locales'` | Vite köküne göreli, JSON dosyalarını içeren klasör. |
| `base` | `'/__i18n_api'` | API uç noktalarının temel yolu. |
| `injectButton` | `true` | Vite'ın `index.html` dönüşümü üzerinden sunulan sayfalara kayan bir düğme ekler. Astro'da böyle sayfalar yoktur: aşağıya bakın. |
| `defaultLocale` | `translationDir` içindeki ilk locale dosyası | `/config` tarafından raporlanır. |
| `fallbackLocale` | `defaultLocale` | `/config` tarafından raporlanır. |

Eklenti yalnızca geliştirme sunucusunda çalışır (`apply: 'serve'`); üretim derlemesi ondan hiçbir şey içermez. Düğme, eklentinin uç noktaları aracılığıyla dosyaları okuyan ve kaydeden `/__i18n_devtools.html` sayfasını açar:

| Uç nokta | Yaptığı |
| --- | --- |
| `GET <base>/translations` | `translationDir` altındaki her sözlük, göreli yola göre |
| `POST <base>/save` | gövde `{ file, content }`; `translationDir` içindeki mevcut bir `.json` dosyasının üzerine yazar, başka her şey için 403. Asla dosya oluşturmaz |
| `GET <base>/config` | `{ defaultLocale, fallbackLocale, locales, translationDir }`; `locales`, `translationDir` içindeki kök dosyalardan gelir |

Uç noktalar yalnızca devtools sayfasına yanıt verir: başka bir origin'den veya host'tan gelen istek `403` alır ve `/save` yalnızca `application/json` kabul eder (`415`). Sayfa, dosya değişikliklerinden Vite'ın HMR soketi üzerinden haberdar olur.

Astro'da eklenti yerine entegrasyonu ekleyin. Bu, geliştirme araç çubuğuna bir uygulama ekler:

```ts
// astro.config.mjs
import { defineConfig } from 'astro/config'
import { i18nDevToolsIntegration } from '@i18n-micro/devtools-ui/vite'

export default defineConfig({
  integrations: [i18nDevToolsIntegration({ translationDir: 'src/locales' })],
})
```

Kaydetme yalnızca dosyayı yazar. JSON'u Vite üzerinden import eden bir uygulama değişikliği HMR ile alır; düzenlemelerin çalışan örneğe doğrudan uygulanması için bir köprü kullanın.

## Canlı bir örneğe köprü {#bridge-to-a-live-instance}

Düzenleyiciyi kendi sayfanıza gömmek ve düzenlemelerin çalışan örneğe anında uygulanmasını sağlamak için bir adaptörden köprü oluşturun ve onu `<i18n-devtools-ui>` öğesine verin:

```ts
import { createBridge, register } from '@i18n-micro/devtools-ui'
import { i18n, locales } from './i18n' // a runtime, React, Preact or Solid instance

register() // defines <i18n-devtools-ui> once

const bridge = createBridge({
  adapter: {
    getRouteCache: () => Object.fromEntries(i18n.storage.translations),
    addTranslations: (locale, content, merge) => i18n.addTranslations(locale, content, merge),
    addRouteTranslations: (locale, route, content, merge) => i18n.addRouteTranslations(locale, route, content, merge),
    subscribe: (cb) => i18n.subscribe(cb),
    getCurrentLocale: () => i18n.locale,
  },
  locales,
  defaultLocale: 'en',
  translationDir: 'src/locales',
})

const el = document.createElement('i18n-devtools-ui') as HTMLElement & { bridge: typeof bridge }
el.bridge = bridge
document.body.append(el)
```

`getRouteCache`, sözlükleri `locale:route` anahtarlarıyla (`en:index`, `en:blog-post`) döndürmelidir; `i18n.storage.translations` tam olarak bunu tutar. Bir Vue örneği için `i18n.global.getRouteCache()` ve `i18n.global.subscribeToChanges(cb)` kullanın.

`saveTranslation` önce örneği günceller, ardından `<base>/save` adresine POST isteği gönderir. Uç nokta olmadığında (statik bir önizleme derlemesi) veya geliştirme sunucusuna ulaşılamadığında düzenleme `localStorage` içinde saklanır; diğer tüm kaydetme hatalarında önceki sözlük geri yüklenir ve hata fırlatılır.

## API {#api}

| Dışa aktarım | Giriş noktası |
| --- | --- |
| `i18nDevToolsPlugin(options)`, `i18nDevToolsIntegration(options)` | `@i18n-micro/devtools-ui/vite` |
| `register()`, `I18nDevToolsElement` | `@i18n-micro/devtools-ui` |
| `createBridge(options)`, `BridgeAdapter`, `CreateBridgeOptions` tipleri | `@i18n-micro/devtools-ui` (ayrıca `/bridge/create`) |
| `I18nDevToolsBridge` tipi | `@i18n-micro/devtools-ui` (ayrıca `/bridge`) |
| `createRpcClient`, `setupRpcHost` | `@i18n-micro/devtools-ui` |

Tam imzalar: [paket başvurusu](/tr/api/packages/devtools-ui).
