Bir ada, sunucunun i18n örneğinin bulunmadığı tarayıcıda çalışır. `@i18n-micro/astro`, sayfanın bir adanın ihtiyaç duyduğu anahtarları seçmesine, bunları tek bir prop olarak geçirmesine ve küçük bir framework adaptörü aracılığıyla adada okumasına olanak tanır. Vue, React, Preact ve Svelte adalarında `t`, `tc`, `tn`, `td`, `tdr` ve `has` elde edersiniz ve HTML'de yalnızca seçilen dizeler bulunur.

## Kurulum {#setup}

Önce [Astro entegrasyonunu ve ara katmanını](/tr/integrations/astro-package#setup) kurun, ardından kullandığınız framework entegrasyonunu ekleyin (`@astrojs/vue`, `@astrojs/react`, `@astrojs/preact`, `@astrojs/svelte`). Ada adaptörleri o framework'e peer bağımlılık olarak ihtiyaç duyar: `vue` `^3.3.0`, `react` `^16.8.0 || ^17.0.0 || ^18.0.0 || ^19.0.0`, `preact` `^10.0.0 || ^11.0.0` veya `svelte` `^4.0.0 || ^5.0.0`.

## Bir adaya çeviri geçirme {#pass-translations-to-an-island}

```astro
---
// src/pages/index.astro
import { getI18nProps } from '@i18n-micro/astro'
import Counter from '../components/Counter.vue'

const i18n = getI18nProps(Astro, ['counter.title', 'counter.apples'])
---

<Counter client:load i18n={i18n} />
```

`getI18nProps(Astro, keys?)`, `{ locale, fallbackLocale, currentRoute, translations }` döndürür (tip `I18nClientProps`). Adanın kullandığı anahtarları geçirin: her biri sunucuda `t()` gibi çözümlenir (rota, kök ve yedek sözlükler) ve yalnızca bulunan anahtarlar HTML'e girer. `keys` olmadan, `t()`'nin bu sayfada yanıtlayabildiği her şey her adaya gönderilir; böylece 2000 kök anahtar ada başına yaklaşık 100 KB eder; geliştirme modunda 20 KB'ın üzerinde bir uyarı bunu belirtir.

Adalar yalnızca bu nesneden çeviri yapar. `t`, geçirilmeyen her şey için anahtarı döndürür ve bağlantılı mesajlar çözümlenmez.

## Vue {#vue}

Adanın kök bileşeninde `provideI18n(() => props.i18n)` ve alt bileşenlerinde `useAstroI18n()` çağırın. Vue'nun `inject` fonksiyonu aynı bileşen tarafından sağlanan bir değeri görmez, bu nedenle hook kökte değil, bir alt bileşende çalışmalıdır:

```vue
<!-- src/components/Counter.vue -->
<script setup lang="ts">
import { provideI18n } from '@i18n-micro/astro/client/vue'
import type { I18nClientProps } from '@i18n-micro/astro'
import CounterBody from './CounterBody.vue'

const props = defineProps<{ i18n: I18nClientProps }>()
provideI18n(() => props.i18n)
</script>

<template><CounterBody /></template>
```

```vue
<!-- src/components/CounterBody.vue -->
<script setup lang="ts">
import { ref } from 'vue'
import { useAstroI18n } from '@i18n-micro/astro/client/vue'

const { t, tc } = useAstroI18n()
const count = ref(0)
</script>

<template>
  <h3>{{ t('counter.title') }}</h3>
  <button @click="count++">{{ tc('counter.apples', count) }}</button>
</template>
```

## React ve Preact {#react-and-preact}

```tsx
// src/components/Counter.tsx
import { useState } from 'react'
import { I18nProvider, useAstroI18n } from '@i18n-micro/astro/client/react'
import type { I18nClientProps } from '@i18n-micro/astro'

function Body() {
  const { t, tc } = useAstroI18n()
  const [count, setCount] = useState(0)
  return <button onClick={() => setCount(count + 1)}>{t('counter.title')}: {tc('counter.apples', count)}</button>
}

export default function Counter({ i18n }: { i18n: I18nClientProps }) {
  return (
    <I18nProvider value={i18n}>
      <Body />
    </I18nProvider>
  )
}
```

Preact için `I18nProvider` ve `useAstroI18n` öğelerini `@i18n-micro/astro/client/preact` paketinden içe aktarın; API aynıdır.

## Svelte {#svelte}

```svelte
<!-- src/components/Counter.svelte -->
<script lang="ts">
  import { createI18nStore, useAstroI18n } from '@i18n-micro/astro/client/svelte'
  import type { I18nClientProps } from '@i18n-micro/astro'

  export let i18n: I18nClientProps
  const { t, tc } = useAstroI18n(createI18nStore(i18n))
  let count = 0
</script>

<button on:click={() => count++}>{t('counter.title')}: {tc('counter.apples', count)}</button>
```

`useAstroI18n(store)`, şablonda `$store` okumaları için `store` değerini de döndürür.

## Kalıcı adalar {#persisted-islands}

`transition:persist` içeren bir ada, bir gezinmeden sonra yeni prop'lar alır. React, Preact ve Vue (bir getter verildiğinde) bunları izler. Svelte'de store'u saklayın ve prop'ları ona aktarın: `const store = createI18nStore(i18n)`, `const { t } = useAstroI18n(store)`, ardından `$: store.set(i18n)` (runes ile `$effect(() => store.set(i18n))`).

## API {#api}

| Giriş | Dışa aktarımlar |
| --- | --- |
| `@i18n-micro/astro` | `getI18nProps`, tip `I18nClientProps` |
| `@i18n-micro/astro/client/vue` | `provideI18n(props \| () => props)`, `useAstroI18n()` |
| `@i18n-micro/astro/client/react` | `I18nProvider` (`value` prop'u), `useAstroI18n()` |
| `@i18n-micro/astro/client/preact` | `I18nProvider` (`value` prop'u), `useAstroI18n()` |
| `@i18n-micro/astro/client/svelte` | `createI18nStore(props)`, `useAstroI18n(store)` |
| `@i18n-micro/astro/client` | framework olmadan saf `translate`, `hasTranslation` |

Her `useAstroI18n`; `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`, `setLocale`, `setRoute` ve `locale` döndürür. Bir adanın tek bir birleştirilmiş sözlüğü vardır, bu nedenle `has`, `t`'nin yanıtlayabildiği bir anahtar için (yedek locale'den de olsa) true döner; sunucuda `has` yalnızca etkin locale'e bakar.
