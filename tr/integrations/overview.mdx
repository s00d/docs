`@i18n-micro/*` paketleri, Nuxt I18n Micro'nun çeviri çekirdeğini Vue, React, Preact, Solid, Astro, VitePress ve düz JavaScript'e taşır. Uygulamanız bir Nuxt uygulaması olmadığında veya Nuxt dışındaki bir betik ya da sunucunun aynı çeviri dosyalarına ihtiyacı olduğunda bunları kullanın. Her paket tek bir instance modelini, tek bir yönlendirici adaptörü sözleşmesini ve aynı dört bileşeni paylaşır; bunlar bu sayfada bir kez açıklanmıştır.

## Instance {#the-instance}

`createI18n(options)`, sözlükleri, geçerli locale'i ve geçerli rotayı tutan tek bir instance döndürür. Seçenekler her pakette aynıdır:

| Seçenek | Tip | Varsayılan | Notlar |
| --- | --- | --- | --- |
| `locale` | `string` | zorunlu | Etkin locale. |
| `fallbackLocale` | `string` | `locale` | `locale` içinde bir anahtar eksik olduğunda aranır. |
| `messages` | `Record<locale, Translations>` | `{}` | Kök sözlükler (`'index'` rotası). |
| `routeMessages` | `Record<route, Record<locale, Translations>>` | `{}` | Rota sözlükleri. Yalnızca Runtime, React, Preact, Node ve VitePress. |
| `plural` | `PluralFunc` | `defaultPlural` | Özel çoğul kuralı. |
| `missingWarn` | `boolean` | `true` | Eksik bir anahtar için tarayıcıda yalnızca geliştirme ortamında `console.warn`. |
| `missingHandler` | `(locale, key, routeName) => void` | — | Uyarı yerine çağrılır. |
| `numberFormats` | `Record<locale, Record<name, Intl.NumberFormatOptions>>` | — | Adlandırılmış biçimler: `tn(9.5, 'currency')`. |
| `datetimeFormats` | `Record<locale, Record<name, Intl.DateTimeFormatOptions>>` | — | Adlandırılmış biçimler: `td(date, 'short')`. |
| `timeZone` | `string` | çalışma zamanının saat dilimi | `td` tarihleri için IANA saat dilimi; `tdr`'yi etkilemez. Sunucu ve tarayıcının aynı tarihi render etmesi için ayarlayın. |
| `now` | `() => number` | `Date.now` | `tdr`'nin saati. Her ikisinin de aynı metni render etmesi için hydration'a sunucunun zamanını verin. |
| `localeIso` | `Record<code, string>` | — | Çoğul kuralları için kullanılan BCP 47 etiketi (`ua` → `uk-UA`). React, Preact ve Solid bunu provider'ın `locales` değerindeki `iso` alanından alır. |

Sözlükler, `locale:route` (`en:index`, `en:about`) anahtarlı bir `Map` olan `i18n.storage.translations` içinde bulunur.

Bir anahtar önce geçerli rotanın sözlüğünde, ardından kök sözlükte aranır; önce `locale` için, sonra `fallbackLocale` için. Eksik bir anahtar anahtarın kendisini (veya verdiğiniz `defaultValue` değerini) döndürür.

```ts
i18n.addTranslations('en', { nav: { home: 'Home' } }) // root, deep-merged
i18n.addRouteTranslations('en', 'about', { title: 'About us' }) // route chunk
i18n.addTranslations('en', { nav: { home: 'Start' } }, false) // replace instead of merge
i18n.setRoute('about')
i18n.t('title') // 'About us'
i18n.t('nav.home') // 'Start' (root key, still visible on the route)
```

### Çeviri ve biçimlendirme {#translate-and-format}

| Metot | Döndürür |
| --- | --- |
| `t(key, params?, defaultValue?, routeName?)` | `{param}` yerleştirilmiş değer (string, sayı, nesne). |
| `ts(...)` | `t` ile aynı, string olarak. |
| `tc(key, count \| params, defaultValue?)` | Çoğul biçim. |
| `tn(value, options \| name)` | Etkin locale'de `Intl.NumberFormat`. |
| `td(value, options \| name)` | `Intl.DateTimeFormat`. |
| `tdr(value, options?)` | Göreli zaman (`3 days ago`). |
| `has(key, routeName?)` | Etkin locale anahtara sahip olduğunda `true` (rota veya kök sözlük; yedek kontrol edilmez). |

`defaultPlural` değeri `|` karakterinden böler ve `count` indeksindeki biçimi seçer, son biçimle sınırlandırılır; negatif, kesirli veya `NaN` bir sayı son biçimi seçer.

Özel bir `plural` fonksiyonu `(key, count, params, locale, getter)` alır. Değeri `getter(key)` üzerinden okuyun; anahtarı bölmeyin:

```ts
import type { PluralFunc } from '@i18n-micro/vue'

const plural: PluralFunc = (key, count, params, _locale, getter) => {
  const value = getter(key)
  if (typeof value !== 'string') return null
  const forms = value.split('|').map((form) => form.trim())
  return (count === 1 ? forms[0] : forms[1] ?? forms[0])!.replace('{count}', String(count))
}
```

## Yönlendirici adaptörü {#router-adapter}

SPA paketleri bir yönlendiriciye bağımlı değildir. Bir yönlendirici adaptörü (`I18nRoutingStrategy`), onlara geçerli yolu nasıl okuyacaklarını, nasıl gezineceklerini ve yerelleştirilmiş bir yolu nasıl oluşturacaklarını söyler. Yerleşik adaptörler `defaultLocale` hariç her locale'e önek ekler (`/about`, `/de/about`).

| Üye | Zorunlu | Kullanan |
| --- | --- | --- |
| `getCurrentPath(): string` | evet | etkin bağlantı kontrolü (sayfaya göre; sorgu ve hash dikkate alınmaz), `switchLocale` (bunları korur) |
| `push({ path }): void` | evet | `switchLocale`, `linkComponent` olmadan `<I18nLink>`, `<I18nSwitcher>` |
| `replace({ path }): void` | evet | — |
| `resolvePath(to, locale)` | hayır | `localePath`, `localeRoute`, `<I18nLink>`; olmadığında yollar olduğu gibi döndürülür |
| `linkComponent` | hayır | `<I18nLink>`, `<a>` yerine bunu (ör. `RouterLink`) render eder |
| `getRoute()` | hayır | SEO yardımcıları için `{ fullPath, query }` |

`push` ve `replace`; Vue, React, Preact ve Solid'de zorunludur. Astro'nun isteğe bağlı `push`/`replace` içeren kendi sunucu tarafı adaptörü vardır (bkz. [Astro](/tr/integrations/astro-package#router-adapter)).

Herhangi bir history tabanlı yönlendirici için minimal bir adaptör:

```ts
import type { I18nRoutingStrategy } from '@i18n-micro/react'

const locales = ['en', 'de']
const stripLocale = (path: string) => path.replace(/^\/(en|de)(?=\/|$)/, '') || '/'

export const historyAdapter: I18nRoutingStrategy = {
  getCurrentPath: () => window.location.pathname + window.location.search + window.location.hash,
  push: ({ path }) => window.history.pushState({}, '', path),
  replace: ({ path }) => window.history.replaceState({}, '', path),
  resolvePath: (to, locale) => {
    const path = stripLocale(typeof to === 'string' ? to : to.path || '/')
    return locale === 'en' ? path : `/${locale}${path === '/' ? '' : path}`
  },
}
```

## Bileşenler {#components}

Vue, React, Preact ve Solid aynı dört bileşeni sunar. Prop'ları eşleşir; React, Preact ve Solid diğer prop'ları kök öğeye aktarır.

### `<I18nT>` {#&lt;i18nt&gt;}

| Prop | Tip | Notlar |
| --- | --- | --- |
| `keypath` | `string` | zorunlu |
| `params` | `object` | yerleştirme değerleri |
| `plural` | `number \| string` | `tc(keypath, count)` render eder |
| `number` | `number \| string` | `tn(number)` değerini `{number}` olarak iletir |
| `date` | `Date \| string \| number` | `td(date)` değerini `{date}` olarak iletir |
| `relativeDate` | `Date \| string \| number` | `tdr(relativeDate)` değerini `{relativeDate}` olarak iletir |
| `tag` | `string` | sarmalayıcı öğe, varsayılan `span` |
| `html` | `boolean` | çeviriyi HTML olarak render eder; güvenilir olmalıdır, parametreler escape edilir |
| `defaultValue` | `string` | eksik bir anahtarın yerine geçer ve `hideIfEmpty` boş bir değeri gizlediğinde yalın olarak render edilir |
| `hideIfEmpty` | `boolean` | boş bir çeviri için hiçbir şey render etmez |
| `customPluralRule` | `PluralFunc` | bu öğe için çoğul kuralı |

Yalnızca bir biçimlendirme prop'u uygulanır ve şu sırayla kontrol edilir: `number`, `date`, `relativeDate`, `plural`.

#### Zengin metin {#rich-text}

Bir `{placeholder}` bir öğe barındırabilir. Vue'da bu adlandırılmış bir slot'tur; React, Preact ve Solid'de `components` prop'u ada göre öğeler veya öğe döndüren fonksiyonlar verir. Her iki durumda da aynı addaki bir parametreye üstün gelir, her dalda çalışır ve yer tutucuların sırasını değiştiren bir locale'de de korunur.

```tsx
// { "terms": "I accept the {link} of {company}" }
<I18nT keypath="terms" params={{ company: 'ACME' }} components={{ link: <a href="/terms">terms</a> }} />
```

Solid'de bir yer tutucu tekrarlandığında bir fonksiyon verin: bir düğüm yalnızca tek bir yerde durabilir. `children` metnin yerini alır; bir fonksiyon olarak, Vue'nun varsayılan slot'u gibi `{ translation }` alır. `html` bunların hepsini yok sayar.

### `<I18nLink>` {#&lt;i18nlink&gt;}

| Prop | Tip | Notlar |
| --- | --- | --- |
| `to` | `string \| { path }` | adaptörün `resolvePath` fonksiyonu üzerinden yerelleştirilir |
| `activeStyle` | stil nesnesi | geçerli sayfada `style` üzerine birleştirilir; React, Preact ve Solid bunu üst bir bölüm için de uygular |
| `localeRoute` | fonksiyon | bu bağlantı için `resolvePath` fonksiyonunu geçersiz kılar |

Harici URL'ler (`https://`, `mailto:`, `tel:`) `<a target="_blank" rel="noopener noreferrer">` olarak render edilir; kendi belirlediğiniz `target` veya `rel` önceliklidir. `onClick` her zaman çalışır. Değiştirici tuşlu bir tıklama, başka bir fare düğmesi veya bir `target` tarayıcıya bırakılır.

### `<I18nSwitcher>` {#&lt;i18nswitcher&gt;}

Satır içi varsayılan stillere sahip, etkin locale'lerin (`disabled: true` locale'ler gizlenir) açılır listesi. Öğeleri, locale'den alınan `lang`, `hreflang` ve `dir` değerlerine sahip bağlantılardır. Varsayılan olarak birine tıklamak locale'i ayarlar ve adaptörün `push` fonksiyonunu yerelleştirilmiş geçerli yolla çağırır; bir `switchLocale` prop'u bu eylemin yerini alır. Bir `localeRoute` olduğunda ve yönlendirici olmadığında tarayıcı bağlantıyı takip eder. Escape tuşu veya dışarıya tıklama listeyi kapatır.

| Prop | Notlar |
| --- | --- |
| `locales`, `currentLocale`, `getLocaleName` | sağlanan değerleri geçersiz kılar |
| `switchLocale(code)` | yerleşik değiştirmenin yerini alır |
| `localeRoute` | `resolvePath` fonksiyonunun yerini alır |
| `customLabels` | `{ de: 'DE' }` |
| `customWrapperStyle`, `customButtonStyle`, `customDropdownStyle`, `customItemStyle`, `customLinkStyle`, `customActiveLinkStyle`, `customDisabledLinkStyle`, `customIconStyle` | stil geçersiz kılmaları |

### `<I18nGroup>` {#&lt;i18ngroup&gt;}

Alt öğelerine önekli bir `t` ileten bir `<div class="i18n-group">`. İçindeki `<I18nT>` veya `t()` çağrılarına önek **eklemez**; yalnızca aşağıya ilettiği `t` öneklidir.

| Prop | Notlar |
| --- | --- |
| `prefix` | zorunlu, ör. `'profile'` |
| `groupClass` | sarmalayıcıya ek sınıf |

Önekli `t`, Vue'da bir scoped slot (`v-slot="{ t }"`), React, Preact ve Solid'de ise bir render-prop alt öğesi (`{({ t }) => …}`) aracılığıyla gelir.

## Tipli anahtarlar {#typed-keys}

`t()` herhangi bir string kabul eder. Anahtarlarınız için otomatik tamamlama almak üzere [tip oluşturucu](/tr/integrations/types-generator) ile bir bildirim oluşturun. Anahtarlar önerilir, zorunlu tutulmaz ve parametreler tiplenmez.

## Nuxt modülüyle karşılaştırma {#compared-with-the-nuxt-module}

Paketlerde dosya tabanlı yönlendirme, sunucu middleware'i ve çeviri yükleyicisi yoktur: JSON'u ne zaman yükleyeceğinize (`import`, `fetch` veya sunucuda `@i18n-micro/node`) ve hangi yönlendirici adaptörünü kullanacağınıza siz karar verirsiniz. Locale algılama, SEO meta ve rota oluşturma Nuxt özellikleridir; Astro'nun algılama için kendi middleware'i ve SEO için `useLocaleHead` fonksiyonu vardır.
