`@i18n-micro/vitepress`, bir VitePress sitesine çalışma zamanı sözlükleri ekler: markdown içinde `$t` ve `<I18nT>`, yol yardımcıları ve SEO etiketleri; [`@i18n-micro/vue`](/tr/integrations/vue-package) üzerine kuruludur. Aynı arayüz dizeleri birçok sayfada göründüğünde ve bunları her locale için çoğaltmak istemediğinizde kullanın. Locale, VitePress'in kendi yol locale'lerini (`/`, `/fr/`) izler.

## Ne zaman kullanılır {#when-to-use-it}

| İhtiyaç | Çözüm |
|------|----------|
| Çoğaltılmış `.md`, URL önekleri | VitePress `locales` |
| Çalışma zamanı `$t` / bileşenler / yol senkronizasyonu / SEO head | `@i18n-micro/vitepress` |
| Varsayılan tema arayüz etiketleri (`docFooter`, arama arayüzü) | Locale başına kendi `themeConfig` yapılandırmanız |

<Tip>

**Playground** — [`packages/vitepress/playground`](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/vitepress/playground) — `pnpm -C packages/vitepress/playground dev`

</Tip>

## Kurulum {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vitepress
```

```bash npm
npm install @i18n-micro/vitepress
```

```bash yarn
yarn add @i18n-micro/vitepress
```

</CodeGroup>

Peer bağımlılıklar: `vitepress` `>=1.0.0 || >=2.0.0-alpha.0`, `vue` `^3.3.0`. Node betikleri, paketle birlikte kurulan ve `/node` üzerinden yeniden dışa aktarılan `@i18n-micro/node` paketini kullanır. Yayımlanan tipler `skipLibCheck: false` ile Vue 3.5.5 veya üstünü gerektirir; olağan şablon ayarı olan `skipLibCheck: true` ile eski sürümler de derlenir.

## Yapılandırma {#setup}

```
locales/en.json
locales/fr.json
locales/pages/guide/demo/en.json   # optional page-scoped
locales/pages/guide/demo/fr.json
```

Sayfa dosyaları, Nuxt/Astro ile aynı şekilde rota adlarına eşlenir (`guide/demo` → `guide-demo`).

### 1. Yapılandırma — `@i18n-micro/vitepress/config` {#1-config-—-@i18n-micro/vitepress/config}

```ts
// .vitepress/config.mts
import { defineConfig } from 'vitepress'
import { withI18n, buildVitePressLocales } from '@i18n-micro/vitepress/config'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English', og: 'en_US' },
  { code: 'fr', iso: 'fr-FR', displayName: 'Français', og: 'fr_FR' },
]
const defaultLocale = 'en'

export default defineConfig(
  withI18n(
    {
      locales: buildVitePressLocales(locales, defaultLocale),
      // themeConfig.i18nRouting is injected automatically
    },
    {
      locale: defaultLocale,
      defaultLocale,
      locales,
      translationDir: 'locales',
      metaBaseUrl: 'https://example.com', // optional SEO head
    },
  ),
)
```

### 2. Tema — `@i18n-micro/vitepress/theme` {#2-theme-—-@i18n-micro/vitepress/theme}

```ts
// .vitepress/theme/index.ts
import DefaultTheme from 'vitepress/theme'
import { defineI18nTheme } from '@i18n-micro/vitepress/theme'

export default defineI18nTheme(DefaultTheme)
```

Başlangıç locale'i kurulumdan önce geçerli yoldan alınır (`/fr/…` üzerinde varsayılan locale'in anlık görünmesi olmaz).

### İleri düzey: manuel `createI18n` {#advanced-manual-createi18n}

İstemci için tek bir fabrika: Vue eklentisi + yol metotları + `enhanceApp` (ayrı yönlendirici yardımcısı dışa aktarımı yoktur).

```ts
import { createI18n, messagesFromGlob } from '@i18n-micro/vitepress'

const i18n = createI18n({
  locale: 'en',
  defaultLocale: 'en',
  locales: [{ code: 'en' }, { code: 'fr' }],
  messages: messagesFromGlob(import.meta.glob('../../locales/*.json', { eager: true })),
})

i18n.localizePath('/guide', 'fr')
// in theme enhanceApp:
i18n.enhanceApp({ app, router })
```

### Node betikleri — `@i18n-micro/vitepress/node` {#node-scripts-—-@i18n-micro/vitepress/node}

`@i18n-micro/node` paketinin `createI18n` / `loadTranslations` fonksiyonlarını kullanır (Astro ve CLI ile aynı), ardından VitePress yol metotlarını `BaseI18n.extend` ile ekler:

```ts
import { createI18n } from '@i18n-micro/vitepress/node'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  translationDir: './locales',
  locales: ['en', 'fr'],
  defaultLocale: 'en',
})
await i18n.loadTranslations()
i18n.t('cta.readMore')
i18n.localizePath('/guide', 'fr')
```

Yolsuz düz Node: `import { createI18n } from '@i18n-micro/node'`.

## Sayfa içi çeviriler {#in-page-translations}

Her VitePress markdown dosyası bir Vue SFC'dir.

### Global bileşenler ve `$t` (markdown'da önerilir) {#global-components-and-$t-recommended-in-markdown}

`createI18n` / `defineI18nTheme`, `I18nT` / `I18nLink` / `I18nGroup` / `I18nSwitcher` bileşenlerini ve `$t` / `$tc` / `$ts` öğelerini kaydeden `@i18n-micro/vue` paketini kurar.

```md
{{ $t('cta.readMore') }}

<I18nT keypath="greeting" :params="{ name: 'VitePress' }" />

<I18nLink to="/guide/demo">Demo</I18nLink>
```

### `<script setup>` içinde `useI18n` {#usei18n-in-&lt;script-setup>}

```md
<script setup>
import { useI18n } from '@i18n-micro/vitepress'
const { t, tc, locale, localePath, switchLocale } = useI18n()
</script>

# {{ t('section.title') }}
```

## Dil açılır menüsü {#language-dropdown}

`locales` birden fazla girdi içerdiğinde VitePress kendi dil menüsünü (`VPNavBarTranslations`) gösterir. `withI18n`, `themeConfig.i18nRouting` ayarını bağlar; böylece küre simgesi `<I18nSwitcher>` / yol yardımcılarıyla eşleşir.

`<I18nSwitcher>` bileşenini varsayılan küre simgesinin yanında değil, yalnızca özel düzenlerde kullanın.

## SSR notları {#ssr-notes}

- Ön render sırasında locale, çerezlerden değil URL yolundan gelir.
- Tema kodu içe aktarma sırasında `window` nesnesine dokunmamalıdır.
- Node yapılandırma değerlendirmesinin hiçbir zaman `virtual:i18n-micro/*` yüklememesi için `defineI18nTheme` öğesini `/theme` üzerinden içe aktarın.

## API yüzeyi {#api-surface}

| Dışa aktarım | Rol |
|--------|------|
| `createI18n` (`.`) | İstemci: Vue eklentisi + yol metotları + `enhanceApp` |
| `getLocaleFromPath` / `stripSiteBase` / `routeNameFromPath` (`.`) | `syncWithVitePress: false` olduğunda manuel locale senkronizasyonu |
| `createI18n` (`/node`) | Node: `@i18n-micro/node` + yol metotları |
| `defineI18nTheme` (`/theme`) | Sıfır şablon kodlu tema |
| `withI18n` (`/config`) | Yapılandırma + sanal modüller + isteğe bağlı SEO |
| `buildVitePressLocales` (`/config`) | `Locale[]` dizisinden VitePress `locales` oluşturur |
| `buildVitePressLocaleHead` (`/config`) | Manuel SEO head (`metaBaseUrl` tarafından da kullanılır) |
| `messagesFromGlob` | `createI18n` için isteğe bağlı glob → mesaj eşlemesi |
| `useI18n` / `I18nT` / … | `@i18n-micro/vue` paketinden yeniden dışa aktarılır |
| `BaseI18n.extend` (`@i18n-micro/core`) | Herhangi bir i18n örneğine özel metotlar ekler |

## OpenAPI tarzı siteler (entegrasyon kilitleri) {#openapi-style-sites-integration-locks}

Regresyon test paketi: `packages/vitepress/tests/integration-openapi.test.ts` (derin yollar, `base=/openapi_docs/`, senkronizasyon kapalı + manuel locale, Node oluşturucular, SEO).

| Desen | Yapılacak |
|---------|---------|
| Derin `/…/{spec}/{op}` sayfaları, yalnızca kök arayüz JSON'u | Varsayılan `syncWithVitePress: true` tercih edin (sayfa sözlüğü yokken `setRoute('index')` korunur) **veya** `syncWithVitePress: false` + `getLocaleFromPath` |
| Sayfa sözlükleri olmadan asla `setRoute(deepName)` çağırmayın | Kök arayüz anahtarları `setRoute('index')` yapılana kadar kaybolur |
| Oluşturucular / `getTranslation` | `/node` üzerinden `createI18n` + `await loadTranslations()` + `i18n.t(key)` (`i18n.locale` ayarlayın) |
| `transformPageData` içinde özel canonical | `withI18n` fonksiyonuna `meta: false` geçirin (çift etiketlerden kaçının) |
| Site tabanıyla paket SEO'su | `metaBaseUrl` + VitePress `base` → mutlak URL'ler tabanı içerir |
| Eski paket derlemelerinden yeniden adlandırma | `withI18nMicro` → `withI18n`, `createVitePressI18n` → `createI18n`, `loadMessages` → node `createI18n` |
