`@i18n-micro/react` ve `@i18n-micro/preact`, framework'ten bağımsız [runtime](/tr/integrations/runtime-package) örneğini bir provider, bir `useI18n()` hook'u ve dört bileşenle sarar. Bunları Nuxt ile oluşturulmamış bir React veya Preact uygulamasında kullanın. Her iki paket de aynı API'ye sahiptir; [Preact](#preact) bölümü birkaç farkı listeler, ortak model ise [Framework'ler](/tr/integrations/overview) sayfasında anlatılır.

## Kurulum {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/react
```

```bash npm
npm install @i18n-micro/react
```

```bash yarn
yarn add @i18n-micro/react
```

</CodeGroup>

Peer bağımlılıkları: `react` `^18.0.0 || ^19.0.0`; `react-dom` (isteğe bağlı, oluşturma için); `react-router-dom` `^6.0.0 || ^7.0.0` (isteğe bağlı, yalnızca `@i18n-micro/react/router` için). React 19.3 ve 18.3, React Router 7.18 ve 6.30 üzerinde test edilmiştir.

## Yapılandırma {#setup}

```tsx
// src/main.tsx
import { createRoot } from 'react-dom/client'
import { createI18n, I18nProvider } from '@i18n-micro/react'
import App from './App'
import en from './locales/en.json'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English' },
  { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
]

const i18n = createI18n({ locale: 'en', fallbackLocale: 'en', messages: { en } })

createRoot(document.getElementById('root')!).render(
  <I18nProvider i18n={i18n} locales={locales} defaultLocale="en">
    <App />
  </I18nProvider>,
)
```

<Warning>

Örneği bir kez, modül düzeyinde veya bir `useState` başlatıcısında oluşturun; asla bir bileşen gövdesinde oluşturmayın.

</Warning>

`<I18nProvider>`, `i18n`, `locales`, `defaultLocale` ve `routingStrategy` alır:

- Belirtilmeyen bir prop, örnek dahil, dıştaki bir provider'ın değerini korur.
- Hiç örnek yoksa, yanlarındaki `createI18n` seçeneklerinden bir tane oluşturur, böylece prop'lar düz veri olarak kalır: `<I18nProvider locale="de" messages={messages}>`.
- Yeni bir `locale` prop'u, o oluşturmanın `messages` değeriyle yeni bir örnek oluşturur. Böyle bir örnek bileşenin içinde yaşar: üstündeki bir şey mount sırasında askıya alınırsa (suspend), React onu kendisine eklenen her şeyle birlikte atar.

`routeMessages` dahil tüm `createI18n` seçenekleri [örnek](/tr/integrations/overview#the-instance) bölümündedir.

## Çeviri {#translate}

```tsx
import { useI18n } from '@i18n-micro/react'

export function Greeting() {
  const { t, tc, tn } = useI18n()
  return (
    <>
      <h1>{t('greeting', { name: 'Ada' })}</h1> {/* Hello, Ada! */}
      <p>{tc('apples', 3)}</p> {/* 3 apples */}
      <p>{tn(1234.5)}</p>
    </>
  )
}
```

`useI18n()` şunları döndürür:

| Grup | Üyeler |
| --- | --- |
| Çeviri | `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has` |
| Yerel ayar ve rota | `locale`, `fallbackLocale`, `currentRoute`, `setLocale`, `setRoute`, `getRoute`, `getLocales`, `defaultLocale()`, `getLocaleName` |
| Yönlendirme | `switchLocale`, `localePath`, `localeRoute` |
| Sözlükler | `addTranslations`, `addRouteTranslations`, `clearCache` |

- Bileşen; yerel ayar, rota veya okunabilir bir sözlük değiştiğinde ve provider yeni bir `locales` veya `routingStrategy` nesnesi aldığında yeniden oluşturulur. Ne etkin ne de yedek olan bir yerel ayarın sözlüğü hiçbir şeyi yeniden oluşturmaz.
- `t` ve diğer çeviri metotları yalnızca depo ile birlikte değişir, bu nedenle `memo` ve effect bağımlılıklarında güvenle kullanılabilir.

`useT`, değer olarak tek bir dizedir. Bileşen, provider'ın diğer prop'larına ne olursa olsun yalnızca o dize değiştiğinde oluşturulur; `<I18nT>` da onlara bağlı değildir:

```tsx
const title = useT('page.title')
```

İstediğiniz zaman daha fazla sözlük yükleyin:

```tsx
const { addTranslations, addRouteTranslations, setRoute } = useI18n()

useEffect(() => {
  import('./locales/de.json').then((m) => addTranslations('de', m.default))
  addRouteTranslations('en', 'about', { title: 'About us' })
  setRoute('about') // t('title') now reads the 'about' dictionary first
}, [])
```

Örneğin kendisinde ayrıca `fetch` üzerinden JSON için `loadFromUrl(url, { locale, routeName })` bulunur.

## Yerel ayarı değiştirme {#switch-locale}

```tsx
const { setLocale, switchLocale } = useI18n()

setLocale('de') // only the locale
switchLocale('de') // the locale, then the adapter's push to the localized current path
```

Değiştirmek hiçbir şey yüklemez; önce yerel ayarın sözlüğünü ekleyin. Bir depo yazması, `startTransition` içinde bile React için senkrondur, bu yüzden eksik bir sözlük nedeniyle askıya alınan bir bileşen kendi fallback'ini gösterir. `useLocaleSwitch` önce yükler ve sözlük gelene kadar eski arayüzü korur:

```tsx
const [switchTo, pending] = useLocaleSwitch((locale) => i18n.loadFromUrl(`/locales/${locale}.json`, { locale }))

<button disabled={pending} onClick={() => switchTo('de')}>Deutsch</button>
```

Son çağrı kazanır. Başarısız bir yükleme reddedilir ve yerel ayarı olduğu gibi bırakır.

`<I18nGroup>`, render-prop alt öğesine önekli bir `t` iletir. İçindeki `<I18nT>` ve `t()` öneklenmez:

```tsx
<I18nGroup prefix="profile">{({ t }) => <h2>{t('title')}</h2> /* profile.title */}</I18nGroup>
```

## Yönlendirme {#routing}

React Router adaptörü bir alt yolda bulunur, böylece ana giriş noktası `react-router-dom`'u asla içe aktarmaz. `useLocation()` ve `useNavigate()` gerektirir, bu yüzden onu router'ın altındaki bir bileşen içinde oluşturun:

```tsx
// src/App.tsx
import { useMemo } from 'react'
import { BrowserRouter, Route, Routes, useLocation, useNavigate } from 'react-router-dom'
import { I18nLink, I18nProvider, I18nSwitcher } from '@i18n-micro/react'
import { createReactRouterAdapter } from '@i18n-micro/react/router'
import { i18n, locales } from './i18n'
import { About, Home } from './pages'

function Localized() {
  const location = useLocation()
  const navigate = useNavigate()
  // memoized: a new object on every render re-renders every `useI18n()` consumer
  const routingStrategy = useMemo(() => createReactRouterAdapter(locales, 'en', location, navigate), [location, navigate])
  return (
    <I18nProvider i18n={i18n} locales={locales} defaultLocale="en" routingStrategy={routingStrategy}>
      <I18nLink to="/about">About</I18nLink>
      <I18nSwitcher />
      <Routes>
        <Route path="/:locale?" element={<Home />} />
        <Route path="/:locale?/about" element={<About />} />
      </Routes>
    </I18nProvider>
  )
}

export default function App() {
  return (
    <BrowserRouter>
      <Localized />
    </BrowserRouter>
  )
}
```

Adaptör, varsayılan dışındaki her yerel ayara önek ekler (`/about`, `/de/about`) ve `<I18nLink>` bileşenini React Router'ın `<Link>` bileşeni olarak oluşturur. Yerel ayarı URL'den kendiniz ayarlayın (örneğin bir effect içinde `useParams().locale` üzerinden). Diğer herhangi bir router için `getCurrentPath`, `push` ve `replace` (hepsi zorunlu) içeren bir adaptör yazın — bkz. [Router adaptörü](/tr/integrations/overview#router-adapter).

## SSR {#ssr}

`renderToString` çalışır: `useI18n()` bir sunucu anlık görüntüsüne sahiptir. Farklı yerel ayarlardaki isteklerin durum paylaşmaması için istek başına bir örnek oluşturun ve oluşturmadan önce sözlüklerini ekleyin ya da provider'a düz veri iletin.

### Hydration {#hydration}

Sayılar, çoğullar ve metin olduğu gibi hydrate edilir. Bir tarih saat dilimine, göreli bir tarih ise saate bağlıdır: `timeZone` değerini sunucuda ve tarayıcıda ayarlayın, `tdr` için de tarayıcıya sunucunun zamanını `now` ile verin. `date` veya `relativeDate` ile kullanılan `<I18nT>`, `suppressHydrationWarning` ayarlar; böylece bir fark hydration'ı başarısız kılmaz, ancak metin değişene kadar sunucunun metni kalır. Bu yalnızca bir seviyeye ulaşır: çeviriyi bir öğe içine saran `children` bir fark olduğunda yine başarısız olur, bu yüzden onlara aynı `timeZone` değerini verin.

### Server Components {#server-components}

Paket, istemci kodunu `'use client'` ile işaretler. `@i18n-micro/react/server`, `createI18n` ve örneği prop olarak alan hook'suz bir `I18nT` içerir, böylece metin istemci paketinin dışında kalır. Next.js app router'da olduğu gibi `react-server` koşulu altında ana giriş noktası da buna çözümlenir, ancak TypeScript bunu varsayılan olarak bilmez: `/server`'dan içe aktarın. `@i18n-micro/react/client` her zaman istemci giriş noktasını verir.

```tsx
// app/[locale]/layout.tsx: a server component
import { cache } from 'react'
import { createI18n, I18nT } from '@i18n-micro/react/server'
import { I18nProvider } from '@i18n-micro/react/client'
import { loadMessages } from './messages'

const getI18n = cache(async (locale: string) => createI18n({ locale, messages: await loadMessages(locale) }))

export default async function Layout({ params, children }) {
  const { locale } = await params
  const i18n = await getI18n(locale)
  return (
    <I18nProvider locale={locale} messages={{ [locale]: i18n.resolveTranslations() }}>
      <h1>
        <I18nT i18n={i18n} keypath="title" />
      </h1>
      {children}
    </I18nProvider>
  )
}
```

`react-server-dom-webpack` üzerinden oluşturulmuştur; bir Next.js uygulamasının kendisi bununla henüz çalıştırılmamıştır.

## Preact {#preact}

`@i18n-micro/preact` aynı kaynaktan, `preact/compat` olmadan doğrudan Preact üzerinde oluşturulmuştur: aynı örnek, provider, hook'lar ve bileşenler. Farklar:

| | React | Preact |
| --- | --- | --- |
| Peer bağımlılığı | `react` (+ isteğe bağlı `react-router-dom`) | `preact` `^10.0.0 \|\| ^11.0.0`, 10.29 ve 11.1 üzerinde test edilmiştir |
| Örnek sınıfı | `ReactI18n` | `PreactI18n` |
| Router adaptörü | `/router`'dan `createReactRouterAdapter` | `/router`'dan `createBrowserHistoryAdapter(locales, defaultLocale, ssrUrl?)` |
| Yeniden oluşturma | `useSyncExternalStore` | depoyu yeniden kontrol eden bir layout-effect aboneliği |
| Server Components | `/server`, `/client` | yok |

`createBrowserHistoryAdapter` herhangi bir History API router'ı (wouter, preact-router) ile çalışır: `push` ve `replace`, `history.pushState` / `replaceState` çağırır ve `popstate` gönderir; `<I18nLink>` ise `push` üzerinden gezinen düz bir `<a>` oluşturur. Sunucunun adres çubuğu yoktur: isteğin URL'sini `ssrUrl` olarak iletin, aksi halde bağlantılar ve dil değiştirici `/` üzerindeymiş gibi oluşturulur. Tarayıcıda adres çubuğu önceliklidir.

```tsx
// src/main.tsx
import { render } from 'preact'
import { createI18n, I18nProvider } from '@i18n-micro/preact'
import { createBrowserHistoryAdapter } from '@i18n-micro/preact/router'
import { App } from './App'
import en from './locales/en.json'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English' },
  { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
]
const i18n = createI18n({ locale: 'en', fallbackLocale: 'en', messages: { en } })

render(
  <I18nProvider i18n={i18n} locales={locales} defaultLocale="en" routingStrategy={createBrowserHistoryAdapter(locales, 'en')}>
    <App />
  </I18nProvider>,
  document.getElementById('app')!,
)
```
