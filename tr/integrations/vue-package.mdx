`@i18n-micro/vue`, Nuxt I18n Micro'nun çeviri çekirdeğini içeren bir Vue 3 eklentisidir: reaktif `t()`, global `$t`, dört bileşen ve isteğe bağlı bir vue-router adaptörü. Nuxt ile oluşturulmamış bir Vite veya SSR Vue uygulamasında kullanın. Örnek modeli, router sözleşmesi ve bileşen prop'ları diğer paketlerle ortaktır ve [Framework'ler](/tr/integrations/overview) sayfasında açıklanır.

## Kurulum {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vue
```

```bash npm
npm install @i18n-micro/vue
```

```bash yarn
yarn add @i18n-micro/vue
```

</CodeGroup>

Peer bağımlılıkları: `vue` `^3.3.0`; `vue-router` `^4.5.1 || ^5.0.0` (isteğe bağlı, yalnızca `@i18n-micro/vue/router` için). Yayımlanan tipler `skipLibCheck: false` ile Vue 3.5.5 veya üstünü gerektirir; olağan şablon ayarı olan `skipLibCheck: true` ile eski sürümler de derlenir.

## Yapılandırma {#setup}

```ts
// src/main.ts
import { createApp } from 'vue'
import { createI18n } from '@i18n-micro/vue'
import App from './App.vue'
import en from './locales/en.json'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales: [
    { code: 'en', iso: 'en-US', displayName: 'English' },
    { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
  ],
  defaultLocale: 'en',
})

createApp(App).use(i18n).mount('#app')
```

`useI18n()` için `locales` ve `defaultLocale` zorunludur: bunlar olmadan `I18nLocalesKey not provided` hatası fırlatır. Bunları `createI18n`'e (yukarıdaki gibi), `useI18n({ locales, defaultLocale })`'a veya `app.provide(I18nLocalesKey, …)` ve `app.provide(I18nDefaultLocaleKey, …)` aracılığıyla verin.

Eklenti `I18nT`, `I18nLink`, `I18nGroup` ve `I18nSwitcher` bileşenlerini global olarak kaydeder ve şablonlara `$t`, `$ts`, `$tc`, `$tn`, `$td`, `$tdr`, `$has` ve `$i18n` ekler. Bileşenlerin dışında örnek `i18n.global`'dir. Diğer seçenekler [örnek](/tr/integrations/overview#the-instance) bölümündedir; `routeMessages` Vue'da kullanılamaz, `addRouteTranslations` kullanın.

## Çeviri {#translate}

```vue
<script setup lang="ts">
import { useI18n } from '@i18n-micro/vue'

const { t, tc, tn } = useI18n()
</script>

<template>
  <h1>{{ t('greeting', { name: 'Ada' }) }}</h1>
  <!-- Hello, Ada! -->
  <p>{{ tc('apples', 3) }}</p>
  <!-- 3 apples -->
  <p>{{ $t('nav.home') }} · {{ tn(1234.5) }}</p>
</template>
```

`useI18n()` şunları döndürür: çeviri metotları (`t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`), `locale` (yazılabilir bir computed), `getLocale`, `getLocales`, `defaultLocale()`, `getLocaleName`, `localePath`, `localeRoute`, `switchLocale`, `setRoute`, `getRoute`, `addTranslations`, `addRouteTranslations`, `mergeTranslations`, `resolveTranslations`, `setTranslation`, `clearCache` ve `instance`.

İstediğiniz zaman daha fazla sözlük yükleyin; onları okuyan her bileşen yeniden render edilir:

```ts
const { addTranslations, addRouteTranslations, setRoute } = useI18n()

addTranslations('de', (await import('./locales/de.json')).default)
addRouteTranslations('en', 'about', { title: 'About us' })
setRoute('about') // t('title') now reads the 'about' dictionary first
```

## Locale değiştirme {#switch-locale}

```ts
const { locale, switchLocale } = useI18n()

locale.value = 'de' // only the locale
switchLocale('de') // the locale, then router.push to the localized current path
```

Locale'in sözlüğünü değiştirmeden önce veya sonra yükleyin; değiştirme işlemi hiçbir şey indirmez.

`<I18nGroup>` slot'una önekli bir `t` verir. `<I18nT>` içindeki veya düz bir `t()` içindeki anahtarlara önek eklenmez:

```vue
<I18nGroup prefix="profile" v-slot="{ t }">
  <h2>{{ t('title') }}</h2>
  <!-- profile.title -->
</I18nGroup>
```

## Yönlendirme {#routing}

vue-router adaptörü bir alt yolda bulunur; böylece ana giriş noktası hiçbir zaman `vue-router`'ı import etmez:

```ts
// src/main.ts
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import { createI18n } from '@i18n-micro/vue'
import { createVueRouterAdapter } from '@i18n-micro/vue/router'
import App from './App.vue'
import Home from './pages/Home.vue'
import About from './pages/About.vue'
import en from './locales/en.json'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English' },
  { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
]

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/:locale(de)?', component: Home },
    { path: '/:locale(de)?/about', component: About },
  ],
})

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales,
  defaultLocale: 'en',
  routingStrategy: createVueRouterAdapter(router, locales, 'en'),
})

createApp(App).use(router).use(i18n).mount('#app')
```

`createVueRouterAdapter(router, locales, defaultLocale)` varsayılan olan hariç her locale'e önek ekler (`/about`, `/de/about`) ve `<I18nLink>`'i `RouterLink` olarak render eder. Locale'i route'tan kendiniz okuyun, örneğin `router.beforeEach` içinde, ve `i18n.global.locale.value` değerini ayarlayın. Bir adaptörü daha sonra `i18n.setRoutingStrategy(adapter)` ile de bağlayabilirsiniz; özel bir adaptör için [Router adaptörü](/tr/integrations/overview#router-adapter) bölümüne bakın.

## SSR {#ssr}

- Router'ı, i18n örneğini ve uygulamayı istek başına çalışan render fonksiyonunun içinde oluşturun. Paylaşılan tek bir örnek, bir ziyaretçinin locale'ini başka birine sızdırır.
- Sunucuda `createMemoryHistory()` kullanın, locale'i URL'den alın ve `renderToString` öncesinde onun sözlüğünü (ve fallback'inkini) yükleyin.
- Locale'i istemciye gönderin (örneğin bir `window.__STATE__` script'inde) ve hydration'ın eşleşmesi için istemci örneğini aynı `locale` ile oluşturun.
- `<I18nSwitcher>` yalnızca açılır menü açıkken `window.location` değerini okur, bu nedenle sunucuda render edilir.

`packages/vue/playground` eksiksiz bir `entry-server.ts` / `entry-client.ts` çifti içerir.

## SEO head {#seo-head}

`useLocaleHead(options)`, locale'lerden ve router adaptöründen `lang`/`dir`, canonical, `hreflang` ve `og:locale` etiketlerini oluşturur. Route değiştiğinde `updateMeta()` çağırın ve `metaObject`'i head yöneticinize verin:

```ts
import { watch } from 'vue'
import { useRoute } from 'vue-router'
import { useHead } from '@unhead/vue'
import { useLocaleHead } from '@i18n-micro/vue'

const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
watch(() => route.fullPath, () => updateMeta(), { immediate: true })
useHead(metaObject)
```

Seçenekler: `baseUrl` (dize veya fonksiyon), `addDirAttribute` (varsayılan `true`), `addSeoAttributes` (varsayılan `true`), `identifierAttribute` (varsayılan `'id'`), `hreflangBaseLanguage` (varsayılan `false`). `disabled: true` veya `seo: false` olan locale'ler alternatif bağlantı almaz.
