**Tarih**: 2025-10-30

**Sürüm**: `v2.0.0`

![v2.0.0 release](/images/2.0.0.png)

Geliştirme ortamında çeviri dosyaları için sunucu tarafı HMR'yi sunuyoruz. Bir JSON çevirisi değiştiğinde sunucu önbelleği yalnızca etkilenen anahtarları geçersiz kılar ve sonraki istekler hemen güncel verileri alır; yeniden başlatma gerekmez.

## Neler Yeni? {#what’s-new}

- Çeviri dosyaları için sunucu tarafı HMR
- Sayfa/yerel ayar başına anında önbellek geçersiz kılma
- İçerik düzenlerken kesintisiz geliştirici deneyimi

## Nasıl çalışır {#how-it-works}

- `src/runtime/server/plugins/watcher.dev.ts` içindeki izleyici `<rootDir>/<translationDir>/**/*.json` dosyalarını gözlemler
- Sayfa dosyaları (ör. `pages/<page>/<locale>.json`) `_locales:merged:<page>:<locale>` anahtarını geçersiz kılar
- Kök düzeyindeki dosyalar (ör. `<locale>.json`) o yerel ayara ait tüm birleştirilmiş anahtarları geçersiz kılar
- `experimental.hmr !== false` olduğunda geliştirme ortamında `src/module.ts` üzerinden otomatik olarak kaydedilir

## Yapılandırma {#configuration}

```ts
export default defineNuxtConfig({
  i18n: {
    experimental: { hmr: true }, // default in dev
  },
})
```
