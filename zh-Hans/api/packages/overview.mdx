# 包 API

`nuxt-i18n-micro` 由一组小型包组成，其中大多数都可以独立使用 —— `@i18n-micro/vue` 可用于普通 Vue 应用，`@i18n-micro/core` 可用于任何地方。

下面每一页都由 [`pnpm run api:surface`](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/maintenance-commands.md#api-surface) 校验 TypeScript 源码所使用的 API 快照生成，因此某项导出如果消失，要么这份参考随之更新，要么 CI 会失败。
