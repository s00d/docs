# 包 API

`nuxt-i18n-micro` 由一组小型包组成,其中大多数都可以独立使用 ——
`@i18n-micro/vue` 可在纯 Vue 应用中使用,`@i18n-micro/core` 可在任何地方使用。

下方每个页面都由 API 快照生成,并由
[`pnpm run api:surface`](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/maintenance-commands.md#api-surface) 对 TypeScript 源码进行校验;
因此,任何导出的消失都会导致本参考页更新,或者 CI 失败。
