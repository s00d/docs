# useI18nLocale

## 签名

{/* generated:symbol:useI18nLocale — do not edit; run `pnpm run docs:generate` */}

```ts
useI18nLocale(): { getEffectiveLocale: (route: unknown, getLocaleFromRoute: GetLocaleFromRoute) => string; getLocale: () => string | null; getLocaleWithServerFallback: (serverLocale?: string | null) => string | null; getPreferredLocale: () => string | null; hashCookie: any; isValidLocale: (locale: string | null | undefined) => locale is string; locale: any; localeCookie: any; resolveInitialLocale: (options: ResolveInitialLocaleOptions) => string; setLocale: (locale: string | null) => void; syncLocale: (locale: string | null) => void; validLocales: string[] }
```

i18n 语言管理的统一入口。
整合了 useState('i18n-locale')、语言 Cookie 与同步工具。

{/* /generated:symbol:useI18nLocale */}

## 用法

```vue
<script setup>
const {
  locale,
  localeCookie,
  hashCookie,
  validLocales,
  getPreferredLocale,
  getLocale,
  getLocaleWithServerFallback,
  getEffectiveLocale,
  resolveInitialLocale,
  setLocale,
  syncLocale,
  isValidLocale,
} = useI18nLocale()

// Set locale (updates state and cookies)
setLocale('de')

// Get current locale (state → cookie)
const current = getLocale()

// Get valid preferred locale
const preferred = getPreferredLocale()
</script>
```

## API

| 属性/方法                                 | 类型                                | 说明                                                                          |
| ----------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| `locale`                                        | `Ref<string \| null>`               | 响应式语言状态(`useState('i18n-locale')`)                                    |
| `localeCookie`                                  | `Ref`                               | 语言 Cookie(启用 `localeCookie` 选项时)                                |
| `hashCookie`                                    | `Ref`                               | 启用 `hashMode` 时使用的 Cookie                                                |
| `validLocales`                                  | `string[]`                          | 模块配置中启用的语言代码(排除 `disabled`)                        |
| `getLocale()`                                   | `() => string \| null`              | 当前语言:state → Cookie(hash 模式下为 hash cookie)                         |
| `getPreferredLocale()`                          | `() => string \| null`              | 从 state/Cookie 获取并**校验**是否在 `validLocales` 中的语言;否则为 `null`             |
| `getLocaleWithServerFallback(serverLocale?)`    | `(serverLocale?) => string \| null` | state → Cookie → 可选的服务端上下文(用于 `no_prefix` 初始化)              |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string`             | 用于加载翻译的语言:hash 模式下优先使用 state;否则从 route 读取 |
| `resolveInitialLocale(options)`                 | `(options) => string`               | 解析语言:state → `serverLocale` → route;并按需同步 state             |
| `setLocale(locale)`                             | `(locale: string \| null) => void`  | 设置语言并同步到 Cookie                                                       |
| `syncLocale(locale)`                            | `(locale: string \| null) => void`  | 仅同步 Cookie(不更新 state)                                                  |
| `isValidLocale(locale)`                         | `(locale) => boolean`               | 检查字符串是否在 `validLocales` 中                                                |

### `resolveInitialLocale` 选项

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

主插件在启动时会在内部使用它。自定义插件在实现替代的检测流程时可以调用。

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

返回用于加载翻译并为给定 route 对象格式化消息的语言。

## 以编程方式设置语言

请优先使用 `useI18nLocale()`,而不是直接使用 `useState('i18n-locale')`:

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
`setLocale()` 只更新语言偏好(state + Cookie)。若还需要在客户端重新加载活动的翻译上下文,请使用 `useNuxtApp()` 或 `useI18n()` 提供的 `$switchLocale()`。这在 `no_prefix` 下尤为重要,因为 URL 不会变化。参见 [FAQ —— 在不改变 URL 的情况下切换语言](/guides/faq#-switch-locale-without-changing-the-url)。
</Tip>
