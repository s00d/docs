# 🛠️ `useI18n` 组合式函数

`Nuxt I18n Micro` 中的 `useI18n` 组合式函数让你可以在组件与脚本中访问大多数运行时 i18n 辅助方法。方法**同时提供带 `$` 前缀与不带前缀的形式**(例如 `$t` 与 `t`)。

某些注入 —— `$defineI18nRoute` 与 `$clearCache` —— 仅在 `useNuxtApp()` 上可用。参见[方法 —— `$defineI18nRoute`](/api/methods#definei18nroute) 与 [`$clearCache`](/api/methods#clearcache)。

## 📊 返回值

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

以普通对象的形式返回所有运行时辅助方法。

即插件注入为 `$t`、`$tc` 等的相同函数,在这里既能通过带美元前缀的名称访问,也能通过其裸别名访问 ——
所以 `const \{ t \} = useI18n()` 与 `const \{ $t \} = useI18n()` 都可用。

**返回值** —— 在[方法参考](/api/methods)中所描述的辅助方法

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

它返回的每个辅助方法 —— `$t`、`$tc`、`$has`、`$switchLocale` 等 —— 都在[方法参考](/api/methods)中列出了签名并有详细说明。

## 仅 `useNuxtApp()` 可用的 API

以下方法**不会**由 `useI18n()` 返回。请从 `useNuxtApp()` 引入:

| 方法                     | 用途                                                                         |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | 在 `script setup` 中配置按页面的语言路由、限制以及内联翻译 |
| `$clearCache()`            | 清空内存中的翻译缓存与已加载的分块                            |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

完整签名与示例请参见[方法](/api/methods)。

## 🛠️ 使用示例

### 基础的语言获取

获取应用当前的语言。

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### 带参数的翻译

翻译带有动态参数的字符串,并提供默认回退值。

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### 切换语言

将应用切换到另一种语言。

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### 生成本地化路由

生成本地化到当前或指定语言的路由。

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
