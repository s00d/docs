# 🛠️ `useI18n` 组合式函数

`Nuxt I18n Micro` 中的 `useI18n` 组合式函数为组件和脚本提供大多数运行时 i18n 辅助函数的访问。这些方法可以**带 `$` 前缀或不带 `$` 前缀**使用（例如 `$t` 和 `t`）。

部分注入 —— `$defineI18nRoute` 与 `$clearCache` —— 只能通过 `useNuxtApp()` 获取。参见 [方法 —— `$defineI18nRoute`](/api/methods#definei18nroute) 与 [`$clearCache`](/api/methods#clearcache)。

## 📊 返回内容

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

每个运行时辅助函数，以普通对象形式返回。

这些函数与插件注入的 `$t`、`$tc` 等相同，同时以带美元符号的名称和裸别名提供，因此 `const \{ t \} = useI18n()` 和 `const \{ $t \} = useI18n()` 都可以使用。

**返回值** —— [方法参考](/api/methods) 中描述的辅助函数

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

它返回的每个辅助函数 —— `$t`、`$tc`、`$has`、`$switchLocale` 等 —— 都在[方法参考](/api/methods)中列出了签名并做了完整说明。

## 仅通过 `useNuxtApp()` 提供的 API

以下 API **不会**被 `useI18n()` 返回。请从 `useNuxtApp()` 中获取：

| 方法                     | 用途                                                                         |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | 在 `script setup` 中按页面配置语言路由、限制和内联翻译 |
| `$clearCache()`            | 清空内存中的翻译缓存和已加载 chunk                            |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

完整签名与示例请参见[方法](/api/methods)。

## 🛠️ 使用示例

### 基础的语言获取

获取当前应用的语言。

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### 带参数的翻译

翻译带有动态参数的字符串，并提供默认回退值。

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### 切换语言

将应用切换到另一种语言。

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### 生成本地化路由

生成一个本地化到当前或指定语言的路由。

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
