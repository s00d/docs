# 🌍 `useLocaleHead` 组合式函数

`useLocaleHead` 是 `Nuxt I18n Micro` 中的一个工具组合式函数,用于为本地化路由管理 SEO 属性与 HTML 元标签。它会动态生成 HTML 文档的 `lang` 与 `dir` 属性,并创建 `meta` 与 `link` 标签,以改进本地化内容的 SEO。

当前路由的 SEO head 标签:为每种语言生成 `hreflang` 备用与 `x-default`,

只有在 `meta` 被禁用或需要调整默认行为时才需要;当 `meta: true` 时,
模块会自己注册相同的标签。

## 🛠️ 返回值

`useLocaleHead` 会返回一个响应式对象和一个更新函数,在数据源变化时应调用后者。两者的类型形状在上面的签名中生成自源码。

### `metaObject`

响应式的 head 载荷(html 属性、meta、link),可直接用于 `useHead(metaObject)`。

- **示例**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

根据当前 route、语言与配置重新计算 `metaObject`。当输入变化时(例如 route 变化)请调用它。

- **示例**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### 访问 `link` 与 `meta`

`link` 与 `meta` 数组可通过 `metaObject.value` 访问:

- **示例**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ 使用示例

### 基础用法

使用默认选项生成按语言的 head 属性。

```js
const head = useLocaleHead()
```

### 自定义标识属性

为生成的标签使用自定义标识属性。

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### 禁用 SEO 属性

只生成 head 属性,而不添加 SEO 相关的 meta 与 link 标签。

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### 指定基础 URL

为 canonical 与备用 URL 设置自定义基础 URL。

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 更多特性

### SEO 元标签与链接

启用 `addSeoAttributes` 时,组合式函数会自动生成以下标签:

- 当前语言的 `og:locale`(`language_TERRITORY`,下划线)。由 `locale.og` 派生,或在可能时由 `locale.iso` 转换而来。
- 页面 canonical URL 的 `og:url`。
- 各备用语言版本的 `og:locale:alternate`。
- 用于 SEO 优化的 `rel="canonical"` 与 `rel="alternate"` 链接。
- 指向默认语言 URL 的 `hreflang="x-default"` 链接。这告诉搜索引擎:当用户语言与所有已定义语言都不匹配时应显示哪个 URL。

### 动态语言与方向

组合式函数会根据当前 route 的语言动态确定 `lang` 与 `dir` 属性,从而确保你的 HTML 文档为国际用户正确配置。

### 处理本地化路由

如果你的路由带有语言前缀(例如 `/en/about`),组合式函数会智能地调整完整路径以生成 URL,确保 SEO 属性准确且相关。

该组合式函数简化了为国际受众优化 Nuxt 应用的过程,让你的站点更好地面向全球搜索引擎与用户。

## 🛠️ 使用示例

以下示例展示了如何在 Vue 组件中使用 `useLocaleHead` 组合式函数(默认设置):

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### 代码说明

- **`useLocaleHead` 组合式函数**:在 `<script setup>` 中调用,返回一个包含 `htmlAttrs`、`meta`、`link` 的对象。

- **`<html>` 标签**:HTML 文档的 `lang` 与 `dir` 属性会根据当前语言动态确定,并应用到 `<html>` 上。

- **`<head>` 部分**:
  - **Meta 标签**:生成 SEO 相关的元标签,包括 `og:locale`、`og:url`,以及 `rel="canonical"` 和 `rel="alternate"`,用于指明各备用语言版本。
  - **Link 标签**:包括 canonical 链接、各备用语言版本的链接,以及指向默认语言 URL 的 `hreflang="x-default"` 链接。

- **`<body>` 部分**:此处显示页面主体内容。示例中使用了简单的标题与段落。

### 📝 注意事项

1. **属性**:所用属性(`lang`、`dir`、`rel`、`href`、`hreflang`、`property`、`content`)均取自 `useLocaleHead` 返回的对象。

2. **SEO 标签生成**:若将 `addSeoAttributes` 设为 `true`,组合式函数会自动为当前语言生成 SEO 标签。

3. **基础 URL**:你可以通过 `baseUrl` 选项设置自定义基础 URL,以正确生成 canonical 与备用链接。

该示例演示了如何轻松地将 `useLocaleHead` 集成到应用组件中,确保正确的 SEO 属性并改进本地化页面的搜索引擎索引。

## 🧩 定制与生命周期

- `useLocaleHead` 不会自行订阅变化。它返回 `metaObject` 与 `updateMeta`。
- 当输入变化时(通常是 route 变化时),应调用 `updateMeta()`,例如在插件中:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## 何时改用 `useI18nHead`

当 `meta: true`(默认)时,若需要对**页面级**内容进行覆盖(自定义 hreflang、额外的 `og:title`、部分禁用),请优先使用 [`useI18nHead`](/api/composables/use-i18n-head)。只有在 `meta: false` 或你自行管理 `useHead` 时,才直接使用 `useLocaleHead`。
