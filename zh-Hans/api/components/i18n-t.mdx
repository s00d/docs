# 🌍 `<i18n-t>` 组件

`Nuxt I18n Micro` 中的 `<i18n-t>` 组件是一个灵活的翻译组件,支持通过插槽动态插入内容。你可以用自定义的 Vue 组件或 HTML 内容对翻译进行插值,以实现更高级的本地化场景。

## ⚙️ Props

| Prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `keypath` **\*** | `string` | — | 要渲染的翻译键。 |
| `plural` | `number \| string` | — | 用于选择复数形式的数量。设置后使用 `$tc` 而非 `$t`。 |
| `tag` | `string` | `'span'` | 要渲染的元素。 |
| `params` | `Record<string, string \| number \| boolean>` | `() => (\{\})` | 插入到翻译中的插值。 |
| `defaultValue` | `string` | `''` | 当 `hideIfEmpty` 使空翻译被抑制时,渲染的替代内容。 |
| `html` | `boolean` | `false` | 将翻译作为 HTML 而非文本渲染。仅用于你能控制的内容。 |
| `hideIfEmpty` | `boolean` | `false` | 当翻译解析为空字符串时不渲染任何内容。 |
| `customPluralRule` | `PluralFunc` | `null` | 仅对该元素生效的复数规则,会覆盖已配置的规则。 |
| `number` | `number \| string` | — | 通过 `$tn` 格式化值,并以 `\{number\}` 传给翻译。 |
| `date` | `Date \| string \| number` | — | 通过 `$td` 格式化值,并以 `\{date\}` 传给翻译。 |
| `relativeDate` | `Date \| string \| number` | — | 通过 `$tdr` 格式化值,并以 `\{relativeDate\}` 传给翻译。 |

**\*** 必填。

{/* /generated:component:i18n-t */}

`plural`、`number`、`date` 与 `relativeDate` 一次只能生效一个;若同时设置多个,以上列表中靠前的优先。

### 按 prop 分类的示例

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

## 🛠️ 使用示例

### 基础用法

```vue
<i18n-t keypath="feedback.text" />
```

这会在 `<span>` 内渲染 `feedback.text` 对应的翻译。

### 使用插槽承载动态内容

`<i18n-t>` 组件支持通过插槽将 Vue 组件或其他内容动态插入到翻译的特定位置。

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

此示例中,`feedback.text` 翻译字符串中的 `\{link\}` 占位符会被 `<nuxt-link>` 组件替换,而该 `<nuxt-link>` 内部又包含另一个翻译组件。

### 复数处理

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

这会根据 `itemCount` 的值自动应用复数规则。

## 🚀 更多特性

### 默认插槽

如果未提供具体插槽,可以通过默认插槽自定义翻译内容,该插槽会提供整个已翻译字符串:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### 条件渲染

使用 `hideIfEmpty` prop,当翻译字符串为空时不渲染任何内容。

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### 自定义复数规则

使用自定义函数处理复数。

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### 使用插槽的进阶示例

利用插槽定制翻译内容的渲染方式。

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
