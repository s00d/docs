# 🌍 `<i18n-link>` 组件

`Nuxt I18n Micro` 中的 `<i18n-link>` 组件是一个通用的链接组件,可基于当前语言自动本地化路由。它是 `<NuxtLink>` 的包装组件,并额外提供激活链接样式与外部链接支持等功能。

## ⚙️ Props

| Prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | 目标 route。会自动本地化;若为外部 URL,则原样传递。 |
| `activeStyle` | `Partial<CSSStyleValue>` | — | 当链接指向当前 route 时应用的内联样式。 |

**\*** 必填。

### 插槽

| 插槽 | 绑定 | 说明 |
| --- | --- | --- |
| `default` | — | 链接内容。 |

{/* /generated:component:i18n-link */}

`to` 接受与 `NuxtLink` 相同的形式 —— 路径、命名 route,或已解析的 route 对象。
若识别为绝对 URL,会渲染为普通的 `<a target="_blank" rel="noopener noreferrer">`,而不会做本地化处理。

## 🛠️ 使用示例

### 基础用法

```vue
<i18n-link to="/about">About Us</i18n-link>
```

该示例创建了一个指向 `/about` 页面的链接,并本地化到当前语言。

### 使用内联样式的激活样式

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

当用户位于 `/about` 页面时,该链接会以粗体显示,便于你通过内联样式直接为激活链接设置样式。

### 外部链接处理

组件会自动检测外部链接,并添加必要的安全属性。

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

该链接会在新标签页打开 `https://example.com`,并应用 `rel="noopener noreferrer"`。

## 🎨 样式

组件的激活态现在使用内联样式,而不是 CSS 类。你可以通过 `activeStyle` prop 自定义这些样式。

### 默认激活样式

- **字重**:`bold`
- **颜色**:继承浏览器默认颜色(若未在 `activeStyle` 中指定 `color`)。

你可以通过 `activeStyle` prop 提供自定义样式覆盖默认值。

### 自定义激活样式

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

此示例中,链接在激活时显示为粗体绿色。

## 🚀 更多特性

### 通过插槽自定义内容

你可以通过插槽在链接内传入自定义内容,让组件适配不同场景。

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### 无障碍增强

组件支持 `aria-label` 及其他无障碍属性,以提供更佳的可访问体验。

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
