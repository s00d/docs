# 🌍 `<i18n-switcher>` 组件

`Nuxt I18n Micro` 中的 `<i18n-switcher>` 组件提供了一个用户友好的下拉界面,用于在应用的不同语言之间切换。该组件高度可定制,能够无缝融入你的应用设计与布局。

`disabled: true` 的语言会从下拉菜单中**排除**(它们仍可通过 `$getLocales()` 用于 SEO / head 标签)。只有可切换的语言才会获得 `NuxtLink` 与 `hreflang`。

各个部分默认没有样式:`custom*Style` prop 接受内联样式对象,当样式不足以满足需求时,下方的插槽可以完全替换其标记结构。

## 🛠️ 使用示例

### 基础用法

```vue
<template>
  <i18n-switcher />
</template>
```

这会渲染出一个使用默认样式与行为的语言切换器。

### 自定义标签与内联样式

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

该示例演示了一个带自定义标签与内联样式的完全定制的语言切换器。

## 🔌 插槽

切换器中所有视觉部分都可被替换。插槽在上面的 props 表格中列出;每个插槽接受模板内容:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

名称以 `-item`、`-link-content` 结尾或以 `before-item` 开头的插槽,会接收所属的 `locale` 对象。

## 🎨 样式概览

`<i18n-switcher>` 组件通过内联样式定义了基础样式,你可以通过 props 传入自定义样式来轻松覆盖。以下是默认样式的简要说明:

- **Wrapper**:控制下拉菜单的定位。
- **Button**:切换下拉的按钮样式。
- **Dropdown**:下拉列表的样式。
- **Items**:列表中每个条目的样式。
- **Links**:每个条目内链接的样式。
- **Icon**:下拉指示图标的样式。

你可以通过相应的 props 传入自定义样式,让语言切换器无缝融入应用 UI。
