## 服务器中间件

服务器处理器使用专用的中间件（而不是客户端 `$t` 辅助函数）：

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) —— 在 API 路由和服务器处理器中进行翻译
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) —— 读取检测到的语言与元数据

设置说明、语言检测优先级与示例请参考完整的[服务器端翻译指南](/guides/server-side-translations)。
