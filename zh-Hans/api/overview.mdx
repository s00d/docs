# API 参考

## 服务端中间件

服务端处理器使用专用的中间件(而非客户端的 `$t` 辅助函数):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) —— 在 API 路由与服务端处理器中进行翻译
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) —— 读取检测到的语言及其元数据

关于配置、语言检测优先级与示例,请参见完整的[服务端翻译指南](/guides/server-side-translations)。
