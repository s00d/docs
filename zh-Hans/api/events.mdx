title: "钩子"
description: "i18n:register 运行时钩子：在加载和导航时从 Nuxt 插件添加翻译。"
---

模块会调用一个运行时（应用）钩子：`i18n:register`。当某个插件或模块需要添加不在 `locales/` 文件中的翻译时使用它。你的回调会收到一个 `register` 函数，用于将翻译合并到当前正在显示的页面中。

## `i18n:register` {#i18nregister}

```ts
'i18n:register': (
  register: (translations: unknown, locale?: string) => void,
  locale: string,
) => HookResult
```

| 参数 | 说明 |
| --- | --- |
| `register(translations, locale?)` | 将 `translations` 深度合并到正在加载的路由的页面块中，作用于 `locale`（默认：钩子的 `locale`）。已存在的键会被覆盖。 |
| `locale` | 正在加载的路由的 locale。 |

该钩子通过 `RuntimeNuxtHooks` 进行类型声明，因此 `nuxtApp.hook('i18n:register', …)` 无需类型转换。

## 触发时机 {#when-it-fires}

加载器插件（`i18n-plugin-loader`）会在以下时机调用它：

1. 启动时调用一次：在所有插件运行完毕后（`app:created`）、应用渲染之前；
2. 在其 `router.beforeEach` 中，当路径变化且目标页面的翻译加载完成后调用——在 `no_prefix` 下每次导航都会调用。

在应用渲染或导航继续之前，每个回调和每次 `register` 调用都会被 await，因此页面渲染时已包含合并后的键。设置 [`hooks: false`](/zh-Hans/api/module-options#hooks) 时，该钩子永远不会被调用。

## 示例 {#example}

```ts
// plugins/i18n-extra.ts
export default defineNuxtPlugin((nuxtApp) => {
  nuxtApp.hook('i18n:register', async (register, locale) => {
    const extra = await $fetch<Record<string, unknown>>(`/api/cms-strings/${locale}`)
    register(extra, locale)
  })
})
```

这是一个运行时钩子：请在插件中通过 `nuxtApp.hook` 注册，而不是在 `nuxt.config` 或模块的 `setup` 中通过 `nuxt.hook` 注册。模块可以通过 `addPlugin` 添加这样的插件。
