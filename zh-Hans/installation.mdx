## 环境要求

- **Node.js**:18 或更高版本。
- **Nuxt**:3.x 或 4.x。

本模块同时支持 Nuxt 3 项目布局(`pages/**/*.vue`)和 Nuxt 4 布局(`app/pages/**/*.vue`)。按照约定,翻译文件放在项目根目录(`locales/`),即使使用 Nuxt 4 的 `app/` 目录也是如此。

## 安装 Nuxt 模块

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

在 `nuxt.config.ts` 中注册模块:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

完整流程请参见[快速开始](/quickstart),所有可用选项请参见[配置参考](/guides/configuration)。

## 项目布局

默认情况下,本模块期望的目录结构为:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

根级文件会在构建时合并到每个页面级文件中。在 `nuxt dev` 期间,缺失的页面级文件会被自动创建。

## Nuxt 4 布局

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

如需将翻译共置在 `app/` 下,请设置 `translationDir: 'app/locales'`。

## 生态包

| 包 | 用途 |
| --- | --- |
| [`@i18n-micro/vue`](/integrations/vue) | Vue 3 集成(独立使用,不依赖 Nuxt)。 |
| [`@i18n-micro/react`](/integrations/react) | React 集成。 |
| [`@i18n-micro/preact`](/integrations/preact) | Preact 集成。 |
| [`@i18n-micro/solid`](/integrations/solid) | SolidJS 集成。 |
| [`@i18n-micro/astro`](/integrations/astro) | Astro 集成。 |
| [`@i18n-micro/node`](/integrations/nodejs) | Node.js 服务端加载器。 |
| [`@i18n-micro/types-generator`](/integrations/types-generator) | 从翻译文件生成 TypeScript 类型。 |
| [`@i18n-micro/devtools-ui`](/integrations/devtools-ui) | 与框架无关的 DevTools 面板。 |

共享的内部包会通过传递依赖自动引入。

## TypeScript

本模块会根据默认语言文件为 `useI18n`、`$t` 及相关辅助函数生成环境类型(ambient types)。此功能默认开启(`types: true`)。

如需为翻译键提供更强的类型支持,请参见 [`@i18n-micro/types-generator`](/integrations/types-generator)。
