本页将 `@nuxtjs/i18n` 应用对应到 nuxt-i18n-micro：选项、辅助方法和文件布局。在现有应用中替换模块时可以参考它。你的 URL 保持不变（策略名称相同），翻译则迁移到按页面划分的 JSON 文件中。

<Tip>

**要升级 nuxt-i18n-micro 本身？** — 参见[升级指南](/zh-Hans/guide/upgrade)。

</Tip>

## 替换模块 {#swap-the-module}

```bash
npm uninstall @nuxtjs/i18n
npm install nuxt-i18n-micro
```

```ts
// nuxt.config.ts — before
export default defineNuxtConfig({
  modules: ['@nuxtjs/i18n'],
  i18n: {
    locales: [
      { code: 'en', language: 'en-US', file: 'en.json' },
      { code: 'de', language: 'de-DE', file: 'de.json' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    langDir: 'locales',
    detectBrowserLanguage: { useCookie: true, cookieKey: 'i18n_redirected', redirectOn: 'root' },
  },
})
```

```ts
// nuxt.config.ts — after
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    translationDir: 'locales',
    localeCookie: 'i18n_redirected',
    autoDetectPath: '/',
  },
})
```

## 选项 {#options}

| `@nuxtjs/i18n` | nuxt-i18n-micro |
| --- | --- |
| `locales[].code` | `locales[].code` |
| `locales[].language`（v9 之前为 `iso`） | `locales[].iso` |
| `locales[].name` | `locales[].displayName` |
| `locales[].dir` | `locales[].dir` |
| `locales[].domain` | `locales[].baseUrl`（带 scheme 的源） |
| `locales[].domainDefault` | `locales[].baseDefault` |
| `differentDomains`, `multiDomainLocales` | 不需要：仅 `baseUrl` 即可按主机路由，参见[层与域名](/zh-Hans/guide/layers#multiple-domains) |
| `locales[].file` / `files`, `langDir`, `lazy` | `translationDir`；文件按名称查找，并始终按页面加载 |
| `defaultLocale`, `strategy` | 名称相同，四个取值也相同 |
| `baseUrl` | `metaBaseUrl` |
| `customRoutes: 'config'` + `pages` | `globalLocaleRoutes` |
| `detectBrowserLanguage: false` | `redirects: false`（不重定向）或 `autoDetectLanguage: false`（忽略请求头） |
| `detectBrowserLanguage.useCookie` / `cookieKey` | `localeCookie: '<name>'`（`null` 关闭 cookie） |
| `detectBrowserLanguage.redirectOn: 'root'` | `autoDetectPath: '/'`（默认） |
| `detectBrowserLanguage.redirectOn: 'no prefix'` | `autoDetectPath: 'no_prefix'` |
| `detectBrowserLanguage.redirectOn: 'all'` | `autoDetectPath: '*'` |
| `vueI18n` 配置文件（`fallbackLocale`、`numberFormats`、`datetimeFormats`） | `i18n` 中的 `fallbackLocale`、`numberFormats`、`datetimeFormats` |

没有 `alwaysRedirect`：设置了 cookie 后，每次访问 `/` 都会遵循它。完整列表见[模块选项](/zh-Hans/api/module-options)；检测规则见 [Locale 检测](/zh-Hans/guide/locale-detection)。

## 辅助方法与组合式函数 {#helpers-and-composables}

| `@nuxtjs/i18n` / vue-i18n | nuxt-i18n-micro（模板 / `useI18n()`） |
| --- | --- |
| `const { t } = useI18n()` | `const { t } = useI18n()`，模板中使用 `$t` |
| `t('key', count)`, `tc` | `$tc('key', count)` |
| `te('key')` | `$has('key')` |
| `n(value, 'currency')`, `d(date, 'short')` | `$tn(value, 'currency')`, `$td(date, 'short')` |
| — | `$tdr(date)`：相对时间（"in 3 days"） |
| `locale.value` | `$getLocale()` |
| `locales.value` | `$getLocales()` |
| `setLocale('de')` | `$switchLocale('de')` |
| `useLocalePath()('about')` | `$localePath({ name: 'about' })` |
| `useLocaleRoute()` | `$localeRoute()` |
| `useSwitchLocalePath()('de')` | `$switchLocalePath('de')` |
| `useSetI18nParams()` | `$setI18nRouteParams()` |
| `useLocaleHead()` | 在 `meta: true` 时自动处理；自定义 head 请使用 [`useLocaleHead`](/zh-Hans/composables/useLocaleHead) |
| `defineI18nRoute({ paths: { de: '/ueber-uns' }, locales: [...] })` | `$defineI18nRoute({ localeRoutes: { de: '/ueber-uns' }, locales: [...] })` |
| `<NuxtLinkLocale to="about">` | `<i18n-link :to="{ name: 'about' }">` |
| `<i18n-t>` | `<i18n-t>`（插槽填充 `{name}` 占位符） |
| 服务端路由中的 `$i18n` | `useTranslationServerMiddleware(event)`，参见[服务端路由与 API](/zh-Hans/guide/server-side-translations) |

`useI18n()` 会自动导入。`$defineI18nRoute` 必须保留 `$`：构建过程会读取这个调用。所有辅助方法：[方法](/zh-Hans/api/methods)。

## 翻译文件 {#translation-files}

把每个 locale 一个大文件中的键，拆分为一个根文件加上每个页面一个文件：

```text
locales/
├── en.json              # keys used on many pages (nav, footer)
├── de.json
└── pages/
    ├── index/en.json    # keys of pages/index.vue
    └── about/en.json    # keys of pages/about.vue
```

把所有内容都保留在根文件中也可以，这是最快的第一步。在拆分之前请设置 `disablePageLocales: true`。参见[翻译文件](/zh-Hans/guide/translations)。

### 消息语法 {#message-syntax}

| vue-i18n | nuxt-i18n-micro |
| --- | --- |
| `{name}` 具名插值 | 相同 |
| `car \| cars`（2 个形式：1 → 第一个） | 形式按数量从 0 开始选取：写成 `no cars \| one car \| {count} cars` |
| `@:other.key` 链接消息 | 不支持：重复文本或在代码中组合 |
| `@.upper:` 修饰符 | 不支持：在代码中格式化或使用 `<i18n-t>` |
| `{'@'}` 字面量转义 | 不需要：只有 `{word}` 形式的标记会被替换 |
| JS/TS 消息文件 | 仅支持 JSON |

复数规则可以通过 [`plural`](/zh-Hans/api/module-options#plural) 选项替换。

## 切换后检查 {#check-after-the-switch}

- 你原有的每个 URL 仍然可以解析；策略名称一致，自定义路径迁移到 `globalLocaleRoutes` 或 `$defineI18nRoute`。
- 在 `meta: true` 时，`hreflang`、canonical 和 `og:locale` 开箱即用；请删除手写的这些标签。
- JSON 解析错误会记录文件路径；在开发环境中，缺失的键会在浏览器控制台中输出警告。
