---
title: "排除路径"
description: "使用 excludePatterns 让页面和文件不参与 locale 路由，并了解哪些路径已默认被排除。"
---

有些路径绝不能带 locale 前缀，也不能被 locale 重定向：管理后台、健康检查、生成的订阅源。`excludePatterns` 用于标记它们，并且内置列表已经覆盖了 Nuxt 内部路径和常见静态文件。被排除的页面会严格保持你编写的路径，并且仍然可以使用 `$t` 渲染。

## 排除一个路径 {#exclude-a-path}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    excludePatterns: [
      '/admin', // /admin and everything below it
      '/preview-*', // glob over the whole path
    ],
  },
})
```

使用此配置后，`pages/admin/index.vue` 只响应 `/admin`；不存在 `/de/admin`，并且 `/admin` 永远不会被重定向到 `/de/admin`。

## 模式语法 {#pattern-syntax}

模式会与不含 `app.baseURL` 的路径进行匹配：

| 模式 | 匹配 | 不匹配 |
| --- | --- | --- |
| `'/admin'` | `/admin`, `/admin/users` | `/administrator`, `/de/admin` |
| `'/preview-*'` | `/preview-1`, `/preview-a/b` | `/de/preview-1` |
| `'/file-?'` | `/file-a` | `/file-ab` |
| `/^\/v\d+\//` | `/v2/docs` | `/docs` |

不含 `*` 或 `?` 的字符串会匹配该路径及其下方的完整路径段。含有 `*`（任意长度的字符，包括斜杠）或 `?`（单个字符）时，必须匹配整个路径。字符串应始终以 `/` 开头。

## 已默认排除的内容 {#what-is-excluded-already}

以下路径无需任何配置，永远不会生成 locale 路由或重定向：

- `/api` 和 `/_nuxt` 及其下方的所有路径；
- 翻译路由，默认为 `/_locales`（[`apiBaseUrl`](/zh-Hans/api/module-options#apibaseurl)）；
- 任何包含以 `__` 开头的路径段的路径（`/__nuxt_content`、`/en/__og-image__`）；
- `/sitemap*.xml`、`/robots.txt`、`/favicon.ico`、`/apple-touch-icon*.png`、`/manifest.json`、`/sw.js`、`/workbox-*.js`；
- 最后一个路径段以静态文件扩展名结尾的任何路径：`xml txt ico json js css png jpg jpeg gif svg webp avif pdf wasm map mp4 webm mp3 zip gz woff woff2 ttf eot`。像 `/user/john.doe` 这样带点的页面 slug 以及 `.html` 路径仍然是页面。

## 排除的作用 {#what-an-exclusion-does}

- **路由：** 不会生成本地化变体；页面保持原样。
- **重定向和 404：** 服务端重定向插件和客户端重定向中间件会跳过该路径。
- **预渲染：** 匹配的路径会从预渲染路由列表中移除。

它不会阻止 i18n 服务端中间件为请求检测 locale，也不会阻止页面使用翻译。若要让页面保持本地化但不输出 SEO 标签，请使用 `disableMeta`（[页面配置](/zh-Hans/guide/per-component-translations#turn-off-seo-tags)）。若要在 `nuxt.config.ts` 中按路径让某个页面不进行本地化，`globalLocaleRoutes: { '/admin': false }`（[本地化路径](/zh-Hans/guide/custom-locale-routes#in-nuxt-config)）在路由方面可以达到相同效果。
