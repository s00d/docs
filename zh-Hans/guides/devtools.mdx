# 🛠️ `nuxt-i18n-micro` 中的 DevTools

## Vue DevTools(浏览器扩展)

在开发环境下,本模块可通过 `@vue/devtools-api` 注册一个 **Vue DevTools** 自定义检查器与时间线。这与下方的 Nuxt DevTools 标签相互独立。

| 工具 | 最适合的场景 |
|------|----------|
| **Vue DevTools** | 实时语言、内存中的翻译缓存、`$t` 时间线(`debug: true`)、缺失键事件 |
| **Nuxt DevTools 标签** | 编辑磁盘上的 JSON 文件、配置总览、导入/导出 |

vue-devtools 插件仅在 `nuxt dev` 期间注册(生产构建中不会注册)。主插件中的开发期桥接状态会被 `import.meta.dev` 的死代码消除清理掉。

在保留 Nuxt 标签的同时禁用浏览器集成:

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

详细的 `$t` 时间线事件需要设置 `debug: true`。

## 📖 什么是 Nuxt DevTools?

DevTools 是一款强大的开发助手,已无缝集成到 `nuxt-i18n-micro` 模块中。它提供了直观的界面用于管理本地化和翻译任务,让你的工作流程更快、更高效。Nuxt DevTools 为注重便利性的开发者而生,弥合了编码与运行时管理之间的差距。

## 🌟 `nuxt-i18n-micro` 中 DevTools 的核心特性

### 1. **语言管理**

在你的应用中轻松浏览、选择并管理各种语言。无论是单语言还是多语言项目,DevTools 都提供了一个集中化的界面来处理所有本地化设置。

### 2. **翻译编辑**

通过内置的 JSON 编辑器直接编辑翻译文件。这样无需借助外部工具即可实现实时更新与修改,不会打断你的工作流。

### 3. **文件导入与导出**

简化翻译文件的管理流程:

- **导出**:将翻译保存为 JSON 文件,便于备份或外部使用。
- **导入**:将更新后的翻译文件加载到项目中,使内容保持最新。

### 4. **实时预览**

在开发环境中立即查看更改。此功能可确保翻译和配置在上线前是准确的。

### 5. **无缝集成 Nuxt**

DevTools 与 `nuxt-i18n-micro` 原生协作,无需额外设置即可增强其能力。它可以适配你的本地化需求,同时保持 Nuxt 的模块化与灵活结构。

## 🛠️ 为何使用 DevTools?

对于需要本地化的项目,Nuxt DevTools 是不可或缺的补充。它可帮助开发者:

- **节省时间**:自动化文件管理、格式校验等重复性工作。
- **减少错误**:提供安全、直观的翻译编辑环境。
- **提升协作**:让非开发人员也能轻松管理翻译。
- **精简工作流**:将多项本地化任务整合到单一界面中。

---

## 🚀 掌控本地化

将 Nuxt DevTools 集成到 `nuxt-i18n-micro` 后,管理多语言应用会变得简单而高效。无论是精调翻译还是新增语言,DevTools 都能为你提供交付精致、易用体验所需的工具。
