- **[CLI](https://github.com/s00d/nuxt-i18n-micro/tree/main/scripts/src/commands/performance.ts)**: `pnpm -C scripts cli performance` / `pnpm test:performance`

### 说明

在一份共享词典配置下,对比 **plain Nuxt**(未启用 i18n 模块的基线)、**i18n-micro** 以及 **`@nuxtjs/i18n` v10.6**。

关注重点:构建时间、峰值 RSS、可部署的**代码 vs 翻译 vs 总体积**,以及在 Artillery + Autocannon 下的服务端表现。

### 方法学说明

- 指标为**每个 fixture 连续 3 次运行的平均值**(先跑 fixture A ×3,再 B ×3,再 C ×3——不交错运行)。
- **翻译**包含 `locales/` / `_locales/` / `translations/` 下的语言 JSON,以及 `chunks/raw/` 下的全部内容和对应的语言分块。较早的报告将 `@nuxtjs/i18n` 的“translations: 0 B”与庞大的“code”列并存,是因为把消息分块当作了应用代码。
- **plain-nuxt** 使用与静态 `public/translations` JSON 等同体量的资源(而非静态 JS 引入)。在 Artillery 下,该基线的 I/O 开销较大;这并非“i18n 开销”,而是每次请求获取大量 JSON 的代价。

### 运行

以下所有指标均为**3 次运行的平均值**。

### Fixture 配置

| 参数 | 值 |
|------|-------|
| Locales | **4**(`en`、`de`、`ru`、`fr`) |
| Pages | **2**(`index`、`page`) |
| Index tree | 深度 **5**,分支 **7** → 每种语言 **16,807** 个叶子键 |
| Secondary pages | 深度 **5**,分支 **6** → 每个页面每种语言 **7,776** 个叶子键 |
| 目标 | 默认 CLI 配置(`--locales 4 --keys 10000`);回归雷达负载可调高 |

词典来自 `test/fixtures/perf-shared/runtime.json`(由 CLI 生成),以确保三个 fixture 保持一致。

## test/fixtures/plain-nuxt 的构建性能

- **构建时间**:5.32 秒
- **打包体积**:8.33 MB(code:1.53 MB,translations:6.8 MB)

- **最大 / 平均 CPU**:207.10% / 166.29%
- **最大 / 平均内存**:810.26 MB / 585.14 MB
