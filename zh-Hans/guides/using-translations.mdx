# 在组件中使用翻译

模块安装并配置好后，你就可以在 Vue 模板和脚本中通过 `$t('your_key')` 展示翻译。

## 1. 根级与页面级翻译文件

1. **根级** 翻译位于 `/locales` 目录下（例如 `/locales/en.json`、`/locales/fr.json`）。在构建期，它们会自动合并进每个页面级文件，从而在所有页面可用。
2. **页面级** 翻译位于 `/locales/pages/...`，与你的 Nuxt pages 目录结构对应：

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. 在模板中使用 `$t`

在 `.vue` 文件的模板中可以直接使用 `$t`：

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
如果键指向嵌套的 JSON 节点（例如 `$t('header')` → `\{ title: "Hi" \}`），`$t` 可能返回**对象**。在模板中这会渲染为 `[object Object]`。若需要保证返回字符串，请使用 `$ts`，或使用更具体的键如 `$t('header.title')`。详见 [API 参考 —— $t 与 $ts](/api/methods#t)。
</Tip>

## 3. 切换当前语言

要在应用中切换语言，可以从 `useI18n()` 获取 `$locale`，或使用 `$switchLocale`：

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. 嵌套键与占位符

- **嵌套键**使用点号，例如 `nested.key.deeper`。
- **占位符**用于插入动态值：
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. 提示与最佳实践

- **键冲突**：如果页面级文件包含与根级文件相同的键，页面级版本优先（根级翻译在构建期作为基础合并进来）。
- **禁用页面级文件**：如果不希望使用页面级翻译，可以在 Nuxt 配置中设置 `disablePageLocales: true`。这样只会使用 `/locales/*.json` 文件。
- **无需直接导入**：不需要 `import \{ useI18n \} from 'nuxt-i18n-micro'`；模块的自动注入功能会自行处理。

就是这样！只需以上步骤，你就可以从根级或页面级 JSON 文件中**获取翻译**，并在 Nuxt 应用中通过 `$t` **展示**它们。
