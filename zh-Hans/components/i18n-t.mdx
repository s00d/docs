---
title: "<i18n-t>"
description: "<i18n-t> 组件渲染一条翻译，支持复数形式、数字与日期格式化、HTML 以及插槽插值。"
---

`<i18n-t>` 将一条翻译渲染到一个元素中。当翻译内部需要组件（句子中的链接）、复数形式，或格式化后的数字或日期时，就可以使用它。它会像 `$t` 一样针对当前路由解析键。

## Props {#props}

| Prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `keypath` **\*** | `string` | — | 要渲染的翻译键。 |
| `plural` | `number \| string \| null` | — | 用于选择复数形式的数量。设置后会使用 `$tc` 而不是 `$t`。`null` 表示未设置。 |
| `tag` | `string` | `'span'` | 要渲染的元素。 |
| `params` | `Record<string, string \| number \| boolean>` | — | 替换到翻译中的插值。 |
| `defaultValue` | `string` | `''` | 当 `hideIfEmpty` 屏蔽了空翻译时，代替组件渲染的内容。 |
| `html` | `boolean` | `false` | 将翻译渲染为 HTML 而不是文本。仅用于你能控制的翻译：`params` 会被转义，翻译本身不会。 |
| `hideIfEmpty` | `boolean` | `false` | 当翻译解析为空字符串时不渲染任何内容。 |
| `customPluralRule` | `PluralFunc` | `null` | 仅用于此元素的复数规则，覆盖已配置的规则。其返回值原样使用；`null` 渲染为空。 |
| `number` | `number \| string \| null` | — | 用 `$tn` 格式化该值，并以 `{number}` 与 `params` 一起传给翻译。 |
| `date` | `Date \| string \| number \| null` | — | 用 `$td` 格式化该值，并以 `{date}` 与 `params` 一起传给翻译。 |
| `relativeDate` | `Date \| string \| number \| null` | — | 用 `$tdr` 格式化该值，并以 `{relativeDate}` 与 `params` 一起传给翻译。 |

**\*** 必填。

## 渲染规则 {#rendering-rules}

第一个匹配的情况决定输出：

1. `number` — 使用 `{ ...params, number: $tn(number) }` 的翻译。
2. `date` — 使用 `{ ...params, date: $td(date) }` 的翻译。
3. `relativeDate` — 使用 `{ ...params, relativeDate: $tdr(relativeDate) }` 的翻译。
4. `plural` — `$tc` 选中的形式（包括 [`=0 ` 标记](/zh-Hans/api/methods#$tc)），使用 `{ ...params, count }`；若设置了 `customPluralRule`，则使用 `customPluralRule(keypath, count, params, locale, t)`，它读取包含标记在内的原始值，其返回值原样使用，`null` 即为空。
5. 否则使用带 `params` 的翻译。

`null` 视为未设置。在所有情况下：

- 在每个分支中，`defaultValue` 都会替代缺失的键。
- `hideIfEmpty` 会渲染 `defaultValue` 而不是空白结果。
- `html` 将结果渲染为 HTML。`params` 会被转义，翻译本身不会；插槽会被忽略。
- `default` 插槽接收 `{ translation }`，具名插槽会被忽略。
- 否则，每个具名插槽会替换所有 `{name}` 占位符，优先于同名 param。看起来像占位符的 param 值仍保留为文本。

`date` 和 `relativeDate` 的输出带有 `data-allow-mismatch="text"`，因为服务器的时区和时钟与浏览器不同。设置 [`timeZone`](/zh-Hans/api/module-options#timezone) 可以在两端渲染相同的日历日期；`relativeDate` 依赖时钟，因此仍可能不同。

## 示例 {#example}

```json
{
  "terms": "I accept the {link}.",
  "termsLink": "terms of use",
  "items": "no items | one item | {count} items"
}
```

```vue
<template>
  <i18n-t keypath="terms" tag="p">
    <template #link>
      <NuxtLink :to="$localePath('/terms')">{{ $t('termsLink') }}</NuxtLink>
    </template>
  </i18n-t>

  <i18n-t keypath="items" :plural="cart.length" />
</template>
```

`html` 会设置 `innerHTML`：只对你能控制的翻译使用它。`params` 会被转义，因此用户数据放在那里是安全的，找不到翻译的键也同样安全。
