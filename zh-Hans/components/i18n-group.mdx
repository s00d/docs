---
title: "<i18n-group>"
description: "<i18n-group> 组件为其插槽提供一个限定在某个键前缀下的 t 函数。"
---

`<i18n-group>` 将一块标记限定在一个键前缀下。当某个区块中的许多键共享同一前缀、而你不想重复书写它时，就可以使用它。默认插槽会收到一个自动添加前缀的 `t`。

## Props 与插槽 {#props-and-slot}

| Prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | 插槽内每次查找所基于的键前缀。 |
| `groupClass` | `string` | `''` | 包裹元素上的额外 class。 |

**\*** 必填。

### 插槽 {#slots}

| 插槽 | 绑定 | 说明 |
| --- | --- | --- |
| `default` | `prefix`, `t` | 接收 `prefix` 以及限定在该前缀下的 `t` 函数。 |

## 行为 {#behaviour}

- 在插槽外层渲染 `<div class="i18n-group {groupClass}">`。
- `t(key, params)` 等同于针对当前路由的 `$t(prefix + '.' + key, params)`。
- 只有插槽的 `t` 受前缀限定：组内的 `$t` 和嵌套的 `<i18n-t>` 仍需使用完整的键。

## 示例 {#example}

```json
{
  "checkout": { "title": "Checkout", "items": "Items: {count}" }
}
```

```vue
<template>
  <i18n-group prefix="checkout" group-class="checkout">
    <template #default="{ t }">
      <h2>{{ t('title') }}</h2>
      <p>{{ t('items', { count: 3 }) }}</p>
    </template>
  </i18n-group>
</template>
```
