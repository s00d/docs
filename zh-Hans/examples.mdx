# 📚 Nuxt I18n Micro 示例与用法

本节提供多种示例,演示如何在 Nuxt.js 应用中使用 `Nuxt I18n Micro`。你将看到如何切换语言,如何使用 `<i18n-link>`、`<i18n-switcher>` 和 `<i18n-t>` 组件,以及如何动态处理翻译键。

## 🛠️ 基础设置

以下是使用 `Nuxt I18n Micro` 的基础配置:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 语言切换

### 以编程方式切换语言

以下示例演示如何通过按钮以编程方式切换语言:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### 语言切换的示例 JSON

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### 使用 `<i18n-switcher>` 组件

`<i18n-switcher>` 组件提供了一个用于切换语言的下拉框,并支持自定义标签:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 📝 从翻译文件中渲染动态键

在某些场景下,你可能希望遍历翻译文件中存储的动态键,并有条件地渲染其对应的值。下面的示例演示如何使用 `Nuxt I18n Micro` 实现这一点。

### 示例:渲染动态键

该示例从指定的翻译路径(此处为 `dynamic`)获取键数组并进行遍历。在使用 `$t` 渲染每个键的值之前,先通过 `$has` 检查该键是否存在。

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### 示例翻译文件(`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### 示例:从对象中渲染动态键

在这个示例中,我们处理翻译文件中存储的一个对象。我们获取并遍历该对象的键,动态渲染键名及其对应的值。

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### 示例翻译文件(`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 使用 `<i18n-t>` 结合插槽与插值进行翻译

`<i18n-t>` 组件适用于渲染含动态内容和 HTML 标签的翻译:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### `<i18n-t>` 的示例 JSON

```json
{
  "greeting": "Welcome to the page"
}
```

### 带插值

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### 插值的示例 JSON

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 使用 `$tc` 进行复数处理

`Nuxt I18n Micro` 中的 `$tc` 函数会根据数量以及语言设置处理复数形式。这对于动态调整涉及数量的消息(例如条目数、通知数或其他可变数量的实体)非常有用。

### 示例:使用 `$tc` 进行复数处理

在以下示例中,我们使用 `$tc` 显示描述苹果数量的消息。翻译键会根据提供的数量处理多种复数形式。

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### 复数处理的示例 JSON

可以在 JSON 文件中按如下方式定义翻译以处理不同的复数形式:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### 说明

- **`$tc('apples', 0)`**:返回第一种形式,数量为零时使用(`"no apples"`)。
- **`$tc('apples', 1)`**:返回第二种形式,数量为一时使用(`"one apple"`)。
- **`$tc('apples', 10)`**:返回带数量值的第三种形式,数量大于等于二时使用(`"10 apples"`)。

### 更复杂的复数处理示例

如果你的应用需要处理更复杂的复数规则(例如针对 zero、one、two、few、many、other 的特殊情形),可以相应扩展翻译字符串:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**:可设置为返回 `"two apples"`。
- **`$tc('apples', 3)`**:可根据为该数量定义的规则返回 `"a few apples"`。

## 🌐 使用 `$tn` 进行数字格式化

`$tn` 函数使用 `Intl.NumberFormat` API 按当前语言格式化数字。这对于按用户地区设置显示数字(例如货币、百分比或其他数字格式)非常有用。

### 示例:使用 `$tn` 进行数字格式化

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ 使用 `$td` 进行日期与时间格式化

`$td` 函数使用 `Intl.DateTimeFormat` API 按当前语言格式化日期与时间。这对于按用户的语言设置以其熟悉的格式显示日期与时间非常有用。

### 示例:使用 `$td` 进行日期与时间格式化

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ 使用 `$tdr` 进行相对日期格式化

`$tdr` 函数使用 `Intl.RelativeTimeFormat` API 按当前语言将日期格式化为相对时间(例如 "5 minutes ago"、"2 days ago")。这对于显示相对于当前日期与时间的时间差非常有用。

### 示例:使用 `$tdr` 进行相对日期格式化

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
