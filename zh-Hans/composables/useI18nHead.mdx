---
title: "useI18nHead"
description: "useI18nHead 为单个页面覆盖生成的 i18n SEO 标签：替换或删除 canonical、hreflang 和 og 标签，或添加你自己的标签。"
---

`useI18nHead()` 修改模块生成的 SEO 标签，且仅作用于单个页面。当页面比路由器了解得更多时使用它：只存在于部分语言中的 CMS 文章、来自 API 的 canonical URL、额外的 `og:` 标签。你会得到生成的标签，并在其上合并你的覆盖项。

## 签名 {#signature}

```ts
useI18nHead(input?: MaybeRefOrGetter<I18nHeadInput | null>): { pageHead: any; resetPageHead: () => void }
```

为 i18n SEO head 标签注册页面级覆盖。
由 `02.meta` 插件合并到 `useLocaleHead` 输出之上。

当值来自 `$t` / `t` 时，优先使用 getter（`() => ({ … })`），这样它们会在语言切换时重新解析。普通对象只求值一次，之后保持不变。

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| `input` *（可选）* | `MaybeRefOrGetter<I18nHeadInput \| null>` |  |

它与 [`meta: true`](/zh-Hans/api/module-options#meta)（默认值）配合使用：模块的 meta 插件会在每次渲染 head 时，将输入合并到 [`useLocaleHead`](/zh-Hans/composables/useLocaleHead) 的输出之上。当 `meta: false` 时，没有任何东西会读取它。

路由名称变化时覆盖项会被重置。设置了 `disableMeta` 的页面不会获得任何 i18n 标签，覆盖项也包括在内。

## 输入 {#input}

`I18nHeadInput`（来自 `@i18n-micro/types`）：

| 键 | 类型 | 作用 |
| --- | --- | --- |
| `htmlAttrs` | `Record<string, string>` | 合并到 `<html>` 属性中（`lang`、`dir`）。 |
| `meta` | `I18nHeadMeta[]` | 添加在生成的标签之后；替换具有相同 `id`、`property` 或 `name` 的标签。 |
| `link` | `I18nHeadLink[]` | 添加在生成的链接之后；替换具有相同 `id`，或相同 `rel` + `hreflang` 的链接。 |
| `replace.canonical` | `string \| false` | 替换 canonical 的 `href`，或移除该链接。 |
| `replace.hreflang` | `I18nHeadLink[] \| false` | 替换或移除**所有** `rel="alternate"` 链接，包括 `x-default`。 |
| `replace.xDefault` | `I18nHeadLink \| false` | 替换或移除 `x-default` 链接。 |
| `replace.ogLocale` | `string \| false` | 替换或移除 `og:locale`。 |
| `replace.ogUrl` | `string \| false` | 替换或移除 `og:url`。 |
| `replace.ogAlternates` | `string[] \| false` | 根据这些语言代码（通过 `og` / `iso`）重建 `og:locale:alternate`，跳过当前语言、未知代码以及没有 `og` 或 `iso` 值的代码；或将其移除。 |
| `disable` | `I18nHeadDisableGroup[]` | 删除生成的分组：`'hreflang'`（不含 `x-default`）、`'x-default'`、`'canonical'`、`'og'`（`og:locale` + `og:url`）、`'og-alternates'`、`'html'`。 |

应用顺序：先 `disable`，然后 `replace`，再然后 `htmlAttrs`、`meta`、`link`。

## 示例 {#example}

一篇只存在于部分语言中的文章，其备用 URL 来自 API：

```vue
<script setup lang="ts">
const route = useRoute()
const { t } = useI18n()
const { data: article } = await useFetch<{ title: string; urls: Record<string, string> }>(`/api/articles/${route.params.slug}`)

useI18nHead(() => {
  if (!article.value) return null
  const codes = Object.keys(article.value.urls)
  return {
    meta: [{ property: 'og:title', content: article.value.title || t('blog.title') }],
    replace: {
      hreflang: codes.map((code) => ({ rel: 'alternate', hreflang: code, href: article.value!.urls[code]! })),
      ogAlternates: codes,
    },
  }
})
</script>
```

当值来自 `t()` 或异步数据时，像这里一样传入 getter：它会在语言切换时重新运行。普通对象只读取一次。
