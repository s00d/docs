**日期**：2025-10-30

**版本**：`v2.0.0`

![v2.0.0 release](/images/2.0.0.png)

我们在开发环境中为翻译文件引入了服务端 HMR。当某个 JSON 翻译文件发生变化时，服务端缓存只会使受影响的键失效，后续请求会立即拿到最新数据，无需重启。

## 有哪些新内容？ {#what’s-new}

- 翻译文件的服务端 HMR
- 按页面/locale 即时失效缓存
- 编辑内容时流畅的开发体验

## 工作原理 {#how-it-works}

- `src/runtime/server/plugins/watcher.dev.ts` 中的监听器会监视 `<rootDir>/<translationDir>/**/*.json`
- 页面文件（例如 `pages/<page>/<locale>.json`）会使 `_locales:merged:<page>:<locale>` 失效
- 根级文件（例如 `<locale>.json`）会使该 locale 的所有合并键失效
- 当 `experimental.hmr !== false` 时，在开发环境中由 `src/module.ts` 自动注册

## 配置 {#configuration}

```ts
export default defineNuxtConfig({
  i18n: {
    experimental: { hmr: true }, // default in dev
  },
})
```
