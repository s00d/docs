**日期**：2025-12-07

**版本**：`v2.14.1`

![v2.14 发布](/images/2.14.0.png)

我们很高兴地宣布 **v2.14.1** 发布，全新推出面向 Node.js、Vue 3 和 Astro 的集成！这些包将同样强大的 i18n 能力带到你喜爱的框架中，并共享相同的核心逻辑，以保证一致性和性能。

## 新功能 {#what’s-new}

- **@i18n-micro/node** - 在任意 Node.js 应用、CLI 工具或后端服务中使用 i18n 翻译
- **@i18n-micro/vue** - 用于国际化的 Vue 3 插件，支持响应式翻译和路由级翻译
- **@i18n-micro/astro** - 用于国际化的 Astro 集成，提供完整的 TypeScript 支持
- **@i18n-micro/types-generator** - 为翻译键自动生成 TypeScript 类型，提供完整的类型安全和 IDE 自动补全

## 主要特性 {#key-features}

所有集成都具备相同的核心优势：

- 轻量且高性能
- 支持路由级翻译
- 内置复数处理
- 数字、日期和相对时间格式化
- 完整的 TypeScript 支持
- 相同的 JSON 翻译文件结构

**Types Generator** 还进一步提升了开发体验：

- 从 JSON 翻译文件自动生成类型
- 类型安全的翻译键，支持编译时校验
- 完整的 IDE 自动补全支持
- 翻译文件变更时热重载
- 零运行时开销

如需详细文档和示例，请访问[仓库](https://github.com/s00d/nuxt-i18n-micro)或查看[文档](https://s00d.github.io/nuxt-i18n-micro/)。
