## المتطلبات

- **Node.js**: 18 أو أحدث.
- **Nuxt**: 3.x أو 4.x.

تدعم الوحدة كلاً من تخطيط مشروع Nuxt 3 (`pages/**/*.vue`) وتخطيط Nuxt 4 (`app/pages/**/*.vue`). تُوضَع الترجمات في جذر المشروع بحكم الاتفاق (`locales/`)، حتى عند استخدام مجلد `app/` الخاص بـ Nuxt 4.

## تثبيت وحدة Nuxt

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

سجّلها في `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

اطّلع على [البدء السريع](/quickstart) للحصول على شرح كامل أو [مرجع الإعدادات](/guides/configuration) لكل الخيارات.

## تخطيط المشروع

تتوقع الوحدة افتراضيًا:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

تُدمج ملفات المستوى الجذر في كل ملف خاص بالصفحة أثناء البناء. تُنشأ الملفات الخاصة بالصفحات تلقائيًا عند غيابها أثناء `nuxt dev`.

## تخطيط Nuxt 4

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

لوضع الترجمات جنبًا إلى جنب داخل `app/`، اضبط `translationDir: 'app/locales'`.

## TypeScript

تولّد الوحدة أنواعًا محيطة لـ `useI18n` و`$t` والدوال المساعدة ذات الصلة استنادًا إلى ملفات اللغة الافتراضية لديك. هذا الأمر مُفعَّل افتراضيًا (`types: true`).

للحصول على كتابة أقوى لمفاتيح الترجمة، انظر [`@i18n-micro/types-generator`](/integrations/types-generator).
