## المتطلبات

- **Node.js**: 18 أو أحدث.
- **Nuxt**: 3.x أو 4.x.

تدعم الوحدة كلا التخطيطين، تخطيط مشروع Nuxt 3 (`pages/**/*.vue`) وتخطيط Nuxt 4 (`app/pages/**/*.vue`). توضع الترجمات في جذر المشروع حسب الاتفاقية (`locales/`)، حتى عند استخدام مجلد `app/` الخاص بـ Nuxt 4.

## تثبيت وحدة Nuxt

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

سجّلها في `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

راجع [البدء السريع](/quickstart) للحصول على شرح كامل أو [مرجع التكوين](/guides/configuration) لكل خيار.

## تخطيط المشروع

افتراضياً، تتوقّع الوحدة:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

تُدمج الملفات الجذرية في كل ملف خاص بصفحة في وقت البناء. تُنشأ الملفات الخاصة بالصفحات تلقائياً عند غيابها أثناء `nuxt dev`.

## تخطيط Nuxt 4

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

لوضع الترجمات ضمن `app/`، اضبط `translationDir: 'app/locales'`.

## TypeScript

تولّد الوحدة أنواعاً ضمنية لـ `useI18n` و `$t` والمساعدات المرتبطة استناداً إلى ملفات لغتك الافتراضية. هذا مفعّل بشكل افتراضي (`types: true`).

للحصول على كتابة أنواع أقوى لمفاتيح الترجمة، راجع [`@i18n-micro/types-generator`](/integrations/types-generator).
