# 📚 أمثلة واستخدام Nuxt I18n Micro

يقدّم هذا القسم أمثلة متنوعة توضّح كيفية استخدام `Nuxt I18n Micro` في تطبيق Nuxt.js الخاص بك. ستتعرّف على كيفية تبديل اللغات، واستخدام مكوّنات `<i18n-link>` و `<i18n-switcher>` و `<i18n-t>`، والتعامل مع مفاتيح الترجمة ديناميكياً.

## 🛠️ الإعداد الأساسي

إليك إعداداً أساسياً للبدء مع `Nuxt I18n Micro`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 تبديل اللغات

### تبديل اللغات برمجياً

يوضّح هذا المثال كيفية تبديل اللغات برمجياً باستخدام الأزرار:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### مثال JSON لتبديل اللغة

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### استخدام مكوّن `<i18n-switcher>`

يوفّر مكوّن `<i18n-switcher>` قائمة منسدلة لتبديل اللغة مع تسميات قابلة للتخصيص:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 🌐 استخدام `<i18n-link>` للتنقل المحلي


## 📝 عرض المفاتيح الديناميكية من ملفات الترجمة

في بعض السيناريوهات، قد ترغب في التكرار عبر مفاتيح ديناميكية مخزّنة داخل ملفات الترجمة الخاصة بك وعرض قيمها بشكل شرطي. يوضّح المثال أدناه كيفية تحقيق ذلك باستخدام `Nuxt I18n Micro`.

### مثال: عرض المفاتيح الديناميكية

يجلب هذا المثال مصفوفة من المفاتيح من مسار ترجمة محدد (في هذه الحالة، `dynamic`) ويكرّر عبرها. يُتحقق من وجود كل مفتاح باستخدام `$has` قبل عرض قيمته باستخدام `$t`.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### مثال ملف الترجمة (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### مثال: عرض المفاتيح الديناميكية من كائن

في هذا المثال، نتعامل مع كائن مخزّن داخل ملف الترجمة الخاص بك. نجلب مفاتيح الكائن ونكرّر عبرها، ونعرض ديناميكياً أسماء المفاتيح والقيم المرتبطة بها.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### مثال ملف الترجمة (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 استخدام `<i18n-t>` للترجمات مع الفتحات والاستكمال

يكون مكوّن `<i18n-t>` مفيداً لعرض الترجمات مع محتوى ديناميكي ووسوم HTML:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### مثال JSON لـ `<i18n-t>`

```json
{
  "greeting": "Welcome to the page"
}
```

### مع الاستكمال

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### مثال JSON للاستكمال

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 استخدام `$tc` للتعامل مع الجموع

تتعامل الدالة `$tc` في `Nuxt I18n Micro` مع صيغ الجمع بناءً على العدد وإعدادات اللغة. هذا مفيد لتعديل الرسائل ديناميكياً التي تتضمّن أعداداً، مثل العناصر أو الإشعارات أو غيرها من الكيانات التي يمكن أن تختلف في العدد.

### مثال: استخدام `$tc` للتعامل مع الجموع

في المثال التالي، نعرض رسالة تشير إلى عدد التفاح باستخدام `$tc`. يتعامل مفتاح الترجمة مع صيغ جمع متعددة بناءً على العدد المُقدَّم.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### مثال JSON للجموع

فيما يلي كيفية تعريف الترجمة في ملف JSON للتعامل مع صيغ الجمع المختلفة:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### الشرح

- **`$tc('apples', 0)`**: تُرجع الصيغة الأولى، تُستخدم عندما يكون العدد صفراً (`"no apples"`).
- **`$tc('apples', 1)`**: تُرجع الصيغة الثانية، تُستخدم عندما يكون العدد واحداً (`"one apple"`).
- **`$tc('apples', 10)`**: تُرجع الصيغة الثالثة مع قيمة العدد، تُستخدم عندما يكون العدد اثنين أو أكثر (`"10 apples"`).

### مثال إضافي مع قواعد جمع أكثر تعقيداً

إذا كان تطبيقك يحتاج إلى التعامل مع قواعد جمع أكثر تعقيداً (مثلاً حالات محددة للصفر والواحد والاثنين والقليل والكثير وغيرها)، يمكنك توسيع سلاسل الترجمة وفقاً لذلك:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: يمكن إعدادها لتعيد `"two apples"`.
- **`$tc('apples', 3)`**: يمكن أن تعيد `"a few apples"`، اعتماداً على القواعد المحدّدة للعدد.

## 🌐 استخدام `$tn` لتنسيق الأرقام

تنسّق الدالة `$tn` الأرقام وفقاً للغة الحالية باستخدام واجهة `Intl.NumberFormat`. هذا مفيد لعرض الأرقام بطريقة تتوافق مع الإعدادات الإقليمية للمستخدم، مثل العملة أو النسب المئوية أو صيغ الأرقام الأخرى.

### مثال: استخدام `$tn` لتنسيق الأرقام

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ استخدام `$td` لتنسيق التاريخ والوقت

تنسّق الدالة `$td` التواريخ والأوقات وفقاً للغة الحالية باستخدام واجهة `Intl.DateTimeFormat`. هذا مفيد لعرض التواريخ والأوقات بصيغ مألوفة للمستخدم بناءً على إعدادات لغته.

### مثال: استخدام `$td` لتنسيق التاريخ والوقت

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ استخدام `$tdr` لتنسيق التواريخ النسبية

تنسّق الدالة `$tdr` التواريخ كأوقات نسبية (مثل "5 minutes ago" أو "2 days ago") وفقاً للغة الحالية باستخدام واجهة `Intl.RelativeTimeFormat`. هذا مفيد لعرض فروق الوقت النسبية للتاريخ والوقت الحاليين.

### مثال: استخدام `$tdr` لتنسيق التواريخ النسبية

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
