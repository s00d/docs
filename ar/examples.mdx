# 📚 أمثلة استخدام Nuxt I18n Micro

يقدّم هذا القسم أمثلة متنوعة توضّح كيفية استخدام `Nuxt I18n Micro` في تطبيق Nuxt.js الخاص بك. سترى كيفية تبديل اللغات، واستخدام مكوّنات `<i18n-link>` و`<i18n-switcher>` و`<i18n-t>`، والتعامل مع مفاتيح الترجمة بشكل ديناميكي.

## 🛠️ الإعداد الأساسي

هذا إعداد أساسي للبدء مع `Nuxt I18n Micro`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 تبديل اللغة

### تبديل اللغات برمجيًا

يوضّح هذا المثال كيفية تبديل اللغات برمجيًا باستخدام الأزرار:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### مثال JSON لتبديل اللغة

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### استخدام مكوّن `<i18n-switcher>`

يوفّر مكوّن `<i18n-switcher>` قائمة منسدلة لتبديل اللغات مع تسميات قابلة للتخصيص:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 🌐 استخدام `<i18n-link>` للتنقل المحلَّى

يعالج مكوّن `<i18n-link>` تلقائيًا التوجيه الخاص بكل لغة:

```vue
<template>
  <div>
    <i18n-link to="/about">{{ $t('about') }}</i18n-link>
    <i18n-link :to="{ name: 'index' }">{{ $t('home') }}</i18n-link>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### مثال JSON لروابط التنقل

```json
{
  "about": "About Us",
  "home": "Home"
}
```

### مثال بتنسيق الرابط النشط

```vue
<template>
  <div>
    <i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
  </div>
</template>
```

### مثال JSON لتنسيق الرابط النشط

يمكن استخدام نفس ملف JSON كما في المثال السابق لهذا السيناريو.

## 📝 عرض المفاتيح الديناميكية من ملفات الترجمة

في بعض السيناريوهات، قد ترغب في المرور عبر المفاتيح الديناميكية المخزنة داخل ملفات الترجمة وعرض قيمها بشكل مشروط. يوضّح المثال أدناه كيفية تحقيق ذلك باستخدام `Nuxt I18n Micro`.

### مثال: عرض المفاتيح الديناميكية

يجلب هذا المثال مصفوفة من المفاتيح من مسار ترجمة محدّد (في هذه الحالة، `dynamic`) ويمرّ عليها. يتم التحقق من وجود كل مفتاح باستخدام `$has` قبل عرض قيمته باستخدام `$t`.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### مثال ملف الترجمة (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### مثال: عرض المفاتيح الديناميكية من كائن

في هذا المثال، نتعامل مع كائن مخزّن داخل ملف الترجمة الخاص بك. نجلب مفاتيح الكائن ونمرّ عليها، فنعرض ديناميكيًا أسماء المفاتيح والقيم المرتبطة بها.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### مثال ملف الترجمة (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 استخدام `<i18n-t>` للترجمات مع الفتحات والاستيفاء

مكوّن `<i18n-t>` مفيد لعرض الترجمات مع محتوى ديناميكي ووسوم HTML:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### مثال JSON لـ `<i18n-t>`

```json
{
  "greeting": "Welcome to the page"
}
```

### مع الاستيفاء

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### مثال JSON للاستيفاء

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 استخدام `$tc` للتصريف بالعدد

تعالج دالة `$tc` في `Nuxt I18n Micro` التصريف بالعدد بناءً على العدد وإعدادات اللغة. هذا مفيد لضبط الرسائل التي تتضمّن أعدادًا بشكل ديناميكي، مثل العناصر أو الإشعارات أو أي كيانات قد يختلف عددها.

### مثال: استخدام `$tc` للتصريف بالعدد

في المثال التالي، نعرض رسالة تشير إلى عدد التفاح باستخدام `$tc`. يتعامل مفتاح الترجمة مع أشكال جمع متعددة بناءً على العدد المُقدَّم.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### مثال JSON للتصريف بالعدد

فيما يلي كيفية تعريف الترجمة في ملف JSON الخاص بك لمعالجة أشكال الجمع المختلفة:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### الشرح

- **`$tc('apples', 0)`**: يعيد الشكل الأول، يُستخدم عندما يكون العدد صفرًا (`"no apples"`).
- **`$tc('apples', 1)`**: يعيد الشكل الثاني، يُستخدم عندما يكون العدد واحدًا (`"one apple"`).
- **`$tc('apples', 10)`**: يعيد الشكل الثالث بقيمة العدد، يُستخدم عندما يكون العدد اثنين أو أكثر (`"10 apples"`).

### مثال إضافي مع تصريف أكثر تعقيدًا

إذا كان تطبيقك يحتاج إلى معالجة قواعد تصريف أكثر تعقيدًا (مثل حالات محدّدة للصفر، الواحد، الاثنين، القليل، الكثير، الأخرى)، فيمكنك توسيع سلاسل الترجمة وفقًا لذلك:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: يمكن إعداده لإرجاع `"two apples"`.
- **`$tc('apples', 3)`**: يمكن أن يعيد `"a few apples"`، اعتمادًا على القواعد المحدّدة للعدد.

## 🌐 استخدام `$tn` لتنسيق الأرقام

تعمل دالة `$tn` على تنسيق الأرقام وفقًا للغة الحالية باستخدام واجهة `Intl.NumberFormat`. هذا مفيد لعرض الأرقام بطريقة تطابق الإعدادات الإقليمية للمستخدم، مثل العملة أو النسب المئوية أو تنسيقات الأرقام الأخرى.

### مثال: استخدام `$tn` لتنسيق الأرقام

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ استخدام `$td` لتنسيق التاريخ والوقت

تعمل دالة `$td` على تنسيق التواريخ والأوقات وفقًا للغة الحالية باستخدام واجهة `Intl.DateTimeFormat`. هذا مفيد لعرض التواريخ والأوقات بتنسيقات مألوفة للمستخدم بناءً على إعدادات لغته.

### مثال: استخدام `$td` لتنسيق التاريخ والوقت

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ استخدام `$tdr` لتنسيق التاريخ النسبي

تعمل دالة `$tdr` على تنسيق التواريخ كأوقات نسبية (مثل: "منذ 5 دقائق"، "منذ يومين") وفقًا للغة الحالية باستخدام واجهة `Intl.RelativeTimeFormat`. هذا مفيد لعرض الفروقات الزمنية بالنسبة للتاريخ والوقت الحاليين.

### مثال: استخدام `$tdr` لتنسيق التاريخ النسبي

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
