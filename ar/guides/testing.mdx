# 🧪 اختبار وحدة `Nuxt I18n Micro`

## 📖 مقدمة عن الاختبار

يُعد اختبار وحدة `Nuxt I18n Micro` أمرًا بالغ الأهمية لضمان عمل ميزات التوطين في تطبيقك كما هو متوقّع. سيرشدك هذا التوثيق خلال إعداد بيئة الاختبار، وإنشاء تهيئات وهمية لـ vitest، وكتابة اختبارات لمكوّناتك. للحصول على مثال عملي، يمكنك الرجوع إلى [مثال المشروع على GitHub](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/test-utils/example).

اطّلع على [اختبار استراتيجيات التوجيه](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/testing-strategies.md) لمعرفة كيفية تشغيل هذا المستودع لأطقم اختباراته الخاصة — مشاريع Vitest للـ `unit` / `integration` / `e2e`، وملفات كل استراتيجية (`test/strategies-*.test.ts`)، وتوليد الانحدارات.

## 🛠️ إعداد بيئة الاختبار

### 1. تثبيت `@i18n-micro/test-utils`

أولًا، تحتاج إلى تثبيت أدوات الاختبار الخاصة بـ `Nuxt I18n Micro`. توفّر هذه الحزمة الأدوات اللازمة لمحاكاة واختبار تهيئات i18n لديك.

```bash
npm install @i18n-micro/test-utils --save-dev
```

### 2. إنشاء ملف تهيئة وهمي

بعد ذلك، أنشئ ملفًا لإعداد تهيئة i18n الوهمية. سيُستخدم هذا الملف لمحاكاة دوال وأدوات i18n أثناء اختباراتك.

```typescript
// tests/unit-setup.ts

import { mockNuxtImport } from '@nuxt/test-utils/runtime'
import { vi } from 'vitest'
import { i18nUtils } from '@i18n-micro/test-utils'

export function createFakeI18n() {
  return {
    $getLocale: vi.fn(i18nUtils.getLocale),
    $t: vi.fn(i18nUtils.t),
    $tc: vi.fn(i18nUtils.tc),
    $setLocale: vi.fn(i18nUtils.setLocale),
    $getLocaleName: vi.fn(i18nUtils.getLocaleName),
    $setLocaleName: vi.fn(i18nUtils.setLocaleName),
    $getLocales: vi.fn(i18nUtils.getLocales),
    $setLocales: vi.fn(i18nUtils.setLocales),
    $defaultLocale: vi.fn(i18nUtils.defaultLocale),
    $setDefaultLocale: vi.fn(i18nUtils.setDefaultLocale),
    $getRouteName: vi.fn(i18nUtils.getRouteName),
    $settRouteName: vi.fn(i18nUtils.settRouteName),
    $ts: vi.fn(i18nUtils.ts),
    $tn: vi.fn(i18nUtils.tn),
    $td: vi.fn(i18nUtils.td),
    $has: vi.fn(i18nUtils.has),
    $resolveTranslations: vi.fn(i18nUtils.resolveTranslations),
    $setTranslation: vi.fn(i18nUtils.setTranslation),
    $mergeTranslations: vi.fn(i18nUtils.mergeTranslations),
    $switchLocaleRoute: vi.fn(i18nUtils.switchLocaleRoute),
    $switchLocalePath: vi.fn(i18nUtils.switchLocalePath),
    $switchLocale: vi.fn(i18nUtils.switchLocale),
    $switchRoute: vi.fn(i18nUtils.switchRoute),
    $localeRoute: vi.fn(i18nUtils.localeRoute),
    $localePath: vi.fn(i18nUtils.localePath),
    $setI18nRouteParams: vi.fn(i18nUtils.setI18nRouteParams),
  }
}

mockNuxtImport<() => ReturnType<typeof createFakeI18n>>('useI18n', () => vi.fn(() => createFakeI18n()))

export const setTranslationsFromJson = i18nUtils.setTranslationsFromJson
```

### 3. تهيئة Vitest

الآن، اضبط Vitest لاستخدام ملف التهيئة الوهمي وإعداد بيئة الاختبار.

```typescript
// vitest.config.ts

import { defineVitestConfig } from '@nuxt/test-utils/config'

export default defineVitestConfig({
  test: {
    watch: false,
    setupFiles: ['./tests/unit-setup.ts'],
    include: ['./**/*.spec.ts'],
  },
})
```

## 🧪 كتابة الاختبارات

### مكوّن مثال

فيما يلي مثال لمكوّن بسيط يستخدم composable `useI18n` لترجمة الرسائل.

```vue
<script setup lang="ts">
const { $t } = useI18n()

const props = defineProps({
  message: {
    type: String,
    default: null,
  },
})

// Test to see that $t works in script setup as well as the template
const message = props.message || $t('defaultMessage')
</script>

<template>
  <div>
    <p>Test from component: {{ $t('welcome') }}</p>
    <p data-testid="message">Test message from props: {{ message }}</p>
  </div>
</template>
```

### ملف الاختبار

الآن، لنكتب اختبارًا لهذا المكوّن.

```typescript
// tests/unit/example.spec.ts

import { describe, it, expect, beforeEach } from 'vitest'
import { mount } from '@vue/test-utils'
import ExampleComponent from '@/components/ExampleComponent.vue'
import fs from 'fs'
import path from 'path'
import { setTranslationsFromJson } from './unit-setup'

describe('ExampleComponent', () => {
  beforeEach(async () => {
    const fileContent = fs.readFileSync(path.join(__dirname, '../../locales/en-GB.json')).toString()
    await setTranslationsFromJson('en', JSON.parse(fileContent))
  })

  it('renders the welcome message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.text()).toContain('Test from component: Welcome')
  })

  it('renders the default message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Default Message')
  })

  it('renders the custom message correctly', () => {
    const wrapper = mount(ExampleComponent, {
      props: {
        message: 'Custom Message',
      },
    })
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Custom Message')
  })
})
```

## 📝 أفضل الممارسات للاختبار

- **🔧 محاكاة دوال i18n:** حاكِ دائمًا دوال i18n باستخدام `@i18n-micro/test-utils` لضمان نتائج اختبار متسقة ويمكن التنبؤ بها.
- **⚙️ استخدم Vitest لاختبارات الوحدة:** Vitest هو إطار عمل اختبار قوي لتطبيقات Vue. استخدمه لكتابة اختبارات الوحدة لمكوّناتك.
- **📚 وثّق اختباراتك:** وثّق الغرض والنتائج المتوقّعة لكل اختبار بوضوح. سيساعد هذا في الحفاظ على الوضوح ويسهّل على الآخرين (أو نفسك مستقبلًا) فهم الاختبارات.

## 📊 دوال أدوات i18n

فيما يلي جدول يصف جميع الدوال المساعدة التي يوفّرها `@i18n-micro/test-utils`.

| الدالة                                          | الوصف                                                                                                                                |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `t(key, params, defaultValue)`                  | يترجم مفتاحًا مع معاملات اختيارية وقيمة افتراضية.                                                                                     |
| `tc(key, params, defaultValue)`                 | يترجم مفتاحًا مع دعم التصريف بالعدد.                                                                                                  |
| `setTranslationsFromJson(locale, translations)` | يحمّل الترجمات من كائن JSON للغة محدّدة.                                                                                              |
| `getLocale()`                                   | يُعيد اللغة الحالية.                                                                                                                  |
| `setLocale(val)`                                | يعيّن اللغة الحالية.                                                                                                                  |
| `getLocaleName()`                               | يُعيد اسم اللغة الحالية.                                                                                                              |
| `setLocaleName(val)`                            | يعيّن اسم اللغة الحالية.                                                                                                              |
| `getLocales()`                                  | يُعيد قائمة اللغات المتاحة.                                                                                                           |
| `setLocales(val)`                               | يعيّن قائمة اللغات المتاحة.                                                                                                           |
| `defaultLocale()`                               | يُعيد اللغة الافتراضية.                                                                                                               |
| `setDefaultLocale(val)`                         | يعيّن اللغة الافتراضية.                                                                                                               |
| `getRouteName()`                                | يُعيد اسم المسار الحالي.                                                                                                              |
| `settRouteName(val)`                            | يعيّن اسم المسار الحالي.                                                                                                              |
| `ts(key, params, defaultValue)`                 | يترجم مفتاحًا ويُعيد النتيجة كسلسلة نصية.                                                                                              |
| `tn(value, options?)`                           | ينسّق رقمًا باستخدام `Intl.NumberFormatOptions` مضمّنة. تحتاج التنسيقات المسمّاة إلى تهيئة الوحدة وليست متاحة في هذا المساعد المستقل.  |
| `td(value, options?)`                           | ينسّق تاريخًا باستخدام `Intl.DateTimeFormatOptions` مضمّنة. تحتاج التنسيقات المسمّاة إلى تهيئة الوحدة وليست متاحة في هذا المساعد المستقل. |
| `has(key)`                                      | يتحقق مما إذا كان مفتاح الترجمة موجودًا.                                                                                              |
| `resolveTranslations()`                         | يُعيد شجرة الترجمة النشطة للغة والمسار الحاليين.                                                                                       |
| `setTranslation(key, value)`                    | يستبدل القيمة عند `key` في القاموس النشط (استبدال، وليس دمج).                                                                          |
| `mergeTranslations(newTranslations)`            | يدمج الترجمات في اللغة النشطة في وقت التشغيل.                                                                                          |

باتباع هذه الخطوات، يمكنك اختبار وحدة `Nuxt I18n Micro` بفعالية والتأكد من عمل ميزات التوطين في تطبيقك كما هو متوقّع.
