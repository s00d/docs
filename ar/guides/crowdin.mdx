# 🌐 دليل تكامل Crowdin

## 📖 مقدمة

يعمل دمج Crowdin في مشروعك على تبسيط عملية التوطين والترجمة، مما يسهّل إدارة الترجمات عبر لغات ومنصات متعددة. يقدّم هذا الدليل شرحًا خطوة بخطوة لإعداد Crowdin مع مشروعك، بما في ذلك الإعداد ورفع المصادر وتنزيل الترجمات.

## 🔧 التثبيت والإعداد

للبدء مع Crowdin، ستحتاج إلى تثبيت Crowdin CLI عالميًا على جهازك وتهيئته داخل مجلد مشروعك.

### 📦 تثبيت Crowdin CLI

أولًا، ثبّت Crowdin CLI عالميًا باستخدام npm:

```bash
npm install -g @crowdin/cli
```

### 🛠 تهيئة Crowdin في مشروعك

هيّئ Crowdin في مشروعك بتشغيل:

```bash
crowdin init
```

سيرشدك هذا الأمر خلال عملية الإعداد، بما في ذلك تحديد معرّف المشروع ورمز API وتفاصيل الإعداد الأخرى.

## 🗂️ دليل الإعداد

### 📄 ملف إعداد Crowdin (`crowdin.yml`)

يحدّد ملف إعداد Crowdin (`crowdin.yml`) كيفية تعيين ملفات المصدر ومكان وضع الترجمات. فيما يلي مثال للإعداد:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 معاملات الإعداد الأساسية

- **`project_id`**: معرّف مشروع Crowdin الخاص بك. يحدّد هذا المشروع داخل Crowdin حيث تُدار الترجمات.
- **`api_token`**: رمز API المستخدم للمصادقة. تأكّد من أن هذا الرمز يمتلك الصلاحيات الصحيحة لرفع الترجمات وتنزيلها.
- **`base_path`**: يحدّد الدليل الأساسي لملفات المصدر. في هذا المثال، تُخزَّن الترجمات في مجلد `./locales`.
- **`base_url`**: عنوان URL الأساسي لواجهة Crowdin API.
- **`preserve_hierarchy`**: عند التعيين إلى `true`، سيحافظ Crowdin على هيكل المجلدات لملفات المصدر في المشروع.

### 📂 إعداد الملفات

يعيّن قسم `files` ملفات المصدر إلى المسارات التي ستُخزَّن فيها الترجمات. على سبيل المثال:

- **مسار المصدر**: يحدّد موقع ملفات الترجمة الأصلية.
- **مسار الترجمة**: يحدّد مكان تخزين الملفات المترجَمة في Crowdin. تُستخدم عناصر نائبة مثل `%two_letters_code%` لتعيين رمز اللغة ديناميكيًا في مسارات الملفات.

## ⬆️ رفع ملفات المصدر إلى Crowdin

بعد إعداد Crowdin، يمكنك رفع ملفات المصدر باستخدام الأمر التالي:

```bash
crowdin upload sources
```

يرفع هذا الأمر جميع ملفات المصدر المحدّدة في إعدادك إلى Crowdin، مما يجعلها متاحة للترجمة.

## ⬇️ تنزيل الترجمات من Crowdin

بعد اكتمال الترجمات أو تحديثها في Crowdin، يمكنك تنزيلها إلى مشروعك عبر:

```bash
crowdin download
```

يجلب هذا الأمر أحدث الترجمات من Crowdin ويحفظها وفقًا للمسارات المحدّدة في ملف الإعداد.

## ⚙️ أفضل الممارسات

### 🔑 تسمية متناسقة للمفاتيح

تأكّد من أن مفاتيح الترجمة متناسقة عبر جميع الملفات لتجنّب الالتباس والتكرار.

### 🧹 صيانة دورية

راجع مفاتيح الترجمة غير المستخدمة ونظّفها دوريًا للحفاظ على ملفاتك منظّمة وسهلة الإدارة.

### 🛠 أتمتة عمليات الرفع والتنزيل

ادمج أوامر Crowdin CLI في خط أنابيب CI/CD لأتمتة رفع ملفات المصدر وتنزيل الترجمات، مما يضمن أن تكون ترجماتك دائمًا محدَّثة.

باتباع هذا الدليل، ستتمكّن من دمج Crowdin بسلاسة في مشروعك، مما يضمن نهجًا فعّالًا ومنظّمًا لإدارة جهود التدويل.
