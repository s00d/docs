# 🌐 دليل تكامل Crowdin

## 📖 مقدمة

يبسّط دمج Crowdin في مشروعك عملية التوطين والترجمة، مما يسهّل إدارة الترجمات عبر لغات ومنصات متعددة. يقدّم هذا الدليل شرحاً خطوة بخطوة لإعداد Crowdin مع مشروعك، بما في ذلك التكوين ورفع المصادر وتنزيل الترجمات.

## 🔧 التثبيت والإعداد

للبدء مع Crowdin، ستحتاج إلى تثبيت Crowdin CLI عالمياً على جهازك وتهيئته داخل مجلد مشروعك.

### 📦 تثبيت Crowdin CLI

أولاً، ثبّت Crowdin CLI عالمياً باستخدام npm:

```bash
npm install -g @crowdin/cli
```

### 🛠 تهيئة Crowdin في مشروعك

هيّئ Crowdin في مشروعك بتشغيل:

```bash
crowdin init
```

سيرشدك هذا الأمر خلال عملية الإعداد، بما في ذلك ضبط معرّف مشروعك ورمز API وتفاصيل تكوين أخرى.

## 🗂️ دليل التكوين

### 📄 ملف تكوين Crowdin (`crowdin.yml`)

يعرّف ملف تكوين Crowdin (`crowdin.yml`) كيف يتم تعيين ملفات المصدر وأين يجب وضع الترجمات. فيما يلي مثال على التكوين:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 معاملات التكوين الرئيسية

- **`project_id`**: معرّف مشروعك في Crowdin. يحدّد هذا المشروع داخل Crowdin حيث تُدار الترجمات.
- **`api_token`**: رمز API المستخدم للمصادقة. تأكّد من أن هذا الرمز يمتلك الأذونات الصحيحة لرفع الترجمات وتنزيلها.
- **`base_path`**: يحدّد المجلد الأساسي لملفات المصدر. في هذا المثال، تُخزَّن الترجمات في مجلد `./locales`.
- **`base_url`**: عنوان URL الأساسي لواجهة Crowdin API.
- **`preserve_hierarchy`**: عند ضبطها على `true`، سيحافظ Crowdin على بنية مجلدات ملفات المصدر الخاصة بك في المشروع.

### 📂 تكوين الملفات

يعيّن قسم `files` ملفات المصدر إلى المسارات التي ستُخزَّن فيها الترجمات. مثلاً:

- **مسار المصدر**: يحدّد موقع ملفات الترجمة الأصلية.
- **مسار الترجمة**: يحدّد أين ستُخزَّن الملفات المترجمة في Crowdin. تُستخدم العناصر النائبة مثل `%two_letters_code%` لضبط رمز اللغة ديناميكياً في مسارات الملفات.

## ⬆️ رفع ملفات المصدر إلى Crowdin

بمجرد إعداد تكوين Crowdin، يمكنك رفع ملفات المصدر باستخدام الأمر التالي:

```bash
crowdin upload sources
```

يرفع هذا الأمر جميع ملفات المصدر المحدّدة في تكوينك إلى Crowdin، مما يجعلها متاحة للترجمة.

## ⬇️ تنزيل الترجمات من Crowdin

بعد اكتمال الترجمات أو تحديثها في Crowdin، يمكنك تنزيلها إلى مشروعك باستخدام:

```bash
crowdin download
```

يجلب هذا الأمر أحدث الترجمات من Crowdin ويحفظها وفقاً للمسارات المحدّدة في ملف التكوين الخاص بك.

## ⚙️ أفضل الممارسات

### 🔑 تسمية مفاتيح متسقة

تأكّد من أن مفاتيح الترجمة متسقة عبر جميع الملفات لتجنّب الالتباس والتكرار.

### 🧹 صيانة منتظمة

راجع ونظّف دورياً مفاتيح الترجمة غير المستخدمة للحفاظ على تنظيم ملفاتك وإدارتها.

### 🛠 أتمت الرفع والتنزيل

ادمج أوامر Crowdin CLI في سير عمل CI/CD لأتمتة رفع ملفات المصدر وتنزيل الترجمات، مما يضمن أن ترجماتك محدّثة دائماً.

باتباع هذا الدليل، ستتمكّن من دمج Crowdin بسلاسة في مشروعك، مما يضمن نهجاً فعّالاً ومنظّماً لإدارة جهود التدويل الخاصة بك.
