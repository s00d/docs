# استخدام الترجمات في المكوّنات

بعد تثبيت الوحدة وإعدادها، يمكنك عرض الترجمات باستدعاء `$t('your_key')` داخل قوالب Vue وسكربتاتها.

## 1. ملفات الترجمة على مستوى الجذر والخاصة بالصفحات

1. تقع ترجمات **مستوى الجذر** مباشرةً تحت مجلد `/locales` (مثل `/locales/en.json` و`/locales/fr.json`). أثناء البناء، تُدمج تلقائيًا في كل ملف خاص بالصفحة، مما يجعلها متاحة في جميع الصفحات.
2. توجد ترجمات **الصفحات** تحت `/locales/pages/...`، بحيث تطابق هيكل مجلد الصفحات في Nuxt:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. استخدام `$t` في القالب

في ملفات `.vue`، يمكنك استخدام `$t` مباشرةً في القالب:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
يمكن أن ترجع `$t` **كائنات** إذا أشار المفتاح إلى عقدة JSON متداخلة (مثل `$t('header')` → `\{ title: "Hi" \}`). في القوالب، يُعرض هذا كـ `[object Object]`. استخدم `$ts` عندما تحتاج إلى سلسلة نصية مضمونة، أو قدّم مفتاحًا أكثر تحديدًا مثل `$t('header.title')`. اطّلع على [مرجع API — $t مقابل $ts](/api/methods#t) لمزيد من التفاصيل.
</Tip>

## 3. تبديل اللغة الحالية

لتغيير اللغات في تطبيقك، يمكنك جلب `$locale` من `useI18n()` وتعيين رمز جديد لها:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. المفاتيح المتداخلة والعناصر النائبة

- **المفاتيح المتداخلة** تستخدم التدوين النقطي، مثل `nested.key.deeper`.
- **العناصر النائبة** تتيح لك إدراج قيم ديناميكية:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. نصائح وأفضل الممارسات

- **المفاتيح المتعارضة**: إذا كان ملف خاص بالصفحة يحتوي على المفتاح ذاته الموجود في ملف مستوى الجذر، فإن نسخة الصفحة تأخذ الأولوية (تُدمج ترجمات الجذر كقاعدة أثناء البناء).
- **تعطيل ملفات الصفحات**: إذا كنت تفضّل عدم استخدام ترجمات خاصة بالصفحات، يمكنك تعيين `disablePageLocales: true` في إعداد Nuxt. بهذه الطريقة، تُستخدم ملفات `/locales/*.json` فقط.
- **بدون استيراد مباشر**: لست بحاجة إلى `import \{ useI18n \} from 'nuxt-i18n-micro'`؛ تتولّى ميزة الحقن التلقائي في الوحدة ذلك نيابةً عنك.

هذا كل شيء! باتباع هذه الخطوات، يمكنك **البدء بسرعة في جلب الترجمات** من ملفات JSON على مستوى الجذر أو الخاصة بالصفحات و**عرضها** في تطبيق Nuxt الخاص بك باستخدام `$t`.

## موارد إضافية

لاستكشاف ميزات أكثر تقدّمًا، تأكد من الاطلاع على:

1. **مكوّن `<i18n-t>`**  
   يُعدّ مكوّن `<i18n-t>` بديلاً قويًا لـ `$t`، ومفيدًا خصوصًا في الحالات التي تتضمّن عناصر متداخلة أو استخدامًا متقدّمًا للعناصر النائبة أو هياكل ترجمة أكثر تعقيدًا.

- **التوثيق**: [i18n-t](/api/components/i18n-t)

2. **Composable `useI18n`**  
   يوفّر `useI18n` مجموعة كاملة من الدوال والخصائص التفاعلية لإدارة الترجمات والتعامل مع تبديل اللغة والتنسيق وأكثر.

- **التوثيق**: [useI18n](/api/composables/use-i18n)
