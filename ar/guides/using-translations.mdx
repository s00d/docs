# استخدام الترجمات في المكوّنات

بمجرد تثبيت الوحدة وتكوينها، يمكنك عرض الترجمات باستدعاء `$t('your_key')` داخل قوالب Vue وسكربتاتك.

## 1. ملفات الترجمة الجذرية والخاصة بالصفحات

1. **الترجمات الجذرية** توجد مباشرة تحت مجلد `/locales` (مثل `/locales/en.json` و `/locales/fr.json`). في وقت البناء، تُدمج تلقائياً في كل ملف خاص بصفحة، مما يجعلها متاحة في جميع الصفحات.
2. **الترجمات الخاصة بالصفحات** توجد تحت `/locales/pages/...`، وتطابق بنية مجلد صفحات Nuxt الخاص بك:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. استخدام القالب مع `$t`

في ملفات `.vue` الخاصة بك، يمكنك استخدام `$t` مباشرة في القالب:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
يمكن أن تُرجع `$t` **كائنات** إذا كان المفتاح يشير إلى عقدة JSON متداخلة (مثل `$t('header')` → `\{ title: "Hi" \}`). في القوالب يُعرض هذا كـ `[object Object]`. استخدم `$ts` عندما تحتاج إلى سلسلة نصية مضمونة، أو قدّم مفتاحاً أكثر تحديداً مثل `$t('header.title')`. راجع [مرجع API — $t مقابل $ts](/api/methods#t) للتفاصيل.
</Tip>

## 3. تبديل اللغة الحالية

لتغيير اللغات في تطبيقك، يمكنك استرداد `$locale` من `useI18n()` وتعيين رمز جديد له:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. المفاتيح المتداخلة والعناصر النائبة

- **المفاتيح المتداخلة** تستخدم رمز النقطة، مثل `nested.key.deeper`.
- **العناصر النائبة** تسمح لك بإدراج قيم ديناميكية:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. نصائح وأفضل الممارسات

- **المفاتيح المتعارضة**: إذا احتوى ملف خاص بصفحة على نفس المفتاح الموجود في ملف جذري، تأخذ النسخة الخاصة بالصفحة الأولوية (تُدمج الترجمات الجذرية كأساس في وقت البناء).
- **تعطيل ملفات الصفحات**: إذا كنت تفضّل عدم استخدام الترجمات الخاصة بالصفحات، يمكنك ضبط `disablePageLocales: true` في تكوين Nuxt الخاص بك. بهذه الطريقة، تُستخدم فقط ملفات `/locales/*.json`.
- **بدون استيرادات مباشرة**: لا تحتاج إلى تنفيذ `import \{ useI18n \} from 'nuxt-i18n-micro'`؛ ميزة الحقن التلقائي في الوحدة تتولّى ذلك.

هذا كل شيء! باتباع هذه الخطوات، يمكنك **البدء بسرعة في استرداد الترجمات** من ملفات JSON الجذرية أو الخاصة بالصفحات و**عرضها** في تطبيق Nuxt الخاص بك باستخدام `$t`.

## موارد إضافية

لاستكشاف المزيد من الميزات المتقدمة، تأكّد من مراجعة:

1. **مكوّن `<i18n-t>`**  
   مكوّن `<i18n-t>` بديل قوي لـ `$t`، مفيد بشكل خاص للحالات التي تتضمّن عناصر متداخلة، واستخداماً متقدماً للعناصر النائبة، وبنى ترجمة أكثر تعقيداً.

- **التوثيق**: [i18n-t](/api/components/i18n-t)

2. **الـ Composable `useI18n`**  
   يقدّم الـ composable `useI18n` مجموعة كاملة من الدوال والخصائص التفاعلية لإدارة الترجمات، والتعامل مع تبديل اللغة، والتنسيق، والمزيد.

- **التوثيق**: [useI18n](/api/composables/use-i18n)
