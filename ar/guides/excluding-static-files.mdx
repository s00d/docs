# استبعاد الملفات الثابتة من توجيه i18n

## نظرة عامة

افتراضياً، يستبعد nuxt-i18n-micro تلقائياً الملفات الثابتة الشائعة من معالجة توجيه i18n. ومع ذلك، يمكنك أيضاً تكوين أنماط استبعاد مخصصة لمنع معالجة مسارات محددة بواسطة نظام i18n.

## الاستبعادات المدمجة

تستبعد الوحدة تلقائياً أنواع الملفات والأنماط التالية:

- **خرائط الموقع**: `/sitemap*.xml` و `/sitemap-en.xml` وغيرها.
- **ملفات SEO**: `/robots.txt` و `/favicon.ico`
- **ملفات PWA**: `/manifest.json` و `/sw.js` و `/workbox-*.js`
- **الأصول الثابتة**: الملفات ذات الامتدادات مثل `.xml` و `.txt` و `.ico` و `.json` و `.js` و `.css` و `.png` و `.jpg` و `.jpeg` و `.gif` و `.svg` و `.woff` و `.woff2` و `.ttf` و `.eot`
- **مسارات Nuxt الداخلية**: أي مسار يبدأ بـ `__` (مثل `/__nuxt/`)

## أنماط الاستبعاد المخصصة

يمكنك تعريف أنماط استبعاد مخصصة باستخدام الخيار `excludePatterns`:

```typescript
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],

  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'it', iso: 'it-IT' },
    ],
    defaultLocale: 'en',

    // Custom exclusion patterns
    excludePatterns: [
      // String patterns (exact match or prefix)
      '/api/health',
      '/admin',

      // String patterns with wildcards
      '/api/*',
      '/admin/**',

      // Regular expressions
      /^\/api\/v\d+\//,
      /\.(pdf|doc|docx)$/,
    ],
  },
})
```

## أنواع الأنماط

### أنماط السلاسل النصية

- **مطابقة دقيقة**: `'/api/health'` - يطابق `/api/health` بالضبط
- **مطابقة بادئة**: `'/admin'` - يطابق `/admin` و `/admin/dashboard`
- **أحرف البدل**: `'/api/*'` - يطابق `/api/users` ولكن ليس `/api/users/123`
- **أحرف بدل عميقة**: `'/admin/**'` - يطابق `/admin/users` و `/admin/users/123`

### التعبيرات العادية

استخدم كائنات RegExp لمطابقة الأنماط المعقّدة:

```typescript
excludePatterns: [
  /^\/api\/v\d+\//, // API versioned routes
  /\.(pdf|doc|docx)$/, // Document files
  /^\/static\//, // Static directory
  /^\/[a-z]{2}\/api\//, // Localized API routes
]
```

## حالات الاستخدام

### ملفات SEO

```typescript
excludePatterns: ['/sitemap.xml', '/sitemap-*.xml', '/robots.txt', '/favicon.ico']
```

### مسارات API

```typescript
excludePatterns: ['/api/**', '/graphql', '/webhook/**']
```

### لوحات المسؤول

```typescript
excludePatterns: ['/admin', '/admin/**', '/dashboard']
```

### الأصول الثابتة

```typescript
excludePatterns: ['/assets/**', '/static/**', '/uploads/**']
```

## كيف يعمل

1. **Middleware الخادم**: يعمل middleware في Nitro أولاً للتحقّق من أنماط الاستبعاد
2. **معالجة الصفحة**: أثناء حلّ الصفحة، تُتخطّى المسارات المستبعدة
3. **مسار الالتقاط الشامل**: يتحقّق المسار الاحتياطي من الاستبعادات قبل المعالجة
4. **التقديم المسبق**: لا تُدرج المسارات المستبعدة في المسارات المقدّمة مسبقاً

## تأثير الأداء

- تُحسَّن فحوصات الاستبعاد وتعمل في وقت مبكر من دورة حياة الطلب
- تستخدم الأنماط المدمجة مطابقة regex فعّالة
- تُخزَّن الأنماط المخصصة مؤقتاً ويُعاد استخدامها
- الحد الأدنى من الحمل على الأداء للمسارات المستبعدة

## استكشاف الأخطاء

### الملفات الثابتة لا تزال يتم اعتراضها

1. **تحقّق من صيغة النمط**: تأكّد من أن أنماطك تطابق بنية المسار الدقيقة
2. **استخدم regex للأنماط المعقّدة**: لأحرف البدل في السلاسل النصية قيود
3. **اختبر الأنماط**: استخدم أدوات مطوّري المتصفح للتحقّق من مسار الطلب الفعلي
4. **تحقّق من الترتيب**: تأكّد من تعريف أنماط الاستبعاد قبل تكوين i18n الآخر

### النمط لا يعمل

```typescript
// ❌ Wrong - this won't work
excludePatterns: ['sitemap.xml']

// ✅ Correct - include leading slash
excludePatterns: ['/sitemap.xml']

// ✅ Better - use regex for flexibility
excludePatterns: [/^\/sitemap.*\.xml$/]
```

### وضع التصحيح

فعّل وضع التصحيح لرؤية معالجة الاستبعاد:

```typescript
i18n: {
  debug: true,
  excludePatterns: ['/api/**']
}
```

سيسجّل هذا قرارات الاستبعاد في وحدة التحكّم.

## الانتقال من الحلول البديلة

إذا كنت تستخدم حلولاً بديلة مثل قواعد المسارات أو middleware، يمكنك الآن استبدالها بـ `excludePatterns`:

```typescript
// ❌ Old workaround
export default defineNuxtConfig({
  routeRules: {
    '/sitemap*.xml': { headers: { 'content-type': 'application/xml' } },
  },
})

// ✅ New approach
export default defineNuxtConfig({
  i18n: {
    excludePatterns: ['/sitemap*.xml'],
  },
})
```

النهج الجديد أكثر موثوقية ويعمل على مستويات متعددة من نظام التوجيه.
