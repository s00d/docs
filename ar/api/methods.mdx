## 🔍 دوال الترجمة

الدوال الأساسية لاسترداد الترجمات وإدارتها.

### `$t`

{/* generated:method:$t — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

ترجمة مفتاح، وإدخال `params` فيه. تُرجع `defaultValue` عندما يكون المفتاح
مفقوداً، أو المفتاح نفسه عندما لا تُعطى قيمة افتراضية.

{/* /generated:method:$t */}

```typescript
const welcomeMessage = $t('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

<Warning>
تُرجع `$t` نوع `CleanTranslation` وهو `string | number | boolean | Translations | PluralTranslations | null`. إذا كان المفتاح يشير إلى **كائن متداخل** في JSON الخاص بك (مثلاً `$t('header')` عندما يحتوي JSON على `\{ "header": \{ "title": "Hi" \} \}`)، ستكون القيمة المُرجعة هي ذلك **الكائن**، وليس سلسلة. سيؤدي استخدامها مباشرةً في قالب Vue (<code v-pre>\{\{ $t('header') \}\}</code>) إلى عرض `[object Object]`.

**كيفية تجنّب ذلك:**

- استخدم مفتاحاً أكثر تحديداً: `$t('header.title')` → `"Hi"`
- استخدم `$ts()` الذي يُرجع دائماً سلسلة (يستدعي `.toString()` على القيم غير النصية)
- استخدم `$t` مع مفتاح متداخل للوصول عمداً إلى الكائنات الفرعية للاستخدام البرمجي
</Warning>

### `$ts`

{/* generated:method:$ts — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string) => string
```

مثل `$t`، لكنها تُرجع دائماً سلسلة نصية: تُحوَّل قيمة كائن أو مصفوفة إلى سلسلة بدلاً من إرجاعها كما هي.

{/* /generated:method:$ts */}

```typescript
const welcomeMessage = $ts('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

### `$_t` و `$_ts`

{/* generated:method:$_t — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

يربط `$t` بمسار محدد، للترجمة خارج الصفحة الحالية — تخطيط يعرض
رابطاً إلى مسار آخر، على سبيل المثال.

{/* /generated:method:$_t */}

{/* generated:method:$_ts — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => string
```

يربط `$ts` بمسار محدد. راجع `$_t`.

{/* /generated:method:$_ts */}

متغيّرات مقيّدة بالمسار لـ `$t` و `$ts`. تأخذ **مساراً** أولاً وتُرجع دالة ترجمة مقفلة على لغة ذلك المسار وسياق الصفحة.

- **الوصول**: `useNuxtApp()` (أُعيد تصديرها أيضاً بواسطة `useI18n()` كـ `$_t` / `$_ts`)

استخدم هذه عندما يختلف المسار النشط أثناء SSR أو الانتقالات عن `router.currentRoute` — على سبيل المثال داخل `<i18n-t>` و `<i18n-group>`، أو عند عرض محتوى لكائن `route` محدد.

```typescript
import { useRoute, useNuxtApp } from '#imports'

const route = useRoute()
const { $_t, $_ts } = useNuxtApp()

const $t = $_t(route)
const title = $t('page.title')

// String-safe variant
const label = $_ts(route)('page.label')
```


### `$tc`

{/* generated:method:$tc — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params: number | Params, defaultValue?: string) => string
```

الترجمة مع صيغ الجمع. قد يكون `params` هو العدد نفسه، أو كائناً يحتوي على
`count`.

{/* /generated:method:$tc */}

**تنسيق الترجمة**: صيغ مفصولة بـ `|`. ضع العناصر النائبة في **كل** صيغة:

```json
{
  "apples": "no apples | one apple | {count} apples",
  "cart": "no items for {name} | one item for {name} | {count} items for {name}"
}
```

```typescript
$tc('apples', 0) // "no apples"
$tc('apples', 1) // "one apple"
$tc('apples', 10) // "10 apples"

// count + other params (second argument must be an object)
$tc('cart', { count: 10, name: 'Alice' }) // "10 items for Alice"
```


**بديل المكوّن** — `<i18n-t keypath="cart" :plural="count" :params="\{ name \}" />` (يدمج `count` مع `params` داخلياً).

### `$resolveTranslations`

{/* generated:method:$resolveTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
() => Translations
```

كل ترجمة موجودة حالياً في الذاكرة للغة النشطة والمسار، كشجرة.
عرض للقراءة فقط لما يمكن أن يحلّه `$t()` الآن.

{/* /generated:method:$resolveTranslations */}

```typescript
const tree = $resolveTranslations()
// { aaa: { bbb: 'ccc' }, ddd: 1111 } — the same dictionary $t() reads from
```

استخدم هذه عندما تحتاج إلى القاموس الكامل في الذاكرة (DevTools والاختبارات ومحرّرات وقت التشغيل). عامل القيمة المُرجعة كقراءة فقط؛ غيّر القيم عبر `$setTranslation` أو ادمج التصحيحات باستخدام `$mergeTranslations`.

### `$setTranslation`

{/* generated:method:$setTranslation — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, value: unknown) => void
```

استبدال القيمة في `key` في القاموس النشط. هذا استبدال وليس دمج —
استخدم `$mergeTranslations` عندما يجب أن يبقى الأشقاء الموجودون.

{/* /generated:method:$setTranslation */}

```typescript
$setTranslation('aaa', { fff: 'ggg' }) // replaces the whole `aaa` subtree
$setTranslation('aaa', 'text')          // replaces `aaa` with a string
$setTranslation('ddd', 1111)            // scalar at the top level
$setTranslation('aaa.bbb', 'nested')    // dotted path
```

هذا **استبدال** وليس دمج. تُزال الأشقاء الموجودون تحت نفس المفتاح. للتصحيح دون فقدان الأشقاء، استخدم `$mergeTranslations`.

### `$setMissingHandler`

{/* generated:method:$setMissingHandler — do not edit; run `pnpm run docs:generate` */}

```ts
(handler: MissingHandler | null) => void
```

تثبيت رد نداء يُستدعى لكل مفتاح لم يُحلّ. مرّر `null` لإزالته.

{/* /generated:method:$setMissingHandler */}

**تعريف النوع**:

```typescript
type MissingHandler = (locale: string, key: string, routeName: string, instance?: unknown, type?: string) => void
```

```typescript
// Set a custom handler
$setMissingHandler((locale, key, routeName) => {
  console.error(`Missing translation: ${key} in ${locale} for route ${routeName}`)
  // Send to Sentry or other error tracking service
  // Sentry.captureMessage(`Missing translation: ${key}`)
})

// Remove the handler
$setMissingHandler(null)
```

**حالات الاستخدام**:

- تسجيل الترجمات المفقودة في خدمات تتبع الأخطاء (Sentry و LogRocket وغيرها)
- جمع تحليلات عن الترجمات المفقودة
- معالجة أخطاء مخصصة لمفاتيح الترجمة المفقودة

## 🔢 تنسيق الأرقام والتواريخ

دوال لتنسيق الأرقام والتواريخ وفقاً لاتفاقيات اللغة.

### `$tn`

{/* generated:method:$tn — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

تنسيق رقم باستخدام `Intl.NumberFormat` في اللغة النشطة. يختار مفتاح صيغة مسمّاة
من التكوين.

{/* /generated:method:$tn */}

```typescript
// Inline options
const formattedNumber = $tn(1234567.89, { style: 'currency', currency: 'USD' })
// "$1,234,567.89"

// Named format (from nuxt.config i18n.numberFormats)
const price = $tn(1000, 'currency')
const priceDe = $tn(1000, 'currency', 'de')
const compact = $tn(1000, 'currency', { notation: 'compact' })
```

تعود مفاتيح الصيغة المسمّاة غير المعروفة إلى خيارات `Intl.NumberFormat` الافتراضية. في وضع التطوير (على العميل)، يُصدر `console.warn` عند تفعيل `missingWarn` (الافتراضي).

**مثال التكوين**:

```ts
export default defineNuxtConfig({
  i18n: {
    numberFormats: {
      en: {
        currency: { style: 'currency', currency: 'USD' },
        decimal: { style: 'decimal', minimumFractionDigits: 2, maximumFractionDigits: 2 },
      },
      de: {
        currency: { style: 'currency', currency: 'EUR' },
      },
    },
  },
})
```

**حالات الاستخدام**:

- تنسيق الأرقام كعملة أو نسب مئوية أو أرقام عشرية بصيغة اللغة المناسبة
- إعادة استخدام الصيغ المسمّاة عبر التطبيق (توازي انتقال Vue I18n)

### `$td`

{/* generated:method:$td — do not edit; run `pnpm run docs:generate` */}

تنسيق تاريخ باستخدام `Intl.DateTimeFormat` في اللغة النشطة. يختار مفتاح صيغة مسمّاة

**مثال التكوين**:


**حالات الاستخدام**:

- عرض التواريخ بصيغة تتوافق مع لغة المستخدم

## 🚦 تكوين المسار

دوال لتكوين سلوك المسار والتحكّم في الوصول.

### `$defineI18nRoute`

{/* generated:method:$defineI18nRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

تسجيل تكوين لغة لكل صفحة وترجمات من داخل مكوّن.
تدمج في اللغة النشطة وتُعاد تطبيقها عند تغيير اللغة.

{/* /generated:method:$defineI18nRoute */}

> [!IMPORTANT]
> `$defineI18nRoute` مقدّمة بواسطة **إضافة define** ومتاحة على `useNuxtApp()` فقط — **ليست** جزءاً من كائن الإرجاع لـ `useI18n()`.
> فكّكها دائماً من `useNuxtApp()` داخل `script setup`. استدعاء `$defineI18nRoute(...)` كعالمي مجرد يرمي `"$defineI18nRoute is not defined"` أثناء SSR/التقديم المسبق.

**المعاملات**:

- **locales**: `string[] | Record<string, Record<string, string>>` — اللغات المتاحة للمسار
- **localeRoutes**: `Record<string, string>` — اختياري. مسارات مخصصة للغات محددة
- **disableMeta**: `boolean | string[]` — اختياري. يعطّل وسوم i18n Meta لجميع اللغات أو لغات محددة

**مثال أساسي**:

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr', 'de'],
  localeRoutes: {
    en: '/welcome',
    fr: '/bienvenue',
    de: '/willkommen',
  },
  disableMeta: false,
})
```

> 📖 **للحصول على أمثلة استخدام مفصّلة وصيغ التكوين وأفضل الممارسات، راجع [دليل ترجمات لكل مكوّن](/guides/per-component-translations).**

### `$setI18nRouteParams`

{/* generated:method:$setI18nRouteParams — do not edit; run `pnpm run docs:generate` */}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

ضبط معاملات لكل لغة للمسار الحالي، بحيث يمكن أن يختلف مقطع ديناميكي لكل لغة.
استدعِها أثناء SSR، قبل عرض head.

{/* /generated:method:$setI18nRouteParams */}

```typescript
// in pages/news/[id].vue
// for en/news/1-first-article
const { $switchLocaleRoute, $setI18nRouteParams, $defineI18nRoute } = useNuxtApp()
$defineI18nRoute({
  localeRoutes: {
    en: '/news/:id()',
    fr: '/nouvelles/:id()',
    de: '/Nachricht/:id()',
  },
})
const { data: news } = await useAsyncData(`news-${params.id}`, async () => {
  let response = await $fetch("/api/getNews", {
    query: {
      id: params.id,
    },
  });
  if (response?.localeSlugs) {
    response.localeSlugs = {
      en: {
        id: '1-first-article'
      }
      fr: {
        id: '1-premier-article'
      }
      de: {
        id: '1-erster-Artikel'
      }
    }
    $setI18nRouteParams(response?.localeSlugs);
  }
  return response;
});
$switchLocalePath('fr') // === 'fr/nouvelles/1-premier-article'
$switchLocalePath('de') // === 'de/Nachricht/1-erster-Artikel'
```

## 🧭 الـ Composable `useI18nLocale`

الـ composable المركزي لإدارة حالة اللغة. استخدم هذا بدلاً من التلاعب المباشر بـ `useState('i18n-locale')` أو `useCookie('user-locale')`.

```typescript
const {
  setLocale, // (locale: string) => void — updates state + cookie
  getLocale, // () => string | null — from state or cookie
  getPreferredLocale, // () => string | null — validated against locales list
  getEffectiveLocale, // (route, getLocaleFromRoute) => string
  resolveInitialLocale, // (options) => string
  isValidLocale, // (locale) => boolean
  locale, // Ref<string | null> — reactive state
  localeCookie, // CookieRef — reactive cookie
  syncLocale, // (locale) => void — sync to cookie only
  validLocales, // string[] — list of valid locale codes
} = useI18nLocale()
```

### الدوال الرئيسية

| الدالة                  | الوصف                                                 |
| ----------------------- | ----------------------------------------------------------- |
| `setLocale(locale)`     | يضبط اللغة في كل من `useState` وملف تعريف الارتباط بشكل ذرّي |
| `getLocale()`           | يُرجع اللغة الحالية من الحالة أو ملف تعريف الارتباط |
| `getPreferredLocale()`  | يُرجع اللغة مُتحقّقاً منها مقابل قائمة `locales`، أو `null` |
| `isValidLocale(locale)` | يتحقّق مما إذا كان رمز اللغة موجوداً في قائمة `locales` المُكوَّنة |
