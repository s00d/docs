description: "كل دالة مساعدة لوقت التشغيل تحقنها الوحدة — `$t` و`$tc` و`$localePath` و`$switchLocale` وغيرها — مع توقيعها."

تحقن الوحدة دوالها المساعدة لوقت التشغيل في تطبيق Nuxt: `$t` و`$tc` و`$localePath` و`$switchLocale` وغيرها. استخدم هذه الصفحة للبحث عن توقيع أي دالة مساعدة وسلوكها. تأتي التواقيع والأوصاف من الواجهتين `PluginsInjections` و`NuxtAppOnlyInjections` في `src/runtime/plugins/01.plugin.ts`.

## الوصول {#access}

| أين | كيف |
| --- | --- |
| القالب | `{{ $t('title') }}` — كل الدوال المساعدة، مع `$` |
| `<script setup>` | `const { t, localePath } = useI18n()` — كل دالة مساعدة في `PluginsInjections`، مع `$` وبدونها |
| الإضافة، الوسيط (middleware)، `<script setup>` | `const { $t, $defineI18nRoute } = useNuxtApp()` — كل شيء، مع `$` فقط |

النوع `$defineI18nRoute` معرَّف على `useNuxtApp()` فقط. راجع [`useI18n`](/ar/composables/useI18n).

```vue
<script setup lang="ts">
const { t, localePath } = useI18n()
</script>

<template>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
</template>
```

## اللغة {#locale}

### `$getLocale` {#$getlocale}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric) => string
```

رمز اللغة النشطة. مرّر مسارًا لقراءة اللغة التي ينتمي إليها ذلك المسار.

```ts
$getLocale() // 'de' on /de/about
```

### `$getLocaleName` {#$getlocalename}

```ts
() => string | null
```

قيمة `displayName` للغة النشطة من الإعدادات، أو `null` إن لم تكن لها قيمة.

### `$getLocales` {#$getlocales}

```ts
() => Locale[]
```

كل اللغات المُعدّة، مع بياناتها الوصفية.

تُعاد الخصائص المخصصة في كائن اللغة كما كُتبت؛ عرّف أنواعها عبر [توسيع الوحدة](/ar/api/module-options#locales) للنوع `Locale`.

### `$defaultLocale` {#$defaultlocale}

```ts
() => string | undefined
```

رمز اللغة الافتراضية المُعدّة.

### `$getI18nConfig` {#$geti18nconfig}

```ts
() => ResolvedI18nConfig
```

إعدادات الوحدة المُحلَّلة، كما يراها وقت التشغيل.

تتضمن القيمة [تجاوزات وقت التشغيل](/ar/guide/runtime-overrides) (`defaultLocale` و`fallbackLocale` واللغات المعطّلة).

```ts
const { strategy, localeCookie } = useNuxtApp().$getI18nConfig()
```

## الترجمة {#translation}

### `$t` {#$t}

```ts
TranslationFn<CleanTranslation>
```

ترجمة مفتاح، مع إدراج `params` فيه. تُرجع `defaultValue` عندما يكون المفتاح
مفقودًا، أو المفتاح نفسه عند عدم تقديم قيمة افتراضية.

```ts
// { "welcome": "Welcome, {name}!" }
$t('welcome', { name: 'Ada' }) // 'Welcome, Ada!'
$t('missing.key', {}, 'Fallback') // 'Fallback'
```

المفتاح الذي يشير إلى كائن متداخل يُرجع ذلك الكائن، لا سلسلة نصية. في القالب يُعرض على أنه `[object Object]`؛ استخدم مفتاحًا طرفيًا (leaf).

### `$ts` {#$ts}

```ts
TranslationFn<string>
```

مثل `$t`، لكنها تُرجع سلسلة نصية دائمًا: تمر القيمة عبر `toString()`، لذا يصبح الكائن
المتداخل `'[object Object]'`. اجعل المفتاح يشير إلى عنصر طرفي.

### `$_t` {#$_t}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<CleanTranslation>
```

ربط `$t` بمسار محدد، للترجمة خارج الصفحة الحالية — كتخطيط (layout) يعرض
رابطًا إلى مسار آخر مثلًا.

```ts
const route = useRoute()
const t = useNuxtApp().$_t(route)
t('page.title')
```

### `$_ts` {#$_ts}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<string>
```

ربط `$ts` بمسار محدد. راجع `$_t`.

### `$tc` {#$tc}

```ts
(key: TranslationKey, params: number | Params, defaultValue?: string) => string
```

الترجمة مع صيغ الجمع. يمكن أن تكون `params` هي العدد نفسه، أو كائنًا يحتوي على
`count`.

تُفصل الصيغ بالرمز `|`. مع القاعدة المدمجة، يختار العدد الصحيح غير السالب `n` الصيغة رقم `n`، مع حدّه عند آخر صيغة؛ أما العدد السالب أو الكسري أو `NaN` فيأخذ آخر صيغة. يُدرج `{count}` والمعاملات الأخرى في الصيغة المختارة.

للغات التي لا تتبع صيغ الجمع فيها العدد مباشرة، ابدأ القالب بـ `=0 `. تكون الصيغة الأولى حينها للصفر، وتتبع البقية فئات [`Intl.PluralRules`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/PluralRules) بالترتيب `zero, one, two, few, many, other`:

```json
{
  "apples": "=0 no apples | one apple | {count} apples",
  "files": "=0 no files | {count} one | {count} few | {count} many"
}
```

```ts
$tc('apples', 0) // 'no apples'
$tc('apples', 1) // 'one apple'
$tc('apples', 7) // '7 apples'

// In `uk` (categories `one, few, many, other`) the forms after the zero form follow those categories:
$tc('files', 21) // '21 one'
$tc('files', 22) // '22 few'
$tc('files', 25) // '25 many'
$tc('files', 2.5) // '2.5 many': no form for `other`, so the last one
```

- لا يُحتسب `=0 ` إلا في بداية القيمة تمامًا، مع المسافة. يعرضه `$t` كنص: فهو خاص بصيغ الجمع.
- الفئة التي ليست لها صيغة خاصة تأخذ آخر صيغة. وكذلك يأخذ العدد السالب أو الكسري آخر صيغة.
- يعمل في أي لغة: `=0 none | one | {count} many` في الإنجليزية.
- تأتي الفئة من قيمة `iso` للغة، وإلا من رمزها. الرمز الذي لا يعرفه `Intl` يرجع إلى قاعدة الفهرس، مع إزالة العلامة رغم ذلك، لذا لا تعتمد النتيجة أبدًا على الجهاز.
- يتبع `<i18n-t :plural>` القاعدة نفسها. تتلقى [`plural`](/ar/api/module-options#plural) المخصصة أو `customPluralRule` القيمة الخام، بما فيها العلامة، وتقرر بنفسها؛ وإذا أرجعت `plural` القيمة `null` يُعاد الاستدعاء إلى القاعدة المدمجة، التي تحترم العلامة.

بدون العلامة يبقى القالب على قاعدة الفهرس، مع استثناء واحد لا يُقرأ إلا بطريقة واحدة: صيغة صفر بلا عنصر نائب، ثم صيغة واحدة لكل فئة، مع `{count}` في كل صيغة تتشاركها عدة أعداد (`no files | {count} one | {count} few | {count} many` في `uk`).

لقواعدك الخاصة اضبط [`plural`](/ar/api/module-options#plural).

```ts
// { "apples": "no apples | one apple | {count} apples" }
$tc('apples', 0) // 'no apples'
$tc('apples', 10) // '10 apples'
$tc('cart', { count: 2, name: 'Ada' }) // count and params in one object
```

الوسيط الثالث هو `defaultValue`، وليس المعاملات.

### `$has` {#$has}

```ts
(key: string) => boolean
```

هل يُحلَّل المفتاح في اللغة النشطة. استخدمها للتفرّع بناءً على نص اختياري بدلًا من
عرض مفتاح خام. ومثل `$t`، ترى أيضًا مفاتيح الصفحة المغادَرة أثناء الانتقال بين
صفحات باللغة نفسها.

```ts
if ($has('promo.banner')) show.value = true
```

## التنسيق {#formatting}

### `$tn` {#$tn}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

تنسيق رقم باستخدام `Intl.NumberFormat` في اللغة النشطة. يختار المفتاح تنسيقًا مسمّى
من الإعدادات.

تأتي التنسيقات المسمّاة من [`numberFormats`](/ar/api/module-options#numberformats).

```ts
$tn(1234.5, { style: 'currency', currency: 'EUR' }) // '1.234,50 €' in de
$tn(1000, 'currency') // named format
$tn(1000, 'currency', 'de') // named format in another locale
```

### `$td` {#$td}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

تنسيق تاريخ باستخدام `Intl.DateTimeFormat` في اللغة النشطة. يختار المفتاح تنسيقًا مسمّى
من الإعدادات.

تأتي التنسيقات المسمّاة من [`datetimeFormats`](/ar/api/module-options#datetimeformats).

```ts
$td(new Date(), { dateStyle: 'long' })
$td(post.createdAt, 'short')
```

### `$tdr` {#$tdr}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

تنسيق تاريخ كوقت نسبي ("قبل 3 أيام") باستخدام `Intl.RelativeTimeFormat`.

```ts
$tdr(Date.now() - 5 * 60_000) // '5 minutes ago' in en
```

## التبديل والروابط {#switching-and-links}

### `$switchLocale` {#$switchlocale}

```ts
(locale: string) => Promise<boolean>
```

الانتقال إلى الصفحة الحالية بلغة أخرى. في `no_prefix` ووضع hash تُحمِّل ترجمات
اللغة قبل الانتقال؛ وفي `no_prefix` يُستبدل المسار في مكانه (دون
إدخال جديد في السجل). تُتجاهل اللغة غير المعروفة.
الاستدعاء غير متزامن: استخدم `await` لتشغيل شيفرة بعد الانتقال. يُحَل بالقيمة `true` عندما يكون
قاموس اللغة نشطًا، و`false` عندما لا يكون كذلك: فشل تحميل الجزء (يبقى القاموس
الحالي؛ استدعها مجددًا لإعادة المحاولة) أو فاز تبديل أحدث.

```ts
await $switchLocale('de')
```

### `$switchLocalePath` {#$switchlocalepath}

```ts
(locale: string) => string
```

مسار الصفحة الحالية بلغة أخرى، دون انتقال.

```vue
<NuxtLink :to="$switchLocalePath('de')">Deutsch</NuxtLink>
```

### `$switchLocaleRoute` {#$switchlocaleroute}

```ts
(locale: string) => RouteLocationRaw
```

كائن المسار للصفحة الحالية بلغة أخرى، دون انتقال، أو سلسلة URL
للغة لها `baseUrl` خاص بها. مع `trailingSlash` يحتوي الكائن على `path` و`fullPath`،
وفق القاعدة، مع `query` و`hash` كما هما، ويحتفظ بهما `router.push` أو الرابط.

### `$switchRoute` {#$switchroute}

```ts
(route: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, toLocale?: string) => Promise<void>
```

الانتقال إلى مسار آخر، مع الإبقاء على اللغة النشطة أو التبديل إلى `toLocale`. غير متزامنة مثل
`$switchLocale`.

```ts
$switchRoute('/about') // active locale
$switchRoute({ name: 'about' }, 'de') // switch to de
```

### `$localePath` {#$localepath}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => string
```

تحليل مسار في اللغة المحددة، أو في اللغة النشطة. السلسلة ذات المخطط `http(s):` أو `mailto:`
أو `tel:` تُعاد كما هي: لا تمرّر مدخلات المستخدم كهدف للرابط دون التحقق منها.

يُقرأ المسار النصي على أنه الصفحة التي يعرضها، لذا يُطبَّق المسار المخصص للغة أيضًا.

```ts
$localePath('/about') // '/about' in en, '/de/ueber-uns' in de with localeRoutes
$localePath({ name: 'about' }, 'fr') // '/fr/about'
```

### `$localeRoute` {#$localeroute}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => RouteLocationResolved
```

تحليل مسار (route) في اللغة المحددة، أو في اللغة النشطة. كائن عادي، آمن للاحتفاظ به في الحالة. عندما يحتاج أحد المعاملات إلى
تهريب، يحتوي الكائن على `path` و`fullPath` و`query` و`hash` لكن دون `name` أو `params`: فالمسار هو ما يمنح الموجّه
عنوان URL المُرمَّز. وللغة على نطاق آخر يكون `path` و`fullPath` مطلقين، وهو ما لا يقبله الموجّه:
مثل هذا الرابط يمر عبر `<i18n-link>`، أو `$localePath`.

### `$getRouteName` {#$getroutename}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric, locale?: string) => string
```

اسم المسار بعد إزالة بادئة اللغة — وهو الاسم الذي تُفهرَس به الترجمات.

```ts
$getRouteName() // 'about' on /de/about
```

## إعدادات الصفحة {#page-config}

### `$defineI18nRoute` {#$definei18nroute}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

تسجيل إعدادات اللغة والترجمات لكل صفحة من داخل مكوّن.
تُدمج في اللغة النشطة ويُعاد تطبيقها عند تغيّر اللغة.

استدعها في `<script setup>` الخاص بالصفحة، مع تفكيكها دائمًا من `useNuxtApp()`. تقرأ عملية البناء `locales` و`localeRoutes` و`disableMeta` من الاستدعاء؛ وفي وقت التشغيل لا يهم سوى `locales` (تُدمج الترجمات المضمّنة للغة النشطة). القواعد الكاملة: [إعدادات الصفحة](/ar/guide/per-component-translations).

```vue
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'de'],
  localeRoutes: { en: '/about', de: '/ueber-uns' },
})
</script>
```

### `$setI18nRouteParams` {#$seti18nrouteparams}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

تعيين معاملات لكل لغة للمسار الحالي، بحيث يمكن أن يختلف المقطع الديناميكي حسب اللغة.
استدعها أثناء SSR، قبل عرض الـ head.

تُمسح المعاملات عند اعتماد انتقال إلى مسار آخر، بما في ذلك من `/news/1` إلى `/news/4`، الذي يحتفظ باسم المسار. التفاصيل: [المسارات المترجمة](/ar/guide/custom-locale-routes).

```ts
$setI18nRouteParams({
  en: { slug: 'my-post' },
  de: { slug: 'mein-beitrag' },
})
```

## ترجمات وقت التشغيل {#runtime-translations}

### `$mergeTranslations` {#$mergetranslations}

```ts
(newTranslations: Translations) => void
```

دمج ترجمات في اللغة النشطة في وقت التشغيل، مع تجاوز ما هو محمَّل.

تدمج دمجًا عميقًا في جزء الصفحة الحالية للغة النشطة؛ وتبقى المفاتيح التي لا تذكرها.

```ts
$mergeTranslations({ banner: { title: 'Sale' } })
```

### `$setTranslation` {#$settranslation}

```ts
(key: string, value: unknown) => void
```

استبدال القيمة عند `key` في القاموس النشط. هذا استبدال، وليس دمجًا —
استخدم `$mergeTranslations` عندما يجب أن تبقى العناصر الشقيقة الموجودة.

```ts
$setTranslation('banner', { title: 'Sale' }) // drops other keys under banner
$setTranslation('banner.title', 'Sale') // dotted path
```

### `$loadPageTranslations` {#$loadpagetranslations}

```ts
(locale: string, routeName: string, translations: Translations) => Promise<void>
```

تحميل ترجمات صفحة في وقت التشغيل، للمحتوى الذي لا تُعرف مفاتيحه وقت البناء.

تُدمج في الجزء `(locale, routeName)` الموجود في الذاكرة، وتتحدّث الشاشة عندما يكون ذلك الجزء نشطًا. لا تُجلب أي حمولة هنا: بالنسبة لصفحة لم تُحمَّل بعد تنتظر الترجمات، وعند تحميل ملفها تبقى فوقه.

```ts
await $loadPageTranslations('en', 'about', { title: 'About us' })
```

### `$resolveTranslations` {#$resolvetranslations}

```ts
() => Translations
```

كل الترجمات الموجودة حاليًا في الذاكرة للغة والمسار النشطين، على شكل شجرة.
عرض للقراءة فقط لما يستطيع `$t()` تحليله الآن.

تعامل مع النتيجة على أنها للقراءة فقط.

### `$setMissingHandler` {#$setmissinghandler}

```ts
(handler: MissingHandler | null) => void
```

تثبيت دالة رد نداء تُستدعى لكل مفتاح لم يُحلَّل. مرّر `null` لإزالتها.

تعمل الدالة بدلًا من تحذير وضع التطوير.

```ts
$setMissingHandler((locale, key, routeName) => {
  console.error(`[i18n] missing ${key} in ${locale} (${routeName})`)
})
```

### `$clearCache` {#$clearcache}

```ts
() => void
```

حذف كل أجزاء الترجمة المخزّنة مؤقتًا وإعادة تحميل قاموس الصفحة الحالية. تستمر الصفحة
في عرض ترجماتها الحالية حتى تصل الترجمات الجديدة. يستدعيها HMR في وضع التطوير عند
كل تغيير في ملفات الترجمة.

```ts
const { clearCache } = useI18n()
clearCache()
```

يُبقي فشل إعادة التحميل القاموس الحالي.
