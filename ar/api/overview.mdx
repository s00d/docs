# مرجع API

## واجهة برمجة وقت التشغيل

- [الدوال](/api/methods) — `$t` و`$ts` و`$_t` و`$_ts` وتبديل اللغة ومساعدات التوجيه
- [الأحداث](/api/events) — `i18n:register` و`i18n:beforeLocaleSwitch` و`i18n:afterLocaleSwitch`
- [الترجمات والتخزين المؤقت](/api/cache) — `TranslationStorage` وتحميل الحمولات و`$clearCache`

## وسيط الخادم (Middleware)

يستخدم معالجو الخادم وسيطًا مخصصًا (وليس دوال العميل `$t`):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — الترجمة في مسارات API ومعالجات الخادم
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — قراءة اللغة المكتشفة وبياناتها الوصفية

اطّلع على دليل [الترجمات من جانب الخادم](/guides/server-side-translations) الكامل للحصول على الإعداد وأولوية اكتشاف اللغة والأمثلة.

## ذات صلة

- [Composables](/api/overview) — `useI18n` و`useI18nLocale` و`useLocaleHead`
- [مرجع الإعدادات](/guides/configuration) — جميع خيارات وحدة `i18n`
