# مرجع API

## واجهة API لوقت التشغيل

- [الدوال](/api/methods) — `$t` و `$ts` و `$_t` و `$_ts` وتبديل اللغة ومساعدات التوجيه
- [الأحداث](/api/events) — `i18n:register` و `i18n:beforeLocaleSwitch` و `i18n:afterLocaleSwitch`
- [الترجمات وذاكرة التخزين المؤقت](/api/cache) — `TranslationStorage` وتحميل الحمولات و `$clearCache`

## Middleware من جانب الخادم

تستخدم معالجات الخادم middleware مخصصاً (وليس مساعدات `$t` من جانب العميل):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — للترجمة في مسارات API ومعالجات الخادم
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — لقراءة اللغة المكتشفة والبيانات الوصفية

راجع دليل [الترجمات من جانب الخادم](/guides/server-side-translations) الكامل للحصول على الإعداد وأولوية اكتشاف اللغة وأمثلة.
