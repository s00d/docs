---

يسرد هذا القسم كل خيار ودالة مساعدة وخطاف و composable ومكون في وحدة Nuxt، بالإضافة إلى واجهة API المُصدَّرة لكل حزمة `@i18n-micro/*`. استخدمه للبحث عن توقيع دالة أو قيمة افتراضية؛ أما [الدليل](/ar/guide/getting-started) فيشرح كيفية استخدامها. معظم الجداول هنا مُولَّدة من الشيفرة المصدرية، لذا فهي مطابقة للكود.

## وحدة Nuxt {#nuxt-module}

| الصفحة | تغطي |
| --- | --- |
| [خيارات الوحدة](/ar/api/module-options) | كل مفتاح `i18n` في `nuxt.config`، مع النوع والقيمة الافتراضية |
| [الدوال المساعدة](/ar/api/methods) | `$t` و`$tc` و`$tn` و`$td` و`$localePath` و`$switchLocale` و`$defineI18nRoute` وغيرها |
| [الخطافات](/ar/api/events) | خطاف وقت التشغيل `i18n:register` |

## Composables {#composables}

| Composable | استخدمه من أجل |
| --- | --- |
| [`useI18n`](/ar/composables/useI18n) | الدوال المساعدة داخل `<script setup>` |
| [`useI18nLocale`](/ar/composables/useI18nLocale) | حالة اللغة المحلية وملف تعريف الارتباط في إضافة اكتشاف مخصصة |
| [`useI18nHead`](/ar/composables/useI18nHead) | تجاوزات وسوم SEO المُولَّدة لكل صفحة |
| [`useLocaleHead`](/ar/composables/useLocaleHead) | وسوم SEO ككائن، لاستخدامها في `useHead` الخاص بك |

## المكونات {#components}

| المكون | يعرض |
| --- | --- |
| [`<i18n-t>`](/ar/components/i18n-t) | ترجمة واحدة، مع صيغ الجمع والتنسيق والاستيفاء عبر الـ slots |
| [`<i18n-link>`](/ar/components/i18n-link) | رابط `NuxtLink` إلى المسار المترجم |
| [`<i18n-switcher>`](/ar/components/i18n-switcher) | قائمة منسدلة للغات المحلية |
| [`<i18n-group>`](/ar/components/i18n-group) | كتلة ذات بادئة مفاتيح مشتركة |

## الخادم {#server}

تستخدم معالجات Nitro كلًّا من `useTranslationServerMiddleware` و`useLocaleServerMiddleware`، وليس الدوال المساعدة الخاصة بالعميل. راجع [مسارات الخادم](/ar/guide/server-side-translations).

## الحزم {#packages}

تسرد صفحة [واجهات API للحزم](/ar/api/packages/overview) صادرات كل حزمة `@i18n-micro/*`، بصفحة مُولَّدة لكل منها.
