يعرض [دليل CLI](/ar/guide/cli) سير العمل الشائع. أما هذه الصفحة فتسرد كل شيء، وهي مولَّدة من الجدول نفسه الذي يغذّي `--help`.

## الخيارات المشتركة {#common-flags}

| الخيار | الافتراضي | الوصف |
| --- | --- | --- |
| `--cwd` | المجلد الحالي | مجلد المشروع |
| `--logLevel` | `info` | مستوى المخرجات: silent، info |
| `--debug` | `false` | طباعة تتبّع المكدس عند فشل أمر ما |

## الفحص {#inspect}

### `info` {#info}

طباعة إعدادات i18n المحلولة للمشروع

| الخيار | الافتراضي | الوصف |
| --- | --- | --- |
| `--json` | `false` | طباعة JSON بدلًا من النص |

### `check` {#check}

بوابة CI: الفشل عند وجود مفاتيح مفقودة أو فارغة أو زائدة أو غير معرَّفة أو غير مستخدمة، أو عناصر نائبة معطوبة

| الخيار | الافتراضي | الوصف |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` من nuxt.config | مجلد الترجمات، نسبةً إلى المشروع |
| `--only` | الكل باستثناء التكرارات | فحوص مفصولة بفواصل لتشغيلها: missing، empty، extra، placeholders، undefined، unused، duplicates. ذكر `unused` هنا يؤدي إلى الفشل حين يتعذّر تشغيله |
| `--duplicates` | `false` | الإبلاغ أيضًا عن النص نفسه تحت مفاتيح مختلفة |
| `--ignore` | — | أنماط glob مفصولة بفواصل لملفات المصدر المراد تخطّيها، نسبةً إلى المشروع |
| `--json` | `false` | طباعة JSON بدلًا من النص |

```bash
i18n-micro check
i18n-micro check --only missing,placeholders --json
```

### `stats` {#stats}

عرض نسبة اكتمال الترجمة لكل لغة

| الخيار | الافتراضي | الوصف |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` من nuxt.config | مجلد الترجمات، نسبةً إلى المشروع |
| `--html` | — | كتابة تقرير HTML أيضًا في هذا الملف |
| `--json` | `false` | طباعة JSON بدلًا من النص |
| `--baseRef` | — | مرجع Git لمقارنة نسبة الاكتمال به، مثل HEAD~1 أو main |

```bash
i18n-micro stats --baseRef main
i18n-micro stats --html reports/i18n.html
```

### `lint` {#lint}

فحص نصوص الترجمات؛ يفشل عند بقاء مشكلات

| الخيار | الافتراضي | الوصف |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` من nuxt.config | مجلد الترجمات، نسبةً إلى المشروع |
| `--rules` | الكل، أو `enabledRules` من .i18n-lintrc.json | قواعد مفصولة بفواصل لتشغيلها: no-trailing-spaces، no-multiple-spaces، no-empty-translation، أو قاعدة مخصصة |
| `--fix` | `false` | إصلاح ما يمكن إصلاحه: المسافات، والقواعد المخصصة التي لها بديل |
| `--json` | `false` | طباعة JSON بدلًا من النص |

```bash
i18n-micro lint --rules no-trailing-spaces --fix
```

### `search` {#search}

البحث في المفاتيح والقيم، وعرض مواضع استخدام كل مفتاح

| الخيار | الافتراضي | الوصف |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` من nuxt.config | مجلد الترجمات، نسبةً إلى المشروع |
| `<query>` | — | النص أو المفتاح المراد البحث عنه |
| `--caseSensitive` | `false` | مطابقة حالة الأحرف |
| `--onlyUnused` | `false` | المفاتيح التي سيزيلها `clean` فقط؛ ويصبح الاستعلام اختياريًا |
| `--scope` | `all` | مكان البحث: global، pages، all |
| `--limit` | — | إرجاع هذا العدد من المفاتيح على الأكثر |
| `--ignore` | — | أنماط glob مفصولة بفواصل لملفات المصدر المراد تخطّيها، نسبةً إلى المشروع |
| `--json` | `false` | طباعة JSON بدلًا من النص |

```bash
i18n-micro search "Welcome"
i18n-micro search --onlyUnused
```

## سير عمل الترجمة {#translation-workflow}

### `extract` {#extract}

سرد المفاتيح التي تستخدمها ملفات المصدر ولا نص لها بعد، وإضافة ما له نص افتراضي منها إلى اللغة الافتراضية

| الخيار | الافتراضي | الوصف |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` من nuxt.config | مجلد الترجمات، نسبةً إلى المشروع |
| `--ignore` | — | أنماط glob مفصولة بفواصل لملفات المصدر المراد تخطّيها، نسبةً إلى المشروع |

```bash
i18n-micro extract
```

### `translate` {#translate}

ملء الترجمات المفقودة انطلاقًا من اللغة الافتراضية عبر خدمة ترجمة

| الخيار | الافتراضي | الوصف |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` من nuxt.config | مجلد الترجمات، نسبةً إلى المشروع |
| `--service` | — | خدمة الترجمة: ai، azure، deepl، google، libretranslate، yandexcloud |
| `--token` | — | مفتاح API. يُفضَّل استخدام متغير البيئة I18N_TRANSLATE_TOKEN: فالخيارات تنتهي في سجل الصدفة |
| `--options` | — | خيارات الخدمة على شكل أزواج key:value، مفصولة بفواصل |
| `--locale` | كل اللغات باستثناء الافتراضية | لغات مفصولة بفواصل لملئها |
| `--replace` | `false` | ترجمة كل مفتاح من جديد، مع استبدال القيم الموجودة |
| `--dryRun` | `false` | عدّ المفاتيح والأحرف لكل لغة؛ دون إرسال أي شيء |
| `--chunkSize` | — | عدد السلاسل في كل طلب؛ بحدٍّ أقصى هو ما تقبله الخدمة |
| `--pluralSeparator` | `\|` | فاصل صيغ الجمع في الرسائل |
| `--glossaryFile` | `.i18n-glossary.json` عند وجوده | ملف المسرد، تستخدمه خدمة `ai` |

```bash
i18n-micro translate --dryRun
I18N_TRANSLATE_TOKEN=... i18n-micro translate --service deepl --locale de,fr
i18n-micro translate --service ai --options provider:openai,model:gpt-4o-mini
i18n-micro translate --service libretranslate --options baseUrl:https://translate.example.com
```

### `sync` {#sync}

إزالة المفاتيح غير الموجودة في اللغة الافتراضية؛ ويتوقف حين يتعذّر إثبات أمان ذلك. تبقى المفاتيح المفقودة مفقودة

| الخيار | الافتراضي | الوصف |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` من nuxt.config | مجلد الترجمات، نسبةً إلى المشروع |
| `--ignore` | — | أنماط glob مفصولة بفواصل لملفات المصدر المراد تخطّيها، نسبةً إلى المشروع |
| `--dryRun` | `false` | سرد ما ستتم إزالته؛ دون كتابة أي شيء |
| `--force` | `false` | إزالة المفاتيح حتى لو تعذّر إثبات أمان ذلك |

```bash
i18n-micro sync --dryRun
```

### `clean` {#clean}

إزالة المفاتيح التي لا يستخدمها شيء في المشروع؛ ويتوقف حين يتعذّر إثبات ذلك

| الخيار | الافتراضي | الوصف |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` من nuxt.config | مجلد الترجمات، نسبةً إلى المشروع |
| `--include` | — | تعبير نمطي: لا يُنظر في إزالة إلا المفاتيح المطابقة |
| `--exclude` | — | تعبير نمطي: لا تُزال المفاتيح المطابقة أبدًا |
| `--ignore` | — | أنماط glob مفصولة بفواصل لملفات المصدر المراد تخطّيها، نسبةً إلى المشروع |
| `--dryRun` | `false` | سرد ما ستتم إزالته؛ دون كتابة أي شيء |
| `--force` | `false` | إزالة المفاتيح حتى لو تعذّر إثبات استخدامها جميعًا |

```bash
i18n-micro clean --dryRun
i18n-micro clean --exclude '^errors\.'
```

## إعادة الهيكلة {#refactoring}

### `text-to-i18n` {#text-to-i18n}

استبدال النصوص المكتوبة مباشرة في قوالب Vue باستدعاءات ترجمة، والإبلاغ عن النصوص المكتوبة مباشرة في الشيفرة

| الخيار | الافتراضي | الوصف |
| --- | --- | --- |
| `--translationFile` | `<translationDir>/<defaultLocale>.json` | الملف الذي تُضاف إليه المفاتيح الجديدة |
| `--path` | المشروع بأكمله | الملف أو المجلد المراد معالجته |
| `--context` | — | بادئة للمفاتيح المولَّدة |
| `--ignore` | — | أنماط glob مفصولة بفواصل لملفات المصدر المراد تخطّيها، نسبةً إلى المشروع |
| `--dryRun` | `false` | عرض ما سيتغيّر؛ دون كتابة أي شيء |
| `--interactive` | `false` | تأكيد أو تعديل كل مفتاح مولَّد |

```bash
i18n-micro text-to-i18n --dryRun
i18n-micro text-to-i18n --path components --context ui
```

### `rename` {#rename}

إعادة تسمية مفتاح أو مساحة أسماء في كل اللغات وفي ملفات المصدر

| الخيار | الافتراضي | الوصف |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` من nuxt.config | مجلد الترجمات، نسبةً إلى المشروع |
| `--from` **\*** | — | المفتاح أو مساحة الأسماء الحالية |
| `--to` **\*** | — | المفتاح أو مساحة الأسماء الجديدة |
| `--ignore` | — | أنماط glob مفصولة بفواصل لملفات المصدر المراد تخطّيها، نسبةً إلى المشروع |
| `--dryRun` | `false` | الإبلاغ عن التغييرات؛ دون كتابة أي شيء |

**\*** مطلوب.

```bash
i18n-micro rename --from common.save --to actions.save
```

### `pseudo` {#pseudo}

ملء لغة بترجمات زائفة للعثور على مشكلات التخطيط والنصوص المكتوبة مباشرة

| الخيار | الافتراضي | الوصف |
| --- | --- | --- |

| `--targetLocale` **\*** | — | اللغة المراد ملؤها |
| `--replace` | `false` | الكتابة فوق القيم الموجودة |

**\*** مطلوب.

### `format` {#format}

إعادة كتابة ملفات اللغات بمفاتيح مرتبة ومسافات بادئة موحّدة

| الخيار | الافتراضي | الوصف |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` من nuxt.config | مجلد الترجمات، نسبةً إلى المشروع |

## التبادل {#exchange}

### `export` {#export}

تصدير ملفات اللغات إلى PO أو CSV، مع نص اللغة الافتراضية بوصفه المصدر

| الخيار | الافتراضي | الوصف |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` من nuxt.config | مجلد الترجمات، نسبةً إلى المشروع |
| `--format` | `po` | صيغة الملف: po، csv |
| `--dir` | `pots` لـ po، و`csv_exports` لـ csv | مجلد المخرجات، نسبةً إلى المشروع |
| `--force` | `false` | الكتابة فوق الملفات التي تغيّرت منذ آخر تصدير ولم تُستورد قط |

```bash
i18n-micro export --format csv
```

### `import` {#import}

دمج ملفات PO أو CSV في ملفات اللغات

| الخيار | الافتراضي | الوصف |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` من nuxt.config | مجلد الترجمات، نسبةً إلى المشروع |
| `--format` | `po` | صيغة الملف: po، csv |
| `--dir` | `pots` لـ po، و`csv_exports` لـ csv | مجلد المدخلات، نسبةً إلى المشروع |
| `--dryRun` | `false` | الإبلاغ عمّا سيُستورد؛ دون كتابة أي شيء |

```bash
i18n-micro import --format csv --dryRun
```

### `sync-remote` {#sync-remote}

سحب الترجمات العامة من نقطة نهاية HTTP المحددة في .i18n-remote.json، أو دفعها إليها

| الخيار | الافتراضي | الوصف |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` من nuxt.config | مجلد الترجمات، نسبةً إلى المشروع |
| `--pull` | `true` | السحب من المصدر البعيد |
| `--push` | `false` | الدفع إلى المصدر البعيد |
| `--force` | `false` | عند السحب، اعتماد القيمة البعيدة؛ وعند الدفع، الكتابة فوق النص الموجود في المصدر البعيد وحده |
| `--dryRun` | `false` | الإبلاغ عمّا سيغيّره السحب؛ دون كتابة أو دفع أي شيء |

```bash
i18n-micro sync-remote --dryRun
i18n-micro sync-remote --no-pull --push
```

## قواعد الفحص اللغوي {#lint-rules}

| القاعدة | ما تكتشفه | يُصلحها `--fix` |
| --- | --- | --- |
| `no-trailing-spaces` | مسافات في نهاية قيمة أو سطر | نعم |
| `no-multiple-spaces` | مسافتان أو أكثر متتاليتان | نعم |
| `no-empty-translation` | قيمة فارغة أو خالية | لا |

## رموز الخروج {#exit-codes}

| الرمز | المعنى |
| --- | --- |
| `0` | تم، لا شيء للإبلاغ عنه |
| `1` | نتائج: وجد `check` أو `lint` أو `format --check` شيئًا، أو تعذّر على `clean` أو `sync` إثبات أمان الإزالة، أو كان `export` سيكتب فوق عمل غير مستورد، أو ترك `translate` مفاتيح دون ترجمة، أو واجه `import` أو `sync-remote` تعارضًا، أو كان دفع `sync-remote` سيُسقط نصًا بعيدًا. يُبلغ `--dryRun` الخاص بـ `clean` أو `sync` أو سحب `sync-remote` عن هذه الحالات ويخرج بالرمز `0` |
| `2` | فشل: استخدام خاطئ، أو مشروع غير قابل للقراءة، أو خطأ في الشبكة أو الملفات |

## ملفات الإعداد {#configuration-files}

| الملف | يستخدمه |
| --- | --- |
| `.i18n-lintrc.json` | `lint`: `enabledRules`، `disabledRules`، `customRegexRules` (`name`، `pattern`، `flags`، `description`، `replacement`) |
| `.i18n-remote.json` | `sync-remote`: `url`، `path`، `token`، `auth` (`username`، `password`). يمكن حذف `type`؛ إذ لا يوجد سوى `custom` |
| `.i18n-glossary.json` | `translate --service ai`: `entries` تتكون من `source` و`target`، و`from` و`to` اختياريين |

## متغيرات البيئة {#environment-variables}

| الاسم | يُستخدم لـ |
| --- | --- |
| `I18N_TRANSLATE_TOKEN` | مفتاح API الخاص بـ `translate`. يُقرأ من `.env` أيضًا |
| `I18N_REMOTE_TOKEN` | رمز Bearer الخاص بـ `sync-remote`. يُقرأ من `.env` أيضًا |
| `AI_GATEWAY_API_KEY, OPENAI_API_KEY, ANTHROPIC_API_KEY` | مفتاح خدمة `ai`، عندما لا يكون `I18N_TRANSLATE_TOKEN` معيَّنًا |
| `DEFAULT_LOCALE` | يتجاوز `defaultLocale`، كما في الوحدة |
