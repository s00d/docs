# 🌍 مكوّن `<i18n-switcher>`

يوفّر مكوّن `<i18n-switcher>` في `Nuxt I18n Micro` واجهة قائمة منسدلة سهلة الاستخدام للتبديل بين اللغات المختلفة في تطبيقك. هذا المكوّن قابل للتخصيص بشكل كبير، مما يسمح بتكامل سلس مع تصميم تطبيقك وتخطيطه.

اللغات ذات `disabled: true` **تُستبعد** من القائمة المنسدلة (تظل متاحة عبر `$getLocales()` لأغراض SEO / وسوم head). تحصل اللغات القابلة للتبديل فقط على `NuxtLink` + `hreflang`.

## 🛠️ أمثلة الاستخدام

### الاستخدام الأساسي

```vue
<template>
  <i18n-switcher />
</template>
```

يعرض هذا مبدّل لغات بتنسيق وسلوك افتراضيين.

### تسميات مخصصة وأنماط مضمَّنة

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

يوضّح هذا المثال مبدّل لغات مخصصاً بالكامل مع تسميات مخصصة وأنماط مضمَّنة.

## 🔌 الفتحات (Slots)

يمكن استبدال كل جزء بصري من المبدّل. الفتحات مدرجة مع جدول الخصائص
أعلاه؛ كل واحدة تأخذ محتوى قالب:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

الفتحات التي ينتهي اسمها بـ `-item` أو `-link-content` أو يبدأ بـ `before-item` تتلقى
كائن `locale` الذي تنتمي إليه.

## 🎨 نظرة عامة على الأنماط

يأتي مكوّن `<i18n-switcher>` بأنماط أساسية معرَّفة باستخدام أنماط مضمَّنة يمكن تجاوزها بسهولة بتمرير أنماط مخصصة عبر الخصائص. إليك نظرة عامة موجزة على التنسيق الافتراضي:

- **الغلاف**: يتحكّم في تحديد موقع القائمة المنسدلة.
- **الزر**: ينسّق زر تبديل القائمة المنسدلة.
- **القائمة المنسدلة**: تنسّق قائمة القائمة المنسدلة.
- **العناصر**: تنسّق كل عنصر في القائمة.
- **الروابط**: تنسّق الروابط داخل كل عنصر.
- **الأيقونة**: تنسّق أيقونة مؤشّر القائمة المنسدلة.

يمكنك تخصيص هذه الأنماط بتمرير أنماط مخصصة عبر الخصائص المقابلة، مما يضمن اندماج مبدّل اللغة بسلاسة في واجهة مستخدم تطبيقك.
