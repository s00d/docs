# 🌍 مكوّن `<i18n-link>`

مكوّن `<i18n-link>` في `Nuxt I18n Micro` هو مكوّن رابط متعدد الاستخدامات يترجم المسارات تلقائياً بناءً على اللغة الحالية. يعمل كغلاف حول مكوّن `<NuxtLink>`، ويقدّم ميزات إضافية مثل تنسيق الرابط النشط ودعم الروابط الخارجية.

## ⚙️ الخصائص

{/* generated:component:i18n-link — do not edit; run `pnpm run docs:generate` */}

| الخاصية | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | المسار المستهدف. يُترجم تلقائياً؛ يُمرَّر URL خارجي دون تغيير. |
| `activeStyle` | `Partial<CSSStyleValue>` | — | نمط مضمَّن يُطبَّق عندما يشير الرابط إلى المسار الحالي. |

**\*** مطلوبة.

### الفتحات (Slots)

| الفتحة | الربط | الوصف |
| --- | --- | --- |
| `default` | — | محتوى الرابط. |

{/* /generated:component:i18n-link */}

يقبل `to` أي شيء يقبله `NuxtLink` — مسار، أو مسار مسمّى، أو كائن مسار محلول.
يُكتشف عنوان URL المطلق ويُعرض كـ `<a target="_blank" rel="noopener noreferrer">` عادي
بدلاً من ترجمته.

## 🛠️ أمثلة الاستخدام

### الاستخدام الأساسي

```vue
<i18n-link to="/about">About Us</i18n-link>
```

يُنشئ هذا المثال رابطاً إلى صفحة `/about`، مترجم إلى اللغة الحالية.

### تنسيق الرابط النشط بأنماط مضمَّنة

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

سيكون للرابط نص عريض عندما يكون المستخدم في صفحة `/about`، مما يسمح لك بتنسيق الرابط النشط مباشرةً بأنماط مضمَّنة.

### التعامل مع الروابط الخارجية

يكتشف المكوّن الروابط الخارجية تلقائياً ويضيف السمات اللازمة للأمان.

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

سيفتح هذا الرابط `https://example.com` في علامة تبويب جديدة مع تطبيق `rel="noopener noreferrer"`.

## 🎨 الأنماط

يستخدم المكوّن الآن أنماطاً مضمَّنة للحالة النشطة بدلاً من فئة. يمكنك تخصيص هذه الأنماط باستخدام الخاصية `activeStyle`.

### الأنماط النشطة الافتراضية

- **وزن الخط**: `bold`
- **اللون**: يرث اللون الافتراضي للمتصفح (إذا لم يُحدَّد `color` في `activeStyle`).

يمكنك تجاوزها بتقديم أنماط مخصصة عبر الخاصية `activeStyle`.

### أنماط نشطة مخصصة

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

في هذا المثال، سيكون الرابط عريضاً وأخضر عندما يكون نشطاً.

## 🚀 ميزات إضافية

### فتحة للمحتوى المخصص

يمكنك تمرير محتوى مخصص داخل الرابط باستخدام الفتحات، مما يجعل المكوّن مرناً لحالات استخدام مختلفة.

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### تحسينات الوصول

يدعم المكوّن `aria-label` وسمات وصول أخرى لضمان تجربة أكثر قابلية للوصول.

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
