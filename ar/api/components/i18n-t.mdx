# 🌍 مكوّن `<i18n-t>`

مكوّن `<i18n-t>` في `Nuxt I18n Micro` هو مكوّن ترجمة مرن يدعم إدخال المحتوى الديناميكي عبر الفتحات. يسمح لك باستكمال الترجمات مع مكوّنات Vue مخصصة أو محتوى HTML، مما يُمكّن سيناريوهات ترجمة متقدمة.

يُطبَّق واحد فقط من `plural` و `number` و `date` و `relativeDate` في المرة الواحدة؛ عندما تُضبط عدة
منها، تفوز الأولى في تلك القائمة.

### أمثلة لكل خاصية

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

```json
{
  "items": "Nothing|You have {count} item|You have {count} items"
}
```

\u0001\u0001\u0001## 🛠️ أمثلة الاستخدام

### الاستخدام الأساسي

```vue
<i18n-t keypath="feedback.text" />
```

يعرض هذا الترجمة لـ `feedback.text` داخل وسم `<span>`.

### استخدام الفتحات للمحتوى الديناميكي

يدعم مكوّن `<i18n-t>` استخدام الفتحات لإدخال مكوّنات Vue أو محتوى آخر ديناميكياً في أجزاء محددة من الترجمة.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

في هذا المثال، يُستبدل العنصر النائب `\{link\}` في سلسلة الترجمة `feedback.text` بمكوّن `<nuxt-link>`، الذي يحتوي بدوره على مكوّن ترجمة آخر.

### التعامل مع الجموع

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

يُطبّق هذا قواعد الجمع تلقائياً بناءً على قيمة `itemCount`.

## 🚀 ميزات إضافية

### الفتحة الافتراضية

إذا لم تُقدَّم فتحة محددة، يمكن تخصيص الترجمة عبر الفتحة الافتراضية، التي توفّر السلسلة المترجمة كاملة:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### العرض الشرطي

لا يعرض شيئاً إذا كانت سلسلة الترجمة فارغة باستخدام الخاصية `hideIfEmpty`.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### قاعدة جمع مخصصة

استخدم دالة مخصصة للتعامل مع الجموع.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### مثال متقدم مع الفتحات

استخدم الفتحات لتخصيص كيفية عرض محتوى الترجمة.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
