# 🌍 مكوّن `<i18n-group>`

يوفّر مكوّن `<i18n-group>` في Nuxt I18n Micro طريقة ملائمة لتجميع الترجمات تحت بادئة مشتركة، مما يقلّل التكرار ويحسّن تنظيم الشيفرة.

## ⚙️ الخصائص

{/* generated:component:i18n-group — do not edit; run `pnpm run docs:generate` */}

| الخاصية | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | بادئة المفتاح التي تُحلّ كل عمليات البحث داخل الفتحة مقابلها. |
| `groupClass` | `string` | `''` | فئة إضافية على عنصر الغلاف. |

**\*** مطلوبة.

### الفتحات (Slots)

| الفتحة | الربط | الوصف |
| --- | --- | --- |
| `default` | `prefix` و `t` | تتلقّى `prefix` ودالة `t` مقيّدة به. |

## 🎯 الفتحات (Slots)

تتلقّى الفتحة الافتراضية `prefix` ودالة `t` مقيّدة به، بحيث تُكتب المفاتيح داخلها
نسبةً إلى البادئة:

```vue
<i18n-group prefix="checkout">
  <template #default="{ t }">
    <h2>{{ t('title') }}</h2>
    <p>{{ t('summary', { count: 3 }) }}</p>
  </template>
</i18n-group>
```

## 🛠️ مثال الاستخدام

### الاستخدام الأساسي

```vue
<template>
  <i18n-group prefix="product.details">
    <template #default="{ t }">
      <h1>{{ t('title') }}</h1>
      <p>{{ t('description') }}</p>
      <div class="price">{{ t('price', { value: 99.99 }) }}</div>
    </template>
  </i18n-group>
</template>
```

ملف الترجمة:

```json
{
  "product": {
    "details": {
      "title": "Premium Product",
      "description": "This is a premium product",
      "price": "Price: ${value}"
    }
  }
}
```

### مع فئة مخصصة

```vue
<template>
  <i18n-group prefix="user.profile" group-class="profile-section">
    <template #default="{ t }">
      <div class="user-info">
        <h2>{{ t('title') }}</h2>
        <p>{{ t('bio') }}</p>
        <div class="stats">
          <span>{{ t('stats.followers') }}</span>
          <span>{{ t('stats.following') }}</span>
        </div>
      </div>
    </template>
  </i18n-group>
</template>
```

ملف الترجمة:

```json
{
  "user": {
    "profile": {
      "title": "User Profile",
      "bio": "User biography goes here",
      "stats": {
        "followers": "Followers: {count}",
        "following": "Following: {count}"
      }
    }
  }
}
```

### مع محتوى ديناميكي

```vue
<template>
  <i18n-group prefix="blog.post">
    <template #default="{ t }">
      <article>
        <h1>{{ t('title') }}</h1>
        <div class="meta">
          {{ t('meta.author', { name: author }) }} |
\u0001\u0001\u0001          {{ t('meta.date', { date: publishDate }) }}
        </div>
        <div v-for="(section, index) in sections" :key="index">
          <h2>{{ t(`sections.${index}.title`) }}</h2>
          <p>{{ t(`sections.${index}.content`) }}</p>
        </div>
      </article>
    </template>
  </i18n-group>
</template>

<script setup>
const author = 'John Doe'
const publishDate = '2024-01-01'
const sections = ['intro', 'main', 'conclusion']
</script>
```

## 🎨 التنسيق

يغلّف المكوّن محتواه في div بالفئة `i18n-group` وأي فئات إضافية محدّدة في الخاصية `groupClass`:

```css
.i18n-group {
  /* Your base styles */
}

.profile-section {
  /* Additional styles for profile sections */
}
```

## 🚀 أفضل الممارسات

1. **بادئات متسقة**: استخدم بادئات متّسقة ومنطقية تعكس بنية تطبيقك

```vue
<i18n-group prefix="features.pricing">
<i18n-group prefix="features.security">
```

2. **التنظيم النموذجي**: جمّع الترجمات ذات الصلة معاً تحت بادئات ذات معنى

```vue
<i18n-group prefix="checkout.payment">
<i18n-group prefix="checkout.shipping">
```

3. **مكوّنات قابلة لإعادة الاستخدام**: أنشئ مكوّنات قابلة لإعادة الاستخدام مع مجموعات ترجمة خاصة بها

```vue
<!-- UserProfile.vue -->
<i18n-group prefix="user.profile">

<!-- UserSettings.vue -->
<i18n-group prefix="user.settings">
```

4. **المجموعات المتداخلة**: تجنّب تعميق تداخل المجموعات للحفاظ على الوضوح

```vue
<!-- Good -->
<i18n-group prefix="shop.product">

<!-- Avoid -->
<i18n-group prefix="shop.category.product.details.specs">
```
