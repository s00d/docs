# useI18nLocale

## التوقيع

{/* generated:symbol:useI18nLocale — do not edit; run `pnpm run docs:generate` */}

```ts
useI18nLocale(): { getEffectiveLocale: (route: unknown, getLocaleFromRoute: GetLocaleFromRoute) => string; getLocale: () => string | null; getLocaleWithServerFallback: (serverLocale?: string | null) => string | null; getPreferredLocale: () => string | null; hashCookie: any; isValidLocale: (locale: string | null | undefined) => locale is string; locale: any; localeCookie: any; resolveInitialLocale: (options: ResolveInitialLocaleOptions) => string; setLocale: (locale: string | null) => void; syncLocale: (locale: string | null) => void; validLocales: string[] }
```

نقطة دخول مركزية لإدارة لغة i18n.
تجمع بين useState('i18n-locale')، وملف تعريف الارتباط للغة، وأدوات المزامنة.

## الاستخدام

```vue
<script setup>
const {
  locale,
  localeCookie,
  hashCookie,
  validLocales,
  getPreferredLocale,
  getLocale,
  getLocaleWithServerFallback,
  getEffectiveLocale,
  resolveInitialLocale,
  setLocale,
  syncLocale,
  isValidLocale,

// Set locale (updates state and cookies)

// Get current locale (state → cookie)

// Get valid preferred locale

</script>
```

## API

| الخاصية/الدالة                                 | النوع                                | الوصف                                                                          |
| ----------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------ |
| `locale`                                        | `Ref<string \| null>`               | حالة لغة تفاعلية (`useState('i18n-locale')`)                                    |
| `localeCookie`                                  | `Ref`                               | ملف تعريف ارتباط اللغة (عند تفعيل خيار `localeCookie`)                          |
| `hashCookie`                                    | `Ref`                               | ملف تعريف ارتباط يُستخدم عندما يكون `hashMode` نشطاً                            |
| `validLocales`                                  | `string[]`                          | رموز اللغات المفعّلة من تكوين الوحدة (يستبعد `disabled`)                        |
| `getLocale()`                                   | `() => string \| null`              | اللغة الحالية: الحالة ← ملف تعريف الارتباط (أو ملف تعريف ارتباط hash في وضع hash) |
| `getPreferredLocale()`                          | `() => string \| null`              | اللغة من الحالة/ملف تعريف الارتباط **مُتحقّق منها** مقابل `validLocales`، أو `null` |
| `getLocaleWithServerFallback(serverLocale?)`    | `(serverLocale?) => string \| null` | الحالة ← ملف تعريف الارتباط ← سياق الخادم الاختياري (يُستخدم أثناء تهيئة `no_prefix`) |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string`             | اللغة لتحميل الترجمات: يفضّل وضع hash الحالة؛ وإلا يقرأ من المسار |
| `resolveInitialLocale(options)`                 | `(options) => string`               | يحلّ اللغة: الحالة ← `serverLocale` ← المسار؛ يزامن الحالة عند الحاجة |
| `setLocale(locale)`                             | `(locale: string \| null) => void`  | تعيين اللغة ومزامنتها مع ملفات تعريف الارتباط |
| `syncLocale(locale)`                            | `(locale: string \| null) => void`  | مزامنة ملفات تعريف الارتباط فقط (بدون تحديث الحالة) |
| `isValidLocale(locale)`                         | `(locale) => boolean`               | التحقّق من وجود السلسلة في `validLocales` |

### خيارات `resolveInitialLocale`

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

تُستخدم داخلياً بواسطة الإضافة الرئيسية عند بدء التشغيل. يمكن للإضافات المخصصة استدعاؤها عند تنفيذ سير عمل كشف بديل.

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

تُرجع اللغة المستخدمة لتحميل الترجمات وتنسيق الرسائل لكائن مسار معيّن.

## تعيين اللغة برمجياً

فضّل `useI18nLocale()` على الاستخدام المباشر لـ `useState('i18n-locale')`:

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
تحدّث `setLocale()` تفضيل اللغة (الحالة + ملف تعريف الارتباط) فقط. لإعادة تحميل سياق الترجمة النشط على العميل أيضاً، استخدم `$switchLocale()` من `useNuxtApp()` أو `useI18n()`. هذا مهم بشكل خاص لـ `no_prefix`، حيث لا يتغيّر URL. راجع [الأسئلة الشائعة — تبديل اللغة دون تغيير URL](/guides/faq#-switch-locale-without-changing-the-url).
</Tip>
