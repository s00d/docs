# 🌍 الـ Composable `useLocaleHead`

الـ composable `useLocaleHead` هو أداة في `Nuxt I18n Micro` تساعدك على إدارة سمات SEO ووسوم HTML Meta للمسارات المترجمة. يولّد ديناميكياً سمات `lang` و `dir` لمستند HTML وينشئ وسوم `meta` و `link` لتحسين SEO لمحتواك المترجم.

## 🛠️ القيم المُرجعة

يُرجع الـ composable `useLocaleHead` كائناً تفاعلياً ودالة تحديث يجب استدعاؤها
عندما تتغيّر بيانات المصدر. كلا الشكلين في التوقيع أعلاه، مولَّدان من
المصدر.

### `metaObject`

حمولة head تفاعلية (سمات html و meta و link) مناسبة لـ `useHead(metaObject)`.

- **مثال**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

يعيد حساب `metaObject` بناءً على المسار الحالي واللغة والتكوين. استدعِها عندما تتغيّر
المدخلات — عند تغيير المسار، على سبيل المثال.

- **مثال**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### الوصول إلى `link` و `meta`

مصفوفتا `link` و `meta` متاحتان عبر `metaObject.value`:

- **مثال**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ أمثلة الاستخدام

### الاستخدام الأساسي

ولّد سمات head الخاصة باللغة مع الخيارات الافتراضية.

```js
const head = useLocaleHead()
```

### تخصيص سمة المعرّف

استخدم سمة معرّف مخصصة للوسوم المُولَّدة.

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### تعطيل سمات SEO

ولّد سمات head دون إضافة وسوم Meta و link ذات صلة بـ SEO.

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### تحديد URL أساسي

اضبط URL أساسياً مخصصاً لعناوين URL الأصلية والبديلة.

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 ميزات إضافية

### وسوم SEO Meta و link

عند تفعيل `addSeoAttributes`، يولّد الـ composable تلقائياً الوسوم التالية:

- `og:locale` للغة الحالية (`language_TERRITORY` مع شرطة سفلية). مشتقّة من `locale.og` أو محوّلة من `locale.iso` عندما يكون ذلك ممكناً.
- `og:url` لعنوان URL الأصلي للصفحة.
- `og:locale:alternate` لإصدارات اللغات البديلة.
- روابط `rel="canonical"` و `rel="alternate"` لتحسين SEO.
- رابط `hreflang="x-default"` يشير إلى URL اللغة الافتراضية. يخبر محركات البحث بأي URL يُعرض للمستخدمين الذين لا تتطابق لغتهم مع أي من اللغات المعرَّفة.

### اللغة والاتجاه الديناميكيان

يحدّد الـ composable ديناميكياً سمتي `lang` و `dir` بناءً على لغة المسار الحالي، مما يضمن تكوين مستند HTML الخاص بك بشكل صحيح للمستخدمين الدوليين.

### التعامل مع المسارات المترجمة

إذا كانت مساراتك مسبوقة برموز لغات (مثل `/en/about`)، يعدّل الـ composable المسار الكامل بذكاء لتوليد عناوين URL، مما يضمن دقّة وأهمية سمات SEO.

يبسّط هذا الـ composable عملية تحسين تطبيق Nuxt الخاص بك للجماهير الدولية، مما يضمن استعداد موقعك جيداً لمحركات البحث والمستخدمين العالميين.

## 🛠️ مثال الاستخدام

يوضّح المثال التالي كيفية استخدام الـ composable `useLocaleHead` داخل مكوّن Vue بالإعدادات الافتراضية:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### شرح الشيفرة

- **الـ Composable `useLocaleHead`**: يُستدعى هذا الـ composable في قسم `<script setup>` ويُرجع كائناً يحتوي على `htmlAttrs` و `meta` و `link`.

- **وسم `<html>`**: تُحدَّد سمتا `lang` و `dir` لمستند HTML ديناميكياً بناءً على اللغة الحالية وتُطبَّق على وسم `<html>`.

- **قسم `<head>`**:
  - **وسوم Meta**: تُولَّد وسوم Meta ذات صلة بـ SEO، بما في ذلك `og:locale` و `og:url` ووسوم `rel="canonical"` و `rel="alternate"` لتحديد إصدارات اللغة البديلة للصفحة.
  - **وسوم Link**: تُدرج الروابط الأصلية والروابط إلى إصدارات اللغة البديلة ورابط `hreflang="x-default"` (يشير إلى URL اللغة الافتراضية).

- **قسم `<body>`**: يُعرض المحتوى الرئيسي للصفحة هنا. في هذا المثال، يُستخدم عنوان وفقرة بسيطان.

### 📝 ملاحظات

1. **السمات**: السمات المستخدمة (`lang` و `dir` و `rel` و `href` و `hreflang` و `property` و `content`) مستخرجة من الكائن الذي يُرجعه `useLocaleHead`.

2. **توليد وسوم SEO**: إذا كان الخيار `addSeoAttributes` مضبوطاً على `true`، يولّد الـ composable تلقائياً وسوم SEO للغة الحالية.

3. **URL الأساسي**: يمكنك ضبط URL الأساسي المخصص باستخدام الخيار `baseUrl` لتوليد الروابط الأصلية والبديلة بشكل صحيح.

يوضّح هذا المثال مدى سهولة دمج `useLocaleHead` في مكوّنات تطبيقك لضمان سمات SEO صحيحة وتحسين فهرسة الصفحات المترجمة من قبل محرك البحث.

## 🧩 التخصيص ودورة الحياة

- لا يشترك `useLocaleHead` في التغييرات بنفسه. يُرجع `metaObject` و `updateMeta`.
- يجب عليك استدعاء `updateMeta()` عندما تتغيّر المدخلات (عادةً عند تغيير المسار)، على سبيل المثال من إضافة:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## متى تستخدم `useI18nHead` بدلاً منها

عندما يكون `meta: true` (الافتراضي)، فضّل [`useI18nHead`](/api/composables/use-i18n-head) للتجاوزات **لكل صفحة** (hreflang مخصص، `og:title` إضافي، تعطيل جزئي). استخدم `useLocaleHead` مباشرة فقط عندما يكون `meta: false` أو تدير `useHead` بنفسك.
