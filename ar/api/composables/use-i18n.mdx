# 🛠️ الـ Composable `useI18n`

يوفّر الـ composable `useI18n` في `Nuxt I18n Micro` وصولاً إلى معظم مساعدات i18n في وقت التشغيل في المكوّنات والسكربتات. الدوال متاحة **مع وبدون البادئة `$`** (مثلاً `$t` و `t`).

بعض الحقن — `$defineI18nRoute` و `$clearCache` — متاحة على `useNuxtApp()` فقط. راجع [الدوال — `$defineI18nRoute`](/api/methods#definei18nroute) و [`$clearCache`](/api/methods#clearcache).

## 📊 ما تُرجعه

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

كل مساعد وقت تشغيل، كائن عادي.

نفس الدوال التي تحقنها الإضافة كـ `$t` و `$tc` وغيرها، متاحة تحت
الاسم المسبوق بعلامة الدولار وأيضاً كاسم مستعار بدون بادئة — لذا `const \{ t \} = useI18n()` و
`const \{ $t \} = useI18n()` كلاهما يعمل.

**تُرجع** — المساعدات الموصوفة في [مرجع الدوال](/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

كل مساعد تُرجعه — `$t` و `$tc` و `$has` و `$switchLocale` وغيرها — مدرج
مع توقيعه وموثّق بالكامل في [مرجع الدوال](/api/methods).

## واجهات API الحصرية لـ `useNuxtApp()`

هذه **لا** تُرجع بواسطة `useI18n()`. استوردها من `useNuxtApp()`:

| الدالة                     | الغرض                                                                         |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | مسارات لغة لكل صفحة، وقيود، وترجمات مضمَّنة في `script setup` |
| `$clearCache()`            | يمسح ذاكرة التخزين المؤقت للترجمة داخل الذاكرة والأجزاء المُحمَّلة |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

راجع [الدوال](/api/methods) للتوقيعات الكاملة والأمثلة.

## 🛠️ أمثلة الاستخدام

### استرداد اللغة الأساسي

استرداد اللغة الحالية للتطبيق.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### الترجمة مع معاملات

ترجمة سلسلة مع معاملات ديناميكية، مع قيمة افتراضية احتياطية.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### تبديل اللغات

بدّل التطبيق إلى لغة مختلفة.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### توليد مسار مترجم

ولّد مساراً مترجماً إلى اللغة الحالية أو المحدّدة.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
