تستدعي الوحدة خطافًا واحدًا لوقت التشغيل (خطاف التطبيق)، وهو `i18n:register`. استخدمه عندما تضيف إضافة أو وحدة ترجمات غير موجودة في ملفات `locales/` الخاصة بك. تتلقى دالة الاستدعاء الخاصة بك دالة `register` تدمج الترجمات في الصفحة المعروضة.

## `i18n:register` {#i18nregister}

```ts
'i18n:register': (
  register: (translations: unknown, locale?: string) => void,
  locale: string,
) => HookResult
```

| الوسيط | الوصف |
| --- | --- |
| `register(translations, locale?)` | يدمج `translations` دمجًا عميقًا في جزء الصفحة الخاص بالمسار الجاري تحميله، للغة `locale` (الافتراضي: `locale` الخاص بالخطاف). تُستبدل المفاتيح الموجودة مسبقًا. |
| `locale` | لغة المسار الجاري تحميله. |

الخطاف مُعرَّف النوع عبر `RuntimeNuxtHooks`، لذا لا يحتاج `nuxtApp.hook('i18n:register', …)` إلى أي تحويل للنوع.

## متى يُطلق {#when-it-fires}

تستدعيه إضافة التحميل (`i18n-plugin-loader`):

1. مرة واحدة عند بدء التشغيل، بعد تشغيل جميع الإضافات (`app:created`) وقبل عرض التطبيق؛
2. داخل `router.beforeEach` الخاص بها، بعد تحميل ترجمات الصفحة الهدف، عندما يتغير المسار — وعند كل تنقل في وضع `no_prefix`.

يُنتظر اكتمال كل دالة استدعاء وكل استدعاء لـ `register` قبل عرض التطبيق أو متابعة التنقل، لذا تُعرض الصفحة بالمفاتيح المدمجة. مع [`hooks: false`](/ar/api/module-options#hooks) لا يُستدعى الخطاف أبدًا.

## مثال {#example}

```ts
// plugins/i18n-extra.ts
export default defineNuxtPlugin((nuxtApp) => {
  nuxtApp.hook('i18n:register', async (register, locale) => {
    const extra = await $fetch<Record<string, unknown>>(`/api/cms-strings/${locale}`)
    register(extra, locale)
  })
})
```

هذا خطاف وقت تشغيل: سجّله باستخدام `nuxtApp.hook` داخل إضافة، وليس باستخدام `nuxt.hook` في `nuxt.config` أو في `setup` الخاص بوحدة. تضيف الوحدة مثل هذه الإضافة باستخدام `addPlugin`.
