# واجهات API للحزم

يُبنى `nuxt-i18n-micro` من مجموعة من الحزم الصغيرة، ومعظمها قابل للاستخدام
بمفرده — `@i18n-micro/vue` في تطبيق Vue عادي، و`@i18n-micro/core` في أي مكان.

كل صفحة أدناه مُولّدة من لقطة API التي يتحقق منها
[`pnpm run api:surface`](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/maintenance-commands.md#api-surface) مقارنةً
بمصادر TypeScript، لذا لا يمكن أن تختفي عملية تصدير دون تغيير هذا المرجع
أو فشل CI.
