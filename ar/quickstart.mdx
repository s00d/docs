## 🚀 البدء السريع

### التثبيت

ثبّت الوحدة في تطبيق Nuxt الخاص بك:

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

### الإعداد الأساسي

أضف الوحدة إلى ملف `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

<Tip>
- **ملفات المستوى الجذر** (`locales/en.json` وغيرها) — ترجمات مشتركة عبر التطبيق بأكمله (القوائم، التذييل، واجهة المستخدم الشائعة). مع `translationPayloads.mode: 'premerged'` (الافتراضي)، يتم دمجها في كل صفحة أثناء البناء.
- **الملفات الخاصة بكل صفحة** (`locales/pages/<route>/<locale>.json`) — ترجمات فريدة لصفحات محددة، تُحمَّل فقط عند زيارة الصفحة.
- **المسارات الديناميكية** — `pages/articles/[id].vue` تتوافق مع `locales/pages/articles-id/` (تُستبدل الأقواس بشرطات).
- **التوليد التلقائي** — تُنشأ جميع ملفات الترجمة تلقائيًا في حالة غيابها أثناء `nuxt dev`.
</Tip>

<Info>
تدعم الوحدة كلا التخطيطين:

- **الصفحات**: `pages/**/*.vue` (Nuxt 3) أو `app/pages/**/*.vue` (Nuxt 4)
- **الترجمات**: احتفظ بمجلد `locales/` في **جذر المشروع** افتراضيًا (الاتفاق الموصى به)، وليس داخل `app/`.

```tree
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   ├── en.json
│   └── pages/
└── nuxt.config.ts
```

الوضع الاختياري: `i18n: \{ translationDir: 'app/locales' \}` (انظر [fixture `n3`](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/n3)).

بالنسبة إلى مساعد CLI الاختياري `text-to-i18n`، استخدم [`nuxt-i18n-micro-cli` ≥ 2.1.1](/guides/cli#-text-to-i18n-command) بحيث تُفحص `app/pages` و`app/components` من جذر المشروع.
</Info>

### الاستخدام الأساسي

استخدم الترجمات في مكوّناتك:

```vue
<template>
  <div>
    <h1>{{ $t('welcome') }}</h1>
    <p>{{ $t('description', { name: 'World' }) }}</p>

    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" @click="$switchLocale(locale.code)">
        {{ locale.code }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useI18n } from '#imports'

const { $t, $getLocales, $switchLocale } = useI18n()
</script>
```
