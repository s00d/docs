title: "مولّد الأنواع"
description: "ولّد إكمالًا تلقائيًا في TypeScript لمفاتيح الترجمة من ملفات JSON لديك، في Nuxt أو أي مشروع Vite."
---

تقرأ `@i18n-micro/types-generator` كل ملف JSON في مجلد الترجمة لديك وتكتب ملف تصريحات يسرد جميع المفاتيح. أضفها عندما تريد أن يقترح محررك المفاتيح في `t()` و`$t()` و`<I18nT keypath>`. تعمل كوحدة Nuxt وكإضافة Vite أو Rollup، وتعيد التوليد عند تغيّر أي ملف.

## التثبيت {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/types-generator
```

```bash npm
npm install -D @i18n-micro/types-generator
```

```bash yarn
yarn add -D @i18n-micro/types-generator
```

</CodeGroup>

الاعتمادية النظيرة: `@nuxt/kit` `^3.18.0 || ^4.0.0`. لا يستوردها إلا مدخل `/nuxt`؛ وفي مشروع Vite فقط يمكن تجاهل تحذير الاعتمادية النظيرة.

## Nuxt {#nuxt}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro', '@i18n-micro/types-generator/nuxt'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

تكتب الوحدة `.nuxt/types/i18n-micro.d.ts` ويضيفه Nuxt إلى سياق الأنواع؛ لا شيء تحتاج إلى تضمينه يدويًا. تقرأ `i18nTypes.translationDir`، وإلا فالمكان الذي يقرأ منه `nuxt-i18n-micro` الترجمات: `translationDir` (من `i18n` أو من خيارات الوحدة المضمّنة، والافتراضي `'locales'`) في كل طبقة، و`additionalTranslationDirs`. يؤدي تعديل ملف JSON داخل ذلك المجلد إلى إعادة توليد الأنواع في `nuxi dev`. يُتجاهل `i18nTypes.outputFile` في Nuxt (ويظهر تحذير بذلك).

## Vite {#vite}

`I18nTypesPlugin` إضافة Vite، يقبلها Rollup أيضًا. ولأي أداة تجميع أخرى، استدعِ `generateTypes` في سكربت.

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { I18nTypesPlugin } from '@i18n-micro/types-generator'

export default defineConfig({
  plugins: [
    vue(),
    I18nTypesPlugin({
      srcDir: process.cwd(),
      translationDir: 'src/locales',
      outputFile: 'src/i18n-micro.d.ts',
    }),
  ],
})
```

| الخيار | مطلوب | ملاحظات |
| --- | --- | --- |
| `srcDir` | نعم | المجلد الأساسي؛ يُحلَّل `translationDir` نسبةً إليه. |
| `translationDir` | نعم | المجلد الذي يحتوي ملفات JSON (بما في ذلك المجلدات الفرعية مثل `pages/`)، أو مصفوفة مجلدات. |
| `outputFile` | لا | مكان كتابة ملف التصريحات؛ الافتراضي `<srcDir>/i18n-micro.d.ts`. |

تولّد الإضافة مرة واحدة عند بدء البناء، وفي خادم التطوير تعيد التوليد بعد 300 ms من أي تغيير في المجلد. تأكد من أن `include` في `tsconfig.json` يشمل ملف المخرجات.

## استخدام المفاتيح {#use-the-keys}

يوسّع الملف المولَّد `DefineLocaleMessage` في `@i18n-micro/types`، مما يحوّل `TranslationKey` إلى مفاتيحك:

```ts
declare module '@i18n-micro/types' {
  export interface DefineLocaleMessage {
    nav: object
    'nav.home': string
    'profile.title': string
  }
}
```

المفاتيح هي تلك التي يجيب عنها `t()`، بما فيها الكائنات، من كل لغة وكل ملف صفحة، مع نوع قيمتها في JSON. `TranslationKey` هو اتحاد تلك المفاتيح مع أي سلسلة نصية، لذا تحصل على إكمال تلقائي، لا على أخطاء: يظل المفتاح المكتوب خطأً أو الديناميكي قابلًا للترجمة البرمجية. لا تُحدَّد أنواع المعاملات والقيم المُرجعة.

للمفاتيح الديناميكية تحت بادئة معروفة، يضيّق `ScopedKey<'prefix'>` النطاق إلى المفاتيح المطابقة:

```ts
import type { ScopedKey } from '@i18n-micro/types'

const statusText = (status: string) => t(`status.${status}` as ScopedKey<'status'>)
```

يأتي `TranslationKey` و`ScopedKey` من `@i18n-micro/types` (تعيد React وPreact وSolid تصدير `TranslationKey`؛ أما Vue فلا).

## API {#api}

| التصدير | المدخل | ملاحظات |
| --- | --- | --- |
| `I18nTypesPlugin(options)` | `@i18n-micro/types-generator` | إضافة Vite وRollup |
| `generateTypes(options)` | `@i18n-micro/types-generator` | يكتب الملف، ويُرجع مساره |
| `getTypesString(options)` | `@i18n-micro/types-generator` | يُرجع التصريحات دون كتابة |
| `formatKeyProperty(key)` | `@i18n-micro/types-generator` | دالة مساعدة |
| وحدة Nuxt (`configKey: 'i18nTypes'`) | `@i18n-micro/types-generator/nuxt` | الخيار `translationDir` |

التواقيع الكاملة: [مرجع الحزمة](/ar/api/packages/types-generator).
