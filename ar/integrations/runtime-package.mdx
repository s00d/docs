`@i18n-micro/runtime` هي نسخة i18n المستقلة عن أطر العمل: القواميس، و`t()`، والجمع، والتنسيق عبر `Intl`، والاشتراك في التغييرات، دون `fs` ودون أي إطار عمل. استخدمها في TypeScript العادية، أو في عامل ويب، أو في دالة طرفية، أو كأساس لربطك الخاص. تمدّد حزم React وPreact وNode وAstro هذه الفئة نفسها.

## التثبيت {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/runtime
```

```bash npm
npm install @i18n-micro/runtime
```

```bash yarn
yarn add @i18n-micro/runtime
```

</CodeGroup>

لا توجد تبعيات نظيرة. لملفات الترجمة على القرص استخدم [`@i18n-micro/node`](/ar/integrations/nodejs-package).

## الإعداد {#setup}

```ts
import { createI18n } from '@i18n-micro/runtime'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    en: { greeting: 'Hello, {name}!', apples: 'no apples | one apple | {count} apples' },
    de: { greeting: 'Hallo, {name}!' },
  },
  routeMessages: {
    about: { en: { title: 'About us' } },
  },
})
```

جميع الخيارات (`plural`، `missingWarn`، `missingHandler`، `numberFormats`، `datetimeFormats`) مدرجة في [النسخة](/ar/integrations/overview#the-instance).

## الترجمة {#translate}

```ts
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.tc('apples', 5) // '5 apples'
i18n.tn(1234.5) // '1,234.5'

i18n.setRoute('about')
i18n.t('title') // 'About us' (route dictionary)
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!' (root, still visible)
```

حمّل مزيدًا من القواميس لاحقًا:

```ts
i18n.loadMessages({ fr: { greeting: 'Bonjour, {name} !' } }, { about: { fr: { title: 'À propos' } } })
i18n.addTranslations('fr', { nav: { home: 'Accueil' } }) // deep merge; pass false to replace

await i18n.loadFromUrl('/locales/fr.json', { locale: 'fr' })
await i18n.loadFromUrl('/locales/pages/about/fr.json', { locale: 'fr', routeName: 'about' })
await i18n.loadFromUrls([
  { url: '/locales/en.json', locale: 'en' },
  { url: '/locales/de.json', locale: 'de' },
])
```

تستخدم `loadFromUrl` الدالة `fetch` (مرّر `init` للترويسات) وترمي خطأً عند استجابة غير ناجحة. وتحمّل `loadFromUrls` الملفات واحدًا تلو الآخر.

## تبديل اللغة {#switch-locale}

```ts
i18n.locale = 'de'
i18n.t('greeting', { name: 'Ada' }) // 'Hallo, Ada!'
```

تُخطر تغييرات اللغة والمسار والقاموس المشتركين، وهذه هي الطريقة التي تعيد بها روابط أطر العمل العرض:

```ts
const stop = i18n.subscribe(() => {
  document.querySelector('#greeting')!.textContent = i18n.t('greeting', { name: 'Ada' }) as string
})
i18n.locale = 'fr'
stop()
```

تعيد `getSnapshot()` سلسلة نصية تتغير مع كل إخطار (للمخازن على غرار `useSyncExternalStore`).

## لكل طلب {#per-request}

تحتفظ النسخة بلغة واحدة ومسار واحد. على الخادم، لا تبدّل لغة نسخة مشتركة لكل طلب: إذ سيرى طلبان متزامنان لغة كل منهما. يمنح `i18n.fork(locale)` الطلب نسخته الخاصة: لغته واحتياطه ومساره الخاصة؛ مع القواميس والمنسّقات والقواعد نفسها. تكلفة التفرّع واحدة مهما كان عدد القواميس. يرى الفرع ما يُكتب في أصله حتى أول كتابة خاصة به، وتبقى كتاباته فيه. يضيف [Node.js](/ar/integrations/nodejs-package#per-request) الدالة `run`.

## واجهة API {#api}

| العضو | ملاحظات |
| --- | --- |
| `t`، `ts`، `tc`، `tn`، `td`، `tdr`، `has` | راجع [الترجمة والتنسيق](/ar/integrations/overview#translate-and-format) |
| `locale`، `fallbackLocale` | قراءة/تعيين |
| `currentRoute`، `setRoute(name)`، `getRoute()` | المسار النشط، والافتراضي `'index'` |
| `loadMessages(messages?, routeMessages?)` | دمج عدة لغات ومسارات دفعة واحدة |
| `addTranslations(locale, tree, merge = true)`، `addRouteTranslations(locale, route, tree, merge = true)` | |
| `loadFromUrl(url, { locale?, routeName?, init? })`، `loadFromUrls(entries)` | جلب JSON عبر `fetch` |
| `hasTranslation(key)` | اللغة النشطة، أي مسار (بخلاف `has`، التي تتحقق من المسار النشط والجذر) |
| `setTranslation(key, value)`، `resolveTranslations()` | كتابة مفتاح واحد؛ قراءة الشجرة المدمجة |
| `clear()`، `clearCache()` | حذف كل القواميس |
| `subscribe(cb)`، `getSnapshot()` | إخطارات التغيير |
| `storage` | `{ translations: Map<'locale:route', Translations> }` |

الرمز الذي ليس وسم لغة يحصل على قواعد الجمع الخاصة به من `localeIso: { ua: 'uk-UA' }`؛ وتبني `localeIsoMap(locales)` ذلك من إدخالات قائمة اللغات التي تحتوي على `iso`.

تصديرات الوحدة: `createI18n`، `I18n`، `fetchJsonTranslations`، `FormatService`، `interpolate`، `localeIsoMap` والأنواع `I18nOptions`، `LoadFromUrlOptions`، `LoadFromUrlEntry`، `TranslationStorage`، `Translations`، `Locale`، `PluralFunc`. التواقيع الكاملة: [مرجع الحزمة](/ar/api/packages/runtime).
