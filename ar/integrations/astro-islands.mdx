---

تعمل الجزيرة في المتصفح، حيث لا توجد نسخة i18n الخاصة بالخادم. تتيح `@i18n-micro/astro` للصفحة اختيار المفاتيح التي تحتاجها الجزيرة، وتمريرها كخاصية واحدة، وقراءتها داخل الجزيرة عبر محوّل صغير خاص بإطار العمل. تحصل على `t` و`tc` و`tn` و`td` و`tdr` و`has` في جزر Vue وReact وPreact وSvelte، مع وجود النصوص المختارة فقط في HTML.

## الإعداد {#setup}

أعدّ [تكامل Astro والبرمجية الوسيطة](/ar/integrations/astro-package#setup) أولًا، ثم أضف تكامل إطار العمل الذي تستخدمه (`@astrojs/vue`، `@astrojs/react`، `@astrojs/preact`، `@astrojs/svelte`). تحتاج محوّلات الجزر إلى إطار العمل ذاك كتبعية نظيرة: `vue` `^3.3.0`، أو `react` `^16.8.0 || ^17.0.0 || ^18.0.0 || ^19.0.0`، أو `preact` `^10.0.0 || ^11.0.0`، أو `svelte` `^4.0.0 || ^5.0.0`.

## تمرير الترجمات إلى جزيرة {#pass-translations-to-an-island}

```astro
---
// src/pages/index.astro
import { getI18nProps } from '@i18n-micro/astro'
import Counter from '../components/Counter.vue'

const i18n = getI18nProps(Astro, ['counter.title', 'counter.apples'])
---

<Counter client:load i18n={i18n} />
```

تعيد `getI18nProps(Astro, keys?)` القيمة `{ locale, fallbackLocale, currentRoute, translations }` (من النوع `I18nClientProps`). مرّر المفاتيح التي تستخدمها الجزيرة: يُحلّ كل منها على الخادم مثل `t()` (قواميس المسار والجذر والاحتياط) ولا تدخل HTML إلا المفاتيح الموجودة. ودون `keys`، يُرسل كل ما يمكن لـ `t()` الإجابة عنه في هذه الصفحة، في كل جزيرة، لذا فإن 2000 مفتاح جذري تعادل نحو 100 كيلوبايت لكل جزيرة؛ وفي وضع التطوير يظهر تحذير بذلك عند تجاوز 20 كيلوبايت.

تترجم الجزر من ذلك الكائن فقط. تعيد `t` المفتاح نفسه لأي شيء لم يُمرَّر، ولا تُحلّ الرسائل المرتبطة.

## Vue {#vue}

استدعِ `provideI18n(() => props.i18n)` في المكوّن الجذري للجزيرة و`useAstroI18n()` في أبنائه. لا ترى دالة `inject` في Vue قيمة يوفرها المكوّن نفسه، لذا يجب أن يعمل الخطاف في مكوّن ابن، لا في الجذر:

```vue
<!-- src/components/Counter.vue -->
<script setup lang="ts">
import { provideI18n } from '@i18n-micro/astro/client/vue'
import type { I18nClientProps } from '@i18n-micro/astro'
import CounterBody from './CounterBody.vue'

const props = defineProps<{ i18n: I18nClientProps }>()
provideI18n(() => props.i18n)
</script>

<template><CounterBody /></template>
```

```vue
<!-- src/components/CounterBody.vue -->
<script setup lang="ts">
import { ref } from 'vue'
import { useAstroI18n } from '@i18n-micro/astro/client/vue'

const { t, tc } = useAstroI18n()
const count = ref(0)
</script>

<template>
  <h3>{{ t('counter.title') }}</h3>
  <button @click="count++">{{ tc('counter.apples', count) }}</button>
</template>
```

## React وPreact {#react-and-preact}

```tsx
// src/components/Counter.tsx
import { useState } from 'react'
import { I18nProvider, useAstroI18n } from '@i18n-micro/astro/client/react'
import type { I18nClientProps } from '@i18n-micro/astro'

function Body() {
  const { t, tc } = useAstroI18n()
  const [count, setCount] = useState(0)
  return <button onClick={() => setCount(count + 1)}>{t('counter.title')}: {tc('counter.apples', count)}</button>
}

export default function Counter({ i18n }: { i18n: I18nClientProps }) {
  return (
    <I18nProvider value={i18n}>
      <Body />
    </I18nProvider>
  )
}
```

في Preact، استورد `I18nProvider` و`useAstroI18n` من `@i18n-micro/astro/client/preact`؛ وواجهة API هي نفسها.

## Svelte {#svelte}

```svelte
<!-- src/components/Counter.svelte -->
<script lang="ts">
  import { createI18nStore, useAstroI18n } from '@i18n-micro/astro/client/svelte'
  import type { I18nClientProps } from '@i18n-micro/astro'

  export let i18n: I18nClientProps
  const { t, tc } = useAstroI18n(createI18nStore(i18n))
  let count = 0
</script>

<button on:click={() => count++}>{t('counter.title')}: {tc('counter.apples', count)}</button>
```

تعيد `useAstroI18n(store)` أيضًا `store` لقراءات `$store` في القالب.

## الجزر المستمرة {#persisted-islands}

تحصل الجزيرة ذات `transition:persist` على خصائص جديدة بعد التنقل. تتبعها React وPreact وVue (عند تمرير دالة جلب). في Svelte، احتفظ بالمخزن ومرّرها إليه: `const store = createI18nStore(i18n)`، `const { t } = useAstroI18n(store)`، ثم `$: store.set(i18n)` (ومع runes: `$effect(() => store.set(i18n))`).

## واجهة API {#api}

| نقطة الدخول | التصديرات |
| --- | --- |
| `@i18n-micro/astro` | `getI18nProps`، النوع `I18nClientProps` |
| `@i18n-micro/astro/client/vue` | `provideI18n(props \| () => props)`، `useAstroI18n()` |
| `@i18n-micro/astro/client/react` | `I18nProvider` (الخاصية `value`)، `useAstroI18n()` |
| `@i18n-micro/astro/client/preact` | `I18nProvider` (الخاصية `value`)، `useAstroI18n()` |
| `@i18n-micro/astro/client/svelte` | `createI18nStore(props)`، `useAstroI18n(store)` |
| `@i18n-micro/astro/client` | الدالتان الخالصتان `translate` و`hasTranslation`، دون أي إطار عمل |

تعيد كل `useAstroI18n` كلًا من `t` و`ts` و`tc` و`tn` و`td` و`tdr` و`has` و`setLocale` و`setRoute` و`locale`. للجزيرة قاموس واحد مدمج، لذا تكون `has` الخاصة بها صحيحة لأي مفتاح يمكن لـ `t` الإجابة عنه، حتى من لغة الاحتياط؛ أما على الخادم فلا تنظر `has` إلا إلى اللغة النشطة.
