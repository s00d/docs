تجلب حزم `@i18n-micro/*` نواة الترجمة في Nuxt I18n Micro إلى Vue وReact وPreact وSolid وAstro وVitePress وJavaScript العادية. استخدمها عندما لا يكون تطبيقك تطبيق Nuxt، أو عندما يحتاج سكربت أو خادم خارج Nuxt إلى ملفات الترجمة نفسها. تتشارك كل الحزم نموذج نسخة واحدًا، وعقد محوّل موجّه واحدًا، والمكوّنات الأربعة نفسها، الموصوفة مرة واحدة في هذه الصفحة.

تُثبَّت `@i18n-micro/core` و`@i18n-micro/types` و`@i18n-micro/utils` مع هذه الحزم؛ ونادرًا ما تستوردها مباشرة. توقيعات كل التصديرات موجودة في [مرجع الحزم](/ar/api/packages/overview) المولَّد.

لكل حزمة ساحة تجربة (playground) تحت `packages/<name>/playground` في المستودع.

## النسخة {#the-instance}

تُعيد `createI18n(options)` نسخة واحدة تحمل القواميس واللغة الحالية والمسار الحالي. الخيارات نفسها في كل حزمة:

| الخيار | النوع | الافتراضي | ملاحظات |
| --- | --- | --- | --- |
| `locale` | `string` | إلزامي | اللغة النشطة. |
| `fallbackLocale` | `string` | `locale` | يُبحث فيها عند غياب مفتاح في `locale`. |
| `messages` | `Record<locale, Translations>` | `{}` | القواميس الجذرية (المسار `'index'`). |
| `routeMessages` | `Record<route, Record<locale, Translations>>` | `{}` | قواميس المسارات. في Runtime وReact وPreact وNode وVitePress فقط. |
| `plural` | `PluralFunc` | `defaultPlural` | قاعدة جمع مخصّصة. |
| `missingWarn` | `boolean` | `true` | `console.warn` في المتصفح في وضع التطوير فقط عند غياب مفتاح. |
| `missingHandler` | `(locale, key, routeName) => void` | — | يُستدعى بدلًا من التحذير. |
| `numberFormats` | `Record<locale, Record<name, Intl.NumberFormatOptions>>` | — | تنسيقات مسمّاة: `tn(9.5, 'currency')`. |
| `datetimeFormats` | `Record<locale, Record<name, Intl.DateTimeFormatOptions>>` | — | تنسيقات مسمّاة: `td(date, 'short')`. |
| `timeZone` | `string` | منطقة بيئة التشغيل | منطقة IANA لتواريخ `td`؛ ولا تؤثر في `tdr`. اضبطها كي يُصيِّر الخادم والمتصفح التاريخ نفسه. |
| `now` | `() => number` | `Date.now` | ساعة `tdr`. مرّر وقت الخادم إلى الإماهة كي يُصيِّر الطرفان النص نفسه. |
| `localeIso` | `Record<code, string>` | — | وسم BCP 47 المستخدم لقواعد الجمع (`ua` → `uk-UA`). تأخذه React وPreact وSolid من `iso` في `locales` الخاصة بالمزوّد. |

تعيش القواميس في `i18n.storage.translations`، وهي `Map` مفاتيحها `locale:route` (`en:index`، `en:about`).

يُبحث عن المفتاح في قاموس المسار الحالي، ثم في القاموس الجذري، أولًا لـ `locale`، ثم لـ `fallbackLocale`. يُعيد المفتاح المفقود المفتاح نفسه (أو `defaultValue` التي تمرّرها).

```ts
i18n.addTranslations('en', { nav: { home: 'Home' } }) // root, deep-merged
i18n.addRouteTranslations('en', 'about', { title: 'About us' }) // route chunk
i18n.addTranslations('en', { nav: { home: 'Start' } }, false) // replace instead of merge
i18n.setRoute('about')
i18n.t('title') // 'About us'
i18n.t('nav.home') // 'Start' (root key, still visible on the route)
```

### الترجمة والتنسيق {#translate-and-format}

| الدالة | القيمة المُعادة |
| --- | --- |
| `t(key, params?, defaultValue?, routeName?)` | القيمة (نص، رقم، كائن) مع استبدال `{param}`. |
| `ts(...)` | مثل `t`، كنص. |
| `tc(key, count \| params, defaultValue?)` | صيغة الجمع. |
| `tn(value, options \| name)` | `Intl.NumberFormat` باللغة النشطة. |
| `td(value, options \| name)` | `Intl.DateTimeFormat`. |
| `tdr(value, options?)` | الوقت النسبي (`3 days ago`). |
| `has(key, routeName?)` | `true` عندما يكون المفتاح موجودًا في اللغة النشطة (قاموس المسار أو الجذر؛ لا يُفحص البديل). |

تقسم `defaultPlural` القيمة عند `|` وتختار الصيغة عند الفهرس `count`، مع حصره في آخر صيغة؛ والعدد السالب أو الكسري أو `NaN` يختار الصيغة الأخيرة.

تستقبل دالة `plural` المخصّصة `(key, count, params, locale, getter)`. اقرأ القيمة عبر `getter(key)`؛ ولا تقسم المفتاح:

```ts
import type { PluralFunc } from '@i18n-micro/vue'

const plural: PluralFunc = (key, count, params, _locale, getter) => {
  const value = getter(key)
  if (typeof value !== 'string') return null
  const forms = value.split('|').map((form) => form.trim())
  return (count === 1 ? forms[0] : forms[1] ?? forms[0])!.replace('{count}', String(count))
}
```

## محوّل الموجّه {#router-adapter}

لا تعتمد حزم SPA على موجّه. يخبرها محوّل الموجّه (`I18nRoutingStrategy`) بكيفية قراءة المسار الحالي، والتنقّل، وبناء مسار مترجم. تضيف المحوّلات المدمجة بادئة لكل لغة باستثناء `defaultLocale` (`/about`، `/de/about`).

| العضو | إلزامي | يستخدمه |
| --- | --- | --- |
| `getCurrentPath(): string` | نعم | فحص الرابط النشط (حسب الصفحة، لا يُحتسب الاستعلام والـ hash)، و`switchLocale` (يحتفظ بهما) |
| `push({ path }): void` | نعم | `switchLocale`، و`<I18nLink>` دون `linkComponent`، و`<I18nSwitcher>` |
| `replace({ path }): void` | نعم | — |
| `resolvePath(to, locale)` | لا | `localePath`، و`localeRoute`، و`<I18nLink>`؛ وبدونه تُعاد المسارات كما هي |
| `linkComponent` | لا | يُصيِّره `<I18nLink>` (مثل `RouterLink`) بدلًا من `<a>` |
| `getRoute()` | لا | `{ fullPath, query }` لمساعدات SEO |

`push` و`replace` إلزاميان في Vue وReact وPreact وSolid. لدى Astro محوّلها الخاص على جانب الخادم مع `push`/`replace` اختياريين (راجع [Astro](/ar/integrations/astro-package#router-adapter)).

محوّل أدنى لأي موجّه يعتمد على history:

```ts
import type { I18nRoutingStrategy } from '@i18n-micro/react'

const locales = ['en', 'de']
const stripLocale = (path: string) => path.replace(/^\/(en|de)(?=\/|$)/, '') || '/'

export const historyAdapter: I18nRoutingStrategy = {
  getCurrentPath: () => window.location.pathname + window.location.search + window.location.hash,
  push: ({ path }) => window.history.pushState({}, '', path),
  replace: ({ path }) => window.history.replaceState({}, '', path),
  resolvePath: (to, locale) => {
    const path = stripLocale(typeof to === 'string' ? to : to.path || '/')
    return locale === 'en' ? path : `/${locale}${path === '/' ? '' : path}`
  },
}
```

## المكوّنات {#components}

تشحن Vue وReact وPreact وSolid المكوّنات الأربعة نفسها. خصائصها متطابقة؛ وتمرّر React وPreact وSolid الخصائص الأخرى إلى العنصر الجذري.

### `<I18nT>` {#&lt;i18nt&gt;}

| الخاصية | النوع | ملاحظات |
| --- | --- | --- |
| `keypath` | `string` | إلزامية |
| `params` | `object` | قيم الاستبدال |
| `plural` | `number \| string` | تُصيِّر `tc(keypath, count)` |
| `number` | `number \| string` | تمرّر `tn(number)` بوصفها `{number}` |
| `date` | `Date \| string \| number` | تمرّر `td(date)` بوصفها `{date}` |
| `relativeDate` | `Date \| string \| number` | تمرّر `tdr(relativeDate)` بوصفها `{relativeDate}` |
| `tag` | `string` | العنصر الغلاف، الافتراضي `span` |
| `html` | `boolean` | تُصيِّر الترجمة كـ HTML؛ يجب أن تكون موثوقة، وتُهرَّب المعاملات |
| `defaultValue` | `string` | تحلّ محل المفتاح المفقود، وتُصيَّر مجرّدة عندما تُخفي `hideIfEmpty` قيمة فارغة |
| `hideIfEmpty` | `boolean` | لا تُصيِّر شيئًا للترجمة الفارغة |
| `customPluralRule` | `PluralFunc` | قاعدة الجمع لهذا العنصر |

لا تُطبَّق إلا خاصية تنسيق واحدة، وتُفحص بهذا الترتيب: `number`، `date`، `relativeDate`، `plural`.

#### النص المنسّق {#rich-text}

يمكن أن يحمل `{placeholder}` عنصرًا. في Vue يكون خانة (slot) مسمّاة؛ وفي React وPreact وSolid تعطي الخاصية `components` العناصر، أو دوالًّا تُعيد عنصرًا، بالاسم. وفي الحالتين يتغلب على المعامل الذي يحمل الاسم نفسه، ويعمل في كل فرع، ويصمد أمام لغة تعيد ترتيب العناصر النائبة.

```tsx
// { "terms": "I accept the {link} of {company}" }
<I18nT keypath="terms" params={{ company: 'ACME' }} components={{ link: <a href="/terms">terms</a> }} />
```

في Solid مرّر دالة عندما يتكرر عنصر نائب: إذ تحلّ العقدة الواحدة في مكان واحد. تستبدل `children` النص، وكدالة تحصل على `{ translation }`، مثل الخانة الافتراضية في Vue. تتجاهل `html` كل ذلك.

### `<I18nLink>` {#&lt;i18nlink&gt;}

| الخاصية | النوع | ملاحظات |
| --- | --- | --- |
| `to` | `string \| { path }` | يُترجَم عبر `resolvePath` الخاصة بالمحوّل |
| `activeStyle` | كائن نمط | يُدمج فوق `style` في الصفحة الحالية؛ وتطبّقه React وPreact وSolid أيضًا على قسم أعلى |
| `localeRoute` | دالة | تتجاوز `resolvePath` لهذا الرابط |

تُصيَّر عناوين URL الخارجية (`https://`، `mailto:`، `tel:`) كـ `<a target="_blank" rel="noopener noreferrer">`؛ ويفوز `target` أو `rel` الذي تضبطه أنت. يعمل `onClick` دائمًا. النقر المعدَّل، أو زر فأرة آخر، أو وجود `target` يُترك للمتصفح.

### `<I18nSwitcher>` {#&lt;i18nswitcher&gt;}

قائمة منسدلة باللغات المفعّلة (اللغات ذات `disabled: true` مخفية) مع أنماط افتراضية مضمّنة. عناصرها روابط، مع `lang` و`hreflang` و`dir` من اللغة. افتراضيًا، يضبط النقر على أحدها اللغة ويستدعي `push` الخاصة بالمحوّل مع المسار الحالي المترجم؛ وتستبدل الخاصية `switchLocale` هذا الإجراء. مع `localeRoute` ودون موجّه، يتبع المتصفح الرابط. يغلقها مفتاح Escape أو النقر خارجها.

| الخاصية | ملاحظات |
| --- | --- |
| `locales`، `currentLocale`، `getLocaleName` | تتجاوز القيم المقدَّمة |
| `switchLocale(code)` | تستبدل التبديل المدمج |
| `localeRoute` | تستبدل `resolvePath` |
| `customLabels` | `{ de: 'DE' }` |
| `customWrapperStyle`، `customButtonStyle`، `customDropdownStyle`، `customItemStyle`، `customLinkStyle`، `customActiveLinkStyle`، `customDisabledLinkStyle`، `customIconStyle` | تجاوزات الأنماط |

### `<I18nGroup>` {#&lt;i18ngroup&gt;}

عنصر `<div class="i18n-group">` يمرّر `t` ببادئة إلى أبنائه. وهو **لا** يضيف بادئة إلى `<I18nT>` أو استدعاءات `t()` داخله؛ فقط `t` التي يمرّرها تحمل البادئة.

| الخاصية | ملاحظات |
| --- | --- |
| `prefix` | إلزامية، مثل `'profile'` |
| `groupClass` | صنف (class) إضافي على الغلاف |

تأتي `t` ذات البادئة عبر خانة محدودة النطاق (scoped slot) في Vue (`v-slot="{ t }"`) وعبر ابن من نوع render-prop في React وPreact وSolid (`{({ t }) => …}`).

## المفاتيح المُنمَّطة {#typed-keys}

تقبل `t()` أي نص. للحصول على الإكمال التلقائي لمفاتيحك، ولّد ملف تصريحات باستخدام [مولّد الأنواع](/ar/integrations/types-generator). تُقترح المفاتيح ولا تُفرض، والمعاملات غير مُنمَّطة.

## مقارنة بوحدة Nuxt {#compared-with-the-nuxt-module}

لا تملك الحزم توجيهًا قائمًا على الملفات، ولا وسيطًا (middleware) على الخادم، ولا محمّل ترجمات: أنت تقرر متى تحمّل JSON (`import`، أو `fetch`، أو `@i18n-micro/node` على الخادم) وأي محوّل موجّه تستخدم. اكتشاف اللغة، وبيانات SEO الوصفية، وتوليد المسارات ميزات خاصة بـ Nuxt؛ ولدى Astro وسيطها الخاص للاكتشاف و`useLocaleHead` لـ SEO.
