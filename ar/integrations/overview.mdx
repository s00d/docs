# التكاملات

حزم `@i18n-micro` هي إصدارات خفيفة الوزن من Nuxt I18n Micro خاصة بكل إطار عمل، مصمّمة للتكامل مع مختلف أُطُر العمل والبيئات. توفّر هذه الحزم وظائف تدويل أساسية بصمة صغيرة، وتركّز على ميزات الترجمة الأساسية والمكوّنات البسيطة.

## نظرة عامة

حزم التكامل هذه هي **إصدارات مصغّرة** من وحدة Nuxt I18n Micro الكاملة، وتحتوي فقط على الوظائف الأساسية اللازمة للتدويل:

- **ميزات ترجمة أساسية** - دوال ترجمة أساسية، وتصريف بالعدد، وتنسيق
- **مكوّنات أساسية** - مجموعة صغيرة من مكوّنات واجهة المستخدم لمهام i18n الشائعة
- **نمط محوّل الموجّه (Router Adapter)** - تكامل توجيه مرن من خلال تجريد المحوّل
- **دعم TypeScript** - تعريفات أنواع كاملة لتطوير آمن من الناحية النوعية

على عكس وحدة Nuxt الكاملة، هذه الحزم:

- لا تتضمّن منطق توجيه خاصًا بإطار عمل
- تتطلّب منك تنفيذ محوّل موجّه لميزات التوجيه
- تركّز على وظيفة الترجمة بدلاً من تكامل إطار العمل
- مصمّمة لتكون خفيفة الوزن ومستقلة عن إطار العمل قدر الإمكان

## المكوّنات الأساسية

تتضمّن جميع حزم إطار العمل المكوّنات الأساسية التالية:

### `<I18nT>`

مكوّن ترجمة يعرض النص المترجم مع دعم:

- **استيفاء المعلمات** - استبدال العناصر النائبة بقيم ديناميكية
- **التصريف بالعدد** - اختيار تلقائي لشكل الجمع بناءً على العدد
- **تنسيق الأرقام** - تنسيق الأرقام وفقًا للغة
- **تنسيق التاريخ** - تنسيق التواريخ والأوقات النسبية
- **عرض HTML** - عرض اختياري لمحتوى HTML
- **قيم افتراضية** - نص احتياطي عندما تكون الترجمة مفقودة

**مثال:**

```vue
<!-- Vue -->
<I18nT keypath="greeting" :params="{ name: 'World' }" />
```

```tsx
// React
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```tsx
// Solid
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```astro
<!-- Astro -->
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

### `<I18nLink>`

مكوّن رابط محلَّى يعالج تلقائيًا بادئات اللغة في عناوين URL. الميزات:

- **توطين المسار التلقائي** - يضيف/يزيل بادئات اللغة استنادًا إلى استراتيجية التوجيه
- **كشف الحالة النشطة** - يميّز المسار الحالي
- **دعم الروابط الخارجية** - يكتشف عناوين URL الخارجية ويعالجها تلقائيًا
- **تكامل الموجّه** - يستخدم مكوّن الرابط الخاص بمحوّل الموجّه عند توفّره
- **تنسيق مخصّص** - يدعم حالتَي النشاط والتحويم

**مثال:**

```vue
<!-- Vue -->
<I18nLink to="/about" active-class="active">
  About Us
</I18nLink>
```

```tsx
// React
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```tsx
// Solid
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```astro
<!-- Astro -->
<I18nLink href="/about" class="nav-link">
  About Us
</I18nLink>
```

### `<I18nSwitcher>`

مكوّن مبدّل اللغة يوفّر واجهة قائمة منسدلة أو قائمة لتغيير اللغات. الميزات:

- **قائمة لغات تلقائية** - يولّد الخيارات من اللغات المُعدّة
- **إبراز اللغة الحالية** - يُشير بصريًا إلى اللغة النشطة
- **تسميات مخصّصة** - يدعم أسماء العرض المخصّصة لكل لغة
- **تكامل الموجّه** - ينتقل تلقائيًا إلى المسارات المترجَمة
- **الوصولية** - سمات ARIA مناسبة والتنقّل بلوحة المفاتيح

**مثال:**

```vue
<!-- Vue -->
<I18nSwitcher />
```

```tsx
// React
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```tsx
// Solid
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```astro
<!-- Astro -->
<I18nSwitcher />
```

### `<I18nGroup>`

مكوّن لتجميع الترجمات ذات البادئة المشتركة، مفيد لتنظيم الترجمات حسب الصفحة أو الميزة. الميزات:

- **نطاق البادئة** - يُضيف تلقائيًا البادئة إلى جميع مفاتيح الترجمة داخل المجموعة
- **مجموعات متداخلة** - يدعم مجموعات الترجمة المتداخلة
- **تنظيم نظيف** - يساعد على الحفاظ على هياكل ترجمة منظّمة

**مثال:**

```vue
<!-- Vue -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

```tsx
// React
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```tsx
// Solid
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```astro
<!-- Astro -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

## خيارات `createI18n` المشتركة \{#create-i18n-options\}

تُنشأ كل حزمة إطار عمل بالطريقة نفسها — يختلف فقط اسم نوع الخيارات باختلاف إطار العمل (`ReactI18nOptions` و`SolidI18nOptions` وهكذا). الخيارات نفسها متطابقة:

| الخاصية         | النوع                                                       | مطلوب | الافتراضي          | الوصف                                    |
| ---------------- | ---------------------------------------------------------- | -------- | ---------------- | ---------------------------------------------- |
| `locale`         | `string`                                                   | ✅       | -                | رمز اللغة الحالي (مثل `'en'`)             |
| `fallbackLocale` | `string`                                                   | ❌       | نفس `locale` | لغة احتياطية عندما تكون الترجمة مفقودة    |
| `messages`       | `Record<string, Translations>`                             | ❌       | `\{\}`             | رسائل الترجمة الأولية                   |
| `plural`         | `PluralFunc`                                               | ❌       | `defaultPlural`  | دالة تصريف بالعدد مخصّصة                  |
| `missingWarn`    | `boolean`                                                  | ❌       | `true`           | إظهار تحذيرات وحدة التحكّم للترجمات المفقودة |
| `missingHandler` | `(locale: string, key: string, routeName: string) => void` | ❌       | -                | معالج مخصّص للترجمات المفقودة        |

أي شيء يتجاوز هذه الخيارات يكون خاصًا بإطار العمل ومُوثَّقًا في صفحة تلك الحزمة.

## تجريد محوّل الموجّه

تستخدم جميع حزم إطار العمل **نمط محوّل الموجّه** لفصل وظيفة i18n عن تنفيذات موجّه محدّدة. يتيح هذا التصميم:

- **المرونة** - استخدام أي مكتبة توجيه أو عدم استخدام موجّه على الإطلاق
- **الاستقلالية عن إطار العمل** - إبقاء منطق التوجيه في تطبيقك، وليس في حزمة i18n
- **نواة خفيفة الوزن** - تظل حزمة i18n صغيرة ومركّزة

### تنفيذ محوّل الموجّه

لاستخدام ميزات التوجيه، تحتاج إلى تنفيذ واجهة `I18nRoutingStrategy`:

```typescript
interface I18nRoutingStrategy {
  getCurrentPath: () => string
  linkComponent?: Component
  push: (target: { path: string }) => void
  replace: (target: { path: string }) => void
  resolvePath?: (to: string | { path?: string }, locale: string) => string | { path?: string }
  getRoute?: () => { fullPath: string; query: Record<string, unknown> }
}
```

يتضمّن توثيق كل حزمة أمثلة كاملة لتنفيذ المحوّلات للموجّهات الشائعة:

- **Vue**: مثال محوّل Vue Router
- **React**: مثال محوّل React Router
- **Solid**: مثال محوّل Solid Router
- **Astro**: مثال محوّل التوجيه القائم على الملفات

## الميزات الأساسية

تشترك جميع الحزم في هذه الميزات الأساسية:

### دوال الترجمة

- `t()` - ترجمة أساسية مع استيفاء المعلمات
- `ts()` - ترجمة تعيد دائمًا سلسلة نصية
- `tc()` - ترجمة تراعي التصريف بالعدد
- `tn()` - تنسيق الأرقام
- `td()` - تنسيق التاريخ
- `tdr()` - تنسيق الوقت النسبي
- `has()` - التحقق مما إذا كان مفتاح الترجمة موجودًا

### إدارة اللغة

- **تبديل اللغة** - تغيير اللغة الحالية برمجيًا
- **لغة احتياطية** - احتياطي تلقائي عندما تكون الترجمة مفقودة
- **ترجمات خاصة بالمسار** - تنظيم الترجمة على مستوى الصفحة
- **تخزين مؤقت للترجمات** - تخزين مؤقت ذكي للأداء

### دعم TypeScript

توفّر جميع الحزم:

- تعريفات TypeScript كاملة
- مفاتيح ترجمة آمنة من الناحية النوعية (مع مولّد الأنواع)
- دعم IntelliSense في بيئات التطوير المتكاملة
- التحقق من الأخطاء أثناء التصريف

## البدء

1. **اختر حزمتك** - حدّد الحزمة لإطار عملك
2. **ثبّت الحزمة** - استخدم مدير الحزم المفضّل لديك
3. **اقرأ التوثيق** - كل حزمة تحتوي على تعليمات إعداد مفصّلة
4. **نفّذ محوّل الموجّه** - إذا كنت تحتاج إلى ميزات التوجيه، نفّذ المحوّل
5. **ابدأ الترجمة** - استخدم المكوّنات والدوال لإضافة الترجمات
