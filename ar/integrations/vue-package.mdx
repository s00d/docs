`@i18n-micro/vue` إضافة لـ Vue 3 تحمل نواة الترجمة في Nuxt I18n Micro: `t()` تفاعلية، و`$t` عامة، وأربعة مكوّنات، ومحوّل اختياري لـ vue-router. استخدمها في تطبيق Vue مبني بـ Vite أو SSR ولا يعتمد على Nuxt. نموذج النسخة وعقد الموجّه وخصائص المكوّنات مشتركة مع الحزم الأخرى وموصوفة في [أطر العمل](/ar/integrations/overview).

## التثبيت {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vue
```

```bash npm
npm install @i18n-micro/vue
```

```bash yarn
yarn add @i18n-micro/vue
```

</CodeGroup>

الاعتماديات النظيرة: `vue` `^3.3.0`؛ و`vue-router` `^4.5.1 || ^5.0.0` (اختيارية، فقط لـ `@i18n-micro/vue/router`). تحتاج الأنواع المنشورة إلى Vue 3.5.5 أو أحدث مع `skipLibCheck: false`؛ أما مع `skipLibCheck: true`، وهو الإعداد المعتاد في القوالب، فتُترجَم الإصدارات الأقدم أيضًا.

## الإعداد {#setup}

```ts
// src/main.ts
import { createApp } from 'vue'
import { createI18n } from '@i18n-micro/vue'
import App from './App.vue'
import en from './locales/en.json'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales: [
    { code: 'en', iso: 'en-US', displayName: 'English' },
    { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
  ],
  defaultLocale: 'en',
})

createApp(App).use(i18n).mount('#app')
```

`locales` و`defaultLocale` مطلوبتان لـ `useI18n()`: إذ ترمي الخطأ `I18nLocalesKey not provided` بدونهما. مرّرهما إلى `createI18n` (كما في المثال أعلاه)، أو إلى `useI18n({ locales, defaultLocale })`، أو عبر `app.provide(I18nLocalesKey, …)` و`app.provide(I18nDefaultLocaleKey, …)`.

تسجّل الإضافة `I18nT` و`I18nLink` و`I18nGroup` و`I18nSwitcher` عامّةً، وتضيف `$t` و`$ts` و`$tc` و`$tn` و`$td` و`$tdr` و`$has` و`$i18n` إلى القوالب. النسخة هي `i18n.global` خارج المكوّنات. الخيارات الأخرى موجودة في [النسخة](/ar/integrations/overview#the-instance)؛ و`routeMessages` غير متاح في Vue، فاستخدم `addRouteTranslations`.

## الترجمة {#translate}

```vue
<script setup lang="ts">
import { useI18n } from '@i18n-micro/vue'

const { t, tc, tn } = useI18n()
</script>

<template>
  <h1>{{ t('greeting', { name: 'Ada' }) }}</h1>
  <!-- Hello, Ada! -->
  <p>{{ tc('apples', 3) }}</p>
  <!-- 3 apples -->
  <p>{{ $t('nav.home') }} · {{ tn(1234.5) }}</p>
</template>
```

تُرجع `useI18n()` دوال الترجمة (`t`، `ts`، `tc`، `tn`، `td`، `tdr`، `has`)، و`locale` (قيمة محسوبة قابلة للكتابة)، و`getLocale` و`getLocales` و`defaultLocale()` و`getLocaleName` و`localePath` و`localeRoute` و`switchLocale` و`setRoute` و`getRoute` و`addTranslations` و`addRouteTranslations` و`mergeTranslations` و`resolveTranslations` و`setTranslation` و`clearCache` و`instance`.

حمّل مزيدًا من القواميس في أي وقت؛ وسيُعاد عرض كل مكوّن يقرأ منها:

```ts
const { addTranslations, addRouteTranslations, setRoute } = useI18n()

addTranslations('de', (await import('./locales/de.json')).default)
addRouteTranslations('en', 'about', { title: 'About us' })
setRoute('about') // t('title') now reads the 'about' dictionary first
```

## تبديل اللغة {#switch-locale}

```ts
const { locale, switchLocale } = useI18n()

locale.value = 'de' // only the locale
switchLocale('de') // the locale, then router.push to the localized current path
```

حمّل قاموس اللغة قبل التبديل أو بعده؛ فالتبديل لا يجلب أي شيء.

يمنح `<I18nGroup>` الفتحة (slot) الخاصة به دالة `t` ذات بادئة. أما المفاتيح داخل `<I18nT>` أو في `t()` عادية فلا تُضاف إليها البادئة:

```vue
<I18nGroup prefix="profile" v-slot="{ t }">
  <h2>{{ t('title') }}</h2>
  <!-- profile.title -->
</I18nGroup>
```

## التوجيه {#routing}

يقع محوّل vue-router في مسار فرعي بحيث لا يستورد المدخل الرئيسي `vue-router` أبدًا:

```ts
// src/main.ts
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import { createI18n } from '@i18n-micro/vue'
import { createVueRouterAdapter } from '@i18n-micro/vue/router'
import App from './App.vue'
import Home from './pages/Home.vue'
import About from './pages/About.vue'
import en from './locales/en.json'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English' },
  { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
]

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/:locale(de)?', component: Home },
    { path: '/:locale(de)?/about', component: About },
  ],
})

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales,
  defaultLocale: 'en',
  routingStrategy: createVueRouterAdapter(router, locales, 'en'),
})

createApp(App).use(router).use(i18n).mount('#app')
```

يضيف `createVueRouterAdapter(router, locales, defaultLocale)` بادئة لكل لغة باستثناء الافتراضية (`/about`، `/de/about`) ويعرض `<I18nLink>` على هيئة `RouterLink`. اقرأ اللغة من المسار بنفسك، مثلًا في `router.beforeEach`، وعيّن `i18n.global.locale.value`. ويمكنك أيضًا إرفاق محوّل لاحقًا باستخدام `i18n.setRoutingStrategy(adapter)`؛ وللمحوّل المخصص راجع [محوّل الموجّه](/ar/integrations/overview#router-adapter).

## SSR {#ssr}

- أنشئ الموجّه ونسخة i18n والتطبيق داخل دالة العرض الخاصة بكل طلب. فالنسخة المشتركة الواحدة ستسرّب لغة زائر إلى زائر آخر.
- استخدم `createMemoryHistory()` على الخادم، وخذ اللغة من عنوان URL، وحمّل قاموسها (وقاموس اللغة الاحتياطية) قبل `renderToString`.
- أرسل اللغة إلى العميل (مثلًا في وسم script باسم `window.__STATE__`) وأنشئ نسخة العميل بنفس `locale` ليتطابق الترطيب.
- لا يقرأ `<I18nSwitcher>` قيمة `window.location` إلا عند فتح القائمة المنسدلة، لذا يُعرض على الخادم.

يحتوي `packages/vue/playground` على زوج كامل من `entry-server.ts` / `entry-client.ts`.

## ترويسة SEO {#seo-head}

تبني `useLocaleHead(options)` وسوم `lang`/`dir` والرابط القانوني (canonical) و`hreflang` و`og:locale` من اللغات ومحوّل الموجّه. استدعِ `updateMeta()` عند تغيّر المسار ومرّر `metaObject` إلى مدير الترويسة لديك:

```ts
import { watch } from 'vue'
import { useRoute } from 'vue-router'
import { useHead } from '@unhead/vue'
import { useLocaleHead } from '@i18n-micro/vue'

const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
watch(() => route.fullPath, () => updateMeta(), { immediate: true })
useHead(metaObject)
```

الخيارات: `baseUrl` (سلسلة نصية أو دالة)، و`addDirAttribute` (الافتراضي `true`)، و`addSeoAttributes` (الافتراضي `true`)، و`identifierAttribute` (الافتراضي `'id'`)، و`hreflangBaseLanguage` (الافتراضي `false`). اللغات التي لها `disabled: true` أو `seo: false` لا تحصل على رابط بديل.

## API {#api}

| التصدير | المدخل |
| --- | --- |
| `createI18n`، `useI18n`، `useLocaleHead` | `@i18n-micro/vue` |
| `I18nT`، `I18nLink`، `I18nSwitcher`، `I18nGroup` | `@i18n-micro/vue` |
| `VueI18n` (صنف النسخة)، `I18nInjectionKey`، `I18nLocalesKey`، `I18nDefaultLocaleKey` | `@i18n-micro/vue` |
| `defaultPlural`، `FormatService`، `interpolate` | `@i18n-micro/vue` |
| الأنواع: `I18nRoutingStrategy`، `Locale`، `Translations`، `PluralFunc`، `Params`، `Getter`، `CleanTranslation`، `LocaleCode`، `VueI18nOptions`، `UseI18nOptions`، `UseLocaleHeadOptions`، `I18nPlugin` | `@i18n-micro/vue` |
| `createVueRouterAdapter` | `@i18n-micro/vue/router` |

لا يُعاد تصدير `TranslationKey` من `@i18n-micro/vue`؛ استورده من `@i18n-micro/types`. التوقيعات الكاملة: [مرجع الحزمة](/ar/api/packages/vue).
