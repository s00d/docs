`@i18n-micro/devtools-ui` هو محرر الترجمات الموجود في تبويب Nuxt DevTools، مُحزَّمًا كمكوّن ويب مع إضافة Vite. أضفه إلى مشروع Vue أو React أو Preact أو Solid أو Astro لتصفّح ملفات JSON في مجلد الترجمات وتحريرها من المتصفح أثناء التطوير. تطبيقات Nuxt تملكه أصلًا في [Nuxt DevTools](/ar/guide/devtools).

![واجهة DevTools: شجرة ملفات ومحرر يعرض نص اللغة الافتراضية بجوار كل مفتاح](/images/devtools/02-translations-editor-dark.webp)

## التثبيت {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/devtools-ui
```

```bash npm
npm install -D @i18n-micro/devtools-ui
```

```bash yarn
yarn add -D @i18n-micro/devtools-ui
```

</CodeGroup>

لا توجد اعتماديات نظيرة (peer dependencies).

## الإعداد {#setup}

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import { i18nDevToolsPlugin } from '@i18n-micro/devtools-ui/vite'

export default defineConfig({
  plugins: [i18nDevToolsPlugin({ translationDir: 'src/locales' })],
})
```

| الخيار | الافتراضي | ملاحظات |
| --- | --- | --- |
| `translationDir` | `'src/locales'` | المجلد الذي يحوي ملفات JSON، نسبةً إلى جذر Vite. |
| `base` | `'/__i18n_api'` | المسار الأساسي لنقاط نهاية API. |
| `injectButton` | `true` | إضافة زر عائم إلى الصفحات المقدَّمة عبر تحويل `index.html` في Vite. لا توجد مثل هذه الصفحات في Astro: انظر أدناه. |
| `defaultLocale` | أول ملف لغة في `translationDir` | يُبلَّغ عنه عبر `/config`. |
| `fallbackLocale` | `defaultLocale` | يُبلَّغ عنه عبر `/config`. |

تعمل الإضافة على خادم التطوير فقط (`apply: 'serve'`)؛ ولا يحتوي بناء الإنتاج على أي شيء منها. يفتح الزر `/__i18n_devtools.html`، الذي يقرأ الملفات ويحفظها عبر نقاط نهاية الإضافة:

| نقطة النهاية | وظيفتها |
| --- | --- |
| `GET <base>/translations` | كل قاموس ضمن `translationDir`، مفهرسًا بالمسار النسبي |
| `POST <base>/save` | الجسم `{ file, content }`؛ يكتب فوق ملف `.json` موجود داخل `translationDir`، ويعيد 403 لأي شيء آخر. لا ينشئ ملفًا أبدًا |
| `GET <base>/config` | `{ defaultLocale, fallbackLocale, locales, translationDir }`؛ تأتي `locales` من الملفات الجذرية في `translationDir` |

لا تجيب نقاط النهاية إلا صفحة أدوات التطوير: الطلب القادم من أصل أو مضيف آخر يُقابَل بـ `403`، ولا تقبل `/save` إلا `application/json` (`415`). وتعلم الصفحة بتغييرات الملفات عبر مقبس HMR الخاص بـ Vite.

في Astro، أضف التكامل بدلًا من الإضافة. فهو يضيف تطبيقًا إلى شريط أدوات التطوير:

```ts
// astro.config.mjs
import { defineConfig } from 'astro/config'
import { i18nDevToolsIntegration } from '@i18n-micro/devtools-ui/vite'

export default defineConfig({
  integrations: [i18nDevToolsIntegration({ translationDir: 'src/locales' })],
})
```

الحفظ يكتب الملف فقط. التطبيق الذي يستورد JSON عبر Vite يحصل عليه عبر HMR؛ أما لتطبيق التعديلات على النسخة العاملة مباشرة، فاستخدم جسرًا.

## الجسر إلى نسخة عاملة {#bridge-to-a-live-instance}

لتضمين المحرر في صفحتك الخاصة وتطبيق التعديلات على النسخة العاملة فورًا، أنشئ جسرًا من محوّل (adapter) ومرّره إلى العنصر `<i18n-devtools-ui>`:

```ts
import { createBridge, register } from '@i18n-micro/devtools-ui'
import { i18n, locales } from './i18n' // a runtime, React, Preact or Solid instance

register() // defines <i18n-devtools-ui> once

const bridge = createBridge({
  adapter: {
    getRouteCache: () => Object.fromEntries(i18n.storage.translations),
    addTranslations: (locale, content, merge) => i18n.addTranslations(locale, content, merge),
    addRouteTranslations: (locale, route, content, merge) => i18n.addRouteTranslations(locale, route, content, merge),
    subscribe: (cb) => i18n.subscribe(cb),
    getCurrentLocale: () => i18n.locale,
  },
  locales,
  defaultLocale: 'en',
  translationDir: 'src/locales',
})

const el = document.createElement('i18n-devtools-ui') as HTMLElement & { bridge: typeof bridge }
el.bridge = bridge
document.body.append(el)
```

يجب أن يُرجع `getRouteCache` القواميس مفهرسة بالصيغة `locale:route` (`en:index`، `en:blog-post`)، وهو ما يحتويه `i18n.storage.translations`. أما لنسخة Vue فاستخدم `i18n.global.getRouteCache()` و`i18n.global.subscribeToChanges(cb)`.

يحدّث `saveTranslation` النسخة أولًا، ثم يرسل طلب POST إلى `<base>/save`. وعند عدم وجود نقطة نهاية (بناء معاينة ثابت) أو تعذّر الوصول إلى خادم التطوير، يُحتفظ بالتعديل في `localStorage`؛ وأي خطأ حفظ آخر يستعيد القاموس السابق ويرمي استثناءً.

## API {#api}

| التصدير | المدخل |
| --- | --- |
| `i18nDevToolsPlugin(options)`، `i18nDevToolsIntegration(options)` | `@i18n-micro/devtools-ui/vite` |
| `register()`، `I18nDevToolsElement` | `@i18n-micro/devtools-ui` |
| `createBridge(options)`، والأنواع `BridgeAdapter`، `CreateBridgeOptions` | `@i18n-micro/devtools-ui` (وأيضًا `/bridge/create`) |
| النوع `I18nDevToolsBridge` | `@i18n-micro/devtools-ui` (وأيضًا `/bridge`) |
| `createRpcClient`، `setupRpcHost` | `@i18n-micro/devtools-ui` |

التوقيعات الكاملة: [مرجع الحزمة](/ar/api/packages/devtools-ui).
