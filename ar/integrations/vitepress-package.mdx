تضيف `@i18n-micro/vitepress` قواميس وقت التشغيل إلى موقع VitePress: ‏`$t` و`<I18nT>` داخل markdown، ودوال مساعدة للمسارات، ووسوم SEO، وهي مبنية على [`@i18n-micro/vue`](/ar/integrations/vue-package). استخدمها عندما تظهر نصوص الواجهة نفسها في صفحات كثيرة ولا تريد تكرارها لكل لغة. تتبع اللغة لغات المسارات الخاصة بـ VitePress نفسها (`/`، `/fr/`).

## متى تستخدمها {#when-to-use-it}

| الحاجة | الحل |
|------|----------|
| ملفات `.md` مكررة، وبادئات عناوين URL | `locales` في VitePress |
| `$t` وقت التشغيل / المكونات / مزامنة المسار / ترويسة SEO | `@i18n-micro/vitepress` |
| تسميات واجهة السمة الافتراضية (`docFooter`، واجهة البحث) | `themeConfig` الخاص بك لكل لغة |

<Tip>

**بيئة التجربة** — [`packages/vitepress/playground`](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/vitepress/playground) — `pnpm -C packages/vitepress/playground dev`

</Tip>

## التثبيت {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vitepress
```

```bash npm
npm install @i18n-micro/vitepress
```

```bash yarn
yarn add @i18n-micro/vitepress
```

</CodeGroup>

التبعيات النظيرة: `vitepress` `>=1.0.0 || >=2.0.0-alpha.0`، و`vue` `^3.3.0`. تستخدم سكربتات Node الحزمة `@i18n-micro/node`، التي تُثبَّت مع الحزمة ويُعاد تصديرها عبر `/node`. تحتاج الأنواع المنشورة إلى Vue 3.5.5 أو أحدث مع `skipLibCheck: false`؛ أما مع `skipLibCheck: true`، وهو الإعداد المعتاد في القوالب، فتُترجم الإصدارات الأقدم أيضًا.

## الإعداد {#setup}

```
locales/en.json
locales/fr.json
locales/pages/guide/demo/en.json   # optional page-scoped
locales/pages/guide/demo/fr.json
```

تُربط ملفات الصفحات بأسماء المسارات بالطريقة نفسها المتبعة في Nuxt/Astro (`guide/demo` → `guide-demo`).

### 1. الإعدادات — `@i18n-micro/vitepress/config` {#1-config-—-@i18n-micro/vitepress/config}

```ts
// .vitepress/config.mts
import { defineConfig } from 'vitepress'
import { withI18n, buildVitePressLocales } from '@i18n-micro/vitepress/config'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English', og: 'en_US' },
  { code: 'fr', iso: 'fr-FR', displayName: 'Français', og: 'fr_FR' },
]
const defaultLocale = 'en'

export default defineConfig(
  withI18n(
    {
      locales: buildVitePressLocales(locales, defaultLocale),
      // themeConfig.i18nRouting is injected automatically
    },
    {
      locale: defaultLocale,
      defaultLocale,
      locales,
      translationDir: 'locales',
      metaBaseUrl: 'https://example.com', // optional SEO head
    },
  ),
)
```

### 2. السمة — `@i18n-micro/vitepress/theme` {#2-theme-—-@i18n-micro/vitepress/theme}

```ts
// .vitepress/theme/index.ts
import DefaultTheme from 'vitepress/theme'
import { defineI18nTheme } from '@i18n-micro/vitepress/theme'

export default defineI18nTheme(DefaultTheme)
```

تُؤخذ اللغة الأولية من المسار الحالي قبل التثبيت (لا وميض للغة الافتراضية على `/fr/…`).

### متقدم: `createI18n` يدويًا {#advanced-manual-createi18n}

مصنع واحد للعميل: إضافة Vue + دوال المسارات + `enhanceApp` (دون تصديرات منفصلة لدوال الموجّه المساعدة).

```ts
import { createI18n, messagesFromGlob } from '@i18n-micro/vitepress'

const i18n = createI18n({
  locale: 'en',
  defaultLocale: 'en',
  locales: [{ code: 'en' }, { code: 'fr' }],
  messages: messagesFromGlob(import.meta.glob('../../locales/*.json', { eager: true })),
})

i18n.localizePath('/guide', 'fr')
// in theme enhanceApp:
i18n.enhanceApp({ app, router })
```

### سكربتات Node — `@i18n-micro/vitepress/node` {#node-scripts-—-@i18n-micro/vitepress/node}

تستخدم `createI18n` / `loadTranslations` من `@i18n-micro/node` (كما في Astro وCLI)، ثم تُرفق دوال مسارات VitePress باستخدام `BaseI18n.extend`:

```ts
import { createI18n } from '@i18n-micro/vitepress/node'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  translationDir: './locales',
  locales: ['en', 'fr'],
  defaultLocale: 'en',
})
await i18n.loadTranslations()
i18n.t('cta.readMore')
i18n.localizePath('/guide', 'fr')
```

Node العادي دون مسارات: `import { createI18n } from '@i18n-micro/node'`.

## الترجمات داخل الصفحة {#in-page-translations}

كل ملف markdown في VitePress هو مكوّن Vue أحادي الملف (SFC).

### المكونات العامة و`$t` (موصى بها في markdown) {#global-components-and-$t-recommended-in-markdown}

تثبّت `createI18n` / `defineI18nTheme` الحزمة `@i18n-micro/vue`، التي تسجّل `I18nT` / `I18nLink` / `I18nGroup` / `I18nSwitcher` و`$t` / `$tc` / `$ts`.

```md
{{ $t('cta.readMore') }}

<I18nT keypath="greeting" :params="{ name: 'VitePress' }" />

<I18nLink to="/guide/demo">Demo</I18nLink>
```

### `useI18n` في `<script setup>` {#usei18n-in-<script-setup>}

```md
<script setup>
import { useI18n } from '@i18n-micro/vitepress'
const { t, tc, locale, localePath, switchLocale } = useI18n()
</script>

# {{ t('section.title') }}
```

## القائمة المنسدلة للغات {#language-dropdown}

عندما تحتوي `locales` على أكثر من إدخال واحد، يعرض VitePress قائمة اللغات الخاصة به (`VPNavBarTranslations`). يربط `withI18n` الإعداد `themeConfig.i18nRouting` لكي تتطابق أيقونة الكرة الأرضية مع `<I18nSwitcher>` / الدوال المساعدة للمسارات.

استخدم `<I18nSwitcher>` في التخطيطات المخصصة فقط، وليس بجوار أيقونة الكرة الأرضية الافتراضية.

## ملاحظات SSR {#ssr-notes}

- تأتي اللغة عند العرض المسبق من مسار عنوان URL، وليس من ملفات تعريف الارتباط.
- يجب ألا تلمس شيفرة السمة `window` وقت الاستيراد.
- استورد `defineI18nTheme` من `/theme` لكي لا يحمّل تقييم الإعدادات في Node أبدًا `virtual:i18n-micro/*`.

## واجهة API المتاحة {#api-surface}

| التصدير | الدور |
|--------|------|
| `createI18n` (`.`) | العميل: إضافة Vue + دوال المسارات + `enhanceApp` |
| `getLocaleFromPath` / `stripSiteBase` / `routeNameFromPath` (`.`) | مزامنة اللغة يدويًا عند `syncWithVitePress: false` |
| `createI18n` (`/node`) | Node: ‏`@i18n-micro/node` + دوال المسارات |
| `defineI18nTheme` (`/theme`) | سمة دون شيفرة متكررة |
| `withI18n` (`/config`) | الإعدادات + الوحدات الافتراضية + SEO اختياري |
| `buildVitePressLocales` (`/config`) | بناء `locales` الخاصة بـ VitePress من `Locale[]` |
| `buildVitePressLocaleHead` (`/config`) | ترويسة SEO يدوية (تستخدمها `metaBaseUrl` أيضًا) |
| `messagesFromGlob` | تحويل اختياري من glob إلى خريطة رسائل لـ `createI18n` |
| `useI18n` / `I18nT` / … | يُعاد تصديرها من `@i18n-micro/vue` |
| `BaseI18n.extend` (`@i18n-micro/core`) | إرفاق دوال مخصصة بأي نسخة i18n |

## المواقع على غرار OpenAPI (أقفال التكامل) {#openapi-style-sites-integration-locks}

مجموعة اختبارات الانحدار: `packages/vitepress/tests/integration-openapi.test.ts` (مسارات عميقة، `base=/openapi_docs/`، المزامنة معطّلة + لغة يدوية، مولّدات Node، SEO).

| النمط | افعل ما يلي |
|---------|---------|
| صفحات عميقة `/…/{spec}/{op}`، مع ملفات JSON لواجهة الجذر فقط | فضّل الإعداد الافتراضي `syncWithVitePress: true` (يحتفظ بـ `setRoute('index')` عند عدم وجود قاموس للصفحة) **أو** `syncWithVitePress: false` + `getLocaleFromPath` |
| لا تستدعِ أبدًا `setRoute(deepName)` دون قواميس صفحات | تختفي مفاتيح واجهة الجذر حتى `setRoute('index')` |
| المولّدات / `getTranslation` | `createI18n` من `/node` + `await loadTranslations()` + `i18n.t(key)` (عيّن `i18n.locale`) |
| رابط canonical مخصص في `transformPageData` | مرّر `meta: false` إلى `withI18n` (لتجنب تكرار الوسوم) |
| SEO الحزمة مع قاعدة الموقع | `metaBaseUrl` + `base` في VitePress ← تتضمن عناوين URL المطلقة القاعدة |
| إعادة التسمية من إصدارات الحزمة الأقدم | `withI18nMicro` → `withI18n`، `createVitePressI18n` → `createI18n`، `loadMessages` → `createI18n` من node |
