تتيح تجاوزات وقت التشغيل تشغيل ناتج بناء واحد بإعدادات locale مختلفة لكل بيئة أو مستأجر، دون إعادة البناء. يمكنك تغيير الـ locale الافتراضي، والـ locale الاحتياطي، والـ locales المعطَّلة. يستخدم التوجيه وإعادة التوجيه والعرض والدوال المساعدة على الخادم القيم المتجاوَزة، وكذلك المتصفح في الصفحة المعروضة على الخادم.

## اضبط التجاوزات باستخدام متغيرات البيئة {#set-overrides-with-environment-variables}

```bash
NUXT_I18N_DEFAULT_LOCALE=de \
NUXT_I18N_FALLBACK_LOCALE=en \
NUXT_I18N_DISABLED_LOCALES=fr,it \
node .output/server/index.mjs
```

| المتغير | الاسم البديل |
| --- | --- |
| `NUXT_I18N_DEFAULT_LOCALE` | `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE` |
| `NUXT_I18N_FALLBACK_LOCALE` | `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE` |
| `NUXT_I18N_DISABLED_LOCALES` (مفصولة بفواصل) | `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES` |

يقرأها الخادم مرة واحدة عند البدء؛ أعد التشغيل لتطبيق أي تغيير. في الصفحة المعروضة على الخادم، يحصل المتصفح على القيم المحلولة من الخادم. مع `ssr: false` لا يوجد عرض على الخادم ولا يملك المتصفح بيئة: لا يُطبَّق هناك إلا `runtimeConfig.public.i18nRuntime`، ويسجّل المتصفح التحذيرات أدناه.

## اضبط التجاوزات في runtimeConfig {#set-overrides-in-runtimeconfig}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

القيمة المضبوطة في `runtimeConfig.public.i18nRuntime` تتغلب على متغير `NUXT_I18N_*` للحقل نفسه.

لا تخلط بينها وبين المتغير `DEFAULT_LOCALE` الخاص بوقت البناء، الذي يستبدل `defaultLocale` أثناء البناء ولا يحتاج إلى دعم في وقت التشغيل.

## ما يمكن تغييره وما لا يمكن {#what-can-and-cannot-change}

| الإعداد | في وقت التشغيل |
| --- | --- |
| `defaultLocale` | نعم مع `prefix` و`no_prefix`. مع `prefix_except_default` و`prefix_and_default` يكون ثابتًا عند البناء (صفحاته هي المسارات بلا بادئة)؛ ويُتجاهل التجاوز مع تحذير. |
| `fallbackLocale` | نعم. |
| `disabledLocales` | يُضاف إلى الـ locales المعطَّلة عند البناء؛ ولا يعيد تفعيل أي منها أبدًا. لا يمكن تعطيل الافتراضي المحدد عند البناء مع `prefix_except_default` / `prefix_and_default`. |
| `strategy` | لا. تُتجاهل الاستراتيجية المحددة في وقت التشغيل مع تحذير؛ ابنِ ناتجًا واحدًا لكل استراتيجية. |

القيم غير الصالحة لا تعطّل التطبيق أبدًا. تسجّل كل حالة تحذيرًا واحدًا لكل عملية خادم:

- يُتجاهل تعطيل جميع الـ locales؛
- يعود `defaultLocale` غير المفعَّل إلى أول locale مفعَّل؛
- يحتفظ `fallbackLocale` غير المفعَّل بقيمة البناء إن كانت مفعَّلة، وإلا فلا يوجد احتياطي.

## اقرأ الإعداد الفعلي {#read-the-effective-config}

```vue
<script setup lang="ts">
const { $getI18nConfig } = useNuxtApp()
const config = $getI18nConfig() // build config with overrides applied
</script>
```

تعامل معه على أنه للقراءة فقط: على الخادم تتشاركه جميع الطلبات ويكون مجمَّدًا في وضع التطوير؛ أما نسخة المتصفح فليست مجمَّدة. استيراد الإعداد من `#build/i18n.strategy.mjs` يعطي قيم البناء دون تجاوزات.

## الـ locales المعطَّلة والملفات الثابتة {#disabled-locales-and-static-files}

يستجيب الـ locale المعطَّل في وقت التشغيل بـ 404 على مساراته ومسار حمولته، لكن ملفات حمولته تظل في `.output/public/_locales/` ويعيدها خادم الملفات الثابتة. عندما يجب ألا تكون تلك الملفات قابلة للوصول، عطّل الـ locale في وقت البناء باستخدام `disabled: true`.
