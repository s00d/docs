تطابق هذه الصفحة تطبيق `@nuxtjs/i18n` مع nuxt-i18n-micro: الخيارات والدوال المساعدة وتخطيط الملفات. استخدمها عند استبدال الوحدة في تطبيق قائم. تحتفظ بعناوين URL الخاصة بك (أسماء الاستراتيجيات هي نفسها) وتنقل الترجمات إلى ملفات JSON لكل صفحة.

<Tip>

**هل تُرقّي nuxt-i18n-micro نفسها؟** — راجع [الترقية](/ar/guide/upgrade).

</Tip>

## استبدل الوحدة {#swap-the-module}

```bash
npm uninstall @nuxtjs/i18n
npm install nuxt-i18n-micro
```

```ts
// nuxt.config.ts — before
export default defineNuxtConfig({
  modules: ['@nuxtjs/i18n'],
  i18n: {
    locales: [
      { code: 'en', language: 'en-US', file: 'en.json' },
      { code: 'de', language: 'de-DE', file: 'de.json' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    langDir: 'locales',
    detectBrowserLanguage: { useCookie: true, cookieKey: 'i18n_redirected', redirectOn: 'root' },
  },
})
```

```ts
// nuxt.config.ts — after
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    translationDir: 'locales',
    localeCookie: 'i18n_redirected',
    autoDetectPath: '/',
  },
})
```

## الخيارات {#options}

| `@nuxtjs/i18n` | nuxt-i18n-micro |
| --- | --- |
| `locales[].code` | `locales[].code` |
| `locales[].language` (`iso` قبل v9) | `locales[].iso` |
| `locales[].name` | `locales[].displayName` |
| `locales[].dir` | `locales[].dir` |
| `locales[].domain` | `locales[].baseUrl` (أصل مع مخططه) |
| `locales[].domainDefault` | `locales[].baseDefault` |
| `differentDomains`, `multiDomainLocales` | غير مطلوب: يكفي `baseUrl` وحده للتوجيه حسب المضيف، راجع [الطبقات والنطاقات](/ar/guide/layers#multiple-domains) |
| `locales[].file` / `files`, `langDir`, `lazy` | `translationDir`؛ يُعثر على الملفات بالاسم وتُحمَّل دائمًا لكل صفحة |
| `defaultLocale`, `strategy` | الأسماء نفسها، والقيم الأربع نفسها |
| `baseUrl` | `metaBaseUrl` |
| `customRoutes: 'config'` + `pages` | `globalLocaleRoutes` |
| `detectBrowserLanguage: false` | `redirects: false` (بلا إعادة توجيه) أو `autoDetectLanguage: false` (تجاهل الترويسة) |
| `detectBrowserLanguage.useCookie` / `cookieKey` | `localeCookie: '<name>'` (تعطّل `null` ملف تعريف الارتباط) |
| `detectBrowserLanguage.redirectOn: 'root'` | `autoDetectPath: '/'` (افتراضي) |
| `detectBrowserLanguage.redirectOn: 'no prefix'` | `autoDetectPath: 'no_prefix'` |
| `detectBrowserLanguage.redirectOn: 'all'` | `autoDetectPath: '*'` |
| ملف إعداد `vueI18n` (`fallbackLocale`, `numberFormats`, `datetimeFormats`) | `fallbackLocale`, `numberFormats`, `datetimeFormats` في `i18n` |

لا يوجد `alwaysRedirect`: عند ضبط ملف تعريف الارتباط، تتبعه `/` في كل زيارة. القائمة الكاملة في [خيارات الوحدة](/ar/api/module-options)؛ وقواعد الاكتشاف في [اكتشاف الـ locale](/ar/guide/locale-detection).

## الدوال المساعدة والـ composables {#helpers-and-composables}

| `@nuxtjs/i18n` / vue-i18n | nuxt-i18n-micro (القالب / `useI18n()`) |
| --- | --- |
| `const { t } = useI18n()` | `const { t } = useI18n()`، و`$t` في القوالب |
| `t('key', count)`, `tc` | `$tc('key', count)` |
| `te('key')` | `$has('key')` |
| `n(value, 'currency')`, `d(date, 'short')` | `$tn(value, 'currency')`, `$td(date, 'short')` |
| — | `$tdr(date)`: وقت نسبي ("in 3 days") |
| `locale.value` | `$getLocale()` |
| `locales.value` | `$getLocales()` |
| `setLocale('de')` | `$switchLocale('de')` |
| `useLocalePath()('about')` | `$localePath({ name: 'about' })` |
| `useLocaleRoute()` | `$localeRoute()` |
| `useSwitchLocalePath()('de')` | `$switchLocalePath('de')` |
| `useSetI18nParams()` | `$setI18nRouteParams()` |
| `useLocaleHead()` | تلقائي مع `meta: true`؛ و[`useLocaleHead`](/ar/composables/useLocaleHead) لترويسات head مخصصة |
| `defineI18nRoute({ paths: { de: '/ueber-uns' }, locales: [...] })` | `$defineI18nRoute({ localeRoutes: { de: '/ueber-uns' }, locales: [...] })` |
| `<NuxtLinkLocale to="about">` | `<i18n-link :to="{ name: 'about' }">` |
| `<i18n-t>` | `<i18n-t>` (تملأ الـ slots العناصر النائبة `{name}`) |
| `$i18n` في مسارات الخادم | `useTranslationServerMiddleware(event)`، راجع [مسارات الخادم وAPI](/ar/guide/server-side-translations) |

يُستورد `useI18n()` تلقائيًا. يجب أن يحتفظ `$defineI18nRoute` بالرمز `$`: إذ يقرأ البناء هذا الاستدعاء. جميع الدوال المساعدة: [الدوال](/ar/api/methods).

## ملفات الترجمة {#translation-files}

انقل مفاتيح الملف الكبير الواحد لكل locale إلى ملف جذر بالإضافة إلى ملف واحد لكل صفحة:

```text
locales/
├── en.json              # keys used on many pages (nav, footer)
├── de.json
└── pages/
    ├── index/en.json    # keys of pages/index.vue
    └── about/en.json    # keys of pages/about.vue
```

إبقاء كل شيء في ملفات الجذر يعمل أيضًا، وهو أسرع خطوة أولى. اضبط `disablePageLocales: true` حتى تقسّمها. راجع [ملفات الترجمة](/ar/guide/translations).

### صياغة الرسائل {#message-syntax}

| vue-i18n | nuxt-i18n-micro |
| --- | --- |
| إقحام مسمّى `{name}` | نفسه |
| `car \| cars` (صيغتان: 1 → الأولى) | تُختار الصيغ حسب العدد بدءًا من 0: اكتب `no cars \| one car \| {count} cars` |
| رسائل مرتبطة `@:other.key` | غير مدعومة: كرّر النص أو ركّبه في الكود |
| معدِّلات `@.upper:` | غير مدعومة: نسّق في الكود أو استخدم `<i18n-t>` |
| تهريب حرفي `{'@'}` | غير مطلوب: لا يُستبدل إلا رموز `{word}` |
| ملفات رسائل JS/TS | JSON فقط |

يمكن استبدال قاعدة الجمع باستخدام الخيار [`plural`](/ar/api/module-options#plural).

## تحقق بعد التبديل {#check-after-the-switch}

- كل عنوان URL كان لديك لا يزال يُحَل؛ أسماء الاستراتيجيات متطابقة، وتنتقل المسارات المخصصة إلى `globalLocaleRoutes` أو `$defineI18nRoute`.
- تأتي `hreflang` وcanonical و`og:locale` جاهزة مع `meta: true`؛ أزل ما كتبته يدويًا.
- يسجّل خطأ تحليل JSON مسار الملف؛ ويسجّل المفتاح المفقود تحذيرًا في وحدة تحكم المتصفح في وضع التطوير.
