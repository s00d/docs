بعض المسارات يجب ألا تحصل أبدًا على بادئة لغة أو إعادة توجيه بحسب اللغة: منطقة الإدارة، أو فحص السلامة، أو موجز مُولَّد. يحدد `excludePatterns` هذه المسارات، كما تغطي قائمة مدمجة بالفعل المكونات الداخلية لـ Nuxt والملفات الثابتة الشائعة. تحتفظ الصفحة المستثناة بالمسار الذي كتبته تمامًا وتظل تُعرض باستخدام `$t`.

## استثناء مسار {#exclude-a-path}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    excludePatterns: [
      '/admin', // /admin and everything below it
      '/preview-*', // glob over the whole path
    ],
  },
})
```

مع هذا الإعداد، لا تستجيب `pages/admin/index.vue` إلا على `/admin`؛ فلا يوجد `/de/admin`، ولا يُعاد توجيه `/admin` أبدًا إلى `/de/admin`.

## صيغة الأنماط {#pattern-syntax}

تُطابَق الأنماط مع المسار دون `app.baseURL`:

| النمط | يطابق | لا يطابق |
| --- | --- | --- |
| `'/admin'` | `/admin`، `/admin/users` | `/administrator`، `/de/admin` |
| `'/preview-*'` | `/preview-1`، `/preview-a/b` | `/de/preview-1` |
| `'/file-?'` | `/file-a` | `/file-ab` |
| `/^\/v\d+\//` | `/v2/docs` | `/docs` |

السلسلة النصية التي لا تحتوي على `*` أو `?` تطابق المسار والمقاطع الكاملة التي تقع تحته. أما مع `*` (أي تسلسل من الأحرف، بما في ذلك الشرطات المائلة) أو `?` (حرف واحد) فيجب أن تطابق المسار كاملًا. ابدأ السلاسل النصية دائمًا بـ `/`.

## ما هو مستثنى مسبقًا {#what-is-excluded-already}

لا تحصل هذه المسارات أبدًا على مسارات لغات أو إعادات توجيه، دون أي إعداد:

- `/api` و`/_nuxt`، وكل ما يقع تحتهما؛
- مسار الترجمات، وهو `/_locales` افتراضيًا ([`apiBaseUrl`](/ar/api/module-options#apibaseurl))؛
- أي مسار يحتوي على مقطع يبدأ بـ `__` (`/__nuxt_content`، `/en/__og-image__`)؛
- `/sitemap*.xml`، `/robots.txt`، `/favicon.ico`، `/apple-touch-icon*.png`، `/manifest.json`، `/sw.js`، `/workbox-*.js`؛
- أي مسار ينتهي مقطعه الأخير بامتداد ملف ثابت: `xml txt ico json js css png jpg jpeg gif svg webp avif pdf wasm map mp4 webm mp3 zip gz woff woff2 ttf eot`. تبقى المعرّفات النصية للصفحات التي تحتوي على نقاط مثل `/user/john.doe` ومسارات `.html` صفحاتٍ عادية.

## ما الذي يفعله الاستثناء {#what-an-exclusion-does}

- **المسارات:** لا تُولَّد أي نسخ مترجمة؛ تبقى الصفحة كما كُتبت.
- **إعادات التوجيه وأخطاء 404:** تتخطى إضافة إعادة التوجيه على الخادم وبرمجية إعادة التوجيه الوسيطة على العميل هذا المسار.
- **العرض المسبق:** تُزال المسارات المطابقة من قائمة مسارات العرض المسبق.

لا يمنع ذلك برمجية i18n الوسيطة على الخادم من اكتشاف لغة للطلب، ولا يمنع الصفحة من استخدام الترجمات. لإبقاء صفحة مترجمة مع استبعادها من وسوم SEO، استخدم `disableMeta` ([إعدادات الصفحة](/ar/guide/per-component-translations#turn-off-seo-tags)). ولإبقاء صفحة واحدة غير مترجمة من `nuxt.config.ts` حسب المسار، فإن `globalLocaleRoutes: { '/admin': false }` ([المسارات المترجمة](/ar/guide/custom-locale-routes#in-nuxt-config)) يفعل الشيء نفسه بالنسبة للتوجيه.
