تنقلك هذه الصفحة بتطبيق Nuxt من عدم وجود i18n إلى صفحة مترجمة مع مبدّل للغة. تحتاجها مرة واحدة، في بداية المشروع. وفي النهاية ستحصل على عناوين URL مترجمة (`/about` و`/de/about`)، وملف JSON واحد لكل لغة وصفحة، و`$t` في قوالبك.

## التثبيت {#install}

تحتاج الوحدة إلى Nuxt 3.18 أو أحدث (يعمل Nuxt 4 أيضًا) وNode 20 أو أحدث.

<CodeGroup>

```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>

## إعداد اللغات {#configure-the-locales}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', displayName: 'English' },
      { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
      { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
    ],
    defaultLocale: 'en',
  },
})
```

هذه كل الإعدادات التي يحتاجها تطبيقك الأول. تمنحك القيم الافتراضية ما يلي:

- `strategy: 'prefix_except_default'`: اللغة الافتراضية بلا بادئة (`/about`)، والبقية ببادئة (`/de/about`). راجع [استراتيجيات التوجيه](/ar/guide/strategy).
- `translationDir: 'locales'`: توجد ملفات الترجمة في `locales/` في جذر المشروع، حتى مع تخطيط `app/` في Nuxt 4.
- `meta: true`: وسوم `hreflang` وcanonical و`og:locale`، إضافة إلى `lang` و`dir` على `<html>`. راجع [SEO](/ar/guide/seo).
- يُرسَل الزائر الذي يفتح `/` إلى اللغة التي يطلبها متصفحه (`Accept-Language`). راجع [اكتشاف اللغة](/ar/guide/locale-detection).

`iso` هو وسم اللغة المستخدم في وسوم SEO؛ و`code` هو ما يظهر في عنوان URL. كل الخيارات مُدرجة في [خيارات الوحدة](/ar/api/module-options).

## إضافة ملفات الترجمة {#add-translation-files}

شغّل خادم التطوير باستخدام `nuxt dev`. عندما يحلّل Nuxt الصفحات، تُنشئ الوحدة ملفًا فارغًا `{}` لكل لغة وصفحة ليس لها ملف (أوقف ذلك باستخدام [`disableWatcher`](/ar/api/module-options#disablewatcher)):

```text
locales/
├── en.json            # root: keys every page can use
├── de.json
├── fr.json
└── pages/
    ├── index/         # pages/index.vue
    │   ├── en.json
    │   ├── de.json
    │   └── fr.json
    └── about/         # pages/about.vue
        ├── en.json
        ├── de.json
        └── fr.json
```

املأ الملف الجذري وملف صفحة:

```json
// locales/en.json
{ "nav": { "home": "Home", "about": "About" } }
```

```json
// locales/pages/index/en.json
{ "welcome": "Welcome, {name}!", "items": "no items | one item | {count} items" }
```

ترى الصفحة المفاتيح الجذرية ومفاتيحها الخاصة؛ ويتغلب ملفها الخاص عند التعارض. تتبع أسماء المجلدات اسم المسار (`pages/articles/[id].vue` يصبح `locales/pages/articles-id/`). يغطي [ملفات الترجمة](/ar/guide/translations) التخطيط والقيم الاحتياطية والتحميل.

## استخدام `$t` في صفحة {#use-$t-on-a-page}

```vue
<!-- pages/index.vue -->
<script setup lang="ts">
const { t, tc, getLocale } = useI18n()

const title = t('nav.home') // 'Home'
</script>

<template>
  <h1>{{ $t('welcome', { name: 'Ada' }) }}</h1>
  <!-- Welcome, Ada! -->
  <p>{{ $tc('items', 3) }}</p>
  <!-- 3 items -->
  <p>{{ getLocale() }}</p>
  <!-- en -->
</template>
```

- في القوالب تتوفر كل دالة مساعدة مع `$` (`$t` و`$tc` و`$localePath`، …).
- في `<script setup>`، تُرجع `useI18n()` الدوال المساعدة نفسها، مع `$` وبدونها (`t` و`$t` دالة واحدة). وتُستورد تلقائيًا.
- تُملأ العناصر النائبة `{name}` من كائن المعاملات. تُفصل صيغ الجمع بالرمز `|`؛ ويختار العدد الصيغة (0، 1، ثم الأخيرة لكل ما هو أكبر).

كل الدوال المساعدة مُدرجة في [الدوال](/ar/api/methods).

## الربط بين الصفحات وتبديل اللغة {#link-between-pages-and-switch-locale}

```vue
<!-- components/AppHeader.vue -->
<template>
  <nav>
    <i18n-link :to="{ name: 'index' }">{{ $t('nav.home') }}</i18n-link>
    <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
    <i18n-switcher />
  </nav>
</template>
```

- [`<i18n-link>`](/ar/components/i18n-link) هو `NuxtLink` يشير إلى الصفحة في اللغة الحالية: في `/de` يذهب رابط about إلى `/de/about`.
- [`<i18n-switcher>`](/ar/components/i18n-switcher) قائمة منسدلة باللغات المفعّلة؛ ويُبقي الزائر في الصفحة نفسها.
- لأزرارك الخاصة استدعِ `$switchLocale('de')`، التي تنتقل إلى الصفحة الحالية بالألمانية وتتذكر الاختيار. ولـ `NuxtLink` عادي، استخدم `$localePath({ name: 'about' })` أو `$switchLocalePath('de')`.

## التحقق {#check-it}

شغّل `nuxt dev` وافتح:

| عنوان URL | يعرض |
| --- | --- |
| `/` | الصفحة الرئيسية بالإنجليزية (أو إعادة توجيه إلى `/de` عندما يفضّل متصفحك الألمانية) |
| `/de` | الصفحة الرئيسية بالألمانية |
| `/de/about` | صفحة about بالألمانية |
| `/en/about` | 404: اللغة الافتراضية بلا بادئة في `prefix_except_default` |

تُطبَّق التعديلات على ملفات JSON في الصفحة المفتوحة دون إعادة تحميل.
