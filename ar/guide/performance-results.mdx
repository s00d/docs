### الوصف {#description}

يقارن بين **Nuxt العادي** و**i18n-micro** و**`@nuxtjs/i18n`** باستخدام ملف تعريف قاموس مشترك واحد عبر `untestutils/perf`.

التركيز: زمن البناء، وذروة RSS، و**الشيفرة مقابل الترجمات (الأصول) مقابل الإجمالي** القابلة للنشر، والحمل (Artillery).

### ملاحظات المنهجية {#methodology-notes}

- المقاييس هي **متوسطات 3 تشغيلات متتالية لكل تجهيزة** (غير متداخلة).
- **الناتج**: ملف Nitro node-server `.output/server/index.mjs` بعد `nuxi build` إجباري؛ و`nuxt-i18n-micro` هو **dist الوحدة المبنية** (وليس بديل jiti الخاص بـ `dev:prepare`). راجع [منهجية القياس](https://s00d.github.io/nuxt-i18n-micro/contributing/performance-methodology).
- **الترجمات** = `bundle.asset` (ملفات JSON للغات، و`chunks/raw/`، وأجزاء اللغات المطابقة عبر `isTranslationFile`).
- **الشيفرة** تستثني خرائط المصدر (`*.map`): إذ تربط التجهيزات الوحدةَ من المستودع، فيكتب Nitro خرائط كاملة لها ولا يكتب أيًّا منها لاعتماديات npm.
- يخدم **plain-nuxt** حجم العناصر الطرفية نفسه كملفات JSON ثابتة — وهو ثقيل في الإدخال/الإخراج تحت الحمل، وليس "عبئًا إضافيًا لـ i18n".
- ملف تعريف الحمل `--load full`: إحماء 6s@6 + رئيسي 60s@60 بلا حد أقصى (تاريخي).
- فترات التهدئة `--cool fast` (راجع وثيقة المنهجية).
- كل عملية بناء من عمليات `runs` **إجبارية** (دون تصفير زمن البناء بسبب ذاكرة مؤقتة دافئة).
- **معدل الأخطاء** في Artillery في الجداول هو أخطاء حالة HTTP من مقاييس الحمل. وترسم المخططات أيضًا `vusers.failed` (مهلات العميل عند التشبع)؛ وقد تكون مرتفعة بينما يبقى معدل أخطاء HTTP عند 0%.

## ملاحظات {#notes}

- ملف تعريف مشترك: 4 لغات × صفحتان × ~16.8k عنصر طرفي في الفهرس.
- الحمل: Artillery برمجيًا فقط — إحماء **6s@6** + رئيسي **60s@60**، مستخدمون افتراضيون بلا حد أقصى (منهجية YAML تاريخية). المسارات من ملف تعريف وقت التشغيل — راجع `scripts/src/perf/load.ts`.
- فترات التهدئة: 2s بعد البناء، و3s بين التشغيلات، و5s بين التجهيزات. تُفرض عمليات البناء في كل تشغيل كي لا تتأثر المتوسطات بإصابات الذاكرة المؤقتة.
- إعادة التشغيل يوميًا: `pnpm test:performance` (`--load short --cool fast`).
- إعادة توليد هذه الصفحة: `pnpm -C scripts cli performance --load full --only all --runs 3`.
- الخيارات: `--locales N --keys K --only all|micro|i18n|plain --runs N --skip-load --cool fast|strict`.
