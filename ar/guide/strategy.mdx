يحدد الخيار `strategy` ما إذا كانت اللغة تظهر في عنوان URL ولأي لغات. اختره مرة واحدة قبل نشر عناوين URL: فتغييره لاحقًا يغيّر كل رابط. ثم تولّد الوحدة المسارات المترجمة وقت البناء، وتقرؤها `$localePath` و`<i18n-link>` ومبدّل اللغات.

## الاستراتيجيات الأربع {#the-four-strategies}

![صفحة /about باللغة en (الافتراضية) وde في ظل كل استراتيجية؛ وعناوين URL نفسها مدرجة في النص أدناه](/images/diagrams/strategies.svg)

**النوع** `Strategies` · **الافتراضي** `'prefix_except_default'`

استراتيجية توجيه عناوين URL لبادئات اللغات.

- `'no_prefix'` — لا لغة في عنوان URL؛ تُخزَّن اللغة في ملف تعريف ارتباط.
- `'prefix_except_default'` — إضافة بادئة لجميع اللغات ما عدا الافتراضية.
- `'prefix'` — إضافة بادئة دائمًا، بما في ذلك اللغة الافتراضية.
- `'prefix_and_default'` — مثل `prefix`، لكن يمكن الوصول إلى اللغة الافتراضية أيضًا دون بادئة.

عناوين URL لصفحة `about` مع `defaultLocale: 'en'` واللغتين `en` و`de`:

| الاستراتيجية | الإنجليزية | الألمانية | غير مُقدَّم |
| --- | --- | --- | --- |
| `prefix_except_default` (الافتراضية) | `/about` | `/de/about` | `/en` و`/en/about` يعيدان 404 |
| `prefix` | `/en/about` | `/de/about` | `/about` يعيد التوجيه إلى عنوان URL ذي بادئة |
| `prefix_and_default` | `/about` و`/en/about` | `/de/about` | — |
| `no_prefix` | `/about` | `/about` | اللغة ليست في عنوان URL |

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix',
  },
})
```

تُثبَّت الاستراتيجية وقت البناء: ويُتجاهل أي تجاوز لها وقت التشغيل مع تحذير ([تجاوزات وقت التشغيل](/ar/guide/runtime-overrides)).

## أيها تختار {#which-one-to-choose}

- **`prefix_except_default`**: لمعظم المواقع. تستمر عناوين URL الحالية دون بادئة في العمل للغة الافتراضية.
- **`prefix`**: جميع اللغات متساوية؛ يقود `/` دائمًا إلى صفحة رئيسية ذات بادئة.
- **`prefix_and_default`**: تحتاج إلى أن تعمل `/en/...` وعناوين URL دون بادئة معًا، على سبيل المثال أثناء الانتقال من إحداهما إلى الأخرى. لا يُعاد توجيه عناوين URL دون بادئة أبدًا.
- **`no_prefix`**: للتطبيقات التي تقع خلف تسجيل الدخول، أو لعنوان URL واحد لكل صفحة لجميع اللغات. تأتي اللغة من ملف تعريف ارتباط أو من `?locale=`. ترى محركات البحث لغة واحدة لكل عنوان URL، لذا لا تُصدر بدائل `hreflang`.

تُشرح كيفية اختيار اللغة لعنوان URL، ومتى يُعاد توجيه الزائر، في [اكتشاف اللغة](/ar/guide/locale-detection).

## المسارات المُولَّدة {#generated-routes}

وقت البناء، تحصل كل صفحة على سجلات المسارات التي تحتاجها استراتيجيتها. يحمل كل سجل `meta.i18n = { name, locales }`: الصفحة التي يعرضها واللغات التي يخدمها. تُجاب الروابط وتبديلات اللغة وإعادات التوجيه جميعها من هذه السجلات، لذا فإن أي عنوان URL تقدّمه الوحدة يكون دائمًا عنوانًا يخدمه الموجّه.

تتشارك اللغات التي تشترك في مسار الصفحة سجلًا واحدًا، `/:locale(de|fr)/about`. وتحصل اللغة ذات المسار الخاص على سجل خاص بها، باسم `localized-<page>-<locale>`:

```ts
// nuxt.config.ts: German has its own path for the about page
i18n: {
  globalLocaleRoutes: { about: { de: '/ueber-uns' } },
}
// prefix_except_default, locales en (default), de, fr:
// about                 /about
// localized-about       /:locale(fr)/about
// localized-about-de    /:locale(de)/ueber-uns
```

تُشرح المسارات المخصصة وقوائم اللغات لكل صفحة واستثناء صفحة من الترجمة في [المسارات المترجمة](/ar/guide/custom-locale-routes) و[إعدادات الصفحة](/ar/guide/per-component-translations). البادئة `localized-` هي [`localizedRouteNamePrefix`](/ar/api/module-options#localizedroutenameprefix).

<Warning>

**أسماء المسارات مُولَّدة** — لا تكتب أسماء `localized-…` بشكل ثابت في `router.push({ name })`. مرّر اسم الصفحة نفسها إلى `$localeRoute` أو `<i18n-link>`؛ فهما يختاران السجل الصحيح.

</Warning>

## الربط بصفحة في لغة معينة {#linking-to-a-page-in-a-locale}

```vue
<script setup lang="ts">
const { localePath, localeRoute, switchLocalePath } = useI18n()

localePath({ name: 'about' }) // '/de/ueber-uns' while the page is German
localePath({ name: 'about' }, 'en') // '/about'
localePath('/about', 'de') // '/de/ueber-uns': a path is read as the page it shows
localeRoute({ name: 'products-id', params: { id: '42' } }, 'de') // resolved route: name, params, fullPath
switchLocalePath('fr') // the current page in French
</script>

<template>
  <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
  <NuxtLink :to="$switchLocalePath('de')">Deutsch</NuxtLink>
</template>
```

- تعمل المسارات المسمّاة والمسارات النصية كلاهما. يُطابَق المسار النصي مع المسارات المُولَّدة، لذا يُقبل شكله في أي لغة.
- اللغة التي لا تخدم الصفحة (راجع `locales` في [إعدادات الصفحة](/ar/guide/per-component-translations)) تربط بالصفحة الرئيسية لتلك اللغة بدلًا من صفحة غير موجودة.
- تمر المعاملات الخاصة بكل لغة (معرّف نصي مترجم) عبر `$setI18nRouteParams`، راجع [المسارات المترجمة](/ar/guide/custom-locale-routes).

التواقيع موجودة في [الدوال](/ar/api/methods).

## تفاصيل `no_prefix` {#no_prefix-details}

- القيمة الافتراضية لـ [`localeCookie`](/ar/api/module-options#localecookie) هي `'user-locale'` في ظل `no_prefix`، لذا يبقى الاختيار بعد إعادة التحميل.
- يحمّل `$switchLocale('de')` القاموس الألماني ويستبدل إدخال السجل الحالي؛ ولا يتغير عنوان URL.
- تظل المسارات المخصصة لكل لغة تعمل: مع `globalLocaleRoutes: { about: { de: '/ueber-uns' } }` يحصل القراء الألمان على `/ueber-uns`. يُعرض هذا العنوان دائمًا بالألمانية بغض النظر عن تفضيل الزائر، والصفحة المقصورة على بعض اللغات تُعرض بإحداها. والمسار الذي تتشاركه عدة لغات (`en` و`de` كلتاهما على `/page/:id`) يُعرض باللغة المفضلة إذا كانت إحداها. ويبقى التفضيل نفسه قائمًا: تعود الصفحة التالية إليه.
- يعيد [`noPrefixRedirect: true`](/ar/api/module-options#noprefixredirect) توجيه المسار الأصلي لصفحة لها مسار مخصص في اللغة الافتراضية: إلى المسار المخصص للغة الزائر، وإلا فإلى مسار اللغة الافتراضية (`/about` → `/about-us` عندما يكون لـ `en` المسار `/about-us`، و→ `/ueber-uns` مع ملف تعريف الارتباط `de`). اللغة التي ليس لها مسار مخصص خاص بها تبقى على المسار الأصلي وتُعرض هناك. لا يُعاد توجيه الصفحات ذات المعاملات.

## التطبيقات دون `pages/` {#apps-without-pages/}

مع `pages: false` لا توجد مسارات صفحات لترجمتها. استخدم ملفات الترجمة الجذرية فقط (`disablePageLocales: true`)؛ ويظل الاكتشاف وملف تعريف الارتباط و`$switchLocale` تعمل. يُعد المتغير `pages-false` من `test/fixtures/basic` في المستودع إعدادًا عاملًا.
