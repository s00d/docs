مع `meta: true` (القيمة الافتراضية) تحصل كل صفحة مترجمة على `<html lang dir>`، ورابط canonical، وبدائل `hreflang`، و`x-default`، ووسوم لغة Open Graph. تحتاج إلى هذه الصفحة عندما تريد ضبط الأصل (origin) العام، أو التحكم في اللغات التي تظهر في الوسوم، أو تجاوزها لصفحة واحدة. معظم المواقع لا تحتاج إلا إلى `site.url` أو `metaBaseUrl` ورموز `iso` صحيحة.

## الإعداد الأدنى {#minimal-setup}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'de', iso: 'de-DE', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    metaBaseUrl: 'https://example.com',
  },
})
```

عندها تُصيِّر `/de/about`:

```html
<html lang="de-DE" dir="ltr">
<link rel="canonical" href="https://example.com/de/about">
<link rel="alternate" hreflang="en-US" href="https://example.com/about">
<link rel="alternate" hreflang="de-DE" href="https://example.com/de/about">
<link rel="alternate" hreflang="ar-SA" href="https://example.com/ar/about">
<link rel="alternate" hreflang="x-default" href="https://example.com/about">
<meta property="og:locale" content="de_DE">
<meta property="og:url" content="https://example.com/de/about">
<meta property="og:locale:alternate" content="en_US">
<meta property="og:locale:alternate" content="ar_SA">
```

## اتجاه النص {#text-direction}

يأتي `<html dir>` من `dir` الخاص باللغة. وبدونه، تحصل اللغة المكتوبة من اليمين إلى اليسار على `rtl`، اعتمادًا على `iso` (أو `code`): العربية، والعبرية، والفارسية، والأردية وبعض اللغات الأخرى، وأي وسم بخط من اليمين إلى اليسار مثل `az-Arab`. أما بقية اللغات فلا تحصل على سمة `dir`، وتقرؤها المتصفحات على أنها `ltr`.

<Warning>

**`dir: 'auto'` يكلّف وقتًا في التحليل على الصفحات الكبيرة** — القيمة `auto` على `<html>` تجعل المتصفح يستنتج الاتجاه من المحتوى أثناء التحليل. في Chromium تنمو هذه الكلفة أسرع من حجم الصفحة: نحو 100 ms عند 5,000 عنصر و1 s عند 20,000. استخدمها فقط لصفحة صغيرة لا يمكنك معرفة لغتها.

</Warning>

## الوسوم التي تحصل عليها {#which-tags-you-get}

- **hreflang**: وسم واحد لكل لغة تقدّم الصفحة، قيمته `iso` (أو `code` عند غياب `iso`)، وعنوان URL الخاص به بمعاملات الاستعلام نفسها الموجودة في canonical. الصفحة المقيّدة عبر [إعداد الصفحة](/ar/guide/per-component-translations) أو `routeLocales` لا تسرد إلا لغاتها. يضيف [`hreflangBaseLanguage: true`](/ar/api/module-options#hreflangbaselanguage) أيضًا اللغة المجرّدة (`es-ES` → `es`) لأول لغة إقليمية.
- **x-default**: عنوان URL للغة الافتراضية، فقط عندما تقدّم اللغة الافتراضية الصفحة.
- **og:locale**: مشتق من `iso` (`en-US` → `en_US`). اضبط `og` على اللغة عندما لا يكون التحويل مباشرًا، مثل `{ code: 'zh', iso: 'zh-Hans', og: 'zh_CN' }`؛ وبدون أيٍّ منهما لا يُكتب `og:locale` ويُحذّر وضع التطوير.
- **canonical / og:url**: عنوان URL الحالي دون معاملات الاستعلام، باستثناء تلك الموجودة في [`canonicalQueryWhitelist`](/ar/api/module-options#canonicalquerywhitelist) (افتراضيًا `page`، `sort`، `filter`، `search`، `q`، `query`، `tag`).

حسب الاستراتيجية:

| الاستراتيجية | hreflang وx-default | canonical وog:url وog:locale وسمات html |
| --- | --- | --- |
| `prefix`، `prefix_except_default`، `prefix_and_default` | نعم | نعم |
| `no_prefix` | لا (عنوان URL واحد يقدّم كل اللغات) | نعم |

## ضبط الأصل العام {#set-the-public-origin}

تستخدم عناوين URL المطلقة أول ما يتوفر من:

1. [`metaBaseUrl`](/ar/api/module-options#metabaseurl)؛
2. `site.url` من `nuxt-site-config` (يثبّته `@nuxtjs/seo`)؛
3. أصل الطلب، مع إلحاق `app.baseURL`.

ثبّت أحد الخيارين الأولين.

<Warning>

يقرأ الخيار الاحتياطي المعتمد على أصل الطلب `X-Forwarded-Host` و`X-Forwarded-Proto`، لأن [`metaTrustForwardedHost`](/ar/api/module-options#metatrustforwardedhost) و`metaTrustForwardedProto` مضبوطان افتراضيًا على `true`. وهذا آمن فقط خلف وكيل (proxy) يستبدل هذه الترويسات؛ وإلا فيمكن للعميل اختيار المضيف في روابط canonical الخاصة بك، ويمكن لذاكرة تخزين مؤقت أن تمرّر تلك الصفحة إلى غيره.

إذا كان التطبيق قابلًا للوصول مباشرة، فثبّت `metaBaseUrl`: فعلى عكس ضبط الخيارين على `false`، فإنه يتجاهل أيضًا ترويسة `Host` المزوّرة. راجع [خلف وكيل أو CDN](/ar/guide/deployment#behind-a-proxy-or-cdn).

</Warning>

يفيد الخيار الاحتياطي في نشر واحد يستجيب لعدة نطاقات: يحصل كلٌّ من `https://site-a.com/en/about` و`https://site-b.com/en/about` على أصله الخاص.

مع ضبط `baseUrl` على اللغات، يستخدم المضيف المعروف `baseUrl` الخاص به، مقدَّمًا على `metaBaseUrl` و`site.url`، فيبقى canonical و`og:url` على ذلك النطاق ويشير `hreflang` بكل لغة إلى نطاقها. أما أي مضيف آخر فيستخدم `metaBaseUrl`، وإلا `baseUrl` الخاص باللغة الافتراضية، وإلا `site.url`، لذا لا يمكن لـ `Host` مزوّر الوصول إلى وسومك. إذا لم يُضبط أيٌّ منها، يبقى الخيار الاحتياطي المعتمد على أصل الطلب، ويُحذّر البناء. راجع [الطبقات والنطاقات](/ar/guide/layers#multiple-domains).

## استبعاد لغات أو صفحات {#leave-locales-or-pages-out}

```ts
i18n: {
  locales: [
    { code: 'en', iso: 'en-US' },
    { code: 'ru', iso: 'ru-RU', seo: false }, // routable, but not in hreflang / og:locale:alternate
    { code: 'fr', iso: 'fr-FR', disabled: true }, // no routes, no switching, no tags
  ],
}
```

إذا كان للغة الافتراضية `seo: false`، فلا يُكتب `x-default`. لإيقاف الوسوم لصفحة واحدة، استخدم `disableMeta` في [إعداد الصفحة](/ar/guide/per-component-translations#turn-off-seo-tags)، أو [`routeDisableMeta`](/ar/api/module-options#routedisablemeta) في الإعدادات.

## تجاوز الوسوم في صفحة واحدة {#override-tags-on-one-page}

لمحتوى نظام إدارة المحتوى الذي لا توجد له إلا بعض الترجمات، أو عندما تأتي عناوين URL من واجهة برمجية، استبدل الوسوم المولّدة باستخدام [`useI18nHead`](/ar/composables/useI18nHead):

```vue
<script setup lang="ts">
const { data: article } = await useFetch('/api/articles/hello')
// article.value.urls = { en: 'https://example.com/blog/hello', de: 'https://example.com/de/artikel/hallo' }

useI18nHead(() => ({
  meta: [{ property: 'og:title', content: article.value?.title ?? '' }],
  replace: {
    hreflang: Object.entries(article.value?.urls ?? {}).map(([locale, href]) => ({ rel: 'alternate', hreflang: locale, href })),
    ogAlternates: Object.keys(article.value?.urls ?? {}),
  },
}))
</script>
```

يمكن لـ `replace` أيضًا ضبط `canonical` و`xDefault` و`ogLocale` و`ogUrl` أو إزالتها؛ ويحذف `disable` مجموعات كاملة (`'hreflang'`، `'x-default'`، `'canonical'`، `'og'`، `'og-alternates'`، `'html'`). مرّر دالة getter كي يُعاد حساب القيم بعد تبديل اللغة. للـ slugs الخاصة بكل لغة، اضبط `$setI18nRouteParams` أولًا ([المسارات المترجمة](/ar/guide/custom-locale-routes#per-locale-slugs)) وستستخدمها البدائل المولّدة تلقائيًا.

## الشرطة المائلة في النهاية {#trailing-slash}

تتبع `$localePath` و`$switchLocalePath` وكائن المسار الخاص بـ `$switchLocaleRoute` و`<i18n-link>` و`<i18n-switcher>` وعمليات إعادة التوجيه الخاصة باللغة وعناوين URL الخاصة بـ SEO قاعدة واحدة للشرطة المائلة: `experimental.defaults.nuxtLink.trailingSlash` افتراضيًا، أو [`trailingSlash`](/ar/api/module-options) في إعدادات i18n عندما يجب أن تختلف مسارات i18n.

## Nuxt SEO {#nuxt-seo}

تعمل [`@nuxtjs/seo`](https://nuxtseo.com/) (خريطة الموقع، وrobots، وschema.org) مع هذه الوحدة عبر `nuxt-site-config` 4+. اذكر `nuxt-i18n-micro` أولًا كي تتمكن إعدادات الموقع من قراءة اللغات، واضبط `site.url` مرة واحدة — فهو يغذّي أيضًا الوسوم المذكورة أعلاه.

```ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro', '@nuxtjs/seo'],
  site: { url: 'https://example.com', name: 'My Site' },
  i18n: {
    defaultLocale: 'en',
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
  },
})
```

يأتي اسم الموقع ووصفه المترجمان من المفتاحين `nuxtSiteConfig.name` / `nuxtSiteConfig.description` في ملفات اللغات لديك. الخطأ `Plugin nuxt-seo:defaults depends on nuxt-site-config:i18n but they are not registered` يعني أن `@nuxtjs/seo` أقدم من الإصدار 3؛ قم بترقيتها ([#133](https://github.com/s00d/nuxt-i18n-micro/issues/133)).
