في `nuxt dev` تضيف الوحدة أداتين للتصحيح: تبويب **i18n Micro** في Nuxt DevTools لتصفح ملفات الترجمة وتحريرها، ومُفتِّش في Vue DevTools للغة المحلية الحية والقواميس المحمّلة. كلاهما موجود في وضع التطوير فقط ولا يضيف شيئًا إلى عمليات البناء الإنتاجية. يحتاج تبويب Nuxt فقط إلى تفعيل Nuxt DevTools؛ أما مُفتِّش Vue فيحتاج أيضًا إلى إضافة Vue DevTools في المتصفح.

## تبويب Nuxt DevTools {#nuxt-devtools-tab}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  devtools: { enabled: true }, // the tab is registered only when DevTools are on
})
```

افتح Nuxt DevTools (`Shift + Alt + D`) واختر **i18n Micro**. يعرض التبويب:

- كل ملف JSON ضمن `locales/` (الجذر و`pages/`) في كل طبقة، بالإضافة إلى الملفات الجذرية من `additionalTranslationDirs`؛
- محررًا لكل ملف؛ يكتب **Save** الملف إلى القرص، ويعيد خادم التطوير تحميل الترجمات؛
- **Export** / **Import** لملف بصيغة JSON، و**Stats** مع أعداد المفاتيح ونسبة تغطية الترجمة؛
- عرضًا للإعدادات يُظهر خيارات الوحدة المُحلَّلة؛
- **Translate**، الذي يملأ المفاتيح الناقصة بمحرك ترجمة آلية تضبطه في إعدادات التبويب.

لا يكتب الحفظ إلا ملفات `.json` الموجودة داخل مجلدات الترجمة لديك. وعندما يوجد ملف في عدة طبقات، تُكتب نسخة المشروع.

## مُفتِّش Vue DevTools {#vue-devtools-inspector}

مع إضافة Vue DevTools في المتصفح، تسجّل الوحدة مُفتِّش i18n (اللغة المحلية الحالية، وجزء المسار، والمفاتيح المحمّلة) وخطًا زمنيًا يضم تبديلات اللغة وتحميلات الأجزاء والمفاتيح الناقصة.

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    debug: true, // also log every $t / $ts / $tc call on the timeline
    // vueDevtools: false, // turn the inspector off, keep the Nuxt tab
  },
})
```

القيمة الافتراضية لـ [`vueDevtools`](/ar/api/module-options) هي `true`. الخيار `debug: true` كثير التفاصيل؛ استخدمه لجلسات قصيرة.

## خارج Nuxt {#outside-nuxt}

تُنشر الواجهة نفسها باسم [`@i18n-micro/devtools-ui`](/ar/integrations/devtools-ui-package) لتطبيقات Vite المبنية على حزم أطر العمل؛ راجع تلك الصفحة لمعرفة الإعداد.
