تدير `@i18n-micro/cli` ملفات الـ locale لمشروع Nuxt. تقرأ `locales` و`defaultLocale` و`translationDir` وطبقاتك من `nuxt.config`، لذا لا تحتاج إلى أي إعداد خاص بها.

![طرفية تشغّل i18n-micro check، التي تسرد مفتاحًا مفقودًا ومفتاحًا غير معرَّف وأربعة مفاتيح غير مستخدمة وتفشل، ثم extract، التي تضيف المفتاح غير المعرَّف، ثم clean --dryRun، التي تسرد المفاتيح الأربعة التي ستزيلها](/images/cli/demo.gif)

| الأمر | استخدمه من أجل |
| --- | --- |
| `check` | إفشال البناء عند وجود أي خطأ في ملفات الـ locale |
| `translate` | ملء المفاتيح المفقودة عبر خدمة ترجمة |
| `clean` | إزالة المفاتيح التي لا يستخدمها شيء |
| `rename` | نقل مفتاح، أو نطاق أسماء كامل، في كل مكان دفعة واحدة |

```bash
npm install -D @i18n-micro/cli
npx i18n-micro --help
```

شغّلها من جذر التطبيق، أو أشر إليه باستخدام `--cwd`. كل علامة لكل أمر موجودة في [مرجع الأوامر](/ar/api/cli).

<Tip>

**هل تنتقل من nuxt-i18n-micro-cli؟** تحل `@i18n-micro/cli` محلها؛ ويبقى الأمران التنفيذيان `i18n-micro` و`i18n-micro-cli`. راجع [جدول الأوامر القديمة](#moving-from-nuxt-i18n-micro-cli).

</Tip>

## استخدمها في CI {#use-it-in-ci}

```bash
i18n-micro check
```

`check` هو البوابة. يبلّغ عن:

| الفحص | المعنى |
| --- | --- |
| `missing` | مفتاح من الـ locale الافتراضي غائب عن locale ما |
| `empty` | القيمة هي `''`. يعرض التطبيق فراغًا، لا القيمة الاحتياطية |
| `extra` | يملك locale مفتاحًا لا يملكه الـ locale الافتراضي |
| `placeholders` | فُقد `{name}` أو أُضيف، أو فقدت صيغة جمع صيغها |
| `undefined` | يستخدم الكود مفتاحًا لا يملكه الـ locale الافتراضي |
| `unused` | لا شيء في المشروع يستخدم المفتاح |
| `duplicates` | النص نفسه تحت مفاتيح مختلفة. معطَّل افتراضيًا: مرّر `--duplicates` |

- يشغّل `--only missing,placeholders` بعض الفحوص؛ ويفشل الفحص المذكور في `--only` إذا تعذّر تشغيله.
- يعطي `--json` تقريرًا للأدوات.
- يتخطى `--ignore` ملفات المصدر.
- ما دامت المفاتيح تُحسب وقت التشغيل، يُتخطى `unused` ويذكر التقرير السبب.

يخرج كل أمر بأحد ثلاثة رموز، حتى يتمكن خط الأنابيب من التمييز بين مشكلة في ترجماتك ومشكلة في الأداة:

| رمز الخروج | المعنى |
| --- | --- |
| `0` | لا شيء للإبلاغ عنه |
| `1` | نتائج |
| `2` | تعذّر تشغيل الأمر: خطأ استخدام، أو ملف معطوب، أو طلب فاشل |

أوامر أخرى تستحق خطوة في CI:

```bash
i18n-micro format --check      # fails if a file is not formatted
i18n-micro lint                # stray spaces, empty values, your own regex rules
i18n-micro stats --baseRef main
```

## أبقِ الـ locales متزامنة {#keep-locales-in-step}

| الأمر | ما يفعله |
| --- | --- |
| `extract` | يسرد المفاتيح التي يستخدمها الكود ولا نص لها بعد. النص الافتراضي، كما في `$t('key', {}, 'Welcome')`، يذهب إلى الـ locale الافتراضي. |
| `sync` | يزيل المفاتيح التي لا يملكها الـ locale الافتراضي. جرّب `--dryRun` أولًا. |
| `clean` | يزيل المفاتيح التي لا يستخدمها شيء. جرّب `--dryRun` أولًا. |
| `search` | يعثر على المفاتيح والقيم، ويعرض أين يُستخدم كل مفتاح. |
| `stats` | نسبة الاكتمال لكل locale؛ ويقارن `--baseRef main` مع مرجع git. |

يتوقف `sync` كما يتوقف `clean` عندما يكون على وشك إزالة مفتاح لا يستطيع إثبات أنه غير مستخدم، وأيضًا عندما لا يملك الـ locale الافتراضي شيئًا للمقارنة معه. وعندما لا يوجد ما يُزال لا يتوقف أبدًا، لذا فإن `$t(item.label)` وحدها ليست سببًا لاستخدام `--force`.

<Note>

لا يكتب `extract` و`sync` أبدًا `''` لمفتاح بلا ترجمة. يبقى المفتاح غائبًا، لذا يُطبَّق `fallbackLocale` وقت التشغيل ويبلّغ عنه `check`. السلسلة الفارغة ستكون قيمة معرَّفة وستعرض فراغًا.

</Note>

### ما تقرؤه الأوامر {#what-the-commands-read}

تقرأ `check` و`extract` و`sync` و`clean` و`search` و`rename` الشيفرة المصدرية عبر المشروع بأكمله، لا قائمة ثابتة من المجلدات:

- **المقروء:** القوالب والسكربتات عبر محلّل، و`.html` وPug كنص، وكل طبقة، والمجلدات خارج الجذر التي يشير إليها اسم بديل أو `components`.
- **المتخطى:** `node_modules`، ومخرجات البناء، وملفات الـ locale. أضف ما يخصك باستخدام `--ignore 'legacy/**,*.stories.ts'`.
- **شيفرة الاختبار** تُعدّ استخدامًا، لذا يحتفظ `clean` و`check --only unused` بالمفتاح الذي لا يقرؤه إلا اختبار. ولا تضيف مفتاحًا أبدًا: يتخطى `extract` هذه المفاتيح، ولا يبلّغ عنها `check` على أنها غير معرَّفة.

تعني شيفرة الاختبار مجلدات الجذر `tests` و`test` و`__tests__` و`e2e` و`cypress` و`playwright`، بالإضافة إلى ملفات JavaScript وTypeScript ذات `.spec` و`.test` (`.ts` و`.tsx` و`.mts` و`.js` و`.jsx` و`.mjs` وما شابه) في أي مكان. مجلدات الجذر فقط معفاة من الشكوك أدناه: `pages/tests/[id].vue` صفحة كأي صفحة أخرى، وكذلك `public/` والملفات المصغَّرة، التي ليست شيفرتها جزءًا من التطبيق.

تتعرف الأوامر على:

- `$t` و`$ts` و`$tc` و`$has` و`$_t(route)`؛
- `t()` من `useI18n()` و`useTranslationServerMiddleware()`؛
- `<i18n-t keypath>` في القوالب وJSX، و`<i18n-group prefix>`؛
- الأسماء البديلة مثل `const { t: tr } = useI18n()`.

### كيف يقرر `clean` {#how-clean-decides}

يفضّل `clean` ترك مفتاح ميت على إزالة مفتاح حي. يبقى المفتاح عندما يتحقق أي مما يلي:

- يستخدمه استدعاء، أو يستخدم مفتاحًا تحته أو فوقه؛
- تساويه سلسلة في الكود: `const key = 'menu.home'`، `<Item label="menu.home" />`؛
- يحتويه ملف JSON أو YAML أو Markdown في المشروع؛
- يملك مفتاح محسوب بداية ثابتة تغطيه: `` $t(`status.${state}`) `` يحتفظ بكل ما تحت `status.`؛
- تعرّفه طبقة.

يتوقف `clean` دون تغيير أي شيء عندما لا يستطيع المعرفة، ويسرد السبب:

- المفتاح محسوب بالكامل، كما في `$t(name)` أو `<i18n-t :keypath="name" />` أو `<i18n-t v-bind="props" />`؛
- تُمرَّر `$t` كقيمة، كما في `items.map($t)`؛
- دالة تسمى `t` تتلقى وسيطًا محسوبًا وتأتي من معامل أو استيراد أو استدعاء: قد تكون غلافًا حول الدالة الحقيقية. الدالة التي يعرّفها الملف نفسه لا تُحتسب، لأن الغلاف سيحتوي على استدعائه الخاص بداخله؛
- ملف مصدر لا يمكن تحليله؛
- لا يستخدم أي ملف أي مفتاح على الإطلاق، ما يعني عادةً أنه يبحث في المكان الخطأ؛
- ملف locale هو رابط رمزي إلى خارج المشروع، لذا قد يقرؤه تطبيق آخر.

<Steps>

<Step title="المعاينة">

شغّل `i18n-micro clean --dryRun` وراجع ما يسرده.

</Step>

<Step title="حماية المفاتيح">

احتفظ بالمفاتيح التي تبدو غير مستخدمة فقط باستخدام `--exclude '^errors\.'`.

</Step>

<Step title="الإزالة">

شغّله مرة أخرى مع `--force`.

</Step>

</Steps>

## ترجم المفاتيح المفقودة {#translate-missing-keys}

```bash
i18n-micro translate --dryRun                     # keys and characters per locale, nothing sent
export I18N_TRANSLATE_TOKEN=...                   # or put it in .env
i18n-micro translate --service deepl --locale de,fr
```

- يملأ `translate` المفاتيح المفقودة أو الفارغة؛ ويعيد `--replace` ترجمة كل شيء.
- العناصر النائبة وصيغ الجمع محمية. لا تُكتب الترجمة التي فقدت عنصرًا نائبًا: يُدرج المفتاح ويخرج الأمر بالرمز `1`.
- تُحفظ كل دفعة قبل إرسال الطلب التالي، لذا لا يكلّف الفشل إلا الطلب الذي فشل.

| `--service` | الخدمة | `--token` | `--options` مفيدة |
| --- | --- | --- | --- |
| `ai` | Vercel AI Gateway أو OpenAI أو Anthropic أو أي خادم متوافق مع OpenAI | مفتاح API، أو `AI_GATEWAY_API_KEY`، `OPENAI_API_KEY`، `ANTHROPIC_API_KEY` | `provider`, `model`, `baseUrl`, `maxTokens` |
| `azure` | Azure Translator | مفتاح الاشتراك | `region` |
| `deepl` | DeepL، بما في ذلك المفاتيح المجانية | مفتاح المصادقة | `formality`, `glossaryId`, `context` |
| `google` | Google Cloud Translation v2 | مفتاح API | `model` |
| `libretranslate` | LibreTranslate | اختياري | `baseUrl` |
| `yandexcloud` | Yandex Cloud Translate | مفتاح API، أو رمز IAM مع `authScheme:Bearer` | `folderId`, `model` |

الخيارات أزواج `key:value`: `--options provider:openai,model:gpt-4o-mini`. تأخذ جميع الخدمات أيضًا `baseUrl` و`retries` و`retryDelayMs` و`timeoutMs`. قد يكون طلب الترجمة قد احتُسب ماليًا بالفعل، لذا لا يُكرَّر إلا بعد `429` أو `503`، ولا يُكرَّر عندما تطلب الخدمة الانتظار أكثر من دقيقة.

<Warning>

العلامات مرئية في سجل الصدفة وقوائم العمليات، لذا مرّر الرمز عبر متغير البيئة. تُخفي CLI ما تعرف أنه سري أينما طبعته، بما في ذلك `--debug`: الرموز، ومفاتيح المزوِّدين، وبيانات اعتماد Basic، والاستعلام وبيانات الاعتماد في عنوان URL الذي ضبطته. الخادم الذي يعيد تنسيق المفتاح قبل إعادته خارج نطاق سيطرتها، لذا تعامل مع سجلات التشغيل الفاشل بحذر.

</Warning>

تتبع خدمة `ai` مسردًا. عند وجود `.i18n-glossary.json` يُستخدم دون علامة؛ ويختار `--glossaryFile` ملفًا آخر.

```json .i18n-glossary.json
{ "entries": [{ "source": "Cart", "target": "Warenkorb", "to": "de" }] }
```

## حوّل النص المكتوب مباشرة إلى مفاتيح {#turn-hardcoded-text-into-keys}

```bash
i18n-micro text-to-i18n --dryRun   # list what would change
i18n-micro text-to-i18n            # rewrite the templates
```

```vue
<!-- before -->
<h1>Welcome to our site</h1>
<!-- after -->
<h1>{{ $t('pages.index.welcome-to-our') }}</h1>
```

لا تُعاد كتابة إلا قوالب `.vue` الخاصة بالمشروع نفسه، لا قوالب الطبقات أو أهداف الأسماء البديلة. يُحلَّل كل ملف أُعيدت كتابته مرة أخرى قبل كتابته. الحالات التالية تُدرج وتحتفظ بنصها:

- النص في ملفات `.ts` والسكربتات، لأن `$t` ليست متاحة في كل مكان؛
- النص المجاور لترميز أو إقحام، مثل `<p>Hello <b>world</b> today</p>`: لا يمكن ترجمة نصف جملة بمفرده؛
- المفتاح المولَّد الذي سيتصادم مع آخر، كما قد يحدث بين صفحة أب وابنها؛
- المفتاح المعروف الذي لا يمكن وضعه بين علامتي اقتباس.

<Warning>

نفّذ commit أولًا، وراجع الفروق.

</Warning>

## أعد تسمية مفتاح {#rename-a-key}

```bash
i18n-micro rename --from common.save --to actions.save
i18n-micro rename --from settings --to account.settings   # a whole namespace
```

يحرّر `rename` شجرة الصياغة، لذا تبقى التعليقات والسلاسل غير ذات الصلة كما هي، وتُتتبَّع الأسماء البديلة و`:keypath`. لا يُغيَّر ملف الطبقة الخاص بها أبدًا. ينبّه إلى ما لا يستطيع إعادة كتابته، ويتركه كما هو:

- مفتاح محسوب تحت الاسم القديم؛
- كل سلسلة عادية تساويه؛
- قالب Pug؛
- مصدر في طبقة أو في مجلد خارج المشروع.

يجب أن يكون `--to` مفتاحًا يمكن كتابته في الكود: بلا علامات اقتباس، ولا شرطة مائلة عكسية، ولا مقطع فارغ، ولا `__proto__`.

## تبادل الملفات مع المترجمين {#exchange-files-with-translators}

```bash
i18n-micro export --format csv
i18n-micro import --format csv --dryRun
```

**`export`** يكتب كل مفتاح لكل locale، بما في ذلك غير المترجمة، مع نص الـ locale الافتراضي كمصدر: عمود `Source` في CSV، وتعليق `#.` في PO.

- بدون `--dir`، يذهب PO إلى `pots` وCSV إلى `csv_exports`.
- يسجّل ما كتبه في `.i18n-export.json`، في مجلد المخرجات. ويتوقف عندما يتغير ملف منذ ذلك الحين ويحتوي على ترجمات لا تملكها ملفات الـ locale، بما في ذلك إدخالات PO الضبابية؛ ويستبدلها `--force`. التعديلات العادية على ملفات الـ locale لا توقفه.

**`import`** يدمج، ويتخطى الخلايا الفارغة، ويتخطى إدخالات PO الموسومة بـ `fuzzy`.

- المفتاح الذي سيستبدل قيمة، أو القيمة فوق مجموعة كاملة من المفاتيح، يُدرج ويُستبعد، ويخرج الأمر بالرمز `1`.
- يتوقف بالرمز `2` عند وجود كتالوج في موقع غير متوقع، أو كتالوج صفحة لم يكتبه آخر تصدير، أو علامة اقتباس في غير موضعها في CSV، أو إدخال صفحة مع `disablePageLocales`.

لمنصة ترجمة، استخدم CLI الخاصة بها: يزامن إعداد [Crowdin](/ar/guide/crowdin) ملفات JSON، بما في ذلك ملفات الصفحات.

## زامن مع نقطة النهاية الخاصة بك {#sync-with-your-own-endpoint}

يتبادل `sync-remote` ملفات الـ locale العامة مع نقطة نهاية HTTP تشغّلها. تبقى ملفات الصفحات محلية، ويذكر الأمر ذلك. صِف نقطة النهاية في `.i18n-remote.json`:

```json .i18n-remote.json
{ "url": "https://translations.example.com", "path": "translations" }
```

تجيب نقطة النهاية على `GET` و`PUT` بكائن `{ locale: messages }`. صادِق باستخدام `auth: { username, password }`، أو ضع رمز bearer في `I18N_REMOTE_TOKEN`.

| | السحب | الدفع |
| --- | --- | --- |
| ما الذي ينتقل | يملأ ما لا تملكه ويحتفظ بالمفاتيح التي تملكها أنت فقط | يرسل مفاتيح المشروع الخاصة، لا مفاتيح الطبقات، ويستبعد القيم الفارغة لديك |
| التعارضات | مفتاح يختلف في الجانبين: لا يُكتب شيء، والخروج `1`؛ ويأخذ `--force` القيمة البعيدة | يستبدل PUT المستند، لذا يقرأ الدفع نقطة النهاية أولًا ويتوقف بالخروج `1` عندما تحتوي على نص لا تملكه؛ ويستبدله `--force`. نقطة النهاية التي تجيب بـ `404` لا تملك ما تخسره |
| `--dryRun` | يقرأ من نقطة النهاية، ويسرد التغييرات، ولا يكتب شيئًا | يذكر ما سيُرسل، دون الاتصال بنقطة النهاية |

يُتخطى الـ locale الذي لم تضبطه، ولا تمسح القيمة البعيدة الفارغة أي شيء.

## الانتقال من nuxt-i18n-micro-cli {#moving-from-nuxt-i18n-micro-cli}

| الأمر القديم | الآن |
| --- | --- |
| `validate` | `check` |
| `diff` | `check --only missing` |
| `check-duplicates` | `check --only duplicates` |
| `export-csv`, `import-csv` | `export --format csv`, `import --format csv` |
| `--potsDir`, `--csvDir` | `--dir` |
| `estimate` | `translate --dryRun` |
| `glossary` | حرّر `.i18n-glossary.json`؛ يقرؤه `translate` تلقائيًا |
| `backup`, `restore` | Git، الذي يحتفظ بالفعل بملفات الـ locale لديك |
| `init` | `nuxi init`، ثم أضف `nuxt-i18n-micro` إلى `modules` |
| `split` | أُزيل: لا تقرأ الوحدة الملفات المقسَّمة |
| `optimize` | `check --only duplicates` |
| `replace-values` | محررك أو `sed` |
| `stats --full` | `stats`؛ وتحتوي [DevTools](/ar/guide/devtools) على التفاصيل |
| `search --hardcodedOnly` | `text-to-i18n --dryRun` |
| `search --preferUnused`, `--onlyVue` | أُزيلت |
| قواعد `lint` `no-html-tags`, `no-special-chars`, `no-mixed-case`, `no-missing-punctuation`, `no-inconsistent-pluralization` | أُزيلت: كانت تُعلِّم نصًا عاديًا. اكتب إدخال `customRegexRules` إن احتجت إلى واحدة |
| `text-to-i18n --extractOnlyDirs`, `--extractOnlyPatterns`, `--verbose` | أُزيلت: لا تُعاد كتابة الكود أبدًا |
| `--logLevel verbose` | أُزيل: لم يكن يفعل شيئًا |

**الخدمات المُزالة:** `googlefree`، `yandex` (استخدم `yandexcloud`)، `ibm`، `lingvatranslate`، `modernmt`، `lilt`، `unbabel`، `reverso`، `baidu`، `papago`، `tencent`، `systran`، `mymemory`.

**أنواع `sync-remote` المُزالة:** `github`، `gitlab`، `crowdin`، `lokalise`، `tolgee`، `weblate`. استخدم CLI الخاصة بالمنصة، أو `custom`، الذي لم يعد يحتاج إلى `type`.

### السلوك المتغيِّر {#changed-behaviour}

- لم يعد `extract` و`sync` يكتبان `''`. تبقى المفاتيح غائبة، ويبلّغ عنها `check`. لا يكتب `extract` مفتاحًا إلا عندما يعطي الكود نصه.
- يكتب `extract` مفاتيح الصفحات إلى `locales/pages/<route name>/`، حيث تقرؤها الوحدة، ويفحص `app/` في Nuxt 4. انقل أي شيء من مجلدات مثل `pages/_about` و`pages/blog_`، واحذف أي `locales/pages/<locale>.json` شارد.
- يُحترم `translationDir` من `nuxt.config`؛ في السابق، كانت كل الأوامر تستخدم `locales` بصمت.
- بدون `defaultLocale`، يكون الافتراضي `en`، كما في الوحدة، ويُحترم `DEFAULT_LOCALE`. كان الافتراضي سابقًا أول locale.
- يستخدم `check` و`sync` الـ locale الافتراضي كمرجع ويفحصان ملفات الصفحات. يُعدّ `"a.b"` و`a: { b }` مفتاحًا واحدًا.
- يحتفظ `clean` بالمفتاح المستخدم في أي مكان، في أي نطاق، ويتوقف عندما لا يمكن إثبات الاستخدام. يختار `--include` و`--exclude` ما يمكن إزالته.
- يتوقف `sync` بالطريقة نفسها، وعندما لا يملك الـ locale الافتراضي مفاتيح للمقارنة. ويتجاوز `--force` ذلك. ويتوقف أيضًا عندما يختار `DEFAULT_LOCALE` مرجعًا غير الموجود في `nuxt.config`.
- العلامات الطويلة بشرطة واحدة والوسائط الشاردة أخطاء: لم يعد `clean -dryRun` يشغّل `clean`.
- لا يمكن حفظ ملف للقراءة فقط، أو ملف ليس بترميز UTF-8: يتوقف الأمر قبل أن يغيّر أي شيء. قراءة ملف كهذا لا بأس بها. المفتاح المكرر، والمفتاح المسمى `__proto__`، والعدد الصحيح الأكبر من 2^53 توقف الأمر، لأن الحفظ سيفقدها.
- العلامة التي تحتاج إلى قيمة ويليها علامة أخرى خطأ؛ اكتب `--flag=--value` لقيمة تبدأ بشرطة. لا تأخذ العلامة المنطقية إلا `true` أو `false`.
- يتوقف `export` بدلًا من استبدال ترجمات لم تُستورد قط.
- رموز الخروج هي `0` و`1` و`2`؛ كانت حالات الفشل سابقًا `1`، و`diff` و`check-duplicates` دائمًا `0`.
- لم يعد `lint --fix` يترك ملفات `.bak`.
- يحتفظ الحفظ بالمسافة البادئة للملف، ونهايات الأسطر، والسطر الجديد الأخير، والرابط الرمزي والرابط الصلب، ويترك الملفات التي لم يغيرها كما هي.
- العلامة المكتوبة خطأً أو المُزالة أصبحت خطأً الآن، ولا تُتجاهل بصمت.
- المسارات مثل `--dir` نسبية إلى المشروع، لا إلى الصدفة.
- لم تعد `ai` تحمّل حزم `@ai-sdk/*`: استخدم `provider` بقيمة `gateway` أو `openai` أو `anthropic`، أو `baseUrl` لخادم متوافق مع OpenAI.
