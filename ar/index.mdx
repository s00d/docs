description: "i18n صغيرة وسريعة لـ Nuxt: ترجمات JSON لكل صفحة، ومسارات موطَّنة وقت البناء، ووسوم SEO جاهزة."
---

Nuxt I18n Micro وحدة i18n خفيفة وعالية الأداء لـ Nuxt 3 و4، مصممة للمشاريع الكبيرة. تُبقي أوقات البناء واستهلاك الذاكرة وحجم الحزمة منخفضة مقارنةً بحلول i18n التقليدية مثل `@nuxtjs/i18n`.

تُولَّد المسارات الموطَّنة وقت البناء بواسطة `@i18n-micro/route-strategy` وتُحَل وقت التشغيل بواسطة `@i18n-micro/path-strategy`، لذا تتوافق الروابط ومبدِّل اللغة و`hreflang` وإعادة التوجيه جميعها مع الموجِّه. الترجمات بصيغة JSON فقط، مقسَّمة بين ملفات جذر مشتركة وملفات لكل صفحة ينشئها خادم التطوير لك، مع HMR مدمج.

<CodeGroup>

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>
