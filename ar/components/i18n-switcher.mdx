يعرض `<i18n-switcher>` زرًا يحمل اللغة المحلية النشطة وقائمة منسدلة بجميع اللغات المحلية المفعّلة، بما فيها اللغة النشطة. استخدمه للحصول على قائمة لغات جاهزة؛ وابنِ قائمتك الخاصة باستخدام [`$getLocales`](/ar/api/methods#$getlocales) و[`$switchLocalePath`](/ar/api/methods#$switchlocalepath) عندما تحتاج إلى ترميز مختلف. يرتبط كل عنصر بالصفحة الحالية بتلك اللغة.

## الخصائص والـ slots {#props-and-slots}

| الخاصية | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `customLabels` | `Record<string, string>` | `() => ({})` | اسم العرض لكل رمز لغة، ويتجاوز `displayName` من إعداد اللغة. |
| `customWrapperStyle` | `CSSProperties` | `() => ({})` | نمط مضمّن للغلاف الخارجي. |
| `customButtonStyle` | `CSSProperties` | `() => ({})` | نمط مضمّن للزر الذي يفتح القائمة المنسدلة. |
| `customDropdownStyle` | `CSSProperties` | `() => ({})` | نمط مضمّن للوحة القائمة المنسدلة. |
| `customItemStyle` | `CSSProperties` | `() => ({})` | نمط مضمّن لكل عنصر في القائمة المنسدلة. |
| `customLinkStyle` | `CSSProperties` | `() => ({})` | نمط مضمّن للرابط داخل العنصر. |
| `customActiveLinkStyle` | `CSSProperties` | `() => ({})` | نمط مضمّن لرابط اللغة المحلية النشطة حاليًا. |
| `customDisabledLinkStyle` | `CSSProperties` | `() => ({})` | نمط مضمّن لزر اللغة *الحالية* عندما تكون `disabled: true` في الإعداد. |
| `customIconStyle` | `CSSProperties` | `() => ({})` | نمط مضمّن لأيقونة السهم على الزر. |

### الـ Slots {#slots}

| الـ Slot | الربط | الوصف |
| --- | --- | --- |
| `before-button` | — | محتوى قبل الزر الذي يفتح القائمة المنسدلة. |
| `before-selected-locale` | — | محتوى قبل تسمية اللغة النشطة داخل الزر. |
| `after-selected-locale` | — | محتوى بعد تسمية اللغة النشطة داخل الزر. |
| `before-dropdown` | — | محتوى بين الزر ولوحة القائمة المنسدلة. |
| `before-dropdown-items` | — | محتوى في أعلى القائمة المنسدلة، فوق قائمة اللغات. |
| `before-item` | `locale` | محتوى قبل كل عنصر لغة. |
| `before-link-content` | `locale` | محتوى قبل تسمية اللغة داخل رابطها. |
| `after-link-content` | `locale` | محتوى بعد تسمية اللغة داخل رابطها. |
| `after-item` | `locale` | محتوى بعد كل عنصر لغة. |
| `after-dropdown-items` | — | محتوى في أسفل القائمة المنسدلة، تحت قائمة اللغات. |
| `after-dropdown` | — | محتوى بعد لوحة القائمة المنسدلة. |

## السلوك {#behaviour}

- يسرد كل لغة محلية ليست `disabled: true`، بما فيها اللغة النشطة.
- كل عنصر هو `<a>` يشير إلى `$switchLocalePath(code)`. يُحَلّ المسار ضمن `app.baseURL`؛ أما `baseUrl` الخاص بلغة على نطاق آخر فيبقى مطلقًا. يحمل `hreflang` و`lang` بقيمة `iso || code`، و`dir` عندما يكون للغة اتجاه محدد، و`aria-current="page"` على اللغة الحالية، والصنف `switcher-locale-<code>`. يستدعي النقر `$switchLocale(code)` ويغلق القائمة المنسدلة؛ ومع مفتاح تعديل يُترك الأمر للمتصفح.
- تبقى القائمة في HTML الخادم، مخفية، لكي ترى برامج الزحف الروابط. يغلقها مفتاح Escape أو النقر خارجها.
- التسمية: `customLabels[code]`، ثم `displayName` الخاص باللغة، ثم الرمز (مع تحذير في وضع التطوير).
- الأنماط: قيم افتراضية مضمّنة صغيرة (زر ولوحة بيضاء بحدود، والعنصر النشط عريض وأزرق). تُطبَّق كل خاصية `custom*Style` بعد النمط الافتراضي لجزئها. يحمل الزر الصنفين `i18n-switcher-button` و`language-switcher`، والغلاف `i18n-switcher-wrapper`، والقائمة `i18n-switcher-dropdown`. تستخدم المواضع خصائص CSS منطقية، لذا يعمل `dir="rtl"`.

## مثال {#example}

```vue
<template>
  <i18n-switcher
    :custom-labels="{ en: 'English', de: 'Deutsch' }"
    :custom-button-style="{ borderRadius: '4px' }"
  >
    <template #before-link-content="{ locale }">
      <img :src="`/flags/${locale.code}.svg`" alt="" width="16" />
    </template>
  </i18n-switcher>
</template>
```
