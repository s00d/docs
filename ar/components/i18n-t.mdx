يعرض `<i18n-t>` ترجمة واحدة داخل عنصر. استخدمه عندما تحتاج الترجمة إلى مكونات بداخلها (رابط داخل جملة)، أو صيغة جمع، أو رقم أو تاريخ منسَّق. يحلّ المفتاح للمسار الحالي، مثل `$t`.

## الخصائص {#props}

| الخاصية | النوع | الافتراضي | الوصف |
| --- | --- | --- | --- |
| `keypath` **\*** | `string` | — | مفتاح الترجمة المراد عرضه. |
| `plural` | `number \| string \| null` | — | العدد الذي يختار صيغة الجمع. اضبطه لاستخدام `$tc` بدلًا من `$t`. تعني `null` أنه غير مضبوط. |
| `tag` | `string` | `'span'` | العنصر المراد عرضه. |
| `params` | `Record<string, string \| number \| boolean>` | — | قيم الإقحام التي تُستبدل في الترجمة. |
| `defaultValue` | `string` | `''` | يُعرض بدلًا من المكوّن عندما يحجب `hideIfEmpty` ترجمة فارغة. |
| `html` | `boolean` | `false` | اعرض الترجمة بصيغة HTML بدلًا من النص. فقط للترجمات التي تتحكم بها: تُهرَّب `params`، أما الترجمة فلا. |
| `hideIfEmpty` | `boolean` | `false` | لا تعرض شيئًا عندما تُحَل الترجمة إلى سلسلة فارغة. |
| `customPluralRule` | `PluralFunc` | `null` | قاعدة جمع لهذا العنصر فقط، تتجاوز القاعدة المضبوطة. تُستخدم إجابتها كما هي؛ وتعرض `null` قيمة فارغة. |
| `number` | `number \| string \| null` | — | ينسّق القيمة باستخدام `$tn` ويمررها إلى الترجمة بصفتها `{number}`، إلى جانب `params`. |
| `date` | `Date \| string \| number \| null` | — | ينسّق القيمة باستخدام `$td` ويمررها إلى الترجمة بصفتها `{date}`، إلى جانب `params`. |
| `relativeDate` | `Date \| string \| number \| null` | — | ينسّق القيمة باستخدام `$tdr` ويمررها إلى الترجمة بصفتها `{relativeDate}`، إلى جانب `params`. |

**\*** مطلوبة.

## قواعد العرض {#rendering-rules}

أول حالة مطابقة تحدد الناتج:

1. `number` — الترجمة مع `{ ...params, number: $tn(number) }`.
2. `date` — الترجمة مع `{ ...params, date: $td(date) }`.
3. `relativeDate` — الترجمة مع `{ ...params, relativeDate: $tdr(relativeDate) }`.
4. `plural` — الصيغة التي تختارها `$tc`، بما في ذلك [علامة `=0 `](/ar/api/methods#$tc)، مع `{ ...params, count }`؛ أو `customPluralRule(keypath, count, params, locale, t)` عند ضبطها، وهي تقرأ القيمة الخام بما فيها العلامة، وتُستخدم إجابتها كما هي، و`null` تعني فارغة.
5. وإلا فالترجمة مع `params`.

تُعدّ `null` غير مضبوطة. وفي كل الحالات:

- يحل `defaultValue` محل المفتاح المفقود، في كل فرع.
- يعرض `hideIfEmpty` قيمة `defaultValue` بدلًا من نتيجة فارغة.
- يعرض `html` النتيجة بصيغة HTML. تُهرَّب `params`، أما الترجمة فلا؛ وتُتجاهل الـ slots.
- يتلقى الـ slot المسمّى `default` القيمة `{ translation }`، وتُتجاهل الـ slots المسماة.
- وإلا فإن كل slot مسمّى يستبدل كل عنصر نائب `{name}`، قبل أي param بالاسم نفسه. وتبقى قيمة الـ param التي تشبه عنصرًا نائبًا نصًا.

يحمل ناتج `date` و`relativeDate` السمة `data-allow-mismatch="text"`، لأن المنطقة الزمنية وساعة الخادم ليستا كما في المتصفح. اضبط [`timeZone`](/ar/api/module-options#timezone) لعرض تاريخ تقويمي واحد في كليهما؛ أما `relativeDate` فيعتمد على الساعة، لذا قد يختلف مع ذلك.

## مثال {#example}

```json
{
  "terms": "I accept the {link}.",
  "termsLink": "terms of use",
  "items": "no items | one item | {count} items"
}
```

```vue
<template>
  <i18n-t keypath="terms" tag="p">
    <template #link>
      <NuxtLink :to="$localePath('/terms')">{{ $t('termsLink') }}</NuxtLink>
    </template>
  </i18n-t>

  <i18n-t keypath="items" :plural="cart.length" />
</template>
```

يضبط `html` قيمة `innerHTML`: استخدمه فقط للترجمات التي تتحكم بها. تُهرَّب `params`، لذا تكون بيانات المستخدم آمنة هناك، وكذلك المفتاح الذي لم يُعثر له على ترجمة.
