title: "useI18n"
description: "تُعيد useI18n مساعدات وقت التشغيل (`$t`، `$tc`، `$localePath`، …) ككائن عادي، مع البادئة `$` وبدونها."
---

تُعيد `useI18n()` مساعدات وقت التشغيل الخاصة بالوحدة ككائن عادي. استخدمها في `<script setup>` والدوال القابلة للتركيب (composables) والإضافات بدلًا من اللجوء إلى `useNuxtApp()`. يأتي كل مساعد باسمه المسبوق بـ `$` وباسم مستعار مجرّد: `t` و`$t` هما الدالة نفسها.

## التوقيع {#signature}

```ts
useI18n(): PluginsInjectionsWithAliases
```

جميع مساعدات وقت التشغيل، ككائن عادي.

الدوال نفسها التي تحقنها الإضافة باسم `$t` و`$tc` وغيرها، متاحة بالاسم المسبوق بعلامة الدولار
وباسم مستعار مجرّد معًا — لذا يعمل كلٌّ من `const { t } = useI18n()` و
`const { $t } = useI18n()`.

**القيمة المُعادة** — المساعدات الموصوفة في [مرجع الدوال](/ar/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

يحتوي الكائن المُعاد على كل مساعدات [`PluginsInjections`](/ar/api/methods). كلٌّ منها موثّق في صفحة [المساعدات](/ar/api/methods).

## مثال {#example}

```vue
<script setup lang="ts">
const { t, tc, localePath, switchLocale, getLocale } = useI18n()

const title = computed(() => t('page.title'))
</script>

<template>
  <h1>{{ title }}</h1>
  <p>{{ tc('items', 3) }}</p>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
  <button @click="switchLocale(getLocale() === 'en' ? 'de' : 'en')">{{ t('nav.switch') }}</button>
</template>
```

## غير موجود في النوع {#not-in-the-type}

النوع `$defineI18nRoute` معرَّف على `useNuxtApp()` فقط:

```ts
const { $defineI18nRoute } = useNuxtApp()
```
