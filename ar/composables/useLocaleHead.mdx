---
title: "useLocaleHead"
description: "تبني useLocaleHead وسوم SEO الخاصة بـ i18n (lang، dir، canonical، hreflang، og:locale) ككائن تمرّره إلى useHead."
---

تبني `useLocaleHead()` وسوم head الخاصة بـ i18n للمسار الحالي: `lang` و`dir` على `<html>`، ورابط canonical، وبدائل `hreflang` مع `x-default`، و`og:url`، و`og:locale`، و`og:locale:alternate`. استخدمها عندما تضبط [`meta: false`](/ar/api/module-options#meta) وتدير `useHead` بنفسك؛ مع `meta: true` تسجّل الوحدة هذه الوسوم بالفعل، وتمرّ التغييرات الخاصة بكل صفحة عبر [`useI18nHead`](/ar/composables/useI18nHead).

## التوقيع {#signature}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { build: () => LocaleHead; metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }, LocaleHead | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

وسوم head الخاصة بـ SEO للمسار الحالي: بدائل `hreflang` لكل لغة إضافة إلى
`x-default`، ورابط canonical، و`og:locale`، و`lang`/`dir` على `<html>`.

لا تحتاجها إلا عند تعطيل `meta` أو عند الحاجة إلى تعديل القيم الافتراضية — مع `meta: true`
تسجّل الوحدة الوسوم نفسها بنفسها.

| المعامل | النوع | الوصف |
| --- | --- | --- |
| `options` | `UseLocaleHeadOptions` |  |

**القيمة المُعادة** — `metaObject`، وهو ref يحمل كائن head جاهزًا للتمرير إلى `useHead`؛ و`updateMeta` تحدّثه؛ و`build` تحسب كائن head من المسار الحالي (تفاعلية عند قراءتها داخل getter، مثل `useHead(() => build())`)

```ts
const { metaObject } = useLocaleHead({ addSeoAttributes: true })
useHead(metaObject)
```

## الخيارات {#options}

| الخيار | القيمة الافتراضية | الوصف |
| --- | --- | --- |
| `addDirAttribute` | `true` | يضبط `dir` على `<html>` من `dir` الخاص باللغة (`'auto'` إن لم تكن لها قيمة). |
| `identifierAttribute` | `'id'` | السمة التي تُميّز كل وسم (`i18n-can`، `i18n-og`، `i18n-alternate-<hreflang>`، …)، بحيث تستبدل التحديثات الوسوم بدلًا من إضافتها. |
| `addSeoAttributes` | `true` | يُصدر وسوم canonical و`hreflang` و`og:`. القيمة `false` تُبقي `htmlAttrs` فقط. |
| `baseUrl` | `'/'` | الأصل (origin) الذي يُضاف إلى كل عنوان URL. أبقِ `'/'` للعناوين النسبية؛ ومرّر `'https://example.com'` للعناوين المطلقة. |
| `autoUpdate` | `true` | يعيد بناء `metaObject` عند تغيّر المسار أو حالة `i18n-locale`. |

## ما تُصدره {#what-it-emits}

- لا شيء على مسار بلا تطابق (404) أو مع `disableMeta` للغة النشطة.
- canonical و`og:url`: `$switchLocalePath(<active locale>)`، مع تقليص معاملات الاستعلام إلى [`canonicalQueryWhitelist`](/ar/api/module-options#canonicalquerywhitelist)، وتطبيق [`trailingSlash`](/ar/api/module-options#trailingslash).
- `hreflang`: رابط واحد لكل لغة مفعّلة توجد فيها الصفحة، `hreflang = iso || code`، مع تخطي اللغات التي لها `seo: false`؛ ومع `hreflangBaseLanguage: true` تُصدر أول لغة إقليمية للغةٍ ما أيضًا وسم اللغة المجرّدة. لا شيء تحت `no_prefix`.
- `x-default`: عنوان URL للغة الافتراضية، ما لم تكن الاستراتيجية `no_prefix`، أو كانت للغة الافتراضية `seo: false`، أو لم تكن الصفحة موجودة فيها.
- `og:locale` / `og:locale:alternate`: من `og` الخاص باللغة، أو من `iso` بعد تحويله (`en-US` → `en_US`)؛ ويُتخطّى مع تحذير في وضع التطوير عندما لا ينجح أيٌّ منهما.

## مثال {#example}

```ts
// app.vue, with i18n.meta: false
const { metaObject } = useLocaleHead({ baseUrl: 'https://example.com' })
useHead(metaObject)
```

تُعيد `build()` الكائن نفسه بدون ref: يبقى `useHead(() => build())` تفاعليًا دون الحاجة إلى مراقب (watcher).
