تغيّر `useI18nHead()` وسوم SEO التي تولّدها الوحدة، لصفحة واحدة فقط. استخدمها عندما تعرف الصفحة أكثر مما يعرفه الموجّه (router): مقالة في نظام إدارة محتوى موجودة في بعض اللغات فقط، أو عنوان URL أساسي (canonical) قادم من واجهة برمجية، أو وسوم `og:` إضافية. تحصل على الوسوم المولّدة مع دمج تجاوزاتك فوقها.

## التوقيع {#signature}

```ts
useI18nHead(input?: MaybeRefOrGetter<I18nHeadInput | null>): { pageHead: any; resetPageHead: () => void }
```

تسجّل تجاوزات على مستوى الصفحة لوسوم head الخاصة بـ SEO في i18n.
تدمجها الإضافة `02.meta` فوق مخرجات `useLocaleHead`.

فضّل استخدام دالة getter (`() => ({ … })`) عندما تأتي القيم من `$t` / `t` كي
يُعاد حسابها عند تغيير اللغة. أما الكائن العادي فيُقيَّم مرة واحدة ويبقى ثابتًا.

| المعامل | النوع | الوصف |
| --- | --- | --- |
| `input` *(اختياري)* | `MaybeRefOrGetter<I18nHeadInput \| null>` |  |

تعمل مع [`meta: true`](/ar/api/module-options#meta) (القيمة الافتراضية): تدمج إضافة meta الخاصة بالوحدة المدخلات فوق مخرجات [`useLocaleHead`](/ar/composables/useLocaleHead) عند كل تصيير لـ head. مع `meta: false` لا شيء يقرأها.

يُعاد تعيين التجاوز عند تغيّر اسم المسار. الصفحة التي تضبط `disableMeta` لا تحصل على أي وسوم i18n على الإطلاق، بما في ذلك التجاوزات.

## المدخلات {#input}

`I18nHeadInput` (من `@i18n-micro/types`):

| المفتاح | النوع | التأثير |
| --- | --- | --- |
| `htmlAttrs` | `Record<string, string>` | يُدمج في سمات `<html>` (`lang`، `dir`). |
| `meta` | `I18nHeadMeta[]` | يُضاف بعد الوسوم المولّدة؛ ويستبدل الوسم الذي له نفس `id` أو `property` أو `name`. |
| `link` | `I18nHeadLink[]` | يُضاف بعد الروابط المولّدة؛ ويستبدل الرابط الذي له نفس `id`، أو `rel` + `hreflang`. |
| `replace.canonical` | `string \| false` | يستبدل `href` الخاص بـ canonical، أو يزيل الرابط. |
| `replace.hreflang` | `I18nHeadLink[] \| false` | يستبدل أو يزيل **كل** روابط `rel="alternate"`، بما فيها `x-default`. |
| `replace.xDefault` | `I18nHeadLink \| false` | يستبدل رابط `x-default` أو يزيله. |
| `replace.ogLocale` | `string \| false` | يستبدل `og:locale` أو يزيله. |
| `replace.ogUrl` | `string \| false` | يستبدل `og:url` أو يزيله. |
| `replace.ogAlternates` | `string[] \| false` | يعيد بناء `og:locale:alternate` من رموز اللغات هذه (عبر `og` / `iso`)، متخطيًا اللغة الحالية والرموز غير المعروفة والرموز التي ليس لها قيمة `og` أو `iso`، أو يزيلها. |
| `disable` | `I18nHeadDisableGroup[]` | يحذف المجموعات المولّدة: `'hreflang'` (ليس `x-default`)، `'x-default'`، `'canonical'`، `'og'` (`og:locale` + `og:url`)، `'og-alternates'`، `'html'`. |

ترتيب التطبيق: `disable`، ثم `replace`، ثم `htmlAttrs`، `meta`، `link`.

## مثال {#example}

مقالة موجودة في بعض اللغات فقط، مع عناوين URL بديلة من الواجهة البرمجية:

```vue
<script setup lang="ts">
const route = useRoute()
const { t } = useI18n()
const { data: article } = await useFetch<{ title: string; urls: Record<string, string> }>(`/api/articles/${route.params.slug}`)

useI18nHead(() => {
  if (!article.value) return null
  const codes = Object.keys(article.value.urls)
  return {
    meta: [{ property: 'og:title', content: article.value.title || t('blog.title') }],
    replace: {
      hreflang: codes.map((code) => ({ rel: 'alternate', hreflang: code, href: article.value!.urls[code]! })),
      ogAlternates: codes,
    },
  }
})
</script>
```

مرّر دالة getter، كما هنا، عندما تأتي القيم من `t()` أو من بيانات غير متزامنة: إذ يُعاد تشغيلها عند تغيير اللغة. أما الكائن العادي فيُقرأ مرة واحدة.
