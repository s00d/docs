---
title: "useI18nLocale"
description: "تقرأ useI18nLocale حالة اللغة وملف تعريف ارتباط اللغة وتكتبهما — وهي نقطة الدخول للكشف المخصص عن اللغة."
---

يتيح `useI18nLocale()` الوصول إلى اللغة التي اختارها التطبيق: الحالة `i18n-locale` وملف تعريف ارتباط اللغة. استخدمه في إضافة تكشف اللغة بنفسها (النطاق، ملف المستخدم الشخصي، الترويسة) بدلًا من كتابة `useState('i18n-locale')` أو ملف تعريف الارتباط يدويًا. تستخدم فحوص الصلاحية فيه اللغات المفعّلة، بما في ذلك تجاوزات وقت التشغيل.

## التوقيع {#signature}

```ts
useI18nLocale(): { getEffectiveLocale: (route: unknown, getLocaleFromRoute: GetLocaleFromRoute) => string; getLocale: () => string | null; getPreferredLocale: () => string | null; hashCookie: CookieRef; isValidLocale: (locale: string | null | undefined) => locale is string; locale: any; localeCookie: CookieRef; resolveInitialLocale: (options: ResolveInitialLocaleOptions) => string; setLocale: (locale: string | null) => void; syncLocale: (locale: string | null) => void; validLocales: string[] }
```

نقطة دخول مركزية لإدارة لغة i18n.
تجمع بين useState('i18n-locale') وملف تعريف ارتباط اللغة وأدوات المزامنة.

## القيم المُرجَعة {#returned-values}

| العضو | النوع | الوصف |
| --- | --- | --- |
| `locale` | `Ref<string \| null>` | المرجع `useState('i18n-locale')`. |
| `localeCookie` | `Ref<string \| null>` | ملف تعريف الارتباط [`localeCookie`](/ar/api/module-options#localecookie)؛ أو `{ value: null }` بسيط عندما يكون الخيار `null`. |
| `hashCookie` | `Ref<string \| null>` | ملف تعريف الارتباط `hash-locale` عند التوجيه بالجزء (hash)؛ و`{ value: null }` في غير ذلك. |
| `validLocales` | `string[]` | رموز اللغات المفعّلة. |
| `setLocale(locale)` | `(locale: string \| null) => void` | كتابة الحالة وملفات تعريف الارتباط. لا يتحقق من الصلاحية ولا يحمّل الترجمات. |
| `syncLocale(locale)` | `(locale: string \| null) => void` | كتابة ملفات تعريف الارتباط فقط. |
| `getLocale()` | `() => string \| null` | الحالة، ثم ملف تعريف ارتباط التفضيل (ملف تعريف ارتباط الجزء عند التوجيه بالجزء). دون تحقق من الصلاحية. |
| `getPreferredLocale()` | `() => string \| null` | أول قيمة **صالحة** من الحالة وملف تعريف ارتباط التفضيل، أو `null`. |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string` | الحالة عند التوجيه بالجزء إن كانت معيّنة؛ وإلا `getLocaleFromRoute(route)`. |
| `resolveInitialLocale(options)` | `(options: ResolveInitialLocaleOptions) => string` | `options.urlLocale`، ثم حالة صالحة، ثم `options.serverLocale`، ثم لغة المسار. يخزّن النتيجة في الحالة عندما لا تكون الحالة صالحة؛ وعلى العميل يكتب ملف تعريف الارتباط أيضًا. |
| `isValidLocale(locale)` | `(locale) => locale is string` | ما إذا كانت `locale` موجودة في `validLocales`. |

تدوم ملفات تعريف الارتباط سنة واحدة، مع `path: '/'` و`sameSite: 'lax'`.

## مثال {#example}

```ts
// plugins/locale-from-domain.server.ts
export default defineNuxtPlugin({
  name: 'locale-from-domain',
  enforce: 'pre',
  setup() {
    const { setLocale, isValidLocale } = useI18nLocale()
    const host = useRequestURL().hostname // e.g. de.example.com
    const code = host.split('.')[0]
    if (isValidLocale(code)) setLocale(code)
  },
})
```

تقرأ إضافة المحمّل في الوحدة الحالة عند بدئها، لذا يجب أن تعمل الإضافة التي تعيّنها أولًا (`enforce: 'pre'`). كيف تتنافس الحالة مع عنوان URL وملف تعريف الارتباط و`Accept-Language`: [كشف اللغة](/ar/guide/locale-detection). الشرح الكامل: [الكشف المخصص](/ar/guide/custom-auto-detect).

لا يبدّل `setLocale()` الترجمات المعروضة على الشاشة. لتغيير لغة الصفحة الحالية، استدعِ [`$switchLocale()`](/ar/api/methods#$switchlocale).
