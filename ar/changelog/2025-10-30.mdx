**التاريخ**: 2025-10-30

**الإصدار**: `v2.0.0`

![إصدار v2.0.0](/images/2.0.0.png)

نقدّم HMR على جانب الخادم لملفات الترجمة أثناء التطوير. عندما يتغير ملف ترجمة JSON، تُبطل ذاكرة التخزين المؤقت للخادم المفاتيح المتأثرة فقط، وتتلقى الطلبات اللاحقة البيانات الجديدة فورًا، دون الحاجة إلى إعادة التشغيل.

## ما الجديد؟ {#what’s-new}

- HMR على جانب الخادم لملفات الترجمة
- إبطال فوري لذاكرة التخزين المؤقت لكل صفحة/locale
- تجربة تطوير سلسة أثناء تحرير المحتوى

## كيف يعمل {#how-it-works}

- يراقب المراقِب في `src/runtime/server/plugins/watcher.dev.ts` الملفات `<rootDir>/<translationDir>/**/*.json`
- ملفات الصفحات (مثل `pages/<page>/<locale>.json`) تُبطل `_locales:merged:<page>:<locale>`
- الملفات على مستوى الجذر (مثل `<locale>.json`) تُبطل جميع المفاتيح المدمجة لذلك الـ locale
- يُسجَّل تلقائيًا من `src/module.ts` في وضع التطوير عندما يكون `experimental.hmr !== false`

## الإعداد {#configuration}

```ts
export default defineNuxtConfig({
  i18n: {
    experimental: { hmr: true }, // default in dev
  },
})
```
