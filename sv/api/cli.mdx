[CLI-guiden](/sv/guide/cli) visar de vanliga arbetsflödena. Den här sidan listar allt och genereras från samma tabell som driver `--help`.

## Gemensamma flaggor {#common-flags}

| Flagga | Standard | Beskrivning |
| --- | --- | --- |
| `--cwd` | aktuell katalog | Projektkatalog |
| `--logLevel` | `info` | Utdatanivå: silent, info |
| `--debug` | `false` | Skriv ut en stackspårning när ett kommando misslyckas |

## Inspektera {#inspect}

### `info` {#info}

Skriv ut projektets upplösta i18n-konfiguration

| Flagga | Standard | Beskrivning |
| --- | --- | --- |
| `--json` | `false` | Skriv ut JSON i stället för text |

### `check` {#check}

CI-spärren: misslyckas vid saknade, tomma, extra, odefinierade eller oanvända nycklar och trasiga platshållare

| Flagga | Standard | Beskrivning |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` i nuxt.config | Översättningskatalog, relativt projektet |
| `--only` | alla utom duplicates | Kommaseparerade kontroller att köra: missing, empty, extra, placeholders, undefined, unused, duplicates. `unused` som anges här misslyckas när den inte kan köras |
| `--duplicates` | `false` | Rapportera även samma text under olika nycklar |
| `--ignore` | — | Kommaseparerade globmönster för källfiler att hoppa över, relativt projektet |
| `--json` | `false` | Skriv ut JSON i stället för text |

```bash
i18n-micro check
i18n-micro check --only missing,placeholders --json
```

### `stats` {#stats}

Visa hur fullständiga översättningarna är per locale

| Flagga | Standard | Beskrivning |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` i nuxt.config | Översättningskatalog, relativt projektet |
| `--html` | — | Skriv även en HTML-rapport till den här filen |
| `--json` | `false` | Skriv ut JSON i stället för text |
| `--baseRef` | — | Git-ref att jämföra fullständigheten med, t.ex. HEAD~1 eller main |

```bash
i18n-micro stats --baseRef main
i18n-micro stats --html reports/i18n.html
```

### `lint` {#lint}

Kontrollera översättningarnas text; misslyckas när problem kvarstår

| Flagga | Standard | Beskrivning |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` i nuxt.config | Översättningskatalog, relativt projektet |
| `--rules` | alla, eller `enabledRules` i .i18n-lintrc.json | Kommaseparerade regler att köra: no-trailing-spaces, no-multiple-spaces, no-empty-translation eller en egen regel |
| `--fix` | `false` | Åtgärda det som kan åtgärdas: mellanslag, och egna regler med en ersättning |
| `--json` | `false` | Skriv ut JSON i stället för text |

```bash
i18n-micro lint --rules no-trailing-spaces --fix
```

### `search` {#search}

Sök bland nycklar och värden, och visa var varje nyckel används

| Flagga | Standard | Beskrivning |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` i nuxt.config | Översättningskatalog, relativt projektet |
| `<query>` | — | Text eller nyckel att söka efter |
| `--caseSensitive` | `false` | Skilj på versaler och gemener |
| `--onlyUnused` | `false` | Endast nycklar som `clean` skulle ta bort; sökfrågan blir valfri |
| `--scope` | `all` | Var det ska sökas: global, pages, all |
| `--limit` | — | Returnera högst så här många nycklar |
| `--ignore` | — | Kommaseparerade globmönster för källfiler att hoppa över, relativt projektet |
| `--json` | `false` | Skriv ut JSON i stället för text |

```bash
i18n-micro search "Welcome"
i18n-micro search --onlyUnused
```

## Översättningsarbetsflöde {#translation-workflow}

### `extract` {#extract}

Lista de nycklar som källfilerna använder men som ännu saknar text, och lägg till dem som har en standardtext i standard-locale

| Flagga | Standard | Beskrivning |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` i nuxt.config | Översättningskatalog, relativt projektet |
| `--ignore` | — | Kommaseparerade globmönster för källfiler att hoppa över, relativt projektet |

```bash
i18n-micro extract
```

### `translate` {#translate}

Fyll i saknade översättningar från standard-locale via en översättningstjänst

| Flagga | Standard | Beskrivning |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` i nuxt.config | Översättningskatalog, relativt projektet |
| `--service` | — | Översättningstjänst: ai, azure, deepl, google, libretranslate, yandexcloud |
| `--token` | — | API-nyckel. Använd hellre miljövariabeln I18N_TRANSLATE_TOKEN: flaggor hamnar i skalets historik |
| `--options` | — | Tjänstalternativ som key:value-par, separerade med kommatecken |
| `--locale` | alla locales utom standard-locale | Kommaseparerade locales att fylla i |
| `--replace` | `false` | Översätt alla nycklar igen och ersätt befintliga värden |
| `--dryRun` | `false` | Räkna nycklar och tecken per locale; skicka ingenting |
| `--chunkSize` | — | Strängar per begäran; begränsas till vad tjänsten accepterar |
| `--pluralSeparator` | `\|` | Avgränsare för pluralformer i meddelanden |
| `--glossaryFile` | `.i18n-glossary.json` när den finns | Ordlistefil, används av tjänsten `ai` |

```bash
i18n-micro translate --dryRun
I18N_TRANSLATE_TOKEN=... i18n-micro translate --service deepl --locale de,fr
i18n-micro translate --service ai --options provider:openai,model:gpt-4o-mini
i18n-micro translate --service libretranslate --options baseUrl:https://translate.example.com
```

### `sync` {#sync}

Ta bort nycklar som standard-locale inte har; avbryter när det inte kan bevisas vara säkert. Saknade nycklar förblir saknade

| Flagga | Standard | Beskrivning |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` i nuxt.config | Översättningskatalog, relativt projektet |
| `--ignore` | — | Kommaseparerade globmönster för källfiler att hoppa över, relativt projektet |
| `--dryRun` | `false` | Lista vad som skulle tas bort; skriv ingenting |
| `--force` | `false` | Ta bort nycklar även om det inte kan bevisas vara säkert |

```bash
i18n-micro sync --dryRun
```

### `clean` {#clean}

Ta bort nycklar som ingenting i projektet använder; avbryter när det inte kan bevisas

| Flagga | Standard | Beskrivning |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` i nuxt.config | Översättningskatalog, relativt projektet |
| `--include` | — | Reguljärt uttryck: överväg endast matchande nycklar för borttagning |
| `--exclude` | — | Reguljärt uttryck: ta aldrig bort matchande nycklar |
| `--ignore` | — | Kommaseparerade globmönster för källfiler att hoppa över, relativt projektet |
| `--dryRun` | `false` | Lista vad som skulle tas bort; skriv ingenting |
| `--force` | `false` | Ta bort nycklar även om användningen inte kan bevisas för alla |

```bash
i18n-micro clean --dryRun
i18n-micro clean --exclude '^errors\.'
```

## Refaktorering {#refactoring}

### `text-to-i18n` {#text-to-i18n}

Ersätt hårdkodad text i Vue-mallar med översättningsanrop, och rapportera hårdkodad text i kod

| Flagga | Standard | Beskrivning |
| --- | --- | --- |
| `--translationFile` | `<translationDir>/<defaultLocale>.json` | Fil som de nya nycklarna hamnar i |
| `--path` | hela projektet | Fil eller katalog att bearbeta |
| `--context` | — | Prefix för genererade nycklar |
| `--ignore` | — | Kommaseparerade globmönster för källfiler att hoppa över, relativt projektet |
| `--dryRun` | `false` | Visa vad som skulle ändras; skriv ingenting |
| `--interactive` | `false` | Bekräfta eller redigera varje genererad nyckel |

```bash
i18n-micro text-to-i18n --dryRun
i18n-micro text-to-i18n --path components --context ui
```

### `rename` {#rename}

Byt namn på en nyckel eller ett namnområde i alla locales och i källfiler

| Flagga | Standard | Beskrivning |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` i nuxt.config | Översättningskatalog, relativt projektet |
| `--from` **\*** | — | Nuvarande nyckel eller namnområde |
| `--to` **\*** | — | Ny nyckel eller nytt namnområde |
| `--ignore` | — | Kommaseparerade globmönster för källfiler att hoppa över, relativt projektet |
| `--dryRun` | `false` | Rapportera ändringarna; skriv ingenting |

**\*** obligatorisk.

```bash
i18n-micro rename --from common.save --to actions.save
```

### `pseudo` {#pseudo}

Fyll en locale med pseudoöversättningar för att hitta layoutproblem och hårdkodad text

| Flagga | Standard | Beskrivning |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` i nuxt.config | Översättningskatalog, relativt projektet |
| `--sourceLocale` | standard-locale | Locale att läsa |
| `--targetLocale` **\*** | — | Locale att fylla i |
| `--replace` | `false` | Skriv över befintliga värden |

**\*** obligatorisk.

### `format` {#format}

Skriv om locale-filer med sorterade nycklar och enhetlig indentering

| Flagga | Standard | Beskrivning |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` i nuxt.config | Översättningskatalog, relativt projektet |
| `--indent` | `2` | Antal mellanslag för indentering |
| `--sortKeys` | `true` | Sortera nycklar; använd --no-sortKeys för att behålla ordningen |
| `--check` | `false` | Misslyckas om en fil skulle ändras; skriv ingenting |

```bash
i18n-micro format --check
```

## Utbyte {#exchange}

### `export` {#export}

Exportera locale-filer till PO eller CSV, med standard-locales text som källa

| Flagga | Standard | Beskrivning |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` i nuxt.config | Översättningskatalog, relativt projektet |
| `--format` | `po` | Filformat: po, csv |
| `--dir` | `pots` för po, `csv_exports` för csv | Utdatakatalog, relativt projektet |
| `--force` | `false` | Skriv över filer som ändrats sedan senaste exporten och aldrig importerats |

```bash
i18n-micro export --format csv
```

### `import` {#import}

Slå samman PO- eller CSV-filer med locale-filerna

| Flagga | Standard | Beskrivning |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` i nuxt.config | Översättningskatalog, relativt projektet |
| `--format` | `po` | Filformat: po, csv |
| `--dir` | `pots` för po, `csv_exports` för csv | Indatakatalog, relativt projektet |
| `--dryRun` | `false` | Rapportera vad som skulle importeras; skriv ingenting |

```bash
i18n-micro import --format csv --dryRun
```

### `sync-remote` {#sync-remote}

Hämta globala översättningar från, eller skicka dem till, HTTP-slutpunkten i .i18n-remote.json

| Flagga | Standard | Beskrivning |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` i nuxt.config | Översättningskatalog, relativt projektet |
| `--pull` | `true` | Hämta från fjärrkällan |
| `--push` | `false` | Skicka till fjärrkällan |
| `--force` | `false` | Vid pull, ta fjärrvärdet; vid push, skriv över text som bara fjärrkällan har |
| `--dryRun` | `false` | Rapportera vad en pull skulle ändra; skriv och skicka ingenting |

```bash
i18n-micro sync-remote --dryRun
i18n-micro sync-remote --no-pull --push
```

## Lint-regler {#lint-rules}

| Regel | Hittar | Åtgärdas av `--fix` |
| --- | --- | --- |
| `no-trailing-spaces` | Mellanslag i slutet av ett värde eller en rad | ja |
| `no-multiple-spaces` | Två eller fler mellanslag i rad | ja |
| `no-empty-translation` | Ett tomt eller blankt värde | nej |

## Avslutningskoder {#exit-codes}

| Kod | Betydelse |
| --- | --- |
| `0` | Klart, inget att rapportera |
| `1` | Fynd: `check`, `lint` eller `format --check` hittade något, `clean` eller `sync` kunde inte bevisa att en borttagning är säker, `export` skulle skriva över oimporterat arbete, `translate` hoppade över nycklar, `import` eller `sync-remote` stötte på en konflikt, en `sync-remote`-push skulle ta bort fjärrtext. En `--dryRun` av `clean`, `sync` eller en `sync-remote`-pull rapporterar dessa och avslutas med `0` |
| `2` | Fel: felaktig användning, oläsbart projekt, nätverks- eller filfel |

## Konfigurationsfiler {#configuration-files}

| Fil | Används av |
| --- | --- |
| `.i18n-lintrc.json` | `lint`: `enabledRules`, `disabledRules`, `customRegexRules` (`name`, `pattern`, `flags`, `description`, `replacement`) |
| `.i18n-remote.json` | `sync-remote`: `url`, `path`, `token`, `auth` (`username`, `password`). `type` kan utelämnas; endast `custom` finns |
| `.i18n-glossary.json` | `translate --service ai`: `entries` med `source`, `target` och valfria `from`, `to` |

## Miljövariabler {#environment-variables}

| Namn | Används för |
| --- | --- |
| `I18N_TRANSLATE_TOKEN` | API-nyckel för `translate`. Läses även från `.env` |
| `I18N_REMOTE_TOKEN` | Bearer-token för `sync-remote`. Läses även från `.env` |
| `AI_GATEWAY_API_KEY, OPENAI_API_KEY, ANTHROPIC_API_KEY` | Nyckel för tjänsten `ai`, när `I18N_TRANSLATE_TOKEN` inte är satt |
| `DEFAULT_LOCALE` | Åsidosätter `defaultLocale`, precis som i modulen |
