title: "Paket-API:er"
description: "Det exporterade API:et för varje @i18n-micro/*-paket, genererat från de API-ögonblicksbilder som CI kontrollerar mot källkoden."
---

Nuxt-modulen är byggd av små `@i18n-micro/*`-paket, och de flesta fungerar fristående: `@i18n-micro/vue` i en Vue-app, `@i18n-micro/core` var som helst. Använd de här sidorna för att slå upp vad ett paket exporterar, per ingångspunkt. Varje sida genereras från den ögonblicksbild som [`pnpm run api:surface`](https://s00d.github.io/nuxt-i18n-micro/contributing/maintenance-commands#api-surface) kontrollerar mot TypeScript-källorna, så en export kan inte ändras utan att CI märker det.
