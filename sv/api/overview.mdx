Det här avsnittet listar varje alternativ, hjälpfunktion, hook, composable och komponent i Nuxt-modulen, plus det exporterade API:et för varje `@i18n-micro/*`-paket. Använd det för att slå upp en signatur eller ett standardvärde; [guiden](/sv/guide/getting-started) förklarar hur du använder dem. De flesta tabeller här genereras från källkoden, så de stämmer överens med koden.

## Nuxt-modul {#nuxt-module}

| Sida | Omfattar |
| --- | --- |
| [Modulalternativ](/sv/api/module-options) | Varje `i18n`-nyckel i `nuxt.config`, med typ och standardvärde |
| [Hjälpfunktioner](/sv/api/methods) | `$t`, `$tc`, `$tn`, `$td`, `$localePath`, `$switchLocale`, `$defineI18nRoute` och resten |
| [Hooks](/sv/api/events) | Runtime-hooken `i18n:register` |

## Composables {#composables}

| Composable | Använd den för |
| --- | --- |
| [`useI18n`](/sv/composables/useI18n) | Hjälpfunktionerna i `<script setup>` |
| [`useI18nLocale`](/sv/composables/useI18nLocale) | Locale-tillstånd och cookie i ett eget detekteringsplugin |
| [`useI18nHead`](/sv/composables/useI18nHead) | Åsidosättningar per sida av de genererade SEO-taggarna |
| [`useLocaleHead`](/sv/composables/useLocaleHead) | SEO-taggarna som ett objekt, för din egen `useHead` |

## Komponenter {#components}

| Komponent | Renderar |
| --- | --- |
| [`<i18n-t>`](/sv/components/i18n-t) | En översättning, med pluralisering, formatering och slot-interpolering |
| [`<i18n-link>`](/sv/components/i18n-link) | En `NuxtLink` till den lokaliserade routen |
| [`<i18n-switcher>`](/sv/components/i18n-switcher) | En rullgardinsmeny för locales |
| [`<i18n-group>`](/sv/components/i18n-group) | Ett block med ett gemensamt nyckelprefix |

## Server {#server}

Nitro-hanterare använder `useTranslationServerMiddleware` och `useLocaleServerMiddleware`, inte klienthjälpfunktionerna. Se [Serverroutes](/sv/guide/server-side-translations).

## Paket {#packages}

[Paket-API:er](/sv/api/packages/overview) listar exporterna från varje `@i18n-micro/*`-paket, en genererad sida per paket.
