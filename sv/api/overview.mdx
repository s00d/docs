# API-referens

## Runtime-API

- [Metoder](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, lokalbyte och routing-hjälpare
- [Händelser](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Översättningar och cache](/api/cache) — `TranslationStorage`, laddning av payload och `$clearCache`

## Server-middleware

Serverhanterare använder dedikerad middleware (inte klient-hjälparna `$t`):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — översätt i API-rutter och serverhanterare
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — läs upptäckt lokal och metadata

Se den fullständiga guiden [Serverbaserade översättningar](/guides/server-side-translations) för installation, prioritet för lokaldetektering och exempel.
