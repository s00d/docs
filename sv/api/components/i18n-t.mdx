# 🌍 Komponenten `<i18n-t>`

Komponenten `<i18n-t>` i `Nuxt I18n Micro` är en flexibel översättningskomponent som stöder dynamiskt innehåll via slots. Du kan interpolera översättningar med anpassade Vue-komponenter eller HTML-innehåll och möjliggöra avancerade lokaliseringsscenarier.

Endast en av `plural`, `number`, `date` och `relativeDate` gäller åt gången; när flera är satta vinner den första i listan.

### Exempel per prop

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

## 🛠️ Exempelanvändning

### Grundläggande användning

```vue
<i18n-t keypath="feedback.text" />
```

Detta renderar översättningen för `feedback.text` inuti en `<span>`-tagg.

### Använda slots för dynamiskt innehåll

Komponenten `<i18n-t>` stöder användning av slots för att dynamiskt infoga Vue-komponenter eller annat innehåll i specifika delar av översättningen.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

I det här exemplet ersätts platshållaren `\{link\}` i översättningssträngen `feedback.text` av `<nuxt-link>`-komponenten, som själv innehåller en annan översättningskomponent.

### Pluralisering

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

Detta tillämpar automatiskt pluraliseringsregler baserat på värdet `itemCount`.

## 🚀 Ytterligare funktioner

### Standardslot

Om ingen specifik slot anges kan översättningen anpassas via standardsloten, som tillhandahåller hela den översatta strängen:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### Villkorlig rendering

Rendera ingenting om översättningssträngen är tom genom att använda propen `hideIfEmpty`.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### Anpassad pluraliseringsregel

Använd en anpassad funktion för att hantera pluralisering.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### Avancerat exempel med slots

Använd slots för att anpassa hur översättningsinnehållet renderas.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
