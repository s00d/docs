# 🌍 Komponenten `<i18n-group>`

Komponenten `<i18n-group>` i Nuxt I18n Micro erbjuder ett bekvämt sätt att gruppera översättningar under ett gemensamt prefix, vilket minskar upprepningar och förbättrar kodorganisationen.

## ⚙️ Props

{/* generated:component:i18n-group — do not edit; run `pnpm run docs:generate` */}

| Prop | Typ | Standard | Beskrivning |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | Nyckelprefix som varje uppslagning inuti sloten resolvas mot. |
| `groupClass` | `string` | `''` | Extra klass på omslagselementet. |

**\*** krävs.

### Slots

| Slot | Bindningar | Beskrivning |
| --- | --- | --- |
| `default` | `prefix`, `t` | Tar emot `prefix` och en `t`-funktion begränsad till det. |

## 🎯 Slots

Standardsloten tar emot `prefix` och en `t`-funktion begränsad till det, så nycklar inuti skrivs relativt till prefixet:

```vue
<i18n-group prefix="checkout">
  <template #default="{ t }">
    <h2>{{ t('title') }}</h2>
    <p>{{ t('summary', { count: 3 }) }}</p>
  </template>
</i18n-group>
```

## 🛠️ Exempelanvändning

### Grundläggande användning

```vue
<template>
  <i18n-group prefix="product.details">
    <template #default="{ t }">
      <h1>{{ t('title') }}</h1>
      <p>{{ t('description') }}</p>
      <div class="price">{{ t('price', { value: 99.99 }) }}</div>
    </template>
  </i18n-group>
</template>
```

Översättningsfil:

```json
{
  "product": {
    "details": {
      "title": "Premium Product",
      "description": "This is a premium product",
      "price": "Price: ${value}"
    }
  }
}
```

### Med anpassad klass

```vue
<template>
  <i18n-group prefix="user.profile" group-class="profile-section">
    <template #default="{ t }">
      <div class="user-info">
        <h2>{{ t('title') }}</h2>
        <p>{{ t('bio') }}</p>
        <div class="stats">
          <span>{{ t('stats.followers') }}</span>
          <span>{{ t('stats.following') }}</span>
        </div>
      </div>
    </template>
  </i18n-group>
</template>
```

Översättningsfil:

```json
{
  "user": {
    "profile": {
      "title": "User Profile",
      "bio": "User biography goes here",
      "stats": {
        "followers": "Followers: {count}",
        "following": "Following: {count}"
      }
    }
  }
}
```

### Med dynamiskt innehåll

```vue
<template>
  <i18n-group prefix="blog.post">
    <template #default="{ t }">
      <article>
        <h1>{{ t('title') }}</h1>
        <div class="meta">
          {{ t('meta.author', { name: author }) }} |
          {{ t('meta.date', { date: publishDate }) }}
        </div>
        <div v-for="(section, index) in sections" :key="index">
          <h2>{{ t(`sections.${index}.title`) }}</h2>
          <p>{{ t(`sections.${index}.content`) }}</p>
        </div>
      </article>
    </template>
  </i18n-group>
</template>

<script setup>
const author = 'John Doe'
const publishDate = '2024-01-01'
const sections = ['intro', 'main', 'conclusion']
</script>
```

## 🎨 Styling

Komponenten omsluter sitt innehåll i en div med klassen `i18n-group` och eventuella ytterligare klasser som anges i `groupClass`-propen:

```css
.i18n-group {
  /* Your base styles */
}

.profile-section {
  /* Additional styles for profile sections */
}
```

## 🚀 Bästa praxis

1. **Konsekventa prefix**: Använd konsekventa och logiska prefix som återspeglar din applikations struktur

```vue
<i18n-group prefix="features.pricing">
<i18n-group prefix="features.security">
```

2. **Modulär organisation**: Gruppera relaterade översättningar tillsammans under meningsfulla prefix

```vue
<i18n-group prefix="checkout.payment">
<i18n-group prefix="checkout.shipping">
```

3. **Återanvändbara komponenter**: Skapa återanvändbara komponenter med sina egna översättningsgrupper

```vue
<!-- UserProfile.vue -->
<i18n-group prefix="user.profile">

<!-- UserSettings.vue -->
<i18n-group prefix="user.settings">
```

4. **Nästlade grupper**: Undvik att nästla grupper djupt för att bibehålla tydlighet

```vue
<!-- Good -->
<i18n-group prefix="shop.product">

<!-- Avoid -->
<i18n-group prefix="shop.category.product.details.specs">
```
