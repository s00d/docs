# 🌍 Komponenten `<i18n-switcher>`

Komponenten `<i18n-switcher>` i `Nuxt I18n Micro` tillhandahåller ett användarvänligt rullgardinsgränssnitt för att byta mellan olika lokaler i din applikation. Denna komponent är mycket anpassningsbar och möjliggör sömlös integration med din applikations design och layout.

Lokaler med `disabled: true` **utelämnas** från rullgardinen (de förblir tillgängliga via `$getLocales()` för SEO / head-taggar). Endast växlingsbara lokaler får `NuxtLink` + `hreflang`.

## 🛠️ Exempelanvändning

### Grundläggande användning

```vue
<template>
  <i18n-switcher />
</template>
```

Detta renderar en lokalväxlare med standardstyling och beteende.

### Anpassade etiketter och inline-stilar

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Detta exempel visar en fullt anpassad lokalväxlare med anpassade etiketter och inline-stilar.

## 🔌 Slots

Varje visuell del av växlaren kan ersättas. Slotsen är listade tillsammans med props-tabellen ovan; varje slot tar mallinnehåll:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Slots vars namn slutar på `-item`, `-link-content` eller börjar med `before-item` tar emot `locale`-objektet de tillhör.

## 🎨 Översikt av stilar

Komponenten `<i18n-switcher>` levereras med grundläggande stilar definierade via inline-stilar som enkelt kan åsidosättas genom att skicka anpassade stilar via props. Här är en kort översikt över standardstilarna:

- **Wrapper**: Styr positioneringen av rullgardinen.
- **Button**: Stylar rullgardinens togglingsknapp.
- **Dropdown**: Stylar rullgardinslistan.
- **Items**: Stylar varje objekt i listan.
- **Links**: Stylar länkarna inuti varje objekt.
- **Icon**: Stylar rullgardinens indikatorikon.

Du kan anpassa dessa stilar genom att skicka anpassade stilar via respektive props, vilket säkerställer att lokalväxlaren integreras sömlöst i din applikations UI.
