# 🌍 Komponenten `<i18n-link>`

Komponenten `<i18n-link>` i `Nuxt I18n Micro` är en mångsidig länkkomponent som automatiskt lokaliserar rutter baserat på aktuell lokal. Den fungerar som en wrapper runt `<NuxtLink>`-komponenten och tillhandahåller ytterligare funktioner som aktiv länkstyling och stöd för externa länkar.

`to` accepterar allt som `NuxtLink` gör — en sökväg, en namngiven rutt eller ett resolvat ruttobjekt. En absolut URL upptäcks och renderas som en vanlig `<a target="_blank" rel="noopener noreferrer">` i stället för att lokaliseras.

## 🛠️ Exempelanvändning

### Grundläggande användning

```vue
<i18n-link to="/about">About Us</i18n-link>
```

Detta exempel skapar en länk till sidan `/about`, lokaliserad till aktuell lokal.

### Styling av aktiv länk med inline-stilar

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

Länken får fet text när användaren är på sidan `/about`, vilket låter dig styla den aktiva länken direkt med inline-stilar.

### Hantering av externa länkar

Komponenten upptäcker automatiskt externa länkar och lägger till nödvändiga attribut för säkerhet.

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

Denna länk öppnar `https://example.com` i en ny flik med `rel="noopener noreferrer"` tillämpat.

## 🎨 Stilar

Komponenten använder nu inline-stilar för det aktiva tillståndet i stället för en klass. Du kan anpassa dessa stilar via propen `activeStyle`.

### Standardstilar för aktivt tillstånd

- **Font Weight**: `bold`
- **Color**: Ärver webbläsarens standardfärg (om ingen `color` anges i `activeStyle`).

Du kan åsidosätta dessa genom att ange anpassade stilar via propen `activeStyle`.

### Anpassade stilar för aktivt tillstånd

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

I det här exemplet blir länken fet och grön när den är aktiv.

## 🚀 Ytterligare funktioner

### Slot för anpassat innehåll

Du kan skicka anpassat innehåll inuti länken med slots, vilket gör komponenten flexibel för olika användningsfall.

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### Förbättringar för tillgänglighet

Komponenten stöder `aria-label` och andra tillgänglighetsattribut för att säkerställa en mer tillgänglig upplevelse.

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
