# 🛠️ Metoder

Denna sida dokumenterar alla tillgängliga metoder som tillhandahålls av nuxt-i18n-micro. Metoderna är organiserade efter funktionalitet för enklare navigering.

### `$getI18nConfig`

{/* generated:method:$getI18nConfig — do not edit; run `pnpm run docs:generate` */}

```ts
() => ModuleOptionsExtend
```

Den upplösta modulkonfigurationen, som runtime ser den.

{/* /generated:method:$getI18nConfig */}

```typescript
const nuxtApp = useNuxtApp()
const { localeCookie, strategy, hooks } = nuxtApp.$getI18nConfig()
```

För byggtid eller kontexter utanför Nuxt, använd `getI18nConfig()` från `#build/i18n.strategy.mjs` i stället.

<Info>
`serverTranslationPreload` är ett privat modulalternativ som endast exponeras i serverns privata konfiguration (`#i18n-internal/config`). Det är inte del av det publika runtime-API:et och kan ändras utan förvarning.
</Info>

## 🔍 Översättningsmetoder

Kärnmetoder för att hämta och hantera översättningar.

### `$t`

{/* generated:method:$t — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Översätt en nyckel och interpolera `params` in i den. Returnerar `defaultValue` när nyckeln saknas, eller själva nyckeln när inget standardvärde anges.

{/* /generated:method:$t */}

```typescript
const welcomeMessage = $t('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

<Warning>
`$t` returnerar `CleanTranslation` som är `string | number | boolean | Translations | PluralTranslations | null`. Om nyckeln pekar på ett **nästlat objekt** i din JSON (till exempel `$t('header')` när JSON innehåller `\{ "header": \{ "title": "Hi" \} \}`), blir returvärdet det **objektet**, inte en sträng. Att använda det direkt i en Vue-mall (<code v-pre>\{\{ $t('header') \}\}</code>) renderar som `[object Object]`.

**Så här undviker du detta:**

- Använd en mer specifik nyckel: `$t('header.title')` → `"Hi"`
- Använd `$ts()` som alltid returnerar en sträng (anropar `.toString()` på icke-strängar)
- Använd `$t` med en nästlad nyckel för att medvetet komma åt underobjekt för programmatisk användning
</Warning>

### `$ts`

{/* generated:method:$ts — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string) => string
```

Som `$t`, men returnerar alltid en sträng: ett objekt- eller arrayvärde stringifieras i stället för att returneras som det är.

{/* /generated:method:$ts */}

```typescript
const welcomeMessage = $ts('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

### `$_t` och `$_ts`

{/* generated:method:$_t — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Bind `$t` till en specifik rutt, för översättning utanför den aktuella sidan. Till exempel en layout som renderar en länk till en annan rutt.

{/* /generated:method:$_t */}

{/* generated:method:$_ts — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => string
```

Bind `$ts` till en specifik rutt. Se `$_t`.

{/* /generated:method:$_ts */}

Ruttbundna varianter av `$t` och `$ts`. De tar en **rutt** först och returnerar en översättningsfunktion låst till den ruttens lokal och sidkontext.

- **Åtkomst**: `useNuxtApp()` (även återexporterad av `useI18n()` som `$_t` / `$_ts`)

Använd dessa när den aktiva rutten under SSR eller övergångar skiljer sig från `router.currentRoute`, till exempel inuti `<i18n-t>`, `<i18n-group>` eller när du renderar innehåll för ett specifikt `route`-objekt.

```typescript
import { useRoute, useNuxtApp } from '#imports'

const route = useRoute()
const { $_t, $_ts } = useNuxtApp()

const $t = $_t(route)
const title = $t('page.title')

// String-safe variant
const label = $_ts(route)('page.label')
```


### `$tc`

{/* generated:method:$tc — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params: number | Params, defaultValue?: string) => string
```

Översätt med pluralisering. `params` kan vara själva antalet, eller ett objekt som innehåller `count`.

{/* /generated:method:$tc */}

**Översättningsformat**: former separerade med `|`. Placera platshållare i **varje** form:

```json
{
  "apples": "no apples | one apple | {count} apples",
  "cart": "no items for {name} | one item for {name} | {count} items for {name}"
}
```

```typescript
$tc('apples', 0) // "no apples"
$tc('apples', 1) // "one apple"
$tc('apples', 10) // "10 apples"

// count + other params (second argument must be an object)
$tc('cart', { count: 10, name: 'Alice' }) // "10 items for Alice"
```


**Komponentalternativ** — `<i18n-t keypath="cart" :plural="count" :params="\{ name \}" />` (slår samman `count` med `params` internt).


### `$mergeTranslations`

{/* generated:method:$mergeTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
(newTranslations: Translations) => void
```

Slå samman översättningar in i den aktiva lokalen vid runtime, med företräde över vad som är laddat.

{/* /generated:method:$mergeTranslations */}

```typescript
$mergeTranslations({
  welcome: 'Bienvenue, {username}!',
})
// Output: Updates the translation cache with the new French translation
```

### `$resolveTranslations`

{/* generated:method:$resolveTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
() => Translations
```

Alla översättningar som för närvarande finns i minnet för den aktiva lokalen och rutten, som ett träd. Skrivskyddad vy av vad `$t()` kan resolva just nu.

{/* /generated:method:$resolveTranslations */}

```typescript
const tree = $resolveTranslations()
// { aaa: { bbb: 'ccc' }, ddd: 1111 } — the same dictionary $t() reads from
```

Använd detta när du behöver den fullständiga in-memory-ordboken (DevTools, tester, runtime-redigerare). Behandla returvärdet som skrivskyddat; ändra värden via `$setTranslation` eller slå samman patcher med `$mergeTranslations`.

### `$setTranslation`

{/* generated:method:$setTranslation — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, value: unknown) => void
```

Ersätt värdet vid `key` i den aktiva ordboken. Detta är en ersättning, inte en sammanslagning. Använd `$mergeTranslations` när befintliga syskon ska överleva.

{/* /generated:method:$setTranslation */}

```typescript
$setTranslation('aaa', { fff: 'ggg' }) // replaces the whole `aaa` subtree
$setTranslation('aaa', 'text')          // replaces `aaa` with a string
$setTranslation('ddd', 1111)            // scalar at the top level
$setTranslation('aaa.bbb', 'nested')    // dotted path
```

Detta är en **ersättning**, inte en sammanslagning. Befintliga syskon under samma nyckel tas bort. Använd `$mergeTranslations` för att patcha utan att förlora syskon.

### `$setMissingHandler`

{/* generated:method:$setMissingHandler — do not edit; run `pnpm run docs:generate` */}

```ts
(handler: MissingHandler | null) => void
```

Installera en callback som anropas för varje oupplöst nyckel. Skicka `null` för att ta bort den.

{/* /generated:method:$setMissingHandler */}

**Typdefinition**:

```typescript
type MissingHandler = (locale: string, key: string, routeName: string, instance?: unknown, type?: string) => void
```

```typescript
// Set a custom handler
$setMissingHandler((locale, key, routeName) => {
  console.error(`Missing translation: ${key} in ${locale} for route ${routeName}`)
  // Send to Sentry or other error tracking service
  // Sentry.captureMessage(`Missing translation: ${key}`)
})

// Remove the handler
$setMissingHandler(null)
```

**Användningsfall**:

- Logga saknade översättningar till felspårningstjänster (Sentry, LogRocket och andra)
- Samla analytik om saknade översättningar
- Anpassad felhantering för saknade översättningsnycklar

## 🔢 Nummer- och datumformatering

Metoder för att formatera tal och datum enligt lokalkonventioner.

### `$tn`

{/* generated:method:$tn — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Formatera ett tal med `Intl.NumberFormat` i den aktiva lokalen. En nyckel väljer ett namngivet format från konfigurationen.

{/* /generated:method:$tn */}

```typescript
// Inline options
const formattedNumber = $tn(1234567.89, { style: 'currency', currency: 'USD' })
// "$1,234,567.89"

// Named format (from nuxt.config i18n.numberFormats)
const price = $tn(1000, 'currency')
const priceDe = $tn(1000, 'currency', 'de')
const compact = $tn(1000, 'currency', { notation: 'compact' })
```

Okända namngivna formatnycklar faller tillbaka till standardvärden för `Intl.NumberFormat`. I utveckling (klient) skickas en `console.warn` när `missingWarn` är aktiverat (standard).

**Konfigurationsexempel**:

```ts
export default defineNuxtConfig({
  i18n: {
    numberFormats: {
      en: {
        currency: { style: 'currency', currency: 'USD' },
        decimal: { style: 'decimal', minimumFractionDigits: 2, maximumFractionDigits: 2 },
      },
      de: {
        currency: { style: 'currency', currency: 'EUR' },
      },
    },
  },
})
```

**Användningsfall**:

- Formatera tal som valuta, procenttal eller decimaler i lämpligt lokalformat
- Återanvända namngivna format i hela appen (paritet med Vue I18n-migrering)

### `$td`

{/* generated:method:$td — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Formatera ett datum med `Intl.DateTimeFormat` i den aktiva lokalen. En nyckel väljer ett namngivet format från konfigurationen.

{/* /generated:method:$td */}

```typescript
const formattedDate = $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' })
// "Friday, September 1, 2023"

const short = $td(new Date(), 'short')
const longDe = $td(new Date(), 'long', 'de')
```

Okända namngivna formatnycklar faller tillbaka till standardvärden för `Intl.DateTimeFormat`. I utveckling (klient) skickas en `console.warn` när `missingWarn` är aktiverat (standard).

**Konfigurationsexempel**:

```ts
export default defineNuxtConfig({
  i18n: {
    datetimeFormats: {
      en: {
        short: { year: 'numeric', month: 'short', day: 'numeric' },
        long: { year: 'numeric', month: 'long', day: 'numeric', weekday: 'long' },
      },
    },
  },
})
```

**Användningsfall**:

- Visa datum i ett format som är anpassat till användarens lokal
- Dela korta/långa/datetime-förinställningar i hela appen

### `$tdr`

{/* generated:method:$tdr — do not edit; run `pnpm run docs:generate` */}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

Formatera ett datum som relativ tid ("3 days ago") med `Intl.RelativeTimeFormat`.

{/* /generated:method:$tdr */}

```typescript
const relativeDate = $tdr(new Date(Date.now() - 1000 * 60 * 5))
// Output: "5 minutes ago" in the 'en-US' locale
```

## 🔄 Rutt- och lokalbyte

Metoder för att växla mellan lokaler och rutter.

### `$switchLocale`

{/* generated:method:$switchLocale — do not edit; run `pnpm run docs:generate` */}

```ts
(locale: string) => void
```

Navigera till den aktuella sidan i en annan lokal.

{/* /generated:method:$switchLocale */}

```typescript
$switchLocale('fr')
// Prefix strategies: navigates to the French version of the route
// no_prefix: updates locale and translations without changing the URL path
```

<Tip>
Se [FAQ — byta lokal utan att ändra URL:en](/guides/faq#-switch-locale-without-changing-the-url). För prefixstrategier, använd `$switchLocalePath()` när du bara behöver ett länkmål.
</Tip>

### `$switchLocaleRoute`

{/* generated:method:$switchLocaleRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(locale: string) => RouteLocationRaw
```

Ruttobjektet för den aktuella sidan i en annan lokal, utan att navigera.

{/* /generated:method:$switchLocaleRoute */}

```typescript
// on /en/news
const routeFr = $switchLocaleRoute('fr')
// Output: A route object with the new locale applied, e.g., { name: 'localized-news', params: { locale: 'fr' } }
```

### `$switchLocalePath`

{/* generated:method:$switchLocalePath — do not edit; run `pnpm run docs:generate` */}

```ts
(locale: string) => string
```

Sökvägen till den aktuella sidan i en annan lokal, utan att navigera.

{/* /generated:method:$switchLocalePath */}

```typescript
// on /en/news
const routeFr = $switchLocalePath('fr')
window.location.href = routeFr
// Output: url with new locale applied, e.g., '/fr/nouvelles'
```

### `$switchRoute`

{/* generated:method:$switchRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, toLocale?: string) => void
```

Navigera till en annan rutt och behåll den aktiva lokalen eller byt till `toLocale`.

{/* /generated:method:$switchRoute */}

**Exempel**:

<CodeGroup>
```typescript String Path
// Switches to the given path with the current locale
$switchRoute('/about')
```

```typescript String Path with Locale
// Switches to the given path with French locale
$switchRoute('/about', 'fr')
```

```typescript Named Route
// Switches to a named route with the current locale
$switchRoute({ name: 'page' })
```

```typescript Named Route with Locale
// Switches to a named route and changes the locale to Spanish
$switchRoute({ name: 'page' }, 'es')
```
</CodeGroup>

## 🚦 Ruttkonfiguration

Metoder för att konfigurera ruttbeteende och åtkomstkontroll.

### `$defineI18nRoute`

{/* generated:method:$defineI18nRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Registrera lokalkonfiguration och översättningar per sida inifrån en komponent. Slås samman med den aktiva lokalen och tillämpas på nytt när lokalen ändras.

{/* /generated:method:$defineI18nRoute */}

> [!IMPORTANT]
> `$defineI18nRoute` tillhandahålls av **define-pluginen** och är endast tillgänglig via `useNuxtApp()`. Den är **inte** en del av returobjektet från `useI18n()`.
> Destrukturera den alltid från `useNuxtApp()` inuti `script setup`. Att anropa `$defineI18nRoute(...)` som en naken global kastar `"$defineI18nRoute is not defined"` under SSR/prerender.

**Parametrar**:

- **locales**: `string[] | Record<string, Record<string, string>>` — Tillgängliga lokaler för rutten
- **localeRoutes**: `Record<string, string>` — Valfritt. Anpassade rutter för specifika lokaler
- **disableMeta**: `boolean | string[]` — Valfritt. Inaktiverar i18n-metataggar för alla eller specifika lokaler

**Grundexempel**:

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr', 'de'],
  localeRoutes: {
    en: '/welcome',
    fr: '/bienvenue',
    de: '/willkommen',
  },
  disableMeta: false,
})
```

> 📖 **För detaljerade användningsexempel, konfigurationsformat och bästa praxis, se [Guiden för översättningar per komponent](/guides/per-component-translations).**

### `$setI18nRouteParams`

{/* generated:method:$setI18nRouteParams — do not edit; run `pnpm run docs:generate` */}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Ställ in per-lokala parametrar för den aktuella rutten, så att ett dynamiskt segment kan skilja sig åt per språk. Anropa den under SSR, innan `head` renderas.

{/* /generated:method:$setI18nRouteParams */}

```typescript
// in pages/news/[id].vue
// for en/news/1-first-article
const { $switchLocaleRoute, $setI18nRouteParams, $defineI18nRoute } = useNuxtApp()
$defineI18nRoute({
  localeRoutes: {
    en: '/news/:id()',
    fr: '/nouvelles/:id()',
    de: '/Nachricht/:id()',
  },
})
const { data: news } = await useAsyncData(`news-${params.id}`, async () => {
  let response = await $fetch("/api/getNews", {
    query: {
      id: params.id,
    },
  });
  if (response?.localeSlugs) {
    response.localeSlugs = {
      en: {
        id: '1-first-article'
      }
      fr: {
        id: '1-premier-article'
      }
      de: {
        id: '1-erster-Artikel'
      }
    }
    $setI18nRouteParams(response?.localeSlugs);
  }
  return response;
});
$switchLocalePath('fr') // === 'fr/nouvelles/1-premier-article'
$switchLocalePath('de') // === 'de/Nachricht/1-erster-Artikel'
```

## 🔧 Cache- och verktygsmetoder

### `$has`

{/* generated:method:$has — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string) => boolean
```

Om en nyckel resolvar i den aktiva lokalen. Använd det för att förgrena på valfri copy i stället för att rendera en rå nyckel.

{/* /generated:method:$has */}

Under sidövergångar inom samma lokal slår v3 automatiskt samman översättningar från den lämnande sidan djupt in i denna ordbok tills övergången är klar. Nycklar från den föregående sidan kan därför fortfarande returnera `true` en kort stund. Det finns inget `previousPageFallback`-alternativ; detta beteende är inbyggt. Se [FAQ — sidövergångar](/guides/faq#-why-do-translations-break-during-page-transitions-especially-with-defineasynccomponent).

```typescript
if ($has('welcome')) {
  console.log($t('welcome'))
} else {
  console.log('Key not found')
}
```

## 🧭 Composablen `useI18nLocale`

Den centraliserade composablen för hantering av lokalstate. Använd denna i stället för att direkt manipulera `useState('i18n-locale')` eller `useCookie('user-locale')`.

```typescript
const {
  setLocale, // (locale: string) => void — updates state + cookie
  getLocale, // () => string | null — from state or cookie
  getPreferredLocale, // () => string | null — validated against locales list
  getEffectiveLocale, // (route, getLocaleFromRoute) => string
  resolveInitialLocale, // (options) => string
  isValidLocale, // (locale) => boolean
  locale, // Ref<string | null> — reactive state
  localeCookie, // CookieRef — reactive cookie
  syncLocale, // (locale) => void — sync to cookie only
  validLocales, // string[] — list of valid locale codes
} = useI18nLocale()
```

### Nyckelmetoder

| Metod                   | Beskrivning                                                    |
| ----------------------- | -------------------------------------------------------------- |
| `setLocale(locale)`     | Sätter lokalen i både `useState` och cookie atomiskt           |
| `getLocale()`           | Returnerar aktuell lokal från state eller cookie               |
| `getPreferredLocale()`  | Returnerar lokal validerad mot listan `locales`, eller `null`  |
| `isValidLocale(locale)` | Kontrollerar om en lokalkod finns i den konfigurerade listan `locales` |

### Användning i anpassade plugins

```typescript
// plugins/i18n-loader.server.ts
export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,
  setup() {
    const { setLocale } = useI18nLocale()
    // Detect locale from headers, domain, etc.
    setLocale('de')
  },
})
```
