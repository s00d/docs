---
title: "Hjälpfunktioner"
description: "Varje körtidshjälpfunktion som modulen injicerar — `$t`, `$tc`, `$localePath`, `$switchLocale` och resten — med sin signatur."
---

Modulen injicerar sina körtidshjälpfunktioner i Nuxt-appen: `$t`, `$tc`, `$localePath`, `$switchLocale` och resten. Använd den här sidan för att slå upp en hjälpfunktions signatur och beteende. Signaturer och beskrivningar kommer från gränssnitten `PluginsInjections` och `NuxtAppOnlyInjections` i `src/runtime/plugins/01.plugin.ts`.

## Åtkomst {#access}

| Var | Hur |
| --- | --- |
| Mall | `{{ $t('title') }}` — varje hjälpfunktion, med `$` |
| `<script setup>` | `const { t, localePath } = useI18n()` — varje hjälpfunktion i `PluginsInjections`, med och utan `$` |
| Plugin, middleware, `<script setup>` | `const { $t, $defineI18nRoute } = useNuxtApp()` — allt, endast med `$` |

`$defineI18nRoute` är typad endast på `useNuxtApp()`. Se [`useI18n`](/sv/composables/useI18n).

```vue
<script setup lang="ts">
const { t, localePath } = useI18n()
</script>

<template>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
</template>
```

## Locale {#locale}

### `$getLocale` {#$getlocale}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric) => string
```

Koden för den aktiva locale. Skicka in en route för att läsa den locale som routen tillhör.

```ts
$getLocale() // 'de' on /de/about
```

### `$getLocaleName` {#$getlocalename}

```ts
() => string | null
```

Den aktiva locales `displayName` från konfigurationen, eller `null` när den saknar ett.

### `$getLocales` {#$getlocales}

```ts
() => Locale[]
```

Varje konfigurerad locale, med dess metadata.

Egna egenskaper på ett locale-objekt returneras som de skrevs; typa dem med [modulutökning](/sv/api/module-options#locales) av `Locale`.

### `$defaultLocale` {#$defaultlocale}

```ts
() => string | undefined
```

Koden för den konfigurerade standard-locale.

### `$getI18nConfig` {#$geti18nconfig}

```ts
() => ResolvedI18nConfig
```

Den upplösta modulkonfigurationen, så som körtiden ser den.

Värdet inkluderar [körtidsåsidosättningar](/sv/guide/runtime-overrides) (`defaultLocale`, `fallbackLocale`, inaktiverade locales).

```ts
const { strategy, localeCookie } = useNuxtApp().$getI18nConfig()
```

## Översättning {#translation}

### `$t` {#$t}

```ts
TranslationFn<CleanTranslation>
```

Översätter en nyckel och interpolerar `params` i den. Returnerar `defaultValue` när nyckeln
saknas, eller själva nyckeln när inget standardvärde anges.

```ts
// { "welcome": "Welcome, {name}!" }
$t('welcome', { name: 'Ada' }) // 'Welcome, Ada!'
$t('missing.key', {}, 'Fallback') // 'Fallback'
```

En nyckel som pekar på ett nästlat objekt returnerar det objektet, inte en sträng. I en mall renderas det som `[object Object]`; använd en lövnyckel.

### `$ts` {#$ts}

```ts
TranslationFn<string>
```

Som `$t`, men returnerar alltid en sträng: värdet går genom `toString()`, så ett nästlat
objekt blir `'[object Object]'`. Låt nyckeln peka på ett löv.

### `$_t` {#$_t}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<CleanTranslation>
```

Binder `$t` till en specifik route, för att översätta utanför den aktuella sidan — till exempel en layout som renderar
en länk till en annan route.

```ts
const route = useRoute()
const t = useNuxtApp().$_t(route)
t('page.title')
```

### `$_ts` {#$_ts}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<string>
```

Binder `$ts` till en specifik route. Se `$_t`.

### `$tc` {#$tc}

```ts
(key: TranslationKey, params: number | Params, defaultValue?: string) => string
```

Översätter med pluralisering. `params` kan vara själva antalet, eller ett objekt som innehåller
`count`.

Formerna separeras med `|`. Med den inbyggda regeln väljer ett icke-negativt heltal `n` form `n`, begränsat till den sista formen; ett negativt antal, ett decimaltal eller `NaN` tar den sista formen. `{count}` och övriga params interpoleras i den valda formen.

För språk vars pluralformer inte följer antalet börjar du mallen med `=0 `. Den första formen gäller då 0, och de övriga följer kategorierna i [`Intl.PluralRules`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/PluralRules), i ordningen `zero, one, two, few, many, other`:

```json
{
  "apples": "=0 no apples | one apple | {count} apples",
  "files": "=0 no files | {count} one | {count} few | {count} many"
}
```

```ts
$tc('apples', 0) // 'no apples'
$tc('apples', 1) // 'one apple'
$tc('apples', 7) // '7 apples'

// In `uk` (categories `one, few, many, other`) the forms after the zero form follow those categories:
$tc('files', 21) // '21 one'
$tc('files', 22) // '22 few'
$tc('files', 25) // '25 many'
$tc('files', 2.5) // '2.5 many': no form for `other`, so the last one
```

- `=0 ` räknas bara allra först i värdet, med mellanslaget. `$t` visar det som text: det hör till pluralformerna.
- En kategori utan egen form tar den sista formen. Ett negativt antal eller ett decimaltal tar också den sista formen.
- Det fungerar i alla locales: `=0 none | one | {count} many` på engelska.
- Kategorin kommer från locales `iso`, annars dess kod. En kod som `Intl` inte känner till faller tillbaka på indexregeln, med markören ändå borttagen, så resultatet beror aldrig på maskinen.
- `<i18n-t :plural>` följer samma regel. En egen [`plural`](/sv/api/module-options#plural) eller `customPluralRule` får det råa värdet, markören inkluderad, och avgör själv; om `plural` returnerar `null` lämnas anropet tillbaka till den inbyggda regeln, som respekterar markören.

Utan markören stannar en mall på indexregeln, med ett undantag som bara kan läsas på ett sätt: en nollform utan platshållare, sedan en form per kategori, med `{count}` i varje form som flera antal delar på (`no files | {count} one | {count} few | {count} many` i `uk`).

För egna regler sätter du [`plural`](/sv/api/module-options#plural).

```ts
// { "apples": "no apples | one apple | {count} apples" }
$tc('apples', 0) // 'no apples'
$tc('apples', 10) // '10 apples'
$tc('cart', { count: 2, name: 'Ada' }) // count and params in one object
```

Det tredje argumentet är `defaultValue`, inte params.

### `$has` {#$has}

```ts
(key: string) => boolean
```

Om en nyckel kan lösas upp i den aktiva locale. Använd den för att förgrena på valfri text i stället för att
rendera en rå nyckel. Precis som `$t` ser den även den lämnade sidans nycklar under en sidövergång
inom samma locale.

```ts
if ($has('promo.banner')) show.value = true
```

## Formatering {#formatting}

### `$tn` {#$tn}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Formaterar ett tal med `Intl.NumberFormat` i den aktiva locale. En nyckel väljer ett namngivet format
från konfigurationen.

Namngivna format kommer från [`numberFormats`](/sv/api/module-options#numberformats).

```ts
$tn(1234.5, { style: 'currency', currency: 'EUR' }) // '1.234,50 €' in de
$tn(1000, 'currency') // named format
$tn(1000, 'currency', 'de') // named format in another locale
```

### `$td` {#$td}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Formaterar ett datum med `Intl.DateTimeFormat` i den aktiva locale. En nyckel väljer ett namngivet format
från konfigurationen.

Namngivna format kommer från [`datetimeFormats`](/sv/api/module-options#datetimeformats).

```ts
$td(new Date(), { dateStyle: 'long' })
$td(post.createdAt, 'short')
```

### `$tdr` {#$tdr}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

Formaterar ett datum som relativ tid ("för 3 dagar sedan") med `Intl.RelativeTimeFormat`.

```ts
$tdr(Date.now() - 5 * 60_000) // '5 minutes ago' in en
```

## Byte och länkar {#switching-and-links}

### `$switchLocale` {#$switchlocale}

```ts
(locale: string) => Promise<boolean>
```

Navigerar till den aktuella sidan i en annan locale. Under `no_prefix` och hash-läge laddar den
locales översättningar innan den navigerar; under `no_prefix` ersätts routen på plats (ingen
ny historikpost). En okänd locale ignoreras.
Anropet är asynkront: använd `await` för att köra kod efter navigeringen. Det löses med `true` när
locales ordbok är aktiv, `false` när den inte är det: chunken kunde inte laddas (den aktuella
ordboken ligger kvar; anropa igen för att försöka på nytt) eller ett nyare byte vann.

```ts
await $switchLocale('de')
```

### `$switchLocalePath` {#$switchlocalepath}

```ts
(locale: string) => string
```

Sökvägen till den aktuella sidan i en annan locale, utan att navigera.

```vue
<NuxtLink :to="$switchLocalePath('de')">Deutsch</NuxtLink>
```

### `$switchLocaleRoute` {#$switchlocaleroute}

```ts
(locale: string) => RouteLocationRaw
```

Route-objektet för den aktuella sidan i en annan locale, utan att navigera, eller en URL-sträng
för en locale på en egen `baseUrl`. Under `trailingSlash` har objektet `path` och `fullPath`
enligt regeln, med `query` och `hash` som de är, och `router.push` eller en länk behåller dem.

### `$switchRoute` {#$switchroute}

```ts
(route: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, toLocale?: string) => Promise<void>
```

Navigerar till en annan route och behåller den aktiva locale eller byter till `toLocale`. Asynkron precis som
`$switchLocale`.

```ts
$switchRoute('/about') // active locale
$switchRoute({ name: 'about' }, 'de') // switch to de
```

### `$localePath` {#$localepath}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => string
```

Löser upp en sökväg i den angivna locale, eller i den aktiva. En sträng med schemat `http(s):`, `mailto:`
eller `tel:` returneras som den är: skicka inte okontrollerad användarinmatning som länkmål.

En strängsökväg tolkas som den sida den visar, så en locales egen sökväg tillämpas också.

```ts
$localePath('/about') // '/about' in en, '/de/ueber-uns' in de with localeRoutes
$localePath({ name: 'about' }, 'fr') // '/fr/about'
```

### `$localeRoute` {#$localeroute}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => RouteLocationResolved
```

Löser upp en route i den angivna locale, eller i den aktiva. Ett vanligt objekt som är säkert att spara i tillstånd. När en param behöver
escapas har det `path`, `fullPath`, `query` och `hash` men inget `name` eller `params`: det är sökvägen som ger routern
den kodade URL:en. För en locale på en annan domän är `path` och `fullPath` absoluta, vilket routern inte kan ta emot:
en sådan länk går via `<i18n-link>`, eller `$localePath`.

### `$getRouteName` {#$getroutename}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric, locale?: string) => string
```

Route-namnet utan locale-prefix — namnet som översättningarna är nycklade efter.

```ts
$getRouteName() // 'about' on /de/about
```

## Sidkonfiguration {#page-config}

### `$defineI18nRoute` {#$definei18nroute}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Registrerar locale-konfiguration och översättningar per sida inifrån en komponent.
Slås ihop med den aktiva locale och tillämpas på nytt när locale ändras.

Anropa den i en sidas `<script setup>`, alltid destrukturerad från `useNuxtApp()`. Bygget läser `locales`, `localeRoutes` och `disableMeta` från anropet; vid körning spelar bara `locales` roll (inline-översättningar slås ihop för den aktiva locale). Fullständiga regler: [Sidkonfiguration](/sv/guide/per-component-translations).

```vue
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'de'],
  localeRoutes: { en: '/about', de: '/ueber-uns' },
})
</script>
```

### `$setI18nRouteParams` {#$seti18nrouteparams}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Sätter params per locale för den aktuella routen, så att ett dynamiskt segment kan skilja sig mellan språk.
Anropa den under SSR, innan head renderas.

Params rensas när en navigering till en annan sökväg genomförs, inklusive `/news/1` till `/news/4`, som behåller route-namnet. Detaljer: [Lokaliserade sökvägar](/sv/guide/custom-locale-routes).

```ts
$setI18nRouteParams({
  en: { slug: 'my-post' },
  de: { slug: 'mein-beitrag' },
})
```

## Översättningar vid körning {#runtime-translations}

### `$mergeTranslations` {#$mergetranslations}

```ts
(newTranslations: Translations) => void
```

Slår ihop översättningar med den aktiva locale vid körning och åsidosätter det som är laddat.

Djupsammanslår med den aktiva locales aktuella sid-chunk; nycklar som den inte nämner finns kvar.

```ts
$mergeTranslations({ banner: { title: 'Sale' } })
```

### `$setTranslation` {#$settranslation}

```ts
(key: string, value: unknown) => void
```

Ersätter värdet vid `key` i den aktiva ordboken. Detta är en ersättning, inte en sammanslagning —
använd `$mergeTranslations` när befintliga syskon ska finnas kvar.

```ts
$setTranslation('banner', { title: 'Sale' }) // drops other keys under banner
$setTranslation('banner.title', 'Sale') // dotted path
```

### `$loadPageTranslations` {#$loadpagetranslations}

```ts
(locale: string, routeName: string, translations: Translations) => Promise<void>
```

Laddar översättningar för en sida vid körning, för innehåll vars nycklar inte är kända vid byggtiden.

Slås ihop med chunken `(locale, routeName)` i minnet, och skärmen uppdateras när den chunken är aktiv. Ingen payload hämtas här: för en sida som ännu inte har laddats väntar översättningarna, och när dess fil laddas ligger de kvar ovanpå den.

```ts
await $loadPageTranslations('en', 'about', { title: 'About us' })
```

### `$resolveTranslations` {#$resolvetranslations}

```ts
() => Translations
```

Varje översättning som just nu finns i minnet för den aktiva locale och routen, som ett träd.
En skrivskyddad vy av vad `$t()` kan lösa upp just nu.

Behandla resultatet som skrivskyddat.

### `$setMissingHandler` {#$setmissinghandler}

```ts
(handler: MissingHandler | null) => void
```

Installerar en callback som anropas för varje nyckel som inte kan lösas upp. Skicka `null` för att ta bort den.

Hanteraren körs i stället för utvecklingsvarningen.

```ts
$setMissingHandler((locale, key, routeName) => {
  console.error(`[i18n] missing ${key} in ${locale} (${routeName})`)
})
```

### `$clearCache` {#$clearcache}

```ts
() => void
```

Släpper varje cachad översättnings-chunk och laddar om den aktuella sidans ordbok. Sidan
fortsätter att visa sina aktuella översättningar tills de nya anländer. HMR i utvecklingsläge anropar den vid
varje ändring i en översättningsfil.

```ts
const { clearCache } = useI18n()
clearCache()
```

En misslyckad omladdning behåller den aktuella ordboken.
