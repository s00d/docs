# useI18nLocale

## Signatur

{/* generated:symbol:useI18nLocale — do not edit; run `pnpm run docs:generate` */}

```ts
useI18nLocale(): { getEffectiveLocale: (route: unknown, getLocaleFromRoute: GetLocaleFromRoute) => string; getLocale: () => string | null; getLocaleWithServerFallback: (serverLocale?: string | null) => string | null; getPreferredLocale: () => string | null; hashCookie: any; isValidLocale: (locale: string | null | undefined) => locale is string; locale: any; localeCookie: any; resolveInitialLocale: (options: ResolveInitialLocaleOptions) => string; setLocale: (locale: string | null) => void; syncLocale: (locale: string | null) => void; validLocales: string[] }
```

Centraliserad ingångspunkt för i18n-lokalhantering. Kombinerar useState('i18n-locale'), lokal-cookie och synkroniseringsverktyg.

{/* /generated:symbol:useI18nLocale */}

## Användning

```vue
<script setup>
const {
  locale,
  localeCookie,
  hashCookie,
  validLocales,
  getPreferredLocale,
  getLocale,
  getLocaleWithServerFallback,
  getEffectiveLocale,
  resolveInitialLocale,
  setLocale,
  syncLocale,
  isValidLocale,
} = useI18nLocale()

// Set locale (updates state and cookies)
setLocale('de')

// Get current locale (state → cookie)
const current = getLocale()

// Get valid preferred locale
const preferred = getPreferredLocale()
</script>
```

## API

| Egenskap/Metod                                  | Typ                                 | Beskrivning                                                                              |
| ----------------------------------------------- | ----------------------------------- | ---------------------------------------------------------------------------------------- |
| `locale`                                        | `Ref<string \| null>`               | Reaktivt lokal-state (`useState('i18n-locale')`)                                         |
| `localeCookie`                                  | `Ref`                               | Lokal-cookie (när alternativet `localeCookie` är aktiverat)                              |
| `hashCookie`                                    | `Ref`                               | Cookie som används när `hashMode` är aktivt                                              |
| `validLocales`                                  | `string[]`                          | Aktiverade lokalkoder från modulkonfigurationen (exkluderar `disabled`)                  |
| `getLocale()`                                   | `() => string \| null`              | Aktuell lokal: state → cookie (eller hash-cookie i hash-läge)                            |
| `getPreferredLocale()`                          | `() => string \| null`              | Lokal från state/cookie **validerad** mot `validLocales`, eller `null`                   |
| `getLocaleWithServerFallback(serverLocale?)`    | `(serverLocale?) => string \| null` | State → cookie → valfri serverkontext (används under init för `no_prefix`)               |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string`             | Lokal för laddning av översättningar: hash-läge föredrar state; annars läses från rutten |
| `resolveInitialLocale(options)`                 | `(options) => string`               | Resolvar lokal: state → `serverLocale` → rutt; synkar state vid behov                    |
| `setLocale(locale)`                             | `(locale: string \| null) => void`  | Sätt lokal och synka till cookies                                                        |
| `syncLocale(locale)`                            | `(locale: string \| null) => void`  | Synka endast cookies (ingen state-uppdatering)                                           |
| `isValidLocale(locale)`                         | `(locale) => boolean`               | Kontrollera om strängen finns i `validLocales`                                           |

### Alternativ för `resolveInitialLocale`

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

Används internt av huvudpluginen vid uppstart. Anpassade plugins kan anropa den när alternativa detekteringsflöden implementeras.

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

Returnerar lokalen som används för att ladda översättningar och formatera meddelanden för ett givet ruttobjekt.

## Programmatisk lokalsättning

Föredra `useI18nLocale()` framför direkt användning av `useState('i18n-locale')`:

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
`setLocale()` uppdaterar endast lokalpreferens (state + cookie). För att också ladda om den aktiva översättningskontexten på klienten, använd `$switchLocale()` från `useNuxtApp()` eller `useI18n()`. Detta spelar särskild roll för `no_prefix`, där URL:en inte ändras. Se [FAQ — byta lokal utan att ändra URL:en](/guides/faq#-switch-locale-without-changing-the-url).
</Tip>
