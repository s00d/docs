# 🛠️ Composablen `useI18n`

Composablen `useI18n` i `Nuxt I18n Micro` ger åtkomst till de flesta runtime-i18n-hjälparna i komponenter och skript. Metoder är tillgängliga **både med och utan `$`-prefix** (till exempel `$t` och `t`).

Vissa injektioner — `$defineI18nRoute` och `$clearCache` — är endast tillgängliga via `useNuxtApp()`. Se [Metoder — `$defineI18nRoute`](/api/methods#definei18nroute) och [`$clearCache`](/api/methods#clearcache).

## 📊 Vad den returnerar

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Varje runtime-hjälpare, som ett vanligt objekt.

Samma funktioner som pluginen injicerar som `$t`, `$tc` och så vidare, tillgängliga både under det dollar-prefixade namnet och ett naket alias — så `const \{ t \} = useI18n()` och `const \{ $t \} = useI18n()` fungerar båda.

**Returnerar** — hjälparna som beskrivs i [metodreferensen](/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

Varje hjälpare den returnerar — `$t`, `$tc`, `$has`, `$switchLocale` och övriga — är listad med sin signatur och dokumenteras i sin helhet i [metodreferensen](/api/methods).

## API:er endast via `useNuxtApp()`

Dessa returneras **inte** av `useI18n()`. Importera dem från `useNuxtApp()`:

| Metod                      | Syfte                                                                          |
| -------------------------- | ------------------------------------------------------------------------------ |
| `$defineI18nRoute(config)` | Lokalrutter per sida, begränsningar och inline-översättningar i `script setup` |
| `$clearCache()`            | Rensar in-memory-översättningscache och laddade chunks                         |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Se [Metoder](/api/methods) för fullständiga signaturer och exempel.

## 🛠️ Exempelanvändning

### Grundläggande lokalhämtning

Hämta applikationens aktuella lokal.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Översättning med parametrar

Översätt en sträng med dynamiska parametrar och ett fallback-standardvärde.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Byta lokal

Byt applikationen till en annan lokal.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Generera en lokaliserad rutt

Generera en rutt lokaliserad till aktuell eller angiven lokal.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
