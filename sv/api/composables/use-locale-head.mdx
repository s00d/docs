# 🌍 Composablen `useLocaleHead`

Composablen `useLocaleHead` är ett verktyg i `Nuxt I18n Micro` som hjälper dig att hantera SEO-attribut och HTML-metataggar för lokaliserade rutter. Den genererar dynamiskt attribut för `lang` och `dir` på HTML-dokumentet och skapar `meta`- och `link`-taggar för att förbättra SEO på ditt lokaliserade innehåll.

SEO-head-taggarna för aktuell rutt: `hreflang`-alternativ för varje lokal plus `x-default`, en canonical-länk, `og:locale` samt `lang`/`dir` på `<html>`.

Behövs endast när `meta` är inaktiverat eller standardvärdena behöver justeras — med `meta: true` registrerar modulen samma taggar själv.

## 🛠️ Returvärden

Composablen `useLocaleHead` returnerar ett reaktivt objekt och en uppdateringsfunktion som du bör anropa när källdata ändras. Båda formerna finns i signaturen ovan, genererad från källkoden.

### `metaObject`

Reaktiv head-payload (html-attribut, meta, link) lämplig för `useHead(metaObject)`.

- **Exempel**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

Räknar om `metaObject` baserat på aktuell rutt, lokal och konfiguration. Anropa det när indata ändras — till exempel vid en ruttändring.

- **Exempel**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### Åtkomst till `link` och `meta`

Arrayerna `link` och `meta` är tillgängliga via `metaObject.value`:

- **Exempel**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ Exempelanvändning

### Grundläggande användning

Generera lokalspecifika head-attribut med standardalternativen.

```js
const head = useLocaleHead()
```

### Anpassa identifierarattribut

Använd ett anpassat identifierarattribut för de genererade taggarna.

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### Inaktivera SEO-attribut

Generera head-attribut utan att lägga till SEO-relaterade meta- och länktaggar.

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### Ange en bas-URL

Sätt en anpassad bas-URL för canonical- och alternativa URL:er.

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 Ytterligare funktioner

### SEO-meta och länktaggar

När `addSeoAttributes` är aktiverat genererar composablen automatiskt följande taggar:

- `og:locale` för aktuell lokal (`language_TERRITORY`, understreck). Härledd från `locale.og` eller konverterad från `locale.iso` när det är möjligt.
- `og:url` för sidans canonical-URL.
- `og:locale:alternate` för alternativa språkversioner.
- `rel="canonical"`- och `rel="alternate"`-länkar för SEO-optimering.
- `hreflang="x-default"`-länk som pekar på standardlokalens URL. Detta talar om för sökmotorer vilken URL som ska visas för användare vars språk inte matchar någon av de definierade lokalerna.

### Dynamisk lokal och riktning

Composablen bestämmer dynamiskt `lang`- och `dir`-attributen baserat på aktuell rutts lokal och säkerställer att ditt HTML-dokument är korrekt konfigurerat för internationella användare.

### Hantering av lokaliserade rutter

Om dina rutter är prefixerade med lokalkoder (till exempel `/en/about`) justerar composablen intelligent den fullständiga sökvägen för att generera URL:er och säkerställer att SEO-attributen är korrekta och relevanta.

Denna composable förenklar processen att optimera din Nuxt-applikation för internationella målgrupper och säkerställer att din webbplats är väl förberedd för globala sökmotorer och användare.

## 🛠️ Exempelanvändning

Följande exempel visar hur du använder composablen `useLocaleHead` inuti en Vue-komponent med standardinställningar:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### Förklaring av koden

- **Composablen `useLocaleHead`**: Denna composable anropas i `<script setup>`-sektionen och returnerar ett objekt som innehåller `htmlAttrs`, `meta` och `link`.

- **`<html>`-tagg**: Attributen `lang` och `dir` för HTML-dokumentet bestäms dynamiskt baserat på aktuell lokal och tillämpas på `<html>`-taggen.

- **`<head>`-sektion**:
  - **Metataggar**: SEO-relaterade metataggar genereras, inklusive `og:locale`, `og:url` samt `rel="canonical"`- och `rel="alternate"`-taggar för att ange alternativa språkversioner av sidan.
  - **Länktaggar**: Canonical-länkar, länkar till alternativa språkversioner och `hreflang="x-default"`-länken (som pekar på standardlokalens URL) inkluderas.

- **`<body>`-sektion**: Sidans huvudsakliga innehåll visas här. I detta exempel används en enkel rubrik och paragraf.

### 📝 Anmärkningar

1. **Attribut**: Attributen som används (`lang`, `dir`, `rel`, `href`, `hreflang`, `property`, `content`) extraheras från objektet som returneras av `useLocaleHead`.

2. **Generering av SEO-taggar**: Om alternativet `addSeoAttributes` är satt till `true` genererar composablen automatiskt SEO-taggar för aktuell lokal.

3. **Bas-URL**: Du kan sätta din anpassade bas-URL med alternativet `baseUrl` för att korrekt generera canonical- och alternativa länkar.

Detta exempel visar hur enkelt det är att integrera `useLocaleHead` i din applikations komponenter för att säkerställa korrekta SEO-attribut och förbättra sökmotorernas indexering av lokaliserade sidor.

## 🧩 Anpassning och livscykel

- `useLocaleHead` prenumererar inte på ändringar av sig själv. Den returnerar `metaObject` och `updateMeta`.
- Du bör anropa `updateMeta()` när indata ändras (vanligtvis vid ruttändring), till exempel från ett plugin:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## När du ska använda `useI18nHead` i stället

När `meta: true` (standard), föredra [`useI18nHead`](/api/composables/use-i18n-head) för **per-sida**-överskrivningar (anpassad hreflang, extra `og:title`, partiell inaktivering). Använd `useLocaleHead` direkt endast när `meta: false` eller när du hanterar `useHead` själv.
