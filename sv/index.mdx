Nuxt I18n Micro är en lätt i18n-modul med hög prestanda för Nuxt 3 och 4, utformad för stora projekt. Den håller byggtider, minnesanvändning och paketstorlek låga jämfört med traditionella i18n-lösningar som `@nuxtjs/i18n`.

Lokaliserade routes genereras vid byggtid av `@i18n-micro/route-strategy` och löses vid runtime av `@i18n-micro/path-strategy`, så länkar, språkväljaren, `hreflang` och omdirigeringar stämmer alltid överens med routern. Översättningar är endast JSON, uppdelade mellan delade rotfiler och filer per sida som utvecklingsservern skapar åt dig, med inbyggd HMR.

<CodeGroup>

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>
