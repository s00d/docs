# Runtime-överskrivningar för i18n

Använd denna guide när du behöver att en byggartefakt körs med olika standard-locales per miljö (till exempel: olika tenant-instanser).

## Vad som kan överskrivas vid runtime

Modulen stöder säkra runtime-överskrivningar för:

- `defaultLocale`
- `fallbackLocale`
- `disabledLocales`

Dessa överskrivningar tillämpas ovanpå byggtidskonfigurationen från `.nuxt/i18n.strategy.mjs` och `.nuxt/i18n.config.mjs`.

## Vad som inte kan överskrivas vid runtime

`strategy` (`no_prefix`, `prefix`, `prefix_except_default`, `prefix_and_default`) är en byggtidsfråga eftersom den påverkar beteendet hos genererade rutter.

Om du skickar en runtime-överskrivning av strategi ignoreras den och en varning skickas.

## Överskrivningar baserade på RuntimeConfig

Ange runtime-värden under `runtimeConfig.public.i18nRuntime`:

```ts
export default defineNuxtConfig({
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

## Överskrivningar via miljövariabler

Du kan även konfigurera överskrivningar via miljövariabler:

- `NUXT_I18N_DEFAULT_LOCALE`
- `NUXT_I18N_FALLBACK_LOCALE`
- `NUXT_I18N_DISABLED_LOCALES` (kommaseparerad, t.ex. `fr,it`)

Fallback-alias stöds också:

- `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES`

## Valideringsregler

Vid runtime validerar modulen överskrivningarna för att undvika trasiga tillstånd:

- Du kan inte inaktivera alla locales.
- `defaultLocale` måste peka på en aktiverad locale.
- `fallbackLocale` måste finnas i deklarerade locales.

Om en överskrivning är ogiltig behåller modulen ett säkert värde och loggar en varning.

## Anmärkningar för distributioner med flera instanser

Denna runtime-funktion är utformad för aktivering av locales per instans och standardvärden utan ombyggnad.

Om instanser kräver olika URL-strategier (`no_prefix` vs `prefix`), använd separata byggen för varje strategi.

## Inaktiverade locales och statiska payloads

`runtimeConfig.public.i18nRuntime.disabledLocales` uppdaterar routing, switcher och Nitro-payload-**hanteraren** — men Nitro serverar filer under `public/` **innan** den hanteraren.

Om `translationPayloads.publicAssets` (eller Node SSR:s framtvingade publika kopia) redan har skrivit `/_locales/\{page\}/\{locale\}/data.json`, kan en runtime-inaktivering inte dölja den filen. Föredra `locale.disabled: true` vid bygge så att premerge inte skickar ut den localens statiska payloads.
