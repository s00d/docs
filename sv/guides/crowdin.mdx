# 🌐 Guide för Crowdin-integration

## 📖 Introduktion

Att integrera Crowdin i ditt projekt effektiviserar lokaliserings- och översättningsprocessen och gör det enklare att hantera översättningar över flera språk och plattformar. Denna guide ger en steg-för-steg-genomgång av hur du konfigurerar Crowdin med ditt projekt, inklusive konfiguration, uppladdning av källor och nedladdning av översättningar.

## 🔧 Installation och konfiguration

För att komma igång med Crowdin behöver du installera Crowdin CLI globalt på din maskin och initiera det i din projektkatalog.

### 📦 Installera Crowdin CLI

Installera först Crowdin CLI globalt med npm:

```bash
npm install -g @crowdin/cli
```

### 🛠 Initiera Crowdin i ditt projekt

Initiera Crowdin i ditt projekt genom att köra:

```bash
crowdin init
```

Detta kommando guidar dig genom installationsprocessen, inklusive att ställa in ditt projekt-ID, API-token och andra konfigurationsdetaljer.

## 🗂️ Konfigurationsguide

### 📄 Crowdin-konfigurationsfil (`crowdin.yml`)

Crowdin-konfigurationsfilen (`crowdin.yml`) definierar hur dina källfiler mappas och var översättningar ska placeras. Nedan är ett exempel på konfiguration:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Viktiga konfigurationsparametrar

- **`project_id`**: Ditt Crowdin-projekt-ID. Detta identifierar projektet inom Crowdin där översättningar hanteras.
- **`api_token`**: API-tokenen som används för autentisering. Se till att denna token har rätt behörigheter för att ladda upp och ladda ner översättningar.
- **`base_path`**: Anger baskatalogen för källfiler. I det här exemplet lagras översättningar i katalogen `./locales`.
- **`base_url`**: Bas-URL för Crowdin-API:et.
- **`preserve_hierarchy`**: När den är inställd på `true` bibehåller Crowdin mappstrukturen för dina källfiler i projektet.

### 📂 Filkonfiguration

Sektionen `files` mappar dina källfiler till de sökvägar där översättningar kommer att lagras. Till exempel:

- **Källsökväg**: Definierar platsen för de ursprungliga översättningsfilerna.
- **Översättningssökväg**: Anger var de översatta filerna kommer att lagras i Crowdin. Platshållare som `%two_letters_code%` används för att dynamiskt ange språkkoden i filsökvägarna.

## ⬆️ Ladda upp källfiler till Crowdin

När din Crowdin-konfiguration är inställd kan du ladda upp dina källfiler med följande kommando:

```bash
crowdin upload sources
```

Detta kommando laddar upp alla angivna källfiler i din konfiguration till Crowdin och gör dem tillgängliga för översättning.

## ⬇️ Ladda ner översättningar från Crowdin

När översättningar är slutförda eller uppdaterade i Crowdin kan du ladda ner dem till ditt projekt med:

```bash
crowdin download
```

Detta kommando hämtar de senaste översättningarna från Crowdin och sparar dem enligt sökvägarna som anges i din konfigurationsfil.

## ⚙️ Bästa praxis

### 🔑 Konsekvent namngivning av nycklar

Se till att översättningsnycklar är konsekventa mellan alla filer för att undvika förvirring och duplicering.

### 🧹 Regelbundet underhåll

Granska och städa periodiskt bort oanvända översättningsnycklar för att hålla dina filer organiserade och hanterbara.

### 🛠 Automatisera uppladdningar och nedladdningar

Integrera Crowdin CLI-kommandon i din CI/CD-pipeline för att automatisera uppladdning av källfiler och nedladdning av översättningar, vilket säkerställer att dina översättningar alltid är aktuella.

Genom att följa denna guide kan du sömlöst integrera Crowdin i ditt projekt och säkerställa en effektiv och organiserad metod för att hantera dina internationaliseringsinsatser.
