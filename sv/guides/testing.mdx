# 🧪 Testa modulen `Nuxt I18n Micro`

## 📖 Introduktion till testning

Att testa `Nuxt I18n Micro`-modulen är avgörande för att säkerställa att din applikations lokaliseringsfunktioner fungerar som förväntat. Denna dokumentation guidar dig genom att sätta upp testmiljön, skapa mock-konfigurationer för Vitest och skriva tester för dina komponenter. För ett praktiskt exempel kan du se [exempelprojektet på GitHub](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/test-utils/example).

Se [Testa routingstrategier](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/testing-strategies.md) för hur detta arkiv kör sina egna sviter — Vitest-projekten `unit` / `integration` / `e2e`, filerna per strategi (`test/strategies-*.test.ts`) och regressionsgenerering.

## 🛠️ Sätta upp testmiljön

### 1. Installera `@i18n-micro/test-utils`

Först behöver du installera testverktygen för `Nuxt I18n Micro`. Detta paket tillhandahåller de nödvändiga verktygen för att mocka och testa dina i18n-konfigurationer.

```bash
npm install @i18n-micro/test-utils --save-dev
```

### 2. Skapa en mock-konfigurationsfil

Skapa sedan en fil för att sätta upp mock-i18n-konfigurationen. Denna fil används för att mocka i18n-funktioner och verktyg under dina tester.

```typescript
// tests/unit-setup.ts

import { mockNuxtImport } from '@nuxt/test-utils/runtime'
import { vi } from 'vitest'
import { i18nUtils } from '@i18n-micro/test-utils'

export function createFakeI18n() {
  return {
    $getLocale: vi.fn(i18nUtils.getLocale),
    $t: vi.fn(i18nUtils.t),
    $tc: vi.fn(i18nUtils.tc),
    $setLocale: vi.fn(i18nUtils.setLocale),
    $getLocaleName: vi.fn(i18nUtils.getLocaleName),
    $setLocaleName: vi.fn(i18nUtils.setLocaleName),
    $getLocales: vi.fn(i18nUtils.getLocales),
    $setLocales: vi.fn(i18nUtils.setLocales),
    $defaultLocale: vi.fn(i18nUtils.defaultLocale),
    $setDefaultLocale: vi.fn(i18nUtils.setDefaultLocale),
    $getRouteName: vi.fn(i18nUtils.getRouteName),
    $settRouteName: vi.fn(i18nUtils.settRouteName),
    $ts: vi.fn(i18nUtils.ts),
    $tn: vi.fn(i18nUtils.tn),
    $td: vi.fn(i18nUtils.td),
    $has: vi.fn(i18nUtils.has),
    $resolveTranslations: vi.fn(i18nUtils.resolveTranslations),
    $setTranslation: vi.fn(i18nUtils.setTranslation),
    $mergeTranslations: vi.fn(i18nUtils.mergeTranslations),
    $switchLocaleRoute: vi.fn(i18nUtils.switchLocaleRoute),
    $switchLocalePath: vi.fn(i18nUtils.switchLocalePath),
    $switchLocale: vi.fn(i18nUtils.switchLocale),
    $switchRoute: vi.fn(i18nUtils.switchRoute),
    $localeRoute: vi.fn(i18nUtils.localeRoute),
    $localePath: vi.fn(i18nUtils.localePath),
    $setI18nRouteParams: vi.fn(i18nUtils.setI18nRouteParams),
  }
}

mockNuxtImport<() => ReturnType<typeof createFakeI18n>>('useI18n', () => vi.fn(() => createFakeI18n()))

export const setTranslationsFromJson = i18nUtils.setTranslationsFromJson
```

### 3. Konfigurera Vitest

Konfigurera nu Vitest till att använda mock-konfigurationsfilen och sätta upp testmiljön.

```typescript
// vitest.config.ts

import { defineVitestConfig } from '@nuxt/test-utils/config'

export default defineVitestConfig({
  test: {
    watch: false,
    setupFiles: ['./tests/unit-setup.ts'],
    include: ['./**/*.spec.ts'],
  },
})
```

## 🧪 Skriva tester

### Exempelkomponent

Här är ett exempel på en enkel komponent som använder composablen `useI18n` för att översätta meddelanden.

```vue
<script setup lang="ts">
const { $t } = useI18n()

const props = defineProps({
  message: {
    type: String,
    default: null,
  },
})

// Test to see that $t works in script setup as well as the template
const message = props.message || $t('defaultMessage')
</script>

<template>
  <div>
    <p>Test from component: {{ $t('welcome') }}</p>
    <p data-testid="message">Test message from props: {{ message }}</p>
  </div>
</template>
```

### Testfil

Låt oss nu skriva ett test för denna komponent.

```typescript
// tests/unit/example.spec.ts

import { describe, it, expect, beforeEach } from 'vitest'
import { mount } from '@vue/test-utils'
import ExampleComponent from '@/components/ExampleComponent.vue'
import fs from 'fs'
import path from 'path'
import { setTranslationsFromJson } from './unit-setup'

describe('ExampleComponent', () => {
  beforeEach(async () => {
    const fileContent = fs.readFileSync(path.join(__dirname, '../../locales/en-GB.json')).toString()
    await setTranslationsFromJson('en', JSON.parse(fileContent))
  })

  it('renders the welcome message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.text()).toContain('Test from component: Welcome')
  })

  it('renders the default message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Default Message')
  })

  it('renders the custom message correctly', () => {
    const wrapper = mount(ExampleComponent, {
      props: {
        message: 'Custom Message',
      },
    })
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Custom Message')
  })
})
```

## 📝 Bästa praxis för testning

- **🔧 Mocka i18n-funktioner:** Mocka alltid i18n-funktioner med `@i18n-micro/test-utils` för att säkerställa konsekventa och förutsägbara testresultat.
- **⚙️ Använd Vitest för enhetstester:** Vitest är ett kraftfullt testramverk för Vue-applikationer. Använd det för att skriva enhetstester för dina komponenter.
- **📚 Dokumentera dina tester:** Dokumentera tydligt syftet och förväntade utfall för varje test. Detta hjälper till att bibehålla tydlighet och gör det enklare för andra (eller ditt framtida jag) att förstå testerna.

## 📊 Verktygsmetoder för i18n

Nedan är en tabell som beskriver alla verktygsmetoder som `@i18n-micro/test-utils` tillhandahåller.

| Metod                                           | Beskrivning                                                                                                                                |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `t(key, params, defaultValue)`                  | Översätter en nyckel med valfria parametrar och ett standardvärde.                                                                         |
| `tc(key, params, defaultValue)`                 | Översätter en nyckel med stöd för pluralisering.                                                                                           |
| `setTranslationsFromJson(locale, translations)` | Laddar översättningar från ett JSON-objekt för en specifik lokal.                                                                          |
| `getLocale()`                                   | Returnerar aktuell lokal.                                                                                                                  |
| `setLocale(val)`                                | Sätter aktuell lokal.                                                                                                                      |
| `getLocaleName()`                               | Returnerar aktuellt lokalnamn.                                                                                                             |
| `setLocaleName(val)`                            | Sätter aktuellt lokalnamn.                                                                                                                 |
| `getLocales()`                                  | Returnerar listan över tillgängliga lokaler.                                                                                               |
| `setLocales(val)`                               | Sätter listan över tillgängliga lokaler.                                                                                                   |
| `defaultLocale()`                               | Returnerar standardlokalen.                                                                                                                |
| `setDefaultLocale(val)`                         | Sätter standardlokalen.                                                                                                                    |
| `getRouteName()`                                | Returnerar aktuellt ruttnamn.                                                                                                              |
| `settRouteName(val)`                            | Sätter aktuellt ruttnamn.                                                                                                                  |
| `ts(key, params, defaultValue)`                 | Översätter en nyckel och returnerar resultatet som en sträng.                                                                              |
| `tn(value, options?)`                           | Formaterar ett tal med inline-`Intl.NumberFormatOptions`. Namngivna format kräver modulkonfiguration och är inte tillgängliga i denna fristående hjälpare. |
| `td(value, options?)`                           | Formaterar ett datum med inline-`Intl.DateTimeFormatOptions`. Namngivna format kräver modulkonfiguration och är inte tillgängliga i denna fristående hjälpare. |
| `has(key)`                                      | Kontrollerar om en översättningsnyckel finns.                                                                                              |
| `resolveTranslations()`                         | Returnerar det aktiva översättningsträdet för aktuell lokal och rutt.                                                                      |
| `setTranslation(key, value)`                    | Ersätter värdet vid `key` i den aktiva ordboken (ersättning, inte sammanslagning).                                                         |
| `mergeTranslations(newTranslations)`            | Slår samman översättningar in i den aktiva lokalen vid runtime.                                                                            |

Genom att följa dessa steg kan du effektivt testa `Nuxt I18n Micro`-modulen och säkerställa att din applikations lokaliseringsfunktioner fungerar som förväntat.
