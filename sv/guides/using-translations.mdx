# Använda översättningar i komponenter

När modulen är installerad och konfigurerad kan du visa översättningar genom att anropa `$t('your_key')` i dina Vue-mallar och skript.

## 1. Rotnivå- och sidspecifika översättningsfiler

1. **Rotnivåöversättningar** finns direkt under mappen `/locales` (t.ex. `/locales/en.json`, `/locales/fr.json`). Vid byggtid slås de automatiskt samman i varje sidspecifik fil, vilket gör dem tillgängliga på alla sidor.
2. **Sidspecifika översättningar** finns under `/locales/pages/...` och matchar strukturen på din Nuxt-sidmapp:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. Malanvändning med `$t`

I dina `.vue`-filer kan du använda `$t` direkt i mallen:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
`$t` kan returnera **objekt** om nyckeln pekar på en kapslad JSON-nod (t.ex. `$t('header')` → `\{ title: "Hi" \}`). I mallar renderas detta som `[object Object]`. Använd `$ts` när du behöver en garanterad sträng, eller ange en mer specifik nyckel som `$t('header.title')`. Se [API-referens — $t vs $ts](/api/methods#t) för detaljer.
</Tip>

## 3. Byta aktuell locale

För att ändra språk i din app kan du hämta `$locale` från `useI18n()` och tilldela den en ny kod:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. Kapslade nycklar och platshållare

- **Kapslade nycklar** använder punktnotation, t.ex. `nested.key.deeper`.
- **Platshållare** låter dig infoga dynamiska värden:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. Tips och bästa praxis

- **Konflikterande nycklar**: Om en sidspecifik fil innehåller samma nyckel som en rotnivåfil har den sidspecifika versionen prioritet (rotöversättningar slås samman som bas vid byggtid).
- **Inaktivera sidfiler**: Om du hellre inte vill använda sidspecifika översättningar kan du ställa in `disablePageLocales: true` i din Nuxt-konfiguration. På så sätt används endast filerna `/locales/*.json`.
- **Inga direkta importer**: Du behöver inte göra `import \{ useI18n \} from 'nuxt-i18n-micro'`; modulens auto-injektionsfunktion hanterar det åt dig.

Det är allt! Med dessa steg kan du snabbt **börja hämta översättningar** från JSON-filer på rotnivå eller sidspecifika filer och **visa dem** i din Nuxt-applikation med `$t`.

## Ytterligare resurser

För att utforska fler avancerade funktioner, var noga med att kolla in:

1. **Komponenten `<i18n-t>`**  
   Komponenten `<i18n-t>` är ett kraftfullt alternativ till `$t`, särskilt användbart i situationer som involverar kapslade element, avancerad platshållaranvändning och mer komplexa översättningsstrukturer.

- **Dokumentation**: [i18n-t](/api/components/i18n-t)

2. **Composable `useI18n`**  
   Composable `useI18n` erbjuder en komplett uppsättning funktioner och reaktiva egenskaper för att hantera översättningar, hantera locale-byten, formatering med mera.

- **Dokumentation**: [useI18n](/api/composables/use-i18n)
