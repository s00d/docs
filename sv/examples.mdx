# 📚 Exempel och användning av Nuxt I18n Micro

Detta avsnitt ger olika exempel som visar hur du använder `Nuxt I18n Micro` i din Nuxt.js-applikation. Du får se hur du byter locale, använder komponenterna `<i18n-link>`, `<i18n-switcher>` och `<i18n-t>` samt hanterar översättningsnycklar dynamiskt.

## 🛠️ Grundläggande installation

Här är en grundläggande installation för att komma igång med `Nuxt I18n Micro`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Locale-byte

### Byta locale programmatiskt

Detta exempel visar hur du byter locale programmatiskt med knappar:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Exempel-JSON för locale-byte

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### Använda komponenten `<i18n-switcher>`

Komponenten `<i18n-switcher>` tillhandahåller en rullgardinsmeny för locale-byte med anpassningsbara etiketter:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 📝 Rendera dynamiska nycklar från översättningsfiler

I vissa scenarier kan du vilja iterera över dynamiska nycklar som lagras i dina översättningsfiler och rendera deras värden villkorligt. Exemplet nedan visar hur du åstadkommer detta med `Nuxt I18n Micro`.

### Exempel: Rendera dynamiska nycklar

Detta exempel hämtar en array av nycklar från en specifik översättningsväg (i det här fallet `dynamic`) och itererar över dem. Varje nyckel kontrolleras för existens med `$has` innan dess värde renderas med `$t`.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Exempel på översättningsfil (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Exempel: Rendera dynamiska nycklar från ett objekt

I det här exemplet hanterar vi ett objekt lagrat i din översättningsfil. Vi hämtar och itererar över objektets nycklar och renderar dynamiskt både nyckelnamnen och deras tillhörande värden.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Exempel på översättningsfil (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 Använda `<i18n-t>` för översättningar med slots och interpolation

Komponenten `<i18n-t>` är användbar för att rendera översättningar med dynamiskt innehåll och HTML-taggar:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### Exempel-JSON för `<i18n-t>`

```json
{
  "greeting": "Welcome to the page"
}
```

### Med interpolation

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### Exempel-JSON för interpolation

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 Använda `$tc` för pluralisering

Funktionen `$tc` i `Nuxt I18n Micro` hanterar pluralisering baserat på antalet och locale-inställningarna. Detta är användbart för att dynamiskt anpassa meddelanden som involverar antal, såsom objekt, notifieringar eller andra entiteter vars antal kan variera.

### Exempel: Använda `$tc` för pluralisering

I följande exempel visar vi ett meddelande som anger antalet äpplen med hjälp av `$tc`. Översättningsnyckeln hanterar flera pluralformer baserat på det angivna antalet.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### Exempel-JSON för pluralisering

Så här kan du definiera översättningen i din JSON-fil för att hantera olika pluralformer:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Förklaring

- **`$tc('apples', 0)`**: Returnerar den första formen, används när antalet är noll (`"no apples"`).
- **`$tc('apples', 1)`**: Returnerar den andra formen, används när antalet är ett (`"one apple"`).
- **`$tc('apples', 10)`**: Returnerar den tredje formen med räknarvärdet, används när antalet är två eller fler (`"10 apples"`).

### Ytterligare exempel med mer komplex pluralisering

Om din applikation behöver hantera mer komplexa pluraliseringsregler (t.ex. specifika fall för noll, ett, två, få, många, annat) kan du utöka översättningssträngarna därefter:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: Kan ställas in för att returnera `"two apples"`.
- **`$tc('apples', 3)`**: Kan returnera `"a few apples"`, beroende på de regler som definierats för antalet.

## 🌐 Använda `$tn` för nummerformatering

Funktionen `$tn` formaterar tal enligt aktuell locale med API:et `Intl.NumberFormat`. Detta är användbart för att visa tal på ett sätt som matchar användarens regionala inställningar, såsom valuta, procentsatser eller andra talformat.

### Exempel: Använda `$tn` för nummerformatering

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ Använda `$td` för datum- och tidsformatering

Funktionen `$td` formaterar datum och tider enligt aktuell locale med API:et `Intl.DateTimeFormat`. Detta är användbart för att visa datum och tider i format som är bekanta för användaren baserat på deras locale-inställningar.

### Exempel: Använda `$td` för datum- och tidsformatering

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ Använda `$tdr` för relativ datumformatering

Funktionen `$tdr` formaterar datum som relativa tider (t.ex. "5 minutes ago", "2 days ago") enligt aktuell locale med API:et `Intl.RelativeTimeFormat`. Detta är användbart för att visa tidsskillnader relativt till aktuellt datum och tid.

### Exempel: Använda `$tdr` för relativ datumformatering

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
