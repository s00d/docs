## 🚀 Snabbstart

### Installation

Installera modulen i din Nuxt-applikation:

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

### Grundläggande konfiguration

Lägg till modulen i din `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

<Tip>
- **Rotnivåfiler** (`locales/en.json` osv.) — översättningar som delas i hela appen (menyer, sidfot, gemensamt UI). Med `translationPayloads.mode: 'premerged'` (standard) slås de samman i varje sida vid byggtid.
- **Sidspecifika filer** (`locales/pages/<route>/<locale>.json`) — översättningar unika för specifika sidor, laddas endast när sidan besöks.
- **Dynamiska rutter** — `pages/articles/[id].vue` mappar till `locales/pages/articles-id/` (hakparenteser ersätts med bindestreck).
- **Autogenerering** — alla översättningsfiler skapas automatiskt om de saknas under `nuxt dev`.
</Tip>

<Info>
Modulen stöder båda layouterna:

- **Sidor**: `pages/**/*.vue` (Nuxt 3) eller `app/pages/**/*.vue` (Nuxt 4)
- **Översättningar**: håll `locales/` i **projektets rot** som standard (rekommenderad konvention), inte inuti `app/`

```tree
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   ├── en.json
│   └── pages/
└── nuxt.config.ts
```

Valfri colocation: `i18n: \{ translationDir: 'app/locales' \}` (se [fixture `n3`](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/n3)).

För den valfria CLI-hjälparen `text-to-i18n`, använd [`nuxt-i18n-micro-cli` ≥ 2.1.1](/guides/cli#-text-to-i18n-command) så att `app/pages` och `app/components` skannas från projektets rot.
</Info>

### Grundläggande användning

Använd översättningar i dina komponenter:

```vue
<template>
  <div>
    <h1>{{ $t('welcome') }}</h1>
    <p>{{ $t('description', { name: 'World' }) }}</p>

    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" @click="$switchLocale(locale.code)">
        {{ locale.code }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useI18n } from '#imports'

const { $t, $getLocales, $switchLocale } = useI18n()
</script>
```
