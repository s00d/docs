## Krav

- **Node.js**: 18 eller nyare.
- **Nuxt**: 3.x eller 4.x.

Modulen stöder både Nuxt 3-projektlayouten (`pages/**/*.vue`) och Nuxt 4-layouten (`app/pages/**/*.vue`). Översättningar ligger enligt konvention i projektets rot (`locales/`), även när Nuxt 4:s `app/`-katalog används.

## Installera Nuxt-modulen

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Registrera den i `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Se [Snabbstart](/quickstart) för en fullständig genomgång eller [Konfigurationsreferens](/guides/configuration) för alla alternativ.

## Projektlayout

Som standard förväntar sig modulen:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Rotnivåfiler slås samman med varje sidspecifik fil vid byggtid. Sidspecifika filer skapas automatiskt om de saknas under `nuxt dev`.

## Nuxt 4-layout

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

För att kolokera översättningar under `app/`, sätt `translationDir: 'app/locales'`.

## TypeScript

Modulen genererar ambienta typer för `useI18n`, `$t` och relaterade hjälpare baserat på dina standardlokalfiler. Detta är aktiverat som standard (`types: true`).

För starkare typning av översättningsnycklar, se [`@i18n-micro/types-generator`](/integrations/types-generator).
