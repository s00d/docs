---
title: "useI18n"
description: "useI18n returnerar körtidshjälparna (`$t`, `$tc`, `$localePath`, …) som ett vanligt objekt, med och utan prefixet `$`."
---

`useI18n()` returnerar modulens körtidshjälpare som ett vanligt objekt. Använd den i `<script setup>`, composables och plugins i stället för att använda `useNuxtApp()`. Varje hjälpare finns under sitt `$`-namn och ett alias utan prefix: `t` och `$t` är samma funktion.

## Signatur {#signature}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Alla körtidshjälpare, som ett vanligt objekt.

Samma funktioner som pluginet injicerar som `$t`, `$tc` och så vidare, tillgängliga både under
namnet med dollarprefix och ett alias utan prefix — så både `const { t } = useI18n()` och
`const { $t } = useI18n()` fungerar.

**Returnerar** — hjälparna som beskrivs i [metodreferensen](/sv/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

Det returnerade objektet innehåller alla hjälpare i [`PluginsInjections`](/sv/api/methods). Var och en dokumenteras på sidan [Hjälpare](/sv/api/methods).

## Exempel {#example}

```vue
<script setup lang="ts">
const { t, tc, localePath, switchLocale, getLocale } = useI18n()

const title = computed(() => t('page.title'))
</script>

<template>
  <h1>{{ title }}</h1>
  <p>{{ tc('items', 3) }}</p>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
  <button @click="switchLocale(getLocale() === 'en' ? 'de' : 'en')">{{ t('nav.switch') }}</button>
</template>
```

## Inte med i typen {#not-in-the-type}

`$defineI18nRoute` är bara typad på `useNuxtApp()`:

```ts
const { $defineI18nRoute } = useNuxtApp()
```
