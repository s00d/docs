---
title: "useI18nHead"
description: "useI18nHead åsidosätter de genererade i18n-SEO-taggarna för en enskild sida: ersätt eller ta bort canonical-, hreflang- och og-taggar, eller lägg till egna."
---

`useI18nHead()` ändrar SEO-taggarna som modulen genererar, endast för en sida. Använd den när en sida vet bättre än routern: en CMS-artikel som bara finns i vissa locales, en canonical-URL från ett API, extra `og:`-taggar. Du får de genererade taggarna med dina åsidosättningar sammanslagna ovanpå.

## Signatur {#signature}

```ts
useI18nHead(input?: MaybeRefOrGetter<I18nHeadInput | null>): { pageHead: any; resetPageHead: () => void }
```

Registrera åsidosättningar på sidnivå för i18n-SEO-taggar i head.
Slås ihop ovanpå utdata från `useLocaleHead` av pluginet `02.meta`.

Använd helst en getter (`() => ({ … })`) när värdena kommer från `$t` / `t` så att de
löses upp på nytt när locale byts. Ett vanligt objekt utvärderas en gång och förblir fryst.

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| `input` *(valfri)* | `MaybeRefOrGetter<I18nHeadInput \| null>` |  |

Den fungerar med [`meta: true`](/sv/api/module-options#meta) (standard): modulens meta-plugin slår ihop indata ovanpå utdata från [`useLocaleHead`](/sv/composables/useLocaleHead) vid varje rendering av head. Med `meta: false` läser ingenting den.

Åsidosättningen återställs när routens namn ändras. En sida som sätter `disableMeta` får inga i18n-taggar alls, inklusive åsidosättningar.

## Indata {#input}

`I18nHeadInput` (från `@i18n-micro/types`):

| Nyckel | Typ | Effekt |
| --- | --- | --- |
| `htmlAttrs` | `Record<string, string>` | Slås ihop med attributen på `<html>` (`lang`, `dir`). |
| `meta` | `I18nHeadMeta[]` | Läggs till efter de genererade taggarna; ersätter en tagg med samma `id`, `property` eller `name`. |
| `link` | `I18nHeadLink[]` | Läggs till efter de genererade länkarna; ersätter en länk med samma `id`, eller `rel` + `hreflang`. |
| `replace.canonical` | `string \| false` | Ersätt canonical-`href`, eller ta bort länken. |
| `replace.hreflang` | `I18nHeadLink[] \| false` | Ersätt eller ta bort **alla** `rel="alternate"`-länkar, inklusive `x-default`. |
| `replace.xDefault` | `I18nHeadLink \| false` | Ersätt eller ta bort `x-default`-länken. |
| `replace.ogLocale` | `string \| false` | Ersätt eller ta bort `og:locale`. |
| `replace.ogUrl` | `string \| false` | Ersätt eller ta bort `og:url`. |
| `replace.ogAlternates` | `string[] \| false` | Bygg om `og:locale:alternate` från dessa locale-koder (via `og` / `iso`), och hoppa över aktuell locale, okända koder och koder utan `og`- eller `iso`-värde, eller ta bort dem. |
| `disable` | `I18nHeadDisableGroup[]` | Ta bort genererade grupper: `'hreflang'` (inte `x-default`), `'x-default'`, `'canonical'`, `'og'` (`og:locale` + `og:url`), `'og-alternates'`, `'html'`. |

Tillämpningsordning: `disable`, sedan `replace`, sedan `htmlAttrs`, `meta`, `link`.

## Exempel {#example}

En artikel som bara finns i vissa locales, med alternativa URL:er från API:t:

```vue
<script setup lang="ts">
const route = useRoute()
const { t } = useI18n()
const { data: article } = await useFetch<{ title: string; urls: Record<string, string> }>(`/api/articles/${route.params.slug}`)

useI18nHead(() => {
  if (!article.value) return null
  const codes = Object.keys(article.value.urls)
  return {
    meta: [{ property: 'og:title', content: article.value.title || t('blog.title') }],
    replace: {
      hreflang: codes.map((code) => ({ rel: 'alternate', hreflang: code, href: article.value!.urls[code]! })),
      ogAlternates: codes,
    },
  }
})
</script>
```

Skicka en getter, som här, när värdena kommer från `t()` eller asynkron data: den körs om när locale byts. Ett vanligt objekt läses en gång.
