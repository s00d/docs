---
title: "useLocaleHead"
description: "useLocaleHead bygger i18n-SEO-taggarna (lang, dir, canonical, hreflang, og:locale) som ett objekt som du skickar till useHead."
---

`useLocaleHead()` bygger i18n-head-taggarna för den aktuella routen: `lang` och `dir` på `<html>`, en canonical-länk, `hreflang`-alternativ med `x-default`, `og:url`, `og:locale` och `og:locale:alternate`. Använd den när du sätter [`meta: false`](/sv/api/module-options#meta) och hanterar `useHead` själv; med `meta: true` registrerar modulen redan dessa taggar, och ändringar per sida görs via [`useI18nHead`](/sv/composables/useI18nHead).

## Signatur {#signature}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { build: () => LocaleHead; metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }, LocaleHead | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

SEO-taggarna i head för den aktuella routen: `hreflang`-alternativ för varje locale plus
`x-default`, en canonical-länk, `og:locale` samt `lang`/`dir` på `<html>`.

Behövs bara när `meta` är avstängt eller standardvärdena behöver justeras — med `meta: true`
registrerar modulen samma taggar själv.

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| `options` | `UseLocaleHeadOptions` |  |

**Returnerar** — `metaObject`, en ref som innehåller head-objektet redo att skickas till `useHead`; `updateMeta` uppdaterar den; `build` beräknar head-objektet från den aktuella routen (reaktivt när det läses i en getter, t.ex. `useHead(() => build())`)

```ts
const { metaObject } = useLocaleHead({ addSeoAttributes: true })
useHead(metaObject)
```

## Alternativ {#options}

| Alternativ | Standard | Beskrivning |
| --- | --- | --- |
| `addDirAttribute` | `true` | Sätt `dir` på `<html>` från locale:ns `dir` (`'auto'` när den saknar ett). |
| `identifierAttribute` | `'id'` | Attribut som identifierar varje tagg (`i18n-can`, `i18n-og`, `i18n-alternate-<hreflang>`, …), så att uppdateringar ersätter taggar i stället för att lägga till nya. |
| `addSeoAttributes` | `true` | Generera canonical-, `hreflang`- och `og:`-taggar. `false` behåller bara `htmlAttrs`. |
| `baseUrl` | `'/'` | Origin som sätts före varje URL. Behåll `'/'` för relativa URL:er; skicka `'https://example.com'` för absoluta. |
| `autoUpdate` | `true` | Bygg om `metaObject` när routen eller tillståndet `i18n-locale` ändras. |

## Vad den genererar {#what-it-emits}

- Ingenting på en route utan matchning (404) eller med `disableMeta` för den aktiva locale:n.
- Canonical och `og:url`: `$switchLocalePath(<active locale>)`, med query reducerad till [`canonicalQueryWhitelist`](/sv/api/module-options#canonicalquerywhitelist) och [`trailingSlash`](/sv/api/module-options#trailingslash) tillämpad.
- `hreflang`: en länk per aktiverad locale som sidan finns i, `hreflang = iso || code`, och locales med `seo: false` hoppas över; med `hreflangBaseLanguage: true` genererar även den första regionala locale:n för ett språk taggen för enbart språket. Inga under `no_prefix`.
- `x-default`: standard-locale:ns URL, såvida inte strategin är `no_prefix`, standard-locale:n har `seo: false` eller sidan inte finns i den.
- `og:locale` / `og:locale:alternate`: från locale:ns `og`, eller dess `iso` konverterad (`en-US` → `en_US`); hoppas över med en varning i dev-läge när ingetdera fungerar.

## Exempel {#example}

```ts
// app.vue, with i18n.meta: false
const { metaObject } = useLocaleHead({ baseUrl: 'https://example.com' })
useHead(metaObject)
```

`build()` returnerar samma objekt utan ref: `useHead(() => build())` förblir reaktivt utan en watcher.
