**Datum**: 2026-05-14

**Version**: `v3.20.0`

![v3.20.0-versionen](/images/3.20.0.png)

Den här versionen omstrukturerar Nuxt-runtime till ett dedikerat **`NuxtI18n`**-lager, delar upp hanteringen av omdirigeringar på server och klient och åtgärdar flera regressioner i SSR/hydrering. Publika composables och `nuxt.config`-alternativ är oförändrade för typiska appar.

## Vad är nytt? {#what’s-new}

### `NuxtI18n` och `NuxtTranslationLoader` {#nuxti18n-&-nuxttranslationloader}

Runtime-logiken för i18n flyttas ut ur det monolitiska pluginet till fokuserade klasser:

- **`NuxtI18n`** — lagret för den aktiva översättningsvyn (`$t`, `$has`, kontext för locale/route, sammanslagning/rensning vid övergångar)
- **`NuxtTranslationLoader`** — läser in chunkar, byter kontext vid navigering, förser SSR-payloaden med data
- **`createNuxtI18nPluginApi`** — tunt plugin-gränssnitt (`$switchLocale`, `$localeRoute` osv.)

Se uppdaterade [Cache & Storage Architecture](https://s00d.github.io/nuxt-i18n-micro/v3/api/i18n-cache-api) och [Prestanda](/sv/guide/performance).

### SSR-payload via `useState('i18n-ssr-chunks')` {#ssr-payload-via-usestate‘i18n-ssr-chunks’}

SSR-översättningar serialiseras via **Nuxt-tillstånd**, inte via en `window.__I18N__`-script-tagg:

1. Servern läser in chunkar → `useState('i18n-ssr-chunks')`
2. Klienten hydreras → `translationStorage.seedFromSsrChunks()`
3. Inga extra hämtningar vid första renderingen

Den äldre läsvägen via `window.__I18N__` är **borttagen**.

### Uppdelad omdirigeringsarkitektur {#redirect-architecture-split}

Omdirigeringar är nu miljöspecifika för tydligare beteende och mindre ryckighet på klienten:

| Miljö    | Komponent                      | Roll                                       |
| -------------- | ------------------------------ | ------------------------------------------ |
| **Server-SSR** | `06.redirect.ts` (endast server) | 302 före rendering, 404-kontroller, cookiesynkronisering |
| **Klient-SPA** | `i18n-redirect.global.ts`      | Global route-middleware vid navigering      |

Omdirigeringar på klienten härleder locale från **målrouten**, bevarar **frågesträng och hash** och respekterar `redirects: false` (middleware registreras inte). Se [Identifiering av locale — omdirigeringar per strategi](/sv/guide/locale-detection#redirects-per-strategy).

### Tidpunkt för kroken `i18n:register` {#i18nregister-hook-timing}

Pluginet **`05.hooks`** (`dependsOn: i18n-plugin-loader`) utlöser `i18n:register` när laddaren är redo — vid uppstart och vid navigering — så att användarens plugins tillförlitligt tar emot händelsen. Inaktivera med `hooks: false`. Se [Händelser](/sv/api/events).

### Extrahering av `defineI18nRoute` vid byggtid {#build-time-definei18nroute-extraction}

Ett Vite-unplugin skannar sidornas `.vue`-filer vid byggtid och skriver route-meta för `@i18n-micro/route-strategy`. `$defineI18nRoute` vid körning i `script setup` finns kvar för utveckling och inline-konfiguration. Se [Översättningar per komponent](/sv/guide/per-component-translations).

## Buggrättningar {#bug-fixes}

- **SSR-hydrering** — reaktiva SSR-chunkar klonas före `Object.freeze` (åtgärdar krascher med `#locale` / 404 på klienten)
- **Byte av locale** — vylagret ersätts vid byte av locale (inga inaktuella nycklar från föregående locale)
- **Omdirigering på klienten** — locale från målrouten; frågesträng/hash bevaras vid omdirigering
- **`has()`** — kontrollerar endast aktiv locale; reserv tillämpas i `$t()`, inte i `$has()`
- **`defineI18nRoute`-meta** — cache per plugininstans; längsta `rootDir`-matchning; korrekta sökvägar för `pages/index` kontra `pages/index/index`

## Brytande ändringar {#breaking-changes}

Inga för standardanvändning av `nuxt.config` + composables. Interna sökvägar och SSR-injektionsmekanismen har ändrats; appar som förlitade sig på manuell injektion av `window.__I18N__` måste i stället använda Nuxt-payload / modulens API:er.

## Varför det spelar roll {#why-it-matters}

- **Mer tillförlitlig överlämning från SSR till klient** — Nuxt-inbyggt tillstånd i stället för tillfälliga globala variabler
- **Tydligare omdirigeringsmodell** — 302 från servern före rendering; klient-middleware bara där det behövs
- **Enklare att underhålla** — runtime uppdelad i testbara enheter med fokuserade regressionstester

Den fullständiga ändringsloggen publiceras tillsammans med versionen på [GitHub](https://github.com/s00d/nuxt-i18n-micro/blob/main/CHANGELOG.md).
