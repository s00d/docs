**Datum**: 2025-10-30

**Version**: `v2.0.0`

![v2.0.0-versionen](/images/2.0.0.png)

Vi introducerar HMR på serversidan för översättningsfiler under utveckling. När en JSON-översättning ändras ogiltigförklarar servercachen bara de berörda nycklarna, och efterföljande förfrågningar får omedelbart färska data – inga omstarter krävs.

## Vad är nytt? {#what’s-new}

- HMR på serversidan för översättningsfiler
- Omedelbar cacheogiltigförklaring per sida/locale
- Smidig utvecklarupplevelse när du redigerar innehåll

## Hur det fungerar {#how-it-works}

- En watcher i `src/runtime/server/plugins/watcher.dev.ts` bevakar `<rootDir>/<translationDir>/**/*.json`
- Sidfiler (t.ex. `pages/<page>/<locale>.json`) ogiltigförklarar `_locales:merged:<page>:<locale>`
- Filer på rotnivå (t.ex. `<locale>.json`) ogiltigförklarar alla sammanslagna nycklar för den locale
- Registreras automatiskt från `src/module.ts` under utveckling när `experimental.hmr !== false`

## Konfiguration {#configuration}

```ts
export default defineNuxtConfig({
  i18n: {
    experimental: { hmr: true }, // default in dev
  },
})
```
