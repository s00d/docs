### Beskrivning {#description}

Jämför **ren Nuxt**, **i18n-micro** och **`@nuxtjs/i18n`** under en gemensam ordboksprofil via `untestutils/perf`.

Fokus: byggtid, högsta RSS, driftsättningsbar **kod vs översättningar (asset) vs totalt**, samt belastning (Artillery).

### Anteckningar om metodik {#methodology-notes}

- Mätvärdena är **medelvärden av 3 på varandra följande körningar per fixture** (inte omväxlande).
- **Artefakt**: Nitro node-server `.output/server/index.mjs` efter tvingad `nuxi build`; `nuxt-i18n-micro` är **modulens byggda dist** (inte jiti-stubben från `dev:prepare`). Se [benchmarkmetodik](https://s00d.github.io/nuxt-i18n-micro/contributing/performance-methodology).
- **Översättningar** = `bundle.asset` (locale-JSON, `chunks/raw/`, matchande locale-chunks via `isTranslationFile`).
- **Kod** exkluderar source maps (`*.map`): fixtures länkar modulen från repot, så Nitro skriver fullständiga maps för den och inga för npm-beroenden.
- **plain-nuxt** serverar samma mängd lövnycklar som statisk JSON — I/O-tungt under belastning, inte ”i18n-overhead”.
- Belastningsprofil `--load full`: uppvärmning 6s@6 + huvudfas 60s@60 utan tak (historisk).
- Nedkylning `--cool fast` (se metodikdokumentet).
- Vart och ett av `runs`-byggena är **tvingat** (ingen nollning av byggtiden via varm cache).
- Artillerys **felfrekvens** i tabellerna är HTTP-statusfel från belastningsmätvärdena. Diagrammen visar även `vusers.failed` (klienttimeouts vid mättnad); dessa kan vara höga medan HTTP-felfrekvensen ligger kvar på 0 %.

## Anteckningar {#notes}

- Gemensam profil: 4 locales × 2 sidor × ~16,8k lövnycklar i index.
- Belastning: endast programmatisk Artillery — uppvärmning **6s@6** + huvudfas **60s@60**, VU utan tak (historisk YAML-metodik). Sökvägar från körtidsprofilen — se `scripts/src/perf/load.ts`.
- Nedkylning: 2 s efter bygge, 3 s mellan körningar, 5 s mellan fixtures. Byggena tvingas vid varje körning så att medelvärdena inte späds ut av cacheträffar.
- Kör om i vardagen: `pnpm test:performance` (`--load short --cool fast`).
- Generera om den här sidan: `pnpm -C scripts cli performance --load full --only all --runs 3`.
- Flaggor: `--locales N --keys K --only all|micro|i18n|plain --runs N --skip-load --cool fast|strict`.
