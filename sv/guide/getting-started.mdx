Den här sidan tar en Nuxt-app från ingen i18n till en översatt sida med en språkväljare. Du behöver den en gång, i början av ett projekt. Resultatet blir lokaliserade URL:er (`/about`, `/de/about`), en JSON-fil per locale och sida, och `$t` i dina mallar.

## Installera {#install}

Modulen kräver Nuxt 3.18 eller senare (Nuxt 4 fungerar också) och Node 20 eller senare.

<CodeGroup>

```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>

## Konfigurera locales {#configure-the-locales}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', displayName: 'English' },
      { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
      { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
    ],
    defaultLocale: 'en',
  },
})
```

Det är all konfiguration som en första app behöver. Standardvärdena ger dig:

- `strategy: 'prefix_except_default'`: standard-locale har inget prefix (`/about`), de andra har det (`/de/about`). Se [Routingstrategier](/sv/guide/strategy).
- `translationDir: 'locales'`: översättningsfilerna ligger i `locales/` i projektets rot, även med Nuxt 4:s `app/`-struktur.
- `meta: true`: taggarna `hreflang`, canonical och `og:locale`, plus `lang` och `dir` på `<html>`. Se [SEO](/sv/guide/seo).
- En besökare som öppnar `/` skickas till det språk som webbläsaren ber om (`Accept-Language`). Se [Identifiering av locale](/sv/guide/locale-detection).

`iso` är språktaggen som används i SEO-taggar; `code` är det som syns i URL:en. Alla alternativ listas i [Modulalternativ](/sv/api/module-options).

## Lägg till översättningsfiler {#add-translation-files}

Starta utvecklingsservern med `nuxt dev`. När Nuxt löser upp sidorna skapar modulen en tom `{}`-fil för varje locale och sida som saknar en (stäng av detta med [`disableWatcher`](/sv/api/module-options#disablewatcher)):

```text
locales/
├── en.json            # root: keys every page can use
├── de.json
├── fr.json
└── pages/
    ├── index/         # pages/index.vue
    │   ├── en.json
    │   ├── de.json
    │   └── fr.json
    └── about/         # pages/about.vue
        ├── en.json
        ├── de.json
        └── fr.json
```

Fyll i rotfilen och en sidfil:

```json
// locales/en.json
{ "nav": { "home": "Home", "about": "About" } }
```

```json
// locales/pages/index/en.json
{ "welcome": "Welcome, {name}!", "items": "no items | one item | {count} items" }
```

En sida ser rotnycklarna och sina egna nycklar; den egna filen vinner vid en krock. Mappnamnen följer route-namnet (`pages/articles/[id].vue` blir `locales/pages/articles-id/`). [Översättningsfiler](/sv/guide/translations) beskriver strukturen, reservvärden och laddning.

## Använd `$t` på en sida {#use-$t-on-a-page}

```vue
<!-- pages/index.vue -->
<script setup lang="ts">
const { t, tc, getLocale } = useI18n()

const title = t('nav.home') // 'Home'
</script>

<template>
  <h1>{{ $t('welcome', { name: 'Ada' }) }}</h1>
  <!-- Welcome, Ada! -->
  <p>{{ $tc('items', 3) }}</p>
  <!-- 3 items -->
  <p>{{ getLocale() }}</p>
  <!-- en -->
</template>
```

- I mallar är varje hjälpfunktion tillgänglig med ett `$` (`$t`, `$tc`, `$localePath`, …).
- I `<script setup>` returnerar `useI18n()` samma hjälpfunktioner, med och utan `$` (`t` och `$t` är samma funktion). Den importeras automatiskt.
- Platshållare som `{name}` fylls i från params-objektet. Pluralformer separeras med `|`; antalet väljer formen (0, 1, sedan den sista för allt däröver).

Alla hjälpfunktioner listas i [Metoder](/sv/api/methods).

## Länka mellan sidor och byt locale {#link-between-pages-and-switch-locale}

```vue
<!-- components/AppHeader.vue -->
<template>
  <nav>
    <i18n-link :to="{ name: 'index' }">{{ $t('nav.home') }}</i18n-link>
    <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
    <i18n-switcher />
  </nav>
</template>
```

- [`<i18n-link>`](/sv/components/i18n-link) är en `NuxtLink` som pekar på sidan i aktuell locale: på `/de` går about-länken till `/de/about`.
- [`<i18n-switcher>`](/sv/components/i18n-switcher) är en rullgardinsmeny med de aktiverade locales; den håller kvar besökaren på samma sida.
- För dina egna knappar anropar du `$switchLocale('de')`, som navigerar till den aktuella sidan på tyska och kommer ihåg valet. För en vanlig `NuxtLink` använder du `$localePath({ name: 'about' })` eller `$switchLocalePath('de')`.

## Kontrollera {#check-it}

Kör `nuxt dev` och öppna:

| URL | Visar |
| --- | --- |
| `/` | Engelsk startsida (eller en omdirigering till `/de` när din webbläsare föredrar tyska) |
| `/de` | Tysk startsida |
| `/de/about` | Tysk about-sida |
| `/en/about` | 404: standard-locale har inget prefix under `prefix_except_default` |

Ändringar i JSON-filerna tillämpas på den öppna sidan utan omladdning.
