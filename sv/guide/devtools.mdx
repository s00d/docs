I `nuxt dev` lägger modulen till två felsökningshjälpmedel: en **i18n Micro**-flik i Nuxt DevTools för att bläddra bland och redigera översättningsfiler, och en Vue DevTools-inspektör för den aktiva locale och de laddade ordlistorna. Båda finns endast under utveckling och tillför ingenting till produktionsbuilds. Nuxt-fliken kräver bara att Nuxt DevTools är aktiverat; Vue-inspektören kräver även webbläsartillägget Vue DevTools.

## Nuxt DevTools-flik {#nuxt-devtools-tab}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  devtools: { enabled: true }, // the tab is registered only when DevTools are on
})
```

Öppna Nuxt DevTools (`Shift + Alt + D`) och välj **i18n Micro**. Fliken visar:

- varje JSON-fil under `locales/` (rot och `pages/`) i varje lager, plus rotfiler från `additionalTranslationDirs`;
- en redigerare per fil; **Save** skriver tillbaka filen till disk och utvecklingsservern laddar om översättningarna;
- **Export** / **Import** av en fil som JSON, och **Stats** med antal nycklar och översättningstäckning;
- en konfigurationsvy över de upplösta modulalternativen;
- **Translate**, som fyller i saknade nycklar med en maskinöversättningsmotor som du konfigurerar i flikens inställningar.

Sparande skriver endast befintliga `.json`-filer i dina översättningskataloger. När en fil finns i flera lager skrivs projektets kopia.

## Vue DevTools-inspektör {#vue-devtools-inspector}

Med webbläsartillägget Vue DevTools registrerar modulen en i18n-inspektör (aktuell locale, route-del, laddade nycklar) och en tidslinje med byten av locale, laddning av delar och saknade nycklar.

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    debug: true, // also log every $t / $ts / $tc call on the timeline
    // vueDevtools: false, // turn the inspector off, keep the Nuxt tab
  },
})
```

[`vueDevtools`](/sv/api/module-options) har `true` som standard. `debug: true` är utförligt; använd det bara under korta sessioner.
