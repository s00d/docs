---
title: "Migrera från @nuxtjs/i18n"
description: "Mappa @nuxtjs/i18n-alternativ, composables och översättningsfiler till nuxt-i18n-micro."
---

Den här sidan mappar en `@nuxtjs/i18n`-app till nuxt-i18n-micro: alternativ, hjälpfunktioner och filstruktur. Använd den när du byter modul i en befintlig app. Du behåller dina URL:er (strateginamnen är desamma) och flyttar översättningar till JSON-filer per sida.

<Tip>

**Uppgraderar du nuxt-i18n-micro självt?** — Se [Uppgradering](/sv/guide/upgrade).

</Tip>

## Byt modul {#swap-the-module}

```bash
npm uninstall @nuxtjs/i18n
npm install nuxt-i18n-micro
```

```ts
// nuxt.config.ts — before
export default defineNuxtConfig({
  modules: ['@nuxtjs/i18n'],
  i18n: {
    locales: [
      { code: 'en', language: 'en-US', file: 'en.json' },
      { code: 'de', language: 'de-DE', file: 'de.json' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    langDir: 'locales',
    detectBrowserLanguage: { useCookie: true, cookieKey: 'i18n_redirected', redirectOn: 'root' },
  },
})
```

```ts
// nuxt.config.ts — after
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    translationDir: 'locales',
    localeCookie: 'i18n_redirected',
    autoDetectPath: '/',
  },
})
```

## Alternativ {#options}

| `@nuxtjs/i18n` | nuxt-i18n-micro |
| --- | --- |
| `locales[].code` | `locales[].code` |
| `locales[].language` (`iso` före v9) | `locales[].iso` |
| `locales[].name` | `locales[].displayName` |
| `locales[].dir` | `locales[].dir` |
| `locales[].domain` | `locales[].baseUrl` (ett origin med schema) |
| `locales[].domainDefault` | `locales[].baseDefault` |
| `differentDomains`, `multiDomainLocales` | behövs inte: `baseUrl` ensamt routar efter värd, se [Layers och domäner](/sv/guide/layers#multiple-domains) |
| `locales[].file` / `files`, `langDir`, `lazy` | `translationDir`; filer hittas efter namn och laddas alltid per sida |
| `defaultLocale`, `strategy` | samma namn, samma fyra värden |
| `baseUrl` | `metaBaseUrl` |
| `customRoutes: 'config'` + `pages` | `globalLocaleRoutes` |
| `detectBrowserLanguage: false` | `redirects: false` (inga omdirigeringar) eller `autoDetectLanguage: false` (ignorera headern) |
| `detectBrowserLanguage.useCookie` / `cookieKey` | `localeCookie: '<name>'` (`null` stänger av cookien) |
| `detectBrowserLanguage.redirectOn: 'root'` | `autoDetectPath: '/'` (standard) |
| `detectBrowserLanguage.redirectOn: 'no prefix'` | `autoDetectPath: 'no_prefix'` |
| `detectBrowserLanguage.redirectOn: 'all'` | `autoDetectPath: '*'` |
| `vueI18n`-konfigurationsfil (`fallbackLocale`, `numberFormats`, `datetimeFormats`) | `fallbackLocale`, `numberFormats`, `datetimeFormats` i `i18n` |

Det finns ingen `alwaysRedirect`: med en cookie satt följer `/` den vid varje besök. Den fullständiga listan finns i [Modulalternativ](/sv/api/module-options); detekteringsreglerna finns på [Locale-detektering](/sv/guide/locale-detection).

## Hjälpfunktioner och composables {#helpers-and-composables}

| `@nuxtjs/i18n` / vue-i18n | nuxt-i18n-micro (mall / `useI18n()`) |
| --- | --- |
| `const { t } = useI18n()` | `const { t } = useI18n()`, `$t` i mallar |
| `t('key', count)`, `tc` | `$tc('key', count)` |
| `te('key')` | `$has('key')` |
| `n(value, 'currency')`, `d(date, 'short')` | `$tn(value, 'currency')`, `$td(date, 'short')` |
| — | `$tdr(date)`: relativ tid ("om 3 dagar") |
| `locale.value` | `$getLocale()` |
| `locales.value` | `$getLocales()` |
| `setLocale('de')` | `$switchLocale('de')` |
| `useLocalePath()('about')` | `$localePath({ name: 'about' })` |
| `useLocaleRoute()` | `$localeRoute()` |
| `useSwitchLocalePath()('de')` | `$switchLocalePath('de')` |
| `useSetI18nParams()` | `$setI18nRouteParams()` |
| `useLocaleHead()` | automatiskt med `meta: true`; [`useLocaleHead`](/sv/composables/useLocaleHead) för anpassade heads |
| `defineI18nRoute({ paths: { de: '/ueber-uns' }, locales: [...] })` | `$defineI18nRoute({ localeRoutes: { de: '/ueber-uns' }, locales: [...] })` |
| `<NuxtLinkLocale to="about">` | `<i18n-link :to="{ name: 'about' }">` |
| `<i18n-t>` | `<i18n-t>` (slots fyller `{name}`-platshållare) |
| `$i18n` i serverroutes | `useTranslationServerMiddleware(event)`, se [Serverroutes och API](/sv/guide/server-side-translations) |

`useI18n()` importeras automatiskt. `$defineI18nRoute` måste behålla sitt `$`: bygget läser det anropet. Alla hjälpfunktioner: [Metoder](/sv/api/methods).

## Översättningsfiler {#translation-files}

Flytta nycklarna från en stor fil per locale till en rotfil plus en fil per sida:

```text
locales/
├── en.json              # keys used on many pages (nav, footer)
├── de.json
└── pages/
    ├── index/en.json    # keys of pages/index.vue
    └── about/en.json    # keys of pages/about.vue
```

Att behålla allt i rotfilerna fungerar också, och är det snabbaste första steget. Sätt `disablePageLocales: true` tills du delar upp dem. Se [Översättningsfiler](/sv/guide/translations).

### Meddelandesyntax {#message-syntax}

| vue-i18n | nuxt-i18n-micro |
| --- | --- |
| `{name}` namngiven interpolering | samma |
| `car \| cars` (2 former: 1 → första) | former väljs efter antal från 0: skriv `no cars \| one car \| {count} cars` |
| `@:other.key` länkade meddelanden | stöds inte: upprepa texten eller komponera i kod |
| `@.upper:`-modifierare | stöds inte: formatera i kod eller använd `<i18n-t>` |
| `{'@'}` literala escapes | behövs inte: endast `{word}`-token ersätts |
| JS/TS-meddelandefiler | endast JSON |

Pluralregeln kan ersättas med alternativet [`plural`](/sv/api/module-options#plural).

## Kontrollera efter bytet {#check-after-the-switch}

- Varje URL du hade löses fortfarande; strateginamnen matchar, anpassade sökvägar flyttas till `globalLocaleRoutes` eller `$defineI18nRoute`.
- `hreflang`, canonical och `og:locale` kommer direkt med `meta: true`; ta bort handskrivna.
- Ett JSON-tolkningsfel loggar filsökvägen; en saknad nyckel loggar en varning i webbläsarkonsolen under utveckling.
