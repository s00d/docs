---
title: "Lokaliserade sökvägar"
description: "Ge en sida en egen URL per locale med localeRoutes eller globalLocaleRoutes, inklusive dynamiska parametrar och slugs per locale."
---

Som standard serverar varje locale en sida på samma sökväg: `/en/about`, `/de/about`. Med lokaliserade sökvägar kan varje locale använda sina egna ord, till exempel `/de/ueber-uns`, medan sidfilen förblir densamma. Du anger dem i sidan med `$defineI18nRoute`, eller för många sidor på en gång i `nuxt.config.ts`.

## I sidan {#in-the-page}

```vue
<!-- pages/about.vue -->
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  localeRoutes: {
    de: '/ueber-uns',
    fr: '/a-propos',
  },
})
</script>
```

Med `prefix_except_default` och `defaultLocale: 'en'` svarar sidan på `/about`, `/de/ueber-uns` och `/fr/a-propos`. En locale utan en post behåller standardsökvägen. Skriv sökvägar utan locale-koden: prefixet läggs till av [strategin](/sv/guide/strategy), och en sökväg som börjar med locale-koden loggar en varning. Vad anropet i övrigt accepterar finns under [Sidkonfiguration](/sv/guide/per-component-translations).

## I nuxt.config {#in-nuxt-config}

[`globalLocaleRoutes`](/sv/api/module-options#globallocaleroutes) gör samma sak för vilken sida som helst, med sidans sökväg som nyckel (eller dess route-namn, när det skrivs utan inledande snedstreck):

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    globalLocaleRoutes: {
      '/about': { de: '/ueber-uns' },
      '/about/team': { de: '/ueber-uns/team' },
      '/admin': false, // not localized: one /admin route, no locale prefix
    },
  },
})
```

När en sida sätter `localeRoutes` och `globalLocaleRoutes` har samma nyckel vinner posten i konfigurationen.

## Dynamiska parametrar {#dynamic-params}

Skriv parametrar i valfri Nuxt-form: `[id]`, `[[page]]`, `[...slug]` eller `:id()`. Parameternamnen måste matcha sidfilen.

```ts
// pages/products/[...slug].vue
$defineI18nRoute({
  localeRoutes: {
    en: '/our-products/[...slug]',
    de: '/unsere-produkte/[...slug]',
  },
})
```

Nästlade sidor tar en absolut barnsökväg (`/ueber-uns/team`) eller en sökväg relativ till förälderns lokaliserade sökväg (`team`).

## Länka till lokaliserade sidor {#linking-to-localized-pages}

Länkar löses upp till mål-locale:ns lokaliserade sökväg, oavsett om du skickar ett route-namn eller en vanlig sökväg:

```vue
<template>
  <i18n-link :to="{ name: 'about' }">About</i18n-link>
  <i18n-link to="/about">About</i18n-link>
  <!-- de: both render /de/ueber-uns -->
  <NuxtLink :to="$localePath('/about', 'de')">Deutsch</NuxtLink>
</template>
```

Route-namn kommer från filsökvägen (`pages/about/team.vue` blir `about-team`) om du inte anger ett med `definePageMeta({ name })`.

## Slugs per locale {#per-locale-slugs}

När själva slugen skiljer sig per locale (`/our-products/red-shoe` jämfört med `/de/unsere-produkte/roter-schuh`), tala om för språkväljaren vilka parametrar den ska använda med `$setI18nRouteParams` när datan har laddats:

```vue
<script setup lang="ts">
const { $setI18nRouteParams } = useNuxtApp()
const route = useRoute()

const { data: product } = await useFetch(`/api/products/${route.params.slug}`)

if (product.value) {
  $setI18nRouteParams({
    en: { slug: product.value.slugEn },
    de: { slug: product.value.slugDe },
  })
}
</script>
```

`$switchLocalePath('de')` och `<i18n-switcher>` länkar då till `/de/unsere-produkte/roter-schuh`. Nycklarna är locale-koder, värdena är parametrar efter namn (som i sidfilen).

En väljare i layouten renderas innan sidans asynkrona setup kommer hit, så när renderingen är klar skriver modulen om länkarna i `<i18n-switcher>`, både i `app.vue` och i sidan. Serverns HTML, en besökare utan JavaScript och den första renderingen på klienten stämmer då överens. Sätt parametrarna under SSR för detta: med `lazy` eller `server: false` ändras länkarna först efter hydrering. Nuxts SSR-streaming skickar HTML innan parametrarna är kända, så då behåller länkarna i den första HTML:en URL:ens egna parametrar.

Bara väljarens egna länkar skrivs om. En handskriven `$switchLocalePath`-länk måste renderas efter att parametrarna har satts, så lägg den i sidan som sätter dem, även efter en `await`. I en layout renderas den först: dess server-HTML behåller URL:ens parametrar, och hydreringen varnar för en avvikelse. Använd `<i18n-switcher>` där, med dess slots och `custom*Style`-props för utseendet.

Parametrarna tillhör sidan som satte dem:

- De tas bort när en navigering till en annan sökväg genomförs, så varje sida sätter sina egna. En avbruten navigering lämnar dem kvar.
- Hämta `$setI18nRouteParams` från `useNuxtApp()` eller `useI18n()` i `setup`, även när du anropar den senare i en `useAsyncData`-hanterare. Hämtad där känner funktionen till sin sida: om besökaren har lämnat gör ett sent anrop ingenting.
- Med `keepalive` får en sida tillbaka de parametrar den satte när besökaren återvänder. `useI18nHead` gör likadant.

## Routes som läggs till i pages:extend {#routes-added-in-pagesextend}

Routes som du lägger till i hooken `pages:extend` har ingen sidfil att läsa `$defineI18nRoute` från, och flera av dem delar ofta en gemensam omslutande komponent. En route som läggs till utan `name` får det namn Nuxt skulle ge dess sökväg (`/a/:id()` blir `a-id`), så att språklänkar når den, såvida inte en annan route redan har det namnet; ge den då ett uttryckligt `name`. Ha en enda lista och dela upp den i sidor och `globalLocaleRoutes` med route-namn som nyckel med `splitLocaleRoutes` från `@i18n-micro/utils/split-locale-routes` (lägg till paketet bland dina beroenden):

```ts
// nuxt.config.ts
import { splitLocaleRoutes } from '@i18n-micro/utils/split-locale-routes'

const dynamic = splitLocaleRoutes([
  { name: 'products-tag', path: '/products/:tag', file: '~/pages/_dynamic.vue', paths: { de: '/produkte/:tag' } },
  { name: 'internal', path: '/internal', file: '~/pages/_dynamic.vue', paths: false }, // not localized
])

export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  hooks: {
    'pages:extend'(pages) {
      pages.push(...dynamic.pages)
    },
  },
  i18n: {
    globalLocaleRoutes: dynamic.globalLocaleRoutes,
  },
})
```

Lägg inte lokaliserade sökvägar i `route.meta`: de skulle skickas med i klientens route-tabell.
