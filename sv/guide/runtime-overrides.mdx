---
title: "Runtime-åsidosättningar"
description: "Ändra standard-locale, reserv-locale eller inaktiverade locales per instans av ett bygge, med miljövariabler eller runtimeConfig."
---

Runtime-åsidosättningar låter en byggartefakt köras med olika locale-inställningar per miljö eller tenant, utan att bygga om. Du kan ändra standard-locale, reserv-locale och vilka locales som är inaktiverade. Routing, omdirigeringar, rendering och serverhjälpare använder de åsidosatta värdena, och det gör även webbläsaren på en serverrenderad sida.

## Ange åsidosättningar med miljövariabler {#set-overrides-with-environment-variables}

```bash
NUXT_I18N_DEFAULT_LOCALE=de \
NUXT_I18N_FALLBACK_LOCALE=en \
NUXT_I18N_DISABLED_LOCALES=fr,it \
node .output/server/index.mjs
```

| Variabel | Alias |
| --- | --- |
| `NUXT_I18N_DEFAULT_LOCALE` | `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE` |
| `NUXT_I18N_FALLBACK_LOCALE` | `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE` |
| `NUXT_I18N_DISABLED_LOCALES` (kommaseparerad) | `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES` |

Servern läser dem en gång vid start; starta om för att tillämpa en ändring. På en serverrenderad sida får webbläsaren de lösta värdena från servern. Med `ssr: false` finns ingen serverrendering och webbläsaren har ingen miljö: där gäller endast `runtimeConfig.public.i18nRuntime`, och webbläsaren loggar varningarna nedan.

## Ange åsidosättningar i runtimeConfig {#set-overrides-in-runtimeconfig}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

Ett värde angivet i `runtimeConfig.public.i18nRuntime` vinner över `NUXT_I18N_*`-variabeln för samma fält.

Blanda inte ihop detta med byggtidsvariabeln `DEFAULT_LOCALE`, som ersätter `defaultLocale` under bygget och inte behöver något runtime-stöd.

## Vad som kan och inte kan ändras {#what-can-and-cannot-change}

| Inställning | Vid runtime |
| --- | --- |
| `defaultLocale` | Ja under `prefix` och `no_prefix`. Under `prefix_except_default` och `prefix_and_default` är den fast vid bygget (dess sidor är routes utan prefix); en åsidosättning ignoreras med en varning. |
| `fallbackLocale` | Ja. |
| `disabledLocales` | Lägger till locales som inaktiverats vid bygget; återaktiverar aldrig någon. Byggets standard kan inte inaktiveras under `prefix_except_default` / `prefix_and_default`. |
| `strategy` | Nej. En runtime-strategi ignoreras med en varning; bygg en artefakt per strategi. |

Ogiltiga värden förstör aldrig appen. Varje fall loggar en varning per serverprocess:

- att inaktivera alla locales ignoreras;
- en `defaultLocale` som inte är aktiverad faller tillbaka till den första aktiverade locale;
- en `fallbackLocale` som inte är aktiverad behåller byggvärdet om det är aktiverat, annars finns ingen reserv.

## Läs den gällande konfigurationen {#read-the-effective-config}

```vue
<script setup lang="ts">
const { $getI18nConfig } = useNuxtApp()
const config = $getI18nConfig() // build config with overrides applied
</script>
```

Behandla den som skrivskyddad: på servern delas den av alla förfrågningar och är fryst under utveckling; webbläsarens kopia är inte fryst. Att importera konfigurationen från `#build/i18n.strategy.mjs` ger byggvärdena utan åsidosättningar.

## Inaktiverade locales och statiska filer {#disabled-locales-and-static-files}

En locale som inaktiverats vid runtime svarar 404 på sina routes och sin payload-route, men dess payload-filer finns kvar i `.output/public/_locales/` och en statisk filserver returnerar dem. När de filerna inte får vara nåbara, inaktivera locale vid byggtid med `disabled: true`.
