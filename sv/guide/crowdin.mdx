[Crowdin](https://crowdin.com/) är en översättningsplattform: du laddar upp standard-locale:ns filer, översättarna arbetar i Crowdin och du laddar ned de andra locales tillbaka. Modulen läser vanliga JSON-filer, så Crowdin CLI behöver bara en `crowdin.yml` som mappar `locales/` och `locales/pages/` korrekt. Inga modulinställningar ändras.

## Konfigurera crowdin.yml {#configure-crowdin-yml}

```yml
# crowdin.yml
project_id_env: CROWDIN_PROJECT_ID
api_token_env: CROWDIN_PERSONAL_TOKEN
base_path: ./locales
preserve_hierarchy: true

files:
  - source: /en.json
    translation: /%two_letters_code%.json
  - source: /pages/**/en.json
    translation: /pages/**/%two_letters_code%.json
```

- `en` är din standard-locale; dess filer är källorna.
- `project_id_env` / `api_token_env` läser ID och token från miljövariabler, så ingen hemlighet checkas in.
- `preserve_hierarchy: true` behåller mapparna `pages/<page>/` som de är.
- Den översatta filens namn måste vara samma som locale-`code` i `nuxt.config.ts`. `%two_letters_code%` passar koder som `de`; för koder som `pt-BR` använder du `%locale%`, eller mappar Crowdins koder till dina med `languages_mapping`.

## Uppladdning och nedladdning {#upload-and-download}

```bash
npm install -g @crowdin/cli

export CROWDIN_PROJECT_ID=123456
export CROWDIN_PERSONAL_TOKEN=...   # from Crowdin account settings

crowdin upload sources   # push locales/en.json and locales/pages/**/en.json
crowdin download         # write locales/de.json, locales/pages/**/de.json, ...
```

Kör båda i CI för att hålla filerna aktuella. Nedladdade filer hamnar i ditt repository precis som handredigerade filer; nästa bygge eller omladdning i dev-läge plockar upp dem.

## Innan uppladdning {#before-uploading}

Rensa källorna först så att översättarna inte arbetar med döda nycklar: [`i18n-micro clean`](/sv/api/cli#clean) tar bort oanvända nycklar, [`i18n-micro check`](/sv/api/cli#check) rapporterar luckor efter en nedladdning. CLI:t har ingen egen Crowdin-integration: den här sidan beskriver det sätt som stöds.
