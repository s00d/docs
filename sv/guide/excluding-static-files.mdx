---
title: "Exkludera sökvägar"
description: "Håll sidor och filer utanför locale-routing med excludePatterns, och se vilka sökvägar som redan är exkluderade."
---

Vissa sökvägar får aldrig få ett locale-prefix eller en locale-omdirigering: ett adminområde, en hälsokontroll, ett genererat flöde. `excludePatterns` markerar dem, och en inbyggd lista täcker redan Nuxts interna sökvägar och vanliga statiska filer. En exkluderad sida behåller exakt den sökväg du skrev och renderas fortfarande med `$t`.

## Exkludera en sökväg {#exclude-a-path}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    excludePatterns: [
      '/admin', // /admin and everything below it
      '/preview-*', // glob over the whole path
    ],
  },
})
```

Med den här konfigurationen svarar `pages/admin/index.vue` bara på `/admin`; det finns ingen `/de/admin`, och `/admin` omdirigeras aldrig till `/de/admin`.

## Mönstersyntax {#pattern-syntax}

Mönster matchas mot sökvägen utan `app.baseURL`:

| Mönster | Matchar | Matchar inte |
| --- | --- | --- |
| `'/admin'` | `/admin`, `/admin/users` | `/administrator`, `/de/admin` |
| `'/preview-*'` | `/preview-1`, `/preview-a/b` | `/de/preview-1` |
| `'/file-?'` | `/file-a` | `/file-ab` |
| `/^\/v\d+\//` | `/v2/docs` | `/docs` |

En sträng utan `*` eller `?` matchar sökvägen och hela segment under den. Med `*` (valfri följd av tecken, inklusive snedstreck) eller `?` (ett tecken) måste den matcha hela sökvägen. Börja alltid strängar med `/`.

## Vad som redan är exkluderat {#what-is-excluded-already}

Dessa får aldrig locale-routes eller omdirigeringar, utan någon konfiguration:

- `/api` och `/_nuxt`, och allt under dem;
- översättningsrouten, `/_locales` som standard ([`apiBaseUrl`](/sv/api/module-options#apibaseurl));
- varje sökväg med ett segment som börjar med `__` (`/__nuxt_content`, `/en/__og-image__`);
- `/sitemap*.xml`, `/robots.txt`, `/favicon.ico`, `/apple-touch-icon*.png`, `/manifest.json`, `/sw.js`, `/workbox-*.js`;
- varje sökväg vars sista segment slutar med en filändelse för statiska filer: `xml txt ico json js css png jpg jpeg gif svg webp avif pdf wasm map mp4 webm mp3 zip gz woff woff2 ttf eot`. Sid-slugs med punkter som `/user/john.doe` och `.html`-sökvägar förblir sidor.

## Vad en exkludering gör {#what-an-exclusion-does}

- **Routes:** inga lokaliserade varianter genereras; sidan behålls som den är skriven.
- **Omdirigeringar och 404:or:** serverns omdirigeringsplugin och klientens omdirigeringsmiddleware hoppar över sökvägen.
- **Prerender:** matchande sökvägar tas bort från listan över routes för prerendering.

Den hindrar inte i18n-servermiddlewaren från att identifiera en locale för förfrågan, och den hindrar inte sidan från att använda översättningar. För att behålla en sida lokaliserad men utan SEO-taggar använder du `disableMeta` ([Sidkonfiguration](/sv/guide/per-component-translations#turn-off-seo-tags)). För att hålla en sida olokaliserad via sökväg från `nuxt.config.ts` gör `globalLocaleRoutes: { '/admin': false }` ([Lokaliserade sökvägar](/sv/guide/custom-locale-routes#in-nuxt-config)) samma sak för routingen.
