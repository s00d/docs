Serverhanterare i `server/api/` och `server/routes/` kan översätta strängar och läsa förfrågans locale med två automatiskt importerade hjälpare. Använd dem för API-svar, e-post, flöden eller annat som renderas utanför en Vue-sida. De läser samma översättningsfiler som dina sidor och identifierar locale från förfrågan.

## Översätt i en hanterare {#translate-in-a-handler}

```ts
// server/api/greeting.get.ts
export default defineEventHandler(async (event) => {
  const t = await useTranslationServerMiddleware(event)
  return { message: t('greeting', { name: 'Ada' }) }
})
```

```bash
curl 'http://localhost:3000/api/greeting?locale=de'
# {"message":"Hallo, Ada!"}
```

`useTranslationServerMiddleware(event, defaultLocale?, locale?)` är asynkron och returnerar `t(key, params?, defaultValue?)`. `t` returnerar strängen, interpolerar `{name}`-parametrar och returnerar ett icke-tomt `defaultValue`, annars nyckeln, när nyckeln saknas.

`t` ser bara `index`-chunken: rotfilerna (`locales/<locale>.json`) plus `locales/pages/index/` när den finns (bara rotfilerna med `disablePageLocales`). Nycklar från andra sidor läses inte in. För dem läser du in chunken själv:

```ts
const { data } = await loadTranslationsFromServer('de', 'about') // Translations object of the about page
```

## Läs förfrågans locale {#read-the-request-locale}

```ts
// server/api/locale.get.ts
export default defineEventHandler((event) => {
  const { current, isDefault, locale } = useLocaleServerMiddleware(event)
  return { current, isDefault, dir: locale?.dir ?? 'ltr' }
})
```

`useLocaleServerMiddleware(event, defaultLocale?, locale?)` är synkron och returnerar:

```ts
interface LocaleInfo {
  current: string // detected locale code
  default: string // defaultLocale, runtime overrides included (fixed at build under prefix_except_default / prefix_and_default)
  fallback: string // fallbackLocale, else the default
  available: string[] // enabled locale codes
  locale: Locale | null // the config entry of `current`
  isDefault: boolean
  isFallback: boolean
}
```

## Hur locale väljs {#how-the-locale-is-chosen}

Båda hjälparna använder samma ordning på varje serverroute, oavsett om det är `/api` eller inte:

1. query-parametern `?locale=` (första värdet om den upprepas);
2. en `[locale]`-routeparameter, eller ett locale-prefix i sökvägen (`/de/...`);
3. locale-cookien, när [`localeCookie`](/sv/api/module-options#localecookie) är satt (`hash-locale` under `hashMode`);
4. `Accept-Language`, när `autoDetectLanguage` är påslaget (q-värden respekteras);
5. `defaultLocale`.

Ogiltiga och inaktiverade koder hoppas över i varje steg. Detta är API-ordningen; en sidrendering ignorerar `?locale=` under prefix-strategierna. Båda ordningarna jämförs under [Locale-detektering](/sv/guide/locale-detection).

## Tvinga en locale {#force-a-locale}

Skicka det tredje argumentet för att hoppa över detekteringen, till exempel i ett jobb som skickar e-post på användarens språk:

```ts
export default defineEventHandler(async (event) => {
  const user = await getUser(event) // your code
  const t = await useTranslationServerMiddleware(event, undefined, user.locale)
  return sendMail(user.email, t('mail.welcome.subject'))
})
```

Det andra argumentet ersätter `defaultLocale` för detta anrops detektering, så det har ingen effekt när en locale tvingas. Ordlistor cachas per förfrågan och per locale, och mellan förfrågningar i serverns översättningscache, så det är billigt att anropa en hjälpare flera gånger.

## Serverkomponenter {#server-components}

En serverkomponent (`.server.vue`, `<NuxtIsland>`) renderas från sin egen URL, `/__nuxt_island/...`, så den ser inte sidans URL, och Nuxt skickar bara dess props till den. Skicka locale som en `locale`-prop. Den renderas då i den locale:n, och ett byte hämtar den på nytt, eftersom props ingår i islandens URL och cachenyckel. Namnet är reserverat: varje aktiverad locale-kod i en prop som heter `locale` sätter renderingens locale, så ge en prop som betyder något annat, till exempel ett talformat, ett annat namn:

```vue
<!-- components/Greeting.server.vue -->
<template><p>{{ $t('greeting') }}</p></template>
<script setup lang="ts">
defineProps<{ locale?: string }>()
</script>
```

```vue
<template>
  <Greeting :locale="$getLocale()" />
  <NuxtIsland name="Greeting" :props="{ locale: $getLocale() }" />
</template>
```

Utan propen renderas den i cookiens locale, annars i standard-locale:n, oavsett vad URL:en säger, och den följer inte ett byte. Dess `$t` ser `index`-chunken: rotfilerna plus `locales/pages/index/`.
