Paketen `@i18n-micro/*` tar översättningskärnan i Nuxt I18n Micro till Vue, React, Preact, Solid, Astro, VitePress och ren JavaScript. Använd dem när din app inte är en Nuxt-app, eller när ett skript eller en server utanför Nuxt behöver samma översättningsfiler. Alla paket delar en instansmodell, ett kontrakt för routeradaptrar och samma fyra komponenter, som beskrivs en gång på den här sidan.

Router-ingången är en separat import, så en app utan router paketerar aldrig någon.

`@i18n-micro/core`, `@i18n-micro/types` och `@i18n-micro/utils` installeras med dessa paket; du importerar dem sällan direkt. Signaturerna för alla exporter finns i den genererade [paketreferensen](/sv/api/packages/overview).

Varje paket har en playground under `packages/<name>/playground` i repositoryt.

## Instansen {#the-instance}

`createI18n(options)` returnerar en instans som innehåller ordlistorna, den aktuella locale:n och den aktuella routen. Alternativen är desamma i alla paket:

| Alternativ | Typ | Standard | Anmärkningar |
| --- | --- | --- | --- |
| `locale` | `string` | obligatorisk | Aktiv locale. |
| `fallbackLocale` | `string` | `locale` | Används när en nyckel saknas i `locale`. |
| `messages` | `Record<locale, Translations>` | `{}` | Rotordlistor (routen `'index'`). |
| `routeMessages` | `Record<route, Record<locale, Translations>>` | `{}` | Route-ordlistor. Endast Runtime, React, Preact, Node och VitePress. |
| `plural` | `PluralFunc` | `defaultPlural` | Egen pluralregel. |
| `missingWarn` | `boolean` | `true` | `console.warn` i webbläsaren för en saknad nyckel, endast i dev-läge. |
| `missingHandler` | `(locale, key, routeName) => void` | — | Anropas i stället för varningen. |
| `numberFormats` | `Record<locale, Record<name, Intl.NumberFormatOptions>>` | — | Namngivna format: `tn(9.5, 'currency')`. |
| `datetimeFormats` | `Record<locale, Record<name, Intl.DateTimeFormatOptions>>` | — | Namngivna format: `td(date, 'short')`. |
| `timeZone` | `string` | körmiljöns zon | IANA-zon för `td`-datum; den påverkar inte `tdr`. Sätt den så att server och webbläsare renderar samma datum. |
| `now` | `() => number` | `Date.now` | Klockan för `tdr`. Ge hydreringen serverns tid så att båda renderar samma text. |
| `localeIso` | `Record<code, string>` | — | BCP 47-tagg som används för pluralregler (`ua` → `uk-UA`). React, Preact och Solid hämtar den från `iso` i providerns `locales`. |

Ordlistorna finns i `i18n.storage.translations`, en `Map` med nycklar på formen `locale:route` (`en:index`, `en:about`).

En nyckel slås upp i den aktuella routens ordlista och sedan i rotordlistan, först för `locale` och sedan för `fallbackLocale`. En saknad nyckel returnerar själva nyckeln (eller det `defaultValue` du skickar).

```ts
i18n.addTranslations('en', { nav: { home: 'Home' } }) // root, deep-merged
i18n.addRouteTranslations('en', 'about', { title: 'About us' }) // route chunk
i18n.addTranslations('en', { nav: { home: 'Start' } }, false) // replace instead of merge
i18n.setRoute('about')
i18n.t('title') // 'About us'
i18n.t('nav.home') // 'Start' (root key, still visible on the route)
```

### Översätt och formatera {#translate-and-format}

| Metod | Returnerar |
| --- | --- |
| `t(key, params?, defaultValue?, routeName?)` | Värdet (sträng, tal, objekt) med `{param}` interpolerat. |
| `ts(...)` | Samma som `t`, som en sträng. |
| `tc(key, count \| params, defaultValue?)` | Pluralform. |
| `tn(value, options \| name)` | `Intl.NumberFormat` i den aktiva locale:n. |
| `td(value, options \| name)` | `Intl.DateTimeFormat`. |
| `tdr(value, options?)` | Relativ tid (`3 days ago`). |
| `has(key, routeName?)` | `true` när den aktiva locale:n har nyckeln (route- eller rotordlista; reservlocale:n kontrolleras inte). |

`defaultPlural` delar värdet vid `|` och väljer formen på index `count`, begränsat till den sista; ett negativt, decimalt eller `NaN`-värde för count väljer den sista formen.

En egen `plural` tar emot `(key, count, params, locale, getter)`. Läs värdet via `getter(key)`; dela inte nyckeln:

```ts
import type { PluralFunc } from '@i18n-micro/vue'

const plural: PluralFunc = (key, count, params, _locale, getter) => {
  const value = getter(key)
  if (typeof value !== 'string') return null
  const forms = value.split('|').map((form) => form.trim())
  return (count === 1 ? forms[0] : forms[1] ?? forms[0])!.replace('{count}', String(count))
}
```

## Routeradapter {#router-adapter}

SPA-paketen är inte beroende av en router. En routeradapter (`I18nRoutingStrategy`) talar om för dem hur de läser den aktuella sökvägen, navigerar och bygger en lokaliserad sökväg. De inbyggda adaptrarna lägger till prefix för varje locale utom `defaultLocale` (`/about`, `/de/about`).

| Medlem | Obligatorisk | Används av |
| --- | --- | --- |
| `getCurrentPath(): string` | ja | kontroll av aktiv länk (per sida, query och hash räknas inte), `switchLocale` (behåller dem) |
| `push({ path }): void` | ja | `switchLocale`, `<I18nLink>` utan `linkComponent`, `<I18nSwitcher>` |
| `replace({ path }): void` | ja | — |
| `resolvePath(to, locale)` | nej | `localePath`, `localeRoute`, `<I18nLink>`; utan den returneras sökvägar som de är |
| `linkComponent` | nej | `<I18nLink>` renderar den (t.ex. `RouterLink`) i stället för `<a>` |
| `getRoute()` | nej | `{ fullPath, query }` för SEO-hjälpare |

`push` och `replace` är obligatoriska i Vue, React, Preact och Solid. Astro har en egen adapter på serversidan med valfria `push`/`replace` (se [Astro](/sv/integrations/astro-package#router-adapter)).

En minimal adapter för valfri historikbaserad router:

```ts
import type { I18nRoutingStrategy } from '@i18n-micro/react'

const locales = ['en', 'de']
const stripLocale = (path: string) => path.replace(/^\/(en|de)(?=\/|$)/, '') || '/'

export const historyAdapter: I18nRoutingStrategy = {
  getCurrentPath: () => window.location.pathname + window.location.search + window.location.hash,
  push: ({ path }) => window.history.pushState({}, '', path),
  replace: ({ path }) => window.history.replaceState({}, '', path),
  resolvePath: (to, locale) => {
    const path = stripLocale(typeof to === 'string' ? to : to.path || '/')
    return locale === 'en' ? path : `/${locale}${path === '/' ? '' : path}`
  },
}
```

## Komponenter {#components}

Vue, React, Preact och Solid levereras med samma fyra komponenter. Deras props är desamma; React, Preact och Solid skickar vidare övriga props till rotelementet.

### `<I18nT>` {#&lt;i18nt&gt;}

| Prop | Typ | Anmärkningar |
| --- | --- | --- |
| `keypath` | `string` | obligatorisk |
| `params` | `object` | interpolationsvärden |
| `plural` | `number \| string` | renderar `tc(keypath, count)` |
| `number` | `number \| string` | skickar `tn(number)` som `{number}` |
| `date` | `Date \| string \| number` | skickar `td(date)` som `{date}` |
| `relativeDate` | `Date \| string \| number` | skickar `tdr(relativeDate)` som `{relativeDate}` |
| `tag` | `string` | omslutande element, standard `span` |
| `html` | `boolean` | rendera översättningen som HTML; den måste vara betrodd, params escapas |
| `defaultValue` | `string` | ersätter en saknad nyckel, och renderas utan omslutning när `hideIfEmpty` döljer ett tomt värde |
| `hideIfEmpty` | `boolean` | rendera ingenting för en tom översättning |
| `customPluralRule` | `PluralFunc` | pluralregel för detta element |

Bara en formateringsprop tillämpas, kontrollerade i denna ordning: `number`, `date`, `relativeDate`, `plural`.

#### Rik text {#rich-text}

En `{placeholder}` kan innehålla ett element. I Vue är det en namngiven slot; i React, Preact och Solid anger propen `components` element, eller funktioner som returnerar ett, efter namn. I båda fallen vinner det över en param med samma namn, fungerar i varje gren och överlever en locale som ändrar ordningen på platshållarna.

```tsx
// { "terms": "I accept the {link} of {company}" }
<I18nT keypath="terms" params={{ company: 'ACME' }} components={{ link: <a href="/terms">terms</a> }} />
```

I Solid skickar du en funktion när en platshållare upprepas: en nod kan bara stå på ett ställe. `children` ersätter texten, och som funktion får de `{ translation }`, som Vues standardslot. `html` ignorerar allt detta.

### `<I18nLink>` {#&lt;i18nlink&gt;}

| Prop | Typ | Anmärkningar |
| --- | --- | --- |
| `to` | `string \| { path }` | lokaliseras via adapterns `resolvePath` |
| `activeStyle` | stilobjekt | slås ihop ovanpå `style` på den aktuella sidan; React, Preact och Solid tillämpar det även på en överordnad sektion |
| `localeRoute` | funktion | åsidosätter `resolvePath` för denna länk |

Externa URL:er (`https://`, `mailto:`, `tel:`) renderas som `<a target="_blank" rel="noopener noreferrer">`; ett eget `target` eller `rel` vinner. `onClick` körs alltid. Ett klick med modifierartangent, en annan musknapp eller ett `target` lämnas åt webbläsaren.

### `<I18nSwitcher>` {#&lt;i18nswitcher&gt;}

En rullgardinsmeny med aktiverade locales (locales med `disabled: true` döljs) med inbäddade standardstilar. Dess objekt är länkar, med `lang`, `hreflang` och `dir` från locale:n. Som standard sätter ett klick på ett objekt locale och anropar adapterns `push` med den lokaliserade aktuella sökvägen; en `switchLocale`-prop ersätter den åtgärden. Med en `localeRoute` och ingen router följer webbläsaren länken. Escape eller ett klick utanför stänger den.

| Prop | Anmärkningar |
| --- | --- |
| `locales`, `currentLocale`, `getLocaleName` | åsidosätter de tillhandahållna värdena |
| `switchLocale(code)` | ersätter det inbyggda bytet |
| `localeRoute` | ersätter `resolvePath` |
| `customLabels` | `{ de: 'DE' }` |
| `customWrapperStyle`, `customButtonStyle`, `customDropdownStyle`, `customItemStyle`, `customLinkStyle`, `customActiveLinkStyle`, `customDisabledLinkStyle`, `customIconStyle` | stilåsidosättningar |

### `<I18nGroup>` {#&lt;i18ngroup&gt;}

En `<div class="i18n-group">` som ger en `t` med prefix till sina barn. Den lägger **inte** till prefix för `<I18nT>` eller `t()`-anrop inuti den; bara den `t` som den skickar nedåt har prefix.

| Prop | Anmärkningar |
| --- | --- |
| `prefix` | obligatorisk, t.ex. `'profile'` |
| `groupClass` | extra klass på det omslutande elementet |

Den `t` som har prefix kommer via en scoped slot i Vue (`v-slot="{ t }"`) och ett render-prop-barn i React, Preact och Solid (`{({ t }) => …}`).

## Typade nycklar {#typed-keys}

`t()` accepterar vilken sträng som helst. För att få autokomplettering för dina nycklar genererar du en deklaration med [typgeneratorn](/sv/integrations/types-generator). Nycklarna föreslås men tvingas inte fram, och params är inte typade.

## Jämfört med Nuxt-modulen {#compared-with-the-nuxt-module}

Paketen har ingen filbaserad routing, ingen server-middleware och ingen översättningsladdare: du bestämmer när JSON ska läsas in (`import`, `fetch` eller `@i18n-micro/node` på servern) och vilken routeradapter som ska användas. Locale-detektering, SEO-meta och generering av routes är Nuxt-funktioner; Astro har en egen middleware för detektering och `useLocaleHead` för SEO.
