# Integrationer

`@i18n-micro`-paketen är lättviktiga, ramverksspecifika versioner av Nuxt I18n Micro utformade för integration i olika ramverk och miljöer. Dessa paket tillhandahåller grundläggande internationaliseringsfunktionalitet med minimalt fotavtryck och fokuserar på väsentliga översättningsfunktioner och grundläggande komponenter.

## Översikt

Dessa integrationspaket är **miniversioner** av den fullständiga Nuxt I18n Micro-modulen och innehåller endast den väsentliga funktionalitet som behövs för internationalisering:

- **Kärnfunktioner för översättning** - Grundläggande översättningsmetoder, pluralisering och formatering
- **Väsentliga komponenter** - En liten uppsättning UI-komponenter för vanliga i18n-uppgifter
- **Router-adapter-mönster** - Flexibel routingintegration via adapterabstraktion
- **TypeScript-stöd** - Fullständiga typdefinitioner för typsäker utveckling

Till skillnad från den fullständiga Nuxt-modulen, dessa paket:

- Inkluderar inte ramverksspecifik routing-logik
- Kräver att du implementerar en router-adapter för routingfunktioner
- Fokuserar på översättningsfunktionalitet snarare än ramverksintegration
- Är utformade för att vara lättviktiga och där det är möjligt ramverksoberoende

## Kärnkomponenter

Alla ramverkspaket inkluderar följande väsentliga komponenter:

### `<I18nT>`

En översättningskomponent som renderar översatt text med stöd för:

- **Parameter-interpolation** - Ersätt platshållare med dynamiska värden
- **Pluralisering** - Automatiskt val av pluralform baserat på antal
- **Nummerformatering** - Formatera tal enligt lokal
- **Datumformatering** - Formatera datum och relativa tider
- **HTML-rendering** - Valfri HTML-innehållsrendering
- **Standardvärden** - Fallback-text när översättning saknas

**Exempel:**

```vue
<!-- Vue -->
<I18nT keypath="greeting" :params="{ name: 'World' }" />
```

```tsx
// React
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```tsx
// Solid
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```astro
<!-- Astro -->
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

### `<I18nLink>`

En lokaliserad länkkomponent som automatiskt hanterar lokalprefix i URL:er. Funktioner:

- **Automatisk sökvägslokalisering** - Lägger till/tar bort lokalprefix baserat på routingstrategi
- **Detektering av aktivt tillstånd** - Markerar aktuell rutt
- **Stöd för externa länkar** - Upptäcker och hanterar automatiskt externa URL:er
- **Router-integration** - Använder router-adapterns länkkomponent när tillgänglig
- **Anpassad styling** - Stödjer aktiva och hover-tillstånd

**Exempel:**

```vue
<!-- Vue -->
<I18nLink to="/about" active-class="active">
  About Us
</I18nLink>
```

```tsx
// React
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```tsx
// Solid
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```astro
<!-- Astro -->
<I18nLink href="/about" class="nav-link">
  About Us
</I18nLink>
```

### `<I18nSwitcher>`

En språkväxlarkomponent som tillhandahåller en rullgardin eller ett listgränssnitt för att byta lokaler. Funktioner:

- **Automatisk lokallista** - Genererar alternativ från konfigurerade lokaler
- **Markering av aktuell lokal** - Indikerar visuellt det aktiva språket
- **Anpassade etiketter** - Stöd för anpassade visningsnamn per lokal
- **Router-integration** - Navigerar automatiskt till lokaliserade sökvägar
- **Tillgänglighet** - Korrekta ARIA-attribut och tangentbordsnavigering

**Exempel:**

```vue
<!-- Vue -->
<I18nSwitcher />
```

```tsx
// React
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```tsx
// Solid
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```astro
<!-- Astro -->
<I18nSwitcher />
```

### `<I18nGroup>`

En komponent för att gruppera översättningar med ett gemensamt prefix, användbar för att organisera översättningar per sida eller funktion. Funktioner:

- **Prefix-scoping** - Lägger automatiskt till prefix till alla översättningsnycklar inom gruppen
- **Nästlade grupper** - Stöd för nästlade översättningsgrupper
- **Ren organisation** - Hjälper till att bibehålla organiserade översättningsstrukturer

**Exempel:**

```vue
<!-- Vue -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

```tsx
// React
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```tsx
// Solid
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```astro
<!-- Astro -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

## Delade `createI18n`-alternativ \{#create-i18n-options\}

Varje ramverkspaket skapas på samma sätt — endast alternativtypen är namngiven efter ramverket (`ReactI18nOptions`, `SolidI18nOptions` och så vidare). Själva alternativen är identiska:

| Egenskap         | Typ                                                        | Krävs | Standard         | Beskrivning                                    |
| ---------------- | ---------------------------------------------------------- | ----- | ---------------- | ---------------------------------------------- |
| `locale`         | `string`                                                   | ✅    | -                | Aktuell lokalkod (till exempel `'en'`)         |
| `fallbackLocale` | `string`                                                   | ❌    | Samma som `locale` | Fallback-lokal när översättning saknas       |
| `messages`       | `Record<string, Translations>`                             | ❌    | `\{\}`           | Initiala översättningsmeddelanden              |
| `plural`         | `PluralFunc`                                               | ❌    | `defaultPlural`  | Anpassad pluraliseringsfunktion                |
| `missingWarn`    | `boolean`                                                  | ❌    | `true`           | Visa konsollvarningar för saknade översättningar |
| `missingHandler` | `(locale: string, key: string, routeName: string) => void` | ❌    | -                | Anpassad hanterare för saknade översättningar  |

Allt utöver dessa är ramverksspecifikt och dokumenteras på det paketets sida.

## Router-adapter-abstraktion

Alla ramverkspaket använder ett **router-adapter-mönster** för att frikoppla i18n-funktionalitet från specifika router-implementationer. Denna design tillåter:

- **Flexibilitet** - Använd valfritt router-bibliotek eller ingen router alls
- **Ramverksoberoende** - Behåll routing-logik i din applikation, inte i i18n-paketet
- **Lättviktig kärna** - i18n-paketet förblir litet och fokuserat

### Implementera en router-adapter

För att använda routingfunktioner behöver du implementera gränssnittet `I18nRoutingStrategy`:

```typescript
interface I18nRoutingStrategy {
  getCurrentPath: () => string
  linkComponent?: Component
  push: (target: { path: string }) => void
  replace: (target: { path: string }) => void
  resolvePath?: (to: string | { path?: string }, locale: string) => string | { path?: string }
  getRoute?: () => { fullPath: string; query: Record<string, unknown> }
}
```

- **Vue**: Exempel på Vue Router-adapter

## Kärnfunktioner

Alla paket delar dessa kärnfunktioner:

### Översättningsmetoder

- `t()` - Grundläggande översättning med parameter-interpolation
- `ts()` - Översättning som alltid returnerar en sträng
- `tc()` - Pluraliseringsmedveten översättning
- `tn()` - Nummerformatering
- `td()` - Datumformatering
- `tdr()` - Formatering av relativ tid
- `has()` - Kontrollera om översättningsnyckel finns

### Lokalhantering

- **Lokalbyte** - Byt aktuell lokal programmatiskt
- **Fallback-lokal** - Automatisk fallback när översättning saknas
- **Ruttspecifika översättningar** - Organisation av översättningar på sidnivå
- **Cachning av översättningar** - Intelligent caching för prestanda

### TypeScript-stöd

Alla paket tillhandahåller:

- Fullständiga TypeScript-definitioner
- Typsäkra översättningsnycklar (med types-generator)
- IntelliSense-stöd i IDE:er
- Kompileringstidskontroll av fel
