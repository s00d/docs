`@i18n-micro/vue` är ett Vue 3-plugin med översättningskärnan från Nuxt I18n Micro: reaktiv `t()`, global `$t`, fyra komponenter och en valfri vue-router-adapter. Använd det i en Vite- eller SSR-app med Vue som inte är byggd med Nuxt. Instansmodellen, routerkontraktet och komponenternas props delas med de andra paketen och beskrivs i [Ramverk](/sv/integrations/overview).

## Installation {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vue
```

```bash npm
npm install @i18n-micro/vue
```

```bash yarn
yarn add @i18n-micro/vue
```

</CodeGroup>

Peer-beroenden: `vue` `^3.3.0`; `vue-router` `^4.5.1 || ^5.0.0` (valfritt, endast för `@i18n-micro/vue/router`). De publicerade typerna kräver Vue 3.5.5 eller senare med `skipLibCheck: false`; med `skipLibCheck: true`, den vanliga mallinställningen, kompilerar även äldre versioner.

## Konfiguration {#setup}

```ts
// src/main.ts
import { createApp } from 'vue'
import { createI18n } from '@i18n-micro/vue'
import App from './App.vue'
import en from './locales/en.json'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales: [
    { code: 'en', iso: 'en-US', displayName: 'English' },
    { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
  ],
  defaultLocale: 'en',
})

createApp(App).use(i18n).mount('#app')
```

`locales` och `defaultLocale` krävs för `useI18n()`: den kastar `I18nLocalesKey not provided` utan dem. Skicka dem till `createI18n` (som ovan), till `useI18n({ locales, defaultLocale })` eller via `app.provide(I18nLocalesKey, …)` och `app.provide(I18nDefaultLocaleKey, …)`.

Pluginet registrerar `I18nT`, `I18nLink`, `I18nGroup` och `I18nSwitcher` globalt och lägger till `$t`, `$ts`, `$tc`, `$tn`, `$td`, `$tdr`, `$has` och `$i18n` i mallar. Utanför komponenter är instansen `i18n.global`. Övriga alternativ finns under [instansen](/sv/integrations/overview#the-instance); `routeMessages` är inte tillgängligt i Vue, använd `addRouteTranslations`.

## Översätta {#translate}

```vue
<script setup lang="ts">
import { useI18n } from '@i18n-micro/vue'

const { t, tc, tn } = useI18n()
</script>

<template>
  <h1>{{ t('greeting', { name: 'Ada' }) }}</h1>
  <!-- Hello, Ada! -->
  <p>{{ tc('apples', 3) }}</p>
  <!-- 3 apples -->
  <p>{{ $t('nav.home') }} · {{ tn(1234.5) }}</p>
</template>
```

`useI18n()` returnerar översättningsmetoderna (`t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`), `locale` (en skrivbar computed), `getLocale`, `getLocales`, `defaultLocale()`, `getLocaleName`, `localePath`, `localeRoute`, `switchLocale`, `setRoute`, `getRoute`, `addTranslations`, `addRouteTranslations`, `mergeTranslations`, `resolveTranslations`, `setTranslation`, `clearCache` och `instance`.

Läs in fler ordlistor när som helst; varje komponent som läser dem renderas om:

```ts
const { addTranslations, addRouteTranslations, setRoute } = useI18n()

addTranslations('de', (await import('./locales/de.json')).default)
addRouteTranslations('en', 'about', { title: 'About us' })
setRoute('about') // t('title') now reads the 'about' dictionary first
```

## Byta locale {#switch-locale}

```ts
const { locale, switchLocale } = useI18n()

locale.value = 'de' // only the locale
switchLocale('de') // the locale, then router.push to the localized current path
```

Läs in localens ordlista före eller efter bytet; ett byte hämtar ingenting.

`<I18nGroup>` ger sin slot en `t` med prefix. Nycklar inuti `<I18nT>` eller i en vanlig `t()` får inget prefix:

```vue
<I18nGroup prefix="profile" v-slot="{ t }">
  <h2>{{ t('title') }}</h2>
  <!-- profile.title -->
</I18nGroup>
```

## Routning {#routing}

Vue-router-adaptern ligger i en undersökväg så att huvudingången aldrig importerar `vue-router`:

```ts
// src/main.ts
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import { createI18n } from '@i18n-micro/vue'
import { createVueRouterAdapter } from '@i18n-micro/vue/router'
import App from './App.vue'
import Home from './pages/Home.vue'
import About from './pages/About.vue'
import en from './locales/en.json'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English' },
  { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
]

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/:locale(de)?', component: Home },
    { path: '/:locale(de)?/about', component: About },
  ],
})

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales,
  defaultLocale: 'en',
  routingStrategy: createVueRouterAdapter(router, locales, 'en'),
})

createApp(App).use(router).use(i18n).mount('#app')
```

`createVueRouterAdapter(router, locales, defaultLocale)` lägger till prefix för alla locales utom standard-locale (`/about`, `/de/about`) och renderar `<I18nLink>` som `RouterLink`. Läs själv av locale från routen, till exempel i `router.beforeEach`, och sätt `i18n.global.locale.value`. Du kan också koppla en adapter senare med `i18n.setRoutingStrategy(adapter)`; för en egen adapter, se [Routeradapter](/sv/integrations/overview#router-adapter).

## SSR {#ssr}

- Skapa routern, i18n-instansen och appen inuti renderingsfunktionen per begäran. En delad instans skulle läcka en besökares locale till en annan.
- Använd `createMemoryHistory()` på servern, ta locale från URL:en och läs in dess ordlista (och reservens) före `renderToString`.
- Skicka locale till klienten (till exempel i ett `window.__STATE__`-skript) och skapa klientinstansen med samma `locale` så att hydreringen stämmer.
- `<I18nSwitcher>` läser `window.location` endast när rullgardinsmenyn är öppen, så den renderas på servern.

`packages/vue/playground` har ett komplett par av `entry-server.ts` / `entry-client.ts`.

## SEO-head {#seo-head}

`useLocaleHead(options)` bygger taggarna `lang`/`dir`, canonical, `hreflang` och `og:locale` utifrån locales och routeradaptern. Anropa `updateMeta()` när routen ändras och skicka `metaObject` till din head-hanterare:

```ts
import { watch } from 'vue'
import { useRoute } from 'vue-router'
import { useHead } from '@unhead/vue'
import { useLocaleHead } from '@i18n-micro/vue'

const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
watch(() => route.fullPath, () => updateMeta(), { immediate: true })
useHead(metaObject)
```

Alternativ: `baseUrl` (sträng eller funktion), `addDirAttribute` (standard `true`), `addSeoAttributes` (standard `true`), `identifierAttribute` (standard `'id'`), `hreflangBaseLanguage` (standard `false`). Locales med `disabled: true` eller `seo: false` får ingen alternate-länk.
