title: "Typgenerator"
description: "Generera TypeScript-autokomplettering för översättningsnycklar från dina JSON-filer, i Nuxt eller i valfritt Vite-projekt."
---

`@i18n-micro/types-generator` läser varje JSON-fil i din översättningsmapp och skriver en deklaration som listar alla nycklar. Lägg till det när du vill att din editor ska föreslå nycklar i `t()`, `$t()` och `<I18nT keypath>`. Det fungerar som en Nuxt-modul och som ett Vite- eller Rollup-plugin, och genererar om när en fil ändras.

## Installera {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/types-generator
```

```bash npm
npm install -D @i18n-micro/types-generator
```

```bash yarn
yarn add -D @i18n-micro/types-generator
```

</CodeGroup>

Peer-beroende: `@nuxt/kit` `^3.18.0 || ^4.0.0`. Endast ingångspunkten `/nuxt` importerar det; i ett rent Vite-projekt kan peer-varningen ignoreras.

## Nuxt {#nuxt}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro', '@i18n-micro/types-generator/nuxt'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Modulen skriver `.nuxt/types/i18n-micro.d.ts` och Nuxt lägger till den i typkontexten; inget behöver inkluderas för hand. Den läser `i18nTypes.translationDir`, annars där `nuxt-i18n-micro` läser översättningar: `translationDir` (från `i18n` eller inline-modulalternativ, standard `'locales'`) i varje lager, samt `additionalTranslationDirs`. När du redigerar en JSON-fil i den mappen genereras typerna om i `nuxi dev`. `i18nTypes.outputFile` ignoreras i Nuxt (en varning talar om det).

## Vite {#vite}

`I18nTypesPlugin` är ett Vite-plugin, som Rollup också accepterar. För en annan bundler anropar du `generateTypes` i ett skript.

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { I18nTypesPlugin } from '@i18n-micro/types-generator'

export default defineConfig({
  plugins: [
    vue(),
    I18nTypesPlugin({
      srcDir: process.cwd(),
      translationDir: 'src/locales',
      outputFile: 'src/i18n-micro.d.ts',
    }),
  ],
})
```

| Alternativ | Obligatoriskt | Anmärkningar |
| --- | --- | --- |
| `srcDir` | ja | Baskatalog; `translationDir` löses relativt till den. |
| `translationDir` | ja | Mapp med JSON-filerna (undermappar som `pages/` inkluderas), eller en array av mappar. |
| `outputFile` | nej | Var deklarationen skrivs; standard `<srcDir>/i18n-micro.d.ts`. |

Pluginet genererar en gång när bygget startar och, på utvecklingsservern, genererar om 300 ms efter en ändring i mappen. Se till att `include` i din `tsconfig.json` täcker utdatafilen.

## Använd nycklarna {#use-the-keys}

Den genererade filen utökar `DefineLocaleMessage` i `@i18n-micro/types`, vilket gör `TranslationKey` till dina nycklar:

```ts
declare module '@i18n-micro/types' {
  export interface DefineLocaleMessage {
    nav: object
    'nav.home': string
    'profile.title': string
  }
}
```

Nycklarna är de som `t()` svarar på, även objekt, från varje locale och varje sidfil, med typen för sitt JSON-värde. `TranslationKey` är unionen av dessa nycklar plus vilken sträng som helst, så du får autokomplettering, inte fel: en felstavad eller dynamisk nyckel kompilerar ändå. Parametrar och returvärden är inte typade.

För dynamiska nycklar under ett känt prefix begränsar `ScopedKey<'prefix'>` till de matchande nycklarna:

```ts
import type { ScopedKey } from '@i18n-micro/types'

const statusText = (status: string) => t(`status.${status}` as ScopedKey<'status'>)
```

`TranslationKey` och `ScopedKey` kommer från `@i18n-micro/types` (React, Preact och Solid återexporterar `TranslationKey`; Vue gör det inte).

## API {#api}

| Export | Ingångspunkt | Anmärkningar |
| --- | --- | --- |
| `I18nTypesPlugin(options)` | `@i18n-micro/types-generator` | Vite- och Rollup-plugin |
| `generateTypes(options)` | `@i18n-micro/types-generator` | skriver filen, returnerar dess sökväg |
| `getTypesString(options)` | `@i18n-micro/types-generator` | returnerar deklarationen utan att skriva |
| `formatKeyProperty(key)` | `@i18n-micro/types-generator` | hjälpfunktion |
| Nuxt-modul (`configKey: 'i18nTypes'`) | `@i18n-micro/types-generator/nuxt` | alternativet `translationDir` |

Fullständiga signaturer: [paketreferens](/sv/api/packages/types-generator).
