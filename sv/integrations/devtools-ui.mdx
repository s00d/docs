# DevTools UI-paket (`@i18n-micro/devtools-ui`)

Paketet `@i18n-micro/devtools-ui` tillhandahåller ett fristående utvecklarverktygsgränssnitt för att hantera översättningar. Det inkluderar en Vite-plugin för automatisk integration och ett universellt bryggsystem för ramverksagnostiskt i18n-stöd.

## Översikt

`@i18n-micro/devtools-ui` är ett självständigt paket som tillhandahåller:

- **Vite-plugin** - Automatisk knappinjektion och API-slutpunkter
- **Universell brygga** - Ramverksagnostisk bryggskapning för valfri i18n-implementation
- **Web Component** - Anpassat element för DevTools-UI:t
- **Filoperationer** - Lista, ladda och spara översättningsfiler via API

## Snabbstart

### Uppsättning av Vite-plugin

Det enklaste sättet att använda DevTools är via Vite-pluginen, som automatiskt injicerar en flytande knapp och tillhandahåller alla nödvändiga API-slutpunkter:

```typescript
import { defineConfig } from 'vite'
import { i18nDevToolsPlugin } from '@i18n-micro/devtools-ui/vite'

export default defineConfig({
  plugins: [
    // ... other plugins
    i18nDevToolsPlugin({
      base: '/__i18n_api', // Optional: API endpoint base path (default: '/__i18n_api')
      translationDir: 'src/locales', // Optional: translation files directory
      injectButton: true, // Optional: automatically inject floating button (default: true)
    }),
  ],
})
```

### Plugin-alternativ

```typescript
interface DevToolsPluginOptions {
  base?: string // API endpoint base path (default: '/__i18n_api')
  translationDir?: string // Translation files directory (default: 'src/locales')
  injectButton?: boolean // Automatically inject floating button (default: true)
}
```

## Funktioner

### Automatisk knappinjektion

Pluginen injicerar automatiskt en flytande knapp i det nedre högra hörnet av din applikation:

- **Smart döljning** - Knappen döljs när markören är långt borta (>200px)
- **Delvis synlighet** - Även när den är dold förblir en liten del synlig för enkel åtkomst
- **Smidiga animeringar** - Övergångar och hover-effekter för bättre UX
- **Autovisning vid hover** - Knappen visas helt när du hovrar över den synliga delen

### API-slutpunkter

Pluginen tillhandahåller följande API-slutpunkter:

#### `GET /__i18n_api/files`

Hämta lista över alla översättningsfiler och katalogstruktur.

**Svar:**

```json
{
  "files": ["en.json", "fr.json", "pages/home/en.json"],
  "structure": {
    "en.json": "en.json",
    "fr.json": "fr.json",
    "pages": {
      "home": {
        "en.json": "pages/home/en.json"
      }
    }
  }
}
```

#### `GET /__i18n_api/file?path=...`

Ladda en specifik översättningsfil.

**Query-parametrar:**

- `path` - Relativ sökväg till översättningsfilen (till exempel `en.json` eller `pages/home/en.json`)

**Svar:**

```json
{
  "success": true,
  "content": {
    "welcome": "Welcome",
    "hello": "Hello"
  },
  "path": "en.json"
}
```

#### `POST /__i18n_api/save`

Spara översättningsinnehåll till en fil.

**Request Body:**

```json
{
  "file": "en.json",
  "content": {
    "welcome": "Welcome",
    "hello": "Hello"
  }
}
```

**Svar:**

```json
{
  "success": true
}
```

#### `GET /__i18n_api/config`

Hämta i18n-konfiguration.

**Svar:**

```json
{
  "defaultLocale": "en",
  "fallbackLocale": "en",
  "locales": [{ "code": "en", "displayName": "English", "iso": "en-US" }],
  "translationDir": "src/locales"
}
```

## Universell brygga

Paketet tillhandahåller en universell bryggskapningsfunktion som fungerar med valfri i18n-implementation:

```typescript
import { createBridge } from '@i18n-micro/devtools-ui'
import type { BridgeAdapter } from '@i18n-micro/devtools-ui'

// Create an adapter for your i18n instance
const adapter: BridgeAdapter = {
  getRouteCache: () => i18nInstance.cache.route,
  addTranslations: (locale, content, merge) => {
    i18nInstance.addTranslations(locale, content, merge)
  },
  addRouteTranslations: (locale, routeName, content, merge) => {
    i18nInstance.addRouteTranslations(locale, routeName, content, merge)
  },
  subscribe: (callback) => {
    return i18nInstance.subscribe(callback)
  },
  getCurrentLocale: () => i18nInstance.locale,
  getFallbackLocale: () => i18nInstance.fallbackLocale,
}

// Create bridge
const bridge = createBridge({
  adapter,
  locales: localesConfig,
  defaultLocale: 'en',
  translationDir: 'src/locales',
})
```

### Bridge Adapter-gränssnitt

```typescript
interface BridgeAdapter {
  // Get translations cache
  // Keys are in format "locale:routeName" (e.g., "en:index", "en:home")
  getRouteCache: () => Record<string, TranslationContent>

  // Add or update translations for a locale
  addTranslations: (locale: string, content: TranslationContent, merge: boolean) => void

  // Add or update route-specific translations
  addRouteTranslations: (locale: string, routeName: string, content: TranslationContent, merge: boolean) => void

  // Subscribe to changes in translations
  subscribe: (callback: () => void) => () => void

  // Get current locale (optional)
  getCurrentLocale?: () => string

  // Get fallback locale (optional)
  getFallbackLocale?: () => string
}
```

## Säkerhet

Pluginen inkluderar säkerhetsåtgärder:

- **Förhindring av path traversal** - Alla filsökvägar valideras för att säkerställa att de stannar inom projektroten
- **Validering av filändelser** - Endast `.json`-filer kan sparas
- **Validering av projektrot** - Filer kan endast nås inom den konfigurerade projektroten

## Utveckling kontra produktion

- **Endast utveckling** - Pluginen fungerar endast i utvecklingsläge (`apply: 'serve'`)
- **Ingen produktionspåverkan** - Pluginen exkluderas automatiskt från produktionsbyggen
- **Noll runtime-overhead** - Ingen kod inkluderas i produktionsbundelar

## Exempel

### Anpassad bryggimplementation

```typescript
import { createBridge } from '@i18n-micro/devtools-ui'
import type { BridgeAdapter } from '@i18n-micro/devtools-ui'

class CustomI18n {
  private cache = {
    root: {},
    route: {},
  }

  addTranslations(locale: string, content: Record<string, unknown>) {
    this.cache.root[locale] = content
  }

  subscribe(callback: () => void) {
    // Your subscription logic
    return () => {} // unsubscribe
  }
}

const customI18n = new CustomI18n()

const adapter: BridgeAdapter = {
  getRouteCache: () => customI18n.cache.route,
  addTranslations: (locale, content) => {
    customI18n.addTranslations(locale, content)
  },
  addRouteTranslations: () => {}, // Not implemented
  subscribe: (callback) => customI18n.subscribe(callback),
}

const bridge = createBridge({
  adapter,
  locales: [{ code: 'en', displayName: 'English' }],
  defaultLocale: 'en',
})
```
