`@i18n-micro/node` är [runtime](/sv/integrations/runtime-package)-instansen plus en laddare som läser en översättningsmapp från disk. Använd den i en Express- eller Fastify-server, ett CLI, en e-post- eller PDF-generator, eller vilket skript som helst som behöver samma JSON-filer som din Nuxt-app. Du laddar filerna en gång och översätter per förfrågan utan att dela muterbart tillstånd mellan förfrågningar.

## Installation {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/node @i18n-micro/utils
```

```bash npm
npm install @i18n-micro/node @i18n-micro/utils
```

```bash yarn
yarn add @i18n-micro/node @i18n-micro/utils
```

</CodeGroup>

Inga peer-beroenden; Node.js `>=20`. `@i18n-micro/utils` behövs bara för `Accept-Language`-hjälpen nedan.

## Konfiguration {#setup}

Laddaren läser [Nuxts mappstruktur](/sv/guide/translations): `locales/en.json` är en rotordlista, `locales/pages/blog/post/en.json` hör till routen `blog-post`.

```ts
import { createI18n } from '@i18n-micro/node'

const i18n = createI18n({ locale: 'en', fallbackLocale: 'en', translationDir: './locales' })
await i18n.loadTranslations()

i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.t('title', undefined, undefined, 'blog-post') // from locales/pages/blog/post/en.json
```

Alternativen är runtime-alternativen (se [instansen](/sv/integrations/overview#the-instance)) plus `translationDir` och `disablePageLocales` (behandla `pages/**`-filer som rotordlistor). `i18n.reload()` rensar alla ordlistor och läser mappen igen, för en filbevakare under utveckling.

`loadTranslations(dir, disablePageLocales?)` exporteras även fristående och returnerar `{ root, routes }`:

```ts
import { loadTranslations } from '@i18n-micro/node'

const { root, routes } = await loadTranslations('./locales')
// root:   { en: {...}, de: {...} }
// routes: { 'blog-post': { en: {...}, de: {...} } }
```

## Per förfrågan {#per-request}

En instans håller en locale och en route. Att byta `i18n.locale` på en delad instans i en request-hanterare ger kapplöpning med samtidiga förfrågningar. `run` ger en förfrågan sin egen:

```ts
const i18n = createI18n({ locale: 'en', fallbackLocale: 'en', translationDir: './locales' })
await i18n.loadTranslations()

// `() => next()`: `run` hands its callback the fork, and Express reads an argument of `next` as an error
app.use((req, res, next) => i18n.run(pickLocale(req), () => next()))

app.get('/', (req, res) => {
  res.send(i18n.t('greeting')) // the request's locale, in everything it awaits
})
```

Inuti `run` läser och sätter den delade instansen förfrågans locale och route (`AsyncLocalStorage`); forken startar på aktuell route, och `i18n.setRoute(...)` inuti callbacken ändrar den förfrågans route. Callbacken får också förfrågans fork: ordlistor som skrivs till den stannar i förfrågan, ordlistor som skrivs till den delade instansen når alla.

Utan `AsyncLocalStorage` returnerar `i18n.fork(locale)` samma slags instans att skicka runt.

`reload()` läser katalogen igen; de gamla ordlistorna svarar tills de nya är på plats.

## Välj locale {#pick-the-locale}

`detectLocaleFromAcceptLanguage(header, locales)` respekterar `q`-vikter och matchar `de-DE` mot en `de`-locale (och `de` mot `de-DE`). Den returnerar `null` när inget matchar.

```ts
import express from 'express'
import { detectLocaleFromAcceptLanguage } from '@i18n-micro/utils/accept-language'

const app = express()

app.get('/hello', (req, res) => {
  const locale = detectLocaleFromAcceptLanguage(req.headers['accept-language'], locales) ?? 'en'
  const i18n = byLocale.get(locale)!
  res.json({ message: i18n.t('greeting', { name: 'Ada' }) })
})
```

För URL-prefix, cookie och header tillsammans tillämpar `resolveLocale({ defaultLocale, validLocales, url, cookie, acceptLanguage, autoDetectLanguage: true })` från `@i18n-micro/utils/resolve-locale` modulens prioritetsordning: URL, sedan cookie, sedan `Accept-Language`, sedan standard. Ogiltiga värden hoppas över.

I en Nuxt-app behöver du inte detta paket på servern: använd modulens [översättningar på serversidan](/sv/guide/server-side-translations).

## API {#api}

| Export | Anteckningar |
| --- | --- |
| `createI18n(options)`, `I18n` | runtime-instans + `translationDir`, `loadTranslations(dir?)`, `reload()` |
| `loadTranslations(dir, disablePageLocales?)` | `{ root, routes }` |
| `loadRootTranslations(dir, disablePageLocales?)` | endast `root` |
| `FormatService`, `interpolate` | från core |
| Typer: `I18nOptions`, `LoadedTranslations`, `Translations`, `Locale`, `PluralFunc`, `Params` | |
