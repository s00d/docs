title: "Astro-öar"
description: "Översättningar i Vue-, React-, Preact- och Svelte-öar med @i18n-micro/astro."
---

En ö körs i webbläsaren, där serverns i18n-instans inte finns. `@i18n-micro/astro` låter sidan välja de nycklar en ö behöver, skicka dem som en enda prop och läsa dem i ön via en liten ramverksadapter. Du får `t`, `tc`, `tn`, `td`, `tdr` och `has` i Vue-, React-, Preact- och Svelte-öar, med bara de valda strängarna i HTML:en.

## Installation {#setup}

Konfigurera först [Astro-integrationen och middlewaren](/sv/integrations/astro-package#setup) och lägg sedan till ramverksintegrationen du använder (`@astrojs/vue`, `@astrojs/react`, `@astrojs/preact`, `@astrojs/svelte`). Ö-adaptrarna behöver det ramverket som peer: `vue` `^3.3.0`, `react` `^16.8.0 || ^17.0.0 || ^18.0.0 || ^19.0.0`, `preact` `^10.0.0 || ^11.0.0` eller `svelte` `^4.0.0 || ^5.0.0`.

## Skicka översättningar till en ö {#pass-translations-to-an-island}

```astro
---
// src/pages/index.astro
import { getI18nProps } from '@i18n-micro/astro'
import Counter from '../components/Counter.vue'

const i18n = getI18nProps(Astro, ['counter.title', 'counter.apples'])
---

<Counter client:load i18n={i18n} />
```

`getI18nProps(Astro, keys?)` returnerar `{ locale, fallbackLocale, currentRoute, translations }` (typen `I18nClientProps`). Skicka de nycklar som ön använder: var och en löses upp på servern som med `t()` (route-, rot- och reservordlistor) och endast hittade nycklar hamnar i HTML:en. Utan `keys` skickas allt som `t()` kan besvara på sidan, i varje ö, så 2000 rotnycklar blir ungefär 100 KB per ö; i utvecklingsläge varnas det för detta över 20 KB.

Öar översätter endast från det objektet. `t` returnerar nyckeln för allt som inte skickats, och länkade meddelanden löses inte upp.

## Vue {#vue}

Anropa `provideI18n(() => props.i18n)` i öns rotkomponent och `useAstroI18n()` i dess barn. Vues `inject` ser inte ett värde som tillhandahålls av samma komponent, så hooken måste köras i ett barn, inte i roten:

```vue
<!-- src/components/Counter.vue -->
<script setup lang="ts">
import { provideI18n } from '@i18n-micro/astro/client/vue'
import type { I18nClientProps } from '@i18n-micro/astro'
import CounterBody from './CounterBody.vue'

const props = defineProps<{ i18n: I18nClientProps }>()
provideI18n(() => props.i18n)
</script>

<template><CounterBody /></template>
```

```vue
<!-- src/components/CounterBody.vue -->
<script setup lang="ts">
import { ref } from 'vue'
import { useAstroI18n } from '@i18n-micro/astro/client/vue'

const { t, tc } = useAstroI18n()
const count = ref(0)
</script>

<template>
  <h3>{{ t('counter.title') }}</h3>
  <button @click="count++">{{ tc('counter.apples', count) }}</button>
</template>
```

## React och Preact {#react-and-preact}

```tsx
// src/components/Counter.tsx
import { useState } from 'react'
import { I18nProvider, useAstroI18n } from '@i18n-micro/astro/client/react'
import type { I18nClientProps } from '@i18n-micro/astro'

function Body() {
  const { t, tc } = useAstroI18n()
  const [count, setCount] = useState(0)
  return <button onClick={() => setCount(count + 1)}>{t('counter.title')}: {tc('counter.apples', count)}</button>
}

export default function Counter({ i18n }: { i18n: I18nClientProps }) {
  return (
    <I18nProvider value={i18n}>
      <Body />
    </I18nProvider>
  )
}
```

För Preact importerar du `I18nProvider` och `useAstroI18n` från `@i18n-micro/astro/client/preact`; API:et är detsamma.

## Svelte {#svelte}

```svelte
<!-- src/components/Counter.svelte -->
<script lang="ts">
  import { createI18nStore, useAstroI18n } from '@i18n-micro/astro/client/svelte'
  import type { I18nClientProps } from '@i18n-micro/astro'

  export let i18n: I18nClientProps
  const { t, tc } = useAstroI18n(createI18nStore(i18n))
  let count = 0
</script>

<button on:click={() => count++}>{t('counter.title')}: {tc('counter.apples', count)}</button>
```

`useAstroI18n(store)` returnerar också `store` för `$store`-läsningar i mallen.

## Beständiga öar {#persisted-islands}

En ö med `transition:persist` får nya props efter en navigering. React, Preact och Vue (givet en getter) följer dem. I Svelte behåller du storen och skickar dem vidare: `const store = createI18nStore(i18n)`, `const { t } = useAstroI18n(store)`, sedan `$: store.set(i18n)` (med runes, `$effect(() => store.set(i18n))`).

## API {#api}

| Ingång | Exporter |
| --- | --- |
| `@i18n-micro/astro` | `getI18nProps`, typen `I18nClientProps` |
| `@i18n-micro/astro/client/vue` | `provideI18n(props \| () => props)`, `useAstroI18n()` |
| `@i18n-micro/astro/client/react` | `I18nProvider` (`value`-prop), `useAstroI18n()` |
| `@i18n-micro/astro/client/preact` | `I18nProvider` (`value`-prop), `useAstroI18n()` |
| `@i18n-micro/astro/client/svelte` | `createI18nStore(props)`, `useAstroI18n(store)` |
| `@i18n-micro/astro/client` | de rena `translate`, `hasTranslation`, utan ramverk |

Varje `useAstroI18n` returnerar `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`, `setLocale`, `setRoute` och `locale`. En ö har en sammanslagen ordlista, så dess `has` är sant för en nyckel som `t` kan besvara, även från reserv-locale; på servern tittar `has` endast på den aktiva locale.
