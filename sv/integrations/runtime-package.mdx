`@i18n-micro/runtime` är den ramverksoberoende i18n-instansen: ordlistor, `t()`, pluralformer, `Intl`-formatering och en prenumeration på ändringar, utan `fs` och utan ramverk. Använd den i ren TypeScript, en web worker, en edge-funktion eller som grund för din egen bindning. Paketen för React, Preact, Node och Astro utökar samma klass.

## Installera {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/runtime
```

```bash npm
npm install @i18n-micro/runtime
```

```bash yarn
yarn add @i18n-micro/runtime
```

</CodeGroup>

Inga peer-beroenden. För översättningsfiler på disk använder du [`@i18n-micro/node`](/sv/integrations/nodejs-package).

## Konfiguration {#setup}

```ts
import { createI18n } from '@i18n-micro/runtime'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    en: { greeting: 'Hello, {name}!', apples: 'no apples | one apple | {count} apples' },
    de: { greeting: 'Hallo, {name}!' },
  },
  routeMessages: {
    about: { en: { title: 'About us' } },
  },
})
```

Alla alternativ (`plural`, `missingWarn`, `missingHandler`, `numberFormats`, `datetimeFormats`) listas under [instansen](/sv/integrations/overview#the-instance).

## Översätt {#translate}

```ts
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.tc('apples', 5) // '5 apples'
i18n.tn(1234.5) // '1,234.5'

i18n.setRoute('about')
i18n.t('title') // 'About us' (route dictionary)
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!' (root, still visible)
```

Läs in fler ordlistor senare:

```ts
i18n.loadMessages({ fr: { greeting: 'Bonjour, {name} !' } }, { about: { fr: { title: 'À propos' } } })
i18n.addTranslations('fr', { nav: { home: 'Accueil' } }) // deep merge; pass false to replace

await i18n.loadFromUrl('/locales/fr.json', { locale: 'fr' })
await i18n.loadFromUrl('/locales/pages/about/fr.json', { locale: 'fr', routeName: 'about' })
await i18n.loadFromUrls([
  { url: '/locales/en.json', locale: 'en' },
  { url: '/locales/de.json', locale: 'de' },
])
```

`loadFromUrl` använder `fetch` (skicka `init` för headers) och kastar ett fel vid ett svar som inte är OK. `loadFromUrls` läser in en i taget.

## Byt locale {#switch-locale}

```ts
i18n.locale = 'de'
i18n.t('greeting', { name: 'Ada' }) // 'Hallo, Ada!'
```

Ändringar av locale, route och ordlistor meddelas till prenumeranter, vilket är hur ramverksbindningar renderar om:

```ts
const stop = i18n.subscribe(() => {
  document.querySelector('#greeting')!.textContent = i18n.t('greeting', { name: 'Ada' }) as string
})
i18n.locale = 'fr'
stop()
```

`getSnapshot()` returnerar en sträng som ändras vid varje notifiering (för stores i stil med `useSyncExternalStore`).

## Per förfrågan {#per-request}

Instansen håller en locale och en route. På en server ska du inte byta en delad instans per förfrågan: två samtidiga förfrågningar skulle se varandras locale. `i18n.fork(locale)` ger en förfrågan en egen: egen locale, reserv och route; samma ordlistor, formaterare och regler. En fork kostar lika mycket oavsett hur många ordlistor det finns. En fork ser skrivningar till sin förälder fram till sin första egna skrivning, och dess skrivningar stannar i den. [Node.js](/sv/integrations/nodejs-package#per-request) lägger till `run`.

## API {#api}

| Medlem | Anmärkningar |
| --- | --- |
| `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has` | se [Översätt och formatera](/sv/integrations/overview#translate-and-format) |
| `locale`, `fallbackLocale` | get/set |
| `currentRoute`, `setRoute(name)`, `getRoute()` | aktiv route, standard `'index'` |
| `loadMessages(messages?, routeMessages?)` | slå samman många locales och routes på en gång |
| `addTranslations(locale, tree, merge = true)`, `addRouteTranslations(locale, route, tree, merge = true)` | |
| `loadFromUrl(url, { locale?, routeName?, init? })`, `loadFromUrls(entries)` | `fetch` JSON |
| `hasTranslation(key)` | aktiv locale, valfri route (till skillnad från `has`, som kontrollerar aktiv route och roten) |
| `setTranslation(key, value)`, `resolveTranslations()` | skriv en nyckel; läs det sammanslagna trädet |
| `clear()`, `clearCache()` | släpp alla ordlistor |
| `subscribe(cb)`, `getSnapshot()` | ändringsnotifieringar |
| `storage` | `{ translations: Map<'locale:route', Translations> }` |

En kod som inte är en språktagg får sina pluralformer från `localeIso: { ua: 'uk-UA' }`; `localeIsoMap(locales)` bygger det från de poster i en locale-lista som har en `iso`.

Modulexporter: `createI18n`, `I18n`, `fetchJsonTranslations`, `FormatService`, `interpolate`, `localeIsoMap` och typerna `I18nOptions`, `LoadFromUrlOptions`, `LoadFromUrlEntry`, `TranslationStorage`, `Translations`, `Locale`, `PluralFunc`. Fullständiga signaturer: [paketreferens](/sv/api/packages/runtime).
