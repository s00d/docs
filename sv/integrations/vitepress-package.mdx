---

`@i18n-micro/vitepress` lägger till runtime-ordlistor på en VitePress-webbplats: `$t` och `<I18nT>` i markdown, sökvägshjälpare och SEO-taggar, byggt på [`@i18n-micro/vue`](/sv/integrations/vue-package). Använd det när samma UI-strängar förekommer på många sidor och du inte vill duplicera dem per locale. Locale följer VitePress egna sökvägs-locales (`/`, `/fr/`).

## När du ska använda det {#when-to-use-it}

| Behov | Lösning |
|------|----------|
| Duplicerade `.md`, URL-prefix | VitePress `locales` |
| Runtime-`$t` / komponenter / sökvägssynkning / SEO-head | `@i18n-micro/vitepress` |
| Etiketter i standardtemats ramverk (`docFooter`, sök-UI) | Din egen `themeConfig` per locale |

<Tip>

**Playground** — [`packages/vitepress/playground`](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/vitepress/playground) — `pnpm -C packages/vitepress/playground dev`

</Tip>

## Installera {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vitepress
```

```bash npm
npm install @i18n-micro/vitepress
```

```bash yarn
yarn add @i18n-micro/vitepress
```

</CodeGroup>

Peer-beroenden: `vitepress` `>=1.0.0 || >=2.0.0-alpha.0`, `vue` `^3.3.0`. Node-skript använder `@i18n-micro/node`, som installeras med paketet och återexporteras via `/node`. De publicerade typerna kräver Vue 3.5.5 eller senare med `skipLibCheck: false`; med `skipLibCheck: true`, den vanliga mallinställningen, kompilerar även äldre versioner.

## Konfiguration {#setup}

```
locales/en.json
locales/fr.json
locales/pages/guide/demo/en.json   # optional page-scoped
locales/pages/guide/demo/fr.json
```

Sidfiler mappas till route-namn på samma sätt som i Nuxt/Astro (`guide/demo` → `guide-demo`).

### 1. Konfiguration — `@i18n-micro/vitepress/config` {#1-config-—-@i18n-micro/vitepress/config}

```ts
// .vitepress/config.mts
import { defineConfig } from 'vitepress'
import { withI18n, buildVitePressLocales } from '@i18n-micro/vitepress/config'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English', og: 'en_US' },
  { code: 'fr', iso: 'fr-FR', displayName: 'Français', og: 'fr_FR' },
]
const defaultLocale = 'en'

export default defineConfig(
  withI18n(
    {
      locales: buildVitePressLocales(locales, defaultLocale),
      // themeConfig.i18nRouting is injected automatically
    },
    {
      locale: defaultLocale,
      defaultLocale,
      locales,
      translationDir: 'locales',
      metaBaseUrl: 'https://example.com', // optional SEO head
    },
  ),
)
```

### 2. Tema — `@i18n-micro/vitepress/theme` {#2-theme-—-@i18n-micro/vitepress/theme}

```ts
// .vitepress/theme/index.ts
import DefaultTheme from 'vitepress/theme'
import { defineI18nTheme } from '@i18n-micro/vitepress/theme'

export default defineI18nTheme(DefaultTheme)
```

Den initiala locale tas från den aktuella sökvägen före installationen (ingen blinkning av standard-locale på `/fr/…`).

### Avancerat: manuell `createI18n` {#advanced-manual-createi18n}

En fabrik för klienten: Vue-plugin + sökvägsmetoder + `enhanceApp` (inga separata exporter av routerhjälpare).

```ts
import { createI18n, messagesFromGlob } from '@i18n-micro/vitepress'

const i18n = createI18n({
  locale: 'en',
  defaultLocale: 'en',
  locales: [{ code: 'en' }, { code: 'fr' }],
  messages: messagesFromGlob(import.meta.glob('../../locales/*.json', { eager: true })),
})

i18n.localizePath('/guide', 'fr')
// in theme enhanceApp:
i18n.enhanceApp({ app, router })
```

### Node-skript — `@i18n-micro/vitepress/node` {#node-scripts-—-@i18n-micro/vitepress/node}

Använder `createI18n` / `loadTranslations` från `@i18n-micro/node` (samma som Astro och CLI) och kopplar sedan på VitePress sökvägsmetoder med `BaseI18n.extend`:

```ts
import { createI18n } from '@i18n-micro/vitepress/node'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  translationDir: './locales',
  locales: ['en', 'fr'],
  defaultLocale: 'en',
})
await i18n.loadTranslations()
i18n.t('cta.readMore')
i18n.localizePath('/guide', 'fr')
```

Ren Node utan sökvägar: `import { createI18n } from '@i18n-micro/node'`.

## Översättningar på sidan {#in-page-translations}

Varje markdown-fil i VitePress är en Vue SFC.

### Globala komponenter och `$t` (rekommenderas i markdown) {#global-components-and-$t-recommended-in-markdown}

`createI18n` / `defineI18nTheme` installerar `@i18n-micro/vue`, som registrerar `I18nT` / `I18nLink` / `I18nGroup` / `I18nSwitcher` och `$t` / `$tc` / `$ts`.

```md
{{ $t('cta.readMore') }}

<I18nT keypath="greeting" :params="{ name: 'VitePress' }" />

<I18nLink to="/guide/demo">Demo</I18nLink>
```

### `useI18n` i `<script setup>` {#usei18n-in-<script-setup>}

```md
<script setup>
import { useI18n } from '@i18n-micro/vitepress'
const { t, tc, locale, localePath, switchLocale } = useI18n()
</script>

# {{ t('section.title') }}
```

## Språkmeny {#language-dropdown}

När `locales` har mer än en post visar VitePress sin egen språkmeny (`VPNavBarTranslations`). `withI18n` kopplar `themeConfig.i18nRouting` så att jordgloben stämmer överens med `<I18nSwitcher>` / sökvägshjälparna.

Använd `<I18nSwitcher>` endast i anpassade layouter, inte bredvid standardjordgloben.

## SSR-anmärkningar {#ssr-notes}

- Locale vid prerendering kommer från URL-sökvägen, inte från cookies.
- Temakod får inte röra `window` vid importtillfället.
- Importera `defineI18nTheme` från `/theme` så att utvärderingen av Node-konfigurationen aldrig läser in `virtual:i18n-micro/*`.

## API-yta {#api-surface}

| Export | Roll |
|--------|------|
| `createI18n` (`.`) | Klient: Vue-plugin + sökvägsmetoder + `enhanceApp` |
| `getLocaleFromPath` / `stripSiteBase` / `routeNameFromPath` (`.`) | Manuell locale-synkning när `syncWithVitePress: false` |
| `createI18n` (`/node`) | Node: `@i18n-micro/node` + sökvägsmetoder |
| `defineI18nTheme` (`/theme`) | Tema utan boilerplate |
| `withI18n` (`/config`) | Konfiguration + virtuella moduler + valfri SEO |
| `buildVitePressLocales` (`/config`) | Bygg VitePress `locales` från `Locale[]` |
| `buildVitePressLocaleHead` (`/config`) | Manuell SEO-head (används även av `metaBaseUrl`) |
| `messagesFromGlob` | Valfri glob → meddelandekarta för `createI18n` |
| `useI18n` / `I18nT` / … | Återexporteras från `@i18n-micro/vue` |
| `BaseI18n.extend` (`@i18n-micro/core`) | Koppla anpassade metoder till valfri i18n-instans |

## Webbplatser i OpenAPI-stil (integrationslås) {#openapi-style-sites-integration-locks}

Regressionssvit: `packages/vitepress/tests/integration-openapi.test.ts` (djupa sökvägar, `base=/openapi_docs/`, synkning av + manuell locale, Node-generatorer, SEO).

| Mönster | Gör så här |
|---------|---------|
| Djupa `/…/{spec}/{op}`-sidor, endast rot-UI-JSON | Föredra standardvärdet `syncWithVitePress: true` (behåller `setRoute('index')` när det inte finns någon sidordlista) **eller** `syncWithVitePress: false` + `getLocaleFromPath` |
| Anropa aldrig `setRoute(deepName)` utan sidordlistor | Rot-UI-nycklar försvinner tills `setRoute('index')` |
| Generatorer / `getTranslation` | `createI18n` från `/node` + `await loadTranslations()` + `i18n.t(key)` (sätt `i18n.locale`) |
| Anpassad canonical i `transformPageData` | Skicka `meta: false` till `withI18n` (undvik dubbla taggar) |
| Paketets SEO med webbplatsens base | `metaBaseUrl` + VitePress `base` → absoluta URL:er inkluderar base |
| Namnbyten från äldre paketbyggen | `withI18nMicro` → `withI18n`, `createVitePressI18n` → `createI18n`, `loadMessages` → node `createI18n` |
