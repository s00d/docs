# 📚 Nuxt I18n Micro उदाहरण और उपयोग

यह अनुभाग विभिन्न उदाहरण प्रदान करता है, जो दिखाते हैं कि `Nuxt I18n Micro` का उपयोग आपके Nuxt.js एप्लिकेशन में कैसे किया जाए। आप देखेंगे कि लोकेल कैसे स्विच करें, `<i18n-link>`, `<i18n-switcher>`, और `<i18n-t>` कंपोनेंट्स का उपयोग कैसे करें, और अनुवाद कुंजियों को गतिशील रूप से कैसे हैंडल करें।

## 🛠️ बुनियादी सेटअप

`Nuxt I18n Micro` के साथ शुरुआत करने के लिए यहाँ एक बुनियादी सेटअप है:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 लोकेल स्विचिंग

### प्रोग्रामेटिक रूप से लोकेल स्विच करना

यह उदाहरण दिखाता है कि बटन का उपयोग करके प्रोग्रामेटिक रूप से लोकेल कैसे स्विच करें:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### लोकेल स्विचिंग के लिए उदाहरण JSON

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### `<i18n-switcher>` कंपोनेंट का उपयोग

`<i18n-switcher>` कंपोनेंट अनुकूलन योग्य लेबल के साथ लोकेल स्विचिंग के लिए एक ड्रॉपडाउन प्रदान करता है:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 🌐 स्थानीयकृत नेविगेशन के लिए `<i18n-link>` का उपयोग

`<i18n-link>` कंपोनेंट स्वचालित रूप से लोकेल-विशिष्ट रूटिंग संभालता है:

```vue
<template>
  <div>
    <i18n-link to="/about">{{ $t('about') }}</i18n-link>
    <i18n-link :to="{ name: 'index' }">{{ $t('home') }}</i18n-link>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### नेविगेशन लिंक के लिए उदाहरण JSON

```json
{
  "about": "About Us",
  "home": "Home"
}
```

### सक्रिय लिंक स्टाइलिंग के साथ उदाहरण

```vue
<template>
  <div>
    <i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
  </div>
</template>
```

### सक्रिय लिंक स्टाइलिंग के लिए उदाहरण JSON

इस परिदृश्य के लिए पिछले उदाहरण के समान JSON फ़ाइल का उपयोग किया जा सकता है।

## 📝 अनुवाद फ़ाइलों से डायनामिक कुंजियाँ रेंडर करना

कुछ परिदृश्यों में, आप अपनी अनुवाद फ़ाइलों में संग्रहीत डायनामिक कुंजियों पर पुनरावृति करना और उनके मानों को सशर्त रूप से रेंडर करना चाह सकते हैं। नीचे दिया गया उदाहरण दिखाता है कि `Nuxt I18n Micro` का उपयोग करके यह कैसे प्राप्त करें।

### उदाहरण: डायनामिक कुंजियाँ रेंडर करना

यह उदाहरण एक विशिष्ट अनुवाद पथ (इस मामले में, `dynamic`) से कुंजियों की एक सारणी लाता है और उन पर पुनरावृति करता है। प्रत्येक कुंजी की उपस्थिति `$has` का उपयोग करके जाँची जाती है, फिर `$t` के साथ उसका मान रेंडर किया जाता है।

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### उदाहरण अनुवाद फ़ाइल (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### उदाहरण: किसी ऑब्जेक्ट से डायनामिक कुंजियाँ रेंडर करना

इस उदाहरण में, हम आपकी अनुवाद फ़ाइल में संग्रहीत एक ऑब्जेक्ट को हैंडल करते हैं। हम ऑब्जेक्ट की कुंजियों को लाते और उन पर पुनरावृति करते हैं, कुंजी नामों और उनके संबद्ध मानों को गतिशील रूप से रेंडर करते हैं।

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### उदाहरण अनुवाद फ़ाइल (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 Slots और Interpolation के साथ अनुवादों के लिए `<i18n-t>` का उपयोग

`<i18n-t>` कंपोनेंट गतिशील सामग्री और HTML टैग्स के साथ अनुवाद रेंडर करने के लिए उपयोगी है:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### `<i18n-t>` के लिए उदाहरण JSON

```json
{
  "greeting": "Welcome to the page"
}
```

### Interpolation के साथ

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### Interpolation के लिए उदाहरण JSON

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 बहुवचन के लिए `$tc` का उपयोग

`Nuxt I18n Micro` में `$tc` फ़ंक्शन गिनती और लोकेल सेटिंग्स के आधार पर बहुवचनीकरण संभालता है। यह उन संदेशों को गतिशील रूप से समायोजित करने के लिए उपयोगी है जिनमें गिनती शामिल है, जैसे कि आइटम, नोटिफ़िकेशन, या अन्य entities जो संख्या में भिन्न हो सकती हैं।

### उदाहरण: बहुवचनीकरण के लिए `$tc` का उपयोग

निम्नलिखित उदाहरण में, हम `$tc` का उपयोग करके सेब की संख्या दर्शाने वाला एक संदेश प्रदर्शित करते हैं। अनुवाद कुंजी दी गई गिनती के आधार पर कई बहुवचन रूपों को संभालती है।

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### बहुवचनीकरण के लिए उदाहरण JSON

अपनी JSON फ़ाइल में विभिन्न बहुवचन रूपों को संभालने के लिए आप अनुवाद को इस प्रकार परिभाषित कर सकते हैं:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### व्याख्या

- **`$tc('apples', 0)`**: पहला रूप लौटाता है, जब गिनती शून्य होती है (`"no apples"`) उपयोग किया जाता है।
- **`$tc('apples', 1)`**: दूसरा रूप लौटाता है, जब गिनती एक होती है (`"one apple"`) उपयोग किया जाता है।
- **`$tc('apples', 10)`**: गिनती मान के साथ तीसरा रूप लौटाता है, जब गिनती दो या अधिक होती है (`"10 apples"`) उपयोग किया जाता है।

### अधिक जटिल बहुवचनीकरण के साथ अतिरिक्त उदाहरण

यदि आपके एप्लिकेशन को अधिक जटिल बहुवचनीकरण नियमों को संभालने की आवश्यकता है (जैसे शून्य, एक, दो, कुछ, कई, अन्य के लिए विशिष्ट मामले), तो आप अनुवाद स्ट्रिंग्स को उसी अनुसार विस्तारित कर सकते हैं:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: `"two apples"` लौटाने के लिए सेट किया जा सकता है।
- **`$tc('apples', 3)`**: गिनती के लिए परिभाषित नियमों के आधार पर `"a few apples"` लौटा सकता है।

## 🌐 संख्या स्वरूपण के लिए `$tn` का उपयोग

`$tn` फ़ंक्शन `Intl.NumberFormat` API का उपयोग करके वर्तमान लोकेल के अनुसार संख्याओं को स्वरूपित करता है। यह संख्याओं को उपयोगकर्ता की क्षेत्रीय सेटिंग्स से मेल खाने वाले तरीके से प्रदर्शित करने के लिए उपयोगी है, जैसे मुद्रा, प्रतिशत, या अन्य संख्या स्वरूप।

### उदाहरण: संख्या स्वरूपण के लिए `$tn` का उपयोग

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ दिनांक और समय स्वरूपण के लिए `$td` का उपयोग

`$td` फ़ंक्शन `Intl.DateTimeFormat` API का उपयोग करके वर्तमान लोकेल के अनुसार दिनांक और समय को स्वरूपित करता है। यह उपयोगकर्ता की लोकेल सेटिंग्स के आधार पर परिचित स्वरूपों में दिनांक और समय प्रदर्शित करने के लिए उपयोगी है।

### उदाहरण: दिनांक और समय स्वरूपण के लिए `$td` का उपयोग

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ सापेक्ष दिनांक स्वरूपण के लिए `$tdr` का उपयोग

`$tdr` फ़ंक्शन `Intl.RelativeTimeFormat` API का उपयोग करके वर्तमान लोकेल के अनुसार दिनांक को सापेक्ष समय के रूप में स्वरूपित करता है (जैसे "5 मिनट पहले", "2 दिन पहले")। यह वर्तमान दिनांक और समय के सापेक्ष समय अंतर प्रदर्शित करने के लिए उपयोगी है।

### उदाहरण: सापेक्ष दिनांक स्वरूपण के लिए `$tdr` का उपयोग

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
