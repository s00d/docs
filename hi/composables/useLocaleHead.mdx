title: "useLocaleHead"
description: "useLocaleHead i18n SEO टैग (lang, dir, canonical, hreflang, og:locale) को एक ऑब्जेक्ट के रूप में बनाता है जिसे आप useHead को पास करते हैं।"
---

`useLocaleHead()` वर्तमान रूट के लिए i18n head टैग बनाता है: `<html>` पर `lang` और `dir`, एक canonical link, `x-default` के साथ `hreflang` alternates, `og:url`, `og:locale` और `og:locale:alternate`। इसका उपयोग तब करें जब आप [`meta: false`](/hi/api/module-options#meta) सेट करते हैं और `useHead` को ख़ुद संभालते हैं; `meta: true` के साथ मॉड्यूल ये टैग पहले से रजिस्टर करता है, और पेज-विशिष्ट बदलाव [`useI18nHead`](/hi/composables/useI18nHead) के ज़रिए होते हैं।

## सिग्नेचर {#signature}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { build: () => LocaleHead; metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }, LocaleHead | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

वर्तमान रूट के लिए SEO head टैग: हर locale के लिए `hreflang` alternates और साथ में
`x-default`, एक canonical link, `og:locale`, और `<html>` पर `lang`/`dir`।

केवल तब ज़रूरी है जब `meta` अक्षम हो या डिफ़ॉल्ट को समायोजित करना हो — `meta: true` के साथ
मॉड्यूल वही टैग ख़ुद रजिस्टर करता है।

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| `options` | `UseLocaleHeadOptions` |  |

**लौटाता है** — `metaObject`, एक ref जिसमें `useHead` को पास करने के लिए तैयार head ऑब्जेक्ट होता है; `updateMeta` उसे रीफ़्रेश करता है; `build` वर्तमान रूट से head ऑब्जेक्ट की गणना करता है (getter में पढ़ने पर reactive, जैसे `useHead(() => build())`)

```ts
const { metaObject } = useLocaleHead({ addSeoAttributes: true })
useHead(metaObject)
```

## विकल्प {#options}

| विकल्प | डिफ़ॉल्ट | विवरण |
| --- | --- | --- |
| `addDirAttribute` | `true` | locale के `dir` से `<html>` पर `dir` सेट करें (जब न हो तो `'auto'`)। |
| `identifierAttribute` | `'id'` | वह attribute जो हर टैग की key होता है (`i18n-can`, `i18n-og`, `i18n-alternate-<hreflang>`, …), ताकि अपडेट टैग जोड़ने के बजाय उन्हें बदलें। |
| `addSeoAttributes` | `true` | canonical, `hreflang` और `og:` टैग जनरेट करें। `false` केवल `htmlAttrs` रखता है। |
| `baseUrl` | `'/'` | हर URL से जोड़ा जाने वाला origin। relative URLs के लिए `'/'` रखें; absolute URLs के लिए `'https://example.com'` पास करें। |
| `autoUpdate` | `true` | रूट या `i18n-locale` स्टेट बदलने पर `metaObject` को फिर से बनाएँ। |

## यह क्या जनरेट करता है {#what-it-emits}

- बिना match वाले रूट (404) पर या सक्रिय locale के लिए `disableMeta` वाले रूट पर कुछ नहीं।
- Canonical और `og:url`: `$switchLocalePath(<active locale>)`, query को [`canonicalQueryWhitelist`](/hi/api/module-options#canonicalquerywhitelist) तक सीमित करके, [`trailingSlash`](/hi/api/module-options#trailingslash) लागू करके।
- `hreflang`: हर सक्षम locale के लिए एक link जिसमें पेज मौजूद है, `hreflang = iso || code`, `seo: false` वाले locales को छोड़कर; `hreflangBaseLanguage: true` के साथ किसी भाषा का पहला क्षेत्रीय locale उसकी केवल-भाषा वाला टैग भी जनरेट करता है। `no_prefix` के तहत कोई नहीं।
- `x-default`: डिफ़ॉल्ट locale का URL, जब तक कि strategy `no_prefix` न हो, डिफ़ॉल्ट locale में `seo: false` न हो, या पेज उसमें मौजूद न हो।
- `og:locale` / `og:locale:alternate`: locale के `og` से, या उसके रूपांतरित `iso` से (`en-US` → `en_US`); जब दोनों में से कोई काम न करे तो dev चेतावनी के साथ छोड़ दिया जाता है।

## उदाहरण {#example}

```ts
// app.vue, with i18n.meta: false
const { metaObject } = useLocaleHead({ baseUrl: 'https://example.com' })
useHead(metaObject)
```

`build()` वही ऑब्जेक्ट बिना ref के लौटाता है: `useHead(() => build())` बिना watcher के reactive रहता है।
