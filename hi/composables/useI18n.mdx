---

`useI18n()` मॉड्यूल के रनटाइम हेल्पर को एक सादे ऑब्जेक्ट के रूप में लौटाता है। `useNuxtApp()` तक पहुँचने के बजाय इसे `<script setup>`, composables और plugins में इस्तेमाल करें। हर हेल्पर अपने `$` नाम और एक बिना-उपसर्ग वाले उपनाम (alias) दोनों से मिलता है: `t` और `$t` एक ही फ़ंक्शन हैं।

## सिग्नेचर {#signature}

```ts
useI18n(): PluginsInjectionsWithAliases
```

हर रनटाइम हेल्पर, एक सादे ऑब्जेक्ट के रूप में।

वही फ़ंक्शन जिन्हें प्लगइन `$t`, `$tc` आदि के रूप में इंजेक्ट करता है, डॉलर-उपसर्ग वाले नाम
और बिना-उपसर्ग वाले उपनाम दोनों के तहत उपलब्ध हैं — इसलिए `const { t } = useI18n()` और
`const { $t } = useI18n()` दोनों काम करते हैं।

**लौटाता है** — [methods संदर्भ](/hi/api/methods) में वर्णित हेल्पर

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

लौटाए गए ऑब्जेक्ट में [`PluginsInjections`](/hi/api/methods) का हर हेल्पर होता है। हर एक का दस्तावेज़ [हेल्पर](/hi/api/methods) पेज पर है।

## उदाहरण {#example}

```vue
<script setup lang="ts">
const { t, tc, localePath, switchLocale, getLocale } = useI18n()

const title = computed(() => t('page.title'))
</script>

<template>
  <h1>{{ title }}</h1>
  <p>{{ tc('items', 3) }}</p>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
  <button @click="switchLocale(getLocale() === 'en' ? 'de' : 'en')">{{ t('nav.switch') }}</button>
</template>
```

## टाइप में शामिल नहीं {#not-in-the-type}

`$defineI18nRoute` का टाइप केवल `useNuxtApp()` पर दिया गया है:

```ts
const { $defineI18nRoute } = useNuxtApp()
```
