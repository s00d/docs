`useI18nHead()` मॉड्यूल द्वारा जनरेट किए गए SEO टैग को केवल एक पेज के लिए बदलता है। इसका उपयोग तब करें जब पेज राउटर से बेहतर जानता हो: ऐसा CMS लेख जो केवल कुछ locales में मौजूद है, API से आया canonical URL, अतिरिक्त `og:` टैग। आपको जनरेट किए गए टैग मिलते हैं, जिनके ऊपर आपके ओवरराइड मर्ज होते हैं।

## सिग्नेचर {#signature}

```ts
useI18nHead(input?: MaybeRefOrGetter<I18nHeadInput | null>): { pageHead: any; resetPageHead: () => void }
```

i18n SEO head टैग के लिए पेज-स्तर के ओवरराइड रजिस्टर करें।
`02.meta` प्लगइन द्वारा `useLocaleHead` के आउटपुट के ऊपर मर्ज किए जाते हैं।

जब मान `$t` / `t` से आते हों तो getter (`() => ({ … })`) को प्राथमिकता दें ताकि वे
locale बदलने पर फिर से resolve हों। सादा ऑब्जेक्ट एक बार evaluate होता है और स्थिर रहता है।

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| `input` *(वैकल्पिक)* | `MaybeRefOrGetter<I18nHeadInput \| null>` |  |

यह [`meta: true`](/hi/api/module-options#meta) (डिफ़ॉल्ट) के साथ काम करता है: मॉड्यूल का meta प्लगइन हर head render पर इनपुट को [`useLocaleHead`](/hi/composables/useLocaleHead) के आउटपुट के ऊपर मर्ज करता है। `meta: false` के साथ इसे कोई नहीं पढ़ता।

रूट का नाम बदलने पर ओवरराइड रीसेट हो जाता है। जो पेज `disableMeta` सेट करता है उसे कोई i18n टैग नहीं मिलता, ओवरराइड सहित।

## इनपुट {#input}

`I18nHeadInput` (`@i18n-micro/types` से):

| Key | टाइप | प्रभाव |
| --- | --- | --- |
| `htmlAttrs` | `Record<string, string>` | `<html>` attributes (`lang`, `dir`) में मर्ज होता है। |
| `meta` | `I18nHeadMeta[]` | जनरेट किए गए टैग के बाद जोड़ा जाता है; समान `id`, `property` या `name` वाले टैग को बदल देता है। |
| `link` | `I18nHeadLink[]` | जनरेट किए गए links के बाद जोड़ा जाता है; समान `id`, या `rel` + `hreflang` वाले link को बदल देता है। |
| `replace.canonical` | `string \| false` | canonical `href` को बदलें, या link हटा दें। |
| `replace.hreflang` | `I18nHeadLink[] \| false` | **हर** `rel="alternate"` link को बदलें या हटाएँ, `x-default` सहित। |
| `replace.xDefault` | `I18nHeadLink \| false` | `x-default` link को बदलें या हटाएँ। |
| `replace.ogLocale` | `string \| false` | `og:locale` को बदलें या हटाएँ। |
| `replace.ogUrl` | `string \| false` | `og:url` को बदलें या हटाएँ। |
| `replace.ogAlternates` | `string[] \| false` | इन locale codes से (`og` / `iso` के ज़रिए) `og:locale:alternate` को फिर से बनाएँ, वर्तमान locale, अज्ञात codes और बिना `og` या `iso` मान वाले codes को छोड़ते हुए, या उन्हें हटा दें। |
| `disable` | `I18nHeadDisableGroup[]` | जनरेट किए गए समूह हटाएँ: `'hreflang'` (`x-default` नहीं), `'x-default'`, `'canonical'`, `'og'` (`og:locale` + `og:url`), `'og-alternates'`, `'html'`। |

लागू होने का क्रम: `disable`, फिर `replace`, फिर `htmlAttrs`, `meta`, `link`।

## उदाहरण {#example}

एक लेख जो केवल कुछ locales में मौजूद है, जिसके वैकल्पिक URL API से आते हैं:

```vue
<script setup lang="ts">
const route = useRoute()
const { t } = useI18n()
const { data: article } = await useFetch<{ title: string; urls: Record<string, string> }>(`/api/articles/${route.params.slug}`)

useI18nHead(() => {
  if (!article.value) return null
  const codes = Object.keys(article.value.urls)
  return {
    meta: [{ property: 'og:title', content: article.value.title || t('blog.title') }],
    replace: {
      hreflang: codes.map((code) => ({ rel: 'alternate', hreflang: code, href: article.value!.urls[code]! })),
      ogAlternates: codes,
    },
  }
})
</script>
```

जब मान `t()` या async डेटा से आते हों, तो यहाँ की तरह getter पास करें: यह locale बदलने पर फिर से चलता है। सादा ऑब्जेक्ट एक बार पढ़ा जाता है।
