## 🚀 त्वरित प्रारंभ

### इंस्टॉलेशन

अपने Nuxt एप्लिकेशन में मॉड्यूल इंस्टॉल करें:

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

### बुनियादी कॉन्फ़िगरेशन

मॉड्यूल को अपने `nuxt.config.ts` में जोड़ें:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

<Tip>
- **रूट-लेवल फ़ाइलें** (`locales/en.json`, आदि) — पूरे ऐप में साझा अनुवाद (मेनू, फ़ुटर, सामान्य UI)। `translationPayloads.mode: 'premerged'` (डिफ़ॉल्ट) के साथ, वे बिल्ड टाइम पर हर पेज में मर्ज हो जाती हैं।
- **पेज-विशिष्ट फ़ाइलें** (`locales/pages/<route>/<locale>.json`) — विशिष्ट पेजों के लिए अद्वितीय अनुवाद, केवल तब लोड होते हैं जब पेज विज़िट किया जाता है
- **डायनामिक रूट्स** — `pages/articles/[id].vue`, `locales/pages/articles-id/` से मैप करता है (कोष्ठक डैश से बदले जाते हैं)
- **ऑटो-जनरेशन** — `nuxt dev` के दौरान गुम होने पर सभी अनुवाद फ़ाइलें स्वतः बनती हैं
</Tip>

<Info>
मॉड्यूल दोनों लेआउट का समर्थन करता है:

- **Pages**: `pages/**/*.vue` (Nuxt 3) या `app/pages/**/*.vue` (Nuxt 4)
- **Translations**: `locales/` को डिफ़ॉल्ट रूप से **प्रोजेक्ट रूट** पर रखें (अनुशंसित परंपरा), `app/` के अंदर नहीं

```tree
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   ├── en.json
│   └── pages/
└── nuxt.config.ts
```

वैकल्पिक colocation: `i18n: \{ translationDir: 'app/locales' \}` ([fixture `n3`](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/n3) देखें)।

वैकल्पिक CLI हेल्पर `text-to-i18n` के लिए, [`nuxt-i18n-micro-cli` ≥ 2.1.1](/guides/cli#-text-to-i18n-command) का उपयोग करें ताकि `app/pages` और `app/components` को प्रोजेक्ट रूट से स्कैन किया जा सके।
</Info>

### बुनियादी उपयोग

अपने कंपोनेंट्स में अनुवादों का उपयोग करें:

```vue
<template>
  <div>
    <h1>{{ $t('welcome') }}</h1>
    <p>{{ $t('description', { name: 'World' }) }}</p>

    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" @click="$switchLocale(locale.code)">
        {{ locale.code }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useI18n } from '#imports'

const { $t, $getLocales, $switchLocale } = useI18n()
</script>
```
