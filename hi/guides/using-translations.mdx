# कंपोनेंट्स में अनुवादों का उपयोग

एक बार मॉड्यूल इंस्टॉल और कॉन्फ़िगर हो जाने पर, आप अपने Vue टेम्पलेट्स और स्क्रिप्ट्स के भीतर `$t('your_key')` कॉल करके अनुवाद प्रदर्शित कर सकते हैं।

## 1. रूट-लेवल और पेज-विशिष्ट अनुवाद फ़ाइलें

1. **रूट-लेवल** अनुवाद सीधे `/locales` फ़ोल्डर के अंतर्गत रहते हैं (जैसे `/locales/en.json`, `/locales/fr.json`)। बिल्ड टाइम पर, वे स्वचालित रूप से हर पेज-विशिष्ट फ़ाइल में मर्ज हो जाते हैं, जिससे वे सभी पेजों पर उपलब्ध होते हैं।
2. **पेज-विशिष्ट** अनुवाद `/locales/pages/...` के अंतर्गत रहते हैं, जो आपकी Nuxt पेजेस फ़ोल्डर संरचना से मेल खाते हैं:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. `$t` के साथ टेम्पलेट उपयोग

आप अपनी `.vue` फ़ाइलों में सीधे टेम्पलेट में `$t` का उपयोग कर सकते हैं:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
`$t` **objects** लौटा सकता है यदि key एक नेस्टेड JSON node की ओर इंगित करती है (जैसे `$t('header')` → `\{ title: "Hi" \}`)। टेम्पलेट्स में यह `[object Object]` के रूप में रेंडर होता है। जब आपको गारंटीड स्ट्रिंग की आवश्यकता हो तो `$ts` का उपयोग करें, या `$t('header.title')` जैसी अधिक विशिष्ट key प्रदान करें। विवरण के लिए [API संदर्भ — $t बनाम $ts](/api/methods#t) देखें।
</Tip>

## 3. वर्तमान लोकेल को स्विच करना

अपने ऐप में भाषाओं को बदलने के लिए, आप `useI18n()` से `$locale` प्राप्त कर सकते हैं और उसे एक नया कोड असाइन कर सकते हैं:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. नेस्टेड Keys और Placeholders

- **नेस्टेड keys** dot notation का उपयोग करती हैं, जैसे `nested.key.deeper`।
- **Placeholders** आपको गतिशील मान डालने की अनुमति देते हैं:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. टिप्स और सर्वोत्तम प्रथाएँ

- **विरोधाभासी Keys**: यदि पेज-विशिष्ट फ़ाइल में रूट-लेवल फ़ाइल के समान key है, तो पेज-विशिष्ट संस्करण को प्राथमिकता मिलती है (रूट अनुवाद बिल्ड टाइम पर आधार के रूप में मर्ज किए जाते हैं)।
- **पेज फ़ाइलों को निष्क्रिय करना**: यदि आप पेज-विशिष्ट अनुवादों का उपयोग नहीं करना चाहते हैं, तो आप अपने Nuxt कॉन्फ़िग में `disablePageLocales: true` सेट कर सकते हैं। इस तरह, केवल `/locales/*.json` फ़ाइलों का उपयोग किया जाता है।
- **कोई प्रत्यक्ष Imports नहीं**: आपको `import \{ useI18n \} from 'nuxt-i18n-micro'` करने की आवश्यकता नहीं है; मॉड्यूल का ऑटो-इंजेक्शन फ़ीचर इसे आपके लिए संभालता है।

बस इतना ही! इन चरणों के साथ, आप जल्दी से रूट-लेवल या पेज-विशिष्ट JSON फ़ाइलों से **अनुवाद प्राप्त करना** शुरू कर सकते हैं और `$t` का उपयोग करके अपने Nuxt एप्लिकेशन में उन्हें **प्रदर्शित** कर सकते हैं।

## अतिरिक्त संसाधन

अधिक उन्नत सुविधाओं का पता लगाने के लिए, इन्हें अवश्य देखें:

1. **`<i18n-t>` कंपोनेंट**  
   `<i18n-t>` कंपोनेंट `$t` का एक शक्तिशाली विकल्प है, विशेष रूप से नेस्टेड elements, उन्नत placeholder उपयोग, और अधिक जटिल अनुवाद संरचनाओं से संबंधित स्थितियों के लिए उपयोगी।

- **दस्तावेज़ीकरण**: [i18n-t](/api/components/i18n-t)

2. **`useI18n` Composable**  
   `useI18n` composable अनुवादों का प्रबंधन करने, लोकेल स्विचिंग हैंडल करने, स्वरूपण, और अधिक के लिए फ़ंक्शन और reactive properties का एक पूरा सेट प्रदान करता है।

- **दस्तावेज़ीकरण**: [useI18n](/api/composables/use-i18n)
