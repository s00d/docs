---

`@i18n-micro/types-generator` आपके अनुवाद फ़ोल्डर की हर JSON फ़ाइल पढ़ता है और एक डिक्लेरेशन लिखता है जिसमें सभी कुंजियाँ सूचीबद्ध होती हैं। इसे तब जोड़ें जब आप चाहते हैं कि आपका एडिटर `t()`, `$t()` और `<I18nT keypath>` में कुंजियाँ सुझाए। यह Nuxt मॉड्यूल के रूप में और Vite या Rollup प्लगइन के रूप में काम करता है, और किसी फ़ाइल के बदलने पर फिर से जनरेट करता है।

## इंस्टॉल करें {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/types-generator
```

```bash npm
npm install -D @i18n-micro/types-generator
```

```bash yarn
yarn add -D @i18n-micro/types-generator
```

</CodeGroup>

Peer निर्भरता: `@nuxt/kit` `^3.18.0 || ^4.0.0`। केवल `/nuxt` एंट्री इसे इम्पोर्ट करती है; केवल-Vite प्रोजेक्ट में peer चेतावनी को अनदेखा किया जा सकता है।

## Nuxt {#nuxt}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro', '@i18n-micro/types-generator/nuxt'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

मॉड्यूल `.nuxt/types/i18n-micro.d.ts` लिखता है और Nuxt इसे टाइप संदर्भ में जोड़ता है; हाथ से कुछ भी शामिल करने की ज़रूरत नहीं। यह `i18nTypes.translationDir` पढ़ता है, अन्यथा वहाँ से जहाँ `nuxt-i18n-micro` अनुवाद पढ़ता है: हर लेयर में `translationDir` (`i18n` या इनलाइन मॉड्यूल विकल्पों से, डिफ़ॉल्ट `'locales'`), और `additionalTranslationDirs`। उस फ़ोल्डर के अंतर्गत किसी JSON फ़ाइल को संपादित करने से `nuxi dev` में टाइप्स फिर से जनरेट होते हैं। Nuxt में `i18nTypes.outputFile` को अनदेखा किया जाता है (एक चेतावनी यह बताती है)।

## Vite {#vite}

`I18nTypesPlugin` एक Vite प्लगइन है, जिसे Rollup भी स्वीकार करता है। किसी अन्य बंडलर के लिए, एक स्क्रिप्ट में `generateTypes` कॉल करें।

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { I18nTypesPlugin } from '@i18n-micro/types-generator'

export default defineConfig({
  plugins: [
    vue(),
    I18nTypesPlugin({
      srcDir: process.cwd(),
      translationDir: 'src/locales',
      outputFile: 'src/i18n-micro.d.ts',
    }),
  ],
})
```

| विकल्प | आवश्यक | नोट्स |
| --- | --- | --- |
| `srcDir` | हाँ | बेस डायरेक्टरी; `translationDir` इसके सापेक्ष resolve होता है। |
| `translationDir` | हाँ | JSON फ़ाइलों वाला फ़ोल्डर (`pages/` जैसे सबफ़ोल्डर सहित), या फ़ोल्डरों की एक array। |
| `outputFile` | नहीं | डिक्लेरेशन कहाँ लिखना है; डिफ़ॉल्ट `<srcDir>/i18n-micro.d.ts`। |

प्लगइन बिल्ड शुरू होने पर एक बार जनरेट करता है और, dev सर्वर पर, फ़ोल्डर में बदलाव के 300 ms बाद फिर से जनरेट करता है। सुनिश्चित करें कि आपके `tsconfig.json` का `include` आउटपुट फ़ाइल को कवर करता है।

## कुंजियों का उपयोग करें {#use-the-keys}

जनरेट की गई फ़ाइल `@i18n-micro/types` में `DefineLocaleMessage` को augment करती है, जो `TranslationKey` को आपकी कुंजियों में बदल देता है:

```ts
declare module '@i18n-micro/types' {
  export interface DefineLocaleMessage {
    nav: object
    'nav.home': string
    'profile.title': string
  }
}
```

कुंजियाँ वे हैं जिनका `t()` उत्तर देता है, ऑब्जेक्ट भी, हर लोकेल और हर पेज फ़ाइल से, उनके JSON मान के टाइप के साथ। `TranslationKey` उन कुंजियों और किसी भी string का union है, इसलिए आपको त्रुटियाँ नहीं, बल्कि ऑटोकम्प्लीट मिलता है: गलत वर्तनी वाली या डायनेमिक कुंजी फिर भी compile होती है। Params और रिटर्न मान टाइप नहीं किए जाते।

किसी ज्ञात प्रीफ़िक्स के अंतर्गत डायनेमिक कुंजियों के लिए, `ScopedKey<'prefix'>` मेल खाने वाली कुंजियों तक सीमित करता है:

```ts
import type { ScopedKey } from '@i18n-micro/types'

const statusText = (status: string) => t(`status.${status}` as ScopedKey<'status'>)
```

`TranslationKey` और `ScopedKey` `@i18n-micro/types` से आते हैं (React, Preact और Solid `TranslationKey` को फिर से एक्सपोर्ट करते हैं; Vue नहीं करता)।

## API {#api}

| एक्सपोर्ट | एंट्री | नोट्स |
| --- | --- | --- |
| `I18nTypesPlugin(options)` | `@i18n-micro/types-generator` | Vite और Rollup प्लगइन |
| `generateTypes(options)` | `@i18n-micro/types-generator` | फ़ाइल लिखता है, उसका पाथ लौटाता है |
| `getTypesString(options)` | `@i18n-micro/types-generator` | बिना लिखे डिक्लेरेशन लौटाता है |
| `formatKeyProperty(key)` | `@i18n-micro/types-generator` | हेल्पर |
| Nuxt मॉड्यूल (`configKey: 'i18nTypes'`) | `@i18n-micro/types-generator/nuxt` | विकल्प `translationDir` |

पूर्ण सिग्नेचर: [पैकेज संदर्भ](/hi/api/packages/types-generator)।
