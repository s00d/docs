`@i18n-micro/*` पैकेज Nuxt I18n Micro के अनुवाद core को Vue, React, Preact, Solid, Astro, VitePress और सादे JavaScript तक लाते हैं। इनका उपयोग तब करें जब आपका ऐप Nuxt ऐप नहीं है, या जब Nuxt के बाहर किसी script या सर्वर को वही अनुवाद फ़ाइलें चाहिए। हर पैकेज एक ही instance मॉडल, एक ही router adapter contract और वही चार components साझा करता है, जिनका वर्णन इस पेज पर एक बार किया गया है।

Router entry एक अलग import है, इसलिए बिना router वाला ऐप कभी router को bundle नहीं करता।

`@i18n-micro/core`, `@i18n-micro/types` और `@i18n-micro/utils` इन पैकेजों के साथ इंस्टॉल होते हैं; आप इन्हें शायद ही कभी सीधे import करते हैं। हर export के सिग्नेचर जनरेट किए गए [पैकेज संदर्भ](/hi/api/packages/overview) पर हैं।

हर पैकेज का रिपॉज़िटरी में `packages/<name>/playground` के तहत एक playground है।

## Instance {#the-instance}

`createI18n(options)` एक instance लौटाता है जिसमें dictionaries, वर्तमान locale और वर्तमान route होते हैं। विकल्प हर पैकेज में समान हैं:

| विकल्प | टाइप | डिफ़ॉल्ट | टिप्पणी |
| --- | --- | --- | --- |
| `locale` | `string` | आवश्यक | सक्रिय locale। |
| `fallbackLocale` | `string` | `locale` | जब `locale` में कोई key गायब हो तब देखा जाता है। |
| `messages` | `Record<locale, Translations>` | `{}` | Root dictionaries (`'index'` route)। |
| `routeMessages` | `Record<route, Record<locale, Translations>>` | `{}` | Route dictionaries। केवल Runtime, React, Preact, Node और VitePress। |
| `plural` | `PluralFunc` | `defaultPlural` | Custom plural नियम। |
| `missingWarn` | `boolean` | `true` | गायब key के लिए ब्राउज़र में केवल-dev `console.warn`। |
| `missingHandler` | `(locale, key, routeName) => void` | — | चेतावनी के बजाय कॉल किया जाता है। |
| `numberFormats` | `Record<locale, Record<name, Intl.NumberFormatOptions>>` | — | नामित formats: `tn(9.5, 'currency')`। |
| `datetimeFormats` | `Record<locale, Record<name, Intl.DateTimeFormatOptions>>` | — | नामित formats: `td(date, 'short')`। |
| `timeZone` | `string` | रनटाइम का zone | `td` तारीखों के लिए IANA zone; यह `tdr` को प्रभावित नहीं करता। इसे सेट करें ताकि सर्वर और ब्राउज़र एक ही तारीख render करें। |
| `now` | `() => number` | `Date.now` | `tdr` की घड़ी। hydration को सर्वर का समय दें ताकि दोनों एक ही टेक्स्ट render करें। |
| `localeIso` | `Record<code, string>` | — | plural नियमों के लिए इस्तेमाल होने वाला BCP 47 टैग (`ua` → `uk-UA`)। React, Preact और Solid इसे provider के `locales` में `iso` से लेते हैं। |

Dictionaries `i18n.storage.translations` में रहती हैं, एक `Map` जिसकी key `locale:route` है (`en:index`, `en:about`)।

कोई key वर्तमान route की dictionary में, फिर root dictionary में देखी जाती है, पहले `locale` के लिए, फिर `fallbackLocale` के लिए। गायब key ख़ुद key को लौटाती है (या आपके द्वारा पास किया गया `defaultValue`)।

```ts
i18n.addTranslations('en', { nav: { home: 'Home' } }) // root, deep-merged
i18n.addRouteTranslations('en', 'about', { title: 'About us' }) // route chunk
i18n.addTranslations('en', { nav: { home: 'Start' } }, false) // replace instead of merge
i18n.setRoute('about')
i18n.t('title') // 'About us'
i18n.t('nav.home') // 'Start' (root key, still visible on the route)
```

### अनुवाद और फ़ॉर्मैट {#translate-and-format}

| Method | लौटाता है |
| --- | --- |
| `t(key, params?, defaultValue?, routeName?)` | `{param}` interpolate करके मान (string, number, object)। |
| `ts(...)` | `t` जैसा ही, string के रूप में। |
| `tc(key, count \| params, defaultValue?)` | Plural रूप। |
| `tn(value, options \| name)` | सक्रिय locale में `Intl.NumberFormat`। |
| `td(value, options \| name)` | `Intl.DateTimeFormat`। |
| `tdr(value, options?)` | सापेक्ष समय (`3 days ago`)। |
| `has(key, routeName?)` | `true` जब सक्रिय locale में key हो (route या root dictionary; fallback की जाँच नहीं होती)। |

`defaultPlural` मान को `|` पर विभाजित करता है और index `count` वाला रूप चुनता है, अंतिम रूप तक सीमित; ऋणात्मक, भिन्नात्मक या `NaN` count अंतिम रूप चुनता है।

Custom `plural` को `(key, count, params, locale, getter)` मिलते हैं। मान `getter(key)` से पढ़ें; key को विभाजित न करें:

```ts
import type { PluralFunc } from '@i18n-micro/vue'

const plural: PluralFunc = (key, count, params, _locale, getter) => {
  const value = getter(key)
  if (typeof value !== 'string') return null
  const forms = value.split('|').map((form) => form.trim())
  return (count === 1 ? forms[0] : forms[1] ?? forms[0])!.replace('{count}', String(count))
}
```

## Router adapter {#router-adapter}

SPA पैकेज किसी router पर निर्भर नहीं हैं। Router adapter (`I18nRoutingStrategy`) उन्हें बताता है कि वर्तमान पाथ कैसे पढ़ें, navigate कैसे करें और स्थानीयकृत पाथ कैसे बनाएँ। Built-in adapters `defaultLocale` को छोड़कर हर locale पर prefix लगाते हैं (`/about`, `/de/about`)।

| Member | आवश्यक | इनके द्वारा उपयोग |
| --- | --- | --- |
| `getCurrentPath(): string` | हाँ | सक्रिय link जाँच (पेज के अनुसार, query और hash की गिनती नहीं होती), `switchLocale` (उन्हें बनाए रखता है) |
| `push({ path }): void` | हाँ | `switchLocale`, `linkComponent` के बिना `<I18nLink>`, `<I18nSwitcher>` |
| `replace({ path }): void` | हाँ | — |
| `resolvePath(to, locale)` | नहीं | `localePath`, `localeRoute`, `<I18nLink>`; इसके बिना पाथ जैसे हैं वैसे लौटाए जाते हैं |
| `linkComponent` | नहीं | `<I18nLink>` `<a>` के बजाय इसे render करता है (जैसे `RouterLink`) |
| `getRoute()` | नहीं | SEO helpers के लिए `{ fullPath, query }` |

Vue, React, Preact और Solid में `push` और `replace` आवश्यक हैं। Astro का अपना, सर्वर-साइड adapter है जिसमें `push`/`replace` वैकल्पिक हैं (देखें [Astro](/hi/integrations/astro-package#router-adapter))।

किसी भी history-आधारित router के लिए एक न्यूनतम adapter:

```ts
import type { I18nRoutingStrategy } from '@i18n-micro/react'

const locales = ['en', 'de']
const stripLocale = (path: string) => path.replace(/^\/(en|de)(?=\/|$)/, '') || '/'

export const historyAdapter: I18nRoutingStrategy = {
  getCurrentPath: () => window.location.pathname + window.location.search + window.location.hash,
  push: ({ path }) => window.history.pushState({}, '', path),
  replace: ({ path }) => window.history.replaceState({}, '', path),
  resolvePath: (to, locale) => {
    const path = stripLocale(typeof to === 'string' ? to : to.path || '/')
    return locale === 'en' ? path : `/${locale}${path === '/' ? '' : path}`
  },
}
```

## Components {#components}

Vue, React, Preact और Solid वही चार components देते हैं। उनके props मेल खाते हैं; React, Preact और Solid अन्य props को root element तक पहुँचा देते हैं।

### `<I18nT>` {#&lt;i18nt&gt;}

| Prop | टाइप | टिप्पणी |
| --- | --- | --- |
| `keypath` | `string` | आवश्यक |
| `params` | `object` | interpolation मान |
| `plural` | `number \| string` | `tc(keypath, count)` render करता है |
| `number` | `number \| string` | `tn(number)` को `{number}` के रूप में पास करता है |
| `date` | `Date \| string \| number` | `td(date)` को `{date}` के रूप में पास करता है |
| `relativeDate` | `Date \| string \| number` | `tdr(relativeDate)` को `{relativeDate}` के रूप में पास करता है |
| `tag` | `string` | wrapper element, डिफ़ॉल्ट `span` |
| `html` | `boolean` | अनुवाद को HTML के रूप में render करें; यह भरोसेमंद होना चाहिए, params escape किए जाते हैं |
| `defaultValue` | `string` | गायब key की जगह लेता है, और जब `hideIfEmpty` ख़ाली मान को छिपाता है तब अकेला render होता है |
| `hideIfEmpty` | `boolean` | ख़ाली अनुवाद के लिए कुछ भी render न करें |
| `customPluralRule` | `PluralFunc` | इस element के लिए plural नियम |

केवल एक formatting prop लागू होता है, इस क्रम में जाँचा जाता है: `number`, `date`, `relativeDate`, `plural`।

#### Rich text {#rich-text}

एक `{placeholder}` में element हो सकता है। Vue में यह एक नामित slot है; React, Preact और Solid में `components` prop नाम के अनुसार elements, या एक element लौटाने वाले functions, देता है। दोनों ही तरह से यह समान नाम वाले param पर भारी पड़ता है, हर branch में काम करता है, और उस locale में भी बना रहता है जो placeholders का क्रम बदल देता है।

```tsx
// { "terms": "I accept the {link} of {company}" }
<I18nT keypath="terms" params={{ company: 'ACME' }} components={{ link: <a href="/terms">terms</a> }} />
```

Solid में जब कोई placeholder दोहराया जाता है तो function पास करें: एक node एक ही जगह पर रहता है। `children` टेक्स्ट की जगह लेते हैं, function के रूप में उन्हें `{ translation }` मिलता है, Vue के default slot की तरह। `html` इन सभी को अनदेखा करता है।

### `<I18nLink>` {#&lt;i18nlink&gt;}

| Prop | टाइप | टिप्पणी |
| --- | --- | --- |
| `to` | `string \| { path }` | adapter के `resolvePath` के ज़रिए स्थानीयकृत |
| `activeStyle` | style ऑब्जेक्ट | वर्तमान पेज पर `style` के ऊपर मर्ज होता है; React, Preact और Solid इसे ऊपर के किसी section पर भी लागू करते हैं |
| `localeRoute` | function | इस link के लिए `resolvePath` को ओवरराइड करता है |

External URLs (`https://`, `mailto:`, `tel:`) `<a target="_blank" rel="noopener noreferrer">` के रूप में render होते हैं; आपका अपना `target` या `rel` मान्य होता है। `onClick` हमेशा चलता है। Modifier वाला क्लिक, कोई दूसरा mouse button या कोई `target` ब्राउज़र पर छोड़ दिया जाता है।

### `<I18nSwitcher>` {#&lt;i18nswitcher&gt;}

सक्षम locales का एक dropdown (`disabled: true` वाले locales छिपे रहते हैं) inline डिफ़ॉल्ट styles के साथ। इसके items links हैं, जिनमें locale से `lang`, `hreflang` और `dir` होते हैं। डिफ़ॉल्ट रूप से, किसी एक पर क्लिक करने से locale सेट होता है और adapter का `push` स्थानीयकृत वर्तमान पाथ के साथ कॉल होता है; `switchLocale` prop उस क्रिया को बदल देता है। `localeRoute` होने और router न होने पर ब्राउज़र link का अनुसरण करता है। Escape या बाहर क्लिक करने से यह बंद हो जाता है।

| Prop | टिप्पणी |
| --- | --- |
| `locales`, `currentLocale`, `getLocaleName` | दिए गए मानों को ओवरराइड करते हैं |
| `switchLocale(code)` | built-in switch को बदल देता है |
| `localeRoute` | `resolvePath` को बदल देता है |
| `customLabels` | `{ de: 'DE' }` |
| `customWrapperStyle`, `customButtonStyle`, `customDropdownStyle`, `customItemStyle`, `customLinkStyle`, `customActiveLinkStyle`, `customDisabledLinkStyle`, `customIconStyle` | style ओवरराइड |

### `<I18nGroup>` {#&lt;i18ngroup&gt;}

एक `<div class="i18n-group">` जो अपने children को prefix वाला `t` देता है। यह अपने अंदर के `<I18nT>` या `t()` कॉल पर prefix **नहीं** लगाता; केवल वही `t` prefix वाला होता है जो यह नीचे पास करता है।

| Prop | टिप्पणी |
| --- | --- |
| `prefix` | आवश्यक, जैसे `'profile'` |
| `groupClass` | wrapper पर अतिरिक्त class |

Prefix वाला `t` Vue में scoped slot (`v-slot="{ t }"`) के ज़रिए और React, Preact और Solid में render-prop child (`{({ t }) => …}`) के ज़रिए आता है।

## Typed keys {#typed-keys}

`t()` कोई भी string स्वीकार करता है। अपनी keys के लिए autocomplete पाने के लिए [types generator](/hi/integrations/types-generator) से एक declaration जनरेट करें। Keys सुझाई जाती हैं, बाध्य नहीं की जातीं, और params typed नहीं होते।

## Nuxt मॉड्यूल से तुलना {#compared-with-the-nuxt-module}

पैकेजों में कोई file-based routing, कोई server middleware और कोई translation loader नहीं है: आप तय करते हैं कि JSON कब लोड करना है (`import`, `fetch`, या सर्वर पर `@i18n-micro/node`) और कौन-सा router adapter इस्तेमाल करना है। Locale detection, SEO meta और route generation Nuxt की सुविधाएँ हैं; Astro के पास detection के लिए अपना middleware और SEO के लिए `useLocaleHead` है।
