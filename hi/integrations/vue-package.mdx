`@i18n-micro/vue` एक Vue 3 प्लगइन है जिसमें Nuxt I18n Micro का अनुवाद कोर है: reactive `t()`, ग्लोबल `$t`, चार कंपोनेंट और एक वैकल्पिक vue-router adapter। इसका उपयोग ऐसे Vite या SSR Vue ऐप में करें जो Nuxt से नहीं बना है। इंस्टेंस मॉडल, राउटर अनुबंध और कंपोनेंट props अन्य पैकेजों के साथ साझा हैं और [फ़्रेमवर्क](/hi/integrations/overview) में वर्णित हैं।

## इंस्टॉल करें {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vue
```

```bash npm
npm install @i18n-micro/vue
```

```bash yarn
yarn add @i18n-micro/vue
```

</CodeGroup>

Peer dependencies: `vue` `^3.3.0`; `vue-router` `^4.5.1 || ^5.0.0` (वैकल्पिक, केवल `@i18n-micro/vue/router` के लिए)। प्रकाशित टाइप को `skipLibCheck: false` के साथ Vue 3.5.5 या बाद का संस्करण चाहिए; `skipLibCheck: true` के साथ, जो सामान्य टेम्पलेट सेटिंग है, पुराने संस्करण भी कंपाइल हो जाते हैं।

## सेटअप {#setup}

```ts
// src/main.ts
import { createApp } from 'vue'
import { createI18n } from '@i18n-micro/vue'
import App from './App.vue'
import en from './locales/en.json'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales: [
    { code: 'en', iso: 'en-US', displayName: 'English' },
    { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
  ],
  defaultLocale: 'en',
})

createApp(App).use(i18n).mount('#app')
```

`useI18n()` के लिए `locales` और `defaultLocale` आवश्यक हैं: इनके बिना यह `I18nLocalesKey not provided` throw करता है। इन्हें `createI18n` को दें (जैसा ऊपर है), `useI18n({ locales, defaultLocale })` को दें, या `app.provide(I18nLocalesKey, …)` और `app.provide(I18nDefaultLocaleKey, …)` के ज़रिए दें।

प्लगइन `I18nT`, `I18nLink`, `I18nGroup` और `I18nSwitcher` को ग्लोबल रूप से रजिस्टर करता है और टेम्पलेट में `$t`, `$ts`, `$tc`, `$tn`, `$td`, `$tdr`, `$has` और `$i18n` जोड़ता है। कंपोनेंट के बाहर इंस्टेंस `i18n.global` है। अन्य विकल्प [इंस्टेंस](/hi/integrations/overview#the-instance) में हैं; Vue में `routeMessages` उपलब्ध नहीं है, `addRouteTranslations` का उपयोग करें।

## अनुवाद करें {#translate}

```vue
<script setup lang="ts">
import { useI18n } from '@i18n-micro/vue'

const { t, tc, tn } = useI18n()
</script>

<template>
  <h1>{{ t('greeting', { name: 'Ada' }) }}</h1>
  <!-- Hello, Ada! -->
  <p>{{ tc('apples', 3) }}</p>
  <!-- 3 apples -->
  <p>{{ $t('nav.home') }} · {{ tn(1234.5) }}</p>
</template>
```

`useI18n()` अनुवाद मेथड (`t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`), `locale` (एक writable computed), `getLocale`, `getLocales`, `defaultLocale()`, `getLocaleName`, `localePath`, `localeRoute`, `switchLocale`, `setRoute`, `getRoute`, `addTranslations`, `addRouteTranslations`, `mergeTranslations`, `resolveTranslations`, `setTranslation`, `clearCache` और `instance` लौटाता है।

किसी भी समय और डिक्शनरी लोड करें; उन्हें पढ़ने वाला हर कंपोनेंट फिर से रेंडर होता है:

```ts
const { addTranslations, addRouteTranslations, setRoute } = useI18n()

addTranslations('de', (await import('./locales/de.json')).default)
addRouteTranslations('en', 'about', { title: 'About us' })
setRoute('about') // t('title') now reads the 'about' dictionary first
```

## लोकेल बदलें {#switch-locale}

```ts
const { locale, switchLocale } = useI18n()

locale.value = 'de' // only the locale
switchLocale('de') // the locale, then router.push to the localized current path
```

लोकेल बदलने से पहले या बाद में उसकी डिक्शनरी लोड करें; बदलने से कुछ भी fetch नहीं होता।

`<I18nGroup>` अपने slot को प्रीफ़िक्स वाला `t` देता है। `<I18nT>` के अंदर या साधारण `t()` की कुंजियों पर प्रीफ़िक्स नहीं लगता:

```vue
<I18nGroup prefix="profile" v-slot="{ t }">
  <h2>{{ t('title') }}</h2>
  <!-- profile.title -->
</I18nGroup>
```

## रूटिंग {#routing}

vue-router adapter एक सबपाथ में रहता है ताकि मुख्य एंट्री कभी `vue-router` इम्पोर्ट न करे:

```ts
// src/main.ts
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import { createI18n } from '@i18n-micro/vue'
import { createVueRouterAdapter } from '@i18n-micro/vue/router'
import App from './App.vue'
import Home from './pages/Home.vue'
import About from './pages/About.vue'
import en from './locales/en.json'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English' },
  { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
]

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/:locale(de)?', component: Home },
    { path: '/:locale(de)?/about', component: About },
  ],
})

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales,
  defaultLocale: 'en',
  routingStrategy: createVueRouterAdapter(router, locales, 'en'),
})

createApp(App).use(router).use(i18n).mount('#app')
```

`createVueRouterAdapter(router, locales, defaultLocale)` डिफ़ॉल्ट को छोड़कर हर लोकेल पर प्रीफ़िक्स लगाता है (`/about`, `/de/about`) और `<I18nLink>` को `RouterLink` के रूप में रेंडर करता है। रूट से लोकेल खुद पढ़ें, उदाहरण के लिए `router.beforeEach` में, और `i18n.global.locale.value` सेट करें। आप बाद में `i18n.setRoutingStrategy(adapter)` से भी adapter जोड़ सकते हैं; कस्टम adapter के लिए [Router adapter](/hi/integrations/overview#router-adapter) देखें।

## SSR {#ssr}

- राउटर, i18n इंस्टेंस और ऐप को प्रति-अनुरोध रेंडर फ़ंक्शन के अंदर बनाएँ। एक साझा इंस्टेंस एक विज़िटर का लोकेल दूसरे तक लीक कर देगा।
- सर्वर पर `createMemoryHistory()` का उपयोग करें, URL से लोकेल लें, और `renderToString` से पहले उसकी डिक्शनरी (और फ़ॉलबैक की भी) लोड करें।
- लोकेल को क्लाइंट तक भेजें (उदाहरण के लिए `window.__STATE__` script में) और क्लाइंट इंस्टेंस को उसी `locale` के साथ बनाएँ ताकि hydration मेल खाए।
- `<I18nSwitcher>` केवल ड्रॉपडाउन खुला होने पर `window.location` पढ़ता है, इसलिए यह सर्वर पर रेंडर होता है।

`packages/vue/playground` में एक पूरी `entry-server.ts` / `entry-client.ts` जोड़ी है।

## SEO head {#seo-head}

`useLocaleHead(options)` लोकेल और राउटर adapter से `lang`/`dir`, canonical, `hreflang` और `og:locale` टैग बनाता है। रूट बदलने पर `updateMeta()` कॉल करें और `metaObject` को अपने head मैनेजर को दें:

```ts
import { watch } from 'vue'
import { useRoute } from 'vue-router'
import { useHead } from '@unhead/vue'
import { useLocaleHead } from '@i18n-micro/vue'

const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
watch(() => route.fullPath, () => updateMeta(), { immediate: true })
useHead(metaObject)
```

विकल्प: `baseUrl` (स्ट्रिंग या फ़ंक्शन), `addDirAttribute` (डिफ़ॉल्ट `true`), `addSeoAttributes` (डिफ़ॉल्ट `true`), `identifierAttribute` (डिफ़ॉल्ट `'id'`), `hreflangBaseLanguage` (डिफ़ॉल्ट `false`)। `disabled: true` या `seo: false` वाले लोकेल को कोई alternate लिंक नहीं मिलता।
