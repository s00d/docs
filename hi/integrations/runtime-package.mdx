`@i18n-micro/runtime` फ़्रेमवर्क-स्वतंत्र i18n इंस्टेंस है: डिक्शनरी, `t()`, बहुवचन, `Intl` फ़ॉर्मेटिंग और एक बदलाव सब्सक्रिप्शन, बिना `fs` और बिना किसी फ़्रेमवर्क के। इसका उपयोग सादे TypeScript, किसी वेब वर्कर, किसी एज फ़ंक्शन में, या अपनी स्वयं की बाइंडिंग के आधार के रूप में करें। React, Preact, Node और Astro पैकेज इसी क्लास को विस्तारित करते हैं।

## इंस्टॉल करें {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/runtime
```

```bash npm
npm install @i18n-micro/runtime
```

```bash yarn
yarn add @i18n-micro/runtime
```

</CodeGroup>

कोई पीयर डिपेंडेंसी नहीं। डिस्क पर अनुवाद फ़ाइलों के लिए [`@i18n-micro/node`](/hi/integrations/nodejs-package) का उपयोग करें।

## सेटअप {#setup}

```ts
import { createI18n } from '@i18n-micro/runtime'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    en: { greeting: 'Hello, {name}!', apples: 'no apples | one apple | {count} apples' },
    de: { greeting: 'Hallo, {name}!' },
  },
  routeMessages: {
    about: { en: { title: 'About us' } },
  },
})
```

सभी विकल्प (`plural`, `missingWarn`, `missingHandler`, `numberFormats`, `datetimeFormats`) [इंस्टेंस](/hi/integrations/overview#the-instance) में सूचीबद्ध हैं।

## अनुवाद करें {#translate}

```ts
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.tc('apples', 5) // '5 apples'
i18n.tn(1234.5) // '1,234.5'

i18n.setRoute('about')
i18n.t('title') // 'About us' (route dictionary)
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!' (root, still visible)
```

बाद में और डिक्शनरी लोड करें:

```ts
i18n.loadMessages({ fr: { greeting: 'Bonjour, {name} !' } }, { about: { fr: { title: 'À propos' } } })
i18n.addTranslations('fr', { nav: { home: 'Accueil' } }) // deep merge; pass false to replace

await i18n.loadFromUrl('/locales/fr.json', { locale: 'fr' })
await i18n.loadFromUrl('/locales/pages/about/fr.json', { locale: 'fr', routeName: 'about' })
await i18n.loadFromUrls([
  { url: '/locales/en.json', locale: 'en' },
  { url: '/locales/de.json', locale: 'de' },
])
```

`loadFromUrl` `fetch` का उपयोग करता है (हेडर के लिए `init` पास करें) और non-OK रिस्पॉन्स पर एरर फेंकता है। `loadFromUrls` एक के बाद एक लोड करता है।

## लोकेल बदलें {#switch-locale}

```ts
i18n.locale = 'de'
i18n.t('greeting', { name: 'Ada' }) // 'Hallo, Ada!'
```

लोकेल, रूट और डिक्शनरी के बदलाव सब्सक्राइबर्स को सूचित करते हैं, और इसी तरह फ़्रेमवर्क बाइंडिंग्स फिर से रेंडर होती हैं:

```ts
const stop = i18n.subscribe(() => {
  document.querySelector('#greeting')!.textContent = i18n.t('greeting', { name: 'Ada' }) as string
})
i18n.locale = 'fr'
stop()
```

`getSnapshot()` एक स्ट्रिंग लौटाता है जो हर सूचना पर बदलती है (`useSyncExternalStore`-शैली के स्टोर के लिए)।

## प्रति अनुरोध {#per-request}

इंस्टेंस एक लोकेल और एक रूट रखता है। सर्वर पर, किसी साझा इंस्टेंस को प्रति अनुरोध न बदलें: दो समवर्ती अनुरोध एक-दूसरे का लोकेल देखेंगे। `i18n.fork(locale)` किसी अनुरोध को उसका अपना इंस्टेंस देता है: अपना लोकेल, फ़ॉलबैक और रूट; वही डिक्शनरी, फ़ॉर्मेटर और नियम। फ़ोर्क करने की लागत समान रहती है चाहे कितनी भी डिक्शनरी हों। एक फ़ोर्क अपने पहले स्वयं के लेखन तक अपने पैरेंट में किए गए लेखन देखता है, और उसके लेखन उसी में रहते हैं। [Node.js](/hi/integrations/nodejs-package#per-request) `run` जोड़ता है।

## API {#api}

| सदस्य | टिप्पणियाँ |
| --- | --- |
| `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has` | [अनुवाद और फ़ॉर्मेट](/hi/integrations/overview#translate-and-format) देखें |
| `locale`, `fallbackLocale` | get/set |
| `currentRoute`, `setRoute(name)`, `getRoute()` | सक्रिय रूट, डिफ़ॉल्ट `'index'` |
| `loadMessages(messages?, routeMessages?)` | एक साथ कई लोकेल और रूट मर्ज करें |
| `addTranslations(locale, tree, merge = true)`, `addRouteTranslations(locale, route, tree, merge = true)` | |
| `loadFromUrl(url, { locale?, routeName?, init? })`, `loadFromUrls(entries)` | JSON `fetch` करें |
| `hasTranslation(key)` | सक्रिय लोकेल, कोई भी रूट (`has` के विपरीत, जो सक्रिय रूट और रूट-स्तर की जाँच करता है) |
| `setTranslation(key, value)`, `resolveTranslations()` | एक कुंजी लिखें; मर्ज किया गया ट्री पढ़ें |
| `clear()`, `clearCache()` | हर डिक्शनरी हटाएँ |
| `subscribe(cb)`, `getSnapshot()` | बदलाव सूचनाएँ |
| `storage` | `{ translations: Map<'locale:route', Translations> }` |

जो कोड भाषा टैग नहीं है उसे अपने बहुवचन `localeIso: { ua: 'uk-UA' }` से मिलते हैं; `localeIsoMap(locales)` इसे लोकेल सूची की उन प्रविष्टियों से बनाता है जिनमें `iso` होता है।

मॉड्यूल एक्सपोर्ट्स: `createI18n`, `I18n`, `fetchJsonTranslations`, `FormatService`, `interpolate`, `localeIsoMap` और टाइप `I18nOptions`, `LoadFromUrlOptions`, `LoadFromUrlEntry`, `TranslationStorage`, `Translations`, `Locale`, `PluralFunc`। पूर्ण सिग्नेचर: [पैकेज संदर्भ](/hi/api/packages/runtime)।
