`@i18n-micro/devtools-ui` Nuxt DevTools टैब वाला अनुवाद एडिटर है, जिसे Vite प्लगइन के साथ एक वेब कंपोनेंट के रूप में पैकेज किया गया है। डेवलपमेंट के दौरान ब्राउज़र से अपने अनुवाद फ़ोल्डर की JSON फ़ाइलें ब्राउज़ और संपादित करने के लिए इसे किसी Vue, React, Preact, Solid या Astro प्रोजेक्ट में जोड़ें। Nuxt ऐप्स में यह पहले से [Nuxt DevTools](/hi/guide/devtools) में मौजूद है।

![DevTools UI: एक फ़ाइल ट्री और एक एडिटर, जिसमें हर कुंजी के पास डिफ़ॉल्ट-लोकेल टेक्स्ट है](/images/devtools/02-translations-editor-dark.webp)

## इंस्टॉल करें {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/devtools-ui
```

```bash npm
npm install -D @i18n-micro/devtools-ui
```

```bash yarn
yarn add -D @i18n-micro/devtools-ui
```

</CodeGroup>

कोई peer dependency नहीं।

## सेटअप {#setup}

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import { i18nDevToolsPlugin } from '@i18n-micro/devtools-ui/vite'

export default defineConfig({
  plugins: [i18nDevToolsPlugin({ translationDir: 'src/locales' })],
})
```

| विकल्प | डिफ़ॉल्ट | नोट्स |
| --- | --- | --- |
| `translationDir` | `'src/locales'` | JSON फ़ाइलों वाला फ़ोल्डर, Vite root के सापेक्ष। |
| `base` | `'/__i18n_api'` | API एंडपॉइंट का बेस पाथ। |
| `injectButton` | `true` | Vite के `index.html` ट्रांसफ़ॉर्म के ज़रिए परोसे गए पेजों में एक फ़्लोटिंग बटन जोड़ें। Astro में ऐसे पेज नहीं होते: नीचे देखें। |
| `defaultLocale` | `translationDir` में पहली लोकेल फ़ाइल | `/config` द्वारा रिपोर्ट किया जाता है। |
| `fallbackLocale` | `defaultLocale` | `/config` द्वारा रिपोर्ट किया जाता है। |

प्लगइन केवल dev सर्वर पर चलता है (`apply: 'serve'`); प्रोडक्शन बिल्ड में इसका कुछ भी शामिल नहीं होता। बटन `/__i18n_devtools.html` खोलता है, जो प्लगइन के एंडपॉइंट के ज़रिए फ़ाइलें पढ़ता और सहेजता है:

| एंडपॉइंट | क्या करता है |
| --- | --- |
| `GET <base>/translations` | `translationDir` के अंतर्गत हर डिक्शनरी, सापेक्ष पाथ के अनुसार |
| `POST <base>/save` | body `{ file, content }`; `translationDir` के अंदर किसी मौजूदा `.json` को अधिलेखित करता है, बाकी किसी भी चीज़ के लिए 403। यह कभी फ़ाइल नहीं बनाता |
| `GET <base>/config` | `{ defaultLocale, fallbackLocale, locales, translationDir }`; `locales` `translationDir` की root फ़ाइलों से आते हैं |

एंडपॉइंट केवल devtools पेज को जवाब देते हैं: किसी अन्य origin या host से आया अनुरोध `403` होता है, और `/save` केवल `application/json` लेता है (`415`)। पेज को फ़ाइल बदलावों की जानकारी Vite के HMR सॉकेट से मिलती है।

Astro में, प्लगइन के बजाय इंटीग्रेशन जोड़ें। यह dev टूलबार में एक ऐप जोड़ता है:

```ts
// astro.config.mjs
import { defineConfig } from 'astro/config'
import { i18nDevToolsIntegration } from '@i18n-micro/devtools-ui/vite'

export default defineConfig({
  integrations: [i18nDevToolsIntegration({ translationDir: 'src/locales' })],
})
```

सहेजने से केवल फ़ाइल लिखी जाती है। जो ऐप Vite के ज़रिए JSON इम्पोर्ट करता है उसे यह HMR के ज़रिए मिल जाती है; चल रहे इंस्टेंस पर सीधे लागू होने वाले संपादनों के लिए, bridge का उपयोग करें।

## लाइव इंस्टेंस से bridge {#bridge-to-a-live-instance}

एडिटर को अपने पेज में एम्बेड करने और संपादनों को चल रहे इंस्टेंस पर तुरंत लागू करने के लिए, एक adapter से bridge बनाएँ और उसे `<i18n-devtools-ui>` एलिमेंट को दें:

```ts
import { createBridge, register } from '@i18n-micro/devtools-ui'
import { i18n, locales } from './i18n' // a runtime, React, Preact or Solid instance

register() // defines <i18n-devtools-ui> once

const bridge = createBridge({
  adapter: {
    getRouteCache: () => Object.fromEntries(i18n.storage.translations),
    addTranslations: (locale, content, merge) => i18n.addTranslations(locale, content, merge),
    addRouteTranslations: (locale, route, content, merge) => i18n.addRouteTranslations(locale, route, content, merge),
    subscribe: (cb) => i18n.subscribe(cb),
    getCurrentLocale: () => i18n.locale,
  },
  locales,
  defaultLocale: 'en',
  translationDir: 'src/locales',
})

const el = document.createElement('i18n-devtools-ui') as HTMLElement & { bridge: typeof bridge }
el.bridge = bridge
document.body.append(el)
```

`getRouteCache` को `locale:route` (`en:index`, `en:blog-post`) कुंजी वाली डिक्शनरी लौटानी चाहिए, जो `i18n.storage.translations` में होती है। Vue इंस्टेंस के लिए `i18n.global.getRouteCache()` और `i18n.global.subscribeToChanges(cb)` का उपयोग करें।

`saveTranslation` पहले इंस्टेंस को अपडेट करता है, फिर `<base>/save` पर POST करता है। जब कोई एंडपॉइंट न हो (एक स्टैटिक प्रीव्यू बिल्ड) या dev सर्वर तक पहुँचा न जा सके, तो संपादन `localStorage` में रखा जाता है; सहेजने की कोई अन्य त्रुटि पिछली डिक्शनरी को बहाल करती है और त्रुटि throw करती है।

## API {#api}

| एक्सपोर्ट | एंट्री |
| --- | --- |
| `i18nDevToolsPlugin(options)`, `i18nDevToolsIntegration(options)` | `@i18n-micro/devtools-ui/vite` |
| `register()`, `I18nDevToolsElement` | `@i18n-micro/devtools-ui` |
| `createBridge(options)`, टाइप `BridgeAdapter`, `CreateBridgeOptions` | `@i18n-micro/devtools-ui` (`/bridge/create` भी) |
| टाइप `I18nDevToolsBridge` | `@i18n-micro/devtools-ui` (`/bridge` भी) |
| `createRpcClient`, `setupRpcHost` | `@i18n-micro/devtools-ui` |
