एक आइलैंड ब्राउज़र में चलता है, जहाँ सर्वर का i18n इंस्टेंस मौजूद नहीं होता। `@i18n-micro/astro` पेज को यह चुनने देता है कि आइलैंड को किन कुंजियों की आवश्यकता है, उन्हें एक प्रॉप के रूप में पास करने देता है, और एक छोटे फ़्रेमवर्क एडेप्टर के माध्यम से आइलैंड में उन्हें पढ़ने देता है। आपको Vue, React, Preact और Svelte आइलैंड्स में `t`, `tc`, `tn`, `td`, `tdr` और `has` मिलते हैं, HTML में केवल चुनी गई स्ट्रिंग्स के साथ।

## सेटअप {#setup}

पहले [Astro इंटीग्रेशन और मिडलवेयर](/hi/integrations/astro-package#setup) सेट करें, फिर वह फ़्रेमवर्क इंटीग्रेशन जोड़ें जिसका आप उपयोग करते हैं (`@astrojs/vue`, `@astrojs/react`, `@astrojs/preact`, `@astrojs/svelte`)। आइलैंड एडेप्टर्स को उस फ़्रेमवर्क की पीयर के रूप में आवश्यकता होती है: `vue` `^3.3.0`, `react` `^16.8.0 || ^17.0.0 || ^18.0.0 || ^19.0.0`, `preact` `^10.0.0 || ^11.0.0` या `svelte` `^4.0.0 || ^5.0.0`।

## किसी आइलैंड को अनुवाद पास करें {#pass-translations-to-an-island}

```astro
---
// src/pages/index.astro
import { getI18nProps } from '@i18n-micro/astro'
import Counter from '../components/Counter.vue'

const i18n = getI18nProps(Astro, ['counter.title', 'counter.apples'])
---

<Counter client:load i18n={i18n} />
```

`getI18nProps(Astro, keys?)` `{ locale, fallbackLocale, currentRoute, translations }` लौटाता है (टाइप `I18nClientProps`)। वे कुंजियाँ पास करें जिनका आइलैंड उपयोग करता है: हर एक को सर्वर पर `t()` की तरह हल किया जाता है (रूट, रूट-स्तर और फ़ॉलबैक डिक्शनरी) और केवल मिली हुई कुंजियाँ HTML में जाती हैं। `keys` के बिना, इस पेज पर `t()` जिसका भी उत्तर दे सकता है वह सब हर आइलैंड में भेजा जाता है, इसलिए 2000 रूट कुंजियाँ प्रति आइलैंड लगभग 100 KB होती हैं; डेव में 20 KB से ऊपर होने पर एक चेतावनी यह बताती है।

आइलैंड केवल उसी ऑब्जेक्ट से अनुवाद करते हैं। पास न की गई किसी भी चीज़ के लिए `t` कुंजी लौटाता है, और लिंक्ड संदेश हल नहीं किए जाते।

## Vue {#vue}

आइलैंड के रूट कंपोनेंट में `provideI18n(() => props.i18n)` और उसके चाइल्ड्स में `useAstroI18n()` कॉल करें। Vue का `inject` उसी कंपोनेंट द्वारा प्रदान किया गया मान नहीं देखता, इसलिए हुक को रूट में नहीं, बल्कि किसी चाइल्ड में चलना चाहिए:

```vue
<!-- src/components/Counter.vue -->
<script setup lang="ts">
import { provideI18n } from '@i18n-micro/astro/client/vue'
import type { I18nClientProps } from '@i18n-micro/astro'
import CounterBody from './CounterBody.vue'

const props = defineProps<{ i18n: I18nClientProps }>()
provideI18n(() => props.i18n)
</script>

<template><CounterBody /></template>
```

```vue
<!-- src/components/CounterBody.vue -->
<script setup lang="ts">
import { ref } from 'vue'
import { useAstroI18n } from '@i18n-micro/astro/client/vue'

const { t, tc } = useAstroI18n()
const count = ref(0)
</script>

<template>
  <h3>{{ t('counter.title') }}</h3>
  <button @click="count++">{{ tc('counter.apples', count) }}</button>
</template>
```

## React और Preact {#react-and-preact}

```tsx
// src/components/Counter.tsx
import { useState } from 'react'
import { I18nProvider, useAstroI18n } from '@i18n-micro/astro/client/react'
import type { I18nClientProps } from '@i18n-micro/astro'

function Body() {
  const { t, tc } = useAstroI18n()
  const [count, setCount] = useState(0)
  return <button onClick={() => setCount(count + 1)}>{t('counter.title')}: {tc('counter.apples', count)}</button>
}

export default function Counter({ i18n }: { i18n: I18nClientProps }) {
  return (
    <I18nProvider value={i18n}>
      <Body />
    </I18nProvider>
  )
}
```

Preact के लिए `I18nProvider` और `useAstroI18n` को `@i18n-micro/astro/client/preact` से इंपोर्ट करें; API वही है।

## Svelte {#svelte}

```svelte
<!-- src/components/Counter.svelte -->
<script lang="ts">
  import { createI18nStore, useAstroI18n } from '@i18n-micro/astro/client/svelte'
  import type { I18nClientProps } from '@i18n-micro/astro'

  export let i18n: I18nClientProps
  const { t, tc } = useAstroI18n(createI18nStore(i18n))
  let count = 0
</script>

<button on:click={() => count++}>{t('counter.title')}: {tc('counter.apples', count)}</button>
```

`useAstroI18n(store)` टेम्पलेट में `$store` रीड के लिए `store` भी लौटाता है।

## स्थायी आइलैंड्स {#persisted-islands}

`transition:persist` वाले आइलैंड को नेविगेशन के बाद नए प्रॉप्स मिलते हैं। React, Preact और Vue (गेटर दिए जाने पर) उनका अनुसरण करते हैं। Svelte में, स्टोर रखें और उन्हें आगे पास करें: `const store = createI18nStore(i18n)`, `const { t } = useAstroI18n(store)`, फिर `$: store.set(i18n)` (runes के साथ, `$effect(() => store.set(i18n))`)।

## API {#api}

| एंट्री | एक्सपोर्ट्स |
| --- | --- |
| `@i18n-micro/astro` | `getI18nProps`, टाइप `I18nClientProps` |
| `@i18n-micro/astro/client/vue` | `provideI18n(props \| () => props)`, `useAstroI18n()` |
| `@i18n-micro/astro/client/react` | `I18nProvider` (`value` प्रॉप), `useAstroI18n()` |
| `@i18n-micro/astro/client/preact` | `I18nProvider` (`value` प्रॉप), `useAstroI18n()` |
| `@i18n-micro/astro/client/svelte` | `createI18nStore(props)`, `useAstroI18n(store)` |
| `@i18n-micro/astro/client` | शुद्ध `translate`, `hasTranslation`, बिना किसी फ़्रेमवर्क के |

हर `useAstroI18n` `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`, `setLocale`, `setRoute` और `locale` लौटाता है। एक आइलैंड में एक मर्ज की गई डिक्शनरी होती है, इसलिए उसका `has` उस कुंजी के लिए true होता है जिसका `t` उत्तर दे सकता है, फ़ॉलबैक लोकेल से भी; सर्वर पर `has` केवल सक्रिय लोकेल को देखता है।
