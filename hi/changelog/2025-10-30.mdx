**संस्करण**: `v2.0.0`

![v2.0.0 रिलीज़](/images/2.0.0.png)

हम डेवलपमेंट में अनुवाद फ़ाइलों के लिए सर्वर‑साइड HMR पेश कर रहे हैं। जब कोई JSON अनुवाद बदलता है, तो सर्वर कैश केवल प्रभावित कुंजियों को अमान्य करता है, और बाद के अनुरोधों को तुरंत ताज़ा डेटा मिलता है—किसी रीस्टार्ट की ज़रूरत नहीं।

## नया क्या है? {#what’s-new}

- अनुवाद फ़ाइलों के लिए सर्वर‑साइड HMR
- हर पेज/लोकेल के लिए तुरंत कैश अमान्यकरण
- सामग्री संपादित करते समय सहज DX

## यह कैसे काम करता है {#how-it-works}

- `src/runtime/server/plugins/watcher.dev.ts` में वॉचर `<rootDir>/<translationDir>/**/*.json` पर नज़र रखता है
- पेज फ़ाइलें (जैसे `pages/<page>/<locale>.json`) `_locales:merged:<page>:<locale>` को अमान्य करती हैं
- रूट-स्तर की फ़ाइलें (जैसे `<locale>.json`) उस लोकेल की सभी मर्ज की गई कुंजियों को अमान्य करती हैं
- जब `experimental.hmr !== false` हो, तो dev में `src/module.ts` से स्वतः पंजीकृत होता है

## कॉन्फ़िगरेशन {#configuration}

```ts
export default defineNuxtConfig({
  i18n: {
    experimental: { hmr: true }, // default in dev
  },
})
```
