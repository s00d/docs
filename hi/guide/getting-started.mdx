यह पेज एक Nuxt ऐप को बिना i18n की स्थिति से भाषा स्विचर वाले अनुवादित पेज तक ले जाता है। आपको इसकी ज़रूरत एक बार, प्रोजेक्ट की शुरुआत में होती है। अंत में आपके पास स्थानीयकृत URL (`/about`, `/de/about`), प्रति लोकेल और पेज एक JSON फ़ाइल, और आपके टेम्पलेट में `$t` होगा।

## इंस्टॉल करें {#install}

मॉड्यूल को Nuxt 3.18 या नया (Nuxt 4 भी काम करता है) और Node 20 या नया चाहिए।

<CodeGroup>

```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>

## लोकेल कॉन्फ़िगर करें {#configure-the-locales}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', displayName: 'English' },
      { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
      { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
    ],
    defaultLocale: 'en',
  },
})
```

पहले ऐप को बस इतनी ही कॉन्फ़िगरेशन चाहिए। डिफ़ॉल्ट आपको यह देते हैं:

- `strategy: 'prefix_except_default'`: डिफ़ॉल्ट लोकेल का कोई प्रीफ़िक्स नहीं होता (`/about`), बाकी का होता है (`/de/about`)। देखें [रूटिंग strategies](/hi/guide/strategy)।
- `translationDir: 'locales'`: अनुवाद फ़ाइलें प्रोजेक्ट रूट पर `locales/` में रहती हैं, Nuxt 4 के `app/` लेआउट के साथ भी।
- `meta: true`: `hreflang`, canonical और `og:locale` टैग, साथ ही `<html>` पर `lang` और `dir`। देखें [SEO](/hi/guide/seo)।
- जो विज़िटर `/` खोलता है, उसे उस भाषा पर भेजा जाता है जो उसका ब्राउज़र माँगता है (`Accept-Language`)। देखें [लोकेल डिटेक्शन](/hi/guide/locale-detection)।

`iso` SEO टैग में उपयोग होने वाला भाषा टैग है; `code` वह है जो URL में दिखता है। हर विकल्प [मॉड्यूल विकल्प](/hi/api/module-options) में सूचीबद्ध है।

## अनुवाद फ़ाइलें जोड़ें {#add-translation-files}

`nuxt dev` के साथ dev सर्वर शुरू करें। जब Nuxt पेज resolve करता है, तो मॉड्यूल हर उस लोकेल और पेज के लिए एक खाली `{}` फ़ाइल बनाता है जिसकी फ़ाइल नहीं है (इसे [`disableWatcher`](/hi/api/module-options#disablewatcher) से बंद करें):

```text
locales/
├── en.json            # root: keys every page can use
├── de.json
├── fr.json
└── pages/
    ├── index/         # pages/index.vue
    │   ├── en.json
    │   ├── de.json
    │   └── fr.json
    └── about/         # pages/about.vue
        ├── en.json
        ├── de.json
        └── fr.json
```

रूट फ़ाइल और एक पेज फ़ाइल भरें:

```json
// locales/en.json
{ "nav": { "home": "Home", "about": "About" } }
```

```json
// locales/pages/index/en.json
{ "welcome": "Welcome, {name}!", "items": "no items | one item | {count} items" }
```

एक पेज रूट कुंजियाँ और अपनी कुंजियाँ देखता है; टकराव होने पर उसकी अपनी फ़ाइल को प्राथमिकता मिलती है। फ़ोल्डर के नाम रूट नाम का पालन करते हैं (`pages/articles/[id].vue` का फ़ोल्डर `locales/pages/articles-id/` है)। [अनुवाद फ़ाइलें](/hi/guide/translations) लेआउट, फ़ॉलबैक और लोडिंग को कवर करता है।

## पेज पर `$t` का उपयोग करें {#use-$t-on-a-page}

```vue
<!-- pages/index.vue -->
<script setup lang="ts">
const { t, tc, getLocale } = useI18n()

const title = t('nav.home') // 'Home'
</script>

<template>
  <h1>{{ $t('welcome', { name: 'Ada' }) }}</h1>
  <!-- Welcome, Ada! -->
  <p>{{ $tc('items', 3) }}</p>
  <!-- 3 items -->
  <p>{{ getLocale() }}</p>
  <!-- en -->
</template>
```

- टेम्पलेट में हर हेल्पर `$` के साथ उपलब्ध है (`$t`, `$tc`, `$localePath`, …)।
- `<script setup>` में, `useI18n()` वही हेल्पर `$` के साथ और उसके बिना लौटाता है (`t` और `$t` एक ही फ़ंक्शन हैं)। यह स्वतः-इम्पोर्ट होता है।
- `{name}` प्लेसहोल्डर params ऑब्जेक्ट से भरे जाते हैं। बहुवचन रूप `|` से अलग किए जाते हैं; गिनती रूप चुनती है (0, 1, फिर उससे ऊपर हर चीज़ के लिए अंतिम रूप)।

सभी हेल्पर [मेथड्स](/hi/api/methods) में सूचीबद्ध हैं।

## पेजों के बीच लिंक करें और लोकेल बदलें {#link-between-pages-and-switch-locale}

```vue
<!-- components/AppHeader.vue -->
<template>
  <nav>
    <i18n-link :to="{ name: 'index' }">{{ $t('nav.home') }}</i18n-link>
    <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
    <i18n-switcher />
  </nav>
</template>
```

- [`<i18n-link>`](/hi/components/i18n-link) एक `NuxtLink` है जो वर्तमान लोकेल में पेज की ओर इशारा करता है: `/de` पर about लिंक `/de/about` पर जाता है।
- [`<i18n-switcher>`](/hi/components/i18n-switcher) सक्षम लोकेल का एक ड्रॉपडाउन है; यह विज़िटर को उसी पेज पर रखता है।
- अपने स्वयं के बटन के लिए `$switchLocale('de')` कॉल करें, जो वर्तमान पेज के जर्मन संस्करण पर नेविगेट करता है और पसंद याद रखता है। सामान्य `NuxtLink` के लिए, `$localePath({ name: 'about' })` या `$switchLocalePath('de')` का उपयोग करें।

## इसे जाँचें {#check-it}

`nuxt dev` चलाएँ और खोलें:

| URL | दिखाता है |
| --- | --- |
| `/` | अंग्रेज़ी होम (या `/de` पर रीडायरेक्ट, जब आपका ब्राउज़र जर्मन पसंद करता है) |
| `/de` | जर्मन होम |
| `/de/about` | जर्मन about पेज |
| `/en/about` | 404: `prefix_except_default` के तहत डिफ़ॉल्ट लोकेल का कोई प्रीफ़िक्स नहीं होता |

JSON फ़ाइलों में किए गए बदलाव खुले पेज में बिना रीलोड के लागू होते हैं।
