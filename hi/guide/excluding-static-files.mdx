---

description: "excludePatterns के साथ पेजों और फ़ाइलों को लोकेल रूटिंग से बाहर रखें, और देखें कि कौन से पाथ पहले से बाहर रखे गए हैं।"
---

कुछ पाथ को कभी भी लोकेल प्रीफ़िक्स या लोकेल रीडायरेक्ट नहीं मिलना चाहिए: एक एडमिन क्षेत्र, एक हेल्थ चेक, एक जनरेट की गई फ़ीड। `excludePatterns` उन्हें चिह्नित करता है, और एक बिल्ट-इन सूची पहले से ही Nuxt के आंतरिक हिस्सों और सामान्य स्टैटिक फ़ाइलों को कवर करती है। बाहर रखा गया पेज ठीक वही पाथ रखता है जो आपने लिखा है और फिर भी `$t` के साथ रेंडर होता है।

## किसी पाथ को बाहर रखें {#exclude-a-path}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    excludePatterns: [
      '/admin', // /admin and everything below it
      '/preview-*', // glob over the whole path
    ],
  },
})
```

इस कॉन्फ़िग के साथ `pages/admin/index.vue` केवल `/admin` पर उत्तर देता है; कोई `/de/admin` नहीं है, और `/admin` को कभी भी `/de/admin` पर रीडायरेक्ट नहीं किया जाता।

## पैटर्न सिंटैक्स {#pattern-syntax}

पैटर्न का मिलान `app.baseURL` के बिना पाथ से किया जाता है:

| पैटर्न | मेल खाता है | मेल नहीं खाता |
| --- | --- | --- |
| `'/admin'` | `/admin`, `/admin/users` | `/administrator`, `/de/admin` |
| `'/preview-*'` | `/preview-1`, `/preview-a/b` | `/de/preview-1` |
| `'/file-?'` | `/file-a` | `/file-ab` |
| `/^\/v\d+\//` | `/v2/docs` | `/docs` |

`*` या `?` के बिना एक स्ट्रिंग पाथ और उसके नीचे के पूरे सेगमेंट से मेल खाती है। `*` (स्लैश सहित, वर्णों का कोई भी क्रम) या `?` (एक वर्ण) के साथ उसे पूरे पाथ से मेल खाना चाहिए। स्ट्रिंग्स को हमेशा `/` से शुरू करें।

## पहले से क्या बाहर रखा गया है {#what-is-excluded-already}

इन्हें बिना किसी कॉन्फ़िग के कभी भी लोकेल रूट या रीडायरेक्ट नहीं मिलते:

- `/api` और `/_nuxt`, और उनके नीचे सब कुछ;
- अनुवाद रूट, डिफ़ॉल्ट रूप से `/_locales` ([`apiBaseUrl`](/hi/api/module-options#apibaseurl));
- कोई भी पाथ जिसका कोई सेगमेंट `__` से शुरू होता है (`/__nuxt_content`, `/en/__og-image__`);
- `/sitemap*.xml`, `/robots.txt`, `/favicon.ico`, `/apple-touch-icon*.png`, `/manifest.json`, `/sw.js`, `/workbox-*.js`;
- कोई भी पाथ जिसका अंतिम सेगमेंट किसी स्टैटिक-फ़ाइल एक्सटेंशन पर समाप्त होता है: `xml txt ico json js css png jpg jpeg gif svg webp avif pdf wasm map mp4 webm mp3 zip gz woff woff2 ttf eot`। `/user/john.doe` जैसे डॉट वाले पेज स्लग और `.html` पाथ पेज ही रहते हैं।

## बाहर रखने का प्रभाव {#what-an-exclusion-does}

- **रूट:** कोई स्थानीयकृत वेरिएंट जनरेट नहीं होते; पेज जैसा लिखा गया है वैसा ही रहता है।
- **रीडायरेक्ट और 404:** सर्वर रीडायरेक्ट प्लगइन और क्लाइंट रीडायरेक्ट मिडलवेयर इस पाथ को छोड़ देते हैं।
- **प्रीरेंडर:** मेल खाने वाले पाथ प्रीरेंडर रूट सूची से हटा दिए जाते हैं।

यह i18n सर्वर मिडलवेयर को अनुरोध के लिए लोकेल का पता लगाने से नहीं रोकता, और यह पेज को अनुवादों का उपयोग करने से नहीं रोकता। किसी पेज को स्थानीयकृत रखते हुए SEO टैग से बाहर रखने के लिए `disableMeta` ([पेज कॉन्फ़िग](/hi/guide/per-component-translations#turn-off-seo-tags)) का उपयोग करें। `nuxt.config.ts` से पाथ के आधार पर एक पेज को अस्थानीयकृत रखने के लिए, `globalLocaleRoutes: { '/admin': false }` ([स्थानीयकृत पाथ](/hi/guide/custom-locale-routes#in-nuxt-config)) रूटिंग के लिए यही काम करता है।
