`nuxt dev` में मॉड्यूल दो डीबगिंग सहायक जोड़ता है: अनुवाद फ़ाइलों को ब्राउज़ और संपादित करने के लिए Nuxt DevTools में एक **i18n Micro** टैब, और लाइव locale व लोड किए गए शब्दकोशों के लिए एक Vue DevTools इंस्पेक्टर। दोनों केवल डेवलपमेंट में मौजूद होते हैं और प्रोडक्शन बिल्ड में कुछ नहीं जोड़ते। Nuxt टैब के लिए केवल Nuxt DevTools सक्षम होना चाहिए; Vue इंस्पेक्टर के लिए Vue DevTools ब्राउज़र एक्सटेंशन भी आवश्यक है।

## Nuxt DevTools टैब {#nuxt-devtools-tab}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  devtools: { enabled: true }, // the tab is registered only when DevTools are on
})
```

Nuxt DevTools खोलें (`Shift + Alt + D`) और **i18n Micro** चुनें। टैब में दिखता है:

- हर लेयर के `locales/` (रूट और `pages/`) के तहत हर JSON फ़ाइल, साथ ही `additionalTranslationDirs` की रूट फ़ाइलें;
- प्रति फ़ाइल एक एडिटर; **Save** फ़ाइल को वापस डिस्क पर लिखता है, और dev सर्वर अनुवादों को फिर से लोड करता है;
- किसी फ़ाइल का JSON के रूप में **Export** / **Import**, और कुंजी गणना व अनुवाद कवरेज के साथ **Stats**;
- रिज़ॉल्व किए गए मॉड्यूल विकल्पों का कॉन्फ़िग व्यू;
- **Translate**, जो टैब की सेटिंग्स में आपके द्वारा कॉन्फ़िगर किए गए मशीन-ट्रांसलेशन इंजन से गायब कुंजियाँ भरता है।

सहेजना केवल आपकी अनुवाद डायरेक्टरी के अंदर मौजूदा `.json` फ़ाइलों को लिखता है। जब कोई फ़ाइल कई लेयर में मौजूद हो, तो प्रोजेक्ट की कॉपी लिखी जाती है।

## Vue DevTools इंस्पेक्टर {#vue-devtools-inspector}

Vue DevTools ब्राउज़र एक्सटेंशन के साथ, मॉड्यूल एक i18n इंस्पेक्टर (वर्तमान locale, रूट चंक, लोड की गई कुंजियाँ) और locale स्विच, चंक लोड और गायब कुंजियों वाली एक टाइमलाइन रजिस्टर करता है।

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    debug: true, // also log every $t / $ts / $tc call on the timeline
    // vueDevtools: false, // turn the inspector off, keep the Nuxt tab
  },
})
```

[`vueDevtools`](/hi/api/module-options) डिफ़ॉल्ट रूप से `true` है। `debug: true` बहुत विस्तृत लॉग देता है; इसे छोटे सत्रों के लिए ही रखें।

## Nuxt के बाहर {#outside-nuxt}

वही UI फ़्रेमवर्क पैकेज पर बने Vite ऐप्स के लिए [`@i18n-micro/devtools-ui`](/hi/integrations/devtools-ui-package) के रूप में प्रकाशित है; सेटअप के लिए वह पेज देखें।
