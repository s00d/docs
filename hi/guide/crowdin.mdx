[Crowdin](https://crowdin.com/) एक अनुवाद प्लेटफ़ॉर्म है: आप डिफ़ॉल्ट locale की फ़ाइलें अपलोड करते हैं, अनुवादक Crowdin में काम करते हैं, और आप बाकी locales वापस डाउनलोड करते हैं। मॉड्यूल सादी JSON फ़ाइलें पढ़ता है, इसलिए Crowdin CLI को बस एक ऐसी `crowdin.yml` चाहिए जो `locales/` और `locales/pages/` को सही ढंग से मैप करे। मॉड्यूल की किसी सेटिंग में बदलाव की ज़रूरत नहीं है।

## crowdin.yml कॉन्फ़िगर करें {#configure-crowdin-yml}

```yml
# crowdin.yml
project_id_env: CROWDIN_PROJECT_ID
api_token_env: CROWDIN_PERSONAL_TOKEN
base_path: ./locales
preserve_hierarchy: true

files:
  - source: /en.json
    translation: /%two_letters_code%.json
  - source: /pages/**/en.json
    translation: /pages/**/%two_letters_code%.json
```

- `en` आपका डिफ़ॉल्ट locale है; उसकी फ़ाइलें स्रोत (sources) हैं।
- `project_id_env` / `api_token_env` ID और टोकन को environment variables से पढ़ते हैं, इसलिए कोई secret कमिट नहीं होता।
- `preserve_hierarchy: true` `pages/<page>/` फ़ोल्डरों को जैसे हैं वैसे ही रखता है।
- अनूदित फ़ाइल का नाम `nuxt.config.ts` में locale के `code` के बराबर होना चाहिए। `%two_letters_code%` `de` जैसे codes के लिए ठीक है; `pt-BR` जैसे codes के लिए `%locale%` इस्तेमाल करें, या `languages_mapping` से Crowdin के codes को अपने codes से मैप करें।

## अपलोड और डाउनलोड {#upload-and-download}

```bash
npm install -g @crowdin/cli

export CROWDIN_PROJECT_ID=123456
export CROWDIN_PERSONAL_TOKEN=...   # from Crowdin account settings

crowdin upload sources   # push locales/en.json and locales/pages/**/en.json
crowdin download         # write locales/de.json, locales/pages/**/de.json, ...
```

फ़ाइलों को अद्यतन रखने के लिए दोनों को CI में चलाएँ। डाउनलोड की गई फ़ाइलें आपकी रिपॉज़िटरी में हाथ से संपादित फ़ाइलों की तरह ही आती हैं; अगला बिल्ड या dev reload उन्हें उठा लेता है।

## अपलोड करने से पहले {#before-uploading}

पहले स्रोतों को साफ़ करें ताकि अनुवादक बेकार keys पर काम न करें: [`i18n-micro clean`](/hi/api/cli#clean) अप्रयुक्त keys हटाता है, [`i18n-micro check`](/hi/api/cli#check) डाउनलोड के बाद कमियों की रिपोर्ट देता है। CLI का अपना कोई Crowdin इंटीग्रेशन नहीं है: यह पेज ही समर्थित तरीका है।
