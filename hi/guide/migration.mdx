यह पेज किसी `@nuxtjs/i18n` ऐप को nuxt-i18n-micro पर मैप करता है: विकल्प, हेल्पर और फ़ाइल लेआउट। किसी मौजूदा ऐप में मॉड्यूल बदलते समय इसका उपयोग करें। आप अपने URL बनाए रखते हैं (रणनीतियों के नाम वही हैं) और अनुवादों को हर पेज की JSON फ़ाइलों में ले जाते हैं।

<Tip>

**nuxt-i18n-micro को ही अपग्रेड कर रहे हैं?** — देखें [अपग्रेड करना](/hi/guide/upgrade)।

</Tip>

## मॉड्यूल बदलें {#swap-the-module}

```bash
npm uninstall @nuxtjs/i18n
npm install nuxt-i18n-micro
```

```ts
// nuxt.config.ts — before
export default defineNuxtConfig({
  modules: ['@nuxtjs/i18n'],
  i18n: {
    locales: [
      { code: 'en', language: 'en-US', file: 'en.json' },
      { code: 'de', language: 'de-DE', file: 'de.json' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    langDir: 'locales',
    detectBrowserLanguage: { useCookie: true, cookieKey: 'i18n_redirected', redirectOn: 'root' },
  },
})
```

```ts
// nuxt.config.ts — after
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    translationDir: 'locales',
    localeCookie: 'i18n_redirected',
    autoDetectPath: '/',
  },
})
```

## विकल्प {#options}

| `@nuxtjs/i18n` | nuxt-i18n-micro |
| --- | --- |
| `locales[].code` | `locales[].code` |
| `locales[].language` (v9 से पहले `iso`) | `locales[].iso` |
| `locales[].name` | `locales[].displayName` |
| `locales[].dir` | `locales[].dir` |
| `locales[].domain` | `locales[].baseUrl` (स्कीम सहित एक origin) |
| `locales[].domainDefault` | `locales[].baseDefault` |
| `differentDomains`, `multiDomainLocales` | ज़रूरत नहीं: केवल `baseUrl` होस्ट के अनुसार रूट करता है, देखें [लेयर और डोमेन](/hi/guide/layers#multiple-domains) |
| `locales[].file` / `files`, `langDir`, `lazy` | `translationDir`; फ़ाइलें नाम से ढूँढी जाती हैं और हमेशा हर पेज के लिए लोड होती हैं |
| `defaultLocale`, `strategy` | वही नाम, वही चार मान |
| `baseUrl` | `metaBaseUrl` |
| `customRoutes: 'config'` + `pages` | `globalLocaleRoutes` |
| `detectBrowserLanguage: false` | `redirects: false` (कोई रीडायरेक्ट नहीं) या `autoDetectLanguage: false` (हेडर को अनदेखा करें) |
| `detectBrowserLanguage.useCookie` / `cookieKey` | `localeCookie: '<name>'` (`null` कुकी को बंद करता है) |
| `detectBrowserLanguage.redirectOn: 'root'` | `autoDetectPath: '/'` (डिफ़ॉल्ट) |
| `detectBrowserLanguage.redirectOn: 'no prefix'` | `autoDetectPath: 'no_prefix'` |
| `detectBrowserLanguage.redirectOn: 'all'` | `autoDetectPath: '*'` |
| `vueI18n` कॉन्फ़िग फ़ाइल (`fallbackLocale`, `numberFormats`, `datetimeFormats`) | `i18n` में `fallbackLocale`, `numberFormats`, `datetimeFormats` |

कोई `alwaysRedirect` नहीं है: कुकी सेट होने पर, `/` हर विज़िट पर उसका पालन करता है। पूरी सूची [मॉड्यूल विकल्प](/hi/api/module-options) में है; पहचान के नियम [लोकेल पहचान](/hi/guide/locale-detection) पर हैं।

## हेल्पर और composables {#helpers-and-composables}

| `@nuxtjs/i18n` / vue-i18n | nuxt-i18n-micro (टेम्पलेट / `useI18n()`) |
| --- | --- |
| `const { t } = useI18n()` | `const { t } = useI18n()`, टेम्पलेट में `$t` |
| `t('key', count)`, `tc` | `$tc('key', count)` |
| `te('key')` | `$has('key')` |
| `n(value, 'currency')`, `d(date, 'short')` | `$tn(value, 'currency')`, `$td(date, 'short')` |
| — | `$tdr(date)`: सापेक्ष समय ("in 3 days") |
| `locale.value` | `$getLocale()` |
| `locales.value` | `$getLocales()` |
| `setLocale('de')` | `$switchLocale('de')` |
| `useLocalePath()('about')` | `$localePath({ name: 'about' })` |
| `useLocaleRoute()` | `$localeRoute()` |
| `useSwitchLocalePath()('de')` | `$switchLocalePath('de')` |
| `useSetI18nParams()` | `$setI18nRouteParams()` |
| `useLocaleHead()` | `meta: true` के साथ स्वचालित; कस्टम head के लिए [`useLocaleHead`](/hi/composables/useLocaleHead) |
| `defineI18nRoute({ paths: { de: '/ueber-uns' }, locales: [...] })` | `$defineI18nRoute({ localeRoutes: { de: '/ueber-uns' }, locales: [...] })` |
| `<NuxtLinkLocale to="about">` | `<i18n-link :to="{ name: 'about' }">` |
| `<i18n-t>` | `<i18n-t>` (स्लॉट `{name}` प्लेसहोल्डर भरते हैं) |
| सर्वर रूट में `$i18n` | `useTranslationServerMiddleware(event)`, देखें [सर्वर रूट और API](/hi/guide/server-side-translations) |

`useI18n()` स्वतः इम्पोर्ट होता है। `$defineI18nRoute` में `$` बना रहना चाहिए: बिल्ड उसी कॉल को पढ़ता है। सभी हेल्पर: [मेथड](/hi/api/methods)।

## अनुवाद फ़ाइलें {#translation-files}

हर लोकेल की एक बड़ी फ़ाइल की कुंजियों को एक रूट फ़ाइल और हर पेज की एक फ़ाइल में ले जाएँ:

```text
locales/
├── en.json              # keys used on many pages (nav, footer)
├── de.json
└── pages/
    ├── index/en.json    # keys of pages/index.vue
    └── about/en.json    # keys of pages/about.vue
```

सब कुछ रूट फ़ाइलों में रखना भी काम करता है, और यह सबसे तेज़ पहला कदम है। जब तक आप उन्हें बाँट न दें, `disablePageLocales: true` सेट करें। देखें [अनुवाद फ़ाइलें](/hi/guide/translations)।

### संदेश सिंटैक्स {#message-syntax}

| vue-i18n | nuxt-i18n-micro |
| --- | --- |
| `{name}` नामित इंटरपोलेशन | वही |
| `car \| cars` (2 रूप: 1 → पहला) | रूप 0 से गिनती के अनुसार चुने जाते हैं: `no cars \| one car \| {count} cars` लिखें |
| `@:other.key` linked messages | समर्थित नहीं: टेक्स्ट दोहराएँ या कोड में संयोजन करें |
| `@.upper:` modifiers | समर्थित नहीं: कोड में फ़ॉर्मेट करें या `<i18n-t>` का उपयोग करें |
| `{'@'}` literal escapes | ज़रूरत नहीं: केवल `{word}` टोकन बदले जाते हैं |
| JS/TS संदेश फ़ाइलें | केवल JSON |

बहुवचन नियम को [`plural`](/hi/api/module-options#plural) विकल्प से बदला जा सकता है।

## बदलाव के बाद जाँचें {#check-after-the-switch}

- आपका हर पुराना URL अब भी हल होता है; रणनीतियों के नाम मेल खाते हैं, कस्टम पाथ `globalLocaleRoutes` या `$defineI18nRoute` में चले जाते हैं।
- `hreflang`, canonical और `og:locale` `meta: true` के साथ बॉक्स से ही आते हैं; हाथ से लिखे टैग हटा दें।
- JSON पार्स त्रुटि फ़ाइल पाथ लॉग करती है; dev में गायब कुंजी ब्राउज़र कंसोल में चेतावनी लॉग करती है।
