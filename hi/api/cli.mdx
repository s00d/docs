[CLI गाइड](/hi/guide/cli) सामान्य वर्कफ़्लो दिखाती है। यह पेज सब कुछ सूचीबद्ध करता है, और उसी तालिका से जनरेट होता है जो `--help` को चलाती है।

## सामान्य फ़्लैग {#common-flags}

| फ़्लैग | डिफ़ॉल्ट | विवरण |
| --- | --- | --- |
| `--cwd` | वर्तमान डायरेक्टरी | प्रोजेक्ट डायरेक्टरी |
| `--logLevel` | `info` | आउटपुट स्तर: silent, info |
| `--debug` | `false` | कमांड विफल होने पर स्टैक ट्रेस प्रिंट करें |

## निरीक्षण {#inspect}

### `info` {#info}

प्रोजेक्ट का हल किया गया i18n कॉन्फ़िगरेशन प्रिंट करें

| फ़्लैग | डिफ़ॉल्ट | विवरण |
| --- | --- | --- |
| `--json` | `false` | टेक्स्ट के बजाय JSON प्रिंट करें |

### `check` {#check}

CI गेट: missing, empty, extra, undefined या unused कुंजियों और टूटे हुए प्लेसहोल्डर पर विफल होता है

| फ़्लैग | डिफ़ॉल्ट | विवरण |
| --- | --- | --- |
| `--translationDir` | nuxt.config का `i18n.translationDir` | अनुवाद डायरेक्टरी, प्रोजेक्ट के सापेक्ष |
| `--only` | duplicates को छोड़कर सभी | चलाने के लिए अल्पविराम से अलग की गई जाँचें: missing, empty, extra, placeholders, undefined, unused, duplicates। यहाँ नामित `unused` तब विफल होता है जब वह चल नहीं पाता |
| `--duplicates` | `false` | अलग-अलग कुंजियों के तहत समान टेक्स्ट की भी रिपोर्ट करें |
| `--ignore` | — | छोड़ी जाने वाली सोर्स फ़ाइलों के अल्पविराम से अलग glob, प्रोजेक्ट के सापेक्ष |
| `--json` | `false` | टेक्स्ट के बजाय JSON प्रिंट करें |

```bash
i18n-micro check
i18n-micro check --only missing,placeholders --json
```

### `stats` {#stats}

प्रति लोकेल अनुवाद की पूर्णता दिखाएँ

| फ़्लैग | डिफ़ॉल्ट | विवरण |
| --- | --- | --- |
| `--translationDir` | nuxt.config का `i18n.translationDir` | अनुवाद डायरेक्टरी, प्रोजेक्ट के सापेक्ष |
| `--html` | — | इस फ़ाइल में एक HTML रिपोर्ट भी लिखें |
| `--json` | `false` | टेक्स्ट के बजाय JSON प्रिंट करें |
| `--baseRef` | — | पूर्णता की तुलना करने के लिए Git ref, जैसे HEAD~1 या main |

```bash
i18n-micro stats --baseRef main
i18n-micro stats --html reports/i18n.html
```

### `lint` {#lint}

अनुवादों के टेक्स्ट की जाँच करें; समस्याएँ बची रहने पर विफल होता है

| फ़्लैग | डिफ़ॉल्ट | विवरण |
| --- | --- | --- |
| `--translationDir` | nuxt.config का `i18n.translationDir` | अनुवाद डायरेक्टरी, प्रोजेक्ट के सापेक्ष |
| `--rules` | सभी, या .i18n-lintrc.json का `enabledRules` | चलाने के लिए अल्पविराम से अलग किए गए नियम: no-trailing-spaces, no-multiple-spaces, no-empty-translation, या कोई कस्टम नियम |
| `--fix` | `false` | जो ठीक किया जा सकता है उसे ठीक करें: स्पेस, और replacement वाले कस्टम नियम |
| `--json` | `false` | टेक्स्ट के बजाय JSON प्रिंट करें |

```bash
i18n-micro lint --rules no-trailing-spaces --fix
```

### `search` {#search}

कुंजियाँ और मान खोजें, और दिखाएँ कि हर कुंजी कहाँ उपयोग होती है

| फ़्लैग | डिफ़ॉल्ट | विवरण |
| --- | --- | --- |
| `--translationDir` | nuxt.config का `i18n.translationDir` | अनुवाद डायरेक्टरी, प्रोजेक्ट के सापेक्ष |
| `<query>` | — | खोजने के लिए टेक्स्ट या कुंजी |
| `--caseSensitive` | `false` | केस का मिलान करें |
| `--onlyUnused` | `false` | केवल वे कुंजियाँ जिन्हें `clean` हटाएगा; क्वेरी वैकल्पिक हो जाती है |
| `--scope` | `all` | कहाँ खोजना है: global, pages, all |
| `--limit` | — | अधिकतम इतनी कुंजियाँ लौटाएँ |
| `--ignore` | — | छोड़ी जाने वाली सोर्स फ़ाइलों के अल्पविराम से अलग glob, प्रोजेक्ट के सापेक्ष |
| `--json` | `false` | टेक्स्ट के बजाय JSON प्रिंट करें |

```bash
i18n-micro search "Welcome"
i18n-micro search --onlyUnused
```

## अनुवाद वर्कफ़्लो {#translation-workflow}

### `extract` {#extract}

उन कुंजियों की सूची बनाएँ जिन्हें सोर्स फ़ाइलें उपयोग करती हैं पर जिनका अभी कोई टेक्स्ट नहीं है, और उन्हें डिफ़ॉल्ट टेक्स्ट के साथ डिफ़ॉल्ट लोकेल में जोड़ें

| फ़्लैग | डिफ़ॉल्ट | विवरण |
| --- | --- | --- |
| `--translationDir` | nuxt.config का `i18n.translationDir` | अनुवाद डायरेक्टरी, प्रोजेक्ट के सापेक्ष |
| `--ignore` | — | छोड़ी जाने वाली सोर्स फ़ाइलों के अल्पविराम से अलग glob, प्रोजेक्ट के सापेक्ष |

```bash
i18n-micro extract
```

### `translate` {#translate}

अनुवाद सेवा के ज़रिए डिफ़ॉल्ट लोकेल से गायब अनुवाद भरें

| फ़्लैग | डिफ़ॉल्ट | विवरण |
| --- | --- | --- |
| `--translationDir` | nuxt.config का `i18n.translationDir` | अनुवाद डायरेक्टरी, प्रोजेक्ट के सापेक्ष |
| `--service` | — | अनुवाद सेवा: ai, azure, deepl, google, libretranslate, yandexcloud |
| `--token` | — | API कुंजी। I18N_TRANSLATE_TOKEN एनवायरनमेंट वेरिएबल को प्राथमिकता दें: फ़्लैग शेल हिस्ट्री में पहुँच जाते हैं |
| `--options` | — | सेवा विकल्प key:value जोड़ों के रूप में, अल्पविराम से अलग |
| `--locale` | डिफ़ॉल्ट को छोड़कर हर लोकेल | भरने के लिए अल्पविराम से अलग किए गए लोकेल |
| `--replace` | `false` | हर कुंजी का फिर से अनुवाद करें, मौजूदा मानों को बदलते हुए |
| `--dryRun` | `false` | प्रति लोकेल कुंजियाँ और अक्षर गिनें; कुछ न भेजें |
| `--chunkSize` | — | प्रति अनुरोध स्ट्रिंग; सेवा जितना स्वीकार करती है उस पर सीमित |
| `--pluralSeparator` | `\|` | संदेशों में बहुवचन रूपों का विभाजक |
| `--glossaryFile` | `.i18n-glossary.json` जब वह मौजूद हो | शब्दावली फ़ाइल, `ai` सेवा द्वारा उपयोग की जाती है |

```bash
i18n-micro translate --dryRun
I18N_TRANSLATE_TOKEN=... i18n-micro translate --service deepl --locale de,fr
i18n-micro translate --service ai --options provider:openai,model:gpt-4o-mini
i18n-micro translate --service libretranslate --options baseUrl:https://translate.example.com
```

### `sync` {#sync}

वे कुंजियाँ हटाएँ जो डिफ़ॉल्ट लोकेल में नहीं हैं; जब इसे सुरक्षित साबित नहीं किया जा सकता तो रुक जाता है। गायब कुंजियाँ गायब ही रहती हैं

| फ़्लैग | डिफ़ॉल्ट | विवरण |
| --- | --- | --- |
| `--translationDir` | nuxt.config का `i18n.translationDir` | अनुवाद डायरेक्टरी, प्रोजेक्ट के सापेक्ष |
| `--ignore` | — | छोड़ी जाने वाली सोर्स फ़ाइलों के अल्पविराम से अलग glob, प्रोजेक्ट के सापेक्ष |
| `--dryRun` | `false` | जो हटाया जाएगा उसकी सूची दें; कुछ न लिखें |
| `--force` | `false` | सुरक्षित साबित न हो पाने पर भी कुंजियाँ हटाएँ |

```bash
i18n-micro sync --dryRun
```

### `clean` {#clean}

वे कुंजियाँ हटाएँ जिन्हें प्रोजेक्ट में कुछ भी उपयोग नहीं करता; जब यह साबित नहीं किया जा सकता तो रुक जाता है

| फ़्लैग | डिफ़ॉल्ट | विवरण |
| --- | --- | --- |
| `--translationDir` | nuxt.config का `i18n.translationDir` | अनुवाद डायरेक्टरी, प्रोजेक्ट के सापेक्ष |
| `--include` | — | रेगुलर एक्सप्रेशन: हटाने के लिए केवल मेल खाने वाली कुंजियों पर विचार करें |
| `--exclude` | — | रेगुलर एक्सप्रेशन: मेल खाने वाली कुंजियाँ कभी न हटाएँ |
| `--ignore` | — | छोड़ी जाने वाली सोर्स फ़ाइलों के अल्पविराम से अलग glob, प्रोजेक्ट के सापेक्ष |
| `--dryRun` | `false` | जो हटाया जाएगा उसकी सूची दें; कुछ न लिखें |
| `--force` | `false` | सभी कुंजियों का उपयोग साबित न हो पाने पर भी कुंजियाँ हटाएँ |

```bash
i18n-micro clean --dryRun
i18n-micro clean --exclude '^errors\.'
```

## रीफ़ैक्टरिंग {#refactoring}

### `text-to-i18n` {#text-to-i18n}

Vue टेम्पलेट में हार्डकोड किए गए टेक्स्ट को अनुवाद कॉल से बदलें, और कोड में हार्डकोड किए गए टेक्स्ट की रिपोर्ट करें

| फ़्लैग | डिफ़ॉल्ट | विवरण |
| --- | --- | --- |
| `--translationFile` | `<translationDir>/<defaultLocale>.json` | वह फ़ाइल जिसमें नई कुंजियाँ जाती हैं |
| `--path` | पूरा प्रोजेक्ट | प्रोसेस करने के लिए फ़ाइल या डायरेक्टरी |
| `--context` | — | जनरेट की गई कुंजियों के लिए प्रीफ़िक्स |
| `--ignore` | — | छोड़ी जाने वाली सोर्स फ़ाइलों के अल्पविराम से अलग glob, प्रोजेक्ट के सापेक्ष |
| `--dryRun` | `false` | दिखाएँ कि क्या बदलेगा; कुछ न लिखें |
| `--interactive` | `false` | हर जनरेट की गई कुंजी की पुष्टि करें या उसे संपादित करें |

```bash
i18n-micro text-to-i18n --dryRun
i18n-micro text-to-i18n --path components --context ui
```

### `rename` {#rename}

हर लोकेल और सोर्स फ़ाइलों में किसी कुंजी या नेमस्पेस का नाम बदलें

| फ़्लैग | डिफ़ॉल्ट | विवरण |
| --- | --- | --- |
| `--translationDir` | nuxt.config का `i18n.translationDir` | अनुवाद डायरेक्टरी, प्रोजेक्ट के सापेक्ष |
| `--from` **\*** | — | वर्तमान कुंजी या नेमस्पेस |
| `--to` **\*** | — | नई कुंजी या नेमस्पेस |
| `--ignore` | — | छोड़ी जाने वाली सोर्स फ़ाइलों के अल्पविराम से अलग glob, प्रोजेक्ट के सापेक्ष |
| `--dryRun` | `false` | बदलावों की रिपोर्ट करें; कुछ न लिखें |

**\*** आवश्यक।

```bash
i18n-micro rename --from common.save --to actions.save
```

### `pseudo` {#pseudo}

लेआउट और हार्डकोड किए गए टेक्स्ट की समस्याएँ खोजने के लिए किसी लोकेल को छद्म-अनुवादों से भरें

| फ़्लैग | डिफ़ॉल्ट | विवरण |
| --- | --- | --- |
| `--translationDir` | nuxt.config का `i18n.translationDir` | अनुवाद डायरेक्टरी, प्रोजेक्ट के सापेक्ष |
| `--sourceLocale` | डिफ़ॉल्ट लोकेल | पढ़ने के लिए लोकेल |
| `--targetLocale` **\*** | — | भरने के लिए लोकेल |
| `--replace` | `false` | मौजूदा मानों को अधिलेखित करें |

**\*** आवश्यक।

### `format` {#format}

लोकेल फ़ाइलों को क्रमबद्ध कुंजियों और एकसमान इंडेंटेशन के साथ फिर से लिखें

| फ़्लैग | डिफ़ॉल्ट | विवरण |
| --- | --- | --- |
| `--translationDir` | nuxt.config का `i18n.translationDir` | अनुवाद डायरेक्टरी, प्रोजेक्ट के सापेक्ष |
| `--indent` | `2` | इंडेंटेशन के स्पेस |
| `--sortKeys` | `true` | कुंजियों को क्रमबद्ध करें; उनका क्रम बनाए रखने के लिए --no-sortKeys का उपयोग करें |
| `--check` | `false` | अगर कोई फ़ाइल बदलेगी तो विफल हों; कुछ न लिखें |

```bash
i18n-micro format --check
```

## आदान-प्रदान {#exchange}

### `export` {#export}

लोकेल फ़ाइलों को PO या CSV में एक्सपोर्ट करें, डिफ़ॉल्ट-लोकेल टेक्स्ट को सोर्स के रूप में रखते हुए

| फ़्लैग | डिफ़ॉल्ट | विवरण |
| --- | --- | --- |
| `--translationDir` | nuxt.config का `i18n.translationDir` | अनुवाद डायरेक्टरी, प्रोजेक्ट के सापेक्ष |
| `--format` | `po` | फ़ाइल फ़ॉर्मेट: po, csv |
| `--dir` | po के लिए `pots`, csv के लिए `csv_exports` | आउटपुट डायरेक्टरी, प्रोजेक्ट के सापेक्ष |
| `--force` | `false` | पिछले एक्सपोर्ट के बाद बदली गई और कभी इम्पोर्ट न की गई फ़ाइलों को अधिलेखित करें |

```bash
i18n-micro export --format csv
```

### `import` {#import}

PO या CSV फ़ाइलों को लोकेल फ़ाइलों में मर्ज करें

| फ़्लैग | डिफ़ॉल्ट | विवरण |
| --- | --- | --- |
| `--translationDir` | nuxt.config का `i18n.translationDir` | अनुवाद डायरेक्टरी, प्रोजेक्ट के सापेक्ष |
| `--format` | `po` | फ़ाइल फ़ॉर्मेट: po, csv |
| `--dir` | po के लिए `pots`, csv के लिए `csv_exports` | इनपुट डायरेक्टरी, प्रोजेक्ट के सापेक्ष |
| `--dryRun` | `false` | जो इम्पोर्ट होगा उसकी रिपोर्ट करें; कुछ न लिखें |

```bash
i18n-micro import --format csv --dryRun
```

### `sync-remote` {#sync-remote}

.i18n-remote.json में दिए गए HTTP एंडपॉइंट से ग्लोबल अनुवाद pull करें, या उन्हें वहाँ push करें

| फ़्लैग | डिफ़ॉल्ट | विवरण |
| --- | --- | --- |
| `--translationDir` | nuxt.config का `i18n.translationDir` | अनुवाद डायरेक्टरी, प्रोजेक्ट के सापेक्ष |
| `--pull` | `true` | रिमोट से pull करें |
| `--push` | `false` | रिमोट पर push करें |
| `--force` | `false` | pull पर, रिमोट मान लें; push पर, वह टेक्स्ट अधिलेखित करें जो केवल रिमोट के पास है |
| `--dryRun` | `false` | pull से क्या बदलेगा उसकी रिपोर्ट करें; कुछ न लिखें और न push करें |

```bash
i18n-micro sync-remote --dryRun
i18n-micro sync-remote --no-pull --push
```

| नियम | क्या खोजता है | `--fix` द्वारा ठीक |
| --- | --- | --- |
| `no-trailing-spaces` | किसी मान या पंक्ति के अंत में स्पेस | हाँ |
| `no-multiple-spaces` | लगातार दो या अधिक स्पेस | हाँ |
| `no-empty-translation` | खाली या रिक्त मान | नहीं |

## एग्ज़िट कोड {#exit-codes}

| कोड | अर्थ |
| --- | --- |
| `0` | पूरा हुआ, रिपोर्ट करने को कुछ नहीं |
| `1` | निष्कर्ष: `check`, `lint` या `format --check` को कुछ मिला, `clean` या `sync` किसी हटाने को सुरक्षित साबित नहीं कर सका, `export` बिना इम्पोर्ट किए काम को अधिलेखित कर देता, `translate` ने कुंजियाँ छोड़ दीं, `import` या `sync-remote` को टकराव मिला, `sync-remote` push रिमोट टेक्स्ट गिरा देता। `clean`, `sync` या `sync-remote` pull का `--dryRun` इनकी रिपोर्ट करता है और `0` के साथ बाहर निकलता है |
| `2` | विफलता: गलत उपयोग, न पढ़ा जा सकने वाला प्रोजेक्ट, नेटवर्क या फ़ाइल त्रुटि |

## कॉन्फ़िगरेशन फ़ाइलें {#configuration-files}

| फ़ाइल | किसके द्वारा उपयोग |
| --- | --- |
| `.i18n-lintrc.json` | `lint`: `enabledRules`, `disabledRules`, `customRegexRules` (`name`, `pattern`, `flags`, `description`, `replacement`) |
| `.i18n-remote.json` | `sync-remote`: `url`, `path`, `token`, `auth` (`username`, `password`)। `type` छोड़ा जा सकता है; केवल `custom` मौजूद है |
| `.i18n-glossary.json` | `translate --service ai`: `source`, `target`, और वैकल्पिक `from`, `to` की `entries` |

## एनवायरनमेंट वेरिएबल {#environment-variables}

| नाम | किसके लिए उपयोग |
| --- | --- |
