# 🌍 `<i18n-switcher>` कंपोनेंट

`Nuxt I18n Micro` में `<i18n-switcher>` कंपोनेंट आपके एप्लिकेशन में विभिन्न locales के बीच स्विच करने के लिए एक user-friendly dropdown interface प्रदान करता है। यह कंपोनेंट अत्यधिक अनुकूलन योग्य है, आपके एप्लिकेशन के design और layout के साथ सहज एकीकरण की अनुमति देता है।

`disabled: true` वाले locales dropdown से **छोड़े जाते हैं** (वे SEO / head tags के लिए `$getLocales()` के माध्यम से उपलब्ध रहते हैं)। केवल switchable locales को `NuxtLink` + `hreflang` मिलता है।

## 🛠️ उदाहरण उपयोग

### बुनियादी उपयोग

```vue
<template>
  <i18n-switcher />
</template>
```

यह डिफ़ॉल्ट styling और व्यवहार के साथ एक locale switcher render करता है।

### कस्टम Labels और Inline Styles

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

यह उदाहरण कस्टम labels और inline styles के साथ पूरी तरह से कस्टमाइज़ किए गए locale switcher को दर्शाता है।

## 🔌 Slots

Switcher का हर visual भाग replace किया जा सकता है। Slots ऊपर props table के साथ सूचीबद्ध हैं; प्रत्येक template सामग्री लेता है:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Slots जिनके नाम `-item`, `-link-content` से समाप्त होते हैं या `before-item` से शुरू होते हैं, वे `locale` object प्राप्त करते हैं जिसका वे भाग हैं।

## 🎨 Styles अवलोकन

`<i18n-switcher>` कंपोनेंट inline styles का उपयोग करके परिभाषित बुनियादी styles के साथ आता है जिन्हें props के माध्यम से कस्टम styles पास करके आसानी से override किया जा सकता है। यहाँ डिफ़ॉल्ट styling का एक संक्षिप्त अवलोकन है:

- **Wrapper**: Dropdown के positioning को नियंत्रित करता है।
- **Button**: Dropdown toggle button को style करता है।
- **Dropdown**: Dropdown list को style करता है।
- **Items**: List में प्रत्येक item को style करता है।
- **Links**: प्रत्येक item के अंदर links को style करता है।
- **Icon**: Dropdown indicator icon को style करता है।

आप संबंधित props के माध्यम से कस्टम styles पास करके इन styles को कस्टमाइज़ कर सकते हैं, यह सुनिश्चित करते हुए कि locale switcher आपके एप्लिकेशन के UI में सहज रूप से एकीकृत हो।
