# 🌍 `<i18n-group>` कंपोनेंट

Nuxt I18n Micro में `<i18n-group>` कंपोनेंट ट्रांसलेशन को एक सामान्य प्रीफ़िक्स के तहत समूहित करने का एक सुविधाजनक तरीका प्रदान करता है, जिससे पुनरावृत्ति कम होती है और कोड संगठन में सुधार होता है।

## ⚙️ Props

{/* generated:component:i18n-group — do not edit; run `pnpm run docs:generate` */}

| Prop | प्रकार | डिफ़ॉल्ट | विवरण |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | स्लॉट के अंदर हर लुकअप जिस कुंजी प्रीफ़िक्स के विरुद्ध हल होता है। |
| `groupClass` | `string` | `''` | रैपर एलिमेंट पर अतिरिक्त क्लास। |

**\*** आवश्यक।

### स्लॉट्स

| स्लॉट | बाइंडिंग्स | विवरण |
| --- | --- | --- |
| `default` | `prefix`, `t` | `prefix` और उससे स्कोप किया गया `t` फ़ंक्शन प्राप्त करता है। |

{/* /generated:component:i18n-group */}

## 🎯 स्लॉट्स

डिफ़ॉल्ट स्लॉट `prefix` और उससे स्कोप किया गया `t` फ़ंक्शन प्राप्त करता है, इसलिए अंदर की कुंजियाँ
प्रीफ़िक्स के सापेक्ष लिखी जाती हैं:

```vue
<i18n-group prefix="checkout">
  <template #default="{ t }">
    <h2>{{ t('title') }}</h2>
    <p>{{ t('summary', { count: 3 }) }}</p>
  </template>
</i18n-group>
```

## 🛠️ उदाहरण उपयोग

### मूल उपयोग

```vue
<template>
  <i18n-group prefix="product.details">
    <template #default="{ t }">
      <h1>{{ t('title') }}</h1>
      <p>{{ t('description') }}</p>
      <div class="price">{{ t('price', { value: 99.99 }) }}</div>
    </template>
  </i18n-group>
</template>
```

ट्रांसलेशन फ़ाइल:

```json
{
  "product": {
    "details": {
      "title": "Premium Product",
      "description": "This is a premium product",
      "price": "Price: ${value}"
    }
  }
}
```

### कस्टम क्लास के साथ

```vue
<template>
  <i18n-group prefix="user.profile" group-class="profile-section">
    <template #default="{ t }">
      <div class="user-info">
        <h2>{{ t('title') }}</h2>
        <p>{{ t('bio') }}</p>
        <div class="stats">
          <span>{{ t('stats.followers') }}</span>
          <span>{{ t('stats.following') }}</span>
        </div>
      </div>
    </template>
  </i18n-group>
</template>
```

ट्रांसलेशन फ़ाइल:

```json
{
  "user": {
    "profile": {
      "title": "User Profile",
      "bio": "User biography goes here",
      "stats": {
        "followers": "Followers: {count}",
        "following": "Following: {count}"
      }
    }
  }
}
```

### डायनामिक कंटेंट के साथ

```vue
<template>
  <i18n-group prefix="blog.post">
    <template #default="{ t }">
      <article>
        <h1>{{ t('title') }}</h1>
        <div class="meta">
          {{ t('meta.author', { name: author }) }} |
          {{ t('meta.date', { date: publishDate }) }}
        </div>
        <div v-for="(section, index) in sections" :key="index">
          <h2>{{ t(`sections.${index}.title`) }}</h2>
          <p>{{ t(`sections.${index}.content`) }}</p>
        </div>
      </article>
    </template>
  </i18n-group>
</template>

<script setup>
const author = 'John Doe'
const publishDate = '2024-01-01'
const sections = ['intro', 'main', 'conclusion']
</script>
```

## 🎨 स्टाइलिंग

कंपोनेंट अपने कंटेंट को `i18n-group` क्लास और `groupClass` prop में निर्दिष्ट किसी भी अतिरिक्त क्लास वाले div में रैप करता है:

```css
.i18n-group {
  /* Your base styles */
}

.profile-section {
  /* Additional styles for profile sections */
}
```

## 🚀 सर्वोत्तम अभ्यास

1. **सुसंगत प्रीफ़िक्स**: सुसंगत और तार्किक प्रीफ़िक्स का उपयोग करें जो आपके एप्लिकेशन की संरचना को प्रतिबिंबित करें

```vue
<i18n-group prefix="features.pricing">
<i18n-group prefix="features.security">
```

2. **मॉड्यूलर संगठन**: संबंधित ट्रांसलेशन को अर्थपूर्ण प्रीफ़िक्स के तहत एक साथ समूहित करें

```vue
<i18n-group prefix="checkout.payment">
<i18n-group prefix="checkout.shipping">
```

3. **पुन: प्रयोज्य कंपोनेंट्स**: अपने स्वयं के ट्रांसलेशन समूहों के साथ पुन: प्रयोज्य कंपोनेंट्स बनाएँ

```vue
<!-- UserProfile.vue -->
<i18n-group prefix="user.profile">

<!-- UserSettings.vue -->
<i18n-group prefix="user.settings">
```

4. **नेस्टेड समूह**: स्पष्टता बनाए रखने के लिए समूहों को गहराई से नेस्ट करने से बचें

```vue
<!-- Good -->
<i18n-group prefix="shop.product">

<!-- Avoid -->
<i18n-group prefix="shop.category.product.details.specs">
```
