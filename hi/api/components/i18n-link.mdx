# 🌍 `<i18n-link>` कंपोनेंट

`Nuxt I18n Micro` में `<i18n-link>` कंपोनेंट एक बहुमुखी लिंक कंपोनेंट है जो वर्तमान लोकेल के आधार पर रूट्स को स्वचालित रूप से लोकेलाइज़ करता है। यह `<NuxtLink>` कंपोनेंट के चारों ओर एक रैपर के रूप में कार्य करता है, जो सक्रिय लिंक स्टाइलिंग और बाहरी लिंक के समर्थन जैसी अतिरिक्त विशेषताएँ प्रदान करता है।

## ⚙️ Props

{/* generated:component:i18n-link — do not edit; run `pnpm run docs:generate` */}

| Prop | प्रकार | डिफ़ॉल्ट | विवरण |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | लक्ष्य रूट। स्वचालित रूप से लोकेलाइज़ किया गया; बाहरी URL को बिना बदले पास किया जाता है। |
| `activeStyle` | `Partial<CSSStyleValue>` | — | तब लागू की जाने वाली इनलाइन स्टाइल जब लिंक वर्तमान रूट पर इंगित हो। |

**\*** आवश्यक।

### स्लॉट्स

| स्लॉट | बाइंडिंग्स | विवरण |
| --- | --- | --- |
| `default` | — | लिंक कंटेंट। |

{/* /generated:component:i18n-link */}

`to` वह सब स्वीकार करता है जो `NuxtLink` करता है — एक पथ, एक नामित रूट, या एक रिज़ॉल्व्ड रूट ऑब्जेक्ट।
एक एब्सोल्यूट URL का पता लगाया जाता है और उसे लोकेलाइज़ करने के बजाय एक साधारण `<a target="_blank" rel="noopener noreferrer">` के रूप में रेंडर किया जाता है।

## 🛠️ उदाहरण उपयोग

### मूल उपयोग

```vue
<i18n-link to="/about">About Us</i18n-link>
```

यह उदाहरण `/about` पेज के लिए एक लिंक बनाता है, जो वर्तमान लोकेल के लिए लोकेलाइज़्ड है।

### इनलाइन स्टाइल के साथ सक्रिय लिंक स्टाइलिंग

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

जब उपयोगकर्ता `/about` पेज पर होगा तो लिंक का टेक्स्ट bold होगा, जिससे आप सक्रिय लिंक को सीधे इनलाइन स्टाइल के साथ स्टाइल कर सकते हैं।

### बाहरी लिंक हैंडलिंग

कंपोनेंट स्वचालित रूप से बाहरी लिंक का पता लगाता है और सुरक्षा के लिए आवश्यक एट्रिब्यूट्स जोड़ता है।

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

यह लिंक `https://example.com` को नए टैब में `rel="noopener noreferrer"` लागू करके खोलेगा।

## 🎨 स्टाइल

कंपोनेंट अब सक्रिय स्थिति के लिए क्लास के बजाय इनलाइन स्टाइल का उपयोग करता है। आप इन स्टाइल्स को `activeStyle` prop का उपयोग करके अनुकूलित कर सकते हैं।

### डिफ़ॉल्ट सक्रिय स्टाइल

- **Font Weight**: `bold`
- **Color**: ब्राउज़र के डिफ़ॉल्ट रंग का उत्तराधिकार (यदि `activeStyle` में कोई `color` निर्दिष्ट नहीं है)।

आप इन्हें `activeStyle` prop के माध्यम से कस्टम स्टाइल्स प्रदान करके ओवरराइड कर सकते हैं।

### कस्टम सक्रिय स्टाइल

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

इस उदाहरण में, सक्रिय होने पर लिंक bold और हरा होगा।

## 🚀 अतिरिक्त विशेषताएँ

### कस्टम कंटेंट के लिए स्लॉट

आप स्लॉट का उपयोग करके लिंक के अंदर कस्टम कंटेंट पास कर सकते हैं, जिससे कंपोनेंट विभिन्न उपयोग-केसों के लिए लचीला बनता है।

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### सुगम्यता संवर्द्धन

अधिक सुगम अनुभव सुनिश्चित करने के लिए कंपोनेंट `aria-label` और अन्य सुगम्यता एट्रिब्यूट्स का समर्थन करता है।

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
