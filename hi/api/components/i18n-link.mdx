# 🌍 `<i18n-link>` कंपोनेंट

`Nuxt I18n Micro` में `<i18n-link>` कंपोनेंट एक बहुमुखी link कंपोनेंट है जो वर्तमान locale के आधार पर स्वचालित रूप से routes को localize करता है। यह `<NuxtLink>` कंपोनेंट के चारों ओर एक wrapper के रूप में कार्य करता है, जो active link styling और external links के लिए समर्थन जैसी अतिरिक्त सुविधाएँ प्रदान करता है।

## ⚙️ Props

| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | लक्षित route। स्वचालित रूप से localized; एक external URL को अपरिवर्तित पास किया जाता है। |
| `activeStyle` | `Partial<CSSStyleValue>` | — | Inline style जो तब लागू होती है जब link वर्तमान route की ओर इंगित करता है। |

`to` वह सब कुछ स्वीकार करता है जो `NuxtLink` करता है — एक path, एक named route, या एक resolved route object।
एक absolute URL का पता लगाया जाता है और इसे localize करने के बजाय एक सादे `<a target="_blank" rel="noopener noreferrer">` के रूप में render किया जाता है।

## 🛠️ उदाहरण उपयोग

### बुनियादी उपयोग

```vue
<i18n-link to="/about">About Us</i18n-link>
```

यह उदाहरण `/about` पेज के लिए एक link बनाता है, जो वर्तमान locale के लिए localized होता है।

### Inline Styles के साथ Active Link Styling

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

जब उपयोगकर्ता `/about` पेज पर होता है तो link में bold text होगा, जिससे आप inline styles के साथ सीधे active link को style कर सकते हैं।

### External Links Handling

कंपोनेंट स्वचालित रूप से external links का पता लगाता है और सुरक्षा के लिए आवश्यक attributes जोड़ता है।

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

यह link `rel="noopener noreferrer"` लागू करके `https://example.com` को एक नए tab में खोलेगा।

## 🎨 Styles

कंपोनेंट अब active state के लिए एक class के बजाय inline styles का उपयोग करता है। आप `activeStyle` prop का उपयोग करके इन styles को कस्टमाइज़ कर सकते हैं।

### डिफ़ॉल्ट Active Styles

- **Font Weight**: `bold`
- **Color**: Browser के डिफ़ॉल्ट color को inherit करता है (यदि `activeStyle` में कोई `color` निर्दिष्ट नहीं है)।

आप `activeStyle` prop के माध्यम से कस्टम styles प्रदान करके इन्हें ओवरराइड कर सकते हैं।

### कस्टम Active Styles

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

इस उदाहरण में, active होने पर link bold और हरा होगा।

## 🚀 अतिरिक्त सुविधाएँ

### कस्टम सामग्री के लिए Slot

आप slots का उपयोग करके link के अंदर कस्टम सामग्री पास कर सकते हैं, जिससे कंपोनेंट विभिन्न उपयोग मामलों के लिए लचीला हो जाता है।

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### Accessibility संवर्द्धन

कंपोनेंट अधिक accessible अनुभव सुनिश्चित करने के लिए `aria-label` और अन्य accessibility attributes का समर्थन करता है।

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
