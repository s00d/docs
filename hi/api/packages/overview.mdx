description: "हर @i18n-micro/* पैकेज का एक्सपोर्ट किया गया API, उन API स्नैपशॉट से जनरेट किया गया जिन्हें CI स्रोत के विरुद्ध जाँचता है।"
---

Nuxt मॉड्यूल छोटे `@i18n-micro/*` पैकेजों से बना है, और उनमें से अधिकांश स्वतंत्र रूप से काम करते हैं: Vue ऐप में `@i18n-micro/vue`, कहीं भी `@i18n-micro/core`। इन पेजों का उपयोग यह देखने के लिए करें कि कोई पैकेज प्रति एंट्री पॉइंट क्या एक्सपोर्ट करता है। हर पेज उस स्नैपशॉट से जनरेट होता है जिसे [`pnpm run api:surface`](https://s00d.github.io/nuxt-i18n-micro/contributing/maintenance-commands#api-surface) TypeScript स्रोतों के विरुद्ध जाँचता है, इसलिए कोई एक्सपोर्ट CI की जानकारी के बिना नहीं बदल सकता।
