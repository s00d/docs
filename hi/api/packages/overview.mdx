# पैकेज APIs

`nuxt-i18n-micro` छोटे पैकेजों के एक सेट से बना है, जिनमें से अधिकांश स्वतंत्र रूप से उपयोग करने योग्य हैं — एक सादे Vue ऐप में `@i18n-micro/vue`, और कहीं भी `@i18n-micro/core`।

नीचे प्रत्येक पेज API snapshot से जनरेट होता है जिसे [`pnpm run api:surface`](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/maintenance-commands.md#api-surface) TypeScript स्रोतों के विरुद्ध जाँचता है, इसलिए कोई export इस संदर्भ में परिवर्तन या CI विफलता के बिना गायब नहीं हो सकता।
