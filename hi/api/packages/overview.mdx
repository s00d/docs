# पैकेज API

`nuxt-i18n-micro` छोटे पैकेजों के एक सेट से बनाया गया है, जिनमें से अधिकांश का उपयोग स्वतंत्र रूप से भी किया जा सकता है — एक साधारण Vue ऐप में `@i18n-micro/vue`, कहीं भी `@i18n-micro/core`।

नीचे दिया गया प्रत्येक पेज उस API स्नैपशॉट से जनरेट होता है जिसकी [`pnpm run api:surface`](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/maintenance-commands.md#api-surface) TypeScript सोर्सेस के विरुद्ध जाँच करती है, इसलिए इस रेफ़रेंस में बदलाव के बिना या CI विफल हुए बिना कोई एक्सपोर्ट गायब नहीं हो सकता।
