# API संदर्भ

## Runtime API

- [Methods](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, locale switching, रूटिंग helpers
- [Events](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [अनुवाद और Cache](/api/cache) — `TranslationStorage`, payload लोडिंग, `$clearCache`

## Server middleware

Server handlers dedicated middleware का उपयोग करते हैं (client `$t` helpers का नहीं):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — API routes और server handlers में अनुवाद करें
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — detected locale और metadata पढ़ें

सेटअप, locale detection प्राथमिकता, और उदाहरणों के लिए पूरी [Server-Side अनुवाद गाइड](/guides/server-side-translations) देखें।
