# API रेफ़रेंस

## रनटाइम API

- [मेथड्स](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, लोकेल स्विचिंग, रूटिंग हेल्पर्स
- [इवेंट्स](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [ट्रांसलेशन और कैश](/api/cache) — `TranslationStorage`, पेलोड लोडिंग, `$clearCache`

## सर्वर मिडलवेयर

सर्वर हैंडलर्स समर्पित मिडलवेयर का उपयोग करते हैं (क्लाइंट `$t` हेल्पर्स का नहीं):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — API रूट्स और सर्वर हैंडलर्स में ट्रांसलेट करें
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — डिटेक्ट किए गए लोकेल और मेटाडेटा को पढ़ें

सेटअप, लोकेल डिटेक्शन प्राथमिकता, और उदाहरणों के लिए पूरी [सर्वर-साइड ट्रांसलेशन गाइड](/guides/server-side-translations) देखें।
