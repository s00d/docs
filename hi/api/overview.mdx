यह अनुभाग Nuxt मॉड्यूल के हर विकल्प, हेल्पर, हुक, composable और कंपोनेंट को सूचीबद्ध करता है, साथ ही हर `@i18n-micro/*` पैकेज की निर्यातित API को भी। किसी सिग्नेचर या डिफ़ॉल्ट मान को देखने के लिए इसका उपयोग करें; [गाइड](/hi/guide/getting-started) बताती है कि इनका उपयोग कैसे करें। यहाँ की अधिकांश तालिकाएँ स्रोत कोड से जनरेट की गई हैं, इसलिए वे कोड से मेल खाती हैं।

## Nuxt मॉड्यूल {#nuxt-module}

| पेज | विषय |
| --- | --- |
| [मॉड्यूल विकल्प](/hi/api/module-options) | `nuxt.config` में हर `i18n` कुंजी, प्रकार और डिफ़ॉल्ट के साथ |
| [हेल्पर](/hi/api/methods) | `$t`, `$tc`, `$tn`, `$td`, `$localePath`, `$switchLocale`, `$defineI18nRoute` और बाकी |
| [हुक](/hi/api/events) | `i18n:register` रनटाइम हुक |

## Composables {#composables}

| Composable | किसके लिए उपयोग करें |
| --- | --- |
| [`useI18n`](/hi/composables/useI18n) | `<script setup>` में हेल्पर |
| [`useI18nLocale`](/hi/composables/useI18nLocale) | कस्टम डिटेक्शन प्लगइन में locale स्थिति और कुकी |
| [`useI18nHead`](/hi/composables/useI18nHead) | जनरेट किए गए SEO टैग के प्रति-पेज ओवरराइड |
| [`useLocaleHead`](/hi/composables/useLocaleHead) | आपके अपने `useHead` के लिए SEO टैग एक ऑब्जेक्ट के रूप में |

## कंपोनेंट {#components}

| कंपोनेंट | क्या रेंडर करता है |
| --- | --- |
| [`<i18n-t>`](/hi/components/i18n-t) | एक अनुवाद, बहुवचन, फ़ॉर्मेटिंग और स्लॉट इंटरपोलेशन के साथ |
| [`<i18n-link>`](/hi/components/i18n-link) | स्थानीयकृत रूट के लिए एक `NuxtLink` |
| [`<i18n-switcher>`](/hi/components/i18n-switcher) | एक locale ड्रॉपडाउन |
| [`<i18n-group>`](/hi/components/i18n-group) | साझा कुंजी उपसर्ग वाला एक ब्लॉक |

## सर्वर {#server}

Nitro हैंडलर क्लाइंट हेल्पर के बजाय `useTranslationServerMiddleware` और `useLocaleServerMiddleware` का उपयोग करते हैं। देखें [सर्वर रूट](/hi/guide/server-side-translations)।

## पैकेज {#packages}

[पैकेज API](/hi/api/packages/overview) हर `@i18n-micro/*` पैकेज के निर्यात सूचीबद्ध करता है, प्रत्येक के लिए एक जनरेट किया गया पेज।
