# 🌍 `useLocaleHead` कंपोज़ेबल

`useLocaleHead` कंपोज़ेबल `Nuxt I18n Micro` में एक यूटिलिटी है जो आपको लोकेलाइज़्ड रूट्स के लिए SEO एट्रिब्यूट्स और HTML मेटा टैग्स को प्रबंधित करने में मदद करती है। यह HTML दस्तावेज़ के `lang` और `dir` के लिए एट्रिब्यूट्स को डायनामिक रूप से जनरेट करता है और आपके लोकेलाइज़्ड कंटेंट के SEO को बेहतर बनाने के लिए `meta` और `link` टैग बनाता है।

वर्तमान रूट के लिए SEO head टैग: हर लोकेल के लिए `hreflang` alternate प्लस
`x-default`, एक canonical लिंक, `og:locale`, और `<html>` पर `lang`/`dir`।

केवल तब आवश्यक है जब `meta` अक्षम हो या डिफ़ॉल्ट्स को समायोजित करने की आवश्यकता हो। `meta: true` के साथ
मॉड्यूल स्वयं वही टैग रजिस्टर करता है।

**लौटाता है** — एक ref जो head ऑब्जेक्ट रखता है, `useHead` को पास करने के लिए तैयार

```ts
const head = useLocaleHead({ addSeoAttributes: true })

```

## 🛠️ लौटाए गए मान

`useLocaleHead` कंपोज़ेबल एक रिएक्टिव ऑब्जेक्ट और एक अपडेटर फ़ंक्शन लौटाता है जिसे स्रोत डेटा बदलने पर आपको कॉल करना चाहिए। दोनों आकार ऊपर के हस्ताक्षर में हैं, जो स्रोत से जनरेट किया गया है।

### `metaObject`

रिएक्टिव head पेलोड (html attrs, meta, link) जो `useHead(metaObject)` के लिए उपयुक्त है।

- **उदाहरण**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

वर्तमान रूट, लोकेल और कॉन्फ़िग के आधार पर `metaObject` को पुनः गणना करता है। इसे इनपुट बदलने पर कॉल करें। उदाहरण के लिए, रूट बदलने पर।

- **उदाहरण**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### `link` और `meta` तक पहुँचना

`link` और `meta` सरणियाँ `metaObject.value` के माध्यम से सुलभ हैं:

- **उदाहरण**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ उदाहरण उपयोग

### मूल उपयोग

डिफ़ॉल्ट विकल्पों के साथ लोकेल-विशिष्ट head एट्रिब्यूट्स जनरेट करें।

```js
const head = useLocaleHead()
```

### पहचानकर्ता एट्रिब्यूट कस्टमाइज़ करें

जनरेट किए गए टैग्स के लिए एक कस्टम पहचानकर्ता एट्रिब्यूट का उपयोग करें।

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### SEO एट्रिब्यूट्स अक्षम करें

SEO-संबंधित मेटा और लिंक टैग जोड़े बिना head एट्रिब्यूट्स जनरेट करें।

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### बेस URL निर्दिष्ट करें

canonical और वैकल्पिक URL के लिए एक कस्टम बेस URL सेट करें।

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 अतिरिक्त विशेषताएँ

### SEO Meta और Link टैग

जब `addSeoAttributes` सक्षम होता है, तो कंपोज़ेबल स्वचालित रूप से निम्नलिखित टैग जनरेट करता है:

- वर्तमान लोकेल के लिए `og:locale` (`language_TERRITORY`, अंडरस्कोर के साथ)। `locale.og` से लिया गया या जब संभव हो तो `locale.iso` से बदला गया।
- पेज के canonical URL के लिए `og:url`।
- वैकल्पिक भाषा संस्करणों के लिए `og:locale:alternate`।
- SEO अनुकूलन के लिए `rel="canonical"` और `rel="alternate"` लिंक।
- डिफ़ॉल्ट लोकेल के URL की ओर इशारा करने वाला `hreflang="x-default"` लिंक। यह सर्च इंजनों को बताता है कि किन उपयोगकर्ताओं को कौन-सा URL दिखाना है जिनकी भाषा किसी भी परिभाषित लोकेल से मेल नहीं खाती।

### डायनामिक लोकेल और डायरेक्शन

कंपोज़ेबल वर्तमान रूट के लोकेल के आधार पर `lang` और `dir` एट्रिब्यूट्स को डायनामिक रूप से निर्धारित करता है, यह सुनिश्चित करते हुए कि आपका HTML दस्तावेज़ अंतरराष्ट्रीय उपयोगकर्ताओं के लिए सही ढंग से कॉन्फ़िगर किया गया है।

### लोकेलाइज़्ड रूट्स हैंडलिंग

यदि आपके रूट्स लोकेल कोड (जैसे `/en/about`) के साथ प्रीफ़िक्स्ड हैं, तो कंपोज़ेबल URL जनरेट करने के लिए फुल पथ को बुद्धिमानी से समायोजित करता है, यह सुनिश्चित करते हुए कि SEO एट्रिब्यूट्स सटीक और प्रासंगिक हैं।

यह कंपोज़ेबल अंतरराष्ट्रीय दर्शकों के लिए आपके Nuxt एप्लिकेशन को अनुकूलित करने की प्रक्रिया को सरल बनाता है, यह सुनिश्चित करते हुए कि आपकी साइट वैश्विक सर्च इंजन और उपयोगकर्ताओं के लिए अच्छी तरह से तैयार है।

## 🛠️ उदाहरण उपयोग

निम्नलिखित उदाहरण दर्शाता है कि डिफ़ॉल्ट सेटिंग्स के साथ Vue कंपोनेंट के भीतर `useLocaleHead` कंपोज़ेबल का उपयोग कैसे करें:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### कोड की व्याख्या

- **`useLocaleHead` कंपोज़ेबल**: यह कंपोज़ेबल `<script setup>` अनुभाग में कॉल किया जाता है और एक ऑब्जेक्ट लौटाता है जिसमें `htmlAttrs`, `meta`, और `link` होते हैं।

- **`<html>` टैग**: HTML दस्तावेज़ के लिए `lang` और `dir` एट्रिब्यूट्स वर्तमान लोकेल के आधार पर डायनामिक रूप से निर्धारित किए जाते हैं और `<html>` टैग पर लागू किए जाते हैं।

- **`<head>` अनुभाग**:
  - **मेटा टैग**: SEO-संबंधित मेटा टैग जनरेट होते हैं, जिनमें `og:locale`, `og:url`, और पेज के वैकल्पिक भाषा संस्करण निर्दिष्ट करने के लिए `rel="canonical"` और `rel="alternate"` टैग शामिल हैं।
  - **लिंक टैग**: Canonical लिंक, वैकल्पिक भाषा संस्करणों के लिंक, और `hreflang="x-default"` लिंक (डिफ़ॉल्ट लोकेल URL की ओर इशारा करते हुए) शामिल हैं।

- **`<body>` अनुभाग**: पेज का मुख्य कंटेंट यहाँ प्रदर्शित होता है। इस उदाहरण में, एक सरल हेडर और पैराग्राफ का उपयोग किया गया है।

### 📝 नोट्स

1. **एट्रिब्यूट्स**: उपयोग किए गए एट्रिब्यूट्स (`lang`, `dir`, `rel`, `href`, `hreflang`, `property`, `content`) `useLocaleHead` द्वारा लौटाए गए ऑब्जेक्ट से निकाले जाते हैं।

2. **SEO टैग जनरेशन**: यदि `addSeoAttributes` विकल्प को `true` पर सेट किया गया है, तो कंपोज़ेबल वर्तमान लोकेल के लिए स्वचालित रूप से SEO टैग जनरेट करता है।

3. **बेस URL**: canonical और वैकल्पिक लिंक सही ढंग से जनरेट करने के लिए आप `baseUrl` विकल्प का उपयोग करके अपना कस्टम बेस URL सेट कर सकते हैं।

यह उदाहरण दिखाता है कि सही SEO एट्रिब्यूट्स सुनिश्चित करने और लोकेलाइज़्ड पेजों की सर्च इंजन इंडेक्सिंग को बेहतर बनाने के लिए अपने एप्लिकेशन के कंपोनेंट्स में `useLocaleHead` को इंटीग्रेट करना कितना आसान है।

## 🧩 कस्टमाइज़ेशन और लाइफ़साइकल

- `useLocaleHead` स्वयं परिवर्तनों की सदस्यता नहीं लेता। यह `metaObject` और `updateMeta` लौटाता है।
- जब इनपुट बदलते हैं (आमतौर पर रूट बदलने पर) आपको `updateMeta()` कॉल करना चाहिए, उदाहरण के लिए एक प्लगइन से:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## `useI18nHead` के बजाय कब उपयोग करें

जब `meta: true` (डिफ़ॉल्ट) हो, तो **प्रति-पेज** ओवरराइड्स (कस्टम hreflang, अतिरिक्त `og:title`, आंशिक अक्षम) के लिए [`useI18nHead`](/api/composables/use-i18n-head) को प्राथमिकता दें। `useLocaleHead` का सीधे उपयोग केवल तब करें जब `meta: false` हो या आप स्वयं `useHead` का प्रबंधन करते हों।
