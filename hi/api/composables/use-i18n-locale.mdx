# useI18nLocale

## हस्ताक्षर

i18n लोकेल प्रबंधन के लिए केंद्रीकृत प्रवेश बिंदु।
useState('i18n-locale'), लोकेल कुकी, और सिंक यूटिलिटीज़ को जोड़ता है।

## API

| प्रॉपर्टी/मेथड                                | प्रकार                              | विवरण                                                                              |
| ----------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| `locale`                                        | `Ref<string \| null>`               | रिएक्टिव लोकेल स्टेट (`useState('i18n-locale')`)                                    |
| `localeCookie`                                  | `Ref`                               | लोकेल कुकी (जब `localeCookie` विकल्प सक्षम हो)                                       |
| `hashCookie`                                    | `Ref`                               | तब उपयोग की जाने वाली कुकी जब `hashMode` सक्रिय हो                                    |
| `validLocales`                                  | `string[]`                          | मॉड्यूल कॉन्फ़िग से सक्षम लोकेल कोड (`disabled` को छोड़कर)                             |
| `getLocale()`                                   | `() => string \| null`              | वर्तमान लोकेल: state → cookie (या hash mode में hash cookie)                          |
| `getPreferredLocale()`                          | `() => string \| null`              | स्टेट/कुकी से लोकेल जो `validLocales` के विरुद्ध **मान्य** किया गया, या `null`         |
| `getLocaleWithServerFallback(serverLocale?)`    | `(serverLocale?) => string \| null` | State → cookie → वैकल्पिक सर्वर संदर्भ (`no_prefix` init के दौरान उपयोग किया जाता है)  |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string`             | ट्रांसलेशन लोड करने के लिए लोकेल: hash mode स्टेट पसंद करता है; अन्यथा रूट से पढ़ता है |
| `resolveInitialLocale(options)`                 | `(options) => string`               | लोकेल हल करता है: state → `serverLocale` → route; आवश्यकता पड़ने पर स्टेट सिंक करता है |
| `setLocale(locale)`                             | `(locale: string \| null) => void`  | लोकेल सेट करें और कुकीज़ के साथ सिंक करें                                              |
| `syncLocale(locale)`                            | `(locale: string \| null) => void`  | केवल कुकीज़ सिंक करें (कोई स्टेट अपडेट नहीं)                                            |
| `isValidLocale(locale)`                         | `(locale) => boolean`               | जाँच करें कि स्ट्रिंग `validLocales` में है या नहीं                                    |

### `resolveInitialLocale` विकल्प

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

स्टार्टअप पर मुख्य प्लगइन द्वारा आंतरिक रूप से उपयोग किया जाता है। कस्टम प्लगइन्स इसे तब कॉल कर सकते हैं जब वैकल्पिक डिटेक्शन फ्लो लागू करते हैं।

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

दिए गए रूट ऑब्जेक्ट के लिए ट्रांसलेशन लोड करने और संदेश फ़ॉर्मेट करने के लिए उपयोग की जाने वाली लोकेल लौटाता है।

## प्रोग्रामेटिक लोकेल सेटिंग

`useState('i18n-locale')` के सीधे उपयोग की तुलना में `useI18nLocale()` को प्राथमिकता दें:

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
`setLocale()` केवल लोकेल वरीयता (state + cookie) अपडेट करता है। क्लाइंट पर सक्रिय ट्रांसलेशन कॉन्टेक्स्ट को भी पुनः लोड करने के लिए, `useNuxtApp()` या `useI18n()` से `$switchLocale()` का उपयोग करें। यह विशेष रूप से `no_prefix` के लिए महत्वपूर्ण है, जहाँ URL नहीं बदलता है। देखें [FAQ — URL बदले बिना लोकेल स्विच करें](/guides/faq#-switch-locale-without-changing-the-url)।
</Tip>
