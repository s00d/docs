# 🛠️ `useI18n` Composable

`Nuxt I18n Micro` में `useI18n` composable कंपोनेंट्स और scripts में अधिकांश रनटाइम i18n helpers तक पहुँच प्रदान करता है। Methods **`$` prefix के साथ और उसके बिना** दोनों उपलब्ध हैं (उदाहरण के लिए `$t` और `t`)।

कुछ injections — `$defineI18nRoute` और `$clearCache` — केवल `useNuxtApp()` पर उपलब्ध हैं। [Methods — `$defineI18nRoute`](/api/methods#definei18nroute) और [`$clearCache`](/api/methods#clearcache) देखें।

## 📊 यह क्या लौटाता है

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

एक सादे object के रूप में प्रत्येक रनटाइम helper।

वही functions जिन्हें plugin `$t`, `$tc` आदि के रूप में inject करता है, दोनों dollar-prefixed नाम और एक bare alias के तहत उपलब्ध हैं — इसलिए `const \{ t \} = useI18n()` और `const \{ $t \} = useI18n()` दोनों काम करते हैं।

**Returns** — [methods संदर्भ](/api/methods) में वर्णित helpers

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

यह जो हर helper लौटाता है — `$t`, `$tc`, `$has`, `$switchLocale` और शेष — उसके signature के साथ [Methods संदर्भ](/api/methods) पर पूर्ण रूप से सूचीबद्ध और प्रलेखित है।

## केवल-`useNuxtApp()` APIs

ये `useI18n()` द्वारा **वापस नहीं** किए जाते हैं। इन्हें `useNuxtApp()` से import करें:

| Method                     | उद्देश्य                                                                         |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | प्रति-पेज locale routes, restrictions, और `script setup` में inline अनुवाद |
| `$clearCache()`            | इन-मेमोरी अनुवाद कैश और लोड किए गए chunks को साफ़ करता है                            |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

पूर्ण signatures और उदाहरणों के लिए [Methods](/api/methods) देखें।

## 🛠️ उदाहरण उपयोग

### बुनियादी Locale पुनर्प्राप्ति

एप्लिकेशन का वर्तमान locale पुनर्प्राप्त करें।

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Parameters के साथ अनुवाद

एक fallback डिफ़ॉल्ट मान के साथ dynamic parameters वाले string का अनुवाद करें।

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Locales को स्विच करना

एप्लिकेशन को एक अलग locale में स्विच करें।

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### एक Localized Route जनरेट करना

वर्तमान या निर्दिष्ट locale के लिए localized एक route जनरेट करें।

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
