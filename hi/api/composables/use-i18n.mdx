# 🛠️ `useI18n` कंपोज़ेबल

`Nuxt I18n Micro` में `useI18n` कंपोज़ेबल कंपोनेंट्स और स्क्रिप्ट्स में अधिकांश रनटाइम i18n हेल्पर्स तक पहुँच प्रदान करता है। मेथड्स **`$` प्रीफ़िक्स के साथ और बिना** दोनों उपलब्ध हैं (उदाहरण के लिए `$t` और `t`)।

कुछ इंजेक्शन — `$defineI18nRoute` और `$clearCache` — केवल `useNuxtApp()` पर उपलब्ध हैं। देखें [मेथड्स — `$defineI18nRoute`](/api/methods#definei18nroute) और [`$clearCache`](/api/methods#clearcache)।

## 📊 यह क्या लौटाता है

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

एक साधारण ऑब्जेक्ट के रूप में हर रनटाइम हेल्पर।

वे ही फ़ंक्शन जिन्हें प्लगइन `$t`, `$tc` इत्यादि के रूप में इंजेक्ट करता है, डॉलर-प्रीफ़िक्स्ड नाम और बिना प्रीफ़िक्स के उपनाम दोनों के तहत उपलब्ध हैं। इसलिए `const \{ t \} = useI18n()` और
`const \{ $t \} = useI18n()` दोनों काम करते हैं।

**लौटाता है** — [मेथड्स रेफ़रेंस](/api/methods) में वर्णित हेल्पर्स

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

यह जो भी हेल्पर लौटाता है — `$t`, `$tc`, `$has`, `$switchLocale` और अन्य — [मेथड्स रेफ़रेंस](/api/methods) में उनके हस्ताक्षर के साथ सूचीबद्ध और पूरी तरह से डॉक्युमेंटेड हैं।

## केवल `useNuxtApp()` वाले API

ये `useI18n()` द्वारा **नहीं** लौटाए जाते हैं। इन्हें `useNuxtApp()` से इंपोर्ट करें:

| मेथड                       | उद्देश्य                                                                        |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | प्रति-पेज लोकेल रूट्स, प्रतिबंध, और `script setup` में इनलाइन ट्रांसलेशन |
| `$clearCache()`            | इन-मेमोरी ट्रांसलेशन कैश और लोड किए गए चंक्स को साफ़ करता है                            |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

पूर्ण हस्ताक्षर और उदाहरणों के लिए [मेथड्स](/api/methods) देखें।

## 🛠️ उदाहरण उपयोग

### मूल लोकेल पुनर्प्राप्ति

एप्लिकेशन की वर्तमान लोकेल पुनर्प्राप्त करें।

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### पैरामीटर के साथ ट्रांसलेशन

डायनामिक पैरामीटर के साथ एक स्ट्रिंग का ट्रांसलेशन करें, फ़ॉलबैक डिफ़ॉल्ट मान के साथ।

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### लोकेल स्विच करना

एप्लिकेशन को एक अलग लोकेल में स्विच करें।

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### लोकेलाइज़्ड रूट जनरेट करना

वर्तमान या निर्दिष्ट लोकेल में लोकेलाइज़्ड एक रूट जनरेट करें।

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
