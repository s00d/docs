title: "Nuxt I18n Micro"
description: "Nuxt के लिए छोटा, तेज़ i18n: हर पेज के लिए JSON अनुवाद, बिल्ड के समय स्थानीयकृत रूट, और बॉक्स से ही SEO टैग।"
---

Nuxt I18n Micro, Nuxt 3 और 4 के लिए एक हल्का, उच्च-प्रदर्शन वाला i18n मॉड्यूल है, जिसे बड़े प्रोजेक्ट के लिए डिज़ाइन किया गया है। यह `@nuxtjs/i18n` जैसे पारंपरिक i18n समाधानों की तुलना में बिल्ड समय, मेमोरी उपयोग और बंडल आकार को कम रखता है।

स्थानीयकृत रूट बिल्ड के समय `@i18n-micro/route-strategy` द्वारा जनरेट किए जाते हैं और रनटाइम पर `@i18n-micro/path-strategy` द्वारा हल किए जाते हैं, इसलिए लिंक, स्विचर, `hreflang` और रीडायरेक्ट सभी राउटर से मेल खाते हैं। अनुवाद केवल JSON में होते हैं, जो साझा रूट फ़ाइलों और हर पेज की फ़ाइलों में बँटे होते हैं जिन्हें dev सर्वर आपके लिए बनाता है, और HMR अंतर्निहित है।

<CodeGroup>

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>
