## आवश्यकताएँ

- **Node.js**: 18 या नया।
- **Nuxt**: 3.x या 4.x।

मॉड्यूल Nuxt 3 प्रोजेक्ट लेआउट (`pages/**/*.vue`) और Nuxt 4 लेआउट (`app/pages/**/*.vue`) दोनों का समर्थन करता है। परंपरा के अनुसार, Nuxt 4 की `app/` निर्देशिका का उपयोग करते समय भी, ट्रांसलेशन प्रोजेक्ट रूट (`locales/`) पर रहते हैं।

## Nuxt मॉड्यूल इंस्टॉल करें

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

इसे `nuxt.config.ts` में रजिस्टर करें:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

पूर्ण वॉकथ्रू के लिए [क्विकस्टार्ट](/quickstart) देखें या हर विकल्प के लिए [कॉन्फ़िगरेशन रेफ़रेंस](/guides/configuration) देखें।

## प्रोजेक्ट लेआउट

डिफ़ॉल्ट रूप से, मॉड्यूल यह अपेक्षा करता है:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

रूट-लेवल फ़ाइलें बिल्ड समय पर हर पेज-विशिष्ट फ़ाइल में मर्ज हो जाती हैं। `nuxt dev` के दौरान गुम होने पर पेज-विशिष्ट फ़ाइलें स्वचालित रूप से बन जाती हैं।

## Nuxt 4 लेआउट

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

`app/` के अंतर्गत ट्रांसलेशन को कोलोकेट करने के लिए, `translationDir: 'app/locales'` सेट करें।

## TypeScript

मॉड्यूल आपकी डिफ़ॉल्ट लोकेल फ़ाइलों के आधार पर `useI18n`, `$t`, और संबंधित हेल्पर्स के लिए ambient टाइप्स जनरेट करता है। यह डिफ़ॉल्ट रूप से सक्षम है (`types: true`)।

ट्रांसलेशन कुंजियों की मज़बूत टाइपिंग के लिए, [`@i18n-micro/types-generator`](/integrations/types-generator) देखें।
