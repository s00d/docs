## आवश्यकताएँ

- **Node.js**: 18 या नया।
- **Nuxt**: 3.x या 4.x।

मॉड्यूल Nuxt 3 प्रोजेक्ट लेआउट (`pages/**/*.vue`) और Nuxt 4 लेआउट (`app/pages/**/*.vue`) दोनों का समर्थन करता है। परंपरा के अनुसार अनुवाद प्रोजेक्ट रूट (`locales/`) में रहते हैं, भले ही आप Nuxt 4 की `app/` डायरेक्टरी का उपयोग कर रहे हों।

## Nuxt मॉड्यूल इंस्टॉल करें

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

इसे `nuxt.config.ts` में रजिस्टर करें:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

पूर्ण walkthrough के लिए [क्विकस्टार्ट](/quickstart) देखें या हर विकल्प के लिए [कॉन्फ़िगरेशन संदर्भ](/guides/configuration) देखें।

## प्रोजेक्ट लेआउट

डिफ़ॉल्ट रूप से मॉड्यूल यह अपेक्षा करता है:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

रूट-स्तरीय फ़ाइलें बिल्ड-टाइम पर प्रत्येक पेज-विशिष्ट फ़ाइल में मर्ज हो जाती हैं। पेज-विशिष्ट फ़ाइलें `nuxt dev` के दौरान गुम होने पर स्वतः बन जाती हैं।

## Nuxt 4 लेआउट

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

`app/` के अंतर्गत अनुवाद colocate करने के लिए, `translationDir: 'app/locales'` सेट करें।

## TypeScript

मॉड्यूल आपकी डिफ़ॉल्ट लोकेल फ़ाइलों के आधार पर `useI18n`, `$t`, और संबंधित हेल्पर्स के लिए ambient टाइप्स जनरेट करता है। यह डिफ़ॉल्ट रूप से सक्षम है (`types: true`)।

अनुवाद कुंजियों की मज़बूत टाइपिंग के लिए, [`@i18n-micro/types-generator`](/integrations/types-generator) देखें।
