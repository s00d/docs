---

Nuxt I18n Micro 是一个轻量、高性能的 Nuxt 3 和 4 i18n 模块，专为大型项目设计。与 `@nuxtjs/i18n` 等传统 i18n 方案相比，它能保持更低的构建时间、内存占用和包体积。

本地化路由在构建时由 `@i18n-micro/route-strategy` 生成，并在运行时由 `@i18n-micro/path-strategy` 解析，因此链接、切换器、`hreflang` 和重定向都与路由器保持一致。翻译仅支持 JSON，分为共享的根文件和按页面划分的文件，后者由开发服务器自动为你创建，并内置 HMR。

<CodeGroup>

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>
