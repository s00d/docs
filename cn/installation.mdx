## 环境要求

- **Node.js**：18 或更高版本。
- **Nuxt**：3.x 或 4.x。

该模块同时支持 Nuxt 3 的目录布局（`pages/**/*.vue`）和 Nuxt 4 的目录布局（`app/pages/**/*.vue`）。按照约定，翻译文件位于项目根目录下的 `locales/`，即使使用 Nuxt 4 的 `app/` 目录也是如此。

## 安装 Nuxt 模块

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

在 `nuxt.config.ts` 中注册模块：

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

完整流程请参考[快速开始](/quickstart)，所有选项请参考[配置参考](/guides/configuration)。

## 项目布局

模块默认期望的结构：

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

根级文件会在构建时合并进每个页面级文件。缺失的页面级文件会在 `nuxt dev` 期间自动创建。

## Nuxt 4 布局

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

若要将翻译放在 `app/` 目录下，设置 `translationDir: 'app/locales'`。

## 生态包

| 包 | 用途 |
| --- | --- |
| [`@i18n-micro/vue`](/integrations/vue) | Vue 3 集成（不依赖 Nuxt 的独立版本）。 |
| [`@i18n-micro/react`](/integrations/react) | React 集成。 |
| [`@i18n-micro/preact`](/integrations/preact) | Preact 集成。 |
| [`@i18n-micro/solid`](/integrations/solid) | SolidJS 集成。 |
| [`@i18n-micro/astro`](/integrations/astro) | Astro 集成。 |
| [`@i18n-micro/node`](/integrations/nodejs) | Node.js 服务器端加载器。 |
| [`@i18n-micro/types-generator`](/integrations/types-generator) | 基于翻译文件生成 TypeScript 类型。 |
| [`@i18n-micro/devtools-ui`](/integrations/devtools-ui) | 与框架无关的 DevTools 面板。 |

共享的内部包会作为传递依赖被引入。

## TypeScript

该模块会基于你的默认语言文件为 `useI18n`、`$t` 及相关辅助函数生成环境类型。此行为默认开启（`types: true`）。

若需要对翻译键进行更严格的类型检查，请参考 [`@i18n-micro/types-generator`](/integrations/types-generator)。
