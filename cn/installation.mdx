## 环境要求

- **Node.js**:18 或更高版本。
- **Nuxt**:3.x 或 4.x。

该模块同时支持 Nuxt 3 项目布局(`pages/**/*.vue`)和 Nuxt 4 布局(`app/pages/**/*.vue`)。按约定,翻译文件位于项目根目录(`locales/`),即使使用 Nuxt 4 的 `app/` 目录也是如此。

## 安装 Nuxt 模块

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

在 `nuxt.config.ts` 中注册:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

完整的操作流程请参见 [快速开始](/quickstart);所有可用选项请参见 [配置参考](/guides/configuration)。

## 项目结构

默认情况下,模块期望的目录结构如下:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

根级别文件在构建时会合并到每个页面级文件。缺失的页面级文件会在 `nuxt dev` 期间自动创建。

## Nuxt 4 布局

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

若想将翻译文件与 `app/` 目录放在一起,可设置 `translationDir: 'app/locales'`。

## 生态包

| 包 | 用途 |
| --- | --- |
| [`@i18n-micro/vue`](/integrations/vue) | Vue 3 集成(独立使用,不依赖 Nuxt)。 |
| [`@i18n-micro/react`](/integrations/react) | React 集成。 |
| [`@i18n-micro/preact`](/integrations/preact) | Preact 集成。 |
| [`@i18n-micro/solid`](/integrations/solid) | SolidJS 集成。 |
| [`@i18n-micro/astro`](/integrations/astro) | Astro 集成。 |
| [`@i18n-micro/node`](/integrations/nodejs) | Node.js 服务端加载器。 |
| [`@i18n-micro/types-generator`](/integrations/types-generator) | 从翻译文件生成 TypeScript 类型。 |
| [`@i18n-micro/devtools-ui`](/integrations/devtools-ui) | 与框架无关的 DevTools 面板。 |

共享的内部包会作为传递依赖自动引入。

## TypeScript

该模块会基于你的默认语言文件为 `useI18n`、`$t` 及相关辅助方法生成环境类型。此功能默认启用(`types: true`)。

如需对翻译键进行更严格的类型标注,请参见 [`@i18n-micro/types-generator`](/integrations/types-generator)。
