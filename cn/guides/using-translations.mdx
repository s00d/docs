# 在组件中使用翻译

模块安装并配置完成后,你可以在 Vue 模板和脚本中调用 `$t('your_key')` 来显示翻译。

## 1. 根级与页面级翻译文件

1. **根级**翻译直接位于 `/locales` 目录下(例如 `/locales/en.json`、`/locales/fr.json`)。它们会在构建期自动合并到每个页面级文件中,从而在所有页面均可使用。
2. **页面级**翻译位于 `/locales/pages/...` 下,与 Nuxt 的页面目录结构对应:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. 在模板中使用 `$t`

在 `.vue` 文件中可以直接在模板中使用 `$t`:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
如果键指向的是嵌套 JSON 节点(例如 `$t('header')` → `\{ title: "Hi" \}`),`$t` 可能返回**对象**。在模板中会被渲染为 `[object Object]`。若你需要确保得到一个字符串,请使用 `$ts`;或使用更具体的键,如 `$t('header.title')`。详见 [API 参考 —— $t 与 $ts](/api/methods#t)。
</Tip>

## 3. 切换当前语言

若要在应用中切换语言,可以从 `useI18n()` 中获取 `$locale`,并为其赋一个新的语言 code:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. 嵌套键与占位符

- **嵌套键**使用点分记法,例如 `nested.key.deeper`。
- **占位符**可用于插入动态值:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. 小贴士与最佳实践

- **键冲突**:若某个页面级文件包含与根级文件相同的键,则以页面级为准(根级翻译会在构建期作为基础合并进来)。
- **禁用页面级文件**:若不希望使用页面级翻译,可以在 Nuxt 配置中设置 `disablePageLocales: true`。这样只会使用 `/locales/*.json` 文件。
- **无需直接导入**:你无需 `import \{ useI18n \} from 'nuxt-i18n-micro'`;模块的自动注入功能会为你处理好。

到此为止,通过以上步骤你就可以快速地从根级或页面级 JSON 文件中**取回翻译**,并使用 `$t` 在 Nuxt 应用中**展示**。
