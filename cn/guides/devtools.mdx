# 🛠️ `nuxt-i18n-micro` 中的 DevTools

## Vue DevTools（浏览器扩展）

在开发模式下，模块可以通过 `@vue/devtools-api` 注册一个 **Vue DevTools** 自定义 inspector 和 timeline。这与下文的 Nuxt DevTools tab 是两个独立的入口。

| 工具 | 最适合 |
|------|----------|
| **Vue DevTools** | 实时的当前语言、内存中的翻译缓存、`$t` timeline（`debug: true`）、缺失键事件 |
| **Nuxt DevTools tab** | 编辑磁盘上的 JSON 文件、配置概览、导入/导出 |

vue-devtools 插件只在 `nuxt dev` 期间注册（不进入生产构建）。主插件中开发专用的桥接状态会被 `import.meta.dev` 的死代码消除移除。

若想关闭浏览器集成但仍保留 Nuxt tab：

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

详细的 `$t` timeline 事件需要设置 `debug: true`。

## 📖 什么是 Nuxt DevTools？

DevTools 是内建于 `nuxt-i18n-micro` 模块的强大开发助手。它提供直观的界面来管理本地化与翻译任务，让你的工作流更快、更高效。Nuxt DevTools 面向注重便捷的开发者，弥合了编码与运行时管理之间的鸿沟。

## 🌟 `nuxt-i18n-micro` 中 DevTools 的关键特性

### 1. **语言管理**

可以轻松浏览、选择并管理应用中的语言。无论是单一语言还是多语言，DevTools 都为所有本地化设置提供集中式的操作面板。

### 2. **翻译编辑**

通过集成的 JSON 编辑器直接编辑翻译文件。无需外部工具，可实时更新并即时生效，避免打断工作流。

### 3. **文件导入与导出**

简化翻译文件的管理：

- **导出**：将翻译保存为 JSON 文件用于备份或外部使用。
- **导入**：把更新后的翻译文件加载进项目，保持内容最新。

### 4. **实时预览**

在开发环境中即时查看变更效果，确保上线前翻译和配置都是准确的。

### 5. **与 Nuxt 无缝集成**

DevTools 原生适配 `nuxt-i18n-micro`，无需额外配置就能增强其能力。它能贴合你的本地化需求，同时保持 Nuxt 一贯的模块化与灵活性。

## 🛠️ 为什么使用 DevTools？

对于需要本地化的项目而言，Nuxt DevTools 是不可或缺的补充。它帮助开发者：

- **节省时间**：自动完成文件管理、格式校验等重复任务。
- **减少错误**：为翻译编辑提供安全、直观的环境。
- **提升协作**：让非开发人员也能轻松管理翻译。
- **精简流程**：把多种本地化任务整合到一个界面。

## 🚀 掌控你的本地化

有了内嵌在 `nuxt-i18n-micro` 中的 Nuxt DevTools，管理多语言应用会变得直接且高效。无论是微调翻译还是新增语言，DevTools 都为你提供了打造精致、易用体验所需的工具。
