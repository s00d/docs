# 🛠️ `nuxt-i18n-micro` 中的 DevTools

## Vue DevTools(浏览器扩展)

在开发模式下,模块可通过 `@vue/devtools-api` 注册一个 **Vue DevTools** 自定义检查器和时间线。此功能与下面的 Nuxt DevTools 标签相互独立。

| 工具 | 适用场景 |
|------|----------|
| **Vue DevTools** | 实时查看当前语言、内存中的翻译缓存、`$t` 时间线(`debug: true`)、缺失键事件 |
| **Nuxt DevTools 标签** | 编辑磁盘上的 JSON 文件、配置概览、导入/导出 |

vue-devtools 插件仅在 `nuxt dev` 时注册(生产构建不包含)。主插件中仅在开发时使用的桥接状态会被 `import.meta.dev` 的死代码消除移除。

若想关闭浏览器扩展集成但保留 Nuxt 标签:

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

详细的 `$t` 时间线事件需要 `debug: true`。

## 📖 什么是 Nuxt DevTools?

DevTools 是无缝集成到 `nuxt-i18n-micro` 模块中的强大开发助手。它提供了直观的界面来管理本地化与翻译任务,使工作流更快、更高效。Nuxt DevTools 面向注重便捷性的开发者,在编码与运行时管理之间架起了桥梁。

## 🌟 `nuxt-i18n-micro` 中 DevTools 的核心特性

### 1. **语言管理**

轻松浏览、选择并管理应用中的语言。无论是单语言还是多语言,DevTools 都为处理所有本地化设置提供了一个集中的入口。

### 2. **翻译编辑**

通过内置的 JSON 编辑器直接编辑翻译文件。这样无需借助外部工具即可实时更新和修改,不会打断你的工作流。

### 3. **文件导入与导出**

简化翻译文件的管理流程:

- **导出**:将翻译保存为 JSON 文件,用于备份或外部使用。
- **导入**:将更新后的翻译文件加载到项目中,保持内容为最新版本。

### 4. **实时预览**

在开发环境中立即查看变更效果,确保翻译和配置在上线之前准确无误。

### 5. **与 Nuxt 无缝集成**

DevTools 与 `nuxt-i18n-micro` 原生协作,无需额外配置即可增强其能力,同时保持 Nuxt 的模块化与灵活性。

---

## 🛠️ 为什么要使用 DevTools?

Nuxt DevTools 是任何涉及本地化的项目中不可或缺的辅助工具。它可帮助开发者:

- **节省时间**:自动处理诸如文件管理和格式校验等重复任务。
- **减少错误**:在安全、直观的环境中编辑翻译。
- **提升协作**:让非开发人员也能轻松管理翻译。
- **精简工作流**:将多项本地化任务整合到同一个界面中。

## 🚀 掌控本地化

借助集成到 `nuxt-i18n-micro` 中的 Nuxt DevTools,管理多语言应用变得既简单又高效。无论是精调翻译还是新增语言,DevTools 都能为你提供打造精致、友好用户体验所需的工具。
