---

`useI18n()` 以普通对象的形式返回模块的运行时辅助函数。在 `<script setup>`、组合式函数和插件中使用它，而无需借助 `useNuxtApp()`。每个辅助函数都同时以 `$` 名称和不带前缀的别名提供：`t` 和 `$t` 是同一个函数。

## 签名 {#signature}

```ts
useI18n(): PluginsInjectionsWithAliases
```

以普通对象形式提供的所有运行时辅助函数。

与插件以 `$t`、`$tc` 等名称注入的函数相同，既可以通过带美元符号前缀的名称访问，
也可以通过不带前缀的别名访问——因此 `const { t } = useI18n()` 和
`const { $t } = useI18n()` 都可以使用。

**返回值** — [方法参考](/cn/api/methods)中描述的辅助函数

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

返回的对象包含 [`PluginsInjections`](/cn/api/methods) 的所有辅助函数。每个函数都在[辅助函数](/cn/api/methods)页面中有说明。

## 示例 {#example}

```vue
<script setup lang="ts">
const { t, tc, localePath, switchLocale, getLocale } = useI18n()

const title = computed(() => t('page.title'))
</script>

<template>
  <h1>{{ title }}</h1>
  <p>{{ tc('items', 3) }}</p>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
  <button @click="switchLocale(getLocale() === 'en' ? 'de' : 'en')">{{ t('nav.switch') }}</button>
</template>
```

## 不在类型中的内容 {#not-in-the-type}

`$defineI18nRoute` 仅在 `useNuxtApp()` 上有类型定义：

```ts
const { $defineI18nRoute } = useNuxtApp()
```
