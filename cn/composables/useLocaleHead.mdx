---
title: "useLocaleHead"
description: "useLocaleHead 将 i18n SEO 标签（lang、dir、canonical、hreflang、og:locale）构建为一个对象，供你传给 useHead。"
---

`useLocaleHead()` 为当前路由构建 i18n head 标签：`<html>` 上的 `lang` 和 `dir`、canonical 链接、带 `x-default` 的 `hreflang` 备用链接、`og:url`、`og:locale` 和 `og:locale:alternate`。当你设置了 [`meta: false`](/cn/api/module-options#meta) 并自行管理 `useHead` 时使用它；使用 `meta: true` 时，模块已经注册了这些标签，单个页面的修改通过 [`useI18nHead`](/cn/composables/useI18nHead) 完成。

## 签名 {#signature}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { build: () => LocaleHead; metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }, LocaleHead | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

当前路由的 SEO head 标签：每个 locale 的 `hreflang` 备用链接加上
`x-default`、canonical 链接、`og:locale`，以及 `<html>` 上的 `lang`/`dir`。

仅在禁用 `meta` 或需要调整默认值时才需要——使用 `meta: true` 时，
模块会自行注册相同的标签。

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| `options` | `UseLocaleHeadOptions` |  |

**返回值** — `metaObject`，一个保存 head 对象的 ref，可直接传给 `useHead`；`updateMeta` 用于刷新它；`build` 根据当前路由计算 head 对象（在 getter 中读取时具有响应性，例如 `useHead(() => build())`）

```ts
const { metaObject } = useLocaleHead({ addSeoAttributes: true })
useHead(metaObject)
```

## 选项 {#options}

| 选项 | 默认值 | 描述 |
| --- | --- | --- |
| `addDirAttribute` | `true` | 根据 locale 的 `dir` 在 `<html>` 上设置 `dir`（未设置时为 `'auto'`）。 |
| `identifierAttribute` | `'id'` | 作为每个标签键的属性（`i18n-can`、`i18n-og`、`i18n-alternate-<hreflang>`……），使更新时替换标签而不是追加标签。 |
| `addSeoAttributes` | `true` | 输出 canonical、`hreflang` 和 `og:` 标签。设为 `false` 时只保留 `htmlAttrs`。 |
| `baseUrl` | `'/'` | 拼接到每个 URL 前的源地址。保持 `'/'` 以使用相对 URL；传入 `'https://example.com'` 以使用绝对 URL。 |
| `autoUpdate` | `true` | 当路由或 `i18n-locale` 状态变化时重建 `metaObject`。 |

## 输出内容 {#what-it-emits}

- 在没有匹配的路由（404）上，或当前 locale 设置了 `disableMeta` 时，不输出任何内容。
- Canonical 和 `og:url`：`$switchLocalePath(<active locale>)`，查询参数缩减为 [`canonicalQueryWhitelist`](/cn/api/module-options#canonicalquerywhitelist) 中的项，并应用 [`trailingSlash`](/cn/api/module-options#trailingslash)。
- `hreflang`：页面所在的每个已启用 locale 各一个链接，`hreflang = iso || code`，跳过设置了 `seo: false` 的 locale；使用 `hreflangBaseLanguage: true` 时，某种语言的第一个地区性 locale 还会输出其纯语言标签。在 `no_prefix` 下不输出。
- `x-default`：默认 locale 的 URL，除非策略为 `no_prefix`、默认 locale 设置了 `seo: false`，或页面不存在于默认 locale 中。
- `og:locale` / `og:locale:alternate`：来自 locale 的 `og`，或由其 `iso` 转换而来（`en-US` → `en_US`）；两者都不可用时跳过，并给出开发环境警告。

## 示例 {#example}

```ts
// app.vue, with i18n.meta: false
const { metaObject } = useLocaleHead({ baseUrl: 'https://example.com' })
useHead(metaObject)
```

`build()` 返回不带 ref 的相同对象：`useHead(() => build())` 无需 watcher 即可保持响应性。
