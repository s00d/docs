---
title: "useI18nLocale"
description: "useI18nLocale 读取和写入 locale 状态及 locale cookie — 是自定义 locale 检测的入口。"
---

`useI18nLocale()` 用于访问应用所选的 locale：`i18n-locale` 状态和 locale cookie。在自行检测 locale 的插件中（域名、用户资料、请求头）使用它，而不是手动写入 `useState('i18n-locale')` 或 cookie。它的有效性检查使用已启用的 locale，包括运行时覆盖。

## 签名 {#signature}

```ts
useI18nLocale(): { getEffectiveLocale: (route: unknown, getLocaleFromRoute: GetLocaleFromRoute) => string; getLocale: () => string | null; getPreferredLocale: () => string | null; hashCookie: CookieRef; isValidLocale: (locale: string | null | undefined) => locale is string; locale: any; localeCookie: CookieRef; resolveInitialLocale: (options: ResolveInitialLocaleOptions) => string; setLocale: (locale: string | null) => void; syncLocale: (locale: string | null) => void; validLocales: string[] }
```

i18n locale 管理的集中入口。
组合了 useState('i18n-locale')、locale cookie 和同步工具。

## 返回值 {#returned-values}

| 成员 | 类型 | 说明 |
| --- | --- | --- |
| `locale` | `Ref<string \| null>` | `useState('i18n-locale')` ref。 |
| `localeCookie` | `Ref<string \| null>` | [`localeCookie`](/cn/api/module-options#localecookie) cookie；当该选项为 `null` 时，是一个普通的 `{ value: null }`。 |
| `hashCookie` | `Ref<string \| null>` | hash 路由下的 `hash-locale` cookie；否则为 `{ value: null }`。 |
| `validLocales` | `string[]` | 已启用 locale 的代码。 |
| `setLocale(locale)` | `(locale: string \| null) => void` | 写入状态和 cookie。不进行校验，也不加载翻译。 |
| `syncLocale(locale)` | `(locale: string \| null) => void` | 仅写入 cookie。 |
| `getLocale()` | `() => string \| null` | 先取状态，再取偏好 cookie（hash 路由下为 hash cookie）。不进行校验。 |
| `getPreferredLocale()` | `() => string \| null` | 状态和偏好 cookie 中第一个**有效**的值，或 `null`。 |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string` | hash 路由下若已设置则为状态；否则为 `getLocaleFromRoute(route)`。 |
| `resolveInitialLocale(options)` | `(options: ResolveInitialLocaleOptions) => string` | 依次取 `options.urlLocale`、有效的状态、`options.serverLocale`、路由的 locale。当状态无效时将结果存入状态；在客户端还会写入 cookie。 |
| `isValidLocale(locale)` | `(locale) => locale is string` | `locale` 是否在 `validLocales` 中。 |

cookie 的有效期为一年，带有 `path: '/'` 和 `sameSite: 'lax'`。

## 示例 {#example}

```ts
// plugins/locale-from-domain.server.ts
export default defineNuxtPlugin({
  name: 'locale-from-domain',
  enforce: 'pre',
  setup() {
    const { setLocale, isValidLocale } = useI18nLocale()
    const host = useRequestURL().hostname // e.g. de.example.com
    const code = host.split('.')[0]
    if (isValidLocale(code)) setLocale(code)
  },
})
```

模块的加载器插件在启动时读取该状态，因此设置状态的插件必须先运行（`enforce: 'pre'`）。状态如何与 URL、cookie 和 `Accept-Language` 竞争：[Locale 检测](/cn/guide/locale-detection)。完整演练：[自定义检测](/cn/guide/custom-auto-detect)。

`setLocale()` 不会切换屏幕上的翻译。要更改当前页面的 locale，请调用 [`$switchLocale()`](/cn/api/methods#$switchlocale)。
