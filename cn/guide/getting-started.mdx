本页将带你把一个没有 i18n 的 Nuxt 应用变成带有语言切换器的翻译页面。你只需要在项目开始时做一次。最终你将得到本地化的 URL（`/about`、`/de/about`）、每个语言区域和页面对应一个 JSON 文件，以及在模板中可用的 `$t`。

## 安装 {#install}

该模块需要 Nuxt 3.18 或更高版本（Nuxt 4 同样适用）以及 Node 20 或更高版本。

<CodeGroup>

```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>

## 配置语言区域 {#configure-the-locales}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', displayName: 'English' },
      { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
      { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
    ],
    defaultLocale: 'en',
  },
})
```

这就是第一个应用所需的全部配置。默认值为你提供：

- `strategy: 'prefix_except_default'`：默认语言区域没有前缀（`/about`），其他语言区域有前缀（`/de/about`）。参见[路由策略](/cn/guide/strategy)。
- `translationDir: 'locales'`：翻译文件位于项目根目录的 `locales/` 中，使用 Nuxt 4 的 `app/` 目录结构时也是如此。
- `meta: true`：生成 `hreflang`、canonical 和 `og:locale` 标签，并在 `<html>` 上设置 `lang` 和 `dir`。参见 [SEO](/cn/guide/seo)。
- 打开 `/` 的访问者会被引导到其浏览器请求的语言（`Accept-Language`）。参见[语言区域检测](/cn/guide/locale-detection)。

`iso` 是 SEO 标签中使用的语言标记；`code` 是出现在 URL 中的内容。所有选项都列在[模块选项](/cn/api/module-options)中。

## 添加翻译文件 {#add-translation-files}

使用 `nuxt dev` 启动开发服务器。当 Nuxt 解析页面时，模块会为每个尚无文件的语言区域和页面创建一个空的 `{}` 文件（可通过 [`disableWatcher`](/cn/api/module-options#disablewatcher) 关闭此行为）：

```text
locales/
├── en.json            # root: keys every page can use
├── de.json
├── fr.json
└── pages/
    ├── index/         # pages/index.vue
    │   ├── en.json
    │   ├── de.json
    │   └── fr.json
    └── about/         # pages/about.vue
        ├── en.json
        ├── de.json
        └── fr.json
```

填写根文件和一个页面文件：

```json
// locales/en.json
{ "nav": { "home": "Home", "about": "About" } }
```

```json
// locales/pages/index/en.json
{ "welcome": "Welcome, {name}!", "items": "no items | one item | {count} items" }
```

页面可以看到根文件中的键和它自己的键；发生冲突时以页面自己的文件为准。文件夹名称遵循路由名称（`pages/articles/[id].vue` 对应 `locales/pages/articles-id/`）。[翻译文件](/cn/guide/translations)介绍了目录结构、回退和加载。

## 在页面中使用 `$t` {#use-$t-on-a-page}

```vue
<!-- pages/index.vue -->
<script setup lang="ts">
const { t, tc, getLocale } = useI18n()

const title = t('nav.home') // 'Home'
</script>

<template>
  <h1>{{ $t('welcome', { name: 'Ada' }) }}</h1>
  <!-- Welcome, Ada! -->
  <p>{{ $tc('items', 3) }}</p>
  <!-- 3 items -->
  <p>{{ getLocale() }}</p>
  <!-- en -->
</template>
```

- 在模板中，每个辅助方法都可以带 `$` 前缀使用（`$t`、`$tc`、`$localePath`……）。
- 在 `<script setup>` 中，`useI18n()` 返回相同的辅助方法，带或不带 `$` 均可（`t` 和 `$t` 是同一个函数）。它会被自动导入。
- `{name}` 占位符由参数对象填充。复数形式用 `|` 分隔；由计数选择形式（0、1，以及超出部分全部使用最后一种）。

所有辅助方法都列在[方法](/cn/api/methods)中。

## 页面间链接与切换语言区域 {#link-between-pages-and-switch-locale}

```vue
<!-- components/AppHeader.vue -->
<template>
  <nav>
    <i18n-link :to="{ name: 'index' }">{{ $t('nav.home') }}</i18n-link>
    <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
    <i18n-switcher />
  </nav>
</template>
```

- [`<i18n-link>`](/cn/components/i18n-link) 是一个指向当前语言区域页面的 `NuxtLink`：在 `/de` 上，about 链接会指向 `/de/about`。
- [`<i18n-switcher>`](/cn/components/i18n-switcher) 是一个列出已启用语言区域的下拉菜单；它会让访问者停留在同一页面。
- 对于你自己的按钮，请调用 `$switchLocale('de')`，它会导航到当前页面的德语版本并记住该选择。对于普通的 `NuxtLink`，请使用 `$localePath({ name: 'about' })` 或 `$switchLocalePath('de')`。

## 检查效果 {#check-it}

运行 `nuxt dev` 并打开：

| URL | 显示内容 |
| --- | --- |
| `/` | 英语首页（如果浏览器偏好德语，则重定向到 `/de`） |
| `/de` | 德语首页 |
| `/de/about` | 德语 about 页面 |
| `/en/about` | 404：在 `prefix_except_default` 下默认语言区域没有前缀 |

对 JSON 文件的修改会直接应用到已打开的页面，无需重新加载。
