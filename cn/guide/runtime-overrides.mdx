---
title: "运行时覆盖"
description: "通过环境变量或 runtimeConfig，为同一构建产物的每个实例修改默认 locale、回退 locale 或禁用的 locale。"
---

运行时覆盖让同一个构建产物无需重新构建，就能在不同环境或租户中使用不同的 locale 设置运行。你可以修改默认 locale、回退 locale 以及哪些 locale 被禁用。路由、重定向、渲染和服务端辅助函数都会使用覆盖后的值，服务端渲染页面上的浏览器端也一样。

## 使用环境变量设置覆盖 {#set-overrides-with-environment-variables}

```bash
NUXT_I18N_DEFAULT_LOCALE=de \
NUXT_I18N_FALLBACK_LOCALE=en \
NUXT_I18N_DISABLED_LOCALES=fr,it \
node .output/server/index.mjs
```

| 变量 | 别名 |
| --- | --- |
| `NUXT_I18N_DEFAULT_LOCALE` | `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE` |
| `NUXT_I18N_FALLBACK_LOCALE` | `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE` |
| `NUXT_I18N_DISABLED_LOCALES`（逗号分隔） | `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES` |

服务器在启动时读取一次这些变量；修改后需要重启才能生效。在服务端渲染的页面上，浏览器会从服务器获取解析后的值。当 `ssr: false` 时没有服务端渲染，而浏览器没有环境变量：此时只有 `runtimeConfig.public.i18nRuntime` 生效，并且浏览器会输出下面列出的警告。

## 在 runtimeConfig 中设置覆盖 {#set-overrides-in-runtimeconfig}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

对于同一字段，`runtimeConfig.public.i18nRuntime` 中设置的值优先于 `NUXT_I18N_*` 变量。

不要与构建时的 `DEFAULT_LOCALE` 变量混淆，后者在构建时替换 `defaultLocale`，不需要运行时支持。

## 哪些可以改变，哪些不能 {#what-can-and-cannot-change}

| 设置 | 运行时 |
| --- | --- |
| `defaultLocale` | 在 `prefix` 和 `no_prefix` 下可以。在 `prefix_except_default` 和 `prefix_and_default` 下它在构建时固定（其页面就是无前缀的路由）；覆盖会被忽略并输出警告。 |
| `fallbackLocale` | 可以。 |
| `disabledLocales` | 在构建时禁用的 locale 基础上追加；永远不会重新启用某个 locale。在 `prefix_except_default` / `prefix_and_default` 下无法禁用构建时的默认 locale。 |
| `strategy` | 不可以。运行时策略会被忽略并输出警告；请为每种策略分别构建一个产物。 |

无效的值永远不会导致应用崩溃。每种情况在每个服务器进程中只输出一次警告：

- 禁用所有 locale 会被忽略；
- 未启用的 `defaultLocale` 会回退到第一个已启用的 locale；
- 未启用的 `fallbackLocale` 会在构建值已启用时保留构建值，否则不使用回退。

## 读取实际生效的配置 {#read-the-effective-config}

```vue
<script setup lang="ts">
const { $getI18nConfig } = useNuxtApp()
const config = $getI18nConfig() // build config with overrides applied
</script>
```

请将其视为只读：在服务端它由所有请求共享，并且在开发环境中被冻结；浏览器端的副本不会被冻结。从 `#build/i18n.strategy.mjs` 导入配置得到的是未应用覆盖的构建值。

## 禁用的 locale 与静态文件 {#disabled-locales-and-static-files}

在运行时被禁用的 locale 会在其路由和 payload 路由上返回 404，但它的 payload 文件仍然位于 `.output/public/_locales/` 中，静态文件服务器仍会返回它们。如果这些文件必须不可访问，请在构建时使用 `disabled: true` 禁用该 locale。
