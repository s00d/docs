---
title: "包 API"
description: "每个 @i18n-micro/* 包导出的 API，根据 CI 对照源码检查的 API 快照生成。"
---

Nuxt 模块由一系列小型 `@i18n-micro/*` 包构建而成，其中大多数可以独立使用：`@i18n-micro/vue` 可用于 Vue 应用，`@i18n-micro/core` 可用于任何环境。通过这些页面，你可以按入口点查阅每个包导出的内容。每个页面都根据 [`pnpm run api:surface`](https://s00d.github.io/nuxt-i18n-micro/contributing/maintenance-commands#api-surface) 对照 TypeScript 源码检查的快照生成，因此任何导出的变更都会被 CI 发现。
