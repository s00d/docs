# 包 API

`nuxt-i18n-micro` 由一组小型包组成,其中大部分都可独立使用——例如
`@i18n-micro/vue` 可用于纯 Vue 应用,`@i18n-micro/core` 则可以在任何地方使用。

下面每个页面都由 API 快照生成,
[`pnpm run api:surface`](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/maintenance-commands.md#api-surface) 会用它与
TypeScript 源代码进行比对,因此导出的 API 若发生消失,要么这里的参考需要相应更新,
要么 CI 就会失败。
