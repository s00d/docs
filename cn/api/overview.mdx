## 服务端中间件

服务端处理函数使用专门的中间件(而非客户端的 `$t` 辅助方法):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) —— 在 API 路由和服务端处理函数中进行翻译
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) —— 读取检测到的语言及其元数据

完整的配置流程、语言检测优先级和示例请参见 [服务端翻译指南](/guides/server-side-translations)。
