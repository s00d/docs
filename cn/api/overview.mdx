本节列出了 Nuxt 模块的所有选项、辅助函数、钩子、组合式函数和组件，以及每个 `@i18n-micro/*` 包导出的 API。可用它查阅签名或默认值；[指南](/cn/guide/getting-started)则说明了如何使用它们。这里的大多数表格都由源代码生成，因此与代码保持一致。

## Nuxt 模块 {#nuxt-module}

| 页面 | 内容 |
| --- | --- |
| [模块选项](/cn/api/module-options) | `nuxt.config` 中每个 `i18n` 键及其类型和默认值 |
| [辅助函数](/cn/api/methods) | `$t`、`$tc`、`$tn`、`$td`、`$localePath`、`$switchLocale`、`$defineI18nRoute` 等 |
| [钩子](/cn/api/events) | `i18n:register` 运行时钩子 |

## 组合式函数 {#composables}

| 组合式函数 | 用途 |
| --- | --- |
| [`useI18n`](/cn/composables/useI18n) | 在 `<script setup>` 中使用辅助函数 |
| [`useI18nLocale`](/cn/composables/useI18nLocale) | 在自定义检测插件中使用 locale 状态和 cookie |
| [`useI18nHead`](/cn/composables/useI18nHead) | 按页面覆盖生成的 SEO 标签 |
| [`useLocaleHead`](/cn/composables/useLocaleHead) | 以对象形式获取 SEO 标签，供你自己的 `useHead` 使用 |

## 组件 {#components}

| 组件 | 渲染内容 |
| --- | --- |
| [`<i18n-t>`](/cn/components/i18n-t) | 单条翻译，支持复数、格式化和插槽插值 |
| [`<i18n-link>`](/cn/components/i18n-link) | 指向本地化路由的 `NuxtLink` |
| [`<i18n-switcher>`](/cn/components/i18n-switcher) | locale 下拉菜单 |
| [`<i18n-group>`](/cn/components/i18n-group) | 共享键前缀的区块 |

## 服务端 {#server}

Nitro 处理器使用 `useTranslationServerMiddleware` 和 `useLocaleServerMiddleware`，而不是客户端辅助函数。参见[服务端路由](/cn/guide/server-side-translations)。

## 包 {#packages}

[包 API](/cn/api/packages/overview) 列出了每个 `@i18n-micro/*` 包的导出内容，每个包对应一个生成的页面。
