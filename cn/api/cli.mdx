## 通用标志 {#common-flags}

| 标志 | 默认值 | 说明 |
| --- | --- | --- |
| `--cwd` | 当前目录 | 项目目录 |
| `--logLevel` | `info` | 输出级别：silent、info |
| `--debug` | `false` | 命令失败时打印堆栈跟踪 |

## 检查 {#inspect}

### `info` {#info}

打印项目解析后的 i18n 配置

| 标志 | 默认值 | 说明 |
| --- | --- | --- |
| `--json` | `false` | 输出 JSON 而不是文本 |

### `check` {#check}

CI 关卡：在出现缺失、空、多余、未定义或未使用的键以及损坏的占位符时失败

| 标志 | 默认值 | 说明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config 中的 `i18n.translationDir` | 翻译目录，相对于项目 |
| `--only` | 除 duplicates 外的全部 | 要运行的检查，以逗号分隔：missing、empty、extra、placeholders、undefined、unused、duplicates。在此处指定的 `unused` 无法运行时会失败 |
| `--duplicates` | `false` | 同时报告不同键下的相同文本 |
| `--ignore` | — | 要跳过的源文件 glob，以逗号分隔，相对于项目 |
| `--json` | `false` | 输出 JSON 而不是文本 |

```bash
i18n-micro check
i18n-micro check --only missing,placeholders --json
```

### `stats` {#stats}

显示每个 locale 的翻译完成度

| 标志 | 默认值 | 说明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config 中的 `i18n.translationDir` | 翻译目录，相对于项目 |
| `--html` | — | 同时将 HTML 报告写入此文件 |
| `--json` | `false` | 输出 JSON 而不是文本 |
| `--baseRef` | — | 用于比较完成度的 Git ref，例如 HEAD~1 或 main |

```bash
i18n-micro stats --baseRef main
i18n-micro stats --html reports/i18n.html
```

### `lint` {#lint}

检查翻译文本；仍有问题时失败

| 标志 | 默认值 | 说明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config 中的 `i18n.translationDir` | 翻译目录，相对于项目 |
| `--rules` | 全部，或 .i18n-lintrc.json 中的 `enabledRules` | 要运行的规则，以逗号分隔：no-trailing-spaces、no-multiple-spaces、no-empty-translation，或自定义规则 |
| `--fix` | `false` | 修复可修复的问题：空格，以及带替换内容的自定义规则 |
| `--json` | `false` | 输出 JSON 而不是文本 |

```bash
i18n-micro lint --rules no-trailing-spaces --fix
```

### `search` {#search}

搜索键和值，并显示每个键的使用位置

| 标志 | 默认值 | 说明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config 中的 `i18n.translationDir` | 翻译目录，相对于项目 |
| `<query>` | — | 要搜索的文本或键 |
| `--caseSensitive` | `false` | 区分大小写 |
| `--onlyUnused` | `false` | 仅显示 `clean` 会删除的键；此时查询变为可选 |
| `--scope` | `all` | 搜索范围：global、pages、all |
| `--limit` | — | 最多返回这么多个键 |
| `--ignore` | — | 要跳过的源文件 glob，以逗号分隔，相对于项目 |
| `--json` | `false` | 输出 JSON 而不是文本 |

```bash
i18n-micro search "Welcome"
i18n-micro search --onlyUnused
```

## 翻译工作流程 {#translation-workflow}

### `extract` {#extract}

列出源文件中使用但尚无文本的键，并将带有默认文本的键添加到默认 locale

| 标志 | 默认值 | 说明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config 中的 `i18n.translationDir` | 翻译目录，相对于项目 |
| `--ignore` | — | 要跳过的源文件 glob，以逗号分隔，相对于项目 |

```bash
i18n-micro extract
```

### `translate` {#translate}

通过翻译服务，从默认 locale 补全缺失的翻译

| 标志 | 默认值 | 说明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config 中的 `i18n.translationDir` | 翻译目录，相对于项目 |
| `--service` | — | 翻译服务：ai、azure、deepl、google、libretranslate、yandexcloud |
| `--token` | — | API 密钥。建议使用 I18N_TRANSLATE_TOKEN 环境变量：标志会留在 shell 历史中 |
| `--options` | — | 服务选项，以 key:value 对表示，用逗号分隔 |
| `--locale` | 除默认 locale 外的所有 locale | 要补全的 locale，以逗号分隔 |
| `--replace` | `false` | 重新翻译每个键，替换已有的值 |
| `--dryRun` | `false` | 统计每个 locale 的键数和字符数；不发送任何内容 |
| `--chunkSize` | — | 每个请求的字符串数；上限为服务所接受的数量 |
| `--pluralSeparator` | `\|` | 消息中复数形式的分隔符 |
| `--glossaryFile` | 存在时为 `.i18n-glossary.json` | 术语表文件，由 `ai` 服务使用 |

```bash
i18n-micro translate --dryRun
I18N_TRANSLATE_TOKEN=... i18n-micro translate --service deepl --locale de,fr
i18n-micro translate --service ai --options provider:openai,model:gpt-4o-mini
i18n-micro translate --service libretranslate --options baseUrl:https://translate.example.com
```

### `sync` {#sync}

删除默认 locale 中没有的键；无法证明安全时停止。缺失的键仍保持缺失

| 标志 | 默认值 | 说明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config 中的 `i18n.translationDir` | 翻译目录，相对于项目 |
| `--ignore` | — | 要跳过的源文件 glob，以逗号分隔，相对于项目 |
| `--dryRun` | `false` | 列出将被删除的内容；不写入任何内容 |
| `--force` | `false` | 即使无法证明安全也删除键 |

```bash
i18n-micro sync --dryRun
```

### `clean` {#clean}

删除项目中没有任何地方使用的键；无法证明时停止

| 标志 | 默认值 | 说明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config 中的 `i18n.translationDir` | 翻译目录，相对于项目 |
| `--include` | — | 正则表达式：仅考虑删除匹配的键 |
| `--exclude` | — | 正则表达式：永不删除匹配的键 |
| `--ignore` | — | 要跳过的源文件 glob，以逗号分隔，相对于项目 |
| `--dryRun` | `false` | 列出将被删除的内容；不写入任何内容 |
| `--force` | `false` | 即使无法证明所有键的使用情况也删除键 |

```bash
i18n-micro clean --dryRun
i18n-micro clean --exclude '^errors\.'
```

## 重构 {#refactoring}

### `text-to-i18n` {#text-to-i18n}

将 Vue 模板中的硬编码文本替换为翻译调用，并报告代码中的硬编码文本

| 标志 | 默认值 | 说明 |
| --- | --- | --- |
| `--translationFile` | `<translationDir>/<defaultLocale>.json` | 新键写入的文件 |
| `--path` | 整个项目 | 要处理的文件或目录 |
| `--context` | — | 生成的键的前缀 |
| `--ignore` | — | 要跳过的源文件 glob，以逗号分隔，相对于项目 |
| `--dryRun` | `false` | 显示将要发生的更改；不写入任何内容 |
| `--interactive` | `false` | 逐个确认或编辑生成的键 |

```bash
i18n-micro text-to-i18n --dryRun
i18n-micro text-to-i18n --path components --context ui
```

### `rename` {#rename}

在所有 locale 和源文件中重命名键或命名空间

| 标志 | 默认值 | 说明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config 中的 `i18n.translationDir` | 翻译目录，相对于项目 |
| `--from` **\*** | — | 当前的键或命名空间 |
| `--to` **\*** | — | 新的键或命名空间 |
| `--ignore` | — | 要跳过的源文件 glob，以逗号分隔，相对于项目 |
| `--dryRun` | `false` | 报告更改；不写入任何内容 |

**\*** 必填。

```bash
i18n-micro rename --from common.save --to actions.save
```

### `pseudo` {#pseudo}

用伪翻译填充某个 locale，以发现布局和硬编码文本问题

| 标志 | 默认值 | 说明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config 中的 `i18n.translationDir` | 翻译目录，相对于项目 |
| `--sourceLocale` | 默认 locale | 要读取的 locale |
| `--targetLocale` **\*** | — | 要填充的 locale |
| `--replace` | `false` | 覆盖已有的值 |

**\*** 必填。

### `format` {#format}

以排序后的键和统一的缩进重写 locale 文件

| 标志 | 默认值 | 说明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config 中的 `i18n.translationDir` | 翻译目录，相对于项目 |
| `--indent` | `2` | 缩进空格数 |
| `--sortKeys` | `true` | 对键排序；使用 --no-sortKeys 保留原有顺序 |
| `--check` | `false` | 如果文件会被更改则失败；不写入任何内容 |

```bash
i18n-micro format --check
```

## 交换 {#exchange}

### `export` {#export}

将 locale 文件导出为 PO 或 CSV，以默认 locale 的文本作为源文本

| 标志 | 默认值 | 说明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config 中的 `i18n.translationDir` | 翻译目录，相对于项目 |
| `--format` | `po` | 文件格式：po、csv |
| `--dir` | po 为 `pots`，csv 为 `csv_exports` | 输出目录，相对于项目 |
| `--force` | `false` | 覆盖自上次导出后被更改且从未导入的文件 |

```bash
i18n-micro export --format csv
```

### `import` {#import}

将 PO 或 CSV 文件合并到 locale 文件中

| 标志 | 默认值 | 说明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config 中的 `i18n.translationDir` | 翻译目录，相对于项目 |
| `--format` | `po` | 文件格式：po、csv |
| `--dir` | po 为 `pots`，csv 为 `csv_exports` | 输入目录，相对于项目 |
| `--dryRun` | `false` | 报告将要导入的内容；不写入任何内容 |

```bash
i18n-micro import --format csv --dryRun
```

### `sync-remote` {#sync-remote}

从 .i18n-remote.json 中的 HTTP 端点拉取全局翻译，或将其推送到该端点

| 标志 | 默认值 | 说明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config 中的 `i18n.translationDir` | 翻译目录，相对于项目 |
| `--pull` | `true` | 从远端拉取 |
| `--push` | `false` | 推送到远端 |
| `--force` | `false` | 拉取时采用远端的值；推送时覆盖仅存在于远端的文本 |
| `--dryRun` | `false` | 报告拉取将带来的更改；不写入也不推送任何内容 |

```bash
i18n-micro sync-remote --dryRun
i18n-micro sync-remote --no-pull --push
```

## Lint 规则 {#lint-rules}

| 规则 | 检测内容 | 可由 `--fix` 修复 |
| --- | --- | --- |
| `no-trailing-spaces` | 值或行末尾的空格 | 是 |
| `no-multiple-spaces` | 连续两个或更多空格 | 是 |
| `no-empty-translation` | 空值或仅含空白的值 | 否 |

## 退出码 {#exit-codes}

| 代码 | 含义 |
| --- | --- |
| `0` | 完成，没有需要报告的内容 |
| `1` | 有发现：`check`、`lint` 或 `format --check` 发现了问题，`clean` 或 `sync` 无法证明删除是安全的，`export` 将覆盖未导入的工作，`translate` 遗漏了键，`import` 或 `sync-remote` 遇到冲突，`sync-remote` 推送将丢弃远端文本。`clean`、`sync` 或 `sync-remote` 拉取的 `--dryRun` 会报告这些情况并以 `0` 退出 |
| `2` | 失败：用法错误、项目无法读取、网络或文件错误 |

## 配置文件 {#configuration-files}

| 文件 | 使用者 |
| --- | --- |
| `.i18n-lintrc.json` | `lint`：`enabledRules`、`disabledRules`、`customRegexRules`（`name`、`pattern`、`flags`、`description`、`replacement`） |
| `.i18n-remote.json` | `sync-remote`：`url`、`path`、`token`、`auth`（`username`、`password`）。`type` 可以省略；只有 `custom` 一种 |
| `.i18n-glossary.json` | `translate --service ai`：由 `source`、`target` 以及可选的 `from`、`to` 组成的 `entries` |

## 环境变量 {#environment-variables}

| 名称 | 用途 |
| --- | --- |
| `I18N_TRANSLATE_TOKEN` | `translate` 的 API 密钥。也会从 `.env` 读取 |
| `I18N_REMOTE_TOKEN` | `sync-remote` 的 Bearer 令牌。也会从 `.env` 读取 |
| `AI_GATEWAY_API_KEY, OPENAI_API_KEY, ANTHROPIC_API_KEY` | 未设置 `I18N_TRANSLATE_TOKEN` 时 `ai` 服务的密钥 |
| `DEFAULT_LOCALE` | 覆盖 `defaultLocale`，与模块中的行为相同 |
