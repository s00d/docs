# 🛠️ `useI18n` Composable

`Nuxt I18n Micro` 中的 `useI18n` composable 可让组件和脚本访问大多数运行时 i18n 辅助方法。这些方法**同时提供带 `$` 前缀和不带前缀的版本**(例如 `$t` 和 `t`)。

有些注入项——`$defineI18nRoute` 和 `$clearCache`——只能通过 `useNuxtApp()` 访问。请参见 [方法参考 —— `$defineI18nRoute`](/api/methods#definei18nroute) 与 [`$clearCache`](/api/methods#clearcache)。

## 📊 返回值

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

以纯对象形式返回所有运行时辅助方法。

这些函数与插件注入的 `$t`、`$tc` 等相同,同时以带 `$` 前缀的名称和不带前缀的别名两种形式提供——因此 `const \{ t \} = useI18n()` 和
`const \{ $t \} = useI18n()` 均可使用。

**返回** —— [方法参考](/api/methods) 中描述的所有辅助方法

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

它返回的每个辅助方法——`$t`、`$tc`、`$has`、`$switchLocale` 以及其他——都在 [方法参考](/api/methods) 中列出了签名并有完整文档。

## 仅通过 `useNuxtApp()` 使用的 API

以下方法**不会**由 `useI18n()` 返回,请从 `useNuxtApp()` 导入:

| 方法                     | 用途                                                                         |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | 在 `script setup` 中定义每个页面的语言路由、限制以及内联翻译 |
| `$clearCache()`            | 清除内存中的翻译缓存和已加载的分片                            |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

完整签名和示例请参见 [方法](/api/methods)。

## 🛠️ 示例用法

### 基本的语言获取

获取应用的当前语言。

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### 带参数的翻译

翻译一个带有动态参数并附带默认回退值的字符串。

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### 切换语言

将应用切换到另一种语言。

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### 生成本地化路由

生成一个针对当前或指定语言的本地化路由。

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
