# 🌍 `useLocaleHead` Composable

`useLocaleHead` 是 `Nuxt I18n Micro` 提供的工具型 composable,可帮助你为本地化路由管理 SEO 属性和 HTML meta 标签。它会动态生成 HTML 文档的 `lang` 与 `dir` 属性,并创建 `meta` 和 `link` 标签以提升本地化内容的 SEO 效果。

## 🛠️ 返回值

`useLocaleHead` 返回一个响应式对象和一个更新函数,当源数据发生变化时应主动调用。二者的形状均已在上面的签名中列出,该签名由源代码生成。

### `metaObject`

响应式的 head 载荷(html 属性、meta、link),可直接用于 `useHead(metaObject)`。

- **示例**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

根据当前路由、语言和配置重新计算 `metaObject`。当输入变化时(例如路由变化)应调用它。

- **示例**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### 访问 `link` 与 `meta`

`link` 和 `meta` 数组可通过 `metaObject.value` 获取:

- **示例**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ 示例用法

### 基本用法

使用默认选项生成语言相关的 head 属性。

```js
const head = useLocaleHead()
```

### 自定义标识属性

为生成的标签使用自定义的标识属性。

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### 禁用 SEO 属性

生成不带 SEO 相关 meta 和 link 标签的 head 属性。

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### 指定基础 URL

为 canonical 和 alternate URL 设置自定义的基础 URL。

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 其他功能

### SEO Meta 与 Link 标签

启用 `addSeoAttributes` 时,该 composable 会自动生成以下标签:

- 当前语言的 `og:locale`(格式为 `language_TERRITORY`,使用下划线)。取自 `locale.og`,或在可能时从 `locale.iso` 转换而来。
- 页面 canonical URL 对应的 `og:url`。
- 各语言备选版本的 `og:locale:alternate`。
- 用于 SEO 优化的 `rel="canonical"` 和 `rel="alternate"` 链接。
- 指向默认语言 URL 的 `hreflang="x-default"` 链接。这会告知搜索引擎:当用户的语言不匹配任何已定义的语言时,应展示哪个 URL。

### 动态 lang 与 dir

该 composable 会根据当前路由的语言动态确定 `lang` 与 `dir` 属性,以确保 HTML 文档对国际化用户的正确显示。

### 处理本地化路由

若你的路由以语言 code 作为前缀(例如 `/en/about`),该 composable 会智能地调整完整路径以生成 URL,从而确保 SEO 属性准确且相关。

它极大简化了将 Nuxt 应用面向国际化受众进行优化的过程,让你的站点能更好地面向全球搜索引擎和用户。

## 🛠️ 示例用法

以下示例展示了如何在 Vue 组件中以默认设置使用 `useLocaleHead` composable:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### 代码说明

- **`useLocaleHead` Composable**:在 `<script setup>` 中调用,返回包含 `htmlAttrs`、`meta` 与 `link` 的对象。

- **`<html>` 标签**:HTML 文档的 `lang` 和 `dir` 属性会根据当前语言动态确定,并应用到 `<html>` 标签上。

- **`<head>` 部分**:
  - **Meta 标签**:生成 SEO 相关的 meta 标签,包括 `og:locale`、`og:url`,以及用于指定备选语言版本的 `rel="canonical"` 和 `rel="alternate"` 标签。
  - **Link 标签**:包含 canonical 链接、备选语言版本链接,以及指向默认语言 URL 的 `hreflang="x-default"` 链接。

- **`<body>` 部分**:此处展示页面主体内容。示例中使用了一个简单的标题和段落。

### 📝 备注

1. **属性**:所用到的属性(`lang`、`dir`、`rel`、`href`、`hreflang`、`property`、`content`)均来自 `useLocaleHead` 返回的对象。

2. **SEO 标签生成**:若 `addSeoAttributes` 设为 `true`,该 composable 会自动为当前语言生成 SEO 标签。

3. **基础 URL**:可通过 `baseUrl` 选项设置自定义的基础 URL,以正确生成 canonical 与 alternate 链接。

该示例展示了如何轻松地将 `useLocaleHead` 集成到应用组件中,确保 SEO 属性正确并提升本地化页面的搜索引擎索引效果。

## 🧩 定制与生命周期

- `useLocaleHead` 自身并不会订阅任何变化。它返回 `metaObject` 和 `updateMeta`。
- 你应在输入变化时(通常是在路由变化时)调用 `updateMeta()`,例如从一个插件中调用:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## 何时改用 `useI18nHead`

当 `meta: true`(默认)时,推荐使用 [`useI18nHead`](/api/composables/use-i18n-head) 进行**页面级**覆盖(自定义 hreflang、额外的 `og:title`、部分禁用等)。仅在 `meta: false` 或你自行管理 `useHead` 时才直接使用 `useLocaleHead`。
