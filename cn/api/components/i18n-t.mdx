# 🌍 `<i18n-t>` 组件

`Nuxt I18n Micro` 中的 `<i18n-t>` 组件是一个灵活的翻译组件,支持通过插槽插入动态内容。你可以在翻译中插值自定义的 Vue 组件或 HTML 内容,以实现更高级的本地化场景。

## ⚙️ 属性

{/* generated:component:i18n-t — do not edit; run `pnpm run docs:generate` */}

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `keypath` **\*** | `string` | — | 要渲染的翻译键。 |
| `plural` | `number \| string` | — | 用于选择复数形式的数量。设置后会使用 `$tc` 而非 `$t`。 |
| `tag` | `string` | `'span'` | 要渲染的元素。 |
| `params` | `Record<string, string \| number \| boolean>` | `() => (\{\})` | 用于替换到翻译中的插值。 |
| `defaultValue` | `string` | `''` | 当 `hideIfEmpty` 抑制空翻译时,替代组件渲染的内容。 |
| `html` | `boolean` | `false` | 将翻译作为 HTML 而非纯文本渲染。仅用于你自己控制的内容。 |
| `hideIfEmpty` | `boolean` | `false` | 当翻译解析为空字符串时不渲染任何内容。 |
| `customPluralRule` | `PluralFunc` | `null` | 仅用于此元素的复数规则,会覆盖已配置的规则。 |
| `number` | `number \| string` | — | 使用 `$tn` 格式化数值,并作为 `\{number\}` 传入翻译。 |
| `date` | `Date \| string \| number` | — | 使用 `$td` 格式化日期,并作为 `\{date\}` 传入翻译。 |
| `relativeDate` | `Date \| string \| number` | — | 使用 `$tdr` 格式化相对日期,并作为 `\{relativeDate\}` 传入翻译。 |

**\*** 必填。

{/* /generated:component:i18n-t */}

`plural`、`number`、`date` 和 `relativeDate` 一次只能生效一个;若同时设置多个,以上述顺序中排在最前的为准。

### 各属性示例

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

## 🛠️ 示例用法

### 基本用法

```vue
<i18n-t keypath="feedback.text" />
```

这会将 `feedback.text` 的翻译渲染在一个 `<span>` 标签内。

### 使用插槽插入动态内容

`<i18n-t>` 组件支持通过插槽,将 Vue 组件或其他内容动态插入到翻译的特定位置。

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

在此示例中,`feedback.text` 翻译字符串中的 `\{link\}` 占位符会被替换为 `<nuxt-link>` 组件,而该组件本身又包含另一个翻译组件。

### 复数

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

这会根据 `itemCount` 的值自动应用复数规则。

## 🚀 其他功能

### 默认插槽

若未提供特定的插槽,可通过默认插槽自定义翻译,插槽会将完整的翻译字符串作为参数传入:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### 条件渲染

使用 `hideIfEmpty` 属性,可在翻译字符串为空时不渲染任何内容。

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### 自定义复数规则

使用自定义函数处理复数逻辑。

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### 使用插槽的高级示例

利用插槽自定义翻译内容的渲染方式。

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
