# 🌍 `<i18n-link>` 组件

`Nuxt I18n Micro` 中的 `<i18n-link>` 组件是一个通用的链接组件,能够根据当前语言自动本地化路由。它是 `<NuxtLink>` 组件的封装,并提供了活动链接样式和外部链接支持等额外功能。

## ⚙️ 属性

{/* generated:component:i18n-link — do not edit; run `pnpm run docs:generate` */}

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | 目标路由。自动本地化;外部 URL 会原样传递。 |
| `activeStyle` | `Partial<CSSStyleValue>` | — | 当链接指向当前路由时应用的内联样式。 |

**\*** 必填。

### 插槽

| 插槽 | 绑定 | 说明 |
| --- | --- | --- |
| `default` | — | 链接内容。 |

{/* /generated:component:i18n-link */}

`to` 接受 `NuxtLink` 支持的任何值——路径、具名路由或已解析的路由对象。
若传入绝对 URL,会被识别为外部链接,并渲染为普通的 `<a target="_blank" rel="noopener noreferrer">`,不会进行本地化。

## 🛠️ 示例用法

### 基本用法

```vue
<i18n-link to="/about">About Us</i18n-link>
```

该示例会创建一个指向 `/about` 页面的链接,并本地化为当前语言。

### 使用内联样式设置活动状态

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

当用户位于 `/about` 页面时,链接文本会加粗,你可以直接通过内联样式定制活动链接的样式。

### 外部链接处理

组件会自动识别外部链接并添加必要的安全属性。

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

此链接会在新标签页中打开 `https://example.com`,并附带 `rel="noopener noreferrer"`。

## 🎨 样式

组件现在使用内联样式而非 class 来设置活动状态。你可以通过 `activeStyle` 属性来自定义这些样式。

### 默认活动样式

- **字重**:`bold`
- **颜色**:继承浏览器默认颜色(若未在 `activeStyle` 中指定 `color`)。

你可以通过 `activeStyle` 属性传入自定义样式来覆盖这些默认值。

### 自定义活动样式

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

在此示例中,链接在活动状态下会呈现加粗的绿色。

## 🚀 其他功能

### 自定义内容插槽

你可以通过插槽在链接内传入自定义内容,以便组件适应各种场景。

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### 无障碍增强

组件支持 `aria-label` 及其他无障碍属性,以提供更佳的无障碍体验。

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
