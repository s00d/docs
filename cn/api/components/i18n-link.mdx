# 🌍 `<i18n-link>` 组件

`Nuxt I18n Micro` 中的 `<i18n-link>` 组件是一个通用链接组件，会根据当前语言自动本地化路由。它是对 `<NuxtLink>` 的封装，额外提供了激活链接样式和外部链接支持等特性。

## ⚙️ 属性

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | 目标路由。会自动本地化；外部 URL 会保持原样透传。 |
| `activeStyle` | `Partial<CSSStyleValue>` | — | 当链接指向当前路由时应用的内联样式。 |

**\*** 必填。

### 插槽

| 插槽 | 绑定 | 描述 |
| --- | --- | --- |
| `default` | — | 链接内容。 |

{/* /generated:component:i18n-link */}

`to` 接受 `NuxtLink` 所支持的任意形式——路径、命名路由或已解析的路由对象。对于绝对 URL，组件会自动识别并渲染为普通的 `<a target="_blank" rel="noopener noreferrer">`，而不会进行本地化。

## 🛠️ 使用示例

### 基本用法

```vue
<i18n-link to="/about">About Us</i18n-link>
```

该示例会创建一个指向 `/about` 页面的链接，并本地化到当前语言。

### 通过内联样式为激活链接添加样式

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

当用户处于 `/about` 页面时链接文本会加粗，你可以通过内联样式直接为激活链接添加样式。

### 外部链接处理

组件会自动识别外部链接并添加必要的安全属性。

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

此链接会在新标签页中打开 `https://example.com`，并带上 `rel="noopener noreferrer"`。

## 🎨 样式

该组件现在使用内联样式而不是 class 表示激活状态。你可以通过 `activeStyle` 属性自定义这些样式。

### 默认激活样式

- **字重**：`bold`
- **颜色**：继承浏览器默认颜色（如果没有在 `activeStyle` 中指定 `color`）。

你可以通过 `activeStyle` 提供自定义样式来覆盖这些默认值。

### 自定义激活样式

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

在该示例中，激活时链接会加粗并显示为绿色。

## 🚀 其他特性

### 用于自定义内容的插槽

你可以通过插槽在链接中传入自定义内容，让组件适用于不同场景。

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### 无障碍增强

组件支持 `aria-label` 及其他无障碍属性，以提供更好的可访问性。

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
