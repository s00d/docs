`@i18n-micro/vue` 是一个 Vue 3 插件，包含 Nuxt I18n Micro 的翻译核心：响应式 `t()`、全局 `$t`、四个组件以及可选的 vue-router 适配器。在不使用 Nuxt 构建的 Vite 或 SSR Vue 应用中使用它。实例模型、路由器约定和组件 props 与其他包共享，详见[框架](/cn/integrations/overview)。

## 安装 {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vue
```

```bash npm
npm install @i18n-micro/vue
```

```bash yarn
yarn add @i18n-micro/vue
```

</CodeGroup>

peer 依赖：`vue` `^3.3.0`；`vue-router` `^4.5.1 || ^5.0.0`（可选，仅用于 `@i18n-micro/vue/router`）。在 `skipLibCheck: false` 时，发布的类型需要 Vue 3.5.5 或更高版本；在常见的模板设置 `skipLibCheck: true` 下，旧版本也可以编译。

## 设置 {#setup}

```ts
// src/main.ts
import { createApp } from 'vue'
import { createI18n } from '@i18n-micro/vue'
import App from './App.vue'
import en from './locales/en.json'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales: [
    { code: 'en', iso: 'en-US', displayName: 'English' },
    { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
  ],
  defaultLocale: 'en',
})

createApp(App).use(i18n).mount('#app')
```

`useI18n()` 需要 `locales` 和 `defaultLocale`：缺少它们时会抛出 `I18nLocalesKey not provided`。可以将它们传给 `createI18n`（如上所示）、传给 `useI18n({ locales, defaultLocale })`，或者通过 `app.provide(I18nLocalesKey, …)` 和 `app.provide(I18nDefaultLocaleKey, …)` 提供。

该插件会全局注册 `I18nT`、`I18nLink`、`I18nGroup` 和 `I18nSwitcher`，并向模板添加 `$t`、`$ts`、`$tc`、`$tn`、`$td`、`$tdr`、`$has` 和 `$i18n`。在组件外部，实例为 `i18n.global`。其他选项见[实例](/cn/integrations/overview#the-instance)；`routeMessages` 在 Vue 中不可用，请使用 `addRouteTranslations`。

## 翻译 {#translate}

```vue
<script setup lang="ts">
import { useI18n } from '@i18n-micro/vue'

const { t, tc, tn } = useI18n()
</script>

<template>
  <h1>{{ t('greeting', { name: 'Ada' }) }}</h1>
  <!-- Hello, Ada! -->
  <p>{{ tc('apples', 3) }}</p>
  <!-- 3 apples -->
  <p>{{ $t('nav.home') }} · {{ tn(1234.5) }}</p>
</template>
```

`useI18n()` 返回翻译方法（`t`、`ts`、`tc`、`tn`、`td`、`tdr`、`has`）、`locale`（可写的 computed）、`getLocale`、`getLocales`、`defaultLocale()`、`getLocaleName`、`localePath`、`localeRoute`、`switchLocale`、`setRoute`、`getRoute`、`addTranslations`、`addRouteTranslations`、`mergeTranslations`、`resolveTranslations`、`setTranslation`、`clearCache` 和 `instance`。

可以随时加载更多字典；每个读取它们的组件都会重新渲染：

```ts
const { addTranslations, addRouteTranslations, setRoute } = useI18n()

addTranslations('de', (await import('./locales/de.json')).default)
addRouteTranslations('en', 'about', { title: 'About us' })
setRoute('about') // t('title') now reads the 'about' dictionary first
```

## 切换 locale {#switch-locale}

```ts
const { locale, switchLocale } = useI18n()

locale.value = 'de' // only the locale
switchLocale('de') // the locale, then router.push to the localized current path
```

在切换之前或之后加载该 locale 的字典；切换本身不会请求任何内容。

`<I18nGroup>` 会向其插槽提供一个带前缀的 `t`。`<I18nT>` 内部或普通 `t()` 中的键不会加前缀：

```vue
<I18nGroup prefix="profile" v-slot="{ t }">
  <h2>{{ t('title') }}</h2>
  <!-- profile.title -->
</I18nGroup>
```

## 路由 {#routing}

vue-router 适配器位于子路径中，因此主入口永远不会导入 `vue-router`：

```ts
// src/main.ts
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import { createI18n } from '@i18n-micro/vue'
import { createVueRouterAdapter } from '@i18n-micro/vue/router'
import App from './App.vue'
import Home from './pages/Home.vue'
import About from './pages/About.vue'
import en from './locales/en.json'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English' },
  { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
]

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/:locale(de)?', component: Home },
    { path: '/:locale(de)?/about', component: About },
  ],
})

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales,
  defaultLocale: 'en',
  routingStrategy: createVueRouterAdapter(router, locales, 'en'),
})

createApp(App).use(router).use(i18n).mount('#app')
```

`createVueRouterAdapter(router, locales, defaultLocale)` 会为除默认 locale 外的所有 locale 添加前缀（`/about`、`/de/about`），并将 `<I18nLink>` 渲染为 `RouterLink`。你需要自行从路由中读取 locale，例如在 `router.beforeEach` 中，并设置 `i18n.global.locale.value`。也可以稍后通过 `i18n.setRoutingStrategy(adapter)` 挂载适配器；自定义适配器请参见[路由器适配器](/cn/integrations/overview#router-adapter)。

## SSR {#ssr}

- 在每个请求的渲染函数内部创建路由器、i18n 实例和应用。共享同一个实例会把一个访问者的 locale 泄露给另一个访问者。
- 在服务端使用 `createMemoryHistory()`，从 URL 中获取 locale，并在 `renderToString` 之前加载其字典（以及回退 locale 的字典）。
- 将 locale 发送到客户端（例如放在 `window.__STATE__` script 中），并用相同的 `locale` 创建客户端实例，以使 hydration 匹配。
- `<I18nSwitcher>` 只在下拉菜单打开时读取 `window.location`，因此它可以在服务端渲染。

`packages/vue/playground` 中有一对完整的 `entry-server.ts` / `entry-client.ts`。

## SEO head {#seo-head}

`useLocaleHead(options)` 根据 locale 和路由器适配器构建 `lang`/`dir`、canonical、`hreflang` 和 `og:locale` 标签。在路由变化时调用 `updateMeta()`，并将 `metaObject` 传给你的 head 管理器：

```ts
import { watch } from 'vue'
import { useRoute } from 'vue-router'
import { useHead } from '@unhead/vue'
import { useLocaleHead } from '@i18n-micro/vue'

const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
watch(() => route.fullPath, () => updateMeta(), { immediate: true })
useHead(metaObject)
```

选项：`baseUrl`（字符串或函数）、`addDirAttribute`（默认 `true`）、`addSeoAttributes`（默认 `true`）、`identifierAttribute`（默认 `'id'`）、`hreflangBaseLanguage`（默认 `false`）。带有 `disabled: true` 或 `seo: false` 的 locale 不会生成 alternate 链接。

## API {#api}

| 导出 | 入口 |
| --- | --- |
| `createI18n`、`useI18n`、`useLocaleHead` | `@i18n-micro/vue` |
| `I18nT`、`I18nLink`、`I18nSwitcher`、`I18nGroup` | `@i18n-micro/vue` |
| `VueI18n`（实例类）、`I18nInjectionKey`、`I18nLocalesKey`、`I18nDefaultLocaleKey` | `@i18n-micro/vue` |
| `defaultPlural`、`FormatService`、`interpolate` | `@i18n-micro/vue` |
| 类型：`I18nRoutingStrategy`、`Locale`、`Translations`、`PluralFunc`、`Params`、`Getter`、`CleanTranslation`、`LocaleCode`、`VueI18nOptions`、`UseI18nOptions`、`UseLocaleHeadOptions`、`I18nPlugin` | `@i18n-micro/vue` |
| `createVueRouterAdapter` | `@i18n-micro/vue/router` |

`TranslationKey` 不会从 `@i18n-micro/vue` 重新导出；请从 `@i18n-micro/types` 导入。完整签名：[包参考](/cn/api/packages/vue)。
