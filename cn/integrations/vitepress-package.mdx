title: "VitePress"

---

`@i18n-micro/vitepress` 为 VitePress 站点添加运行时字典：markdown 中的 `$t` 和 `<I18nT>`、路径辅助函数以及 SEO 标签，基于 [`@i18n-micro/vue`](/cn/integrations/vue-package) 构建。当相同的 UI 字符串出现在许多页面上、而你又不想为每个 locale 重复编写时，请使用它。locale 跟随 VitePress 自身的路径 locale（`/`、`/fr/`）。

## 何时使用 {#when-to-use-it}

| 需求 | 方案 |
|------|----------|
| 复制 `.md`、URL 前缀 | VitePress `locales` |
| 运行时 `$t` / 组件 / 路径同步 / SEO head | `@i18n-micro/vitepress` |
| 默认主题界面标签（`docFooter`、搜索 UI） | 为每个 locale 配置自己的 `themeConfig` |

<Tip>

**Playground** — [`packages/vitepress/playground`](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/vitepress/playground) — `pnpm -C packages/vitepress/playground dev`

</Tip>

## 安装 {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vitepress
```

```bash npm
npm install @i18n-micro/vitepress
```

```bash yarn
yarn add @i18n-micro/vitepress
```

</CodeGroup>

peer 依赖：`vitepress` `>=1.0.0 || >=2.0.0-alpha.0`、`vue` `^3.3.0`。Node 脚本使用 `@i18n-micro/node`，它会随本包一起安装，并通过 `/node` 重新导出。在 `skipLibCheck: false` 下，发布的类型需要 Vue 3.5.5 或更高版本；在常见的模板设置 `skipLibCheck: true` 下，旧版本也能编译通过。

## 设置 {#setup}

```
locales/en.json
locales/fr.json
locales/pages/guide/demo/en.json   # optional page-scoped
locales/pages/guide/demo/fr.json
```

页面文件到路由名称的映射方式与 Nuxt/Astro 相同（`guide/demo` → `guide-demo`）。

### 1. 配置 — `@i18n-micro/vitepress/config` {#1-config-—-@i18n-micro/vitepress/config}

```ts
// .vitepress/config.mts
import { defineConfig } from 'vitepress'
import { withI18n, buildVitePressLocales } from '@i18n-micro/vitepress/config'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English', og: 'en_US' },
  { code: 'fr', iso: 'fr-FR', displayName: 'Français', og: 'fr_FR' },
]
const defaultLocale = 'en'

export default defineConfig(
  withI18n(
    {
      locales: buildVitePressLocales(locales, defaultLocale),
      // themeConfig.i18nRouting is injected automatically
    },
    {
      locale: defaultLocale,
      defaultLocale,
      locales,
      translationDir: 'locales',
      metaBaseUrl: 'https://example.com', // optional SEO head
    },
  ),
)
```

### 2. 主题 — `@i18n-micro/vitepress/theme` {#2-theme-—-@i18n-micro/vitepress/theme}

```ts
// .vitepress/theme/index.ts
import DefaultTheme from 'vitepress/theme'
import { defineI18nTheme } from '@i18n-micro/vitepress/theme'

export default defineI18nTheme(DefaultTheme)
```

初始 locale 在安装前从当前路径中获取（在 `/fr/…` 上不会闪现默认 locale）。

### 进阶：手动调用 `createI18n` {#advanced-manual-createi18n}

客户端只需一个工厂函数：Vue 插件 + 路径方法 + `enhanceApp`（没有单独导出的路由辅助函数）。

```ts
import { createI18n, messagesFromGlob } from '@i18n-micro/vitepress'

const i18n = createI18n({
  locale: 'en',
  defaultLocale: 'en',
  locales: [{ code: 'en' }, { code: 'fr' }],
  messages: messagesFromGlob(import.meta.glob('../../locales/*.json', { eager: true })),
})

i18n.localizePath('/guide', 'fr')
// in theme enhanceApp:
i18n.enhanceApp({ app, router })
```

### Node 脚本 — `@i18n-micro/vitepress/node` {#node-scripts-—-@i18n-micro/vitepress/node}

使用 `@i18n-micro/node` 的 `createI18n` / `loadTranslations`（与 Astro 和 CLI 相同），然后通过 `BaseI18n.extend` 附加 VitePress 路径方法：

```ts
import { createI18n } from '@i18n-micro/vitepress/node'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  translationDir: './locales',
  locales: ['en', 'fr'],
  defaultLocale: 'en',
})
await i18n.loadTranslations()
i18n.t('cta.readMore')
i18n.localizePath('/guide', 'fr')
```

不需要路径功能的纯 Node 环境：`import { createI18n } from '@i18n-micro/node'`。

## 页面内翻译 {#in-page-translations}

每个 VitePress markdown 文件都是一个 Vue SFC。

### 全局组件和 `$t`（推荐在 markdown 中使用） {#global-components-and-$t-recommended-in-markdown}

`createI18n` / `defineI18nTheme` 会安装 `@i18n-micro/vue`，后者会注册 `I18nT` / `I18nLink` / `I18nGroup` / `I18nSwitcher` 以及 `$t` / `$tc` / `$ts`。

```md
{{ $t('cta.readMore') }}

<I18nT keypath="greeting" :params="{ name: 'VitePress' }" />

<I18nLink to="/guide/demo">Demo</I18nLink>
```

### 在 `<script setup>` 中使用 `useI18n` {#usei18n-in-<script-setup>}

```md
<script setup>
import { useI18n } from '@i18n-micro/vitepress'
const { t, tc, locale, localePath, switchLocale } = useI18n()
</script>

# {{ t('section.title') }}
```

## 语言下拉菜单 {#language-dropdown}

当 `locales` 有多个条目时，VitePress 会显示自己的语言菜单（`VPNavBarTranslations`）。`withI18n` 会配置 `themeConfig.i18nRouting`，使地球图标菜单与 `<I18nSwitcher>` / 路径辅助函数保持一致。

仅在自定义布局中使用 `<I18nSwitcher>`，不要将其放在默认的地球图标菜单旁边。

## SSR 注意事项 {#ssr-notes}

- 预渲染时的 locale 来自 URL 路径，而不是 cookie。
- 主题代码在导入时不得访问 `window`。
- 从 `/theme` 导入 `defineI18nTheme`，这样 Node 配置求值时永远不会加载 `virtual:i18n-micro/*`。

## API 概览 {#api-surface}

| 导出 | 作用 |
|--------|------|
| `createI18n`（`.`） | 客户端：Vue 插件 + 路径方法 + `enhanceApp` |
| `getLocaleFromPath` / `stripSiteBase` / `routeNameFromPath`（`.`） | 在 `syncWithVitePress: false` 时手动同步 locale |
| `createI18n`（`/node`） | Node：`@i18n-micro/node` + 路径方法 |
| `defineI18nTheme`（`/theme`） | 零样板代码的主题 |
| `withI18n`（`/config`） | 配置 + 虚拟模块 + 可选 SEO |
| `buildVitePressLocales`（`/config`） | 从 `Locale[]` 构建 VitePress `locales` |
| `buildVitePressLocaleHead`（`/config`） | 手动 SEO head（`metaBaseUrl` 也会使用） |
| `messagesFromGlob` | 可选：将 glob 转换为供 `createI18n` 使用的 messages 映射 |
| `useI18n` / `I18nT` / … | 从 `@i18n-micro/vue` 重新导出 |
| `BaseI18n.extend`（`@i18n-micro/core`） | 在任意 i18n 实例上附加自定义方法 |

## OpenAPI 风格的站点（集成约束） {#openapi-style-sites-integration-locks}

回归测试套件：`packages/vitepress/tests/integration-openapi.test.ts`（深层路径、`base=/openapi_docs/`、关闭同步 + 手动 locale、Node 生成器、SEO）。

| 场景 | 做法 |
|---------|---------|
| 深层 `/…/{spec}/{op}` 页面，仅有根 UI JSON | 优先使用默认的 `syncWithVitePress: true`（没有页面字典时保持 `setRoute('index')`）**或** `syncWithVitePress: false` + `getLocaleFromPath` |
| 没有页面字典时切勿调用 `setRoute(deepName)` | 否则根 UI 键会消失，直到调用 `setRoute('index')` |
| 生成器 / `getTranslation` | 使用 `/node` 中的 `createI18n` + `await loadTranslations()` + `i18n.t(key)`（设置 `i18n.locale`） |
| 在 `transformPageData` 中自定义 canonical | 向 `withI18n` 传入 `meta: false`（避免重复标签） |
| 带站点 base 的包 SEO | `metaBaseUrl` + VitePress `base` → 绝对 URL 包含 base |
| 从旧版本包构建迁移时的重命名 | `withI18nMicro` → `withI18n`、`createVitePressI18n` → `createI18n`、`loadMessages` → node `createI18n` |
