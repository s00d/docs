`@i18n-micro/*` 包将 Nuxt I18n Micro 的翻译核心带到 Vue、React、Preact、Solid、Astro、VitePress 和原生 JavaScript 中。当你的应用不是 Nuxt 应用，或 Nuxt 之外的脚本或服务器需要使用相同的翻译文件时，请使用它们。所有包共享同一种实例模型、同一套路由适配器约定和相同的四个组件，本页对其统一说明。

## 包 {#packages}

| 技术栈 | 包 | 路由入口 |
| --- | --- | --- |
| [Vue 3 SPA](/cn/integrations/vue-package) | `@i18n-micro/vue` | `@i18n-micro/vue/router` |
| [React](/cn/integrations/react-package) | `@i18n-micro/react` | `@i18n-micro/react/router` |
| [Preact](/cn/integrations/react-package#preact) | `@i18n-micro/preact` | — |
| [SolidJS](/cn/integrations/solid-package) | `@i18n-micro/solid` | `@i18n-micro/solid/router` |
| [Astro](/cn/integrations/astro-package)：SSR 与 [islands](/cn/integrations/astro-islands) | `@i18n-micro/astro` | — |
| [VitePress](/cn/integrations/vitepress-package) | `@i18n-micro/vitepress` | — |
| [浏览器或边缘环境](/cn/integrations/runtime-package)，无框架 | `@i18n-micro/runtime` | — |
| [Node.js](/cn/integrations/nodejs-package) 服务器、CLI | `@i18n-micro/node` | — |
| [类型化键](/cn/integrations/types-generator)，Vite 或 Nuxt | `@i18n-micro/types-generator` | — |
| 开发环境中的[翻译编辑器](/cn/integrations/devtools-ui-package) | `@i18n-micro/devtools-ui` | — |

路由入口是单独的导入，因此没有路由的应用永远不会打包路由代码。

`@i18n-micro/core`、`@i18n-micro/types` 和 `@i18n-micro/utils` 会随这些包一起安装；你很少需要直接导入它们。所有导出的签名见自动生成的[包参考](/cn/api/packages/overview)。

每个包在仓库的 `packages/<name>/playground` 下都有一个 playground。

## 实例 {#the-instance}

`createI18n(options)` 返回一个实例，其中保存字典、当前 locale 和当前路由。所有包的选项都相同：

| 选项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `locale` | `string` | 必填 | 当前 locale。 |
| `fallbackLocale` | `string` | `locale` | 当 `locale` 中缺少某个键时查找。 |
| `messages` | `Record<locale, Translations>` | `{}` | 根字典（`'index'` 路由）。 |
| `routeMessages` | `Record<route, Record<locale, Translations>>` | `{}` | 路由字典。仅限 Runtime、React、Preact、Node 和 VitePress。 |
| `plural` | `PluralFunc` | `defaultPlural` | 自定义复数规则。 |
| `missingWarn` | `boolean` | `true` | 缺少键时，仅在开发环境下于浏览器中调用 `console.warn`。 |
| `missingHandler` | `(locale, key, routeName) => void` | — | 代替警告被调用。 |
| `numberFormats` | `Record<locale, Record<name, Intl.NumberFormatOptions>>` | — | 命名格式：`tn(9.5, 'currency')`。 |
| `datetimeFormats` | `Record<locale, Record<name, Intl.DateTimeFormatOptions>>` | — | 命名格式：`td(date, 'short')`。 |
| `timeZone` | `string` | 运行时所在时区 | `td` 日期使用的 IANA 时区；不影响 `tdr`。设置它可使服务器和浏览器渲染出相同的日期。 |
| `now` | `() => number` | `Date.now` | `tdr` 使用的时钟。在水合时传入服务器时间，使两端渲染相同的文本。 |
| `localeIso` | `Record<code, string>` | — | 用于复数规则的 BCP 47 标签（`ua` → `uk-UA`）。React、Preact 和 Solid 从 provider 的 `locales` 中的 `iso` 获取。 |

字典保存在 `i18n.storage.translations` 中，这是一个以 `locale:route` 为键的 `Map`（`en:index`、`en:about`）。

键会先在当前路由的字典中查找，然后在根字典中查找，先针对 `locale`，再针对 `fallbackLocale`。缺失的键会返回键本身（或你传入的 `defaultValue`）。

```ts
i18n.addTranslations('en', { nav: { home: 'Home' } }) // root, deep-merged
i18n.addRouteTranslations('en', 'about', { title: 'About us' }) // route chunk
i18n.addTranslations('en', { nav: { home: 'Start' } }, false) // replace instead of merge
i18n.setRoute('about')
i18n.t('title') // 'About us'
i18n.t('nav.home') // 'Start' (root key, still visible on the route)
```

### 翻译与格式化 {#translate-and-format}

| 方法 | 返回值 |
| --- | --- |
| `t(key, params?, defaultValue?, routeName?)` | 插入 `{param}` 后的值（字符串、数字、对象）。 |
| `ts(...)` | 与 `t` 相同，但返回字符串。 |
| `tc(key, count \| params, defaultValue?)` | 复数形式。 |
| `tn(value, options \| name)` | 当前 locale 下的 `Intl.NumberFormat`。 |
| `td(value, options \| name)` | `Intl.DateTimeFormat`。 |
| `tdr(value, options?)` | 相对时间（`3 days ago`）。 |
| `has(key, routeName?)` | 当前 locale 拥有该键时为 `true`（路由或根字典；不检查回退）。 |

`defaultPlural` 按 `|` 拆分值，并选取索引为 `count` 的形式，超出时取最后一个；负数、小数或 `NaN` 的 count 会选取最后一个形式。

自定义 `plural` 接收 `(key, count, params, locale, getter)`。请通过 `getter(key)` 读取值；不要拆分键：

```ts
import type { PluralFunc } from '@i18n-micro/vue'

const plural: PluralFunc = (key, count, params, _locale, getter) => {
  const value = getter(key)
  if (typeof value !== 'string') return null
  const forms = value.split('|').map((form) => form.trim())
  return (count === 1 ? forms[0] : forms[1] ?? forms[0])!.replace('{count}', String(count))
}
```

## 路由适配器 {#router-adapter}

SPA 包不依赖任何路由。路由适配器（`I18nRoutingStrategy`）告诉它们如何读取当前路径、如何导航以及如何构建本地化路径。内置适配器会为 `defaultLocale` 之外的每个 locale 添加前缀（`/about`、`/de/about`）。

| 成员 | 必需 | 使用方 |
| --- | --- | --- |
| `getCurrentPath(): string` | 是 | 激活链接检查（按页面，不计查询参数和 hash）、`switchLocale`（保留它们） |
| `push({ path }): void` | 是 | `switchLocale`、未设置 `linkComponent` 的 `<I18nLink>`、`<I18nSwitcher>` |
| `replace({ path }): void` | 是 | — |
| `resolvePath(to, locale)` | 否 | `localePath`、`localeRoute`、`<I18nLink>`；未提供时路径原样返回 |
| `linkComponent` | 否 | `<I18nLink>` 会渲染它（例如 `RouterLink`）而不是 `<a>` |
| `getRoute()` | 否 | 供 SEO 辅助函数使用的 `{ fullPath, query }` |

在 Vue、React、Preact 和 Solid 中，`push` 和 `replace` 是必需的。Astro 有自己的服务器端适配器，其中 `push`/`replace` 是可选的（参见 [Astro](/cn/integrations/astro-package#router-adapter)）。

适用于任何基于 history 的路由的最小适配器：

```ts
import type { I18nRoutingStrategy } from '@i18n-micro/react'

const locales = ['en', 'de']
const stripLocale = (path: string) => path.replace(/^\/(en|de)(?=\/|$)/, '') || '/'

export const historyAdapter: I18nRoutingStrategy = {
  getCurrentPath: () => window.location.pathname + window.location.search + window.location.hash,
  push: ({ path }) => window.history.pushState({}, '', path),
  replace: ({ path }) => window.history.replaceState({}, '', path),
  resolvePath: (to, locale) => {
    const path = stripLocale(typeof to === 'string' ? to : to.path || '/')
    return locale === 'en' ? path : `/${locale}${path === '/' ? '' : path}`
  },
}
```

## 组件 {#components}

Vue、React、Preact 和 Solid 提供相同的四个组件。它们的 props 一致；React、Preact 和 Solid 会将其他 props 透传给根元素。

### `<I18nT>` {#&lt;i18nt&gt;}

| Prop | 类型 | 说明 |
| --- | --- | --- |
| `keypath` | `string` | 必填 |
| `params` | `object` | 插值的值 |
| `plural` | `number \| string` | 渲染 `tc(keypath, count)` |
| `number` | `number \| string` | 将 `tn(number)` 作为 `{number}` 传入 |
| `date` | `Date \| string \| number` | 将 `td(date)` 作为 `{date}` 传入 |
| `relativeDate` | `Date \| string \| number` | 将 `tdr(relativeDate)` 作为 `{relativeDate}` 传入 |
| `tag` | `string` | 包装元素，默认为 `span` |
| `html` | `boolean` | 将翻译渲染为 HTML；翻译内容必须可信，参数会被转义 |
| `defaultValue` | `string` | 代替缺失的键；当 `hideIfEmpty` 隐藏空值时，会以纯文本形式渲染 |
| `hideIfEmpty` | `boolean` | 翻译为空时不渲染任何内容 |
| `customPluralRule` | `PluralFunc` | 此元素使用的复数规则 |

只有一个格式化 prop 会生效，按以下顺序检查：`number`、`date`、`relativeDate`、`plural`。

#### 富文本 {#rich-text}

`{placeholder}` 可以容纳一个元素。在 Vue 中它是一个具名插槽；在 React、Preact 和 Solid 中，`components` prop 按名称提供元素或返回元素的函数。无论哪种方式，它都优先于同名参数，在每个分支中都有效，并且在 locale 调整占位符顺序时依然正常工作。

```tsx
// { "terms": "I accept the {link} of {company}" }
<I18nT keypath="terms" params={{ company: 'ACME' }} components={{ link: <a href="/terms">terms</a> }} />
```

在 Solid 中，当占位符重复出现时请传入函数：一个节点只能占据一个位置。`children` 会替换文本，作为函数时它们会接收 `{ translation }`，类似于 Vue 的默认插槽。`html` 会忽略以上所有内容。

### `<I18nLink>` {#&lt;i18nlink&gt;}

| Prop | 类型 | 说明 |
| --- | --- | --- |
| `to` | `string \| { path }` | 通过适配器的 `resolvePath` 本地化 |
| `activeStyle` | 样式对象 | 在当前页面上合并到 `style` 之上；React、Preact 和 Solid 也会将其应用于上级路径的分区 |
| `localeRoute` | 函数 | 为此链接覆盖 `resolvePath` |

外部 URL（`https://`、`mailto:`、`tel:`）会渲染为 `<a target="_blank" rel="noopener noreferrer">`；你自己设置的 `target` 或 `rel` 优先。`onClick` 始终会执行。带修饰键的点击、其他鼠标按键或设置了 `target` 时，交由浏览器处理。

### `<I18nSwitcher>` {#&lt;i18nswitcher&gt;}

一个列出已启用 locale 的下拉菜单（`disabled: true` 的 locale 会被隐藏），带有内联默认样式。其中的项是链接，带有来自 locale 的 `lang`、`hreflang` 和 `dir`。默认情况下，点击某一项会设置 locale，并以本地化后的当前路径调用适配器的 `push`；`switchLocale` prop 会替换这一行为。设置了 `localeRoute` 但没有路由时，浏览器会跟随该链接。按 Escape 或点击外部会关闭它。

| Prop | 说明 |
| --- | --- |
| `locales`、`currentLocale`、`getLocaleName` | 覆盖提供的值 |
| `switchLocale(code)` | 替换内置的切换行为 |
| `localeRoute` | 替换 `resolvePath` |
| `customLabels` | `{ de: 'DE' }` |
| `customWrapperStyle`、`customButtonStyle`、`customDropdownStyle`、`customItemStyle`、`customLinkStyle`、`customActiveLinkStyle`、`customDisabledLinkStyle`、`customIconStyle` | 样式覆盖 |

### `<I18nGroup>` {#&lt;i18ngroup&gt;}

一个 `<div class="i18n-group">`，向其子元素提供带前缀的 `t`。它**不会**为内部的 `<I18nT>` 或 `t()` 调用添加前缀；只有它向下传递的 `t` 带有前缀。

| Prop | 说明 |
| --- | --- |
| `prefix` | 必填，例如 `'profile'` |
| `groupClass` | 包装元素上的额外 class |

带前缀的 `t` 在 Vue 中通过作用域插槽（`v-slot="{ t }"`）提供，在 React、Preact 和 Solid 中通过 render-prop 子元素（`{({ t }) => …}`）提供。

## 类型化键 {#typed-keys}

`t()` 接受任意字符串。要为你的键获得自动补全，请使用[类型生成器](/cn/integrations/types-generator)生成声明文件。键只是建议而非强制，参数也没有类型。

## 与 Nuxt 模块的比较 {#compared-with-the-nuxt-module}

这些包没有基于文件的路由、没有服务器中间件，也没有翻译加载器：由你决定何时加载 JSON（`import`、`fetch`，或在服务器上使用 `@i18n-micro/node`）以及使用哪个路由适配器。Locale 检测、SEO meta 和路由生成是 Nuxt 的功能；Astro 有自己用于检测的中间件，以及用于 SEO 的 `useLocaleHead`。
