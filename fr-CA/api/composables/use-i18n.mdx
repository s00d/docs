# 🛠️ Composable `useI18n`

Le composable `useI18n` de `Nuxt I18n Micro` donne accès à la plupart des assistants i18n d'exécution dans les composants et les scripts. Les méthodes sont disponibles **avec et sans le préfixe `$`** (par exemple `$t` et `t`).

Certaines injections, comme `$defineI18nRoute` et `$clearCache`, sont disponibles uniquement sur `useNuxtApp()`. Consultez [Méthodes — `$defineI18nRoute`](/api/methods#definei18nroute) et [`$clearCache`](/api/methods#clearcache).

## 📊 Ce qu'il retourne

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Chaque assistant d'exécution, sous forme d'objet ordinaire.

Les mêmes fonctions que le plugin injecte comme `$t`, `$tc` et ainsi de suite, disponibles à la fois sous le nom préfixé par un dollar et sous un alias nu. Ainsi, `const \{ t \} = useI18n()` et `const \{ $t \} = useI18n()` fonctionnent tous les deux.

**Retourne** : les assistants décrits dans la [référence des méthodes](/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

Chaque assistant qu'il retourne (`$t`, `$tc`, `$has`, `$switchLocale` et les autres) est listé avec sa signature et documenté en détail dans la [référence des méthodes](/api/methods).

## API réservées à `useNuxtApp()`

Elles **ne sont pas** retournées par `useI18n()`. Importez-les depuis `useNuxtApp()` :

| Méthode                    | Rôle                                                                             |
| -------------------------- | -------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Routes linguistiques par page, restrictions et traductions en ligne dans `script setup` |
| `$clearCache()`            | Vide le cache de traduction en mémoire et les morceaux chargés                     |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Consultez [Méthodes](/api/methods) pour les signatures complètes et des exemples.

## 🛠️ Exemples d'utilisation

### Récupération de base de la langue

Récupérez la langue courante de l'application.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Traduction avec paramètres

Traduisez une chaîne avec des paramètres dynamiques, avec une valeur par défaut de repli.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Changer de langue

Basculez l'application dans une autre langue.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Générer une route localisée

Générez une route localisée pour la langue courante ou spécifiée.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
