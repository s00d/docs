# 🛠️ Composable `useI18n`

Le composable `useI18n` dans `Nuxt I18n Micro` donne accès à la plupart des utilitaires i18n d'exécution dans les composants et les scripts. Les méthodes sont disponibles **avec et sans le préfixe `$`** (par exemple `$t` et `t`).

Certaines injections — `$defineI18nRoute` et `$clearCache` — ne sont disponibles que sur `useNuxtApp()`. Consultez [Méthodes — `$defineI18nRoute`](/api/methods#definei18nroute) et [`$clearCache`](/api/methods#clearcache).

## 📊 Ce qu'il retourne

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Chaque utilitaire d'exécution, sous forme d'objet simple.

Les mêmes fonctions que le greffon injecte sous les noms `$t`, `$tc`, etc., disponibles à la fois sous le nom préfixé par un dollar et sous un alias simple — de sorte que `const \{ t \} = useI18n()` et
`const \{ $t \} = useI18n()` fonctionnent tous les deux.

**Retourne** — les utilitaires décrits dans la [référence des méthodes](/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

Chaque utilitaire retourné — `$t`, `$tc`, `$has`, `$switchLocale` et les autres — est répertorié
avec sa signature et documenté en détail dans la [référence des méthodes](/api/methods).

## API disponibles seulement via `useNuxtApp()`

Celles-ci ne sont **pas** retournées par `useI18n()`. Importez-les depuis `useNuxtApp()` :

| Méthode                     | Objectif                                                                         |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Routes de langue par page, restrictions et traductions en ligne dans `script setup` |
| `$clearCache()`            | Vide le cache de traduction en mémoire et les fragments chargés                            |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Consultez [Méthodes](/api/methods) pour les signatures complètes et les exemples.

## 🛠️ Exemples d'utilisation

### Récupération de base de la langue

Récupérer la langue courante de l'application.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Traduction avec paramètres

Traduire une chaîne avec des paramètres dynamiques, avec une valeur par défaut de repli.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Changement de langue

Faire passer l'application à une langue différente.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Générer une route localisée

Générer une route localisée pour la langue courante ou spécifiée.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
