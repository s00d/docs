# useI18nLocale

## Utilisation

```vue
<script setup>
const {
  locale,
  localeCookie,
  hashCookie,
  validLocales,
  getPreferredLocale,
  getLocale,
  getLocaleWithServerFallback,
  getEffectiveLocale,
  resolveInitialLocale,
  setLocale,
  syncLocale,
  isValidLocale,

// Set locale (updates state and cookies)
```

## API

| Propriété/Méthode                               | Type                                | Description                                                                          |
| ----------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| `locale`                                        | `Ref<string \| null>`               | État linguistique réactif (`useState('i18n-locale')`)                                 |
| `localeCookie`                                  | `Ref`                               | Témoin de langue (lorsque l'option `localeCookie` est activée)                        |
| `hashCookie`                                    | `Ref`                               | Témoin utilisé lorsque `hashMode` est actif                                            |
| `validLocales`                                  | `string[]`                          | Codes de langue activés depuis la configuration du module (exclut `disabled`)          |
| `getLocale()`                                   | `() => string \| null`              | Langue courante : état → témoin (ou témoin de hachage en mode hachage)                 |
| `getPreferredLocale()`                          | `() => string \| null`              | Langue de l'état/du témoin **validée** par rapport à `validLocales`, ou `null`         |
| `getLocaleWithServerFallback(serverLocale?)`    | `(serverLocale?) => string \| null` | État → témoin → contexte serveur facultatif (utilisé pendant l'init en `no_prefix`)    |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string`             | Langue pour charger les traductions : le mode hachage préfère l'état; sinon lit depuis la route |
| `resolveInitialLocale(options)`                 | `(options) => string`               | Résout la langue : état → `serverLocale` → route; synchronise l'état au besoin           |
| `setLocale(locale)`                             | `(locale: string \| null) => void`  | Définit la langue et la synchronise avec les témoins                                    |
| `syncLocale(locale)`                            | `(locale: string \| null) => void`  | Synchronise uniquement les témoins (aucune mise à jour de l'état)                       |
| `isValidLocale(locale)`                         | `(locale) => boolean`               | Vérifie si une chaîne est dans `validLocales`                                           |

### Options de `resolveInitialLocale`

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

Utilisée en interne par le plugin principal au démarrage. Les plugins personnalisés peuvent l'appeler lorsqu'ils implémentent des flux de détection alternatifs.

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

Retourne la langue utilisée pour charger les traductions et formater les messages pour un objet route donné.

## Définition programmée de la langue

Préférez `useI18nLocale()` à l'utilisation directe de `useState('i18n-locale')` :

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
`setLocale()` met à jour la préférence linguistique (état + témoin) uniquement. Pour aussi recharger le contexte de traduction actif côté client, utilisez `$switchLocale()` depuis `useNuxtApp()` ou `useI18n()`. C'est particulièrement important pour `no_prefix`, où l'URL ne change pas. Consultez la [FAQ — changer de langue sans changer l'URL](/guides/faq#-switch-locale-without-changing-the-url).
</Tip>
