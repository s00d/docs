# useI18nLocale

Point d'entrée centralisé pour la gestion de la langue i18n.
Combine useState('i18n-locale'), le témoin de langue et les utilitaires de synchronisation.

## API

| Propriété/Méthode                                 | Type                                | Description                                                                          |
| ----------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| `locale`                                        | `Ref<string \| null>`               | État réactif de la langue (`useState('i18n-locale')`)                                    |
| `localeCookie`                                  | `Ref`                               | Témoin de langue (lorsque l'option `localeCookie` est activée)                                |
| `hashCookie`                                    | `Ref`                               | Témoin utilisé lorsque `hashMode` est actif                                                |
| `validLocales`                                  | `string[]`                          | Codes de langue activés dans la configuration du module (exclut les `disabled`)                        |
| `getLocale()`                                   | `() => string \| null`              | Langue courante : état → témoin (ou témoin de hachage en mode hash)                         |
| `getPreferredLocale()`                          | `() => string \| null`              | Langue de l'état/du témoin **validée** contre `validLocales`, sinon `null`             |
| `getLocaleWithServerFallback(serverLocale?)`    | `(serverLocale?) => string \| null` | État → témoin → contexte serveur optionnel (utilisé pendant l'initialisation de `no_prefix`)              |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string`             | Langue pour le chargement des traductions : le mode hash privilégie l'état ; sinon lecture depuis la route |
| `resolveInitialLocale(options)`                 | `(options) => string`               | Résout la langue : état → `serverLocale` → route ; synchronise l'état au besoin             |
| `setLocale(locale)`                             | `(locale: string \| null) => void`  | Définit la langue et synchronise avec les témoins                                                       |
| `syncLocale(locale)`                            | `(locale: string \| null) => void`  | Synchronise les témoins seulement (pas de mise à jour de l'état)                                                  |
| `isValidLocale(locale)`                         | `(locale) => boolean`               | Vérifie si la chaîne est dans `validLocales`                                                |

### Options de `resolveInitialLocale`

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

Utilisée en interne par le greffon principal au démarrage. Les greffons personnalisés peuvent l'appeler lors de l'implémentation de flux de détection alternatifs.

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

Retourne la langue utilisée pour charger les traductions et formater les messages pour un objet route donné.

## Définition programmatique de la langue

Préférez `useI18nLocale()` à l'utilisation directe de `useState('i18n-locale')` :

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
`setLocale()` met à jour la préférence de langue (état + témoin) uniquement. Pour aussi recharger le contexte de traduction actif côté client, utilisez `$switchLocale()` depuis `useNuxtApp()` ou `useI18n()`. Cela a de l'importance surtout pour `no_prefix`, où l'URL ne change pas. Consultez [FAQ — changer de langue sans changer l'URL](/guides/faq#-switch-locale-without-changing-the-url).
</Tip>
