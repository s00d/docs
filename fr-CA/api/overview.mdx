# Référence de l'API

## API d'exécution

- [Méthodes](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, changement de langue, utilitaires de routage
- [Événements](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Traductions et cache](/api/cache) — `TranslationStorage`, chargement des charges utiles, `$clearCache`

## Intergiciels serveur

Les gestionnaires côté serveur utilisent des intergiciels dédiés (pas les utilitaires client `$t`) :

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — traduire dans les routes d'API et gestionnaires serveur
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — lire la langue détectée et ses métadonnées

Consultez le [guide complet des traductions côté serveur](/guides/server-side-translations) pour la configuration, la priorité de détection de langue et les exemples.
