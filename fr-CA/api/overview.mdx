# Référence de l'API

## API d'exécution

- [Méthodes](/api/methods) : `$t`, `$ts`, `$_t`, `$_ts`, changement de langue, assistants de routage
- [Événements](/api/events) : `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Traductions et cache](/api/cache) : `TranslationStorage`, chargement de charge utile, `$clearCache`

## Middleware serveur

Les gestionnaires de serveur utilisent un middleware dédié (et non les assistants client `$t`) :

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) : traduire dans les routes API et les gestionnaires de serveur
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) : lire la langue détectée et ses métadonnées

Consultez le [guide complet des traductions côté serveur](/guides/server-side-translations) pour la configuration, la priorité de détection de la langue et des exemples.
