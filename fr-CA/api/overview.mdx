Cette section énumère chaque option, fonction utilitaire, hook, composable et composant du module Nuxt, ainsi que l'API exportée de chaque paquet `@i18n-micro/*`. Servez-vous-en pour trouver une signature ou une valeur par défaut; le [Guide](/fr-CA/guide/getting-started) explique comment les utiliser. La plupart des tableaux de cette section sont générés à partir du code source, ils correspondent donc au code.

## Module Nuxt {#nuxt-module}

| Page | Contenu |
| --- | --- |
| [Options du module](/fr-CA/api/module-options) | Chaque clé `i18n` de `nuxt.config`, avec son type et sa valeur par défaut |
| [Fonctions utilitaires](/fr-CA/api/methods) | `$t`, `$tc`, `$tn`, `$td`, `$localePath`, `$switchLocale`, `$defineI18nRoute` et les autres |
| [Hooks](/fr-CA/api/events) | Le hook d'exécution `i18n:register` |

## Composables {#composables}

| Composable | À utiliser pour |
| --- | --- |
| [`useI18n`](/fr-CA/composables/useI18n) | Les fonctions utilitaires dans `<script setup>` |
| [`useI18nLocale`](/fr-CA/composables/useI18nLocale) | L'état de la locale et le témoin dans un plugiciel de détection personnalisé |
| [`useI18nHead`](/fr-CA/composables/useI18nHead) | Les remplacements par page des balises SEO générées |
| [`useLocaleHead`](/fr-CA/composables/useLocaleHead) | Les balises SEO sous forme d'objet, pour votre propre `useHead` |

## Composants {#components}

| Composant | Affiche |
| --- | --- |
| [`<i18n-t>`](/fr-CA/components/i18n-t) | Une traduction, avec pluriel, formatage et interpolation de slots |
| [`<i18n-link>`](/fr-CA/components/i18n-link) | Un `NuxtLink` vers la route localisée |
| [`<i18n-switcher>`](/fr-CA/components/i18n-switcher) | Un menu déroulant de locales |
| [`<i18n-group>`](/fr-CA/components/i18n-group) | Un bloc avec un préfixe de clé commun |

## Serveur {#server}

Les gestionnaires Nitro utilisent `useTranslationServerMiddleware` et `useLocaleServerMiddleware`, et non les fonctions utilitaires côté client. Voir [Routes serveur](/fr-CA/guide/server-side-translations).

## Paquets {#packages}

[API des paquets](/fr-CA/api/packages/overview) énumère les exportations de chaque paquet `@i18n-micro/*`, avec une page générée pour chacun.
