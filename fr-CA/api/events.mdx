# 📢 Événements

## 🔄 `i18n:register`

L'événement `i18n:register` dans `Nuxt I18n Micro` permet d'ajouter dynamiquement des traductions au contexte i18n de votre application, rendant le processus d'internationalisation transparent et souple. Cet événement vous permet d'intégrer de nouvelles traductions au besoin, améliorant les capacités de localisation de votre application.

### 📝 Détails de l'événement

- **Objectif** :
  - Permet l'intégration dynamique de traductions supplémentaires à l'ensemble existant pour une langue précise.

- **Charge utile** :
  - **`register`** :
    - Une fonction fournie par l'événement qui prend deux arguments :
      - **`translations`** (`Translations`) :
        - Un objet contenant des paires clé-valeur représentant les traductions, organisé selon l'interface `Translations`.
      - **`locale`** (`string`, optionnel) :
        - Le code de langue (p. ex. `'en'`, `'ru'`) pour lequel les traductions sont enregistrées. Par défaut, la langue fournie par l'événement est utilisée si non spécifiée.

- **Comportement** :
  - Lorsqu'elle est déclenchée, la fonction `register` fusionne les nouvelles traductions dans le contexte courant pour la langue spécifiée, en mettant à jour les traductions disponibles dans toute l'application.

### ⏱️ Quand il se déclenche

Le greffon de crochets du module (`05.hooks.ts`, `dependsOn: ['i18n-plugin-loader']`) appelle `nuxtApp.callHook('i18n:register', …)` :

1. **Une fois au démarrage** — après que le greffon i18n principal (`01.plugin.ts`) a chargé les traductions pour la route initiale
2. **À la navigation** — dans `router.beforeEach` lorsque le chemin change, ou à chaque navigation lorsque `strategy: 'no_prefix'`

Enregistrez votre écouteur dans un greffon Nuxt normal avec `nuxtApp.hook('i18n:register', …)`. Le greffon de crochets s'exécute après que le chargeur est prêt, de sorte que votre rappel est invoqué lorsque les traductions doivent être étendues.

Définissez `hooks: false` dans `nuxt.config` pour désactiver les appels automatiques à `i18n:register` (voir [Configuration — `hooks`](/guides/configuration#hooks)).

### 💡 Exemple d'utilisation

L'exemple suivant montre comment utiliser l'événement `i18n:register` pour ajouter dynamiquement des traductions :

```typescript
nuxt.hook('i18n:register', async (register: (translations: unknown, locale?: string) => void, locale: string) => {
  register(
    {
      greeting: 'Hello',
      farewell: 'Goodbye',
    },
    locale,
  )
})
```

  - Le greffon de crochets (`05.hooks.ts`) déclenche `i18n:register` après que le chargeur principal est prêt et lors des navigations pertinentes.

- **Ajout de traductions** :
  - L'exemple enregistre des traductions anglaises pour `"greeting"` et `"farewell"`.
  - La fonction `register` fusionne ces traductions dans l'ensemble existant pour la langue fournie.

### 🔗 Avantages clés

- **Mises à jour dynamiques** :
  - Mettez à jour ou ajoutez facilement des traductions sans avoir à redéployer l'ensemble de votre application.

- **Souplesse de localisation** :
  - Prend en charge les ajustements de localisation en temps réel en fonction des besoins de l'utilisateur ou de l'application.

En utilisant l'événement `i18n:register`, vous pouvez garantir que la stratégie de localisation de votre application reste souple et adaptable, améliorant l'expérience utilisateur globale.

## 🛠️ Modifier les traductions avec des greffons

Pour modifier les traductions dynamiquement dans votre application Nuxt, l'utilisation de greffons est recommandée. Les greffons offrent une manière structurée de gérer les mises à jour de localisation, particulièrement lorsque vous travaillez avec des modules ou des fichiers de traduction externes.

### **Enregistrer le greffon**

Si vous utilisez un module, enregistrez le greffon où les modifications de traduction auront lieu en l'ajoutant à la configuration de votre module :

```javascript
addPlugin({
  src: resolve('./plugins/extend_locales'),
})
```

Cela enregistre le greffon situé à `./plugins/extend_locales`, qui gérera le chargement et l'enregistrement dynamiques des traductions.

### **Implémenter le greffon**

Dans le greffon, vous pouvez gérer les modifications de langue. Voici un exemple d'implémentation dans un greffon Nuxt :

```typescript
import { defineNuxtPlugin } from '#app'

export default defineNuxtPlugin(async (nuxtApp) => {
  // Function to load translations from JSON files and register them
  const loadTranslations = async (lang: string) => {
    try {
      const translations = await import(`../locales/${lang}.json`)
      return translations.default
    } catch (error) {
      console.error(`Error loading translations for language: ${lang}`, error)
      return null
    }
  }

  // Hook into the 'i18n:register' event to dynamically add translations
  // eslint-disable-next-line @typescript-eslint/ban-ts-comment
  // @ts-expect-error
  nuxtApp.hook('i18n:register', async (register: (translations: unknown, locale?: string) => void, locale: string) => {
    const translations = await loadTranslations(locale)
    if (translations) {
      register(translations, locale)
    }
  })
})
```

### 📝 Explication détaillée

1. **Chargement des traductions** :

- La fonction `loadTranslations` importe dynamiquement les fichiers de traduction en fonction de la langue. Les fichiers sont attendus dans le répertoire `locales` et nommés selon les codes de langue (p. ex. `en.json`, `de.json`).
- En cas de chargement réussi, les traductions sont retournées ; sinon, une erreur est journalisée.

2. **Enregistrement des traductions** :

- Le greffon s'accroche à l'événement `i18n:register` avec `nuxtApp.hook`.
- Lorsque l'événement est déclenché, la fonction `register` est appelée avec les traductions chargées et la langue correspondante.
- Cela fusionne les nouvelles traductions dans le contexte i18n pour la langue spécifiée, en mettant à jour les traductions disponibles dans toute l'application.

### 🔗 Avantages d'utiliser des greffons pour la modification des traductions

- **Séparation des responsabilités** :
  - Encapsule la logique de localisation à part du code principal de l'application, ce qui facilite la gestion et l'entretien.

- **Dynamique et évolutif** :
  - En chargeant et en enregistrant dynamiquement les traductions, vous pouvez mettre à jour le contenu sans nécessiter un redéploiement complet de l'application, ce qui est particulièrement utile pour les applications au contenu fréquemment mis à jour ou multilingue.

- **Souplesse de localisation améliorée** :
  - Les greffons vous permettent de modifier ou d'étendre les traductions au besoin, offrant une stratégie de localisation plus adaptable et réactive qui répond aux préférences des utilisateurs ou aux exigences d'affaires.

En adoptant cette approche, vous pouvez étendre et modifier efficacement la localisation de votre application à travers un processus structuré et maintenable au moyen de greffons, en gardant l'internationalisation adaptée aux besoins changeants et en améliorant l'expérience utilisateur globale.
