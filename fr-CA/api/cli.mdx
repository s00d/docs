Le [guide de la CLI](/fr-CA/guide/cli) présente les flux de travail courants. Cette page liste tout, et elle est générée à partir de la même table qui alimente `--help`.

## Options communes {#common-flags}

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--cwd` | répertoire courant | Répertoire du projet |
| `--logLevel` | `info` | Niveau de sortie : silent, info |
| `--debug` | `false` | Afficher une trace de pile quand une commande échoue |

## Inspection {#inspect}

### `info` {#info}

Afficher la configuration i18n résolue du projet

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--json` | `false` | Afficher du JSON au lieu de texte |

### `check` {#check}

Le contrôle d'intégration continue : échoue sur les clés manquantes, vides, en trop, non définies ou inutilisées et sur les espaces réservés brisés

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Répertoire des traductions, relatif au projet |
| `--only` | toutes sauf duplicates | Vérifications à exécuter, séparées par des virgules : missing, empty, extra, placeholders, undefined, unused, duplicates. `unused` nommée ici échoue quand elle ne peut pas s'exécuter |
| `--duplicates` | `false` | Signaler aussi le même texte sous des clés différentes |
| `--ignore` | — | Globs de fichiers sources à ignorer, séparés par des virgules, relatifs au projet |
| `--json` | `false` | Afficher du JSON au lieu de texte |

```bash
i18n-micro check
i18n-micro check --only missing,placeholders --json
```

### `stats` {#stats}

Afficher le taux d'achèvement des traductions par locale

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Répertoire des traductions, relatif au projet |
| `--html` | — | Écrire aussi un rapport HTML dans ce fichier |
| `--json` | `false` | Afficher du JSON au lieu de texte |
| `--baseRef` | — | Référence Git avec laquelle comparer l'achèvement, p. ex. HEAD~1 ou main |

```bash
i18n-micro stats --baseRef main
i18n-micro stats --html reports/i18n.html
```

### `lint` {#lint}

Vérifier le texte des traductions; échoue quand des problèmes subsistent

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Répertoire des traductions, relatif au projet |
| `--rules` | toutes, ou `enabledRules` de .i18n-lintrc.json | Règles à exécuter, séparées par des virgules : no-trailing-spaces, no-multiple-spaces, no-empty-translation, ou une règle personnalisée |
| `--fix` | `false` | Corriger ce qui peut l'être : les espaces, et les règles personnalisées dotées d'un remplacement |
| `--json` | `false` | Afficher du JSON au lieu de texte |

```bash
i18n-micro lint --rules no-trailing-spaces --fix
```

### `search` {#search}

Rechercher des clés et des valeurs, et montrer où chaque clé est utilisée

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Répertoire des traductions, relatif au projet |
| `<query>` | — | Texte ou clé à rechercher |
| `--caseSensitive` | `false` | Respecter la casse |
| `--onlyUnused` | `false` | Seulement les clés que `clean` supprimerait; la requête devient facultative |
| `--scope` | `all` | Où chercher : global, pages, all |
| `--limit` | — | Renvoyer au plus ce nombre de clés |
| `--ignore` | — | Globs de fichiers sources à ignorer, séparés par des virgules, relatifs au projet |
| `--json` | `false` | Afficher du JSON au lieu de texte |

```bash
i18n-micro search "Welcome"
i18n-micro search --onlyUnused
```

## Flux de traduction {#translation-workflow}

### `extract` {#extract}

Lister les clés utilisées par les fichiers sources qui n'ont pas encore de texte, et ajouter celles qui ont un texte par défaut à la locale par défaut

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Répertoire des traductions, relatif au projet |
| `--ignore` | — | Globs de fichiers sources à ignorer, séparés par des virgules, relatifs au projet |

```bash
i18n-micro extract
```

### `translate` {#translate}

Remplir les traductions manquantes à partir de la locale par défaut au moyen d'un service de traduction

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Répertoire des traductions, relatif au projet |
| `--service` | — | Service de traduction : ai, azure, deepl, google, libretranslate, yandexcloud |
| `--token` | — | Clé d'API. Privilégiez la variable d'environnement I18N_TRANSLATE_TOKEN : les options aboutissent dans l'historique du shell |
| `--options` | — | Options du service sous forme de paires clé:valeur, séparées par des virgules |
| `--locale` | toutes les locales sauf celle par défaut | Locales à remplir, séparées par des virgules |
| `--replace` | `false` | Retraduire chaque clé en remplaçant les valeurs existantes |
| `--dryRun` | `false` | Compter les clés et les caractères par locale; ne rien envoyer |
| `--chunkSize` | — | Chaînes par requête; plafonné à ce que le service accepte |
| `--pluralSeparator` | `\|` | Séparateur des formes plurielles dans les messages |
| `--glossaryFile` | `.i18n-glossary.json` s'il existe | Fichier de glossaire, utilisé par le service `ai` |

```bash
i18n-micro translate --dryRun
I18N_TRANSLATE_TOKEN=... i18n-micro translate --service deepl --locale de,fr
i18n-micro translate --service ai --options provider:openai,model:gpt-4o-mini
i18n-micro translate --service libretranslate --options baseUrl:https://translate.example.com
```

### `sync` {#sync}

Supprimer les clés que la locale par défaut n'a pas; s'arrête quand on ne peut pas prouver que c'est sans risque. Les clés manquantes restent manquantes

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Répertoire des traductions, relatif au projet |
| `--ignore` | — | Globs de fichiers sources à ignorer, séparés par des virgules, relatifs au projet |
| `--dryRun` | `false` | Lister ce qui serait supprimé; ne rien écrire |
| `--force` | `false` | Supprimer les clés même si on ne peut pas prouver que c'est sans risque |

```bash
i18n-micro sync --dryRun
```

### `clean` {#clean}

Supprimer les clés que rien n'utilise dans le projet; s'arrête quand on ne peut pas le prouver

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Répertoire des traductions, relatif au projet |
| `--include` | — | Expression régulière : ne considérer pour la suppression que les clés correspondantes |
| `--exclude` | — | Expression régulière : ne jamais supprimer les clés correspondantes |
| `--ignore` | — | Globs de fichiers sources à ignorer, séparés par des virgules, relatifs au projet |
| `--dryRun` | `false` | Lister ce qui serait supprimé; ne rien écrire |
| `--force` | `false` | Supprimer les clés même si leur utilisation ne peut pas être prouvée pour toutes |

```bash
i18n-micro clean --dryRun
i18n-micro clean --exclude '^errors\.'
```

## Refactorisation {#refactoring}

### `text-to-i18n` {#text-to-i18n}

Remplacer le texte codé en dur dans les gabarits Vue par des appels de traduction, et signaler le texte codé en dur dans le code

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--translationFile` | `<translationDir>/<defaultLocale>.json` | Fichier où vont les nouvelles clés |
| `--path` | tout le projet | Fichier ou répertoire à traiter |
| `--context` | — | Préfixe des clés générées |
| `--ignore` | — | Globs de fichiers sources à ignorer, séparés par des virgules, relatifs au projet |
| `--dryRun` | `false` | Montrer ce qui changerait; ne rien écrire |
| `--interactive` | `false` | Confirmer ou modifier chaque clé générée |

```bash
i18n-micro text-to-i18n --dryRun
i18n-micro text-to-i18n --path components --context ui
```

### `rename` {#rename}

Renommer une clé ou un espace de noms dans chaque locale et dans les fichiers sources

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Répertoire des traductions, relatif au projet |
| `--from` **\*** | — | Clé ou espace de noms actuel |
| `--to` **\*** | — | Nouvelle clé ou nouvel espace de noms |
| `--ignore` | — | Globs de fichiers sources à ignorer, séparés par des virgules, relatifs au projet |
| `--dryRun` | `false` | Signaler les changements; ne rien écrire |

**\*** obligatoire.

```bash
i18n-micro rename --from common.save --to actions.save
```

### `pseudo` {#pseudo}

Remplir une locale de pseudo-traductions pour repérer les problèmes de mise en page et de texte codé en dur

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Répertoire des traductions, relatif au projet |
| `--sourceLocale` | la locale par défaut | Locale à lire |
| `--targetLocale` **\*** | — | Locale à remplir |
| `--replace` | `false` | Écraser les valeurs existantes |

**\*** obligatoire.

### `format` {#format}

Réécrire les fichiers de locale avec des clés triées et une indentation uniforme

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Répertoire des traductions, relatif au projet |
| `--indent` | `2` | Espaces d'indentation |
| `--sortKeys` | `true` | Trier les clés; utilisez --no-sortKeys pour conserver leur ordre |
| `--check` | `false` | Échouer si un fichier changerait; ne rien écrire |

```bash
i18n-micro format --check
```

## Échange {#exchange}

### `export` {#export}

Exporter les fichiers de locale en PO ou en CSV, avec le texte de la locale par défaut comme source

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Répertoire des traductions, relatif au projet |
| `--format` | `po` | Format de fichier : po, csv |
| `--dir` | `pots` pour po, `csv_exports` pour csv | Répertoire de sortie, relatif au projet |
| `--force` | `false` | Écraser les fichiers modifiés depuis la dernière exportation et jamais importés |

```bash
i18n-micro export --format csv
```

### `import` {#import}

Fusionner des fichiers PO ou CSV dans les fichiers de locale

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Répertoire des traductions, relatif au projet |
| `--format` | `po` | Format de fichier : po, csv |
| `--dir` | `pots` pour po, `csv_exports` pour csv | Répertoire d'entrée, relatif au projet |
| `--dryRun` | `false` | Signaler ce qui serait importé; ne rien écrire |

```bash
i18n-micro import --format csv --dryRun
```

### `sync-remote` {#sync-remote}

Récupérer les traductions globales depuis le point de terminaison HTTP de .i18n-remote.json, ou les y pousser

| Option | Valeur par défaut | Description |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Répertoire des traductions, relatif au projet |
| `--pull` | `true` | Récupérer depuis le serveur distant |
| `--push` | `false` | Pousser vers le serveur distant |
| `--force` | `false` | Lors d'une récupération, prendre la valeur distante; lors d'un envoi, écraser le texte que seul le serveur distant possède |
| `--dryRun` | `false` | Signaler ce qu'une récupération changerait; ne rien écrire ni pousser |

```bash
i18n-micro sync-remote --dryRun
i18n-micro sync-remote --no-pull --push
```

## Règles de lint {#lint-rules}

| Règle | Détecte | Corrigée par `--fix` |
| --- | --- | --- |
| `no-trailing-spaces` | Des espaces à la fin d'une valeur ou d'une ligne | oui |
| `no-multiple-spaces` | Deux espaces consécutifs ou plus | oui |
| `no-empty-translation` | Une valeur vide ou blanche | non |

## Codes de sortie {#exit-codes}

| Code | Signification |
| --- | --- |
| `0` | Terminé, rien à signaler |
| `1` | Constats : `check`, `lint` ou `format --check` a trouvé quelque chose, `clean` ou `sync` n'a pas pu prouver qu'une suppression était sans risque, `export` écraserait du travail non importé, `translate` a laissé des clés de côté, `import` ou `sync-remote` a rencontré un conflit, un envoi `sync-remote` supprimerait du texte distant. Un `--dryRun` de `clean`, de `sync` ou d'une récupération `sync-remote` signale ces cas et se termine avec `0` |
| `2` | Échec : mauvaise utilisation, projet illisible, erreur réseau ou de fichier |

## Fichiers de configuration {#configuration-files}

| Fichier | Utilisé par |
| --- | --- |
| `.i18n-lintrc.json` | `lint` : `enabledRules`, `disabledRules`, `customRegexRules` (`name`, `pattern`, `flags`, `description`, `replacement`) |
| `.i18n-remote.json` | `sync-remote` : `url`, `path`, `token`, `auth` (`username`, `password`). `type` peut être omis; seul `custom` existe |
| `.i18n-glossary.json` | `translate --service ai` : `entries` composées de `source`, `target`, et facultativement `from`, `to` |

## Variables d'environnement {#environment-variables}

| Nom | Utilisée pour |
| --- | --- |
| `I18N_TRANSLATE_TOKEN` | Clé d'API de `translate`. Lue aussi depuis `.env` |
| `I18N_REMOTE_TOKEN` | Jeton Bearer de `sync-remote`. Lu aussi depuis `.env` |
| `AI_GATEWAY_API_KEY, OPENAI_API_KEY, ANTHROPIC_API_KEY` | Clé du service `ai`, quand `I18N_TRANSLATE_TOKEN` n'est pas défini |
| `DEFAULT_LOCALE` | Remplace `defaultLocale`, comme dans le module |
