# 🌍 Composant `<i18n-switcher>`

Le composant `<i18n-switcher>` de `Nuxt I18n Micro` fournit une interface conviviale en menu déroulant pour basculer entre différentes langues dans votre application. Ce composant est hautement personnalisable, ce qui permet une intégration fluide avec la conception et la disposition de votre application.

Les langues avec `disabled: true` sont **omises** du menu déroulant (elles restent disponibles via `$getLocales()` pour le SEO et les balises head). Seules les langues commutables reçoivent `NuxtLink` + `hreflang`.

Chaque partie est sans style par défaut : les props `custom*Style` prennent des objets de style en ligne, et les fentes ci-dessous remplacent complètement le balisage quand le style ne suffit pas.

## 🛠️ Exemples d'utilisation

### Utilisation de base

```vue
<template>
  <i18n-switcher />
</template>
```

Cela affiche un sélecteur de langue avec le style et le comportement par défaut.

### Libellés personnalisés et styles en ligne

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Cet exemple montre un sélecteur de langue entièrement personnalisé avec des libellés personnalisés et des styles en ligne.

## 🔌 Fentes

Chaque partie visuelle du sélecteur peut être remplacée. Les fentes sont listées avec le tableau de props ci-dessus; chacune prend du contenu de modèle :

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Les fentes dont le nom se termine par `-item`, `-link-content` ou commence par `before-item` reçoivent l'objet `locale` auquel elles appartiennent.

## 🎨 Aperçu des styles

Le composant `<i18n-switcher>` est livré avec des styles de base définis en ligne, faciles à remplacer en passant des styles personnalisés via des props. Voici un bref aperçu du style par défaut :

- **Wrapper** : contrôle le positionnement du menu déroulant.
- **Bouton** : styles le bouton de bascule du menu déroulant.
- **Menu déroulant** : styles la liste déroulante.
- **Éléments** : styles chaque élément de la liste.
- **Liens** : styles les liens à l'intérieur de chaque élément.
- **Icône** : styles l'icône d'indicateur du menu déroulant.

Vous pouvez personnaliser ces styles en passant des styles personnalisés via les props correspondantes, garantissant que le sélecteur de langue s'intègre parfaitement à l'interface utilisateur de votre application.
