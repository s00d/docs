# 🌍 Composant `<i18n-switcher>`

Le composant `<i18n-switcher>` dans `Nuxt I18n Micro` offre une interface conviviale de liste déroulante pour changer entre différentes langues dans votre application. Ce composant est très personnalisable, ce qui permet une intégration transparente avec la conception et la mise en page de votre application.

Les langues avec `disabled: true` sont **omises** de la liste déroulante (elles restent disponibles via `$getLocales()` pour le SEO / les balises head). Seules les langues commutables reçoivent `NuxtLink` + `hreflang`.

Chaque partie est non stylisée par défaut : les props `custom*Style` prennent des objets de style en ligne, et
les créneaux ci-dessous remplacent entièrement le balisage lorsque le stylage ne suffit pas.

## 🛠️ Exemples d'utilisation

### Utilisation de base

```vue
<template>
  <i18n-switcher />
</template>
```

Cela rend un sélecteur de langue avec le style et le comportement par défaut.

### Étiquettes personnalisées et styles en ligne

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Cet exemple montre un sélecteur de langue entièrement personnalisé avec des étiquettes personnalisées et des styles en ligne.

## 🔌 Créneaux

Chaque partie visuelle du sélecteur peut être remplacée. Les créneaux sont énumérés avec le tableau des props
ci-dessus ; chacun prend du contenu de gabarit :

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Les créneaux dont le nom se termine par `-item`, `-link-content` ou commence par `before-item` reçoivent
l'objet `locale` auquel ils appartiennent.

## 🎨 Aperçu des styles

Le composant `<i18n-switcher>` est livré avec des styles de base définis en ligne, qui peuvent facilement être remplacés en passant des styles personnalisés via les props. Voici un bref aperçu du stylage par défaut :

- **Enveloppe** : contrôle le positionnement de la liste déroulante.
- **Bouton** : stylise le bouton de bascule de la liste déroulante.
- **Liste déroulante** : stylise la liste déroulante.
- **Éléments** : stylise chaque élément dans la liste.
- **Liens** : stylise les liens à l'intérieur de chaque élément.
- **Icône** : stylise l'icône d'indicateur de la liste déroulante.

Vous pouvez personnaliser ces styles en passant des styles personnalisés via les props respectives, garantissant que le sélecteur de langue s'intègre parfaitement à l'interface utilisateur de votre application.
