# 🌍 Composant `<i18n-link>`

Le composant `<i18n-link>` de `Nuxt I18n Micro` est un composant de lien polyvalent qui localise automatiquement les routes selon la langue active. Il agit comme une enveloppe autour du composant `<NuxtLink>`, offrant des fonctionnalités supplémentaires comme le style de lien actif et la prise en charge des liens externes.

## ⚙️ Props

| Prop | Type | Valeur par défaut | Description |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | Route cible. Localisée automatiquement; une URL externe est transmise sans modification. |
| `activeStyle` | `Partial<CSSStyleValue>` | — | Style en ligne appliqué lorsque le lien pointe vers la route courante. |

**\*** obligatoire.

### Fentes

| Fente | Bindings | Description |
| --- | --- | --- |
| `default` | — | Contenu du lien. |

{/* /generated:component:i18n-link */}

`to` accepte tout ce que `NuxtLink` accepte : un chemin, une route nommée ou un objet de route résolu. Une URL absolue est détectée et rendue comme un simple `<a target="_blank" rel="noopener noreferrer">` plutôt que d'être localisée.

## 🛠️ Exemples d'utilisation

### Utilisation de base

```vue
<i18n-link to="/about">About Us</i18n-link>
```

Cet exemple crée un lien vers la page `/about`, localisé selon la langue active.

### Style de lien actif avec styles en ligne

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

Le lien sera en gras lorsque l'utilisateur se trouve sur la page `/about`, ce qui vous permet de styliser directement le lien actif avec des styles en ligne.

### Gestion des liens externes

Le composant détecte automatiquement les liens externes et ajoute les attributs nécessaires à la sécurité.

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

Ce lien ouvrira `https://example.com` dans un nouvel onglet avec l'attribut `rel="noopener noreferrer"` appliqué.

## 🎨 Styles

Le composant utilise désormais des styles en ligne pour l'état actif plutôt qu'une classe. Vous pouvez personnaliser ces styles à l'aide de la prop `activeStyle`.

### Styles actifs par défaut

- **Poids de la police** : `bold`
- **Couleur** : hérite de la couleur par défaut du navigateur (si aucune `color` n'est spécifiée dans `activeStyle`).

Vous pouvez les remplacer en fournissant des styles personnalisés via la prop `activeStyle`.

### Styles actifs personnalisés

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

Dans cet exemple, le lien sera en gras et en vert lorsqu'il est actif.

## 🚀 Fonctionnalités supplémentaires

### Fente pour du contenu personnalisé

Vous pouvez passer du contenu personnalisé à l'intérieur du lien à l'aide de fentes, rendant le composant flexible pour différents cas d'utilisation.

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### Améliorations d'accessibilité

Le composant prend en charge `aria-label` et d'autres attributs d'accessibilité pour offrir une expérience plus accessible.

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
