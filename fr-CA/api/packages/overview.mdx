# API des paquets

`nuxt-i18n-micro` est bâti à partir d'un ensemble de petits paquets, dont la plupart sont utilisables de manière autonome — `@i18n-micro/vue` dans une application Vue simple, `@i18n-micro/core` n'importe où.

Chaque page ci-dessous est générée à partir de l'instantané d'API que [`pnpm run api:surface`](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/maintenance-commands.md#api-surface) compare aux sources TypeScript ; ainsi, une exportation ne peut pas disparaître sans que cette référence ne change ou que la CI n'échoue.
