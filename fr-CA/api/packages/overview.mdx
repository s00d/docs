title: "API des paquets"
description: "L'API exportée de chaque paquet @i18n-micro/*, générée à partir des instantanés d'API que la CI vérifie par rapport au code source."
---

Le module Nuxt est construit à partir de petits paquets `@i18n-micro/*`, et la plupart fonctionnent de façon autonome : `@i18n-micro/vue` dans une application Vue, `@i18n-micro/core` n'importe où. Utilisez ces pages pour consulter ce qu'un paquet exporte, par point d'entrée. Chaque page est générée à partir de l'instantané que [`pnpm run api:surface`](https://s00d.github.io/nuxt-i18n-micro/contributing/maintenance-commands#api-surface) vérifie par rapport aux sources TypeScript, de sorte qu'un export ne peut pas changer sans que la CI s'en aperçoive.
