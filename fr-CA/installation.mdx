## Prérequis

- **Node.js** : 18 ou plus récent.
- **Nuxt** : 3.x ou 4.x.

Le module prend en charge la disposition de projet Nuxt 3 (`pages/**/*.vue`) ainsi que celle de Nuxt 4 (`app/pages/**/*.vue`). Par convention, les traductions se trouvent à la racine du projet (`locales/`), même lorsque vous utilisez le répertoire `app/` de Nuxt 4.

## Installer le module Nuxt

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Enregistrez-le dans `nuxt.config.ts` :

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Consultez le [Démarrage rapide](/quickstart) pour une visite guidée complète ou la [Référence de configuration](/guides/configuration) pour toutes les options.

## Disposition du projet

Par défaut, le module s'attend à ceci :

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Les fichiers à la racine sont fusionnés dans chaque fichier propre à une page au moment de la compilation. Les fichiers propres à une page sont créés automatiquement lorsqu'ils sont absents pendant `nuxt dev`.

## Disposition Nuxt 4

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Pour colocaliser les traductions sous `app/`, définissez `translationDir: 'app/locales'`.

## Paquets de l'écosystème

| Paquet | Rôle |
| --- | --- |
| [`@i18n-micro/vue`](/integrations/vue) | Intégration Vue 3 (autonome, sans Nuxt). |
| [`@i18n-micro/react`](/integrations/react) | Intégration React. |
| [`@i18n-micro/preact`](/integrations/preact) | Intégration Preact. |
| [`@i18n-micro/solid`](/integrations/solid) | Intégration SolidJS. |
| [`@i18n-micro/astro`](/integrations/astro) | Intégration Astro. |
| [`@i18n-micro/node`](/integrations/nodejs) | Chargeur côté serveur pour Node.js. |
| [`@i18n-micro/types-generator`](/integrations/types-generator) | Génération de types TypeScript à partir des fichiers de traduction. |
| [`@i18n-micro/devtools-ui`](/integrations/devtools-ui) | Panneau DevTools indépendant du cadriciel. |

Les paquets internes partagés sont importés de manière transitive.

## TypeScript

Le module génère des types ambiants pour `useI18n`, `$t` et les assistants associés à partir de vos fichiers de la langue par défaut. Cette option est activée par défaut (`types: true`).

Pour un typage plus fort des clés de traduction, consultez [`@i18n-micro/types-generator`](/integrations/types-generator).
