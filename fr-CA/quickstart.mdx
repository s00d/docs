## 🚀 Démarrage rapide

### Installation

Installez le module dans votre application Nuxt :

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

### Configuration de base

Ajoutez le module à votre `nuxt.config.ts` :

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

<Tip>
- **Fichiers à la racine** (`locales/en.json`, etc.) : traductions partagées dans toute l'application (menus, pied de page, interface commune). Avec `translationPayloads.mode: 'premerged'` (par défaut), elles sont fusionnées dans chaque page au moment de la compilation.
- **Fichiers propres à une page** (`locales/pages/<route>/<locale>.json`) : traductions propres à des pages spécifiques, chargées uniquement lors de la visite de la page.
- **Routes dynamiques** : `pages/articles/[id].vue` correspond à `locales/pages/articles-id/` (les crochets sont remplacés par des tirets).
- **Génération automatique** : tous les fichiers de traduction manquants sont créés automatiquement pendant `nuxt dev`.
</Tip>

<Info>
Le module prend en charge les deux dispositions :

- **Pages** : `pages/**/*.vue` (Nuxt 3) ou `app/pages/**/*.vue` (Nuxt 4)
- **Traductions** : conservez `locales/` à la **racine du projet** par défaut (convention recommandée), pas à l'intérieur de `app/`

```tree
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   ├── en.json
│   └── pages/
└── nuxt.config.ts
```

Colocation facultative : `i18n: \{ translationDir: 'app/locales' \}` (voir la [fixture `n3`](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/n3)).

Pour l'assistant CLI facultatif `text-to-i18n`, utilisez [`nuxt-i18n-micro-cli` ≥ 2.1.1](/guides/cli#-text-to-i18n-command) afin que `app/pages` et `app/components` soient analysés depuis la racine du projet.
</Info>

### Utilisation de base

Utilisez les traductions dans vos composants :

```vue
<template>
  <div>
    <h1>{{ $t('welcome') }}</h1>
    <p>{{ $t('description', { name: 'World' }) }}</p>

    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" @click="$switchLocale(locale.code)">
        {{ locale.code }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useI18n } from '#imports'

const { $t, $getLocales, $switchLocale } = useI18n()
</script>
```
