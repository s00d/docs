# Utiliser les traductions dans les composants

Une fois le module installé et configuré, vous pouvez afficher les traductions en appelant `$t('votre_cle')` dans vos gabarits et scripts Vue.

## 1. Fichiers de traduction racines et propres aux pages

1. Les traductions **de niveau racine** résident directement sous le dossier `/locales` (p. ex. `/locales/en.json`, `/locales/fr.json`). À la compilation, elles sont automatiquement fusionnées dans chaque fichier propre à une page, ce qui les rend disponibles dans toutes les pages.
2. Les traductions **propres aux pages** se trouvent sous `/locales/pages/...`, en suivant la structure de vos dossiers de pages Nuxt :

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. Utilisation dans le gabarit avec `$t`

Dans vos fichiers `.vue`, vous pouvez utiliser directement `$t` dans le gabarit :

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
`$t` peut retourner des **objets** si la clé pointe vers un nœud JSON imbriqué (p. ex. `$t('header')` → `\{ title: "Hi" \}`). Dans les gabarits, cela s'affiche sous la forme `[object Object]`. Utilisez `$ts` lorsqu'une chaîne de caractères garantie est nécessaire, ou fournissez une clé plus précise comme `$t('header.title')`. Consultez [la référence de l'API — $t vs $ts](/api/methods#t) pour plus de détails.
</Tip>

## 3. Changer la langue courante

Pour changer la langue dans votre application, vous pouvez récupérer `$locale` depuis `useI18n()` et lui assigner un nouveau code :

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. Clés imbriquées et espaces réservés

- Les **clés imbriquées** utilisent la notation par point, p. ex. `nested.key.deeper`.
- Les **espaces réservés** vous permettent d'insérer des valeurs dynamiques :
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. Trucs et bonnes pratiques

- **Clés en conflit** : si un fichier propre à une page contient la même clé qu'un fichier racine, la version propre à la page a la priorité (les traductions racines sont fusionnées comme base à la compilation).
- **Désactiver les fichiers par page** : si vous préférez ne pas utiliser les traductions propres aux pages, vous pouvez définir `disablePageLocales: true` dans votre configuration Nuxt. De cette façon, seuls les fichiers `/locales/*.json` seront utilisés.
- **Pas d'importation directe** : vous n'avez pas besoin de faire `import \{ useI18n \} from 'nuxt-i18n-micro'`; la fonction d'auto-injection du module s'en charge pour vous.

Voilà ! Avec ces étapes, vous pouvez rapidement **commencer à récupérer les traductions** depuis les fichiers JSON racines ou propres aux pages et **les afficher** dans votre application Nuxt à l'aide de `$t`.

## Ressources supplémentaires

Pour explorer des fonctionnalités plus avancées, consultez :

1. **Composant `<i18n-t>`**  
   Le composant `<i18n-t>` est une alternative puissante à `$t`, particulièrement utile dans les situations impliquant des éléments imbriqués, une utilisation avancée des espaces réservés et des structures de traduction plus complexes.

- **Documentation** : [i18n-t](/api/components/i18n-t)

2. **Composable `useI18n`**  
   Le composable `useI18n` offre un ensemble complet de fonctions et de propriétés réactives pour gérer les traductions, le changement de langue, le formatage, et plus encore.

- **Documentation** : [useI18n](/api/composables/use-i18n)
