# 🌐 Guide d'intégration Crowdin

## 📖 Introduction

Intégrer Crowdin à votre projet simplifie le processus de localisation et de traduction, ce qui facilite la gestion des traductions à travers plusieurs langues et plateformes. Ce guide propose une visite guidée étape par étape pour la configuration de Crowdin avec votre projet, y compris la configuration, le téléversement des sources et le téléchargement des traductions.

## 🔧 Installation et configuration

Pour démarrer avec Crowdin, vous devrez installer la CLI Crowdin globalement sur votre machine et l'initialiser dans le répertoire de votre projet.

### 📦 Installer la CLI Crowdin

Installez d'abord la CLI Crowdin globalement avec npm :

```bash
npm install -g @crowdin/cli
```

### 🛠 Initialiser Crowdin dans votre projet

Initialisez Crowdin dans votre projet en exécutant :

```bash
crowdin init
```

Cette commande vous guidera à travers la configuration, notamment la définition de votre identifiant de projet, du jeton API et des autres détails de configuration.

## 🗂️ Guide de configuration

### 📄 Fichier de configuration Crowdin (`crowdin.yml`)

Le fichier de configuration Crowdin (`crowdin.yml`) définit la correspondance de vos fichiers sources et l'emplacement des traductions. Voici un exemple de configuration :

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Paramètres de configuration clés

- **`project_id`** : votre identifiant de projet Crowdin. Il identifie le projet dans Crowdin où sont gérées les traductions.
- **`api_token`** : le jeton API utilisé pour l'authentification. Assurez-vous que ce jeton possède les bonnes permissions pour téléverser et télécharger des traductions.
- **`base_path`** : spécifie le répertoire de base des fichiers sources. Dans cet exemple, les traductions sont stockées dans le répertoire `./locales`.
- **`base_url`** : l'URL de base de l'API Crowdin.
- **`preserve_hierarchy`** : lorsqu'il est défini à `true`, Crowdin conservera la structure de dossiers de vos fichiers sources dans le projet.

### 📂 Configuration des fichiers

La section `files` associe vos fichiers sources aux chemins où les traductions seront stockées. Par exemple :

- **Chemin source** : définit l'emplacement des fichiers de traduction d'origine.
- **Chemin de traduction** : spécifie où les fichiers traduits seront stockés dans Crowdin. Des espaces réservés comme `%two_letters_code%` sont utilisés pour définir dynamiquement le code de langue dans les chemins de fichiers.

## ⬆️ Téléverser les fichiers sources vers Crowdin

Une fois votre configuration Crowdin en place, vous pouvez téléverser vos fichiers sources avec la commande suivante :

```bash
crowdin upload sources
```

Cette commande téléverse vers Crowdin tous les fichiers sources spécifiés dans votre configuration, les rendant disponibles pour la traduction.

## ⬇️ Télécharger les traductions depuis Crowdin

Une fois les traductions terminées ou mises à jour dans Crowdin, vous pouvez les télécharger dans votre projet avec :

```bash
crowdin download
```

Cette commande récupère les traductions les plus récentes depuis Crowdin et les enregistre selon les chemins spécifiés dans votre fichier de configuration.

## ⚙️ Bonnes pratiques

### 🔑 Nommage cohérent des clés

Assurez-vous que les clés de traduction soient cohérentes dans tous les fichiers, afin d'éviter la confusion et les doublons.

### 🧹 Entretien régulier

Passez périodiquement en revue et nettoyez les clés de traduction inutilisées pour garder vos fichiers organisés et faciles à gérer.

### 🛠 Automatiser les téléversements et téléchargements

Intégrez les commandes de la CLI Crowdin dans votre pipeline CI/CD pour automatiser le téléversement des fichiers sources et le téléchargement des traductions, afin que vos traductions soient toujours à jour.

En suivant ce guide, vous pourrez intégrer Crowdin à votre projet de façon transparente, en assurant une approche efficace et organisée pour gérer vos efforts d'internationalisation.
