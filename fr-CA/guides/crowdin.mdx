# 🌐 Guide d'intégration Crowdin

## 📖 Introduction

Intégrer Crowdin dans votre projet simplifie les processus de localisation et de traduction, ce qui facilite la gestion des traductions dans plusieurs langues et sur plusieurs plateformes. Ce guide propose une marche à suivre pour configurer Crowdin avec votre projet, y compris la configuration, le téléversement des sources et le téléchargement des traductions.

## 🔧 Installation et configuration

Pour commencer avec Crowdin, vous devez installer le CLI Crowdin globalement sur votre machine et l'initialiser dans le répertoire de votre projet.

### 📦 Installer le CLI Crowdin

Installez d'abord le CLI Crowdin globalement avec npm :

```bash
npm install -g @crowdin/cli
```

### 🛠 Initialiser Crowdin dans votre projet

Initialisez Crowdin dans votre projet en exécutant :

```bash
crowdin init
```

Cette commande vous guidera à travers le processus de configuration, incluant votre ID de projet, le jeton API et d'autres détails de configuration.

## 🗂️ Guide de configuration

### 📄 Fichier de configuration Crowdin (`crowdin.yml`)

Le fichier de configuration Crowdin (`crowdin.yml`) définit comment vos fichiers sources sont mappés et où les traductions doivent être placées. Voici un exemple :

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Paramètres clés de configuration

- **`project_id`** : votre ID de projet Crowdin. Il identifie le projet dans Crowdin où les traductions sont gérées.
- **`api_token`** : le jeton API utilisé pour l'authentification. Assurez-vous que ce jeton possède les autorisations correctes pour téléverser et télécharger des traductions.
- **`base_path`** : spécifie le répertoire de base des fichiers sources. Dans cet exemple, les traductions sont stockées dans le répertoire `./locales`.
- **`base_url`** : l'URL de base de l'API Crowdin.
- **`preserve_hierarchy`** : lorsque défini à `true`, Crowdin conservera la structure de dossiers de vos fichiers sources dans le projet.

### 📂 Configuration des fichiers

La section `files` mappe vos fichiers sources aux chemins où les traductions seront stockées. Par exemple :

- **Chemin source** : définit l'emplacement des fichiers de traduction originaux.
- **Chemin de traduction** : spécifie où les fichiers traduits seront stockés dans Crowdin. Des substituants comme `%two_letters_code%` sont utilisés pour définir dynamiquement le code de langue dans les chemins de fichiers.

## ⬆️ Téléverser des fichiers sources vers Crowdin

Une fois votre configuration Crowdin en place, vous pouvez téléverser vos fichiers sources avec la commande suivante :

```bash
crowdin upload sources
```

Cette commande téléverse tous les fichiers sources spécifiés dans votre configuration vers Crowdin, les rendant disponibles à la traduction.

## ⬇️ Télécharger les traductions depuis Crowdin

Une fois les traductions terminées ou mises à jour dans Crowdin, vous pouvez les télécharger dans votre projet avec :

```bash
crowdin download
```

Cette commande récupère les traductions les plus récentes depuis Crowdin et les enregistre selon les chemins spécifiés dans votre fichier de configuration.

## ⚙️ Bonnes pratiques

### 🔑 Nommage cohérent des clés

Assurez-vous que les clés de traduction sont cohérentes dans tous les fichiers pour éviter confusion et duplication.

### 🧹 Entretien régulier

Passez régulièrement en revue et nettoyez les clés de traduction inutilisées pour garder vos fichiers organisés et faciles à gérer.

### 🛠 Automatiser les téléversements et téléchargements

Intégrez les commandes du CLI Crowdin à votre pipeline d'IC/DC pour automatiser le téléversement des fichiers sources et le téléchargement des traductions, garantissant que vos traductions sont toujours à jour.

En suivant ce guide, vous pourrez intégrer Crowdin dans votre projet en toute fluidité, garantissant une approche efficace et organisée pour gérer vos efforts d'internationalisation.
