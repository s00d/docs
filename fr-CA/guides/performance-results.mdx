# Résultats des tests de performance

## Renseignements sur le projet

- **[plain-nuxt](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/plain-nuxt)** : ./test/fixtures/plain-nuxt
- **[i18n-micro](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/i18n-micro)** : ./test/fixtures/i18n-micro
- **[i18n](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/i18n)** : ./test/fixtures/i18n
- **[CLI](https://github.com/s00d/nuxt-i18n-micro/tree/main/scripts/src/commands/performance.ts)** : `pnpm -C scripts cli performance` / `pnpm test:performance`

### Description

Compare **plain Nuxt** (référence sans module i18n), **i18n-micro** et **`@nuxtjs/i18n` v10.6** sous un même profil de dictionnaire partagé.

Points d'attention : temps de compilation, RSS de pointe, **code vs traductions vs total** déployables, et comportement serveur sous Artillery + Autocannon.

### Notes méthodologiques

- Les mesures sont des **moyennes de 3 exécutions consécutives par fixture** (fixture A ×3, puis B ×3, puis C ×3 — non entrelacées).
- Les **traductions** incluent les fichiers JSON de langue sous `locales/` / `_locales/` / `translations/`, tout ce qui est sous `chunks/raw/`, et les fragments de langue correspondants. Les rapports antérieurs qui montraient `@nuxtjs/i18n` « translations: 0 B » et une énorme colonne « code » comptaient les fragments de messages comme du code d'application.
- **plain-nuxt** sert le même volume de feuilles qu'un JSON statique `public/translations` (et non des importations JS statiques). Sous Artillery, cette référence est très gourmande en E/S ; ce n'est pas une « surcharge i18n », c'est le coût de récupération de gros JSON par requête.

### Exécutions

Toutes les mesures ci-dessous sont des **moyennes sur 3 exécutions**.

Les dictionnaires viennent de `test/fixtures/perf-shared/runtime.json` (écrit par la CLI) afin que les trois fixtures restent alignées.

| Projet | Temps de compilation | Paquet de code | Traductions | Total |

- Profil partagé : 4 langues × 2 pages × ~16,8 k feuilles d'index.
