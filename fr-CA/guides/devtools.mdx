# 🛠️ DevTools dans `nuxt-i18n-micro`

## Vue DevTools (extension de navigateur)

En développement, le module peut enregistrer un inspecteur personnalisé et une frise chronologique **Vue DevTools** via `@vue/devtools-api`. C'est distinct de l'onglet Nuxt DevTools ci-dessous.

| Outil | Idéal pour |
|------|----------|
| **Vue DevTools** | Langue courante en direct, cache de traduction en mémoire, frise chronologique `$t` (`debug: true`), événements de clés manquantes |
| **Onglet Nuxt DevTools** | Édition des fichiers JSON sur disque, aperçu de la configuration, import/export |

Le greffon vue-devtools n'est enregistré que pendant `nuxt dev` (pas dans les compilations de production). L'état de pont réservé au développement dans le greffon principal est éliminé par l'élimination du code mort via `import.meta.dev`.

Désactivez l'intégration au navigateur tout en gardant l'onglet Nuxt :

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

Les événements verbeux de la frise chronologique `$t` nécessitent `debug: true`.

## 📖 Qu'est-ce que Nuxt DevTools ?

DevTools est un assistant de développement puissant, intégré de façon transparente au module `nuxt-i18n-micro`. Il offre une interface intuitive pour gérer les tâches de localisation et de traduction, ce qui rend votre flux de travail plus rapide et plus efficace. Conçu pour les développeurs qui apprécient le confort, Nuxt DevTools comble l'écart entre le codage et la gestion à l'exécution.

## 🌟 Fonctionnalités clés de DevTools dans `nuxt-i18n-micro`

### 1. **Gestion des langues**

Parcourez, sélectionnez et gérez sans effort les langues dans votre application. Que vous travailliez avec une seule langue ou plusieurs, DevTools offre un point central pour gérer tous les paramètres de localisation.

### 2. **Édition des traductions**

Modifiez les fichiers de traduction directement à travers un éditeur JSON intégré. Cela évite le recours à des outils externes et permet des mises à jour et des modifications en temps réel sans interrompre votre flux de travail.

### 3. **Import et export de fichiers**

Simplifiez la gestion des fichiers de traduction :

- **Exporter** : sauvegardez les traductions dans un fichier JSON pour des sauvegardes ou une utilisation externe.
- **Importer** : chargez des fichiers de traduction mis à jour dans le projet pour garder le contenu à jour.

### 4. **Aperçus en temps réel**

Voyez les modifications immédiatement dans l'environnement de développement. Cette fonctionnalité garantit que les traductions et les configurations sont exactes avant la mise en production.

### 5. **Intégration Nuxt transparente**

DevTools fonctionne nativement avec `nuxt-i18n-micro`, ce qui améliore ses capacités sans configuration supplémentaire. Il s'adapte à vos besoins de localisation tout en respectant la structure modulaire et flexible de Nuxt.

## 🛠️ Pourquoi utiliser DevTools ?

Nuxt DevTools est un ajout indispensable pour les projets nécessitant la localisation. Il aide les développeurs à :

- **Gagner du temps** : automatise les tâches répétitives comme la gestion de fichiers et la validation de format.
- **Réduire les erreurs** : offre un environnement sûr et intuitif pour éditer les traductions.
- **Améliorer la collaboration** : permet à des non-développeurs de gérer facilement les traductions.
- **Simplifier les flux de travail** : regroupe plusieurs tâches de localisation dans une seule interface.
