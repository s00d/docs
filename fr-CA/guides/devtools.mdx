# 🛠️ DevTools dans `nuxt-i18n-micro`

## Vue DevTools (extension de navigateur)

En développement, le module peut enregistrer un inspecteur et une chronologie personnalisés dans **Vue DevTools** via `@vue/devtools-api`. C'est distinct de l'onglet Nuxt DevTools ci-dessous.

| Outil | Idéal pour |
|------|----------|
| **Vue DevTools** | Langue active, cache de traduction en mémoire, chronologie de `$t` (`debug: true`), événements de clés manquantes |
| **Onglet Nuxt DevTools** | Modification des fichiers JSON sur disque, vue d'ensemble de la configuration, import/export |

Le plugin vue-devtools est enregistré uniquement pendant `nuxt dev` (pas dans les compilations de production). L'état de pont réservé au dev dans le plugin principal est retiré par l'élimination de code mort `import.meta.dev`.

Désactivez l'intégration navigateur tout en conservant l'onglet Nuxt :

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

Les événements détaillés de chronologie de `$t` requièrent `debug: true`.

## 📖 Qu'est-ce que Nuxt DevTools ?

DevTools est un puissant assistant de développement intégré nativement dans le module `nuxt-i18n-micro`. Il fournit une interface intuitive pour gérer les tâches de localisation et de traduction, rendant votre flux de travail plus rapide et plus efficace. Conçu pour les développeurs qui apprécient la commodité, Nuxt DevTools comble l'écart entre le codage et la gestion à l'exécution.

## 🌟 Fonctionnalités clés de DevTools dans `nuxt-i18n-micro`

### 1. **Gestion des langues**

Parcourez, sélectionnez et gérez facilement les langues de votre application. Que vous travailliez avec une seule langue ou plusieurs, DevTools fournit un point central pour gérer tous les paramètres de localisation.

### 2. **Édition des traductions**

Modifiez les fichiers de traduction directement via un éditeur JSON intégré. Cela élimine le besoin d'outils externes, permettant des mises à jour en temps réel sans interrompre votre flux de travail.

### 3. **Import et export de fichiers**

Simplifiez la gestion des fichiers de traduction :

- **Exporter** : enregistrez les traductions sous forme de fichier JSON pour des sauvegardes ou un usage externe.
- **Importer** : chargez des fichiers de traduction mis à jour dans le projet pour maintenir le contenu à jour.

### 4. **Aperçus en temps réel**

Visualisez les changements immédiatement dans l'environnement de développement. Cette fonctionnalité garantit l'exactitude des traductions et des configurations avant la mise en ligne.

### 5. **Intégration fluide avec Nuxt**

DevTools fonctionne nativement avec `nuxt-i18n-micro`, renforçant ses capacités sans nécessiter de configuration supplémentaire. Il s'adapte à vos besoins de localisation tout en conservant la structure modulaire et flexible de Nuxt.

## 🛠️ Pourquoi utiliser DevTools ?

Nuxt DevTools est un ajout indispensable pour les projets nécessitant de la localisation. Il aide les développeurs à :

- **Gagner du temps** : automatise les tâches répétitives comme la gestion de fichiers et la validation de formats.
- **Réduire les erreurs** : offre un environnement sûr et intuitif pour éditer les traductions.
- **Améliorer la collaboration** : permet aux non-développeurs de gérer facilement les traductions.
- **Rationaliser les flux de travail** : regroupe plusieurs tâches de localisation dans une seule interface.
