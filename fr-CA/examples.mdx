# 📚 Exemples et utilisation de Nuxt I18n Micro

Cette section propose divers exemples démontrant comment utiliser `Nuxt I18n Micro` dans votre application Nuxt.js. Vous verrez comment changer de langue, utiliser les composants `<i18n-link>`, `<i18n-switcher>` et `<i18n-t>`, et gérer dynamiquement les clés de traduction.

## 🛠️ Configuration de base

Voici une configuration de base pour démarrer avec `Nuxt I18n Micro` :

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Changement de langue

### Changer de langue par programme

Cet exemple montre comment changer de langue par programme à l'aide de boutons :

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Exemple de JSON pour le changement de langue

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### Utilisation du composant `<i18n-switcher>`

Le composant `<i18n-switcher>` fournit une liste déroulante pour changer de langue avec des étiquettes personnalisables :

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 📝 Rendu de clés dynamiques à partir des fichiers de traduction

Dans certains cas, vous voudrez itérer sur des clés dynamiques stockées dans vos fichiers de traduction et rendre leurs valeurs conditionnellement. L'exemple ci-dessous montre comment y parvenir avec `Nuxt I18n Micro`.

### Exemple : rendu de clés dynamiques

Cet exemple récupère un tableau de clés à partir d'un chemin de traduction précis (ici, `dynamic`) et itère sur celles-ci. L'existence de chaque clé est vérifiée avec `$has` avant que sa valeur soit rendue avec `$t`.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Exemple de fichier de traduction (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Exemple : rendu de clés dynamiques d'un objet

Dans cet exemple, nous traitons un objet stocké dans votre fichier de traduction. Nous récupérons et itérons sur les clés de l'objet, en rendant dynamiquement à la fois les noms des clés et leurs valeurs associées.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Exemple de fichier de traduction (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 Utilisation de `<i18n-t>` pour les traductions avec créneaux et interpolation

Le composant `<i18n-t>` est utile pour rendre des traductions avec du contenu dynamique et des balises HTML :

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### Exemple de JSON pour `<i18n-t>`

```json
{
  "greeting": "Welcome to the page"
}
```

### Avec interpolation

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### Exemple de JSON pour l'interpolation

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 Utilisation de `$tc` pour la pluralisation

La fonction `$tc` dans `Nuxt I18n Micro` gère la pluralisation en fonction du nombre et des paramètres régionaux. Cela permet d'adapter dynamiquement les messages qui impliquent des quantités, comme des articles, des notifications ou d'autres entités dont le nombre peut varier.

### Exemple : utiliser `$tc` pour la pluralisation

Dans l'exemple suivant, nous affichons un message indiquant le nombre de pommes à l'aide de `$tc`. La clé de traduction gère plusieurs formes de pluriel en fonction du nombre fourni.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### Exemple de JSON pour la pluralisation

Voici comment définir la traduction dans votre fichier JSON pour gérer différentes formes plurielles :

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Explication

- **`$tc('apples', 0)`** : retourne la première forme, utilisée lorsque le nombre est zéro (`"no apples"`).
- **`$tc('apples', 1)`** : retourne la seconde forme, utilisée lorsque le nombre est un (`"one apple"`).
- **`$tc('apples', 10)`** : retourne la troisième forme avec la valeur du nombre, utilisée lorsque le nombre est de deux ou plus (`"10 apples"`).

### Exemple supplémentaire avec pluralisation plus complexe

Si votre application doit gérer des règles de pluralisation plus complexes (par exemple, des cas spécifiques pour zéro, un, deux, quelques-uns, plusieurs, autre), vous pouvez étendre les chaînes de traduction en conséquence :

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`** : peut être configuré pour retourner `"two apples"`.
- **`$tc('apples', 3)`** : peut retourner `"a few apples"`, selon les règles définies pour le nombre.

## 🌐 Utilisation de `$tn` pour le formatage des nombres

La fonction `$tn` formate les nombres selon la langue courante en utilisant l'API `Intl.NumberFormat`. Cela est utile pour afficher les nombres d'une manière qui correspond aux paramètres régionaux de l'utilisateur, comme les devises, les pourcentages ou d'autres formats numériques.

### Exemple : utiliser `$tn` pour le formatage des nombres

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ Utilisation de `$td` pour le formatage des dates et heures

La fonction `$td` formate les dates et heures selon la langue courante en utilisant l'API `Intl.DateTimeFormat`. Cela permet d'afficher les dates et les heures dans des formats familiers à l'utilisateur en fonction de ses paramètres régionaux.

### Exemple : utiliser `$td` pour le formatage des dates et heures

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ Utilisation de `$tdr` pour le formatage des dates relatives

La fonction `$tdr` formate les dates comme des temps relatifs (p. ex. « il y a 5 minutes », « il y a 2 jours ») selon la langue courante en utilisant l'API `Intl.RelativeTimeFormat`. Cela est utile pour afficher les écarts de temps par rapport à la date et à l'heure actuelles.

### Exemple : utiliser `$tdr` pour le formatage des dates relatives

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
