# Paquet DevTools UI (`@i18n-micro/devtools-ui`)

Le paquet `@i18n-micro/devtools-ui` fournit une interface d'outils de développement autonome pour gérer les traductions. Il inclut un plugin Vite pour l'intégration automatique et un système de pont universel pour un support i18n indépendant du cadriciel.

## Aperçu

`@i18n-micro/devtools-ui` est un paquet autonome qui fournit :

- **Plugin Vite** : injection automatique de bouton et points de terminaison API
- **Pont universel** : création de pont indépendant du cadriciel pour toute implémentation i18n
- **Composant Web** : élément personnalisé pour l'interface DevTools
- **Opérations sur les fichiers** : lister, charger et enregistrer les fichiers de traduction via API

## Démarrage rapide

### Configuration du plugin Vite

La façon la plus simple d'utiliser DevTools est via le plugin Vite, qui injecte automatiquement un bouton flottant et fournit tous les points de terminaison API nécessaires :

```typescript
import { defineConfig } from 'vite'
import { i18nDevToolsPlugin } from '@i18n-micro/devtools-ui/vite'

export default defineConfig({
  plugins: [
    // ... other plugins
    i18nDevToolsPlugin({
      base: '/__i18n_api', // Optional: API endpoint base path (default: '/__i18n_api')
      translationDir: 'src/locales', // Optional: translation files directory
      injectButton: true, // Optional: automatically inject floating button (default: true)
    }),
  ],
})
```

### Options du plugin

```typescript
interface DevToolsPluginOptions {
  base?: string // API endpoint base path (default: '/__i18n_api')
  translationDir?: string // Translation files directory (default: 'src/locales')
  injectButton?: boolean // Automatically inject floating button (default: true)
}
```

## Fonctionnalités

### Injection automatique de bouton

Le plugin injecte automatiquement un bouton flottant dans le coin inférieur droit de votre application :

- **Masquage intelligent** : le bouton se cache quand le curseur est loin (>200 px)
- **Visibilité partielle** : même caché, une petite partie reste visible pour un accès facile
- **Animations fluides** : transitions et effets au survol pour une meilleure expérience utilisateur
- **Affichage automatique au survol** : le bouton apparaît complètement quand vous survolez la partie visible

### Points de terminaison API

Le plugin fournit les points de terminaison API suivants :

#### `GET /__i18n_api/files`

Obtenir la liste de tous les fichiers de traduction et la structure de répertoire.

**Réponse :**

```json
{
  "files": ["en.json", "fr.json", "pages/home/en.json"],
  "structure": {
    "en.json": "en.json",
    "fr.json": "fr.json",
    "pages": {
      "home": {
        "en.json": "pages/home/en.json"
      }
    }
  }
}
```

#### `GET /__i18n_api/file?path=...`

Charger un fichier de traduction précis.

**Paramètres de requête :**

- `path` : chemin relatif vers le fichier de traduction (par exemple, `en.json` ou `pages/home/en.json`)

**Réponse :**

```json
{
  "success": true,
  "content": {
    "welcome": "Welcome",
    "hello": "Hello"
  },
  "path": "en.json"
}
```

#### `POST /__i18n_api/save`

Enregistrer le contenu de traduction dans un fichier.

**Corps de la requête :**

```json
{
  "file": "en.json",
  "content": {
    "welcome": "Welcome",
    "hello": "Hello"
  }
}
```

**Réponse :**

```json
{
  "success": true
}
```

#### `GET /__i18n_api/config`

Obtenir la configuration i18n.

**Réponse :**

```json
{
  "defaultLocale": "en",
  "fallbackLocale": "en",
  "locales": [{ "code": "en", "displayName": "English", "iso": "en-US" }],
  "translationDir": "src/locales"
}
```

## Pont universel

Le paquet fournit une fonction de création de pont universelle qui fonctionne avec toute implémentation i18n :

```typescript
import { createBridge } from '@i18n-micro/devtools-ui'
import type { BridgeAdapter } from '@i18n-micro/devtools-ui'

// Create an adapter for your i18n instance
const adapter: BridgeAdapter = {
  getRouteCache: () => i18nInstance.cache.route,
  addTranslations: (locale, content, merge) => {
    i18nInstance.addTranslations(locale, content, merge)
  },
  addRouteTranslations: (locale, routeName, content, merge) => {
    i18nInstance.addRouteTranslations(locale, routeName, content, merge)
  },
  subscribe: (callback) => {
    return i18nInstance.subscribe(callback)
  },
  getCurrentLocale: () => i18nInstance.locale,
  getFallbackLocale: () => i18nInstance.fallbackLocale,
}

// Create bridge
const bridge = createBridge({
  adapter,
  locales: localesConfig,
  defaultLocale: 'en',
  translationDir: 'src/locales',
})
```

### Interface d'adaptateur de pont

```typescript
interface BridgeAdapter {
  // Get translations cache
  // Keys are in format "locale:routeName" (e.g., "en:index", "en:home")
  getRouteCache: () => Record<string, TranslationContent>

  // Add or update translations for a locale
  addTranslations: (locale: string, content: TranslationContent, merge: boolean) => void

  // Add or update route-specific translations
  addRouteTranslations: (locale: string, routeName: string, content: TranslationContent, merge: boolean) => void

  // Subscribe to changes in translations
  subscribe: (callback: () => void) => () => void

  // Get current locale (optional)
  getCurrentLocale?: () => string

  // Get fallback locale (optional)
  getFallbackLocale?: () => string
}
```

## Sécurité

Le plugin inclut des mesures de sécurité :

- **Prévention de traversée de chemin** : tous les chemins de fichiers sont validés pour s'assurer qu'ils restent dans la racine du projet
- **Validation d'extension de fichier** : seuls les fichiers `.json` peuvent être enregistrés
- **Validation de la racine du projet** : les fichiers ne sont accessibles que dans la racine du projet configurée

## Développement vs production

- **Développement uniquement** : le plugin fonctionne uniquement en mode développement (`apply: 'serve'`)
- **Aucun impact en production** : le plugin est automatiquement exclu des compilations de production
- **Aucun surcoût à l'exécution** : aucun code n'est inclus dans les bundles de production

## Exemples

### Implémentation de pont personnalisé

```typescript
import { createBridge } from '@i18n-micro/devtools-ui'
import type { BridgeAdapter } from '@i18n-micro/devtools-ui'

class CustomI18n {
  private cache = {
    root: {},
    route: {},
  }

  addTranslations(locale: string, content: Record<string, unknown>) {
    this.cache.root[locale] = content
  }

  subscribe(callback: () => void) {
    // Your subscription logic
    return () => {} // unsubscribe
  }
}

const customI18n = new CustomI18n()

const adapter: BridgeAdapter = {
  getRouteCache: () => customI18n.cache.route,
  addTranslations: (locale, content) => {
    customI18n.addTranslations(locale, content)
  },
  addRouteTranslations: () => {}, // Not implemented
  subscribe: (callback) => customI18n.subscribe(callback),
}

const bridge = createBridge({
  adapter,
  locales: [{ code: 'en', displayName: 'English' }],
  defaultLocale: 'en',
})
```
