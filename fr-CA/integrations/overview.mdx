# Intégrations

Les paquets `@i18n-micro` sont des versions légères, propres à chaque cadriciel, de Nuxt I18n Micro, conçues pour l'intégration dans divers cadriciels et environnements. Ces paquets fournissent les fonctionnalités d'internationalisation de base avec une empreinte minimale, en se concentrant sur les fonctionnalités essentielles de traduction et sur des composants de base.

## Aperçu

Ces paquets d'intégration sont des **versions miniatures** du module complet Nuxt I18n Micro, contenant uniquement les fonctionnalités essentielles nécessaires à l'internationalisation :

- **Fonctionnalités de traduction de base** : méthodes de traduction de base, pluralisation et formatage
- **Composants essentiels** : un petit ensemble de composants d'interface pour les tâches i18n courantes
- **Motif d'adaptateur de routeur** : intégration de routage flexible via l'abstraction d'adaptateur
- **Prise en charge TypeScript** : définitions de types complètes pour un développement typé

Contrairement au module Nuxt complet, ces paquets :

- N'incluent pas de logique de routage propre à un cadriciel
- Vous demandent d'implémenter un adaptateur de routeur pour les fonctionnalités de routage
- Se concentrent sur la fonctionnalité de traduction plutôt que sur l'intégration au cadriciel
- Sont conçus pour être légers et indépendants du cadriciel autant que possible

## Composants principaux

Tous les paquets de cadriciels incluent les composants essentiels suivants :

### `<I18nT>`

Un composant de traduction qui affiche du texte traduit avec prise en charge de :

- **Interpolation de paramètres** : remplacer les substituants par des valeurs dynamiques
- **Pluralisation** : sélection automatique de la forme plurielle selon le compte
- **Formatage des nombres** : formater les nombres selon la langue
- **Formatage des dates** : formater les dates et les durées relatives
- **Rendu HTML** : rendu de contenu HTML facultatif
- **Valeurs par défaut** : texte de repli quand la traduction est manquante

**Exemple :**

```vue
<!-- Vue -->
<I18nT keypath="greeting" :params="{ name: 'World' }" />
```

```tsx
// React
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```tsx
// Solid
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```astro
<!-- Astro -->
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

### `<I18nLink>`

Un composant de lien localisé qui gère automatiquement les préfixes de langue dans les URL. Fonctionnalités :

- **Localisation automatique de chemin** : ajoute/retire les préfixes de langue selon la stratégie de routage
- **Détection d'état actif** : met en évidence la route courante
- **Support des liens externes** : détecte et gère automatiquement les URL externes
- **Intégration au routeur** : utilise le composant lien de l'adaptateur de routeur quand disponible
- **Style personnalisé** : prend en charge les états actif et survol

**Exemple :**

```vue
<!-- Vue -->
<I18nLink to="/about" active-class="active">
  About Us
</I18nLink>
```

```tsx
// React
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```tsx
// Solid
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```astro
<!-- Astro -->
<I18nLink href="/about" class="nav-link">
  About Us
</I18nLink>
```

### `<I18nSwitcher>`

Un composant de sélecteur de langue qui fournit une interface en menu déroulant ou en liste pour changer de langue. Fonctionnalités :

- **Liste automatique des langues** : génère les options depuis les langues configurées
- **Mise en évidence de la langue courante** : indique visuellement la langue active
- **Libellés personnalisés** : prise en charge de noms d'affichage personnalisés par langue
- **Intégration au routeur** : navigue automatiquement vers les chemins localisés
- **Accessibilité** : attributs ARIA appropriés et navigation au clavier

**Exemple :**

```vue
<!-- Vue -->
<I18nSwitcher />
```

```tsx
// React
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```tsx
// Solid
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```astro
<!-- Astro -->
<I18nSwitcher />
```

### `<I18nGroup>`

Un composant pour regrouper les traductions sous un préfixe commun, utile pour organiser les traductions par page ou fonctionnalité. Fonctionnalités :

- **Portée de préfixe** : ajoute automatiquement le préfixe à toutes les clés de traduction dans le groupe
- **Groupes imbriqués** : prise en charge des groupes de traduction imbriqués
- **Organisation propre** : aide à maintenir des structures de traduction organisées

**Exemple :**

```vue
<!-- Vue -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

```tsx
// React
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```tsx
// Solid
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```astro
<!-- Astro -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

## Options `createI18n` partagées \{#create-i18n-options\}

Chaque paquet de cadriciel est créé de la même manière. Seul le type des options est nommé d'après le cadriciel (`ReactI18nOptions`, `SolidI18nOptions`, et ainsi de suite). Les options elles-mêmes sont identiques :

| Propriété        | Type                                                       | Requis | Défaut           | Description                                    |
| ---------------- | ---------------------------------------------------------- | ------ | ---------------- | ---------------------------------------------- |
| `locale`         | `string`                                                   | ✅     | -                | Code de la langue courante (par exemple, `'en'`)             |
| `fallbackLocale` | `string`                                                   | ❌     | Identique à `locale` | Langue de repli quand la traduction est manquante    |
| `messages`       | `Record<string, Translations>`                             | ❌     | `\{\}`             | Messages de traduction initiaux                    |
| `plural`         | `PluralFunc`                                               | ❌     | `defaultPlural`  | Fonction de pluralisation personnalisée         |
| `missingWarn`    | `boolean`                                                  | ❌     | `true`           | Afficher les avertissements pour les traductions manquantes |
| `missingHandler` | `(locale: string, key: string, routeName: string) => void` | ❌     | -                | Gestionnaire personnalisé pour les traductions manquantes |

Tout ce qui va au-delà est propre au cadriciel et documenté sur la page de ce paquet.

## Abstraction d'adaptateur de routeur

Tous les paquets de cadriciels utilisent un **motif d'adaptateur de routeur** pour découpler la fonctionnalité i18n des implémentations de routeur spécifiques. Cette conception permet :

- **Flexibilité** : utilisez n'importe quelle bibliothèque de routeur ou pas de routeur du tout
- **Indépendance du cadriciel** : gardez la logique de routage dans votre application, pas dans le paquet i18n
- **Noyau léger** : le paquet i18n reste petit et concentré

### Implémenter un adaptateur de routeur

Pour utiliser les fonctionnalités de routage, vous devez implémenter l'interface `I18nRoutingStrategy` :

```typescript
interface I18nRoutingStrategy {
  getCurrentPath: () => string
  linkComponent?: Component
  push: (target: { path: string }) => void
  replace: (target: { path: string }) => void
  resolvePath?: (to: string | { path?: string }, locale: string) => string | { path?: string }
  getRoute?: () => { fullPath: string; query: Record<string, unknown> }
}
```

Chaque documentation de paquet inclut des exemples complets d'implémentation d'adaptateurs pour les routeurs populaires :

- **Vue** : exemple d'adaptateur Vue Router
- **React** : exemple d'adaptateur React Router
- **Solid** : exemple d'adaptateur Solid Router
- **Astro** : exemple d'adaptateur de routage basé sur les fichiers

## Fonctionnalités principales

Tous les paquets partagent ces fonctionnalités principales :

### Méthodes de traduction

- `t()` : traduction de base avec interpolation de paramètres
- `ts()` : traduction qui retourne toujours une chaîne
- `tc()` : traduction sensible à la pluralisation
- `tn()` : formatage des nombres
- `td()` : formatage des dates
- `tdr()` : formatage des durées relatives
- `has()` : vérifier si une clé de traduction existe

### Gestion de la langue

- **Changement de langue** : changer la langue courante par programmation
- **Langue de repli** : repli automatique quand la traduction est manquante
- **Traductions propres aux routes** : organisation des traductions au niveau de la page
- **Cache des traductions** : mise en cache intelligente pour la performance

### Prise en charge TypeScript

Tous les paquets offrent :

- Définitions TypeScript complètes
- Clés de traduction typées (avec le générateur de types)
- Support IntelliSense dans les IDE
- Vérification d'erreurs à la compilation

## Bien démarrer

1. **Choisissez votre paquet** : sélectionnez le paquet pour votre cadriciel
2. **Installez le paquet** : utilisez votre gestionnaire de paquets préféré
3. **Lisez la documentation** : chaque paquet a des instructions de configuration détaillées
4. **Implémentez l'adaptateur de routeur** : si vous avez besoin des fonctionnalités de routage, implémentez l'adaptateur
5. **Commencez à traduire** : utilisez les composants et méthodes pour ajouter des traductions

Pour des instructions de configuration détaillées, consultez la documentation de votre paquet spécifique :

- [Documentation du paquet Vue](/integrations/vue)
- [Documentation du paquet React](/integrations/react)
- [Documentation du paquet Solid](/integrations/solid)
- [Documentation du paquet Astro](/integrations/astro)
