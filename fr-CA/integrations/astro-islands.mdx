---
title: "Îlots Astro"
description: "Des traductions dans les îlots Vue, React, Preact et Svelte avec @i18n-micro/astro."
---

Un îlot s'exécute dans le navigateur, là où l'instance i18n du serveur n'existe pas. `@i18n-micro/astro` permet à la page de choisir les clés dont un îlot a besoin, de les transmettre dans une seule prop et de les lire dans l'îlot grâce à un petit adaptateur propre au cadriciel. Vous obtenez `t`, `tc`, `tn`, `td`, `tdr` et `has` dans les îlots Vue, React, Preact et Svelte, avec seulement les chaînes choisies dans le HTML.

## Configuration {#setup}

Configurez d'abord l'[intégration Astro et le middleware](/fr-CA/integrations/astro-package#setup), puis ajoutez l'intégration du cadriciel que vous utilisez (`@astrojs/vue`, `@astrojs/react`, `@astrojs/preact`, `@astrojs/svelte`). Les adaptateurs d'îlots ont besoin de ce cadriciel comme dépendance homologue (peer) : `vue` `^3.3.0`, `react` `^16.8.0 || ^17.0.0 || ^18.0.0 || ^19.0.0`, `preact` `^10.0.0 || ^11.0.0` ou `svelte` `^4.0.0 || ^5.0.0`.

## Transmettre des traductions à un îlot {#pass-translations-to-an-island}

```astro
---
// src/pages/index.astro
import { getI18nProps } from '@i18n-micro/astro'
import Counter from '../components/Counter.vue'

const i18n = getI18nProps(Astro, ['counter.title', 'counter.apples'])
---

<Counter client:load i18n={i18n} />
```

`getI18nProps(Astro, keys?)` retourne `{ locale, fallbackLocale, currentRoute, translations }` (type `I18nClientProps`). Transmettez les clés qu'utilise l'îlot : chacune est résolue sur le serveur comme avec `t()` (dictionnaires de route, racine et de repli) et seules les clés trouvées sont placées dans le HTML. Sans `keys`, tout ce à quoi `t()` peut répondre sur cette page est envoyé, dans chaque îlot; 2000 clés racine représentent donc environ 100 Ko par îlot. En développement, un avertissement le signale au-delà de 20 Ko.

Les îlots traduisent uniquement à partir de cet objet. `t` retourne la clé pour tout ce qui n'a pas été transmis, et les messages liés ne sont pas résolus.

## Vue {#vue}

Appelez `provideI18n(() => props.i18n)` dans le composant racine de l'îlot et `useAstroI18n()` dans ses enfants. Le `inject` de Vue ne voit pas une valeur fournie par le même composant; le hook doit donc s'exécuter dans un enfant, et non dans la racine :

```vue
<!-- src/components/Counter.vue -->
<script setup lang="ts">
import { provideI18n } from '@i18n-micro/astro/client/vue'
import type { I18nClientProps } from '@i18n-micro/astro'
import CounterBody from './CounterBody.vue'

const props = defineProps<{ i18n: I18nClientProps }>()
provideI18n(() => props.i18n)
</script>

<template><CounterBody /></template>
```

```vue
<!-- src/components/CounterBody.vue -->
<script setup lang="ts">
import { ref } from 'vue'
import { useAstroI18n } from '@i18n-micro/astro/client/vue'

const { t, tc } = useAstroI18n()
const count = ref(0)
</script>

<template>
  <h3>{{ t('counter.title') }}</h3>
  <button @click="count++">{{ tc('counter.apples', count) }}</button>
</template>
```

## React et Preact {#react-and-preact}

```tsx
// src/components/Counter.tsx
import { useState } from 'react'
import { I18nProvider, useAstroI18n } from '@i18n-micro/astro/client/react'
import type { I18nClientProps } from '@i18n-micro/astro'

function Body() {
  const { t, tc } = useAstroI18n()
  const [count, setCount] = useState(0)
  return <button onClick={() => setCount(count + 1)}>{t('counter.title')}: {tc('counter.apples', count)}</button>
}

export default function Counter({ i18n }: { i18n: I18nClientProps }) {
  return (
    <I18nProvider value={i18n}>
      <Body />
    </I18nProvider>
  )
}
```

Pour Preact, importez `I18nProvider` et `useAstroI18n` depuis `@i18n-micro/astro/client/preact`; l'API est la même.

## Svelte {#svelte}

```svelte
<!-- src/components/Counter.svelte -->
<script lang="ts">
  import { createI18nStore, useAstroI18n } from '@i18n-micro/astro/client/svelte'
  import type { I18nClientProps } from '@i18n-micro/astro'

  export let i18n: I18nClientProps
  const { t, tc } = useAstroI18n(createI18nStore(i18n))
  let count = 0
</script>

<button on:click={() => count++}>{t('counter.title')}: {tc('counter.apples', count)}</button>
```

`useAstroI18n(store)` retourne aussi le `store` pour les lectures `$store` dans le gabarit.

## Îlots persistants {#persisted-islands}

Un îlot avec `transition:persist` reçoit de nouvelles props après une navigation. React, Preact et Vue (avec un accesseur) les suivent. Dans Svelte, conservez le store et transmettez-les-lui : `const store = createI18nStore(i18n)`, `const { t } = useAstroI18n(store)`, puis `$: store.set(i18n)` (avec les runes, `$effect(() => store.set(i18n))`).

## API {#api}

| Point d'entrée | Exportations |
| --- | --- |
| `@i18n-micro/astro` | `getI18nProps`, type `I18nClientProps` |
| `@i18n-micro/astro/client/vue` | `provideI18n(props \| () => props)`, `useAstroI18n()` |
| `@i18n-micro/astro/client/react` | `I18nProvider` (prop `value`), `useAstroI18n()` |
| `@i18n-micro/astro/client/preact` | `I18nProvider` (prop `value`), `useAstroI18n()` |
| `@i18n-micro/astro/client/svelte` | `createI18nStore(props)`, `useAstroI18n(store)` |
| `@i18n-micro/astro/client` | les fonctions pures `translate` et `hasTranslation`, sans cadriciel |

Chaque `useAstroI18n` retourne `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`, `setLocale`, `setRoute` et la `locale`. Un îlot possède un seul dictionnaire fusionné; son `has` est donc vrai pour toute clé à laquelle `t` peut répondre, y compris depuis la locale de repli. Sur le serveur, `has` examine uniquement la locale active.
