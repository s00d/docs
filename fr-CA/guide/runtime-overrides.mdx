---
title: "Substitutions à l’exécution"
description: "Modifiez la langue par défaut, la langue de repli ou les langues désactivées pour chaque instance d’une même compilation, avec des variables d’environnement ou runtimeConfig."
---

Les substitutions à l’exécution permettent à un seul artefact de compilation de fonctionner avec des paramètres de langue différents selon l’environnement ou le locataire, sans recompiler. Vous pouvez modifier la langue par défaut, la langue de repli et les langues désactivées. Le routage, les redirections, le rendu et les fonctions utilitaires du serveur utilisent les valeurs substituées, tout comme le navigateur sur une page rendue par le serveur.

## Définir les substitutions avec des variables d’environnement {#set-overrides-with-environment-variables}

```bash
NUXT_I18N_DEFAULT_LOCALE=de \
NUXT_I18N_FALLBACK_LOCALE=en \
NUXT_I18N_DISABLED_LOCALES=fr,it \
node .output/server/index.mjs
```

| Variable | Alias |
| --- | --- |
| `NUXT_I18N_DEFAULT_LOCALE` | `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE` |
| `NUXT_I18N_FALLBACK_LOCALE` | `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE` |
| `NUXT_I18N_DISABLED_LOCALES` (séparées par des virgules) | `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES` |

Le serveur les lit une seule fois au démarrage; redémarrez-le pour appliquer un changement. Sur une page rendue par le serveur, le navigateur reçoit les valeurs résolues du serveur. Avec `ssr: false`, il n’y a pas de rendu serveur et le navigateur n’a pas d’environnement : seul `runtimeConfig.public.i18nRuntime` s’applique alors, et le navigateur journalise les avertissements ci-dessous.

## Définir les substitutions dans runtimeConfig {#set-overrides-in-runtimeconfig}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

Une valeur définie dans `runtimeConfig.public.i18nRuntime` l’emporte sur la variable `NUXT_I18N_*` du même champ.

À ne pas confondre avec la variable `DEFAULT_LOCALE` de compilation, qui remplace `defaultLocale` pendant la compilation et ne nécessite aucune prise en charge à l’exécution.

## Ce qui peut changer et ce qui ne le peut pas {#what-can-and-cannot-change}

| Paramètre | À l’exécution |
| --- | --- |
| `defaultLocale` | Oui avec `prefix` et `no_prefix`. Avec `prefix_except_default` et `prefix_and_default`, elle est fixée à la compilation (ses pages sont les routes sans préfixe); une substitution est ignorée avec un avertissement. |
| `fallbackLocale` | Oui. |
| `disabledLocales` | S’ajoute aux langues désactivées à la compilation; n’en réactive jamais une. La langue par défaut de la compilation ne peut pas être désactivée avec `prefix_except_default` / `prefix_and_default`. |
| `strategy` | Non. Une stratégie définie à l’exécution est ignorée avec un avertissement; compilez un artefact par stratégie. |

Les valeurs invalides ne cassent jamais l’application. Chaque cas journalise un avertissement par processus serveur :

- désactiver toutes les langues est ignoré;
- une `defaultLocale` qui n’est pas activée est remplacée par la première langue activée;
- une `fallbackLocale` qui n’est pas activée conserve la valeur de compilation si celle-ci est activée; sinon, il n’y a pas de langue de repli.

## Lire la configuration effective {#read-the-effective-config}

```vue
<script setup lang="ts">
const { $getI18nConfig } = useNuxtApp()
const config = $getI18nConfig() // build config with overrides applied
</script>
```

Traitez-la en lecture seule : sur le serveur, elle est partagée par toutes les requêtes et gelée en développement; la copie du navigateur n’est pas gelée. Importer la configuration depuis `#build/i18n.strategy.mjs` donne les valeurs de compilation sans les substitutions.

## Langues désactivées et fichiers statiques {#disabled-locales-and-static-files}

Une langue désactivée à l’exécution répond 404 sur ses routes et sur sa route de charge utile, mais ses fichiers de charge utile restent dans `.output/public/_locales/` et un serveur de fichiers statiques les renvoie. Si ces fichiers ne doivent pas être accessibles, désactivez la langue à la compilation avec `disabled: true`.
