title: "Crowdin"
description: "Synchronisez locales/ avec un projet Crowdin au moyen de la CLI Crowdin et d'un crowdin.yml qui correspond à l'organisation des fichiers du module."
---

[Crowdin](https://crowdin.com/) est une plateforme de traduction : vous téléversez les fichiers de la locale par défaut, les traducteurs travaillent dans Crowdin, puis vous téléchargez les autres locales. Le module lit de simples fichiers JSON; la CLI Crowdin n'a donc besoin que d'un `crowdin.yml` qui associe correctement `locales/` et `locales/pages/`. Aucun réglage du module ne change.

## Configurer crowdin.yml {#configure-crowdin-yml}

```yml
# crowdin.yml
project_id_env: CROWDIN_PROJECT_ID
api_token_env: CROWDIN_PERSONAL_TOKEN
base_path: ./locales
preserve_hierarchy: true

files:
  - source: /en.json
    translation: /%two_letters_code%.json
  - source: /pages/**/en.json
    translation: /pages/**/%two_letters_code%.json
```

- `en` est votre locale par défaut; ses fichiers sont les sources.
- `project_id_env` / `api_token_env` lisent l'identifiant et le jeton dans des variables d'environnement, de sorte qu'aucun secret n'est commité.
- `preserve_hierarchy: true` conserve les dossiers `pages/<page>/` tels quels.
- Le nom du fichier traduit doit être identique au `code` de la locale dans `nuxt.config.ts`. `%two_letters_code%` convient aux codes comme `de`; pour des codes comme `pt-BR`, utilisez `%locale%`, ou associez les codes de Crowdin aux vôtres avec `languages_mapping`.

## Téléverser et télécharger {#upload-and-download}

```bash
npm install -g @crowdin/cli

export CROWDIN_PROJECT_ID=123456
export CROWDIN_PERSONAL_TOKEN=...   # from Crowdin account settings

crowdin upload sources   # push locales/en.json and locales/pages/**/en.json
crowdin download         # write locales/de.json, locales/pages/**/de.json, ...
```

Exécutez les deux commandes en CI pour garder les fichiers à jour. Les fichiers téléchargés arrivent dans votre dépôt comme s'ils avaient été modifiés à la main; le prochain build ou rechargement en développement les prend en compte.

## Avant de téléverser {#before-uploading}

Nettoyez d'abord les sources pour que les traducteurs ne travaillent pas sur des clés mortes : [`i18n-micro clean`](/fr-CA/api/cli#clean) retire les clés inutilisées, [`i18n-micro check`](/fr-CA/api/cli#check) signale les lacunes après un téléchargement. La CLI n'a pas d'intégration Crowdin propre : cette page décrit la méthode prise en charge.
