Avec `nuxt dev`, le module ajoute deux outils de débogage : un onglet **i18n Micro** dans les Nuxt DevTools pour parcourir et modifier les fichiers de traduction, et un inspecteur Vue DevTools pour la locale active et les dictionnaires chargés. Les deux n'existent qu'en développement et n'ajoutent rien aux compilations de production. L'onglet Nuxt ne nécessite que l'activation des Nuxt DevTools; l'inspecteur Vue nécessite aussi l'extension de navigateur Vue DevTools.

## Onglet des Nuxt DevTools {#nuxt-devtools-tab}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  devtools: { enabled: true }, // the tab is registered only when DevTools are on
})
```

Ouvrez les Nuxt DevTools (`Shift + Alt + D`) et choisissez **i18n Micro**. L'onglet affiche :

- chaque fichier JSON sous `locales/` (racine et `pages/`) de chaque couche, ainsi que les fichiers racine de `additionalTranslationDirs`;
- un éditeur par fichier; **Save** réécrit le fichier sur le disque, et le serveur de développement recharge les traductions;
- **Export** / **Import** d'un fichier au format JSON, et **Stats** avec le nombre de clés et la couverture des traductions;
- une vue de la configuration avec les options résolues du module;
- **Translate**, qui remplit les clés manquantes à l'aide d'un moteur de traduction automatique que vous configurez dans les paramètres de l'onglet.

L'enregistrement n'écrit que dans des fichiers `.json` existants à l'intérieur de vos répertoires de traduction. Lorsqu'un fichier existe dans plusieurs couches, c'est la copie du projet qui est écrite.

## Inspecteur des Vue DevTools {#vue-devtools-inspector}

Avec l'extension de navigateur Vue DevTools, le module enregistre un inspecteur i18n (locale actuelle, fragment de la route, clés chargées) et une chronologie des changements de locale, des chargements de fragments et des clés manquantes.

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    debug: true, // also log every $t / $ts / $tc call on the timeline
    // vueDevtools: false, // turn the inspector off, keep the Nuxt tab
  },
})
```

[`vueDevtools`](/fr-CA/api/module-options) vaut `true` par défaut. `debug: true` est très verbeux; réservez-le à de courtes sessions.

## En dehors de Nuxt {#outside-nuxt}

La même interface est publiée sous le nom [`@i18n-micro/devtools-ui`](/fr-CA/integrations/devtools-ui-package) pour les applications Vite construites sur les paquets pour frameworks; consultez cette page pour la configuration.
