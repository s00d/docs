---
title: "useI18n"
description: "useI18n retourne les utilitaires d'exécution (`$t`, `$tc`, `$localePath`, …) sous forme d'objet simple, avec et sans le préfixe `$`."
---

`useI18n()` retourne les utilitaires d'exécution du module sous forme d'objet simple. Utilisez-le dans `<script setup>`, les composables et les plugins plutôt que de passer par `useNuxtApp()`. Chaque utilitaire est offert sous son nom avec `$` et sous un alias sans préfixe : `t` et `$t` sont la même fonction.

## Signature {#signature}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Tous les utilitaires d'exécution, sous forme d'objet simple.

Les mêmes fonctions que le plugin injecte sous `$t`, `$tc`, etc., offertes à la fois sous
le nom préfixé par le dollar et sous un alias sans préfixe — ainsi, `const { t } = useI18n()` et
`const { $t } = useI18n()` fonctionnent tous les deux.

**Retourne** — les utilitaires décrits dans la [référence des méthodes](/fr-CA/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

L'objet retourné contient tous les utilitaires de [`PluginsInjections`](/fr-CA/api/methods). Chacun est documenté sur la page [Utilitaires](/fr-CA/api/methods).

## Exemple {#example}

```vue
<script setup lang="ts">
const { t, tc, localePath, switchLocale, getLocale } = useI18n()

const title = computed(() => t('page.title'))
</script>

<template>
  <h1>{{ title }}</h1>
  <p>{{ tc('items', 3) }}</p>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
  <button @click="switchLocale(getLocale() === 'en' ? 'de' : 'en')">{{ t('nav.switch') }}</button>
</template>
```

## Absent du type {#not-in-the-type}

`$defineI18nRoute` est typé uniquement sur `useNuxtApp()` :

```ts
const { $defineI18nRoute } = useNuxtApp()
```
