---
title: "useLocaleHead"
description: "useLocaleHead construit les balises SEO i18n (lang, dir, canonical, hreflang, og:locale) sous forme d'objet à passer à useHead."
---

`useLocaleHead()` construit les balises head i18n pour la route courante : `lang` et `dir` sur `<html>`, un lien canonique, des alternatives `hreflang` avec `x-default`, `og:url`, `og:locale` et `og:locale:alternate`. Utilisez-le lorsque vous définissez [`meta: false`](/fr-CA/api/module-options#meta) et gérez `useHead` vous-même; avec `meta: true`, le module enregistre déjà ces balises, et les modifications par page passent par [`useI18nHead`](/fr-CA/composables/useI18nHead).

## Signature {#signature}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { build: () => LocaleHead; metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }, LocaleHead | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

Les balises head SEO pour la route courante : des alternatives `hreflang` pour chaque locale, plus
`x-default`, un lien canonique, `og:locale`, ainsi que `lang`/`dir` sur `<html>`.

Nécessaire seulement lorsque `meta` est désactivé ou que les valeurs par défaut doivent être ajustées — avec `meta: true`,
le module enregistre lui-même les mêmes balises.

| Paramètre | Type | Description |
| --- | --- | --- |
| `options` | `UseLocaleHeadOptions` |  |

**Retourne** — `metaObject`, une ref contenant l'objet head prêt à passer à `useHead`; `updateMeta` le rafraîchit; `build` calcule l'objet head à partir de la route courante (réactif lorsqu'il est lu dans un getter, p. ex. `useHead(() => build())`)

```ts
const { metaObject } = useLocaleHead({ addSeoAttributes: true })
useHead(metaObject)
```

## Options {#options}

| Option | Par défaut | Description |
| --- | --- | --- |
| `addDirAttribute` | `true` | Définit `dir` sur `<html>` à partir du `dir` de la locale (`'auto'` si elle n'en a pas). |
| `identifierAttribute` | `'id'` | Attribut qui identifie chaque balise (`i18n-can`, `i18n-og`, `i18n-alternate-<hreflang>`, …), afin que les mises à jour remplacent les balises au lieu d'en ajouter. |
| `addSeoAttributes` | `true` | Émet les balises canonical, `hreflang` et `og:`. `false` ne conserve que `htmlAttrs`. |
| `baseUrl` | `'/'` | Origine jointe à chaque URL. Gardez `'/'` pour des URL relatives; passez `'https://example.com'` pour des URL absolues. |
| `autoUpdate` | `true` | Reconstruit `metaObject` lorsque la route ou l'état `i18n-locale` change. |

## Ce qu'il émet {#what-it-emits}

- Rien sur une route sans correspondance (404) ou avec `disableMeta` pour la locale active.
- Canonical et `og:url` : `$switchLocalePath(<active locale>)`, requête réduite à [`canonicalQueryWhitelist`](/fr-CA/api/module-options#canonicalquerywhitelist), [`trailingSlash`](/fr-CA/api/module-options#trailingslash) appliqué.
- `hreflang` : un lien par locale activée dans laquelle la page existe, `hreflang = iso || code`, en ignorant les locales avec `seo: false`; avec `hreflangBaseLanguage: true`, la première locale régionale d'une langue émet aussi la balise de la langue de base. Aucun avec `no_prefix`.
- `x-default` : l'URL de la locale par défaut, sauf si la stratégie est `no_prefix`, si la locale par défaut a `seo: false` ou si la page n'y existe pas.
- `og:locale` / `og:locale:alternate` : à partir du `og` de la locale, ou de son `iso` converti (`en-US` → `en_US`); ignoré avec un avertissement en développement lorsqu'aucun des deux ne fonctionne.

## Exemple {#example}

```ts
// app.vue, with i18n.meta: false
const { metaObject } = useLocaleHead({ baseUrl: 'https://example.com' })
useHead(metaObject)
```

`build()` retourne le même objet sans la ref : `useHead(() => build())` reste réactif sans watcher.
