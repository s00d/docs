Versions : **v3.22.0 → v3.26.0**.

## Nouvelles fonctionnalités

- **API de mémoire de traduction.** Lisez et modifiez le dictionnaire de la langue active à l'exécution avec `$resolveTranslations()` et `$setTranslation(key, value)`. Utile pour les DevTools, les tests et les éditeurs intégrés. Consultez [Méthodes](/api/methods#resolvetranslations).
- **`numberFormats` et `datetimeFormats` nommés.** Configurez des formats nommés compatibles Vue I18n par langue, puis appelez `$tn(1000, 'currency')` ou `$td(date, 'short')`. Consultez les [options du module](/api/module-options).
- **Contrôle du cache HTTP sur les charges utiles `/_locales`.** La nouvelle option [`httpCacheDuration`](/api/module-options) définit `Cache-Control: public, max-age=…, immutable` sur les charges utiles de traduction. Défaut : un an, associé de façon sûre à l'invalidation `?v={dateBuild}`.
- **Charges utiles de traduction compressées.** Lorsque `nitro.compressPublicAssets` est activé, les charges utiles publiques de traduction sont compressées automatiquement. Consultez le [guide de performance](/guides/performance).
- **Utilitaire `splitLocaleRoutes`.** Construisez à la fois `pages` et `globalLocaleRoutes` à partir d'une seule liste programmatique (pour les scénarios `pages:extend`), indexée par nom de route. Consultez [Routes de langue personnalisées](/guides/custom-locale-routes#programmatic-routes-pagesextend--244).
- **Repli `site.url` pour la base SEO.** Lorsque `metaBaseUrl` n'est pas défini, les balises SEO retombent sur `site.url` de `nuxt-site-config` s'il est présent, sinon sur l'origine de la requête. Consultez [`metaBaseUrl`](/api/module-options).

## Mises à jour

- **Adaptateur Astro.** Isolation du contexte de routage, plus le câblage pour `numberFormats` et `datetimeFormats`.
- **React et Preact.** `I18nSwitcher` définit désormais correctement les attributs `aria-haspopup` et `aria-expanded`.
- **Bancs d'essai.** Les bancs d'essai de performance sont passés à un CLI basé sur citty.
- **Empreinte de contenu `dateBuild`.** Le `dateBuild` par défaut est maintenant une empreinte de contenu, donc `?v=` sur la charge utile ne change que lorsque les traductions changent réellement.

## Corrections

- **Routage.**
  - Les matchers de routes localisées gèrent maintenant correctement les chemins avec tirets, imbriqués et les segments paramétrés.
  - Les parents imbriqués sont conservés lorsqu'une route enfant est absolue.
  - `hreflang` est émis depuis le `iso` de la langue, pas depuis le code de routage.
  - Le changement de langue sous `no_prefix` remplace l'historique au lieu d'y pousser.
- **Redirections.**
  - `autoDetectPath` est respecté pour les redirections de préférence par témoin et `Accept-Language`.
  - Les alias `localeRoutes` sont préservés sous `autoDetectPath: '/'`.
- **Traductions.**
  - Les fonctions de pluralisation personnalisées qui retournent `null` retombent maintenant sur la règle plurielle par défaut.
  - Les couches de traduction fusionnent sans mise à plat des dumps.
  - Les langues désactivées sont omises des charges utiles publiques préfusionnées.
  - Le HMR ignore les écritures de fichiers sans changement et refusionne en simultané lors des changements de langue racine.
- **Sélecteur.** Cache les langues `disabled` et rétablit la priorité de `customDisabledLinkStyle` et du style actif.
- **Module.** Pont pour les types `Plugin` d'unplugin Vite 8 pour la compatibilité avec Nuxt Kit.
- **SSR.** Le SSR Node lit maintenant les charges utiles publiques (plus d'import Rollup `raw:`).

## Changements incompatibles (v3.22.0)

- Les morceaux SSR sont passés de `useState('i18n-ssr-chunks')` à `nuxtApp.payload.data['i18n-ssr-chunks']`.
- `getAllTranslations()` a été retiré de `@i18n-micro/vue`. Utilisez plutôt `resolveTranslations()`, `getStorage()` ou `getRouteCache()`.
- Le `dateBuild` par défaut est maintenant une empreinte de contenu, donc `?v=` sur la charge utile changera une fois lors de la mise à niveau.
