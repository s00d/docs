---
title: "<i18n-switcher>"
description: "Le composant <i18n-switcher> est un menu déroulant des locales activées, chacune menant à la page actuelle dans cette locale."
---

`<i18n-switcher>` affiche un bouton avec la locale active et un menu déroulant de toutes les locales activées, y compris l'active. Utilisez-le pour obtenir un menu de langues prêt à l'emploi; construisez le vôtre à partir de [`$getLocales`](/fr-CA/api/methods#$getlocales) et de [`$switchLocalePath`](/fr-CA/api/methods#$switchlocalepath) lorsque vous avez besoin d'un balisage différent. Chaque entrée mène à la page actuelle dans cette locale.

## Props et slots {#props-and-slots}

| Prop | Type | Par défaut | Description |
| --- | --- | --- | --- |
| `customLabels` | `Record<string, string>` | `() => ({})` | Nom affiché par code de locale, qui remplace le `displayName` de la configuration de la locale. |
| `customWrapperStyle` | `CSSProperties` | `() => ({})` | Style en ligne de l'enveloppe externe. |
| `customButtonStyle` | `CSSProperties` | `() => ({})` | Style en ligne du bouton qui ouvre le menu déroulant. |
| `customDropdownStyle` | `CSSProperties` | `() => ({})` | Style en ligne du panneau déroulant. |
| `customItemStyle` | `CSSProperties` | `() => ({})` | Style en ligne de chaque élément du menu déroulant. |
| `customLinkStyle` | `CSSProperties` | `() => ({})` | Style en ligne du lien à l'intérieur d'un élément. |
| `customActiveLinkStyle` | `CSSProperties` | `() => ({})` | Style en ligne du lien de la locale actuellement active. |
| `customDisabledLinkStyle` | `CSSProperties` | `() => ({})` | Style en ligne du bouton de la locale *actuelle* lorsqu'elle a `disabled: true` dans la configuration. |
| `customIconStyle` | `CSSProperties` | `() => ({})` | Style en ligne de l'icône en chevron du bouton. |

### Slots {#slots}

| Slot | Liaisons | Description |
| --- | --- | --- |
| `before-button` | — | Contenu avant le bouton qui ouvre le menu déroulant. |
| `before-selected-locale` | — | Contenu avant le libellé de la locale active, dans le bouton. |
| `after-selected-locale` | — | Contenu après le libellé de la locale active, dans le bouton. |
| `before-dropdown` | — | Contenu entre le bouton et le panneau déroulant. |
| `before-dropdown-items` | — | Contenu en haut du menu déroulant, au-dessus de la liste des locales. |
| `before-item` | `locale` | Contenu avant chaque entrée de locale. |
| `before-link-content` | `locale` | Contenu avant le libellé d'une locale, dans son lien. |
| `after-link-content` | `locale` | Contenu après le libellé d'une locale, dans son lien. |
| `after-item` | `locale` | Contenu après chaque entrée de locale. |
| `after-dropdown-items` | — | Contenu en bas du menu déroulant, sous la liste des locales. |
| `after-dropdown` | — | Contenu après le panneau déroulant. |

## Comportement {#behaviour}

- Énumère chaque locale sans `disabled: true`, y compris l'active.
- Chaque entrée est un `<a>` vers `$switchLocalePath(code)`. Un chemin est résolu sous `app.baseURL`; un `baseUrl` de locale sur un autre domaine reste absolu. L'entrée a `hreflang` et `lang` définis à `iso || code`, `dir` lorsque la locale en a un, `aria-current="page"` sur la locale actuelle et la classe `switcher-locale-<code>`. Un clic appelle `$switchLocale(code)` et ferme le menu déroulant; avec une touche de modification, le clic est laissé au navigateur.
- La liste reste dans le HTML du serveur, masquée, pour que les robots d'indexation voient les liens. La touche Échap ou un clic à l'extérieur la ferme.
- Libellé : `customLabels[code]`, puis le `displayName` de la locale, puis le code (avec un avertissement en développement).
- Styles : de petites valeurs par défaut en ligne (bouton et panneau blancs avec bordure, entrée active en gras et en bleu). Chaque prop `custom*Style` est appliquée après la valeur par défaut de sa partie. Le bouton a les classes `i18n-switcher-button` et `language-switcher`, l'enveloppe `i18n-switcher-wrapper`, la liste `i18n-switcher-dropdown`. Les positions utilisent des propriétés CSS logiques, donc `dir="rtl"` fonctionne.

## Exemple {#example}

```vue
<template>
  <i18n-switcher
    :custom-labels="{ en: 'English', de: 'Deutsch' }"
    :custom-button-style="{ borderRadius: '4px' }"
  >
    <template #before-link-content="{ locale }">
      <img :src="`/flags/${locale.code}.svg`" alt="" width="16" />
    </template>
  </i18n-switcher>
</template>
```
