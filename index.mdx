Nuxt I18n Micro is a lightweight, high-performance i18n module for Nuxt, designed for large projects. It reduces build times, memory usage, and bundle size compared with traditional i18n solutions like `@nuxtjs/i18n`.

The core is a single Nuxt module plus a small set of runtime plugins. Locale prefixes are handled by `@i18n-micro/route-strategy` (build-time) and `@i18n-micro/path-strategy` (runtime). Translations are JSON-only, split between shared root files and per-page files that are auto-generated in development.

## When to use Nuxt I18n Micro

- You need lazy-loaded, per-page translations without inflating the Nitro payload.
- You want strategy-based routing without runtime route generation overhead.
- You need SSR and edge deployments to stay fast under load.
- You're migrating from `@nuxtjs/i18n` and want a smaller runtime with similar ergonomics.
