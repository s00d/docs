---
title: "Nuxt I18n Micro"
description: "Small, fast i18n for Nuxt: JSON translations per page, build-time localized routes, SEO tags out of the box."
---

Nuxt I18n Micro is a lightweight, high-performance i18n module for Nuxt 3 and 4, designed for large projects. It keeps build times, memory usage and bundle size low compared with traditional i18n solutions like `@nuxtjs/i18n`.

`@i18n-micro/route-strategy` generates localized routes at build time, and `@i18n-micro/path-strategy` resolves them at runtime. As a result, links, the switcher, `hreflang` and redirects all agree with the router. Translations are JSON only, split between shared root files and per-page files that the dev server creates for you, with HMR built in.

<CodeGroup>

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>

## Key capabilities

<CardGroup cols={2}>
  <Card title="Strategy-based routing" icon="route" href="/guide/strategy">
    `prefix`, `no_prefix`, `prefix_except_default` and `prefix_and_default`.
  </Card>
  <Card title="Per-page translations" icon="folder-tree" href="/guide/translations">
    JSON only, root plus page-scoped files, one payload per page and locale.
  </Card>
  <Card title="One build for every domain" icon="globe" href="/guide/layers">
    Locale domains route requests under every strategy and in `nuxt generate`.
  </Card>
  <Card title="SEO out of the box" icon="magnifying-glass" href="/guide/seo">
