This page collects practical examples that show how to use Nuxt I18n Micro in a Nuxt application. You will see how to switch locales, use the `<i18n-link>`, `<i18n-switcher>`, and `<i18n-t>` components, handle pluralization, load translations at runtime, and configure per-locale dynamic route params.

## Basic setup

A minimal configuration to get started with Nuxt I18n Micro:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

See [Configuration](/guides/configuration) and [Module options](/api/module-options) for every available option.

## Locale switching

### Switch locales programmatically

Render one button per configured locale and call `$switchLocale` to change the active language.

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button
        v-for="locale in $getLocales()"
        :key="locale.code"
        :disabled="locale.code === $getLocale()"
        @click="() => $switchLocale(locale.code)"
      >
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

Example translation file used by the buttons above:

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### Use the `<i18n-switcher>` component

The [`<i18n-switcher>`](/api/components/i18n-switcher) component ships a ready-made dropdown with customizable labels.

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## Localized navigation with `<i18n-link>`

The [`<i18n-link>`](/api/components/i18n-link) component wraps `NuxtLink` and applies the current locale to its target.

```vue
<template>
  <div>
    <i18n-link to="/about">{{ $t('about') }}</i18n-link>
    <i18n-link :to="{ name: 'index' }">{{ $t('home') }}</i18n-link>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

```json
{
  "about": "About Us",
  "home": "Home"
}
```

```vue
<template>
  <div>
    <i18n-link to="/about" :active-style="{ fontWeight: 'bold' }">About Us</i18n-link>
  </div>

```

## Rendering translations with `<i18n-t>`

The [`<i18n-t>`](/api/components/i18n-t) component renders a translation into a chosen tag and supports slots and parameter interpolation.

### Basic usage with a slot

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

```json
{
  "greeting": "Welcome to the page"
}
```

### With interpolation

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }" />
</template>
```

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## Rendering dynamic keys from translation files

Sometimes you want to iterate over dynamic keys stored inside your translation files and render each value conditionally. Use `$t` to fetch an array and combine it with `$has` to skip missing keys.

### Iterating over an array of keys

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Iterating over an object

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## Pluralization with `$tc`

`$tc` handles pluralization based on a count and the active locale. Define the plural forms in your translation file separated by `|`.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

- `$tc('apples', 0)` returns the first form, used when the count is zero (`"no apples"`).
- `$tc('apples', 1)` returns the second form, used when the count is one (`"one apple"`).
- `$tc('apples', 10)` returns the third form with the count value, used when the count is two or more (`"10 apples"`).

### Complex plural forms

If your application needs richer plural rules (zero, one, two, few, many, other), extend the translation string accordingly:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

## Number formatting with `$tn`

`$tn` formats numbers using `Intl.NumberFormat` and the current locale.

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## Date and time formatting with `$td`

`$td` formats dates using `Intl.DateTimeFormat` and the current locale.

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## Relative time with `$tdr`

`$tdr` formats a date as a relative time (for example, "5 minutes ago" or "in 1 day") using `Intl.RelativeTimeFormat`.

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```

## Dynamic route params with `$setI18nRouteParams`

For dynamic routes that carry a slug or ID, combine `$defineI18nRoute` with `$setI18nRouteParams` to supply locale-specific segment values. Call it during SSR, before the head is rendered, and typically inside `useAsyncData` or `useFetch` after your data lands.

```vue
<script setup>
// pages/news/[id].vue — for en/news/1-first-article
import { useNuxtApp } from '#imports'

const { $switchLocalePath, $setI18nRouteParams, $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  localeRoutes: {
    en: '/news/:id()',
    fr: '/nouvelles/:id()',
    de: '/Nachricht/:id()',
  },
})

const route = useRoute()

const { data: news } = await useAsyncData(`news-${route.params.id}`, async () => {
  const response = await $fetch('/api/getNews', {
    query: { id: route.params.id },
  })

  if (response?.localeSlugs) {
    $setI18nRouteParams(response.localeSlugs)
  }

  return response
})

// $switchLocalePath('fr') === 'fr/nouvelles/1-premier-article'
// $switchLocalePath('de') === 'de/Nachricht/1-erster-Artikel'
</script>
```

The `localeSlugs` payload has the shape:

```typescript
{
  en: { id: '1-first-article' },
  fr: { id: '1-premier-article' },
  de: { id: '1-erster-Artikel' },
}
```

See [Custom locale routes](/guides/custom-locale-routes) for the full pattern.

## Runtime translation loading with `$loadPageTranslations`

Use `$loadPageTranslations` to inject translations for a page at runtime, for content whose keys are not known at build time.

```typescript
await $loadPageTranslations('en', 'about', {
  title: 'About Us',
  description: 'Learn more about our company',
})
```

This is useful when your copy comes from a CMS or another dynamic source. See [Server-side translations](/guides/server-side-translations) for a full server-integration example.

## Combining techniques on a real page

Below is a more complex page that mixes navigation translations, nested sections, and locale switching in a single template.

```vue
<template>
  <div>
    <h1>{{ $t('mainHeader') }}</h1>

    <nav>
      <ul>
        <li>
          <a href="#">{{ $t('nav.home') }}</a>
        </li>
        <li>
          <a href="#">{{ $t('nav.about') }}</a>
        </li>
        <li>
          <a href="#">{{ $t('nav.services') }}</a>
        </li>
        <li>
          <a href="#">{{ $t('nav.contact') }}</a>
        </li>
      </ul>
    </nav>

    <section>
      <h2>{{ $t('section1.header') }}</h2>
      <p>{{ $t('section1.intro') }}</p>

      <div>
        <h3>{{ $t('section1.subsection1.header') }}</h3>
        <p>{{ $t('section1.subsection1.content') }}</p>
      </div>

      <div>
        <h3>{{ $t('section1.subsection2.header') }}</h3>
        <ul>
          <li>{{ $t('section1.subsection2.item1') }}</li>
          <li>{{ $t('section1.subsection2.item2') }}</li>
          <li>{{ $t('section1.subsection2.item3') }}</li>
        </ul>
      </div>
    </section>

    <footer>
      <h4>{{ $t('footer.contact.header') }}</h4>
      <address>
        {{ $t('footer.contact.address') }}<br />
        {{ $t('footer.contact.city') }}<br />
        {{ $t('footer.contact.phone') }}
      </address>
    </footer>

    <div>
      <button
        v-for="locale in $getLocales()"
        :key="locale.code"
        :disabled="locale.code === $getLocale()"
        @click="() => $switchLocale(locale.code)"
      >
        Switch to {{ locale.code }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```
