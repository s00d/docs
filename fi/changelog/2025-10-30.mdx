**Päivämäärä**: 2025-10-30

**Versio**: `v2.0.0`

![v2.0.0-julkaisu](/images/2.0.0.png)

Esittelemme palvelinpuolen HMR:n käännöstiedostoille kehitystilassa. Kun JSON-käännös muuttuu, palvelimen välimuisti mitätöi vain asianomaiset avaimet, ja seuraavat pyynnöt saavat heti tuoreen datan — uudelleenkäynnistyksiä ei tarvita.

## Mitä uutta? {#what’s-new}

- Palvelinpuolen HMR käännöstiedostoille
- Välitön välimuistin mitätöinti sivu- ja lokaalikohtaisesti
- Saumaton kehittäjäkokemus sisältöä muokattaessa

## Miten se toimii {#how-it-works}

- Tiedoston `src/runtime/server/plugins/watcher.dev.ts` tarkkailija seuraa polkua `<rootDir>/<translationDir>/**/*.json`
- Sivutiedostot (esim. `pages/<page>/<locale>.json`) mitätöivät avaimen `_locales:merged:<page>:<locale>`
- Juuritason tiedostot (esim. `<locale>.json`) mitätöivät kaikki kyseisen lokaalin yhdistetyt avaimet
- Rekisteröidään automaattisesti tiedostosta `src/module.ts` kehitystilassa, kun `experimental.hmr !== false`

## Konfiguraatio {#configuration}

```ts
export default defineNuxtConfig({
  i18n: {
    experimental: { hmr: true }, // default in dev
  },
})
```
