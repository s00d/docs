**Päivämäärä**: 2026-06-25

**Versio**: `v3.21.0`

![v3.21.0 release](/images/3.21.0.png)

Tämä julkaisu lisää **`useI18nHead`**-composablen — sivutason composablen i18n-hakukoneoptimoinnin ohituksiin sisäänrakennetun `02.meta`-liitännäisen päälle. Mukauta `hreflang`-, canonical-, `og:url`- ja Open Graph -tageja reittikohtaisesti ilman omaa meta-liitännäistä tai `meta: false` -asetusta.

## Mitä uutta? {#what’s-new}

### `useI18nHead`-composable {#usei18nhead-composable}

Kutsu `useI18nHead`-funktiota millä tahansa sivulla, kun `meta: true` (oletus). Moduuli yhdistää syötteesi `useLocaleHead`-tuloksen jälkeen jokaisella reitin päivityksellä:

```vue
<script setup lang="ts">
useI18nHead(() => ({
  meta: [{ property: 'og:title', content: article.value?.title }],
  replace: {
    canonical: article.value?.canonicalUrl,
    ogUrl: article.value?.canonicalUrl,
    hreflang: localeCodes.map((locale) => ({
      rel: 'alternate',
      hreflang: locale,
      href: article.value!.locales[locale]!,
    })),
    ogAlternates: localeCodes,
  },
}))
</script>
```

Tukee staattisia objekteja, reaktiivisia gettereitä, `meta`- / `link`-lisäyksiä, `replace`-korvausta sisäänrakennetuille ryhmille sekä `disable`-asetusta automaattisesti luotujen tagien poistamiseen. Katso [`useI18nHead`](/fi/composables/useI18nHead).

### `mergeI18nHead`-apuohjelma (`@i18n-micro/utils`) {#mergei18nhead-utility-@i18n-micro/utils}

Kehysriippumaton yhdistämislogiikka sijaitsee polussa `@i18n-micro/utils/merge-i18n-head` — `02.meta`-liitännäinen käyttää sitä, ja sitä voi testata erikseen. Tyypit (`I18nHeadInput`, `I18nHeadLink`, `I18nHeadMeta`) viedään paketista `@i18n-micro/types`.

### Liitännäisintegraatio {#plugin-integration}

- **`02.meta`** — yhdistää `useLocaleHead`-tuloksen `useI18nHead`-sivutilaan `useHead`-kutsun kautta
- **`01.plugin`** — nollaa sivun ohitukset reitin nimen muuttuessa `resetPageHead()`-kutsulla (jaettu tila composablen kanssa)

### Dokumentaatio ja testit {#documentation-&-tests}

- Uusi opas: [`useI18nHead`](/fi/composables/useI18nHead) CMS- ja artikkeliesimerkkeineen
- Päivitetyt [SEO](/fi/guide/seo) ja [`useLocaleHead`](/fi/composables/useLocaleHead) — milloin käyttää mitäkin API:a
- Playwright- ja Vitest-kattavuus: SSR, SPA-navigointi, uudelleenlataus, `nuxi generate`, osittaiset vaihtoehtoiskielet, `x-default`, reaktiivinen lataus asiakkaalla

## Tyypilliset käyttötapaukset {#typical-use-cases}

| Skenaario                                    | Lähestymistapa                                                 |
| -------------------------------------------- | -------------------------------------------------------------- |
| Blogi/CMS osittaisilla käännöksillä          | `replace.hreflang` + `replace.ogAlternates` API:n kielistä     |
| Oma canonical CMS:stä                        | `replace.canonical` + `replace.ogUrl`                          |
| Vain laskeutumissivun OG                     | `meta: [{ property: 'og:title', ... }]` — säilytä moduulin hreflang |
| Ei hreflangia sivulla                        | `disable: ['hreflang', 'x-default']`                           |
| Korvaa oma liitännäinen (`i18nManualHreflang`) | `useI18nHead` sisältösivukohtaisesti + `meta: true`          |

**JSON-LD** pysyy `useHead({ script: [...] })` -kutsussa — `useI18nHead` ei luo rakenteistettua dataa.

## Rikkovat muutokset {#breaking-changes}

Ei mitään tavallisessa `nuxt.config`-käytössä. Uusi composable ja utils-alipolku ovat lisäyksiä.

## Miksi tällä on merkitystä {#why-it-matters}

- **Ei omaa meta-liitännäistä** CMS-julkaisuille, uutisille tai oppaille, joilla on kielikohtaiset URL-osoitteet
- **Yksi putki** — moduulin oletukset + sivun ohitukset yhdessä `useHead`-kutsussa
- **Tyyppiturvallinen** — `I18nHeadInput` apufunktioille, kuten `buildArticleHead(content)`

Täydellinen muutosloki julkaistaan julkaisun yhteydessä [GitHubissa](https://github.com/s00d/nuxt-i18n-micro/blob/main/CHANGELOG.md).
