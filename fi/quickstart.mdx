## 🚀 Pika-aloitus

### Asennus

Asenna moduuli Nuxt-sovellukseesi:

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

### Perusmääritys

Lisää moduuli tiedostoon `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

<Tip>
- **Juuritason tiedostot** (`locales/en.json` jne.) — koko sovelluksen jaetut käännökset (valikot, alatunniste, yleinen käyttöliittymä). Kun `translationPayloads.mode: 'premerged'` (oletus) on käytössä, ne yhdistetään jokaiseen sivuun käännösvaiheessa.
- **Sivukohtaiset tiedostot** (`locales/pages/<route>/<locale>.json`) — yksittäisille sivuille ainutlaatuiset käännökset, jotka ladataan vasta kun sivu avataan.
- **Dynaamiset reitit** — `pages/articles/[id].vue` yhdistyy hakemistoon `locales/pages/articles-id/` (hakasulkeet korvataan viivoilla).
- **Automaattinen luonti** — kaikki käännöstiedostot luodaan automaattisesti, jos ne puuttuvat komennon `nuxt dev` aikana.
</Tip>

<Info>
Moduuli tukee molempia asetteluja:

- **Sivut**: `pages/**/*.vue` (Nuxt 3) tai `app/pages/**/*.vue` (Nuxt 4)
- **Käännökset**: pidä `locales/` **projektin juuressa** oletuksena (suositeltu käytäntö), ei kansion `app/` sisällä.

```tree
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   ├── en.json
│   └── pages/
└── nuxt.config.ts
```

Valinnainen sijainti kansion sisällä: `i18n: \{ translationDir: 'app/locales' \}` (katso [testiaineisto `n3`](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/n3)).

Valinnaiseen CLI-apuriin `text-to-i18n` käytä paketin [`nuxt-i18n-micro-cli` ≥ 2.1.1](/guides/cli#-text-to-i18n-command) versiota, jotta `app/pages` ja `app/components` skannataan projektin juuresta.
</Info>

### Peruskäyttö

Käytä käännöksiä komponenteissasi:

```vue
<template>
  <div>
    <h1>{{ $t('welcome') }}</h1>
    <p>{{ $t('description', { name: 'World' }) }}</p>

    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" @click="$switchLocale(locale.code)">
        {{ locale.code }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useI18n } from '#imports'

const { $t, $getLocales, $switchLocale } = useI18n()
</script>
```
