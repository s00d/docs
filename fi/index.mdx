---

Nuxt I18n Micro on kevyt ja suorituskykyinen i18n-moduuli Nuxt 3:lle ja 4:lle, suunniteltu suuriin projekteihin. Se pitää käännösajat, muistinkäytön ja bundlen koon pieninä verrattuna perinteisiin i18n-ratkaisuihin, kuten `@nuxtjs/i18n`.

Lokalisoidut reitit luodaan käännösaikana `@i18n-micro/route-strategy`-paketilla ja ratkaistaan ajonaikana `@i18n-micro/path-strategy`-paketilla, joten linkit, kielenvaihdin, `hreflang` ja uudelleenohjaukset ovat kaikki yhtäpitäviä reitittimen kanssa. Käännökset ovat pelkkää JSONia, jaettuina yhteisiin juuritiedostoihin ja sivukohtaisiin tiedostoihin, jotka kehityspalvelin luo puolestasi, ja HMR on sisäänrakennettu.

<CodeGroup>

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>
