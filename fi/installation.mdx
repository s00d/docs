## Vaatimukset

- **Node.js**: 18 tai uudempi.
- **Nuxt**: 3.x tai 4.x.

Moduuli tukee sekä Nuxt 3 -projektin rakennetta (`pages/**/*.vue`) että Nuxt 4 -rakennetta (`app/pages/**/*.vue`). Käännökset sijaitsevat konvention mukaan projektin juuressa (`locales/`), myös silloin kun käytössä on Nuxt 4:n `app/`-hakemisto.

## Asenna Nuxt-moduuli

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Rekisteröi se tiedostoon `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Katso [Pika-aloitus](/quickstart) täydellistä läpikäyntiä varten tai [Konfiguraatioviite](/guides/configuration) kaikkia asetuksia varten.

## Projektin rakenne

Oletuksena moduuli olettaa:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Juuritason tiedostot yhdistyvät jokaiseen sivukohtaiseen tiedostoon käännösaikana. Sivukohtaiset tiedostot luodaan automaattisesti, jos ne puuttuvat komennon `nuxt dev` aikana.

## Nuxt 4 -rakenne

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Jos haluat sijoittaa käännökset `app/`-hakemistoon, aseta `translationDir: 'app/locales'`.

## TypeScript

Moduuli generoi ambient-tyypit apureille `useI18n`, `$t` ja siihen liittyville helpereille oletuskielesi tiedostojen pohjalta. Tämä on oletuksena päällä (`types: true`).

Käännösavainten vahvempaa tyypitystä varten katso [`@i18n-micro/types-generator`](/integrations/types-generator).
