## Vaatimukset

- **Node.js**: 18 tai uudempi.
- **Nuxt**: 3.x tai 4.x.

Moduuli tukee sekä Nuxt 3 -projektin asettelua (`pages/**/*.vue`) että Nuxt 4 -asettelua (`app/pages/**/*.vue`). Käännökset sijaitsevat käytännön mukaan projektin juuressa (`locales/`), vaikka käyttäisit Nuxt 4:n hakemistoa `app/`.

## Asenna Nuxt-moduuli

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Rekisteröi se tiedostossa `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Katso [pika-aloituksesta](/quickstart) täydellinen läpikäynti tai [konfiguraatioviitteestä](/guides/configuration) kaikki asetukset.

## Projektin rakenne

Oletuksena moduuli odottaa seuraavaa rakennetta:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Juuritason tiedostot yhdistetään käännösvaiheessa jokaiseen sivukohtaiseen tiedostoon. Sivukohtaiset tiedostot luodaan automaattisesti, jos ne puuttuvat komennon `nuxt dev` aikana.

## Nuxt 4 -asettelu

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Jos haluat pitää käännökset hakemistossa `app/`, aseta `translationDir: 'app/locales'`.

## TypeScript

Moduuli luo automaattiset tyypit funktioille `useI18n`, `$t` ja niihin liittyville apureille oletuskielen tiedostojen perusteella. Tämä on käytössä oletuksena (`types: true`).

Vahvempaa käännösavainten tyypitystä varten katso [`@i18n-micro/types-generator`](/integrations/types-generator).
