---

Asetuksella `meta: true` (oletus) jokainen lokalisoitu sivu saa `<html lang dir>`-attribuutit, canonical-linkin, `hreflang`-vaihtoehdot, `x-default`-linkin ja Open Graph -kielitagit. Tarvitset tätä sivua, kun haluat asettaa julkisen alkuperän (origin), säätää, mitkä kielet näkyvät tageissa, tai ohittaa ne yhdellä sivulla. Useimmat sivustot tarvitsevat vain `site.url`- tai `metaBaseUrl`-arvon ja oikeat `iso`-koodit.

## Vähimmäisasetukset {#minimal-setup}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'de', iso: 'de-DE', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    metaBaseUrl: 'https://example.com',
  },
})
```

Tällöin `/de/about` renderöi:

```html
<html lang="de-DE" dir="ltr">
<link rel="canonical" href="https://example.com/de/about">
<link rel="alternate" hreflang="en-US" href="https://example.com/about">
<link rel="alternate" hreflang="de-DE" href="https://example.com/de/about">
<link rel="alternate" hreflang="ar-SA" href="https://example.com/ar/about">
<link rel="alternate" hreflang="x-default" href="https://example.com/about">
<meta property="og:locale" content="de_DE">
<meta property="og:url" content="https://example.com/de/about">
<meta property="og:locale:alternate" content="en_US">
<meta property="og:locale:alternate" content="ar_SA">
```

## Tekstin suunta {#text-direction}

`<html dir>` tulee kielen `dir`-arvosta. Jos sitä ei ole, oikealta vasemmalle kirjoitettava kieli saa arvon `rtl`, joka päätellään `iso`-arvosta (tai `code`-arvosta): arabia, heprea, persia, urdu ja muutama muu sekä mikä tahansa tagi, jossa on RTL-kirjoitusjärjestelmä, kuten `az-Arab`. Kaikki muut kielet eivät saa `dir`-attribuuttia, minkä selaimet tulkitsevat arvoksi `ltr`.

<Warning>

**`dir: 'auto'` maksaa jäsennysaikaa suurilla sivuilla** — `auto` `<html>`-elementillä saa selaimen päättelemään suunnan sisällöstä jäsennyksen aikana. Chromiumissa tämä kustannus kasvaa sivua nopeammin: noin 100 ms 5 000 elementillä ja 1 s 20 000 elementillä. Käytä sitä vain pienellä sivulla, jonka kieltä et voi tietää.

</Warning>

## Mitkä tagit saat {#which-tags-you-get}

- **hreflang**: yksi tagi jokaiselle kielelle, joka tarjoaa sivun, arvona `iso` (tai `code`, kun `iso` puuttuu), ja sen URL samalla kyselyllä kuin canonical-linkissä. Sivu, joka on rajattu [Sivun asetuksilla](/fi/guide/per-component-translations) tai `routeLocales`-asetuksella, listaa vain omat kielensä. [`hreflangBaseLanguage: true`](/fi/api/module-options#hreflangbaselanguage) lisää myös pelkän kielen (`es-ES` → `es`) ensimmäiselle alueelliselle kielelle.
- **x-default**: oletuskielen URL, vain kun oletuskieli tarjoaa sivun.
- **og:locale**: johdetaan `iso`-arvosta (`en-US` → `en_US`). Aseta kielelle `og`, kun vastaavuus ei ole suora, esimerkiksi `{ code: 'zh', iso: 'zh-Hans', og: 'zh_CN' }`; ilman kumpaakaan `og:locale`-tagia ei kirjoiteta ja kehitystila varoittaa.
- **canonical / og:url**: nykyinen URL ilman kyselyparametreja, lukuun ottamatta [`canonicalQueryWhitelist`](/fi/api/module-options#canonicalquerywhitelist)-listan parametreja (oletuksena `page`, `sort`, `filter`, `search`, `q`, `query`, `tag`).

Strategioittain:

| Strategia | hreflang ja x-default | canonical, og:url, og:locale, html-attribuutit |
| --- | --- | --- |
| `prefix`, `prefix_except_default`, `prefix_and_default` | kyllä | kyllä |
| `no_prefix` | ei (yksi URL palvelee kaikkia kieliä) | kyllä |

## Julkisen alkuperän asettaminen {#set-the-public-origin}

Absoluuttiset URL-osoitteet käyttävät ensimmäistä seuraavista:

1. [`metaBaseUrl`](/fi/api/module-options#metabaseurl);
2. `site.url` `nuxt-site-config`-moduulista (asennetaan `@nuxtjs/seo`-paketin mukana);
3. pyynnön alkuperä, johon liitetään `app.baseURL`.

Kiinnitä jompikumpi kahdesta ensimmäisestä.

<Warning>

Pyynnön alkuperään perustuva varavaihtoehto lukee `X-Forwarded-Host`- ja `X-Forwarded-Proto`-otsakkeet, koska [`metaTrustForwardedHost`](/fi/api/module-options#metatrustforwardedhost) ja `metaTrustForwardedProto` ovat oletuksena `true`. Se on turvallista vain välityspalvelimen takana, joka ylikirjoittaa nämä otsakkeet; muuten asiakas voi valita canonical-linkkiesi isännän, ja välimuisti voi välittää tämän sivun eteenpäin.

Jos sovellukseen pääsee suoraan, kiinnitä `metaBaseUrl`: toisin kuin molempien asetusten asettaminen arvoon `false`, se ohittaa myös väärennetyn `Host`-otsakkeen. Katso [Välityspalvelimen tai CDN:n takana](/fi/guide/deployment#behind-a-proxy-or-cdn).

</Warning>

Varavaihtoehto on hyödyllinen, kun yksi julkaisu vastaa useisiin verkkotunnuksiin: `https://site-a.com/en/about` ja `https://site-b.com/en/about` saavat kumpikin oman alkuperänsä.

Kun kielillä on `baseUrl`, tunnettu isäntä käyttää omaa `baseUrl`-arvoaan `metaBaseUrl`- ja `site.url`-arvojen sijaan, joten canonical ja `og:url` pysyvät kyseisessä verkkotunnuksessa ja `hreflang` osoittaa jokaisen kielen sen omaan verkkotunnukseen. Mikä tahansa muu isäntä käyttää `metaBaseUrl`-arvoa, muuten oletuskielen `baseUrl`-arvoa, muuten `site.url`-arvoa, joten väärennetty `Host` ei pääse tageihisi. Jos mitään näistä ei ole asetettu, pyynnön alkuperään perustuva varavaihtoehto säilyy, ja build varoittaa. Katso [Kerrokset ja verkkotunnukset](/fi/guide/layers#multiple-domains).

## Kielten tai sivujen jättäminen pois {#leave-locales-or-pages-out}

```ts
i18n: {
  locales: [
    { code: 'en', iso: 'en-US' },
    { code: 'ru', iso: 'ru-RU', seo: false }, // routable, but not in hreflang / og:locale:alternate
    { code: 'fr', iso: 'fr-FR', disabled: true }, // no routes, no switching, no tags
  ],
}
```

Jos oletuskielellä on `seo: false`, `x-default`-linkkiä ei kirjoiteta. Poista tagit käytöstä yhdeltä sivulta käyttämällä `disableMeta`-asetusta [Sivun asetuksissa](/fi/guide/per-component-translations#turn-off-seo-tags) tai [`routeDisableMeta`](/fi/api/module-options#routedisablemeta)-asetusta konfiguraatiossa.

## Tagien ohittaminen yhdellä sivulla {#override-tags-on-one-page}

CMS-sisällölle, josta on olemassa vain osa käännöksistä tai jonka URL-osoitteet tulevat API:sta, korvaa generoidut tagit [`useI18nHead`](/fi/composables/useI18nHead)-funktiolla:

```vue
<script setup lang="ts">
const { data: article } = await useFetch('/api/articles/hello')
// article.value.urls = { en: 'https://example.com/blog/hello', de: 'https://example.com/de/artikel/hallo' }

useI18nHead(() => ({
  meta: [{ property: 'og:title', content: article.value?.title ?? '' }],
  replace: {
    hreflang: Object.entries(article.value?.urls ?? {}).map(([locale, href]) => ({ rel: 'alternate', hreflang: locale, href })),
    ogAlternates: Object.keys(article.value?.urls ?? {}),
  },
}))
</script>
```

`replace` voi myös asettaa tai poistaa `canonical`-, `xDefault`-, `ogLocale`- ja `ogUrl`-arvot; `disable` pudottaa kokonaisia ryhmiä (`'hreflang'`, `'x-default'`, `'canonical'`, `'og'`, `'og-alternates'`, `'html'`). Välitä getteri, jotta arvot lasketaan uudelleen kielen vaihdon jälkeen. Kielikohtaisille slugeille aseta ensin `$setI18nRouteParams` ([Lokalisoidut polut](/fi/guide/custom-locale-routes#per-locale-slugs)), jolloin generoidut vaihtoehdot käyttävät niitä jo valmiiksi.

## Loppukauttaviiva {#trailing-slash}

`$localePath`, `$switchLocalePath`, `$switchLocaleRoute`-funktion reittiolio, `<i18n-link>`, `<i18n-switcher>`, kieliuudelleenohjaukset ja SEO-URL-osoitteet noudattavat yhtä kauttaviivasääntöä: oletuksena `experimental.defaults.nuxtLink.trailingSlash`, tai i18n-konfiguraation [`trailingSlash`](/fi/api/module-options), kun i18n-polkujen pitää poiketa.

## Nuxt SEO {#nuxt-seo}

[`@nuxtjs/seo`](https://nuxtseo.com/) (sitemap, robots, schema.org) toimii tämän moduulin kanssa `nuxt-site-config` 4+:n kautta. Listaa `nuxt-i18n-micro` ensimmäisenä, jotta site config voi lukea kielet, ja aseta `site.url` kerran — se syöttää myös yllä olevat tagit.

```ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro', '@nuxtjs/seo'],
  site: { url: 'https://example.com', name: 'My Site' },
  i18n: {
    defaultLocale: 'en',
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
  },
})
```

Käännetty sivuston nimi ja kuvaus tulevat kielitiedostojesi `nuxtSiteConfig.name`- / `nuxtSiteConfig.description`-avaimista. Virhe `Plugin nuxt-seo:defaults depends on nuxt-site-config:i18n but they are not registered` tarkoittaa, että `@nuxtjs/seo` on vanhempi kuin 3; päivitä se ([#133](https://github.com/s00d/nuxt-i18n-micro/issues/133)).
