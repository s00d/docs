`nuxt dev` -tilassa moduuli lisää kaksi virheenjäljityksen apuvälinettä: **i18n Micro** -välilehden Nuxt DevToolsiin käännöstiedostojen selaamiseen ja muokkaamiseen sekä Vue DevTools -tarkastimen elävälle lokaalille ja ladatuille sanakirjoille. Molemmat ovat olemassa vain kehityksessä eivätkä lisää mitään tuotantobuildeihin. Nuxt-välilehti tarvitsee vain käytössä olevan Nuxt DevToolsin; Vue-tarkastin tarvitsee lisäksi Vue DevTools -selainlaajennuksen.

## Nuxt DevTools -välilehti {#nuxt-devtools-tab}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  devtools: { enabled: true }, // the tab is registered only when DevTools are on
})
```

Avaa Nuxt DevTools (`Shift + Alt + D`) ja valitse **i18n Micro**. Välilehti näyttää:

- jokaisen `locales/`-hakemiston (juuri ja `pages/`) JSON-tiedoston jokaisesta kerroksesta sekä `additionalTranslationDirs`-hakemistojen juuritiedostot;
- editorin tiedostoa kohden; **Save** kirjoittaa tiedoston takaisin levylle, ja kehityspalvelin lataa käännökset uudelleen;
- tiedoston **Export** / **Import** JSON-muodossa sekä **Stats**, jossa näkyvät avainmäärät ja käännösten kattavuus;
- konfiguraationäkymän ratkaistuista moduulin asetuksista;
- **Translate**-toiminnon, joka täyttää puuttuvat avaimet konekäännösmoottorilla, jonka määrität välilehden asetuksissa.

Tallennus kirjoittaa vain olemassa oleviin `.json`-tiedostoihin käännöshakemistojesi sisällä. Kun tiedosto on olemassa useassa kerroksessa, kirjoitetaan projektin kopioon.

## Vue DevTools -tarkastin {#vue-devtools-inspector}

Vue DevTools -selainlaajennuksen kanssa moduuli rekisteröi i18n-tarkastimen (nykyinen lokaali, reitin pala, ladatut avaimet) sekä aikajanan, jolla näkyvät lokaalin vaihdot, palojen lataukset ja puuttuvat avaimet.

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    debug: true, // also log every $t / $ts / $tc call on the timeline
    // vueDevtools: false, // turn the inspector off, keep the Nuxt tab
  },
})
```

[`vueDevtools`](/fi/api/module-options) on oletuksena `true`. `debug: true` on monisanainen; käytä sitä vain lyhyissä istunnoissa.
