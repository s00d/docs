title: "Ajonaikaiset ohitukset"

---

Ajonaikaisten ohitusten avulla yksi build-artefakti voi toimia eri lokaaliasetuksilla ympäristö- tai asiakaskohtaisesti ilman uudelleenkääntämistä. Voit muuttaa oletuslokaalia, varalokaalia ja sitä, mitkä lokaalit ovat poissa käytöstä. Reititys, uudelleenohjaukset, renderöinti ja palvelimen apufunktiot käyttävät ohitettuja arvoja, samoin selain palvelimella renderöidyllä sivulla.

## Ohitusten asettaminen ympäristömuuttujilla {#set-overrides-with-environment-variables}

```bash
NUXT_I18N_DEFAULT_LOCALE=de \
NUXT_I18N_FALLBACK_LOCALE=en \
NUXT_I18N_DISABLED_LOCALES=fr,it \
node .output/server/index.mjs
```

| Muuttuja | Alias |
| --- | --- |
| `NUXT_I18N_DEFAULT_LOCALE` | `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE` |
| `NUXT_I18N_FALLBACK_LOCALE` | `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE` |
| `NUXT_I18N_DISABLED_LOCALES` (pilkuin eroteltu) | `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES` |

Palvelin lukee ne kerran käynnistyessään; käynnistä uudelleen ottaaksesi muutoksen käyttöön. Palvelimella renderöidyllä sivulla selain saa ratkaistut arvot palvelimelta. Asetuksella `ssr: false` palvelinrenderöintiä ei ole eikä selaimella ole ympäristöä: siellä pätee vain `runtimeConfig.public.i18nRuntime`, ja selain kirjaa alla kuvatut varoitukset.

## Ohitusten asettaminen runtimeConfigissa {#set-overrides-in-runtimeconfig}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

`runtimeConfig.public.i18nRuntime`-asetuksessa annettu arvo voittaa saman kentän `NUXT_I18N_*`-muuttujan.

Ei pidä sekoittaa käännösaikaiseen `DEFAULT_LOCALE`-muuttujaan, joka korvaa `defaultLocale`-arvon buildin aikana eikä tarvitse ajonaikaista tukea.

## Mitä voi ja ei voi muuttaa {#what-can-and-cannot-change}

| Asetus | Ajonaikana |
| --- | --- |
| `defaultLocale` | Kyllä strategioilla `prefix` ja `no_prefix`. Strategioilla `prefix_except_default` ja `prefix_and_default` se kiinnitetään buildissa (sen sivut ovat etuliitteettömät reitit); ohitus ohitetaan varoituksella. |
| `fallbackLocale` | Kyllä. |
| `disabledLocales` | Lisää buildissa poistettujen lokaalien joukkoon; ei koskaan ota yhtäkään takaisin käyttöön. Buildin oletusta ei voi poistaa käytöstä strategioilla `prefix_except_default` / `prefix_and_default`. |
| `strategy` | Ei. Ajonaikainen strategia ohitetaan varoituksella; käännä yksi artefakti strategiaa kohden. |

Virheelliset arvot eivät koskaan riko sovellusta. Jokainen tapaus kirjaa yhden varoituksen palvelinprosessia kohden:

- kaikkien lokaalien poistaminen käytöstä ohitetaan;
- `defaultLocale`, joka ei ole käytössä, palaa ensimmäiseen käytössä olevaan lokaaliin;
- `fallbackLocale`, joka ei ole käytössä, säilyttää buildin arvon, jos se on käytössä, muuten varalokaalia ei ole.

## Voimassa olevan konfiguraation lukeminen {#read-the-effective-config}

```vue
<script setup lang="ts">
const { $getI18nConfig } = useNuxtApp()
const config = $getI18nConfig() // build config with overrides applied
</script>
```

Käsittele sitä vain luku -muotoisena: palvelimella se on jaettu kaikkien pyyntöjen kesken ja jäädytetty kehitystilassa; selaimen kopiota ei ole jäädytetty. Konfiguraation tuominen polusta `#build/i18n.strategy.mjs` antaa buildin arvot ilman ohituksia.

## Poistetut lokaalit ja staattiset tiedostot {#disabled-locales-and-static-files}

Ajonaikana poistettu lokaali vastaa 404 reiteillään ja payload-reitillään, mutta sen payload-tiedostot ovat yhä hakemistossa `.output/public/_locales/` ja staattinen tiedostopalvelin palauttaa ne. Kun näiden tiedostojen ei saa olla saavutettavissa, poista lokaali käytöstä käännösaikana asetuksella `disabled: true`.
