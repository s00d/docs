---
title: "Polkujen poissulkeminen"
description: "Pidä sivut ja tiedostot locale-reitityksen ulkopuolella excludePatterns-asetuksella ja katso, mitkä polut on jo suljettu pois."
---

Joillekin poluille ei saa koskaan tulla locale-etuliitettä tai locale-uudelleenohjausta: hallintanäkymä, terveystarkistus, generoitu syöte. `excludePatterns` merkitsee ne, ja sisäänrakennettu lista kattaa jo Nuxtin sisäiset polut ja yleiset staattiset tiedostot. Poissuljettu sivu säilyttää täsmälleen kirjoittamasi polun ja renderöityy silti `$t`:n kanssa.

## Polun poissulkeminen {#exclude-a-path}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    excludePatterns: [
      '/admin', // /admin and everything below it
      '/preview-*', // glob over the whole path
    ],
  },
})
```

Tällä konfiguraatiolla `pages/admin/index.vue` vastaa vain osoitteessa `/admin`; `/de/admin`-polkua ei ole, eikä `/admin`-polkua koskaan ohjata osoitteeseen `/de/admin`.

## Kuvioiden syntaksi {#pattern-syntax}

Kuvioita verrataan polkuun ilman `app.baseURL`-osaa:

| Kuvio | Vastaa | Ei vastaa |
| --- | --- | --- |
| `'/admin'` | `/admin`, `/admin/users` | `/administrator`, `/de/admin` |
| `'/preview-*'` | `/preview-1`, `/preview-a/b` | `/de/preview-1` |
| `'/file-?'` | `/file-a` | `/file-ab` |
| `/^\/v\d+\//` | `/v2/docs` | `/docs` |

Merkkijono ilman `*`- tai `?`-merkkiä vastaa polkua ja kokonaisia sen alla olevia segmenttejä. Kun mukana on `*` (mikä tahansa merkkijono, kauttaviivat mukaan lukien) tai `?` (yksi merkki), sen on vastattava koko polkua. Aloita merkkijonot aina `/`-merkillä.

## Mitä on jo suljettu pois {#what-is-excluded-already}

Nämä eivät koskaan saa locale-reittejä tai uudelleenohjauksia, ilman mitään konfiguraatiota:

- `/api` ja `/_nuxt` sekä kaikki niiden alla oleva;
- käännösreitti, oletuksena `/_locales` ([`apiBaseUrl`](/fi/api/module-options#apibaseurl));
- mikä tahansa polku, jossa on `__`-alkuinen segmentti (`/__nuxt_content`, `/en/__og-image__`);
- `/sitemap*.xml`, `/robots.txt`, `/favicon.ico`, `/apple-touch-icon*.png`, `/manifest.json`, `/sw.js`, `/workbox-*.js`;
- mikä tahansa polku, jonka viimeinen segmentti päättyy staattisen tiedoston päätteeseen: `xml txt ico json js css png jpg jpeg gif svg webp avif pdf wasm map mp4 webm mp3 zip gz woff woff2 ttf eot`. Pisteelliset sivujen slugit, kuten `/user/john.doe`, ja `.html`-polut pysyvät sivuina.

## Mitä poissulkeminen tekee {#what-an-exclusion-does}

- **Reitit:** lokalisoituja variantteja ei generoida; sivu säilyy kirjoitetun mukaisena.
- **Uudelleenohjaukset ja 404-vastaukset:** palvelimen uudelleenohjausplugin ja asiakkaan uudelleenohjausmiddleware ohittavat polun.
- **Esirenderöinti:** vastaavat polut poistetaan esirenderöitävien reittien listalta.

Se ei estä i18n-palvelinmiddlewarea tunnistamasta pyynnön localea, eikä se estä sivua käyttämästä käännöksiä. Jos haluat pitää sivun lokalisoituna mutta SEO-tagien ulkopuolella, käytä `disableMeta`-asetusta ([Sivun konfiguraatio](/fi/guide/per-component-translations#turn-off-seo-tags)). Jos haluat pitää yhden sivun lokalisoimattomana `nuxt.config.ts`-tiedostosta polun perusteella, `globalLocaleRoutes: { '/admin': false }` ([Lokalisoidut polut](/fi/guide/custom-locale-routes#in-nuxt-config)) tekee saman reitityksen osalta.
