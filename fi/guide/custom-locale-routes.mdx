---
title: "Lokalisoidut polut"
description: "Anna sivulle eri URL jokaisella kielellä localeRoutes- tai globalLocaleRoutes-asetuksella, mukaan lukien dynaamiset parametrit ja kielikohtaiset slugit."
---

Oletuksena jokainen kieli tarjoaa sivun samassa polussa: `/en/about`, `/de/about`. Lokalisoitujen polkujen avulla kukin kieli voi käyttää omia sanojaan, kuten `/de/ueber-uns`, vaikka sivutiedosto pysyy samana. Määrität ne sivulla `$defineI18nRoute`-funktiolla tai usealle sivulle kerralla `nuxt.config.ts`-tiedostossa.

## Sivulla {#in-the-page}

```vue
<!-- pages/about.vue -->
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  localeRoutes: {
    de: '/ueber-uns',
    fr: '/a-propos',
  },
})
</script>
```

Strategialla `prefix_except_default` ja asetuksella `defaultLocale: 'en'` sivu vastaa poluissa `/about`, `/de/ueber-uns` ja `/fr/a-propos`. Kieli, jolla ei ole merkintää, säilyttää oletuspolun. Kirjoita polut ilman kielikoodia: etuliitteen lisää [strategia](/fi/guide/strategy), ja kielikoodilla alkava polku kirjaa varoituksen. Mitä muuta kutsu hyväksyy, kerrotaan sivulla [Sivun asetukset](/fi/guide/per-component-translations).

## nuxt.config-tiedostossa {#in-nuxt-config}

[`globalLocaleRoutes`](/fi/api/module-options#globallocaleroutes) tekee saman mille tahansa sivulle sen polun avaimella (tai reitin nimellä, kun se kirjoitetaan ilman alkukauttaviivaa):

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    globalLocaleRoutes: {
      '/about': { de: '/ueber-uns' },
      '/about/team': { de: '/ueber-uns/team' },
      '/admin': false, // not localized: one /admin route, no locale prefix
    },
  },
})
```

Kun sivu asettaa `localeRoutes`-arvon ja `globalLocaleRoutes`-asetuksessa on sama avain, asetustiedoston merkintä voittaa.

## Dynaamiset parametrit {#dynamic-params}

Kirjoita parametrit missä tahansa Nuxtin muodossa: `[id]`, `[[page]]`, `[...slug]` tai `:id()`. Parametrien nimien on vastattava sivutiedostoa.

```ts
// pages/products/[...slug].vue
$defineI18nRoute({
  localeRoutes: {
    en: '/our-products/[...slug]',
    de: '/unsere-produkte/[...slug]',
  },
})
```

Sisäkkäiset sivut ottavat absoluuttisen lapsipolun (`/ueber-uns/team`) tai polun, joka on suhteellinen vanhemman lokalisoituun polkuun (`team`).

## Linkittäminen lokalisoituihin sivuihin {#linking-to-localized-pages}

Linkit ratkeavat kohdekielen lokalisoituun polkuun, annoitpa reitin nimen tai tavallisen polun:

```vue
<template>
  <i18n-link :to="{ name: 'about' }">About</i18n-link>
  <i18n-link to="/about">About</i18n-link>
  <!-- de: both render /de/ueber-uns -->
  <NuxtLink :to="$localePath('/about', 'de')">Deutsch</NuxtLink>
</template>
```

Reittien nimet tulevat tiedostopolusta (`pages/about/team.vue` on `about-team`), ellet aseta nimeä `definePageMeta({ name })`-kutsulla.

## Kielikohtaiset slugit {#per-locale-slugs}

Kun itse slug eroaa kielittäin (`/our-products/red-shoe` vs. `/de/unsere-produkte/roter-schuh`), kerro kielenvaihtajalle käytettävät parametrit `$setI18nRouteParams`-funktiolla, kun data on ladattu:

```vue
<script setup lang="ts">
const { $setI18nRouteParams } = useNuxtApp()
const route = useRoute()

const { data: product } = await useFetch(`/api/products/${route.params.slug}`)

if (product.value) {
  $setI18nRouteParams({
    en: { slug: product.value.slugEn },
    de: { slug: product.value.slugDe },
  })
}
</script>
```

Tämän jälkeen `$switchLocalePath('de')` ja `<i18n-switcher>` linkittävät polkuun `/de/unsere-produkte/roter-schuh`. Avaimet ovat kielikoodeja, arvot ovat parametreja nimen mukaan (kuten sivutiedostossa).

Layoutissa oleva kielenvaihtaja renderöityy ennen kuin sivun asynkroninen setup ehtii tähän, joten renderöinnin päättyessä moduuli kirjoittaa `<i18n-switcher>`-komponentin linkit uudelleen niin `app.vue`-tiedostossa kuin sivullakin. Palvelimen HTML, vierailija ilman JavaScriptiä ja ensimmäinen asiakaspuolen renderöinti ovat silloin yhtä mieltä. Aseta parametrit tätä varten SSR:n aikana: asetuksilla `lazy` tai `server: false` linkit muuttuvat vasta hydraation jälkeen. Nuxtin SSR-striimaus lähettää HTML:n ennen kuin parametrit tiedetään, joten sitä käytettäessä ensimmäisen HTML:n linkit säilyttävät URL:n omat parametrit.

Vain kielenvaihtajan omat linkit kirjoitetaan uudelleen. Käsin kirjoitetun `$switchLocalePath`-linkin on renderöidyttävä parametrien asettamisen jälkeen, joten sijoita se sivulle, joka asettaa ne, myös `await`-lauseen jälkeen. Layoutissa se renderöityy ensin: sen palvelin-HTML säilyttää URL:n parametrit, ja hydraatio varoittaa epäsuhdasta. Käytä siellä `<i18n-switcher>`-komponenttia ja muokkaa ulkoasua sen sloteilla ja `custom*Style`-propseilla.

Parametrit kuuluvat sivulle, joka ne asetti:

- Ne pudotetaan, kun navigointi toiseen polkuun vahvistuu, joten jokainen sivu asettaa omansa. Peruutettu navigointi jättää ne paikalleen.
- Ota `$setI18nRouteParams` `useNuxtApp()`- tai `useI18n()`-funktiosta `setup`-vaiheessa, myös silloin, kun kutsut sitä myöhemmin `useAsyncData`-käsittelijässä. Siellä otettuna funktio tuntee sivunsa: jos vierailija on poistunut, myöhäinen kutsu ei tee mitään.
- `keepalive`-tilassa sivu saa asettamansa parametrit takaisin, kun vierailija palaa. `useI18nHead` toimii samoin.

## pages:extend-hookissa lisätyt reitit {#routes-added-in-pagesextend}

`pages:extend`-hookissa lisätyillä reiteillä ei ole sivutiedostoa, josta `$defineI18nRoute` luettaisiin, ja usein useat niistä jakavat yhden käärekomponentin. Ilman `name`-arvoa lisätty reitti saa nimen, jonka Nuxt antaisi sen polulle (`/a/:id()` on `a-id`), joten kielilinkit löytävät sen, ellei jollakin toisella reitillä ole jo sama nimi; anna sille silloin eksplisiittinen `name`. Pidä yhtä listaa ja jaa se sivuiksi ja reitin nimellä avainnetuksi `globalLocaleRoutes`-asetukseksi `splitLocaleRoutes`-funktiolla moduulista `@i18n-micro/utils/split-locale-routes` (lisää paketti riippuvuuksiisi):

```ts
// nuxt.config.ts
import { splitLocaleRoutes } from '@i18n-micro/utils/split-locale-routes'

const dynamic = splitLocaleRoutes([
  { name: 'products-tag', path: '/products/:tag', file: '~/pages/_dynamic.vue', paths: { de: '/produkte/:tag' } },
  { name: 'internal', path: '/internal', file: '~/pages/_dynamic.vue', paths: false }, // not localized
])

export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  hooks: {
    'pages:extend'(pages) {
      pages.push(...dynamic.pages)
    },
  },
  i18n: {
    globalLocaleRoutes: dynamic.globalLocaleRoutes,
  },
})
```

Älä laita lokalisoituja polkuja `route.meta`-kenttään: ne päätyisivät asiakaspuolen reittitaulukkoon.
