[Crowdin](https://crowdin.com/) on käännösalusta: lataat oletuskielen tiedostot palveluun, kääntäjät työskentelevät Crowdinissa ja lataat muut kielet takaisin. Moduuli lukee tavallisia JSON-tiedostoja, joten Crowdin CLI tarvitsee vain `crowdin.yml`-tiedoston, joka kuvaa `locales/`- ja `locales/pages/`-hakemistot oikein. Moduulin asetuksia ei tarvitse muuttaa.

## crowdin.yml-tiedoston määrittäminen {#configure-crowdin-yml}

```yml
# crowdin.yml
project_id_env: CROWDIN_PROJECT_ID
api_token_env: CROWDIN_PERSONAL_TOKEN
base_path: ./locales
preserve_hierarchy: true

files:
  - source: /en.json
    translation: /%two_letters_code%.json
  - source: /pages/**/en.json
    translation: /pages/**/%two_letters_code%.json
```

- `en` on oletuskielesi; sen tiedostot ovat lähdetiedostoja.
- `project_id_env` / `api_token_env` lukevat tunnisteen ja tokenin ympäristömuuttujista, joten salaisuuksia ei commitoida.
- `preserve_hierarchy: true` säilyttää `pages/<page>/`-kansiot sellaisinaan.
- Käännetyn tiedoston nimen on vastattava `nuxt.config.ts`-tiedoston kielen `code`-arvoa. `%two_letters_code%` sopii koodeille kuten `de`; koodeille kuten `pt-BR` käytä `%locale%`-muuttujaa tai kuvaa Crowdinin koodit omiisi `languages_mapping`-asetuksella.

## Lähetys ja lataus {#upload-and-download}

```bash
npm install -g @crowdin/cli

export CROWDIN_PROJECT_ID=123456
export CROWDIN_PERSONAL_TOKEN=...   # from Crowdin account settings

crowdin upload sources   # push locales/en.json and locales/pages/**/en.json
crowdin download         # write locales/de.json, locales/pages/**/de.json, ...
```

Aja molemmat CI:ssä pitääksesi tiedostot ajan tasalla. Ladatut tiedostot päätyvät repositorioosi kuten käsin muokatut; seuraava build tai kehityspalvelimen uudelleenlataus ottaa ne käyttöön.

## Ennen lähettämistä {#before-uploading}

Siivoa lähdetiedostot ensin, jotta kääntäjät eivät työskentele kuolleiden avainten parissa: [`i18n-micro clean`](/fi/api/cli#clean) poistaa käyttämättömät avaimet, [`i18n-micro check`](/fi/api/cli#check) raportoi puutteet latauksen jälkeen. CLI:ssä ei ole omaa Crowdin-integraatiota: tämä sivu kuvaa tuetun tavan.
