Tämä sivu kuvaa `@nuxtjs/i18n`-sovelluksen vastaavuudet nuxt-i18n-microssa: asetukset, apufunktiot ja tiedostorakenne. Käytä sitä, kun vaihdat moduulin olemassa olevassa sovelluksessa. URL-osoitteesi säilyvät (strategioiden nimet ovat samat), ja käännökset siirretään sivukohtaisiin JSON-tiedostoihin.

<Tip>

**Päivitätkö itse nuxt-i18n-microa?** — Katso [Päivittäminen](/fi/guide/upgrade).

</Tip>

## Moduulin vaihtaminen {#swap-the-module}

```bash
npm uninstall @nuxtjs/i18n
npm install nuxt-i18n-micro
```

```ts
// nuxt.config.ts — before
export default defineNuxtConfig({
  modules: ['@nuxtjs/i18n'],
  i18n: {
    locales: [
      { code: 'en', language: 'en-US', file: 'en.json' },
      { code: 'de', language: 'de-DE', file: 'de.json' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    langDir: 'locales',
    detectBrowserLanguage: { useCookie: true, cookieKey: 'i18n_redirected', redirectOn: 'root' },
  },
})
```

```ts
// nuxt.config.ts — after
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    translationDir: 'locales',
    localeCookie: 'i18n_redirected',
    autoDetectPath: '/',
  },
})
```

## Asetukset {#options}

| `@nuxtjs/i18n` | nuxt-i18n-micro |
| --- | --- |
| `locales[].code` | `locales[].code` |
| `locales[].language` (`iso` ennen v9:ää) | `locales[].iso` |
| `locales[].name` | `locales[].displayName` |
| `locales[].dir` | `locales[].dir` |
| `locales[].domain` | `locales[].baseUrl` (origin skeemoineen) |
| `locales[].domainDefault` | `locales[].baseDefault` |
| `differentDomains`, `multiDomainLocales` | ei tarvita: pelkkä `baseUrl` reitittää isännän mukaan, katso [Kerrokset ja verkkotunnukset](/fi/guide/layers#multiple-domains) |
| `locales[].file` / `files`, `langDir`, `lazy` | `translationDir`; tiedostot löydetään nimen perusteella ja ladataan aina sivukohtaisesti |
| `defaultLocale`, `strategy` | samat nimet, samat neljä arvoa |
| `baseUrl` | `metaBaseUrl` |
| `customRoutes: 'config'` + `pages` | `globalLocaleRoutes` |
| `detectBrowserLanguage: false` | `redirects: false` (ei uudelleenohjauksia) tai `autoDetectLanguage: false` (ohita otsake) |
| `detectBrowserLanguage.useCookie` / `cookieKey` | `localeCookie: '<name>'` (`null` poistaa evästeen käytöstä) |
| `detectBrowserLanguage.redirectOn: 'root'` | `autoDetectPath: '/'` (oletus) |
| `detectBrowserLanguage.redirectOn: 'no prefix'` | `autoDetectPath: 'no_prefix'` |
| `detectBrowserLanguage.redirectOn: 'all'` | `autoDetectPath: '*'` |
| `vueI18n`-konfiguraatiotiedosto (`fallbackLocale`, `numberFormats`, `datetimeFormats`) | `fallbackLocale`, `numberFormats`, `datetimeFormats` `i18n`-osiossa |

`alwaysRedirect`-asetusta ei ole: kun eväste on asetettu, `/` seuraa sitä jokaisella käynnillä. Täydellinen luettelo on sivulla [Moduulin asetukset](/fi/api/module-options); tunnistussäännöt ovat sivulla [Lokaalin tunnistus](/fi/guide/locale-detection).

## Apufunktiot ja composablet {#helpers-and-composables}

| `@nuxtjs/i18n` / vue-i18n | nuxt-i18n-micro (malli / `useI18n()`) |
| --- | --- |
| `const { t } = useI18n()` | `const { t } = useI18n()`, `$t` malleissa |
| `t('key', count)`, `tc` | `$tc('key', count)` |
| `te('key')` | `$has('key')` |
| `n(value, 'currency')`, `d(date, 'short')` | `$tn(value, 'currency')`, `$td(date, 'short')` |
| — | `$tdr(date)`: suhteellinen aika ("3 päivän päästä") |
| `locale.value` | `$getLocale()` |
| `locales.value` | `$getLocales()` |
| `setLocale('de')` | `$switchLocale('de')` |
| `useLocalePath()('about')` | `$localePath({ name: 'about' })` |
| `useLocaleRoute()` | `$localeRoute()` |
| `useSwitchLocalePath()('de')` | `$switchLocalePath('de')` |
| `useSetI18nParams()` | `$setI18nRouteParams()` |
| `useLocaleHead()` | automaattinen asetuksella `meta: true`; [`useLocaleHead`](/fi/composables/useLocaleHead) mukautetuille head-osioille |
| `defineI18nRoute({ paths: { de: '/ueber-uns' }, locales: [...] })` | `$defineI18nRoute({ localeRoutes: { de: '/ueber-uns' }, locales: [...] })` |
| `<NuxtLinkLocale to="about">` | `<i18n-link :to="{ name: 'about' }">` |
| `<i18n-t>` | `<i18n-t>` (slotit täyttävät `{name}`-paikkamerkit) |
| `$i18n` palvelinreiteissä | `useTranslationServerMiddleware(event)`, katso [Palvelinreitit ja API](/fi/guide/server-side-translations) |

`useI18n()` tuodaan automaattisesti. `$defineI18nRoute`-kutsun on säilytettävä `$`-merkkinsä: build lukee sen kutsun. Kaikki apufunktiot: [Metodit](/fi/api/methods).

## Käännöstiedostot {#translation-files}

Siirrä yhden suuren lokaalikohtaisen tiedoston avaimet juuritiedostoon sekä yhteen tiedostoon sivua kohden:

```text
locales/
├── en.json              # keys used on many pages (nav, footer)
├── de.json
└── pages/
    ├── index/en.json    # keys of pages/index.vue
    └── about/en.json    # keys of pages/about.vue
```

Kaiken pitäminen juuritiedostoissa toimii myös ja on nopein ensimmäinen askel. Aseta `disablePageLocales: true`, kunnes jaat ne. Katso [Käännöstiedostot](/fi/guide/translations).

### Viestisyntaksi {#message-syntax}

| vue-i18n | nuxt-i18n-micro |
| --- | --- |
| `{name}` nimetty interpolointi | sama |
| `car \| cars` (2 muotoa: 1 → ensimmäinen) | muodot valitaan määrän mukaan nollasta alkaen: kirjoita `no cars \| one car \| {count} cars` |
| `@:other.key` linkitetyt viestit | ei tueta: toista teksti tai koosta koodissa |
| `@.upper:` modifikaattorit | ei tueta: muotoile koodissa tai käytä `<i18n-t>`-komponenttia |
| `{'@'}` literaalit escapet | ei tarvita: vain `{word}`-tokenit korvataan |
| JS/TS-viestitiedostot | vain JSON |

Monikkosäännön voi korvata [`plural`](/fi/api/module-options#plural)-asetuksella.

## Tarkistukset vaihdon jälkeen {#check-after-the-switch}

- Jokainen aiempi URL-osoite ratkeaa yhä; strategioiden nimet täsmäävät, mukautetut polut siirtyvät `globalLocaleRoutes`-asetukseen tai `$defineI18nRoute`-kutsuun.
- `hreflang`, canonical ja `og:locale` tulevat valmiina asetuksella `meta: true`; poista käsin kirjoitetut.
- JSON-jäsennysvirhe kirjaa tiedostopolun; puuttuva avain kirjaa varoituksen selaimen konsoliin kehitystilassa.
