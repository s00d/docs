Tämä sivu vie Nuxt-sovelluksen tilasta, jossa i18n:ää ei ole, käännettyyn sivuun, jossa on kielenvaihdin. Tarvitset sitä kerran, projektin alussa. Lopputuloksena sinulla on lokalisoidut URL-osoitteet (`/about`, `/de/about`), yksi JSON-tiedosto kieltä ja sivua kohden sekä `$t` malleissasi.

## Asennus {#install}

Moduuli vaatii Nuxt 3.18:n tai uudemman (myös Nuxt 4 toimii) ja Node 20:n tai uudemman.

<CodeGroup>

```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>

## Määritä kielet {#configure-the-locales}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', displayName: 'English' },
      { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
      { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
    ],
    defaultLocale: 'en',
  },
})
```

Siinä on kaikki määritykset, joita ensimmäinen sovellus tarvitsee. Oletukset antavat sinulle:

- `strategy: 'prefix_except_default'`: oletuskielellä ei ole etuliitettä (`/about`), muilla on (`/de/about`). Katso [Reititysstrategiat](/fi/guide/strategy).
- `translationDir: 'locales'`: käännöstiedostot sijaitsevat projektin juuren `locales/`-hakemistossa, myös Nuxt 4:n `app/`-rakenteessa.
- `meta: true`: `hreflang`-, canonical- ja `og:locale`-tagit sekä `lang` ja `dir` `<html>`-elementissä. Katso [SEO](/fi/guide/seo).
- Vierailija, joka avaa `/`-polun, ohjataan kieleen, jota hänen selaimensa pyytää (`Accept-Language`). Katso [Kielen tunnistus](/fi/guide/locale-detection).

`iso` on SEO-tageissa käytetty kielitunniste; `code` on se, mikä näkyy URL-osoitteessa. Kaikki asetukset on lueteltu sivulla [Moduulin asetukset](/fi/api/module-options).

## Lisää käännöstiedostot {#add-translation-files}

Käynnistä kehityspalvelin komennolla `nuxt dev`. Kun Nuxt selvittää sivut, moduuli luo tyhjän `{}`-tiedoston jokaiselle kielelle ja sivulle, jolla sellaista ei ole (poista tämä käytöstä asetuksella [`disableWatcher`](/fi/api/module-options#disablewatcher)):

```text
locales/
├── en.json            # root: keys every page can use
├── de.json
├── fr.json
└── pages/
    ├── index/         # pages/index.vue
    │   ├── en.json
    │   ├── de.json
    │   └── fr.json
    └── about/         # pages/about.vue
        ├── en.json
        ├── de.json
        └── fr.json
```

Täytä juuritiedosto ja sivutiedosto:

```json
// locales/en.json
{ "nav": { "home": "Home", "about": "About" } }
```

```json
// locales/pages/index/en.json
{ "welcome": "Welcome, {name}!", "items": "no items | one item | {count} items" }
```

Sivu näkee juuriavaimet ja omat avaimensa; sen oma tiedosto voittaa ristiriidassa. Kansioiden nimet noudattavat reitin nimeä (`pages/articles/[id].vue` on `locales/pages/articles-id/`). [Käännöstiedostot](/fi/guide/translations) kattaa rakenteen, varakielet ja latauksen.

## Käytä `$t`-funktiota sivulla {#use-$t-on-a-page}

```vue
<!-- pages/index.vue -->
<script setup lang="ts">
const { t, tc, getLocale } = useI18n()

const title = t('nav.home') // 'Home'
</script>

<template>
  <h1>{{ $t('welcome', { name: 'Ada' }) }}</h1>
  <!-- Welcome, Ada! -->
  <p>{{ $tc('items', 3) }}</p>
  <!-- 3 items -->
  <p>{{ getLocale() }}</p>
  <!-- en -->
</template>
```

- Malleissa jokainen apufunktio on käytettävissä `$`-etuliitteellä (`$t`, `$tc`, `$localePath`, …).
- `<script setup>`-lohkossa `useI18n()` palauttaa samat apufunktiot sekä `$`-etuliitteellä että ilman (`t` ja `$t` ovat sama funktio). Se tuodaan automaattisesti.
- `{name}`-paikkamerkit täytetään parametriobjektista. Monikkomuodot erotetaan merkillä `|`; lukumäärä valitsee muodon (0, 1 ja sitten viimeinen kaikille suuremmille).

Kaikki apufunktiot on lueteltu sivulla [Metodit](/fi/api/methods).

## Linkitä sivujen välillä ja vaihda kieltä {#link-between-pages-and-switch-locale}

```vue
<!-- components/AppHeader.vue -->
<template>
  <nav>
    <i18n-link :to="{ name: 'index' }">{{ $t('nav.home') }}</i18n-link>
    <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
    <i18n-switcher />
  </nav>
</template>
```

- [`<i18n-link>`](/fi/components/i18n-link) on `NuxtLink`, joka osoittaa sivulle nykyisellä kielellä: `/de`-polulla about-linkki vie osoitteeseen `/de/about`.
- [`<i18n-switcher>`](/fi/components/i18n-switcher) on pudotusvalikko käytössä olevista kielistä; se pitää vierailijan samalla sivulla.
- Omille painikkeillesi kutsu `$switchLocale('de')`, joka siirtyy nykyiselle sivulle saksaksi ja muistaa valinnan. Tavalliselle `NuxtLink`-linkille käytä `$localePath({ name: 'about' })` tai `$switchLocalePath('de')`.

## Tarkista {#check-it}

Aja `nuxt dev` ja avaa:

| URL | Näyttää |
| --- | --- |
| `/` | Englanninkielisen etusivun (tai uudelleenohjauksen osoitteeseen `/de`, kun selaimesi suosii saksaa) |
| `/de` | Saksankielisen etusivun |
| `/de/about` | Saksankielisen about-sivun |
| `/en/about` | 404: oletuskielellä ei ole etuliitettä `prefix_except_default`-strategiassa |

JSON-tiedostoihin tehdyt muutokset näkyvät avoimella sivulla ilman uudelleenlatausta.
