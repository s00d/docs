title: "Reititysstrategiat"

---

`strategy`-asetus ratkaisee, näkyykö locale URL:ssä ja millä localeilla. Valitse se kerran, ennen kuin julkaiset URL:ejä: sen muuttaminen myöhemmin muuttaa jokaisen linkin. Moduuli generoi sitten lokalisoidut reitit build-vaiheessa, ja `$localePath`, `<i18n-link>` sekä kielenvaihdin lukevat ne.

## Neljä strategiaa {#the-four-strategies}

![/about-sivu localeilla en (oletus) ja de kussakin strategiassa; samat URL:t on lueteltu alla olevassa tekstissä](/images/diagrams/strategies.svg)

**Tyyppi** `Strategies` · **Oletus** `'prefix_except_default'`

URL-reititysstrategia locale-etuliitteille.

- `'no_prefix'` — URL:ssä ei ole localea; locale tallennetaan evästeeseen.
- `'prefix_except_default'` — etuliite kaikille localeille paitsi oletukselle.
- `'prefix'` — aina etuliite, myös oletuslocalelle.
- `'prefix_and_default'` — kuten `prefix`, mutta oletuslocale on saatavilla myös ilman etuliitettä.

`about`-sivun URL:t asetuksella `defaultLocale: 'en'` ja localeilla `en`, `de`:

| Strategia | Englanti | Saksa | Ei tarjoilla |
| --- | --- | --- | --- |
| `prefix_except_default` (oletus) | `/about` | `/de/about` | `/en` ja `/en/about` antavat 404:n |
| `prefix` | `/en/about` | `/de/about` | `/about` ohjaa etuliitteelliseen URL:ään |
| `prefix_and_default` | `/about` ja `/en/about` | `/de/about` | — |
| `no_prefix` | `/about` | `/about` | locale ei ole URL:ssä |

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix',
  },
})
```

Strategia kiinnitetään buildissa: sen ajonaikainen ohitus ohitetaan varoituksen kera ([Ajonaikaiset ohitukset](/fi/guide/runtime-overrides)).

## Minkä valita {#which-one-to-choose}

- **`prefix_except_default`**: useimmat sivustot. Olemassa olevat etuliitteettömät URL:t toimivat edelleen oletuskielellä.
- **`prefix`**: jokainen kieli on tasavertainen; `/` johtaa aina etuliitteelliseen etusivuun.
- **`prefix_and_default`**: tarvitset sekä `/en/...`-URL:ien että etuliitteettömien URL:ien toimivan, esimerkiksi siirtyessäsi yhdestä toiseen. Etuliitteettömiä URL:ejä ei koskaan ohjata uudelleen.
- **`no_prefix`**: kirjautumisen takana olevat sovellukset tai yksi URL sivua kohden kaikille kielille. Locale tulee evästeestä tai `?locale=`-parametrista. Hakukoneet näkevät yhden kielen URL:ää kohden, joten `hreflang`-vaihtoehtoja ei tuoteta.

Miten URL:n locale valitaan ja milloin vierailija ohjataan uudelleen, kerrotaan sivulla [Localen tunnistus](/fi/guide/locale-detection).

## Generoidut reitit {#generated-routes}

Build-vaiheessa jokainen sivu saa strategiansa tarvitsemat reittitietueet. Jokainen tietue sisältää `meta.i18n = { name, locales }`: sivun, jonka se näyttää, ja localet, joita se palvelee. Linkit, vaihdot ja uudelleenohjaukset vastataan kaikki näiden tietueiden perusteella, joten moduulin antama URL on aina sellainen, jonka reititin tarjoilee.

Localet, joilla on sama sivun polku, jakavat yhden tietueen, `/:locale(de|fr)/about`. Locale, jolla on oma polkunsa, saa oman tietueensa, jonka nimi on `localized-<page>-<locale>`:

```ts
// nuxt.config.ts: German has its own path for the about page
i18n: {
  globalLocaleRoutes: { about: { de: '/ueber-uns' } },
}
// prefix_except_default, locales en (default), de, fr:
// about                 /about
// localized-about       /:locale(fr)/about
// localized-about-de    /:locale(de)/ueber-uns
```

Mukautetut polut, sivukohtaiset locale-listat ja sivun sulkeminen lokalisoinnin ulkopuolelle käsitellään sivuilla [Lokalisoidut polut](/fi/guide/custom-locale-routes) ja [Sivun konfiguraatio](/fi/guide/per-component-translations). `localized-`-etuliite on [`localizedRouteNamePrefix`](/fi/api/module-options#localizedroutenameprefix).

<Warning>

**Reittien nimet generoidaan** — Älä kovakoodaa `localized-…`-nimiä kutsuun `router.push({ name })`. Anna sivun oma nimi `$localeRoute`-funktiolle tai `<i18n-link>`-komponentille; ne valitsevat oikean tietueen.

</Warning>

## Linkittäminen sivuun tietyllä localella {#linking-to-a-page-in-a-locale}

```vue
<script setup lang="ts">
const { localePath, localeRoute, switchLocalePath } = useI18n()

localePath({ name: 'about' }) // '/de/ueber-uns' while the page is German
localePath({ name: 'about' }, 'en') // '/about'
localePath('/about', 'de') // '/de/ueber-uns': a path is read as the page it shows
localeRoute({ name: 'products-id', params: { id: '42' } }, 'de') // resolved route: name, params, fullPath
switchLocalePath('fr') // the current page in French
</script>

<template>
  <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
  <NuxtLink :to="$switchLocalePath('de')">Deutsch</NuxtLink>
</template>
```

- Sekä nimetyt reitit että polut toimivat. Polkua verrataan generoituihin reitteihin, joten minkä tahansa localen muoto siitä hyväksytään.
- Locale, joka ei palvele sivua (katso `locales` sivulla [Sivun konfiguraatio](/fi/guide/per-component-translations)), linkittää puuttuvan sivun sijaan kyseisen localen etusivulle.
- Localekohtaiset parametrit (käännetty slug) kulkevat `$setI18nRouteParams`-funktion kautta, katso [Lokalisoidut polut](/fi/guide/custom-locale-routes).

Allekirjoitukset löytyvät sivulta [Metodit](/fi/api/methods).

## `no_prefix`-yksityiskohdat {#no_prefix-details}

- [`localeCookie`](/fi/api/module-options#localecookie) on `no_prefix`-strategiassa oletuksena `'user-locale'`, joten valinta säilyy sivun uudelleenlatauksen yli.
- `$switchLocale('de')` lataa saksankielisen sanakirjan ja korvaa nykyisen historiamerkinnän; URL ei muutu.
- Mukautetut localekohtaiset polut toimivat edelleen: asetuksella `globalLocaleRoutes: { about: { de: '/ueber-uns' } }` saksankieliset lukijat saavat polun `/ueber-uns`. Tämä URL renderöidään aina saksaksi riippumatta vierailijan preferenssistä, ja tiettyihin localeihin rajattu sivu renderöidään jollakin niistä. Polku, jonka useampi locale jakaa (`en` ja `de` molemmat polulla `/page/:id`), renderöidään preferenssin mukaan, kun se on jokin niistä. Itse preferenssi säilyy: seuraava sivu palaa siihen.
- [`noPrefixRedirect: true`](/fi/api/module-options#noprefixredirect) ohjaa uudelleen sellaisen sivun alkuperäisen polun, jolla on oletuslocalessa mukautettu polku: vierailijan localen mukautettuun polkuun, muuten oletuslocalen (`/about` → `/about-us`, kun localella `en` on `/about-us`, → `/ueber-uns` evästeellä `de`). Locale, jolla ei ole omaa mukautettua polkua, pysyy alkuperäisellä polulla ja renderöidään siellä. Parametrillisia sivuja ei ohjata uudelleen.

## Sovellukset ilman `pages/`-hakemistoa {#apps-without-pages/}

Asetuksella `pages: false` ei ole sivureittejä lokalisoitavaksi. Käytä vain juuritason käännöstiedostoja (`disablePageLocales: true`); tunnistus, eväste ja `$switchLocale` toimivat edelleen. Repositorion `test/fixtures/basic`-hakemiston `pages-false`-variantti on toimiva esimerkkikokoonpano.
