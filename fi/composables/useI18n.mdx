---
title: "useI18n"
description: "useI18n palauttaa ajonaikaiset apufunktiot (`$t`, `$tc`, `$localePath`, …) tavallisena oliona sekä `$`-etuliitteellä että ilman."
---

`useI18n()` palauttaa moduulin ajonaikaiset apufunktiot tavallisena oliona. Käytä sitä `<script setup>`-lohkoissa, composableissa ja plugineissa sen sijaan, että hakisit ne `useNuxtApp()`-kutsulla. Jokainen apufunktio on saatavilla `$`-nimellään ja etuliitteettömällä aliaksella: `t` ja `$t` ovat sama funktio.

## Allekirjoitus {#signature}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Kaikki ajonaikaiset apufunktiot tavallisena oliona.

Samat funktiot, jotka plugin injektoi nimillä `$t`, `$tc` ja niin edelleen, ovat saatavilla sekä
dollarietuliitteisellä nimellä että etuliitteettömällä aliaksella — joten sekä `const { t } = useI18n()` että
`const { $t } = useI18n()` toimivat.

**Palauttaa** — [metodiviitteessä](/fi/api/methods) kuvatut apufunktiot

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

Palautettu olio sisältää kaikki [`PluginsInjections`](/fi/api/methods)-tyypin apufunktiot. Jokainen niistä on dokumentoitu [Apufunktiot](/fi/api/methods)-sivulla.

## Esimerkki {#example}

```vue
<script setup lang="ts">
const { t, tc, localePath, switchLocale, getLocale } = useI18n()

const title = computed(() => t('page.title'))
</script>

<template>
  <h1>{{ title }}</h1>
  <p>{{ tc('items', 3) }}</p>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
  <button @click="switchLocale(getLocale() === 'en' ? 'de' : 'en')">{{ t('nav.switch') }}</button>
</template>
```

## Ei tyypissä {#not-in-the-type}

`$defineI18nRoute` on tyypitetty vain `useNuxtApp()`-funktiolle:

```ts
const { $defineI18nRoute } = useNuxtApp()
```
