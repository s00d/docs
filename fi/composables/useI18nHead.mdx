---
title: "useI18nHead"
description: "useI18nHead ohittaa generoidut i18n-SEO-tagit yhdellä sivulla: korvaa tai poista canonical-, hreflang- ja og-tagit tai lisää omiasi."
---

`useI18nHead()` muuttaa moduulin generoimia SEO-tageja vain yhdellä sivulla. Käytä sitä, kun sivu tietää reititintä paremmin: CMS-artikkeli, joka on olemassa vain joillakin kielillä, API:sta saatava canonical-URL tai ylimääräiset `og:`-tagit. Saat generoidut tagit, joiden päälle omat ohituksesi yhdistetään.

## Allekirjoitus {#signature}

```ts
useI18nHead(input?: MaybeRefOrGetter<I18nHeadInput | null>): { pageHead: any; resetPageHead: () => void }
```

Rekisteröi sivukohtaiset ohitukset i18n-SEO-head-tageille.
`02.meta`-plugin yhdistää ne `useLocaleHead`-tuloksen päälle.

Suosi getteriä (`() => ({ … })`), kun arvot tulevat `$t`- / `t`-funktiosta, jotta ne
ratkaistaan uudelleen kielen vaihtuessa. Tavallinen olio arvioidaan kerran ja pysyy jäädytettynä.

| Parametri | Tyyppi | Kuvaus |
| --- | --- | --- |
| `input` *(valinnainen)* | `MaybeRefOrGetter<I18nHeadInput \| null>` |  |

Se toimii asetuksella [`meta: true`](/fi/api/module-options#meta) (oletus): moduulin meta-plugin yhdistää syötteen [`useLocaleHead`](/fi/composables/useLocaleHead)-tuloksen päälle jokaisella head-renderöinnillä. Asetuksella `meta: false` mikään ei lue sitä.

Ohitus nollataan, kun reitin nimi muuttuu. Sivu, joka asettaa `disableMeta`-arvon, ei saa lainkaan i18n-tageja, ei myöskään ohituksia.

## Syöte {#input}

`I18nHeadInput` (paketista `@i18n-micro/types`):

| Avain | Tyyppi | Vaikutus |
| --- | --- | --- |
| `htmlAttrs` | `Record<string, string>` | Yhdistetään `<html>`-elementin attribuutteihin (`lang`, `dir`). |
| `meta` | `I18nHeadMeta[]` | Lisätään generoitujen tagien jälkeen; korvaa tagin, jolla on sama `id`, `property` tai `name`. |
| `link` | `I18nHeadLink[]` | Lisätään generoitujen linkkien jälkeen; korvaa linkin, jolla on sama `id` tai `rel` + `hreflang`. |
| `replace.canonical` | `string \| false` | Korvaa canonical-linkin `href`-arvon tai poistaa linkin. |
| `replace.hreflang` | `I18nHeadLink[] \| false` | Korvaa tai poistaa **kaikki** `rel="alternate"`-linkit, myös `x-default`-linkin. |
| `replace.xDefault` | `I18nHeadLink \| false` | Korvaa tai poistaa `x-default`-linkin. |
| `replace.ogLocale` | `string \| false` | Korvaa tai poistaa `og:locale`-tagin. |
| `replace.ogUrl` | `string \| false` | Korvaa tai poistaa `og:url`-tagin. |
| `replace.ogAlternates` | `string[] \| false` | Rakentaa `og:locale:alternate`-tagit uudelleen näistä kielikoodeista (`og`- / `iso`-arvon kautta) ohittaen nykyisen kielen, tuntemattomat koodit ja koodit, joilla ei ole `og`- tai `iso`-arvoa, tai poistaa ne. |
| `disable` | `I18nHeadDisableGroup[]` | Pudottaa generoituja ryhmiä: `'hreflang'` (ei `x-default`), `'x-default'`, `'canonical'`, `'og'` (`og:locale` + `og:url`), `'og-alternates'`, `'html'`. |

Soveltamisjärjestys: `disable`, sitten `replace`, sitten `htmlAttrs`, `meta`, `link`.

## Esimerkki {#example}

Artikkeli, joka on olemassa vain joillakin kielillä ja jonka vaihtoehtoiset URL-osoitteet tulevat API:sta:

```vue
<script setup lang="ts">
const route = useRoute()
const { t } = useI18n()
const { data: article } = await useFetch<{ title: string; urls: Record<string, string> }>(`/api/articles/${route.params.slug}`)

useI18nHead(() => {
  if (!article.value) return null
  const codes = Object.keys(article.value.urls)
  return {
    meta: [{ property: 'og:title', content: article.value.title || t('blog.title') }],
    replace: {
      hreflang: codes.map((code) => ({ rel: 'alternate', hreflang: code, href: article.value!.urls[code]! })),
      ogAlternates: codes,
    },
  }
})
</script>
```

Välitä getteri, kuten tässä, kun arvot tulevat `t()`-funktiosta tai asynkronisesta datasta: se suoritetaan uudelleen kielen vaihtuessa. Tavallinen olio luetaan kerran.
