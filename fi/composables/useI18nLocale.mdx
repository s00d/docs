---
title: "useI18nLocale"
description: "useI18nLocale lukee ja kirjoittaa locale-tilaa ja locale-evästettä — sisääntulopiste mukautetulle locale-tunnistukselle."
---

`useI18nLocale()` antaa pääsyn sovelluksen valitsemaan localeen: `i18n-locale`-tilaan ja locale-evästeeseen. Käytä sitä liitännäisessä, joka tunnistaa localen itse (verkkotunnus, käyttäjäprofiili, otsake), sen sijaan että kirjoittaisit `useState('i18n-locale')`-tilaa tai evästettä käsin. Sen kelpoisuustarkistukset käyttävät käytössä olevia localeja, ajonaikaiset ohitukset mukaan lukien.

## Allekirjoitus {#signature}

```ts
useI18nLocale(): { getEffectiveLocale: (route: unknown, getLocaleFromRoute: GetLocaleFromRoute) => string; getLocale: () => string | null; getPreferredLocale: () => string | null; hashCookie: CookieRef; isValidLocale: (locale: string | null | undefined) => locale is string; locale: any; localeCookie: CookieRef; resolveInitialLocale: (options: ResolveInitialLocaleOptions) => string; setLocale: (locale: string | null) => void; syncLocale: (locale: string | null) => void; validLocales: string[] }
```

Keskitetty sisääntulopiste i18n-localen hallintaan.
Yhdistää useState('i18n-locale'):n, locale-evästeen ja synkronointiapuvälineet.

## Palautetut arvot {#returned-values}

| Jäsen | Tyyppi | Kuvaus |
| --- | --- | --- |
| `locale` | `Ref<string \| null>` | `useState('i18n-locale')`-ref. |
| `localeCookie` | `Ref<string \| null>` | [`localeCookie`](/fi/api/module-options#localecookie)-eväste; pelkkä `{ value: null }`, kun asetus on `null`. |
| `hashCookie` | `Ref<string \| null>` | `hash-locale`-eväste hash-reitityksessä; muuten `{ value: null }`. |
| `validLocales` | `string[]` | Käytössä olevien localejen koodit. |
| `setLocale(locale)` | `(locale: string \| null) => void` | Kirjoittaa tilan ja evästeet. Ei validoi eikä lataa käännöksiä. |
| `syncLocale(locale)` | `(locale: string \| null) => void` | Kirjoittaa vain evästeet. |
| `getLocale()` | `() => string \| null` | Tila, sitten preferenssieväste (hash-eväste hash-reitityksessä). Ei validoida. |
| `getPreferredLocale()` | `() => string \| null` | Ensimmäinen **kelvollinen** arvo tilasta ja preferenssievästeestä, tai `null`. |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string` | Tila hash-reitityksessä, kun se on asetettu; muuten `getLocaleFromRoute(route)`. |
| `resolveInitialLocale(options)` | `(options: ResolveInitialLocaleOptions) => string` | `options.urlLocale`, sitten kelvollinen tila, sitten `options.serverLocale`, sitten reitin locale. Tallentaa tuloksen tilaan, kun tila ei ole kelvollinen; asiakkaalla se kirjoittaa myös evästeen. |
| `isValidLocale(locale)` | `(locale) => locale is string` | Onko `locale` listassa `validLocales`. |

Evästeet ovat voimassa vuoden, asetuksilla `path: '/'` ja `sameSite: 'lax'`.

## Esimerkki {#example}

```ts
// plugins/locale-from-domain.server.ts
export default defineNuxtPlugin({
  name: 'locale-from-domain',
  enforce: 'pre',
  setup() {
    const { setLocale, isValidLocale } = useI18nLocale()
    const host = useRequestURL().hostname // e.g. de.example.com
    const code = host.split('.')[0]
    if (isValidLocale(code)) setLocale(code)
  },
})
```

Moduulin lataajaliitännäinen lukee tilan käynnistyessään, joten sen asettavan liitännäisen on suoritettava ensin (`enforce: 'pre'`). Miten tila kilpailee URL:n, evästeen ja `Accept-Language`-otsakkeen kanssa: [Locale-tunnistus](/fi/guide/locale-detection). Koko läpikäynti: [Mukautettu tunnistus](/fi/guide/custom-auto-detect).

`setLocale()` ei vaihda näytöllä olevia käännöksiä. Vaihtaaksesi nykyisen sivun localen kutsu [`$switchLocale()`](/fi/api/methods#$switchlocale).
