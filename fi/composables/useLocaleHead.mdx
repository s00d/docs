---
title: "useLocaleHead"
description: "useLocaleHead rakentaa i18n-SEO-tagit (lang, dir, canonical, hreflang, og:locale) oliona, jonka välität useHead-funktiolle."
---

`useLocaleHead()` rakentaa nykyisen reitin i18n-head-tagit: `lang`- ja `dir`-attribuutit `<html>`-elementille, canonical-linkin, `hreflang`-vaihtoehdot `x-default`-linkin kanssa sekä `og:url`-, `og:locale`- ja `og:locale:alternate`-tagit. Käytä sitä, kun asetat [`meta: false`](/fi/api/module-options#meta) ja hallitset `useHead`-kutsua itse; asetuksella `meta: true` moduuli rekisteröi nämä tagit jo valmiiksi, ja sivukohtaiset muutokset tehdään [`useI18nHead`](/fi/composables/useI18nHead)-funktiolla.

## Allekirjoitus {#signature}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { build: () => LocaleHead; metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }, LocaleHead | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

Nykyisen reitin SEO-head-tagit: `hreflang`-vaihtoehdot jokaiselle kielelle sekä
`x-default`, canonical-linkki, `og:locale` ja `lang`/`dir` `<html>`-elementillä.

Tarvitaan vain, kun `meta` on poistettu käytöstä tai oletuksia on säädettävä — asetuksella `meta: true`
moduuli rekisteröi samat tagit itse.

| Parametri | Tyyppi | Kuvaus |
| --- | --- | --- |
| `options` | `UseLocaleHeadOptions` |  |

**Palauttaa** — `metaObject`, ref, joka sisältää `useHead`-funktiolle valmiin head-olion; `updateMeta` päivittää sen; `build` laskee head-olion nykyisestä reitistä (reaktiivinen, kun sitä luetaan getterissä, esim. `useHead(() => build())`)

```ts
const { metaObject } = useLocaleHead({ addSeoAttributes: true })
useHead(metaObject)
```

## Asetukset {#options}

| Asetus | Oletus | Kuvaus |
| --- | --- | --- |
| `addDirAttribute` | `true` | Asettaa `<html>`-elementin `dir`-attribuutin kielen `dir`-arvosta (`'auto'`, jos sitä ei ole). |
| `identifierAttribute` | `'id'` | Attribuutti, joka yksilöi jokaisen tagin (`i18n-can`, `i18n-og`, `i18n-alternate-<hreflang>`, …), jotta päivitykset korvaavat tagit niiden lisäämisen sijaan. |
| `addSeoAttributes` | `true` | Tuottaa canonical-, `hreflang`- ja `og:`-tagit. `false` säilyttää vain `htmlAttrs`-arvon. |
| `baseUrl` | `'/'` | Alkuperä (origin), joka liitetään jokaiseen URL-osoitteeseen. Pidä `'/'` suhteellisille URL-osoitteille; anna `'https://example.com'` absoluuttisille. |
| `autoUpdate` | `true` | Rakentaa `metaObject`-olion uudelleen, kun reitti tai `i18n-locale`-tila muuttuu. |

## Mitä se tuottaa {#what-it-emits}

- Ei mitään reitillä, jolla ei ole osumaa (404), tai jolla on `disableMeta` aktiiviselle kielelle.
- Canonical ja `og:url`: `$switchLocalePath(<active locale>)`, kyselyparametrit rajattuina [`canonicalQueryWhitelist`](/fi/api/module-options#canonicalquerywhitelist)-listaan ja [`trailingSlash`](/fi/api/module-options#trailingslash) sovellettuna.
- `hreflang`: yksi linkki jokaiselle käytössä olevalle kielelle, jolla sivu on olemassa, `hreflang = iso || code`, ohittaen kielet, joilla on `seo: false`; asetuksella `hreflangBaseLanguage: true` kielen ensimmäinen alueellinen locale tuottaa myös pelkän kielen tagin. Ei yhtään `no_prefix`-strategiassa.
- `x-default`: oletuskielen URL, paitsi jos strategia on `no_prefix`, oletuskielellä on `seo: false` tai sivua ei ole olemassa sillä kielellä.
- `og:locale` / `og:locale:alternate`: kielen `og`-arvosta tai muunnetusta `iso`-arvosta (`en-US` → `en_US`); ohitetaan kehitysaikaisella varoituksella, kun kumpikaan ei toimi.

## Esimerkki {#example}

```ts
// app.vue, with i18n.meta: false
const { metaObject } = useLocaleHead({ baseUrl: 'https://example.com' })
useHead(metaObject)
```

`build()` palauttaa saman olion ilman refiä: `useHead(() => build())` pysyy reaktiivisena ilman watcheria.
