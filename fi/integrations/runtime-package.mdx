`@i18n-micro/runtime` on kehysriippumaton i18n-instanssi: sanakirjat, `t()`, monikot, `Intl`-muotoilu ja muutosten tilaus, ilman `fs`-moduulia ja ilman kehystä. Käytä sitä tavallisessa TypeScriptissä, web workerissa, edge-funktiossa tai oman sidontasi pohjana. React-, Preact-, Node- ja Astro-paketit laajentavat tätä samaa luokkaa.

## Asennus {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/runtime
```

```bash npm
npm install @i18n-micro/runtime
```

```bash yarn
yarn add @i18n-micro/runtime
```

</CodeGroup>

Ei peer-riippuvuuksia. Levyllä oleville käännöstiedostoille käytä pakettia [`@i18n-micro/node`](/fi/integrations/nodejs-package).

## Käyttöönotto {#setup}

```ts
import { createI18n } from '@i18n-micro/runtime'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    en: { greeting: 'Hello, {name}!', apples: 'no apples | one apple | {count} apples' },
    de: { greeting: 'Hallo, {name}!' },
  },
  routeMessages: {
    about: { en: { title: 'About us' } },
  },
})
```

Kaikki asetukset (`plural`, `missingWarn`, `missingHandler`, `numberFormats`, `datetimeFormats`) on lueteltu kohdassa [instanssi](/fi/integrations/overview#the-instance).

## Kääntäminen {#translate}

```ts
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.tc('apples', 5) // '5 apples'
i18n.tn(1234.5) // '1,234.5'

i18n.setRoute('about')
i18n.t('title') // 'About us' (route dictionary)
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!' (root, still visible)
```

Lataa lisää sanakirjoja myöhemmin:

```ts
i18n.loadMessages({ fr: { greeting: 'Bonjour, {name} !' } }, { about: { fr: { title: 'À propos' } } })
i18n.addTranslations('fr', { nav: { home: 'Accueil' } }) // deep merge; pass false to replace

await i18n.loadFromUrl('/locales/fr.json', { locale: 'fr' })
await i18n.loadFromUrl('/locales/pages/about/fr.json', { locale: 'fr', routeName: 'about' })
await i18n.loadFromUrls([
  { url: '/locales/en.json', locale: 'en' },
  { url: '/locales/de.json', locale: 'de' },
])
```

`loadFromUrl` käyttää `fetch`-funktiota (anna `init` otsakkeita varten) ja heittää virheen, jos vastaus ei ole OK. `loadFromUrls` lataa yksi kerrallaan.

## Localen vaihtaminen {#switch-locale}

```ts
i18n.locale = 'de'
i18n.t('greeting', { name: 'Ada' }) // 'Hallo, Ada!'
```

Localen, reitin ja sanakirjan muutokset ilmoitetaan tilaajille, ja näin kehyssidonnat renderöivät uudelleen:

```ts
const stop = i18n.subscribe(() => {
  document.querySelector('#greeting')!.textContent = i18n.t('greeting', { name: 'Ada' }) as string
})
i18n.locale = 'fr'
stop()
```

`getSnapshot()` palauttaa merkkijonon, joka muuttuu jokaisella ilmoituksella (`useSyncExternalStore`-tyylisiä storeja varten).

## Pyyntökohtaisesti {#per-request}

Instanssi sisältää yhden localen ja yhden reitin. Älä vaihda palvelimella jaetun instanssin localea pyyntökohtaisesti: kaksi samanaikaista pyyntöä näkisivät toistensa localen. `i18n.fork(locale)` antaa pyynnölle oman instanssin: oma locale, varalocale ja reitti; samat sanakirjat, muotoilijat ja säännöt. Haarauttaminen maksaa saman verran riippumatta sanakirjojen määrästä. Haara näkee vanhempaansa tehdyt kirjoitukset ensimmäiseen omaan kirjoitukseensa asti, ja sen omat kirjoitukset pysyvät siinä. [Node.js](/fi/integrations/nodejs-package#per-request) lisää `run`-metodin.

## API {#api}

| Jäsen | Huomautukset |
| --- | --- |
| `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has` | katso [Kääntäminen ja muotoilu](/fi/integrations/overview#translate-and-format) |
| `locale`, `fallbackLocale` | luku/asetus |
| `currentRoute`, `setRoute(name)`, `getRoute()` | aktiivinen reitti, oletus `'index'` |
| `loadMessages(messages?, routeMessages?)` | yhdistää useita localeja ja reittejä kerralla |
| `addTranslations(locale, tree, merge = true)`, `addRouteTranslations(locale, route, tree, merge = true)` | |
| `loadFromUrl(url, { locale?, routeName?, init? })`, `loadFromUrls(entries)` | hakee JSONin `fetch`-funktiolla |
| `hasTranslation(key)` | aktiivinen locale, mikä tahansa reitti (toisin kuin `has`, joka tarkistaa aktiivisen reitin ja juuren) |
| `setTranslation(key, value)`, `resolveTranslations()` | kirjoittaa yhden avaimen; lukee yhdistetyn puun |
| `clear()`, `clearCache()` | poistaa kaikki sanakirjat |
| `subscribe(cb)`, `getSnapshot()` | muutosilmoitukset |
| `storage` | `{ translations: Map<'locale:route', Translations> }` |

Koodi, joka ei ole kielitunniste, saa monikkonsa asetuksesta `localeIso: { ua: 'uk-UA' }`; `localeIsoMap(locales)` muodostaa sen locale-listan niistä merkinnöistä, joilla on `iso`.

Moduulin exportit: `createI18n`, `I18n`, `fetchJsonTranslations`, `FormatService`, `interpolate`, `localeIsoMap` sekä tyypit `I18nOptions`, `LoadFromUrlOptions`, `LoadFromUrlEntry`, `TranslationStorage`, `Translations`, `Locale`, `PluralFunc`. Täydelliset allekirjoitukset: [pakettiviite](/fi/api/packages/runtime).
