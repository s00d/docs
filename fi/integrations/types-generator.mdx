`@i18n-micro/types-generator` lukee käännöskansiosi jokaisen JSON-tiedoston ja kirjoittaa määrittelyn, joka luettelee kaikki avaimet. Lisää se, kun haluat editorisi ehdottavan avaimia `t()`-, `$t()`- ja `<I18nT keypath>`-kutsuissa. Se toimii Nuxt-moduulina sekä Vite- tai Rollup-liitännäisenä ja luo tyypit uudelleen, kun tiedosto muuttuu.

## Asennus {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/types-generator
```

```bash npm
npm install -D @i18n-micro/types-generator
```

```bash yarn
yarn add -D @i18n-micro/types-generator
```

</CodeGroup>

Vertaisriippuvuus: `@nuxt/kit` `^3.18.0 || ^4.0.0`. Vain `/nuxt`-sisääntulo tuo sen; pelkässä Vite-projektissa vertaisriippuvuusvaroituksen voi jättää huomiotta.

## Nuxt {#nuxt}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro', '@i18n-micro/types-generator/nuxt'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Moduuli kirjoittaa tiedoston `.nuxt/types/i18n-micro.d.ts`, ja Nuxt lisää sen tyyppikontekstiin; mitään ei tarvitse sisällyttää käsin. Se lukee `i18nTypes.translationDir`-asetuksen, muuten sieltä, mistä `nuxt-i18n-micro` lukee käännökset: `translationDir` (`i18n`-asetuksista tai moduulin inline-asetuksista, oletus `'locales'`) jokaisessa kerroksessa sekä `additionalTranslationDirs`. JSON-tiedoston muokkaaminen kyseisessä kansiossa luo tyypit uudelleen `nuxi dev` -tilassa. `i18nTypes.outputFile` ohitetaan Nuxtissa (varoitus kertoo siitä).

## Vite {#vite}

`I18nTypesPlugin` on Vite-liitännäinen, jonka myös Rollup hyväksyy. Muille paketoijille kutsu `generateTypes`-funktiota skriptissä.

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { I18nTypesPlugin } from '@i18n-micro/types-generator'

export default defineConfig({
  plugins: [
    vue(),
    I18nTypesPlugin({
      srcDir: process.cwd(),
      translationDir: 'src/locales',
      outputFile: 'src/i18n-micro.d.ts',
    }),
  ],
})
```

| Asetus | Pakollinen | Huomautukset |
| --- | --- | --- |
| `srcDir` | kyllä | Perushakemisto; `translationDir` ratkaistaan sen suhteen. |
| `translationDir` | kyllä | Kansio, jossa JSON-tiedostot ovat (alikansiot kuten `pages/` mukaan lukien), tai kansioiden taulukko. |
| `outputFile` | ei | Minne määrittely kirjoitetaan; oletus `<srcDir>/i18n-micro.d.ts`. |

Liitännäinen luo tyypit kerran käännöksen alussa ja kehityspalvelimella uudelleen 300 ms kansiossa tapahtuneen muutoksen jälkeen. Varmista, että `tsconfig.json`-tiedoston `include` kattaa tulostiedoston.

## Käytä avaimia {#use-the-keys}

Luotu tiedosto laajentaa `@i18n-micro/types`-paketin `DefineLocaleMessage`-rajapintaa, mikä muuttaa `TranslationKey`-tyypin omiksi avaimiksesi:

```ts
declare module '@i18n-micro/types' {
  export interface DefineLocaleMessage {
    nav: object
    'nav.home': string
    'profile.title': string
  }
}
```

Avaimet ovat ne, joihin `t()` vastaa, myös objektit, jokaisesta kielestä ja jokaisesta sivutiedostosta, JSON-arvonsa tyypillä. `TranslationKey` on näiden avainten sekä minkä tahansa merkkijonon unioni, joten saat automaattitäydennyksen, et virheitä: väärin kirjoitettu tai dynaaminen avain kääntyy silti. Parametreja ja paluuarvoja ei tyypitetä.

Tunnetun etuliitteen alla oleville dynaamisille avaimille `ScopedKey<'prefix'>` rajaa vastaaviin avaimiin:

```ts
import type { ScopedKey } from '@i18n-micro/types'

const statusText = (status: string) => t(`status.${status}` as ScopedKey<'status'>)
```

`TranslationKey` ja `ScopedKey` tulevat paketista `@i18n-micro/types` (React, Preact ja Solid vievät uudelleen `TranslationKey`-tyypin; Vue ei).

## API {#api}

| Vienti | Sisääntulo | Huomautukset |
| --- | --- | --- |
| `I18nTypesPlugin(options)` | `@i18n-micro/types-generator` | Vite- ja Rollup-liitännäinen |
| `generateTypes(options)` | `@i18n-micro/types-generator` | kirjoittaa tiedoston, palauttaa sen polun |
| `getTypesString(options)` | `@i18n-micro/types-generator` | palauttaa määrittelyn kirjoittamatta |
| `formatKeyProperty(key)` | `@i18n-micro/types-generator` | apufunktio |
| Nuxt-moduuli (`configKey: 'i18nTypes'`) | `@i18n-micro/types-generator/nuxt` | asetus `translationDir` |

Täydelliset allekirjoitukset: [pakettiviite](/fi/api/packages/types-generator).
