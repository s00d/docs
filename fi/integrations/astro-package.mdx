`@i18n-micro/astro` kääntää Astro-sivut palvelimella: middleware valitsee kielen URL-osoitteesta ja sijoittaa pyyntökohtaisen instanssin `Astro.locals`-objektiin, ja `useI18n(Astro)` lukee sen. Käytä sitä Astro-sivustossa, joka tarvitsee kielietuliitteellisiä URL-osoitteita (`/about`, `/fr/about`) ja jaettuja JSON-sanakirjoja. Saat `.astro`-komponentit, etusivun uudelleenohjauksen vierailijan kieleen, `hreflang`-tagit ja propsit [saarekkeille](/fi/integrations/astro-islands).

## Asennus {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/astro
```

```bash npm
npm install @i18n-micro/astro
```

```bash yarn
yarn add @i18n-micro/astro
```

</CodeGroup>

Vertaisriippuvuudet: `astro` `^5.0.0 || ^6.0.0 || ^7.0.0`. Valinnaiset, vain [saarekkeille](/fi/integrations/astro-islands): `vue` `^3.3.0`, `react` `^16.8.0 || ^17.0.0 || ^18.0.0 || ^19.0.0`, `preact` `^10.0.0 || ^11.0.0`, `svelte` `^4.0.0 || ^5.0.0`.

## Käyttöönotto {#setup}

Lisää integraatio. Se paketoi sanakirjasi palvelimeen ja asentaa middlewaren, joten `src/middleware.ts`-tiedostoa ei tarvita:

```ts
// astro.config.mjs
import { defineConfig } from 'astro/config'
import node from '@astrojs/node'
import { i18nIntegration } from '@i18n-micro/astro'

export default defineConfig({
  output: 'server',
  adapter: node({ mode: 'standalone' }),
  integrations: [
    i18nIntegration({
      locale: 'en',
      fallbackLocale: 'en',
      locales: [
        { code: 'en', iso: 'en-US', displayName: 'English' },
        { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
        { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
      ],
      translationDir: 'src/locales',
    }),
  ],
})
```

Sanakirjoista tulee koodia käännösvaiheessa: palvelin ei lue levyltä, joten se toimii myös reunalla (Cloudflare, Vercel Edge). `astro dev` -tilassa tiedostoon tehty muutos tulee voimaan seuraavassa pyynnössä.

### Integraation asetukset {#integration-options}

| Asetus | Oletus | Huomautukset |
| --- | --- | --- |
| `locale` | pakollinen | Oletuskieli. |
| `fallbackLocale` | `locale` | |
| `locales` | `[]` | Täydet `Locale`-objektit. `disabled`-kieli ei ole minkään URL-osoitteen kieli eikä uudelleenohjauksen kohde. `iso` on tunniste, jonka mukaan monikot muodostetaan, kun koodi ei ole sellainen (`ua` → `uk-UA`). |
| `translationDir` | ei mitään | Palvelimeen paketoitava kansio suhteessa projektin juureen. |
| `disablePageLocales` | `false` | Sivutiedostot lasketaan juurikäännöksiksi. |
| `autoDetect` | `true` | Etusivun uudelleenohjaus, katso [Kielen tunnistus](#locale-detection). |
| `redirectToDefault` | `false` | `/` ohjaa uudelleen myös silloin, kun mikään ei suosi toista kieltä. |
| `localeCookie` | `'i18n-locale'` | `null` poistaa evästeen käytöstä. |
| `missingWarn` | `false` | |
| `middleware` | `true` | `false`: kirjoita middleware itse, katso alla. |

Ajonaikaiset asetukset julkaistaan moduulissa `virtual:i18n-micro/config` (`config.base` on Astron `base`, `config.localeCodes` käytössä olevat koodit), sanakirjat moduulissa `virtual:i18n-micro/messages`.

### Oma middleware {#your-own-middleware}

Monikkosääntö, puuttuvien avainten käsittelijä ja reititinadapteri eivät voi siirtyä konfiguraatioprosessista palvelinpakettiin. Niitä varten välitä `middleware: false` ja kirjoita `src/middleware.ts`. Astron `i18n`-konfiguraatio asetetaan silloin puolestasi arvolla `routing: 'manual'`, joten `Astro.currentLocale` ja `astro:i18n` toimivat. Astro ei salli tätä asetusta ilman `src/middleware.ts`-tiedostoa, joten integraation omalla middlewarella ne eivät toimi.

```ts
// src/middleware.ts
import { config } from 'virtual:i18n-micro/config'
import { messages } from 'virtual:i18n-micro/messages'
import { createAstroRouterAdapter, createI18n, createI18nMiddleware, localeIsoMap } from '@i18n-micro/astro'

const i18n = createI18n({
  locale: config.defaultLocale,
  fallbackLocale: config.fallbackLocale,
  localeIso: localeIsoMap(config.locales),
  messages: messages.root,
  routeMessages: messages.routes,
  plural: myPluralRule,
})

export const onRequest = createI18nMiddleware({
  i18n,
  defaultLocale: config.defaultLocale,
  locales: config.localeCodes,
  localeObjects: config.locales,
  autoDetect: config.autoDetect,
  redirectToDefault: config.redirectToDefault,
  localeCookie: config.localeCookie,
  base: config.base,
  routingStrategy: createAstroRouterAdapter(config.locales, config.defaultLocale),
})
```

Jos haluat sen sijaan lukea kansion ajon aikana, `loadTranslationsFromDir` ja `loadTranslationsIntoI18n` ovat paketissa `@i18n-micro/astro/node` (vain Node).

### Middlewaren asetukset {#middleware-options}

| Asetus | Oletus | Huomautukset |
| --- | --- | --- |
| `i18n` | pakollinen | Globaali instanssi; jokainen pyyntö saa `i18n.fork(locale)`-kopion, joka maksaa saman verran riippumatta sanakirjojen määrästä. |
| `defaultLocale` | pakollinen | |
| `locales` | pakollinen | Kielikoodit. |
| `localeObjects` | `locales` muodossa `{ code }` | Täydet `Locale`-objektit komponentteja ja SEO:ta varten. |
| `autoDetect` | `true` | Etusivun uudelleenohjaus, katso [Kielen tunnistus](#locale-detection). |
| `redirectToDefault` | `false` | `/` ohjaa uudelleen myös silloin, kun mikään ei suosi toista kieltä, oletuskielen etusivulle sellaisena kuin reititysstrategia sen ratkaisee. |
| `localeCookie` | `'i18n-locale'` | `null` poistaa evästeen käytöstä. |
| `routingStrategy` | etuliite paitsi oletus | Reititinadapteri. Metodit, jotka se jättää pois, tulevat oletusadapterista. |
| `base` | ei mitään | Astron `base`: `config.base`. |

Sivutiedostot (`src/locales/pages/blog/post/de.json`) ovat reitti `blog-post`: sivun polku yhdistettynä merkillä `-`.

## Kääntäminen {#translate}

```astro
---
// src/pages/index.astro
import { useI18n } from '@i18n-micro/astro'
import I18nT from '@i18n-micro/astro/i18n-t'

const { t, tc, locale } = useI18n(Astro)
---

<h1>{t('greeting', { name: 'Ada' })}</h1>
<p>{tc('apples', 3)}</p>
<I18nT keypath="welcome" tag="p" />
<p>{locale}</p>
```

`useI18n(Astro)` palauttaa `locale`, `defaultLocale`, `locales`, `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`, `getRoute`, `getRouteName(path?)`, `getLocaleFromPath(path?)`, `switchLocalePath(locale)`, `localizePath(path, locale?)`, `getBasePath(url?)`, `getI18n`, `addTranslations`, `addRouteTranslations`, `mergeTranslations` ja `clearCache`. Se heittää virheen, kun middleware ei ole suoritettu. Apufunktiot `getI18n`, `getLocale`, `getDefaultLocale` ja `getLocales` lukevat samaa `Astro.locals`-objektia.

Reitin nimi tulee reitistä ilman sen kieltä: `/fr/blog/post` → `blog-post`, ja jokainen `src/pages/blog/[slug].astro`-sivun URL → `blog-slug`, joten yksi kansio `locales/pages/blog-slug/` palvelee niitä kaikkia. `[...path]` on `path`. Astron `base`-asetuksen alla apufunktiot ottavat ja palauttavat sivuston URL-osoitteita: `switchLocalePath` ja `localizePath` sisältävät sen, `getBasePath` ei, koska `Astro.rewrite` ottaa polun ilman sitä.

### Komponentit {#components}

Tuo ne polusta `@i18n-micro/astro/<name>` (tai `@i18n-micro/astro/components/<name>.astro`):

| Komponentti | Propsit |
| --- | --- |
| `i18n-t` | `keypath`, `params`, `plural`, `number`, `date`, `relativeDate`, `tag` (`span`, mikä tahansa tagi), `html`, `hideIfEmpty`, `defaultValue`; muut attribuutit välitetään eteenpäin. `html`-asetuksella jokaisen haaran tulos renderöidään HTML:nä ja `params` escapoidaan. Slotteja ei ole |
| `i18n-link` | `href`, `locale` (kohdekieli, oletuksena nykyinen), `class`; muut attribuutit välitetään eteenpäin. Ulkoiset URL-osoitteet, `#hash` ja `?query` säilyvät kirjoitetun mukaisina; reitti säilyttää kyselynsä, hashinsa ja loppukauttaviivansa |
| `i18n-switcher` | `class`, `activeClass` (`'active'`), `customLabels`; renderöi linkit nykyiselle sivulle jokaisella käytössä olevalla kielellä kyselyineen |
| `i18n-group` | ei tulosteeseen vaikuttavia: `<div>` slotinsa ympärillä, ei etuliitettä |

## Kielietuliitteelliset reitit {#locale-prefixed-routes}

Pidä yksi sivu reittiä kohden hakemistossa `src/pages/` ja lisää ohuet uudelleenkirjoitustyngät hakemistoon `src/pages/[locale]/`:

```
src/pages/
  index.astro
  about.astro
  [locale]/
    index.astro
    about.astro
```

```astro
---
// src/pages/[locale]/about.astro
import { prepareLocaleRewrite } from '@i18n-micro/astro'

const target = prepareLocaleRewrite(Astro)
if (target instanceof Response) return target
return Astro.rewrite(target)
---
```

`prepareLocaleRewrite` palauttaa `404`-vastauksen tuntemattomalle `:locale`-arvolle, muuten se asettaa kielen `Astro.locals`-objektiin ja palauttaa polun ilman etuliitettä. Middleware säilyttää `locals`-objektissa jo olevan kielen, joten uudelleenkirjoitettu sivu renderöidään sillä. `getLocaleRewritePath(Astro)` palauttaa vain polun, kun validoit kielen itse.

## Kielen tunnistus {#locale-detection}

URL ratkaisee sivun kielen:

1. Kielietuliite (`/fr/about` → `fr`; myös `/en/about` on `en`).
2. Muuten se, mitä reititinadapterin `getLocaleFromPath` palauttaa, jos se ei ole oletus.
3. Muuten oletuskieli. `/about` on aina oletuskielen sivu, sanoipa eväste mitä tahansa.

`autoDetect` on uudelleenohjausvihje vain etusivulla:

- Pyyntö polkuun `/`, jonka eväste tai `Accept-Language` suosii toista kieltä, saa `302`-uudelleenohjauksen kyseisen kielen etusivulle (`/de`). q-painot huomioidaan; `de-DE` vastaa `de`-kieltä ja `de` vastaa `de-DE`-kieltä.
- `redirectToDefault`-asetuksella `/` ohjaa aina uudelleen: suositun kielen etusivulle, muuten oletuskielen etusivulle.
- `/`-vastauksessa on `Vary: Cookie, Accept-Language` (vain `Accept-Language`, kun `localeCookie` on `null`).
- Esirenderöidyt sivut eivät koskaan ohjaa uudelleen.

`detectLocale(pathname, cookies, headers, defaultLocale, locales, localeCookie?, routingStrategy?, autoDetect?)` palauttaa saman suositun kielen omaa logiikkaasi varten.

Eväste muistaa valinnan. Sivun katselu, joka tulee saman alkuperän toisen kielen sivulta, on vierailija vaihtamassa kieltä, vei hänet sinne mikä linkki tahansa: HTML-vastaus asettaa evästeen uuteen kieleen, eikä `/` ohjaa uudelleen, joten vaihdin pääsee oletuskielen etusivulle. Päätepiste, kuva, 404, lomakkeen lähetys ja esihaku eivät muuta mitään. "Sama alkuperä" on se, mitä selain kertoo `Sec-Fetch-Site`-otsakkeessa; ilman tätä otsaketta `Referer`-otsakkeen isäntää verrataan pyynnön isäntään, joten aseta välityspalvelimen takana Astron `security.allowedDomains`.

[Palvelinsaarekkeen](https://docs.astro.build/en/guides/server-islands/) tai actionin URL-osoitteessa ei ole kieltä. Se renderöidään sivulle, joka sitä pyysi, luettuna `Referer`-otsakkeesta, jonka polku on ainoa merkitsevä, joten palvelimen edessä oleva välityspalvelin ei muuta mitään, eikä se koskaan ohjaa uudelleen. Sen vastauksessa on `Vary: Referer`. Ilman `Referer`-otsaketta (`no-referrer`-käytäntö) se on oletuskielellä, ja dynaamisella sivulla sen reitti tulee URL-osoitteesta, joten sivusanakirjat eivät tavoita sitä.

## Reititinadapteri {#router-adapter}

`createAstroRouterAdapter(locales, defaultLocale)` lisää etuliitteen jokaiseen kieleen paitsi oletukseen. Astro-adapteri tarvitsee vain `getCurrentPath`-metodin; muut jäsenet ovat valinnaisia ja palaavat oletusadapteriin: `getRouteName(path, locales, routePattern?)`, `getLocaleFromPath`, `switchLocalePath`, `localizePath`, `removeLocaleFromPath`, `resolvePath` (etusivun uudelleenohjauksen kohde), `push`, `replace`, `getRoute`. Kirjoita oma adapteri aliverkkotunnus- tai jälkiliite-URL-osoitteille ja välitä se `createI18nMiddleware`-funktiolle.

## SEO {#seo}

```astro
---
// src/layouts/Layout.astro
import { useLocaleHead } from '@i18n-micro/astro'

const head = useLocaleHead(Astro, { baseUrl: 'https://example.com' })
---

<html lang={head.htmlAttrs.lang} dir={head.htmlAttrs.dir}>
  <head>
    {head.link.map((l) => <link rel={l.rel} href={l.href} hreflang={l.hreflang} />)}
    {head.meta.map((m) => <meta property={m.property} content={m.content} />)}
  </head>
  <body><slot /></body>
</html>
```

Se palauttaa `htmlAttrs`-arvot (`lang` `iso`-arvosta, `dir`), canonical-linkin (polku ilman kyselyä), `hreflang`-vaihtoehdot jokaiselle käytössä olevalle kielelle, jolla `seo !== false`, sekä `x-default`, `og:locale`, `og:locale:alternate` ja `og:url`. Asetukset: `baseUrl` (`site` Astron konfiguraatiosta, muuten juurisuhteelliset URL-osoitteet), `addDirAttribute` (`true`), `addSeoAttributes` (`true`), `hreflangBaseLanguage` (`false`).
