Saareke suoritetaan selaimessa, jossa palvelimen i18n-instanssia ei ole olemassa. `@i18n-micro/astro` antaa sivun valita saarekkeen tarvitsemat avaimet, välittää ne yhtenä propina ja lukea ne saarekkeessa pienen kehyskohtaisen adapterin kautta. Saat käyttöösi `t`, `tc`, `tn`, `td`, `tdr` ja `has` Vue-, React-, Preact- ja Svelte-saarekkeissa, ja HTML:ään päätyvät vain valitut merkkijonot.

## Käyttöönotto {#setup}

Ota ensin käyttöön [Astro-integraatio ja middleware](/fi/integrations/astro-package#setup), ja lisää sitten käyttämäsi kehyksen integraatio (`@astrojs/vue`, `@astrojs/react`, `@astrojs/preact`, `@astrojs/svelte`). Saarekeadapterit tarvitsevat kyseisen kehyksen peer-riippuvuutena: `vue` `^3.3.0`, `react` `^16.8.0 || ^17.0.0 || ^18.0.0 || ^19.0.0`, `preact` `^10.0.0 || ^11.0.0` tai `svelte` `^4.0.0 || ^5.0.0`.

## Käännösten välittäminen saarekkeelle {#pass-translations-to-an-island}

```astro
---
// src/pages/index.astro
import { getI18nProps } from '@i18n-micro/astro'
import Counter from '../components/Counter.vue'

const i18n = getI18nProps(Astro, ['counter.title', 'counter.apples'])
---

<Counter client:load i18n={i18n} />
```

`getI18nProps(Astro, keys?)` palauttaa `{ locale, fallbackLocale, currentRoute, translations }` (tyyppi `I18nClientProps`). Anna avaimet, joita saareke käyttää: jokainen ratkaistaan palvelimella kuten `t()` (reitti-, juuri- ja varasanakirjat), ja vain löydetyt avaimet päätyvät HTML:ään. Ilman `keys`-argumenttia lähetetään kaikki, mihin `t()` pystyy tällä sivulla vastaamaan, jokaiseen saarekkeeseen, joten 2000 juuriavainta tarkoittaa noin 100 kt saareketta kohden; kehitystilassa varoitus kertoo tästä, kun koko ylittää 20 kt.

Saarekkeet kääntävät vain tämän objektin perusteella. `t` palauttaa avaimen kaikelle, mitä ei välitetty, eikä linkitettyjä viestejä ratkaista.

## Vue {#vue}

Kutsu `provideI18n(() => props.i18n)` saarekkeen juurikomponentissa ja `useAstroI18n()` sen lapsikomponenteissa. Vuen `inject` ei näe saman komponentin tarjoamaa arvoa, joten hookin on oltava lapsessa, ei juuressa:

```vue
<!-- src/components/Counter.vue -->
<script setup lang="ts">
import { provideI18n } from '@i18n-micro/astro/client/vue'
import type { I18nClientProps } from '@i18n-micro/astro'
import CounterBody from './CounterBody.vue'

const props = defineProps<{ i18n: I18nClientProps }>()
provideI18n(() => props.i18n)
</script>

<template><CounterBody /></template>
```

```vue
<!-- src/components/CounterBody.vue -->
<script setup lang="ts">
import { ref } from 'vue'
import { useAstroI18n } from '@i18n-micro/astro/client/vue'

const { t, tc } = useAstroI18n()
const count = ref(0)
</script>

<template>
  <h3>{{ t('counter.title') }}</h3>
  <button @click="count++">{{ tc('counter.apples', count) }}</button>
</template>
```

## React ja Preact {#react-and-preact}

```tsx
// src/components/Counter.tsx
import { useState } from 'react'
import { I18nProvider, useAstroI18n } from '@i18n-micro/astro/client/react'
import type { I18nClientProps } from '@i18n-micro/astro'

function Body() {
  const { t, tc } = useAstroI18n()
  const [count, setCount] = useState(0)
  return <button onClick={() => setCount(count + 1)}>{t('counter.title')}: {tc('counter.apples', count)}</button>
}

export default function Counter({ i18n }: { i18n: I18nClientProps }) {
  return (
    <I18nProvider value={i18n}>
      <Body />
    </I18nProvider>
  )
}
```

Preactissa tuo `I18nProvider` ja `useAstroI18n` polusta `@i18n-micro/astro/client/preact`; API on sama.

## Svelte {#svelte}

```svelte
<!-- src/components/Counter.svelte -->
<script lang="ts">
  import { createI18nStore, useAstroI18n } from '@i18n-micro/astro/client/svelte'
  import type { I18nClientProps } from '@i18n-micro/astro'

  export let i18n: I18nClientProps
  const { t, tc } = useAstroI18n(createI18nStore(i18n))
  let count = 0
</script>

<button on:click={() => count++}>{t('counter.title')}: {tc('counter.apples', count)}</button>
```

`useAstroI18n(store)` palauttaa myös `store`-olion `$store`-lukuja varten templatessa.

## Säilyvät saarekkeet {#persisted-islands}

Saareke, jolla on `transition:persist`, saa uudet propsit navigoinnin jälkeen. React, Preact ja Vue (kun sille annetaan getter) seuraavat niitä. Sveltessä säilytä store ja välitä ne eteenpäin: `const store = createI18nStore(i18n)`, `const { t } = useAstroI18n(store)`, sitten `$: store.set(i18n)` (runesien kanssa `$effect(() => store.set(i18n))`).

## API {#api}

| Tulopiste | Exportit |
| --- | --- |
| `@i18n-micro/astro` | `getI18nProps`, tyyppi `I18nClientProps` |
| `@i18n-micro/astro/client/vue` | `provideI18n(props \| () => props)`, `useAstroI18n()` |
| `@i18n-micro/astro/client/react` | `I18nProvider` (`value`-prop), `useAstroI18n()` |
| `@i18n-micro/astro/client/preact` | `I18nProvider` (`value`-prop), `useAstroI18n()` |
| `@i18n-micro/astro/client/svelte` | `createI18nStore(props)`, `useAstroI18n(store)` |
| `@i18n-micro/astro/client` | puhtaat `translate` ja `hasTranslation` ilman kehystä |

Jokainen `useAstroI18n` palauttaa `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`, `setLocale`, `setRoute` sekä `locale`-arvon. Saarekkeella on yksi yhdistetty sanakirja, joten sen `has` on tosi avaimelle, johon `t` pystyy vastaamaan, myös varalocalesta; palvelimella `has` katsoo vain aktiivista localea.
