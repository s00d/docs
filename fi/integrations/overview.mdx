`@i18n-micro/*`-paketit tuovat Nuxt I18n Micron käännösytimen Vueen, Reactiin, Preactiin, Solidiin, Astroon, VitePressiin ja tavalliseen JavaScriptiin. Käytä niitä, kun sovelluksesi ei ole Nuxt-sovellus tai kun Nuxtin ulkopuolinen skripti tai palvelin tarvitsee samat käännöstiedostot. Kaikki paketit jakavat yhden instanssimallin, yhden reititinsovittimen sopimuksen ja samat neljä komponenttia, jotka kuvataan kerran tällä sivulla.

Jokaisella paketilla on playground repositorion hakemistossa `packages/<name>/playground`.

## Instanssi {#the-instance}

`createI18n(options)` palauttaa yhden instanssin, joka sisältää sanakirjat, nykyisen kielen ja nykyisen reitin. Asetukset ovat samat jokaisessa paketissa:

| Asetus | Tyyppi | Oletus | Huomiot |
| --- | --- | --- | --- |
| `locale` | `string` | pakollinen | Aktiivinen kieli. |
| `fallbackLocale` | `string` | `locale` | Haetaan, kun avain puuttuu `locale`-kielestä. |
| `messages` | `Record<locale, Translations>` | `{}` | Juurisanakirjat (`'index'`-reitti). |
| `routeMessages` | `Record<route, Record<locale, Translations>>` | `{}` | Reittisanakirjat. Vain Runtime, React, Preact, Node ja VitePress. |
| `plural` | `PluralFunc` | `defaultPlural` | Mukautettu monikkosääntö. |
| `missingWarn` | `boolean` | `true` | Vain kehityksessä `console.warn` selaimessa puuttuvasta avaimesta. |
| `missingHandler` | `(locale, key, routeName) => void` | — | Kutsutaan varoituksen sijaan. |
| `numberFormats` | `Record<locale, Record<name, Intl.NumberFormatOptions>>` | — | Nimetyt muodot: `tn(9.5, 'currency')`. |
| `datetimeFormats` | `Record<locale, Record<name, Intl.DateTimeFormatOptions>>` | — | Nimetyt muodot: `td(date, 'short')`. |
| `timeZone` | `string` | ajoympäristön vyöhyke | IANA-vyöhyke `td`-päivämäärille; se ei vaikuta `tdr`-funktioon. Aseta se, jotta palvelin ja selain renderöivät saman päivämäärän. |
| `now` | `() => number` | `Date.now` | `tdr`-funktion kello. Anna hydraatiolle palvelimen aika, jotta molemmat renderöivät saman tekstin. |
| `localeIso` | `Record<code, string>` | — | Monikkosääntöihin käytettävä BCP 47 -tagi (`ua` → `uk-UA`). React, Preact ja Solid ottavat sen providerin `locales`-asetuksen `iso`-arvosta. |

Sanakirjat ovat `i18n.storage.translations`-kentässä, joka on `Map`, jonka avaimet ovat muotoa `locale:route` (`en:index`, `en:about`).

Avainta haetaan nykyisen reitin sanakirjasta, sitten juurisanakirjasta, ensin `locale`-kielelle, sitten `fallbackLocale`-kielelle. Puuttuva avain palauttaa itse avaimen (tai antamasi `defaultValue`-arvon).

```ts
i18n.addTranslations('en', { nav: { home: 'Home' } }) // root, deep-merged
i18n.addRouteTranslations('en', 'about', { title: 'About us' }) // route chunk
i18n.addTranslations('en', { nav: { home: 'Start' } }, false) // replace instead of merge
i18n.setRoute('about')
i18n.t('title') // 'About us'
i18n.t('nav.home') // 'Start' (root key, still visible on the route)
```

### Kääntäminen ja muotoilu {#translate-and-format}

| Metodi | Palauttaa |
| --- | --- |
| `t(key, params?, defaultValue?, routeName?)` | Arvon (merkkijono, numero, olio), johon `{param}` on interpoloitu. |
| `ts(...)` | Sama kuin `t`, merkkijonona. |
| `tc(key, count \| params, defaultValue?)` | Monikkomuodon. |
| `tn(value, options \| name)` | `Intl.NumberFormat` aktiivisella kielellä. |
| `td(value, options \| name)` | `Intl.DateTimeFormat`. |
| `tdr(value, options?)` | Suhteellisen ajan (`3 days ago`). |
| `has(key, routeName?)` | `true`, kun aktiivisella kielellä on avain (reitti- tai juurisanakirja; varakieltä ei tarkisteta). |

`defaultPlural` jakaa arvon `|`-merkin kohdalta ja valitsee muodon indeksistä `count` rajattuna viimeiseen; negatiivinen, murtoluku tai `NaN` valitsee viimeisen muodon.

Mukautettu `plural` saa argumentit `(key, count, params, locale, getter)`. Lue arvo `getter(key)`-kutsulla; älä jaa avainta:

```ts
import type { PluralFunc } from '@i18n-micro/vue'

const plural: PluralFunc = (key, count, params, _locale, getter) => {
  const value = getter(key)
  if (typeof value !== 'string') return null
  const forms = value.split('|').map((form) => form.trim())
  return (count === 1 ? forms[0] : forms[1] ?? forms[0])!.replace('{count}', String(count))
}
```

## Reititinsovitin {#router-adapter}

SPA-paketit eivät riipu reitittimestä. Reititinsovitin (`I18nRoutingStrategy`) kertoo niille, miten nykyinen polku luetaan, miten navigoidaan ja miten lokalisoitu polku rakennetaan. Sisäänrakennetut sovittimet lisäävät etuliitteen jokaiselle kielelle paitsi `defaultLocale`-kielelle (`/about`, `/de/about`).

| Jäsen | Pakollinen | Käyttäjä |
| --- | --- | --- |
| `getCurrentPath(): string` | kyllä | aktiivisen linkin tarkistus (sivun mukaan, kysely ja hash eivät vaikuta), `switchLocale` (säilyttää ne) |
| `push({ path }): void` | kyllä | `switchLocale`, `<I18nLink>` ilman `linkComponent`-arvoa, `<I18nSwitcher>` |
| `replace({ path }): void` | kyllä | — |
| `resolvePath(to, locale)` | ei | `localePath`, `localeRoute`, `<I18nLink>`; ilman sitä polut palautetaan sellaisinaan |
| `linkComponent` | ei | `<I18nLink>` renderöi sen (esim. `RouterLink`) `<a>`-elementin sijaan |
| `getRoute()` | ei | `{ fullPath, query }` SEO-apufunktioille |

`push` ja `replace` ovat pakollisia Vuessa, Reactissa, Preactissa ja Solidissa. Astrolla on oma palvelinpuolen sovittimensa, jossa `push`/`replace` ovat valinnaisia (katso [Astro](/fi/integrations/astro-package#router-adapter)).

Minimaalinen sovitin mille tahansa historiaan perustuvalle reitittimelle:

```ts
import type { I18nRoutingStrategy } from '@i18n-micro/react'

const locales = ['en', 'de']
const stripLocale = (path: string) => path.replace(/^\/(en|de)(?=\/|$)/, '') || '/'

export const historyAdapter: I18nRoutingStrategy = {
  getCurrentPath: () => window.location.pathname + window.location.search + window.location.hash,
  push: ({ path }) => window.history.pushState({}, '', path),
  replace: ({ path }) => window.history.replaceState({}, '', path),
  resolvePath: (to, locale) => {
    const path = stripLocale(typeof to === 'string' ? to : to.path || '/')
    return locale === 'en' ? path : `/${locale}${path === '/' ? '' : path}`
  },
}
```

## Komponentit {#components}

Vue, React, Preact ja Solid sisältävät samat neljä komponenttia. Niiden propsit vastaavat toisiaan; React, Preact ja Solid välittävät muut propsit juurielementille.

### `<I18nT>` {#&lt;i18nt&gt;}

| Props | Tyyppi | Huomiot |
| --- | --- | --- |
| `keypath` | `string` | pakollinen |
| `params` | `object` | interpolointiarvot |
| `plural` | `number \| string` | renderöi `tc(keypath, count)` |
| `number` | `number \| string` | välittää `tn(number)` muodossa `{number}` |
| `date` | `Date \| string \| number` | välittää `td(date)` muodossa `{date}` |
| `relativeDate` | `Date \| string \| number` | välittää `tdr(relativeDate)` muodossa `{relativeDate}` |
| `tag` | `string` | kääre-elementti, oletuksena `span` |
| `html` | `boolean` | renderöi käännöksen HTML:nä; sen on oltava luotettava, parametrit escapetaan |
| `defaultValue` | `string` | korvaa puuttuvan avaimen, ja renderöidään sellaisenaan, kun `hideIfEmpty` piilottaa tyhjän arvon |
| `hideIfEmpty` | `boolean` | ei renderöi mitään tyhjälle käännökselle |
| `customPluralRule` | `PluralFunc` | monikkosääntö tälle elementille |

Vain yksi muotoiluprops on voimassa, tarkistettuna tässä järjestyksessä: `number`, `date`, `relativeDate`, `plural`.

#### Rikas teksti {#rich-text}

`{placeholder}` voi sisältää elementin. Vuessa se on nimetty slot; Reactissa, Preactissa ja Solidissa `components`-props antaa elementit, tai niitä palauttavat funktiot, nimen mukaan. Kummassakin tapauksessa se voittaa samannimisen parametrin, toimii jokaisessa haarassa ja säilyy, vaikka kieli järjestäisi paikkamerkit uudelleen.

```tsx
// { "terms": "I accept the {link} of {company}" }
<I18nT keypath="terms" params={{ company: 'ACME' }} components={{ link: <a href="/terms">terms</a> }} />
```

Solidissa välitä funktio, kun paikkamerkki toistuu: yksi solmu voi olla vain yhdessä paikassa. `children` korvaavat tekstin, ja funktiona ne saavat `{ translation }`, kuten Vuen oletusslot. `html` ohittaa kaikki nämä.

### `<I18nLink>` {#&lt;i18nlink&gt;}

| Props | Tyyppi | Huomiot |
| --- | --- | --- |
| `to` | `string \| { path }` | lokalisoidaan sovittimen `resolvePath`-funktiolla |
| `activeStyle` | tyyliolio | yhdistetään `style`-arvon päälle nykyisellä sivulla; React, Preact ja Solid soveltavat sitä myös ylempään osioon |
| `localeRoute` | funktio | ohittaa `resolvePath`-funktion tälle linkille |

Ulkoiset URL-osoitteet (`https://`, `mailto:`, `tel:`) renderöidään muodossa `<a target="_blank" rel="noopener noreferrer">`; oma `target`- tai `rel`-arvosi voittaa. `onClick` suoritetaan aina. Muokattu napsautus, toinen hiiren painike tai `target` jätetään selaimen hoidettavaksi.

### `<I18nSwitcher>` {#&lt;i18nswitcher&gt;}

Pudotusvalikko käytössä olevista kielistä (`disabled: true` -kielet piilotetaan) sisäisillä oletustyyleillä. Sen kohteet ovat linkkejä, joiden `lang`, `hreflang` ja `dir` tulevat kielestä. Oletuksena kohteen napsauttaminen asettaa kielen ja kutsuu sovittimen `push`-funktiota lokalisoidulla nykyisellä polulla; `switchLocale`-props korvaa tämän toiminnon. Kun käytössä on `localeRoute` eikä reititintä, selain seuraa linkkiä. Escape tai napsautus valikon ulkopuolella sulkee sen.

| Props | Huomiot |
| --- | --- |
| `locales`, `currentLocale`, `getLocaleName` | ohittavat tarjotut arvot |
| `switchLocale(code)` | korvaa sisäänrakennetun vaihdon |
| `localeRoute` | korvaa `resolvePath`-funktion |
| `customLabels` | `{ de: 'DE' }` |
| `customWrapperStyle`, `customButtonStyle`, `customDropdownStyle`, `customItemStyle`, `customLinkStyle`, `customActiveLinkStyle`, `customDisabledLinkStyle`, `customIconStyle` | tyylien ohitukset |

### `<I18nGroup>` {#&lt;i18ngroup&gt;}

`<div class="i18n-group">`, joka antaa lapsilleen etuliitteellä varustetun `t`-funktion. Se **ei** lisää etuliitettä sen sisällä oleviin `<I18nT>`- tai `t()`-kutsuihin; vain sen eteenpäin välittämä `t` saa etuliitteen.

| Props | Huomiot |
| --- | --- |
| `prefix` | pakollinen, esim. `'profile'` |
| `groupClass` | ylimääräinen luokka kääreelle |

Etuliitteellinen `t` tulee Vuessa scoped slotin kautta (`v-slot="{ t }"`) ja Reactissa, Preactissa ja Solidissa render-prop-lapsen kautta (`{({ t }) => …}`).

## Tyypitetyt avaimet {#typed-keys}

`t()` hyväksyy minkä tahansa merkkijonon. Saadaksesi automaattisen täydennyksen avaimillesi generoi määrittely [tyyppigeneraattorilla](/fi/integrations/types-generator). Avaimia ehdotetaan, mutta niitä ei pakoteta, eikä parametreja tyypitetä.

## Vertailu Nuxt-moduuliin {#compared-with-the-nuxt-module}

Paketeissa ei ole tiedostopohjaista reititystä, palvelinmiddlewarea eikä käännöslataajaa: sinä päätät, milloin JSON ladataan (`import`, `fetch` tai `@i18n-micro/node` palvelimella) ja mitä reititinsovitinta käytetään. Kielen tunnistus, SEO-metatiedot ja reittien generointi ovat Nuxt-ominaisuuksia; Astrolla on oma middlewarensa tunnistukseen ja `useLocaleHead` SEO:ta varten.
