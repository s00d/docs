# Integraatiot

`@i18n-micro`-paketit ovat kevyitä, frameworkkiin sidottuja versioita Nuxt I18n Microsta, jotka on suunniteltu integroitavaksi eri frameworkeihin ja ympäristöihin. Nämä paketit tarjoavat i18n-ydintoiminnallisuuden minimaalisella jalanjäljellä keskittyen olennaisiin käännösominaisuuksiin ja peruskomponentteihin.

## Yleiskatsaus

Nämä integraatiopaketit ovat **pienoisversioita** täydestä Nuxt I18n Micro -moduulista sisältäen vain olennaisen toiminnallisuuden, jota kansainvälistämiseen tarvitaan:

- **Käännöksen ydinominaisuudet** - Peruskäännösmetodit, monikkomuodot ja muotoilu
- **Olennaiset komponentit** - Pieni joukko UI-komponentteja yleisiin i18n-tehtäviin
- **Router-adapterikuvio** - Joustava reititysintegraatio adapterin abstraktion kautta
- **TypeScript-tuki** - Täydelliset tyyppimäärittelyt tyyppiturvalliseen kehitykseen

Toisin kuin täysi Nuxt-moduuli, nämä paketit:

- Eivät sisällä frameworkkikohtaista reitityslogiikkaa
- Vaativat, että toteutat router-adapterin reititysominaisuuksia varten
- Keskittyvät käännöstoiminnallisuuteen frameworkkiin integroinnin sijaan
- On suunniteltu kevyiksi ja frameworkista riippumattomiksi, kun mahdollista

## Ydinkomponentit

Kaikki frameworkkipaketit sisältävät seuraavat olennaiset komponentit:

### `<I18nT>`

Käännöskomponentti, joka renderöi käännetyn tekstin tuella seuraaville:

- **Parametrien interpolaatio** - Korvaa paikkamerkit dynaamisilla arvoilla
- **Monikkomuodot** - Automaattinen monikkomuodon valinta lukumäärän perusteella
- **Numeroiden muotoilu** - Muotoile numerot kielen mukaan
- **Päivämäärän muotoilu** - Muotoile päivämäärät ja suhteelliset ajat
- **HTML-renderöinti** - Valinnainen HTML-sisällön renderöinti
- **Oletusarvot** - Fallback-teksti, kun käännös puuttuu

**Esimerkki:**

```vue
<!-- Vue -->
<I18nT keypath="greeting" :params="{ name: 'World' }" />
```

```tsx
// React
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```tsx
// Solid
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```astro
<!-- Astro -->
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

### `<I18nLink>`

Paikallistettu linkkikomponentti, joka käsittelee kieliprefiksejä URL-osoitteissa automaattisesti. Ominaisuudet:

- **Automaattinen polun paikallistaminen** - Lisää/poistaa kieliprefiksejä reititysstrategian perusteella
- **Aktiivisen tilan tunnistus** - Korostaa nykyisen reitin
- **Ulkoisten linkkien tuki** - Tunnistaa ja käsittelee ulkoiset URL-osoitteet automaattisesti
- **Router-integraatio** - Käyttää router-adapterin linkkikomponenttia, kun saatavilla
- **Mukautettu tyylitys** - Tukee aktiivisia ja hover-tiloja

**Esimerkki:**

```vue
<!-- Vue -->
<I18nLink to="/about" active-class="active">
  About Us
</I18nLink>
```

```tsx
// React
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```tsx
// Solid
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```astro
<!-- Astro -->
<I18nLink href="/about" class="nav-link">
  About Us
</I18nLink>
```

### `<I18nSwitcher>`

Kielenvaihtajakomponentti, joka tarjoaa alasvetovalikon tai listan käyttöliittymän kielten vaihtamiseen. Ominaisuudet:

- **Automaattinen kielilista** - Generoi vaihtoehdot konfiguroiduista kielistä
- **Nykyisen kielen korostus** - Ilmaisee aktiivisen kielen visuaalisesti
- **Mukautetut otsikot** - Tuki mukautetuille kielinäyttönimille
- **Router-integraatio** - Navigoi automaattisesti paikallistettuihin polkuihin
- **Saavutettavuus** - Asianmukaiset ARIA-attribuutit ja näppäimistönavigointi

**Esimerkki:**

```vue
<!-- Vue -->
<I18nSwitcher />
```

```tsx
// React
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```tsx
// Solid
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```astro
<!-- Astro -->
<I18nSwitcher />
```

### `<I18nGroup>`

Komponentti käännösten ryhmittelyyn yhteisellä prefiksillä, hyödyllinen käännösten järjestämiseen sivun tai ominaisuuden mukaan. Ominaisuudet:

- **Prefiksin scope** - Lisää prefiksin automaattisesti kaikkien ryhmässä olevien käännösavainten eteen
- **Sisäkkäiset ryhmät** - Tuki sisäkkäisille käännösryhmille
- **Selkeä organisointi** - Auttaa säilyttämään järjestäytyneen käännösrakenteen

**Esimerkki:**

```vue
<!-- Vue -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

```tsx
// React
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```tsx
// Solid
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```astro
<!-- Astro -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

## Jaetut `createI18n`-asetukset \{#create-i18n-options\}

Jokainen frameworkkipaketti luodaan samalla tavalla — vain asetustyypin nimi on frameworkin mukainen (`ReactI18nOptions`, `SolidI18nOptions` jne.). Asetukset itsessään ovat identtiset:

| Ominaisuus       | Tyyppi                                                     | Pakollinen | Oletus           | Kuvaus                                          |
| ---------------- | ---------------------------------------------------------- | ---------- | ---------------- | ----------------------------------------------- |
| `locale`         | `string`                                                   | ✅         | -                | Nykyinen kielikoodi (esim. `'en'`)              |
| `fallbackLocale` | `string`                                                   | ❌         | Sama kuin `locale` | Fallback-kieli, kun käännös puuttuu           |
| `messages`       | `Record<string, Translations>`                             | ❌         | `\{\}`             | Alkuperäiset käännösviestit                    |
| `plural`         | `PluralFunc`                                               | ❌         | `defaultPlural`  | Mukautettu monikkomuotofunktio                  |
| `missingWarn`    | `boolean`                                                  | ❌         | `true`           | Näytä konsolivaroituksia puuttuvista käännöksistä |
| `missingHandler` | `(locale: string, key: string, routeName: string) => void` | ❌         | -                | Mukautettu käsittelijä puuttuville käännöksille |

Kaikki näiden lisäksi on frameworkkikohtaista ja dokumentoitu kyseisen paketin sivulla.

## Router-adapterin abstraktio

Kaikki frameworkkipaketit käyttävät **router-adapterikuviota** erottaakseen i18n-toiminnallisuuden tietyistä router-toteutuksista. Tämä suunnittelu mahdollistaa:

- **Joustavuus** - Käytä mitä tahansa router-kirjastoa tai ei router-kirjastoa lainkaan
- **Frameworkista riippumattomuus** - Pidä reitityslogiikka sovelluksessasi, ei i18n-paketissa
- **Kevyt ydin** - I18n-paketti pysyy pienenä ja keskittyneenä

### Router-adapterin toteuttaminen

Käyttääksesi reititysominaisuuksia sinun täytyy toteuttaa `I18nRoutingStrategy`-rajapinta:

```typescript
interface I18nRoutingStrategy {
  getCurrentPath: () => string
  linkComponent?: Component
  push: (target: { path: string }) => void
  replace: (target: { path: string }) => void
  resolvePath?: (to: string | { path?: string }, locale: string) => string | { path?: string }
  getRoute?: () => { fullPath: string; query: Record<string, unknown> }
}
```

Jokaisen paketin dokumentaatio sisältää täydelliset esimerkit adaptereiden toteuttamisesta suosituille routereille:

- **Vue**: Vue Router -adapterin esimerkki
- **React**: React Router -adapterin esimerkki
- **Solid**: Solid Router -adapterin esimerkki
- **Astro**: Tiedostopohjaisen reitityksen adapteriesimerkki

## Ydinominaisuudet

Kaikki paketit jakavat nämä ydinominaisuudet:

### Käännösmetodit

- `t()` - Peruskäännös parametrien interpolaatiolla
- `ts()` - Käännös, joka palauttaa aina merkkijonon
- `tc()` - Monikkomuototietoinen käännös
- `tn()` - Numeroiden muotoilu
- `td()` - Päivämäärän muotoilu
- `tdr()` - Suhteellisen ajan muotoilu
- `has()` - Tarkista onko käännösavain olemassa

### Kielenhallinta

- **Kielen vaihtaminen** - Vaihda nykyinen kieli ohjelmallisesti
- **Fallback-kieli** - Automaattinen palautuminen, kun käännös puuttuu
- **Reittikohtaiset käännökset** - Sivutason käännösten organisointi
- **Käännösten välimuistitus** - Älykäs välimuistitus suorituskyvyn parantamiseksi

### TypeScript-tuki

Kaikki paketit tarjoavat:

- Täydelliset TypeScript-määrittelyt
- Tyyppiturvalliset käännösavaimet (types-generatorin kanssa)
- IntelliSense-tuki IDE:issä
- Käännösaikaisen virhetarkistuksen

## Aloittaminen

2. **Asenna paketti** - Käytä haluamaasi pakettien hallintaa
