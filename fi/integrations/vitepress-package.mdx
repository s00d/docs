`@i18n-micro/vitepress` lisää VitePress-sivustolle ajonaikaiset sanakirjat: `$t` ja `<I18nT>` markdownin sisällä, polkuapufunktiot ja SEO-tagit, rakennettuna paketin [`@i18n-micro/vue`](/fi/integrations/vue-package) päälle. Käytä sitä, kun samat käyttöliittymän merkkijonot esiintyvät monilla sivuilla etkä halua monistaa niitä jokaiselle localelle. Locale seuraa VitePressin omia polkulocaleja (`/`, `/fr/`).

## Milloin sitä käytetään {#when-to-use-it}

| Tarve | Ratkaisu |
|------|----------|
| Monistetut `.md`-tiedostot, URL-etuliitteet | VitePressin `locales` |
| Ajonaikainen `$t` / komponentit / polkujen synkronointi / SEO-head | `@i18n-micro/vitepress` |
| Oletusteeman käyttöliittymän otsikot (`docFooter`, hakukäyttöliittymä) | Oma `themeConfig` jokaiselle localelle |

<Tip>

**Playground** — [`packages/vitepress/playground`](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/vitepress/playground) — `pnpm -C packages/vitepress/playground dev`

</Tip>

## Asennus {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vitepress
```

```bash npm
npm install @i18n-micro/vitepress
```

```bash yarn
yarn add @i18n-micro/vitepress
```

</CodeGroup>

Peer-riippuvuudet: `vitepress` `>=1.0.0 || >=2.0.0-alpha.0`, `vue` `^3.3.0`. Node-skriptit käyttävät pakettia `@i18n-micro/node`, joka asennetaan paketin mukana ja exportataan uudelleen polun `/node` kautta. Julkaistut tyypit vaativat Vue 3.5.5:n tai uudemman asetuksella `skipLibCheck: false`; asetuksella `skipLibCheck: true`, joka on tavallinen template-asetus, myös vanhemmat versiot kääntyvät.

## Käyttöönotto {#setup}

```
locales/en.json
locales/fr.json
locales/pages/guide/demo/en.json   # optional page-scoped
locales/pages/guide/demo/fr.json
```

Sivutiedostot vastaavat reittien nimiä samalla tavalla kuin Nuxtissa/Astrossa (`guide/demo` → `guide-demo`).

### 1. Konfiguraatio — `@i18n-micro/vitepress/config` {#1-config-—-@i18n-micro/vitepress/config}

```ts
// .vitepress/config.mts
import { defineConfig } from 'vitepress'
import { withI18n, buildVitePressLocales } from '@i18n-micro/vitepress/config'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English', og: 'en_US' },
  { code: 'fr', iso: 'fr-FR', displayName: 'Français', og: 'fr_FR' },
]
const defaultLocale = 'en'

export default defineConfig(
  withI18n(
    {
      locales: buildVitePressLocales(locales, defaultLocale),
      // themeConfig.i18nRouting is injected automatically
    },
    {
      locale: defaultLocale,
      defaultLocale,
      locales,
      translationDir: 'locales',
      metaBaseUrl: 'https://example.com', // optional SEO head
    },
  ),
)
```

### 2. Teema — `@i18n-micro/vitepress/theme` {#2-theme-—-@i18n-micro/vitepress/theme}

```ts
// .vitepress/theme/index.ts
import DefaultTheme from 'vitepress/theme'
import { defineI18nTheme } from '@i18n-micro/vitepress/theme'

export default defineI18nTheme(DefaultTheme)
```

Alkuperäinen locale otetaan nykyisestä polusta ennen asennusta (ei oletuslocalen välähdystä poluilla `/fr/…`).

### Edistynyt: manuaalinen `createI18n` {#advanced-manual-createi18n}

Yksi tehdasfunktio asiakkaalle: Vue-plugin + polkumetodit + `enhanceApp` (ei erillisiä reititinapufunktioiden exportteja).

```ts
import { createI18n, messagesFromGlob } from '@i18n-micro/vitepress'

const i18n = createI18n({
  locale: 'en',
  defaultLocale: 'en',
  locales: [{ code: 'en' }, { code: 'fr' }],
  messages: messagesFromGlob(import.meta.glob('../../locales/*.json', { eager: true })),
})

i18n.localizePath('/guide', 'fr')
// in theme enhanceApp:
i18n.enhanceApp({ app, router })
```

### Node-skriptit — `@i18n-micro/vitepress/node` {#node-scripts-—-@i18n-micro/vitepress/node}

Käyttää paketin `@i18n-micro/node` funktioita `createI18n` / `loadTranslations` (samoin kuin Astro ja CLI) ja liittää sitten VitePressin polkumetodit `BaseI18n.extend`-funktiolla:

```ts
import { createI18n } from '@i18n-micro/vitepress/node'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  translationDir: './locales',
  locales: ['en', 'fr'],
  defaultLocale: 'en',
})
await i18n.loadTranslations()
i18n.t('cta.readMore')
i18n.localizePath('/guide', 'fr')
```

Pelkkä Node ilman polkuja: `import { createI18n } from '@i18n-micro/node'`.

## Sivun sisäiset käännökset {#in-page-translations}

Jokainen VitePressin markdown-tiedosto on Vue SFC.

### Globaalit komponentit ja `$t` (suositeltu markdownissa) {#global-components-and-$t-recommended-in-markdown}

`createI18n` / `defineI18nTheme` asentavat paketin `@i18n-micro/vue`, joka rekisteröi komponentit `I18nT` / `I18nLink` / `I18nGroup` / `I18nSwitcher` sekä `$t` / `$tc` / `$ts`.

```md
{{ $t('cta.readMore') }}

<I18nT keypath="greeting" :params="{ name: 'VitePress' }" />

<I18nLink to="/guide/demo">Demo</I18nLink>
```

### `useI18n` lohkossa `<script setup>` {#usei18n-in-<script-setup>}

```md
<script setup>
import { useI18n } from '@i18n-micro/vitepress'
const { t, tc, locale, localePath, switchLocale } = useI18n()
</script>

# {{ t('section.title') }}
```

## Kielen pudotusvalikko {#language-dropdown}

Kun `locales`-listassa on useampi kuin yksi merkintä, VitePress näyttää oman kielivalikkonsa (`VPNavBarTranslations`). `withI18n` kytkee `themeConfig.i18nRouting`-asetuksen, jotta maapallovalikko vastaa `<I18nSwitcher>`-komponenttia / polkuapufunktioita.

Käytä `<I18nSwitcher>`-komponenttia vain mukautetuissa layouteissa, ei oletusmaapallon vieressä.

## SSR-huomautukset {#ssr-notes}

- Locale esirenderöinnissä tulee URL-polusta, ei evästeistä.
- Teeman koodi ei saa koskea `window`-olioon importin aikana.
- Tuo `defineI18nTheme` polusta `/theme`, jotta Noden konfiguraatioevaluointi ei koskaan lataa moduuleja `virtual:i18n-micro/*`.

## API-pinta {#api-surface}

| Exportti | Rooli |
|--------|------|
| `createI18n` (`.`) | Asiakas: Vue-plugin + polkumetodit + `enhanceApp` |
| `getLocaleFromPath` / `stripSiteBase` / `routeNameFromPath` (`.`) | Manuaalinen localen synkronointi, kun `syncWithVitePress: false` |
| `createI18n` (`/node`) | Node: `@i18n-micro/node` + polkumetodit |
| `defineI18nTheme` (`/theme`) | Teema ilman boilerplatea |
| `withI18n` (`/config`) | Konfiguraatio + virtuaalimoduulit + valinnainen SEO |
| `buildVitePressLocales` (`/config`) | Muodostaa VitePressin `locales`-asetuksen `Locale[]`-taulukosta |
| `buildVitePressLocaleHead` (`/config`) | Manuaalinen SEO-head (käytetään myös `metaBaseUrl`-asetuksessa) |
| `messagesFromGlob` | Valinnainen glob → viestikartta `createI18n`-funktiolle |
| `useI18n` / `I18nT` / … | Exportattu uudelleen paketista `@i18n-micro/vue` |
| `BaseI18n.extend` (`@i18n-micro/core`) | Liittää mukautettuja metodeja mihin tahansa i18n-instanssiin |

## OpenAPI-tyyliset sivustot (integraatiolukot) {#openapi-style-sites-integration-locks}

Regressiotestisarja: `packages/vitepress/tests/integration-openapi.test.ts` (syvät polut, `base=/openapi_docs/`, synkronointi pois + manuaalinen locale, Node-generaattorit, SEO).

| Kuvio | Toimi näin |
|---------|---------|
| Syvät `/…/{spec}/{op}`-sivut, vain juuritason käyttöliittymä-JSON | Suosi oletusta `syncWithVitePress: true` (säilyttää `setRoute('index')`, kun sivusanakirjaa ei ole) **tai** `syncWithVitePress: false` + `getLocaleFromPath` |
| Älä koskaan kutsu `setRoute(deepName)` ilman sivusanakirjoja | Juuritason käyttöliittymäavaimet katoavat, kunnes kutsutaan `setRoute('index')` |
| Generaattorit / `getTranslation` | `createI18n` polusta `/node` + `await loadTranslations()` + `i18n.t(key)` (aseta `i18n.locale`) |
| Mukautettu canonical `transformPageData`-funktiossa | Anna `meta: false` funktiolle `withI18n` (vältä kaksinkertaiset tagit) |
| Paketin SEO sivuston basen kanssa | `metaBaseUrl` + VitePressin `base` → absoluuttiset URL:t sisältävät basen |
| Uudelleennimeäminen vanhemmista paketin buildeista | `withI18nMicro` → `withI18n`, `createVitePressI18n` → `createI18n`, `loadMessages` → Noden `createI18n` |
