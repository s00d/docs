`@i18n-micro/vue` on Vue 3 -liitännäinen, joka sisältää Nuxt I18n Micron käännösytimen: reaktiivisen `t()`-funktion, globaalin `$t`:n, neljä komponenttia ja valinnaisen vue-router-adapterin. Käytä sitä Vite- tai SSR-Vue-sovelluksessa, jota ei ole rakennettu Nuxtilla. Instanssimalli, reititinsopimus ja komponenttien propsit ovat yhteisiä muiden pakettien kanssa, ja ne on kuvattu sivulla [Kehykset](/fi/integrations/overview).

## Asennus {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vue
```

```bash npm
npm install @i18n-micro/vue
```

```bash yarn
yarn add @i18n-micro/vue
```

</CodeGroup>

Vertaisriippuvuudet: `vue` `^3.3.0`; `vue-router` `^4.5.1 || ^5.0.0` (valinnainen, vain `@i18n-micro/vue/router`-polulle). Julkaistut tyypit vaativat Vue 3.5.5:n tai uudemman asetuksella `skipLibCheck: false`; asetuksella `skipLibCheck: true`, joka on tavallinen pohja-asetus, myös vanhemmat versiot kääntyvät.

## Käyttöönotto {#setup}

```ts
// src/main.ts
import { createApp } from 'vue'
import { createI18n } from '@i18n-micro/vue'
import App from './App.vue'
import en from './locales/en.json'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales: [
    { code: 'en', iso: 'en-US', displayName: 'English' },
    { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
  ],
  defaultLocale: 'en',
})

createApp(App).use(i18n).mount('#app')
```

`locales` ja `defaultLocale` ovat pakollisia `useI18n()`-funktiolle: ilman niitä se heittää virheen `I18nLocalesKey not provided`. Välitä ne `createI18n`-funktiolle (kuten yllä), `useI18n({ locales, defaultLocale })`-kutsulle tai `app.provide(I18nLocalesKey, …)`- ja `app.provide(I18nDefaultLocaleKey, …)`-kutsujen kautta.

Liitännäinen rekisteröi `I18nT`-, `I18nLink`-, `I18nGroup`- ja `I18nSwitcher`-komponentit globaalisti ja lisää pohjiin `$t`, `$ts`, `$tc`, `$tn`, `$td`, `$tdr`, `$has` ja `$i18n`. Komponenttien ulkopuolella instanssi on `i18n.global`. Muut asetukset löytyvät kohdasta [instanssi](/fi/integrations/overview#the-instance); `routeMessages` ei ole saatavilla Vuessa, käytä `addRouteTranslations`-funktiota.

## Kääntäminen {#translate}

```vue
<script setup lang="ts">
import { useI18n } from '@i18n-micro/vue'

const { t, tc, tn } = useI18n()
</script>

<template>
  <h1>{{ t('greeting', { name: 'Ada' }) }}</h1>
  <!-- Hello, Ada! -->
  <p>{{ tc('apples', 3) }}</p>
  <!-- 3 apples -->
  <p>{{ $t('nav.home') }} · {{ tn(1234.5) }}</p>
</template>
```

`useI18n()` palauttaa käännösmetodit (`t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`), `locale`-arvon (kirjoitettava computed), `getLocale`, `getLocales`, `defaultLocale()`, `getLocaleName`, `localePath`, `localeRoute`, `switchLocale`, `setRoute`, `getRoute`, `addTranslations`, `addRouteTranslations`, `mergeTranslations`, `resolveTranslations`, `setTranslation`, `clearCache` ja `instance`.

Lataa lisää sanakirjoja milloin tahansa; jokainen niitä lukeva komponentti renderöidään uudelleen:

```ts
const { addTranslations, addRouteTranslations, setRoute } = useI18n()

addTranslations('de', (await import('./locales/de.json')).default)
addRouteTranslations('en', 'about', { title: 'About us' })
setRoute('about') // t('title') now reads the 'about' dictionary first
```

## Localen vaihtaminen {#switch-locale}

```ts
const { locale, switchLocale } = useI18n()

locale.value = 'de' // only the locale
switchLocale('de') // the locale, then router.push to the localized current path
```

Lataa localen sanakirja ennen vaihtoa tai sen jälkeen; vaihtaminen ei hae mitään.

`<I18nGroup>` antaa slotilleen etuliitteellisen `t`:n. Avaimet `<I18nT>`-komponentin sisällä tai tavallisessa `t()`-kutsussa eivät saa etuliitettä:

```vue
<I18nGroup prefix="profile" v-slot="{ t }">
  <h2>{{ t('title') }}</h2>
  <!-- profile.title -->
</I18nGroup>
```

## Reititys {#routing}

vue-router-adapteri sijaitsee alipolussa, joten pääsisääntulo ei koskaan tuo `vue-router`-pakettia:

```ts
// src/main.ts
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import { createI18n } from '@i18n-micro/vue'
import { createVueRouterAdapter } from '@i18n-micro/vue/router'
import App from './App.vue'
import Home from './pages/Home.vue'
import About from './pages/About.vue'
import en from './locales/en.json'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English' },
  { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
]

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/:locale(de)?', component: Home },
    { path: '/:locale(de)?/about', component: About },
  ],
})

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales,
  defaultLocale: 'en',
  routingStrategy: createVueRouterAdapter(router, locales, 'en'),
})

createApp(App).use(router).use(i18n).mount('#app')
```

`createVueRouterAdapter(router, locales, defaultLocale)` lisää etuliitteen jokaiselle localelle oletusta lukuun ottamatta (`/about`, `/de/about`) ja renderöi `<I18nLink>`-komponentin `RouterLink`-komponenttina. Lue locale reitistä itse, esimerkiksi `router.beforeEach`-koukussa, ja aseta `i18n.global.locale.value`. Voit myös liittää adapterin myöhemmin kutsulla `i18n.setRoutingStrategy(adapter)`; mukautetusta adapterista katso [Reititinadapteri](/fi/integrations/overview#router-adapter).

## SSR {#ssr}

- Luo reititin, i18n-instanssi ja sovellus pyyntökohtaisen renderöintifunktion sisällä. Yksi jaettu instanssi vuotaisi yhden vierailijan localen toiselle.
- Käytä palvelimella `createMemoryHistory()`-funktiota, ota locale URL-osoitteesta ja lataa sen sanakirja (ja varakielen sanakirja) ennen `renderToString`-kutsua.
- Lähetä locale asiakkaalle (esimerkiksi `window.__STATE__`-scriptissä) ja luo asiakasinstanssi samalla `locale`-arvolla, jotta hydraatio täsmää.
- `<I18nSwitcher>` lukee `window.location`-arvoa vain, kun pudotusvalikko on auki, joten se renderöityy palvelimella.

`packages/vue/playground` sisältää täydellisen `entry-server.ts` / `entry-client.ts` -parin.

## SEO-head {#seo-head}

`useLocaleHead(options)` rakentaa `lang`/`dir`-, canonical-, `hreflang`- ja `og:locale`-tagit localeista ja reititinadapterista. Kutsu `updateMeta()`, kun reitti muuttuu, ja välitä `metaObject` head-hallintaasi:

```ts
import { watch } from 'vue'
import { useRoute } from 'vue-router'
import { useHead } from '@unhead/vue'
import { useLocaleHead } from '@i18n-micro/vue'

const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
watch(() => route.fullPath, () => updateMeta(), { immediate: true })
useHead(metaObject)
```

Asetukset: `baseUrl` (merkkijono tai funktio), `addDirAttribute` (oletus `true`), `addSeoAttributes` (oletus `true`), `identifierAttribute` (oletus `'id'`), `hreflangBaseLanguage` (oletus `false`). Localet, joilla on `disabled: true` tai `seo: false`, eivät saa vaihtoehtoista linkkiä.

## API {#api}

| Vienti | Sisääntulo |
| --- | --- |
| `createI18n`, `useI18n`, `useLocaleHead` | `@i18n-micro/vue` |
| `I18nT`, `I18nLink`, `I18nSwitcher`, `I18nGroup` | `@i18n-micro/vue` |
| `VueI18n` (instanssiluokka), `I18nInjectionKey`, `I18nLocalesKey`, `I18nDefaultLocaleKey` | `@i18n-micro/vue` |
| `defaultPlural`, `FormatService`, `interpolate` | `@i18n-micro/vue` |
| Tyypit: `I18nRoutingStrategy`, `Locale`, `Translations`, `PluralFunc`, `Params`, `Getter`, `CleanTranslation`, `LocaleCode`, `VueI18nOptions`, `UseI18nOptions`, `UseLocaleHeadOptions`, `I18nPlugin` | `@i18n-micro/vue` |
| `createVueRouterAdapter` | `@i18n-micro/vue/router` |
