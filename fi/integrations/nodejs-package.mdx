`@i18n-micro/node` on [runtime](/fi/integrations/runtime-package)-instanssi sekä lataaja, joka lukee käännöskansion levyltä. Käytä sitä Express- tai Fastify-palvelimessa, komentorivityökalussa, sähköposti- tai PDF-generaattorissa tai missä tahansa skriptissä, joka tarvitsee samat JSON-tiedostot kuin Nuxt-sovelluksesi. Lataat tiedostot kerran ja käännät pyyntökohtaisesti jakamatta muuttuvaa tilaa pyyntöjen välillä.

## Asennus {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/node @i18n-micro/utils
```

```bash npm
npm install @i18n-micro/node @i18n-micro/utils
```

```bash yarn
yarn add @i18n-micro/node @i18n-micro/utils
```

</CodeGroup>

Ei peer-riippuvuuksia; Node.js `>=20`. `@i18n-micro/utils` tarvitaan vain alla olevaa `Accept-Language`-apufunktiota varten.

## Käyttöönotto {#setup}

Lataaja lukee [Nuxtin kansiorakennetta](/fi/guide/translations): `locales/en.json` on juurisanakirja, `locales/pages/blog/post/en.json` kuuluu reitille `blog-post`.

```ts
import { createI18n } from '@i18n-micro/node'

const i18n = createI18n({ locale: 'en', fallbackLocale: 'en', translationDir: './locales' })
await i18n.loadTranslations()

i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.t('title', undefined, undefined, 'blog-post') // from locales/pages/blog/post/en.json
```

Asetukset ovat runtimen asetukset (katso [instanssi](/fi/integrations/overview#the-instance)) sekä `translationDir` ja `disablePageLocales` (käsittele `pages/**`-tiedostoja juurisanakirjoina). `i18n.reload()` tyhjentää jokaisen sanakirjan ja lukee kansion uudelleen, kehitystilan tiedostotarkkailijaa varten.

`loadTranslations(dir, disablePageLocales?)` viedään myös erikseen ja palauttaa `{ root, routes }`:

```ts
import { loadTranslations } from '@i18n-micro/node'

const { root, routes } = await loadTranslations('./locales')
// root:   { en: {...}, de: {...} }
// routes: { 'blog-post': { en: {...}, de: {...} } }
```

## Pyyntökohtaisesti {#per-request}

Instanssi pitää yhtä lokaalia ja yhtä reittiä. `i18n.locale`-arvon vaihtaminen jaetussa instanssissa pyynnönkäsittelijän sisällä aiheuttaa kilpatilanteen samanaikaisten pyyntöjen kanssa. `run` antaa pyynnölle oman:

```ts
const i18n = createI18n({ locale: 'en', fallbackLocale: 'en', translationDir: './locales' })
await i18n.loadTranslations()

// `() => next()`: `run` hands its callback the fork, and Express reads an argument of `next` as an error
app.use((req, res, next) => i18n.run(pickLocale(req), () => next()))

app.get('/', (req, res) => {
  res.send(i18n.t('greeting')) // the request's locale, in everything it awaits
})
```

`run`-kutsun sisällä jaettu instanssi lukee ja asettaa pyynnön lokaalin ja reitin (`AsyncLocalStorage`); haara alkaa nykyiseltä reitiltä, ja `i18n.setRoute(...)` takaisinkutsun sisällä muuttaa kyseisen pyynnön reitin. Takaisinkutsu saa myös pyynnön haaran: siihen kirjoitetut sanakirjat pysyvät pyynnössä, jaettuun instanssiin kirjoitetut sanakirjat näkyvät kaikille.

Ilman `AsyncLocalStorage`-tukea `i18n.fork(locale)` palauttaa samanlaisen instanssin välitettäväksi eteenpäin.

`reload()` lukee hakemiston uudelleen; vanhat sanakirjat vastaavat, kunnes uudet ovat ladattu.

## Lokaalin valitseminen {#pick-the-locale}

`detectLocaleFromAcceptLanguage(header, locales)` huomioi `q`-painot ja täsmää `de-DE`:n `de`-lokaaliin (ja `de`:n `de-DE`:hen). Se palauttaa `null`, kun mikään ei täsmää.

```ts
import express from 'express'
import { detectLocaleFromAcceptLanguage } from '@i18n-micro/utils/accept-language'

const app = express()

app.get('/hello', (req, res) => {
  const locale = detectLocaleFromAcceptLanguage(req.headers['accept-language'], locales) ?? 'en'
  const i18n = byLocale.get(locale)!
  res.json({ message: i18n.t('greeting', { name: 'Ada' }) })
})
```

URL-etuliitteen, evästeen ja otsakkeen yhdistelmälle `resolveLocale({ defaultLocale, validLocales, url, cookie, acceptLanguage, autoDetectLanguage: true })` modulista `@i18n-micro/utils/resolve-locale` soveltaa moduulin etusijajärjestystä: URL, sitten eväste, sitten `Accept-Language`, sitten oletus. Virheelliset arvot ohitetaan.

Nuxt-sovelluksen sisällä et tarvitse tätä pakettia palvelimella: käytä moduulin [palvelinpuolen käännöksiä](/fi/guide/server-side-translations).

## API {#api}

| Vienti | Huomiot |
| --- | --- |
| `createI18n(options)`, `I18n` | runtime-instanssi + `translationDir`, `loadTranslations(dir?)`, `reload()` |
| `loadTranslations(dir, disablePageLocales?)` | `{ root, routes }` |
| `loadRootTranslations(dir, disablePageLocales?)` | vain `root` |
| `FormatService`, `interpolate` | coresta |
| Tyypit: `I18nOptions`, `LoadedTranslations`, `Translations`, `Locale`, `PluralFunc`, `Params` | |

Instanssin metodit on lueteltu sivulla [Runtime](/fi/integrations/runtime-package#api). Täydet signatuurit: [pakettiviite](/fi/api/packages/node).
