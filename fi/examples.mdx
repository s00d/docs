# 📚 Nuxt I18n Microin esimerkit ja käyttö

Tässä osiossa esitellään useita esimerkkejä siitä, miten `Nuxt I18n Micro`ia käytetään Nuxt.js-sovelluksessasi. Näet, miten vaihdat kieliä, käytät komponentteja `<i18n-link>`, `<i18n-switcher>` ja `<i18n-t>` sekä käsittelet käännösavaimia dynaamisesti.

## 🛠️ Perusasetukset

Tässä on perusasetukset, joilla pääset alkuun `Nuxt I18n Micro`n kanssa:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Kielen vaihto

### Kielen vaihto ohjelmallisesti

Tämä esimerkki näyttää, miten kieltä vaihdetaan ohjelmallisesti painikkeiden avulla:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Esimerkki-JSON kielen vaihtoon

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### Komponentin `<i18n-switcher>` käyttö

Komponentti `<i18n-switcher>` tarjoaa pudotusvalikon kielen vaihtoon mukautettavilla teksteillä:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 🌐 Komponentin `<i18n-link>` käyttö lokalisoituun navigointiin

Komponentti `<i18n-link>` huolehtii automaattisesti kielikohtaisesta reitityksestä:

```vue
<template>
  <div>
    <i18n-link to="/about">{{ $t('about') }}</i18n-link>
    <i18n-link :to="{ name: 'index' }">{{ $t('home') }}</i18n-link>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Esimerkki-JSON navigointilinkeille

```json
{
  "about": "About Us",
  "home": "Home"
}
```

### Esimerkki aktiivisen linkin tyylityksestä

```vue
<template>
  <div>
    <i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
  </div>
</template>
```

### Esimerkki-JSON aktiivisen linkin tyylitykseen

Samaa JSON-tiedostoa voi käyttää kuin edellisessä esimerkissä.

## 📝 Dynaamisten avainten renderöinti käännöstiedostoista

Joissakin tilanteissa haluat käydä läpi käännöstiedostoihin tallennettuja dynaamisia avaimia ja renderöidä niiden arvot ehdollisesti. Alla oleva esimerkki näyttää, miten se toteutetaan `Nuxt I18n Micro`n avulla.

### Esimerkki: dynaamisten avainten renderöinti

Tämä esimerkki hakee tietystä käännöspolusta (tässä tapauksessa `dynamic`) avainten taulukon ja käy sen läpi. Kunkin avaimen olemassaolo tarkistetaan funktiolla `$has` ennen sen arvon renderöintiä funktiolla `$t`.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Esimerkkikäännöstiedosto (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Esimerkki: dynaamisten avainten renderöinti objektista

Tässä esimerkissä käsittelemme käännöstiedostoosi tallennettua objektia. Haemme ja käymme läpi objektin avaimet renderöiden dynaamisesti sekä avainten nimet että niihin liittyvät arvot.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Esimerkkikäännöstiedosto (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 Komponentin `<i18n-t>` käyttö käännöksissä, joissa on slotit ja interpolointi

Komponentti `<i18n-t>` on hyödyllinen käännösten renderöintiin, kun käytössä on dynaamista sisältöä ja HTML-tageja:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### Esimerkki-JSON komponentille `<i18n-t>`

```json
{
  "greeting": "Welcome to the page"
}
```

### Interpoloinnin kanssa

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### Esimerkki-JSON interpoloinnille

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 Funktion `$tc` käyttö monikoihin

Funktio `$tc` käsittelee monikkomuotoja `Nuxt I18n Micro`ssa lukumäärän ja kieliasetusten mukaan. Se on hyödyllinen viestien dynaamiseen mukautukseen, kun mukana on lukumääriä, kuten tuotteita, ilmoituksia tai muita määrällisiä kohteita.

### Esimerkki: `$tc`:n käyttö monikoihin

Seuraavassa esimerkissä näytämme funktion `$tc` avulla viestin, joka ilmaisee omenoiden määrän. Käännösavain käsittelee useita monikkomuotoja annetun lukumäärän mukaan.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### Esimerkki-JSON monikoille

Näin voit määrittää käännöksen JSON-tiedostossasi käsitelläksesi eri monikkomuotoja:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Selitys

- **`$tc('apples', 0)`**: palauttaa ensimmäisen muodon, jota käytetään lukumäärän ollessa nolla (`"no apples"`).
- **`$tc('apples', 1)`**: palauttaa toisen muodon, jota käytetään lukumäärän ollessa yksi (`"one apple"`).
- **`$tc('apples', 10)`**: palauttaa kolmannen muodon lukumäärän arvon kanssa, kun lukumäärä on kaksi tai enemmän (`"10 apples"`).

### Lisäesimerkki monimutkaisemmalla monikkokäsittelyllä

Jos sovelluksesi tarvitsee monimutkaisempia monikkosääntöjä (esim. erikoistapaukset nollalle, yhdelle, kahdelle, muutamalle, monelle tai muille), voit laajentaa käännösmerkkijonoja vastaavasti:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: voidaan määrittää palauttamaan `"two apples"`.
- **`$tc('apples', 3)`**: voi palauttaa `"a few apples"` riippuen lukumäärälle määritellyistä säännöistä.

## 🌐 Funktion `$tn` käyttö numeroiden muotoiluun

Funktio `$tn` muotoilee numerot nykyisen kielen mukaan `Intl.NumberFormat` -API:n avulla. Se on hyödyllinen numeroiden näyttämiseen käyttäjän alueasetusten mukaisesti, kuten valuutat, prosentit tai muut numeromuodot.

### Esimerkki: `$tn`:n käyttö numeroiden muotoiluun

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ Funktion `$td` käyttö päivämäärien ja aikojen muotoiluun

Funktio `$td` muotoilee päivämäärät ja ajat nykyisen kielen mukaan `Intl.DateTimeFormat` -API:n avulla. Se on hyödyllinen päivämäärien ja aikojen näyttämiseen käyttäjän kieliasetusten mukaisissa muodoissa.

### Esimerkki: `$td`:n käyttö päivämäärien ja aikojen muotoiluun

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ Funktion `$tdr` käyttö suhteelliseen päivämäärämuotoiluun

Funktio `$tdr` muotoilee päivämäärät suhteellisiksi ajoiksi (esim. "5 minuuttia sitten", "2 päivää sitten") nykyisen kielen mukaan `Intl.RelativeTimeFormat` -API:n avulla. Se on hyödyllinen ajallisten erojen näyttämiseen suhteessa nykyiseen päivämäärään ja aikaan.

### Esimerkki: `$tdr`:n käyttö suhteelliseen päivämäärämuotoiluun

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
