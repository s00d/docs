# 📚 Nuxt I18n Micro -esimerkit ja käyttö

Tässä osiossa on useita esimerkkejä, jotka havainnollistavat `Nuxt I18n Micro` -moduulin käyttöä Nuxt.js-sovelluksessa. Näet, kuinka vaihdat kieliä, käytät komponentteja `<i18n-link>`, `<i18n-switcher>` ja `<i18n-t>` sekä käsittelet käännösavaimia dynaamisesti.

## 🛠️ Perusmääritys

Tässä on perusmääritys, jolla pääset alkuun `Nuxt I18n Micro` -moduulin kanssa:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Kielten vaihtaminen

### Kielen vaihtaminen ohjelmallisesti

Tämä esimerkki näyttää, kuinka kieliä vaihdetaan ohjelmallisesti painikkeilla:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Esimerkki-JSON kielten vaihtamiseen

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### Komponentin `<i18n-switcher>` käyttäminen

Komponentti `<i18n-switcher>` tarjoaa alasvetovalikon kielten vaihtamiseen mukautettavilla otsikoilla:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 🌐 Komponentin `<i18n-link>` käyttäminen paikallistettuun navigointiin


## 📝 Dynaamisten avainten renderöinti käännöstiedostoista

Joskus voit haluta iteroida käännöstiedostoihisi tallennettujen dynaamisten avainten yli ja renderöidä niiden arvot ehdollisesti. Alla oleva esimerkki näyttää, kuinka tämä tehdään moduulilla `Nuxt I18n Micro`.

### Esimerkki: Dynaamisten avainten renderöinti

Tämä esimerkki hakee taulukon avaimista tietystä käännöspolusta (tässä tapauksessa `dynamic`) ja iteroi niiden yli. Jokaisen avaimen olemassaolo tarkistetaan metodilla `$has` ennen sen arvon renderöimistä metodilla `$t`.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Esimerkki käännöstiedostosta (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Esimerkki: Dynaamisten avainten renderöinti objektista

Tässä esimerkissä käsittelemme käännöstiedostoon tallennettua objektia. Haemme ja iteroimme objektin avaimet, renderöiden dynaamisesti sekä avainten nimet että niihin liittyvät arvot.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Esimerkki käännöstiedostosta (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 Komponentin `<i18n-t>` käyttäminen käännöksissä slotien ja interpolaation kanssa

Komponentti `<i18n-t>` on hyödyllinen käännösten renderöintiin, joissa on dynaamista sisältöä ja HTML-tageja:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### Esimerkki-JSON komponentille `<i18n-t>`

```json
{
  "greeting": "Welcome to the page"
}
```

### Interpolaation kanssa

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### Esimerkki-JSON interpolaatiolle

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 Metodin `$tc` käyttäminen monikkomuodoille

Metodi `$tc` moduulissa `Nuxt I18n Micro` käsittelee monikkomuotoja lukumäärän ja kieliasetusten perusteella. Tämä on hyödyllistä, kun mukautetaan dynaamisesti viestejä, joihin liittyy lukumääriä, kuten esineitä, ilmoituksia tai muita lukumäärältään vaihtelevia yksiköitä.

### Esimerkki: Metodin `$tc` käyttö monikkomuodoille

Seuraavassa esimerkissä näytämme viestin, joka ilmaisee omenoiden lukumäärän metodilla `$tc`. Käännösavain käsittelee useita monikkomuotoja annetun lukumäärän perusteella.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### Esimerkki-JSON monikkomuodoille

Näin voit määrittää käännöksen JSON-tiedostossasi käsittelemään eri monikkomuotoja:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Selitys

- **`$tc('apples', 0)`**: Palauttaa ensimmäisen muodon, jota käytetään lukumäärän ollessa nolla (`"no apples"`).
- **`$tc('apples', 1)`**: Palauttaa toisen muodon, jota käytetään lukumäärän ollessa yksi (`"one apple"`).
- **`$tc('apples', 10)`**: Palauttaa kolmannen muodon lukuarvon kanssa, jota käytetään kun lukumäärä on kaksi tai enemmän (`"10 apples"`).

### Lisäesimerkki monimutkaisemmilla monikkomuodoilla

Jos sovelluksesi tarvitsee käsitellä monimutkaisempia monikkomuotosääntöjä (esim. erityistapaukset nollalle, yhdelle, kahdelle, muutamalle, monelle, muille), voit laajentaa käännösmerkkijonoja sen mukaisesti:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: Voidaan asettaa palauttamaan `"two apples"`.
- **`$tc('apples', 3)`**: Voi palauttaa `"a few apples"` riippuen lukumäärälle määritellyistä säännöistä.

## 🌐 Metodin `$tn` käyttö numeroiden muotoiluun

Metodi `$tn` muotoilee numerot nykyisen kielen mukaisesti käyttäen `Intl.NumberFormat` -APIa. Tämä on hyödyllistä numeroiden näyttämiseen käyttäjän alueasetuksia vastaavassa muodossa, kuten valuutta, prosentit tai muut numeromuodot.

### Esimerkki: Metodin `$tn` käyttö numeroiden muotoiluun

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ Metodin `$td` käyttö päivämäärän ja ajan muotoiluun

Metodi `$td` muotoilee päivämäärät ja ajat nykyisen kielen mukaisesti käyttäen `Intl.DateTimeFormat` -APIa. Tämä on hyödyllistä päivämäärien ja aikojen näyttämiseen muodoissa, jotka ovat käyttäjälle tuttuja kieliasetusten perusteella.

### Esimerkki: Metodin `$td` käyttö päivämäärän ja ajan muotoiluun

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ Metodin `$tdr` käyttö suhteellisen päivämäärän muotoiluun

Metodi `$tdr` muotoilee päivämäärät suhteellisina aikoina (esim. "5 minutes ago", "2 days ago") nykyisen kielen mukaisesti käyttäen `Intl.RelativeTimeFormat` -APIa. Tämä on hyödyllistä aikaerojen näyttämiseen suhteessa nykyiseen päivämäärään ja aikaan.

### Esimerkki: Metodin `$tdr` käyttö suhteellisen päivämäärän muotoiluun

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
