title: "<i18n-switcher>"
description: "<i18n-switcher>-komponentti on käytössä olevien lokaalien pudotusvalikko, jonka jokainen kohta linkittää nykyiseen sivuun kyseisellä lokaalilla."
---

`<i18n-switcher>` renderöi painikkeen, jossa näkyy aktiivinen lokaali, sekä pudotusvalikon kaikista käytössä olevista lokaaleista aktiivinen mukaan lukien. Käytä sitä valmiina kielivalikkona; rakenna oma valikkosi [`$getLocales`](/fi/api/methods#$getlocales)- ja [`$switchLocalePath`](/fi/api/methods#$switchlocalepath)-funktioiden avulla, kun tarvitset erilaisen merkinnän. Jokainen kohta linkittää nykyiseen sivuun kyseisellä lokaalilla.

## Propsit ja slotit {#props-and-slots}

| Props | Tyyppi | Oletus | Kuvaus |
| --- | --- | --- | --- |
| `customLabels` | `Record<string, string>` | `() => ({})` | Näyttönimi lokaalikoodia kohden; ohittaa lokaalin konfiguraation `displayName`-arvon. |
| `customWrapperStyle` | `CSSProperties` | `() => ({})` | Ulomman käärimen inline-tyyli. |
| `customButtonStyle` | `CSSProperties` | `() => ({})` | Pudotusvalikon avaavan painikkeen inline-tyyli. |
| `customDropdownStyle` | `CSSProperties` | `() => ({})` | Pudotusvalikon paneelin inline-tyyli. |
| `customItemStyle` | `CSSProperties` | `() => ({})` | Pudotusvalikon jokaisen kohdan inline-tyyli. |
| `customLinkStyle` | `CSSProperties` | `() => ({})` | Kohdan sisällä olevan linkin inline-tyyli. |
| `customActiveLinkStyle` | `CSSProperties` | `() => ({})` | Tällä hetkellä aktiivisen lokaalin linkin inline-tyyli. |
| `customDisabledLinkStyle` | `CSSProperties` | `() => ({})` | *Nykyisen* lokaalin painikkeen inline-tyyli, kun lokaalilla on konfiguraatiossa `disabled: true`. |
| `customIconStyle` | `CSSProperties` | `() => ({})` | Painikkeen nuolikuvakkeen inline-tyyli. |

### Slotit {#slots}

| Slot | Sidonnat | Kuvaus |
| --- | --- | --- |
| `before-button` | — | Sisältö ennen pudotusvalikon avaavaa painiketta. |
| `before-selected-locale` | — | Sisältö ennen aktiivisen lokaalin nimeä painikkeen sisällä. |
| `after-selected-locale` | — | Sisältö aktiivisen lokaalin nimen jälkeen painikkeen sisällä. |
| `before-dropdown` | — | Sisältö painikkeen ja pudotusvalikon paneelin välissä. |
| `before-dropdown-items` | — | Sisältö pudotusvalikon yläosassa lokaalilistan yläpuolella. |
| `before-item` | `locale` | Sisältö ennen jokaista lokaalikohtaa. |
| `before-link-content` | `locale` | Sisältö ennen lokaalin nimeä sen linkin sisällä. |
| `after-link-content` | `locale` | Sisältö lokaalin nimen jälkeen sen linkin sisällä. |
| `after-item` | `locale` | Sisältö jokaisen lokaalikohdan jälkeen. |
| `after-dropdown-items` | — | Sisältö pudotusvalikon alaosassa lokaalilistan alapuolella. |
| `after-dropdown` | — | Sisältö pudotusvalikon paneelin jälkeen. |

## Toiminta {#behaviour}

- Listaa jokaisen lokaalin, jolla ei ole `disabled: true`, aktiivinen mukaan lukien.
- Jokainen kohta on `<a>`-elementti, joka osoittaa kohteeseen `$switchLocalePath(code)`. Polku ratkaistaan `app.baseURL`-arvon alle; toisella verkkotunnuksella oleva lokaalin `baseUrl` pysyy absoluuttisena. Elementillä on `hreflang` ja `lang` arvona `iso || code`, `dir`, jos lokaalilla sellainen on, `aria-current="page"` nykyisellä lokaalilla sekä luokka `switcher-locale-<code>`. Napsautus kutsuu `$switchLocale(code)`-funktiota ja sulkee pudotusvalikon; muokkausnäppäimen kanssa napsautus jätetään selaimen hoidettavaksi.
- Lista säilyy palvelimen HTML:ssä piilotettuna, joten hakurobotit näkevät linkit. Escape tai napsautus valikon ulkopuolelle sulkee sen.
- Nimi: `customLabels[code]`, sitten lokaalin `displayName`, sitten koodi (kehitystilan varoituksen kera).
- Tyylit: pienet inline-oletukset (reunustettu valkoinen painike ja paneeli, aktiivinen kohta lihavoituna ja sinisenä). Jokainen `custom*Style`-props sovelletaan oman osansa oletuksen jälkeen. Painikkeella on luokat `i18n-switcher-button` ja `language-switcher`, käärimellä `i18n-switcher-wrapper` ja listalla `i18n-switcher-dropdown`. Sijoittelu käyttää loogisia CSS-ominaisuuksia, joten `dir="rtl"` toimii.

## Esimerkki {#example}

```vue
<template>
  <i18n-switcher
    :custom-labels="{ en: 'English', de: 'Deutsch' }"
    :custom-button-style="{ borderRadius: '4px' }"
  >
    <template #before-link-content="{ locale }">
      <img :src="`/flags/${locale.code}.svg`" alt="" width="16" />
    </template>
  </i18n-switcher>
</template>
```
