# 🛠️ Metodit

Tämä sivu dokumentoi kaikki `nuxt-i18n-micro`-moduulin tarjoamat metodit. Metodit on järjestetty toiminnallisuuden mukaan navigoinnin helpottamiseksi.

<Info>
`$defineI18nRoute` ja `$clearCache` tarjoaa pää-i18n-liitännäinen kohteessa `useNuxtApp()`, mutta **ei** koostajan `useI18n()` palauttamana. Siksi ne puuttuvat yllä olevasta taulukosta. (`$getI18nConfig` **on** saatavilla molempien kautta.) Katso niiden osiot alla.
</Info>

### `$getI18nConfig`

{/* generated:method:$getI18nConfig — do not edit; run `pnpm run docs:generate` */}

```ts
() => ModuleOptionsExtend
```

Ratkaistu moduulikonfiguraatio ajonaikaisesta näkökulmasta.

{/* /generated:method:$getI18nConfig */}

```typescript
const nuxtApp = useNuxtApp()
const { localeCookie, strategy, hooks } = nuxtApp.$getI18nConfig()
```

Käännösvaiheen tai muiden kuin Nuxt-kontekstien osalta käytä sen sijaan funktiota `getI18nConfig()` tiedostosta `#build/i18n.strategy.mjs`.

<Info>
`serverTranslationPreload` on yksityinen moduuliasetus, joka on saatavilla vain palvelimen yksityisessä konfiguraatiossa (`#i18n-internal/config`). Se ei ole osa julkista ajonaikaista API:ta ja voi muuttua ilman ilmoitusta.
</Info>

## 🔍 Käännösmetodit

Ydinmetodit käännösten hakemiseen ja hallintaan.

### `$t`

{/* generated:method:$t — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Käännä avain ja interpoloi `params` siihen. Palauttaa arvon `defaultValue`, kun avain puuttuu, tai itse avaimen, jos oletusta ei ole annettu.

{/* /generated:method:$t */}

```typescript
const welcomeMessage = $t('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

<Warning>
`$t` palauttaa tyypin `CleanTranslation`, joka on `string | number | boolean | Translations | PluralTranslations | null`. Jos avain osoittaa JSON:ssasi **sisäkkäiseen objektiin** (esim. `$t('header')`, kun JSON sisältää `\{ "header": \{ "title": "Hi" \} \}`), palautusarvo on tuo **objekti**, ei merkkijono. Sen käyttäminen suoraan Vue-mallissa (<code v-pre>\{\{ $t('header') \}\}</code>) renderöityy muotoon `[object Object]`.

**Miten välttää tämä:**

- Käytä tarkempaa avainta: `$t('header.title')` → `"Hi"`
- Käytä funktiota `$ts()`, joka palauttaa aina merkkijonon (kutsuu `.toString()`-metodia muille kuin merkkijonoille).
- Käytä funktiota `$t` sisäkkäisellä avaimella, kun haluat tarkoituksellisesti käsitellä ali-objekteja ohjelmallisesti.
</Warning>

### `$ts`

{/* generated:method:$ts — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string) => string
```

Kuten `$t`, mutta palauttaa aina merkkijonon: objekti- tai taulukkoarvo muunnetaan merkkijonoksi.

{/* /generated:method:$ts */}

```typescript
const welcomeMessage = $ts('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

### `$_t` ja `$_ts`

{/* generated:method:$_t — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Sido `$t` tiettyyn reittiin, jotta voit kääntää nykyisen sivun ulkopuolella. Esimerkiksi asettelu, joka renderöi linkin toiseen reittiin.

{/* /generated:method:$_t */}

{/* generated:method:$_ts — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => string
```

Sido `$ts` tiettyyn reittiin. Katso `$_t`.

{/* /generated:method:$_ts */}

Reittiin sidotut variantit funktioista `$t` ja `$ts`. Ne ottavat ensin **reitin** ja palauttavat käännösfunktion, joka on lukittu kyseisen reitin kieleen ja sivukontekstiin.

- **Käyttö**: `useNuxtApp()` (myös uudelleenviety funktion `useI18n()` kautta nimillä `$_t`/`$_ts`)

Käytä näitä, kun aktiivinen reitti SSR:n tai siirtymien aikana eroaa arvosta `router.currentRoute` — esimerkiksi komponenttien `<i18n-t>` tai `<i18n-group>` sisällä, tai kun renderöit sisältöä tietylle `route`-objektille.

```typescript
import { useRoute, useNuxtApp } from '#imports'

const route = useRoute()
const { $_t, $_ts } = useNuxtApp()

const $t = $_t(route)
const title = $t('page.title')

// String-safe variant
const label = $_ts(route)('page.label')
```


### `$tc`

{/* generated:method:$tc — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params: number | Params, defaultValue?: string) => string
```

Käännä monikkokäsittelyllä. `params` voi olla itse lukumäärä tai objekti, joka sisältää arvon `count`.

{/* /generated:method:$tc */}

**Käännöksen muoto**: muodot erotettu merkillä `|`. Lisää paikkamerkit **jokaiseen** muotoon:

```json
{
  "apples": "no apples | one apple | {count} apples",
  "cart": "no items for {name} | one item for {name} | {count} items for {name}"
}
```

```typescript
$tc('apples', 0) // "no apples"
$tc('apples', 1) // "one apple"
$tc('apples', 10) // "10 apples"

// count + other params (second argument must be an object)
$tc('cart', { count: 10, name: 'Alice' }) // "10 items for Alice"
```


**Komponenttivaihtoehto** — `<i18n-t keypath="cart" :plural="count" :params="\{ name \}" />` (yhdistää sisäisesti arvon `count` propsiin `params`).


### `$mergeTranslations`

{/* generated:method:$mergeTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
(newTranslations: Translations) => void
```

Yhdistä käännökset aktiiviseen kieleen ajonaikaisesti ja ohita ladatut.

{/* /generated:method:$mergeTranslations */}

```typescript
$mergeTranslations({
  welcome: 'Bienvenue, {username}!',
})
// Output: Updates the translation cache with the new French translation
```

### `$resolveTranslations`

{/* generated:method:$resolveTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
() => Translations
```

Kaikki tällä hetkellä muistissa olevat käännökset aktiiviselle kielelle ja reitille puuna. Vain luku -näkymä siitä, mitä `$t()` voi juuri nyt ratkaista.

{/* /generated:method:$resolveTranslations */}

```typescript
const tree = $resolveTranslations()
// { aaa: { bbb: 'ccc' }, ddd: 1111 } — the same dictionary $t() reads from
```

Käytä tätä, kun tarvitset koko muistinsisäisen sanakirjan (DevTools, testit, ajonaikaiset editorit). Käsittele palautusarvoa vain luettavana. Muuta arvoja funktiolla `$setTranslation` tai yhdistä muutokset funktiolla `$mergeTranslations`.

### `$setTranslation`

{/* generated:method:$setTranslation — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, value: unknown) => void
```

Korvaa arvo avaimessa `key` aktiivisessa sanakirjassa. Tämä on korvaus, ei yhdistäminen. Käytä funktiota `$mergeTranslations`, kun olemassa olevien sisarusten pitää säilyä.

{/* /generated:method:$setTranslation */}

```typescript
$setTranslation('aaa', { fff: 'ggg' }) // replaces the whole `aaa` subtree
$setTranslation('aaa', 'text')          // replaces `aaa` with a string
$setTranslation('ddd', 1111)            // scalar at the top level
$setTranslation('aaa.bbb', 'nested')    // dotted path
```

Tämä on **korvaus**, ei yhdistäminen. Saman avaimen olemassa olevat sisarukset poistetaan. Paikkaa hukkaamatta sisaruksia käyttämällä funktiota `$mergeTranslations`.

### `$setMissingHandler`

{/* generated:method:$setMissingHandler — do not edit; run `pnpm run docs:generate` */}

```ts
(handler: MissingHandler | null) => void
```

Asenna callback, jota kutsutaan jokaiselle ratkaisemattomalle avaimelle. Anna `null`, jos haluat poistaa sen.

{/* /generated:method:$setMissingHandler */}

**Tyyppimäärittely**:

```typescript
type MissingHandler = (locale: string, key: string, routeName: string, instance?: unknown, type?: string) => void
```

```typescript
// Set a custom handler
$setMissingHandler((locale, key, routeName) => {
  console.error(`Missing translation: ${key} in ${locale} for route ${routeName}`)
  // Send to Sentry or other error tracking service
  // Sentry.captureMessage(`Missing translation: ${key}`)
})

// Remove the handler
$setMissingHandler(null)
```

**Käyttötapaukset**:

- Puuttuvien käännösten kirjaus virheenseurantapalveluihin (Sentry, LogRocket jne.)
- Analytiikan kerääminen puuttuvista käännöksistä
- Puuttuvien käännösavainten mukautettu virhekäsittely

## 🔢 Numeroiden ja päivämäärien muotoilu

Metodit numeroiden ja päivämäärien muotoilemiseen kielen käytäntöjen mukaan.

### `$tn`

{/* generated:method:$tn — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Muotoile numero funktiolla `Intl.NumberFormat` aktiivisella kielellä. Avain valitsee nimetyn muodon konfiguraatiosta.

{/* /generated:method:$tn */}

```typescript
// Inline options
const formattedNumber = $tn(1234567.89, { style: 'currency', currency: 'USD' })
// "$1,234,567.89"

// Named format (from nuxt.config i18n.numberFormats)
const price = $tn(1000, 'currency')
const priceDe = $tn(1000, 'currency', 'de')
const compact = $tn(1000, 'currency', { notation: 'compact' })
```

Tuntemattomat nimetyn muodon avaimet palautuvat oletusarvoisiin `Intl.NumberFormat`-asetuksiin. Kehityksessä (asiakas) lähetetään `console.warn`, kun `missingWarn` on käytössä (oletus).

**Konfiguraatioesimerkki**:

```ts
export default defineNuxtConfig({
  i18n: {
    numberFormats: {
      en: {
        currency: { style: 'currency', currency: 'USD' },
        decimal: { style: 'decimal', minimumFractionDigits: 2, maximumFractionDigits: 2 },
      },
      de: {
        currency: { style: 'currency', currency: 'EUR' },
      },
    },
  },
})
```

**Käyttötapaukset**:

- Numeroiden muotoilu valuuttana, prosentteina tai desimaaleina asianmukaisessa kielimuodossa
- Nimettyjen muotojen uudelleenkäyttö koko sovelluksessa (Vue I18n -siirtymän vastaavuus)

### `$td`

{/* generated:method:$td — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Muotoile päivämäärä funktiolla `Intl.DateTimeFormat` aktiivisella kielellä. Avain valitsee nimetyn muodon konfiguraatiosta.

{/* /generated:method:$td */}

```typescript
const formattedDate = $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' })
// "Friday, September 1, 2023"

const short = $td(new Date(), 'short')
const longDe = $td(new Date(), 'long', 'de')
```

Tuntemattomat nimetyn muodon avaimet palautuvat oletusarvoisiin `Intl.DateTimeFormat`-asetuksiin. Kehityksessä (asiakas) lähetetään `console.warn`, kun `missingWarn` on käytössä (oletus).

**Konfiguraatioesimerkki**:

```ts
export default defineNuxtConfig({
  i18n: {
    datetimeFormats: {
      en: {
        short: { year: 'numeric', month: 'short', day: 'numeric' },
        long: { year: 'numeric', month: 'long', day: 'numeric', weekday: 'long' },
      },
    },
  },
})
```

**Käyttötapaukset**:

- Päivämäärien näyttö käyttäjän kielen mukaisessa muodossa
- Lyhyiden/pitkien/päivämääräaikaisten esiasetusten jakaminen koko sovelluksessa

### `$tdr`

{/* generated:method:$tdr — do not edit; run `pnpm run docs:generate` */}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

Muotoile päivämäärä suhteellisena aikana ("3 päivää sitten") funktiolla `Intl.RelativeTimeFormat`.

{/* /generated:method:$tdr */}

```typescript
const relativeDate = $tdr(new Date(Date.now() - 1000 * 60 * 5))
// Output: "5 minutes ago" in the 'en-US' locale
```

## 🔄 Reitin ja kielen vaihto

Metodit kielten ja reittien välillä vaihtamiseen.

### `$switchLocale`

{/* generated:method:$switchLocale — do not edit; run `pnpm run docs:generate` */}

```ts
(locale: string) => void
```

Siirry nykyiselle sivulle toisella kielellä.

{/* /generated:method:$switchLocale */}

```typescript
$switchLocale('fr')
// Prefix strategies: navigates to the French version of the route
// no_prefix: updates locale and translations without changing the URL path
```

<Tip>
Katso [UKK — vaihda kieli muuttamatta URL:ää](/guides/faq#-switch-locale-without-changing-the-url). Etuliitestrategioissa käytä funktiota `$switchLocalePath()`, kun tarvitset vain linkin kohteen.
</Tip>

### `$switchLocaleRoute`

{/* generated:method:$switchLocaleRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(locale: string) => RouteLocationRaw
```

Nykyisen sivun reittiobjekti toisella kielellä ilman siirtymistä.

{/* /generated:method:$switchLocaleRoute */}

```typescript
// on /en/news
const routeFr = $switchLocaleRoute('fr')
// Output: A route object with the new locale applied, e.g., { name: 'localized-news', params: { locale: 'fr' } }
```

### `$switchLocalePath`

{/* generated:method:$switchLocalePath — do not edit; run `pnpm run docs:generate` */}

```ts
(locale: string) => string
```

Nykyisen sivun polku toisella kielellä ilman siirtymistä.

{/* /generated:method:$switchLocalePath */}

```typescript
// on /en/news
const routeFr = $switchLocalePath('fr')
window.location.href = routeFr
// Output: url with new locale applied, e.g., '/fr/nouvelles'
```

### `$switchRoute`

{/* generated:method:$switchRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, toLocale?: string) => void
```

Siirry toiselle reitille säilyttäen aktiivisen kielen tai vaihda kieleen `toLocale`.

{/* /generated:method:$switchRoute */}

**Esimerkkejä**:

<CodeGroup>
```typescript String Path
// Switches to the given path with the current locale
$switchRoute('/about')
```

```typescript String Path with Locale
// Switches to the given path with French locale
$switchRoute('/about', 'fr')
```

```typescript Named Route
// Switches to a named route with the current locale
$switchRoute({ name: 'page' })
```

```typescript Named Route with Locale
// Switches to a named route and changes the locale to Spanish
$switchRoute({ name: 'page' }, 'es')
```
</CodeGroup>

## 🚦 Reitin konfiguraatio

Metodit reitin käytöksen ja pääsynhallinnan konfigurointiin.

### `$defineI18nRoute`

{/* generated:method:$defineI18nRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Rekisteröi sivukohtainen kielikonfiguraatio ja käännökset komponentin sisältä. Yhdistää aktiiviseen kieleen ja soveltaa uudelleen, kun kieli muuttuu.

{/* /generated:method:$defineI18nRoute */}

> [!IMPORTANT]
> `$defineI18nRoute` on **define-liitännäisen** tarjoama ja saatavilla vain funktiolla `useNuxtApp()`. Se **ei** ole osa funktion `useI18n()` palautusobjektia.
> Ota se aina destrukturoiden funktiosta `useNuxtApp()` `script setup`-osiossa. Funktion `$defineI18nRoute(...)` kutsuminen pelkkänä globaalina heittää virheen `"$defineI18nRoute is not defined"` SSR:n/esirenderöinnin aikana.

**Parametrit**:

- **locales**: `string[] | Record<string, Record<string, string>>` — reitin käytettävissä olevat kielet
- **localeRoutes**: `Record<string, string>` — valinnainen. Mukautetut reitit tietyille kielille
- **disableMeta**: `boolean | string[]` — valinnainen. Poistaa i18n-metatunnisteet käytöstä kaikille tai tietyille kielille

**Perusesimerkki**:

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr', 'de'],
  localeRoutes: {
    en: '/welcome',
    fr: '/bienvenue',
    de: '/willkommen',
  },
  disableMeta: false,
})
```

> 📖 **Yksityiskohtaisia käyttöesimerkkejä, konfiguraatiomuotoja ja parhaita käytäntöjä varten katso [komponenttikohtaisten käännösten opas](/guides/per-component-translations).**

### `$setI18nRouteParams`

{/* generated:method:$setI18nRouteParams — do not edit; run `pnpm run docs:generate` */}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Aseta kielikohtaiset parametrit nykyiselle reitille, jotta dynaaminen segmentti voi erota kielten välillä. Kutsu sitä SSR:ssä ennen kuin head renderöidään.

{/* /generated:method:$setI18nRouteParams */}

```typescript
// in pages/news/[id].vue
// for en/news/1-first-article
const { $switchLocaleRoute, $setI18nRouteParams, $defineI18nRoute } = useNuxtApp()
$defineI18nRoute({
  localeRoutes: {
    en: '/news/:id()',
    fr: '/nouvelles/:id()',
    de: '/Nachricht/:id()',
  },
})
const { data: news } = await useAsyncData(`news-${params.id}`, async () => {
  let response = await $fetch("/api/getNews", {
    query: {
      id: params.id,
    },
  });
  if (response?.localeSlugs) {
    response.localeSlugs = {
      en: {
        id: '1-first-article'
      }
      fr: {
        id: '1-premier-article'
      }
      de: {
        id: '1-erster-Artikel'
      }
    }
    $setI18nRouteParams(response?.localeSlugs);
  }
  return response;
});
$switchLocalePath('fr') // === 'fr/nouvelles/1-premier-article'
$switchLocalePath('de') // === 'de/Nachricht/1-erster-Artikel'
```

## 🧭 `useI18nLocale`-koostaja

Keskitetty koostaja kielitilan hallintaan. Käytä tätä sen sijaan, että manipuloisit suoraan funktiota `useState('i18n-locale')` tai `useCookie('user-locale')`.

```typescript
const {
  setLocale, // (locale: string) => void — updates state + cookie
  getLocale, // () => string | null — from state or cookie
  getPreferredLocale, // () => string | null — validated against locales list
  getEffectiveLocale, // (route, getLocaleFromRoute) => string
  resolveInitialLocale, // (options) => string
  isValidLocale, // (locale) => boolean
  locale, // Ref<string | null> — reactive state
  localeCookie, // CookieRef — reactive cookie
  syncLocale, // (locale) => void — sync to cookie only
  validLocales, // string[] — list of valid locale codes
} = useI18nLocale()
```

### Keskeiset metodit

| Metodi                  | Kuvaus                                                     |
| ----------------------- | ---------------------------------------------------------- |
| `setLocale(locale)`     | Asettaa kielen sekä `useState`-tilaan että evästeeseen atomisesti |
| `getLocale()`           | Palauttaa nykyisen kielen tilasta tai evästeestä           |
| `getPreferredLocale()`  | Palauttaa kielen, joka on validoitu `locales`-listaa vastaan, tai `null` |
| `isValidLocale(locale)` | Tarkistaa, onko kielikoodi määritetyssä `locales`-listassa |

### Käyttö mukautetuissa liitännäisissä

```typescript
// plugins/i18n-loader.server.ts
export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,
  setup() {
    const { setLocale } = useI18nLocale()
    // Detect locale from headers, domain, etc.
    setLocale('de')
  },
})
```

Katso [mukautettu kielen tunnistus](/guides/custom-language-detection) yksityiskohtaisia esimerkkejä varten.
