Moduuli injektoi ajonaikaiset apufunktionsa Nuxt-sovellukseen: `$t`, `$tc`, `$localePath`, `$switchLocale` ja muut. Tältä sivulta voit tarkistaa apufunktion allekirjoituksen ja toiminnan. Allekirjoitukset ja kuvaukset tulevat tiedoston `src/runtime/plugins/01.plugin.ts` rajapinnoista `PluginsInjections` ja `NuxtAppOnlyInjections`.

## Käyttö {#access}

| Missä | Miten |
| --- | --- |
| Malli | `{{ $t('title') }}` — jokainen apufunktio, `$`-etuliitteellä |
| `<script setup>` | `const { t, localePath } = useI18n()` — jokainen `PluginsInjections`-rajapinnan apufunktio, `$`-etuliitteellä ja ilman |
| Liitännäinen, middleware, `<script setup>` | `const { $t, $defineI18nRoute } = useNuxtApp()` — kaikki, vain `$`-etuliitteellä |

`$defineI18nRoute` on tyypitetty vain `useNuxtApp()`-kutsussa. Katso [`useI18n`](/fi/composables/useI18n).

```vue
<script setup lang="ts">
const { t, localePath } = useI18n()
</script>

<template>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
</template>
```

## Kieli {#locale}

### `$getLocale` {#$getlocale}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric) => string
```

Aktiivisen kielen koodi. Välitä reitti lukeaksesi kielen, johon kyseinen reitti kuuluu.

```ts
$getLocale() // 'de' on /de/about
```

### `$getLocaleName` {#$getlocalename}

```ts
() => string | null
```

Aktiivisen kielen `displayName` konfiguraatiosta, tai `null`, kun sitä ei ole.

### `$getLocales` {#$getlocales}

```ts
() => Locale[]
```

Kaikki määritetyt kielet metatietoineen.

Kieliobjektin mukautetut ominaisuudet palautetaan sellaisina kuin ne kirjoitettiin; tyypitä ne `Locale`-rajapinnan [moduulilaajennuksella](/fi/api/module-options#locales).

### `$defaultLocale` {#$defaultlocale}

```ts
() => string | undefined
```

Määritetyn oletuskielen koodi.

### `$getI18nConfig` {#$geti18nconfig}

```ts
() => ResolvedI18nConfig
```

Ratkaistu moduulin konfiguraatio sellaisena kuin ajonaikainen ympäristö sen näkee.

Arvo sisältää [ajonaikaiset ohitukset](/fi/guide/runtime-overrides) (`defaultLocale`, `fallbackLocale`, käytöstä poistetut kielet).

```ts
const { strategy, localeCookie } = useNuxtApp().$getI18nConfig()
```

## Kääntäminen {#translation}

### `$t` {#$t}

```ts
TranslationFn<CleanTranslation>
```

Kääntää avaimen ja interpoloi siihen `params`. Palauttaa `defaultValue`-arvon, kun avain
puuttuu, tai itse avaimen, kun oletusarvoa ei ole annettu.

```ts
// { "welcome": "Welcome, {name}!" }
$t('welcome', { name: 'Ada' }) // 'Welcome, Ada!'
$t('missing.key', {}, 'Fallback') // 'Fallback'
```

Avain, joka osoittaa sisäkkäiseen objektiin, palauttaa kyseisen objektin, ei merkkijonoa. Mallissa se renderöityy muodossa `[object Object]`; käytä lehtiavainta.

### `$ts` {#$ts}

```ts
TranslationFn<string>
```

Kuten `$t`, mutta palauttaa aina merkkijonon: arvo kulkee `toString()`-kutsun läpi, joten sisäkkäisestä
objektista tulee `'[object Object]'`. Osoita avaimella lehteen.

### `$_t` {#$_t}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<CleanTranslation>
```

Sitoo `$t`:n tiettyyn reittiin kääntämistä varten nykyisen sivun ulkopuolella — esimerkiksi asettelussa,
joka renderöi linkin toiseen reittiin.

```ts
const route = useRoute()
const t = useNuxtApp().$_t(route)
t('page.title')
```

### `$_ts` {#$_ts}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<string>
```

Sitoo `$ts`:n tiettyyn reittiin. Katso `$_t`.

### `$tc` {#$tc}

```ts
(key: TranslationKey, params: number | Params, defaultValue?: string) => string
```

Kääntää monikkomuodoilla. `params` voi olla itse lukumäärä tai objekti, joka sisältää
`count`-arvon.

Muodot erotetaan merkillä `|`. Sisäänrakennetulla säännöllä ei-negatiivinen kokonaislukumäärä `n` valitsee muodon `n`, rajattuna viimeiseen muotoon; negatiivinen, murtoluku tai `NaN` saa viimeisen muodon. `{count}` ja muut parametrit interpoloidaan valittuun muotoon.

Kielille, joiden monikot eivät seuraa lukumäärää, aloita malli merkinnällä `=0 `. Ensimmäinen muoto on silloin nollalle, ja muut menevät [`Intl.PluralRules`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/PluralRules)-kategorian mukaan järjestyksessä `zero, one, two, few, many, other`:

```json
{
  "apples": "=0 no apples | one apple | {count} apples",
  "files": "=0 no files | {count} one | {count} few | {count} many"
}
```

```ts
$tc('apples', 0) // 'no apples'
$tc('apples', 1) // 'one apple'
$tc('apples', 7) // '7 apples'

// In `uk` (categories `one, few, many, other`) the forms after the zero form follow those categories:
$tc('files', 21) // '21 one'
$tc('files', 22) // '22 few'
$tc('files', 25) // '25 many'
$tc('files', 2.5) // '2.5 many': no form for `other`, so the last one
```

- `=0 ` lasketaan vain arvon aivan alussa välilyönnin kanssa. `$t` näyttää sen tekstinä: se kuuluu monikoille.
- Kategoria, jolla ei ole omaa muotoa, saa viimeisen muodon. Myös negatiivinen tai murtolukumäärä saa viimeisen muodon.
- Se toimii millä tahansa kielellä: `=0 none | one | {count} many` englanniksi.
- Kategoria tulee kielen `iso`-arvosta, muuten sen koodista. Koodi, jota `Intl` ei tunne, palaa indeksisääntöön, ja merkintä poistetaan silti, joten tulos ei koskaan riipu koneesta.
- `<i18n-t :plural>` noudattaa samaa sääntöä. Mukautettu [`plural`](/fi/api/module-options#plural) tai `customPluralRule` saa raa'an arvon merkintöineen ja päättää itse; `null`-arvon palauttava `plural` antaa kutsun takaisin sisäänrakennetulle säännölle, joka huomioi merkinnän.

Ilman merkintää malli pysyy indeksisäännössä yhtä poikkeusta lukuun ottamatta, joka voidaan lukea vain yhdellä tavalla: nollamuoto ilman paikkamerkkiä, sitten yksi muoto kategoriaa kohden, ja `{count}` jokaisessa muodossa, jonka useampi lukumäärä jakaa (`no files | {count} one | {count} few | {count} many` kielellä `uk`).

Omia sääntöjä varten aseta [`plural`](/fi/api/module-options#plural).

```ts
// { "apples": "no apples | one apple | {count} apples" }
$tc('apples', 0) // 'no apples'
$tc('apples', 10) // '10 apples'
$tc('cart', { count: 2, name: 'Ada' }) // count and params in one object
```

Kolmas argumentti on `defaultValue`, ei parametrit.

### `$has` {#$has}

```ts
(key: string) => boolean
```

Ratkeaako avain aktiivisessa kielessä. Käytä sitä haarautumiseen valinnaisen tekstin perusteella sen sijaan, että
renderöisit raa'an avaimen. Kuten `$t`, se näkee myös poistuvan sivun avaimet saman kielen
sivusiirtymän aikana.

```ts
if ($has('promo.banner')) show.value = true
```

## Muotoilu {#formatting}

### `$tn` {#$tn}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Muotoilee luvun `Intl.NumberFormat`-rajapinnalla aktiivisella kielellä. Avain valitsee nimetyn muodon
konfiguraatiosta.

Nimetyt muodot tulevat asetuksesta [`numberFormats`](/fi/api/module-options#numberformats).

```ts
$tn(1234.5, { style: 'currency', currency: 'EUR' }) // '1.234,50 €' in de
$tn(1000, 'currency') // named format
$tn(1000, 'currency', 'de') // named format in another locale
```

### `$td` {#$td}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Muotoilee päivämäärän `Intl.DateTimeFormat`-rajapinnalla aktiivisella kielellä. Avain valitsee nimetyn muodon
konfiguraatiosta.

Nimetyt muodot tulevat asetuksesta [`datetimeFormats`](/fi/api/module-options#datetimeformats).

```ts
$td(new Date(), { dateStyle: 'long' })
$td(post.createdAt, 'short')
```

### `$tdr` {#$tdr}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

Muotoilee päivämäärän suhteellisena aikana ("3 päivää sitten") `Intl.RelativeTimeFormat`-rajapinnalla.

```ts
$tdr(Date.now() - 5 * 60_000) // '5 minutes ago' in en
```

## Vaihtaminen ja linkit {#switching-and-links}

### `$switchLocale` {#$switchlocale}

```ts
(locale: string) => Promise<boolean>
```

Siirtyy nykyiselle sivulle toisella kielellä. `no_prefix`- ja hash-tilassa se lataa
kielen käännökset ennen siirtymistä; `no_prefix`-tilassa reitti korvataan paikallaan (ei
uutta historiamerkintää). Tuntematon kieli ohitetaan.
Kutsu on asynkroninen: odota sitä `await`-avainsanalla suorittaaksesi koodia siirtymän jälkeen. Se ratkeaa arvoon `true`, kun
kielen sanakirja on aktiivinen, ja arvoon `false`, kun ei ole: pala ei latautunut (nykyinen
sanakirja säilyy; kutsu uudelleen yrittääksesi uudestaan) tai uudempi vaihto voitti.

```ts
await $switchLocale('de')
```

### `$switchLocalePath` {#$switchlocalepath}

```ts
(locale: string) => string
```

Nykyisen sivun polku toisella kielellä, siirtymättä.

```vue
<NuxtLink :to="$switchLocalePath('de')">Deutsch</NuxtLink>
```

### `$switchLocaleRoute` {#$switchlocaleroute}

```ts
(locale: string) => RouteLocationRaw
```

Nykyisen sivun reittiobjekti toisella kielellä, siirtymättä, tai URL-merkkijono
kielelle, jolla on oma `baseUrl`. `trailingSlash`-asetuksella objektilla on `path` ja `fullPath`
säännön mukaisesti, `query` ja `hash` sellaisinaan, ja `router.push` tai linkki säilyttää ne.

### `$switchRoute` {#$switchroute}

```ts
(route: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, toLocale?: string) => Promise<void>
```

Siirtyy toiseen reittiin säilyttäen aktiivisen kielen tai vaihtaen kieleen `toLocale`. Asynkroninen kuten
`$switchLocale`.

```ts
$switchRoute('/about') // active locale
$switchRoute({ name: 'about' }, 'de') // switch to de
```

### `$localePath` {#$localepath}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => string
```

Ratkaisee polun annetulla kielellä tai aktiivisella kielellä. Merkkijono, jossa on `http(s):`-, `mailto:`-
tai `tel:`-skeema, palautetaan sellaisenaan: älä välitä käyttäjän syötettä linkin kohteeksi tarkistamatta.

Merkkijonopolku luetaan sivuna, jonka se näyttää, joten myös kielen mukautettu polku otetaan käyttöön.

```ts
$localePath('/about') // '/about' in en, '/de/ueber-uns' in de with localeRoutes
$localePath({ name: 'about' }, 'fr') // '/fr/about'
```

### `$localeRoute` {#$localeroute}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => RouteLocationResolved
```

Ratkaisee reitin annetulla kielellä tai aktiivisella kielellä. Tavallinen objekti, jonka voi turvallisesti säilyttää tilassa. Kun parametri vaatii
koodausta, sillä on `path`, `fullPath`, `query` ja `hash` mutta ei `name`- tai `params`-kenttiä: polku antaa reitittimelle
koodatun URL-osoitteen. Toisella verkkotunnuksella olevalle kielelle `path` ja `fullPath` ovat absoluuttisia, eikä reititin voi ottaa niitä:
tällainen linkki kulkee `<i18n-link>`-komponentin tai `$localePath`-funktion kautta.

### `$getRouteName` {#$getroutename}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric, locale?: string) => string
```

Reitin nimi ilman kielietuliitettä — nimi, jonka mukaan käännökset on avainnettu.

```ts
$getRouteName() // 'about' on /de/about
```

## Sivukonfiguraatio {#page-config}

### `$defineI18nRoute` {#$definei18nroute}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Rekisteröi sivukohtaisen kielikonfiguraation ja käännökset komponentin sisältä.
Yhdistää aktiiviseen kieleen ja ottaa uudelleen käyttöön, kun kieli vaihtuu.

Kutsu sitä sivun `<script setup>`-lohkossa, aina `useNuxtApp()`-kutsusta puretulla muuttujalla. Käännös lukee kutsusta `locales`-, `localeRoutes`- ja `disableMeta`-arvot; ajon aikana vain `locales` on merkitsevä (inline-käännökset yhdistetään aktiiviselle kielelle). Täydelliset säännöt: [Sivukonfiguraatio](/fi/guide/per-component-translations).

```vue
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'de'],
  localeRoutes: { en: '/about', de: '/ueber-uns' },
})
</script>
```

### `$setI18nRouteParams` {#$seti18nrouteparams}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Asettaa nykyiselle reitille kielikohtaiset parametrit, jotta dynaaminen segmentti voi vaihdella kielittäin.
Kutsu sitä SSR:n aikana ennen kuin head renderöidään.

Parametrit tyhjennetään, kun siirtymä toiseen polkuun vahvistetaan, mukaan lukien `/news/1` → `/news/4`, joka säilyttää reitin nimen. Lisätietoja: [Lokalisoidut polut](/fi/guide/custom-locale-routes).

```ts
$setI18nRouteParams({
  en: { slug: 'my-post' },
  de: { slug: 'mein-beitrag' },
})
```

## Ajonaikaiset käännökset {#runtime-translations}

### `$mergeTranslations` {#$mergetranslations}

```ts
(newTranslations: Translations) => void
```

Yhdistää käännöksiä aktiiviseen kieleen ajon aikana ja ohittaa ladatut.

Syväyhdistää aktiivisen kielen nykyiseen sivupalaan; avaimet, joita se ei mainitse, säilyvät.

```ts
$mergeTranslations({ banner: { title: 'Sale' } })
```

### `$setTranslation` {#$settranslation}

```ts
(key: string, value: unknown) => void
```

Korvaa `key`-kohdan arvon aktiivisessa sanakirjassa. Tämä on korvaus, ei yhdistäminen —
käytä `$mergeTranslations`-funktiota, kun olemassa olevien sisarten pitää säilyä.

```ts
$setTranslation('banner', { title: 'Sale' }) // drops other keys under banner
$setTranslation('banner.title', 'Sale') // dotted path
```

### `$loadPageTranslations` {#$loadpagetranslations}

```ts
(locale: string, routeName: string, translations: Translations) => Promise<void>
```

Lataa sivun käännökset ajon aikana sisällölle, jonka avaimet eivät ole tiedossa käännösvaiheessa.

Yhdistää muistissa olevaan `(locale, routeName)`-palaan, ja näkymä päivittyy, kun pala on aktiivinen. Tässä ei haeta payloadia: vielä lataamattoman sivun käännökset odottavat, ja kun sen tiedosto latautuu, ne pysyvät sen päällä.

```ts
await $loadPageTranslations('en', 'about', { title: 'About us' })
```

### `$resolveTranslations` {#$resolvetranslations}

```ts
() => Translations
```

Kaikki muistissa olevat käännökset aktiiviselle kielelle ja reitille puuna.
Vain luku -näkymä siihen, mitä `$t()` pystyy ratkaisemaan juuri nyt.

Käsittele tulosta vain luku -muotoisena.

### `$setMissingHandler` {#$setmissinghandler}

```ts
(handler: MissingHandler | null) => void
```

Asentaa takaisinkutsun, jota kutsutaan jokaiselle ratkeamattomalle avaimelle. Välitä `null` poistaaksesi sen.

Käsittelijä suoritetaan kehitysvaroituksen sijaan.

```ts
$setMissingHandler((locale, key, routeName) => {
  console.error(`[i18n] missing ${key} in ${locale} (${routeName})`)
})
```

### `$clearCache` {#$clearcache}

```ts
() => void
```

Hylkää kaikki välimuistissa olevat käännöspalat ja lataa nykyisen sivun sanakirjan uudelleen. Sivu
näyttää nykyiset käännöksensä, kunnes tuoreet saapuvat. Kehitystilan HMR kutsuu sitä
jokaisen käännöstiedoston muutoksen yhteydessä.

```ts
const { clearCache } = useI18n()
clearCache()
```

Epäonnistunut uudelleenlataus säilyttää nykyisen sanakirjan.
