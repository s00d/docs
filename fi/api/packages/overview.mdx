title: "Pakettien API:t"
description: "Jokaisen @i18n-micro/*-paketin viety API, luotu API-tilannevedoksista, jotka CI tarkistaa lähdekoodia vasten."
---

Nuxt-moduuli on rakennettu pienistä `@i18n-micro/*`-paketeista, ja useimmat niistä toimivat itsenäisesti: `@i18n-micro/vue` Vue-sovelluksessa, `@i18n-micro/core` missä tahansa. Näiltä sivuilta voit tarkistaa, mitä paketti vie, sisääntulokohtaisesti. Jokainen sivu on luotu tilannevedoksesta, jonka [`pnpm run api:surface`](https://s00d.github.io/nuxt-i18n-micro/contributing/maintenance-commands#api-surface) tarkistaa TypeScript-lähteitä vasten, joten vienti ei voi muuttua CI:n huomaamatta.
