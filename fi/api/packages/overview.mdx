# Pakettien API:t

`nuxt-i18n-micro` on rakennettu joukosta pieniä paketteja, joista useimpia voi käyttää yksinään — `@i18n-micro/vue` tavallisessa Vue-sovelluksessa, `@i18n-micro/core` missä tahansa.

Jokainen alla oleva sivu on luotu API-tilannekuvasta, jota [`pnpm run api:surface`](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/maintenance-commands.md#api-surface) tarkistaa TypeScript-lähteitä vastaan. Näin vientilause ei voi kadota ilman, että joko tämä viite muuttuu tai CI hajoaa.
