[CLI-opas](/fi/guide/cli) näyttää yleisimmät työnkulut. Tämä sivu luettelee kaiken, ja se on generoitu samasta taulukosta, joka ohjaa `--help`-tulostetta.

## Yleiset liput {#common-flags}

| Lippu | Oletus | Kuvaus |
| --- | --- | --- |
| `--cwd` | nykyinen hakemisto | Projektihakemisto |
| `--logLevel` | `info` | Tulostustaso: silent, info |
| `--debug` | `false` | Tulosta pinojälki, kun komento epäonnistuu |

## Tarkastelu {#inspect}

### `info` {#info}

Tulosta projektin ratkaistu i18n-konfiguraatio

| Lippu | Oletus | Kuvaus |
| --- | --- | --- |
| `--json` | `false` | Tulosta JSON tekstin sijaan |

### `check` {#check}

CI-portti: epäonnistuu puuttuvista, tyhjistä, ylimääräisistä, määrittelemättömistä tai käyttämättömistä avaimista sekä rikkinäisistä paikkamerkeistä

| Lippu | Oletus | Kuvaus |
| --- | --- | --- |
| `--translationDir` | nuxt.config-tiedoston `i18n.translationDir` | Käännöshakemisto suhteessa projektiin |
| `--only` | kaikki paitsi duplicates | Pilkuin erotetut suoritettavat tarkistukset: missing, empty, extra, placeholders, undefined, unused, duplicates. Tässä nimetty `unused` epäonnistuu, kun sitä ei voida suorittaa |
| `--duplicates` | `false` | Raportoi myös sama teksti eri avaimien alla |
| `--ignore` | — | Pilkuin erotetut glob-kuviot ohitettaville lähdetiedostoille suhteessa projektiin |
| `--json` | `false` | Tulosta JSON tekstin sijaan |

```bash
i18n-micro check
i18n-micro check --only missing,placeholders --json
```

### `stats` {#stats}

Näytä käännösten valmiusaste localeittain

| Lippu | Oletus | Kuvaus |
| --- | --- | --- |
| `--translationDir` | nuxt.config-tiedoston `i18n.translationDir` | Käännöshakemisto suhteessa projektiin |
| `--html` | — | Kirjoita lisäksi HTML-raportti tähän tiedostoon |
| `--json` | `false` | Tulosta JSON tekstin sijaan |
| `--baseRef` | — | Git-viite, johon valmiusastetta verrataan, esim. HEAD~1 tai main |

```bash
i18n-micro stats --baseRef main
i18n-micro stats --html reports/i18n.html
```

### `lint` {#lint}

Tarkista käännösten teksti; epäonnistuu, jos ongelmia jää

| Lippu | Oletus | Kuvaus |
| --- | --- | --- |
| `--translationDir` | nuxt.config-tiedoston `i18n.translationDir` | Käännöshakemisto suhteessa projektiin |
| `--rules` | kaikki, tai .i18n-lintrc.json-tiedoston `enabledRules` | Pilkuin erotetut suoritettavat säännöt: no-trailing-spaces, no-multiple-spaces, no-empty-translation tai mukautettu sääntö |
| `--fix` | `false` | Korjaa korjattavissa olevat: välilyönnit sekä mukautetut säännöt, joilla on korvaus |
| `--json` | `false` | Tulosta JSON tekstin sijaan |

```bash
i18n-micro lint --rules no-trailing-spaces --fix
```

### `search` {#search}

Hae avaimia ja arvoja ja näytä, missä kutakin avainta käytetään

| Lippu | Oletus | Kuvaus |
| --- | --- | --- |
| `--translationDir` | nuxt.config-tiedoston `i18n.translationDir` | Käännöshakemisto suhteessa projektiin |
| `<query>` | — | Haettava teksti tai avain |
| `--caseSensitive` | `false` | Huomioi kirjainkoko |
| `--onlyUnused` | `false` | Vain avaimet, jotka `clean` poistaisi; hakuehdosta tulee valinnainen |
| `--scope` | `all` | Mistä haetaan: global, pages, all |
| `--limit` | — | Palauta enintään näin monta avainta |
| `--ignore` | — | Pilkuin erotetut glob-kuviot ohitettaville lähdetiedostoille suhteessa projektiin |
| `--json` | `false` | Tulosta JSON tekstin sijaan |

```bash
i18n-micro search "Welcome"
i18n-micro search --onlyUnused
```

## Käännöstyönkulku {#translation-workflow}

### `extract` {#extract}

Luettele lähdetiedostojen käyttämät avaimet, joilla ei vielä ole tekstiä, ja lisää ne, joilla on oletusteksti, oletuslocaleen

| Lippu | Oletus | Kuvaus |
| --- | --- | --- |
| `--translationDir` | nuxt.config-tiedoston `i18n.translationDir` | Käännöshakemisto suhteessa projektiin |
| `--ignore` | — | Pilkuin erotetut glob-kuviot ohitettaville lähdetiedostoille suhteessa projektiin |

```bash
i18n-micro extract
```

### `translate` {#translate}

Täytä puuttuvat käännökset oletuslocalesta käännöspalvelun avulla

| Lippu | Oletus | Kuvaus |
| --- | --- | --- |
| `--translationDir` | nuxt.config-tiedoston `i18n.translationDir` | Käännöshakemisto suhteessa projektiin |
| `--service` | — | Käännöspalvelu: ai, azure, deepl, google, libretranslate, yandexcloud |
| `--token` | — | API-avain. Suosi I18N_TRANSLATE_TOKEN-ympäristömuuttujaa: liput päätyvät komentotulkin historiaan |
| `--options` | — | Palvelun asetukset avain:arvo-pareina pilkuin erotettuina |
| `--locale` | kaikki localet oletusta lukuun ottamatta | Pilkuin erotetut täytettävät localet |
| `--replace` | `false` | Käännä jokainen avain uudelleen ja korvaa olemassa olevat arvot |
| `--dryRun` | `false` | Laske avaimet ja merkit localeittain; älä lähetä mitään |
| `--chunkSize` | — | Merkkijonoja pyyntöä kohden; rajoitettu siihen, mitä palvelu hyväksyy |
| `--pluralSeparator` | `\|` | Monikkomuotojen erotin viesteissä |
| `--glossaryFile` | `.i18n-glossary.json`, kun se on olemassa | Sanastotiedosto, jota `ai`-palvelu käyttää |

```bash
i18n-micro translate --dryRun
I18N_TRANSLATE_TOKEN=... i18n-micro translate --service deepl --locale de,fr
i18n-micro translate --service ai --options provider:openai,model:gpt-4o-mini
i18n-micro translate --service libretranslate --options baseUrl:https://translate.example.com
```

### `sync` {#sync}

Poista avaimet, joita oletuslocalessa ei ole; pysähtyy, kun turvallisuutta ei voida todistaa. Puuttuvat avaimet jäävät puuttumaan

| Lippu | Oletus | Kuvaus |
| --- | --- | --- |
| `--translationDir` | nuxt.config-tiedoston `i18n.translationDir` | Käännöshakemisto suhteessa projektiin |
| `--ignore` | — | Pilkuin erotetut glob-kuviot ohitettaville lähdetiedostoille suhteessa projektiin |
| `--dryRun` | `false` | Luettele, mitä poistettaisiin; älä kirjoita mitään |
| `--force` | `false` | Poista avaimet, vaikka turvallisuutta ei voida todistaa |

```bash
i18n-micro sync --dryRun
```

### `clean` {#clean}

Poista avaimet, joita mikään projektissa ei käytä; pysähtyy, kun sitä ei voida todistaa

| Lippu | Oletus | Kuvaus |
| --- | --- | --- |
| `--translationDir` | nuxt.config-tiedoston `i18n.translationDir` | Käännöshakemisto suhteessa projektiin |
| `--include` | — | Säännöllinen lauseke: harkitse poistettavaksi vain vastaavia avaimia |
| `--exclude` | — | Säännöllinen lauseke: älä koskaan poista vastaavia avaimia |
| `--ignore` | — | Pilkuin erotetut glob-kuviot ohitettaville lähdetiedostoille suhteessa projektiin |
| `--dryRun` | `false` | Luettele, mitä poistettaisiin; älä kirjoita mitään |
| `--force` | `false` | Poista avaimet, vaikka käyttöä ei voida todistaa kaikille niistä |

```bash
i18n-micro clean --dryRun
i18n-micro clean --exclude '^errors\.'
```

## Refaktorointi {#refactoring}

### `text-to-i18n` {#text-to-i18n}

Korvaa Vue-pohjien kovakoodattu teksti käännöskutsuilla ja raportoi koodin kovakoodattu teksti

| Lippu | Oletus | Kuvaus |
| --- | --- | --- |
| `--translationFile` | `<translationDir>/<defaultLocale>.json` | Tiedosto, johon uudet avaimet menevät |
| `--path` | koko projekti | Käsiteltävä tiedosto tai hakemisto |
| `--context` | — | Generoitujen avainten etuliite |
| `--ignore` | — | Pilkuin erotetut glob-kuviot ohitettaville lähdetiedostoille suhteessa projektiin |
| `--dryRun` | `false` | Näytä, mitä muuttuisi; älä kirjoita mitään |
| `--interactive` | `false` | Vahvista tai muokkaa jokainen generoitu avain |

```bash
i18n-micro text-to-i18n --dryRun
i18n-micro text-to-i18n --path components --context ui
```

### `rename` {#rename}

Nimeä avain tai nimiavaruus uudelleen kaikissa localeissa ja lähdetiedostoissa

| Lippu | Oletus | Kuvaus |
| --- | --- | --- |
| `--translationDir` | nuxt.config-tiedoston `i18n.translationDir` | Käännöshakemisto suhteessa projektiin |
| `--from` **\*** | — | Nykyinen avain tai nimiavaruus |
| `--to` **\*** | — | Uusi avain tai nimiavaruus |
| `--ignore` | — | Pilkuin erotetut glob-kuviot ohitettaville lähdetiedostoille suhteessa projektiin |
| `--dryRun` | `false` | Raportoi muutokset; älä kirjoita mitään |

**\*** pakollinen.

```bash
i18n-micro rename --from common.save --to actions.save
```

### `pseudo` {#pseudo}

Täytä locale pseudokäännöksillä asettelu- ja kovakoodattu teksti -ongelmien löytämiseksi

| Lippu | Oletus | Kuvaus |
| --- | --- | --- |
| `--translationDir` | nuxt.config-tiedoston `i18n.translationDir` | Käännöshakemisto suhteessa projektiin |
| `--sourceLocale` | oletuslocale | Luettava locale |
| `--targetLocale` **\*** | — | Täytettävä locale |
| `--replace` | `false` | Korvaa olemassa olevat arvot |

**\*** pakollinen.

### `format` {#format}

Kirjoita locale-tiedostot uudelleen lajitelluin avaimin ja yhtenäisin sisennyksin

| Lippu | Oletus | Kuvaus |
| --- | --- | --- |
| `--translationDir` | nuxt.config-tiedoston `i18n.translationDir` | Käännöshakemisto suhteessa projektiin |
| `--indent` | `2` | Sisennyksen välilyönnit |
| `--sortKeys` | `true` | Lajittele avaimet; käytä --no-sortKeys säilyttääksesi niiden järjestyksen |
| `--check` | `false` | Epäonnistu, jos tiedosto muuttuisi; älä kirjoita mitään |

```bash
i18n-micro format --check
```

## Vaihto {#exchange}

### `export` {#export}

Vie locale-tiedostot PO- tai CSV-muotoon oletuslocalen teksti lähteenä

| Lippu | Oletus | Kuvaus |
| --- | --- | --- |
| `--translationDir` | nuxt.config-tiedoston `i18n.translationDir` | Käännöshakemisto suhteessa projektiin |
| `--format` | `po` | Tiedostomuoto: po, csv |
| `--dir` | `pots` po-muodolle, `csv_exports` csv-muodolle | Tulostehakemisto suhteessa projektiin |
| `--force` | `false` | Korvaa tiedostot, joita on muutettu edellisen viennin jälkeen eikä koskaan tuotu |

```bash
i18n-micro export --format csv
```

### `import` {#import}

Yhdistä PO- tai CSV-tiedostot locale-tiedostoihin

| Lippu | Oletus | Kuvaus |
| --- | --- | --- |
| `--translationDir` | nuxt.config-tiedoston `i18n.translationDir` | Käännöshakemisto suhteessa projektiin |
| `--format` | `po` | Tiedostomuoto: po, csv |
| `--dir` | `pots` po-muodolle, `csv_exports` csv-muodolle | Syötehakemisto suhteessa projektiin |
| `--dryRun` | `false` | Raportoi, mitä tuotaisiin; älä kirjoita mitään |

```bash
i18n-micro import --format csv --dryRun
```

### `sync-remote` {#sync-remote}

Hae globaalit käännökset .i18n-remote.json-tiedostossa määritetystä HTTP-päätepisteestä tai lähetä ne sinne

| Lippu | Oletus | Kuvaus |
| --- | --- | --- |
| `--translationDir` | nuxt.config-tiedoston `i18n.translationDir` | Käännöshakemisto suhteessa projektiin |
| `--pull` | `true` | Hae etäpalvelimelta |
| `--push` | `false` | Lähetä etäpalvelimelle |
| `--force` | `false` | Haettaessa käytä etäarvoa; lähetettäessä korvaa teksti, joka on vain etäpalvelimella |
| `--dryRun` | `false` | Raportoi, mitä haku muuttaisi; älä kirjoita tai lähetä mitään |

```bash
i18n-micro sync-remote --dryRun
i18n-micro sync-remote --no-pull --push
```

## Lint-säännöt {#lint-rules}

| Sääntö | Löytää | Korjataan `--fix`-lipulla |
| --- | --- | --- |
| `no-trailing-spaces` | Välilyönnit arvon tai rivin lopussa | kyllä |
| `no-multiple-spaces` | Kaksi tai useampia välilyöntejä peräkkäin | kyllä |
| `no-empty-translation` | Tyhjä tai pelkkiä välilyöntejä sisältävä arvo | ei |

## Poistumiskoodit {#exit-codes}

| Koodi | Merkitys |
| --- | --- |
| `0` | Valmis, ei raportoitavaa |
| `1` | Löydöksiä: `check`, `lint` tai `format --check` löysi jotain, `clean` tai `sync` ei voinut todistaa poistoa turvalliseksi, `export` korvaisi tuomattoman työn, `translate` jätti avaimia pois, `import` tai `sync-remote` kohtasi ristiriidan, `sync-remote`-lähetys pudottaisi etätekstiä. `clean`-, `sync`- tai `sync-remote`-haun `--dryRun` raportoi nämä ja palauttaa koodin `0` |
| `2` | Virhe: väärä käyttö, lukukelvoton projekti, verkko- tai tiedostovirhe |

## Konfiguraatiotiedostot {#configuration-files}

| Tiedosto | Käyttäjä |
| --- | --- |
| `.i18n-lintrc.json` | `lint`: `enabledRules`, `disabledRules`, `customRegexRules` (`name`, `pattern`, `flags`, `description`, `replacement`) |
| `.i18n-remote.json` | `sync-remote`: `url`, `path`, `token`, `auth` (`username`, `password`). `type` voidaan jättää pois; vain `custom` on olemassa |
| `.i18n-glossary.json` | `translate --service ai`: `entries`, joissa `source`, `target` ja valinnaiset `from`, `to` |

## Ympäristömuuttujat {#environment-variables}

| Nimi | Käyttötarkoitus |
| --- | --- |
| `I18N_TRANSLATE_TOKEN` | `translate`-komennon API-avain. Luetaan myös `.env`-tiedostosta |
| `I18N_REMOTE_TOKEN` | `sync-remote`-komennon bearer-tunniste. Luetaan myös `.env`-tiedostosta |
| `AI_GATEWAY_API_KEY, OPENAI_API_KEY, ANTHROPIC_API_KEY` | `ai`-palvelun avain, kun `I18N_TRANSLATE_TOKEN` ei ole asetettu |
| `DEFAULT_LOCALE` | Ohittaa `defaultLocale`-asetuksen, kuten moduulissa |
