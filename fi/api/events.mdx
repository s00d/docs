Moduuli kutsuu yhtä ajonaikaista (sovelluksen) hookia, `i18n:register`. Käytä sitä, kun plugin tai moduuli lisää käännöksiä, joita ei ole `locales/`-tiedostoissasi. Callback-funktiosi saa `register`-funktion, joka yhdistää käännökset näytettävään sivuun.

## `i18n:register` {#i18nregister}

```ts
'i18n:register': (
  register: (translations: unknown, locale?: string) => void,
  locale: string,
) => HookResult
```

| Argumentti | Kuvaus |
| --- | --- |
| `register(translations, locale?)` | Yhdistää (deep merge) `translations`-käännökset ladattavan reitin sivukohtaiseen osaan localelle `locale` (oletus: hookin `locale`). Jo olemassa olevat avaimet korvataan. |
| `locale` | Ladattavan reitin locale. |

Hook on tyypitetty `RuntimeNuxtHooks`-rajapinnan kautta, joten `nuxtApp.hook('i18n:register', …)` ei tarvitse tyyppimuunnosta.

## Milloin se laukeaa {#when-it-fires}

Latausplugin (`i18n-plugin-loader`) kutsuu sitä:

1. kerran käynnistyksessä, kun jokainen plugin on suoritettu (`app:created`) ja ennen kuin sovellus renderöidään;
2. omassa `router.beforeEach`-käsittelijässään, kun kohdesivun käännökset on ladattu ja polku muuttuu — `no_prefix`-strategiassa jokaisella navigoinnilla.

Jokaista callbackia ja jokaista `register`-kutsua odotetaan ennen kuin sovellus renderöidään tai navigointi jatkuu, joten sivu renderöidään yhdistetyillä avaimilla. Asetuksella [`hooks: false`](/fi/api/module-options#hooks) hookia ei kutsuta koskaan.

## Esimerkki {#example}

```ts
// plugins/i18n-extra.ts
export default defineNuxtPlugin((nuxtApp) => {
  nuxtApp.hook('i18n:register', async (register, locale) => {
    const extra = await $fetch<Record<string, unknown>>(`/api/cms-strings/${locale}`)
    register(extra, locale)
  })
})
```

Tämä on ajonaikainen hook: rekisteröi se `nuxtApp.hook`-kutsulla pluginissa, älä `nuxt.hook`-kutsulla `nuxt.config`-tiedostossa tai moduulin `setup`-funktiossa. Moduuli lisää tällaisen pluginin `addPlugin`-funktiolla.
