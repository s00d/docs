# 🌍 `<i18n-group>`-komponentti

Nuxt I18n Micron `<i18n-group>`-komponentti tarjoaa kätevän tavan ryhmitellä käännökset yhteisen etuliitteen alle. Se vähentää toistoa ja parantaa koodin organisointia.

## ⚙️ Propsit

{/* generated:component:i18n-group — do not edit; run `pnpm run docs:generate` */}

| Prop | Tyyppi | Oletus | Kuvaus |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | Avaimen etuliite, johon kaikki slotin sisäiset haut suhteutetaan. |
| `groupClass` | `string` | `''` | Lisäluokka kääre-elementille. |

**\*** pakollinen.

### Slotit

| Slotti | Sidokset | Kuvaus |
| --- | --- | --- |
| `default` | `prefix`, `t` | Vastaanottaa etuliitteen `prefix` ja siihen rajatun funktion `t`. |

{/* /generated:component:i18n-group */}

## 🎯 Slotit

Oletusslot saa etuliitteen `prefix` ja siihen rajatun funktion `t`, joten sisällä olevat avaimet kirjoitetaan suhteessa etuliitteeseen:

```vue
<i18n-group prefix="checkout">
  <template #default="{ t }">
    <h2>{{ t('title') }}</h2>
    <p>{{ t('summary', { count: 3 }) }}</p>
  </template>
</i18n-group>
```

## 🛠️ Käyttöesimerkki

### Peruskäyttö

```vue
<template>
  <i18n-group prefix="product.details">
    <template #default="{ t }">
      <h1>{{ t('title') }}</h1>
      <p>{{ t('description') }}</p>
      <div class="price">{{ t('price', { value: 99.99 }) }}</div>
    </template>
  </i18n-group>
</template>
```

Käännöstiedosto:

```json
{
  "product": {
    "details": {
      "title": "Premium Product",
      "description": "This is a premium product",
      "price": "Price: ${value}"
    }
  }
}
```

### Mukautetun luokan kanssa

```vue
<template>
  <i18n-group prefix="user.profile" group-class="profile-section">
    <template #default="{ t }">
      <div class="user-info">
        <h2>{{ t('title') }}</h2>
        <p>{{ t('bio') }}</p>
        <div class="stats">
          <span>{{ t('stats.followers') }}</span>
          <span>{{ t('stats.following') }}</span>
        </div>
      </div>
    </template>
  </i18n-group>
</template>
```

Käännöstiedosto:

```json
{
  "user": {
    "profile": {
      "title": "User Profile",
      "bio": "User biography goes here",
      "stats": {
        "followers": "Followers: {count}",
        "following": "Following: {count}"
      }
    }
  }
}
```

### Dynaamisen sisällön kanssa

```vue
<template>
  <i18n-group prefix="blog.post">
    <template #default="{ t }">
      <article>
        <h1>{{ t('title') }}</h1>
        <div class="meta">
          {{ t('meta.author', { name: author }) }} |
          {{ t('meta.date', { date: publishDate }) }}
        </div>
        <div v-for="(section, index) in sections" :key="index">
          <h2>{{ t(`sections.${index}.title`) }}</h2>
          <p>{{ t(`sections.${index}.content`) }}</p>
        </div>
      </article>
    </template>
  </i18n-group>
</template>

<script setup>
const author = 'John Doe'
const publishDate = '2024-01-01'
const sections = ['intro', 'main', 'conclusion']
</script>
```

## 🎨 Tyylitys

Komponentti kääri sisältönsä div-elementtiin, jolla on luokka `i18n-group` sekä `groupClass`-propissa määritellyt lisäluokat:

```css
.i18n-group {
  /* Your base styles */
}

.profile-section {
  /* Additional styles for profile sections */
}
```

## 🚀 Parhaat käytännöt

1. **Yhtenäiset etuliitteet**: käytä yhtenäisiä ja loogisia etuliitteitä, jotka heijastavat sovelluksesi rakennetta.

```vue
<i18n-group prefix="features.pricing">
<i18n-group prefix="features.security">
```

2. **Modulaarinen organisointi**: ryhmittele toisiinsa liittyvät käännökset merkityksellisten etuliitteiden alle.

```vue
<i18n-group prefix="checkout.payment">
<i18n-group prefix="checkout.shipping">
```

3. **Uudelleenkäytettävät komponentit**: luo uudelleenkäytettäviä komponentteja omilla käännösryhmillään.

```vue
<!-- UserProfile.vue -->
<i18n-group prefix="user.profile">

<!-- UserSettings.vue -->
<i18n-group prefix="user.settings">
```

4. **Sisäkkäiset ryhmät**: vältä liian syvää ryhmien sisäkkäistämistä selkeyden säilyttämiseksi.

```vue
<!-- Good -->
<i18n-group prefix="shop.product">

<!-- Avoid -->
<i18n-group prefix="shop.category.product.details.specs">
```
