# 🌍 `<i18n-switcher>`-komponentti

`Nuxt I18n Micro`n `<i18n-switcher>`-komponentti tarjoaa käyttäjäystävällisen pudotusvalikkokäyttöliittymän kielen vaihtoon sovelluksessasi. Komponentti on erittäin mukautettavissa ja sopii saumattomasti sovelluksesi ulkoasuun ja rakenteeseen.

Kielet, joilla on `disabled: true`, **ohitetaan** pudotusvalikossa (ne ovat edelleen saatavilla `$getLocales()`-funktiolla SEO:ta ja head-tageja varten). Vain vaihdettavat kielet saavat `NuxtLink`-linkin ja `hreflang`-attribuutin.

Jokainen osa on oletuksena tyylittelemätön: `custom*Style`-propsit ottavat vastaan sisäisiä tyyliobjekteja, ja alla olevat slotit korvaavat kokonaan markupin silloin, kun tyylittely ei riitä.

## 🛠️ Käyttöesimerkkejä

### Peruskäyttö

```vue
<template>
  <i18n-switcher />
</template>
```

Tämä renderöi kielenvaihtimen oletustyyleillä ja -toiminnallisuudella.

### Mukautetut tekstit ja sisäiset tyylit

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Tämä esimerkki esittää täysin mukautetun kielenvaihtimen omilla teksteillä ja sisäisillä tyyleillä.

## 🔌 Slotit

Jokainen vaihtimen visuaalinen osa voidaan korvata. Slotit on lueteltu yllä olevassa taulukossa. Jokainen niistä ottaa mallikoodin sisällökseen:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Slotit, joiden nimi päättyy merkkeihin `-item`, `-link-content` tai alkaa merkkijonolla `before-item`, saavat kohteen, johon ne liittyvät, `locale`-objektina.

## 🎨 Tyylien yleiskatsaus

`<i18n-switcher>`-komponentissa on perustyylit, jotka on määritelty sisäisillä tyyleillä ja jotka voidaan helposti ohittaa antamalla mukautettuja tyylejä propsien kautta. Tässä lyhyt yhteenveto oletustyylityksestä:

- **Kääre**: hallitsee pudotusvalikon sijoittelua.
- **Painike**: tyylittää pudotusvalikon avauspainiketta.
- **Pudotusvalikko**: tyylittää pudotusvalikon listan.
- **Kohteet**: tyylittävät jokaisen listakohteen.
- **Linkit**: tyylittävät kunkin kohteen sisällä olevat linkit.
- **Kuvake**: tyylittää pudotusvalikon osoitinkuvakkeen.

Voit mukauttaa näitä tyylejä antamalla omia tyylejä vastaavien propsien kautta, jolloin kielenvaihdin sulautuu saumattomasti sovelluksesi käyttöliittymään.
