# 🌍 `<i18n-t>`-komponentti

`Nuxt I18n Micro`n `<i18n-t>`-komponentti on joustava käännöskomponentti, joka tukee dynaamisen sisällön lisäämistä slottien kautta. Sen avulla voit interpoloida käännöksiä mukautetuilla Vue-komponenteilla tai HTML-sisällöllä. Näin voit toteuttaa monimutkaisia lokalisointiskenaarioita.

Vain yksi propseista `plural`, `number`, `date` ja `relativeDate` on käytössä kerrallaan. Jos useita on asetettu, listan ensimmäinen voittaa.

### Esimerkit propseittain

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

## 🛠️ Käyttöesimerkkejä

### Peruskäyttö

```vue
<i18n-t keypath="feedback.text" />
```

Tämä renderöi käännöksen avaimelle `feedback.text` `<span>`-elementin sisällä.

### Slottien käyttö dynaamiseen sisältöön

`<i18n-t>`-komponentti tukee slottien käyttöä Vue-komponenttien tai muun sisällön dynaamiseen sijoittamiseen käännöksen tiettyihin osiin.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

Tässä esimerkissä paikkamerkki `\{link\}` käännösmerkkijonossa `feedback.text` korvataan `<nuxt-link>`-komponentilla, joka itsessään sisältää toisen käännöskomponentin.

### Monikoiden käsittely

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

Tämä soveltaa automaattisesti monikkosääntöjä arvon `itemCount` mukaan.

## 🚀 Lisäominaisuudet

### Oletusslot

Jos erityistä slottia ei ole annettu, käännöstä voi mukauttaa oletusslotin avulla, joka tarjoaa koko käännetyn merkkijonon:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### Ehdollinen renderöinti

Älä renderöi mitään, jos käännösmerkkijono on tyhjä. Käytä propsia `hideIfEmpty`.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### Mukautettu monikkosääntö

Käytä mukautettua funktiota monikoiden käsittelyyn.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### Edistynyt esimerkki slottien avulla

Käytä slotteja mukauttaaksesi, miten käännössisältö renderöidään.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
