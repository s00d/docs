# useI18nLocale

## Allekirjoitus

{/* generated:symbol:useI18nLocale — do not edit; run `pnpm run docs:generate` */}

```ts
useI18nLocale(): { getEffectiveLocale: (route: unknown, getLocaleFromRoute: GetLocaleFromRoute) => string; getLocale: () => string | null; getLocaleWithServerFallback: (serverLocale?: string | null) => string | null; getPreferredLocale: () => string | null; hashCookie: any; isValidLocale: (locale: string | null | undefined) => locale is string; locale: any; localeCookie: any; resolveInitialLocale: (options: ResolveInitialLocaleOptions) => string; setLocale: (locale: string | null) => void; syncLocale: (locale: string | null) => void; validLocales: string[] }
```

Keskitetty sisäänpääsypiste i18n-kielen hallintaan.
Yhdistää `useState('i18n-locale')`-tilan, kielievästeen ja synkronointiapurit.

{/* /generated:symbol:useI18nLocale */}

## Käyttö

```vue
<script setup>
const {
  locale,
  localeCookie,
  hashCookie,
  validLocales,
  getPreferredLocale,
  getLocale,
  getLocaleWithServerFallback,
  getEffectiveLocale,
  resolveInitialLocale,
  setLocale,
  syncLocale,
  isValidLocale,
} = useI18nLocale()

// Set locale (updates state and cookies)
setLocale('de')

// Get current locale (state → cookie)
const current = getLocale()

// Get valid preferred locale
const preferred = getPreferredLocale()
</script>
```

## API

| Ominaisuus/metodi                               | Tyyppi                              | Kuvaus                                                                             |
| ----------------------------------------------- | ----------------------------------- | ---------------------------------------------------------------------------------- |
| `locale`                                        | `Ref<string \| null>`               | Reaktiivinen kielitila (`useState('i18n-locale')`)                                 |
| `localeCookie`                                  | `Ref`                               | Kielieväste (kun asetus `localeCookie` on käytössä)                                |
| `hashCookie`                                    | `Ref`                               | Eväste, jota käytetään kun `hashMode` on aktiivinen                                |
| `validLocales`                                  | `string[]`                          | Käytössä olevat kielikoodit moduulikonfiguraatiosta (ei sisällä `disabled`-kieliä) |
| `getLocale()`                                   | `() => string \| null`              | Nykyinen kieli: tila → eväste (tai hash-eväste hash-tilassa)                       |
| `getPreferredLocale()`                          | `() => string \| null`              | Kieli tilasta/evästeestä **validoituna** listaa `validLocales` vastaan tai `null`  |
| `getLocaleWithServerFallback(serverLocale?)`    | `(serverLocale?) => string \| null` | Tila → eväste → valinnainen palvelinkonteksti (käytetään `no_prefix`-alustuksessa) |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string`             | Käännösten lataukseen käytettävä kieli: hash-tilassa etusijalla on tila, muuten se luetaan reitistä |
| `resolveInitialLocale(options)`                 | `(options) => string`               | Ratkaisee kielen: tila → `serverLocale` → reitti. Synkronoi tilan tarvittaessa    |
| `setLocale(locale)`                             | `(locale: string \| null) => void`  | Aseta kieli ja synkronoi evästeet                                                  |
| `syncLocale(locale)`                            | `(locale: string \| null) => void`  | Synkronoi vain evästeet (ei tilapäivitystä)                                        |
| `isValidLocale(locale)`                         | `(locale) => boolean`               | Tarkista, onko merkkijono listalla `validLocales`                                  |

### `resolveInitialLocale`-asetukset

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

Päällinen liitännäinen käyttää tätä sisäisesti käynnistyksessä. Mukautetut liitännäiset voivat kutsua sitä toteuttaessaan vaihtoehtoisia tunnistusvirtoja.

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

Palauttaa kielen, jota käytetään käännösten lataamiseen ja viestien muotoiluun annetulle reittiobjektille.

## Ohjelmallinen kielen asetus

Suosi `useI18nLocale()`-koostajaa suoran `useState('i18n-locale')`-käytön sijaan:

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
`setLocale()` päivittää vain kielivalinnan (tila + eväste). Jos haluat myös ladata aktiivisen käännöskontekstin uudelleen asiakkaalla, käytä funktiota `$switchLocale()` kohteesta `useNuxtApp()` tai `useI18n()`. Tämä on tärkeää erityisesti `no_prefix`-strategiassa, jossa URL ei muutu. Katso [UKK — vaihda kieli muuttamatta URL:ää](/guides/faq#-switch-locale-without-changing-the-url).
</Tip>
