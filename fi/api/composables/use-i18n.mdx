# 🛠️ `useI18n`-koostetoiminto

`useI18n`-koostetoiminto moduulissa `Nuxt I18n Micro` tarjoaa pääsyn useimpiin ajonaikaisiin i18n-apureihin komponenteissa ja skripteissä. Metodit ovat saatavilla **sekä `$`-prefiksillä että ilman** (esimerkiksi `$t` ja `t`).

Jotkut injektiot — `$defineI18nRoute` ja `$clearCache` — ovat saatavilla vain `useNuxtApp()`:ssa. Katso [Metodit — `$defineI18nRoute`](/api/methods#definei18nroute) ja [`$clearCache`](/api/methods#clearcache).

## 📊 Mitä se palauttaa

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Jokainen ajonaikainen apuri tavallisena objektina.

Samat funktiot, joita plugin injektoi nimillä `$t`, `$tc` ja niin edelleen, saatavilla sekä
dollariprefiksatulla nimellä että paljaana aliaksena — joten `const \{ t \} = useI18n()` ja
`const \{ $t \} = useI18n()` toimivat molemmat.

**Palauttaa** — apurit, jotka on kuvattu [metodien viitteessä](/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

Jokainen apuri, jonka se palauttaa — `$t`, `$tc`, `$has`, `$switchLocale` ja muut — on listattu
allekirjoituksineen ja dokumentoitu kokonaisuudessaan kohdassa [Metodien viite](/api/methods).

## Vain `useNuxtApp()`-API:t

Nämä **eivät** palaudu `useI18n()`-kutsusta. Tuo ne `useNuxtApp()`-metodista:

| Metodi                     | Tarkoitus                                                                       |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Sivukohtaiset kielireitit, rajoitukset ja inline-käännökset `script setup`-lohkossa |
| `$clearCache()`            | Tyhjentää muistissa olevan käännösvälimuistin ja ladatut chunkit                |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Katso [Metodit](/api/methods) täydellisiä allekirjoituksia ja esimerkkejä varten.

## 🛠️ Esimerkkikäyttö

### Peruskielen hakeminen

Hae sovelluksen nykyinen kieli.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Käännös parametreillä

Käännä merkkijono dynaamisilla parametreilla, fallback-oletusarvolla.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Kielen vaihtaminen

Vaihda sovellus toiselle kielelle.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Paikallistetun reitin generointi

Generoi reitti, joka on paikallistettu nykyiselle tai määritetylle kielelle.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
