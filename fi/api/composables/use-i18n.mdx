# 🛠️ `useI18n`-koostaja

`Nuxt I18n Micro`n `useI18n`-koostaja tarjoaa pääsyn useimpiin ajonaikaisiin i18n-apureihin komponenteissa ja skripteissä. Metodit ovat käytettävissä **sekä `$`-etuliitteellä että ilman** (esimerkiksi `$t` ja `t`).

Osa injektioista — `$defineI18nRoute` ja `$clearCache` — on käytettävissä vain funktiolla `useNuxtApp()`. Katso [Metodit — `$defineI18nRoute`](/api/methods#definei18nroute) ja [`$clearCache`](/api/methods#clearcache).

## 📊 Mitä se palauttaa

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Kaikki ajonaikaiset apurit tavallisena objektina.

Samat funktiot, jotka liitännäinen injektoi nimillä `$t`, `$tc` ja niin edelleen, ovat käytettävissä sekä dollari-etuliitteellä että pelkkänä aliaksena. Näin sekä `const \{ t \} = useI18n()` että `const \{ $t \} = useI18n()` toimivat.

**Palauttaa** — apurit, jotka on kuvattu [metodien viitteessä](/api/methods).

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

Kaikki sen palauttamat apurit — `$t`, `$tc`, `$has`, `$switchLocale` ja muut — on lueteltu allekirjoituksineen ja dokumentoitu täydellisesti [metodien viitteessä](/api/methods).

## Vain `useNuxtApp()`-pohjaiset API:t

Näitä **ei** palauteta funktiolla `useI18n()`. Tuo ne kohteesta `useNuxtApp()`:

| Metodi                     | Tarkoitus                                                                         |
| -------------------------- | -------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Sivukohtaiset kielireitit, rajoitukset ja sisäiset käännökset `script setup`issa |
| `$clearCache()`            | Tyhjentää muistinsisäisen käännösvälimuistin ja ladatut palat                    |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Katso [metodit](/api/methods) täydellisiä allekirjoituksia ja esimerkkejä varten.

## 🛠️ Käyttöesimerkkejä

### Perustason kielen haku

Hae sovelluksen nykyinen kieli.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Käännös parametreilla

Käännä merkkijono dynaamisilla parametreilla ja varmistuksena olevalla oletusarvolla.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Kielen vaihto

Vaihda sovelluksen kieli.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Lokalisoidun reitin luonti

Luo reitti, joka on lokalisoitu nykyiselle tai määrätylle kielelle.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
