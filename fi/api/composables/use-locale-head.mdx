# 🌍 `useLocaleHead`-koostaja

`useLocaleHead`-koostaja on `Nuxt I18n Micro`n apuväline, joka auttaa hallitsemaan SEO-attribuutteja ja HTML-metatunnisteita lokalisoiduilla reiteillä. Se luo dynaamisesti HTML-dokumentin `lang`- ja `dir`-attribuutit sekä `meta`- ja `link`-tagit, jotka parantavat lokalisoidun sisällön hakukoneoptimointia.

## ⚙️ Asetukset

```ts
useLocaleHead(options: UseLocaleHeadOptions): { metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }, MetaObject | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

Nykyisen reitin SEO-head-tagit: `hreflang`-vaihtoehdot kaikille kielille sekä `x-default`, kanoninen linkki, `og:locale` sekä `lang`/`dir` `<html>`-elementissä.

Tätä tarvitaan vain, kun `meta` on pois päältä tai oletusarvoja pitää säätää. Kun `meta: true`, moduuli rekisteröi samat tagit itse.

| Parametri | Tyyppi | Kuvaus |
| --- | --- | --- |
| `options` | `UseLocaleHeadOptions` |  |

**Palauttaa** — ref-objektin, joka pitää sisällään head-objektin ja on valmis välitettäväksi funktiolle `useHead`.

```ts
const head = useLocaleHead({ addSeoAttributes: true })
useHead(head)
```

## 🛠️ Palautusarvot

`useLocaleHead`-koostaja palauttaa reaktiivisen objektin ja päivitysfunktion, jota tulee kutsua lähdedatan muuttuessa. Molemmat rakenteet näkyvät yllä olevassa allekirjoituksessa, joka on luotu lähdekoodista.

### `metaObject`

Reaktiivinen head-hyötykuorma (html-attribuutit, meta, link), joka sopii funktioon `useHead(metaObject)`.

- **Esimerkki**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

Laskee objektin `metaObject` uudelleen nykyisen reitin, kielen ja konfiguraation perusteella. Kutsu sitä, kun syötteet muuttuvat, esimerkiksi reitin vaihtuessa.

- **Esimerkki**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### `link`- ja `meta`-taulukoiden käyttö

Taulukot `link` ja `meta` ovat saatavilla polussa `metaObject.value`:

- **Esimerkki**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ Käyttöesimerkkejä

### Peruskäyttö

Luo kielikohtaiset head-attribuutit oletusasetuksilla.

```js
const head = useLocaleHead()
```

### Mukauta tunnisteattribuutti

Käytä mukautettua tunnisteattribuuttia luoduille tageille.

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### Poista SEO-attribuutit käytöstä

Luo head-attribuutit lisäämättä SEO-metatunnisteita ja -linkkejä.

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### Määritä perus-URL

Aseta mukautettu perus-URL kanonisille ja vaihtoehtoisille URL-osoitteille.

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 Lisäominaisuudet

### SEO-meta ja -linkit

Kun `addSeoAttributes` on käytössä, koostaja luo automaattisesti seuraavat tagit:

- `og:locale` nykyiselle kielelle (`language_TERRITORY`, alaviiva). Johdettu arvosta `locale.og` tai muunnettu arvosta `locale.iso` mahdollisuuksien mukaan.
- `og:url` sivun kanoniselle URL-osoitteelle.
- `og:locale:alternate` vaihtoehtoisille kieliversioille.
- `rel="canonical"`- ja `rel="alternate"`-linkit SEO-optimointia varten.
- `hreflang="x-default"`-linkki, joka osoittaa oletuskielen URL-osoitteeseen. Tämä kertoo hakukoneille, minkä URL:n näyttää käyttäjille, joiden kieli ei vastaa mitään määriteltyä kieltä.

### Dynaaminen kieli ja suunta

Koostaja määrittää dynaamisesti `lang`- ja `dir`-attribuutit nykyisen reitin kielen perusteella. Näin HTML-dokumenttisi on oikein määritelty kansainvälisille käyttäjille.

### Lokalisoitujen reittien käsittely

Jos reittisi on etuliitteitetty kielikoodilla (esim. `/en/about`), koostaja mukauttaa älykkäästi täyden polun URL-osoitteiden luontia varten. Näin SEO-attribuutit ovat tarkkoja ja olennaisia.

Tämä koostaja yksinkertaistaa Nuxt-sovelluksesi optimointia kansainväliselle yleisölle. Se varmistaa, että sivustosi on hyvin valmistautunut globaaleihin hakukoneisiin ja käyttäjiin.

## 🛠️ Käyttöesimerkki

Seuraava esimerkki näyttää, miten `useLocaleHead`-koostajaa käytetään Vue-komponentissa oletusasetuksilla:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### Koodin selitys

- **`useLocaleHead`-koostaja**: tätä koostajaa kutsutaan `<script setup>` -osiossa, ja se palauttaa objektin, joka sisältää arvot `htmlAttrs`, `meta` ja `link`.

- **`<html>`-tagi**: HTML-dokumentin `lang`- ja `dir`-attribuutit määräytyvät dynaamisesti nykyisen kielen perusteella ja lisätään `<html>`-tagiin.

- **`<head>`-osio**:
  - **Meta-tagit**: SEO-metatunnisteet luodaan, mukaan lukien `og:locale`, `og:url` sekä `rel="canonical"`- ja `rel="alternate"`-tagit, jotka määrittelevät sivun vaihtoehtoiset kieliversiot.
  - **Link-tagit**: kanoniset linkit, vaihtoehtoisiin kieliversioihin osoittavat linkit sekä `hreflang="x-default"`-linkki (joka osoittaa oletuskielen URL-osoitteeseen) sisällytetään.

- **`<body>`-osio**: sivun pääsisältö näytetään täällä. Tässä esimerkissä käytetään yksinkertaista otsikkoa ja kappaletta.

### 📝 Huomioita

1. **Attribuutit**: käytetyt attribuutit (`lang`, `dir`, `rel`, `href`, `hreflang`, `property`, `content`) poimitaan objektista, jonka `useLocaleHead` palauttaa.

2. **SEO-tagien luonti**: jos `addSeoAttributes` on `true`, koostaja luo automaattisesti SEO-tagit nykyiselle kielelle.

3. **Perus-URL**: voit asettaa mukautetun perus-URL:n `baseUrl`-asetuksella. Näin kanoniset ja vaihtoehtoiset linkit luodaan oikein.

Tämä esimerkki osoittaa, miten helppoa `useLocaleHead`-koostajan käyttö on sovelluksesi komponenteissa. Se varmistaa oikeat SEO-attribuutit ja parantaa lokalisoitujen sivujen indeksointia hakukoneissa.

## 🧩 Mukautus ja elinkaari

- `useLocaleHead` ei tilaa muutoksia itse. Se palauttaa arvot `metaObject` ja `updateMeta`.
- Kutsu funktiota `updateMeta()`, kun syötteet muuttuvat (yleensä reitin vaihtuessa), esimerkiksi liitännäisestä:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## Milloin käyttää `useI18nHead`-koostajaa sen sijaan

Kun `meta: true` (oletus), suosi koostajaa [`useI18nHead`](/api/composables/use-i18n-head) **sivukohtaisiin** ohituksiin (mukautettu hreflang, ylimääräinen `og:title`, osittainen poistaminen käytöstä). Käytä koostajaa `useLocaleHead` suoraan vain, kun `meta: false` tai hallitset `useHead`-funktiota itse.
