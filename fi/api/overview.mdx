Tämä osio luettelee Nuxt-moduulin jokaisen asetuksen, apufunktion, koukun, composablen ja komponentin sekä jokaisen `@i18n-micro/*`-paketin viedyn API:n. Käytä sitä etsiäksesi allekirjoituksen tai oletusarvon; [opas](/fi/guide/getting-started) selittää, miten niitä käytetään. Useimmat tämän osion taulukot generoidaan lähdekoodista, joten ne vastaavat koodia.

## Nuxt-moduuli {#nuxt-module}

| Sivu | Kattaa |
| --- | --- |
| [Moduulin asetukset](/fi/api/module-options) | Jokainen `nuxt.config`-tiedoston `i18n`-avain tyyppeineen ja oletusarvoineen |
| [Apufunktiot](/fi/api/methods) | `$t`, `$tc`, `$tn`, `$td`, `$localePath`, `$switchLocale`, `$defineI18nRoute` ja muut |
| [Koukut](/fi/api/events) | Ajonaikainen `i18n:register`-koukku |

## Composablet {#composables}

| Composable | Käyttötarkoitus |
| --- | --- |
| [`useI18n`](/fi/composables/useI18n) | Apufunktiot `<script setup>`-lohkossa |
| [`useI18nLocale`](/fi/composables/useI18nLocale) | Lokaalin tila ja eväste mukautetussa tunnistuslisäosassa |
| [`useI18nHead`](/fi/composables/useI18nHead) | Generoitujen SEO-tagien sivukohtaiset ohitukset |
| [`useLocaleHead`](/fi/composables/useLocaleHead) | SEO-tagit objektina omaa `useHead`-kutsuasi varten |

## Komponentit {#components}

| Komponentti | Renderöi |
| --- | --- |
| [`<i18n-t>`](/fi/components/i18n-t) | Yhden käännöksen monikolla, muotoilulla ja slot-interpoloinnilla |
| [`<i18n-link>`](/fi/components/i18n-link) | `NuxtLink`-linkin lokalisoituun reittiin |
| [`<i18n-switcher>`](/fi/components/i18n-switcher) | Lokaalien pudotusvalikon |
| [`<i18n-group>`](/fi/components/i18n-group) | Lohkon, jolla on yhteinen avaimen etuliite |

## Palvelin {#server}

Nitro-käsittelijät käyttävät `useTranslationServerMiddleware`- ja `useLocaleServerMiddleware`-funktioita, eivät asiakaspuolen apufunktioita. Katso [Palvelinreitit](/fi/guide/server-side-translations).

## Paketit {#packages}

[Pakettien API:t](/fi/api/packages/overview) luettelee jokaisen `@i18n-micro/*`-paketin viennit, kukin omalla generoidulla sivullaan.
