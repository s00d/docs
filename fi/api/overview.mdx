# API-viite

## Ajonaikainen API

- [Metodit](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, kielen vaihto, reititysapurit
- [Tapahtumat](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Käännökset ja välimuisti](/api/cache) — `TranslationStorage`, hyötykuorman lataus, `$clearCache`

## Palvelinvälimuisti

Palvelinkäsittelijät käyttävät omaa välimuistiaan (eivät asiakaspuolen `$t`-apureita):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — käännä API-reiteillä ja palvelinkäsittelijöissä
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — lue tunnistettu kieli ja metatiedot

Katso koko [palvelinpuolen käännösopas](/guides/server-side-translations) asennukseen, kielentunnistuksen prioriteettiin ja esimerkkeihin.
