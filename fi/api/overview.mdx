# API-viite

## Ajonaikainen API

- [Metodit](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, kielen vaihtaminen, reititysapurit
- [Tapahtumat](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Käännökset ja välimuisti](/api/cache) — `TranslationStorage`, payloadien lataus, `$clearCache`

## Palvelinmiddleware

Palvelinkäsittelijät käyttävät omaa middlewarea (eivät asiakaspuolen `$t`-apureita):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — käännä API-reiteissä ja palvelinkäsittelijöissä
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — lue havaittu kieli ja metadata

Katso täydellinen [Palvelinpuolen käännökset -opas](/guides/server-side-translations) asennusta, kielen tunnistuksen prioriteettia ja esimerkkejä varten.
