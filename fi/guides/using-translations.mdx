# Käännösten käyttö komponenteissa

Kun moduuli on asennettu ja määritetty, voit näyttää käännöksiä kutsumalla `$t('your_key')` Vue-templaateissa ja skripteissä.

## 1. Juuritason ja sivukohtaiset käännöstiedostot

1. **Juuritason** käännökset sijaitsevat suoraan `/locales`-kansiossa (esim. `/locales/en.json`, `/locales/fr.json`). Käännösaikana ne yhdistetään automaattisesti jokaiseen sivukohtaiseen tiedostoon, jotta ne ovat käytettävissä kaikilla sivuilla.
2. **Sivukohtaiset** käännökset sijaitsevat `/locales/pages/...`-hakemiston alla, vastaten Nuxt-sivujesi kansiorakennetta:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. Templaattikäyttö `$t`-metodilla

`.vue`-tiedostoissa voit käyttää `$t`-metodia suoraan templaatissa:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
`$t` voi palauttaa **objekteja**, jos avain osoittaa sisäkkäiseen JSON-solmuun (esim. `$t('header')` → `\{ title: "Hi" \}`). Templaateissa tämä renderöityy muodossa `[object Object]`. Käytä `$ts`-metodia, kun tarvitset varmasti merkkijonon, tai anna tarkempi avain kuten `$t('header.title')`. Katso lisätietoja kohdasta [API-viite — $t vs $ts](/api/methods#t).
</Tip>

## 3. Nykyisen kielen vaihtaminen

Vaihtaaksesi kieliä sovelluksessasi voit hakea `$locale`-arvon `useI18n()`-metodista ja asettaa sille uuden koodin:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. Sisäkkäiset avaimet ja paikkamerkit

- **Sisäkkäiset avaimet** käyttävät pistemerkintää, esim. `nested.key.deeper`.
- **Paikkamerkit** mahdollistavat dynaamisten arvojen lisäämisen:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. Vinkkejä ja parhaita käytäntöjä

- **Ristiriitaiset avaimet**: Jos sivukohtainen tiedosto sisältää saman avaimen kuin juuritason tiedosto, sivukohtainen versio on etusijalla (juurikäännökset yhdistetään perustaksi käännösaikana).
- **Sivutiedostojen poistaminen käytöstä**: Jos et halua käyttää sivukohtaisia käännöksiä, voit asettaa `disablePageLocales: true` Nuxt-konfiguraatiossasi. Tällöin käytetään vain `/locales/*.json`-tiedostoja.
- **Ei suoria tuonteja**: Sinun ei tarvitse tehdä `import \{ useI18n \} from 'nuxt-i18n-micro'`; moduulin automaattinen injektiotoiminto hoitaa sen puolestasi.

Siinä kaikki! Näillä vaiheilla voit nopeasti **alkaa hakea käännöksiä** juuritason tai sivukohtaisista JSON-tiedostoista ja **näyttää ne** Nuxt-sovelluksessasi `$t`-metodilla.

## Lisäresurssit

Tutustuaksesi lisäominaisuuksiin, muista tarkistaa:

1. **`<i18n-t>`-komponentti**  
   `<i18n-t>`-komponentti on tehokas vaihtoehto `$t`-metodille, erityisen hyödyllinen tilanteissa, joissa on sisäkkäisiä elementtejä, edistynyt paikkamerkkien käyttö ja monimutkaisempia käännösrakenteita.

- **Dokumentaatio**: [i18n-t](/api/components/i18n-t)

2. **`useI18n`-koostetoiminto**  
   `useI18n`-koostetoiminto tarjoaa kattavan joukon funktioita ja reaktiivisia ominaisuuksia käännösten hallintaan, kielen vaihtamiseen, muotoiluun ja moneen muuhun.

- **Dokumentaatio**: [useI18n](/api/composables/use-i18n)
