# Käännösten käyttö komponenteissa

Kun moduuli on asennettu ja määritetty, voit näyttää käännöksiä kutsumalla `$t('your_key')` Vue-malleissasi ja -skripteissäsi.

## 1. Juuritason ja sivukohtaiset käännöstiedostot

1. **Juuritason** käännökset sijaitsevat suoraan `/locales`-kansiossa (esim. `/locales/en.json`, `/locales/fr.json`). Käännösvaiheessa ne yhdistetään automaattisesti jokaiseen sivukohtaiseen tiedostoon, jolloin ne ovat käytettävissä kaikilla sivuilla.
2. **Sivukohtaiset** käännökset sijaitsevat polussa `/locales/pages/...` ja vastaavat Nuxt-sivujesi kansiorakennetta:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. Mallien käyttö funktiolla `$t`

`.vue`-tiedostoissasi voit käyttää `$t`-funktiota suoraan mallissa:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
`$t` voi palauttaa **objekteja**, jos avain osoittaa sisäkkäiseen JSON-solmuun (esim. `$t('header')` → `\{ title: "Hi" \}`). Malleissa tämä renderöityy muotoon `[object Object]`. Käytä `$ts`, kun tarvitset varmasti merkkijonon, tai anna tarkempi avain kuten `$t('header.title')`. Katso [API-viite — $t vs $ts](/api/methods#t) yksityiskohdat.
</Tip>

## 3. Nykyisen kielen vaihto

Vaihtaaksesi kieliä sovelluksessasi voit hakea `$locale`-arvon koostajasta `useI18n()` ja määrittää sille uuden koodin:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. Sisäkkäiset avaimet ja paikkamerkit

- **Sisäkkäiset avaimet** käyttävät pistemäistä merkintää, esim. `nested.key.deeper`.
- **Paikkamerkit** mahdollistavat dynaamisten arvojen lisäämisen:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. Vinkkejä ja parhaita käytäntöjä

- **Ristiriitaiset avaimet**: jos sivukohtainen tiedosto sisältää saman avaimen kuin juuritason tiedosto, sivukohtainen versio on etusijalla (juuritason käännökset yhdistetään perustaksi käännösvaiheessa).
- **Sivutiedostojen poistaminen käytöstä**: jos et halua käyttää sivukohtaisia käännöksiä, aseta `disablePageLocales: true` Nuxt-konfiguraatiossasi. Tällöin käytössä ovat vain `/locales/*.json`-tiedostot.
- **Ei suoria tuonteja**: sinun ei tarvitse tehdä `import \{ useI18n \} from 'nuxt-i18n-micro'`. Moduulin automaattinen injektointi hoitaa sen puolestasi.

Siinä kaikki! Näillä vaiheilla voit nopeasti **alkaa hakea käännöksiä** juuritason tai sivukohtaisista JSON-tiedostoista ja **näyttää ne** Nuxt-sovelluksessasi funktiolla `$t`.

## Lisäresurssit

Tutustuaksesi kehittyneempiin ominaisuuksiin, tarkista seuraavat:

1. **`<i18n-t>`-komponentti**  
   `<i18n-t`-komponentti on tehokas vaihtoehto funktiolle `$t`. Se on erityisen hyödyllinen tilanteissa, joissa on sisäkkäisiä elementtejä, edistynyttä paikkamerkkien käyttöä ja monimutkaisempia käännösrakenteita.

- **Dokumentaatio**: [i18n-t](/api/components/i18n-t)

2. **`useI18n`-koostaja**  
   `useI18n`-koostaja tarjoaa täydellisen joukon funktioita ja reaktiivisia ominaisuuksia käännösten hallintaan, kielen vaihdon käsittelyyn, muotoiluun ja muuhun.

- **Dokumentaatio**: [useI18n](/api/composables/use-i18n)
