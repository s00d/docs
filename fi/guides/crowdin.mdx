# 🌐 Crowdin-integraatio-opas

## 📖 Johdanto

Crowdinin integrointi projektiisi virtaviivaistaa paikallistamis- ja käännösprosessia tehden useiden kielten ja alustojen käännösten hallinnasta helpompaa. Tämä opas tarjoaa vaiheittaisen läpikäynnin Crowdinin määrittämiseen projektissasi, mukaan lukien konfiguraatio, lähdetiedostojen lataaminen ja käännösten lataaminen.

## 🔧 Asennus ja käyttöönotto

Aloittaaksesi Crowdinin käytön sinun täytyy asentaa Crowdin CLI globaalisti koneellesi ja alustaa se projektikansiossasi.

### 📦 Crowdin CLI:n asentaminen

Asenna ensin Crowdin CLI globaalisti npm:llä:

```bash
npm install -g @crowdin/cli
```

### 🛠 Crowdinin alustaminen projektissasi

Alusta Crowdin projektissasi ajamalla:

```bash
crowdin init
```

Tämä komento ohjaa sinut asennusprosessin läpi, mukaan lukien projektin ID:n, API-tokenin ja muiden konfiguraatiotietojen asettamisen.

## 🗂️ Konfiguraatio-opas

### 📄 Crowdinin konfiguraatiotiedosto (`crowdin.yml`)

Crowdinin konfiguraatiotiedosto (`crowdin.yml`) määrittää, miten lähdetiedostosi kartoitetaan ja mihin käännökset sijoitetaan. Alla on esimerkkikonfiguraatio:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Keskeiset konfiguraatioparametrit

- **`project_id`**: Crowdin-projektisi ID. Tämä tunnistaa projektin Crowdinissa, jossa käännöksiä hallinnoidaan.
- **`api_token`**: Autentikointiin käytettävä API-token. Varmista, että tokenilla on oikeat oikeudet käännösten lataamiseen ja lähettämiseen.
- **`base_path`**: Määrittää lähdetiedostojen perushakemiston. Tässä esimerkissä käännökset tallennetaan hakemistoon `./locales`.
- **`base_url`**: Crowdin API:n perus-URL.
- **`preserve_hierarchy`**: Kun arvo on `true`, Crowdin säilyttää lähdetiedostojesi kansiorakenteen projektissa.

### 📂 Tiedostokonfiguraatio

`files`-osio kartoittaa lähdetiedostosi polkuihin, joihin käännökset tallennetaan. Esimerkiksi:

- **Lähdepolku**: Määrittää alkuperäisten käännöstiedostojen sijainnin.
- **Käännöspolku**: Määrittää, mihin käännetyt tiedostot tallennetaan Crowdinissa. Paikkamerkkejä kuten `%two_letters_code%` käytetään kielikoodin dynaamiseen asettamiseen tiedostopoluissa.

## ⬆️ Lähdetiedostojen lataaminen Crowdiniin

Kun Crowdin-konfiguraatiosi on määritetty, voit ladata lähdetiedostosi seuraavalla komennolla:

```bash
crowdin upload sources
```

Tämä komento lataa kaikki konfiguraatiossa määritetyt lähdetiedostot Crowdiniin, jolloin ne ovat saatavilla käännöstä varten.

## ⬇️ Käännösten lataaminen Crowdinista

Kun käännökset on valmiit tai päivitetty Crowdinissa, voit ladata ne projektiisi käyttämällä:

```bash
crowdin download
```

Tämä komento hakee uusimmat käännökset Crowdinista ja tallentaa ne konfiguraatiotiedostossa määritettyihin polkuihin.

## ⚙️ Parhaat käytännöt

### 🔑 Yhdenmukainen avainten nimeäminen

Varmista, että käännösavaimet ovat yhdenmukaisia kaikissa tiedostoissa sekaannusten ja päällekkäisyyksien välttämiseksi.

### 🧹 Säännöllinen ylläpito

Käy säännöllisesti läpi ja siivoa käyttämättömät käännösavaimet pitääksesi tiedostot järjestyksessä ja hallittavina.

### 🛠 Automatisoi lataukset ja lähetykset

Integroi Crowdin CLI -komennot CI/CD-putkellesi automatisoidaksesi lähdetiedostojen lataamisen ja käännösten latauksen, jotta käännöksesi ovat aina ajan tasalla.

Tätä opasta seuraamalla pystyt integroimaan Crowdinin saumattomasti projektiisi ja varmistamaan tehokkaan ja järjestäytyneen tavan hallita kansainvälistämispyrkimyksiäsi.
