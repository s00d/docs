# 🌐 Crowdin-integraatio-opas

## 📖 Johdanto

Crowdinin integrointi projektiisi sujuvoittaa lokalisointi- ja käännösprosessia. Se helpottaa käännösten hallintaa usealla kielellä ja alustalla. Tämä opas tarjoaa vaiheittaisen läpikäynnin Crowdinin asentamiseen projektisi kanssa, mukaan lukien konfiguraatio, lähdetiedostojen lataaminen palveluun ja käännösten lataaminen sieltä.

## 🔧 Asennus ja käyttöönotto

Aloittaaksesi Crowdinin käytön asenna Crowdin-CLI globaalisti koneellesi ja alusta se projektihakemistossasi.

### 📦 Crowdin-CLI:n asennus

Asenna ensin Crowdin-CLI globaalisti npm:llä:

```bash
npm install -g @crowdin/cli
```

### 🛠 Crowdinin alustaminen projektissa

Alusta Crowdin projektissasi ajamalla:

```bash
crowdin init
```

Tämä komento opastaa asennusprosessissa, mukaan lukien projektisi tunnuksen, API-tokenin ja muiden konfiguraatiotietojen asettamisessa.

## 🗂️ Konfiguraatio-opas

### 📄 Crowdin-konfiguraatiotiedosto (`crowdin.yml`)

Crowdin-konfiguraatiotiedosto (`crowdin.yml`) määrittää, miten lähdetiedostosi kartoitetaan ja mihin käännökset sijoitetaan. Alla on esimerkkikonfiguraatio:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Keskeiset konfiguraatioparametrit

- **`project_id`**: Crowdin-projektisi tunnus. Tämä tunnistaa projektin Crowdinissä, jossa käännöksiä hallitaan.
- **`api_token`**: API-token, jota käytetään autentikointiin. Varmista, että tokenilla on oikeat oikeudet käännösten lataamiseen molempiin suuntiin.
- **`base_path`**: määrittää lähdetiedostojen perushakemiston. Tässä esimerkissä käännökset tallennetaan hakemistoon `./locales`.
- **`base_url`**: Crowdin-API:n perus-URL.
- **`preserve_hierarchy`**: kun asetettu arvoon `true`, Crowdin säilyttää lähdetiedostojesi kansiorakenteen projektissa.

### 📂 Tiedostojen konfiguraatio

`files`-osio kartoittaa lähdetiedostosi polkuihin, joihin käännökset tallennetaan. Esimerkki:

- **Lähdepolku**: määrittää alkuperäisten käännöstiedostojen sijainnin.
- **Käännöspolku**: määrittää, mihin käännetyt tiedostot tallennetaan Crowdinissä. Paikkamerkit kuten `%two_letters_code%` asettavat dynaamisesti kielikoodin tiedostopolkuihin.

## ⬆️ Lähdetiedostojen lataaminen Crowdiniin

Kun Crowdin-konfiguraatio on asetettu, voit ladata lähdetiedostosi seuraavalla komennolla:

```bash
crowdin upload sources
```

Tämä komento lataa kaikki konfiguraatiossasi määritetyt lähdetiedostot Crowdiniin ja tekee ne saataville käännettäväksi.

## ⬇️ Käännösten lataaminen Crowdinistä

Kun käännökset on valmistuneet tai päivitetty Crowdinissä, voit ladata ne projektiisi:

```bash
crowdin download
```

Tämä komento hakee viimeisimmät käännökset Crowdinistä ja tallentaa ne konfiguraatiotiedostosi määrittelemiin polkuihin.

## ⚙️ Parhaat käytännöt

### 🔑 Johdonmukainen avaimien nimeäminen

Varmista, että käännösavaimet ovat johdonmukaisia kaikissa tiedostoissa sekaannusten ja päällekkäisyyksien välttämiseksi.

### 🧹 Säännöllinen ylläpito

Käy säännöllisesti läpi ja siivoa käyttämättömät käännösavaimet pitääksesi tiedostosi järjestyksessä ja hallittavissa.

### 🛠 Automatisoi lataukset molempiin suuntiin

Integroi Crowdin-CLI-komennot CI/CD-putkeesi automatisoidaksesi lähdetiedostojen lataamisen ja käännösten haun. Näin käännöksesi ovat aina ajan tasalla.

Tätä opasta seuraamalla voit integroida Crowdinin projektiisi saumattomasti ja varmistaa tehokkaan ja järjestäytyneen lähestymistavan kansainvälistämispyrkimyksiisi.
