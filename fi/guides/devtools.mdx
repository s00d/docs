# 🛠️ DevTools moduulissa `nuxt-i18n-micro`

## Vue DevTools (selaimen laajennus)

Kehityksessä moduuli voi rekisteröidä **Vue DevTools** -mukautetun inspektorin ja aikajanan paketin `@vue/devtools-api` kautta. Tämä on erillinen alla olevasta Nuxt DevTools -välilehdestä.

| Työkalu | Parhaimmillaan |
|------|----------|
| **Vue DevTools** | Elävä kieli, muistinsisäinen käännösvälimuisti, `$t`-aikajana (`debug: true`), puuttuvat avaimet -tapahtumat |
| **Nuxt DevTools -välilehti** | JSON-tiedostojen muokkaus levylle, konfiguraation yleiskuva, tuonti/vienti |

Vue-devtools-liitännäinen rekisteröidään vain komennon `nuxt dev` aikana (ei tuotantokäännöksissä). Pää-liitännäisen vain kehityksessä käytettävä sillan tila karsitaan `import.meta.dev`-kuolleen koodin eliminoinnilla.

Poista selainintegraatio käytöstä säilyttäen Nuxt-välilehden:

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

Yksityiskohtaiset `$t`-aikajanan tapahtumat vaativat asetuksen `debug: true`.

## 📖 Mikä Nuxt DevTools on?

DevTools on tehokas kehittäjäapulainen, joka on saumattomasti integroitu `nuxt-i18n-micro`-moduuliin. Se tarjoaa intuitiivisen käyttöliittymän lokalisointi- ja käännöstehtävien hallintaan, mikä nopeuttaa ja tehostaa työnkulkuasi. Kehittäjille, jotka arvostavat mukavuutta, Nuxt DevTools kaventaa kuilua koodauksen ja ajonaikaisen hallinnan välillä.

## 🌟 DevToolsin keskeiset ominaisuudet moduulissa `nuxt-i18n-micro`

### 1. **Kielten hallinta**

Selaa, valitse ja hallitse kieliä sovelluksessasi vaivattomasti. Työskenteletpä sitten yhdellä tai useammalla kielellä, DevTools tarjoaa keskitetyn keskuksen kaikkien lokalisointiasetusten hoitamiseen.

### 2. **Käännösten muokkaus**

Muokkaa käännöstiedostoja suoraan integroidun JSON-editorin kautta. Tämä poistaa tarpeen ulkoisille työkaluille ja mahdollistaa reaaliaikaiset päivitykset ja muutokset keskeyttämättä työnkulkuasi.

### 3. **Tiedostojen tuonti ja vienti**

Yksinkertaista käännöstiedostojen hallintaa:

- **Vienti**: tallenna käännökset JSON-tiedostona varmuuskopioita tai ulkoista käyttöä varten.
- **Tuonti**: lataa päivitetyt käännöstiedostot projektiin pitääksesi sisällön ajan tasalla.

### 4. **Reaaliaikaiset esikatselut**

Näe muutokset välittömästi kehitysympäristössä. Tämä ominaisuus varmistaa, että käännökset ja konfiguraatiot ovat tarkkoja ennen tuotantoon vientiä.

### 5. **Saumaton Nuxt-integraatio**

DevTools toimii natiivisti `nuxt-i18n-micro`n kanssa ja laajentaa sen ominaisuuksia ilman lisäasennuksia. Se mukautuu lokalisointitarpeisiisi säilyttäen samalla Nuxtin modulaarisen ja joustavan rakenteen.

## 🛠️ Miksi käyttää DevToolsia?

Nuxt DevTools on välttämätön lisä projekteissa, jotka vaativat lokalisointia. Se auttaa kehittäjiä seuraavilla tavoilla:

- **Aikaa säästäen**: automatisoi toistuvia tehtäviä, kuten tiedostonhallintaa ja muodon tarkistusta.
- **Virheitä vähentäen**: tarjoaa turvallisen ja intuitiivisen ympäristön käännösten muokkaamiseen.
- **Yhteistyötä parantaen**: mahdollistaa muiden kuin kehittäjien hallita käännöksiä helposti.
- **Työnkulkuja sujuvoittaen**: yhdistää useat lokalisointitehtävät yhteen käyttöliittymään.

---

## 🚀 Ota lokalisointi hallintaasi

Nuxt DevTools integroituna `nuxt-i18n-micro`-moduuliin tekee monikielisten sovellusten hallinnasta suoraviivaista ja tehokasta. Hienosäädätpä käännöksiä tai lisäätpä uusia kieliä, DevTools tarjoaa työkalut, joita tarvitset viimeisteltyjen ja käyttäjäystävällisten kokemusten toimittamiseen.
