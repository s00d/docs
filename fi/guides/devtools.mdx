# 🛠️ DevTools moduulissa `nuxt-i18n-micro`

## Vue DevTools (selainlaajennus)

Kehitysvaiheessa moduuli voi rekisteröidä **Vue DevTools** -mukautetun tarkistajan ja aikajanan `@vue/devtools-api`:n kautta. Tämä on erillinen alla olevasta Nuxt DevTools -välilehdestä.

| Työkalu | Sopii parhaiten |
|------|----------|
| **Vue DevTools** | Live-kieli, muistissa oleva käännösvälimuisti, `$t`-aikajana (`debug: true`), puuttuvien avainten tapahtumat |
| **Nuxt DevTools -välilehti** | JSON-tiedostojen muokkaaminen levyllä, konfiguraation yleiskuva, tuonti/vienti |

vue-devtools-liitännäinen rekisteröidään vain komennon `nuxt dev` aikana (ei tuotantokäännöksissä). Vain kehitykselle tarkoitettu siltatila päälisäntäplugarissa karsitaan pois `import.meta.dev`:n dead-code-eliminaatiolla.

Ota selainintegraatio pois käytöstä säilyttäen Nuxt-välilehden:

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

Yksityiskohtaiset `$t`-aikajanan tapahtumat vaativat asetuksen `debug: true`.

## 📖 Mikä on Nuxt DevTools?

DevTools on tehokas kehitysavustaja, joka on saumattomasti integroitu `nuxt-i18n-micro` -moduuliin. Se tarjoaa intuitiivisen käyttöliittymän paikallistamis- ja käännöstehtävien hallintaan tehden työnkulustasi nopeamman ja tehokkaamman. Nuxt DevTools on suunniteltu kehittäjille, jotka arvostavat helppokäyttöisyyttä, ja se kaventaa kuilua koodauksen ja ajonaikaisen hallinnan välillä.

## 🌟 DevToolsin keskeiset ominaisuudet moduulissa `nuxt-i18n-micro`

### 1. **Kielenhallinta**

Selaa, valitse ja hallinnoi sovelluksesi kieliä vaivattomasti. Työskenteletpä yhdellä tai useammalla kielellä, DevTools tarjoaa keskitetyn keskuksen kaikkien paikallistamisasetusten hallintaan.

### 2. **Käännösten muokkaus**

Muokkaa käännöstiedostoja suoraan integroidun JSON-editorin kautta. Tämä poistaa ulkoisten työkalujen tarpeen ja mahdollistaa reaaliaikaiset päivitykset ja muutokset työnkulkua keskeyttämättä.

### 3. **Tiedostojen tuonti ja vienti**

Yksinkertaista käännöstiedostojen hallintaa:

- **Vienti**: Tallenna käännökset JSON-tiedostona varmuuskopioita tai ulkoista käyttöä varten.
- **Tuonti**: Lataa päivitetyt käännöstiedostot projektiin sisällön ajantasaisuuden varmistamiseksi.

### 4. **Reaaliaikaiset esikatselut**

Näe muutokset välittömästi kehitysympäristössä. Tämä ominaisuus varmistaa, että käännökset ja asetukset ovat oikein ennen julkaisua.

### 5. **Saumaton Nuxt-integraatio**

DevTools toimii natiivisti moduulin `nuxt-i18n-micro` kanssa parantaen sen ominaisuuksia ilman lisäasetuksia. Se mukautuu paikallistamistarpeisiisi säilyttäen Nuxtin modulaarisen ja joustavan rakenteen.

## 🛠️ Miksi käyttää DevToolsia?

Nuxt DevTools on välttämätön lisä projekteille, jotka vaativat paikallistamista. Se auttaa kehittäjiä:

- **Säästämällä aikaa**: Automatisoi toistuvia tehtäviä, kuten tiedostojen hallintaa ja muodon validointia.
- **Vähentämällä virheitä**: Tarjoaa turvallisen ja intuitiivisen ympäristön käännösten muokkaamiseen.
- **Parantamalla yhteistyötä**: Antaa muille kuin kehittäjille mahdollisuuden hallita käännöksiä helposti.
- **Virtaviivaistamalla työnkulkuja**: Yhdistää useita paikallistamistehtäviä yhteen käyttöliittymään.

---

## 🚀 Ota paikallistaminen hallintaan

Kun Nuxt DevTools on integroitu moduuliin `nuxt-i18n-micro`, monikielisten sovellusten hallinnasta tulee suoraviivaista ja tehokasta. Hienosäädätpä käännöksiä tai lisäätpä uusia kieliä, DevTools tarjoaa työkalut viimeisteltyjen ja käyttäjäystävällisten kokemusten toimittamiseen.
