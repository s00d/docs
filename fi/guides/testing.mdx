# 🧪 `Nuxt I18n Micro` -moduulin testaus

## 📖 Johdanto testaukseen

`Nuxt I18n Micro` -moduulin testaus on ratkaisevaa varmistamaan, että sovelluksesi paikallistamisominaisuudet toimivat odotetusti. Tämä dokumentaatio ohjaa sinut testausympäristön asennuksen, vitest-mock-konfiguraatioiden luomisen ja komponenttien testien kirjoittamisen läpi. Käytännön esimerkkiä varten voit tutustua [esimerkkiprojektiin GitHubissa](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/test-utils/example).

Katso [Reititysstrategioiden testaus](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/testing-strategies.md), miten tämä repositorio ajaa omat testisarjansa — `unit` / `integration` / `e2e` Vitest-projektit, strategiakohtaiset tiedostot (`test/strategies-*.test.ts`) ja regressiotestien generointi.

## 🛠️ Testausympäristön asennus

### 1. Asenna `@i18n-micro/test-utils`

Ensin sinun tulee asentaa `Nuxt I18n Micron` testausapuvälineet. Tämä paketti tarjoaa tarvittavat työkalut i18n-konfiguraatioiden mockaamiseen ja testaamiseen.

```bash
npm install @i18n-micro/test-utils --save-dev
```

### 2. Luo mock-konfiguraatiotiedosto

Seuraavaksi luo tiedosto mock-i18n-konfiguraation asettamiseen. Tätä tiedostoa käytetään i18n-funktioiden ja apuohjelmien mockaamiseen testien aikana.

```typescript
// tests/unit-setup.ts

import { mockNuxtImport } from '@nuxt/test-utils/runtime'
import { vi } from 'vitest'
import { i18nUtils } from '@i18n-micro/test-utils'

export function createFakeI18n() {
  return {
    $getLocale: vi.fn(i18nUtils.getLocale),
    $t: vi.fn(i18nUtils.t),
    $tc: vi.fn(i18nUtils.tc),
    $setLocale: vi.fn(i18nUtils.setLocale),
    $getLocaleName: vi.fn(i18nUtils.getLocaleName),
    $setLocaleName: vi.fn(i18nUtils.setLocaleName),
    $getLocales: vi.fn(i18nUtils.getLocales),
    $setLocales: vi.fn(i18nUtils.setLocales),
    $defaultLocale: vi.fn(i18nUtils.defaultLocale),
    $setDefaultLocale: vi.fn(i18nUtils.setDefaultLocale),
    $getRouteName: vi.fn(i18nUtils.getRouteName),
    $settRouteName: vi.fn(i18nUtils.settRouteName),
    $ts: vi.fn(i18nUtils.ts),
    $tn: vi.fn(i18nUtils.tn),
    $td: vi.fn(i18nUtils.td),
    $has: vi.fn(i18nUtils.has),
    $resolveTranslations: vi.fn(i18nUtils.resolveTranslations),
    $setTranslation: vi.fn(i18nUtils.setTranslation),
    $mergeTranslations: vi.fn(i18nUtils.mergeTranslations),
    $switchLocaleRoute: vi.fn(i18nUtils.switchLocaleRoute),
    $switchLocalePath: vi.fn(i18nUtils.switchLocalePath),
    $switchLocale: vi.fn(i18nUtils.switchLocale),
    $switchRoute: vi.fn(i18nUtils.switchRoute),
    $localeRoute: vi.fn(i18nUtils.localeRoute),
    $localePath: vi.fn(i18nUtils.localePath),
    $setI18nRouteParams: vi.fn(i18nUtils.setI18nRouteParams),
  }
}

mockNuxtImport<() => ReturnType<typeof createFakeI18n>>('useI18n', () => vi.fn(() => createFakeI18n()))

export const setTranslationsFromJson = i18nUtils.setTranslationsFromJson
```

### 3. Määritä Vitest

Määritä nyt Vitest käyttämään mock-konfiguraatiotiedostoa ja asentamaan testausympäristö.

```typescript
// vitest.config.ts

import { defineVitestConfig } from '@nuxt/test-utils/config'

export default defineVitestConfig({
  test: {
    watch: false,
    setupFiles: ['./tests/unit-setup.ts'],
    include: ['./**/*.spec.ts'],
  },
})
```

## 🧪 Testien kirjoittaminen

### Esimerkkikomponentti

Tässä esimerkki yksinkertaisesta komponentista, joka käyttää `useI18n`-koostetoimintoa viestien kääntämiseen.

```vue
<script setup lang="ts">
const { $t } = useI18n()

const props = defineProps({
  message: {
    type: String,
    default: null,
  },
})

// Test to see that $t works in script setup as well as the template
const message = props.message || $t('defaultMessage')
</script>

<template>
  <div>
    <p>Test from component: {{ $t('welcome') }}</p>
    <p data-testid="message">Test message from props: {{ message }}</p>
  </div>
</template>
```

### Testitiedosto

Kirjoitetaan nyt testi tälle komponentille.

```typescript
// tests/unit/example.spec.ts

import { describe, it, expect, beforeEach } from 'vitest'
import { mount } from '@vue/test-utils'
import ExampleComponent from '@/components/ExampleComponent.vue'
import fs from 'fs'
import path from 'path'
import { setTranslationsFromJson } from './unit-setup'

describe('ExampleComponent', () => {
  beforeEach(async () => {
    const fileContent = fs.readFileSync(path.join(__dirname, '../../locales/en-GB.json')).toString()
    await setTranslationsFromJson('en', JSON.parse(fileContent))
  })

  it('renders the welcome message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.text()).toContain('Test from component: Welcome')
  })

  it('renders the default message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Default Message')
  })

  it('renders the custom message correctly', () => {
    const wrapper = mount(ExampleComponent, {
      props: {
        message: 'Custom Message',
      },
    })
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Custom Message')
  })
})
```

## 📝 Parhaat käytännöt testaukseen

- **🔧 Mockaa i18n-funktiot:** Mockaa i18n-funktiot aina paketilla `@i18n-micro/test-utils` varmistaaksesi johdonmukaiset ja ennustettavat testitulokset.
- **⚙️ Käytä Vitestiä yksikkötesteihin:** Vitest on tehokas testauskehys Vue-sovelluksille. Käytä sitä komponenttiesi yksikkötestien kirjoittamiseen.
- **📚 Dokumentoi testisi:** Dokumentoi selkeästi kunkin testin tarkoitus ja odotetut tulokset. Tämä auttaa säilyttämään selkeyden ja tekee testien ymmärtämisestä helpompaa muille (tai tulevalle sinulle).

## 📊 i18n-apumetodit

Alla on taulukko, joka kuvaa kaikki paketin `@i18n-micro/test-utils` tarjoamat apumetodit.

| Metodi                                          | Kuvaus                                                                                                                                     |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `t(key, params, defaultValue)`                  | Kääntää avaimen valinnaisilla parametreillä ja oletusarvolla.                                                                              |
| `tc(key, params, defaultValue)`                 | Kääntää avaimen monikkomuototuen kanssa.                                                                                                   |
| `setTranslationsFromJson(locale, translations)` | Lataa käännökset JSON-objektista tietylle kielelle.                                                                                        |
| `getLocale()`                                   | Palauttaa nykyisen kielen.                                                                                                                 |
| `setLocale(val)`                                | Asettaa nykyisen kielen.                                                                                                                   |
| `getLocaleName()`                               | Palauttaa nykyisen kielen nimen.                                                                                                           |
| `setLocaleName(val)`                            | Asettaa nykyisen kielen nimen.                                                                                                             |
| `getLocales()`                                  | Palauttaa saatavilla olevien kielten listan.                                                                                               |
| `setLocales(val)`                               | Asettaa saatavilla olevien kielten listan.                                                                                                 |
| `defaultLocale()`                               | Palauttaa oletuskielen.                                                                                                                    |
| `setDefaultLocale(val)`                         | Asettaa oletuskielen.                                                                                                                      |
| `getRouteName()`                                | Palauttaa nykyisen reitin nimen.                                                                                                           |
| `settRouteName(val)`                            | Asettaa nykyisen reitin nimen.                                                                                                             |
| `ts(key, params, defaultValue)`                 | Kääntää avaimen ja palauttaa tuloksen merkkijonona.                                                                                        |
| `tn(value, options?)`                           | Muotoilee numeron inline-tyyppisillä `Intl.NumberFormatOptions`-asetuksilla. Nimetyt muodot tarvitsevat moduulin konfiguraation eivätkä ole saatavilla tässä itsenäisessä apurissa. |
| `td(value, options?)`                           | Muotoilee päivämäärän inline-tyyppisillä `Intl.DateTimeFormatOptions`-asetuksilla. Nimetyt muodot tarvitsevat moduulin konfiguraation eivätkä ole saatavilla tässä itsenäisessä apurissa. |
| `has(key)`                                      | Tarkistaa, onko käännösavain olemassa.                                                                                                     |
| `resolveTranslations()`                         | Palauttaa aktiivisen käännöspuun nykyiselle kielelle ja reitille.                                                                          |
| `setTranslation(key, value)`                    | Korvaa arvon avaimessa `key` aktiivisessa sanakirjassa (korvaus, ei yhdistäminen).                                                         |
| `mergeTranslations(newTranslations)`            | Yhdistää käännökset aktiiviseen kieleen ajonaikaisesti.                                                                                    |

Näitä vaiheita seuraamalla voit testata `Nuxt I18n Micro` -moduulin tehokkaasti ja varmistaa, että sovelluksesi paikallistamisominaisuudet toimivat odotetusti.
