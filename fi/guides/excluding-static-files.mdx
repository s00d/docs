# Staattisten tiedostojen jättäminen i18n-reitityksen ulkopuolelle

## Yleiskatsaus

Oletusarvoisesti nuxt-i18n-micro sulkee yleiset staattiset tiedostot automaattisesti pois i18n-reitityksen käsittelystä. Voit kuitenkin myös määrittää mukautettuja poissulkumallejä estääksesi tiettyjen polkujen käsittelyn i18n-järjestelmässä.

## Sisäänrakennetut poissulut

Moduuli sulkee automaattisesti pois seuraavat tiedostotyypit ja mallit:

- **Sivustokartat**: `/sitemap*.xml`, `/sitemap-en.xml` jne.
- **SEO-tiedostot**: `/robots.txt`, `/favicon.ico`
- **PWA-tiedostot**: `/manifest.json`, `/sw.js`, `/workbox-*.js`
- **Staattiset resurssit**: Tiedostot, joiden pääte on `.xml`, `.txt`, `.ico`, `.json`, `.js`, `.css`, `.png`, `.jpg`, `.jpeg`, `.gif`, `.svg`, `.woff`, `.woff2`, `.ttf`, `.eot`
- **Sisäiset Nuxt-polut**: Kaikki polut, jotka alkavat `__`-merkeillä (kuten `/__nuxt/`)

## Mukautetut poissulkumallit

Voit määrittää mukautettuja poissulkumallejä `excludePatterns`-asetuksen avulla:

```typescript
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],

  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'it', iso: 'it-IT' },
    ],
    defaultLocale: 'en',

    // Custom exclusion patterns
    excludePatterns: [
      // String patterns (exact match or prefix)
      '/api/health',
      '/admin',

      // String patterns with wildcards
      '/api/*',
      '/admin/**',

      // Regular expressions
      /^\/api\/v\d+\//,
      /\.(pdf|doc|docx)$/,
    ],
  },
})
```

## Mallityypit

### Merkkijonomallit

- **Tarkka vastaavuus**: `'/api/health'` - vastaa täsmälleen polkua `/api/health`
- **Prefiksin vastaavuus**: `'/admin'` - vastaa polkuja `/admin` ja `/admin/dashboard`
- **Jokerimerkit**: `'/api/*'` - vastaa polkua `/api/users` mutta ei polkua `/api/users/123`
- **Syvät jokerimerkit**: `'/admin/**'` - vastaa polkuja `/admin/users` ja `/admin/users/123`

### Säännölliset lausekkeet

Käytä RegExp-objekteja monimutkaiseen mallien vastaavuuteen:

```typescript
excludePatterns: [
  /^\/api\/v\d+\//, // API versioned routes
  /\.(pdf|doc|docx)$/, // Document files
  /^\/static\//, // Static directory
  /^\/[a-z]{2}\/api\//, // Localized API routes
]
```

## Käyttötapaukset

### SEO-tiedostot

```typescript
excludePatterns: ['/sitemap.xml', '/sitemap-*.xml', '/robots.txt', '/favicon.ico']
```

### API-reitit

```typescript
excludePatterns: ['/api/**', '/graphql', '/webhook/**']
```

### Hallintapaneelit

```typescript
excludePatterns: ['/admin', '/admin/**', '/dashboard']
```

### Staattiset resurssit

```typescript
excludePatterns: ['/assets/**', '/static/**', '/uploads/**']
```

## Miten se toimii

1. **Palvelinmiddleware**: Nitro-middleware ajetaan ensin tarkistamaan poissulkumallit
2. **Sivujen käsittely**: Sivun resolvoinnin aikana poissuljetut polut ohitetaan
3. **Catch-all-reitti**: Fallback-reitti tarkistaa poissulut ennen käsittelyä
4. **Esirenderöinti**: Poissuljettuja polkuja ei sisällytetä esirenderöityihin reitteihin

## Suorituskykyvaikutus

- Poissulkutarkistukset on optimoitu ja ne ajetaan varhain pyynnön elinkaaressa
- Sisäänrakennetut mallit käyttävät tehokasta regex-vastaavuutta
- Mukautetut mallit välimuistitetaan ja käytetään uudelleen
- Poissuljetuille poluille aiheutuva suorituskykylisä on minimaalinen

## Vianmääritys

### Staattiset tiedostot siepataan edelleen

1. **Tarkista mallin syntaksi**: Varmista, että mallisi vastaavat täsmällistä polkurakennetta
2. **Käytä regexiä monimutkaisiin malleihin**: Merkkijonojokereissa on rajoituksia
3. **Testaa mallit**: Käytä selaimen kehittäjätyökaluja tarkistaaksesi todellisen pyyntöpolun
4. **Tarkista järjestys**: Varmista, että poissulkumallit määritetään ennen muuta i18n-konfiguraatiota

### Malli ei toimi

```typescript
// ❌ Wrong - this won't work
excludePatterns: ['sitemap.xml']

// ✅ Correct - include leading slash
excludePatterns: ['/sitemap.xml']

// ✅ Better - use regex for flexibility
excludePatterns: [/^\/sitemap.*\.xml$/]
```

### Debug-tila

Ota debug-tila käyttöön nähdäksesi poissulun käsittelyn:

```typescript
i18n: {
  debug: true,
  excludePatterns: ['/api/**']
}
```

Tämä kirjaa poissulkupäätökset konsoliin.

## Siirtyminen kiertotieratkaisuista

Jos käytit kiertoteitä, kuten reittisääntöjä tai middlewarea, voit nyt korvata ne asetuksella `excludePatterns`:

```typescript
// ❌ Old workaround
export default defineNuxtConfig({
  routeRules: {
    '/sitemap*.xml': { headers: { 'content-type': 'application/xml' } },
  },
})

// ✅ New approach
export default defineNuxtConfig({
  i18n: {
    excludePatterns: ['/sitemap*.xml'],
  },
})
```

Uusi lähestymistapa on luotettavampi ja toimii reititysjärjestelmän useilla tasoilla.
