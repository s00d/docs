# Ajonaikaiset i18n-ohitukset

Käytä tätä opasta, kun haluat yhden käännöstuloksen ajaa eri kielen oletusarvoilla ympäristökohtaisesti (esimerkiksi eri asiakasinstanssit).

## Mitä voi ohittaa ajonaikaisesti

Moduuli tukee turvallisia ajonaikaisia ohituksia seuraaville:

- `defaultLocale`
- `fallbackLocale`
- `disabledLocales`

Nämä ohitukset lisätään käännösvaiheen konfiguraation päälle tiedostoista `.nuxt/i18n.strategy.mjs` ja `.nuxt/i18n.config.mjs`.

## Mitä ei voi ohittaa ajonaikaisesti

`strategy` (`no_prefix`, `prefix`, `prefix_except_default`, `prefix_and_default`) on käännösvaiheen asia, koska se vaikuttaa luotujen reittien käyttäytymiseen.

Jos annat ajonaikaisen strategiaohituksen, se ohitetaan ja varoitus tulostetaan.

## RuntimeConfig-pohjaiset ohitukset

Anna ajonaikaiset arvot polussa `runtimeConfig.public.i18nRuntime`:

```ts
export default defineNuxtConfig({
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

## Ympäristömuuttujien ohitukset

Voit myös määrittää ohitukset ympäristömuuttujilla:

- `NUXT_I18N_DEFAULT_LOCALE`
- `NUXT_I18N_FALLBACK_LOCALE`
- `NUXT_I18N_DISABLED_LOCALES` (pilkulla erotettu, esim. `fr,it`)

Varakäyttöiset aliakset ovat myös tuettuja:

- `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES`

## Validointisäännöt

Ajonaikaisesti moduuli validoi ohitukset välttääkseen rikkoutuneita tiloja:

- Et voi poistaa kaikkia kieliä käytöstä.
- `defaultLocale` täytyy osoittaa käytössä olevaan kieleen.
- `fallbackLocale` täytyy olla olemassa määritetyissä kielissä.

Jos ohitus on virheellinen, moduuli pitää turvallisen arvon ja kirjaa varoituksen.

## Huomioita moni-instanssijulkaisuille

Tämä ajonaikainen ominaisuus on suunniteltu instanssikohtaiseen kielten aktivointiin ja oletusarvoihin ilman uudelleenkäännöstä.

Jos instanssit vaativat eri URL-strategioita (`no_prefix` vs `prefix`), käytä erillisiä käännöksiä kullekin strategialle.

## Poistetut kielet ja staattiset hyötykuormat

`runtimeConfig.public.i18nRuntime.disabledLocales` päivittää reitityksen, vaihtimen ja Nitro-hyötykuorman **käsittelijän**, mutta Nitro tarjoilee tiedostoja hakemistosta `public/` **ennen** kyseistä käsittelijää.

Jos `translationPayloads.publicAssets` (tai Node-SSR:n pakottama julkinen kopio) on jo kirjoittanut polun `/_locales/\{page\}/\{locale\}/data.json`, ajonaikainen poistaminen käytöstä ei voi piilottaa tuota tiedostoa. Suosi käännösvaiheen `locale.disabled: true`-asetusta, jotta esikoonti ei tulosta kyseisen kielen staattisia hyötykuormia.
