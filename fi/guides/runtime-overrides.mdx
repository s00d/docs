# Ajonaikaiset i18n-ohitukset

Käytä tätä opasta, kun tarvitset yhden build-artefaktin ajamaan eri kielioletuksilla ympäristöä kohti (esimerkiksi: erilaiset vuokralaisinstanssit).

## Mitä voidaan ohittaa ajonaikaisesti

Moduuli tukee turvallisia ajonaikaisia ohituksia seuraaville:

- `defaultLocale`
- `fallbackLocale`
- `disabledLocales`

Nämä ohitukset sovelletaan käännösaikaisen konfiguraation päälle tiedostoista `.nuxt/i18n.strategy.mjs` ja `.nuxt/i18n.config.mjs`.

## Mitä ei voida ohittaa ajonaikaisesti

`strategy` (`no_prefix`, `prefix`, `prefix_except_default`, `prefix_and_default`) on käännösaikainen asia, koska se vaikuttaa generoitujen reittien käyttäytymiseen.

Jos välität ajonaikaisen strategiaohituksen, se sivuutetaan ja varoitus näytetään.

## RuntimeConfig-pohjaiset ohitukset

Anna ajonaikaiset arvot avaimen `runtimeConfig.public.i18nRuntime` alla:

```ts
export default defineNuxtConfig({
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

## Ympäristömuuttujien ohitukset

Voit myös määrittää ohitukset ympäristömuuttujien kautta:

- `NUXT_I18N_DEFAULT_LOCALE`
- `NUXT_I18N_FALLBACK_LOCALE`
- `NUXT_I18N_DISABLED_LOCALES` (pilkuin eroteltu, esim. `fr,it`)

Myös aliakset tuetaan:

- `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES`

## Validointisäännöt

Ajonaikaisesti moduuli validoi ohitukset välttääkseen rikkinäisen tilan:

- Kaikkia kieliä ei voi poistaa käytöstä.
- Asetuksen `defaultLocale` tulee osoittaa käytössä olevaan kieleen.
- Asetuksen `fallbackLocale` tulee olla ilmoitettujen kielten joukossa.

Jos ohitus on virheellinen, moduuli säilyttää turvallisen arvon ja kirjaa varoituksen.

## Huomioita monen instanssin käyttöönotoista

Tämä ajonaikainen ominaisuus on suunniteltu instanssikohtaiseen kielten aktivointiin ja oletuksiin ilman uudelleenkäännöstä.

Jos instanssit vaativat eri URL-strategioita (`no_prefix` vs. `prefix`), käytä kullekin strategialle erillisiä buildeja.

## Poistetut kielet ja staattiset payloadit

`runtimeConfig.public.i18nRuntime.disabledLocales` päivittää reitityksen, vaihtajan ja Nitro-payload-**käsittelijän** — mutta Nitro tarjoilee tiedostot `public/`-hakemiston alta **ennen** kyseistä käsittelijää.

Jos `translationPayloads.publicAssets` (tai Node SSR:n pakotettu julkinen kopio) on jo kirjoittanut tiedoston `/_locales/\{page\}/\{locale\}/data.json`, ajonaikainen käytöstä poisto ei voi piilottaa sitä tiedostoa. Suosi asetusta `locale.disabled: true` käännösvaiheessa, jotta esiyhdistys ei tuota kyseisen kielen staattisia payloadeja.
