## Requirements

- **Node.js**: 18 or newer.
- **Nuxt**: 3.x or 4.x.

The module supports both the Nuxt 3 project layout (`pages/**/*.vue`) and the Nuxt 4 layout (`app/pages/**/*.vue`). Translations live at the project root by convention (`locales/`), even when using the Nuxt 4 `app/` directory.

## Install the Nuxt module

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Register it in `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

See the [Quickstart](/quickstart) for a full walkthrough or the [Configuration reference](/guides/configuration) for every option.

## Project layout

By default the module expects:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Root-level files merge into every page-specific file at build time. Page-specific files are auto-created when missing during `nuxt dev`.

## Nuxt 4 layout

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

To colocate translations under `app/`, set `translationDir: 'app/locales'`.

## TypeScript

The module generates ambient types for `useI18n`, `$t`, and related helpers based on your default locale files. This is enabled by default (`types: true`).

For stronger typing of translation keys, see [`@i18n-micro/types-generator`](/integrations/types-generator).
