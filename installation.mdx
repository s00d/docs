## Requirements

- **Node.js**: 18 or newer.
- **Nuxt**: 3.x or 4.x.

The module supports both the Nuxt 3 project layout (`pages/**/*.vue`) and the Nuxt 4 layout (`app/pages/**/*.vue`). Translations live at the project root by convention (`locales/`), even when using the Nuxt 4 `app/` directory.

## Install the Nuxt module

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Register it in `nuxt.config.ts`:

```typescript nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

See the [Quickstart](/quickstart) for a full walkthrough or the [Configuration reference](/guides/configuration) for every option.

## Project layout

By default the module expects:

```
my-project/
├── locales/
│   ├── en.json           # Root-level translations (shared across pages)
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json   # Page-specific translations
│           └── fr.json
├── pages/                # or app/pages/ for Nuxt 4
│   └── index.vue
└── nuxt.config.ts
```

Root-level files (`locales/{locale}.json`) merge into every page-specific file at build time. Page-specific files (`locales/pages/{route}/{locale}.json`) are auto-created when missing during `nuxt dev`.

<Info>
  Dynamic route brackets are replaced with dashes: `pages/articles/[id].vue` maps to `locales/pages/articles-id/`.
</Info>

## Nuxt 4 layout

For projects using the `app/` directory, keep `locales/` at the project root:

```
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

To colocate translations under `app/`, set `translationDir: 'app/locales'`.

## Ecosystem packages

The i18n-micro ecosystem includes standalone packages for non-Nuxt frameworks. Install these directly with your package manager — they do **not** require the Nuxt module.

| Package | Purpose |
| --- | --- |
| [`@i18n-micro/vue`](/integrations/vue) | Vue 3 integration (standalone, without Nuxt). |
| [`@i18n-micro/react`](/integrations/react) | React integration. |
| [`@i18n-micro/preact`](/integrations/preact) | Preact integration. |
| [`@i18n-micro/solid`](/integrations/solid) | SolidJS integration. |
| [`@i18n-micro/astro`](/integrations/astro) | Astro integration. |
| [`@i18n-micro/node`](/integrations/nodejs) | Node.js server-side loader. |
| [`@i18n-micro/types-generator`](/integrations/types-generator) | Generate TypeScript types from translation files. |
| [`@i18n-micro/devtools-ui`](/integrations/devtools-ui) | Framework-agnostic DevTools panel. |

Shared internal packages (`@i18n-micro/core`, `@i18n-micro/types`, `@i18n-micro/utils`, `@i18n-micro/path-strategy`, `@i18n-micro/route-strategy`) are pulled in transitively — install them explicitly only if you use them from your own code.

## TypeScript

The module generates ambient types for `useI18n`, `$t`, and related helpers based on your default locale files. This is enabled by default (`types: true`). Disable it to opt out:

```typescript nuxt.config.ts
export default defineNuxtConfig({
  i18n: {
    types: false,
  },
})
```

For stronger typing of translation keys, see [`@i18n-micro/types-generator`](/integrations/types-generator).
