---
title: "useLocaleHead"
description: "useLocaleHead construeix les etiquetes SEO d'i18n (lang, dir, canonical, hreflang, og:locale) com un objecte que passeu a useHead."
---

`useLocaleHead()` construeix les etiquetes d'i18n del head per a la ruta actual: `lang` i `dir` a `<html>`, un enllaç canònic, alternatives `hreflang` amb `x-default`, `og:url`, `og:locale` i `og:locale:alternate`. Feu-lo servir quan establiu [`meta: false`](/ca/api/module-options#meta) i gestioneu `useHead` vosaltres mateixos; amb `meta: true` el mòdul ja registra aquestes etiquetes, i els canvis per pàgina es fan amb [`useI18nHead`](/ca/composables/useI18nHead).

## Signatura {#signature}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { build: () => LocaleHead; metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }, LocaleHead | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

Les etiquetes SEO del head per a la ruta actual: alternatives `hreflang` per a cada locale més
`x-default`, un enllaç canònic, `og:locale` i `lang`/`dir` a `<html>`.

Només cal quan `meta` està desactivat o cal ajustar els valors per defecte; amb `meta: true`
el mòdul registra les mateixes etiquetes pel seu compte.

| Paràmetre | Tipus | Descripció |
| --- | --- | --- |
| `options` | `UseLocaleHeadOptions` |  |

**Retorna**: `metaObject`, una ref que conté l'objecte del head a punt per passar a `useHead`; `updateMeta` l'actualitza; `build` calcula l'objecte del head a partir de la ruta actual (reactiu quan es llegeix dins d'un getter, p. ex. `useHead(() => build())`)

```ts
const { metaObject } = useLocaleHead({ addSeoAttributes: true })
useHead(metaObject)
```

## Opcions {#options}

| Opció | Per defecte | Descripció |
| --- | --- | --- |
| `addDirAttribute` | `true` | Estableix `dir` a `<html>` a partir del `dir` del locale (`'auto'` si no en té). |
| `identifierAttribute` | `'id'` | Atribut que identifica cada etiqueta (`i18n-can`, `i18n-og`, `i18n-alternate-<hreflang>`, …), de manera que les actualitzacions substitueixen etiquetes en lloc d'afegir-ne. |
| `addSeoAttributes` | `true` | Emet les etiquetes canonical, `hreflang` i `og:`. `false` només conserva `htmlAttrs`. |
| `baseUrl` | `'/'` | Origen que s'uneix a cada URL. Mantingueu `'/'` per a URL relatives; passeu `'https://example.com'` per a URL absolutes. |
| `autoUpdate` | `true` | Reconstrueix `metaObject` quan canvia la ruta o l'estat `i18n-locale`. |

## Què emet {#what-it-emits}

- Res en una ruta sense coincidència (404) o amb `disableMeta` per al locale actiu.
- Canonical i `og:url`: `$switchLocalePath(<active locale>)`, amb la query reduïda a [`canonicalQueryWhitelist`](/ca/api/module-options#canonicalquerywhitelist) i aplicant [`trailingSlash`](/ca/api/module-options#trailingslash).
- `hreflang`: un enllaç per cada locale habilitat en què existeix la pàgina, `hreflang = iso || code`, ometent els locales amb `seo: false`; amb `hreflangBaseLanguage: true` el primer locale regional d'una llengua també emet l'etiqueta de la llengua base. Cap amb `no_prefix`.
- `x-default`: la URL del locale per defecte, tret que l'estratègia sigui `no_prefix`, el locale per defecte tingui `seo: false` o la pàgina no hi existeixi.
- `og:locale` / `og:locale:alternate`: a partir de l'`og` del locale, o del seu `iso` convertit (`en-US` → `en_US`); s'ometen amb un avís en desenvolupament quan cap dels dos funciona.

## Exemple {#example}

```ts
// app.vue, with i18n.meta: false
const { metaObject } = useLocaleHead({ baseUrl: 'https://example.com' })
useHead(metaObject)
```

`build()` retorna el mateix objecte sense la ref: `useHead(() => build())` es manté reactiu sense cap watcher.
