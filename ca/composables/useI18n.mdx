---
title: "useI18n"
description: "useI18n retorna els helpers d'execució (`$t`, `$tc`, `$localePath`, …) com a objecte simple, amb i sense el prefix `$`."
---

`useI18n()` retorna els helpers d'execució del mòdul com a objecte simple. Feu-lo servir a `<script setup>`, composables i plugins en lloc de recórrer a `useNuxtApp()`. Cada helper apareix amb el seu nom amb `$` i amb un àlies sense prefix: `t` i `$t` són la mateixa funció.

## Signatura {#signature}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Tots els helpers d'execució, com a objecte simple.

Les mateixes funcions que el plugin injecta com a `$t`, `$tc`, etc., disponibles tant amb
el nom amb prefix de dòlar com amb un àlies sense prefix; així, tant `const { t } = useI18n()` com
`const { $t } = useI18n()` funcionen.

**Retorna**: els helpers descrits a la [referència de mètodes](/ca/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

L'objecte retornat conté tots els helpers de [`PluginsInjections`](/ca/api/methods). Cadascun està documentat a la pàgina [Helpers](/ca/api/methods).

## Exemple {#example}

```vue
<script setup lang="ts">
const { t, tc, localePath, switchLocale, getLocale } = useI18n()

const title = computed(() => t('page.title'))
</script>

<template>
  <h1>{{ title }}</h1>
  <p>{{ tc('items', 3) }}</p>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
  <button @click="switchLocale(getLocale() === 'en' ? 'de' : 'en')">{{ t('nav.switch') }}</button>
</template>
```

## Fora del tipus {#not-in-the-type}

`$defineI18nRoute` només està tipat a `useNuxtApp()`:

```ts
const { $defineI18nRoute } = useNuxtApp()
```
