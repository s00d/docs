---
title: "useI18nHead"
description: "useI18nHead sobreescriu les etiquetes SEO d'i18n generades per a una pàgina: substituïu o elimineu les etiquetes canonical, hreflang i og, o afegiu-ne de pròpies."
---

`useI18nHead()` canvia les etiquetes SEO que genera el mòdul, només per a una pàgina. Feu-lo servir quan una pàgina en sap més que el router: un article d'un CMS que només existeix en alguns locales, una URL canònica que ve d'una API, etiquetes `og:` addicionals. Obteniu les etiquetes generades amb les vostres sobreescriptures fusionades a sobre.

## Signatura {#signature}

```ts
useI18nHead(input?: MaybeRefOrGetter<I18nHeadInput | null>): { pageHead: any; resetPageHead: () => void }
```

Registra sobreescriptures a nivell de pàgina per a les etiquetes SEO d'i18n del head.
El plugin `02.meta` les fusiona per sobre de la sortida de `useLocaleHead`.

Preferiu un getter (`() => ({ … })`) quan els valors provenen de `$t` / `t` perquè
es tornin a resoldre en canviar de locale. Un objecte simple s'avalua una sola vegada i queda congelat.

| Paràmetre | Tipus | Descripció |
| --- | --- | --- |
| `input` *(opcional)* | `MaybeRefOrGetter<I18nHeadInput \| null>` |  |

Funciona amb [`meta: true`](/ca/api/module-options#meta) (el valor per defecte): el plugin de metadades del mòdul fusiona l'entrada per sobre de la sortida de [`useLocaleHead`](/ca/composables/useLocaleHead) a cada renderització del head. Amb `meta: false` ningú no la llegeix.

La sobreescriptura es restableix quan canvia el nom de la ruta. Una pàgina que estableix `disableMeta` no rep cap etiqueta d'i18n, ni tan sols les sobreescriptures.

## Entrada {#input}

`I18nHeadInput` (de `@i18n-micro/types`):

| Clau | Tipus | Efecte |
| --- | --- | --- |
| `htmlAttrs` | `Record<string, string>` | Es fusiona als atributs de `<html>` (`lang`, `dir`). |
| `meta` | `I18nHeadMeta[]` | S'afegeix després de les etiquetes generades; substitueix una etiqueta amb el mateix `id`, `property` o `name`. |
| `link` | `I18nHeadLink[]` | S'afegeix després dels enllaços generats; substitueix un enllaç amb el mateix `id`, o `rel` + `hreflang`. |
| `replace.canonical` | `string \| false` | Substitueix el `href` canònic, o elimina l'enllaç. |
| `replace.hreflang` | `I18nHeadLink[] \| false` | Substitueix o elimina **tots** els enllaços `rel="alternate"`, inclòs `x-default`. |
| `replace.xDefault` | `I18nHeadLink \| false` | Substitueix o elimina l'enllaç `x-default`. |
| `replace.ogLocale` | `string \| false` | Substitueix o elimina `og:locale`. |
| `replace.ogUrl` | `string \| false` | Substitueix o elimina `og:url`. |
| `replace.ogAlternates` | `string[] \| false` | Reconstrueix `og:locale:alternate` a partir d'aquests codis de locale (mitjançant `og` / `iso`), ometent el locale actual, els codis desconeguts i els codis sense valor `og` ni `iso`, o els elimina. |
| `disable` | `I18nHeadDisableGroup[]` | Descarta grups generats: `'hreflang'` (no `x-default`), `'x-default'`, `'canonical'`, `'og'` (`og:locale` + `og:url`), `'og-alternates'`, `'html'`. |

Ordre d'aplicació: `disable`, després `replace` i després `htmlAttrs`, `meta`, `link`.

## Exemple {#example}

Un article que només existeix en alguns locales, amb URL alternatives que vénen de l'API:

```vue
<script setup lang="ts">
const route = useRoute()
const { t } = useI18n()
const { data: article } = await useFetch<{ title: string; urls: Record<string, string> }>(`/api/articles/${route.params.slug}`)

useI18nHead(() => {
  if (!article.value) return null
  const codes = Object.keys(article.value.urls)
  return {
    meta: [{ property: 'og:title', content: article.value.title || t('blog.title') }],
    replace: {
      hreflang: codes.map((code) => ({ rel: 'alternate', hreflang: code, href: article.value!.urls[code]! })),
      ogAlternates: codes,
    },
  }
})
</script>
```

Passeu un getter, com aquí, quan els valors provenen de `t()` o de dades asíncrones: es torna a executar en canviar de locale. Un objecte simple només es llegeix una vegada.
