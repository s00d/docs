---
title: "useI18nLocale"
description: "useI18nLocale llegeix i escriu l'estat de l'idioma i la galeta d'idioma — el punt d'entrada per a la detecció d'idioma personalitzada."
---

`useI18nLocale()` dona accés a l'idioma que ha triat l'aplicació: l'estat `i18n-locale` i la galeta d'idioma. Utilitzeu-lo en un plugin que detecti l'idioma pel seu compte (domini, perfil d'usuari, capçalera) en lloc d'escriure a mà `useState('i18n-locale')` o la galeta. Les seves comprovacions de validesa utilitzen els idiomes activats, incloses les sobreescriptures en temps d'execució.

## Signatura {#signature}

```ts
useI18nLocale(): { getEffectiveLocale: (route: unknown, getLocaleFromRoute: GetLocaleFromRoute) => string; getLocale: () => string | null; getPreferredLocale: () => string | null; hashCookie: CookieRef; isValidLocale: (locale: string | null | undefined) => locale is string; locale: any; localeCookie: CookieRef; resolveInitialLocale: (options: ResolveInitialLocaleOptions) => string; setLocale: (locale: string | null) => void; syncLocale: (locale: string | null) => void; validLocales: string[] }
```

Punt d'entrada centralitzat per a la gestió de l'idioma i18n.
Combina useState('i18n-locale'), la galeta d'idioma i les utilitats de sincronització.

## Valors retornats {#returned-values}

| Membre | Tipus | Descripció |
| --- | --- | --- |
| `locale` | `Ref<string \| null>` | La ref `useState('i18n-locale')`. |
| `localeCookie` | `Ref<string \| null>` | La galeta [`localeCookie`](/ca/api/module-options#localecookie); un simple `{ value: null }` quan l'opció és `null`. |
| `hashCookie` | `Ref<string \| null>` | La galeta `hash-locale` amb l'encaminament per hash; `{ value: null }` en cas contrari. |
| `validLocales` | `string[]` | Codis dels idiomes activats. |
| `setLocale(locale)` | `(locale: string \| null) => void` | Escriu l'estat i les galetes. No valida ni carrega traduccions. |
| `syncLocale(locale)` | `(locale: string \| null) => void` | Escriu només les galetes. |
| `getLocale()` | `() => string \| null` | L'estat i, després, la galeta de preferència (la galeta de hash amb l'encaminament per hash). No es valida. |
| `getPreferredLocale()` | `() => string \| null` | El primer valor **vàlid** entre l'estat i la galeta de preferència, o `null`. |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string` | L'estat, amb l'encaminament per hash, quan està definit; altrament `getLocaleFromRoute(route)`. |
| `resolveInitialLocale(options)` | `(options: ResolveInitialLocaleOptions) => string` | `options.urlLocale`, després un estat vàlid, després `options.serverLocale` i després l'idioma de la ruta. Desa el resultat a l'estat quan l'estat no és vàlid; al client també escriu la galeta. |
| `isValidLocale(locale)` | `(locale) => locale is string` | Indica si `locale` és a `validLocales`. |

Les galetes duren un any, amb `path: '/'` i `sameSite: 'lax'`.

## Exemple {#example}

```ts
// plugins/locale-from-domain.server.ts
export default defineNuxtPlugin({
  name: 'locale-from-domain',
  enforce: 'pre',
  setup() {
    const { setLocale, isValidLocale } = useI18nLocale()
    const host = useRequestURL().hostname // e.g. de.example.com
    const code = host.split('.')[0]
    if (isValidLocale(code)) setLocale(code)
  },
})
```

El plugin carregador del mòdul llegeix l'estat quan s'inicia, de manera que un plugin que el defineixi s'ha d'executar abans (`enforce: 'pre'`). Com competeix l'estat amb l'URL, la galeta i `Accept-Language`: [Detecció de l'idioma](/ca/guide/locale-detection). Guia completa: [Detecció personalitzada](/ca/guide/custom-auto-detect).

`setLocale()` no canvia les traduccions que es mostren a la pantalla. Per canviar l'idioma de la pàgina actual, crideu [`$switchLocale()`](/ca/api/methods#$switchlocale).
