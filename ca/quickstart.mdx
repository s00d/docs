## 🚀 Inici ràpid

### Instal·lació

Instal·la el mòdul a la teva aplicació Nuxt:

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

### Configuració bàsica

Afegeix el mòdul al teu `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

<Tip>
- **Fitxers d'arrel** (`locales/en.json`, etc.) — traduccions compartides a tota l'aplicació (menús, peu de pàgina, UI comuna). Amb `translationPayloads.mode: 'premerged'` (per defecte), es fusionen en cada pàgina en temps de compilació.
- **Fitxers específics de pàgina** (`locales/pages/<route>/<locale>.json`) — traduccions úniques per a pàgines concretes, carregades només quan es visita la pàgina.
- **Rutes dinàmiques** — `pages/articles/[id].vue` es correspon amb `locales/pages/articles-id/` (els claudàtors se substitueixen per guions).
- **Generació automàtica** — tots els fitxers de traducció es creen automàticament si falten durant `nuxt dev`.
</Tip>

<Info>
El mòdul admet ambdós layouts:

- **Pàgines**: `pages/**/*.vue` (Nuxt 3) o `app/pages/**/*.vue` (Nuxt 4)
- **Traduccions**: mantén `locales/` a l'**arrel del projecte** per defecte (convenció recomanada), no dins d'`app/`

```tree
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   ├── en.json
│   └── pages/
└── nuxt.config.ts
```

Col·locació opcional: `i18n: \{ translationDir: 'app/locales' \}` (vegeu [fixture `n3`](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/n3)).

Per al helper opcional de la CLI `text-to-i18n`, utilitza [`nuxt-i18n-micro-cli` ≥ 2.1.1](/guides/cli#-text-to-i18n-command) perquè `app/pages` i `app/components` s'escanegin des de l'arrel del projecte.
</Info>

### Ús bàsic

Utilitza les traduccions als teus components:

```vue
<template>
  <div>
    <h1>{{ $t('welcome') }}</h1>
    <p>{{ $t('description', { name: 'World' }) }}</p>

    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" @click="$switchLocale(locale.code)">
        {{ locale.code }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useI18n } from '#imports'

const { $t, $getLocales, $switchLocale } = useI18n()
</script>
```
