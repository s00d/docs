**Data**: 2025-10-30

**Versió**: `v2.0.0`

![Versió v2.0.0](/images/2.0.0.png)

Presentem l'HMR al servidor per als fitxers de traducció en desenvolupament. Quan canvia una traducció JSON, la memòria cau del servidor invalida només les claus afectades, i les peticions següents reben immediatament dades noves, sense necessitat de reiniciar.

## Què hi ha de nou? {#what’s-new}

- HMR al servidor per als fitxers de traducció
- Invalidació instantània de la memòria cau per pàgina/locale
- Una experiència de desenvolupament fluida mentre s'edita el contingut

## Com funciona {#how-it-works}

- L'observador de `src/runtime/server/plugins/watcher.dev.ts` vigila `<rootDir>/<translationDir>/**/*.json`
- Els fitxers de pàgina (p. ex., `pages/<page>/<locale>.json`) invaliden `_locales:merged:<page>:<locale>`
- Els fitxers de nivell arrel (p. ex., `<locale>.json`) invaliden totes les claus fusionades d'aquell locale
- Es registra automàticament des de `src/module.ts` en desenvolupament quan `experimental.hmr !== false`

## Configuració {#configuration}

```ts
export default defineNuxtConfig({
  i18n: {
    experimental: { hmr: true }, // default in dev
  },
})
```
