**Data**: 2026-06-25

**Versió**: `v3.21.0`

![v3.21.0 release](/images/3.21.0.png)

Aquesta versió afegeix **`useI18nHead`**, un composable a nivell de pàgina per sobreescriure el SEO d'i18n per damunt del plugin integrat `02.meta`. Personalitzeu `hreflang`, l'URL canònica, `og:url` i les etiquetes Open Graph per ruta sense un plugin de meta personalitzat ni `meta: false`.

## Què hi ha de nou? {#what’s-new}

### Composable `useI18nHead` {#usei18nhead-composable}

Crideu `useI18nHead` a qualsevol pàgina quan `meta: true` (per defecte). El mòdul fusiona la vostra entrada després de `useLocaleHead` a cada actualització de ruta:

```vue
<script setup lang="ts">
useI18nHead(() => ({
  meta: [{ property: 'og:title', content: article.value?.title }],
  replace: {
    canonical: article.value?.canonicalUrl,
    ogUrl: article.value?.canonicalUrl,
    hreflang: localeCodes.map((locale) => ({
      rel: 'alternate',
      hreflang: locale,
      href: article.value!.locales[locale]!,
    })),
    ogAlternates: localeCodes,
  },
}))
</script>
```

Admet objectes estàtics, getters reactius, l'addició de `meta` / `link`, `replace` per als grups integrats i `disable` per eliminar etiquetes generades automàticament. Vegeu [`useI18nHead`](/ca/composables/useI18nHead).

### Utilitat `mergeI18nHead` (`@i18n-micro/utils`) {#mergei18nhead-utility-@i18n-micro/utils}

La lògica de fusió independent del framework es troba a `@i18n-micro/utils/merge-i18n-head`: la utilitza el plugin `02.meta` i es pot provar de manera aïllada. Els tipus (`I18nHeadInput`, `I18nHeadLink`, `I18nHeadMeta`) s'exporten des de `@i18n-micro/types`.

### Integració amb plugins {#plugin-integration}

- **`02.meta`**: fusiona la sortida de `useLocaleHead` amb l'estat de pàgina de `useI18nHead` mitjançant `useHead`
- **`01.plugin`**: restableix les sobreescriptures de pàgina quan canvia el nom de la ruta mitjançant `resetPageHead()` (estat compartit amb el composable)

### Documentació i proves {#documentation-&-tests}

- Nova guia: [`useI18nHead`](/ca/composables/useI18nHead) amb exemples de CMS/articles
- S'han actualitzat [SEO](/ca/guide/seo) i [`useLocaleHead`](/ca/composables/useLocaleHead): quan utilitzar cada API
- Cobertura amb Playwright + Vitest: SSR, navegació SPA, recàrrega, `nuxi generate`, alternatives parcials, `x-default`, càrrega reactiva al client

## Casos d'ús habituals {#typical-use-cases}

| Escenari                                     | Enfocament                                                     |
| -------------------------------------------- | -------------------------------------------------------------- |
| Blog/CMS amb traduccions parcials            | `replace.hreflang` + `replace.ogAlternates` a partir dels locales de l'API |
| URL canònica personalitzada des del CMS      | `replace.canonical` + `replace.ogUrl`                          |
| Només OG en una pàgina de destinació         | `meta: [{ property: 'og:title', ... }]` — mantenir el hreflang del mòdul |
| Sense hreflang en una pàgina                 | `disable: ['hreflang', 'x-default']`                           |
| Substituir un plugin personalitzat (`i18nManualHreflang`) | `useI18nHead` per pàgina de contingut + `meta: true` |

El **JSON-LD** es manté a `useHead({ script: [...] })`: `useI18nHead` no genera dades estructurades.

## Canvis incompatibles {#breaking-changes}

Cap per a l'ús estàndard de `nuxt.config`. El nou composable i el subcamí de utils són additius.

## Per què és important {#why-it-matters}

- **Cap plugin de meta personalitzat** per a entrades de CMS, notícies o guies amb URL per locale
- **Un sol pipeline**: valors per defecte del mòdul + sobreescriptures de pàgina en una sola crida a `useHead`
- **Amb seguretat de tipus**: `I18nHeadInput` per a helpers com `buildArticleHead(content)`

El registre de canvis complet es publicarà amb la versió a [GitHub](https://github.com/s00d/nuxt-i18n-micro/blob/main/CHANGELOG.md).
