---

Nuxt I18n Micro és un mòdul d'i18n lleuger i d'alt rendiment per a Nuxt 3 i 4, dissenyat per a projectes grans. Manté baixos els temps de compilació, l'ús de memòria i la mida del paquet en comparació amb solucions d'i18n tradicionals com `@nuxtjs/i18n`.

Les rutes localitzades es generen en temps de compilació amb `@i18n-micro/route-strategy` i es resolen en temps d'execució amb `@i18n-micro/path-strategy`, de manera que els enllaços, el selector, `hreflang` i les redireccions coincideixen sempre amb el router. Les traduccions són només JSON, repartides entre fitxers arrel compartits i fitxers per pàgina que el servidor de desenvolupament crea per vosaltres, amb HMR integrat.

<CodeGroup>

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>
