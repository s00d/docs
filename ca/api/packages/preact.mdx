<Info>
Els components `I18nGroupProps`, `I18nLinkProps`, `I18nSwitcherProps` i `I18nTProps` accepten centenars d'atributs HTML estàndard, ARIA i controladors d'esdeveniments de Preact, a més de les seves props específiques de l'i18n. Consulta els fonts a [`packages/preact/src`](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/preact/src) per a la llista completa. Les props específiques d'i18n són:

- **`I18nGroupProps`**: `prefix` (obligatori), `groupClass?`, `children?` (com a funció de render).
- **`I18nLinkProps`**: `to` (obligatori), `activeStyle?`, `localeRoute?`, més els atributs habituals d'`<a>`.
- **`I18nSwitcherProps`**: `locales?`, `currentLocale?`, `getLocaleName?`, `switchLocale?`, `localeRoute?`, `customLabels?` i les propietats `custom*Style` per a l'aspecte visual.
- **`I18nTProps`**: `keypath` (obligatori), `plural?`, `params?`, `tag?`, `date?`, `number?`, `relativeDate?`, `defaultValue?`, `html?`, `hideIfEmpty?`, `customPluralRule?`.
</Info>
