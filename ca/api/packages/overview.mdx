# API dels paquets

`nuxt-i18n-micro` es construeix a partir d'un conjunt de paquets petits, la majoria dels quals es poden fer servir per si sols. `@i18n-micro/vue` en una app Vue simple, `@i18n-micro/core` a qualsevol lloc.

Cada pàgina següent es genera a partir de la instantània de l'API que [`pnpm run api:surface`](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/maintenance-commands.md#api-surface) comprova contra els fonts TypeScript, de manera que una exportació no pot desaparèixer sense que aquesta referència canviï o la CI falli.
