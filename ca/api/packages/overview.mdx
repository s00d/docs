---
title: "API dels paquets"
description: "L'API exportada de cada paquet @i18n-micro/*, generada a partir de les instantànies d'API que la CI comprova amb el codi font."
---

El mòdul de Nuxt està construït a partir de petits paquets `@i18n-micro/*`, i la majoria funcionen per si sols: `@i18n-micro/vue` en una aplicació Vue, `@i18n-micro/core` a qualsevol lloc. Utilitzeu aquestes pàgines per consultar què exporta un paquet, per punt d'entrada. Cada pàgina es genera a partir de la instantània que [`pnpm run api:surface`](https://s00d.github.io/nuxt-i18n-micro/contributing/maintenance-commands#api-surface) comprova amb el codi font de TypeScript, de manera que una exportació no pot canviar sense que la CI se n'adoni.
