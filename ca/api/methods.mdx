---
title: "Helpers"
description: "Tots els helpers en temps d'execució que injecta el mòdul (`$t`, `$tc`, `$localePath`, `$switchLocale` i la resta) amb la seva signatura."
---

El mòdul injecta els seus helpers en temps d'execució a l'aplicació Nuxt: `$t`, `$tc`, `$localePath`, `$switchLocale` i la resta. Utilitzeu aquesta pàgina per consultar la signatura i el comportament d'un helper. Les signatures i les descripcions provenen de les interfícies `PluginsInjections` i `NuxtAppOnlyInjections` de `src/runtime/plugins/01.plugin.ts`.

## Accés {#access}

| On | Com |
| --- | --- |
| Plantilla | `{{ $t('title') }}`: tots els helpers, amb el `$` |
| `<script setup>` | `const { t, localePath } = useI18n()`: tots els helpers de `PluginsInjections`, amb i sense el `$` |
| Plugin, middleware, `<script setup>` | `const { $t, $defineI18nRoute } = useNuxtApp()`: tot, només amb `$` |

`$defineI18nRoute` només està tipat a `useNuxtApp()`. Vegeu [`useI18n`](/ca/composables/useI18n).

```vue
<script setup lang="ts">
const { t, localePath } = useI18n()
</script>

<template>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
</template>
```

## Locale {#locale}

### `$getLocale` {#$getlocale}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric) => string
```

Codi del locale actiu. Passeu-hi una ruta per llegir el locale al qual pertany aquesta ruta.

```ts
$getLocale() // 'de' on /de/about
```

### `$getLocaleName` {#$getlocalename}

```ts
() => string | null
```

El `displayName` del locale actiu segons la configuració, o `null` si no en té.

### `$getLocales` {#$getlocales}

```ts
() => Locale[]
```

Tots els locales configurats, amb les seves metadades.

Les propietats personalitzades d'un objecte de locale es retornen tal com s'han escrit; tipeu-les amb l'[ampliació de mòdul](/ca/api/module-options#locales) de `Locale`.

### `$defaultLocale` {#$defaultlocale}

```ts
() => string | undefined
```

Codi del locale per defecte configurat.

### `$getI18nConfig` {#$geti18nconfig}

```ts
() => ResolvedI18nConfig
```

La configuració resolta del mòdul, tal com la veu el runtime.

El valor inclou les [sobreescriptures en temps d'execució](/ca/guide/runtime-overrides) (`defaultLocale`, `fallbackLocale`, locales desactivats).

```ts
const { strategy, localeCookie } = useNuxtApp().$getI18nConfig()
```

## Traducció {#translation}

### `$t` {#$t}

```ts
TranslationFn<CleanTranslation>
```

Tradueix una clau, interpolant-hi `params`. Retorna `defaultValue` quan la clau
no existeix, o la mateixa clau quan no s'indica cap valor per defecte.

```ts
// { "welcome": "Welcome, {name}!" }
$t('welcome', { name: 'Ada' }) // 'Welcome, Ada!'
$t('missing.key', {}, 'Fallback') // 'Fallback'
```

Una clau que apunta a un objecte niat retorna aquest objecte, no una cadena. En una plantilla es renderitza com a `[object Object]`; utilitzeu una clau fulla.

### `$ts` {#$ts}

```ts
TranslationFn<string>
```

Com `$t`, però sempre retorna una cadena: el valor passa per `toString()`, de manera que un objecte
niat es converteix en `'[object Object]'`. Feu que la clau apunti a una fulla.

### `$_t` {#$_t}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<CleanTranslation>
```

Vincula `$t` a una ruta concreta, per traduir fora de la pàgina actual; per exemple, un layout
que renderitza un enllaç a una altra ruta.

```ts
const route = useRoute()
const t = useNuxtApp().$_t(route)
t('page.title')
```

### `$_ts` {#$_ts}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<string>
```

Vincula `$ts` a una ruta concreta. Vegeu `$_t`.

### `$tc` {#$tc}

```ts
(key: TranslationKey, params: number | Params, defaultValue?: string) => string
```

Tradueix amb pluralització. `params` pot ser el mateix recompte, o un objecte que contingui
`count`.

Les formes se separen amb `|`. Amb la regla integrada, un recompte enter no negatiu `n` tria la forma `n`, limitada a l'última forma; un recompte negatiu, fraccionari o `NaN` agafa l'última forma. `{count}` i la resta de paràmetres s'interpolen a la forma triada.

Per als idiomes els plurals dels quals no segueixen el recompte, comenceu la plantilla amb `=0 `. Aleshores la primera forma és per al 0, i les altres van segons la categoria d'[`Intl.PluralRules`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/PluralRules), en l'ordre `zero, one, two, few, many, other`:

```json
{
  "apples": "=0 no apples | one apple | {count} apples",
  "files": "=0 no files | {count} one | {count} few | {count} many"
}
```

```ts
$tc('apples', 0) // 'no apples'
$tc('apples', 1) // 'one apple'
$tc('apples', 7) // '7 apples'

// In `uk` (categories `one, few, many, other`) the forms after the zero form follow those categories:
$tc('files', 21) // '21 one'
$tc('files', 22) // '22 few'
$tc('files', 25) // '25 many'
$tc('files', 2.5) // '2.5 many': no form for `other`, so the last one
```

- `=0 ` només compta al principi de tot del valor, amb l'espai. `$t` el mostra com a text: pertany als plurals.
- Una categoria sense forma pròpia agafa l'última forma. Un recompte negatiu o fraccionari també agafa l'última forma.
- Funciona en qualsevol locale: `=0 none | one | {count} many` en anglès.
- La categoria prové de l'`iso` del locale o, si no, del seu codi. Un codi que `Intl` no coneix recorre a la regla d'índex, amb el marcador igualment eliminat, de manera que el resultat mai no depèn de la màquina.
- `<i18n-t :plural>` segueix la mateixa regla. Un [`plural`](/ca/api/module-options#plural) personalitzat o `customPluralRule` rep el valor en brut, marcador inclòs, i decideix per si mateix; si `plural` retorna `null`, la crida torna a la regla integrada, que respecta el marcador.

Sense el marcador, una plantilla es manté amb la regla d'índex, amb una excepció que només es pot llegir d'una manera: una forma zero sense marcador de posició, després una forma per categoria, amb `{count}` a cada forma que comparteixen diversos recomptes (`no files | {count} one | {count} few | {count} many` en `uk`).

Per a regles pròpies, establiu [`plural`](/ca/api/module-options#plural).

```ts
// { "apples": "no apples | one apple | {count} apples" }
$tc('apples', 0) // 'no apples'
$tc('apples', 10) // '10 apples'
$tc('cart', { count: 2, name: 'Ada' }) // count and params in one object
```

El tercer argument és `defaultValue`, no els paràmetres.

### `$has` {#$has}

```ts
(key: string) => boolean
```

Indica si una clau es resol en el locale actiu. Utilitzeu-lo per bifurcar segons textos opcionals en lloc de
renderitzar una clau en brut. Com `$t`, també veu les claus de la pàgina que s'abandona durant una transició
de pàgina dins del mateix locale.

```ts
if ($has('promo.banner')) show.value = true
```

## Formatació {#formatting}

### `$tn` {#$tn}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Formata un número amb `Intl.NumberFormat` en el locale actiu. Una clau selecciona un format amb nom
de la configuració.

Els formats amb nom provenen de [`numberFormats`](/ca/api/module-options#numberformats).

```ts
$tn(1234.5, { style: 'currency', currency: 'EUR' }) // '1.234,50 €' in de
$tn(1000, 'currency') // named format
$tn(1000, 'currency', 'de') // named format in another locale
```

### `$td` {#$td}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Formata una data amb `Intl.DateTimeFormat` en el locale actiu. Una clau selecciona un format amb nom
de la configuració.

Els formats amb nom provenen de [`datetimeFormats`](/ca/api/module-options#datetimeformats).

```ts
$td(new Date(), { dateStyle: 'long' })
$td(post.createdAt, 'short')
```

### `$tdr` {#$tdr}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

Formata una data com a temps relatiu ("fa 3 dies") amb `Intl.RelativeTimeFormat`.

```ts
$tdr(Date.now() - 5 * 60_000) // '5 minutes ago' in en
```

## Canvi de locale i enllaços {#switching-and-links}

### `$switchLocale` {#$switchlocale}

```ts
(locale: string) => Promise<boolean>
```

Navega a la pàgina actual en un altre locale. Amb `no_prefix` i el mode hash, carrega les
traduccions del locale abans de navegar; amb `no_prefix` la ruta es substitueix in situ (sense
nova entrada a l'historial). Un locale desconegut s'ignora.
La crida és asíncrona: feu-ne `await` per executar codi després de la navegació. Es resol amb `true` quan el
diccionari del locale està actiu, i amb `false` quan no ho està: el chunk no s'ha pogut carregar (el diccionari
actual es manté; torneu-la a cridar per reintentar-ho) o un canvi més recent ha guanyat.

```ts
await $switchLocale('de')
```

### `$switchLocalePath` {#$switchlocalepath}

```ts
(locale: string) => string
```

El camí de la pàgina actual en un altre locale, sense navegar.

```vue
<NuxtLink :to="$switchLocalePath('de')">Deutsch</NuxtLink>
```

### `$switchLocaleRoute` {#$switchlocaleroute}

```ts
(locale: string) => RouteLocationRaw
```

L'objecte de ruta de la pàgina actual en un altre locale, sense navegar, o una cadena d'URL
per a un locale amb el seu propi `baseUrl`. Amb `trailingSlash`, l'objecte té `path` i `fullPath`
segons la regla, amb `query` i `hash` tal com són, i `router.push` o un enllaç els conserven.

### `$switchRoute` {#$switchroute}

```ts
(route: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, toLocale?: string) => Promise<void>
```

Navega a una altra ruta, mantenint el locale actiu o canviant a `toLocale`. Asíncron com
`$switchLocale`.

```ts
$switchRoute('/about') // active locale
$switchRoute({ name: 'about' }, 'de') // switch to de
```

### `$localePath` {#$localepath}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => string
```

Resol un camí en el locale indicat, o en l'actiu. Una cadena amb un esquema `http(s):`, `mailto:`
o `tel:` es retorna tal qual: no passeu dades de l'usuari com a destinació d'un enllaç sense comprovar-les.

Un camí en forma de cadena es llegeix com la pàgina que mostra, de manera que també s'aplica el camí personalitzat d'un locale.

```ts
$localePath('/about') // '/about' in en, '/de/ueber-uns' in de with localeRoutes
$localePath({ name: 'about' }, 'fr') // '/fr/about'
```

### `$localeRoute` {#$localeroute}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => RouteLocationResolved
```

Resol una ruta en el locale indicat, o en l'actiu. Un objecte simple, segur per desar-lo a l'estat. Quan un paràmetre necessita
escapament, té `path`, `fullPath`, `query` i `hash` però no `name` ni `params`: el camí és el que dona al router
l'URL codificada. Per a un locale en un altre domini, `path` i `fullPath` són absoluts, cosa que el router no pot acceptar:
un enllaç així passa per `<i18n-link>`, o per `$localePath`.

### `$getRouteName` {#$getroutename}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric, locale?: string) => string
```

Nom de la ruta sense el prefix de locale: el nom amb què s'indexen les traduccions.

```ts
$getRouteName() // 'about' on /de/about
```

## Configuració de pàgina {#page-config}

### `$defineI18nRoute` {#$definei18nroute}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Registra la configuració de locale i les traduccions per pàgina des de dins d'un component.
Es fusiona al locale actiu i es torna a aplicar quan canvia el locale.

Crideu-lo al `<script setup>` d'una pàgina, sempre desestructurat de `useNuxtApp()`. La compilació llegeix `locales`, `localeRoutes` i `disableMeta` de la crida; en temps d'execució només importa `locales` (les traduccions en línia es fusionen per al locale actiu). Regles completes: [Configuració de pàgina](/ca/guide/per-component-translations).

```vue
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'de'],
  localeRoutes: { en: '/about', de: '/ueber-uns' },
})
</script>
```

### `$setI18nRouteParams` {#$seti18nrouteparams}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Estableix paràmetres per locale per a la ruta actual, perquè un segment dinàmic pugui ser diferent segons l'idioma.
Crideu-lo durant l'SSR, abans que es renderitzi el head.

Els paràmetres s'esborren quan es confirma una navegació a un altre camí, inclòs de `/news/1` a `/news/4`, que manté el nom de la ruta. Detalls: [Camins localitzats](/ca/guide/custom-locale-routes).

```ts
$setI18nRouteParams({
  en: { slug: 'my-post' },
  de: { slug: 'mein-beitrag' },
})
```

## Traduccions en temps d'execució {#runtime-translations}

### `$mergeTranslations` {#$mergetranslations}

```ts
(newTranslations: Translations) => void
```

Fusiona traduccions al locale actiu en temps d'execució, sobreescrivint el que hi ha carregat.

Fa una fusió profunda al chunk de la pàgina actual del locale actiu; les claus que no esmenta es conserven.

```ts
$mergeTranslations({ banner: { title: 'Sale' } })
```

### `$setTranslation` {#$settranslation}

```ts
(key: string, value: unknown) => void
```

Substitueix el valor de `key` al diccionari actiu. És una substitució, no una fusió:
utilitzeu `$mergeTranslations` quan s'hagin de conservar les claus germanes existents.

```ts
$setTranslation('banner', { title: 'Sale' }) // drops other keys under banner
$setTranslation('banner.title', 'Sale') // dotted path
```

### `$loadPageTranslations` {#$loadpagetranslations}

```ts
(locale: string, routeName: string, translations: Translations) => Promise<void>
```

Carrega traduccions per a una pàgina en temps d'execució, per a contingut les claus del qual no es coneixen en temps de compilació.

Es fusiona al chunk `(locale, routeName)` en memòria, i la pantalla s'actualitza quan aquest chunk està actiu. Aquí no es descarrega cap payload: per a una pàgina encara no carregada, les traduccions esperen, i quan es carrega el seu fitxer es queden per damunt.

```ts
await $loadPageTranslations('en', 'about', { title: 'About us' })
```

### `$resolveTranslations` {#$resolvetranslations}

```ts
() => Translations
```

Totes les traduccions que hi ha actualment en memòria per al locale i la ruta actius, en forma d'arbre.
Vista de només lectura del que `$t()` pot resoldre ara mateix.

Tracteu el resultat com a només lectura.

### `$setMissingHandler` {#$setmissinghandler}

```ts
(handler: MissingHandler | null) => void
```

Instal·la una funció de retorn que s'invoca per a cada clau no resolta. Passeu-hi `null` per eliminar-la.

El handler s'executa en lloc de l'avís de desenvolupament.

```ts
$setMissingHandler((locale, key, routeName) => {
  console.error(`[i18n] missing ${key} in ${locale} (${routeName})`)
})
```

### `$clearCache` {#$clearcache}

```ts
() => void
```

Descarta tots els chunks de traducció en memòria cau i torna a carregar el diccionari de la pàgina actual. La pàgina
continua mostrant les traduccions actuals fins que arriben les noves. L'HMR de desenvolupament el crida a
cada canvi d'un fitxer de traducció.

```ts
const { clearCache } = useI18n()
clearCache()
```

Una recàrrega fallida manté el diccionari actual.
