# 🛠️ Mètodes

Aquesta pàgina documenta tots els mètodes disponibles proporcionats per nuxt-i18n-micro. Els mètodes s'organitzen per funcionalitat per facilitar la navegació.

### `$getI18nConfig`

{/* generated:method:$getI18nConfig — do not edit; run `pnpm run docs:generate` */}

```ts
() => ModuleOptionsExtend
```

La configuració resolta del mòdul, tal com la veu el temps d'execució.

{/* /generated:method:$getI18nConfig */}

```typescript
const nuxtApp = useNuxtApp()
const { localeCookie, strategy, hooks } = nuxtApp.$getI18nConfig()
```

Per a contextos de temps de compilació o fora de Nuxt, fes servir `getI18nConfig()` de `#build/i18n.strategy.mjs` en lloc d'això.

<Info>
`serverTranslationPreload` és una opció privada del mòdul exposada només a la configuració privada del servidor (`#i18n-internal/config`). No forma part de l'API pública de temps d'execució i pot canviar sense avís.
</Info>

## 🔍 Mètodes de traducció

Mètodes principals per obtenir i gestionar traduccions.

### `$t`

{/* generated:method:$t — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Tradueix una clau, interpolant-hi `params`. Retorna `defaultValue` quan la clau falta, o la clau mateixa quan no s'ha donat cap valor per defecte.

{/* /generated:method:$t */}

```typescript
const welcomeMessage = $t('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

<Warning>
`$t` retorna `CleanTranslation`, que és `string | number | boolean | Translations | PluralTranslations | null`. Si la clau apunta a un **objecte imbricat** al teu JSON (per exemple, `$t('header')` quan el JSON conté `\{ "header": \{ "title": "Hi" \} \}`), el valor retornat serà aquest **objecte**, no una cadena. Fer-lo servir directament en una plantilla Vue (<code v-pre>\{\{ $t('header') \}\}</code>) es renderitzarà com a `[object Object]`.

**Com evitar-ho:**

- Fer servir una clau més específica: `$t('header.title')` → `"Hi"`
- Fer servir `$ts()`, que sempre retorna una cadena (crida `.toString()` als no-cadenes).
- Fer servir `$t` amb una clau imbricada per accedir intencionadament a subobjectes per a ús programàtic.
</Warning>

### `$ts`

{/* generated:method:$ts — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string) => string
```

Com `$t`, però sempre retorna una cadena: un valor objecte o array es converteix a cadena en lloc de retornar-se tal qual.

{/* /generated:method:$ts */}

```typescript
const welcomeMessage = $ts('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

### `$_t` i `$_ts`

{/* generated:method:$_t — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Vincula `$t` a una ruta concreta, per traduir fora de la pàgina actual. Per exemple, un layout que renderitza un enllaç cap a una altra ruta.

{/* /generated:method:$_t */}

{/* generated:method:$_ts — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => string
```

Vincula `$ts` a una ruta concreta. Consulta `$_t`.

{/* /generated:method:$_ts */}

Variants lligades a ruta de `$t` i `$ts`. Reben una **ruta** primer i retornen una funció de traducció fixada al locale i context de pàgina d'aquesta ruta.

- **Accés**: `useNuxtApp()` (també reexportat per `useI18n()` com a `$_t` / `$_ts`).

Fes-les servir quan la ruta activa durant SSR o transicions difereixi de `router.currentRoute`. Per exemple dins de `<i18n-t>`, `<i18n-group>`, o quan es renderitza contingut per a un objecte `route` concret.

```typescript
import { useRoute, useNuxtApp } from '#imports'

const route = useRoute()
const { $_t, $_ts } = useNuxtApp()

const $t = $_t(route)
const title = $t('page.title')

// String-safe variant
const label = $_ts(route)('page.label')
```


### `$tc`

{/* generated:method:$tc — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params: number | Params, defaultValue?: string) => string
```

Tradueix amb pluralització. `params` pot ser el recompte mateix, o un objecte que contingui `count`.

{/* /generated:method:$tc */}

**Format de la traducció**: formes separades per `|`. Posa els marcadors a **cada** forma:

```json
{
  "apples": "no apples | one apple | {count} apples",
  "cart": "no items for {name} | one item for {name} | {count} items for {name}"
}
```

```typescript
$tc('apples', 0) // "no apples"
$tc('apples', 1) // "one apple"
$tc('apples', 10) // "10 apples"

// count + other params (second argument must be an object)
$tc('cart', { count: 10, name: 'Alice' }) // "10 items for Alice"
```


**Alternativa amb component**: `<i18n-t keypath="cart" :plural="count" :params="\{ name \}" />` (fusiona `count` amb `params` internament).


### `$mergeTranslations`

{/* generated:method:$mergeTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
(newTranslations: Translations) => void
```

Fusiona traduccions al locale actiu en temps d'execució, sobreescrivint el que s'ha carregat.

{/* /generated:method:$mergeTranslations */}

```typescript
$mergeTranslations({
  welcome: 'Bienvenue, {username}!',
})
// Output: Updates the translation cache with the new French translation
```

### `$resolveTranslations`

{/* generated:method:$resolveTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
() => Translations
```

Cada traducció actualment en memòria per al locale i ruta actius, com a arbre. Vista de només lectura del que `$t()` pot resoldre ara mateix.

{/* /generated:method:$resolveTranslations */}

```typescript
const tree = $resolveTranslations()
// { aaa: { bbb: 'ccc' }, ddd: 1111 } — the same dictionary $t() reads from
```

Fes servir això quan necessitis el diccionari complet en memòria (DevTools, tests, editors en temps d'execució). Tracta el valor retornat com a només lectura; canvia valors amb `$setTranslation` o fusiona pedaços amb `$mergeTranslations`.

### `$setTranslation`

{/* generated:method:$setTranslation — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, value: unknown) => void
```

Substitueix el valor a `key` al diccionari actiu. Això és una substitució, no una fusió. Fes servir `$mergeTranslations` quan els germans existents hagin de sobreviure.

{/* /generated:method:$setTranslation */}

```typescript
$setTranslation('aaa', { fff: 'ggg' }) // replaces the whole `aaa` subtree
$setTranslation('aaa', 'text')          // replaces `aaa` with a string
$setTranslation('ddd', 1111)            // scalar at the top level
$setTranslation('aaa.bbb', 'nested')    // dotted path
```

Això és una **substitució**, no una fusió. Els germans existents sota la mateixa clau s'eliminen. Per pedaçar sense perdre germans, fes servir `$mergeTranslations`.

### `$setMissingHandler`

{/* generated:method:$setMissingHandler — do not edit; run `pnpm run docs:generate` */}

```ts
(handler: MissingHandler | null) => void
```

Instal·la una callback invocada per a cada clau no resolta. Passa `null` per treure-la.

{/* /generated:method:$setMissingHandler */}

**Definició de tipus**:

```typescript
type MissingHandler = (locale: string, key: string, routeName: string, instance?: unknown, type?: string) => void
```

```typescript
// Set a custom handler
$setMissingHandler((locale, key, routeName) => {
  console.error(`Missing translation: ${key} in ${locale} for route ${routeName}`)
  // Send to Sentry or other error tracking service
  // Sentry.captureMessage(`Missing translation: ${key}`)
})

// Remove the handler
$setMissingHandler(null)
```

**Casos d'ús**:

- Registrar traduccions que falten a serveis de seguiment d'errors (Sentry, LogRocket, etc.).
- Recollir analítiques sobre traduccions que falten.
- Gestió d'errors personalitzada per a claus de traducció que falten.

## 🔢 Formatació de nombres i dates

Mètodes per formatar nombres i dates segons les convencions del locale.

### `$tn`

{/* generated:method:$tn — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Formata un nombre amb `Intl.NumberFormat` al locale actiu. Una clau selecciona un format amb nom de la configuració.

{/* /generated:method:$tn */}

```typescript
// Inline options
const formattedNumber = $tn(1234567.89, { style: 'currency', currency: 'USD' })
// "$1,234,567.89"

// Named format (from nuxt.config i18n.numberFormats)
const price = $tn(1000, 'currency')
const priceDe = $tn(1000, 'currency', 'de')
const compact = $tn(1000, 'currency', { notation: 'compact' })
```

Les claus de format amb nom desconegudes retornen a les opcions per defecte d'`Intl.NumberFormat`. En desenvolupament (client), s'emet un `console.warn` quan `missingWarn` està activat (per defecte).

**Exemple de configuració**:

```ts
export default defineNuxtConfig({
  i18n: {
    numberFormats: {
      en: {
        currency: { style: 'currency', currency: 'USD' },
        decimal: { style: 'decimal', minimumFractionDigits: 2, maximumFractionDigits: 2 },
      },
      de: {
        currency: { style: 'currency', currency: 'EUR' },
      },
    },
  },
})
```

**Casos d'ús**:

- Formatar nombres com a moneda, percentatges o decimals en el format de locale apropiat.
- Reutilitzar formats amb nom a tota l'app (paritat amb la migració de Vue I18n).

### `$td`

{/* generated:method:$td — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Formata una data amb `Intl.DateTimeFormat` al locale actiu. Una clau selecciona un format amb nom de la configuració.

{/* /generated:method:$td */}

```typescript
const formattedDate = $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' })
// "Friday, September 1, 2023"

const short = $td(new Date(), 'short')
const longDe = $td(new Date(), 'long', 'de')
```

Les claus de format amb nom desconegudes retornen a les opcions per defecte d'`Intl.DateTimeFormat`. En desenvolupament (client), s'emet un `console.warn` quan `missingWarn` està activat (per defecte).

**Exemple de configuració**:

```ts
export default defineNuxtConfig({
  i18n: {
    datetimeFormats: {
      en: {
        short: { year: 'numeric', month: 'short', day: 'numeric' },
        long: { year: 'numeric', month: 'long', day: 'numeric', weekday: 'long' },
      },
    },
  },
})
```

**Casos d'ús**:

- Mostrar dates en un format que s'alinea amb el locale de l'usuari.
- Compartir preajustos de data curta/llarga/data-hora a tota l'app.

### `$tdr`

{/* generated:method:$tdr — do not edit; run `pnpm run docs:generate` */}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

Formata una data com a temps relatiu ("fa 3 dies") amb `Intl.RelativeTimeFormat`.

{/* /generated:method:$tdr */}

```typescript
const relativeDate = $tdr(new Date(Date.now() - 1000 * 60 * 5))
// Output: "5 minutes ago" in the 'en-US' locale
```

## 🔄 Canvi de ruta i locale

Mètodes per canviar entre locales i rutes.

### `$switchLocale`

{/* generated:method:$switchLocale — do not edit; run `pnpm run docs:generate` */}

```ts
(locale: string) => void
```

Navega a la pàgina actual en un altre locale.

{/* /generated:method:$switchLocale */}

```typescript
$switchLocale('fr')
// Prefix strategies: navigates to the French version of the route
// no_prefix: updates locale and translations without changing the URL path
```

<Tip>
Consulta [PMF — canviar de locale sense canviar la URL](/guides/faq#-switch-locale-without-changing-the-url). Per a estratègies amb prefix, fes servir `$switchLocalePath()` quan només necessitis un destí d'enllaç.
</Tip>

### `$switchLocaleRoute`

{/* generated:method:$switchLocaleRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(locale: string) => RouteLocationRaw
```

L'objecte de ruta de la pàgina actual en un altre locale, sense navegar.

{/* /generated:method:$switchLocaleRoute */}

```typescript
// on /en/news
const routeFr = $switchLocaleRoute('fr')
// Output: A route object with the new locale applied, e.g., { name: 'localized-news', params: { locale: 'fr' } }
```

### `$switchLocalePath`

{/* generated:method:$switchLocalePath — do not edit; run `pnpm run docs:generate` */}

```ts
(locale: string) => string
```

El camí de la pàgina actual en un altre locale, sense navegar.

{/* /generated:method:$switchLocalePath */}

```typescript
// on /en/news
const routeFr = $switchLocalePath('fr')
window.location.href = routeFr
// Output: url with new locale applied, e.g., '/fr/nouvelles'
```

### `$switchRoute`

{/* generated:method:$switchRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, toLocale?: string) => void
```

Navega a una altra ruta, mantenint el locale actiu o canviant a `toLocale`.

{/* /generated:method:$switchRoute */}

**Exemples**:

<CodeGroup>
```typescript String Path
// Switches to the given path with the current locale
$switchRoute('/about')
```

```typescript String Path with Locale
// Switches to the given path with French locale
$switchRoute('/about', 'fr')
```

```typescript Named Route
// Switches to a named route with the current locale
$switchRoute({ name: 'page' })
```

```typescript Named Route with Locale
// Switches to a named route and changes the locale to Spanish
$switchRoute({ name: 'page' }, 'es')
```
</CodeGroup>

## 🚦 Configuració de ruta

Mètodes per configurar el comportament de rutes i el control d'accés.

### `$defineI18nRoute`

{/* generated:method:$defineI18nRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Registra configuració de locale i traduccions per pàgina des de dins d'un component. Fusiona al locale actiu i s'aplica de nou quan canvia el locale.

{/* /generated:method:$defineI18nRoute */}

> [!IMPORTANT]
> `$defineI18nRoute` el proporciona el **plugin define** i està disponible només a `useNuxtApp()`. **No** forma part de l'objecte de retorn de `useI18n()`.
> Desestructura-la sempre des de `useNuxtApp()` dins de `script setup`. Cridar `$defineI18nRoute(...)` com a global sense més llança `"$defineI18nRoute is not defined"` durant SSR/prerender.

**Paràmetres**:

- **locales**: `string[] | Record<string, Record<string, string>>`: locales disponibles per a la ruta.
- **localeRoutes**: `Record<string, string>`: opcional. Rutes personalitzades per a locales concrets.
- **disableMeta**: `boolean | string[]`: opcional. Desactiva les etiquetes meta d'i18n per a tots o per a locales concrets.

**Exemple bàsic**:

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr', 'de'],
  localeRoutes: {
    en: '/welcome',
    fr: '/bienvenue',
    de: '/willkommen',
  },
  disableMeta: false,
})
```

> 📖 **Per a exemples d'ús detallats, formats de configuració i bones pràctiques, consulta la [Guia de traduccions per component](/guides/per-component-translations).**

### `$setI18nRouteParams`

{/* generated:method:$setI18nRouteParams — do not edit; run `pnpm run docs:generate` */}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Defineix paràmetres per locale per a la ruta actual, de manera que un segment dinàmic pot diferir per idioma. Crida'l durant SSR, abans que es renderitzi el head.

{/* /generated:method:$setI18nRouteParams */}

```typescript
// in pages/news/[id].vue
// for en/news/1-first-article
const { $switchLocaleRoute, $setI18nRouteParams, $defineI18nRoute } = useNuxtApp()
$defineI18nRoute({
  localeRoutes: {
    en: '/news/:id()',
    fr: '/nouvelles/:id()',
    de: '/Nachricht/:id()',
  },
})
const { data: news } = await useAsyncData(`news-${params.id}`, async () => {
  let response = await $fetch("/api/getNews", {
    query: {
      id: params.id,
    },
  });
  if (response?.localeSlugs) {
    response.localeSlugs = {
      en: {
        id: '1-first-article'
      }
      fr: {
        id: '1-premier-article'
      }
      de: {
        id: '1-erster-Artikel'
      }
    }
    $setI18nRouteParams(response?.localeSlugs);
  }
  return response;
});
$switchLocalePath('fr') // === 'fr/nouvelles/1-premier-article'
$switchLocalePath('de') // === 'de/Nachricht/1-erster-Artikel'
```

## 🔧 Mètodes de memòria cau i utilitat

### `$has`

{/* generated:method:$has — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string) => boolean
```

Si una clau es resol al locale actiu. Fes-lo servir per bifurcar sobre text opcional en lloc de renderitzar una clau bruta.

{/* /generated:method:$has */}

Durant transicions entre pàgines amb el mateix locale, v3 fusiona automàticament en profunditat les traduccions de la pàgina que surt amb aquest diccionari fins que la transició acaba. Per això, les claus de la pàgina anterior encara poden retornar `true` breument. No hi ha cap opció `previousPageFallback`; aquest comportament està integrat. Consulta [PMF — transicions de pàgina](/guides/faq#-why-do-translations-break-during-page-transitions-especially-with-defineasynccomponent).

```typescript
if ($has('welcome')) {
  console.log($t('welcome'))
} else {
  console.log('Key not found')
}
```

### `$clearCache`

{/* generated:method:$clearCache — do not edit; run `pnpm run docs:generate` */}

```ts
() => void
```

Descarta cada fragment en memòria cau, al client i al diccionari actiu.

{/* /generated:method:$clearCache */}

**Accés**: `useNuxtApp().$clearCache`. Declarat a `NuxtAppOnlyInjections` en lloc de `PluginsInjections`, per la qual cosa està tipat però deliberadament absent de l'objecte ajudant `useI18n()`:

```typescript
const { $clearCache } = useNuxtApp()

```

## 🧭 Composable `useI18nLocale`

El composable centralitzat per a la gestió de l'estat del locale. Fes-lo servir en lloc de manipular directament `useState('i18n-locale')` o `useCookie('user-locale')`.

```typescript
const {
  setLocale, // (locale: string) => void — updates state + cookie
  getLocale, // () => string | null — from state or cookie
  getPreferredLocale, // () => string | null — validated against locales list
  getEffectiveLocale, // (route, getLocaleFromRoute) => string
  resolveInitialLocale, // (options) => string
  isValidLocale, // (locale) => boolean
  locale, // Ref<string | null> — reactive state
  localeCookie, // CookieRef — reactive cookie
  syncLocale, // (locale) => void — sync to cookie only
  validLocales, // string[] — list of valid locale codes
} = useI18nLocale()
```

### Mètodes clau

| Mètode                  | Descripció                                                   |
| ----------------------- | ------------------------------------------------------------ |
| `setLocale(locale)`     | Defineix el locale tant a `useState` com a la cookie atòmicament. |
| `getLocale()`           | Retorna el locale actual des de l'estat o la cookie.         |
| `getPreferredLocale()`  | Retorna el locale validat contra la llista `locales`, o `null`. |
| `isValidLocale(locale)` | Comprova si un codi de locale és a la llista `locales` configurada. |

### Ús en plugins personalitzats

```typescript
// plugins/i18n-loader.server.ts
export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  },
})
```
