# Referència de l'API

## API de temps d'execució

- [Mètodes](/api/methods): `$t`, `$ts`, `$_t`, `$_ts`, canvi de locale i ajudants d'enrutament.
- [Esdeveniments](/api/events): `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`.
- [Traduccions i memòria cau](/api/cache): `TranslationStorage`, càrrega de payloads i `$clearCache`.

## Middleware del servidor

Els gestors del servidor fan servir middleware dedicat (no els ajudants `$t` del client):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers): tradueix a rutes d'API i gestors del servidor.
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers): llegeix el locale detectat i les metadades.

Consulta la [guia completa de traduccions al servidor](/guides/server-side-translations) per veure la configuració, la prioritat de detecció del locale i els exemples.

## Relacionats

- [Composables](/api/overview): `useI18n`, `useI18nLocale`, `useLocaleHead`.
- [Referència de configuració](/guides/configuration): totes les opcions del mòdul `i18n`.
