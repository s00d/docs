# Referència de l'API

## API de runtime

- [Mètodes](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, canvi de locale, helpers d'enrutament
- [Esdeveniments](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Traduccions i memòria cau](/api/cache) — `TranslationStorage`, càrrega de payloads, `$clearCache`

## Middleware del servidor

Els handlers del servidor utilitzen middleware dedicat (no els helpers `$t` del client):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — traduir a rutes d'API i handlers del servidor
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — llegir el locale detectat i les metadades

Consulta la [guia completa de traduccions al costat del servidor](/guides/server-side-translations) per a la configuració, la prioritat de detecció del locale i exemples.
