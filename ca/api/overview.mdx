Aquesta secció enumera totes les opcions, helpers, hooks, composables i components del mòdul de Nuxt, a més de l'API exportada de cada paquet `@i18n-micro/*`. Feu-la servir per consultar una signatura o un valor per defecte; la [Guia](/ca/guide/getting-started) explica com fer-los servir. La majoria de les taules d'aquí es generen a partir del codi font, de manera que coincideixen amb el codi.

## Mòdul de Nuxt {#nuxt-module}

| Pàgina | Cobreix |
| --- | --- |
| [Opcions del mòdul](/ca/api/module-options) | Cada clau `i18n` de `nuxt.config`, amb el tipus i el valor per defecte |
| [Helpers](/ca/api/methods) | `$t`, `$tc`, `$tn`, `$td`, `$localePath`, `$switchLocale`, `$defineI18nRoute` i la resta |
| [Hooks](/ca/api/events) | El hook d'execució `i18n:register` |

## Composables {#composables}

| Composable | Feu-lo servir per a |
| --- | --- |
| [`useI18n`](/ca/composables/useI18n) | Els helpers a `<script setup>` |
| [`useI18nLocale`](/ca/composables/useI18nLocale) | L'estat de l'idioma i la galeta en un plugin de detecció personalitzat |
| [`useI18nHead`](/ca/composables/useI18nHead) | Substitucions per pàgina de les etiquetes SEO generades |
| [`useLocaleHead`](/ca/composables/useLocaleHead) | Les etiquetes SEO com a objecte, per al vostre propi `useHead` |

## Components {#components}

| Component | Renderitza |
| --- | --- |
| [`<i18n-t>`](/ca/components/i18n-t) | Una traducció, amb plurals, format i interpolació de slots |
| [`<i18n-link>`](/ca/components/i18n-link) | Un `NuxtLink` cap a la ruta localitzada |
| [`<i18n-switcher>`](/ca/components/i18n-switcher) | Un desplegable d'idiomes |
| [`<i18n-group>`](/ca/components/i18n-group) | Un bloc amb un prefix de clau compartit |

## Servidor {#server}

Els handlers de Nitro fan servir `useTranslationServerMiddleware` i `useLocaleServerMiddleware`, no els helpers del client. Vegeu [Rutes del servidor](/ca/guide/server-side-translations).

## Paquets {#packages}

[API dels paquets](/ca/api/packages/overview) enumera les exportacions de cada paquet `@i18n-micro/*`, amb una pàgina generada per a cadascun.
