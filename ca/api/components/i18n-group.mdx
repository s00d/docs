# 🌍 Component `<i18n-group>`

El component `<i18n-group>` de Nuxt I18n Micro proporciona una manera còmoda d'agrupar traduccions sota un prefix comú, reduint la repetició i millorant l'organització del codi.

## ⚙️ Props

{/* generated:component:i18n-group — do not edit; run `pnpm run docs:generate` */}

| Prop | Tipus | Per defecte | Descripció |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | Prefix de clau contra el qual es resol cada consulta dins del slot. |
| `groupClass` | `string` | `''` | Classe addicional a l'element embolcall. |

**\*** obligatori.

### Slots

| Slot | Bindings | Descripció |
| --- | --- | --- |
| `default` | `prefix`, `t` | Rep `prefix` i una funció `t` amb àmbit sobre ell. |

{/* /generated:component:i18n-group */}

## 🎯 Slots

El slot per defecte rep `prefix` i una funció `t` amb àmbit sobre ell, de manera que les claus dins
s'escriuen relatives al prefix:

```vue
<i18n-group prefix="checkout">
  <template #default="{ t }">
    <h2>{{ t('title') }}</h2>
    <p>{{ t('summary', { count: 3 }) }}</p>
  </template>
</i18n-group>
```

## 🛠️ Exemple d'ús

### Ús bàsic

```vue
<template>
  <i18n-group prefix="product.details">
    <template #default="{ t }">
      <h1>{{ t('title') }}</h1>
      <p>{{ t('description') }}</p>
      <div class="price">{{ t('price', { value: 99.99 }) }}</div>
    </template>
  </i18n-group>
</template>
```

Fitxer de traducció:

```json
{
  "product": {
    "details": {
      "title": "Premium Product",
      "description": "This is a premium product",
      "price": "Price: ${value}"
    }
  }
}
```

### Amb classe personalitzada

```vue
<template>
  <i18n-group prefix="user.profile" group-class="profile-section">
    <template #default="{ t }">
      <div class="user-info">
        <h2>{{ t('title') }}</h2>
        <p>{{ t('bio') }}</p>
        <div class="stats">
          <span>{{ t('stats.followers') }}</span>
          <span>{{ t('stats.following') }}</span>
        </div>
      </div>
    </template>
  </i18n-group>
</template>
```

Fitxer de traducció:

```json
{
  "user": {
    "profile": {
      "title": "User Profile",
      "bio": "User biography goes here",
      "stats": {
        "followers": "Followers: {count}",
        "following": "Following: {count}"
      }
    }
  }
}
```

### Amb contingut dinàmic

```vue
<template>
  <i18n-group prefix="blog.post">
    <template #default="{ t }">
      <article>
        <h1>{{ t('title') }}</h1>
        <div class="meta">
          {{ t('meta.author', { name: author }) }} |
          {{ t('meta.date', { date: publishDate }) }}
        </div>
        <div v-for="(section, index) in sections" :key="index">
          <h2>{{ t(`sections.${index}.title`) }}</h2>
          <p>{{ t(`sections.${index}.content`) }}</p>
        </div>
      </article>
    </template>
  </i18n-group>
</template>

<script setup>
const author = 'John Doe'
const publishDate = '2024-01-01'
const sections = ['intro', 'main', 'conclusion']
</script>
```

## 🎨 Estilat

El component embolica el seu contingut en un div amb la classe `i18n-group` i qualsevol classe addicional especificada a la prop `groupClass`:

```css
.i18n-group {
  /* Your base styles */
}

.profile-section {
  /* Additional styles for profile sections */
}
```

## 🚀 Bones pràctiques

1. **Prefixos consistents**: Utilitza prefixos consistents i lògics que reflecteixin l'estructura de la teva aplicació

```vue
<i18n-group prefix="features.pricing">
<i18n-group prefix="features.security">
```

2. **Organització modular**: Agrupa les traduccions relacionades sota prefixos significatius

```vue
<i18n-group prefix="checkout.payment">
<i18n-group prefix="checkout.shipping">
```

3. **Components reutilitzables**: Crea components reutilitzables amb els seus propis grups de traduccions

```vue
<!-- UserProfile.vue -->
<i18n-group prefix="user.profile">

<!-- UserSettings.vue -->
<i18n-group prefix="user.settings">
```

4. **Grups imbricats**: Evita imbricar grups massa profundament per mantenir la claredat

```vue
<!-- Good -->
<i18n-group prefix="shop.product">

<!-- Avoid -->
<i18n-group prefix="shop.category.product.details.specs">
```
