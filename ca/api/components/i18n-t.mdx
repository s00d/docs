# 🌍 Component `<i18n-t>`

El component `<i18n-t>` de `Nuxt I18n Micro` és un component de traducció flexible que admet la inserció de contingut dinàmic mitjançant slots. Et permet interpolar traduccions amb components Vue personalitzats o contingut HTML, permetent escenaris de localització avançats.

Només s'aplica un de `plural`, `number`, `date` i `relativeDate` alhora; quan n'hi ha diversos
definits, guanya el primer d'aquesta llista.

### Exemples per prop

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

## 🛠️ Exemples d'ús

### Ús bàsic

```vue
<i18n-t keypath="feedback.text" />
```

Això renderitza la traducció de `feedback.text` dins d'una etiqueta `<span>`.

### Utilitzar slots per a contingut dinàmic

El component `<i18n-t>` admet l'ús de slots per inserir dinàmicament components Vue o altre contingut en parts específiques de la traducció.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

En aquest exemple, el marcador de posició `\{link\}` a la cadena de traducció `feedback.text` es reemplaça pel component `<nuxt-link>`, que al seu torn conté un altre component de traducció.

### Pluralització

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

Això aplica automàticament les regles de pluralització en funció del valor `itemCount`.

## 🚀 Funcionalitats addicionals

### Slot per defecte

Si no es proporciona cap slot específic, la traducció es pot personalitzar mitjançant el slot per defecte, que proporciona la cadena traduïda sencera:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### Renderització condicional

No renderitza res si la cadena de traducció està buida utilitzant la prop `hideIfEmpty`.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### Regla de pluralització personalitzada

Utilitza una funció personalitzada per gestionar la pluralització.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### Exemple avançat amb slots

Utilitza slots per personalitzar com es renderitza el contingut de la traducció.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
