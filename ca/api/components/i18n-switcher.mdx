# 🌍 Component `<i18n-switcher>`

El component `<i18n-switcher>` de `Nuxt I18n Micro` proporciona una interfície desplegable fàcil d'utilitzar per canviar entre diferents locales de la teva aplicació. Aquest component és altament personalitzable, permetent una integració perfecta amb el disseny i el layout de la teva aplicació.

Els locales amb `disabled: true` s'**ometen** del desplegable (romanen disponibles a través de `$getLocales()` per a SEO / head tags). Només els locales commutables obtenen `NuxtLink` + `hreflang`.

Cada part està sense estil per defecte: les props `custom*Style` accepten objectes d'estil inline, i
els slots següents substitueixen completament el marcatge quan els estils no són suficients.

## 🛠️ Exemples d'ús

### Ús bàsic

```vue
<template>
  <i18n-switcher />
</template>
```

Això renderitza un commutador de locale amb l'estil i el comportament per defecte.

### Etiquetes personalitzades i estils inline

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Aquest exemple mostra un commutador de locale totalment personalitzat amb etiquetes personalitzades i estils inline.

## 🔌 Slots

Cada part visual del commutador es pot substituir. Els slots es llisten a la taula de props
anterior; cadascun accepta contingut de plantilla:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Els slots el nom dels quals acaba en `-item`, `-link-content` o comença amb `before-item` reben l'objecte
`locale` al qual pertanyen.

## 🎨 Visió general dels estils

El component `<i18n-switcher>` inclou estils bàsics definits mitjançant estils inline que es poden sobreescriure fàcilment passant estils personalitzats via props. Aquí tens una breu visió general de l'estil per defecte:

- **Wrapper**: Controla el posicionament del desplegable.
- **Button**: Estilitza el botó de commutació del desplegable.
- **Dropdown**: Estilitza la llista desplegable.
- **Items**: Estilitza cada element de la llista.
- **Links**: Estilitza els enllaços dins de cada element.
- **Icon**: Estilitza la icona indicadora del desplegable.

Pots personalitzar aquests estils passant estils personalitzats mitjançant les props respectives, garantint que el commutador de locale s'integri perfectament a la UI de la teva aplicació.
