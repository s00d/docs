# 🌍 Component `<i18n-switcher>`

El component `<i18n-switcher>` de `Nuxt I18n Micro` proporciona una interfície desplegable senzilla per canviar entre diferents locales a la teva aplicació. Aquest component és altament personalitzable, permetent una integració fluida amb el disseny i la disposició de la teva aplicació.

Els locales amb `disabled: true` s'**ometen** del desplegable (segueixen disponibles via `$getLocales()` per a SEO / etiquetes del head). Només els locales als quals es pot canviar reben `NuxtLink` + `hreflang`.

Cada part està sense estil per defecte: les props `custom*Style` prenen objectes d'estil en línia, i els slots següents substitueixen el marcatge completament quan l'estil no és suficient.

## 🛠️ Exemples d'ús

### Ús bàsic

```vue
<template>
  <i18n-switcher />
</template>
```

Això renderitza un commutador de locale amb l'estil i el comportament per defecte.

### Etiquetes personalitzades i estils en línia

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Aquest exemple mostra un commutador de locale totalment personalitzat amb etiquetes personalitzades i estils en línia.

## 🔌 Slots

Cada part visual del commutador es pot substituir. Els slots es llisten amb la taula de props anterior; cadascun accepta contingut de plantilla:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Els slots amb nom acabat en `-item`, `-link-content` o que comencen per `before-item` reben l'objecte `locale` al qual pertanyen.

## 🎨 Visió general dels estils

El component `<i18n-switcher>` incorpora estils bàsics definits com a estils en línia que es poden sobreescriure fàcilment passant estils personalitzats via props. Aquesta és una visió breu de l'estil per defecte:

- **Embolcall**: controla el posicionament del desplegable.
- **Botó**: dona estil al botó que obre el desplegable.
- **Desplegable**: dona estil a la llista desplegable.
- **Elements**: dona estil a cada element de la llista.
- **Enllaços**: dona estil als enllaços dins de cada element.
- **Icona**: dona estil a la icona indicadora del desplegable.

Pots personalitzar aquests estils passant estils personalitzats a través de les props corresponents, garantint que el commutador de locale s'integri sense problemes a la UI de la teva aplicació.
