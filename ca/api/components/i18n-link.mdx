# 🌍 Component `<i18n-link>`

El component `<i18n-link>` de `Nuxt I18n Micro` és un component d'enllaç versàtil que localitza automàticament les rutes segons el locale actual. Actua com a embolcall de `<NuxtLink>`, oferint funcions addicionals com l'estil d'enllaç actiu i el suport per a enllaços externs.

## ⚙️ Props

{/* generated:component:i18n-link — do not edit; run `pnpm run docs:generate` */}

| Prop | Tipus | Per defecte | Descripció |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | Ruta destí. Es localitza automàticament; una URL externa es passa sense canvis. |
| `activeStyle` | `Partial<CSSStyleValue>` | — | Estil en línia aplicat mentre l'enllaç apunta a la ruta actual. |

**\*** obligatori.

### Slots

| Slot | Bindings | Descripció |
| --- | --- | --- |
| `default` | — | Contingut de l'enllaç. |

{/* /generated:component:i18n-link */}

`to` accepta el mateix que `NuxtLink`: un camí, una ruta amb nom o un objecte de ruta resolt. Es detecta una URL absoluta i es renderitza com un `<a target="_blank" rel="noopener noreferrer">` normal en lloc de localitzar-se.

## 🛠️ Exemples d'ús

### Ús bàsic

```vue
<i18n-link to="/about">About Us</i18n-link>
```

Aquest exemple crea un enllaç a la pàgina `/about`, localitzat al locale actual.

### Estil d'enllaç actiu amb estils en línia

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

L'enllaç tindrà text en negreta quan l'usuari sigui a la pàgina `/about`, permetent-te aplicar estil a l'enllaç actiu directament amb estils en línia.

### Gestió d'enllaços externs

El component detecta automàticament els enllaços externs i afegeix els atributs necessaris per a la seguretat.

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

Aquest enllaç obrirà `https://example.com` en una pestanya nova amb `rel="noopener noreferrer"` aplicat.

## 🎨 Estils

El component ara fa servir estils en línia per a l'estat actiu en lloc d'una classe. Pots personalitzar aquests estils amb la prop `activeStyle`.

### Estils actius per defecte

- **Font Weight**: `bold`
- **Color**: hereta el color per defecte del navegador (si no s'especifica `color` a `activeStyle`).

Pots sobreescriure'ls proporcionant estils personalitzats a través de la prop `activeStyle`.

### Estils actius personalitzats

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

En aquest exemple, l'enllaç serà en negreta i verd quan estigui actiu.

## 🚀 Funcions addicionals

### Slot per a contingut personalitzat

Pots passar contingut personalitzat dins de l'enllaç amb slots, fent el component flexible per a diferents casos d'ús.

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### Millores d'accessibilitat

El component admet `aria-label` i altres atributs d'accessibilitat per garantir una experiència més accessible.

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
