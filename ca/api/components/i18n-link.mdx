# 🌍 Component `<i18n-link>`

El component `<i18n-link>` de `Nuxt I18n Micro` és un component d'enllaç versàtil que localitza automàticament les rutes en funció del locale actual. Actua com un embolcall del component `<NuxtLink>`, proporcionant funcionalitats addicionals com ara l'estil d'enllaç actiu i el suport per a enllaços externs.

## ⚙️ Props

| Prop | Tipus | Per defecte | Descripció |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | Ruta de destinació. Es localitza automàticament; una URL externa es passa sense canvis. |
| `activeStyle` | `Partial<CSSStyleValue>` | — | Estil inline aplicat mentre l'enllaç apunta a la ruta actual. |

**\*** obligatori.

### Slots

| Slot | Bindings | Descripció |
| --- | --- | --- |
| `default` | — | Contingut de l'enllaç. |

{/* /generated:component:i18n-link */}

`to` accepta qualsevol cosa que accepti `NuxtLink` — una ruta, una ruta amb nom o un objecte de ruta resolt.
Una URL absoluta es detecta i es renderitza com un `<a target="_blank" rel="noopener noreferrer">` pla
en lloc de ser localitzada.

## 🛠️ Exemples d'ús

### Ús bàsic

```vue
<i18n-link to="/about">About Us</i18n-link>
```

Aquest exemple crea un enllaç a la pàgina `/about`, localitzat al locale actual.

### Estilat d'enllaç actiu amb estils inline

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

L'enllaç tindrà text en negreta quan l'usuari es trobi a la pàgina `/about`, permetent-te estilitzar l'enllaç actiu directament amb estils inline.

### Gestió d'enllaços externs

El component detecta automàticament els enllaços externs i afegeix els atributs necessaris per a la seguretat.

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

Aquest enllaç obrirà `https://example.com` en una nova pestanya amb `rel="noopener noreferrer"` aplicat.

## 🎨 Estils

El component ara utilitza estils inline per a l'estat actiu en lloc d'una classe. Pots personalitzar aquests estils utilitzant la prop `activeStyle`.

### Estils actius per defecte

- **Font Weight**: `bold`
- **Color**: Hereta el color per defecte del navegador (si no s'especifica cap `color` a `activeStyle`).

Pots sobreescriure'ls proporcionant estils personalitzats mitjançant la prop `activeStyle`.

### Estils actius personalitzats

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

En aquest exemple, l'enllaç serà en negreta i verd quan estigui actiu.

## 🚀 Funcionalitats addicionals

### Slot per a contingut personalitzat

Pots passar contingut personalitzat dins de l'enllaç utilitzant slots, fent que el component sigui flexible per a diferents casos d'ús.

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### Millores d'accessibilitat

El component admet `aria-label` i altres atributs d'accessibilitat per garantir una experiència més accessible.

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
