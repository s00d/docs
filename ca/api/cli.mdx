La [guia de la CLI](/ca/guide/cli) mostra els fluxos de treball habituals. Aquesta pàgina ho llista tot i es genera a partir de la mateixa taula que alimenta `--help`.

## Opcions comunes {#common-flags}

| Opció | Per defecte | Descripció |
| --- | --- | --- |
| `--cwd` | directori actual | Directori del projecte |
| `--logLevel` | `info` | Nivell de sortida: silent, info |
| `--debug` | `false` | Mostra una traça de la pila quan una ordre falla |

## Inspecció {#inspect}

### `info` {#info}

Mostra la configuració i18n resolta del projecte

| Opció | Per defecte | Descripció |
| --- | --- | --- |
| `--json` | `false` | Mostra JSON en lloc de text |

### `check` {#check}

La porta de CI: falla amb claus que falten, buides, sobrants, no definides o no utilitzades i amb marcadors de posició trencats

| Opció | Per defecte | Descripció |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Directori de traduccions, relatiu al projecte |
| `--only` | totes excepte duplicates | Comprovacions a executar, separades per comes: missing, empty, extra, placeholders, undefined, unused, duplicates. Si s'anomena `unused` aquí, falla quan no es pot executar |
| `--duplicates` | `false` | Informa també del mateix text sota claus diferents |
| `--ignore` | — | Patrons glob, separats per comes, de fitxers font a ometre, relatius al projecte |
| `--json` | `false` | Mostra JSON en lloc de text |

```bash
i18n-micro check
i18n-micro check --only missing,placeholders --json
```

### `stats` {#stats}

Mostra el grau de compleció de les traduccions per idioma

| Opció | Per defecte | Descripció |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Directori de traduccions, relatiu al projecte |
| `--html` | — | Escriu també un informe HTML en aquest fitxer |
| `--json` | `false` | Mostra JSON en lloc de text |
| `--baseRef` | — | Referència de Git amb què comparar la compleció, p. ex. HEAD~1 o main |

```bash
i18n-micro stats --baseRef main
i18n-micro stats --html reports/i18n.html
```

### `lint` {#lint}

Comprova el text de les traduccions; falla quan queden problemes

| Opció | Per defecte | Descripció |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Directori de traduccions, relatiu al projecte |
| `--rules` | totes, o `enabledRules` de .i18n-lintrc.json | Regles a executar, separades per comes: no-trailing-spaces, no-multiple-spaces, no-empty-translation, o una de personalitzada |
| `--fix` | `false` | Corregeix el que es pot corregir: espais i regles personalitzades amb substitució |
| `--json` | `false` | Mostra JSON en lloc de text |

```bash
i18n-micro lint --rules no-trailing-spaces --fix
```

### `search` {#search}

Cerca claus i valors, i mostra on s'utilitza cada clau

| Opció | Per defecte | Descripció |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Directori de traduccions, relatiu al projecte |
| `<query>` | — | Text o clau a cercar |
| `--caseSensitive` | `false` | Distingeix majúscules i minúscules |
| `--onlyUnused` | `false` | Només les claus que `clean` eliminaria; la consulta passa a ser opcional |
| `--scope` | `all` | On cercar: global, pages, all |
| `--limit` | — | Retorna com a màxim aquest nombre de claus |
| `--ignore` | — | Patrons glob, separats per comes, de fitxers font a ometre, relatius al projecte |
| `--json` | `false` | Mostra JSON en lloc de text |

```bash
i18n-micro search "Welcome"
i18n-micro search --onlyUnused
```

## Flux de traducció {#translation-workflow}

### `extract` {#extract}

Llista les claus que utilitzen els fitxers font i que encara no tenen text, i afegeix les que tenen un text per defecte a l'idioma per defecte

| Opció | Per defecte | Descripció |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Directori de traduccions, relatiu al projecte |
| `--ignore` | — | Patrons glob, separats per comes, de fitxers font a ometre, relatius al projecte |

```bash
i18n-micro extract
```

### `translate` {#translate}

Omple les traduccions que falten a partir de l'idioma per defecte mitjançant un servei de traducció

| Opció | Per defecte | Descripció |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Directori de traduccions, relatiu al projecte |
| `--service` | — | Servei de traducció: ai, azure, deepl, google, libretranslate, yandexcloud |
| `--token` | — | Clau d'API. És preferible la variable d'entorn I18N_TRANSLATE_TOKEN: les opcions acaben a l'historial de la shell |
| `--options` | — | Opcions del servei com a parells clau:valor, separats per comes |
| `--locale` | tots els idiomes excepte el per defecte | Idiomes a omplir, separats per comes |
| `--replace` | `false` | Torna a traduir totes les claus, substituint els valors existents |
| `--dryRun` | `false` | Compta claus i caràcters per idioma; no envia res |
| `--chunkSize` | — | Cadenes per petició; limitat al que accepta el servei |
| `--pluralSeparator` | `\|` | Separador de les formes de plural als missatges |
| `--glossaryFile` | `.i18n-glossary.json` quan existeix | Fitxer de glossari, utilitzat pel servei `ai` |

```bash
i18n-micro translate --dryRun
I18N_TRANSLATE_TOKEN=... i18n-micro translate --service deepl --locale de,fr
i18n-micro translate --service ai --options provider:openai,model:gpt-4o-mini
i18n-micro translate --service libretranslate --options baseUrl:https://translate.example.com
```

### `sync` {#sync}

Elimina les claus que l'idioma per defecte no té; s'atura quan no es pot demostrar que sigui segur. Les claus que falten continuen faltant

| Opció | Per defecte | Descripció |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Directori de traduccions, relatiu al projecte |
| `--ignore` | — | Patrons glob, separats per comes, de fitxers font a ometre, relatius al projecte |
| `--dryRun` | `false` | Llista el que s'eliminaria; no escriu res |
| `--force` | `false` | Elimina claus encara que no es pugui demostrar que sigui segur |

```bash
i18n-micro sync --dryRun
```

### `clean` {#clean}

Elimina les claus que res del projecte utilitza; s'atura quan no es pot demostrar

| Opció | Per defecte | Descripció |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Directori de traduccions, relatiu al projecte |
| `--include` | — | Expressió regular: només es consideren per eliminar les claus que hi coincideixen |
| `--exclude` | — | Expressió regular: mai no s'eliminen les claus que hi coincideixen |
| `--ignore` | — | Patrons glob, separats per comes, de fitxers font a ometre, relatius al projecte |
| `--dryRun` | `false` | Llista el que s'eliminaria; no escriu res |
| `--force` | `false` | Elimina claus encara que no es pugui demostrar l'ús de totes |

```bash
i18n-micro clean --dryRun
i18n-micro clean --exclude '^errors\.'
```

## Refactorització {#refactoring}

### `text-to-i18n` {#text-to-i18n}

Substitueix el text escrit directament a les plantilles Vue per crides de traducció, i informa del text escrit directament al codi

| Opció | Per defecte | Descripció |
| --- | --- | --- |
| `--translationFile` | `<translationDir>/<defaultLocale>.json` | Fitxer on van les claus noves |
| `--path` | tot el projecte | Fitxer o directori a processar |
| `--context` | — | Prefix per a les claus generades |
| `--ignore` | — | Patrons glob, separats per comes, de fitxers font a ometre, relatius al projecte |
| `--dryRun` | `false` | Mostra el que canviaria; no escriu res |
| `--interactive` | `false` | Confirma o edita cada clau generada |

```bash
i18n-micro text-to-i18n --dryRun
i18n-micro text-to-i18n --path components --context ui
```

### `rename` {#rename}

Reanomena una clau o un espai de noms a tots els idiomes i als fitxers font

| Opció | Per defecte | Descripció |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Directori de traduccions, relatiu al projecte |
| `--from` **\*** | — | Clau o espai de noms actual |
| `--to` **\*** | — | Clau o espai de noms nou |
| `--ignore` | — | Patrons glob, separats per comes, de fitxers font a ometre, relatius al projecte |
| `--dryRun` | `false` | Informa dels canvis; no escriu res |

**\*** obligatori.

```bash
i18n-micro rename --from common.save --to actions.save
```

### `pseudo` {#pseudo}

Omple un idioma amb pseudotraduccions per trobar problemes de disseny i de text escrit directament

| Opció | Per defecte | Descripció |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Directori de traduccions, relatiu al projecte |
| `--sourceLocale` | l'idioma per defecte | Idioma a llegir |
| `--targetLocale` **\*** | — | Idioma a omplir |
| `--replace` | `false` | Sobreescriu els valors existents |

**\*** obligatori.

### `format` {#format}

Reescriu els fitxers d'idioma amb les claus ordenades i un sagnat uniforme

| Opció | Per defecte | Descripció |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Directori de traduccions, relatiu al projecte |
| `--indent` | `2` | Espais de sagnat |
| `--sortKeys` | `true` | Ordena les claus; utilitzeu --no-sortKeys per mantenir-ne l'ordre |
| `--check` | `false` | Falla si un fitxer canviaria; no escriu res |

```bash
i18n-micro format --check
```

## Intercanvi {#exchange}

### `export` {#export}

Exporta els fitxers d'idioma a PO o CSV, amb el text de l'idioma per defecte com a font

| Opció | Per defecte | Descripció |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Directori de traduccions, relatiu al projecte |
| `--format` | `po` | Format de fitxer: po, csv |
| `--dir` | `pots` per a po, `csv_exports` per a csv | Directori de sortida, relatiu al projecte |
| `--force` | `false` | Sobreescriu fitxers modificats des de l'última exportació i mai importats |

```bash
i18n-micro export --format csv
```

### `import` {#import}

Fusiona fitxers PO o CSV amb els fitxers d'idioma

| Opció | Per defecte | Descripció |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Directori de traduccions, relatiu al projecte |
| `--format` | `po` | Format de fitxer: po, csv |
| `--dir` | `pots` per a po, `csv_exports` per a csv | Directori d'entrada, relatiu al projecte |
| `--dryRun` | `false` | Informa del que s'importaria; no escriu res |

```bash
i18n-micro import --format csv --dryRun
```

### `sync-remote` {#sync-remote}

Baixa les traduccions globals del punt d'accés HTTP de .i18n-remote.json, o les hi puja

| Opció | Per defecte | Descripció |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` de nuxt.config | Directori de traduccions, relatiu al projecte |
| `--pull` | `true` | Baixa des del remot |
| `--push` | `false` | Puja al remot |
| `--force` | `false` | En baixar, pren el valor remot; en pujar, sobreescriu el text que només té el remot |
| `--dryRun` | `false` | Informa del que canviaria una baixada; no escriu ni puja res |

```bash
i18n-micro sync-remote --dryRun
i18n-micro sync-remote --no-pull --push
```

## Regles de lint {#lint-rules}

| Regla | Detecta | Corregit per `--fix` |
| --- | --- | --- |
| `no-trailing-spaces` | Espais al final d'un valor o d'una línia | sí |
| `no-multiple-spaces` | Dos o més espais seguits | sí |
| `no-empty-translation` | Un valor buit o en blanc | no |

## Codis de sortida {#exit-codes}

| Codi | Significat |
| --- | --- |
| `0` | Fet, res a informar |
| `1` | Troballes: `check`, `lint` o `format --check` han trobat alguna cosa, `clean` o `sync` no han pogut demostrar que una eliminació sigui segura, `export` sobreescriuria feina no importada, `translate` ha deixat claus fora, `import` o `sync-remote` han trobat un conflicte, una pujada de `sync-remote` descartaria text remot. Un `--dryRun` de `clean`, `sync` o d'una baixada de `sync-remote` n'informa i surt amb `0` |
| `2` | Error: ús incorrecte, projecte il·legible, error de xarxa o de fitxer |

## Fitxers de configuració {#configuration-files}

| Fitxer | Utilitzat per |
| --- | --- |
| `.i18n-lintrc.json` | `lint`: `enabledRules`, `disabledRules`, `customRegexRules` (`name`, `pattern`, `flags`, `description`, `replacement`) |
| `.i18n-remote.json` | `sync-remote`: `url`, `path`, `token`, `auth` (`username`, `password`). `type` es pot ometre; només existeix `custom` |
| `.i18n-glossary.json` | `translate --service ai`: `entries` de `source`, `target` i, opcionalment, `from`, `to` |

## Variables d'entorn {#environment-variables}

| Nom | S'utilitza per a |
| --- | --- |
| `I18N_TRANSLATE_TOKEN` | Clau d'API de `translate`. També es llegeix de `.env` |
| `I18N_REMOTE_TOKEN` | Token Bearer de `sync-remote`. També es llegeix de `.env` |
| `AI_GATEWAY_API_KEY, OPENAI_API_KEY, ANTHROPIC_API_KEY` | Clau del servei `ai`, quan `I18N_TRANSLATE_TOKEN` no està definida |
| `DEFAULT_LOCALE` | Substitueix `defaultLocale`, com al mòdul |
