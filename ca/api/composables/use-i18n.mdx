# 🛠️ Composable `useI18n`

El composable `useI18n` de `Nuxt I18n Micro` proporciona accés a la majoria d'ajudants d'i18n de temps d'execució a components i scripts. Els mètodes estan disponibles **amb i sense el prefix `$`** (per exemple, `$t` i `t`).

Algunes injeccions, `$defineI18nRoute` i `$clearCache`, només estan disponibles a `useNuxtApp()`. Consulta [Mètodes — `$defineI18nRoute`](/api/methods#definei18nroute) i [`$clearCache`](/api/methods#clearcache).

## 📊 Què retorna

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Cada ajudant de temps d'execució, com a objecte pla.

Les mateixes funcions que el plugin injecta com a `$t`, `$tc`, etc., disponibles tant sota el nom amb prefix de dòlar com sota un àlies nu. Així, tant `const \{ t \} = useI18n()` com `const \{ $t \} = useI18n()` funcionen.

**Retorna**: els ajudants descrits a la [referència de mètodes](/api/methods).

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

Cada ajudant que retorna (`$t`, `$tc`, `$has`, `$switchLocale` i la resta) es llista amb la seva signatura i es documenta a fons a la [referència de mètodes](/api/methods).

## API només de `useNuxtApp()`

Aquests **no** els retorna `useI18n()`. Importa'ls des de `useNuxtApp()`:

| Mètode                     | Finalitat                                                                       |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Rutes de locale, restriccions i traduccions en línia per pàgina a `script setup`. |
| `$clearCache()`            | Buida la memòria cau de traduccions en memòria i els fragments carregats.       |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Consulta [Mètodes](/api/methods) per veure les signatures i exemples complets.

## 🛠️ Exemples d'ús

### Obtenció bàsica del locale

Obtén el locale actual de l'aplicació.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Traducció amb paràmetres

Tradueix una cadena amb paràmetres dinàmics, amb un valor per defecte de reserva.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Canvi de locale

Canvia l'aplicació a un locale diferent.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Generació d'una ruta localitzada

Genera una ruta localitzada al locale actual o especificat.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
