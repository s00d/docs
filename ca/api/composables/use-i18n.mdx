# 🛠️ Composable `useI18n`

El composable `useI18n` de `Nuxt I18n Micro` proporciona accés a la majoria dels helpers de runtime d'i18n en components i scripts. Els mètodes estan disponibles **amb i sense el prefix `$`** (per exemple, `$t` i `t`).

Algunes injeccions —`$defineI18nRoute` i `$clearCache`— només estan disponibles a `useNuxtApp()`. Vegeu [Mètodes — `$defineI18nRoute`](/api/methods#definei18nroute) i [`$clearCache`](/api/methods#clearcache).

## 📊 Què retorna

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Cada helper de runtime, com un objecte pla.

Les mateixes funcions que el plugin injecta com a `$t`, `$tc`, etc., disponibles tant
amb el nom prefixat amb el dòlar com amb un àlies sense prefix — així que
`const \{ t \} = useI18n()` i `const \{ $t \} = useI18n()` funcionen tots dos.

**Retorna** — els helpers descrits a la [referència de mètodes](/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

Cada helper que retorna — `$t`, `$tc`, `$has`, `$switchLocale` i la resta — està llistat
amb la seva signatura i documentat íntegrament a la [Referència de mètodes](/api/methods).

## APIs només de `useNuxtApp()`

Aquestes **no** les retorna `useI18n()`. Importa-les des de `useNuxtApp()`:

| Mètode                     | Propòsit                                                                         |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Rutes de locale per pàgina, restriccions i traduccions inline a `script setup` |
| `$clearCache()`            | Neteja la memòria cau de traduccions i els chunks carregats                     |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Consulta [Mètodes](/api/methods) per a les signatures completes i exemples.

## 🛠️ Exemples d'ús

### Obtenció bàsica del locale

Recupera el locale actual de l'aplicació.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Traducció amb paràmetres

Tradueix una cadena amb paràmetres dinàmics, amb un valor per defecte de reserva.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Canviar de locale

Canvia l'aplicació a un locale diferent.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Generar una ruta localitzada

Genera una ruta localitzada al locale actual o especificat.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
