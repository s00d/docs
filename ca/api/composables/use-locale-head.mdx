# 🌍 Composable `useLocaleHead`

El composable `useLocaleHead` és una utilitat de `Nuxt I18n Micro` que t'ajuda a gestionar atributs SEO i etiquetes meta d'HTML per a rutes localitzades. Genera dinàmicament atributs per al `lang` i `dir` del document HTML i crea etiquetes `meta` i `link` per millorar el SEO del teu contingut localitzat.

## ⚙️ Opcions

```ts
useLocaleHead(options: UseLocaleHeadOptions): { metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }, MetaObject | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

Les etiquetes head SEO per a la ruta actual: alternatives `hreflang` per a cada locale més `x-default`, un enllaç canonical, `og:locale` i `lang`/`dir` a `<html>`.

Només és necessari quan `meta` està desactivat o els valors per defecte necessiten ajust. Amb `meta: true` el mòdul registra les mateixes etiquetes automàticament.

```ts
const head = useLocaleHead({ addSeoAttributes: true })
```

## 🛠️ Valors de retorn

El composable `useLocaleHead` retorna un objecte reactiu i una funció d'actualització que has de cridar quan les dades font canvien. Ambdues formes es troben a la signatura anterior, generada des del codi font.

### `metaObject`

Càrrega útil reactiva del head (html attrs, meta, link) adequada per a `useHead(metaObject)`.

- **Exemple**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

Recalcula `metaObject` en funció de la ruta, el locale i la configuració actuals. Crida'l quan canviïn les entrades. Per exemple, en un canvi de ruta.

- **Exemple**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### Accés a `link` i `meta`

Els arrays `link` i `meta` són accessibles via `metaObject.value`:

- **Exemple**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ Exemples d'ús

### Ús bàsic

Genera atributs head específics del locale amb les opcions per defecte.

```js
const head = useLocaleHead()
```

### Personalitza l'atribut identificador

Fes servir un atribut identificador personalitzat per a les etiquetes generades.

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### Desactivar atributs SEO

Genera atributs head sense afegir etiquetes meta i link relacionades amb SEO.

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### Especifica una URL base

Defineix una URL base personalitzada per a URL canòniques i alternatives.

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 Funcions addicionals

### Etiquetes meta i link SEO

Quan `addSeoAttributes` està activat, el composable genera automàticament les etiquetes següents:

- `og:locale` per al locale actual (`language_TERRITORY`, guió baix). Derivat de `locale.og` o convertit des de `locale.iso` quan és possible.
- `og:url` per a la URL canònica de la pàgina.
- `og:locale:alternate` per a versions d'idiomes alternatius.
- Enllaços `rel="canonical"` i `rel="alternate"` per a optimització SEO.
- Enllaç `hreflang="x-default"` que apunta a la URL del locale per defecte. Això indica als motors de cerca quina URL mostrar als usuaris l'idioma dels quals no coincideix amb cap dels locales definits.

### Locale i direcció dinàmics

El composable determina dinàmicament els atributs `lang` i `dir` en funció del locale de la ruta actual, assegurant que el teu document HTML estigui configurat correctament per a usuaris internacionals.

### Gestió de rutes localitzades

Si les teves rutes estan prefixades amb codis de locale (per exemple, `/en/about`), el composable ajusta intel·ligentment el camí complet per generar URL, garantint que els atributs SEO siguin precisos i rellevants.

Aquest composable simplifica el procés d'optimitzar la teva aplicació Nuxt per a audiències internacionals, assegurant que el teu lloc estigui ben preparat per a motors de cerca i usuaris globals.

## 🛠️ Exemple d'ús

L'exemple següent mostra com fer servir el composable `useLocaleHead` dins d'un component Vue amb la configuració per defecte:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### Explicació del codi

- **Composable `useLocaleHead`**: aquest composable es crida dins de `<script setup>` i retorna un objecte que conté `htmlAttrs`, `meta` i `link`.

- **Etiqueta `<html>`**: els atributs `lang` i `dir` del document HTML es determinen dinàmicament en funció del locale actual i s'apliquen a l'etiqueta `<html>`.

- **Secció `<head>`**:
  - **Etiquetes meta**: es generen etiquetes meta SEO, incloent-hi `og:locale`, `og:url` i etiquetes `rel="canonical"` i `rel="alternate"` per especificar versions d'idioma alternatives de la pàgina.
  - **Etiquetes link**: s'inclouen enllaços canonicals, enllaços a versions d'idioma alternatives i l'enllaç `hreflang="x-default"` (que apunta a la URL del locale per defecte).

- **Secció `<body>`**: aquí es mostra el contingut principal de la pàgina. En aquest exemple, es fan servir una capçalera senzilla i un paràgraf.

### 📝 Notes

1. **Atributs**: els atributs utilitzats (`lang`, `dir`, `rel`, `href`, `hreflang`, `property`, `content`) s'extreuen de l'objecte retornat per `useLocaleHead`.

2. **Generació d'etiquetes SEO**: si l'opció `addSeoAttributes` es defineix a `true`, el composable genera automàticament etiquetes SEO per al locale actual.

3. **URL base**: pots definir la teva URL base personalitzada amb l'opció `baseUrl` per generar correctament enllaços canonicals i alternatius.

Aquest exemple demostra com és fàcil integrar `useLocaleHead` als components de la teva aplicació per garantir atributs SEO correctes i millorar la indexació dels motors de cerca a les pàgines localitzades.

## 🧩 Personalització i cicle de vida

- `useLocaleHead` no s'inscriu als canvis per si mateix. Retorna `metaObject` i `updateMeta`.
- Has de cridar `updateMeta()` quan canviïn les entrades (típicament en un canvi de ruta), per exemple des d'un plugin:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## Quan fer servir `useI18nHead` en lloc

Quan `meta: true` (per defecte), prefereix [`useI18nHead`](/api/composables/use-i18n-head) per a sobreescriptures **per pàgina** (hreflang personalitzat, `og:title` extra, desactivació parcial). Fes servir `useLocaleHead` directament només quan `meta: false` o gestionis `useHead` tu mateix.
