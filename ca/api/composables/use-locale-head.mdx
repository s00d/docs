# 🌍 Composable `useLocaleHead`

El composable `useLocaleHead` és una utilitat de `Nuxt I18n Micro` que t'ajuda a gestionar els atributs SEO i les meta tags HTML per a rutes localitzades. Genera dinàmicament els atributs `lang` i `dir` del document HTML i crea etiquetes `meta` i `link` per millorar el SEO del teu contingut localitzat.

## ⚙️ Opcións

```ts
useLocaleHead(options: UseLocaleHeadOptions): { metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }, MetaObject | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

Les head tags de SEO per a la ruta actual: alternatives `hreflang` per a cada locale més
`x-default`, un enllaç canonical, `og:locale` i `lang`/`dir` a `<html>`.

Només és necessari quan `meta` està desactivat o cal ajustar els valors per defecte — amb `meta: true`
el mòdul registra les mateixes tags per si mateix.

## 🛠️ Valors retornats

El composable `useLocaleHead` retorna un objecte reactiu i una funció d'actualització que hauries de
cridar quan les dades d'origen canvien. Ambdues formes es troben a la signatura anterior, generada a partir del
codi font.

### `metaObject`

Payload reactiu de head (html attrs, meta, link) adequat per a `useHead(metaObject)`.

- **Exemple**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

Recalcula `metaObject` en funció de la ruta actual, el locale i la configuració. Crida'l quan les entrades
canviïn — en un canvi de ruta, per exemple.

- **Exemple**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### Accedir a `link` i `meta`

Les matrius `link` i `meta` són accessibles mitjançant `metaObject.value`:

- **Exemple**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ Exemples d'ús

### Ús bàsic

Genera atributs head específics de locale amb les opcions per defecte.

```js
const head = useLocaleHead()
```

### Personalitzar l'atribut identificador

Utilitza un atribut identificador personalitzat per a les tags generades.

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### Desactivar els atributs SEO

Genera atributs head sense afegir tags meta i link relacionades amb SEO.

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### Especificar una URL base

Estableix una URL base personalitzada per a les URLs canonicals i alternatives.

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 Funcionalitats addicionals

### Tags meta i link de SEO

Quan `addSeoAttributes` està activat, el composable genera automàticament les tags següents:

- `og:locale` per al locale actual (`language_TERRITORY`, amb guió baix). Derivat de `locale.og` o convertit de `locale.iso` quan és possible.
- `og:url` per a la URL canònica de la pàgina.
- `og:locale:alternate` per a versions d'idioma alternatives.
- Enllaços `rel="canonical"` i `rel="alternate"` per a l'optimització SEO.
- Enllaç `hreflang="x-default"` que apunta a l'URL del locale per defecte. Això indica als motors de cerca quina URL mostrar als usuaris l'idioma dels quals no coincideix amb cap dels locales definits.

### Locale i direcció dinàmics

El composable determina dinàmicament els atributs `lang` i `dir` en funció del locale de la ruta actual, garantint que el teu document HTML estigui configurat correctament per a usuaris internacionals.

### Gestió de rutes localitzades

Si les teves rutes tenen prefixos amb codis de locale (per exemple, `/en/about`), el composable ajusta intel·ligentment la ruta completa per generar URLs, garantint que els atributs SEO siguin precisos i rellevants.

Aquest composable simplifica el procés d'optimització de la teva aplicació Nuxt per a audiències internacionals, garantint que el teu lloc estigui ben preparat per a motors de cerca i usuaris globals.

## 🛠️ Exemple d'ús

L'exemple següent demostra com utilitzar el composable `useLocaleHead` dins d'un component Vue amb la configuració per defecte:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### Explicació del codi

- **Composable `useLocaleHead`**: Aquest composable es crida a la secció `<script setup>` i retorna un objecte que conté `htmlAttrs`, `meta` i `link`.

- **Etiqueta `<html>`**: Els atributs `lang` i `dir` del document HTML es determinen dinàmicament en funció del locale actual i s'apliquen a l'etiqueta `<html>`.

- **Secció `<head>`**:
  - **Meta tags**: Es generen meta tags relacionades amb SEO, incloent `og:locale`, `og:url` i tags `rel="canonical"` i `rel="alternate"` per especificar versions d'idioma alternatives de la pàgina.
  - **Link tags**: S'inclouen enllaços canonicals, enllaços a versions d'idioma alternatives i l'enllaç `hreflang="x-default"` (que apunta a l'URL del locale per defecte).

- **Secció `<body>`**: Aquí es mostra el contingut principal de la pàgina. En aquest exemple, s'utilitza una capçalera i un paràgraf simples.

### 📝 Notes

1. **Atributs**: Els atributs utilitzats (`lang`, `dir`, `rel`, `href`, `hreflang`, `property`, `content`) s'extreuen de l'objecte retornat per `useLocaleHead`.

2. **Generació de tags SEO**: Si l'opció `addSeoAttributes` està definida a `true`, el composable genera automàticament tags SEO per al locale actual.

3. **URL base**: Pots definir la teva URL base personalitzada utilitzant l'opció `baseUrl` per generar correctament enllaços canonicals i alternatius.

Aquest exemple demostra com és de fàcil integrar `useLocaleHead` als components de la teva aplicació per garantir uns atributs SEO correctes i millorar la indexació dels motors de cerca de les pàgines localitzades.

## 🧩 Personalització i cicle de vida

- `useLocaleHead` no se subscriu als canvis per si mateix. Retorna `metaObject` i `updateMeta`.
- Hauries de cridar `updateMeta()` quan les entrades canviïn (normalment en un canvi de ruta), per exemple des d'un plugin:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## Quan utilitzar `useI18nHead`

Quan `meta: true` (el valor per defecte), prefereix [`useI18nHead`](/api/composables/use-i18n-head) per a sobreescriptures **per pàgina** (hreflang personalitzat, `og:title` extra, desactivació parcial). Utilitza `useLocaleHead` directament només quan `meta: false` o si gestiones `useHead` per tu mateix.
