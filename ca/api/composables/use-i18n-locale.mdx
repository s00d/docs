# useI18nLocale

Punt d'entrada centralitzat per a la gestió de locale d'i18n.
Combina useState('i18n-locale'), la cookie de locale i les utilitats de sincronització.

## API

| Propietat/Mètode                                | Tipus                               | Descripció                                                                          |
| ----------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| `locale`                                        | `Ref<string \| null>`               | Estat reactiu del locale (`useState('i18n-locale')`)                                 |
| `localeCookie`                                  | `Ref`                               | Cookie de locale (quan l'opció `localeCookie` està activada)                        |
| `hashCookie`                                    | `Ref`                               | Cookie utilitzada quan `hashMode` és actiu                                          |
| `validLocales`                                  | `string[]`                          | Codis de locale habilitats des de la configuració del mòdul (exclou els `disabled`) |
| `getLocale()`                                   | `() => string \| null`              | Locale actual: estat → cookie (o cookie de hash en mode hash)                       |
| `getPreferredLocale()`                          | `() => string \| null`              | Locale de l'estat/cookie **validat** contra `validLocales`, o `null`                |
| `getLocaleWithServerFallback(serverLocale?)`    | `(serverLocale?) => string \| null` | Estat → cookie → context opcional del servidor (utilitzat durant l'inici `no_prefix`) |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string`             | Locale per carregar traduccions: el mode hash prefereix l'estat; altrament, es llegeix de la ruta |
| `resolveInitialLocale(options)`                 | `(options) => string`               | Resol el locale: estat → `serverLocale` → ruta; sincronitza l'estat quan cal        |
| `setLocale(locale)`                             | `(locale: string \| null) => void`  | Estableix el locale i sincronitza amb les cookies                                   |
| `syncLocale(locale)`                            | `(locale: string \| null) => void`  | Sincronitza només les cookies (sense actualitzar l'estat)                           |
| `isValidLocale(locale)`                         | `(locale) => boolean`               | Comprova si la cadena està a `validLocales`                                         |

### Opcións de `resolveInitialLocale`

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

Utilitzat internament pel plugin principal a l'inici. Els plugins personalitzats poden cridar-lo quan implementen fluxos de detecció alternatius.

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

Retorna el locale utilitzat per carregar traduccions i formatar missatges per a un objecte de ruta donat.

## Establir el locale de forma programàtica

Prefereix `useI18nLocale()` en lloc de l'ús directe de `useState('i18n-locale')`:

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
`setLocale()` només actualitza la preferència de locale (estat + cookie). Per recarregar també el context de traducció actiu al client, utilitza `$switchLocale()` des de `useNuxtApp()` o `useI18n()`. Això és especialment important per a `no_prefix`, on l'URL no canvia. Vegeu [FAQ — canviar de locale sense canviar l'URL](/guides/faq#-switch-locale-without-changing-the-url).
</Tip>
