# useI18nLocale

## Signatura

Punt d'entrada centralitzat per a la gestió del locale d'i18n. Combina `useState('i18n-locale')`, la cookie de locale i utilitats de sincronització.

## Ús

```vue
<script setup>
const {
  locale,
  localeCookie,
  hashCookie,
  validLocales,
  getPreferredLocale,
  getLocale,
  getLocaleWithServerFallback,
  getEffectiveLocale,
  resolveInitialLocale,
  setLocale,
  syncLocale,
  isValidLocale,
} = useI18nLocale()

// Set locale (updates state and cookies)
setLocale('de')

// Get current locale (state → cookie)
const current = getLocale()

// Get valid preferred locale
const preferred = getPreferredLocale()
</script>
```

## API

| Propietat/Mètode                                 | Tipus                                | Descripció                                                                          |
| ------------------------------------------------ | ------------------------------------ | ------------------------------------------------------------------------------------ |
| `locale`                                         | `Ref<string \| null>`                | Estat reactiu del locale (`useState('i18n-locale')`).                                |
| `localeCookie`                                   | `Ref`                                | Cookie de locale (quan l'opció `localeCookie` està activada).                        |
| `hashCookie`                                     | `Ref`                                | Cookie utilitzada quan `hashMode` està actiu.                                        |
| `validLocales`                                   | `string[]`                           | Codis de locale actius de la configuració del mòdul (exclou els `disabled`).         |
| `getLocale()`                                    | `() => string \| null`               | Locale actual: estat → cookie (o cookie de hash en mode hash).                       |
| `getPreferredLocale()`                           | `() => string \| null`               | Locale de l'estat/cookie **validat** contra `validLocales`, o `null`.                |
| `getLocaleWithServerFallback(serverLocale?)`     | `(serverLocale?) => string \| null`  | Estat → cookie → context de servidor opcional (usat durant init de `no_prefix`).     |
| `getEffectiveLocale(route, getLocaleFromRoute)`  | `(route, fn) => string`              | Locale per carregar traduccions: en mode hash prefereix l'estat; si no, llegeix de la ruta. |
| `resolveInitialLocale(options)`                  | `(options) => string`                | Resol el locale: estat → `serverLocale` → ruta; sincronitza l'estat quan cal.        |
| `setLocale(locale)`                              | `(locale: string \| null) => void`   | Defineix el locale i sincronitza amb les cookies.                                    |
| `syncLocale(locale)`                             | `(locale: string \| null) => void`   | Sincronitza només les cookies (sense actualitzar l'estat).                           |
| `isValidLocale(locale)`                          | `(locale) => boolean`                | Comprova si la cadena està a `validLocales`.                                         |

### Opcions de `resolveInitialLocale`

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

L'utilitza internament el plugin principal a l'inici. Els plugins personalitzats el poden cridar quan implementen fluxos de detecció alternatius.

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

Retorna el locale utilitzat per carregar traduccions i formatar missatges per a un objecte de ruta donat.

## Definició programàtica del locale

Prefereix `useI18nLocale()` a l'ús directe de `useState('i18n-locale')`:

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
`setLocale()` actualitza la preferència de locale (estat + cookie) només. Per recarregar també el context de traducció actiu al client, fes servir `$switchLocale()` de `useNuxtApp()` o `useI18n()`. Això és especialment important per a `no_prefix`, on la URL no canvia. Consulta [PMF — canviar de locale sense canviar la URL](/guides/faq#-switch-locale-without-changing-the-url).
</Tip>
