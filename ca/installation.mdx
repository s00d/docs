## Requisits

- **Node.js**: 18 o més recent.
- **Nuxt**: 3.x o 4.x.

El mòdul admet tant el layout de projecte de Nuxt 3 (`pages/**/*.vue`) com el layout de Nuxt 4 (`app/pages/**/*.vue`). Les traduccions viuen a l'arrel del projecte per convenció (`locales/`), fins i tot quan s'utilitza el directori `app/` de Nuxt 4.

## Instal·lar el mòdul de Nuxt

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Registra'l a `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Consulta l'[Inici ràpid](/quickstart) per a un recorregut complet o la [Referència de configuració](/guides/configuration) per a totes les opcions.

## Estructura del projecte

Per defecte el mòdul espera:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Els fitxers d'arrel es fusionen en cada fitxer específic de pàgina en temps de compilació. Els fitxers específics de pàgina es creen automàticament si falten durant `nuxt dev`.

## Layout de Nuxt 4

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Per col·locar les traduccions dins d'`app/`, defineix `translationDir: 'app/locales'`.

## Paquets de l'ecosistema

| Paquet | Propòsit |
| --- | --- |
| [`@i18n-micro/vue`](/integrations/vue) | Integració amb Vue 3 (independent, sense Nuxt). |
| [`@i18n-micro/react`](/integrations/react) | Integració amb React. |
| [`@i18n-micro/preact`](/integrations/preact) | Integració amb Preact. |
| [`@i18n-micro/solid`](/integrations/solid) | Integració amb SolidJS. |
| [`@i18n-micro/astro`](/integrations/astro) | Integració amb Astro. |
| [`@i18n-micro/node`](/integrations/nodejs) | Carregador de Node.js al costat del servidor. |
| [`@i18n-micro/types-generator`](/integrations/types-generator) | Genera tipus de TypeScript a partir dels fitxers de traducció. |
| [`@i18n-micro/devtools-ui`](/integrations/devtools-ui) | Panell de DevTools agnòstic al framework. |

Els paquets interns compartits s'inclouen de manera transitiva.

## TypeScript

El mòdul genera tipus ambient per a `useI18n`, `$t` i altres helpers relacionats a partir dels teus fitxers de locale per defecte. Això està activat per defecte (`types: true`).

Per obtenir una tipificació més forta de les claus de traducció, consulta [`@i18n-micro/types-generator`](/integrations/types-generator).
