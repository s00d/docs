# Ús de traduccions als components

Un cop el mòdul està instal·lat i configurat, pots mostrar traduccions cridant `$t('la_teva_clau')` dins les teves plantilles i scripts Vue.

## 1. Fitxers de traducció d'arrel i específics de pàgina

1. Les traduccions **d'arrel** viuen directament sota la carpeta `/locales` (per exemple, `/locales/en.json`, `/locales/fr.json`). En temps de compilació, es fusionen automàticament a cada fitxer específic de pàgina, fent-les disponibles a totes les pàgines.
2. Les traduccions **específiques de pàgina** viuen sota `/locales/pages/...`, coincidint amb l'estructura de la carpeta de pàgines de Nuxt:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. Ús a plantilles amb `$t`

Als teus fitxers `.vue`, pots fer servir `$t` directament a la plantilla:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
`$t` pot retornar **objectes** si la clau apunta a un node JSON imbricat (per exemple, `$t('header')` → `\{ title: "Hi" \}`). A les plantilles això es renderitza com a `[object Object]`. Fes servir `$ts` quan necessitis una cadena garantida, o proporciona una clau més específica com `$t('header.title')`. Consulta [Referència de l'API — $t vs $ts](/api/methods#t) per a més detalls.
</Tip>

## 3. Canvi del locale actual

Per canviar d'idioma a la teva app, pots obtenir `$locale` de `useI18n()` i assignar-li un nou codi:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. Claus imbricades i marcadors

- Les **claus imbricades** fan servir notació amb punt, per exemple `nested.key.deeper`.
- Els **marcadors** et permeten inserir valors dinàmics:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. Consells i bones pràctiques

- **Claus en conflicte**: si un fitxer específic de pàgina conté la mateixa clau que un fitxer d'arrel, la versió específica de pàgina té prioritat (les traduccions d'arrel es fusionen com a base en temps de compilació).
- **Desactivar fitxers de pàgina**: si prefereixes no fer servir traduccions específiques de pàgina, pots definir `disablePageLocales: true` a la teva config de Nuxt. Així, només es fan servir els fitxers `/locales/*.json`.
- **Sense imports directes**: no cal que facis `import \{ useI18n \} from 'nuxt-i18n-micro'`; la funcionalitat d'auto-injecció del mòdul ho gestiona per tu.

Això és tot! Amb aquests passos, pots començar ràpidament a **obtenir traduccions** de fitxers JSON d'arrel o específics de pàgina i **mostrar-les** a la teva aplicació Nuxt fent servir `$t`.

## Recursos addicionals

Per explorar funcionalitats més avançades, assegura't de consultar:

1. **Component `<i18n-t>`**  
   El component `<i18n-t>` és una alternativa potent a `$t`, especialment útil per a situacions que involucren elements imbricats, ús avançat de marcadors i estructures de traducció més complexes.

- **Documentació**: [i18n-t](/api/components/i18n-t)

2. **Composable `useI18n`**  
   El composable `useI18n` ofereix un conjunt complet de funcions i propietats reactives per gestionar traduccions, canvi de locale, formatació i més.

- **Documentació**: [useI18n](/api/composables/use-i18n)
