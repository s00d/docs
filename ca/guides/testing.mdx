# 🧪 Testing del mòdul `Nuxt I18n Micro`

## 📖 Introducció al testing

Provar el mòdul `Nuxt I18n Micro` és crucial per assegurar que les funcionalitats de localització de la teva aplicació funcionen com s'espera. Aquesta documentació et guiarà per la configuració de l'entorn de testing, la creació de configuracions mock per a vitest i l'escriptura de tests per als teus components. Per veure un exemple pràctic, pots consultar el [projecte d'exemple a GitHub](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/test-utils/example).

Consulta [Testing d'estratègies d'enrutament](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/testing-strategies.md) per veure com aquest repositori executa les seves pròpies suites: els projectes Vitest `unit` / `integration` / `e2e`, els fitxers per estratègia (`test/strategies-*.test.ts`) i les regressions de generació.

## 🛠️ Configuració de l'entorn de testing

### 1. Instal·la `@i18n-micro/test-utils`

Primer, has d'instal·lar les utilitats de testing per a `Nuxt I18n Micro`. Aquest paquet proporciona les eines necessàries per mockar i provar les teves configuracions d'i18n.

```bash
npm install @i18n-micro/test-utils --save-dev
```

### 2. Crea un fitxer de configuració mock

A continuació, crea un fitxer per configurar la configuració mock d'i18n. Aquest fitxer es farà servir per mockar les funcions i utilitats d'i18n durant els teus tests.

```typescript
// tests/unit-setup.ts

import { mockNuxtImport } from '@nuxt/test-utils/runtime'
import { vi } from 'vitest'
import { i18nUtils } from '@i18n-micro/test-utils'

export function createFakeI18n() {
  return {
    $getLocale: vi.fn(i18nUtils.getLocale),
    $t: vi.fn(i18nUtils.t),
    $tc: vi.fn(i18nUtils.tc),
    $setLocale: vi.fn(i18nUtils.setLocale),
    $getLocaleName: vi.fn(i18nUtils.getLocaleName),
    $setLocaleName: vi.fn(i18nUtils.setLocaleName),
    $getLocales: vi.fn(i18nUtils.getLocales),
    $setLocales: vi.fn(i18nUtils.setLocales),
    $defaultLocale: vi.fn(i18nUtils.defaultLocale),
    $setDefaultLocale: vi.fn(i18nUtils.setDefaultLocale),
    $getRouteName: vi.fn(i18nUtils.getRouteName),
    $settRouteName: vi.fn(i18nUtils.settRouteName),
    $ts: vi.fn(i18nUtils.ts),
    $tn: vi.fn(i18nUtils.tn),
    $td: vi.fn(i18nUtils.td),
    $has: vi.fn(i18nUtils.has),
    $resolveTranslations: vi.fn(i18nUtils.resolveTranslations),
    $setTranslation: vi.fn(i18nUtils.setTranslation),
    $mergeTranslations: vi.fn(i18nUtils.mergeTranslations),
    $switchLocaleRoute: vi.fn(i18nUtils.switchLocaleRoute),
    $switchLocalePath: vi.fn(i18nUtils.switchLocalePath),
    $switchLocale: vi.fn(i18nUtils.switchLocale),
    $switchRoute: vi.fn(i18nUtils.switchRoute),
    $localeRoute: vi.fn(i18nUtils.localeRoute),
    $localePath: vi.fn(i18nUtils.localePath),
    $setI18nRouteParams: vi.fn(i18nUtils.setI18nRouteParams),
  }
}

mockNuxtImport<() => ReturnType<typeof createFakeI18n>>('useI18n', () => vi.fn(() => createFakeI18n()))

export const setTranslationsFromJson = i18nUtils.setTranslationsFromJson
```

### 3. Configura Vitest

Ara, configura Vitest per fer servir el fitxer de configuració mock i configurar l'entorn de testing.

```typescript
// vitest.config.ts

import { defineVitestConfig } from '@nuxt/test-utils/config'

export default defineVitestConfig({
  test: {
    watch: false,
    setupFiles: ['./tests/unit-setup.ts'],
    include: ['./**/*.spec.ts'],
  },
})
```

## 🧪 Escriptura de tests

### Component d'exemple

Aquest és un exemple d'un component senzill que fa servir el composable `useI18n` per traduir missatges.

```vue
<script setup lang="ts">
const { $t } = useI18n()

const props = defineProps({
  message: {
    type: String,
    default: null,
  },
})

// Test to see that $t works in script setup as well as the template
const message = props.message || $t('defaultMessage')
</script>

<template>
  <div>
    <p>Test from component: {{ $t('welcome') }}</p>
    <p data-testid="message">Test message from props: {{ message }}</p>
  </div>
</template>
```

### Fitxer de test

Ara, escrivim un test per a aquest component.

```typescript
// tests/unit/example.spec.ts

import { describe, it, expect, beforeEach } from 'vitest'
import { mount } from '@vue/test-utils'
import ExampleComponent from '@/components/ExampleComponent.vue'
import fs from 'fs'
import path from 'path'
import { setTranslationsFromJson } from './unit-setup'

describe('ExampleComponent', () => {
  beforeEach(async () => {
    const fileContent = fs.readFileSync(path.join(__dirname, '../../locales/en-GB.json')).toString()
    await setTranslationsFromJson('en', JSON.parse(fileContent))
  })

  it('renders the welcome message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.text()).toContain('Test from component: Welcome')
  })

  it('renders the default message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Default Message')
  })

  it('renders the custom message correctly', () => {
    const wrapper = mount(ExampleComponent, {
      props: {
        message: 'Custom Message',
      },
    })
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Custom Message')
  })
})
```

## 📝 Bones pràctiques per al testing

- **🔧 Mockar les funcions d'i18n:** mocka sempre les funcions d'i18n amb `@i18n-micro/test-utils` per garantir resultats de test consistents i predictibles.
- **⚙️ Fer servir Vitest per als tests unitaris:** Vitest és un framework de testing potent per a aplicacions Vue. Fes-lo servir per escriure tests unitaris per als teus components.
- **📚 Documenta els teus tests:** documenta clarament la finalitat i els resultats esperats de cada test. Això ajudarà a mantenir la claredat i farà més fàcil que altres (o tu mateix en el futur) entenguin els tests.

## 📊 Mètodes d'utilitat d'i18n

A continuació hi ha una taula que descriu tots els mètodes d'utilitat proporcionats per `@i18n-micro/test-utils`.

| Mètode                                          | Descripció                                                                                                                                |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `t(key, params, defaultValue)`                  | Tradueix una clau amb paràmetres opcionals i un valor per defecte.                                                                        |
| `tc(key, params, defaultValue)`                 | Tradueix una clau amb suport de pluralització.                                                                                            |
| `setTranslationsFromJson(locale, translations)` | Carrega traduccions d'un objecte JSON per a un locale concret.                                                                            |
| `getLocale()`                                   | Retorna el locale actual.                                                                                                                 |
| `setLocale(val)`                                | Defineix el locale actual.                                                                                                                |
| `getLocaleName()`                               | Retorna el nom del locale actual.                                                                                                         |
| `setLocaleName(val)`                            | Defineix el nom del locale actual.                                                                                                        |
| `getLocales()`                                  | Retorna la llista de locales disponibles.                                                                                                 |
| `setLocales(val)`                               | Defineix la llista de locales disponibles.                                                                                                |
| `defaultLocale()`                               | Retorna el locale per defecte.                                                                                                            |
| `setDefaultLocale(val)`                         | Defineix el locale per defecte.                                                                                                           |
| `getRouteName()`                                | Retorna el nom de ruta actual.                                                                                                            |
| `settRouteName(val)`                            | Defineix el nom de ruta actual.                                                                                                           |
| `ts(key, params, defaultValue)`                 | Tradueix una clau i retorna el resultat com a cadena.                                                                                     |
| `tn(value, options?)`                           | Formata un nombre amb `Intl.NumberFormatOptions` en línia. Els formats amb nom necessiten la configuració del mòdul i no estan disponibles en aquest ajudant independent. |
| `td(value, options?)`                           | Formata una data amb `Intl.DateTimeFormatOptions` en línia. Els formats amb nom necessiten la configuració del mòdul i no estan disponibles en aquest ajudant independent. |
| `has(key)`                                      | Comprova si existeix una clau de traducció.                                                                                               |
| `resolveTranslations()`                         | Retorna l'arbre de traduccions actiu per al locale i ruta actuals.                                                                        |
| `setTranslation(key, value)`                    | Substitueix el valor a `key` al diccionari actiu (substitució, no fusió).                                                                 |
| `mergeTranslations(newTranslations)`            | Fusiona traduccions al locale actiu en temps d'execució.                                                                                  |

Seguint aquests passos, pots provar efectivament el mòdul `Nuxt I18n Micro` i assegurar que les funcionalitats de localització de la teva aplicació funcionen com s'espera.
