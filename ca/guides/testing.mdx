# 🧪 Testejar el mòdul `Nuxt I18n Micro`

## 📖 Introducció als tests

Testejar el mòdul `Nuxt I18n Micro` és crucial per garantir que les funcionalitats de localització de la teva aplicació funcionin com s'espera. Aquesta documentació et guiarà per la configuració de l'entorn de tests, la creació de configuracions mock per a vitest i l'escriptura de tests per als teus components. Per a un exemple pràctic, pots consultar el [projecte d'exemple a GitHub](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/test-utils/example).

Consulta [Testejar estratègies d'enrutament](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/testing-strategies.md) per veure com aquest repositori executa les seves pròpies suites — els projectes de Vitest `unit` / `integration` / `e2e`, els fitxers per estratègia (`test/strategies-*.test.ts`) i les regressions de generació.

## 🛠️ Configurar l'entorn de tests

### 1. Instal·la `@i18n-micro/test-utils`

Primer, has d'instal·lar les utilitats de tests per a `Nuxt I18n Micro`. Aquest paquet proporciona les eines necessàries per mockejar i testejar les teves configuracions d'i18n.

```bash
npm install @i18n-micro/test-utils --save-dev
```

### 2. Crea un fitxer de configuració mock

A continuació, crea un fitxer per configurar la configuració mock d'i18n. Aquest fitxer s'utilitzarà per mockejar les funcions i utilitats d'i18n durant els teus tests.

```typescript
// tests/unit-setup.ts

import { mockNuxtImport } from '@nuxt/test-utils/runtime'
import { vi } from 'vitest'
import { i18nUtils } from '@i18n-micro/test-utils'

export function createFakeI18n() {
  return {
    $getLocale: vi.fn(i18nUtils.getLocale),
    $t: vi.fn(i18nUtils.t),
    $tc: vi.fn(i18nUtils.tc),
    $setLocale: vi.fn(i18nUtils.setLocale),
    $getLocaleName: vi.fn(i18nUtils.getLocaleName),
    $setLocaleName: vi.fn(i18nUtils.setLocaleName),
    $getLocales: vi.fn(i18nUtils.getLocales),
    $setLocales: vi.fn(i18nUtils.setLocales),
    $defaultLocale: vi.fn(i18nUtils.defaultLocale),
    $setDefaultLocale: vi.fn(i18nUtils.setDefaultLocale),
    $getRouteName: vi.fn(i18nUtils.getRouteName),
    $settRouteName: vi.fn(i18nUtils.settRouteName),
    $ts: vi.fn(i18nUtils.ts),
    $tn: vi.fn(i18nUtils.tn),
    $td: vi.fn(i18nUtils.td),
    $has: vi.fn(i18nUtils.has),
    $resolveTranslations: vi.fn(i18nUtils.resolveTranslations),
    $setTranslation: vi.fn(i18nUtils.setTranslation),
    $mergeTranslations: vi.fn(i18nUtils.mergeTranslations),
    $switchLocaleRoute: vi.fn(i18nUtils.switchLocaleRoute),
    $switchLocalePath: vi.fn(i18nUtils.switchLocalePath),
    $switchLocale: vi.fn(i18nUtils.switchLocale),
    $switchRoute: vi.fn(i18nUtils.switchRoute),
    $localeRoute: vi.fn(i18nUtils.localeRoute),
    $localePath: vi.fn(i18nUtils.localePath),
    $setI18nRouteParams: vi.fn(i18nUtils.setI18nRouteParams),
  }
}

mockNuxtImport<() => ReturnType<typeof createFakeI18n>>('useI18n', () => vi.fn(() => createFakeI18n()))

export const setTranslationsFromJson = i18nUtils.setTranslationsFromJson
```

### 3. Configura Vitest

Ara, configura Vitest per utilitzar el fitxer de configuració mock i preparar l'entorn de tests.

```typescript
// vitest.config.ts

import { defineVitestConfig } from '@nuxt/test-utils/config'

export default defineVitestConfig({
  test: {
    watch: false,
    setupFiles: ['./tests/unit-setup.ts'],
    include: ['./**/*.spec.ts'],
  },
})
```

## 🧪 Escriure tests

### Component d'exemple

Aquí tens un exemple d'un component senzill que utilitza el composable `useI18n` per traduir missatges.

```vue
<script setup lang="ts">
const { $t } = useI18n()

const props = defineProps({
  message: {
    type: String,
    default: null,
  },
})

// Test to see that $t works in script setup as well as the template
const message = props.message || $t('defaultMessage')
</script>

<template>
  <div>
    <p>Test from component: {{ $t('welcome') }}</p>
    <p data-testid="message">Test message from props: {{ message }}</p>
  </div>
</template>
```

### Fitxer de test

Ara, escrivim un test per a aquest component.

```typescript
// tests/unit/example.spec.ts

import { describe, it, expect, beforeEach } from 'vitest'
import { mount } from '@vue/test-utils'
import ExampleComponent from '@/components/ExampleComponent.vue'
import fs from 'fs'
import path from 'path'
import { setTranslationsFromJson } from './unit-setup'

describe('ExampleComponent', () => {
  beforeEach(async () => {
    const fileContent = fs.readFileSync(path.join(__dirname, '../../locales/en-GB.json')).toString()
    await setTranslationsFromJson('en', JSON.parse(fileContent))
  })

  it('renders the welcome message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.text()).toContain('Test from component: Welcome')
  })

  it('renders the default message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Default Message')
  })

  it('renders the custom message correctly', () => {
    const wrapper = mount(ExampleComponent, {
      props: {
        message: 'Custom Message',
      },
    })
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Custom Message')
  })
})
```

## 📝 Bones pràctiques per als tests

- **🔧 Mockeja funcions d'i18n:** Sempre mockeja les funcions d'i18n utilitzant `@i18n-micro/test-utils` per garantir resultats de tests consistents i predictibles.
- **⚙️ Utilitza Vitest per a tests unitaris:** Vitest és un framework de tests potent per a aplicacions Vue. Utilitza'l per escriure tests unitaris per als teus components.
- **📚 Documenta els teus tests:** Documenta clarament el propòsit i els resultats esperats de cada test. Això ajudarà a mantenir la claredat i facilitarà que altres (o tu mateix en el futur) entengueu els tests.

## 📊 Mètodes d'utilitat d'i18n

A continuació hi ha una taula que descriu tots els mètodes d'utilitat proporcionats per `@i18n-micro/test-utils`.

| Mètode                                          | Descripció                                                                                                                                |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `t(key, params, defaultValue)`                  | Tradueix una clau amb paràmetres opcionals i un valor per defecte.                                                                        |
| `tc(key, params, defaultValue)`                 | Tradueix una clau amb suport de pluralització.                                                                                             |
| `setTranslationsFromJson(locale, translations)` | Carrega traduccions des d'un objecte JSON per a un locale específic.                                                                       |
| `getLocale()`                                   | Retorna el locale actual.                                                                                                                  |
| `setLocale(val)`                                | Estableix el locale actual.                                                                                                                |
| `getLocaleName()`                               | Retorna el nom del locale actual.                                                                                                          |
| `setLocaleName(val)`                            | Estableix el nom del locale actual.                                                                                                        |
| `getLocales()`                                  | Retorna la llista de locales disponibles.                                                                                                  |
| `setLocales(val)`                               | Estableix la llista de locales disponibles.                                                                                                |
| `defaultLocale()`                               | Retorna el locale per defecte.                                                                                                             |
| `setDefaultLocale(val)`                         | Estableix el locale per defecte.                                                                                                           |
| `getRouteName()`                                | Retorna el nom de la ruta actual.                                                                                                          |
| `settRouteName(val)`                            | Estableix el nom de la ruta actual.                                                                                                        |
| `ts(key, params, defaultValue)`                 | Tradueix una clau i retorna el resultat com a cadena.                                                                                      |
| `tn(value, options?)`                           | Formata un nombre amb `Intl.NumberFormatOptions` inline. Els formats amb nom necessiten configuració del mòdul i no estan disponibles en aquest helper independent. |
| `td(value, options?)`                           | Formata una data amb `Intl.DateTimeFormatOptions` inline. Els formats amb nom necessiten configuració del mòdul i no estan disponibles en aquest helper independent. |
| `has(key)`                                      | Comprova si existeix una clau de traducció.                                                                                                |
| `resolveTranslations()`                             | Retorna l'arbre de traduccions actiu per al locale i la ruta actuals.                                                                    |
| `setTranslation(key, value)`                    | Reemplaça el valor a `key` al diccionari actiu (reemplaça, no fusiona).                                                                    |
| `mergeTranslations(newTranslations)`              | Fusiona traduccions al locale actiu en temps d'execució.                                                                                   |

Seguint aquests passos, pots testejar efectivament el mòdul `Nuxt I18n Micro` i garantir que les funcionalitats de localització de la teva aplicació funcionin com s'espera.
