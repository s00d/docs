# 🌐 Guia d'integració amb Crowdin

## 📖 Introducció

Integrar Crowdin al teu projecte simplifica el procés de localització i traducció, facilitant la gestió de traduccions entre múltiples idiomes i plataformes. Aquesta guia ofereix un recorregut pas a pas sobre com configurar Crowdin amb el teu projecte, incloent-hi la configuració, la pujada de fonts i la baixada de traduccions.

## 🔧 Instal·lació i configuració

Per començar amb Crowdin, has d'instal·lar el CLI de Crowdin globalment a la teva màquina i inicialitzar-lo al directori del teu projecte.

### 📦 Instal·lació del CLI de Crowdin

Primer, instal·la el CLI de Crowdin globalment amb npm:

```bash
npm install -g @crowdin/cli
```

### 🛠 Inicialització de Crowdin al teu projecte

Inicialitza Crowdin al teu projecte executant:

```bash
crowdin init
```

Aquesta ordre et guiarà pel procés de configuració, incloent-hi la definició de l'ID del projecte, el token de l'API i altres detalls de configuració.

## 🗂️ Guia de configuració

### 📄 Fitxer de configuració de Crowdin (`crowdin.yml`)

El fitxer de configuració de Crowdin (`crowdin.yml`) defineix com es mapegen els fitxers font i on s'han de col·locar les traduccions. A continuació hi ha un exemple de configuració:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Paràmetres de configuració clau

- **`project_id`**: l'ID del teu projecte de Crowdin. Identifica el projecte dins de Crowdin on es gestionen les traduccions.
- **`api_token`**: el token d'API utilitzat per a l'autenticació. Assegura't que aquest token té els permisos correctes per pujar i baixar traduccions.
- **`base_path`**: especifica el directori base dels fitxers font. En aquest exemple, les traduccions s'emmagatzemen al directori `./locales`.
- **`base_url`**: l'URL base de l'API de Crowdin.
- **`preserve_hierarchy`**: quan es defineix a `true`, Crowdin manté l'estructura de carpetes dels teus fitxers font al projecte.

### 📂 Configuració de fitxers

La secció `files` mapeja els teus fitxers font als camins on s'emmagatzemaran les traduccions. Per exemple:

- **Camí font**: defineix la ubicació dels fitxers de traducció originals.
- **Camí de traducció**: especifica on s'emmagatzemaran els fitxers traduïts a Crowdin. Es fan servir marcadors com `%two_letters_code%` per definir dinàmicament el codi d'idioma als camins dels fitxers.

## ⬆️ Pujada de fitxers font a Crowdin

Un cop la teva configuració de Crowdin està definida, pots pujar els teus fitxers font amb l'ordre següent:

```bash
crowdin upload sources
```

Aquesta ordre puja tots els fitxers font especificats a la teva configuració a Crowdin, fent-los disponibles per a la traducció.

## ⬇️ Baixada de traduccions de Crowdin

Un cop s'han completat o actualitzat les traduccions a Crowdin, pots baixar-les al teu projecte amb:

```bash
crowdin download
```

Aquesta ordre obté les últimes traduccions de Crowdin i les desa segons els camins especificats al teu fitxer de configuració.

## ⚙️ Bones pràctiques

### 🔑 Nomenclatura consistent de claus

Assegura't que les claus de traducció siguin consistents a tots els fitxers per evitar confusió i duplicació.

### 🧹 Manteniment regular

Revisa i neteja periòdicament les claus de traducció no utilitzades per mantenir els fitxers organitzats i manejables.

### 🛠 Automatització de pujades i baixades

Integra les ordres del CLI de Crowdin al teu pipeline CI/CD per automatitzar la pujada de fitxers font i la baixada de traduccions, assegurant que les teves traduccions estiguin sempre al dia.

Seguint aquesta guia, podràs integrar Crowdin de manera fluida al teu projecte, garantint un enfocament eficient i organitzat per gestionar els teus esforços d'internacionalització.
