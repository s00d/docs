# 🌐 Guia d'integració amb Crowdin

## 📖 Introducció

Integrar Crowdin al teu projecte agilitza el procés de localització i traducció, facilitant la gestió de traduccions a través de múltiples idiomes i plataformes. Aquesta guia proporciona una explicació pas a pas de com configurar Crowdin amb el teu projecte, incloent la configuració, pujada de fonts i baixada de traduccions.

## 🔧 Instal·lació i configuració

Per començar amb Crowdin, hauràs d'instal·lar el CLI de Crowdin globalment a la teva màquina i inicialitzar-lo dins del directori del teu projecte.

### 📦 Instal·lar el CLI de Crowdin

Primer, instal·la el CLI de Crowdin globalment utilitzant npm:

```bash
npm install -g @crowdin/cli
```

### 🛠 Inicialitzar Crowdin al teu projecte

Inicialitza Crowdin al teu projecte executant:

```bash
crowdin init
```

Aquesta comanda et guiarà pel procés de configuració, incloent l'establiment del teu ID de projecte, token d'API i altres detalls de configuració.

## 🗂️ Guia de configuració

### 📄 Fitxer de configuració de Crowdin (`crowdin.yml`)

El fitxer de configuració de Crowdin (`crowdin.yml`) defineix com es mapegen els teus fitxers font i on s'han de col·locar les traduccions. A continuació hi ha un exemple de configuració:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Paràmetres clau de configuració

- **`project_id`**: El teu ID de projecte de Crowdin. Identifica el projecte dins de Crowdin on es gestionen les traduccions.
- **`api_token`**: El token d'API utilitzat per a l'autenticació. Assegura't que aquest token té els permisos correctes per pujar i baixar traduccions.
- **`base_path`**: Especifica el directori base per als fitxers font. En aquest exemple, les traduccions s'emmagatzemen al directori `./locales`.
- **`base_url`**: L'URL base per a l'API de Crowdin.
- **`preserve_hierarchy`**: Quan es defineix a `true`, Crowdin mantindrà l'estructura de carpetes dels teus fitxers font al projecte.

### 📂 Configuració de fitxers

La secció `files` mapeja els teus fitxers font a les rutes on s'emmagatzemaran les traduccions. Per exemple:

- **Ruta de la font**: Defineix la ubicació dels fitxers de traducció originals.
- **Ruta de la traducció**: Especifica on s'emmagatzemaran els fitxers traduïts a Crowdin. Els placeholders com `%two_letters_code%` s'utilitzen per establir dinàmicament el codi d'idioma a les rutes dels fitxers.

## ⬆️ Pujar fitxers font a Crowdin

Un cop configurat Crowdin, pots pujar els teus fitxers font utilitzant la comanda següent:

```bash
crowdin upload sources
```

Aquesta comanda puja tots els fitxers font especificats a la teva configuració a Crowdin, fent-los disponibles per a la traducció.

## ⬇️ Baixar traduccions de Crowdin

Un cop completades o actualitzades les traduccions a Crowdin, pots baixar-les al teu projecte utilitzant:

```bash
crowdin download
```

Aquesta comanda obté les últimes traduccions de Crowdin i les desa segons les rutes especificades al teu fitxer de configuració.

## ⚙️ Bones pràctiques

### 🔑 Nomenclatura consistent de claus

Assegura't que les claus de traducció siguin consistents a tots els fitxers per evitar confusions i duplicacions.

### 🧹 Manteniment regular

Revisa i neteja periòdicament les claus de traducció no utilitzades per mantenir els teus fitxers organitzats i manejables.

### 🛠 Automatitzar pujades i baixades

Integra les comandes del CLI de Crowdin al teu pipeline de CI/CD per automatitzar la pujada de fitxers font i la baixada de traduccions, garantint que les teves traduccions estiguin sempre actualitzades.

Seguint aquesta guia, podràs integrar Crowdin al teu projecte de manera fluida, garantint un enfocament eficient i organitzat per gestionar els teus esforços d'internacionalització.
