# Exclusió de fitxers estàtics de l'enrutament d'i18n

## Visió general

Per defecte, nuxt-i18n-micro exclou automàticament fitxers estàtics habituals del processament d'enrutament d'i18n. Tanmateix, també pots configurar patrons d'exclusió personalitzats per evitar que camins específics siguin processats pel sistema d'i18n.

## Exclusions integrades

El mòdul exclou automàticament els següents tipus de fitxers i patrons:

- **Sitemaps**: `/sitemap*.xml`, `/sitemap-en.xml`, etc.
- **Fitxers SEO**: `/robots.txt`, `/favicon.ico`
- **Fitxers PWA**: `/manifest.json`, `/sw.js`, `/workbox-*.js`
- **Actius estàtics**: fitxers amb extensions com `.xml`, `.txt`, `.ico`, `.json`, `.js`, `.css`, `.png`, `.jpg`, `.jpeg`, `.gif`, `.svg`, `.woff`, `.woff2`, `.ttf`, `.eot`
- **Camins interns de Nuxt**: qualsevol camí que comenci per `__` (com `/__nuxt/`)

## Patrons d'exclusió personalitzats

Pots definir patrons d'exclusió personalitzats amb l'opció `excludePatterns`:

```typescript
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],

  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'it', iso: 'it-IT' },
    ],
    defaultLocale: 'en',

    // Custom exclusion patterns
    excludePatterns: [
      // String patterns (exact match or prefix)
      '/api/health',
      '/admin',

      // String patterns with wildcards
      '/api/*',
      '/admin/**',

      // Regular expressions
      /^\/api\/v\d+\//,
      /\.(pdf|doc|docx)$/,
    ],
  },
})
```

## Tipus de patrons

### Patrons amb cadenes

- **Coincidència exacta**: `'/api/health'`: coincideix exactament amb `/api/health`.
- **Coincidència de prefix**: `'/admin'`: coincideix amb `/admin` i `/admin/dashboard`.
- **Wildcards**: `'/api/*'`: coincideix amb `/api/users` però no amb `/api/users/123`.
- **Wildcards profunds**: `'/admin/**'`: coincideix amb `/admin/users` i `/admin/users/123`.

### Expressions regulars

Fes servir objectes RegExp per a comparacions de patrons complexes:

```typescript
excludePatterns: [
  /^\/api\/v\d+\//, // API versioned routes
  /\.(pdf|doc|docx)$/, // Document files
  /^\/static\//, // Static directory
  /^\/[a-z]{2}\/api\//, // Localized API routes
]
```

## Casos d'ús

### Fitxers SEO

```typescript
excludePatterns: ['/sitemap.xml', '/sitemap-*.xml', '/robots.txt', '/favicon.ico']
```

### Rutes d'API

```typescript
excludePatterns: ['/api/**', '/graphql', '/webhook/**']
```

### Panells d'administració

```typescript
excludePatterns: ['/admin', '/admin/**', '/dashboard']
```

### Actius estàtics

```typescript
excludePatterns: ['/assets/**', '/static/**', '/uploads/**']
```

## Com funciona

1. **Middleware del servidor**: un middleware Nitro s'executa primer per comprovar els patrons d'exclusió.
2. **Processament de pàgines**: durant la resolució de pàgines, els camins exclosos s'ometen.
3. **Ruta catch-all**: la ruta de reserva comprova les exclusions abans de processar.
4. **Pre-renderització**: els camins exclosos no s'inclouen a les rutes pre-renderitzades.

## Impacte en el rendiment

- Les comprovacions d'exclusió estan optimitzades i s'executen aviat en el cicle de vida de la petició.
- Els patrons integrats fan servir comparació regex eficient.
- Els patrons personalitzats es guarden en memòria cau i es reutilitzen.
- Sobrecàrrega mínima per als camins exclosos.

## Resolució de problemes

### Els fitxers estàtics encara s'intercepten

1. **Comprova la sintaxi del patró**: assegura't que els teus patrons coincideixen exactament amb l'estructura del camí.
2. **Fes servir regex per a patrons complexos**: els wildcards amb cadenes tenen limitacions.
3. **Prova els patrons**: fes servir les eines de desenvolupament del navegador per verificar el camí real de la petició.
4. **Comprova l'ordre**: assegura't que els patrons d'exclusió es defineixen abans d'altres configuracions d'i18n.

### El patró no funciona

```typescript
// ❌ Wrong - this won't work
excludePatterns: ['sitemap.xml']

// ✅ Correct - include leading slash
excludePatterns: ['/sitemap.xml']

// ✅ Better - use regex for flexibility
excludePatterns: [/^\/sitemap.*\.xml$/]
```

### Mode de depuració

Activa el mode de depuració per veure el processament d'exclusions:

```typescript
i18n: {
  debug: true,
  excludePatterns: ['/api/**']
}
```

Això registrarà les decisions d'exclusió a la consola.

## Migració des de solucions temporals

Si feies servir solucions temporals com regles de ruta o middleware, ara pots substituir-les per `excludePatterns`:

```typescript
// ❌ Old workaround
export default defineNuxtConfig({
  routeRules: {
    '/sitemap*.xml': { headers: { 'content-type': 'application/xml' } },
  },
})

// ✅ New approach
export default defineNuxtConfig({
  i18n: {
    excludePatterns: ['/sitemap*.xml'],
  },
})
```

El nou enfocament és més fiable i funciona a múltiples nivells del sistema d'enrutament.
