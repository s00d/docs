# Excloure fitxers estàtics de l'enrutament d'i18n

## Visió general

Per defecte, nuxt-i18n-micro exclou automàticament els fitxers estàtics comuns del processament d'enrutament d'i18n. Tanmateix, també pots configurar patrons d'exclusió personalitzats per evitar que rutes específiques siguin processades pel sistema d'i18n.

## Exclusions integrades

El mòdul exclou automàticament els tipus de fitxers i patrons següents:

- **Sitemaps**: `/sitemap*.xml`, `/sitemap-en.xml`, etc.
- **Fitxers SEO**: `/robots.txt`, `/favicon.ico`
- **Fitxers PWA**: `/manifest.json`, `/sw.js`, `/workbox-*.js`
- **Actius estàtics**: Fitxers amb extensions com `.xml`, `.txt`, `.ico`, `.json`, `.js`, `.css`, `.png`, `.jpg`, `.jpeg`, `.gif`, `.svg`, `.woff`, `.woff2`, `.ttf`, `.eot`
- **Rutes internes de Nuxt**: Qualsevol ruta que comenci per `__` (com `/__nuxt/`)

## Patrons d'exclusió personalitzats

Pots definir patrons d'exclusió personalitzats utilitzant l'opció `excludePatterns`:

```typescript
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],

  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'it', iso: 'it-IT' },
    ],
    defaultLocale: 'en',

    // Custom exclusion patterns
    excludePatterns: [
      // String patterns (exact match or prefix)
      '/api/health',
      '/admin',

      // String patterns with wildcards
      '/api/*',
      '/admin/**',

      // Regular expressions
      /^\/api\/v\d+\//,
      /\.(pdf|doc|docx)$/,
    ],
  },
})
```

## Tipus de patrons

### Patrons de cadena

- **Coincidència exacta**: `'/api/health'` - coincideix exactament amb `/api/health`
- **Coincidència per prefix**: `'/admin'` - coincideix amb `/admin` i `/admin/dashboard`
- **Comodins**: `'/api/*'` - coincideix amb `/api/users` però no amb `/api/users/123`
- **Comodins profunds**: `'/admin/**'` - coincideix amb `/admin/users` i `/admin/users/123`

### Expressions regulars

Utilitza objectes RegExp per a la coincidència de patrons complexes:

```typescript
excludePatterns: [
  /^\/api\/v\d+\//, // API versioned routes
  /\.(pdf|doc|docx)$/, // Document files
  /^\/static\//, // Static directory
  /^\/[a-z]{2}\/api\//, // Localized API routes
]
```

## Casos d'ús

### Fitxers SEO

```typescript
excludePatterns: ['/sitemap.xml', '/sitemap-*.xml', '/robots.txt', '/favicon.ico']
```

### Rutes d'API

```typescript
excludePatterns: ['/api/**', '/graphql', '/webhook/**']
```

### Panells d'administració

```typescript
excludePatterns: ['/admin', '/admin/**', '/dashboard']
```

### Actius estàtics

```typescript
excludePatterns: ['/assets/**', '/static/**', '/uploads/**']
```

## Com funciona

1. **Middleware del servidor**: Un middleware de Nitro s'executa primer per comprovar els patrons d'exclusió
2. **Processament de pàgina**: Durant la resolució de la pàgina, les rutes excloses s'ometen
3. **Ruta catch-all**: La ruta de fallback comprova les exclusions abans de processar
4. **Prerenderització**: Les rutes excloses no s'inclouen a les rutes prerenderitzades

## Impacte de rendiment

- Les comprovacions d'exclusió estan optimitzades i s'executen aviat al cicle de vida de la petició
- Els patrons integrats utilitzen coincidència de regex eficient
- Els patrons personalitzats es guarden a la memòria cau i es reutilitzen
- Sobrecàrrega de rendiment mínima per a les rutes excloses

## Resolució de problemes

### Els fitxers estàtics continuen sent interceptats

1. **Comprova la sintaxi del patró**: Assegura't que els teus patrons coincideixin amb l'estructura de ruta exacta
2. **Utilitza regex per a patrons complexos**: Els comodins de cadena tenen limitacions
3. **Prova els patrons**: Utilitza les eines de desenvolupament del navegador per verificar la ruta de la petició real
4. **Comprova l'ordre**: Assegura't que els patrons d'exclusió es defineixin abans que altra configuració d'i18n

### El patró no funciona

```typescript
// ❌ Wrong - this won't work
excludePatterns: ['sitemap.xml']

// ✅ Correct - include leading slash
excludePatterns: ['/sitemap.xml']

// ✅ Better - use regex for flexibility
excludePatterns: [/^\/sitemap.*\.xml$/]
```

### Mode de depuració

Activa el mode de depuració per veure el processament d'exclusions:

```typescript
i18n: {
  debug: true,
  excludePatterns: ['/api/**']
}
```

Això registrarà les decisions d'exclusió a la consola.

## Migració de solucions alternatives

Si utilitzaves solucions alternatives com regles de ruta o middleware, ara pots substituir-les per `excludePatterns`:

```typescript
// ❌ Old workaround
export default defineNuxtConfig({
  routeRules: {
    '/sitemap*.xml': { headers: { 'content-type': 'application/xml' } },
  },
})

// ✅ New approach
export default defineNuxtConfig({
  i18n: {
    excludePatterns: ['/sitemap*.xml'],
  },
})
```

El nou enfocament és més fiable i funciona en múltiples nivells del sistema d'enrutament.
