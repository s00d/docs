### Descripció

Compara **Nuxt pla** (línia base sense un mòdul d'i18n), **i18n-micro** i **`@nuxtjs/i18n` v10.6** sota un perfil de diccionari compartit.

Enfocament: temps de compilació, RSS pic, **codi vs traduccions vs total** desplegable, i comportament del servidor sota Artillery + Autocannon.

### Notes de metodologia

- Les mètriques són **mitjanes de 3 execucions consecutives per fixture** (fixture A ×3, després B ×3, després C ×3, no intercalades).
- Les **traduccions** inclouen JSON de locale sota `locales/` / `_locales/` / `translations/`, tot el que hi ha sota `chunks/raw/` i els fragments de locale corresponents. Informes més antics que mostraven `@nuxtjs/i18n` "translations: 0 B" i una columna "code" enorme comptaven els fragments de missatges com a codi d'aplicació.
- **plain-nuxt** serveix el mateix volum de fulles com a JSON estàtic de `public/translations` (no imports JS estàtics). Sota Artillery, aquesta línia base té molta I/O; no és "sobrecàrrega d'i18n", és el cost d'obtenir JSON grans per petició.

### Execucions

Totes les mètriques següents són **mitjanes entre 3 execucions**.
