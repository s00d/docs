# 🔄 Migració de `nuxt-i18n` a `Nuxt I18n Micro`

## Quina guia necessites?

| Estàs migrant des de…                  | Guia                                             |
| -------------------------------------- | ------------------------------------------------ |
| `@nuxtjs/i18n` (mòdul basat en vue-i18n) | **Aquesta pàgina**                            |
| `nuxt-i18n-micro` v2.x                 | [Actualització de v2.x a v3.x](/migration/v2-to-v3) |

## Per què migrar?

- **Rendiment millorat**: ~51% més ràpid en les compilacions i ~54% menys memòria de compilació vs `@nuxtjs/i18n` **v10.6** als nostres [fixtures de benchmark](/guides/performance-results)
- **Configuració simplificada**: Configuració racionalitzada amb valors per defecte sensats
- **Millor gestió de recursos**: Gestió optimitzada de fitxers de traducció grans

## Diferències clau

| Funcionalitat            | `nuxt-i18n`                      | `Nuxt I18n Micro`                         |
| ----------------------- | -------------------------------- | ----------------------------------------- |
| Fitxers de traducció    | JS/TS/JSON, carregats via `vueI18n` | Només JSON, autogenerats en dev        |
| Generació de rutes      | En temps d'execució              | En temps de compilació (`@i18n-micro/route-strategy`) |
| Càrrega de traduccions  | Empaquetada al JS                | JSON carregat de manera diferida per pàgina |
| Estat del locale        | `useI18n()` de `vue-i18n`        | Composable `useI18nLocale()`              |
| `detectBrowserLanguage` | Admès                            | Utilitza `autoDetectLanguage` en el seu lloc |

## Pas a pas

### 1. Instal·lar

```bash
npm install nuxt-i18n-micro
```

### 2. Actualitzar la configuració

**Abans (nuxt-i18n):**

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'fr', iso: 'fr-FR' },
    ],
    defaultLocale: 'en',
    vueI18n: './i18n.config.js',
    detectBrowserLanguage: { useCookie: true },
  },
})
```

**Després (Nuxt I18n Micro v3):**

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
    localeCookie: 'user-locale',
    autoDetectLanguage: true,
  },
})
```

### 3. Reorganitzar els fitxers de traducció

Mou les traduccions al directori `locales` en format JSON. Aquí hi ha una comparació completa del projecte:

**Before (`nuxt-i18n`):**

```text
my-app/
├── i18n/
│   └── locales/          # langDir
│       ├── en.json       # all translations in one file
│       ├── ru.json
│       └── de.json
├── pages/
│   ├── index.vue
│   └── page.vue
├── server/
│   └── tsconfig.json
├── nuxt.config.ts        # config will change
└── package.json
```

**After (Nuxt I18n Micro):**

```text
my-app/
├── locales/              # translationDir
│   ├── en.json           # root-level translations
│   ├── ru.json
│   ├── de.json
│   └── pages/            # page-specific
│       ├── index/
│       │   ├── en.json
│       │   ├── ru.json
│       │   └── de.json
│       └── page/
│           ├── en.json
│           ├── ru.json
│           └── de.json
├── pages/
│   ├── index.vue         # API changes
│   └── page.vue
├── server/
│   └── tsconfig.json
├── nuxt.config.ts        # new config
└── package.json
```

<Tip>
Missing page-specific translation files are **auto-generated** in development mode — just run `nuxt dev` and the module will create empty JSON files for each page and locale.
</Tip>

### 4. Actualitzar la navegació

```diff
- <nuxt-link :to="{ name: 'index' }">Home</nuxt-link>
+ <NuxtLink :to="$localeRoute({ name: 'index' })">Home</NuxtLink>
+ <!-- or use the built-in component -->
+ <i18n-link :to="{ name: 'index' }">Home</i18n-link>
```

### 5. Actualitzar SEO

Elimina qualsevol configuració manual de SEO de `nuxt-i18n`. Nuxt I18n Micro genera automàticament `hreflang`, URLs canonicals i tags d'Open Graph quan `meta: true` està definit.

### 6. Provar

Prova a fons les traduccions, el canvi de locale, les redireccions i els meta tags de SEO.

---

## 🛡️ Problemes comuns i resolució

### ❌ Els fitxers de traducció no es carreguen

Assegura't que els fitxers de traducció es trobin al directori correcte i segueixin el format JSON. Verifica que `translationDir` coincideixi amb la ubicació dels teus fitxers.

### ⚠️ Errors de ruta no trobada

Comprova que tots els codis de locale de la matriu `locales` siguin correctes i que les rutes estiguin correctament configurades.

### 🏷️ Meta tags de SEO faltants

Verifica que `meta: true` estigui definit i que cada locale tingui un codi `iso` vàlid.

### 🔄 Desajustos d'hidratació

Si utilitzes l'estratègia `no_prefix`, defineix el locale en un plugin del servidor amb `order: -10` utilitzant `useI18nLocale().setLocale()` per garantir que el servidor i el client estiguin d'acord sobre el locale. Consulta [Detecció d'idioma personalitzada](/guides/custom-language-detection).

### 🍪 Les redireccions no funcionen

Per a les estratègies amb prefix, assegura't que `localeCookie: 'user-locale'` estigui definit. Sense una cookie, el plugin de redirecció del servidor no té manera de recordar el locale preferit de l'usuari a través de les recàrregues de pàgina.
