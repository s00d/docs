title: "Migració des de @nuxtjs/i18n"

---

Aquesta pàgina fa la correspondència d'una aplicació amb `@nuxtjs/i18n` cap a nuxt-i18n-micro: opcions, helpers i estructura de fitxers. Feu-la servir quan canvieu el mòdul en una aplicació existent. Conserveu els vostres URL (els noms de les estratègies són els mateixos) i moveu les traduccions a fitxers JSON per pàgina.

<Tip>

**Esteu actualitzant el mateix nuxt-i18n-micro?** — Vegeu [Actualització](/ca/guide/upgrade).

</Tip>

## Canviar el mòdul {#swap-the-module}

```bash
npm uninstall @nuxtjs/i18n
npm install nuxt-i18n-micro
```

```ts
// nuxt.config.ts — before
export default defineNuxtConfig({
  modules: ['@nuxtjs/i18n'],
  i18n: {
    locales: [
      { code: 'en', language: 'en-US', file: 'en.json' },
      { code: 'de', language: 'de-DE', file: 'de.json' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    langDir: 'locales',
    detectBrowserLanguage: { useCookie: true, cookieKey: 'i18n_redirected', redirectOn: 'root' },
  },
})
```

```ts
// nuxt.config.ts — after
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    translationDir: 'locales',
    localeCookie: 'i18n_redirected',
    autoDetectPath: '/',
  },
})
```

## Opcions {#options}

| `@nuxtjs/i18n` | nuxt-i18n-micro |
| --- | --- |
| `locales[].code` | `locales[].code` |
| `locales[].language` (`iso` abans de la v9) | `locales[].iso` |
| `locales[].name` | `locales[].displayName` |
| `locales[].dir` | `locales[].dir` |
| `locales[].domain` | `locales[].baseUrl` (un origen amb el seu esquema) |
| `locales[].domainDefault` | `locales[].baseDefault` |
| `differentDomains`, `multiDomainLocales` | no calen: `baseUrl` sol ja encamina per host, vegeu [Capes i dominis](/ca/guide/layers#multiple-domains) |
| `locales[].file` / `files`, `langDir`, `lazy` | `translationDir`; els fitxers es troben pel nom i sempre es carreguen per pàgina |
| `defaultLocale`, `strategy` | mateixos noms, mateixos quatre valors |
| `baseUrl` | `metaBaseUrl` |
| `customRoutes: 'config'` + `pages` | `globalLocaleRoutes` |
| `detectBrowserLanguage: false` | `redirects: false` (sense redireccions) o `autoDetectLanguage: false` (ignora la capçalera) |
| `detectBrowserLanguage.useCookie` / `cookieKey` | `localeCookie: '<name>'` (`null` desactiva la galeta) |
| `detectBrowserLanguage.redirectOn: 'root'` | `autoDetectPath: '/'` (per defecte) |
| `detectBrowserLanguage.redirectOn: 'no prefix'` | `autoDetectPath: 'no_prefix'` |
| `detectBrowserLanguage.redirectOn: 'all'` | `autoDetectPath: '*'` |
| Fitxer de configuració `vueI18n` (`fallbackLocale`, `numberFormats`, `datetimeFormats`) | `fallbackLocale`, `numberFormats`, `datetimeFormats` dins d'`i18n` |

No hi ha `alwaysRedirect`: amb una galeta establerta, `/` la segueix a cada visita. La llista completa és a [Opcions del mòdul](/ca/api/module-options); les regles de detecció són a [Detecció del locale](/ca/guide/locale-detection).

## Helpers i composables {#helpers-and-composables}

| `@nuxtjs/i18n` / vue-i18n | nuxt-i18n-micro (plantilla / `useI18n()`) |
| --- | --- |
| `const { t } = useI18n()` | `const { t } = useI18n()`, `$t` a les plantilles |
| `t('key', count)`, `tc` | `$tc('key', count)` |
| `te('key')` | `$has('key')` |
| `n(value, 'currency')`, `d(date, 'short')` | `$tn(value, 'currency')`, `$td(date, 'short')` |
| — | `$tdr(date)`: temps relatiu ("d'aquí a 3 dies") |
| `locale.value` | `$getLocale()` |
| `locales.value` | `$getLocales()` |
| `setLocale('de')` | `$switchLocale('de')` |
| `useLocalePath()('about')` | `$localePath({ name: 'about' })` |
| `useLocaleRoute()` | `$localeRoute()` |
| `useSwitchLocalePath()('de')` | `$switchLocalePath('de')` |
| `useSetI18nParams()` | `$setI18nRouteParams()` |
| `useLocaleHead()` | automàtic amb `meta: true`; [`useLocaleHead`](/ca/composables/useLocaleHead) per a capçaleres personalitzades |
| `defineI18nRoute({ paths: { de: '/ueber-uns' }, locales: [...] })` | `$defineI18nRoute({ localeRoutes: { de: '/ueber-uns' }, locales: [...] })` |
| `<NuxtLinkLocale to="about">` | `<i18n-link :to="{ name: 'about' }">` |
| `<i18n-t>` | `<i18n-t>` (els slots omplen els marcadors `{name}`) |
| `$i18n` a les rutes del servidor | `useTranslationServerMiddleware(event)`, vegeu [Rutes del servidor i API](/ca/guide/server-side-translations) |

`useI18n()` s'importa automàticament. `$defineI18nRoute` ha de mantenir el seu `$`: la compilació llegeix aquesta crida. Tots els helpers: [Mètodes](/ca/api/methods).

## Fitxers de traducció {#translation-files}

Moveu les claus d'un gran fitxer per locale a un fitxer arrel més un fitxer per pàgina:

```text
locales/
├── en.json              # keys used on many pages (nav, footer)
├── de.json
└── pages/
    ├── index/en.json    # keys of pages/index.vue
    └── about/en.json    # keys of pages/about.vue
```

Mantenir-ho tot als fitxers arrel també funciona, i és el primer pas més ràpid. Establiu `disablePageLocales: true` fins que els dividiu. Vegeu [Fitxers de traducció](/ca/guide/translations).

### Sintaxi dels missatges {#message-syntax}

| vue-i18n | nuxt-i18n-micro |
| --- | --- |
| Interpolació amb nom `{name}` | igual |
| `car \| cars` (2 formes: 1 → la primera) | les formes es trien per quantitat a partir de 0: escriviu `no cars \| one car \| {count} cars` |
| Missatges enllaçats `@:other.key` | no compatible: repetiu el text o composeu-lo en codi |
| Modificadors `@.upper:` | no compatible: doneu format en codi o feu servir `<i18n-t>` |
| Escapaments literals `{'@'}` | no calen: només se substitueixen els tokens `{word}` |
| Fitxers de missatges JS/TS | només JSON |

La regla de plural es pot substituir amb l'opció [`plural`](/ca/api/module-options#plural).

## Comprovacions després del canvi {#check-after-the-switch}

- Tots els URL que teníeu continuen resolent-se; els noms de les estratègies coincideixen, i els camins personalitzats passen a `globalLocaleRoutes` o `$defineI18nRoute`.
- `hreflang`, canonical i `og:locale` surten de sèrie amb `meta: true`; elimineu els que hàgiu escrit a mà.
- Un error d'anàlisi de JSON registra el camí del fitxer; una clau que falta registra un avís a la consola del navegador en desenvolupament.
