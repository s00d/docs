Aquesta pàgina porta una aplicació Nuxt de no tenir i18n a tenir una pàgina traduïda amb un selector d'idioma. La necessiteu una sola vegada, a l'inici d'un projecte. Acabareu amb URL localitzades (`/about`, `/de/about`), un fitxer JSON per locale i pàgina, i `$t` a les plantilles.

## Instal·lació {#install}

El mòdul necessita Nuxt 3.18 o posterior (Nuxt 4 també funciona) i Node 20 o posterior.

<CodeGroup>

```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>

## Configurar els locales {#configure-the-locales}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', displayName: 'English' },
      { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
      { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
    ],
    defaultLocale: 'en',
  },
})
```

Aquesta és tota la configuració que necessita una primera aplicació. Els valors per defecte us proporcionen:

- `strategy: 'prefix_except_default'`: el locale per defecte no té prefix (`/about`), els altres sí (`/de/about`). Vegeu [Estratègies d'enrutament](/ca/guide/strategy).
- `translationDir: 'locales'`: els fitxers de traducció es troben a `locales/` a l'arrel del projecte, també amb l'estructura `app/` de Nuxt 4.
- `meta: true`: etiquetes `hreflang`, canònica i `og:locale`, a més de `lang` i `dir` a `<html>`. Vegeu [SEO](/ca/guide/seo).
- Un visitant que obre `/` és enviat a l'idioma que demana el seu navegador (`Accept-Language`). Vegeu [Detecció del locale](/ca/guide/locale-detection).

`iso` és l'etiqueta d'idioma que s'utilitza a les etiquetes SEO; `code` és el que apareix a l'URL. Totes les opcions es llisten a [Opcions del mòdul](/ca/api/module-options).

## Afegir fitxers de traducció {#add-translation-files}

Inicieu el servidor de desenvolupament amb `nuxt dev`. Quan Nuxt resol les pàgines, el mòdul crea un fitxer buit `{}` per a cada locale i pàgina que no en tingui (desactiveu-ho amb [`disableWatcher`](/ca/api/module-options#disablewatcher)):

```text
locales/
├── en.json            # root: keys every page can use
├── de.json
├── fr.json
└── pages/
    ├── index/         # pages/index.vue
    │   ├── en.json
    │   ├── de.json
    │   └── fr.json
    └── about/         # pages/about.vue
        ├── en.json
        ├── de.json
        └── fr.json
```

Ompliu el fitxer arrel i un fitxer de pàgina:

```json
// locales/en.json
{ "nav": { "home": "Home", "about": "About" } }
```

```json
// locales/pages/index/en.json
{ "welcome": "Welcome, {name}!", "items": "no items | one item | {count} items" }
```

Una pàgina veu les claus arrel i les seves pròpies claus; el seu propi fitxer preval en cas de conflicte. Els noms de carpeta segueixen el nom de la ruta (`pages/articles/[id].vue` és `locales/pages/articles-id/`). [Fitxers de traducció](/ca/guide/translations) tracta l'estructura, els fallbacks i la càrrega.

## Utilitzar `$t` en una pàgina {#use-$t-on-a-page}

```vue
<!-- pages/index.vue -->
<script setup lang="ts">
const { t, tc, getLocale } = useI18n()

const title = t('nav.home') // 'Home'
</script>

<template>
  <h1>{{ $t('welcome', { name: 'Ada' }) }}</h1>
  <!-- Welcome, Ada! -->
  <p>{{ $tc('items', 3) }}</p>
  <!-- 3 items -->
  <p>{{ getLocale() }}</p>
  <!-- en -->
</template>
```

- A les plantilles, tots els helpers estan disponibles amb un `$` (`$t`, `$tc`, `$localePath`, …).
- A `<script setup>`, `useI18n()` retorna els mateixos helpers, amb i sense el `$` (`t` i `$t` són una mateixa funció). S'importa automàticament.
- Els marcadors `{name}` s'omplen a partir de l'objecte de paràmetres. Les formes de plural se separen amb `|`; el recompte tria la forma (0, 1 i després l'última per a tot el que sigui superior).

Tots els helpers es llisten a [Mètodes](/ca/api/methods).

## Enllaçar entre pàgines i canviar de locale {#link-between-pages-and-switch-locale}

```vue
<!-- components/AppHeader.vue -->
<template>
  <nav>
    <i18n-link :to="{ name: 'index' }">{{ $t('nav.home') }}</i18n-link>
    <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
    <i18n-switcher />
  </nav>
</template>
```

- [`<i18n-link>`](/ca/components/i18n-link) és un `NuxtLink` que apunta a la pàgina en el locale actual: a `/de`, l'enllaç a about va a `/de/about`.
- [`<i18n-switcher>`](/ca/components/i18n-switcher) és un desplegable amb els locales habilitats; manté el visitant a la mateixa pàgina.
- Per als vostres propis botons, crideu `$switchLocale('de')`, que navega a la pàgina actual en alemany i recorda l'elecció. Per a un `NuxtLink` normal, utilitzeu `$localePath({ name: 'about' })` o `$switchLocalePath('de')`.

## Comprovar-ho {#check-it}

Executeu `nuxt dev` i obriu:

| URL | Mostra |
| --- | --- |
| `/` | Inici en anglès (o una redirecció a `/de` quan el navegador prefereix l'alemany) |
| `/de` | Inici en alemany |
| `/de/about` | Pàgina about en alemany |
| `/en/about` | 404: el locale per defecte no té prefix amb `prefix_except_default` |

Les modificacions als fitxers JSON s'apliquen a la pàgina oberta sense recarregar.
