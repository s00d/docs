[Crowdin](https://crowdin.com/) és una plataforma de traducció: hi pugeu els fitxers del locale per defecte, els traductors treballen a Crowdin i després en descarregueu els altres locales. El mòdul llegeix fitxers JSON simples, de manera que la CLI de Crowdin només necessita un `crowdin.yml` que mapegi correctament `locales/` i `locales/pages/`. No cal canviar cap opció del mòdul.

## Configurar crowdin.yml {#configure-crowdin-yml}

```yml
# crowdin.yml
project_id_env: CROWDIN_PROJECT_ID
api_token_env: CROWDIN_PERSONAL_TOKEN
base_path: ./locales
preserve_hierarchy: true

files:
  - source: /en.json
    translation: /%two_letters_code%.json
  - source: /pages/**/en.json
    translation: /pages/**/%two_letters_code%.json
```

- `en` és el vostre locale per defecte; els seus fitxers són les fonts.
- `project_id_env` / `api_token_env` llegeixen l'ID i el token de variables d'entorn, de manera que no es desa cap secret al repositori.
- `preserve_hierarchy: true` manté les carpetes `pages/<page>/` tal com són.
- El nom del fitxer traduït ha de ser igual al `code` del locale a `nuxt.config.ts`. `%two_letters_code%` serveix per a codis com `de`; per a codis com `pt-BR` feu servir `%locale%`, o mapegeu els codis de Crowdin als vostres amb `languages_mapping`.

## Pujar i descarregar {#upload-and-download}

```bash
npm install -g @crowdin/cli

export CROWDIN_PROJECT_ID=123456
export CROWDIN_PERSONAL_TOKEN=...   # from Crowdin account settings

crowdin upload sources   # push locales/en.json and locales/pages/**/en.json
crowdin download         # write locales/de.json, locales/pages/**/de.json, ...
```

Executeu totes dues ordres a la CI per mantenir els fitxers actualitzats. Els fitxers descarregats arriben al repositori com si s'haguessin editat a mà; la següent compilació o recàrrega en desenvolupament els incorpora.

## Abans de pujar {#before-uploading}

Netegeu primer les fonts perquè els traductors no treballin en claus mortes: [`i18n-micro clean`](/ca/api/cli#clean) elimina les claus no utilitzades, i [`i18n-micro check`](/ca/api/cli#check) informa dels buits després d'una descàrrega. La CLI no té cap integració pròpia amb Crowdin: aquesta pàgina és la manera admesa.
