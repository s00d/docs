---
title: "Estratègies d'encaminament"
description: "Les quatre estratègies d'URL, les rutes localitzades que generen i com enllaçar una pàgina en qualsevol locale."
---

L'opció `strategy` decideix si un locale apareix a la URL i per a quins locales. Trieu-la una sola vegada, abans de publicar URL: canviar-la més endavant canvia tots els enllaços. Llavors el mòdul genera les rutes localitzades en temps de compilació, i `$localePath`, `<i18n-link>` i el selector les llegeixen.

## Les quatre estratègies {#the-four-strategies}

![La pàgina /about en en (per defecte) i de amb cada estratègia; les mateixes URL es detallen al text següent](/images/diagrams/strategies.svg)

**Tipus** `Strategies` · **Per defecte** `'prefix_except_default'`

Estratègia d'encaminament d'URL per als prefixos de locale.

- `'no_prefix'` — cap locale a la URL; el locale es desa en una galeta.
- `'prefix_except_default'` — prefix per a tots els locales excepte el per defecte.
- `'prefix'` — sempre amb prefix, inclòs el locale per defecte.
- `'prefix_and_default'` — com `prefix`, però el locale per defecte també és accessible sense prefix.

URL d'una pàgina `about` amb `defaultLocale: 'en'` i els locales `en`, `de`:

| Estratègia | Anglès | Alemany | No servides |
| --- | --- | --- | --- |
| `prefix_except_default` (per defecte) | `/about` | `/de/about` | `/en` i `/en/about` donen un 404 |
| `prefix` | `/en/about` | `/de/about` | `/about` redirigeix a una URL amb prefix |
| `prefix_and_default` | `/about` i `/en/about` | `/de/about` | — |
| `no_prefix` | `/about` | `/about` | el locale no és a la URL |

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix',
  },
})
```

L'estratègia es fixa en compilar: una sobreescriptura en temps d'execució s'ignora amb un avís ([Sobreescriptures en temps d'execució](/ca/guide/runtime-overrides)).

## Quina triar {#which-one-to-choose}

- **`prefix_except_default`**: la majoria de llocs. Les URL existents sense prefix continuen funcionant per a l'idioma per defecte.
- **`prefix`**: tots els idiomes són iguals; `/` sempre porta a una pàgina d'inici amb prefix.
- **`prefix_and_default`**: necessiteu que funcionin tant `/en/...` com les URL sense prefix, per exemple mentre passeu d'un esquema a l'altre. Les URL sense prefix no es redirigeixen mai.
- **`no_prefix`**: aplicacions darrere d'un inici de sessió, o una URL per pàgina per a tots els idiomes. El locale prové d'una galeta o de `?locale=`. Els cercadors veuen un idioma per URL, de manera que no s'emeten alternatives `hreflang`.

Com es tria el locale per a una URL, i quan es redirigeix un visitant, s'explica a [Detecció del locale](/ca/guide/locale-detection).

## Rutes generades {#generated-routes}

En temps de compilació, cada pàgina rep els registres de ruta que necessita la seva estratègia. Cada registre porta `meta.i18n = { name, locales }`: la pàgina que mostra i els locales que serveix. Els enllaços, els canvis d'idioma i les redireccions es resolen tots a partir d'aquests registres, de manera que una URL que proporciona el mòdul sempre és una que el router serveix.

Els locales que comparteixen la ruta de la pàgina comparteixen un registre, `/:locale(de|fr)/about`. Un locale amb una ruta pròpia rep el seu propi registre, anomenat `localized-<page>-<locale>`:

```ts
// nuxt.config.ts: German has its own path for the about page
i18n: {
  globalLocaleRoutes: { about: { de: '/ueber-uns' } },
}
// prefix_except_default, locales en (default), de, fr:
// about                 /about
// localized-about       /:locale(fr)/about
// localized-about-de    /:locale(de)/ueber-uns
```

Les rutes personalitzades, les llistes de locales per pàgina i l'exclusió d'una pàgina de la localització s'expliquen a [Rutes localitzades](/ca/guide/custom-locale-routes) i [Configuració de pàgina](/ca/guide/per-component-translations). El prefix `localized-` és [`localizedRouteNamePrefix`](/ca/api/module-options#localizedroutenameprefix).

<Warning>

**Els noms de ruta es generen** — No escriviu directament noms `localized-…` a `router.push({ name })`. Passeu el nom propi de la pàgina a `$localeRoute` o a `<i18n-link>`; ells trien el registre correcte.

</Warning>

## Enllaçar una pàgina en un locale {#linking-to-a-page-in-a-locale}

```vue
<script setup lang="ts">
const { localePath, localeRoute, switchLocalePath } = useI18n()

localePath({ name: 'about' }) // '/de/ueber-uns' while the page is German
localePath({ name: 'about' }, 'en') // '/about'
localePath('/about', 'de') // '/de/ueber-uns': a path is read as the page it shows
localeRoute({ name: 'products-id', params: { id: '42' } }, 'de') // resolved route: name, params, fullPath
switchLocalePath('fr') // the current page in French
</script>

<template>
  <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
  <NuxtLink :to="$switchLocalePath('de')">Deutsch</NuxtLink>
</template>
```

- Funcionen tant les rutes amb nom com les rutes per camí. Un camí es compara amb les rutes generades, de manera que s'accepta la forma de qualsevol locale.
- Un locale que no serveix la pàgina (vegeu `locales` a [Configuració de pàgina](/ca/guide/per-component-translations)) enllaça a la pàgina d'inici d'aquell locale en lloc d'una pàgina inexistent.
- Els paràmetres per locale (un slug traduït) passen per `$setI18nRouteParams`, vegeu [Rutes localitzades](/ca/guide/custom-locale-routes).

Les signatures són a [Mètodes](/ca/api/methods).

## Detalls de `no_prefix` {#no_prefix-details}

- [`localeCookie`](/ca/api/module-options#localecookie) és `'user-locale'` per defecte amb `no_prefix`, de manera que l'elecció es manté després de recarregar.
- `$switchLocale('de')` carrega el diccionari alemany i substitueix l'entrada actual de l'historial; la URL no canvia.
- Les rutes personalitzades per locale continuen funcionant: amb `globalLocaleRoutes: { about: { de: '/ueber-uns' } }`, els lectors en alemany reben `/ueber-uns`. Aquesta URL sempre es renderitza en alemany, sigui quina sigui la preferència del visitant, i una pàgina restringida a alguns locales es renderitza en un d'ells. Una ruta que comparteixen diversos locales (`en` i `de` tots dos a `/page/:id`) es renderitza en la preferència quan és un d'ells. La preferència en si es manté: la pàgina següent hi torna.
- [`noPrefixRedirect: true`](/ca/api/module-options#noprefixredirect) redirigeix la ruta original d'una pàgina amb una ruta personalitzada al locale per defecte: cap a la ruta personalitzada del locale del visitant o, si no, cap a la del locale per defecte (`/about` → `/about-us` quan `en` té `/about-us`, → `/ueber-uns` amb la galeta `de`). Un locale sense ruta personalitzada pròpia es queda a la ruta original i s'hi renderitza. Les pàgines amb paràmetres no es redirigeixen.

## Aplicacions sense `pages/` {#apps-without-pages/}

Amb `pages: false` no hi ha rutes de pàgina per localitzar. Feu servir només fitxers de traducció arrel (`disablePageLocales: true`); la detecció, la galeta i `$switchLocale` continuen funcionant. La variant `pages-false` de `test/fixtures/basic` al repositori és una configuració que funciona.
