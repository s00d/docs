---
title: "Substitucions en temps d'execució"
description: "Canvieu el locale per defecte, el locale alternatiu o els locales desactivats per a cada instància d'una mateixa compilació, amb variables d'entorn o runtimeConfig."
---

Les substitucions en temps d'execució permeten que un mateix artefacte de compilació s'executi amb una configuració de locales diferent per a cada entorn o client, sense tornar a compilar. Podeu canviar el locale per defecte, el locale alternatiu i quins locales estan desactivats. L'encaminament, les redireccions, el renderitzat i els helpers del servidor fan servir els valors substituïts, i també ho fa el navegador en una pàgina renderitzada al servidor.

## Establir substitucions amb variables d'entorn {#set-overrides-with-environment-variables}

```bash
NUXT_I18N_DEFAULT_LOCALE=de \
NUXT_I18N_FALLBACK_LOCALE=en \
NUXT_I18N_DISABLED_LOCALES=fr,it \
node .output/server/index.mjs
```

| Variable | Àlies |
| --- | --- |
| `NUXT_I18N_DEFAULT_LOCALE` | `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE` |
| `NUXT_I18N_FALLBACK_LOCALE` | `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE` |
| `NUXT_I18N_DISABLED_LOCALES` (separats per comes) | `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES` |

El servidor les llegeix una sola vegada en arrencar; reinicieu-lo per aplicar un canvi. En una pàgina renderitzada al servidor, el navegador rep els valors resolts del servidor. Amb `ssr: false` no hi ha renderitzat al servidor i el navegador no té entorn: allà només s'aplica `runtimeConfig.public.i18nRuntime`, i el navegador registra els avisos que es descriuen a continuació.

## Establir substitucions a runtimeConfig {#set-overrides-in-runtimeconfig}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

Un valor establert a `runtimeConfig.public.i18nRuntime` té prioritat sobre la variable `NUXT_I18N_*` del mateix camp.

No s'ha de confondre amb la variable `DEFAULT_LOCALE` de temps de compilació, que substitueix `defaultLocale` durant la compilació i no necessita cap suport en temps d'execució.

## Què pot canviar i què no {#what-can-and-cannot-change}

| Opció | En temps d'execució |
| --- | --- |
| `defaultLocale` | Sí amb `prefix` i `no_prefix`. Amb `prefix_except_default` i `prefix_and_default` queda fixat a la compilació (les seves pàgines són les rutes sense prefix); una substitució s'ignora amb un avís. |
| `fallbackLocale` | Sí. |
| `disabledLocales` | S'afegeix als locales desactivats a la compilació; mai no en torna a habilitar cap. El locale per defecte de la compilació no es pot desactivar amb `prefix_except_default` / `prefix_and_default`. |
| `strategy` | No. Una estratègia en temps d'execució s'ignora amb un avís; compileu un artefacte per estratègia. |

Els valors no vàlids mai no trenquen l'aplicació. Cada cas registra un avís per procés de servidor:

- desactivar tots els locales s'ignora;
- un `defaultLocale` que no està habilitat passa al primer locale habilitat;
- un `fallbackLocale` que no està habilitat manté el valor de la compilació si aquest està habilitat; si no, no hi ha locale alternatiu.

## Llegir la configuració efectiva {#read-the-effective-config}

```vue
<script setup lang="ts">
const { $getI18nConfig } = useNuxtApp()
const config = $getI18nConfig() // build config with overrides applied
</script>
```

Tracteu-la com a només de lectura: al servidor la comparteixen totes les peticions i està congelada en desenvolupament; la còpia del navegador no està congelada. Importar la configuració de `#build/i18n.strategy.mjs` dona els valors de la compilació sense substitucions.

## Locales desactivats i fitxers estàtics {#disabled-locales-and-static-files}

Un locale desactivat en temps d'execució respon amb un 404 a les seves rutes i a la seva ruta de càrrega, però els seus fitxers de càrrega continuen a `.output/public/_locales/` i un servidor de fitxers estàtics els retorna. Quan aquests fitxers no han de ser accessibles, desactiveu el locale en temps de compilació amb `disabled: true`.
