---
title: "Exclusió de rutes"
description: "Mantingueu pàgines i fitxers fora de l'encaminament per locale amb excludePatterns i vegeu quines rutes ja estan excloses."
---

Algunes rutes no han de rebre mai un prefix de locale ni una redirecció de locale: una àrea d'administració, una comprovació d'estat, un feed generat. `excludePatterns` les marca, i una llista integrada ja cobreix els elements interns de Nuxt i els fitxers estàtics habituals. Una pàgina exclosa conserva exactament la ruta que heu escrit i continua renderitzant-se amb `$t`.

## Excloure una ruta {#exclude-a-path}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    excludePatterns: [
      '/admin', // /admin and everything below it
      '/preview-*', // glob over the whole path
    ],
  },
})
```

Amb aquesta configuració, `pages/admin/index.vue` només respon a `/admin`; no hi ha `/de/admin`, i `/admin` no es redirigeix mai a `/de/admin`.

## Sintaxi dels patrons {#pattern-syntax}

Els patrons es comparen amb la ruta sense `app.baseURL`:

| Patró | Coincideix | No coincideix |
| --- | --- | --- |
| `'/admin'` | `/admin`, `/admin/users` | `/administrator`, `/de/admin` |
| `'/preview-*'` | `/preview-1`, `/preview-a/b` | `/de/preview-1` |
| `'/file-?'` | `/file-a` | `/file-ab` |
| `/^\/v\d+\//` | `/v2/docs` | `/docs` |

Una cadena sense `*` ni `?` coincideix amb la ruta i amb els segments sencers que hi ha a sota. Amb `*` (qualsevol seqüència de caràcters, barres incloses) o `?` (un caràcter) ha de coincidir amb la ruta sencera. Comenceu sempre les cadenes amb `/`.

## Què ja està exclòs {#what-is-excluded-already}

Aquestes rutes no reben mai rutes de locale ni redireccions, sense cap configuració:

- `/api` i `/_nuxt`, i tot el que hi ha a sota;
- la ruta de traduccions, `/_locales` per defecte ([`apiBaseUrl`](/ca/api/module-options#apibaseurl));
- qualsevol ruta amb un segment que comenci per `__` (`/__nuxt_content`, `/en/__og-image__`);
- `/sitemap*.xml`, `/robots.txt`, `/favicon.ico`, `/apple-touch-icon*.png`, `/manifest.json`, `/sw.js`, `/workbox-*.js`;
- qualsevol ruta l'últim segment de la qual acabi amb una extensió de fitxer estàtic: `xml txt ico json js css png jpg jpeg gif svg webp avif pdf wasm map mp4 webm mp3 zip gz woff woff2 ttf eot`. Els slugs de pàgina amb punts com `/user/john.doe` i les rutes `.html` continuen sent pàgines.

## Què fa una exclusió {#what-an-exclusion-does}

- **Rutes:** no es generen variants localitzades; la pàgina es manté tal com s'ha escrit.
- **Redireccions i 404:** el plugin de redirecció del servidor i el middleware de redirecció del client ignoren la ruta.
- **Prerenderitzat:** les rutes coincidents s'eliminen de la llista de rutes a prerenderitzar.

No impedeix que el middleware i18n del servidor detecti un locale per a la petició, ni impedeix que la pàgina faci servir traduccions. Per mantenir una pàgina localitzada però sense etiquetes SEO, feu servir `disableMeta` ([Configuració de pàgina](/ca/guide/per-component-translations#turn-off-seo-tags)). Per mantenir una pàgina sense localitzar des de `nuxt.config.ts` per ruta, `globalLocaleRoutes: { '/admin': false }` ([Rutes localitzades](/ca/guide/custom-locale-routes#in-nuxt-config)) fa el mateix pel que fa a l'encaminament.
