---
title: "Configuració de pàgina"
description: "Restringiu una pàgina a alguns locales, doneu-li rutes personalitzades, traduccions en línia o cap etiqueta SEO amb $defineI18nRoute."
---

`$defineI18nRoute` defineix les opcions i18n d'una pàgina des de dins de la mateixa pàgina. Feu-lo servir quan una pàgina només existeix en alguns locales, necessita la seva pròpia ruta localitzada, porta algunes traduccions pròpies o no ha de rebre etiquetes hreflang/canonical. El mòdul llegeix la crida en temps de compilació i la incorpora a les rutes generades.

## Restringir una pàgina a alguns locales {#restrict-a-page-to-some-locales}

```vue
<!-- pages/product/index.vue -->
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'de'],
})
</script>
```

Només es generen `/product` i `/de/product` amb l'estratègia per defecte `prefix_except_default`; la pàgina no té cap ruta en cap altre locale. El mateix es pot definir des de `nuxt.config.ts` amb [`routeLocales`](/ca/api/module-options#routelocales).

`$defineI18nRoute` és una injecció de l'aplicació Nuxt, no una macro del compilador: obteniu-la sempre de `useNuxtApp()` i crideu-la amb el `$`. El pas de compilació només reconeix `$defineI18nRoute(`.

## Afegir traduccions en línia {#add-inline-translations}

Passeu un objecte en lloc d'un array. Les seves claus són els locales permesos i els seus valors es fusionen al diccionari de la pàgina per al locale actiu.

```vue
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: {
    en: { greeting: 'Hello' },
    de: { greeting: 'Hallo' },
    fr: {}, // allowed, no inline keys
  },
})
</script>

<template>
  <h1>{{ $t('greeting') }}</h1>
</template>
```

Les traduccions en línia s'inclouen dins del component de pàgina per a tots els locales. Preferiu els [fitxers de traducció de pàgina](/ca/guide/translations) per a qualsevol cosa més gran que unes quantes claus; reserveu les claus en línia per a pàgines i components autònoms.

## Definir rutes localitzades {#set-localized-paths}

```ts
$defineI18nRoute({
  locales: ['en', 'de'],
  localeRoutes: {
    en: '/welcome',
    de: '/willkommen',
  },
})
```

Amb `prefix_except_default` i `defaultLocale: 'en'` això produeix `/welcome` i `/de/willkommen`. Un `path` dins d'un objecte de locale en línia fa el mateix: `locales: { de: { path: '/willkommen' } }`. Els paràmetres dinàmics, les rutes niades i l'alternativa a nivell de configuració es tracten a [Rutes localitzades](/ca/guide/custom-locale-routes).

## Desactivar les etiquetes SEO {#turn-off-seo-tags}

```ts
$defineI18nRoute({
  disableMeta: true, // no hreflang, canonical or og:locale tags on this page
})

$defineI18nRoute({
  disableMeta: ['de'], // only the de version has no tags
})
```

L'alternativa a nivell de configuració és [`routeDisableMeta`](/ca/api/module-options#routedisablemeta). Què són les etiquetes s'explica a la pàgina de [SEO](/ca/guide/seo).

## Què pot llegir la compilació {#what-the-build-can-read}

El pas de compilació troba la crida a cada fitxer de pàgina i n'avalua l'argument sense executar la vostra aplicació. Funciona quan la configuració és:

- un objecte literal (cadenes, arrays, objectes niats, plantilles literals, operadors ternaris sobre `process.env.NODE_ENV`);
- construïda a partir de constants declarades al mateix `<script setup>` (`const locales = ['en', 'de']`, inclosos els operadors de propagació);
- un array d'objectes amb un camp `code` (`[{ code: 'en' }, { code: 'de' }]`).

No pot llegir valors importats d'un altre mòdul, ni res que necessiti la vostra aplicació en temps d'execució (composables, `await`, dades obtingudes). En aquest cas, la compilació registra `Ignored the $defineI18nRoute() config in <file>` i la pàgina conserva els locales i les rutes per defecte.

En temps d'execució, la crida només fusiona les traduccions en línia per al locale actual i les torna a fusionar quan canvia el locale. `locales`, `localeRoutes` i `disableMeta` només tenen efecte mitjançant la compilació, de manera que canviar-los requereix recompilar (el servidor de desenvolupament recompila en desar).
