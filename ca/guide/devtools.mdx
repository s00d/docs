A `nuxt dev`, el mòdul afegeix dues ajudes de depuració: una pestanya **i18n Micro** a Nuxt DevTools per navegar pels fitxers de traducció i editar-los, i un inspector de Vue DevTools per a l'idioma actiu i els diccionaris carregats. Totes dues existeixen només en desenvolupament i no afegeixen res a les compilacions de producció. La pestanya de Nuxt només necessita Nuxt DevTools activat; l'inspector de Vue també necessita l'extensió de navegador Vue DevTools.

## Pestanya de Nuxt DevTools {#nuxt-devtools-tab}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  devtools: { enabled: true }, // the tab is registered only when DevTools are on
})
```

Obriu Nuxt DevTools (`Shift + Alt + D`) i trieu **i18n Micro**. La pestanya mostra:

- tots els fitxers JSON sota `locales/` (arrel i `pages/`) de cada capa, a més dels fitxers arrel d'`additionalTranslationDirs`;
- un editor per fitxer; **Save** torna a escriure el fitxer al disc i el servidor de desenvolupament recarrega les traduccions;
- **Export** / **Import** d'un fitxer com a JSON, i **Stats** amb el recompte de claus i la cobertura de traducció;
- una vista de configuració de les opcions del mòdul resoltes;
- **Translate**, que omple les claus que falten amb un motor de traducció automàtica que configureu a la configuració de la pestanya.

En desar només s'escriuen fitxers `.json` existents dins dels vostres directoris de traducció. Quan un fitxer existeix en diverses capes, s'escriu la còpia del projecte.

## Inspector de Vue DevTools {#vue-devtools-inspector}

Amb l'extensió de navegador Vue DevTools, el mòdul registra un inspector d'i18n (idioma actual, fragment de la ruta, claus carregades) i una línia de temps amb els canvis d'idioma, les càrregues de fragments i les claus que falten.

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    debug: true, // also log every $t / $ts / $tc call on the timeline
    // vueDevtools: false, // turn the inspector off, keep the Nuxt tab
  },
})
```

[`vueDevtools`](/ca/api/module-options) és `true` per defecte. `debug: true` és molt detallat; feu-lo servir en sessions curtes.
