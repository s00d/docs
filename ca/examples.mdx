# 📚 Exemples i ús de Nuxt I18n Micro

Aquesta secció ofereix diversos exemples que mostren com utilitzar `Nuxt I18n Micro` a la teva aplicació Nuxt.js. Veuràs com canviar de locale, com utilitzar els components `<i18n-link>`, `<i18n-switcher>` i `<i18n-t>`, i com gestionar dinàmicament les claus de traducció.

## 🛠️ Configuració bàsica

Aquí tens una configuració bàsica per començar amb `Nuxt I18n Micro`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Canvi de locale

### Canviar locales de forma programàtica

Aquest exemple mostra com canviar de locale de forma programàtica utilitzant botons:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### JSON d'exemple per al canvi de locale

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### Ús del component `<i18n-switcher>`

El component `<i18n-switcher>` proporciona un desplegable per canviar de locale amb etiquetes personalitzables:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 📝 Renderitzar claus dinàmiques a partir dels fitxers de traducció

En alguns escenaris, potser voldràs iterar sobre claus dinàmiques emmagatzemades dins dels teus fitxers de traducció i renderitzar els seus valors condicionalment. L'exemple següent demostra com aconseguir-ho utilitzant `Nuxt I18n Micro`.

### Exemple: Renderitzar claus dinàmiques

Aquest exemple obté una matriu de claus des d'una ruta de traducció específica (en aquest cas, `dynamic`) i itera sobre elles. Es comprova l'existència de cada clau amb `$has` abans de renderitzar el seu valor amb `$t`.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Fitxer de traducció d'exemple (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Exemple: Renderitzar claus dinàmiques a partir d'un objecte

En aquest exemple, gestionem un objecte emmagatzemat dins del teu fitxer de traducció. Obtenim i iterem sobre les claus de l'objecte, renderitzant dinàmicament tant els noms de les claus com els seus valors associats.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Fitxer de traducció d'exemple (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 Utilitzar `<i18n-t>` per a traduccions amb slots i interpolació

El component `<i18n-t>` és útil per renderitzar traduccions amb contingut dinàmic i etiquetes HTML:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### JSON d'exemple per a `<i18n-t>`

```json
{
  "greeting": "Welcome to the page"
}
```

### Amb interpolació

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### JSON d'exemple per a la interpolació

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 Utilitzar `$tc` per a la pluralització

La funció `$tc` de `Nuxt I18n Micro` gestiona la pluralització segons el recompte i la configuració del locale. Això és útil per ajustar dinàmicament missatges que impliquen recomptes, com ara elements, notificacions o altres entitats la quantitat de les quals pot variar.

### Exemple: Utilitzar `$tc` per a la pluralització

En l'exemple següent, mostrem un missatge que indica el nombre de pomes utilitzant `$tc`. La clau de traducció gestiona múltiples formes plurals segons el recompte proporcionat.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### JSON d'exemple per a la pluralització

Aquí tens com definir la traducció al teu fitxer JSON per gestionar diferents formes plurals:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Explicació

- **`$tc('apples', 0)`**: Retorna la primera forma, utilitzada quan el recompte és zero (`"no apples"`).
- **`$tc('apples', 1)`**: Retorna la segona forma, utilitzada quan el recompte és u (`"one apple"`).
- **`$tc('apples', 10)`**: Retorna la tercera forma amb el valor del recompte, utilitzada quan el recompte és dos o més (`"10 apples"`).

### Exemple addicional amb una pluralització més complexa

Si la teva aplicació necessita gestionar regles de pluralització més complexes (per exemple, casos específics per a zero, un, dos, uns quants, molts, altres), pots ampliar les cadenes de traducció en conseqüència:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: Es podria configurar per retornar `"two apples"`.
- **`$tc('apples', 3)`**: Podria retornar `"a few apples"`, segons les regles definides per al recompte.

## 🌐 Utilitzar `$tn` per al format de nombres

La funció `$tn` formata nombres segons el locale actual utilitzant l'API `Intl.NumberFormat`. Això és útil per mostrar nombres d'una manera que coincideixi amb la configuració regional de l'usuari, com ara la moneda, els percentatges o altres formats de nombre.

### Exemple: Utilitzar `$tn` per al format de nombres

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ Utilitzar `$td` per al format de data i hora

La funció `$td` formata dates i hores segons el locale actual utilitzant l'API `Intl.DateTimeFormat`. Això és útil per mostrar dates i hores en formats familiars a l'usuari segons la configuració del seu locale.

### Exemple: Utilitzar `$td` per al format de data i hora

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ Utilitzar `$tdr` per al format de dates relatives

La funció `$tdr` formata dates com a temps relatius (per exemple, "fa 5 minuts", "fa 2 dies") segons el locale actual utilitzant l'API `Intl.RelativeTimeFormat`. Això és útil per mostrar diferències de temps relatives a la data i hora actuals.

### Exemple: Utilitzar `$tdr` per al format de dates relatives

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
