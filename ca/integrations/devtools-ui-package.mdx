`@i18n-micro/devtools-ui` és l'editor de traduccions de la pestanya de Nuxt DevTools, empaquetat com a web component amb un plugin de Vite. Afegiu-lo a un projecte Vue, React, Preact, Solid o Astro per explorar i editar des del navegador, durant el desenvolupament, els fitxers JSON de la vostra carpeta de traduccions. Les aplicacions Nuxt ja el tenen a [Nuxt DevTools](/ca/guide/devtools).

![The DevTools UI: a file tree and an editor with the default-locale text next to each key](/images/devtools/02-translations-editor-dark.webp)

## Configuració {#setup}

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import { i18nDevToolsPlugin } from '@i18n-micro/devtools-ui/vite'

export default defineConfig({
  plugins: [i18nDevToolsPlugin({ translationDir: 'src/locales' })],
})
```

| Opció | Per defecte | Notes |
| --- | --- | --- |
| `translationDir` | `'src/locales'` | Carpeta amb els fitxers JSON, relativa a l'arrel de Vite. |
| `base` | `'/__i18n_api'` | Camí base dels punts d'accés de l'API. |
| `injectButton` | `true` | Afegeix un botó flotant a les pàgines servides mitjançant la transformació d'`index.html` de Vite. Astro no té aquestes pàgines: vegeu més avall. |
| `defaultLocale` | primer fitxer d'idioma de `translationDir` | El retorna `/config`. |
| `fallbackLocale` | `defaultLocale` | El retorna `/config`. |

El plugin només s'executa al servidor de desenvolupament (`apply: 'serve'`); una compilació de producció no en conté res. El botó obre `/__i18n_devtools.html`, que llegeix i desa fitxers mitjançant els punts d'accés del plugin:

| Punt d'accés | Fa |
| --- | --- |
| `GET <base>/translations` | tots els diccionaris de `translationDir`, per camí relatiu |
| `POST <base>/save` | cos `{ file, content }`; sobreescriu un `.json` existent dins de `translationDir`, 403 per a qualsevol altra cosa. Mai no crea cap fitxer |
| `GET <base>/config` | `{ defaultLocale, fallbackLocale, locales, translationDir }`; `locales` prové dels fitxers arrel de `translationDir` |

Els punts d'accés només responen a la pàgina de devtools: una petició des d'un altre origen o amfitrió rep un `403`, i `/save` només accepta `application/json` (`415`). La pàgina s'assabenta dels canvis de fitxers pel socket HMR de Vite.

A Astro, afegiu la integració en lloc del plugin. Afegeix una aplicació a la barra d'eines de desenvolupament:

```ts
// astro.config.mjs
import { defineConfig } from 'astro/config'
import { i18nDevToolsIntegration } from '@i18n-micro/devtools-ui/vite'

export default defineConfig({
  integrations: [i18nDevToolsIntegration({ translationDir: 'src/locales' })],
})
```

Desar només escriu el fitxer. Una aplicació que importa el JSON mitjançant Vite el rep per HMR; perquè les edicions s'apliquin directament a la instància en execució, utilitzeu un pont.

## Pont a una instància en execució {#bridge-to-a-live-instance}

Per incrustar l'editor a la vostra pròpia pàgina i que les edicions s'apliquin a l'instant a la instància en execució, creeu un pont a partir d'un adaptador i passeu-lo a l'element `<i18n-devtools-ui>`:

```ts
import { createBridge, register } from '@i18n-micro/devtools-ui'
import { i18n, locales } from './i18n' // a runtime, React, Preact or Solid instance

register() // defines <i18n-devtools-ui> once

const bridge = createBridge({
  adapter: {
    getRouteCache: () => Object.fromEntries(i18n.storage.translations),
    addTranslations: (locale, content, merge) => i18n.addTranslations(locale, content, merge),
    addRouteTranslations: (locale, route, content, merge) => i18n.addRouteTranslations(locale, route, content, merge),
    subscribe: (cb) => i18n.subscribe(cb),
    getCurrentLocale: () => i18n.locale,
  },
  locales,
  defaultLocale: 'en',
  translationDir: 'src/locales',
})

const el = document.createElement('i18n-devtools-ui') as HTMLElement & { bridge: typeof bridge }
el.bridge = bridge
document.body.append(el)
```

`getRouteCache` ha de retornar els diccionaris amb claus `locale:route` (`en:index`, `en:blog-post`), que és el que conté `i18n.storage.translations`. Per a una instància de Vue, utilitzeu `i18n.global.getRouteCache()` i `i18n.global.subscribeToChanges(cb)`.

`saveTranslation` actualitza primer la instància i després fa un POST a `<base>/save`. Quan no hi ha punt d'accés (una compilació de previsualització estàtica) o no es pot accedir al servidor de desenvolupament, l'edició es conserva a `localStorage`; qualsevol altre error en desar restaura el diccionari anterior i llança una excepció.
