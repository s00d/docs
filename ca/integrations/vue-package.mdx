`@i18n-micro/vue` és un plugin de Vue 3 amb el nucli de traducció de Nuxt I18n Micro: `t()` reactiu, `$t` global, quatre components i un adaptador opcional per a vue-router. Utilitzeu-lo en una aplicació Vue amb Vite o SSR que no estigui construïda amb Nuxt. El model d'instància, el contracte del router i les props dels components es comparteixen amb els altres paquets i es descriuen a [Frameworks](/ca/integrations/overview).

## Instal·lació {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vue
```

```bash npm
npm install @i18n-micro/vue
```

```bash yarn
yarn add @i18n-micro/vue
```

</CodeGroup>

Dependències peer: `vue` `^3.3.0`; `vue-router` `^4.5.1 || ^5.0.0` (opcional, només per a `@i18n-micro/vue/router`). Els tipus publicats necessiten Vue 3.5.5 o posterior amb `skipLibCheck: false`; amb `skipLibCheck: true`, la configuració habitual de les plantilles, també compilen les versions anteriors.

## Configuració {#setup}

```ts
// src/main.ts
import { createApp } from 'vue'
import { createI18n } from '@i18n-micro/vue'
import App from './App.vue'
import en from './locales/en.json'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales: [
    { code: 'en', iso: 'en-US', displayName: 'English' },
    { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
  ],
  defaultLocale: 'en',
})

createApp(App).use(i18n).mount('#app')
```

`locales` i `defaultLocale` són obligatoris per a `useI18n()`: sense ells llança `I18nLocalesKey not provided`. Passeu-los a `createI18n` (com a dalt), a `useI18n({ locales, defaultLocale })`, o mitjançant `app.provide(I18nLocalesKey, …)` i `app.provide(I18nDefaultLocaleKey, …)`.

El plugin registra globalment `I18nT`, `I18nLink`, `I18nGroup` i `I18nSwitcher`, i afegeix `$t`, `$ts`, `$tc`, `$tn`, `$td`, `$tdr`, `$has` i `$i18n` a les plantilles. Fora dels components, la instància és `i18n.global`. La resta d'opcions són a [la instància](/ca/integrations/overview#the-instance); `routeMessages` no està disponible a Vue, utilitzeu `addRouteTranslations`.

## Traduir {#translate}

```vue
<script setup lang="ts">
import { useI18n } from '@i18n-micro/vue'

const { t, tc, tn } = useI18n()
</script>

<template>
  <h1>{{ t('greeting', { name: 'Ada' }) }}</h1>
  <!-- Hello, Ada! -->
  <p>{{ tc('apples', 3) }}</p>
  <!-- 3 apples -->
  <p>{{ $t('nav.home') }} · {{ tn(1234.5) }}</p>
</template>
```

`useI18n()` retorna els mètodes de traducció (`t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`), `locale` (un computed modificable), `getLocale`, `getLocales`, `defaultLocale()`, `getLocaleName`, `localePath`, `localeRoute`, `switchLocale`, `setRoute`, `getRoute`, `addTranslations`, `addRouteTranslations`, `mergeTranslations`, `resolveTranslations`, `setTranslation`, `clearCache` i `instance`.

Podeu carregar més diccionaris en qualsevol moment; tots els components que els llegeixen es tornen a renderitzar:

```ts
const { addTranslations, addRouteTranslations, setRoute } = useI18n()

addTranslations('de', (await import('./locales/de.json')).default)
addRouteTranslations('en', 'about', { title: 'About us' })
setRoute('about') // t('title') now reads the 'about' dictionary first
```

## Canviar d'idioma {#switch-locale}

```ts
const { locale, switchLocale } = useI18n()

locale.value = 'de' // only the locale
switchLocale('de') // the locale, then router.push to the localized current path
```

Carregueu el diccionari de l'idioma abans o després de canviar-lo; el canvi no descarrega res.

`<I18nGroup>` dona al seu slot un `t` amb prefix. Les claus dins de `<I18nT>` o d'un `t()` normal no porten prefix:

```vue
<I18nGroup prefix="profile" v-slot="{ t }">
  <h2>{{ t('title') }}</h2>
  <!-- profile.title -->
</I18nGroup>
```

## Encaminament {#routing}

L'adaptador de vue-router viu en un subcamí perquè el punt d'entrada principal no importi mai `vue-router`:

```ts
// src/main.ts
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import { createI18n } from '@i18n-micro/vue'
import { createVueRouterAdapter } from '@i18n-micro/vue/router'
import App from './App.vue'
import Home from './pages/Home.vue'
import About from './pages/About.vue'
import en from './locales/en.json'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English' },
  { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
]

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/:locale(de)?', component: Home },
    { path: '/:locale(de)?/about', component: About },
  ],
})

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales,
  defaultLocale: 'en',
  routingStrategy: createVueRouterAdapter(router, locales, 'en'),
})

createApp(App).use(router).use(i18n).mount('#app')
```

`createVueRouterAdapter(router, locales, defaultLocale)` afegeix un prefix a tots els idiomes excepte el per defecte (`/about`, `/de/about`) i renderitza `<I18nLink>` com a `RouterLink`. Llegiu vosaltres mateixos l'idioma de la ruta, per exemple a `router.beforeEach`, i definiu `i18n.global.locale.value`. També podeu connectar un adaptador més tard amb `i18n.setRoutingStrategy(adapter)`; per a un adaptador personalitzat, vegeu [Adaptador de router](/ca/integrations/overview#router-adapter).

## SSR {#ssr}

- Creeu el router, la instància i18n i l'aplicació dins de la funció de renderitzat de cada petició. Una sola instància compartida filtraria l'idioma d'un visitant a un altre.
- Utilitzeu `createMemoryHistory()` al servidor, preneu l'idioma de l'URL i carregueu-ne el diccionari (i el de l'idioma alternatiu) abans de `renderToString`.
- Envieu l'idioma al client (per exemple en un script `window.__STATE__`) i creeu la instància del client amb el mateix `locale` perquè la hidratació coincideixi.
- `<I18nSwitcher>` només llegeix `window.location` quan el desplegable està obert, de manera que es renderitza al servidor.

`packages/vue/playground` té un parell complet `entry-server.ts` / `entry-client.ts`.

## Capçalera SEO {#seo-head}

`useLocaleHead(options)` construeix les etiquetes `lang`/`dir`, canonical, `hreflang` i `og:locale` a partir dels idiomes i de l'adaptador de router. Crideu `updateMeta()` quan canviï la ruta i passeu `metaObject` al vostre gestor de capçalera:

```ts
import { watch } from 'vue'
import { useRoute } from 'vue-router'
import { useHead } from '@unhead/vue'
import { useLocaleHead } from '@i18n-micro/vue'

const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
watch(() => route.fullPath, () => updateMeta(), { immediate: true })
useHead(metaObject)
```

Opcions: `baseUrl` (cadena o funció), `addDirAttribute` (per defecte `true`), `addSeoAttributes` (per defecte `true`), `identifierAttribute` (per defecte `'id'`), `hreflangBaseLanguage` (per defecte `false`). Els idiomes amb `disabled: true` o `seo: false` no reben cap enllaç alternatiu.
