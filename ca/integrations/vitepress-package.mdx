`@i18n-micro/vitepress` afegeix diccionaris en temps d'execució a un lloc VitePress: `$t` i `<I18nT>` dins de markdown, funcions auxiliars de rutes i etiquetes SEO, construït sobre [`@i18n-micro/vue`](/ca/integrations/vue-package). Feu-lo servir quan les mateixes cadenes d'interfície apareixen en moltes pàgines i no les voleu duplicar per locale. El locale segueix els locales de ruta propis de VitePress (`/`, `/fr/`).

## Quan fer-lo servir {#when-to-use-it}

| Necessitat | Solució |
|------|----------|
| `.md` duplicats, prefixos d'URL | `locales` de VitePress |
| `$t` en temps d'execució / components / sincronització de rutes / head SEO | `@i18n-micro/vitepress` |
| Etiquetes de la interfície del tema per defecte (`docFooter`, interfície de cerca) | El vostre propi `themeConfig` per locale |

<Tip>

**Playground** — [`packages/vitepress/playground`](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/vitepress/playground) — `pnpm -C packages/vitepress/playground dev`

</Tip>

## Instal·lació {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vitepress
```

```bash npm
npm install @i18n-micro/vitepress
```

```bash yarn
yarn add @i18n-micro/vitepress
```

</CodeGroup>

Dependències peer: `vitepress` `>=1.0.0 || >=2.0.0-alpha.0`, `vue` `^3.3.0`. Els scripts de Node fan servir `@i18n-micro/node`, que s'instal·la amb el paquet i es reexporta mitjançant `/node`. Els tipus publicats necessiten Vue 3.5.5 o posterior amb `skipLibCheck: false`; amb `skipLibCheck: true`, la configuració habitual de les plantilles, també compilen versions anteriors.

## Configuració {#setup}

```
locales/en.json
locales/fr.json
locales/pages/guide/demo/en.json   # optional page-scoped
locales/pages/guide/demo/fr.json
```

Els fitxers de pàgina es corresponen amb noms de ruta de la mateixa manera que a Nuxt/Astro (`guide/demo` → `guide-demo`).

### 1. Configuració — `@i18n-micro/vitepress/config` {#1-config-—-@i18n-micro/vitepress/config}

```ts
// .vitepress/config.mts
import { defineConfig } from 'vitepress'
import { withI18n, buildVitePressLocales } from '@i18n-micro/vitepress/config'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English', og: 'en_US' },
  { code: 'fr', iso: 'fr-FR', displayName: 'Français', og: 'fr_FR' },
]
const defaultLocale = 'en'

export default defineConfig(
  withI18n(
    {
      locales: buildVitePressLocales(locales, defaultLocale),
      // themeConfig.i18nRouting is injected automatically
    },
    {
      locale: defaultLocale,
      defaultLocale,
      locales,
      translationDir: 'locales',
      metaBaseUrl: 'https://example.com', // optional SEO head
    },
  ),
)
```

### 2. Tema — `@i18n-micro/vitepress/theme` {#2-theme-—-@i18n-micro/vitepress/theme}

```ts
// .vitepress/theme/index.ts
import DefaultTheme from 'vitepress/theme'
import { defineI18nTheme } from '@i18n-micro/vitepress/theme'

export default defineI18nTheme(DefaultTheme)
```

El locale inicial es pren de la ruta actual abans de la instal·lació (sense parpelleig del locale per defecte a `/fr/…`).

### Avançat: `createI18n` manual {#advanced-manual-createi18n}

Una sola factoria per al client: plugin de Vue + mètodes de rutes + `enhanceApp` (sense exportacions separades d'auxiliars del router).

```ts
import { createI18n, messagesFromGlob } from '@i18n-micro/vitepress'

const i18n = createI18n({
  locale: 'en',
  defaultLocale: 'en',
  locales: [{ code: 'en' }, { code: 'fr' }],
  messages: messagesFromGlob(import.meta.glob('../../locales/*.json', { eager: true })),
})

i18n.localizePath('/guide', 'fr')
// in theme enhanceApp:
i18n.enhanceApp({ app, router })
```

### Scripts de Node — `@i18n-micro/vitepress/node` {#node-scripts-—-@i18n-micro/vitepress/node}

Fa servir `createI18n` / `loadTranslations` de `@i18n-micro/node` (igual que Astro i la CLI) i després hi afegeix els mètodes de rutes de VitePress amb `BaseI18n.extend`:

```ts
import { createI18n } from '@i18n-micro/vitepress/node'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  translationDir: './locales',
  locales: ['en', 'fr'],
  defaultLocale: 'en',
})
await i18n.loadTranslations()
i18n.t('cta.readMore')
i18n.localizePath('/guide', 'fr')
```

Node pur sense rutes: `import { createI18n } from '@i18n-micro/node'`.

## Traduccions dins de la pàgina {#in-page-translations}

Cada fitxer markdown de VitePress és un SFC de Vue.

### Components globals i `$t` (recomanat a markdown) {#global-components-and-$t-recommended-in-markdown}

`createI18n` / `defineI18nTheme` instal·len `@i18n-micro/vue`, que registra `I18nT` / `I18nLink` / `I18nGroup` / `I18nSwitcher` i `$t` / `$tc` / `$ts`.

```md
{{ $t('cta.readMore') }}

<I18nT keypath="greeting" :params="{ name: 'VitePress' }" />

<I18nLink to="/guide/demo">Demo</I18nLink>
```

### `useI18n` a `<script setup>` {#usei18n-in-<script-setup>}

```md
<script setup>
import { useI18n } from '@i18n-micro/vitepress'
const { t, tc, locale, localePath, switchLocale } = useI18n()
</script>

# {{ t('section.title') }}
```

## Menú desplegable d'idiomes {#language-dropdown}

Quan `locales` té més d'una entrada, VitePress mostra el seu propi menú d'idiomes (`VPNavBarTranslations`). `withI18n` configura `themeConfig.i18nRouting` perquè el globus coincideixi amb `<I18nSwitcher>` / les funcions auxiliars de rutes.

Feu servir `<I18nSwitcher>` només en dissenys personalitzats, no al costat del globus per defecte.

## Notes sobre SSR {#ssr-notes}

- En el prerenderitzat, el locale prové de la ruta de la URL, no de les galetes.
- El codi del tema no ha de tocar `window` en el moment de la importació.
- Importeu `defineI18nTheme` des de `/theme` perquè l'avaluació de la configuració a Node no carregui mai `virtual:i18n-micro/*`.

## Superfície de l'API {#api-surface}

| Exportació | Funció |
|--------|------|
| `createI18n` (`.`) | Client: plugin de Vue + mètodes de rutes + `enhanceApp` |
| `getLocaleFromPath` / `stripSiteBase` / `routeNameFromPath` (`.`) | Sincronització manual del locale quan `syncWithVitePress: false` |
| `createI18n` (`/node`) | Node: `@i18n-micro/node` + mètodes de rutes |
| `defineI18nTheme` (`/theme`) | Tema sense codi repetitiu |
| `withI18n` (`/config`) | Configuració + mòduls virtuals + SEO opcional |
| `buildVitePressLocales` (`/config`) | Construeix els `locales` de VitePress a partir de `Locale[]` |
| `buildVitePressLocaleHead` (`/config`) | Head SEO manual (també el fa servir `metaBaseUrl`) |
| `messagesFromGlob` | Glob opcional → mapa de missatges per a `createI18n` |
| `useI18n` / `I18nT` / … | Reexportats de `@i18n-micro/vue` |
| `BaseI18n.extend` (`@i18n-micro/core`) | Afegeix mètodes personalitzats a qualsevol instància i18n |

## Llocs a l'estil OpenAPI (garanties d'integració) {#openapi-style-sites-integration-locks}

Suite de regressió: `packages/vitepress/tests/integration-openapi.test.ts` (rutes profundes, `base=/openapi_docs/`, sincronització desactivada + locale manual, generadors de Node, SEO).

| Patró | Feu això |
|---------|---------|
| Pàgines profundes `/…/{spec}/{op}`, només JSON d'interfície arrel | Preferiu el valor per defecte `syncWithVitePress: true` (manté `setRoute('index')` quan no hi ha diccionari de pàgina) **o** `syncWithVitePress: false` + `getLocaleFromPath` |
| No crideu mai `setRoute(deepName)` sense diccionaris de pàgina | Les claus d'interfície arrel desapareixen fins a `setRoute('index')` |
| Generadors / `getTranslation` | `createI18n` de `/node` + `await loadTranslations()` + `i18n.t(key)` (definiu `i18n.locale`) |
| Canonical personalitzat a `transformPageData` | Passeu `meta: false` a `withI18n` (eviteu etiquetes duplicades) |
| SEO del paquet amb base del lloc | `metaBaseUrl` + `base` de VitePress → les URL absolutes inclouen la base |
| Canvis de nom respecte a versions anteriors del paquet | `withI18nMicro` → `withI18n`, `createVitePressI18n` → `createI18n`, `loadMessages` → `createI18n` de node |
