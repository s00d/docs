# Integracions

Els paquets `@i18n-micro` són versions lleugeres i específiques de framework de Nuxt I18n Micro dissenyades per a la integració en diversos frameworks i entorns. Aquests paquets proporcionen la funcionalitat bàsica d'internacionalització amb una petjada mínima, centrant-se en funcionalitats essencials de traducció i components bàsics.

## Visió general

Aquests paquets d'integració són **versions en miniatura** del mòdul complet Nuxt I18n Micro, contenint només la funcionalitat essencial necessària per a la internacionalització:

- **Funcionalitats bàsiques de traducció** - Mètodes bàsics de traducció, pluralització i format
- **Components essencials** - Un petit conjunt de components d'UI per a tasques comunes d'i18n
- **Patró d'adaptador de router** - Integració d'enrutament flexible mitjançant l'abstracció d'adaptador
- **Suport de TypeScript** - Definicións de tipus completes per al desenvolupament tipat

A diferència del mòdul complet de Nuxt, aquests paquets:

- No inclouen lògica d'enrutament específica de framework
- Requereixen que implementis un adaptador de router per a funcionalitats d'enrutament
- Se centren en la funcionalitat de traducció més que en la integració amb el framework
- Estan dissenyats per ser lleugers i, quan és possible, agnòstics al framework

## Components bàsics

Tots els paquets de framework inclouen els components essencials següents:

### `<I18nT>`

Un component de traducció que renderitza text traduït amb suport per a:

- **Interpolació de paràmetres** - Reemplaça marcadors amb valors dinàmics
- **Pluralització** - Selecció automàtica de forma plural segons el recompte
- **Format de nombres** - Format de nombres segons el locale
- **Format de dates** - Format de dates i temps relatius
- **Renderització HTML** - Renderització opcional de contingut HTML
- **Valors per defecte** - Text de reserva quan falta una traducció

**Exemple:**

```vue
<!-- Vue -->
<I18nT keypath="greeting" :params="{ name: 'World' }" />
```

```tsx
// React
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```tsx
// Solid
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```astro
<!-- Astro -->
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

### `<I18nLink>`

Un component d'enllaç localitzat que gestiona automàticament els prefixos de locale a les URLs. Funcionalitats:

- **Localització automàtica de rutes** - Afegeix/elimina prefixos de locale segons l'estratègia d'enrutament
- **Detecció d'estat actiu** - Ressalta la ruta actual
- **Suport per a enllaços externs** - Detecta i gestiona automàticament les URLs externes
- **Integració amb router** - Utilitza el component d'enllaç de l'adaptador del router quan està disponible
- **Estilat personalitzat** - Admet estats actius i hover

**Exemple:**

```vue
<!-- Vue -->
<I18nLink to="/about" active-class="active">
  About Us
</I18nLink>
```

```tsx
// React
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```tsx
// Solid
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```astro
<!-- Astro -->
<I18nLink href="/about" class="nav-link">
  About Us
</I18nLink>
```

### `<I18nSwitcher>`

Un component commutador d'idioma que proporciona una interfície de desplegable o llista per canviar de locale. Funcionalitats:

- **Llista automàtica de locales** - Genera opcions a partir dels locales configurats
- **Ressaltat del locale actual** - Indica visualment l'idioma actiu
- **Etiquetes personalitzades** - Suport per a noms de visualització personalitzats per locale
- **Integració amb router** - Navega automàticament a rutes localitzades
- **Accessibilitat** - Atributs ARIA adequats i navegació per teclat

**Exemple:**

```vue
<!-- Vue -->
<I18nSwitcher />
```

```tsx
// React
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```tsx
// Solid
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```astro
<!-- Astro -->
<I18nSwitcher />
```

### `<I18nGroup>`

Un component per agrupar traduccions amb un prefix comú, útil per organitzar traduccions per pàgina o funcionalitat. Funcionalitats:

- **Àmbit de prefix** - Afegeix automàticament el prefix a totes les claus de traducció dins del grup
- **Grups imbricats** - Suport per a grups de traducció imbricats
- **Organització neta** - Ajuda a mantenir estructures de traducció organitzades

**Exemple:**

```vue
<!-- Vue -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

```tsx
// React
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```tsx
// Solid
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```astro
<!-- Astro -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

## Opcións compartides de `createI18n` \{#create-i18n-options\}

Cada paquet de framework es crea de la mateixa manera — només el tipus d'opcions es nomena segons el
framework (`ReactI18nOptions`, `SolidI18nOptions`, etc.). Les opcions en si
són idèntiques:

| Propietat        | Tipus                                                      | Obligatori | Per defecte     | Descripció                                     |
| ---------------- | ---------------------------------------------------------- | -------- | ---------------- | ---------------------------------------------- |
| `locale`         | `string`                                                   | ✅       | -                | Codi de locale actual (per exemple, `'en'`)   |
| `fallbackLocale` | `string`                                                   | ❌       | Igual que `locale` | Locale de reserva quan falta la traducció   |
| `messages`       | `Record<string, Translations>`                             | ❌       | `\{\}`           | Missatges de traducció inicials                |
| `plural`         | `PluralFunc`                                               | ❌       | `defaultPlural`  | Funció de pluralització personalitzada         |
| `missingWarn`    | `boolean`                                                  | ❌       | `true`           | Mostra advertències a la consola per a traduccions faltants |
| `missingHandler` | `(locale: string, key: string, routeName: string) => void` | ❌       | -                | Handler personalitzat per a traduccions faltants |

Qualsevol cosa més enllà és específica del framework i està documentada a la pàgina d'aquest paquet.

## Abstracció d'adaptador de router

Tots els paquets de framework utilitzen un **patró d'adaptador de router** per desacoblar la funcionalitat d'i18n d'implementacions específiques de router. Aquest disseny permet:

- **Flexibilitat** - Utilitza qualsevol biblioteca de router o cap router
- **Independència de framework** - Manté la lògica d'enrutament a la teva aplicació, no al paquet d'i18n
- **Nucli lleuger** - El paquet d'i18n roman petit i enfocat

### Implementar un adaptador de router

Per utilitzar les funcionalitats d'enrutament, has d'implementar la interfície `I18nRoutingStrategy`:

```typescript
interface I18nRoutingStrategy {
  getCurrentPath: () => string
  linkComponent?: Component
  push: (target: { path: string }) => void
  replace: (target: { path: string }) => void
  resolvePath?: (to: string | { path?: string }, locale: string) => string | { path?: string }
  getRoute?: () => { fullPath: string; query: Record<string, unknown> }
}
```

La documentació de cada paquet inclou exemples complets d'implementació d'adaptadors per a routers populars:

- **Vue**: Exemple d'adaptador de Vue Router
- **React**: Exemple d'adaptador de React Router
- **Solid**: Exemple d'adaptador de Solid Router
- **Astro**: Exemple d'adaptador d'enrutament basat en fitxers

## Funcionalitats bàsiques

Tots els paquets comparteixen aquestes funcionalitats bàsiques:

### Mètodes de traducció

- `t()` - Traducció bàsica amb interpolació de paràmetres
- `ts()` - Traducció que sempre retorna una cadena
- `tc()` - Traducció amb suport de pluralització
- `tn()` - Format de nombres
- `td()` - Format de dates
- `tdr()` - Format de temps relatius
- `has()` - Comprova si existeix una clau de traducció

### Gestió de locales

- **Canvi de locale** - Canvia el locale actual programàticament
- **Locale de reserva** - Fallback automàtic quan falta una traducció
- **Traduccions específiques de ruta** - Organització de traducció a nivell de pàgina
- **Memòria cau de traduccions** - Memòria cau intel·ligent per al rendiment

### Suport de TypeScript

Tots els paquets proporcionen:

- Definicións completes de TypeScript
- Claus de traducció amb tipus segurs (amb el generador de tipus)
- Suport d'IntelliSense als IDEs
- Comprovació d'errors en temps de compilació

## Començar

1. **Escull el teu paquet** - Selecciona el paquet per al teu framework
2. **Instal·la el paquet** - Utilitza el teu gestor de paquets preferit
3. **Llegeix la documentació** - Cada paquet té instruccions de configuració detallades
4. **Implementa l'adaptador de router** - Si necessites funcionalitats d'enrutament, implementa l'adaptador
5. **Comença a traduir** - Utilitza components i mètodes per afegir traduccions
