Els paquets `@i18n-micro/*` porten el nucli de traducció de Nuxt I18n Micro a Vue, React, Preact, Solid, Astro, VitePress i JavaScript pur. Feu-los servir quan la vostra aplicació no és una aplicació Nuxt, o quan un script o un servidor fora de Nuxt necessita els mateixos fitxers de traducció. Tots els paquets comparteixen un mateix model d'instància, un mateix contracte d'adaptador de router i els mateixos quatre components, que es descriuen una sola vegada en aquesta pàgina.

Cada paquet té un playground a `packages/<name>/playground` al repositori.

## La instància {#the-instance}

`createI18n(options)` retorna una instància que conté els diccionaris, el locale actual i la ruta actual. Les opcions són les mateixes a tots els paquets:

| Opció | Tipus | Per defecte | Notes |
| --- | --- | --- | --- |
| `locale` | `string` | obligatòria | Locale actiu. |
| `fallbackLocale` | `string` | `locale` | Es consulta quan falta una clau a `locale`. |
| `messages` | `Record<locale, Translations>` | `{}` | Diccionaris arrel (ruta `'index'`). |
| `routeMessages` | `Record<route, Record<locale, Translations>>` | `{}` | Diccionaris de ruta. Només Runtime, React, Preact, Node i VitePress. |
| `plural` | `PluralFunc` | `defaultPlural` | Regla de plural personalitzada. |
| `missingWarn` | `boolean` | `true` | `console.warn` al navegador, només en desenvolupament, per a una clau que falta. |
| `missingHandler` | `(locale, key, routeName) => void` | — | Es crida en lloc de l'avís. |
| `numberFormats` | `Record<locale, Record<name, Intl.NumberFormatOptions>>` | — | Formats amb nom: `tn(9.5, 'currency')`. |
| `datetimeFormats` | `Record<locale, Record<name, Intl.DateTimeFormatOptions>>` | — | Formats amb nom: `td(date, 'short')`. |
| `timeZone` | `string` | la zona de l'entorn d'execució | Zona IANA per a les dates de `td`; no afecta `tdr`. Establiu-la perquè el servidor i el navegador renderitzin la mateixa data. |
| `now` | `() => number` | `Date.now` | El rellotge de `tdr`. Passeu a la hidratació l'hora del servidor perquè tots dos renderitzin el mateix text. |
| `localeIso` | `Record<code, string>` | — | Etiqueta BCP 47 utilitzada per a les regles de plural (`ua` → `uk-UA`). React, Preact i Solid la prenen de l'`iso` dels `locales` del provider. |

Els diccionaris viuen a `i18n.storage.translations`, un `Map` indexat per `locale:route` (`en:index`, `en:about`).

Una clau es cerca al diccionari de la ruta actual i després al diccionari arrel, primer per a `locale` i després per a `fallbackLocale`. Una clau que falta retorna la clau mateixa (o el `defaultValue` que passeu).

```ts
i18n.addTranslations('en', { nav: { home: 'Home' } }) // root, deep-merged
i18n.addRouteTranslations('en', 'about', { title: 'About us' }) // route chunk
i18n.addTranslations('en', { nav: { home: 'Start' } }, false) // replace instead of merge
i18n.setRoute('about')
i18n.t('title') // 'About us'
i18n.t('nav.home') // 'Start' (root key, still visible on the route)
```

### Traduir i formatar {#translate-and-format}

| Mètode | Retorna |
| --- | --- |
| `t(key, params?, defaultValue?, routeName?)` | El valor (cadena, número, objecte) amb `{param}` interpolat. |
| `ts(...)` | El mateix que `t`, com a cadena. |
| `tc(key, count \| params, defaultValue?)` | Forma plural. |
| `tn(value, options \| name)` | `Intl.NumberFormat` en el locale actiu. |
| `td(value, options \| name)` | `Intl.DateTimeFormat`. |
| `tdr(value, options?)` | Temps relatiu (`3 days ago`). |
| `has(key, routeName?)` | `true` quan el locale actiu té la clau (diccionari de ruta o arrel; no es comprova l'alternativa). |

`defaultPlural` divideix el valor per `|` i tria la forma de l'índex `count`, limitada a l'última; un recompte negatiu, fraccionari o `NaN` tria l'última forma.

Un `plural` personalitzat rep `(key, count, params, locale, getter)`. Llegiu el valor mitjançant `getter(key)`; no dividiu la clau:

```ts
import type { PluralFunc } from '@i18n-micro/vue'

const plural: PluralFunc = (key, count, params, _locale, getter) => {
  const value = getter(key)
  if (typeof value !== 'string') return null
  const forms = value.split('|').map((form) => form.trim())
  return (count === 1 ? forms[0] : forms[1] ?? forms[0])!.replace('{count}', String(count))
}
```

## Adaptador de router {#router-adapter}

Els paquets SPA no depenen de cap router. Un adaptador de router (`I18nRoutingStrategy`) els indica com llegir el camí actual, navegar i construir un camí localitzat. Els adaptadors integrats afegeixen un prefix a tots els locales excepte `defaultLocale` (`/about`, `/de/about`).

| Membre | Obligatori | Utilitzat per |
| --- | --- | --- |
| `getCurrentPath(): string` | sí | comprovació d'enllaç actiu (per pàgina; la query i el hash no compten), `switchLocale` (els conserva) |
| `push({ path }): void` | sí | `switchLocale`, `<I18nLink>` sense `linkComponent`, `<I18nSwitcher>` |
| `replace({ path }): void` | sí | — |
| `resolvePath(to, locale)` | no | `localePath`, `localeRoute`, `<I18nLink>`; sense ell els camins es retornen tal qual |
| `linkComponent` | no | `<I18nLink>` el renderitza (p. ex. `RouterLink`) en lloc de `<a>` |
| `getRoute()` | no | `{ fullPath, query }` per als helpers de SEO |

`push` i `replace` són obligatoris a Vue, React, Preact i Solid. Astro té el seu propi adaptador del costat del servidor amb `push`/`replace` opcionals (vegeu [Astro](/ca/integrations/astro-package#router-adapter)).

Un adaptador mínim per a qualsevol router basat en l'historial:

```ts
import type { I18nRoutingStrategy } from '@i18n-micro/react'

const locales = ['en', 'de']
const stripLocale = (path: string) => path.replace(/^\/(en|de)(?=\/|$)/, '') || '/'

export const historyAdapter: I18nRoutingStrategy = {
  getCurrentPath: () => window.location.pathname + window.location.search + window.location.hash,
  push: ({ path }) => window.history.pushState({}, '', path),
  replace: ({ path }) => window.history.replaceState({}, '', path),
  resolvePath: (to, locale) => {
    const path = stripLocale(typeof to === 'string' ? to : to.path || '/')
    return locale === 'en' ? path : `/${locale}${path === '/' ? '' : path}`
  },
}
```

## Components {#components}

Vue, React, Preact i Solid inclouen els mateixos quatre components. Les seves props coincideixen; React, Preact i Solid passen la resta de props a l'element arrel.

### `<I18nT>` {#&lt;i18nt&gt;}

| Prop | Tipus | Notes |
| --- | --- | --- |
| `keypath` | `string` | obligatòria |
| `params` | `object` | valors d'interpolació |
| `plural` | `number \| string` | renderitza `tc(keypath, count)` |
| `number` | `number \| string` | passa `tn(number)` com a `{number}` |
| `date` | `Date \| string \| number` | passa `td(date)` com a `{date}` |
| `relativeDate` | `Date \| string \| number` | passa `tdr(relativeDate)` com a `{relativeDate}` |
| `tag` | `string` | element embolcall, per defecte `span` |
| `html` | `boolean` | renderitza la traducció com a HTML; ha de ser de confiança, els paràmetres s'escapen |
| `defaultValue` | `string` | substitueix una clau que falta, i es renderitza sol quan `hideIfEmpty` amaga un valor buit |
| `hideIfEmpty` | `boolean` | no renderitza res per a una traducció buida |
| `customPluralRule` | `PluralFunc` | regla de plural per a aquest element |

Només s'aplica una prop de format, comprovades en aquest ordre: `number`, `date`, `relativeDate`, `plural`.

#### Text enriquit {#rich-text}

Un `{placeholder}` pot contenir un element. A Vue és un slot amb nom; a React, Preact i Solid la prop `components` proporciona elements, o funcions que en retornen un, per nom. En tots dos casos s'imposa a un paràmetre amb el mateix nom, funciona a totes les branques i sobreviu a un locale que reordeni els marcadors.

```tsx
// { "terms": "I accept the {link} of {company}" }
<I18nT keypath="terms" params={{ company: 'ACME' }} components={{ link: <a href="/terms">terms</a> }} />
```

A Solid, passeu una funció quan un marcador es repeteix: un node només pot ocupar un lloc. Els `children` substitueixen el text; com a funció reben `{ translation }`, com l'slot per defecte de Vue. `html` ignora tot això.

### `<I18nLink>` {#&lt;i18nlink&gt;}

| Prop | Tipus | Notes |
| --- | --- | --- |
| `to` | `string \| { path }` | localitzat mitjançant el `resolvePath` de l'adaptador |
| `activeStyle` | objecte d'estil | es fusiona per sobre de `style` a la pàgina actual; React, Preact i Solid també l'apliquen a una secció superior |
| `localeRoute` | funció | sobreescriu `resolvePath` per a aquest enllaç |

Les URL externes (`https://`, `mailto:`, `tel:`) es renderitzen com a `<a target="_blank" rel="noopener noreferrer">`; un `target` o `rel` propi s'imposa. `onClick` sempre s'executa. Un clic amb modificador, un altre botó del ratolí o un `target` es deixen al navegador.

### `<I18nSwitcher>` {#&lt;i18nswitcher&gt;}

Un desplegable dels locales habilitats (els locales amb `disabled: true` s'amaguen) amb estils per defecte en línia. Els seus elements són enllaços, amb `lang`, `hreflang` i `dir` del locale. Per defecte, fer clic en un estableix el locale i crida el `push` de l'adaptador amb el camí actual localitzat; una prop `switchLocale` substitueix aquesta acció. Amb un `localeRoute` i sense router, el navegador segueix l'enllaç. Escape o un clic a fora el tanquen.

| Prop | Notes |
| --- | --- |
| `locales`, `currentLocale`, `getLocaleName` | sobreescriuen els valors proporcionats |
| `switchLocale(code)` | substitueix el canvi integrat |
| `localeRoute` | substitueix `resolvePath` |
| `customLabels` | `{ de: 'DE' }` |
| `customWrapperStyle`, `customButtonStyle`, `customDropdownStyle`, `customItemStyle`, `customLinkStyle`, `customActiveLinkStyle`, `customDisabledLinkStyle`, `customIconStyle` | sobreescriptures d'estil |

### `<I18nGroup>` {#&lt;i18ngroup&gt;}

Un `<div class="i18n-group">` que passa un `t` amb prefix als seus fills. **No** afegeix el prefix a les crides `<I18nT>` o `t()` que hi ha a dins; només té prefix el `t` que passa cap avall.

| Prop | Notes |
| --- | --- |
| `prefix` | obligatòria, p. ex. `'profile'` |
| `groupClass` | classe addicional a l'embolcall |

El `t` amb prefix arriba mitjançant un slot amb àmbit a Vue (`v-slot="{ t }"`) i un fill render-prop a React, Preact i Solid (`{({ t }) => …}`).

## Claus tipades {#typed-keys}

`t()` accepta qualsevol cadena. Per obtenir l'autocompletat de les vostres claus, genereu una declaració amb el [generador de tipus](/ca/integrations/types-generator). Les claus se suggereixen, no s'imposen, i els paràmetres no estan tipats.

## Comparació amb el mòdul de Nuxt {#compared-with-the-nuxt-module}

Els paquets no tenen encaminament basat en fitxers, ni middleware de servidor, ni carregador de traduccions: vosaltres decidiu quan carregar el JSON (`import`, `fetch` o `@i18n-micro/node` al servidor) i quin adaptador de router fer servir. La detecció del locale, les metadades de SEO i la generació de rutes són funcionalitats de Nuxt; Astro té el seu propi middleware per a la detecció i `useLocaleHead` per a SEO.
