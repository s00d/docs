---
title: "Astro"
description: "Traduccions al servidor, rutes amb prefix de locale, detecció a la pàgina d'inici i etiquetes SEO per a Astro amb @i18n-micro/astro."
---

`@i18n-micro/astro` tradueix les pàgines d'Astro al servidor: un middleware tria el locale a partir de l'URL i posa una instància per petició a `Astro.locals`, i `useI18n(Astro)` la llegeix. Utilitzeu-lo en un lloc Astro que necessiti URL amb prefix de locale (`/about`, `/fr/about`) i diccionaris JSON compartits. Obteniu components `.astro`, una redirecció de la pàgina d'inici a l'idioma del visitant, etiquetes `hreflang` i props per a [illes](/ca/integrations/astro-islands).

## Instal·lació {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/astro
```

```bash npm
npm install @i18n-micro/astro
```

```bash yarn
yarn add @i18n-micro/astro
```

</CodeGroup>

Dependències peer: `astro` `^5.0.0 || ^6.0.0 || ^7.0.0`. Opcionals, només per a [illes](/ca/integrations/astro-islands): `vue` `^3.3.0`, `react` `^16.8.0 || ^17.0.0 || ^18.0.0 || ^19.0.0`, `preact` `^10.0.0 || ^11.0.0`, `svelte` `^4.0.0 || ^5.0.0`.

## Configuració {#setup}

Afegiu la integració. Empaqueta els vostres diccionaris al servidor i instal·la el middleware, de manera que no cal cap `src/middleware.ts`:

```ts
// astro.config.mjs
import { defineConfig } from 'astro/config'
import node from '@astrojs/node'
import { i18nIntegration } from '@i18n-micro/astro'

export default defineConfig({
  output: 'server',
  adapter: node({ mode: 'standalone' }),
  integrations: [
    i18nIntegration({
      locale: 'en',
      fallbackLocale: 'en',
      locales: [
        { code: 'en', iso: 'en-US', displayName: 'English' },
        { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
        { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
      ],
      translationDir: 'src/locales',
    }),
  ],
})
```

Els diccionaris es converteixen en codi en temps de compilació: el servidor no llegeix el disc, de manera que també funciona a l'edge (Cloudflare, Vercel Edge). A `astro dev`, una modificació d'un fitxer s'aplica a la petició següent.

### Opcions de la integració {#integration-options}

| Opció | Per defecte | Notes |
| --- | --- | --- |
| `locale` | obligatòria | Locale per defecte. |
| `fallbackLocale` | `locale` | |
| `locales` | `[]` | Objectes `Locale` complets. Un de `disabled` no és el locale de cap URL ni destinació de cap redirecció. `iso` és l'etiqueta segons la qual es fan els plurals quan el codi no ho és (`ua` → `uk-UA`). |
| `translationDir` | cap | Carpeta empaquetada al servidor, relativa a l'arrel del projecte. |
| `disablePageLocales` | `false` | Els fitxers de pàgina compten com a traduccions arrel. |
| `autoDetect` | `true` | Redirecció de la pàgina d'inici, vegeu [Detecció del locale](#locale-detection). |
| `redirectToDefault` | `false` | `/` també redirigeix quan res no prefereix un altre locale. |
| `localeCookie` | `'i18n-locale'` | `null` desactiva la galeta. |
| `missingWarn` | `false` | |
| `middleware` | `true` | `false`: escriviu el middleware vosaltres mateixos, vegeu més avall. |

La configuració en temps d'execució es publica a `virtual:i18n-micro/config` (`config.base` és el `base` d'Astro, `config.localeCodes` els codis habilitats), i els diccionaris a `virtual:i18n-micro/messages`.

### El vostre propi middleware {#your-own-middleware}

Una regla de plural, un handler de claus que falten i un adaptador de router no poden passar del procés de configuració al bundle del servidor. Per a aquests casos, passeu `middleware: false` i escriviu `src/middleware.ts`. Aleshores la configuració `i18n` d'Astro s'estableix automàticament amb `routing: 'manual'`, de manera que `Astro.currentLocale` i `astro:i18n` funcionen. Astro no permet aquesta configuració sense un `src/middleware.ts`, de manera que amb el middleware propi de la integració no funcionen.

```ts
// src/middleware.ts
import { config } from 'virtual:i18n-micro/config'
import { messages } from 'virtual:i18n-micro/messages'
import { createAstroRouterAdapter, createI18n, createI18nMiddleware, localeIsoMap } from '@i18n-micro/astro'

const i18n = createI18n({
  locale: config.defaultLocale,
  fallbackLocale: config.fallbackLocale,
  localeIso: localeIsoMap(config.locales),
  messages: messages.root,
  routeMessages: messages.routes,
  plural: myPluralRule,
})

export const onRequest = createI18nMiddleware({
  i18n,
  defaultLocale: config.defaultLocale,
  locales: config.localeCodes,
  localeObjects: config.locales,
  autoDetect: config.autoDetect,
  redirectToDefault: config.redirectToDefault,
  localeCookie: config.localeCookie,
  base: config.base,
  routingStrategy: createAstroRouterAdapter(config.locales, config.defaultLocale),
})
```

Per llegir la carpeta en temps d'execució, `loadTranslationsFromDir` i `loadTranslationsIntoI18n` són a `@i18n-micro/astro/node` (només Node).

### Opcions del middleware {#middleware-options}

| Opció | Per defecte | Notes |
| --- | --- | --- |
| `i18n` | obligatòria | Instància global; cada petició obté `i18n.fork(locale)`, que costa el mateix independentment de quants diccionaris hi hagi. |
| `defaultLocale` | obligatòria | |
| `locales` | obligatòria | Codis de locale. |
| `localeObjects` | `locales` com a `{ code }` | Objectes `Locale` complets per als components i el SEO. |
| `autoDetect` | `true` | Redirecció de la pàgina d'inici, vegeu [Detecció del locale](#locale-detection). |
| `redirectToDefault` | `false` | `/` també redirigeix quan res no prefereix un altre locale, a l'inici del locale per defecte tal com el resol l'estratègia d'enrutament. |
| `localeCookie` | `'i18n-locale'` | `null` desactiva la galeta. |
| `routingStrategy` | prefix excepte el per defecte | Adaptador de router. Els mètodes que ometi provenen de l'adaptador per defecte. |
| `base` | cap | El `base` d'Astro: `config.base`. |

Els fitxers de pàgina (`src/locales/pages/blog/post/de.json`) són la ruta `blog-post`: el camí de la pàgina unit amb `-`.

## Traduir {#translate}

```astro
---
// src/pages/index.astro
import { useI18n } from '@i18n-micro/astro'
import I18nT from '@i18n-micro/astro/i18n-t'

const { t, tc, locale } = useI18n(Astro)
---

<h1>{t('greeting', { name: 'Ada' })}</h1>
<p>{tc('apples', 3)}</p>
<I18nT keypath="welcome" tag="p" />
<p>{locale}</p>
```

`useI18n(Astro)` retorna `locale`, `defaultLocale`, `locales`, `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`, `getRoute`, `getRouteName(path?)`, `getLocaleFromPath(path?)`, `switchLocalePath(locale)`, `localizePath(path, locale?)`, `getBasePath(url?)`, `getI18n`, `addTranslations`, `addRouteTranslations`, `mergeTranslations` i `clearCache`. Llança un error quan el middleware no s'ha executat. Els helpers `getI18n`, `getLocale`, `getDefaultLocale` i `getLocales` llegeixen el mateix `Astro.locals`.

El nom de la ruta prové de la ruta sense el locale: `/fr/blog/post` → `blog-post`, i cada URL de `src/pages/blog/[slug].astro` → `blog-slug`, de manera que una sola carpeta `locales/pages/blog-slug/` les serveix totes. `[...path]` és `path`. Amb el `base` d'Astro, els helpers accepten i retornen URL del lloc: `switchLocalePath` i `localizePath` l'inclouen, `getBasePath` no, perquè `Astro.rewrite` accepta el camí sense ell.

### Components {#components}

Importeu-los des de `@i18n-micro/astro/<name>` (o `@i18n-micro/astro/components/<name>.astro`):

| Component | Props |
| --- | --- |
| `i18n-t` | `keypath`, `params`, `plural`, `number`, `date`, `relativeDate`, `tag` (`span`, qualsevol etiqueta), `html`, `hideIfEmpty`, `defaultValue`; la resta d'atributs es transmeten. Amb `html`, el resultat de cada branca es renderitza com a HTML i els `params` s'escapen. No hi ha slots |
| `i18n-link` | `href`, `locale` (locale de destinació, per defecte l'actual), `class`; la resta d'atributs es transmeten. Les URL externes, `#hash` i `?query` es mantenen tal com s'han escrit; una ruta conserva la query, el hash i la barra final |
| `i18n-switcher` | `class`, `activeClass` (`'active'`), `customLabels`; renderitza enllaços a la pàgina actual en cada locale habilitat, amb la seva query |
| `i18n-group` | cap que canviï la sortida: un `<div>` al voltant del seu slot, sense prefix |

## Rutes amb prefix de locale {#locale-prefixed-routes}

Mantingueu una pàgina per ruta a `src/pages/` i afegiu stubs de reescriptura lleugers a `src/pages/[locale]/`:

```
src/pages/
  index.astro
  about.astro
  [locale]/
    index.astro
    about.astro
```

```astro
---
// src/pages/[locale]/about.astro
import { prepareLocaleRewrite } from '@i18n-micro/astro'

const target = prepareLocaleRewrite(Astro)
if (target instanceof Response) return target
return Astro.rewrite(target)
---
```

`prepareLocaleRewrite` retorna una resposta `404` per a un `:locale` desconegut; altrament estableix el locale a `Astro.locals` i retorna el camí sense el prefix. El middleware conserva un locale que ja és a `locals`, de manera que la pàgina reescrita es renderitza en aquest locale. `getLocaleRewritePath(Astro)` només retorna el camí, per quan valideu el locale vosaltres mateixos.

## Detecció del locale {#locale-detection}

L'URL decideix el locale de la pàgina:

1. Un prefix de locale (`/fr/about` → `fr`; `/en/about` també és `en`).
2. Altrament, el que retorni `getLocaleFromPath` de l'adaptador de router, si no és el per defecte.
3. Altrament, el locale per defecte. `/about` sempre és la pàgina del locale per defecte, digui el que digui la galeta.

`autoDetect` és una indicació de redirecció només a la pàgina d'inici:

- Una petició a `/` la galeta o l'`Accept-Language` de la qual prefereix un altre locale rep un `302` cap a l'inici d'aquest locale (`/de`). Es respecten els pesos q; `de-DE` coincideix amb un locale `de`, i `de` coincideix amb un `de-DE`.
- Amb `redirectToDefault`, `/` sempre redirigeix: a l'inici del locale preferit o, si no, al del locale per defecte.
- La resposta de `/` porta `Vary: Cookie, Accept-Language` (només `Accept-Language` quan `localeCookie` és `null`).
- Les pàgines prerenderitzades mai no redirigeixen.

`detectLocale(pathname, cookies, headers, defaultLocale, locales, localeCookie?, routingStrategy?, autoDetect?)` retorna el mateix locale preferit per a la vostra pròpia lògica.

La galeta recorda una elecció. Una visualització de pàgina que prové d'una pàgina del mateix origen d'un altre locale és un visitant que canvia d'idioma, sigui quin sigui l'enllaç que l'hi ha portat: la resposta HTML estableix la galeta al nou locale, i `/` no redirigeix, de manera que un selector arriba a l'inici del locale per defecte. Un endpoint, una imatge, un 404, l'enviament d'un formulari i un prefetch no canvien res. "Mateix origen" és el que diu el navegador a `Sec-Fetch-Site`; sense aquesta capçalera es compara l'host del `Referer` amb el de la petició, de manera que darrere d'un proxy cal establir `security.allowedDomains` d'Astro.

Una [illa de servidor](https://docs.astro.build/en/guides/server-islands/) o una acció no té locale a l'URL. Es renderitza per a la pàgina que l'ha demanada, llegida del `Referer`, del qual només compta el camí, de manera que un proxy davant del servidor no canvia res, i mai no redirigeix. La seva resposta porta `Vary: Referer`. Sense `Referer` (una política `no-referrer`) es renderitza en el locale per defecte, i en una pàgina dinàmica la seva ruta prové de l'URL, de manera que els diccionaris de pàgina no hi arriben.

## Adaptador de router {#router-adapter}

`createAstroRouterAdapter(locales, defaultLocale)` afegeix prefix a tots els locales excepte el per defecte. Un adaptador d'Astro només necessita `getCurrentPath`; la resta de membres són opcionals i recorren a l'adaptador per defecte: `getRouteName(path, locales, routePattern?)`, `getLocaleFromPath`, `switchLocalePath`, `localizePath`, `removeLocaleFromPath`, `resolvePath` (destinació de la redirecció de l'inici), `push`, `replace`, `getRoute`. Escriviu-ne un de propi per a URL amb subdomini o sufix i passeu-lo a `createI18nMiddleware`.

## SEO {#seo}

```astro
---
// src/layouts/Layout.astro
import { useLocaleHead } from '@i18n-micro/astro'

const head = useLocaleHead(Astro, { baseUrl: 'https://example.com' })
---

<html lang={head.htmlAttrs.lang} dir={head.htmlAttrs.dir}>
  <head>
    {head.link.map((l) => <link rel={l.rel} href={l.href} hreflang={l.hreflang} />)}
    {head.meta.map((m) => <meta property={m.property} content={m.content} />)}
  </head>
  <body><slot /></body>
</html>
```

Retorna `htmlAttrs` (`lang` a partir d'`iso`, `dir`), un enllaç canònic (camí sense query), alternatives `hreflang` per a cada locale habilitat amb `seo !== false` més `x-default`, `og:locale`, `og:locale:alternate` i `og:url`. Opcions: `baseUrl` (`site` de la configuració d'Astro o, si no, URL relatives a l'arrel), `addDirAttribute` (`true`), `addSeoAttributes` (`true`), `hreflangBaseLanguage` (`false`).
