---
title: "Generador de tipus"
description: "Genereu autocompletat de TypeScript per a les claus de traducció a partir dels fitxers JSON, a Nuxt o a qualsevol projecte Vite."
---

`@i18n-micro/types-generator` llegeix tots els fitxers JSON de la carpeta de traduccions i escriu una declaració que llista totes les claus. Afegiu-lo quan vulgueu que l'editor us suggereixi claus a `t()`, `$t()` i `<I18nT keypath>`. Funciona com a mòdul de Nuxt i com a plugin de Vite o Rollup, i es regenera quan canvia un fitxer.

## Instal·lació {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/types-generator
```

```bash npm
npm install -D @i18n-micro/types-generator
```

```bash yarn
yarn add -D @i18n-micro/types-generator
```

</CodeGroup>

Dependència peer: `@nuxt/kit` `^3.18.0 || ^4.0.0`. Només l'entrada `/nuxt` la importa; en un projecte només amb Vite es pot ignorar l'avís de la dependència peer.

## Nuxt {#nuxt}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro', '@i18n-micro/types-generator/nuxt'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

El mòdul escriu `.nuxt/types/i18n-micro.d.ts` i Nuxt l'afegeix al context de tipus; no cal incloure res manualment. Llegeix `i18nTypes.translationDir` o, si no, d'on `nuxt-i18n-micro` llegeix les traduccions: `translationDir` (des de `i18n` o des de les opcions del mòdul en línia, per defecte `'locales'`) a cada capa, i `additionalTranslationDirs`. En editar un fitxer JSON dins d'aquesta carpeta es regeneren els tipus a `nuxi dev`. `i18nTypes.outputFile` s'ignora a Nuxt (un avís ho indica).

## Vite {#vite}

`I18nTypesPlugin` és un plugin de Vite, que Rollup també accepta. Per a un altre bundler, crideu `generateTypes` en un script.

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { I18nTypesPlugin } from '@i18n-micro/types-generator'

export default defineConfig({
  plugins: [
    vue(),
    I18nTypesPlugin({
      srcDir: process.cwd(),
      translationDir: 'src/locales',
      outputFile: 'src/i18n-micro.d.ts',
    }),
  ],
})
```

| Opció | Obligatòria | Notes |
| --- | --- | --- |
| `srcDir` | sí | Directori base; `translationDir` es resol respecte a aquest. |
| `translationDir` | sí | Carpeta amb els fitxers JSON (subcarpetes com `pages/` incloses), o un array de carpetes. |
| `outputFile` | no | On escriure la declaració; per defecte `<srcDir>/i18n-micro.d.ts`. |

El plugin genera una vegada a l'inici de la compilació i, al servidor de desenvolupament, regenera 300 ms després d'un canvi a la carpeta. Assegureu-vos que l'`include` del vostre `tsconfig.json` cobreix el fitxer de sortida.

## Utilitzar les claus {#use-the-keys}

El fitxer generat amplia `DefineLocaleMessage` a `@i18n-micro/types`, cosa que converteix `TranslationKey` en les vostres claus:

```ts
declare module '@i18n-micro/types' {
  export interface DefineLocaleMessage {
    nav: object
    'nav.home': string
    'profile.title': string
  }
}
```

Les claus són les que respon `t()`, també els objectes, de tots els locales i de tots els fitxers de pàgina, amb el tipus del seu valor JSON. `TranslationKey` és la unió d'aquestes claus més qualsevol string, de manera que obteniu autocompletat, no errors: una clau mal escrita o dinàmica continua compilant. Els paràmetres i els valors de retorn no estan tipats.

Per a claus dinàmiques sota un prefix conegut, `ScopedKey<'prefix'>` restringeix a les claus coincidents:

```ts
import type { ScopedKey } from '@i18n-micro/types'

const statusText = (status: string) => t(`status.${status}` as ScopedKey<'status'>)
```

`TranslationKey` i `ScopedKey` provenen de `@i18n-micro/types` (React, Preact i Solid reexporten `TranslationKey`; Vue no).

## API {#api}

| Export | Entrada | Notes |
| --- | --- | --- |
| `I18nTypesPlugin(options)` | `@i18n-micro/types-generator` | Plugin de Vite i Rollup |
| `generateTypes(options)` | `@i18n-micro/types-generator` | escriu el fitxer i en retorna el camí |
| `getTypesString(options)` | `@i18n-micro/types-generator` | retorna la declaració sense escriure-la |
| `formatKeyProperty(key)` | `@i18n-micro/types-generator` | helper |
| Mòdul de Nuxt (`configKey: 'i18nTypes'`) | `@i18n-micro/types-generator/nuxt` | opció `translationDir` |
