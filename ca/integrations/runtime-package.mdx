`@i18n-micro/runtime` és la instància i18n independent del framework: diccionaris, `t()`, plurals, format amb `Intl` i una subscripció als canvis, sense `fs` i sense cap framework. Feu-la servir en TypeScript pur, en un web worker, en una funció edge o com a base del vostre propi binding. Els paquets de React, Preact, Node i Astro estenen aquesta mateixa classe.

## Instal·lació {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/runtime
```

```bash npm
npm install @i18n-micro/runtime
```

```bash yarn
yarn add @i18n-micro/runtime
```

</CodeGroup>

Sense dependències peer. Per a fitxers de traducció al disc, feu servir [`@i18n-micro/node`](/ca/integrations/nodejs-package).

## Configuració {#setup}

```ts
import { createI18n } from '@i18n-micro/runtime'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    en: { greeting: 'Hello, {name}!', apples: 'no apples | one apple | {count} apples' },
    de: { greeting: 'Hallo, {name}!' },
  },
  routeMessages: {
    about: { en: { title: 'About us' } },
  },
})
```

Totes les opcions (`plural`, `missingWarn`, `missingHandler`, `numberFormats`, `datetimeFormats`) es detallen a [la instància](/ca/integrations/overview#the-instance).

## Traduir {#translate}

```ts
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.tc('apples', 5) // '5 apples'
i18n.tn(1234.5) // '1,234.5'

i18n.setRoute('about')
i18n.t('title') // 'About us' (route dictionary)
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!' (root, still visible)
```

Carregueu més diccionaris més endavant:

```ts
i18n.loadMessages({ fr: { greeting: 'Bonjour, {name} !' } }, { about: { fr: { title: 'À propos' } } })
i18n.addTranslations('fr', { nav: { home: 'Accueil' } }) // deep merge; pass false to replace

await i18n.loadFromUrl('/locales/fr.json', { locale: 'fr' })
await i18n.loadFromUrl('/locales/pages/about/fr.json', { locale: 'fr', routeName: 'about' })
await i18n.loadFromUrls([
  { url: '/locales/en.json', locale: 'en' },
  { url: '/locales/de.json', locale: 'de' },
])
```

`loadFromUrl` fa servir `fetch` (passeu `init` per a les capçaleres) i llança un error amb una resposta no correcta. `loadFromUrls` els carrega l'un darrere l'altre.

## Canviar de locale {#switch-locale}

```ts
i18n.locale = 'de'
i18n.t('greeting', { name: 'Ada' }) // 'Hallo, Ada!'
```

Els canvis de locale, de ruta i de diccionari notifiquen els subscriptors, que és com els bindings de framework tornen a renderitzar:

```ts
const stop = i18n.subscribe(() => {
  document.querySelector('#greeting')!.textContent = i18n.t('greeting', { name: 'Ada' }) as string
})
i18n.locale = 'fr'
stop()
```

`getSnapshot()` retorna una cadena que canvia a cada notificació (per a stores a l'estil de `useSyncExternalStore`).

## Per petició {#per-request}

La instància conté un locale i una ruta. En un servidor, no canvieu el locale d'una instància compartida per a cada petició: dues peticions concurrents veurien el locale de l'altra. `i18n.fork(locale)` dona a una petició la seva pròpia instància: locale, locale de reserva i ruta propis; els mateixos diccionaris, formatadors i regles. Fer un fork costa el mateix independentment de quants diccionaris hi hagi. Un fork veu les escriptures a la instància pare fins a la seva primera escriptura pròpia, i les seves escriptures es queden en ell. [Node.js](/ca/integrations/nodejs-package#per-request) hi afegeix `run`.

## API {#api}

| Membre | Notes |
| --- | --- |
| `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has` | vegeu [Traduir i formatar](/ca/integrations/overview#translate-and-format) |
| `locale`, `fallbackLocale` | lectura/escriptura |
| `currentRoute`, `setRoute(name)`, `getRoute()` | ruta activa, per defecte `'index'` |
| `loadMessages(messages?, routeMessages?)` | fusiona molts locales i rutes alhora |
| `addTranslations(locale, tree, merge = true)`, `addRouteTranslations(locale, route, tree, merge = true)` | |
| `loadFromUrl(url, { locale?, routeName?, init? })`, `loadFromUrls(entries)` | JSON amb `fetch` |
| `hasTranslation(key)` | locale actiu, qualsevol ruta (a diferència de `has`, que comprova la ruta activa i l'arrel) |
| `setTranslation(key, value)`, `resolveTranslations()` | escriu una clau; llegeix l'arbre fusionat |
| `clear()`, `clearCache()` | elimina tots els diccionaris |
| `subscribe(cb)`, `getSnapshot()` | notificacions de canvis |
| `storage` | `{ translations: Map<'locale:route', Translations> }` |

Un codi que no és una etiqueta d'idioma obté els plurals de `localeIso: { ua: 'uk-UA' }`; `localeIsoMap(locales)` ho construeix a partir de les entrades d'una llista de locales que tenen un `iso`.

Exportacions del mòdul: `createI18n`, `I18n`, `fetchJsonTranslations`, `FormatService`, `interpolate`, `localeIsoMap` i els tipus `I18nOptions`, `LoadFromUrlOptions`, `LoadFromUrlEntry`, `TranslationStorage`, `Translations`, `Locale`, `PluralFunc`. Signatures completes: [referència del paquet](/ca/api/packages/runtime).
