---
title: "Illes d'Astro"
description: "Traduccions dins d'illes de Vue, React, Preact i Svelte amb @i18n-micro/astro."
---

Una illa s'executa al navegador, on la instància i18n del servidor no existeix. `@i18n-micro/astro` permet que la pàgina triï les claus que necessita una illa, les passi com una sola prop i les llegeixi a l'illa mitjançant un petit adaptador del framework. Obteniu `t`, `tc`, `tn`, `td`, `tdr` i `has` a les illes de Vue, React, Preact i Svelte, amb només les cadenes escollides a l'HTML.

## Configuració {#setup}

Configureu primer la [integració i el middleware d'Astro](/ca/integrations/astro-package#setup) i després afegiu la integració del framework que feu servir (`@astrojs/vue`, `@astrojs/react`, `@astrojs/preact`, `@astrojs/svelte`). Els adaptadors d'illa necessiten aquest framework com a dependència peer: `vue` `^3.3.0`, `react` `^16.8.0 || ^17.0.0 || ^18.0.0 || ^19.0.0`, `preact` `^10.0.0 || ^11.0.0` o `svelte` `^4.0.0 || ^5.0.0`.

## Passar traduccions a una illa {#pass-translations-to-an-island}

```astro
---
// src/pages/index.astro
import { getI18nProps } from '@i18n-micro/astro'
import Counter from '../components/Counter.vue'

const i18n = getI18nProps(Astro, ['counter.title', 'counter.apples'])
---

<Counter client:load i18n={i18n} />
```

`getI18nProps(Astro, keys?)` retorna `{ locale, fallbackLocale, currentRoute, translations }` (tipus `I18nClientProps`). Passeu les claus que fa servir l'illa: cadascuna es resol al servidor com `t()` (diccionaris de ruta, arrel i de reserva) i només les claus trobades van a l'HTML. Sense `keys`, s'envia tot el que `t()` pot respondre en aquesta pàgina, a cada illa, de manera que 2000 claus arrel són uns 100 KB per illa; en desenvolupament, un avís ho indica per sobre de 20 KB.

Les illes només tradueixen a partir d'aquest objecte. `t` retorna la clau per a qualsevol cosa que no s'hagi passat, i els missatges enllaçats no es resolen.

## Vue {#vue}

Crideu `provideI18n(() => props.i18n)` al component arrel de l'illa i `useAstroI18n()` als seus fills. L'`inject` de Vue no veu un valor proporcionat pel mateix component, de manera que el hook s'ha d'executar en un fill, no a l'arrel:

```vue
<!-- src/components/Counter.vue -->
<script setup lang="ts">
import { provideI18n } from '@i18n-micro/astro/client/vue'
import type { I18nClientProps } from '@i18n-micro/astro'
import CounterBody from './CounterBody.vue'

const props = defineProps<{ i18n: I18nClientProps }>()
provideI18n(() => props.i18n)
</script>

<template><CounterBody /></template>
```

```vue
<!-- src/components/CounterBody.vue -->
<script setup lang="ts">
import { ref } from 'vue'
import { useAstroI18n } from '@i18n-micro/astro/client/vue'

const { t, tc } = useAstroI18n()
const count = ref(0)
</script>

<template>
  <h3>{{ t('counter.title') }}</h3>
  <button @click="count++">{{ tc('counter.apples', count) }}</button>
</template>
```

## React i Preact {#react-and-preact}

```tsx
// src/components/Counter.tsx
import { useState } from 'react'
import { I18nProvider, useAstroI18n } from '@i18n-micro/astro/client/react'
import type { I18nClientProps } from '@i18n-micro/astro'

function Body() {
  const { t, tc } = useAstroI18n()
  const [count, setCount] = useState(0)
  return <button onClick={() => setCount(count + 1)}>{t('counter.title')}: {tc('counter.apples', count)}</button>
}

export default function Counter({ i18n }: { i18n: I18nClientProps }) {
  return (
    <I18nProvider value={i18n}>
      <Body />
    </I18nProvider>
  )
}
```

Per a Preact, importeu `I18nProvider` i `useAstroI18n` de `@i18n-micro/astro/client/preact`; l'API és la mateixa.

## Svelte {#svelte}

```svelte
<!-- src/components/Counter.svelte -->
<script lang="ts">
  import { createI18nStore, useAstroI18n } from '@i18n-micro/astro/client/svelte'
  import type { I18nClientProps } from '@i18n-micro/astro'

  export let i18n: I18nClientProps
  const { t, tc } = useAstroI18n(createI18nStore(i18n))
  let count = 0
</script>

<button on:click={() => count++}>{t('counter.title')}: {tc('counter.apples', count)}</button>
```

`useAstroI18n(store)` també retorna el `store` per a lectures amb `$store` a la plantilla.

## Illes persistents {#persisted-islands}

Una illa amb `transition:persist` rep props noves després d'una navegació. React, Preact i Vue (si se'ls dona un getter) les segueixen. A Svelte, conserveu el store i passeu-les-hi: `const store = createI18nStore(i18n)`, `const { t } = useAstroI18n(store)`, i després `$: store.set(i18n)` (amb runes, `$effect(() => store.set(i18n))`).

## API {#api}

| Punt d'entrada | Exportacions |
| --- | --- |
| `@i18n-micro/astro` | `getI18nProps`, tipus `I18nClientProps` |
| `@i18n-micro/astro/client/vue` | `provideI18n(props \| () => props)`, `useAstroI18n()` |
| `@i18n-micro/astro/client/react` | `I18nProvider` (prop `value`), `useAstroI18n()` |
| `@i18n-micro/astro/client/preact` | `I18nProvider` (prop `value`), `useAstroI18n()` |
| `@i18n-micro/astro/client/svelte` | `createI18nStore(props)`, `useAstroI18n(store)` |
| `@i18n-micro/astro/client` | les funcions pures `translate` i `hasTranslation`, sense cap framework |

Cada `useAstroI18n` retorna `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`, `setLocale`, `setRoute` i el `locale`. Una illa té un sol diccionari fusionat, de manera que el seu `has` és cert per a una clau que `t` pot respondre, també des del locale de reserva; al servidor, `has` només mira el locale actiu.
