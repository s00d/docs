---
title: "<i18n-group>"
description: "El component <i18n-group> proporciona al seu slot una funció t limitada a un prefix de clau."
---

`<i18n-group>` limita un bloc de marcatge a un prefix de clau. Feu-lo servir quan moltes claus d'una secció comparteixen un prefix i no el voleu repetir. El slot per defecte rep una `t` que hi anteposa el prefix.

## Props i slot {#props-and-slot}

| Prop | Tipus | Per defecte | Descripció |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | Prefix de clau sobre el qual es resol cada cerca dins del slot. |
| `groupClass` | `string` | `''` | Classe addicional a l'element contenidor. |

**\*** obligatori.

### Slots {#slots}

| Slot | Vinculacions | Descripció |
| --- | --- | --- |
| `default` | `prefix`, `t` | Rep `prefix` i una funció `t` limitada a aquest prefix. |

## Comportament {#behaviour}

- Renderitza `<div class="i18n-group {groupClass}">` al voltant del slot.
- `t(key, params)` equival a `$t(prefix + '.' + key, params)` per a la ruta actual.
- Només la `t` del slot queda limitada: `$t` i els `<i18n-t>` niats dins del grup continuen fent servir claus completes.

## Exemple {#example}

```json
{
  "checkout": { "title": "Checkout", "items": "Items: {count}" }
}
```

```vue
<template>
  <i18n-group prefix="checkout" group-class="checkout">
    <template #default="{ t }">
      <h2>{{ t('title') }}</h2>
      <p>{{ t('items', { count: 3 }) }}</p>
    </template>
  </i18n-group>
</template>
```
