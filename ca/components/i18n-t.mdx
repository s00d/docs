---
title: "<i18n-t>"
description: "El component <i18n-t> renderitza una traducció, amb formes de plural, format de nombres i dates, i interpolació d'HTML i slots."
---

`<i18n-t>` renderitza una traducció dins d'un element. Feu-lo servir quan una traducció necessita components a dins (un enllaç dins d'una frase), una forma de plural, o un nombre o una data amb format. Resol la clau per a la ruta actual, com `$t`.

## Props {#props}

| Prop | Tipus | Per defecte | Descripció |
| --- | --- | --- | --- |
| `keypath` **\*** | `string` | — | Clau de traducció que es renderitza. |
| `plural` | `number \| string \| null` | — | Quantitat que selecciona la forma de plural. Establiu-la per fer servir `$tc` en lloc de `$t`. `null` vol dir sense establir. |
| `tag` | `string` | `'span'` | Element que es renderitza. |
| `params` | `Record<string, string \| number \| boolean>` | — | Valors d'interpolació que se substitueixen a la traducció. |
| `defaultValue` | `string` | `''` | Es renderitza en lloc del component quan `hideIfEmpty` suprimeix una traducció buida. |
| `html` | `boolean` | `false` | Renderitza la traducció com a HTML en lloc de text. Només per a traduccions que controleu: els `params` s'escapen, la traducció no. |
| `hideIfEmpty` | `boolean` | `false` | No renderitza res quan la traducció es resol com una cadena buida. |
| `customPluralRule` | `PluralFunc` | `null` | Regla de plural només per a aquest element, que substitueix la configurada. La seva resposta es fa servir tal qual; `null` renderitza buit. |
| `number` | `number \| string \| null` | — | Dona format al valor amb `$tn` i el passa a la traducció com a `{number}`, juntament amb `params`. |
| `date` | `Date \| string \| number \| null` | — | Dona format al valor amb `$td` i el passa a la traducció com a `{date}`, juntament amb `params`. |
| `relativeDate` | `Date \| string \| number \| null` | — | Dona format al valor amb `$tdr` i el passa a la traducció com a `{relativeDate}`, juntament amb `params`. |

**\*** obligatori.

## Regles de renderització {#rendering-rules}

El primer cas que coincideix decideix la sortida:

1. `number` — la traducció amb `{ ...params, number: $tn(number) }`.
2. `date` — la traducció amb `{ ...params, date: $td(date) }`.
3. `relativeDate` — la traducció amb `{ ...params, relativeDate: $tdr(relativeDate) }`.
4. `plural` — la forma que tria `$tc`, inclòs el [marcador `=0 `](/ca/api/methods#$tc), amb `{ ...params, count }`; o `customPluralRule(keypath, count, params, locale, t)` si està establerta, que llegeix el valor en brut, marcador inclòs, i la resposta de la qual es fa servir tal qual, i `null` equival a buit.
5. Altrament, la traducció amb `params`.

`null` compta com a no establert. En tots els casos:

- `defaultValue` substitueix una clau que falta, en totes les branques.
- `hideIfEmpty` renderitza `defaultValue` en lloc d'un resultat en blanc.
- `html` renderitza el resultat com a HTML. Els `params` s'escapen, la traducció no; els slots s'ignoren.
- Un slot `default` rep `{ translation }`, i els slots amb nom s'ignoren.
- Altrament, cada slot amb nom substitueix tots els marcadors de posició `{name}`, abans que un paràmetre amb aquest nom. Un valor de paràmetre que sembla un marcador de posició queda com a text.

La sortida de `date` i `relativeDate` porta `data-allow-mismatch="text"`, perquè la zona horària i el rellotge del servidor no són els del navegador. Establiu [`timeZone`](/ca/api/module-options#timezone) per renderitzar la mateixa data de calendari als dos; `relativeDate` depèn del rellotge, així que encara pot diferir.

## Exemple {#example}

```json
{
  "terms": "I accept the {link}.",
  "termsLink": "terms of use",
  "items": "no items | one item | {count} items"
}
```

```vue
<template>
  <i18n-t keypath="terms" tag="p">
    <template #link>
      <NuxtLink :to="$localePath('/terms')">{{ $t('termsLink') }}</NuxtLink>
    </template>
  </i18n-t>

  <i18n-t keypath="items" :plural="cart.length" />
</template>
```

`html` estableix `innerHTML`: feu-lo servir només per a traduccions que controleu. Els `params` s'escapen, de manera que les dades d'usuari hi són segures, i també ho és una clau que no ha trobat cap traducció.
