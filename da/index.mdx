title: "Nuxt I18n Micro"

---

Nuxt I18n Micro er et letvægts, højtydende i18n-modul til Nuxt 3 og 4, designet til store projekter. Det holder build-tider, hukommelsesforbrug og bundlestørrelse lave sammenlignet med traditionelle i18n-løsninger som `@nuxtjs/i18n`.

Lokaliserede routes genereres ved build af `@i18n-micro/route-strategy` og afgøres ved runtime af `@i18n-micro/path-strategy`, så links, sprogvælgeren, `hreflang` og redirects alle stemmer overens med routeren. Oversættelser er kun JSON, fordelt mellem delte rodfiler og filer pr. side, som dev-serveren opretter for dig, med indbygget HMR.

<CodeGroup>

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>
