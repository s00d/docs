# 🌐 Guide til Crowdin-integration

## 📖 Introduktion

Integration af Crowdin i dit projekt strømliner lokaliserings- og oversættelsesprocessen. Det bliver lettere at styre oversættelser på tværs af flere sprog og platforme. Denne guide giver en trin-for-trin gennemgang af opsætning af Crowdin i dit projekt, inklusive konfiguration, upload af kilder og download af oversættelser.

## 🔧 Installation og opsætning

For at komme i gang med Crowdin skal du installere Crowdin CLI globalt på din maskine og initialisere den i din projektmappe.

### 📦 Installation af Crowdin CLI

Installer først Crowdin CLI globalt med npm:

```bash
npm install -g @crowdin/cli
```

### 🛠 Initialisering af Crowdin i dit projekt

Initialiser Crowdin i dit projekt ved at køre:

```bash
crowdin init
```

Denne kommando guider dig gennem opsætningen, herunder indstilling af dit projekt-ID, API-token og andre konfigurationsdetaljer.

## 🗂️ Konfigurationsguide

### 📄 Crowdin-konfigurationsfil (`crowdin.yml`)

Crowdin-konfigurationsfilen (`crowdin.yml`) definerer, hvordan dine kildefiler mappes, og hvor oversættelser skal placeres. Nedenfor er et eksempel på konfiguration:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Vigtige konfigurationsparametre

- **`project_id`**: Dit Crowdin-projekt-ID. Det identificerer det projekt i Crowdin, hvor oversættelser styres.
- **`api_token`**: API-tokenet, der bruges til godkendelse. Sørg for, at dette token har de rigtige rettigheder til at uploade og downloade oversættelser.
- **`base_path`**: Angiver basismappen for kildefiler. I dette eksempel gemmes oversættelser i mappen `./locales`.
- **`base_url`**: Base-URL'en for Crowdin-API'et.
- **`preserve_hierarchy`**: Når den er sat til `true`, bevarer Crowdin mappestrukturen for dine kildefiler i projektet.

### 📂 Konfiguration af filer

`files`-sektionen mapper dine kildefiler til de stier, hvor oversættelser gemmes. For eksempel:

- **Kildesti**: Angiver placeringen af de oprindelige oversættelsesfiler.
- **Oversættelsessti**: Angiver, hvor de oversatte filer gemmes i Crowdin. Pladsholdere som `%two_letters_code%` bruges til dynamisk at indsætte sprogkoden i filstierne.

## ⬆️ Upload af kildefiler til Crowdin

Når din Crowdin-konfiguration er sat op, kan du uploade dine kildefiler med følgende kommando:

```bash
crowdin upload sources
```

Denne kommando uploader alle angivne kildefiler i din konfiguration til Crowdin og gør dem tilgængelige for oversættelse.

## ⬇️ Download af oversættelser fra Crowdin

Efter oversættelser er færdige eller opdateret i Crowdin, kan du downloade dem til dit projekt med:

```bash
crowdin download
```

Denne kommando henter de nyeste oversættelser fra Crowdin og gemmer dem i henhold til de stier, der er angivet i din konfigurationsfil.

## ⚙️ Bedste praksis

### 🔑 Konsistent nøglenavngivning

Sørg for, at oversættelsesnøgler er konsistente på tværs af alle filer for at undgå forvirring og duplikering.

### 🧹 Regelmæssig vedligeholdelse

Gennemgå og ryd op i ubrugte oversættelsesnøgler jævnligt for at holde dine filer organiserede og overskuelige.

### 🛠 Automatisér upload og download

Integrer Crowdin CLI-kommandoerne i din CI/CD-pipeline for at automatisere upload af kildefiler og download af oversættelser. Så er dine oversættelser altid opdaterede.

Ved at følge denne guide kan du problemfrit integrere Crowdin i dit projekt og sikre en effektiv og organiseret tilgang til at styre din internationaliseringsindsats.
