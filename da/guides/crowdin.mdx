# 🌐 Crowdin-integrationsvejledning

## 📖 Introduktion

Integration af Crowdin i dit projekt strømliner lokaliserings- og oversættelsesprocessen og gør det lettere at håndtere oversættelser på tværs af flere sprog og platforme. Denne vejledning giver en trinvis gennemgang af opsætningen af Crowdin med dit projekt, herunder konfiguration, upload af kilder og download af oversættelser.

## 🔧 Installation og opsætning

For at komme i gang med Crowdin skal du installere Crowdin CLI globalt på din maskine og initialisere det inden i dit projektmappe.

### 📦 Installation af Crowdin CLI

Først installerer du Crowdin CLI globalt via npm:

```bash
npm install -g @crowdin/cli
```

### 🛠 Initialisering af Crowdin i dit projekt

Initialisér Crowdin i dit projekt ved at køre:

```bash
crowdin init
```

Denne kommando guider dig gennem opsætningsprocessen, herunder angivelse af projekt-ID, API-token og andre konfigurationsdetaljer.

## 🗂️ Konfigurationsvejledning

### 📄 Crowdin-konfigurationsfilen (`crowdin.yml`)

Crowdin-konfigurationsfilen (`crowdin.yml`) definerer, hvordan dine kildefiler mappes, og hvor oversættelser skal placeres. Nedenfor er et eksempel på konfiguration:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Vigtige konfigurationsparametre

- **`project_id`**: Dit Crowdin-projekt-ID. Dette identificerer det projekt inden for Crowdin, hvor oversættelser håndteres.
- **`api_token`**: API-tokenet, der bruges til autentifikation. Sørg for, at dette token har de korrekte tilladelser til at uploade og downloade oversættelser.
- **`base_path`**: Angiver base-mappen for kildefiler. I dette eksempel gemmes oversættelser i `./locales`-mappen.
- **`base_url`**: Base-URL'en for Crowdin-API'et.
- **`preserve_hierarchy`**: Når den er sat til `true`, bevarer Crowdin mappestrukturen for dine kildefiler i projektet.

### 📂 Filkonfiguration

`files`-sektionen mapper dine kildefiler til de stier, hvor oversættelser vil blive gemt. For eksempel:

- **Source Path**: Definerer placeringen af de originale oversættelsesfiler.
- **Translation Path**: Angiver, hvor de oversatte filer vil blive gemt i Crowdin. Placeholders som `%two_letters_code%` bruges til dynamisk at sætte sprogkoden i filstierne.

## ⬆️ Upload af kildefiler til Crowdin

Når din Crowdin-konfiguration er sat op, kan du uploade dine kildefiler med følgende kommando:

```bash
crowdin upload sources
```

Denne kommando uploader alle specificerede kildefiler i din konfiguration til Crowdin og gør dem tilgængelige for oversættelse.

## ⬇️ Download af oversættelser fra Crowdin

Når oversættelser er færdige eller opdateret i Crowdin, kan du downloade dem til dit projekt via:

```bash
crowdin download
```

Denne kommando henter de nyeste oversættelser fra Crowdin og gemmer dem i overensstemmelse med de stier, der er angivet i din konfigurationsfil.

## ⚙️ Best practices

### 🔑 Konsistent navngivning af nøgler

Sørg for, at oversættelsesnøgler er konsistente på tværs af alle filer for at undgå forvirring og duplikering.

### 🧹 Regelmæssig vedligeholdelse

Gennemgå og ryd op i ubrugte oversættelsesnøgler med jævne mellemrum for at holde dine filer organiserede og håndterbare.

### 🛠 Automatisér uploads og downloads

Integrér Crowdin CLI-kommandoerne i din CI/CD-pipeline for at automatisere upload af kildefiler og download af oversættelser, så dine oversættelser altid er ajour.

Ved at følge denne vejledning kan du sømløst integrere Crowdin i dit projekt og sikre en effektiv og organiseret tilgang til håndtering af dine internationaliseringsindsatser.
