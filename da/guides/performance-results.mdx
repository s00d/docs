### Beskrivelse

Sammenligner **plain Nuxt** (baseline uden i18n-modul), **i18n-micro** og **`@nuxtjs/i18n` v10.6** under én delt ordbogsprofil.

Fokus: byggetid, peak-RSS, deployerbar **kode vs. oversættelser vs. total** og serveradfærd under Artillery + Autocannon.

### Bemærkninger til metodologien

- Metrikker er **gennemsnit af 3 på hinanden følgende kørsler pr. fixture** (fixture A ×3, derefter B ×3, derefter C ×3 — ikke interleaved).
- **Oversættelser** omfatter locale-JSON under `locales/` / `_locales/` / `translations/`, alt under `chunks/raw/` og matchende locale-chunks. Ældre rapporter, der viste `@nuxtjs/i18n` "translations: 0 B" og en enorm "code"-kolonne, tællede message-chunks som app-kode.
- **plain-nuxt** serverer det samme leaf-volumen som statisk `public/translations`-JSON (ikke statiske JS-imports). Under Artillery er den baseline I/O-tung. Det er ikke "i18n-overhead", det er omkostningerne ved at hente store JSON pr. request.

### Kørsler

Alle metrikker nedenfor er **gennemsnit af 3 kørsler**.

### Fixture-profil

| Parameter | Værdi |
|------|-------|
| Locales | **4** (`en`, `de`, `ru`, `fr`) |
| Sider | **2** (`index`, `page`) |
| Index-træ | dybde **5**, gren **7** → **16.807** leaf-nøgler / locale |
| Sekundære sider | dybde **5**, gren **6** → **7.776** leaf-nøgler / side / locale |
| Mål | Standard CLI-profil (`--locales 4 --keys 10000`). Skru op for parametrene til regressionsradar-belastninger |

Ordbøger kommer fra `test/fixtures/perf-shared/runtime.json` (skrevet af CLI'en), så alle tre fixtures forbliver i sync.

## Build-performance for test/fixtures/plain-nuxt

- **Byggetid**: 5,32 sekunder
- **Bundle-størrelse**: 8,33 MB (kode: 1,53 MB, oversættelser: 6,8 MB)
- **Kode-bundle**: klient: 201,88 KB, server: 1,33 MB
- **Maks. / gns. CPU**: 207,10% / 166,29%
- **Maks. / gns. hukommelse**: 810,26 MB / 585,14 MB

## Build-performance for test/fixtures/i18n

- **Byggetid**: 8,34 sekunder
- **Bundle-størrelse**: 9,37 MB (kode: 2,16 MB, oversættelser: 7,21 MB)
- **Kode-bundle**: klient: 315,17 KB, server: 1,86 MB
- **Maks. / gns. CPU**: 203,97% / 164,39%
- **Maks. / gns. hukommelse**: 1820,57 MB / 1177,11 MB

## Build-performance for test/fixtures/i18n-micro

## Bemærkninger

- Delt profil: 4 locales × 2 sider × ~16,8k index-leaves.
- Artillery: 6s opvarmning @6 VU/s + 60s hoved @60 VU/s. Autocannon: 10 forbindelser × 10s.
- Kør igen: `pnpm test:performance` eller `pnpm -C scripts cli performance --locales N --keys K --only all|micro|i18n|plain --runs N`.
