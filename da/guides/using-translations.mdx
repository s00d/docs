# Brug af oversættelser i komponenter

Når modulet er installeret og konfigureret, kan du vise oversættelser ved at kalde `$t('your_key')` i dine Vue-templates og -scripts.

## 1. Root-niveau- & sidespecifikke oversættelsesfiler

1. **Root-niveau**-oversættelser ligger direkte under `/locales`-mappen (f.eks. `/locales/en.json`, `/locales/fr.json`). Ved build-tid merges de automatisk ind i hver sidespecifik fil, hvilket gør dem tilgængelige på alle sider.
2. **Sidespecifikke** oversættelser bor under `/locales/pages/...`, svarende til strukturen i din Nuxt pages-mappe:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. Brug i template med `$t`

I dine `.vue`-filer kan du bruge `$t` direkte i template:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
`$t` kan returnere **objekter**, hvis nøglen peger på en nested JSON-node (f.eks. `$t('header')` → `\{ title: "Hi" \}`). I templates renderes dette som `[object Object]`. Brug `$ts`, når du har brug for en garanteret streng, eller angiv en mere specifik nøgle som `$t('header.title')`. Se [API-reference — $t vs $ts](/api/methods#t) for detaljer.
</Tip>

## 3. Skift af den aktuelle locale

For at ændre sprog i din app kan du hente `$locale` fra `useI18n()` og tildele den en ny kode:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. Nested nøgler og placeholders

- **Nested nøgler** bruger dot-notation, f.eks. `nested.key.deeper`.
- **Placeholders** giver dig mulighed for at indsætte dynamiske værdier:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. Tips & best practices

- **Konfliktende nøgler**: Hvis en sidespecifik fil indeholder samme nøgle som en root-niveau-fil, har den sidespecifikke version prioritet (root-oversættelser merges som en base ved build-tid).
- **Deaktivering af sidefiler**: Hvis du hellere ikke vil bruge sidespecifikke oversættelser, kan du sætte `disablePageLocales: true` i din Nuxt-konfiguration. På den måde bruges kun `/locales/*.json`-filerne.
- **Ingen direkte imports**: Du behøver ikke at gøre `import \{ useI18n \} from 'nuxt-i18n-micro'`; modulets auto-injektion håndterer det for dig.

Det var det! Med disse trin kan du hurtigt **begynde at hente oversættelser** fra root-niveau- eller sidespecifikke JSON-filer og **vise dem** i din Nuxt-applikation ved hjælp af `$t`.

## Yderligere ressourcer

For at udforske mere avancerede funktioner, sørg for at tjekke:

1. **`<i18n-t>`-komponent**  
   `<i18n-t>`-komponenten er et kraftfuldt alternativ til `$t`, især nyttig i situationer med nested elementer, avanceret brug af placeholders og mere komplekse oversættelsesstrukturer.

- **Dokumentation**: [i18n-t](/api/components/i18n-t)

2. **`useI18n` Composable**  
   `useI18n`-composablen tilbyder et komplet sæt af funktioner og reaktive egenskaber til håndtering af oversættelser, skift af locales, formatering og meget mere.

- **Dokumentation**: [useI18n](/api/composables/use-i18n)
