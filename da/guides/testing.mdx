# 🧪 Test af `Nuxt I18n Micro`-modulet

## 📖 Introduktion til testning

Test af `Nuxt I18n Micro`-modulet er afgørende for at sikre, at din applikations lokaliseringsfunktioner fungerer som forventet. Denne dokumentation guider dig gennem opsætning af testmiljøet, oprettelse af mock-konfigurationer til vitest og skrivning af tests til dine komponenter. Se et praktisk eksempel i [eksempelprojektet på GitHub](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/test-utils/example).

Se [Test af routing-strategier](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/testing-strategies.md) for, hvordan dette repository kører sine egne suites — Vitest-projekterne `unit` / `integration` / `e2e`, filerne pr. strategi (`test/strategies-*.test.ts`) og generering af regressioner.

## 🛠️ Opsætning af testmiljøet

### 1. Installer `@i18n-micro/test-utils`

Først skal du installere test-utilities til `Nuxt I18n Micro`. Denne pakke leverer de nødvendige værktøjer til at mocke og teste dine i18n-konfigurationer.

```bash
npm install @i18n-micro/test-utils --save-dev
```

### 2. Opret en mock-konfigurationsfil

Opret dernæst en fil til opsætning af mock-i18n-konfigurationen. Denne fil bruges til at mocke i18n-funktioner og -utilities under dine tests.

```typescript
// tests/unit-setup.ts

import { mockNuxtImport } from '@nuxt/test-utils/runtime'
import { vi } from 'vitest'
import { i18nUtils } from '@i18n-micro/test-utils'

export function createFakeI18n() {
  return {
    $getLocale: vi.fn(i18nUtils.getLocale),
    $t: vi.fn(i18nUtils.t),
    $tc: vi.fn(i18nUtils.tc),
    $setLocale: vi.fn(i18nUtils.setLocale),
    $getLocaleName: vi.fn(i18nUtils.getLocaleName),
    $setLocaleName: vi.fn(i18nUtils.setLocaleName),
    $getLocales: vi.fn(i18nUtils.getLocales),
    $setLocales: vi.fn(i18nUtils.setLocales),
    $defaultLocale: vi.fn(i18nUtils.defaultLocale),
    $setDefaultLocale: vi.fn(i18nUtils.setDefaultLocale),
    $getRouteName: vi.fn(i18nUtils.getRouteName),
    $settRouteName: vi.fn(i18nUtils.settRouteName),
    $ts: vi.fn(i18nUtils.ts),
    $tn: vi.fn(i18nUtils.tn),
    $td: vi.fn(i18nUtils.td),
    $has: vi.fn(i18nUtils.has),
    $resolveTranslations: vi.fn(i18nUtils.resolveTranslations),
    $setTranslation: vi.fn(i18nUtils.setTranslation),
    $mergeTranslations: vi.fn(i18nUtils.mergeTranslations),
    $switchLocaleRoute: vi.fn(i18nUtils.switchLocaleRoute),
    $switchLocalePath: vi.fn(i18nUtils.switchLocalePath),
    $switchLocale: vi.fn(i18nUtils.switchLocale),
    $switchRoute: vi.fn(i18nUtils.switchRoute),
    $localeRoute: vi.fn(i18nUtils.localeRoute),
    $localePath: vi.fn(i18nUtils.localePath),
    $setI18nRouteParams: vi.fn(i18nUtils.setI18nRouteParams),
  }
}

mockNuxtImport<() => ReturnType<typeof createFakeI18n>>('useI18n', () => vi.fn(() => createFakeI18n()))

export const setTranslationsFromJson = i18nUtils.setTranslationsFromJson
```

### 3. Konfigurer Vitest

Konfigurer nu Vitest til at bruge mock-konfigurationsfilen og opsæt testmiljøet.

```typescript
// vitest.config.ts

import { defineVitestConfig } from '@nuxt/test-utils/config'

export default defineVitestConfig({
  test: {
    watch: false,
    setupFiles: ['./tests/unit-setup.ts'],
    include: ['./**/*.spec.ts'],
  },
})
```

## 🧪 Skrivning af tests

### Eksempelkomponent

Her er et eksempel på en simpel komponent, der bruger `useI18n`-composablen til at oversætte beskeder.

```vue
<script setup lang="ts">
const { $t } = useI18n()

const props = defineProps({
  message: {
    type: String,
    default: null,
  },
})

// Test to see that $t works in script setup as well as the template
const message = props.message || $t('defaultMessage')
</script>

<template>
  <div>
    <p>Test from component: {{ $t('welcome') }}</p>
    <p data-testid="message">Test message from props: {{ message }}</p>
  </div>
</template>
```

### Testfil

Nu skriver vi en test for denne komponent.

```typescript
// tests/unit/example.spec.ts

import { describe, it, expect, beforeEach } from 'vitest'
import { mount } from '@vue/test-utils'
import ExampleComponent from '@/components/ExampleComponent.vue'
import fs from 'fs'
import path from 'path'
import { setTranslationsFromJson } from './unit-setup'

describe('ExampleComponent', () => {
  beforeEach(async () => {
    const fileContent = fs.readFileSync(path.join(__dirname, '../../locales/en-GB.json')).toString()
    await setTranslationsFromJson('en', JSON.parse(fileContent))
  })

  it('renders the welcome message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.text()).toContain('Test from component: Welcome')
  })

  it('renders the default message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Default Message')
  })

  it('renders the custom message correctly', () => {
    const wrapper = mount(ExampleComponent, {
      props: {
        message: 'Custom Message',
      },
    })
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Custom Message')
  })
})
```

## 📝 Bedste praksis for testning

- **🔧 Mock i18n-funktioner:** Mock altid i18n-funktioner med `@i18n-micro/test-utils` for at sikre konsistente og forudsigelige testresultater.
- **⚙️ Brug Vitest til unit-tests:** Vitest er et kraftfuldt testframework til Vue-applikationer. Brug det til at skrive unit-tests til dine komponenter.
- **📚 Dokumentér dine tests:** Dokumentér tydeligt formålet og de forventede udfald for hver test. Det bevarer klarheden og gør det lettere for andre (eller dig selv i fremtiden) at forstå testene.

## 📊 i18n-hjælpermetoder

Nedenfor er en tabel over alle hjælpermetoder leveret af `@i18n-micro/test-utils`.

| Metode                                          | Beskrivelse                                                                                                                                |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `t(key, params, defaultValue)`                  | Oversætter en nøgle med valgfrie parametre og en standardværdi.                                                                            |
| `tc(key, params, defaultValue)`                 | Oversætter en nøgle med understøttelse af pluralisering.                                                                                   |
| `setTranslationsFromJson(locale, translations)` | Indlæser oversættelser fra et JSON-objekt for et bestemt locale.                                                                           |
| `getLocale()`                                   | Returnerer det aktuelle locale.                                                                                                            |
| `setLocale(val)`                                | Sætter det aktuelle locale.                                                                                                                |
| `getLocaleName()`                               | Returnerer det aktuelle locale-navn.                                                                                                       |
| `setLocaleName(val)`                            | Sætter det aktuelle locale-navn.                                                                                                           |
| `getLocales()`                                  | Returnerer listen over tilgængelige locales.                                                                                               |
| `setLocales(val)`                               | Sætter listen over tilgængelige locales.                                                                                                   |
| `defaultLocale()`                               | Returnerer standard-locale.                                                                                                                |
| `setDefaultLocale(val)`                         | Sætter standard-locale.                                                                                                                    |
| `getRouteName()`                                | Returnerer det aktuelle rutenavn.                                                                                                          |
| `settRouteName(val)`                            | Sætter det aktuelle rutenavn.                                                                                                              |
| `ts(key, params, defaultValue)`                 | Oversætter en nøgle og returnerer resultatet som en streng.                                                                                |
| `tn(value, options?)`                           | Formaterer et tal med inline `Intl.NumberFormatOptions`. Navngivne formater kræver modulkonfiguration og er ikke tilgængelige i denne selvstændige hjælper. |
| `td(value, options?)`                           | Formaterer en dato med inline `Intl.DateTimeFormatOptions`. Navngivne formater kræver modulkonfiguration og er ikke tilgængelige i denne selvstændige hjælper. |
| `has(key)`                                      | Tjekker, om en oversættelsesnøgle findes.                                                                                                  |
| `resolveTranslations()`                         | Returnerer det aktive oversættelsestræ for det aktuelle locale og rute.                                                                    |
| `setTranslation(key, value)`                    | Erstatter værdien ved `key` i den aktive ordbog (erstatning, ikke fletning).                                                               |
| `mergeTranslations(newTranslations)`            | Fletter oversættelser ind i det aktive locale på runtime.                                                                                  |

Ved at følge disse trin kan du effektivt teste `Nuxt I18n Micro`-modulet og sikre, at din applikations lokaliseringsfunktioner fungerer som forventet.
