---
title: "useI18n"
description: "useI18n returnerer runtime-hjælperne (`$t`, `$tc`, `$localePath`, …) som et almindeligt objekt, både med og uden `$`-præfikset."
---

`useI18n()` returnerer modulets runtime-hjælpere som et almindeligt objekt. Brug det i `<script setup>`, composables og plugins i stedet for at gribe til `useNuxtApp()`. Hver hjælper findes under sit `$`-navn og et alias uden præfiks: `t` og `$t` er den samme funktion.

## Signatur {#signature}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Alle runtime-hjælpere som et almindeligt objekt.

De samme funktioner, som pluginet injicerer som `$t`, `$tc` og så videre, er tilgængelige både
under navnet med dollartegn og under et alias uden præfiks — så både `const { t } = useI18n()` og
`const { $t } = useI18n()` virker.

**Returnerer** — hjælperne beskrevet i [metodereferencen](/da/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

Det returnerede objekt indeholder alle hjælpere fra [`PluginsInjections`](/da/api/methods). Hver af dem er dokumenteret på siden [Hjælpere](/da/api/methods).

## Eksempel {#example}

```vue
<script setup lang="ts">
const { t, tc, localePath, switchLocale, getLocale } = useI18n()

const title = computed(() => t('page.title'))
</script>

<template>
  <h1>{{ title }}</h1>
  <p>{{ tc('items', 3) }}</p>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
  <button @click="switchLocale(getLocale() === 'en' ? 'de' : 'en')">{{ t('nav.switch') }}</button>
</template>
```

## Ikke i typen {#not-in-the-type}

`$defineI18nRoute` er kun typet på `useNuxtApp()`:

```ts
const { $defineI18nRoute } = useNuxtApp()
```
