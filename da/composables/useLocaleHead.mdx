---
title: "useLocaleHead"
description: "useLocaleHead bygger i18n-SEO-tags (lang, dir, canonical, hreflang, og:locale) som et objekt, du sender til useHead."
---

`useLocaleHead()` bygger i18n-head-tags for den aktuelle route: `lang` og `dir` på `<html>`, et canonical-link, `hreflang`-alternativer med `x-default`, `og:url`, `og:locale` og `og:locale:alternate`. Brug den, når du sætter [`meta: false`](/da/api/module-options#meta) og selv håndterer `useHead`; med `meta: true` registrerer modulet allerede disse tags, og ændringer pr. side går gennem [`useI18nHead`](/da/composables/useI18nHead).

## Signatur {#signature}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { build: () => LocaleHead; metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }, LocaleHead | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

SEO-head-tags for den aktuelle route: `hreflang`-alternativer for hver locale plus
`x-default`, et canonical-link, `og:locale` samt `lang`/`dir` på `<html>`.

Kun nødvendig, når `meta` er slået fra, eller standardværdierne skal justeres — med `meta: true`
registrerer modulet selv de samme tags.

| Parameter | Type | Beskrivelse |
| --- | --- | --- |
| `options` | `UseLocaleHeadOptions` |  |

**Returnerer** — `metaObject`, en ref med head-objektet klar til at blive sendt til `useHead`; `updateMeta` opdaterer det; `build` beregner head-objektet ud fra den aktuelle route (reaktivt, når det læses i en getter, f.eks. `useHead(() => build())`)

```ts
const { metaObject } = useLocaleHead({ addSeoAttributes: true })
useHead(metaObject)
```

## Indstillinger {#options}

| Indstilling | Standard | Beskrivelse |
| --- | --- | --- |
| `addDirAttribute` | `true` | Sæt `dir` på `<html>` ud fra localens `dir` (`'auto'`, hvis den ikke har nogen). |
| `identifierAttribute` | `'id'` | Attribut, der identificerer hvert tag (`i18n-can`, `i18n-og`, `i18n-alternate-<hreflang>`, …), så opdateringer erstatter tags i stedet for at tilføje nye. |
| `addSeoAttributes` | `true` | Udsend canonical-, `hreflang`- og `og:`-tags. `false` beholder kun `htmlAttrs`. |
| `baseUrl` | `'/'` | Origin, der sættes foran hver URL. Behold `'/'` for relative URL'er; angiv `'https://example.com'` for absolutte. |
| `autoUpdate` | `true` | Genopbyg `metaObject`, når routen eller tilstanden `i18n-locale` ændres. |

## Hvad den udsender {#what-it-emits}

- Intet på en route uden match (404) eller med `disableMeta` for den aktive locale.
- Canonical og `og:url`: `$switchLocalePath(<active locale>)`, med query reduceret til [`canonicalQueryWhitelist`](/da/api/module-options#canonicalquerywhitelist) og [`trailingSlash`](/da/api/module-options#trailingslash) anvendt.
- `hreflang`: ét link pr. aktiveret locale, som siden findes i, `hreflang = iso || code`, idet locales med `seo: false` springes over; med `hreflangBaseLanguage: true` udsender den første regionale locale for et sprog også sit tag for det rene sprog. Ingen under `no_prefix`.
- `x-default`: URL'en for standard-localen, medmindre strategien er `no_prefix`, standard-localen har `seo: false`, eller siden ikke findes i den.
- `og:locale` / `og:locale:alternate`: fra localens `og` eller dens konverterede `iso` (`en-US` → `en_US`); springes over med en advarsel under udvikling, når ingen af dem virker.

## Eksempel {#example}

```ts
// app.vue, with i18n.meta: false
const { metaObject } = useLocaleHead({ baseUrl: 'https://example.com' })
useHead(metaObject)
```

`build()` returnerer det samme objekt uden ref'en: `useHead(() => build())` forbliver reaktivt uden en watcher.
