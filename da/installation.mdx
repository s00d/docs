## Krav

- **Node.js**: 18 eller nyere.
- **Nuxt**: 3.x eller 4.x.

Modulet understøtter både Nuxt 3-projektlayoutet (`pages/**/*.vue`) og Nuxt 4-layoutet (`app/pages/**/*.vue`). Oversættelser bor i projekt-roden som konvention (`locales/`), selv når `app/`-mappen fra Nuxt 4 anvendes.

## Installer Nuxt-modulet

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Registrer det i `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Se [Hurtigstart](/quickstart) for en fuld gennemgang eller [Konfigurationsreference](/guides/configuration) for alle options.

## Projektlayout

Som standard forventer modulet:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Root-niveau-filer merges ind i hver sidespecifik fil ved build-tid. Sidespecifikke filer oprettes automatisk, hvis de mangler under `nuxt dev`.

## Nuxt 4-layout

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

For at samle oversættelser under `app/`, sæt `translationDir: 'app/locales'`.

## TypeScript

Modulet genererer ambient-typer for `useI18n`, `$t` og relaterede hjælpere baseret på dine standard-locale-filer. Dette er aktiveret som standard (`types: true`).

For stærkere typing af oversættelsesnøgler, se [`@i18n-micro/types-generator`](/integrations/types-generator).
