## Krav

- **Node.js**: 18 eller nyere.
- **Nuxt**: 3.x eller 4.x.

Modulet understøtter både Nuxt 3-projektlayoutet (`pages/**/*.vue`) og Nuxt 4-layoutet (`app/pages/**/*.vue`). Oversættelser ligger som konvention i projektets rod (`locales/`), også når du bruger `app/`-mappen i Nuxt 4.

## Installer Nuxt-modulet

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Registrer det i `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Se [Kom hurtigt i gang](/quickstart) for en komplet gennemgang eller [Konfigurationsreferencen](/guides/configuration) for alle indstillinger.

## Projektlayout

Som standard forventer modulet:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Filer på rodniveau flettes ind i hver sideafgrænset fil ved buildtid. Sideafgrænsede filer oprettes automatisk, når de mangler under `nuxt dev`.

## Nuxt 4-layout

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

For at kolokere oversættelser under `app/` skal du sætte `translationDir: 'app/locales'`.

## TypeScript

Modulet genererer ambient-typer for `useI18n`, `$t` og relaterede hjælpere ud fra dine filer for standard-locale. Dette er aktiveret som standard (`types: true`).

For stærkere typning af oversættelsesnøgler, se [`@i18n-micro/types-generator`](/integrations/types-generator).
