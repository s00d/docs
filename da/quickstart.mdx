## 🚀 Hurtigstart

### Installation

Installer modulet i din Nuxt-applikation:

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

### Grundlæggende konfiguration

Tilføj modulet til din `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

<Tip>
- **Root-niveau-filer** (`locales/en.json` osv.) — oversættelser delt på tværs af hele appen (menuer, footer, fælles UI). Med `translationPayloads.mode: 'premerged'` (standard) merges de ind i hver side ved build-tid.
- **Sidespecifikke filer** (`locales/pages/<route>/<locale>.json`) — oversættelser unikke for specifikke sider, indlæses kun når siden besøges
- **Dynamiske ruter** — `pages/articles/[id].vue` mappes til `locales/pages/articles-id/` (kantede parenteser erstattes med bindestreger)
- **Auto-generering** — alle oversættelsesfiler oprettes automatisk, hvis de mangler under `nuxt dev`
</Tip>

<Info>
Modulet understøtter begge layouts:

- **Pages**: `pages/**/*.vue` (Nuxt 3) eller `app/pages/**/*.vue` (Nuxt 4)
- **Translations**: hold `locales/` på **projekt-rod** som standard (anbefalet konvention), ikke inde i `app/`

```tree
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   ├── en.json
│   └── pages/
└── nuxt.config.ts
```

Valgfri kolokation: `i18n: \{ translationDir: 'app/locales' \}` (se [fixture `n3`](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/n3)).

Til den valgfri CLI-hjælper `text-to-i18n`, brug [`nuxt-i18n-micro-cli` ≥ 2.1.1](/guides/cli#-text-to-i18n-command), så `app/pages` og `app/components` scannes fra projekt-roden.
</Info>

### Grundlæggende brug

Brug oversættelser i dine komponenter:

```vue
<template>
  <div>
    <h1>{{ $t('welcome') }}</h1>
    <p>{{ $t('description', { name: 'World' }) }}</p>

    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" @click="$switchLocale(locale.code)">
        {{ locale.code }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useI18n } from '#imports'

const { $t, $getLocales, $switchLocale } = useI18n()
</script>
```
