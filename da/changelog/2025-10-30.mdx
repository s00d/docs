**Dato**: 2025-10-30

**Version**: `v2.0.0`

![v2.0.0 release](/images/2.0.0.png)

Vi introducerer server‑side HMR for oversættelsesfiler under udvikling. Når en JSON-oversættelse ændres, invaliderer servercachen kun de berørte nøgler, og efterfølgende forespørgsler modtager straks friske data—uden genstart.

## Hvad er nyt? {#what’s-new}

- Server‑side HMR for oversættelsesfiler
- Øjeblikkelig cache-invalidering pr. side/locale
- Problemfri DX, mens du redigerer indhold

## Sådan virker det {#how-it-works}

- Watcheren i `src/runtime/server/plugins/watcher.dev.ts` overvåger `<rootDir>/<translationDir>/**/*.json`
- Sidefiler (f.eks. `pages/<page>/<locale>.json`) invaliderer `_locales:merged:<page>:<locale>`
- Filer på rodniveau (f.eks. `<locale>.json`) invaliderer alle flettede nøgler for den locale
- Registreres automatisk fra `src/module.ts` i dev, når `experimental.hmr !== false`

## Konfiguration {#configuration}

```ts
export default defineNuxtConfig({
  i18n: {
    experimental: { hmr: true }, // default in dev
  },
})
```
