**Dato**: 2026-05-14

**Version**: `v3.20.0`

![v3.20.0-udgivelse](/images/3.20.0.png)

Denne udgivelse refaktorerer Nuxt-runtime til et dedikeret **`NuxtI18n`**-lag, opdeler redirect-håndteringen mellem server og klient og retter flere SSR-/hydreringsregressioner. Offentlige composables og `nuxt.config`-indstillinger forbliver de samme for typiske apps.

## Hvad er nyt? {#what’s-new}

### `NuxtI18n` og `NuxtTranslationLoader` {#nuxti18n-&-nuxttranslationloader}

Runtime-i18n-logikken flyttes ud af det monolitiske plugin til fokuserede klasser:

- **`NuxtI18n`** — aktivt visningslag for oversættelser (`$t`, `$has`, locale-/routekontekst, fletning/oprydning ved overgange)
- **`NuxtTranslationLoader`** — indlæser chunks, skifter kontekst ved navigation, forsyner SSR-payloadet
- **`createNuxtI18nPluginApi`** — tynd plugin-overflade (`$switchLocale`, `$localeRoute` osv.)

Se den opdaterede [Cache & Storage Architecture](https://s00d.github.io/nuxt-i18n-micro/v3/api/i18n-cache-api) og [Ydelse](/da/guide/performance).

### SSR-payload via `useState('i18n-ssr-chunks')` {#ssr-payload-via-usestate‘i18n-ssr-chunks’}

SSR-oversættelser serialiseres gennem **Nuxt state**, ikke et `window.__I18N__`-script-tag:

1. Serveren indlæser chunks → `useState('i18n-ssr-chunks')`
2. Klienten hydrerer → `translationStorage.seedFromSsrChunks()`
3. Ingen ekstra fetches ved første visning

Den gamle læsesti via `window.__I18N__` er **fjernet**.

### Opdeling af redirect-arkitekturen {#redirect-architecture-split}

Redirects er nu miljøspecifikke for tydeligere adfærd og mindre hakken på klienten:

| Miljø    | Komponent                      | Rolle                                       |
| -------------- | ------------------------------ | ------------------------------------------ |
| **Server-SSR** | `06.redirect.ts` (kun server) | 302 før rendering, 404-kontroller, cookie-synkronisering |
| **Klient-SPA** | `i18n-redirect.global.ts`      | Global route-middleware ved navigation      |

Klient-redirects udleder locale fra **målrouten**, bevarer **query string og hash** og respekterer `redirects: false` (middleware registreres ikke). Se [Locale-registrering — redirects pr. strategi](/da/guide/locale-detection#redirects-per-strategy).

### Timing for `i18n:register`-hooket {#i18nregister-hook-timing}

Pluginet **`05.hooks`** (`dependsOn: i18n-plugin-loader`) udløser `i18n:register`, efter loaderen er klar — ved opstart og ved navigation — så brugerplugins pålideligt modtager hændelsen. Deaktivér med `hooks: false`. Se [Hændelser](/da/api/events).

### Udtrækning af `defineI18nRoute` ved build-tid {#build-time-definei18nroute-extraction}

Et Vite-unplugin scanner sidernes `.vue`-filer ved build-tid og skriver routemeta til `@i18n-micro/route-strategy`. Runtime-`$defineI18nRoute` i `script setup` bevares til udvikling og inline-konfiguration. Se [Oversættelser pr. komponent](/da/guide/per-component-translations).

## Fejlrettelser {#bug-fixes}

- **SSR-hydrering** — klon reaktive SSR-chunks før `Object.freeze` (retter `#locale`-/404-nedbrud på klienten)
- **Locale-skift** — udskift visningslaget ved locale-ændring (ingen forældede nøgler fra den forrige locale)
- **Klient-redirect** — locale fra målrouten; query/hash bevares ved redirect
- **`has()`** — kontrollerer kun den aktive locale; fallback gælder i `$t()`, ikke i `$has()`
- **`defineI18nRoute`-meta** — cache pr. plugininstans; længste `rootDir`-match; korrekte stier for `pages/index` vs. `pages/index/index`

## Breaking changes {#breaking-changes}

Ingen ved standardbrug af `nuxt.config` + composables. Interne stier og SSR-injektionsmekanismen er ændret; apps, der var afhængige af manuel `window.__I18N__`-injektion, skal i stedet bruge Nuxt-payload / modulets API'er.

## Hvorfor det er vigtigt {#why-it-matters}

- **Mere pålidelig overdragelse fra SSR → klient** — Nuxt-native state i stedet for ad hoc-globaler
- **Tydeligere redirect-model** — server-302 før visning; klient-middleware kun hvor det er nødvendigt
- **Lettere at vedligeholde** — runtime opdelt i testbare enheder med fokuserede regressionstests
