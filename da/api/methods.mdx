# 🛠️ Metoder

Denne side dokumenterer alle tilgængelige metoder i nuxt-i18n-micro. Metoderne er organiseret efter funktion for lettere navigation.

### `$getI18nConfig`

{/* generated:method:$getI18nConfig — do not edit; run `pnpm run docs:generate` */}

```ts
() => ModuleOptionsExtend
```

Den resolverede modulkonfiguration, som runtime ser den.

{/* /generated:method:$getI18nConfig */}

```typescript
const nuxtApp = useNuxtApp()
const { localeCookie, strategy, hooks } = nuxtApp.$getI18nConfig()
```

Brug i stedet `getI18nConfig()` fra `#build/i18n.strategy.mjs` til buildtid eller kontekster uden Nuxt.

<Info>
`serverTranslationPreload` er en privat modulindstilling, som kun eksponeres i serverens private config (`#i18n-internal/config`). Den er ikke en del af det offentlige runtime-API og kan ændres uden varsel.
</Info>

## 🔍 Oversættelsesmetoder

Kernemetoder til at hente og styre oversættelser.

### `$t`

{/* generated:method:$t — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Oversæt en nøgle og interpoler `params` ind. Returnerer `defaultValue`, når nøglen mangler, eller nøglen selv, hvis der ikke er angivet en standard.

{/* /generated:method:$t */}

```typescript
const welcomeMessage = $t('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

<Warning>
`$t` returnerer `CleanTranslation`, som er `string | number | boolean | Translations | PluralTranslations | null`. Hvis nøglen peger på et **indlejret objekt** i din JSON (f.eks. `$t('header')`, når JSON'en indeholder `\{ "header": \{ "title": "Hi" \} \}`), er returværdien det **objekt**, ikke en streng. Bruger du det direkte i en Vue-template (<code v-pre>\{\{ $t('header') \}\}</code>), renderes det som `[object Object]`.

**Sådan undgår du det:**

- Brug en mere specifik nøgle: `$t('header.title')` → `"Hi"`
- Brug `$ts()`, som altid returnerer en streng (kalder `.toString()` på ikke-strenge)
- Brug `$t` med en indlejret nøgle, når du bevidst vil tilgå underobjekter programmatisk
</Warning>

### `$ts`

{/* generated:method:$ts — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string) => string
```

Som `$t`, men returnerer altid en streng: et objekt eller array bliver stringificeret i stedet for at blive returneret som det er.

{/* /generated:method:$ts */}

```typescript
const welcomeMessage = $ts('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

### `$_t` og `$_ts`

{/* generated:method:$_t — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Bind `$t` til en bestemt rute, så du kan oversætte uden for den aktuelle side. For eksempel et layout, der viser et link til en anden rute.

{/* /generated:method:$_t */}

{/* generated:method:$_ts — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => string
```

Bind `$ts` til en bestemt rute. Se `$_t`.

{/* /generated:method:$_ts */}

Rutebundne varianter af `$t` og `$ts`. De tager en **rute** først og returnerer en oversættelsesfunktion, der er låst til den rutes locale- og sidekontekst.

- **Adgang**: `useNuxtApp()` (også reeksporteret af `useI18n()` som `$_t` / `$_ts`)

Brug disse, når den aktive rute under SSR eller overgange afviger fra `router.currentRoute`. For eksempel inde i `<i18n-t>`, `<i18n-group>`, eller når du renderer indhold for et bestemt `route`-objekt.

```typescript
import { useRoute, useNuxtApp } from '#imports'

const route = useRoute()
const { $_t, $_ts } = useNuxtApp()

const $t = $_t(route)
const title = $t('page.title')

// String-safe variant
const label = $_ts(route)('page.label')
```


### `$tc`

{/* generated:method:$tc — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params: number | Params, defaultValue?: string) => string
```

Oversæt med pluralisering. `params` kan være selve antallet eller et objekt, der indeholder `count`.

{/* /generated:method:$tc */}

**Oversættelsesformat**: former adskilt med `|`. Placer pladsholdere i **hver** form:

```json
{
  "apples": "no apples | one apple | {count} apples",
  "cart": "no items for {name} | one item for {name} | {count} items for {name}"
}
```

```typescript
$tc('apples', 0) // "no apples"
$tc('apples', 1) // "one apple"
$tc('apples', 10) // "10 apples"

// count + other params (second argument must be an object)
$tc('cart', { count: 10, name: 'Alice' }) // "10 items for Alice"
```


**Komponentalternativ** — `<i18n-t keypath="cart" :plural="count" :params="\{ name \}" />` (fletter `count` med `params` internt).


### `$mergeTranslations`

{/* generated:method:$mergeTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
(newTranslations: Translations) => void
```

Flet oversættelser ind i det aktive locale på runtime og overskriv det, der er indlæst.

{/* /generated:method:$mergeTranslations */}

```typescript
$mergeTranslations({
  welcome: 'Bienvenue, {username}!',
})
// Output: Updates the translation cache with the new French translation
```

### `$resolveTranslations`

{/* generated:method:$resolveTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
() => Translations
```

Alle oversættelser, der aktuelt ligger i hukommelsen for det aktive locale og rute, som et træ. Skrivebeskyttet visning af det, `$t()` kan resolve lige nu.

{/* /generated:method:$resolveTranslations */}

```typescript
const tree = $resolveTranslations()
// { aaa: { bbb: 'ccc' }, ddd: 1111 } — the same dictionary $t() reads from
```

Brug denne, når du har brug for den fulde in-memory-ordbog (DevTools, tests, runtime-editorer). Behandl returværdien som skrivebeskyttet. Skift værdier gennem `$setTranslation` eller flet patches ind med `$mergeTranslations`.

### `$setTranslation`

{/* generated:method:$setTranslation — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, value: unknown) => void
```

Erstat værdien ved `key` i den aktive ordbog. Dette er en erstatning, ikke en fletning. Brug `$mergeTranslations`, når eksisterende søskende skal bevares.

{/* /generated:method:$setTranslation */}

```typescript
$setTranslation('aaa', { fff: 'ggg' }) // replaces the whole `aaa` subtree
$setTranslation('aaa', 'text')          // replaces `aaa` with a string
$setTranslation('ddd', 1111)            // scalar at the top level
$setTranslation('aaa.bbb', 'nested')    // dotted path
```

Dette er en **erstatning**, ikke en fletning. Eksisterende søskende under samme nøgle fjernes. Brug `$mergeTranslations` for at patche uden at miste søskende.

### `$setMissingHandler`

{/* generated:method:$setMissingHandler — do not edit; run `pnpm run docs:generate` */}

```ts
(handler: MissingHandler | null) => void
```

Installer et callback, der kaldes for hver uløst nøgle. Angiv `null` for at fjerne den.

{/* /generated:method:$setMissingHandler */}

**Typedefinition**:

```typescript
type MissingHandler = (locale: string, key: string, routeName: string, instance?: unknown, type?: string) => void
```

```typescript
// Set a custom handler
$setMissingHandler((locale, key, routeName) => {
  console.error(`Missing translation: ${key} in ${locale} for route ${routeName}`)
  // Send to Sentry or other error tracking service
  // Sentry.captureMessage(`Missing translation: ${key}`)
})

// Remove the handler
$setMissingHandler(null)
```

**Brugsscenarier**:

- Log manglende oversættelser til fejlsporingstjenester (Sentry, LogRocket osv.)
- Indsaml analytics om manglende oversættelser
- Brugerdefineret fejlhåndtering for manglende oversættelsesnøgler

## 🔢 Tal- og datoformatering

Metoder til at formatere tal og datoer efter locale-konventioner.

### `$tn`

{/* generated:method:$tn — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Formatér et tal med `Intl.NumberFormat` i det aktive locale. En nøgle vælger et navngivet format fra konfigurationen.

{/* /generated:method:$tn */}

```typescript
// Inline options
const formattedNumber = $tn(1234567.89, { style: 'currency', currency: 'USD' })
// "$1,234,567.89"

// Named format (from nuxt.config i18n.numberFormats)
const price = $tn(1000, 'currency')
const priceDe = $tn(1000, 'currency', 'de')
const compact = $tn(1000, 'currency', { notation: 'compact' })
```

Ukendte navngivne formatnøgler falder tilbage til standardindstillinger for `Intl.NumberFormat`. I udvikling (klient) udsendes en `console.warn`, når `missingWarn` er aktiveret (standard).

**Eksempel på config**:

```ts
export default defineNuxtConfig({
  i18n: {
    numberFormats: {
      en: {
        currency: { style: 'currency', currency: 'USD' },
        decimal: { style: 'decimal', minimumFractionDigits: 2, maximumFractionDigits: 2 },
      },
      de: {
        currency: { style: 'currency', currency: 'EUR' },
      },
    },
  },
})
```

**Brugsscenarier**:

- Formatering af tal som valuta, procenter eller decimaler i det passende locale-format
- Genbrug af navngivne formater i hele appen (paritet med Vue I18n-migration)

### `$td`

{/* generated:method:$td — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Formatér en dato med `Intl.DateTimeFormat` i det aktive locale. En nøgle vælger et navngivet format fra konfigurationen.

{/* /generated:method:$td */}

```typescript
const formattedDate = $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' })
// "Friday, September 1, 2023"

const short = $td(new Date(), 'short')
const longDe = $td(new Date(), 'long', 'de')
```

Ukendte navngivne formatnøgler falder tilbage til standardindstillinger for `Intl.DateTimeFormat`. I udvikling (klient) udsendes en `console.warn`, når `missingWarn` er aktiveret (standard).

**Eksempel på config**:

```ts
export default defineNuxtConfig({
  i18n: {
    datetimeFormats: {
      en: {
        short: { year: 'numeric', month: 'short', day: 'numeric' },
        long: { year: 'numeric', month: 'long', day: 'numeric', weekday: 'long' },
      },
    },
  },
})
```

**Brugsscenarier**:

- Vise datoer i et format, der svarer til brugerens locale
- Dele forudindstillinger for korte/lange/dato-tid-formater i hele appen

### `$tdr`

{/* generated:method:$tdr — do not edit; run `pnpm run docs:generate` */}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

Formatér en dato som relativ tid ("3 dage siden") med `Intl.RelativeTimeFormat`.

### `$switchRoute`

{/* generated:method:$switchRoute — do not edit; run `pnpm run docs:generate` */}

```ts

```

{/* /generated:method:$switchRoute */}

**Eksempler**:

<CodeGroup>

## 🚦 Rutekonfiguration

Metoder til at konfigurere ruteadfærd og adgangskontrol.

### `$defineI18nRoute`

{/* generated:method:$defineI18nRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Registrer locale-konfiguration og oversættelser pr. side inde fra en komponent. Fletter ind i det aktive locale og genanvender, når locale skifter.

{/* /generated:method:$defineI18nRoute */}

> [!IMPORTANT]
> `$defineI18nRoute` leveres af **define-pluginet** og er kun tilgængelig på `useNuxtApp()`. Det er **ikke** en del af `useI18n()`-returobjektet.
> Destructure den altid fra `useNuxtApp()` inde i `script setup`. Kald af `$defineI18nRoute(...)` som en bar global kaster `"$defineI18nRoute is not defined"` under SSR/prerender.

**Parametre**:

- **locales**: `string[] | Record<string, Record<string, string>>` — Tilgængelige locales for ruten
- **localeRoutes**: `Record<string, string>` — Valgfri. Brugerdefinerede ruter for specifikke locales
- **disableMeta**: `boolean | string[]` — Valgfri. Deaktiverer i18n-metatags for alle eller specifikke locales

**Grundlæggende eksempel**:

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr', 'de'],
  localeRoutes: {
    en: '/welcome',
    fr: '/bienvenue',
    de: '/willkommen',
  },
  disableMeta: false,
})
```

> 📖 **For detaljerede brugseksempler, konfigurationsformater og bedste praksis, se [guiden om oversættelser pr. komponent](/guides/per-component-translations).**

### `$setI18nRouteParams`

{/* generated:method:$setI18nRouteParams — do not edit; run `pnpm run docs:generate` */}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Sæt locale-specifikke params for den aktuelle rute, så et dynamisk segment kan afvige pr. sprog. Kald den under SSR, før head'et renderes.

{/* /generated:method:$setI18nRouteParams */}

```typescript
// in pages/news/[id].vue
// for en/news/1-first-article
const { $switchLocaleRoute, $setI18nRouteParams, $defineI18nRoute } = useNuxtApp()
$defineI18nRoute({
  localeRoutes: {
    en: '/news/:id()',
    fr: '/nouvelles/:id()',
    de: '/Nachricht/:id()',
  },
})
const { data: news } = await useAsyncData(`news-${params.id}`, async () => {
  let response = await $fetch("/api/getNews", {
    query: {
      id: params.id,
    },
  });
  if (response?.localeSlugs) {
    response.localeSlugs = {
      en: {
        id: '1-first-article'
      }
      fr: {
        id: '1-premier-article'
      }
      de: {
        id: '1-erster-Artikel'
      }
    }
    $setI18nRouteParams(response?.localeSlugs);
  }
  return response;
});
$switchLocalePath('fr') // === 'fr/nouvelles/1-premier-article'
$switchLocalePath('de') // === 'de/Nachricht/1-erster-Artikel'
```

## 🔧 Cache- og hjælpermetoder

### `$has`

{/* generated:method:$has — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string) => boolean
```

Om en nøgle kan resolveres i det aktive locale. Brug den til at forgrene på valgfrit copy i stedet for at rendere en rå nøgle.

{/* /generated:method:$has */}

Under sideovergange i samme locale foretager v3 automatisk dyb fletning af oversættelser fra den forladte side ind i denne ordbog, indtil overgangen er færdig. Derfor kan nøgler fra den forrige side stadig returnere `true` i kort tid. Der er ingen `previousPageFallback`-indstilling. Adfærden er indbygget. Se [FAQ — sideovergange](/guides/faq#-why-do-translations-break-during-page-transitions-especially-with-defineasynccomponent).

```typescript
if ($has('welcome')) {
  console.log($t('welcome'))
} else {
  console.log('Key not found')
}
```

## 🧭 Composablen `useI18nLocale`

Den centraliserede composable til håndtering af locale-state. Brug denne i stedet for at manipulere `useState('i18n-locale')` eller `useCookie('user-locale')` direkte.

```typescript
const {
  setLocale, // (locale: string) => void — updates state + cookie
  getLocale, // () => string | null — from state or cookie
  getPreferredLocale, // () => string | null — validated against locales list
  getEffectiveLocale, // (route, getLocaleFromRoute) => string
  resolveInitialLocale, // (options) => string
  isValidLocale, // (locale) => boolean
  locale, // Ref<string | null> — reactive state
  localeCookie, // CookieRef — reactive cookie
  syncLocale, // (locale) => void — sync to cookie only
  validLocales, // string[] — list of valid locale codes
} = useI18nLocale()
```

### Nøglemetoder

| Metode                  | Beskrivelse                                                 |
| ----------------------- | ----------------------------------------------------------- |
| `setLocale(locale)`     | Sætter locale i både `useState` og cookie atomisk           |
| `getLocale()`           | Returnerer det aktuelle locale fra state eller cookie       |
| `getPreferredLocale()`  | Returnerer et locale valideret mod `locales`-listen, eller `null` |
| `isValidLocale(locale)` | Kontrollerer, om en locale-kode findes i den konfigurerede `locales`-liste |

### Brug i brugerdefinerede plugins

```typescript
// plugins/i18n-loader.server.ts
export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,
  setup() {

    // Detect locale from headers, domain, etc.

  },
})
```
