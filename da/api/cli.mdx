[CLI-guiden](/da/guide/cli) viser de almindelige arbejdsgange. Denne side viser alt og er genereret ud fra den samme tabel, som driver `--help`.

## Fælles flag {#common-flags}

| Flag | Standard | Beskrivelse |
| --- | --- | --- |
| `--cwd` | aktuel mappe | Projektmappe |
| `--logLevel` | `info` | Outputniveau: silent, info |
| `--debug` | `false` | Udskriv en stack trace, når en kommando fejler |

## Inspicér {#inspect}

### `info` {#info}

Udskriv projektets opløste i18n-konfiguration

| Flag | Standard | Beskrivelse |
| --- | --- | --- |
| `--json` | `false` | Udskriv JSON i stedet for tekst |

### `check` {#check}

CI-porten: fejler ved manglende, tomme, overskydende, udefinerede eller ubrugte nøgler og ødelagte pladsholdere

| Flag | Standard | Beskrivelse |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` fra nuxt.config | Oversættelsesmappe, relativt til projektet |
| `--only` | alle undtagen duplicates | Kommaseparerede kontroller, der skal køres: missing, empty, extra, placeholders, undefined, unused, duplicates. `unused` angivet her fejler, når den ikke kan køre |
| `--duplicates` | `false` | Rapportér også den samme tekst under forskellige nøgler |
| `--ignore` | — | Kommaseparerede globs for kildefiler, der skal springes over, relativt til projektet |
| `--json` | `false` | Udskriv JSON i stedet for tekst |

```bash
i18n-micro check
i18n-micro check --only missing,placeholders --json
```

### `stats` {#stats}

Vis oversættelsesfuldførelse pr. locale

| Flag | Standard | Beskrivelse |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` fra nuxt.config | Oversættelsesmappe, relativt til projektet |
| `--html` | — | Skriv også en HTML-rapport til denne fil |
| `--json` | `false` | Udskriv JSON i stedet for tekst |
| `--baseRef` | — | Git-ref at sammenligne fuldførelse med, f.eks. HEAD~1 eller main |

```bash
i18n-micro stats --baseRef main
i18n-micro stats --html reports/i18n.html
```

### `lint` {#lint}

Kontrollér teksten i oversættelser; fejler, når der stadig er problemer

| Flag | Standard | Beskrivelse |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` fra nuxt.config | Oversættelsesmappe, relativt til projektet |
| `--rules` | alle, eller `enabledRules` fra .i18n-lintrc.json | Kommaseparerede regler, der skal køres: no-trailing-spaces, no-multiple-spaces, no-empty-translation eller en brugerdefineret |
| `--fix` | `false` | Ret det, der kan rettes: mellemrum og brugerdefinerede regler med en erstatning |
| `--json` | `false` | Udskriv JSON i stedet for tekst |

```bash
i18n-micro lint --rules no-trailing-spaces --fix
```

### `search` {#search}

Søg i nøgler og værdier, og vis hvor hver nøgle bruges

| Flag | Standard | Beskrivelse |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` fra nuxt.config | Oversættelsesmappe, relativt til projektet |
| `<query>` | — | Tekst eller nøgle at søge efter |
| `--caseSensitive` | `false` | Skeln mellem store og små bogstaver |
| `--onlyUnused` | `false` | Kun nøgler, som `clean` ville fjerne; forespørgslen bliver valgfri |
| `--scope` | `all` | Hvor der søges: global, pages, all |
| `--limit` | — | Returnér højst dette antal nøgler |
| `--ignore` | — | Kommaseparerede globs for kildefiler, der skal springes over, relativt til projektet |
| `--json` | `false` | Udskriv JSON i stedet for tekst |

```bash
i18n-micro search "Welcome"
i18n-micro search --onlyUnused
```

## Oversættelsesarbejdsgang {#translation-workflow}

### `extract` {#extract}

Vis de nøgler, som kildefiler bruger, der endnu ikke har tekst, og tilføj dem med en standardtekst til standard-localen

| Flag | Standard | Beskrivelse |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` fra nuxt.config | Oversættelsesmappe, relativt til projektet |
| `--ignore` | — | Kommaseparerede globs for kildefiler, der skal springes over, relativt til projektet |

```bash
i18n-micro extract
```

### `translate` {#translate}

Udfyld manglende oversættelser fra standard-localen via en oversættelsestjeneste

| Flag | Standard | Beskrivelse |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` fra nuxt.config | Oversættelsesmappe, relativt til projektet |
| `--service` | — | Oversættelsestjeneste: ai, azure, deepl, google, libretranslate, yandexcloud |
| `--token` | — | API-nøgle. Foretræk miljøvariablen I18N_TRANSLATE_TOKEN: flag ender i shell-historikken |
| `--options` | — | Tjenesteindstillinger som key:value-par, adskilt af kommaer |
| `--locale` | alle locales undtagen standard-localen | Kommaseparerede locales, der skal udfyldes |
| `--replace` | `false` | Oversæt alle nøgler igen og erstat eksisterende værdier |
| `--dryRun` | `false` | Tæl nøgler og tegn pr. locale; send intet |
| `--chunkSize` | — | Strenge pr. forespørgsel; begrænset til det, tjenesten accepterer |
| `--pluralSeparator` | `\|` | Separator for flertalsformer i beskeder |
| `--glossaryFile` | `.i18n-glossary.json` når den findes | Ordlistefil, bruges af `ai`-tjenesten |

```bash
i18n-micro translate --dryRun
I18N_TRANSLATE_TOKEN=... i18n-micro translate --service deepl --locale de,fr
i18n-micro translate --service ai --options provider:openai,model:gpt-4o-mini
i18n-micro translate --service libretranslate --options baseUrl:https://translate.example.com
```

### `sync` {#sync}

Fjern nøgler, som standard-localen ikke har; stopper, når det ikke kan bevises sikkert. Manglende nøgler forbliver manglende

| Flag | Standard | Beskrivelse |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` fra nuxt.config | Oversættelsesmappe, relativt til projektet |
| `--ignore` | — | Kommaseparerede globs for kildefiler, der skal springes over, relativt til projektet |
| `--dryRun` | `false` | Vis hvad der ville blive fjernet; skriv intet |
| `--force` | `false` | Fjern nøgler, selvom det ikke kan bevises sikkert |

```bash
i18n-micro sync --dryRun
```

### `clean` {#clean}

Fjern nøgler, som intet i projektet bruger; stopper, når det ikke kan bevises

| Flag | Standard | Beskrivelse |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` fra nuxt.config | Oversættelsesmappe, relativt til projektet |
| `--include` | — | Regulært udtryk: overvej kun matchende nøgler til fjernelse |
| `--exclude` | — | Regulært udtryk: fjern aldrig matchende nøgler |
| `--ignore` | — | Kommaseparerede globs for kildefiler, der skal springes over, relativt til projektet |
| `--dryRun` | `false` | Vis hvad der ville blive fjernet; skriv intet |
| `--force` | `false` | Fjern nøgler, selvom brug ikke kan bevises for dem alle |

```bash
i18n-micro clean --dryRun
i18n-micro clean --exclude '^errors\.'
```

## Refaktorering {#refactoring}

### `text-to-i18n` {#text-to-i18n}

Erstat hardkodet tekst i Vue-skabeloner med oversættelseskald, og rapportér hardkodet tekst i kode

| Flag | Standard | Beskrivelse |
| --- | --- | --- |
| `--translationFile` | `<translationDir>/<defaultLocale>.json` | Fil, som de nye nøgler skrives til |
| `--path` | hele projektet | Fil eller mappe, der skal behandles |
| `--context` | — | Præfiks for genererede nøgler |
| `--ignore` | — | Kommaseparerede globs for kildefiler, der skal springes over, relativt til projektet |
| `--dryRun` | `false` | Vis hvad der ville ændre sig; skriv intet |
| `--interactive` | `false` | Bekræft eller redigér hver genereret nøgle |

```bash
i18n-micro text-to-i18n --dryRun
i18n-micro text-to-i18n --path components --context ui
```

### `rename` {#rename}

Omdøb en nøgle eller et navnerum i alle locales og i kildefiler

| Flag | Standard | Beskrivelse |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` fra nuxt.config | Oversættelsesmappe, relativt til projektet |
| `--from` **\*** | — | Nuværende nøgle eller navnerum |
| `--to` **\*** | — | Ny nøgle eller nyt navnerum |
| `--ignore` | — | Kommaseparerede globs for kildefiler, der skal springes over, relativt til projektet |
| `--dryRun` | `false` | Rapportér ændringerne; skriv intet |

**\*** påkrævet.

```bash
i18n-micro rename --from common.save --to actions.save
```

### `pseudo` {#pseudo}

Udfyld en locale med pseudo-oversættelser for at finde layoutproblemer og hardkodet tekst

| Flag | Standard | Beskrivelse |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` fra nuxt.config | Oversættelsesmappe, relativt til projektet |
| `--sourceLocale` | standard-localen | Locale, der skal læses |
| `--targetLocale` **\*** | — | Locale, der skal udfyldes |
| `--replace` | `false` | Overskriv eksisterende værdier |

**\*** påkrævet.

### `format` {#format}

Omskriv locale-filer med sorterede nøgler og ensartet indrykning

| Flag | Standard | Beskrivelse |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` fra nuxt.config | Oversættelsesmappe, relativt til projektet |
| `--indent` | `2` | Antal mellemrum i indrykning |
| `--sortKeys` | `true` | Sortér nøgler; brug --no-sortKeys for at bevare deres rækkefølge |
| `--check` | `false` | Fejl, hvis en fil ville ændre sig; skriv intet |

```bash
i18n-micro format --check
```

## Udveksling {#exchange}

### `export` {#export}

Eksportér locale-filer til PO eller CSV med standard-localens tekst som kilde

| Flag | Standard | Beskrivelse |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` fra nuxt.config | Oversættelsesmappe, relativt til projektet |
| `--format` | `po` | Filformat: po, csv |
| `--dir` | `pots` for po, `csv_exports` for csv | Outputmappe, relativt til projektet |
| `--force` | `false` | Overskriv filer, der er ændret siden sidste eksport og aldrig importeret |

```bash
i18n-micro export --format csv
```

### `import` {#import}

Flet PO- eller CSV-filer ind i locale-filerne

| Flag | Standard | Beskrivelse |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` fra nuxt.config | Oversættelsesmappe, relativt til projektet |
| `--format` | `po` | Filformat: po, csv |
| `--dir` | `pots` for po, `csv_exports` for csv | Inputmappe, relativt til projektet |
| `--dryRun` | `false` | Rapportér hvad der ville blive importeret; skriv intet |

```bash
i18n-micro import --format csv --dryRun
```

### `sync-remote` {#sync-remote}

Hent globale oversættelser fra, eller send dem til, HTTP-endpointet i .i18n-remote.json

| Flag | Standard | Beskrivelse |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` fra nuxt.config | Oversættelsesmappe, relativt til projektet |
| `--pull` | `true` | Hent fra remote |
| `--push` | `false` | Send til remote |
| `--force` | `false` | Ved pull: tag remote-værdien; ved push: overskriv tekst, som kun remote har |
| `--dryRun` | `false` | Rapportér hvad et pull ville ændre; skriv og send intet |

```bash
i18n-micro sync-remote --dryRun
i18n-micro sync-remote --no-pull --push
```

## Lint-regler {#lint-rules}

| Regel | Finder | Rettes af `--fix` |
| --- | --- | --- |
| `no-trailing-spaces` | Mellemrum i slutningen af en værdi eller linje | ja |
| `no-multiple-spaces` | To eller flere mellemrum i træk | ja |
| `no-empty-translation` | En tom eller blank værdi | nej |

## Exitkoder {#exit-codes}

| Kode | Betydning |
| --- | --- |
| `0` | Færdig, intet at rapportere |
| `1` | Fund: `check`, `lint` eller `format --check` fandt noget, `clean` eller `sync` kunne ikke bevise, at en fjernelse var sikker, `export` ville overskrive ikke-importeret arbejde, `translate` udelod nøgler, `import` eller `sync-remote` stødte på en konflikt, et `sync-remote`-push ville fjerne remote-tekst. Et `--dryRun` af `clean`, `sync` eller et `sync-remote`-pull rapporterer disse og afslutter med `0` |
| `2` | Fejl: forkert brug, ulæseligt projekt, netværks- eller filfejl |

## Konfigurationsfiler {#configuration-files}

| Fil | Bruges af |
| --- | --- |
| `.i18n-lintrc.json` | `lint`: `enabledRules`, `disabledRules`, `customRegexRules` (`name`, `pattern`, `flags`, `description`, `replacement`) |
| `.i18n-remote.json` | `sync-remote`: `url`, `path`, `token`, `auth` (`username`, `password`). `type` kan udelades; kun `custom` findes |
| `.i18n-glossary.json` | `translate --service ai`: `entries` med `source`, `target` og valgfrie `from`, `to` |

## Miljøvariabler {#environment-variables}

| Navn | Bruges til |
| --- | --- |
| `I18N_TRANSLATE_TOKEN` | API-nøgle for `translate`. Læses også fra `.env` |
| `I18N_REMOTE_TOKEN` | Bearer-token for `sync-remote`. Læses også fra `.env` |
| `AI_GATEWAY_API_KEY, OPENAI_API_KEY, ANTHROPIC_API_KEY` | Nøgle til `ai`-tjenesten, når `I18N_TRANSLATE_TOKEN` ikke er sat |
| `DEFAULT_LOCALE` | Tilsidesætter `defaultLocale`, som i modulet |
