Modulet kalder ét runtime-hook (app-hook), `i18n:register`. Brug det, når et plugin eller et modul tilføjer oversættelser, der ikke findes i dine `locales/`-filer. Din callback får en `register`-funktion, der fletter oversættelser ind i den side, der vises.

## `i18n:register` {#i18nregister}

```ts
'i18n:register': (
  register: (translations: unknown, locale?: string) => void,
  locale: string,
) => HookResult
```

| Argument | Beskrivelse |
| --- | --- |
| `register(translations, locale?)` | Dybdefletter `translations` ind i sidechunken for den rute, der indlæses, for `locale` (standard: hookets `locale`). Nøgler, der allerede findes, overskrives. |
| `locale` | Localet for den rute, der indlæses. |

Hooket er typet via `RuntimeNuxtHooks`, så `nuxtApp.hook('i18n:register', …)` kræver ingen cast.

## Hvornår det udløses {#when-it-fires}

Loader-pluginet (`i18n-plugin-loader`) kalder det:

1. én gang ved opstart, når alle plugins har kørt (`app:created`), og før appen renderes;
2. i sin `router.beforeEach`, efter at målsidens oversættelser er indlæst, når stien ændres — ved hver navigation under `no_prefix`.

Hver callback og hvert `register`-kald afventes, før appen renderes eller navigationen fortsætter, så siden renderes med de flettede nøgler. Med [`hooks: false`](/da/api/module-options#hooks) kaldes hooket aldrig.

## Eksempel {#example}

```ts
// plugins/i18n-extra.ts
export default defineNuxtPlugin((nuxtApp) => {
  nuxtApp.hook('i18n:register', async (register, locale) => {
    const extra = await $fetch<Record<string, unknown>>(`/api/cms-strings/${locale}`)
    register(extra, locale)
  })
})
```

Dette er et runtime-hook: registrér det med `nuxtApp.hook` i et plugin, ikke med `nuxt.hook` i `nuxt.config` eller i et moduls `setup`. Et modul tilføjer et sådant plugin med `addPlugin`.
