# 🌍 Komponenten `<i18n-link>`

Komponenten `<i18n-link>` i `Nuxt I18n Micro` er en alsidig linkkomponent, der automatisk lokaliserer ruter baseret på det aktuelle locale. Den fungerer som en wrapper omkring komponenten `<NuxtLink>` og tilføjer ekstra funktioner som styling af aktivt link og understøttelse af eksterne links.

## ⚙️ Props

| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | Målrute. Lokaliseres automatisk. En ekstern URL føres uændret igennem. |
| `activeStyle` | `Partial<CSSStyleValue>` | — | Inline-stil anvendt, mens linket peger på den aktuelle rute. |

`to` accepterer alt, hvad `NuxtLink` gør — en sti, en navngivet rute eller et resolveret rute-objekt. En absolut URL detekteres og renderes som et almindeligt `<a target="_blank" rel="noopener noreferrer">` i stedet for at blive lokaliseret.

## 🛠️ Eksempler på brug

### Grundlæggende brug

```vue
<i18n-link to="/about">About Us</i18n-link>
```

Dette eksempel opretter et link til `/about`-siden, lokaliseret til det aktuelle locale.

### Styling af aktivt link med inline-stil

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

Linket får fed tekst, når brugeren er på `/about`-siden, så du kan style det aktive link direkte med inline-stile.

### Håndtering af eksterne links

Komponenten opdager automatisk eksterne links og tilføjer de nødvendige attributter for sikkerhed.

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

Dette link åbner `https://example.com` i en ny fane med `rel="noopener noreferrer"` anvendt.

## 🎨 Stile

Komponenten bruger nu inline-stile til den aktive tilstand i stedet for en klasse. Du kan tilpasse disse stile med `activeStyle`-proppen.

### Standardstile for aktiv tilstand

- **Fontvægt**: `bold`
- **Farve**: arver browserens standardfarve (hvis der ikke er angivet en `color` i `activeStyle`).

Du kan overskrive disse ved at angive brugerdefinerede stile gennem `activeStyle`-proppen.

### Brugerdefinerede stile for aktiv tilstand

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

I dette eksempel bliver linket fed og grønt, når det er aktivt.

## 🚀 Yderligere funktioner

### Slot til brugerdefineret indhold

Du kan sende brugerdefineret indhold ind i linket via slots, hvilket gør komponenten fleksibel til forskellige brugstilfælde.

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### Forbedringer af tilgængelighed

Komponenten understøtter `aria-label` og andre tilgængelighedsattributter for at sikre en mere tilgængelig oplevelse.

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
