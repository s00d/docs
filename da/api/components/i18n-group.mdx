# 🌍 Komponenten `<i18n-group>`

Komponenten `<i18n-group>` i Nuxt I18n Micro giver en bekvem måde at gruppere oversættelser under et fælles præfiks. Det reducerer gentagelse og forbedrer kodeorganiseringen.

## ⚙️ Props

{/* generated:component:i18n-group — do not edit; run `pnpm run docs:generate` */}

| Prop | Type | Standard | Beskrivelse |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | Nøglepræfiks, som alle opslag inde i slottet resolveres mod. |
| `groupClass` | `string` | `''` | Ekstra klasse på wrapper-elementet. |

**\*** påkrævet.

### Slots

| Slot | Bindings | Beskrivelse |
| --- | --- | --- |
| `default` | `prefix`, `t` | Modtager `prefix` og en `t`-funktion afgrænset til det. |

## 🎯 Slots

Default-slottet modtager `prefix` og en `t`-funktion afgrænset til det, så nøgler indeni skrives relativt til præfikset:

```vue
<i18n-group prefix="checkout">
  <template #default="{ t }">
    <h2>{{ t('title') }}</h2>
    <p>{{ t('summary', { count: 3 }) }}</p>
  </template>
</i18n-group>
```

## 🛠️ Eksempel på brug

### Grundlæggende brug

```vue
<template>
  <i18n-group prefix="product.details">
    <template #default="{ t }">
      <h1>{{ t('title') }}</h1>
      <p>{{ t('description') }}</p>
      <div class="price">{{ t('price', { value: 99.99 }) }}</div>
    </template>
  </i18n-group>
</template>
```

Oversættelsesfil:

```json
{
  "product": {
    "details": {
      "title": "Premium Product",
      "description": "This is a premium product",
      "price": "Price: ${value}"
    }
  }
}
```

### Med brugerdefineret klasse

```vue
<template>
  <i18n-group prefix="user.profile" group-class="profile-section">
    <template #default="{ t }">
      <div class="user-info">
        <h2>{{ t('title') }}</h2>
        <p>{{ t('bio') }}</p>
        <div class="stats">
          <span>{{ t('stats.followers') }}</span>
          <span>{{ t('stats.following') }}</span>
        </div>
      </div>
    </template>
  </i18n-group>
</template>
```

Oversættelsesfil:

```json
{
  "user": {
    "profile": {
      "title": "User Profile",
      "bio": "User biography goes here",
      "stats": {
        "followers": "Followers: {count}",
        "following": "Following: {count}"
      }
    }
  }
}
```

### Med dynamisk indhold

```vue
<template>
  <i18n-group prefix="blog.post">
    <template #default="{ t }">
      <article>
        <h1>{{ t('title') }}</h1>
        <div class="meta">
          {{ t('meta.author', { name: author }) }} |
          {{ t('meta.date', { date: publishDate }) }}
        </div>
        <div v-for="(section, index) in sections" :key="index">
          <h2>{{ t(`sections.${index}.title`) }}</h2>
          <p>{{ t(`sections.${index}.content`) }}</p>
        </div>
      </article>
    </template>
  </i18n-group>
</template>

<script setup>
const author = 'John Doe'
const publishDate = '2024-01-01'
const sections = ['intro', 'main', 'conclusion']
</script>
```

## 🎨 Styling

Komponenten pakker sit indhold i en div med klassen `i18n-group` samt eventuelle ekstra klasser angivet i `groupClass`-proppen:

```css
.i18n-group {
  /* Your base styles */
}

.profile-section {
  /* Additional styles for profile sections */
}
```

## 🚀 Bedste praksis

1. **Konsistente præfikser**: brug konsistente og logiske præfikser, der afspejler din applikations struktur

```vue
<i18n-group prefix="features.pricing">
<i18n-group prefix="features.security">
```

2. **Modulær organisering**: grupper relaterede oversættelser under meningsfulde præfikser

```vue
<i18n-group prefix="checkout.payment">
<i18n-group prefix="checkout.shipping">
```

3. **Genbrugelige komponenter**: opret genbrugelige komponenter med egne oversættelsesgrupper

```vue
<!-- UserProfile.vue -->
<i18n-group prefix="user.profile">

<!-- UserSettings.vue -->
<i18n-group prefix="user.settings">
```

4. **Indlejrede grupper**: undgå at nested grupper for dybt, så du bevarer klarheden

```vue
<!-- Good -->
<i18n-group prefix="shop.product">

<!-- Avoid -->
<i18n-group prefix="shop.category.product.details.specs">
```
