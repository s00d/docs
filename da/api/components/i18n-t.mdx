# 🌍 Komponenten `<i18n-t>`

Komponenten `<i18n-t>` i `Nuxt I18n Micro` er en fleksibel oversættelseskomponent, der understøtter dynamisk indsætning af indhold via slots. Den giver dig mulighed for at interpolere oversættelser med brugerdefinerede Vue-komponenter eller HTML-indhold og understøtter dermed avancerede lokaliseringsscenarier.

Kun én af `plural`, `number`, `date` og `relativeDate` gælder ad gangen. Når flere er sat, vinder den første i den liste.

### Eksempler pr. prop

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

## 🛠️ Eksempler på brug

### Grundlæggende brug

```vue
<i18n-t keypath="feedback.text" />
```

Dette renderer oversættelsen for `feedback.text` i et `<span>`-tag.

### Brug af slots til dynamisk indhold

Komponenten `<i18n-t>` understøtter brug af slots til dynamisk at indsætte Vue-komponenter eller andet indhold i bestemte dele af oversættelsen.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

I dette eksempel erstattes pladsholderen `\{link\}` i oversættelsen `feedback.text` af komponenten `<nuxt-link>`, som selv indeholder en anden oversættelseskomponent.

### Pluralisering

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

Dette anvender automatisk pluraliseringsregler baseret på værdien af `itemCount`.

## 🚀 Yderligere funktioner

### Default-slot

Hvis der ikke er angivet et bestemt slot, kan oversættelsen tilpasses via default-slottet, som giver hele den oversatte streng:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### Betinget rendering

Render intet, hvis oversættelsesstrengen er tom, ved at bruge `hideIfEmpty`-proppen.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### Brugerdefineret pluraliseringsregel

Brug en brugerdefineret funktion til at håndtere pluralisering.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### Avanceret eksempel med slots

Brug slots til at tilpasse, hvordan oversættelsesindholdet renderes.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
