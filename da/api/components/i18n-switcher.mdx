# 🌍 `<i18n-switcher>` Component

`<i18n-switcher>`-komponenten i `Nuxt I18n Micro` tilbyder en brugervenlig dropdown-grænseflade til at skifte mellem forskellige locales i din applikation. Denne komponent er meget tilpasselig og muliggør sømløs integration med din applikations design og layout.

Locales med `disabled: true` **udelades** fra dropdown'en (de forbliver tilgængelige via `$getLocales()` til SEO / head-tags). Kun skiftbare locales får `NuxtLink` + `hreflang`.

Hver del er ustylet som standard: `custom*Style`-props'ene tager inline-style-objekter, og
slots'ene nedenfor erstatter markuppen helt, når styling ikke er nok.

## 🛠️ Eksempler på brug

### Grundlæggende brug

```vue
<template>
  <i18n-switcher />
</template>
```

Dette renderer en locale-switcher med standard-styling og adfærd.

### Brugerdefinerede etiketter og inline-styles

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Dette eksempel demonstrerer en fuldt tilpasset locale-switcher med brugerdefinerede etiketter og inline-styles.

## 🔌 Slots

Hver visuel del af switcheren kan udskiftes. Slots'ene er listet med props-tabellen
ovenfor; hver enkelt tager template-indhold:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Slots, hvis navn ender på `-item`, `-link-content` eller starter med `before-item`, modtager det
`locale`-objekt, de tilhører.

## 🎨 Overblik over styles

`<i18n-switcher>`-komponenten kommer med grundlæggende styles defineret ved hjælp af inline-styles, der let kan tilsidesættes ved at sende brugerdefinerede styles via props. Her er et kort overblik over standard-stylingen:

- **Wrapper**: Styrer placeringen af dropdown'en.
- **Button**: Styler dropdown-toggle-knappen.
- **Dropdown**: Styler dropdown-listen.
- **Items**: Styler hvert element i listen.
- **Links**: Styler links'ene inde i hvert element.
- **Icon**: Styler dropdown-indikator-ikonet.

Du kan tilpasse disse styles ved at sende brugerdefinerede styles gennem de respektive props, hvilket sikrer, at locale-switcheren integreres sømløst i din applikations UI.
