# 🌍 Komponenten `<i18n-switcher>`

Komponenten `<i18n-switcher>` i `Nuxt I18n Micro` tilbyder en brugervenlig dropdown-grænseflade til at skifte mellem forskellige locales i din applikation. Denne komponent er meget tilpasningsdygtig og kan integreres problemfrit med din applikations design og layout.

Locales med `disabled: true` **udelades** fra dropdownen (de er stadig tilgængelige via `$getLocales()` til SEO-/head-tags). Kun locales, du kan skifte til, får `NuxtLink` + `hreflang`.

## 🛠️ Eksempler på brug

### Grundlæggende brug

```vue
<template>
  <i18n-switcher />
</template>
```

Dette renderer en locale-switcher med standard-styling og -adfærd.

### Brugerdefinerede labels og inline-stile

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Dette eksempel viser en fuldt tilpasset locale-switcher med brugerdefinerede labels og inline-stile.

## 🔌 Slots

Alle visuelle dele af switcheren kan erstattes. Slottene er listet med props-tabellen ovenfor. Hvert slot tager template-indhold:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Slots, hvis navn ender på `-item`, `-link-content` eller starter med `before-item`, modtager det `locale`-objekt, de tilhører.

## 🎨 Oversigt over stile

Komponenten `<i18n-switcher>` leveres med grundlæggende stile defineret ved inline-stile, som nemt kan overskrives ved at sende brugerdefinerede stile ind via props. Her er en kort oversigt over standard-stylingen:

- **Wrapper**: styrer positioneringen af dropdownen.
- **Knap**: styler dropdown-toggle-knappen.
- **Dropdown**: styler dropdown-listen.
- **Elementer**: styler hvert element i listen.
- **Links**: styler linkene inde i hvert element.
- **Ikon**: styler dropdown-indikator-ikonet.

Du kan tilpasse disse stile ved at sende brugerdefinerede stile gennem de tilsvarende props, så locale-switcheren integreres problemfrit i din applikations UI.
