---
title: "Pakke-API'er"
description: "Det eksporterede API for hver @i18n-micro/*-pakke, genereret ud fra de API-snapshots, som CI kontrollerer mod kildekoden."
---

Nuxt-modulet er bygget af små `@i18n-micro/*`-pakker, og de fleste af dem fungerer også alene: `@i18n-micro/vue` i en Vue-app, `@i18n-micro/core` hvor som helst. Brug disse sider til at slå op, hvad en pakke eksporterer, pr. indgangspunkt. Hver side genereres ud fra det snapshot, som [`pnpm run api:surface`](https://s00d.github.io/nuxt-i18n-micro/contributing/maintenance-commands#api-surface) kontrollerer mod TypeScript-kildekoden, så en eksport kan ikke ændres, uden at CI opdager det.
