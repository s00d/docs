# 🛠️ `useI18n` Composable

`useI18n`-composablen i `Nuxt I18n Micro` giver adgang til de fleste runtime-i18n-hjælpere i komponenter og scripts. Metoder er tilgængelige **med og uden `$`-præfikset** (for eksempel `$t` og `t`).

Nogle injektioner — `$defineI18nRoute` og `$clearCache` — er kun tilgængelige på `useNuxtApp()`. Se [Metoder — `$defineI18nRoute`](/api/methods#definei18nroute) og [`$clearCache`](/api/methods#clearcache).

## 📊 Hvad den returnerer

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Alle runtime-hjælpere, som et almindeligt objekt.

De samme funktioner, som pluginet injicerer som `$t`, `$tc` og så videre, tilgængelige både under
dollar-præfiks-navnet og et bare alias — så `const \{ t \} = useI18n()` og
`const \{ $t \} = useI18n()` fungerer begge.

**Returnerer** — hjælperne beskrevet i [metodereferencen](/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

Hver hjælper, den returnerer — `$t`, `$tc`, `$has`, `$switchLocale` og resten — er listet
med sin signatur og dokumenteret i sin helhed i [Metodereferencen](/api/methods).

## `useNuxtApp()`-eksklusive API'er

Disse returneres **ikke** af `useI18n()`. Importér dem fra `useNuxtApp()`:

| Metode                      | Formål                                                                            |
| --------------------------- | --------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)`  | Per-side locale-ruter, restriktioner og inline-oversættelser i `script setup`     |
| `$clearCache()`             | Rydder in-memory oversættelses-cachen og indlæste chunks                          |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Se [Metoder](/api/methods) for fulde signaturer og eksempler.

## 🛠️ Eksempler på brug

### Grundlæggende hentning af locale

Hent den aktuelle locale for applikationen.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Oversættelse med parametre

Oversæt en streng med dynamiske parametre og en fallback-standardværdi.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Skift af locales

Skift applikationen til en anden locale.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Generering af en lokaliseret rute

Generér en rute lokaliseret til den aktuelle eller en specificeret locale.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
