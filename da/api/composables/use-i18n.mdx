# 🛠️ Composablen `useI18n`

Composablen `useI18n` i `Nuxt I18n Micro` giver adgang til de fleste runtime i18n-hjælpere i komponenter og scripts. Metoderne er tilgængelige **med og uden `$`-præfiks** (f.eks. `$t` og `t`).

Nogle injektioner — `$defineI18nRoute` og `$clearCache` — er kun tilgængelige på `useNuxtApp()`. Se [Metoder — `$defineI18nRoute`](/api/methods#definei18nroute) og [`$clearCache`](/api/methods#clearcache).

## 📊 Hvad den returnerer

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Alle runtime-hjælpere, som et almindeligt objekt.

De samme funktioner, som pluginet injicerer som `$t`, `$tc` og så videre, er tilgængelige både under det dollar-præfiksede navn og et bart alias. Så `const \{ t \} = useI18n()` og `const \{ $t \} = useI18n()` virker begge.

**Returnerer** — hjælperne beskrevet i [metodereferencen](/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

Alle hjælpere den returnerer — `$t`, `$tc`, `$has`, `$switchLocale` og resten — er listet med deres signaturer og dokumenteret fuldt ud i [Metodereferencen](/api/methods).

## API'er kun til `useNuxtApp()`

Disse returneres **ikke** af `useI18n()`. Importér dem fra `useNuxtApp()`:

| Metode                     | Formål                                                                          |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Locale-ruter, begrænsninger og inline-oversættelser pr. side i `script setup`   |
| `$clearCache()`            | Rydder in-memory-oversættelsescache og indlæste chunks                          |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Se [Metoder](/api/methods) for fulde signaturer og eksempler.

## 🛠️ Eksempler på brug

### Grundlæggende hentning af locale

Hent applikationens aktuelle locale.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Oversættelse med parametre

Oversæt en streng med dynamiske parametre og en fallback-standardværdi.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Skift af locales

Skift applikationen til et andet locale.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Generering af en lokaliseret rute

Generér en rute lokaliseret til det aktuelle eller det angivne locale.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
