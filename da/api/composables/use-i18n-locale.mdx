# useI18nLocale

## Signatur

## Brug

```vue
<script setup>
const {
  locale,
  localeCookie,
  hashCookie,
  validLocales,
  getPreferredLocale,
  getLocale,
  getLocaleWithServerFallback,
  getEffectiveLocale,
  resolveInitialLocale,
  setLocale,
  syncLocale,
  isValidLocale,
} = useI18nLocale()

// Set locale (updates state and cookies)
setLocale('de')

// Get current locale (state → cookie)
const current = getLocale()

// Get valid preferred locale
const preferred = getPreferredLocale()
</script>
```

## API

| Egenskab/metode                                 | Type                                | Beskrivelse                                                                          |
| ----------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| `locale`                                        | `Ref<string \| null>`               | Reaktiv locale-state (`useState('i18n-locale')`)                                     |
| `localeCookie`                                  | `Ref`                               | Locale-cookie (når `localeCookie`-indstillingen er aktiveret)                         |
| `hashCookie`                                    | `Ref`                               | Cookie brugt, når `hashMode` er aktiv                                                |
| `validLocales`                                  | `string[]`                          | Aktive locale-koder fra modulkonfiguration (udelader `disabled`)                     |
| `getLocale()`                                   | `() => string \| null`              | Aktuelt locale: state → cookie (eller hash-cookie i hash-tilstand)                   |
| `getPreferredLocale()`                          | `() => string \| null`              | Locale fra state/cookie **valideret** mod `validLocales`, eller `null`               |
| `getLocaleWithServerFallback(serverLocale?)`    | `(serverLocale?) => string \| null` | State → cookie → valgfri serverkontekst (bruges under `no_prefix`-init)              |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string`             | Locale til indlæsning af oversættelser: hash-tilstand foretrækker state; ellers læses fra ruten |
| `resolveInitialLocale(options)`                 | `(options) => string`               | Resolver locale: state → `serverLocale` → rute. Synkroniserer state, når det er nødvendigt |
| `setLocale(locale)`                             | `(locale: string \| null) => void`  | Sæt locale og synkroniser til cookies                                                |
| `syncLocale(locale)`                            | `(locale: string \| null) => void`  | Synkroniser kun cookies (ingen state-opdatering)                                     |
| `isValidLocale(locale)`                         | `(locale) => boolean`               | Kontrollér om en streng findes i `validLocales`                                      |

### `resolveInitialLocale`-indstillinger

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

Bruges internt af hoved-pluginet ved opstart. Brugerdefinerede plugins kan kalde den, når de implementerer alternative detektionsflows.

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

Returnerer det locale, der bruges til at indlæse oversættelser og formatere beskeder for et givet rute-objekt.

## Programmatisk indstilling af locale

Foretræk `useI18nLocale()` frem for direkte brug af `useState('i18n-locale')`:

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
`setLocale()` opdaterer kun locale-præferencen (state + cookie). For også at genindlæse den aktive oversættelseskontekst på klienten kan du bruge `$switchLocale()` fra `useNuxtApp()` eller `useI18n()`. Det er især vigtigt for `no_prefix`, hvor URL'en ikke ændrer sig. Se [FAQ — skift locale uden at ændre URL'en](/guides/faq#-switch-locale-without-changing-the-url).
</Tip>
