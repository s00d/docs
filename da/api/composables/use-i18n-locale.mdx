# useI18nLocale

## Signatur

Centraliseret entry point til håndtering af i18n-locale.
Kombinerer useState('i18n-locale'), locale-cookie og sync-utilities.

## Brug

```vue
<script setup>
const {
  locale,
  localeCookie,
  hashCookie,
  validLocales,
  getPreferredLocale,
  getLocale,
  getLocaleWithServerFallback,
  getEffectiveLocale,
  resolveInitialLocale,
  setLocale,
  syncLocale,
  isValidLocale,
} = useI18nLocale()

// Set locale (updates state and cookies)
setLocale('de')

// Get current locale (state → cookie)

// Get valid preferred locale
const preferred = getPreferredLocale()
</script>
```

## API

| Egenskab/Metode                                 | Type                                | Beskrivelse                                                                          |
| ----------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| `locale`                                        | `Ref<string \| null>`               | Reaktiv locale-state (`useState('i18n-locale')`)                                     |
| `localeCookie`                                  | `Ref`                               | Locale-cookie (når `localeCookie`-option er aktiveret)                               |
| `hashCookie`                                    | `Ref`                               | Cookie brugt, når `hashMode` er aktiv                                                |
| `validLocales`                                  | `string[]`                          | Aktiverede locale-koder fra moduloption (ekskluderer `disabled`)                     |
| `getLocale()`                                   | `() => string \| null`              | Aktuel locale: state → cookie (eller hash-cookie i hash-mode)                        |
| `getPreferredLocale()`                          | `() => string \| null`              | Locale fra state/cookie **valideret** mod `validLocales`, eller `null`               |
| `getLocaleWithServerFallback(serverLocale?)`    | `(serverLocale?) => string \| null` | State → cookie → valgfri server-kontekst (bruges under `no_prefix`-init)             |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string`             | Locale til indlæsning af oversættelser: hash-mode foretrækker state; ellers læses fra rute |
| `resolveInitialLocale(options)`                 | `(options) => string`               | Resolver locale: state → `serverLocale` → rute; synkroniserer state efter behov      |
| `setLocale(locale)`                             | `(locale: string \| null) => void`  | Sæt locale og synkronisér til cookies                                                |
| `syncLocale(locale)`                            | `(locale: string \| null) => void`  | Synkronisér kun cookies (ingen state-opdatering)                                     |
| `isValidLocale(locale)`                         | `(locale) => boolean`               | Tjek om strengen findes i `validLocales`                                             |

### `resolveInitialLocale`-options

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

Bruges internt af hovedpluginet ved opstart. Brugerdefinerede plugins kan kalde den, når de implementerer alternative detektionsforløb.

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

Returnerer den locale, der bruges til at indlæse oversættelser og formatere beskeder for et givent rute-objekt.

## Programmatisk indstilling af locale

Foretræk `useI18nLocale()` frem for direkte brug af `useState('i18n-locale')`:

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
`setLocale()` opdaterer kun locale-præference (state + cookie). For også at genindlæse den aktive oversættelseskontekst på klienten, brug `$switchLocale()` fra `useNuxtApp()` eller `useI18n()`. Dette betyder især noget for `no_prefix`, hvor URL'en ikke ændres. Se [FAQ — skift locale uden at ændre URL'en](/guides/faq#-switch-locale-without-changing-the-url).
</Tip>
