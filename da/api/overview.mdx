# API-reference

## Runtime-API

- [Metoder](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, locale-skift og routing-hjælpere
- [Events](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Oversættelser og cache](/api/cache) — `TranslationStorage`, payload-indlæsning og `$clearCache`

## Server-middleware

Serverhandlers bruger dedikeret middleware (ikke klient-`$t`-hjælperne):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — oversæt i API-ruter og serverhandlers
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — læs det detekterede locale og metadata

Se den fulde [guide om oversættelser på serversiden](/guides/server-side-translations) for opsætning, prioritering af locale-detektion og eksempler.
