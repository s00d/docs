# API-reference

## Runtime-API

- [Metoder](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, skift af locale, routing-hjælpere
- [Events](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Oversættelser og cache](/api/cache) — `TranslationStorage`, indlæsning af payload, `$clearCache`

## Server-middleware

Server-handlers bruger dedikeret middleware (ikke klient-`$t`-hjælperne):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — oversæt i API-ruter og server-handlers
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — læs detekteret locale og metadata

Se den fulde [Server-side-oversættelser-guide](/guides/server-side-translations) for opsætning, prioritet for locale-detektion og eksempler.
