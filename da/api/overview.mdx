Dette afsnit viser alle optioner, hjælpefunktioner, hooks, composables og komponenter i Nuxt-modulet samt den eksporterede API for hver `@i18n-micro/*`-pakke. Brug det til at slå en signatur eller en standardværdi op; [vejledningen](/da/guide/getting-started) forklarer, hvordan de bruges. De fleste tabeller her er genereret ud fra kildekoden, så de stemmer overens med koden.

## Nuxt-modul {#nuxt-module}

| Side | Dækker |
| --- | --- |
| [Moduloptioner](/da/api/module-options) | Hver `i18n`-nøgle i `nuxt.config` med type og standardværdi |
| [Hjælpefunktioner](/da/api/methods) | `$t`, `$tc`, `$tn`, `$td`, `$localePath`, `$switchLocale`, `$defineI18nRoute` og resten |
| [Hooks](/da/api/events) | Runtime-hooket `i18n:register` |

## Composables {#composables}

| Composable | Brug den til |
| --- | --- |
| [`useI18n`](/da/composables/useI18n) | Hjælpefunktionerne i `<script setup>` |
| [`useI18nLocale`](/da/composables/useI18nLocale) | Locale-tilstand og cookie i et brugerdefineret detektions-plugin |
| [`useI18nHead`](/da/composables/useI18nHead) | Tilsidesættelser pr. side af de genererede SEO-tags |
| [`useLocaleHead`](/da/composables/useLocaleHead) | SEO-tags som et objekt til dit eget `useHead` |

## Komponenter {#components}

| Komponent | Renderer |
| --- | --- |
| [`<i18n-t>`](/da/components/i18n-t) | Én oversættelse med pluralisering, formatering og slot-interpolation |
| [`<i18n-link>`](/da/components/i18n-link) | Et `NuxtLink` til den lokaliserede rute |
| [`<i18n-switcher>`](/da/components/i18n-switcher) | En locale-dropdown |
| [`<i18n-group>`](/da/components/i18n-group) | En blok med et fælles nøglepræfiks |

## Server {#server}

Nitro-handlere bruger `useTranslationServerMiddleware` og `useLocaleServerMiddleware`, ikke klient-hjælpefunktionerne. Se [Serverruter](/da/guide/server-side-translations).

## Pakker {#packages}

[Pakke-API'er](/da/api/packages/overview) viser eksporterne fra hver `@i18n-micro/*`-pakke, med én genereret side for hver.
