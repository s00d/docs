`@i18n-micro/devtools-ui` er oversættelseseditoren fra Nuxt DevTools-fanen, pakket som en webkomponent med et Vite-plugin. Tilføj den til et Vue-, React-, Preact-, Solid- eller Astro-projekt for at gennemse og redigere JSON-filerne i din oversættelsesmappe fra browseren under udvikling. Nuxt-apps har den allerede i [Nuxt DevTools](/da/guide/devtools).

![DevTools UI: et filtræ og en editor med standard-localens tekst ved siden af hver nøgle](/images/devtools/02-translations-editor-dark.webp)

## Installation {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/devtools-ui
```

```bash npm
npm install -D @i18n-micro/devtools-ui
```

```bash yarn
yarn add -D @i18n-micro/devtools-ui
```

</CodeGroup>

Ingen peer dependencies.

## Opsætning {#setup}

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import { i18nDevToolsPlugin } from '@i18n-micro/devtools-ui/vite'

export default defineConfig({
  plugins: [i18nDevToolsPlugin({ translationDir: 'src/locales' })],
})
```

| Indstilling | Standard | Bemærkninger |
| --- | --- | --- |
| `translationDir` | `'src/locales'` | Mappe med JSON-filerne, relativt til Vite-roden. |
| `base` | `'/__i18n_api'` | Basissti for API-endpoints. |
| `injectButton` | `true` | Tilføj en flydende knap til sider, der serveres gennem Vites `index.html`-transformation. Astro har ingen sådanne sider: se nedenfor. |
| `defaultLocale` | første locale-fil i `translationDir` | Rapporteres af `/config`. |
| `fallbackLocale` | `defaultLocale` | Rapporteres af `/config`. |

Pluginet kører kun på udviklingsserveren (`apply: 'serve'`); et produktionsbuild indeholder intet fra det. Knappen åbner `/__i18n_devtools.html`, som læser og gemmer filer gennem pluginets endpoints:

| Endpoint | Gør |
| --- | --- |
| `GET <base>/translations` | alle ordbøger under `translationDir`, efter relativ sti |
| `POST <base>/save` | body `{ file, content }`; overskriver en eksisterende `.json` inde i `translationDir`, 403 for alt andet. Den opretter aldrig en fil |
| `GET <base>/config` | `{ defaultLocale, fallbackLocale, locales, translationDir }`; `locales` kommer fra rodfilerne i `translationDir` |

Endpointsene svarer kun devtools-siden: en forespørgsel fra en anden origin eller host giver `403`, og `/save` accepterer kun `application/json` (`415`). Siden får besked om filændringer via Vites HMR-socket.

I Astro tilføjer du integrationen i stedet for pluginet. Den tilføjer en app til dev-værktøjslinjen:

```ts
// astro.config.mjs
import { defineConfig } from 'astro/config'
import { i18nDevToolsIntegration } from '@i18n-micro/devtools-ui/vite'

export default defineConfig({
  integrations: [i18nDevToolsIntegration({ translationDir: 'src/locales' })],
})
```

At gemme skriver kun filen. En app, der importerer JSON'en gennem Vite, får den via HMR; for redigeringer, der anvendes direkte på den kørende instans, skal du bruge en bro.

## Bro til en kørende instans {#bridge-to-a-live-instance}

For at indlejre editoren på din egen side og få redigeringer anvendt på den kørende instans med det samme skal du oprette en bro ud fra en adapter og give den til `<i18n-devtools-ui>`-elementet:

```ts
import { createBridge, register } from '@i18n-micro/devtools-ui'
import { i18n, locales } from './i18n' // a runtime, React, Preact or Solid instance

register() // defines <i18n-devtools-ui> once

const bridge = createBridge({
  adapter: {
    getRouteCache: () => Object.fromEntries(i18n.storage.translations),
    addTranslations: (locale, content, merge) => i18n.addTranslations(locale, content, merge),
    addRouteTranslations: (locale, route, content, merge) => i18n.addRouteTranslations(locale, route, content, merge),
    subscribe: (cb) => i18n.subscribe(cb),
    getCurrentLocale: () => i18n.locale,
  },
  locales,
  defaultLocale: 'en',
  translationDir: 'src/locales',
})

const el = document.createElement('i18n-devtools-ui') as HTMLElement & { bridge: typeof bridge }
el.bridge = bridge
document.body.append(el)
```

`getRouteCache` skal returnere ordbøgerne med nøglerne `locale:route` (`en:index`, `en:blog-post`), hvilket er det, `i18n.storage.translations` indeholder. For en Vue-instans skal du bruge `i18n.global.getRouteCache()` og `i18n.global.subscribeToChanges(cb)`.

`saveTranslation` opdaterer først instansen og sender derefter en POST til `<base>/save`. Når der ikke er noget endpoint (et statisk preview-build), eller udviklingsserveren ikke kan nås, gemmes redigeringen i `localStorage`; enhver anden gemmefejl gendanner den forrige ordbog og kaster en fejl.
