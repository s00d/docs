title: "Typegenerator"
description: "Generér TypeScript-autofuldførelse for oversættelsesnøgler ud fra dine JSON-filer, i Nuxt eller ethvert Vite-projekt."
---

`@i18n-micro/types-generator` læser alle JSON-filer i din oversættelsesmappe og skriver en deklaration, der lister alle nøgler. Tilføj den, når du vil have din editor til at foreslå nøgler i `t()`, `$t()` og `<I18nT keypath>`. Den virker som et Nuxt-modul og som et Vite- eller Rollup-plugin og genererer igen, når en fil ændres.

## Installation {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/types-generator
```

```bash npm
npm install -D @i18n-micro/types-generator
```

```bash yarn
yarn add -D @i18n-micro/types-generator
```

</CodeGroup>

Peer-afhængighed: `@nuxt/kit` `^3.18.0 || ^4.0.0`. Kun indgangen `/nuxt` importerer den; i et rent Vite-projekt kan peer-advarslen ignoreres.

## Nuxt {#nuxt}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro', '@i18n-micro/types-generator/nuxt'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Modulet skriver `.nuxt/types/i18n-micro.d.ts`, og Nuxt tilføjer den til typekonteksten; der er intet at inkludere manuelt. Det læser `i18nTypes.translationDir`, ellers dér, hvor `nuxt-i18n-micro` læser oversættelser: `translationDir` (fra `i18n` eller inline-modulindstillinger, standard `'locales'`) i hvert lag samt `additionalTranslationDirs`. Når du redigerer en JSON-fil under den mappe, genereres typerne igen i `nuxi dev`. `i18nTypes.outputFile` ignoreres i Nuxt (en advarsel siger det).

## Vite {#vite}

`I18nTypesPlugin` er et Vite-plugin, som Rollup også accepterer. Til en anden bundler skal du kalde `generateTypes` i et script.

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { I18nTypesPlugin } from '@i18n-micro/types-generator'

export default defineConfig({
  plugins: [
    vue(),
    I18nTypesPlugin({
      srcDir: process.cwd(),
      translationDir: 'src/locales',
      outputFile: 'src/i18n-micro.d.ts',
    }),
  ],
})
```

| Indstilling | Påkrævet | Noter |
| --- | --- | --- |
| `srcDir` | ja | Basismappe; `translationDir` resolves i forhold til den. |
| `translationDir` | ja | Mappe med JSON-filerne (undermapper som `pages/` inklusive) eller et array af mapper. |
| `outputFile` | nej | Hvor deklarationen skal skrives; standard `<srcDir>/i18n-micro.d.ts`. |

Pluginet genererer én gang ved build-start og, på udviklingsserveren, igen 300 ms efter en ændring i mappen. Sørg for, at `include` i din `tsconfig.json` dækker output-filen.

## Brug nøglerne {#use-the-keys}

Den genererede fil udvider `DefineLocaleMessage` i `@i18n-micro/types`, hvilket gør `TranslationKey` til dine nøgler:

```ts
declare module '@i18n-micro/types' {
  export interface DefineLocaleMessage {
    nav: object
    'nav.home': string
    'profile.title': string
  }
}
```

Nøglerne er dem, `t()` svarer på, også objekter, fra alle locales og alle sidefiler, med typen af deres JSON-værdi. `TranslationKey` er foreningen af disse nøgler plus enhver streng, så du får autofuldførelse, ikke fejl: en stavet forkert eller dynamisk nøgle kompilerer stadig. Params og returværdier er ikke typede.

For dynamiske nøgler under et kendt præfiks indsnævrer `ScopedKey<'prefix'>` til de matchende nøgler:

```ts
import type { ScopedKey } from '@i18n-micro/types'

const statusText = (status: string) => t(`status.${status}` as ScopedKey<'status'>)
```

`TranslationKey` og `ScopedKey` kommer fra `@i18n-micro/types` (React, Preact og Solid re-eksporterer `TranslationKey`; Vue gør ikke).

## API {#api}

| Eksport | Indgang | Noter |
| --- | --- | --- |
| `I18nTypesPlugin(options)` | `@i18n-micro/types-generator` | Vite- og Rollup-plugin |
| `generateTypes(options)` | `@i18n-micro/types-generator` | skriver filen, returnerer dens sti |
| `getTypesString(options)` | `@i18n-micro/types-generator` | returnerer deklarationen uden at skrive |
| `formatKeyProperty(key)` | `@i18n-micro/types-generator` | hjælpefunktion |
| Nuxt-modul (`configKey: 'i18nTypes'`) | `@i18n-micro/types-generator/nuxt` | indstilling `translationDir` |

Fulde signaturer: [pakkereference](/da/api/packages/types-generator).
