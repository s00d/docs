`@i18n-micro/node` er [runtime](/da/integrations/runtime-package)-instansen plus en loader, der læser en oversættelsesmappe fra disk. Brug den i en Express- eller Fastify-server, en CLI, en e-mail- eller PDF-generator eller ethvert script, der har brug for de samme JSON-filer som din Nuxt-app. Du indlæser filerne én gang og oversætter pr. forespørgsel uden at dele foranderlig tilstand mellem forespørgsler.

## Installation {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/node @i18n-micro/utils
```

```bash npm
npm install @i18n-micro/node @i18n-micro/utils
```

```bash yarn
yarn add @i18n-micro/node @i18n-micro/utils
```

</CodeGroup>

Ingen peer dependencies; Node.js `>=20`. `@i18n-micro/utils` er kun nødvendig for `Accept-Language`-hjælperen nedenfor.

## Opsætning {#setup}

Loaderen læser [Nuxt-mappelayoutet](/da/guide/translations): `locales/en.json` er en rodordbog, `locales/pages/blog/post/en.json` hører til routen `blog-post`.

```ts
import { createI18n } from '@i18n-micro/node'

const i18n = createI18n({ locale: 'en', fallbackLocale: 'en', translationDir: './locales' })
await i18n.loadTranslations()

i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.t('title', undefined, undefined, 'blog-post') // from locales/pages/blog/post/en.json
```

Indstillingerne er runtime-indstillingerne (se [instansen](/da/integrations/overview#the-instance)) plus `translationDir` og `disablePageLocales` (behandl `pages/**`-filer som rodordbøger). `i18n.reload()` rydder alle ordbøger og læser mappen igen, til en filovervåger under udvikling.

`loadTranslations(dir, disablePageLocales?)` eksporteres også selvstændigt og returnerer `{ root, routes }`:

```ts
import { loadTranslations } from '@i18n-micro/node'

const { root, routes } = await loadTranslations('./locales')
// root:   { en: {...}, de: {...} }
// routes: { 'blog-post': { en: {...}, de: {...} } }
```

## Pr. forespørgsel {#per-request}

En instans har én locale og én route. At skifte `i18n.locale` på en delt instans inde i en request-handler giver race conditions med samtidige forespørgsler. `run` giver en forespørgsel sin egen:

```ts
const i18n = createI18n({ locale: 'en', fallbackLocale: 'en', translationDir: './locales' })
await i18n.loadTranslations()

// `() => next()`: `run` hands its callback the fork, and Express reads an argument of `next` as an error
app.use((req, res, next) => i18n.run(pickLocale(req), () => next()))

app.get('/', (req, res) => {
  res.send(i18n.t('greeting')) // the request's locale, in everything it awaits
})
```

Inde i `run` læser og sætter den delte instans forespørgslens locale og route (`AsyncLocalStorage`); forken starter på den aktuelle route, og `i18n.setRoute(...)` inde i callbacken ændrer den forespørgsels route. Callbacken får også forespørgslens fork: ordbøger skrevet til den bliver i forespørgslen, ordbøger skrevet til den delte instans når alle.

Uden `AsyncLocalStorage` returnerer `i18n.fork(locale)` samme slags instans, som kan sendes rundt.

`reload()` læser mappen igen; de gamle ordbøger svarer, indtil de nye er på plads.

## Vælg locale {#pick-the-locale}

`detectLocaleFromAcceptLanguage(header, locales)` respekterer `q`-vægte og matcher `de-DE` med en `de`-locale (og `de` med `de-DE`). Den returnerer `null`, når intet matcher.

```ts
import express from 'express'
import { detectLocaleFromAcceptLanguage } from '@i18n-micro/utils/accept-language'

const app = express()

app.get('/hello', (req, res) => {
  const locale = detectLocaleFromAcceptLanguage(req.headers['accept-language'], locales) ?? 'en'
  const i18n = byLocale.get(locale)!
  res.json({ message: i18n.t('greeting', { name: 'Ada' }) })
})
```

For URL-præfiks, cookie og header samlet anvender `resolveLocale({ defaultLocale, validLocales, url, cookie, acceptLanguage, autoDetectLanguage: true })` fra `@i18n-micro/utils/resolve-locale` modulets prioritet: URL, derefter cookie, derefter `Accept-Language`, derefter standarden. Ugyldige værdier springes over.

Inde i en Nuxt-app har du ikke brug for denne pakke på serveren: brug modulets [server-side oversættelser](/da/guide/server-side-translations).

## API {#api}

| Eksport | Noter |
| --- | --- |
| `createI18n(options)`, `I18n` | runtime-instans + `translationDir`, `loadTranslations(dir?)`, `reload()` |
| `loadTranslations(dir, disablePageLocales?)` | `{ root, routes }` |
| `loadRootTranslations(dir, disablePageLocales?)` | kun `root` |
| `FormatService`, `interpolate` | fra core |
| Typer: `I18nOptions`, `LoadedTranslations`, `Translations`, `Locale`, `PluralFunc`, `Params` | |

Instansmetoder er angivet på [Runtime](/da/integrations/runtime-package#api). Fulde signaturer: [pakkereference](/da/api/packages/node).
