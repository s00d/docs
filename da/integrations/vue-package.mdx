`@i18n-micro/vue` er et Vue 3-plugin med oversættelseskernen fra Nuxt I18n Micro: reaktiv `t()`, global `$t`, fire komponenter og en valgfri vue-router-adapter. Brug den i en Vite- eller SSR-Vue-app, der ikke er bygget med Nuxt. Instansmodellen, router-kontrakten og komponenternes props deles med de andre pakker og er beskrevet i [Frameworks](/da/integrations/overview).

## Installation {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vue
```

```bash npm
npm install @i18n-micro/vue
```

```bash yarn
yarn add @i18n-micro/vue
```

</CodeGroup>

Peer dependencies: `vue` `^3.3.0`; `vue-router` `^4.5.1 || ^5.0.0` (valgfri, kun til `@i18n-micro/vue/router`). De publicerede typer kræver Vue 3.5.5 eller nyere med `skipLibCheck: false`; med `skipLibCheck: true`, den sædvanlige skabelonindstilling, kompilerer ældre versioner også.

## Opsætning {#setup}

```ts
// src/main.ts
import { createApp } from 'vue'
import { createI18n } from '@i18n-micro/vue'
import App from './App.vue'
import en from './locales/en.json'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales: [
    { code: 'en', iso: 'en-US', displayName: 'English' },
    { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
  ],
  defaultLocale: 'en',
})

createApp(App).use(i18n).mount('#app')
```

`locales` og `defaultLocale` er påkrævet for `useI18n()`: den kaster `I18nLocalesKey not provided` uden dem. Giv dem til `createI18n` (som ovenfor), til `useI18n({ locales, defaultLocale })` eller via `app.provide(I18nLocalesKey, …)` og `app.provide(I18nDefaultLocaleKey, …)`.

Pluginet registrerer `I18nT`, `I18nLink`, `I18nGroup` og `I18nSwitcher` globalt og tilføjer `$t`, `$ts`, `$tc`, `$tn`, `$td`, `$tdr`, `$has` og `$i18n` til skabeloner. Instansen er `i18n.global` uden for komponenter. Andre indstillinger findes under [instansen](/da/integrations/overview#the-instance); `routeMessages` er ikke tilgængelig i Vue, brug `addRouteTranslations`.

## Oversæt {#translate}

```vue
<script setup lang="ts">
import { useI18n } from '@i18n-micro/vue'

const { t, tc, tn } = useI18n()
</script>

<template>
  <h1>{{ t('greeting', { name: 'Ada' }) }}</h1>
  <!-- Hello, Ada! -->
  <p>{{ tc('apples', 3) }}</p>
  <!-- 3 apples -->
  <p>{{ $t('nav.home') }} · {{ tn(1234.5) }}</p>
</template>
```

`useI18n()` returnerer oversættelsesmetoderne (`t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`), `locale` (en skrivbar computed), `getLocale`, `getLocales`, `defaultLocale()`, `getLocaleName`, `localePath`, `localeRoute`, `switchLocale`, `setRoute`, `getRoute`, `addTranslations`, `addRouteTranslations`, `mergeTranslations`, `resolveTranslations`, `setTranslation`, `clearCache` og `instance`.

Indlæs flere ordbøger når som helst; alle komponenter, der læser dem, renderes igen:

```ts
const { addTranslations, addRouteTranslations, setRoute } = useI18n()

addTranslations('de', (await import('./locales/de.json')).default)
addRouteTranslations('en', 'about', { title: 'About us' })
setRoute('about') // t('title') now reads the 'about' dictionary first
```

## Skift locale {#switch-locale}

```ts
const { locale, switchLocale } = useI18n()

locale.value = 'de' // only the locale
switchLocale('de') // the locale, then router.push to the localized current path
```

Indlæs localens ordbog før eller efter skiftet; et skift henter ikke noget.

`<I18nGroup>` giver sin slot en `t` med præfiks. Nøgler inde i `<I18nT>` eller en almindelig `t()` får ikke præfiks:

```vue
<I18nGroup prefix="profile" v-slot="{ t }">
  <h2>{{ t('title') }}</h2>
  <!-- profile.title -->
</I18nGroup>
```

## Routing {#routing}

vue-router-adapteren ligger i en subpath, så hovedindgangen aldrig importerer `vue-router`:

```ts
// src/main.ts
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import { createI18n } from '@i18n-micro/vue'
import { createVueRouterAdapter } from '@i18n-micro/vue/router'
import App from './App.vue'
import Home from './pages/Home.vue'
import About from './pages/About.vue'
import en from './locales/en.json'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English' },
  { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
]

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/:locale(de)?', component: Home },
    { path: '/:locale(de)?/about', component: About },
  ],
})

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales,
  defaultLocale: 'en',
  routingStrategy: createVueRouterAdapter(router, locales, 'en'),
})

createApp(App).use(router).use(i18n).mount('#app')
```

`createVueRouterAdapter(router, locales, defaultLocale)` sætter præfiks på alle locales undtagen standard-localen (`/about`, `/de/about`) og renderer `<I18nLink>` som `RouterLink`. Læs selv locale fra routen, for eksempel i `router.beforeEach`, og sæt `i18n.global.locale.value`. Du kan også tilknytte en adapter senere med `i18n.setRoutingStrategy(adapter)`; for en brugerdefineret adapter, se [Router-adapter](/da/integrations/overview#router-adapter).

## SSR {#ssr}

- Opret routeren, i18n-instansen og appen inde i render-funktionen pr. forespørgsel. Én delt instans ville lække én besøgendes locale til en anden.
- Brug `createMemoryHistory()` på serveren, tag locale fra URL'en, og indlæs dens ordbog (og fallback-localens) før `renderToString`.
- Send locale til klienten (for eksempel i et `window.__STATE__`-script), og opret klientinstansen med samme `locale`, så hydreringen matcher.
- `<I18nSwitcher>` læser kun `window.location`, når dropdownen er åben, så den renderes på serveren.

`packages/vue/playground` har et komplet par af `entry-server.ts` / `entry-client.ts`.

## SEO-head {#seo-head}

`useLocaleHead(options)` bygger `lang`/`dir`-, canonical-, `hreflang`- og `og:locale`-tags ud fra locales og router-adapteren. Kald `updateMeta()`, når routen ændres, og giv `metaObject` til din head-manager:

```ts
import { watch } from 'vue'
import { useRoute } from 'vue-router'
import { useHead } from '@unhead/vue'
import { useLocaleHead } from '@i18n-micro/vue'

const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
watch(() => route.fullPath, () => updateMeta(), { immediate: true })
useHead(metaObject)
```

Indstillinger: `baseUrl` (streng eller funktion), `addDirAttribute` (standard `true`), `addSeoAttributes` (standard `true`), `identifierAttribute` (standard `'id'`), `hreflangBaseLanguage` (standard `false`). Locales med `disabled: true` eller `seo: false` får intet alternate-link.

| `I18nT`, `I18nLink`, `I18nSwitcher`, `I18nGroup` | `@i18n-micro/vue` |
