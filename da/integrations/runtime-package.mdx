`@i18n-micro/runtime` er den framework-uafhængige i18n-instans: ordbøger, `t()`, pluralformer, `Intl`-formatering og et abonnement på ændringer, uden `fs` og uden framework. Brug den i ren TypeScript, en web worker, en edge-funktion eller som grundlag for din egen binding. React-, Preact-, Node- og Astro-pakkerne udvider den samme klasse.

## Installation {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/runtime
```

```bash npm
npm install @i18n-micro/runtime
```

```bash yarn
yarn add @i18n-micro/runtime
```

</CodeGroup>

Ingen peer-afhængigheder. Til oversættelsesfiler på disk bruger du [`@i18n-micro/node`](/da/integrations/nodejs-package).

## Opsætning {#setup}

```ts
import { createI18n } from '@i18n-micro/runtime'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    en: { greeting: 'Hello, {name}!', apples: 'no apples | one apple | {count} apples' },
    de: { greeting: 'Hallo, {name}!' },
  },
  routeMessages: {
    about: { en: { title: 'About us' } },
  },
})
```

Alle optioner (`plural`, `missingWarn`, `missingHandler`, `numberFormats`, `datetimeFormats`) er listet under [instansen](/da/integrations/overview#the-instance).

## Oversæt {#translate}

```ts
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.tc('apples', 5) // '5 apples'
i18n.tn(1234.5) // '1,234.5'

i18n.setRoute('about')
i18n.t('title') // 'About us' (route dictionary)
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!' (root, still visible)
```

Indlæs flere ordbøger senere:

```ts
i18n.loadMessages({ fr: { greeting: 'Bonjour, {name} !' } }, { about: { fr: { title: 'À propos' } } })
i18n.addTranslations('fr', { nav: { home: 'Accueil' } }) // deep merge; pass false to replace

await i18n.loadFromUrl('/locales/fr.json', { locale: 'fr' })
await i18n.loadFromUrl('/locales/pages/about/fr.json', { locale: 'fr', routeName: 'about' })
await i18n.loadFromUrls([
  { url: '/locales/en.json', locale: 'en' },
  { url: '/locales/de.json', locale: 'de' },
])
```

`loadFromUrl` bruger `fetch` (send `init` med for headers) og kaster en fejl ved et svar, der ikke er OK. `loadFromUrls` indlæser én ad gangen.

## Skift locale {#switch-locale}

```ts
i18n.locale = 'de'
i18n.t('greeting', { name: 'Ada' }) // 'Hallo, Ada!'
```

Ændringer af locale, rute og ordbog giver besked til abonnenter, og det er sådan, framework-bindinger renderer igen:

```ts
const stop = i18n.subscribe(() => {
  document.querySelector('#greeting')!.textContent = i18n.t('greeting', { name: 'Ada' }) as string
})
i18n.locale = 'fr'
stop()
```

`getSnapshot()` returnerer en streng, der ændres ved hver notifikation (til stores i stil med `useSyncExternalStore`).

## Pr. forespørgsel {#per-request}

Instansen har ét locale og én rute. På en server må du ikke skifte en delt instans pr. forespørgsel: to samtidige forespørgsler ville se hinandens locale. `i18n.fork(locale)` giver en forespørgsel sin egen: eget locale, fallback og rute; de samme ordbøger, formattere og regler. En fork koster det samme, uanset hvor mange ordbøger der er. En fork ser skrivninger til sin forælder indtil sin første egen skrivning, og dens skrivninger bliver i den. [Node.js](/da/integrations/nodejs-package#per-request) tilføjer `run`.

## API {#api}

| Medlem | Noter |
| --- | --- |
| `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has` | se [Oversæt og formatér](/da/integrations/overview#translate-and-format) |
| `locale`, `fallbackLocale` | get/set |
| `currentRoute`, `setRoute(name)`, `getRoute()` | aktiv rute, standard `'index'` |
| `loadMessages(messages?, routeMessages?)` | flet mange locales og ruter på én gang |
| `addTranslations(locale, tree, merge = true)`, `addRouteTranslations(locale, route, tree, merge = true)` | |
| `loadFromUrl(url, { locale?, routeName?, init? })`, `loadFromUrls(entries)` | `fetch` JSON |
| `hasTranslation(key)` | aktivt locale, enhver rute (i modsætning til `has`, som tjekker den aktive rute og roden) |
| `setTranslation(key, value)`, `resolveTranslations()` | skriv én nøgle; læs det flettede træ |
| `clear()`, `clearCache()` | fjern alle ordbøger |
| `subscribe(cb)`, `getSnapshot()` | ændringsnotifikationer |
| `storage` | `{ translations: Map<'locale:route', Translations> }` |

En kode, der ikke er et sprogtag, får sine pluralformer fra `localeIso: { ua: 'uk-UA' }`; `localeIsoMap(locales)` bygger det ud fra de poster i en locale-liste, der har en `iso`.

Moduleksporter: `createI18n`, `I18n`, `fetchJsonTranslations`, `FormatService`, `interpolate`, `localeIsoMap` og typerne `I18nOptions`, `LoadFromUrlOptions`, `LoadFromUrlEntry`, `TranslationStorage`, `Translations`, `Locale`, `PluralFunc`. Fulde signaturer: [pakkereference](/da/api/packages/runtime).
