`@i18n-micro/*`-pakkerne bringer oversættelseskernen fra Nuxt I18n Micro til Vue, React, Preact, Solid, Astro, VitePress og almindelig JavaScript. Brug dem, når din app ikke er en Nuxt-app, eller når et script eller en server uden for Nuxt har brug for de samme oversættelsesfiler. Alle pakker deler én instansmodel, én kontrakt for router-adaptere og de samme fire komponenter, som beskrives én gang på denne side.

Router-indgangen er et separat import, så en app uden router aldrig bundler en.

`@i18n-micro/core`, `@i18n-micro/types` og `@i18n-micro/utils` installeres sammen med disse pakker; du importerer dem sjældent direkte. Signaturerne for alle eksporter findes i den genererede [pakkereference](/da/api/packages/overview).

Hver pakke har en playground under `packages/<name>/playground` i repositoryet.

## Instansen {#the-instance}

`createI18n(options)` returnerer én instans, der indeholder ordbøgerne, den aktuelle locale og den aktuelle route. Indstillingerne er de samme i alle pakker:

| Indstilling | Type | Standard | Bemærkninger |
| --- | --- | --- | --- |
| `locale` | `string` | påkrævet | Aktiv locale. |
| `fallbackLocale` | `string` | `locale` | Slås op, når en nøgle mangler i `locale`. |
| `messages` | `Record<locale, Translations>` | `{}` | Rodordbøger (`'index'`-route). |
| `routeMessages` | `Record<route, Record<locale, Translations>>` | `{}` | Route-ordbøger. Kun Runtime, React, Preact, Node og VitePress. |
| `plural` | `PluralFunc` | `defaultPlural` | Brugerdefineret pluralisregel. |
| `missingWarn` | `boolean` | `true` | `console.warn` i browseren for en manglende nøgle, kun under udvikling. |
| `missingHandler` | `(locale, key, routeName) => void` | — | Kaldes i stedet for advarslen. |
| `numberFormats` | `Record<locale, Record<name, Intl.NumberFormatOptions>>` | — | Navngivne formater: `tn(9.5, 'currency')`. |
| `datetimeFormats` | `Record<locale, Record<name, Intl.DateTimeFormatOptions>>` | — | Navngivne formater: `td(date, 'short')`. |
| `timeZone` | `string` | runtimens zone | IANA-zone for `td`-datoer; påvirker ikke `tdr`. Sæt den, så server og browser renderer samme dato. |
| `now` | `() => number` | `Date.now` | Uret for `tdr`. Giv hydreringen serverens tid, så begge renderer samme tekst. |
| `localeIso` | `Record<code, string>` | — | BCP 47-tag, der bruges til pluralisregler (`ua` → `uk-UA`). React, Preact og Solid tager det fra `iso` i providerens `locales`. |

Ordbøgerne ligger i `i18n.storage.translations`, et `Map` med nøglen `locale:route` (`en:index`, `en:about`).

En nøgle slås op i den aktuelle routes ordbog og derefter i rodordbogen, først for `locale` og derefter for `fallbackLocale`. En manglende nøgle returnerer selve nøglen (eller den `defaultValue`, du angiver).

```ts
i18n.addTranslations('en', { nav: { home: 'Home' } }) // root, deep-merged
i18n.addRouteTranslations('en', 'about', { title: 'About us' }) // route chunk
i18n.addTranslations('en', { nav: { home: 'Start' } }, false) // replace instead of merge
i18n.setRoute('about')
i18n.t('title') // 'About us'
i18n.t('nav.home') // 'Start' (root key, still visible on the route)
```

### Oversæt og formatér {#translate-and-format}

| Metode | Returnerer |
| --- | --- |
| `t(key, params?, defaultValue?, routeName?)` | Værdien (streng, tal, objekt) med `{param}` interpoleret. |
| `ts(...)` | Samme som `t`, som streng. |
| `tc(key, count \| params, defaultValue?)` | Pluralisform. |
| `tn(value, options \| name)` | `Intl.NumberFormat` i den aktive locale. |
| `td(value, options \| name)` | `Intl.DateTimeFormat`. |
| `tdr(value, options?)` | Relativ tid (`3 days ago`). |
| `has(key, routeName?)` | `true`, når den aktive locale har nøglen (route- eller rodordbog; fallbacken kontrolleres ikke). |

`defaultPlural` deler værdien ved `|` og vælger formen ved indeks `count`, begrænset til den sidste; et negativt, decimalt eller `NaN`-antal vælger den sidste form.

En brugerdefineret `plural` modtager `(key, count, params, locale, getter)`. Læs værdien via `getter(key)`; del ikke nøglen op:

```ts
import type { PluralFunc } from '@i18n-micro/vue'

const plural: PluralFunc = (key, count, params, _locale, getter) => {
  const value = getter(key)
  if (typeof value !== 'string') return null
  const forms = value.split('|').map((form) => form.trim())
  return (count === 1 ? forms[0] : forms[1] ?? forms[0])!.replace('{count}', String(count))
}
```

## Router-adapter {#router-adapter}

SPA-pakkerne afhænger ikke af en router. En router-adapter (`I18nRoutingStrategy`) fortæller dem, hvordan de læser den aktuelle sti, navigerer og bygger en lokaliseret sti. De indbyggede adaptere sætter præfiks på alle locales undtagen `defaultLocale` (`/about`, `/de/about`).

| Medlem | Påkrævet | Bruges af |
| --- | --- | --- |
| `getCurrentPath(): string` | ja | kontrol af aktivt link (efter side; query og hash tæller ikke), `switchLocale` (bevarer dem) |
| `push({ path }): void` | ja | `switchLocale`, `<I18nLink>` uden `linkComponent`, `<I18nSwitcher>` |
| `replace({ path }): void` | ja | — |
| `resolvePath(to, locale)` | nej | `localePath`, `localeRoute`, `<I18nLink>`; uden den returneres stier uændret |
| `linkComponent` | nej | `<I18nLink>` renderer den (f.eks. `RouterLink`) i stedet for `<a>` |
| `getRoute()` | nej | `{ fullPath, query }` til SEO-hjælpere |

`push` og `replace` er påkrævet i Vue, React, Preact og Solid. Astro har sin egen adapter på serversiden med valgfri `push`/`replace` (se [Astro](/da/integrations/astro-package#router-adapter)).

En minimal adapter til enhver historikbaseret router:

```ts
import type { I18nRoutingStrategy } from '@i18n-micro/react'

const locales = ['en', 'de']
const stripLocale = (path: string) => path.replace(/^\/(en|de)(?=\/|$)/, '') || '/'

export const historyAdapter: I18nRoutingStrategy = {
  getCurrentPath: () => window.location.pathname + window.location.search + window.location.hash,
  push: ({ path }) => window.history.pushState({}, '', path),
  replace: ({ path }) => window.history.replaceState({}, '', path),
  resolvePath: (to, locale) => {
    const path = stripLocale(typeof to === 'string' ? to : to.path || '/')
    return locale === 'en' ? path : `/${locale}${path === '/' ? '' : path}`
  },
}
```

## Komponenter {#components}

Vue, React, Preact og Solid leveres med de samme fire komponenter. Deres props er ens; React, Preact og Solid sender andre props videre til rodelementet.

### `<I18nT>` {#&lt;i18nt&gt;}

| Prop | Type | Bemærkninger |
| --- | --- | --- |
| `keypath` | `string` | påkrævet |
| `params` | `object` | interpolationsværdier |
| `plural` | `number \| string` | renderer `tc(keypath, count)` |
| `number` | `number \| string` | sender `tn(number)` som `{number}` |
| `date` | `Date \| string \| number` | sender `td(date)` som `{date}` |
| `relativeDate` | `Date \| string \| number` | sender `tdr(relativeDate)` som `{relativeDate}` |
| `tag` | `string` | omsluttende element, standard `span` |
| `html` | `boolean` | render oversættelsen som HTML; den skal være betroet, parametre escapes |
| `defaultValue` | `string` | træder i stedet for en manglende nøgle og renderes uden omslutning, når `hideIfEmpty` skjuler en tom værdi |
| `hideIfEmpty` | `boolean` | render intet for en tom oversættelse |
| `customPluralRule` | `PluralFunc` | pluralisregel for dette element |

Kun én formateringsprop anvendes, kontrolleret i denne rækkefølge: `number`, `date`, `relativeDate`, `plural`.

#### Rich text {#rich-text}

En `{placeholder}` kan indeholde et element. I Vue er det en navngivet slot; i React, Preact og Solid angiver `components`-proppen elementer, eller funktioner, der returnerer et, efter navn. Uanset hvad slår det en parameter med samme navn, virker i alle grene og overlever en locale, der ændrer pladsholdernes rækkefølge.

```tsx
// { "terms": "I accept the {link} of {company}" }
<I18nT keypath="terms" params={{ company: 'ACME' }} components={{ link: <a href="/terms">terms</a> }} />
```

I Solid skal du angive en funktion, når en pladsholder gentages: én node kan kun stå ét sted. `children` erstatter teksten; som funktion får de `{ translation }`, ligesom Vues standard-slot. `html` ignorerer alt dette.

### `<I18nLink>` {#&lt;i18nlink&gt;}

| Prop | Type | Bemærkninger |
| --- | --- | --- |
| `to` | `string \| { path }` | lokaliseres via adapterens `resolvePath` |
| `activeStyle` | style-objekt | flettes oven på `style` på den aktuelle side; React, Preact og Solid anvender det også på en overordnet sektion |
| `localeRoute` | funktion | tilsidesætter `resolvePath` for dette link |

Eksterne URL'er (`https://`, `mailto:`, `tel:`) renderes som `<a target="_blank" rel="noopener noreferrer">`; din egen `target` eller `rel` vinder. `onClick` kører altid. Et klik med modifikatortast, en anden museknap eller en `target` overlades til browseren.

### `<I18nSwitcher>` {#&lt;i18nswitcher&gt;}

En dropdown med aktiverede locales (locales med `disabled: true` skjules) med indlejrede standardstile. Dens elementer er links med `lang`, `hreflang` og `dir` fra localen. Som standard sætter et klik på et af dem localen og kalder adapterens `push` med den lokaliserede aktuelle sti; en `switchLocale`-prop erstatter den handling. Med en `localeRoute` og ingen router følger browseren linket. Escape eller et klik udenfor lukker den.

| Prop | Bemærkninger |
| --- | --- |
| `locales`, `currentLocale`, `getLocaleName` | tilsidesætter de leverede værdier |
| `switchLocale(code)` | erstatter det indbyggede skift |
| `localeRoute` | erstatter `resolvePath` |
| `customLabels` | `{ de: 'DE' }` |
| `customWrapperStyle`, `customButtonStyle`, `customDropdownStyle`, `customItemStyle`, `customLinkStyle`, `customActiveLinkStyle`, `customDisabledLinkStyle`, `customIconStyle` | tilsidesættelser af stil |

### `<I18nGroup>` {#&lt;i18ngroup&gt;}

En `<div class="i18n-group">`, der giver en `t` med præfiks videre til sine børn. Den sætter **ikke** præfiks på `<I18nT>` eller `t()`-kald inde i den; kun den `t`, den sender videre, har præfiks.

| Prop | Bemærkninger |
| --- | --- |
| `prefix` | påkrævet, f.eks. `'profile'` |
| `groupClass` | ekstra klasse på wrapperen |

Den `t`, der har præfiks, kommer via en scoped slot i Vue (`v-slot="{ t }"`) og et render-prop-barn i React, Preact og Solid (`{({ t }) => …}`).

## Typede nøgler {#typed-keys}

`t()` accepterer enhver streng. For at få autofuldførelse af dine nøgler skal du generere en deklaration med [typegeneratoren](/da/integrations/types-generator). Nøgler foreslås, men håndhæves ikke, og parametre er ikke typede.

## Sammenlignet med Nuxt-modulet {#compared-with-the-nuxt-module}

Pakkerne har ingen filbaseret routing, ingen server-middleware og ingen oversættelsesloader: du bestemmer, hvornår JSON skal indlæses (`import`, `fetch` eller `@i18n-micro/node` på serveren), og hvilken router-adapter der skal bruges. Locale-detektion, SEO-meta og route-generering er Nuxt-funktioner; Astro har sin egen middleware til detektion og `useLocaleHead` til SEO.
