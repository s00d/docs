---
title: "Udelukkelse af stier"
description: "Hold sider og filer uden for locale-routing med excludePatterns, og se hvilke stier der allerede er udelukket."
---

Nogle stier må aldrig få et locale-præfiks eller en locale-omdirigering: et adminområde, et health check, et genereret feed. `excludePatterns` markerer dem, og en indbygget liste dækker allerede Nuxt-interne stier og almindelige statiske filer. En udelukket side beholder præcis den sti, du skrev, og renderes stadig med `$t`.

## Udeluk en sti {#exclude-a-path}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    excludePatterns: [
      '/admin', // /admin and everything below it
      '/preview-*', // glob over the whole path
    ],
  },
})
```

Med denne konfiguration svarer `pages/admin/index.vue` kun på `/admin`; der findes ingen `/de/admin`, og `/admin` omdirigeres aldrig til `/de/admin`.

## Mønstersyntaks {#pattern-syntax}

Mønstre matches mod stien uden `app.baseURL`:

| Mønster | Matcher | Matcher ikke |
| --- | --- | --- |
| `'/admin'` | `/admin`, `/admin/users` | `/administrator`, `/de/admin` |
| `'/preview-*'` | `/preview-1`, `/preview-a/b` | `/de/preview-1` |
| `'/file-?'` | `/file-a` | `/file-ab` |
| `/^\/v\d+\//` | `/v2/docs` | `/docs` |

En streng uden `*` eller `?` matcher stien og hele segmenter under den. Med `*` (en vilkårlig række tegn, inklusive skråstreger) eller `?` (ét tegn) skal den matche hele stien. Start altid strenge med `/`.

## Hvad der allerede er udelukket {#what-is-excluded-already}

Disse får aldrig locale-ruter eller omdirigeringer, uden nogen konfiguration:

- `/api` og `/_nuxt` samt alt under dem;
- oversættelsesruten, som standard `/_locales` ([`apiBaseUrl`](/da/api/module-options#apibaseurl));
- enhver sti med et segment, der starter med `__` (`/__nuxt_content`, `/en/__og-image__`);
- `/sitemap*.xml`, `/robots.txt`, `/favicon.ico`, `/apple-touch-icon*.png`, `/manifest.json`, `/sw.js`, `/workbox-*.js`;
- enhver sti, hvis sidste segment ender på en filendelse for statiske filer: `xml txt ico json js css png jpg jpeg gif svg webp avif pdf wasm map mp4 webm mp3 zip gz woff woff2 ttf eot`. Side-slugs med punktum som `/user/john.doe` og `.html`-stier forbliver sider.

## Hvad en udelukkelse gør {#what-an-exclusion-does}

- **Ruter:** der genereres ingen lokaliserede varianter; siden bevares, som den er skrevet.
- **Omdirigeringer og 404'er:** serverens omdirigeringsplugin og klientens omdirigerings-middleware springer stien over.
- **Prerender:** matchende stier fjernes fra listen over prerender-ruter.

Det forhindrer ikke i18n-servermiddlewaren i at detektere et locale for forespørgslen, og det forhindrer ikke siden i at bruge oversættelser. For at holde en side lokaliseret, men uden SEO-tags, brug `disableMeta` ([Sidekonfiguration](/da/guide/per-component-translations#turn-off-seo-tags)). For at holde én side ulokaliseret fra `nuxt.config.ts` via sti gør `globalLocaleRoutes: { '/admin': false }` ([Lokaliserede stier](/da/guide/custom-locale-routes#in-nuxt-config)) det samme for routing.
