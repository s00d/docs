---
title: "Migrering fra @nuxtjs/i18n"
description: "Overfør @nuxtjs/i18n-indstillinger, composables og oversættelsesfiler til nuxt-i18n-micro."
---

Denne side overfører en `@nuxtjs/i18n`-app til nuxt-i18n-micro: indstillinger, hjælpere og fillayout. Brug den, når du udskifter modulet i en eksisterende app. Du beholder dine URL'er (strateginavnene er de samme) og flytter oversættelser over i JSON-filer pr. side.

<Tip>

**Opgraderer du selve nuxt-i18n-micro?** — Se [Opgradering](/da/guide/upgrade).

</Tip>

## Udskift modulet {#swap-the-module}

```bash
npm uninstall @nuxtjs/i18n
npm install nuxt-i18n-micro
```

```ts
// nuxt.config.ts — before
export default defineNuxtConfig({
  modules: ['@nuxtjs/i18n'],
  i18n: {
    locales: [
      { code: 'en', language: 'en-US', file: 'en.json' },
      { code: 'de', language: 'de-DE', file: 'de.json' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    langDir: 'locales',
    detectBrowserLanguage: { useCookie: true, cookieKey: 'i18n_redirected', redirectOn: 'root' },
  },
})
```

```ts
// nuxt.config.ts — after
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    translationDir: 'locales',
    localeCookie: 'i18n_redirected',
    autoDetectPath: '/',
  },
})
```

## Indstillinger {#options}

| `@nuxtjs/i18n` | nuxt-i18n-micro |
| --- | --- |
| `locales[].code` | `locales[].code` |
| `locales[].language` (`iso` før v9) | `locales[].iso` |
| `locales[].name` | `locales[].displayName` |
| `locales[].dir` | `locales[].dir` |
| `locales[].domain` | `locales[].baseUrl` (en origin med dens skema) |
| `locales[].domainDefault` | `locales[].baseDefault` |
| `differentDomains`, `multiDomainLocales` | ikke nødvendigt: `baseUrl` alene router efter host, se [Lag og domæner](/da/guide/layers#multiple-domains) |
| `locales[].file` / `files`, `langDir`, `lazy` | `translationDir`; filer findes efter navn og indlæses altid pr. side |
| `defaultLocale`, `strategy` | samme navne, samme fire værdier |
| `baseUrl` | `metaBaseUrl` |
| `customRoutes: 'config'` + `pages` | `globalLocaleRoutes` |
| `detectBrowserLanguage: false` | `redirects: false` (ingen redirects) eller `autoDetectLanguage: false` (ignorer headeren) |
| `detectBrowserLanguage.useCookie` / `cookieKey` | `localeCookie: '<name>'` (`null` slår cookien fra) |
| `detectBrowserLanguage.redirectOn: 'root'` | `autoDetectPath: '/'` (standard) |
| `detectBrowserLanguage.redirectOn: 'no prefix'` | `autoDetectPath: 'no_prefix'` |
| `detectBrowserLanguage.redirectOn: 'all'` | `autoDetectPath: '*'` |
| `vueI18n`-konfigurationsfil (`fallbackLocale`, `numberFormats`, `datetimeFormats`) | `fallbackLocale`, `numberFormats`, `datetimeFormats` i `i18n` |

Der er ingen `alwaysRedirect`: med en cookie sat følger `/` den ved hvert besøg. Den fulde liste er [Modulindstillinger](/da/api/module-options); detektionsregler står på [Locale-detektion](/da/guide/locale-detection).

## Hjælpere og composables {#helpers-and-composables}

| `@nuxtjs/i18n` / vue-i18n | nuxt-i18n-micro (template / `useI18n()`) |
| --- | --- |
| `const { t } = useI18n()` | `const { t } = useI18n()`, `$t` i templates |
| `t('key', count)`, `tc` | `$tc('key', count)` |
| `te('key')` | `$has('key')` |
| `n(value, 'currency')`, `d(date, 'short')` | `$tn(value, 'currency')`, `$td(date, 'short')` |
| — | `$tdr(date)`: relativ tid ("om 3 dage") |
| `locale.value` | `$getLocale()` |
| `locales.value` | `$getLocales()` |
| `setLocale('de')` | `$switchLocale('de')` |
| `useLocalePath()('about')` | `$localePath({ name: 'about' })` |
| `useLocaleRoute()` | `$localeRoute()` |
| `useSwitchLocalePath()('de')` | `$switchLocalePath('de')` |
| `useSetI18nParams()` | `$setI18nRouteParams()` |
| `useLocaleHead()` | automatisk med `meta: true`; [`useLocaleHead`](/da/composables/useLocaleHead) til brugerdefinerede heads |
| `defineI18nRoute({ paths: { de: '/ueber-uns' }, locales: [...] })` | `$defineI18nRoute({ localeRoutes: { de: '/ueber-uns' }, locales: [...] })` |
| `<NuxtLinkLocale to="about">` | `<i18n-link :to="{ name: 'about' }">` |
| `<i18n-t>` | `<i18n-t>` (slots udfylder `{name}`-pladsholdere) |
| `$i18n` i server-routes | `useTranslationServerMiddleware(event)`, se [Server-routes og API](/da/guide/server-side-translations) |

`useI18n()` importeres automatisk. `$defineI18nRoute` skal beholde sit `$`: buildet læser det kald. Alle hjælpere: [Metoder](/da/api/methods).

## Oversættelsesfiler {#translation-files}

Flyt nøglerne fra én stor fil pr. locale over i en rodfil plus én fil pr. side:

```text
locales/
├── en.json              # keys used on many pages (nav, footer)
├── de.json
└── pages/
    ├── index/en.json    # keys of pages/index.vue
    └── about/en.json    # keys of pages/about.vue
```

At beholde alt i rodfilerne virker også og er det hurtigste første skridt. Sæt `disablePageLocales: true`, indtil du deler dem op. Se [Oversættelsesfiler](/da/guide/translations).

### Beskedsyntaks {#message-syntax}

| vue-i18n | nuxt-i18n-micro |
| --- | --- |
| `{name}` navngiven interpolation | samme |
| `car \| cars` (2 former: 1 → første) | former vælges efter antal fra 0: skriv `no cars \| one car \| {count} cars` |
| `@:other.key` linkede beskeder | understøttes ikke: gentag teksten eller sammensæt i kode |
| `@.upper:`-modifikatorer | understøttes ikke: formater i kode eller brug `<i18n-t>` |
| `{'@'}` bogstavelige escapes | ikke nødvendigt: kun `{word}`-tokens erstattes |
| JS/TS-beskedfiler | kun JSON |

Flertalsreglen kan udskiftes med indstillingen [`plural`](/da/api/module-options#plural).

## Tjek efter skiftet {#check-after-the-switch}

- Alle URL'er, du havde, virker stadig; strateginavnene matcher, brugerdefinerede stier flyttes til `globalLocaleRoutes` eller `$defineI18nRoute`.
- `hreflang`, canonical og `og:locale` kommer ud af boksen med `meta: true`; fjern håndskrevne.
- En JSON-parsefejl logger filstien; en manglende nøgle logger en advarsel i browserkonsollen under dev.
