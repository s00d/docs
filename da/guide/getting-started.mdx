Denne side fører en Nuxt-app fra ingen i18n til en oversat side med en sprogvælger. Du har brug for den én gang, i starten af et projekt. Du ender med lokaliserede URL'er (`/about`, `/de/about`), én JSON-fil pr. locale og side samt `$t` i dine templates.

## Installation {#install}

Modulet kræver Nuxt 3.18 eller nyere (Nuxt 4 virker også) og Node 20 eller nyere.

<CodeGroup>

```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>

## Konfigurer locales {#configure-the-locales}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', displayName: 'English' },
      { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
      { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
    ],
    defaultLocale: 'en',
  },
})
```

Det er al den konfiguration, en første app behøver. Standardværdierne giver dig:

- `strategy: 'prefix_except_default'`: standard-locale'en har intet præfiks (`/about`), de andre har (`/de/about`). Se [Routing-strategier](/da/guide/strategy).
- `translationDir: 'locales'`: oversættelsesfilerne ligger i `locales/` i projektets rod, også med Nuxt 4's `app/`-struktur.
- `meta: true`: `hreflang`-, canonical- og `og:locale`-tags samt `lang` og `dir` på `<html>`. Se [SEO](/da/guide/seo).
- En besøgende, der åbner `/`, sendes til det sprog, browseren beder om (`Accept-Language`). Se [Locale-detektion](/da/guide/locale-detection).

`iso` er det sprogtag, der bruges i SEO-tags; `code` er det, der står i URL'en. Alle indstillinger er listet i [Modulindstillinger](/da/api/module-options).

## Tilføj oversættelsesfiler {#add-translation-files}

Start udviklingsserveren med `nuxt dev`. Når Nuxt resolver siderne, opretter modulet en tom `{}`-fil for hver locale og side, der ikke har en (slå det fra med [`disableWatcher`](/da/api/module-options#disablewatcher)):

```text
locales/
├── en.json            # root: keys every page can use
├── de.json
├── fr.json
└── pages/
    ├── index/         # pages/index.vue
    │   ├── en.json
    │   ├── de.json
    │   └── fr.json
    └── about/         # pages/about.vue
        ├── en.json
        ├── de.json
        └── fr.json
```

Udfyld rodfilen og en sidefil:

```json
// locales/en.json
{ "nav": { "home": "Home", "about": "About" } }
```

```json
// locales/pages/index/en.json
{ "welcome": "Welcome, {name}!", "items": "no items | one item | {count} items" }
```

En side ser rodnøglerne og sine egne nøgler; ved en konflikt vinder dens egen fil. Mappenavnene følger route-navnet (`pages/articles/[id].vue` er `locales/pages/articles-id/`). [Oversættelsesfiler](/da/guide/translations) dækker struktur, fallbacks og indlæsning.

## Brug `$t` på en side {#use-$t-on-a-page}

```vue
<!-- pages/index.vue -->
<script setup lang="ts">
const { t, tc, getLocale } = useI18n()

const title = t('nav.home') // 'Home'
</script>

<template>
  <h1>{{ $t('welcome', { name: 'Ada' }) }}</h1>
  <!-- Welcome, Ada! -->
  <p>{{ $tc('items', 3) }}</p>
  <!-- 3 items -->
  <p>{{ getLocale() }}</p>
  <!-- en -->
</template>
```

- I templates er alle hjælpefunktioner tilgængelige med `$` (`$t`, `$tc`, `$localePath`, …).
- I `<script setup>` returnerer `useI18n()` de samme hjælpefunktioner, med og uden `$` (`t` og `$t` er én og samme funktion). Den auto-importeres.
- `{name}`-pladsholdere udfyldes fra params-objektet. Pluralformer adskilles med `|`; antallet vælger formen (0, 1 og derefter den sidste for alt derover).

Alle hjælpefunktioner er listet under [Metoder](/da/api/methods).

## Link mellem sider og skift locale {#link-between-pages-and-switch-locale}

```vue
<!-- components/AppHeader.vue -->
<template>
  <nav>
    <i18n-link :to="{ name: 'index' }">{{ $t('nav.home') }}</i18n-link>
    <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
    <i18n-switcher />
  </nav>
</template>
```

- [`<i18n-link>`](/da/components/i18n-link) er et `NuxtLink`, der peger på siden i den aktuelle locale: på `/de` går about-linket til `/de/about`.
- [`<i18n-switcher>`](/da/components/i18n-switcher) er en dropdown med de aktiverede locales; den holder den besøgende på samme side.
- Til dine egne knapper kan du kalde `$switchLocale('de')`, som navigerer til den aktuelle side på tysk og husker valget. Til et almindeligt `NuxtLink` skal du bruge `$localePath({ name: 'about' })` eller `$switchLocalePath('de')`.

## Tjek det {#check-it}

Kør `nuxt dev`, og åbn:

| URL | Viser |
| --- | --- |
| `/` | Engelsk forside (eller en omdirigering til `/de`, når din browser foretrækker tysk) |
| `/de` | Tysk forside |
| `/de/about` | Tysk about-side |
| `/en/about` | 404: standard-locale'en har intet præfiks under `prefix_except_default` |

Ændringer i JSON-filerne slår igennem på den åbne side uden genindlæsning.
