I `nuxt dev` tilføjer modulet to fejlfindingshjælpemidler: en **i18n Micro**-fane i Nuxt DevTools til at gennemse og redigere oversættelsesfiler og en Vue DevTools-inspektør til den aktive locale og de indlæste ordbøger. Begge findes kun under udvikling og tilføjer intet til produktionsbuilds. Nuxt-fanen kræver kun, at Nuxt DevTools er slået til; Vue-inspektøren kræver også browserudvidelsen Vue DevTools.

## Nuxt DevTools-fanen {#nuxt-devtools-tab}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  devtools: { enabled: true }, // the tab is registered only when DevTools are on
})
```

Åbn Nuxt DevTools (`Shift + Alt + D`), og vælg **i18n Micro**. Fanen viser:

- hver JSON-fil under `locales/` (rod og `pages/`) i hvert lag samt rodfiler fra `additionalTranslationDirs`;
- en editor pr. fil; **Save** skriver filen tilbage til disken, og udviklingsserveren genindlæser oversættelserne;
- **Export** / **Import** af en fil som JSON og **Stats** med antal nøgler og oversættelsesdækning;
- en konfigurationsvisning af de opløste moduloptioner;
- **Translate**, som udfylder manglende nøgler med en maskinoversættelsesmotor, du konfigurerer i fanens indstillinger.

Gem skriver kun eksisterende `.json`-filer i dine oversættelsesmapper. Når en fil findes i flere lag, skrives projektets kopi.

## Vue DevTools-inspektør {#vue-devtools-inspector}

Med browserudvidelsen Vue DevTools registrerer modulet en i18n-inspektør (aktuel locale, rute-chunk, indlæste nøgler) og en tidslinje med locale-skift, chunk-indlæsninger og manglende nøgler.

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    debug: true, // also log every $t / $ts / $tc call on the timeline
    // vueDevtools: false, // turn the inspector off, keep the Nuxt tab
  },
})
```

[`vueDevtools`](/da/api/module-options) er som standard `true`. `debug: true` er meget ordrig; brug det kun i korte sessioner.
