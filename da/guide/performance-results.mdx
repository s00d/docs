### Beskrivelse {#description}

Sammenligner **ren Nuxt**, **i18n-micro** og **`@nuxtjs/i18n`** under én fælles ordbogsprofil via `untestutils/perf`.

Fokus: build-tid, maksimal RSS, deploybar **kode vs. oversættelser (asset) vs. total** og belastning (Artillery).

### Noter om metode {#methodology-notes}

- Målingerne er **gennemsnit af 3 på hinanden følgende kørsler pr. fixture** (ikke sammenflettet).
- **Artefakt**: Nitro node-server `.output/server/index.mjs` efter tvunget `nuxi build`; `nuxt-i18n-micro` er **modulets byggede dist** (ikke `dev:prepare`-jiti-stubben). Se [benchmark-metode](https://s00d.github.io/nuxt-i18n-micro/contributing/performance-methodology).
- **Oversættelser** = `bundle.asset` (locale-JSON, `chunks/raw/`, matchende locale-chunks via `isTranslationFile`).
- **Kode** udelukker source maps (`*.map`): fixtures linker modulet fra repoet, så Nitro skriver fulde maps for det og ingen for npm-afhængigheder.
- **plain-nuxt** serverer den samme mængde bladnøgler som statisk JSON — I/O-tungt under belastning, ikke “i18n-overhead”.
- Belastningsprofil `--load full`: opvarmning 6s@6 + hovedfase 60s@60 uden loft (historisk).
- Nedkølinger `--cool fast` (se metodedokumentet).
- Hvert af de `runs` builds er **tvunget** (ingen varm cache, der nulstiller build-tiden).
- Artillerys **fejlrate** i tabellerne er HTTP-statusfejl fra belastningsmålingerne. Diagrammerne viser også `vusers.failed` (klient-timeouts under mætning); de kan være høje, mens HTTP-fejlraten forbliver 0%.
### Kørsler {#runs}

Alle målinger nedenfor er **gennemsnit over 3 kørsler**.

## Noter {#notes}

- Fælles profil: 4 locales × 2 sider × ~16,8k bladnøgler i indekset.
- Belastning: kun programmatisk Artillery — opvarmning **6s@6** + hovedfase **60s@60**, VU uden loft (historisk YAML-metode). Stier fra runtime-profilen — se `scripts/src/perf/load.ts`.
- Nedkølinger: 2s efter build, 3s mellem kørsler, 5s mellem fixtures. Builds tvinges ved hver kørsel, så gennemsnittene ikke udvandes af cache-hits.
- Kør igen i det daglige: `pnpm test:performance` (`--load short --cool fast`).
- Generér denne side igen: `pnpm -C scripts cli performance --load full --only all --runs 3`.
- Flags: `--locales N --keys K --only all|micro|i18n|plain --runs N --skip-load --cool fast|strict`.
