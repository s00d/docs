Serverhandlers i `server/api/` og `server/routes/` kan oversætte strenge og læse forespørgslens locale med to automatisk importerede hjælpere. Brug dem til API-svar, e-mails, feeds eller alt andet, der renderes uden for en Vue-side. De læser de samme oversættelsesfiler som dine sider og registrerer localen ud fra forespørgslen.

## Oversæt i en handler {#translate-in-a-handler}

```ts
// server/api/greeting.get.ts
export default defineEventHandler(async (event) => {
  const t = await useTranslationServerMiddleware(event)
  return { message: t('greeting', { name: 'Ada' }) }
})
```

```bash
curl 'http://localhost:3000/api/greeting?locale=de'
# {"message":"Hallo, Ada!"}
```

`useTranslationServerMiddleware(event, defaultLocale?, locale?)` er asynkron og returnerer `t(key, params?, defaultValue?)`. `t` returnerer strengen, interpolerer `{name}`-parametre og returnerer en ikke-tom `defaultValue`, ellers nøglen, når nøglen mangler.

`t` ser kun `index`-chunken: rodfilerne (`locales/<locale>.json`) plus `locales/pages/index/`, når den findes (kun rodfiler med `disablePageLocales`). Nøgler fra andre sider indlæses ikke. For dem skal du selv indlæse chunken:

```ts
const { data } = await loadTranslationsFromServer('de', 'about') // Translations object of the about page
```

## Læs forespørgslens locale {#read-the-request-locale}

```ts
// server/api/locale.get.ts
export default defineEventHandler((event) => {
  const { current, isDefault, locale } = useLocaleServerMiddleware(event)
  return { current, isDefault, dir: locale?.dir ?? 'ltr' }
})
```

`useLocaleServerMiddleware(event, defaultLocale?, locale?)` er synkron og returnerer:

```ts
interface LocaleInfo {
  current: string // detected locale code
  default: string // defaultLocale, runtime overrides included (fixed at build under prefix_except_default / prefix_and_default)
  fallback: string // fallbackLocale, else the default
  available: string[] // enabled locale codes
  locale: Locale | null // the config entry of `current`
  isDefault: boolean
  isFallback: boolean
}
```

## Sådan vælges localen {#how-the-locale-is-chosen}

Begge hjælpere bruger samme rækkefølge på alle server-routes, uanset om de er under `/api` eller ej:

1. `?locale=`-query (den første værdi, hvis den gentages);
2. en `[locale]`-route-parameter eller et locale-præfiks i stien (`/de/...`);
3. locale-cookien, når [`localeCookie`](/da/api/module-options#localecookie) er sat (`hash-locale` under `hashMode`);
4. `Accept-Language`, når `autoDetectLanguage` er slået til (q-værdier respekteres);
5. `defaultLocale`.

Ugyldige og deaktiverede koder springes over på hvert trin. Dette er API-rækkefølgen; en siderendering ignorerer `?locale=` under præfiks-strategierne. Begge rækkefølger sammenlignes under [Locale-detektion](/da/guide/locale-detection).

## Gennemtving en locale {#force-a-locale}

Angiv det tredje argument for at springe detektionen over, f.eks. i et job, der sender mail på brugerens sprog:

```ts
export default defineEventHandler(async (event) => {
  const user = await getUser(event) // your code
  const t = await useTranslationServerMiddleware(event, undefined, user.locale)
  return sendMail(user.email, t('mail.welcome.subject'))
})
```

Det andet argument erstatter `defaultLocale` for dette kalds detektion, så det har ingen effekt, når en locale gennemtvinges. Ordbøger caches pr. forespørgsel og pr. locale samt på tværs af forespørgsler i serverens oversættelsescache, så det er billigt at kalde en hjælper flere gange.

## Serverkomponenter {#server-components}

En serverkomponent (`.server.vue`, `<NuxtIsland>`) renderes fra sin egen URL, `/__nuxt_island/...`, så den ser ikke sidens URL, og Nuxt giver den kun dens props. Send localen som en `locale`-prop. Den renderes så i den locale, og et skift henter den igen, da props er en del af islandens URL og cachenøgle. Navnet er reserveret: enhver aktiveret locale-kode i en prop ved navn `locale` bestemmer renderingens locale, så giv en prop, der betyder noget andet, f.eks. et talformat, et andet navn:

```vue
<!-- components/Greeting.server.vue -->
<template><p>{{ $t('greeting') }}</p></template>
<script setup lang="ts">
defineProps<{ locale?: string }>()
</script>
```

```vue
<template>
  <Greeting :locale="$getLocale()" />
  <NuxtIsland name="Greeting" :props="{ locale: $getLocale() }" />
</template>
```

Uden proppen renderes den i cookiens locale, ellers i standard-localen, uanset hvad URL'en siger, og den følger ikke et skift. Dens `$t` ser `index`-chunken: rodfilerne plus `locales/pages/index/`.
