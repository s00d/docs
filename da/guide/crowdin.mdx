---

[Crowdin](https://crowdin.com/) er en oversættelsesplatform: du uploader standard-localens filer, oversætterne arbejder i Crowdin, og du downloader de andre locales igen. Modulet læser almindelige JSON-filer, så Crowdin CLI behøver kun en `crowdin.yml`, der mapper `locales/` og `locales/pages/` korrekt. Ingen modulindstillinger ændres.

## Konfigurer crowdin.yml {#configure-crowdin-yml}

```yml
# crowdin.yml
project_id_env: CROWDIN_PROJECT_ID
api_token_env: CROWDIN_PERSONAL_TOKEN
base_path: ./locales
preserve_hierarchy: true

files:
  - source: /en.json
    translation: /%two_letters_code%.json
  - source: /pages/**/en.json
    translation: /pages/**/%two_letters_code%.json
```

- `en` er din standard-locale; dens filer er kilderne.
- `project_id_env` / `api_token_env` læser ID og token fra miljøvariabler, så ingen hemmeligheder bliver committet.
- `preserve_hierarchy: true` bevarer `pages/<page>/`-mapperne, som de er.
- Navnet på den oversatte fil skal være lig med locale-`code` i `nuxt.config.ts`. `%two_letters_code%` passer til koder som `de`; for koder som `pt-BR` skal du bruge `%locale%` eller mappe Crowdins koder til dine med `languages_mapping`.

## Upload og download {#upload-and-download}

```bash
npm install -g @crowdin/cli

export CROWDIN_PROJECT_ID=123456
export CROWDIN_PERSONAL_TOKEN=...   # from Crowdin account settings

crowdin upload sources   # push locales/en.json and locales/pages/**/en.json
crowdin download         # write locales/de.json, locales/pages/**/de.json, ...
```

Kør begge i CI for at holde filerne opdaterede. Downloadede filer havner i dit repository ligesom håndredigerede filer; næste build eller genindlæsning under udvikling samler dem op.

## Før upload {#before-uploading}

Ryd først op i kilderne, så oversætterne ikke arbejder på døde nøgler: [`i18n-micro clean`](/da/api/cli#clean) fjerner ubrugte nøgler, og [`i18n-micro check`](/da/api/cli#check) rapporterer huller efter en download. CLI'en har ingen egen Crowdin-integration: denne side beskriver den understøttede fremgangsmåde.
