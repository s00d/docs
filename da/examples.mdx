# 📚 Eksempler og brug af Nuxt I18n Micro

Dette afsnit indeholder forskellige eksempler, der viser, hvordan du bruger `Nuxt I18n Micro` i din Nuxt.js-applikation. Du får vist, hvordan du skifter locale, bruger komponenterne `<i18n-link>`, `<i18n-switcher>` og `<i18n-t>` samt håndterer oversættelsesnøgler dynamisk.

## 🛠️ Grundlæggende opsætning

Her er en grundlæggende opsætning til at komme i gang med `Nuxt I18n Micro`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Skift af locale

### Skift locale programmatisk

Dette eksempel viser, hvordan du skifter locale programmatisk ved hjælp af knapper:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Eksempel-JSON til locale-skift

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### Brug af komponenten `<i18n-switcher>`

Komponenten `<i18n-switcher>` giver en dropdown til locale-skift med tilpasselige labels:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 🌐 Brug af `<i18n-link>` til lokaliseret navigation

Komponenten `<i18n-link>` håndterer automatisk locale-specifik routing:

```vue
<template>
  <div>
    <i18n-link to="/about">{{ $t('about') }}</i18n-link>
    <i18n-link :to="{ name: 'index' }">{{ $t('home') }}</i18n-link>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

```

## 📝 Rendering af dynamiske nøgler fra oversættelsesfiler

I nogle scenarier kan du have brug for at iterere over dynamiske nøgler, der er gemt i dine oversættelsesfiler, og rendere deres værdier betinget. Eksemplet nedenfor viser, hvordan du gør det med `Nuxt I18n Micro`.

### Eksempel: Rendering af dynamiske nøgler

Dette eksempel henter et array af nøgler fra en bestemt oversættelsessti (i dette tilfælde `dynamic`) og itererer over dem. Hver nøgle tjekkes for eksistens med `$has`, før dens værdi renderes med `$t`.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Eksempel på oversættelsesfil (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Eksempel: Rendering af dynamiske nøgler fra et objekt

I dette eksempel arbejder vi med et objekt gemt i din oversættelsesfil. Vi henter og itererer over objektets nøgler og renderer dynamisk både nøglenavnene og de tilhørende værdier.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Eksempel på oversættelsesfil (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 Brug af `<i18n-t>` til oversættelser med slots og interpolation

Komponenten `<i18n-t>` er nyttig til at rendere oversættelser med dynamisk indhold og HTML-tags:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### Eksempel-JSON til `<i18n-t>`

```json
{
  "greeting": "Welcome to the page"
}
```

### Med interpolation

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### Eksempel-JSON til interpolation

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 Brug af `$tc` til pluralisering

Funktionen `$tc` i `Nuxt I18n Micro` håndterer pluralisering baseret på antal og locale-indstillinger. Det er nyttigt til dynamisk justering af beskeder, der involverer antal, såsom antal elementer, notifikationer eller andre entiteter, der kan variere i antal.

### Eksempel: Brug af `$tc` til pluralisering

I det følgende eksempel viser vi en besked, der angiver antallet af æbler ved hjælp af `$tc`. Oversættelsesnøglen håndterer flere pluralformer baseret på det angivne antal.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### Eksempel-JSON til pluralisering

Sådan kan du definere oversættelsen i din JSON-fil for at håndtere forskellige pluralformer:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Forklaring

- **`$tc('apples', 0)`**: Returnerer den første form, som bruges når antallet er nul (`"no apples"`).
- **`$tc('apples', 1)`**: Returnerer den anden form, som bruges når antallet er ét (`"one apple"`).
- **`$tc('apples', 10)`**: Returnerer den tredje form med antallet, som bruges når antallet er to eller flere (`"10 apples"`).

### Yderligere eksempel med mere kompleks pluralisering

Hvis din applikation har brug for at håndtere mere komplekse pluraliseringsregler (f.eks. specifikke tilfælde for nul, én, to, få, mange, andet), kan du udvide oversættelsesstrengene tilsvarende:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: Kan sættes op til at returnere `"two apples"`.
- **`$tc('apples', 3)`**: Kan returnere `"a few apples"`, afhængigt af reglerne defineret for antallet.

## 🌐 Brug af `$tn` til talformatering

Funktionen `$tn` formaterer tal efter den aktuelle locale via `Intl.NumberFormat`-API'en. Det er nyttigt til at vise tal på en måde, der matcher brugerens regionale indstillinger, f.eks. valuta, procenter eller andre talformater.

### Eksempel: Brug af `$tn` til talformatering

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ Brug af `$td` til dato- og tidsformatering

Funktionen `$td` formaterer datoer og klokkeslæt efter den aktuelle locale via `Intl.DateTimeFormat`-API'en. Det er nyttigt til at vise datoer og klokkeslæt i formater, som brugeren kender ud fra sine locale-indstillinger.

### Eksempel: Brug af `$td` til dato- og tidsformatering

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ Brug af `$tdr` til relative datoformater

Funktionen `$tdr` formaterer datoer som relative tider (f.eks. "5 minutter siden", "2 dage siden") efter den aktuelle locale via `Intl.RelativeTimeFormat`-API'en. Det er nyttigt til at vise tidsforskelle i forhold til den aktuelle dato og tid.

### Eksempel: Brug af `$tdr` til relative datoformater

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
