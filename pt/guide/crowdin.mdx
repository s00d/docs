O [Crowdin](https://crowdin.com/) é uma plataforma de tradução: carrega os ficheiros do locale predefinido, os tradutores trabalham no Crowdin e descarrega de volta os restantes locales. O módulo lê ficheiros JSON simples, por isso a Crowdin CLI só precisa de um `crowdin.yml` que mapeie corretamente `locales/` e `locales/pages/`. Nenhuma definição do módulo é alterada.

## Configurar o crowdin.yml {#configure-crowdin-yml}

```yml
# crowdin.yml
project_id_env: CROWDIN_PROJECT_ID
api_token_env: CROWDIN_PERSONAL_TOKEN
base_path: ./locales
preserve_hierarchy: true

files:
  - source: /en.json
    translation: /%two_letters_code%.json
  - source: /pages/**/en.json
    translation: /pages/**/%two_letters_code%.json
```

- `en` é o seu locale predefinido; os respetivos ficheiros são as fontes.
- `project_id_env` / `api_token_env` leem o ID e o token a partir de variáveis de ambiente, para que nenhum segredo seja incluído no repositório.
- `preserve_hierarchy: true` mantém as pastas `pages/<page>/` tal como estão.
- O nome do ficheiro traduzido tem de ser igual ao `code` do locale em `nuxt.config.ts`. `%two_letters_code%` serve para códigos como `de`; para códigos como `pt-BR` use `%locale%`, ou mapeie os códigos do Crowdin para os seus com `languages_mapping`.

## Carregar e descarregar {#upload-and-download}

```bash
npm install -g @crowdin/cli

export CROWDIN_PROJECT_ID=123456
export CROWDIN_PERSONAL_TOKEN=...   # from Crowdin account settings

crowdin upload sources   # push locales/en.json and locales/pages/**/en.json
crowdin download         # write locales/de.json, locales/pages/**/de.json, ...
```

Execute ambos em CI para manter os ficheiros atualizados. Os ficheiros descarregados ficam no seu repositório como se tivessem sido editados à mão; o próximo build ou recarregamento em desenvolvimento aplica-os.

## Antes de carregar {#before-uploading}

Limpe primeiro as fontes para que os tradutores não trabalhem em chaves mortas: [`i18n-micro clean`](/pt/api/cli#clean) remove as chaves não utilizadas e [`i18n-micro check`](/pt/api/cli#check) indica as lacunas depois de um download. A CLI não tem integração própria com o Crowdin: esta página descreve a forma suportada.
