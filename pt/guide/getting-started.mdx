Esta página leva uma aplicação Nuxt de nenhuma i18n até uma página traduzida com um seletor de idioma. Só precisa dela uma vez, no início de um projeto. No final terá URLs localizados (`/about`, `/de/about`), um ficheiro JSON por locale e página, e `$t` nos seus templates.

## Instalar {#install}

O módulo requer Nuxt 3.18 ou mais recente (o Nuxt 4 também funciona) e Node 20 ou mais recente.

<CodeGroup>

```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>

## Configurar os locales {#configure-the-locales}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', displayName: 'English' },
      { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
      { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
    ],
    defaultLocale: 'en',
  },
})
```

É toda a configuração de que uma primeira aplicação precisa. As predefinições dão-lhe:

- `strategy: 'prefix_except_default'`: o locale por omissão não tem prefixo (`/about`), os restantes têm (`/de/about`). Consulte [Estratégias de encaminhamento](/pt/guide/strategy).
- `translationDir: 'locales'`: os ficheiros de tradução ficam em `locales/` na raiz do projeto, também com a estrutura `app/` do Nuxt 4.
- `meta: true`: etiquetas `hreflang`, canonical e `og:locale`, além de `lang` e `dir` em `<html>`. Consulte [SEO](/pt/guide/seo).
- Um visitante que abra `/` é enviado para o idioma que o seu navegador pede (`Accept-Language`). Consulte [Deteção de locale](/pt/guide/locale-detection).

`iso` é a etiqueta de idioma usada nas etiquetas de SEO; `code` é o que aparece no URL. Todas as opções estão listadas em [Opções do módulo](/pt/api/module-options).

## Adicionar ficheiros de tradução {#add-translation-files}

Inicie o servidor de desenvolvimento com `nuxt dev`. Quando o Nuxt resolve as páginas, o módulo cria um ficheiro vazio `{}` para cada locale e página que ainda não o tenha (desative isto com [`disableWatcher`](/pt/api/module-options#disablewatcher)):

```text
locales/
├── en.json            # root: keys every page can use
├── de.json
├── fr.json
└── pages/
    ├── index/         # pages/index.vue
    │   ├── en.json
    │   ├── de.json
    │   └── fr.json
    └── about/         # pages/about.vue
        ├── en.json
        ├── de.json
        └── fr.json
```

Preencha o ficheiro raiz e um ficheiro de página:

```json
// locales/en.json
{ "nav": { "home": "Home", "about": "About" } }
```

```json
// locales/pages/index/en.json
{ "welcome": "Welcome, {name}!", "items": "no items | one item | {count} items" }
```

Uma página vê as chaves raiz e as suas próprias chaves; em caso de conflito, prevalece o seu próprio ficheiro. Os nomes das pastas seguem o nome da rota (`pages/articles/[id].vue` corresponde a `locales/pages/articles-id/`). [Ficheiros de tradução](/pt/guide/translations) aborda a estrutura, os fallbacks e o carregamento.

## Usar `$t` numa página {#use-$t-on-a-page}

```vue
<!-- pages/index.vue -->
<script setup lang="ts">
const { t, tc, getLocale } = useI18n()

const title = t('nav.home') // 'Home'
</script>

<template>
  <h1>{{ $t('welcome', { name: 'Ada' }) }}</h1>
  <!-- Welcome, Ada! -->
  <p>{{ $tc('items', 3) }}</p>
  <!-- 3 items -->
  <p>{{ getLocale() }}</p>
  <!-- en -->
</template>
```

- Nos templates, todos os helpers estão disponíveis com `$` (`$t`, `$tc`, `$localePath`, …).
- Em `<script setup>`, `useI18n()` devolve os mesmos helpers, com e sem `$` (`t` e `$t` são a mesma função). É importado automaticamente.
- Os placeholders `{name}` são preenchidos a partir do objeto de parâmetros. As formas de plural são separadas por `|`; a contagem escolhe a forma (0, 1 e depois a última para tudo o que for superior).

Todos os helpers estão listados em [Métodos](/pt/api/methods).

## Criar links entre páginas e mudar de locale {#link-between-pages-and-switch-locale}

```vue
<!-- components/AppHeader.vue -->
<template>
  <nav>
    <i18n-link :to="{ name: 'index' }">{{ $t('nav.home') }}</i18n-link>
    <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
    <i18n-switcher />
  </nav>
</template>
```

- [`<i18n-link>`](/pt/components/i18n-link) é um `NuxtLink` que aponta para a página no locale atual: em `/de`, o link para about vai para `/de/about`.
- [`<i18n-switcher>`](/pt/components/i18n-switcher) é uma lista pendente com os locales ativos; mantém o visitante na mesma página.
- Para os seus próprios botões, chame `$switchLocale('de')`, que navega para a página atual em alemão e memoriza a escolha. Para um `NuxtLink` simples, use `$localePath({ name: 'about' })` ou `$switchLocalePath('de')`.

## Verificar {#check-it}

Execute `nuxt dev` e abra:

| URL | Mostra |
| --- | --- |
| `/` | Página inicial em inglês (ou um redirecionamento para `/de` quando o navegador prefere alemão) |
| `/de` | Página inicial em alemão |
| `/de/about` | Página about em alemão |
| `/en/about` | 404: o locale por omissão não tem prefixo com `prefix_except_default` |

As alterações aos ficheiros JSON aplicam-se na página aberta sem recarregar.
