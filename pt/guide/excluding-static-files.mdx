---
title: "Excluir caminhos"
description: "Mantenha páginas e ficheiros fora do encaminhamento por locale com excludePatterns e veja que caminhos já estão excluídos."
---

Alguns caminhos nunca devem receber um prefixo de locale nem um redirecionamento de locale: uma área de administração, um health check, um feed gerado. `excludePatterns` marca-os, e uma lista incorporada já abrange os internos do Nuxt e os ficheiros estáticos mais comuns. Uma página excluída mantém exatamente o caminho que escreveu e continua a ser renderizada com `$t`.

## Excluir um caminho {#exclude-a-path}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    excludePatterns: [
      '/admin', // /admin and everything below it
      '/preview-*', // glob over the whole path
    ],
  },
})
```

Com esta configuração, `pages/admin/index.vue` responde apenas em `/admin`; não existe `/de/admin`, e `/admin` nunca é redirecionado para `/de/admin`.

## Sintaxe dos padrões {#pattern-syntax}

Os padrões são comparados com o caminho sem `app.baseURL`:

| Padrão | Corresponde a | Não corresponde a |
| --- | --- | --- |
| `'/admin'` | `/admin`, `/admin/users` | `/administrator`, `/de/admin` |
| `'/preview-*'` | `/preview-1`, `/preview-a/b` | `/de/preview-1` |
| `'/file-?'` | `/file-a` | `/file-ab` |
| `/^\/v\d+\//` | `/v2/docs` | `/docs` |

Uma string sem `*` nem `?` corresponde ao caminho e a segmentos completos abaixo dele. Com `*` (qualquer sequência de caracteres, incluindo barras) ou `?` (um carácter) tem de corresponder ao caminho inteiro. Comece sempre as strings com `/`.

## O que já está excluído {#what-is-excluded-already}

Estes caminhos nunca recebem rotas de locale nem redirecionamentos, sem qualquer configuração:

- `/api` e `/_nuxt`, e tudo o que está abaixo deles;
- a rota das traduções, `/_locales` por omissão ([`apiBaseUrl`](/pt/api/module-options#apibaseurl));
- qualquer caminho com um segmento que comece por `__` (`/__nuxt_content`, `/en/__og-image__`);
- `/sitemap*.xml`, `/robots.txt`, `/favicon.ico`, `/apple-touch-icon*.png`, `/manifest.json`, `/sw.js`, `/workbox-*.js`;
- qualquer caminho cujo último segmento termine numa extensão de ficheiro estático: `xml txt ico json js css png jpg jpeg gif svg webp avif pdf wasm map mp4 webm mp3 zip gz woff woff2 ttf eot`. Slugs de páginas com pontos, como `/user/john.doe`, e caminhos `.html` continuam a ser páginas.

## O que faz uma exclusão {#what-an-exclusion-does}

- **Rotas:** não são geradas variantes localizadas; a página é mantida tal como foi escrita.
- **Redirecionamentos e 404:** o plugin de redirecionamento do servidor e o middleware de redirecionamento do cliente ignoram o caminho.
- **Pré-renderização:** os caminhos correspondentes são removidos da lista de rotas a pré-renderizar.

Não impede o middleware i18n do servidor de detetar um locale para o pedido, nem impede a página de utilizar traduções. Para manter uma página localizada mas fora das tags de SEO, utilize `disableMeta` ([Configuração da página](/pt/guide/per-component-translations#turn-off-seo-tags)). Para manter uma página não localizada a partir do `nuxt.config.ts` pelo caminho, `globalLocaleRoutes: { '/admin': false }` ([Caminhos localizados](/pt/guide/custom-locale-routes#in-nuxt-config)) faz o mesmo para o encaminhamento.
