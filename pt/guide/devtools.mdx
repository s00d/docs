Em `nuxt dev`, o módulo acrescenta duas ajudas de depuração: um separador **i18n Micro** no Nuxt DevTools para navegar e editar ficheiros de tradução, e um inspetor no Vue DevTools para o locale ativo e os dicionários carregados. Ambos existem apenas em desenvolvimento e não acrescentam nada às builds de produção. O separador do Nuxt precisa apenas do Nuxt DevTools ativado; o inspetor do Vue precisa também da extensão de browser Vue DevTools.

## Separador do Nuxt DevTools {#nuxt-devtools-tab}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  devtools: { enabled: true }, // the tab is registered only when DevTools are on
})
```

Abra o Nuxt DevTools (`Shift + Alt + D`) e escolha **i18n Micro**. O separador mostra:

- todos os ficheiros JSON em `locales/` (raiz e `pages/`) de todas as camadas, bem como os ficheiros raiz de `additionalTranslationDirs`;
- um editor por ficheiro; **Save** grava o ficheiro no disco e o servidor de desenvolvimento recarrega as traduções;
- **Export** / **Import** de um ficheiro em JSON, e **Stats** com contagens de chaves e cobertura das traduções;
- uma vista de configuração das opções do módulo resolvidas;
- **Translate**, que preenche as chaves em falta com um motor de tradução automática configurado nas definições do separador.

A gravação escreve apenas ficheiros `.json` existentes dentro dos seus diretórios de tradução. Quando um ficheiro existe em várias camadas, é escrita a cópia do projeto.

## Inspetor do Vue DevTools {#vue-devtools-inspector}

Com a extensão de browser Vue DevTools, o módulo regista um inspetor i18n (locale atual, chunk da rota, chaves carregadas) e uma linha temporal com mudanças de locale, carregamentos de chunks e chaves em falta.

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    debug: true, // also log every $t / $ts / $tc call on the timeline
    // vueDevtools: false, // turn the inspector off, keep the Nuxt tab
  },
})
```

[`vueDevtools`](/pt/api/module-options) tem como predefinição `true`. `debug: true` é verboso; use-o apenas em sessões curtas.

## Fora do Nuxt {#outside-nuxt}

A mesma interface é publicada como [`@i18n-micro/devtools-ui`](/pt/integrations/devtools-ui-package) para aplicações Vite construídas com os pacotes de frameworks; consulte essa página para a configuração.
