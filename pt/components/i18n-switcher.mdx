---
title: "<i18n-switcher>"
description: "O componente <i18n-switcher> é um menu pendente dos locales ativos, cada um com uma ligação para a página atual nesse locale."
---

`<i18n-switcher>` apresenta um botão com o locale ativo e um menu pendente com todos os locales ativos, incluindo o atual. Utilize-o para ter um menu de idiomas pronto a usar; construa o seu próprio a partir de [`$getLocales`](/pt/api/methods#$getlocales) e [`$switchLocalePath`](/pt/api/methods#$switchlocalepath) quando precisar de markup diferente. Cada entrada aponta para a página atual nesse locale.

## Props e slots {#props-and-slots}

| Prop | Tipo | Predefinição | Descrição |
| --- | --- | --- | --- |
| `customLabels` | `Record<string, string>` | `() => ({})` | Nome apresentado por código de locale, substituindo o `displayName` da configuração do locale. |
| `customWrapperStyle` | `CSSProperties` | `() => ({})` | Estilo inline para o contentor exterior. |
| `customButtonStyle` | `CSSProperties` | `() => ({})` | Estilo inline para o botão que abre o menu pendente. |
| `customDropdownStyle` | `CSSProperties` | `() => ({})` | Estilo inline para o painel do menu pendente. |
| `customItemStyle` | `CSSProperties` | `() => ({})` | Estilo inline para cada item do menu pendente. |
| `customLinkStyle` | `CSSProperties` | `() => ({})` | Estilo inline para a ligação dentro de um item. |
| `customActiveLinkStyle` | `CSSProperties` | `() => ({})` | Estilo inline para a ligação do locale atualmente ativo. |
| `customDisabledLinkStyle` | `CSSProperties` | `() => ({})` | Estilo inline para o botão do locale *atual* quando este tem `disabled: true` na configuração. |
| `customIconStyle` | `CSSProperties` | `() => ({})` | Estilo inline para o ícone de seta no botão. |

### Slots {#slots}

| Slot | Bindings | Descrição |
| --- | --- | --- |
| `before-button` | — | Conteúdo antes do botão que abre o menu pendente. |
| `before-selected-locale` | — | Conteúdo antes da etiqueta do locale ativo dentro do botão. |
| `after-selected-locale` | — | Conteúdo depois da etiqueta do locale ativo dentro do botão. |
| `before-dropdown` | — | Conteúdo entre o botão e o painel do menu pendente. |
| `before-dropdown-items` | — | Conteúdo no topo do menu pendente, acima da lista de locales. |
| `before-item` | `locale` | Conteúdo antes de cada entrada de locale. |
| `before-link-content` | `locale` | Conteúdo antes da etiqueta de um locale dentro da sua ligação. |
| `after-link-content` | `locale` | Conteúdo depois da etiqueta de um locale dentro da sua ligação. |
| `after-item` | `locale` | Conteúdo depois de cada entrada de locale. |
| `after-dropdown-items` | — | Conteúdo no fundo do menu pendente, abaixo da lista de locales. |
| `after-dropdown` | — | Conteúdo depois do painel do menu pendente. |

## Comportamento {#behaviour}

- Lista todos os locales sem `disabled: true`, incluindo o ativo.
- Cada entrada é um `<a>` para `$switchLocalePath(code)`. Um caminho é resolvido sob `app.baseURL`; um `baseUrl` de locale noutro domínio mantém-se absoluto. Tem `hreflang` e `lang` definidos como `iso || code`, `dir` quando o locale o tem, `aria-current="page"` no locale atual e a classe `switcher-locale-<code>`. Um clique chama `$switchLocale(code)` e fecha o menu pendente; com uma tecla modificadora, fica a cargo do browser.
- A lista permanece no HTML do servidor, oculta, para que os crawlers vejam as ligações. A tecla Escape ou um clique fora fecha-a.
- Etiqueta: `customLabels[code]`, depois o `displayName` do locale e depois o código (com um aviso em desenvolvimento).
- Estilos: pequenas predefinições inline (botão e painel brancos com contorno, a entrada ativa a negrito e a azul). Cada prop `custom*Style` é aplicada depois da predefinição da respetiva parte. O botão tem as classes `i18n-switcher-button` e `language-switcher`, o contentor `i18n-switcher-wrapper` e a lista `i18n-switcher-dropdown`. As posições usam propriedades CSS lógicas, pelo que `dir="rtl"` funciona.

## Exemplo {#example}

```vue
<template>
  <i18n-switcher
    :custom-labels="{ en: 'English', de: 'Deutsch' }"
    :custom-button-style="{ borderRadius: '4px' }"
  >
    <template #before-link-content="{ locale }">
      <img :src="`/flags/${locale.code}.svg`" alt="" width="16" />
    </template>
  </i18n-switcher>
</template>
```
