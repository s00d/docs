title: "<i18n-t>"
description: "O componente <i18n-t> renderiza uma tradução, com formas de plural, formatação de números e datas, e interpolação de HTML e slots."
---

`<i18n-t>` renderiza uma tradução num elemento. Utilize-o quando uma tradução precisa de componentes no seu interior (uma ligação numa frase), de uma forma de plural ou de um número ou data formatados. Resolve a chave para a rota atual, tal como `$t`.

## Props {#props}

| Prop | Tipo | Predefinição | Descrição |
| --- | --- | --- | --- |
| `keypath` **\*** | `string` | — | Chave de tradução a renderizar. |
| `plural` | `number \| string \| null` | — | Contagem que seleciona a forma de plural. Defina-a para utilizar `$tc` em vez de `$t`. `null` significa não definido. |
| `tag` | `string` | `'span'` | Elemento a renderizar. |
| `params` | `Record<string, string \| number \| boolean>` | — | Valores de interpolação substituídos na tradução. |
| `defaultValue` | `string` | `''` | Renderizado em vez do componente quando `hideIfEmpty` suprime uma tradução vazia. |
| `html` | `boolean` | `false` | Renderiza a tradução como HTML em vez de texto. Apenas para traduções que controla: os `params` são escapados, a tradução não. |
| `hideIfEmpty` | `boolean` | `false` | Não renderiza nada quando a tradução resulta numa string vazia. |
| `customPluralRule` | `PluralFunc` | `null` | Regra de plural apenas para este elemento, substituindo a configurada. A sua resposta é utilizada tal como está; `null` renderiza vazio. |
| `number` | `number \| string \| null` | — | Formata o valor com `$tn` e passa-o à tradução como `{number}`, juntamente com `params`. |
| `date` | `Date \| string \| number \| null` | — | Formata o valor com `$td` e passa-o à tradução como `{date}`, juntamente com `params`. |
| `relativeDate` | `Date \| string \| number \| null` | — | Formata o valor com `$tdr` e passa-o à tradução como `{relativeDate}`, juntamente com `params`. |

**\*** obrigatório.

## Regras de renderização {#rendering-rules}

O primeiro caso correspondente decide o resultado:

1. `number` — a tradução com `{ ...params, number: $tn(number) }`.
2. `date` — a tradução com `{ ...params, date: $td(date) }`.
3. `relativeDate` — a tradução com `{ ...params, relativeDate: $tdr(relativeDate) }`.
4. `plural` — a forma escolhida por `$tc`, incluindo o [marcador `=0 `](/pt/api/methods#$tc), com `{ ...params, count }`; ou `customPluralRule(keypath, count, params, locale, t)` quando definida, que lê o valor em bruto, incluindo o marcador, e cuja resposta é utilizada tal como está, sendo `null` vazio.
5. Caso contrário, a tradução com `params`.

`null` conta como não definido. Em todos os casos:

- `defaultValue` substitui uma chave em falta, em todos os ramos.
- `hideIfEmpty` renderiza `defaultValue` em vez de um resultado em branco.
- `html` renderiza o resultado como HTML. Os `params` são escapados, a tradução não; os slots são ignorados.
- Um slot `default` recebe `{ translation }`, e os slots com nome são ignorados.
- Caso contrário, cada slot com nome substitui todos os placeholders `{name}`, antes de um parâmetro com esse nome. Um valor de parâmetro que pareça um placeholder permanece como texto.

O resultado de `date` e `relativeDate` inclui `data-allow-mismatch="text"`, porque o fuso horário e o relógio do servidor não são os do navegador. Defina [`timeZone`](/pt/api/module-options#timezone) para renderizar a mesma data de calendário em ambos; `relativeDate` depende do relógio, pelo que ainda pode diferir.

## Exemplo {#example}

```json
{
  "terms": "I accept the {link}.",
  "termsLink": "terms of use",
  "items": "no items | one item | {count} items"
}
```

```vue
<template>
  <i18n-t keypath="terms" tag="p">
    <template #link>
      <NuxtLink :to="$localePath('/terms')">{{ $t('termsLink') }}</NuxtLink>
    </template>
  </i18n-t>

  <i18n-t keypath="items" :plural="cart.length" />
</template>
```

`html` define `innerHTML`: utilize-o apenas para traduções que controla. Os `params` são escapados, pelo que os dados do utilizador estão seguros aí, tal como uma chave para a qual não foi encontrada tradução.
