---
title: "<i18n-group>"
description: "O componente <i18n-group> fornece ao seu slot uma função t limitada a um prefixo de chave."
---

`<i18n-group>` limita um bloco de markup a um único prefixo de chave. Utilize-o quando muitas chaves de uma secção partilham um prefixo e não quer repeti-lo. O slot predefinido recebe um `t` que acrescenta o prefixo no início.

## Props e slot {#props-and-slot}

| Prop | Tipo | Predefinição | Descrição |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | Prefixo de chave a partir do qual é resolvida cada pesquisa dentro do slot. |
| `groupClass` | `string` | `''` | Classe adicional no elemento envolvente. |

**\*** obrigatório.

### Slots {#slots}

| Slot | Bindings | Descrição |
| --- | --- | --- |
| `default` | `prefix`, `t` | Recebe `prefix` e uma função `t` limitada a esse prefixo. |

## Comportamento {#behaviour}

- Renderiza `<div class="i18n-group {groupClass}">` à volta do slot.
- `t(key, params)` equivale a `$t(prefix + '.' + key, params)` para a rota atual.
- Apenas o `t` do slot é limitado: `$t` e os `<i18n-t>` aninhados dentro do grupo continuam a receber chaves completas.

## Exemplo {#example}

```json
{
  "checkout": { "title": "Checkout", "items": "Items: {count}" }
}
```

```vue
<template>
  <i18n-group prefix="checkout" group-class="checkout">
    <template #default="{ t }">
      <h2>{{ t('title') }}</h2>
      <p>{{ t('items', { count: 3 }) }}</p>
    </template>
  </i18n-group>
</template>
```
