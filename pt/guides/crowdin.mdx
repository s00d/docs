# 🌐 Guia de integração com o Crowdin

## 📖 Introdução

Integrar o Crowdin no seu projeto simplifica o processo de localização e tradução, facilitando a gestão de traduções em várias línguas e plataformas. Este guia apresenta um percurso passo a passo para configurar o Crowdin com o seu projeto, incluindo a configuração, o envio de fontes e a transferência de traduções.

## 🔧 Instalação e configuração

Para começar a utilizar o Crowdin, terá de instalar o Crowdin CLI globalmente na sua máquina e inicializá-lo no diretório do projeto.

### 📦 Instalar o Crowdin CLI

Primeiro, instale o Crowdin CLI globalmente com o npm:

```bash
npm install -g @crowdin/cli
```

### 🛠 Inicializar o Crowdin no seu projeto

Inicialize o Crowdin no seu projeto executando:

```bash
crowdin init
```

Este comando irá guiá-lo pelo processo de configuração, incluindo a definição do ID do projeto, token da API e outros detalhes de configuração.

## 🗂️ Guia de configuração

### 📄 Ficheiro de configuração do Crowdin (`crowdin.yml`)

O ficheiro de configuração do Crowdin (`crowdin.yml`) define como os ficheiros de origem são mapeados e onde as traduções devem ser colocadas. Segue-se um exemplo de configuração:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Parâmetros de configuração principais

- **`project_id`**: o ID do seu projeto no Crowdin. Identifica o projeto no Crowdin onde as traduções são geridas.
- **`api_token`**: o token da API utilizado para autenticação. Garanta que este token tem as permissões corretas para carregar e transferir traduções.
- **`base_path`**: define o diretório base dos ficheiros de origem. Neste exemplo, as traduções ficam guardadas no diretório `./locales`.
- **`base_url`**: o URL base da API do Crowdin.
- **`preserve_hierarchy`**: quando definido como `true`, o Crowdin mantém a estrutura de pastas dos seus ficheiros de origem no projeto.

### 📂 Configuração de ficheiros

A secção `files` mapeia os seus ficheiros de origem para os caminhos onde as traduções serão guardadas. Por exemplo:

- **Caminho de origem**: define a localização dos ficheiros de tradução originais.
- **Caminho de tradução**: especifica onde os ficheiros traduzidos serão guardados no Crowdin. São utilizados marcadores como `%two_letters_code%` para definir dinamicamente o código de idioma nos caminhos dos ficheiros.

## ⬆️ Carregar ficheiros de origem para o Crowdin

Depois de configurar o Crowdin, pode carregar os seus ficheiros de origem com o seguinte comando:

```bash
crowdin upload sources
```

Este comando carrega todos os ficheiros de origem indicados na configuração para o Crowdin, disponibilizando-os para tradução.

## ⬇️ Transferir traduções do Crowdin

Depois de as traduções serem concluídas ou atualizadas no Crowdin, pode transferi-las para o seu projeto com:

```bash
crowdin download
```

Este comando obtém as traduções mais recentes do Crowdin e guarda-as nos caminhos especificados no seu ficheiro de configuração.

## ⚙️ Boas práticas

### 🔑 Nomenclatura de chaves consistente

Garanta que as chaves de tradução são consistentes em todos os ficheiros, para evitar confusão e duplicação.

### 🧹 Manutenção regular

Reveja periodicamente e limpe chaves de tradução não utilizadas, para manter os seus ficheiros organizados e geríveis.

### 🛠 Automatize carregamentos e transferências

Integre os comandos do Crowdin CLI no seu pipeline de CI/CD para automatizar o carregamento dos ficheiros de origem e a transferência de traduções, garantindo que as suas traduções estão sempre atualizadas.

Seguindo este guia, conseguirá integrar o Crowdin no seu projeto de forma transparente, assegurando uma abordagem eficiente e organizada à gestão dos seus esforços de internacionalização.
