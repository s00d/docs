# 🌐 Guia de integração do Crowdin

## 📖 Introdução

Integrar o Crowdin no seu projeto simplifica o processo de localização e tradução, facilitando a gestão de traduções em vários idiomas e plataformas. Este guia oferece um passo a passo para configurar o Crowdin no seu projeto, incluindo configuração, envio de ficheiros de origem e transferência de traduções.

## 🔧 Instalação e configuração

Para começar com o Crowdin, precisa de instalar a CLI do Crowdin globalmente na sua máquina e de a inicializar no diretório do seu projeto.

### 📦 Instalar a CLI do Crowdin

Primeiro, instale a CLI do Crowdin globalmente via npm:

```bash
npm install -g @crowdin/cli
```

### 🛠 Inicializar o Crowdin no seu projeto

Inicialize o Crowdin no seu projeto executando:

```bash
crowdin init
```

Este comando orienta-o pelo processo de configuração, incluindo a definição do ID do projeto, do token de API e de outros detalhes.

## 🗂️ Guia de configuração

### 📄 Ficheiro de configuração do Crowdin (`crowdin.yml`)

O ficheiro de configuração do Crowdin (`crowdin.yml`) define como os seus ficheiros de origem são mapeados e onde as traduções devem ser colocadas. Segue um exemplo de configuração:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Parâmetros de configuração principais

- **`project_id`**: o ID do seu projeto Crowdin. Identifica o projeto no Crowdin onde as traduções são geridas.
- **`api_token`**: o token de API usado para autenticação. Certifique-se de que este token tem as permissões corretas para carregar e transferir traduções.
- **`base_path`**: especifica o diretório base dos ficheiros de origem. Neste exemplo, as traduções são armazenadas no diretório `./locales`.
- **`base_url`**: o URL base da API do Crowdin.
- **`preserve_hierarchy`**: quando definido como `true`, o Crowdin mantém a estrutura de pastas dos ficheiros de origem no projeto.

### 📂 Configuração de ficheiros

A secção `files` mapeia os seus ficheiros de origem para os caminhos onde as traduções serão armazenadas. Por exemplo:

- **Caminho de origem**: define a localização dos ficheiros de tradução originais.
- **Caminho da tradução**: especifica onde os ficheiros traduzidos serão armazenados no Crowdin. Marcadores como `%two_letters_code%` são usados para definir dinamicamente o código do idioma nos caminhos dos ficheiros.

## ⬆️ Carregar ficheiros de origem para o Crowdin

Depois de a configuração do Crowdin estar pronta, pode carregar os seus ficheiros de origem com o comando:

```bash
crowdin upload sources
```

Este comando carrega todos os ficheiros de origem especificados na configuração para o Crowdin, tornando-os disponíveis para tradução.

## ⬇️ Transferir traduções do Crowdin

Depois de as traduções estarem concluídas ou atualizadas no Crowdin, pode transferi-las para o seu projeto com:

```bash
crowdin download
```

Este comando obtém as traduções mais recentes do Crowdin e guarda-as de acordo com os caminhos especificados no ficheiro de configuração.

## ⚙️ Boas práticas

### 🔑 Nomenclatura consistente das chaves

Garanta que as chaves de tradução são consistentes em todos os ficheiros para evitar confusão e duplicação.

### 🧹 Manutenção regular

Reveja e limpe periodicamente as chaves de tradução não usadas para manter os seus ficheiros organizados e geríveis.

### 🛠 Automatizar carregamentos e transferências

Integre os comandos da CLI do Crowdin no seu pipeline de CI/CD para automatizar o carregamento de ficheiros de origem e a transferência de traduções, garantindo que estão sempre atualizadas.

Ao seguir este guia, poderá integrar o Crowdin no seu projeto de forma fluida, garantindo uma abordagem eficiente e organizada à gestão dos seus esforços de internacionalização.
