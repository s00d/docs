# Utilizar traduções em componentes

Depois de o módulo estar instalado e configurado, pode apresentar traduções chamando `$t('your_key')` dentro dos seus templates e scripts Vue.

## 1. Ficheiros de tradução ao nível raiz e específicos de página

1. As traduções de **nível raiz** ficam diretamente na pasta `/locales` (por exemplo, `/locales/en.json`, `/locales/fr.json`). Em tempo de build são fundidas automaticamente em cada ficheiro específico de página, ficando disponíveis em todas as páginas.
2. As traduções **específicas de página** ficam em `/locales/pages/...`, correspondendo à estrutura da pasta de páginas do Nuxt:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. Utilização em template com `$t`

Nos seus ficheiros `.vue`, pode usar `$t` diretamente no template:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
`$t` pode devolver **objetos** se a chave apontar para um nó JSON aninhado (por exemplo, `$t('header')` → `\{ title: "Hi" \}`). Em templates, isso renderiza como `[object Object]`. Utilize `$ts` quando precisar de uma string garantida, ou forneça uma chave mais específica como `$t('header.title')`. Consulte [Referência da API — $t vs $ts](/api/methods#t) para mais detalhes.
</Tip>

## 3. Mudar o locale atual

Para mudar de idioma na sua aplicação, pode obter `$locale` a partir de `useI18n()` e atribuir-lhe um novo código:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. Chaves aninhadas e marcadores

- As **chaves aninhadas** usam notação com ponto, por exemplo `nested.key.deeper`.
- Os **marcadores** permitem inserir valores dinâmicos:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. Dicas e boas práticas

- **Chaves em conflito**: se um ficheiro específico de página contiver a mesma chave de um ficheiro de nível raiz, a versão específica de página tem prioridade (as traduções raiz são fundidas como base em tempo de build).
- **Desativar ficheiros de página**: se preferir não usar traduções específicas de página, pode definir `disablePageLocales: true` na sua configuração Nuxt. Assim, só são usados os ficheiros `/locales/*.json`.
- **Sem imports diretos**: não precisa de fazer `import \{ useI18n \} from 'nuxt-i18n-micro'`; a funcionalidade de auto-injeção do módulo trata disso por si.

E é tudo! Com estes passos, pode rapidamente **começar a obter traduções** a partir de ficheiros JSON de nível raiz ou específicos de página e **apresentá-las** na sua aplicação Nuxt usando `$t`.

## Recursos adicionais

Para explorar funcionalidades mais avançadas, consulte:

1. **Componente `<i18n-t>`**  
   O componente `<i18n-t>` é uma alternativa poderosa a `$t`, especialmente útil em situações que envolvem elementos aninhados, uso avançado de marcadores e estruturas de tradução mais complexas.

- **Documentação**: [i18n-t](/api/components/i18n-t)

2. **Composable `useI18n`**  
   O composable `useI18n` oferece um conjunto completo de funções e propriedades reativas para gerir traduções, tratar da troca de locale, formatação e mais.

- **Documentação**: [useI18n](/api/composables/use-i18n)
