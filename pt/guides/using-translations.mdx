# Utilizar traduções em componentes

Depois de o módulo estar instalado e configurado, pode apresentar traduções chamando `$t('your_key')` nos seus templates e scripts Vue.

## 1. Ficheiros de tradução ao nível da raiz e por página

1. As traduções **ao nível da raiz** ficam diretamente na pasta `/locales` (p. ex. `/locales/en.json`, `/locales/fr.json`). Em build-time, são fundidas automaticamente em cada ficheiro por página, ficando disponíveis em todas as páginas.
2. As traduções **específicas por página** ficam em `/locales/pages/...`, correspondendo à estrutura da pasta pages do Nuxt:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. Utilização em templates com `$t`

Nos seus ficheiros `.vue`, pode utilizar `$t` diretamente no template:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
`$t` pode devolver **objetos** se a chave apontar para um nó JSON aninhado (p. ex. `$t('header')` → `\{ title: "Hi" \}`). Em templates, isto é renderizado como `[object Object]`. Utilize `$ts` quando precisar de garantir que o resultado é uma string, ou forneça uma chave mais específica como `$t('header.title')`. Consulte a [Referência da API — $t vs $ts](/api/methods#t) para mais detalhes.
</Tip>

## 3. Alternar o locale atual

Para mudar de idioma na sua aplicação, pode obter `$locale` a partir de `useI18n()` e atribuir-lhe um novo código:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. Chaves aninhadas e marcadores

- **Chaves aninhadas** utilizam notação por pontos, p. ex. `nested.key.deeper`.
- **Marcadores** permitem inserir valores dinâmicos:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. Sugestões e boas práticas

- **Chaves em conflito**: se um ficheiro específico de página contiver a mesma chave que um ficheiro ao nível da raiz, a versão específica de página tem prioridade (as traduções raiz são fundidas como base em build-time).
- **Desativar ficheiros de página**: se preferir não utilizar traduções específicas de página, pode definir `disablePageLocales: true` na sua configuração Nuxt. Assim, são utilizados apenas os ficheiros `/locales/*.json`.
- **Sem imports diretos**: não precisa de fazer `import \{ useI18n \} from 'nuxt-i18n-micro'`; a funcionalidade de auto-injeção do módulo trata disso por si.

E é tudo! Com estes passos, pode rapidamente **começar a obter traduções** dos ficheiros JSON ao nível da raiz ou específicos por página e **apresentá-las** na sua aplicação Nuxt usando `$t`.

## Recursos adicionais

Para explorar funcionalidades mais avançadas, não deixe de consultar:

1. **Componente `<i18n-t>`**  
   O componente `<i18n-t>` é uma alternativa poderosa ao `$t`, particularmente útil em situações que envolvem elementos aninhados, utilização avançada de marcadores e estruturas de tradução mais complexas.

- **Documentação**: [i18n-t](/api/components/i18n-t)

2. **Composable `useI18n`**  
   O composable `useI18n` disponibiliza um conjunto completo de funções e propriedades reativas para gerir traduções, alternar locales, formatação e muito mais.

- **Documentação**: [useI18n](/api/composables/use-i18n)
