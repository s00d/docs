# 🛠️ DevTools no `nuxt-i18n-micro`

## Vue DevTools (extensão do browser)

Em desenvolvimento, o módulo pode registar um inspetor personalizado e uma timeline no **Vue DevTools** através de `@vue/devtools-api`. Isto é independente do separador de Nuxt DevTools mencionado abaixo.

| Ferramenta | Ideal para |
|------|----------|
| **Vue DevTools** | Locale em direto, cache de traduções em memória, timeline de `$t` (`debug: true`), eventos de chave em falta |
| **Separador do Nuxt DevTools** | Editar ficheiros JSON em disco, visão geral de configuração, importação/exportação |

O plugin do vue-devtools é registado apenas durante `nuxt dev` (não em builds de produção). O estado da bridge exclusivo de dev no plugin principal é removido pela eliminação de código morto via `import.meta.dev`.

Desative a integração do browser mantendo o separador Nuxt:

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

Os eventos de timeline detalhados de `$t` exigem `debug: true`.

## 📖 O que é o Nuxt DevTools?

O DevTools é um assistente de desenvolvimento poderoso, integrado de forma transparente no módulo `nuxt-i18n-micro`. Oferece uma interface intuitiva para gerir tarefas de localização e tradução, tornando o seu fluxo de trabalho mais rápido e eficiente. Concebido para programadores que valorizam a conveniência, o Nuxt DevTools reduz a distância entre a codificação e a gestão em runtime.

## 🌌 Funcionalidades principais dos DevTools no `nuxt-i18n-micro`

### 1. **Gestão de locale**

Navegue, selecione e faça a gestão de locales na sua aplicação sem esforço. Quer trabalhe com um único idioma ou vários, o DevTools oferece um centro unificado para tratar de todas as definições de localização.

### 2. **Edição de traduções**

Edite ficheiros de tradução diretamente através de um editor JSON integrado. Isto elimina a necessidade de ferramentas externas, permitindo atualizações e alterações em tempo real sem interromper o seu fluxo de trabalho.

### 3. **Importação e exportação de ficheiros**

Simplifique a gestão de ficheiros de tradução:

- **Exportar**: guarde traduções como ficheiro JSON para cópias de segurança ou uso externo.
- **Importar**: carregue ficheiros de tradução atualizados no projeto para manter o conteúdo em dia.

### 4. **Pré-visualizações em tempo real**

Veja as alterações imediatamente no ambiente de desenvolvimento. Esta funcionalidade garante que traduções e configurações estão corretas antes de irem para produção.

### 5. **Integração fluida com o Nuxt**

O DevTools funciona nativamente com o `nuxt-i18n-micro`, potenciando as suas capacidades sem exigir configuração adicional. Adapta-se às suas necessidades de localização mantendo a estrutura modular e flexível do Nuxt.

## 🛠️ Porquê usar o DevTools?

O Nuxt DevTools é uma adição indispensável para projetos que exigem localização. Ajuda os programadores ao:

- **Poupar tempo**: automatiza tarefas repetitivas, como gestão de ficheiros e validação de formatos.
- **Reduzir erros**: proporciona um ambiente seguro e intuitivo para editar traduções.
- **Melhorar a colaboração**: permite a pessoas não técnicas gerir traduções facilmente.
- **Simplificar fluxos de trabalho**: consolida várias tarefas de localização numa única interface.
