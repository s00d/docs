# 🛠️ DevTools no `nuxt-i18n-micro`

## Vue DevTools (extensão do navegador)

Em desenvolvimento, o módulo pode registar um inspetor personalizado e uma linha temporal do **Vue DevTools** através de `@vue/devtools-api`. Isto é independente do separador Nuxt DevTools descrito abaixo.

| Ferramenta | Mais indicada para |
|------|----------|
| **Vue DevTools** | Locale atual, cache de traduções em memória, linha temporal de `$t` (`debug: true`), eventos de chaves em falta |
| **Separador Nuxt DevTools** | Edição de ficheiros JSON no disco, visão geral da configuração, importação/exportação |

O plugin do vue-devtools apenas é registado durante `nuxt dev` (não em builds de produção). O estado da ponte, exclusivo do modo de desenvolvimento no plugin principal, é removido pela eliminação de código morto através de `import.meta.dev`.

Desative a integração do navegador mantendo o separador Nuxt:

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

Os eventos detalhados na linha temporal de `$t` requerem `debug: true`.

## 📖 O que são as Nuxt DevTools?

As DevTools são um assistente de desenvolvimento poderoso, integrado de forma transparente no módulo `nuxt-i18n-micro`. Oferecem uma interface intuitiva para gerir tarefas de localização e tradução, tornando o seu fluxo de trabalho mais rápido e eficiente. Concebidas para programadores que valorizam a comodidade, as Nuxt DevTools eliminam a distância entre o desenvolvimento e a gestão em runtime.

## 🌟 Principais funcionalidades das DevTools no `nuxt-i18n-micro`

### 1. **Gestão de locales**

Explore, selecione e gira facilmente os locales na sua aplicação. Quer trabalhe com um único idioma ou vários, as DevTools disponibilizam um centro unificado para lidar com todas as definições de localização.

### 2. **Edição de traduções**

Edite os ficheiros de tradução diretamente através de um editor JSON integrado. Isto dispensa a necessidade de ferramentas externas e permite atualizações e alterações em tempo real sem interromper o seu fluxo de trabalho.

### 3. **Importação e exportação de ficheiros**

Simplifique a gestão dos ficheiros de tradução:

- **Exportação**: guarde as traduções como ficheiro JSON para efeitos de cópia de segurança ou utilização externa.
- **Importação**: carregue ficheiros de tradução atualizados no projeto para manter o conteúdo atualizado.

### 4. **Pré-visualizações em tempo real**

Veja as alterações imediatamente no ambiente de desenvolvimento. Esta funcionalidade garante que as traduções e configurações estão corretas antes de serem publicadas.

### 5. **Integração transparente com o Nuxt**

As DevTools funcionam nativamente com o `nuxt-i18n-micro`, ampliando as suas capacidades sem exigir configuração adicional. Adaptam-se às suas necessidades de localização, preservando a estrutura modular e flexível do Nuxt.

## 🛠️ Porquê utilizar as DevTools?

As Nuxt DevTools são um complemento indispensável para projetos que exigem localização. Ajudam os programadores ao:

- **Poupar tempo**: automatizando tarefas repetitivas como a gestão de ficheiros e a validação de formatos.
- **Reduzir erros**: proporcionando um ambiente seguro e intuitivo para editar traduções.
- **Melhorar a colaboração**: permitindo que pessoas sem experiência de desenvolvimento giram traduções com facilidade.
- **Otimizar os fluxos de trabalho**: consolidando várias tarefas de localização numa única interface.

## 🚀 Assuma o controlo da localização

Com as Nuxt DevTools integradas no `nuxt-i18n-micro`, gerir aplicações multilingues torna-se simples e eficiente. Quer esteja a afinar traduções ou a adicionar novos locales, as DevTools disponibilizam-lhe as ferramentas necessárias para oferecer experiências polidas e centradas no utilizador.
