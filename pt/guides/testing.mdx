# 🧪 Testar o módulo `Nuxt I18n Micro`

## 📖 Introdução aos testes

Testar o módulo `Nuxt I18n Micro` é fundamental para garantir que as funcionalidades de localização da sua aplicação funcionam como esperado. Esta documentação irá guiá-lo pela configuração do ambiente de testes, criação de configurações mock para o vitest e escrita de testes para os seus componentes. Para um exemplo prático, consulte o [projeto de exemplo no GitHub](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/test-utils/example).

Consulte [Testing routing strategies](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/testing-strategies.md) para ver como este repositório executa as suas próprias suítes — os projetos Vitest `unit` / `integration` / `e2e`, os ficheiros por estratégia (`test/strategies-*.test.ts`) e as regressões geradas.

## 🛠️ Configurar o ambiente de testes

### 1. Instalar `@i18n-micro/test-utils`

Primeiro, tem de instalar os utilitários de teste para o `Nuxt I18n Micro`. Este pacote fornece as ferramentas necessárias para simular e testar as suas configurações i18n.

```bash
npm install @i18n-micro/test-utils --save-dev
```

### 2. Criar um ficheiro de configuração mock

De seguida, crie um ficheiro para preparar a configuração mock do i18n. Este ficheiro será utilizado para simular as funções e utilitários i18n durante os seus testes.

```typescript
// tests/unit-setup.ts

import { mockNuxtImport } from '@nuxt/test-utils/runtime'
import { vi } from 'vitest'
import { i18nUtils } from '@i18n-micro/test-utils'

export function createFakeI18n() {
  return {
    $getLocale: vi.fn(i18nUtils.getLocale),
    $t: vi.fn(i18nUtils.t),
    $tc: vi.fn(i18nUtils.tc),
    $setLocale: vi.fn(i18nUtils.setLocale),
    $getLocaleName: vi.fn(i18nUtils.getLocaleName),
    $setLocaleName: vi.fn(i18nUtils.setLocaleName),
    $getLocales: vi.fn(i18nUtils.getLocales),
    $setLocales: vi.fn(i18nUtils.setLocales),
    $defaultLocale: vi.fn(i18nUtils.defaultLocale),
    $setDefaultLocale: vi.fn(i18nUtils.setDefaultLocale),
    $getRouteName: vi.fn(i18nUtils.getRouteName),
    $settRouteName: vi.fn(i18nUtils.settRouteName),
    $ts: vi.fn(i18nUtils.ts),
    $tn: vi.fn(i18nUtils.tn),
    $td: vi.fn(i18nUtils.td),
    $has: vi.fn(i18nUtils.has),
    $resolveTranslations: vi.fn(i18nUtils.resolveTranslations),
    $setTranslation: vi.fn(i18nUtils.setTranslation),
    $mergeTranslations: vi.fn(i18nUtils.mergeTranslations),
    $switchLocaleRoute: vi.fn(i18nUtils.switchLocaleRoute),
    $switchLocalePath: vi.fn(i18nUtils.switchLocalePath),
    $switchLocale: vi.fn(i18nUtils.switchLocale),
    $switchRoute: vi.fn(i18nUtils.switchRoute),
    $localeRoute: vi.fn(i18nUtils.localeRoute),
    $localePath: vi.fn(i18nUtils.localePath),
    $setI18nRouteParams: vi.fn(i18nUtils.setI18nRouteParams),
  }
}

mockNuxtImport<() => ReturnType<typeof createFakeI18n>>('useI18n', () => vi.fn(() => createFakeI18n()))

export const setTranslationsFromJson = i18nUtils.setTranslationsFromJson
```

### 3. Configurar o Vitest

Agora, configure o Vitest para usar o ficheiro de configuração mock e preparar o ambiente de testes.

```typescript
// vitest.config.ts

import { defineVitestConfig } from '@nuxt/test-utils/config'

export default defineVitestConfig({
  test: {
    watch: false,
    setupFiles: ['./tests/unit-setup.ts'],
    include: ['./**/*.spec.ts'],
  },
})
```

## 🧪 Escrever testes

### Componente de exemplo

Segue-se um exemplo de um componente simples que utiliza o composable `useI18n` para traduzir mensagens.

```vue
<script setup lang="ts">
const { $t } = useI18n()

const props = defineProps({
  message: {
    type: String,
    default: null,
  },
})

// Test to see that $t works in script setup as well as the template
const message = props.message || $t('defaultMessage')
</script>

<template>
  <div>
    <p>Test from component: {{ $t('welcome') }}</p>
    <p data-testid="message">Test message from props: {{ message }}</p>
  </div>
</template>
```

### Ficheiro de teste

Vamos agora escrever um teste para este componente.

```typescript
// tests/unit/example.spec.ts

import { describe, it, expect, beforeEach } from 'vitest'
import { mount } from '@vue/test-utils'
import ExampleComponent from '@/components/ExampleComponent.vue'
import fs from 'fs'
import path from 'path'
import { setTranslationsFromJson } from './unit-setup'

describe('ExampleComponent', () => {
  beforeEach(async () => {
    const fileContent = fs.readFileSync(path.join(__dirname, '../../locales/en-GB.json')).toString()
    await setTranslationsFromJson('en', JSON.parse(fileContent))
  })

  it('renders the welcome message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.text()).toContain('Test from component: Welcome')
  })

  it('renders the default message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Default Message')
  })

  it('renders the custom message correctly', () => {
    const wrapper = mount(ExampleComponent, {
      props: {
        message: 'Custom Message',
      },
    })
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Custom Message')
  })
})
```

## 📝 Boas práticas para testes

- **🔧 Simule as funções i18n:** simule sempre as funções i18n com `@i18n-micro/test-utils` para garantir resultados de teste consistentes e previsíveis.
- **⚙️ Utilize o Vitest para testes unitários:** o Vitest é uma framework de teste poderosa para aplicações Vue. Utilize-o para escrever testes unitários dos seus componentes.
- **📚 Documente os seus testes:** documente claramente o objetivo e os resultados esperados de cada teste. Isto ajuda a manter a clareza e facilita a compreensão dos testes por outras pessoas (ou pelo seu eu futuro).

## 📊 Métodos utilitários i18n

Segue-se uma tabela que descreve todos os métodos utilitários fornecidos pelo `@i18n-micro/test-utils`.

| Método                                          | Descrição                                                                                                                                |
| ----------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `t(key, params, defaultValue)`                  | Traduz uma chave com parâmetros opcionais e um valor por omissão.                                                                        |
| `tc(key, params, defaultValue)`                 | Traduz uma chave com suporte a pluralização.                                                                                             |
| `setTranslationsFromJson(locale, translations)` | Carrega traduções a partir de um objeto JSON para um locale específico.                                                                  |
| `getLocale()`                                   | Devolve o locale atual.                                                                                                                  |
| `setLocale(val)`                                | Define o locale atual.                                                                                                                   |
| `getLocaleName()`                               | Devolve o nome do locale atual.                                                                                                          |
| `setLocaleName(val)`                            | Define o nome do locale atual.                                                                                                           |
| `getLocales()`                                  | Devolve a lista de locales disponíveis.                                                                                                  |
| `setLocales(val)`                               | Define a lista de locales disponíveis.                                                                                                   |
| `defaultLocale()`                               | Devolve o locale predefinido.                                                                                                            |
| `setDefaultLocale(val)`                         | Define o locale predefinido.                                                                                                             |
| `getRouteName()`                                | Devolve o nome da rota atual.                                                                                                            |
| `settRouteName(val)`                            | Define o nome da rota atual.                                                                                                             |
| `ts(key, params, defaultValue)`                 | Traduz uma chave e devolve o resultado como string.                                                                                      |
| `tn(value, options?)`                           | Formata um número com `Intl.NumberFormatOptions` inline. Os formatos nomeados requerem configuração do módulo e não estão disponíveis neste helper autónomo. |
| `td(value, options?)`                           | Formata uma data com `Intl.DateTimeFormatOptions` inline. Os formatos nomeados requerem configuração do módulo e não estão disponíveis neste helper autónomo. |
| `has(key)`                                      | Verifica se existe uma chave de tradução.                                                                                                |
| `resolveTranslations()`                         | Devolve a árvore de traduções ativa para o locale e rota atuais.                                                                          |
| `setTranslation(key, value)`                    | Substitui o valor em `key` no dicionário ativo (substitui, sem fundir).                                                                  |
| `mergeTranslations(newTranslations)`            | Funde traduções no locale ativo em runtime.                                                                                              |

Seguindo estes passos, pode testar de forma eficaz o módulo `Nuxt I18n Micro` e garantir que as funcionalidades de localização da sua aplicação funcionam como esperado.
