# 🌍 Configurar locales multi-domínio com o `Nuxt I18n Micro` utilizando camadas

## 📝 Introdução

Ao tirar partido das camadas do `Nuxt I18n Micro`, pode criar uma configuração multi-domínio de localização flexível e fácil de manter. Esta abordagem não só simplifica a gestão de domínios ao eliminar a necessidade de funcionalidades complexas, como também permite uma distribuição de carga eficiente e reduz a complexidade do projeto. Ao executar projetos separados para diferentes locales, a sua aplicação pode escalar facilmente e adaptar-se a requisitos de locale diversos em vários domínios, oferecendo uma solução robusta e escalável para aplicações globais.

## 🎯 Objetivo

Criar uma configuração em que diferentes domínios servem locales específicos, personalizando as configurações em camadas filhas. Este método aproveita o sistema de camadas do Nuxt, permitindo manter uma configuração base e estendê-la ou modificá-la para cada domínio.

## 🛠 Passos para implementar locales multi-domínio

### 1. **Criar a camada base**

Comece por criar uma camada de configuração base que inclua todas as definições de locale comuns à aplicação. Esta configuração servirá de alicerce para as restantes configurações específicas de cada domínio.

#### **Configuração da camada base**

Crie o ficheiro de configuração base `base/nuxt.config.ts`:

```typescript
// base/nuxt.config.ts

export default defineNuxtConfig({
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'de', iso: 'de-DE', dir: 'ltr' },
      { code: 'es', iso: 'es-ES', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
    autoDetectLanguage: true,
  },
})
```

### 2. **Criar camadas filhas específicas por domínio**

Para cada domínio, crie uma camada filha que altere a configuração base para satisfazer os requisitos específicos desse domínio. Pode desativar locales que não sejam necessários para um determinado domínio.

#### **Exemplo: configuração para o domínio francês**

Crie uma configuração de camada filha para o domínio francês em `fr/nuxt.config.ts`:

```typescript
// fr/nuxt.config.ts

export default defineNuxtConfig({
  extends: '../base', // Inherit from the base configuration

  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: true }, // Disable English
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' }, // Add and enable the French locale
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: true }, // Disable German
      { code: 'es', iso: 'es-ES', dir: 'ltr', disabled: true }, // Disable Spanish
    ],
    defaultLocale: 'fr', // Set French as the default locale
    autoDetectLanguage: false, // Disable automatic language detection
  },
})
```

#### **Exemplo: configuração para o domínio alemão**

De igual modo, crie uma configuração de camada filha para o domínio alemão em `de/nuxt.config.ts`:

```typescript
// de/nuxt.config.ts

export default defineNuxtConfig({
  extends: '../base', // Inherit from the base configuration

  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: true }, // Disable English
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: true }, // Disable French
      { code: 'de', iso: 'de-DE', dir: 'ltr' }, // Use the German locale
      { code: 'es', iso: 'es-ES', dir: 'ltr', disabled: true }, // Disable Spanish
    ],
    defaultLocale: 'de', // Set German as the default locale
    autoDetectLanguage: false, // Disable automatic language detection
  },
})
```

### 3. **Implementar a aplicação para cada domínio**

Implemente a aplicação com a configuração adequada para cada domínio. Por exemplo:

- Implemente a configuração da camada `fr` em `fr.example.com`.
- Implemente a configuração da camada `de` em `de.example.com`.

### 4. **Configurar vários projetos para diferentes locales**

Para cada locale e domínio, terá de executar uma instância separada da aplicação. Isto garante que cada domínio serve a configuração de locale correta, otimizando a distribuição de carga e simplificando a estrutura do projeto. Ao executar vários projetos adaptados a cada locale, pode manter uma separação clara entre as configurações e reduzir a complexidade global.

### 5. **Configurar o encaminhamento com base no domínio**

Garanta que o seu encaminhamento está configurado para direcionar os utilizadores para o projeto correto com base no domínio a que estão a aceder. Isto garante que cada domínio serve o locale adequado, melhorando a experiência do utilizador e mantendo a consistência entre diferentes regiões.

### 6. **Implementar e verificar**

Depois de configurar as camadas e as implementar nos respetivos domínios, verifique se cada domínio está a servir o locale correto. Teste a aplicação de forma exaustiva para confirmar que o locale correto é carregado consoante o domínio.

## 📝 Boas práticas

- **Mantenha a configuração base genérica**: a configuração base deve abranger definições gerais aplicáveis a todos os domínios.
- **Isole a lógica específica de cada domínio**: mantenha as configurações específicas de domínio nas respetivas camadas para preservar a clareza e a separação de responsabilidades.

## 🎉 Conclusão

Ao tirar partido das camadas do `Nuxt I18n Micro`, pode criar uma configuração de localização multi-domínio flexível e fácil de manter. Esta abordagem não só elimina a necessidade de funcionalidades complexas de gestão de domínios, como também lhe permite distribuir a carga de forma eficiente e reduzir a complexidade do projeto. Executar projetos separados para diferentes locales garante que a sua aplicação pode escalar facilmente e adaptar-se a diferentes requisitos de locale em vários domínios, proporcionando uma solução robusta e escalável para aplicações globais.
