**Data**: 2025-10-30

**Versão**: `v2.0.0`

![v2.0.0 release](/images/2.0.0.png)

Estamos a introduzir HMR do lado do servidor para ficheiros de tradução em desenvolvimento. Quando uma tradução JSON é alterada, a cache do servidor invalida apenas as chaves afetadas e os pedidos seguintes recebem imediatamente os dados atualizados — sem necessidade de reinícios.

## Novidades {#what’s-new}

- HMR do lado do servidor para ficheiros de tradução
- Invalidação instantânea da cache por página/locale
- Experiência de desenvolvimento fluida durante a edição de conteúdos

## Como funciona {#how-it-works}

- O watcher em `src/runtime/server/plugins/watcher.dev.ts` observa `<rootDir>/<translationDir>/**/*.json`
- Os ficheiros de página (por exemplo, `pages/<page>/<locale>.json`) invalidam `_locales:merged:<page>:<locale>`
- Os ficheiros de nível raiz (por exemplo, `<locale>.json`) invalidam todas as chaves fundidas desse locale
- Registado automaticamente a partir de `src/module.ts` em desenvolvimento quando `experimental.hmr !== false`

## Configuração {#configuration}

```ts
export default defineNuxtConfig({
  i18n: {
    experimental: { hmr: true }, // default in dev
  },
})
```
