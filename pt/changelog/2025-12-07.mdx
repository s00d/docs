**Data**: 2025-12-07

**Versão**: `v2.14.1`

![Lançamento v2.14](/images/2.14.0.png)

Temos o prazer de anunciar a **v2.14.1** com novas integrações para Node.js, Vue 3 e Astro! Estes pacotes trazem as mesmas poderosas capacidades de i18n às suas frameworks favoritas, partilhando a mesma lógica central para consistência e desempenho.

## O que há de novo? {#what’s-new}

- **@i18n-micro/node** - Utilize traduções i18n em qualquer aplicação Node.js, ferramenta CLI ou serviço de backend
- **@i18n-micro/vue** - Plugin Vue 3 para internacionalização com traduções reativas e suporte específico por rota
- **@i18n-micro/astro** - Integração Astro para internacionalização com suporte completo para TypeScript
- **@i18n-micro/types-generator** - Geração automática de tipos TypeScript para chaves de tradução, com total segurança de tipos e preenchimento automático no IDE

## Funcionalidades principais {#key-features}

Todas as integrações partilham as mesmas vantagens centrais:

- Leves e eficientes
- Suporte para traduções específicas por rota
- Pluralização integrada
- Formatação de números, datas e tempo relativo
- Suporte completo para TypeScript
- Mesma estrutura de ficheiros JSON de tradução

O **Types Generator** oferece melhorias adicionais à experiência de desenvolvimento:

- Geração automática de tipos a partir de ficheiros JSON de tradução
- Chaves de tradução com segurança de tipos e validação em tempo de compilação
- Suporte completo de preenchimento automático no IDE
- Recarregamento automático quando os ficheiros de tradução mudam
- Zero sobrecarga em runtime

Para documentação detalhada e exemplos, visite o [repositório](https://github.com/s00d/nuxt-i18n-micro) ou consulte a [documentação](https://s00d.github.io/nuxt-i18n-micro/).
