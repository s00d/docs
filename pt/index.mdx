title: "Nuxt I18n Micro"
description: "i18n pequeno e rápido para Nuxt: traduções JSON por página, rotas localizadas em tempo de build e tags de SEO de origem."
---

O Nuxt I18n Micro é um módulo i18n leve e de alto desempenho para Nuxt 3 e 4, concebido para projetos de grande dimensão. Mantém baixos os tempos de build, o consumo de memória e o tamanho do bundle em comparação com soluções i18n tradicionais como o `@nuxtjs/i18n`.

As rotas localizadas são geradas em tempo de build pelo `@i18n-micro/route-strategy` e resolvidas em tempo de execução pelo `@i18n-micro/path-strategy`, pelo que as ligações, o seletor de idioma, o `hreflang` e os redirecionamentos estão todos em concordância com o router. As traduções são apenas em JSON, divididas entre ficheiros raiz partilhados e ficheiros por página que o servidor de desenvolvimento cria por si, com HMR incorporado.

<CodeGroup>

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>
