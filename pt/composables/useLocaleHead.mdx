---
title: "useLocaleHead"
description: "useLocaleHead constrói as tags SEO i18n (lang, dir, canonical, hreflang, og:locale) como um objeto que passa a useHead."
---

`useLocaleHead()` constrói as tags de head i18n para a rota atual: `lang` e `dir` em `<html>`, um link canónico, alternativas `hreflang` com `x-default`, `og:url`, `og:locale` e `og:locale:alternate`. Use-o quando definir [`meta: false`](/pt/api/module-options#meta) e gerir `useHead` por conta própria; com `meta: true` o módulo já regista estas tags, e as alterações por página passam por [`useI18nHead`](/pt/composables/useI18nHead).

## Assinatura {#signature}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { build: () => LocaleHead; metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }, LocaleHead | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

As tags de head SEO para a rota atual: alternativas `hreflang` para cada locale mais
`x-default`, um link canónico, `og:locale` e `lang`/`dir` em `<html>`.

Só é necessário quando `meta` está desativado ou as predefinições precisam de ajustes — com `meta: true`
o módulo regista as mesmas tags por si.

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| `options` | `UseLocaleHeadOptions` |  |

**Devolve** — `metaObject`, uma ref com o objeto de head pronto a passar a `useHead`; `updateMeta` atualiza-o; `build` calcula o objeto de head a partir da rota atual (reativo quando lido num getter, por exemplo `useHead(() => build())`)

```ts
const { metaObject } = useLocaleHead({ addSeoAttributes: true })
useHead(metaObject)
```

## Opções {#options}

| Opção | Predefinição | Descrição |
| --- | --- | --- |
| `addDirAttribute` | `true` | Define `dir` em `<html>` a partir do `dir` do locale (`'auto'` quando não tem nenhum). |
| `identifierAttribute` | `'id'` | Atributo que identifica cada tag (`i18n-can`, `i18n-og`, `i18n-alternate-<hreflang>`, …), para que as atualizações substituam as tags em vez de as acrescentar. |
| `addSeoAttributes` | `true` | Emite as tags canonical, `hreflang` e `og:`. `false` mantém apenas `htmlAttrs`. |
| `baseUrl` | `'/'` | Origem juntada a cada URL. Mantenha `'/'` para URLs relativos; passe `'https://example.com'` para URLs absolutos. |
| `autoUpdate` | `true` | Reconstrói `metaObject` quando a rota ou o estado `i18n-locale` muda. |

## O que emite {#what-it-emits}

- Nada numa rota sem correspondência (404) ou com `disableMeta` para o locale ativo.
- Canonical e `og:url`: `$switchLocalePath(<active locale>)`, com a query reduzida a [`canonicalQueryWhitelist`](/pt/api/module-options#canonicalquerywhitelist) e [`trailingSlash`](/pt/api/module-options#trailingslash) aplicado.
- `hreflang`: um link por cada locale ativo em que a página existe, `hreflang = iso || code`, ignorando os locales com `seo: false`; com `hreflangBaseLanguage: true` o primeiro locale regional de uma língua emite também a tag da língua base. Nenhum com `no_prefix`.
- `x-default`: o URL do locale predefinido, exceto se a estratégia for `no_prefix`, se o locale predefinido tiver `seo: false` ou se a página não existir nele.
- `og:locale` / `og:locale:alternate`: a partir do `og` do locale, ou do seu `iso` convertido (`en-US` → `en_US`); ignorado com um aviso em desenvolvimento quando nenhum funciona.

## Exemplo {#example}

```ts
// app.vue, with i18n.meta: false
const { metaObject } = useLocaleHead({ baseUrl: 'https://example.com' })
useHead(metaObject)
```

`build()` devolve o mesmo objeto sem a ref: `useHead(() => build())` mantém-se reativo sem um watcher.
