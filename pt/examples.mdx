# 📚 Exemplos e utilização do Nuxt I18n Micro

Esta secção apresenta vários exemplos que demonstram como utilizar o `Nuxt I18n Micro` na sua aplicação Nuxt.js. Verá como trocar de locale, utilizar os componentes `<i18n-link>`, `<i18n-switcher>` e `<i18n-t>` e lidar dinamicamente com chaves de tradução.

## 🛠️ Configuração básica

Segue uma configuração básica para começar com o `Nuxt I18n Micro`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Troca de locale

### Trocar locales programaticamente

Este exemplo demonstra como trocar de locale programaticamente usando botões:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Exemplo de JSON para troca de locale

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### Utilizar o componente `<i18n-switcher>`

O componente `<i18n-switcher>` fornece uma lista pendente para troca de locale com rótulos personalizáveis:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 🌐 Utilizar `<i18n-link>` para navegação localizada

## 📝 Renderizar chaves dinâmicas a partir de ficheiros de tradução

Em alguns cenários, poderá querer iterar sobre chaves dinâmicas armazenadas nos seus ficheiros de tradução e renderizar os respetivos valores condicionalmente. O exemplo abaixo demonstra como conseguir isto com `Nuxt I18n Micro`.

### Exemplo: renderizar chaves dinâmicas

Este exemplo obtém um array de chaves a partir de um caminho de tradução específico (neste caso, `dynamic`) e itera sobre elas. A existência de cada chave é verificada com `$has` antes de renderizar o seu valor com `$t`.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Exemplo de ficheiro de tradução (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Exemplo: renderizar chaves dinâmicas a partir de um objeto

Neste exemplo, tratamos um objeto armazenado no seu ficheiro de tradução. Obtemos e iteramos sobre as chaves do objeto, renderizando dinamicamente tanto os nomes das chaves como os respetivos valores.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Exemplo de ficheiro de tradução (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 Utilizar `<i18n-t>` para traduções com slots e interpolação

O componente `<i18n-t>` é útil para renderizar traduções com conteúdo dinâmico e tags HTML:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### Exemplo de JSON para `<i18n-t>`

```json
{
  "greeting": "Welcome to the page"
}
```

### Com interpolação

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### Exemplo de JSON para interpolação

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 Utilizar `$tc` para pluralização

A função `$tc` em `Nuxt I18n Micro` trata da pluralização com base na contagem e nas definições de locale. Isto é útil para ajustar dinamicamente mensagens que envolvem contagens, como itens, notificações ou outras entidades cuja quantidade pode variar.

### Exemplo: utilizar `$tc` para pluralização

No exemplo seguinte, apresentamos uma mensagem que indica o número de maçãs usando `$tc`. A chave de tradução gere várias formas plurais com base na contagem fornecida.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### Exemplo de JSON para pluralização

Eis como pode definir a tradução no seu ficheiro JSON para lidar com diferentes formas plurais:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Explicação

- **`$tc('apples', 0)`**: Devolve a primeira forma, usada quando a contagem é zero (`"no apples"`).
- **`$tc('apples', 1)`**: Devolve a segunda forma, usada quando a contagem é um (`"one apple"`).
- **`$tc('apples', 10)`**: Devolve a terceira forma com o valor da contagem, usada quando a contagem é dois ou mais (`"10 apples"`).

### Exemplo adicional com pluralização mais complexa

Se a sua aplicação precisar de lidar com regras de pluralização mais complexas (por exemplo, casos específicos para zero, um, dois, poucos, muitos, outros), pode estender as strings de tradução em conformidade:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: Pode ser configurado para devolver `"two apples"`.
- **`$tc('apples', 3)`**: Pode devolver `"a few apples"`, dependendo das regras definidas para a contagem.

## 🌐 Utilizar `$tn` para formatação de números

A função `$tn` formata números de acordo com o locale atual usando a API `Intl.NumberFormat`. Isto é útil para apresentar números de forma consistente com as definições regionais do utilizador, como moeda, percentagens ou outros formatos numéricos.

### Exemplo: utilizar `$tn` para formatação de números

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ Utilizar `$td` para formatação de datas e horas

A função `$td` formata datas e horas de acordo com o locale atual usando a API `Intl.DateTimeFormat`. Isto é útil para apresentar datas e horas em formatos familiares ao utilizador com base nas suas definições de locale.

### Exemplo: utilizar `$td` para formatação de datas e horas

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ Utilizar `$tdr` para formatação de datas relativas

A função `$tdr` formata datas como tempos relativos (por exemplo, "5 minutes ago", "2 days ago") de acordo com o locale atual usando a API `Intl.RelativeTimeFormat`. Isto é útil para apresentar diferenças de tempo relativas à data e hora atuais.

### Exemplo: utilizar `$tdr` para formatação de datas relativas

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
