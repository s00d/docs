`@i18n-micro/runtime` é a instância i18n independente da framework: dicionários, `t()`, plurais, formatação `Intl` e uma subscrição de alterações, sem `fs` e sem framework. Utilize-a em TypeScript simples, num web worker, numa função edge ou como base da sua própria integração. Os pacotes React, Preact, Node e Astro estendem esta mesma classe.

## Instalação {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/runtime
```

```bash npm
npm install @i18n-micro/runtime
```

```bash yarn
yarn add @i18n-micro/runtime
```

</CodeGroup>

Sem dependências peer. Para ficheiros de tradução em disco, utilize [`@i18n-micro/node`](/pt/integrations/nodejs-package).

## Configuração {#setup}

```ts
import { createI18n } from '@i18n-micro/runtime'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    en: { greeting: 'Hello, {name}!', apples: 'no apples | one apple | {count} apples' },
    de: { greeting: 'Hallo, {name}!' },
  },
  routeMessages: {
    about: { en: { title: 'About us' } },
  },
})
```

Todas as opções (`plural`, `missingWarn`, `missingHandler`, `numberFormats`, `datetimeFormats`) estão listadas em [a instância](/pt/integrations/overview#the-instance).

## Traduzir {#translate}

```ts
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.tc('apples', 5) // '5 apples'
i18n.tn(1234.5) // '1,234.5'

i18n.setRoute('about')
i18n.t('title') // 'About us' (route dictionary)
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!' (root, still visible)
```

Carregue mais dicionários mais tarde:

```ts
i18n.loadMessages({ fr: { greeting: 'Bonjour, {name} !' } }, { about: { fr: { title: 'À propos' } } })
i18n.addTranslations('fr', { nav: { home: 'Accueil' } }) // deep merge; pass false to replace

await i18n.loadFromUrl('/locales/fr.json', { locale: 'fr' })
await i18n.loadFromUrl('/locales/pages/about/fr.json', { locale: 'fr', routeName: 'about' })
await i18n.loadFromUrls([
  { url: '/locales/en.json', locale: 'en' },
  { url: '/locales/de.json', locale: 'de' },
])
```

`loadFromUrl` utiliza `fetch` (passe `init` para os cabeçalhos) e lança um erro perante uma resposta que não seja OK. `loadFromUrls` carrega um a seguir ao outro.

## Mudar de locale {#switch-locale}

```ts
i18n.locale = 'de'
i18n.t('greeting', { name: 'Ada' }) // 'Hallo, Ada!'
```

As alterações de locale, de rota e de dicionário notificam os subscritores, que é a forma como as integrações das frameworks voltam a renderizar:

```ts
const stop = i18n.subscribe(() => {
  document.querySelector('#greeting')!.textContent = i18n.t('greeting', { name: 'Ada' }) as string
})
i18n.locale = 'fr'
stop()
```

`getSnapshot()` devolve uma string que muda a cada notificação (para stores no estilo de `useSyncExternalStore`).

## Por pedido {#per-request}

A instância guarda um locale e uma rota. Num servidor, não mude uma instância partilhada por pedido: dois pedidos simultâneos veriam o locale um do outro. `i18n.fork(locale)` dá a um pedido a sua própria instância: locale, fallback e rota próprios; os mesmos dicionários, formatadores e regras. Fazer fork custa o mesmo independentemente do número de dicionários. Um fork vê as escritas no seu pai até à sua primeira escrita própria, e as suas escritas ficam nele. [Node.js](/pt/integrations/nodejs-package#per-request) acrescenta `run`.

## API {#api}

| Membro | Notas |
| --- | --- |
| `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has` | ver [Traduzir e formatar](/pt/integrations/overview#translate-and-format) |
| `locale`, `fallbackLocale` | get/set |
| `currentRoute`, `setRoute(name)`, `getRoute()` | rota ativa, por omissão `'index'` |
| `loadMessages(messages?, routeMessages?)` | funde vários locales e rotas de uma só vez |
| `addTranslations(locale, tree, merge = true)`, `addRouteTranslations(locale, route, tree, merge = true)` | |
| `loadFromUrl(url, { locale?, routeName?, init? })`, `loadFromUrls(entries)` | JSON via `fetch` |
| `hasTranslation(key)` | locale ativo, qualquer rota (ao contrário de `has`, que verifica a rota ativa e a raiz) |
| `setTranslation(key, value)`, `resolveTranslations()` | escreve uma chave; lê a árvore fundida |
| `clear()`, `clearCache()` | descarta todos os dicionários |
| `subscribe(cb)`, `getSnapshot()` | notificações de alterações |
| `storage` | `{ translations: Map<'locale:route', Translations> }` |

Um código que não seja uma etiqueta de idioma obtém os seus plurais a partir de `localeIso: { ua: 'uk-UA' }`; `localeIsoMap(locales)` constrói isso a partir das entradas de uma lista de locales que tenham `iso`.

Exportações do módulo: `createI18n`, `I18n`, `fetchJsonTranslations`, `FormatService`, `interpolate`, `localeIsoMap` e os tipos `I18nOptions`, `LoadFromUrlOptions`, `LoadFromUrlEntry`, `TranslationStorage`, `Translations`, `Locale`, `PluralFunc`. Assinaturas completas: [referência do pacote](/pt/api/packages/runtime).
