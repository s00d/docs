Os pacotes `@i18n-micro/*` levam o núcleo de tradução do Nuxt I18n Micro para Vue, React, Preact, Solid, Astro, VitePress e JavaScript simples. Use-os quando a sua aplicação não é uma aplicação Nuxt, ou quando um script ou servidor fora do Nuxt precisa dos mesmos ficheiros de tradução. Todos os pacotes partilham um único modelo de instância, um único contrato de adaptador de router e os mesmos quatro componentes, descritos uma vez nesta página.

A entrada do router é um import separado, por isso uma aplicação sem router nunca inclui um no bundle.

`@i18n-micro/core`, `@i18n-micro/types` e `@i18n-micro/utils` são instalados com estes pacotes; raramente os importa diretamente. As assinaturas de todos os exports estão na [referência de pacotes](/pt/api/packages/overview) gerada.

Cada pacote tem um playground em `packages/<name>/playground` no repositório.

## A instância {#the-instance}

`createI18n(options)` devolve uma instância que contém os dicionários, o locale atual e a rota atual. As opções são as mesmas em todos os pacotes:

| Opção | Tipo | Predefinição | Notas |
| --- | --- | --- | --- |
| `locale` | `string` | obrigatório | Locale ativo. |
| `fallbackLocale` | `string` | `locale` | Consultado quando uma chave falta em `locale`. |
| `messages` | `Record<locale, Translations>` | `{}` | Dicionários raiz (rota `'index'`). |
| `routeMessages` | `Record<route, Record<locale, Translations>>` | `{}` | Dicionários de rota. Apenas Runtime, React, Preact, Node e VitePress. |
| `plural` | `PluralFunc` | `defaultPlural` | Regra de plural personalizada. |
| `missingWarn` | `boolean` | `true` | `console.warn` no browser, apenas em desenvolvimento, para uma chave em falta. |
| `missingHandler` | `(locale, key, routeName) => void` | — | Chamado em vez do aviso. |
| `numberFormats` | `Record<locale, Record<name, Intl.NumberFormatOptions>>` | — | Formatos com nome: `tn(9.5, 'currency')`. |
| `datetimeFormats` | `Record<locale, Record<name, Intl.DateTimeFormatOptions>>` | — | Formatos com nome: `td(date, 'short')`. |
| `timeZone` | `string` | fuso do runtime | Fuso IANA para as datas de `td`; não afeta `tdr`. Defina-o para que servidor e browser renderizem a mesma data. |
| `now` | `() => number` | `Date.now` | O relógio de `tdr`. Passe à hidratação a hora do servidor para que ambos renderizem o mesmo texto. |
| `localeIso` | `Record<code, string>` | — | Tag BCP 47 usada para as regras de plural (`ua` → `uk-UA`). React, Preact e Solid obtêm-na a partir de `iso` nos `locales` do provider. |

Os dicionários ficam em `i18n.storage.translations`, um `Map` indexado por `locale:route` (`en:index`, `en:about`).

Uma chave é procurada no dicionário da rota atual e depois no dicionário raiz, primeiro para `locale` e depois para `fallbackLocale`. Uma chave em falta devolve a própria chave (ou o `defaultValue` que passar).

```ts
i18n.addTranslations('en', { nav: { home: 'Home' } }) // root, deep-merged
i18n.addRouteTranslations('en', 'about', { title: 'About us' }) // route chunk
i18n.addTranslations('en', { nav: { home: 'Start' } }, false) // replace instead of merge
i18n.setRoute('about')
i18n.t('title') // 'About us'
i18n.t('nav.home') // 'Start' (root key, still visible on the route)
```

### Traduzir e formatar {#translate-and-format}

| Método | Devolve |
| --- | --- |
| `t(key, params?, defaultValue?, routeName?)` | O valor (string, número, objeto) com `{param}` interpolado. |
| `ts(...)` | O mesmo que `t`, como string. |
| `tc(key, count \| params, defaultValue?)` | Forma plural. |
| `tn(value, options \| name)` | `Intl.NumberFormat` no locale ativo. |
| `td(value, options \| name)` | `Intl.DateTimeFormat`. |
| `tdr(value, options?)` | Tempo relativo (`3 days ago`). |
| `has(key, routeName?)` | `true` quando o locale ativo tem a chave (dicionário de rota ou raiz; o fallback não é verificado). |

`defaultPlural` divide o valor por `|` e escolhe a forma no índice `count`, limitado à última; uma contagem negativa, fracionária ou `NaN` escolhe a última forma.

Um `plural` personalizado recebe `(key, count, params, locale, getter)`. Leia o valor através de `getter(key)`; não divida a chave:

```ts
import type { PluralFunc } from '@i18n-micro/vue'

const plural: PluralFunc = (key, count, params, _locale, getter) => {
  const value = getter(key)
  if (typeof value !== 'string') return null
  const forms = value.split('|').map((form) => form.trim())
  return (count === 1 ? forms[0] : forms[1] ?? forms[0])!.replace('{count}', String(count))
}
```

## Adaptador de router {#router-adapter}

Os pacotes SPA não dependem de um router. Um adaptador de router (`I18nRoutingStrategy`) indica-lhes como ler o caminho atual, navegar e construir um caminho localizado. Os adaptadores integrados adicionam prefixo a todos os locales exceto `defaultLocale` (`/about`, `/de/about`).

| Membro | Obrigatório | Usado por |
| --- | --- | --- |
| `getCurrentPath(): string` | sim | verificação de link ativo (por página; query e hash não contam), `switchLocale` (mantém-nos) |
| `push({ path }): void` | sim | `switchLocale`, `<I18nLink>` sem `linkComponent`, `<I18nSwitcher>` |
| `replace({ path }): void` | sim | — |
| `resolvePath(to, locale)` | não | `localePath`, `localeRoute`, `<I18nLink>`; sem ele os caminhos são devolvidos tal como estão |
| `linkComponent` | não | `<I18nLink>` renderiza-o (por exemplo `RouterLink`) em vez de `<a>` |
| `getRoute()` | não | `{ fullPath, query }` para os helpers de SEO |

`push` e `replace` são obrigatórios em Vue, React, Preact e Solid. O Astro tem o seu próprio adaptador do lado do servidor, com `push`/`replace` opcionais (consulte [Astro](/pt/integrations/astro-package#router-adapter)).

Um adaptador mínimo para qualquer router baseado em history:

```ts
import type { I18nRoutingStrategy } from '@i18n-micro/react'

const locales = ['en', 'de']
const stripLocale = (path: string) => path.replace(/^\/(en|de)(?=\/|$)/, '') || '/'

export const historyAdapter: I18nRoutingStrategy = {
  getCurrentPath: () => window.location.pathname + window.location.search + window.location.hash,
  push: ({ path }) => window.history.pushState({}, '', path),
  replace: ({ path }) => window.history.replaceState({}, '', path),
  resolvePath: (to, locale) => {
    const path = stripLocale(typeof to === 'string' ? to : to.path || '/')
    return locale === 'en' ? path : `/${locale}${path === '/' ? '' : path}`
  },
}
```

## Componentes {#components}

Vue, React, Preact e Solid incluem os mesmos quatro componentes. As suas props coincidem; React, Preact e Solid passam as restantes props para o elemento raiz.

### `<I18nT>` {#&lt;i18nt&gt;}

| Prop | Tipo | Notas |
| --- | --- | --- |
| `keypath` | `string` | obrigatório |
| `params` | `object` | valores de interpolação |
| `plural` | `number \| string` | renderiza `tc(keypath, count)` |
| `number` | `number \| string` | passa `tn(number)` como `{number}` |
| `date` | `Date \| string \| number` | passa `td(date)` como `{date}` |
| `relativeDate` | `Date \| string \| number` | passa `tdr(relativeDate)` como `{relativeDate}` |
| `tag` | `string` | elemento envolvente, por omissão `span` |
| `html` | `boolean` | renderiza a tradução como HTML; tem de ser de confiança, os parâmetros são escapados |
| `defaultValue` | `string` | substitui uma chave em falta, e é renderizado sem envolvente quando `hideIfEmpty` oculta um valor vazio |
| `hideIfEmpty` | `boolean` | não renderiza nada para uma tradução vazia |
| `customPluralRule` | `PluralFunc` | regra de plural para este elemento |

Só se aplica uma prop de formatação, verificada por esta ordem: `number`, `date`, `relativeDate`, `plural`.

#### Rich text {#rich-text}

Um `{placeholder}` pode conter um elemento. Em Vue é um slot com nome; em React, Preact e Solid a prop `components` fornece elementos, ou funções que devolvem um, por nome. Em ambos os casos prevalece sobre um parâmetro com o mesmo nome, funciona em todos os ramos e sobrevive a um locale que reordene os placeholders.

```tsx
// { "terms": "I accept the {link} of {company}" }
<I18nT keypath="terms" params={{ company: 'ACME' }} components={{ link: <a href="/terms">terms</a> }} />
```

Em Solid, passe uma função quando um placeholder se repete: um nó ocupa um único lugar. `children` substituem o texto; como função, recebem `{ translation }`, tal como o slot predefinido do Vue. `html` ignora tudo isto.

### `<I18nLink>` {#&lt;i18nlink&gt;}

| Prop | Tipo | Notas |
| --- | --- | --- |
| `to` | `string \| { path }` | localizado através do `resolvePath` do adaptador |
| `activeStyle` | objeto de estilo | fundido sobre `style` na página atual; React, Preact e Solid aplicam-no também a uma secção superior |
| `localeRoute` | função | substitui `resolvePath` para este link |

Os URLs externos (`https://`, `mailto:`, `tel:`) são renderizados como `<a target="_blank" rel="noopener noreferrer">`; um `target` ou `rel` seu prevalece. `onClick` é sempre executado. Um clique com tecla modificadora, outro botão do rato ou um `target` ficam a cargo do browser.

### `<I18nSwitcher>` {#&lt;i18nswitcher&gt;}

Um menu pendente com os locales ativos (os locales com `disabled: true` ficam ocultos) com estilos predefinidos inline. Os seus itens são links, com `lang`, `hreflang` e `dir` do locale. Por omissão, clicar num define o locale e chama o `push` do adaptador com o caminho atual localizado; uma prop `switchLocale` substitui essa ação. Com um `localeRoute` e sem router, o browser segue o link. Escape ou um clique fora fecha-o.

| Prop | Notas |
| --- | --- |
| `locales`, `currentLocale`, `getLocaleName` | substituem os valores fornecidos |
| `switchLocale(code)` | substitui a mudança integrada |
| `localeRoute` | substitui `resolvePath` |
| `customLabels` | `{ de: 'DE' }` |
| `customWrapperStyle`, `customButtonStyle`, `customDropdownStyle`, `customItemStyle`, `customLinkStyle`, `customActiveLinkStyle`, `customDisabledLinkStyle`, `customIconStyle` | substituições de estilo |

### `<I18nGroup>` {#&lt;i18ngroup&gt;}

Um `<div class="i18n-group">` que passa um `t` com prefixo aos seus filhos. **Não** adiciona prefixo às chamadas `<I18nT>` ou `t()` no seu interior; só o `t` que passa aos filhos tem prefixo.

| Prop | Notas |
| --- | --- |
| `prefix` | obrigatório, por exemplo `'profile'` |
| `groupClass` | classe adicional no wrapper |

O `t` com prefixo chega através de um scoped slot em Vue (`v-slot="{ t }"`) e de um filho render-prop em React, Preact e Solid (`{({ t }) => …}`).

## Chaves tipadas {#typed-keys}

`t()` aceita qualquer string. Para obter autocompletar das suas chaves, gere uma declaração com o [gerador de tipos](/pt/integrations/types-generator). As chaves são sugeridas, não impostas, e os parâmetros não são tipados.

## Comparação com o módulo Nuxt {#compared-with-the-nuxt-module}

Os pacotes não têm routing baseado em ficheiros, middleware de servidor nem loader de traduções: decide quando carregar o JSON (`import`, `fetch` ou `@i18n-micro/node` no servidor) e que adaptador de router usar. A deteção de locale, as meta de SEO e a geração de rotas são funcionalidades do Nuxt; o Astro tem o seu próprio middleware para deteção e `useLocaleHead` para SEO.
