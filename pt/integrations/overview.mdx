# Integrações

Os pacotes `@i18n-micro` são versões leves e específicas de framework do Nuxt I18n Micro, concebidas para integração em diversos frameworks e ambientes. Estes pacotes disponibilizam a funcionalidade central de internacionalização com um footprint mínimo, centrando-se em funcionalidades essenciais de tradução e componentes básicos.

## Visão geral

Estes pacotes de integração são **versões em miniatura** do módulo completo Nuxt I18n Micro, contendo apenas a funcionalidade essencial para internacionalização:

- **Funcionalidades essenciais de tradução** - métodos básicos de tradução, pluralização e formatação
- **Componentes essenciais** - um pequeno conjunto de componentes de UI para tarefas i18n comuns
- **Padrão de adaptador de router** - integração de encaminhamento flexível através de abstração por adaptador
- **Suporte a TypeScript** - definições de tipos completas para desenvolvimento com tipagem segura

Ao contrário do módulo Nuxt completo, estes pacotes:

- Não incluem lógica de encaminhamento específica do framework
- Requerem que implemente um adaptador de router para funcionalidades de encaminhamento
- Focam-se na funcionalidade de tradução em vez da integração com o framework
- Foram concebidos para serem leves e, sempre que possível, agnósticos ao framework

## Componentes principais

Todos os pacotes de framework incluem os seguintes componentes essenciais:

### `<I18nT>`

Um componente de tradução que renderiza texto traduzido com suporte para:

- **Interpolação de parâmetros** - substitui marcadores por valores dinâmicos
- **Pluralização** - seleção automática da forma plural com base na contagem
- **Formatação de números** - formata números de acordo com o locale
- **Formatação de datas** - formata datas e tempos relativos
- **Renderização de HTML** - renderização opcional de conteúdo HTML
- **Valores predefinidos** - texto de fallback quando a tradução está em falta

**Exemplo:**

```vue
<!-- Vue -->
<I18nT keypath="greeting" :params="{ name: 'World' }" />
```

```tsx
// React
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```tsx
// Solid
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```astro
<!-- Astro -->
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

### `<I18nLink>`

Um componente de ligação localizada que trata automaticamente dos prefixos de locale nos URLs. Funcionalidades:

- **Localização automática de caminhos** - adiciona/remove prefixos de locale com base na estratégia de encaminhamento
- **Deteção de estado ativo** - realça a rota atual
- **Suporte a ligações externas** - deteta e trata automaticamente URLs externos
- **Integração com router** - utiliza o componente de ligação do adaptador de router quando disponível
- **Estilo personalizado** - suporta estados ativos e de hover

**Exemplo:**

```vue
<!-- Vue -->
<I18nLink to="/about" active-class="active">
  About Us
</I18nLink>
```

```tsx
// React
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```tsx
// Solid
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```astro
<!-- Astro -->
<I18nLink href="/about" class="nav-link">
  About Us
</I18nLink>
```

### `<I18nSwitcher>`

Um componente seletor de idioma que oferece uma interface pendente ou de lista para mudar de locale. Funcionalidades:

- **Lista automática de locales** - gera opções a partir dos locales configurados
- **Realce do locale atual** - indica visualmente o idioma ativo
- **Rótulos personalizados** - suporta nomes de apresentação personalizados por locale
- **Integração com router** - navega automaticamente para caminhos localizados
- **Acessibilidade** - atributos ARIA adequados e navegação por teclado

**Exemplo:**

```vue
<!-- Vue -->
<I18nSwitcher />
```

```tsx
// React
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```tsx
// Solid
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```astro
<!-- Astro -->
<I18nSwitcher />
```

### `<I18nGroup>`

Um componente para agrupar traduções sob um prefixo comum, útil para organizar traduções por página ou funcionalidade. Funcionalidades:

- **Âmbito por prefixo** - antecede automaticamente o prefixo a todas as chaves de tradução dentro do grupo
- **Grupos aninhados** - suporte para grupos de tradução aninhados
- **Organização limpa** - ajuda a manter estruturas de tradução organizadas

**Exemplo:**

```vue
<!-- Vue -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

```tsx
// React
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```tsx
// Solid
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```astro
<!-- Astro -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

## Opções partilhadas de `createI18n` \{#create-i18n-options\}

Cada pacote de framework é criado da mesma forma; apenas o tipo das opções tem o nome do framework (`ReactI18nOptions`, `SolidI18nOptions`, etc.). As opções em si são idênticas:

| Propriedade      | Tipo                                                       | Obrigatório | Predefinição      | Descrição                                        |
| ---------------- | ---------------------------------------------------------- | -------- | ---------------- | ---------------------------------------------- |
| `locale`         | `string`                                                   | ✅       | -                | Código do locale atual (por exemplo, `'en'`)   |
| `fallbackLocale` | `string`                                                   | ❌       | Igual a `locale` | Locale de fallback quando a tradução está em falta |
| `messages`       | `Record<string, Translations>`                             | ❌       | `\{\}`           | Mensagens de tradução iniciais                  |
| `plural`         | `PluralFunc`                                               | ❌       | `defaultPlural`  | Função de pluralização personalizada           |
| `missingWarn`    | `boolean`                                                  | ❌       | `true`           | Mostra avisos na consola para traduções em falta |
| `missingHandler` | `(locale: string, key: string, routeName: string) => void` | ❌       | -                | Handler personalizado para traduções em falta   |

Qualquer coisa para além destas é específica do framework e está documentada na página do respetivo pacote.

## Abstração do adaptador de router

Todos os pacotes de framework utilizam um **padrão de adaptador de router** para desacoplar a funcionalidade i18n de implementações específicas de router. Este design permite:

- **Flexibilidade** - use qualquer biblioteca de router ou nenhum de todo
- **Independência do framework** - mantenha a lógica de encaminhamento na sua aplicação, e não no pacote i18n
- **Núcleo leve** - o pacote i18n mantém-se pequeno e focado

### Implementar um adaptador de router

Para utilizar funcionalidades de encaminhamento, precisa de implementar a interface `I18nRoutingStrategy`:

```typescript
interface I18nRoutingStrategy {
  getCurrentPath: () => string
  linkComponent?: Component
  push: (target: { path: string }) => void
  replace: (target: { path: string }) => void
  resolvePath?: (to: string | { path?: string }, locale: string) => string | { path?: string }
  getRoute?: () => { fullPath: string; query: Record<string, unknown> }
}
```

A documentação de cada pacote inclui exemplos completos de implementação de adaptadores para routers populares:

- **Vue**: exemplo de adaptador para Vue Router
- **React**: exemplo de adaptador para React Router
- **Solid**: exemplo de adaptador para Solid Router
- **Astro**: exemplo de adaptador para encaminhamento baseado em ficheiros

## Funcionalidades principais

Todos os pacotes partilham estas funcionalidades principais:

### Métodos de tradução

- `t()` - tradução básica com interpolação de parâmetros
- `ts()` - tradução que devolve sempre uma string
- `tc()` - tradução com pluralização
- `tn()` - formatação de números
- `td()` - formatação de datas
- `tdr()` - formatação de tempo relativo
- `has()` - verifica se uma chave de tradução existe

### Gestão de locale

- **Troca de locale** - muda o locale atual programaticamente
- **Locale de fallback** - fallback automático quando a tradução está em falta
- **Traduções específicas da rota** - organização de traduções ao nível da página
- **Cache de traduções** - cache inteligente para desempenho

### Suporte a TypeScript

Todos os pacotes fornecem:

- Definições TypeScript completas
- Chaves de tradução com tipagem segura (com o gerador de tipos)
- Suporte a IntelliSense nos IDEs
- Verificação de erros em tempo de compilação
