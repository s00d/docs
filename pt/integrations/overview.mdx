# Integrações

Os pacotes `@i18n-micro` são versões leves, específicas para cada framework, do Nuxt I18n Micro, concebidas para integração em várias frameworks e ambientes. Estes pacotes fornecem a funcionalidade nuclear de internacionalização com uma pegada mínima, centrando-se em funcionalidades essenciais de tradução e componentes básicos.

## Visão geral

Estes pacotes de integração são **versões em miniatura** do módulo completo Nuxt I18n Micro, contendo apenas a funcionalidade essencial necessária para a internacionalização:

- **Funcionalidades nucleares de tradução** - métodos de tradução básicos, pluralização e formatação.
- **Componentes essenciais** - um pequeno conjunto de componentes de UI para tarefas i18n comuns.
- **Padrão de router adapter** - integração flexível de encaminhamento através de uma abstração por adapter.
- **Suporte TypeScript** - definições de tipo completas para desenvolvimento com segurança de tipos.

Ao contrário do módulo Nuxt completo, estes pacotes:

- Não incluem lógica de encaminhamento específica da framework.
- Exigem que implemente um router adapter para funcionalidades de encaminhamento.
- Centram-se na funcionalidade de tradução, e não na integração com a framework.
- São concebidos para serem leves e, sempre que possível, agnósticos em relação à framework.

## Componentes nucleares

Todos os pacotes de framework incluem os seguintes componentes essenciais:

### `<I18nT>`

Um componente de tradução que renderiza texto traduzido com suporte para:

- **Interpolação de parâmetros** - substituir marcadores por valores dinâmicos.
- **Pluralização** - seleção automática da forma plural com base na contagem.
- **Formatação de números** - formatar números de acordo com o locale.
- **Formatação de datas** - formatar datas e tempos relativos.
- **Renderização HTML** - renderização opcional de conteúdo HTML.
- **Valores por omissão** - texto de fallback quando falta a tradução.

**Exemplo:**

```vue
<!-- Vue -->
<I18nT keypath="greeting" :params="{ name: 'World' }" />
```

```tsx
// React
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```tsx
// Solid
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```astro
<!-- Astro -->
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

### `<I18nLink>`

Um componente de ligação localizada que trata automaticamente dos prefixos de locale nos URLs. Funcionalidades:

- **Localização automática de caminhos** - adiciona/remove prefixos de locale com base na estratégia de encaminhamento.
- **Deteção do estado ativo** - destaca a rota atual.
- **Suporte a ligações externas** - deteta e trata automaticamente URLs externos.
- **Integração com router** - utiliza o componente de ligação do router adapter quando disponível.
- **Estilo personalizado** - suporta estados ativos e de hover.

**Exemplo:**

```vue
<!-- Vue -->
<I18nLink to="/about" active-class="active">
  About Us
</I18nLink>
```

```tsx
// React
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```tsx
// Solid
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```astro
<!-- Astro -->
<I18nLink href="/about" class="nav-link">
  About Us
</I18nLink>
```

### `<I18nSwitcher>`

Um componente de seleção de idioma que disponibiliza uma interface em lista pendente ou de lista para alternar locales. Funcionalidades:

- **Lista automática de locales** - gera opções a partir dos locales configurados.
- **Destaque do locale atual** - indica visualmente o idioma ativo.
- **Etiquetas personalizadas** - suporte a nomes de apresentação personalizados por locale.
- **Integração com router** - navega automaticamente para caminhos localizados.
- **Acessibilidade** - atributos ARIA adequados e navegação por teclado.

**Exemplo:**

```vue
<!-- Vue -->
<I18nSwitcher />
```

```tsx
// React
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```tsx
// Solid
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```astro
<!-- Astro -->
<I18nSwitcher />
```

### `<I18nGroup>`

Um componente para agrupar traduções sob um prefixo comum, útil para organizar traduções por página ou funcionalidade. Funcionalidades:

- **Definição de prefixo** - antepõe automaticamente o prefixo a todas as chaves de tradução dentro do grupo.
- **Grupos aninhados** - suporte a grupos de traduções aninhados.
- **Organização limpa** - ajuda a manter estruturas de tradução organizadas.

**Exemplo:**

```vue
<!-- Vue -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

```tsx
// React
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```tsx
// Solid
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```astro
<!-- Astro -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

## Opções partilhadas de `createI18n` \{#create-i18n-options\}

Todos os pacotes de framework são criados da mesma forma — apenas o tipo de opções tem o nome da
framework (`ReactI18nOptions`, `SolidI18nOptions`, etc.). As próprias opções
são idênticas:

| Propriedade         | Tipo                                                       | Obrigatório | Predefinição          | Descrição                                    |
| ---------------- | ---------------------------------------------------------- | -------- | ---------------- | ---------------------------------------------- |
| `locale`         | `string`                                                   | ✅       | -                | Código do locale atual (p. ex. `'en'`)             |
| `fallbackLocale` | `string`                                                   | ❌       | Igual a `locale` | Locale de fallback quando falta a tradução    |
| `messages`       | `Record<string, Translations>`                             | ❌       | `\{\}`             | Mensagens de tradução iniciais                   |
| `plural`         | `PluralFunc`                                               | ❌       | `defaultPlural`  | Função de pluralização personalizada                  |
| `missingWarn`    | `boolean`                                                  | ❌       | `true`           | Mostrar avisos na consola para traduções em falta |
| `missingHandler` | `(locale: string, key: string, routeName: string) => void` | ❌       | -                | Handler personalizado para traduções em falta        |

Tudo o que vai além disto é específico de cada framework e está documentado na página desse pacote.

## Abstração de router adapter

Todos os pacotes de framework utilizam um **padrão de router adapter** para desacoplar a funcionalidade i18n de implementações específicas de router. Este desenho permite:

- **Flexibilidade** - utilizar qualquer biblioteca de router ou nenhum router.
- **Independência da framework** - manter a lógica de encaminhamento na sua aplicação, e não no pacote i18n.
- **Núcleo leve** - o pacote i18n mantém-se pequeno e focado.

### Implementar um router adapter

Para utilizar funcionalidades de encaminhamento, tem de implementar a interface `I18nRoutingStrategy`:

```typescript
interface I18nRoutingStrategy {
  getCurrentPath: () => string
  linkComponent?: Component
  push: (target: { path: string }) => void
  replace: (target: { path: string }) => void
  resolvePath?: (to: string | { path?: string }, locale: string) => string | { path?: string }
  getRoute?: () => { fullPath: string; query: Record<string, unknown> }
}
```

A documentação de cada pacote inclui exemplos completos de implementação de adapters para routers populares:

- **Vue**: exemplo de adapter para Vue Router.
- **React**: exemplo de adapter para React Router.
- **Solid**: exemplo de adapter para Solid Router.
- **Astro**: exemplo de adapter para encaminhamento baseado em ficheiros.

## Funcionalidades nucleares

Todos os pacotes partilham estas funcionalidades nucleares:

### Métodos de tradução

- `t()` - Tradução básica com interpolação de parâmetros.
- `ts()` - Tradução que devolve sempre uma string.
- `tc()` - Tradução com suporte a pluralização.
- `tn()` - Formatação de números.
- `td()` - Formatação de datas.
- `tdr()` - Formatação de tempos relativos.
- `has()` - Verificar se existe uma chave de tradução.

### Gestão de locales

- **Alternância de locale** - alterar programaticamente o locale atual.
- **Locale de fallback** - fallback automático quando falta a tradução.
- **Traduções específicas de rota** - organização das traduções ao nível da página.
- **Cache de traduções** - cache inteligente para desempenho.

### Suporte TypeScript

Todos os pacotes fornecem:

- Definições TypeScript completas.
- Chaves de tradução com segurança de tipos (com o gerador de tipos).
- Suporte IntelliSense em IDEs.
- Verificação de erros em tempo de compilação.

## Começar

1. **Escolha o seu pacote** - Selecione o pacote para a sua framework.

3. **Leia a documentação** - Cada pacote tem instruções detalhadas de configuração.
4. **Implemente o router adapter** - Se precisar de funcionalidades de encaminhamento, implemente o adapter.
5. **Comece a traduzir** - Utilize componentes e métodos para adicionar traduções.
