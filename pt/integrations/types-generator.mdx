---
title: "Gerador de tipos"
description: "Gere autocompletar TypeScript para as chaves de tradução a partir dos seus ficheiros JSON, em Nuxt ou em qualquer projeto Vite."
---

`@i18n-micro/types-generator` lê todos os ficheiros JSON da sua pasta de traduções e escreve uma declaração que lista todas as chaves. Adicione-o quando quiser que o seu editor sugira chaves em `t()`, `$t()` e `<I18nT keypath>`. Funciona como módulo Nuxt e como plugin Vite ou Rollup, e volta a gerar quando um ficheiro muda.

## Instalar {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/types-generator
```

```bash npm
npm install -D @i18n-micro/types-generator
```

```bash yarn
yarn add -D @i18n-micro/types-generator
```

</CodeGroup>

Dependência peer: `@nuxt/kit` `^3.18.0 || ^4.0.0`. Apenas a entrada `/nuxt` a importa; num projeto só com Vite, o aviso de peer pode ser ignorado.

## Nuxt {#nuxt}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro', '@i18n-micro/types-generator/nuxt'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

O módulo escreve `.nuxt/types/i18n-micro.d.ts` e o Nuxt adiciona-o ao contexto de tipos; não há nada a incluir manualmente. Lê `i18nTypes.translationDir` ou, caso contrário, os locais onde o `nuxt-i18n-micro` lê as traduções: `translationDir` (de `i18n` ou das opções inline do módulo, por omissão `'locales'`) em cada camada, e `additionalTranslationDirs`. Editar um ficheiro JSON nessa pasta volta a gerar os tipos em `nuxi dev`. `i18nTypes.outputFile` é ignorado no Nuxt (um aviso indica-o).

## Vite {#vite}

`I18nTypesPlugin` é um plugin Vite, que o Rollup também aceita. Para outro bundler, chame `generateTypes` num script.

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { I18nTypesPlugin } from '@i18n-micro/types-generator'

export default defineConfig({
  plugins: [
    vue(),
    I18nTypesPlugin({
      srcDir: process.cwd(),
      translationDir: 'src/locales',
      outputFile: 'src/i18n-micro.d.ts',
    }),
  ],
})
```

| Opção | Obrigatória | Notas |
| --- | --- | --- |
| `srcDir` | sim | Diretório base; `translationDir` é resolvido relativamente a ele. |
| `translationDir` | sim | Pasta com os ficheiros JSON (incluindo subpastas como `pages/`), ou um array de pastas. |
| `outputFile` | não | Onde escrever a declaração; por omissão `<srcDir>/i18n-micro.d.ts`. |

O plugin gera uma vez no início do build e, no servidor de desenvolvimento, volta a gerar 300 ms após uma alteração na pasta. Certifique-se de que o `include` do seu `tsconfig.json` abrange o ficheiro de saída.

## Usar as chaves {#use-the-keys}

O ficheiro gerado aumenta `DefineLocaleMessage` em `@i18n-micro/types`, o que transforma `TranslationKey` nas suas chaves:

```ts
declare module '@i18n-micro/types' {
  export interface DefineLocaleMessage {
    nav: object
    'nav.home': string
    'profile.title': string
  }
}
```

As chaves são aquelas a que `t()` responde, incluindo objetos, de todos os locales e de todos os ficheiros de página, com o tipo do respetivo valor JSON. `TranslationKey` é a união dessas chaves com qualquer string, pelo que obtém autocompletar e não erros: uma chave mal escrita ou dinâmica continua a compilar. Os parâmetros e os valores de retorno não são tipados.

Para chaves dinâmicas sob um prefixo conhecido, `ScopedKey<'prefix'>` restringe às chaves correspondentes:

```ts
import type { ScopedKey } from '@i18n-micro/types'

const statusText = (status: string) => t(`status.${status}` as ScopedKey<'status'>)
```

`TranslationKey` e `ScopedKey` vêm de `@i18n-micro/types` (React, Preact e Solid reexportam `TranslationKey`; Vue não).

## API {#api}

| Export | Entrada | Notas |
| --- | --- | --- |
| `I18nTypesPlugin(options)` | `@i18n-micro/types-generator` | plugin Vite e Rollup |
| `generateTypes(options)` | `@i18n-micro/types-generator` | escreve o ficheiro e devolve o seu caminho |
| `getTypesString(options)` | `@i18n-micro/types-generator` | devolve a declaração sem a escrever |
| `formatKeyProperty(key)` | `@i18n-micro/types-generator` | helper |
| Módulo Nuxt (`configKey: 'i18nTypes'`) | `@i18n-micro/types-generator/nuxt` | opção `translationDir` |

Assinaturas completas: [referência do pacote](/pt/api/packages/types-generator).
