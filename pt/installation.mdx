## Requisitos

- **Node.js**: 18 ou superior.
- **Nuxt**: 3.x ou 4.x.

O módulo suporta tanto a organização de projeto do Nuxt 3 (`pages/**/*.vue`) como a do Nuxt 4 (`app/pages/**/*.vue`). Por convenção, as traduções ficam na raiz do projeto (`locales/`), mesmo quando é utilizado o diretório `app/` do Nuxt 4.

## Instalar o módulo Nuxt

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Registe-o em `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Consulte o [Início rápido](/quickstart) para um percurso completo ou a [Referência de configuração](/guides/configuration) para todas as opções.

## Organização do projeto

Por predefinição, o módulo espera:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Os ficheiros ao nível da raiz são fundidos em cada ficheiro específico de página no momento do build. Os ficheiros específicos de página são criados automaticamente quando não existem, durante o `nuxt dev`.

</Info>

## Organização do Nuxt 4

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Para colocar as traduções em `app/`, defina `translationDir: 'app/locales'`.

## Pacotes do ecossistema

| Pacote | Finalidade |
| --- | --- |
| [`@i18n-micro/vue`](/integrations/vue) | Integração com Vue 3 (autónoma, sem Nuxt). |
| [`@i18n-micro/react`](/integrations/react) | Integração com React. |
| [`@i18n-micro/preact`](/integrations/preact) | Integração com Preact. |

| [`@i18n-micro/astro`](/integrations/astro) | Integração com Astro. |
| [`@i18n-micro/node`](/integrations/nodejs) | Loader server-side para Node.js. |

| [`@i18n-micro/devtools-ui`](/integrations/devtools-ui) | Painel de DevTools agnóstico em relação à framework. |

Os pacotes internos partilhados são obtidos de forma transitiva.

## TypeScript

O módulo gera tipos ambientais para `useI18n`, `$t` e helpers relacionados com base nos ficheiros do seu locale predefinido. Isto está ativado por predefinição (`types: true`).

Para uma tipagem mais robusta das chaves de tradução, consulte [`@i18n-micro/types-generator`](/integrations/types-generator).
