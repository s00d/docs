## Requisitos

- **Node.js**: 18 ou superior.
- **Nuxt**: 3.x ou 4.x.

O módulo suporta tanto o layout de projeto do Nuxt 3 (`pages/**/*.vue`) como o layout do Nuxt 4 (`app/pages/**/*.vue`). Por convenção, as traduções ficam na raiz do projeto (`locales/`), mesmo quando utiliza o diretório `app/` do Nuxt 4.

## Instale o módulo Nuxt

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Registe-o em `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Consulte o [Guia rápido](/quickstart) para um passo a passo completo ou a [Referência de configuração](/guides/configuration) para todas as opções.

## Estrutura do projeto

Por predefinição, o módulo espera:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Os ficheiros de nível raiz são fundidos em cada ficheiro específico de página em tempo de build. Os ficheiros específicos de página são criados automaticamente quando estão em falta durante o `nuxt dev`.

## Layout do Nuxt 4

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Para colocar as traduções em `app/`, defina `translationDir: 'app/locales'`.

## Pacotes do ecossistema

| Pacote | Propósito |
| --- | --- |
| [`@i18n-micro/vue`](/integrations/vue) | Integração Vue 3 (autónoma, sem Nuxt). |
| [`@i18n-micro/react`](/integrations/react) | Integração React. |
| [`@i18n-micro/preact`](/integrations/preact) | Integração Preact. |
| [`@i18n-micro/solid`](/integrations/solid) | Integração SolidJS. |
| [`@i18n-micro/astro`](/integrations/astro) | Integração Astro. |
| [`@i18n-micro/node`](/integrations/nodejs) | Carregador do lado do servidor para Node.js. |
| [`@i18n-micro/types-generator`](/integrations/types-generator) | Gera tipos TypeScript a partir dos ficheiros de tradução. |
| [`@i18n-micro/devtools-ui`](/integrations/devtools-ui) | Painel de DevTools independente de framework. |

Os pacotes internos partilhados são incluídos transitivamente.

## TypeScript

O módulo gera tipos ambiente para `useI18n`, `$t` e helpers relacionados com base nos ficheiros do seu locale predefinido. Isto está ativado por predefinição (`types: true`).

Para uma tipagem mais forte das chaves de tradução, consulte [`@i18n-micro/types-generator`](/integrations/types-generator).
