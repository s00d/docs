# 🛠️ Métodos

Esta página documenta todos os métodos disponíveis fornecidos pelo nuxt-i18n-micro. Os métodos estão organizados por funcionalidade para navegação mais fácil.

## 📊 Visão geral da API

Cada helper que o plugin injeta é lido da interface `PluginsInjections`, pelo que esta lista não pode divergir do que está realmente disponível.

### `$getI18nConfig`

{/* generated:method:$getI18nConfig — do not edit; run `pnpm run docs:generate` */}

```ts
() => ModuleOptionsExtend
```

A configuração do módulo resolvida, tal como o runtime a vê.

{/* /generated:method:$getI18nConfig */}

## 🔍 Métodos de tradução

Métodos essenciais para obter e gerir traduções.

### `$t`

{/* generated:method:$t — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Traduz uma chave, interpolando `params`. Devolve `defaultValue` quando a chave está em falta, ou a própria chave quando não é fornecido nenhum valor predefinido.

{/* /generated:method:$t */}

```typescript
const welcomeMessage = $t('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

<Warning>
`$t` devolve `CleanTranslation` que é `string | number | boolean | Translations | PluralTranslations | null`. Se a chave apontar para um **objeto aninhado** no seu JSON (por exemplo, `$t('header')` quando o JSON contém `\{ "header": \{ "title": "Hi" \} \}`), o valor devolvido será esse **objeto**, não uma string. Utilizá-lo diretamente num template Vue (<code v-pre>\{\{ $t('header') \}\}</code>) irá renderizar como `[object Object]`.

**Como evitar:**

- Utilize uma chave mais específica: `$t('header.title')` → `"Hi"`
- Utilize `$ts()`, que devolve sempre uma string (chama `.toString()` para não-strings)
- Utilize `$t` com uma chave aninhada para aceder intencionalmente a subobjetos para uso programático
</Warning>

### `$ts`

{/* generated:method:$ts — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string) => string
```

Como `$t`, mas devolve sempre uma string: um valor de objeto ou array é convertido em texto em vez de ser devolvido como está.

{/* /generated:method:$ts */}

```typescript
const welcomeMessage = $ts('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

### `$_t` e `$_ts`

{/* generated:method:$_t — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Vincula `$t` a uma rota específica, para traduzir fora da página atual. Por exemplo, um layout que renderiza uma ligação para outra rota.

{/* /generated:method:$_t */}

{/* generated:method:$_ts — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => string
```

Vincula `$ts` a uma rota específica. Ver `$_t`.

{/* /generated:method:$_ts */}

Variantes de `$t` e `$ts` vinculadas a uma rota. Recebem primeiro uma **rota** e devolvem uma função de tradução fixada ao locale e ao contexto de página dessa rota.

- **Acesso**: `useNuxtApp()` (também reexportadas por `useI18n()` como `$_t` / `$_ts`)

Utilize-as quando a rota ativa durante SSR ou transições difere de `router.currentRoute`. Por exemplo, dentro de `<i18n-t>`, `<i18n-group>`, ou quando renderiza conteúdo para um objeto `route` específico.

```typescript
import { useRoute, useNuxtApp } from '#imports'

const route = useRoute()
const { $_t, $_ts } = useNuxtApp()

const $t = $_t(route)
const title = $t('page.title')

// String-safe variant
const label = $_ts(route)('page.label')
```


### `$tc`

{/* generated:method:$tc — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params: number | Params, defaultValue?: string) => string
```

Traduz com pluralização. `params` pode ser a própria contagem, ou um objeto que contém `count`.

{/* /generated:method:$tc */}

**Formato da tradução**: formas separadas por `|`. Coloque marcadores em **cada** forma:

```json
{
  "apples": "no apples | one apple | {count} apples",
  "cart": "no items for {name} | one item for {name} | {count} items for {name}"
}
```

```typescript
$tc('apples', 0) // "no apples"
$tc('apples', 1) // "one apple"
$tc('apples', 10) // "10 apples"

// count + other params (second argument must be an object)
$tc('cart', { count: 10, name: 'Alice' }) // "10 items for Alice"
```


**Alternativa por componente** — `<i18n-t keypath="cart" :plural="count" :params="\{ name \}" />` (funde `count` com `params` internamente).


### `$mergeTranslations`

{/* generated:method:$mergeTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
(newTranslations: Translations) => void
```

Funde traduções no locale ativo em runtime, sobrepondo-se ao que foi carregado.

{/* /generated:method:$mergeTranslations */}

```typescript
$mergeTranslations({
  welcome: 'Bienvenue, {username}!',
})
// Output: Updates the translation cache with the new French translation
```

### `$resolveTranslations`

{/* generated:method:$resolveTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
() => Translations
```

Todas as traduções atualmente em memória para o locale e a rota ativos, em forma de árvore.
Vista só de leitura daquilo que `$t()` consegue resolver neste momento.

{/* /generated:method:$resolveTranslations */}

```typescript
const tree = $resolveTranslations()
// { aaa: { bbb: 'ccc' }, ddd: 1111 } — the same dictionary $t() reads from
```

Utilize isto quando precisar do dicionário completo em memória (DevTools, testes, editores em runtime). Trate o valor devolvido como só de leitura; altere os valores através de `$setTranslation` ou funda patches com `$mergeTranslations`.

### `$setTranslation`

{/* generated:method:$setTranslation — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, value: unknown) => void
```

Substitui o valor em `key` no dicionário ativo. Trata-se de uma substituição, não de uma fusão. Utilize `$mergeTranslations` quando os irmãos existentes devem ser preservados.

{/* /generated:method:$setTranslation */}

```typescript
$setTranslation('aaa', { fff: 'ggg' }) // replaces the whole `aaa` subtree
$setTranslation('aaa', 'text')          // replaces `aaa` with a string
$setTranslation('ddd', 1111)            // scalar at the top level
$setTranslation('aaa.bbb', 'nested')    // dotted path
```

Isto é uma **substituição**, não uma fusão. Os irmãos existentes sob a mesma chave são removidos. Para aplicar um patch sem perder irmãos, utilize `$mergeTranslations`.

### `$setMissingHandler`

{/* generated:method:$setMissingHandler — do not edit; run `pnpm run docs:generate` */}

```ts
(handler: MissingHandler | null) => void
```

Instala um callback invocado para cada chave não resolvida. Passe `null` para o remover.

{/* /generated:method:$setMissingHandler */}

**Definição do tipo**:

```typescript
type MissingHandler = (locale: string, key: string, routeName: string, instance?: unknown, type?: string) => void
```

```typescript
// Set a custom handler
$setMissingHandler((locale, key, routeName) => {
  console.error(`Missing translation: ${key} in ${locale} for route ${routeName}`)
  // Send to Sentry or other error tracking service
  // Sentry.captureMessage(`Missing translation: ${key}`)
})

// Remove the handler
$setMissingHandler(null)
```

**Casos de uso**:

- Registar traduções em falta em serviços de monitorização de erros (Sentry, LogRocket, etc.)
- Recolher analytics sobre traduções em falta
- Tratamento de erros personalizado para chaves de tradução em falta

## 🔢 Formatação de números e datas

Métodos para formatar números e datas de acordo com as convenções do locale.

### `$tn`

{/* generated:method:$tn — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Formata um número com `Intl.NumberFormat` no locale ativo. Uma chave seleciona um formato nomeado a partir da configuração.

{/* /generated:method:$tn */}

```typescript
// Inline options
const formattedNumber = $tn(1234567.89, { style: 'currency', currency: 'USD' })
// "$1,234,567.89"

// Named format (from nuxt.config i18n.numberFormats)
const price = $tn(1000, 'currency')
const priceDe = $tn(1000, 'currency', 'de')
const compact = $tn(1000, 'currency', { notation: 'compact' })
```

Chaves de formato nomeado desconhecidas caem para as opções predefinidas de `Intl.NumberFormat`. Em desenvolvimento (cliente), é emitido `console.warn` quando `missingWarn` está ativado (predefinição).

**Exemplo de configuração**:

```ts
export default defineNuxtConfig({
  i18n: {
    numberFormats: {
      en: {
        currency: { style: 'currency', currency: 'USD' },
        decimal: { style: 'decimal', minimumFractionDigits: 2, maximumFractionDigits: 2 },
      },
      de: {
        currency: { style: 'currency', currency: 'EUR' },
      },
    },
  },
})
```

**Casos de uso**:

- Formatar números como moeda, percentagens ou decimais no formato apropriado ao locale
- Reutilizar formatos nomeados por toda a aplicação (paridade com migração de Vue I18n)

### `$td`

{/* generated:method:$td — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Formata uma data com `Intl.DateTimeFormat` no locale ativo. Uma chave seleciona um formato nomeado a partir da configuração.

{/* /generated:method:$td */}

```typescript
const formattedDate = $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' })
// "Friday, September 1, 2023"

const short = $td(new Date(), 'short')
const longDe = $td(new Date(), 'long', 'de')
```

Chaves de formato nomeado desconhecidas caem para as opções predefinidas de `Intl.DateTimeFormat`. Em desenvolvimento (cliente), é emitido `console.warn` quando `missingWarn` está ativado (predefinição).

**Exemplo de configuração**:

```ts
export default defineNuxtConfig({
  i18n: {
    datetimeFormats: {
      en: {
        short: { year: 'numeric', month: 'short', day: 'numeric' },
        long: { year: 'numeric', month: 'long', day: 'numeric', weekday: 'long' },
      },
    },
  },
})
```

**Casos de uso**:

- Apresentar datas num formato alinhado com o locale do utilizador
- Partilhar predefinições curtas/longas/data-hora por toda a aplicação

### `$tdr`

{/* generated:method:$tdr — do not edit; run `pnpm run docs:generate` */}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

Formata uma data como tempo relativo ("há 3 dias") com `Intl.RelativeTimeFormat`.

{/* /generated:method:$tdr */}

```typescript
const relativeDate = $tdr(new Date(Date.now() - 1000 * 60 * 5))
// Output: "5 minutes ago" in the 'en-US' locale
```

## 🔄 Troca de rota e locale

Métodos para trocar entre locales e rotas.

### `$switchLocale`

{/* generated:method:$switchLocale — do not edit; run `pnpm run docs:generate` */}

```ts
(locale: string) => void
```

Navega para a página atual noutro locale.

{/* /generated:method:$switchLocale */}

```typescript
$switchLocale('fr')
// Prefix strategies: navigates to the French version of the route
// no_prefix: updates locale and translations without changing the URL path
```

<Tip>
Consulte [FAQ — mudar de locale sem alterar o URL](/guides/faq#-switch-locale-without-changing-the-url). Para estratégias com prefixo, utilize `$switchLocalePath()` quando só precisa do destino de uma ligação.
</Tip>

### `$switchLocaleRoute`

{/* generated:method:$switchLocaleRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(locale: string) => RouteLocationRaw
```

O objeto de rota para a página atual noutro locale, sem navegar.

{/* /generated:method:$switchLocaleRoute */}

```typescript
// on /en/news
const routeFr = $switchLocaleRoute('fr')
// Output: A route object with the new locale applied, e.g., { name: 'localized-news', params: { locale: 'fr' } }
```

### `$switchLocalePath`

{/* generated:method:$switchLocalePath — do not edit; run `pnpm run docs:generate` */}

```ts
(locale: string) => string
```

O caminho da página atual noutro locale, sem navegar.

{/* /generated:method:$switchLocalePath */}

```typescript
// on /en/news
const routeFr = $switchLocalePath('fr')
window.location.href = routeFr
// Output: url with new locale applied, e.g., '/fr/nouvelles'
```

### `$switchRoute`

{/* generated:method:$switchRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, toLocale?: string) => void
```

Navega para outra rota, mantendo o locale ativo ou mudando para `toLocale`.

{/* /generated:method:$switchRoute */}

**Exemplos**:

<CodeGroup>
```typescript String Path
// Switches to the given path with the current locale
$switchRoute('/about')
```

```typescript String Path with Locale
// Switches to the given path with French locale
$switchRoute('/about', 'fr')
```

```typescript Named Route
// Switches to a named route with the current locale
$switchRoute({ name: 'page' })
```

```typescript Named Route with Locale
// Switches to a named route and changes the locale to Spanish
$switchRoute({ name: 'page' }, 'es')
```
</CodeGroup>

## 🚦 Configuração de rota

Métodos para configurar o comportamento das rotas e o controlo de acesso.

### `$defineI18nRoute`

{/* generated:method:$defineI18nRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Regista configuração de locale por página e traduções a partir de dentro de um componente.
Funde-se no locale ativo e reaplica-se quando o locale muda.

{/* /generated:method:$defineI18nRoute */}

> [!IMPORTANT]
> `$defineI18nRoute` é fornecido pelo **plugin define** e está disponível apenas em `useNuxtApp()`. **Não** faz parte do objeto devolvido por `useI18n()`.
> Faça sempre destructuring a partir de `useNuxtApp()` dentro de `script setup`. Chamar `$defineI18nRoute(...)` como um global sem destructuring lança `"$defineI18nRoute is not defined"` durante SSR/prerender.

**Parâmetros**:

- **locales**: `string[] | Record<string, Record<string, string>>` — Locales disponíveis para a rota
- **localeRoutes**: `Record<string, string>` — Opcional. Rotas personalizadas para locales específicos
- **disableMeta**: `boolean | string[]` — Opcional. Desativa meta tags i18n para todos ou para locales específicos

**Exemplo básico**:

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
```

### `$setI18nRouteParams`

{/* generated:method:$setI18nRouteParams — do not edit; run `pnpm run docs:generate` */}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Define parâmetros por locale para a rota atual, permitindo que um segmento dinâmico varie por idioma. Chame-a durante o SSR, antes de o head ser renderizado.

{/* /generated:method:$setI18nRouteParams */}

```typescript
// in pages/news/[id].vue
// for en/news/1-first-article
const { $switchLocaleRoute, $setI18nRouteParams, $defineI18nRoute } = useNuxtApp()
$defineI18nRoute({
  localeRoutes: {
    en: '/news/:id()',
    fr: '/nouvelles/:id()',
    de: '/Nachricht/:id()',
  },
})
const { data: news } = await useAsyncData(`news-${params.id}`, async () => {
  let response = await $fetch("/api/getNews", {
    query: {
      id: params.id,
    },
  });
  if (response?.localeSlugs) {
    response.localeSlugs = {
      en: {
        id: '1-first-article'
      }
      fr: {
        id: '1-premier-article'
      }
      de: {
        id: '1-erster-Artikel'
      }
    }
    $setI18nRouteParams(response?.localeSlugs);
  }
  return response;
});
$switchLocalePath('fr') // === 'fr/nouvelles/1-premier-article'
$switchLocalePath('de') // === 'de/Nachricht/1-erster-Artikel'
```

## 🔧 Métodos de cache e utilitários

### `$has`

{/* generated:method:$has — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string) => boolean
```

Indica se uma chave é resolvida no locale ativo. Utilize-a para bifurcar em texto opcional em vez de renderizar uma chave em bruto.

{/* /generated:method:$has */}

Durante transições entre páginas no mesmo locale, a v3 funde automaticamente as traduções da página que sai neste dicionário até a transição terminar. Por isso, chaves da página anterior podem continuar a devolver `true` por breves instantes. Não existe uma opção `previousPageFallback`; este comportamento está incorporado. Consulte [FAQ — transições de página](/guides/faq#-why-do-translations-break-during-page-transitions-especially-with-defineasynccomponent).

```typescript
if ($has('welcome')) {
  console.log($t('welcome'))
} else {
  console.log('Key not found')
}
```

## 🧭 Composable `useI18nLocale`

O composable centralizado para a gestão do estado de locale. Utilize isto em vez de manipular diretamente `useState('i18n-locale')` ou `useCookie('user-locale')`.

```typescript
const {
  setLocale, // (locale: string) => void — updates state + cookie
  getLocale, // () => string | null — from state or cookie
  getPreferredLocale, // () => string | null — validated against locales list
  getEffectiveLocale, // (route, getLocaleFromRoute) => string
  resolveInitialLocale, // (options) => string
  isValidLocale, // (locale) => boolean
  locale, // Ref<string | null> — reactive state
  localeCookie, // CookieRef — reactive cookie
  syncLocale, // (locale) => void — sync to cookie only
  validLocales, // string[] — list of valid locale codes
} = useI18nLocale()
```

### Métodos principais

| Método                  | Descrição                                                   |
| ----------------------- | ----------------------------------------------------------- |
| `setLocale(locale)`     | Define o locale tanto em `useState` como no cookie de forma atómica |
| `getLocale()`           | Devolve o locale atual a partir do estado ou do cookie      |
| `getPreferredLocale()`  | Devolve o locale validado contra a lista `locales`, ou `null` |
| `isValidLocale(locale)` | Verifica se um código de locale existe na lista `locales` configurada |

### Utilização em plugins personalizados

```typescript
// plugins/i18n-loader.server.ts
export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,
  setup() {

    // Detect locale from headers, domain, etc.

  },
})
```
