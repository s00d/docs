O módulo injeta os seus helpers de runtime na aplicação Nuxt: `$t`, `$tc`, `$localePath`, `$switchLocale` e os restantes. Use esta página para consultar a assinatura e o comportamento de um helper. As assinaturas e descrições vêm das interfaces `PluginsInjections` e `NuxtAppOnlyInjections` em `src/runtime/plugins/01.plugin.ts`.

## Acesso {#access}

| Onde | Como |
| --- | --- |
| Template | `{{ $t('title') }}` — todos os helpers, com o `$` |
| `<script setup>` | `const { t, localePath } = useI18n()` — todos os helpers de `PluginsInjections`, com e sem o `$` |
| Plugin, middleware, `<script setup>` | `const { $t, $defineI18nRoute } = useNuxtApp()` — tudo, apenas com `$` |

`$defineI18nRoute` só está tipado em `useNuxtApp()`. Consulte [`useI18n`](/pt/composables/useI18n).

```vue
<script setup lang="ts">
const { t, localePath } = useI18n()
</script>

<template>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
</template>
```

## Locale {#locale}

### `$getLocale` {#$getlocale}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric) => string
```

Código do locale ativo. Passe uma rota para ler o locale a que essa rota pertence.

```ts
$getLocale() // 'de' on /de/about
```

### `$getLocaleName` {#$getlocalename}

```ts
() => string | null
```

O `displayName` do locale ativo a partir da configuração, ou `null` quando não tem.

### `$getLocales` {#$getlocales}

```ts
() => Locale[]
```

Todos os locales configurados, com os respetivos metadados.

As propriedades personalizadas de um objeto de locale são devolvidas tal como escritas; tipifique-as com [module augmentation](/pt/api/module-options#locales) de `Locale`.

### `$defaultLocale` {#$defaultlocale}

```ts
() => string | undefined
```

Código do locale por omissão configurado.

### `$getI18nConfig` {#$geti18nconfig}

```ts
() => ResolvedI18nConfig
```

A configuração resolvida do módulo, tal como o runtime a vê.

O valor inclui as [substituições em runtime](/pt/guide/runtime-overrides) (`defaultLocale`, `fallbackLocale`, locales desativados).

```ts
const { strategy, localeCookie } = useNuxtApp().$getI18nConfig()
```

## Tradução {#translation}

### `$t` {#$t}

```ts
TranslationFn<CleanTranslation>
```

Traduz uma chave, interpolando `params` nela. Devolve `defaultValue` quando a chave está
em falta, ou a própria chave quando não é indicado um valor por omissão.

```ts
// { "welcome": "Welcome, {name}!" }
$t('welcome', { name: 'Ada' }) // 'Welcome, Ada!'
$t('missing.key', {}, 'Fallback') // 'Fallback'
```

Uma chave que aponta para um objeto aninhado devolve esse objeto, não uma string. Num template é apresentada como `[object Object]`; use uma chave folha.

### `$ts` {#$ts}

```ts
TranslationFn<string>
```

Como `$t`, mas devolve sempre uma string: o valor passa por `toString()`, pelo que um objeto
aninhado se torna `'[object Object]'`. Aponte a chave para uma folha.

### `$_t` {#$_t}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<CleanTranslation>
```

Associa `$t` a uma rota específica, para traduzir fora da página atual — por exemplo, um layout
que apresenta um link para outra rota.

```ts
const route = useRoute()
const t = useNuxtApp().$_t(route)
t('page.title')
```

### `$_ts` {#$_ts}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<string>
```

Associa `$ts` a uma rota específica. Consulte `$_t`.

### `$tc` {#$tc}

```ts
(key: TranslationKey, params: number | Params, defaultValue?: string) => string
```

Traduz com pluralização. `params` pode ser a própria contagem, ou um objeto que contenha
`count`.

As formas são separadas por `|`. Com a regra incorporada, uma contagem inteira não negativa `n` escolhe a forma `n`, limitada à última forma; uma contagem negativa, fracionária ou `NaN` fica com a última forma. `{count}` e os restantes parâmetros são interpolados na forma escolhida.

Para idiomas cujos plurais não seguem a contagem, comece o template com `=0 `. A primeira forma passa então a ser para 0, e as restantes seguem a categoria de [`Intl.PluralRules`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/PluralRules), pela ordem `zero, one, two, few, many, other`:

```json
{
  "apples": "=0 no apples | one apple | {count} apples",
  "files": "=0 no files | {count} one | {count} few | {count} many"
}
```

```ts
$tc('apples', 0) // 'no apples'
$tc('apples', 1) // 'one apple'
$tc('apples', 7) // '7 apples'

// In `uk` (categories `one, few, many, other`) the forms after the zero form follow those categories:
$tc('files', 21) // '21 one'
$tc('files', 22) // '22 few'
$tc('files', 25) // '25 many'
$tc('files', 2.5) // '2.5 many': no form for `other`, so the last one
```

- `=0 ` só conta mesmo no início do valor, com o espaço. `$t` mostra-o como texto: pertence aos plurais.
- Uma categoria sem forma própria fica com a última forma. Uma contagem negativa ou fracionária também fica com a última forma.
- Funciona em qualquer locale: `=0 none | one | {count} many` em inglês.
- A categoria vem do `iso` do locale ou, caso contrário, do seu código. Um código que o `Intl` não conheça recorre à regra de índice, com o marcador removido na mesma, pelo que o resultado nunca depende da máquina.
- `<i18n-t :plural>` segue a mesma regra. Um [`plural`](/pt/api/module-options#plural) ou `customPluralRule` personalizado recebe o valor em bruto, com o marcador incluído, e decide por si; um `plural` que devolva `null` devolve a chamada à regra incorporada, que respeita o marcador.

Sem o marcador, um template mantém-se na regra de índice, com uma exceção que só pode ser lida de uma forma: uma forma zero sem placeholder, seguida de uma forma por categoria, com `{count}` em cada forma partilhada por várias contagens (`no files | {count} one | {count} few | {count} many` em `uk`).

Para regras próprias, defina [`plural`](/pt/api/module-options#plural).

```ts
// { "apples": "no apples | one apple | {count} apples" }
$tc('apples', 0) // 'no apples'
$tc('apples', 10) // '10 apples'
$tc('cart', { count: 2, name: 'Ada' }) // count and params in one object
```

O terceiro argumento é `defaultValue`, não params.

### `$has` {#$has}

```ts
(key: string) => boolean
```

Se uma chave é resolvida no locale ativo. Use-o para ramificar em texto opcional em vez de
apresentar uma chave em bruto. Tal como `$t`, também vê as chaves da página que está a sair durante uma
transição de página no mesmo locale.

```ts
if ($has('promo.banner')) show.value = true
```

## Formatação {#formatting}

### `$tn` {#$tn}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Formata um número com `Intl.NumberFormat` no locale ativo. Uma chave seleciona um formato com nome
a partir da configuração.

Os formatos com nome vêm de [`numberFormats`](/pt/api/module-options#numberformats).

```ts
$tn(1234.5, { style: 'currency', currency: 'EUR' }) // '1.234,50 €' in de
$tn(1000, 'currency') // named format
$tn(1000, 'currency', 'de') // named format in another locale
```

### `$td` {#$td}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Formata uma data com `Intl.DateTimeFormat` no locale ativo. Uma chave seleciona um formato com nome
a partir da configuração.

Os formatos com nome vêm de [`datetimeFormats`](/pt/api/module-options#datetimeformats).

```ts
$td(new Date(), { dateStyle: 'long' })
$td(post.createdAt, 'short')
```

### `$tdr` {#$tdr}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

Formata uma data como tempo relativo ("há 3 dias") com `Intl.RelativeTimeFormat`.

```ts
$tdr(Date.now() - 5 * 60_000) // '5 minutes ago' in en
```

## Mudança de locale e links {#switching-and-links}

### `$switchLocale` {#$switchlocale}

```ts
(locale: string) => Promise<boolean>
```

Navega para a página atual noutro locale. Com `no_prefix` e no modo hash, carrega as
traduções do locale antes de navegar; com `no_prefix`, a rota é substituída no lugar (sem
nova entrada no histórico). Um locale desconhecido é ignorado.
A chamada é assíncrona: use `await` para executar código após a navegação. Resolve `true` quando o
dicionário do locale está ativo, `false` quando não está: o chunk não carregou (o dicionário
atual mantém-se; chame-a de novo para tentar outra vez) ou uma mudança mais recente prevaleceu.

```ts
await $switchLocale('de')
```

### `$switchLocalePath` {#$switchlocalepath}

```ts
(locale: string) => string
```

O caminho da página atual noutro locale, sem navegar.

```vue
<NuxtLink :to="$switchLocalePath('de')">Deutsch</NuxtLink>
```

### `$switchLocaleRoute` {#$switchlocaleroute}

```ts
(locale: string) => RouteLocationRaw
```

O objeto de rota da página atual noutro locale, sem navegar, ou uma string de URL
para um locale com o seu próprio `baseUrl`. Com `trailingSlash`, o objeto tem `path` e `fullPath`,
seguindo a regra, com `query` e `hash` tal como estão, e `router.push` ou um link mantêm-nos.

### `$switchRoute` {#$switchroute}

```ts
(route: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, toLocale?: string) => Promise<void>
```

Navega para outra rota, mantendo o locale ativo ou mudando para `toLocale`. Assíncrono tal como
`$switchLocale`.

```ts
$switchRoute('/about') // active locale
$switchRoute({ name: 'about' }, 'de') // switch to de
```

### `$localePath` {#$localepath}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => string
```

Resolve um caminho no locale indicado, ou no ativo. Uma string com um esquema `http(s):`, `mailto:`
ou `tel:` é devolvida tal como está: não passe dados do utilizador como destino de link sem os verificar.

Um caminho em string é lido como a página que mostra, pelo que o caminho personalizado de um locale também é aplicado.

```ts
$localePath('/about') // '/about' in en, '/de/ueber-uns' in de with localeRoutes
$localePath({ name: 'about' }, 'fr') // '/fr/about'
```

### `$localeRoute` {#$localeroute}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => RouteLocationResolved
```

Resolve uma rota no locale indicado, ou no ativo. Um objeto simples, seguro para guardar em estado. Quando um parâmetro precisa
de ser escapado, tem `path`, `fullPath`, `query` e `hash`, mas não `name` nem `params`: é o caminho que dá ao router
o URL codificado. Para um locale noutro domínio, `path` e `fullPath` são absolutos, o que o router não aceita:
um link desses passa por `<i18n-link>`, ou por `$localePath`.

### `$getRouteName` {#$getroutename}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric, locale?: string) => string
```

Nome da rota sem o prefixo de locale — o nome usado como chave das traduções.

```ts
$getRouteName() // 'about' on /de/about
```

## Configuração da página {#page-config}

### `$defineI18nRoute` {#$definei18nroute}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Regista a configuração de locales e as traduções por página a partir de dentro de um componente.
Funde no locale ativo e volta a aplicar quando o locale muda.

Chame-o no `<script setup>` de uma página, sempre desestruturado de `useNuxtApp()`. O build lê `locales`, `localeRoutes` e `disableMeta` a partir da chamada; em runtime só `locales` importa (as traduções inline são fundidas para o locale ativo). Regras completas: [Configuração da página](/pt/guide/per-component-translations).

```vue
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'de'],
  localeRoutes: { en: '/about', de: '/ueber-uns' },
})
</script>
```

### `$setI18nRouteParams` {#$seti18nrouteparams}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Define parâmetros por locale para a rota atual, para que um segmento dinâmico possa diferir por idioma.
Chame-o durante o SSR, antes de o head ser apresentado.

Os parâmetros são limpos quando uma navegação para outro caminho é concluída, incluindo de `/news/1` para `/news/4`, que mantém o nome da rota. Detalhes: [Caminhos localizados](/pt/guide/custom-locale-routes).

```ts
$setI18nRouteParams({
  en: { slug: 'my-post' },
  de: { slug: 'mein-beitrag' },
})
```

## Traduções em runtime {#runtime-translations}

### `$mergeTranslations` {#$mergetranslations}

```ts
(newTranslations: Translations) => void
```

Funde traduções no locale ativo em runtime, sobrepondo-se ao que está carregado.

Faz uma fusão profunda no chunk da página atual do locale ativo; as chaves que não menciona mantêm-se.

```ts
$mergeTranslations({ banner: { title: 'Sale' } })
```

### `$setTranslation` {#$settranslation}

```ts
(key: string, value: unknown) => void
```

Substitui o valor em `key` no dicionário ativo. Trata-se de uma substituição, não de uma fusão —
use `$mergeTranslations` quando os irmãos existentes devem manter-se.

```ts
$setTranslation('banner', { title: 'Sale' }) // drops other keys under banner
$setTranslation('banner.title', 'Sale') // dotted path
```

### `$loadPageTranslations` {#$loadpagetranslations}

```ts
(locale: string, routeName: string, translations: Translations) => Promise<void>
```

Carrega traduções para uma página em runtime, para conteúdo cujas chaves não são conhecidas no momento do build.

Funde no chunk `(locale, routeName)` em memória, e o ecrã é atualizado quando esse chunk está ativo. Nenhum payload é obtido aqui: para uma página ainda não carregada, as traduções aguardam e, quando o seu ficheiro carrega, ficam por cima dele.

```ts
await $loadPageTranslations('en', 'about', { title: 'About us' })
```

### `$resolveTranslations` {#$resolvetranslations}

```ts
() => Translations
```

Todas as traduções atualmente em memória para o locale e a rota ativos, em árvore.
Vista só de leitura do que `$t()` consegue resolver neste momento.

Trate o resultado como só de leitura.

### `$setMissingHandler` {#$setmissinghandler}

```ts
(handler: MissingHandler | null) => void
```

Instala um callback invocado para cada chave não resolvida. Passe `null` para o remover.

O handler é executado em vez do aviso de desenvolvimento.

```ts
$setMissingHandler((locale, key, routeName) => {
  console.error(`[i18n] missing ${key} in ${locale} (${routeName})`)
})
```

### `$clearCache` {#$clearcache}

```ts
() => void
```

Descarta todos os chunks de tradução em cache e recarrega o dicionário da página atual. A página
continua a mostrar as traduções atuais até chegarem as novas. O HMR de desenvolvimento chama-o
a cada alteração de um ficheiro de tradução.

```ts
const { clearCache } = useI18n()
clearCache()
```

Um recarregamento falhado mantém o dicionário atual.
