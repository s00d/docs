# 🌍 Componente `<i18n-switcher>`

O componente `<i18n-switcher>` do `Nuxt I18n Micro` oferece uma interface pendente amigável para mudar entre diferentes locales na sua aplicação. Este componente é altamente personalizável, permitindo uma integração perfeita com o design e o layout da sua aplicação.

Os locales com `disabled: true` são **omitidos** da lista pendente (mantêm-se disponíveis via `$getLocales()` para SEO / meta tags). Só locales comutáveis recebem `NuxtLink` + `hreflang`.

| `customLinkStyle` | `CSSProperties` | `() => (\{\})` | Estilo inline da ligação dentro de um item. |

Todas as partes são sem estilo por predefinição: as props `custom*Style` aceitam objetos de estilo inline, e
os slots abaixo substituem o markup por completo quando o estilo não é suficiente.

## 🛠️ Exemplos de utilização

### Utilização básica

```vue
<template>
  <i18n-switcher />
</template>
```

Isto renderiza um seletor de locale com estilo e comportamento predefinidos.

### Rótulos personalizados e estilos inline

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Este exemplo demonstra um seletor de locale totalmente personalizado com rótulos personalizados e estilos inline.

## 🔌 Slots

Cada parte visual do seletor pode ser substituída. Os slots estão listados junto à tabela de props acima; cada um recebe conteúdo de template:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Os slots cujo nome termina em `-item`, `-link-content` ou começa com `before-item` recebem o objeto `locale` a que pertencem.

## 🎨 Visão geral dos estilos

O componente `<i18n-switcher>` traz estilos básicos definidos através de estilos inline que podem ser facilmente substituídos ao passar estilos personalizados via props. Segue uma breve descrição do estilo predefinido:

- **Envolvente**: controla o posicionamento da lista pendente.
- **Botão**: define o estilo do botão que alterna a lista pendente.
- **Lista pendente**: define o estilo da lista pendente.
- **Itens**: define o estilo de cada item da lista.
- **Ligações**: define o estilo das ligações dentro de cada item.
- **Ícone**: define o estilo do ícone indicador da lista pendente.

Pode personalizar estes estilos passando estilos personalizados através das props correspondentes, garantindo que o seletor de locale se integra perfeitamente no UI da sua aplicação.
