# 🌍 Componente `<i18n-link>`

O componente `<i18n-link>` do `Nuxt I18n Micro` é um componente de ligação versátil que localiza automaticamente as rotas com base no locale atual. Funciona como um envolvente para o componente `<NuxtLink>`, oferecendo funcionalidades adicionais como estilo de ligação ativa e suporte para ligações externas.

## ⚙️ Props

| Prop | Tipo | Predefinição | Descrição |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | Rota de destino. É localizada automaticamente; um URL externo é passado sem alterações. |
| `activeStyle` | `Partial<CSSStyleValue>` | — | Estilo inline aplicado enquanto a ligação aponta para a rota atual. |

**\*** obrigatório.

### Slots

| Slot | Bindings | Descrição |
| --- | --- | --- |
| `default` | — | Conteúdo da ligação. |

{/* /generated:component:i18n-link */}

`to` aceita tudo o que o `NuxtLink` aceita: um caminho, uma rota nomeada ou um objeto de rota resolvido.
Um URL absoluto é detetado e renderizado como um `<a target="_blank" rel="noopener noreferrer">` simples,
em vez de ser localizado.

## 🛠️ Exemplos de utilização

### Utilização básica

```vue
<i18n-link to="/about">About Us</i18n-link>
```

Este exemplo cria uma ligação para a página `/about`, localizada para o locale atual.

### Estilo de ligação ativa com estilos inline

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

A ligação terá texto a negrito quando o utilizador estiver na página `/about`, permitindo estilizar a ligação ativa diretamente com estilos inline.

### Tratamento de ligações externas

O componente deteta automaticamente ligações externas e adiciona os atributos necessários para segurança.

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

Esta ligação abrirá `https://example.com` num novo separador com `rel="noopener noreferrer"` aplicado.

## 🎨 Estilos

O componente utiliza agora estilos inline para o estado ativo em vez de uma classe. Pode personalizar estes estilos através da prop `activeStyle`.

### Estilos ativos predefinidos

- **Font Weight**: `bold`
- **Cor**: herda a cor predefinida do navegador (se não for especificada `color` em `activeStyle`).

Pode substituir estes estilos fornecendo estilos personalizados através da prop `activeStyle`.

### Estilos ativos personalizados

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

Neste exemplo, a ligação ficará a negrito e verde quando estiver ativa.

## 🚀 Funcionalidades adicionais

### Slot para conteúdo personalizado

Pode passar conteúdo personalizado dentro da ligação através de slots, tornando o componente flexível para diferentes casos de utilização.

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### Melhorias de acessibilidade

O componente suporta `aria-label` e outros atributos de acessibilidade para garantir uma experiência mais acessível.

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
