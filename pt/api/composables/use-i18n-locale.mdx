# useI18nLocale

## Assinatura

Ponto de entrada centralizado para a gestão do locale i18n.
Combina `useState('i18n-locale')`, o cookie de locale e utilitários de sincronização.

## Utilização

```vue
<script setup>
const {
  locale,
  localeCookie,
  hashCookie,
  validLocales,
  getPreferredLocale,
  getLocale,
  getLocaleWithServerFallback,
  getEffectiveLocale,
  resolveInitialLocale,
  setLocale,
  syncLocale,
  isValidLocale,
} = useI18nLocale()

// Set locale (updates state and cookies)
setLocale('de')

// Get current locale (state → cookie)
const current = getLocale()

// Get valid preferred locale
const preferred = getPreferredLocale()
</script>
```

## API

| Propriedade/Método                              | Tipo                                | Descrição                                                                            |
| ----------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| `locale`                                        | `Ref<string \| null>`               | Estado reativo do locale (`useState('i18n-locale')`)                                 |
| `localeCookie`                                  | `Ref`                               | Cookie de locale (quando a opção `localeCookie` está ativada)                        |
| `hashCookie`                                    | `Ref`                               | Cookie usado quando `hashMode` está ativo                                            |
| `validLocales`                                  | `string[]`                          | Códigos de locale ativos da configuração do módulo (exclui `disabled`)               |
| `getLocale()`                                   | `() => string \| null`              | Locale atual: estado → cookie (ou cookie de hash em modo hash)                       |
| `getPreferredLocale()`                          | `() => string \| null`              | Locale a partir do estado/cookie **validado** contra `validLocales`, ou `null`       |
| `getLocaleWithServerFallback(serverLocale?)`    | `(serverLocale?) => string \| null` | Estado → cookie → contexto opcional do servidor (usado durante a inicialização `no_prefix`) |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string`             | Locale para carregar traduções: modo hash prefere o estado; caso contrário, lê da rota |
| `resolveInitialLocale(options)`                 | `(options) => string`               | Resolve o locale: estado → `serverLocale` → rota; sincroniza o estado quando necessário |
| `setLocale(locale)`                             | `(locale: string \| null) => void`  | Define o locale e sincroniza com os cookies                                          |
| `syncLocale(locale)`                            | `(locale: string \| null) => void`  | Sincroniza apenas os cookies (sem atualizar o estado)                                |
| `isValidLocale(locale)`                         | `(locale) => boolean`               | Verifica se a string existe em `validLocales`                                        |

### Opções de `resolveInitialLocale`

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

Utilizado internamente pelo plugin principal no arranque. Plugins personalizados podem chamá-lo ao implementar fluxos alternativos de deteção.

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

Devolve o locale usado para carregar traduções e formatar mensagens para um determinado objeto de rota.

## Definição programática do locale

Prefira `useI18nLocale()` a utilizar diretamente `useState('i18n-locale')`:

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
`setLocale()` atualiza apenas a preferência de locale (estado + cookie). Para também recarregar o contexto de tradução ativo no cliente, utilize `$switchLocale()` a partir de `useNuxtApp()` ou `useI18n()`. Isto é especialmente relevante em `no_prefix`, onde o URL não muda. Consulte [FAQ — mudar o locale sem alterar o URL](/guides/faq#-switch-locale-without-changing-the-url).
</Tip>
