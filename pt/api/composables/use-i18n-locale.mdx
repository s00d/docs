# useI18nLocale

## Assinatura

Ponto de entrada centralizado para a gestão de locale i18n.
Combina useState('i18n-locale'), cookie de locale e utilitários de sincronização.

## Utilização

```vue
<script setup>
const {
  locale,
  localeCookie,
  hashCookie,
  validLocales,
  getPreferredLocale,
  getLocale,
  getLocaleWithServerFallback,
  getEffectiveLocale,
  resolveInitialLocale,
  setLocale,
  syncLocale,
  isValidLocale,
} = useI18nLocale()

// Set locale (updates state and cookies)
setLocale('de')

// Get current locale (state → cookie)
const current = getLocale()

// Get valid preferred locale
const preferred = getPreferredLocale()
</script>
```

## API

| Propriedade/Método                                 | Tipo                                | Descrição                                                                          |
| ----------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| `locale`                                        | `Ref<string \| null>`               | Estado reativo do locale (`useState('i18n-locale')`)                                    |
| `localeCookie`                                  | `Ref`                               | Cookie de locale (quando a opção `localeCookie` está ativada)                                |
| `hashCookie`                                    | `Ref`                               | Cookie utilizado quando `hashMode` está ativo                                                |
| `validLocales`                                  | `string[]`                          | Códigos de locale ativados na configuração do módulo (exclui os `disabled`)                        |
| `getLocale()`                                   | `() => string \| null`              | Locale atual: estado → cookie (ou hash cookie em hash mode)                         |
| `getPreferredLocale()`                          | `() => string \| null`              | Locale de estado/cookie **validado** contra `validLocales`, ou `null`             |
| `getLocaleWithServerFallback(serverLocale?)`    | `(serverLocale?) => string \| null` | Estado → cookie → contexto de servidor opcional (usado durante a init de `no_prefix`)              |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string`             | Locale para carregamento de traduções: hash mode prefere o estado; caso contrário lê da rota |
| `resolveInitialLocale(options)`                 | `(options) => string`               | Resolve o locale: estado → `serverLocale` → rota; sincroniza o estado quando necessário             |
| `setLocale(locale)`                             | `(locale: string \| null) => void`  | Define o locale e sincroniza com os cookies                                                       |
| `syncLocale(locale)`                            | `(locale: string \| null) => void`  | Sincroniza apenas os cookies (sem atualizar o estado)                                                  |
| `isValidLocale(locale)`                         | `(locale) => boolean`               | Verifica se a string está em `validLocales`                                                 |

### Opções de `resolveInitialLocale`

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

Utilizado internamente pelo plugin principal no arranque. Plugins personalizados podem chamá-lo ao implementar fluxos de deteção alternativos.

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

Devolve o locale utilizado para carregar traduções e formatar mensagens para um determinado objeto de rota.

## Definição programática de locale

Prefira `useI18nLocale()` em vez do uso direto de `useState('i18n-locale')`:

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
O `setLocale()` atualiza apenas a preferência de locale (estado + cookie). Para também recarregar o contexto de traduções ativo no cliente, utilize `$switchLocale()` de `useNuxtApp()` ou `useI18n()`. Isto é particularmente relevante para `no_prefix`, onde o URL não muda. Consulte [FAQ — alternar locale sem alterar o URL](/guides/faq#-switch-locale-without-changing-the-url).
</Tip>
