# 🌍 Composable `useLocaleHead`

O composable `useLocaleHead` é um utilitário do `Nuxt I18n Micro` que ajuda a gerir atributos de SEO e meta tags HTML para rotas localizadas. Gera dinamicamente os atributos `lang` e `dir` do documento HTML e cria tags `meta` e `link` para melhorar o SEO do seu conteúdo localizado.

## ⚙️ Opções

```ts
useLocaleHead(options: UseLocaleHeadOptions): { metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }, MetaObject | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

As tags SEO do head para a rota atual: alternates `hreflang` para cada locale, mais `x-default`, uma ligação canonical, `og:locale` e `lang`/`dir` em `<html>`.

Só é necessário quando `meta` está desativado ou quando os valores predefinidos precisam de ajustes. Com `meta: true` o módulo regista as mesmas tags automaticamente.

## 🛠️ Valores devolvidos

O composable `useLocaleHead` devolve um objeto reativo e uma função de atualização que deve chamar quando os dados de origem mudam. Ambas as formas estão na assinatura acima, gerada a partir do código-fonte.

### `metaObject`

Payload reativo do head (html attrs, meta, link) adequado a `useHead(metaObject)`.

- **Exemplo**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

Recalcula `metaObject` com base na rota atual, no locale e na configuração. Chame-a quando as entradas mudarem, por exemplo, numa mudança de rota.

- **Exemplo**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### Acesso a `link` e `meta`

Os arrays `link` e `meta` são acessíveis através de `metaObject.value`:

- **Exemplo**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ Exemplos de utilização

### Utilização básica

Gera os atributos de head específicos do locale com as opções predefinidas.

```js
const head = useLocaleHead()
```

### Personalizar o atributo identificador

Utilize um atributo identificador personalizado para as tags geradas.

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### Desativar atributos de SEO

Gera atributos de head sem adicionar meta tags nem ligações relacionadas com SEO.

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### Especificar um URL base

Defina um URL base personalizado para URLs canónicos e alternativos.

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 Funcionalidades adicionais

### Meta tags e ligações SEO

Quando `addSeoAttributes` está ativado, o composable gera automaticamente as seguintes tags:

- `og:locale` para o locale atual (`language_TERRITORY`, underscore). Derivado de `locale.og` ou convertido de `locale.iso` quando possível.
- `og:url` para o URL canónico da página.
- `og:locale:alternate` para versões noutros idiomas.
- Ligações `rel="canonical"` e `rel="alternate"` para otimização SEO.
- Ligação `hreflang="x-default"` a apontar para o URL do locale predefinido. Indica aos motores de busca que URL apresentar a utilizadores cujo idioma não corresponde a nenhum dos locales definidos.

### Locale e direção dinâmicos

O composable determina dinamicamente os atributos `lang` e `dir` com base no locale da rota atual, garantindo que o documento HTML fica corretamente configurado para utilizadores internacionais.

### Tratamento de rotas localizadas

Se as suas rotas tiverem prefixos com códigos de locale (por exemplo, `/en/about`), o composable ajusta inteligentemente o caminho completo para gerar URLs, garantindo que os atributos de SEO são exatos e relevantes.

Este composable simplifica o processo de otimização da sua aplicação Nuxt para audiências internacionais, garantindo que o seu site está bem preparado para motores de busca e utilizadores globais.

## 🛠️ Exemplo de utilização

O exemplo seguinte demonstra como utilizar o composable `useLocaleHead` num componente Vue com as definições predefinidas:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### Explicação do código

- **Composable `useLocaleHead`**: este composable é chamado na secção `<script setup>` e devolve um objeto que contém `htmlAttrs`, `meta` e `link`.

- **Tag `<html>`**: os atributos `lang` e `dir` do documento HTML são determinados dinamicamente com base no locale atual e aplicados à tag `<html>`.

- **Secção `<head>`**:
  - **Meta tags**: são geradas meta tags relacionadas com SEO, incluindo `og:locale`, `og:url`, e tags `rel="canonical"` e `rel="alternate"` para especificar versões alternativas da página em outros idiomas.
  - **Tags de ligação**: são incluídas ligações canónicas, ligações para versões noutros idiomas e a ligação `hreflang="x-default"` (a apontar para o URL do locale predefinido).

- **Secção `<body>`**: aqui é apresentado o conteúdo principal da página. Neste exemplo, é usado um simples cabeçalho e parágrafo.

### 📝 Notas

1. **Atributos**: os atributos usados (`lang`, `dir`, `rel`, `href`, `hreflang`, `property`, `content`) são extraídos do objeto devolvido por `useLocaleHead`.

2. **Geração de tags SEO**: se a opção `addSeoAttributes` estiver definida como `true`, o composable gera automaticamente tags SEO para o locale atual.

3. **URL base**: pode definir o seu URL base personalizado através da opção `baseUrl` para gerar corretamente ligações canónicas e alternativas.

Este exemplo demonstra como é fácil integrar `useLocaleHead` nos componentes da sua aplicação para garantir atributos SEO corretos e melhorar a indexação de páginas localizadas por motores de busca.

## 🧩 Personalização e ciclo de vida

- `useLocaleHead` não subscreve alterações por si só. Devolve `metaObject` e `updateMeta`.
- Deve chamar `updateMeta()` quando as entradas mudarem (tipicamente numa mudança de rota), por exemplo, a partir de um plugin:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## Quando utilizar antes `useI18nHead`

Quando `meta: true` (predefinição), prefira [`useI18nHead`](/api/composables/use-i18n-head) para substituições **por página** (hreflang personalizado, `og:title` extra, desativação parcial). Utilize `useLocaleHead` diretamente apenas quando `meta: false` ou quando gere `useHead` manualmente.
