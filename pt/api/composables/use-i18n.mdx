# 🛠️ Composable `useI18n`

O composable `useI18n` do `Nuxt I18n Micro` fornece acesso à maioria dos helpers de i18n em runtime em componentes e scripts. Os métodos estão disponíveis **com e sem o prefixo `$`** (por exemplo, `$t` e `t`).

Algumas injeções — `$defineI18nRoute` e `$clearCache` — só estão disponíveis através de `useNuxtApp()`. Consulte [Métodos — `$defineI18nRoute`](/api/methods#definei18nroute) e [`$clearCache`](/api/methods#clearcache).

## 📊 O que devolve

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Cada helper de runtime, como um objeto simples.

As mesmas funções que o plugin injeta como `$t`, `$tc`, etc., disponíveis tanto sob o nome com prefixo em dólar como sob um alias sem prefixo, pelo que `const \{ t \} = useI18n()` e
`const \{ $t \} = useI18n()` funcionam ambos.

**Devolve** — os helpers descritos na [referência de métodos](/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

Cada helper que devolve — `$t`, `$tc`, `$has`, `$switchLocale` e os restantes — está listado com a sua assinatura e totalmente documentado na [referência de métodos](/api/methods).

## APIs disponíveis apenas em `useNuxtApp()`

Estes **não** são devolvidos por `useI18n()`. Importe-os a partir de `useNuxtApp()`:

| Método                     | Propósito                                                                       |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Rotas de locale por página, restrições e traduções inline em `script setup`    |
| `$clearCache()`            | Limpa a cache de traduções em memória e os chunks carregados                    |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Consulte [Métodos](/api/methods) para assinaturas e exemplos completos.

## 🛠️ Exemplos de utilização

### Obtenção básica do locale

Obtenha o locale atual da aplicação.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Tradução com parâmetros

Traduza uma string com parâmetros dinâmicos e um valor predefinido de fallback.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Mudança de locale

Mude a aplicação para um locale diferente.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Gerar uma rota localizada

Gere uma rota localizada para o locale atual ou para o especificado.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
