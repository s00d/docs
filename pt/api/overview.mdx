Esta secção lista todas as opções, helpers, hooks, composables e componentes do módulo Nuxt, bem como a API exportada de cada pacote `@i18n-micro/*`. Utilize-a para consultar uma assinatura ou um valor predefinido; o [Guia](/pt/guide/getting-started) explica como os utilizar. A maioria das tabelas aqui é gerada a partir do código-fonte, pelo que corresponde ao código.

## Módulo Nuxt {#nuxt-module}

| Página | Abrange |
| --- | --- |
| [Opções do módulo](/pt/api/module-options) | Todas as chaves `i18n` em `nuxt.config`, com tipo e valor predefinido |
| [Helpers](/pt/api/methods) | `$t`, `$tc`, `$tn`, `$td`, `$localePath`, `$switchLocale`, `$defineI18nRoute` e os restantes |
| [Hooks](/pt/api/events) | O hook de runtime `i18n:register` |

## Composables {#composables}

| Composable | Utilize-o para |
| --- | --- |
| [`useI18n`](/pt/composables/useI18n) | Os helpers em `<script setup>` |
| [`useI18nLocale`](/pt/composables/useI18nLocale) | Estado do locale e cookie num plugin de deteção personalizado |
| [`useI18nHead`](/pt/composables/useI18nHead) | Substituições por página das tags SEO geradas |
| [`useLocaleHead`](/pt/composables/useLocaleHead) | As tags SEO como objeto, para o seu próprio `useHead` |

## Componentes {#components}

| Componente | Apresenta |
| --- | --- |
| [`<i18n-t>`](/pt/components/i18n-t) | Uma tradução, com plural, formatação e interpolação de slots |
| [`<i18n-link>`](/pt/components/i18n-link) | Um `NuxtLink` para a rota localizada |
| [`<i18n-switcher>`](/pt/components/i18n-switcher) | Um menu pendente de locales |
| [`<i18n-group>`](/pt/components/i18n-group) | Um bloco com um prefixo de chave partilhado |

## Servidor {#server}

Os handlers Nitro utilizam `useTranslationServerMiddleware` e `useLocaleServerMiddleware`, e não os helpers do cliente. Consulte [Rotas do servidor](/pt/guide/server-side-translations).

## Pacotes {#packages}

[APIs dos pacotes](/pt/api/packages/overview) lista as exportações de cada pacote `@i18n-micro/*`, uma página gerada para cada um.
