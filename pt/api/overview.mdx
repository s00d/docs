# Referência da API

## API de runtime

- [Métodos](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, alternância de locale, helpers de encaminhamento.
- [Eventos](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`.
- [Traduções e cache](/api/cache) — `TranslationStorage`, carregamento de payloads, `$clearCache`.

## Middleware do servidor

Os handlers do servidor utilizam middleware dedicado (não os helpers `$t` do cliente):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — traduzir em rotas de API e handlers do servidor.
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — ler o locale detetado e os metadados.

Consulte o [guia completo de traduções no lado do servidor](/guides/server-side-translations) para configuração, prioridade de deteção de locale e exemplos.
