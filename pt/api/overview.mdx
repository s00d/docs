# Referência da API

## API de runtime

- [Métodos](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, troca de locale, helpers de encaminhamento
- [Eventos](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Traduções e cache](/api/cache) — `TranslationStorage`, carregamento de payloads, `$clearCache`

## Middleware de servidor

Os handlers de servidor usam middleware dedicado (não os helpers `$t` do cliente):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — traduza em rotas de API e handlers de servidor
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — leia o locale detetado e os respetivos metadados

Consulte o [guia completo de traduções no lado do servidor](/guides/server-side-translations) para a configuração, a prioridade de deteção de locale e exemplos.
