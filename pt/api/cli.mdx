O [guia da CLI](/pt/guide/cli) mostra os fluxos de trabalho comuns. Esta página lista tudo e é gerada a partir da mesma tabela que alimenta `--help`.

## Flags comuns {#common-flags}

| Flag | Predefinição | Descrição |
| --- | --- | --- |
| `--cwd` | diretório atual | Diretório do projeto |
| `--logLevel` | `info` | Nível de saída: silent, info |
| `--debug` | `false` | Imprimir um stack trace quando um comando falha |

## Inspecionar {#inspect}

### `info` {#info}

Imprimir a configuração i18n resolvida do projeto

| Flag | Predefinição | Descrição |
| --- | --- | --- |
| `--json` | `false` | Imprimir JSON em vez de texto |

### `check` {#check}

A barreira de CI: falha perante chaves em falta, vazias, extra, não definidas ou não utilizadas e placeholders inválidos

| Flag | Predefinição | Descrição |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` do nuxt.config | Diretório de traduções, relativo ao projeto |
| `--only` | todas exceto duplicates | Verificações a executar, separadas por vírgulas: missing, empty, extra, placeholders, undefined, unused, duplicates. `unused` indicado aqui falha quando não pode ser executado |
| `--duplicates` | `false` | Reportar também o mesmo texto sob chaves diferentes |
| `--ignore` | — | Globs de ficheiros de código-fonte a ignorar, separados por vírgulas, relativos ao projeto |
| `--json` | `false` | Imprimir JSON em vez de texto |

```bash
i18n-micro check
i18n-micro check --only missing,placeholders --json
```

### `stats` {#stats}

Mostrar a percentagem de conclusão das traduções por locale

| Flag | Predefinição | Descrição |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` do nuxt.config | Diretório de traduções, relativo ao projeto |
| `--html` | — | Escrever também um relatório HTML neste ficheiro |
| `--json` | `false` | Imprimir JSON em vez de texto |
| `--baseRef` | — | Ref Git com a qual comparar a conclusão, p. ex. HEAD~1 ou main |

```bash
i18n-micro stats --baseRef main
i18n-micro stats --html reports/i18n.html
```

### `lint` {#lint}

Verificar o texto das traduções; falha quando restam problemas

| Flag | Predefinição | Descrição |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` do nuxt.config | Diretório de traduções, relativo ao projeto |
| `--rules` | todas, ou `enabledRules` de .i18n-lintrc.json | Regras a executar, separadas por vírgulas: no-trailing-spaces, no-multiple-spaces, no-empty-translation, ou uma personalizada |
| `--fix` | `false` | Corrigir o que pode ser corrigido: espaços e regras personalizadas com substituição |
| `--json` | `false` | Imprimir JSON em vez de texto |

```bash
i18n-micro lint --rules no-trailing-spaces --fix
```

### `search` {#search}

Pesquisar chaves e valores e mostrar onde cada chave é utilizada

| Flag | Predefinição | Descrição |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` do nuxt.config | Diretório de traduções, relativo ao projeto |
| `<query>` | — | Texto ou chave a pesquisar |
| `--caseSensitive` | `false` | Distinguir maiúsculas de minúsculas |
| `--onlyUnused` | `false` | Apenas as chaves que `clean` removeria; a pesquisa torna-se opcional |
| `--scope` | `all` | Onde pesquisar: global, pages, all |
| `--limit` | — | Devolver no máximo este número de chaves |
| `--ignore` | — | Globs de ficheiros de código-fonte a ignorar, separados por vírgulas, relativos ao projeto |
| `--json` | `false` | Imprimir JSON em vez de texto |

```bash
i18n-micro search "Welcome"
i18n-micro search --onlyUnused
```

## Fluxo de trabalho de tradução {#translation-workflow}

### `extract` {#extract}

Listar as chaves usadas pelos ficheiros de código-fonte que ainda não têm texto e adicioná-las, com um texto predefinido, ao locale predefinido

| Flag | Predefinição | Descrição |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` do nuxt.config | Diretório de traduções, relativo ao projeto |
| `--ignore` | — | Globs de ficheiros de código-fonte a ignorar, separados por vírgulas, relativos ao projeto |

```bash
i18n-micro extract
```

### `translate` {#translate}

Preencher as traduções em falta a partir do locale predefinido através de um serviço de tradução

| Flag | Predefinição | Descrição |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` do nuxt.config | Diretório de traduções, relativo ao projeto |
| `--service` | — | Serviço de tradução: ai, azure, deepl, google, libretranslate, yandexcloud |
| `--token` | — | Chave de API. Prefira a variável de ambiente I18N_TRANSLATE_TOKEN: as flags ficam no histórico da shell |
| `--options` | — | Opções do serviço como pares key:value, separados por vírgulas |
| `--locale` | todos os locales exceto o predefinido | Locales a preencher, separados por vírgulas |
| `--replace` | `false` | Traduzir novamente todas as chaves, substituindo os valores existentes |
| `--dryRun` | `false` | Contar chaves e caracteres por locale; não enviar nada |
| `--chunkSize` | — | Strings por pedido; limitado ao que o serviço aceita |
| `--pluralSeparator` | `\|` | Separador das formas de plural nas mensagens |
| `--glossaryFile` | `.i18n-glossary.json` quando existe | Ficheiro de glossário, usado pelo serviço `ai` |

```bash
i18n-micro translate --dryRun
I18N_TRANSLATE_TOKEN=... i18n-micro translate --service deepl --locale de,fr
i18n-micro translate --service ai --options provider:openai,model:gpt-4o-mini
i18n-micro translate --service libretranslate --options baseUrl:https://translate.example.com
```

### `sync` {#sync}

Remover as chaves que o locale predefinido não tem; para quando não é possível provar que é seguro. As chaves em falta continuam em falta

| Flag | Predefinição | Descrição |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` do nuxt.config | Diretório de traduções, relativo ao projeto |
| `--ignore` | — | Globs de ficheiros de código-fonte a ignorar, separados por vírgulas, relativos ao projeto |
| `--dryRun` | `false` | Listar o que seria removido; não escrever nada |
| `--force` | `false` | Remover as chaves mesmo sem ser possível provar que é seguro |

```bash
i18n-micro sync --dryRun
```

### `clean` {#clean}

Remover as chaves que nada no projeto utiliza; para quando isso não pode ser provado

| Flag | Predefinição | Descrição |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` do nuxt.config | Diretório de traduções, relativo ao projeto |
| `--include` | — | Expressão regular: considerar para remoção apenas as chaves correspondentes |
| `--exclude` | — | Expressão regular: nunca remover as chaves correspondentes |
| `--ignore` | — | Globs de ficheiros de código-fonte a ignorar, separados por vírgulas, relativos ao projeto |
| `--dryRun` | `false` | Listar o que seria removido; não escrever nada |
| `--force` | `false` | Remover as chaves mesmo que não seja possível provar a utilização de todas |

```bash
i18n-micro clean --dryRun
i18n-micro clean --exclude '^errors\.'
```

## Refatoração {#refactoring}

### `text-to-i18n` {#text-to-i18n}

Substituir texto fixo nos templates Vue por chamadas de tradução e reportar texto fixo no código

| Flag | Predefinição | Descrição |
| --- | --- | --- |
| `--translationFile` | `<translationDir>/<defaultLocale>.json` | Ficheiro para onde vão as novas chaves |
| `--path` | o projeto inteiro | Ficheiro ou diretório a processar |
| `--context` | — | Prefixo para as chaves geradas |
| `--ignore` | — | Globs de ficheiros de código-fonte a ignorar, separados por vírgulas, relativos ao projeto |
| `--dryRun` | `false` | Mostrar o que mudaria; não escrever nada |
| `--interactive` | `false` | Confirmar ou editar cada chave gerada |

```bash
i18n-micro text-to-i18n --dryRun
i18n-micro text-to-i18n --path components --context ui
```

### `rename` {#rename}

Mudar o nome de uma chave ou de um namespace em todos os locales e nos ficheiros de código-fonte

| Flag | Predefinição | Descrição |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` do nuxt.config | Diretório de traduções, relativo ao projeto |
| `--from` **\*** | — | Chave ou namespace atual |
| `--to` **\*** | — | Nova chave ou namespace |
| `--ignore` | — | Globs de ficheiros de código-fonte a ignorar, separados por vírgulas, relativos ao projeto |
| `--dryRun` | `false` | Reportar as alterações; não escrever nada |

**\*** obrigatório.

```bash
i18n-micro rename --from common.save --to actions.save
```

### `pseudo` {#pseudo}

Preencher um locale com pseudotraduções para encontrar problemas de layout e de texto fixo

| Flag | Predefinição | Descrição |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` do nuxt.config | Diretório de traduções, relativo ao projeto |
| `--sourceLocale` | o locale predefinido | Locale a ler |
| `--targetLocale` **\*** | — | Locale a preencher |
| `--replace` | `false` | Substituir os valores existentes |

**\*** obrigatório.

### `format` {#format}

Reescrever os ficheiros de locale com chaves ordenadas e indentação uniforme

| Flag | Predefinição | Descrição |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` do nuxt.config | Diretório de traduções, relativo ao projeto |
| `--indent` | `2` | Espaços de indentação |
| `--sortKeys` | `true` | Ordenar as chaves; use --no-sortKeys para manter a ordem |
| `--check` | `false` | Falhar se um ficheiro fosse alterado; não escrever nada |

```bash
i18n-micro format --check
```

## Intercâmbio {#exchange}

### `export` {#export}

Exportar os ficheiros de locale para PO ou CSV, com o texto do locale predefinido como origem

| Flag | Predefinição | Descrição |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` do nuxt.config | Diretório de traduções, relativo ao projeto |
| `--format` | `po` | Formato de ficheiro: po, csv |
| `--dir` | `pots` para po, `csv_exports` para csv | Diretório de saída, relativo ao projeto |
| `--force` | `false` | Substituir ficheiros alterados desde a última exportação e nunca importados |

```bash
i18n-micro export --format csv
```

### `import` {#import}

Fundir ficheiros PO ou CSV nos ficheiros de locale

| Flag | Predefinição | Descrição |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` do nuxt.config | Diretório de traduções, relativo ao projeto |
| `--format` | `po` | Formato de ficheiro: po, csv |
| `--dir` | `pots` para po, `csv_exports` para csv | Diretório de entrada, relativo ao projeto |
| `--dryRun` | `false` | Reportar o que seria importado; não escrever nada |

```bash
i18n-micro import --format csv --dryRun
```

### `sync-remote` {#sync-remote}

Obter as traduções globais do endpoint HTTP definido em .i18n-remote.json, ou enviá-las para ele

| Flag | Predefinição | Descrição |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` do nuxt.config | Diretório de traduções, relativo ao projeto |
| `--pull` | `true` | Obter do remoto |
| `--push` | `false` | Enviar para o remoto |
| `--force` | `false` | Num pull, ficar com o valor remoto; num push, substituir texto que só o remoto tem |
| `--dryRun` | `false` | Reportar o que um pull alteraria; não escrever nem enviar nada |

```bash
i18n-micro sync-remote --dryRun
i18n-micro sync-remote --no-pull --push
```

## Regras de lint {#lint-rules}

| Regra | Deteta | Corrigida por `--fix` |
| --- | --- | --- |
| `no-trailing-spaces` | Espaços no fim de um valor ou de uma linha | sim |
| `no-multiple-spaces` | Dois ou mais espaços seguidos | sim |
| `no-empty-translation` | Um valor vazio ou em branco | não |

## Códigos de saída {#exit-codes}

| Código | Significado |
| --- | --- |
| `0` | Concluído, nada a reportar |
| `1` | Problemas encontrados: `check`, `lint` ou `format --check` encontraram algo, `clean` ou `sync` não conseguiram provar que uma remoção é segura, `export` substituiria trabalho não importado, `translate` deixou chaves de fora, `import` ou `sync-remote` encontraram um conflito, um push de `sync-remote` eliminaria texto remoto. Um `--dryRun` de `clean`, `sync` ou de um pull de `sync-remote` reporta estes casos e termina com `0` |
| `2` | Falha: utilização incorreta, projeto ilegível, erro de rede ou de ficheiro |

## Ficheiros de configuração {#configuration-files}

| Ficheiro | Usado por |
| --- | --- |
| `.i18n-lintrc.json` | `lint`: `enabledRules`, `disabledRules`, `customRegexRules` (`name`, `pattern`, `flags`, `description`, `replacement`) |
| `.i18n-remote.json` | `sync-remote`: `url`, `path`, `token`, `auth` (`username`, `password`). `type` pode ser omitido; só existe `custom` |
| `.i18n-glossary.json` | `translate --service ai`: `entries` de `source`, `target` e, opcionalmente, `from`, `to` |

## Variáveis de ambiente {#environment-variables}

| Nome | Usada para |
| --- | --- |
| `I18N_TRANSLATE_TOKEN` | Chave de API de `translate`. Também é lida de `.env` |
| `I18N_REMOTE_TOKEN` | Bearer token de `sync-remote`. Também é lido de `.env` |
| `AI_GATEWAY_API_KEY, OPENAI_API_KEY, ANTHROPIC_API_KEY` | Chave do serviço `ai`, quando `I18N_TRANSLATE_TOKEN` não está definido |
| `DEFAULT_LOCALE` | Substitui `defaultLocale`, tal como no módulo |
