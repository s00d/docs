**Tanggal**: 2025-10-30

**Versi**: `v2.0.0`

![Rilis v2.0.0](/images/2.0.0.png)

Kami memperkenalkan HMR sisi server untuk file terjemahan dalam mode pengembangan. Ketika sebuah terjemahan JSON berubah, cache server hanya membatalkan key yang terdampak, dan request berikutnya langsung menerima data terbaru—tanpa perlu restart.

## Apa yang Baru? {#what’s-new}

- HMR sisi server untuk file terjemahan
- Invalidasi cache instan per halaman/locale
- DX yang mulus saat mengedit konten

## Cara kerjanya {#how-it-works}

- Watcher di `src/runtime/server/plugins/watcher.dev.ts` memantau `<rootDir>/<translationDir>/**/*.json`
- File halaman (mis. `pages/<page>/<locale>.json`) membatalkan `_locales:merged:<page>:<locale>`
- File tingkat root (mis. `<locale>.json`) membatalkan semua key gabungan untuk locale tersebut
- Didaftarkan otomatis dari `src/module.ts` dalam mode dev ketika `experimental.hmr !== false`

## Konfigurasi {#configuration}

```ts
export default defineNuxtConfig({
  i18n: {
    experimental: { hmr: true }, // default in dev
  },
})
```
