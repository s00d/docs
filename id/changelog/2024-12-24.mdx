![v1.1.0 CLI text-to-i18n demo](/images/text-to-i18n.gif)

Dengan gembira kami umumkan perintah baru `text-to-i18n` di CLI Nuxt I18n Micro! Fitur canggih ini mengotomatiskan proses mengekstrak string teks yang di-hardcode dari codebase Anda dan mengubahnya menjadi kunci terjemahan i18n. Fitur ini dirancang untuk menghemat waktu, mengurangi kesalahan, dan menyederhanakan alur kerja lokalisasi Anda.

## Manfaat Utama {#key-benefits}

- **Ekstraksi Teks Otomatis**: Memindai template Vue, file JavaScript, dan TypeScript.
- **Pembuatan Kunci yang Mulus**: Membuat kunci terjemahan terstruktur berdasarkan path file dan konten.
- **Pengelolaan Terjemahan yang Efisien**: Memperbarui file terjemahan Anda sambil mempertahankan entri yang sudah ada.

## Cara Kerjanya {#how-it-works}

1. **Pemindaian File**: Memproses file di direktori utama seperti `pages`, `components`, dan `plugins`.
2. **Pemrosesan Teks**: Mengidentifikasi dan mengekstrak string yang dapat diterjemahkan, sambil membuat kunci unik.
3. **Pembaruan Terjemahan**: Secara otomatis menyisipkan kunci baru ke file terjemahan Anda dan mempertahankan struktur bersarangnya.

## Penggunaan {#usage}

```bash
i18n-micro text-to-i18n [options]
```

Contoh:

```bash
i18n-micro text-to-i18n --translationFile locales/en.json --context auth
```

## Contoh Transformasi {#example-transformations}

### Sebelum {#before}

```vue
<template>
  <div>
    <h1>Welcome to our site</h1>
    <p>Please sign in to continue</p>
  </div>
</template>
```

### Sesudah {#after}

```vue
<template>
  <div>
    <h1>{{ $t('pages.home.welcome_to_our_site') }}</h1>
    <p>{{ $t('pages.home.please_sign_in') }}</p>
  </div>
</template>
```
