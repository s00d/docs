Rilis: **v3.22.0 → v3.26.0**.

## Fitur baru

- **Translation Memory API.** Baca dan patch kamus lokal aktif saat runtime dengan `$resolveTranslations()` dan `$setTranslation(key, value)`. Berguna untuk DevTools, pengujian, dan editor dalam aplikasi. Lihat [Metode](/api/methods#resolvetranslations).
- **`numberFormats` dan `datetimeFormats` bernama.** Konfigurasikan format bernama yang kompatibel dengan Vue I18n per lokal, lalu panggil `$tn(1000, 'currency')` atau `$td(date, 'short')`. Lihat [Opsi modul](/api/module-options).
- **Kontrol cache HTTP pada payload `/_locales`.** [`httpCacheDuration`](/api/module-options) baru mengatur `Cache-Control: public, max-age=…, immutable` pada payload terjemahan. Default satu tahun, dipasangkan dengan aman dengan cache-busting `?v={dateBuild}`.
- **Payload terjemahan terkompresi.** Saat `nitro.compressPublicAssets` diaktifkan, payload terjemahan publik dikompresi secara otomatis. Lihat [panduan Kinerja](/guides/performance).
- **Utilitas `splitLocaleRoutes`.** Bangun `pages` dan `globalLocaleRoutes` dari satu daftar programatis (untuk skenario `pages:extend`), dikunci berdasarkan nama rute. Lihat [Rute lokal kustom](/guides/custom-locale-routes#programmatic-routes-pagesextend--244).
- **Fallback `site.url` untuk basis SEO.** Saat `metaBaseUrl` tidak diatur, tag SEO kembali ke `site.url` dari `nuxt-site-config` jika ada, jika tidak, ke asal permintaan. Lihat [`metaBaseUrl`](/api/module-options).

## Pembaruan

- **Adaptor Astro.** Isolasi konteks perutean, ditambah wiring untuk `numberFormats` dan `datetimeFormats`.
- **React dan Preact.** `I18nSwitcher` sekarang mengatur atribut `aria-haspopup` dan `aria-expanded` yang benar.
- **Tolok ukur.** Tolok ukur kinerja dipindahkan ke CLI berbasis citty.
- **Sidik jari konten `dateBuild`.** `dateBuild` default sekarang adalah sidik jari konten, jadi payload `?v=` hanya berubah saat terjemahan benar-benar berubah.

## Perbaikan

- **Perutean.**
  - Pencocok rute lokal sekarang menangani jalur dengan tanda hubung, jalur bersarang, dan segmen berparameter dengan benar.
  - Parent bersarang dipertahankan saat rute child absolut.
  - `hreflang` dipancarkan dari `iso` lokal, bukan kode perutean.
  - Peralihan lokal di bawah `no_prefix` sekarang mengganti riwayat alih-alih mendorong.
- **Pengalihan.**
  - `autoDetectPath` dihormati untuk pengalihan preferensi cookie dan `Accept-Language`.
  - Alias `localeRoutes` dipertahankan di bawah `autoDetectPath: '/'`.
- **Terjemahan.**
  - Fungsi plural kustom yang mengembalikan `null` sekarang jatuh melalui aturan plural default.
  - Lapisan terjemahan digabungkan tanpa meratakan dump.
  - Lokal yang dinonaktifkan dihilangkan dari payload publik premerged.
  - HMR melewati penulisan file yang tidak ada operasinya dan menggabungkan ulang secara bersamaan pada perubahan lokal root.
- **Switcher.** Menyembunyikan lokal `disabled` dan memulihkan `customDisabledLinkStyle` serta prioritas gaya aktif.
- **Modul.** Menjembatani tipe `Plugin` unplugin Vite 8 untuk kompatibilitas Nuxt Kit.
- **SSR.** SSR Node sekarang membaca dari payload publik (tanpa impor Rollup `raw:`).

## Perubahan yang menghancurkan (v3.22.0)

- Chunk SSR dipindahkan dari `useState('i18n-ssr-chunks')` ke `nuxtApp.payload.data['i18n-ssr-chunks']`.
- `getAllTranslations()` dihapus dari `@i18n-micro/vue`. Gunakan `resolveTranslations()`, `getStorage()`, atau `getRouteCache()` sebagai gantinya.
- `dateBuild` default sekarang adalah sidik jari konten, jadi `?v=` payload akan berubah sekali saat peningkatan.
