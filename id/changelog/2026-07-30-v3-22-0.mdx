## Nuxt I18n Micro v3.22.0 — Format, Cache & Translation Memory {#nuxt-i18n-micro-v3-22-0-—-formats-cache-&-translation-memory}

**Tanggal**: 2026-07-30

**Versi**: `v3.22.0`

![Rilis v3.22.0](/images/3.22.0.png)

Kami mengumumkan **v3.22.0**: format angka/tanggal bernama bergaya Vue I18n dengan cache formatter, caching payload terjemahan yang ramah CDN (fingerprint konten + `httpCacheDuration`), dan API Translation Memory untuk membaca serta mengganti kamus aktif saat runtime.

## Apa yang Baru? {#what’s-new}

### `numberFormats` / `datetimeFormats` bernama + cache formatter {#named-numberformats-/-datetimeformats-+-formatter-cache}

Format bernama yang kompatibel dengan Vue I18n dan pemformatan Intl yang lebih cepat:

- Konfigurasi: `numberFormats` / `datetimeFormats` per locale
- API: `$tn(1000, 'currency')`, `$td(date, 'short')` (+ override locale dan penggabungan opsi)
- `FormatService` menyimpan cache `Intl.NumberFormat` / `DateTimeFormat` / `RelativeTimeFormat` berdasarkan locale+opsi

Lihat [Metode — `$tn` / `$td`](/id/api/methods#$tn) dan [Opsi modul](/id/api/module-options#numberformats).

### `dateBuild` secara default menggunakan fingerprint konten {#datebuild-defaults-to-a-content-fingerprint}

`?v=` pada permintaan `/_locales` sebelumnya secara default bernilai `Date.now()`, sementara respons disajikan sebagai `immutable` selama satu tahun. Akibatnya, setiap rebuild membatalkan kamus di setiap klien, bahkan ketika tidak ada terjemahan yang berubah.

Default-nya sekarang adalah fingerprint SHA-256 dari sumber terjemahan, sesuai urutan layer. Rebuild dengan terjemahan yang tidak diubah mempertahankan URL yang sama. Menetapkan `dateBuild` secara eksplisit tetap diutamakan. Lihat [Opsi modul — `dateBuild`](/id/api/module-options#datebuild).

### `httpCacheDuration` untuk payload `/_locales` {#httpcacheduration-for-/_locales-payloads}

Rute bawaan `/{apiBaseUrl}/:page/:locale/data.json` sekarang mengirimkan HTTP `Cache-Control` untuk browser dan CDN:

- Opsi: `httpCacheDuration` (detik, default `31536000` / 1 tahun)
- Header: `Cache-Control: public, max-age=…, immutable`
- Aman digunakan bersama cache-busting `dateBuild` yang ada (`?v=...`); `0` menonaktifkan header; tidak diterapkan di mode development

Analog dari `experimental.httpCacheDuration` di `@nuxtjs/i18n` v10.2.0, sebagai header respons eksplisit.

### Payload publik terkompresi {#compressed-public-payloads}

`nitro.compressPublicAssets` sekarang juga berlaku untuk payload terjemahan yang disalin ke direktori public (`.gz` + `.br`). Nitro mengompresi aset publik sebelum penyalinan terjadi, sehingga sebelumnya payload tersebut menjadi satu-satunya bagian yang tidak terkompresi dari build statis — 6,65 MB mentah dibandingkan 1,01 MB gzip pada index playground. Modul tetap tidak pernah mengaktifkan kompresi dengan sendirinya. Lihat [Performa](/id/guide/performance#payload-size).

### `resolveTranslations()` dan `setTranslation(key, value)` {#resolvetranslations-and-settranslationkey-value}

Helper runtime untuk membaca dan mengganti kamus terjemahan aktif di memori:

- **`resolveTranslations()`** mengembalikan seluruh pohon yang dibaca oleh `$t()` untuk locale dan rute yang aktif — berguna untuk DevTools, pengujian, dan editor runtime. Ketika layer kedua aktif (locale fallback atau hot-reload transisi halaman Nuxt), hasil dump mempertahankan bentuk bersarang melalui `mergeTranslationLayers` dan hanya menggunakan kunci bertitik datar untuk benturan skalar-vs-objek yang tidak dapat diekspresikan oleh satu pohon.
- **`setTranslation(key, value)`** mengganti nilai pada sebuah kunci (tingkat atas, path bertitik, objek, string, atau skalar). Ini adalah **penggantian**, bukan penggabungan; gunakan `$mergeTranslations` bila kunci saudara harus tetap ada.
- Tersedia di `useI18n()`, `useNuxtApp()`, dan instance i18n framework yang diwarisi dari `@i18n-micro/core`.
- `@i18n-micro/test-utils` menambahkan helper `resolveTranslations` / `setTranslation` yang sesuai untuk unit test.

### `getAllTranslations()` dihapus dari paket Vue {#getalltranslations-removed-from-vue-package}

Gunakan `resolveTranslations()` untuk pohon lookup yang aktif. Untuk dump storage lengkap di Vue, gunakan `getStorage()` atau `getRouteCache()`.

## Perubahan yang Merusak Kompatibilitas {#breaking-changes}

Tidak ada bagian dari konfigurasi publik yang mengharuskan perubahan kode aplikasi untuk penggunaan umum. Hal-hal berikut penting jika Anda mengakses internal runtime:

- **Payload SSR dipindahkan dari `useState('i18n-ssr-chunks')` ke `nuxtApp.payload.data['i18n-ssr-chunks']`.** Payload ini tetap membawa **chunk terjemahan lengkap** untuk setiap `(locale, route)` yang dimuat selama SSR — kamus yang sama seperti sebelumnya, di slot yang dapat dieksternalisasi Nuxt ke `_payload.json` saat prerender. `useState('i18n-ssr-chunks')` sekarang tidak mengembalikan apa pun. Membaca terjemahan dengan cara itu tidak pernah didukung, tetapi hal tersebut dijelaskan di dokumentasi API cache, sehingga disebutkan di sini.
- **`NuxtTranslationLoaderOptions` mengekspos `setSsrChunk`.** Loader menulis setiap chunk yang telah digabung ke `payload.data` di server saat memuatnya. `getSsrChunks` tidak digunakan.
- **`nitro.compressPublicAssets` sekarang menghasilkan `.gz` / `.br` di samping payload yang disalin.** Akan ada lebih banyak file di output public jika Anda mengaktifkannya. Tooling deploy yang menelusuri direktori terjemahan mungkin perlu memperhitungkannya.
- **URL payload berubah sekali saat upgrade**, karena `?v=` beralih dari timestamp build ke fingerprint konten. Klien mengunduh ulang kamus pada permintaan pertama setelah upgrade lalu menyimpannya di deploy berikutnya — dan memang itulah tujuannya.
- **`getAllTranslations()` dihapus dari `@i18n-micro/vue`.** Gunakan `resolveTranslations()` / `getStorage()` / `getRouteCache()` sebagai gantinya.

## Perbaikan Bug {#bug-fixes}

- **`<i18n-switcher>`** — menghilangkan locale dengan `disabled: true` dari dropdown. `$getLocales()` tetap mengembalikan daftar lengkap untuk kode Anda sendiri, sementara output SEO/meta bawaan mengecualikan locale yang dinonaktifkan.
- **Gaya switcher** — `cursor: not-allowed` diterapkan pada locale **saat ini** melalui `activeLinkStyle` / `customActiveLinkStyle`; `customDisabledLinkStyle` dipulihkan untuk kompatibilitas mundur dan diterapkan pada tombol switcher ketika locale saat ini memiliki `disabled: true`.
- **Dev HMR** — penulisan yang tidak mengubah isi file (save-on-blur editor, penulisan ulang oleh formatter) tidak lagi memicu penggabungan ulang. Perubahan locale root membangun ulang setiap halaman untuk locale tersebut, sehingga hal ini mahal jika dilakukan untuk operasi yang tidak mengubah apa pun.
- **Dev HMR** — halaman digabung ulang secara bersamaan saat terjadi perubahan locale root, bukan satu per satu.
- **Transisi halaman** — navigasi dalam locale yang sama mempertahankan chunk yang keluar sebagai layer fallthrough hingga `page:transition:finish`, alih-alih melakukan deep merge yang mahal di setiap navigasi.

## Mengapa Ini Penting {#why-it-matters}

- Pemformatan bergaya Vue I18n tanpa perlu menarik stack yang lebih berat.
- URL terjemahan ramah CDN yang tetap stabil di setiap rebuild ketika kamus tidak berubah.
- API runtime yang didukung untuk memeriksa dan menambal kamus aktif — DevTools, pengujian, dan editor tidak lagi memerlukan helper privat.
