**Tanggal**: 2026-06-25

**Versi**: `v3.21.0`

![v3.21.0 release](/images/3.21.0.png)

Rilis ini menambahkan **`useI18nHead`** — composable tingkat halaman untuk menimpa SEO i18n di atas plugin bawaan `02.meta`. Sesuaikan `hreflang`, canonical, `og:url`, dan tag Open Graph per rute tanpa plugin meta kustom atau `meta: false`.

## Apa yang Baru? {#what’s-new}

### Composable `useI18nHead` {#usei18nhead-composable}

Panggil `useI18nHead` di halaman mana pun saat `meta: true` (default). Modul menggabungkan input Anda setelah `useLocaleHead` pada setiap pembaruan rute:

```vue
<script setup lang="ts">
useI18nHead(() => ({
  meta: [{ property: 'og:title', content: article.value?.title }],
  replace: {
    canonical: article.value?.canonicalUrl,
    ogUrl: article.value?.canonicalUrl,
    hreflang: localeCodes.map((locale) => ({
      rel: 'alternate',
      hreflang: locale,
      href: article.value!.locales[locale]!,
    })),
    ogAlternates: localeCodes,
  },
}))
</script>
```

Mendukung objek statis, getter reaktif, penambahan `meta` / `link`, `replace` untuk grup bawaan, dan `disable` untuk menghapus tag yang dihasilkan otomatis. Lihat [`useI18nHead`](/id/composables/useI18nHead).

### Utilitas `mergeI18nHead` (`@i18n-micro/utils`) {#mergei18nhead-utility-@i18n-micro/utils}

Logika penggabungan yang tidak bergantung pada framework berada di `@i18n-micro/utils/merge-i18n-head` — digunakan oleh plugin `02.meta` dan dapat diuji secara terpisah. Tipe (`I18nHeadInput`, `I18nHeadLink`, `I18nHeadMeta`) diekspor dari `@i18n-micro/types`.

### Integrasi Plugin {#plugin-integration}

- **`02.meta`** — menggabungkan output `useLocaleHead` dengan state halaman dari `useI18nHead` melalui `useHead`
- **`01.plugin`** — mereset penimpaan halaman saat nama rute berubah melalui `resetPageHead()` (state bersama dengan composable)

### Dokumentasi & Pengujian {#documentation-&-tests}

- Panduan baru: [`useI18nHead`](/id/composables/useI18nHead) dengan contoh CMS/artikel
- Pembaruan [SEO](/id/guide/seo) dan [`useLocaleHead`](/id/composables/useLocaleHead) — kapan menggunakan API yang mana
- Cakupan Playwright + Vitest: SSR, navigasi SPA, reload, `nuxi generate`, alternate parsial, `x-default`, pemuatan klien reaktif

## Kasus Penggunaan Umum {#typical-use-cases}

| Skenario                                     | Pendekatan                                                     |
| -------------------------------------------- | -------------------------------------------------------------- |
| Blog/CMS dengan terjemahan parsial           | `replace.hreflang` + `replace.ogAlternates` dari locale API    |
| Canonical kustom dari CMS                    | `replace.canonical` + `replace.ogUrl`                          |
| Hanya OG untuk landing page                  | `meta: [{ property: 'og:title', ... }]` — pertahankan hreflang modul |
| Tanpa hreflang di suatu halaman              | `disable: ['hreflang', 'x-default']`                           |
| Mengganti plugin kustom (`i18nManualHreflang`) | `useI18nHead` per halaman konten + `meta: true`              |

**JSON-LD** tetap berada di `useHead({ script: [...] })` — `useI18nHead` tidak menghasilkan data terstruktur.

## Perubahan yang Merusak Kompatibilitas {#breaking-changes}

Tidak ada untuk penggunaan `nuxt.config` standar. Composable baru dan subpath utils bersifat tambahan.

## Mengapa Ini Penting {#why-it-matters}

- **Tanpa plugin meta kustom** untuk postingan CMS, berita, atau panduan dengan URL per locale
- **Satu pipeline** — default modul + penimpaan halaman dalam satu panggilan `useHead`
- **Type-safe** — `I18nHeadInput` untuk helper seperti `buildArticleHead(content)`
