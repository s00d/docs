**Tanggal**: 2025-12-07

**Versi**: `v2.14.1`

![Rilis v2.14](/images/2.14.0.png)

Kami dengan senang hati mengumumkan **v2.14.1** dengan integrasi baru untuk Node.js, Vue 3, dan Astro! Paket-paket ini menghadirkan kemampuan i18n yang sama andalnya ke framework favorit Anda, dengan berbagi logika inti yang sama demi konsistensi dan performa.

## Apa yang Baru? {#what’s-new}

- **@i18n-micro/node** - Gunakan terjemahan i18n di aplikasi Node.js, alat CLI, atau layanan backend apa pun
- **@i18n-micro/vue** - Plugin Vue 3 untuk internasionalisasi dengan terjemahan reaktif dan dukungan per rute
- **@i18n-micro/astro** - Integrasi Astro untuk internasionalisasi dengan dukungan TypeScript penuh
- **@i18n-micro/types-generator** - Pembuatan tipe TypeScript otomatis untuk kunci terjemahan dengan type safety penuh dan autocomplete IDE

## Fitur Utama {#key-features}

Semua integrasi memiliki manfaat inti yang sama:

- Ringan dan berperforma tinggi
- Dukungan terjemahan per rute
- Pluralisasi bawaan
- Pemformatan angka, tanggal, dan waktu relatif
- Dukungan TypeScript penuh
- Struktur file terjemahan JSON yang sama

**Types Generator** memberikan peningkatan pengalaman pengembang tambahan:

- Pembuatan tipe otomatis dari file terjemahan JSON
- Kunci terjemahan yang type-safe dengan validasi saat kompilasi
- Dukungan autocomplete IDE penuh
- Hot reload saat file terjemahan berubah
- Tanpa overhead runtime

Untuk dokumentasi dan contoh terperinci, kunjungi [repositori](https://github.com/s00d/nuxt-i18n-micro) atau lihat [dokumentasi](https://s00d.github.io/nuxt-i18n-micro/).
