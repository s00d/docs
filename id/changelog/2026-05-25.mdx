**Tanggal**: 2026-05-25

**Versi**: `v3.19.0`

![Rilis v3.19.0](/images/3.19.0.png)

Rilis ini berfokus pada **modularisasi utilitas internal**, penambahan **mode payload serverless yang ringkas**, dan **penggunaan ulang logika bersama** di Nuxt, Node, Astro, dan DevTools — tanpa mengubah API modul publik untuk aplikasi pada umumnya.

## Apa yang Baru? {#what’s-new}

### `@i18n-micro/utils` — Utilitas Agnostik Framework {#@i18n-micro/utils-—-framework-agnostic-utilities}

Logika bersama yang sebelumnya tersebar di `src/runtime/utils/` dan `src/module.ts` kini berada dalam paket workspace khusus dengan **impor subpath granular** (tanpa barrel besar, ramah tree-shake):

- **Build** — `preMergeLocales`, `buildTranslationSourceLayers` (`@i18n-micro/utils/build`)
- **Payload** — resolusi `translationPayloads`, pembuatan URL, helper fetch, statistik (`payload-config`, `payload-url`, `payload-fetch`, `payload-stats`)
- **Mode source** — rantai fallback, path file source, merge saat runtime (`merge-source`, `source-loader`)
- **Helper runtime** — resolusi locale, cookie, parsing Accept-Language, helper route/meta (`resolve-locale`, `accept-language`, `cookie`, `route`, `route-pattern`, `runtime-config`)
- **Path FS bersama** — klasifikasi file terjemahan, path halaman bersarang (`parse-path`)

Modul Nuxt menyimpan perekat tipis di `src/runtime/` dan hanya mengimpor subpath yang dibutuhkannya.

### `@i18n-micro/hmr` — Hot Reload Terjemahan saat Dev {#@i18n-micro/hmr-—-dev-translation-hot-reload}

HMR untuk pengembangan diekstrak ke `@i18n-micro/hmr`:

- **`watcher`** — penanganan perubahan file, invalidasi cache, merge source/premerged saat dev
- **`generate-plugin`** — pembuatan plugin HMR sisi klien
- **`cache-keys`** — kunci `Symbol.for` bersama untuk cache server/storage

Berfungsi dengan `translationPayloads.mode: 'premerged'` maupun `'source'`.

### `translationPayloads.mode: 'source'` — Deployment Serverless yang Ringkas {#translationpayloads-mode-‘source’-—-compact-serverless-deployments}

Mode payload baru untuk matriks locale besar di platform serverless (Cloudflare Workers, dll.):

```typescript
export default defineNuxtConfig({
  i18n: {
    translationPayloads: {
      mode: 'source',
    },
  },
})
```

- Membundel **file source yang ringkas** ke dalam aset Nitro alih-alih matriks pre-merged lengkap
- Menggabungkan rantai locale root, halaman, dan fallback **saat runtime** melalui route bawaan `/_locales/:page/:locale/data.json`
- Default `publicAssets` dan `prerenderRoutes` menjadi `false` — ideal jika Anda mengandalkan runtime Nitro/edge alih-alih hosting statis murni

Lihat [Deployment — serverless dan Edge](/id/guide/deployment#serverless-and-edge) dan [Arsitektur Cache & Storage](https://s00d.github.io/nuxt-i18n-micro/v3/api/i18n-cache-api).

### Utilitas Bersama di Seluruh Paket Integrasi {#shared-utilities-across-integration-packages}

- **`@i18n-micro/node`** dan **`@i18n-micro/astro`** — parsing path terjemahan dan deep merge yang disatukan melalui `@i18n-micro/utils/parse-path`
- **`@i18n-micro/astro`** — `detectLocaleFromAcceptLanguage` dari `@i18n-micro/utils/accept-language` (parser duplikat dihapus)
- **`@i18n-micro/devtools-ui`** — path file virtual melalui helper `merge-source` + `parse-path`
- **Deteksi locale server** — penanganan Accept-Language diselaraskan dengan utils bersama

### Perbaikan HMR & DevTools {#hmr-&-devtools-fixes}

- Plugin HMR klien kini memanggil **`$loadPageTranslations`** (API yang benar) alih-alih `$loadTranslations` yang sudah dihapus
- Cakupan Playwright untuk watcher terjemahan dalam mode **premerged** dan **source**

## Perubahan yang Merusak (Lanjutan / Internal) {#breaking-changes-advanced-/-internal}

Ini hanya memengaruhi proyek yang mengimpor path modul **internal** (bukan bagian dari API publik):

- Dihapus dari `src/runtime/utils/`: `route-utils.ts`, `runtime-i18n-config.ts`, dan utilitas lain yang dipindahkan ke `@i18n-micro/utils/*`
- Dihapus dari `src/runtime/server/plugins/`: watcher/generator HMR inline — gunakan `@i18n-micro/hmr/*` jika Anda mem-fork tooling dev
- **`nuxt-i18n-micro`** kini bergantung pada paket workspace `@i18n-micro/utils` dan `@i18n-micro/hmr` (terpasang otomatis bersama modul)

Penggunaan `nuxt.config` + composable yang umum tidak berubah.

## Mengapa Ini Penting {#why-it-matters}

- **Bundel serverless lebih kecil** — mode `source` menghindari pengiriman file pre-merged per locale × halaman
- **Satu sumber kebenaran** — satu implementasi untuk parsing path, merge, deteksi locale, dan konfigurasi payload
- **Pemeliharaan lebih mudah** — kode agnostik framework diuji di `@i18n-micro/utils` (50+ unit test) dan digunakan ulang di mana-mana
- **UX dev lebih baik** — logika HMR terisolasi, dapat diuji, dan konsisten di semua mode payload
