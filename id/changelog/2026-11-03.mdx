**Tanggal**: 2026-11-03

**Versi**: `v4.0.0`

![Rilis v4.0.0](/images/4.0.0.png)

**v4.0.0** telah dirilis. Routing, inti terjemahan, file kamus, deteksi locale, dan setiap paket framework ditulis ulang. Opsi, `$t`, `$localePath`, `$switchLocale`, komponen, dan composable tetap mempertahankan namanya. Yang berubah adalah perilakunya, dan sebagian besar perubahan tersebut adalah bug yang kini sudah hilang. Sebagian besar app hanya membutuhkan sedikit perubahan kode, tetapi baca [Perubahan yang Merusak Kompatibilitas](#breaking-changes) sebelum Anda upgrade: URL, tag SEO, dan API paket framework berubah di beberapa tempat. [Upgrade](/id/guide/upgrade) berisi setiap detailnya.

## Apa yang Baru? {#what’s-new}

### Satu Build untuk Setiap Domain {#one-build-for-every-domain}

`locales[].baseUrl` dan `baseDefault` dulu hanya membentuk link. Kini keduanya juga merutekan request, di bawah keempat strategi dan di `nuxt generate`:

```ts
export default defineNuxtConfig({
  i18n: {
    locales: [
      { code: 'en', baseUrl: 'https://example.com', baseDefault: true },
      { code: 'fr', baseUrl: 'https://example.com' },
      { code: 'de', baseUrl: 'https://example.de', baseDefault: true },
    ],
  },
})
```

- Sebuah host melayani locale miliknya sendiri. Link ke locale milik domain lain menjadi URL absolut di domain tersebut, dan beralih ke locale itu akan bernavigasi ke sana.
- `trustForwardedHost` memilih domain dari `X-Forwarded-Host` di belakang proxy yang menimpanya. Nonaktif secara default.
- `NUXT_I18N_DOMAIN` memberikan host kepada `nuxt generate`: jalankan sekali per domain, dan setiap output hanya berisi halaman dan kamus milik domain tersebut.
- App tanpa `baseUrl` tidak menyertakan kode ini sama sekali.

Lihat [Layer dan domain](/id/guide/layers#multiple-domains) dan [Deployment](/id/guide/deployment).

### Routing yang Selaras dengan Router {#routing-that-agrees-with-the-router}

Build dan runtime tidak lagi menghitung URL terlokalisasi secara terpisah. Setiap jawaban berasal dari route yang dihasilkan build, sehingga link, switcher, `hreflang`, dan redirect tidak dapat mengarah ke halaman yang tidak ada.

- Locale yang tidak melayani sebuah halaman akan menautkan ke halaman utamanya, tidak pernah ke halaman milik locale lain.
- `hreflang` hanya mencantumkan locale yang melayani halaman tersebut.
- `$switchLocale` me-resolve `true` atau `false`, sehingga Anda dapat mengetahui kapan kamus gagal dimuat. Pemanggilan ulang akan mencoba lagi.
- `$setI18nRouteParams` dan `useI18nHead` yang diatur selama SSR tetap bertahan setelah hidrasi. Switcher menautkan ke slug yang diterjemahkan, termasuk di HTML server.
- Navigasi berlaku saat di-commit: navigasi yang dibatalkan atau diblokir tidak mengubah apa pun.
- Hash mode berfungsi di bawah `prefix`.
- `<Greeting :locale="$getLocale()" />` pada server component mengatur locale render-nya.

### Satu Deteksi Locale {#one-locale-detection}

Satu urutan di mana-mana, di server, di browser, di helper API server, dan di Astro. `Accept-Language` memperhatikan nilai `q`, pencocokan regional tidak lagi bergantung pada urutan `locales`, dan tidak pernah melintasi aksara Tionghoa. Override runtime kini menjangkau routing: `NUXT_I18N_DEFAULT_LOCALE` dan `disabledLocales` runtime mengubah apa yang benar-benar dilayani. Lihat [Deteksi locale](/id/guide/locale-detection).

### Satu Kamus di Setiap Mode {#one-dictionary-in-every-mode}

Build premerged, `mode: 'source'`, dan dev dulu memberikan hasil berbeda di banyak halaman. Kini semuanya memberikan kamus yang sama.

- Penggabungan bersifat dalam (deep) di setiap tingkat, dan rantai fallback (`fr` → `de` → `en`) diikuti sampai akhir.
- Pengeditan terjemahan di dev diterapkan langsung, tanpa reload halaman. Key yang dihapus menghilang, dan pengeditan file root menjangkau setiap halaman.
- `$clearCache()` memuat ulang halaman saat ini dan mempertahankan teks lama di layar sampai teks baru tiba.
- Chunk yang gagal mempertahankan kamus saat ini alih-alih menampilkan key mentah.

### File Kamus yang Lebih Kecil {#smaller-dictionary-files}

- File sebuah halaman kini hanya berisi apa yang berbeda dari root locale, di `__root/<locale>/data.json`. Browser memuat root sekali dan menggabungkan setiap halaman di atasnya, sehingga penggunaan disk berkurang dan halaman berikutnya hanya membutuhkan sebagian kecil dari biaya halaman pertama.
- URL kamus membawa versi. URL dengan `?v=` saat ini disematkan selama satu tahun di server Node, dan salinan statis milik host menjawab `max-age=60`. Lihat [Header cache](/id/guide/deployment#cache-headers-and-datebuild).
- Setiap halaman SSR melakukan preload file kamusnya, sehingga file tersebut mulai dimuat bersama HTML.
- Pembacaan yang gagal tidak lagi menetap: request berikutnya membaca lagi. Lihat [Ketika kamus tidak dapat dibaca](/id/guide/deployment#when-a-dictionary-cannot-be-read).

### `<i18n-t>`, Bentuk Jamak, dan Format yang Lebih Baik {#better-&lt;i18n-t&gt;-plurals-and-formats}

- Slot berfungsi dengan `plural`, `number`, `date`, dan `relativeDate`, dan setiap `{name}` diisi, bukan hanya yang pertama.
- `<i18n-t>` adalah satu renderer di Nuxt, Vue, React, Preact, Solid, dan Astro.
- Bentuk pertama yang diawali `=0 ` adalah bentuk nol eksplisit, dan sisanya mengikuti `Intl.PluralRules`: `=0 no apples | one apple | {count} apples`. Lihat [`$tc`](/id/api/methods#$tc).
- Opsi baru `timeZone`: satu tanggal kalender yang sama di server dan di setiap browser.
- `{firstName}`, `{first-name}`, dan `{user.name}` adalah placeholder yang valid.
- `$tn`, `$td`, dan `$tdr` mengikuti `iso`, seperti halnya bentuk jamak.
- `$tdr` memberikan tanggal masa depan yang sebenarnya: `in 3 days`, atau `tomorrow` dengan `numeric: 'auto'`.

### Lebih Aman secara Default {#safer-by-default}

- `<i18n-t html>` meng-escape `params`. Hanya terjemahannya yang dipercaya sebagai markup.
- Tidak ada link yang meninggalkan origin secara tidak sengaja: `//host`, `/\host`, dan nilai kosong tetap berada di situs ini.
- Cache terjemahan server dibatasi, sehingga URL dengan nama halaman karangan tidak dapat memperbesar memori.
- Endpoint penyimpanan DevTools hanya menerima file `.json` yang sudah ada di dalam direktori terjemahan Anda, dan menolak request lintas situs.

### Paket Framework di 2.0 {#framework-packages-at-2-0}

- **React, Preact, Solid:** `I18nT` menerima prop `components` untuk rich text. `useT` dan `useLocaleSwitch` baru, serta dukungan React Server Components melalui `@i18n-micro/react/server` dan `/client`. Preact tidak lagi membutuhkan `preact/compat`.
- **Vue dan VitePress:** `I18nLink` mempertahankan `name`, `query`, dan `hash`, dan VitePress menghormati `base`.
- **Astro:** `i18nIntegration` membundel kamus Anda dan memasang middleware. Entry utama tidak memiliki import `node:*`, sehingga dapat berjalan di edge. `base` berfungsi.
- **Node dan runtime:** `fork(locale)` memberikan instance per request yang murah, dan `run(locale, fn)` di `@i18n-micro/node` membatasi satu instance pada sebuah request.
- **`@i18n-micro/types-generator`:** tanpa dependensi pihak ketiga, dan berupa plugin Vite dan Rollup biasa.
- **`@i18n-micro/devtools-ui`:** pembaruan langsung melalui socket Vite, dan app toolbar Astro.

### `@i18n-micro/cli` {#@i18n-micro/cli}

CLI kini berada di monorepo sebagai `@i18n-micro/cli`, ditulis ulang dengan 16 perintah alih-alih 28 dan jauh lebih sedikit dependensi. `check` menggantikan `validate`, `diff`, dan `check-duplicates`, dengan `--json` dan kode keluar untuk CI. Ketika tidak dapat membuktikan bahwa sebuah key tidak digunakan, `clean` tidak menulis apa pun. Lihat [CLI](/id/guide/cli).

### Dokumentasi {#documentation}

Dokumentasi ditulis ulang dari kode di sekitar satu alur bacaan: instalasi, halaman terjemahan pertama, file terjemahan, routing, deteksi, lalu panduan tugas. URL lama di-redirect. [Upgrade](/id/guide/upgrade) mencantumkan setiap perubahan secara detail.

## Kecepatan dan Ukuran {#speed-and-size}

- Render server membaca kamus secara langsung, tanpa request HTTP lokal dan tanpa parsing ulang.
- `dir="auto"` tidak lagi menjadi default. Browser menghabiskan waktu lama untuk itu di halaman besar: dengan 20.000 elemen `$t`, DOMContentLoaded di Chromium turun dari sekitar 980 ms menjadi sekitar 115 ms.
- `serverTranslationPreload` dan `i18n:register` tidak lagi memperlambat setiap request.
- Bundle klien membuang `useCookie` ketika tidak ada cookie yang dikonfigurasi, dan `@i18n-micro/path-strategy` hanya sebagian kecil dari ukuran lamanya.

## Perubahan yang Merusak Kompatibilitas {#breaking-changes}

### Persyaratan {#requirements}

- **Nuxt 3.18 atau lebih baru**, dan **Node 20 atau lebih baru**.
- **`@i18n-micro/test-utils`** tidak lagi dipasang bersama modul. Tambahkan sendiri jika test Anda mengimpornya.
- **`@i18n-micro/hmr`** sudah tidak ada: HMR terjemahan sudah bawaan. Hapus paket tersebut jika Anda memasangnya.
- **`@i18n-micro/react`** membutuhkan React 18 atau lebih baru.
- **`nuxt-i18n-micro-cli`** digantikan oleh `@i18n-micro/cli`.

### Opsi dan Konfigurasi {#options-and-config}

- `i18n-plugin-hooks` dan `i18n-plugin-define` di dalam `dependsOn` tidak lagi menunggu apa pun, tanpa error. Gunakan `i18n-plugin-loader`.
- Auto-import server adalah `useLocaleServerMiddleware`, `useTranslationServerMiddleware`, `loadTranslationsFromServer`, dan `detectCurrentLocale`. Yang lain tidak lagi diimpor otomatis.
- `resolveTranslationPayloadMode` dan helper `resolveTranslationPayload*` lainnya sudah dihapus dari `nuxt-i18n-micro`, bersama `shouldCopyTranslationPayloadsToPublic` dan `shouldRegisterNitroServerAssets`. Tipe `TranslationPayloadMode` tetap ada.
- `$getI18nConfig()` tidak lagi memiliki `isSSG`, `hmr`, `hooks`, `noPrefixRedirect`, `routeLocales`, `routeDisableMeta`, atau `globalLocaleRoutes`. Opsi-opsinya sendiri tidak berubah.
- `locales[].baseUrl` kini merutekan request: locale milik domain lain menghasilkan 404 di host ini, dan link di host yang sama bersifat relatif. Pada build semacam itu `$getI18nConfig().locales` berisi apa yang dilayani host, dan `linkLocales` berisi semuanya.
- `baseUrl` juga mengatur origin di host lain mana pun: canonical dan `hreflang` menggunakan `metaBaseUrl` jika diatur, jika tidak, `baseUrl` milik locale default, bukan origin request.
- `excludePatterns` mencocokkan segmen utuh (`'/admin'` tidak lagi cocok dengan `/administrator`), glob dijangkarkan, dan pola `RegExp` kini menjangkau runtime.
- `cacheMaxSize` yang tidak diatur berarti maksimal 1000 entri di server. `cacheTtl` dihitung sejak entri disimpan, dan pembacaan tidak lagi memperpanjangnya.
- Di bawah `no_prefix`, `localeCookie: null` yang eksplisit di konfigurasi `i18n` tetap nonaktif.
- Di bawah `prefix_except_default` dan `prefix_and_default`, `defaultLocale` runtime diabaikan dengan peringatan. `fallbackLocale` runtime harus berupa locale yang aktif.
- `routeDisableMeta` di `nuxt.config` dihormati, dan entri `nuxt.config` mengalahkan `$defineI18nRoute` dalam bentuk key apa pun.
- Di server dalam mode dev, konfigurasi yang sudah di-resolve dibekukan: penulisan ke dalamnya akan melempar error.
- Entri `locales` milik proyek mengalahkan milik layer untuk `code` yang sama.

### Composable dan Metode `$` {#composables-and-$-methods}

- `$switchLocale` me-resolve `true` atau `false`, sebelumnya tidak me-resolve apa pun. `$switchRoute` bertipe `Promise<void>`.
- `$localeRoute`, `$switchLocalePath`, dan switcher menautkan locale yang tidak melayani sebuah halaman ke halaman utama locale tersebut.
- `$localePath` mengembalikan string dengan skema `http(s):`, `mailto:`, atau `tel:` apa adanya, dan `$localeRoute` membawanya di `path` dan `fullPath`. Jangan meneruskan nilai yang belum diperiksa kepada keduanya sebagai target link. `//host` dan nama polos seperti `x.com` tetap menjadi path di origin ini.
- Link tanpa path tetap berada di halaman saat ini: `$localePath('#top')`, `'?p=2'`, `''`, dan `{ query }`. `'#top'` dulu dibaca dari root situs. `'about'` polos tetap berarti `/about`.
- `$switchRoute` tetap berada di dalam app. Hanya `baseUrl` milik locale itu sendiri, `mailto:`, dan `tel:` yang meninggalkannya.
- Link ke locale dengan `baseUrl` melalui `$localePath` atau `<i18n-link>`. `<NuxtLink :to="$localeRoute(x, 'fr')">` dan `router.push($localeRoute(x, 'fr'))` tetap menjadi path di app ini. Di dalam kode gunakan `navigateTo($localePath(x, 'fr'), { external: true })`.
- `$switchLocaleRoute` dan redirect mengikuti `trailingSlash`.
- `$setI18nRouteParams` dan `useI18nHead` yang diatur di server dibuang ketika navigasi mengubah path, termasuk `/news/1` ke `/news/4`: atur lagi di halaman baru.
- `$setI18nRouteParams` yang dibaca di setup terikat pada halaman tersebut: pemanggilan terlambat dari halaman yang sudah ditinggalkan tidak melakukan apa pun. Fungsi ini tidak memiliki setter, jadi stub `useI18n` itu sendiri di test.
- `useI18n()` mengembalikan satu objek per app. Menulis ke objek tersebut menjangkau setiap pemanggil.
- Kamus, locale, params, dan head berubah saat navigasi di-commit. `beforeResolve`, `beforeRouteEnter`, atau global guard yang lebih belakangan melihat nilai yang lama. Route middleware tidak terpengaruh.
- `$switchLocale` memulihkan locale yang tersimpan ketika navigasinya dibatalkan, di bawah strategi URL.
- `$t` menginterpolasi `defaultValue`: `$t('missing', { n: 1 }, 'Got {n}')` menghasilkan `Got 1`. `$tc` juga, dan pada terjemahan kosong ia menjawab `''`.
- `$has(key, route)` menghormati route.
- `$clearCache()` memuat ulang kamus halaman saat ini.
- Placeholder `{param}` hanya membaca params yang Anda teruskan: `{constructor}` tetap seperti yang ditulis.
- `$tc` dengan jumlah negatif, pecahan, atau sangat besar mengambil bentuk terakhir dengan jumlah yang sebenarnya. `{ count: null }` tidak lagi melempar error, dan key jamak yang hilang menjangkau missing handler.
- `$tdr` memberikan `Invalid Date` untuk input yang tidak valid. Kurang dari satu detik di masa lalu adalah `0 seconds ago`.
- `$tn`, `$td`, dan `$tdr` mengikuti `iso`: `{ code: 'en', iso: 'en-GB' }` memformat tanggal sebagai `31/10/2026`. Kode yang tidak dikenal `Intl` diformat sebagai `en`, dan bentuk jamaknya mengikuti aturan indeks: atur `iso` (`{ code: 'ua', iso: 'uk-UA' }`).
- `detectCurrentLocale` sudah usang (deprecated): gunakan `useLocaleServerMiddleware(event).current`.

### Bentuk Jamak {#plurals}

Template mempertahankan maknanya, dengan satu pengecualian. Bentuk nol tanpa placeholder, lalu satu bentuk per kategori, dengan `{count}` di setiap bentuk yang digunakan oleh beberapa jumlah, kini mengikuti kategori di locale dengan tiga kategori atau lebih (`ru`, `uk`, `pl`, `cs`, `ar`, dan lainnya): `none | {count} one | {count} few | {count} many` menghasilkan `3 few` dan `21 one` di `uk`. Untuk menggunakan kategori di template lain, tambahkan penanda `=0 `. Aturan `plural` kustom membaca nilai mentah, sehingga template yang bertanda menjangkaunya dengan `=0 ` tetap di tempatnya. Lihat [tabel di Upgrade](/id/guide/upgrade#plurals-and-formatting).

### Komponen {#components}

**`<i18n-t>`**

- `html` meng-escape `params` dalam setiap kasus dan mengabaikan semua slot.
- Slot mengalahkan param dengan nama yang sama.
- `null` berarti tidak diatur untuk `plural`, `number`, `date`, dan `relativeDate`.
- `plural` menghitung seperti `$tc`, dengan `Number`: `1.5` tetap `1.5`, `"2 items"` adalah `NaN`, `""` adalah `0`.
- `number`, `date`, dan `relativeDate` mempertahankan `params`.
- `hideIfEmpty` berlaku di setiap cabang, dan `defaultValue` menggantikan key yang hilang di setiap cabang.
- Key yang hilang di bawah `html` adalah teks yang di-escape.
- Output `date` dan `relativeDate` membawa `data-allow-mismatch="text"`, dan di samping slot bernama teksnya berada di `<span>` tersendiri.
- Atribut `.innerHTML` dan `textContent` dibuang.
- Komponen ini adalah functional component: `ref` padanya tidak memberikan instance.
- `<i18n-t>` dan `<i18n-group>` membaca kamus aktif, seperti halnya `$t`.

**`<i18n-switcher>`**

- Link adalah `<a>` biasa yang memanggil `$switchLocale`, sehingga class `router-link-active` sudah tidak ada.
- Tombolnya adalah `type="button"` dengan `aria-expanded`. Escape dan klik di luar menutup dropdown.
- Class baru `i18n-switcher-wrapper`, `i18n-switcher-dropdown`, dan `i18n-switcher-button`. Setiap link memiliki `lang`, dan `dir` ketika locale mengaturnya.
- Style default menggunakan properti CSS logis, dan dropdown memiliki `z-index` yang lebih besar, lebar minimum, dan bayangan.
- Server menulis ulang link-nya ketika render selesai, pada halaman dengan params. Link `$switchLocalePath` yang ditulis manual tidak ditulis ulang.

**`<i18n-link>`**

- `https://`, `mailto:`, dan `tel:` dicocokkan tanpa memperhatikan huruf besar/kecil. `report.pdf` polos adalah route, dan `example.com` tetap eksternal. Akhiran file yang juga merupakan TLD (`example.md`) dihitung sebagai file: tulis `https://`.
- `activeStyle` mengabaikan garis miring di akhir, query, dan hash.

### Hook dan Tipe {#hooks-and-types}

- `i18n:register` adalah hook runtime: `nuxtApp.hook('i18n:register', …)` di dalam plugin.
- Tipe yang diekspor `ModuleHooks` diganti namanya menjadi `ModuleRuntimeHooks`.
- `i18n:beforeLocaleSwitch` dan `i18n:afterLocaleSwitch` tidak pernah dipancarkan dan tidak lagi didokumentasikan.
- `ModuleOptionsExtend.isSSG` bersifat opsional dan usang: tidak ada yang mengaturnya.

### URL dan Redirect {#urls-and-redirects}

- **`/en` dan `/en/...` menghasilkan 404** di bawah `prefix_except_default`, dengan `en` sebagai default.
- **Prefiks locale dengan huruf besar/kecil atau ejaan berbeda menghasilkan 404** (`/DE/about`). Begitu pula `/DE/x` di bawah `[...slug]` dan `/DE` di samping `[slug]`, sehingga slug CMS yang sama dengan kode locale dalam huruf berbeda kehilangan halamannya.
- **URL yang tidak dikenal tetap 404** dengan `autoDetectPath: '*'` atau `'no_prefix'`. `prefix` mempertahankan redirect, begitu pula `/` di mana pun.
- **Path kustom milik locale lain, tanpa prefiks,** adalah `302` ke URL locale default di bawah `prefix_except_default`. Di bawah `prefix`, redirect kini mencapai halaman yang aktif. `prefix_and_default` tetap 404.
- **`prefix` dengan `redirects: false`** menjawab 404 pada URL tanpa prefiks, termasuk URL asli dari halaman dengan path default kustom.
- **`autoDetectPath: '*'`** juga menerapkan cookie dan `Accept-Language` pada path tanpa prefiks.
- **Di bawah `prefix`**, URL tanpa prefiks mempertahankan locale pengunjung, di setiap path, apa pun yang dikatakan `autoDetectPath`.
- **Di bawah `prefix_and_default`**, URL tanpa prefiks adalah locale default.
- **Di bawah `no_prefix`**, path kustom merender locale-nya sendiri, halaman yang dibatasi merender dalam locale yang dilayaninya, dan locale yang berbagi path berbagi satu record.
- **Redirect `routeRules` tanpa halaman** tidak dilokalkan: `/de/old` adalah 404, sebelumnya 200 kosong.
- **Aturan route menjangkau path kustom,** dan juga disalin di bawah `no_prefix`. Saudara statis seperti `/de/artikel/news` cocok dengan `/de/artikel/:slug`.
- **Locale dengan `disabled: true`** langsung menjawab 404 pada prefiksnya, dan link ke locale tersebut tetap berada di halaman.
- **Path halaman dengan huruf besar/kecil berbeda** adalah `302` ke ejaannya sendiri: `/T/BASIC` menuju `/t/basic`.
- **URL asli dari halaman dengan path default kustom** adalah `302` ke path tersebut di bawah `prefix_except_default`. Sebelumnya 404.
- **`noPrefixRedirect`** mengikuti locale pengunjung: dengan cookie `de`, `/about` menuju `/ueber-uns`, bukan ke path locale default.
- **Prefiks milik host itu sendiri** adalah 404 di host `baseDefault`-nya di bawah `prefix_except_default`: `/de/x` di host `de` sebelumnya 200.
- **`customRegexMatcher`** tidak lagi menghasilkan 404 untuk halaman nyata yang segmen pertamanya terlihat seperti locale.
- **`nuxi generate`** melakukan prerender setiap halaman statis di setiap locale yang melayaninya, kecuali aturan route mengatur `prerender: false`: lebih banyak file di output. Dengan `baseUrl`, jalankan sekali per domain dengan `NUXT_I18N_DOMAIN`.
- **Redirect klien mempertahankan mode navigasinya:** `<NuxtLink>` biasa menambahkan entri riwayat.
- **Nama route terlokalisasi konsisten.** Hanya kode yang meng-hardcode nama `localized-…` di `router.push({ name })` yang terpengaruh: teruskan nama halaman itu sendiri ke `$localeRoute`.
- **Halaman tanpa nama dari `extendPages`** dilokalkan dan mendapatkan nama.
- **Di bawah `prefix`, link ke domain lain** mempertahankan prefiks locale.
- **Halaman utama sebuah domain** ditulis tanpa garis miring di akhir di mana pun.
- **`?locale=`** hanya berlaku pada halaman di bawah `no_prefix`. `/about?locale=de` tidak lagi merender bahasa Jerman di bawah `lang="en"`.
- **`setLocale('de')` dari plugin** di `/en/...` tidak lagi memuat kamus `de`.

### SEO dan Output HTML {#seo-and-html-output}

- `dir="auto"` tidak lagi menjadi default. Bahasa RTL yang dikenal mendapat `dir="rtl"`, dan locale lain tanpa `dir` tidak mendapat atribut. Untuk mempertahankan output lama, atur `dir: 'auto'`, dengan biaya parsing di halaman besar. Lihat [Arah teks](/id/guide/seo#text-direction).
- `disableMeta` kini berfungsi: halaman tidak memiliki `hreflang`, canonical, atau `og:locale`. `lang` dan `dir` tetap ada.
- `hreflang` hanya mencantumkan locale yang melayani halaman tersebut. `x-default` hanya muncul ketika locale default melayaninya.
- Halaman yang tidak dilokalkan tidak memiliki `hreflang` atau `og:locale:alternate`.
- Halaman 404 membawa `<html lang dir>` dalam locale dari URL, dan tanpa canonical atau `hreflang`.
- Canonical, `og:url`, dan `hreflang` mempertahankan query yang masuk whitelist (`/about?page=2`), juga di server.
- Canonical dan `hreflang` menyertakan `app.baseURL` ketika origin berasal dari request.
- Setiap halaman SSR memiliki `<link rel="preload" as="fetch" crossorigin="anonymous">` untuk file kamusnya, termasuk halaman 404. Izinkan di CSP yang ketat. Dengan `apiBaseClientHost`, host tersebut membutuhkan CORS.
- `Vary` diatur di setiap halaman di bawah `no_prefix`, dan pada redirect locale di strategi lainnya. Periksa cache key CDN Anda.
- Cookie locale hanya ditulis oleh halaman yang dilayani.

### Deteksi dan Server {#detection-and-server}

- `Accept-Language` memperhatikan nilai `q`, dan `q=0` mengecualikan sebuah bahasa.
- `useLocaleServerMiddleware` dan `useTranslationServerMiddleware` menggunakan satu urutan di setiap route (`?locale`, param `[locale]` atau prefiks, cookie, header, default), menghormati `localeCookie: null` dan `autoDetectLanguage: false`, dan menyimpan cache kamus per locale.
- Cookie locale yang formatnya salah diabaikan dan dibiarkan apa adanya, alih-alih menggagalkan SSR.
- Hash mode hanya membaca cookie `hash-locale`. `user-locale=de` saja tidak lagi dihitung.
- `NUXT_I18N_DEFAULT_LOCALE` dan `disabledLocales` runtime mengubah routing.
- **Output `premerged` berubah.** `/{apiBaseUrl}/<page>/<locale>/data.json` hanya berisi apa yang berbeda dari `__root/<locale>/data.json`. Apa pun yang membaca file tersebut secara langsung harus menggabungkan keduanya. Kamus lengkap tetap merupakan file yang valid.
- **Kamus mengikuti `app.cdnURL`.** Browser mengambilnya dari `<cdnURL>/_locales/...`, di mana sebelumnya menggunakan `app.baseURL`. CDN harus menyimpan `_locales/` dan mengizinkan origin situs Anda. Lihat [App baseURL dan host payload](/id/guide/deployment#app-baseurl-and-payload-hosts).
- Tidak ada cache route Nitro pada `/{apiBaseUrl}/**`, dan header `s-maxage=60, stale-while-revalidate` sudah tidak ada. Jika Anda mengandalkan cache tersebut, taruh CDN di depan route payload.
- `/{apiBaseUrl}/<page without a folder>/<locale>/data.json` menjawab dengan kamus root, sebelumnya `{}`. 404 dari host kini diteruskan sebagai 404, di mana sebelumnya menjawab `200 {}`.
- Prerender yang tidak dapat memuat kamusnya gagal dengan 500 dan peringatan, dan dengan `failOnError` default Nuxt, build keluar dengan kode 1.
- Terjemahan yang berubah tanpa rebuild hanya mencapai browser ketika `v` berubah: atur `NUXT_I18N_DATE_BUILD`.
- SSR tidak lagi meminta `/{apiBaseUrl}` melalui HTTP, kecuali `apiBaseServerHost` diatur.

### Terjemahan {#translations}

- Penggabungan bersifat dalam (deep) di setiap tingkat, dan rantai fallback diikuti sampai akhir.
- Penggabungan mengikuti locale: file root milik locale aktif mengalahkan file halaman milik locale fallback.
- Halaman tanpa folder `pages/<name>/` miliknya sendiri membaca kamus root di produksi. Sebelumnya mendapat `{}`.
- `disablePageLocales: true` hanya membaca file root.
- Key milik halaman yang ditinggalkan berhenti ter-resolve setelah navigasi. Jika sebuah layout menggunakan key yang hanya ada di file halaman sebelumnya, pindahkan ke file root.
- File locale yang rusak memberi peringatan sekali beserta path-nya di setiap mode. Dev sebelumnya melempar error.

### Paket `@i18n-micro/*` {#@i18n-micro/*-packages}

Setiap paket `@i18n-micro/*` berada di versi 2.0.0, termasuk `@i18n-micro/types` dan `@i18n-micro/cli` yang baru.

**`@i18n-micro/react`, `preact`, `solid`**

- Adapter router dipindahkan ke `/router`: `createReactRouterAdapter`, `createSolidRouterAdapter`, dan `createBrowserHistoryAdapter` milik Preact. `createPreactRouterAdapter` dihapus.
- `I18nT` mengikuti `<i18n-t>` di atas. Atribut `dangerouslySetInnerHTML`, `innerHTML`, dan `textContent` dibuang.
- `I18nSwitcher` merender item `<a href>` dengan `aria-current="page"`, `▾`, CSS logis, dan `language-switcher` pada tombol. Tanpa `aria-haspopup`. `className` ditambahkan ke `i18n-switcher-wrapper`.
- Link ke `/` atau root locale hanya aktif pada kecocokan persis (React, Preact).
- `I18nLink` mempertahankan `onClick` dan `style` milik pengguna, dan menyerahkan klik dengan modifier ke browser. Query dan hash tidak dihitung untuk pemeriksaan aktif. Tanpa router, tidak ada link yang aktif.
- React dan Preact: `I18nLocalesContext`, `I18nDefaultLocaleContext`, dan `I18nRouterContext` menjadi satu `I18nConfigContext`. Solid: satu `I18nContext` berisi `{ i18n, locales, defaultLocale, router }`.
- `getCurrentPath` milik adapter menyertakan query dan hash, dan key yang berulang di `getRoute().query` berupa array.
- `I18nProvider` bersarang tanpa `i18n` mempertahankan instance luar, dan provider tanpa instance sama sekali akan melempar error.
- `defaultLocale()` tanpa nilai adalah `fallbackLocale`.
- Solid: `getCurrentPathAccessor` dihapus. `useI18n()` tidak lagi melempar error tanpa `locales`.
- React: `use-sync-external-store` tidak lagi menjadi dependensi, dan `react-dom` adalah peer opsional.

**`@i18n-micro/vue`, `vitepress`**

- `I18nT` adalah functional component.
- `I18nSwitcher` dan `I18nLink` mengikuti bagian di atas. `aria-haspopup` sudah tidak ada.
- `I18nLink` dan `createVueRouterAdapter` me-resolve `name`, `query`, dan `hash`. `name` yang tidak dikenal melempar error, seperti halnya `RouterLink`.
- `useLocaleHead` tidak lagi membuat `//de/`. Canonical dan `hreflang` dari satu halaman selaras (`/de`), dan param query yang masuk whitelist menjangkau keduanya.
- `I18nRoutingStrategy.resolvePath` dapat menerima objek location dan path dengan query dan hash. `toHref` opsional yang baru.
- VitePress: link, switcher, `push`, dan `replace` membawa `site.base`.

**`@i18n-micro/astro`**

- `i18nIntegration` membundel `translationDir` dan memasang middleware: hapus `src/middleware.ts` yang hanya menyalin penyiapan, atau berikan `middleware: false`. `src/middleware.ts` milik Anda sendiri meneruskan `base: config.base`.
- `i18nIntegration` melempar error pada `messages`, `plural`, `missingHandler`, dan `routingStrategy`: teruskan ke `createI18n` atau `createI18nMiddleware`, dengan `middleware: false`. Opsi yang tidak pernah melakukan apa pun dihapus dari tipenya.
- `loadTranslationsFromDir` dan `loadTranslationsIntoI18n` dipindahkan ke `@i18n-micro/astro/node`, yang hanya ESM.
- `getGlobalRoutingStrategy`, `setGlobalRoutingStrategy`, dan `runWithRoutingStrategy` dihapus: baca `Astro.locals.routingStrategy`.
- `clone()` menjadi `fork()`, dan opsi `_storage` sudah tidak ada.
- Halaman dinamis adalah satu route: `/blog/hello` adalah `blog-slug`, sebelumnya `blog-hello`. Pindahkan `pages/blog-hello/` ke `pages/blog-slug/`. `getRouteName` kustom menerima pola sebagai argumen ketiga.
- URL menentukan locale halaman. `autoDetect` adalah 302 dari `/` ke halaman utama locale yang dipilih. Opsi `localeCookie` baru, dan `redirectToDefault` sudah diimplementasikan.
- Tampilan halaman dari halaman same-origin milik locale lain menulis cookie locale dan tidak melakukan redirect. Server island dan action tidak pernah melakukan redirect dan membawa `Vary: Referer`.
- `config.localeCodes` tidak menyertakan locale yang dinonaktifkan, dan `prepareLocaleRewrite` menjawab 404 untuk locale tersebut.
- `getI18nProps()` tanpa key mengirim semua yang dapat dijawab `t()` di halaman, dengan peringatan dev di atas 20 KB. Teruskan key yang digunakan island.
- `useLocaleHead`: `baseUrl` default adalah `site`, jika tidak, relatif terhadap root. Link dan meta membawa `id`.
- `<I18nT html>` meng-escape `params`, dan terjemahan kosong dirender kosong.
- `<I18nLink>` dan `localizePath` membiarkan URL eksternal, `#hash`, dan `?query`, serta mempertahankan garis miring di akhir.
- `<I18nSwitcher>` mempertahankan query dan menggunakan `data-i18n-switcher` alih-alih id yang dihasilkan.
- `@i18n-micro/astro/client` hanya memiliki `translate` dan `hasTranslation`: impor adapter dari `/client/vue`, `/client/react`, `/client/preact`, dan `/client/svelte`. `client/vue` membutuhkan `vue` terpasang.
- Island: `has()` bernilai true untuk subtree, `t('')` adalah `''`. `provideI18n` menerima getter untuk mengikuti props baru.
- `getLocale` dan `getDefaultLocale` melempar error tanpa middleware.

**`@i18n-micro/runtime`, `node`**

- Penulisan ke locale yang bukan locale aktif maupun fallback tidak memberi tahu subscriber.
- `addRouteTranslations(locale, route, messages, false)` menggantikan chunk.
- `loadFromUrls` mengambil secara paralel dan tidak menulis apa pun jika salah satunya gagal.
- Node: `reload()` menukar kamus alih-alih mengosongkannya terlebih dahulu, dan tidak mencatat pesan sukses. Direktori yang sudah tidak ada mempertahankan kamus lama.
- Node, Astro, VitePress: satu pembaca untuk folder locales. Folder yang hilang memberi peringatan, file yang bukan objek JSON dilaporkan dan dilewati, dan pesan diawali `[i18n]`.

**`@i18n-micro/test-utils`**

- Mock mengikuti aturan terjemahan yang sebenarnya: `tc('a', 1.5)` mengambil bentuk terakhir, `td('nope')` adalah `Invalid Date`, `t(miss, undefined, '')` adalah key-nya, dan key yang tidak ditemukan tidak lagi dicatat.
- `isolated` sudah tidak ada di `createI18nTestContext`, dan `./publish-smoke` dihapus.

**`@i18n-micro/types-generator`**

- `I18nTypesPlugin(options)` adalah plugin Vite dan Rollup biasa: tanpa `.vite()`, `.webpack()`, atau `.esbuild()`. Untuk webpack atau esbuild, panggil `generateTypes` di dalam skrip.
- `getTypesString` dan `generateTypes` bersifat sinkron. `flattenKeys` dan `isPlainTranslationObject` dihapus.
- Key adalah apa yang dibaca `t()`: path objek ditambahkan, dan file di luar tata letak locale dibuang.

**`@i18n-micro/devtools-ui`**

- Penyimpanan hanya menerima `.json` yang sudah ada di dalam `translationDir`, dan tidak lagi membuat file. Request lintas situs mendapat 403.
- Penyimpanan yang gagal ke endpoint yang dapat dijangkau melempar error dan melakukan rollback.
- `createBridge` menerima opsi `base`. Astro menggunakan `i18nDevToolsIntegration`.

**`@i18n-micro/utils`, `core`, `path-strategy`, `route-strategy`**

Hanya untuk adapter kustom dan tooling.

- `utils`: subpath `./route`, `./route-pattern`, `./build`, `./payload-stats`, dan `./payload-config` dihapus, bersama `resolveServerLocale` dan `resolvePreferredLocale`: panggil `resolveLocale`. `deepMergeTranslations` dan `mergeRouteTranslationsWithRoot` sudah tidak ada: gunakan `deepMergeTranslationsRecursive`.
- `core`: `TranslationHelper` membuang `setCache`, `getGeneration`, dan `lookupIn` (gunakan `lookup(chunkKey, key)`). `BaseI18n` membuang `ensurePinnedChunk` dan `invalidatePin`. `useTranslationHelper(storage)` sudah tidak ada: gunakan `new TranslationHelper(storage)`.
- `path-strategy`: **`switchLocaleRoute(fromLocale, toLocale, route, options)` kini menjadi `switchLocaleRoute(toLocale, route, options)`. Pemanggilan JavaScript lama mengembalikan hasil yang salah tanpa error.** `$switchLocaleRoute` milik Nuxt tidak terpengaruh. Entry `/prefix`, `/no-prefix`, `/prefix-except-default`, dan `/prefix-and-default` sudah tidak ada, begitu pula `getRedirect` dan `getCanonicalPath`. `RouterAdapter` membutuhkan `getRoutes`. `createPathStrategy` tidak membuat URL absolut: gunakan `new DomainPathStrategy(ctx)` ketika locale memiliki `baseUrl`.
- `route-strategy`: hanya `RouteGenerator`, `generateRoutes`, `Rules`, dan helper path yang diekspor.

## Migrasi {#migration}

1. Periksa persyaratan: Nuxt 3.18, Node 20, dan React 18 jika Anda menggunakan `@i18n-micro/react`.
2. Perbarui `nuxt-i18n-micro` dan setiap paket `@i18n-micro/*` secara bersamaan. Hapus `@i18n-micro/hmr`. Tambahkan `@i18n-micro/test-utils` sebagai dev dependency jika test Anda mengimpornya. Ganti `nuxt-i18n-micro-cli` dengan `@i18n-micro/cli` dan ikuti [tabel perintahnya](/id/guide/cli#moving-from-nuxt-i18n-micro-cli).
3. Cari di kode Anda `switchLocaleRoute(` dari `@i18n-micro/path-strategy`, `i18n-plugin-hooks`, `i18n-plugin-define`, nama route `localized-`, `$getI18nConfig().globalLocaleRoutes` dan key konfigurasi lain yang dihapus, `ModuleHooks`, serta `@ts-expect-error` pada `i18n:register`.
4. Pindahkan markup dari params `<i18n-t html>` ke dalam terjemahan, dan teruskan data sebagai params.
5. Jika Anda mengatur `baseUrl`: tinjau link yang dibuat dengan `$localeRoute`, atur `trustForwardedHost` di belakang proxy, dan jalankan `nuxi generate` sekali per domain dengan `NUXT_I18N_DOMAIN`.
6. Periksa URL Anda terhadap strategi Anda: `/en` di bawah `prefix_except_default`, slug CMS yang mirip locale, redirect `routeRules`, dan `excludePatterns`.
7. Periksa cache key CDN Anda untuk `Vary`, dan izinkan link preload di CSP yang ketat. Dengan `app.cdnURL`, taruh `_locales/` di CDN dan izinkan CORS.
8. Jika sebuah tool membaca file `/_locales/...` secara langsung, gabungkan file halaman di atas `__root/<locale>/data.json`.
9. Jika global guard membaca locale atau kamus, pastikan guard tersebut dapat berjalan sebelum navigasi di-commit. Pindahkan key yang diambil layout dari file halaman sebelumnya ke file root.
10. Bandingkan output `nuxi generate` atau crawl sitemap sebelum dan sesudah: `hreflang`, `x-default`, canonical, dan daftar halaman memang berubah secara sengaja.
11. Perbarui import untuk paket framework: `/router` untuk adapter React, Solid, dan Preact, `/node` untuk loader Astro, dan `I18nTypesPlugin(o)` untuk plugin tipe.
12. Untuk Astro, hapus `src/middleware.ts` yang hanya menyalin penyiapan, dan ganti nama kamus bergaya `pages/blog-hello/` sesuai polanya.
13. Perbarui test yang mematok `router-link-active`, `li button`, `▼`, atau perilaku mock lama.

Detail dan setiap kasus tepi: [Upgrade](/id/guide/upgrade).

## Mengapa Ini Penting {#why-it-matters}

- **Benar secara konstruksi:** link, redirect, dan tag SEO berasal dari route yang benar-benar dimiliki app.
- **Satu jawaban di mana-mana:** build, mode source, dan dev memberikan kamus yang sama, dan setiap pemanggil menggunakan satu urutan deteksi.
- **Domain:** satu deployment untuk setiap domain locale, tanpa build kedua.
- **Default yang lebih aman:** params yang di-escape, cache yang dibatasi, link yang tetap berada di origin Anda.
- **Lebih sedikit yang dikirim:** file kamus yang lebih kecil, paket routing yang lebih kecil, dan logika bersama di satu tempat.

Untuk daftar lengkap perubahan, lihat [Upgrade](/id/guide/upgrade) dan [changelog](https://github.com/s00d/nuxt-i18n-micro/blob/main/CHANGELOG.md).
