**Tanggal**: 2026-07-30

**Versi**: `v3.24.0`

![Rilis v3.24.0](/images/3.24.0.png)

Build produksi Node tidak lagi menyematkan payload terjemahan sebagai `serverAssets` Nitro / Rollup `raw:` (RSS build berukuran multi‑GB pada katalog besar). SSR membaca pohon `/{apiBaseUrl}/{page}/{locale}/data.json` yang sama dengan yang diambil klien — dari `public/` melalui `readFile`. Edge tetap menggunakan embed Nitro dan sebaiknya memilih `mode: 'source'`.

## Apa yang Baru? {#what’s-new}

### Node: SSR dari `public/<apiBaseUrl>` {#node-ssr-from-public/&lt;apibaseurl&gt;}

- Preset Node yang menyajikan `public/` dari disk **tidak** mendaftarkan `serverAssets` Nitro.
- Payload disalin ke `public/<apiBaseUrl>` (default `_locales`) sebagai `{page}/{locale}/data.json`.
- SSR memuatnya melalui `#i18n-internal/payload-source` → `readFile` (path produksi di samping `.output/server`).
- `translationPayloads.serverAssets: true` tetap berarti "SSR lokal" dan **memaksa** salinan public tersebut meskipun `publicAssets` bernilai false.

Playground (dibandingkan embed `serverAssets` sebelumnya): ~**1,25 GB** / ~6–7 dtk / `raw`=0 vs ~**3 GB** / ~13 dtk / ~170 chunk raw.

### Edge: `serverAssets` hanya saat diperlukan {#edge-serverassets-only-when-needed}

- Edge (`nitro.node === false`) tetap menyematkan melalui `serverAssets` Nitro (`assets:i18n`) dengan tata letak yang sama seperti `mode`.
- Edge **tidak** memaksa salinan public — tetapkan `publicAssets: true` untuk CDN/statis.
- Memberi peringatan saat Edge + `mode: 'premerged'` (sebaiknya gunakan `mode: 'source'` untuk katalog besar).

### `publicDir` selaras dengan URL klien {#publicdir-aligns-with-client-urls}

- `translationPayloads.publicDir` secara default bernilai **`apiBaseUrl`** (bukan `translationDir`).
- Pohon public/Edge premerged adalah `{page}/{locale}/data.json`, sesuai dengan `$fetch('/_locales/...')`.
- Default modul tidak lagi menetapkan `publicAssets: true` bersarang (deep-merge Nuxt memaksa salinan public bahkan untuk `mode: 'source'`).

Lihat [Opsi modul — `translationPayloads`](/id/api/module-options#translationpayloads), [Deployment — serverless dan Edge](/id/guide/deployment#serverless-and-edge), dan [Arsitektur Cache & Storage](https://s00d.github.io/nuxt-i18n-micro/v3/api/i18n-cache-api).

## Perubahan yang Merusak Kompatibilitas {#breaking-changes}

- **Tidak ada kamus di payload HTML SSR Nuxt.** `payload.data['i18n-ssr-chunks']`, `setSsrChunk`, dan `seedFromSsrChunks` **dihapus**. Pendekatan default yang sama seperti `@nuxtjs/i18n` (`experimental.preload: false`): server menyimpan terjemahan di memori untuk SSR; klien memuat `/{apiBaseUrl}/.../data.json` saat setup plugin (`await switchContext`).
- **`prerenderRoutes` secara default bernilai `false`.** Aktifkan hanya jika Anda memerlukan Nitro untuk mewujudkan rute handler ketika `publicAssets` belum menulis pohonnya (`publicAssets` premerged sudah menghasilkan `{page}/{locale}/data.json`).
- **Default `publicDir` adalah `apiBaseUrl`**, bukan `translationDir`. Output statis berpindah dari misalnya `public/locales/...` ke `public/_locales/{page}/{locale}/data.json` kecuali Anda menetapkan `publicDir` secara eksplisit.
- **Tata letak storage premerged** sekarang adalah `{page}/{locale}/data.json` (sebelumnya `pages/{page}/{locale}.json`). Apa pun yang membaca kunci Nitro/storage atau menyalin pohon dengan bentuk lama harus diperbarui.
- **Di Node, `serverAssets: true` tidak lagi berarti embed Nitro** — artinya SSR lokal melalui salinan public. Embed Rollup `raw:` yang sesungguhnya tetap hanya untuk Edge.

## Migrasi {#migration}

1. Hapus kode apa pun yang membaca `payload.data['i18n-ssr-chunks']` atau memanggil `seedFromSsrChunks` / `setSsrChunk`.
2. Untuk host statis murni: pertahankan default premerged + `publicAssets` (file berada di `/_locales/.../data.json`), atau tetapkan `prerenderRoutes: true` / host payload di CDN.
3. Untuk Cloudflare / Edge lainnya: tetapkan `translationPayloads: { mode: 'source' }` pada katalog besar; tambahkan `publicAssets: true` hanya jika Anda memerlukan salinan statis/CDN.
4. Jika Anda bergantung pada payload di bawah `public/<translationDir>`, tetapkan `translationPayloads.publicDir` atau arahkan tooling ke `public/<apiBaseUrl>`.

## Perbaikan: lewati locale yang dinonaktifkan di payload public premerged {#fix-skip-disabled-locales-in-premerged-public-payloads}

`preMergeLocales` sekarang menulis `{page}/{locale}/data.json` hanya untuk locale yang diteruskan ke proses merge (`locale.disabled: true` saat build dihilangkan). Sebelumnya setiap locale JSON di disk disalin ke `public/`, sehingga static Nitro menyajikan locale yang dinonaktifkan dengan status 200 dan melewati handler. `disabledLocales` saat runtime tetap tidak dapat membatalkan publikasi file yang sudah di-build — gunakan `locale.disabled` saat build ketika `publicAssets` / salinan public SSR Node aktif.

## Mengapa Ini Penting {#why-it-matters}

- Build Node tetap ramping: tidak ada lonjakan Rollup `raw:` multi‑GB dari katalog terjemahan.
- File public dan URL `$fetch` klien berbagi satu tata letak path — hosting statis berfungsi tanpa pemetaan ulang khusus.
- Edge tetap dapat menyematkan payload `source` yang ringkas tanpa memaksa pohon public duplikat.
