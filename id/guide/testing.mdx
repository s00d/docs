Komponen yang memanggil `useI18n()` memerlukan instance i18n dalam unit test. `@i18n-micro/test-utils` memberi Anda `useI18n()` palsu dengan logika terjemahan, plural, dan pemformatan yang sesungguhnya, sehingga Anda dapat me-mount komponen dengan kamus Anda sendiri tanpa server Nuxt. Untuk routing dan redirect, jalankan modul yang sesungguhnya secara end to end dengan `@nuxt/test-utils`.

Halaman ini membahas pengujian aplikasi Anda. Cara repositori ini menguji modul itu sendiri dijelaskan di [Menguji modul](https://s00d.github.io/nuxt-i18n-micro/contributing/testing).

## Instalasi {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/test-utils @nuxt/test-utils vitest @vue/test-utils happy-dom
```

```bash npm
npm install -D @i18n-micro/test-utils @nuxt/test-utils vitest @vue/test-utils happy-dom
```

</CodeGroup>

## Mock useI18n {#mock-usei18n}

```ts
// tests/unit-setup.ts
import { setupNuxtI18nMock } from '@i18n-micro/test-utils'
import { mockNuxtImport } from '@nuxt/test-utils/runtime'
import { beforeEach, vi } from 'vitest'

export const { i18n, useI18n, setTranslationsFromJson } = setupNuxtI18nMock({
  spy: vi.fn, // every method becomes a vi.fn, so you can assert calls
  beforeEach, // reset state and reseed `translations` before each test
  translations: { welcome: 'Welcome' },
})

mockNuxtImport('useI18n', () => useI18n)
```

```ts
// vitest.config.ts
import { defineVitestConfig } from '@nuxt/test-utils/config'

export default defineVitestConfig({
  test: {
    environment: 'nuxt',
    setupFiles: ['./tests/unit-setup.ts'],
  },
})
```

Simpan `mockNuxtImport` di file setup: `@nuxt/test-utils` harus mentransformasinya. `setupNuxtI18nMock` menggunakan cache terjemahan privat, sehingga file test yang berjalan paralel tidak berbagi state.

## Menulis test {#write-a-test}

```vue
<!-- components/Greeting.vue -->
<script setup lang="ts">
const { $t } = useI18n()
</script>

<template>
  <p>{{ $t('welcome') }}</p>
</template>
```

```ts
// tests/greeting.spec.ts
import { mountSuspended } from '@nuxt/test-utils/runtime'
import { expect, it } from 'vitest'
import Greeting from '~/components/Greeting.vue'
import de from '~/locales/de.json'
import { i18n, setTranslationsFromJson } from './unit-setup'

it('renders the German greeting', async () => {
  await setTranslationsFromJson('de', de)
  i18n.setLocale('de')

  const wrapper = await mountSuspended(Greeting)
  expect(wrapper.text()).toBe('Willkommen') // de.json: { "welcome": "Willkommen" }
})
```

Objek palsu ini mengekspos metode yang sama dengan `useI18n()` yang sesungguhnya (`$t`, `$tc`, `$tn`, `$td`, `$has`, `$localePath`, …, dengan dan tanpa `$`) ditambah setter untuk test: `setLocale`, `setLocales`, `setDefaultLocale`, `setRouteName`, `setTranslationsFromJson`, `loadPageTranslations`, `mergeTranslations`, `setMissingHandler`.

`$localePath` dan `$switchLocalePath` adalah stub yang menambahkan prefiks ke path sesuai opsi `strategy` (tanpa router sungguhan). Uji tautan dan redirect sungguhan secara end to end.

## Helper tingkat rendah {#lower-level-helpers}

| Helper | Gunakan untuk |
| --- | --- |
| `createIsolatedFakeI18n(options)` | Objek palsu terisolasi tanpa wiring `useI18n` Nuxt, misalnya untuk `mount` `@vue/test-utils` biasa dengan `global.mocks`. |
| `createFakeI18n(options)` | Objek palsu pada cache modul bersama (panggil `resetI18n()` di `beforeEach`), atau terisolasi dengan `isolated: true`. |
| `createI18nTestContext(options)` | Konteks di balik keduanya, ketika Anda memerlukan beberapa objek palsu. |
| `t`, `tc`, `ts`, `tn`, `td`, `tdr`, `has` | Pemanggilan langsung pada konteks bersama, untuk menguji fungsi biasa. |

Mock ini adalah `BaseI18n`: `t`, `tc`, `tn`, `td`, `tdr`, dan `has` adalah implementasi yang sesungguhnya, pada kamus yang sesungguhnya, sehingga test melihat apa yang ditampilkan aplikasi.

Helper factory di atas menerima `locale`, `defaultLocale`, `locales`, `routeName`, `strategy`, `translations`, dan `messages` (kamus per locale). Proyek contoh lengkap tersedia di [`packages/test-utils/example`](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/test-utils/example).

## Test end-to-end {#end-to-end-tests}

Routing, redirect, tag SEO, dan pemuatan payload memerlukan modul yang sesungguhnya. Jalankan aplikasi Anda dengan `@nuxt/test-utils/e2e`:

```ts
// tests/e2e/locales.test.ts
import { $fetch, fetch, setup } from '@nuxt/test-utils/e2e'
import { describe, expect, it } from 'vitest'

describe('locales', async () => {
  await setup({ server: true })

  it('serves the German page', async () => {
    expect(await $fetch('/de')).toContain('lang="de-DE"')
  })

  it('redirects / for a German browser', async () => {
    const res = await fetch('/', { headers: { 'accept-language': 'de' }, redirect: 'manual' })
    expect(res.headers.get('location')).toBe('/de')
  })
})
```

Test kedua mengasumsikan `prefix` (atau `prefix_except_default` dengan locale default lain); lihat [Deteksi locale](/id/guide/locale-detection) untuk mengetahui kapan `/` melakukan redirect.
