Halaman ini membawa aplikasi Nuxt dari tanpa i18n menjadi halaman terjemahan dengan pengalih bahasa. Anda membutuhkannya sekali, di awal proyek. Hasilnya adalah URL yang dilokalkan (`/about`, `/de/about`), satu file JSON per locale dan halaman, serta `$t` di template Anda.

## Instalasi {#install}

Modul ini membutuhkan Nuxt 3.18 atau lebih baru (Nuxt 4 juga bisa) dan Node 20 atau lebih baru.

<CodeGroup>

```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>

## Konfigurasikan locale {#configure-the-locales}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', displayName: 'English' },
      { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
      { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
    ],
    defaultLocale: 'en',
  },
})
```

Itulah seluruh konfigurasi yang dibutuhkan aplikasi pertama. Nilai default memberi Anda:

- `strategy: 'prefix_except_default'`: locale default tidak memiliki prefiks (`/about`), sedangkan yang lain memilikinya (`/de/about`). Lihat [Strategi routing](/id/guide/strategy).
- `translationDir: 'locales'`: file terjemahan berada di `locales/` di root proyek, juga dengan tata letak `app/` Nuxt 4.
- `meta: true`: tag `hreflang`, canonical, dan `og:locale`, ditambah `lang` dan `dir` pada `<html>`. Lihat [SEO](/id/guide/seo).
- Pengunjung yang membuka `/` diarahkan ke bahasa yang diminta browsernya (`Accept-Language`). Lihat [Deteksi locale](/id/guide/locale-detection).

`iso` adalah tag bahasa yang digunakan di tag SEO; `code` adalah yang muncul di URL. Setiap opsi tercantum di [Opsi modul](/id/api/module-options).

## Tambahkan file terjemahan {#add-translation-files}

Jalankan server pengembangan dengan `nuxt dev`. Saat Nuxt me-resolve halaman, modul membuat file kosong `{}` untuk setiap locale dan halaman yang belum memilikinya (matikan dengan [`disableWatcher`](/id/api/module-options#disablewatcher)):

```text
locales/
├── en.json            # root: keys every page can use
├── de.json
├── fr.json
└── pages/
    ├── index/         # pages/index.vue
    │   ├── en.json
    │   ├── de.json
    │   └── fr.json
    └── about/         # pages/about.vue
        ├── en.json
        ├── de.json
        └── fr.json
```

Isi file root dan file halaman:

```json
// locales/en.json
{ "nav": { "home": "Home", "about": "About" } }
```

```json
// locales/pages/index/en.json
{ "welcome": "Welcome, {name}!", "items": "no items | one item | {count} items" }
```

Sebuah halaman melihat key root dan key miliknya sendiri; file miliknya sendiri menang jika terjadi bentrok. Nama folder mengikuti nama rute (`pages/articles/[id].vue` menjadi `locales/pages/articles-id/`). [File terjemahan](/id/guide/translations) membahas tata letak, fallback, dan pemuatan.

## Gunakan `$t` di halaman {#use-$t-on-a-page}

```vue
<!-- pages/index.vue -->
<script setup lang="ts">
const { t, tc, getLocale } = useI18n()

const title = t('nav.home') // 'Home'
</script>

<template>
  <h1>{{ $t('welcome', { name: 'Ada' }) }}</h1>
  <!-- Welcome, Ada! -->
  <p>{{ $tc('items', 3) }}</p>
  <!-- 3 items -->
  <p>{{ getLocale() }}</p>
  <!-- en -->
</template>
```

- Di template, setiap helper tersedia dengan `$` (`$t`, `$tc`, `$localePath`, …).
- Di `<script setup>`, `useI18n()` mengembalikan helper yang sama, dengan dan tanpa `$` (`t` dan `$t` adalah satu fungsi yang sama). Fungsi ini diimpor otomatis.
- Placeholder `{name}` diisi dari objek params. Bentuk jamak dipisahkan dengan `|`; jumlah menentukan bentuknya (0, 1, lalu yang terakhir untuk semua nilai di atasnya).

Semua helper tercantum di [Metode](/id/api/methods).

## Tautkan antarhalaman dan ganti locale {#link-between-pages-and-switch-locale}

```vue
<!-- components/AppHeader.vue -->
<template>
  <nav>
    <i18n-link :to="{ name: 'index' }">{{ $t('nav.home') }}</i18n-link>
    <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
    <i18n-switcher />
  </nav>
</template>
```

- [`<i18n-link>`](/id/components/i18n-link) adalah `NuxtLink` yang menunjuk ke halaman dalam locale saat ini: di `/de`, tautan about mengarah ke `/de/about`.
- [`<i18n-switcher>`](/id/components/i18n-switcher) adalah dropdown berisi locale yang diaktifkan; komponen ini membuat pengunjung tetap berada di halaman yang sama.
- Untuk tombol Anda sendiri, panggil `$switchLocale('de')`, yang menavigasi ke halaman saat ini dalam bahasa Jerman dan mengingat pilihan tersebut. Untuk `NuxtLink` biasa, gunakan `$localePath({ name: 'about' })` atau `$switchLocalePath('de')`.

## Periksa hasilnya {#check-it}

Jalankan `nuxt dev` dan buka:

| URL | Menampilkan |
| --- | --- |
| `/` | Beranda bahasa Inggris (atau redirect ke `/de` jika browser Anda lebih memilih bahasa Jerman) |
| `/de` | Beranda bahasa Jerman |
| `/de/about` | Halaman about bahasa Jerman |
| `/en/about` | 404: locale default tidak memiliki prefiks pada `prefix_except_default` |

Perubahan pada file JSON langsung diterapkan di halaman yang terbuka tanpa reload.
