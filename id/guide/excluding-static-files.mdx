---
title: "Mengecualikan path"
description: "Jauhkan halaman dan file dari routing locale dengan excludePatterns, dan lihat path mana yang sudah dikecualikan."
---

Beberapa path tidak boleh mendapatkan prefiks locale atau redirect locale: area admin, health check, feed yang dihasilkan. `excludePatterns` menandai path tersebut, dan daftar bawaan sudah mencakup internal Nuxt serta file statis yang umum. Halaman yang dikecualikan tetap memakai path persis seperti yang Anda tulis dan tetap dirender dengan `$t`.

## Mengecualikan sebuah path {#exclude-a-path}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    excludePatterns: [
      '/admin', // /admin and everything below it
      '/preview-*', // glob over the whole path
    ],
  },
})
```

Dengan konfigurasi ini, `pages/admin/index.vue` hanya merespons di `/admin`; tidak ada `/de/admin`, dan `/admin` tidak pernah di-redirect ke `/de/admin`.

## Sintaks pola {#pattern-syntax}

Pola dicocokkan dengan path tanpa `app.baseURL`:

| Pola | Cocok | Tidak cocok |
| --- | --- | --- |
| `'/admin'` | `/admin`, `/admin/users` | `/administrator`, `/de/admin` |
| `'/preview-*'` | `/preview-1`, `/preview-a/b` | `/de/preview-1` |
| `'/file-?'` | `/file-a` | `/file-ab` |
| `/^\/v\d+\//` | `/v2/docs` | `/docs` |

String tanpa `*` atau `?` cocok dengan path tersebut dan seluruh segmen di bawahnya. Dengan `*` (rangkaian karakter apa pun, termasuk garis miring) atau `?` (satu karakter), string harus cocok dengan seluruh path. Selalu awali string dengan `/`.

## Apa yang sudah dikecualikan {#what-is-excluded-already}

Path berikut tidak pernah mendapatkan rute atau redirect locale, tanpa konfigurasi apa pun:

- `/api` dan `/_nuxt`, beserta semua yang ada di bawahnya;
- rute terjemahan, secara default `/_locales` ([`apiBaseUrl`](/id/api/module-options#apibaseurl));
- path apa pun dengan segmen yang diawali `__` (`/__nuxt_content`, `/en/__og-image__`);
- `/sitemap*.xml`, `/robots.txt`, `/favicon.ico`, `/apple-touch-icon*.png`, `/manifest.json`, `/sw.js`, `/workbox-*.js`;
- path apa pun yang segmen terakhirnya berakhiran ekstensi file statis: `xml txt ico json js css png jpg jpeg gif svg webp avif pdf wasm map mp4 webm mp3 zip gz woff woff2 ttf eot`. Slug halaman bertitik seperti `/user/john.doe` dan path `.html` tetap dianggap halaman.

## Apa yang dilakukan pengecualian {#what-an-exclusion-does}

- **Rute:** tidak ada varian terlokalisasi yang dibuat; halaman dipertahankan seperti yang ditulis.
- **Redirect dan 404:** plugin redirect server dan middleware redirect klien melewati path tersebut.
- **Prerender:** path yang cocok dihapus dari daftar rute prerender.

Pengecualian tidak menghentikan middleware server i18n untuk mendeteksi locale dari request, dan tidak menghentikan halaman untuk menggunakan terjemahan. Untuk mempertahankan halaman tetap terlokalisasi tetapi tanpa tag SEO, gunakan `disableMeta` ([Konfigurasi halaman](/id/guide/per-component-translations#turn-off-seo-tags)). Untuk membuat satu halaman tidak terlokalisasi dari `nuxt.config.ts` berdasarkan path, `globalLocaleRoutes: { '/admin': false }` ([Path terlokalisasi](/id/guide/custom-locale-routes#in-nuxt-config)) melakukan hal yang sama untuk routing.
