Di `nuxt dev`, modul menambahkan dua alat bantu debugging: tab **i18n Micro** di Nuxt DevTools untuk menelusuri dan mengedit file terjemahan, serta inspector Vue DevTools untuk locale aktif dan kamus yang dimuat. Keduanya hanya ada di mode development dan tidak menambahkan apa pun ke build produksi. Tab Nuxt hanya memerlukan Nuxt DevTools yang diaktifkan; inspector Vue juga memerlukan ekstensi browser Vue DevTools.

## Tab Nuxt DevTools {#nuxt-devtools-tab}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  devtools: { enabled: true }, // the tab is registered only when DevTools are on
})
```

Buka Nuxt DevTools (`Shift + Alt + D`) lalu pilih **i18n Micro**. Tab ini menampilkan:

- setiap file JSON di bawah `locales/` (root dan `pages/`) dari setiap layer, ditambah file root dari `additionalTranslationDirs`;
- editor per file; **Save** menulis file kembali ke disk, dan server dev memuat ulang terjemahan;
- **Export** / **Import** file sebagai JSON, serta **Stats** dengan jumlah kunci dan cakupan terjemahan;
- tampilan konfigurasi dari opsi modul yang telah di-resolve;
- **Translate**, yang mengisi kunci yang hilang dengan mesin terjemahan otomatis yang Anda konfigurasikan di pengaturan tab.

Penyimpanan hanya menulis file `.json` yang sudah ada di dalam direktori terjemahan Anda. Ketika sebuah file ada di beberapa layer, salinan milik proyek yang ditulis.

## Inspector Vue DevTools {#vue-devtools-inspector}

Dengan ekstensi browser Vue DevTools, modul mendaftarkan inspector i18n (locale saat ini, chunk rute, kunci yang dimuat) dan timeline berisi pergantian locale, pemuatan chunk, dan kunci yang hilang.

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    debug: true, // also log every $t / $ts / $tc call on the timeline
    // vueDevtools: false, // turn the inspector off, keep the Nuxt tab
  },
})
```

[`vueDevtools`](/id/api/module-options) secara default bernilai `true`. `debug: true` menghasilkan banyak output; gunakan hanya untuk sesi singkat.

## Di luar Nuxt {#outside-nuxt}
