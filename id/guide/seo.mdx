Dengan `meta: true` (default) setiap halaman yang dilokalkan mendapatkan `<html lang dir>`, link canonical, alternatif `hreflang`, `x-default`, dan tag locale Open Graph. Anda memerlukan halaman ini jika ingin menetapkan origin publik, mengatur locale mana yang muncul di tag, atau menimpanya untuk satu halaman. Sebagian besar situs hanya memerlukan `site.url` atau `metaBaseUrl` dan kode `iso` yang benar.

## Penyiapan minimal {#minimal-setup}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'de', iso: 'de-DE', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    metaBaseUrl: 'https://example.com',
  },
})
```

`/de/about` kemudian merender:

```html
<html lang="de-DE" dir="ltr">
<link rel="canonical" href="https://example.com/de/about">
<link rel="alternate" hreflang="en-US" href="https://example.com/about">
<link rel="alternate" hreflang="de-DE" href="https://example.com/de/about">
<link rel="alternate" hreflang="ar-SA" href="https://example.com/ar/about">
<link rel="alternate" hreflang="x-default" href="https://example.com/about">
<meta property="og:locale" content="de_DE">
<meta property="og:url" content="https://example.com/de/about">
<meta property="og:locale:alternate" content="en_US">
<meta property="og:locale:alternate" content="ar_SA">
```

## Arah teks {#text-direction}

`<html dir>` berasal dari `dir` milik locale. Tanpa nilai itu, bahasa yang ditulis dari kanan ke kiri mendapatkan `rtl`, dibaca dari `iso` (atau `code`): Arab, Ibrani, Persia, Urdu, dan beberapa lainnya, serta tag apa pun dengan aksara RTL seperti `az-Arab`. Semua locale lainnya tidak mendapatkan atribut `dir`, yang dibaca browser sebagai `ltr`.

<Warning>

**`dir: 'auto'` memakan waktu parsing pada halaman besar** — `auto` pada `<html>` membuat browser menentukan arah dari konten saat melakukan parsing. Di Chromium biaya itu tumbuh lebih cepat daripada halamannya: sekitar 100 ms pada 5.000 elemen dan 1 s pada 20.000. Gunakan hanya untuk halaman kecil yang bahasanya tidak dapat Anda ketahui.

</Warning>

## Tag yang Anda dapatkan {#which-tags-you-get}

- **hreflang**: satu tag per locale yang menyajikan halaman, bernilai `iso` (atau `code` jika `iso` tidak ada), dengan URL yang memiliki query sama seperti canonical. Halaman yang dibatasi dengan [Konfigurasi halaman](/id/guide/per-component-translations) atau `routeLocales` hanya mencantumkan locale-nya. [`hreflangBaseLanguage: true`](/id/api/module-options#hreflangbaselanguage) juga menambahkan bahasa dasar (`es-ES` → `es`) untuk locale regional pertama.
- **x-default**: URL locale default, hanya jika locale default menyajikan halaman tersebut.
- **og:locale**: diturunkan dari `iso` (`en-US` → `en_US`). Tetapkan `og` pada locale jika pemetaannya tidak langsung, misalnya `{ code: 'zh', iso: 'zh-Hans', og: 'zh_CN' }`; tanpa keduanya, tidak ada `og:locale` yang ditulis dan mode dev memberi peringatan.
- **canonical / og:url**: URL saat ini tanpa parameter query, kecuali yang ada di [`canonicalQueryWhitelist`](/id/api/module-options#canonicalquerywhitelist) (default `page`, `sort`, `filter`, `search`, `q`, `query`, `tag`).

Berdasarkan strategi:

| Strategi | hreflang dan x-default | canonical, og:url, og:locale, atribut html |
| --- | --- | --- |
| `prefix`, `prefix_except_default`, `prefix_and_default` | ya | ya |
| `no_prefix` | tidak (satu URL melayani setiap locale) | ya |

## Menetapkan origin publik {#set-the-public-origin}

URL absolut menggunakan yang pertama dari:

1. [`metaBaseUrl`](/id/api/module-options#metabaseurl);
2. `site.url` dari `nuxt-site-config` (dipasang oleh `@nuxtjs/seo`);
3. origin permintaan, dengan `app.baseURL` ditambahkan.

Tetapkan salah satu dari dua yang pertama.

<Warning>

Fallback origin permintaan membaca `X-Forwarded-Host` dan `X-Forwarded-Proto`, karena [`metaTrustForwardedHost`](/id/api/module-options#metatrustforwardedhost) dan `metaTrustForwardedProto` default-nya `true`. Ini hanya aman di belakang proxy yang menimpa header tersebut; jika tidak, klien dapat memilih host di link canonical Anda, dan cache dapat meneruskan halaman itu.

Jika aplikasi dapat dijangkau secara langsung, tetapkan `metaBaseUrl`: tidak seperti menetapkan kedua opsi ke `false`, ini juga mengabaikan `Host` palsu. Lihat [Di belakang proxy atau CDN](/id/guide/deployment#behind-a-proxy-or-cdn).

</Warning>

Fallback ini berguna untuk satu deployment yang melayani beberapa domain: `https://site-a.com/en/about` dan `https://site-b.com/en/about` masing-masing mendapatkan origin sendiri.

Dengan `baseUrl` pada locale, host yang dikenal menggunakan `baseUrl`-nya sendiri, mengungguli `metaBaseUrl` dan `site.url`, sehingga canonical dan `og:url` tetap di domain tersebut dan `hreflang` mengarahkan setiap locale ke domainnya. Host lain menggunakan `metaBaseUrl`, jika tidak ada maka `baseUrl` locale default, jika tidak ada maka `site.url`, sehingga `Host` palsu tidak dapat menjangkau tag Anda. Jika tidak satu pun ditetapkan, fallback origin permintaan tetap berlaku, dan build memberi peringatan. Lihat [Layer dan domain](/id/guide/layers#multiple-domains).

## Mengecualikan locale atau halaman {#leave-locales-or-pages-out}

```ts
i18n: {
  locales: [
    { code: 'en', iso: 'en-US' },
    { code: 'ru', iso: 'ru-RU', seo: false }, // routable, but not in hreflang / og:locale:alternate
    { code: 'fr', iso: 'fr-FR', disabled: true }, // no routes, no switching, no tags
  ],
}
```

Jika locale default memiliki `seo: false`, tidak ada `x-default` yang ditulis. Untuk mematikan tag pada satu halaman, gunakan `disableMeta` di [Konfigurasi halaman](/id/guide/per-component-translations#turn-off-seo-tags), atau [`routeDisableMeta`](/id/api/module-options#routedisablemeta) di konfigurasi.

## Menimpa tag pada satu halaman {#override-tags-on-one-page}

Untuk konten CMS yang hanya memiliki sebagian terjemahan, atau URL-nya berasal dari API, ganti tag yang dihasilkan dengan [`useI18nHead`](/id/composables/useI18nHead):

```vue
<script setup lang="ts">
const { data: article } = await useFetch('/api/articles/hello')
// article.value.urls = { en: 'https://example.com/blog/hello', de: 'https://example.com/de/artikel/hallo' }

useI18nHead(() => ({
  meta: [{ property: 'og:title', content: article.value?.title ?? '' }],
  replace: {
    hreflang: Object.entries(article.value?.urls ?? {}).map(([locale, href]) => ({ rel: 'alternate', hreflang: locale, href })),
    ogAlternates: Object.keys(article.value?.urls ?? {}),
  },
}))
</script>
```

`replace` juga dapat menetapkan atau menghapus `canonical`, `xDefault`, `ogLocale`, dan `ogUrl`; `disable` menghapus seluruh grup (`'hreflang'`, `'x-default'`, `'canonical'`, `'og'`, `'og-alternates'`, `'html'`). Berikan getter agar nilai dihitung ulang setelah pergantian locale. Untuk slug per locale, tetapkan `$setI18nRouteParams` terlebih dahulu ([Path yang dilokalkan](/id/guide/custom-locale-routes#per-locale-slugs)) dan alternatif yang dihasilkan sudah menggunakannya.

## Garis miring di akhir {#trailing-slash}

`$localePath`, `$switchLocalePath`, objek route dari `$switchLocaleRoute`, `<i18n-link>`, `<i18n-switcher>`, pengalihan locale, dan URL SEO mengikuti satu aturan garis miring: `experimental.defaults.nuxtLink.trailingSlash` secara default, atau [`trailingSlash`](/id/api/module-options) di konfigurasi i18n jika path i18n harus berbeda.

## Nuxt SEO {#nuxt-seo}

[`@nuxtjs/seo`](https://nuxtseo.com/) (sitemap, robots, schema.org) bekerja dengan modul ini melalui `nuxt-site-config` 4+. Cantumkan `nuxt-i18n-micro` terlebih dahulu agar site config dapat membaca locale, dan tetapkan `site.url` sekali — nilai ini juga mengisi tag di atas.

```ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro', '@nuxtjs/seo'],
  site: { url: 'https://example.com', name: 'My Site' },
  i18n: {
    defaultLocale: 'en',
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
  },
})
```

Nama dan deskripsi situs yang diterjemahkan berasal dari kunci `nuxtSiteConfig.name` / `nuxtSiteConfig.description` di file locale Anda. Error `Plugin nuxt-seo:defaults depends on nuxt-site-config:i18n but they are not registered` berarti `@nuxtjs/seo` lebih lama dari versi 3; tingkatkan versinya ([#133](https://github.com/s00d/nuxt-i18n-micro/issues/133)).
