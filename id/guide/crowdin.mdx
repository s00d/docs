[Crowdin](https://crowdin.com/) adalah platform terjemahan: Anda mengunggah file locale default, penerjemah bekerja di Crowdin, lalu Anda mengunduh kembali locale lainnya. Modul membaca file JSON biasa, sehingga Crowdin CLI hanya memerlukan `crowdin.yml` yang memetakan `locales/` dan `locales/pages/` dengan benar. Tidak ada pengaturan modul yang berubah.

## Konfigurasi crowdin.yml {#configure-crowdin-yml}

```yml
# crowdin.yml
project_id_env: CROWDIN_PROJECT_ID
api_token_env: CROWDIN_PERSONAL_TOKEN
base_path: ./locales
preserve_hierarchy: true

files:
  - source: /en.json
    translation: /%two_letters_code%.json
  - source: /pages/**/en.json
    translation: /pages/**/%two_letters_code%.json
```

- `en` adalah locale default Anda; file-filenya menjadi sumber.
- `project_id_env` / `api_token_env` membaca ID dan token dari variabel lingkungan, sehingga tidak ada rahasia yang di-commit.
- `preserve_hierarchy: true` mempertahankan folder `pages/<page>/` apa adanya.
- Nama file terjemahan harus sama dengan `code` locale di `nuxt.config.ts`. `%two_letters_code%` cocok untuk kode seperti `de`; untuk kode seperti `pt-BR` gunakan `%locale%`, atau petakan kode Crowdin ke kode Anda dengan `languages_mapping`.

## Unggah dan unduh {#upload-and-download}

```bash
npm install -g @crowdin/cli

export CROWDIN_PROJECT_ID=123456
export CROWDIN_PERSONAL_TOKEN=...   # from Crowdin account settings

crowdin upload sources   # push locales/en.json and locales/pages/**/en.json
crowdin download         # write locales/de.json, locales/pages/**/de.json, ...
```

Jalankan keduanya di CI agar file tetap mutakhir. File yang diunduh masuk ke repositori Anda seperti file yang diedit manual; build atau reload dev berikutnya akan mengambilnya.

## Sebelum mengunggah {#before-uploading}

Bersihkan sumber terlebih dahulu agar penerjemah tidak mengerjakan kunci yang sudah mati: [`i18n-micro clean`](/id/api/cli#clean) menghapus kunci yang tidak terpakai, [`i18n-micro check`](/id/api/cli#check) melaporkan kekurangan setelah unduhan. CLI tidak memiliki integrasi Crowdin sendiri: halaman ini adalah cara yang didukung.
