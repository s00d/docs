Opsi `strategy` menentukan apakah locale muncul di URL dan untuk locale mana saja. Pilih sekali, sebelum Anda memublikasikan URL: mengubahnya nanti akan mengubah setiap tautan. Modul kemudian menghasilkan rute terlokalisasi saat build, dan `$localePath`, `<i18n-link>`, serta switcher membacanya.

## Empat strategi {#the-four-strategies}

![The /about page in en (default) and de under each strategy; the same URLs are listed in the text below](/images/diagrams/strategies.svg)

**Tipe** `Strategies` · **Default** `'prefix_except_default'`

Strategi routing URL untuk prefiks locale.

- `'no_prefix'` — tidak ada locale di URL; locale disimpan di cookie.
- `'prefix_except_default'` — beri prefiks pada semua locale kecuali locale default.
- `'prefix'` — selalu beri prefiks, termasuk locale default.
- `'prefix_and_default'` — seperti `prefix`, tetapi locale default juga dapat diakses tanpa prefiks.

URL untuk halaman `about` dengan `defaultLocale: 'en'` dan locale `en`, `de`:

| Strategi | Inggris | Jerman | Tidak dilayani |
| --- | --- | --- | --- |
| `prefix_except_default` (default) | `/about` | `/de/about` | `/en` dan `/en/about` menghasilkan 404 |
| `prefix` | `/en/about` | `/de/about` | `/about` di-redirect ke URL berprefiks |
| `prefix_and_default` | `/about` dan `/en/about` | `/de/about` | — |
| `no_prefix` | `/about` | `/about` | locale tidak ada di URL |

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix',
  },
})
```

Strategi ditetapkan saat build: override runtime terhadapnya diabaikan dengan peringatan ([Override runtime](/id/guide/runtime-overrides)).

## Mana yang harus dipilih {#which-one-to-choose}

- **`prefix_except_default`**: sebagian besar situs. URL tanpa prefiks yang sudah ada tetap berfungsi untuk bahasa default.
- **`prefix`**: setiap bahasa setara; `/` selalu mengarah ke beranda berprefiks.
- **`prefix_and_default`**: Anda membutuhkan `/en/...` dan URL tanpa prefiks agar sama-sama berfungsi, misalnya saat berpindah dari satu ke yang lain. URL tanpa prefiks tidak pernah di-redirect.
- **`no_prefix`**: aplikasi di balik login, atau satu URL per halaman untuk setiap bahasa. Locale berasal dari cookie atau `?locale=`. Mesin pencari melihat satu bahasa per URL, sehingga tidak ada alternatif `hreflang` yang dihasilkan.

Bagaimana locale dipilih untuk sebuah URL, dan kapan pengunjung di-redirect, dijelaskan di [Deteksi locale](/id/guide/locale-detection).

## Rute yang dihasilkan {#generated-routes}

Saat build, setiap halaman mendapatkan record rute yang dibutuhkan oleh strateginya. Setiap record membawa `meta.i18n = { name, locales }`: halaman yang ditampilkannya dan locale yang dilayaninya. Tautan, perpindahan locale, dan redirect semuanya dijawab dari record tersebut, sehingga URL yang diberikan modul selalu merupakan URL yang dilayani router.

Locale yang berbagi path halaman yang sama berbagi satu record, `/:locale(de|fr)/about`. Locale dengan path sendiri mendapatkan record sendiri, bernama `localized-<page>-<locale>`:

```ts
// nuxt.config.ts: German has its own path for the about page
i18n: {
  globalLocaleRoutes: { about: { de: '/ueber-uns' } },
}
// prefix_except_default, locales en (default), de, fr:
// about                 /about
// localized-about       /:locale(fr)/about
// localized-about-de    /:locale(de)/ueber-uns
```

Path kustom, daftar locale per halaman, dan mengecualikan halaman dari lokalisasi dibahas di [Path terlokalisasi](/id/guide/custom-locale-routes) dan [Konfigurasi halaman](/id/guide/per-component-translations). Prefiks `localized-` adalah [`localizedRouteNamePrefix`](/id/api/module-options#localizedroutenameprefix).

<Warning>

**Nama rute dihasilkan secara otomatis** — Jangan menulis nama `localized-…` secara hard-code di `router.push({ name })`. Berikan nama halaman itu sendiri ke `$localeRoute` atau `<i18n-link>`; keduanya memilih record yang tepat.

</Warning>

## Menautkan ke halaman dalam sebuah locale {#linking-to-a-page-in-a-locale}

```vue
<script setup lang="ts">
const { localePath, localeRoute, switchLocalePath } = useI18n()

localePath({ name: 'about' }) // '/de/ueber-uns' while the page is German
localePath({ name: 'about' }, 'en') // '/about'
localePath('/about', 'de') // '/de/ueber-uns': a path is read as the page it shows
localeRoute({ name: 'products-id', params: { id: '42' } }, 'de') // resolved route: name, params, fullPath
switchLocalePath('fr') // the current page in French
</script>

<template>
  <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
  <NuxtLink :to="$switchLocalePath('de')">Deutsch</NuxtLink>
</template>
```

- Rute bernama dan path sama-sama berfungsi. Path dicocokkan dengan rute yang dihasilkan, sehingga bentuk path dari locale mana pun diterima.
- Locale yang tidak melayani halaman tersebut (lihat `locales` di [Konfigurasi halaman](/id/guide/per-component-translations)) menautkan ke beranda locale tersebut alih-alih ke halaman yang tidak ada.
- Parameter per locale (slug yang diterjemahkan) melalui `$setI18nRouteParams`, lihat [Path terlokalisasi](/id/guide/custom-locale-routes).

Signature ada di [Metode](/id/api/methods).

## Detail `no_prefix` {#no_prefix-details}

- [`localeCookie`](/id/api/module-options#localecookie) default-nya `'user-locale'` di bawah `no_prefix`, sehingga pilihan tetap bertahan setelah reload.
- `$switchLocale('de')` memuat kamus Jerman dan mengganti entri riwayat saat ini; URL tidak berubah.
- Path kustom per locale tetap berfungsi: dengan `globalLocaleRoutes: { about: { de: '/ueber-uns' } }`, pembaca Jerman mendapatkan `/ueber-uns`. URL tersebut selalu dirender dalam bahasa Jerman, apa pun preferensi pengunjung, dan halaman yang dibatasi ke beberapa locale dirender dalam salah satunya. Path yang dibagi oleh beberapa locale (`en` dan `de` sama-sama di `/page/:id`) dirender sesuai preferensi jika preferensi tersebut adalah salah satunya. Preferensi itu sendiri tetap: halaman berikutnya kembali ke preferensi tersebut.
- [`noPrefixRedirect: true`](/id/api/module-options#noprefixredirect) me-redirect path asli dari halaman yang memiliki path kustom di locale default: ke path kustom dari locale pengunjung, atau ke path kustom locale default jika tidak ada (`/about` → `/about-us` ketika `en` memiliki `/about-us`, → `/ueber-uns` dengan cookie `de`). Locale tanpa path kustom sendiri tetap berada di path asli dan dirender di sana. Halaman dengan parameter tidak di-redirect.

## Aplikasi tanpa `pages/` {#apps-without-pages/}

Dengan `pages: false` tidak ada rute halaman yang perlu dilokalkan. Gunakan hanya file terjemahan root (`disablePageLocales: true`); deteksi, cookie, dan `$switchLocale` tetap berfungsi. Varian `pages-false` dari `test/fixtures/basic` di repositori adalah contoh pengaturan yang berfungsi.
