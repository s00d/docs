description: "Terjemahkan string dan baca locale permintaan di dalam route server Nitro dan handler API."
---

Handler server di `server/api/` dan `server/routes/` dapat menerjemahkan string dan membaca locale permintaan dengan dua helper yang diimpor otomatis. Gunakan keduanya untuk respons API, email, feed, atau apa pun yang dirender di luar halaman Vue. Keduanya membaca file terjemahan yang sama dengan halaman Anda dan mendeteksi locale dari permintaan.

## Menerjemahkan di handler {#translate-in-a-handler}

```ts
// server/api/greeting.get.ts
export default defineEventHandler(async (event) => {
  const t = await useTranslationServerMiddleware(event)
  return { message: t('greeting', { name: 'Ada' }) }
})
```

```bash
curl 'http://localhost:3000/api/greeting?locale=de'
# {"message":"Hallo, Ada!"}
```

`useTranslationServerMiddleware(event, defaultLocale?, locale?)` bersifat async dan mengembalikan `t(key, params?, defaultValue?)`. `t` mengembalikan string, menginterpolasi parameter `{name}`, dan mengembalikan `defaultValue` yang tidak kosong, atau kuncinya, jika kunci tidak ditemukan.

`t` hanya melihat chunk `index`: file root (`locales/<locale>.json`) ditambah `locales/pages/index/` jika ada (hanya file root dengan `disablePageLocales`). Kunci dari halaman lain tidak dimuat. Untuk itu, muat chunk-nya sendiri:

```ts
const { data } = await loadTranslationsFromServer('de', 'about') // Translations object of the about page
```

## Membaca locale permintaan {#read-the-request-locale}

```ts
// server/api/locale.get.ts
export default defineEventHandler((event) => {
  const { current, isDefault, locale } = useLocaleServerMiddleware(event)
  return { current, isDefault, dir: locale?.dir ?? 'ltr' }
})
```

`useLocaleServerMiddleware(event, defaultLocale?, locale?)` bersifat sinkron dan mengembalikan:

```ts
interface LocaleInfo {
  current: string // detected locale code
  default: string // defaultLocale, runtime overrides included (fixed at build under prefix_except_default / prefix_and_default)
  fallback: string // fallbackLocale, else the default
  available: string[] // enabled locale codes
  locale: Locale | null // the config entry of `current`
  isDefault: boolean
  isFallback: boolean
}
```

## Cara locale dipilih {#how-the-locale-is-chosen}

Kedua helper menggunakan urutan yang sama di setiap route server, baik `/api` maupun bukan:

1. query `?locale=` (nilai pertama jika berulang);
2. parameter route `[locale]`, atau prefiks locale di path (`/de/...`);
3. cookie locale, jika [`localeCookie`](/id/api/module-options#localecookie) ditetapkan (`hash-locale` di bawah `hashMode`);
4. `Accept-Language`, jika `autoDetectLanguage` aktif (q-value dihormati);
5. `defaultLocale`.

Kode yang tidak valid dan dinonaktifkan dilewati di setiap langkah. Ini adalah urutan API; render halaman mengabaikan `?locale=` di bawah strategi prefiks. Kedua urutan dibandingkan di [Deteksi locale](/id/guide/locale-detection).

## Memaksakan locale {#force-a-locale}

Berikan argumen ketiga untuk melewati deteksi, misalnya dalam job yang mengirim email dalam bahasa pengguna:

```ts
export default defineEventHandler(async (event) => {
  const user = await getUser(event) // your code
  const t = await useTranslationServerMiddleware(event, undefined, user.locale)
  return sendMail(user.email, t('mail.welcome.subject'))
})
```

Argumen kedua menggantikan `defaultLocale` untuk deteksi pada pemanggilan ini, sehingga tidak berpengaruh saat locale dipaksakan. Kamus di-cache per permintaan dan per locale, serta antar permintaan di cache terjemahan server, sehingga memanggil helper beberapa kali itu murah.

## Komponen server {#server-components}

Komponen server (`.server.vue`, `<NuxtIsland>`) dirender dari URL-nya sendiri, `/__nuxt_island/...`, sehingga tidak melihat URL halaman, dan Nuxt hanya memberikan props-nya. Berikan locale sebagai prop `locale`. Komponen kemudian dirender dalam locale tersebut, dan pergantian locale akan mengambilnya lagi, karena props merupakan bagian dari URL dan kunci cache island. Nama ini dicadangkan: kode locale aktif apa pun dalam prop bernama `locale` menetapkan locale render, jadi berikan nama lain untuk prop yang bermakna hal berbeda, seperti format angka:

```vue
<!-- components/Greeting.server.vue -->
<template><p>{{ $t('greeting') }}</p></template>
<script setup lang="ts">
defineProps<{ locale?: string }>()
</script>
```

```vue
<template>
  <Greeting :locale="$getLocale()" />
  <NuxtIsland name="Greeting" :props="{ locale: $getLocale() }" />
</template>
```

Tanpa prop tersebut komponen dirender dalam locale dari cookie, atau locale default jika tidak ada, apa pun isi URL-nya, dan tidak mengikuti pergantian locale. `$t`-nya melihat chunk `index`: file root ditambah `locales/pages/index/`.
