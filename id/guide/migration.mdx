---

Halaman ini memetakan app `@nuxtjs/i18n` ke nuxt-i18n-micro: opsi, helper, dan tata letak file. Gunakan saat Anda mengganti modul di app yang sudah ada. URL Anda tetap sama (nama strateginya sama) dan terjemahan dipindahkan ke file JSON per halaman.

<Tip>

**Ingin meng-upgrade nuxt-i18n-micro itu sendiri?** — Lihat [Upgrade](/id/guide/upgrade).

</Tip>

## Mengganti modul {#swap-the-module}

```bash
npm uninstall @nuxtjs/i18n
npm install nuxt-i18n-micro
```

```ts
// nuxt.config.ts — before
export default defineNuxtConfig({
  modules: ['@nuxtjs/i18n'],
  i18n: {
    locales: [
      { code: 'en', language: 'en-US', file: 'en.json' },
      { code: 'de', language: 'de-DE', file: 'de.json' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    langDir: 'locales',
    detectBrowserLanguage: { useCookie: true, cookieKey: 'i18n_redirected', redirectOn: 'root' },
  },
})
```

```ts
// nuxt.config.ts — after
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    translationDir: 'locales',
    localeCookie: 'i18n_redirected',
    autoDetectPath: '/',
  },
})
```

## Opsi {#options}

| `@nuxtjs/i18n` | nuxt-i18n-micro |
| --- | --- |
| `locales[].code` | `locales[].code` |
| `locales[].language` (`iso` sebelum v9) | `locales[].iso` |
| `locales[].name` | `locales[].displayName` |
| `locales[].dir` | `locales[].dir` |
| `locales[].domain` | `locales[].baseUrl` (origin beserta skemanya) |
| `locales[].domainDefault` | `locales[].baseDefault` |
| `differentDomains`, `multiDomainLocales` | tidak diperlukan: `baseUrl` saja sudah merutekan berdasarkan host, lihat [Layer dan domain](/id/guide/layers#multiple-domains) |
| `locales[].file` / `files`, `langDir`, `lazy` | `translationDir`; file ditemukan berdasarkan nama dan selalu dimuat per halaman |
| `defaultLocale`, `strategy` | nama yang sama, empat nilai yang sama |
| `baseUrl` | `metaBaseUrl` |
| `customRoutes: 'config'` + `pages` | `globalLocaleRoutes` |
| `detectBrowserLanguage: false` | `redirects: false` (tanpa redirect) atau `autoDetectLanguage: false` (abaikan header) |
| `detectBrowserLanguage.useCookie` / `cookieKey` | `localeCookie: '<name>'` (`null` menonaktifkan cookie) |
| `detectBrowserLanguage.redirectOn: 'root'` | `autoDetectPath: '/'` (default) |
| `detectBrowserLanguage.redirectOn: 'no prefix'` | `autoDetectPath: 'no_prefix'` |
| `detectBrowserLanguage.redirectOn: 'all'` | `autoDetectPath: '*'` |
| File konfigurasi `vueI18n` (`fallbackLocale`, `numberFormats`, `datetimeFormats`) | `fallbackLocale`, `numberFormats`, `datetimeFormats` di `i18n` |

Tidak ada `alwaysRedirect`: dengan cookie yang sudah diatur, `/` mengikutinya di setiap kunjungan. Daftar lengkapnya ada di [Opsi modul](/id/api/module-options); aturan deteksi ada di [Deteksi locale](/id/guide/locale-detection).

## Helper dan composable {#helpers-and-composables}

| `@nuxtjs/i18n` / vue-i18n | nuxt-i18n-micro (template / `useI18n()`) |
| --- | --- |
| `const { t } = useI18n()` | `const { t } = useI18n()`, `$t` di template |
| `t('key', count)`, `tc` | `$tc('key', count)` |
| `te('key')` | `$has('key')` |
| `n(value, 'currency')`, `d(date, 'short')` | `$tn(value, 'currency')`, `$td(date, 'short')` |
| — | `$tdr(date)`: waktu relatif ("dalam 3 hari") |
| `locale.value` | `$getLocale()` |
| `locales.value` | `$getLocales()` |
| `setLocale('de')` | `$switchLocale('de')` |
| `useLocalePath()('about')` | `$localePath({ name: 'about' })` |
| `useLocaleRoute()` | `$localeRoute()` |
| `useSwitchLocalePath()('de')` | `$switchLocalePath('de')` |
| `useSetI18nParams()` | `$setI18nRouteParams()` |
| `useLocaleHead()` | otomatis dengan `meta: true`; [`useLocaleHead`](/id/composables/useLocaleHead) untuk head kustom |
| `defineI18nRoute({ paths: { de: '/ueber-uns' }, locales: [...] })` | `$defineI18nRoute({ localeRoutes: { de: '/ueber-uns' }, locales: [...] })` |
| `<NuxtLinkLocale to="about">` | `<i18n-link :to="{ name: 'about' }">` |
| `<i18n-t>` | `<i18n-t>` (slot mengisi placeholder `{name}`) |
| `$i18n` di server route | `useTranslationServerMiddleware(event)`, lihat [Server route dan API](/id/guide/server-side-translations) |

`useI18n()` diimpor secara otomatis. `$defineI18nRoute` harus mempertahankan `$`-nya: build membaca pemanggilan tersebut. Semua helper: [Metode](/id/api/methods).

## File terjemahan {#translation-files}

Pindahkan key dari satu file besar per locale ke file root ditambah satu file per halaman:

```text
locales/
├── en.json              # keys used on many pages (nav, footer)
├── de.json
└── pages/
    ├── index/en.json    # keys of pages/index.vue
    └── about/en.json    # keys of pages/about.vue
```

Menyimpan semuanya di file root juga berfungsi, dan merupakan langkah awal yang paling cepat. Atur `disablePageLocales: true` sampai Anda memecahnya. Lihat [File terjemahan](/id/guide/translations).

### Sintaks pesan {#message-syntax}

| vue-i18n | nuxt-i18n-micro |
| --- | --- |
| Interpolasi bernama `{name}` | sama |
| `car \| cars` (2 bentuk: 1 → yang pertama) | bentuk dipilih berdasarkan jumlah mulai dari 0: tulis `no cars \| one car \| {count} cars` |
| Linked messages `@:other.key` | tidak didukung: ulangi teksnya atau susun di kode |
| Modifier `@.upper:` | tidak didukung: format di kode atau gunakan `<i18n-t>` |
| Escape literal `{'@'}` | tidak diperlukan: hanya token `{word}` yang diganti |
| File pesan JS/TS | hanya JSON |

Aturan jamak dapat diganti dengan opsi [`plural`](/id/api/module-options#plural).

## Periksa setelah peralihan {#check-after-the-switch}

- Setiap URL yang Anda miliki masih dapat di-resolve; nama strategi sama, path kustom dipindahkan ke `globalLocaleRoutes` atau `$defineI18nRoute`.
- `hreflang`, canonical, dan `og:locale` tersedia langsung dengan `meta: true`; hapus yang ditulis manual.
- Error parse JSON mencatat path file; key yang hilang mencatat peringatan di konsol browser dalam mode dev.
