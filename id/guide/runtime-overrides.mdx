---
title: "Override runtime"
description: "Ubah locale default, locale fallback, atau locale yang dinonaktifkan per instance dari satu build, dengan variabel lingkungan atau runtimeConfig."
---

Override runtime memungkinkan satu artefak build berjalan dengan pengaturan locale yang berbeda per lingkungan atau tenant, tanpa build ulang. Anda dapat mengubah locale default, locale fallback, dan locale mana saja yang dinonaktifkan. Routing, redirect, rendering, dan helper server menggunakan nilai yang di-override, begitu pula browser pada halaman yang dirender di server.

## Mengatur override dengan variabel lingkungan {#set-overrides-with-environment-variables}

```bash
NUXT_I18N_DEFAULT_LOCALE=de \
NUXT_I18N_FALLBACK_LOCALE=en \
NUXT_I18N_DISABLED_LOCALES=fr,it \
node .output/server/index.mjs
```

| Variabel | Alias |
| --- | --- |
| `NUXT_I18N_DEFAULT_LOCALE` | `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE` |
| `NUXT_I18N_FALLBACK_LOCALE` | `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE` |
| `NUXT_I18N_DISABLED_LOCALES` (dipisahkan koma) | `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES` |

Server membacanya sekali saat start; restart untuk menerapkan perubahan. Pada halaman yang dirender di server, browser mendapat nilai yang sudah di-resolve dari server. Dengan `ssr: false` tidak ada render server dan browser tidak memiliki environment: hanya `runtimeConfig.public.i18nRuntime` yang berlaku di sana, dan browser mencatat peringatan di bawah ini.

## Mengatur override di runtimeConfig {#set-overrides-in-runtimeconfig}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

Nilai yang diatur di `runtimeConfig.public.i18nRuntime` mengalahkan variabel `NUXT_I18N_*` untuk field yang sama.

Jangan disamakan dengan variabel `DEFAULT_LOCALE` saat build, yang menggantikan `defaultLocale` selama build dan tidak membutuhkan dukungan runtime.

## Apa yang bisa dan tidak bisa diubah {#what-can-and-cannot-change}

| Pengaturan | Saat runtime |
| --- | --- |
| `defaultLocale` | Ya di bawah `prefix` dan `no_prefix`. Di bawah `prefix_except_default` dan `prefix_and_default` nilainya tetap sejak build (halamannya adalah route tanpa prefiks); override diabaikan dengan peringatan. |
| `fallbackLocale` | Ya. |
| `disabledLocales` | Menambah locale yang dinonaktifkan saat build; tidak pernah mengaktifkan kembali. Default build tidak dapat dinonaktifkan di bawah `prefix_except_default` / `prefix_and_default`. |
| `strategy` | Tidak. Strategi runtime diabaikan dengan peringatan; buat satu artefak build per strategi. |

Nilai yang tidak valid tidak pernah merusak app. Setiap kasus mencatat satu peringatan per proses server:

- menonaktifkan semua locale diabaikan;
- `defaultLocale` yang tidak aktif beralih ke locale aktif pertama;
- `fallbackLocale` yang tidak aktif mempertahankan nilai build jika nilai tersebut aktif, jika tidak, tidak ada fallback.

## Membaca konfigurasi efektif {#read-the-effective-config}

```vue
<script setup lang="ts">
const { $getI18nConfig } = useNuxtApp()
const config = $getI18nConfig() // build config with overrides applied
</script>
```

Perlakukan sebagai read-only: di server konfigurasi ini dibagikan oleh setiap request dan dibekukan dalam mode pengembangan; salinan di browser tidak dibekukan. Mengimpor konfigurasi dari `#build/i18n.strategy.mjs` memberikan nilai build tanpa override.

## Locale yang dinonaktifkan dan file statis {#disabled-locales-and-static-files}

Locale yang dinonaktifkan saat runtime menjawab 404 pada route-nya dan route payload-nya, tetapi file payload-nya masih ada di `.output/public/_locales/` dan server file statis tetap mengembalikannya. Jika file tersebut tidak boleh dapat diakses, nonaktifkan locale saat build dengan `disabled: true`.
