Jawaban singkat untuk masalah yang paling sering ditemui, untuk pertanyaan yang tidak dijawab langsung oleh halaman topik. Setiap jawaban menautkan halaman yang membahas topik tersebut. Jika masalah Anda tidak ada di sini, cari di dokumentasi atau buka [issue](https://github.com/s00d/nuxt-i18n-micro/issues).

## Terjemahan {#translations}

### `$t` gagal di plugin atau fungsi utilitas {#$t-fails-in-a-plugin-or-a-utility-function}

Composable membutuhkan konteks Nuxt. Di luar `setup`, ambil helper dari app, atau jalankan dalam konteksnya setelah `await`:

```ts
const nuxtApp = useNuxtApp()
const title = nuxtApp.$t('errors.unknown')
await nuxtApp.runWithContext(() => nuxtApp.$t('errors.unknown'))
```

Di service yang sama sekali tidak memiliki app, teruskan key dan terjemahkan di dalam komponen.

### Sebuah key tampil sebagai teks mentah hanya di satu halaman {#a-key-shows-as-raw-text-on-one-page-only}

Key tersebut ada di file milik halaman lain. Sebuah halaman hanya melihat file root dan file `locales/pages/<route-name>/` miliknya sendiri; pindahkan key bersama ke file root. Lihat [File terjemahan](/id/guide/translations).

### Key berkedip saat transisi halaman berjalan {#keys-flash-while-a-page-transition-runs}

Seharusnya tidak: key halaman yang ditinggalkan tetap ter-resolve sampai transisi selesai. Jika masih berkedip, key tersebut hanya ada di file halaman yang tidak dimiliki oleh kedua halaman (misalnya di layout); pindahkan ke file root.

### Terjemahan hilang saat SSR di Vercel, Netlify, atau Edge {#translations-are-missing-during-ssr-on-vercel-netlify-or-edge}

Fungsi server tidak dapat membaca `public/` di sana, sehingga payload disematkan ke dalam bundle server. Itu adalah default-nya; pastikan `translationPayloads.serverAssets` tidak dimatikan. Jika log menyebutkan `public/ is not deployed next to the server`, atur `nitro.serveStatic: false`. Lihat [Deployment](/id/guide/deployment).

### Bagaimana cara menaruh link di dalam kalimat terjemahan? {#how-do-i-put-a-link-inside-a-translated-sentence}

Gunakan `<i18n-t>`: setiap slot bernama mengisi `{placeholder}` dengan nama yang sama.

```vue
<!-- "share": "Share your {link} with friends" -->
<i18n-t keypath="share">
  <template #link>
    <i18n-link :to="{ name: 'referral' }">{{ $t('referralLink') }}</i18n-link>
  </template>
</i18n-t>
```

Lihat [`<i18n-t>`](/id/components/i18n-t). Linked messages dan modifier dari vue-i18n tidak didukung; susun di template seperti ini.

## Locale dan URL {#locales-and-urls}

### `/en/about` menghasilkan 404 {#/en/about-is-a-404}

Dengan `prefix_except_default` default, locale default tidak memiliki prefiks: `/about` adalah bahasa Inggris. Gunakan `prefix` atau `prefix_and_default` jika Anda menginginkan `/en/...`. Lihat [Strategi routing](/id/guide/strategy).

### Pengunjung tidak di-redirect pada deep link {#visitors-are-not-redirected-on-deep-links}

Secara default hanya `/` yang mengikuti bahasa browser atau cookie, sehingga link yang dibagikan tetap mempertahankan bahasanya. Atur `autoDetectPath: 'no_prefix'` atau `'*'`. Lihat [Deteksi locale](/id/guide/locale-detection#autodetectpath).

### Bahasa yang dipilih terlupakan setelah reload {#the-chosen-language-is-forgotten-after-a-reload}

Cookie locale dinonaktifkan untuk strategi prefiks. Atur `localeCookie: 'user-locale'`. Lihat [Deteksi locale](/id/guide/locale-detection#the-cookie).

### Bisakah saya mengganti locale tanpa mengubah URL? {#can-i-switch-locale-without-changing-the-url}

Hanya dengan `strategy: 'no_prefix'`, di mana `$switchLocale('de')` memuat ulang kamus pada path yang sama. Pada strategi prefiks, locale adalah bagian dari URL, sehingga mengganti locale berarti bernavigasi. Untuk link alih-alih pemanggilan, gunakan `$switchLocalePath('de')`.

### Halaman bergulir ke atas saat saya mengganti locale {#the-page-scrolls-to-the-top-when-i-switch-locale}

Itu adalah `scrollBehavior` Nuxt untuk setiap navigasi. Atur `definePageMeta({ scrollToTop: false })` dan pulihkan posisinya sendiri. [`SwitchLocalePreserve.vue`](https://github.com/s00d/nuxt-i18n-micro/blob/main/playground/components/SwitchLocalePreserve.vue) di playground adalah wrapper yang dapat disalin ([halaman demo](https://github.com/s00d/nuxt-i18n-micro/blob/main/playground/pages/scroll-test.vue)).

## Build dan integrasi {#build-and-integrations}

### `nuxt-seo:defaults depends on nuxt-site-config:i18n but they are not registered` {#nuxt-seodefaults-depends-on-nuxt-site-configi18n-but-they-are-not-registered}

`nuxt-site-config` versi lama hanya mengenal `@nuxtjs/i18n`. Upgrade `@nuxtjs/seo` ke versi 3 atau lebih baru dan cantumkan `nuxt-i18n-micro` sebelumnya di `modules`. Lihat [SEO](/id/guide/seo).

### Error build terkait `@unhead/vue` di Cloudflare {#build-error-about-@unhead/vue-on-cloudflare}

Pasang `@unhead/vue` di app agar langkah prerender dapat menemukannya. Modul itu sendiri tidak membutuhkan `nodejs_compat`: tambahkan `compatibility_flags = ["nodejs_compat"]` ke `wrangler.toml` hanya jika ada bagian lain dari app yang membutuhkannya.
