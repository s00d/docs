---
title: "Deteksi locale kustom"
description: "Pilih locale sendiri — berdasarkan domain, header, atau profil pengguna — dengan plugin server dan useI18nLocale().setLocale()."
---

Deteksi bawaan membaca URL, cookie, dan `Accept-Language`. Ketika locale bergantung pada hal lain — domain, header geo yang diatur oleh CDN Anda, profil pengguna — atur sendiri di plugin yang berjalan sebelum plugin i18n. Modul kemudian memuat terjemahan locale tersebut dan menggunakannya untuk redirect persis seolah-olah modul sendiri yang mendeteksinya. Aturan yang menentukan kapan locale yang dipilih mengalahkan URL ada di [Deteksi locale](/id/guide/locale-detection); halaman ini menunjukkan cara memasang sumber Anda sendiri.

## Atur locale di plugin server {#set-the-locale-in-a-server-plugin}

```ts
// plugins/i18n-locale.server.ts
export default defineNuxtPlugin({
  name: 'i18n-custom-locale',
  enforce: 'pre',
  order: -10, // before the i18n plugin (order -5)
  setup() {
    const { setLocale } = useI18nLocale()
    const host = (useRequestHeaders(['host']).host ?? '').split(':')[0]! // without the port

    if (host.endsWith('.de')) setLocale('de')
    else if (host.endsWith('.fr')) setLocale('fr')
  },
})
```

`setLocale(code)` menulis state locale (`useState('i18n-locale')`) dan, jika cookie locale dikonfigurasi, juga cookie-nya. Gunakan ini alih-alih menulis `useState` atau `useCookie` sendiri. Hanya berikan kode locale yang diaktifkan.

Pertahankan plugin sebagai `.server.ts` jika membaca header permintaan: header tersebut tidak ada di browser. Plugin `.client.ts` adalah tempat untuk sumber yang hanya ada di browser seperti `localStorage`.

## Matikan langkah Accept-Language bawaan {#turn-off-the-built-in-accept-language-step}

Plugin Anda dan `Accept-Language` bisa saja tidak sepakat. Agar hanya kode Anda (ditambah URL dan cookie) yang menentukan, matikan header tersebut:

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    autoDetectLanguage: false,
  },
})
```

[`autoDetectLanguage`](/id/api/module-options#autodetectlanguage) hanya mengontrol langkah header. URL dan cookie yang valid tetap diperhitungkan.

## Apa yang terjadi selanjutnya {#what-happens-next}

Efek `setLocale` bergantung pada [strategi](/id/guide/strategy):

| Strategi | Efek `setLocale('de')` di plugin |
| --- | --- |
| `no_prefix` | Halaman dirender dalam bahasa Jerman; URL tidak berubah. |
| `prefix`, `prefix_except_default` | Pada path tanpa prefiks di mana [`autoDetectPath`](/id/api/module-options#autodetectpath) mengizinkan redirect (secara default hanya `/`), server merespons `302` ke URL berbahasa Jerman. URL dengan prefiks locale tetap mempertahankannya. |
| `prefix_and_default` | Tidak ada redirect: URL tanpa prefiks adalah halaman locale default yang valid. |

Pada strategi prefiks, locale di URL adalah pilihan pengguna dan plugin Anda tidak menimpanya. `autoDetectPath: '*'` adalah pengecualiannya: server kemudian memindahkan URL berprefiks berdasarkan cookie dan `Accept-Language` serta mengabaikan state, tetapi `setLocale()` juga menulis cookie jika dikonfigurasi, sehingga sejak permintaan berikutnya pilihan plugin Anda dapat me-redirect URL berprefiks. Pertahankan `'/'` atau gunakan `'no_prefix'` jika URL locale eksplisit harus menang. Gunakan plugin Anda untuk memilih ke mana pengunjung mendarat, bukan untuk menulis ulang tautan yang mereka ikuti.

## Hormati locale yang dipilih pengguna {#respect-a-locale-the-user-picked}

Begitu pengguna berganti bahasa, pergantian tersebut menulis cookie. Lewati deteksi Anda sendiri jika sudah ada preferensi yang valid:

```ts
// plugins/i18n-locale.server.ts
import { detectLocaleFromAcceptLanguage } from '@i18n-micro/utils/accept-language'

export default defineNuxtPlugin({
  name: 'i18n-custom-locale',
  enforce: 'pre',
  order: -10,
  setup() {
    const { getPreferredLocale, setLocale, validLocales } = useI18nLocale()
    if (getPreferredLocale()) return // valid state or cookie: keep it

    const country = useRequestHeaders(['x-country'])['x-country']
    if (country === 'JP') return setLocale('ja')

    const header = useRequestHeaders(['accept-language'])['accept-language']
    setLocale(detectLocaleFromAcceptLanguage(header, validLocales))
  },
})
```

`getPreferredLocale()` mengembalikan state atau cookie hanya jika nilainya adalah locale yang diaktifkan, sehingga cookie yang usang tidak menghentikan deteksi. `detectLocaleFromAcceptLanguage` adalah pencocok yang memperhitungkan q-value yang digunakan modul itu sendiri (instal `@i18n-micro/utils` untuk mengimpornya); `setLocale(null)` tidak melakukan apa-apa.

## Satu domain per locale {#one-domain-per-locale}

Jika setiap domain harus menyajikan locale-nya sendiri, Anda tidak memerlukan plugin: beri setiap locale sebuah `baseUrl`, atur `baseDefault: true` pada locale default setiap domain, dan build sekali (situs statis tetap menjalankan `nuxi generate` per domain). Lihat [Layer dan domain](/id/guide/layers#multiple-domains).
