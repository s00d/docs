### Deskripsi {#description}

Membandingkan **Nuxt polos**, **i18n-micro**, dan **`@nuxtjs/i18n`** dengan satu profil kamus bersama melalui `untestutils/perf`.

Fokus: waktu build, RSS puncak, **kode vs terjemahan (aset) vs total** yang dapat di-deploy, dan beban (Artillery).

### Catatan metodologi {#methodology-notes}

- Metrik adalah **rata-rata dari 3 kali eksekusi berturut-turut per fixture** (tidak diselang-seling).
- **Artefak**: Nitro node-server `.output/server/index.mjs` setelah `nuxi build` yang dipaksa; `nuxt-i18n-micro` adalah **dist modul hasil build** (bukan stub jiti `dev:prepare`). Lihat [metodologi benchmark](https://s00d.github.io/nuxt-i18n-micro/contributing/performance-methodology).
- **Terjemahan** = `bundle.asset` (JSON locale, `chunks/raw/`, chunk locale yang cocok melalui `isTranslationFile`).
- **Kode** tidak menyertakan source map (`*.map`): fixture menautkan modul dari repo, sehingga Nitro menulis map lengkap untuknya dan tidak ada untuk dependensi npm.
- **plain-nuxt** menyajikan volume leaf yang sama sebagai JSON statis — berat di I/O saat dibebani, bukan "overhead i18n".
- Profil beban `--load full`: warm 6s@6 + main 60s@60 tanpa batas (historis).
- Jeda pendinginan `--cool fast` (lihat dokumen metodologi).
- Setiap build dari `runs` **dipaksa** (tanpa pengosongan waktu build karena cache hangat).
- **Error rate** Artillery di tabel adalah error status HTTP dari metrik beban. Grafik juga memplot `vusers.failed` (timeout klien saat saturasi); nilainya bisa tinggi sementara error rate HTTP tetap 0%.
### Eksekusi {#runs}

Semua metrik di bawah adalah **rata-rata dari 3 kali eksekusi**.

## Catatan {#notes}

- Profil bersama: 4 locale × 2 halaman × ~16.8k leaf index.
- Beban: hanya Artillery terprogram — warm **6s@6** + main **60s@60**, VU tanpa batas (metodologi YAML historis). Path dari profil runtime — lihat `scripts/src/perf/load.ts`.
- Jeda pendinginan: 2s setelah build, 3s antar eksekusi, 5s antar fixture. Build dipaksa di setiap eksekusi agar rata-rata tidak terdilusi oleh cache hit.
- Jalankan ulang sehari-hari: `pnpm test:performance` (`--load short --cool fast`).
- Buat ulang halaman ini: `pnpm -C scripts cli performance --load full --only all --runs 3`.
- Flag: `--locales N --keys K --only all|micro|i18n|plain --runs N --skip-load --cool fast|strict`.
