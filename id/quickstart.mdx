## 🚀 Mulai cepat

### Instalasi

Instal modul di aplikasi Nuxt Anda:

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

### Konfigurasi dasar

Tambahkan modul ke `nuxt.config.ts` Anda:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

<Tip>
- **File tingkat root** (`locales/en.json`, dll.) — terjemahan yang digunakan bersama di seluruh aplikasi (menu, footer, UI umum). Dengan `translationPayloads.mode: 'premerged'` (default), file-file ini digabungkan ke setiap halaman saat build.
- **File per halaman** (`locales/pages/<route>/<locale>.json`) — terjemahan unik untuk halaman tertentu, hanya dimuat saat halaman dikunjungi
- **Rute dinamis** — `pages/articles/[id].vue` dipetakan ke `locales/pages/articles-id/` (tanda kurung siku diganti dengan tanda hubung)
- **Pembuatan otomatis** — semua file terjemahan dibuat secara otomatis jika belum ada selama `nuxt dev`
</Tip>

<Info>
Modul mendukung kedua tata letak:

- **Pages**: `pages/**/*.vue` (Nuxt 3) atau `app/pages/**/*.vue` (Nuxt 4)
- **Terjemahan**: simpan `locales/` di **root proyek** secara default (konvensi yang direkomendasikan), bukan di dalam `app/`

```tree
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   ├── en.json
│   └── pages/
└── nuxt.config.ts
```

Kolokasi opsional: `i18n: \{ translationDir: 'app/locales' \}` (lihat [fixture `n3`](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/n3)).

Untuk helper CLI opsional `text-to-i18n`, gunakan [`nuxt-i18n-micro-cli` ≥ 2.1.1](/guides/cli#-text-to-i18n-command) agar `app/pages` dan `app/components` dipindai dari root proyek.
</Info>

### Penggunaan dasar

Gunakan terjemahan pada komponen Anda:

```vue
<template>
  <div>
    <h1>{{ $t('welcome') }}</h1>
    <p>{{ $t('description', { name: 'World' }) }}</p>

    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" @click="$switchLocale(locale.code)">
        {{ locale.code }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useI18n } from '#imports'

const { $t, $getLocales, $switchLocale } = useI18n()
</script>
```
