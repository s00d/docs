# 🧪 Menguji Modul `Nuxt I18n Micro`

## 📖 Pengenalan Pengujian

Menguji modul `Nuxt I18n Micro` sangat penting untuk memastikan fitur lokalisasi aplikasi Anda bekerja sesuai harapan. Dokumentasi ini akan memandu Anda melalui pengaturan lingkungan pengujian, pembuatan konfigurasi mock untuk vitest, dan penulisan pengujian untuk komponen Anda. Untuk contoh praktik, Anda dapat merujuk ke [proyek contoh di GitHub](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/test-utils/example).

Lihat [Menguji strategi perutean](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/testing-strategies.md) untuk melihat bagaimana repositori ini menjalankan suite pengujiannya sendiri — proyek Vitest `unit` / `integration` / `e2e`, file per strategi (`test/strategies-*.test.ts`), dan regresi generate.

## 🛠️ Menyiapkan Lingkungan Pengujian

### 1. Instal `@i18n-micro/test-utils`

Pertama, Anda perlu menginstal utilitas pengujian untuk `Nuxt I18n Micro`. Paket ini menyediakan alat-alat yang dibutuhkan untuk mem-mock dan menguji konfigurasi i18n Anda.

```bash
npm install @i18n-micro/test-utils --save-dev
```

### 2. Buat File Konfigurasi Mock

Selanjutnya, buat sebuah file untuk menyiapkan konfigurasi mock i18n. File ini akan digunakan untuk mem-mock fungsi dan utilitas i18n selama pengujian Anda.

```typescript
// tests/unit-setup.ts

import { mockNuxtImport } from '@nuxt/test-utils/runtime'
import { vi } from 'vitest'
import { i18nUtils } from '@i18n-micro/test-utils'

export function createFakeI18n() {
  return {
    $getLocale: vi.fn(i18nUtils.getLocale),
    $t: vi.fn(i18nUtils.t),
    $tc: vi.fn(i18nUtils.tc),
    $setLocale: vi.fn(i18nUtils.setLocale),
    $getLocaleName: vi.fn(i18nUtils.getLocaleName),
    $setLocaleName: vi.fn(i18nUtils.setLocaleName),
    $getLocales: vi.fn(i18nUtils.getLocales),
    $setLocales: vi.fn(i18nUtils.setLocales),
    $defaultLocale: vi.fn(i18nUtils.defaultLocale),
    $setDefaultLocale: vi.fn(i18nUtils.setDefaultLocale),
    $getRouteName: vi.fn(i18nUtils.getRouteName),
    $settRouteName: vi.fn(i18nUtils.settRouteName),
    $ts: vi.fn(i18nUtils.ts),
    $tn: vi.fn(i18nUtils.tn),
    $td: vi.fn(i18nUtils.td),
    $has: vi.fn(i18nUtils.has),
    $resolveTranslations: vi.fn(i18nUtils.resolveTranslations),
    $setTranslation: vi.fn(i18nUtils.setTranslation),
    $mergeTranslations: vi.fn(i18nUtils.mergeTranslations),
    $switchLocaleRoute: vi.fn(i18nUtils.switchLocaleRoute),
    $switchLocalePath: vi.fn(i18nUtils.switchLocalePath),
    $switchLocale: vi.fn(i18nUtils.switchLocale),
    $switchRoute: vi.fn(i18nUtils.switchRoute),
    $localeRoute: vi.fn(i18nUtils.localeRoute),
    $localePath: vi.fn(i18nUtils.localePath),
    $setI18nRouteParams: vi.fn(i18nUtils.setI18nRouteParams),
  }
}

mockNuxtImport<() => ReturnType<typeof createFakeI18n>>('useI18n', () => vi.fn(() => createFakeI18n()))

export const setTranslationsFromJson = i18nUtils.setTranslationsFromJson
```

### 3. Konfigurasikan Vitest

Sekarang, konfigurasikan Vitest untuk menggunakan file konfigurasi mock dan menyiapkan lingkungan pengujian.

```typescript
// vitest.config.ts

import { defineVitestConfig } from '@nuxt/test-utils/config'

export default defineVitestConfig({
  test: {
    watch: false,
    setupFiles: ['./tests/unit-setup.ts'],
    include: ['./**/*.spec.ts'],
  },
})
```

## 🧪 Menulis Pengujian

### Contoh Komponen

Berikut contoh komponen sederhana yang menggunakan composable `useI18n` untuk menerjemahkan pesan.

```vue
<script setup lang="ts">
const { $t } = useI18n()

const props = defineProps({
  message: {
    type: String,
    default: null,
  },
})

// Test to see that $t works in script setup as well as the template
const message = props.message || $t('defaultMessage')
</script>

<template>
  <div>
    <p>Test from component: {{ $t('welcome') }}</p>
    <p data-testid="message">Test message from props: {{ message }}</p>
  </div>
</template>
```

### File Pengujian

Sekarang, mari kita tulis pengujian untuk komponen ini.

```typescript
// tests/unit/example.spec.ts

import { describe, it, expect, beforeEach } from 'vitest'
import { mount } from '@vue/test-utils'
import ExampleComponent from '@/components/ExampleComponent.vue'
import fs from 'fs'
import path from 'path'
import { setTranslationsFromJson } from './unit-setup'

describe('ExampleComponent', () => {
  beforeEach(async () => {
    const fileContent = fs.readFileSync(path.join(__dirname, '../../locales/en-GB.json')).toString()
    await setTranslationsFromJson('en', JSON.parse(fileContent))
  })

  it('renders the welcome message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.text()).toContain('Test from component: Welcome')
  })

  it('renders the default message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Default Message')
  })

  it('renders the custom message correctly', () => {
    const wrapper = mount(ExampleComponent, {
      props: {
        message: 'Custom Message',
      },
    })
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Custom Message')
  })
})
```

## 📝 Praktik Terbaik untuk Pengujian

- **🔧 Mock Fungsi i18n:** Selalu mock fungsi i18n menggunakan `@i18n-micro/test-utils` untuk memastikan hasil pengujian yang konsisten dan dapat diprediksi.
- **⚙️ Gunakan Vitest untuk Unit Test:** Vitest adalah kerangka pengujian yang kuat untuk aplikasi Vue. Gunakan untuk menulis unit test bagi komponen Anda.
- **📚 Dokumentasikan Pengujian Anda:** Dokumentasikan tujuan dan hasil yang diharapkan dari setiap pengujian dengan jelas. Ini akan menjaga kejelasan dan mempermudah orang lain (atau Anda di masa depan) untuk memahami pengujian tersebut.

## 📊 Method Utilitas i18n

Di bawah ini adalah tabel yang menjelaskan semua method utilitas yang disediakan oleh `@i18n-micro/test-utils`.

| Method                                          | Deskripsi                                                                                                                                |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `t(key, params, defaultValue)`                  | Menerjemahkan kunci dengan parameter opsional dan nilai default.                                                                             |
| `tc(key, params, defaultValue)`                 | Menerjemahkan kunci dengan dukungan pluralisasi.                                                                                               |
| `setTranslationsFromJson(locale, translations)` | Memuat terjemahan dari objek JSON untuk lokal tertentu.                                                                               |
| `getLocale()`                                   | Mengembalikan lokal saat ini.                                                                                                                |
| `setLocale(val)`                                | Mengatur lokal saat ini.                                                                                                                   |
| `getLocaleName()`                               | Mengembalikan nama lokal saat ini.                                                                                                           |
| `setLocaleName(val)`                            | Mengatur nama lokal saat ini.                                                                                                              |
| `getLocales()`                                  | Mengembalikan daftar lokal yang tersedia.                                                                                                     |
| `setLocales(val)`                               | Mengatur daftar lokal yang tersedia.                                                                                                        |
| `defaultLocale()`                               | Mengembalikan lokal default.                                                                                                                |
| `setDefaultLocale(val)`                         | Mengatur lokal default.                                                                                                                   |
| `getRouteName()`                                | Mengembalikan nama rute saat ini.                                                                                                            |
| `settRouteName(val)`                            | Mengatur nama rute saat ini.                                                                                                               |
| `ts(key, params, defaultValue)`                 | Menerjemahkan kunci dan mengembalikan hasilnya sebagai string.                                                                                       |
| `tn(value, options?)`                           | Memformat angka dengan `Intl.NumberFormatOptions` inline. Format bernama membutuhkan konfigurasi modul dan tidak tersedia di helper mandiri ini. |
| `td(value, options?)`                           | Memformat tanggal dengan `Intl.DateTimeFormatOptions` inline. Format bernama membutuhkan konfigurasi modul dan tidak tersedia di helper mandiri ini. |
| `has(key)`                                      | Memeriksa apakah kunci terjemahan ada.                                                                                                        |
| `resolveTranslations()`                             | Mengembalikan pohon terjemahan aktif untuk lokal dan rute saat ini.                                                                      |
| `setTranslation(key, value)`                    | Mengganti nilai pada `key` di kamus aktif (ganti, bukan gabung).                                                                 |
| `mergeTranslations(newTranslations)`              | Menggabungkan terjemahan ke lokal aktif pada runtime.                                                                                     |

Dengan mengikuti langkah-langkah ini, Anda dapat menguji modul `Nuxt I18n Micro` secara efektif dan memastikan fitur lokalisasi aplikasi Anda berjalan seperti yang diharapkan.
