# Mengecualikan File Statis dari Perutean i18n

## Ikhtisar

Secara default, nuxt-i18n-micro secara otomatis mengecualikan file statis umum dari pemrosesan perutean i18n. Namun, Anda juga dapat mengonfigurasi pola pengecualian kustom untuk mencegah jalur tertentu diproses oleh sistem i18n.

## Pengecualian Bawaan

Modul ini secara otomatis mengecualikan jenis dan pola file berikut:

- **Sitemap**: `/sitemap*.xml`, `/sitemap-en.xml`, dll.
- **File SEO**: `/robots.txt`, `/favicon.ico`
- **File PWA**: `/manifest.json`, `/sw.js`, `/workbox-*.js`
- **Aset statis**: File dengan ekstensi seperti `.xml`, `.txt`, `.ico`, `.json`, `.js`, `.css`, `.png`, `.jpg`, `.jpeg`, `.gif`, `.svg`, `.woff`, `.woff2`, `.ttf`, `.eot`
- **Jalur internal Nuxt**: Jalur apa pun yang diawali dengan `__` (seperti `/__nuxt/`)

## Pola Pengecualian Kustom

Anda dapat mendefinisikan pola pengecualian kustom menggunakan opsi `excludePatterns`:

```typescript
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],

  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'it', iso: 'it-IT' },
    ],
    defaultLocale: 'en',

    // Custom exclusion patterns
    excludePatterns: [
      // String patterns (exact match or prefix)
      '/api/health',
      '/admin',

      // String patterns with wildcards
      '/api/*',
      '/admin/**',

      // Regular expressions
      /^\/api\/v\d+\//,
      /\.(pdf|doc|docx)$/,
    ],
  },
})
```

## Jenis Pola

### Pola String

- **Cocok tepat**: `'/api/health'` - cocok tepat dengan `/api/health`
- **Cocok awalan**: `'/admin'` - cocok dengan `/admin` dan `/admin/dashboard`
- **Wildcard**: `'/api/*'` - cocok dengan `/api/users` tetapi tidak dengan `/api/users/123`
- **Wildcard dalam**: `'/admin/**'` - cocok dengan `/admin/users` dan `/admin/users/123`

### Ekspresi Reguler

Gunakan objek RegExp untuk pencocokan pola yang kompleks:

```typescript
excludePatterns: [
  /^\/api\/v\d+\//, // API versioned routes
  /\.(pdf|doc|docx)$/, // Document files
  /^\/static\//, // Static directory
  /^\/[a-z]{2}\/api\//, // Localized API routes
]
```

## Kasus Penggunaan

### File SEO

```typescript
excludePatterns: ['/sitemap.xml', '/sitemap-*.xml', '/robots.txt', '/favicon.ico']
```

### Rute API

```typescript
excludePatterns: ['/api/**', '/graphql', '/webhook/**']
```

### Panel Admin

```typescript
excludePatterns: ['/admin', '/admin/**', '/dashboard']
```

### Aset Statis

```typescript
excludePatterns: ['/assets/**', '/static/**', '/uploads/**']
```

## Cara Kerja

1. **Middleware Server**: Middleware Nitro berjalan terlebih dahulu untuk memeriksa pola pengecualian
2. **Pemrosesan Halaman**: Selama resolusi halaman, jalur yang dikecualikan dilewati
3. **Rute Catch-all**: Rute fallback memeriksa pengecualian sebelum diproses
4. **Prerendering**: Jalur yang dikecualikan tidak dimasukkan dalam rute yang di-prerender

## Dampak Performa

- Pemeriksaan pengecualian dioptimalkan dan berjalan lebih awal dalam siklus hidup permintaan
- Pola bawaan menggunakan pencocokan regex yang efisien
- Pola kustom di-cache dan digunakan kembali
- Overhead performa minimal untuk jalur yang dikecualikan

## Pemecahan Masalah

### File Statis Masih Diintersep

1. **Periksa sintaks pola**: Pastikan pola Anda cocok dengan struktur jalur yang tepat
2. **Gunakan regex untuk pola kompleks**: Wildcard string memiliki keterbatasan
3. **Uji pola**: Gunakan browser dev tools untuk memverifikasi jalur permintaan sebenarnya
4. **Periksa urutan**: Pastikan pola pengecualian didefinisikan sebelum konfigurasi i18n lainnya

### Pola Tidak Bekerja

```typescript
// ❌ Wrong - this won't work
excludePatterns: ['sitemap.xml']

// ✅ Correct - include leading slash
excludePatterns: ['/sitemap.xml']

// ✅ Better - use regex for flexibility
excludePatterns: [/^\/sitemap.*\.xml$/]
```

### Mode Debug

Aktifkan mode debug untuk melihat pemrosesan pengecualian:

```typescript
i18n: {
  debug: true,
  excludePatterns: ['/api/**']
}
```

Ini akan mencatat keputusan pengecualian di konsol.

## Migrasi dari Solusi Sementara

Jika Anda menggunakan solusi sementara seperti route rules atau middleware, sekarang Anda dapat menggantinya dengan `excludePatterns`:

```typescript
// ❌ Old workaround
export default defineNuxtConfig({
  routeRules: {
    '/sitemap*.xml': { headers: { 'content-type': 'application/xml' } },
  },
})

// ✅ New approach
export default defineNuxtConfig({
  i18n: {
    excludePatterns: ['/sitemap*.xml'],
  },
})
```

Pendekatan baru lebih andal dan bekerja pada berbagai tingkat sistem perutean.
