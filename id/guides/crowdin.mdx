# 🌐 Panduan Integrasi Crowdin

## 📖 Pendahuluan

Mengintegrasikan Crowdin ke proyek Anda merampingkan proses lokalisasi dan terjemahan, sehingga memudahkan pengelolaan terjemahan di berbagai bahasa dan platform. Panduan ini memberikan panduan langkah demi langkah tentang cara menyiapkan Crowdin dengan proyek Anda, termasuk konfigurasi, mengunggah sumber, dan mengunduh terjemahan.

## 🔧 Instalasi dan Pengaturan

Untuk memulai dengan Crowdin, Anda perlu menginstal Crowdin CLI secara global pada mesin Anda dan menginisialisasinya di dalam direktori proyek Anda.

### 📦 Menginstal Crowdin CLI

Pertama, instal Crowdin CLI secara global menggunakan npm:

```bash
npm install -g @crowdin/cli
```

### 🛠 Menginisialisasi Crowdin di Proyek Anda

Inisialisasi Crowdin di proyek Anda dengan menjalankan:

```bash
crowdin init
```

Perintah ini akan memandu Anda melalui proses pengaturan, termasuk pengaturan ID proyek, token API, dan detail konfigurasi lainnya.

## 🗂️ Panduan Konfigurasi

### 📄 File Konfigurasi Crowdin (`crowdin.yml`)

File konfigurasi Crowdin (`crowdin.yml`) mendefinisikan bagaimana file sumber Anda dipetakan dan di mana terjemahan harus ditempatkan. Di bawah ini adalah contoh konfigurasi:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Parameter Konfigurasi Utama

- **`project_id`**: ID proyek Crowdin Anda. Ini mengidentifikasi proyek di dalam Crowdin tempat terjemahan dikelola.
- **`api_token`**: Token API yang digunakan untuk autentikasi. Pastikan token ini memiliki izin yang benar untuk mengunggah dan mengunduh terjemahan.
- **`base_path`**: Menentukan direktori dasar untuk file sumber. Pada contoh ini, terjemahan disimpan di direktori `./locales`.
- **`base_url`**: URL dasar untuk API Crowdin.
- **`preserve_hierarchy`**: Jika disetel ke `true`, Crowdin akan mempertahankan struktur folder file sumber Anda dalam proyek.

### 📂 Konfigurasi Files

Bagian `files` memetakan file sumber Anda ke jalur tempat terjemahan akan disimpan. Contohnya:

- **Source Path**: Menentukan lokasi file terjemahan asli.
- **Translation Path**: Menentukan tempat file yang telah diterjemahkan akan disimpan di Crowdin. Placeholder seperti `%two_letters_code%` digunakan untuk mengatur kode bahasa di jalur file secara dinamis.

## ⬆️ Mengunggah File Sumber ke Crowdin

Setelah konfigurasi Crowdin Anda diatur, Anda dapat mengunggah file sumber Anda menggunakan perintah berikut:

```bash
crowdin upload sources
```

Perintah ini mengunggah semua file sumber yang ditentukan dalam konfigurasi Anda ke Crowdin, sehingga tersedia untuk diterjemahkan.

## ⬇️ Mengunduh Terjemahan dari Crowdin

Setelah terjemahan selesai atau diperbarui di Crowdin, Anda dapat mengunduhnya ke proyek Anda menggunakan:

```bash
crowdin download
```

Perintah ini mengambil terjemahan terbaru dari Crowdin dan menyimpannya sesuai dengan jalur yang ditentukan pada file konfigurasi Anda.

## ⚙️ Praktik Terbaik

### 🔑 Penamaan Kunci yang Konsisten

Pastikan kunci terjemahan konsisten di semua file untuk menghindari kebingungan dan duplikasi.

### 🧹 Pemeliharaan Rutin

Tinjau dan bersihkan kunci terjemahan yang tidak digunakan secara berkala agar file Anda tetap teratur dan mudah dikelola.

### 🛠 Otomatiskan Unggah dan Unduh

Integrasikan perintah CLI Crowdin ke pipeline CI/CD Anda untuk mengotomatiskan pengunggahan file sumber dan pengunduhan terjemahan, memastikan terjemahan Anda selalu terkini.

Dengan mengikuti panduan ini, Anda akan dapat mengintegrasikan Crowdin ke proyek Anda dengan mulus, memastikan pendekatan yang efisien dan terorganisir untuk mengelola upaya internasionalisasi Anda.
