# 🌐 Crowdin Integration Guide

## 📖 Pengantar

Integrating Crowdin into your project streamlines the localization dan translation process, making it easier to manage translations across multiple languages dan platforms. Panduan ini menyediakan a step-by-step walkthrough on setting up Crowdin dengan your project, including configuration, uploading sources, dan downloading translations.

## 🔧 Instalasi dan Setup

To get started dengan Crowdin, you'll need to install the Crowdin CLI globally on your machine dan initialize it within your project directory.

### 📦 Installing Crowdin CLI

First, install the Crowdin CLI globally using npm:

```bash
npm install -g @crowdin/cli
```

### 🛠 Initializing Crowdin in Your Project

Initialize Crowdin in your project by running:

```bash
crowdin init
```

This command will guide you through the setup process, including setting your project ID, API token, dan other configuration details.

## 🗂️ Configuration Guide

### 📄 Crowdin Configuration File (`crowdin.yml`)

The Crowdin configuration file (`crowdin.yml`) defines how your source files are mapped dan where translations harus placed. Di bawah adalah an example configuration:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Key Configuration Parameters

- **`project_id`**: Your Crowdin project ID. This identifies the project within Crowdin where translations are managed.
- **`api_token`**: The API token digunakan untuk authentication. Ensure this token has the correct permissions to upload dan download translations.
- **`base_path`**: Specifies the base directory untuk source files. Dalam contoh ini, translations are stored di `./locales` directory.
- **`base_url`**: The base URL untuk the Crowdin API.
- **`preserve_hierarchy`**: When set to `true`, Crowdin will maintain the folder structure of your source files di project.

### 📂 Files Configuration

The `files` section maps your source files ke paths where translations akan stored. Sebagai contoh:

- **Source Path**: Defines the location of the original translation files.
- **Translation Path**: Specifies where the translated files akan stored in Crowdin. Placeholders like `%two_letters_code%` are digunakan untuk dynamically set the language code di file paths.

## ⬆️ Uploading Source Files to Crowdin

Once your Crowdin configuration diatur up, you can upload your source files using the following command:

```bash
crowdin upload sources
```

This command uploads all specified source files in your configuration to Crowdin, making them available untuk translation.

## ⬇️ Downloading Translations dari Crowdin

After translations are completed atau updated in Crowdin, you can download them to your project using:

```bash
crowdin download
```

This command fetches the latest translations dari Crowdin dan saves them according ke paths specified in your configuration file.

## ⚙️ Best Practices

### 🔑 Consistent Key Naming

Ensure translation keys are consistent across all files to avoid confusion dan duplication.

### 🧹 Regular Maintenance

Periodically review dan clean up unused translation keys to keep your files organized dan manageable.

### 🛠 Automate Uploads dan Downloads

Integrate the Crowdin CLI commands into your CI/CD pipeline to automate the upload of source files dan download of translations, ensuring your translations are always up to date.

By following this guide, you’ll be able to seamlessly integrate Crowdin into your project, ensuring an efficient dan organized approach to managing your internationalization efforts.
