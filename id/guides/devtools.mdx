# 🛠️ DevTools in `nuxt-i18n-micro`

## Vue DevTools (browser extension)

In development, the module can register a **Vue DevTools** custom inspector dan timeline via `@vue/devtools-api`. This is separate dari the Nuxt DevTools tab below.

| Tool | Best untuk |
|------|----------|
| **Vue DevTools** | Live locale, in-memory translation cache, `$t` timeline (`debug: true`), missing-key events |
| **Nuxt DevTools tab** | Editing JSON files on disk, config overview, import/export |

The vue-devtools plugin is registered only during `nuxt dev` (not in production builds). Dev-only bridge state di main plugin is stripped by `import.meta.dev` dead-code elimination.

Disable the browser integration while keeping the Nuxt tab:

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

Verbose `$t` timeline events require `debug: true`.

## 📖 What Is Nuxt DevTools?

DevTools adalah powerful development assistant seamlessly integrated into the `nuxt-i18n-micro` module. It menyediakan an intuitive interface untuk managing localization dan translation tasks, making your workflow faster dan more efficient. Designed untuk developers who value convenience, Nuxt DevTools bridges the gap between coding dan runtime management.

## 🌟 Key Features of DevTools in `nuxt-i18n-micro`

### 1. **Locale Management**

Effortlessly browse, select, dan manage locales in your application. Whether you’re working dengan a single language atau multiple, DevTools menyediakan a centralized hub untuk handling all localization settings.

### 2. **Translation Editing**

Edit translation files directly through an integrated JSON editor. This eliminates the need untuk external tools, allowing real-time updates dan changes tanpa interrupting your workflow.

### 3. **File Impor dan Export**

Simplify the process of managing translation files:

- **Export**: Save translations as a JSON file untuk backups atau external use.
- **Import**: Load updated translation files into the project to keep content up-to-date.

### 4. **Real-Time Previews**

View changes immediately within the development environment. This feature ensures translations dan configurations are accurate before going live.

### 5. **Seamless Nuxt Integration**

DevTools works natively dengan `nuxt-i18n-micro`, enhancing its capabilities tanpa requiring additional setup. It adapts to your localization needs while maintaining Nuxt's modular dan flexible structure.

## 🛠️ Why Use DevTools?

Nuxt DevTools adalahn indispensable addition untuk projects requiring localization. It helps developers by:

- **Improving Collaboration**: Enables non-developers to manage translations easily.
- **Streamlining Workflows**: Consolidates multiple localization tasks into a single interface.
