# 🛠️ DevTools di `nuxt-i18n-micro`

## Vue DevTools (ekstensi peramban)

Saat development, modul dapat mendaftarkan **inspektor kustom Vue DevTools** dan timeline melalui `@vue/devtools-api`. Ini terpisah dari tab Nuxt DevTools di bawah.

| Alat | Terbaik untuk |
|------|----------|
| **Vue DevTools** | Lokal langsung, cache terjemahan in-memory, timeline `$t` (`debug: true`), event kunci yang hilang |
| **Tab Nuxt DevTools** | Menyunting file JSON di disk, ringkasan konfigurasi, impor/ekspor |

Plugin vue-devtools hanya didaftarkan selama `nuxt dev` (bukan pada build produksi). State bridge khusus dev di plugin utama dihapus oleh eliminasi kode mati `import.meta.dev`.

Nonaktifkan integrasi peramban sambil tetap mempertahankan tab Nuxt:

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

Event timeline `$t` yang verbose memerlukan `debug: true`.

## 📖 Apa Itu Nuxt DevTools?

DevTools adalah asisten development yang kuat yang terintegrasi mulus dengan modul `nuxt-i18n-micro`. Ia menyediakan antarmuka intuitif untuk mengelola tugas lokalisasi dan terjemahan, membuat alur kerja Anda lebih cepat dan efisien. Dirancang untuk developer yang menghargai kenyamanan, Nuxt DevTools menjembatani celah antara pengkodean dan manajemen runtime.

## 🌟 Fitur Utama DevTools di `nuxt-i18n-micro`

### 1. **Manajemen Lokal**

Jelajahi, pilih, dan kelola lokal di aplikasi Anda dengan mudah. Apakah Anda bekerja dengan satu bahasa atau banyak, DevTools menyediakan pusat terpusat untuk menangani semua pengaturan lokalisasi.

### 2. **Penyuntingan Terjemahan**

Sunting file terjemahan langsung melalui editor JSON terintegrasi. Ini menghilangkan kebutuhan akan alat eksternal, memungkinkan pembaruan dan perubahan secara real-time tanpa mengganggu alur kerja Anda.

### 3. **Impor dan Ekspor File**

Sederhanakan proses pengelolaan file terjemahan:

- **Ekspor**: Simpan terjemahan sebagai file JSON untuk cadangan atau penggunaan eksternal.
- **Impor**: Muat file terjemahan yang telah diperbarui ke proyek untuk menjaga konten tetap terkini.

### 4. **Pratinjau Real-Time**

Lihat perubahan segera di dalam lingkungan development. Fitur ini memastikan terjemahan dan konfigurasi akurat sebelum diluncurkan.

### 5. **Integrasi Nuxt Mulus**

DevTools bekerja secara native dengan `nuxt-i18n-micro`, meningkatkan kemampuannya tanpa memerlukan pengaturan tambahan. Ia beradaptasi dengan kebutuhan lokalisasi Anda sambil mempertahankan struktur modular dan fleksibel Nuxt.

## 🛠️ Mengapa Menggunakan DevTools?

Nuxt DevTools adalah tambahan yang tak tergantikan untuk proyek yang membutuhkan lokalisasi. Ia membantu developer dengan:

- **Menghemat Waktu**: Mengotomatiskan tugas berulang seperti manajemen file dan validasi format.
- **Mengurangi Kesalahan**: Menyediakan lingkungan yang aman dan intuitif untuk menyunting terjemahan.
- **Meningkatkan Kolaborasi**: Memungkinkan non-developer mengelola terjemahan dengan mudah.
- **Merampingkan Alur Kerja**: Mengonsolidasikan berbagai tugas lokalisasi ke dalam satu antarmuka.
