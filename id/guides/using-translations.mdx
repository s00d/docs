# Menggunakan Terjemahan di Komponen

Setelah modul terpasang dan dikonfigurasi, Anda dapat menampilkan terjemahan dengan memanggil `$t('your_key')` di dalam template dan script Vue Anda.

## 1. File Terjemahan Tingkat Root & Per Halaman

1. Terjemahan **tingkat root** berada langsung di bawah folder `/locales` (misalnya `/locales/en.json`, `/locales/fr.json`). Saat build, terjemahan tersebut secara otomatis digabungkan ke setiap file per halaman, sehingga tersedia di semua halaman.
2. Terjemahan **per halaman** berada di bawah `/locales/pages/...`, sesuai dengan struktur folder pages Nuxt Anda:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. Penggunaan Template dengan `$t`

Pada file `.vue` Anda, Anda dapat langsung menggunakan `$t` di dalam template:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
`$t` dapat mengembalikan **objek** jika kunci menunjuk ke node JSON bersarang (mis. `$t('header')` → `\{ title: "Hi" \}`). Pada template ini dirender sebagai `[object Object]`. Gunakan `$ts` bila Anda memerlukan string yang dijamin, atau berikan kunci yang lebih spesifik seperti `$t('header.title')`. Lihat [Referensi API — $t vs $ts](/api/methods#t) untuk detailnya.
</Tip>

## 3. Mengganti Lokal Saat Ini

Untuk mengubah bahasa di aplikasi Anda, Anda dapat mengambil `$locale` dari `useI18n()` dan menetapkannya sebuah kode baru:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. Kunci Bersarang dan Placeholder

- **Kunci bersarang** menggunakan notasi titik, mis. `nested.key.deeper`.
- **Placeholder** memungkinkan Anda menyisipkan nilai dinamis:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. Tips & Praktik Terbaik

- **Kunci yang Bertabrakan**: Jika file per halaman berisi kunci yang sama dengan file tingkat root, versi per halaman diprioritaskan (terjemahan root digabung sebagai basis saat build).
- **Menonaktifkan File Halaman**: Jika Anda tidak ingin menggunakan terjemahan per halaman, Anda dapat mengatur `disablePageLocales: true` pada konfigurasi Nuxt Anda. Dengan begitu, hanya file `/locales/*.json` yang digunakan.
- **Tanpa Impor Langsung**: Anda tidak perlu melakukan `import \{ useI18n \} from 'nuxt-i18n-micro'`; fitur auto-injection modul akan menangani hal ini untuk Anda.

Selesai! Dengan langkah-langkah ini, Anda dapat dengan cepat **mulai mengambil terjemahan** dari file JSON tingkat root atau per halaman dan **menampilkannya** di aplikasi Nuxt Anda menggunakan `$t`.

## Sumber Daya Tambahan

Untuk menjelajahi fitur yang lebih lanjut, pastikan untuk memeriksa:

1. **Komponen `<i18n-t>`**  
   Komponen `<i18n-t>` adalah alternatif yang kuat untuk `$t`, sangat berguna untuk situasi yang melibatkan elemen bersarang, penggunaan placeholder yang lebih lanjut, dan struktur terjemahan yang lebih kompleks.

- **Dokumentasi**: [i18n-t](/api/components/i18n-t)

2. **Composable `useI18n`**  
   Composable `useI18n` menawarkan seperangkat fungsi lengkap dan properti reaktif untuk mengelola terjemahan, menangani peralihan lokal, pemformatan, dan lainnya.

- **Dokumentasi**: [useI18n](/api/composables/use-i18n)
