# Hasil Uji Performa

### Deskripsi

Membandingkan **plain Nuxt** (baseline tanpa modul i18n), **i18n-micro**, dan **`@nuxtjs/i18n` v10.6** di bawah satu profil kamus bersama.

Fokus: waktu build, puncak RSS, deployable **code vs terjemahan vs total**, dan perilaku server di bawah Artillery + Autocannon.

### Catatan metodologi

- Metrik adalah **rata-rata dari 3 kali eksekusi berturut-turut per fixture** (fixture A ×3, lalu B ×3, lalu C ×3 — tidak diselingi).
- **Terjemahan** meliputi JSON lokal di bawah `locales/` / `_locales/` / `translations/`, semua yang ada di bawah `chunks/raw/`, dan potongan lokal yang cocok. Laporan lama yang menunjukkan `@nuxtjs/i18n` "translations: 0 B" dan kolom "code" yang besar telah menghitung message chunk sebagai kode aplikasi.
- **plain-nuxt** menyajikan volume leaf yang sama sebagai JSON statis `public/translations` (bukan impor JS statis). Di bawah Artillery baseline tersebut berat I/O; ini bukan "overhead i18n", melainkan biaya pengambilan JSON besar per permintaan.

### Runs

Semua metrik di bawah adalah **rata-rata dari 3 kali eksekusi**.

| Knob | Nilai |
|------|-------|
| Locales | **4** (`en`, `de`, `ru`, `fr`) |
| Pages | **2** (`index`, `page`) |
| Index tree | depth **5**, branch **7** → **16,807** kunci leaf / locale |
| Secondary pages | depth **5**, branch **6** → **7,776** kunci leaf / page / locale |
| Tujuan | Profil default CLI (`--locales 4 --keys 10000`); naikkan knob untuk load radar-regresi |

Kamus berasal dari `test/fixtures/perf-shared/runtime.json` (ditulis oleh CLI) sehingga ketiga fixture tetap selaras.

## Catatan

- Profil bersama: 4 locales × 2 pages × ~16.8k index leaves.
- Artillery: 6s warm-up @6 VU/s + 60s main @60 VU/s. Autocannon: 10 connections × 10s.
- Jalankan ulang: `pnpm test:performance` atau `pnpm -C scripts cli performance --locales N --keys K --only all|micro|i18n|plain --runs N`.
