# Override i18n Runtime

Gunakan panduan ini bila Anda membutuhkan satu artefak build untuk berjalan dengan default lokal yang berbeda per lingkungan (misalnya: instance tenant yang berbeda).

## Apa yang dapat di-override pada runtime

Modul mendukung override runtime yang aman untuk:

- `defaultLocale`
- `fallbackLocale`
- `disabledLocales`

Override ini diterapkan di atas konfigurasi build-time dari `.nuxt/i18n.strategy.mjs` dan `.nuxt/i18n.config.mjs`.

## Apa yang tidak dapat di-override pada runtime

`strategy` (`no_prefix`, `prefix`, `prefix_except_default`, `prefix_and_default`) merupakan urusan build-time karena memengaruhi perilaku rute yang dihasilkan.

Jika Anda mengoper override strategy pada runtime, override tersebut diabaikan dan peringatan diterbitkan.

## Override berbasis RuntimeConfig

Sediakan nilai runtime di bawah `runtimeConfig.public.i18nRuntime`:

```ts
export default defineNuxtConfig({
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

## Override variabel lingkungan

Anda juga dapat mengonfigurasi override melalui variabel lingkungan:

- `NUXT_I18N_DEFAULT_LOCALE`
- `NUXT_I18N_FALLBACK_LOCALE`
- `NUXT_I18N_DISABLED_LOCALES` (dipisahkan koma, mis. `fr,it`)

Alias fallback juga didukung:

- `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES`

## Aturan validasi

Pada runtime, modul memvalidasi override untuk menghindari kondisi yang rusak:

- Anda tidak dapat menonaktifkan semua lokal.
- `defaultLocale` harus menunjuk ke lokal yang diaktifkan.
- `fallbackLocale` harus ada di lokal yang dideklarasikan.

Jika override tidak valid, modul mempertahankan nilai yang aman dan mencatat peringatan.

## Catatan untuk penerapan multi-instance

Fitur runtime ini dirancang untuk aktivasi lokal per instance dan default tanpa build ulang.

Jika instance memerlukan strategi URL yang berbeda (`no_prefix` vs `prefix`), gunakan build terpisah untuk masing-masing strategi.

## Lokal yang dinonaktifkan dan payload statis

`runtimeConfig.public.i18nRuntime.disabledLocales` memperbarui perutean, switcher, dan **handler** payload Nitro — tetapi Nitro menyajikan file di bawah `public/` **sebelum** handler tersebut.

Jika `translationPayloads.publicAssets` (atau salinan publik paksa dari Node SSR) telah menulis `/_locales/\{page\}/\{locale\}/data.json`, penonaktifan runtime tidak dapat menyembunyikan file tersebut. Sebaiknya gunakan `locale.disabled: true` saat build agar premerge tidak menghasilkan payload statis untuk lokal tersebut.
