Nuxt I18n Micro adalah modul i18n yang ringan dan berkinerja tinggi untuk Nuxt, dirancang untuk proyek berskala besar. Modul ini mengurangi waktu build, penggunaan memori, dan ukuran bundle dibandingkan dengan solusi i18n tradisional seperti `@nuxtjs/i18n`.

Intinya adalah satu modul Nuxt ditambah sekumpulan kecil plugin runtime. Awalan lokal ditangani oleh `@i18n-micro/route-strategy` (waktu build) dan `@i18n-micro/path-strategy` (runtime). Terjemahan hanya berformat JSON, dibagi antara file root bersama dan file per halaman yang dihasilkan secara otomatis saat pengembangan.

## Kapan menggunakan Nuxt I18n Micro

- Anda memerlukan terjemahan per halaman yang dimuat malas tanpa menggelembungkan payload Nitro.
- Anda menginginkan perutean berbasis strategi tanpa beban pembuatan rute saat runtime.
- Anda memerlukan SSR dan penerapan edge tetap cepat di bawah beban.
- Anda bermigrasi dari `@nuxtjs/i18n` dan menginginkan runtime yang lebih kecil dengan ergonomi serupa.
