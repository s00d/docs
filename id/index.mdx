---

Nuxt I18n Micro adalah modul i18n yang ringan dan berperforma tinggi untuk Nuxt 3 dan 4, dirancang untuk proyek besar. Modul ini menjaga waktu build, penggunaan memori, dan ukuran bundle tetap rendah dibandingkan solusi i18n tradisional seperti `@nuxtjs/i18n`.

Route terlokalisasi dibuat saat build oleh `@i18n-micro/route-strategy` dan di-resolve saat runtime oleh `@i18n-micro/path-strategy`, sehingga link, switcher, `hreflang`, dan redirect semuanya selaras dengan router. Terjemahan hanya berupa JSON, terbagi antara file root bersama dan file per halaman yang dibuatkan oleh dev server untuk Anda, dengan HMR bawaan.

<CodeGroup>

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>
