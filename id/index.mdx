Nuxt I18n Micro adalah modul i18n yang ringan dan berkinerja tinggi untuk Nuxt, dirancang untuk proyek besar. Modul ini mengurangi waktu build, penggunaan memori, dan ukuran bundle dibandingkan solusi i18n tradisional seperti `@nuxtjs/i18n`.

Intinya adalah satu modul Nuxt ditambah sekumpulan kecil plugin runtime. Awalan lokal ditangani oleh `@i18n-micro/route-strategy` (build-time) dan `@i18n-micro/path-strategy` (runtime). Terjemahan hanya menggunakan JSON, dipisahkan antara file root bersama dan file per halaman yang dibuat otomatis saat development.

## Kapan menggunakan Nuxt I18n Micro

- Anda membutuhkan terjemahan per halaman yang dimuat secara lazy tanpa membengkakkan payload Nitro.
- Anda menginginkan perutean berbasis strategi tanpa overhead pembuatan rute runtime.
- Anda membutuhkan SSR dan penerapan edge tetap cepat di bawah beban.
- Anda bermigrasi dari `@nuxtjs/i18n` dan menginginkan runtime yang lebih kecil dengan ergonomi yang serupa.
