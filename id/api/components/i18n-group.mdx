# 🌍 Komponen `<i18n-group>`

Komponen `<i18n-group>` di Nuxt I18n Micro menyediakan cara yang nyaman untuk mengelompokkan terjemahan di bawah awalan umum, mengurangi pengulangan dan meningkatkan organisasi kode.

## ⚙️ Prop

{/* generated:component:i18n-group — do not edit; run `pnpm run docs:generate` */}

| Prop | Tipe | Default | Deskripsi |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | Awalan kunci untuk setiap pencarian di dalam slot. |
| `groupClass` | `string` | `''` | Kelas tambahan pada elemen wrapper. |

**\*** wajib.

### Slot

| Slot | Binding | Deskripsi |
| --- | --- | --- |
| `default` | `prefix`, `t` | Menerima `prefix` dan fungsi `t` yang dicakup ke prefix tersebut. |

{/* /generated:component:i18n-group */}

## 🎯 Slot

Slot default menerima `prefix` dan fungsi `t` yang dicakupkan padanya, sehingga kunci di dalamnya
ditulis relatif terhadap awalan:

```vue
<i18n-group prefix="checkout">
  <template #default="{ t }">
    <h2>{{ t('title') }}</h2>
    <p>{{ t('summary', { count: 3 }) }}</p>
  </template>
</i18n-group>
```

## 🛠️ Contoh Penggunaan

### Penggunaan Dasar

```vue
<template>
  <i18n-group prefix="product.details">
    <template #default="{ t }">
      <h1>{{ t('title') }}</h1>
      <p>{{ t('description') }}</p>
      <div class="price">{{ t('price', { value: 99.99 }) }}</div>
    </template>
  </i18n-group>
</template>
```

File terjemahan:

```json
{
  "product": {
    "details": {
      "title": "Premium Product",
      "description": "This is a premium product",
      "price": "Price: ${value}"
    }
  }
}
```

### Dengan Kelas Kustom

```vue
<template>
  <i18n-group prefix="user.profile" group-class="profile-section">
    <template #default="{ t }">
      <div class="user-info">
        <h2>{{ t('title') }}</h2>
        <p>{{ t('bio') }}</p>
        <div class="stats">
          <span>{{ t('stats.followers') }}</span>
          <span>{{ t('stats.following') }}</span>
        </div>
      </div>
    </template>
  </i18n-group>
</template>
```

File terjemahan:

```json
{
  "user": {
    "profile": {
      "title": "User Profile",
      "bio": "User biography goes here",
      "stats": {
        "followers": "Followers: {count}",
        "following": "Following: {count}"
      }
    }
  }
}
```

### Dengan Konten Dinamis

```vue
<template>
  <i18n-group prefix="blog.post">
    <template #default="{ t }">
      <article>
        <h1>{{ t('title') }}</h1>
        <div class="meta">
          {{ t('meta.author', { name: author }) }} |
          {{ t('meta.date', { date: publishDate }) }}
        </div>
        <div v-for="(section, index) in sections" :key="index">
          <h2>{{ t(`sections.${index}.title`) }}</h2>
          <p>{{ t(`sections.${index}.content`) }}</p>
        </div>
      </article>
    </template>
  </i18n-group>
</template>

<script setup>
const author = 'John Doe'
const publishDate = '2024-01-01'
const sections = ['intro', 'main', 'conclusion']
</script>
```

## 🎨 Penggayaan

Komponen membungkus kontennya dalam div dengan kelas `i18n-group` dan kelas tambahan apa pun yang ditentukan pada prop `groupClass`:

```css
.i18n-group {
  /* Your base styles */
}

.profile-section {
  /* Additional styles for profile sections */
}
```

## 🚀 Praktik Terbaik

1. **Awalan yang Konsisten**: Gunakan awalan yang konsisten dan logis yang mencerminkan struktur aplikasi Anda

```vue
<i18n-group prefix="features.pricing">
<i18n-group prefix="features.security">
```

2. **Organisasi Modular**: Kelompokkan terjemahan terkait bersama di bawah awalan yang bermakna

```vue
<i18n-group prefix="checkout.payment">
<i18n-group prefix="checkout.shipping">
```

3. **Komponen yang Dapat Digunakan Kembali**: Buat komponen yang dapat digunakan kembali dengan grup terjemahan sendiri

```vue
<!-- UserProfile.vue -->
<i18n-group prefix="user.profile">

<!-- UserSettings.vue -->
<i18n-group prefix="user.settings">
```

4. **Grup Bersarang**: Hindari nesting grup terlalu dalam untuk menjaga kejelasan

```vue
<!-- Good -->
<i18n-group prefix="shop.product">

<!-- Avoid -->
<i18n-group prefix="shop.category.product.details.specs">
```
