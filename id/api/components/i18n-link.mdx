# 🌍 Komponen `<i18n-link>`

Komponen `<i18n-link>` di `Nuxt I18n Micro` adalah komponen tautan serbaguna yang secara otomatis melokalisasi rute berdasarkan lokal saat ini. Ia bertindak sebagai pembungkus komponen `<NuxtLink>`, menyediakan fitur tambahan seperti pemformatan tautan aktif dan dukungan untuk tautan eksternal.

## ⚙️ Prop

{/* generated:component:i18n-link — do not edit; run `pnpm run docs:generate` */}

| Prop | Tipe | Default | Deskripsi |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | Rute target. Dilokalisasi secara otomatis; URL eksternal diteruskan tanpa perubahan. |
| `activeStyle` | `Partial<CSSStyleValue>` | — | Gaya inline yang diterapkan saat tautan menunjuk ke rute saat ini. |

**\*** wajib.

### Slot

| Slot | Binding | Deskripsi |
| --- | --- | --- |
| `default` | — | Konten tautan. |

{/* /generated:component:i18n-link */}

`to` menerima apa saja yang diterima `NuxtLink` — jalur, rute bernama, atau objek rute yang telah diselesaikan.
URL absolut dideteksi dan dirender sebagai `<a target="_blank" rel="noopener noreferrer">` biasa
alih-alih dilokalisasi.

## 🛠️ Contoh Penggunaan

### Penggunaan Dasar

```vue
<i18n-link to="/about">About Us</i18n-link>
```

Contoh ini membuat tautan ke halaman `/about`, dilokalisasi ke lokal saat ini.

### Pemformatan Tautan Aktif dengan Gaya Inline

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

Tautan akan memiliki teks tebal saat pengguna berada di halaman `/about`, memungkinkan Anda memformat tautan aktif langsung dengan gaya inline.

### Penanganan Tautan Eksternal

Komponen secara otomatis mendeteksi tautan eksternal dan menambahkan atribut yang diperlukan untuk keamanan.

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

Tautan ini akan membuka `https://example.com` di tab baru dengan `rel="noopener noreferrer"` diterapkan.

## 🎨 Gaya

Komponen sekarang menggunakan gaya inline untuk state aktif alih-alih kelas. Anda dapat menyesuaikan gaya ini menggunakan prop `activeStyle`.

### Gaya Aktif Default

- **Font Weight**: `bold`
- **Color**: Mewarisi warna default peramban (jika tidak ada `color` yang ditentukan di `activeStyle`).

Anda dapat menimpanya dengan menyediakan gaya kustom melalui prop `activeStyle`.

### Gaya Aktif Kustom

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

Pada contoh ini, tautan akan tebal dan berwarna hijau saat aktif.

## 🚀 Fitur Tambahan

### Slot untuk Konten Kustom

Anda dapat mengoper konten kustom di dalam tautan menggunakan slot, membuat komponen fleksibel untuk berbagai kasus penggunaan.

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### Peningkatan Aksesibilitas

Komponen mendukung `aria-label` dan atribut aksesibilitas lainnya untuk memastikan pengalaman yang lebih dapat diakses.

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
