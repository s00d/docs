# 🌍 Komponen `<i18n-link>`

Komponen `<i18n-link>` di `Nuxt I18n Micro` adalah komponen tautan serbaguna yang secara otomatis melokalkan rute berdasarkan lokal saat ini. Komponen ini bertindak sebagai pembungkus di sekitar komponen `<NuxtLink>`, menyediakan fitur tambahan seperti penataan tautan aktif dan dukungan untuk tautan eksternal.

## ⚙️ Props

{/* generated:component:i18n-link — do not edit; run `pnpm run docs:generate` */}

| Prop | Tipe | Default | Deskripsi |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | Rute target. Dilokalkan otomatis; URL eksternal diteruskan tanpa perubahan. |
| `activeStyle` | `Partial<CSSStyleValue>` | — | Gaya sebaris yang diterapkan saat tautan menunjuk ke rute saat ini. |

**\*** wajib.

### Slot

| Slot | Binding | Deskripsi |
| --- | --- | --- |
| `default` | — | Konten tautan. |

{/* /generated:component:i18n-link */}

`to` menerima apa pun yang diterima `NuxtLink` — jalur, rute bernama, atau objek rute yang telah diselesaikan. URL absolut dideteksi dan dirender sebagai `<a target="_blank" rel="noopener noreferrer">` biasa alih-alih dilokalkan.

## 🛠️ Contoh penggunaan

### Penggunaan dasar

```vue
<i18n-link to="/about">About Us</i18n-link>
```

Contoh ini membuat tautan ke halaman `/about`, dilokalkan ke lokal saat ini.

### Penataan tautan aktif dengan gaya sebaris

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

Tautan akan memiliki teks tebal saat pengguna berada di halaman `/about`, memungkinkan Anda menata tautan aktif langsung dengan gaya sebaris.

### Penanganan tautan eksternal

Komponen secara otomatis mendeteksi tautan eksternal dan menambahkan atribut yang diperlukan untuk keamanan.

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

Tautan ini akan membuka `https://example.com` di tab baru dengan `rel="noopener noreferrer"` diterapkan.

## 🎨 Gaya

Komponen sekarang menggunakan gaya sebaris untuk keadaan aktif alih-alih kelas. Anda dapat menyesuaikan gaya ini menggunakan prop `activeStyle`.

### Gaya aktif default

- **Berat font**: `bold`
- **Warna**: Mewarisi warna default browser (jika tidak ada `color` yang ditentukan di `activeStyle`).

Anda dapat menimpa ini dengan menyediakan gaya kustom melalui prop `activeStyle`.

### Gaya aktif kustom

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

Dalam contoh ini, tautan akan tebal dan hijau saat aktif.

## 🚀 Fitur tambahan

### Slot untuk konten kustom

Anda dapat memberikan konten kustom di dalam tautan menggunakan slot, membuat komponen fleksibel untuk berbagai kasus penggunaan.

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### Peningkatan aksesibilitas

Komponen mendukung `aria-label` dan atribut aksesibilitas lainnya untuk memastikan pengalaman yang lebih dapat diakses.

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
