# 🌍 Komponen `<i18n-t>`

Komponen `<i18n-t>` di `Nuxt I18n Micro` adalah komponen terjemahan yang fleksibel yang mendukung penyisipan konten dinamis melalui slot. Ini memungkinkan Anda menginterpolasi terjemahan dengan komponen Vue kustom atau konten HTML, memungkinkan skenario lokalisasi yang lebih canggih.

| `tag` | `string` | `'span'` | Elemen yang akan dirender. |

| `defaultValue` | `string` | `''` | Dirender alih-alih komponen saat `hideIfEmpty` menekan terjemahan kosong. |
| `html` | `boolean` | `false` | Render terjemahan sebagai HTML alih-alih teks. Hanya untuk konten yang Anda kontrol. |
| `hideIfEmpty` | `boolean` | `false` | Jangan render apa pun saat terjemahan menghasilkan string kosong. |
| `customPluralRule` | `PluralFunc` | `null` | Aturan plural untuk elemen ini saja, menimpa yang dikonfigurasi. |
| `number` | `number \| string` | — | Memformat nilai dengan `$tn` dan meneruskannya ke terjemahan sebagai `\{number\}`. |
| `date` | `Date \| string \| number` | — | Memformat nilai dengan `$td` dan meneruskannya ke terjemahan sebagai `\{date\}`. |
| `relativeDate` | `Date \| string \| number` | — | Memformat nilai dengan `$tdr` dan meneruskannya ke terjemahan sebagai `\{relativeDate\}`. |

**\*** wajib.

{/* /generated:component:i18n-t */}

Hanya salah satu dari `plural`, `number`, `date`, dan `relativeDate` yang berlaku pada satu waktu; saat beberapa diatur, yang pertama dalam daftar tersebut menang.

### Contoh per prop

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

## 🛠️ Contoh penggunaan

### Penggunaan dasar

```vue
<i18n-t keypath="feedback.text" />
```

Ini merender terjemahan untuk `feedback.text` di dalam tag `<span>`.

### Menggunakan slot untuk konten dinamis

Komponen `<i18n-t>` mendukung penggunaan slot untuk menyisipkan komponen Vue atau konten lainnya secara dinamis ke bagian tertentu dari terjemahan.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

Dalam contoh ini, placeholder `\{link\}` di string terjemahan `feedback.text` diganti dengan komponen `<nuxt-link>`, yang sendiri berisi komponen terjemahan lain.

### Pluralisasi

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

Ini secara otomatis menerapkan aturan pluralisasi berdasarkan nilai `itemCount`.

## 🚀 Fitur tambahan

### Slot default

Jika tidak ada slot spesifik yang disediakan, terjemahan dapat disesuaikan melalui slot default, yang menyediakan seluruh string yang diterjemahkan:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### Rendering bersyarat

Jangan render apa pun jika string terjemahan kosong dengan menggunakan prop `hideIfEmpty`.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### Aturan pluralisasi kustom

Gunakan fungsi kustom untuk menangani pluralisasi.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### Contoh lanjutan dengan slot

Manfaatkan slot untuk menyesuaikan cara konten terjemahan dirender.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
