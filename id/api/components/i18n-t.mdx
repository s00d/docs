# 🌍 Komponen `<i18n-t>`

Komponen `<i18n-t>` di `Nuxt I18n Micro` adalah komponen terjemahan yang fleksibel yang mendukung penyisipan konten dinamis melalui slot. Ia memungkinkan Anda menginterpolasi terjemahan dengan komponen Vue kustom atau konten HTML, memungkinkan skenario lokalisasi lanjutan.

## ⚙️ Prop

| Prop | Tipe | Default | Deskripsi |
| --- | --- | --- | --- |
| `keypath` **\*** | `string` | — | Kunci terjemahan yang akan dirender. |
| `plural` | `number \| string` | — | Hitungan yang memilih bentuk plural. Setel untuk menggunakan `$tc` alih-alih `$t`. |
| `tag` | `string` | `'span'` | Elemen yang akan dirender. |
| `params` | `Record<string, string \| number \| boolean>` | `() => (\{\})` | Nilai interpolasi yang disubstitusikan ke dalam terjemahan. |
| `defaultValue` | `string` | `''` | Dirender sebagai pengganti komponen saat `hideIfEmpty` menyembunyikan terjemahan kosong. |
| `html` | `boolean` | `false` | Merender terjemahan sebagai HTML alih-alih teks. Hanya untuk konten yang Anda kontrol. |
| `hideIfEmpty` | `boolean` | `false` | Tidak merender apa pun saat terjemahan menyelesaikan ke string kosong. |
| `customPluralRule` | `PluralFunc` | `null` | Aturan plural khusus untuk elemen ini saja, menimpa aturan yang dikonfigurasi. |
| `number` | `number \| string` | — | Memformat nilai dengan `$tn` dan mengopernya ke terjemahan sebagai `\{number\}`. |
| `date` | `Date \| string \| number` | — | Memformat nilai dengan `$td` dan mengopernya ke terjemahan sebagai `\{date\}`. |
| `relativeDate` | `Date \| string \| number` | — | Memformat nilai dengan `$tdr` dan mengopernya ke terjemahan sebagai `\{relativeDate\}`. |

**\*** wajib.

{/* /generated:component:i18n-t */}

Hanya satu dari `plural`, `number`, `date`, dan `relativeDate` yang berlaku pada satu waktu; saat beberapa
disetel, yang pertama pada daftar itu menang.

### Contoh per prop

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

## 🛠️ Contoh Penggunaan

### Penggunaan Dasar

```vue
<i18n-t keypath="feedback.text" />
```

Ini me-render terjemahan untuk `feedback.text` di dalam tag `<span>`.

### Menggunakan Slot untuk Konten Dinamis

Komponen `<i18n-t>` mendukung penggunaan slot untuk memasukkan komponen Vue atau konten lainnya secara dinamis ke bagian tertentu dari terjemahan.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

Pada contoh ini, placeholder `\{link\}` pada string terjemahan `feedback.text` digantikan oleh komponen `<nuxt-link>`, yang di dalamnya berisi komponen terjemahan lain.

### Pluralisasi

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

Ini secara otomatis menerapkan aturan pluralisasi berdasarkan nilai `itemCount`.

## 🚀 Fitur Tambahan

### Slot Default

Jika tidak ada slot spesifik yang disediakan, terjemahan dapat dikustomisasi melalui slot default, yang menyediakan seluruh string yang telah diterjemahkan:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### Rendering Kondisional

Tidak merender apa pun jika string terjemahan kosong dengan menggunakan prop `hideIfEmpty`.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### Aturan Pluralisasi Kustom

Gunakan fungsi kustom untuk menangani pluralisasi.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### Contoh Lanjutan dengan Slot

Manfaatkan slot untuk menyesuaikan cara konten terjemahan dirender.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
