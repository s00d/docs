# 🌍 Komponen `<i18n-switcher>`

Komponen `<i18n-switcher>` di `Nuxt I18n Micro` menyediakan antarmuka dropdown yang ramah pengguna untuk beralih antara lokal berbeda di aplikasi Anda. Komponen ini sangat dapat disesuaikan, memungkinkan integrasi mulus dengan desain dan tata letak aplikasi Anda.

Lokal dengan `disabled: true` **dihilangkan** dari dropdown (masih tersedia melalui `$getLocales()` untuk SEO / tag head). Hanya lokal yang dapat dialihkan yang mendapatkan `NuxtLink` + `hreflang`.

Setiap bagian tidak ditata secara default: prop `custom*Style` menerima objek gaya sebaris, dan slot di bawah menggantikan markup sepenuhnya saat penataan tidak cukup.

## 🛠️ Contoh penggunaan

### Penggunaan dasar

```vue
<template>
  <i18n-switcher />
</template>
```

Ini merender pengalih lokal dengan penataan dan perilaku default.

### Label kustom dan gaya sebaris

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Contoh ini menunjukkan pengalih lokal yang sepenuhnya dikustomisasi dengan label kustom dan gaya sebaris.

## 🔌 Slot

Setiap bagian visual dari pengalih dapat diganti. Slot terdaftar dengan tabel prop di atas; masing-masing mengambil konten template:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Slot yang namanya berakhir dengan `-item`, `-link-content` atau dimulai dengan `before-item` menerima objek `locale` yang menjadi miliknya.

## 🎨 Ikhtisar gaya

Komponen `<i18n-switcher>` dilengkapi dengan gaya dasar yang didefinisikan menggunakan gaya sebaris yang dapat dengan mudah ditimpa dengan memberikan gaya kustom melalui prop. Berikut ikhtisar singkat penataan default:

- **Wrapper**: Mengontrol pemosisian dropdown.
- **Button**: Menata tombol toggle dropdown.
- **Dropdown**: Menata daftar dropdown.
- **Items**: Menata setiap item dalam daftar.
- **Links**: Menata tautan di dalam setiap item.
- **Icon**: Menata ikon indikator dropdown.

Anda dapat menyesuaikan gaya ini dengan memberikan gaya kustom melalui prop masing-masing, memastikan bahwa pengalih lokal terintegrasi mulus ke UI aplikasi Anda.
