# 🌍 Komponen `<i18n-switcher>`

Komponen `<i18n-switcher>` di `Nuxt I18n Micro` menyediakan antarmuka dropdown yang ramah pengguna untuk beralih di antara lokal yang berbeda dalam aplikasi Anda. Komponen ini sangat dapat dikustomisasi, memungkinkan integrasi mulus dengan desain dan tata letak aplikasi Anda.

Lokal dengan `disabled: true` **dihilangkan** dari dropdown (masih tersedia melalui `$getLocales()` untuk SEO / tag head). Hanya lokal yang dapat diganti mendapatkan `NuxtLink` + `hreflang`.

Setiap bagian tidak digayakan secara default: prop `custom*Style` menerima objek gaya inline, dan
slot di bawah mengganti markup sepenuhnya saat penggayaan tidak cukup.

## 🛠️ Contoh Penggunaan

### Penggunaan Dasar

```vue
<template>
  <i18n-switcher />
</template>
```

Ini me-render pengganti lokal dengan penggayaan dan perilaku default.

### Label Kustom dan Gaya Inline

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Contoh ini menunjukkan pengganti lokal yang sepenuhnya dikustomisasi dengan label kustom dan gaya inline.

## 🔌 Slot

Setiap bagian visual dari switcher dapat diganti. Slot-slot terdaftar bersama tabel prop
di atas; masing-masing menerima konten template:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Slot yang namanya berakhir dengan `-item`, `-link-content` atau diawali dengan `before-item` menerima objek
`locale` yang menjadi tempatnya.

## 🎨 Ikhtisar Gaya

Komponen `<i18n-switcher>` hadir dengan gaya dasar yang didefinisikan menggunakan gaya inline yang dapat dengan mudah ditimpa dengan mengoper gaya kustom melalui prop. Berikut ikhtisar singkat penggayaan default:

- **Wrapper**: Mengontrol pemosisian dropdown.
- **Button**: Menggayakan tombol pemicu dropdown.
- **Dropdown**: Menggayakan daftar dropdown.
- **Items**: Menggayakan setiap item pada daftar.
- **Links**: Menggayakan tautan di dalam setiap item.
- **Icon**: Menggayakan ikon indikator dropdown.

Anda dapat menyesuaikan gaya ini dengan mengoper gaya kustom melalui prop yang bersangkutan, memastikan pengganti lokal terintegrasi mulus ke UI aplikasi Anda.
