# API paket

`nuxt-i18n-micro` dibangun dari sekumpulan paket kecil, yang sebagian besar dapat digunakan sendiri — `@i18n-micro/vue` di aplikasi Vue biasa, `@i18n-micro/core` di mana saja.

Setiap halaman di bawah dihasilkan dari snapshot API yang [`pnpm run api:surface`](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/maintenance-commands.md#api-surface) periksa terhadap sumber TypeScript, sehingga ekspor tidak dapat menghilang tanpa referensi ini berubah atau CI gagal.
