Modul Nuxt dibangun dari paket-paket kecil `@i18n-micro/*`, dan sebagian besar dapat bekerja secara mandiri: `@i18n-micro/vue` di aplikasi Vue, `@i18n-micro/core` di mana saja. Gunakan halaman-halaman ini untuk mencari apa yang diekspor sebuah paket, per entry point. Setiap halaman dihasilkan dari snapshot yang diperiksa oleh [`pnpm run api:surface`](https://s00d.github.io/nuxt-i18n-micro/contributing/maintenance-commands#api-surface) terhadap kode sumber TypeScript, sehingga sebuah ekspor tidak dapat berubah tanpa diketahui oleh CI.
