Modul memanggil satu hook runtime (hook aplikasi), yaitu `i18n:register`. Gunakan hook ini ketika sebuah plugin atau modul menambahkan terjemahan yang tidak ada di file `locales/` Anda. Callback Anda menerima fungsi `register` yang menggabungkan terjemahan ke halaman yang sedang ditampilkan.

## `i18n:register` {#i18nregister}

```ts
'i18n:register': (
  register: (translations: unknown, locale?: string) => void,
  locale: string,
) => HookResult
```

| Argumen | Deskripsi |
| --- | --- |
| `register(translations, locale?)` | Menggabungkan `translations` secara mendalam (deep merge) ke chunk halaman dari rute yang sedang dimuat, untuk `locale` (default: `locale` milik hook). Kunci yang sudah ada akan ditimpa. |
| `locale` | Locale dari rute yang sedang dimuat. |

Hook ini diberi tipe melalui `RuntimeNuxtHooks`, sehingga `nuxtApp.hook('i18n:register', …)` tidak memerlukan cast.

## Kapan hook dipanggil {#when-it-fires}

Plugin loader (`i18n-plugin-loader`) memanggilnya:

1. sekali saat startup, setelah semua plugin berjalan (`app:created`) dan sebelum aplikasi dirender;
2. di dalam `router.beforeEach` miliknya, setelah terjemahan halaman tujuan dimuat, ketika path berubah — pada setiap navigasi di bawah `no_prefix`.

Setiap callback dan setiap pemanggilan `register` ditunggu (await) sebelum aplikasi dirender atau navigasi dilanjutkan, sehingga halaman dirender dengan kunci yang sudah digabungkan. Dengan [`hooks: false`](/id/api/module-options#hooks) hook ini tidak pernah dipanggil.

## Contoh {#example}

```ts
// plugins/i18n-extra.ts
export default defineNuxtPlugin((nuxtApp) => {
  nuxtApp.hook('i18n:register', async (register, locale) => {
    const extra = await $fetch<Record<string, unknown>>(`/api/cms-strings/${locale}`)
    register(extra, locale)
  })
})
```

Ini adalah hook runtime: daftarkan dengan `nuxtApp.hook` di dalam plugin, bukan dengan `nuxt.hook` di `nuxt.config` atau di `setup` sebuah modul. Modul dapat menambahkan plugin semacam itu dengan `addPlugin`.
