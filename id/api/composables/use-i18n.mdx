# 🛠️ Composable `useI18n`

Composable `useI18n` di `Nuxt I18n Micro` memberikan akses ke sebagian besar helper i18n runtime pada komponen dan script. Method tersedia **dengan dan tanpa awalan `$`** (misalnya `$t` dan `t`).

Beberapa injeksi — `$defineI18nRoute` dan `$clearCache` — hanya tersedia pada `useNuxtApp()`. Lihat [Method — `$defineI18nRoute`](/api/methods#definei18nroute) dan [`$clearCache`](/api/methods#clearcache).

## 📊 Apa yang dikembalikan

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Setiap helper runtime, sebagai objek biasa.

Fungsi-fungsi yang sama yang disuntikkan plugin sebagai `$t`, `$tc` dan seterusnya, tersedia baik di bawah
nama berawalan dollar maupun alias polos — sehingga `const \{ t \} = useI18n()` dan
`const \{ $t \} = useI18n()` keduanya berfungsi.

**Mengembalikan** — helper yang dijelaskan pada [referensi method](/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

Setiap helper yang dikembalikan — `$t`, `$tc`, `$has`, `$switchLocale` dan lainnya — didaftar
dengan signature-nya dan didokumentasikan lengkap pada [Referensi method](/api/methods).

## API khusus `useNuxtApp()`

Ini **tidak** dikembalikan oleh `useI18n()`. Impor dari `useNuxtApp()`:

| Method                     | Tujuan                                                                         |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Rute lokal per halaman, pembatasan, dan terjemahan inline pada `script setup` |
| `$clearCache()`            | Membersihkan cache terjemahan in-memory dan chunk yang dimuat                            |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Lihat [Method](/api/methods) untuk signature lengkap dan contoh.

## 🛠️ Contoh Penggunaan

### Pengambilan Lokal Dasar

Ambil lokal aplikasi saat ini.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Terjemahan dengan Parameter

Terjemahkan string dengan parameter dinamis, dengan nilai default fallback.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Mengganti Lokal

Ganti aplikasi ke lokal berbeda.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Menghasilkan Rute Terlokalisasi

Menghasilkan rute yang terlokalisasi ke lokal saat ini atau yang ditentukan.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
