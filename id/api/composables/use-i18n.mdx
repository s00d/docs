# 🛠️ Composable `useI18n`

Composable `useI18n` di `Nuxt I18n Micro` menyediakan akses ke sebagian besar pembantu i18n runtime di komponen dan skrip. Metode tersedia **dengan dan tanpa awalan `$`** (misalnya `$t` dan `t`).

Beberapa injeksi — `$defineI18nRoute` dan `$clearCache` — tersedia di `useNuxtApp()` saja. Lihat [Metode — `$defineI18nRoute`](/api/methods#definei18nroute) dan [`$clearCache`](/api/methods#clearcache).

## 📊 Apa yang dikembalikan

```ts
useI18n(): PluginsInjectionsWithAliases
```

Setiap pembantu runtime, sebagai objek biasa.

Fungsi yang sama yang disuntikkan plugin sebagai `$t`, `$tc`, dan seterusnya, tersedia baik dengan nama berawalan dolar maupun alias telanjang — jadi `const \{ t \} = useI18n()` dan `const \{ $t \} = useI18n()` keduanya berfungsi.

**Mengembalikan** — pembantu yang dijelaskan di [referensi metode](/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

## API khusus `useNuxtApp()`

Ini **tidak** dikembalikan oleh `useI18n()`. Impor dari `useNuxtApp()`:

| Metode                     | Tujuan                                                                          |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Rute lokal per halaman, pembatasan, dan terjemahan sebaris di `script setup`    |
| `$clearCache()`            | Menghapus cache terjemahan dalam memori dan chunk yang dimuat                   |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Lihat [Metode](/api/methods) untuk signature dan contoh lengkap.

## 🛠️ Contoh penggunaan

### Pengambilan lokal dasar

Ambil lokal aplikasi saat ini.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Terjemahan dengan parameter

Terjemahkan string dengan parameter dinamis, dengan nilai default fallback.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Beralih lokal

Alihkan aplikasi ke lokal berbeda.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Menghasilkan rute lokal

Hasilkan rute yang dilokalkan ke lokal saat ini atau yang ditentukan.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
