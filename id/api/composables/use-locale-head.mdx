# 🌍 Composable `useLocaleHead`

Composable `useLocaleHead` adalah utilitas di `Nuxt I18n Micro` yang membantu Anda mengelola atribut SEO dan tag meta HTML untuk rute lokal. Ini secara dinamis menghasilkan atribut untuk `lang` dan `dir` dokumen HTML serta membuat tag `meta` dan `link` untuk meningkatkan SEO konten lokal Anda.

## ⚙️ Opsi

Tag head SEO untuk rute saat ini: alternatif `hreflang` untuk setiap lokal ditambah `x-default`, tautan canonical, `og:locale`, dan `lang`/`dir` pada `<html>`.

Hanya diperlukan saat `meta` dinonaktifkan atau default perlu disesuaikan — dengan `meta: true`, modul mendaftarkan tag yang sama sendiri.

## 🛠️ Nilai kembali

Composable `useLocaleHead` mengembalikan objek reaktif dan fungsi updater yang harus Anda panggil saat data sumber berubah. Kedua bentuk ada di signature di atas, dihasilkan dari sumber.

### `metaObject`

Payload head reaktif (atribut html, meta, link) yang cocok untuk `useHead(metaObject)`.

- **Contoh**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

Menghitung ulang `metaObject` berdasarkan rute, lokal, dan konfigurasi saat ini. Panggil saat input berubah — pada perubahan rute, misalnya.

- **Contoh**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### Mengakses `link` dan `meta`

Array `link` dan `meta` dapat diakses melalui `metaObject.value`:

- **Contoh**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ Contoh penggunaan

### Penggunaan dasar

Hasilkan atribut head khusus lokal dengan opsi default.

```js
const head = useLocaleHead()
```

### Menyesuaikan atribut pengenal

Gunakan atribut pengenal kustom untuk tag yang dihasilkan.

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### Menonaktifkan atribut SEO

Hasilkan atribut head tanpa menambahkan tag meta dan link terkait SEO.

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### Menentukan URL dasar

Atur URL dasar kustom untuk URL canonical dan alternatif.

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 Fitur tambahan

### Tag meta dan link SEO

Saat `addSeoAttributes` diaktifkan, composable secara otomatis menghasilkan tag berikut:

- `og:locale` untuk lokal saat ini (`language_TERRITORY`, garis bawah). Berasal dari `locale.og` atau dikonversi dari `locale.iso` bila memungkinkan.
- `og:url` untuk URL canonical halaman.
- `og:locale:alternate` untuk versi bahasa alternatif.
- Tautan `rel="canonical"` dan `rel="alternate"` untuk pengoptimalan SEO.
- Tautan `hreflang="x-default"` yang menunjuk ke URL lokal default. Ini memberi tahu mesin pencari URL mana yang akan ditampilkan kepada pengguna yang bahasanya tidak cocok dengan lokal yang ditentukan.

### Lokal dan arah dinamis

Composable secara dinamis menentukan atribut `lang` dan `dir` berdasarkan lokal rute saat ini, memastikan dokumen HTML Anda dikonfigurasi dengan benar untuk pengguna internasional.

### Menangani rute lokal

Jika rute Anda diawali dengan kode lokal (misalnya, `/en/about`), composable secara cerdas menyesuaikan jalur penuh untuk menghasilkan URL, memastikan atribut SEO akurat dan relevan.

Composable ini menyederhanakan proses pengoptimalan aplikasi Nuxt Anda untuk audiens internasional, memastikan situs Anda dipersiapkan dengan baik untuk mesin pencari global dan pengguna.

## 🛠️ Contoh penggunaan

Contoh berikut menunjukkan cara menggunakan composable `useLocaleHead` dalam komponen Vue dengan pengaturan default:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### Penjelasan kode

- **Composable `useLocaleHead`**: Composable ini dipanggil di bagian `<script setup>` dan mengembalikan objek yang berisi `htmlAttrs`, `meta`, dan `link`.

- **Tag `<html>`**: Atribut `lang` dan `dir` untuk dokumen HTML ditentukan secara dinamis berdasarkan lokal saat ini dan diterapkan ke tag `<html>`.

- **Bagian `<head>`**:
  - **Tag meta**: Tag meta terkait SEO dihasilkan, termasuk `og:locale`, `og:url`, dan tag `rel="canonical"` serta `rel="alternate"` untuk menentukan versi bahasa alternatif halaman.
  - **Tag link**: Tautan canonical, tautan ke versi bahasa alternatif, dan tautan `hreflang="x-default"` (menunjuk ke URL lokal default) disertakan.

- **Bagian `<body>`**: Konten utama halaman ditampilkan di sini. Dalam contoh ini, header dan paragraf sederhana digunakan.

### 📝 Catatan

1. **Atribut**: Atribut yang digunakan (`lang`, `dir`, `rel`, `href`, `hreflang`, `property`, `content`) diekstrak dari objek yang dikembalikan oleh `useLocaleHead`.

2. **Pembuatan tag SEO**: Jika opsi `addSeoAttributes` disetel ke `true`, composable secara otomatis menghasilkan tag SEO untuk lokal saat ini.

3. **URL dasar**: Anda dapat mengatur URL dasar kustom menggunakan opsi `baseUrl` untuk menghasilkan tautan canonical dan alternatif dengan benar.

Contoh ini menunjukkan betapa mudahnya mengintegrasikan `useLocaleHead` ke dalam komponen aplikasi Anda untuk memastikan atribut SEO yang benar dan meningkatkan pengindeksan mesin pencari halaman lokal.

## 🧩 Kustomisasi & siklus hidup

- `useLocaleHead` tidak berlangganan perubahan sendiri. Ini mengembalikan `metaObject` dan `updateMeta`.
- Anda harus memanggil `updateMeta()` saat input berubah (biasanya pada perubahan rute), misalnya dari plugin:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## Kapan menggunakan `useI18nHead` sebagai gantinya

Saat `meta: true` (default), pilih [`useI18nHead`](/api/composables/use-i18n-head) untuk penggantian **per halaman** (hreflang kustom, `og:title` tambahan, nonaktifkan parsial). Gunakan `useLocaleHead` langsung hanya saat `meta: false` atau Anda mengelola `useHead` sendiri.
