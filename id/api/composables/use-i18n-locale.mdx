# useI18nLocale

```vue
<script setup>
```

## API

| Properti/Metode                                 | Tipe                                | Deskripsi                                                                            |
| ----------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| `locale`                                        | `Ref<string \| null>`               | State lokal reaktif (`useState('i18n-locale')`)                                      |
| `localeCookie`                                  | `Ref`                               | Cookie lokal (saat opsi `localeCookie` diaktifkan)                                   |
| `hashCookie`                                    | `Ref`                               | Cookie yang digunakan saat `hashMode` aktif                                          |
| `validLocales`                                  | `string[]`                          | Kode lokal yang diaktifkan dari konfigurasi modul (tidak termasuk `disabled`)        |
| `getLocale()`                                   | `() => string \| null`              | Lokal saat ini: state → cookie (atau cookie hash dalam mode hash)                    |
| `getPreferredLocale()`                          | `() => string \| null`              | Lokal dari state/cookie **divalidasi** terhadap `validLocales`, atau `null`          |
| `getLocaleWithServerFallback(serverLocale?)`    | `(serverLocale?) => string \| null` | State → cookie → konteks server opsional (digunakan selama init `no_prefix`)         |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string`             | Lokal untuk memuat terjemahan: mode hash memilih state; jika tidak, membaca dari rute |
| `resolveInitialLocale(options)`                 | `(options) => string`               | Menyelesaikan lokal: state → `serverLocale` → rute; menyinkronkan state saat diperlukan |
| `setLocale(locale)`                             | `(locale: string \| null) => void`  | Atur lokal dan sinkronkan ke cookie                                                  |
| `syncLocale(locale)`                            | `(locale: string \| null) => void`  | Sinkronkan cookie saja (tanpa pembaruan state)                                       |
| `isValidLocale(locale)`                         | `(locale) => boolean`               | Periksa apakah string ada di `validLocales`                                          |

### Opsi `resolveInitialLocale`

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

Digunakan secara internal oleh plugin utama saat startup. Plugin kustom dapat memanggilnya saat menerapkan alur deteksi alternatif.

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

Mengembalikan lokal yang digunakan untuk memuat terjemahan dan memformat pesan untuk objek rute tertentu.

## Pengaturan lokal secara programatis

Lebih pilih `useI18nLocale()` daripada penggunaan langsung `useState('i18n-locale')`:

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
`setLocale()` memperbarui preferensi lokal (state + cookie) saja. Untuk juga memuat ulang konteks terjemahan aktif di klien, gunakan `$switchLocale()` dari `useNuxtApp()` atau `useI18n()`. Ini sangat penting untuk `no_prefix`, tempat URL tidak berubah. Lihat [FAQ — beralih lokal tanpa mengubah URL](/guides/faq#-switch-locale-without-changing-the-url).
</Tip>
