# 🛠️ Metode

## 🔍 Metode terjemahan

Metode inti untuk mengambil dan mengelola terjemahan.

### `$t`

{/* generated:method:$t — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Terjemahkan kunci, menyisipkan `params` ke dalamnya. Mengembalikan `defaultValue` saat kunci hilang, atau kunci itu sendiri saat tidak ada default yang diberikan.

{/* /generated:method:$t */}

```typescript
const welcomeMessage = $t('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

<Warning>
`$t` mengembalikan `CleanTranslation` yang merupakan `string | number | boolean | Translations | PluralTranslations | null`. Jika kunci mengarah ke **objek bersarang** di JSON Anda (misalnya `$t('header')` saat JSON berisi `\{ "header": \{ "title": "Hi" \} \}`), nilai kembalian akan menjadi **objek** tersebut, bukan string. Menggunakannya langsung dalam template Vue (<code v-pre>\{\{ $t('header') \}\}</code>) akan dirender sebagai `[object Object]`.

**Cara menghindarinya:**

- Gunakan kunci yang lebih spesifik: `$t('header.title')` → `"Hi"`
- Gunakan `$ts()` yang selalu mengembalikan string (memanggil `.toString()` pada non-string)
- Gunakan `$t` dengan kunci bersarang untuk secara sengaja mengakses sub-objek untuk penggunaan programatis
</Warning>

### `$ts`

{/* generated:method:$ts — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string) => string
```

Seperti `$t`, tetapi selalu mengembalikan string: nilai objek atau array di-stringifikasi alih-alih dikembalikan apa adanya.

{/* /generated:method:$ts */}

```typescript
const welcomeMessage = $ts('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

### `$_t` dan `$_ts`

{/* generated:method:$_t — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Ikat `$t` ke rute tertentu, untuk menerjemahkan di luar halaman saat ini — misalnya layout yang merender tautan ke rute lain.

{/* /generated:method:$_t */}

{/* generated:method:$_ts — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => string
```

Ikat `$ts` ke rute tertentu. Lihat `$_t`.

{/* /generated:method:$_ts */}

Varian terikat rute dari `$t` dan `$ts`. Mereka mengambil **rute** terlebih dahulu dan mengembalikan fungsi terjemahan yang terkunci ke lokal dan konteks halaman rute tersebut.

- **Akses**: `useNuxtApp()` (juga diekspor ulang oleh `useI18n()` sebagai `$_t` / `$_ts`)

Gunakan ini saat rute aktif selama SSR atau transisi berbeda dari `router.currentRoute` — misalnya di dalam `<i18n-t>`, `<i18n-group>`, atau saat merender konten untuk objek `route` tertentu.

```typescript
import { useRoute, useNuxtApp } from '#imports'

const route = useRoute()
const { $_t, $_ts } = useNuxtApp()

const $t = $_t(route)
const title = $t('page.title')

// String-safe variant
const label = $_ts(route)('page.label')
```


### `$tc`

{/* generated:method:$tc — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params: number | Params, defaultValue?: string) => string
```

Terjemahkan dengan pluralisasi. `params` dapat berupa jumlah itu sendiri, atau objek yang berisi `count`.

{/* /generated:method:$tc */}

**Format terjemahan**: bentuk dipisahkan oleh `|`. Tempatkan placeholder di **setiap** bentuk:

```json
{
  "apples": "no apples | one apple | {count} apples",
  "cart": "no items for {name} | one item for {name} | {count} items for {name}"
}
```

```typescript
$tc('apples', 0) // "no apples"
$tc('apples', 1) // "one apple"
$tc('apples', 10) // "10 apples"

// count + other params (second argument must be an object)
$tc('cart', { count: 10, name: 'Alice' }) // "10 items for Alice"
```


**Alternatif komponen** — `<i18n-t keypath="cart" :plural="count" :params="\{ name \}" />` (menggabungkan `count` dengan `params` secara internal).


### `$mergeTranslations`

{/* generated:method:$mergeTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
(newTranslations: Translations) => void
```

Gabungkan terjemahan ke lokal aktif saat runtime, menimpa yang dimuat.

{/* /generated:method:$mergeTranslations */}

```typescript
$mergeTranslations({
  welcome: 'Bienvenue, {username}!',
})
// Output: Updates the translation cache with the new French translation
```

### `$resolveTranslations`

{/* generated:method:$resolveTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
() => Translations
```

Setiap terjemahan yang saat ini di memori untuk lokal aktif dan rute, sebagai pohon. Tampilan hanya-baca dari apa yang dapat diselesaikan `$t()` sekarang.

{/* /generated:method:$resolveTranslations */}

```typescript
const tree = $resolveTranslations()
// { aaa: { bbb: 'ccc' }, ddd: 1111 } — the same dictionary $t() reads from
```

Gunakan ini saat Anda memerlukan kamus lengkap dalam memori (DevTools, pengujian, editor runtime). Perlakukan nilai kembalian sebagai hanya-baca; ubah nilai melalui `$setTranslation` atau gabungkan patch dengan `$mergeTranslations`.

### `$setTranslation`

{/* generated:method:$setTranslation — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, value: unknown) => void
```

Ganti nilai di `key` di kamus aktif. Ini adalah penggantian, bukan penggabungan — gunakan `$mergeTranslations` saat saudara yang ada harus bertahan.

{/* /generated:method:$setTranslation */}

```typescript
$setTranslation('aaa', { fff: 'ggg' }) // replaces the whole `aaa` subtree
$setTranslation('aaa', 'text')          // replaces `aaa` with a string
$setTranslation('ddd', 1111)            // scalar at the top level
$setTranslation('aaa.bbb', 'nested')    // dotted path
```

Ini adalah **penggantian**, bukan penggabungan. Saudara yang ada di bawah kunci yang sama dihapus. Untuk melakukan patch tanpa kehilangan saudara, gunakan `$mergeTranslations`.

### `$setMissingHandler`

{/* generated:method:$setMissingHandler — do not edit; run `pnpm run docs:generate` */}

```ts
(handler: MissingHandler | null) => void
```

Instal callback yang dipanggil untuk setiap kunci yang tidak terselesaikan. Berikan `null` untuk menghapusnya.

{/* /generated:method:$setMissingHandler */}

**Definisi tipe**:

```typescript
type MissingHandler = (locale: string, key: string, routeName: string, instance?: unknown, type?: string) => void
```

```typescript
// Set a custom handler
$setMissingHandler((locale, key, routeName) => {
  console.error(`Missing translation: ${key} in ${locale} for route ${routeName}`)
  // Send to Sentry or other error tracking service
  // Sentry.captureMessage(`Missing translation: ${key}`)
})

// Remove the handler
$setMissingHandler(null)
```

**Kasus penggunaan**:

- Mencatat terjemahan yang hilang ke layanan pelacakan kesalahan (Sentry, LogRocket, dll.)
- Mengumpulkan analitik pada terjemahan yang hilang
- Penanganan kesalahan kustom untuk kunci terjemahan yang hilang

## 🔢 Format angka & tanggal

Metode untuk memformat angka dan tanggal sesuai dengan konvensi lokal.

### `$tn`

{/* generated:method:$tn — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Format angka dengan `Intl.NumberFormat` di lokal aktif. Kunci memilih format bernama dari konfigurasi.

{/* /generated:method:$tn */}

```typescript
// Inline options
const formattedNumber = $tn(1234567.89, { style: 'currency', currency: 'USD' })
// "$1,234,567.89"

// Named format (from nuxt.config i18n.numberFormats)
const price = $tn(1000, 'currency')
const priceDe = $tn(1000, 'currency', 'de')
const compact = $tn(1000, 'currency', { notation: 'compact' })
```

Kunci format bernama yang tidak dikenal kembali ke opsi `Intl.NumberFormat` default. Dalam pengembangan (klien), `console.warn` dipancarkan saat `missingWarn` diaktifkan (default).

**Contoh konfigurasi**:

```ts
export default defineNuxtConfig({
  i18n: {
    numberFormats: {
      en: {
        currency: { style: 'currency', currency: 'USD' },
        decimal: { style: 'decimal', minimumFractionDigits: 2, maximumFractionDigits: 2 },
      },
      de: {
        currency: { style: 'currency', currency: 'EUR' },
      },
    },
  },
})
```

**Kasus penggunaan**:

- Memformat angka sebagai mata uang, persentase, atau desimal dalam format lokal yang sesuai
- Menggunakan kembali format bernama di seluruh aplikasi (paritas migrasi Vue I18n)

### `$td`

{/* generated:method:$td — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Format tanggal dengan `Intl.DateTimeFormat` di lokal aktif. Kunci memilih format bernama dari konfigurasi.

{/* /generated:method:$td */}

```typescript
const formattedDate = $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' })
// "Friday, September 1, 2023"

const short = $td(new Date(), 'short')
const longDe = $td(new Date(), 'long', 'de')
```

Kunci format bernama yang tidak dikenal kembali ke opsi `Intl.DateTimeFormat` default. Dalam pengembangan (klien), `console.warn` dipancarkan saat `missingWarn` diaktifkan (default).

**Contoh konfigurasi**:

```ts
export default defineNuxtConfig({
  i18n: {
    datetimeFormats: {
      en: {
        short: { year: 'numeric', month: 'short', day: 'numeric' },
        long: { year: 'numeric', month: 'long', day: 'numeric', weekday: 'long' },
      },
    },
  },
})
```

**Kasus penggunaan**:

- Menampilkan tanggal dalam format yang selaras dengan lokal pengguna
- Berbagi preset short/long/date-time di seluruh aplikasi

### `$tdr`

{/* generated:method:$tdr — do not edit; run `pnpm run docs:generate` */}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

Format tanggal sebagai waktu relatif ("3 hari yang lalu") dengan `Intl.RelativeTimeFormat`.

{/* /generated:method:$tdr */}

```typescript
const relativeDate = $tdr(new Date(Date.now() - 1000 * 60 * 5))
// Output: "5 minutes ago" in the 'en-US' locale
```

## 🚦 Konfigurasi rute

Metode untuk mengonfigurasi perilaku rute dan kontrol akses.

### `$defineI18nRoute`

{/* generated:method:$defineI18nRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Daftarkan konfigurasi lokal dan terjemahan per halaman dari dalam komponen. Digabungkan ke lokal aktif dan diterapkan ulang saat lokal berubah.

{/* /generated:method:$defineI18nRoute */}

> [!IMPORTANT]
> `$defineI18nRoute` disediakan oleh **plugin define** dan tersedia hanya di `useNuxtApp()` — ini **bukan** bagian dari objek kembalian `useI18n()`.
> Selalu destrukturkan dari `useNuxtApp()` di dalam `script setup`. Memanggil `$defineI18nRoute(...)` sebagai global telanjang menghasilkan `"$defineI18nRoute is not defined"` selama SSR/prerender.

**Parameter**:

- **locales**: `string[] | Record<string, Record<string, string>>` — Lokal yang tersedia untuk rute
- **localeRoutes**: `Record<string, string>` — Opsional. Rute kustom untuk lokal tertentu
- **disableMeta**: `boolean | string[]` — Opsional. Nonaktifkan tag meta i18n untuk semua atau lokal tertentu

**Contoh dasar**:

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr', 'de'],
  localeRoutes: {
    en: '/welcome',
    fr: '/bienvenue',
    de: '/willkommen',
  },
  disableMeta: false,
})
```

> 📖 **Untuk contoh penggunaan rinci, format konfigurasi, dan praktik terbaik, lihat [Panduan terjemahan per komponen](/guides/per-component-translations).**

### `$setI18nRouteParams`

{/* generated:method:$setI18nRouteParams — do not edit; run `pnpm run docs:generate` */}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Atur parameter per lokal untuk rute saat ini, sehingga segmen dinamis dapat berbeda per bahasa. Panggil selama SSR, sebelum head dirender.

{/* /generated:method:$setI18nRouteParams */}

```typescript
// in pages/news/[id].vue
// for en/news/1-first-article
const { $switchLocaleRoute, $setI18nRouteParams, $defineI18nRoute } = useNuxtApp()
$defineI18nRoute({
  localeRoutes: {
    en: '/news/:id()',
    fr: '/nouvelles/:id()',
    de: '/Nachricht/:id()',
  },
})
const { data: news } = await useAsyncData(`news-${params.id}`, async () => {
  let response = await $fetch("/api/getNews", {
    query: {
      id: params.id,
    },
  });
  if (response?.localeSlugs) {
    response.localeSlugs = {
      en: {
        id: '1-first-article'
      }
      fr: {
        id: '1-premier-article'
      }
      de: {
        id: '1-erster-Artikel'
      }
    }
    $setI18nRouteParams(response?.localeSlugs);
  }
  return response;
});
$switchLocalePath('fr') // === 'fr/nouvelles/1-premier-article'
$switchLocalePath('de') // === 'de/Nachricht/1-erster-Artikel'
```

## 🧭 Composable `useI18nLocale`

Composable terpusat untuk manajemen keadaan lokal. Gunakan ini alih-alih memanipulasi langsung `useState('i18n-locale')` atau `useCookie('user-locale')`.

```typescript
const {
  setLocale, // (locale: string) => void — updates state + cookie
  getLocale, // () => string | null — from state or cookie
  getPreferredLocale, // () => string | null — validated against locales list
  getEffectiveLocale, // (route, getLocaleFromRoute) => string
  resolveInitialLocale, // (options) => string
  isValidLocale, // (locale) => boolean
  locale, // Ref<string | null> — reactive state
  localeCookie, // CookieRef — reactive cookie
  syncLocale, // (locale) => void — sync to cookie only
  validLocales, // string[] — list of valid locale codes
} = useI18nLocale()
```

### Metode utama

| Metode                  | Deskripsi                                                   |
| ----------------------- | ----------------------------------------------------------- |
| `setLocale(locale)`     | Menetapkan lokal di `useState` dan cookie secara atomik     |
| `getLocale()`           | Mengembalikan lokal saat ini dari state atau cookie         |
| `getPreferredLocale()`  | Mengembalikan lokal yang divalidasi terhadap daftar `locales`, atau `null` |
| `isValidLocale(locale)` | Memeriksa apakah kode lokal ada di daftar `locales` yang dikonfigurasi |

### Penggunaan di plugin kustom

```typescript
// plugins/i18n-loader.server.ts
export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,
  setup() {

    // Detect locale from headers, domain, etc.
    setLocale('de')
  },
})
```
