---

Modul menyuntikkan helper runtime-nya ke dalam aplikasi Nuxt: `$t`, `$tc`, `$localePath`, `$switchLocale`, dan lainnya. Gunakan halaman ini untuk mencari signature dan perilaku sebuah helper. Signature dan deskripsi berasal dari interface `PluginsInjections` dan `NuxtAppOnlyInjections` di `src/runtime/plugins/01.plugin.ts`.

## Akses {#access}

| Di mana | Caranya |
| --- | --- |
| Template | `{{ $t('title') }}` — setiap helper, dengan `$` |
| `<script setup>` | `const { t, localePath } = useI18n()` — setiap helper di `PluginsInjections`, dengan dan tanpa `$` |
| Plugin, middleware, `<script setup>` | `const { $t, $defineI18nRoute } = useNuxtApp()` — semuanya, hanya dengan `$` |

`$defineI18nRoute` hanya diberi tipe pada `useNuxtApp()`. Lihat [`useI18n`](/id/composables/useI18n).

```vue
<script setup lang="ts">
const { t, localePath } = useI18n()
</script>

<template>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
</template>
```

## Locale {#locale}

### `$getLocale` {#$getlocale}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric) => string
```

Kode locale aktif. Berikan sebuah rute untuk membaca locale milik rute tersebut.

```ts
$getLocale() // 'de' on /de/about
```

### `$getLocaleName` {#$getlocalename}

```ts
() => string | null
```

`displayName` locale aktif dari konfigurasi, atau `null` jika tidak ada.

### `$getLocales` {#$getlocales}

```ts
() => Locale[]
```

Setiap locale yang dikonfigurasi, beserta metadatanya.

Properti kustom pada objek locale dikembalikan apa adanya; beri tipe dengan [module augmentation](/id/api/module-options#locales) pada `Locale`.

### `$defaultLocale` {#$defaultlocale}

```ts
() => string | undefined
```

Kode locale default yang dikonfigurasi.

### `$getI18nConfig` {#$geti18nconfig}

```ts
() => ResolvedI18nConfig
```

Konfigurasi modul yang telah di-resolve, sebagaimana dilihat oleh runtime.

Nilainya mencakup [penimpaan runtime](/id/guide/runtime-overrides) (`defaultLocale`, `fallbackLocale`, locale yang dinonaktifkan).

```ts
const { strategy, localeCookie } = useNuxtApp().$getI18nConfig()
```

## Terjemahan {#translation}

### `$t` {#$t}

```ts
TranslationFn<CleanTranslation>
```

Menerjemahkan key, menyisipkan `params` ke dalamnya. Mengembalikan `defaultValue` jika key
tidak ada, atau key itu sendiri jika tidak ada default yang diberikan.

```ts
// { "welcome": "Welcome, {name}!" }
$t('welcome', { name: 'Ada' }) // 'Welcome, Ada!'
$t('missing.key', {}, 'Fallback') // 'Fallback'
```

Key yang menunjuk ke objek bersarang mengembalikan objek tersebut, bukan string. Di template, objek itu dirender sebagai `[object Object]`; gunakan leaf key.

### `$ts` {#$ts}

```ts
TranslationFn<string>
```

Seperti `$t`, tetapi selalu mengembalikan string: nilainya melewati `toString()`, sehingga objek
bersarang menjadi `'[object Object]'`. Arahkan key ke leaf.

### `$_t` {#$_t}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<CleanTranslation>
```

Mengikat `$t` ke rute tertentu, untuk menerjemahkan di luar halaman saat ini — misalnya layout
yang merender tautan ke rute lain.

```ts
const route = useRoute()
const t = useNuxtApp().$_t(route)
t('page.title')
```

### `$_ts` {#$_ts}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<string>
```

Mengikat `$ts` ke rute tertentu. Lihat `$_t`.

### `$tc` {#$tc}

```ts
(key: TranslationKey, params: number | Params, defaultValue?: string) => string
```

Menerjemahkan dengan pluralisasi. `params` dapat berupa jumlahnya sendiri, atau objek yang berisi
`count`.

Bentuk-bentuk dipisahkan dengan `|`. Dengan aturan bawaan, jumlah bilangan bulat non-negatif `n` memilih bentuk `n`, dibatasi hingga bentuk terakhir; jumlah negatif, pecahan, atau `NaN` mengambil bentuk terakhir. `{count}` dan params lainnya disisipkan ke dalam bentuk yang dipilih.

Untuk bahasa yang bentuk jamaknya tidak mengikuti jumlah, awali template dengan `=0 `. Bentuk pertama kemudian untuk 0, dan bentuk lainnya mengikuti kategori [`Intl.PluralRules`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/PluralRules), dengan urutan `zero, one, two, few, many, other`:

```json
{
  "apples": "=0 no apples | one apple | {count} apples",
  "files": "=0 no files | {count} one | {count} few | {count} many"
}
```

```ts
$tc('apples', 0) // 'no apples'
$tc('apples', 1) // 'one apple'
$tc('apples', 7) // '7 apples'

// In `uk` (categories `one, few, many, other`) the forms after the zero form follow those categories:
$tc('files', 21) // '21 one'
$tc('files', 22) // '22 few'
$tc('files', 25) // '25 many'
$tc('files', 2.5) // '2.5 many': no form for `other`, so the last one
```

- `=0 ` hanya diperhitungkan di awal nilai, dengan spasinya. `$t` menampilkannya sebagai teks: penanda ini milik bentuk jamak.
- Kategori yang tidak memiliki bentuknya sendiri mengambil bentuk terakhir. Jumlah negatif atau pecahan juga mengambil bentuk terakhir.
- Ini berfungsi di locale mana pun: `=0 none | one | {count} many` dalam bahasa Inggris.
- Kategori berasal dari `iso` locale, atau kodenya. Kode yang tidak dikenal `Intl` kembali ke aturan indeks, dengan penanda tetap dihapus, sehingga hasilnya tidak pernah bergantung pada mesin.
- `<i18n-t :plural>` mengikuti aturan yang sama. [`plural`](/id/api/module-options#plural) kustom atau `customPluralRule` menerima nilai mentah, termasuk penandanya, dan memutuskan sendiri; `plural` yang mengembalikan `null` menyerahkan panggilan kembali ke aturan bawaan, yang menghormati penanda.

Tanpa penanda, template tetap menggunakan aturan indeks, dengan satu pengecualian yang hanya dapat dibaca dengan satu cara: bentuk nol tanpa placeholder, lalu satu bentuk per kategori, dengan `{count}` di setiap bentuk yang dipakai bersama oleh beberapa jumlah (`no files | {count} one | {count} few | {count} many` dalam `uk`).

Untuk aturan Anda sendiri, atur [`plural`](/id/api/module-options#plural).

```ts
// { "apples": "no apples | one apple | {count} apples" }
$tc('apples', 0) // 'no apples'
$tc('apples', 10) // '10 apples'
$tc('cart', { count: 2, name: 'Ada' }) // count and params in one object
```

Argumen ketiga adalah `defaultValue`, bukan params.

### `$has` {#$has}

```ts
(key: string) => boolean
```

Apakah sebuah key dapat di-resolve di locale aktif. Gunakan untuk bercabang pada teks opsional alih-alih
merender key mentah. Seperti `$t`, fungsi ini juga melihat key halaman yang sedang ditinggalkan selama
transisi halaman dengan locale yang sama.

```ts
if ($has('promo.banner')) show.value = true
```

## Pemformatan {#formatting}

### `$tn` {#$tn}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Memformat angka dengan `Intl.NumberFormat` dalam locale aktif. Sebuah key memilih format bernama
dari konfigurasi.

Format bernama berasal dari [`numberFormats`](/id/api/module-options#numberformats).

```ts
$tn(1234.5, { style: 'currency', currency: 'EUR' }) // '1.234,50 €' in de
$tn(1000, 'currency') // named format
$tn(1000, 'currency', 'de') // named format in another locale
```

### `$td` {#$td}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Memformat tanggal dengan `Intl.DateTimeFormat` dalam locale aktif. Sebuah key memilih format bernama
dari konfigurasi.

Format bernama berasal dari [`datetimeFormats`](/id/api/module-options#datetimeformats).

```ts
$td(new Date(), { dateStyle: 'long' })
$td(post.createdAt, 'short')
```

### `$tdr` {#$tdr}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

Memformat tanggal sebagai waktu relatif ("3 hari yang lalu") dengan `Intl.RelativeTimeFormat`.

```ts
$tdr(Date.now() - 5 * 60_000) // '5 minutes ago' in en
```

## Peralihan dan tautan {#switching-and-links}

### `$switchLocale` {#$switchlocale}

```ts
(locale: string) => Promise<boolean>
```

Menavigasi ke halaman saat ini dalam locale lain. Pada `no_prefix` dan mode hash, fungsi ini memuat
terjemahan locale sebelum navigasi; pada `no_prefix` rute diganti di tempat (tanpa
entri riwayat baru). Locale yang tidak dikenal diabaikan.
Panggilan ini async: gunakan `await` untuk menjalankan kode setelah navigasi. Hasilnya `true` jika
kamus locale aktif, `false` jika tidak: chunk gagal dimuat (kamus saat ini
tetap dipakai; panggil lagi untuk mencoba ulang) atau peralihan yang lebih baru yang menang.

```ts
await $switchLocale('de')
```

### `$switchLocalePath` {#$switchlocalepath}

```ts
(locale: string) => string
```

Path halaman saat ini dalam locale lain, tanpa navigasi.

```vue
<NuxtLink :to="$switchLocalePath('de')">Deutsch</NuxtLink>
```

### `$switchLocaleRoute` {#$switchlocaleroute}

```ts
(locale: string) => RouteLocationRaw
```

Objek rute untuk halaman saat ini dalam locale lain, tanpa navigasi, atau string URL
untuk locale dengan `baseUrl` sendiri. Pada `trailingSlash`, objek memiliki `path` dan `fullPath`
yang mengikuti aturan tersebut, dengan `query` dan `hash` apa adanya, dan `router.push` atau tautan mempertahankannya.

### `$switchRoute` {#$switchroute}

```ts
(route: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, toLocale?: string) => Promise<void>
```

Menavigasi ke rute lain, mempertahankan locale aktif atau beralih ke `toLocale`. Async seperti
`$switchLocale`.

```ts
$switchRoute('/about') // active locale
$switchRoute({ name: 'about' }, 'de') // switch to de
```

### `$localePath` {#$localepath}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => string
```

Me-resolve path dalam locale yang diberikan, atau locale aktif. String dengan skema `http(s):`, `mailto:`
atau `tel:` dikembalikan apa adanya: jangan berikan input pengguna sebagai target tautan tanpa diperiksa.

Path berupa string dibaca sebagai halaman yang ditampilkannya, sehingga path kustom locale juga diterapkan.

```ts
$localePath('/about') // '/about' in en, '/de/ueber-uns' in de with localeRoutes
$localePath({ name: 'about' }, 'fr') // '/fr/about'
```

### `$localeRoute` {#$localeroute}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => RouteLocationResolved
```

Me-resolve rute dalam locale yang diberikan, atau locale aktif. Objek biasa, aman disimpan di state. Jika sebuah param perlu
di-escape, objek ini memiliki `path`, `fullPath`, `query`, dan `hash` tetapi tanpa `name` atau `params`: path-lah yang memberi router
URL yang telah di-encode. Untuk locale di domain lain, `path` dan `fullPath` bersifat absolut, yang tidak dapat diterima router:
tautan seperti itu melalui `<i18n-link>`, atau `$localePath`.

### `$getRouteName` {#$getroutename}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric, locale?: string) => string
```

Nama rute tanpa prefiks locale — nama yang menjadi key terjemahan.

```ts
$getRouteName() // 'about' on /de/about
```

## Konfigurasi halaman {#page-config}

### `$defineI18nRoute` {#$definei18nroute}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Mendaftarkan konfigurasi locale dan terjemahan per halaman dari dalam komponen.
Digabungkan ke locale aktif dan diterapkan ulang saat locale berubah.

Panggil di `<script setup>` sebuah halaman, selalu dengan destrukturisasi dari `useNuxtApp()`. Build membaca `locales`, `localeRoutes`, dan `disableMeta` dari panggilan tersebut; saat runtime hanya `locales` yang berpengaruh (terjemahan inline digabungkan untuk locale aktif). Aturan lengkap: [Konfigurasi halaman](/id/guide/per-component-translations).

```vue
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'de'],
  localeRoutes: { en: '/about', de: '/ueber-uns' },
})
</script>
```

### `$setI18nRouteParams` {#$seti18nrouteparams}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Mengatur params per locale untuk rute saat ini, sehingga segmen dinamis dapat berbeda per bahasa.
Panggil selama SSR, sebelum head dirender.

Params dihapus saat navigasi ke path lain di-commit, termasuk `/news/1` ke `/news/4`, yang mempertahankan nama rute. Detail: [Path yang dilokalkan](/id/guide/custom-locale-routes).

```ts
$setI18nRouteParams({
  en: { slug: 'my-post' },
  de: { slug: 'mein-beitrag' },
})
```

## Terjemahan runtime {#runtime-translations}

### `$mergeTranslations` {#$mergetranslations}

```ts
(newTranslations: Translations) => void
```

Menggabungkan terjemahan ke locale aktif saat runtime, menimpa yang sudah dimuat.

Melakukan deep-merge ke chunk halaman saat ini dari locale aktif; key yang tidak disebutkan tetap ada.

```ts
$mergeTranslations({ banner: { title: 'Sale' } })
```

### `$setTranslation` {#$settranslation}

```ts
(key: string, value: unknown) => void
```

Mengganti nilai pada `key` di kamus aktif. Ini penggantian, bukan penggabungan —
gunakan `$mergeTranslations` jika saudara yang sudah ada harus tetap dipertahankan.

```ts
$setTranslation('banner', { title: 'Sale' }) // drops other keys under banner
$setTranslation('banner.title', 'Sale') // dotted path
```

### `$loadPageTranslations` {#$loadpagetranslations}

```ts
(locale: string, routeName: string, translations: Translations) => Promise<void>
```

Memuat terjemahan untuk sebuah halaman saat runtime, untuk konten yang key-nya tidak diketahui saat build.

Digabungkan ke chunk `(locale, routeName)` di memori, dan layar diperbarui saat chunk tersebut aktif. Tidak ada payload yang diambil di sini: untuk halaman yang belum dimuat, terjemahan menunggu, dan saat file-nya dimuat terjemahan tersebut tetap berada di atasnya.

```ts
await $loadPageTranslations('en', 'about', { title: 'About us' })
```

### `$resolveTranslations` {#$resolvetranslations}

```ts
() => Translations
```

Setiap terjemahan yang saat ini ada di memori untuk locale dan rute aktif, sebagai pohon.
Tampilan hanya-baca dari apa yang dapat di-resolve `$t()` saat ini.

Perlakukan hasilnya sebagai hanya-baca.

### `$setMissingHandler` {#$setmissinghandler}

```ts
(handler: MissingHandler | null) => void
```

Memasang callback yang dipanggil untuk setiap key yang tidak ter-resolve. Berikan `null` untuk menghapusnya.

Handler berjalan sebagai pengganti peringatan dev.

```ts
$setMissingHandler((locale, key, routeName) => {
  console.error(`[i18n] missing ${key} in ${locale} (${routeName})`)
})
```

### `$clearCache` {#$clearcache}

```ts
() => void
```

Membuang setiap chunk terjemahan yang di-cache dan memuat ulang kamus halaman saat ini. Halaman
tetap menampilkan terjemahan saat ini hingga yang baru tiba. HMR dev memanggilnya pada
setiap perubahan file terjemahan.

```ts
const { clearCache } = useI18n()
clearCache()
```

Pemuatan ulang yang gagal mempertahankan kamus saat ini.
