# Referensi opsi modul

Setiap opsi yang diterima `nuxt-i18n-micro`, dibaca saat waktu build dari antarmuka `ModuleOptions` di [`packages/types/src/index.ts`](https://github.com/s00d/nuxt-i18n-micro/blob/main/packages/types/src/index.ts). Tidak ada yang ditulis dengan tangan di sini, sehingga tidak dapat tertinggal dari kode — tipe, default, dan deskripsi berasal dari deklarasi itu sendiri.

Untuk memahami *makna* opsi-opsi ini secara bersamaan — kombinasi mana yang masuk akal, apa yang berubah saat Anda beralih strategi, contoh nyata — baca [Konfigurasi](/guides/configuration). Halaman ini adalah daftar lengkap; halaman itu adalah penjelasannya.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'de', iso: 'de-DE', dir: 'ltr' },
    ],
    defaultLocale: 'en',
  },
})
```

Opsi bersarang muncul di bawah jalur bertitik, jadi `translationPayloads.mode` adalah kunci `mode` di dalam objek `translationPayloads`.

## Lokal dan perutean

Bahasa apa saja yang ada dan bagaimana ditampilkan di URL.

| Opsi | Tipe | Default | Deskripsi |
| --- | --- | --- | --- |
| `locales` | `Locale[]` | `[]` | Daftar lokal yang didukung. Setiap entri mendefinisikan kode lokal ditambah metadata opsional (ISO, arah, nama tampilan, dll.). |
| `strategy` | `Strategies` | `'prefix_except_default'` | Strategi perutean URL untuk awalan lokal. - `'no_prefix'` — tanpa lokal di URL; lokal disimpan di cookie. - `'prefix_except_default'` — awalkan semua lokal kecuali default. - `'prefix'` — selalu awalkan, termasuk lokal default. - `'prefix_and_default'` — seperti `prefix`, tetapi lokal default juga dapat diakses tanpa awalan. |
| `defaultLocale` | `string` | `'en'` | Lokal yang digunakan saat tidak ada lokal yang dapat ditentukan dari URL atau preferensi pengguna. Juga digunakan sebagai lokal fallback untuk terjemahan yang hilang saat `fallbackLocale` tidak diatur. |
| `localeCookie` | `string \| null` | `null` | Nama cookie untuk mempertahankan preferensi lokal pengguna di seluruh sesi. Atur ke `null` untuk menonaktifkan persistensi berbasis cookie. Diatur otomatis ke `'user-locale'` untuk strategi `no_prefix` jika tidak disediakan. |
| `globalLocaleRoutes` | `GlobalLocaleRoutes` | `\{\}` | Konfigurasi lokal tingkat rute global. Memungkinkan pembatasan atau penyesuaian rute lokal untuk halaman tertentu tanpa memodifikasi komponennya. - `false` — kecualikan rute dari lokalisasi. - `Record<LocaleCode, string>` — jalur kustom per lokal. |
| `customRegexMatcher` | `string \| RegExp` | `undefined (uses built-in pattern based on locale codes)` | Ekspresi reguler kustom (atau sumber string-nya) untuk mencocokkan kode lokal di segmen URL. Semua kode lokal yang didefinisikan di `locales` harus cocok dengan pola ini, atau peringatan akan muncul. |
| `noPrefixRedirect` | `boolean` | `false` | Untuk strategi `no_prefix`: aktifkan pengalihan dari URL berawalan lokal (misalnya `/en/about`) ke versi tanpa awalan (`/about`). |
| `excludePatterns` | `(string \| RegExp)[]` | `undefined` | Pola URL (string atau RegExp) yang sepenuhnya dikecualikan dari pemrosesan i18n. Rute yang cocok tidak akan mendapatkan awalan lokal, pengalihan, atau pemuatan terjemahan. Jalur Nuxt internal (`/__nuxt_error`, dll.) selalu dikecualikan secara otomatis. |
| `routeLocales` | `Record<string, string[]>` | — | Pembatasan lokal per rute, diekstrak dari panggilan `defineI18nRoute()`. Memetakan jalur rute (misalnya `'/about'`) ke array kode lokal yang diizinkan. Rute yang tidak terdaftar tidak memiliki pembatasan (semua lokal diizinkan). |

## Terjemahan

Tempat file terjemahan berada dan cara kunci diselesaikan.

| Opsi | Tipe | Default | Deskripsi |
| --- | --- | --- | --- |
| `translationDir` | `string` | `'locales'` | Jalur ke direktori yang berisi file JSON terjemahan, relatif terhadap root proyek. |
| `disableWatcher` | `boolean` | `false` | Nonaktifkan file watcher yang secara otomatis membuat file terjemahan yang hilang dalam mode pengembangan. |
| `routesLocaleLinks` | `\{ [key: string]: string \}` | `\{\}` | Petakan nama rute ke nama rute lain untuk berbagi file terjemahan yang sama. Misalnya, `\{ 'about-us': 'about' \}` berarti halaman `about-us` akan menggunakan terjemahan dari halaman `about` alih-alih miliknya sendiri. |
| `plural` | `PluralFunc` | `built-in pluralization (form index by count)` | Fungsi pluralisasi kustom. Menerima `(key, count, params, locale, getter)` dan harus mengembalikan bentuk plural yang dipilih sebagai string, atau `null`/`undefined` untuk kembali ke logika `defaultPlural` bawaan (sehingga Anda dapat menimpa hanya beberapa lokal). Untuk modul Nuxt, fungsi diserialisasi dengan `.toString()` ke `.nuxt/i18n.plural.mjs` — harus mandiri (tanpa impor / lingkup luar). String jalur file **tidak** didukung. |
| `disablePageLocales` | `boolean` | `false` | Nonaktifkan file terjemahan per halaman. Saat `true`, hanya terjemahan global (`\{locale\}.json`) yang dimuat; file khusus halaman (`pages/\{page\}/\{locale\}.json`) tidak dibuat atau dimuat. |
| `fallbackLocale` | `string` | `undefined (no fallback; returns the raw key)` | Kode lokal fallback global. Saat kunci terjemahan hilang di lokal aktif, modul mencarinya di lokal ini sebelum mengembalikan kunci itu sendiri. |

## Payload dan caching

Cara terjemahan mencapai browser. [Kinerja](/guides/performance) menjelaskan apa yang berubah saat runtime.

| Opsi | Tipe | Default | Deskripsi |
| --- | --- | --- | --- |
| `serverTranslationPreload` | `boolean` | `false` | Pramuat terjemahan halaman indeks di middleware global Nitro (khusus server, konfigurasi pribadi). |
| `apiBaseUrl` | `string` | `'_locales'` | Segmen jalur URL dasar untuk rute API terjemahan (digunakan dalam pengambilan data SSR/SSG). Juga dapat diatur melalui variabel lingkungan `NUXT_I18N_APP_BASE_URL`. |
| `apiBaseClientHost` | `string` | `undefined` | Timpa host yang digunakan untuk permintaan fetch terjemahan sisi klien. Berguna saat klien mencapai server melalui hostname berbeda dari yang dilihat Nuxt. Juga dapat diatur melalui variabel lingkungan `NUXT_I18N_APP_BASE_CLIENT_HOST`. |
| `apiBaseServerHost` | `string` | `undefined` | Timpa host yang digunakan untuk permintaan fetch terjemahan sisi server. Berguna dalam pengaturan container/microservice tempat server mencapai dirinya sendiri melalui hostname internal. Juga dapat diatur melalui variabel lingkungan `NUXT_I18N_APP_BASE_SERVER_HOST`. |
| `translationPayloads` | `TranslationPayloadOptions` | — | Mengontrol bagaimana payload terjemahan dipancarkan (Node: `public/<apiBaseUrl>`; Edge: Nitro `serverAssets`). - **Node**: `serverAssets` berarti SSR lokal melalui `readFile` di bawah `public/` (tanpa Rollup `raw:`). - **Edge**: `serverAssets` mendaftarkan Nitro `serverAssets` (`assets:i18n`); tidak memaksa salinan publik. Pertahankan default untuk pengaturan all-in-one biasa. Untuk katalog Edge besar, pilih `mode: 'source'`. Untuk penerapan yang didukung CDN, nonaktifkan output lokal dan atur `apiBaseClientHost` / `apiBaseServerHost`. |
| `translationPayloads.mode` | `'premerged' \| 'source'` | `'premerged'` | Strategi payload terjemahan. - `premerged`: matriks `\{page\}/\{locale\}/data.json` waktu build (default) - `source`: file sumber ringkas yang digabungkan saat runtime (lebih disukai di Edge / katalog besar) |
| `translationPayloads.serverAssets` | `boolean` | `true` | Payload SSR lokal: Node membaca `public/<apiBaseUrl>` (memaksa salinan publik); Edge menyematkan melalui Nitro `serverAssets`. - **Node**: tanpa Nitro `serverAssets` (menghindari Rollup `raw:`). SSR membaca   `public/<apiBaseUrl\|publicDir>` sebagai `\{page\}/\{locale\}/data.json`; saat ini `true`,   salinan publik dipaksa bahkan jika `publicAssets` false. - **Edge** (`nitro.node === false`): Nitro `serverAssets` (`assets:i18n`) dengan tata letak yang sama seperti `mode`. **Tidak** memaksa salinan publik — atur `publicAssets: true` untuk CDN. |
| `translationPayloads.serverHandler` | `boolean` | `true` | Daftarkan rute server bawaan di `/\{apiBaseUrl\}/:page/:locale/data.json`. Nonaktifkan ini saat payload terjemahan disajikan dari host/CDN eksternal. |
| `translationPayloads.publicAssets` | `boolean` | `true in premerged mode, false in source mode` | Salin payload ke output publik Nitro. Premerged → `\{page\}/\{locale\}/data.json` di bawah `apiBaseUrl`; source → pohon ringkas. Di Node, pohon ini juga menjadi sumber SSR saat `serverAssets` memaksa salinan publik. |
| `translationPayloads.prerenderRoutes` | `boolean` | `false` | Ikut serta ke Nitro-prerender `/\{apiBaseUrl\}/.../data.json`. Biasanya berlebihan saat premerged `publicAssets` sudah menulis file tersebut. |
| `translationPayloads.publicDir` | `string` | — | Folder output publik relatif terhadap root publik Nitro. Default ke `apiBaseUrl` (`_locales`). Sehingga file statis cocok dengan URL fetch klien (`/\{apiBaseUrl\}/\{page\}/\{locale\}/data.json`). |
| `translationPayloads.warnFileCount` | `number` | `500` | Peringatkan saat build ketika jumlah file payload yang dihasilkan melebihi ambang ini. |
| `translationPayloads.warnSizeBytes` | `number` | `10485760 (10 MB)` | Peringatkan saat build ketika total ukuran payload yang dihasilkan melebihi ambang ini dalam byte. |

## SEO

Tag meta yang dihasilkan untuk setiap halaman lokal.

| Opsi | Tipe | Default | Deskripsi |
| --- | --- | --- | --- |
| `meta` | `boolean` | `true` | Hasilkan tag meta SEO (`hreflang`, `canonical`, `og:url`, `og:locale`) secara otomatis. |
| `metaBaseUrl` | `string` | `undefined` | URL dasar untuk tag meta SEO (canonical, og:url, hreflang). - String URL konkret (misalnya `'https://example.com'`) — digunakan apa adanya (prioritas tertinggi). - `undefined` — kembali ke `site.url` dari `nuxt-site-config` saat modul tersebut hadir, jika tidak, asal permintaan saat ini (`useRequestURL().origin` di server, `window.location.origin` di klien). |
| `metaTrustForwardedHost` | `boolean` | `true` | Percayai header `X-Forwarded-Host` saat menyelesaikan URL dasar untuk tag meta. Aktifkan saat aplikasi berjalan di belakang reverse proxy (nginx, Cloudflare, AWS ALB, dll.) yang mengatur header ini ke hostname klien nyata. |
| `metaTrustForwardedProto` | `boolean` | `true` | Percayai header `X-Forwarded-Proto` saat menyelesaikan protokol untuk tag meta. Aktifkan saat aplikasi berjalan di belakang proxy penghenti TLS sehingga URL canonical menggunakan `https://` meskipun aplikasi itu sendiri mendengarkan HTTP. |
| `canonicalQueryWhitelist` | `string[]` | `['page', 'sort', 'filter', 'search', 'q', 'query', 'tag']` | Daftar nama parameter kueri yang dipertahankan dalam tag meta canonical dan `og:url`. Parameter yang tidak ada dalam daftar ini dihapus dari URL canonical. |

## Deteksi dan pengalihan

Memilih lokal untuk pengunjung yang belum memilih.

| Opsi | Tipe | Default | Deskripsi |
| --- | --- | --- | --- |
| `redirects` | `boolean` | `true` | Aktifkan pengalihan otomatis berbasis lokal. Saat `true`, pengunjung dialihkan ke lokal pilihan mereka (dideteksi dari cookie, header `Accept-Language`, atau default) pada kunjungan pertama. |
| `autoDetectLanguage` | `boolean` | `true` | Deteksi otomatis bahasa pilihan pengguna dari header HTTP `Accept-Language`. Digunakan bersama dengan `autoDetectPath` untuk menentukan kapan deteksi terjadi. |
| `autoDetectPath` | `string` | `'/'` | Tempat pengalihan preferensi cookie / Accept-Language dapat berjalan (saat `redirects` diaktifkan). - `'/'` — hanya `/` (deep link di lokal default tetap dapat dijangkau; default) - `'no_prefix'` — hanya jalur tanpa awalan lokal - `'*'` — setiap jalur, termasuk menulis ulang awalan lokal eksplisit (misalnya `/fr/about` → `/de/about` saat cookie lebih memilih `de`) - string lainnya — kecocokan jalur persis (misalnya `'/welcome'`) Pembersihan strategi awalan (misalnya `/en` → `/` di bawah `prefix_except_default`) tidak dikontrol. |

| `datetimeFormats` | `Record<string, Record<string, Intl.DateTimeFormatOptions>>` | — | Format datetime bernama per lokal (kompatibel Vue I18n `datetimeFormats`). Mengaktifkan panggilan gaya `$td(date, 'short')`. |
| `httpCacheDuration` | `number` | `31536000` | HTTP `Cache-Control` max-age (detik) untuk `/\{apiBaseUrl\}/:page/:locale/data.json`.
