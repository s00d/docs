Halaman ini mencantumkan setiap kunci dari objek `i18n` di `nuxt.config`. Gunakan tabel untuk mencari tipe atau nilai default, dan detail di bawahnya untuk contoh serta hal-hal yang perlu diperhatikan. Tipe, nilai default, dan deskripsi dihasilkan dari interface `ModuleOptions` di [`packages/types/src/index.ts`](https://github.com/s00d/nuxt-i18n-micro/blob/main/packages/types/src/index.ts).

```ts nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', displayName: 'English' },
      { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
  },
})
```

Opsi bersarang ditampilkan dengan path bertitiknya: `translationPayloads.mode` adalah kunci `mode` dari `translationPayloads`.

## Locale dan routing {#locales-and-routing}

Bahasa apa saja yang ada dan bagaimana bahasa tersebut muncul di URL.

| Opsi | Tipe | Default | Deskripsi |
| --- | --- | --- | --- |
| `locales` | `Locale[]` | `[]` | Daftar locale yang didukung. Setiap entri mendefinisikan kode locale beserta metadata opsional (ISO, arah teks, nama tampilan, dll.). |
| `strategy` | `Strategies` | `'prefix_except_default'` | Strategi routing URL untuk prefiks locale. - `'no_prefix'` — tidak ada locale di URL; locale disimpan di cookie. - `'prefix_except_default'` — beri prefiks pada semua locale kecuali default. - `'prefix'` — selalu beri prefiks, termasuk locale default. - `'prefix_and_default'` — seperti `prefix`, tetapi locale default juga dapat diakses tanpa prefiks. |
| `defaultLocale` | `string` | `'en'` | Locale yang digunakan ketika tidak ada locale yang dapat ditentukan dari URL atau preferensi pengguna. Ini bukan fallback terjemahan: tetapkan `fallbackLocale` untuk itu. |
| `localeCookie` | `string \| null` | `null` | Nama cookie untuk menyimpan preferensi locale pengguna di berbagai sesi. Tetapkan ke `null` untuk menonaktifkan penyimpanan berbasis cookie. Otomatis ditetapkan ke `'user-locale'` untuk strategi `no_prefix` jika tidak diberikan; `null` eksplisit di blok konfigurasi `i18n` juga tetap menonaktifkannya di sana. |
| `globalLocaleRoutes` | `GlobalLocaleRoutes` | `{}` | Konfigurasi locale global di tingkat rute. Memungkinkan pembatasan atau kustomisasi rute locale untuk halaman tertentu tanpa mengubah komponennya. - `false` — kecualikan rute dari lokalisasi. - `Record<LocaleCode, string>` — path kustom per locale. |
| `customRegexMatcher` | `string \| RegExp` | `undefined (uses built-in pattern based on locale codes)` | Ekspresi reguler kustom (atau sumber string-nya) untuk mencocokkan kode locale di segmen URL. Setiap kode locale di `locales` harus cocok dengan seluruh pola, tanpa flag-nya, atau build akan gagal. |
| `noPrefixRedirect` | `boolean` | `false` | Untuk strategi `no_prefix`: ketika locale default memiliki path kustom untuk sebuah halaman (`localeRoutes` / `globalLocaleRoutes`), redirect path asli halaman ke path kustom locale pengunjung, atau ke milik locale default jika tidak ada (misalnya `/about` → `/about-us`). Locale tanpa path kustom sendiri tetap di path asli. Halaman dengan segmen dinamis tidak di-redirect. |
| `excludePatterns` | `(string \| RegExp)[]` | `undefined` | Path yang dikecualikan dari routing i18n: string adalah prefiks path (`/admin` mencakup `/admin/x`) atau glob `*` / `?`; RegExp diuji terhadap path. Halaman yang cocok tidak mendapatkan varian locale, redirect locale, maupun 404, dan dihapus dari prerender; halaman tersebut tetap dirender dengan terjemahan. `/api`, `/_nuxt`, `/__*`, rute terjemahan, dan file statis umum (sitemap, robots.txt, favicon, aset berdasarkan ekstensi) selalu dikecualikan. |
| `routeLocales` | `Record<string, string[]>` | — | Pembatasan locale per rute, diekstrak saat build dari pemanggilan `$defineI18nRoute()`. Memetakan path rute (misalnya `'/about'`) ke array kode locale yang diizinkan. Rute yang tidak tercantum tidak memiliki pembatasan (semua locale diizinkan). |

## Terjemahan {#translations}

Lokasi file terjemahan dan cara kunci di-resolve.

| Opsi | Tipe | Default | Deskripsi |
| --- | --- | --- | --- |
| `translationDir` | `string` | `'locales'` | Path ke direktori yang berisi file JSON terjemahan, relatif terhadap root proyek. |
| `disableWatcher` | `boolean` | `false` | Menonaktifkan file watcher yang otomatis membuat file terjemahan yang hilang di mode development. |
| `routesLocaleLinks` | `{ [key: string]: string }` | `{}` | Memetakan nama rute ke nama rute lain untuk berbagi file terjemahan yang sama. Misalnya, `{ 'about-us': 'about' }` berarti halaman `about-us` akan menggunakan terjemahan dari halaman `about` alih-alih miliknya sendiri. |
| `plural` | `PluralFunc` | ``built-in pluralization (a non-negative integer count picks the form at that index, clamped to the last; negative, fractional and `NaN` counts take the last; `=0 ` opens a template of `Intl.PluralRules` categories)`` | Fungsi pluralisasi kustom. Menerima `(key, count, params, locale, getter)` dan harus mengembalikan bentuk plural yang dipilih sebagai string, atau `null`/`undefined` untuk kembali ke logika bawaan `defaultPlural` (sehingga Anda dapat meng-override hanya sebagian locale). Untuk modul Nuxt, fungsi ini diserialisasi dengan `.toString()` ke `.nuxt/i18n.plural.mjs` — fungsi harus mandiri (tanpa import / scope luar). String path file **tidak** didukung. |
| `disablePageLocales` | `boolean` | `false` | Menonaktifkan file terjemahan per halaman. Jika `true`, hanya terjemahan global (`{locale}.json`) yang dimuat; file khusus halaman (`pages/{page}/{locale}.json`) tidak dihasilkan maupun dimuat. |
| `fallbackLocale` | `string` | `undefined (no fallback; returns the raw key)` | Kode locale fallback global. Kunci yang hilang di sebuah locale diambil dari locale ini (digabungkan ke setiap payload saat di-build atau dimuat); tanpanya, kunci yang hilang dirender sebagai kunci itu sendiri. |

## Payload dan caching {#payloads-and-caching}

Bagaimana terjemahan sampai ke browser. [Performa](/id/guide/performance) menjelaskan apa yang diubah oleh opsi-opsi ini saat runtime.

| Opsi | Tipe | Default | Deskripsi |
| --- | --- | --- | --- |
| `serverTranslationPreload` | `boolean` | `false` | Memuat lebih awal terjemahan halaman index di middleware global Nitro (khusus server, konfigurasi privat). |
| `apiBaseUrl` | `string` | `'_locales'` | Segmen path URL dasar untuk rute API terjemahan (digunakan dalam pengambilan data SSR/SSG). Juga dapat diatur melalui variabel environment `NUXT_I18N_APP_BASE_URL`. |
| `apiBaseClientHost` | `string` | `undefined` | Meng-override host yang digunakan untuk permintaan fetch terjemahan di sisi klien. Berguna ketika klien menjangkau server melalui hostname yang berbeda dari yang dilihat Nuxt. Juga dapat diatur melalui variabel environment `NUXT_I18N_APP_BASE_CLIENT_HOST`. |
| `apiBaseServerHost` | `string` | `undefined` | Meng-override host yang digunakan untuk permintaan fetch terjemahan di sisi server. Berguna pada penyiapan container/microservice di mana server menjangkau dirinya sendiri melalui hostname internal. Juga dapat diatur melalui variabel environment `NUXT_I18N_APP_BASE_SERVER_HOST`. |
| `translationPayloads` | `TranslationPayloadOptions` | — | Mengontrol cara payload terjemahan dihasilkan (server Node: `public/<apiBaseUrl>`; Edge / function / inline: `serverAssets` Nitro). - **Server Node** (`node-server`, `node-cluster`, `serveStatic` disk): `serverAssets` berarti SSR lokal melalui `readFile` di bawah `public/` (tanpa Rollup `raw:`). - **Edge, preset function, dan `serveStatic: "inline"`** (`vercel`, `netlify`, `aws-lambda`, winterjs, …): `serverAssets` mendaftarkan `serverAssets` Nitro (`assets:i18n`), karena `public/` tidak tersedia di disk untuk SSR. Tidak memaksa salinan public — tetapkan `publicAssets: true` untuk CDN/statis. Pertahankan default untuk penyiapan all-in-one yang umum. Untuk katalog Edge yang besar, sebaiknya gunakan `mode: 'source'`. Untuk deployment berbasis CDN, nonaktifkan output lokal dan tetapkan `apiBaseClientHost` / `apiBaseServerHost`. |
| `translationPayloads.mode` | `'premerged' \| 'source'` | `'premerged'` | Strategi payload terjemahan. - `premerged`: matriks `{page}/{locale}/data.json` saat build (default) - `source`: file sumber ringkas yang digabungkan saat runtime (lebih disarankan di Edge / katalog besar) |
| `translationPayloads.serverAssets` | `boolean` | `true` | Payload SSR lokal: server Node yang menyajikan `public/` dari disk membaca pohon tersebut (memaksa salinan public); Edge, preset function, dan `serveStatic: "inline"` menyematkan melalui `serverAssets` Nitro. - **Server Node** (preset menyajikan `public/` sendiri, misalnya `node-server`): tanpa `serverAssets` Nitro (menghindari Rollup `raw:`). SSR membaca `public/<apiBaseUrl\|publicDir>` sebagai `{page}/{locale}/data.json`; jika ini `true`, salinan public dipaksakan meskipun `publicAssets` bernilai false. - **Edge, preset function, dan inline** (`nitro.node === false`, tanpa `serveStatic` disk seperti `vercel` / `netlify` / `aws-lambda`, atau `serveStatic: "inline"` misalnya winterjs): `serverAssets` Nitro (`assets:i18n`) dengan tata letak yang sama seperti `mode`. **Tidak** memaksa salinan public — tetapkan `publicAssets: true` untuk CDN/statis. |
| `translationPayloads.serverHandler` | `boolean` | `true` | Mendaftarkan rute server bawaan di `/{apiBaseUrl}/:page/:locale/data.json`. Nonaktifkan ini ketika payload terjemahan disajikan dari host/CDN eksternal. |
| `translationPayloads.publicAssets` | `boolean` | `true in premerged mode, false in source mode` | Menyalin payload ke output public Nitro. Premerged → `{page}/{locale}/data.json` di bawah `apiBaseUrl`; source → pohon ringkas. Ketika SSR membaca `public/` (`node-server` dan sejenisnya), `serverAssets: true` juga memaksa salinan ini. Pada preset Edge / function / `serveStatic: "inline"`, salin hanya jika ini `true` (SSR menggunakan embed Nitro). |
| `translationPayloads.prerenderRoutes` | `boolean` | `false` | Ikut serta dalam prerender Nitro untuk `/{apiBaseUrl}/.../data.json`. Biasanya tidak diperlukan ketika `publicAssets` premerged sudah menulis file-file tersebut. |
| `translationPayloads.publicDir` | `string` | — | Folder output public relatif terhadap root public Nitro. Default-nya `apiBaseUrl` (`_locales`). Dengan begitu, file statis sesuai dengan URL fetch klien (`/{apiBaseUrl}/{page}/{locale}/data.json`). |
| `translationPayloads.rootDelta` | `boolean` | `true` | Menulis satu file root per locale, dan di setiap file halaman hanya apa yang berbeda darinya. Klien dan SSR menggabungkannya; chunk utuh tetap berfungsi di mana pun file dibaca. `false` menyimpan kamus utuh di setiap file halaman. Hanya untuk `premerged`, dan nonaktif dengan `disablePageLocales`. |
| `translationPayloads.warnFileCount` | `number` | `500` | Memberi peringatan saat build ketika jumlah file payload yang dihasilkan melebihi ambang batas ini. |
| `translationPayloads.warnSizeBytes` | `number` | `10485760 (10 MB)` | Memberi peringatan saat build ketika total ukuran payload yang dihasilkan melebihi ambang batas ini dalam byte. |

## Deteksi dan redirect {#detection-and-redirects}

Memilih locale untuk pengunjung yang belum memilihnya.

| Opsi | Tipe | Default | Deskripsi |
| --- | --- | --- | --- |
| `redirects` | `boolean` | `true` | Mengaktifkan redirect locale otomatis (plugin server dan middleware rute klien). Jika `true`, strategi prefiks me-redirect URL tanpa prefiks ke bentuk yang dilokalkan. Locale berasal dari state aplikasi, cookie, atau `Accept-Language` di tempat yang diizinkan `autoDetectPath`, jika tidak, default. Di bawah `no_prefix`, deteksi tidak pernah mengubah URL (lihat `noPrefixRedirect` untuk path kustom). |
| `autoDetectLanguage` | `boolean` | `true` | Mendeteksi bahasa pilihan pengguna secara otomatis dari header HTTP `Accept-Language`. Digunakan bersama `autoDetectPath` untuk menentukan kapan deteksi terjadi. |
| `autoDetectPath` | `string` | `'/'` | Tempat redirect berdasarkan preferensi cookie / Accept-Language boleh dijalankan (ketika `redirects` diaktifkan). - `'/'` — hanya `/` (deep link di locale default tetap dapat dijangkau; default) - `'no_prefix'` — hanya path tanpa prefiks locale - `'*'` — setiap path, termasuk menulis ulang prefiks locale eksplisit (misalnya `/fr/about` → `/de/about` ketika cookie lebih memilih `de`) - string lainnya — path tersebut, garis miring di akhir diabaikan (misalnya `'/welcome'`) Di bawah `prefix`, URL tanpa prefiks di luar path yang diizinkan tetap di-redirect ke bentuk locale default (`/about` → `/en/about`). Locale default dengan prefiks di bawah `prefix_except_default` (`/en`) menghasilkan 404, bukan redirect. |

Tetapkan nilai stabil (SHA git, nomor build) untuk mematoknya sendiri. `NUXT_I18N_DATE_BUILD` atau `runtimeConfig.public.i18nRuntime.dateBuild` menggantikannya saat runtime, setelah kamus diganti di tempat: URL yang dipatok ditinggalkan, tanpa rebuild. |
| `experimental` | `Record<string, unknown>` | — | Wadah untuk opsi eksperimental/tidak stabil. Isinya dapat berubah atau dihapus tanpa pemberitahuan di antara versi minor. |

## Detail opsi {#option-details}

Opsi yang tidak memiliki tambahan informasi di luar tabel tidak diulang di sini.

### Locale dan URL {#locales-and-urls}

#### `locales` {#locales}

**Tipe** `Locale[]` · **Default** `[]`

Daftar locale yang didukung.
Setiap entri mendefinisikan kode locale beserta metadata opsional (ISO, arah teks, nama tampilan, dll.).

Setiap entri adalah objek `Locale`:

| Properti | Tipe | Deskripsi |
| --- | --- | --- |
| `code` | `string` | **Wajib.** Segmen URL dan nama file (`en`, `de-at`). |
| `iso` | `string` | Tag BCP-47 untuk `<html lang>`, `hreflang`, plural, dan `$tn` / `$td` / `$tdr` (`en-US`). |
| `displayName` | `string` | Label di `<i18n-switcher>` dan `$getLocaleName()`. |
| `dir` | `'ltr' \| 'rtl' \| 'auto'` | `<html dir>`. Tanpanya, bahasa RTL yang dikenal mendapatkan `rtl` dan setiap locale lain tidak mendapatkan atribut. Lihat [SEO](/id/guide/seo#text-direction). |
| `disabled` | `boolean` | Dikecualikan dari rute, payload, dan pergantian locale. Prefiksnya menghasilkan 404, dan tautan ke locale tersebut tetap berada di halaman. |
| `fallbackLocale` | `string` | Fallback untuk locale ini; meng-override `fallbackLocale` global. |
| `seo` | `boolean` | `false` mengecualikan locale dari `hreflang` dan `og:locale:alternate`. |
| `og` | `string` | Nilai `og:locale` (`ar_AE`); default: `iso` yang dikonversi. |
| `baseUrl` | `string` | Domain milik locale itu sendiri: satu build menyajikannya, dan tautan ke dalamnya dari domain lain bersifat absolut. |
| `baseDefault` | `boolean` | Dengan `baseUrl`: locale default dari host-nya, tanpa prefiks `/<code>` di tautan ke sana (`prefix` tetap mempertahankannya). |

Properti lainnya dipertahankan dan dikembalikan oleh `$getLocales()`. Beri tipe dengan melakukan augmentasi pada `Locale`:

```ts
// i18n.d.ts
declare module '@i18n-micro/types' {
  interface Locale {
    flag?: string
  }
}
export {}
```

Modul melakukan hoisting pada `@i18n-micro/types`, sehingga hal ini berfungsi di pnpm tanpa perlu menginstal paket tersebut.

#### `defaultLocale` {#defaultlocale}

**Tipe** `string` · **Default** `'en'`

Locale yang digunakan ketika tidak ada locale yang dapat ditentukan dari URL atau preferensi pengguna.
Ini bukan fallback terjemahan: tetapkan `fallbackLocale` untuk itu.

#### `strategy` {#strategy}

**Tipe** `Strategies` · **Default** `'prefix_except_default'`

Strategi routing URL untuk prefiks locale.

- `'no_prefix'` — tidak ada locale di URL; locale disimpan di cookie.
- `'prefix_except_default'` — beri prefiks pada semua locale kecuali default.
- `'prefix'` — selalu beri prefiks, termasuk locale default.
- `'prefix_and_default'` — seperti `prefix`, tetapi locale default juga dapat diakses tanpa prefiks.

URL per strategi dan redirect: [Strategi routing](/id/guide/strategy).

#### `globalLocaleRoutes` {#globallocaleroutes}

**Tipe** `GlobalLocaleRoutes` · **Default** `{}`

Konfigurasi locale global di tingkat rute.
Memungkinkan pembatasan atau kustomisasi rute locale untuk halaman tertentu tanpa
mengubah komponennya.

- `false` — kecualikan rute dari lokalisasi.
- `Record<LocaleCode, string>` — path kustom per locale.

Kuncinya adalah nama rute atau path. Biasanya ditetapkan per halaman dengan [`$defineI18nRoute`](/id/guide/per-component-translations).

```ts
globalLocaleRoutes: {
  about: { en: '/about-us', de: '/ueber-uns' },
  'admin-dashboard': false, // not localized
}
```

Detail, segmen dinamis, dan rute `pages:extend`: [Path yang dilokalkan](/id/guide/custom-locale-routes).

#### `routeLocales` {#routelocales}

**Tipe** `Record<string, string[]>` · **Default** —

Pembatasan locale per rute, diekstrak saat build dari pemanggilan `$defineI18nRoute()`.
Memetakan path rute (misalnya `'/about'`) ke array kode locale yang diizinkan.
Rute yang tidak tercantum tidak memiliki pembatasan (semua locale diizinkan).

#### `routeDisableMeta` {#routedisablemeta}

**Tipe** `Record<string, boolean \| string[]>` · **Default** —

Penonaktifan meta tag per rute. Memetakan nama atau path rute ke `true` (nonaktifkan semua meta) atau array
kode locale yang meta-nya harus dinonaktifkan. Entri yang ditemukan dalam pemanggilan `$defineI18nRoute()`
saat build ditambahkan ke dalamnya.

#### `customRegexMatcher` {#customregexmatcher}

**Tipe** `string \| RegExp` · **Default** `undefined (uses built-in pattern based on locale codes)`

Ekspresi reguler kustom (atau sumber string-nya) untuk mencocokkan kode locale di segmen URL.
Setiap kode locale di `locales` harus cocok dengan seluruh pola, tanpa flag-nya, atau build akan gagal.

```ts
customRegexMatcher: '[a-z]{2}-[a-z]{2}', // en-us, de-at
```

#### `excludePatterns` {#excludepatterns}

**Tipe** `(string \| RegExp)[]` · **Default** `undefined`

Path yang dikecualikan dari routing i18n: string adalah prefiks path (`/admin` mencakup `/admin/x`)
atau glob `*` / `?`; RegExp diuji terhadap path. Halaman yang cocok tidak mendapatkan varian
locale, redirect locale, maupun 404, dan dihapus dari prerender; halaman tersebut tetap dirender dengan
terjemahan. `/api`, `/_nuxt`, `/__*`, rute terjemahan, dan file statis umum
(sitemap, robots.txt, favicon, aset berdasarkan ekstensi) selalu dikecualikan.

```ts
excludePatterns: ['/admin', '/docs/*', /^\/preview\//],
```

Selengkapnya: [Mengecualikan path](/id/guide/excluding-static-files).

#### `localizedRouteNamePrefix` {#localizedroutenameprefix}

**Tipe** `string` · **Default** `'localized-'`

Prefiks yang ditambahkan di depan nama rute yang dilokalkan (misalnya `'localized-index'`).
Digunakan secara internal untuk membedakan rute asli dari varian locale yang dihasilkan.

#### `trailingSlash` {#trailingslash}

**Tipe** `'append' \| 'remove'` · **Default** `undefined (inherit from Nuxt)`

Garis miring di akhir untuk `$localePath` / `$switchLocalePath` (setara dengan NuxtLink).
Default-nya `experimental.defaults.nuxtLink.trailingSlash` jika tidak diatur.
Tetapkan secara eksplisit untuk meng-override default tautan Nuxt bagi helper path i18n.

### Terjemahan {#translations}

#### `translationDir` {#translationdir}

**Tipe** `string` · **Default** `'locales'`

Path ke direktori yang berisi file JSON terjemahan, relatif terhadap root proyek.

Relatif terhadap root setiap layer, bukan terhadap `app/` (`'app/locales'` untuk tata letak Nuxt 4). Tata letak file: [File terjemahan](/id/guide/translations).

#### `additionalTranslationDirs` {#additionaltranslationdirs}

**Tipe** `string[]` · **Default** `[]`

Direktori tambahan (relatif terhadap root proyek / root setiap layer Nuxt) yang file
`{locale}.json` tingkat atasnya di-deep-merge ke kamus global sebelum `translationDir`.

Urutan penggabungan: setiap entri sesuai urutan array (lintas layer), lalu `translationDir` (menang saat terjadi konflik).
Hanya file root `{locale}.json` yang dibaca — `pages/` di bawah direktori ini diabaikan.

Contoh: `translationDir: 'frontend'`, `additionalTranslationDirs: ['common']` → `common/en.json` lalu `frontend/en.json`.

#### `disablePageLocales` {#disablepagelocales}

**Tipe** `boolean` · **Default** `false`

Menonaktifkan file terjemahan per halaman.
Jika `true`, hanya terjemahan global (`{locale}.json`) yang dimuat;
file khusus halaman (`pages/{page}/{locale}.json`) tidak dihasilkan maupun dimuat.

#### `fallbackLocale` {#fallbacklocale}

**Tipe** `string` · **Default** `undefined (no fallback; returns the raw key)`

Kode locale fallback global.
Kunci yang hilang di sebuah locale diambil dari locale ini (digabungkan ke setiap payload saat
di-build atau dimuat); tanpanya, kunci yang hilang dirender sebagai kunci itu sendiri.

#### `routesLocaleLinks` {#routeslocalelinks}

**Tipe** `{ [key: string]: string }` · **Default** `{}`

Memetakan nama rute ke nama rute lain untuk berbagi file terjemahan yang sama.
Misalnya, `{ 'about-us': 'about' }` berarti halaman `about-us` akan menggunakan
terjemahan dari halaman `about` alih-alih miliknya sendiri.

```ts
routesLocaleLinks: { 'products-id': 'products' },
```

#### `plural` {#plural}

**Tipe** `PluralFunc` · **Default** ``built-in pluralization (a non-negative integer count picks the form at that index, clamped to the last; negative, fractional and `NaN` counts take the last; `=0 ` opens a template of `Intl.PluralRules` categories)``

Fungsi pluralisasi kustom.
Menerima `(key, count, params, locale, getter)` dan harus mengembalikan bentuk
plural yang dipilih sebagai string, atau `null`/`undefined` untuk kembali ke logika bawaan
`defaultPlural` (sehingga Anda dapat meng-override hanya sebagian locale).

Untuk modul Nuxt, fungsi ini diserialisasi dengan `.toString()` ke
`.nuxt/i18n.plural.mjs` — fungsi harus mandiri (tanpa import / scope luar).
String path file **tidak** didukung.

Aturan bawaan dan penanda `=0 ` dijelaskan di [`$tc`](/id/api/methods#$tc). Fungsi Anda menggantikannya untuk apa yang dijawabnya, menerima nilai mentah dengan penanda apa pun tetap di tempatnya, dan `null` mengembalikan pemanggilan ke aturan bawaan. Fungsi menerima `(key, count, params, locale, getter)`; `getter(key)` mengembalikan string mentah dengan semua bentuknya. Tulis sebagai ekspresi `function` atau arrow yang mandiri (tanpa method shorthand, tanpa import, tanpa variabel luar):

```ts
plural: function (key, count, params, locale, getter) {
  if (!locale.startsWith('en')) return null // built-in rule for other locales
  const forms = String(getter(key) ?? '').split('|').map((form) => form.trim())
  const index = count === 0 ? 0 : count === 1 ? 1 : 2
  return (forms[Math.min(index, forms.length - 1)] ?? '').replace('{count}', String(count))
},
```

```json
{ "apples": "no apples | one apple | {count} apples" }
```

#### `numberFormats` {#numberformats}

**Tipe** `Record<string, Record<string, Intl.NumberFormatOptions>>` · **Default** —

Format angka bernama per locale (kompatibel dengan Vue I18n).
Memungkinkan pemanggilan bergaya `$tn(1000, 'currency')`.

Digunakan oleh [`$tn`](/id/api/methods#$tn).

#### `datetimeFormats` {#datetimeformats}

**Tipe** `Record<string, Record<string, Intl.DateTimeFormatOptions>>` · **Default** —

Format tanggal-waktu bernama per locale (`datetimeFormats` yang kompatibel dengan Vue I18n).
Memungkinkan pemanggilan bergaya `$td(date, 'short')`.

Digunakan oleh [`$td`](/id/api/methods#$td).

#### `timeZone` {#timezone}

**Tipe** `string` · **Default** `the runtime's zone`

Zona waktu IANA untuk `$td` dan `<i18n-t date>` (`Europe/Berlin`). Tetapkan agar satu tanggal dirender sama di
server dan di setiap browser; `timeZone` milik format bernama lebih diutamakan.

#### `disableWatcher` {#disablewatcher}

**Tipe** `boolean` · **Default** `false`

Menonaktifkan file watcher yang otomatis membuat file terjemahan yang hilang di mode development.

#### `missingWarn` {#missingwarn}

**Tipe** `boolean` · **Default** `true`

Menampilkan peringatan console ketika kunci terjemahan hilang (build development, di browser).

Untuk melaporkan kunci yang hilang, gunakan [`$setMissingHandler`](/id/api/methods#$setmissinghandler).

### Payload dan caching {#payloads-and-caching}

#### `translationPayloads` {#translationpayloads}

**Tipe** `TranslationPayloadOptions` · **Default** —

Mengontrol cara payload terjemahan dihasilkan (server Node: `public/<apiBaseUrl>`; Edge / function / inline: `serverAssets` Nitro).

- **Server Node** (`node-server`, `node-cluster`, `serveStatic` disk): `serverAssets` berarti SSR lokal melalui `readFile` di bawah `public/` (tanpa Rollup `raw:`).
- **Edge, preset function, dan `serveStatic: "inline"`** (`vercel`, `netlify`, `aws-lambda`, winterjs, …): `serverAssets` mendaftarkan `serverAssets` Nitro (`assets:i18n`),
  karena `public/` tidak tersedia di disk untuk SSR. Tidak memaksa salinan public — tetapkan `publicAssets: true` untuk CDN/statis.

Pertahankan default untuk penyiapan all-in-one yang umum. Untuk katalog Edge yang besar, sebaiknya gunakan `mode: 'source'`.
Untuk deployment berbasis CDN, nonaktifkan output lokal dan tetapkan `apiBaseClientHost` / `apiBaseServerHost`.

Sub-opsi ada di tabel [Payload dan caching](#payloads-and-caching). Kombinasi mana yang cocok untuk Node, serverless, Edge, hosting statis, atau CDN: [Deployment](/id/guide/deployment).

#### `apiBaseUrl` {#apibaseurl}

**Tipe** `string` · **Default** `'_locales'`

Segmen path URL dasar untuk rute API terjemahan (digunakan dalam pengambilan data SSR/SSG).
Juga dapat diatur melalui variabel environment `NUXT_I18N_APP_BASE_URL`.

URL payload berbentuk `/{apiBaseUrl}/{page}/{locale}/data.json`.

#### `apiBaseClientHost` {#apibaseclienthost}

**Tipe** `string` · **Default** `undefined`

Meng-override host yang digunakan untuk permintaan fetch terjemahan di sisi klien.
Berguna ketika klien menjangkau server melalui hostname yang berbeda dari yang dilihat Nuxt.
Juga dapat diatur melalui variabel environment `NUXT_I18N_APP_BASE_CLIENT_HOST`.

#### `apiBaseServerHost` {#apibaseserverhost}

**Tipe** `string` · **Default** `undefined`

Meng-override host yang digunakan untuk permintaan fetch terjemahan di sisi server.
Berguna pada penyiapan container/microservice di mana server menjangkau dirinya sendiri melalui hostname internal.
Juga dapat diatur melalui variabel environment `NUXT_I18N_APP_BASE_SERVER_HOST`.

Host harus menyajikan respons `/{apiBaseUrl}/{page}/{locale}/data.json` yang sama dengan rute bawaan.

#### `dateBuild` {#datebuild}

**Tipe** `string \| number` · **Default** —

Nilai yang digunakan untuk cache-busting permintaan terjemahan (`?v=...`).

Jika tidak diberikan, modul menggunakan hash dari file terjemahan, sehingga nilainya berubah
hanya ketika terjemahan berubah (`Date.now()` jika hash tidak dapat dihitung). `0` atau `''` menonaktifkan
cache-busting. Tetapkan nilai stabil (SHA git, nomor build) untuk mematoknya sendiri.
`NUXT_I18N_DATE_BUILD` atau `runtimeConfig.public.i18nRuntime.dateBuild` menggantikannya saat runtime, setelah kamus
diganti di tempat: URL yang dipatok ditinggalkan, tanpa rebuild.

#### `httpCacheDuration` {#httpcacheduration}

**Tipe** `number` · **Default** `31536000`

max-age HTTP `Cache-Control` (detik) untuk `/{apiBaseUrl}/:page/:locale/data.json`.

Berlaku sepenuhnya hanya selama `dateBuild` melakukan cache-busting pada URL (`?v=...`), yang merupakan default:
respons kemudian menjadi `private, max-age=…, immutable`: browser mematoknya, sedangkan CDN yang mengabaikan query tidak dapat melakukannya
(`public` dengan `httpCacheControl: false`).

- `dateBuild: 0`/`''` — URL stabil, sehingga durasi ini *tidak* dipatuhi;
  respons menjadi `public, max-age=0, must-revalidate` sebagai gantinya. `max-age` yang panjang pada
  URL yang tidak berubah akan mematok payload pertama yang pernah dilihat browser.

- `0` — tidak mengatur `Cache-Control` sama sekali (berguna untuk debugging lokal)
- Tidak diterapkan di mode development (`import.meta.dev`) agar HMR tidak terhalang oleh cache browser
- Hanya berlaku untuk respons yang disajikan melalui Nitro. Payload yang disalin ke `public/` dan disajikan
  oleh platform hosting mengikuti header platform tersebut — lihat panduan Performa.

Analog dengan `httpCacheDuration` eksperimental di `@nuxtjs/i18n` (v10.2.0), tetapi sebagai
header respons eksplisit alih-alih maxAge `defineCachedEventHandler` Nitro.

#### `cacheMaxSize` {#cachemaxsize}

**Tipe** `number` · **Default** `0`

Jumlah maksimum entri di cache terjemahan dalam memori. Cache fetch dan server
membuang entri yang paling lama tidak digunakan; map kamus browser membuang entri tertua (FIFO).
`0` berarti tanpa batas di browser; cache server menyimpan paling banyak 1000 entri dalam kasus ini, sehingga URL
permintaan yang menyebut halaman karangan tidak dapat memperbesar memori server.

#### `cacheTtl` {#cachettl}

**Tipe** `number` · **Default** `0`

Time-to-live (dalam detik) dari cache terjemahan fetch dan server, dihitung sejak
entri disimpan (pembacaan tidak memperpanjangnya), sehingga data dari `apiBaseServerHost` disegarkan
setidaknya sesering itu. Kamus aktif di browser tidak kedaluwarsa karenanya. `0` berarti entri
tidak pernah kedaluwarsa.

Apa yang diubah keduanya saat runtime: [Performa](/id/guide/performance).

#### `serverTranslationPreload` {#servertranslationpreload}

**Tipe** `boolean` · **Default** `false`

Memuat lebih awal terjemahan halaman index di middleware global Nitro (khusus server, konfigurasi privat).

### SEO {#seo}

#### `meta` {#meta}

**Tipe** `boolean` · **Default** `true`

Menghasilkan meta tag SEO (`hreflang`, `canonical`, `og:url`, `og:locale`) secara otomatis.

Override per halaman: [`useI18nHead`](/id/composables/useI18nHead). Selebihnya: [SEO](/id/guide/seo).

#### `metaBaseUrl` {#metabaseurl}

**Tipe** `string` · **Default** `undefined`

URL dasar untuk meta tag SEO (canonical, og:url, hreflang).

- String URL konkret (misalnya `'https://example.com'`) — digunakan apa adanya (prioritas tertinggi).
- `undefined` — kembali ke `site.url` dari `nuxt-site-config` jika modul tersebut
  ada, jika tidak, origin permintaan saat ini
  (`useRequestURL().origin` di server, `window.location.origin` di klien).

#### `metaTrustForwardedHost` {#metatrustforwardedhost}

**Tipe** `boolean` · **Default** `true`

Memercayai header `X-Forwarded-Host` saat menentukan URL dasar untuk meta tag.
Aktifkan ketika aplikasi berjalan di belakang reverse proxy (nginx, Cloudflare, AWS ALB, dll.)
yang mengatur header ini ke hostname sebenarnya yang dilihat klien.

Hanya dibaca ketika `metaBaseUrl` maupun `site.url` tidak diatur. Tetapkan ke `false` ketika aplikasi dapat dijangkau tanpa proxy yang menimpa header tersebut: jika tidak, klien dapat memilih host di URL canonical Anda.

#### `metaTrustForwardedProto` {#metatrustforwardedproto}

**Tipe** `boolean` · **Default** `true`

Memercayai header `X-Forwarded-Proto` saat menentukan protokol untuk meta tag.
Aktifkan ketika aplikasi berjalan di belakang proxy yang melakukan terminasi TLS agar
URL canonical menggunakan `https://` meskipun aplikasi itu sendiri mendengarkan di HTTP.

Cakupannya sama dengan `metaTrustForwardedHost`.

#### `trustForwardedHost` {#trustforwardedhost}

**Tipe** `boolean` · **Default** `false`

Memilih domain sebuah permintaan (`locales[].baseUrl`) dari `X-Forwarded-Host` alih-alih
`Host`. Aktifkan hanya di belakang proxy yang menimpa header tersebut.

Terpisah dari `metaTrustForwardedHost` dan nonaktif secara default: di sini header akan memilih locale milik domain lain, bukan hanya origin sebuah tag. Lihat [Layer dan domain](/id/guide/layers#multiple-domains).

#### `hreflangBaseLanguage` {#hreflangbaselanguage}

**Tipe** `boolean` · **Default** `false`

Juga menghasilkan `hreflang` bahasa dasar yang diturunkan dari `iso` setiap locale
(misalnya `es-ES` → juga `es`). Locale regional pertama di `locales` mengklaim
tag dasar untuk bahasa tersebut. `code` routing tidak pernah digunakan — hanya `iso || code`.

#### `canonicalQueryWhitelist` {#canonicalquerywhitelist}

**Tipe** `string[]` · **Default** `['page', 'sort', 'filter', 'search', 'q', 'query', 'tag']`

Daftar nama parameter query yang dipertahankan di meta tag canonical dan `og:url`.
Parameter yang tidak ada di daftar ini dihapus dari URL canonical.

### Deteksi dan redirect {#detection-and-redirects}

Aturan yang dipengaruhi opsi-opsi ini: [Deteksi locale](/id/guide/locale-detection).

#### `redirects` {#redirects}

**Tipe** `boolean` · **Default** `true`

Mengaktifkan redirect locale otomatis (plugin server dan middleware rute klien).
Jika `true`, strategi prefiks me-redirect URL tanpa prefiks ke bentuk yang dilokalkan. Locale
berasal dari state aplikasi, cookie, atau `Accept-Language` di tempat yang diizinkan `autoDetectPath`, jika tidak,
default. Di bawah `no_prefix`, deteksi tidak pernah mengubah URL (lihat `noPrefixRedirect` untuk path kustom).

Dengan `false`, middleware redirect klien tidak didaftarkan. Plugin server tetap mengembalikan 404 untuk URL locale yang tidak valid dan menulis cookie untuk URL berprefiks.

#### `autoDetectLanguage` {#autodetectlanguage}

**Tipe** `boolean` · **Default** `true`

Mendeteksi bahasa pilihan pengguna secara otomatis dari header HTTP `Accept-Language`.
Digunakan bersama `autoDetectPath` untuk menentukan kapan deteksi terjadi.

#### `autoDetectPath` {#autodetectpath}

**Tipe** `string` · **Default** `'/'`

Tempat redirect berdasarkan preferensi cookie / Accept-Language boleh dijalankan (ketika `redirects` diaktifkan).

- `'/'` — hanya `/` (deep link di locale default tetap dapat dijangkau; default)
- `'no_prefix'` — hanya path tanpa prefiks locale
- `'*'` — setiap path, termasuk menulis ulang prefiks locale eksplisit
  (misalnya `/fr/about` → `/de/about` ketika cookie lebih memilih `de`)

- string lainnya — path tersebut, garis miring di akhir diabaikan (misalnya `'/welcome'`)

Di bawah `prefix`, URL tanpa prefiks di luar path yang diizinkan tetap di-redirect ke bentuk
locale default (`/about` → `/en/about`). Locale default dengan prefiks di bawah
`prefix_except_default` (`/en`) menghasilkan 404, bukan redirect.

#### `localeCookie` {#localecookie}

**Tipe** `string \| null` · **Default** `null`

Nama cookie untuk menyimpan preferensi locale pengguna di berbagai sesi.
Tetapkan ke `null` untuk menonaktifkan penyimpanan berbasis cookie.
Otomatis ditetapkan ke `'user-locale'` untuk strategi `no_prefix` jika tidak diberikan; `null`
eksplisit di blok konfigurasi `i18n` juga tetap menonaktifkannya di sana.

Tanpa cookie, `Accept-Language` tetap menentukan redirect; cookie mengingat pilihan di setiap kunjungan.

#### `noPrefixRedirect` {#noprefixredirect}

**Tipe** `boolean` · **Default** `false`

Untuk strategi `no_prefix`: ketika locale default memiliki path kustom untuk sebuah halaman
(`localeRoutes` / `globalLocaleRoutes`), redirect path asli halaman ke path kustom
locale pengunjung, atau ke milik locale default jika tidak ada (misalnya `/about` → `/about-us`).
Locale tanpa path kustom sendiri tetap di path asli. Halaman dengan segmen
dinamis tidak di-redirect.

Menghasilkan deklarasi tipe TypeScript untuk `useI18n`, `$t`, dan helper terkait
berdasarkan kunci terjemahan di file locale default Anda.

Terpisah dari paket [`@i18n-micro/types-generator`](/id/integrations/types-generator).

#### `hmr` {#hmr}

**Tipe** `boolean` · **Default** `true`

Mengaktifkan Hot Module Replacement untuk file terjemahan di mode development.
Jika `true`, perubahan pada file terjemahan JSON memicu pemuatan ulang otomatis
tanpa refresh halaman penuh.

#### `debug` {#debug}

**Tipe** `boolean` · **Default** `false`

Mengaktifkan logging debug yang detail untuk deteksi locale, pembuatan rute, dan pemuatan terjemahan.

#### `vueDevtools` {#vuedevtools}

**Tipe** `boolean` · **Default** `true`

Mendaftarkan inspector dan timeline Vue DevTools di mode dev (ekstensi browser).
Terpisah dari tab kustom Nuxt DevTools.

#### `experimental` {#experimental}

**Tipe** `Record<string, unknown>` · **Default** —

Wadah untuk opsi eksperimental/tidak stabil.
Isinya dapat berubah atau dihapus tanpa pemberitahuan di antara versi minor.
