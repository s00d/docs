# Referensi API

## API runtime

- [Metode](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, peralihan lokal, pembantu perutean
- [Event](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Terjemahan dan cache](/api/cache) — `TranslationStorage`, pemuatan payload, `$clearCache`

## Middleware server

Handler server menggunakan middleware khusus (bukan pembantu `$t` klien):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — terjemahkan di rute API dan handler server
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — baca lokal yang terdeteksi dan metadata

Lihat [Panduan terjemahan sisi server](/guides/server-side-translations) lengkap untuk pengaturan, prioritas deteksi lokal, dan contoh.
