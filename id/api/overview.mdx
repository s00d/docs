# Referensi API

## API Runtime

- [Method](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, peralihan lokal, helper perutean
- [Event](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Terjemahan dan Cache](/api/cache) — `TranslationStorage`, pemuatan payload, `$clearCache`

## Middleware server

Handler server menggunakan middleware khusus (bukan helper `$t` klien):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — menerjemahkan pada rute API dan handler server
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — membaca lokal yang terdeteksi dan metadatanya

Lihat [Panduan Terjemahan Sisi Server](/guides/server-side-translations) yang lengkap untuk pengaturan, prioritas deteksi lokal, dan contoh.
