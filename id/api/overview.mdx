Bagian ini mencantumkan setiap opsi, helper, hook, composable, dan komponen dari modul Nuxt, beserta API yang diekspor oleh setiap paket `@i18n-micro/*`. Gunakan bagian ini untuk mencari signature atau nilai default; [Panduan](/id/guide/getting-started) menjelaskan cara menggunakannya. Sebagian besar tabel di sini dihasilkan dari kode sumber, sehingga sesuai dengan kode.

## Modul Nuxt {#nuxt-module}

| Halaman | Cakupan |
| --- | --- |
| [Opsi modul](/id/api/module-options) | Setiap kunci `i18n` di `nuxt.config`, beserta tipe dan nilai default |
| [Helper](/id/api/methods) | `$t`, `$tc`, `$tn`, `$td`, `$localePath`, `$switchLocale`, `$defineI18nRoute`, dan lainnya |
| [Hook](/id/api/events) | Hook runtime `i18n:register` |

## Composable {#composables}

| Composable | Gunakan untuk |
| --- | --- |
| [`useI18n`](/id/composables/useI18n) | Helper di `<script setup>` |
| [`useI18nLocale`](/id/composables/useI18nLocale) | State locale dan cookie dalam plugin deteksi kustom |
| [`useI18nHead`](/id/composables/useI18nHead) | Override per halaman untuk tag SEO yang dihasilkan |
| [`useLocaleHead`](/id/composables/useLocaleHead) | Tag SEO sebagai objek, untuk `useHead` Anda sendiri |

## Komponen {#components}

| Komponen | Merender |
| --- | --- |
| [`<i18n-t>`](/id/components/i18n-t) | Satu terjemahan, dengan plural, pemformatan, dan interpolasi slot |
| [`<i18n-link>`](/id/components/i18n-link) | `NuxtLink` ke rute yang dilokalkan |
| [`<i18n-switcher>`](/id/components/i18n-switcher) | Dropdown locale |
| [`<i18n-group>`](/id/components/i18n-group) | Blok dengan prefiks kunci bersama |

## Server {#server}

Handler Nitro menggunakan `useTranslationServerMiddleware` dan `useLocaleServerMiddleware`, bukan helper klien. Lihat [Rute server](/id/guide/server-side-translations).

## Paket {#packages}

[API paket](/id/api/packages/overview) mencantumkan ekspor dari setiap paket `@i18n-micro/*`, masing-masing dengan satu halaman yang dihasilkan.
