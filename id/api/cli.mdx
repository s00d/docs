[Panduan CLI](/id/guide/cli) menunjukkan alur kerja yang umum. Halaman ini mencantumkan semuanya, dan dihasilkan dari tabel yang sama yang menggerakkan `--help`.

## Flag umum {#common-flags}

| Flag | Default | Deskripsi |
| --- | --- | --- |
| `--cwd` | direktori saat ini | Direktori proyek |
| `--logLevel` | `info` | Tingkat output: silent, info |
| `--debug` | `false` | Cetak stack trace ketika sebuah perintah gagal |

## Inspeksi {#inspect}

### `info` {#info}

Cetak konfigurasi i18n proyek yang sudah di-resolve

| Flag | Default | Deskripsi |
| --- | --- | --- |
| `--json` | `false` | Cetak JSON alih-alih teks |

### `check` {#check}

Gerbang CI: gagal pada kunci yang hilang, kosong, berlebih, tidak terdefinisi, atau tidak terpakai, serta placeholder yang rusak

| Flag | Default | Deskripsi |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` dari nuxt.config | Direktori terjemahan, relatif terhadap proyek |
| `--only` | semua kecuali duplicates | Pemeriksaan yang dijalankan, dipisahkan koma: missing, empty, extra, placeholders, undefined, unused, duplicates. `unused` yang disebut di sini akan gagal jika tidak dapat dijalankan |
| `--duplicates` | `false` | Laporkan juga teks yang sama di bawah kunci yang berbeda |
| `--ignore` | — | Glob file sumber yang dilewati, dipisahkan koma, relatif terhadap proyek |
| `--json` | `false` | Cetak JSON alih-alih teks |

```bash
i18n-micro check
i18n-micro check --only missing,placeholders --json
```

### `stats` {#stats}

Tampilkan tingkat kelengkapan terjemahan per locale

| Flag | Default | Deskripsi |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` dari nuxt.config | Direktori terjemahan, relatif terhadap proyek |
| `--html` | — | Tulis juga laporan HTML ke file ini |
| `--json` | `false` | Cetak JSON alih-alih teks |
| `--baseRef` | — | Ref Git sebagai pembanding kelengkapan, mis. HEAD~1 atau main |

```bash
i18n-micro stats --baseRef main
i18n-micro stats --html reports/i18n.html
```

### `lint` {#lint}

Periksa teks terjemahan; gagal jika masih ada masalah

| Flag | Default | Deskripsi |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` dari nuxt.config | Direktori terjemahan, relatif terhadap proyek |
| `--rules` | semua, atau `enabledRules` dari .i18n-lintrc.json | Aturan yang dijalankan, dipisahkan koma: no-trailing-spaces, no-multiple-spaces, no-empty-translation, atau aturan kustom |
| `--fix` | `false` | Perbaiki apa yang bisa diperbaiki: spasi, dan aturan kustom yang memiliki pengganti |
| `--json` | `false` | Cetak JSON alih-alih teks |

```bash
i18n-micro lint --rules no-trailing-spaces --fix
```

### `search` {#search}

Cari kunci dan nilai, dan tampilkan di mana setiap kunci digunakan

| Flag | Default | Deskripsi |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` dari nuxt.config | Direktori terjemahan, relatif terhadap proyek |
| `<query>` | — | Teks atau kunci yang dicari |
| `--caseSensitive` | `false` | Cocokkan huruf besar/kecil |
| `--onlyUnused` | `false` | Hanya kunci yang akan dihapus oleh `clean`; query menjadi opsional |
| `--scope` | `all` | Lokasi pencarian: global, pages, all |
| `--limit` | — | Kembalikan paling banyak sejumlah kunci ini |
| `--ignore` | — | Glob file sumber yang dilewati, dipisahkan koma, relatif terhadap proyek |
| `--json` | `false` | Cetak JSON alih-alih teks |

```bash
i18n-micro search "Welcome"
i18n-micro search --onlyUnused
```

## Alur kerja terjemahan {#translation-workflow}

### `extract` {#extract}

Daftar kunci yang digunakan file sumber tetapi belum memiliki teks, dan tambahkan kunci yang memiliki teks default ke locale default

| Flag | Default | Deskripsi |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` dari nuxt.config | Direktori terjemahan, relatif terhadap proyek |
| `--ignore` | — | Glob file sumber yang dilewati, dipisahkan koma, relatif terhadap proyek |

```bash
i18n-micro extract
```

### `translate` {#translate}

Isi terjemahan yang hilang dari locale default melalui layanan terjemahan

| Flag | Default | Deskripsi |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` dari nuxt.config | Direktori terjemahan, relatif terhadap proyek |
| `--service` | — | Layanan terjemahan: ai, azure, deepl, google, libretranslate, yandexcloud |
| `--token` | — | Kunci API. Sebaiknya gunakan variabel lingkungan I18N_TRANSLATE_TOKEN: flag akan tersimpan di riwayat shell |
| `--options` | — | Opsi layanan sebagai pasangan key:value, dipisahkan koma |
| `--locale` | setiap locale kecuali locale default | Locale yang diisi, dipisahkan koma |
| `--replace` | `false` | Terjemahkan ulang setiap kunci, menggantikan nilai yang sudah ada |
| `--dryRun` | `false` | Hitung kunci dan karakter per locale; tidak mengirim apa pun |
| `--chunkSize` | — | Jumlah string per permintaan; dibatasi sesuai yang diterima layanan |
| `--pluralSeparator` | `\|` | Pemisah bentuk jamak dalam pesan |
| `--glossaryFile` | `.i18n-glossary.json` jika ada | File glosarium, digunakan oleh layanan `ai` |

```bash
i18n-micro translate --dryRun
I18N_TRANSLATE_TOKEN=... i18n-micro translate --service deepl --locale de,fr
i18n-micro translate --service ai --options provider:openai,model:gpt-4o-mini
i18n-micro translate --service libretranslate --options baseUrl:https://translate.example.com
```

### `sync` {#sync}

Hapus kunci yang tidak dimiliki locale default; berhenti jika hal itu tidak dapat dibuktikan aman. Kunci yang hilang tetap hilang

| Flag | Default | Deskripsi |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` dari nuxt.config | Direktori terjemahan, relatif terhadap proyek |
| `--ignore` | — | Glob file sumber yang dilewati, dipisahkan koma, relatif terhadap proyek |
| `--dryRun` | `false` | Daftar apa yang akan dihapus; tidak menulis apa pun |
| `--force` | `false` | Hapus kunci meskipun tidak dapat dibuktikan aman |

```bash
i18n-micro sync --dryRun
```

### `clean` {#clean}

Hapus kunci yang tidak digunakan oleh apa pun di proyek; berhenti jika hal itu tidak dapat dibuktikan

| Flag | Default | Deskripsi |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` dari nuxt.config | Direktori terjemahan, relatif terhadap proyek |
| `--include` | — | Ekspresi reguler: hanya kunci yang cocok yang dipertimbangkan untuk dihapus |
| `--exclude` | — | Ekspresi reguler: jangan pernah menghapus kunci yang cocok |
| `--ignore` | — | Glob file sumber yang dilewati, dipisahkan koma, relatif terhadap proyek |
| `--dryRun` | `false` | Daftar apa yang akan dihapus; tidak menulis apa pun |
| `--force` | `false` | Hapus kunci meskipun penggunaannya tidak dapat dibuktikan untuk semuanya |

```bash
i18n-micro clean --dryRun
i18n-micro clean --exclude '^errors\.'
```

## Refactoring {#refactoring}

### `text-to-i18n` {#text-to-i18n}

Ganti teks hardcoded di template Vue dengan pemanggilan terjemahan, dan laporkan teks hardcoded di kode

| Flag | Default | Deskripsi |
| --- | --- | --- |
| `--translationFile` | `<translationDir>/<defaultLocale>.json` | File tujuan kunci baru |
| `--path` | seluruh proyek | File atau direktori yang diproses |
| `--context` | — | Prefiks untuk kunci yang dihasilkan |
| `--ignore` | — | Glob file sumber yang dilewati, dipisahkan koma, relatif terhadap proyek |
| `--dryRun` | `false` | Tampilkan apa yang akan berubah; tidak menulis apa pun |
| `--interactive` | `false` | Konfirmasi atau sunting setiap kunci yang dihasilkan |

```bash
i18n-micro text-to-i18n --dryRun
i18n-micro text-to-i18n --path components --context ui
```

### `rename` {#rename}

Ganti nama kunci atau namespace di setiap locale dan di file sumber

| Flag | Default | Deskripsi |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` dari nuxt.config | Direktori terjemahan, relatif terhadap proyek |
| `--from` **\*** | — | Kunci atau namespace saat ini |
| `--to` **\*** | — | Kunci atau namespace baru |
| `--ignore` | — | Glob file sumber yang dilewati, dipisahkan koma, relatif terhadap proyek |
| `--dryRun` | `false` | Laporkan perubahan; tidak menulis apa pun |

**\*** wajib.

```bash
i18n-micro rename --from common.save --to actions.save
```

### `pseudo` {#pseudo}

Isi sebuah locale dengan pseudo-terjemahan untuk menemukan masalah tata letak dan teks hardcoded

| Flag | Default | Deskripsi |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` dari nuxt.config | Direktori terjemahan, relatif terhadap proyek |
| `--sourceLocale` | locale default | Locale yang dibaca |
| `--targetLocale` **\*** | — | Locale yang diisi |
| `--replace` | `false` | Timpa nilai yang sudah ada |

**\*** wajib.

### `format` {#format}

Tulis ulang file locale dengan kunci terurut dan indentasi yang seragam

| Flag | Default | Deskripsi |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` dari nuxt.config | Direktori terjemahan, relatif terhadap proyek |
| `--indent` | `2` | Jumlah spasi indentasi |
| `--sortKeys` | `true` | Urutkan kunci; gunakan --no-sortKeys untuk mempertahankan urutannya |
| `--check` | `false` | Gagal jika sebuah file akan berubah; tidak menulis apa pun |

```bash
i18n-micro format --check
```

## Pertukaran {#exchange}

### `export` {#export}

Ekspor file locale ke PO atau CSV, dengan teks locale default sebagai sumber

| Flag | Default | Deskripsi |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` dari nuxt.config | Direktori terjemahan, relatif terhadap proyek |
| `--format` | `po` | Format file: po, csv |
| `--dir` | `pots` untuk po, `csv_exports` untuk csv | Direktori output, relatif terhadap proyek |
| `--force` | `false` | Timpa file yang berubah sejak ekspor terakhir dan belum pernah diimpor |

```bash
i18n-micro export --format csv
```

### `import` {#import}

Gabungkan file PO atau CSV ke dalam file locale

| Flag | Default | Deskripsi |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` dari nuxt.config | Direktori terjemahan, relatif terhadap proyek |
| `--format` | `po` | Format file: po, csv |
| `--dir` | `pots` untuk po, `csv_exports` untuk csv | Direktori input, relatif terhadap proyek |
| `--dryRun` | `false` | Laporkan apa yang akan diimpor; tidak menulis apa pun |

```bash
i18n-micro import --format csv --dryRun
```

### `sync-remote` {#sync-remote}

Tarik terjemahan global dari, atau dorong ke, endpoint HTTP di .i18n-remote.json

| Flag | Default | Deskripsi |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` dari nuxt.config | Direktori terjemahan, relatif terhadap proyek |
| `--pull` | `true` | Tarik dari remote |
| `--push` | `false` | Dorong ke remote |
| `--force` | `false` | Saat pull, ambil nilai remote; saat push, timpa teks yang hanya dimiliki remote |
| `--dryRun` | `false` | Laporkan apa yang akan diubah oleh pull; tidak menulis maupun mendorong apa pun |

```bash
i18n-micro sync-remote --dryRun
i18n-micro sync-remote --no-pull --push
```

## Aturan lint {#lint-rules}

| Aturan | Mendeteksi | Diperbaiki oleh `--fix` |
| --- | --- | --- |
| `no-trailing-spaces` | Spasi di akhir nilai atau baris | ya |
| `no-multiple-spaces` | Dua spasi atau lebih berturut-turut | ya |
| `no-empty-translation` | Nilai yang kosong atau hanya berisi spasi | tidak |

## Kode keluar {#exit-codes}

| Kode | Arti |
| --- | --- |
| `0` | Selesai, tidak ada yang dilaporkan |
| `1` | Temuan: `check`, `lint`, atau `format --check` menemukan sesuatu, `clean` atau `sync` tidak dapat membuktikan penghapusan aman, `export` akan menimpa pekerjaan yang belum diimpor, `translate` melewatkan kunci, `import` atau `sync-remote` menemui konflik, push `sync-remote` akan membuang teks remote. `--dryRun` dari `clean`, `sync`, atau pull `sync-remote` melaporkan hal ini dan keluar dengan `0` |
| `2` | Kegagalan: penggunaan salah, proyek tidak dapat dibaca, galat jaringan atau file |

## File konfigurasi {#configuration-files}

| File | Digunakan oleh |
| --- | --- |
| `.i18n-lintrc.json` | `lint`: `enabledRules`, `disabledRules`, `customRegexRules` (`name`, `pattern`, `flags`, `description`, `replacement`) |
| `.i18n-remote.json` | `sync-remote`: `url`, `path`, `token`, `auth` (`username`, `password`). `type` boleh dihilangkan; hanya `custom` yang ada |
| `.i18n-glossary.json` | `translate --service ai`: `entries` berisi `source`, `target`, serta `from`, `to` opsional |

## Variabel lingkungan {#environment-variables}

| Nama | Digunakan untuk |
| --- | --- |
| `I18N_TRANSLATE_TOKEN` | Kunci API untuk `translate`. Juga dibaca dari `.env` |
| `I18N_REMOTE_TOKEN` | Bearer token untuk `sync-remote`. Juga dibaca dari `.env` |
| `AI_GATEWAY_API_KEY, OPENAI_API_KEY, ANTHROPIC_API_KEY` | Kunci layanan `ai`, ketika `I18N_TRANSLATE_TOKEN` tidak diatur |
| `DEFAULT_LOCALE` | Menimpa `defaultLocale`, sama seperti di modul |
