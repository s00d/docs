`@i18n-micro/devtools-ui` adalah editor terjemahan dari tab Nuxt DevTools, dikemas sebagai web component dengan plugin Vite. Tambahkan ke proyek Vue, React, Preact, Solid, atau Astro untuk menelusuri dan menyunting file JSON di folder terjemahan Anda dari browser selama development. Aplikasi Nuxt sudah memilikinya di [Nuxt DevTools](/id/guide/devtools).

![DevTools UI: pohon file dan editor dengan teks locale default di samping setiap kunci](/images/devtools/02-translations-editor-dark.webp)

## Instalasi {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/devtools-ui
```

```bash npm
npm install -D @i18n-micro/devtools-ui
```

```bash yarn
yarn add -D @i18n-micro/devtools-ui
```

</CodeGroup>

Tidak ada peer dependency.

## Penyiapan {#setup}

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import { i18nDevToolsPlugin } from '@i18n-micro/devtools-ui/vite'

export default defineConfig({
  plugins: [i18nDevToolsPlugin({ translationDir: 'src/locales' })],
})
```

| Opsi | Default | Catatan |
| --- | --- | --- |
| `translationDir` | `'src/locales'` | Folder berisi file JSON, relatif terhadap root Vite. |
| `base` | `'/__i18n_api'` | Base path dari endpoint API. |
| `injectButton` | `true` | Tambahkan tombol mengambang ke halaman yang disajikan melalui transformasi `index.html` Vite. Astro tidak memiliki halaman seperti itu: lihat di bawah. |
| `defaultLocale` | file locale pertama di `translationDir` | Dilaporkan oleh `/config`. |
| `fallbackLocale` | `defaultLocale` | Dilaporkan oleh `/config`. |

Plugin hanya berjalan di dev server (`apply: 'serve'`); build produksi tidak berisi apa pun darinya. Tombol membuka `/__i18n_devtools.html`, yang membaca dan menyimpan file melalui endpoint plugin:

| Endpoint | Fungsi |
| --- | --- |
| `GET <base>/translations` | setiap kamus di bawah `translationDir`, berdasarkan path relatif |
| `POST <base>/save` | body `{ file, content }`; menimpa `.json` yang sudah ada di dalam `translationDir`, 403 untuk hal lainnya. Tidak pernah membuat file |
| `GET <base>/config` | `{ defaultLocale, fallbackLocale, locales, translationDir }`; `locales` berasal dari file root di `translationDir` |

Endpoint hanya melayani halaman devtools: permintaan dari origin atau host lain mendapat `403`, dan `/save` hanya menerima `application/json` (`415`). Halaman mengetahui perubahan file melalui socket HMR Vite.

Di Astro, tambahkan integrasi alih-alih plugin. Integrasi ini menambahkan aplikasi ke dev toolbar:

```ts
// astro.config.mjs
import { defineConfig } from 'astro/config'
import { i18nDevToolsIntegration } from '@i18n-micro/devtools-ui/vite'

export default defineConfig({
  integrations: [i18nDevToolsIntegration({ translationDir: 'src/locales' })],
})
```

Menyimpan hanya menulis file. Aplikasi yang mengimpor JSON melalui Vite menerimanya lewat HMR; agar suntingan langsung diterapkan ke instance yang berjalan, gunakan bridge.

## Bridge ke instance yang berjalan {#bridge-to-a-live-instance}

Untuk menyematkan editor di halaman Anda sendiri dan menerapkan suntingan ke instance yang berjalan seketika, buat bridge dari sebuah adapter dan berikan ke elemen `<i18n-devtools-ui>`:

```ts
import { createBridge, register } from '@i18n-micro/devtools-ui'
import { i18n, locales } from './i18n' // a runtime, React, Preact or Solid instance

register() // defines <i18n-devtools-ui> once

const bridge = createBridge({
  adapter: {
    getRouteCache: () => Object.fromEntries(i18n.storage.translations),
    addTranslations: (locale, content, merge) => i18n.addTranslations(locale, content, merge),
    addRouteTranslations: (locale, route, content, merge) => i18n.addRouteTranslations(locale, route, content, merge),
    subscribe: (cb) => i18n.subscribe(cb),
    getCurrentLocale: () => i18n.locale,
  },
  locales,
  defaultLocale: 'en',
  translationDir: 'src/locales',
})

const el = document.createElement('i18n-devtools-ui') as HTMLElement & { bridge: typeof bridge }
el.bridge = bridge
document.body.append(el)
```

`getRouteCache` harus mengembalikan kamus dengan kunci `locale:route` (`en:index`, `en:blog-post`), yang merupakan isi `i18n.storage.translations`. Untuk instance Vue, gunakan `i18n.global.getRouteCache()` dan `i18n.global.subscribeToChanges(cb)`.

`saveTranslation` memperbarui instance terlebih dahulu, lalu mengirim POST ke `<base>/save`. Ketika tidak ada endpoint (build pratinjau statis) atau dev server tidak dapat dijangkau, suntingan disimpan di `localStorage`; galat penyimpanan lainnya memulihkan kamus sebelumnya dan melempar error.
