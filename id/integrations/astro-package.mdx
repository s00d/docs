---

`@i18n-micro/astro` menerjemahkan halaman Astro di server: sebuah middleware memilih locale dari URL dan menempatkan instance per permintaan di `Astro.locals`, lalu `useI18n(Astro)` membacanya. Gunakan di situs Astro yang membutuhkan URL berprefiks locale (`/about`, `/fr/about`) dan kamus JSON bersama. Anda mendapatkan komponen `.astro`, redirect halaman beranda ke bahasa pengunjung, tag `hreflang`, dan props untuk [islands](/id/integrations/astro-islands).

## Instalasi {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/astro
```

```bash npm
npm install @i18n-micro/astro
```

```bash yarn
yarn add @i18n-micro/astro
```

</CodeGroup>

Peer dependency: `astro` `^5.0.0 || ^6.0.0 || ^7.0.0`. Opsional, hanya untuk [islands](/id/integrations/astro-islands): `vue` `^3.3.0`, `react` `^16.8.0 || ^17.0.0 || ^18.0.0 || ^19.0.0`, `preact` `^10.0.0 || ^11.0.0`, `svelte` `^4.0.0 || ^5.0.0`.

## Penyiapan {#setup}

Tambahkan integrasinya. Integrasi ini membundel kamus Anda ke dalam server dan memasang middleware, sehingga `src/middleware.ts` tidak diperlukan:

```ts
// astro.config.mjs
import { defineConfig } from 'astro/config'
import node from '@astrojs/node'
import { i18nIntegration } from '@i18n-micro/astro'

export default defineConfig({
  output: 'server',
  adapter: node({ mode: 'standalone' }),
  integrations: [
    i18nIntegration({
      locale: 'en',
      fallbackLocale: 'en',
      locales: [
        { code: 'en', iso: 'en-US', displayName: 'English' },
        { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
        { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
      ],
      translationDir: 'src/locales',
    }),
  ],
})
```

Kamus menjadi kode saat build: server tidak membaca disk, sehingga juga dapat berjalan di edge (Cloudflare, Vercel Edge). Di `astro dev`, perubahan pada file diterapkan pada permintaan berikutnya.

### Opsi integrasi {#integration-options}

| Opsi | Default | Catatan |
| --- | --- | --- |
| `locale` | wajib | Locale default. |
| `fallbackLocale` | `locale` | |
| `locales` | `[]` | Objek `Locale` lengkap. Locale yang `disabled` bukan locale dari URL mana pun dan bukan target redirect. `iso` adalah tag yang dipakai untuk bentuk jamak jika kodenya bukan tag bahasa (`ua` → `uk-UA`). |
| `translationDir` | tidak ada | Folder yang dibundel ke dalam server, relatif terhadap root proyek. |
| `disablePageLocales` | `false` | File halaman dihitung sebagai terjemahan root. |
| `autoDetect` | `true` | Redirect halaman beranda, lihat [Deteksi locale](#locale-detection). |
| `redirectToDefault` | `false` | `/` juga me-redirect jika tidak ada yang lebih memilih locale lain. |
| `localeCookie` | `'i18n-locale'` | `null` menonaktifkan cookie. |
| `missingWarn` | `false` | |
| `middleware` | `true` | `false`: tulis middleware sendiri, lihat di bawah. |

Pengaturan runtime dipublikasikan di `virtual:i18n-micro/config` (`config.base` adalah `base` milik Astro, `config.localeCodes` adalah kode yang diaktifkan), sedangkan kamus di `virtual:i18n-micro/messages`.

### Middleware Anda sendiri {#your-own-middleware}

Aturan jamak, handler key yang hilang, dan adapter router tidak dapat berpindah dari proses konfigurasi ke bundle server. Untuk hal-hal tersebut, berikan `middleware: false` dan tulis `src/middleware.ts`. Konfigurasi `i18n` Astro kemudian diatur untuk Anda dengan `routing: 'manual'`, sehingga `Astro.currentLocale` dan `astro:i18n` berfungsi. Astro tidak mengizinkan pengaturan itu tanpa `src/middleware.ts`, sehingga dengan middleware bawaan integrasi keduanya tidak berfungsi.

```ts
// src/middleware.ts
import { config } from 'virtual:i18n-micro/config'
import { messages } from 'virtual:i18n-micro/messages'
import { createAstroRouterAdapter, createI18n, createI18nMiddleware, localeIsoMap } from '@i18n-micro/astro'

const i18n = createI18n({
  locale: config.defaultLocale,
  fallbackLocale: config.fallbackLocale,
  localeIso: localeIsoMap(config.locales),
  messages: messages.root,
  routeMessages: messages.routes,
  plural: myPluralRule,
})

export const onRequest = createI18nMiddleware({
  i18n,
  defaultLocale: config.defaultLocale,
  locales: config.localeCodes,
  localeObjects: config.locales,
  autoDetect: config.autoDetect,
  redirectToDefault: config.redirectToDefault,
  localeCookie: config.localeCookie,
  base: config.base,
  routingStrategy: createAstroRouterAdapter(config.locales, config.defaultLocale),
})
```

Untuk membaca folder saat runtime sebagai gantinya, `loadTranslationsFromDir` dan `loadTranslationsIntoI18n` tersedia di `@i18n-micro/astro/node` (hanya Node).

### Opsi middleware {#middleware-options}

| Opsi | Default | Catatan |
| --- | --- | --- |
| `i18n` | wajib | Instance global; setiap permintaan mendapat `i18n.fork(locale)`, yang biayanya sama berapa pun jumlah kamusnya. |
| `defaultLocale` | wajib | |
| `locales` | wajib | Kode locale. |
| `localeObjects` | `locales` sebagai `{ code }` | Objek `Locale` lengkap untuk komponen dan SEO. |
| `autoDetect` | `true` | Redirect halaman beranda, lihat [Deteksi locale](#locale-detection). |
| `redirectToDefault` | `false` | `/` juga me-redirect jika tidak ada yang lebih memilih locale lain, ke beranda locale default sebagaimana di-resolve oleh strategi routing. |
| `localeCookie` | `'i18n-locale'` | `null` menonaktifkan cookie. |
| `routingStrategy` | prefiks kecuali default | Adapter router. Metode yang tidak disediakannya diambil dari adapter default. |
| `base` | tidak ada | `base` milik Astro: `config.base`. |

File halaman (`src/locales/pages/blog/post/de.json`) adalah rute `blog-post`: path halaman yang digabung dengan `-`.

## Terjemahkan {#translate}

```astro
---
// src/pages/index.astro
import { useI18n } from '@i18n-micro/astro'
import I18nT from '@i18n-micro/astro/i18n-t'

const { t, tc, locale } = useI18n(Astro)
---

<h1>{t('greeting', { name: 'Ada' })}</h1>
<p>{tc('apples', 3)}</p>
<I18nT keypath="welcome" tag="p" />
<p>{locale}</p>
```

`useI18n(Astro)` mengembalikan `locale`, `defaultLocale`, `locales`, `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`, `getRoute`, `getRouteName(path?)`, `getLocaleFromPath(path?)`, `switchLocalePath(locale)`, `localizePath(path, locale?)`, `getBasePath(url?)`, `getI18n`, `addTranslations`, `addRouteTranslations`, `mergeTranslations`, dan `clearCache`. Fungsi ini melempar error jika middleware tidak berjalan. Helper `getI18n`, `getLocale`, `getDefaultLocale`, dan `getLocales` membaca `Astro.locals` yang sama.

Nama rute berasal dari rute tanpa locale-nya: `/fr/blog/post` → `blog-post`, dan setiap URL dari `src/pages/blog/[slug].astro` → `blog-slug`, sehingga satu folder `locales/pages/blog-slug/` melayani semuanya. `[...path]` adalah `path`. Di bawah `base` Astro, helper menerima dan mengembalikan URL situs: `switchLocalePath` dan `localizePath` menyertakannya, `getBasePath` tidak, karena `Astro.rewrite` menerima path tanpanya.

### Komponen {#components}

Impor dari `@i18n-micro/astro/<name>` (atau `@i18n-micro/astro/components/<name>.astro`):

| Komponen | Props |
| --- | --- |
| `i18n-t` | `keypath`, `params`, `plural`, `number`, `date`, `relativeDate`, `tag` (`span`, tag apa pun), `html`, `hideIfEmpty`, `defaultValue`; atribut lain diteruskan. Dengan `html`, hasil dari setiap cabang dirender sebagai HTML dan `params` di-escape. Tidak ada slot |
| `i18n-link` | `href`, `locale` (locale tujuan, default saat ini), `class`; atribut lain diteruskan. URL eksternal, `#hash`, dan `?query` tetap seperti yang ditulis; sebuah rute mempertahankan query, hash, dan garis miring di akhirnya |
| `i18n-switcher` | `class`, `activeClass` (`'active'`), `customLabels`; merender tautan ke halaman saat ini dalam setiap locale yang diaktifkan, beserta query-nya |
| `i18n-group` | tidak ada yang mengubah output: sebuah `<div>` di sekitar slot-nya, tanpa prefiks |

## Rute berprefiks locale {#locale-prefixed-routes}

Simpan satu halaman per rute di `src/pages/` dan tambahkan stub rewrite tipis di bawah `src/pages/[locale]/`:

```
src/pages/
  index.astro
  about.astro
  [locale]/
    index.astro
    about.astro
```

```astro
---
// src/pages/[locale]/about.astro
import { prepareLocaleRewrite } from '@i18n-micro/astro'

const target = prepareLocaleRewrite(Astro)
if (target instanceof Response) return target
return Astro.rewrite(target)
---
```

`prepareLocaleRewrite` mengembalikan respons `404` untuk `:locale` yang tidak dikenal; jika tidak, fungsi ini mengatur locale di `Astro.locals` dan mengembalikan path tanpa prefiks. Middleware mempertahankan locale yang sudah ada di `locals`, sehingga halaman hasil rewrite dirender dalam locale tersebut. `getLocaleRewritePath(Astro)` hanya mengembalikan path, untuk saat Anda memvalidasi locale sendiri.

## Deteksi locale {#locale-detection}

URL menentukan locale halaman:

1. Prefiks locale (`/fr/about` → `fr`; `/en/about` juga `en`).
2. Jika tidak ada, nilai yang dikembalikan `getLocaleFromPath` milik adapter router, jika bukan default.
3. Jika tidak, locale default. `/about` selalu merupakan halaman locale default, apa pun isi cookie-nya.

`autoDetect` adalah petunjuk redirect hanya di halaman beranda:

- Permintaan ke `/` yang cookie atau `Accept-Language`-nya lebih memilih locale lain mendapat `302` ke beranda locale tersebut (`/de`). Bobot q dihormati; `de-DE` cocok dengan locale `de`, dan `de` cocok dengan locale `de-DE`.
- Dengan `redirectToDefault`, `/` selalu me-redirect: ke beranda locale yang dipilih, atau jika tidak ada, ke beranda locale default.
- Respons `/` membawa `Vary: Cookie, Accept-Language` (hanya `Accept-Language` jika `localeCookie` bernilai `null`).
- Halaman yang di-prerender tidak pernah me-redirect.

`detectLocale(pathname, cookies, headers, defaultLocale, locales, localeCookie?, routingStrategy?, autoDetect?)` mengembalikan locale pilihan yang sama untuk logika Anda sendiri.

Cookie mengingat sebuah pilihan. Tampilan halaman yang berasal dari halaman same-origin dengan locale lain berarti pengunjung sedang berganti bahasa, tautan apa pun yang membawanya ke sana: respons HTML mengatur cookie ke locale baru, dan `/` tidak me-redirect, sehingga pengalih bahasa dapat mencapai beranda locale default. Endpoint, gambar, 404, form post, dan prefetch tidak mengubah apa pun. "Same origin" adalah apa yang dinyatakan browser di `Sec-Fetch-Site`; tanpa header tersebut, host dari `Referer` dibandingkan dengan host permintaan, jadi di belakang proxy atur `security.allowedDomains` milik Astro.

[Server island](https://docs.astro.build/en/guides/server-islands/) atau action tidak memiliki locale di URL-nya. Ia dirender untuk halaman yang memintanya, dibaca dari `Referer`, yang hanya path-nya yang diperhitungkan, sehingga proxy di depan server tidak mengubah apa pun, dan ia tidak pernah me-redirect. Responsnya membawa `Vary: Referer`. Tanpa `Referer` (kebijakan `no-referrer`), ia berada dalam locale default, dan pada halaman dinamis rutenya berasal dari URL, sehingga kamus halaman tidak menjangkaunya.

## Adapter router {#router-adapter}

`createAstroRouterAdapter(locales, defaultLocale)` memberi prefiks pada setiap locale kecuali default. Adapter Astro hanya membutuhkan `getCurrentPath`; anggota lainnya opsional dan kembali ke adapter default: `getRouteName(path, locales, routePattern?)`, `getLocaleFromPath`, `switchLocalePath`, `localizePath`, `removeLocaleFromPath`, `resolvePath` (target redirect beranda), `push`, `replace`, `getRoute`. Tulis adapter sendiri untuk URL subdomain atau sufiks dan berikan ke `createI18nMiddleware`.

## SEO {#seo}

```astro
---
// src/layouts/Layout.astro
import { useLocaleHead } from '@i18n-micro/astro'

const head = useLocaleHead(Astro, { baseUrl: 'https://example.com' })
---

<html lang={head.htmlAttrs.lang} dir={head.htmlAttrs.dir}>
  <head>
    {head.link.map((l) => <link rel={l.rel} href={l.href} hreflang={l.hreflang} />)}
    {head.meta.map((m) => <meta property={m.property} content={m.content} />)}
  </head>
  <body><slot /></body>
</html>
```

Fungsi ini mengembalikan `htmlAttrs` (`lang` dari `iso`, `dir`), tautan canonical (path tanpa query), alternate `hreflang` untuk setiap locale yang diaktifkan dengan `seo !== false` ditambah `x-default`, `og:locale`, `og:locale:alternate`, dan `og:url`. Opsi: `baseUrl` (`site` dari konfigurasi Astro, atau jika tidak ada, URL relatif terhadap root), `addDirAttribute` (`true`), `addSeoAttributes` (`true`), `hreflangBaseLanguage` (`false`).
