`@i18n-micro/runtime` adalah instance i18n yang agnostik terhadap framework: kamus, `t()`, bentuk jamak, pemformatan `Intl`, dan langganan perubahan, tanpa `fs` dan tanpa framework. Gunakan di TypeScript biasa, web worker, fungsi edge, atau sebagai dasar binding Anda sendiri. Paket React, Preact, Node, dan Astro memperluas kelas yang sama ini.

## Instalasi {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/runtime
```

```bash npm
npm install @i18n-micro/runtime
```

```bash yarn
yarn add @i18n-micro/runtime
```

</CodeGroup>

Tanpa peer dependency. Untuk file terjemahan di disk, gunakan [`@i18n-micro/node`](/id/integrations/nodejs-package).

## Penyiapan {#setup}

```ts
import { createI18n } from '@i18n-micro/runtime'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    en: { greeting: 'Hello, {name}!', apples: 'no apples | one apple | {count} apples' },
    de: { greeting: 'Hallo, {name}!' },
  },
  routeMessages: {
    about: { en: { title: 'About us' } },
  },
})
```

Semua opsi (`plural`, `missingWarn`, `missingHandler`, `numberFormats`, `datetimeFormats`) tercantum di [instance](/id/integrations/overview#the-instance).

## Menerjemahkan {#translate}

```ts
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.tc('apples', 5) // '5 apples'
i18n.tn(1234.5) // '1,234.5'

i18n.setRoute('about')
i18n.t('title') // 'About us' (route dictionary)
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!' (root, still visible)
```

Muat kamus tambahan nanti:

```ts
i18n.loadMessages({ fr: { greeting: 'Bonjour, {name} !' } }, { about: { fr: { title: 'À propos' } } })
i18n.addTranslations('fr', { nav: { home: 'Accueil' } }) // deep merge; pass false to replace

await i18n.loadFromUrl('/locales/fr.json', { locale: 'fr' })
await i18n.loadFromUrl('/locales/pages/about/fr.json', { locale: 'fr', routeName: 'about' })
await i18n.loadFromUrls([
  { url: '/locales/en.json', locale: 'en' },
  { url: '/locales/de.json', locale: 'de' },
])
```

`loadFromUrl` menggunakan `fetch` (berikan `init` untuk header) dan melempar error pada respons yang tidak OK. `loadFromUrls` memuat satu per satu secara berurutan.

## Mengganti locale {#switch-locale}

```ts
i18n.locale = 'de'
i18n.t('greeting', { name: 'Ada' }) // 'Hallo, Ada!'
```

Perubahan locale, rute, dan kamus memberi tahu para subscriber, begitulah cara binding framework melakukan render ulang:

```ts
const stop = i18n.subscribe(() => {
  document.querySelector('#greeting')!.textContent = i18n.t('greeting', { name: 'Ada' }) as string
})
i18n.locale = 'fr'
stop()
```

`getSnapshot()` mengembalikan string yang berubah pada setiap notifikasi (untuk store bergaya `useSyncExternalStore`).

## Per request {#per-request}

Instance menyimpan satu locale dan satu rute. Di server, jangan mengganti locale instance bersama per request: dua request bersamaan akan melihat locale satu sama lain. `i18n.fork(locale)` memberi request instance-nya sendiri: locale, fallback, dan rute sendiri; kamus, formatter, dan aturan yang sama. Biaya fork tetap sama berapa pun jumlah kamusnya. Fork melihat penulisan ke induknya sampai penulisan pertamanya sendiri, dan penulisannya tetap berada di fork tersebut. [Node.js](/id/integrations/nodejs-package#per-request) menambahkan `run`.

## API {#api}

| Anggota | Catatan |
| --- | --- |
| `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has` | lihat [Menerjemahkan dan memformat](/id/integrations/overview#translate-and-format) |
| `locale`, `fallbackLocale` | get/set |
| `currentRoute`, `setRoute(name)`, `getRoute()` | rute aktif, default `'index'` |
| `loadMessages(messages?, routeMessages?)` | gabungkan banyak locale dan rute sekaligus |
| `addTranslations(locale, tree, merge = true)`, `addRouteTranslations(locale, route, tree, merge = true)` | |
| `loadFromUrl(url, { locale?, routeName?, init? })`, `loadFromUrls(entries)` | `fetch` JSON |
| `hasTranslation(key)` | locale aktif, rute apa pun (berbeda dengan `has`, yang memeriksa rute aktif dan root) |
| `setTranslation(key, value)`, `resolveTranslations()` | tulis satu kunci; baca pohon gabungan |
| `clear()`, `clearCache()` | hapus semua kamus |
| `subscribe(cb)`, `getSnapshot()` | notifikasi perubahan |
| `storage` | `{ translations: Map<'locale:route', Translations> }` |

Kode yang bukan tag bahasa mendapatkan bentuk jamaknya dari `localeIso: { ua: 'uk-UA' }`; `localeIsoMap(locales)` membangunnya dari entri daftar locale yang memiliki `iso`.

Ekspor modul: `createI18n`, `I18n`, `fetchJsonTranslations`, `FormatService`, `interpolate`, `localeIsoMap`, serta tipe `I18nOptions`, `LoadFromUrlOptions`, `LoadFromUrlEntry`, `TranslationStorage`, `Translations`, `Locale`, `PluralFunc`. Signature lengkap: [referensi paket](/id/api/packages/runtime).
