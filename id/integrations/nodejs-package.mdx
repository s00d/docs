`@i18n-micro/node` adalah instance [runtime](/id/integrations/runtime-package) ditambah loader yang membaca folder terjemahan dari disk. Gunakan di server Express atau Fastify, CLI, generator email atau PDF, atau skrip apa pun yang membutuhkan file JSON yang sama dengan app Nuxt Anda. Anda memuat file sekali dan menerjemahkan per request tanpa berbagi state yang dapat berubah antar-request.

## Instalasi {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/node @i18n-micro/utils
```

```bash npm
npm install @i18n-micro/node @i18n-micro/utils
```

```bash yarn
yarn add @i18n-micro/node @i18n-micro/utils
```

</CodeGroup>

Tanpa peer dependency; Node.js `>=20`. `@i18n-micro/utils` hanya diperlukan untuk helper `Accept-Language` di bawah.

## Penyiapan {#setup}

Loader membaca [tata letak folder Nuxt](/id/guide/translations): `locales/en.json` adalah kamus root, `locales/pages/blog/post/en.json` milik route `blog-post`.

```ts
import { createI18n } from '@i18n-micro/node'

const i18n = createI18n({ locale: 'en', fallbackLocale: 'en', translationDir: './locales' })
await i18n.loadTranslations()

i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.t('title', undefined, undefined, 'blog-post') // from locales/pages/blog/post/en.json
```

Opsinya adalah opsi runtime (lihat [instance](/id/integrations/overview#the-instance)) ditambah `translationDir` dan `disablePageLocales` (memperlakukan file `pages/**` sebagai kamus root). `i18n.reload()` membersihkan setiap kamus dan membaca folder lagi, untuk file watcher dalam mode pengembangan.

`loadTranslations(dir, disablePageLocales?)` juga diekspor secara terpisah dan mengembalikan `{ root, routes }`:

```ts
import { loadTranslations } from '@i18n-micro/node'

const { root, routes } = await loadTranslations('./locales')
// root:   { en: {...}, de: {...} }
// routes: { 'blog-post': { en: {...}, de: {...} } }
```

## Per request {#per-request}

Sebuah instance menyimpan satu locale dan satu route. Mengganti `i18n.locale` pada instance bersama di dalam request handler menimbulkan race condition dengan request yang berjalan bersamaan. `run` memberikan request instance-nya sendiri:

```ts
const i18n = createI18n({ locale: 'en', fallbackLocale: 'en', translationDir: './locales' })
await i18n.loadTranslations()

// `() => next()`: `run` hands its callback the fork, and Express reads an argument of `next` as an error
app.use((req, res, next) => i18n.run(pickLocale(req), () => next()))

app.get('/', (req, res) => {
  res.send(i18n.t('greeting')) // the request's locale, in everything it awaits
})
```

Di dalam `run`, instance bersama membaca dan mengatur locale dan route milik request (`AsyncLocalStorage`); fork dimulai pada route saat ini, dan `i18n.setRoute(...)` di dalam callback mengubah route milik request tersebut. Callback juga menerima fork milik request: kamus yang ditulis ke fork tetap berada di request, sedangkan kamus yang ditulis ke instance bersama menjangkau semua orang.

Tanpa `AsyncLocalStorage`, `i18n.fork(locale)` mengembalikan jenis instance yang sama untuk diteruskan.

`reload()` membaca direktori lagi; kamus lama tetap menjawab sampai kamus baru selesai dimuat.

## Memilih locale {#pick-the-locale}

`detectLocaleFromAcceptLanguage(header, locales)` memperhatikan bobot `q` dan mencocokkan `de-DE` dengan locale `de` (dan `de` dengan `de-DE`). Fungsi ini mengembalikan `null` jika tidak ada yang cocok.

```ts
import express from 'express'
import { detectLocaleFromAcceptLanguage } from '@i18n-micro/utils/accept-language'

const app = express()

app.get('/hello', (req, res) => {
  const locale = detectLocaleFromAcceptLanguage(req.headers['accept-language'], locales) ?? 'en'
  const i18n = byLocale.get(locale)!
  res.json({ message: i18n.t('greeting', { name: 'Ada' }) })
})
```

Untuk prefiks URL, cookie, dan header sekaligus, `resolveLocale({ defaultLocale, validLocales, url, cookie, acceptLanguage, autoDetectLanguage: true })` dari `@i18n-micro/utils/resolve-locale` menerapkan urutan prioritas modul: URL, lalu cookie, lalu `Accept-Language`, lalu default. Nilai yang tidak valid dilewati.

Di dalam app Nuxt Anda tidak memerlukan paket ini di server: gunakan [terjemahan sisi server](/id/guide/server-side-translations) milik modul.

## API {#api}

| Ekspor | Catatan |
| --- | --- |
| `createI18n(options)`, `I18n` | instance runtime + `translationDir`, `loadTranslations(dir?)`, `reload()` |
| `loadTranslations(dir, disablePageLocales?)` | `{ root, routes }` |
| `loadRootTranslations(dir, disablePageLocales?)` | hanya `root` |
| `FormatService`, `interpolate` | dari core |
| Tipe: `I18nOptions`, `LoadedTranslations`, `Translations`, `Locale`, `PluralFunc`, `Params` | |

Metode instance tercantum di [Runtime](/id/integrations/runtime-package#api). Signature lengkap: [referensi paket](/id/api/packages/node).
