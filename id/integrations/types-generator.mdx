title: "Generator tipe"
description: "Hasilkan autocomplete TypeScript untuk key terjemahan dari file JSON Anda, di Nuxt atau proyek Vite mana pun."
---

`@i18n-micro/types-generator` membaca setiap file JSON di folder terjemahan Anda dan menulis deklarasi yang mencantumkan semua key. Tambahkan jika Anda ingin editor menyarankan key di `t()`, `$t()`, dan `<I18nT keypath>`. Paket ini berfungsi sebagai modul Nuxt dan sebagai plugin Vite atau Rollup, serta membuat ulang deklarasi saat file berubah.

## Instalasi {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/types-generator
```

```bash npm
npm install -D @i18n-micro/types-generator
```

```bash yarn
yarn add -D @i18n-micro/types-generator
```

</CodeGroup>

Peer dependency: `@nuxt/kit` `^3.18.0 || ^4.0.0`. Hanya entry `/nuxt` yang mengimpornya; di proyek yang hanya memakai Vite, peringatan peer dapat diabaikan.

## Nuxt {#nuxt}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro', '@i18n-micro/types-generator/nuxt'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Modul menulis `.nuxt/types/i18n-micro.d.ts` dan Nuxt menambahkannya ke konteks tipe; tidak ada yang perlu disertakan secara manual. Modul membaca `i18nTypes.translationDir`, atau jika tidak ada, lokasi tempat `nuxt-i18n-micro` membaca terjemahan: `translationDir` (dari `i18n` atau opsi modul inline, default `'locales'`) di setiap layer, dan `additionalTranslationDirs`. Mengedit file JSON di bawah folder tersebut membuat ulang tipe di `nuxi dev`. `i18nTypes.outputFile` diabaikan di Nuxt (sebuah peringatan memberitahukannya).

## Vite {#vite}

`I18nTypesPlugin` adalah plugin Vite, yang juga diterima oleh Rollup. Untuk bundler lain, panggil `generateTypes` dalam sebuah skrip.

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { I18nTypesPlugin } from '@i18n-micro/types-generator'

export default defineConfig({
  plugins: [
    vue(),
    I18nTypesPlugin({
      srcDir: process.cwd(),
      translationDir: 'src/locales',
      outputFile: 'src/i18n-micro.d.ts',
    }),
  ],
})
```

| Opsi | Wajib | Catatan |
| --- | --- | --- |
| `srcDir` | ya | Direktori dasar; `translationDir` di-resolve relatif terhadapnya. |
| `translationDir` | ya | Folder berisi file JSON (termasuk subfolder seperti `pages/`), atau array folder. |
| `outputFile` | tidak | Tempat menulis deklarasi; default `<srcDir>/i18n-micro.d.ts`. |

Plugin menghasilkan deklarasi sekali saat build dimulai dan, di server pengembangan, membuatnya ulang 300 ms setelah ada perubahan di folder. Pastikan `include` di `tsconfig.json` Anda mencakup file output.

## Gunakan key {#use-the-keys}

File yang dihasilkan memperluas `DefineLocaleMessage` di `@i18n-micro/types`, yang mengubah `TranslationKey` menjadi key Anda:

```ts
declare module '@i18n-micro/types' {
  export interface DefineLocaleMessage {
    nav: object
    'nav.home': string
    'profile.title': string
  }
}
```

Key-nya adalah key yang dijawab oleh `t()`, termasuk objek, dari setiap locale dan setiap file halaman, dengan tipe nilai JSON-nya. `TranslationKey` adalah gabungan (union) dari key tersebut ditambah string apa pun, sehingga Anda mendapatkan autocomplete, bukan error: key yang salah ketik atau dinamis tetap dapat dikompilasi. Params dan nilai kembalian tidak diberi tipe.

Untuk key dinamis di bawah prefiks yang diketahui, `ScopedKey<'prefix'>` mempersempit ke key yang cocok:

```ts
import type { ScopedKey } from '@i18n-micro/types'

const statusText = (status: string) => t(`status.${status}` as ScopedKey<'status'>)
```

`TranslationKey` dan `ScopedKey` berasal dari `@i18n-micro/types` (React, Preact, dan Solid mengekspor ulang `TranslationKey`; Vue tidak).

## API {#api}

| Ekspor | Entry | Catatan |
| --- | --- | --- |
| `I18nTypesPlugin(options)` | `@i18n-micro/types-generator` | Plugin Vite dan Rollup |
| `generateTypes(options)` | `@i18n-micro/types-generator` | menulis file, mengembalikan path-nya |
| `getTypesString(options)` | `@i18n-micro/types-generator` | mengembalikan deklarasi tanpa menulis |
| `formatKeyProperty(key)` | `@i18n-micro/types-generator` | helper |
| Modul Nuxt (`configKey: 'i18nTypes'`) | `@i18n-micro/types-generator/nuxt` | opsi `translationDir` |
