title: "Astro islands"
description: "Terjemahan di dalam island Vue, React, Preact, dan Svelte dengan @i18n-micro/astro."
---

Sebuah island berjalan di browser, tempat instance i18n milik server tidak ada. `@i18n-micro/astro` memungkinkan halaman memilih kunci yang dibutuhkan island, meneruskannya sebagai satu prop, dan membacanya di island melalui adapter framework kecil. Anda mendapatkan `t`, `tc`, `tn`, `td`, `tdr`, dan `has` di island Vue, React, Preact, dan Svelte, dengan hanya string yang dipilih yang masuk ke HTML.

## Penyiapan {#setup}

Siapkan [integrasi dan middleware Astro](/id/integrations/astro-package#setup) terlebih dahulu, lalu tambahkan integrasi framework yang Anda gunakan (`@astrojs/vue`, `@astrojs/react`, `@astrojs/preact`, `@astrojs/svelte`). Adapter island membutuhkan framework tersebut sebagai peer: `vue` `^3.3.0`, `react` `^16.8.0 || ^17.0.0 || ^18.0.0 || ^19.0.0`, `preact` `^10.0.0 || ^11.0.0` atau `svelte` `^4.0.0 || ^5.0.0`.

## Meneruskan terjemahan ke island {#pass-translations-to-an-island}

```astro
---
// src/pages/index.astro
import { getI18nProps } from '@i18n-micro/astro'
import Counter from '../components/Counter.vue'

const i18n = getI18nProps(Astro, ['counter.title', 'counter.apples'])
---

<Counter client:load i18n={i18n} />
```

`getI18nProps(Astro, keys?)` mengembalikan `{ locale, fallbackLocale, currentRoute, translations }` (tipe `I18nClientProps`). Berikan kunci yang digunakan island: masing-masing di-resolve di server seperti `t()` (kamus rute, root, dan fallback) dan hanya kunci yang ditemukan yang masuk ke HTML. Tanpa `keys`, semua yang dapat dijawab `t()` di halaman ini akan dikirim, di setiap island, sehingga 2000 kunci root berukuran sekitar 100 KB per island; di mode dev sebuah peringatan muncul jika ukurannya di atas 20 KB.

Island hanya menerjemahkan dari objek tersebut. `t` mengembalikan kunci untuk apa pun yang tidak diteruskan, dan pesan tertaut (linked messages) tidak di-resolve.

## Vue {#vue}

Panggil `provideI18n(() => props.i18n)` di komponen root island dan `useAstroI18n()` di komponen anaknya. `inject` milik Vue tidak melihat nilai yang di-provide oleh komponen yang sama, sehingga hook harus berjalan di komponen anak, bukan di root:

```vue
<!-- src/components/Counter.vue -->
<script setup lang="ts">
import { provideI18n } from '@i18n-micro/astro/client/vue'
import type { I18nClientProps } from '@i18n-micro/astro'
import CounterBody from './CounterBody.vue'

const props = defineProps<{ i18n: I18nClientProps }>()
provideI18n(() => props.i18n)
</script>

<template><CounterBody /></template>
```

```vue
<!-- src/components/CounterBody.vue -->
<script setup lang="ts">
import { ref } from 'vue'
import { useAstroI18n } from '@i18n-micro/astro/client/vue'

const { t, tc } = useAstroI18n()
const count = ref(0)
</script>

<template>
  <h3>{{ t('counter.title') }}</h3>
  <button @click="count++">{{ tc('counter.apples', count) }}</button>
</template>
```

## React dan Preact {#react-and-preact}

```tsx
// src/components/Counter.tsx
import { useState } from 'react'
import { I18nProvider, useAstroI18n } from '@i18n-micro/astro/client/react'
import type { I18nClientProps } from '@i18n-micro/astro'

function Body() {
  const { t, tc } = useAstroI18n()
  const [count, setCount] = useState(0)
  return <button onClick={() => setCount(count + 1)}>{t('counter.title')}: {tc('counter.apples', count)}</button>
}

export default function Counter({ i18n }: { i18n: I18nClientProps }) {
  return (
    <I18nProvider value={i18n}>
      <Body />
    </I18nProvider>
  )
}
```

Untuk Preact, impor `I18nProvider` dan `useAstroI18n` dari `@i18n-micro/astro/client/preact`; API-nya sama.

## Svelte {#svelte}

```svelte
<!-- src/components/Counter.svelte -->
<script lang="ts">
  import { createI18nStore, useAstroI18n } from '@i18n-micro/astro/client/svelte'
  import type { I18nClientProps } from '@i18n-micro/astro'

  export let i18n: I18nClientProps
  const { t, tc } = useAstroI18n(createI18nStore(i18n))
  let count = 0
</script>

<button on:click={() => count++}>{t('counter.title')}: {tc('counter.apples', count)}</button>
```

`useAstroI18n(store)` juga mengembalikan `store` untuk pembacaan `$store` di template.

## Island yang dipertahankan {#persisted-islands}

Island dengan `transition:persist` mendapatkan props baru setelah navigasi. React, Preact, dan Vue (jika diberi getter) mengikutinya. Di Svelte, simpan store dan teruskan props tersebut: `const store = createI18nStore(i18n)`, `const { t } = useAstroI18n(store)`, lalu `$: store.set(i18n)` (dengan runes, `$effect(() => store.set(i18n))`).

## API {#api}

| Entry | Ekspor |
| --- | --- |
| `@i18n-micro/astro` | `getI18nProps`, tipe `I18nClientProps` |
| `@i18n-micro/astro/client/vue` | `provideI18n(props \| () => props)`, `useAstroI18n()` |
| `@i18n-micro/astro/client/react` | `I18nProvider` (prop `value`), `useAstroI18n()` |
| `@i18n-micro/astro/client/preact` | `I18nProvider` (prop `value`), `useAstroI18n()` |
| `@i18n-micro/astro/client/svelte` | `createI18nStore(props)`, `useAstroI18n(store)` |
| `@i18n-micro/astro/client` | `translate`, `hasTranslation` murni, tanpa framework |

Setiap `useAstroI18n` mengembalikan `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`, `setLocale`, `setRoute`, dan `locale`. Sebuah island memiliki satu kamus gabungan, sehingga `has` miliknya bernilai true untuk kunci yang dapat dijawab `t`, termasuk dari locale fallback; di server `has` hanya melihat locale yang aktif.
