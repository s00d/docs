`@i18n-micro/vitepress` menambahkan kamus runtime ke situs VitePress: `$t` dan `<I18nT>` di dalam markdown, helper path, dan tag SEO, dibangun di atas [`@i18n-micro/vue`](/id/integrations/vue-package). Gunakan ketika string UI yang sama muncul di banyak halaman dan Anda tidak ingin menduplikasinya per locale. Locale mengikuti path locale milik VitePress sendiri (`/`, `/fr/`).

## Kapan menggunakannya {#when-to-use-it}

| Kebutuhan | Solusi |
|------|----------|
| `.md` duplikat, prefiks URL | `locales` VitePress |
| `$t` runtime / komponen / sinkronisasi path / head SEO | `@i18n-micro/vitepress` |
| Label chrome tema default (`docFooter`, UI pencarian) | `themeConfig` Anda sendiri per locale |

<Tip>

**Playground** — [`packages/vitepress/playground`](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/vitepress/playground) — `pnpm -C packages/vitepress/playground dev`

</Tip>

## Instalasi {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vitepress
```

```bash npm
npm install @i18n-micro/vitepress
```

```bash yarn
yarn add @i18n-micro/vitepress
```

</CodeGroup>

Peer dependency: `vitepress` `>=1.0.0 || >=2.0.0-alpha.0`, `vue` `^3.3.0`. Skrip Node menggunakan `@i18n-micro/node`, yang terpasang bersama paket ini dan diekspor ulang melalui `/node`. Tipe yang dipublikasikan membutuhkan Vue 3.5.5 atau lebih baru dengan `skipLibCheck: false`; dengan `skipLibCheck: true`, pengaturan template yang umum, versi yang lebih lama juga dapat dikompilasi.

## Penyiapan {#setup}

```
locales/en.json
locales/fr.json
locales/pages/guide/demo/en.json   # optional page-scoped
locales/pages/guide/demo/fr.json
```

File halaman dipetakan ke nama rute dengan cara yang sama seperti Nuxt/Astro (`guide/demo` → `guide-demo`).

### 1. Konfigurasi — `@i18n-micro/vitepress/config` {#1-config-—-@i18n-micro/vitepress/config}

```ts
// .vitepress/config.mts
import { defineConfig } from 'vitepress'
import { withI18n, buildVitePressLocales } from '@i18n-micro/vitepress/config'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English', og: 'en_US' },
  { code: 'fr', iso: 'fr-FR', displayName: 'Français', og: 'fr_FR' },
]
const defaultLocale = 'en'

export default defineConfig(
  withI18n(
    {
      locales: buildVitePressLocales(locales, defaultLocale),
      // themeConfig.i18nRouting is injected automatically
    },
    {
      locale: defaultLocale,
      defaultLocale,
      locales,
      translationDir: 'locales',
      metaBaseUrl: 'https://example.com', // optional SEO head
    },
  ),
)
```

### 2. Tema — `@i18n-micro/vitepress/theme` {#2-theme-—-@i18n-micro/vitepress/theme}

```ts
// .vitepress/theme/index.ts
import DefaultTheme from 'vitepress/theme'
import { defineI18nTheme } from '@i18n-micro/vitepress/theme'

export default defineI18nTheme(DefaultTheme)
```

Locale awal diambil dari path saat ini sebelum instalasi (tidak ada kilasan locale default pada `/fr/…`).

### Lanjutan: `createI18n` manual {#advanced-manual-createi18n}

Satu factory untuk klien: plugin Vue + metode path + `enhanceApp` (tidak ada ekspor helper router terpisah).

```ts
import { createI18n, messagesFromGlob } from '@i18n-micro/vitepress'

const i18n = createI18n({
  locale: 'en',
  defaultLocale: 'en',
  locales: [{ code: 'en' }, { code: 'fr' }],
  messages: messagesFromGlob(import.meta.glob('../../locales/*.json', { eager: true })),
})

i18n.localizePath('/guide', 'fr')
// in theme enhanceApp:
i18n.enhanceApp({ app, router })
```

### Skrip Node — `@i18n-micro/vitepress/node` {#node-scripts-—-@i18n-micro/vitepress/node}

Menggunakan `createI18n` / `loadTranslations` dari `@i18n-micro/node` (sama seperti Astro & CLI), lalu memasang metode path VitePress dengan `BaseI18n.extend`:

```ts
import { createI18n } from '@i18n-micro/vitepress/node'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  translationDir: './locales',
  locales: ['en', 'fr'],
  defaultLocale: 'en',
})
await i18n.loadTranslations()
i18n.t('cta.readMore')
i18n.localizePath('/guide', 'fr')
```

Node biasa tanpa path: `import { createI18n } from '@i18n-micro/node'`.

## Terjemahan di dalam halaman {#in-page-translations}

Setiap file markdown VitePress adalah Vue SFC.

### Komponen global dan `$t` (direkomendasikan di markdown) {#global-components-and-$t-recommended-in-markdown}

`createI18n` / `defineI18nTheme` memasang `@i18n-micro/vue`, yang mendaftarkan `I18nT` / `I18nLink` / `I18nGroup` / `I18nSwitcher` serta `$t` / `$tc` / `$ts`.

```md
{{ $t('cta.readMore') }}

<I18nT keypath="greeting" :params="{ name: 'VitePress' }" />

<I18nLink to="/guide/demo">Demo</I18nLink>
```

### `useI18n` di `<script setup>` {#usei18n-in-script-setup}

```md
<script setup>
import { useI18n } from '@i18n-micro/vitepress'
const { t, tc, locale, localePath, switchLocale } = useI18n()
</script>

# {{ t('section.title') }}
```

## Dropdown bahasa {#language-dropdown}

Ketika `locales` memiliki lebih dari satu entri, VitePress menampilkan menu bahasanya sendiri (`VPNavBarTranslations`). `withI18n` menghubungkan `themeConfig.i18nRouting` sehingga ikon globe selaras dengan `<I18nSwitcher>` / helper path.

Gunakan `<I18nSwitcher>` hanya di layout kustom, jangan di samping globe default.

## Catatan SSR {#ssr-notes}

- Locale saat prerender berasal dari path URL, bukan cookie.
- Kode tema tidak boleh menyentuh `window` saat import.
- Impor `defineI18nTheme` dari `/theme` agar evaluasi konfigurasi Node tidak pernah memuat `virtual:i18n-micro/*`.

## Permukaan API {#api-surface}

| Ekspor | Peran |
|--------|------|
| `createI18n` (`.`) | Klien: plugin Vue + metode path + `enhanceApp` |
| `getLocaleFromPath` / `stripSiteBase` / `routeNameFromPath` (`.`) | Sinkronisasi locale manual ketika `syncWithVitePress: false` |
| `createI18n` (`/node`) | Node: `@i18n-micro/node` + metode path |
| `defineI18nTheme` (`/theme`) | Tema tanpa boilerplate |
| `withI18n` (`/config`) | Konfigurasi + modul virtual + SEO opsional |
| `buildVitePressLocales` (`/config`) | Membangun `locales` VitePress dari `Locale[]` |
| `buildVitePressLocaleHead` (`/config`) | Head SEO manual (juga digunakan oleh `metaBaseUrl`) |
| `messagesFromGlob` | Peta glob → messages opsional untuk `createI18n` |
| `useI18n` / `I18nT` / … | Diekspor ulang dari `@i18n-micro/vue` |
| `BaseI18n.extend` (`@i18n-micro/core`) | Memasang metode kustom pada instance i18n mana pun |

## Situs bergaya OpenAPI (kunci integrasi) {#openapi-style-sites-integration-locks}

Rangkaian uji regresi: `packages/vitepress/tests/integration-openapi.test.ts` (path dalam, `base=/openapi_docs/`, sinkronisasi nonaktif + locale manual, generator Node, SEO).

| Pola | Lakukan ini |
|---------|---------|
| Halaman `/…/{spec}/{op}` yang dalam, hanya JSON UI root | Utamakan default `syncWithVitePress: true` (mempertahankan `setRoute('index')` ketika tidak ada kamus halaman) **atau** `syncWithVitePress: false` + `getLocaleFromPath` |
| Jangan pernah memanggil `setRoute(deepName)` tanpa kamus halaman | Kunci UI root menghilang sampai `setRoute('index')` |
| Generator / `getTranslation` | `createI18n` dari `/node` + `await loadTranslations()` + `i18n.t(key)` (atur `i18n.locale`) |
| Canonical kustom di `transformPageData` | Berikan `meta: false` ke `withI18n` (hindari tag ganda) |
| SEO paket dengan base situs | `metaBaseUrl` + `base` VitePress → URL absolut menyertakan base |
| Penggantian nama dari build paket yang lebih lama | `withI18nMicro` → `withI18n`, `createVitePressI18n` → `createI18n`, `loadMessages` → `createI18n` node |
