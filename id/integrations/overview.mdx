# Integrasi

Paket `@i18n-micro` adalah versi ringan dari Nuxt I18n Micro khusus framework yang dirancang untuk integrasi ke berbagai framework dan lingkungan. Paket ini menyediakan fungsionalitas internasionalisasi inti dengan jejak minimal, berfokus pada fitur terjemahan esensial dan komponen dasar.

## Ikhtisar

Paket integrasi ini adalah **versi mini** dari modul Nuxt I18n Micro lengkap, hanya berisi fungsionalitas esensial yang dibutuhkan untuk internasionalisasi:

- **Fitur Terjemahan Inti** - Method terjemahan dasar, pluralisasi, dan pemformatan
- **Komponen Esensial** - Sekumpulan kecil komponen UI untuk tugas i18n umum
- **Pola Adapter Router** - Integrasi perutean yang fleksibel melalui abstraksi adapter
- **Dukungan TypeScript** - Definisi tipe lengkap untuk pengembangan yang aman-tipe

Tidak seperti modul Nuxt lengkap, paket ini:

- Tidak menyertakan logika perutean khusus framework
- Membutuhkan Anda mengimplementasikan adapter router untuk fitur perutean
- Fokus pada fungsionalitas terjemahan daripada integrasi framework
- Dirancang agar ringan dan agnostik framework sedapat mungkin

## Komponen Inti

Semua paket framework menyertakan komponen esensial berikut:

### `<I18nT>`

Komponen terjemahan yang me-render teks yang diterjemahkan dengan dukungan untuk:

- **Interpolasi parameter** - Ganti placeholder dengan nilai dinamis
- **Pluralisasi** - Pemilihan bentuk plural otomatis berdasarkan hitungan
- **Pemformatan angka** - Memformat angka sesuai lokal
- **Pemformatan tanggal** - Memformat tanggal dan waktu relatif
- **Rendering HTML** - Perenderan konten HTML opsional
- **Nilai default** - Teks fallback saat terjemahan hilang

**Contoh:**

```vue
<!-- Vue -->
<I18nT keypath="greeting" :params="{ name: 'World' }" />
```

```tsx
// React
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```tsx
// Solid
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```astro
<!-- Astro -->
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

### `<I18nLink>`

Komponen tautan terlokalisasi yang otomatis menangani awalan lokal pada URL. Fitur:

- **Lokalisasi jalur otomatis** - Menambah/menghapus awalan lokal berdasarkan strategi perutean
- **Deteksi state aktif** - Menandai rute saat ini
- **Dukungan tautan eksternal** - Otomatis mendeteksi dan menangani URL eksternal
- **Integrasi router** - Menggunakan komponen link adapter router bila tersedia
- **Penggayaan kustom** - Mendukung state aktif dan hover

**Contoh:**

```vue
<!-- Vue -->
<I18nLink to="/about" active-class="active">
  About Us
</I18nLink>
```

```tsx
// React
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```tsx
// Solid
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```astro
<!-- Astro -->
<I18nLink href="/about" class="nav-link">
  About Us
</I18nLink>
```

### `<I18nSwitcher>`

Komponen pengganti bahasa yang menyediakan antarmuka dropdown atau daftar untuk mengubah lokal. Fitur:

- **Daftar lokal otomatis** - Menghasilkan opsi dari lokal yang dikonfigurasi
- **Penyorotan lokal saat ini** - Menunjukkan bahasa aktif secara visual
- **Label kustom** - Mendukung nama tampilan kustom per lokal
- **Integrasi router** - Bernavigasi otomatis ke jalur yang terlokalisasi
- **Aksesibilitas** - Atribut ARIA yang tepat dan navigasi keyboard

**Contoh:**

```vue
<!-- Vue -->
<I18nSwitcher />
```

```tsx
// React
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```tsx
// Solid
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```astro
<!-- Astro -->
<I18nSwitcher />
```

### `<I18nGroup>`

Komponen untuk mengelompokkan terjemahan dengan awalan bersama, berguna untuk mengorganisir terjemahan berdasarkan halaman atau fitur. Fitur:

- **Cakupan awalan** - Otomatis menambahkan awalan ke semua kunci terjemahan dalam grup
- **Grup bersarang** - Mendukung grup terjemahan bersarang
- **Organisasi bersih** - Membantu mempertahankan struktur terjemahan yang teratur

**Contoh:**

```vue
<!-- Vue -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

```tsx
// React
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```tsx
// Solid
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```astro
<!-- Astro -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

## Opsi `createI18n` bersama \{#create-i18n-options\}

Setiap paket framework dibuat dengan cara yang sama — hanya tipe opsi yang dinamai sesuai
framework (`ReactI18nOptions`, `SolidI18nOptions`, dan seterusnya). Opsinya sendiri
identik:

| Property         | Type                                                       | Required | Default          | Description                                    |
| ---------------- | ---------------------------------------------------------- | -------- | ---------------- | ---------------------------------------------- |
| `locale`         | `string`                                                   | ✅       | -                | Current locale code (e.g., `'en'`)             |
| `fallbackLocale` | `string`                                                   | ❌       | Same as `locale` | Fallback locale when translation is missing    |
| `messages`       | `Record<string, Translations>`                             | ❌       | `\{\}`             | Initial translation messages                   |
| `plural`         | `PluralFunc`                                               | ❌       | `defaultPlural`  | Custom pluralization function                  |
| `missingWarn`    | `boolean`                                                  | ❌       | `true`           | Show console warnings for missing translations |
| `missingHandler` | `(locale: string, key: string, routeName: string) => void` | ❌       | -                | Custom handler for missing translations        |

Apa pun di luar ini bersifat khusus framework dan didokumentasikan pada halaman paket tersebut.

## Abstraksi Adapter Router

Semua paket framework menggunakan **pola adapter router** untuk memisahkan fungsionalitas i18n dari implementasi router tertentu. Desain ini memungkinkan:

- **Fleksibilitas** - Gunakan library router apa pun atau tanpa router sama sekali
- **Independensi framework** - Simpan logika perutean di aplikasi Anda, bukan di paket i18n
- **Inti ringan** - Paket i18n tetap kecil dan terfokus

### Mengimplementasikan Adapter Router

Untuk menggunakan fitur perutean, Anda perlu mengimplementasikan interface `I18nRoutingStrategy`:

```typescript
interface I18nRoutingStrategy {
  getCurrentPath: () => string
  linkComponent?: Component
  push: (target: { path: string }) => void
  replace: (target: { path: string }) => void
  resolvePath?: (to: string | { path?: string }, locale: string) => string | { path?: string }
  getRoute?: () => { fullPath: string; query: Record<string, unknown> }
}
```

Setiap dokumentasi paket menyertakan contoh lengkap implementasi adapter untuk router populer:

- **Vue**: Contoh adapter Vue Router
- **React**: Contoh adapter React Router
- **Solid**: Contoh adapter Solid Router
- **Astro**: Contoh adapter perutean berbasis file

## Fitur Inti

Semua paket berbagi fitur inti berikut:

### Method Terjemahan

- `t()` - Terjemahan dasar dengan interpolasi parameter
- `ts()` - Terjemahan yang selalu mengembalikan string
- `tc()` - Terjemahan yang sadar pluralisasi
- `tn()` - Pemformatan angka
- `td()` - Pemformatan tanggal
- `tdr()` - Pemformatan waktu relatif
- `has()` - Memeriksa apakah kunci terjemahan ada

### Manajemen Lokal

- **Peralihan lokal** - Mengubah lokal saat ini secara programatik
- **Lokal fallback** - Fallback otomatis saat terjemahan hilang
- **Terjemahan khusus rute** - Organisasi terjemahan tingkat halaman
- **Caching terjemahan** - Caching cerdas untuk performa

### Dukungan TypeScript

Semua paket menyediakan:

- Definisi TypeScript lengkap
- Kunci terjemahan yang aman-tipe (dengan types generator)
- Dukungan IntelliSense di IDE
- Pemeriksaan kesalahan saat kompilasi
