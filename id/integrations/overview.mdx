Paket `@i18n-micro/*` membawa inti terjemahan Nuxt I18n Micro ke Vue, React, Preact, Solid, Astro, VitePress, dan JavaScript biasa. Gunakan paket-paket ini saat aplikasi Anda bukan aplikasi Nuxt, atau saat skrip atau server di luar Nuxt membutuhkan file terjemahan yang sama. Setiap paket berbagi satu model instance, satu kontrak adapter router, dan empat komponen yang sama, yang dijelaskan sekali di halaman ini.

Entri router adalah impor terpisah, sehingga aplikasi tanpa router tidak pernah membundelnya.

`@i18n-micro/core`, `@i18n-micro/types`, dan `@i18n-micro/utils` terpasang bersama paket-paket ini; Anda jarang mengimpornya secara langsung. Signature setiap ekspor ada di [referensi paket](/id/api/packages/overview) yang dihasilkan.

Setiap paket memiliki playground di bawah `packages/<name>/playground` di repositori.

## Instance {#the-instance}

`createI18n(options)` mengembalikan satu instance yang menyimpan kamus, locale saat ini, dan route saat ini. Opsinya sama di setiap paket:

| Opsi | Tipe | Default | Catatan |
| --- | --- | --- | --- |
| `locale` | `string` | wajib | Locale aktif. |
| `fallbackLocale` | `string` | `locale` | Dicari saat kunci tidak ada di `locale`. |
| `messages` | `Record<locale, Translations>` | `{}` | Kamus root (route `'index'`). |
| `routeMessages` | `Record<route, Record<locale, Translations>>` | `{}` | Kamus route. Hanya Runtime, React, Preact, Node, dan VitePress. |
| `plural` | `PluralFunc` | `defaultPlural` | Aturan plural kustom. |
| `missingWarn` | `boolean` | `true` | `console.warn` khusus dev di browser untuk kunci yang hilang. |
| `missingHandler` | `(locale, key, routeName) => void` | — | Dipanggil sebagai pengganti peringatan. |
| `numberFormats` | `Record<locale, Record<name, Intl.NumberFormatOptions>>` | — | Format bernama: `tn(9.5, 'currency')`. |
| `datetimeFormats` | `Record<locale, Record<name, Intl.DateTimeFormatOptions>>` | — | Format bernama: `td(date, 'short')`. |
| `timeZone` | `string` | zona runtime | Zona IANA untuk tanggal `td`; tidak memengaruhi `tdr`. Tetapkan agar server dan browser merender tanggal yang sama. |
| `now` | `() => number` | `Date.now` | Jam untuk `tdr`. Berikan waktu server saat hidrasi agar keduanya merender teks yang sama. |
| `localeIso` | `Record<code, string>` | — | Tag BCP 47 yang digunakan untuk aturan plural (`ua` → `uk-UA`). React, Preact, dan Solid mengambilnya dari `iso` di `locales` milik provider. |

Kamus disimpan di `i18n.storage.translations`, sebuah `Map` dengan kunci `locale:route` (`en:index`, `en:about`).

Sebuah kunci dicari di kamus route saat ini, lalu di kamus root, pertama untuk `locale`, lalu untuk `fallbackLocale`. Kunci yang hilang mengembalikan kunci itu sendiri (atau `defaultValue` yang Anda berikan).

```ts
i18n.addTranslations('en', { nav: { home: 'Home' } }) // root, deep-merged
i18n.addRouteTranslations('en', 'about', { title: 'About us' }) // route chunk
i18n.addTranslations('en', { nav: { home: 'Start' } }, false) // replace instead of merge
i18n.setRoute('about')
i18n.t('title') // 'About us'
i18n.t('nav.home') // 'Start' (root key, still visible on the route)
```

### Menerjemahkan dan memformat {#translate-and-format}

| Method | Mengembalikan |
| --- | --- |
| `t(key, params?, defaultValue?, routeName?)` | Nilai (string, number, objek) dengan `{param}` diinterpolasi. |
| `ts(...)` | Sama seperti `t`, sebagai string. |
| `tc(key, count \| params, defaultValue?)` | Bentuk plural. |
| `tn(value, options \| name)` | `Intl.NumberFormat` dalam locale aktif. |
| `td(value, options \| name)` | `Intl.DateTimeFormat`. |
| `tdr(value, options?)` | Waktu relatif (`3 days ago`). |
| `has(key, routeName?)` | `true` jika locale aktif memiliki kunci tersebut (kamus route atau root; fallback tidak diperiksa). |

`defaultPlural` memecah nilai pada `|` dan memilih bentuk pada indeks `count`, dibatasi ke bentuk terakhir; count negatif, pecahan, atau `NaN` memilih bentuk terakhir.

`plural` kustom menerima `(key, count, params, locale, getter)`. Baca nilai melalui `getter(key)`; jangan memecah kuncinya:

```ts
import type { PluralFunc } from '@i18n-micro/vue'

const plural: PluralFunc = (key, count, params, _locale, getter) => {
  const value = getter(key)
  if (typeof value !== 'string') return null
  const forms = value.split('|').map((form) => form.trim())
  return (count === 1 ? forms[0] : forms[1] ?? forms[0])!.replace('{count}', String(count))
}
```

## Adapter router {#router-adapter}

Paket SPA tidak bergantung pada router. Adapter router (`I18nRoutingStrategy`) memberi tahu mereka cara membaca path saat ini, bernavigasi, dan membangun path yang dilokalkan. Adapter bawaan memberi prefiks pada setiap locale kecuali `defaultLocale` (`/about`, `/de/about`).

| Anggota | Wajib | Digunakan oleh |
| --- | --- | --- |
| `getCurrentPath(): string` | ya | pemeriksaan link aktif (berdasarkan halaman, query dan hash tidak dihitung), `switchLocale` (mempertahankannya) |
| `push({ path }): void` | ya | `switchLocale`, `<I18nLink>` tanpa `linkComponent`, `<I18nSwitcher>` |
| `replace({ path }): void` | ya | — |
| `resolvePath(to, locale)` | tidak | `localePath`, `localeRoute`, `<I18nLink>`; tanpanya path dikembalikan apa adanya |
| `linkComponent` | tidak | `<I18nLink>` merendernya (mis. `RouterLink`) alih-alih `<a>` |
| `getRoute()` | tidak | `{ fullPath, query }` untuk helper SEO |

`push` dan `replace` wajib di Vue, React, Preact, dan Solid. Astro memiliki adapter sisi server sendiri dengan `push`/`replace` opsional (lihat [Astro](/id/integrations/astro-package#router-adapter)).

Adapter minimal untuk router berbasis history apa pun:

```ts
import type { I18nRoutingStrategy } from '@i18n-micro/react'

const locales = ['en', 'de']
const stripLocale = (path: string) => path.replace(/^\/(en|de)(?=\/|$)/, '') || '/'

export const historyAdapter: I18nRoutingStrategy = {
  getCurrentPath: () => window.location.pathname + window.location.search + window.location.hash,
  push: ({ path }) => window.history.pushState({}, '', path),
  replace: ({ path }) => window.history.replaceState({}, '', path),
  resolvePath: (to, locale) => {
    const path = stripLocale(typeof to === 'string' ? to : to.path || '/')
    return locale === 'en' ? path : `/${locale}${path === '/' ? '' : path}`
  },
}
```

## Komponen {#components}

Vue, React, Preact, dan Solid menyertakan empat komponen yang sama. Props-nya sama; React, Preact, dan Solid meneruskan props lain ke elemen root.

### `<I18nT>` {#&lt;i18nt&gt;}

| Prop | Tipe | Catatan |
| --- | --- | --- |
| `keypath` | `string` | wajib |
| `params` | `object` | nilai interpolasi |
| `plural` | `number \| string` | merender `tc(keypath, count)` |
| `number` | `number \| string` | meneruskan `tn(number)` sebagai `{number}` |
| `date` | `Date \| string \| number` | meneruskan `td(date)` sebagai `{date}` |
| `relativeDate` | `Date \| string \| number` | meneruskan `tdr(relativeDate)` sebagai `{relativeDate}` |
| `tag` | `string` | elemen pembungkus, default `span` |
| `html` | `boolean` | merender terjemahan sebagai HTML; terjemahan harus tepercaya, params di-escape |
| `defaultValue` | `string` | menggantikan kunci yang hilang, dan dirender tanpa pembungkus saat `hideIfEmpty` menyembunyikan nilai kosong |
| `hideIfEmpty` | `boolean` | tidak merender apa pun untuk terjemahan kosong |
| `customPluralRule` | `PluralFunc` | aturan plural untuk elemen ini |

Hanya satu prop pemformatan yang berlaku, diperiksa dalam urutan ini: `number`, `date`, `relativeDate`, `plural`.

#### Rich text {#rich-text}

Sebuah `{placeholder}` dapat berisi elemen. Di Vue berupa slot bernama; di React, Preact, dan Solid prop `components` memberikan elemen, atau fungsi yang mengembalikan elemen, berdasarkan nama. Dengan cara mana pun, ini mengalahkan param dengan nama yang sama, berfungsi di setiap cabang, dan tetap bertahan pada locale yang mengubah urutan placeholder.

```tsx
// { "terms": "I accept the {link} of {company}" }
<I18nT keypath="terms" params={{ company: 'ACME' }} components={{ link: <a href="/terms">terms</a> }} />
```

Di Solid berikan fungsi jika sebuah placeholder berulang: satu node hanya dapat menempati satu tempat. `children` menggantikan teks; sebagai fungsi, ia menerima `{ translation }`, seperti slot default Vue. `html` mengabaikan semua ini.

### `<I18nLink>` {#&lt;i18nlink&gt;}

| Prop | Tipe | Catatan |
| --- | --- | --- |
| `to` | `string \| { path }` | dilokalkan melalui `resolvePath` milik adapter |
| `activeStyle` | objek style | digabungkan di atas `style` pada halaman saat ini; React, Preact, dan Solid juga menerapkannya pada bagian di atasnya |
| `localeRoute` | fungsi | menimpa `resolvePath` untuk link ini |

URL eksternal (`https://`, `mailto:`, `tel:`) dirender sebagai `<a target="_blank" rel="noopener noreferrer">`; `target` atau `rel` milik Anda sendiri yang menang. `onClick` selalu dijalankan. Klik dengan tombol pengubah, tombol mouse lain, atau `target` tetap ditangani browser.

### `<I18nSwitcher>` {#&lt;i18nswitcher&gt;}

Dropdown berisi locale aktif (locale dengan `disabled: true` disembunyikan) dengan style default inline. Item-itemnya berupa link, dengan `lang`, `hreflang`, dan `dir` dari locale. Secara default, mengklik salah satunya menetapkan locale dan memanggil `push` milik adapter dengan path saat ini yang dilokalkan; prop `switchLocale` menggantikan aksi tersebut. Dengan `localeRoute` dan tanpa router, browser mengikuti link. Tombol Escape atau klik di luar akan menutupnya.

| Prop | Catatan |
| --- | --- |
| `locales`, `currentLocale`, `getLocaleName` | menimpa nilai yang disediakan |
| `switchLocale(code)` | menggantikan pergantian bawaan |
| `localeRoute` | menggantikan `resolvePath` |
| `customLabels` | `{ de: 'DE' }` |
| `customWrapperStyle`, `customButtonStyle`, `customDropdownStyle`, `customItemStyle`, `customLinkStyle`, `customActiveLinkStyle`, `customDisabledLinkStyle`, `customIconStyle` | penimpaan style |

### `<I18nGroup>` {#&lt;i18ngroup&gt;}

Sebuah `<div class="i18n-group">` yang memberikan `t` berprefiks kepada anak-anaknya. Komponen ini **tidak** memberi prefiks pada `<I18nT>` atau pemanggilan `t()` di dalamnya; hanya `t` yang diteruskannya yang diberi prefiks.

| Prop | Catatan |
| --- | --- |
| `prefix` | wajib, mis. `'profile'` |
| `groupClass` | class tambahan pada pembungkus |

`t` berprefiks diberikan melalui scoped slot di Vue (`v-slot="{ t }"`) dan anak render-prop di React, Preact, dan Solid (`{({ t }) => …}`).

## Kunci bertipe {#typed-keys}

`t()` menerima string apa pun. Untuk mendapatkan autocomplete bagi kunci Anda, hasilkan deklarasi dengan [types generator](/id/integrations/types-generator). Kunci disarankan, bukan diwajibkan, dan params tidak bertipe.

## Dibandingkan dengan modul Nuxt {#compared-with-the-nuxt-module}

Paket-paket ini tidak memiliki routing berbasis file, middleware server, atau loader terjemahan: Anda yang menentukan kapan memuat JSON (`import`, `fetch`, atau `@i18n-micro/node` di server) dan adapter router mana yang digunakan. Deteksi locale, meta SEO, dan pembuatan route adalah fitur Nuxt; Astro memiliki middleware sendiri untuk deteksi dan `useLocaleHead` untuk SEO.
