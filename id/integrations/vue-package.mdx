`@i18n-micro/vue` adalah plugin Vue 3 dengan inti terjemahan Nuxt I18n Micro: `t()` reaktif, `$t` global, empat komponen, dan adapter vue-router opsional. Gunakan di aplikasi Vue Vite atau SSR yang tidak dibangun dengan Nuxt. Model instance, kontrak router, dan props komponen digunakan bersama dengan paket lain dan dijelaskan di [Framework](/id/integrations/overview).

## Instalasi {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vue
```

```bash npm
npm install @i18n-micro/vue
```

```bash yarn
yarn add @i18n-micro/vue
```

</CodeGroup>

Peer dependency: `vue` `^3.3.0`; `vue-router` `^4.5.1 || ^5.0.0` (opsional, hanya untuk `@i18n-micro/vue/router`). Tipe yang dipublikasikan memerlukan Vue 3.5.5 atau lebih baru dengan `skipLibCheck: false`; dengan `skipLibCheck: true`, pengaturan template yang umum, versi yang lebih lama juga dapat dikompilasi.

## Penyiapan {#setup}

```ts
// src/main.ts
import { createApp } from 'vue'
import { createI18n } from '@i18n-micro/vue'
import App from './App.vue'
import en from './locales/en.json'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales: [
    { code: 'en', iso: 'en-US', displayName: 'English' },
    { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
  ],
  defaultLocale: 'en',
})

createApp(App).use(i18n).mount('#app')
```

`locales` dan `defaultLocale` wajib untuk `useI18n()`: tanpa keduanya, fungsi ini melempar `I18nLocalesKey not provided`. Berikan keduanya ke `createI18n` (seperti di atas), ke `useI18n({ locales, defaultLocale })`, atau melalui `app.provide(I18nLocalesKey, …)` dan `app.provide(I18nDefaultLocaleKey, …)`.

Plugin mendaftarkan `I18nT`, `I18nLink`, `I18nGroup`, dan `I18nSwitcher` secara global dan menambahkan `$t`, `$ts`, `$tc`, `$tn`, `$td`, `$tdr`, `$has`, dan `$i18n` ke template. Di luar komponen, instance-nya adalah `i18n.global`. Opsi lainnya ada di [instance](/id/integrations/overview#the-instance); `routeMessages` tidak tersedia di Vue, gunakan `addRouteTranslations`.

## Menerjemahkan {#translate}

```vue
<script setup lang="ts">
import { useI18n } from '@i18n-micro/vue'

const { t, tc, tn } = useI18n()
</script>

<template>
  <h1>{{ t('greeting', { name: 'Ada' }) }}</h1>
  <!-- Hello, Ada! -->
  <p>{{ tc('apples', 3) }}</p>
  <!-- 3 apples -->
  <p>{{ $t('nav.home') }} · {{ tn(1234.5) }}</p>
</template>
```

`useI18n()` mengembalikan metode terjemahan (`t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`), `locale` (computed yang dapat ditulis), `getLocale`, `getLocales`, `defaultLocale()`, `getLocaleName`, `localePath`, `localeRoute`, `switchLocale`, `setRoute`, `getRoute`, `addTranslations`, `addRouteTranslations`, `mergeTranslations`, `resolveTranslations`, `setTranslation`, `clearCache`, dan `instance`.

Muat kamus tambahan kapan saja; setiap komponen yang membacanya akan di-render ulang:

```ts
const { addTranslations, addRouteTranslations, setRoute } = useI18n()

addTranslations('de', (await import('./locales/de.json')).default)
addRouteTranslations('en', 'about', { title: 'About us' })
setRoute('about') // t('title') now reads the 'about' dictionary first
```

## Mengganti locale {#switch-locale}

```ts
const { locale, switchLocale } = useI18n()

locale.value = 'de' // only the locale
switchLocale('de') // the locale, then router.push to the localized current path
```

Muat kamus locale sebelum atau sesudah mengganti; penggantian tidak mengambil apa pun.

`<I18nGroup>` memberikan `t` berprefiks ke slot-nya. Kunci di dalam `<I18nT>` atau `t()` biasa tidak diberi prefiks:

```vue
<I18nGroup prefix="profile" v-slot="{ t }">
  <h2>{{ t('title') }}</h2>
  <!-- profile.title -->
</I18nGroup>
```

## Routing {#routing}

Adapter vue-router berada di subpath sehingga entry utama tidak pernah mengimpor `vue-router`:

```ts
// src/main.ts
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import { createI18n } from '@i18n-micro/vue'
import { createVueRouterAdapter } from '@i18n-micro/vue/router'
import App from './App.vue'
import Home from './pages/Home.vue'
import About from './pages/About.vue'
import en from './locales/en.json'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English' },
  { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
]

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/:locale(de)?', component: Home },
    { path: '/:locale(de)?/about', component: About },
  ],
})

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales,
  defaultLocale: 'en',
  routingStrategy: createVueRouterAdapter(router, locales, 'en'),
})

createApp(App).use(router).use(i18n).mount('#app')
```

`createVueRouterAdapter(router, locales, defaultLocale)` memberi prefiks pada setiap locale kecuali locale default (`/about`, `/de/about`) dan me-render `<I18nLink>` sebagai `RouterLink`. Baca locale dari rute sendiri, misalnya di `router.beforeEach`, lalu atur `i18n.global.locale.value`. Anda juga dapat memasang adapter belakangan dengan `i18n.setRoutingStrategy(adapter)`; untuk adapter kustom lihat [Adapter router](/id/integrations/overview#router-adapter).

## SSR {#ssr}

- Buat router, instance i18n, dan aplikasi di dalam fungsi render per permintaan. Satu instance bersama akan membocorkan locale seorang pengunjung ke pengunjung lain.
- Gunakan `createMemoryHistory()` di server, ambil locale dari URL, dan muat kamusnya (serta kamus fallback) sebelum `renderToString`.
- Kirim locale ke klien (misalnya dalam script `window.__STATE__`) dan buat instance klien dengan `locale` yang sama agar hidrasi cocok.
- `<I18nSwitcher>` hanya membaca `window.location` ketika dropdown terbuka, sehingga komponen ini dapat di-render di server.

`packages/vue/playground` memiliki pasangan `entry-server.ts` / `entry-client.ts` yang lengkap.

## Head SEO {#seo-head}

`useLocaleHead(options)` membangun tag `lang`/`dir`, canonical, `hreflang`, dan `og:locale` dari locale dan adapter router. Panggil `updateMeta()` ketika rute berubah dan berikan `metaObject` ke head manager Anda:

```ts
import { watch } from 'vue'
import { useRoute } from 'vue-router'
import { useHead } from '@unhead/vue'
import { useLocaleHead } from '@i18n-micro/vue'

const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
watch(() => route.fullPath, () => updateMeta(), { immediate: true })
useHead(metaObject)
```

Opsi: `baseUrl` (string atau fungsi), `addDirAttribute` (default `true`), `addSeoAttributes` (default `true`), `identifierAttribute` (default `'id'`), `hreflangBaseLanguage` (default `false`). Locale dengan `disabled: true` atau `seo: false` tidak mendapatkan link alternate.
