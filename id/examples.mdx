# 📚 Contoh dan Penggunaan Nuxt I18n Micro

Bagian ini menyediakan berbagai contoh yang mendemonstrasikan cara menggunakan `Nuxt I18n Micro` di aplikasi Nuxt.js Anda. Anda akan melihat cara mengganti lokal, menggunakan komponen `<i18n-link>`, `<i18n-switcher>`, dan `<i18n-t>`, serta menangani kunci terjemahan secara dinamis.

## 🛠️ Pengaturan Dasar

Berikut pengaturan dasar untuk memulai `Nuxt I18n Micro`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Peralihan Lokal

### Mengganti Lokal Secara Programatik

Contoh ini menunjukkan cara mengganti lokal secara programatik menggunakan tombol:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Contoh JSON untuk Peralihan Lokal

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### Menggunakan Komponen `<i18n-switcher>`

Komponen `<i18n-switcher>` menyediakan dropdown untuk peralihan lokal dengan label yang dapat dikustomisasi:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 🌐 Menggunakan `<i18n-link>` untuk Navigasi Terlokalisasi

Komponen `<i18n-link>` secara otomatis menangani perutean khusus lokal:

```vue
<template>
  <div>
    <i18n-link to="/about">{{ $t('about') }}</i18n-link>
    <i18n-link :to="{ name: 'index' }">{{ $t('home') }}</i18n-link>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Contoh JSON untuk Tautan Navigasi

```json
{
  "about": "About Us",
  "home": "Home"
}
```

### Contoh dengan Gaya Tautan Aktif

```vue
<template>
  <div>
    <i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
  </div>
</template>
```

### Contoh JSON untuk Gaya Tautan Aktif

File JSON yang sama dapat digunakan seperti pada contoh sebelumnya untuk skenario ini.

## 📝 Merender Kunci Dinamis dari File Terjemahan

Dalam beberapa skenario, Anda mungkin ingin mengiterasi kunci dinamis yang disimpan dalam file terjemahan Anda dan merender nilainya secara kondisional. Contoh di bawah menunjukkan cara mencapai hal ini menggunakan `Nuxt I18n Micro`.

### Contoh: Merender Kunci Dinamis

Contoh ini mengambil sebuah array kunci dari jalur terjemahan tertentu (dalam kasus ini, `dynamic`) dan mengiterasi kunci tersebut. Setiap kunci diperiksa keberadaannya menggunakan `$has` sebelum merender nilainya dengan `$t`.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Contoh File Terjemahan (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Contoh: Merender Kunci Dinamis dari Sebuah Objek

Pada contoh ini, kita menangani objek yang disimpan di dalam file terjemahan Anda. Kita mengambil dan mengiterasi kunci-kunci objek, dinamis merender nama kunci dan nilai yang terkait.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Contoh File Terjemahan (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 Menggunakan `<i18n-t>` untuk Terjemahan dengan Slot dan Interpolasi

Komponen `<i18n-t>` berguna untuk merender terjemahan dengan konten dinamis dan tag HTML:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### Contoh JSON untuk `<i18n-t>`

```json
{
  "greeting": "Welcome to the page"
}
```

### Dengan Interpolasi

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### Contoh JSON untuk Interpolasi

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 Menggunakan `$tc` untuk Pluralisasi

Fungsi `$tc` di `Nuxt I18n Micro` menangani pluralisasi berdasarkan hitungan dan pengaturan lokal. Ini berguna untuk secara dinamis menyesuaikan pesan yang melibatkan jumlah, seperti item, notifikasi, atau entitas lain yang dapat bervariasi jumlahnya.

### Contoh: Menggunakan `$tc` untuk Pluralisasi

Pada contoh berikut, kita menampilkan pesan yang menunjukkan jumlah apel menggunakan `$tc`. Kunci terjemahan menangani beberapa bentuk plural berdasarkan hitungan yang diberikan.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### Contoh JSON untuk Pluralisasi

Berikut cara mendefinisikan terjemahan dalam file JSON Anda untuk menangani berbagai bentuk plural:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Penjelasan

- **`$tc('apples', 0)`**: Mengembalikan bentuk pertama, digunakan ketika hitungannya nol (`"no apples"`).
- **`$tc('apples', 1)`**: Mengembalikan bentuk kedua, digunakan ketika hitungannya satu (`"one apple"`).
- **`$tc('apples', 10)`**: Mengembalikan bentuk ketiga dengan nilai hitungan, digunakan ketika hitungannya dua atau lebih (`"10 apples"`).

### Contoh Tambahan dengan Pluralisasi yang Lebih Kompleks

Jika aplikasi Anda perlu menangani aturan pluralisasi yang lebih kompleks (misalnya, kasus khusus untuk zero, one, two, few, many, other), Anda dapat memperluas string terjemahan sesuai kebutuhan:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: Dapat diatur untuk mengembalikan `"two apples"`.
- **`$tc('apples', 3)`**: Dapat mengembalikan `"a few apples"`, tergantung aturan yang didefinisikan untuk hitungan tersebut.

## 🌐 Menggunakan `$tn` untuk Pemformatan Angka

Fungsi `$tn` memformat angka sesuai dengan lokal saat ini menggunakan API `Intl.NumberFormat`. Ini berguna untuk menampilkan angka dengan cara yang sesuai dengan pengaturan regional pengguna, seperti mata uang, persentase, atau format angka lainnya.

### Contoh: Menggunakan `$tn` untuk Pemformatan Angka

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ Menggunakan `$td` untuk Pemformatan Tanggal dan Waktu

Fungsi `$td` memformat tanggal dan waktu sesuai dengan lokal saat ini menggunakan API `Intl.DateTimeFormat`. Ini berguna untuk menampilkan tanggal dan waktu dalam format yang familier bagi pengguna berdasarkan pengaturan lokal mereka.

### Contoh: Menggunakan `$td` untuk Pemformatan Tanggal dan Waktu

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ Menggunakan `$tdr` untuk Pemformatan Tanggal Relatif

Fungsi `$tdr` memformat tanggal sebagai waktu relatif (misalnya, "5 menit yang lalu", "2 hari yang lalu") sesuai dengan lokal saat ini menggunakan API `Intl.RelativeTimeFormat`. Ini berguna untuk menampilkan perbedaan waktu relatif terhadap tanggal dan waktu saat ini.

### Contoh: Menggunakan `$tdr` untuk Pemformatan Tanggal Relatif

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
