# 📚 Contoh dan penggunaan Nuxt I18n Micro

Bagian ini menyediakan berbagai contoh yang menunjukkan cara menggunakan `Nuxt I18n Micro` di aplikasi Nuxt.js Anda. Anda akan melihat cara beralih lokal, menggunakan komponen `<i18n-link>`, `<i18n-switcher>`, dan `<i18n-t>`, serta menangani kunci terjemahan secara dinamis.

## 🛠️ Pengaturan dasar

Berikut pengaturan dasar untuk memulai dengan `Nuxt I18n Micro`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Peralihan lokal

### Beralih lokal secara programatis

Contoh ini menunjukkan cara beralih lokal secara programatis menggunakan tombol:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Contoh JSON untuk peralihan lokal

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### Menggunakan komponen `<i18n-switcher>`

Komponen `<i18n-switcher>` menyediakan dropdown untuk peralihan lokal dengan label yang dapat disesuaikan:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 🌐 Menggunakan `<i18n-link>` untuk navigasi lokal

Komponen `<i18n-link>` secara otomatis menangani perutean khusus lokal:

```vue
<template>
  <div>
    <i18n-link to="/about">{{ $t('about') }}</i18n-link>
    <i18n-link :to="{ name: 'index' }">{{ $t('home') }}</i18n-link>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Contoh JSON untuk tautan navigasi

```json
{
  "about": "About Us",
  "home": "Home"
}
```

### Contoh dengan penataan tautan aktif

```vue
<template>
  <div>
    <i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
  </div>
</template>
```

### Contoh JSON untuk penataan tautan aktif

File JSON yang sama dapat digunakan seperti pada contoh sebelumnya untuk skenario ini.

## 📝 Merender kunci dinamis dari file terjemahan

Dalam beberapa skenario, Anda mungkin ingin mengiterasi kunci dinamis yang disimpan dalam file terjemahan Anda dan merender nilainya secara bersyarat. Contoh di bawah menunjukkan cara mencapai ini menggunakan `Nuxt I18n Micro`.

### Contoh: Merender kunci dinamis

Contoh ini mengambil array kunci dari jalur terjemahan tertentu (dalam kasus ini, `dynamic`) dan mengiterasinya. Setiap kunci diperiksa keberadaannya menggunakan `$has` sebelum merender nilainya dengan `$t`.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Contoh file terjemahan (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Contoh: Merender kunci dinamis dari objek

Dalam contoh ini, kami menangani objek yang disimpan dalam file terjemahan Anda. Kami mengambil dan mengiterasi kunci objek, secara dinamis merender nama kunci dan nilai yang terkait.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Contoh file terjemahan (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 Menggunakan `<i18n-t>` untuk terjemahan dengan slot dan interpolasi

Komponen `<i18n-t>` berguna untuk merender terjemahan dengan konten dinamis dan tag HTML:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### Contoh JSON untuk `<i18n-t>`

```json
{
  "greeting": "Welcome to the page"
}
```

### Dengan interpolasi

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### Contoh JSON untuk interpolasi

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 Menggunakan `$tc` untuk pluralisasi

Fungsi `$tc` di `Nuxt I18n Micro` menangani pluralisasi berdasarkan pengaturan hitungan dan lokal. Ini berguna untuk menyesuaikan pesan secara dinamis yang melibatkan hitungan, seperti item, notifikasi, atau entitas lain yang jumlahnya dapat bervariasi.

### Contoh: Menggunakan `$tc` untuk pluralisasi

Dalam contoh berikut, kami menampilkan pesan yang menunjukkan jumlah apel menggunakan `$tc`. Kunci terjemahan menangani beberapa bentuk plural berdasarkan hitungan yang diberikan.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### Contoh JSON untuk pluralisasi

Berikut cara mendefinisikan terjemahan di file JSON Anda untuk menangani berbagai bentuk plural:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Penjelasan

- **`$tc('apples', 0)`**: Mengembalikan bentuk pertama, digunakan saat hitungan nol (`"no apples"`).
- **`$tc('apples', 1)`**: Mengembalikan bentuk kedua, digunakan saat hitungan satu (`"one apple"`).
- **`$tc('apples', 10)`**: Mengembalikan bentuk ketiga dengan nilai hitungan, digunakan saat hitungan dua atau lebih (`"10 apples"`).

### Contoh tambahan dengan pluralisasi yang lebih kompleks

Jika aplikasi Anda perlu menangani aturan pluralisasi yang lebih kompleks (misalnya, kasus spesifik untuk nol, satu, dua, sedikit, banyak, lainnya), Anda dapat memperluas string terjemahan sesuai:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: Dapat diatur untuk mengembalikan `"two apples"`.
- **`$tc('apples', 3)`**: Dapat mengembalikan `"a few apples"`, tergantung aturan yang didefinisikan untuk hitungan.

## 🌐 Menggunakan `$tn` untuk format angka

Fungsi `$tn` memformat angka sesuai lokal saat ini menggunakan API `Intl.NumberFormat`. Ini berguna untuk menampilkan angka dengan cara yang cocok dengan pengaturan regional pengguna, seperti mata uang, persentase, atau format angka lainnya.

### Contoh: Menggunakan `$tn` untuk format angka

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ Menggunakan `$td` untuk format tanggal dan waktu

Fungsi `$td` memformat tanggal dan waktu sesuai lokal saat ini menggunakan API `Intl.DateTimeFormat`. Ini berguna untuk menampilkan tanggal dan waktu dalam format yang familiar bagi pengguna berdasarkan pengaturan lokal mereka.

### Contoh: Menggunakan `$td` untuk format tanggal dan waktu

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ Menggunakan `$tdr` untuk format tanggal relatif

Fungsi `$tdr` memformat tanggal sebagai waktu relatif (misalnya, "5 menit yang lalu", "2 hari yang lalu") sesuai lokal saat ini menggunakan API `Intl.RelativeTimeFormat`. Ini berguna untuk menampilkan perbedaan waktu relatif terhadap tanggal dan waktu saat ini.

### Contoh: Menggunakan `$tdr` untuk format tanggal relatif

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
