# 🔄 Migrasi dari `nuxt-i18n` ke `Nuxt I18n Micro`

## Panduan mana yang Anda perlukan?

| Anda bermigrasi dari…                | Panduan                                            |
| -------------------------------------- | ------------------------------------------------ |
| `@nuxtjs/i18n` (modul berbasis vue-i18n) | **Halaman ini**                                    |
| `nuxt-i18n-micro` v2.x                 | [Upgrade dari v2.x ke v3.x](/migration/v2-to-v3) |

## Mengapa Bermigrasi?

- **Performa yang lebih baik**: build ~51% lebih cepat dan memori build ~54% lebih sedikit vs `@nuxtjs/i18n` **v10.6** pada [fixture benchmark](/guides/performance-results) kami
- **Konfigurasi yang disederhanakan**: Pengaturan yang efisien dengan default yang masuk akal
- **Manajemen sumber daya yang lebih baik**: Penanganan yang dioptimalkan untuk file terjemahan besar

## Perbedaan Utama

| Fitur                 | `nuxt-i18n`                      | `Nuxt I18n Micro`                         |
| ----------------------- | -------------------------------- | ----------------------------------------- |
| File terjemahan       | JS/TS/JSON, dimuat melalui `vueI18n` | Hanya JSON, dibuat otomatis saat dev          |
| Pembuatan rute        | Runtime                          | Saat build (`@i18n-micro/route-strategy`) |
| Pemuatan terjemahan     | Di-bundle ke JS                  | JSON dimuat lazy per halaman                 |
| State lokal            | `useI18n()` dari `vue-i18n`      | Composable `useI18nLocale()`              |
| `detectBrowserLanguage` | Didukung                        | Gunakan `autoDetectLanguage` sebagai gantinya          |

## Langkah demi Langkah

### 1. Instal

```bash
npm install nuxt-i18n-micro
```

### 2. Perbarui Konfigurasi

**Sebelum (nuxt-i18n):**

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'fr', iso: 'fr-FR' },
    ],
    defaultLocale: 'en',
    vueI18n: './i18n.config.js',
    detectBrowserLanguage: { useCookie: true },
  },
})
```

**Sesudah (Nuxt I18n Micro v3):**

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
    localeCookie: 'user-locale',
    autoDetectLanguage: true,
  },
})
```

### 3. Reorganisasi File Terjemahan

Pindahkan terjemahan ke direktori `locales` dalam format JSON. Berikut perbandingan proyek yang lengkap:

**Before (`nuxt-i18n`):**

```text
my-app/
├── i18n/
│   └── locales/          # langDir
│       ├── en.json       # all translations in one file
│       ├── ru.json
│       └── de.json
├── pages/
│   ├── index.vue
│   └── page.vue
├── server/
│   └── tsconfig.json
├── nuxt.config.ts        # config will change
└── package.json
```

**After (Nuxt I18n Micro):**

```text
my-app/
├── locales/              # translationDir
│   ├── en.json           # root-level translations
│   ├── ru.json
│   ├── de.json
│   └── pages/            # page-specific
│       ├── index/
│       │   ├── en.json
│       │   ├── ru.json
│       │   └── de.json
│       └── page/
│           ├── en.json
│           ├── ru.json
│           └── de.json
├── pages/
│   ├── index.vue         # API changes
│   └── page.vue
├── server/
│   └── tsconfig.json
├── nuxt.config.ts        # new config
└── package.json
```

<Tip>
Missing page-specific translation files are **auto-generated** in development mode — just run `nuxt dev` and the module will create empty JSON files for each page and locale.
</Tip>

### 4. Perbarui Navigasi

```diff
- <nuxt-link :to="{ name: 'index' }">Home</nuxt-link>
+ <NuxtLink :to="$localeRoute({ name: 'index' })">Home</NuxtLink>
+ <!-- or use the built-in component -->
+ <i18n-link :to="{ name: 'index' }">Home</i18n-link>
```

### 5. Perbarui SEO

Hapus konfigurasi SEO manual apa pun dari `nuxt-i18n`. Nuxt I18n Micro menghasilkan `hreflang`, URL canonical, dan tag Open Graph secara otomatis saat `meta: true` disetel.

### 6. Uji

Uji terjemahan, peralihan lokal, pengalihan, dan tag meta SEO secara menyeluruh.

## 🛡️ Masalah Umum dan Pemecahan Masalah

### ❌ File Terjemahan Tidak Dimuat

Pastikan file terjemahan berada di direktori yang benar dan mengikuti format JSON. Verifikasi bahwa `translationDir` cocok dengan lokasi file Anda.

### ⚠️ Kesalahan Rute Tidak Ditemukan

Periksa bahwa semua kode lokal di array `locales` benar dan rute diatur dengan benar.

### 🏷️ Tag SEO Hilang

Verifikasi bahwa `meta: true` disetel dan setiap lokal memiliki kode `iso` yang valid.

### 🔄 Hydration Mismatch

Jika menggunakan strategi `no_prefix`, setel lokal di plugin server dengan `order: -10` menggunakan `useI18nLocale().setLocale()` untuk memastikan server dan klien sepakat tentang lokal. Lihat [Deteksi Bahasa Kustom](/guides/custom-language-detection).

### 🍪 Pengalihan Tidak Berfungsi

Untuk strategi prefix, pastikan `localeCookie: 'user-locale'` disetel. Tanpa cookie, plugin pengalihan server tidak memiliki cara untuk mengingat lokal yang disukai pengguna di seluruh reload halaman.
