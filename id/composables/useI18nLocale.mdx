---
title: "useI18nLocale"
description: "useI18nLocale membaca dan menulis state locale serta cookie locale — titik masuk untuk deteksi locale kustom."
---

`useI18nLocale()` memberikan akses ke locale yang dipilih aplikasi: state `i18n-locale` dan cookie locale. Gunakan di plugin yang mendeteksi locale sendiri (domain, profil pengguna, header) alih-alih menulis `useState('i18n-locale')` atau cookie secara manual. Pemeriksaan validitasnya menggunakan locale yang diaktifkan, termasuk override runtime.

## Signature {#signature}

```ts
useI18nLocale(): { getEffectiveLocale: (route: unknown, getLocaleFromRoute: GetLocaleFromRoute) => string; getLocale: () => string | null; getPreferredLocale: () => string | null; hashCookie: CookieRef; isValidLocale: (locale: string | null | undefined) => locale is string; locale: any; localeCookie: CookieRef; resolveInitialLocale: (options: ResolveInitialLocaleOptions) => string; setLocale: (locale: string | null) => void; syncLocale: (locale: string | null) => void; validLocales: string[] }
```

Titik masuk terpusat untuk manajemen locale i18n.
Menggabungkan useState('i18n-locale'), cookie locale, dan utilitas sinkronisasi.

## Nilai yang dikembalikan {#returned-values}

| Anggota | Tipe | Deskripsi |
| --- | --- | --- |
| `locale` | `Ref<string \| null>` | Ref `useState('i18n-locale')`. |
| `localeCookie` | `Ref<string \| null>` | Cookie [`localeCookie`](/id/api/module-options#localecookie); berupa `{ value: null }` biasa ketika opsinya `null`. |
| `hashCookie` | `Ref<string \| null>` | Cookie `hash-locale` saat hash routing; selain itu `{ value: null }`. |
| `validLocales` | `string[]` | Kode locale yang diaktifkan. |
| `setLocale(locale)` | `(locale: string \| null) => void` | Menulis state dan cookie. Tidak memvalidasi dan tidak memuat terjemahan. |
| `syncLocale(locale)` | `(locale: string \| null) => void` | Hanya menulis cookie. |
| `getLocale()` | `() => string \| null` | State, lalu cookie preferensi (cookie hash saat hash routing). Tidak divalidasi. |
| `getPreferredLocale()` | `() => string \| null` | Nilai **valid** pertama dari state dan cookie preferensi, atau `null`. |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string` | State saat hash routing jika diatur; selain itu `getLocaleFromRoute(route)`. |
| `resolveInitialLocale(options)` | `(options: ResolveInitialLocaleOptions) => string` | `options.urlLocale`, lalu state yang valid, lalu `options.serverLocale`, lalu locale dari rute. Menyimpan hasilnya di state ketika state tidak valid; di klien juga menulis cookie. |
| `isValidLocale(locale)` | `(locale) => locale is string` | Apakah `locale` ada di `validLocales`. |

Cookie berlaku selama satu tahun, dengan `path: '/'` dan `sameSite: 'lax'`.

## Contoh {#example}

```ts
// plugins/locale-from-domain.server.ts
export default defineNuxtPlugin({
  name: 'locale-from-domain',
  enforce: 'pre',
  setup() {
    const { setLocale, isValidLocale } = useI18nLocale()
    const host = useRequestURL().hostname // e.g. de.example.com
    const code = host.split('.')[0]
    if (isValidLocale(code)) setLocale(code)
  },
})
```

Plugin loader milik modul membaca state saat mulai berjalan, sehingga plugin yang mengaturnya harus berjalan lebih dulu (`enforce: 'pre'`). Bagaimana state bersaing dengan URL, cookie, dan `Accept-Language`: [Deteksi locale](/id/guide/locale-detection). Panduan lengkap: [Deteksi kustom](/id/guide/custom-auto-detect).

`setLocale()` tidak mengganti terjemahan yang tampil di layar. Untuk mengubah locale halaman saat ini, panggil [`$switchLocale()`](/id/api/methods#$switchlocale).
