---
title: "useLocaleHead"
description: "useLocaleHead membangun tag SEO i18n (lang, dir, canonical, hreflang, og:locale) sebagai objek yang Anda berikan ke useHead."
---

`useLocaleHead()` membangun tag head i18n untuk route saat ini: `lang` dan `dir` pada `<html>`, link canonical, alternatif `hreflang` dengan `x-default`, `og:url`, `og:locale`, dan `og:locale:alternate`. Gunakan saat Anda menetapkan [`meta: false`](/id/api/module-options#meta) dan mengelola `useHead` sendiri; dengan `meta: true` modul sudah mendaftarkan tag-tag ini, dan perubahan per halaman dilakukan melalui [`useI18nHead`](/id/composables/useI18nHead).

## Signature {#signature}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { build: () => LocaleHead; metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }, LocaleHead | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

Tag head SEO untuk route saat ini: alternatif `hreflang` untuk setiap locale ditambah
`x-default`, link canonical, `og:locale`, serta `lang`/`dir` pada `<html>`.

Hanya diperlukan saat `meta` dinonaktifkan atau default perlu disesuaikan — dengan `meta: true`
modul mendaftarkan tag yang sama dengan sendirinya.

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| `options` | `UseLocaleHeadOptions` |  |

**Mengembalikan** — `metaObject`, ref yang menyimpan objek head siap diberikan ke `useHead`; `updateMeta` menyegarkannya; `build` menghitung objek head dari route saat ini (reaktif saat dibaca di dalam getter, mis. `useHead(() => build())`)

```ts
const { metaObject } = useLocaleHead({ addSeoAttributes: true })
useHead(metaObject)
```

## Opsi {#options}

| Opsi | Default | Deskripsi |
| --- | --- | --- |
| `addDirAttribute` | `true` | Menetapkan `dir` pada `<html>` dari `dir` milik locale (`'auto'` jika tidak ada). |
| `identifierAttribute` | `'id'` | Atribut yang menjadi kunci setiap tag (`i18n-can`, `i18n-og`, `i18n-alternate-<hreflang>`, …), sehingga pembaruan menggantikan tag alih-alih menambahkannya. |
| `addSeoAttributes` | `true` | Menghasilkan tag canonical, `hreflang`, dan `og:`. `false` hanya mempertahankan `htmlAttrs`. |
| `baseUrl` | `'/'` | Origin yang digabungkan ke setiap URL. Biarkan `'/'` untuk URL relatif; berikan `'https://example.com'` untuk URL absolut. |
| `autoUpdate` | `true` | Membangun ulang `metaObject` saat route atau state `i18n-locale` berubah. |

## Apa yang dihasilkan {#what-it-emits}

- Tidak ada apa pun pada route tanpa kecocokan (404) atau dengan `disableMeta` untuk locale aktif.
- Canonical dan `og:url`: `$switchLocalePath(<active locale>)`, query dikurangi menjadi [`canonicalQueryWhitelist`](/id/api/module-options#canonicalquerywhitelist), [`trailingSlash`](/id/api/module-options#trailingslash) diterapkan.
- `hreflang`: satu link per locale aktif tempat halaman tersebut ada, `hreflang = iso || code`, melewati locale dengan `seo: false`; dengan `hreflangBaseLanguage: true` locale regional pertama dari suatu bahasa juga menghasilkan tag bahasa dasarnya. Tidak ada di bawah `no_prefix`.
- `x-default`: URL locale default, kecuali strateginya `no_prefix`, locale default memiliki `seo: false`, atau halaman tidak ada di locale tersebut.
- `og:locale` / `og:locale:alternate`: dari `og` milik locale, atau `iso`-nya yang dikonversi (`en-US` → `en_US`); dilewati dengan peringatan dev jika keduanya tidak berfungsi.

## Contoh {#example}

```ts
// app.vue, with i18n.meta: false
const { metaObject } = useLocaleHead({ baseUrl: 'https://example.com' })
useHead(metaObject)
```

`build()` mengembalikan objek yang sama tanpa ref: `useHead(() => build())` tetap reaktif tanpa watcher.
