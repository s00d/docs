---
title: "useI18n"
description: "useI18n mengembalikan helper runtime (`$t`, `$tc`, `$localePath`, …) sebagai objek biasa, dengan dan tanpa prefiks `$`."
---

`useI18n()` mengembalikan helper runtime modul sebagai objek biasa. Gunakan di `<script setup>`, composable, dan plugin alih-alih memakai `useNuxtApp()`. Setiap helper tersedia dengan nama `$`-nya dan alias tanpa prefiks: `t` dan `$t` adalah fungsi yang sama.

## Signature {#signature}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Setiap helper runtime, sebagai objek biasa.

Fungsi-fungsi yang sama dengan yang diinjeksikan plugin sebagai `$t`, `$tc`, dan seterusnya, tersedia dengan
nama berprefiks dolar maupun alias tanpa prefiks — sehingga `const { t } = useI18n()` dan
`const { $t } = useI18n()` sama-sama berfungsi.

**Mengembalikan** — helper yang dijelaskan di [referensi method](/id/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

Objek yang dikembalikan memuat setiap helper dari [`PluginsInjections`](/id/api/methods). Masing-masing didokumentasikan di halaman [Helper](/id/api/methods).

## Contoh {#example}

```vue
<script setup lang="ts">
const { t, tc, localePath, switchLocale, getLocale } = useI18n()

const title = computed(() => t('page.title'))
</script>

<template>
  <h1>{{ title }}</h1>
  <p>{{ tc('items', 3) }}</p>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
  <button @click="switchLocale(getLocale() === 'en' ? 'de' : 'en')">{{ t('nav.switch') }}</button>
</template>
```

## Tidak ada di tipe {#not-in-the-type}

`$defineI18nRoute` hanya diberi tipe pada `useNuxtApp()`:

```ts
const { $defineI18nRoute } = useNuxtApp()
```
