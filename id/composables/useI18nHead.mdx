`useI18nHead()` mengubah tag SEO yang dihasilkan modul, hanya untuk satu halaman. Gunakan saat sebuah halaman lebih tahu daripada router: artikel CMS yang hanya ada di beberapa locale, URL canonical dari API, tag `og:` tambahan. Anda mendapatkan tag yang dihasilkan dengan override Anda digabungkan di atasnya.

## Signature {#signature}

```ts
useI18nHead(input?: MaybeRefOrGetter<I18nHeadInput | null>): { pageHead: any; resetPageHead: () => void }
```

Mendaftarkan override tingkat halaman untuk tag head SEO i18n.
Digabungkan di atas output `useLocaleHead` oleh plugin `02.meta`.

Utamakan getter (`() => ({ … })`) saat nilai berasal dari `$t` / `t` agar nilainya
di-resolve ulang saat locale berubah. Objek biasa dievaluasi sekali dan tetap beku.

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| `input` *(opsional)* | `MaybeRefOrGetter<I18nHeadInput \| null>` |  |

Ini bekerja dengan [`meta: true`](/id/api/module-options#meta) (default): plugin meta modul menggabungkan input di atas output [`useLocaleHead`](/id/composables/useLocaleHead) pada setiap render head. Dengan `meta: false` tidak ada yang membacanya.

Override di-reset saat nama route berubah. Halaman yang menetapkan `disableMeta` tidak mendapatkan tag i18n sama sekali, termasuk override.

## Input {#input}

`I18nHeadInput` (dari `@i18n-micro/types`):

| Kunci | Tipe | Efek |
| --- | --- | --- |
| `htmlAttrs` | `Record<string, string>` | Digabungkan ke atribut `<html>` (`lang`, `dir`). |
| `meta` | `I18nHeadMeta[]` | Ditambahkan setelah tag yang dihasilkan; menggantikan tag dengan `id`, `property`, atau `name` yang sama. |
| `link` | `I18nHeadLink[]` | Ditambahkan setelah link yang dihasilkan; menggantikan link dengan `id` yang sama, atau `rel` + `hreflang` yang sama. |
| `replace.canonical` | `string \| false` | Mengganti `href` canonical, atau menghapus link-nya. |
| `replace.hreflang` | `I18nHeadLink[] \| false` | Mengganti atau menghapus **setiap** link `rel="alternate"`, termasuk `x-default`. |
| `replace.xDefault` | `I18nHeadLink \| false` | Mengganti atau menghapus link `x-default`. |
| `replace.ogLocale` | `string \| false` | Mengganti atau menghapus `og:locale`. |
| `replace.ogUrl` | `string \| false` | Mengganti atau menghapus `og:url`. |
| `replace.ogAlternates` | `string[] \| false` | Membangun ulang `og:locale:alternate` dari kode locale ini (melalui `og` / `iso`), melewati locale saat ini, kode yang tidak dikenal, dan kode tanpa nilai `og` atau `iso`, atau menghapusnya. |
| `disable` | `I18nHeadDisableGroup[]` | Menghapus grup yang dihasilkan: `'hreflang'` (bukan `x-default`), `'x-default'`, `'canonical'`, `'og'` (`og:locale` + `og:url`), `'og-alternates'`, `'html'`. |

Urutan penerapan: `disable`, lalu `replace`, lalu `htmlAttrs`, `meta`, `link`.

## Contoh {#example}

Artikel yang hanya ada di beberapa locale, dengan URL alternatif dari API:

```vue
<script setup lang="ts">
const route = useRoute()
const { t } = useI18n()
const { data: article } = await useFetch<{ title: string; urls: Record<string, string> }>(`/api/articles/${route.params.slug}`)

useI18nHead(() => {
  if (!article.value) return null
  const codes = Object.keys(article.value.urls)
  return {
    meta: [{ property: 'og:title', content: article.value.title || t('blog.title') }],
    replace: {
      hreflang: codes.map((code) => ({ rel: 'alternate', hreflang: code, href: article.value!.urls[code]! })),
      ogAlternates: codes,
    },
  }
})
</script>
```

Berikan getter, seperti di sini, saat nilai berasal dari `t()` atau data async: getter dijalankan ulang saat locale berubah. Objek biasa hanya dibaca sekali.
