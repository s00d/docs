---
title: "<i18n-switcher>"
description: "Komponen <i18n-switcher> adalah dropdown berisi locale yang diaktifkan, masing-masing menautkan ke halaman saat ini dalam locale tersebut."
---

`<i18n-switcher>` merender tombol dengan locale aktif dan dropdown berisi semua locale yang diaktifkan, termasuk locale aktif. Gunakan komponen ini untuk menu bahasa siap pakai; buat sendiri dari [`$getLocales`](/id/api/methods#$getlocales) dan [`$switchLocalePath`](/id/api/methods#$switchlocalepath) bila Anda membutuhkan markup yang berbeda. Setiap entri menautkan ke halaman saat ini dalam locale tersebut.

## Props dan slot {#props-and-slots}

| Prop | Tipe | Default | Deskripsi |
| --- | --- | --- | --- |
| `customLabels` | `Record<string, string>` | `() => ({})` | Nama tampilan per kode locale, menggantikan `displayName` dari konfigurasi locale. |
| `customWrapperStyle` | `CSSProperties` | `() => ({})` | Gaya inline untuk wrapper terluar. |
| `customButtonStyle` | `CSSProperties` | `() => ({})` | Gaya inline untuk tombol yang membuka dropdown. |
| `customDropdownStyle` | `CSSProperties` | `() => ({})` | Gaya inline untuk panel dropdown. |
| `customItemStyle` | `CSSProperties` | `() => ({})` | Gaya inline untuk setiap item di dropdown. |
| `customLinkStyle` | `CSSProperties` | `() => ({})` | Gaya inline untuk tautan di dalam item. |
| `customActiveLinkStyle` | `CSSProperties` | `() => ({})` | Gaya inline untuk tautan locale yang sedang aktif. |
| `customDisabledLinkStyle` | `CSSProperties` | `() => ({})` | Gaya inline untuk tombol locale *saat ini* ketika locale tersebut bernilai `disabled: true` di konfigurasi. |
| `customIconStyle` | `CSSProperties` | `() => ({})` | Gaya inline untuk ikon caret pada tombol. |

### Slot {#slots}

| Slot | Binding | Deskripsi |
| --- | --- | --- |
| `before-button` | — | Konten sebelum tombol yang membuka dropdown. |
| `before-selected-locale` | — | Konten sebelum label locale aktif di dalam tombol. |
| `after-selected-locale` | — | Konten setelah label locale aktif di dalam tombol. |
| `before-dropdown` | — | Konten di antara tombol dan panel dropdown. |
| `before-dropdown-items` | — | Konten di bagian atas dropdown, di atas daftar locale. |
| `before-item` | `locale` | Konten sebelum setiap entri locale. |
| `before-link-content` | `locale` | Konten sebelum label locale di dalam tautannya. |
| `after-link-content` | `locale` | Konten setelah label locale di dalam tautannya. |
| `after-item` | `locale` | Konten setelah setiap entri locale. |
| `after-dropdown-items` | — | Konten di bagian bawah dropdown, di bawah daftar locale. |
| `after-dropdown` | — | Konten setelah panel dropdown. |

## Perilaku {#behaviour}

- Mencantumkan setiap locale tanpa `disabled: true`, termasuk locale aktif.
- Setiap entri adalah `<a>` ke `$switchLocalePath(code)`. Path di-resolve di bawah `app.baseURL`; `baseUrl` locale di domain lain tetap absolut. Entri memiliki `hreflang` dan `lang` yang diatur ke `iso || code`, `dir` jika locale memilikinya, `aria-current="page"` pada locale saat ini, dan class `switcher-locale-<code>`. Klik memanggil `$switchLocale(code)` dan menutup dropdown; jika disertai tombol modifier, klik diserahkan ke browser.
- Daftar tetap ada di HTML server, dalam keadaan tersembunyi, sehingga crawler dapat melihat tautannya. Tombol Escape atau klik di luar akan menutupnya.
- Label: `customLabels[code]`, lalu `displayName` locale, lalu kodenya (dengan peringatan di mode dev).
- Gaya: default inline kecil (tombol dan panel putih berbingkai, entri aktif tebal dan biru). Setiap prop `custom*Style` diterapkan setelah default dari bagiannya. Tombol memiliki class `i18n-switcher-button` dan `language-switcher`, wrapper `i18n-switcher-wrapper`, dan daftar `i18n-switcher-dropdown`. Posisi menggunakan properti CSS logis, sehingga `dir="rtl"` berfungsi.

## Contoh {#example}

```vue
<template>
  <i18n-switcher
    :custom-labels="{ en: 'English', de: 'Deutsch' }"
    :custom-button-style="{ borderRadius: '4px' }"
  >
    <template #before-link-content="{ locale }">
      <img :src="`/flags/${locale.code}.svg`" alt="" width="16" />
    </template>
  </i18n-switcher>
</template>
```
