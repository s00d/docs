---
title: "<i18n-group>"
description: "Komponen <i18n-group> memberikan slot-nya fungsi t yang dibatasi pada sebuah prefiks key."
---

`<i18n-group>` membatasi satu blok markup pada satu prefiks key. Gunakan saat banyak key dalam satu bagian berbagi prefiks yang sama dan Anda tidak ingin mengulanginya. Slot default menerima `t` yang menambahkan prefiks tersebut di depan.

## Props dan slot {#props-and-slot}

| Prop | Tipe | Default | Deskripsi |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | Prefiks key yang menjadi dasar resolusi setiap pencarian di dalam slot. |
| `groupClass` | `string` | `''` | Class tambahan pada elemen pembungkus. |

**\*** wajib.

### Slot {#slots}

| Slot | Binding | Deskripsi |
| --- | --- | --- |
| `default` | `prefix`, `t` | Menerima `prefix` dan fungsi `t` yang dibatasi padanya. |

## Perilaku {#behaviour}

- Merender `<div class="i18n-group {groupClass}">` di sekitar slot.
- `t(key, params)` adalah `$t(prefix + '.' + key, params)` untuk route saat ini.
- Hanya `t` milik slot yang dibatasi: `$t` dan `<i18n-t>` bersarang di dalam grup tetap menggunakan key lengkap.

## Contoh {#example}

```json
{
  "checkout": { "title": "Checkout", "items": "Items: {count}" }
}
```

```vue
<template>
  <i18n-group prefix="checkout" group-class="checkout">
    <template #default="{ t }">
      <h2>{{ t('title') }}</h2>
      <p>{{ t('items', { count: 3 }) }}</p>
    </template>
  </i18n-group>
</template>
```
