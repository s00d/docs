---
title: "<i18n-t>"
description: "Komponen <i18n-t> merender satu terjemahan, dengan bentuk jamak, format angka dan tanggal, serta interpolasi HTML dan slot."
---

`<i18n-t>` merender satu terjemahan ke dalam sebuah elemen. Gunakan saat terjemahan membutuhkan komponen di dalamnya (link di dalam kalimat), bentuk jamak, atau angka maupun tanggal yang diformat. Komponen ini me-resolve key untuk route saat ini, seperti `$t`.

## Props {#props}

| Prop | Tipe | Default | Deskripsi |
| --- | --- | --- | --- |
| `keypath` **\*** | `string` | — | Key terjemahan yang akan dirender. |
| `plural` | `number \| string \| null` | — | Jumlah yang memilih bentuk jamak. Atur untuk menggunakan `$tc` alih-alih `$t`. `null` berarti tidak diatur. |
| `tag` | `string` | `'span'` | Elemen yang dirender. |
| `params` | `Record<string, string \| number \| boolean>` | — | Nilai interpolasi yang disisipkan ke dalam terjemahan. |
| `defaultValue` | `string` | `''` | Dirender sebagai pengganti komponen ketika `hideIfEmpty` menyembunyikan terjemahan kosong. |
| `html` | `boolean` | `false` | Merender terjemahan sebagai HTML, bukan teks. Hanya untuk terjemahan yang Anda kendalikan: `params` di-escape, terjemahannya tidak. |
| `hideIfEmpty` | `boolean` | `false` | Tidak merender apa pun ketika terjemahan menghasilkan string kosong. |
| `customPluralRule` | `PluralFunc` | `null` | Aturan jamak khusus untuk elemen ini saja, menggantikan yang dikonfigurasi. Hasilnya digunakan apa adanya; `null` merender kosong. |
| `number` | `number \| string \| null` | — | Memformat nilai dengan `$tn` dan meneruskannya ke terjemahan sebagai `{number}`, bersama `params`. |
| `date` | `Date \| string \| number \| null` | — | Memformat nilai dengan `$td` dan meneruskannya ke terjemahan sebagai `{date}`, bersama `params`. |
| `relativeDate` | `Date \| string \| number \| null` | — | Memformat nilai dengan `$tdr` dan meneruskannya ke terjemahan sebagai `{relativeDate}`, bersama `params`. |

**\*** wajib.

## Aturan rendering {#rendering-rules}

Kasus pertama yang cocok menentukan output:

1. `number` — terjemahan dengan `{ ...params, number: $tn(number) }`.
2. `date` — terjemahan dengan `{ ...params, date: $td(date) }`.
3. `relativeDate` — terjemahan dengan `{ ...params, relativeDate: $tdr(relativeDate) }`.
4. `plural` — bentuk yang dipilih `$tc`, termasuk [penanda `=0 `](/id/api/methods#$tc), dengan `{ ...params, count }`; atau `customPluralRule(keypath, count, params, locale, t)` bila diatur, yang membaca nilai mentah termasuk penandanya, dan hasilnya digunakan apa adanya, dengan `null` berarti kosong.
5. Selain itu, terjemahan dengan `params`.

`null` dianggap tidak diatur. Dalam setiap kasus:

- `defaultValue` menggantikan key yang hilang, di setiap cabang.
- `hideIfEmpty` merender `defaultValue` alih-alih hasil kosong.
- `html` merender hasil sebagai HTML. `params` di-escape, terjemahannya tidak; slot diabaikan.
- Slot `default` menerima `{ translation }`, dan slot bernama diabaikan.
- Selain itu, setiap slot bernama menggantikan setiap placeholder `{name}`, sebelum param dengan nama yang sama. Nilai param yang terlihat seperti placeholder tetap menjadi teks.

Output `date` dan `relativeDate` membawa `data-allow-mismatch="text"`, karena zona waktu dan jam server tidak sama dengan milik browser. Atur [`timeZone`](/id/api/module-options#timezone) untuk merender satu tanggal kalender yang sama di keduanya; `relativeDate` bergantung pada jam, sehingga masih bisa berbeda.

## Contoh {#example}

```json
{
  "terms": "I accept the {link}.",
  "termsLink": "terms of use",
  "items": "no items | one item | {count} items"
}
```

```vue
<template>
  <i18n-t keypath="terms" tag="p">
    <template #link>
      <NuxtLink :to="$localePath('/terms')">{{ $t('termsLink') }}</NuxtLink>
    </template>
  </i18n-t>

  <i18n-t keypath="items" :plural="cart.length" />
</template>
```

`html` mengatur `innerHTML`: gunakan hanya untuk terjemahan yang Anda kendalikan. `params` di-escape, sehingga data pengguna aman di sana, begitu pula key yang tidak menemukan terjemahan.
