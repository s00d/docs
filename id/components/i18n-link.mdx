---
title: "<i18n-link>"
description: "Komponen <i18n-link> adalah NuxtLink ke route dalam locale aktif; URL eksternal dibuka di tab baru."
---

`<i18n-link>` merender `NuxtLink` ke `to` dalam locale aktif. Gunakan sebagai pengganti `<NuxtLink :to="$localePath(...)">` di template. URL eksternal menjadi `<a target="_blank" rel="noopener noreferrer">` biasa.

## Props {#props}

| Prop | Tipe | Default | Deskripsi |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | Route tujuan. Dilokalkan secara otomatis; URL eksternal diteruskan tanpa perubahan. |
| `activeStyle` | `CSSProperties` | — | Style inline yang diterapkan selama link mengarah ke route saat ini. |

**\*** wajib.

### Slot {#slots}

| Slot | Binding | Deskripsi |
| --- | --- | --- |
| `default` | — | Konten link. |

## Perilaku {#behaviour}

- `to` diproses melalui [`$localePath`](/id/api/methods#$localepath): sebuah path, named route, atau objek route, dengan path locale kustom diterapkan.
- Eksternal: string yang diawali `http://`, `https://` atau `//`, domain polos (`example.com`), atau link `tel:` / `mailto:`. Domain polos mendapat `https://`, dan string bertitik apa pun tanpa garis miring dianggap sebagai domain: tulis file lokal sebagai `/report.pdf`, bukan `report.pdf`.
- Aktif: ketika `route.path` saat ini sama dengan path yang dilokalkan (query dan hash diabaikan), `activeStyle` diterapkan. Tidak ada class aktif dan tidak ada style aktif default.
- Atribut lain (`class`, `aria-*`) diteruskan ke link.

## Contoh {#example}

```vue
<template>
  <i18n-link to="/about" :active-style="{ fontWeight: 'bold' }">{{ $t('nav.about') }}</i18n-link>
  <i18n-link :to="{ name: 'blog-slug', params: { slug: 'hello' } }">{{ $t('nav.post') }}</i18n-link>
  <i18n-link to="https://github.com/s00d/nuxt-i18n-micro">GitHub</i18n-link>
</template>
```
