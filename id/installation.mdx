## Persyaratan

- **Node.js**: 18 atau lebih baru.
- **Nuxt**: 3.x atau 4.x.

Modul ini mendukung tata letak proyek Nuxt 3 (`pages/**/*.vue`) maupun tata letak Nuxt 4 (`app/pages/**/*.vue`). Berdasarkan konvensi, terjemahan berada di root proyek (`locales/`), bahkan saat menggunakan direktori `app/` Nuxt 4.

## Instal modul Nuxt

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Daftarkan pada `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Lihat [Mulai cepat](/quickstart) untuk panduan lengkap atau [Referensi konfigurasi](/guides/configuration) untuk setiap opsi.

## Tata letak proyek

Secara default modul mengharapkan:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

File tingkat root digabungkan ke setiap file per halaman saat build. File per halaman dibuat otomatis jika belum ada selama `nuxt dev`.

## Tata letak Nuxt 4

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Untuk menempatkan terjemahan bersama di dalam `app/`, atur `translationDir: 'app/locales'`.

## Paket ekosistem

| Paket | Tujuan |
| --- | --- |
| [`@i18n-micro/vue`](/integrations/vue) | Integrasi Vue 3 (mandiri, tanpa Nuxt). |
| [`@i18n-micro/react`](/integrations/react) | Integrasi React. |
| [`@i18n-micro/preact`](/integrations/preact) | Integrasi Preact. |
| [`@i18n-micro/solid`](/integrations/solid) | Integrasi SolidJS. |
| [`@i18n-micro/astro`](/integrations/astro) | Integrasi Astro. |
| [`@i18n-micro/node`](/integrations/nodejs) | Pemuat sisi server Node.js. |
| [`@i18n-micro/types-generator`](/integrations/types-generator) | Menghasilkan tipe TypeScript dari file terjemahan. |
| [`@i18n-micro/devtools-ui`](/integrations/devtools-ui) | Panel DevTools yang agnostik framework. |

Paket internal bersama akan ditarik secara transitif.

## TypeScript

Modul menghasilkan tipe ambient untuk `useI18n`, `$t`, dan helper terkait berdasarkan file locale default Anda. Ini diaktifkan secara default (`types: true`).

Untuk tipe kunci terjemahan yang lebih kuat, lihat [`@i18n-micro/types-generator`](/integrations/types-generator).
