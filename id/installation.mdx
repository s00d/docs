## Persyaratan

- **Node.js**: 18 atau yang lebih baru.
- **Nuxt**: 3.x atau 4.x.

Modul ini mendukung tata letak proyek Nuxt 3 (`pages/**/*.vue`) dan tata letak Nuxt 4 (`app/pages/**/*.vue`). Terjemahan berada di root proyek berdasarkan konvensi (`locales/`), bahkan saat menggunakan direktori `app/` Nuxt 4.

## Instal modul Nuxt

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Daftarkan di `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Lihat [Panduan cepat](/quickstart) untuk penelusuran lengkap atau [Referensi konfigurasi](/guides/configuration) untuk setiap opsi.

## Tata letak proyek

Secara default, modul mengharapkan:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

File tingkat root digabungkan ke setiap file khusus halaman saat waktu build. File khusus halaman dibuat secara otomatis jika tidak ada saat `nuxt dev`.

## Tata letak Nuxt 4

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Untuk mengumpulkan terjemahan di bawah `app/`, atur `translationDir: 'app/locales'`.

## Paket ekosistem

| Paket | Tujuan |

| [`@i18n-micro/vue`](/integrations/vue) | Integrasi Vue 3 (mandiri, tanpa Nuxt). |
| [`@i18n-micro/react`](/integrations/react) | Integrasi React. |

| [`@i18n-micro/types-generator`](/integrations/types-generator) | Menghasilkan tipe TypeScript dari file terjemahan. |
| [`@i18n-micro/devtools-ui`](/integrations/devtools-ui) | Panel DevTools yang agnostik terhadap framework. |

Paket internal bersama ditarik secara transitif.

## TypeScript

Modul menghasilkan tipe ambient untuk `useI18n`, `$t`, dan pembantu terkait berdasarkan file lokal default Anda. Ini diaktifkan secara default (`types: true`).

Untuk pengetikan kunci terjemahan yang lebih kuat, lihat [`@i18n-micro/types-generator`](/integrations/types-generator).
