У `nuxt dev` модуль додає два інструменти налагодження: вкладку **i18n Micro** у Nuxt DevTools для перегляду й редагування файлів перекладів та інспектор Vue DevTools для живої локалі й завантажених словників. Обидва існують лише в режимі розробки й нічого не додають до продакшн-збірок. Для вкладки Nuxt потрібні лише ввімкнені Nuxt DevTools; для інспектора Vue також потрібне браузерне розширення Vue DevTools.

## Вкладка Nuxt DevTools {#nuxt-devtools-tab}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  devtools: { enabled: true }, // the tab is registered only when DevTools are on
})
```

Відкрийте Nuxt DevTools (`Shift + Alt + D`) і виберіть **i18n Micro**. Вкладка показує:

- кожен JSON-файл у `locales/` (корінь і `pages/`) кожного шару, а також кореневі файли з `additionalTranslationDirs`;
- редактор для кожного файлу; **Save** записує файл назад на диск, і сервер розробки перезавантажує переклади;
- **Export** / **Import** файлу у форматі JSON і **Stats** з кількістю ключів і покриттям перекладів;
- перегляд конфігурації з розв'язаними опціями модуля;
- **Translate**, що заповнює відсутні ключі за допомогою рушія машинного перекладу, який ви налаштовуєте в параметрах вкладки.

Збереження записує лише наявні файли `.json` у ваших директоріях перекладів. Якщо файл існує в кількох шарах, записується копія проєкту.

## Інспектор Vue DevTools {#vue-devtools-inspector}

З браузерним розширенням Vue DevTools модуль реєструє інспектор i18n (поточна локаль, чанк маршруту, завантажені ключі) і часову шкалу з перемиканнями локалі, завантаженнями чанків і відсутніми ключами.

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    debug: true, // also log every $t / $ts / $tc call on the timeline
    // vueDevtools: false, // turn the inspector off, keep the Nuxt tab
  },
})
```

[`vueDevtools`](/uk/api/module-options) за замовчуванням має значення `true`. `debug: true` дає багато виводу; використовуйте його лише для коротких сесій.

## Поза Nuxt {#outside-nuxt}

Той самий інтерфейс опубліковано як [`@i18n-micro/devtools-ui`](/uk/integrations/devtools-ui-package) для застосунків Vite, побудованих на пакетах для фреймворків; налаштування описано на тій сторінці.
