Ця сторінка проводить застосунок Nuxt від відсутності i18n до перекладеної сторінки з перемикачем мови. Вона знадобиться вам один раз, на початку проєкту. У результаті ви отримаєте локалізовані URL (`/about`, `/de/about`), по одному JSON-файлу на локаль і сторінку та `$t` у ваших шаблонах.

## Встановлення {#install}

Модулю потрібен Nuxt 3.18 або новіший (Nuxt 4 теж працює) і Node 20 або новіший.

<CodeGroup>

```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>

## Налаштування локалей {#configure-the-locales}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', displayName: 'English' },
      { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
      { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
    ],
    defaultLocale: 'en',
  },
})
```

Це вся конфігурація, яка потрібна першому застосунку. Значення за замовчуванням дають вам:

- `strategy: 'prefix_except_default'`: локаль за замовчуванням не має префікса (`/about`), інші мають (`/de/about`). Див. [Стратегії маршрутизації](/uk/guide/strategy).
- `translationDir: 'locales'`: файли перекладів лежать у `locales/` у корені проєкту, зокрема й зі структурою `app/` у Nuxt 4.
- `meta: true`: теги `hreflang`, canonical і `og:locale`, а також `lang` і `dir` на `<html>`. Див. [SEO](/uk/guide/seo).
- Відвідувача, який відкриває `/`, буде перенаправлено на мову, яку запитує його браузер (`Accept-Language`). Див. [Визначення локалі](/uk/guide/locale-detection).

`iso` — це мовний тег, що використовується в SEO-тегах; `code` — це те, що з’являється в URL. Усі опції перелічено в [Опціях модуля](/uk/api/module-options).

## Додавання файлів перекладів {#add-translation-files}

Запустіть сервер розробки командою `nuxt dev`. Коли Nuxt визначає сторінки, модуль створює порожній файл `{}` для кожної локалі та сторінки, у яких його ще немає (вимкніть це за допомогою [`disableWatcher`](/uk/api/module-options#disablewatcher)):

```text
locales/
├── en.json            # root: keys every page can use
├── de.json
├── fr.json
└── pages/
    ├── index/         # pages/index.vue
    │   ├── en.json
    │   ├── de.json
    │   └── fr.json
    └── about/         # pages/about.vue
        ├── en.json
        ├── de.json
        └── fr.json
```

Заповніть кореневий файл і файл сторінки:

```json
// locales/en.json
{ "nav": { "home": "Home", "about": "About" } }
```

```json
// locales/pages/index/en.json
{ "welcome": "Welcome, {name}!", "items": "no items | one item | {count} items" }
```

Сторінка бачить кореневі ключі та власні ключі; у разі конфлікту перевагу має її власний файл. Назви тек відповідають імені маршруту (`pages/articles/[id].vue` — це `locales/pages/articles-id/`). Структуру, резервні локалі та завантаження описано в розділі [Файли перекладів](/uk/guide/translations).

## Використання `$t` на сторінці {#use-$t-on-a-page}

```vue
<!-- pages/index.vue -->
<script setup lang="ts">
const { t, tc, getLocale } = useI18n()

const title = t('nav.home') // 'Home'
</script>

<template>
  <h1>{{ $t('welcome', { name: 'Ada' }) }}</h1>
  <!-- Welcome, Ada! -->
  <p>{{ $tc('items', 3) }}</p>
  <!-- 3 items -->
  <p>{{ getLocale() }}</p>
  <!-- en -->
</template>
```

- У шаблонах кожен хелпер доступний із `$` (`$t`, `$tc`, `$localePath`, …).
- У `<script setup>` `useI18n()` повертає ті самі хелпери, із `$` і без нього (`t` і `$t` — одна функція). Він імпортується автоматично.
- Плейсхолдери `{name}` заповнюються з об’єкта параметрів. Форми множини розділяються `|`; кількість обирає форму (0, 1, а потім остання для всього, що більше).

Усі хелпери перелічено в розділі [Методи](/uk/api/methods).

## Посилання між сторінками та перемикання локалі {#link-between-pages-and-switch-locale}

```vue
<!-- components/AppHeader.vue -->
<template>
  <nav>
    <i18n-link :to="{ name: 'index' }">{{ $t('nav.home') }}</i18n-link>
    <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
    <i18n-switcher />
  </nav>
</template>
```

- [`<i18n-link>`](/uk/components/i18n-link) — це `NuxtLink`, що вказує на сторінку в поточній локалі: на `/de` посилання about веде на `/de/about`.
- [`<i18n-switcher>`](/uk/components/i18n-switcher) — випадний список увімкнених локалей; він залишає відвідувача на тій самій сторінці.
- Для власних кнопок викликайте `$switchLocale('de')`, що переходить на поточну сторінку німецькою та запам’ятовує вибір. Для звичайного `NuxtLink` використовуйте `$localePath({ name: 'about' })` або `$switchLocalePath('de')`.

## Перевірка {#check-it}

Запустіть `nuxt dev` і відкрийте:

| URL | Показує |
| --- | --- |
| `/` | Англійську головну сторінку (або перенаправлення на `/de`, коли ваш браузер віддає перевагу німецькій) |
| `/de` | Німецьку головну сторінку |
| `/de/about` | Німецьку сторінку about |
| `/en/about` | 404: локаль за замовчуванням не має префікса за `prefix_except_default` |

Зміни у JSON-файлах застосовуються на відкритій сторінці без перезавантаження.
