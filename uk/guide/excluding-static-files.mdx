---
title: "Виключення шляхів"
description: "Виведіть сторінки та файли з-під маршрутизації за локалями за допомогою excludePatterns і дізнайтеся, які шляхи вже виключено."
---

Деякі шляхи ніколи не повинні отримувати префікс локалі чи перенаправлення за локаллю: адмін-панель, health check, згенерована стрічка. `excludePatterns` позначає їх, а вбудований список уже охоплює внутрішні шляхи Nuxt і поширені статичні файли. Виключена сторінка зберігає саме той шлях, який ви написали, і все одно рендериться з `$t`.

## Виключення шляху {#exclude-a-path}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    excludePatterns: [
      '/admin', // /admin and everything below it
      '/preview-*', // glob over the whole path
    ],
  },
})
```

З цією конфігурацією `pages/admin/index.vue` відповідає лише за адресою `/admin`; `/de/admin` не існує, і `/admin` ніколи не перенаправляється на `/de/admin`.

## Синтаксис шаблонів {#pattern-syntax}

Шаблони зіставляються зі шляхом без `app.baseURL`:

| Шаблон | Збігається | Не збігається |
| --- | --- | --- |
| `'/admin'` | `/admin`, `/admin/users` | `/administrator`, `/de/admin` |
| `'/preview-*'` | `/preview-1`, `/preview-a/b` | `/de/preview-1` |
| `'/file-?'` | `/file-a` | `/file-ab` |
| `/^\/v\d+\//` | `/v2/docs` | `/docs` |

Рядок без `*` чи `?` збігається зі шляхом і цілими сегментами під ним. З `*` (будь-яка послідовність символів, включно зі скісними рисками) або `?` (один символ) він має збігатися з усім шляхом. Завжди починайте рядки з `/`.

## Що вже виключено {#what-is-excluded-already}

Ці шляхи ніколи не отримують маршрутів локалей чи перенаправлень, без жодної конфігурації:

- `/api` і `/_nuxt` та все під ними;
- маршрут перекладів, за замовчуванням `/_locales` ([`apiBaseUrl`](/uk/api/module-options#apibaseurl));
- будь-який шлях із сегментом, що починається з `__` (`/__nuxt_content`, `/en/__og-image__`);
- `/sitemap*.xml`, `/robots.txt`, `/favicon.ico`, `/apple-touch-icon*.png`, `/manifest.json`, `/sw.js`, `/workbox-*.js`;
- будь-який шлях, останній сегмент якого закінчується розширенням статичного файлу: `xml txt ico json js css png jpg jpeg gif svg webp avif pdf wasm map mp4 webm mp3 zip gz woff woff2 ttf eot`. Slug-и сторінок із крапками, як-от `/user/john.doe`, і шляхи `.html` залишаються сторінками.

## Що робить виключення {#what-an-exclusion-does}

- **Маршрути:** локалізовані варіанти не генеруються; сторінка залишається такою, як написана.
- **Перенаправлення та 404:** серверний плагін перенаправлень і клієнтський middleware перенаправлень пропускають цей шлях.
- **Пререндеринг:** відповідні шляхи вилучаються зі списку маршрутів для пререндерингу.

Воно не заважає серверному middleware i18n визначати локаль для запиту і не заважає сторінці використовувати переклади. Щоб залишити сторінку локалізованою, але без SEO-тегів, використовуйте `disableMeta` ([Конфігурація сторінки](/uk/guide/per-component-translations#turn-off-seo-tags)). Щоб залишити одну сторінку нелокалізованою з `nuxt.config.ts` за шляхом, `globalLocaleRoutes: { '/admin': false }` ([Локалізовані шляхи](/uk/guide/custom-locale-routes#in-nuxt-config)) робить те саме для маршрутизації.
