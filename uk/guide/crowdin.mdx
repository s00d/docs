[Crowdin](https://crowdin.com/) — це платформа для перекладу: ви завантажуєте файли локалі за замовчуванням, перекладачі працюють у Crowdin, а ви завантажуєте інші локалі назад. Модуль читає звичайні JSON-файли, тож Crowdin CLI потрібен лише `crowdin.yml`, який правильно відображає `locales/` і `locales/pages/`. Жодних змін у налаштуваннях модуля.

## Налаштування crowdin.yml {#configure-crowdin-yml}

```yml
# crowdin.yml
project_id_env: CROWDIN_PROJECT_ID
api_token_env: CROWDIN_PERSONAL_TOKEN
base_path: ./locales
preserve_hierarchy: true

files:
  - source: /en.json
    translation: /%two_letters_code%.json
  - source: /pages/**/en.json
    translation: /pages/**/%two_letters_code%.json
```

- `en` — ваша локаль за замовчуванням; її файли є вихідними.
- `project_id_env` / `api_token_env` читають ID і токен зі змінних середовища, тож жоден секрет не потрапляє в коміт.
- `preserve_hierarchy: true` зберігає папки `pages/<page>/` такими, як вони є.
- Ім'я перекладеного файлу має збігатися з `code` локалі в `nuxt.config.ts`. `%two_letters_code%` підходить для кодів на кшталт `de`; для кодів на кшталт `pt-BR` використовуйте `%locale%` або зіставте коди Crowdin з вашими через `languages_mapping`.

## Вивантаження і завантаження {#upload-and-download}

```bash
npm install -g @crowdin/cli

export CROWDIN_PROJECT_ID=123456
export CROWDIN_PERSONAL_TOKEN=...   # from Crowdin account settings

crowdin upload sources   # push locales/en.json and locales/pages/**/en.json
crowdin download         # write locales/de.json, locales/pages/**/de.json, ...
```

Запускайте обидві команди в CI, щоб файли були актуальними. Завантажені файли потрапляють у ваш репозиторій так само, як відредаговані вручну; наступна збірка або перезавантаження в режимі розробки підхоплює їх.

## Перед вивантаженням {#before-uploading}

Спершу почистіть вихідні файли, щоб перекладачі не працювали з мертвими ключами: [`i18n-micro clean`](/uk/api/cli#clean) видаляє невикористані ключі, [`i18n-micro check`](/uk/api/cli#check) повідомляє про прогалини після завантаження. CLI не має власної інтеграції з Crowdin: ця сторінка описує підтримуваний спосіб.
