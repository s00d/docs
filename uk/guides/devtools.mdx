# 🛠️ DevTools у `nuxt-i18n-micro`

## Vue DevTools (розширення браузера)

У режимі розробки модуль може реєструвати кастомний інспектор та timeline **Vue DevTools** через `@vue/devtools-api`. Це відокремлено від вкладки Nuxt DevTools нижче.

| Інструмент | Найкраще підходить для |
|------|----------|
| **Vue DevTools** | Активна локаль, in-memory кеш перекладів, timeline `$t` (`debug: true`), події про відсутні ключі |
| **Вкладка Nuxt DevTools** | Редагування JSON-файлів на диску, огляд конфігурації, імпорт/експорт |

Плагін vue-devtools реєструється лише під час `nuxt dev` (не у продакшн-збірках). Стан bridge, доступний лише в dev, у основному плагіні видаляється завдяки dead-code elimination через `import.meta.dev`.

Вимкнення інтеграції з браузером зі збереженням вкладки Nuxt:

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

Детальні події timeline для `$t` потребують `debug: true`.

## 📖 Що таке Nuxt DevTools?

DevTools — це потужний асистент розробки, безшовно інтегрований у модуль `nuxt-i18n-micro`. Він надає інтуїтивний інтерфейс для керування завданнями локалізації та перекладу, роблячи ваш робочий процес швидшим та ефективнішим. Розроблений для розробників, які цінують зручність, Nuxt DevTools ліквідує розрив між написанням коду та керуванням під час виконання.

## 🌟 Ключові можливості DevTools у `nuxt-i18n-micro`

### 1. **Керування локалями**

Без зусиль переглядайте, обирайте та керуйте локалями у вашому застосунку. Незалежно від того, чи працюєте ви з однією мовою чи декількома, DevTools надає централізований хаб для обробки всіх налаштувань локалізації.

### 2. **Редагування перекладів**

Редагуйте файли перекладів безпосередньо через інтегрований JSON-редактор. Це усуває потребу у зовнішніх інструментах, дозволяючи оновлення та зміни в реальному часі без переривання вашого робочого процесу.

### 3. **Імпорт та експорт файлів**

Спростіть процес керування файлами перекладів:

- **Експорт**: збереження перекладів як JSON-файлу для резервних копій або зовнішнього використання.
- **Імпорт**: завантаження оновлених файлів перекладів у проєкт, щоб підтримувати актуальність контенту.

### 4. **Попередній перегляд у реальному часі**

Переглядайте зміни негайно у середовищі розробки. Ця можливість гарантує, що переклади та конфігурації є точними ще до виходу в продакшн.

### 5. **Безшовна інтеграція з Nuxt**

DevTools нативно працює з `nuxt-i18n-micro`, розширюючи його можливості без потреби у додатковому налаштуванні. Він адаптується до ваших потреб локалізації, зберігаючи модульну та гнучку структуру Nuxt.

## 🛠️ Навіщо використовувати DevTools?

Nuxt DevTools — незамінне доповнення для проєктів, що потребують локалізації. Він допомагає розробникам, зокрема:

- **Заощаджує час**: автоматизує повторювані завдання, як-от керування файлами та валідацію формату.
- **Зменшує помилки**: надає безпечне, інтуїтивне середовище для редагування перекладів.
- **Покращує співпрацю**: дозволяє нерозробникам легко керувати перекладами.
- **Оптимізує робочі процеси**: обʼєднує кілька завдань локалізації в єдиному інтерфейсі.

## 🚀 Візьміть локалізацію під контроль

З інтегрованим у `nuxt-i18n-micro` Nuxt DevTools керування багатомовними застосунками стає простим та ефективним. Незалежно від того, тонко налаштовуєте ви переклади чи додаєте нові локалі, DevTools забезпечить вас інструментами, потрібними для створення відшліфованого, зручного для користувача досвіду.
