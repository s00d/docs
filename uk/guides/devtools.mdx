# 🛠️ DevTools у `nuxt-i18n-micro`

## Vue DevTools (розширення браузера)

У режимі розробки модуль може реєструвати кастомний інспектор та таймлайн **Vue DevTools** через `@vue/devtools-api`. Це окремо від вкладки Nuxt DevTools нижче.

| Інструмент | Найкраще підходить для |
|------------|-----------------------|
| **Vue DevTools** | Жива локаль, in-memory кеш перекладів, таймлайн `$t` (`debug: true`), події відсутніх ключів |
| **Вкладка Nuxt DevTools** | Редагування JSON-файлів на диску, огляд конфігу, імпорт/експорт |

Плагін vue-devtools реєструється лише під час `nuxt dev` (не у продакшн-збірках). Стан dev-only мосту в основному плагіні відсікається dead-code elimination через `import.meta.dev`.

Вимкнути браузерну інтеграцію, зберігаючи вкладку Nuxt:

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

Детальні події таймлайна `$t` потребують `debug: true`.

## 📖 Що таке Nuxt DevTools?

DevTools — це потужний помічник розробника, безшовно інтегрований у модуль `nuxt-i18n-micro`. Він надає інтуїтивний інтерфейс для керування завданнями локалізації та перекладу, роблячи ваш робочий процес швидшим і ефективнішим. Розроблений для розробників, які цінують зручність, Nuxt DevTools ліквідує розрив між кодуванням та керуванням у рантаймі.

## 🌟 Ключові можливості DevTools у `nuxt-i18n-micro`

### 1. **Керування локалями**

Легко переглядайте, обирайте та керуйте локалями у вашому застосунку. Незалежно від того, чи працюєте ви з однією мовою, чи з кількома, DevTools надає централізований хаб для роботи з усіма налаштуваннями локалізації.

### 2. **Редагування перекладів**

Редагуйте файли перекладів безпосередньо через інтегрований JSON-редактор. Це усуває потребу у зовнішніх інструментах, дозволяючи оновлення у реальному часі без переривання робочого процесу.

### 3. **Імпорт та експорт файлів**

Спростіть процес керування файлами перекладів:

- **Експорт**: збережіть переклади як JSON-файл для резервних копій або зовнішнього використання.
- **Імпорт**: завантажте оновлені файли перекладів у проєкт, щоб тримати вміст актуальним.

### 4. **Перегляд у реальному часі**

Дивіться зміни негайно у середовищі розробки. Ця функція гарантує, що переклади та конфігурації правильні перед публікацією.

### 5. **Безшовна інтеграція з Nuxt**

DevTools нативно працює з `nuxt-i18n-micro`, розширюючи його можливості без потреби у додатковому налаштуванні. Адаптується до ваших потреб локалізації, зберігаючи модульну та гнучку структуру Nuxt.

## 🛠️ Навіщо використовувати DevTools?

Nuxt DevTools — незамінне доповнення для проєктів, які потребують локалізації. Він допомагає розробникам, забезпечуючи:

- **Економію часу**: автоматизує рутинні завдання, як-от керування файлами й валідація формату.
- **Менше помилок**: надає безпечне, інтуїтивне середовище для редагування перекладів.
- **Кращу співпрацю**: дозволяє неперозробникам легко керувати перекладами.
- **Ефективні процеси**: обʼєднує кілька завдань локалізації в один інтерфейс.

## 🚀 Візьміть локалізацію під контроль

З інтеграцією Nuxt DevTools у `nuxt-i18n-micro` керування багатомовними застосунками стає простим та ефективним. Незалежно від того, чи ви тонко налаштовуєте переклади чи додаєте нові локалі, DevTools дає вам інструменти, потрібні для полірованих, дружніх до користувача продуктів.
