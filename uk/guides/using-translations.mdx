# Використання перекладів у компонентах

Після встановлення та налаштування модуля ви можете відображати переклади, викликаючи `$t('your_key')` у ваших Vue-шаблонах та скриптах.

## 1. Файли перекладів кореневого рівня та посторінкові

1. **Кореневі** переклади знаходяться безпосередньо у теці `/locales` (наприклад, `/locales/en.json`, `/locales/fr.json`). На етапі збірки вони автоматично зливаються з кожним посторінковим файлом, стаючи доступними на всіх сторінках.
2. **Посторінкові** переклади зберігаються у `/locales/pages/...`, відповідаючи структурі теки сторінок Nuxt:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. Використання у шаблоні з `$t`

У ваших `.vue`-файлах ви можете безпосередньо використовувати `$t` у шаблоні:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
`$t` може повертати **обʼєкти**, якщо ключ вказує на вкладений JSON-вузол (наприклад, `$t('header')` → `\{ title: "Hi" \}`). У шаблонах це відображається як `[object Object]`. Використовуйте `$ts`, коли вам гарантовано потрібен рядок, або надайте специфічніший ключ, як-от `$t('header.title')`. Див. [Довідник API — $t проти $ts](/api/methods#t) для деталей.
</Tip>

## 3. Перемикання поточної локалі

Щоб змінити мову у вашому застосунку, ви можете отримати `$locale` з `useI18n()` та призначити йому новий код:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. Вкладені ключі та плейсхолдери

- **Вкладені ключі** використовують нотацію з крапками, наприклад `nested.key.deeper`.
- **Плейсхолдери** дозволяють вставляти динамічні значення:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. Поради та найкращі практики

- **Конфліктні ключі**: якщо посторінковий файл містить той самий ключ, що й кореневий файл, посторінкова версія має пріоритет (кореневі переклади зливаються як база на етапі збірки).
- **Вимкнення посторінкових файлів**: якщо ви волієте не використовувати посторінкові переклади, ви можете встановити `disablePageLocales: true` у конфігурації Nuxt. Так використовуватимуться лише файли `/locales/*.json`.
- **Без прямих імпортів**: вам не потрібно робити `import \{ useI18n \} from 'nuxt-i18n-micro'`; функція автоматичної інʼєкції модуля робить це за вас.

Ось і все! Цих кроків достатньо, щоб швидко **почати отримувати переклади** з кореневих або посторінкових JSON-файлів та **відображати їх** у вашому Nuxt-застосунку за допомогою `$t`.

## Додаткові ресурси

Щоб дослідити розширеніші можливості, обовʼязково ознайомтеся з:

1. **Компонент `<i18n-t>`**  
   Компонент `<i18n-t>` — потужна альтернатива `$t`, особливо корисна для ситуацій із вкладеними елементами, розширеним використанням плейсхолдерів та складнішими структурами перекладу.

- **Документація**: [i18n-t](/api/components/i18n-t)

2. **Composable `useI18n`**  
   Composable `useI18n` пропонує повний набір функцій та реактивних властивостей для керування перекладами, обробки перемикання локалей, форматування та іншого.

- **Документація**: [useI18n](/api/composables/use-i18n)
