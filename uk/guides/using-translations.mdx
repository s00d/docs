# Використання перекладів у компонентах

Коли модуль встановлений і налаштований, ви можете відображати переклади, викликаючи `$t('your_key')` у ваших Vue-шаблонах та скриптах.

## 1. Root-файли та посторінкові файли перекладів

1. **Root-переклади** розташовані безпосередньо у теці `/locales` (наприклад, `/locales/en.json`, `/locales/fr.json`). На етапі збірки вони автоматично зливаються у кожен посторінковий файл, роблячись доступними на всіх сторінках.
2. **Посторінкові** переклади живуть під `/locales/pages/...` і відповідають структурі тек сторінок Nuxt:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. Використання в шаблоні з `$t`

У ваших `.vue`-файлах ви можете безпосередньо використовувати `$t` у шаблоні:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
`$t` може повертати **обʼєкти**, якщо ключ вказує на вкладений JSON-вузол (наприклад, `$t('header')` → `\{ title: "Hi" \}`). У шаблонах це рендериться як `[object Object]`. Використовуйте `$ts`, коли вам потрібен гарантований рядок, або задавайте конкретніший ключ на кшталт `$t('header.title')`. Деталі див. у [Довіднику API — $t vs $ts](/api/methods#t).
</Tip>

## 3. Перемикання поточної локалі

Щоб змінити мову у вашому застосунку, ви можете отримати `$locale` з `useI18n()` і присвоїти йому новий код:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. Вкладені ключі та плейсхолдери

- **Вкладені ключі** використовують крапкову нотацію, наприклад `nested.key.deeper`.
- **Плейсхолдери** дозволяють вставляти динамічні значення:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. Поради та кращі практики

- **Конфлікт ключів**: якщо посторінковий файл містить той самий ключ, що й root-файл, версія посторінки має пріоритет (root-переклади зливаються як база на етапі збірки).
- **Вимкнення посторінкових файлів**: якщо ви не хочете використовувати посторінкові переклади, встановіть `disablePageLocales: true` у вашому Nuxt-конфігу. Тоді використовуватимуться лише файли `/locales/*.json`.
- **Без прямих імпортів**: вам не потрібно робити `import \{ useI18n \} from 'nuxt-i18n-micro'`; авто-впорскування модуля робить це за вас.

Ось і все! Зробивши ці кроки, ви можете швидко **почати отримувати переклади** з root- або посторінкових JSON-файлів та **відображати їх** у вашому Nuxt-застосунку за допомогою `$t`.

## Додаткові ресурси

Щоб дослідити більш розширені можливості, обовʼязково перегляньте:

1. **Компонент `<i18n-t>`**  
   Компонент `<i18n-t>` — потужна альтернатива `$t`, особливо корисна для ситуацій з вкладеними елементами, розширеним використанням плейсхолдерів та складнішими структурами перекладів.

- **Документація**: [i18n-t](/api/components/i18n-t)

2. **Композабл `useI18n`**  
   Композабл `useI18n` пропонує повний набір функцій та реактивних властивостей для керування перекладами, перемикання локалей, форматування тощо.

- **Документація**: [useI18n](/api/composables/use-i18n)
