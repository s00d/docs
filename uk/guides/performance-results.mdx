# Результати тестів продуктивності

## Інформація про проєкт

- **[plain-nuxt](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/plain-nuxt)**: ./test/fixtures/plain-nuxt
- **[i18n-micro](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/i18n-micro)**: ./test/fixtures/i18n-micro
- **[i18n](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/i18n)**: ./test/fixtures/i18n
- **[CLI](https://github.com/s00d/nuxt-i18n-micro/tree/main/scripts/src/commands/performance.ts)**: `pnpm -C scripts cli performance` / `pnpm test:performance`

### Опис

Порівнює **plain Nuxt** (baseline без модуля i18n), **i18n-micro** та **`@nuxtjs/i18n` v10.6** під одним спільним профілем словника.

Фокус: час збірки, пікова RSS, розгортуване **коду проти перекладів проти сумарно**, і поведінка сервера під Artillery + Autocannon.

### Нотатки методології

- Метрики — **середні з 3 послідовних запусків на фікстуру** (фікстура A ×3, потім B ×3, потім C ×3 — не по черзі).
- **Переклади** включають JSON-локалі під `locales/` / `_locales/` / `translations/`, все під `chunks/raw/` та відповідні чанки локалей. Старіші звіти, що показували `@nuxtjs/i18n` «translations: 0 B» і величезну колонку «code», зараховували чанки повідомлень до коду застосунку.
- **plain-nuxt** обслуговує той самий обсяг листя як статичний `public/translations` JSON (а не статичні JS-імпорти). Під Artillery ця базова лінія I/O-важка; це не «накладні витрати i18n», це вартість отримання великого JSON на запит.

### Запуски

Всі метрики нижче — **середні по 3 запусках**.

### Профіль фікстури

| Параметр | Значення |
|----------|----------|
| Локалі | **4** (`en`, `de`, `ru`, `fr`) |
| Сторінки | **2** (`index`, `page`) |
| Дерево index | глибина **5**, гілка **7** → **16,807** листкових ключів / локаль |
| Другорядні сторінки | глибина **5**, гілка **6** → **7,776** листкових ключів / сторінка / локаль |
| Мета | Профіль CLI за замовчуванням (`--locales 4 --keys 10000`); підвищуйте параметри для навантажень regression-radar |

Словники беруться з `test/fixtures/perf-shared/runtime.json` (записується CLI), тож усі три фікстури залишаються узгодженими.

## Нотатки

- Спільний профіль: 4 локалі × 2 сторінки × ~16.8k листя index.
- Artillery: 6s прогрів @6 VU/s + 60s основний @60 VU/s. Autocannon: 10 зʼєднань × 10s.
- Повторний запуск: `pnpm test:performance` або `pnpm -C scripts cli performance --locales N --keys K --only all|micro|i18n|plain --runs N`.
