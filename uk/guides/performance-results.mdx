# Результати тестів продуктивності

## Інформація про проєкти

- **[plain-nuxt](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/plain-nuxt)**: ./test/fixtures/plain-nuxt
- **[i18n-micro](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/i18n-micro)**: ./test/fixtures/i18n-micro
- **[i18n](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/i18n)**: ./test/fixtures/i18n
- **[CLI](https://github.com/s00d/nuxt-i18n-micro/tree/main/scripts/src/commands/performance.ts)**: `pnpm -C scripts cli performance` / `pnpm test:performance`

### Опис

Порівнює **plain Nuxt** (базова лінія без i18n-модуля), **i18n-micro** та **`@nuxtjs/i18n` v10.6** за одним спільним профілем словника.

Фокус: час збірки, пікова RSS, розгортуваний **код проти перекладів проти всього**, а також серверна поведінка під Artillery + Autocannon.

### Примітки щодо методології

- Метрики — **середні з 3 послідовних запусків для кожної фікстури** (фікстура A ×3, потім B ×3, потім C ×3 — не з чергуванням).
- **Переклади** включають JSON локалей у `locales/` / `_locales/` / `translations/`, все у `chunks/raw/` та відповідні чанки локалей. Старіші звіти, що показували «translations: 0 B» для `@nuxtjs/i18n` та величезну колонку «code», рахували message-чанки як код застосунку.
- **plain-nuxt** обслуговує той самий обсяг листів як статичний JSON `public/translations` (а не статичні JS-імпорти). Під Artillery ця базова лінія є I/O-важкою; це не «i18n-overhead», це вартість отримання великого JSON на запит.

### Запуски

Усі метрики нижче — **середні по 3 запусках**.

### Профіль фікстури

| Параметр | Значення |
|------|-------|
| Локалі | **4** (`en`, `de`, `ru`, `fr`) |
| Сторінки | **2** (`index`, `page`) |
| Дерево index | глибина **5**, гілкування **7** → **16 807** листових ключів / локаль |
| Вторинні сторінки | глибина **5**, гілкування **6** → **7 776** листових ключів / сторінку / локаль |
| Мета | Профіль CLI за замовчуванням (`--locales 4 --keys 10000`); підвищуйте параметри для навантажень radar-регресії |

Словники приходять з `test/fixtures/perf-shared/runtime.json` (записаний CLI), тож усі три фікстури залишаються узгодженими.

## Примітки

- Спільний профіль: 4 локалі × 2 сторінки × ~16.8k index-листів.
- Artillery: 6s розігрів @6 VU/s + 60s основний @60 VU/s. Autocannon: 10 зʼєднань × 10s.
- Перезапуск: `pnpm test:performance` або `pnpm -C scripts cli performance --locales N --keys K --only all|micro|i18n|plain --runs N`.
