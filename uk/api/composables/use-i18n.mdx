# 🛠️ Композабл `useI18n`

Композабл `useI18n` у `Nuxt I18n Micro` надає доступ до більшості рантайм-помічників i18n у компонентах і скриптах. Методи доступні **з префіксом `$` та без нього** (наприклад, `$t` і `t`).

Деякі впорскування — `$defineI18nRoute` і `$clearCache` — доступні лише через `useNuxtApp()`. Див. [Методи — `$defineI18nRoute`](/api/methods#definei18nroute) та [`$clearCache`](/api/methods#clearcache).

## 📊 Що повертає

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Кожен рантайм-помічник — як звичайний обʼєкт.

Ті самі функції, які плагін впорскує як `$t`, `$tc` тощо, доступні як під іменем з префіксом `$`, так і під голим аліасом. Тому `const \{ t \} = useI18n()` та `const \{ $t \} = useI18n()` обидва працюють.

**Повертає** — помічники, описані у [довіднику методів](/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

Кожен помічник, який він повертає — `$t`, `$tc`, `$has`, `$switchLocale` та інші — перелічений із сигнатурою й повністю задокументований у [довіднику методів](/api/methods).

## API лише через `useNuxtApp()`

Ці **не** повертаються з `useI18n()`. Імпортуйте їх з `useNuxtApp()`:

| Метод                      | Призначення                                                                     |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Посторінкові маршрути локалей, обмеження та інлайн-переклади у `script setup` |
| `$clearCache()`            | Очищає in-memory кеш перекладів і завантажені чанки                             |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Повні сигнатури та приклади див. у [Методах](/api/methods).

## 🛠️ Приклади використання

### Базове отримання локалі

Отримайте поточну локаль застосунку.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Переклад із параметрами

Перекладіть рядок із динамічними параметрами та значенням за замовчуванням.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Перемикання локалей

Перемкніть застосунок на іншу локаль.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Генерація локалізованого маршруту

Згенеруйте маршрут, локалізований до поточної або вказаної локалі.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
