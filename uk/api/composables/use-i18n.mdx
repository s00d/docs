# 🛠️ Composable `useI18n`

Composable `useI18n` у `Nuxt I18n Micro` надає доступ до більшості runtime-помічників i18n у компонентах та скриптах. Методи доступні **як з префіксом `$`, так і без нього** (наприклад, `$t` та `t`).

Деякі інʼєкції — `$defineI18nRoute` та `$clearCache` — доступні лише через `useNuxtApp()`. Див. [Методи — `$defineI18nRoute`](/api/methods#definei18nroute) та [`$clearCache`](/api/methods#clearcache).

## 📊 Що повертає

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Кожен runtime-помічник у вигляді звичайного обʼєкта.

Ті самі функції, які плагін інʼєктує як `$t`, `$tc` тощо, доступні як під імʼям з префіксом-доларом, так і під голим аліасом — тож `const \{ t \} = useI18n()` та
`const \{ $t \} = useI18n()` обидва працюють.

**Повертає** — помічники, описані у [довіднику методів](/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

Кожен помічник, який він повертає — `$t`, `$tc`, `$has`, `$switchLocale` та інші — перелічено з його сигнатурою та детально задокументовано у [довіднику методів](/api/methods).

## API, доступні лише через `useNuxtApp()`

Ці API **не** повертаються з `useI18n()`. Імпортуйте їх із `useNuxtApp()`:

| Метод                      | Призначення                                                                     |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Посторінкові маршрути локалей, обмеження та inline-переклади у `script setup`   |
| `$clearCache()`            | Очищає in-memory кеш перекладів та завантажені чанки                            |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Див. [Методи](/api/methods) для повних сигнатур та прикладів.

## 🛠️ Приклади використання

### Базове отримання локалі

Отримайте поточну локаль застосунку.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Переклад з параметрами

Перекладіть рядок з динамічними параметрами із резервним значенням за замовчуванням.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Перемикання локалей

Перемкніть застосунок на іншу локаль.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Генерація локалізованого маршруту

Згенеруйте маршрут, локалізований до поточної або вказаної локалі.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
