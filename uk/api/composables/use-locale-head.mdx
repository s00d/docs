# 🌍 Композабл `useLocaleHead`

Композабл `useLocaleHead` — це утиліта в `Nuxt I18n Micro`, яка допомагає керувати SEO-атрибутами та HTML мета-тегами для локалізованих маршрутів. Він динамічно генерує атрибути `lang` та `dir` HTML-документа і створює теги `meta` й `link` для покращення SEO вашого локалізованого контенту.

SEO head-теги для поточного маршруту: `hreflang`-альтернативи для кожної локалі плюс `x-default`, canonical-посилання, `og:locale`, а також `lang`/`dir` на `<html>`.

Потрібно лише коли `meta` вимкнено або значення за замовчуванням потребують корекції. З `meta: true` модуль реєструє ті самі теги самостійно.

## 🛠️ Повернені значення

Композабл `useLocaleHead` повертає реактивний обʼєкт та функцію-оновлювача, яку слід викликати, коли змінюються вхідні дані. Обидві форми є у сигнатурі вище, згенерованій з вихідного коду.

### `metaObject`

Реактивний head-пейлоад (html-атрибути, meta, link), придатний для `useHead(metaObject)`.

- **Приклад**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

Перераховує `metaObject` на основі поточного маршруту, локалі та конфігурації. Викликайте його, коли змінюються входи, наприклад під час зміни маршруту.

- **Приклад**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### Доступ до `link` та `meta`

Масиви `link` та `meta` доступні через `metaObject.value`:

- **Приклад**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ Приклади використання

### Базове використання

Згенеруйте head-атрибути для конкретної локалі з опціями за замовчуванням.

```js
const head = useLocaleHead()
```

### Налаштувати атрибут-ідентифікатор

Використайте кастомний атрибут-ідентифікатор для згенерованих тегів.

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### Вимкнути SEO-атрибути

Згенеруйте head-атрибути без додавання SEO-повʼязаних meta- та link-тегів.

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### Задати базовий URL

Задайте кастомний базовий URL для canonical- та альтернативних URL.

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 Додаткові можливості

### SEO meta- та link-теги

Коли `addSeoAttributes` увімкнено, композабл автоматично генерує такі теги:

- `og:locale` для поточної локалі (`language_TERRITORY`, з підкресленням). Виводиться з `locale.og` або конвертується з `locale.iso` за можливості.
- `og:url` для канонічного URL сторінки.
- `og:locale:alternate` для альтернативних мовних версій.
- Посилання `rel="canonical"` та `rel="alternate"` для SEO-оптимізації.
- Посилання `hreflang="x-default"`, що вказує на URL локалі за замовчуванням. Це повідомляє пошуковим системам, який URL показати користувачам, чия мова не збігається з жодною з визначених локалей.

### Динамічна локаль та напрямок

Композабл динамічно визначає атрибути `lang` та `dir` на основі локалі поточного маршруту, забезпечуючи, що ваш HTML-документ правильно налаштовано для міжнародних користувачів.

### Обробка локалізованих маршрутів

Якщо ваші маршрути мають префікси з кодами локалей (наприклад, `/en/about`), композабл інтелектуально коригує повний шлях для генерації URL, забезпечуючи точність і релевантність SEO-атрибутів.

Цей композабл спрощує процес оптимізації вашого Nuxt-застосунку для міжнародної аудиторії, забезпечуючи, що сайт добре підготовлений для глобальних пошукових систем та користувачів.

## 🛠️ Приклад використання

Наступний приклад демонструє, як використати композабл `useLocaleHead` у Vue-компоненті з налаштуваннями за замовчуванням:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### Пояснення коду

- **Композабл `useLocaleHead`**: викликається у секції `<script setup>` та повертає обʼєкт, що містить `htmlAttrs`, `meta` та `link`.

- **Тег `<html>`**: атрибути `lang` та `dir` для HTML-документа визначаються динамічно на основі поточної локалі та застосовуються до тегу `<html>`.

- **Секція `<head>`**:
  - **Мета-теги**: генеруються SEO-повʼязані мета-теги, включно з `og:locale`, `og:url`, а також теги `rel="canonical"` та `rel="alternate"` для вказання альтернативних мовних версій сторінки.
  - **Link-теги**: включаються canonical-посилання, посилання на альтернативні мовні версії та посилання `hreflang="x-default"` (що вказує на URL локалі за замовчуванням).

- **Секція `<body>`**: тут відображається основний вміст сторінки. У цьому прикладі використано простий заголовок та абзац.

### 📝 Нотатки

1. **Атрибути**: використані атрибути (`lang`, `dir`, `rel`, `href`, `hreflang`, `property`, `content`) витягуються з обʼєкта, що повертає `useLocaleHead`.

2. **Генерація SEO-тегів**: якщо опцію `addSeoAttributes` встановлено у `true`, композабл автоматично генерує SEO-теги для поточної локалі.

3. **Базовий URL**: ви можете задати свій кастомний базовий URL через опцію `baseUrl`, щоб коректно генерувати canonical- та альтернативні посилання.

Цей приклад показує, наскільки легко інтегрувати `useLocaleHead` у компоненти вашого застосунку, щоб забезпечити правильні SEO-атрибути та покращити індексацію локалізованих сторінок пошуковими системами.

## 🧩 Кастомізація та життєвий цикл

- `useLocaleHead` не підписується на зміни самостійно. Він повертає `metaObject` та `updateMeta`.
- Ви маєте викликати `updateMeta()`, коли змінюються входи (зазвичай при зміні маршруту), наприклад з плагіна:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## Коли використовувати `useI18nHead` натомість

Коли `meta: true` (за замовчуванням), надавайте перевагу [`useI18nHead`](/api/composables/use-i18n-head) для **посторінкових** перевизначень (кастомний hreflang, додатковий `og:title`, часткове вимкнення). Використовуйте `useLocaleHead` напряму лише коли `meta: false` або ви керуєте `useHead` самостійно.
