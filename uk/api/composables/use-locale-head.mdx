# 🌍 Composable `useLocaleHead`

Composable `useLocaleHead` — це утиліта у `Nuxt I18n Micro`, яка допомагає керувати SEO-атрибутами та HTML-мета-тегами для локалізованих маршрутів. Він динамічно генерує атрибути `lang` та `dir` HTML-документа і створює теги `meta` та `link` для покращення SEO вашого локалізованого контенту.

SEO head-теги для поточного маршруту: альтернативи `hreflang` для кожної локалі плюс
`x-default`, canonical-посилання, `og:locale` та `lang`/`dir` на `<html>`.

Потрібно лише коли `meta` вимкнено або значення за замовчуванням потребують коригування — з `meta: true`
модуль реєструє ті самі теги сам.

## 🛠️ Значення, що повертаються

Composable `useLocaleHead` повертає реактивний обʼєкт та функцію оновлення, яку слід
викликати, коли змінюються вхідні дані. Обидві форми наведені у сигнатурі вище, згенеровані з
джерела.

### `metaObject`

Реактивний head-payload (html-атрибути, meta, link), придатний для `useHead(metaObject)`.

- **Приклад**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

Перераховує `metaObject` на основі поточного маршруту, локалі та конфігурації. Викликайте його, коли змінюються вхідні дані — наприклад, при зміні маршруту.

- **Приклад**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### Доступ до `link` та `meta`

Масиви `link` та `meta` доступні через `metaObject.value`:

- **Приклад**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ Приклади використання

### Базове використання

Згенерувати head-атрибути, специфічні для локалі, зі значеннями за замовчуванням.

```js
const head = useLocaleHead()
```

### Кастомізація атрибута ідентифікатора

Використовувати кастомний атрибут ідентифікатора для згенерованих тегів.

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### Вимкнення SEO-атрибутів

Згенерувати head-атрибути без додавання SEO-повʼязаних мета- та link-тегів.

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### Задання базового URL

Встановити кастомний базовий URL для canonical- та альтернативних URL.

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 Додаткові можливості

### SEO мета- та link-теги

Коли `addSeoAttributes` увімкнено, composable автоматично генерує наступні теги:

- `og:locale` для поточної локалі (`language_TERRITORY`, з підкресленням). Похідне від `locale.og` або конвертоване з `locale.iso`, коли можливо.
- `og:url` для canonical URL сторінки.
- `og:locale:alternate` для альтернативних мовних версій.
- Посилання `rel="canonical"` та `rel="alternate"` для SEO-оптимізації.
- Посилання `hreflang="x-default"`, що вказує на URL локалі за замовчуванням. Це повідомляє пошуковим системам, який URL показувати користувачам, чия мова не збігається з жодною з визначених локалей.

### Динамічна локаль та напрямок

Composable динамічно визначає атрибути `lang` та `dir` на основі локалі поточного маршруту, забезпечуючи, що ваш HTML-документ коректно налаштований для міжнародних користувачів.

### Обробка локалізованих маршрутів

Якщо ваші маршрути мають префікси з кодами локалей (наприклад, `/en/about`), composable інтелектуально коригує повний шлях для генерації URL, забезпечуючи, що SEO-атрибути є точними та релевантними.

Цей composable спрощує процес оптимізації вашого Nuxt-застосунку для міжнародної аудиторії, забезпечуючи, що ваш сайт добре підготовлений для глобальних пошукових систем та користувачів.

## 🛠️ Приклад використання

Наступний приклад демонструє, як використовувати composable `useLocaleHead` всередині Vue-компонента з налаштуваннями за замовчуванням:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### Пояснення коду

- **Composable `useLocaleHead`**: цей composable викликається в секції `<script setup>` і повертає обʼєкт, що містить `htmlAttrs`, `meta` та `link`.

- **Тег `<html>`**: атрибути `lang` та `dir` для HTML-документа динамічно визначаються на основі поточної локалі та застосовуються до тегу `<html>`.

- **Секція `<head>`**:
  - **Мета-теги**: генеруються SEO-повʼязані мета-теги, включно з `og:locale`, `og:url` та `rel="canonical"` і `rel="alternate"`-тегами для вказання альтернативних мовних версій сторінки.
  - **Link-теги**: включаються canonical-посилання, посилання на альтернативні мовні версії та посилання `hreflang="x-default"` (яке вказує на URL локалі за замовчуванням).

- **Секція `<body>`**: тут відображається основний вміст сторінки. У цьому прикладі використано простий заголовок та абзац.

### 📝 Примітки

1. **Атрибути**: використовувані атрибути (`lang`, `dir`, `rel`, `href`, `hreflang`, `property`, `content`) вилучаються з обʼєкта, поверненого `useLocaleHead`.

2. **Генерація SEO-тегів**: якщо опція `addSeoAttributes` встановлена в `true`, composable автоматично генерує SEO-теги для поточної локалі.

3. **Базовий URL**: ви можете встановити свій кастомний базовий URL за допомогою опції `baseUrl` для коректної генерації canonical- та альтернативних посилань.

Цей приклад демонструє, наскільки легко інтегрувати `useLocaleHead` у компоненти вашого застосунку, щоб забезпечити коректні SEO-атрибути та покращити індексацію локалізованих сторінок пошуковими системами.

## 🧩 Кастомізація та життєвий цикл

- `useLocaleHead` не підписується на зміни сам. Він повертає `metaObject` та `updateMeta`.
- Вам слід викликати `updateMeta()`, коли змінюються вхідні дані (зазвичай при зміні маршруту), наприклад, з плагіна:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## Коли використовувати `useI18nHead` замість цього

Коли `meta: true` (за замовчуванням), надавайте перевагу [`useI18nHead`](/api/composables/use-i18n-head) для **посторінкових** перевизначень (кастомний hreflang, додатковий `og:title`, часткове вимкнення). Використовуйте `useLocaleHead` безпосередньо лише коли `meta: false` або ви керуєте `useHead` самі.
