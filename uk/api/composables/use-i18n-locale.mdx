# useI18nLocale

## Сигнатура

Централізована точка входу для керування локаллю i18n.
Обʼєднує useState('i18n-locale'), cookie локалі та утиліти синхронізації.

## API

| Властивість/Метод                               | Тип                                 | Опис                                                                                 |
| ----------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| `locale`                                        | `Ref<string \| null>`               | Реактивний стан локалі (`useState('i18n-locale')`)                                   |
| `localeCookie`                                  | `Ref`                               | Cookie локалі (коли увімкнено опцію `localeCookie`)                                  |
| `hashCookie`                                    | `Ref`                               | Cookie, що використовується, коли активний `hashMode`                                |
| `validLocales`                                  | `string[]`                          | Коди увімкнених локалей із конфігурації модуля (виключаючи `disabled`)               |
| `getLocale()`                                   | `() => string \| null`              | Поточна локаль: стан → cookie (або hash-cookie у hash-режимі)                        |
| `getPreferredLocale()`                          | `() => string \| null`              | Локаль зі стану/cookie **валідована** відносно `validLocales`, або `null`            |
| `getLocaleWithServerFallback(serverLocale?)`    | `(serverLocale?) => string \| null` | Стан → cookie → опціональний серверний контекст (використовується під час ініціалізації `no_prefix`) |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string`             | Локаль для завантаження перекладів: hash-режим надає перевагу стану; інакше — читає з маршруту |
| `resolveInitialLocale(options)`                 | `(options) => string`               | Розвʼязує локаль: стан → `serverLocale` → маршрут; синхронізує стан за потреби       |
| `setLocale(locale)`                             | `(locale: string \| null) => void`  | Встановлює локаль і синхронізує з cookies                                            |
| `syncLocale(locale)`                            | `(locale: string \| null) => void`  | Синхронізує лише cookies (без оновлення стану)                                       |
| `isValidLocale(locale)`                         | `(locale) => boolean`               | Перевіряє, чи рядок є у `validLocales`                                               |

### Опції `resolveInitialLocale`

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

Використовується внутрішньо основним плагіном під час старту. Кастомні плагіни можуть викликати її при реалізації альтернативних потоків визначення локалі.

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

Повертає локаль, що використовується для завантаження перекладів та форматування повідомлень для заданого обʼєкта маршруту.

## Програмне встановлення локалі

Надавайте перевагу `useI18nLocale()` над прямим використанням `useState('i18n-locale')`:

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
`setLocale()` оновлює лише уподобання локалі (стан + cookie). Щоб також перезавантажити активний контекст перекладу на клієнті, використовуйте `$switchLocale()` з `useNuxtApp()` або `useI18n()`. Це особливо важливо для `no_prefix`, де URL не змінюється. Див. [FAQ — переключення локалі без зміни URL](/guides/faq#-switch-locale-without-changing-the-url).
</Tip>
