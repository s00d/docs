---
title: "Хелпери"
description: "Кожен runtime-хелпер, який впроваджує модуль, — `$t`, `$tc`, `$localePath`, `$switchLocale` та інші — з його сигнатурою."
---

Модуль впроваджує свої runtime-хелпери в застосунок Nuxt: `$t`, `$tc`, `$localePath`, `$switchLocale` та інші. Використовуйте цю сторінку, щоб знайти сигнатуру та поведінку хелпера. Сигнатури й описи взято з інтерфейсів `PluginsInjections` і `NuxtAppOnlyInjections` у `src/runtime/plugins/01.plugin.ts`.

## Доступ {#access}

| Де | Як |
| --- | --- |
| Шаблон | `{{ $t('title') }}` — кожен хелпер, із `$` |
| `<script setup>` | `const { t, localePath } = useI18n()` — кожен хелпер із `PluginsInjections`, із `$` і без нього |
| Плагін, middleware, `<script setup>` | `const { $t, $defineI18nRoute } = useNuxtApp()` — усе, лише з `$` |

`$defineI18nRoute` типізовано лише в `useNuxtApp()`. Див. [`useI18n`](/uk/composables/useI18n).

```vue
<script setup lang="ts">
const { t, localePath } = useI18n()
</script>

<template>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
</template>
```

## Локаль {#locale}

### `$getLocale` {#$getlocale}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric) => string
```

Код активної локалі. Передайте маршрут, щоб зчитати локаль, до якої належить цей маршрут.

```ts
$getLocale() // 'de' on /de/about
```

### `$getLocaleName` {#$getlocalename}

```ts
() => string | null
```

`displayName` активної локалі з конфігурації або `null`, якщо його немає.

### `$getLocales` {#$getlocales}

```ts
() => Locale[]
```

Усі налаштовані локалі з їхніми метаданими.

Власні властивості об’єкта локалі повертаються так, як їх записано; типізуйте їх за допомогою [розширення модуля](/uk/api/module-options#locales) для `Locale`.

### `$defaultLocale` {#$defaultlocale}

```ts
() => string | undefined
```

Код налаштованої локалі за замовчуванням.

### `$getI18nConfig` {#$geti18nconfig}

```ts
() => ResolvedI18nConfig
```

Визначена конфігурація модуля, як її бачить runtime.

Значення включає [runtime-перевизначення](/uk/guide/runtime-overrides) (`defaultLocale`, `fallbackLocale`, вимкнені локалі).

```ts
const { strategy, localeCookie } = useNuxtApp().$getI18nConfig()
```

## Переклад {#translation}

### `$t` {#$t}

```ts
TranslationFn<CleanTranslation>
```

Перекладає ключ, підставляючи в нього `params`. Повертає `defaultValue`, коли ключа
немає, або сам ключ, коли значення за замовчуванням не задано.

```ts
// { "welcome": "Welcome, {name}!" }
$t('welcome', { name: 'Ada' }) // 'Welcome, Ada!'
$t('missing.key', {}, 'Fallback') // 'Fallback'
```

Ключ, що вказує на вкладений об’єкт, повертає цей об’єкт, а не рядок. У шаблоні він рендериться як `[object Object]`; використовуйте листовий ключ.

### `$ts` {#$ts}

```ts
TranslationFn<string>
```

Як `$t`, але завжди повертає рядок: значення проходить через `toString()`, тож вкладений
об’єкт стає `'[object Object]'`. Спрямовуйте ключ на лист.

### `$_t` {#$_t}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<CleanTranslation>
```

Прив’язує `$t` до конкретного маршруту, щоб перекладати поза поточною сторінкою — наприклад, у layout,
що рендерить посилання на інший маршрут.

```ts
const route = useRoute()
const t = useNuxtApp().$_t(route)
t('page.title')
```

### `$_ts` {#$_ts}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<string>
```

Прив’язує `$ts` до конкретного маршруту. Див. `$_t`.

### `$tc` {#$tc}

```ts
(key: TranslationKey, params: number | Params, defaultValue?: string) => string
```

Перекладає з урахуванням множини. `params` може бути самою кількістю або об’єктом, що містить
`count`.

Форми розділяються `|`. Із вбудованим правилом невід’ємна ціла кількість `n` обирає форму `n`, обмежену останньою формою; від’ємна, дробова кількість або `NaN` бере останню форму. `{count}` та інші параметри підставляються в обрану форму.

Для мов, у яких множина не відповідає кількості напряму, починайте шаблон із `=0 `. Тоді перша форма призначена для 0, а інші відповідають категоріям [`Intl.PluralRules`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/PluralRules) у порядку `zero, one, two, few, many, other`:

```json
{
  "apples": "=0 no apples | one apple | {count} apples",
  "files": "=0 no files | {count} one | {count} few | {count} many"
}
```

```ts
$tc('apples', 0) // 'no apples'
$tc('apples', 1) // 'one apple'
$tc('apples', 7) // '7 apples'

// In `uk` (categories `one, few, many, other`) the forms after the zero form follow those categories:
$tc('files', 21) // '21 one'
$tc('files', 22) // '22 few'
$tc('files', 25) // '25 many'
$tc('files', 2.5) // '2.5 many': no form for `other`, so the last one
```

- `=0 ` враховується лише на самому початку значення, разом із пробілом. `$t` показує його як текст: він належить до множини.
- Категорія без власної форми бере останню форму. Від’ємна або дробова кількість теж бере останню форму.
- Це працює в будь-якій локалі: `=0 none | one | {count} many` англійською.
- Категорія визначається за `iso` локалі, інакше за її кодом. Код, якого не знає `Intl`, повертається до індексного правила, а маркер усе одно видаляється, тож результат ніколи не залежить від машини.
- `<i18n-t :plural>` дотримується того самого правила. Власне правило [`plural`](/uk/api/module-options#plural) або `customPluralRule` отримує сире значення разом із маркером і вирішує самостійно; якщо `plural` повертає `null`, виклик передається вбудованому правилу, яке враховує маркер.

Без маркера шаблон залишається на індексному правилі, з одним винятком, який можна прочитати лише одним способом: нульова форма без плейсхолдера, потім по одній формі на категорію, з `{count}` у кожній формі, яку ділять кілька кількостей (`no files | {count} one | {count} few | {count} many` в `uk`).

Для власних правил налаштуйте [`plural`](/uk/api/module-options#plural).

```ts
// { "apples": "no apples | one apple | {count} apples" }
$tc('apples', 0) // 'no apples'
$tc('apples', 10) // '10 apples'
$tc('cart', { count: 2, name: 'Ada' }) // count and params in one object
```

Третій аргумент — це `defaultValue`, а не параметри.

### `$has` {#$has}

```ts
(key: string) => boolean
```

Чи визначається ключ в активній локалі. Використовуйте його, щоб розгалужувати необов’язковий текст замість
рендерингу сирого ключа. Як і `$t`, він також бачить ключі сторінки, яку покидають, під час переходу між сторінками
в межах тієї самої локалі.

```ts
if ($has('promo.banner')) show.value = true
```

## Форматування {#formatting}

### `$tn` {#$tn}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Форматує число за допомогою `Intl.NumberFormat` в активній локалі. Ключ обирає іменований формат
із конфігурації.

Іменовані формати беруться з [`numberFormats`](/uk/api/module-options#numberformats).

```ts
$tn(1234.5, { style: 'currency', currency: 'EUR' }) // '1.234,50 €' in de
$tn(1000, 'currency') // named format
$tn(1000, 'currency', 'de') // named format in another locale
```

### `$td` {#$td}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Форматує дату за допомогою `Intl.DateTimeFormat` в активній локалі. Ключ обирає іменований формат
із конфігурації.

Іменовані формати беруться з [`datetimeFormats`](/uk/api/module-options#datetimeformats).

```ts
$td(new Date(), { dateStyle: 'long' })
$td(post.createdAt, 'short')
```

### `$tdr` {#$tdr}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

Форматує дату як відносний час («3 дні тому») за допомогою `Intl.RelativeTimeFormat`.

```ts
$tdr(Date.now() - 5 * 60_000) // '5 minutes ago' in en
```

## Перемикання та посилання {#switching-and-links}

### `$switchLocale` {#$switchlocale}

```ts
(locale: string) => Promise<boolean>
```

Переходить на поточну сторінку в іншій локалі. За `no_prefix` і в режимі hash він завантажує
переклади локалі перед переходом; за `no_prefix` маршрут замінюється на місці (без
нового запису в історії). Невідома локаль ігнорується.
Виклик асинхронний: використовуйте `await`, щоб виконати код після переходу. Він повертає `true`, коли
словник локалі активний, і `false`, коли ні: чанк не вдалося завантажити (поточний
словник залишається; викличте ще раз, щоб повторити спробу) або переміг новіший перемикач.

```ts
await $switchLocale('de')
```

### `$switchLocalePath` {#$switchlocalepath}

```ts
(locale: string) => string
```

Шлях поточної сторінки в іншій локалі, без переходу.

```vue
<NuxtLink :to="$switchLocalePath('de')">Deutsch</NuxtLink>
```

### `$switchLocaleRoute` {#$switchlocaleroute}

```ts
(locale: string) => RouteLocationRaw
```

Об’єкт маршруту для поточної сторінки в іншій локалі, без переходу, або рядок URL
для локалі з власним `baseUrl`. За `trailingSlash` об’єкт має `path` і `fullPath`,
що відповідають правилу, із `query` і `hash` як є, і `router.push` або посилання зберігають їх.

### `$switchRoute` {#$switchroute}

```ts
(route: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, toLocale?: string) => Promise<void>
```

Переходить на інший маршрут, зберігаючи активну локаль або перемикаючись на `toLocale`. Асинхронний, як
`$switchLocale`.

```ts
$switchRoute('/about') // active locale
$switchRoute({ name: 'about' }, 'de') // switch to de
```

### `$localePath` {#$localepath}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => string
```

Визначає шлях у заданій локалі або в активній. Рядок зі схемою `http(s):`, `mailto:`
або `tel:` повертається як є: не передавайте введення користувача як ціль посилання без перевірки.

Рядковий шлях читається як сторінка, яку він показує, тож власний шлях локалі теж застосовується.

```ts
$localePath('/about') // '/about' in en, '/de/ueber-uns' in de with localeRoutes
$localePath({ name: 'about' }, 'fr') // '/fr/about'
```

### `$localeRoute` {#$localeroute}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => RouteLocationResolved
```

Визначає маршрут у заданій локалі або в активній. Звичайний об’єкт, який безпечно зберігати в стані. Коли параметр потребує
екранування, він має `path`, `fullPath`, `query` і `hash`, але не має `name` чи `params`: саме шлях дає маршрутизатору
закодований URL. Для локалі на іншому домені `path` і `fullPath` є абсолютними, чого маршрутизатор не приймає:
таке посилання проходить через `<i18n-link>` або `$localePath`.

### `$getRouteName` {#$getroutename}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric, locale?: string) => string
```

Ім’я маршруту без префікса локалі — ім’я, за яким ключуються переклади.

```ts
$getRouteName() // 'about' on /de/about
```

## Конфігурація сторінки {#page-config}

### `$defineI18nRoute` {#$definei18nroute}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Реєструє конфігурацію локалей і переклади для сторінки зсередини компонента.
Об’єднується з активною локаллю та застосовується повторно, коли локаль змінюється.

Викликайте його в `<script setup>` сторінки, завжди деструктуруючи з `useNuxtApp()`. Збирання зчитує `locales`, `localeRoutes` і `disableMeta` з виклику; під час виконання має значення лише `locales` (вбудовані переклади об’єднуються для активної локалі). Повні правила: [Конфігурація сторінки](/uk/guide/per-component-translations).

```vue
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'de'],
  localeRoutes: { en: '/about', de: '/ueber-uns' },
})
</script>
```

### `$setI18nRouteParams` {#$seti18nrouteparams}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Встановлює параметри поточного маршруту для кожної локалі, щоб динамічний сегмент міг відрізнятися залежно від мови.
Викликайте його під час SSR, до рендерингу head.

Параметри очищаються, коли завершується перехід на інший шлях, зокрема з `/news/1` на `/news/4`, що зберігає ім’я маршруту. Подробиці: [Локалізовані шляхи](/uk/guide/custom-locale-routes).

```ts
$setI18nRouteParams({
  en: { slug: 'my-post' },
  de: { slug: 'mein-beitrag' },
})
```

## Переклади під час виконання {#runtime-translations}

### `$mergeTranslations` {#$mergetranslations}

```ts
(newTranslations: Translations) => void
```

Об’єднує переклади з активною локаллю під час виконання, перевизначаючи завантажене.

Виконує глибоке об’єднання з поточним чанком сторінки активної локалі; ключі, яких він не згадує, зберігаються.

```ts
$mergeTranslations({ banner: { title: 'Sale' } })
```

### `$setTranslation` {#$settranslation}

```ts
(key: string, value: unknown) => void
```

Замінює значення за `key` в активному словнику. Це заміна, а не об’єднання —
використовуйте `$mergeTranslations`, коли наявні сусідні ключі мають зберегтися.

```ts
$setTranslation('banner', { title: 'Sale' }) // drops other keys under banner
$setTranslation('banner.title', 'Sale') // dotted path
```

### `$loadPageTranslations` {#$loadpagetranslations}

```ts
(locale: string, routeName: string, translations: Translations) => Promise<void>
```

Завантажує переклади для сторінки під час виконання, для контенту, ключі якого невідомі під час збирання.

Об’єднує їх із чанком `(locale, routeName)` у пам’яті, і екран оновлюється, коли цей чанк активний. Тут нічого не завантажується з payload: для ще не завантаженої сторінки переклади чекають, а коли її файл завантажиться, вони залишаються поверх нього.

```ts
await $loadPageTranslations('en', 'about', { title: 'About us' })
```

### `$resolveTranslations` {#$resolvetranslations}

```ts
() => Translations
```

Усі переклади, що зараз у пам’яті для активної локалі та маршруту, у вигляді дерева.
Подання лише для читання того, що `$t()` може визначити просто зараз.

Розглядайте результат як доступний лише для читання.

### `$setMissingHandler` {#$setmissinghandler}

```ts
(handler: MissingHandler | null) => void
```

Встановлює колбек, що викликається для кожного невизначеного ключа. Передайте `null`, щоб видалити його.

Обробник виконується замість попередження в режимі розробки.

```ts
$setMissingHandler((locale, key, routeName) => {
  console.error(`[i18n] missing ${key} in ${locale} (${routeName})`)
})
```

### `$clearCache` {#$clearcache}

```ts
() => void
```

Скидає всі кешовані чанки перекладів і перезавантажує словник поточної сторінки. Сторінка
продовжує показувати поточні переклади, доки не надійдуть нові. HMR у режимі розробки викликає його
під час кожної зміни файлу перекладів.

```ts
const { clearCache } = useI18n()
clearCache()
```

Невдале перезавантаження зберігає поточний словник.
