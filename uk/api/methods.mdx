# 🛠️ Методи

Ця сторінка документує всі доступні методи, які надає nuxt-i18n-micro. Методи згруповано за функціональністю для зручнішої навігації.

## 🔍 Методи перекладу

Основні методи для отримання й керування перекладами.

### `$t`

{/* generated:method:$t — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Перекласти ключ, інтерполюючи в нього `params`. Повертає `defaultValue`, коли ключ відсутній, або сам ключ, якщо значення за замовчуванням не задано.

{/* /generated:method:$t */}

```typescript
const welcomeMessage = $t('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

<Warning>
`$t` повертає `CleanTranslation`, тобто `string | number | boolean | Translations | PluralTranslations | null`. Якщо ключ вказує на **вкладений обʼєкт** у вашому JSON (наприклад, `$t('header')`, коли JSON містить `\{ "header": \{ "title": "Hi" \} \}`), поверненим значенням буде цей **обʼєкт**, а не рядок. Використання його безпосередньо у Vue-шаблоні (<code v-pre>\{\{ $t('header') \}\}</code>) відрендериться як `[object Object]`.

**Як уникнути цього:**

- Використайте конкретніший ключ: `$t('header.title')` → `"Hi"`
- Використайте `$ts()`, яка завжди повертає рядок (викликає `.toString()` для нестрокових значень)
- Використовуйте `$t` з вкладеним ключем свідомо для програмного доступу до підобʼєктів
</Warning>

### `$ts`

{/* generated:method:$ts — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string) => string
```

Як `$t`, але завжди повертає рядок: обʼєкт чи масив стрінгіфікуються замість повернення як є.

{/* /generated:method:$ts */}

```typescript
const welcomeMessage = $ts('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

### `$_t` та `$_ts`

{/* generated:method:$_t — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Привʼязати `$t` до конкретного маршруту, щоб перекладати поза поточною сторінкою — наприклад, у layout, що рендерить посилання на інший маршрут.

{/* /generated:method:$_t */}

{/* generated:method:$_ts — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => string
```

Привʼязати `$ts` до конкретного маршруту. Див. `$_t`.

{/* /generated:method:$_ts */}

Прив'язані до маршруту варіанти `$t` та `$ts`. Вони приймають **маршрут** першим аргументом і повертають функцію перекладу, замкнену на локалі та контексті сторінки цього маршруту.

- **Доступ**: `useNuxtApp()` (також реекспортовано `useI18n()` як `$_t` / `$_ts`)

Використовуйте їх, коли активний маршрут під час SSR чи переходів відрізняється від `router.currentRoute` — наприклад, всередині `<i18n-t>`, `<i18n-group>`, або коли рендерите контент для конкретного обʼєкта `route`.

```typescript
import { useRoute, useNuxtApp } from '#imports'

const route = useRoute()
const { $_t, $_ts } = useNuxtApp()

const $t = $_t(route)
const title = $t('page.title')

// String-safe variant
const label = $_ts(route)('page.label')
```


### `$tc`

{/* generated:method:$tc — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params: number | Params, defaultValue?: string) => string
```

Перекласти з плюралізацією. `params` може бути числом-лічильником або обʼєктом, що містить `count`.

{/* /generated:method:$tc */}

**Формат перекладу**: форми розділені `|`. Додавайте плейсхолдери у **кожну** форму:

```json
{
  "apples": "no apples | one apple | {count} apples",
  "cart": "no items for {name} | one item for {name} | {count} items for {name}"
}
```

```typescript
$tc('apples', 0) // "no apples"
$tc('apples', 1) // "one apple"
$tc('apples', 10) // "10 apples"

// count + other params (second argument must be an object)
$tc('cart', { count: 10, name: 'Alice' }) // "10 items for Alice"
```


**Альтернатива у вигляді компонента** — `<i18n-t keypath="cart" :plural="count" :params="\{ name \}" />` (внутрішньо зливає `count` з `params`).


### `$mergeTranslations`

{/* generated:method:$mergeTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
(newTranslations: Translations) => void
```

Злити переклади в активну локаль у рантаймі, перевизначаючи завантажене.

{/* /generated:method:$mergeTranslations */}

```typescript
$mergeTranslations({
  welcome: 'Bienvenue, {username}!',
})
// Output: Updates the translation cache with the new French translation
```

### `$resolveTranslations`

{/* generated:method:$resolveTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
() => Translations
```

Кожен переклад, наразі у памʼяті для активної локалі та маршруту, як дерево.
Read-only-погляд на те, що `$t()` може розвʼязати саме зараз.

{/* /generated:method:$resolveTranslations */}

```typescript
const tree = $resolveTranslations()
// { aaa: { bbb: 'ccc' }, ddd: 1111 } — the same dictionary $t() reads from
```

Використовуйте це, коли потрібен повний in-memory словник (DevTools, тести, рантайм-редактори). Ставтеся до поверненого значення як до read-only; змінюйте значення через `$setTranslation` або патчте через `$mergeTranslations`.

### `$setTranslation`

{/* generated:method:$setTranslation — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, value: unknown) => void
```

Замінити значення за `key` в активному словнику. Це заміна, а не злиття — використовуйте `$mergeTranslations`, коли наявні сусідні ключі мають вижити.

{/* /generated:method:$setTranslation */}

```typescript
$setTranslation('aaa', { fff: 'ggg' }) // replaces the whole `aaa` subtree
$setTranslation('aaa', 'text')          // replaces `aaa` with a string
$setTranslation('ddd', 1111)            // scalar at the top level
$setTranslation('aaa.bbb', 'nested')    // dotted path
```

Це **заміна**, а не злиття. Наявні сусідні ключі під тим самим ключем видаляються. Щоб пропатчити без втрати сусідніх ключів, використовуйте `$mergeTranslations`.

### `$setMissingHandler`

{/* generated:method:$setMissingHandler — do not edit; run `pnpm run docs:generate` */}

```ts
(handler: MissingHandler | null) => void
```

Встановити колбек, що викликається для кожного нерозвʼязаного ключа. Передайте `null`, щоб видалити його.

{/* /generated:method:$setMissingHandler */}

**Визначення типу**:

```typescript
type MissingHandler = (locale: string, key: string, routeName: string, instance?: unknown, type?: string) => void
```

```typescript
// Set a custom handler
$setMissingHandler((locale, key, routeName) => {
  console.error(`Missing translation: ${key} in ${locale} for route ${routeName}`)
  // Send to Sentry or other error tracking service
  // Sentry.captureMessage(`Missing translation: ${key}`)
})

// Remove the handler
$setMissingHandler(null)
```

**Сценарії використання**:

- Логування відсутніх перекладів у сервіси відстеження помилок (Sentry, LogRocket тощо)
- Збір аналітики за відсутніми перекладами
- Кастомна обробка помилок для відсутніх ключів перекладу

## 🔢 Форматування чисел і дат

Методи для форматування чисел і дат відповідно до конвенцій локалі.

### `$tn`

{/* generated:method:$tn — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Форматувати число через `Intl.NumberFormat` у активній локалі. Ключ обирає іменований формат з конфігу.

{/* /generated:method:$tn */}

```typescript
// Inline options
const formattedNumber = $tn(1234567.89, { style: 'currency', currency: 'USD' })
// "$1,234,567.89"

// Named format (from nuxt.config i18n.numberFormats)
const price = $tn(1000, 'currency')
const priceDe = $tn(1000, 'currency', 'de')
const compact = $tn(1000, 'currency', { notation: 'compact' })
```

Невідомі іменовані ключі формату повертаються до опцій `Intl.NumberFormat` за замовчуванням. У розробці (клієнт) видається `console.warn`, коли увімкнено `missingWarn` (за замовчуванням).

**Приклад конфігу**:

```ts
export default defineNuxtConfig({
  i18n: {
    numberFormats: {
      en: {
        currency: { style: 'currency', currency: 'USD' },
        decimal: { style: 'decimal', minimumFractionDigits: 2, maximumFractionDigits: 2 },
      },
      de: {
        currency: { style: 'currency', currency: 'EUR' },
      },
    },
  },
})
```

**Сценарії використання**:

- Форматування чисел як валюти, відсотків або десяткових у відповідному форматі локалі
- Багаторазове використання іменованих форматів у застосунку (паритет з міграцією з Vue I18n)

### `$td`

{/* generated:method:$td — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Форматувати дату через `Intl.DateTimeFormat` у активній локалі. Ключ обирає іменований формат з конфігу.

{/* /generated:method:$td */}

```typescript
const formattedDate = $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' })
// "Friday, September 1, 2023"

const short = $td(new Date(), 'short')
const longDe = $td(new Date(), 'long', 'de')
```

Невідомі іменовані ключі формату повертаються до опцій `Intl.DateTimeFormat` за замовчуванням. У розробці (клієнт) видається `console.warn`, коли увімкнено `missingWarn` (за замовчуванням).

**Приклад конфігу**:

```ts
export default defineNuxtConfig({
  i18n: {
    datetimeFormats: {
      en: {
        short: { year: 'numeric', month: 'short', day: 'numeric' },
        long: { year: 'numeric', month: 'long', day: 'numeric', weekday: 'long' },
      },
    },
  },
})
```

**Сценарії використання**:

- Відображення дат у форматі, що відповідає локалі користувача
- Спільні пресети short/long/date-time на рівні застосунку

### `$tdr`

{/* generated:method:$tdr — do not edit; run `pnpm run docs:generate` */}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

Форматувати дату як відносний час («3 дні тому») через `Intl.RelativeTimeFormat`.

{/* /generated:method:$tdr */}

```typescript
const relativeDate = $tdr(new Date(Date.now() - 1000 * 60 * 5))
// Output: "5 minutes ago" in the 'en-US' locale
```

(locale: string) => void

## 🚦 Конфігурація маршрутів

Методи для налаштування поведінки маршрутів і контролю доступу.

### `$defineI18nRoute`

{/* generated:method:$defineI18nRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Зареєструвати посторінкову конфігурацію локалей і переклади з середини компонента.
Зливається в активну локаль і повторно застосовується при зміні локалі.

{/* /generated:method:$defineI18nRoute */}

> [!IMPORTANT]
> `$defineI18nRoute` надається **плагіном define** і доступний лише через `useNuxtApp()` — він **не** є частиною обʼєкта, який повертає `useI18n()`.
> Завжди деструктуруйте його з `useNuxtApp()` усередині `script setup`. Виклик `$defineI18nRoute(...)` як голого глобала кине `"$defineI18nRoute is not defined"` під час SSR/prerender.

**Параметри**:

- **locales**: `string[] | Record<string, Record<string, string>>` — доступні локалі для маршруту
- **localeRoutes**: `Record<string, string>` — опційно. Кастомні маршрути для конкретних локалей
- **disableMeta**: `boolean | string[]` — опційно. Вимикає i18n мета-теги для всіх або конкретних локалей

**Базовий приклад**:

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr', 'de'],
  localeRoutes: {
    en: '/welcome',
    fr: '/bienvenue',
    de: '/willkommen',
  },
  disableMeta: false,
})
```

> 📖 **Детальні приклади використання, формати конфігурації та кращі практики — у [Посібнику з перекладів для окремих компонентів](/guides/per-component-translations).**

### `$setI18nRouteParams`

{/* generated:method:$setI18nRouteParams — do not edit; run `pnpm run docs:generate` */}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Задати параметри для кожної локалі поточного маршруту, щоб динамічний сегмент відрізнявся за мовою.
Викликайте його під час SSR, перед тим як буде відрендерено head.

{/* /generated:method:$setI18nRouteParams */}

```typescript
// in pages/news/[id].vue
// for en/news/1-first-article
const { $switchLocaleRoute, $setI18nRouteParams, $defineI18nRoute } = useNuxtApp()
$defineI18nRoute({
  localeRoutes: {
    en: '/news/:id()',
    fr: '/nouvelles/:id()',
    de: '/Nachricht/:id()',
  },
})
const { data: news } = await useAsyncData(`news-${params.id}`, async () => {
  let response = await $fetch("/api/getNews", {
    query: {
      id: params.id,
    },
  });
  if (response?.localeSlugs) {
    response.localeSlugs = {
      en: {
        id: '1-first-article'
      }
      fr: {
        id: '1-premier-article'
      }
      de: {
        id: '1-erster-Artikel'
      }
    }
    $setI18nRouteParams(response?.localeSlugs);
  }
  return response;
});
$switchLocalePath('fr') // === 'fr/nouvelles/1-premier-article'
$switchLocalePath('de') // === 'de/Nachricht/1-erster-Artikel'
```

## 🧭 Композабл `useI18nLocale`

Централізований композабл для керування станом локалі. Використовуйте його замість прямого маніпулювання `useState('i18n-locale')` або `useCookie('user-locale')`.

```typescript
const {
  setLocale, // (locale: string) => void — updates state + cookie
  getLocale, // () => string | null — from state or cookie
  getPreferredLocale, // () => string | null — validated against locales list
  getEffectiveLocale, // (route, getLocaleFromRoute) => string
  resolveInitialLocale, // (options) => string
  isValidLocale, // (locale) => boolean
  locale, // Ref<string | null> — reactive state
  localeCookie, // CookieRef — reactive cookie
  syncLocale, // (locale) => void — sync to cookie only
  validLocales, // string[] — list of valid locale codes
} = useI18nLocale()
```

### Ключові методи

| Метод                   | Опис                                                            |
| ----------------------- | --------------------------------------------------------------- |
| `setLocale(locale)`     | Атомарно встановлює локаль у `useState` та cookie               |
| `getLocale()`           | Повертає поточну локаль зі стану або cookie                     |
| `getPreferredLocale()`  | Повертає локаль, перевірену проти списку `locales`, або `null`  |
| `isValidLocale(locale)` | Перевіряє, чи код локалі є у налаштованому списку `locales`     |

### Використання у кастомних плагінах

```typescript
// plugins/i18n-loader.server.ts
export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,
  setup() {
    const { setLocale } = useI18nLocale()
    // Detect locale from headers, domain, etc.
    setLocale('de')
  },
})
```
