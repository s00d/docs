# Довідник API

## Runtime API

- [Методи](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, перемикання локалі, допоміжні функції маршрутизації
- [Події](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Переклади та кеш](/api/cache) — `TranslationStorage`, завантаження payload, `$clearCache`

## Серверне middleware

Серверні обробники використовують спеціалізоване middleware (а не клієнтські помічники `$t`):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — переклад у API-маршрутах та серверних обробниках
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — читання визначеної локалі та метаданих

Див. повний [гайд з серверних перекладів](/guides/server-side-translations) щодо налаштування, пріоритетів визначення локалі та прикладів.

## Повʼязане

- [Довідник з конфігурації](/guides/configuration) — усі опції модуля `i18n`
