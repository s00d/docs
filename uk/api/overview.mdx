У цьому розділі перелічено всі опції, хелпери, хуки, composables і компоненти модуля Nuxt, а також експортований API кожного пакета `@i18n-micro/*`. Використовуйте його, щоб знайти сигнатуру чи значення за замовчуванням; [Посібник](/uk/guide/getting-started) пояснює, як ними користуватися. Більшість таблиць тут згенеровано з вихідного коду, тож вони відповідають коду.

## Модуль Nuxt {#nuxt-module}

| Сторінка | Що охоплює |
| --- | --- |
| [Опції модуля](/uk/api/module-options) | Кожен ключ `i18n` у `nuxt.config` із типом і значенням за замовчуванням |
| [Хелпери](/uk/api/methods) | `$t`, `$tc`, `$tn`, `$td`, `$localePath`, `$switchLocale`, `$defineI18nRoute` та інші |
| [Хуки](/uk/api/events) | Хук часу виконання `i18n:register` |

## Composables {#composables}

| Composable | Для чого |
| --- | --- |
| [`useI18n`](/uk/composables/useI18n) | Хелпери в `<script setup>` |
| [`useI18nLocale`](/uk/composables/useI18nLocale) | Стан локалі та cookie у власному плагіні визначення локалі |
| [`useI18nHead`](/uk/composables/useI18nHead) | Перевизначення згенерованих SEO-тегів для окремих сторінок |
| [`useLocaleHead`](/uk/composables/useLocaleHead) | SEO-теги як об'єкт для власного `useHead` |

## Компоненти {#components}

| Компонент | Що рендерить |
| --- | --- |
| [`<i18n-t>`](/uk/components/i18n-t) | Один переклад із плюралізацією, форматуванням та інтерполяцією слотів |
| [`<i18n-link>`](/uk/components/i18n-link) | `NuxtLink` на локалізований маршрут |
| [`<i18n-switcher>`](/uk/components/i18n-switcher) | Випадний список локалей |
| [`<i18n-group>`](/uk/components/i18n-group) | Блок зі спільним префіксом ключів |

## Сервер {#server}

Обробники Nitro використовують `useTranslationServerMiddleware` і `useLocaleServerMiddleware`, а не клієнтські хелпери. Див. [Серверні маршрути](/uk/guide/server-side-translations).

## Пакети {#packages}

[API пакетів](/uk/api/packages/overview) перелічує експорти кожного пакета `@i18n-micro/*`, по одній згенерованій сторінці на пакет.
