# Довідник API

## Рантайм-API

- [Методи](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, перемикання локалей, помічники маршрутизації
- [Події](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Переклади та кеш](/api/cache) — `TranslationStorage`, завантаження пейлоаду, `$clearCache`

## Серверне middleware

Серверні хендлери використовують окреме middleware (а не клієнтські помічники `$t`):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — перекладайте в API-маршрутах та серверних хендлерах
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — читайте визначену локаль та її метадані

Повний [посібник із серверних перекладів](/guides/server-side-translations) містить налаштування, пріоритет визначення локалі та приклади.
