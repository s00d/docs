[Посібник з CLI](/uk/guide/cli) показує типові сценарії роботи. Ця сторінка перелічує все й генерується з тієї самої таблиці, що керує `--help`.

## Спільні прапорці {#common-flags}

| Прапорець | За замовчуванням | Опис |
| --- | --- | --- |
| `--cwd` | поточний каталог | Каталог проєкту |
| `--logLevel` | `info` | Рівень виводу: silent, info |
| `--debug` | `false` | Виводити стек викликів, коли команда завершується помилкою |

## Перегляд {#inspect}

### `info` {#info}

Вивести розв'язану конфігурацію i18n проєкту

| Прапорець | За замовчуванням | Опис |
| --- | --- | --- |
| `--json` | `false` | Виводити JSON замість тексту |

### `check` {#check}

Перевірка для CI: помилка при відсутніх, порожніх, зайвих, невизначених або невикористаних ключах і зламаних плейсхолдерах

| Прапорець | За замовчуванням | Опис |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` з nuxt.config | Каталог перекладів відносно проєкту |
| `--only` | усі, крім duplicates | Перелік перевірок через кому: missing, empty, extra, placeholders, undefined, unused, duplicates. Явно вказана `unused` завершується помилкою, якщо не може виконатися |
| `--duplicates` | `false` | Також повідомляти про однаковий текст під різними ключами |
| `--ignore` | — | Glob-шаблони вихідних файлів для пропуску через кому, відносно проєкту |
| `--json` | `false` | Виводити JSON замість тексту |

```bash
i18n-micro check
i18n-micro check --only missing,placeholders --json
```

### `stats` {#stats}

Показати повноту перекладу для кожної локалі

| Прапорець | За замовчуванням | Опис |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` з nuxt.config | Каталог перекладів відносно проєкту |
| `--html` | — | Також записати HTML-звіт у цей файл |
| `--json` | `false` | Виводити JSON замість тексту |
| `--baseRef` | — | Git-посилання для порівняння повноти, напр. HEAD~1 або main |

```bash
i18n-micro stats --baseRef main
i18n-micro stats --html reports/i18n.html
```

### `lint` {#lint}

Перевірити текст перекладів; завершується помилкою, якщо проблеми лишаються

| Прапорець | За замовчуванням | Опис |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` з nuxt.config | Каталог перекладів відносно проєкту |
| `--rules` | усі, або `enabledRules` з .i18n-lintrc.json | Правила для запуску через кому: no-trailing-spaces, no-multiple-spaces, no-empty-translation або власне |
| `--fix` | `false` | Виправити те, що можна: пробіли та власні правила із заміною |
| `--json` | `false` | Виводити JSON замість тексту |

```bash
i18n-micro lint --rules no-trailing-spaces --fix
```

### `search` {#search}

Шукати ключі та значення й показувати, де використовується кожен ключ

| Прапорець | За замовчуванням | Опис |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` з nuxt.config | Каталог перекладів відносно проєкту |
| `<query>` | — | Текст або ключ для пошуку |
| `--caseSensitive` | `false` | Враховувати регістр |
| `--onlyUnused` | `false` | Лише ключі, які видалила б `clean`; запит стає необов'язковим |
| `--scope` | `all` | Де шукати: global, pages, all |
| `--limit` | — | Повертати щонайбільше стільки ключів |
| `--ignore` | — | Glob-шаблони вихідних файлів для пропуску через кому, відносно проєкту |
| `--json` | `false` | Виводити JSON замість тексту |

```bash
i18n-micro search "Welcome"
i18n-micro search --onlyUnused
```

## Робота з перекладами {#translation-workflow}

### `extract` {#extract}

Перелічити ключі, які використовують вихідні файли, але які ще не мають тексту, і додати ті, що мають текст за замовчуванням, до локалі за замовчуванням

| Прапорець | За замовчуванням | Опис |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` з nuxt.config | Каталог перекладів відносно проєкту |
| `--ignore` | — | Glob-шаблони вихідних файлів для пропуску через кому, відносно проєкту |

```bash
i18n-micro extract
```

### `translate` {#translate}

Заповнити відсутні переклади з локалі за замовчуванням через сервіс перекладу

| Прапорець | За замовчуванням | Опис |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` з nuxt.config | Каталог перекладів відносно проєкту |
| `--service` | — | Сервіс перекладу: ai, azure, deepl, google, libretranslate, yandexcloud |
| `--token` | — | API-ключ. Краще використовуйте змінну середовища I18N_TRANSLATE_TOKEN: прапорці потрапляють в історію оболонки |
| `--options` | — | Параметри сервісу як пари key:value, розділені комами |
| `--locale` | усі локалі, крім локалі за замовчуванням | Локалі для заповнення через кому |
| `--replace` | `false` | Перекласти кожен ключ заново, замінивши наявні значення |
| `--dryRun` | `false` | Порахувати ключі та символи для кожної локалі; нічого не надсилати |
| `--chunkSize` | — | Рядків на запит; обмежено тим, що приймає сервіс |
| `--pluralSeparator` | `\|` | Роздільник форм множини в повідомленнях |
| `--glossaryFile` | `.i18n-glossary.json`, якщо існує | Файл глосарію, використовується сервісом `ai` |

```bash
i18n-micro translate --dryRun
I18N_TRANSLATE_TOKEN=... i18n-micro translate --service deepl --locale de,fr
i18n-micro translate --service ai --options provider:openai,model:gpt-4o-mini
i18n-micro translate --service libretranslate --options baseUrl:https://translate.example.com
```

### `sync` {#sync}

Видалити ключі, яких немає в локалі за замовчуванням; зупиняється, коли безпечність цього неможливо довести. Відсутні ключі залишаються відсутніми

| Прапорець | За замовчуванням | Опис |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` з nuxt.config | Каталог перекладів відносно проєкту |
| `--ignore` | — | Glob-шаблони вихідних файлів для пропуску через кому, відносно проєкту |
| `--dryRun` | `false` | Перелічити, що буде видалено; нічого не записувати |
| `--force` | `false` | Видалити ключі, навіть якщо безпечність неможливо довести |

```bash
i18n-micro sync --dryRun
```

### `clean` {#clean}

Видалити ключі, які ніщо в проєкті не використовує; зупиняється, коли це неможливо довести

| Прапорець | За замовчуванням | Опис |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` з nuxt.config | Каталог перекладів відносно проєкту |
| `--include` | — | Регулярний вираз: розглядати для видалення лише відповідні ключі |
| `--exclude` | — | Регулярний вираз: ніколи не видаляти відповідні ключі |
| `--ignore` | — | Glob-шаблони вихідних файлів для пропуску через кому, відносно проєкту |
| `--dryRun` | `false` | Перелічити, що буде видалено; нічого не записувати |
| `--force` | `false` | Видалити ключі, навіть якщо використання неможливо довести для всіх |

```bash
i18n-micro clean --dryRun
i18n-micro clean --exclude '^errors\.'
```

## Рефакторинг {#refactoring}

### `text-to-i18n` {#text-to-i18n}

Замінити жорстко закодований текст у шаблонах Vue на виклики перекладу та повідомити про жорстко закодований текст у коді

| Прапорець | За замовчуванням | Опис |
| --- | --- | --- |
| `--translationFile` | `<translationDir>/<defaultLocale>.json` | Файл, куди потрапляють нові ключі |
| `--path` | увесь проєкт | Файл або каталог для обробки |
| `--context` | — | Префікс для згенерованих ключів |
| `--ignore` | — | Glob-шаблони вихідних файлів для пропуску через кому, відносно проєкту |
| `--dryRun` | `false` | Показати, що зміниться; нічого не записувати |
| `--interactive` | `false` | Підтверджувати або редагувати кожен згенерований ключ |

```bash
i18n-micro text-to-i18n --dryRun
i18n-micro text-to-i18n --path components --context ui
```

### `rename` {#rename}

Перейменувати ключ або простір імен у кожній локалі та у вихідних файлах

| Прапорець | За замовчуванням | Опис |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` з nuxt.config | Каталог перекладів відносно проєкту |
| `--from` **\*** | — | Поточний ключ або простір імен |
| `--to` **\*** | — | Новий ключ або простір імен |
| `--ignore` | — | Glob-шаблони вихідних файлів для пропуску через кому, відносно проєкту |
| `--dryRun` | `false` | Повідомити про зміни; нічого не записувати |

**\*** обов'язковий.

```bash
i18n-micro rename --from common.save --to actions.save
```

### `pseudo` {#pseudo}

Заповнити локаль псевдоперекладами, щоб знайти проблеми з версткою та жорстко закодованим текстом

| Прапорець | За замовчуванням | Опис |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` з nuxt.config | Каталог перекладів відносно проєкту |
| `--sourceLocale` | локаль за замовчуванням | Локаль для читання |
| `--targetLocale` **\*** | — | Локаль для заповнення |
| `--replace` | `false` | Перезаписати наявні значення |

**\*** обов'язковий.

### `format` {#format}

Переписати файли локалей із відсортованими ключами та однаковими відступами

| Прапорець | За замовчуванням | Опис |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` з nuxt.config | Каталог перекладів відносно проєкту |
| `--indent` | `2` | Кількість пробілів відступу |
| `--sortKeys` | `true` | Сортувати ключі; використовуйте --no-sortKeys, щоб зберегти їхній порядок |
| `--check` | `false` | Помилка, якщо файл зміниться; нічого не записувати |

```bash
i18n-micro format --check
```

## Обмін {#exchange}

### `export` {#export}

Експортувати файли локалей у PO або CSV з текстом локалі за замовчуванням як джерелом

| Прапорець | За замовчуванням | Опис |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` з nuxt.config | Каталог перекладів відносно проєкту |
| `--format` | `po` | Формат файлу: po, csv |
| `--dir` | `pots` для po, `csv_exports` для csv | Вихідний каталог відносно проєкту |
| `--force` | `false` | Перезаписати файли, змінені з останнього експорту й ніколи не імпортовані |

```bash
i18n-micro export --format csv
```

### `import` {#import}

Об'єднати файли PO або CSV з файлами локалей

| Прапорець | За замовчуванням | Опис |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` з nuxt.config | Каталог перекладів відносно проєкту |
| `--format` | `po` | Формат файлу: po, csv |
| `--dir` | `pots` для po, `csv_exports` для csv | Вхідний каталог відносно проєкту |
| `--dryRun` | `false` | Повідомити, що буде імпортовано; нічого не записувати |

```bash
i18n-micro import --format csv --dryRun
```

### `sync-remote` {#sync-remote}

Отримати глобальні переклади з HTTP-ендпоінту з .i18n-remote.json або надіслати їх туди

| Прапорець | За замовчуванням | Опис |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` з nuxt.config | Каталог перекладів відносно проєкту |
| `--pull` | `true` | Отримати з віддаленого джерела |
| `--push` | `false` | Надіслати на віддалене джерело |
| `--force` | `false` | При отриманні брати віддалене значення; при надсиланні перезаписувати текст, який є лише на віддаленому джерелі |
| `--dryRun` | `false` | Повідомити, що змінить отримання; нічого не записувати й не надсилати |

```bash
i18n-micro sync-remote --dryRun
i18n-micro sync-remote --no-pull --push
```

## Правила лінтингу {#lint-rules}

| Правило | Знаходить | Виправляється `--fix` |
| --- | --- | --- |
| `no-trailing-spaces` | Пробіли в кінці значення або рядка | так |
| `no-multiple-spaces` | Два або більше пробілів поспіль | так |
| `no-empty-translation` | Порожнє або пусте значення | ні |

## Коди виходу {#exit-codes}

| Код | Значення |
| --- | --- |
| `0` | Готово, повідомляти нічого |
| `1` | Знахідки: `check`, `lint` або `format --check` щось знайшли, `clean` або `sync` не змогли довести безпечність видалення, `export` перезаписав би неімпортовану роботу, `translate` пропустив ключі, `import` або `sync-remote` натрапили на конфлікт, надсилання `sync-remote` видалило б віддалений текст. `--dryRun` для `clean`, `sync` або отримання `sync-remote` повідомляє про це й завершується з `0` |
| `2` | Збій: неправильне використання, нечитабельний проєкт, помилка мережі або файлу |

## Файли конфігурації {#configuration-files}

| Файл | Використовується |
| --- | --- |
| `.i18n-lintrc.json` | `lint`: `enabledRules`, `disabledRules`, `customRegexRules` (`name`, `pattern`, `flags`, `description`, `replacement`) |
| `.i18n-remote.json` | `sync-remote`: `url`, `path`, `token`, `auth` (`username`, `password`). `type` можна опустити; існує лише `custom` |
| `.i18n-glossary.json` | `translate --service ai`: `entries` із `source`, `target` та необов'язковими `from`, `to` |

## Змінні середовища {#environment-variables}

| Назва | Призначення |
| --- | --- |
| `I18N_TRANSLATE_TOKEN` | API-ключ для `translate`. Читається також з `.env` |
| `I18N_REMOTE_TOKEN` | Bearer-токен для `sync-remote`. Читається також з `.env` |
| `AI_GATEWAY_API_KEY, OPENAI_API_KEY, ANTHROPIC_API_KEY` | Ключ сервісу `ai`, коли `I18N_TRANSLATE_TOKEN` не задано |
| `DEFAULT_LOCALE` | Перевизначає `defaultLocale`, як і в модулі |
