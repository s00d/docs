# 🌍 Компонент `<i18n-group>`

Компонент `<i18n-group>` у Nuxt I18n Micro надає зручний спосіб згрупувати переклади під спільним префіксом, зменшуючи повторення й покращуючи організацію коду.

## ⚙️ Пропси

{/* generated:component:i18n-group — do not edit; run `pnpm run docs:generate` */}

| Проп | Тип | За замовчуванням | Опис |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | Префікс ключа, відносно якого розвʼязується кожен пошук усередині слоту. |
| `groupClass` | `string` | `''` | Додатковий клас на елементі-обгортці. |

**\*** обовʼязковий.

### Слоти

| Слот | Прив'язки | Опис |
| --- | --- | --- |
| `default` | `prefix`, `t` | Отримує `prefix` та функцію `t`, обмежену цим префіксом. |

{/* /generated:component:i18n-group */}

## 🎯 Слоти

Слот за замовчуванням отримує `prefix` та функцію `t`, обмежену цим префіксом, тож ключі всередині записуються відносно префікса:

```vue
<i18n-group prefix="checkout">
  <template #default="{ t }">
    <h2>{{ t('title') }}</h2>
    <p>{{ t('summary', { count: 3 }) }}</p>
  </template>
</i18n-group>
```

## 🛠️ Приклад використання

### Базове використання

```vue
<template>
  <i18n-group prefix="product.details">
    <template #default="{ t }">
      <h1>{{ t('title') }}</h1>
      <p>{{ t('description') }}</p>
      <div class="price">{{ t('price', { value: 99.99 }) }}</div>
    </template>
  </i18n-group>
</template>
```

Файл перекладу:

```json
{
  "product": {
    "details": {
      "title": "Premium Product",
      "description": "This is a premium product",
      "price": "Price: ${value}"
    }
  }
}
```

### З кастомним класом

```vue
<template>
  <i18n-group prefix="user.profile" group-class="profile-section">
    <template #default="{ t }">
      <div class="user-info">
        <h2>{{ t('title') }}</h2>
        <p>{{ t('bio') }}</p>
        <div class="stats">
          <span>{{ t('stats.followers') }}</span>
          <span>{{ t('stats.following') }}</span>
        </div>
      </div>
    </template>
  </i18n-group>
</template>
```

Файл перекладу:

```json
{
  "user": {
    "profile": {
      "title": "User Profile",
      "bio": "User biography goes here",
      "stats": {
        "followers": "Followers: {count}",
        "following": "Following: {count}"
      }
    }
  }
}
```

### З динамічним вмістом

```vue
<template>
  <i18n-group prefix="blog.post">
    <template #default="{ t }">
      <article>
        <h1>{{ t('title') }}</h1>
        <div class="meta">
          {{ t('meta.author', { name: author }) }} |
          {{ t('meta.date', { date: publishDate }) }}
        </div>
        <div v-for="(section, index) in sections" :key="index">
          <h2>{{ t(`sections.${index}.title`) }}</h2>
          <p>{{ t(`sections.${index}.content`) }}</p>
        </div>
      </article>
    </template>
  </i18n-group>
</template>

<script setup>
const author = 'John Doe'
const publishDate = '2024-01-01'
const sections = ['intro', 'main', 'conclusion']
</script>
```

## 🎨 Стилізація

Компонент огортає свій вміст у div із класом `i18n-group` та будь-якими додатковими класами, зазначеними у пропі `groupClass`:

```css
.i18n-group {
  /* Your base styles */
}

.profile-section {
  /* Additional styles for profile sections */
}
```

## 🚀 Кращі практики

1. **Узгоджені префікси**: використовуйте узгоджені й логічні префікси, що відображають структуру вашого застосунку.

```vue
<i18n-group prefix="features.pricing">
<i18n-group prefix="features.security">
```

2. **Модульна організація**: групуйте повʼязані переклади разом під змістовними префіксами.

```vue
<i18n-group prefix="checkout.payment">
<i18n-group prefix="checkout.shipping">
```

3. **Багаторазові компоненти**: створюйте багаторазові компоненти зі своїми групами перекладів.

```vue
<!-- UserProfile.vue -->
<i18n-group prefix="user.profile">

<!-- UserSettings.vue -->
<i18n-group prefix="user.settings">
```

4. **Вкладені групи**: уникайте глибокої вкладеності груп, щоб зберегти ясність.

```vue
<!-- Good -->
<i18n-group prefix="shop.product">

<!-- Avoid -->
<i18n-group prefix="shop.category.product.details.specs">
```
