# 🌍 Компонент `<i18n-switcher>`

Компонент `<i18n-switcher>` у `Nuxt I18n Micro` надає зручний випадний інтерфейс для перемикання між різними локалями у вашому застосунку. Компонент має широкі можливості налаштування, що дозволяє безшовно інтегрувати його з дизайном та розкладкою вашого застосунку.

Локалі з `disabled: true` **не потрапляють** до випадного списку (вони залишаються доступними через `$getLocales()` для SEO та head-тегів). Лише перемикані локалі отримують `NuxtLink` та `hreflang`.

За замовчуванням усі елементи не стилізовані: пропси `custom*Style` приймають обʼєкти інлайн-стилів, а слоти нижче повністю замінюють розмітку, коли стилізації недостатньо.

## 🛠️ Приклади використання

### Базове використання

```vue
<template>
  <i18n-switcher />
</template>
```

Це відрендерить перемикач локалей зі стилізацією й поведінкою за замовчуванням.

### Кастомні підписи й інлайн-стилі

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Цей приклад демонструє повністю кастомізований перемикач локалей із кастомними підписами й інлайн-стилями.

## 🔌 Слоти

Кожну візуальну частину перемикача можна замінити. Слоти перелічені в таблиці пропсів вище; кожен приймає шаблонний вміст:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Слоти, назви яких закінчуються на `-item`, `-link-content` або починаються з `before-item`, отримують обʼєкт `locale`, якому вони належать.

## 🎨 Огляд стилів

Компонент `<i18n-switcher>` постачається з базовими стилями, визначеними через інлайн-стилі, які легко перевизначити, передавши кастомні стилі через пропси. Ось короткий огляд стилізації за замовчуванням:

- **Wrapper**: керує позиціонуванням випадного списку.
- **Button**: стилізує кнопку відкриття випадного списку.
- **Dropdown**: стилізує список випадного меню.
- **Items**: стилізує кожен елемент списку.
- **Links**: стилізує посилання всередині кожного елемента.
- **Icon**: стилізує іконку-індикатор випадного списку.

Ви можете налаштувати ці стилі, передавши власні через відповідні пропси, забезпечивши безшовну інтеграцію перемикача локалей у UI вашого застосунку.
