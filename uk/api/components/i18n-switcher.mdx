# 🌍 Компонент `<i18n-switcher>`

Компонент `<i18n-switcher>` у `Nuxt I18n Micro` надає зручний інтерфейс випадаючого меню для перемикання між різними локалями у вашому застосунку. Цей компонент є високо налаштовуваним, дозволяючи безшовну інтеграцію з дизайном та лейаутом вашого застосунку.

Локалі з `disabled: true` **виключаються** з випадаючого меню (вони залишаються доступними через `$getLocales()` для SEO / head-тегів). Лише перемикувані локалі отримують `NuxtLink` + `hreflang`.

Кожна частина за замовчуванням не має стилів: props `custom*Style` приймають обʼєкти inline-стилів, а
слоти нижче повністю замінюють розмітку, коли стилізації недостатньо.

## 🛠️ Приклади використання

### Базове використання

```vue
<template>
  <i18n-switcher />
</template>
```

Це рендерить перемикач локалей зі стилями та поведінкою за замовчуванням.

### Кастомні мітки та inline-стилі

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Цей приклад демонструє повністю налаштований перемикач локалей із кастомними мітками та inline-стилями.

## 🔌 Слоти

Кожну візуальну частину перемикача можна замінити. Слоти перелічені у таблиці props вище; кожен приймає template-контент:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Слоти, імена яких закінчуються на `-item`, `-link-content` або починаються з `before-item`, отримують
обʼєкт `locale`, якому вони належать.

## 🎨 Огляд стилів

Компонент `<i18n-switcher>` має базові стилі, визначені через inline-стилі, які легко перевизначити, передавши кастомні стилі через props. Ось короткий огляд стилізації за замовчуванням:

- **Wrapper**: керує позиціюванням випадаючого меню.
- **Button**: стилізує кнопку-перемикач випадаючого меню.
- **Dropdown**: стилізує список випадаючого меню.
- **Items**: стилізує кожен елемент у списку.
- **Links**: стилізує посилання всередині кожного елемента.
- **Icon**: стилізує іконку-індикатор випадаючого меню.

Ви можете кастомізувати ці стилі, передавши власні стилі через відповідні props, забезпечуючи, що перемикач локалей органічно інтегрується в UI вашого застосунку.
