# 🌍 Компонент `<i18n-t>`

Компонент `<i18n-t>` у `Nuxt I18n Micro` — це гнучкий компонент перекладу, який підтримує динамічне вставляння вмісту через слоти. Він дозволяє інтерполювати переклади кастомними Vue-компонентами або HTML-вмістом, уможливлюючи розширені сценарії локалізації.

Одночасно застосовується лише один із `plural`, `number`, `date` та `relativeDate`; коли задано кілька, перший у цьому списку перемагає.

### Приклади для кожного пропа

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

## 🛠️ Приклади використання

### Базове використання

```vue
<i18n-t keypath="feedback.text" />
```

Це рендерить переклад для `feedback.text` усередині тегу `<span>`.

### Використання слотів для динамічного вмісту

Компонент `<i18n-t>` підтримує використання слотів для динамічного вставляння Vue-компонентів або іншого вмісту у певні частини перекладу.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

У цьому прикладі плейсхолдер `\{link\}` у рядку перекладу `feedback.text` замінюється компонентом `<nuxt-link>`, який сам містить інший компонент перекладу.

### Плюралізація

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

Це автоматично застосовує правила плюралізації на основі значення `itemCount`.

## 🚀 Додаткові можливості

### Слот за замовчуванням

Якщо конкретний слот не задано, переклад можна налаштувати через слот за замовчуванням, який надає весь перекладений рядок:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### Умовний рендеринг

Не рендерити нічого, якщо рядок перекладу порожній, — використовуйте проп `hideIfEmpty`.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### Кастомне правило плюралізації

Використовуйте кастомну функцію для обробки плюралізації.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### Розширений приклад зі слотами

Використовуйте слоти, щоб налаштувати, як рендериться вміст перекладу.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
