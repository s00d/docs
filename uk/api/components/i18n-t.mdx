# 🌍 Компонент `<i18n-t>`

Компонент `<i18n-t>` у `Nuxt I18n Micro` — це гнучкий компонент перекладу, який підтримує динамічну вставку контенту через слоти. Він дозволяє інтерполювати переклади кастомними Vue-компонентами чи HTML-вмістом, забезпечуючи розширені сценарії локалізації.

Одночасно застосовується лише один з `plural`, `number`, `date` та `relativeDate`; коли встановлено кілька, виграє перший у цьому переліку.

### Приклади для кожного prop

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

```json
{
  "items": "Nothing|You have {count} item|You have {count} items"
}
```

## 🛠️ Приклади використання

### Базове використання

```vue
<i18n-t keypath="feedback.text" />
```

Це рендерить переклад для `feedback.text` всередині тегу `<span>`.

### Використання слотів для динамічного вмісту

Компонент `<i18n-t>` підтримує використання слотів для динамічного вставлення Vue-компонентів чи іншого вмісту у певні частини перекладу.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

У цьому прикладі плейсхолдер `\{link\}` у рядку перекладу `feedback.text` замінюється компонентом `<nuxt-link>`, який сам містить інший компонент перекладу.

### Множинні форми

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

Це автоматично застосовує правила множини на основі значення `itemCount`.

## 🚀 Додаткові можливості

### Слот за замовчуванням

Якщо конкретний слот не надано, переклад можна кастомізувати через слот за замовчуванням, який надає весь перекладений рядок:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### Умовний рендеринг

Нічого не рендерити, якщо рядок перекладу порожній, використовуючи prop `hideIfEmpty`.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### Кастомне правило множини

Використовуйте кастомну функцію для обробки множинних форм.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### Розширений приклад зі слотами

Використовуйте слоти для кастомізації того, як рендериться вміст перекладу.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
