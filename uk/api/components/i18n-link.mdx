# 🌍 Компонент `<i18n-link>`

Компонент `<i18n-link>` у `Nuxt I18n Micro` — це універсальний компонент посилання, який автоматично локалізує маршрути на основі поточної локалі. Він виступає обгорткою навколо компонента `<NuxtLink>`, надаючи додаткові можливості, як-от стилізація активного посилання й підтримка зовнішніх посилань.

## ⚙️ Пропси

{/* generated:component:i18n-link — do not edit; run `pnpm run docs:generate` */}

| Проп | Тип | За замовчуванням | Опис |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | Цільовий маршрут. Локалізується автоматично; зовнішній URL передається без змін. |
| `activeStyle` | `Partial<CSSStyleValue>` | — | Інлайн-стиль, який застосовується, коли посилання вказує на поточний маршрут. |

**\*** обовʼязковий.

### Слоти

| Слот | Прив'язки | Опис |
| --- | --- | --- |
| `default` | — | Вміст посилання. |

{/* /generated:component:i18n-link */}

`to` приймає все те саме, що й `NuxtLink`: шлях, іменований маршрут або обʼєкт розвʼязаного маршруту.
Абсолютний URL визначається та рендериться як звичайний `<a target="_blank" rel="noopener noreferrer">`, а не локалізується.

## 🛠️ Приклади використання

### Базове використання

```vue
<i18n-link to="/about">About Us</i18n-link>
```

Цей приклад створює посилання на сторінку `/about`, локалізоване відповідно до поточної локалі.

### Стилізація активного посилання інлайн-стилями

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

Посилання матиме жирний текст, коли користувач перебуває на сторінці `/about`, що дозволяє стилізувати активне посилання безпосередньо інлайн-стилями.

### Обробка зовнішніх посилань

Компонент автоматично визначає зовнішні посилання й додає необхідні атрибути для безпеки.

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

Це посилання відкриє `https://example.com` у новій вкладці з атрибутом `rel="noopener noreferrer"`.

## 🎨 Стилі

Тепер компонент використовує інлайн-стилі для активного стану замість класу. Ви можете налаштувати ці стилі за допомогою пропа `activeStyle`.

### Стилі активного стану за замовчуванням

- **Font Weight**: `bold`
- **Color**: успадковує кольори за замовчуванням від браузера (якщо в `activeStyle` не вказано `color`).

Ви можете перевизначити їх, передавши власні стилі через проп `activeStyle`.

### Кастомні стилі активного стану

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

У цьому прикладі посилання буде жирним та зеленим, коли активне.

## 🚀 Додаткові можливості

### Слот для кастомного вмісту

Ви можете передати кастомний вміст усередині посилання через слоти, що робить компонент гнучким для різних сценаріїв.

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### Покращення доступності

Компонент підтримує `aria-label` та інші атрибути доступності, щоб забезпечити більш доступний досвід.

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
