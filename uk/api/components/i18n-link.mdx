# 🌍 Компонент `<i18n-link>`

Компонент `<i18n-link>` у `Nuxt I18n Micro` — це універсальний компонент посилання, який автоматично локалізує маршрути відповідно до поточної локалі. Він виступає обгорткою навколо компонента `<NuxtLink>`, надаючи додаткові можливості, як-от стилізацію активного посилання та підтримку зовнішніх посилань.

## ⚙️ Props

| Prop | Тип | Значення за замовчуванням | Опис |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | Цільовий маршрут. Локалізується автоматично; зовнішній URL передається без змін. |
| `activeStyle` | `Partial<CSSStyleValue>` | — | Inline-стиль, що застосовується, поки посилання вказує на поточний маршрут. |

**\*** обовʼязково.

### Слоти

| Слот | Прив'язки | Опис |
| --- | --- | --- |
| `default` | — | Вміст посилання. |

`to` приймає все те саме, що й `NuxtLink` — шлях, іменований маршрут або розвʼязаний обʼєкт маршруту.
Абсолютний URL виявляється і рендериться як звичайне `<a target="_blank" rel="noopener noreferrer">`,
а не локалізується.

## 🛠️ Приклади використання

### Базове використання

```vue
<i18n-link to="/about">About Us</i18n-link>
```

Цей приклад створює посилання на сторінку `/about`, локалізоване до поточної локалі.

### Стилізація активного посилання за допомогою inline-стилів

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

Посилання матиме жирний текст, коли користувач перебуває на сторінці `/about`, дозволяючи вам стилізувати активне посилання безпосередньо через inline-стилі.

### Обробка зовнішніх посилань

Компонент автоматично виявляє зовнішні посилання та додає необхідні атрибути для безпеки.

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

Це посилання відкриє `https://example.com` у новій вкладці з застосованим `rel="noopener noreferrer"`.

## 🎨 Стилі

Тепер компонент використовує inline-стилі для активного стану замість класу. Ви можете кастомізувати ці стилі за допомогою prop `activeStyle`.

### Стилі активного стану за замовчуванням

- **Font Weight**: `bold`
- **Color**: успадковує колір за замовчуванням від браузера (якщо `color` не вказано у `activeStyle`).

Ви можете перевизначити їх, надавши власні стилі через prop `activeStyle`.

### Кастомні стилі активного стану

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

У цьому прикладі посилання буде жирним і зеленим у активному стані.

## 🚀 Додаткові можливості

### Слот для кастомного вмісту

Ви можете передавати кастомний вміст всередину посилання через слоти, що робить компонент гнучким для різних сценаріїв використання.

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### Покращення доступності

Компонент підтримує `aria-label` та інші атрибути доступності, щоб забезпечити доступніший досвід.

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
