# API пакетів

`nuxt-i18n-micro` побудований із набору невеликих пакетів, більшість яких можна використовувати самостійно: `@i18n-micro/vue` — у звичайному застосунку Vue, `@i18n-micro/core` — де завгодно.

Кожну сторінку нижче згенеровано зі знімка API, з яким [`pnpm run api:surface`](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/maintenance-commands.md#api-surface) звіряє TypeScript-джерела, тож експорт не може зникнути без того, щоб змінився цей довідник або впав CI.
