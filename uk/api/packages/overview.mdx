title: "API пакетів"
description: "Експортований API кожного пакета @i18n-micro/*, згенерований зі знімків API, які CI звіряє з вихідним кодом."
---

Модуль Nuxt побудовано з невеликих пакетів `@i18n-micro/*`, і більшість із них працюють самостійно: `@i18n-micro/vue` у застосунку Vue, `@i18n-micro/core` будь-де. Використовуйте ці сторінки, щоб дізнатися, що експортує пакет, для кожної точки входу. Кожну сторінку згенеровано зі знімка, який [`pnpm run api:surface`](https://s00d.github.io/nuxt-i18n-micro/contributing/maintenance-commands#api-surface) звіряє з вихідним кодом TypeScript, тож експорт не може змінитися непомітно для CI.
