# API пакетів

`nuxt-i18n-micro` побудовано з набору невеликих пакетів, більшість з яких можна використовувати
самостійно — `@i18n-micro/vue` у звичайному Vue-застосунку, `@i18n-micro/core` будь-де.

Кожна сторінка нижче генерується зі знімка API, який
[`pnpm run api:surface`](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/maintenance-commands.md#api-surface) перевіряє відносно
TypeScript-джерел, тож експорт не може зникнути без зміни цього довідника або
падіння CI.
