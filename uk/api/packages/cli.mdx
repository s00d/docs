звіряє з вихідним кодом TypeScript.

## `@i18n-micro/cli` {#i18n-microcli}

```ts
import { /* … */ } from '@i18n-micro/cli'
```

| Експорт | Вид | Сигнатура |
| --- | --- | --- |
| `ArgSpec` | інтерфейс | 8 членів |
| `COMMAND_GROUPS` | константа | `readonly ["Inspect", "Translation workflow", "Refactoring", "Exchange"]` |
| `CommandGroup` | тип | `(typeof COMMAND_GROUPS)[number]` |
| `commands` | константа | `Record<string, CommandSpec>` |
| `CommandSpec` | інтерфейс | 5 членів |
| `runCli` | функція | `(rawArgs: string[]) => Promise<void>` |
