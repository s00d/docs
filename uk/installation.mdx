## Вимоги

- **Node.js**: 18 або новіша.
- **Nuxt**: 3.x або 4.x.

Модуль підтримує як структуру проєкту Nuxt 3 (`pages/**/*.vue`), так і структуру Nuxt 4 (`app/pages/**/*.vue`). За конвенцією переклади зберігаються у корені проєкту (`locales/`), навіть при використанні теки `app/` у Nuxt 4.

## Встановлення модуля Nuxt

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Зареєструйте його у `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Див. [Швидкий старт](/quickstart) для повного покрокового посібника або [Довідник з конфігурації](/guides/configuration) для опису всіх опцій.

## Структура проєкту

За замовчуванням модуль очікує:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Файли кореневого рівня обʼєднуються з кожним файлом конкретної сторінки під час збірки. Файли для окремих сторінок автоматично створюються за їх відсутності під час `nuxt dev`.

## Структура Nuxt 4

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Щоб розмістити переклади всередині `app/`, встановіть `translationDir: 'app/locales'`.

| Пакет | Призначення |
| --- | --- |
| [`@i18n-micro/vue`](/integrations/vue) | Інтеграція з Vue 3 (окремо, без Nuxt). |
| [`@i18n-micro/react`](/integrations/react) | Інтеграція з React. |
| [`@i18n-micro/preact`](/integrations/preact) | Інтеграція з Preact. |
| [`@i18n-micro/solid`](/integrations/solid) | Інтеграція з SolidJS. |

| [`@i18n-micro/types-generator`](/integrations/types-generator) | Генерація TypeScript-типів із файлів перекладів. |

Спільні внутрішні пакети підключаються транзитивно.

## TypeScript

Модуль генерує ambient-типи для `useI18n`, `$t` та повʼязаних допоміжних функцій на основі ваших файлів локалі за замовчуванням. Це увімкнено за замовчуванням (`types: true`).

Для суворішої типізації ключів перекладів див. [`@i18n-micro/types-generator`](/integrations/types-generator).
