## Вимоги

- **Node.js**: 18 або новіший.
- **Nuxt**: 3.x або 4.x.

Модуль підтримує обидві розкладки проєкту: Nuxt 3 (`pages/**/*.vue`) та Nuxt 4 (`app/pages/**/*.vue`). За домовленістю переклади живуть у корені проєкту (`locales/`), навіть коли ви використовуєте каталог `app/` з Nuxt 4.

## Встановлення модуля Nuxt

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Зареєструйте його в `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Повний опис див. у [Швидкому старті](/quickstart), а всі опції — у [Довіднику з конфігурації](/guides/configuration).

## Розкладка проєкту

За замовчуванням модуль очікує таку структуру:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Файли кореневого рівня мержаться у кожен посторінковий файл під час збірки. Посторінкові файли автоматично створюються, коли їх немає, під час `nuxt dev`.

## Розкладка Nuxt 4

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Щоб розмістити переклади всередині `app/`, встановіть `translationDir: 'app/locales'`.

## Пакети екосистеми

| Пакет | Призначення |
| --- | --- |
| [`@i18n-micro/vue`](/integrations/vue) | Інтеграція з Vue 3 (окремо, без Nuxt). |
| [`@i18n-micro/react`](/integrations/react) | Інтеграція з React. |
| [`@i18n-micro/preact`](/integrations/preact) | Інтеграція з Preact. |
| [`@i18n-micro/solid`](/integrations/solid) | Інтеграція з SolidJS. |
| [`@i18n-micro/astro`](/integrations/astro) | Інтеграція з Astro. |
| [`@i18n-micro/node`](/integrations/nodejs) | Серверний завантажувач для Node.js. |
| [`@i18n-micro/types-generator`](/integrations/types-generator) | Генерація типів TypeScript з файлів перекладу. |

Спільні внутрішні пакети підтягуються транзитивно.

## TypeScript

Модуль генерує ambient-типи для `useI18n`, `$t` та повʼязаних помічників на основі ваших файлів локалі за замовчуванням. Це увімкнено за замовчуванням (`types: true`).

Для сильнішої типізації ключів перекладів див. [`@i18n-micro/types-generator`](/integrations/types-generator).
