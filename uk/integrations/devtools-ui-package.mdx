`@i18n-micro/devtools-ui` — це редактор перекладів із вкладки Nuxt DevTools, упакований як вебкомпонент із плагіном Vite. Додайте його до проєкту на Vue, React, Preact, Solid або Astro, щоб під час розробки переглядати й редагувати JSON-файли з теки перекладів у браузері. Застосунки Nuxt уже мають його в [Nuxt DevTools](/uk/guide/devtools).

![DevTools UI: дерево файлів і редактор із текстом локалі за замовчуванням поруч із кожним ключем](/images/devtools/02-translations-editor-dark.webp)

## Встановлення {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/devtools-ui
```

```bash npm
npm install -D @i18n-micro/devtools-ui
```

```bash yarn
yarn add -D @i18n-micro/devtools-ui
```

</CodeGroup>

Без peer-залежностей.

## Налаштування {#setup}

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import { i18nDevToolsPlugin } from '@i18n-micro/devtools-ui/vite'

export default defineConfig({
  plugins: [i18nDevToolsPlugin({ translationDir: 'src/locales' })],
})
```

| Опція | За замовчуванням | Примітки |
| --- | --- | --- |
| `translationDir` | `'src/locales'` | Тека з JSON-файлами відносно кореня Vite. |
| `base` | `'/__i18n_api'` | Базовий шлях ендпоінтів API. |
| `injectButton` | `true` | Додає плаваючу кнопку на сторінки, що віддаються через трансформацію `index.html` у Vite. В Astro таких сторінок немає: див. нижче. |
| `defaultLocale` | перший файл локалі в `translationDir` | Повертається через `/config`. |
| `fallbackLocale` | `defaultLocale` | Повертається через `/config`. |

Плагін працює лише на dev-сервері (`apply: 'serve'`); продакшн-збірка не містить нічого з нього. Кнопка відкриває `/__i18n_devtools.html`, яка читає та зберігає файли через ендпоінти плагіна:

| Ендпоінт | Що робить |
| --- | --- |
| `GET <base>/translations` | усі словники в `translationDir` за відносним шляхом |
| `POST <base>/save` | тіло `{ file, content }`; перезаписує наявний `.json` усередині `translationDir`, 403 для всього іншого. Ніколи не створює файл |
| `GET <base>/config` | `{ defaultLocale, fallbackLocale, locales, translationDir }`; `locales` беруться з кореневих файлів у `translationDir` |

Ендпоінти відповідають лише сторінці devtools: запит з іншого origin чи хоста отримує `403`, а `/save` приймає лише `application/json` (`415`). Сторінка дізнається про зміни файлів через HMR-сокет Vite.

В Astro додайте інтеграцію замість плагіна. Вона додає застосунок на панель інструментів розробника:

```ts
// astro.config.mjs
import { defineConfig } from 'astro/config'
import { i18nDevToolsIntegration } from '@i18n-micro/devtools-ui/vite'

export default defineConfig({
  integrations: [i18nDevToolsIntegration({ translationDir: 'src/locales' })],
})
```

Збереження лише записує файл. Застосунок, який імпортує JSON через Vite, отримує його через HMR; щоб зміни застосовувалися безпосередньо до запущеного екземпляра, використовуйте міст.

## Міст до запущеного екземпляра {#bridge-to-a-live-instance}

Щоб вбудувати редактор у власну сторінку й одразу застосовувати зміни до запущеного екземпляра, створіть міст з адаптера та передайте його елементу `<i18n-devtools-ui>`:

```ts
import { createBridge, register } from '@i18n-micro/devtools-ui'
import { i18n, locales } from './i18n' // a runtime, React, Preact or Solid instance

register() // defines <i18n-devtools-ui> once

const bridge = createBridge({
  adapter: {
    getRouteCache: () => Object.fromEntries(i18n.storage.translations),
    addTranslations: (locale, content, merge) => i18n.addTranslations(locale, content, merge),
    addRouteTranslations: (locale, route, content, merge) => i18n.addRouteTranslations(locale, route, content, merge),
    subscribe: (cb) => i18n.subscribe(cb),
    getCurrentLocale: () => i18n.locale,
  },
  locales,
  defaultLocale: 'en',
  translationDir: 'src/locales',
})

const el = document.createElement('i18n-devtools-ui') as HTMLElement & { bridge: typeof bridge }
el.bridge = bridge
document.body.append(el)
```

`getRouteCache` має повертати словники з ключами `locale:route` (`en:index`, `en:blog-post`) — саме це містить `i18n.storage.translations`. Для екземпляра Vue використовуйте `i18n.global.getRouteCache()` і `i18n.global.subscribeToChanges(cb)`.

`saveTranslation` спочатку оновлює екземпляр, а потім надсилає POST на `<base>/save`. Коли ендпоінта немає (статична preview-збірка) або dev-сервер недоступний, зміна зберігається в `localStorage`; будь-яка інша помилка збереження відновлює попередній словник і викидає виняток.

## API {#api}

| Експорт | Точка входу |
| --- | --- |
| `i18nDevToolsPlugin(options)`, `i18nDevToolsIntegration(options)` | `@i18n-micro/devtools-ui/vite` |
| `register()`, `I18nDevToolsElement` | `@i18n-micro/devtools-ui` |
| `createBridge(options)`, типи `BridgeAdapter`, `CreateBridgeOptions` | `@i18n-micro/devtools-ui` (також `/bridge/create`) |
| тип `I18nDevToolsBridge` | `@i18n-micro/devtools-ui` (також `/bridge`) |
| `createRpcClient`, `setupRpcHost` | `@i18n-micro/devtools-ui` |

Повні сигнатури: [довідник пакета](/uk/api/packages/devtools-ui).
