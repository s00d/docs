# Пакет DevTools UI (`@i18n-micro/devtools-ui`)

Пакет `@i18n-micro/devtools-ui` надає окремий інтерфейс інструментів розробки для керування перекладами. Він включає Vite-плагін для автоматичної інтеграції та універсальну bridge-систему для framework-agnostic підтримки i18n.

## Огляд

`@i18n-micro/devtools-ui` — це самодостатній пакет, що надає:

- **Vite-плагін** — автоматичне впорскування кнопки та API-ендпоінти
- **Універсальний Bridge** — framework-agnostic створення bridge для будь-якої реалізації i18n
- **Web-компонент** — кастомний елемент для UI DevTools
- **Операції з файлами** — перелік, завантаження та збереження файлів перекладу через API

## Швидкий старт

### Налаштування Vite-плагіна

Найпростіший спосіб використати DevTools — через Vite-плагін, який автоматично впорскує плаваючу кнопку та надає всі необхідні API-ендпоінти:

```typescript
import { defineConfig } from 'vite'
import { i18nDevToolsPlugin } from '@i18n-micro/devtools-ui/vite'

export default defineConfig({
  plugins: [
    // ... other plugins
    i18nDevToolsPlugin({
      base: '/__i18n_api', // Optional: API endpoint base path (default: '/__i18n_api')
      translationDir: 'src/locales', // Optional: translation files directory
      injectButton: true, // Optional: automatically inject floating button (default: true)
    }),
  ],
})
```

### Опції плагіна

```typescript
interface DevToolsPluginOptions {
  base?: string // API endpoint base path (default: '/__i18n_api')
  translationDir?: string // Translation files directory (default: 'src/locales')
  injectButton?: boolean // Automatically inject floating button (default: true)
}
```

## Можливості

### Автоматичне впорскування кнопки

Плагін автоматично впорскує плаваючу кнопку у правий нижній кут вашого застосунку:

- **Розумне приховування** — кнопка ховається, коли курсор далеко (>200px)
- **Часткова видимість** — навіть коли схована, невелика частина залишається видимою для легкого доступу
- **Плавні анімації** — переходи та hover-ефекти для кращого UX
- **Автопояв на hover** — кнопка повністю зʼявляється, коли ви наводите на видиму частину

### API-ендпоінти

Плагін надає такі API-ендпоінти:

#### `GET /__i18n_api/files`

Отримати список усіх файлів перекладу та структуру каталогів.

**Відповідь:**

```json
{
  "files": ["en.json", "fr.json", "pages/home/en.json"],
  "structure": {
    "en.json": "en.json",
    "fr.json": "fr.json",
    "pages": {
      "home": {
        "en.json": "pages/home/en.json"
      }
    }
  }
}
```

#### `GET /__i18n_api/file?path=...`

Завантажити конкретний файл перекладу.

**Query-параметри:**

- `path` — відносний шлях до файла перекладу (наприклад, `en.json` або `pages/home/en.json`)

**Відповідь:**

```json
{
  "success": true,
  "content": {
    "welcome": "Welcome",
    "hello": "Hello"
  },
  "path": "en.json"
}
```

#### `POST /__i18n_api/save`

Зберегти вміст перекладу у файл.

**Тіло запиту:**

```json
{
  "file": "en.json",
  "content": {
    "welcome": "Welcome",
    "hello": "Hello"
  }
}
```

**Відповідь:**

```json
{
  "success": true
}
```

#### `GET /__i18n_api/config`

Отримати конфігурацію i18n.

**Відповідь:**

```json
{
  "defaultLocale": "en",
  "fallbackLocale": "en",
  "locales": [{ "code": "en", "displayName": "English", "iso": "en-US" }],
  "translationDir": "src/locales"
}
```

## Універсальний Bridge

Пакет надає універсальну функцію створення bridge, що працює з будь-якою реалізацією i18n:

```typescript
import { createBridge } from '@i18n-micro/devtools-ui'
import type { BridgeAdapter } from '@i18n-micro/devtools-ui'

// Create an adapter for your i18n instance
const adapter: BridgeAdapter = {
  getRouteCache: () => i18nInstance.cache.route,
  addTranslations: (locale, content, merge) => {
    i18nInstance.addTranslations(locale, content, merge)
  },
  addRouteTranslations: (locale, routeName, content, merge) => {
    i18nInstance.addRouteTranslations(locale, routeName, content, merge)
  },
  subscribe: (callback) => {
    return i18nInstance.subscribe(callback)
  },
  getCurrentLocale: () => i18nInstance.locale,
  getFallbackLocale: () => i18nInstance.fallbackLocale,
}

// Create bridge
const bridge = createBridge({
  adapter,
  locales: localesConfig,
  defaultLocale: 'en',
  translationDir: 'src/locales',
})
```

### Інтерфейс Bridge Adapter

```typescript
interface BridgeAdapter {
  // Get translations cache
  // Keys are in format "locale:routeName" (e.g., "en:index", "en:home")
  getRouteCache: () => Record<string, TranslationContent>

  // Add or update translations for a locale
  addTranslations: (locale: string, content: TranslationContent, merge: boolean) => void

  // Add or update route-specific translations
  addRouteTranslations: (locale: string, routeName: string, content: TranslationContent, merge: boolean) => void

  // Subscribe to changes in translations
  subscribe: (callback: () => void) => () => void

  // Get current locale (optional)
  getCurrentLocale?: () => string

  // Get fallback locale (optional)
  getFallbackLocale?: () => string
}
```

Пакет експортує кастомний елемент, який можна використовувати безпосередньо:

## Безпека

Плагін містить заходи безпеки:

- **Запобігання Path Traversal** — усі шляхи файлів валідуються, щоб гарантувати, що вони залишаються в межах кореня проєкту
- **Валідація розширення файла** — можна зберігати лише файли `.json`
- **Валідація кореня проєкту** — файли доступні лише в межах налаштованого кореня проєкту

## Розробка vs продакшн

- **Лише розробка** — плагін працює лише у режимі розробки (`apply: 'serve'`)
- **Без впливу на продакшн** — плагін автоматично виключається з продакшн-збірок
- **Без рантайм-накладних витрат** — жодного коду не потрапляє у продакшн-бандли

## Приклади

### Кастомна реалізація bridge

```typescript
import { createBridge } from '@i18n-micro/devtools-ui'
import type { BridgeAdapter } from '@i18n-micro/devtools-ui'

class CustomI18n {
  private cache = {
    root: {},
    route: {},
  }

  addTranslations(locale: string, content: Record<string, unknown>) {
    this.cache.root[locale] = content
  }

  subscribe(callback: () => void) {
    // Your subscription logic
    return () => {} // unsubscribe
  }
}

const customI18n = new CustomI18n()

const adapter: BridgeAdapter = {
  getRouteCache: () => customI18n.cache.route,
  addTranslations: (locale, content) => {
    customI18n.addTranslations(locale, content)
  },
  addRouteTranslations: () => {}, // Not implemented
  subscribe: (callback) => customI18n.subscribe(callback),
}

const bridge = createBridge({
  adapter,
  locales: [{ code: 'en', displayName: 'English' }],
  defaultLocale: 'en',
})
```
