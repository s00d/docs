---
title: "Runtime"
description: "Незалежний від фреймворку createI18n для браузерів, воркерів і edge-середовищ з @i18n-micro/runtime."
---

`@i18n-micro/runtime` — це незалежний від фреймворку екземпляр i18n: словники, `t()`, множина, форматування `Intl` і підписка на зміни, без `fs` і без фреймворку. Використовуйте його у звичайному TypeScript, web worker, edge-функції або як основу власної прив’язки. Пакети React, Preact, Node і Astro розширюють цей самий клас.

## Встановлення {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/runtime
```

```bash npm
npm install @i18n-micro/runtime
```

```bash yarn
yarn add @i18n-micro/runtime
```

</CodeGroup>

Без peer-залежностей. Для файлів перекладів на диску використовуйте [`@i18n-micro/node`](/uk/integrations/nodejs-package).

## Налаштування {#setup}

```ts
import { createI18n } from '@i18n-micro/runtime'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    en: { greeting: 'Hello, {name}!', apples: 'no apples | one apple | {count} apples' },
    de: { greeting: 'Hallo, {name}!' },
  },
  routeMessages: {
    about: { en: { title: 'About us' } },
  },
})
```

Усі опції (`plural`, `missingWarn`, `missingHandler`, `numberFormats`, `datetimeFormats`) перелічено в розділі [Екземпляр](/uk/integrations/overview#the-instance).

## Переклад {#translate}

```ts
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.tc('apples', 5) // '5 apples'
i18n.tn(1234.5) // '1,234.5'

i18n.setRoute('about')
i18n.t('title') // 'About us' (route dictionary)
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!' (root, still visible)
```

Завантажуйте додаткові словники пізніше:

```ts
i18n.loadMessages({ fr: { greeting: 'Bonjour, {name} !' } }, { about: { fr: { title: 'À propos' } } })
i18n.addTranslations('fr', { nav: { home: 'Accueil' } }) // deep merge; pass false to replace

await i18n.loadFromUrl('/locales/fr.json', { locale: 'fr' })
await i18n.loadFromUrl('/locales/pages/about/fr.json', { locale: 'fr', routeName: 'about' })
await i18n.loadFromUrls([
  { url: '/locales/en.json', locale: 'en' },
  { url: '/locales/de.json', locale: 'de' },
])
```

`loadFromUrl` використовує `fetch` (передайте `init` для заголовків) і кидає помилку на відповідь, що не є OK. `loadFromUrls` завантажує по черзі.

## Перемикання локалі {#switch-locale}

```ts
i18n.locale = 'de'
i18n.t('greeting', { name: 'Ada' }) // 'Hallo, Ada!'
```

Зміни локалі, маршруту та словників сповіщають підписників — саме так прив’язки фреймворків виконують повторний рендеринг:

```ts
const stop = i18n.subscribe(() => {
  document.querySelector('#greeting')!.textContent = i18n.t('greeting', { name: 'Ada' }) as string
})
i18n.locale = 'fr'
stop()
```

`getSnapshot()` повертає рядок, що змінюється з кожним сповіщенням (для сховищ у стилі `useSyncExternalStore`).

## Для кожного запиту {#per-request}

Екземпляр містить одну локаль і один маршрут. На сервері не перемикайте спільний екземпляр для кожного запиту: два паралельні запити бачитимуть локаль одне одного. `i18n.fork(locale)` дає запиту власний екземпляр: власні локаль, резервну локаль і маршрут; ті самі словники, форматери й правила. Форк коштує однаково незалежно від кількості словників. Форк бачить записи в батьківський екземпляр до свого першого власного запису, а його записи залишаються в ньому. [Node.js](/uk/integrations/nodejs-package#per-request) додає `run`.

## API {#api}

| Член | Примітки |
| --- | --- |
| `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has` | див. [Переклад і форматування](/uk/integrations/overview#translate-and-format) |
| `locale`, `fallbackLocale` | get/set |
| `currentRoute`, `setRoute(name)`, `getRoute()` | активний маршрут, за замовчуванням `'index'` |
| `loadMessages(messages?, routeMessages?)` | злиття багатьох локалей і маршрутів за раз |
| `addTranslations(locale, tree, merge = true)`, `addRouteTranslations(locale, route, tree, merge = true)` | |
| `loadFromUrl(url, { locale?, routeName?, init? })`, `loadFromUrls(entries)` | `fetch` JSON |
| `hasTranslation(key)` | активна локаль, будь-який маршрут (на відміну від `has`, що перевіряє активний маршрут і корінь) |
| `setTranslation(key, value)`, `resolveTranslations()` | запис одного ключа; читання злитого дерева |
| `clear()`, `clearCache()` | скидання всіх словників |
| `subscribe(cb)`, `getSnapshot()` | сповіщення про зміни |
| `storage` | `{ translations: Map<'locale:route', Translations> }` |

Код, що не є мовним тегом, отримує свої правила множини з `localeIso: { ua: 'uk-UA' }`; `localeIsoMap(locales)` будує це із записів списку локалей, що мають `iso`.

Експорти модуля: `createI18n`, `I18n`, `fetchJsonTranslations`, `FormatService`, `interpolate`, `localeIsoMap` і типи `I18nOptions`, `LoadFromUrlOptions`, `LoadFromUrlEntry`, `TranslationStorage`, `Translations`, `Locale`, `PluralFunc`. Повні сигнатури: [довідка пакета](/uk/api/packages/runtime).
