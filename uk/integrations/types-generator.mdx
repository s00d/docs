description: "Генеруйте автодоповнення TypeScript для ключів перекладів із ваших JSON-файлів у Nuxt або будь-якому проєкті Vite."
---

`@i18n-micro/types-generator` зчитує кожен JSON-файл у вашій теці перекладів і записує декларацію, що перелічує всі ключі. Додайте його, коли хочете, щоб редактор підказував ключі в `t()`, `$t()` і `<I18nT keypath>`. Він працює як модуль Nuxt і як плагін Vite або Rollup та перегенеровує типи, коли файл змінюється.

## Встановлення {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/types-generator
```

```bash npm
npm install -D @i18n-micro/types-generator
```

```bash yarn
yarn add -D @i18n-micro/types-generator
```

</CodeGroup>

Peer-залежність: `@nuxt/kit` `^3.18.0 || ^4.0.0`. Її імпортує лише точка входу `/nuxt`; у проєкті лише з Vite попередження про peer-залежність можна ігнорувати.

## Nuxt {#nuxt}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro', '@i18n-micro/types-generator/nuxt'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Модуль записує `.nuxt/types/i18n-micro.d.ts`, і Nuxt додає його до контексту типів; нічого не потрібно підключати вручну. Він зчитує `i18nTypes.translationDir`, а інакше — там, де `nuxt-i18n-micro` зчитує переклади: `translationDir` (з `i18n` або вбудованих опцій модуля, за замовчуванням `'locales'`) у кожному шарі та `additionalTranslationDirs`. Редагування JSON-файлу в цій теці перегенеровує типи в `nuxi dev`. `i18nTypes.outputFile` у Nuxt ігнорується (про це повідомляє попередження).

## Vite {#vite}

`I18nTypesPlugin` — це плагін Vite, який також приймає Rollup. Для іншого бандлера викликайте `generateTypes` у скрипті.

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { I18nTypesPlugin } from '@i18n-micro/types-generator'

export default defineConfig({
  plugins: [
    vue(),
    I18nTypesPlugin({
      srcDir: process.cwd(),
      translationDir: 'src/locales',
      outputFile: 'src/i18n-micro.d.ts',
    }),
  ],
})
```

| Опція | Обов’язкова | Примітки |
| --- | --- | --- |
| `srcDir` | так | Базовий каталог; `translationDir` визначається відносно нього. |
| `translationDir` | так | Тека з JSON-файлами (включно з підтеками, як-от `pages/`) або масив тек. |
| `outputFile` | ні | Куди записувати декларацію; за замовчуванням `<srcDir>/i18n-micro.d.ts`. |

Плагін генерує типи один раз на початку збирання, а на сервері розробки перегенеровує їх через 300 ms після зміни в теці. Переконайтеся, що `include` у вашому `tsconfig.json` охоплює вихідний файл.

## Використання ключів {#use-the-keys}

Згенерований файл розширює `DefineLocaleMessage` в `@i18n-micro/types`, що перетворює `TranslationKey` на ваші ключі:

```ts
declare module '@i18n-micro/types' {
  export interface DefineLocaleMessage {
    nav: object
    'nav.home': string
    'profile.title': string
  }
}
```

Ключі — це ті, на які відповідає `t()`, зокрема й об’єкти, з кожної локалі та кожного файлу сторінки, з типом їхнього значення в JSON. `TranslationKey` — це об’єднання цих ключів і будь-якого рядка, тож ви отримуєте автодоповнення, а не помилки: ключ з помилкою в написанні чи динамічний ключ однаково компілюється. Параметри та значення, що повертаються, не типізуються.

Для динамічних ключів з відомим префіксом `ScopedKey<'prefix'>` звужує тип до відповідних ключів:

```ts
import type { ScopedKey } from '@i18n-micro/types'

const statusText = (status: string) => t(`status.${status}` as ScopedKey<'status'>)
```

`TranslationKey` і `ScopedKey` надходять з `@i18n-micro/types` (React, Preact і Solid реекспортують `TranslationKey`; Vue — ні).

## API {#api}

| Експорт | Точка входу | Примітки |
| --- | --- | --- |
| `I18nTypesPlugin(options)` | `@i18n-micro/types-generator` | плагін Vite і Rollup |
| `generateTypes(options)` | `@i18n-micro/types-generator` | записує файл, повертає його шлях |
| `getTypesString(options)` | `@i18n-micro/types-generator` | повертає декларацію без запису |
| `formatKeyProperty(key)` | `@i18n-micro/types-generator` | хелпер |
| Модуль Nuxt (`configKey: 'i18nTypes'`) | `@i18n-micro/types-generator/nuxt` | опція `translationDir` |

Повні сигнатури: [довідник пакета](/uk/api/packages/types-generator).
