`@i18n-micro/vue` — це плагін Vue 3 з ядром перекладу Nuxt I18n Micro: реактивний `t()`, глобальний `$t`, чотири компоненти та необов'язковий адаптер vue-router. Використовуйте його у Vue-застосунку на Vite або з SSR, який не побудовано на Nuxt. Модель екземпляра, контракт маршрутизатора та пропси компонентів спільні з іншими пакетами й описані в розділі [Фреймворки](/uk/integrations/overview).

## Встановлення {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vue
```

```bash npm
npm install @i18n-micro/vue
```

```bash yarn
yarn add @i18n-micro/vue
```

</CodeGroup>

Peer-залежності: `vue` `^3.3.0`; `vue-router` `^4.5.1 || ^5.0.0` (необов'язково, лише для `@i18n-micro/vue/router`). Опубліковані типи потребують Vue 3.5.5 або новішої версії з `skipLibCheck: false`; з `skipLibCheck: true`, звичайним налаштуванням шаблонів, компілюються й старіші версії.

## Налаштування {#setup}

```ts
// src/main.ts
import { createApp } from 'vue'
import { createI18n } from '@i18n-micro/vue'
import App from './App.vue'
import en from './locales/en.json'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales: [
    { code: 'en', iso: 'en-US', displayName: 'English' },
    { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
  ],
  defaultLocale: 'en',
})

createApp(App).use(i18n).mount('#app')
```

`locales` і `defaultLocale` обов'язкові для `useI18n()`: без них він викидає `I18nLocalesKey not provided`. Передайте їх у `createI18n` (як вище), у `useI18n({ locales, defaultLocale })` або через `app.provide(I18nLocalesKey, …)` і `app.provide(I18nDefaultLocaleKey, …)`.

Плагін глобально реєструє `I18nT`, `I18nLink`, `I18nGroup` і `I18nSwitcher` та додає `$t`, `$ts`, `$tc`, `$tn`, `$td`, `$tdr`, `$has` і `$i18n` до шаблонів. Поза компонентами екземпляр доступний як `i18n.global`. Інші опції описано в розділі [екземпляр](/uk/integrations/overview#the-instance); `routeMessages` у Vue недоступний, використовуйте `addRouteTranslations`.

## Переклад {#translate}

```vue
<script setup lang="ts">
import { useI18n } from '@i18n-micro/vue'

const { t, tc, tn } = useI18n()
</script>

<template>
  <h1>{{ t('greeting', { name: 'Ada' }) }}</h1>
  <!-- Hello, Ada! -->
  <p>{{ tc('apples', 3) }}</p>
  <!-- 3 apples -->
  <p>{{ $t('nav.home') }} · {{ tn(1234.5) }}</p>
</template>
```

`useI18n()` повертає методи перекладу (`t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`), `locale` (записуваний computed), `getLocale`, `getLocales`, `defaultLocale()`, `getLocaleName`, `localePath`, `localeRoute`, `switchLocale`, `setRoute`, `getRoute`, `addTranslations`, `addRouteTranslations`, `mergeTranslations`, `resolveTranslations`, `setTranslation`, `clearCache` та `instance`.

Додаткові словники можна завантажити будь-коли; кожен компонент, що їх читає, перерендериться:

```ts
const { addTranslations, addRouteTranslations, setRoute } = useI18n()

addTranslations('de', (await import('./locales/de.json')).default)
addRouteTranslations('en', 'about', { title: 'About us' })
setRoute('about') // t('title') now reads the 'about' dictionary first
```

## Перемикання локалі {#switch-locale}

```ts
const { locale, switchLocale } = useI18n()

locale.value = 'de' // only the locale
switchLocale('de') // the locale, then router.push to the localized current path
```

Завантажте словник локалі до або після перемикання; перемикання нічого не завантажує.

`<I18nGroup>` передає своєму слоту `t` з префіксом. Ключі всередині `<I18nT>` або звичайного `t()` префікс не отримують:

```vue
<I18nGroup prefix="profile" v-slot="{ t }">
  <h2>{{ t('title') }}</h2>
  <!-- profile.title -->
</I18nGroup>
```

## Маршрутизація {#routing}

Адаптер vue-router розміщено в підшляху, тож основна точка входу ніколи не імпортує `vue-router`:

```ts
// src/main.ts
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import { createI18n } from '@i18n-micro/vue'
import { createVueRouterAdapter } from '@i18n-micro/vue/router'
import App from './App.vue'
import Home from './pages/Home.vue'
import About from './pages/About.vue'
import en from './locales/en.json'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English' },
  { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
]

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/:locale(de)?', component: Home },
    { path: '/:locale(de)?/about', component: About },
  ],
})

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales,
  defaultLocale: 'en',
  routingStrategy: createVueRouterAdapter(router, locales, 'en'),
})

createApp(App).use(router).use(i18n).mount('#app')
```

`createVueRouterAdapter(router, locales, defaultLocale)` додає префікс до кожної локалі, крім локалі за замовчуванням (`/about`, `/de/about`), і рендерить `<I18nLink>` як `RouterLink`. Зчитуйте локаль із маршруту самостійно, наприклад у `router.beforeEach`, і встановлюйте `i18n.global.locale.value`. Адаптер також можна підключити пізніше через `i18n.setRoutingStrategy(adapter)`; про власний адаптер див. [Адаптер маршрутизатора](/uk/integrations/overview#router-adapter).

## SSR {#ssr}

- Створюйте маршрутизатор, екземпляр i18n і застосунок усередині функції рендерингу для кожного запиту. Один спільний екземпляр передаватиме локаль одного відвідувача іншому.
- Використовуйте `createMemoryHistory()` на сервері, беріть локаль з URL і завантажуйте її словник (і словник резервної локалі) перед `renderToString`.
- Передайте локаль клієнту (наприклад, у скрипті `window.__STATE__`) і створіть клієнтський екземпляр із тією самою `locale`, щоб гідратація збігалася.
- `<I18nSwitcher>` читає `window.location` лише тоді, коли випадний список відкрито, тому він рендериться на сервері.

У `packages/vue/playground` є повна пара `entry-server.ts` / `entry-client.ts`.

## SEO head {#seo-head}

`useLocaleHead(options)` формує теги `lang`/`dir`, canonical, `hreflang` і `og:locale` на основі локалей та адаптера маршрутизатора. Викликайте `updateMeta()` при зміні маршруту й передавайте `metaObject` своєму менеджеру head:

```ts
import { watch } from 'vue'
import { useRoute } from 'vue-router'
import { useHead } from '@unhead/vue'
import { useLocaleHead } from '@i18n-micro/vue'

const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
watch(() => route.fullPath, () => updateMeta(), { immediate: true })
useHead(metaObject)
```

Опції: `baseUrl` (рядок або функція), `addDirAttribute` (за замовчуванням `true`), `addSeoAttributes` (за замовчуванням `true`), `identifierAttribute` (за замовчуванням `'id'`), `hreflangBaseLanguage` (за замовчуванням `false`). Локалі з `disabled: true` або `seo: false` не отримують альтернативного посилання.

| Експорт | Точка входу |
| --- | --- |
| `createI18n`, `useI18n`, `useLocaleHead` | `@i18n-micro/vue` |
| `I18nT`, `I18nLink`, `I18nSwitcher`, `I18nGroup` | `@i18n-micro/vue` |
| `VueI18n` (клас екземпляра), `I18nInjectionKey`, `I18nLocalesKey`, `I18nDefaultLocaleKey` | `@i18n-micro/vue` |
| `defaultPlural`, `FormatService`, `interpolate` | `@i18n-micro/vue` |
| Типи: `I18nRoutingStrategy`, `Locale`, `Translations`, `PluralFunc`, `Params`, `Getter`, `CleanTranslation`, `LocaleCode`, `VueI18nOptions`, `UseI18nOptions`, `UseLocaleHeadOptions`, `I18nPlugin` | `@i18n-micro/vue` |
