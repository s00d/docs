# Інтеграції

Пакети `@i18n-micro` — це легковагі, специфічні для фреймворків версії Nuxt I18n Micro, розроблені для інтеграції у різні фреймворки та середовища. Ці пакети надають основну функціональність інтернаціоналізації з мінімальним відбитком, зосереджуючись на важливих функціях перекладу та базових компонентах.

## Огляд

Ці інтеграційні пакети є **мініатюрними версіями** повного модуля Nuxt I18n Micro, що містять лише важливу функціональність, потрібну для інтернаціоналізації:

- **Основні можливості перекладу** — базові методи перекладу, множинні форми та форматування
- **Основні компоненти** — невеликий набір UI-компонентів для типових i18n-завдань
- **Патерн адаптера роутера** — гнучка інтеграція маршрутизації через абстракцію адаптера
- **Підтримка TypeScript** — повні визначення типів для типобезпечної розробки

На відміну від повного модуля Nuxt, ці пакети:

- Не включають специфічну для фреймворка логіку маршрутизації
- Вимагають від вас реалізувати адаптер роутера для функцій маршрутизації
- Зосереджуються на функціональності перекладу, а не на інтеграції з фреймворком
- Розроблені для того, щоб бути легковаговими та, коли можливо, незалежними від фреймворка

## Основні компоненти

Усі пакети для фреймворків включають наступні основні компоненти:

### `<I18nT>`

Компонент перекладу, що рендерить перекладений текст з підтримкою:

- **Інтерполяції параметрів** — заміна плейсхолдерів динамічними значеннями
- **Множинних форм** — автоматичний вибір форми множини на основі кількості
- **Форматування чисел** — форматування чисел відповідно до локалі
- **Форматування дат** — форматування дат та відносного часу
- **Рендерингу HTML** — опціональний рендеринг HTML-вмісту
- **Значень за замовчуванням** — резервний текст, коли переклад відсутній

**Приклад:**

```vue
<!-- Vue -->
<I18nT keypath="greeting" :params="{ name: 'World' }" />
```

```tsx
// React
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```tsx
// Solid
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```astro
<!-- Astro -->
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

### `<I18nLink>`

Компонент локалізованого посилання, який автоматично обробляє префікси локалей у URL. Можливості:

- **Автоматична локалізація шляху** — додає/видаляє префікси локалей на основі стратегії маршрутизації
- **Виявлення активного стану** — підсвічує поточний маршрут
- **Підтримка зовнішніх посилань** — автоматично виявляє та обробляє зовнішні URL
- **Інтеграція з роутером** — використовує компонент-посилання адаптера роутера, коли доступний
- **Кастомна стилізація** — підтримує активний стан та стан наведення

**Приклад:**

```vue
<!-- Vue -->
<I18nLink to="/about" active-class="active">
  About Us
</I18nLink>
```

```tsx
// React
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```tsx
// Solid
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```astro
<!-- Astro -->
<I18nLink href="/about" class="nav-link">
  About Us
</I18nLink>
```

### `<I18nSwitcher>`

Компонент перемикача мов, що надає інтерфейс випадаючого меню або списку для зміни локалей. Можливості:

- **Автоматичний список локалей** — генерує опції з налаштованих локалей
- **Підсвічування поточної локалі** — візуально позначає активну мову
- **Кастомні мітки** — підтримка кастомних відображуваних імен для кожної локалі
- **Інтеграція з роутером** — автоматично навігує на локалізовані шляхи
- **Доступність** — коректні ARIA-атрибути та навігація з клавіатури

**Приклад:**

```vue
<!-- Vue -->
<I18nSwitcher />
```

```tsx
// React
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```tsx
// Solid
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```astro
<!-- Astro -->
<I18nSwitcher />
```

### `<I18nGroup>`

Компонент для групування перекладів зі спільним префіксом, корисний для організації перекладів за сторінкою чи функціоналом. Можливості:

- **Обмеження префіксом** — автоматично додає префікс до всіх ключів перекладу в межах групи
- **Вкладені групи** — підтримка вкладених груп перекладів
- **Чиста організація** — допомагає підтримувати організовані структури перекладів

**Приклад:**

```vue
<!-- Vue -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

```tsx
// React
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```tsx
// Solid
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```astro
<!-- Astro -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

## Спільні опції `createI18n` \{#create-i18n-options\}

Кожен пакет для фреймворка створюється однаково — лише тип опцій має імʼя, повʼязане з
фреймворком (`ReactI18nOptions`, `SolidI18nOptions` тощо). Самі опції
ідентичні:

| Властивість      | Тип                                                       | Обовʼязково | Значення за замовчуванням | Опис                                            |
| ---------------- | --------------------------------------------------------- | -------- | ---------------- | ---------------------------------------------- |
| `locale`         | `string`                                                   | ✅       | -                | Код поточної локалі (наприклад, `'en'`)         |
| `fallbackLocale` | `string`                                                   | ❌       | Те саме, що `locale` | Резервна локаль, коли переклад відсутній    |
| `messages`       | `Record<string, Translations>`                             | ❌       | `\{\}`             | Початкові повідомлення перекладу                |
| `plural`         | `PluralFunc`                                               | ❌       | `defaultPlural`  | Кастомна функція множинних форм                 |
| `missingWarn`    | `boolean`                                                  | ❌       | `true`           | Показувати попередження в консолі для відсутніх перекладів |
| `missingHandler` | `(locale: string, key: string, routeName: string) => void` | ❌       | -                | Кастомний обробник для відсутніх перекладів     |

Все, що виходить за межі цього, є специфічним для фреймворка і задокументоване на сторінці цього пакета.

## Абстракція адаптера роутера

Усі пакети для фреймворків використовують **патерн адаптера роутера**, щоб роз'єднати i18n-функціональність з конкретними реалізаціями роутера. Цей дизайн дозволяє:

- **Гнучкість** — використовуйте будь-яку бібліотеку роутера або взагалі не використовуйте роутер
- **Незалежність від фреймворка** — тримайте логіку маршрутизації у своєму застосунку, а не в i18n-пакеті
- **Легковагове ядро** — i18n-пакет залишається малим та зосередженим

### Реалізація адаптера роутера

Щоб використовувати можливості маршрутизації, вам потрібно реалізувати інтерфейс `I18nRoutingStrategy`:

```typescript
interface I18nRoutingStrategy {
  getCurrentPath: () => string
  linkComponent?: Component
  push: (target: { path: string }) => void
  replace: (target: { path: string }) => void
  resolvePath?: (to: string | { path?: string }, locale: string) => string | { path?: string }
  getRoute?: () => { fullPath: string; query: Record<string, unknown> }
}
```

Документація кожного пакета містить повні приклади реалізації адаптерів для популярних роутерів:

- **Vue**: приклад адаптера Vue Router
- **React**: приклад адаптера React Router
- **Solid**: приклад адаптера Solid Router
- **Astro**: приклад адаптера для маршрутизації на основі файлів

## Основні можливості

Усі пакети мають ці спільні основні можливості:

### Методи перекладу

- `t()` — базовий переклад з інтерполяцією параметрів
- `ts()` — переклад, що завжди повертає рядок
- `tc()` — переклад з підтримкою множинних форм
- `tn()` — форматування чисел
- `td()` — форматування дат
- `tdr()` — форматування відносного часу
- `has()` — перевірка існування ключа перекладу

### Керування локалями

- **Перемикання локалі** — програмна зміна поточної локалі
- **Резервна локаль** — автоматичний fallback, коли переклад відсутній
- **Переклади для конкретних маршрутів** — організація перекладів на рівні сторінки
- **Кешування перекладів** — інтелектуальне кешування для продуктивності

### Підтримка TypeScript

Усі пакети надають:

- Повні визначення TypeScript
- Типобезпечні ключі перекладу (з types generator)
- Підтримку IntelliSense в IDE
- Перевірку помилок на етапі компіляції
