title: "Острови Astro"
description: "Переклади всередині островів Vue, React, Preact і Svelte з @i18n-micro/astro."
---

Острів виконується в браузері, де серверного екземпляра i18n не існує. `@i18n-micro/astro` дозволяє сторінці обрати ключі, потрібні острову, передати їх одним prop і читати їх в острові через невеликий адаптер фреймворку. Ви отримуєте `t`, `tc`, `tn`, `td`, `tdr` і `has` в островах Vue, React, Preact і Svelte, а в HTML потрапляють лише обрані рядки.

## Налаштування {#setup}

Спершу налаштуйте [інтеграцію Astro та middleware](/uk/integrations/astro-package#setup), потім додайте інтеграцію фреймворку, який ви використовуєте (`@astrojs/vue`, `@astrojs/react`, `@astrojs/preact`, `@astrojs/svelte`). Адаптери островів потребують цього фреймворку як peer-залежності: `vue` `^3.3.0`, `react` `^16.8.0 || ^17.0.0 || ^18.0.0 || ^19.0.0`, `preact` `^10.0.0 || ^11.0.0` або `svelte` `^4.0.0 || ^5.0.0`.

## Передавання перекладів острову {#pass-translations-to-an-island}

```astro
---
// src/pages/index.astro
import { getI18nProps } from '@i18n-micro/astro'
import Counter from '../components/Counter.vue'

const i18n = getI18nProps(Astro, ['counter.title', 'counter.apples'])
---

<Counter client:load i18n={i18n} />
```

`getI18nProps(Astro, keys?)` повертає `{ locale, fallbackLocale, currentRoute, translations }` (тип `I18nClientProps`). Передавайте ключі, які використовує острів: кожен розв’язується на сервері як `t()` (словники маршруту, кореневий і резервний), і в HTML потрапляють лише знайдені ключі. Без `keys` надсилається все, на що `t()` може відповісти на цій сторінці, у кожен острів, тож 2000 кореневих ключів — це близько 100 KB на острів; у dev попередження повідомляє про це понад 20 KB.

Острови перекладають лише з цього об’єкта. `t` повертає ключ для всього, що не передано, а пов’язані повідомлення не розв’язуються.

## Vue {#vue}

Викличте `provideI18n(() => props.i18n)` у кореневому компоненті острова та `useAstroI18n()` у його дочірніх компонентах. `inject` у Vue не бачить значення, наданого тим самим компонентом, тож хук має виконуватися в дочірньому компоненті, а не в кореневому:

```vue
<!-- src/components/Counter.vue -->
<script setup lang="ts">
import { provideI18n } from '@i18n-micro/astro/client/vue'
import type { I18nClientProps } from '@i18n-micro/astro'
import CounterBody from './CounterBody.vue'

const props = defineProps<{ i18n: I18nClientProps }>()
provideI18n(() => props.i18n)
</script>

<template><CounterBody /></template>
```

```vue
<!-- src/components/CounterBody.vue -->
<script setup lang="ts">
import { ref } from 'vue'
import { useAstroI18n } from '@i18n-micro/astro/client/vue'

const { t, tc } = useAstroI18n()
const count = ref(0)
</script>

<template>
  <h3>{{ t('counter.title') }}</h3>
  <button @click="count++">{{ tc('counter.apples', count) }}</button>
</template>
```

## React і Preact {#react-and-preact}

```tsx
// src/components/Counter.tsx
import { useState } from 'react'
import { I18nProvider, useAstroI18n } from '@i18n-micro/astro/client/react'
import type { I18nClientProps } from '@i18n-micro/astro'

function Body() {
  const { t, tc } = useAstroI18n()
  const [count, setCount] = useState(0)
  return <button onClick={() => setCount(count + 1)}>{t('counter.title')}: {tc('counter.apples', count)}</button>
}

export default function Counter({ i18n }: { i18n: I18nClientProps }) {
  return (
    <I18nProvider value={i18n}>
      <Body />
    </I18nProvider>
  )
}
```

Для Preact імпортуйте `I18nProvider` і `useAstroI18n` з `@i18n-micro/astro/client/preact`; API той самий.

## Svelte {#svelte}

```svelte
<!-- src/components/Counter.svelte -->
<script lang="ts">
  import { createI18nStore, useAstroI18n } from '@i18n-micro/astro/client/svelte'
  import type { I18nClientProps } from '@i18n-micro/astro'

  export let i18n: I18nClientProps
  const { t, tc } = useAstroI18n(createI18nStore(i18n))
  let count = 0
</script>

<button on:click={() => count++}>{t('counter.title')}: {tc('counter.apples', count)}</button>
```

`useAstroI18n(store)` також повертає `store` для читання через `$store` у шаблоні.

## Збережені острови {#persisted-islands}

Острів із `transition:persist` отримує нові props після навігації. React, Preact і Vue (якщо передано геттер) стежать за ними. У Svelte збережіть store і передавайте їх далі: `const store = createI18nStore(i18n)`, `const { t } = useAstroI18n(store)`, потім `$: store.set(i18n)` (з runes — `$effect(() => store.set(i18n))`).

## API {#api}

| Точка входу | Експорти |
| --- | --- |
| `@i18n-micro/astro` | `getI18nProps`, тип `I18nClientProps` |
| `@i18n-micro/astro/client/vue` | `provideI18n(props \| () => props)`, `useAstroI18n()` |
| `@i18n-micro/astro/client/react` | `I18nProvider` (prop `value`), `useAstroI18n()` |
| `@i18n-micro/astro/client/preact` | `I18nProvider` (prop `value`), `useAstroI18n()` |
| `@i18n-micro/astro/client/svelte` | `createI18nStore(props)`, `useAstroI18n(store)` |
| `@i18n-micro/astro/client` | чисті `translate`, `hasTranslation`, без фреймворку |

Кожен `useAstroI18n` повертає `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`, `setLocale`, `setRoute` і `locale`. Острів має один злитий словник, тож його `has` дає true для ключа, на який може відповісти `t`, зокрема з резервної локалі; на сервері `has` дивиться лише на активну локаль.
