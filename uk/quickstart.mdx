## 🚀 Швидкий старт

### Встановлення

Встановіть модуль у вашому Nuxt-застосунку:

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

### Базова конфігурація

Додайте модуль у `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

<Tip>
- **Файли кореневого рівня** (`locales/en.json` тощо) — переклади, спільні для всього застосунку (меню, футер, загальні елементи UI). З `translationPayloads.mode: 'premerged'` (за замовчуванням) вони мержаться в кожну сторінку на етапі збірки.
- **Посторінкові файли** (`locales/pages/<route>/<locale>.json`) — переклади, унікальні для конкретних сторінок, завантажуються лише під час відвідування сторінки.
- **Динамічні маршрути** — `pages/articles/[id].vue` мапиться на `locales/pages/articles-id/` (квадратні дужки замінюються на дефіси).
- **Автогенерація** — усі файли перекладів автоматично створюються, якщо відсутні, під час `nuxt dev`.
</Tip>

<Info>
Модуль підтримує обидва варіанти розкладки:

- **Сторінки**: `pages/**/*.vue` (Nuxt 3) або `app/pages/**/*.vue` (Nuxt 4)
- **Переклади**: за замовчуванням тримайте `locales/` у **корені проєкту** (рекомендована домовленість), а не всередині `app/`

```tree
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   ├── en.json
│   └── pages/
└── nuxt.config.ts
```

Опціональне спільне розміщення: `i18n: \{ translationDir: 'app/locales' \}` (див. [fixture `n3`](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/n3)).

Для опціонального CLI-помічника `text-to-i18n` використовуйте [`nuxt-i18n-micro-cli` ≥ 2.1.1](/guides/cli#-text-to-i18n-command), щоб `app/pages` та `app/components` сканувалися з кореня проєкту.
</Info>

### Базове використання

Використовуйте переклади у своїх компонентах:

```vue
<template>
  <div>
    <h1>{{ $t('welcome') }}</h1>
    <p>{{ $t('description', { name: 'World' }) }}</p>

    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" @click="$switchLocale(locale.code)">
        {{ locale.code }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useI18n } from '#imports'

const { $t, $getLocales, $switchLocale } = useI18n()
</script>
```
