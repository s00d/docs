# 📚 Приклади та використання Nuxt I18n Micro

Цей розділ містить різноманітні приклади, що демонструють, як використовувати `Nuxt I18n Micro` у вашому Nuxt.js-застосунку. Ви побачите, як перемикати локалі, використовувати компоненти `<i18n-link>`, `<i18n-switcher>` та `<i18n-t>`, а також динамічно обробляти ключі перекладу.

## 🛠️ Базове налаштування

Ось базове налаштування для початку роботи з `Nuxt I18n Micro`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Перемикання локалей

### Програмне перемикання локалей

Цей приклад демонструє, як перемикати локалі програмно за допомогою кнопок:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Приклад JSON для перемикання локалей

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### Використання компонента `<i18n-switcher>`

Компонент `<i18n-switcher>` надає випадаючий список для перемикання локалей із можливістю налаштування підписів:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 🌐 Використання `<i18n-link>` для локалізованої навігації

Компонент `<i18n-link>` автоматично обробляє маршрутизацію з урахуванням локалі:

```vue
<template>
  <div>
    <i18n-link to="/about">{{ $t('about') }}</i18n-link>
    <i18n-link :to="{ name: 'index' }">{{ $t('home') }}</i18n-link>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Приклад JSON для навігаційних посилань

```json
{
  "about": "About Us",
  "home": "Home"
}
```

### Приклад зі стилізацією активного посилання

## 📝 Рендеринг динамічних ключів із файлів перекладів

У деяких сценаріях ви можете захотіти ітерувати динамічні ключі, збережені у ваших файлах перекладів, і рендерити їхні значення умовно. Наведений нижче приклад демонструє, як досягти цього за допомогою `Nuxt I18n Micro`.

### Приклад: рендеринг динамічних ключів

Цей приклад отримує масив ключів із певного шляху перекладу (у цьому випадку — `dynamic`) та ітерує ними. Кожен ключ перевіряється на існування за допомогою `$has` перед рендерингом його значення з `$t`.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Приклад файлу перекладу (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Приклад: рендеринг динамічних ключів з обʼєкта

У цьому прикладі ми обробляємо обʼєкт, що зберігається у вашому файлі перекладу. Ми отримуємо та ітеруємо ключі обʼєкта, динамічно рендерячи як імена ключів, так і повʼязані з ними значення.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Приклад файлу перекладу (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 Використання `<i18n-t>` для перекладів зі слотами та інтерполяцією

Компонент `<i18n-t>` корисний для рендерингу перекладів із динамічним вмістом та HTML-тегами:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### Приклад JSON для `<i18n-t>`

```json
{
  "greeting": "Welcome to the page"
}
```

### З інтерполяцією

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### Приклад JSON для інтерполяції

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 Використання `$tc` для множинних форм

Функція `$tc` у `Nuxt I18n Micro` обробляє множину на основі кількості та налаштувань локалі. Це корисно для динамічного налаштування повідомлень, повʼязаних із підрахунком елементів, сповіщень або інших сутностей, кількість яких може змінюватися.

### Приклад: використання `$tc` для множинних форм

У наступному прикладі ми відображаємо повідомлення, що вказує на кількість яблук, за допомогою `$tc`. Ключ перекладу обробляє кілька множинних форм на основі наданої кількості.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### Приклад JSON для множинних форм

Ось як можна визначити переклад у вашому JSON-файлі для обробки різних множинних форм:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Пояснення

- **`$tc('apples', 0)`**: повертає першу форму, використовується, коли кількість дорівнює нулю (`"no apples"`).
- **`$tc('apples', 1)`**: повертає другу форму, використовується, коли кількість дорівнює одиниці (`"one apple"`).
- **`$tc('apples', 10)`**: повертає третю форму зі значенням кількості, використовується, коли кількість два або більше (`"10 apples"`).

### Додатковий приклад зі складнішими правилами множинних форм

Якщо вашому застосунку потрібно обробляти складніші правила множинних форм (наприклад, окремі випадки для zero, one, two, few, many, other), ви можете відповідно розширити рядки перекладу:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: можна налаштувати для повернення `"two apples"`.
- **`$tc('apples', 3)`**: може повертати `"a few apples"`, залежно від правил, визначених для кількості.

## 🌐 Використання `$tn` для форматування чисел

Функція `$tn` форматує числа відповідно до поточної локалі за допомогою API `Intl.NumberFormat`. Це корисно для відображення чисел у форматі, що відповідає регіональним налаштуванням користувача, як-от валюта, відсотки чи інші числові формати.

### Приклад: використання `$tn` для форматування чисел

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ Використання `$td` для форматування дати й часу

Функція `$td` форматує дати та час відповідно до поточної локалі за допомогою API `Intl.DateTimeFormat`. Це корисно для відображення дат і часу у форматах, звичних для користувача згідно з його налаштуваннями локалі.

### Приклад: використання `$td` для форматування дати й часу

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ Використання `$tdr` для форматування відносної дати

Функція `$tdr` форматує дати як відносний час (наприклад, «5 хвилин тому», «2 дні тому») відповідно до поточної локалі за допомогою API `Intl.RelativeTimeFormat`. Це корисно для відображення різниць у часі відносно поточної дати й часу.

### Приклад: використання `$tdr` для форматування відносної дати

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
