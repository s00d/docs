`useI18nHead()` змінює SEO-теги, які генерує модуль, лише для однієї сторінки. Використовуйте його, коли сторінка знає краще за роутер: стаття з CMS, що існує лише в деяких локалях, canonical URL з API, додаткові теги `og:`. Ви отримуєте згенеровані теги з вашими перевизначеннями, злитими поверх.

## Сигнатура {#signature}

```ts
useI18nHead(input?: MaybeRefOrGetter<I18nHeadInput | null>): { pageHead: any; resetPageHead: () => void }
```

Реєструє перевизначення SEO-тегів head i18n на рівні сторінки.
Зливаються поверх результату `useLocaleHead` плагіном `02.meta`.

Віддавайте перевагу getter-функції (`() => ({ … })`), коли значення надходять із `$t` / `t`, щоб вони
повторно обчислювалися при зміні локалі. Звичайний об'єкт обчислюється один раз і залишається незмінним.

| Параметр | Тип | Опис |
| --- | --- | --- |
| `input` *(необов'язковий)* | `MaybeRefOrGetter<I18nHeadInput \| null>` |  |

Працює з [`meta: true`](/uk/api/module-options#meta) (за замовчуванням): meta-плагін модуля зливає вхідні дані поверх результату [`useLocaleHead`](/uk/composables/useLocaleHead) під час кожного рендерингу head. З `meta: false` ніщо їх не читає.

Перевизначення скидається, коли змінюється ім'я маршруту. Сторінка, яка встановлює `disableMeta`, взагалі не отримує тегів i18n, включно з перевизначеннями.

## Вхідні дані {#input}

`I18nHeadInput` (з `@i18n-micro/types`):

| Ключ | Тип | Дія |
| --- | --- | --- |
| `htmlAttrs` | `Record<string, string>` | Зливається з атрибутами `<html>` (`lang`, `dir`). |
| `meta` | `I18nHeadMeta[]` | Додається після згенерованих тегів; замінює тег із тим самим `id`, `property` або `name`. |
| `link` | `I18nHeadLink[]` | Додається після згенерованих посилань; замінює посилання з тим самим `id` або `rel` + `hreflang`. |
| `replace.canonical` | `string \| false` | Замінити canonical `href` або видалити посилання. |
| `replace.hreflang` | `I18nHeadLink[] \| false` | Замінити або видалити **всі** посилання `rel="alternate"`, включно з `x-default`. |
| `replace.xDefault` | `I18nHeadLink \| false` | Замінити або видалити посилання `x-default`. |
| `replace.ogLocale` | `string \| false` | Замінити або видалити `og:locale`. |
| `replace.ogUrl` | `string \| false` | Замінити або видалити `og:url`. |
| `replace.ogAlternates` | `string[] \| false` | Перебудувати `og:locale:alternate` з цих кодів локалей (через `og` / `iso`), пропускаючи поточну локаль, невідомі коди та коди без значення `og` чи `iso`, або видалити їх. |
| `disable` | `I18nHeadDisableGroup[]` | Прибрати згенеровані групи: `'hreflang'` (без `x-default`), `'x-default'`, `'canonical'`, `'og'` (`og:locale` + `og:url`), `'og-alternates'`, `'html'`. |

Порядок застосування: `disable`, потім `replace`, потім `htmlAttrs`, `meta`, `link`.

## Приклад {#example}

Стаття, яка існує лише в деяких локалях, з альтернативними URL з API:

```vue
<script setup lang="ts">
const route = useRoute()
const { t } = useI18n()
const { data: article } = await useFetch<{ title: string; urls: Record<string, string> }>(`/api/articles/${route.params.slug}`)

useI18nHead(() => {
  if (!article.value) return null
  const codes = Object.keys(article.value.urls)
  return {
    meta: [{ property: 'og:title', content: article.value.title || t('blog.title') }],
    replace: {
      hreflang: codes.map((code) => ({ rel: 'alternate', hreflang: code, href: article.value!.urls[code]! })),
      ogAlternates: codes,
    },
  }
})
</script>
```

Передавайте getter-функцію, як тут, коли значення надходять із `t()` або асинхронних даних: вона перезапускається при зміні локалі. Звичайний об'єкт читається один раз.
