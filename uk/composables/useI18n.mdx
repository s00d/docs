---
title: "useI18n"
description: "useI18n повертає допоміжні функції runtime (`$t`, `$tc`, `$localePath`, …) як звичайний об'єкт, з префіксом `$` і без нього."
---

`useI18n()` повертає допоміжні функції runtime модуля як звичайний об'єкт. Використовуйте його в `<script setup>`, composables і плагінах замість звернення до `useNuxtApp()`. Кожна допоміжна функція доступна під своїм ім'ям із `$` і під простим псевдонімом: `t` і `$t` — це одна й та сама функція.

## Сигнатура {#signature}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Усі допоміжні функції runtime як звичайний об'єкт.

Ті самі функції, які плагін впроваджує як `$t`, `$tc` тощо, доступні як під іменем із префіксом-доларом,
так і під простим псевдонімом — тож працюють і `const { t } = useI18n()`, і
`const { $t } = useI18n()`.

**Повертає** — допоміжні функції, описані в [довіднику методів](/uk/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

Повернений об'єкт містить усі допоміжні функції [`PluginsInjections`](/uk/api/methods). Кожну з них задокументовано на сторінці [Допоміжні функції](/uk/api/methods).

## Приклад {#example}

```vue
<script setup lang="ts">
const { t, tc, localePath, switchLocale, getLocale } = useI18n()

const title = computed(() => t('page.title'))
</script>

<template>
  <h1>{{ title }}</h1>
  <p>{{ tc('items', 3) }}</p>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
  <button @click="switchLocale(getLocale() === 'en' ? 'de' : 'en')">{{ t('nav.switch') }}</button>
</template>
```

## Чого немає в типі {#not-in-the-type}

`$defineI18nRoute` типізовано лише в `useNuxtApp()`:

```ts
const { $defineI18nRoute } = useNuxtApp()
```
