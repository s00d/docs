Nuxt I18n Micro — це легковагий, високопродуктивний i18n-модуль для Nuxt, розроблений для великих проєктів. Він скорочує час збірки, споживання памʼяті та розмір бандлу порівняно з традиційними i18n-рішеннями, як-от `@nuxtjs/i18n`.

Ядро — це один модуль Nuxt плюс невеликий набір runtime-плагінів. Префікси локалей обробляються пакетами `@i18n-micro/route-strategy` (на етапі збірки) та `@i18n-micro/path-strategy` (на етапі виконання). Переклади зберігаються лише у форматі JSON і розділені між спільними кореневими файлами та файлами для окремих сторінок, які автоматично генеруються під час розробки.

## Коли варто використовувати Nuxt I18n Micro

- Вам потрібні ліниво завантажувані посторінкові переклади без роздування Nitro-payload.
- Ви хочете маршрутизацію на основі стратегій без накладних витрат на генерацію маршрутів під час виконання.
- Вам потрібно, щоб SSR та edge-деплойменти залишалися швидкими під навантаженням.
- Ви мігруєте з `@nuxtjs/i18n` і хочете менший runtime зі схожою ергономікою.
