---

Nuxt I18n Micro — це легкий високопродуктивний i18n-модуль для Nuxt 3 і 4, створений для великих проєктів. Він зберігає низькими час збірки, використання пам'яті та розмір бандла порівняно з традиційними i18n-рішеннями на кшталт `@nuxtjs/i18n`.

Локалізовані маршрути генеруються під час збірки за допомогою `@i18n-micro/route-strategy` і розв'язуються під час виконання за допомогою `@i18n-micro/path-strategy`, тож посилання, перемикач, `hreflang` і перенаправлення узгоджуються з роутером. Переклади зберігаються лише в JSON і розділені між спільними кореневими файлами та файлами окремих сторінок, які dev-сервер створює за вас, із вбудованим HMR.

<CodeGroup>

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>
