---
title: "<i18n-group>"
description: "Компонент <i18n-group> передає своєму слоту функцію t, обмежену префіксом ключа."
---

`<i18n-group>` прив'язує блок розмітки до одного префікса ключів. Використовуйте його, коли багато ключів розділу мають спільний префікс і ви не хочете його повторювати. Слот за замовчуванням отримує `t`, яка додає префікс.

## Пропси та слот {#props-and-slot}

| Проп | Тип | За замовчуванням | Опис |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | Префікс ключа, відносно якого розв'язується кожен пошук усередині слоту. |
| `groupClass` | `string` | `''` | Додатковий клас для елемента-обгортки. |

**\*** обов'язковий.

### Слоти {#slots}

| Слот | Прив'язки | Опис |
| --- | --- | --- |
| `default` | `prefix`, `t` | Отримує `prefix` і функцію `t`, обмежену ним. |

## Поведінка {#behaviour}

- Рендерить `<div class="i18n-group {groupClass}">` навколо слоту.
- `t(key, params)` дорівнює `$t(prefix + '.' + key, params)` для поточного маршруту.
- Обмежена лише `t` слоту: `$t` і вкладені `<i18n-t>` усередині групи, як і раніше, приймають повні ключі.

## Приклад {#example}

```json
{
  "checkout": { "title": "Checkout", "items": "Items: {count}" }
}
```

```vue
<template>
  <i18n-group prefix="checkout" group-class="checkout">
    <template #default="{ t }">
      <h2>{{ t('title') }}</h2>
      <p>{{ t('items', { count: 3 }) }}</p>
    </template>
  </i18n-group>
</template>
```
