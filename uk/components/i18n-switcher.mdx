title: "<i18n-switcher>"
description: "Компонент <i18n-switcher> — це випадний список увімкнених локалей, кожна з яких веде на поточну сторінку в цій локалі."
---

`<i18n-switcher>` рендерить кнопку з активною локаллю та випадний список усіх увімкнених локалей, включно з активною. Використовуйте його як готове меню мов; створіть власне на основі [`$getLocales`](/uk/api/methods#$getlocales) і [`$switchLocalePath`](/uk/api/methods#$switchlocalepath), коли потрібна інша розмітка. Кожен пункт веде на поточну сторінку в цій локалі.

## Пропси та слоти {#props-and-slots}

| Проп | Тип | За замовчуванням | Опис |
| --- | --- | --- | --- |
| `customLabels` | `Record<string, string>` | `() => ({})` | Відображувана назва для кожного коду локалі, що перевизначає `displayName` з конфігурації локалі. |
| `customWrapperStyle` | `CSSProperties` | `() => ({})` | Вбудований стиль для зовнішньої обгортки. |
| `customButtonStyle` | `CSSProperties` | `() => ({})` | Вбудований стиль для кнопки, що відкриває випадний список. |
| `customDropdownStyle` | `CSSProperties` | `() => ({})` | Вбудований стиль для панелі випадного списку. |
| `customItemStyle` | `CSSProperties` | `() => ({})` | Вбудований стиль для кожного пункту випадного списку. |
| `customLinkStyle` | `CSSProperties` | `() => ({})` | Вбудований стиль для посилання всередині пункту. |
| `customActiveLinkStyle` | `CSSProperties` | `() => ({})` | Вбудований стиль для посилання поточної активної локалі. |
| `customDisabledLinkStyle` | `CSSProperties` | `() => ({})` | Вбудований стиль для кнопки *поточної* локалі, коли в конфігурації для неї задано `disabled: true`. |
| `customIconStyle` | `CSSProperties` | `() => ({})` | Вбудований стиль для іконки-стрілки на кнопці. |

### Слоти {#slots}

| Слот | Прив'язки | Опис |
| --- | --- | --- |
| `before-button` | — | Вміст перед кнопкою, що відкриває випадний список. |
| `before-selected-locale` | — | Вміст перед підписом активної локалі всередині кнопки. |
| `after-selected-locale` | — | Вміст після підпису активної локалі всередині кнопки. |
| `before-dropdown` | — | Вміст між кнопкою та панеллю випадного списку. |
| `before-dropdown-items` | — | Вміст угорі випадного списку, над списком локалей. |
| `before-item` | `locale` | Вміст перед кожним пунктом локалі. |
| `before-link-content` | `locale` | Вміст перед підписом локалі всередині її посилання. |
| `after-link-content` | `locale` | Вміст після підпису локалі всередині її посилання. |
| `after-item` | `locale` | Вміст після кожного пункту локалі. |
| `after-dropdown-items` | — | Вміст унизу випадного списку, під списком локалей. |
| `after-dropdown` | — | Вміст після панелі випадного списку. |

## Поведінка {#behaviour}

- Перелічує кожну локаль без `disabled: true`, включно з активною.
- Кожен пункт — це `<a>` на `$switchLocalePath(code)`. Шлях розв'язується відносно `app.baseURL`; `baseUrl` локалі на іншому домені залишається абсолютним. Для нього задано `hreflang` і `lang` зі значенням `iso || code`, `dir`, якщо він є в локалі, `aria-current="page"` для поточної локалі та клас `switcher-locale-<code>`. Клік викликає `$switchLocale(code)` і закриває випадний список; із клавішею-модифікатором обробка залишається за браузером.
- Список залишається в серверному HTML у прихованому вигляді, тож пошукові роботи бачать посилання. Escape або клік поза ним закриває його.
- Підпис: `customLabels[code]`, потім `displayName` локалі, потім код (з попередженням у режимі розробки).
- Стилі: невеликі вбудовані стилі за замовчуванням (біла кнопка й панель із рамкою, активний пункт жирний і синій). Кожен проп `custom*Style` застосовується після стилю за замовчуванням відповідної частини. Кнопка має класи `i18n-switcher-button` і `language-switcher`, обгортка — `i18n-switcher-wrapper`, список — `i18n-switcher-dropdown`. Позиціонування використовує логічні властивості CSS, тож `dir="rtl"` працює.

## Приклад {#example}

```vue
<template>
  <i18n-switcher
    :custom-labels="{ en: 'English', de: 'Deutsch' }"
    :custom-button-style="{ borderRadius: '4px' }"
  >
    <template #before-link-content="{ locale }">
      <img :src="`/flags/${locale.code}.svg`" alt="" width="16" />
    </template>
  </i18n-switcher>
</template>
```
