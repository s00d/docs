**Дата**: 2025-10-30

**Версія**: `v2.0.0`

![v2.0.0 release](/images/2.0.0.png)

Ми представляємо серверний HMR для файлів перекладів у режимі розробки. Коли JSON-файл перекладу змінюється, серверний кеш інвалідує лише відповідні ключі, і наступні запити одразу отримують свіжі дані — без перезапусків.

## Що нового? {#what’s-new}

- Серверний HMR для файлів перекладів
- Миттєва інвалідація кешу для кожної сторінки/локалі
- Зручна робота розробника під час редагування вмісту

## Як це працює {#how-it-works}

- Спостерігач у `src/runtime/server/plugins/watcher.dev.ts` відстежує `<rootDir>/<translationDir>/**/*.json`
- Файли сторінок (наприклад, `pages/<page>/<locale>.json`) інвалідують `_locales:merged:<page>:<locale>`
- Файли кореневого рівня (наприклад, `<locale>.json`) інвалідують усі об'єднані ключі для цієї локалі
- Автоматично реєструється з `src/module.ts` у режимі розробки, коли `experimental.hmr !== false`

## Конфігурація {#configuration}

```ts
export default defineNuxtConfig({
  i18n: {
    experimental: { hmr: true }, // default in dev
  },
})
```
