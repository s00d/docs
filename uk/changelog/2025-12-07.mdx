![Випуск v2.14](/images/2.14.0.png)

Ми раді представити **v2.14.1** з абсолютно новими інтеграціями для Node.js, Vue 3 та Astro! Ці пакети приносять ті самі потужні можливості i18n у ваші улюблені фреймворки й використовують спільну основну логіку для узгодженості та продуктивності.

## Що нового? {#what’s-new}

- **@i18n-micro/node** - Використовуйте переклади i18n у будь-якому застосунку Node.js, CLI-інструменті чи бекенд-сервісі
- **@i18n-micro/vue** - Плагін Vue 3 для інтернаціоналізації з реактивними перекладами та підтримкою перекладів для окремих маршрутів
- **@i18n-micro/astro** - Інтеграція Astro для інтернаціоналізації з повною підтримкою TypeScript
- **@i18n-micro/types-generator** - Автоматична генерація типів TypeScript для ключів перекладу з повною типобезпекою та автодоповненням в IDE

## Ключові можливості {#key-features}

Усі інтеграції мають спільні переваги:

- Легкі та продуктивні
- Підтримка перекладів для окремих маршрутів
- Вбудована плюралізація
- Форматування чисел, дат і відносного часу
- Повна підтримка TypeScript
- Однакова структура JSON-файлів перекладів

**Types Generator** додатково покращує досвід розробника:

- Автоматична генерація типів із JSON-файлів перекладів
- Типобезпечні ключі перекладу з перевіркою під час компіляції
- Повна підтримка автодоповнення в IDE
- Гаряче перезавантаження при зміні файлів перекладів
- Нульові накладні витрати під час виконання

Детальну документацію та приклади дивіться в [репозиторії](https://github.com/s00d/nuxt-i18n-micro) або в [документації](https://s00d.github.io/nuxt-i18n-micro/).
