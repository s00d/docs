**Dátum**: 2026-06-25

**Verzió**: `v3.21.0`

![v3.21.0 kiadás](/images/3.21.0.png)

Ez a kiadás bevezeti a **`useI18nHead`**-et — egy oldalszintű composable-t az i18n SEO-felülírásokhoz a beépített `02.meta` plugin mellett. Testreszabhatod a `hreflang`, a canonical, az `og:url` és az Open Graph tageket útvonalanként, egyéni meta plugin vagy `meta: false` nélkül.

## Újdonságok {#what’s-new}

### `useI18nHead` composable {#usei18nhead-composable}

Hívd meg a `useI18nHead`-et bármely oldalon, ha `meta: true` (alapértelmezett). A modul minden útvonalfrissítéskor a `useLocaleHead` után olvasztja be a bemenetedet:

```vue
<script setup lang="ts">
useI18nHead(() => ({
  meta: [{ property: 'og:title', content: article.value?.title }],
  replace: {
    canonical: article.value?.canonicalUrl,
    ogUrl: article.value?.canonicalUrl,
    hreflang: localeCodes.map((locale) => ({
      rel: 'alternate',
      hreflang: locale,
      href: article.value!.locales[locale]!,
    })),
    ogAlternates: localeCodes,
  },
}))
</script>
```

Támogatja a statikus objektumokat, a reaktív gettereket, a `meta` / `link` hozzáfűzést, a `replace`-t a beépített csoportokhoz, valamint a `disable`-t az automatikusan generált tagek eltávolításához. Lásd: [`useI18nHead`](/hu/composables/useI18nHead).

### `mergeI18nHead` segédfüggvény (`@i18n-micro/utils`) {#mergei18nhead-utility-@i18n-micro/utils}

A keretrendszerfüggetlen összefésülési logika a `@i18n-micro/utils/merge-i18n-head` modulban található — ezt használja a `02.meta` plugin, és önállóan is tesztelhető. A típusok (`I18nHeadInput`, `I18nHeadLink`, `I18nHeadMeta`) a `@i18n-micro/types` csomagból exportálódnak.

### Plugin-integráció {#plugin-integration}

- **`02.meta`** — a `useHead` segítségével összefésüli a `useLocaleHead` kimenetét a `useI18nHead` oldalállapotával
- **`01.plugin`** — útvonalnév-változáskor visszaállítja az oldalfelülírásokat a `resetPageHead()` segítségével (közös állapot a composable-lel)

### Dokumentáció és tesztek {#documentation-tests}

- Új útmutató: [`useI18nHead`](/hu/composables/useI18nHead) CMS-/cikkpéldákkal
- Frissített [SEO](/hu/guide/seo) és [`useLocaleHead`](/hu/composables/useLocaleHead) — mikor melyik API-t használd
- Playwright + Vitest lefedettség: SSR, SPA-navigáció, újratöltés, `nuxi generate`, részleges alternatívák, `x-default`, reaktív kliensoldali betöltés

## Tipikus felhasználási esetek {#typical-use-cases}

| Forgatókönyv                                   | Megközelítés                                                       |
| ---------------------------------------------- | ------------------------------------------------------------------ |
| Blog/CMS részleges fordításokkal               | `replace.hreflang` + `replace.ogAlternates` az API locale-jaiból    |
| Egyéni canonical a CMS-ből                     | `replace.canonical` + `replace.ogUrl`                              |
| Csak OG a landing oldalon                      | `meta: [{ property: 'og:title', ... }]` — a modul hreflangja marad |
| Nincs hreflang egy oldalon                     | `disable: ['hreflang', 'x-default']`                               |
| Egyéni plugin cseréje (`i18nManualHreflang`)   | `useI18nHead` tartalomoldalanként + `meta: true`                   |

A **JSON-LD** a `useHead({ script: [...] })`-ben marad — a `useI18nHead` nem generál strukturált adatokat.

## Kompatibilitástörő változások {#breaking-changes}

Nincsenek a szabványos `nuxt.config`-használat esetén. Az új composable és az utils alútvonal csak kiegészítés.

## Miért fontos {#why-it-matters}

- **Nincs szükség egyéni meta pluginra** CMS-bejegyzésekhez, hírekhez vagy útmutatókhoz locale-onkénti URL-ekkel
- **Egyetlen folyamat** — a modul alapértékei + oldalfelülírások egyetlen `useHead` hívásban
- **Típusbiztos** — `I18nHeadInput` olyan segédfüggvényekhez, mint a `buildArticleHead(content)`

A teljes változásnapló a kiadással együtt jelenik meg a [GitHubon](https://github.com/s00d/nuxt-i18n-micro/blob/main/CHANGELOG.md).
