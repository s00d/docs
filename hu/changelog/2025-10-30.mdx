**Dátum**: 2025-10-30

**Verzió**: `v2.0.0`

![v2.0.0 kiadás](/images/2.0.0.png)

Bevezetjük a fordítási fájlok szerveroldali HMR-jét fejlesztési módban. Amikor egy JSON fordítás megváltozik, a szerver gyorsítótára csak az érintett kulcsokat érvényteleníti, és a következő kérések azonnal friss adatokat kapnak — újraindítás nélkül.

## Mi az újdonság? {#what’s-new}

- Szerveroldali HMR a fordítási fájlokhoz
- Azonnali gyorsítótár-érvénytelenítés oldalanként/locale-onként
- Zökkenőmentes fejlesztői élmény tartalomszerkesztés közben

## Hogyan működik {#how-it-works}

- A `src/runtime/server/plugins/watcher.dev.ts` figyelője a `<rootDir>/<translationDir>/**/*.json` fájlokat követi
- Az oldalfájlok (pl. `pages/<page>/<locale>.json`) a `_locales:merged:<page>:<locale>` kulcsot érvénytelenítik
- A gyökérszintű fájlok (pl. `<locale>.json`) az adott locale összes összefésült kulcsát érvénytelenítik
- Fejlesztési módban automatikusan regisztrálódik a `src/module.ts` fájlból, ha `experimental.hmr !== false`

## Konfiguráció {#configuration}

```ts
export default defineNuxtConfig({
  i18n: {
    experimental: { hmr: true }, // default in dev
  },
})
```
