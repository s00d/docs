# 📚 Nuxt I18n Micro példák és használat

Ez a szakasz különböző példákon keresztül mutatja be a `Nuxt I18n Micro` használatát a Nuxt.js alkalmazásodban. Láthatod, hogyan válthatsz területi beállítást, hogyan használhatod az `<i18n-link>`, `<i18n-switcher>` és `<i18n-t>` komponenseket, valamint hogyan kezelheted dinamikusan a fordítási kulcsokat.

## 🛠️ Alapbeállítás

Íme egy alapkonfiguráció a `Nuxt I18n Micro` használatához:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Területi beállítás váltása

### Területi beállítások programozott váltása

Ez a példa bemutatja, hogyan válthatsz területi beállítást programozottan gombokkal:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Példa JSON területi beállítás váltásához

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### Az `<i18n-switcher>` komponens használata

Az `<i18n-switcher>` komponens legördülő listát biztosít a területi beállítás váltásához, testreszabható címkékkel:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 📝 Dinamikus kulcsok megjelenítése fordítási fájlokból

Bizonyos helyzetekben szeretnél végigmenni a fordítási fájlokban tárolt dinamikus kulcsokon, és feltételesen megjeleníteni azok értékeit. Az alábbi példa bemutatja, hogyan érheted el ezt a `Nuxt I18n Micro` segítségével.

### Példa: Dinamikus kulcsok megjelenítése

Ez a példa egy adott fordítási útvonalból (ebben az esetben `dynamic`) lekéri a kulcsok tömbjét, és végigmegy rajtuk. Minden kulcsot ellenőrzünk létezésre a `$has` segítségével, mielőtt az értékét a `$t`-vel megjelenítenénk.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Példa fordítási fájl (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Példa: Dinamikus kulcsok megjelenítése objektumból

Ebben a példában egy fordítási fájlban tárolt objektumot kezelünk. Lekérjük és iteráljuk az objektum kulcsain, dinamikusan megjelenítve mind a kulcsneveket, mind a hozzájuk tartozó értékeket.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Példa fordítási fájl (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 Az `<i18n-t>` használata slotokkal és interpolációval

Az `<i18n-t>` komponens hasznos a fordítások dinamikus tartalommal és HTML címkékkel történő megjelenítéséhez:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### Példa JSON az `<i18n-t>`-hez

```json
{
  "greeting": "Welcome to the page"
}
```

### Interpolációval

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### Példa JSON az interpolációhoz

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 A `$tc` használata többes szám kezeléshez

A `$tc` függvény a `Nuxt I18n Micro`-ban a többes szám kezelését végzi a szám és a területi beállítások alapján. Ez hasznos dinamikusan igazítható üzeneteknél, amelyek számokat tartalmaznak, például elemek, értesítések vagy más entitások esetén, amelyek száma változhat.

### Példa: A `$tc` használata többes szám kezeléshez

A következő példában az almák számát jelenítjük meg a `$tc` segítségével. A fordítási kulcs több többes számú formát kezel a megadott szám alapján.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### Példa JSON többes szám kezeléshez

Így definiálhatod a fordítást a JSON fájlban a különböző többes számú formák kezeléséhez:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Magyarázat

- **`$tc('apples', 0)`**: Az első formát adja vissza, amelyet akkor használunk, ha a szám nulla (`"no apples"`).
- **`$tc('apples', 1)`**: A második formát adja vissza, amelyet akkor használunk, ha a szám egy (`"one apple"`).
- **`$tc('apples', 10)`**: A harmadik formát adja vissza a számmal, amelyet akkor használunk, ha a szám kettő vagy több (`"10 apples"`).

### További példa összetettebb többes szám kezeléssel

Ha az alkalmazásodnak összetettebb többes szám szabályokat kell kezelnie (pl. speciális esetek nullára, egyre, kettőre, néhányra, sokra, egyébre), akkor ennek megfelelően bővítheted a fordítási karakterláncokat:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: Beállítható úgy, hogy `"two apples"` értéket adjon vissza.
- **`$tc('apples', 3)`**: `"a few apples"` értéket adhat vissza, a számhoz definiált szabályoktól függően.

## 🌐 A `$tn` használata számformázáshoz

A `$tn` függvény a számokat az aktuális területi beállítás szerint formázza az `Intl.NumberFormat` API segítségével. Ez hasznos a számok olyan formában történő megjelenítéséhez, amely megfelel a felhasználó regionális beállításainak, például pénznemhez, százalékokhoz vagy más számformátumokhoz.

### Példa: A `$tn` használata számformázáshoz

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ A `$td` használata dátum- és időformázáshoz

A `$td` függvény a dátumokat és időket az aktuális területi beállítás szerint formázza az `Intl.DateTimeFormat` API segítségével. Ez hasznos a dátumok és időpontok olyan formátumban történő megjelenítéséhez, amelyek a felhasználó számára ismerősek a területi beállításai alapján.

### Példa: A `$td` használata dátum- és időformázáshoz

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ A `$tdr` használata relatív dátumformázáshoz

A `$tdr` függvény a dátumokat relatív időként formázza (pl. "5 perce", "2 napja") az aktuális területi beállítás szerint az `Intl.RelativeTimeFormat` API segítségével. Ez hasznos időkülönbségek megjelenítéséhez az aktuális dátumhoz és időhöz képest.

### Példa: A `$tdr` használata relatív dátumformázáshoz

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
