# 📚 Nuxt I18n Micro – példák és használat

Ez a rész különféle példákat mutat be arra, hogyan használhatod a `Nuxt I18n Micro`-t a Nuxt.js alkalmazásodban. Megnézed, hogyan válts területi beállítást, hogyan használd az `<i18n-link>`, az `<i18n-switcher>` és az `<i18n-t>` komponenseket, valamint hogyan kezelj dinamikusan fordításkulcsokat.

## 🛠️ Alapbeállítás

Íme egy alapbeállítás, amellyel elkezdheted a `Nuxt I18n Micro` használatát:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Területi váltás

### Területek programozott váltása

Ez a példa bemutatja, hogyan válts területet gombokkal, programozott módon:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Példa JSON a területi váltáshoz

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### Az `<i18n-switcher>` komponens használata

Az `<i18n-switcher>` komponens legördülőt biztosít a területi váltáshoz, testre szabható címkékkel:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 🌐 Az `<i18n-link>` használata területspecifikus navigációhoz

```vue

  <div>

    <i18n-link :to="{ name: 'index' }">{{ $t('home') }}</i18n-link>

<script setup>

```

### Példa JSON a navigációs linkekhez

```json
{
  "about": "About Us",
```

## 📝 Dinamikus kulcsok renderelése fordítási fájlokból

Bizonyos esetekben szeretnél végigmenni a fordítási fájlokban tárolt dinamikus kulcsokon, és feltételesen renderelni az értékeiket. Az alábbi példa bemutatja, hogyan érhető ez el a `Nuxt I18n Micro` segítségével.

### Példa: dinamikus kulcsok renderelése

Ez a példa lekéri egy adott fordítási útvonalból (jelen esetben a `dynamic`-ből) a kulcsok tömbjét, és végigmegy rajtuk. Minden kulcs létezését a `$has` ellenőrzi, mielőtt az értékét a `$t` megjelenítené.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Példa fordítási fájl (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Példa: dinamikus kulcsok renderelése objektumból

Ebben a példában a fordítási fájlodban tárolt objektumot kezeljük. Lekérjük és bejárjuk az objektum kulcsait, dinamikusan renderelve a kulcsneveket és a hozzájuk tartozó értékeket.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Példa fordítási fájl (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 Az `<i18n-t>` használata fordításokhoz slotokkal és interpolációval

Az `<i18n-t>` komponens hasznos, ha dinamikus tartalmú és HTML-címkéket tartalmazó fordításokat kell renderelni:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### Példa JSON az `<i18n-t>`-hez

```json
{
  "greeting": "Welcome to the page"
}
```

### Interpolációval

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### Példa JSON az interpolációhoz

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 A `$tc` használata többes számhoz

A `$tc` függvény a `Nuxt I18n Micro`-ban a számosság és a területi beállítások alapján kezeli a többesszám-formákat. Ez akkor hasznos, ha dinamikusan kell módosítani mennyiséghez kapcsolódó üzeneteket, például elemek, értesítések vagy egyéb, számban változó entitások esetén.

### Példa: `$tc` használata többes számhoz

Az alábbi példában olyan üzenetet jelenítünk meg, amely az almák számát mutatja `$tc`-vel. A fordításkulcs a megadott mennyiség alapján több többesszám-formát is kezel.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### Példa JSON a többes számhoz

Így definiálhatod a fordítást a JSON-fájlodban különböző többesszám-formák kezelésére:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Magyarázat

- **`$tc('apples', 0)`**: Az első formát adja vissza, amelyet nulla mennyiségnél használunk (`"no apples"`).
- **`$tc('apples', 1)`**: A második formát adja vissza, amelyet egyes számnál használunk (`"one apple"`).
- **`$tc('apples', 10)`**: A harmadik formát adja vissza a mennyiséggel együtt, amelyet kettő vagy több esetén használunk (`"10 apples"`).

### További példa összetettebb többes szám kezelésével

Ha az alkalmazásodnak összetettebb többesszám-szabályokat kell kezelnie (pl. külön eseteket nullára, egyre, kettőre, néhányra, sokra, egyébre), a fordítási sztringeket megfelelően bővítheted:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: Beállítható úgy, hogy `"two apples"`-t adjon vissza.
- **`$tc('apples', 3)`**: A mennyiséghez definiált szabályoktól függően `"a few apples"`-t adhat vissza.

## 🌐 A `$tn` használata számformázáshoz

A `$tn` függvény az aktuális területi beállításnak megfelelően formázza a számokat az `Intl.NumberFormat` API-val. Ez akkor hasznos, ha a számokat a felhasználó regionális beállításaihoz igazítva szeretnéd megjeleníteni, például pénznemekhez, százalékokhoz vagy egyéb számformátumokhoz.

### Példa: `$tn` használata számformázáshoz

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ A `$td` használata dátum és idő formázásához

A `$td` függvény az aktuális területi beállításnak megfelelően formázza a dátumokat és időpontokat az `Intl.DateTimeFormat` API-val. Ez akkor hasznos, ha a dátumokat és időpontokat a felhasználó számára a területi beállításai alapján ismerős formátumban szeretnéd megjeleníteni.

### Példa: `$td` használata dátum és idő formázásához

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ A `$tdr` használata relatív dátumok formázásához

A `$tdr` függvény relatív időként formázza a dátumokat (pl. „5 perccel ezelőtt”, „2 nappal ezelőtt”) az aktuális területi beállításnak megfelelően, az `Intl.RelativeTimeFormat` API-val. Ez akkor hasznos, ha az aktuális dátumhoz és időhöz viszonyított időkülönbségeket szeretnéd megjeleníteni.

### Példa: `$tdr` használata relatív dátumok formázásához

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
