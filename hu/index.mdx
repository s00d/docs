A Nuxt I18n Micro egy könnyűsúlyú, nagy teljesítményű i18n modul a Nuxt 3 és 4 számára, nagy projektekhez tervezve. A hagyományos i18n megoldásokhoz, például az `@nuxtjs/i18n` modulhoz képest alacsonyan tartja a build-időt, a memóriahasználatot és a csomagméretet.

A lokalizált útvonalakat build időben az `@i18n-micro/route-strategy` generálja, futásidőben pedig az `@i18n-micro/path-strategy` oldja fel, így a linkek, a nyelvváltó, a `hreflang` és az átirányítások mind összhangban vannak a routerrel. A fordítások kizárólag JSON formátumúak, megosztott gyökérfájlokra és oldalankénti fájlokra bontva, amelyeket a fejlesztői szerver hoz létre helyetted, beépített HMR-rel.

<CodeGroup>

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>
