## 🚀 Gyorsindítás

### Telepítés

Telepítsd a modult a Nuxt alkalmazásodba:

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

### Alapkonfiguráció

Add hozzá a modult a `nuxt.config.ts` fájlodhoz:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

<Tip>
- **Gyökérszintű fájlok** (`locales/en.json` stb.) — az egész alkalmazásban megosztott fordítások (menük, lábléc, közös UI). A `translationPayloads.mode: 'premerged'` (alapértelmezett) beállítással minden oldalba beolvadnak build időben.
- **Oldalspecifikus fájlok** (`locales/pages/<route>/<locale>.json`) — az adott oldalakra jellemző fordítások, amelyek csak az oldal meglátogatásakor töltődnek be.
- **Dinamikus útvonalak** — a `pages/articles/[id].vue` a `locales/pages/articles-id/` mappához tartozik (a szögletes zárójelek kötőjelekre cserélődnek).
- **Automatikus generálás** — minden fordítási fájl automatikusan létrejön, ha hiányzik a `nuxt dev` során.
</Tip>

<Info>
A modul mindkét elrendezést támogatja:

- **Oldalak**: `pages/**/*.vue` (Nuxt 3) vagy `app/pages/**/*.vue` (Nuxt 4)
- **Fordítások**: alapértelmezés szerint tartsd a `locales/` mappát a **projekt gyökerében** (ajánlott konvenció), ne az `app/` mappán belül.

```tree
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   ├── en.json
│   └── pages/
└── nuxt.config.ts
```

Opcionális kolokáció: `i18n: \{ translationDir: 'app/locales' \}` (lásd [fixture `n3`](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/n3)).

Az opcionális `text-to-i18n` CLI segédhez használd a [`nuxt-i18n-micro-cli` ≥ 2.1.1](/guides/cli#-text-to-i18n-command) verziót, így az `app/pages` és `app/components` mappák a projekt gyökeréből kerülnek átvizsgálásra.
</Info>

### Alapvető használat

Használd a fordításokat a komponensekben:

```vue
<template>
  <div>
    <h1>{{ $t('welcome') }}</h1>
    <p>{{ $t('description', { name: 'World' }) }}</p>

    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" @click="$switchLocale(locale.code)">
        {{ locale.code }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useI18n } from '#imports'

const { $t, $getLocales, $switchLocale } = useI18n()
</script>
```
