## Követelmények

- **Node.js**: 18 vagy újabb.
- **Nuxt**: 3.x vagy 4.x.

A modul támogatja mind a Nuxt 3 projektfelépítést (`pages/**/*.vue`), mind a Nuxt 4 elrendezést (`app/pages/**/*.vue`). A fordítások konvenció szerint a projekt gyökerében (`locales/`) találhatók, még akkor is, ha a Nuxt 4 `app/` könyvtárát használod.

## A Nuxt modul telepítése

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Regisztráld a `nuxt.config.ts` fájlban:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Nézd meg a [Gyorsindítást](/quickstart) a teljes bemutatóért, vagy a [Konfigurációs referenciát](/guides/configuration) minden opció megismeréséért.

## Projektfelépítés

Alapértelmezés szerint a modul a következőt várja:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

A gyökérszintű fájlok minden oldalspecifikus fájlba beolvadnak build időben. Az oldalspecifikus fájlok automatikusan létrejönnek, ha hiányoznak a `nuxt dev` során.

## Nuxt 4 elrendezés

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Ha a fordításokat az `app/` alatt szeretnéd elhelyezni, állítsd be a `translationDir: 'app/locales'` értéket.

## TypeScript

A modul környezeti típusokat generál a `useI18n`, `$t` és a kapcsolódó segédek számára az alapértelmezett területi beállítás fájljai alapján. Ez alapértelmezés szerint engedélyezve van (`types: true`).

A fordítási kulcsok erősebb típusozásához nézd meg a [`@i18n-micro/types-generator`](/integrations/types-generator) csomagot.
