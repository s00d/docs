## Követelmények

- **Node.js**: 18-as vagy újabb.
- **Nuxt**: 3.x vagy 4.x.

A modul támogatja mind a Nuxt 3 projektelrendezést (`pages/**/*.vue`), mind a Nuxt 4 elrendezést (`app/pages/**/*.vue`). A fordítások konvenció szerint a projekt gyökerében (`locales/`) helyezkednek el, akkor is, ha a Nuxt 4 `app/` könyvtárát használod.

## A Nuxt modul telepítése

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Regisztráld a `nuxt.config.ts`-ben:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Teljes körű bemutatóért lásd a [Gyorsindítás](/quickstart) oldalt, minden opcióért pedig a [Konfigurációs referenciát](/guides/configuration).

## Projektelrendezés

Alapértelmezetten a modul az alábbit várja:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

A gyökérszintű fájlok build-időben minden oldalspecifikus fájlba beolvadnak. A hiányzó oldalspecifikus fájlok automatikusan létrejönnek a `nuxt dev` során.

## Nuxt 4 elrendezés

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Ha a fordításokat az `app/` alá szeretnéd kolokálni, állítsd be a `translationDir: 'app/locales'` értéket.

## TypeScript

A modul környezeti (ambient) típusokat generál a `useI18n`-hez, a `$t`-hez és a kapcsolódó segédekhez az alapértelmezett területi fájljaid alapján. Ez alapértelmezetten engedélyezve van (`types: true`).

Erősebb típusossághoz a fordításkulcsoknál lásd a [`@i18n-micro/types-generator`](/integrations/types-generator) csomagot.
