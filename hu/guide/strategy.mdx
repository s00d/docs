A `strategy` beállítás dönti el, hogy megjelenik-e a locale az URL-ben, és mely locale-ok esetén. Egyszer válaszd ki, még mielőtt URL-eket publikálnál: a későbbi módosítás minden linket megváltoztat. A modul ezután build időben generálja a lokalizált útvonalakat, és ezeket olvassa a `$localePath`, az `<i18n-link>` és a nyelvváltó.

## A négy stratégia {#the-four-strategies}

![The /about page in en (default) and de under each strategy; the same URLs are listed in the text below](/images/diagrams/strategies.svg)

**Típus** `Strategies` · **Alapértelmezés** `'prefix_except_default'`

URL-útválasztási stratégia a locale-előtagokhoz.

- `'no_prefix'` — nincs locale az URL-ben; a locale sütiben tárolódik.
- `'prefix_except_default'` — minden locale előtagot kap, kivéve az alapértelmezettet.
- `'prefix'` — mindig van előtag, az alapértelmezett locale esetén is.
- `'prefix_and_default'` — mint a `prefix`, de az alapértelmezett locale előtag nélkül is elérhető.

Egy `about` oldal URL-jei `defaultLocale: 'en'` és `en`, `de` locale-ok esetén:

| Stratégia | Angol | Német | Nem kiszolgált |
| --- | --- | --- | --- |
| `prefix_except_default` (alapértelmezés) | `/about` | `/de/about` | a `/en` és a `/en/about` 404-et ad |
| `prefix` | `/en/about` | `/de/about` | a `/about` előtagos URL-re irányít át |
| `prefix_and_default` | `/about` és `/en/about` | `/de/about` | — |
| `no_prefix` | `/about` | `/about` | a locale nincs az URL-ben |

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix',
  },
})
```

A stratégia build időben rögzül: futásidejű felülírása figyelmeztetéssel figyelmen kívül marad ([Futásidejű felülírások](/hu/guide/runtime-overrides)).

## Melyiket válaszd {#which-one-to-choose}

- **`prefix_except_default`**: a legtöbb webhelyhez. A meglévő előtag nélküli URL-ek továbbra is működnek az alapértelmezett nyelven.
- **`prefix`**: minden nyelv egyenrangú; a `/` mindig egy előtagos kezdőlapra vezet.
- **`prefix_and_default`**: ha az `/en/...` és az előtag nélküli URL-eknek is működniük kell, például az egyikről a másikra való átállás idején. Az előtag nélküli URL-ek soha nem irányítódnak át.
- **`no_prefix`**: bejelentkezés mögötti alkalmazásokhoz, vagy ha oldalanként egyetlen URL kell minden nyelvhez. A locale sütiből vagy a `?locale=` paraméterből származik. A keresőmotorok URL-enként egy nyelvet látnak, így nem jönnek létre `hreflang` alternatívák.

Hogy hogyan választódik ki a locale egy URL-hez, és mikor irányítódik át a látogató, azt a [Locale-észlelés](/hu/guide/locale-detection) oldal ismerteti.

## Generált útvonalak {#generated-routes}

Build időben minden oldal megkapja azokat az útvonalrekordokat, amelyekre a stratégiájának szüksége van. Minden rekord tartalmazza a `meta.i18n = { name, locales }` értéket: a megjelenített oldalt és a kiszolgált locale-okat. A linkek, a váltások és az átirányítások mind ezekből a rekordokból kapják a választ, így a modul által kiadott URL-t a router mindig ki is szolgálja.

Az oldal útvonalán osztozó locale-ok egy közös rekordon osztoznak: `/:locale(de|fr)/about`. A saját útvonallal rendelkező locale saját rekordot kap `localized-<page>-<locale>` névvel:

```ts
// nuxt.config.ts: German has its own path for the about page
i18n: {
  globalLocaleRoutes: { about: { de: '/ueber-uns' } },
}
// prefix_except_default, locales en (default), de, fr:
// about                 /about
// localized-about       /:locale(fr)/about
// localized-about-de    /:locale(de)/ueber-uns
```

Az egyéni útvonalakat, az oldalankénti locale-listákat és egy oldal lokalizációból való kizárását a [Lokalizált útvonalak](/hu/guide/custom-locale-routes) és az [Oldalkonfiguráció](/hu/guide/per-component-translations) oldal ismerteti. A `localized-` előtagot a [`localizedRouteNamePrefix`](/hu/api/module-options#localizedroutenameprefix) határozza meg.

<Warning>

**Az útvonalnevek generáltak** — Ne írj be fixen `localized-…` neveket a `router.push({ name })` hívásokba. Az oldal saját nevét add át a `$localeRoute`-nak vagy az `<i18n-link>`-nek; ezek kiválasztják a megfelelő rekordot.

</Warning>

## Linkelés egy oldalra egy adott locale-ban {#linking-to-a-page-in-a-locale}

```vue
<script setup lang="ts">
const { localePath, localeRoute, switchLocalePath } = useI18n()

localePath({ name: 'about' }) // '/de/ueber-uns' while the page is German
localePath({ name: 'about' }, 'en') // '/about'
localePath('/about', 'de') // '/de/ueber-uns': a path is read as the page it shows
localeRoute({ name: 'products-id', params: { id: '42' } }, 'de') // resolved route: name, params, fullPath
switchLocalePath('fr') // the current page in French
</script>

<template>
  <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
  <NuxtLink :to="$switchLocalePath('de')">Deutsch</NuxtLink>
</template>
```

- A nevesített útvonalak és az útvonalak is működnek. Az útvonal a generált útvonalakhoz illesztődik, így bármely locale szerinti alakja elfogadott.
- Az a locale, amely nem szolgálja ki az oldalt (lásd a `locales` beállítást az [Oldalkonfiguráció](/hu/guide/per-component-translations) oldalon), a hiányzó oldal helyett az adott locale kezdőlapjára linkel.
- A locale-onkénti paraméterek (egy lefordított slug) a `$setI18nRouteParams` segítségével adhatók meg, lásd a [Lokalizált útvonalak](/hu/guide/custom-locale-routes) oldalt.

A szignatúrák a [Metódusok](/hu/api/methods) oldalon találhatók.

## A `no_prefix` részletei {#no_prefix-details}

- A [`localeCookie`](/hu/api/module-options#localecookie) alapértelmezett értéke `no_prefix` esetén `'user-locale'`, így a választás túléli az újratöltést.
- A `$switchLocale('de')` betölti a német szótárt, és lecseréli az aktuális előzménybejegyzést; az URL nem változik.
- Az egyéni, locale-onkénti útvonalak továbbra is működnek: `globalLocaleRoutes: { about: { de: '/ueber-uns' } }` esetén a német olvasók a `/ueber-uns` útvonalat kapják. Ez az URL mindig németül renderelődik, bármit is preferál a látogató, és a bizonyos locale-okra korlátozott oldal ezek egyikén renderelődik. A több locale által közösen használt útvonal (az `en` és a `de` is a `/page/:id` útvonalon) a preferált locale-on renderelődik, ha az közéjük tartozik. Maga a preferencia megmarad: a következő oldal visszatér hozzá.
- A [`noPrefixRedirect: true`](/hu/api/module-options#noprefixredirect) átirányítja azon oldalak eredeti útvonalát, amelyeknek az alapértelmezett locale-ban egyéni útvonaluk van: a látogató locale-jának egyéni útvonalára, egyébként az alapértelmezett locale-éra (`/about` → `/about-us`, ha az `en` locale-nak `/about-us` az útvonala, `de` süti esetén → `/ueber-uns`). A saját egyéni útvonallal nem rendelkező locale az eredeti útvonalon marad, és ott renderelődik. A paraméteres oldalak nem irányítódnak át.

## Alkalmazások `pages/` nélkül {#apps-without-pages/}

`pages: false` esetén nincsenek lokalizálandó oldalútvonalak. Csak gyökérszintű fordítási fájlokat használj (`disablePageLocales: true`); az észlelés, a süti és a `$switchLocale` továbbra is működik. A repository `test/fixtures/basic` mappájának `pages-false` változata egy működő beállítás.
