---
title: "Migrálás az @nuxtjs/i18n modulról"
description: "Az @nuxtjs/i18n opcióinak, composable-jeinek és fordítási fájljainak megfeleltetése a nuxt-i18n-micro számára."
---

Ez az oldal egy `@nuxtjs/i18n` alapú alkalmazást képez le a nuxt-i18n-micro modulra: opciók, segédfüggvények és fájlszerkezet. Akkor használd, ha egy meglévő alkalmazásban cseréled le a modult. Az URL-jeid megmaradnak (a stratégiák neve ugyanaz), a fordítások pedig oldalankénti JSON-fájlokba kerülnek.

<Tip>

**Magát a nuxt-i18n-micro modult frissíted?** — Lásd: [Frissítés](/hu/guide/upgrade).

</Tip>

## A modul cseréje {#swap-the-module}

```bash
npm uninstall @nuxtjs/i18n
npm install nuxt-i18n-micro
```

```ts
// nuxt.config.ts — before
export default defineNuxtConfig({
  modules: ['@nuxtjs/i18n'],
  i18n: {
    locales: [
      { code: 'en', language: 'en-US', file: 'en.json' },
      { code: 'de', language: 'de-DE', file: 'de.json' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    langDir: 'locales',
    detectBrowserLanguage: { useCookie: true, cookieKey: 'i18n_redirected', redirectOn: 'root' },
  },
})
```

```ts
// nuxt.config.ts — after
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    translationDir: 'locales',
    localeCookie: 'i18n_redirected',
    autoDetectPath: '/',
  },
})
```

## Opciók {#options}

| `@nuxtjs/i18n` | nuxt-i18n-micro |
| --- | --- |
| `locales[].code` | `locales[].code` |
| `locales[].language` (v9 előtt `iso`) | `locales[].iso` |
| `locales[].name` | `locales[].displayName` |
| `locales[].dir` | `locales[].dir` |
| `locales[].domain` | `locales[].baseUrl` (origin a sémával együtt) |
| `locales[].domainDefault` | `locales[].baseDefault` |
| `differentDomains`, `multiDomainLocales` | nem szükséges: a `baseUrl` önmagában host szerint irányít, lásd: [Rétegek és domainek](/hu/guide/layers#multiple-domains) |
| `locales[].file` / `files`, `langDir`, `lazy` | `translationDir`; a fájlok név szerint kerülnek megtalálásra, és mindig oldalanként töltődnek be |
| `defaultLocale`, `strategy` | ugyanazok a nevek, ugyanaz a négy érték |
| `baseUrl` | `metaBaseUrl` |
| `customRoutes: 'config'` + `pages` | `globalLocaleRoutes` |
| `detectBrowserLanguage: false` | `redirects: false` (nincs átirányítás) vagy `autoDetectLanguage: false` (a fejléc figyelmen kívül hagyása) |
| `detectBrowserLanguage.useCookie` / `cookieKey` | `localeCookie: '<name>'` (a `null` kikapcsolja a cookie-t) |
| `detectBrowserLanguage.redirectOn: 'root'` | `autoDetectPath: '/'` (alapértelmezett) |
| `detectBrowserLanguage.redirectOn: 'no prefix'` | `autoDetectPath: 'no_prefix'` |
| `detectBrowserLanguage.redirectOn: 'all'` | `autoDetectPath: '*'` |
| `vueI18n` konfigurációs fájl (`fallbackLocale`, `numberFormats`, `datetimeFormats`) | `fallbackLocale`, `numberFormats`, `datetimeFormats` az `i18n` alatt |

Nincs `alwaysRedirect`: beállított cookie esetén a `/` minden látogatáskor azt követi. A teljes lista a [Modulopciók](/hu/api/module-options) oldalon található; a felismerési szabályok a [Locale-felismerés](/hu/guide/locale-detection) oldalon.

## Segédfüggvények és composable-ök {#helpers-and-composables}

| `@nuxtjs/i18n` / vue-i18n | nuxt-i18n-micro (sablon / `useI18n()`) |
| --- | --- |
| `const { t } = useI18n()` | `const { t } = useI18n()`, sablonokban `$t` |
| `t('key', count)`, `tc` | `$tc('key', count)` |
| `te('key')` | `$has('key')` |
| `n(value, 'currency')`, `d(date, 'short')` | `$tn(value, 'currency')`, `$td(date, 'short')` |
| — | `$tdr(date)`: relatív idő ("3 nap múlva") |
| `locale.value` | `$getLocale()` |
| `locales.value` | `$getLocales()` |
| `setLocale('de')` | `$switchLocale('de')` |
| `useLocalePath()('about')` | `$localePath({ name: 'about' })` |
| `useLocaleRoute()` | `$localeRoute()` |
| `useSwitchLocalePath()('de')` | `$switchLocalePath('de')` |
| `useSetI18nParams()` | `$setI18nRouteParams()` |
| `useLocaleHead()` | automatikus `meta: true` esetén; egyéni headhez [`useLocaleHead`](/hu/composables/useLocaleHead) |
| `defineI18nRoute({ paths: { de: '/ueber-uns' }, locales: [...] })` | `$defineI18nRoute({ localeRoutes: { de: '/ueber-uns' }, locales: [...] })` |
| `<NuxtLinkLocale to="about">` | `<i18n-link :to="{ name: 'about' }">` |
| `<i18n-t>` | `<i18n-t>` (a slotok a `{name}` helyőrzőket töltik ki) |
| `$i18n` szerveroldali útvonalakban | `useTranslationServerMiddleware(event)`, lásd: [Szerveroldali útvonalak és API](/hu/guide/server-side-translations) |

A `useI18n()` automatikusan importálódik. A `$defineI18nRoute` hívásnak meg kell tartania a `$` jelet: a build ezt a hívást olvassa be. Az összes segédfüggvény: [Metódusok](/hu/api/methods).

## Fordítási fájlok {#translation-files}

Locale-onként egy nagy fájl kulcsait helyezd át egy gyökérfájlba és oldalanként egy-egy fájlba:

```text
locales/
├── en.json              # keys used on many pages (nav, footer)
├── de.json
└── pages/
    ├── index/en.json    # keys of pages/index.vue
    └── about/en.json    # keys of pages/about.vue
```

Az is működik, ha mindent a gyökérfájlokban tartasz, és ez a leggyorsabb első lépés. Állítsd be a `disablePageLocales: true` opciót, amíg szét nem bontod őket. Lásd: [Fordítási fájlok](/hu/guide/translations).

### Üzenetszintaxis {#message-syntax}

| vue-i18n | nuxt-i18n-micro |
| --- | --- |
| `{name}` nevesített interpoláció | ugyanaz |
| `car \| cars` (2 alak: 1 → első) | az alakok darabszám szerint, 0-tól kerülnek kiválasztásra: írd így: `no cars \| one car \| {count} cars` |
| `@:other.key` hivatkozott üzenetek | nem támogatott: ismételd meg a szöveget, vagy állítsd össze kódban |
| `@.upper:` módosítók | nem támogatott: formázz kódban, vagy használd az `<i18n-t>` komponenst |
| `{'@'}` literális escape-ek | nem szükséges: csak a `{word}` tokenek kerülnek lecserélésre |
| JS/TS üzenetfájlok | csak JSON |

A többesszám-szabály a [`plural`](/hu/api/module-options#plural) opcióval cserélhető le.

## Ellenőrzés a csere után {#check-after-the-switch}

- Minden korábbi URL-ed továbbra is feloldódik; a stratégiák neve egyezik, az egyéni útvonalak a `globalLocaleRoutes` vagy a `$defineI18nRoute` alá kerülnek.
- A `hreflang`, a canonical és az `og:locale` alapból elkészül `meta: true` esetén; távolítsd el a kézzel írtakat.
- JSON-feldolgozási hiba esetén a fájl útvonala naplózásra kerül; hiányzó kulcs esetén fejlesztési módban figyelmeztetés jelenik meg a böngésző konzolján.
