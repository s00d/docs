---
title: "Futásidejű felülírások"
description: "Módosítsd az alapértelmezett locale-t, a tartalék locale-t vagy a letiltott locale-okat egyetlen build példányaiként, környezeti változókkal vagy runtimeConfig segítségével."
---

A futásidejű felülírásokkal egyetlen build-artefaktum környezetenként vagy bérlőnként eltérő locale-beállításokkal futhat, újrabuildelés nélkül. Módosíthatod az alapértelmezett locale-t, a tartalék locale-t, valamint azt, hogy mely locale-ok vannak letiltva. Az útválasztás, az átirányítások, a renderelés és a szerveroldali segédfüggvények a felülírt értékeket használják, ahogy a böngésző is egy szerveren renderelt oldalon.

## Felülírások beállítása környezeti változókkal {#set-overrides-with-environment-variables}

```bash
NUXT_I18N_DEFAULT_LOCALE=de \
NUXT_I18N_FALLBACK_LOCALE=en \
NUXT_I18N_DISABLED_LOCALES=fr,it \
node .output/server/index.mjs
```

| Változó | Alias |
| --- | --- |
| `NUXT_I18N_DEFAULT_LOCALE` | `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE` |
| `NUXT_I18N_FALLBACK_LOCALE` | `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE` |
| `NUXT_I18N_DISABLED_LOCALES` (vesszővel elválasztva) | `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES` |

A szerver induláskor egyszer olvassa be őket; egy módosítás érvényesítéséhez indítsd újra. Szerveren renderelt oldalon a böngésző a feloldott értékeket a szervertől kapja. `ssr: false` esetén nincs szerveroldali renderelés, és a böngészőnek nincs környezete: ott csak a `runtimeConfig.public.i18nRuntime` érvényes, és a böngésző az alább felsorolt figyelmeztetéseket naplózza.

## Felülírások beállítása runtimeConfig segítségével {#set-overrides-in-runtimeconfig}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

A `runtimeConfig.public.i18nRuntime` alatt beállított érték elsőbbséget élvez az ugyanarra a mezőre vonatkozó `NUXT_I18N_*` változóval szemben.

Ne keverd össze a build idejű `DEFAULT_LOCALE` változóval, amely buildelés közben helyettesíti a `defaultLocale` értéket, és nem igényel futásidejű támogatást.

## Mi változtatható és mi nem {#what-can-and-cannot-change}

| Beállítás | Futásidőben |
| --- | --- |
| `defaultLocale` | Igen, `prefix` és `no_prefix` alatt. `prefix_except_default` és `prefix_and_default` alatt a buildkor rögzül (az oldalai a prefix nélküli útvonalak); a felülírás figyelmeztetéssel figyelmen kívül marad. |
| `fallbackLocale` | Igen. |
| `disabledLocales` | Hozzáadódik a buildkor letiltott locale-okhoz; soha nem engedélyez újra egyet sem. A build alapértelmezettje nem tiltható le `prefix_except_default` / `prefix_and_default` alatt. |
| `strategy` | Nem. A futásidejű stratégia figyelmeztetéssel figyelmen kívül marad; stratégiánként egy artefaktumot buildelj. |

Az érvénytelen értékek soha nem törik el az alkalmazást. Minden eset szerverfolyamatonként egy figyelmeztetést naplóz:

- az összes locale letiltása figyelmen kívül marad;
- a nem engedélyezett `defaultLocale` az első engedélyezett locale-ra esik vissza;
- a nem engedélyezett `fallbackLocale` megtartja a build értékét, ha az engedélyezett, egyébként nincs tartalék.

## A tényleges konfiguráció olvasása {#read-the-effective-config}

```vue
<script setup lang="ts">
const { $getI18nConfig } = useNuxtApp()
const config = $getI18nConfig() // build config with overrides applied
</script>
```

Kezeld csak olvashatóként: a szerveren minden kérés osztozik rajta, és fejlesztési módban fagyasztott; a böngészőbeli másolat nincs fagyasztva. A konfiguráció `#build/i18n.strategy.mjs` útvonalról történő importálása a build értékeit adja, felülírások nélkül.

## Letiltott locale-ok és statikus fájlok {#disabled-locales-and-static-files}

Egy futásidőben letiltott locale az útvonalain és a payload-útvonalán 404-gyel válaszol, de a payloadfájljai továbbra is a `.output/public/_locales/` mappában vannak, és egy statikus fájlszerver visszaadja őket. Ha ezek a fájlok nem lehetnek elérhetők, tiltsd le a locale-t build időben a `disabled: true` beállítással.
