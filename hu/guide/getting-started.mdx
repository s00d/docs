Ez az oldal végigvezet egy i18n nélküli Nuxt alkalmazástól egy nyelvváltóval rendelkező, lefordított oldalig. Erre egyszer van szükséged, a projekt elején. A végén lokalizált URL-ekkel (`/about`, `/de/about`), locale-onként és oldalanként egy JSON-fájllal, valamint a sablonjaidban használható `$t`-vel rendelkezel.

## Telepítés {#install}

A modulhoz Nuxt 3.18 vagy újabb (a Nuxt 4 is működik) és Node 20 vagy újabb szükséges.

<CodeGroup>

```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>

## A locale-ok konfigurálása {#configure-the-locales}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', displayName: 'English' },
      { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
      { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
    ],
    defaultLocale: 'en',
  },
})
```

Egy első alkalmazásnak ennyi konfiguráció elég. Az alapértékek a következőket adják:

- `strategy: 'prefix_except_default'`: az alapértelmezett locale-nak nincs előtagja (`/about`), a többinek van (`/de/about`). Lásd: [Útválasztási stratégiák](/hu/guide/strategy).
- `translationDir: 'locales'`: a fordítási fájlok a projekt gyökerében lévő `locales/` mappában vannak, a Nuxt 4 `app/` elrendezésével is.
- `meta: true`: `hreflang`, canonical és `og:locale` tagek, valamint `lang` és `dir` a `<html>` elemen. Lásd: [SEO](/hu/guide/seo).
- A `/` oldalt megnyitó látogató arra a nyelvre kerül, amelyet a böngészője kér (`Accept-Language`). Lásd: [Locale-felismerés](/hu/guide/locale-detection).

Az `iso` a SEO-tagekben használt nyelvi címke; a `code` az, ami az URL-ben megjelenik. Minden opció megtalálható a [Modulopciók](/hu/api/module-options) oldalon.

## Fordítási fájlok hozzáadása {#add-translation-files}

Indítsd el a fejlesztői szervert a `nuxt dev` paranccsal. Amikor a Nuxt feloldja az oldalakat, a modul létrehoz egy üres `{}` fájlt minden olyan locale-hoz és oldalhoz, amelyhez még nincs (ezt a [`disableWatcher`](/hu/api/module-options#disablewatcher) opcióval kapcsolhatod ki):

```text
locales/
├── en.json            # root: keys every page can use
├── de.json
├── fr.json
└── pages/
    ├── index/         # pages/index.vue
    │   ├── en.json
    │   ├── de.json
    │   └── fr.json
    └── about/         # pages/about.vue
        ├── en.json
        ├── de.json
        └── fr.json
```

Töltsd ki a gyökérfájlt és egy oldalfájlt:

```json
// locales/en.json
{ "nav": { "home": "Home", "about": "About" } }
```

```json
// locales/pages/index/en.json
{ "welcome": "Welcome, {name}!", "items": "no items | one item | {count} items" }
```

Egy oldal látja a gyökérkulcsokat és a saját kulcsait; ütközés esetén a saját fájlja győz. A mappanevek az útvonal nevét követik (a `pages/articles/[id].vue` a `locales/pages/articles-id/` mappának felel meg). A [Fordítási fájlok](/hu/guide/translations) oldal ismerteti az elrendezést, a tartalék-értékeket és a betöltést.

## A `$t` használata egy oldalon {#use-$t-on-a-page}

```vue
<!-- pages/index.vue -->
<script setup lang="ts">
const { t, tc, getLocale } = useI18n()

const title = t('nav.home') // 'Home'
</script>

<template>
  <h1>{{ $t('welcome', { name: 'Ada' }) }}</h1>
  <!-- Welcome, Ada! -->
  <p>{{ $tc('items', 3) }}</p>
  <!-- 3 items -->
  <p>{{ getLocale() }}</p>
  <!-- en -->
</template>
```

- A sablonokban minden segédfüggvény `$` előtaggal érhető el (`$t`, `$tc`, `$localePath`, …).
- A `<script setup>` blokkban a `useI18n()` ugyanezeket a segédfüggvényeket adja vissza, `$`-ral és anélkül is (a `t` és a `$t` ugyanaz a függvény). Automatikusan importálódik.
- A `{name}` helyőrzők a paraméterobjektumból töltődnek ki. A többes számú alakokat `|` választja el; a darabszám választja ki az alakot (0, 1, majd minden ennél nagyobb értékre az utolsót).

Minden segédfüggvény megtalálható a [Metódusok](/hu/api/methods) oldalon.

## Hivatkozás oldalak között és locale-váltás {#link-between-pages-and-switch-locale}

```vue
<!-- components/AppHeader.vue -->
<template>
  <nav>
    <i18n-link :to="{ name: 'index' }">{{ $t('nav.home') }}</i18n-link>
    <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
    <i18n-switcher />
  </nav>
</template>
```

- Az [`<i18n-link>`](/hu/components/i18n-link) egy `NuxtLink`, amely az aktuális locale-ban lévő oldalra mutat: a `/de` oldalon az about link a `/de/about` címre visz.
- Az [`<i18n-switcher>`](/hu/components/i18n-switcher) az engedélyezett locale-ok legördülő listája; a látogatót ugyanazon az oldalon tartja.
- Saját gombokhoz hívd meg a `$switchLocale('de')`-t, amely az aktuális oldal német változatára navigál, és megjegyzi a választást. Sima `NuxtLink`-hez használd a `$localePath({ name: 'about' })` vagy a `$switchLocalePath('de')` függvényt.

## Ellenőrzés {#check-it}

Futtasd a `nuxt dev` parancsot, és nyisd meg:

| URL | Mit mutat |
| --- | --- |
| `/` | Angol kezdőoldal (vagy átirányítás a `/de` címre, ha a böngésződ a németet részesíti előnyben) |
| `/de` | Német kezdőoldal |
| `/de/about` | Német about oldal |
| `/en/about` | 404: `prefix_except_default` esetén az alapértelmezett locale-nak nincs előtagja |

A JSON-fájlok módosításai újratöltés nélkül érvényesülnek a megnyitott oldalon.
