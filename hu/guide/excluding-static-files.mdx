---
title: "Útvonalak kizárása"
description: "Tartsd távol az oldalakat és fájlokat a locale-útválasztástól az excludePatterns segítségével, és nézd meg, mely útvonalak vannak már kizárva."
---

Egyes útvonalak soha nem kaphatnak locale-előtagot vagy locale-átirányítást: egy adminfelület, egy állapotellenőrző végpont, egy generált hírfolyam. Az `excludePatterns` jelöli meg ezeket, és egy beépített lista már lefedi a Nuxt belső útvonalait és a gyakori statikus fájlokat. Egy kizárt oldal pontosan azt az útvonalat tartja meg, amelyet megadtál, és továbbra is a `$t` használatával renderelődik.

## Útvonal kizárása {#exclude-a-path}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    excludePatterns: [
      '/admin', // /admin and everything below it
      '/preview-*', // glob over the whole path
    ],
  },
})
```

Ezzel a konfigurációval a `pages/admin/index.vue` csak a `/admin` útvonalon válaszol; nincs `/de/admin`, és a `/admin` soha nem irányít át a `/de/admin` útvonalra.

## Mintaszintaxis {#pattern-syntax}

A minták az `app.baseURL` nélküli útvonalra illeszkednek:

| Minta | Illeszkedik | Nem illeszkedik |
| --- | --- | --- |
| `'/admin'` | `/admin`, `/admin/users` | `/administrator`, `/de/admin` |
| `'/preview-*'` | `/preview-1`, `/preview-a/b` | `/de/preview-1` |
| `'/file-?'` | `/file-a` | `/file-ab` |
| `/^\/v\d+\//` | `/v2/docs` | `/docs` |

Egy `*` vagy `?` nélküli karakterlánc magára az útvonalra és az alatta lévő teljes szegmensekre illeszkedik. `*` (tetszőleges karaktersorozat, a perjeleket is beleértve) vagy `?` (egy karakter) esetén a teljes útvonalra kell illeszkednie. A karakterláncokat mindig `/` jellel kezdd.

## Ami már ki van zárva {#what-is-excluded-already}

Ezek konfiguráció nélkül sem kapnak soha locale-útvonalakat vagy átirányításokat:

- az `/api` és a `/_nuxt`, valamint minden alattuk lévő útvonal;
- a fordítások útvonala, alapértelmezés szerint `/_locales` ([`apiBaseUrl`](/hu/api/module-options#apibaseurl));
- minden olyan útvonal, amelynek valamelyik szegmense `__` jellel kezdődik (`/__nuxt_content`, `/en/__og-image__`);
- `/sitemap*.xml`, `/robots.txt`, `/favicon.ico`, `/apple-touch-icon*.png`, `/manifest.json`, `/sw.js`, `/workbox-*.js`;
- minden olyan útvonal, amelynek utolsó szegmense statikus fájlkiterjesztésre végződik: `xml txt ico json js css png jpg jpeg gif svg webp avif pdf wasm map mp4 webm mp3 zip gz woff woff2 ttf eot`. A pontot tartalmazó oldal-slugok, például a `/user/john.doe`, és a `.html` útvonalak oldalak maradnak.

## Mit tesz a kizárás {#what-an-exclusion-does}

- **Útvonalak:** nem generálódnak lokalizált változatok; az oldal a megadott formában marad.
- **Átirányítások és 404-ek:** a szerveroldali átirányító plugin és a kliensoldali átirányító middleware kihagyja az útvonalat.
- **Előrenderelés:** az illeszkedő útvonalak kikerülnek az előrenderelendő útvonalak listájából.

Nem akadályozza meg, hogy az i18n szerver-middleware locale-t észleljen a kéréshez, és azt sem, hogy az oldal fordításokat használjon. Ha egy oldalt lokalizáltan szeretnél megtartani, de SEO-címkék nélkül, használd a `disableMeta` beállítást ([Oldalkonfiguráció](/hu/guide/per-component-translations#turn-off-seo-tags)). Ha egy oldalt útvonal alapján a `nuxt.config.ts`-ből szeretnél lokalizálatlanul hagyni, a `globalLocaleRoutes: { '/admin': false }` ([Lokalizált útvonalak](/hu/guide/custom-locale-routes#in-nuxt-config)) ugyanezt teszi az útválasztásnál.
