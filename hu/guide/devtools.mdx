A `nuxt dev` alatt a modul két hibakeresési segédeszközt ad hozzá: egy **i18n Micro** fület a Nuxt DevToolsban a fordítási fájlok böngészéséhez és szerkesztéséhez, valamint egy Vue DevTools inspectort az élő locale-hoz és a betöltött szótárakhoz. Mindkettő csak fejlesztés közben létezik, és semmit sem ad a production buildekhez. A Nuxt fülhöz csak a Nuxt DevToolsnak kell engedélyezve lennie; a Vue inspectorhoz a Vue DevTools böngészőbővítmény is szükséges.

## Nuxt DevTools fül {#nuxt-devtools-tab}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  devtools: { enabled: true }, // the tab is registered only when DevTools are on
})
```

Nyisd meg a Nuxt DevToolst (`Shift + Alt + D`), és válaszd az **i18n Micro** fület. A fül a következőket mutatja:

- minden réteg `locales/` könyvtára alatti összes JSON-fájl (gyökér és `pages/`), valamint az `additionalTranslationDirs` gyökérfájljai;
- fájlonként egy szerkesztő; a **Save** visszaírja a fájlt a lemezre, és a fejlesztői szerver újratölti a fordításokat;
- egy fájl **Export** / **Import** funkciója JSON-ként, valamint **Stats** a kulcsok számával és a fordítási lefedettséggel;
- a feloldott modulbeállítások konfigurációs nézete;
- **Translate**, amely a hiányzó kulcsokat a fül beállításaiban konfigurált gépi fordítómotorral tölti ki.

A mentés csak a fordítási könyvtáraidon belüli, már létező `.json` fájlokat írja. Ha egy fájl több rétegben is létezik, a projekt saját példánya íródik.

## Vue DevTools inspector {#vue-devtools-inspector}

A Vue DevTools böngészőbővítménnyel a modul regisztrál egy i18n inspectort (aktuális locale, útvonal-chunk, betöltött kulcsok) és egy idővonalat a locale-váltásokkal, chunk-betöltésekkel és hiányzó kulcsokkal.

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    debug: true, // also log every $t / $ts / $tc call on the timeline
    // vueDevtools: false, // turn the inspector off, keep the Nuxt tab
  },
})
```

A [`vueDevtools`](/hu/api/module-options) alapértelmezése `true`. A `debug: true` bőbeszédű; csak rövid munkamenetekhez használd.

## Nuxton kívül {#outside-nuxt}

Ugyanez a felület [`@i18n-micro/devtools-ui`](/hu/integrations/devtools-ui-package) néven is megjelent a keretrendszer-csomagokra épülő Vite-alkalmazásokhoz; a beállításhoz lásd azt az oldalt.
