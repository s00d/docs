title: "useI18n"
description: "A useI18n egyszerű objektumként adja vissza a futásidejű segédfüggvényeket (`$t`, `$tc`, `$localePath`, …), `$` előtaggal és anélkül is."
---

A `useI18n()` egyszerű objektumként adja vissza a modul futásidejű segédfüggvényeit. Használd `<script setup>` blokkban, composable-ökben és pluginekben a `useNuxtApp()` helyett. Minden segédfüggvény elérhető a `$` kezdetű nevén és egy előtag nélküli aliasként is: a `t` és a `$t` ugyanaz a függvény.

## Szignatúra {#signature}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Minden futásidejű segédfüggvény, egyszerű objektumként.

Ugyanazok a függvények, amelyeket a plugin `$t`, `$tc` stb. néven injektál, elérhetők
a dollárjeles néven és egy előtag nélküli aliasként is — így a `const { t } = useI18n()` és
a `const { $t } = useI18n()` egyaránt működik.

**Visszatérési érték** — a [metódusreferenciában](/hu/api/methods) leírt segédfüggvények

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

A visszaadott objektum a [`PluginsInjections`](/hu/api/methods) minden segédfüggvényét tartalmazza. Mindegyik dokumentálva van a [Segédfüggvények](/hu/api/methods) oldalon.

## Példa {#example}

```vue
<script setup lang="ts">
const { t, tc, localePath, switchLocale, getLocale } = useI18n()

const title = computed(() => t('page.title'))
</script>

<template>
  <h1>{{ title }}</h1>
  <p>{{ tc('items', 3) }}</p>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
  <button @click="switchLocale(getLocale() === 'en' ? 'de' : 'en')">{{ t('nav.switch') }}</button>
</template>
```

## Ami nincs a típusban {#not-in-the-type}

A `$defineI18nRoute` csak a `useNuxtApp()` típusán szerepel:

```ts
const { $defineI18nRoute } = useNuxtApp()
```
