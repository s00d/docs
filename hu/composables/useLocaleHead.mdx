---
title: "useLocaleHead"
description: "A useLocaleHead objektumként állítja elő az i18n SEO tageket (lang, dir, canonical, hreflang, og:locale), amelyet a useHead függvénynek adhatsz át."
---

A `useLocaleHead()` előállítja az aktuális route i18n head tagjeit: `lang` és `dir` a `<html>` elemen, egy canonical link, `hreflang` alternatívák `x-default` linkkel, `og:url`, `og:locale` és `og:locale:alternate`. Akkor használd, ha [`meta: false`](/hu/api/module-options#meta) beállítást adsz meg, és magad kezeled a `useHead` hívást; `meta: true` esetén a modul már regisztrálja ezeket a tageket, az oldalankénti módosítások pedig a [`useI18nHead`](/hu/composables/useI18nHead) segítségével történnek.

## Szignatúra {#signature}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { build: () => LocaleHead; metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }, LocaleHead | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

Az aktuális route SEO head tagjei: `hreflang` alternatívák minden locale-hoz, valamint
`x-default`, egy canonical link, `og:locale`, és `lang`/`dir` a `<html>` elemen.

Csak akkor szükséges, ha a `meta` ki van kapcsolva, vagy az alapértelmezéseket módosítani kell — `meta: true` esetén
a modul maga regisztrálja ugyanezeket a tageket.

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| `options` | `UseLocaleHeadOptions` |  |

**Visszatérési érték** — `metaObject`, egy ref, amely a `useHead` függvénynek átadható head objektumot tartalmazza; az `updateMeta` frissíti; a `build` az aktuális route alapján számítja ki a head objektumot (reaktív, ha getterben olvasod, pl. `useHead(() => build())`)

```ts
const { metaObject } = useLocaleHead({ addSeoAttributes: true })
useHead(metaObject)
```

## Beállítások {#options}

| Beállítás | Alapértelmezés | Leírás |
| --- | --- | --- |
| `addDirAttribute` | `true` | Beállítja a `dir` attribútumot a `<html>` elemen a locale `dir` értéke alapján (`'auto'`, ha nincs ilyen). |
| `identifierAttribute` | `'id'` | Az attribútum, amely az egyes tageket azonosítja (`i18n-can`, `i18n-og`, `i18n-alternate-<hreflang>`, …), így a frissítések lecserélik a tageket ahelyett, hogy újakat adnának hozzá. |
| `addSeoAttributes` | `true` | Canonical, `hreflang` és `og:` tagek kiírása. `false` esetén csak a `htmlAttrs` marad. |
| `baseUrl` | `'/'` | Minden URL elé illesztett origin. Relatív URL-ekhez hagyd `'/'` értéken; abszolút URL-ekhez adj meg `'https://example.com'` értéket. |
| `autoUpdate` | `true` | Újraépíti a `metaObject` objektumot, ha a route vagy az `i18n-locale` állapot megváltozik. |

## Mit ír ki {#what-it-emits}

- Semmit egy illeszkedés nélküli route-on (404) vagy olyan route-on, amelyen az aktív locale-hoz `disableMeta` van beállítva.
- Canonical és `og:url`: `$switchLocalePath(<active locale>)`, a query a [`canonicalQueryWhitelist`](/hu/api/module-options#canonicalquerywhitelist) listára szűkítve, a [`trailingSlash`](/hu/api/module-options#trailingslash) alkalmazásával.
- `hreflang`: egy link minden olyan engedélyezett locale-hoz, amelyben az oldal létezik, `hreflang = iso || code`, kihagyva a `seo: false` beállítású locale-okat; `hreflangBaseLanguage: true` esetén egy nyelv első regionális locale-ja a puszta nyelvi taget is kiírja. `no_prefix` esetén egy sem.
- `x-default`: az alapértelmezett locale URL-je, kivéve ha a stratégia `no_prefix`, az alapértelmezett locale `seo: false` beállítású, vagy az oldal nem létezik benne.
- `og:locale` / `og:locale:alternate`: a locale `og` értékéből, vagy az átalakított `iso` értékéből (`en-US` → `en_US`); ha egyik sem működik, fejlesztői figyelmeztetéssel kimarad.

## Példa {#example}

```ts
// app.vue, with i18n.meta: false
const { metaObject } = useLocaleHead({ baseUrl: 'https://example.com' })
useHead(metaObject)
```

A `build()` ugyanazt az objektumot adja vissza ref nélkül: a `useHead(() => build())` watcher nélkül is reaktív marad.
