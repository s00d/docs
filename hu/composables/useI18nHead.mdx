title: "useI18nHead"
description: "A useI18nHead egyetlen oldalra felülírja a generált i18n SEO tageket: lecseréli vagy eltávolítja a canonical, hreflang és og tageket, vagy sajátokat ad hozzá."
---

A `useI18nHead()` a modul által generált SEO tageket módosítja, kizárólag egy oldalon. Akkor használd, ha az oldal jobban tudja, mint a router: egy CMS-cikk, amely csak néhány locale-ban létezik, egy API-ból érkező canonical URL, további `og:` tagek. A generált tageket kapod meg, rajtuk a te felülírásaiddal.

## Szignatúra {#signature}

```ts
useI18nHead(input?: MaybeRefOrGetter<I18nHeadInput | null>): { pageHead: any; resetPageHead: () => void }
```

Oldalszintű felülírások regisztrálása az i18n SEO head tagekhez.
A `02.meta` plugin a `useLocaleHead` kimenetére fésüli rá őket.

Használj inkább gettert (`() => ({ … })`), ha az értékek a `$t` / `t` függvényből jönnek, így
locale-váltáskor újra kiértékelődnek. Egy egyszerű objektum egyszer értékelődik ki, és utána változatlan marad.

| Paraméter | Típus | Leírás |
| --- | --- | --- |
| `input` *(opcionális)* | `MaybeRefOrGetter<I18nHeadInput \| null>` |  |

A [`meta: true`](/hu/api/module-options#meta) beállítással működik (ez az alapértelmezés): a modul meta pluginje minden head-rendereléskor a [`useLocaleHead`](/hu/composables/useLocaleHead) kimenetére fésüli a bemenetet. `meta: false` esetén semmi sem olvassa.

A felülírás a route nevének változásakor visszaáll. Az az oldal, amely beállítja a `disableMeta` értéket, egyáltalán nem kap i18n tageket, a felülírásokat is beleértve.

## Bemenet {#input}

`I18nHeadInput` (az `@i18n-micro/types` csomagból):

| Kulcs | Típus | Hatás |
| --- | --- | --- |
| `htmlAttrs` | `Record<string, string>` | Hozzáfésülődik a `<html>` attribútumaihoz (`lang`, `dir`). |
| `meta` | `I18nHeadMeta[]` | A generált tagek után kerül be; lecseréli az azonos `id`, `property` vagy `name` értékű taget. |
| `link` | `I18nHeadLink[]` | A generált linkek után kerül be; lecseréli az azonos `id`, vagy `rel` + `hreflang` értékű linket. |
| `replace.canonical` | `string \| false` | Lecseréli a canonical `href` értékét, vagy eltávolítja a linket. |
| `replace.hreflang` | `I18nHeadLink[] \| false` | Lecseréli vagy eltávolítja az **összes** `rel="alternate"` linket, az `x-default` linket is beleértve. |
| `replace.xDefault` | `I18nHeadLink \| false` | Lecseréli vagy eltávolítja az `x-default` linket. |
| `replace.ogLocale` | `string \| false` | Lecseréli vagy eltávolítja az `og:locale` taget. |
| `replace.ogUrl` | `string \| false` | Lecseréli vagy eltávolítja az `og:url` taget. |
| `replace.ogAlternates` | `string[] \| false` | Újraépíti az `og:locale:alternate` tageket ezekből a locale-kódokból (az `og` / `iso` alapján), kihagyva az aktuális locale-t, az ismeretlen kódokat és az `og` vagy `iso` érték nélküli kódokat, vagy eltávolítja őket. |
| `disable` | `I18nHeadDisableGroup[]` | Eltávolítja a generált csoportokat: `'hreflang'` (az `x-default` nélkül), `'x-default'`, `'canonical'`, `'og'` (`og:locale` + `og:url`), `'og-alternates'`, `'html'`. |

Az alkalmazás sorrendje: `disable`, majd `replace`, majd `htmlAttrs`, `meta`, `link`.

## Példa {#example}

Egy cikk, amely csak néhány locale-ban létezik, az API-ból érkező alternatív URL-ekkel:

```vue
<script setup lang="ts">
const route = useRoute()
const { t } = useI18n()
const { data: article } = await useFetch<{ title: string; urls: Record<string, string> }>(`/api/articles/${route.params.slug}`)

useI18nHead(() => {
  if (!article.value) return null
  const codes = Object.keys(article.value.urls)
  return {
    meta: [{ property: 'og:title', content: article.value.title || t('blog.title') }],
    replace: {
      hreflang: codes.map((code) => ({ rel: 'alternate', hreflang: code, href: article.value!.urls[code]! })),
      ogAlternates: codes,
    },
  }
})
</script>
```

Adj át gettert, ahogy itt, ha az értékek a `t()` függvényből vagy aszinkron adatból jönnek: locale-váltáskor újra lefut. Egy egyszerű objektumot csak egyszer olvas be.
