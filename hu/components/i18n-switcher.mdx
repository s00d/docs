---
title: "<i18n-switcher>"
description: "Az <i18n-switcher> komponens az engedélyezett locale-ok legördülő listája, amelyek mindegyike az aktuális oldalra mutat az adott locale-ban."
---

Az `<i18n-switcher>` egy gombot renderel az aktív locale-lal, valamint egy legördülő listát az összes engedélyezett locale-lal, az aktívat is beleértve. Használd kész nyelvi menüként; ha más markupra van szükséged, építsd fel a sajátodat a [`$getLocales`](/hu/api/methods#$getlocales) és a [`$switchLocalePath`](/hu/api/methods#$switchlocalepath) segítségével. Minden bejegyzés az aktuális oldalra mutat az adott locale-ban.

## Propok és slotok {#props-and-slots}

| Prop | Típus | Alapértelmezés | Leírás |
| --- | --- | --- | --- |
| `customLabels` | `Record<string, string>` | `() => ({})` | Megjelenítendő név locale-kódonként, amely felülírja a locale-konfiguráció `displayName` értékét. |
| `customWrapperStyle` | `CSSProperties` | `() => ({})` | Inline stílus a külső burkolóelemhez. |
| `customButtonStyle` | `CSSProperties` | `() => ({})` | Inline stílus a legördülő listát megnyitó gombhoz. |
| `customDropdownStyle` | `CSSProperties` | `() => ({})` | Inline stílus a legördülő panelhez. |
| `customItemStyle` | `CSSProperties` | `() => ({})` | Inline stílus a legördülő lista minden eleméhez. |
| `customLinkStyle` | `CSSProperties` | `() => ({})` | Inline stílus az elemen belüli linkhez. |
| `customActiveLinkStyle` | `CSSProperties` | `() => ({})` | Inline stílus az éppen aktív locale linkjéhez. |
| `customDisabledLinkStyle` | `CSSProperties` | `() => ({})` | Inline stílus az *aktuális* locale gombjához, ha a konfigurációban `disabled: true`. |
| `customIconStyle` | `CSSProperties` | `() => ({})` | Inline stílus a gombon lévő nyíl ikonhoz. |

### Slotok {#slots}

| Slot | Kötések | Leírás |
| --- | --- | --- |
| `before-button` | — | Tartalom a legördülő listát megnyitó gomb előtt. |
| `before-selected-locale` | — | Tartalom az aktív locale címkéje előtt a gombon belül. |
| `after-selected-locale` | — | Tartalom az aktív locale címkéje után a gombon belül. |
| `before-dropdown` | — | Tartalom a gomb és a legördülő panel között. |
| `before-dropdown-items` | — | Tartalom a legördülő lista tetején, a locale-lista fölött. |
| `before-item` | `locale` | Tartalom minden locale-bejegyzés előtt. |
| `before-link-content` | `locale` | Tartalom egy locale címkéje előtt a linkjén belül. |
| `after-link-content` | `locale` | Tartalom egy locale címkéje után a linkjén belül. |
| `after-item` | `locale` | Tartalom minden locale-bejegyzés után. |
| `after-dropdown-items` | — | Tartalom a legördülő lista alján, a locale-lista alatt. |
| `after-dropdown` | — | Tartalom a legördülő panel után. |

## Működés {#behaviour}

- Minden olyan locale-t felsorol, amely nem `disabled: true`, az aktívat is beleértve.
- Minden bejegyzés egy `<a>`, amely a `$switchLocalePath(code)` címre mutat. Az útvonal az `app.baseURL` alatt oldódik fel; egy másik domainen lévő locale `baseUrl` abszolút marad. A `hreflang` és a `lang` értéke `iso || code`, a `dir` akkor van beállítva, ha a locale-nak van ilyen, az aktuális locale-on `aria-current="page"` szerepel, az osztály pedig `switcher-locale-<code>`. Kattintásra meghívódik a `$switchLocale(code)`, és bezárul a legördülő lista; módosítóbillentyűvel a kattintást a böngésző kezeli.
- A lista rejtve a szerver HTML-ben marad, így a crawlerek látják a linkeket. Az Escape billentyű vagy egy kívülre kattintás bezárja.
- Címke: `customLabels[code]`, majd a locale `displayName` értéke, végül a kód (fejlesztői figyelmeztetéssel).
- Stílusok: kis inline alapértelmezések (keretes fehér gomb és panel, az aktív bejegyzés félkövér és kék). Minden `custom*Style` prop az adott rész alapértelmezése után kerül alkalmazásra. A gomb osztályai `i18n-switcher-button` és `language-switcher`, a burkolóé `i18n-switcher-wrapper`, a listáé `i18n-switcher-dropdown`. A pozicionálás logikai CSS-tulajdonságokat használ, így a `dir="rtl"` működik.

## Példa {#example}

```vue
<template>
  <i18n-switcher
    :custom-labels="{ en: 'English', de: 'Deutsch' }"
    :custom-button-style="{ borderRadius: '4px' }"
  >
    <template #before-link-content="{ locale }">
      <img :src="`/flags/${locale.code}.svg`" alt="" width="16" />
    </template>
  </i18n-switcher>
</template>
```
