Az `@i18n-micro/types-generator` beolvassa a fordítási mappád összes JSON-fájlját, és egy deklarációt ír, amely felsorolja az összes kulcsot. Akkor add hozzá, ha azt szeretnéd, hogy a szerkesztőd kulcsokat javasoljon a `t()`, a `$t()` és az `<I18nT keypath>` használatakor. Nuxt modulként, valamint Vite- vagy Rollup-pluginként is működik, és egy fájl módosulásakor újragenerál.

## Telepítés {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/types-generator
```

```bash npm
npm install -D @i18n-micro/types-generator
```

```bash yarn
yarn add -D @i18n-micro/types-generator
```

</CodeGroup>

Peer-függőség: `@nuxt/kit` `^3.18.0 || ^4.0.0`. Csak a `/nuxt` belépési pont importálja; egy csak Vite-ot használó projektben a peer-figyelmeztetés figyelmen kívül hagyható.

## Nuxt {#nuxt}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro', '@i18n-micro/types-generator/nuxt'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

A modul a `.nuxt/types/i18n-micro.d.ts` fájlt írja, a Nuxt pedig hozzáadja a típuskontextushoz; semmit sem kell kézzel felvenni. Az `i18nTypes.translationDir` értéket olvassa, ennek hiányában azt, ahonnan a `nuxt-i18n-micro` a fordításokat olvassa: a `translationDir` értéket (az `i18n`-ből vagy az inline modulopciókból, alapértelmezés `'locales'`) minden rétegben, valamint az `additionalTranslationDirs` értéket. Az e mappában lévő JSON-fájl szerkesztése `nuxi dev` alatt újragenerálja a típusokat. Az `i18nTypes.outputFile` értéket a Nuxt figyelmen kívül hagyja (erről figyelmeztetés szól).

## Vite {#vite}

Az `I18nTypesPlugin` egy Vite-plugin, amelyet a Rollup is elfogad. Más bundlerhez hívd meg a `generateTypes` függvényt egy szkriptben.

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { I18nTypesPlugin } from '@i18n-micro/types-generator'

export default defineConfig({
  plugins: [
    vue(),
    I18nTypesPlugin({
      srcDir: process.cwd(),
      translationDir: 'src/locales',
      outputFile: 'src/i18n-micro.d.ts',
    }),
  ],
})
```

| Opció | Kötelező | Megjegyzések |
| --- | --- | --- |
| `srcDir` | igen | Alapkönyvtár; a `translationDir` ehhez képest oldódik fel. |
| `translationDir` | igen | A JSON-fájlokat tartalmazó mappa (az almappákkal, például a `pages/`-szel együtt), vagy mappák tömbje. |
| `outputFile` | nem | Hová kerüljön a deklaráció; alapértelmezés `<srcDir>/i18n-micro.d.ts`. |

A plugin a build indulásakor egyszer generál, a fejlesztői szerveren pedig a mappában történt változás után 300 ms-mal újragenerál. Győződj meg róla, hogy a `tsconfig.json` `include` beállítása lefedi a kimeneti fájlt.

## A kulcsok használata {#use-the-keys}

A generált fájl kiegészíti a `DefineLocaleMessage` interfészt az `@i18n-micro/types` csomagban, amely a `TranslationKey` típust a te kulcsaiddá alakítja:

```ts
declare module '@i18n-micro/types' {
  export interface DefineLocaleMessage {
    nav: object
    'nav.home': string
    'profile.title': string
  }
}
```

A kulcsok azok, amelyekre a `t()` választ ad — objektumok is —, minden locale-ból és minden oldalfájlból, a JSON-értékük típusával. A `TranslationKey` ezen kulcsok és bármely string uniója, így automatikus kiegészítést kapsz, nem hibákat: egy elgépelt vagy dinamikus kulcs is lefordul. A paraméterek és a visszatérési értékek nincsenek típusozva.

Egy ismert előtag alatti dinamikus kulcsoknál a `ScopedKey<'prefix'>` az illeszkedő kulcsokra szűkít:

```ts
import type { ScopedKey } from '@i18n-micro/types'

const statusText = (status: string) => t(`status.${status}` as ScopedKey<'status'>)
```

A `TranslationKey` és a `ScopedKey` az `@i18n-micro/types` csomagból származik (a React, a Preact és a Solid újraexportálja a `TranslationKey`-t; a Vue nem).

## API {#api}

| Export | Belépési pont | Megjegyzések |
| --- | --- | --- |
| `I18nTypesPlugin(options)` | `@i18n-micro/types-generator` | Vite- és Rollup-plugin |
| `generateTypes(options)` | `@i18n-micro/types-generator` | megírja a fájlt, visszaadja az útvonalát |
| `getTypesString(options)` | `@i18n-micro/types-generator` | írás nélkül visszaadja a deklarációt |
| `formatKeyProperty(key)` | `@i18n-micro/types-generator` | segédfüggvény |
| Nuxt modul (`configKey: 'i18nTypes'`) | `@i18n-micro/types-generator/nuxt` | `translationDir` opció |

Teljes szignatúrák: [csomagreferencia](/hu/api/packages/types-generator).
