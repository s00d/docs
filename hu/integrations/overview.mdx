Az `@i18n-micro/*` csomagok a Nuxt I18n Micro fordítási magját hozzák el a Vue, React, Preact, Solid, Astro, VitePress és a sima JavaScript számára. Akkor használd őket, ha az alkalmazásod nem Nuxt-alkalmazás, vagy ha egy Nuxton kívüli szkriptnek vagy szervernek ugyanazokra a fordítási fájlokra van szüksége. Minden csomag egyetlen példánymodellen, egyetlen router adapter szerződésen és ugyanazon a négy komponensen osztozik, amelyeket ez az oldal egyszer ír le.

Az `@i18n-micro/core`, az `@i18n-micro/types` és az `@i18n-micro/utils` ezekkel a csomagokkal együtt települ; ritkán importálod őket közvetlenül. Minden export szignatúrája megtalálható a generált [csomagreferenciában](/hu/api/packages/overview).

Minden csomagnak van egy playgroundja a repositoryban, a `packages/<name>/playground` alatt.

## A példány {#the-instance}

A `createI18n(options)` egyetlen példányt ad vissza, amely a szótárakat, az aktuális locale-t és az aktuális route-ot tárolja. A beállítások minden csomagban azonosak:

| Beállítás | Típus | Alapértelmezés | Megjegyzések |
| --- | --- | --- | --- |
| `locale` | `string` | kötelező | Aktív locale. |
| `fallbackLocale` | `string` | `locale` | Ebben keres, ha egy kulcs hiányzik a `locale`-ból. |
| `messages` | `Record<locale, Translations>` | `{}` | Gyökérszótárak (`'index'` route). |
| `routeMessages` | `Record<route, Record<locale, Translations>>` | `{}` | Route-szótárak. Csak Runtime, React, Preact, Node és VitePress. |
| `plural` | `PluralFunc` | `defaultPlural` | Egyéni többesszám-szabály. |
| `missingWarn` | `boolean` | `true` | Csak fejlesztéskor: `console.warn` a böngészőben hiányzó kulcs esetén. |
| `missingHandler` | `(locale, key, routeName) => void` | — | A figyelmeztetés helyett hívódik meg. |
| `numberFormats` | `Record<locale, Record<name, Intl.NumberFormatOptions>>` | — | Elnevezett formátumok: `tn(9.5, 'currency')`. |
| `datetimeFormats` | `Record<locale, Record<name, Intl.DateTimeFormatOptions>>` | — | Elnevezett formátumok: `td(date, 'short')`. |
| `timeZone` | `string` | a futtatókörnyezet zónája | IANA zóna a `td` dátumaihoz; a `tdr` értékét nem befolyásolja. Állítsd be, hogy a szerver és a böngésző ugyanazt a dátumot renderelje. |
| `now` | `() => number` | `Date.now` | A `tdr` órája. Add át a hidratálásnak a szerver idejét, hogy mindkettő ugyanazt a szöveget renderelje. |
| `localeIso` | `Record<code, string>` | — | A többesszám-szabályokhoz használt BCP 47 tag (`ua` → `uk-UA`). A React, a Preact és a Solid a provider `locales` listájának `iso` értékéből veszi. |

A szótárak az `i18n.storage.translations` objektumban élnek, amely egy `locale:route` kulcsú `Map` (`en:index`, `en:about`).

Egy kulcsot a modul először az aktuális route szótárában, majd a gyökérszótárban keres, előbb a `locale`, aztán a `fallbackLocale` számára. Egy hiányzó kulcs magát a kulcsot adja vissza (vagy az általad átadott `defaultValue` értéket).

```ts
i18n.addTranslations('en', { nav: { home: 'Home' } }) // root, deep-merged
i18n.addRouteTranslations('en', 'about', { title: 'About us' }) // route chunk
i18n.addTranslations('en', { nav: { home: 'Start' } }, false) // replace instead of merge
i18n.setRoute('about')
i18n.t('title') // 'About us'
i18n.t('nav.home') // 'Start' (root key, still visible on the route)
```

### Fordítás és formázás {#translate-and-format}

| Metódus | Visszatérési érték |
| --- | --- |
| `t(key, params?, defaultValue?, routeName?)` | Az érték (string, szám, objektum) a `{param}` behelyettesítésével. |
| `ts(...)` | Ugyanaz, mint a `t`, stringként. |
| `tc(key, count \| params, defaultValue?)` | Többes számú alak. |
| `tn(value, options \| name)` | `Intl.NumberFormat` az aktív locale-ban. |
| `td(value, options \| name)` | `Intl.DateTimeFormat`. |
| `tdr(value, options?)` | Relatív idő (`3 days ago`). |
| `has(key, routeName?)` | `true`, ha az aktív locale tartalmazza a kulcsot (route- vagy gyökérszótár; a tartalékot nem vizsgálja). |

A `defaultPlural` a `|` mentén felosztja az értéket, és a `count` indexű alakot választja, az utolsóra korlátozva; negatív, tört vagy `NaN` count esetén az utolsó alakot választja.

Egy egyéni `plural` a `(key, count, params, locale, getter)` argumentumokat kapja. Az értéket a `getter(key)` segítségével olvasd ki; ne a kulcsot oszd fel:

```ts
import type { PluralFunc } from '@i18n-micro/vue'

const plural: PluralFunc = (key, count, params, _locale, getter) => {
  const value = getter(key)
  if (typeof value !== 'string') return null
  const forms = value.split('|').map((form) => form.trim())
  return (count === 1 ? forms[0] : forms[1] ?? forms[0])!.replace('{count}', String(count))
}
```

## Router adapter {#router-adapter}

Az SPA csomagok nem függenek routertől. Egy router adapter (`I18nRoutingStrategy`) mondja meg nekik, hogyan olvassák ki az aktuális útvonalat, hogyan navigáljanak és hogyan építsenek lokalizált útvonalat. A beépített adapterek a `defaultLocale` kivételével minden locale-t előtaggal látnak el (`/about`, `/de/about`).

| Tag | Kötelező | Használja |
| --- | --- | --- |
| `getCurrentPath(): string` | igen | aktív link ellenőrzése (oldal szerint, a query és a hash nem számít), `switchLocale` (megtartja őket) |
| `push({ path }): void` | igen | `switchLocale`, `<I18nLink>` `linkComponent` nélkül, `<I18nSwitcher>` |
| `replace({ path }): void` | igen | — |
| `resolvePath(to, locale)` | nem | `localePath`, `localeRoute`, `<I18nLink>`; nélküle az útvonalak változatlanul térnek vissza |
| `linkComponent` | nem | az `<I18nLink>` ezt rendereli (pl. `RouterLink`) az `<a>` helyett |
| `getRoute()` | nem | `{ fullPath, query }` a SEO segédfüggvényekhez |

A `push` és a `replace` kötelező a Vue, React, Preact és Solid csomagokban. Az Astrónak saját, szerveroldali adaptere van opcionális `push`/`replace` taggal (lásd: [Astro](/hu/integrations/astro-package#router-adapter)).

Egy minimális adapter bármely history-alapú routerhez:

```ts
import type { I18nRoutingStrategy } from '@i18n-micro/react'

const locales = ['en', 'de']
const stripLocale = (path: string) => path.replace(/^\/(en|de)(?=\/|$)/, '') || '/'

export const historyAdapter: I18nRoutingStrategy = {
  getCurrentPath: () => window.location.pathname + window.location.search + window.location.hash,
  push: ({ path }) => window.history.pushState({}, '', path),
  replace: ({ path }) => window.history.replaceState({}, '', path),
  resolvePath: (to, locale) => {
    const path = stripLocale(typeof to === 'string' ? to : to.path || '/')
    return locale === 'en' ? path : `/${locale}${path === '/' ? '' : path}`
  },
}
```

## Komponensek {#components}

A Vue, a React, a Preact és a Solid ugyanazt a négy komponenst szállítja. A propjaik megegyeznek; a React, a Preact és a Solid a többi propot továbbadja a gyökérelemnek.

### `<I18nT>` {#&lt;i18nt&gt;}

| Prop | Típus | Megjegyzések |
| --- | --- | --- |
| `keypath` | `string` | kötelező |
| `params` | `object` | behelyettesítési értékek |
| `plural` | `number \| string` | a `tc(keypath, count)` eredményét rendereli |
| `number` | `number \| string` | a `tn(number)` eredményét adja át `{number}` néven |
| `date` | `Date \| string \| number` | a `td(date)` eredményét adja át `{date}` néven |
| `relativeDate` | `Date \| string \| number` | a `tdr(relativeDate)` eredményét adja át `{relativeDate}` néven |
| `tag` | `string` | burkoló elem, alapértelmezés `span` |
| `html` | `boolean` | a fordítást HTML-ként rendereli; megbízhatónak kell lennie, a paraméterek escape-elődnek |
| `defaultValue` | `string` | egy hiányzó kulcs helyett áll, és burkolás nélkül renderelődik, ha a `hideIfEmpty` elrejt egy üres értéket |
| `hideIfEmpty` | `boolean` | üres fordítás esetén semmit sem renderel |
| `customPluralRule` | `PluralFunc` | többesszám-szabály ehhez az elemhez |

Csak egy formázó prop érvényesül, ebben a sorrendben vizsgálva: `number`, `date`, `relativeDate`, `plural`.

#### Formázott szöveg {#rich-text}

Egy `{placeholder}` elemet is tartalmazhat. A Vue-ban ez egy elnevezett slot; a React, a Preact és a Solid esetén a `components` prop név szerint ad meg elemeket, vagy elemet visszaadó függvényeket. Mindkét esetben erősebb az azonos nevű paraméternél, minden ágban működik, és túléli, ha egy locale átrendezi a helyőrzőket.

```tsx
// { "terms": "I accept the {link} of {company}" }
<I18nT keypath="terms" params={{ company: 'ACME' }} components={{ link: <a href="/terms">terms</a> }} />
```

Solidban adj át függvényt, ha egy helyőrző ismétlődik: egy csomópont csak egy helyen állhat. A `children` lecseréli a szöveget; függvényként a `{ translation }` objektumot kapja, akárcsak a Vue alapértelmezett slotja. A `html` mindezeket figyelmen kívül hagyja.

### `<I18nLink>` {#&lt;i18nlink&gt;}

| Prop | Típus | Megjegyzések |
| --- | --- | --- |
| `to` | `string \| { path }` | az adapter `resolvePath` függvényével lokalizálva |
| `activeStyle` | stílusobjektum | az aktuális oldalon a `style` fölé fésülődik; a React, a Preact és a Solid egy fölötte lévő szakaszra is alkalmazza |
| `localeRoute` | függvény | felülírja a `resolvePath` függvényt ennél a linknél |

A külső URL-ek (`https://`, `mailto:`, `tel:`) `<a target="_blank" rel="noopener noreferrer">` elemként renderelődnek; a saját `target` vagy `rel` értéked győz. Az `onClick` mindig lefut. Egy módosítóbillentyűs kattintás, egy másik egérgomb vagy egy `target` a böngészőnél marad.

### `<I18nSwitcher>` {#&lt;i18nswitcher&gt;}

Az engedélyezett locale-ok legördülő listája (a `disabled: true` locale-ok rejtve vannak) beágyazott alapértelmezett stílusokkal. Az elemei linkek, a locale-ból származó `lang`, `hreflang` és `dir` értékkel. Alapértelmezés szerint egy elemre kattintva beállítódik a locale, és meghívódik az adapter `push` függvénye a lokalizált aktuális útvonallal; egy `switchLocale` prop lecseréli ezt a műveletet. `localeRoute` megadásával és router nélkül a böngésző követi a linket. Az Escape vagy egy kívülre kattintás bezárja.

| Prop | Megjegyzések |
| --- | --- |
| `locales`, `currentLocale`, `getLocaleName` | felülírják a biztosított értékeket |
| `switchLocale(code)` | lecseréli a beépített váltást |
| `localeRoute` | lecseréli a `resolvePath` függvényt |
| `customLabels` | `{ de: 'DE' }` |
| `customWrapperStyle`, `customButtonStyle`, `customDropdownStyle`, `customItemStyle`, `customLinkStyle`, `customActiveLinkStyle`, `customDisabledLinkStyle`, `customIconStyle` | stílusfelülírások |

### `<I18nGroup>` {#&lt;i18ngroup&gt;}

Egy `<div class="i18n-group">`, amely egy előtaggal ellátott `t` függvényt ad át a gyermekeinek. A benne lévő `<I18nT>` vagy `t()` hívásokat **nem** látja el előtaggal; csak az általa továbbadott `t` kap előtagot.

| Prop | Megjegyzések |
| --- | --- |
| `prefix` | kötelező, pl. `'profile'` |
| `groupClass` | további osztály a burkoló elemen |

Az előtaggal ellátott `t` Vue-ban egy scoped sloton keresztül (`v-slot="{ t }"`), a React, a Preact és a Solid esetén egy render-prop gyermeken keresztül érkezik (`{({ t }) => …}`).

## Típusos kulcsok {#typed-keys}

A `t()` bármilyen stringet elfogad. Ha automatikus kiegészítést szeretnél a kulcsaidhoz, generálj deklarációt a [típusgenerátorral](/hu/integrations/types-generator). A kulcsokat javasolja, de nem kényszeríti ki, és a paraméterek nem típusosak.

## Összehasonlítás a Nuxt modullal {#compared-with-the-nuxt-module}

A csomagokban nincs fájlalapú routing, szerver middleware és fordításbetöltő: te döntöd el, mikor töltöd be a JSON-t (`import`, `fetch`, vagy szerveren az `@i18n-micro/node`), és melyik router adaptert használod. A locale-felismerés, a SEO meta és a route-generálás Nuxt-funkciók; az Astrónak saját middleware-je van a felismeréshez és `useLocaleHead` függvénye a SEO-hoz.
