A `@i18n-micro/vue` egy Vue 3 plugin a Nuxt I18n Micro fordítási magjával: reaktív `t()`, globális `$t`, négy komponens és egy opcionális vue-router adapter. Olyan Vite vagy SSR Vue alkalmazásban használd, amely nem Nuxttal készül. A példánymodell, a router-szerződés és a komponensek propjai közösek a többi csomaggal, leírásukat a [Keretrendszerek](/hu/integrations/overview) oldalon találod.

## Telepítés {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vue
```

```bash npm
npm install @i18n-micro/vue
```

```bash yarn
yarn add @i18n-micro/vue
```

</CodeGroup>

Peer függőségek: `vue` `^3.3.0`; `vue-router` `^4.5.1 || ^5.0.0` (opcionális, csak a `@i18n-micro/vue/router` esetén). A publikált típusokhoz Vue 3.5.5 vagy újabb szükséges `skipLibCheck: false` mellett; `skipLibCheck: true` esetén, ami a szokásos sablonbeállítás, a régebbi verziók is lefordulnak.

## Beállítás {#setup}

```ts
// src/main.ts
import { createApp } from 'vue'
import { createI18n } from '@i18n-micro/vue'
import App from './App.vue'
import en from './locales/en.json'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales: [
    { code: 'en', iso: 'en-US', displayName: 'English' },
    { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
  ],
  defaultLocale: 'en',
})

createApp(App).use(i18n).mount('#app')
```

A `locales` és a `defaultLocale` kötelező a `useI18n()` számára: nélkülük `I18nLocalesKey not provided` hibát dob. Add át őket a `createI18n` függvénynek (mint fent), a `useI18n({ locales, defaultLocale })` hívásnak, vagy az `app.provide(I18nLocalesKey, …)` és az `app.provide(I18nDefaultLocaleKey, …)` segítségével.

A plugin globálisan regisztrálja az `I18nT`, `I18nLink`, `I18nGroup` és `I18nSwitcher` komponenseket, és a sablonokhoz hozzáadja a `$t`, `$ts`, `$tc`, `$tn`, `$td`, `$tdr`, `$has` és `$i18n` elemeket. Komponenseken kívül a példány az `i18n.global`. A további opciókat lásd: [a példány](/hu/integrations/overview#the-instance); a `routeMessages` Vue-ban nem érhető el, használd az `addRouteTranslations` függvényt.

## Fordítás {#translate}

```vue
<script setup lang="ts">
import { useI18n } from '@i18n-micro/vue'

const { t, tc, tn } = useI18n()
</script>

<template>
  <h1>{{ t('greeting', { name: 'Ada' }) }}</h1>
  <!-- Hello, Ada! -->
  <p>{{ tc('apples', 3) }}</p>
  <!-- 3 apples -->
  <p>{{ $t('nav.home') }} · {{ tn(1234.5) }}</p>
</template>
```

A `useI18n()` visszaadja a fordítási metódusokat (`t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`), a `locale` értéket (írható computed), valamint a `getLocale`, `getLocales`, `defaultLocale()`, `getLocaleName`, `localePath`, `localeRoute`, `switchLocale`, `setRoute`, `getRoute`, `addTranslations`, `addRouteTranslations`, `mergeTranslations`, `resolveTranslations`, `setTranslation`, `clearCache` és `instance` elemeket.

Bármikor tölthetsz be további szótárakat; minden komponens, amely olvassa őket, újrarenderelődik:

```ts
const { addTranslations, addRouteTranslations, setRoute } = useI18n()

addTranslations('de', (await import('./locales/de.json')).default)
addRouteTranslations('en', 'about', { title: 'About us' })
setRoute('about') // t('title') now reads the 'about' dictionary first
```

## Locale váltása {#switch-locale}

```ts
const { locale, switchLocale } = useI18n()

locale.value = 'de' // only the locale
switchLocale('de') // the locale, then router.push to the localized current path
```

A locale szótárát a váltás előtt vagy után töltsd be; a váltás semmit sem kér le.

Az `<I18nGroup>` előtaggal ellátott `t` függvényt ad a slotjának. Az `<I18nT>` belsejében vagy egy sima `t()` hívásban lévő kulcsok nem kapnak előtagot:

```vue
<I18nGroup prefix="profile" v-slot="{ t }">
  <h2>{{ t('title') }}</h2>
  <!-- profile.title -->
</I18nGroup>
```

## Útválasztás {#routing}

A vue-router adapter egy alútvonalon található, így a fő belépési pont soha nem importálja a `vue-router` csomagot:

```ts
// src/main.ts
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import { createI18n } from '@i18n-micro/vue'
import { createVueRouterAdapter } from '@i18n-micro/vue/router'
import App from './App.vue'
import Home from './pages/Home.vue'
import About from './pages/About.vue'
import en from './locales/en.json'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English' },
  { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
]

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/:locale(de)?', component: Home },
    { path: '/:locale(de)?/about', component: About },
  ],
})

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales,
  defaultLocale: 'en',
  routingStrategy: createVueRouterAdapter(router, locales, 'en'),
})

createApp(App).use(router).use(i18n).mount('#app')
```

A `createVueRouterAdapter(router, locales, defaultLocale)` az alapértelmezett kivételével minden locale-t előtaggal lát el (`/about`, `/de/about`), és az `<I18nLink>` elemet `RouterLink`-ként rendereli. A locale-t magadnak kell kiolvasnod az útvonalból, például a `router.beforeEach` hookban, és beállítanod az `i18n.global.locale.value` értékét. Adaptert később is csatolhatsz az `i18n.setRoutingStrategy(adapter)` hívással; egyéni adapterhez lásd: [Router adapter](/hu/integrations/overview#router-adapter).

## SSR {#ssr}

- A routert, az i18n-példányt és az alkalmazást a kérésenkénti renderfüggvényen belül hozd létre. Egyetlen közös példány esetén az egyik látogató locale-ja átszivároghatna egy másikhoz.
- A szerveren használd a `createMemoryHistory()` függvényt, vedd a locale-t az URL-ből, és töltsd be a szótárát (valamint a tartalékét) a `renderToString` előtt.
- Küldd el a locale-t a kliensnek (például egy `window.__STATE__` scriptben), és ugyanazzal a `locale` értékkel hozd létre a kliensoldali példányt, hogy a hidratálás egyezzen.
- Az `<I18nSwitcher>` csak akkor olvassa a `window.location` értékét, amikor a legördülő menü nyitva van, így a szerveren is renderelődik.

A `packages/vue/playground` egy teljes `entry-server.ts` / `entry-client.ts` párost tartalmaz.

## SEO head {#seo-head}

A `useLocaleHead(options)` a locale-okból és a router adapterből építi fel a `lang`/`dir`, a canonical, a `hreflang` és az `og:locale` tageket. Hívd meg az `updateMeta()` függvényt, amikor az útvonal megváltozik, és add át a `metaObject` objektumot a head-kezelődnek:

```ts
import { watch } from 'vue'
import { useRoute } from 'vue-router'
import { useHead } from '@unhead/vue'
import { useLocaleHead } from '@i18n-micro/vue'

const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
watch(() => route.fullPath, () => updateMeta(), { immediate: true })
useHead(metaObject)
```

Opciók: `baseUrl` (karakterlánc vagy függvény), `addDirAttribute` (alapértelmezés: `true`), `addSeoAttributes` (alapértelmezés: `true`), `identifierAttribute` (alapértelmezés: `'id'`), `hreflangBaseLanguage` (alapértelmezés: `false`). A `disabled: true` vagy `seo: false` beállítású locale-ok nem kapnak alternate linket.

| Export | Belépési pont |
| --- | --- |
| `createI18n`, `useI18n`, `useLocaleHead` | `@i18n-micro/vue` |
| `I18nT`, `I18nLink`, `I18nSwitcher`, `I18nGroup` | `@i18n-micro/vue` |
| `VueI18n` (példányosztály), `I18nInjectionKey`, `I18nLocalesKey`, `I18nDefaultLocaleKey` | `@i18n-micro/vue` |
| `defaultPlural`, `FormatService`, `interpolate` | `@i18n-micro/vue` |
| Típusok: `I18nRoutingStrategy`, `Locale`, `Translations`, `PluralFunc`, `Params`, `Getter`, `CleanTranslation`, `LocaleCode`, `VueI18nOptions`, `UseI18nOptions`, `UseLocaleHeadOptions`, `I18nPlugin` | `@i18n-micro/vue` |
