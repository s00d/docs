A `@i18n-micro/devtools-ui` a Nuxt DevTools fül fordításszerkesztője, webkomponensként és Vite pluginnal csomagolva. Add hozzá egy Vue, React, Preact, Solid vagy Astro projekthez, hogy fejlesztés közben a böngészőből böngészhesd és szerkeszthesd a fordítási mappád JSON-fájljait. A Nuxt alkalmazásokban ez már elérhető a [Nuxt DevTools](/hu/guide/devtools) részeként.

![A DevTools UI: egy fájlfa és egy szerkesztő, amely minden kulcs mellett mutatja az alapértelmezett locale szövegét](/images/devtools/02-translations-editor-dark.webp)

## Telepítés {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/devtools-ui
```

```bash npm
npm install -D @i18n-micro/devtools-ui
```

```bash yarn
yarn add -D @i18n-micro/devtools-ui
```

</CodeGroup>

Nincsenek peer függőségek.

## Beállítás {#setup}

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import { i18nDevToolsPlugin } from '@i18n-micro/devtools-ui/vite'

export default defineConfig({
  plugins: [i18nDevToolsPlugin({ translationDir: 'src/locales' })],
})
```

| Opció | Alapértelmezés | Megjegyzések |
| --- | --- | --- |
| `translationDir` | `'src/locales'` | A JSON-fájlokat tartalmazó mappa, a Vite gyökeréhez viszonyítva. |
| `base` | `'/__i18n_api'` | Az API-végpontok alapútvonala. |
| `injectButton` | `true` | Lebegő gomb hozzáadása a Vite `index.html` transzformációján keresztül kiszolgált oldalakhoz. Az Astrónak nincsenek ilyen oldalai: lásd alább. |
| `defaultLocale` | az első locale-fájl a `translationDir` mappában | A `/config` adja vissza. |
| `fallbackLocale` | `defaultLocale` | A `/config` adja vissza. |

A plugin csak a fejlesztői szerveren fut (`apply: 'serve'`); a production buildben semmi sem marad belőle. A gomb a `/__i18n_devtools.html` oldalt nyitja meg, amely a plugin végpontjain keresztül olvassa és menti a fájlokat:

| Végpont | Feladata |
| --- | --- |
| `GET <base>/translations` | a `translationDir` alatti összes szótár, relatív útvonal szerint |
| `POST <base>/save` | törzs: `{ file, content }`; felülír egy meglévő `.json` fájlt a `translationDir` mappán belül, minden más esetben 403. Soha nem hoz létre fájlt |
| `GET <base>/config` | `{ defaultLocale, fallbackLocale, locales, translationDir }`; a `locales` a `translationDir` gyökerében lévő fájlokból származik |

A végpontok csak a devtools oldalnak válaszolnak: egy másik originről vagy hostról érkező kérés `403`, a `/save` pedig csak `application/json` tartalmat fogad el (`415`). Az oldal a Vite HMR socketjén keresztül értesül a fájlváltozásokról.

Astróban a plugin helyett az integrációt add hozzá. Ez egy alkalmazást ad a fejlesztői eszköztárhoz:

```ts
// astro.config.mjs
import { defineConfig } from 'astro/config'
import { i18nDevToolsIntegration } from '@i18n-micro/devtools-ui/vite'

export default defineConfig({
  integrations: [i18nDevToolsIntegration({ translationDir: 'src/locales' })],
})
```

A mentés csak a fájlt írja. Az az alkalmazás, amely a Vite-on keresztül importálja a JSON-t, HMR-rel kapja meg; ha a szerkesztéseket közvetlenül a futó példányra szeretnéd alkalmazni, használj hidat.

## Híd egy futó példányhoz {#bridge-to-a-live-instance}

Ha a szerkesztőt a saját oldaladba szeretnéd beágyazni, és azt szeretnéd, hogy a szerkesztések azonnal érvényesüljenek a futó példányon, hozz létre egy hidat egy adapterből, és add át az `<i18n-devtools-ui>` elemnek:

```ts
import { createBridge, register } from '@i18n-micro/devtools-ui'
import { i18n, locales } from './i18n' // a runtime, React, Preact or Solid instance

register() // defines <i18n-devtools-ui> once

const bridge = createBridge({
  adapter: {
    getRouteCache: () => Object.fromEntries(i18n.storage.translations),
    addTranslations: (locale, content, merge) => i18n.addTranslations(locale, content, merge),
    addRouteTranslations: (locale, route, content, merge) => i18n.addRouteTranslations(locale, route, content, merge),
    subscribe: (cb) => i18n.subscribe(cb),
    getCurrentLocale: () => i18n.locale,
  },
  locales,
  defaultLocale: 'en',
  translationDir: 'src/locales',
})

const el = document.createElement('i18n-devtools-ui') as HTMLElement & { bridge: typeof bridge }
el.bridge = bridge
document.body.append(el)
```

A `getRouteCache` függvénynek `locale:route` kulcsokkal (`en:index`, `en:blog-post`) kell visszaadnia a szótárakat, ami pontosan az, amit az `i18n.storage.translations` tartalmaz. Vue-példány esetén használd az `i18n.global.getRouteCache()` és az `i18n.global.subscribeToChanges(cb)` hívást.

A `saveTranslation` először a példányt frissíti, majd POST kérést küld a `<base>/save` végpontra. Ha nincs végpont (statikus előnézeti build), vagy a fejlesztői szerver nem érhető el, a szerkesztés a `localStorage`-ban marad meg; bármely más mentési hiba visszaállítja az előző szótárat, és kivételt dob.

## API {#api}

| Export | Belépési pont |
| --- | --- |
| `i18nDevToolsPlugin(options)`, `i18nDevToolsIntegration(options)` | `@i18n-micro/devtools-ui/vite` |
| `register()`, `I18nDevToolsElement` | `@i18n-micro/devtools-ui` |
| `createBridge(options)`, típusok: `BridgeAdapter`, `CreateBridgeOptions` | `@i18n-micro/devtools-ui` (valamint `/bridge/create`) |
| típus: `I18nDevToolsBridge` | `@i18n-micro/devtools-ui` (valamint `/bridge`) |
| `createRpcClient`, `setupRpcHost` | `@i18n-micro/devtools-ui` |

Teljes szignatúrák: [csomagreferencia](/hu/api/packages/devtools-ui).
