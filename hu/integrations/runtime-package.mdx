Az `@i18n-micro/runtime` a keretrendszer-független i18n-példány: szótárak, `t()`, többes számok, `Intl`-formázás és változásfeliratkozás, `fs` és keretrendszer nélkül. Használd egyszerű TypeScriptben, web workerben, edge függvényben, vagy saját kötésed alapjaként. A React, Preact, Node és Astro csomagok ugyanezt az osztályt bővítik ki.

## Telepítés {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/runtime
```

```bash npm
npm install @i18n-micro/runtime
```

```bash yarn
yarn add @i18n-micro/runtime
```

</CodeGroup>

Nincsenek peer függőségei. A lemezen tárolt fordítási fájlokhoz használd az [`@i18n-micro/node`](/hu/integrations/nodejs-package) csomagot.

## Beállítás {#setup}

```ts
import { createI18n } from '@i18n-micro/runtime'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    en: { greeting: 'Hello, {name}!', apples: 'no apples | one apple | {count} apples' },
    de: { greeting: 'Hallo, {name}!' },
  },
  routeMessages: {
    about: { en: { title: 'About us' } },
  },
})
```

Az összes beállítás (`plural`, `missingWarn`, `missingHandler`, `numberFormats`, `datetimeFormats`) megtalálható [a példány](/hu/integrations/overview#the-instance) leírásában.

## Fordítás {#translate}

```ts
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.tc('apples', 5) // '5 apples'
i18n.tn(1234.5) // '1,234.5'

i18n.setRoute('about')
i18n.t('title') // 'About us' (route dictionary)
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!' (root, still visible)
```

További szótárak betöltése később:

```ts
i18n.loadMessages({ fr: { greeting: 'Bonjour, {name} !' } }, { about: { fr: { title: 'À propos' } } })
i18n.addTranslations('fr', { nav: { home: 'Accueil' } }) // deep merge; pass false to replace

await i18n.loadFromUrl('/locales/fr.json', { locale: 'fr' })
await i18n.loadFromUrl('/locales/pages/about/fr.json', { locale: 'fr', routeName: 'about' })
await i18n.loadFromUrls([
  { url: '/locales/en.json', locale: 'en' },
  { url: '/locales/de.json', locale: 'de' },
])
```

A `loadFromUrl` a `fetch`-et használja (fejlécekhez add át az `init` értéket), és nem OK válasz esetén hibát dob. A `loadFromUrls` egymás után tölti be őket.

## Locale váltása {#switch-locale}

```ts
i18n.locale = 'de'
i18n.t('greeting', { name: 'Ada' }) // 'Hallo, Ada!'
```

A locale, az útvonal és a szótár változásai értesítik a feliratkozókat; a keretrendszer-kötések így renderelnek újra:

```ts
const stop = i18n.subscribe(() => {
  document.querySelector('#greeting')!.textContent = i18n.t('greeting', { name: 'Ada' }) as string
})
i18n.locale = 'fr'
stop()
```

A `getSnapshot()` egy olyan karakterláncot ad vissza, amely minden értesítéskor megváltozik (`useSyncExternalStore`-stílusú store-okhoz).

## Kérésenként {#per-request}

A példány egy locale-t és egy útvonalat tárol. Szerveren ne válts egy megosztott példányt kérésenként: két párhuzamos kérés látná egymás locale-ját. Az `i18n.fork(locale)` saját példányt ad a kérésnek: saját locale-lal, tartalék locale-lal és útvonallal; ugyanazokkal a szótárakkal, formázókkal és szabályokkal. A forkolás költsége független a szótárak számától. Egy fork az első saját írásáig látja a szülője írásait, a saját írásai pedig benne maradnak. A [Node.js](/hu/integrations/nodejs-package#per-request) a `run` függvénnyel egészíti ki.

## API {#api}

| Tag | Megjegyzések |
| --- | --- |
| `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has` | lásd: [Fordítás és formázás](/hu/integrations/overview#translate-and-format) |
| `locale`, `fallbackLocale` | lekérdezés/beállítás |
| `currentRoute`, `setRoute(name)`, `getRoute()` | aktív útvonal, alapértelmezés: `'index'` |
| `loadMessages(messages?, routeMessages?)` | sok locale és útvonal egyszerre történő beolvasztása |
| `addTranslations(locale, tree, merge = true)`, `addRouteTranslations(locale, route, tree, merge = true)` | |
| `loadFromUrl(url, { locale?, routeName?, init? })`, `loadFromUrls(entries)` | JSON `fetch` |
| `hasTranslation(key)` | aktív locale, bármely útvonal (ellentétben a `has`-szal, amely az aktív útvonalat és a gyökeret vizsgálja) |
| `setTranslation(key, value)`, `resolveTranslations()` | egy kulcs írása; az összevont fa olvasása |
| `clear()`, `clearCache()` | minden szótár eldobása |
| `subscribe(cb)`, `getSnapshot()` | változásértesítések |
| `storage` | `{ translations: Map<'locale:route', Translations> }` |

Az a kód, amely nem nyelvi címke, a többes számú szabályait a `localeIso: { ua: 'uk-UA' }` beállításból kapja; a `localeIsoMap(locales)` ezt egy locale-lista azon bejegyzéseiből állítja elő, amelyeknek van `iso` értéke.

Modulexportok: `createI18n`, `I18n`, `fetchJsonTranslations`, `FormatService`, `interpolate`, `localeIsoMap`, valamint az `I18nOptions`, `LoadFromUrlOptions`, `LoadFromUrlEntry`, `TranslationStorage`, `Translations`, `Locale`, `PluralFunc` típusok. Teljes szignatúrák: [csomagreferencia](/hu/api/packages/runtime).
