Az `@i18n-micro/vitepress` futásidejű szótárakat ad egy VitePress-webhelyhez: `$t` és `<I18nT>` a markdownon belül, útvonal-segédfüggvények és SEO-címkék, az [`@i18n-micro/vue`](/hu/integrations/vue-package) csomagra építve. Akkor használd, ha ugyanazok a felületi szövegek sok oldalon megjelennek, és nem szeretnéd őket locale-onként megkettőzni. A locale a VitePress saját útvonal-locale-jait követi (`/`, `/fr/`).

## Mikor érdemes használni {#when-to-use-it}

| Igény | Megoldás |
|------|----------|
| Duplikált `.md`, URL-előtagok | VitePress `locales` |
| Futásidejű `$t` / komponensek / útvonal-szinkronizálás / SEO head | `@i18n-micro/vitepress` |
| Az alapértelmezett téma kezelőfelületének feliratai (`docFooter`, keresési felület) | Saját `themeConfig` locale-onként |

<Tip>

**Playground** — [`packages/vitepress/playground`](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/vitepress/playground) — `pnpm -C packages/vitepress/playground dev`

</Tip>

## Telepítés {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vitepress
```

```bash npm
npm install @i18n-micro/vitepress
```

```bash yarn
yarn add @i18n-micro/vitepress
```

</CodeGroup>

Peer függőségek: `vitepress` `>=1.0.0 || >=2.0.0-alpha.0`, `vue` `^3.3.0`. A Node-szkriptek az `@i18n-micro/node` csomagot használják, amely a csomaggal együtt települ, és a `/node` útvonalon keresztül újraexportálódik. A publikált típusokhoz Vue 3.5.5 vagy újabb verzió szükséges `skipLibCheck: false` esetén; `skipLibCheck: true` esetén, ami a szokásos sablonbeállítás, a régebbi verziókkal is lefordul.

## Beállítás {#setup}

```
locales/en.json
locales/fr.json
locales/pages/guide/demo/en.json   # optional page-scoped
locales/pages/guide/demo/fr.json
```

Az oldalfájlok ugyanúgy képeződnek le útvonalnevekre, mint Nuxt/Astro esetén (`guide/demo` → `guide-demo`).

### 1. Konfiguráció — `@i18n-micro/vitepress/config` {#1-config-—-@i18n-micro/vitepress/config}

```ts
// .vitepress/config.mts
import { defineConfig } from 'vitepress'
import { withI18n, buildVitePressLocales } from '@i18n-micro/vitepress/config'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English', og: 'en_US' },
  { code: 'fr', iso: 'fr-FR', displayName: 'Français', og: 'fr_FR' },
]
const defaultLocale = 'en'

export default defineConfig(
  withI18n(
    {
      locales: buildVitePressLocales(locales, defaultLocale),
      // themeConfig.i18nRouting is injected automatically
    },
    {
      locale: defaultLocale,
      defaultLocale,
      locales,
      translationDir: 'locales',
      metaBaseUrl: 'https://example.com', // optional SEO head
    },
  ),
)
```

### 2. Téma — `@i18n-micro/vitepress/theme` {#2-theme-—-@i18n-micro/vitepress/theme}

```ts
// .vitepress/theme/index.ts
import DefaultTheme from 'vitepress/theme'
import { defineI18nTheme } from '@i18n-micro/vitepress/theme'

export default defineI18nTheme(DefaultTheme)
```

A kezdeti locale a telepítés előtt az aktuális útvonalból származik (a `/fr/…` útvonalon nem villan fel az alapértelmezett locale).

### Haladó: manuális `createI18n` {#advanced-manual-createi18n}

Egyetlen gyártófüggvény a klienshez: Vue plugin + útvonalmetódusok + `enhanceApp` (nincsenek külön router-segédexportok).

```ts
import { createI18n, messagesFromGlob } from '@i18n-micro/vitepress'

const i18n = createI18n({
  locale: 'en',
  defaultLocale: 'en',
  locales: [{ code: 'en' }, { code: 'fr' }],
  messages: messagesFromGlob(import.meta.glob('../../locales/*.json', { eager: true })),
})

i18n.localizePath('/guide', 'fr')
// in theme enhanceApp:
i18n.enhanceApp({ app, router })
```

### Node-szkriptek — `@i18n-micro/vitepress/node` {#node-scripts-—-@i18n-micro/vitepress/node}

Az `@i18n-micro/node` `createI18n` / `loadTranslations` függvényeit használja (ugyanúgy, mint az Astro és a CLI), majd a `BaseI18n.extend` segítségével hozzácsatolja a VitePress útvonalmetódusait:

```ts
import { createI18n } from '@i18n-micro/vitepress/node'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  translationDir: './locales',
  locales: ['en', 'fr'],
  defaultLocale: 'en',
})
await i18n.loadTranslations()
i18n.t('cta.readMore')
i18n.localizePath('/guide', 'fr')
```

Egyszerű Node útvonalak nélkül: `import { createI18n } from '@i18n-micro/node'`.

## Oldalon belüli fordítások {#in-page-translations}

Minden VitePress markdownfájl egy Vue SFC.

### Globális komponensek és `$t` (markdownban ajánlott) {#global-components-and-$t-recommended-in-markdown}

A `createI18n` / `defineI18nTheme` telepíti az `@i18n-micro/vue` csomagot, amely regisztrálja az `I18nT` / `I18nLink` / `I18nGroup` / `I18nSwitcher` komponenseket és a `$t` / `$tc` / `$ts` függvényeket.

```md
{{ $t('cta.readMore') }}

<I18nT keypath="greeting" :params="{ name: 'VitePress' }" />

<I18nLink to="/guide/demo">Demo</I18nLink>
```

### `useI18n` a `<script setup>` blokkban {#usei18n-in-<script-setup>}

```md
<script setup>
import { useI18n } from '@i18n-micro/vitepress'
const { t, tc, locale, localePath, switchLocale } = useI18n()
</script>

# {{ t('section.title') }}
```

## Nyelvválasztó legördülő menü {#language-dropdown}

Ha a `locales` egynél több bejegyzést tartalmaz, a VitePress megjeleníti a saját nyelvi menüjét (`VPNavBarTranslations`). A `withI18n` beköti a `themeConfig.i18nRouting` beállítást, így a földgömb ikon összhangban van az `<I18nSwitcher>` komponenssel és az útvonal-segédfüggvényekkel.

Az `<I18nSwitcher>` komponenst csak egyéni layoutokban használd, ne az alapértelmezett földgömb mellett.

## SSR-megjegyzések {#ssr-notes}

- Előrendereléskor a locale az URL útvonalából származik, nem sütikből.
- A témakód nem nyúlhat a `window` objektumhoz importáláskor.
- A `defineI18nTheme` függvényt a `/theme` útvonalról importáld, így a Node-os konfigurációkiértékelés soha nem tölti be a `virtual:i18n-micro/*` modulokat.

## API-felület {#api-surface}

| Export | Szerep |
|--------|------|
| `createI18n` (`.`) | Kliens: Vue plugin + útvonalmetódusok + `enhanceApp` |
| `getLocaleFromPath` / `stripSiteBase` / `routeNameFromPath` (`.`) | Manuális locale-szinkronizálás `syncWithVitePress: false` esetén |
| `createI18n` (`/node`) | Node: `@i18n-micro/node` + útvonalmetódusok |
| `defineI18nTheme` (`/theme`) | Sablonkód nélküli téma |
| `withI18n` (`/config`) | Konfiguráció + virtuális modulok + opcionális SEO |
| `buildVitePressLocales` (`/config`) | A VitePress `locales` felépítése `Locale[]` alapján |
| `buildVitePressLocaleHead` (`/config`) | Manuális SEO head (a `metaBaseUrl` is ezt használja) |
| `messagesFromGlob` | Opcionális glob → üzenettérkép a `createI18n` számára |
| `useI18n` / `I18nT` / … | Újraexportálva az `@i18n-micro/vue` csomagból |
| `BaseI18n.extend` (`@i18n-micro/core`) | Egyéni metódusok csatolása bármely i18n-példányhoz |

## OpenAPI-stílusú webhelyek (integrációs rögzítések) {#openapi-style-sites-integration-locks}

Regressziós tesztcsomag: `packages/vitepress/tests/integration-openapi.test.ts` (mély útvonalak, `base=/openapi_docs/`, kikapcsolt szinkronizálás + manuális locale, Node-generátorok, SEO).

| Minta | Teendő |
|---------|---------|
| Mély `/…/{spec}/{op}` oldalak, csak gyökérszintű felületi JSON | Inkább az alapértelmezett `syncWithVitePress: true` (megtartja a `setRoute('index')` értéket, ha nincs oldalszótár) **vagy** `syncWithVitePress: false` + `getLocaleFromPath` |
| Soha ne hívd meg a `setRoute(deepName)` függvényt oldalszótárak nélkül | A gyökérszintű felületi kulcsok eltűnnek a `setRoute('index')` hívásig |
| Generátorok / `getTranslation` | `createI18n` a `/node` útvonalról + `await loadTranslations()` + `i18n.t(key)` (állítsd be az `i18n.locale` értéket) |
| Egyéni canonical a `transformPageData` függvényben | Adj át `meta: false` értéket a `withI18n`-nek (kerüld a dupla címkéket) |
| A csomag SEO-ja webhely-bázissal | `metaBaseUrl` + VitePress `base` → az abszolút URL-ek tartalmazzák a bázist |
| Átnevezés a csomag régebbi buildjeiről | `withI18nMicro` → `withI18n`, `createVitePressI18n` → `createI18n`, `loadMessages` → node `createI18n` |
