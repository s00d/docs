---

A sziget a böngészőben fut, ahol a szerver i18n-példánya nem létezik. Az `@i18n-micro/astro` lehetővé teszi, hogy az oldal kiválassza a sziget által igényelt kulcsokat, egyetlen propként átadja őket, a szigetben pedig egy kis keretrendszer-adapteren keresztül olvassa ki őket. A Vue, React, Preact és Svelte szigetekben megkapod a `t`, `tc`, `tn`, `td`, `tdr` és `has` függvényeket, és a HTML-be csak a kiválasztott szövegek kerülnek.

## Beállítás {#setup}

Először állítsd be az [Astro-integrációt és a middleware-t](/hu/integrations/astro-package#setup), majd add hozzá a használt keretrendszer integrációját (`@astrojs/vue`, `@astrojs/react`, `@astrojs/preact`, `@astrojs/svelte`). A szigetadaptereknek peer függőségként szükségük van az adott keretrendszerre: `vue` `^3.3.0`, `react` `^16.8.0 || ^17.0.0 || ^18.0.0 || ^19.0.0`, `preact` `^10.0.0 || ^11.0.0` vagy `svelte` `^4.0.0 || ^5.0.0`.

## Fordítások átadása egy szigetnek {#pass-translations-to-an-island}

```astro
---
// src/pages/index.astro
import { getI18nProps } from '@i18n-micro/astro'
import Counter from '../components/Counter.vue'

const i18n = getI18nProps(Astro, ['counter.title', 'counter.apples'])
---

<Counter client:load i18n={i18n} />
```

A `getI18nProps(Astro, keys?)` a `{ locale, fallbackLocale, currentRoute, translations }` objektumot adja vissza (`I18nClientProps` típus). Add át a sziget által használt kulcsokat: mindegyik a szerveren oldódik fel, a `t()`-hez hasonlóan (útvonal-, gyökér- és tartalék szótárak), és csak a megtalált kulcsok kerülnek a HTML-be. `keys` nélkül minden, amire a `t()` ezen az oldalon választ tud adni, minden szigetbe elküldődik, így 2000 gyökérkulcs szigetenként nagyjából 100 KB; fejlesztői módban 20 KB felett figyelmeztetés jelzi ezt.

A szigetek kizárólag ebből az objektumból fordítanak. A `t` minden át nem adott kulcs esetén magát a kulcsot adja vissza, és a hivatkozott üzenetek nem oldódnak fel.

## Vue {#vue}

Hívd meg a `provideI18n(() => props.i18n)` függvényt a sziget gyökérkomponensében, a `useAstroI18n()` függvényt pedig a gyermekeiben. A Vue `inject` függvénye nem látja az ugyanabban a komponensben biztosított értéket, ezért a hooknak egy gyermekben kell futnia, nem a gyökérben:

```vue
<!-- src/components/Counter.vue -->
<script setup lang="ts">
import { provideI18n } from '@i18n-micro/astro/client/vue'
import type { I18nClientProps } from '@i18n-micro/astro'
import CounterBody from './CounterBody.vue'

const props = defineProps<{ i18n: I18nClientProps }>()
provideI18n(() => props.i18n)
</script>

<template><CounterBody /></template>
```

```vue
<!-- src/components/CounterBody.vue -->
<script setup lang="ts">
import { ref } from 'vue'
import { useAstroI18n } from '@i18n-micro/astro/client/vue'

const { t, tc } = useAstroI18n()
const count = ref(0)
</script>

<template>
  <h3>{{ t('counter.title') }}</h3>
  <button @click="count++">{{ tc('counter.apples', count) }}</button>
</template>
```

## React és Preact {#react-and-preact}

```tsx
// src/components/Counter.tsx
import { useState } from 'react'
import { I18nProvider, useAstroI18n } from '@i18n-micro/astro/client/react'
import type { I18nClientProps } from '@i18n-micro/astro'

function Body() {
  const { t, tc } = useAstroI18n()
  const [count, setCount] = useState(0)
  return <button onClick={() => setCount(count + 1)}>{t('counter.title')}: {tc('counter.apples', count)}</button>
}

export default function Counter({ i18n }: { i18n: I18nClientProps }) {
  return (
    <I18nProvider value={i18n}>
      <Body />
    </I18nProvider>
  )
}
```

Preact esetén az `I18nProvider`-t és a `useAstroI18n`-t a `@i18n-micro/astro/client/preact` csomagból importáld; az API ugyanaz.

## Svelte {#svelte}

```svelte
<!-- src/components/Counter.svelte -->
<script lang="ts">
  import { createI18nStore, useAstroI18n } from '@i18n-micro/astro/client/svelte'
  import type { I18nClientProps } from '@i18n-micro/astro'

  export let i18n: I18nClientProps
  const { t, tc } = useAstroI18n(createI18nStore(i18n))
  let count = 0
</script>

<button on:click={() => count++}>{t('counter.title')}: {tc('counter.apples', count)}</button>
```

A `useAstroI18n(store)` a `store`-t is visszaadja a sablonban történő `$store` olvasásokhoz.

## Megőrzött szigetek {#persisted-islands}

A `transition:persist` attribútummal rendelkező sziget navigáció után új propokat kap. A React, a Preact és a Vue (getter átadása esetén) követi ezeket. Svelte-ben tartsd meg a store-t, és add tovább neki őket: `const store = createI18nStore(i18n)`, `const { t } = useAstroI18n(store)`, majd `$: store.set(i18n)` (runes használatával `$effect(() => store.set(i18n))`).

## API {#api}

| Belépési pont | Exportok |
| --- | --- |
| `@i18n-micro/astro` | `getI18nProps`, `I18nClientProps` típus |
| `@i18n-micro/astro/client/vue` | `provideI18n(props \| () => props)`, `useAstroI18n()` |
| `@i18n-micro/astro/client/react` | `I18nProvider` (`value` prop), `useAstroI18n()` |
| `@i18n-micro/astro/client/preact` | `I18nProvider` (`value` prop), `useAstroI18n()` |
| `@i18n-micro/astro/client/svelte` | `createI18nStore(props)`, `useAstroI18n(store)` |
| `@i18n-micro/astro/client` | a tiszta `translate`, `hasTranslation`, keretrendszer nélkül |

Minden `useAstroI18n` visszaadja a `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`, `setLocale`, `setRoute` függvényeket és a `locale` értéket. Egy szigetnek egyetlen összevont szótára van, így a `has` igaz minden olyan kulcsra, amelyre a `t` választ tud adni, a tartalék locale-ból is; a szerveren a `has` csak az aktív locale-t vizsgálja.
