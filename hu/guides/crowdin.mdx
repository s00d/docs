# 🌐 Crowdin-integrációs útmutató

## 📖 Bevezetés

A Crowdin integrálása a projektedbe leegyszerűsíti a lokalizációs és fordítási folyamatot, könnyebbé téve a fordítások kezelését több nyelven és platformon. Ez az útmutató lépésről lépésre bemutatja, hogyan állítsd be a Crowdint a projektedhez, beleértve a konfigurációt, a forrásfájlok feltöltését és a fordítások letöltését.

## 🔧 Telepítés és beállítás

A Crowdinnal való munkához először telepítened kell a Crowdin CLI-t globálisan a gépedre, és inicializálnod a projektkönyvtáradban.

### 📦 A Crowdin CLI telepítése

Először telepítsd a Crowdin CLI-t globálisan npm-en keresztül:

```bash
npm install -g @crowdin/cli
```

### 🛠 A Crowdin inicializálása a projektben

Inicializáld a Crowdint a projektben az alábbi paranccsal:

```bash
crowdin init
```

Ez a parancs végigvezet a beállítási folyamaton, beleértve a projekt-azonosító, API-token és egyéb konfigurációs adatok megadását.

## 🗂️ Konfigurációs útmutató

### 📄 Crowdin konfigurációs fájl (`crowdin.yml`)

A Crowdin konfigurációs fájl (`crowdin.yml`) meghatározza, hogyan képezzük le a forrásfájlokat, és hova kerüljenek a fordítások. Íme egy példa:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Fő konfigurációs paraméterek

- **`project_id`**: A Crowdin projekt-azonosítód. Ez azonosítja azt a Crowdin-projektet, ahol a fordításokat kezeled.
- **`api_token`**: Az azonosításra használt API-token. Győződj meg róla, hogy megfelelő jogosultsága van a fordítások fel- és letöltéséhez.
- **`base_path`**: A forrásfájlok bázis-könyvtárát adja meg. Ebben a példában a fordítások a `./locales` könyvtárban vannak.
- **`base_url`**: A Crowdin API bázis-URL-je.
- **`preserve_hierarchy`**: Ha `true`, a Crowdin megőrzi a forrásfájlok mappaszerkezetét a projekten belül.

### 📂 Fájlkonfiguráció

A `files` szakasz a forrásfájlokat képezi le azokra az útvonalakra, ahová a fordítások kerülnek. Például:

- **Forrás útvonala**: az eredeti fordítási fájlok helyét adja meg.
- **Fordítás útvonala**: azt adja meg, hova kerüljenek a lefordított fájlok a Crowdinban. A `%two_letters_code%` és hasonló helyőrzőkkel dinamikusan állítható be a nyelvi kód a fájlútvonalakban.

## ⬆️ Forrásfájlok feltöltése a Crowdinba

Miután a Crowdin-konfiguráció készen áll, az alábbi paranccsal töltheted fel a forrásfájlokat:

```bash
crowdin upload sources
```

Ez a parancs feltölti a konfigurációban megadott forrásfájlokat a Crowdinba, elérhetővé téve őket fordításra.

## ⬇️ Fordítások letöltése a Crowdinból

Miután a fordítások elkészültek vagy frissültek a Crowdinban, letöltheted őket a projektbe:

```bash
crowdin download
```

Ez a parancs lekéri a legfrissebb fordításokat a Crowdinból, és a konfigurációs fájlodban megadott útvonalakra menti.

## ⚙️ Legjobb gyakorlatok

### 🔑 Egységes kulcsnevezés

Ügyelj arra, hogy a fordításkulcsok egységesek legyenek minden fájlban, hogy elkerüld a zavart és a duplikációt.

### 🧹 Rendszeres karbantartás

Időnként nézd át és takarítsd ki a nem használt fordításkulcsokat, hogy a fájljaid rendezettek és kezelhetők maradjanak.

### 🛠 Automatizált fel- és letöltés

Építsd be a Crowdin CLI-parancsokat a CI/CD-pipeline-odba, hogy automatizáld a forrásfájlok feltöltését és a fordítások letöltését, így a fordításaid mindig naprakészek maradnak.

Az útmutatót követve zökkenőmentesen integrálhatod a Crowdint a projektedbe, hatékony és rendezett megközelítést biztosítva a nemzetköziesítési munkádhoz.
