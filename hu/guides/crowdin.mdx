# 🌐 Crowdin integrációs útmutató

## 📖 Bevezetés

A Crowdin integrálása a projektedbe egyszerűsíti a honosítási és fordítási folyamatot, megkönnyítve a fordítások kezelését több nyelven és platformon. Ez az útmutató lépésről lépésre bemutatja a Crowdin beállítását a projektedhez, beleértve a konfigurációt, a források feltöltését és a fordítások letöltését.

## 🔧 Telepítés és beállítás

A Crowdin használatának megkezdéséhez telepítened kell a Crowdin CLI-t globálisan a gépeden, és inicializálnod kell a projekted könyvtárában.

### 📦 Crowdin CLI telepítése

Először telepítsd a Crowdin CLI-t globálisan az npm segítségével:

```bash
npm install -g @crowdin/cli
```

### 🛠 A Crowdin inicializálása a projektben

Inicializáld a Crowdin-t a projektben a következő futtatásával:

```bash
crowdin init
```

Ez a parancs végigvezet a beállítási folyamaton, beleértve a projekt ID, API token és egyéb konfigurációs részletek beállítását.

## 🗂️ Konfigurációs útmutató

### 📄 Crowdin konfigurációs fájl (`crowdin.yml`)

A Crowdin konfigurációs fájl (`crowdin.yml`) meghatározza, hogyan képződnek le a forrásfájlok, és hova kerülnek a fordítások. Alább egy példa konfiguráció:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Fő konfigurációs paraméterek

- **`project_id`**: A Crowdin projekt azonosítója. Ez azonosítja a projektet a Crowdin-ban, ahol a fordítások kezelve vannak.
- **`api_token`**: A hitelesítéshez használt API token. Győződj meg róla, hogy ez a token megfelelő jogosultságokkal rendelkezik a fordítások feltöltéséhez és letöltéséhez.
- **`base_path`**: Meghatározza a forrásfájlok alap könyvtárát. Ebben a példában a fordítások a `./locales` könyvtárban vannak tárolva.
- **`base_url`**: A Crowdin API alap URL-je.
- **`preserve_hierarchy`**: Ha `true`-ra állítod, a Crowdin megőrzi a forrásfájlok mappaszerkezetét a projektben.

### 📂 Fájlok konfigurációja

A `files` szakasz leképezi a forrásfájlokat a fordítások tárolási útvonalaira. Például:

- **Forrás útvonal**: Meghatározza az eredeti fordítási fájlok helyét.
- **Fordítási útvonal**: Megadja, hova kerülnek a lefordított fájlok a Crowdin-ban. Az olyan helyőrzők, mint a `%two_letters_code%`, a nyelvi kód dinamikus beállítására szolgálnak a fájl útvonalakban.

## ⬆️ Forrásfájlok feltöltése a Crowdin-ba

Miután a Crowdin konfigurációd be van állítva, feltöltheted a forrásfájlokat a következő parancs használatával:

```bash
crowdin upload sources
```

Ez a parancs feltölti a konfigurációdban megadott összes forrásfájlt a Crowdin-ba, elérhetővé téve őket a fordításhoz.

## ⬇️ Fordítások letöltése a Crowdin-ból

Miután a fordítások elkészültek vagy frissültek a Crowdin-ban, letöltheted őket a projektbe a következő paranccsal:

```bash
crowdin download
```

Ez a parancs letölti a legfrissebb fordításokat a Crowdin-ból, és a konfigurációs fájlban megadott útvonalak szerint menti el őket.

## ⚙️ Legjobb gyakorlatok

### 🔑 Konzisztens kulcselnevezés

Győződj meg róla, hogy a fordítási kulcsok konzisztensek minden fájlban, hogy elkerüld a zavart és a duplikációt.

### 🧹 Rendszeres karbantartás

Rendszeresen tekintsd át és tisztítsd meg a nem használt fordítási kulcsokat, hogy a fájljaid szervezettek és kezelhetők maradjanak.

### 🛠 Automatizáld a feltöltéseket és letöltéseket

Integráld a Crowdin CLI parancsokat a CI/CD pipeline-odba, hogy automatizáld a forrásfájlok feltöltését és a fordítások letöltését, biztosítva, hogy a fordításaid mindig naprakészek legyenek.

Ezen útmutatót követve zökkenőmentesen integrálhatod a Crowdin-t a projektedbe, biztosítva egy hatékony és szervezett megközelítést a nemzetköziesítési erőfeszítéseid kezeléséhez.
