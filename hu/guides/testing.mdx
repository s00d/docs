# 🧪 A `Nuxt I18n Micro` modul tesztelése

## 📖 Bevezetés a teszteléshez

A `Nuxt I18n Micro` modul tesztelése elengedhetetlen ahhoz, hogy az alkalmazásod lokalizációs funkciói az elvárt módon működjenek. Ez a dokumentáció végigvezet a tesztelési környezet felépítésén, a vitest-hez tartozó mock-konfigurációk létrehozásán, és a komponensekhez írt tesztek megírásán. Gyakorlati példáért nézd meg a [példaprojektet a GitHubon](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/test-utils/example).

Az útvonalstratégiák teszteléséhez lásd az [útvonalstratégiák tesztelése](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/testing-strategies.md) dokumentációt, amely bemutatja, hogyan futtatja ez a repository a saját tesztkészleteit — az `unit` / `integration` / `e2e` Vitest-projekteket, a stratégiánkénti fájlokat (`test/strategies-*.test.ts`) és a regressziógenerálást.

## 🛠️ A tesztelési környezet beállítása

### 1. Az `@i18n-micro/test-utils` telepítése

Először telepítened kell a `Nuxt I18n Micro` teszt-segédeit. Ez a csomag biztosítja a szükséges eszközöket az i18n-konfigurációk mockolásához és teszteléséhez.

```bash
npm install @i18n-micro/test-utils --save-dev
```

### 2. Mock-konfigurációs fájl létrehozása

Ezután hozz létre egy fájlt a mock i18n-konfiguráció felállításához. Ez a fájl mockolja az i18n-függvényeket és -segédeket a tesztek során.

```typescript
// tests/unit-setup.ts

import { mockNuxtImport } from '@nuxt/test-utils/runtime'
import { vi } from 'vitest'
import { i18nUtils } from '@i18n-micro/test-utils'

export function createFakeI18n() {
  return {
    $getLocale: vi.fn(i18nUtils.getLocale),
    $t: vi.fn(i18nUtils.t),
    $tc: vi.fn(i18nUtils.tc),
    $setLocale: vi.fn(i18nUtils.setLocale),
    $getLocaleName: vi.fn(i18nUtils.getLocaleName),
    $setLocaleName: vi.fn(i18nUtils.setLocaleName),
    $getLocales: vi.fn(i18nUtils.getLocales),
    $setLocales: vi.fn(i18nUtils.setLocales),
    $defaultLocale: vi.fn(i18nUtils.defaultLocale),
    $setDefaultLocale: vi.fn(i18nUtils.setDefaultLocale),
    $getRouteName: vi.fn(i18nUtils.getRouteName),
    $settRouteName: vi.fn(i18nUtils.settRouteName),
    $ts: vi.fn(i18nUtils.ts),
    $tn: vi.fn(i18nUtils.tn),
    $td: vi.fn(i18nUtils.td),
    $has: vi.fn(i18nUtils.has),
    $resolveTranslations: vi.fn(i18nUtils.resolveTranslations),
    $setTranslation: vi.fn(i18nUtils.setTranslation),
    $mergeTranslations: vi.fn(i18nUtils.mergeTranslations),
    $switchLocaleRoute: vi.fn(i18nUtils.switchLocaleRoute),
    $switchLocalePath: vi.fn(i18nUtils.switchLocalePath),
    $switchLocale: vi.fn(i18nUtils.switchLocale),
    $switchRoute: vi.fn(i18nUtils.switchRoute),
    $localeRoute: vi.fn(i18nUtils.localeRoute),
    $localePath: vi.fn(i18nUtils.localePath),
    $setI18nRouteParams: vi.fn(i18nUtils.setI18nRouteParams),
  }
}

mockNuxtImport<() => ReturnType<typeof createFakeI18n>>('useI18n', () => vi.fn(() => createFakeI18n()))

export const setTranslationsFromJson = i18nUtils.setTranslationsFromJson
```

### 3. Vitest konfigurálása

Most konfiguráld a Vitestet, hogy a mock-konfigurációs fájlt használja, és állítsd fel a tesztkörnyezetet.

```typescript
// vitest.config.ts

import { defineVitestConfig } from '@nuxt/test-utils/config'

export default defineVitestConfig({
  test: {
    watch: false,
    setupFiles: ['./tests/unit-setup.ts'],
    include: ['./**/*.spec.ts'],
  },
})
```

## 🧪 Tesztek írása

### Példa komponens

Íme egy egyszerű komponens, amely a `useI18n` composable-t használja az üzenetek fordítására.

```vue
<script setup lang="ts">
const { $t } = useI18n()

const props = defineProps({
  message: {
    type: String,
    default: null,
  },
})

// Test to see that $t works in script setup as well as the template
const message = props.message || $t('defaultMessage')
</script>

<template>
  <div>
    <p>Test from component: {{ $t('welcome') }}</p>
    <p data-testid="message">Test message from props: {{ message }}</p>
  </div>
</template>
```

### Tesztfájl

Most írjunk tesztet ehhez a komponenshez.

```typescript
// tests/unit/example.spec.ts

import { describe, it, expect, beforeEach } from 'vitest'
import { mount } from '@vue/test-utils'
import ExampleComponent from '@/components/ExampleComponent.vue'
import fs from 'fs'
import path from 'path'
import { setTranslationsFromJson } from './unit-setup'

describe('ExampleComponent', () => {
  beforeEach(async () => {
    const fileContent = fs.readFileSync(path.join(__dirname, '../../locales/en-GB.json')).toString()
    await setTranslationsFromJson('en', JSON.parse(fileContent))
  })

  it('renders the welcome message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.text()).toContain('Test from component: Welcome')
  })

  it('renders the default message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Default Message')
  })

  it('renders the custom message correctly', () => {
    const wrapper = mount(ExampleComponent, {
      props: {
        message: 'Custom Message',
      },
    })
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Custom Message')
  })
})
```

## 📝 Legjobb gyakorlatok a teszteléshez

- **🔧 i18n-függvények mockolása:** Mindig mockold az i18n-függvényeket az `@i18n-micro/test-utils`-tal, hogy konzisztens és kiszámítható tesztetjenek legyenek.
- **⚙️ Vitest egységtesztekhez:** A Vitest egy erős tesztelési keretrendszer Vue-alkalmazásokhoz. Használd egységtesztek írására a komponensekhez.
- **📚 Dokumentáld a tesztjeidet:** Világosan dokumentáld minden teszt célját és várt eredményét. Ez fenntartja az áttekinthetőséget, és megkönnyíti mások (vagy jövőbeli önmagad) számára, hogy megértsék a teszteket.

## 📊 i18n segédmetódusok

Az alábbi táblázat bemutatja az `@i18n-micro/test-utils` által biztosított összes segédmetódust.

| Metódus                                         | Leírás                                                                                                                                     |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `t(key, params, defaultValue)`                  | Fordít egy kulcsot opcionális paraméterekkel és alapértékkel.                                                                              |
| `tc(key, params, defaultValue)`                 | Fordít egy kulcsot többesszám-támogatással.                                                                                                |
| `setTranslationsFromJson(locale, translations)` | Fordításokat tölt be JSON-objektumból egy adott területhez.                                                                                |
| `getLocale()`                                   | Visszaadja az aktuális területet.                                                                                                          |
| `setLocale(val)`                                | Beállítja az aktuális területet.                                                                                                           |
| `getLocaleName()`                               | Visszaadja az aktuális terület nevét.                                                                                                      |
| `setLocaleName(val)`                            | Beállítja az aktuális terület nevét.                                                                                                       |
| `getLocales()`                                  | Visszaadja az elérhető területek listáját.                                                                                                 |
| `setLocales(val)`                               | Beállítja az elérhető területek listáját.                                                                                                  |
| `defaultLocale()`                               | Visszaadja az alapértelmezett területet.                                                                                                   |
| `setDefaultLocale(val)`                         | Beállítja az alapértelmezett területet.                                                                                                    |
| `getRouteName()`                                | Visszaadja az aktuális útvonal nevét.                                                                                                      |
| `settRouteName(val)`                            | Beállítja az aktuális útvonal nevét.                                                                                                       |
| `ts(key, params, defaultValue)`                 | Fordít egy kulcsot, és az eredményt sztringként adja vissza.                                                                               |
| `tn(value, options?)`                           | Számot formáz inline `Intl.NumberFormatOptions`-szal. Az elnevezett formátumok modulkonfigurációt igényelnek, itt nem érhetők el.          |
| `td(value, options?)`                           | Dátumot formáz inline `Intl.DateTimeFormatOptions`-szal. Az elnevezett formátumok modulkonfigurációt igényelnek, itt nem érhetők el.       |
| `has(key)`                                      | Ellenőrzi, hogy létezik-e egy fordításkulcs.                                                                                               |
| `resolveTranslations()`                         | Visszaadja az aktuális terület és útvonal aktív fordítási fáját.                                                                           |
| `setTranslation(key, value)`                    | Lecseréli a `key` helyén lévő értéket az aktív szótárban (csere, nem egyesítés).                                                           |
| `mergeTranslations(newTranslations)`            | Fordításokat olvaszt be az aktív területbe futásidőben.                                                                                    |

Ezekkel a lépésekkel hatékonyan tesztelheted a `Nuxt I18n Micro` modult, és biztosíthatod, hogy az alkalmazásod lokalizációs funkciói az elvárt módon működjenek.
