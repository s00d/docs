# Statikus fájlok kizárása az i18n-útvonalkezelésből

## Áttekintés

Alapértelmezés szerint a `nuxt-i18n-micro` automatikusan kizárja a gyakori statikus fájlokat az i18n-útvonalkezelési feldolgozásból. Emellett saját kizárási mintákat is konfigurálhatsz, hogy megakadályozd, hogy bizonyos útvonalakat az i18n-rendszer feldolgozzon.

## Beépített kizárások

A modul automatikusan kizárja az alábbi fájltípusokat és mintákat:

- **Sitemap-fájlok**: `/sitemap*.xml`, `/sitemap-en.xml` stb.
- **SEO-fájlok**: `/robots.txt`, `/favicon.ico`
- **PWA-fájlok**: `/manifest.json`, `/sw.js`, `/workbox-*.js`
- **Statikus assetek**: olyan kiterjesztésű fájlok, mint `.xml`, `.txt`, `.ico`, `.json`, `.js`, `.css`, `.png`, `.jpg`, `.jpeg`, `.gif`, `.svg`, `.woff`, `.woff2`, `.ttf`, `.eot`
- **Belső Nuxt-útvonalak**: bármely `__`-kal kezdődő útvonal (mint a `/__nuxt/`)

## Egyedi kizárási minták

Saját kizárási mintákat az `excludePatterns` opcióval adhatsz meg:

```typescript
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],

  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'it', iso: 'it-IT' },
    ],
    defaultLocale: 'en',

    // Custom exclusion patterns
    excludePatterns: [
      // String patterns (exact match or prefix)
      '/api/health',
      '/admin',

      // String patterns with wildcards
      '/api/*',
      '/admin/**',

      // Regular expressions
      /^\/api\/v\d+\//,
      /\.(pdf|doc|docx)$/,
    ],
  },
})
```

## Mintatípusok

### Sztringminták

- **Pontos egyezés**: `'/api/health'` — pontosan a `/api/health`-re illik
- **Előtag-egyezés**: `'/admin'` — illik a `/admin`-ra és a `/admin/dashboard`-ra
- **Helyettesítő karakterek**: `'/api/*'` — illik a `/api/users`-re, de a `/api/users/123`-ra nem
- **Mély helyettesítők**: `'/admin/**'` — illik a `/admin/users`-re és a `/admin/users/123`-ra

### Reguláris kifejezések

Használj RegExp-objektumokat összetett minták illesztésére:

```typescript
excludePatterns: [
  /^\/api\/v\d+\//, // API versioned routes
  /\.(pdf|doc|docx)$/, // Document files
  /^\/static\//, // Static directory
  /^\/[a-z]{2}\/api\//, // Localized API routes
]
```

## Felhasználási esetek

### SEO-fájlok

```typescript
excludePatterns: ['/sitemap.xml', '/sitemap-*.xml', '/robots.txt', '/favicon.ico']
```

### API-útvonalak

```typescript
excludePatterns: ['/api/**', '/graphql', '/webhook/**']
```

### Adminpanelek

```typescript
excludePatterns: ['/admin', '/admin/**', '/dashboard']
```

### Statikus assetek

```typescript
excludePatterns: ['/assets/**', '/static/**', '/uploads/**']
```

## Hogyan működik

1. **Szerver middleware**: elsőként egy Nitro middleware fut a kizárási minták ellenőrzésére
2. **Oldalfeldolgozás**: az oldalfeloldás során a kizárt útvonalakat kihagyjuk
3. **Catch-all útvonal**: a tartalék útvonal ellenőrzi a kizárásokat feldolgozás előtt
4. **Előrenderelés**: a kizárt útvonalak nem kerülnek bele az előrendelt útvonalakba

## Teljesítménybeli hatás

- A kizárás-ellenőrzések optimalizáltak és a kérés életciklusának korai szakaszában futnak
- A beépített minták hatékony regex-illesztést használnak
- Az egyedi minták gyorsítótárazódnak és újrahasználódnak
- A kizárt útvonalak minimális teljesítmény-többletköltséggel járnak

## Hibaelhárítás

### A statikus fájlokat továbbra is elfogja a modul

1. **Ellenőrizd a minta szintaxisát**: győződj meg róla, hogy a mintáid pontosan illeszkednek az útvonalszerkezetre
2. **Használj regexet összetett mintákhoz**: a sztring-helyettesítőknek vannak korlátaik
3. **Teszteld a mintákat**: böngésző-fejlesztőeszközökkel ellenőrizd a tényleges kérési útvonalat
4. **Ügyelj a sorrendre**: a kizárási minták az egyéb i18n-konfig előtt legyenek definiálva

### A minta nem működik

```typescript
// ❌ Wrong - this won't work
excludePatterns: ['sitemap.xml']

// ✅ Correct - include leading slash
excludePatterns: ['/sitemap.xml']

// ✅ Better - use regex for flexibility
excludePatterns: [/^\/sitemap.*\.xml$/]
```

### Hibakeresési mód

Engedélyezd a debug módot, hogy lásd a kizárási feldolgozást:

```typescript
i18n: {
  debug: true,
  excludePatterns: ['/api/**']
}
```

Ez naplózza a kizárási döntéseket a konzolra.

## Migráció megkerülő megoldásokról

Ha eddig megkerülő megoldásokat használtál — például route rule-okat vagy middleware-t —, most lecserélheted őket `excludePatterns`-re:

```typescript
// ❌ Old workaround
export default defineNuxtConfig({
  routeRules: {
    '/sitemap*.xml': { headers: { 'content-type': 'application/xml' } },
  },
})

// ✅ New approach
export default defineNuxtConfig({
  i18n: {
    excludePatterns: ['/sitemap*.xml'],
  },
})
```

Az új megközelítés megbízhatóbb, és az útvonalkezelő rendszer több szintjén is működik.
