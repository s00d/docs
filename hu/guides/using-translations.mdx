# Fordítások használata komponensekben

Miután a modul telepítve és konfigurálva van, fordításokat úgy jeleníthetsz meg, hogy a Vue-sablonokban és -szkriptekben meghívod a `$t('your_key')`-et.

## 1. Gyökérszintű és oldalspecifikus fordítási fájlok

1. A **gyökérszintű** fordítások közvetlenül a `/locales` mappában találhatók (pl. `/locales/en.json`, `/locales/fr.json`). Build-időben automatikusan minden oldalspecifikus fájlba beolvadnak, így minden oldalon elérhetők.
2. Az **oldalspecifikus** fordítások a `/locales/pages/...` alatt élnek, a Nuxt-oldalaid mappaszerkezetét követve:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. Sablonhasználat a `$t`-vel

A `.vue` fájljaidban közvetlenül használhatod a `$t`-t a sablonban:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
A `$t` **objektumokat** is visszaadhat, ha a kulcs egy beágyazott JSON-csomópontra mutat (pl. `$t('header')` → `\{ title: "Hi" \}`). Sablonokban ez `[object Object]`-ként jelenik meg. Használd a `$ts`-t, ha biztosan sztringre van szükséged, vagy adj meg konkrétabb kulcsot, például `$t('header.title')`. Részletekért lásd az [API-referencia — $t vs $ts](/api/methods#t) részt.
</Tip>

## 3. Az aktuális terület váltása

A nyelvek váltásához az alkalmazásodban a `useI18n()`-ből lekérheted a `$locale`-t, és új kódot rendelhetsz hozzá:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. Egymásba ágyazott kulcsok és helyőrzők

- **Egymásba ágyazott kulcsok** pontjelöléssel: pl. `nested.key.deeper`.
- **Helyőrzők** dinamikus értékek beszúrását teszik lehetővé:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. Tippek és legjobb gyakorlatok

- **Ütköző kulcsok**: Ha egy oldalspecifikus fájl ugyanazt a kulcsot tartalmazza, mint egy gyökérszintű fájl, az oldalspecifikus változat elsőbbséget élvez (a gyökérfordítások build-időben alapul olvadnak be).
- **Oldalfájlok kikapcsolása**: Ha inkább nem használnál oldalspecifikus fordításokat, a Nuxt-konfigban beállíthatod a `disablePageLocales: true` értéket. Így csak a `/locales/*.json` fájlok kerülnek felhasználásra.
- **Nincs közvetlen import**: nem kell `import \{ useI18n \} from 'nuxt-i18n-micro'`-t írnod; ezt a modul automatikus injektálása elintézi.

Ennyi! Ezekkel a lépésekkel gyorsan **lekérheted a fordításokat** a gyökér- vagy oldalspecifikus JSON-fájlokból, és **megjelenítheted őket** a Nuxt-alkalmazásodban a `$t` segítségével.

## További források

Haladóbb funkciók megismeréséhez érdemes megnézni:

1. **`<i18n-t>` komponens**  
   Az `<i18n-t>` komponens erős alternatíva a `$t`-hez, különösen hasznos egymásba ágyazott elemeknél, haladó helyőrző-használatnál és összetettebb fordítási szerkezeteknél.

- **Dokumentáció**: [i18n-t](/api/components/i18n-t)

2. **`useI18n` composable**  
   A `useI18n` composable teljes függvény- és reaktív tulajdonságkészletet kínál a fordítások kezeléséhez, területváltáshoz, formázáshoz és további feladatokhoz.

- **Dokumentáció**: [useI18n](/api/composables/use-i18n)
