# Fordítások használata a komponensekben

Miután a modul telepítve és konfigurálva van, megjelenítheted a fordításokat a `$t('your_key')` hívásával a Vue sablonokban és szkriptekben.

## 1. Gyökérszintű és oldalspecifikus fordítási fájlok

1. A **gyökérszintű** fordítások közvetlenül a `/locales` mappa alatt találhatók (pl. `/locales/en.json`, `/locales/fr.json`). Build időben automatikusan beolvadnak minden oldalspecifikus fájlba, elérhetővé téve őket minden oldalon.
2. Az **oldalspecifikus** fordítások a `/locales/pages/...` alatt élnek, illeszkedve a Nuxt oldalak mappaszerkezetéhez:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. Sablon használat a `$t`-vel

A `.vue` fájljaidban közvetlenül használhatod a `$t`-t a sablonban:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
A `$t` **objektumokat** adhat vissza, ha a kulcs egy beágyazott JSON csomópontra mutat (pl. `$t('header')` → `\{ title: "Hi" \}`). A sablonokban ez `[object Object]`-ként renderelődik. Használd a `$ts`-t, ha garantált karakterláncra van szükséged, vagy adj meg konkrétabb kulcsot, például `$t('header.title')`. Nézd meg az [API referencia — $t vs $ts](/api/methods#t) oldalt a részletekért.
</Tip>

## 3. Az aktuális területi beállítás váltása

Ahhoz, hogy nyelvet válts az alkalmazásodban, lekérheted a `$locale`-t a `useI18n()`-ből, és hozzárendelhetsz egy új kódot:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. Beágyazott kulcsok és helyőrzők

- A **beágyazott kulcsok** pontjelölést használnak, pl. `nested.key.deeper`.
- A **helyőrzők** lehetővé teszik dinamikus értékek beszúrását:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. Tippek és legjobb gyakorlatok

- **Ütköző kulcsok**: Ha egy oldalspecifikus fájl ugyanazt a kulcsot tartalmazza, mint egy gyökérszintű fájl, az oldalspecifikus verzió elsőbbséget élvez (a gyökér fordítások alapként olvadnak be build időben).
- **Oldal fájlok letiltása**: Ha inkább nem használnál oldalspecifikus fordításokat, beállíthatod a `disablePageLocales: true` értéket a Nuxt konfigurációdban. Így csak a `/locales/*.json` fájlok kerülnek felhasználásra.
- **Nincs közvetlen import**: Nem kell `import \{ useI18n \} from 'nuxt-i18n-micro'`-t írnod. A modul automatikus injektálási funkciója ezt elvégzi helyetted.

Ennyi! Ezekkel a lépésekkel gyorsan **elkezdheted a fordítások lekérését** gyökérszintű vagy oldalspecifikus JSON fájlokból, és **megjelenítheted őket** a Nuxt alkalmazásodban a `$t` segítségével.

## További források

További haladó funkciók megismeréséhez feltétlenül nézd meg:

1. **`<i18n-t>` komponens**  
   Az `<i18n-t>` komponens erőteljes alternatívája a `$t`-nek, különösen hasznos beágyazott elemeket, haladó helyőrző használatot és összetettebb fordítási szerkezeteket tartalmazó helyzetekben.

- **Dokumentáció**: [i18n-t](/api/components/i18n-t)

2. **`useI18n` composable**  
   A `useI18n` composable teljes függvénykészletet és reaktív tulajdonságokat biztosít a fordítások kezeléséhez, területi váltás kezeléshez, formázáshoz és többhez.

- **Dokumentáció**: [useI18n](/api/composables/use-i18n)
