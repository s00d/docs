---
title: "Csomag-API-k"
description: "Minden @i18n-micro/* csomag exportált API-ja, azokból az API-pillanatképekből generálva, amelyeket a CI összevet a forráskóddal."
---

A Nuxt modul kis `@i18n-micro/*` csomagokból épül fel, és ezek többsége önállóan is működik: az `@i18n-micro/vue` egy Vue alkalmazásban, az `@i18n-micro/core` bárhol. Ezeken az oldalakon belépési pontonként nézheted meg, mit exportál egy csomag. Minden oldal abból a pillanatképből generálódik, amelyet a [`pnpm run api:surface`](https://s00d.github.io/nuxt-i18n-micro/contributing/maintenance-commands#api-surface) összevet a TypeScript-forrásokkal, így egy export sem változhat meg anélkül, hogy a CI észrevenné.
