A [CLI útmutató](/hu/guide/cli) a gyakori munkafolyamatokat mutatja be. Ez az oldal mindent felsorol, és ugyanabból a táblából készül, amely a `--help` kimenetét is adja.

## Közös kapcsolók {#common-flags}

| Kapcsoló | Alapértelmezés | Leírás |
| --- | --- | --- |
| `--cwd` | aktuális könyvtár | Projektkönyvtár |
| `--logLevel` | `info` | Kimeneti szint: silent, info |
| `--debug` | `false` | Veremkivonat kiírása, ha egy parancs sikertelen |

## Vizsgálat {#inspect}

### `info` {#info}

A projekt feloldott i18n-konfigurációjának kiírása

| Kapcsoló | Alapértelmezés | Leírás |
| --- | --- | --- |
| `--json` | `false` | JSON kiírása szöveg helyett |

### `check` {#check}

A CI-kapu: hibát jelez hiányzó, üres, felesleges, nem definiált vagy nem használt kulcsok és hibás helyőrzők esetén

| Kapcsoló | Alapértelmezés | Leírás |
| --- | --- | --- |
| `--translationDir` | a nuxt.config `i18n.translationDir` értéke | Fordítási könyvtár, a projekthez viszonyítva |
| `--only` | mind, kivéve a duplicates | Futtatandó ellenőrzések vesszővel elválasztva: missing, empty, extra, placeholders, undefined, unused, duplicates. Az itt megnevezett `unused` hibát jelez, ha nem tud lefutni |
| `--duplicates` | `false` | Az eltérő kulcsok alatti azonos szövegek jelentése is |
| `--ignore` | — | Kihagyandó forrásfájlok globmintái vesszővel elválasztva, a projekthez viszonyítva |
| `--json` | `false` | JSON kiírása szöveg helyett |

```bash
i18n-micro check
i18n-micro check --only missing,placeholders --json
```

### `stats` {#stats}

A fordítások készültségi szintjének megjelenítése locale-onként

| Kapcsoló | Alapértelmezés | Leírás |
| --- | --- | --- |
| `--translationDir` | a nuxt.config `i18n.translationDir` értéke | Fordítási könyvtár, a projekthez viszonyítva |
| `--html` | — | HTML-jelentés írása is ebbe a fájlba |
| `--json` | `false` | JSON kiírása szöveg helyett |
| `--baseRef` | — | Git ref, amellyel a készültséget összeveti, pl. HEAD~1 vagy main |

```bash
i18n-micro stats --baseRef main
i18n-micro stats --html reports/i18n.html
```

### `lint` {#lint}

A fordítások szövegének ellenőrzése; hibát jelez, ha problémák maradnak

| Kapcsoló | Alapértelmezés | Leírás |
| --- | --- | --- |
| `--translationDir` | a nuxt.config `i18n.translationDir` értéke | Fordítási könyvtár, a projekthez viszonyítva |
| `--rules` | mind, vagy a .i18n-lintrc.json `enabledRules` értéke | Futtatandó szabályok vesszővel elválasztva: no-trailing-spaces, no-multiple-spaces, no-empty-translation, vagy egy egyéni szabály |
| `--fix` | `false` | A javítható hibák javítása: szóközök, valamint a cserével rendelkező egyéni szabályok |
| `--json` | `false` | JSON kiírása szöveg helyett |

```bash
i18n-micro lint --rules no-trailing-spaces --fix
```

### `search` {#search}

Kulcsok és értékek keresése, és annak megjelenítése, hol használják az egyes kulcsokat

| Kapcsoló | Alapértelmezés | Leírás |
| --- | --- | --- |
| `--translationDir` | a nuxt.config `i18n.translationDir` értéke | Fordítási könyvtár, a projekthez viszonyítva |
| `<query>` | — | A keresendő szöveg vagy kulcs |
| `--caseSensitive` | `false` | Kis- és nagybetűk megkülönböztetése |
| `--onlyUnused` | `false` | Csak azok a kulcsok, amelyeket a `clean` eltávolítana; a lekérdezés ilyenkor elhagyható |
| `--scope` | `all` | Hol keressen: global, pages, all |
| `--limit` | — | Legfeljebb ennyi kulcs visszaadása |
| `--ignore` | — | Kihagyandó forrásfájlok globmintái vesszővel elválasztva, a projekthez viszonyítva |
| `--json` | `false` | JSON kiírása szöveg helyett |

```bash
i18n-micro search "Welcome"
i18n-micro search --onlyUnused
```

## Fordítási munkafolyamat {#translation-workflow}

### `extract` {#extract}

Felsorolja a forrásfájlok által használt, még szöveg nélküli kulcsokat, és alapértelmezett szöveggel felveszi őket az alapértelmezett locale-ba

| Kapcsoló | Alapértelmezés | Leírás |
| --- | --- | --- |
| `--translationDir` | a nuxt.config `i18n.translationDir` értéke | Fordítási könyvtár, a projekthez viszonyítva |
| `--ignore` | — | Kihagyandó forrásfájlok globmintái vesszővel elválasztva, a projekthez viszonyítva |

```bash
i18n-micro extract
```

### `translate` {#translate}

A hiányzó fordítások kitöltése az alapértelmezett locale-ból egy fordítószolgáltatás segítségével

| Kapcsoló | Alapértelmezés | Leírás |
| --- | --- | --- |
| `--translationDir` | a nuxt.config `i18n.translationDir` értéke | Fordítási könyvtár, a projekthez viszonyítva |
| `--service` | — | Fordítószolgáltatás: ai, azure, deepl, google, libretranslate, yandexcloud |
| `--token` | — | API-kulcs. Inkább az I18N_TRANSLATE_TOKEN környezeti változót használd: a kapcsolók bekerülnek a shell előzményeibe |
| `--options` | — | Szolgáltatásbeállítások kulcs:érték párokként, vesszővel elválasztva |
| `--locale` | minden locale az alapértelmezett kivételével | Kitöltendő locale-ok vesszővel elválasztva |
| `--replace` | `false` | Minden kulcs újrafordítása, a meglévő értékek felülírásával |
| `--dryRun` | `false` | Kulcsok és karakterek megszámolása locale-onként; semmit nem küld el |
| `--chunkSize` | — | Karakterláncok száma kérésenként; a szolgáltatás által elfogadott értékre korlátozva |
| `--pluralSeparator` | `\|` | A többes számú alakok elválasztója az üzenetekben |
| `--glossaryFile` | `.i18n-glossary.json`, ha létezik | Szójegyzékfájl, az `ai` szolgáltatás használja |

```bash
i18n-micro translate --dryRun
I18N_TRANSLATE_TOKEN=... i18n-micro translate --service deepl --locale de,fr
i18n-micro translate --service ai --options provider:openai,model:gpt-4o-mini
i18n-micro translate --service libretranslate --options baseUrl:https://translate.example.com
```

### `sync` {#sync}

Eltávolítja azokat a kulcsokat, amelyek az alapértelmezett locale-ban nincsenek meg; leáll, ha ez nem bizonyítható biztonságosnak. A hiányzó kulcsok hiányoznak továbbra is

| Kapcsoló | Alapértelmezés | Leírás |
| --- | --- | --- |
| `--translationDir` | a nuxt.config `i18n.translationDir` értéke | Fordítási könyvtár, a projekthez viszonyítva |
| `--ignore` | — | Kihagyandó forrásfájlok globmintái vesszővel elválasztva, a projekthez viszonyítva |
| `--dryRun` | `false` | Felsorolja, mi kerülne eltávolításra; semmit nem ír |
| `--force` | `false` | A kulcsok eltávolítása akkor is, ha ez nem bizonyítható biztonságosnak |

```bash
i18n-micro sync --dryRun
```

### `clean` {#clean}

Eltávolítja azokat a kulcsokat, amelyeket a projektben semmi sem használ; leáll, ha ez nem bizonyítható

| Kapcsoló | Alapértelmezés | Leírás |
| --- | --- | --- |
| `--translationDir` | a nuxt.config `i18n.translationDir` értéke | Fordítási könyvtár, a projekthez viszonyítva |
| `--include` | — | Reguláris kifejezés: csak az illeszkedő kulcsok jöhetnek szóba eltávolításra |
| `--exclude` | — | Reguláris kifejezés: az illeszkedő kulcsokat soha nem távolítja el |
| `--ignore` | — | Kihagyandó forrásfájlok globmintái vesszővel elválasztva, a projekthez viszonyítva |
| `--dryRun` | `false` | Felsorolja, mi kerülne eltávolításra; semmit nem ír |
| `--force` | `false` | A kulcsok eltávolítása akkor is, ha nem mindegyik használata bizonyítható |

```bash
i18n-micro clean --dryRun
i18n-micro clean --exclude '^errors\.'
```

## Refaktorálás {#refactoring}

### `text-to-i18n` {#text-to-i18n}

A Vue-sablonokban beégetett szövegek cseréje fordítási hívásokra, valamint a kódban beégetett szövegek jelentése

| Kapcsoló | Alapértelmezés | Leírás |
| --- | --- | --- |
| `--translationFile` | `<translationDir>/<defaultLocale>.json` | A fájl, amelybe az új kulcsok kerülnek |
| `--path` | a teljes projekt | Feldolgozandó fájl vagy könyvtár |
| `--context` | — | Előtag a generált kulcsokhoz |
| `--ignore` | — | Kihagyandó forrásfájlok globmintái vesszővel elválasztva, a projekthez viszonyítva |
| `--dryRun` | `false` | Megmutatja, mi változna; semmit nem ír |
| `--interactive` | `false` | Minden generált kulcs megerősítése vagy szerkesztése |

```bash
i18n-micro text-to-i18n --dryRun
i18n-micro text-to-i18n --path components --context ui
```

### `rename` {#rename}

Egy kulcs vagy névtér átnevezése minden locale-ban és a forrásfájlokban

| Kapcsoló | Alapértelmezés | Leírás |
| --- | --- | --- |
| `--translationDir` | a nuxt.config `i18n.translationDir` értéke | Fordítási könyvtár, a projekthez viszonyítva |
| `--from` **\*** | — | Jelenlegi kulcs vagy névtér |
| `--to` **\*** | — | Új kulcs vagy névtér |
| `--ignore` | — | Kihagyandó forrásfájlok globmintái vesszővel elválasztva, a projekthez viszonyítva |
| `--dryRun` | `false` | A változások jelentése; semmit nem ír |

**\*** kötelező.

```bash
i18n-micro rename --from common.save --to actions.save
```

### `pseudo` {#pseudo}

Egy locale kitöltése álfordításokkal az elrendezési és beégetett szöveggel kapcsolatos problémák felderítésére

| Kapcsoló | Alapértelmezés | Leírás |
| --- | --- | --- |
| `--translationDir` | a nuxt.config `i18n.translationDir` értéke | Fordítási könyvtár, a projekthez viszonyítva |
| `--sourceLocale` | az alapértelmezett locale | Beolvasandó locale |
| `--targetLocale` **\*** | — | Kitöltendő locale |
| `--replace` | `false` | A meglévő értékek felülírása |

**\*** kötelező.

### `format` {#format}

A locale-fájlok újraírása rendezett kulcsokkal és egységes behúzással

| Kapcsoló | Alapértelmezés | Leírás |
| --- | --- | --- |
| `--translationDir` | a nuxt.config `i18n.translationDir` értéke | Fordítási könyvtár, a projekthez viszonyítva |
| `--indent` | `2` | A behúzás szóközeinek száma |
| `--sortKeys` | `true` | Kulcsok rendezése; a --no-sortKeys megtartja a sorrendjüket |
| `--check` | `false` | Hibát jelez, ha egy fájl megváltozna; semmit nem ír |

```bash
i18n-micro format --check
```

## Csere {#exchange}

### `export` {#export}

A locale-fájlok exportálása PO vagy CSV formátumba, az alapértelmezett locale szövegével mint forrással

| Kapcsoló | Alapértelmezés | Leírás |
| --- | --- | --- |
| `--translationDir` | a nuxt.config `i18n.translationDir` értéke | Fordítási könyvtár, a projekthez viszonyítva |
| `--format` | `po` | Fájlformátum: po, csv |
| `--dir` | `pots` po esetén, `csv_exports` csv esetén | Kimeneti könyvtár, a projekthez viszonyítva |
| `--force` | `false` | Az utolsó export óta módosított és soha nem importált fájlok felülírása |

```bash
i18n-micro export --format csv
```

### `import` {#import}

PO vagy CSV fájlok beolvasztása a locale-fájlokba

| Kapcsoló | Alapértelmezés | Leírás |
| --- | --- | --- |
| `--translationDir` | a nuxt.config `i18n.translationDir` értéke | Fordítási könyvtár, a projekthez viszonyítva |
| `--format` | `po` | Fájlformátum: po, csv |
| `--dir` | `pots` po esetén, `csv_exports` csv esetén | Bemeneti könyvtár, a projekthez viszonyítva |
| `--dryRun` | `false` | Jelenti, mi kerülne importálásra; semmit nem ír |

```bash
i18n-micro import --format csv --dryRun
```

### `sync-remote` {#sync-remote}

Globális fordítások lekérése a .i18n-remote.json fájlban megadott HTTP-végpontról, vagy feltöltése oda

| Kapcsoló | Alapértelmezés | Leírás |
| --- | --- | --- |
| `--translationDir` | a nuxt.config `i18n.translationDir` értéke | Fordítási könyvtár, a projekthez viszonyítva |
| `--pull` | `true` | Lekérés a távoli végpontról |
| `--push` | `false` | Feltöltés a távoli végpontra |
| `--force` | `false` | Lekéréskor a távoli értéket veszi át; feltöltéskor felülírja azt a szöveget, amely csak a távoli oldalon van meg |
| `--dryRun` | `false` | Jelenti, mit változtatna egy lekérés; semmit nem ír és nem tölt fel |

```bash
i18n-micro sync-remote --dryRun
i18n-micro sync-remote --no-pull --push
```

## Lint-szabályok {#lint-rules}

| Szabály | Mit talál | Javítja a `--fix` |
| --- | --- | --- |
| `no-trailing-spaces` | Szóközök egy érték vagy sor végén | igen |
| `no-multiple-spaces` | Két vagy több egymást követő szóköz | igen |
| `no-empty-translation` | Üres vagy csak szóközökből álló érték | nem |

## Kilépési kódok {#exit-codes}

| Kód | Jelentés |
| --- | --- |
| `0` | Kész, nincs mit jelenteni |
| `1` | Találatok: a `check`, a `lint` vagy a `format --check` talált valamit, a `clean` vagy a `sync` nem tudta biztonságosnak bizonyítani egy eltávolítást, az `export` felülírna nem importált munkát, a `translate` kihagyott kulcsokat, az `import` vagy a `sync-remote` ütközésbe ütközött, egy `sync-remote` feltöltés távoli szöveget dobna el. A `clean`, a `sync` vagy egy `sync-remote` lekérés `--dryRun` futtatása ezeket jelenti, és `0` kóddal lép ki |
| `2` | Hiba: helytelen használat, olvashatatlan projekt, hálózati vagy fájlhiba |

## Konfigurációs fájlok {#configuration-files}

| Fájl | Használja |
| --- | --- |
| `.i18n-lintrc.json` | `lint`: `enabledRules`, `disabledRules`, `customRegexRules` (`name`, `pattern`, `flags`, `description`, `replacement`) |
| `.i18n-remote.json` | `sync-remote`: `url`, `path`, `token`, `auth` (`username`, `password`). A `type` elhagyható; csak a `custom` létezik |
| `.i18n-glossary.json` | `translate --service ai`: `source`, `target`, valamint opcionális `from`, `to` mezőkből álló `entries` |

## Környezeti változók {#environment-variables}

| Név | Mire szolgál |
| --- | --- |
| `I18N_TRANSLATE_TOKEN` | A `translate` API-kulcsa. A `.env` fájlból is beolvasva |
| `I18N_REMOTE_TOKEN` | A `sync-remote` Bearer tokenje. A `.env` fájlból is beolvasva |
| `AI_GATEWAY_API_KEY, OPENAI_API_KEY, ANTHROPIC_API_KEY` | Az `ai` szolgáltatás kulcsa, ha az `I18N_TRANSLATE_TOKEN` nincs beállítva |
| `DEFAULT_LOCALE` | Felülírja a `defaultLocale` értékét, ahogy a modulban is |
