# 🌍 `<i18n-group>` komponens

Az `<i18n-group>` komponens a Nuxt I18n Micro-ban kényelmes módot biztosít a fordítások közös előtag alatti csoportosítására, csökkentve az ismétlést és javítva a kódszervezést.

## ⚙️ Propok

{/* generated:component:i18n-group — do not edit; run `pnpm run docs:generate` */}

| Prop | Típus | Alapértelmezett | Leírás |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | Kulcselőtag, amellyel a slotban minden keresés feloldásra kerül. |
| `groupClass` | `string` | `''` | Extra osztály a burkoló elemen. |

**\*** kötelező.

### Slotok

| Slot | Kötések | Leírás |
| --- | --- | --- |
| `default` | `prefix`, `t` | Megkapja a `prefix`-et és egy hozzá tartozó `t` függvényt. |

{/* /generated:component:i18n-group */}

## 🎯 Slotok

Az alapértelmezett slot megkapja a `prefix`-et és egy hozzá tartozó `t` függvényt, így a kulcsok az előtaghoz képest íródnak:

```vue
<i18n-group prefix="checkout">
  <template #default="{ t }">
    <h2>{{ t('title') }}</h2>
    <p>{{ t('summary', { count: 3 }) }}</p>
  </template>
</i18n-group>
```

## 🛠️ Példa használat

### Alapvető használat

```vue
<template>
  <i18n-group prefix="product.details">
    <template #default="{ t }">
      <h1>{{ t('title') }}</h1>
      <p>{{ t('description') }}</p>
      <div class="price">{{ t('price', { value: 99.99 }) }}</div>
    </template>
  </i18n-group>
</template>
```

Fordítási fájl:

```json
{
  "product": {
    "details": {
      "title": "Premium Product",
      "description": "This is a premium product",
      "price": "Price: ${value}"
    }
  }
}
```

### Egyéni osztállyal

```vue
<template>
  <i18n-group prefix="user.profile" group-class="profile-section">
    <template #default="{ t }">
      <div class="user-info">
        <h2>{{ t('title') }}</h2>
        <p>{{ t('bio') }}</p>
        <div class="stats">
          <span>{{ t('stats.followers') }}</span>
          <span>{{ t('stats.following') }}</span>
        </div>
      </div>
    </template>
  </i18n-group>
</template>
```

Fordítási fájl:

```json
{
  "user": {
    "profile": {
      "title": "User Profile",
      "bio": "User biography goes here",
      "stats": {
        "followers": "Followers: {count}",
        "following": "Following: {count}"
      }
    }
  }
}
```

### Dinamikus tartalommal

```vue
<template>
  <i18n-group prefix="blog.post">
    <template #default="{ t }">
      <article>
        <h1>{{ t('title') }}</h1>
        <div class="meta">
          {{ t('meta.author', { name: author }) }} |
          {{ t('meta.date', { date: publishDate }) }}
        </div>
        <div v-for="(section, index) in sections" :key="index">
          <h2>{{ t(`sections.${index}.title`) }}</h2>
          <p>{{ t(`sections.${index}.content`) }}</p>
        </div>
      </article>
    </template>
  </i18n-group>
</template>

<script setup>
const author = 'John Doe'
const publishDate = '2024-01-01'
const sections = ['intro', 'main', 'conclusion']
</script>
```

## 🎨 Stílusozás

A komponens a tartalmát egy `i18n-group` osztályú divbe csomagolja, valamint minden további osztályt, amelyet a `groupClass` propon keresztül megadsz:

```css
.i18n-group {
  /* Your base styles */
}

.profile-section {
  /* Additional styles for profile sections */
}
```

## 🚀 Legjobb gyakorlatok

1. **Konzisztens előtagok**: Használj konzisztens és logikus előtagokat, amelyek tükrözik az alkalmazásod szerkezetét

```vue
<i18n-group prefix="features.pricing">
<i18n-group prefix="features.security">
```

2. **Moduláris szervezés**: Csoportosítsd a kapcsolódó fordításokat értelmes előtagok alatt

```vue
<i18n-group prefix="checkout.payment">
<i18n-group prefix="checkout.shipping">
```

3. **Újrahasznosítható komponensek**: Hozz létre újrahasznosítható komponenseket saját fordítási csoportjaikkal

```vue
<!-- UserProfile.vue -->
<i18n-group prefix="user.profile">

<!-- UserSettings.vue -->
<i18n-group prefix="user.settings">
```

4. **Beágyazott csoportok**: Kerüld a csoportok mély beágyazását a világosság megőrzése érdekében

```vue
<!-- Good -->
<i18n-group prefix="shop.product">

<!-- Avoid -->
<i18n-group prefix="shop.category.product.details.specs">
```
