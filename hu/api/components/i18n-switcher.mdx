# 🌍 `<i18n-switcher>` komponens

A `Nuxt I18n Micro` `<i18n-switcher>` komponense felhasználóbarát legördülőt biztosít az alkalmazás területei közötti váltáshoz. Erősen testreszabható, így zökkenőmentesen illeszkedik az alkalmazásod dizájnjához és elrendezéséhez.

A `disabled: true` területeket **kihagyjuk** a legördülőből (a `$getLocales()`-ben továbbra is elérhetők SEO-hoz / head-címkékhez). Csak a válthó területek kapnak `NuxtLink`-et + `hreflang`-et.

Minden rész alapértelmezetten stílus nélküli: a `custom*Style` propok inline stílus-objektumokat várnak,
az alábbi slotok pedig teljesen lecserélik a markupot, ha a stílusozás önmagában nem elég.

## 🛠️ Példák a használatra

### Alapvető használat

```vue
<template>
  <i18n-switcher />
</template>
```

Ez alapértelmezett stílusú és viselkedésű területi váltót renderel.

### Egyedi címkék és inline stílusok

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Ez a példa teljesen testreszabott területi váltót mutat egyedi címkékkel és inline stílusokkal.

## 🔌 Slotok

A váltó minden vizuális része lecserélhető. A slotokat a propok táblázatával együtt fentebb soroltuk fel; mindegyik sablon-tartalmat vár:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Az `-item`, `-link-content` végű vagy `before-item`-mel kezdődő slotok megkapják a
`locale` objektumot, amelyhez tartoznak.

## 🎨 Stílusok áttekintése

Az `<i18n-switcher>` komponens alap-stílusokat biztosít inline stílusokkal, amelyeket a propokon keresztül átadott egyedi stílusokkal könnyen felülírhatsz. Íme az alapértelmezett stílusok rövid áttekintése:

- **Wrapper**: A legördülő pozicionálását vezérli.
- **Button**: A legördülő kapcsológomb stílusa.
- **Dropdown**: A legördülő lista stílusa.
- **Items**: A lista egyes elemeinek stílusa.
- **Links**: Az elemeken belüli linkek stílusa.
- **Icon**: A legördülő jelzőikon stílusa.

Ezeket a stílusokat a megfelelő propokon keresztül átadott egyedi stílusokkal testreszabhatod, biztosítva, hogy a területi váltó zökkenőmentesen illeszkedjen az alkalmazásod felületéhez.
