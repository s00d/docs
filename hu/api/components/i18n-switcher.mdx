# 🌍 `<i18n-switcher>` komponens

Az `<i18n-switcher>` komponens a `Nuxt I18n Micro`-ban felhasználóbarát legördülő felületet biztosít az alkalmazásod különböző területi beállításai közötti váltáshoz. Ez a komponens erősen testreszabható, zökkenőmentes integrációt biztosítva az alkalmazásod dizájnjához és elrendezéséhez.

A `disabled: true` beállítású területi beállítások **kimaradnak** a legördülő menüből (elérhetők maradnak a `$getLocales()` segítségével SEO / head címkékhez). Csak a válthatók kapnak `NuxtLink` + `hreflang` értéket.

Minden rész alapértelmezés szerint stílus nélküli. A `custom*Style` propok inline stílus objektumokat vesznek fel, és az alábbi slotok teljesen lecserélik a jelölést, amikor a stílusozás nem elegendő.

## 🛠️ Példa használatok

### Alapvető használat

```vue
<template>
  <i18n-switcher />
</template>
```

Ez egy területi váltót renderel alapértelmezett stílusozással és viselkedéssel.

### Egyéni címkék és inline stílusok

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Ez a példa egy teljesen testreszabott területi váltót mutat be egyéni címkékkel és inline stílusokkal.

## 🔌 Slotok

A váltó minden vizuális része cserélhető. A slotokat a fenti propok táblázattal együtt soroljuk fel. Mindegyikbe sablon tartalom kerülhet:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Azok a slotok, amelyek neve `-item`, `-link-content`-tel végződik, vagy `before-item`-mal kezdődik, megkapják azt a `locale` objektumot, amelyhez tartoznak.

## 🎨 Stílusok áttekintés

Az `<i18n-switcher>` komponens alapstílusokkal rendelkezik, amelyeket inline stílusokkal definiálunk, és amelyek könnyen felülbírálhatók egyéni stílusok átadásával propokon keresztül. Íme egy rövid áttekintés az alapértelmezett stílusozásról:

- **Burkoló**: Vezérli a legördülő menü elhelyezését.
- **Gomb**: Stílusozza a legördülő menü váltó gombját.
- **Legördülő menü**: Stílusozza a legördülő listát.
- **Elemek**: Stílusozza a lista minden elemét.
- **Linkek**: Stílusozza a linkeket az egyes elemeken belül.
- **Ikon**: Stílusozza a legördülő menü jelző ikonját.

Ezeket a stílusokat testreszabhatod egyéni stílusok átadásával a megfelelő propokon keresztül, biztosítva, hogy a területi váltó zökkenőmentesen illeszkedjen az alkalmazásod felhasználói felületébe.
