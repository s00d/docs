# 🌍 `<i18n-t>` komponens

Az `<i18n-t>` komponens a `Nuxt I18n Micro`-ban rugalmas fordítási komponens, amely támogatja a dinamikus tartalombeillesztést slotokon keresztül. Lehetővé teszi a fordítások interpolálását egyéni Vue komponensekkel vagy HTML tartalommal, fejlett honosítási forgatókönyveket biztosítva.

| `tag` | `string` | `'span'` | A renderelendő elem. |

{/* /generated:component:i18n-t */}

A `plural`, `number`, `date` és `relativeDate` közül egyszerre csak egy alkalmazható. Ha többet állítasz be, a listában első nyer.

### Példák propokként

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

```json
{
  "items": "Nothing|You have {count} item|You have {count} items"
}
```

## 🛠️ Példa használatok

### Alapvető használat

```vue
<i18n-t keypath="feedback.text" />
```

Ez a `feedback.text` fordítást rendereli egy `<span>` címkén belül.

### Slotok használata dinamikus tartalomhoz

Az `<i18n-t>` komponens támogatja a slotok használatát Vue komponensek vagy más tartalom dinamikus beszúrásához a fordítás meghatározott részeibe.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

Ebben a példában a `feedback.text` fordítási karakterláncban lévő `\{link\}` helyőrzőt a `<nuxt-link>` komponens váltja fel, amely maga is egy másik fordítási komponenst tartalmaz.

### Többes szám kezelés

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

Ez automatikusan alkalmazza a többes szám szabályokat az `itemCount` érték alapján.

## 🚀 További funkciók

### Alapértelmezett slot

Ha nincs megadva speciális slot, a fordítás testreszabható az alapértelmezett sloton keresztül, amely a teljes lefordított karakterláncot biztosítja:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### Feltételes renderelés

Ne rendereld semmit, ha a fordítás karakterlánc üres, a `hideIfEmpty` prop használatával.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### Egyéni többes szám szabály

Használj egyéni függvényt a többes szám kezelésére.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### Haladó példa slotokkal

Használj slotokat annak testreszabására, hogyan renderelődik a fordítási tartalom.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
