# 🌍 `<i18n-t>` komponens

A `Nuxt I18n Micro` `<i18n-t>` komponense rugalmas fordítási komponens, amely slotokon keresztül támogatja a dinamikus tartalombeszúrást. Egyedi Vue-komponenseket vagy HTML-tartalmat interpolálhatsz a fordításba, ami haladó lokalizációs forgatókönyveket tesz lehetővé.

| `plural` | `number \| string` | — | Mennyiség, amely a többes formát választja. Állítsd be, hogy a `$t` helyett a `$tc`-t használja. |
| `tag` | `string` | `'span'` | A renderelendő elem. |
| `params` | `Record<string, string \| number \| boolean>` | `() => (\{\})` | A fordításba behelyettesítendő interpolációs értékek. |
| `defaultValue` | `string` | `''` | A komponens helyett ez jelenik meg, ha a `hideIfEmpty` elnyomja az üres fordítást. |
| `html` | `boolean` | `false` | A fordítást HTML-ként rendereli szöveg helyett. Csak olyan tartalomhoz, amit te kontrollálsz. |

| `customPluralRule` | `PluralFunc` | `null` | Csak ehhez az elemhez tartozó többesszám-szabály, felülírva a konfigurációban lévőt. |
| `number` | `number \| string` | — | Az értéket `$tn`-nel formázza, és `\{number\}`-ként adja át a fordításnak. |
| `date` | `Date \| string \| number` | — | Az értéket `$td`-vel formázza, és `\{date\}`-ként adja át a fordításnak. |

{/* /generated:component:i18n-t */}

Egyszerre csak egy `plural`, `number`, `date` és `relativeDate` érvényesül; ha többet is
beállítasz, a listában az első nyer.

### Példák propokra

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

```json
{
  "items": "Nothing|You have {count} item|You have {count} items"
}
```

## 🛠️ Példák a használatra

### Alapvető használat

```vue
<i18n-t keypath="feedback.text" />
```

Ez rendereli a `feedback.text` fordítását egy `<span>` címkén belül.

### Slotok használata dinamikus tartalomhoz

Az `<i18n-t>` komponens támogatja a slotok használatát, hogy dinamikusan illeszthess be Vue-komponenseket vagy más tartalmat a fordítás meghatározott részeibe.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

Ebben a példában a `feedback.text` fordítási sztringben lévő `\{link\}` helyőrzőt a `<nuxt-link>` komponens váltja fel, amely maga is egy másik fordítási komponenst tartalmaz.

### Többes szám

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

Ez automatikusan alkalmazza a többesszám-szabályokat az `itemCount` értéke alapján.

## 🚀 További jellemzők

### Alapértelmezett slot

Ha nincs megadva speciális slot, a fordítás az alapértelmezett sloton keresztül szabható testre, amely megkapja a teljes lefordított sztringet:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### Feltételes renderelés

Ne rendereljen semmit, ha a fordítási sztring üres — használd a `hideIfEmpty` propot.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### Egyedi többesszám-szabály

Egyedi függvénnyel kezelheted a többes számot.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### Haladó példa slotokkal

Használj slotokat a fordítási tartalom megjelenítésének testreszabására.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
