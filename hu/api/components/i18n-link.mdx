# 🌍 `<i18n-link>` komponens

A `Nuxt I18n Micro` `<i18n-link>` komponense sokoldalú link-komponens, amely az aktuális terület alapján automatikusan lokalizálja az útvonalakat. A `<NuxtLink>` komponens köré épített csomagolóként további jellemzőket biztosít, például aktív link stílusozását és külső linkek támogatását.

## ⚙️ Propok

| Prop | Típus | Alapérték | Leírás |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | Céloldali útvonal. Automatikusan lokalizálva; a külső URL változatlanul átadódik. |
| `activeStyle` | `Partial<CSSStyleValue>` | — | Inline stílus, amelyet akkor alkalmazunk, amikor a link az aktuális útvonalra mutat. |

**\*** kötelező.

### Slotok

| Slot | Kötések | Leírás |
| --- | --- | --- |
| `default` | — | A link tartalma. |

{/* /generated:component:i18n-link */}

A `to` mindent elfogad, amit a `NuxtLink` — útvonalat, elnevezett útvonalat vagy feloldott útvonal-objektumot.
Az abszolút URL-t felismerjük, és sima `<a target="_blank" rel="noopener noreferrer">`-ként rendereljük, nem
lokalizáljuk.

## 🛠️ Példák a használatra

### Alapvető használat

```vue
<i18n-link to="/about">About Us</i18n-link>
```

Ez a példa egy `/about` oldalra mutató linket hoz létre, az aktuális területre lokalizálva.

### Aktív link stílusozása inline stílusokkal

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

A link félkövér szövegű lesz, amikor a felhasználó az `/about` oldalon van, így az aktív linket közvetlenül inline stílusokkal formázhatod.

### Külső linkek kezelése

A komponens automatikusan felismeri a külső linkeket, és hozzáadja a biztonsághoz szükséges attribútumokat.

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

Ez a link a `https://example.com`-ot új lapon nyitja meg, `rel="noopener noreferrer"` értékkel.

## 🎨 Stílusok

A komponens most már inline stílusokat használ az aktív állapothoz osztály helyett. Ezeket a stílusokat az `activeStyle` prop segítségével testre szabhatod.

### Alapértelmezett aktív stílusok

- **Betűvastagság**: `bold`
- **Szín**: A böngésző alapértelmezett színét örökli (ha nincs `color` az `activeStyle`-ban).

Ezeket az `activeStyle` propon keresztül adott egyedi stílusokkal felülírhatod.

### Egyedi aktív stílusok

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

Ebben a példában a link félkövér és zöld lesz aktív állapotban.

## 🚀 További jellemzők

### Slot egyedi tartalomhoz

A linken belül slotokkal egyedi tartalmat helyezhetsz el, így a komponens rugalmasan illeszthető különféle felhasználási esetekhez.

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### Akadálymentesítési kiegészítések

A komponens támogatja az `aria-label`-t és más akadálymentesítési attribútumokat a hozzáférhetőbb élményért.

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
