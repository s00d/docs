# 🌍 `<i18n-link>` komponens

Az `<i18n-link>` komponens a `Nuxt I18n Micro`-ban egy sokoldalú link komponens, amely automatikusan honosítja az útvonalakat az aktuális területi beállítás alapján. A `<NuxtLink>` komponens burkolójaként működik, további funkciókat biztosítva, mint az aktív link stílusozás és a külső linkek támogatása.

## ⚙️ Propok

| Prop | Típus | Alapértelmezett | Leírás |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | Cél útvonal. Automatikusan honosítva. A külső URL változtatás nélkül átmegy. |
| `activeStyle` | `Partial<CSSStyleValue>` | — | Inline stílus, amely akkor alkalmazandó, amikor a link az aktuális útvonalra mutat. |

**\*** kötelező.

### Slotok

| Slot | Kötések | Leírás |
| --- | --- | --- |
| `default` | — | Link tartalma. |

{/* /generated:component:i18n-link */}

A `to` bármit elfogad, amit a `NuxtLink`. Egy útvonalat, egy elnevezett útvonalat vagy egy feloldott útvonal objektumot. Az abszolút URL felismerésre kerül, és egyszerű `<a target="_blank" rel="noopener noreferrer">` elemként renderelődik ahelyett, hogy honosítanánk.

## 🛠️ Példa használatok

### Alapvető használat

```vue
<i18n-link to="/about">About Us</i18n-link>
```

Ez a példa egy linket hoz létre az `/about` oldalra, az aktuális területi beállítás szerint honosítva.

### Aktív link stílusozás inline stílusokkal

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

A link félkövér szöveget kap, ha a felhasználó az `/about` oldalon van, lehetővé téve az aktív link közvetlen stílusozását inline stílusokkal.

### Külső linkek kezelése

A komponens automatikusan észleli a külső linkeket, és hozzáadja a szükséges attribútumokat a biztonsághoz.

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

Ez a link az `https://example.com` oldalt nyitja meg egy új lapon, `rel="noopener noreferrer"` alkalmazásával.

## 🎨 Stílusok

A komponens most inline stílusokat használ az aktív állapothoz osztály helyett. Ezeket a stílusokat testreszabhatod az `activeStyle` prop segítségével.

### Alapértelmezett aktív stílusok

- **Betűvastagság**: `bold`
- **Szín**: Örökli a böngésző alapértelmezett színét (ha nincs `color` megadva az `activeStyle`-ban).

Ezeket felülbírálhatod egyéni stílusok megadásával az `activeStyle` propon keresztül.

### Egyéni aktív stílusok

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

Ebben a példában a link félkövér és zöld lesz aktív állapotban.

## 🚀 További funkciók

### Slot egyéni tartalomhoz

Egyéni tartalmat adhatsz át a linken belül slotok segítségével, rugalmassá téve a komponenst különböző használati esetekhez.

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### Akadálymentesítési fejlesztések

A komponens támogatja az `aria-label` és más akadálymentesítési attribútumokat, hogy elérhetőbb élményt biztosítson.

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
