# 🛠️ `useI18n` composable

A `useI18n` composable a `Nuxt I18n Micro`-ban a legtöbb futásidejű i18n-segédhez ad hozzáférést komponensekben és szkriptekben. A metódusok **`$` előtaggal és anélkül is** elérhetők (például `$t` és `t`).

Néhány injekció — a `$defineI18nRoute` és a `$clearCache` — csak a `useNuxtApp()`-on keresztül érhető el. Lásd a [Metódusok — `$defineI18nRoute`](/api/methods#definei18nroute) és a [`$clearCache`](/api/methods#clearcache) részt.

## 📊 Mit ad vissza

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Minden futásidejű segéd, sima objektumként.

Ugyanazok a függvények, amelyeket a plugin `$t`, `$tc` stb. néven injektál, elérhetők
a dollár-előtaggal ellátott néven és sima aliasként is — tehát a `const \{ t \} = useI18n()` és
a `const \{ $t \} = useI18n()` egyaránt működik.

**Visszatérési érték** — a [metódus-referenciában](/api/methods) leírt segédek

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

Minden általa visszaadott segédet — `$t`, `$tc`, `$has`, `$switchLocale` és a többit — a szignatúrájával együtt a
[metódus-referencia](/api/methods) sorol fel és dokumentál teljeskörűen.

## Csak `useNuxtApp()`-on át elérhető API-k

Ezeket a `useI18n()` **nem** adja vissza. A `useNuxtApp()`-ból importáld őket:

| Metódus                    | Cél                                                                             |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Oldalankénti területi útvonalak, korlátozások és inline fordítások `script setup`-ban |
| `$clearCache()`            | Törli a memóriában lévő fordítási gyorsítótárat és a betöltött darabokat        |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Teljes szignatúrákért és példákért lásd a [Metódusokat](/api/methods).

## 🛠️ Példák a használatra

### Aktuális terület lekérése

Kérd le az alkalmazás aktuális területét.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Fordítás paraméterekkel

Fordíts sztringet dinamikus paraméterekkel, tartalék alapértékkel.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Területváltás

Kapcsold át az alkalmazást másik területre.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Területspecifikus útvonal generálása

Generálj útvonalat az aktuális vagy egy megadott területhez.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
