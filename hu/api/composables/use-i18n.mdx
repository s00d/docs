# 🛠️ `useI18n` composable

A `useI18n` composable a `Nuxt I18n Micro`-ban hozzáférést biztosít a legtöbb futásidejű i18n segédhez komponensekben és szkriptekben. A metódusok **elérhetők a `$` előtaggal és anélkül is** (például `$t` és `t`).

Néhány injekció (`$defineI18nRoute` és `$clearCache`) csak a `useNuxtApp()`-on érhető el. Lásd [Metódusok — `$defineI18nRoute`](/api/methods#definei18nroute) és [`$clearCache`](/api/methods#clearcache).

## 📊 Mit ad vissza

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Minden futásidejű segéd, mint egyszerű objektum.

Ugyanazok a függvények, amelyeket a bővítmény `$t`, `$tc` és így tovább néven injektál, elérhetők mind a dollár-előtaggal ellátott néven, mind egy csupasz álnév alatt. Tehát a `const \{ t \} = useI18n()` és a `const \{ $t \} = useI18n()` egyaránt működik.

**Visszatérési érték** — a [metódus referenciában](/api/methods) leírt segédek

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

Minden segéd, amelyet visszaad (`$t`, `$tc`, `$has`, `$switchLocale` és a többi), fel van sorolva az aláírásával, és teljesen dokumentálva van a [Metódusok referenciában](/api/methods).

## Csak `useNuxtApp()` API-k

Ezeket **nem** adja vissza a `useI18n()`. Importáld őket a `useNuxtApp()`-ból:

| Metódus                    | Cél                                                                             |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Oldalankénti területi útvonalak, korlátozások és inline fordítások a `script setup`-ban |
| `$clearCache()`            | Törli a memóriabeli fordítási gyorsítótárat és a betöltött darabokat            |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Nézd meg a [Metódusokat](/api/methods) a teljes aláírásokért és példákért.

## 🛠️ Példa használatok

### Alapvető területi lekérés

Kérdezd le az alkalmazás aktuális területi beállítását.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Fordítás paraméterekkel

Fordíts le egy karakterláncot dinamikus paraméterekkel, alapértelmezett értékkel tartalékként.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Területi beállítások váltása

Váltsd át az alkalmazást egy másik területi beállításra.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Honosított útvonal generálása

Generálj egy útvonalat, amely az aktuális vagy megadott területi beállításhoz honosított.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
