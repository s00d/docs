# 🌍 `useLocaleHead` composable

A `useLocaleHead` composable a `Nuxt I18n Micro` egyik segédeszköze, amellyel a területi útvonalakhoz SEO-attribútumokat és HTML-meta-címkéket kezelhetsz. Dinamikusan generálja a HTML-dokumentum `lang` és `dir` attribútumait, valamint `meta` és `link` címkéket hoz létre a területspecifikus tartalom SEO-jának javítására.

## ⚙️ Opciók

{/* generated:symbol:useLocaleHead — do not edit; run `pnpm run docs:generate` */}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }, MetaObject | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

Az aktuális útvonal SEO-fejcímkéi: `hreflang` alternatívák minden területhez plusz
`x-default`, canonical link, `og:locale` és `lang`/`dir` a `<html>`-en.

Csak akkor szükséges, ha a `meta` le van tiltva, vagy az alapértékeket állítani kell — `meta: true` esetén
a modul maga regisztrálja ugyanezeket a címkéket.

**Visszatérési érték** — a head-objektumot tartalmazó ref, készen az `useHead`-nek átadva

```ts
const head = useLocaleHead({ addSeoAttributes: true })
useHead(head)
```

## 🛠️ Visszatérési értékek

A `useLocaleHead` egy reaktív objektumot és egy frissítő függvényt ad vissza, amelyet
akkor kell hívnod, amikor a forrásadatok változnak. Mindkét szerkezet a fenti, a forrásból
generált szignatúrában szerepel.

### `metaObject`

Reaktív head-payload (html attrs, meta, link), amelyet a `useHead(metaObject)` fogyaszt.

- **Példa**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

Újraszámolja a `metaObject`-et az aktuális útvonal, terület és konfiguráció alapján. Hívd meg, amikor a bemenetek
változnak — például útvonalváltáskor.

- **Példa**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### A `link` és `meta` elérése

A `link` és `meta` tömbök a `metaObject.value`-n keresztül érhetők el:

- **Példa**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ Példák a használatra

### Alapvető használat

Területspecifikus head-attribútumok generálása alapértelmezett opciókkal.

```js
const head = useLocaleHead()
```

### Azonosító-attribútum testreszabása

Egyedi azonosító-attribútum a generált címkékhez.

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### SEO-attribútumok kikapcsolása

Head-attribútumok generálása anélkül, hogy SEO-hoz kapcsolódó meta- és link-címkéket adna hozzá.

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### Egyedi bázis-URL megadása

Egyedi bázis-URL a canonical és alternatív URL-ekhez.

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 További jellemzők

### SEO meta- és link-címkék

Ha az `addSeoAttributes` engedélyezve van, a composable automatikusan generálja az alábbi címkéket:

- `og:locale` az aktuális területhez (`language_TERRITORY`, aláhúzással). A `locale.og`-ból származtatva, vagy — ha lehet — a `locale.iso`-ból konvertálva.
- `og:url` az oldal kanonikus URL-jéhez.
- `og:locale:alternate` az alternatív nyelvi verziókhoz.
- `rel="canonical"` és `rel="alternate"` linkek SEO-optimalizáláshoz.
- `hreflang="x-default"` link az alapértelmezett terület URL-jére mutatva. Ez jelzi a keresőknek, mely URL-t mutassák azoknak a felhasználóknak, akiknek a nyelve egyik definiált területhez sem illik.

### Dinamikus terület és irány

A composable az aktuális útvonal területe alapján dinamikusan határozza meg a `lang` és `dir` attribútumokat, így a HTML-dokumentum helyesen van konfigurálva a nemzetközi felhasználók számára.

### Területspecifikus útvonalak kezelése

Ha az útvonalaid területkód-előtaggal szerepelnek (pl. `/en/about`), a composable intelligensen igazítja a teljes útvonalat az URL-generáláshoz, biztosítva, hogy a SEO-attribútumok pontosak és relevánsak legyenek.

Ez a composable leegyszerűsíti a Nuxt-alkalmazásod nemzetközi közönségre optimalizálásának folyamatát, hogy a webhely felkészült legyen a globális keresőmotorok és felhasználók számára.

## 🛠️ Példa a használatra

Az alábbi példa bemutatja, hogyan használható a `useLocaleHead` composable egy Vue-komponensen belül alapértelmezett beállításokkal:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### A kód magyarázata

- **`useLocaleHead` composable**: Ezt a composable-t a `<script setup>` szakaszban hívjuk meg, és egy `htmlAttrs`, `meta` és `link` mezőket tartalmazó objektumot ad vissza.

- **`<html>` címke**: A HTML-dokumentum `lang` és `dir` attribútumai az aktuális terület alapján dinamikusan határozódnak meg, és a `<html>` címkére kerülnek.

- **`<head>` szakasz**:
  - **Meta-címkék**: A SEO-hoz kapcsolódó meta-címkék generálódnak, például `og:locale`, `og:url`, valamint `rel="canonical"` és `rel="alternate"` az oldal alternatív nyelvi verzióinak megadásához.
  - **Link-címkék**: Canonical linkek, alternatív nyelvi linkek és a `hreflang="x-default"` link (az alapértelmezett terület URL-jére mutatva) is szerepelnek.

- **`<body>` szakasz**: Itt jelenik meg az oldal fő tartalma. Ebben a példában egy egyszerű fejlécet és bekezdést használunk.

### 📝 Megjegyzések

1. **Attribútumok**: A használt attribútumok (`lang`, `dir`, `rel`, `href`, `hreflang`, `property`, `content`) a `useLocaleHead` által visszaadott objektumból származnak.

2. **SEO-címkék generálása**: Ha az `addSeoAttributes` opció `true`, a composable automatikusan generálja az aktuális területhez tartozó SEO-címkéket.

3. **Bázis-URL**: A `baseUrl` opcióval megadhatod az egyedi bázis-URL-t a canonical és alternatív linkek helyes generálásához.

Ez a példa jól szemlélteti, milyen egyszerű integrálni a `useLocaleHead`-et az alkalmazás komponenseibe, hogy helyes SEO-attribútumokat és jobb keresőindexelést biztosíts a területi oldalakhoz.

## 🧩 Testreszabás és életciklus

- A `useLocaleHead` önmagában nem iratkozik fel változásokra. Egy `metaObject`-et és egy `updateMeta`-t ad vissza.
- Az `updateMeta()`-t akkor kell meghívnod, amikor a bemenetek változnak (jellemzően útvonalváltáskor), például egy pluginből:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## Mikor használd inkább a `useI18nHead`-et

Ha `meta: true` (az alapértelmezés), az **oldalankénti** felülírásokhoz (egyedi hreflang, extra `og:title`, részleges kikapcsolás) inkább a [`useI18nHead`](/api/composables/use-i18n-head)-et használd. A `useLocaleHead`-et közvetlenül csak akkor használd, ha `meta: false`, vagy magad kezeled a `useHead`-et.
