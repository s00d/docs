# 🌍 `useLocaleHead` composable

A `useLocaleHead` composable egy segédfüggvény a `Nuxt I18n Micro`-ban, amely segít kezelni a SEO attribútumokat és a HTML metacímkéket a honosított útvonalakhoz. Dinamikusan generálja a HTML dokumentum `lang` és `dir` attribútumait, valamint `meta` és `link` címkéket hoz létre a honosított tartalom SEO-jának javításához.

## ⚙️ Opciók

{/* generated:symbol:useLocaleHead — do not edit; run `pnpm run docs:generate` */}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }, MetaObject | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

A SEO head címkék az aktuális útvonalhoz: `hreflang` alternatívák minden területi beállításhoz plusz `x-default`, canonical link, `og:locale` és `lang`/`dir` a `<html>`-en.

Csak akkor szükséges, ha a `meta` le van tiltva, vagy az alapértelmezéseket módosítani kell. `meta: true` esetén a modul maga regisztrálja ugyanezeket a címkéket.

## 🛠️ Visszatérési értékek

A `useLocaleHead` composable egy reaktív objektumot és egy frissítő függvényt ad vissza, amelyet meg kell hívnod, amikor a forrásadatok változnak. Mindkét forma benne van a fenti aláírásban, amely a forrásból van generálva.

### `metaObject`

Reaktív head payload (html attrs, meta, link), amely alkalmas a `useHead(metaObject)`-hez.

- **Példa**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

Újraszámolja a `metaObject`-et az aktuális útvonal, területi beállítás és konfiguráció alapján. Hívd meg, amikor a bemenetek változnak. Például útvonalváltáskor.

- **Példa**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### A `link` és `meta` elérése

A `link` és `meta` tömbök a `metaObject.value`-n keresztül érhetők el:

- **Példa**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ Példa használatok

### Alapvető használat

Területi beállítás-specifikus head attribútumok generálása alapértelmezett opciókkal.

```js
const head = useLocaleHead()
```

### Egyéni azonosító attribútum

Használj egyéni azonosító attribútumot a generált címkékhez.

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### SEO attribútumok letiltása

Head attribútumok generálása SEO-val kapcsolatos meta és link címkék hozzáadása nélkül.

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### Alap URL megadása

Állíts be egyéni alap URL-t a canonical és alternatív URL-ekhez.

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 További funkciók

### SEO meta és link címkék

Amikor az `addSeoAttributes` engedélyezve van, a composable automatikusan generálja a következő címkéket:

- `og:locale` az aktuális területi beállításhoz (`language_TERRITORY`, alsóvonás). A `locale.og`-ból származik, vagy a `locale.iso`-ból konvertálva, ha lehetséges.
- `og:url` az oldal canonical URL-jéhez.
- `og:locale:alternate` az alternatív nyelvi verziókhoz.
- `rel="canonical"` és `rel="alternate"` linkek SEO optimalizáláshoz.
- `hreflang="x-default"` link, amely az alapértelmezett területi beállítás URL-jére mutat. Ez megmondja a keresőmotoroknak, hogy melyik URL-t mutassák azoknak a felhasználóknak, akiknek a nyelve nem egyezik meg egyik definiált területi beállítással sem.

### Dinamikus területi beállítás és irány

A composable dinamikusan határozza meg a `lang` és `dir` attribútumokat az aktuális útvonal területi beállítása alapján, biztosítva, hogy a HTML dokumentum helyesen legyen konfigurálva a nemzetközi felhasználók számára.

### Honosított útvonalak kezelése

Ha az útvonalak területi kódokkal vannak előtaggal ellátva (pl. `/en/about`), a composable intelligensen módosítja a teljes útvonalat az URL-ek generálásához, biztosítva, hogy a SEO attribútumok pontosak és relevánsak legyenek.

Ez a composable leegyszerűsíti a Nuxt alkalmazásod nemzetközi közönség számára történő optimalizálásának folyamatát, biztosítva, hogy a webhelyed jól fel legyen készítve a globális keresőmotorokra és felhasználókra.

## 🛠️ Példa használat

A következő példa bemutatja, hogyan használhatod a `useLocaleHead` composable-t egy Vue komponensen belül alapértelmezett beállításokkal:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### A kód magyarázata

- **`useLocaleHead` composable**: Ez a composable a `<script setup>` szakaszban van meghívva, és egy objektumot ad vissza, amely tartalmazza a `htmlAttrs`, `meta` és `link` mezőket.

- **`<html>` címke**: A HTML dokumentum `lang` és `dir` attribútumait dinamikusan határozzuk meg az aktuális területi beállítás alapján, és a `<html>` címkére alkalmazzuk.

- **`<head>` szakasz**:
  - **Meta címkék**: SEO-val kapcsolatos meta címkék generálódnak, beleértve az `og:locale`, `og:url` és `rel="canonical"` és `rel="alternate"` címkéket az oldal alternatív nyelvi verzióinak megadásához.
  - **Link címkék**: Canonical linkek, linkek az alternatív nyelvi verziókhoz és a `hreflang="x-default"` link (amely az alapértelmezett területi beállítás URL-jére mutat) tartozéka.

- **`<body>` szakasz**: Az oldal fő tartalma itt jelenik meg. Ebben a példában egy egyszerű fejléc és bekezdés van használva.

### 📝 Megjegyzések

1. **Attribútumok**: A használt attribútumok (`lang`, `dir`, `rel`, `href`, `hreflang`, `property`, `content`) a `useLocaleHead` által visszaadott objektumból kerülnek kivonásra.

2. **SEO címkék generálása**: Ha az `addSeoAttributes` opció `true` értékre van állítva, a composable automatikusan generál SEO címkéket az aktuális területi beállításhoz.

3. **Alap URL**: Egyéni alap URL-t állíthatsz be a `baseUrl` opció használatával a canonical és alternatív linkek helyes generálásához.

Ez a példa bemutatja, milyen egyszerű integrálni a `useLocaleHead`-et az alkalmazásod komponenseibe, hogy biztosítsd a helyes SEO attribútumokat, és javítsd a honosított oldalak keresőmotor-indexelését.

## 🧩 Testreszabás és életciklus

- A `useLocaleHead` nem iratkozik fel önmagában a változásokra. Visszaadja a `metaObject`-et és az `updateMeta`-t.
- Meg kell hívnod az `updateMeta()`-t, amikor a bemenetek változnak (jellemzően útvonalváltáskor), például egy bővítményből:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## Mikor használd inkább a `useI18nHead`-et

Amikor `meta: true` (az alapértelmezett), előnyben részesítsd a [`useI18nHead`](/api/composables/use-i18n-head) használatát az **oldalankénti** felülbírálásokhoz (egyéni hreflang, extra `og:title`, részleges letiltás). Használd a `useLocaleHead`-et közvetlenül csak akkor, ha `meta: false`, vagy magad kezeled a `useHead`-et.
