title: "Segédfüggvények"
description: "Minden futásidejű segédfüggvény, amelyet a modul injektál — `$t`, `$tc`, `$localePath`, `$switchLocale` és a többi — a szignatúrájával."
---

A modul a futásidejű segédfüggvényeit a Nuxt alkalmazásba injektálja: `$t`, `$tc`, `$localePath`, `$switchLocale` és a többi. Ezen az oldalon kikeresheted egy segédfüggvény szignatúráját és viselkedését. A szignatúrák és leírások a `src/runtime/plugins/01.plugin.ts` fájl `PluginsInjections` és `NuxtAppOnlyInjections` interfészeiből származnak.

## Hozzáférés {#access}

| Hol | Hogyan |
| --- | --- |
| Sablon | `{{ $t('title') }}` — minden segédfüggvény, `$` előtaggal |
| `<script setup>` | `const { t, localePath } = useI18n()` — a `PluginsInjections` minden segédfüggvénye, `$`-ral és anélkül |
| Plugin, middleware, `<script setup>` | `const { $t, $defineI18nRoute } = useNuxtApp()` — minden, csak `$`-ral |

A `$defineI18nRoute` csak a `useNuxtApp()`-on van típusozva. Lásd: [`useI18n`](/hu/composables/useI18n).

```vue
<script setup lang="ts">
const { t, localePath } = useI18n()
</script>

<template>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
</template>
```

## Locale {#locale}

### `$getLocale` {#$getlocale}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric) => string
```

Az aktív locale kódja. Adj át egy útvonalat, hogy annak a locale-ját olvasd ki.

```ts
$getLocale() // 'de' on /de/about
```

### `$getLocaleName` {#$getlocalename}

```ts
() => string | null
```

Az aktív locale `displayName` értéke a konfigurációból, vagy `null`, ha nincs ilyen.

### `$getLocales` {#$getlocales}

```ts
() => Locale[]
```

Minden beállított locale a metaadataival.

A locale-objektum egyéni tulajdonságai úgy jönnek vissza, ahogy megadtad őket; típusozd őket a `Locale` [modulkiegészítésével](/hu/api/module-options#locales).

### `$defaultLocale` {#$defaultlocale}

```ts
() => string | undefined
```

A beállított alapértelmezett locale kódja.

### `$getI18nConfig` {#$geti18nconfig}

```ts
() => ResolvedI18nConfig
```

A feloldott modulkonfiguráció, ahogy a futtatókörnyezet látja.

Az érték tartalmazza a [futásidejű felülírásokat](/hu/guide/runtime-overrides) (`defaultLocale`, `fallbackLocale`, letiltott locale-ok).

```ts
const { strategy, localeCookie } = useNuxtApp().$getI18nConfig()
```

## Fordítás {#translation}

### `$t` {#$t}

```ts
TranslationFn<CleanTranslation>
```

Egy kulcs lefordítása, a `params` behelyettesítésével. Hiányzó kulcs esetén a `defaultValue` értéket adja vissza,
vagy magát a kulcsot, ha nincs megadva alapérték.

```ts
// { "welcome": "Welcome, {name}!" }
$t('welcome', { name: 'Ada' }) // 'Welcome, Ada!'
$t('missing.key', {}, 'Fallback') // 'Fallback'
```

Egy beágyazott objektumra mutató kulcs azt az objektumot adja vissza, nem stringet. Sablonban `[object Object]`-ként jelenik meg; használj levélkulcsot.

### `$ts` {#$ts}

```ts
TranslationFn<string>
```

Mint a `$t`, de mindig stringet ad vissza: az érték a `toString()`-en megy át, így egy beágyazott
objektumból `'[object Object]'` lesz. A kulcs levélre mutasson.

### `$_t` {#$_t}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<CleanTranslation>
```

A `$t` hozzákötése egy adott útvonalhoz, az aktuális oldalon kívüli fordításhoz — például egy layouthoz,
amely egy másik útvonalra mutató linket jelenít meg.

```ts
const route = useRoute()
const t = useNuxtApp().$_t(route)
t('page.title')
```

### `$_ts` {#$_ts}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<string>
```

A `$ts` hozzákötése egy adott útvonalhoz. Lásd: `$_t`.

### `$tc` {#$tc}

```ts
(key: TranslationKey, params: number | Params, defaultValue?: string) => string
```

Fordítás többes számmal. A `params` lehet maga a darabszám, vagy egy `count` mezőt tartalmazó
objektum.

Az alakokat `|` választja el. A beépített szabállyal egy nemnegatív egész `n` darabszám az `n`-edik alakot választja, az utolsó alakra korlátozva; negatív, tört vagy `NaN` darabszám az utolsó alakot kapja. A `{count}` és a többi paraméter a kiválasztott alakba helyettesítődik be.

Olyan nyelveknél, amelyek többes száma nem a darabszámot követi, kezdd a sablont `=0 ` jelöléssel. Ekkor az első alak a 0-ra vonatkozik, a többi pedig az [`Intl.PluralRules`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/PluralRules) kategóriái szerint, `zero, one, two, few, many, other` sorrendben:

```json
{
  "apples": "=0 no apples | one apple | {count} apples",
  "files": "=0 no files | {count} one | {count} few | {count} many"
}
```

```ts
$tc('apples', 0) // 'no apples'
$tc('apples', 1) // 'one apple'
$tc('apples', 7) // '7 apples'

// In `uk` (categories `one, few, many, other`) the forms after the zero form follow those categories:
$tc('files', 21) // '21 one'
$tc('files', 22) // '22 few'
$tc('files', 25) // '25 many'
$tc('files', 2.5) // '2.5 many': no form for `other`, so the last one
```

- A `=0 ` csak az érték legelején számít, a szóközzel együtt. A `$t` szövegként jeleníti meg: a többes számhoz tartozik.
- Az a kategória, amelynek nincs saját alakja, az utolsó alakot kapja. Negatív vagy tört darabszám szintén az utolsó alakot kapja.
- Bármely locale-ban működik: angolul `=0 none | one | {count} many`.
- A kategória a locale `iso` értékéből származik, egyébként a kódjából. Az `Intl` által nem ismert kód az indexszabályra esik vissza, a jelölő ekkor is eltávolításra kerül, így az eredmény sosem függ a géptől.
- Az `<i18n-t :plural>` ugyanazt a szabályt követi. Egy egyéni [`plural`](/hu/api/module-options#plural) vagy `customPluralRule` a nyers értéket kapja, a jelölővel együtt, és maga dönt; ha a `plural` `null`-t ad vissza, a hívás visszakerül a beépített szabályhoz, amely figyelembe veszi a jelölőt.

Jelölő nélkül a sablon az indexszabálynál marad, egyetlen kivétellel, amely csak egyféleképpen értelmezhető: egy helyőrző nélküli nulla alak, majd kategóriánként egy alak, `{count}`-tal minden olyan alakban, amelyen több darabszám osztozik (`no files | {count} one | {count} few | {count} many` az `uk` locale-ban).

Saját szabályokhoz állítsd be a [`plural`](/hu/api/module-options#plural) opciót.

```ts
// { "apples": "no apples | one apple | {count} apples" }
$tc('apples', 0) // 'no apples'
$tc('apples', 10) // '10 apples'
$tc('cart', { count: 2, name: 'Ada' }) // count and params in one object
```

A harmadik argumentum a `defaultValue`, nem a paraméterek.

### `$has` {#$has}

```ts
(key: string) => boolean
```

Feloldható-e egy kulcs az aktív locale-ban. Arra használd, hogy opcionális szövegek esetén elágazz ahelyett,
hogy nyers kulcsot jelenítenél meg. A `$t`-hez hasonlóan azonos locale-on belüli
oldalváltáskor az elhagyott oldal kulcsait is látja.

```ts
if ($has('promo.banner')) show.value = true
```

## Formázás {#formatting}

### `$tn` {#$tn}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Szám formázása `Intl.NumberFormat` segítségével az aktív locale-ban. Egy kulcs egy elnevezett formátumot
választ ki a konfigurációból.

Az elnevezett formátumok a [`numberFormats`](/hu/api/module-options#numberformats) opcióból származnak.

```ts
$tn(1234.5, { style: 'currency', currency: 'EUR' }) // '1.234,50 €' in de
$tn(1000, 'currency') // named format
$tn(1000, 'currency', 'de') // named format in another locale
```

### `$td` {#$td}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Dátum formázása `Intl.DateTimeFormat` segítségével az aktív locale-ban. Egy kulcs egy elnevezett formátumot
választ ki a konfigurációból.

Az elnevezett formátumok a [`datetimeFormats`](/hu/api/module-options#datetimeformats) opcióból származnak.

```ts
$td(new Date(), { dateStyle: 'long' })
$td(post.createdAt, 'short')
```

### `$tdr` {#$tdr}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

Dátum formázása relatív időként („3 napja”) az `Intl.RelativeTimeFormat` segítségével.

```ts
$tdr(Date.now() - 5 * 60_000) // '5 minutes ago' in en
```

## Váltás és linkek {#switching-and-links}

### `$switchLocale` {#$switchlocale}

```ts
(locale: string) => Promise<boolean>
```

Navigálás az aktuális oldalra egy másik locale-ban. `no_prefix` és hash mód esetén navigálás előtt betölti a
locale fordításait; `no_prefix` esetén az útvonal helyben cserélődik (nem keletkezik
új előzménybejegyzés). Az ismeretlen locale figyelmen kívül marad.
A hívás aszinkron: `await`-eld, ha a navigáció után kódot szeretnél futtatni. `true` értékkel oldódik fel, ha a
locale szótára aktív, és `false` értékkel, ha nem: a chunk betöltése sikertelen volt (a jelenlegi
szótár marad; hívd meg újra a próbálkozáshoz), vagy egy újabb váltás győzött.

```ts
await $switchLocale('de')
```

### `$switchLocalePath` {#$switchlocalepath}

```ts
(locale: string) => string
```

Az aktuális oldal útvonala egy másik locale-ban, navigálás nélkül.

```vue
<NuxtLink :to="$switchLocalePath('de')">Deutsch</NuxtLink>
```

### `$switchLocaleRoute` {#$switchlocaleroute}

```ts
(locale: string) => RouteLocationRaw
```

Az aktuális oldal route-objektuma egy másik locale-ban, navigálás nélkül, vagy egy URL-string
a saját `baseUrl`-lel rendelkező locale esetén. `trailingSlash` esetén az objektum `path` és `fullPath` mezője
a szabályt követi, a `query` és a `hash` változatlan, és a `router.push` vagy egy link megtartja őket.

### `$switchRoute` {#$switchroute}

```ts
(route: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, toLocale?: string) => Promise<void>
```

Navigálás egy másik útvonalra, az aktív locale megtartásával vagy `toLocale`-ra váltva. Aszinkron, mint a
`$switchLocale`.

```ts
$switchRoute('/about') // active locale
$switchRoute({ name: 'about' }, 'de') // switch to de
```

### `$localePath` {#$localepath}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => string
```

Útvonal feloldása a megadott locale-ban vagy az aktívban. Egy `http(s):`, `mailto:`
vagy `tel:` sémájú string változatlanul jön vissza: ne adj át ellenőrizetlenül felhasználói bemenetet link céljaként.

A string útvonal az általa megjelenített oldalként értelmeződik, így a locale egyéni útvonala is érvényesül.

```ts
$localePath('/about') // '/about' in en, '/de/ueber-uns' in de with localeRoutes
$localePath({ name: 'about' }, 'fr') // '/fr/about'
```

### `$localeRoute` {#$localeroute}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => RouteLocationResolved
```

Route feloldása a megadott locale-ban vagy az aktívban. Egyszerű objektum, biztonságosan tárolható állapotban. Ha egy paramétert
escape-elni kell, akkor `path`, `fullPath`, `query` és `hash` mezője van, de `name` és `params` nincs: a path adja meg a routernek
a kódolt URL-t. Másik domainen lévő locale esetén a `path` és a `fullPath` abszolút, amit a router nem tud fogadni:
egy ilyen link az `<i18n-link>`-en vagy a `$localePath`-on keresztül megy.

### `$getRouteName` {#$getroutename}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric, locale?: string) => string
```

Az útvonal neve a locale-előtag nélkül — ez az a név, amely alapján a fordítások kulcsolva vannak.

```ts
$getRouteName() // 'about' on /de/about
```

## Oldalkonfiguráció {#page-config}

### `$defineI18nRoute` {#$definei18nroute}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Oldalankénti locale-konfiguráció és fordítások regisztrálása egy komponensen belülről.
Az aktív locale-ba fésül össze, és a locale változásakor újra alkalmazódik.

Egy oldal `<script setup>` blokkjában hívd meg, mindig a `useNuxtApp()`-ból destrukturálva. A build a hívásból olvassa a `locales`, `localeRoutes` és `disableMeta` értékeket; futásidőben csak a `locales` számít (az inline fordítások az aktív locale-hoz fésülődnek össze). A teljes szabályok: [Oldalkonfiguráció](/hu/guide/per-component-translations).

```vue
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'de'],
  localeRoutes: { en: '/about', de: '/ueber-uns' },
})
</script>
```

### `$setI18nRouteParams` {#$seti18nrouteparams}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Locale-onkénti paraméterek beállítása az aktuális útvonalhoz, hogy egy dinamikus szegmens nyelvenként eltérhessen.
SSR közben hívd meg, mielőtt a head renderelődik.

A paraméterek törlődnek, amikor egy másik útvonalra történő navigáció véglegesül, beleértve a `/news/1` → `/news/4` váltást is, amely megtartja az útvonal nevét. Részletek: [Lokalizált útvonalak](/hu/guide/custom-locale-routes).

```ts
$setI18nRouteParams({
  en: { slug: 'my-post' },
  de: { slug: 'mein-beitrag' },
})
```

## Futásidejű fordítások {#runtime-translations}

### `$mergeTranslations` {#$mergetranslations}

```ts
(newTranslations: Translations) => void
```

Fordítások összefésülése az aktív locale-ba futásidőben, felülírva a betöltötteket.

Mélyen összefésül az aktív locale aktuális oldalchunkjába; az általa nem említett kulcsok megmaradnak.

```ts
$mergeTranslations({ banner: { title: 'Sale' } })
```

### `$setTranslation` {#$settranslation}

```ts
(key: string, value: unknown) => void
```

A `key` helyén lévő érték cseréje az aktív szótárban. Ez csere, nem összefésülés —
használd a `$mergeTranslations`-t, ha a meglévő testvérelemeknek meg kell maradniuk.

```ts
$setTranslation('banner', { title: 'Sale' }) // drops other keys under banner
$setTranslation('banner.title', 'Sale') // dotted path
```

### `$loadPageTranslations` {#$loadpagetranslations}

```ts
(locale: string, routeName: string, translations: Translations) => Promise<void>
```

Fordítások betöltése egy oldalhoz futásidőben, olyan tartalomhoz, amelynek kulcsai build-időben nem ismertek.

A memóriában lévő `(locale, routeName)` chunkba fésül össze, és a képernyő frissül, ha az a chunk aktív. Itt nem történik payload-lekérés: egy még be nem töltött oldal esetén a fordítások várakoznak, és amikor a fájlja betöltődik, felette maradnak.

```ts
await $loadPageTranslations('en', 'about', { title: 'About us' })
```

### `$resolveTranslations` {#$resolvetranslations}

```ts
() => Translations
```

Az aktív locale-hoz és útvonalhoz jelenleg a memóriában lévő összes fordítás, faként.
Csak olvasható nézet arról, amit a `$t()` éppen fel tud oldani.

Kezeld az eredményt csak olvashatóként.

### `$setMissingHandler` {#$setmissinghandler}

```ts
(handler: MissingHandler | null) => void
```

Egy callback telepítése, amely minden fel nem oldott kulcsnál meghívódik. Az eltávolításhoz adj át `null`-t.

A kezelő a fejlesztői figyelmeztetés helyett fut le.

```ts
$setMissingHandler((locale, key, routeName) => {
  console.error(`[i18n] missing ${key} in ${locale} (${routeName})`)
})
```

### `$clearCache` {#$clearcache}

```ts
() => void
```

Eldobja az összes gyorsítótárazott fordítási chunkot, és újratölti az aktuális oldal szótárát. Az oldal
továbbra is a jelenlegi fordításait mutatja, amíg a frissek meg nem érkeznek. A fejlesztői HMR
minden fordítási fájl módosításakor meghívja.

```ts
const { clearCache } = useI18n()
clearCache()
```

A sikertelen újratöltés megtartja a jelenlegi szótárat.
