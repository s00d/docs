## 🌍 Területi beállítás kezelése

Metódusok a területi beállítás információk lekéréséhez és kezeléséhez.

### `$getLocale`

{/* generated:method:$getLocale — do not edit; run `pnpm run docs:generate` */}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric) => string
```

Az aktív területi beállítás kódja. Adj át egy útvonalat annak a területi beállításnak az olvasásához, amelyhez az útvonal tartozik.

{/* /generated:method:$getLocale */}

```typescript
const locale = $getLocale()
// Output: 'en' (assuming the current locale is English)
```

{/* /generated:method:$getLocaleName */}

```typescript
const locale = $getLocaleName()
// Output: 'English'
```

## 🔍 Fordítási metódusok

Alapvető metódusok a fordítások lekéréséhez és kezeléséhez.

### `$t`

{/* generated:method:$t — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Fordíts le egy kulcsot, interpolálva a `params`-t. Visszaadja a `defaultValue`-t, ha a kulcs hiányzik, vagy magát a kulcsot, ha nincs alapértelmezés megadva.

{/* /generated:method:$t */}

```typescript
const welcomeMessage = $t('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

<Warning>
A `$t` visszaadja a `CleanTranslation` értékét, amely `string | number | boolean | Translations | PluralTranslations | null`. Ha a kulcs egy **beágyazott objektumra** mutat a JSON-ban (pl. `$t('header')`, amikor a JSON tartalma `\{ "header": \{ "title": "Hi" \} \}`), a visszatérési érték maga az **objektum** lesz, nem karakterlánc. Közvetlen használata egy Vue sablonban (<code v-pre>\{\{ $t('header') \}\}</code>) `[object Object]`-ként renderelődik.

**Hogyan kerüld el:**

- Használj konkrétabb kulcsot: `$t('header.title')` → `"Hi"`
- Használd a `$ts()`-t, amely mindig karakterláncot ad vissza (`.toString()`-et hív a nem-karakterláncokon)
- Használd a `$t`-t egy beágyazott kulccsal, ha szándékosan alobjektumokat akarsz elérni programozott használatra
</Warning>

### `$ts`

{/* generated:method:$ts — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string) => string
```

Mint a `$t`, de mindig karakterláncot ad vissza: egy objektum vagy tömb érték karakterláncosításra kerül, nem pedig úgy visszatérítve, ahogy van.

{/* /generated:method:$ts */}

```typescript
const welcomeMessage = $ts('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

### `$_t` és `$_ts`

{/* generated:method:$_t — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

A `$t` egy adott útvonalhoz kötése, az aktuális oldalon kívüli fordításhoz. Például egy elrendezéshez, amely egy másik útvonalra mutató linket renderel.

{/* /generated:method:$_t */}

{/* generated:method:$_ts — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => string
```

A `$ts` egy adott útvonalhoz kötése. Lásd a `$_t`-t.

{/* /generated:method:$_ts */}

Útvonal-kötött változatok a `$t`-hez és `$ts`-hez. Először egy **útvonalat** vesznek fel, és visszaadnak egy fordítási függvényt, amely az adott útvonal területi beállításához és oldal kontextusához van rögzítve.

- **Elérés**: `useNuxtApp()` (a `useI18n()` is újraexportálja `$_t` / `$_ts` néven)

Használd ezeket, amikor az aktív útvonal SSR vagy átmenetek során eltér a `router.currentRoute`-tól. Például az `<i18n-t>`, `<i18n-group>` belsejében, vagy amikor egy adott `route` objektumhoz tartozó tartalmat renderelsz.

```typescript
import { useRoute, useNuxtApp } from '#imports'

const route = useRoute()
const { $_t, $_ts } = useNuxtApp()

const $t = $_t(route)
const title = $t('page.title')

// String-safe variant
const label = $_ts(route)('page.label')
```


### `$tc`

{/* generated:method:$tc — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params: number | Params, defaultValue?: string) => string
```

Fordítás többes szám kezeléssel. A `params` lehet maga a szám, vagy egy `count`-ot tartalmazó objektum.

{/* /generated:method:$tc */}

**Fordítási formátum**: formák `|` karakterrel elválasztva. Tegyél helyőrzőket **minden** formába:

```json
{
  "apples": "no apples | one apple | {count} apples",
  "cart": "no items for {name} | one item for {name} | {count} items for {name}"
}
```

```typescript
$tc('apples', 0) // "no apples"
$tc('apples', 1) // "one apple"
$tc('apples', 10) // "10 apples"

// count + other params (second argument must be an object)
$tc('cart', { count: 10, name: 'Alice' }) // "10 items for Alice"
```


**Komponens alternatíva** — `<i18n-t keypath="cart" :plural="count" :params="\{ name \}" />` (belsőleg összeolvasztja a `count`-ot a `params`-szel).


### `$mergeTranslations`

{/* generated:method:$mergeTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
(newTranslations: Translations) => void
```

Fordítások összeolvasztása az aktív területi beállításba futásidőben, felülbírálva a betöltötteket.

{/* /generated:method:$mergeTranslations */}

```typescript
$mergeTranslations({
  welcome: 'Bienvenue, {username}!',
})
// Output: Updates the translation cache with the new French translation
```

### `$resolveTranslations`

{/* generated:method:$resolveTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
() => Translations
```

Minden fordítás, amely jelenleg memóriában van az aktív területi beállításhoz és útvonalhoz, mint fa. Csak olvasható nézet arról, amit a `$t()` most fel tud oldani.

{/* /generated:method:$resolveTranslations */}

```typescript
const tree = $resolveTranslations()
// { aaa: { bbb: 'ccc' }, ddd: 1111 } — the same dictionary $t() reads from
```

Használd, amikor a teljes memóriabeli szótárra van szükséged (DevTools, tesztek, futásidejű szerkesztők). Kezeld a visszatérési értéket csak olvashatóként. Az értékek módosításához használd a `$setTranslation`-t, vagy javításokat olvasz össze a `$mergeTranslations` segítségével.

### `$setTranslation`

{/* generated:method:$setTranslation — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, value: unknown) => void
```

Cseréld le a `key` értékét az aktív szótárban. Ez csere, nem összeolvasztás. Használd a `$mergeTranslations`-t, ha a meglévő testvéreknek meg kell maradniuk.

{/* /generated:method:$setTranslation */}

```typescript
$setTranslation('aaa', { fff: 'ggg' }) // replaces the whole `aaa` subtree
$setTranslation('aaa', 'text')          // replaces `aaa` with a string
$setTranslation('ddd', 1111)            // scalar at the top level
$setTranslation('aaa.bbb', 'nested')    // dotted path
```

Ez **csere**, nem összeolvasztás. Ugyanazon kulcs alatti meglévő testvérek eltávolításra kerülnek. Ahhoz, hogy javítsd testvérek elvesztése nélkül, használd a `$mergeTranslations`-t.

### `$setMissingHandler`

{/* generated:method:$setMissingHandler — do not edit; run `pnpm run docs:generate` */}

```ts
(handler: MissingHandler | null) => void
```

Egy visszahívás telepítése, amelyet minden feloldatlan kulcshoz meghívnak. Adj át `null`-t az eltávolításához.

{/* /generated:method:$setMissingHandler */}

**Típusdefiníció**:

```typescript
type MissingHandler = (locale: string, key: string, routeName: string, instance?: unknown, type?: string) => void
```

```typescript
// Set a custom handler
$setMissingHandler((locale, key, routeName) => {
  console.error(`Missing translation: ${key} in ${locale} for route ${routeName}`)
  // Send to Sentry or other error tracking service
  // Sentry.captureMessage(`Missing translation: ${key}`)
})

// Remove the handler
$setMissingHandler(null)
```

**Használati esetek**:

- Hiányzó fordítások naplózása hibakövető szolgáltatásokba (Sentry, LogRocket stb.)
- Analitika gyűjtése a hiányzó fordításokról
- Egyéni hibakezelés hiányzó fordítási kulcsokhoz

## 🔢 Szám- és dátumformázás

Metódusok a számok és dátumok formázásához a területi beállítás konvenciói szerint.

### `$tn`

{/* generated:method:$tn — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Formázz egy számot az `Intl.NumberFormat`-tal az aktív területi beállításban. Egy kulcs kiválaszt egy elnevezett formátumot a konfigurációból.

{/* /generated:method:$tn */}

```typescript
// Inline options
const formattedNumber = $tn(1234567.89, { style: 'currency', currency: 'USD' })
// "$1,234,567.89"

// Named format (from nuxt.config i18n.numberFormats)
const price = $tn(1000, 'currency')
const priceDe = $tn(1000, 'currency', 'de')
const compact = $tn(1000, 'currency', { notation: 'compact' })
```

Az ismeretlen elnevezett formátum kulcsok visszaesnek az alapértelmezett `Intl.NumberFormat` opciókra. Fejlesztésben (kliens) `console.warn` bocsátódik ki, amikor a `missingWarn` engedélyezve van (alapértelmezett).

**Konfigurációs példa**:

```ts
export default defineNuxtConfig({
  i18n: {
    numberFormats: {
      en: {
        currency: { style: 'currency', currency: 'USD' },
        decimal: { style: 'decimal', minimumFractionDigits: 2, maximumFractionDigits: 2 },
      },
      de: {
        currency: { style: 'currency', currency: 'EUR' },
      },
    },
  },
})
```

**Használati esetek**:

- Számok formázása pénznemként, százalékként vagy tizedesként a megfelelő területi formátumban
- Elnevezett formátumok újrahasznosítása az alkalmazásban (Vue I18n migráció párhuzamosság)

### `$td`

{/* generated:method:$td — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Formázz egy dátumot az `Intl.DateTimeFormat`-tal az aktív területi beállításban. Egy kulcs kiválaszt egy elnevezett formátumot a konfigurációból.

{/* /generated:method:$td */}

```typescript
const formattedDate = $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' })
// "Friday, September 1, 2023"

const short = $td(new Date(), 'short')
const longDe = $td(new Date(), 'long', 'de')
```

Az ismeretlen elnevezett formátum kulcsok visszaesnek az alapértelmezett `Intl.DateTimeFormat` opciókra. Fejlesztésben (kliens) `console.warn` bocsátódik ki, amikor a `missingWarn` engedélyezve van (alapértelmezett).

**Konfigurációs példa**:

```ts
export default defineNuxtConfig({
  i18n: {
    datetimeFormats: {
      en: {
        short: { year: 'numeric', month: 'short', day: 'numeric' },
        long: { year: 'numeric', month: 'long', day: 'numeric', weekday: 'long' },
      },
    },
  },
})
```

**Használati esetek**:

- Dátumok megjelenítése olyan formátumban, amely igazodik a felhasználó területi beállításához
- Rövid/hosszú/dátum-idő előbeállítások megosztása az alkalmazásban

### `$tdr`

{/* generated:method:$tdr — do not edit; run `pnpm run docs:generate` */}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

Formázz egy dátumot relatív időként ("3 nappal ezelőtt") az `Intl.RelativeTimeFormat` segítségével.

{/* /generated:method:$tdr */}

```typescript
const relativeDate = $tdr(new Date(Date.now() - 1000 * 60 * 5))
// Output: "5 minutes ago" in the 'en-US' locale
```

## 🔄 Útvonal és területi váltás

Metódusok a területi beállítások és útvonalak közötti váltáshoz.

### `$switchLocale`

{/* generated:method:$switchLocale — do not edit; run `pnpm run docs:generate` */}

```ts
(locale: string) => void
```

Navigálás az aktuális oldalra egy másik területi beállításban.

{/* /generated:method:$switchLocale */}

```typescript
$switchLocale('fr')
// Prefix strategies: navigates to the French version of the route
// no_prefix: updates locale and translations without changing the URL path
```

<Tip>
Lásd [GYIK — területi váltás az URL megváltoztatása nélkül](/guides/faq#-switch-locale-without-changing-the-url). Előtag stratégiák esetén használd a `$switchLocalePath()`-et, ha csak link célra van szükséged.
</Tip>

### `$switchLocaleRoute`

{/* generated:method:$switchLocaleRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(locale: string) => RouteLocationRaw
```

Az aktuális oldal útvonal objektuma egy másik területi beállításban, navigálás nélkül.

{/* /generated:method:$switchLocaleRoute */}

```typescript
// on /en/news
const routeFr = $switchLocaleRoute('fr')
```

## 🚦 Útvonal konfiguráció

Metódusok az útvonal viselkedésének és hozzáférés-vezérlésének konfigurálásához.

### `$defineI18nRoute`

{/* generated:method:$defineI18nRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Regisztrálj oldalankénti területi konfigurációt és fordításokat egy komponensen belülről. Az aktív területi beállításba olvad, és újraalkalmazódik, amikor a területi beállítás megváltozik.

{/* /generated:method:$defineI18nRoute */}

> [!IMPORTANT]
> A `$defineI18nRoute`-ot a **define plugin** biztosítja, és csak a `useNuxtApp()`-on érhető el. **Nem** része a `useI18n()` visszatérési objektumnak.
> Mindig destrukturáld ki a `useNuxtApp()`-ból a `script setup` belsejében. A `$defineI18nRoute(...)` puszta globális hívása `"$defineI18nRoute is not defined"` kivételt dob SSR/előrenderelés során.

**Paraméterek**:

- **locales**: `string[] | Record<string, Record<string, string>>` — Az útvonalhoz elérhető területi beállítások
- **localeRoutes**: `Record<string, string>` — Opcionális. Egyéni útvonalak konkrét területi beállításokhoz
- **disableMeta**: `boolean | string[]` — Opcionális. Letiltja az i18n metacímkéket az összes vagy adott területi beállításokhoz

**Alapvető példa**:

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr', 'de'],
  localeRoutes: {
    en: '/welcome',
    fr: '/bienvenue',
    de: '/willkommen',
  },
  disableMeta: false,
})
```

> 📖 **Részletes használati példákért, konfigurációs formátumokért és legjobb gyakorlatokért nézd meg a [Komponensenkénti fordítások útmutatót](/guides/per-component-translations).**

### `$setI18nRouteParams`

{/* generated:method:$setI18nRouteParams — do not edit; run `pnpm run docs:generate` */}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Területi beállításonkénti paraméterek beállítása az aktuális útvonalhoz, így egy dinamikus szegmens nyelvenként eltérhet. Hívd meg SSR során, mielőtt a head renderelődik.

{/* /generated:method:$setI18nRouteParams */}

```typescript
// in pages/news/[id].vue
// for en/news/1-first-article
const { $switchLocaleRoute, $setI18nRouteParams, $defineI18nRoute } = useNuxtApp()
$defineI18nRoute({
  localeRoutes: {
    en: '/news/:id()',
    fr: '/nouvelles/:id()',
    de: '/Nachricht/:id()',
  },
})
const { data: news } = await useAsyncData(`news-${params.id}`, async () => {
  let response = await $fetch("/api/getNews", {
    query: {
      id: params.id,
    },
  });
  if (response?.localeSlugs) {
    response.localeSlugs = {
      en: {
        id: '1-first-article'
      }
      fr: {
        id: '1-premier-article'
      }
      de: {
        id: '1-erster-Artikel'
      }
    }
    $setI18nRouteParams(response?.localeSlugs);
  }
  return response;
});
$switchLocalePath('fr') // === 'fr/nouvelles/1-premier-article'
$switchLocalePath('de') // === 'de/Nachricht/1-erster-Artikel'
```

## 🧭 `useI18nLocale` composable

A központosított composable a területi állapot kezeléshez. Használd ezt a `useState('i18n-locale')` vagy `useCookie('user-locale')` közvetlen manipulálása helyett.

```typescript
const {
  setLocale, // (locale: string) => void — updates state + cookie
  getLocale, // () => string | null — from state or cookie
  getPreferredLocale, // () => string | null — validated against locales list
  getEffectiveLocale, // (route, getLocaleFromRoute) => string
  resolveInitialLocale, // (options) => string
  isValidLocale, // (locale) => boolean
  locale, // Ref<string | null> — reactive state
  localeCookie, // CookieRef — reactive cookie
  syncLocale, // (locale) => void — sync to cookie only
  validLocales, // string[] — list of valid locale codes
} = useI18nLocale()
```

### Fő metódusok

| Metódus                 | Leírás                                                       |
| ----------------------- | ------------------------------------------------------------ |
| `setLocale(locale)`     | Beállítja a területi beállítást atomárisan a `useState`-ben és a sütiben |
| `getLocale()`           | Visszaadja az aktuális területi beállítást az állapotból vagy a sütiből |
| `getPreferredLocale()`  | Visszaadja a `locales` listával szemben érvényesített területi beállítást, vagy `null`-t |
| `isValidLocale(locale)` | Ellenőrzi, hogy egy területi kód szerepel-e a konfigurált `locales` listában |

### Használat egyéni bővítményekben

```typescript
// plugins/i18n-loader.server.ts
export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,
  setup() {
    const { setLocale } = useI18nLocale()
    // Detect locale from headers, domain, etc.
    setLocale('de')
  },
})
```
