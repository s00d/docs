# API referencia

## Futásidejű API

- [Metódusok](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, területi beállítás váltása, útválasztási segédek
- [Események](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Fordítások és gyorsítótár](/api/cache) — `TranslationStorage`, payload betöltés, `$clearCache`

## Szerver middleware

A szerverkezelők dedikált middleware-t használnak (nem a kliens `$t` segédeket):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — fordítás API útvonalakon és szerverkezelőkben
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — az észlelt területi beállítás és metaadatok olvasása

Nézd meg a teljes [Szerveroldali fordítások útmutatót](/guides/server-side-translations) a beállításhoz, a területi beállítás észlelési prioritásához és a példákhoz.
