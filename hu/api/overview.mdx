# API-referencia

## Futásidejű API

- [Metódusok](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, területi váltás, útvonal-segédek
- [Események](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Fordítások és gyorsítótár](/api/cache) — `TranslationStorage`, payload-betöltés, `$clearCache`

## Szerver middleware

A szerverkezelők dedikált middleware-t használnak (nem a kliensoldali `$t` segédeket):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — fordítás API-útvonalakban és szerverkezelőkben
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — a felismert terület és metaadatok kiolvasása

A beállításról, a területi felismerés prioritásáról és a példákról részletesen a teljes [Szerveroldali fordítások útmutatóban](/guides/server-side-translations) olvashatsz.
