Ez a szakasz felsorolja a Nuxt modul összes beállítását, segédfüggvényét, hookját, composable-jét és komponensét, valamint minden `@i18n-micro/*` csomag exportált API-ját. Használd egy szignatúra vagy alapértelmezett érték kikeresésére; az [Útmutató](/hu/guide/getting-started) elmagyarázza, hogyan kell ezeket használni. Az itteni táblázatok többsége a forráskódból generálódik, így megegyeznek a kóddal.

## Nuxt modul {#nuxt-module}

| Oldal | Tartalom |
| --- | --- |
| [Modulbeállítások](/hu/api/module-options) | Minden `i18n` kulcs a `nuxt.config`-ban, típussal és alapértelmezett értékkel |
| [Segédfüggvények](/hu/api/methods) | `$t`, `$tc`, `$tn`, `$td`, `$localePath`, `$switchLocale`, `$defineI18nRoute` és a többi |
| [Hookok](/hu/api/events) | Az `i18n:register` futásidejű hook |

## Composable-ök {#composables}

| Composable | Mire használd |
| --- | --- |
| [`useI18n`](/hu/composables/useI18n) | A segédfüggvények a `<script setup>`-ban |
| [`useI18nLocale`](/hu/composables/useI18nLocale) | Locale-állapot és cookie egy egyéni felismerő pluginban |
| [`useI18nHead`](/hu/composables/useI18nHead) | A generált SEO-címkék oldalankénti felülírása |
| [`useLocaleHead`](/hu/composables/useLocaleHead) | A SEO-címkék objektumként, a saját `useHead` hívásodhoz |

## Komponensek {#components}

| Komponens | Mit renderel |
| --- | --- |
| [`<i18n-t>`](/hu/components/i18n-t) | Egy fordítást, többes számmal, formázással és slot-interpolációval |
| [`<i18n-link>`](/hu/components/i18n-link) | Egy `NuxtLink`-et a lokalizált útvonalra |
| [`<i18n-switcher>`](/hu/components/i18n-switcher) | Egy locale-választó legördülő menüt |
| [`<i18n-group>`](/hu/components/i18n-group) | Egy blokkot közös kulcselőtaggal |

## Szerver {#server}

A Nitro handlerek a `useTranslationServerMiddleware` és a `useLocaleServerMiddleware` függvényeket használják, nem a kliensoldali segédfüggvényeket. Lásd: [Szerver útvonalak](/hu/guide/server-side-translations).

## Csomagok {#packages}

A [Csomag-API-k](/hu/api/packages/overview) oldal felsorolja minden `@i18n-micro/*` csomag exportjait, mindegyikhez egy generált oldallal.
