# 🛠️ Phương thức

Trang này ghi lại tất cả các phương thức có sẵn do nuxt-i18n-micro cung cấp. Các phương thức được tổ chức theo chức năng để dễ điều hướng.

## 📊 Tổng quan API

Mọi trợ giúp mà plugin tiêm vào, được đọc từ interface `PluginsInjections`. Vì vậy danh sách này không thể lệch khỏi những gì thực sự có sẵn.

### `$getI18nConfig`

{/* generated:method:$getI18nConfig — do not edit; run `pnpm run docs:generate` */}

```ts
() => ModuleOptionsExtend
```

Cấu hình mô-đun đã phân giải, theo cách runtime nhìn nhận.

{/* /generated:method:$getI18nConfig */}

```typescript
const nuxtApp = useNuxtApp()
const { localeCookie, strategy, hooks } = nuxtApp.$getI18nConfig()
```

Với ngữ cảnh thời điểm build hoặc không phải Nuxt, hãy dùng `getI18nConfig()` từ `#build/i18n.strategy.mjs` thay thế.

<Info>
`serverTranslationPreload` là một tùy chọn mô-đun riêng tư chỉ được lộ trong cấu hình riêng tư của server (`#i18n-internal/config`). Nó không phải là một phần của API runtime công khai và có thể thay đổi mà không báo trước.
</Info>

## 🔍 Phương thức dịch

Các phương thức cốt lõi để truy xuất và quản lý bản dịch.

### `$t`

{/* generated:method:$t — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Dịch một khóa, nội suy `params` vào đó. Trả về `defaultValue` khi khóa bị thiếu,
hoặc chính khóa đó khi không có giá trị mặc định.

{/* /generated:method:$t */}

```typescript
const welcomeMessage = $t('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

<Warning>
`$t` trả về `CleanTranslation` tức là `string | number | boolean | Translations | PluralTranslations | null`. Nếu khóa trỏ đến một **đối tượng lồng nhau** trong JSON của bạn (ví dụ `$t('header')` khi JSON chứa `\{ "header": \{ "title": "Hi" \} \}`), giá trị trả về sẽ là **đối tượng** đó, không phải chuỗi. Dùng trực tiếp trong template Vue (<code v-pre>\{\{ $t('header') \}\}</code>) sẽ hiển thị là `[object Object]`.

**Cách tránh:**

- Dùng khóa cụ thể hơn: `$t('header.title')` → `"Hi"`
- Dùng `$ts()` luôn trả về chuỗi (gọi `.toString()` với giá trị không phải chuỗi)
- Dùng `$t` với khóa lồng nhau khi cố ý truy cập các đối tượng con cho mục đích lập trình
</Warning>

### `$ts`

{/* generated:method:$ts — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string) => string
```

Giống `$t`, nhưng luôn trả về chuỗi: một giá trị đối tượng hoặc mảng sẽ được chuyển thành chuỗi thay vì trả về nguyên trạng.

{/* /generated:method:$ts */}

```typescript
const welcomeMessage = $ts('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

### `$_t` và `$_ts`

{/* generated:method:$_t — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Gắn `$t` với một route cụ thể, để dịch bên ngoài trang hiện tại. Ví dụ, một layout hiển thị
liên kết đến một route khác.

{/* /generated:method:$_t */}

{/* generated:method:$_ts — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => string
```

Gắn `$ts` với một route cụ thể. Xem `$_t`.

{/* /generated:method:$_ts */}

Các biến thể gắn với route của `$t` và `$ts`. Chúng nhận **route** trước và trả về một hàm dịch bị khóa theo ngôn ngữ và ngữ cảnh trang của route đó.

- **Truy cập**: `useNuxtApp()` (cũng được `useI18n()` tái xuất dưới dạng `$_t` / `$_ts`)

Dùng chúng khi route đang hoạt động trong SSR hoặc trong các quá trình chuyển tiếp khác với `router.currentRoute`. Ví dụ, bên trong `<i18n-t>`, `<i18n-group>`, hoặc khi hiển thị nội dung cho một đối tượng `route` cụ thể.

```typescript
import { useRoute, useNuxtApp } from '#imports'

const route = useRoute()
const { $_t, $_ts } = useNuxtApp()

const $t = $_t(route)
const title = $t('page.title')

// String-safe variant
const label = $_ts(route)('page.label')
```


### `$tc`

{/* generated:method:$tc — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params: number | Params, defaultValue?: string) => string
```

Dịch có xử lý số nhiều. `params` có thể chính là số lượng, hoặc một đối tượng chứa
`count`.

{/* /generated:method:$tc */}

**Định dạng bản dịch**: các dạng được ngăn cách bằng `|`. Đặt placeholder trong **mỗi** dạng:

```json
{
  "apples": "no apples | one apple | {count} apples",
  "cart": "no items for {name} | one item for {name} | {count} items for {name}"
}
```

```typescript
$tc('apples', 0) // "no apples"
$tc('apples', 1) // "one apple"
$tc('apples', 10) // "10 apples"

// count + other params (second argument must be an object)
$tc('cart', { count: 10, name: 'Alice' }) // "10 items for Alice"
```


**Thay thế bằng thành phần** — `<i18n-t keypath="cart" :plural="count" :params="\{ name \}" />` (gộp nội bộ `count` với `params`).


### `$mergeTranslations`

{/* generated:method:$mergeTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
(newTranslations: Translations) => void
```

Hợp nhất bản dịch vào ngôn ngữ đang hoạt động tại runtime, ghi đè những gì đã tải.

{/* /generated:method:$mergeTranslations */}

```typescript
$mergeTranslations({

// Output: Updates the translation cache with the new French translation
```

### `$resolveTranslations`

{/* generated:method:$resolveTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
() => Translations
```

Mọi bản dịch hiện đang trong bộ nhớ cho ngôn ngữ và route đang hoạt động, dưới dạng cây.
Chế độ xem chỉ đọc của những gì `$t()` có thể phân giải ngay bây giờ.

{/* /generated:method:$resolveTranslations */}

```typescript
const tree = $resolveTranslations()
// { aaa: { bbb: 'ccc' }, ddd: 1111 } — the same dictionary $t() reads from
```

Dùng nó khi bạn cần từ điển đầy đủ trong bộ nhớ (DevTools, kiểm thử, trình chỉnh sửa runtime). Hãy coi giá trị trả về là chỉ đọc; thay đổi giá trị thông qua `$setTranslation` hoặc hợp nhất các bản vá bằng `$mergeTranslations`.

### `$setTranslation`

{/* generated:method:$setTranslation — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, value: unknown) => void
```

Thay thế giá trị tại `key` trong từ điển đang hoạt động. Đây là thay thế, không phải gộp.
Dùng `$mergeTranslations` khi các nhánh anh chị em hiện có cần được giữ lại.

{/* /generated:method:$setTranslation */}

```typescript
$setTranslation('aaa', { fff: 'ggg' }) // replaces the whole `aaa` subtree
$setTranslation('aaa', 'text')          // replaces `aaa` with a string
$setTranslation('ddd', 1111)            // scalar at the top level
$setTranslation('aaa.bbb', 'nested')    // dotted path
```

Đây là **thay thế**, không phải gộp. Các nhánh anh chị em hiện có dưới cùng khóa sẽ bị xóa. Để vá mà không mất các nhánh anh chị em, hãy dùng `$mergeTranslations`.

### `$setMissingHandler`

{/* generated:method:$setMissingHandler — do not edit; run `pnpm run docs:generate` */}

```ts
(handler: MissingHandler | null) => void
```

Cài đặt một callback được gọi cho mọi khóa không phân giải được. Truyền `null` để xóa nó.

{/* /generated:method:$setMissingHandler */}

**Định nghĩa kiểu**:

```typescript
type MissingHandler = (locale: string, key: string, routeName: string, instance?: unknown, type?: string) => void
```

```typescript
// Set a custom handler
$setMissingHandler((locale, key, routeName) => {
  console.error(`Missing translation: ${key} in ${locale} for route ${routeName}`)
  // Send to Sentry or other error tracking service
  // Sentry.captureMessage(`Missing translation: ${key}`)
})

// Remove the handler
$setMissingHandler(null)
```

**Trường hợp sử dụng**:

- Ghi log các bản dịch bị thiếu vào dịch vụ theo dõi lỗi (Sentry, LogRocket, v.v.)
- Thu thập phân tích về các bản dịch bị thiếu
- Xử lý lỗi tùy chỉnh cho các khóa bản dịch bị thiếu

## 🔢 Định dạng số & ngày

Các phương thức để định dạng số và ngày theo quy ước ngôn ngữ.

### `$tn`

{/* generated:method:$tn — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Định dạng số với `Intl.NumberFormat` trong ngôn ngữ đang hoạt động. Một khóa chọn một định dạng có tên
từ cấu hình.

{/* /generated:method:$tn */}

```typescript
// Inline options
const formattedNumber = $tn(1234567.89, { style: 'currency', currency: 'USD' })
// "$1,234,567.89"

// Named format (from nuxt.config i18n.numberFormats)
const price = $tn(1000, 'currency')
const priceDe = $tn(1000, 'currency', 'de')
const compact = $tn(1000, 'currency', { notation: 'compact' })
```

Các khóa định dạng có tên không xác định sẽ dùng tùy chọn `Intl.NumberFormat` mặc định. Trong môi trường phát triển (client), một `console.warn` sẽ được phát khi bật `missingWarn` (mặc định).

**Ví dụ cấu hình**:

```ts
export default defineNuxtConfig({
  i18n: {
    numberFormats: {
      en: {
        currency: { style: 'currency', currency: 'USD' },
        decimal: { style: 'decimal', minimumFractionDigits: 2, maximumFractionDigits: 2 },
      },
      de: {
        currency: { style: 'currency', currency: 'EUR' },
      },
    },
  },
})
```

**Trường hợp sử dụng**:

- Định dạng số dưới dạng tiền tệ, phần trăm hoặc thập phân theo đúng định dạng ngôn ngữ
- Tái sử dụng các định dạng có tên trên toàn ứng dụng (tương đương với việc di chuyển từ Vue I18n)

### `$td`

{/* generated:method:$td — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Định dạng ngày với `Intl.DateTimeFormat` trong ngôn ngữ đang hoạt động. Một khóa chọn một định dạng có tên
từ cấu hình.

{/* /generated:method:$td */}

```typescript
const formattedDate = $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' })
// "Friday, September 1, 2023"

const short = $td(new Date(), 'short')
const longDe = $td(new Date(), 'long', 'de')
```

Các khóa định dạng có tên không xác định sẽ dùng tùy chọn `Intl.DateTimeFormat` mặc định. Trong môi trường phát triển (client), một `console.warn` sẽ được phát khi bật `missingWarn` (mặc định).

**Ví dụ cấu hình**:

```ts
export default defineNuxtConfig({
  i18n: {
    datetimeFormats: {
      en: {
        short: { year: 'numeric', month: 'short', day: 'numeric' },
        long: { year: 'numeric', month: 'long', day: 'numeric', weekday: 'long' },
      },
    },
  },
})
```

**Trường hợp sử dụng**:

## 🚦 Cấu hình route

Các phương thức để cấu hình hành vi của route và kiểm soát truy cập.

### `$defineI18nRoute`

{/* generated:method:$defineI18nRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Đăng ký cấu hình ngôn ngữ và bản dịch theo trang từ bên trong một thành phần.
Hợp nhất vào ngôn ngữ đang hoạt động và áp dụng lại khi ngôn ngữ thay đổi.

{/* /generated:method:$defineI18nRoute */}

> [!IMPORTANT]
> `$defineI18nRoute` được cung cấp bởi **define plugin** và chỉ có sẵn trên `useNuxtApp()`. Nó **không** phải là một phần của đối tượng trả về từ `useI18n()`.
> Luôn destructure nó từ `useNuxtApp()` bên trong `script setup`. Gọi `$defineI18nRoute(...)` như một biến toàn cục trần sẽ ném lỗi `"$defineI18nRoute is not defined"` trong SSR/prerender.

**Tham số**:

- **locales**: `string[] | Record<string, Record<string, string>>` — Các ngôn ngữ khả dụng cho route
- **localeRoutes**: `Record<string, string>` — Tùy chọn. Các route tùy chỉnh cho các ngôn ngữ cụ thể
- **disableMeta**: `boolean | string[]` — Tùy chọn. Tắt các thẻ meta i18n cho tất cả hoặc các ngôn ngữ cụ thể

**Ví dụ cơ bản**:

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr', 'de'],
  localeRoutes: {
    en: '/welcome',
    fr: '/bienvenue',
    de: '/willkommen',
  },
  disableMeta: false,
})
```

> 📖 **Để xem các ví dụ sử dụng chi tiết, định dạng cấu hình và thực hành tốt nhất, xem [Hướng dẫn bản dịch theo từng thành phần](/guides/per-component-translations).**

### `$setI18nRouteParams`

{/* generated:method:$setI18nRouteParams — do not edit; run `pnpm run docs:generate` */}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Đặt tham số theo ngôn ngữ cho route hiện tại, để một segment động có thể khác nhau theo ngôn ngữ.
Gọi nó trong SSR, trước khi head được render.

{/* /generated:method:$setI18nRouteParams */}

```typescript
// in pages/news/[id].vue
// for en/news/1-first-article
const { $switchLocaleRoute, $setI18nRouteParams, $defineI18nRoute } = useNuxtApp()
$defineI18nRoute({
  localeRoutes: {
    en: '/news/:id()',
    fr: '/nouvelles/:id()',
    de: '/Nachricht/:id()',
  },
})
const { data: news } = await useAsyncData(`news-${params.id}`, async () => {
  let response = await $fetch("/api/getNews", {
    query: {
      id: params.id,
    },
  });
  if (response?.localeSlugs) {
    response.localeSlugs = {
      en: {
        id: '1-first-article'
      }
      fr: {
        id: '1-premier-article'
      }
      de: {
        id: '1-erster-Artikel'
      }
    }
    $setI18nRouteParams(response?.localeSlugs);
  }
  return response;
});
$switchLocalePath('fr') // === 'fr/nouvelles/1-premier-article'
$switchLocalePath('de') // === 'de/Nachricht/1-erster-Artikel'
```

## 🧭 Composable `useI18nLocale`

Composable tập trung để quản lý trạng thái ngôn ngữ. Hãy dùng nó thay vì thao tác trực tiếp với `useState('i18n-locale')` hoặc `useCookie('user-locale')`.

```typescript
const {
  setLocale, // (locale: string) => void — updates state + cookie
  getLocale, // () => string | null — from state or cookie
  getPreferredLocale, // () => string | null — validated against locales list
  getEffectiveLocale, // (route, getLocaleFromRoute) => string
  resolveInitialLocale, // (options) => string
  isValidLocale, // (locale) => boolean
  locale, // Ref<string | null> — reactive state
  localeCookie, // CookieRef — reactive cookie
  syncLocale, // (locale) => void — sync to cookie only
  validLocales, // string[] — list of valid locale codes
} = useI18nLocale()
```

### Các phương thức chính

| Phương thức | Mô tả |
| ----------------------- | ----------------------------------------------------------- |
| `setLocale(locale)`     | Đặt ngôn ngữ trong cả `useState` và cookie một cách nguyên tử |
| `getLocale()`           | Trả về ngôn ngữ hiện tại từ state hoặc cookie |
| `getPreferredLocale()`  | Trả về ngôn ngữ được xác thực với danh sách `locales`, hoặc `null` |
| `isValidLocale(locale)` | Kiểm tra một mã ngôn ngữ có nằm trong danh sách `locales` đã cấu hình hay không |
