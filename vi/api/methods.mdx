Module inject các helper runtime vào ứng dụng Nuxt: `$t`, `$tc`, `$localePath`, `$switchLocale` và các helper khác. Hãy dùng trang này để tra cứu chữ ký và hành vi của một helper. Chữ ký và mô tả được lấy từ các interface `PluginsInjections` và `NuxtAppOnlyInjections` trong `src/runtime/plugins/01.plugin.ts`.

## Truy cập {#access}

| Ở đâu | Cách nào |
| --- | --- |
| Template | `{{ $t('title') }}` — mọi helper, có `$` |
| `<script setup>` | `const { t, localePath } = useI18n()` — mọi helper trong `PluginsInjections`, có và không có `$` |
| Plugin, middleware, `<script setup>` | `const { $t, $defineI18nRoute } = useNuxtApp()` — tất cả, chỉ có `$` |

`$defineI18nRoute` chỉ được khai báo kiểu trên `useNuxtApp()`. Xem [`useI18n`](/vi/composables/useI18n).

```vue
<script setup lang="ts">
const { t, localePath } = useI18n()
</script>

<template>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
</template>
```

## Locale {#locale}

### `$getLocale` {#$getlocale}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric) => string
```

Mã của locale đang hoạt động. Truyền một route để đọc locale mà route đó thuộc về.

```ts
$getLocale() // 'de' on /de/about
```

### `$getLocaleName` {#$getlocalename}

```ts
() => string | null
```

`displayName` của locale đang hoạt động từ cấu hình, hoặc `null` nếu không có.

### `$getLocales` {#$getlocales}

```ts
() => Locale[]
```

Mọi locale đã cấu hình, kèm metadata của chúng.

Các thuộc tính tùy chỉnh trên đối tượng locale được trả về đúng như khi viết; khai báo kiểu cho chúng bằng [module augmentation](/vi/api/module-options#locales) của `Locale`.

### `$defaultLocale` {#$defaultlocale}

```ts
() => string | undefined
```

Mã của locale mặc định đã cấu hình.

### `$getI18nConfig` {#$geti18nconfig}

```ts
() => ResolvedI18nConfig
```

Cấu hình module đã được phân giải, theo cách runtime nhìn thấy.

Giá trị này bao gồm các [ghi đè runtime](/vi/guide/runtime-overrides) (`defaultLocale`, `fallbackLocale`, các locale bị vô hiệu hóa).

```ts
const { strategy, localeCookie } = useNuxtApp().$getI18nConfig()
```

## Dịch {#translation}

### `$t` {#$t}

```ts
TranslationFn<CleanTranslation>
```

Dịch một khóa, nội suy `params` vào đó. Trả về `defaultValue` khi khóa bị thiếu,
hoặc chính khóa đó khi không có giá trị mặc định.

```ts
// { "welcome": "Welcome, {name}!" }
$t('welcome', { name: 'Ada' }) // 'Welcome, Ada!'
$t('missing.key', {}, 'Fallback') // 'Fallback'
```

Một khóa trỏ tới đối tượng lồng nhau sẽ trả về đối tượng đó, không phải chuỗi. Trong template nó hiển thị thành `[object Object]`; hãy dùng khóa lá.

### `$ts` {#$ts}

```ts
TranslationFn<string>
```

Giống `$t`, nhưng luôn trả về chuỗi: giá trị đi qua `toString()`, nên một đối tượng
lồng nhau trở thành `'[object Object]'`. Hãy trỏ khóa tới một lá.

### `$_t` {#$_t}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<CleanTranslation>
```

Gắn `$t` với một route cụ thể, để dịch bên ngoài trang hiện tại — ví dụ một layout hiển thị
liên kết tới route khác.

```ts
const route = useRoute()
const t = useNuxtApp().$_t(route)
t('page.title')
```

### `$_ts` {#$_ts}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<string>
```

Gắn `$ts` với một route cụ thể. Xem `$_t`.

### `$tc` {#$tc}

```ts
(key: TranslationKey, params: number | Params, defaultValue?: string) => string
```

Dịch có chia số nhiều. `params` có thể là chính số đếm, hoặc một đối tượng chứa
`count`.

Các dạng được phân tách bằng `|`. Với quy tắc tích hợp sẵn, một số đếm nguyên không âm `n` chọn dạng thứ `n`, giới hạn ở dạng cuối cùng; số đếm âm, số thập phân hoặc `NaN` lấy dạng cuối cùng. `{count}` và các tham số khác được nội suy vào dạng được chọn.

Với những ngôn ngữ có số nhiều không theo số đếm, hãy bắt đầu template bằng `=0 `. Khi đó dạng đầu tiên dành cho 0, và các dạng còn lại theo category của [`Intl.PluralRules`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/PluralRules), theo thứ tự `zero, one, two, few, many, other`:

```json
{
  "apples": "=0 no apples | one apple | {count} apples",
  "files": "=0 no files | {count} one | {count} few | {count} many"
}
```

```ts
$tc('apples', 0) // 'no apples'
$tc('apples', 1) // 'one apple'
$tc('apples', 7) // '7 apples'

// In `uk` (categories `one, few, many, other`) the forms after the zero form follow those categories:
$tc('files', 21) // '21 one'
$tc('files', 22) // '22 few'
$tc('files', 25) // '25 many'
$tc('files', 2.5) // '2.5 many': no form for `other`, so the last one
```

- `=0 ` chỉ có tác dụng ở ngay đầu giá trị, kèm dấu cách. `$t` hiển thị nó như văn bản: nó thuộc về số nhiều.
- Một category không có dạng riêng sẽ lấy dạng cuối cùng. Số đếm âm hoặc thập phân cũng lấy dạng cuối cùng.
- Nó hoạt động trong mọi locale: `=0 none | one | {count} many` trong tiếng Anh.
- Category được lấy từ `iso` của locale, nếu không thì từ mã của nó. Một mã mà `Intl` không biết sẽ quay về quy tắc chỉ số, dấu đánh dấu vẫn bị loại bỏ, nên kết quả không bao giờ phụ thuộc vào máy.
- `<i18n-t :plural>` tuân theo cùng quy tắc. Một [`plural`](/vi/api/module-options#plural) tùy chỉnh hoặc `customPluralRule` nhận giá trị thô, bao gồm cả dấu đánh dấu, và tự quyết định; `plural` trả về `null` sẽ trả lời gọi lại cho quy tắc tích hợp sẵn, vốn tôn trọng dấu đánh dấu.

Không có dấu đánh dấu, template vẫn theo quy tắc chỉ số, với một ngoại lệ chỉ có thể hiểu theo một cách: một dạng zero không có placeholder, sau đó mỗi category một dạng, với `{count}` trong mỗi dạng mà nhiều số đếm dùng chung (`no files | {count} one | {count} few | {count} many` trong `uk`).

Để dùng quy tắc của riêng bạn, hãy đặt [`plural`](/vi/api/module-options#plural).

```ts
// { "apples": "no apples | one apple | {count} apples" }
$tc('apples', 0) // 'no apples'
$tc('apples', 10) // '10 apples'
$tc('cart', { count: 2, name: 'Ada' }) // count and params in one object
```

Đối số thứ ba là `defaultValue`, không phải params.

### `$has` {#$has}

```ts
(key: string) => boolean
```

Liệu một khóa có phân giải được trong locale đang hoạt động hay không. Dùng nó để rẽ nhánh cho nội dung tùy chọn thay vì
hiển thị một khóa thô. Giống `$t`, nó cũng thấy các khóa của trang đang rời đi trong quá trình chuyển trang cùng
locale.

```ts
if ($has('promo.banner')) show.value = true
```

## Định dạng {#formatting}

### `$tn` {#$tn}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Định dạng số bằng `Intl.NumberFormat` trong locale đang hoạt động. Một khóa chọn một định dạng có tên
từ cấu hình.

Các định dạng có tên đến từ [`numberFormats`](/vi/api/module-options#numberformats).

```ts
$tn(1234.5, { style: 'currency', currency: 'EUR' }) // '1.234,50 €' in de
$tn(1000, 'currency') // named format
$tn(1000, 'currency', 'de') // named format in another locale
```

### `$td` {#$td}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Định dạng ngày bằng `Intl.DateTimeFormat` trong locale đang hoạt động. Một khóa chọn một định dạng có tên
từ cấu hình.

Các định dạng có tên đến từ [`datetimeFormats`](/vi/api/module-options#datetimeformats).

```ts
$td(new Date(), { dateStyle: 'long' })
$td(post.createdAt, 'short')
```

### `$tdr` {#$tdr}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

Định dạng ngày dưới dạng thời gian tương đối ("3 ngày trước") bằng `Intl.RelativeTimeFormat`.

```ts
$tdr(Date.now() - 5 * 60_000) // '5 minutes ago' in en
```

## Chuyển đổi và liên kết {#switching-and-links}

### `$switchLocale` {#$switchlocale}

```ts
(locale: string) => Promise<boolean>
```

Điều hướng tới trang hiện tại trong một locale khác. Với `no_prefix` và chế độ hash, nó tải
bản dịch của locale trước khi điều hướng; với `no_prefix`, route được thay thế tại chỗ (không
tạo mục lịch sử mới). Một locale không xác định sẽ bị bỏ qua.
Lời gọi là bất đồng bộ: hãy `await` nó để chạy mã sau khi điều hướng. Nó resolve `true` khi
từ điển của locale đang hoạt động, `false` khi không: chunk tải thất bại (từ điển hiện tại
được giữ nguyên; gọi lại để thử lại) hoặc một lần chuyển mới hơn đã thắng.

```ts
await $switchLocale('de')
```

### `$switchLocalePath` {#$switchlocalepath}

```ts
(locale: string) => string
```

Đường dẫn của trang hiện tại trong một locale khác, không điều hướng.

```vue
<NuxtLink :to="$switchLocalePath('de')">Deutsch</NuxtLink>
```

### `$switchLocaleRoute` {#$switchlocaleroute}

```ts
(locale: string) => RouteLocationRaw
```

Đối tượng route của trang hiện tại trong một locale khác, không điều hướng, hoặc một chuỗi URL
cho locale có `baseUrl` riêng. Với `trailingSlash`, đối tượng có `path` và `fullPath`
theo quy tắc, với `query` và `hash` giữ nguyên, và `router.push` hoặc một liên kết sẽ giữ chúng.

### `$switchRoute` {#$switchroute}

```ts
(route: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, toLocale?: string) => Promise<void>
```

Điều hướng tới một route khác, giữ locale đang hoạt động hoặc chuyển sang `toLocale`. Bất đồng bộ giống
`$switchLocale`.

```ts
$switchRoute('/about') // active locale
$switchRoute({ name: 'about' }, 'de') // switch to de
```

### `$localePath` {#$localepath}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => string
```

Phân giải một đường dẫn trong locale được chỉ định, hoặc locale đang hoạt động. Một chuỗi có scheme `http(s):`, `mailto:`
hoặc `tel:` được trả về nguyên trạng: đừng truyền dữ liệu người dùng làm đích liên kết khi chưa kiểm tra.

Một đường dẫn dạng chuỗi được hiểu là trang mà nó hiển thị, nên đường dẫn tùy chỉnh của locale cũng được áp dụng.

```ts
$localePath('/about') // '/about' in en, '/de/ueber-uns' in de with localeRoutes
$localePath({ name: 'about' }, 'fr') // '/fr/about'
```

### `$localeRoute` {#$localeroute}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => RouteLocationResolved
```

Phân giải một route trong locale được chỉ định, hoặc locale đang hoạt động. Một đối tượng thuần, an toàn để giữ trong state. Khi một tham số cần
escape, nó có `path`, `fullPath`, `query` và `hash` nhưng không có `name` hay `params`: đường dẫn là thứ cung cấp cho router
URL đã mã hóa. Với một locale trên domain khác, `path` và `fullPath` là tuyệt đối, điều mà router không chấp nhận:
liên kết như vậy phải đi qua `<i18n-link>`, hoặc `$localePath`.

### `$getRouteName` {#$getroutename}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric, locale?: string) => string
```

Tên route đã bỏ tiền tố locale — tên được dùng làm khóa cho bản dịch.

```ts
$getRouteName() // 'about' on /de/about
```

## Cấu hình trang {#page-config}

### `$defineI18nRoute` {#$definei18nroute}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Đăng ký cấu hình locale và bản dịch cho từng trang từ bên trong một component.
Hợp nhất vào locale đang hoạt động và áp dụng lại khi locale thay đổi.

Gọi nó trong `<script setup>` của một trang, luôn được destructure từ `useNuxtApp()`. Quá trình build đọc `locales`, `localeRoutes` và `disableMeta` từ lời gọi; lúc runtime chỉ `locales` có ý nghĩa (bản dịch inline được hợp nhất cho locale đang hoạt động). Quy tắc đầy đủ: [Cấu hình trang](/vi/guide/per-component-translations).

```vue
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'de'],
  localeRoutes: { en: '/about', de: '/ueber-uns' },
})
</script>
```

### `$setI18nRouteParams` {#$seti18nrouteparams}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Đặt tham số theo từng locale cho route hiện tại, để một segment động có thể khác nhau theo ngôn ngữ.
Gọi nó trong SSR, trước khi head được render.

Các tham số bị xóa khi một lần điều hướng tới đường dẫn khác được commit, kể cả `/news/1` sang `/news/4`, vốn giữ nguyên tên route. Chi tiết: [Đường dẫn bản địa hóa](/vi/guide/custom-locale-routes).

```ts
$setI18nRouteParams({
  en: { slug: 'my-post' },
  de: { slug: 'mein-beitrag' },
})
```

## Bản dịch lúc runtime {#runtime-translations}

### `$mergeTranslations` {#$mergetranslations}

```ts
(newTranslations: Translations) => void
```

Hợp nhất bản dịch vào locale đang hoạt động lúc runtime, ghi đè lên những gì đã tải.

Hợp nhất sâu vào chunk trang hiện tại của locale đang hoạt động; các khóa không được nhắc đến vẫn được giữ lại.

```ts
$mergeTranslations({ banner: { title: 'Sale' } })
```

### `$setTranslation` {#$settranslation}

```ts
(key: string, value: unknown) => void
```

Thay thế giá trị tại `key` trong từ điển đang hoạt động. Đây là thay thế, không phải hợp nhất —
hãy dùng `$mergeTranslations` khi các khóa anh em hiện có cần được giữ lại.

```ts
$setTranslation('banner', { title: 'Sale' }) // drops other keys under banner
$setTranslation('banner.title', 'Sale') // dotted path
```

### `$loadPageTranslations` {#$loadpagetranslations}

```ts
(locale: string, routeName: string, translations: Translations) => Promise<void>
```

Tải bản dịch cho một trang lúc runtime, cho nội dung có khóa không biết trước lúc build.

Hợp nhất vào chunk `(locale, routeName)` trong bộ nhớ, và màn hình cập nhật khi chunk đó đang hoạt động. Không có payload nào được tải ở đây: với một trang chưa được tải, các bản dịch sẽ chờ, và khi tệp của nó tải xong chúng vẫn nằm trên cùng.

```ts
await $loadPageTranslations('en', 'about', { title: 'About us' })
```

### `$resolveTranslations` {#$resolvetranslations}

```ts
() => Translations
```

Mọi bản dịch hiện có trong bộ nhớ cho locale và route đang hoạt động, dưới dạng cây.
Chế độ xem chỉ đọc về những gì `$t()` có thể phân giải ngay lúc này.

Hãy coi kết quả là chỉ đọc.

### `$setMissingHandler` {#$setmissinghandler}

```ts
(handler: MissingHandler | null) => void
```

Cài đặt một callback được gọi cho mỗi khóa không phân giải được. Truyền `null` để gỡ bỏ nó.

Handler chạy thay cho cảnh báo dev.

```ts
$setMissingHandler((locale, key, routeName) => {
  console.error(`[i18n] missing ${key} in ${locale} (${routeName})`)
})
```

### `$clearCache` {#$clearcache}

```ts
() => void
```

Xóa mọi chunk bản dịch đã cache và tải lại từ điển của trang hiện tại. Trang
vẫn hiển thị bản dịch hiện tại cho đến khi bản mới đến. HMR trong dev gọi nó mỗi khi
một tệp bản dịch thay đổi.

```ts
const { clearCache } = useI18n()
clearCache()
```

Một lần tải lại thất bại sẽ giữ nguyên từ điển hiện tại.
