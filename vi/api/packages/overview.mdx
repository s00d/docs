# API các gói

`nuxt-i18n-micro` được xây dựng từ một tập hợp các gói nhỏ, hầu hết đều có thể sử dụng
độc lập — `@i18n-micro/vue` trong một ứng dụng Vue thuần, `@i18n-micro/core` ở bất kỳ đâu.

Mỗi trang bên dưới được tạo từ snapshot API mà
[`pnpm run api:surface`](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/maintenance-commands.md#api-surface) kiểm tra so với các
mã nguồn TypeScript, nên một export không thể biến mất mà không có tham chiếu này thay đổi
hoặc CI thất bại.
