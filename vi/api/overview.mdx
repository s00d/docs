# Tham chiếu API

## API Runtime

- [Phương thức](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, chuyển đổi locale, các trình trợ giúp định tuyến
- [Sự kiện](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Bản dịch và Cache](/api/cache) — `TranslationStorage`, tải payload, `$clearCache`

## Server middleware

Các server handler dùng middleware chuyên biệt (không phải các trình trợ giúp `$t` phía client):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — dịch trong các route API và server handler
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — đọc locale được phát hiện và metadata

Xem [hướng dẫn Bản dịch phía server](/guides/server-side-translations) đầy đủ để biết thiết lập, ưu tiên phát hiện locale và các ví dụ.
