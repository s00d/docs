Phần này liệt kê mọi tùy chọn, helper, hook, composable và component của module Nuxt, cùng với API được export của từng package `@i18n-micro/*`. Hãy dùng nó để tra cứu chữ ký hàm hoặc giá trị mặc định; phần [Hướng dẫn](/vi/guide/getting-started) giải thích cách sử dụng chúng. Phần lớn các bảng ở đây được tạo tự động từ mã nguồn, nên chúng khớp với code.

## Module Nuxt {#nuxt-module}

| Trang | Nội dung |
| --- | --- |
| [Tùy chọn module](/vi/api/module-options) | Mọi khóa `i18n` trong `nuxt.config`, kèm kiểu và giá trị mặc định |
| [Helper](/vi/api/methods) | `$t`, `$tc`, `$tn`, `$td`, `$localePath`, `$switchLocale`, `$defineI18nRoute` và các helper khác |
| [Hook](/vi/api/events) | Hook runtime `i18n:register` |

## Composable {#composables}

| Composable | Dùng để |
| --- | --- |
| [`useI18n`](/vi/composables/useI18n) | Các helper trong `<script setup>` |
| [`useI18nLocale`](/vi/composables/useI18nLocale) | Trạng thái locale và cookie trong plugin phát hiện tùy chỉnh |
| [`useI18nHead`](/vi/composables/useI18nHead) | Ghi đè theo từng trang cho các thẻ SEO được tạo |
| [`useLocaleHead`](/vi/composables/useLocaleHead) | Các thẻ SEO dưới dạng object, cho `useHead` của riêng bạn |

## Component {#components}

| Component | Hiển thị |
| --- | --- |
| [`<i18n-t>`](/vi/components/i18n-t) | Một bản dịch, với số nhiều, định dạng và nội suy slot |
| [`<i18n-link>`](/vi/components/i18n-link) | Một `NuxtLink` tới route đã bản địa hóa |
| [`<i18n-switcher>`](/vi/components/i18n-switcher) | Một dropdown chọn locale |
| [`<i18n-group>`](/vi/components/i18n-group) | Một khối có chung tiền tố khóa |

## Server {#server}

Các handler Nitro dùng `useTranslationServerMiddleware` và `useLocaleServerMiddleware`, không dùng các helper phía client. Xem [Route server](/vi/guide/server-side-translations).

## Package {#packages}

[API của package](/vi/api/packages/overview) liệt kê các export của mọi package `@i18n-micro/*`, mỗi package một trang được tạo tự động.
