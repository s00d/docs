# Tham chiếu API

## API runtime

- [Phương thức](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, chuyển ngôn ngữ, trợ giúp định tuyến
- [Sự kiện](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Bản dịch và bộ nhớ đệm](/api/cache) — `TranslationStorage`, tải payload, `$clearCache`

## Middleware phía máy chủ

Các trình xử lý máy chủ sử dụng middleware riêng (không dùng trợ giúp `$t` phía client):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — dịch trong các route API và trình xử lý máy chủ
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — đọc ngôn ngữ đã phát hiện và siêu dữ liệu

Xem toàn bộ [Hướng dẫn bản dịch phía máy chủ](/guides/server-side-translations) để biết cách thiết lập, thứ tự ưu tiên phát hiện ngôn ngữ và ví dụ.
