# 🌍 Thành phần `<i18n-t>`

Thành phần `<i18n-t>` trong `Nuxt I18n Micro` là một thành phần dịch linh hoạt hỗ trợ chèn nội dung động qua slot. Nó cho phép bạn nội suy các bản dịch với các thành phần Vue tùy chỉnh hoặc nội dung HTML, cho phép các kịch bản bản địa hóa nâng cao.

Chỉ một trong các prop `plural`, `number`, `date` và `relativeDate` được áp dụng tại một thời điểm; khi nhiều prop được đặt, prop đầu tiên trong danh sách đó sẽ thắng.

### Ví dụ cho từng prop

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

```json
{
  "items": "Nothing|You have {count} item|You have {count} items"
}
```

## 🛠️ Ví dụ sử dụng

### Cách dùng cơ bản

```vue
<i18n-t keypath="feedback.text" />
```

Đoạn này hiển thị bản dịch cho `feedback.text` trong thẻ `<span>`.

### Dùng slot cho nội dung động

Thành phần `<i18n-t>` hỗ trợ dùng slot để chèn động các thành phần Vue hoặc nội dung khác vào các phần cụ thể của bản dịch.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

Trong ví dụ này, placeholder `\{link\}` trong chuỗi bản dịch `feedback.text` được thay thế bằng thành phần `<nuxt-link>`, bản thân nó chứa thêm một thành phần dịch khác.

### Số nhiều

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

Đoạn này tự động áp dụng các quy tắc số nhiều dựa trên giá trị `itemCount`.

## 🚀 Tính năng bổ sung

### Slot mặc định

Nếu không cung cấp slot cụ thể nào, bản dịch có thể được tùy chỉnh qua slot mặc định, slot này cung cấp toàn bộ chuỗi đã dịch:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### Hiển thị có điều kiện

Không hiển thị gì nếu chuỗi bản dịch rỗng bằng cách dùng prop `hideIfEmpty`.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### Quy tắc số nhiều tùy chỉnh

Sử dụng một hàm tùy chỉnh để xử lý số nhiều.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### Ví dụ nâng cao với slot

Tận dụng slot để tùy chỉnh cách hiển thị nội dung bản dịch.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
