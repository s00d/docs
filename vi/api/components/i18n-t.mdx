# 🌍 Component `<i18n-t>`

Component `<i18n-t>` trong `Nuxt I18n Micro` là một component dịch linh hoạt hỗ trợ chèn nội dung động qua slot. Nó cho phép bạn nội suy các bản dịch với các component Vue tùy chỉnh hoặc nội dung HTML, kích hoạt các kịch bản bản địa hóa nâng cao.

Chỉ một trong `plural`, `number`, `date` và `relativeDate` được áp dụng tại một thời điểm; khi nhiều
được đặt, cái đầu tiên trong danh sách đó thắng.

### Ví dụ theo prop

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

```json
{
  "items": "Nothing|You have {count} item|You have {count} items"
}
```

## 🛠️ Ví dụ sử dụng

### Cách dùng cơ bản

```vue
<i18n-t keypath="feedback.text" />
```

Điều này render bản dịch cho `feedback.text` trong một thẻ `<span>`.

### Dùng Slot cho nội dung động

Component `<i18n-t>` hỗ trợ việc dùng slot để chèn động các component Vue hoặc nội dung khác vào các phần cụ thể của bản dịch.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

Trong ví dụ này, placeholder `\{link\}` trong chuỗi bản dịch `feedback.text` được thay thế bởi component `<nuxt-link>`, chính nó chứa một component dịch khác.

### Pluralization

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

Điều này tự động áp dụng các quy tắc pluralization dựa trên giá trị `itemCount`.

## 🚀 Tính năng bổ sung

### Slot mặc định

Nếu không có slot cụ thể nào được cung cấp, bản dịch có thể được tùy chỉnh qua slot mặc định, cung cấp toàn bộ chuỗi đã dịch:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### Render có điều kiện

Không render gì nếu chuỗi bản dịch trống bằng cách dùng prop `hideIfEmpty`.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### Quy tắc Pluralization tùy chỉnh

Dùng một hàm tùy chỉnh để xử lý pluralization.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### Ví dụ nâng cao với Slot

Tận dụng slot để tùy chỉnh cách nội dung bản dịch được render.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
