# 🌍 Component `<i18n-group>`

Component `<i18n-group>` trong Nuxt I18n Micro cung cấp một cách thuận tiện để nhóm các bản dịch dưới một tiền tố chung, giảm sự lặp lại và cải thiện tổ chức mã.

## ⚙️ Props

## 🎯 Slot

Slot mặc định nhận `prefix` và một hàm `t` được đặt phạm vi theo nó, nên các khóa bên trong được
viết tương đối với tiền tố:

```vue
<i18n-group prefix="checkout">
  <template #default="{ t }">
    <h2>{{ t('title') }}</h2>
    <p>{{ t('summary', { count: 3 }) }}</p>
  </template>
</i18n-group>
```

## 🛠️ Ví dụ sử dụng

### Cách dùng cơ bản

```vue
<template>
  <i18n-group prefix="product.details">
    <template #default="{ t }">
      <h1>{{ t('title') }}</h1>
      <p>{{ t('description') }}</p>
      <div class="price">{{ t('price', { value: 99.99 }) }}</div>
    </template>
  </i18n-group>
</template>
```

Tệp bản dịch:

```json
{
  "product": {
    "details": {
      "title": "Premium Product",
      "description": "This is a premium product",
      "price": "Price: ${value}"
    }
  }
}
```

### Với class tùy chỉnh

```vue
<template>
  <i18n-group prefix="user.profile" group-class="profile-section">
    <template #default="{ t }">
      <div class="user-info">
        <h2>{{ t('title') }}</h2>
        <p>{{ t('bio') }}</p>
        <div class="stats">
          <span>{{ t('stats.followers') }}</span>
          <span>{{ t('stats.following') }}</span>
        </div>
      </div>
    </template>
  </i18n-group>
</template>
```

Tệp bản dịch:

```json
{
  "user": {
    "profile": {
      "title": "User Profile",
      "bio": "User biography goes here",
      "stats": {
        "followers": "Followers: {count}",
        "following": "Following: {count}"
      }
    }
  }
}
```

### Với nội dung động

```vue
<template>
  <i18n-group prefix="blog.post">
    <template #default="{ t }">
      <article>
        <h1>{{ t('title') }}</h1>
        <div class="meta">
          {{ t('meta.author', { name: author }) }} |
          {{ t('meta.date', { date: publishDate }) }}
        </div>
        <div v-for="(section, index) in sections" :key="index">
          <h2>{{ t(`sections.${index}.title`) }}</h2>
          <p>{{ t(`sections.${index}.content`) }}</p>
        </div>
      </article>
    </template>
  </i18n-group>
</template>

<script setup>
const author = 'John Doe'
const publishDate = '2024-01-01'
const sections = ['intro', 'main', 'conclusion']
</script>
```

## 🎨 Styling

Component bọc nội dung của nó trong một div với class `i18n-group` và bất kỳ class bổ sung nào được chỉ định trong prop `groupClass`:

```css
.i18n-group {
  /* Your base styles */
}

.profile-section {
  /* Additional styles for profile sections */
}
```

## 🚀 Thực hành tốt nhất

1. **Tiền tố nhất quán**: Dùng các tiền tố nhất quán và logic phản ánh cấu trúc ứng dụng của bạn

```vue
<i18n-group prefix="features.pricing">
<i18n-group prefix="features.security">
```

2. **Tổ chức mô-đun**: Nhóm các bản dịch liên quan cùng nhau dưới các tiền tố có ý nghĩa

```vue
<i18n-group prefix="checkout.payment">
<i18n-group prefix="checkout.shipping">
```

3. **Component có thể tái sử dụng**: Tạo các component có thể tái sử dụng với các nhóm bản dịch riêng

```vue
<!-- UserProfile.vue -->
<i18n-group prefix="user.profile">

<!-- UserSettings.vue -->
<i18n-group prefix="user.settings">
```

4. **Nhóm lồng nhau**: Tránh lồng các nhóm sâu để duy trì sự rõ ràng

```vue
<!-- Good -->
<i18n-group prefix="shop.product">

<!-- Avoid -->
<i18n-group prefix="shop.category.product.details.specs">
```
