# 🌍 Composable `useLocaleHead`

Composable `useLocaleHead` là một tiện ích trong `Nuxt I18n Micro` giúp bạn quản lý các thuộc tính SEO và các thẻ meta HTML cho các route đã bản địa hóa. Nó tự động tạo các thuộc tính cho `lang` và `dir` của tài liệu HTML và tạo các thẻ `meta` và `link` để cải thiện SEO của nội dung đã bản địa hóa của bạn.

## ⚙️ Tùy chọn

```ts

```

Các thẻ head SEO cho route hiện tại: các alternate `hreflang` cho mọi locale cộng với
`x-default`, một canonical link, `og:locale`, và `lang`/`dir` trên `<html>`.

Chỉ cần thiết khi `meta` bị vô hiệu hóa hoặc các mặc định cần điều chỉnh — với `meta: true`
module tự đăng ký các thẻ tương tự.

## 🛠️ Giá trị trả về

Composable `useLocaleHead` trả về một object reactive và một hàm updater bạn nên
gọi khi dữ liệu nguồn thay đổi. Cả hai hình dạng đều nằm trong chữ ký ở trên, được tạo từ
mã nguồn.

### `metaObject`

Payload head reactive (html attrs, meta, link) phù hợp cho `useHead(metaObject)`.

- **Ví dụ**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

Tính toán lại `metaObject` dựa trên route, locale và cấu hình hiện tại. Gọi nó khi input
thay đổi — ví dụ, khi thay đổi route.

- **Ví dụ**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### Truy cập `link` và `meta`

Các mảng `link` và `meta` có thể truy cập qua `metaObject.value`:

- **Ví dụ**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ Ví dụ sử dụng

### Cách dùng cơ bản

Tạo các thuộc tính head theo locale với các tùy chọn mặc định.

```js
const head = useLocaleHead()
```

### Tùy chỉnh thuộc tính định danh

Dùng một thuộc tính định danh tùy chỉnh cho các thẻ được tạo.

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### Vô hiệu hóa thuộc tính SEO

Tạo các thuộc tính head mà không thêm các thẻ meta và link liên quan đến SEO.

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### Chỉ định Base URL

Đặt một base URL tùy chỉnh cho các URL canonical và alternate.

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 Tính năng bổ sung

### Các thẻ Meta và Link SEO

Khi `addSeoAttributes` được bật, composable tự động tạo các thẻ sau:

- `og:locale` cho locale hiện tại (`language_TERRITORY`, dấu gạch dưới). Được suy ra từ `locale.og` hoặc chuyển đổi từ `locale.iso` khi có thể.
- `og:url` cho URL canonical của trang.
- `og:locale:alternate` cho các phiên bản ngôn ngữ thay thế.
- Các link `rel="canonical"` và `rel="alternate"` để tối ưu hóa SEO.
- Link `hreflang="x-default"` trỏ đến URL của locale mặc định. Điều này cho các công cụ tìm kiếm biết URL nào để hiển thị cho người dùng có ngôn ngữ không khớp với bất kỳ locale nào được định nghĩa.

### Locale và hướng động

Composable tự động xác định các thuộc tính `lang` và `dir` dựa trên locale của route hiện tại, đảm bảo tài liệu HTML của bạn được cấu hình chính xác cho người dùng quốc tế.

### Xử lý các route đã bản địa hóa

Nếu các route của bạn có tiền tố mã locale (ví dụ, `/en/about`), composable điều chỉnh thông minh đường dẫn đầy đủ để tạo URL, đảm bảo các thuộc tính SEO chính xác và có liên quan.

Composable này đơn giản hóa quá trình tối ưu hóa ứng dụng Nuxt của bạn cho khán giả quốc tế, đảm bảo trang của bạn được chuẩn bị tốt cho các công cụ tìm kiếm và người dùng toàn cầu.

## 🛠️ Ví dụ sử dụng

Ví dụ sau minh họa cách dùng composable `useLocaleHead` trong một component Vue với các thiết lập mặc định:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### Giải thích mã

- **Composable `useLocaleHead`**: Composable này được gọi trong phần `<script setup>` và trả về một object chứa `htmlAttrs`, `meta`, và `link`.

- **Thẻ `<html>`**: Các thuộc tính `lang` và `dir` cho tài liệu HTML được xác định động dựa trên locale hiện tại và được áp dụng cho thẻ `<html>`.

- **Phần `<head>`**:
  - **Thẻ Meta**: Các thẻ meta liên quan đến SEO được tạo, bao gồm `og:locale`, `og:url`, và các thẻ `rel="canonical"` và `rel="alternate"` để chỉ định các phiên bản ngôn ngữ thay thế của trang.
  - **Thẻ Link**: Các link canonical, các link đến các phiên bản ngôn ngữ thay thế và link `hreflang="x-default"` (trỏ đến URL locale mặc định) được bao gồm.

- **Phần `<body>`**: Nội dung chính của trang được hiển thị ở đây. Trong ví dụ này, một header và đoạn văn đơn giản được dùng.

### 📝 Ghi chú

1. **Thuộc tính**: Các thuộc tính được dùng (`lang`, `dir`, `rel`, `href`, `hreflang`, `property`, `content`) được trích xuất từ object được trả về bởi `useLocaleHead`.

2. **Tạo thẻ SEO**: Nếu tùy chọn `addSeoAttributes` được đặt là `true`, composable tự động tạo các thẻ SEO cho locale hiện tại.

3. **Base URL**: Bạn có thể đặt base URL tùy chỉnh của mình bằng tùy chọn `baseUrl` để tạo chính xác các link canonical và alternate.

Ví dụ này minh họa cách dễ dàng để tích hợp `useLocaleHead` vào các component của ứng dụng để đảm bảo các thuộc tính SEO chính xác và cải thiện việc lập chỉ mục công cụ tìm kiếm của các trang đã bản địa hóa.

## 🧩 Tùy chỉnh & Vòng đời

- `useLocaleHead` không tự đăng ký các thay đổi. Nó trả về `metaObject` và `updateMeta`.
- Bạn nên gọi `updateMeta()` khi input thay đổi (thường là khi thay đổi route), ví dụ từ một plugin:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## Khi nào nên dùng `useI18nHead` thay thế

Khi `meta: true` (mặc định), hãy ưu tiên [`useI18nHead`](/api/composables/use-i18n-head) cho các ghi đè **theo trang** (hreflang tùy chỉnh, `og:title` bổ sung, vô hiệu hóa một phần). Chỉ dùng `useLocaleHead` trực tiếp khi `meta: false` hoặc bạn tự quản lý `useHead`.
