# 🌍 Composable `useLocaleHead`

Composable `useLocaleHead` là một tiện ích trong `Nuxt I18n Micro` giúp bạn quản lý các thuộc tính SEO và các thẻ meta HTML cho các route được bản địa hóa. Nó sinh động các thuộc tính cho `lang` và `dir` của tài liệu HTML, đồng thời tạo các thẻ `meta` và `link` để cải thiện SEO cho nội dung đã bản địa hóa của bạn.

## ⚙️ Tùy chọn

```ts
useLocaleHead(options: UseLocaleHeadOptions): { metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }, MetaObject | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

Các thẻ head SEO cho route hiện tại: các thẻ alternate `hreflang` cho mọi ngôn ngữ cộng với `x-default`, một liên kết canonical, `og:locale`, và `lang`/`dir` trên `<html>`.

Chỉ cần thiết khi `meta` bị tắt hoặc cần điều chỉnh các mặc định. Với `meta: true`, mô-đun tự đăng ký các thẻ tương tự.

**Trả về** — một ref chứa đối tượng head, sẵn sàng để truyền vào `useHead`

## 🛠️ Giá trị trả về

Composable `useLocaleHead` trả về một đối tượng phản ứng và một hàm cập nhật mà bạn cần gọi khi dữ liệu nguồn thay đổi. Cả hai kiểu đều nằm trong chữ ký ở trên, được sinh từ nguồn.

### `metaObject`

Payload head có tính phản ứng (thuộc tính html, meta, link) phù hợp để dùng cho `useHead(metaObject)`.

- **Ví dụ**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

Tính lại `metaObject` dựa trên route, ngôn ngữ và cấu hình hiện tại. Gọi nó khi đầu vào thay đổi. Ví dụ, khi đổi route.

- **Ví dụ**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### Truy cập `link` và `meta`

Các mảng `link` và `meta` có thể truy cập qua `metaObject.value`:

- **Ví dụ**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ Ví dụ sử dụng

### Cách dùng cơ bản

Sinh các thuộc tính head theo ngôn ngữ với các tùy chọn mặc định.

```js
const head = useLocaleHead()
```

### Tùy chỉnh thuộc tính định danh

Dùng một thuộc tính định danh tùy chỉnh cho các thẻ được sinh.

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### Tắt thuộc tính SEO

Sinh các thuộc tính head mà không thêm các thẻ meta và link liên quan đến SEO.

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### Chỉ định URL cơ sở

Đặt một URL cơ sở tùy chỉnh cho URL canonical và alternate.

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 Tính năng bổ sung

### Thẻ meta SEO và thẻ link

Khi bật `addSeoAttributes`, composable tự động sinh các thẻ sau:

- `og:locale` cho ngôn ngữ hiện tại (`language_TERRITORY`, dùng dấu gạch dưới). Được suy ra từ `locale.og` hoặc được chuyển đổi từ `locale.iso` khi có thể.
- `og:url` cho URL canonical của trang.
- `og:locale:alternate` cho các phiên bản ngôn ngữ thay thế.
- Các liên kết `rel="canonical"` và `rel="alternate"` để tối ưu SEO.
- Liên kết `hreflang="x-default"` trỏ đến URL của ngôn ngữ mặc định. Điều này cho công cụ tìm kiếm biết URL nào cần hiển thị cho những người dùng có ngôn ngữ không khớp với bất kỳ ngôn ngữ nào được định nghĩa.

### Ngôn ngữ và hướng động

Composable xác định động các thuộc tính `lang` và `dir` dựa trên ngôn ngữ của route hiện tại, đảm bảo tài liệu HTML của bạn được cấu hình đúng cho người dùng quốc tế.

### Xử lý các route đã bản địa hóa

Nếu các route của bạn có tiền tố là mã ngôn ngữ (ví dụ `/en/about`), composable điều chỉnh thông minh đường dẫn đầy đủ để sinh URL, đảm bảo các thuộc tính SEO chính xác và phù hợp.

Composable này đơn giản hóa quá trình tối ưu hóa ứng dụng Nuxt của bạn cho người dùng quốc tế, đảm bảo trang web của bạn được chuẩn bị tốt cho các công cụ tìm kiếm và người dùng toàn cầu.

## 🛠️ Ví dụ sử dụng

Ví dụ sau minh họa cách dùng composable `useLocaleHead` trong một thành phần Vue với các cài đặt mặc định:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### Giải thích đoạn mã

- **Composable `useLocaleHead`**: Composable này được gọi trong phần `<script setup>` và trả về một đối tượng chứa `htmlAttrs`, `meta`, và `link`.

- **Thẻ `<html>`**: Các thuộc tính `lang` và `dir` cho tài liệu HTML được xác định động dựa trên ngôn ngữ hiện tại và được áp dụng vào thẻ `<html>`.

- **Phần `<head>`**:
  - **Thẻ meta**: Các thẻ meta liên quan đến SEO được sinh, bao gồm `og:locale`, `og:url`, và các thẻ `rel="canonical"` và `rel="alternate"` để chỉ định các phiên bản ngôn ngữ thay thế của trang.
  - **Thẻ link**: Các liên kết canonical, liên kết đến các phiên bản ngôn ngữ thay thế, và liên kết `hreflang="x-default"` (trỏ đến URL ngôn ngữ mặc định) đều được bao gồm.

- **Phần `<body>`**: Nội dung chính của trang được hiển thị ở đây. Trong ví dụ này, chỉ dùng một tiêu đề và đoạn văn đơn giản.

### 📝 Ghi chú

1. **Thuộc tính**: Các thuộc tính được sử dụng (`lang`, `dir`, `rel`, `href`, `hreflang`, `property`, `content`) được trích xuất từ đối tượng do `useLocaleHead` trả về.

2. **Sinh thẻ SEO**: Nếu tùy chọn `addSeoAttributes` được đặt là `true`, composable tự động sinh các thẻ SEO cho ngôn ngữ hiện tại.

3. **URL cơ sở**: Bạn có thể đặt URL cơ sở tùy chỉnh bằng tùy chọn `baseUrl` để sinh đúng các liên kết canonical và alternate.

Ví dụ này minh họa việc tích hợp `useLocaleHead` vào các thành phần trong ứng dụng của bạn dễ dàng như thế nào để đảm bảo các thuộc tính SEO chính xác và cải thiện việc lập chỉ mục của công cụ tìm kiếm cho các trang đã bản địa hóa.

## 🧩 Tùy chỉnh & vòng đời

- `useLocaleHead` tự nó không đăng ký lắng nghe các thay đổi. Nó trả về `metaObject` và `updateMeta`.
- Bạn nên gọi `updateMeta()` khi đầu vào thay đổi (thường là khi đổi route), ví dụ từ một plugin:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## Khi nào nên dùng `useI18nHead` thay thế

Khi `meta: true` (mặc định), hãy ưu tiên [`useI18nHead`](/api/composables/use-i18n-head) cho các ghi đè **theo trang** (hreflang tùy chỉnh, `og:title` bổ sung, tắt một phần). Chỉ dùng trực tiếp `useLocaleHead` khi `meta: false` hoặc bạn tự quản lý `useHead`.
