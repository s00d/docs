# useI18nLocale

## Chữ ký

Điểm vào tập trung cho quản lý locale i18n.
Kết hợp useState('i18n-locale'), cookie locale và các tiện ích đồng bộ.

## Cách dùng

```vue
<script setup>
const {
  locale,
  localeCookie,
  hashCookie,
  validLocales,
  getPreferredLocale,
  getLocale,
  getLocaleWithServerFallback,
  getEffectiveLocale,
  resolveInitialLocale,
  setLocale,
  syncLocale,
  isValidLocale,
} = useI18nLocale()

// Set locale (updates state and cookies)
setLocale('de')

// Get current locale (state → cookie)
const current = getLocale()

// Get valid preferred locale
const preferred = getPreferredLocale()
</script>
```

## API

| Thuộc tính/Phương thức                                 | Kiểu                                | Mô tả                                                                          |
| ----------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| `locale`                                        | `Ref<string \| null>`               | Trạng thái locale reactive (`useState('i18n-locale')`)                                    |
| `localeCookie`                                  | `Ref`                               | Cookie locale (khi tùy chọn `localeCookie` được bật)                                |
| `hashCookie`                                    | `Ref`                               | Cookie được dùng khi `hashMode` đang hoạt động                                                |
| `validLocales`                                  | `string[]`                          | Các mã locale được kích hoạt từ cấu hình module (loại trừ `disabled`)                        |
| `getLocale()`                                   | `() => string \| null`              | Locale hiện tại: state → cookie (hoặc hash cookie ở hash mode)                         |
| `getPreferredLocale()`                          | `() => string \| null`              | Locale từ state/cookie **đã xác thực** với `validLocales`, hoặc `null`             |
| `getLocaleWithServerFallback(serverLocale?)`    | `(serverLocale?) => string \| null` | State → cookie → server context tùy chọn (được dùng trong quá trình init `no_prefix`)              |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string`             | Locale để tải bản dịch: hash mode ưu tiên state; ngược lại đọc từ route |
| `resolveInitialLocale(options)`                 | `(options) => string`               | Phân giải locale: state → `serverLocale` → route; đồng bộ state khi cần             |
| `setLocale(locale)`                             | `(locale: string \| null) => void`  | Đặt locale và đồng bộ sang cookie                                                       |
| `syncLocale(locale)`                            | `(locale: string \| null) => void`  | Chỉ đồng bộ cookie (không cập nhật state)                                                  |
| `isValidLocale(locale)`                         | `(locale) => boolean`               | Kiểm tra xem chuỗi có trong `validLocales` không                                                 |

### Tùy chọn `resolveInitialLocale`

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

Được dùng nội bộ bởi plugin chính khi khởi động. Các plugin tùy chỉnh có thể gọi nó khi triển khai các luồng phát hiện thay thế.

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

Trả về locale được dùng để tải bản dịch và định dạng thông điệp cho một đối tượng route nhất định.

## Đặt Locale bằng chương trình

Ưu tiên `useI18nLocale()` hơn việc dùng trực tiếp `useState('i18n-locale')`:

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
`setLocale()` chỉ cập nhật sở thích locale (state + cookie). Để tải lại cả ngữ cảnh bản dịch đang hoạt động trên client, hãy dùng `$switchLocale()` từ `useNuxtApp()` hoặc `useI18n()`. Điều này đặc biệt quan trọng cho `no_prefix`, nơi URL không thay đổi. Xem [FAQ — chuyển locale mà không thay đổi URL](/guides/faq#-switch-locale-without-changing-the-url).
</Tip>
