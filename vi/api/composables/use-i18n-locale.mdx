# useI18nLocale

## Chữ ký

Điểm vào tập trung cho việc quản lý ngôn ngữ i18n.

## Cách dùng

```vue
<script setup>
const {
  locale,
  localeCookie,
  hashCookie,
  validLocales,
  getPreferredLocale,
  getLocale,
  getLocaleWithServerFallback,
  getEffectiveLocale,
  resolveInitialLocale,
  setLocale,
  syncLocale,
  isValidLocale,
} = useI18nLocale()

// Set locale (updates state and cookies)
setLocale('de')

// Get current locale (state → cookie)
const current = getLocale()

// Get valid preferred locale
const preferred = getPreferredLocale()
</script>
```

## API

| Thuộc tính/Phương thức | Kiểu | Mô tả |
| ----------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| `locale` | `Ref<string \| null>` | Trạng thái ngôn ngữ có tính phản ứng (`useState('i18n-locale')`) |
| `localeCookie` | `Ref` | Cookie ngôn ngữ (khi bật tùy chọn `localeCookie`) |
| `hashCookie` | `Ref` | Cookie được dùng khi `hashMode` đang bật |
| `validLocales` | `string[]` | Các mã ngôn ngữ đã bật từ cấu hình mô-đun (loại trừ `disabled`) |
| `getLocale()` | `() => string \| null` | Ngôn ngữ hiện tại: state → cookie (hoặc cookie hash trong chế độ hash) |
| `getPreferredLocale()` | `() => string \| null` | Ngôn ngữ từ state/cookie **được xác thực** với `validLocales`, hoặc `null` |
| `getLocaleWithServerFallback(serverLocale?)` | `(serverLocale?) => string \| null` | State → cookie → ngữ cảnh máy chủ tùy chọn (dùng trong khởi tạo `no_prefix`) |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string` | Ngôn ngữ để tải bản dịch: chế độ hash ưu tiên state; ngược lại đọc từ route |
| `resolveInitialLocale(options)` | `(options) => string` | Phân giải ngôn ngữ: state → `serverLocale` → route; đồng bộ state khi cần |
| `setLocale(locale)` | `(locale: string \| null) => void` | Đặt ngôn ngữ và đồng bộ vào cookie |
| `syncLocale(locale)` | `(locale: string \| null) => void` | Chỉ đồng bộ cookie (không cập nhật state) |
| `isValidLocale(locale)` | `(locale) => boolean` | Kiểm tra chuỗi có nằm trong `validLocales` không |

### Tùy chọn `resolveInitialLocale`

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

Được dùng nội bộ bởi plugin chính khi khởi động. Các plugin tùy chỉnh có thể gọi nó khi triển khai các luồng phát hiện thay thế.

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

Trả về ngôn ngữ được sử dụng để tải bản dịch và định dạng thông báo cho một đối tượng route nhất định.

## Đặt ngôn ngữ theo cách lập trình

Ưu tiên dùng `useI18nLocale()` thay vì trực tiếp dùng `useState('i18n-locale')`:

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
`setLocale()` chỉ cập nhật tùy chọn ngôn ngữ (state + cookie). Để cũng tải lại ngữ cảnh bản dịch đang hoạt động trên client, hãy dùng `$switchLocale()` từ `useNuxtApp()` hoặc `useI18n()`. Điều này đặc biệt quan trọng với `no_prefix`, nơi URL không thay đổi. Xem [FAQ — chuyển ngôn ngữ mà không thay đổi URL](/guides/faq#-switch-locale-without-changing-the-url).
</Tip>
