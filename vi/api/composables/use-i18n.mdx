# 🛠️ Composable `useI18n`

Composable `useI18n` trong `Nuxt I18n Micro` cung cấp quyền truy cập vào hầu hết các trình trợ giúp i18n runtime trong các component và script. Các phương thức có sẵn **có và không có tiền tố `$`** (ví dụ `$t` và `t`).

Một số injection — `$defineI18nRoute` và `$clearCache` — chỉ có trên `useNuxtApp()`. Xem [Phương thức — `$defineI18nRoute`](/api/methods#definei18nroute) và [`$clearCache`](/api/methods#clearcache).

## 📊 Nó trả về gì

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Mọi trình trợ giúp runtime, dưới dạng một object thuần.

Cùng các hàm mà plugin tiêm vào dưới dạng `$t`, `$tc` v.v., có sẵn dưới cả
tên có tiền tố đô-la và một bí danh trần — vì vậy `const \{ t \} = useI18n()` và
`const \{ $t \} = useI18n()` đều hoạt động.

**Trả về** — các trình trợ giúp được mô tả trong [tham chiếu phương thức](/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

Mọi trình trợ giúp nó trả về — `$t`, `$tc`, `$has`, `$switchLocale` và phần còn lại — được liệt kê
với chữ ký của nó và được ghi tài liệu đầy đủ trên [Tham chiếu phương thức](/api/methods).

## API chỉ dành cho `useNuxtApp()`

Những cái này **không** được trả về bởi `useI18n()`. Hãy import chúng từ `useNuxtApp()`:

| Phương thức                     | Mục đích                                                                         |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Các route locale theo trang, hạn chế và bản dịch inline trong `script setup` |
| `$clearCache()`            | Xóa cache bản dịch trong bộ nhớ và các chunk đã tải                            |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Xem [Phương thức](/api/methods) để có chữ ký và ví dụ đầy đủ.

## 🛠️ Ví dụ sử dụng

### Lấy Locale cơ bản

Lấy locale hiện tại của ứng dụng.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Dịch với tham số

Dịch một chuỗi với các tham số động, với giá trị mặc định dự phòng.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Chuyển đổi Locale

Chuyển ứng dụng sang một locale khác.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Tạo Route bản địa hóa

Tạo một route được bản địa hóa theo locale hiện tại hoặc được chỉ định.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
