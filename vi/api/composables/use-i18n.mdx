# 🛠️ Composable `useI18n`

Composable `useI18n` trong `Nuxt I18n Micro` cung cấp truy cập đến hầu hết các trợ giúp i18n runtime trong các thành phần và script. Các phương thức có sẵn **cả với và không có tiền tố `$`** (ví dụ `$t` và `t`).

Một số phần được tiêm vào — `$defineI18nRoute` và `$clearCache` — chỉ có sẵn trên `useNuxtApp()`. Xem [Phương thức — `$defineI18nRoute`](/api/methods#definei18nroute) và [`$clearCache`](/api/methods#clearcache).

## 📊 Nó trả về gì

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Mọi trợ giúp runtime, dưới dạng một đối tượng thuần.

Cùng các hàm mà plugin tiêm vào dưới dạng `$t`, `$tc`, v.v., có sẵn cả dưới
tên có tiền tố dollar lẫn một bí danh không tiền tố. Vì vậy `const \{ t \} = useI18n()` và
`const \{ $t \} = useI18n()` đều hoạt động.

**Trả về** — các trợ giúp được mô tả trong [tham chiếu phương thức](/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

Mọi trợ giúp mà nó trả về — `$t`, `$tc`, `$has`, `$switchLocale` và các trợ giúp còn lại — đều được liệt kê
kèm chữ ký và được ghi đầy đủ trong [Tham chiếu phương thức](/api/methods).

## API chỉ có trên `useNuxtApp()`

Những API này **không** được `useI18n()` trả về. Hãy nhập chúng từ `useNuxtApp()`:

| Phương thức | Mục đích |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Các route theo ngôn ngữ, hạn chế và bản dịch inline theo trang trong `script setup` |
| `$clearCache()` | Xóa bộ nhớ đệm bản dịch trong bộ nhớ và các chunk đã tải |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Xem [Phương thức](/api/methods) để biết chữ ký đầy đủ và ví dụ.

## 🛠️ Ví dụ sử dụng

### Lấy ngôn ngữ cơ bản

Lấy ngôn ngữ hiện tại của ứng dụng.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Dịch với tham số

Dịch một chuỗi với các tham số động, kèm giá trị mặc định dự phòng.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Chuyển ngôn ngữ

Chuyển ứng dụng sang một ngôn ngữ khác.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Tạo route đã bản địa hóa

Tạo một route đã bản địa hóa theo ngôn ngữ hiện tại hoặc được chỉ định.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
