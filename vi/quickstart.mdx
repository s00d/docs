## 🚀 Bắt đầu nhanh

### Cài đặt

Cài đặt mô-đun vào ứng dụng Nuxt của bạn:

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

### Cấu hình cơ bản

Thêm mô-đun vào tệp `nuxt.config.ts` của bạn:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

<Tip>
- **Tệp cấp gốc** (`locales/en.json`, v.v.) — bản dịch được chia sẻ trên toàn ứng dụng (menu, footer, UI chung). Với `translationPayloads.mode: 'premerged'` (mặc định), chúng được gộp vào mọi trang tại thời điểm build.
- **Tệp riêng cho trang** (`locales/pages/<route>/<locale>.json`) — bản dịch chỉ dành cho các trang cụ thể, chỉ được tải khi truy cập trang đó.
- **Route động** — `pages/articles/[id].vue` ánh xạ tới `locales/pages/articles-id/` (dấu ngoặc vuông được thay bằng dấu gạch nối).
- **Tự động tạo** — tất cả tệp bản dịch được tạo tự động nếu thiếu trong khi chạy `nuxt dev`.
</Tip>

<Info>
Mô-đun hỗ trợ cả hai bố cục:

- **Pages**: `pages/**/*.vue` (Nuxt 3) hoặc `app/pages/**/*.vue` (Nuxt 4)
- **Translations**: mặc định giữ `locales/` ở **gốc dự án** (quy ước được khuyến nghị), không đặt bên trong `app/`

```tree
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   ├── en.json
│   └── pages/
└── nuxt.config.ts
```

Đồng vị trí tùy chọn: `i18n: \{ translationDir: 'app/locales' \}` (xem [fixture `n3`](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/n3)).

Đối với trợ giúp CLI tùy chọn `text-to-i18n`, hãy dùng [`nuxt-i18n-micro-cli` ≥ 2.1.1](/guides/cli#-text-to-i18n-command) để `app/pages` và `app/components` được quét từ gốc dự án.
</Info>

### Cách dùng cơ bản

Sử dụng bản dịch trong các thành phần của bạn:

```vue
<template>
  <div>
    <h1>{{ $t('welcome') }}</h1>
    <p>{{ $t('description', { name: 'World' }) }}</p>

    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" @click="$switchLocale(locale.code)">
        {{ locale.code }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useI18n } from '#imports'

const { $t, $getLocales, $switchLocale } = useI18n()
</script>
```
