---

Một island chạy trong trình duyệt, nơi instance i18n của server không tồn tại. `@i18n-micro/astro` cho phép trang chọn các khóa mà một island cần, truyền chúng dưới dạng một prop, và đọc chúng trong island qua một adapter framework nhỏ. Bạn có `t`, `tc`, `tn`, `td`, `tdr` và `has` trong các island Vue, React, Preact và Svelte, với chỉ những chuỗi được chọn nằm trong HTML.

## Thiết lập {#setup}

Trước tiên hãy thiết lập [tích hợp Astro và middleware](/vi/integrations/astro-package#setup), sau đó thêm tích hợp framework bạn dùng (`@astrojs/vue`, `@astrojs/react`, `@astrojs/preact`, `@astrojs/svelte`). Các adapter island cần framework đó làm peer: `vue` `^3.3.0`, `react` `^16.8.0 || ^17.0.0 || ^18.0.0 || ^19.0.0`, `preact` `^10.0.0 || ^11.0.0` hoặc `svelte` `^4.0.0 || ^5.0.0`.

## Truyền bản dịch vào một island {#pass-translations-to-an-island}

```astro
---
// src/pages/index.astro
import { getI18nProps } from '@i18n-micro/astro'
import Counter from '../components/Counter.vue'

const i18n = getI18nProps(Astro, ['counter.title', 'counter.apples'])
---

<Counter client:load i18n={i18n} />
```

`getI18nProps(Astro, keys?)` trả về `{ locale, fallbackLocale, currentRoute, translations }` (kiểu `I18nClientProps`). Hãy truyền các khóa mà island sử dụng: mỗi khóa được phân giải trên server giống `t()` (từ điển của route, từ điển gốc và từ điển dự phòng) và chỉ các khóa tìm thấy mới được đưa vào HTML. Không có `keys`, mọi thứ mà `t()` có thể trả lời trên trang này đều được gửi đi, trong mọi island, nên 2000 khóa gốc tương đương khoảng 100 KB cho mỗi island; trong dev, một cảnh báo sẽ báo điều này khi vượt quá 20 KB.

Island chỉ dịch từ object đó. `t` trả về khóa cho bất cứ thứ gì không được truyền vào, và các linked message không được phân giải.

## Vue {#vue}

Gọi `provideI18n(() => props.i18n)` trong component gốc của island và `useAstroI18n()` trong các component con. `inject` của Vue không thấy giá trị được provide bởi chính component đó, nên hook phải chạy trong một component con, không phải trong component gốc:

```vue
<!-- src/components/Counter.vue -->
<script setup lang="ts">
import { provideI18n } from '@i18n-micro/astro/client/vue'
import type { I18nClientProps } from '@i18n-micro/astro'
import CounterBody from './CounterBody.vue'

const props = defineProps<{ i18n: I18nClientProps }>()
provideI18n(() => props.i18n)
</script>

<template><CounterBody /></template>
```

```vue
<!-- src/components/CounterBody.vue -->
<script setup lang="ts">
import { ref } from 'vue'
import { useAstroI18n } from '@i18n-micro/astro/client/vue'

const { t, tc } = useAstroI18n()
const count = ref(0)
</script>

<template>
  <h3>{{ t('counter.title') }}</h3>
  <button @click="count++">{{ tc('counter.apples', count) }}</button>
</template>
```

## React và Preact {#react-and-preact}

```tsx
// src/components/Counter.tsx
import { useState } from 'react'
import { I18nProvider, useAstroI18n } from '@i18n-micro/astro/client/react'
import type { I18nClientProps } from '@i18n-micro/astro'

function Body() {
  const { t, tc } = useAstroI18n()
  const [count, setCount] = useState(0)
  return <button onClick={() => setCount(count + 1)}>{t('counter.title')}: {tc('counter.apples', count)}</button>
}

export default function Counter({ i18n }: { i18n: I18nClientProps }) {
  return (
    <I18nProvider value={i18n}>
      <Body />
    </I18nProvider>
  )
}
```

Với Preact, hãy import `I18nProvider` và `useAstroI18n` từ `@i18n-micro/astro/client/preact`; API giống hệt.

## Svelte {#svelte}

```svelte
<!-- src/components/Counter.svelte -->
<script lang="ts">
  import { createI18nStore, useAstroI18n } from '@i18n-micro/astro/client/svelte'
  import type { I18nClientProps } from '@i18n-micro/astro'

  export let i18n: I18nClientProps
  const { t, tc } = useAstroI18n(createI18nStore(i18n))
  let count = 0
</script>

<button on:click={() => count++}>{t('counter.title')}: {tc('counter.apples', count)}</button>
```

`useAstroI18n(store)` cũng trả về `store` để đọc `$store` trong template.

## Island được duy trì {#persisted-islands}

Một island có `transition:persist` nhận props mới sau một lần điều hướng. React, Preact và Vue (khi được truyền một getter) sẽ theo chúng. Trong Svelte, hãy giữ store và chuyển tiếp chúng: `const store = createI18nStore(i18n)`, `const { t } = useAstroI18n(store)`, sau đó `$: store.set(i18n)` (với runes, `$effect(() => store.set(i18n))`).

## API {#api}

| Entry | Export |
| --- | --- |
| `@i18n-micro/astro` | `getI18nProps`, kiểu `I18nClientProps` |
| `@i18n-micro/astro/client/vue` | `provideI18n(props \| () => props)`, `useAstroI18n()` |
| `@i18n-micro/astro/client/react` | `I18nProvider` (prop `value`), `useAstroI18n()` |
| `@i18n-micro/astro/client/preact` | `I18nProvider` (prop `value`), `useAstroI18n()` |
| `@i18n-micro/astro/client/svelte` | `createI18nStore(props)`, `useAstroI18n(store)` |
| `@i18n-micro/astro/client` | các hàm thuần `translate`, `hasTranslation`, không cần framework |

Mọi `useAstroI18n` đều trả về `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`, `setLocale`, `setRoute` và `locale`. Một island có một từ điển đã hợp nhất duy nhất, nên `has` của nó là true cho một khóa mà `t` có thể trả lời, kể cả từ locale dự phòng; trên server, `has` chỉ xem xét locale đang hoạt động.
