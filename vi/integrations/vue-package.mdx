`@i18n-micro/vue` là một plugin Vue 3 chứa lõi dịch của Nuxt I18n Micro: `t()` reactive, `$t` toàn cục, bốn component và một adapter vue-router tùy chọn. Hãy dùng nó trong một ứng dụng Vue chạy Vite hoặc SSR không được xây dựng bằng Nuxt. Mô hình instance, hợp đồng router và props của component được dùng chung với các gói khác và được mô tả trong [Framework](/vi/integrations/overview).

## Cài đặt {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vue
```

```bash npm
npm install @i18n-micro/vue
```

```bash yarn
yarn add @i18n-micro/vue
```

</CodeGroup>

Peer dependency: `vue` `^3.3.0`; `vue-router` `^4.5.1 || ^5.0.0` (tùy chọn, chỉ dành cho `@i18n-micro/vue/router`). Các kiểu được phát hành cần Vue 3.5.5 trở lên khi dùng `skipLibCheck: false`; với `skipLibCheck: true`, thiết lập thường thấy trong template, các phiên bản cũ hơn cũng biên dịch được.

## Thiết lập {#setup}

```ts
// src/main.ts
import { createApp } from 'vue'
import { createI18n } from '@i18n-micro/vue'
import App from './App.vue'
import en from './locales/en.json'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales: [
    { code: 'en', iso: 'en-US', displayName: 'English' },
    { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
  ],
  defaultLocale: 'en',
})

createApp(App).use(i18n).mount('#app')
```

`locales` và `defaultLocale` là bắt buộc đối với `useI18n()`: nó ném lỗi `I18nLocalesKey not provided` nếu thiếu chúng. Hãy truyền chúng cho `createI18n` (như trên), cho `useI18n({ locales, defaultLocale })`, hoặc thông qua `app.provide(I18nLocalesKey, …)` và `app.provide(I18nDefaultLocaleKey, …)`.

Plugin đăng ký `I18nT`, `I18nLink`, `I18nGroup` và `I18nSwitcher` ở phạm vi toàn cục và thêm `$t`, `$ts`, `$tc`, `$tn`, `$td`, `$tdr`, `$has` và `$i18n` vào template. Bên ngoài component, instance là `i18n.global`. Các tùy chọn khác nằm trong [instance](/vi/integrations/overview#the-instance); `routeMessages` không khả dụng trong Vue, hãy dùng `addRouteTranslations`.

## Dịch {#translate}

```vue
<script setup lang="ts">
import { useI18n } from '@i18n-micro/vue'

const { t, tc, tn } = useI18n()
</script>

<template>
  <h1>{{ t('greeting', { name: 'Ada' }) }}</h1>
  <!-- Hello, Ada! -->
  <p>{{ tc('apples', 3) }}</p>
  <!-- 3 apples -->
  <p>{{ $t('nav.home') }} · {{ tn(1234.5) }}</p>
</template>
```

`useI18n()` trả về các phương thức dịch (`t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`), `locale` (một computed có thể ghi), `getLocale`, `getLocales`, `defaultLocale()`, `getLocaleName`, `localePath`, `localeRoute`, `switchLocale`, `setRoute`, `getRoute`, `addTranslations`, `addRouteTranslations`, `mergeTranslations`, `resolveTranslations`, `setTranslation`, `clearCache` và `instance`.

Tải thêm từ điển bất cứ lúc nào; mọi component đọc chúng sẽ render lại:

```ts
const { addTranslations, addRouteTranslations, setRoute } = useI18n()

addTranslations('de', (await import('./locales/de.json')).default)
addRouteTranslations('en', 'about', { title: 'About us' })
setRoute('about') // t('title') now reads the 'about' dictionary first
```

## Chuyển locale {#switch-locale}

```ts
const { locale, switchLocale } = useI18n()

locale.value = 'de' // only the locale
switchLocale('de') // the locale, then router.push to the localized current path
```

Hãy tải từ điển của locale trước hoặc sau khi chuyển; việc chuyển locale không fetch gì cả.

`<I18nGroup>` cung cấp cho slot của nó một `t` có tiền tố. Các key bên trong `<I18nT>` hoặc một `t()` thông thường không có tiền tố:

```vue
<I18nGroup prefix="profile" v-slot="{ t }">
  <h2>{{ t('title') }}</h2>
  <!-- profile.title -->
</I18nGroup>
```

## Định tuyến {#routing}

Adapter vue-router nằm trong một subpath để entry chính không bao giờ import `vue-router`:

```ts
// src/main.ts
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import { createI18n } from '@i18n-micro/vue'
import { createVueRouterAdapter } from '@i18n-micro/vue/router'
import App from './App.vue'
import Home from './pages/Home.vue'
import About from './pages/About.vue'
import en from './locales/en.json'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English' },
  { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
]

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/:locale(de)?', component: Home },
    { path: '/:locale(de)?/about', component: About },
  ],
})

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales,
  defaultLocale: 'en',
  routingStrategy: createVueRouterAdapter(router, locales, 'en'),
})

createApp(App).use(router).use(i18n).mount('#app')
```

`createVueRouterAdapter(router, locales, defaultLocale)` thêm tiền tố cho mọi locale trừ locale mặc định (`/about`, `/de/about`) và render `<I18nLink>` thành `RouterLink`. Bạn tự đọc locale từ route, ví dụ trong `router.beforeEach`, và đặt `i18n.global.locale.value`. Bạn cũng có thể gắn adapter sau bằng `i18n.setRoutingStrategy(adapter)`; với adapter tùy chỉnh, xem [Router adapter](/vi/integrations/overview#router-adapter).

## SSR {#ssr}

- Tạo router, instance i18n và ứng dụng bên trong hàm render của mỗi yêu cầu. Một instance dùng chung sẽ làm rò rỉ locale của khách truy cập này sang khách khác.
- Dùng `createMemoryHistory()` trên server, lấy locale từ URL, và tải từ điển của nó (cùng từ điển fallback) trước `renderToString`.
- Gửi locale tới client (ví dụ trong một script `window.__STATE__`) và tạo instance phía client với cùng `locale` để hydration khớp.
- `<I18nSwitcher>` chỉ đọc `window.location` khi dropdown mở, nên nó render được trên server.

`packages/vue/playground` có một cặp `entry-server.ts` / `entry-client.ts` hoàn chỉnh.

## SEO head {#seo-head}

`useLocaleHead(options)` xây dựng các thẻ `lang`/`dir`, canonical, `hreflang` và `og:locale` từ các locale và router adapter. Gọi `updateMeta()` khi route thay đổi và truyền `metaObject` cho trình quản lý head của bạn:

```ts
import { watch } from 'vue'
import { useRoute } from 'vue-router'
import { useHead } from '@unhead/vue'
import { useLocaleHead } from '@i18n-micro/vue'

const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
watch(() => route.fullPath, () => updateMeta(), { immediate: true })
useHead(metaObject)
```

Tùy chọn: `baseUrl` (chuỗi hoặc hàm), `addDirAttribute` (mặc định `true`), `addSeoAttributes` (mặc định `true`), `identifierAttribute` (mặc định `'id'`), `hreflangBaseLanguage` (mặc định `false`). Các locale có `disabled: true` hoặc `seo: false` không nhận được liên kết alternate.
