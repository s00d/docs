`@i18n-micro/node` là instance [runtime](/vi/integrations/runtime-package) cộng với một loader đọc thư mục bản dịch từ ổ đĩa. Hãy dùng nó trong máy chủ Express hoặc Fastify, một CLI, trình tạo email hoặc PDF, hoặc bất kỳ script nào cần cùng các tệp JSON với app Nuxt của bạn. Bạn tải tệp một lần và dịch theo từng yêu cầu mà không chia sẻ trạng thái có thể thay đổi giữa các yêu cầu.

## Cài đặt {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/node @i18n-micro/utils
```

```bash npm
npm install @i18n-micro/node @i18n-micro/utils
```

```bash yarn
yarn add @i18n-micro/node @i18n-micro/utils
```

</CodeGroup>

Không có peer dependency; Node.js `>=20`. `@i18n-micro/utils` chỉ cần cho hàm trợ giúp `Accept-Language` bên dưới.

## Thiết lập {#setup}

Loader đọc [cách bố trí thư mục của Nuxt](/vi/guide/translations): `locales/en.json` là từ điển gốc, `locales/pages/blog/post/en.json` thuộc về route `blog-post`.

```ts
import { createI18n } from '@i18n-micro/node'

const i18n = createI18n({ locale: 'en', fallbackLocale: 'en', translationDir: './locales' })
await i18n.loadTranslations()

i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.t('title', undefined, undefined, 'blog-post') // from locales/pages/blog/post/en.json
```

Các tùy chọn là tùy chọn của runtime (xem [instance](/vi/integrations/overview#the-instance)) cộng với `translationDir` và `disablePageLocales` (coi các tệp `pages/**` là từ điển gốc). `i18n.reload()` xóa mọi từ điển và đọc lại thư mục, dùng cho file watcher trong môi trường phát triển.

`loadTranslations(dir, disablePageLocales?)` cũng được export riêng và trả về `{ root, routes }`:

```ts
import { loadTranslations } from '@i18n-micro/node'

const { root, routes } = await loadTranslations('./locales')
// root:   { en: {...}, de: {...} }
// routes: { 'blog-post': { en: {...}, de: {...} } }
```

## Theo từng yêu cầu {#per-request}

Một instance giữ một locale và một route. Đổi `i18n.locale` trên một instance dùng chung bên trong request handler sẽ gây tranh chấp với các yêu cầu đồng thời. `run` cho mỗi yêu cầu một instance riêng:

```ts
const i18n = createI18n({ locale: 'en', fallbackLocale: 'en', translationDir: './locales' })
await i18n.loadTranslations()

// `() => next()`: `run` hands its callback the fork, and Express reads an argument of `next` as an error
app.use((req, res, next) => i18n.run(pickLocale(req), () => next()))

app.get('/', (req, res) => {
  res.send(i18n.t('greeting')) // the request's locale, in everything it awaits
})
```

Bên trong `run`, instance dùng chung đọc và đặt locale cùng route của yêu cầu (`AsyncLocalStorage`); bản fork bắt đầu trên route hiện tại, và `i18n.setRoute(...)` bên trong callback thay đổi route của yêu cầu đó. Callback cũng nhận bản fork của yêu cầu: từ điển ghi vào nó chỉ nằm trong yêu cầu, từ điển ghi vào instance dùng chung thì đến với mọi người.

Khi không có `AsyncLocalStorage`, `i18n.fork(locale)` trả về cùng loại instance để truyền đi.

`reload()` đọc lại thư mục; các từ điển cũ vẫn trả lời cho tới khi các từ điển mới được nạp xong.

## Chọn locale {#pick-the-locale}

`detectLocaleFromAcceptLanguage(header, locales)` tôn trọng trọng số `q` và khớp `de-DE` với locale `de` (và `de` với `de-DE`). Nó trả về `null` khi không có gì khớp.

```ts
import express from 'express'
import { detectLocaleFromAcceptLanguage } from '@i18n-micro/utils/accept-language'

const app = express()

app.get('/hello', (req, res) => {
  const locale = detectLocaleFromAcceptLanguage(req.headers['accept-language'], locales) ?? 'en'
  const i18n = byLocale.get(locale)!
  res.json({ message: i18n.t('greeting', { name: 'Ada' }) })
})
```

Để kết hợp tiền tố URL, cookie và header, `resolveLocale({ defaultLocale, validLocales, url, cookie, acceptLanguage, autoDetectLanguage: true })` từ `@i18n-micro/utils/resolve-locale` áp dụng thứ tự ưu tiên của module: URL, rồi cookie, rồi `Accept-Language`, rồi mặc định. Các giá trị không hợp lệ bị bỏ qua.

Bên trong một app Nuxt, bạn không cần package này trên máy chủ: hãy dùng [bản dịch phía máy chủ](/vi/guide/server-side-translations) của module.

## API {#api}

| Export | Ghi chú |
| --- | --- |
| `createI18n(options)`, `I18n` | instance runtime + `translationDir`, `loadTranslations(dir?)`, `reload()` |
| `loadTranslations(dir, disablePageLocales?)` | `{ root, routes }` |
| `loadRootTranslations(dir, disablePageLocales?)` | chỉ `root` |
| `FormatService`, `interpolate` | từ core |
| Kiểu: `I18nOptions`, `LoadedTranslations`, `Translations`, `Locale`, `PluralFunc`, `Params` | |

Các phương thức của instance được liệt kê tại [Runtime](/vi/integrations/runtime-package#api). Chữ ký đầy đủ: [tham chiếu package](/vi/api/packages/node).
