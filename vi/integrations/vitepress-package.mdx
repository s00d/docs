`@i18n-micro/vitepress` thêm từ điển lúc runtime vào một trang VitePress: `$t` và `<I18nT>` bên trong markdown, các hàm trợ giúp đường dẫn và thẻ SEO, được xây dựng trên [`@i18n-micro/vue`](/vi/integrations/vue-package). Hãy dùng nó khi cùng các chuỗi giao diện xuất hiện trên nhiều trang và bạn không muốn lặp lại chúng cho từng locale. Locale theo các locale đường dẫn riêng của VitePress (`/`, `/fr/`).

## Khi nào nên dùng {#when-to-use-it}

| Nhu cầu | Giải pháp |
|------|----------|
| Nhân bản `.md`, tiền tố URL | VitePress `locales` |
| `$t` lúc runtime / component / đồng bộ đường dẫn / head SEO | `@i18n-micro/vitepress` |
| Nhãn giao diện của theme mặc định (`docFooter`, giao diện tìm kiếm) | `themeConfig` riêng của bạn cho mỗi locale |

<Tip>

**Playground** — [`packages/vitepress/playground`](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/vitepress/playground) — `pnpm -C packages/vitepress/playground dev`

</Tip>

## Cài đặt {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vitepress
```

```bash npm
npm install @i18n-micro/vitepress
```

```bash yarn
yarn add @i18n-micro/vitepress
```

</CodeGroup>

Peer dependency: `vitepress` `>=1.0.0 || >=2.0.0-alpha.0`, `vue` `^3.3.0`. Các script Node dùng `@i18n-micro/node`, được cài cùng package và export lại qua `/node`. Các kiểu được phát hành cần Vue 3.5.5 trở lên với `skipLibCheck: false`; với `skipLibCheck: true`, thiết lập thường gặp trong template, các phiên bản cũ hơn cũng biên dịch được.

## Thiết lập {#setup}

```
locales/en.json
locales/fr.json
locales/pages/guide/demo/en.json   # optional page-scoped
locales/pages/guide/demo/fr.json
```

Các tệp trang ánh xạ tới tên route giống như Nuxt/Astro (`guide/demo` → `guide-demo`).

### 1. Cấu hình — `@i18n-micro/vitepress/config` {#1-config-—-@i18n-micro/vitepress/config}

```ts
// .vitepress/config.mts
import { defineConfig } from 'vitepress'
import { withI18n, buildVitePressLocales } from '@i18n-micro/vitepress/config'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English', og: 'en_US' },
  { code: 'fr', iso: 'fr-FR', displayName: 'Français', og: 'fr_FR' },
]
const defaultLocale = 'en'

export default defineConfig(
  withI18n(
    {
      locales: buildVitePressLocales(locales, defaultLocale),
      // themeConfig.i18nRouting is injected automatically
    },
    {
      locale: defaultLocale,
      defaultLocale,
      locales,
      translationDir: 'locales',
      metaBaseUrl: 'https://example.com', // optional SEO head
    },
  ),
)
```

### 2. Theme — `@i18n-micro/vitepress/theme` {#2-theme-—-@i18n-micro/vitepress/theme}

```ts
// .vitepress/theme/index.ts
import DefaultTheme from 'vitepress/theme'
import { defineI18nTheme } from '@i18n-micro/vitepress/theme'

export default defineI18nTheme(DefaultTheme)
```

Locale ban đầu được lấy từ đường dẫn hiện tại trước khi cài đặt (không bị nháy locale mặc định trên `/fr/…`).

### Nâng cao: `createI18n` thủ công {#advanced-manual-createi18n}

Một factory duy nhất cho client: plugin Vue + các phương thức đường dẫn + `enhanceApp` (không có export hàm trợ giúp router riêng).

```ts
import { createI18n, messagesFromGlob } from '@i18n-micro/vitepress'

const i18n = createI18n({
  locale: 'en',
  defaultLocale: 'en',
  locales: [{ code: 'en' }, { code: 'fr' }],
  messages: messagesFromGlob(import.meta.glob('../../locales/*.json', { eager: true })),
})

i18n.localizePath('/guide', 'fr')
// in theme enhanceApp:
i18n.enhanceApp({ app, router })
```

### Script Node — `@i18n-micro/vitepress/node` {#node-scripts-—-@i18n-micro/vitepress/node}

Dùng `createI18n` / `loadTranslations` của `@i18n-micro/node` (giống Astro và CLI), sau đó gắn các phương thức đường dẫn của VitePress bằng `BaseI18n.extend`:

```ts
import { createI18n } from '@i18n-micro/vitepress/node'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  translationDir: './locales',
  locales: ['en', 'fr'],
  defaultLocale: 'en',
})
await i18n.loadTranslations()
i18n.t('cta.readMore')
i18n.localizePath('/guide', 'fr')
```

Node thuần không có đường dẫn: `import { createI18n } from '@i18n-micro/node'`.

## Bản dịch trong trang {#in-page-translations}

Mỗi tệp markdown của VitePress là một Vue SFC.

### Component toàn cục và `$t` (khuyến nghị trong markdown) {#global-components-and-$t-recommended-in-markdown}

`createI18n` / `defineI18nTheme` cài đặt `@i18n-micro/vue`, vốn đăng ký `I18nT` / `I18nLink` / `I18nGroup` / `I18nSwitcher` và `$t` / `$tc` / `$ts`.

```md
{{ $t('cta.readMore') }}

<I18nT keypath="greeting" :params="{ name: 'VitePress' }" />

<I18nLink to="/guide/demo">Demo</I18nLink>
```

### `useI18n` trong `<script setup>` {#usei18n-in-<script-setup>}

```md
<script setup>
import { useI18n } from '@i18n-micro/vitepress'
const { t, tc, locale, localePath, switchLocale } = useI18n()
</script>

# {{ t('section.title') }}
```

## Menu chọn ngôn ngữ {#language-dropdown}

Khi `locales` có nhiều hơn một mục, VitePress hiển thị menu ngôn ngữ riêng của nó (`VPNavBarTranslations`). `withI18n` kết nối `themeConfig.i18nRouting` để biểu tượng quả địa cầu khớp với `<I18nSwitcher>` / các hàm trợ giúp đường dẫn.

Chỉ dùng `<I18nSwitcher>` trong các layout tùy chỉnh, không đặt cạnh biểu tượng quả địa cầu mặc định.

## Lưu ý về SSR {#ssr-notes}

- Locale khi prerender đến từ đường dẫn URL, không phải từ cookie.
- Mã theme không được truy cập `window` tại thời điểm import.
- Import `defineI18nTheme` từ `/theme` để việc đánh giá cấu hình trong Node không bao giờ tải `virtual:i18n-micro/*`.

## Bề mặt API {#api-surface}

| Export | Vai trò |
|--------|------|
| `createI18n` (`.`) | Client: plugin Vue + các phương thức đường dẫn + `enhanceApp` |
| `getLocaleFromPath` / `stripSiteBase` / `routeNameFromPath` (`.`) | Đồng bộ locale thủ công khi `syncWithVitePress: false` |
| `createI18n` (`/node`) | Node: `@i18n-micro/node` + các phương thức đường dẫn |
| `defineI18nTheme` (`/theme`) | Theme không cần mã khởi tạo |
| `withI18n` (`/config`) | Cấu hình + module ảo + SEO tùy chọn |
| `buildVitePressLocales` (`/config`) | Tạo `locales` của VitePress từ `Locale[]` |
| `buildVitePressLocaleHead` (`/config`) | Head SEO thủ công (cũng được `metaBaseUrl` sử dụng) |
| `messagesFromGlob` | Ánh xạ glob → messages tùy chọn cho `createI18n` |
| `useI18n` / `I18nT` / … | Được export lại từ `@i18n-micro/vue` |
| `BaseI18n.extend` (`@i18n-micro/core`) | Gắn phương thức tùy chỉnh vào bất kỳ instance i18n nào |

## Trang kiểu OpenAPI (khóa tích hợp) {#openapi-style-sites-integration-locks}

Bộ kiểm thử hồi quy: `packages/vitepress/tests/integration-openapi.test.ts` (đường dẫn sâu, `base=/openapi_docs/`, tắt đồng bộ + locale thủ công, trình tạo Node, SEO).

| Mẫu | Việc cần làm |
|---------|---------|
| Các trang sâu `/…/{spec}/{op}`, chỉ có JSON giao diện gốc | Ưu tiên `syncWithVitePress: true` mặc định (giữ `setRoute('index')` khi không có từ điển trang) **hoặc** `syncWithVitePress: false` + `getLocaleFromPath` |
| Không bao giờ gọi `setRoute(deepName)` khi không có từ điển trang | Các khóa giao diện gốc biến mất cho đến khi gọi `setRoute('index')` |
| Trình tạo / `getTranslation` | `createI18n` từ `/node` + `await loadTranslations()` + `i18n.t(key)` (đặt `i18n.locale`) |
| Canonical tùy chỉnh trong `transformPageData` | Truyền `meta: false` cho `withI18n` (tránh trùng thẻ) |
| SEO của package với base của trang | `metaBaseUrl` + `base` của VitePress → URL tuyệt đối bao gồm base |
| Đổi tên từ các bản build cũ của package | `withI18nMicro` → `withI18n`, `createVitePressI18n` → `createI18n`, `loadMessages` → node `createI18n` |
