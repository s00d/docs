# Tích hợp

Các gói `@i18n-micro` là các phiên bản dành riêng cho framework, nhẹ của Nuxt I18n Micro được thiết kế để tích hợp vào nhiều framework và môi trường khác nhau. Các gói này cung cấp chức năng quốc tế hóa cốt lõi với dấu chân tối thiểu, tập trung vào các tính năng dịch thiết yếu và các component cơ bản.

## Tổng quan

Các gói tích hợp này là **phiên bản thu nhỏ** của module Nuxt I18n Micro đầy đủ, chỉ chứa chức năng thiết yếu cần thiết cho quốc tế hóa:

- **Tính năng dịch cốt lõi** - Các phương thức dịch cơ bản, pluralization và định dạng
- **Component thiết yếu** - Một tập nhỏ các component UI cho các tác vụ i18n phổ biến
- **Mẫu Router Adapter** - Tích hợp định tuyến linh hoạt thông qua trừu tượng hóa adapter
- **Hỗ trợ TypeScript** - Định nghĩa kiểu đầy đủ cho phát triển an toàn kiểu

Không giống module Nuxt đầy đủ, các gói này:

- Không bao gồm logic định tuyến dành riêng cho framework
- Yêu cầu bạn triển khai một router adapter cho các tính năng định tuyến
- Tập trung vào chức năng dịch thay vì tích hợp framework
- Được thiết kế nhẹ và không phụ thuộc framework khi có thể

## Các component cốt lõi

Tất cả các gói framework bao gồm các component thiết yếu sau:

### `<I18nT>`

Một component dịch render văn bản đã dịch với hỗ trợ:

- **Nội suy tham số** - Thay thế các placeholder với các giá trị động
- **Pluralization** - Tự động chọn dạng số nhiều dựa trên số đếm
- **Định dạng số** - Định dạng số theo locale
- **Định dạng ngày** - Định dạng ngày và thời gian tương đối
- **Render HTML** - Render nội dung HTML tùy chọn
- **Giá trị mặc định** - Văn bản dự phòng khi bản dịch thiếu

**Ví dụ:**

```vue
<!-- Vue -->
<I18nT keypath="greeting" :params="{ name: 'World' }" />
```

```tsx
// React
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```tsx
// Solid
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

```astro
<!-- Astro -->
<I18nT keypath="greeting" params={{ name: 'World' }} />
```

### `<I18nLink>`

Một component link bản địa hóa tự động xử lý các tiền tố locale trong URL. Tính năng:

- **Bản địa hóa đường dẫn tự động** - Thêm/bỏ tiền tố locale dựa trên chiến lược định tuyến
- **Phát hiện trạng thái đang hoạt động** - Làm nổi bật route hiện tại
- **Hỗ trợ link bên ngoài** - Tự động phát hiện và xử lý các URL bên ngoài
- **Tích hợp Router** - Dùng component link của router adapter khi khả dụng
- **Styling tùy chỉnh** - Hỗ trợ các trạng thái active và hover

**Ví dụ:**

```vue
<!-- Vue -->
<I18nLink to="/about" active-class="active">
  About Us
</I18nLink>
```

```tsx
// React
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```tsx
// Solid
<I18nLink to="/about" activeStyle={{ fontWeight: 'bold' }}>
  About Us
</I18nLink>
```

```astro
<!-- Astro -->
<I18nLink href="/about" class="nav-link">
  About Us
</I18nLink>
```

### `<I18nSwitcher>`

Một component chuyển đổi ngôn ngữ cung cấp giao diện dropdown hoặc list để thay đổi locale. Tính năng:

- **Danh sách locale tự động** - Tạo các tùy chọn từ các locale đã cấu hình
- **Làm nổi bật locale hiện tại** - Chỉ ra ngôn ngữ đang hoạt động một cách trực quan
- **Nhãn tùy chỉnh** - Hỗ trợ tên hiển thị tùy chỉnh theo locale
- **Tích hợp Router** - Tự động điều hướng đến các đường dẫn đã bản địa hóa
- **Khả năng truy cập** - Các thuộc tính ARIA phù hợp và điều hướng bằng bàn phím

**Ví dụ:**

```vue
<!-- Vue -->
<I18nSwitcher />
```

```tsx
// React
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```tsx
// Solid
<I18nSwitcher locales={locales} currentLocale={locale} switchLocale={switchLocale} />
```

```astro
<!-- Astro -->
<I18nSwitcher />
```

### `<I18nGroup>`

Một component để nhóm các bản dịch với một tiền tố chung, hữu ích để tổ chức các bản dịch theo trang hoặc tính năng. Tính năng:

- **Đặt phạm vi tiền tố** - Tự động thêm tiền tố vào tất cả các khóa bản dịch trong nhóm
- **Nhóm lồng nhau** - Hỗ trợ các nhóm bản dịch lồng nhau
- **Tổ chức sạch sẽ** - Giúp duy trì cấu trúc bản dịch có tổ chức

**Ví dụ:**

```vue
<!-- Vue -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

```tsx
// React
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```tsx
// Solid
<I18nGroup prefix="home">
  <I18nT keypath="title" /> {/* Uses "home.title" */}
  <I18nT keypath="description" /> {/* Uses "home.description" */}
</I18nGroup>
```

```astro
<!-- Astro -->
<I18nGroup prefix="home">
  <I18nT keypath="title" /> <!-- Uses "home.title" -->
  <I18nT keypath="description" /> <!-- Uses "home.description" -->
</I18nGroup>
```

## Các tùy chọn `createI18n` dùng chung \{#create-i18n-options\}

Mọi gói framework được tạo theo cùng một cách — chỉ có kiểu tùy chọn được đặt tên theo
framework (`ReactI18nOptions`, `SolidI18nOptions`, v.v.). Chính các tùy chọn
đều giống nhau:

| Thuộc tính         | Kiểu                                                       | Bắt buộc | Mặc định          | Mô tả                                    |
| ---------------- | ---------------------------------------------------------- | -------- | ---------------- | ---------------------------------------------- |
| `locale`         | `string`                                                   | ✅       | -                | Mã locale hiện tại (ví dụ, `'en'`)             |
| `fallbackLocale` | `string`                                                   | ❌       | Giống `locale` | Locale dự phòng khi bản dịch thiếu    |
| `messages`       | `Record<string, Translations>`                             | ❌       | `\{\}`             | Các thông điệp bản dịch ban đầu                   |
| `plural`         | `PluralFunc`                                               | ❌       | `defaultPlural`  | Hàm pluralization tùy chỉnh                  |
| `missingWarn`    | `boolean`                                                  | ❌       | `true`           | Hiển thị cảnh báo console cho các bản dịch thiếu |
| `missingHandler` | `(locale: string, key: string, routeName: string) => void` | ❌       | -                | Handler tùy chỉnh cho các bản dịch thiếu        |

Bất cứ điều gì ngoài những cái này đều là dành riêng cho framework và được ghi tài liệu trên trang của gói đó.

## Trừu tượng hóa Router Adapter

Tất cả các gói framework dùng **mẫu router adapter** để tách rời chức năng i18n khỏi các triển khai router cụ thể. Thiết kế này cho phép:

- **Linh hoạt** - Dùng bất kỳ thư viện router nào hoặc không dùng router
- **Độc lập với framework** - Giữ logic định tuyến trong ứng dụng của bạn, không phải trong gói i18n
- **Cốt lõi nhẹ** - Gói i18n vẫn nhỏ và tập trung

### Triển khai Router Adapter

Để dùng các tính năng định tuyến, bạn cần triển khai interface `I18nRoutingStrategy`:

```typescript
interface I18nRoutingStrategy {
  getCurrentPath: () => string
  linkComponent?: Component
  push: (target: { path: string }) => void
  replace: (target: { path: string }) => void
  resolvePath?: (to: string | { path?: string }, locale: string) => string | { path?: string }
  getRoute?: () => { fullPath: string; query: Record<string, unknown> }
}
```

Tài liệu của mỗi gói bao gồm các ví dụ hoàn chỉnh về việc triển khai adapter cho các router phổ biến:

- **Vue**: Ví dụ Vue Router adapter
- **React**: Ví dụ React Router adapter
- **Solid**: Ví dụ Solid Router adapter
- **Astro**: Ví dụ adapter định tuyến dựa trên tệp

## Tính năng cốt lõi

Tất cả các gói chia sẻ các tính năng cốt lõi này:

### Các phương thức dịch

- `t()` - Dịch cơ bản với nội suy tham số
- `ts()` - Dịch luôn trả về chuỗi
- `tc()` - Dịch nhận biết pluralization
- `tn()` - Định dạng số
- `td()` - Định dạng ngày
- `tdr()` - Định dạng thời gian tương đối
- `has()` - Kiểm tra xem khóa bản dịch có tồn tại không

### Quản lý Locale

- **Chuyển đổi Locale** - Thay đổi locale hiện tại bằng chương trình
- **Locale dự phòng** - Dự phòng tự động khi bản dịch thiếu
- **Bản dịch theo route** - Tổ chức bản dịch cấp trang
- **Cache bản dịch** - Cache thông minh để có hiệu năng

### Hỗ trợ TypeScript

Tất cả các gói cung cấp:

- Định nghĩa TypeScript đầy đủ
- Khóa bản dịch an toàn kiểu (với types generator)
- Hỗ trợ IntelliSense trong IDE
- Kiểm tra lỗi tại thời điểm biên dịch
