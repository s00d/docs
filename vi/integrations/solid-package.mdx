`@i18n-micro/solid` cung cấp cho app SolidJS một instance i18n dựa trên signal, một provider, `useI18n()` và bốn component. Hãy dùng nó trong app Solid không được build bằng Nuxt. Việc đọc `t()` bên trong JSX hoặc effect sẽ theo dõi locale, route và các từ điển; mô hình chung có tại [Frameworks](/vi/integrations/overview).

## Cài đặt {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/solid
```

```bash npm
npm install @i18n-micro/solid
```

```bash yarn
yarn add @i18n-micro/solid
```

</CodeGroup>

Peer dependency: `solid-js` `^1.8.0`; `@solidjs/router` `^0.15.4 || ^1.0.0` (tùy chọn, chỉ cho `@i18n-micro/solid/router`). Solid 2 chưa được hỗ trợ.

## Thiết lập {#setup}

```tsx
// src/index.tsx
import { render } from 'solid-js/web'
import { createI18n, I18nProvider } from '@i18n-micro/solid'
import App from './App'
import en from './locales/en.json'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English' },
  { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
]

const i18n = createI18n({ locale: 'en', fallbackLocale: 'en', messages: { en } })

render(
  () => (
    <I18nProvider i18n={i18n} locales={locales} defaultLocale="en">
      <App />
    </I18nProvider>
  ),
  document.getElementById('root')!,
)
```

`<I18nProvider>` nhận `i18n`, `locales`, `defaultLocale` và `routingStrategy`; prop bị bỏ qua sẽ giữ giá trị của provider bên ngoài, kể cả instance. `getLocaleName()` và `<I18nSwitcher>` đọc `locales`; thiếu nó thì chúng không có gì để liệt kê. Các tùy chọn có tại [instance](/vi/integrations/overview#the-instance). Instance là của [runtime](/vi/integrations/runtime-package), với một signal bao trên store của nó.

## Dịch {#translate}

```tsx
import { useI18n } from '@i18n-micro/solid'

export function Greeting() {
  const { t, tc, tn } = useI18n()
  return (
    <>
      <h1>{t('greeting', { name: 'Ada' }) as string}</h1> {/* Hello, Ada! */}
      <p>{tc('apples', 3)}</p> {/* 3 apples */}
      <p>{tn(1234.5)}</p>
    </>
  )
}
```

Gọi các phương thức bên trong JSX hoặc effect để Solid theo dõi chúng, kể cả `localePath` và `getLocale`; giá trị được đọc một lần trong thân component sẽ không cập nhật. Trên instance, hãy theo dõi bằng `i18n.locale` và `i18n.currentRoute`: `i18n.getLocale()` vẫn là hàm thường, vì các thao tác ghi đọc nó. Việc đọc locale chỉ được đánh thức bởi locale, nên một effect đọc nó và tải từ điển sẽ chạy một lần. Đừng destructure props hoặc giữ kết quả `t('key')` trong biến thường.

`useI18n()` trả về `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`, `locale` (một accessor: `locale()`), `getLocale`, `getLocales`, `defaultLocale()`, `getLocaleName`, `switchLocale`, `localePath`, `localeRoute`, `setRoute`, `getRoute`, `addTranslations`, `addRouteTranslations`, `resolveTranslations`, `setTranslation`, `clearCache` và `instance`.

```ts
const { addTranslations, addRouteTranslations, setRoute } = useI18n()

addTranslations('de', (await import('./locales/de.json')).default)
addRouteTranslations('en', 'about', { title: 'About us' })
setRoute('about') // t('title') now reads the 'about' dictionary first
```

## Chuyển locale {#switch-locale}

```ts
const { instance, switchLocale } = useI18n()

instance.locale = 'de' // only the locale
switchLocale('de') // the locale, then the adapter's push to the localized current path
```

Việc chuyển đổi không tải gì cả; hãy thêm từ điển của locale trước.

`<I18nGroup>` truyền một `t` có tiền tố cho một function child. `<I18nT>` và `t()` bên trong nó không có tiền tố:

```tsx
<I18nGroup prefix="profile">{({ t }) => <h2>{t('title')}</h2> /* profile.title */}</I18nGroup>
```

## Định tuyến {#routing}

Adapter cho `@solidjs/router` nằm trong một subpath để entry chính không bao giờ import router. Hãy gọi nó bên dưới router, thường trong `root` của router, nơi `useNavigate` và `useLocation` hoạt động:

```tsx
// src/App.tsx
import { Route, Router, useLocation, useNavigate, type RouteSectionProps } from '@solidjs/router'
import { I18nLink, I18nProvider, I18nSwitcher } from '@i18n-micro/solid'
import { createSolidRouterAdapter } from '@i18n-micro/solid/router'
import { i18n, locales } from './i18n'
import { About, Home } from './pages'

function Root(props: RouteSectionProps) {
  const routingStrategy = createSolidRouterAdapter(locales, 'en', useNavigate(), useLocation())
  return (
    <I18nProvider i18n={i18n} locales={locales} defaultLocale="en" routingStrategy={routingStrategy}>
      <I18nLink to="/about">About</I18nLink>
      <I18nSwitcher />
      {props.children}
    </I18nProvider>
  )
}

export default function App() {
  return (
    <Router root={Root}>
      <Route path="/:locale?" component={Home} />
      <Route path="/:locale?/about" component={About} />
    </Router>
  )
}
```

Adapter thêm tiền tố cho mọi locale trừ locale mặc định (`/about`, `/de/about`), và render `<I18nLink>` thành `<A>` của router. `getCurrentPath` đọc location reactive của router, nên liên kết active và bộ chuyển đổi đi theo nó; một chiến lược tùy chỉnh có được điều tương tự bằng cách đọc một signal ở đó. Lưu ý thứ tự đối số: `(locales, defaultLocale, navigate, location)`. Với các router khác, hãy viết adapter có `getCurrentPath`, `push` và `replace` (đều bắt buộc) — xem [Router adapter](/vi/integrations/overview#router-adapter).

## SSR {#ssr}

Để render phía máy chủ, hãy build với `vite-plugin-solid`: điều kiện export `solid` của package cung cấp mã nguồn cho nó, nên nó được biên dịch cho máy chủ. Bản `dist` dựng sẵn chỉ dành cho trình duyệt. Instance không có `destroy()`; hãy tạo một instance cho mỗi app, hoặc một cho mỗi yêu cầu trên máy chủ, và để bộ thu gom rác xử lý.
