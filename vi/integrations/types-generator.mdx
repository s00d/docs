description: "Tạo gợi ý TypeScript cho các khóa bản dịch từ tệp JSON của bạn, trong Nuxt hoặc bất kỳ dự án Vite nào."
---

`@i18n-micro/types-generator` đọc mọi tệp JSON trong thư mục bản dịch của bạn và ghi ra một tệp khai báo liệt kê tất cả các khóa. Hãy thêm nó khi bạn muốn trình soạn thảo gợi ý khóa trong `t()`, `$t()` và `<I18nT keypath>`. Nó hoạt động như một module Nuxt và như một plugin Vite hoặc Rollup, và tự tạo lại khi một tệp thay đổi.

## Cài đặt {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/types-generator
```

```bash npm
npm install -D @i18n-micro/types-generator
```

```bash yarn
yarn add -D @i18n-micro/types-generator
```

</CodeGroup>

Peer dependency: `@nuxt/kit` `^3.18.0 || ^4.0.0`. Chỉ entry `/nuxt` import nó; trong dự án chỉ dùng Vite, có thể bỏ qua cảnh báo peer.

## Nuxt {#nuxt}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro', '@i18n-micro/types-generator/nuxt'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Module ghi `.nuxt/types/i18n-micro.d.ts` và Nuxt thêm nó vào ngữ cảnh kiểu; không cần include thủ công. Nó đọc `i18nTypes.translationDir`, nếu không thì đọc ở nơi `nuxt-i18n-micro` đọc bản dịch: `translationDir` (từ `i18n` hoặc tùy chọn module inline, mặc định `'locales'`) trong mọi layer, và `additionalTranslationDirs`. Chỉnh sửa một tệp JSON trong thư mục đó sẽ tạo lại các kiểu trong `nuxi dev`. `i18nTypes.outputFile` bị bỏ qua trong Nuxt (có cảnh báo thông báo điều này).

## Vite {#vite}

`I18nTypesPlugin` là một plugin Vite, Rollup cũng chấp nhận nó. Với bundler khác, hãy gọi `generateTypes` trong một script.

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { I18nTypesPlugin } from '@i18n-micro/types-generator'

export default defineConfig({
  plugins: [
    vue(),
    I18nTypesPlugin({
      srcDir: process.cwd(),
      translationDir: 'src/locales',
      outputFile: 'src/i18n-micro.d.ts',
    }),
  ],
})
```

| Tùy chọn | Bắt buộc | Ghi chú |
| --- | --- | --- |
| `srcDir` | có | Thư mục cơ sở; `translationDir` được phân giải dựa trên nó. |
| `translationDir` | có | Thư mục chứa các tệp JSON (bao gồm thư mục con như `pages/`), hoặc một mảng thư mục. |
| `outputFile` | không | Nơi ghi tệp khai báo; mặc định `<srcDir>/i18n-micro.d.ts`. |

Plugin tạo một lần khi bắt đầu build và, trên dev server, tạo lại 300 ms sau khi có thay đổi trong thư mục. Hãy đảm bảo `include` trong `tsconfig.json` bao gồm tệp đầu ra.

## Sử dụng các khóa {#use-the-keys}

Tệp được tạo sẽ augment `DefineLocaleMessage` trong `@i18n-micro/types`, biến `TranslationKey` thành các khóa của bạn:

```ts
declare module '@i18n-micro/types' {
  export interface DefineLocaleMessage {
    nav: object
    'nav.home': string
    'profile.title': string
  }
}
```

Các khóa là những khóa mà `t()` trả lời được, kể cả đối tượng, từ mọi locale và mọi tệp trang, với kiểu của giá trị JSON tương ứng. `TranslationKey` là hợp của các khóa đó cộng với bất kỳ chuỗi nào, nên bạn được gợi ý, không bị lỗi: một khóa viết sai hoặc động vẫn biên dịch được. Params và giá trị trả về không được khai báo kiểu.

Với các khóa động dưới một tiền tố đã biết, `ScopedKey<'prefix'>` thu hẹp về các khóa khớp:

```ts
import type { ScopedKey } from '@i18n-micro/types'

const statusText = (status: string) => t(`status.${status}` as ScopedKey<'status'>)
```

`TranslationKey` và `ScopedKey` đến từ `@i18n-micro/types` (React, Preact và Solid re-export `TranslationKey`; Vue thì không).

## API {#api}

| Export | Entry | Ghi chú |
| --- | --- | --- |
| `I18nTypesPlugin(options)` | `@i18n-micro/types-generator` | Plugin Vite và Rollup |
| `generateTypes(options)` | `@i18n-micro/types-generator` | ghi tệp, trả về đường dẫn của nó |
| `getTypesString(options)` | `@i18n-micro/types-generator` | trả về tệp khai báo mà không ghi |
| `formatKeyProperty(key)` | `@i18n-micro/types-generator` | helper |
| Module Nuxt (`configKey: 'i18nTypes'`) | `@i18n-micro/types-generator/nuxt` | tùy chọn `translationDir` |

Chữ ký đầy đủ: [tham chiếu package](/vi/api/packages/types-generator).
