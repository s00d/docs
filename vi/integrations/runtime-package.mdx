`@i18n-micro/runtime` là instance i18n độc lập với framework: từ điển, `t()`, số nhiều, định dạng `Intl` và cơ chế đăng ký theo dõi thay đổi, không cần `fs` và không cần framework. Hãy dùng nó trong TypeScript thuần, một web worker, một edge function, hoặc làm nền cho binding của riêng bạn. Các package React, Preact, Node và Astro đều mở rộng chính class này.

## Cài đặt {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/runtime
```

```bash npm
npm install @i18n-micro/runtime
```

```bash yarn
yarn add @i18n-micro/runtime
```

</CodeGroup>

Không có peer dependency. Với các tệp bản dịch trên đĩa, hãy dùng [`@i18n-micro/node`](/vi/integrations/nodejs-package).

## Thiết lập {#setup}

```ts
import { createI18n } from '@i18n-micro/runtime'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    en: { greeting: 'Hello, {name}!', apples: 'no apples | one apple | {count} apples' },
    de: { greeting: 'Hallo, {name}!' },
  },
  routeMessages: {
    about: { en: { title: 'About us' } },
  },
})
```

Mọi tùy chọn (`plural`, `missingWarn`, `missingHandler`, `numberFormats`, `datetimeFormats`) được liệt kê trong [instance](/vi/integrations/overview#the-instance).

## Dịch {#translate}

```ts
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.tc('apples', 5) // '5 apples'
i18n.tn(1234.5) // '1,234.5'

i18n.setRoute('about')
i18n.t('title') // 'About us' (route dictionary)
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!' (root, still visible)
```

Tải thêm từ điển sau đó:

```ts
i18n.loadMessages({ fr: { greeting: 'Bonjour, {name} !' } }, { about: { fr: { title: 'À propos' } } })
i18n.addTranslations('fr', { nav: { home: 'Accueil' } }) // deep merge; pass false to replace

await i18n.loadFromUrl('/locales/fr.json', { locale: 'fr' })
await i18n.loadFromUrl('/locales/pages/about/fr.json', { locale: 'fr', routeName: 'about' })
await i18n.loadFromUrls([
  { url: '/locales/en.json', locale: 'en' },
  { url: '/locales/de.json', locale: 'de' },
])
```

`loadFromUrl` dùng `fetch` (truyền `init` để đặt header) và ném lỗi khi response không OK. `loadFromUrls` tải lần lượt từng cái một.

## Chuyển locale {#switch-locale}

```ts
i18n.locale = 'de'
i18n.t('greeting', { name: 'Ada' }) // 'Hallo, Ada!'
```

Các thay đổi về locale, route và từ điển sẽ thông báo cho subscriber, đó là cách các binding framework render lại:

```ts
const stop = i18n.subscribe(() => {
  document.querySelector('#greeting')!.textContent = i18n.t('greeting', { name: 'Ada' }) as string
})
i18n.locale = 'fr'
stop()
```

`getSnapshot()` trả về một chuỗi thay đổi sau mỗi lần thông báo (cho các store kiểu `useSyncExternalStore`).

## Theo từng request {#per-request}

Instance giữ một locale và một route. Trên server, đừng chuyển locale của một instance dùng chung theo từng request: hai request đồng thời sẽ thấy locale của nhau. `i18n.fork(locale)` cho mỗi request một instance riêng: locale, locale dự phòng và route riêng; cùng từ điển, bộ định dạng và quy tắc. Chi phí fork là như nhau bất kể có bao nhiêu từ điển. Một fork thấy các phép ghi vào instance cha cho đến phép ghi đầu tiên của chính nó, và các phép ghi của nó ở lại trong nó. [Node.js](/vi/integrations/nodejs-package#per-request) bổ sung `run`.

## API {#api}

| Thành viên | Ghi chú |
| --- | --- |
| `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has` | xem [Dịch và định dạng](/vi/integrations/overview#translate-and-format) |
| `locale`, `fallbackLocale` | get/set |
| `currentRoute`, `setRoute(name)`, `getRoute()` | route đang hoạt động, mặc định `'index'` |
| `loadMessages(messages?, routeMessages?)` | hợp nhất nhiều locale và route cùng lúc |
| `addTranslations(locale, tree, merge = true)`, `addRouteTranslations(locale, route, tree, merge = true)` | |
| `loadFromUrl(url, { locale?, routeName?, init? })`, `loadFromUrls(entries)` | `fetch` JSON |
| `hasTranslation(key)` | locale đang hoạt động, bất kỳ route nào (khác với `has`, vốn kiểm tra route đang hoạt động và gốc) |
| `setTranslation(key, value)`, `resolveTranslations()` | ghi một khóa; đọc cây đã hợp nhất |
| `clear()`, `clearCache()` | loại bỏ mọi từ điển |
| `subscribe(cb)`, `getSnapshot()` | thông báo thay đổi |
| `storage` | `{ translations: Map<'locale:route', Translations> }` |

Một mã không phải là language tag sẽ lấy quy tắc số nhiều từ `localeIso: { ua: 'uk-UA' }`; `localeIsoMap(locales)` tạo giá trị đó từ các mục có `iso` trong một danh sách locale.

Export của module: `createI18n`, `I18n`, `fetchJsonTranslations`, `FormatService`, `interpolate`, `localeIsoMap` và các kiểu `I18nOptions`, `LoadFromUrlOptions`, `LoadFromUrlEntry`, `TranslationStorage`, `Translations`, `Locale`, `PluralFunc`. Chữ ký đầy đủ: [tham chiếu package](/vi/api/packages/runtime).
