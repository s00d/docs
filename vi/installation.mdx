## Yêu cầu

- **Node.js**: 18 trở lên.
- **Nuxt**: 3.x hoặc 4.x.

Mô-đun hỗ trợ cả bố cục dự án Nuxt 3 (`pages/**/*.vue`) và bố cục Nuxt 4 (`app/pages/**/*.vue`). Theo quy ước, các bản dịch nằm ở gốc dự án (`locales/`), ngay cả khi bạn sử dụng thư mục `app/` của Nuxt 4.

## Cài đặt mô-đun Nuxt

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Đăng ký mô-đun trong `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Xem [Hướng dẫn nhanh](/quickstart) để có tổng quan đầy đủ hoặc [Tham chiếu cấu hình](/guides/configuration) để biết mọi tùy chọn.

## Bố cục dự án

Theo mặc định, mô-đun mong đợi:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Các tệp cấp gốc được hợp nhất vào mọi tệp riêng cho trang tại thời điểm build. Các tệp riêng cho trang được tạo tự động nếu thiếu khi chạy `nuxt dev`.

## Bố cục Nuxt 4

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Để đặt bản dịch cùng vị trí bên trong `app/`, hãy dùng `translationDir: 'app/locales'`.

| Gói | Mục đích |

## TypeScript

Mô-đun tự sinh các kiểu ambient cho `useI18n`, `$t`, và các trợ giúp liên quan dựa trên tệp ngôn ngữ mặc định của bạn. Tính năng này được bật mặc định (`types: true`).

Để có kiểu mạnh hơn cho các khóa bản dịch, xem [`@i18n-micro/types-generator`](/integrations/types-generator).
