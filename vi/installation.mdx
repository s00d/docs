## Yêu cầu

- **Node.js**: 18 trở lên.
- **Nuxt**: 3.x hoặc 4.x.

Module hỗ trợ cả bố cục dự án Nuxt 3 (`pages/**/*.vue`) và bố cục Nuxt 4 (`app/pages/**/*.vue`). Theo quy ước, các bản dịch nằm ở gốc dự án (`locales/`), ngay cả khi dùng thư mục `app/` của Nuxt 4.

## Cài đặt module Nuxt

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Đăng ký nó trong `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Xem [Khởi động nhanh](/quickstart) để có hướng dẫn đầy đủ hoặc [Tham chiếu cấu hình](/guides/configuration) cho mọi tùy chọn.

## Bố cục dự án

Theo mặc định, module mong đợi:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Các tệp cấp gốc được gộp vào mọi tệp theo trang tại thời điểm build. Các tệp theo trang được tự động tạo khi thiếu trong quá trình `nuxt dev`.

## Bố cục Nuxt 4

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

Để đặt bản dịch cùng chỗ dưới `app/`, hãy thiết lập `translationDir: 'app/locales'`.

## TypeScript

Module tạo các kiểu ambient cho `useI18n`, `$t`, và các trình trợ giúp liên quan dựa trên các tệp locale mặc định của bạn. Điều này được bật theo mặc định (`types: true`).

Để có kiểu chặt hơn cho các khóa bản dịch, xem [`@i18n-micro/types-generator`](/integrations/types-generator).
