# Sử dụng bản dịch trong thành phần

Sau khi mô-đun được cài đặt và cấu hình, bạn có thể hiển thị bản dịch bằng cách gọi `$t('your_key')` trong các template và script Vue.

## 1. Tệp bản dịch cấp gốc & theo trang

1. Các bản dịch **cấp gốc** nằm ngay dưới thư mục `/locales` (ví dụ `/locales/en.json`, `/locales/fr.json`). Tại thời điểm build, chúng tự động được gộp vào mọi tệp riêng theo trang, làm cho chúng khả dụng trên mọi trang.
2. Các bản dịch **riêng theo trang** nằm dưới `/locales/pages/...`, khớp với cấu trúc thư mục pages của Nuxt:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. Sử dụng trong template với `$t`

Trong các tệp `.vue`, bạn có thể dùng trực tiếp `$t` trong template:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
`$t` có thể trả về **đối tượng** nếu khóa trỏ đến một nút JSON lồng nhau (ví dụ `$t('header')` → `\{ title: "Hi" \}`). Trong template điều này hiển thị là `[object Object]`. Hãy dùng `$ts` khi cần một chuỗi đảm bảo, hoặc cung cấp khóa cụ thể hơn như `$t('header.title')`. Xem [Tham chiếu API — $t so với $ts](/api/methods#t) để biết chi tiết.
</Tip>

## 3. Chuyển ngôn ngữ hiện tại

Để thay đổi ngôn ngữ trong ứng dụng, bạn có thể lấy `$locale` từ `useI18n()` và gán một mã mới:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. Khóa lồng nhau và placeholder

- **Khóa lồng nhau** dùng ký hiệu dấu chấm, ví dụ `nested.key.deeper`.
- **Placeholder** cho phép bạn chèn các giá trị động:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. Mẹo & thực hành tốt nhất

- **Khóa xung đột**: Nếu một tệp riêng theo trang chứa cùng khóa như tệp cấp gốc, phiên bản riêng theo trang được ưu tiên (các bản dịch gốc được gộp làm nền tại thời điểm build).
- **Tắt tệp theo trang**: Nếu bạn không muốn dùng bản dịch riêng theo trang, bạn có thể đặt `disablePageLocales: true` trong cấu hình Nuxt. Khi đó, chỉ các tệp `/locales/*.json` được sử dụng.
- **Không cần nhập trực tiếp**: Bạn không cần `import \{ useI18n \} from 'nuxt-i18n-micro'`; tính năng tự động tiêm của mô-đun xử lý việc đó cho bạn.

Vậy là xong! Với các bước này, bạn có thể nhanh chóng **bắt đầu truy xuất bản dịch** từ các tệp JSON cấp gốc hoặc riêng theo trang và **hiển thị chúng** trong ứng dụng Nuxt bằng `$t`.

## Tài nguyên bổ sung

Để khám phá thêm các tính năng nâng cao, hãy xem:

1. **Thành phần `<i18n-t>`**  
   Thành phần `<i18n-t>` là một thay thế mạnh mẽ cho `$t`, đặc biệt hữu ích cho các tình huống liên quan đến các phần tử lồng nhau, sử dụng placeholder nâng cao và các cấu trúc bản dịch phức tạp hơn.

- **Tài liệu**: [i18n-t](/api/components/i18n-t)

2. **Composable `useI18n`**  
   Composable `useI18n` cung cấp một tập hợp đầy đủ các hàm và thuộc tính phản ứng để quản lý bản dịch, xử lý chuyển đổi ngôn ngữ, định dạng và nhiều hơn nữa.

- **Tài liệu**: [useI18n](/api/composables/use-i18n)
