# Sử dụng bản dịch trong component

Khi module đã được cài đặt và cấu hình, bạn có thể hiển thị bản dịch bằng cách gọi `$t('your_key')` trong template và script Vue của mình.

## 1. Tệp bản dịch cấp gốc & theo trang

1. Các bản dịch **cấp gốc** nằm trực tiếp dưới thư mục `/locales` (ví dụ `/locales/en.json`, `/locales/fr.json`). Tại thời điểm build, chúng được tự động gộp vào mọi tệp theo trang, giúp chúng có sẵn trên tất cả các trang.
2. Các bản dịch **theo trang** nằm dưới `/locales/pages/...`, khớp với cấu trúc thư mục pages Nuxt của bạn:

```text
locales/
├── en.json
├── fr.json
└── pages/
    └── dir1/
        ├── en.json
        └── fr.json

```

## 2. Sử dụng trong template với `$t`

Trong các tệp `.vue` của bạn, bạn có thể dùng trực tiếp `$t` trong template:

```vue
<template>
  <div>
    <!-- Root-level translation (available on all pages) -->
    <p>{{ $t('test_key') }}</p>
    <!-- Displays: Hello World! -->

    <!-- Page-specific translation (if this page is /dir1) -->
    <p>{{ $t('local_key') }}</p>
    <!-- Displays: This is a page-specific translation for /dir1. -->

    <!-- Nested key -->
    <p>{{ $t('nested.key.deeper') }}</p>
    <!-- Displays: Nested translation here -->

    <!-- Placeholder usage -->
    <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
    <!-- Displays: Hello, Alice! -->
  </div>
</template>

<script setup lang="ts">
// No need to import anything from 'nuxt-i18n-micro'.
// The plugin automatically provides `useI18n` and `$t`.
const { $t } = useI18n()

// You can now use $t in your script, for example:
console.log($t('test_key')) // "Hello World!"
</script>
```

<Tip>
`$t` có thể trả về **object** nếu khóa trỏ đến một node JSON lồng nhau (ví dụ `$t('header')` → `\{ title: "Hi" \}`). Trong template, điều này hiển thị dưới dạng `[object Object]`. Hãy dùng `$ts` khi bạn cần một chuỗi được đảm bảo, hoặc cung cấp một khóa cụ thể hơn như `$t('header.title')`. Xem [Tham chiếu API — $t vs $ts](/api/methods#t) để biết chi tiết.
</Tip>

## 3. Chuyển đổi locale hiện tại

Để thay đổi ngôn ngữ trong ứng dụng, bạn có thể lấy `$locale` từ `useI18n()` và gán cho nó một mã mới:

```vue
<template>
  <div>
    <button @click="$switchLocale('en')">English</button>
    <button @click="$switchLocale('fr')">Français</button>
  </div>
</template>

<script setup lang="ts">
// The plugin auto-injects these references
const { $t, $switchLocale } = useI18n()
</script>
```

## 4. Khóa lồng nhau và placeholder

- **Khóa lồng nhau** sử dụng ký pháp dấu chấm, ví dụ `nested.key.deeper`.
- **Placeholder** cho phép bạn chèn các giá trị động:
  ```json
  { "greeting": "Hello, {name}!" }
  ```
  ```vue
  <p>{{ $t('greeting', { name: 'Alice' }) }}</p>
  <!-- Displays: Hello, Alice! -->
  ```

## 5. Mẹo & thực hành tốt nhất

- **Khóa xung đột**: Nếu một tệp theo trang chứa cùng khóa với tệp cấp gốc, phiên bản theo trang được ưu tiên (các bản dịch gốc được gộp làm cơ sở tại thời điểm build).
- **Vô hiệu hóa tệp trang**: Nếu bạn không muốn dùng bản dịch theo trang, bạn có thể đặt `disablePageLocales: true` trong cấu hình Nuxt. Bằng cách này, chỉ các tệp `/locales/*.json` được sử dụng.
- **Không cần import trực tiếp**: Bạn không cần làm `import \{ useI18n \} from 'nuxt-i18n-micro'`; tính năng auto-injection của module xử lý điều đó cho bạn.

Vậy là xong! Với các bước này, bạn có thể nhanh chóng **bắt đầu lấy bản dịch** từ tệp JSON cấp gốc hoặc theo trang và **hiển thị chúng** trong ứng dụng Nuxt bằng `$t`.

## Tài nguyên bổ sung

Để khám phá thêm các tính năng nâng cao, hãy tham khảo:

1. **Component `<i18n-t>`**  
   Component `<i18n-t>` là một giải pháp thay thế mạnh mẽ cho `$t`, đặc biệt hữu ích cho các tình huống liên quan đến phần tử lồng nhau, cách dùng placeholder nâng cao và các cấu trúc bản dịch phức tạp hơn.

- **Tài liệu**: [i18n-t](/api/components/i18n-t)

2. **Composable `useI18n`**  
   Composable `useI18n` cung cấp một tập đầy đủ các hàm và thuộc tính reactive để quản lý bản dịch, xử lý chuyển đổi locale, định dạng và hơn thế nữa.

- **Tài liệu**: [useI18n](/api/composables/use-i18n)
