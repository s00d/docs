# 🌍 Thiết lập Locale đa miền với `Nuxt I18n Micro` bằng Layer

## 📝 Giới thiệu

Bằng cách tận dụng layer trong `Nuxt I18n Micro`, bạn có thể tạo một thiết lập bản địa hóa đa miền linh hoạt và dễ bảo trì. Cách tiếp cận này không chỉ đơn giản hóa việc quản lý miền bằng cách loại bỏ nhu cầu về các chức năng phức tạp mà còn cho phép phân phối tải hiệu quả và giảm độ phức tạp của dự án. Bằng cách chạy các dự án riêng biệt cho các locale khác nhau, ứng dụng của bạn có thể dễ dàng mở rộng và thích ứng với các yêu cầu locale khác nhau trên nhiều miền, mang lại giải pháp mạnh mẽ và có thể mở rộng cho các ứng dụng toàn cầu.

## 🎯 Mục tiêu

Tạo một thiết lập mà các miền khác nhau phục vụ các locale cụ thể bằng cách tùy chỉnh cấu hình trong các layer con. Phương pháp này tận dụng hệ thống layer của Nuxt, cho phép bạn duy trì cấu hình cơ sở đồng thời mở rộng hoặc sửa đổi nó cho từng miền.

## 🛠 Các bước triển khai Locale đa miền

### 1. **Tạo Layer cơ sở**

Bắt đầu bằng việc tạo layer cấu hình cơ sở bao gồm tất cả các thiết lập locale chung cho ứng dụng của bạn. Cấu hình này sẽ đóng vai trò là nền tảng cho các cấu hình theo miền khác.

#### **Cấu hình Layer cơ sở**

Tạo tệp cấu hình cơ sở `base/nuxt.config.ts`:

```typescript
// base/nuxt.config.ts

export default defineNuxtConfig({
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'de', iso: 'de-DE', dir: 'ltr' },
      { code: 'es', iso: 'es-ES', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
    autoDetectLanguage: true,
  },
})
```

### 2. **Tạo Layer con theo miền**

Cho mỗi miền, tạo một layer con sửa đổi cấu hình cơ sở để đáp ứng các yêu cầu cụ thể của miền đó. Bạn có thể vô hiệu hóa các locale không cần thiết cho một miền cụ thể.

#### **Ví dụ: Cấu hình cho miền tiếng Pháp**

Tạo cấu hình layer con cho miền tiếng Pháp trong `fr/nuxt.config.ts`:

```typescript
// fr/nuxt.config.ts

export default defineNuxtConfig({
  extends: '../base', // Inherit from the base configuration

  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: true }, // Disable English
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' }, // Add and enable the French locale
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: true }, // Disable German
      { code: 'es', iso: 'es-ES', dir: 'ltr', disabled: true }, // Disable Spanish
    ],
    defaultLocale: 'fr', // Set French as the default locale
    autoDetectLanguage: false, // Disable automatic language detection
  },
})
```

#### **Ví dụ: Cấu hình cho miền tiếng Đức**

Tương tự, tạo cấu hình layer con cho miền tiếng Đức trong `de/nuxt.config.ts`:

```typescript
// de/nuxt.config.ts

export default defineNuxtConfig({
  extends: '../base', // Inherit from the base configuration

  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: true }, // Disable English
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: true }, // Disable French
      { code: 'de', iso: 'de-DE', dir: 'ltr' }, // Use the German locale
      { code: 'es', iso: 'es-ES', dir: 'ltr', disabled: true }, // Disable Spanish
    ],
    defaultLocale: 'de', // Set German as the default locale
    autoDetectLanguage: false, // Disable automatic language detection
  },
})
```

### 3. **Triển khai ứng dụng cho từng miền**

Triển khai ứng dụng với cấu hình phù hợp cho từng miền. Ví dụ:

- Triển khai cấu hình layer `fr` lên `fr.example.com`.
- Triển khai cấu hình layer `de` lên `de.example.com`.

### 4. **Thiết lập nhiều dự án cho các Locale khác nhau**

Cho mỗi locale và miền, bạn sẽ cần chạy một instance riêng của ứng dụng. Điều này đảm bảo mỗi miền phục vụ cấu hình locale chính xác, tối ưu hóa việc phân phối tải và đơn giản hóa cấu trúc dự án. Bằng cách chạy nhiều dự án được tùy chỉnh cho từng locale, bạn có thể duy trì sự tách biệt sạch sẽ giữa các cấu hình và giảm độ phức tạp của thiết lập tổng thể.

### 5. **Cấu hình định tuyến dựa trên miền**

Đảm bảo định tuyến của bạn được cấu hình để hướng người dùng đến đúng dự án dựa trên miền họ đang truy cập. Điều này sẽ đảm bảo mỗi miền phục vụ locale phù hợp, nâng cao trải nghiệm người dùng và duy trì tính nhất quán trên các vùng khác nhau.

### 6. **Triển khai và xác minh**

Sau khi cấu hình các layer và triển khai chúng lên các miền tương ứng, hãy đảm bảo mỗi miền đang phục vụ đúng locale. Kiểm tra ứng dụng kỹ càng để xác nhận rằng locale chính xác được tải tùy thuộc vào miền.

## 📝 Thực hành tốt nhất

- **Giữ cấu hình cơ sở chung**: Cấu hình cơ sở nên bao gồm các thiết lập chung áp dụng cho tất cả các miền.
- **Cô lập logic theo miền**: Giữ các cấu hình theo miền trong các layer tương ứng để duy trì sự rõ ràng và tách biệt các mối quan tâm.
