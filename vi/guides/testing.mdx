# 🧪 Kiểm thử mô-đun `Nuxt I18n Micro`

## 📖 Giới thiệu về kiểm thử

Kiểm thử mô-đun `Nuxt I18n Micro` rất quan trọng để đảm bảo các tính năng bản địa hóa của ứng dụng hoạt động như mong đợi. Tài liệu này sẽ hướng dẫn bạn qua việc thiết lập môi trường kiểm thử, tạo cấu hình giả cho vitest và viết các bài kiểm thử cho các thành phần. Để có ví dụ thực tế, bạn có thể tham khảo [dự án ví dụ trên GitHub](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/test-utils/example).

Xem [Kiểm thử chiến lược định tuyến](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/testing-strategies.md) để biết cách repo này chạy các bộ kiểm thử của chính nó: các dự án Vitest `unit` / `integration` / `e2e`, các tệp theo chiến lược (`test/strategies-*.test.ts`) và sinh các bài regression.

## 🛠️ Thiết lập môi trường kiểm thử

### 1. Cài đặt `@i18n-micro/test-utils`

Đầu tiên, bạn cần cài đặt các tiện ích kiểm thử cho `Nuxt I18n Micro`. Gói này cung cấp các công cụ cần thiết để giả lập và kiểm thử cấu hình i18n của bạn.

```bash
npm install @i18n-micro/test-utils --save-dev
```

### 2. Tạo tệp cấu hình giả

Tiếp theo, tạo một tệp để thiết lập cấu hình i18n giả. Tệp này sẽ được dùng để giả lập các hàm và tiện ích i18n trong quá trình kiểm thử.

```typescript
// tests/unit-setup.ts

import { mockNuxtImport } from '@nuxt/test-utils/runtime'
import { vi } from 'vitest'
import { i18nUtils } from '@i18n-micro/test-utils'

export function createFakeI18n() {
  return {
    $getLocale: vi.fn(i18nUtils.getLocale),
    $t: vi.fn(i18nUtils.t),
    $tc: vi.fn(i18nUtils.tc),
    $setLocale: vi.fn(i18nUtils.setLocale),
    $getLocaleName: vi.fn(i18nUtils.getLocaleName),
    $setLocaleName: vi.fn(i18nUtils.setLocaleName),
    $getLocales: vi.fn(i18nUtils.getLocales),
    $setLocales: vi.fn(i18nUtils.setLocales),
    $defaultLocale: vi.fn(i18nUtils.defaultLocale),
    $setDefaultLocale: vi.fn(i18nUtils.setDefaultLocale),
    $getRouteName: vi.fn(i18nUtils.getRouteName),
    $settRouteName: vi.fn(i18nUtils.settRouteName),
    $ts: vi.fn(i18nUtils.ts),
    $tn: vi.fn(i18nUtils.tn),
    $td: vi.fn(i18nUtils.td),
    $has: vi.fn(i18nUtils.has),
    $resolveTranslations: vi.fn(i18nUtils.resolveTranslations),
    $setTranslation: vi.fn(i18nUtils.setTranslation),
    $mergeTranslations: vi.fn(i18nUtils.mergeTranslations),
    $switchLocaleRoute: vi.fn(i18nUtils.switchLocaleRoute),
    $switchLocalePath: vi.fn(i18nUtils.switchLocalePath),
    $switchLocale: vi.fn(i18nUtils.switchLocale),
    $switchRoute: vi.fn(i18nUtils.switchRoute),
    $localeRoute: vi.fn(i18nUtils.localeRoute),
    $localePath: vi.fn(i18nUtils.localePath),
    $setI18nRouteParams: vi.fn(i18nUtils.setI18nRouteParams),
  }
}

mockNuxtImport<() => ReturnType<typeof createFakeI18n>>('useI18n', () => vi.fn(() => createFakeI18n()))

export const setTranslationsFromJson = i18nUtils.setTranslationsFromJson
```

### 3. Cấu hình Vitest

Bây giờ, cấu hình Vitest để dùng tệp cấu hình giả và thiết lập môi trường kiểm thử.

```typescript
// vitest.config.ts

import { defineVitestConfig } from '@nuxt/test-utils/config'

export default defineVitestConfig({
  test: {
    watch: false,
    setupFiles: ['./tests/unit-setup.ts'],
    include: ['./**/*.spec.ts'],
  },
})
```

## 🧪 Viết bài kiểm thử

### Thành phần ví dụ

Đây là ví dụ về một thành phần đơn giản dùng composable `useI18n` để dịch thông báo.

```vue
<script setup lang="ts">
const { $t } = useI18n()

const props = defineProps({
  message: {
    type: String,
    default: null,
  },
})

// Test to see that $t works in script setup as well as the template
const message = props.message || $t('defaultMessage')
</script>

<template>
  <div>
    <p>Test from component: {{ $t('welcome') }}</p>
    <p data-testid="message">Test message from props: {{ message }}</p>
  </div>
</template>
```

### Tệp kiểm thử

Bây giờ, hãy viết một bài kiểm thử cho thành phần này.

```typescript
// tests/unit/example.spec.ts

import { describe, it, expect, beforeEach } from 'vitest'
import { mount } from '@vue/test-utils'
import ExampleComponent from '@/components/ExampleComponent.vue'
import fs from 'fs'
import path from 'path'
import { setTranslationsFromJson } from './unit-setup'

describe('ExampleComponent', () => {
  beforeEach(async () => {
    const fileContent = fs.readFileSync(path.join(__dirname, '../../locales/en-GB.json')).toString()
    await setTranslationsFromJson('en', JSON.parse(fileContent))
  })

  it('renders the welcome message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.text()).toContain('Test from component: Welcome')
  })

  it('renders the default message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Default Message')
  })

  it('renders the custom message correctly', () => {
    const wrapper = mount(ExampleComponent, {
      props: {
        message: 'Custom Message',
      },
    })
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Custom Message')
  })
})
```

## 📝 Thực hành tốt nhất khi kiểm thử

- **🔧 Giả lập các hàm i18n:** Luôn giả lập các hàm i18n bằng `@i18n-micro/test-utils` để đảm bảo kết quả kiểm thử nhất quán và có thể dự đoán được.
- **⚙️ Dùng Vitest cho kiểm thử đơn vị:** Vitest là một framework kiểm thử mạnh mẽ cho các ứng dụng Vue. Hãy dùng nó để viết bài kiểm thử đơn vị cho các thành phần của bạn.
- **📚 Ghi tài liệu các bài kiểm thử:** Ghi rõ mục đích và kết quả mong đợi của mỗi bài kiểm thử. Điều này sẽ giúp duy trì sự rõ ràng và giúp người khác (hoặc chính bạn trong tương lai) hiểu các bài kiểm thử.

## 📊 Các phương thức tiện ích i18n

Dưới đây là bảng mô tả tất cả các phương thức tiện ích do `@i18n-micro/test-utils` cung cấp.

| Phương thức | Mô tả |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `t(key, params, defaultValue)`                  | Dịch một khóa với các tham số tùy chọn và giá trị mặc định. |
| `tc(key, params, defaultValue)`                 | Dịch một khóa với hỗ trợ số nhiều. |
| `setTranslationsFromJson(locale, translations)` | Tải bản dịch từ một đối tượng JSON cho một ngôn ngữ cụ thể. |
| `getLocale()`                                   | Trả về ngôn ngữ hiện tại. |
| `setLocale(val)`                                | Đặt ngôn ngữ hiện tại. |
| `getLocaleName()`                               | Trả về tên ngôn ngữ hiện tại. |
| `setLocaleName(val)`                            | Đặt tên ngôn ngữ hiện tại. |
| `getLocales()`                                  | Trả về danh sách các ngôn ngữ khả dụng. |
| `setLocales(val)`                               | Đặt danh sách các ngôn ngữ khả dụng. |
| `defaultLocale()`                               | Trả về ngôn ngữ mặc định. |
| `setDefaultLocale(val)`                         | Đặt ngôn ngữ mặc định. |
| `getRouteName()`                                | Trả về tên route hiện tại. |
| `settRouteName(val)`                            | Đặt tên route hiện tại. |
| `ts(key, params, defaultValue)`                 | Dịch một khóa và trả về kết quả dưới dạng chuỗi. |
| `tn(value, options?)`                           | Định dạng số với `Intl.NumberFormatOptions` inline. Các định dạng có tên cần cấu hình mô-đun và không có sẵn trong trợ giúp độc lập này. |
| `td(value, options?)`                           | Định dạng ngày với `Intl.DateTimeFormatOptions` inline. Các định dạng có tên cần cấu hình mô-đun và không có sẵn trong trợ giúp độc lập này. |
| `has(key)`                                      | Kiểm tra liệu một khóa bản dịch có tồn tại. |
| `resolveTranslations()`                         | Trả về cây bản dịch đang hoạt động cho ngôn ngữ và route hiện tại. |
| `setTranslation(key, value)`                    | Thay giá trị tại `key` trong từ điển đang hoạt động (thay thế, không gộp). |
| `mergeTranslations(newTranslations)`            | Gộp bản dịch vào ngôn ngữ đang hoạt động tại runtime. |

Bằng cách làm theo các bước này, bạn có thể kiểm thử hiệu quả mô-đun `Nuxt I18n Micro` và đảm bảo các tính năng bản địa hóa của ứng dụng hoạt động như mong đợi.
