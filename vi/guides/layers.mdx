# 🗂️ Layer trong `Nuxt I18n Micro`

## 📖 Giới thiệu về Layer

Layer trong `Nuxt I18n Micro` cho phép bạn quản lý và tùy chỉnh các thiết lập bản địa hóa một cách linh hoạt trên các phần khác nhau của ứng dụng. Bằng cách định nghĩa các layer khác nhau, bạn có thể điều chỉnh cấu hình cho các ngữ cảnh khác nhau, chẳng hạn như ghi đè thiết lập cho các phần cụ thể của trang web hoặc tạo cấu hình cơ sở có thể tái sử dụng và được mở rộng bởi các phần khác của ứng dụng.

## 🛠️ Layer cấu hình chính

**Layer cấu hình chính** là nơi bạn thiết lập các thiết lập bản địa hóa mặc định cho toàn bộ ứng dụng. Layer này rất cần thiết vì nó xác định cấu hình toàn cục, bao gồm các locale được hỗ trợ, ngôn ngữ mặc định và các thiết lập i18n quan trọng khác.

### 📄 Ví dụ: Định nghĩa Layer cấu hình chính

Đây là ví dụ về cách bạn có thể định nghĩa layer cấu hình chính trong tệp `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  i18n: {
    locales: [
      { code: 'en', iso: 'en-EN', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en', // The default locale for the entire app
    translationDir: 'locales', // Directory where translations are stored
    meta: true, // Automatically generate SEO-related meta tags like `alternate`
    autoDetectLanguage: true, // Automatically detect and use the user's preferred language
  },
})
```

## 🌱 Layer con

Layer con được dùng để mở rộng hoặc ghi đè cấu hình chính cho các phần cụ thể của ứng dụng. Ví dụ, bạn có thể muốn thêm các locale bổ sung hoặc sửa đổi locale mặc định cho một phần cụ thể của trang web. Layer con đặc biệt hữu ích trong các ứng dụng mô-đun nơi các phần khác nhau có thể có các yêu cầu bản địa hóa khác nhau.

### 📄 Ví dụ: Mở rộng Layer chính trong Layer con

Giả sử bạn có một phần của trang web cần hỗ trợ các locale bổ sung, hoặc bạn muốn vô hiệu hóa một locale cụ thể trong một ngữ cảnh nhất định. Đây là cách bạn có thể thực hiện điều đó bằng cách mở rộng layer cấu hình chính:

```typescript
// basic/nuxt.config.ts (Primary Layer)
export default defineNuxtConfig({
  i18n: {
    locales: [
      { code: 'en', iso: 'en-EN', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    meta: true,
    translationDir: 'locales',
  },
})
```

```typescript
// extended/nuxt.config.ts (Child Layer)
export default defineNuxtConfig({
  extends: '../basic', // Inherit the base configuration from the 'basic' layer
  i18n: {
    locales: [
      { code: 'en', iso: 'en-EN', dir: 'ltr' }, // Inherited from the base layer
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' }, // Inherited from the base layer
      { code: 'de', iso: 'de-DE', dir: 'ltr' }, // Added in the child layer
    ],
    defaultLocale: 'fr', // Override the default locale to French for this section
    autoDetectLanguage: false, // Disable automatic language detection in this section
  },
})
```

### 🌐 Sử dụng Layer trong ứng dụng mô-đun

Trong một ứng dụng Nuxt mô-đun lớn hơn, bạn có thể có nhiều phần, mỗi phần yêu cầu các thiết lập i18n riêng. Bằng cách tận dụng layer, bạn có thể duy trì cấu trúc cấu hình sạch sẽ và có thể mở rộng.

### 📄 Ví dụ: Cấu hình phân lớp trong ứng dụng mô-đun

Hãy tưởng tượng bạn có một trang thương mại điện tử với các phần riêng biệt như website chính, bảng quản trị và cổng hỗ trợ khách hàng. Mỗi phần có thể cần một tập locale khác nhau hoặc các thiết lập i18n khác.

#### **Layer chính (Cấu hình toàn cục):**

```typescript
// nuxt.config.ts
export default defineNuxtConfig({
  i18n: {
    locales: [
      { code: 'en', iso: 'en-EN', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    meta: true,
    translationDir: 'locales',
    autoDetectLanguage: true,
  },
})
```

#### **Layer con cho bảng quản trị:**

```typescript
// admin/nuxt.config.ts
export default defineNuxtConfig({
  extends: '../nuxt.config', // Inherit the global settings
  i18n: {
    locales: [
      { code: 'en', iso: 'en-EN', dir: 'ltr' }, // Inherited
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' }, // Inherited
      { code: 'es', iso: 'es-ES', dir: 'ltr' }, // Specific to the admin panel
    ],
    defaultLocale: 'en',
    meta: false, // Disable automatic meta generation in the admin panel
  },
})
```

#### **Layer con cho cổng hỗ trợ khách hàng:**

```typescript
// support/nuxt.config.ts
export default defineNuxtConfig({
  extends: '../nuxt.config', // Inherit the global settings
  i18n: {
    locales: [
      { code: 'en', iso: 'en-EN', dir: 'ltr' }, // Inherited
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' }, // Inherited
      { code: 'de', iso: 'de-DE', dir: 'ltr' }, // Specific to the support portal
    ],
    defaultLocale: 'de', // Default to German in the support portal
    autoDetectLanguage: false, // Disable automatic language detection
  },
})
```

Trong ví dụ mô-đun này:

- Mỗi phần (admin, support) có thiết lập i18n riêng, nhưng tất cả đều kế thừa cấu hình cơ sở.
- Bảng quản trị thêm tiếng Tây Ban Nha (`es`) làm locale và vô hiệu hóa việc tạo meta tag.
- Cổng hỗ trợ thêm tiếng Đức (`de`) làm locale và mặc định là tiếng Đức cho giao diện người dùng.

## 📝 Thực hành tốt nhất khi sử dụng Layer

- **🔧 Giữ Layer chính đơn giản:** Layer chính nên chứa các thiết lập được sử dụng phổ biến nhất áp dụng toàn cục cho toàn bộ ứng dụng. Giữ nó đơn giản để đảm bảo tính nhất quán.
- **⚙️ Dùng Layer con cho các tùy chỉnh cụ thể:** Chỉ ghi đè hoặc mở rộng thiết lập trong layer con khi cần thiết. Cách tiếp cận này tránh sự phức tạp không cần thiết trong cấu hình.
- **📚 Ghi tài liệu cho Layer của bạn:** Ghi tài liệu rõ ràng về mục đích và đặc điểm của mỗi layer trong dự án. Điều này sẽ giúp duy trì sự rõ ràng và giúp người khác (hoặc chính bạn trong tương lai) dễ dàng hiểu cấu hình.
