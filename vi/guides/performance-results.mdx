### Mô tả

So sánh **plain Nuxt** (đường cơ sở không có module i18n), **i18n-micro**, và **`@nuxtjs/i18n` v10.6** dưới một profile từ điển chung.

Trọng tâm: thời gian build, RSS đỉnh, **code so với translations so với total** có thể triển khai, và hành vi máy chủ dưới Artillery + Autocannon.

### Ghi chú về phương pháp

- Các chỉ số là **trung bình của 3 lần chạy liên tiếp cho mỗi fixture** (fixture A ×3, sau đó B ×3, rồi C ×3 — không xen kẽ).
- **Translations** bao gồm JSON locale dưới `locales/` / `_locales/` / `translations/`, mọi thứ dưới `chunks/raw/`, và các chunk locale phù hợp. Các báo cáo cũ hiển thị `@nuxtjs/i18n` "translations: 0 B" và cột "code" khổng lồ đã đếm các message chunk là code ứng dụng.
- **plain-nuxt** phục vụ cùng khối lượng lá dưới dạng JSON `public/translations` tĩnh (không phải import JS tĩnh). Dưới Artillery, đường cơ sở đó nặng về I/O; đó không phải là "chi phí i18n", mà là chi phí lấy JSON lớn cho mỗi request.

### Các lần chạy

Tất cả các chỉ số bên dưới là **trung bình qua 3 lần chạy**.

## Ghi chú

- Profile chung: 4 locale × 2 trang × ~16.8k lá index.
- Artillery: warm-up 6s @6 VU/s + main 60s @60 VU/s. Autocannon: 10 kết nối × 10s.
- Chạy lại: `pnpm test:performance` hoặc `pnpm -C scripts cli performance --locales N --keys K --only all|micro|i18n|plain --runs N`.
