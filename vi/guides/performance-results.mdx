### Mô tả

So sánh **plain Nuxt** (baseline không có mô-đun i18n), **i18n-micro** và **`@nuxtjs/i18n` v10.6** dưới một profile từ điển dùng chung.

Trọng tâm: thời gian build, đỉnh RSS, **code so với translations so với total** có thể triển khai, và hành vi máy chủ dưới Artillery + Autocannon.

### Ghi chú phương pháp

- Các chỉ số là **trung bình của 3 lần chạy liên tiếp cho mỗi fixture** (fixture A ×3, sau đó B ×3, sau đó C ×3. Không xen kẽ).
- **Translations** bao gồm JSON ngôn ngữ dưới `locales/` / `_locales/` / `translations/`, mọi thứ dưới `chunks/raw/`, và các chunk ngôn ngữ khớp. Các báo cáo cũ hiển thị `@nuxtjs/i18n` "translations: 0 B" và cột "code" khổng lồ đã tính các chunk message là mã ứng dụng.
- **plain-nuxt** phục vụ cùng khối lượng lá dưới dạng JSON tĩnh `public/translations` (không phải các import JS tĩnh). Dưới Artillery, baseline đó nặng về I/O. Đó không phải là "chi phí i18n", đó là chi phí lấy JSON lớn theo mỗi yêu cầu.

### Các lần chạy

Tất cả chỉ số dưới đây là **trung bình qua 3 lần chạy**.

## Ghi chú

- Profile dùng chung: 4 ngôn ngữ × 2 trang × ~16.8k lá index.
- Artillery: warm-up 6s @6 VU/s + main 60s @60 VU/s. Autocannon: 10 kết nối × 10s.
- Chạy lại: `pnpm test:performance` hoặc `pnpm -C scripts cli performance --locales N --keys K --only all|micro|i18n|plain --runs N`.
