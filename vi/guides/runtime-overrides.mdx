# Ghi đè i18n tại runtime

Dùng hướng dẫn này khi bạn cần một artifact build chạy với các giá trị mặc định locale khác nhau theo môi trường (ví dụ: các instance tenant khác nhau).

## Những gì có thể được ghi đè tại runtime

Module hỗ trợ ghi đè runtime an toàn cho:

- `defaultLocale`
- `fallbackLocale`
- `disabledLocales`

Các ghi đè này được áp dụng lên trên cấu hình thời điểm build từ `.nuxt/i18n.strategy.mjs` và `.nuxt/i18n.config.mjs`.

## Những gì không thể được ghi đè tại runtime

`strategy` (`no_prefix`, `prefix`, `prefix_except_default`, `prefix_and_default`) là vấn đề thời điểm build vì nó ảnh hưởng đến hành vi route được sinh ra.

Nếu bạn truyền một strategy ghi đè tại runtime, nó sẽ bị bỏ qua và một cảnh báo sẽ được phát ra.

## Ghi đè dựa trên RuntimeConfig

Cung cấp các giá trị runtime dưới `runtimeConfig.public.i18nRuntime`:

```ts
export default defineNuxtConfig({
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

## Ghi đè bằng biến môi trường

Bạn cũng có thể cấu hình ghi đè bằng các biến môi trường:

- `NUXT_I18N_DEFAULT_LOCALE`
- `NUXT_I18N_FALLBACK_LOCALE`
- `NUXT_I18N_DISABLED_LOCALES` (phân tách bằng dấu phẩy, ví dụ `fr,it`)

Các bí danh dự phòng cũng được hỗ trợ:

- `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES`

## Quy tắc xác thực

Tại runtime, module xác thực các ghi đè để tránh trạng thái hỏng:

- Bạn không thể vô hiệu hóa tất cả các locale.
- `defaultLocale` phải trỏ đến một locale được kích hoạt.
- `fallbackLocale` phải tồn tại trong các locale đã khai báo.

Nếu một ghi đè không hợp lệ, module sẽ giữ một giá trị an toàn và ghi log cảnh báo.

## Lưu ý cho triển khai đa instance

Tính năng runtime này được thiết kế cho việc kích hoạt locale theo từng instance và giá trị mặc định mà không cần build lại.

Nếu các instance yêu cầu các chiến lược URL khác nhau (`no_prefix` so với `prefix`), hãy dùng các bản build riêng biệt cho từng chiến lược.

## Locale bị vô hiệu hóa và payload tĩnh

`runtimeConfig.public.i18nRuntime.disabledLocales` cập nhật routing, switcher và **handler** payload Nitro — nhưng Nitro phục vụ các tệp dưới `public/` **trước** handler đó.

Nếu `translationPayloads.publicAssets` (hoặc bản sao public bắt buộc của Node SSR) đã ghi `/_locales/\{page\}/\{locale\}/data.json`, việc vô hiệu hóa tại runtime không thể ẩn tệp đó. Ưu tiên `locale.disabled: true` tại thời điểm build để premerge không phát ra các payload tĩnh của locale đó.
