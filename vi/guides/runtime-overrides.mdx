# Ghi đè i18n tại runtime

Dùng hướng dẫn này khi bạn cần một artefact build duy nhất chạy với các mặc định ngôn ngữ khác nhau cho từng môi trường (ví dụ: các thể hiện của tenant khác nhau).

## Có thể ghi đè tại runtime

Mô-đun hỗ trợ ghi đè an toàn tại runtime cho:

- `defaultLocale`
- `fallbackLocale`
- `disabledLocales`

Các ghi đè này được áp dụng lên trên cấu hình thời điểm build từ `.nuxt/i18n.strategy.mjs` và `.nuxt/i18n.config.mjs`.

## Không thể ghi đè tại runtime

`strategy` (`no_prefix`, `prefix`, `prefix_except_default`, `prefix_and_default`) là mối quan tâm ở thời điểm build vì nó ảnh hưởng đến hành vi route được sinh.

Nếu bạn truyền một ghi đè strategy tại runtime, nó sẽ bị bỏ qua và một cảnh báo được phát ra.

## Ghi đè dựa trên RuntimeConfig

Cung cấp các giá trị runtime dưới `runtimeConfig.public.i18nRuntime`:

```ts
export default defineNuxtConfig({
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

## Ghi đè bằng biến môi trường

Bạn cũng có thể cấu hình ghi đè qua các biến môi trường:

- `NUXT_I18N_DEFAULT_LOCALE`
- `NUXT_I18N_FALLBACK_LOCALE`
- `NUXT_I18N_DISABLED_LOCALES` (ngăn cách bằng dấu phẩy, ví dụ `fr,it`)

Các bí danh dự phòng cũng được hỗ trợ:

- `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES`

## Quy tắc xác thực

Tại runtime, mô-đun xác thực các ghi đè để tránh trạng thái hỏng:

- Bạn không thể tắt tất cả các ngôn ngữ.
- `defaultLocale` phải trỏ đến một ngôn ngữ đang bật.
- `fallbackLocale` phải tồn tại trong các ngôn ngữ đã khai báo.

Nếu một ghi đè không hợp lệ, mô-đun giữ giá trị an toàn và ghi log cảnh báo.

## Ghi chú cho triển khai đa thể hiện

Tính năng runtime này được thiết kế cho việc kích hoạt ngôn ngữ và mặc định theo từng thể hiện mà không cần build lại.

Nếu các thể hiện yêu cầu chiến lược URL khác nhau (`no_prefix` so với `prefix`), hãy dùng các bản build riêng cho từng chiến lược.

## Ngôn ngữ bị tắt và payload tĩnh

`runtimeConfig.public.i18nRuntime.disabledLocales` cập nhật định tuyến, switcher và **trình xử lý** payload Nitro. Nhưng Nitro phục vụ các tệp bên dưới `public/` **trước khi** trình xử lý đó chạy.

Nếu `translationPayloads.publicAssets` (hoặc bản sao public bị Node SSR ép buộc) đã ghi `/_locales/\{page\}/\{locale\}/data.json`, một lệnh tắt tại runtime không thể ẩn tệp đó. Hãy ưu tiên đặt `locale.disabled: true` tại thời điểm build để premerge không phát ra các payload tĩnh của ngôn ngữ đó.
