**Ngày**: 2025-12-07

**Phiên bản**: `v2.14.1`

![Bản phát hành v2.14](/images/2.14.0.png)

Chúng tôi rất vui mừng giới thiệu **v2.14.1** với các tích hợp hoàn toàn mới cho Node.js, Vue 3 và Astro! Các package này mang những khả năng i18n mạnh mẽ tương tự đến các framework yêu thích của bạn, dùng chung logic lõi để đảm bảo tính nhất quán và hiệu năng.

## Có gì mới? {#what’s-new}

- **@i18n-micro/node** - Dùng bản dịch i18n trong bất kỳ ứng dụng Node.js, công cụ CLI hoặc dịch vụ backend nào
- **@i18n-micro/vue** - Plugin Vue 3 cho quốc tế hóa với bản dịch reactive và hỗ trợ theo từng route
- **@i18n-micro/astro** - Tích hợp Astro cho quốc tế hóa với hỗ trợ TypeScript đầy đủ
- **@i18n-micro/types-generator** - Tự động tạo kiểu TypeScript cho các khóa dịch với an toàn kiểu đầy đủ và tự động hoàn thành trong IDE

## Tính năng chính {#key-features}

Tất cả các tích hợp đều có chung những lợi ích cốt lõi:

- Nhẹ và hiệu năng cao
- Hỗ trợ bản dịch theo từng route
- Số nhiều tích hợp sẵn
- Định dạng số, ngày và thời gian tương đối
- Hỗ trợ TypeScript đầy đủ
- Cùng cấu trúc file dịch JSON

**Types Generator** mang lại thêm các cải tiến về trải nghiệm nhà phát triển:

- Tự động tạo kiểu từ các file dịch JSON
- Khóa dịch an toàn kiểu với kiểm tra tại thời điểm biên dịch
- Hỗ trợ tự động hoàn thành đầy đủ trong IDE
- Hot reload khi file dịch thay đổi
- Không tốn chi phí runtime

Để xem tài liệu chi tiết và ví dụ, hãy truy cập [repository](https://github.com/s00d/nuxt-i18n-micro) hoặc xem [tài liệu](https://s00d.github.io/nuxt-i18n-micro/).
