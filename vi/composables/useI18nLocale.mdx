---
title: "useI18nLocale"
description: "useI18nLocale đọc và ghi trạng thái locale cùng cookie locale — điểm vào cho việc phát hiện locale tùy chỉnh."
---

`useI18nLocale()` cho phép truy cập locale mà ứng dụng đã chọn: state `i18n-locale` và cookie locale. Hãy dùng nó trong một plugin tự phát hiện locale (theo tên miền, hồ sơ người dùng, header) thay vì tự ghi `useState('i18n-locale')` hoặc cookie bằng tay. Các kiểm tra tính hợp lệ của nó sử dụng các locale đang bật, bao gồm cả các runtime override.

## Chữ ký {#signature}

```ts
useI18nLocale(): { getEffectiveLocale: (route: unknown, getLocaleFromRoute: GetLocaleFromRoute) => string; getLocale: () => string | null; getPreferredLocale: () => string | null; hashCookie: CookieRef; isValidLocale: (locale: string | null | undefined) => locale is string; locale: any; localeCookie: CookieRef; resolveInitialLocale: (options: ResolveInitialLocaleOptions) => string; setLocale: (locale: string | null) => void; syncLocale: (locale: string | null) => void; validLocales: string[] }
```

Điểm vào tập trung cho việc quản lý locale i18n.
Kết hợp useState('i18n-locale'), cookie locale và các tiện ích đồng bộ.

## Giá trị trả về {#returned-values}

| Thành viên | Kiểu | Mô tả |
| --- | --- | --- |
| `locale` | `Ref<string \| null>` | Ref `useState('i18n-locale')`. |
| `localeCookie` | `Ref<string \| null>` | Cookie [`localeCookie`](/vi/api/module-options#localecookie); một `{ value: null }` đơn giản khi tùy chọn là `null`. |
| `hashCookie` | `Ref<string \| null>` | Cookie `hash-locale` khi dùng hash routing; ngược lại là `{ value: null }`. |
| `validLocales` | `string[]` | Mã của các locale đang bật. |
| `setLocale(locale)` | `(locale: string \| null) => void` | Ghi state và các cookie. Không kiểm tra tính hợp lệ và không tải bản dịch. |
| `syncLocale(locale)` | `(locale: string \| null) => void` | Chỉ ghi các cookie. |
| `getLocale()` | `() => string \| null` | State, sau đó là cookie ưu tiên (cookie hash khi dùng hash routing). Không được kiểm tra tính hợp lệ. |
| `getPreferredLocale()` | `() => string \| null` | Giá trị **hợp lệ** đầu tiên trong state và cookie ưu tiên, hoặc `null`. |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string` | State khi dùng hash routing nếu đã được đặt; ngược lại là `getLocaleFromRoute(route)`. |
| `resolveInitialLocale(options)` | `(options: ResolveInitialLocaleOptions) => string` | `options.urlLocale`, sau đó là một state hợp lệ, sau đó là `options.serverLocale`, rồi đến locale của route. Lưu kết quả vào state khi state không hợp lệ; trên client nó cũng ghi cookie. |
| `isValidLocale(locale)` | `(locale) => locale is string` | Liệu `locale` có nằm trong `validLocales` hay không. |

Các cookie tồn tại trong một năm, với `path: '/'` và `sameSite: 'lax'`.

## Ví dụ {#example}

```ts
// plugins/locale-from-domain.server.ts
export default defineNuxtPlugin({
  name: 'locale-from-domain',
  enforce: 'pre',
  setup() {
    const { setLocale, isValidLocale } = useI18nLocale()
    const host = useRequestURL().hostname // e.g. de.example.com
    const code = host.split('.')[0]
    if (isValidLocale(code)) setLocale(code)
  },
})
```

Plugin loader của module đọc state khi khởi động, nên plugin nào đặt state phải chạy trước (`enforce: 'pre'`). Cách state cạnh tranh với URL, cookie và `Accept-Language`: [Phát hiện locale](/vi/guide/locale-detection). Hướng dẫn đầy đủ: [Phát hiện tùy chỉnh](/vi/guide/custom-auto-detect).

`setLocale()` không chuyển đổi các bản dịch trên màn hình. Để thay đổi locale của trang hiện tại, hãy gọi [`$switchLocale()`](/vi/api/methods#$switchlocale).
