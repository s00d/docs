---
title: "useLocaleHead"
description: "useLocaleHead dựng các thẻ SEO i18n (lang, dir, canonical, hreflang, og:locale) dưới dạng một object mà bạn truyền vào useHead."
---

`useLocaleHead()` dựng các thẻ head i18n cho route hiện tại: `lang` và `dir` trên `<html>`, một link canonical, các bản thay thế `hreflang` cùng `x-default`, `og:url`, `og:locale` và `og:locale:alternate`. Hãy dùng nó khi bạn đặt [`meta: false`](/vi/api/module-options#meta) và tự quản lý `useHead`; với `meta: true` module đã tự đăng ký các thẻ này, và các thay đổi theo từng trang được thực hiện qua [`useI18nHead`](/vi/composables/useI18nHead).

## Chữ ký {#signature}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { build: () => LocaleHead; metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }, LocaleHead | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

Các thẻ head SEO cho route hiện tại: các bản thay thế `hreflang` cho mọi locale cùng
`x-default`, một link canonical, `og:locale`, và `lang`/`dir` trên `<html>`.

Chỉ cần thiết khi `meta` bị tắt hoặc cần điều chỉnh các giá trị mặc định — với `meta: true`
module tự đăng ký chính các thẻ này.

| Tham số | Kiểu | Mô tả |
| --- | --- | --- |
| `options` | `UseLocaleHeadOptions` |  |

**Trả về** — `metaObject`, một ref chứa object head sẵn sàng để truyền vào `useHead`; `updateMeta` làm mới nó; `build` tính toán object head từ route hiện tại (có tính phản ứng khi được đọc trong một getter, ví dụ `useHead(() => build())`)

```ts
const { metaObject } = useLocaleHead({ addSeoAttributes: true })
useHead(metaObject)
```

## Tùy chọn {#options}

| Tùy chọn | Mặc định | Mô tả |
| --- | --- | --- |
| `addDirAttribute` | `true` | Đặt `dir` trên `<html>` từ `dir` của locale (`'auto'` khi locale không có). |
| `identifierAttribute` | `'id'` | Thuộc tính làm khóa cho mỗi thẻ (`i18n-can`, `i18n-og`, `i18n-alternate-<hreflang>`, …), để các lần cập nhật thay thế thẻ thay vì thêm mới. |
| `addSeoAttributes` | `true` | Xuất các thẻ canonical, `hreflang` và `og:`. `false` chỉ giữ lại `htmlAttrs`. |
| `baseUrl` | `'/'` | Origin được nối vào mọi URL. Giữ `'/'` cho URL tương đối; truyền `'https://example.com'` cho URL tuyệt đối. |
| `autoUpdate` | `true` | Dựng lại `metaObject` khi route hoặc state `i18n-locale` thay đổi. |

## Những gì nó xuất ra {#what-it-emits}

- Không có gì trên route không khớp (404) hoặc có `disableMeta` cho locale đang hoạt động.
- Canonical và `og:url`: `$switchLocalePath(<active locale>)`, query được rút gọn theo [`canonicalQueryWhitelist`](/vi/api/module-options#canonicalquerywhitelist), áp dụng [`trailingSlash`](/vi/api/module-options#trailingslash).
- `hreflang`: một link cho mỗi locale được bật mà trang tồn tại, `hreflang = iso || code`, bỏ qua các locale có `seo: false`; với `hreflangBaseLanguage: true` locale vùng đầu tiên của một ngôn ngữ cũng xuất thẻ ngôn ngữ gốc của nó. Không có gì dưới `no_prefix`.
- `x-default`: URL của locale mặc định, trừ khi strategy là `no_prefix`, locale mặc định có `seo: false`, hoặc trang không tồn tại trong locale đó.
- `og:locale` / `og:locale:alternate`: từ `og` của locale, hoặc `iso` của nó được chuyển đổi (`en-US` → `en_US`); bị bỏ qua kèm cảnh báo khi phát triển nếu không cách nào hoạt động.

## Ví dụ {#example}

```ts
// app.vue, with i18n.meta: false
const { metaObject } = useLocaleHead({ baseUrl: 'https://example.com' })
useHead(metaObject)
```

`build()` trả về cùng object đó nhưng không có ref: `useHead(() => build())` vẫn có tính phản ứng mà không cần watcher.
