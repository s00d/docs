---

`useI18nHead()` thay đổi các thẻ SEO mà module tạo ra, chỉ cho một trang. Hãy dùng nó khi một trang biết rõ hơn router: một bài viết CMS chỉ tồn tại ở một số locale, một URL canonical lấy từ API, các thẻ `og:` bổ sung. Bạn nhận được các thẻ đã tạo với phần ghi đè của bạn được hợp nhất lên trên.

## Chữ ký {#signature}

```ts
useI18nHead(input?: MaybeRefOrGetter<I18nHeadInput | null>): { pageHead: any; resetPageHead: () => void }
```

Đăng ký các ghi đè cấp trang cho các thẻ head SEO i18n.
Được plugin `02.meta` hợp nhất lên trên kết quả của `useLocaleHead`.

Nên dùng getter (`() => ({ … })`) khi giá trị đến từ `$t` / `t` để chúng
được phân giải lại khi locale thay đổi. Một object thuần chỉ được đánh giá một lần và giữ nguyên.

| Tham số | Kiểu | Mô tả |
| --- | --- | --- |
| `input` *(tùy chọn)* | `MaybeRefOrGetter<I18nHeadInput \| null>` |  |

Nó hoạt động với [`meta: true`](/vi/api/module-options#meta) (mặc định): plugin meta của module hợp nhất input lên trên kết quả của [`useLocaleHead`](/vi/composables/useLocaleHead) ở mỗi lần render head. Với `meta: false` thì không có gì đọc nó.

Phần ghi đè được đặt lại khi tên route thay đổi. Một trang đặt `disableMeta` sẽ không nhận bất kỳ thẻ i18n nào, kể cả các ghi đè.

## Đầu vào {#input}

`I18nHeadInput` (từ `@i18n-micro/types`):

| Khóa | Kiểu | Tác dụng |
| --- | --- | --- |
| `htmlAttrs` | `Record<string, string>` | Được hợp nhất vào các thuộc tính của `<html>` (`lang`, `dir`). |
| `meta` | `I18nHeadMeta[]` | Được thêm sau các thẻ đã tạo; thay thế thẻ có cùng `id`, `property` hoặc `name`. |
| `link` | `I18nHeadLink[]` | Được thêm sau các link đã tạo; thay thế link có cùng `id`, hoặc cùng `rel` + `hreflang`. |
| `replace.canonical` | `string \| false` | Thay thế `href` canonical, hoặc xóa link. |
| `replace.hreflang` | `I18nHeadLink[] \| false` | Thay thế hoặc xóa **mọi** link `rel="alternate"`, bao gồm cả `x-default`. |
| `replace.xDefault` | `I18nHeadLink \| false` | Thay thế hoặc xóa link `x-default`. |
| `replace.ogLocale` | `string \| false` | Thay thế hoặc xóa `og:locale`. |
| `replace.ogUrl` | `string \| false` | Thay thế hoặc xóa `og:url`. |
| `replace.ogAlternates` | `string[] \| false` | Dựng lại `og:locale:alternate` từ các mã locale này (qua `og` / `iso`), bỏ qua locale hiện tại, các mã không xác định và các mã không có giá trị `og` hoặc `iso`, hoặc xóa chúng. |
| `disable` | `I18nHeadDisableGroup[]` | Loại bỏ các nhóm đã tạo: `'hreflang'` (không gồm `x-default`), `'x-default'`, `'canonical'`, `'og'` (`og:locale` + `og:url`), `'og-alternates'`, `'html'`. |

Thứ tự áp dụng: `disable`, sau đó `replace`, rồi `htmlAttrs`, `meta`, `link`.

## Ví dụ {#example}

Một bài viết chỉ tồn tại ở một số locale, với các URL thay thế lấy từ API:

```vue
<script setup lang="ts">
const route = useRoute()
const { t } = useI18n()
const { data: article } = await useFetch<{ title: string; urls: Record<string, string> }>(`/api/articles/${route.params.slug}`)

useI18nHead(() => {
  if (!article.value) return null
  const codes = Object.keys(article.value.urls)
  return {
    meta: [{ property: 'og:title', content: article.value.title || t('blog.title') }],
    replace: {
      hreflang: codes.map((code) => ({ rel: 'alternate', hreflang: code, href: article.value!.urls[code]! })),
      ogAlternates: codes,
    },
  }
})
</script>
```

Hãy truyền một getter, như ở đây, khi giá trị đến từ `t()` hoặc dữ liệu bất đồng bộ: nó sẽ chạy lại khi locale thay đổi. Một object thuần chỉ được đọc một lần.
