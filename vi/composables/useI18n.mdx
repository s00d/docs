---
title: "useI18n"
description: "useI18n trả về các hàm hỗ trợ runtime (`$t`, `$tc`, `$localePath`, …) dưới dạng một object thuần, có và không có tiền tố `$`."
---

`useI18n()` trả về các hàm hỗ trợ runtime của module dưới dạng một object thuần. Hãy dùng nó trong `<script setup>`, composables và plugin thay vì gọi đến `useNuxtApp()`. Mỗi hàm hỗ trợ có cả tên với `$` và một bí danh không có tiền tố: `t` và `$t` là cùng một hàm.

## Chữ ký {#signature}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Mọi hàm hỗ trợ runtime, dưới dạng một object thuần.

Đây chính là các hàm mà plugin inject dưới dạng `$t`, `$tc`, v.v., có sẵn dưới cả
tên có tiền tố dollar và một bí danh không tiền tố — vì vậy cả `const { t } = useI18n()` và
`const { $t } = useI18n()` đều hoạt động.

**Trả về** — các hàm hỗ trợ được mô tả trong [tài liệu tham khảo các phương thức](/vi/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

Object trả về chứa mọi hàm hỗ trợ của [`PluginsInjections`](/vi/api/methods). Mỗi hàm được mô tả trên trang [Hàm hỗ trợ](/vi/api/methods).

## Ví dụ {#example}

```vue
<script setup lang="ts">
const { t, tc, localePath, switchLocale, getLocale } = useI18n()

const title = computed(() => t('page.title'))
</script>

<template>
  <h1>{{ title }}</h1>
  <p>{{ tc('items', 3) }}</p>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
  <button @click="switchLocale(getLocale() === 'en' ? 'de' : 'en')">{{ t('nav.switch') }}</button>
</template>
```

## Không có trong kiểu {#not-in-the-type}

`$defineI18nRoute` chỉ được khai báo kiểu trên `useNuxtApp()`:

```ts
const { $defineI18nRoute } = useNuxtApp()
```
