Trang này đưa một ứng dụng Nuxt từ chỗ chưa có i18n đến một trang được dịch với bộ chuyển ngôn ngữ. Bạn chỉ cần nó một lần, khi bắt đầu dự án. Kết quả là bạn có các URL được bản địa hóa (`/about`, `/de/about`), mỗi locale và trang một tệp JSON, và `$t` trong template.

## Cài đặt {#install}

Module cần Nuxt 3.18 trở lên (Nuxt 4 cũng hoạt động) và Node 20 trở lên.

<CodeGroup>

```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>

## Cấu hình các locale {#configure-the-locales}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', displayName: 'English' },
      { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
      { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
    ],
    defaultLocale: 'en',
  },
})
```

Đó là toàn bộ cấu hình mà một ứng dụng đầu tiên cần. Các giá trị mặc định mang lại cho bạn:

- `strategy: 'prefix_except_default'`: locale mặc định không có tiền tố (`/about`), các locale khác thì có (`/de/about`). Xem [Chiến lược định tuyến](/vi/guide/strategy).
- `translationDir: 'locales'`: các tệp bản dịch nằm trong `locales/` ở thư mục gốc dự án, kể cả với bố cục `app/` của Nuxt 4.
- `meta: true`: các thẻ `hreflang`, canonical và `og:locale`, cùng với `lang` và `dir` trên `<html>`. Xem [SEO](/vi/guide/seo).
- Khách truy cập mở `/` sẽ được chuyển tới ngôn ngữ mà trình duyệt của họ yêu cầu (`Accept-Language`). Xem [Phát hiện locale](/vi/guide/locale-detection).

`iso` là thẻ ngôn ngữ được dùng trong các thẻ SEO; `code` là thứ xuất hiện trong URL. Mọi tùy chọn được liệt kê trong [Tùy chọn module](/vi/api/module-options).

## Thêm tệp bản dịch {#add-translation-files}

Khởi động dev server bằng `nuxt dev`. Khi Nuxt phân giải các trang, module tạo một tệp `{}` rỗng cho mỗi locale và trang chưa có tệp (tắt tính năng này bằng [`disableWatcher`](/vi/api/module-options#disablewatcher)):

```text
locales/
├── en.json            # root: keys every page can use
├── de.json
├── fr.json
└── pages/
    ├── index/         # pages/index.vue
    │   ├── en.json
    │   ├── de.json
    │   └── fr.json
    └── about/         # pages/about.vue
        ├── en.json
        ├── de.json
        └── fr.json
```

Điền vào tệp gốc và một tệp trang:

```json
// locales/en.json
{ "nav": { "home": "Home", "about": "About" } }
```

```json
// locales/pages/index/en.json
{ "welcome": "Welcome, {name}!", "items": "no items | one item | {count} items" }
```

Một trang thấy các khóa gốc và các khóa của riêng nó; tệp riêng của trang thắng khi trùng. Tên thư mục theo tên route (`pages/articles/[id].vue` là `locales/pages/articles-id/`). [Tệp bản dịch](/vi/guide/translations) trình bày bố cục, fallback và cách tải.

## Dùng `$t` trên một trang {#use-$t-on-a-page}

```vue
<!-- pages/index.vue -->
<script setup lang="ts">
const { t, tc, getLocale } = useI18n()

const title = t('nav.home') // 'Home'
</script>

<template>
  <h1>{{ $t('welcome', { name: 'Ada' }) }}</h1>
  <!-- Welcome, Ada! -->
  <p>{{ $tc('items', 3) }}</p>
  <!-- 3 items -->
  <p>{{ getLocale() }}</p>
  <!-- en -->
</template>
```

- Trong template, mọi helper đều có sẵn với `$` (`$t`, `$tc`, `$localePath`, …).
- Trong `<script setup>`, `useI18n()` trả về cùng các helper đó, có và không có `$` (`t` và `$t` là một hàm). Nó được auto-import.
- Các placeholder `{name}` được điền từ đối tượng params. Các dạng số nhiều được phân tách bằng `|`; số đếm chọn dạng (0, 1, rồi dạng cuối cùng cho mọi số lớn hơn).

Tất cả helper được liệt kê trong [Phương thức](/vi/api/methods).

## Liên kết giữa các trang và chuyển locale {#link-between-pages-and-switch-locale}

```vue
<!-- components/AppHeader.vue -->
<template>
  <nav>
    <i18n-link :to="{ name: 'index' }">{{ $t('nav.home') }}</i18n-link>
    <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
    <i18n-switcher />
  </nav>
</template>
```

- [`<i18n-link>`](/vi/components/i18n-link) là một `NuxtLink` trỏ tới trang trong locale hiện tại: trên `/de`, liên kết about đi tới `/de/about`.
- [`<i18n-switcher>`](/vi/components/i18n-switcher) là một dropdown chứa các locale đang được bật; nó giữ khách truy cập ở cùng trang.
- Với các nút của riêng bạn, hãy gọi `$switchLocale('de')`, hàm này điều hướng tới trang hiện tại bằng tiếng Đức và ghi nhớ lựa chọn. Với một `NuxtLink` thông thường, hãy dùng `$localePath({ name: 'about' })` hoặc `$switchLocalePath('de')`.

## Kiểm tra {#check-it}

Chạy `nuxt dev` và mở:

| URL | Hiển thị |
| --- | --- |
| `/` | Trang chủ tiếng Anh (hoặc chuyển hướng tới `/de` khi trình duyệt của bạn ưu tiên tiếng Đức) |
| `/de` | Trang chủ tiếng Đức |
| `/de/about` | Trang about tiếng Đức |
| `/en/about` | 404: locale mặc định không có tiền tố với `prefix_except_default` |

Các chỉnh sửa trong tệp JSON được áp dụng vào trang đang mở mà không cần tải lại.
