Trong `nuxt dev`, module bổ sung hai công cụ hỗ trợ gỡ lỗi: tab **i18n Micro** trong Nuxt DevTools để duyệt và chỉnh sửa file dịch, và một inspector trong Vue DevTools cho locale đang hoạt động và các từ điển đã tải. Cả hai chỉ tồn tại trong môi trường development và không thêm gì vào bản build production. Tab Nuxt chỉ cần bật Nuxt DevTools; inspector của Vue còn cần thêm tiện ích trình duyệt Vue DevTools.

## Tab Nuxt DevTools {#nuxt-devtools-tab}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  devtools: { enabled: true }, // the tab is registered only when DevTools are on
})
```

Mở Nuxt DevTools (`Shift + Alt + D`) và chọn **i18n Micro**. Tab này hiển thị:

- mọi file JSON trong `locales/` (gốc và `pages/`) của mọi layer, cùng các file gốc từ `additionalTranslationDirs`;
- một trình soạn thảo cho mỗi file; **Save** ghi file trở lại ổ đĩa, và dev server tải lại bản dịch;
- **Export** / **Import** một file dưới dạng JSON, và **Stats** với số lượng khóa và độ bao phủ bản dịch;
- một chế độ xem cấu hình hiển thị các tùy chọn module đã được phân giải;
- **Translate**, điền các khóa còn thiếu bằng một công cụ dịch máy mà bạn cấu hình trong phần cài đặt của tab.

Việc lưu chỉ ghi vào các file `.json` đã tồn tại bên trong thư mục dịch của bạn. Khi một file tồn tại ở nhiều layer, bản sao của dự án sẽ được ghi.

## Inspector Vue DevTools {#vue-devtools-inspector}

Với tiện ích trình duyệt Vue DevTools, module đăng ký một inspector i18n (locale hiện tại, chunk của route, các khóa đã tải) và một timeline ghi lại các lần chuyển locale, lần tải chunk và các khóa bị thiếu.

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    debug: true, // also log every $t / $ts / $tc call on the timeline
    // vueDevtools: false, // turn the inspector off, keep the Nuxt tab
  },
})
```

[`vueDevtools`](/vi/api/module-options) mặc định là `true`. `debug: true` tạo ra rất nhiều log; chỉ nên dùng trong các phiên ngắn.

## Bên ngoài Nuxt {#outside-nuxt}

Giao diện tương tự được phát hành dưới dạng [`@i18n-micro/devtools-ui`](/vi/integrations/devtools-ui-package) cho các ứng dụng Vite xây dựng trên các package framework; xem trang đó để biết cách thiết lập.
