Trang này ánh xạ một app `@nuxtjs/i18n` sang nuxt-i18n-micro: tùy chọn, hàm trợ giúp và cách bố trí tệp. Hãy dùng nó khi bạn thay module trong một app hiện có. Bạn giữ nguyên URL (tên các chiến lược giống nhau) và chuyển bản dịch vào các tệp JSON theo từng trang.

<Tip>

**Bạn đang nâng cấp chính nuxt-i18n-micro?** — Xem [Nâng cấp](/vi/guide/upgrade).

</Tip>

## Thay module {#swap-the-module}

```bash
npm uninstall @nuxtjs/i18n
npm install nuxt-i18n-micro
```

```ts
// nuxt.config.ts — before
export default defineNuxtConfig({
  modules: ['@nuxtjs/i18n'],
  i18n: {
    locales: [
      { code: 'en', language: 'en-US', file: 'en.json' },
      { code: 'de', language: 'de-DE', file: 'de.json' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    langDir: 'locales',
    detectBrowserLanguage: { useCookie: true, cookieKey: 'i18n_redirected', redirectOn: 'root' },
  },
})
```

```ts
// nuxt.config.ts — after
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    translationDir: 'locales',
    localeCookie: 'i18n_redirected',
    autoDetectPath: '/',
  },
})
```

## Tùy chọn {#options}

| `@nuxtjs/i18n` | nuxt-i18n-micro |
| --- | --- |
| `locales[].code` | `locales[].code` |
| `locales[].language` (`iso` trước v9) | `locales[].iso` |
| `locales[].name` | `locales[].displayName` |
| `locales[].dir` | `locales[].dir` |
| `locales[].domain` | `locales[].baseUrl` (một origin kèm scheme) |
| `locales[].domainDefault` | `locales[].baseDefault` |
| `differentDomains`, `multiDomainLocales` | không cần: chỉ riêng `baseUrl` đã định tuyến theo host, xem [Layer và tên miền](/vi/guide/layers#multiple-domains) |
| `locales[].file` / `files`, `langDir`, `lazy` | `translationDir`; tệp được tìm theo tên và luôn được tải theo từng trang |
| `defaultLocale`, `strategy` | cùng tên, cùng bốn giá trị |
| `baseUrl` | `metaBaseUrl` |
| `customRoutes: 'config'` + `pages` | `globalLocaleRoutes` |
| `detectBrowserLanguage: false` | `redirects: false` (không chuyển hướng) hoặc `autoDetectLanguage: false` (bỏ qua header) |
| `detectBrowserLanguage.useCookie` / `cookieKey` | `localeCookie: '<name>'` (`null` tắt cookie) |
| `detectBrowserLanguage.redirectOn: 'root'` | `autoDetectPath: '/'` (mặc định) |
| `detectBrowserLanguage.redirectOn: 'no prefix'` | `autoDetectPath: 'no_prefix'` |
| `detectBrowserLanguage.redirectOn: 'all'` | `autoDetectPath: '*'` |
| Tệp cấu hình `vueI18n` (`fallbackLocale`, `numberFormats`, `datetimeFormats`) | `fallbackLocale`, `numberFormats`, `datetimeFormats` trong `i18n` |

Không có `alwaysRedirect`: khi đã đặt cookie, `/` làm theo cookie ở mọi lần truy cập. Danh sách đầy đủ có tại [Tùy chọn module](/vi/api/module-options); quy tắc phát hiện có tại [Phát hiện locale](/vi/guide/locale-detection).

## Hàm trợ giúp và composable {#helpers-and-composables}

| `@nuxtjs/i18n` / vue-i18n | nuxt-i18n-micro (template / `useI18n()`) |
| --- | --- |
| `const { t } = useI18n()` | `const { t } = useI18n()`, `$t` trong template |
| `t('key', count)`, `tc` | `$tc('key', count)` |
| `te('key')` | `$has('key')` |
| `n(value, 'currency')`, `d(date, 'short')` | `$tn(value, 'currency')`, `$td(date, 'short')` |
| — | `$tdr(date)`: thời gian tương đối ("in 3 days") |
| `locale.value` | `$getLocale()` |
| `locales.value` | `$getLocales()` |
| `setLocale('de')` | `$switchLocale('de')` |
| `useLocalePath()('about')` | `$localePath({ name: 'about' })` |
| `useLocaleRoute()` | `$localeRoute()` |
| `useSwitchLocalePath()('de')` | `$switchLocalePath('de')` |
| `useSetI18nParams()` | `$setI18nRouteParams()` |
| `useLocaleHead()` | tự động với `meta: true`; [`useLocaleHead`](/vi/composables/useLocaleHead) cho head tùy chỉnh |
| `defineI18nRoute({ paths: { de: '/ueber-uns' }, locales: [...] })` | `$defineI18nRoute({ localeRoutes: { de: '/ueber-uns' }, locales: [...] })` |
| `<NuxtLinkLocale to="about">` | `<i18n-link :to="{ name: 'about' }">` |
| `<i18n-t>` | `<i18n-t>` (slot điền các placeholder `{name}`) |
| `$i18n` trong server route | `useTranslationServerMiddleware(event)`, xem [Server route và API](/vi/guide/server-side-translations) |

`useI18n()` được tự động import. `$defineI18nRoute` phải giữ dấu `$`: quá trình build đọc lời gọi đó. Tất cả hàm trợ giúp: [Phương thức](/vi/api/methods).

## Tệp bản dịch {#translation-files}

Chuyển các khóa của một tệp lớn cho mỗi locale thành một tệp gốc cộng với một tệp cho mỗi trang:

```text
locales/
├── en.json              # keys used on many pages (nav, footer)
├── de.json
└── pages/
    ├── index/en.json    # keys of pages/index.vue
    └── about/en.json    # keys of pages/about.vue
```

Giữ mọi thứ trong các tệp gốc cũng hoạt động, và là bước đầu tiên nhanh nhất. Đặt `disablePageLocales: true` cho tới khi bạn tách chúng. Xem [Tệp bản dịch](/vi/guide/translations).

### Cú pháp thông điệp {#message-syntax}

| vue-i18n | nuxt-i18n-micro |
| --- | --- |
| Nội suy có tên `{name}` | giống nhau |
| `car \| cars` (2 dạng: 1 → dạng đầu) | các dạng được chọn theo số đếm từ 0: viết `no cars \| one car \| {count} cars` |
| Linked messages `@:other.key` | không hỗ trợ: lặp lại văn bản hoặc kết hợp trong code |
| Modifier `@.upper:` | không hỗ trợ: định dạng trong code hoặc dùng `<i18n-t>` |
| Escape ký tự `{'@'}` | không cần: chỉ các token `{word}` được thay thế |
| Tệp thông điệp JS/TS | chỉ JSON |

Quy tắc số nhiều có thể thay thế bằng tùy chọn [`plural`](/vi/api/module-options#plural).

## Kiểm tra sau khi chuyển đổi {#check-after-the-switch}

- Mọi URL bạn từng có vẫn phân giải được; tên chiến lược khớp nhau, đường dẫn tùy chỉnh chuyển sang `globalLocaleRoutes` hoặc `$defineI18nRoute`.
- `hreflang`, canonical và `og:locale` có sẵn với `meta: true`; hãy xóa các thẻ viết tay.
- Lỗi phân tích JSON ghi log đường dẫn tệp; khóa bị thiếu ghi cảnh báo trong console trình duyệt ở môi trường phát triển.
