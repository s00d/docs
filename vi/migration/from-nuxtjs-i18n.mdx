# 🔄 Di chuyển từ `nuxt-i18n` sang `Nuxt I18n Micro`

## Bạn cần hướng dẫn nào?

| Bạn đang di chuyển từ…                | Hướng dẫn                                            |
| -------------------------------------- | ------------------------------------------------ |
| `@nuxtjs/i18n` (module dựa trên vue-i18n) | **Trang này**                                    |
| `nuxt-i18n-micro` v2.x                 | [Nâng cấp từ v2.x lên v3.x](/migration/v2-to-v3) |

## Tại sao nên di chuyển?

- **Hiệu năng được cải thiện**: build nhanh hơn ~51% và ít bộ nhớ build hơn ~54% so với `@nuxtjs/i18n` **v10.6** trong [các fixture benchmark](/guides/performance-results) của chúng tôi
- **Cấu hình đơn giản hóa**: Thiết lập tinh gọn với các mặc định hợp lý
- **Quản lý tài nguyên tốt hơn**: Xử lý tối ưu các tệp bản dịch lớn

## Sự khác biệt chính

| Tính năng                 | `nuxt-i18n`                      | `Nuxt I18n Micro`                         |
| ----------------------- | -------------------------------- | ----------------------------------------- |
| Tệp bản dịch       | JS/TS/JSON, được tải qua `vueI18n` | Chỉ JSON, tự động tạo trong dev          |
| Tạo route        | Runtime                          | Thời điểm build (`@i18n-micro/route-strategy`) |
| Tải bản dịch     | Được bundle vào JS                  | JSON tải chậm theo trang                 |
| Trạng thái locale            | `useI18n()` từ `vue-i18n`      | Composable `useI18nLocale()`              |
| `detectBrowserLanguage` | Được hỗ trợ                        | Dùng `autoDetectLanguage` thay thế          |

## Từng bước

### 1. Cài đặt

```bash
npm install nuxt-i18n-micro
```

### 2. Cập nhật cấu hình

**Trước (nuxt-i18n):**

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'fr', iso: 'fr-FR' },
    ],
    defaultLocale: 'en',
    vueI18n: './i18n.config.js',
    detectBrowserLanguage: { useCookie: true },
  },
})
```

**Sau (Nuxt I18n Micro v3):**

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
    localeCookie: 'user-locale',
    autoDetectLanguage: true,
  },
})
```

### 3. Sắp xếp lại các tệp bản dịch

Di chuyển các bản dịch sang thư mục `locales` ở định dạng JSON. Đây là so sánh dự án đầy đủ:

**Before (`nuxt-i18n`):**

```text
my-app/
├── i18n/
│   └── locales/          # langDir
│       ├── en.json       # all translations in one file
│       ├── ru.json
│       └── de.json
├── pages/
│   ├── index.vue
│   └── page.vue
├── server/
│   └── tsconfig.json
├── nuxt.config.ts        # config will change
└── package.json
```

**After (Nuxt I18n Micro):**

```text
my-app/
├── locales/              # translationDir
│   ├── en.json           # root-level translations
│   ├── ru.json
│   ├── de.json
│   └── pages/            # page-specific
│       ├── index/
│       │   ├── en.json
│       │   ├── ru.json
│       │   └── de.json
│       └── page/
│           ├── en.json
│           ├── ru.json
│           └── de.json
├── pages/
│   ├── index.vue         # API changes
│   └── page.vue
├── server/
│   └── tsconfig.json
├── nuxt.config.ts        # new config
└── package.json
```

<Tip>
Missing page-specific translation files are **auto-generated** in development mode — just run `nuxt dev` and the module will create empty JSON files for each page and locale.
</Tip>

### 4. Cập nhật điều hướng

```diff
- <nuxt-link :to="{ name: 'index' }">Home</nuxt-link>
+ <NuxtLink :to="$localeRoute({ name: 'index' })">Home</NuxtLink>
+ <!-- or use the built-in component -->
+ <i18n-link :to="{ name: 'index' }">Home</i18n-link>
```

### 5. Cập nhật SEO

Loại bỏ mọi cấu hình SEO thủ công từ `nuxt-i18n`. Nuxt I18n Micro tự động tạo `hreflang`, các URL canonical và các thẻ Open Graph khi `meta: true` được đặt.

### 6. Kiểm thử

Kiểm thử kỹ lưỡng các bản dịch, chuyển đổi locale, chuyển hướng và các thẻ meta SEO.

## 🛡️ Các vấn đề phổ biến và xử lý sự cố

### ❌ Tệp bản dịch không tải

Đảm bảo các tệp bản dịch nằm trong thư mục đúng và tuân theo định dạng JSON. Xác minh rằng `translationDir` khớp với vị trí tệp của bạn.

### ⚠️ Lỗi Route không tìm thấy

Kiểm tra rằng tất cả các mã locale trong mảng `locales` đều chính xác và các route được thiết lập đúng.

### 🏷️ Thiếu thẻ SEO

Xác minh rằng `meta: true` được đặt và mỗi locale có một mã `iso` hợp lệ.

### 🔄 Không khớp Hydration

Nếu dùng chiến lược `no_prefix`, hãy đặt locale trong plugin server với `order: -10` bằng `useI18nLocale().setLocale()` để đảm bảo server và client đồng ý về locale. Xem [Phát hiện ngôn ngữ tùy chỉnh](/guides/custom-language-detection).

### 🍪 Chuyển hướng không hoạt động

Đối với các chiến lược có tiền tố, hãy đảm bảo `localeCookie: 'user-locale'` được đặt. Không có cookie, plugin chuyển hướng server không có cách nào để ghi nhớ locale ưu tiên của người dùng qua các lần tải lại trang.
