---

Nuxt I18n Micro là một module i18n nhẹ, hiệu năng cao cho Nuxt 3 và 4, được thiết kế cho các dự án lớn. Nó giữ thời gian build, mức dùng bộ nhớ và kích thước bundle ở mức thấp so với các giải pháp i18n truyền thống như `@nuxtjs/i18n`.

Các route bản địa hóa được tạo khi build bởi `@i18n-micro/route-strategy` và được phân giải lúc chạy bởi `@i18n-micro/path-strategy`, nên liên kết, bộ chuyển đổi, `hreflang` và chuyển hướng đều thống nhất với router. Bản dịch chỉ dùng JSON, chia thành các tệp gốc dùng chung và các tệp theo từng trang mà dev server tạo sẵn cho bạn, có tích hợp HMR.

<CodeGroup>

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>
