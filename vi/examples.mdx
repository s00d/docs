# 📚 Ví dụ và cách dùng Nuxt I18n Micro

Phần này cung cấp nhiều ví dụ thể hiện cách sử dụng `Nuxt I18n Micro` trong ứng dụng Nuxt.js của bạn. Bạn sẽ thấy cách chuyển đổi locale, dùng các component `<i18n-link>`, `<i18n-switcher>`, và `<i18n-t>`, cũng như xử lý các khóa bản dịch động.

## 🛠️ Thiết lập cơ bản

Đây là thiết lập cơ bản để bắt đầu với `Nuxt I18n Micro`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Chuyển đổi locale

### Chuyển đổi locale bằng chương trình

Ví dụ này minh họa cách chuyển đổi locale theo cách lập trình bằng các nút:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### JSON ví dụ cho chuyển đổi locale

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### Dùng component `<i18n-switcher>`

Component `<i18n-switcher>` cung cấp một dropdown để chuyển đổi locale với nhãn có thể tùy chỉnh:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 🌐 Dùng `<i18n-link>` cho điều hướng đã bản địa hóa

Component `<i18n-link>` tự động xử lý định tuyến theo locale:

```vue
<template>
  <div>
    <i18n-link to="/about">{{ $t('about') }}</i18n-link>
    <i18n-link :to="{ name: 'index' }">{{ $t('home') }}</i18n-link>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### JSON ví dụ cho liên kết điều hướng

```json
{
  "about": "About Us",
  "home": "Home"
}
```

## 📝 Hiển thị khóa động từ tệp bản dịch

Trong một số tình huống, bạn có thể muốn duyệt qua các khóa động được lưu trong tệp bản dịch và hiển thị giá trị của chúng có điều kiện. Ví dụ dưới đây minh họa cách thực hiện điều này bằng `Nuxt I18n Micro`.

### Ví dụ: Hiển thị khóa động

Ví dụ này lấy một mảng các khóa từ một đường dẫn bản dịch cụ thể (trong trường hợp này là `dynamic`) và duyệt qua chúng. Mỗi khóa được kiểm tra sự tồn tại bằng `$has` trước khi hiển thị giá trị bằng `$t`.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Tệp bản dịch ví dụ (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Ví dụ: Hiển thị khóa động từ một object

Trong ví dụ này, chúng ta xử lý một object được lưu trong tệp bản dịch. Chúng ta lấy và duyệt qua các khóa của object, hiển thị động cả tên khóa và giá trị tương ứng.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Tệp bản dịch ví dụ (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 Dùng `<i18n-t>` cho bản dịch với slot và nội suy

Component `<i18n-t>` hữu ích để hiển thị bản dịch với nội dung động và các thẻ HTML:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### JSON ví dụ cho `<i18n-t>`

```json
{
  "greeting": "Welcome to the page"
}
```

### Với nội suy

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### JSON ví dụ cho nội suy

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 Dùng `$tc` cho pluralization

Hàm `$tc` trong `Nuxt I18n Micro` xử lý pluralization dựa trên số đếm và thiết lập locale. Điều này hữu ích để điều chỉnh động các thông báo liên quan đến số đếm, như các mục, thông báo, hoặc các thực thể khác có thể thay đổi về số lượng.

### Ví dụ: Dùng `$tc` cho pluralization

Trong ví dụ dưới đây, chúng ta hiển thị một thông báo cho biết số lượng táo bằng `$tc`. Khóa bản dịch xử lý nhiều dạng số nhiều dựa trên số đếm được cung cấp.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### JSON ví dụ cho pluralization

Đây là cách bạn có thể định nghĩa bản dịch trong tệp JSON để xử lý các dạng số nhiều khác nhau:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Giải thích

- **`$tc('apples', 0)`**: Trả về dạng đầu tiên, dùng khi số đếm là 0 (`"no apples"`).
- **`$tc('apples', 1)`**: Trả về dạng thứ hai, dùng khi số đếm là 1 (`"one apple"`).
- **`$tc('apples', 10)`**: Trả về dạng thứ ba với giá trị số đếm, dùng khi số đếm là hai trở lên (`"10 apples"`).

### Ví dụ bổ sung với pluralization phức tạp hơn

Nếu ứng dụng của bạn cần xử lý các quy tắc pluralization phức tạp hơn (ví dụ: các trường hợp cụ thể cho zero, one, two, few, many, other), bạn có thể mở rộng chuỗi bản dịch tương ứng:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: Có thể được thiết lập để trả về `"two apples"`.
- **`$tc('apples', 3)`**: Có thể trả về `"a few apples"`, tùy theo các quy tắc được định nghĩa cho số đếm.

## 🌐 Dùng `$tn` để định dạng số

Hàm `$tn` định dạng số theo locale hiện tại bằng API `Intl.NumberFormat`. Điều này hữu ích để hiển thị số theo cách phù hợp với thiết lập vùng của người dùng, chẳng hạn như tiền tệ, phần trăm, hoặc các định dạng số khác.

### Ví dụ: Dùng `$tn` để định dạng số

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ Dùng `$td` để định dạng ngày và giờ

Hàm `$td` định dạng ngày và giờ theo locale hiện tại bằng API `Intl.DateTimeFormat`. Điều này hữu ích để hiển thị ngày và giờ theo các định dạng quen thuộc với người dùng dựa trên thiết lập locale của họ.

### Ví dụ: Dùng `$td` để định dạng ngày và giờ

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ Dùng `$tdr` để định dạng ngày tương đối

Hàm `$tdr` định dạng ngày dưới dạng thời gian tương đối (ví dụ: "5 minutes ago", "2 days ago") theo locale hiện tại bằng API `Intl.RelativeTimeFormat`. Điều này hữu ích để hiển thị chênh lệch thời gian so với ngày và giờ hiện tại.

### Ví dụ: Dùng `$tdr` để định dạng ngày tương đối

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
