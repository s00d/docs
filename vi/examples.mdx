# 📚 Ví dụ và cách dùng Nuxt I18n Micro

Phần này cung cấp nhiều ví dụ minh họa cách sử dụng `Nuxt I18n Micro` trong ứng dụng Nuxt.js của bạn. Bạn sẽ thấy cách chuyển đổi ngôn ngữ, dùng các thành phần `<i18n-link>`, `<i18n-switcher>`, `<i18n-t>`, và xử lý các khóa bản dịch một cách động.

## 🛠️ Thiết lập cơ bản

Đây là thiết lập cơ bản để bắt đầu với `Nuxt I18n Micro`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Chuyển đổi ngôn ngữ

### Chuyển ngôn ngữ theo cách lập trình

Ví dụ này minh họa cách chuyển đổi ngôn ngữ theo cách lập trình bằng các nút bấm:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### JSON ví dụ cho chuyển đổi ngôn ngữ

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### Sử dụng thành phần `<i18n-switcher>`

Thành phần `<i18n-switcher>` cung cấp một menu thả xuống để chuyển đổi ngôn ngữ, kèm theo các nhãn có thể tùy chỉnh:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 🌐 Sử dụng `<i18n-link>` cho điều hướng đã bản địa hóa

Thành phần `<i18n-link>` tự động xử lý định tuyến theo ngôn ngữ:

```vue
<template>
  <div>
    <i18n-link to="/about">{{ $t('about') }}</i18n-link>
    <i18n-link :to="{ name: 'index' }">{{ $t('home') }}</i18n-link>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### JSON ví dụ cho liên kết điều hướng

```json
{
  "about": "About Us",
  "home": "Home"
}
```

### Ví dụ với kiểu liên kết đang hoạt động

```vue
<template>
  <div>
    <i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
  </div>
</template>
```

### JSON ví dụ cho kiểu liên kết đang hoạt động

Bạn có thể dùng cùng tệp JSON như ở ví dụ trước cho trường hợp này.

## 📝 Hiển thị khóa động từ tệp bản dịch

Trong một số tình huống, bạn có thể muốn duyệt qua các khóa động lưu trong tệp bản dịch và hiển thị giá trị của chúng có điều kiện. Ví dụ dưới đây minh họa cách thực hiện điều đó với `Nuxt I18n Micro`.

### Ví dụ: Hiển thị các khóa động

Ví dụ này lấy một mảng khóa từ một đường dẫn bản dịch cụ thể (ở đây là `dynamic`) và duyệt qua chúng. Mỗi khóa được kiểm tra sự tồn tại bằng `$has` trước khi hiển thị giá trị của nó bằng `$t`.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Tệp bản dịch ví dụ (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Ví dụ: Hiển thị khóa động từ một đối tượng

Trong ví dụ này, chúng ta xử lý một đối tượng được lưu trong tệp bản dịch của bạn. Chúng ta lấy và duyệt qua các khóa của đối tượng, hiển thị động cả tên khóa lẫn giá trị tương ứng.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Tệp bản dịch ví dụ (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 Sử dụng `<i18n-t>` cho bản dịch với slot và nội suy

Thành phần `<i18n-t>` hữu ích để hiển thị bản dịch với nội dung động và các thẻ HTML:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### JSON ví dụ cho `<i18n-t>`

```json
{
  "greeting": "Welcome to the page"
}
```

### Với nội suy

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### JSON ví dụ cho nội suy

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 Sử dụng `$tc` cho số nhiều

Hàm `$tc` trong `Nuxt I18n Micro` xử lý số nhiều dựa trên số lượng và cấu hình ngôn ngữ. Điều này hữu ích khi điều chỉnh động các thông báo liên quan đến số lượng, chẳng hạn như mục, thông báo hoặc các thực thể khác có thể thay đổi số lượng.

### Ví dụ: Sử dụng `$tc` cho số nhiều

Trong ví dụ sau, chúng ta hiển thị thông báo cho biết số quả táo bằng `$tc`. Khóa bản dịch xử lý nhiều dạng số nhiều dựa trên số lượng được cung cấp.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### JSON ví dụ cho số nhiều

Đây là cách bạn định nghĩa bản dịch trong tệp JSON để xử lý các dạng số nhiều khác nhau:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Giải thích

- **`$tc('apples', 0)`**: Trả về dạng đầu tiên, dùng khi số lượng là không (`"no apples"`).
- **`$tc('apples', 1)`**: Trả về dạng thứ hai, dùng khi số lượng là một (`"one apple"`).
- **`$tc('apples', 10)`**: Trả về dạng thứ ba với giá trị số lượng, dùng khi số lượng từ hai trở lên (`"10 apples"`).

### Ví dụ bổ sung với quy tắc số nhiều phức tạp hơn

Nếu ứng dụng của bạn cần xử lý các quy tắc số nhiều phức tạp hơn (ví dụ các trường hợp cụ thể cho zero, one, two, few, many, other), bạn có thể mở rộng chuỗi bản dịch tương ứng:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: Có thể được cấu hình để trả về `"two apples"`.
- **`$tc('apples', 3)`**: Có thể trả về `"a few apples"`, tùy thuộc vào các quy tắc được định nghĩa cho số lượng.

## 🌐 Sử dụng `$tn` cho định dạng số

Hàm `$tn` định dạng số theo ngôn ngữ hiện tại bằng API `Intl.NumberFormat`. Điều này hữu ích để hiển thị số theo cách khớp với cài đặt khu vực của người dùng, chẳng hạn như tiền tệ, phần trăm hoặc các định dạng số khác.

### Ví dụ: Sử dụng `$tn` cho định dạng số

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ Sử dụng `$td` cho định dạng ngày và giờ

Hàm `$td` định dạng ngày và giờ theo ngôn ngữ hiện tại bằng API `Intl.DateTimeFormat`. Điều này hữu ích để hiển thị ngày và giờ ở định dạng quen thuộc với người dùng dựa trên cài đặt ngôn ngữ của họ.

### Ví dụ: Sử dụng `$td` cho định dạng ngày và giờ

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ Sử dụng `$tdr` cho định dạng ngày tương đối

Hàm `$tdr` định dạng ngày dưới dạng thời gian tương đối (ví dụ "5 minutes ago", "2 days ago") theo ngôn ngữ hiện tại bằng API `Intl.RelativeTimeFormat`. Điều này hữu ích để hiển thị chênh lệch thời gian so với ngày giờ hiện tại.

### Ví dụ: Sử dụng `$tdr` cho định dạng ngày tương đối

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
