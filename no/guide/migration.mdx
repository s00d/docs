---
title: "Migrering fra @nuxtjs/i18n"
description: "Overfør alternativer, composables og oversettelsesfiler fra @nuxtjs/i18n til nuxt-i18n-micro."
---

Denne siden overfører en `@nuxtjs/i18n`-app til nuxt-i18n-micro: alternativer, hjelpefunksjoner og filoppsett. Bruk den når du bytter modulen i en eksisterende app. Du beholder URL-ene dine (strateginavnene er de samme) og flytter oversettelsene til JSON-filer per side.

<Tip>

**Oppgraderer du selve nuxt-i18n-micro?** — Se [Oppgradering](/no/guide/upgrade).

</Tip>

## Bytt modulen {#swap-the-module}

```bash
npm uninstall @nuxtjs/i18n
npm install nuxt-i18n-micro
```

```ts
// nuxt.config.ts — before
export default defineNuxtConfig({
  modules: ['@nuxtjs/i18n'],
  i18n: {
    locales: [
      { code: 'en', language: 'en-US', file: 'en.json' },
      { code: 'de', language: 'de-DE', file: 'de.json' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    langDir: 'locales',
    detectBrowserLanguage: { useCookie: true, cookieKey: 'i18n_redirected', redirectOn: 'root' },
  },
})
```

```ts
// nuxt.config.ts — after
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    translationDir: 'locales',
    localeCookie: 'i18n_redirected',
    autoDetectPath: '/',
  },
})
```

## Alternativer {#options}

| `@nuxtjs/i18n` | nuxt-i18n-micro |
| --- | --- |
| `locales[].code` | `locales[].code` |
| `locales[].language` (`iso` før v9) | `locales[].iso` |
| `locales[].name` | `locales[].displayName` |
| `locales[].dir` | `locales[].dir` |
| `locales[].domain` | `locales[].baseUrl` (en opprinnelse med skjema) |
| `locales[].domainDefault` | `locales[].baseDefault` |
| `differentDomains`, `multiDomainLocales` | ikke nødvendig: `baseUrl` alene ruter etter vert, se [Lag og domener](/no/guide/layers#multiple-domains) |
| `locales[].file` / `files`, `langDir`, `lazy` | `translationDir`; filer finnes etter navn og lastes alltid per side |
| `defaultLocale`, `strategy` | samme navn, samme fire verdier |
| `baseUrl` | `metaBaseUrl` |
| `customRoutes: 'config'` + `pages` | `globalLocaleRoutes` |
| `detectBrowserLanguage: false` | `redirects: false` (ingen omdirigeringer) eller `autoDetectLanguage: false` (ignorer headeren) |
| `detectBrowserLanguage.useCookie` / `cookieKey` | `localeCookie: '<name>'` (`null` slår av informasjonskapselen) |
| `detectBrowserLanguage.redirectOn: 'root'` | `autoDetectPath: '/'` (standard) |
| `detectBrowserLanguage.redirectOn: 'no prefix'` | `autoDetectPath: 'no_prefix'` |
| `detectBrowserLanguage.redirectOn: 'all'` | `autoDetectPath: '*'` |
| `vueI18n`-konfigurasjonsfil (`fallbackLocale`, `numberFormats`, `datetimeFormats`) | `fallbackLocale`, `numberFormats`, `datetimeFormats` i `i18n` |

Det finnes ingen `alwaysRedirect`: med en informasjonskapsel satt følger `/` den ved hvert besøk. Den fullstendige listen er [Modulalternativer](/no/api/module-options); gjenkjenningsreglene står på [Locale-gjenkjenning](/no/guide/locale-detection).

## Hjelpefunksjoner og composables {#helpers-and-composables}

| `@nuxtjs/i18n` / vue-i18n | nuxt-i18n-micro (mal / `useI18n()`) |
| --- | --- |
| `const { t } = useI18n()` | `const { t } = useI18n()`, `$t` i maler |
| `t('key', count)`, `tc` | `$tc('key', count)` |
| `te('key')` | `$has('key')` |
| `n(value, 'currency')`, `d(date, 'short')` | `$tn(value, 'currency')`, `$td(date, 'short')` |
| — | `$tdr(date)`: relativ tid ("om 3 dager") |
| `locale.value` | `$getLocale()` |
| `locales.value` | `$getLocales()` |
| `setLocale('de')` | `$switchLocale('de')` |
| `useLocalePath()('about')` | `$localePath({ name: 'about' })` |
| `useLocaleRoute()` | `$localeRoute()` |
| `useSwitchLocalePath()('de')` | `$switchLocalePath('de')` |
| `useSetI18nParams()` | `$setI18nRouteParams()` |
| `useLocaleHead()` | automatisk med `meta: true`; [`useLocaleHead`](/no/composables/useLocaleHead) for egendefinerte heads |
| `defineI18nRoute({ paths: { de: '/ueber-uns' }, locales: [...] })` | `$defineI18nRoute({ localeRoutes: { de: '/ueber-uns' }, locales: [...] })` |
| `<NuxtLinkLocale to="about">` | `<i18n-link :to="{ name: 'about' }">` |
| `<i18n-t>` | `<i18n-t>` (slots fyller `{name}`-plassholdere) |
| `$i18n` i serverruter | `useTranslationServerMiddleware(event)`, se [Serverruter og API](/no/guide/server-side-translations) |

`useI18n()` importeres automatisk. `$defineI18nRoute` må beholde sin `$`: bygget leser det kallet. Alle hjelpefunksjoner: [Metoder](/no/api/methods).

## Oversettelsesfiler {#translation-files}

Flytt nøklene fra én stor fil per locale til en rotfil pluss én fil per side:

```text
locales/
├── en.json              # keys used on many pages (nav, footer)
├── de.json
└── pages/
    ├── index/en.json    # keys of pages/index.vue
    └── about/en.json    # keys of pages/about.vue
```

Å beholde alt i rotfilene fungerer også, og er det raskeste første steget. Sett `disablePageLocales: true` til du deler dem opp. Se [Oversettelsesfiler](/no/guide/translations).

### Meldingssyntaks {#message-syntax}

| vue-i18n | nuxt-i18n-micro |
| --- | --- |
| `{name}` navngitt interpolering | det samme |
| `car \| cars` (2 former: 1 → første) | former velges etter antall fra 0: skriv `no cars \| one car \| {count} cars` |
| `@:other.key` lenkede meldinger | støttes ikke: gjenta teksten eller komponer i kode |
| `@.upper:`-modifikatorer | støttes ikke: formater i kode eller bruk `<i18n-t>` |
| `{'@'}` bokstavelige escapes | ikke nødvendig: bare `{word}`-tokens erstattes |
| JS/TS-meldingsfiler | kun JSON |

Flertallsregelen kan erstattes med alternativet [`plural`](/no/api/module-options#plural).

## Sjekk etter byttet {#check-after-the-switch}

- Hver URL du hadde, løses fortsatt; strateginavnene samsvarer, egendefinerte stier flyttes til `globalLocaleRoutes` eller `$defineI18nRoute`.
- `hreflang`, canonical og `og:locale` kommer rett ut av boksen med `meta: true`; fjern håndskrevne.
- En JSON-parsefeil logger filstien; en manglende nøkkel logger en advarsel i nettleserkonsollen under utvikling.
