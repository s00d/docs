---
title: "Ekskludere stier"
description: "Hold sider og filer utenfor locale-ruting med excludePatterns, og se hvilke stier som allerede er ekskludert."
---

Noen stier skal aldri få et locale-prefiks eller en locale-omdirigering: et adminområde, en helsesjekk, en generert feed. `excludePatterns` markerer dem, og en innebygd liste dekker allerede Nuxt-interne stier og vanlige statiske filer. En ekskludert side beholder nøyaktig stien du skrev, og rendres fortsatt med `$t`.

## Ekskludere en sti {#exclude-a-path}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    excludePatterns: [
      '/admin', // /admin and everything below it
      '/preview-*', // glob over the whole path
    ],
  },
})
```

Med denne konfigurasjonen svarer `pages/admin/index.vue` bare på `/admin`; det finnes ingen `/de/admin`, og `/admin` blir aldri omdirigert til `/de/admin`.

## Mønstersyntaks {#pattern-syntax}

Mønstre matches mot stien uten `app.baseURL`:

| Mønster | Matcher | Matcher ikke |
| --- | --- | --- |
| `'/admin'` | `/admin`, `/admin/users` | `/administrator`, `/de/admin` |
| `'/preview-*'` | `/preview-1`, `/preview-a/b` | `/de/preview-1` |
| `'/file-?'` | `/file-a` | `/file-ab` |
| `/^\/v\d+\//` | `/v2/docs` | `/docs` |

En streng uten `*` eller `?` matcher stien og hele segmenter under den. Med `*` (en hvilken som helst rekke tegn, skråstreker inkludert) eller `?` (ett tegn) må den matche hele stien. Start alltid strenger med `/`.

## Hva som allerede er ekskludert {#what-is-excluded-already}

Disse får aldri locale-ruter eller omdirigeringer, uten noen konfigurasjon:

- `/api` og `/_nuxt`, og alt under dem;
- oversettelsesruten, `/_locales` som standard ([`apiBaseUrl`](/no/api/module-options#apibaseurl));
- enhver sti med et segment som starter med `__` (`/__nuxt_content`, `/en/__og-image__`);
- `/sitemap*.xml`, `/robots.txt`, `/favicon.ico`, `/apple-touch-icon*.png`, `/manifest.json`, `/sw.js`, `/workbox-*.js`;
- enhver sti der siste segment slutter på en filendelse for statiske filer: `xml txt ico json js css png jpg jpeg gif svg webp avif pdf wasm map mp4 webm mp3 zip gz woff woff2 ttf eot`. Sideslugs med punktum som `/user/john.doe` og `.html`-stier forblir sider.

## Hva en ekskludering gjør {#what-an-exclusion-does}

- **Ruter:** ingen lokaliserte varianter genereres; siden beholdes slik den er skrevet.
- **Omdirigeringer og 404-feil:** server-omdirigeringspluginen og klientens omdirigeringsmiddleware hopper over stien.
- **Prerendering:** matchende stier fjernes fra listen over ruter som prerendres.

Den hindrer ikke i18n-servermiddlewaren i å oppdage et locale for forespørselen, og den hindrer ikke siden i å bruke oversettelser. For å holde en side lokalisert, men utenfor SEO-tagger, bruk `disableMeta` ([Sidekonfigurasjon](/no/guide/per-component-translations#turn-off-seo-tags)). For å holde én side ulokalisert fra `nuxt.config.ts` etter sti gjør `globalLocaleRoutes: { '/admin': false }` ([Lokaliserte stier](/no/guide/custom-locale-routes#in-nuxt-config)) det samme for rutingen.
