---
title: "Kjøretidsoverstyringer"
description: "Endre standard-locale, reserve-locale eller deaktiverte locales per instans av ett bygg, med miljøvariabler eller runtimeConfig."
---

Kjøretidsoverstyringer lar ett byggeartefakt kjøre med ulike locale-innstillinger per miljø eller leietaker, uten å bygge på nytt. Du kan endre standard-locale, reserve-locale og hvilke locales som er deaktivert. Ruting, omdirigeringer, gjengivelse og serverhjelpere bruker de overstyrte verdiene, og det samme gjør nettleseren på en servergjengitt side.

## Sett overstyringer med miljøvariabler {#set-overrides-with-environment-variables}

```bash
NUXT_I18N_DEFAULT_LOCALE=de \
NUXT_I18N_FALLBACK_LOCALE=en \
NUXT_I18N_DISABLED_LOCALES=fr,it \
node .output/server/index.mjs
```

| Variabel | Alias |
| --- | --- |
| `NUXT_I18N_DEFAULT_LOCALE` | `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE` |
| `NUXT_I18N_FALLBACK_LOCALE` | `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE` |
| `NUXT_I18N_DISABLED_LOCALES` (kommaseparert) | `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES` |

Serveren leser dem én gang ved oppstart; start på nytt for å ta i bruk en endring. På en servergjengitt side får nettleseren de løste verdiene fra serveren. Med `ssr: false` finnes det ingen servergjengivelse, og nettleseren har ikke noe miljø: bare `runtimeConfig.public.i18nRuntime` gjelder der, og nettleseren logger advarslene nedenfor.

## Sett overstyringer i runtimeConfig {#set-overrides-in-runtimeconfig}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

En verdi satt i `runtimeConfig.public.i18nRuntime` vinner over `NUXT_I18N_*`-variabelen for samme felt.

Må ikke forveksles med byggetidsvariabelen `DEFAULT_LOCALE`, som erstatter `defaultLocale` under bygging og ikke trenger støtte ved kjøretid.

## Hva som kan og ikke kan endres {#what-can-and-cannot-change}

| Innstilling | Ved kjøretid |
| --- | --- |
| `defaultLocale` | Ja under `prefix` og `no_prefix`. Under `prefix_except_default` og `prefix_and_default` er den fastsatt ved bygging (sidene dens er rutene uten prefiks); en overstyring ignoreres med en advarsel. |
| `fallbackLocale` | Ja. |
| `disabledLocales` | Legges til locales som er deaktivert ved bygging; aktiverer aldri en på nytt. Byggets standard kan ikke deaktiveres under `prefix_except_default` / `prefix_and_default`. |
| `strategy` | Nei. En strategi ved kjøretid ignoreres med en advarsel; bygg ett artefakt per strategi. |

Ugyldige verdier ødelegger aldri appen. Hvert tilfelle logger én advarsel per serverprosess:

- å deaktivere alle locales ignoreres;
- en `defaultLocale` som ikke er aktivert, faller tilbake til første aktiverte locale;
- en `fallbackLocale` som ikke er aktivert, beholder byggeverdien hvis den er aktivert, ellers finnes det ingen reserve.

## Les den effektive konfigurasjonen {#read-the-effective-config}

```vue
<script setup lang="ts">
const { $getI18nConfig } = useNuxtApp()
const config = $getI18nConfig() // build config with overrides applied
</script>
```

Behandle den som skrivebeskyttet: på serveren deles den av alle forespørsler og er frosset under utvikling; nettleserens kopi er ikke frosset. Å importere konfigurasjonen fra `#build/i18n.strategy.mjs` gir byggeverdiene uten overstyringer.

## Deaktiverte locales og statiske filer {#disabled-locales-and-static-files}

En locale som er deaktivert ved kjøretid, svarer 404 på sine ruter og payload-rute, men payload-filene ligger fortsatt i `.output/public/_locales/`, og en statisk filserver returnerer dem. Når disse filene ikke skal være tilgjengelige, deaktiver locale ved bygging med `disabled: true`.
