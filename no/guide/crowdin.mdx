---

[Crowdin](https://crowdin.com/) er en oversettelsesplattform: du laster opp filene for standard-locale, oversetterne jobber i Crowdin, og du laster ned de andre locales igjen. Modulen leser vanlige JSON-filer, så Crowdin CLI trenger bare en `crowdin.yml` som kartlegger `locales/` og `locales/pages/` riktig. Ingen modulinnstillinger endres.

## Konfigurer crowdin.yml {#configure-crowdin-yml}

```yml
# crowdin.yml
project_id_env: CROWDIN_PROJECT_ID
api_token_env: CROWDIN_PERSONAL_TOKEN
base_path: ./locales
preserve_hierarchy: true

files:
  - source: /en.json
    translation: /%two_letters_code%.json
  - source: /pages/**/en.json
    translation: /pages/**/%two_letters_code%.json
```

- `en` er standard-locale; filene for den er kildene.
- `project_id_env` / `api_token_env` leser ID og token fra miljøvariabler, så ingen hemmeligheter blir committet.
- `preserve_hierarchy: true` beholder `pages/<page>/`-mappene som de er.
- Navnet på den oversatte filen må være lik locale-`code` i `nuxt.config.ts`. `%two_letters_code%` passer for koder som `de`; for koder som `pt-BR` bruker du `%locale%`, eller kartlegger Crowdins koder til dine med `languages_mapping`.

## Opplasting og nedlasting {#upload-and-download}

```bash
npm install -g @crowdin/cli

export CROWDIN_PROJECT_ID=123456
export CROWDIN_PERSONAL_TOKEN=...   # from Crowdin account settings

crowdin upload sources   # push locales/en.json and locales/pages/**/en.json
crowdin download         # write locales/de.json, locales/pages/**/de.json, ...
```

Kjør begge i CI for å holde filene oppdatert. Nedlastede filer havner i repositoriet ditt akkurat som håndredigerte filer; neste bygg eller omlasting i utviklingsmodus plukker dem opp.

## Før opplasting {#before-uploading}

Rydd i kildene først, slik at oversetterne ikke jobber med døde nøkler: [`i18n-micro clean`](/no/api/cli#clean) fjerner ubrukte nøkler, [`i18n-micro check`](/no/api/cli#check) rapporterer hull etter en nedlasting. CLI-en har ingen egen Crowdin-integrasjon: denne siden beskriver den støttede fremgangsmåten.
