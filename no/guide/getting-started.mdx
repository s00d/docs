Denne siden tar en Nuxt-app fra ingen i18n til en oversatt side med en språkvelger. Du trenger den én gang, i starten av et prosjekt. Du ender opp med lokaliserte URL-er (`/about`, `/de/about`), én JSON-fil per språk og side, og `$t` i malene dine.

## Installer {#install}

Modulen krever Nuxt 3.18 eller nyere (Nuxt 4 fungerer også) og Node 20 eller nyere.

<CodeGroup>

```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>

## Konfigurer språkene {#configure-the-locales}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', displayName: 'English' },
      { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
      { code: 'fr', iso: 'fr-FR', displayName: 'Français' },
    ],
    defaultLocale: 'en',
  },
})
```

Det er all konfigurasjonen en første app trenger. Standardverdiene gir deg:

- `strategy: 'prefix_except_default'`: standardspråket har ikke prefiks (`/about`), de andre har det (`/de/about`). Se [Rutingstrategier](/no/guide/strategy).
- `translationDir: 'locales'`: oversettelsesfilene ligger i `locales/` i prosjektroten, også med Nuxt 4-oppsettet `app/`.
- `meta: true`: `hreflang`-, canonical- og `og:locale`-tagger, samt `lang` og `dir` på `<html>`. Se [SEO](/no/guide/seo).
- En besøkende som åpner `/`, sendes til språket nettleseren ber om (`Accept-Language`). Se [Språkgjenkjenning](/no/guide/locale-detection).

`iso` er språktaggen som brukes i SEO-tagger; `code` er det som vises i URL-en. Alle alternativer er oppført i [Modulalternativer](/no/api/module-options).

## Legg til oversettelsesfiler {#add-translation-files}

Start utviklingsserveren med `nuxt dev`. Når Nuxt løser opp sidene, oppretter modulen en tom `{}`-fil for hvert språk og hver side som mangler en (slå dette av med [`disableWatcher`](/no/api/module-options#disablewatcher)):

```text
locales/
├── en.json            # root: keys every page can use
├── de.json
├── fr.json
└── pages/
    ├── index/         # pages/index.vue
    │   ├── en.json
    │   ├── de.json
    │   └── fr.json
    └── about/         # pages/about.vue
        ├── en.json
        ├── de.json
        └── fr.json
```

Fyll ut rotfilen og en sidefil:

```json
// locales/en.json
{ "nav": { "home": "Home", "about": "About" } }
```

```json
// locales/pages/index/en.json
{ "welcome": "Welcome, {name}!", "items": "no items | one item | {count} items" }
```

En side ser rotnøklene og sine egne nøkler; dens egen fil vinner ved konflikt. Mappenavn følger rutenavnet (`pages/articles/[id].vue` blir `locales/pages/articles-id/`). [Oversettelsesfiler](/no/guide/translations) dekker oppsettet, fallbacks og lasting.

## Bruk `$t` på en side {#use-$t-on-a-page}

```vue
<!-- pages/index.vue -->
<script setup lang="ts">
const { t, tc, getLocale } = useI18n()

const title = t('nav.home') // 'Home'
</script>

<template>
  <h1>{{ $t('welcome', { name: 'Ada' }) }}</h1>
  <!-- Welcome, Ada! -->
  <p>{{ $tc('items', 3) }}</p>
  <!-- 3 items -->
  <p>{{ getLocale() }}</p>
  <!-- en -->
</template>
```

- I maler er alle hjelpefunksjoner tilgjengelige med `$` (`$t`, `$tc`, `$localePath`, …).
- I `<script setup>` returnerer `useI18n()` de samme hjelpefunksjonene, med og uten `$` (`t` og `$t` er én og samme funksjon). Den importeres automatisk.
- `{name}`-plassholdere fylles ut fra params-objektet. Flertallsformer skilles med `|`; antallet velger formen (0, 1, deretter den siste for alt over det).

Alle hjelpefunksjoner er oppført i [Metoder](/no/api/methods).

## Lenk mellom sider og bytt språk {#link-between-pages-and-switch-locale}

```vue
<!-- components/AppHeader.vue -->
<template>
  <nav>
    <i18n-link :to="{ name: 'index' }">{{ $t('nav.home') }}</i18n-link>
    <i18n-link :to="{ name: 'about' }">{{ $t('nav.about') }}</i18n-link>
    <i18n-switcher />
  </nav>
</template>
```

- [`<i18n-link>`](/no/components/i18n-link) er en `NuxtLink` som peker til siden på gjeldende språk: på `/de` går about-lenken til `/de/about`.
- [`<i18n-switcher>`](/no/components/i18n-switcher) er en nedtrekksliste med de aktiverte språkene; den holder den besøkende på samme side.
- For dine egne knapper kaller du `$switchLocale('de')`, som navigerer til gjeldende side på tysk og husker valget. For en vanlig `NuxtLink` bruker du `$localePath({ name: 'about' })` eller `$switchLocalePath('de')`.

## Sjekk det {#check-it}

Kjør `nuxt dev` og åpne:

| URL | Viser |
| --- | --- |
| `/` | Engelsk forside (eller en omdirigering til `/de` når nettleseren din foretrekker tysk) |
| `/de` | Tysk forside |
| `/de/about` | Tysk about-side |
| `/en/about` | 404: standardspråket har ikke prefiks under `prefix_except_default` |

Endringer i JSON-filene tas i bruk på den åpne siden uten omlasting.
