I `nuxt dev` legger modulen til to feilsøkingshjelpemidler: en **i18n Micro**-fane i Nuxt DevTools for å bla gjennom og redigere oversettelsesfiler, og en Vue DevTools-inspektør for den aktive locale og innlastede ordbøker. Begge finnes bare under utvikling og legger ingenting til i produksjonsbygginger. Nuxt-fanen krever bare at Nuxt DevTools er aktivert; Vue-inspektøren krever i tillegg nettleserutvidelsen Vue DevTools.

## Nuxt DevTools-fane {#nuxt-devtools-tab}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  devtools: { enabled: true }, // the tab is registered only when DevTools are on
})
```

Åpne Nuxt DevTools (`Shift + Alt + D`) og velg **i18n Micro**. Fanen viser:

- alle JSON-filer under `locales/` (rot og `pages/`) i alle lag, samt rotfiler fra `additionalTranslationDirs`;
- en editor per fil; **Save** skriver filen tilbake til disk, og utviklingsserveren laster oversettelsene på nytt;
- **Export** / **Import** av en fil som JSON, og **Stats** med antall nøkler og oversettelsesdekning;
- en konfigurasjonsvisning av de løste modulalternativene;
- **Translate**, som fyller inn manglende nøkler med en maskinoversettelsesmotor du konfigurerer i fanens innstillinger.

Lagring skriver bare eksisterende `.json`-filer i oversettelseskatalogene dine. Når en fil finnes i flere lag, skrives prosjektets kopi.

## Vue DevTools-inspektør {#vue-devtools-inspector}

Med nettleserutvidelsen Vue DevTools registrerer modulen en i18n-inspektør (gjeldende locale, rutebit, innlastede nøkler) og en tidslinje med locale-bytter, lasting av biter og manglende nøkler.

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    debug: true, // also log every $t / $ts / $tc call on the timeline
    // vueDevtools: false, // turn the inspector off, keep the Nuxt tab
  },
})
```

[`vueDevtools`](/no/api/module-options) har `true` som standard. `debug: true` gir mye utdata; bruk det bare i korte økter.
