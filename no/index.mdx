title: "Nuxt I18n Micro"
description: "Liten, rask i18n for Nuxt: JSON-oversettelser per side, lokaliserte ruter ved byggetid, SEO-tagger rett ut av boksen."
---

Nuxt I18n Micro er en lett og høyytelses i18n-modul for Nuxt 3 og 4, laget for store prosjekter. Den holder byggetid, minnebruk og bundlestørrelse lave sammenlignet med tradisjonelle i18n-løsninger som `@nuxtjs/i18n`.

Lokaliserte ruter genereres ved byggetid av `@i18n-micro/route-strategy` og løses ved kjøretid av `@i18n-micro/path-strategy`, slik at lenker, språkvelgeren, `hreflang` og omdirigeringer alle stemmer overens med ruteren. Oversettelser er kun JSON, fordelt mellom delte rotfiler og filer per side som utviklingsserveren oppretter for deg, med innebygd HMR.

<CodeGroup>

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```

</CodeGroup>
