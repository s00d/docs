---
title: "useLocaleHead"
description: "useLocaleHead bygger i18n-SEO-taggene (lang, dir, canonical, hreflang, og:locale) som et objekt du sender til useHead."
---

`useLocaleHead()` bygger i18n-taggene i head for gjeldende rute: `lang` og `dir` på `<html>`, en canonical-lenke, `hreflang`-alternativer med `x-default`, `og:url`, `og:locale` og `og:locale:alternate`. Bruk den når du setter [`meta: false`](/no/api/module-options#meta) og håndterer `useHead` selv; med `meta: true` registrerer modulen allerede disse taggene, og endringer per side går gjennom [`useI18nHead`](/no/composables/useI18nHead).

## Signatur {#signature}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { build: () => LocaleHead; metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }, LocaleHead | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string; [key: string]: string | undefined }; link: ({ href: string; rel: "canonical"; [key: string]: string | undefined } | { href: string; hreflang: string; rel: "alternate"; [key: string]: string | undefined })[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

SEO-taggene i head for gjeldende rute: `hreflang`-alternativer for hver locale pluss
`x-default`, en canonical-lenke, `og:locale`, og `lang`/`dir` på `<html>`.

Trengs bare når `meta` er deaktivert eller standardverdiene må justeres — med `meta: true`
registrerer modulen de samme taggene selv.

| Parameter | Type | Beskrivelse |
| --- | --- | --- |
| `options` | `UseLocaleHeadOptions` |  |

**Returnerer** — `metaObject`, en ref som holder head-objektet klart til å sendes til `useHead`; `updateMeta` oppdaterer det; `build` beregner head-objektet fra gjeldende rute (reaktivt når det leses i en getter, f.eks. `useHead(() => build())`)

```ts
const { metaObject } = useLocaleHead({ addSeoAttributes: true })
useHead(metaObject)
```

## Alternativer {#options}

| Alternativ | Standard | Beskrivelse |
| --- | --- | --- |
| `addDirAttribute` | `true` | Sett `dir` på `<html>` fra locale-ens `dir` (`'auto'` når den ikke har noen). |
| `identifierAttribute` | `'id'` | Attributtet som identifiserer hver tagg (`i18n-can`, `i18n-og`, `i18n-alternate-<hreflang>`, …), slik at oppdateringer erstatter tagger i stedet for å legge til nye. |
| `addSeoAttributes` | `true` | Generer canonical-, `hreflang`- og `og:`-tagger. `false` beholder bare `htmlAttrs`. |
| `baseUrl` | `'/'` | Opprinnelse (origin) som settes foran hver URL. Behold `'/'` for relative URL-er; send `'https://example.com'` for absolutte. |
| `autoUpdate` | `true` | Bygg `metaObject` på nytt når ruten eller tilstanden `i18n-locale` endres. |

## Hva den genererer {#what-it-emits}

- Ingenting på en rute uten treff (404) eller med `disableMeta` for aktiv locale.
- Canonical og `og:url`: `$switchLocalePath(<active locale>)`, med spørrestrengen redusert til [`canonicalQueryWhitelist`](/no/api/module-options#canonicalquerywhitelist) og [`trailingSlash`](/no/api/module-options#trailingslash) anvendt.
- `hreflang`: én lenke per aktivert locale som siden finnes i, `hreflang = iso || code`, og locales med `seo: false` hoppes over; med `hreflangBaseLanguage: true` genererer også den første regionale locale-en for et språk taggen for basisspråket. Ingen under `no_prefix`.
- `x-default`: URL-en til standard-locale, med mindre strategien er `no_prefix`, standard-locale har `seo: false`, eller siden ikke finnes i den.
- `og:locale` / `og:locale:alternate`: fra locale-ens `og`, eller dens `iso` konvertert (`en-US` → `en_US`); hoppes over med en advarsel i utviklingsmodus når ingen av dem fungerer.

## Eksempel {#example}

```ts
// app.vue, with i18n.meta: false
const { metaObject } = useLocaleHead({ baseUrl: 'https://example.com' })
useHead(metaObject)
```

`build()` returnerer det samme objektet uten ref: `useHead(() => build())` forblir reaktivt uten en watcher.
