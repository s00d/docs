---
title: "useI18n"
description: "useI18n returnerer kjøretidshjelperne (`$t`, `$tc`, `$localePath`, …) som et vanlig objekt, både med og uten `$`-prefikset."
---

`useI18n()` returnerer modulens kjøretidshjelpere som et vanlig objekt. Bruk den i `<script setup>`, composables og plugins i stedet for å gå via `useNuxtApp()`. Hver hjelper finnes under sitt `$`-navn og et alias uten prefiks: `t` og `$t` er samme funksjon.

## Signatur {#signature}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Alle kjøretidshjelpere, som et vanlig objekt.

De samme funksjonene som pluginen injiserer som `$t`, `$tc` og så videre, tilgjengelige både under
navnet med dollarprefiks og et alias uten prefiks — så både `const { t } = useI18n()` og
`const { $t } = useI18n()` fungerer.

**Returnerer** — hjelperne som er beskrevet i [metodereferansen](/no/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

Det returnerte objektet inneholder alle hjelperne i [`PluginsInjections`](/no/api/methods). Hver av dem er dokumentert på siden [Hjelpere](/no/api/methods).

## Eksempel {#example}

```vue
<script setup lang="ts">
const { t, tc, localePath, switchLocale, getLocale } = useI18n()

const title = computed(() => t('page.title'))
</script>

<template>
  <h1>{{ title }}</h1>
  <p>{{ tc('items', 3) }}</p>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
  <button @click="switchLocale(getLocale() === 'en' ? 'de' : 'en')">{{ t('nav.switch') }}</button>
</template>
```

## Ikke i typen {#not-in-the-type}

`$defineI18nRoute` er kun typet på `useNuxtApp()`:

```ts
const { $defineI18nRoute } = useNuxtApp()
```
