## 🚀 Kom raskt i gang

### Installasjon

Installer modulen i din Nuxt-applikasjon:

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

### Grunnleggende konfigurasjon

Legg modulen til i `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
      { code: 'ar', iso: 'ar-SA', dir: 'rtl' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

<Tip>
- **Filer på rotnivå** (`locales/en.json`, osv.) — oversettelser som deles på tvers av hele appen (menyer, footer, felles brukergrensesnitt). Med `translationPayloads.mode: 'premerged'` (standard) slås de sammen inn i hver side ved byggetid.
- **Sidespesifikke filer** (`locales/pages/<route>/<locale>.json`) — oversettelser som er unike for enkeltsider, lastes kun når siden besøkes.
- **Dynamiske ruter** — `pages/articles/[id].vue` mappes til `locales/pages/articles-id/` (klammer erstattes med bindestreker).
- **Autogenerering** — alle oversettelsesfiler opprettes automatisk hvis de mangler under `nuxt dev`.
</Tip>

<Info>
Modulen støtter begge strukturene:

- **Sider**: `pages/**/*.vue` (Nuxt 3) eller `app/pages/**/*.vue` (Nuxt 4)
- **Oversettelser**: behold `locales/` i **prosjektroten** som standard (anbefalt konvensjon), ikke inne i `app/`

```tree
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   ├── en.json
│   └── pages/
└── nuxt.config.ts
```

Valgfri samlokalisering: `i18n: \{ translationDir: 'app/locales' \}` (se [fixture `n3`](https://github.com/s00d/nuxt-i18n-micro/tree/main/test/fixtures/n3)).

For den valgfrie CLI-hjelperen `text-to-i18n`, bruk [`nuxt-i18n-micro-cli` ≥ 2.1.1](/guides/cli#-text-to-i18n-command) slik at `app/pages` og `app/components` skannes fra prosjektroten.
</Info>

### Grunnleggende bruk

Bruk oversettelser i komponentene dine:

```vue
<template>
  <div>
    <h1>{{ $t('welcome') }}</h1>
    <p>{{ $t('description', { name: 'World' }) }}</p>

    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" @click="$switchLocale(locale.code)">
        {{ locale.code }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useI18n } from '#imports'

const { $t, $getLocales, $switchLocale } = useI18n()
</script>
```
