# 🌍 `<i18n-switcher>`-komponent

Komponenten `<i18n-switcher>` i `Nuxt I18n Micro` gir et brukervennlig nedtrekksgrensesnitt for å bytte mellom ulike lokaler i applikasjonen. Denne komponenten er svært tilpassbar og lar seg sømløst integrere med applikasjonens design og layout.

Lokaler med `disabled: true` **utelates** fra nedtrekket (de er fortsatt tilgjengelige via `$getLocales()` for SEO- / head-tagger). Bare byttbare lokaler får `NuxtLink` + `hreflang`.

Hver del er ustylet som standard: `custom*Style`-propene tar inline-stil-objekter, og
slotene under erstatter markupen helt når styling ikke er nok.

## 🛠️ Eksempelbruk

### Grunnleggende bruk

```vue
<template>
  <i18n-switcher />
</template>
```

Dette rendrer en lokale-veksler med standard styling og oppførsel.

### Egendefinerte etiketter og inline-stiler

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

Dette eksempelet viser en fullt tilpasset lokale-veksler med egendefinerte etiketter og inline-stiler.

## 🔌 Slots

Hver visuelle del av veksleren kan erstattes. Slotene er oppført sammen med props-tabellen over; hver
tar mal-innhold:

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

Slots hvis navn ender på `-item`, `-link-content` eller starter med `before-item`, mottar
`locale`-objektet de tilhører.

## 🎨 Stilsammendrag

`<i18n-switcher>`-komponenten leveres med grunnleggende stiler definert med inline-stiler som enkelt kan overstyres ved å sende egendefinerte stiler via props. Her er en kort oversikt over standardstylingen:

- **Wrapper**: Styrer plasseringen av nedtrekket.
- **Knapp**: Styler nedtrekkets veksleknapp.
- **Nedtrekk**: Styler nedtrekkslisten.
- **Elementer**: Styler hvert element i listen.
- **Lenker**: Styler lenkene inne i hvert element.
- **Ikon**: Styler nedtrekksindikatorikonet.

Du kan tilpasse disse stilene ved å sende egendefinerte stiler gjennom de respektive propene, og sikre at lokale-veksleren integreres sømløst i applikasjonens UI.
