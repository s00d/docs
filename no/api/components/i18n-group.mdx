# 🌍 `<i18n-group>`-komponent

Komponenten `<i18n-group>` i Nuxt I18n Micro gir en praktisk måte å gruppere oversettelser under et felles prefiks. Det reduserer repetisjon og forbedrer kodeorganisering.

## ⚙️ Props

{/* generated:component:i18n-group — do not edit; run `pnpm run docs:generate` */}

| Prop | Type | Standard | Beskrivelse |
| --- | --- | --- | --- |
| `prefix` **\*** | `string` | — | Nøkkelprefikset som hvert oppslag inne i sloten løses mot. |
| `groupClass` | `string` | `''` | Ekstra klasse på wrapper-elementet. |

| Slot | Bindings | Beskrivelse |

## 🎯 Slots

Standard-sloten mottar `prefix` og en `t`-funksjon som er scopet til den, slik at nøkler inne er
skrevet relativt til prefikset:

```vue
<i18n-group prefix="checkout">
  <template #default="{ t }">
    <h2>{{ t('title') }}</h2>
    <p>{{ t('summary', { count: 3 }) }}</p>
  </template>
</i18n-group>
```

## 🛠️ Eksempelbruk

### Grunnleggende bruk

```vue
<template>
  <i18n-group prefix="product.details">
    <template #default="{ t }">
      <h1>{{ t('title') }}</h1>
      <p>{{ t('description') }}</p>
      <div class="price">{{ t('price', { value: 99.99 }) }}</div>
    </template>
  </i18n-group>
</template>
```

Oversettelsesfil:

```json
{
  "product": {
    "details": {
      "title": "Premium Product",
      "description": "This is a premium product",
      "price": "Price: ${value}"
    }
  }
}
```

### Med egendefinert klasse

```vue
<template>
  <i18n-group prefix="user.profile" group-class="profile-section">
    <template #default="{ t }">
      <div class="user-info">
        <h2>{{ t('title') }}</h2>
        <p>{{ t('bio') }}</p>
        <div class="stats">
          <span>{{ t('stats.followers') }}</span>
          <span>{{ t('stats.following') }}</span>
        </div>
      </div>
    </template>
  </i18n-group>
</template>
```

Oversettelsesfil:

```json
{
  "user": {
    "profile": {
      "title": "User Profile",
      "bio": "User biography goes here",
      "stats": {
        "followers": "Followers: {count}",
        "following": "Following: {count}"
      }
    }
  }
}
```

### Med dynamisk innhold

```vue
<template>
  <i18n-group prefix="blog.post">
    <template #default="{ t }">
      <article>
        <h1>{{ t('title') }}</h1>
        <div class="meta">
          {{ t('meta.author', { name: author }) }} |
          {{ t('meta.date', { date: publishDate }) }}
        </div>
        <div v-for="(section, index) in sections" :key="index">
          <h2>{{ t(`sections.${index}.title`) }}</h2>
          <p>{{ t(`sections.${index}.content`) }}</p>
        </div>
      </article>
    </template>
  </i18n-group>
</template>

<script setup>
const author = 'John Doe'
const publishDate = '2024-01-01'
const sections = ['intro', 'main', 'conclusion']
</script>
```

## 🎨 Styling

Komponenten pakker innholdet i en div med klassen `i18n-group` og eventuelle tilleggsklasser som angis i `groupClass`-propen:

```css
.i18n-group {
  /* Your base styles */
}

.profile-section {
  /* Additional styles for profile sections */
}
```

## 🚀 Beste praksis

1. **Konsistente prefikser**: Bruk konsistente og logiske prefikser som gjenspeiler applikasjonens struktur

```vue
<i18n-group prefix="features.pricing">
<i18n-group prefix="features.security">
```

2. **Modulær organisering**: Grupper relaterte oversettelser under meningsfulle prefikser

```vue
<i18n-group prefix="checkout.payment">
<i18n-group prefix="checkout.shipping">
```

3. **Gjenbrukbare komponenter**: Lag gjenbrukbare komponenter med egne oversettelsesgrupper

```vue
<!-- UserProfile.vue -->
<i18n-group prefix="user.profile">

<!-- UserSettings.vue -->
<i18n-group prefix="user.settings">
```

4. **Nøstede grupper**: Unngå å nøste grupper for dypt for å bevare klarhet

```vue
<!-- Good -->
<i18n-group prefix="shop.product">

<!-- Avoid -->
<i18n-group prefix="shop.category.product.details.specs">
```
