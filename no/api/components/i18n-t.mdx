# 🌍 `<i18n-t>`-komponent

Komponenten `<i18n-t>` i `Nuxt I18n Micro` er en fleksibel oversettelseskomponent som støtter dynamisk innholdsinjeksjon via slots. Den lar deg interpolere oversettelser med egendefinerte Vue-komponenter eller HTML-innhold, og muliggjør avanserte lokaliseringsscenarier.

**\*** påkrevd.

{/* /generated:component:i18n-t */}

Bare én av `plural`, `number`, `date` og `relativeDate` gjelder om gangen; når flere
er satt, vinner den første i den listen.

### Eksempler per prop

```vue
<!-- keypath: the translation to render -->
<i18n-t keypath="feedback.text" />

<!-- plural: selects the plural form -->
<i18n-t keypath="items" :plural="10" />

<!-- params: interpolated into the translation -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: the element to render -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: formatted, then interpolated -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty with a fallback -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

## 🛠️ Eksempelbruk

### Grunnleggende bruk

```vue
<i18n-t keypath="feedback.text" />
```

Dette rendrer oversettelsen for `feedback.text` inne i en `<span>`-tagg.

### Bruke slots for dynamisk innhold

`<i18n-t>`-komponenten støtter bruk av slots for å dynamisk sette inn Vue-komponenter eller annet innhold i bestemte deler av oversettelsen.

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

I dette eksempelet erstattes `\{link\}`-plassholderen i oversettelsesstrengen `feedback.text` av `<nuxt-link>`-komponenten, som selv inneholder en annen oversettelseskomponent.

### Flertallsbøying

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

Dette anvender automatisk flertallsregler basert på `itemCount`-verdien.

## 🚀 Tilleggsfunksjoner

### Standard-slot

Hvis ingen spesifikk slot oppgis, kan oversettelsen tilpasses via standard-sloten, som gir hele den oversatte strengen:

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### Betinget rendering

Render ingenting hvis oversettelsesstrengen er tom, ved å bruke `hideIfEmpty`-propen.

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### Egendefinert flertallsregel

Bruk en egendefinert funksjon for å håndtere flertallsbøying.

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### Avansert eksempel med slots

Bruk slots for å tilpasse hvordan oversettelsesinnholdet rendres.

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
