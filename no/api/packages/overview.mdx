# Pakke-API-er

`nuxt-i18n-micro` er bygget opp av et sett med små pakker, hvorav de fleste kan brukes
alene — `@i18n-micro/vue` i en vanlig Vue-app, `@i18n-micro/core` hvor som helst.

Hver side under er generert fra API-snapshotet som
[`pnpm run api:surface`](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/maintenance-commands.md#api-surface) sjekker mot
TypeScript-kildene, slik at en eksport ikke kan forsvinne uten at enten denne referansen endres
eller CI feiler.
