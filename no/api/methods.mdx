title: "Hjelpefunksjoner"

---

Modulen injiserer sine kjøretidshjelpefunksjoner i Nuxt-appen: `$t`, `$tc`, `$localePath`, `$switchLocale` og resten. Bruk denne siden til å slå opp signaturen og oppførselen til en hjelpefunksjon. Signaturer og beskrivelser kommer fra grensesnittene `PluginsInjections` og `NuxtAppOnlyInjections` i `src/runtime/plugins/01.plugin.ts`.

## Tilgang {#access}

| Hvor | Hvordan |
| --- | --- |
| Mal | `{{ $t('title') }}` — alle hjelpefunksjoner, med `$` |
| `<script setup>` | `const { t, localePath } = useI18n()` — alle hjelpefunksjoner i `PluginsInjections`, med og uten `$` |
| Plugin, middleware, `<script setup>` | `const { $t, $defineI18nRoute } = useNuxtApp()` — alt, bare med `$` |

`$defineI18nRoute` er bare typet på `useNuxtApp()`. Se [`useI18n`](/no/composables/useI18n).

```vue
<script setup lang="ts">
const { t, localePath } = useI18n()
</script>

<template>
  <NuxtLink :to="localePath('/about')">{{ t('nav.about') }}</NuxtLink>
</template>
```

## Språk {#locale}

### `$getLocale` {#$getlocale}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric) => string
```

Koden til det aktive språket. Send inn en rute for å lese språket som ruten tilhører.

```ts
$getLocale() // 'de' on /de/about
```

### `$getLocaleName` {#$getlocalename}

```ts
() => string | null
```

Det aktive språkets `displayName` fra konfigurasjonen, eller `null` når det ikke har noe.

### `$getLocales` {#$getlocales}

```ts
() => Locale[]
```

Alle konfigurerte språk, med metadata.

Egendefinerte egenskaper på et språkobjekt returneres som de er skrevet; typ dem med [modulutvidelse](/no/api/module-options#locales) av `Locale`.

### `$defaultLocale` {#$defaultlocale}

```ts
() => string | undefined
```

Koden til det konfigurerte standardspråket.

### `$getI18nConfig` {#$geti18nconfig}

```ts
() => ResolvedI18nConfig
```

Den oppløste modulkonfigurasjonen, slik kjøretiden ser den.

Verdien inkluderer [kjøretidsoverstyringer](/no/guide/runtime-overrides) (`defaultLocale`, `fallbackLocale`, deaktiverte språk).

```ts
const { strategy, localeCookie } = useNuxtApp().$getI18nConfig()
```

## Oversettelse {#translation}

### `$t` {#$t}

```ts
TranslationFn<CleanTranslation>
```

Oversett en nøkkel og interpoler `params` inn i den. Returnerer `defaultValue` når nøkkelen
mangler, eller selve nøkkelen når ingen standardverdi er gitt.

```ts
// { "welcome": "Welcome, {name}!" }
$t('welcome', { name: 'Ada' }) // 'Welcome, Ada!'
$t('missing.key', {}, 'Fallback') // 'Fallback'
```

En nøkkel som peker på et nestet objekt, returnerer det objektet, ikke en streng. I en mal gjengis det som `[object Object]`; bruk en bladnøkkel.

### `$ts` {#$ts}

```ts
TranslationFn<string>
```

Som `$t`, men returnerer alltid en streng: verdien går gjennom `toString()`, så et nestet
objekt blir `'[object Object]'`. La nøkkelen peke på et blad.

### `$_t` {#$_t}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<CleanTranslation>
```

Bind `$t` til en bestemt rute, for å oversette utenfor gjeldende side — for eksempel en layout som gjengir
en lenke til en annen rute.

```ts
const route = useRoute()
const t = useNuxtApp().$_t(route)
t('page.title')
```

### `$_ts` {#$_ts}

```ts
(route: RouteLocationNormalizedLoaded) => TranslationFn<string>
```

Bind `$ts` til en bestemt rute. Se `$_t`.

### `$tc` {#$tc}

```ts
(key: TranslationKey, params: number | Params, defaultValue?: string) => string
```

Oversett med flertallsbøying. `params` kan være selve antallet, eller et objekt som inneholder
`count`.

Formene skilles med `|`. Med den innebygde regelen velger et ikke-negativt heltallsantall `n` form `n`, begrenset til den siste formen; et negativt antall, et desimalantall eller `NaN` tar den siste formen. `{count}` og de andre parameterne interpoleres inn i den valgte formen.

For språk der flertall ikke følger antallet, start malen med `=0 `. Den første formen er da for 0, og de andre styres etter kategorien fra [`Intl.PluralRules`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/PluralRules), i rekkefølgen `zero, one, two, few, many, other`:

```json
{
  "apples": "=0 no apples | one apple | {count} apples",
  "files": "=0 no files | {count} one | {count} few | {count} many"
}
```

```ts
$tc('apples', 0) // 'no apples'
$tc('apples', 1) // 'one apple'
$tc('apples', 7) // '7 apples'

// In `uk` (categories `one, few, many, other`) the forms after the zero form follow those categories:
$tc('files', 21) // '21 one'
$tc('files', 22) // '22 few'
$tc('files', 25) // '25 many'
$tc('files', 2.5) // '2.5 many': no form for `other`, so the last one
```

- `=0 ` teller bare helt i starten av verdien, med mellomrommet. `$t` viser den som tekst: den hører til flertall.
- En kategori uten egen form tar den siste formen. Et negativt antall eller et desimalantall tar også den siste formen.
- Det fungerer på alle språk: `=0 none | one | {count} many` på engelsk.
- Kategorien kommer fra språkets `iso`, ellers koden. En kode som `Intl` ikke kjenner, faller tilbake til indeksregelen, med markøren fortsatt fjernet, så resultatet aldri avhenger av maskinen.
- `<i18n-t :plural>` følger samme regel. En egendefinert [`plural`](/no/api/module-options#plural) eller `customPluralRule` får den rå verdien, markøren inkludert, og avgjør selv; når `plural` returnerer `null`, overlates kallet til den innebygde regelen, som respekterer markøren.

Uten markøren forblir en mal på indeksregelen, med ett unntak som bare kan leses på én måte: en nullform uten plassholder, deretter én form per kategori, med `{count}` i hver form som flere antall deler (`no files | {count} one | {count} few | {count} many` på `uk`).

For egne regler setter du [`plural`](/no/api/module-options#plural).

```ts
// { "apples": "no apples | one apple | {count} apples" }
$tc('apples', 0) // 'no apples'
$tc('apples', 10) // '10 apples'
$tc('cart', { count: 2, name: 'Ada' }) // count and params in one object
```

Det tredje argumentet er `defaultValue`, ikke params.

### `$has` {#$has}

```ts
(key: string) => boolean
```

Om en nøkkel løses opp i det aktive språket. Bruk den til å forgrene på valgfri tekst i stedet for
å gjengi en rå nøkkel. I likhet med `$t` ser den også nøklene til siden som forlates under en
sideovergang på samme språk.

```ts
if ($has('promo.banner')) show.value = true
```

## Formatering {#formatting}

### `$tn` {#$tn}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Formater et tall med `Intl.NumberFormat` på det aktive språket. En nøkkel velger et navngitt format
fra konfigurasjonen.

Navngitte formater kommer fra [`numberFormats`](/no/api/module-options#numberformats).

```ts
$tn(1234.5, { style: 'currency', currency: 'EUR' }) // '1.234,50 €' in de
$tn(1000, 'currency') // named format
$tn(1000, 'currency', 'de') // named format in another locale
```

### `$td` {#$td}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Formater en dato med `Intl.DateTimeFormat` på det aktive språket. En nøkkel velger et navngitt format
fra konfigurasjonen.

Navngitte formater kommer fra [`datetimeFormats`](/no/api/module-options#datetimeformats).

```ts
$td(new Date(), { dateStyle: 'long' })
$td(post.createdAt, 'short')
```

### `$tdr` {#$tdr}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

Formater en dato som relativ tid ("for 3 dager siden") med `Intl.RelativeTimeFormat`.

```ts
$tdr(Date.now() - 5 * 60_000) // '5 minutes ago' in en
```

## Bytte og lenker {#switching-and-links}

### `$switchLocale` {#$switchlocale}

```ts
(locale: string) => Promise<boolean>
```

Naviger til gjeldende side på et annet språk. Under `no_prefix` og hash-modus laster den
språkets oversettelser før navigering; under `no_prefix` erstattes ruten på stedet (ingen
ny historikkoppføring). Et ukjent språk ignoreres.
Kallet er asynkront: bruk `await` for å kjøre kode etter navigeringen. Det løses til `true` når
språkets ordbok er aktiv, `false` når den ikke er det: chunken kunne ikke lastes (gjeldende
ordbok beholdes; kall den igjen for å prøve på nytt) eller et nyere bytte vant.

```ts
await $switchLocale('de')
```

### `$switchLocalePath` {#$switchlocalepath}

```ts
(locale: string) => string
```

Stien til gjeldende side på et annet språk, uten å navigere.

```vue
<NuxtLink :to="$switchLocalePath('de')">Deutsch</NuxtLink>
```

### `$switchLocaleRoute` {#$switchlocaleroute}

```ts
(locale: string) => RouteLocationRaw
```

Ruteobjektet for gjeldende side på et annet språk, uten å navigere, eller en URL-streng
for et språk på sin egen `baseUrl`. Under `trailingSlash` har objektet `path` og `fullPath`
i henhold til regelen, med `query` og `hash` som de er, og `router.push` eller en lenke beholder dem.

### `$switchRoute` {#$switchroute}

```ts
(route: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, toLocale?: string) => Promise<void>
```

Naviger til en annen rute, og behold det aktive språket eller bytt til `toLocale`. Asynkron i likhet med
`$switchLocale`.

```ts
$switchRoute('/about') // active locale
$switchRoute({ name: 'about' }, 'de') // switch to de
```

### `$localePath` {#$localepath}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => string
```

Løs opp en sti på det angitte språket, eller det aktive. En streng med skjemaet `http(s):`, `mailto:`
eller `tel:` returneres uendret: ikke send brukerinput som lenkemål uten å kontrollere det.

En strengsti leses som siden den viser, så et språks egendefinerte sti brukes også.

```ts
$localePath('/about') // '/about' in en, '/de/ueber-uns' in de with localeRoutes
$localePath({ name: 'about' }, 'fr') // '/fr/about'
```

### `$localeRoute` {#$localeroute}

```ts
(to: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, locale?: string) => RouteLocationResolved
```

Løs opp en rute på det angitte språket, eller det aktive. Et vanlig objekt, trygt å ha i tilstand. Når en parameter må
escapes, har det `path`, `fullPath`, `query` og `hash`, men ikke `name` eller `params`: det er stien som gir ruteren
den kodede URL-en. For et språk på et annet domene er `path` og `fullPath` absolutte, noe ruteren ikke kan ta imot:
en slik lenke går via `<i18n-link>` eller `$localePath`.

### `$getRouteName` {#$getroutename}

```ts
(route?: RouteLocationNormalizedLoaded | RouteLocationResolvedGeneric, locale?: string) => string
```

Rutenavn uten språkprefiks — navnet oversettelsene er knyttet til.

```ts
$getRouteName() // 'about' on /de/about
```

## Sidekonfigurasjon {#page-config}

### `$defineI18nRoute` {#$definei18nroute}

```ts
(routeDefinition: DefineI18nRouteConfig) => Promise<void>
```

Registrer språkkonfigurasjon og oversettelser per side fra innsiden av en komponent.
Slås sammen inn i det aktive språket og brukes på nytt når språket endres.

Kall den i en sides `<script setup>`, alltid destrukturert fra `useNuxtApp()`. Bygget leser `locales`, `localeRoutes` og `disableMeta` fra kallet; ved kjøretid er det bare `locales` som teller (inline oversettelser slås sammen for det aktive språket). Fullstendige regler: [Sidekonfigurasjon](/no/guide/per-component-translations).

```vue
<script setup lang="ts">
const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'de'],
  localeRoutes: { en: '/about', de: '/ueber-uns' },
})
</script>
```

### `$setI18nRouteParams` {#$seti18nrouteparams}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Sett parametere per språk for gjeldende rute, slik at et dynamisk segment kan variere per språk.
Kall den under SSR, før head gjengis.

Parameterne tømmes når en navigering til en annen sti fullføres, inkludert `/news/1` til `/news/4`, som beholder rutenavnet. Detaljer: [Lokaliserte stier](/no/guide/custom-locale-routes).

```ts
$setI18nRouteParams({
  en: { slug: 'my-post' },
  de: { slug: 'mein-beitrag' },
})
```

## Kjøretidsoversettelser {#runtime-translations}

### `$mergeTranslations` {#$mergetranslations}

```ts
(newTranslations: Translations) => void
```

Slå sammen oversettelser inn i det aktive språket ved kjøretid, og overstyr det som er lastet.

Slår dypt sammen inn i det aktive språkets gjeldende side-chunk; nøkler den ikke nevner, beholdes.

```ts
$mergeTranslations({ banner: { title: 'Sale' } })
```

### `$setTranslation` {#$settranslation}

```ts
(key: string, value: unknown) => void
```

Erstatt verdien ved `key` i den aktive ordboken. Dette er en erstatning, ikke en sammenslåing —
bruk `$mergeTranslations` når eksisterende søsken skal beholdes.

```ts
$setTranslation('banner', { title: 'Sale' }) // drops other keys under banner
$setTranslation('banner.title', 'Sale') // dotted path
```

### `$loadPageTranslations` {#$loadpagetranslations}

```ts
(locale: string, routeName: string, translations: Translations) => Promise<void>
```

Last inn oversettelser for en side ved kjøretid, for innhold der nøklene ikke er kjent ved byggetid.

Slår sammen inn i `(locale, routeName)`-chunken i minnet, og skjermen oppdateres når den chunken er aktiv. Ingen payload hentes her: for en side som ikke er lastet ennå, venter oversettelsene, og når filen dens lastes, forblir de oppå den.

```ts
await $loadPageTranslations('en', 'about', { title: 'About us' })
```

### `$resolveTranslations` {#$resolvetranslations}

```ts
() => Translations
```

Alle oversettelser som for øyeblikket er i minnet for det aktive språket og ruten, som et tre.
Skrivebeskyttet visning av hva `$t()` kan løse opp akkurat nå.

Behandle resultatet som skrivebeskyttet.

### `$setMissingHandler` {#$setmissinghandler}

```ts
(handler: MissingHandler | null) => void
```

Installer en callback som kalles for hver nøkkel som ikke løses opp. Send `null` for å fjerne den.

Håndtereren kjører i stedet for utviklingsadvarselen.

```ts
$setMissingHandler((locale, key, routeName) => {
  console.error(`[i18n] missing ${key} in ${locale} (${routeName})`)
})
```

### `$clearCache` {#$clearcache}

```ts
() => void
```

Forkast alle hurtigbufrede oversettelses-chunks og last inn ordboken for gjeldende side på nytt. Siden
fortsetter å vise sine gjeldende oversettelser til de nye kommer. Dev-HMR kaller den ved
hver endring i en oversettelsesfil.

```ts
const { clearCache } = useI18n()
clearCache()
```

En mislykket ny innlasting beholder gjeldende ordbok.
