# 🛠️ Metoder

Denne siden dokumenterer alle tilgjengelige metoder som `nuxt-i18n-micro` tilbyr. Metodene er organisert etter funksjonalitet for enklere navigasjon.

## 📊 API-oversikt

Alle hjelpere pluginen injiserer, lest fra `PluginsInjections`-grensesnittet, slik at denne
listen ikke kan avvike fra hva som faktisk er tilgjengelig.

### `$getI18nConfig`

{/* generated:method:$getI18nConfig — do not edit; run `pnpm run docs:generate` */}

```ts
() => ModuleOptionsExtend
```

Den løste modulkonfigurasjonen, slik runtime ser den.

{/* /generated:method:$getI18nConfig */}

```typescript
const nuxtApp = useNuxtApp()
const { localeCookie, strategy, hooks } = nuxtApp.$getI18nConfig()
```

For byggetids- eller ikke-Nuxt-kontekster, bruk `getI18nConfig()` fra `#build/i18n.strategy.mjs` i stedet.

<Info>
`serverTranslationPreload` er et privat modulalternativ eksponert bare i server-privat konfigurasjon (`#i18n-internal/config`). Det er ikke del av den offentlige runtime-API-en og kan endres uten forvarsel.
</Info>

## 🔍 Oversettelsesmetoder

Kjernemetoder for henting og håndtering av oversettelser.

### `$t`

{/* generated:method:$t — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Oversett en nøkkel og interpoler `params` inn i den. Returnerer `defaultValue` når nøkkelen
mangler, eller selve nøkkelen når ingen standard er gitt.

{/* /generated:method:$t */}

```typescript
const welcomeMessage = $t('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

<Warning>
`$t` returnerer `CleanTranslation`, som er `string | number | boolean | Translations | PluralTranslations | null`. Hvis nøkkelen peker på et **nøstet objekt** i JSON-en din (f.eks. `$t('header')` når JSON-en inneholder `\{ "header": \{ "title": "Hi" \} \}`), vil returverdien være det **objektet**, ikke en streng. Å bruke det direkte i en Vue-mal (<code v-pre>\{\{ $t('header') \}\}</code>) vil rendres som `[object Object]`.

**Slik unngår du dette:**

- Bruk en mer spesifikk nøkkel: `$t('header.title')` → `"Hi"`
- Bruk `$ts()` som alltid returnerer en streng (kaller `.toString()` på ikke-strenger)
- Bruk `$t` med en nøstet nøkkel når du bevisst ønsker å hente underobjekter for programmatisk bruk
</Warning>

### `$ts`

{/* generated:method:$ts — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params?: Params, defaultValue?: string) => string
```

Som `$t`, men returnerer alltid en streng: en objekt- eller array-verdi konverteres til streng i stedet for å returneres som den er.

{/* /generated:method:$ts */}

```typescript
const welcomeMessage = $ts('welcome', { username: 'Alice', unreadCount: 5 })
// Output: "Welcome, Alice! You have 5 unread messages."
```

### `$_t` og `$_ts`

{/* generated:method:$_t — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => CleanTranslation
```

Bind `$t` til en spesifikk rute for å oversette utenfor gjeldende side, for eksempel et layout som viser
en lenke til en annen rute.

{/* /generated:method:$_t */}

{/* generated:method:$_ts — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNormalizedLoaded) => (key: string, params?: Params, defaultValue?: string | null) => string
```

Bind `$ts` til en spesifikk rute. Se `$_t`.

{/* /generated:method:$_ts */}

Rute-bundne varianter av `$t` og `$ts`. De tar en **rute** først og returnerer en oversettelsesfunksjon låst til den rutens lokale- og sidekontekst.

- **Tilgang**: `useNuxtApp()` (også re-eksportert av `useI18n()` som `$_t` / `$_ts`)

Bruk disse når den aktive ruten under SSR eller overganger avviker fra `router.currentRoute`, for eksempel inne i `<i18n-t>`, `<i18n-group>`, eller når du rendrer innhold for et spesifikt `route`-objekt.

```typescript
import { useRoute, useNuxtApp } from '#imports'

const route = useRoute()
const { $_t, $_ts } = useNuxtApp()

const $t = $_t(route)
const title = $t('page.title')

// String-safe variant
const label = $_ts(route)('page.label')
```


### `$tc`

{/* generated:method:$tc — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, params: number | Params, defaultValue?: string) => string
```

Oversett med flertallsbøying. `params` kan være selve antallet, eller et objekt som inneholder
`count`.

{/* /generated:method:$tc */}

**Oversettelsesformat**: former separert med `|`. Plasser plassholdere i **hver** form:

```json
{
  "apples": "no apples | one apple | {count} apples",
  "cart": "no items for {name} | one item for {name} | {count} items for {name}"
}
```

```typescript
$tc('apples', 0) // "no apples"
$tc('apples', 1) // "one apple"
$tc('apples', 10) // "10 apples"

// count + other params (second argument must be an object)
$tc('cart', { count: 10, name: 'Alice' }) // "10 items for Alice"
```


**Komponentalternativ** — `<i18n-t keypath="cart" :plural="count" :params="\{ name \}" />` (fletter `count` med `params` internt).


### `$mergeTranslations`

{/* generated:method:$mergeTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
(newTranslations: Translations) => void
```

Flett oversettelser inn i den aktive lokalen i kjøretid, og overstyr det som er lastet.

{/* /generated:method:$mergeTranslations */}

```typescript
$mergeTranslations({
  welcome: 'Bienvenue, {username}!',
})
// Output: Updates the translation cache with the new French translation
```

### `$resolveTranslations`

{/* generated:method:$resolveTranslations — do not edit; run `pnpm run docs:generate` */}

```ts
() => Translations
```

Alle oversettelser som per nå finnes i minnet for aktiv lokale og rute, som et tre.
Skrivebeskyttet visning av det `$t()` kan løse akkurat nå.

{/* /generated:method:$resolveTranslations */}

```typescript
const tree = $resolveTranslations()
// { aaa: { bbb: 'ccc' }, ddd: 1111 } — the same dictionary $t() reads from
```

Bruk denne når du trenger hele in-memory-ordboken (DevTools, tester, runtime-redigerere). Behandle returverdien som skrivebeskyttet; endre verdier gjennom `$setTranslation` eller flett patcher med `$mergeTranslations`.

### `$setTranslation`

{/* generated:method:$setTranslation — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string, value: unknown) => void
```

Erstatt verdien ved `key` i den aktive ordboken. Dette er en erstatning, ikke en fletting.
Bruk `$mergeTranslations` når eksisterende søsken skal beholdes.

{/* /generated:method:$setTranslation */}

```typescript
$setTranslation('aaa', { fff: 'ggg' }) // replaces the whole `aaa` subtree
$setTranslation('aaa', 'text')          // replaces `aaa` with a string
$setTranslation('ddd', 1111)            // scalar at the top level
$setTranslation('aaa.bbb', 'nested')    // dotted path
```

Dette er en **erstatning**, ikke en fletting. Eksisterende søsken under samme nøkkel fjernes. For å oppdatere uten å miste søsken, bruk `$mergeTranslations`.

### `$setMissingHandler`

{/* generated:method:$setMissingHandler — do not edit; run `pnpm run docs:generate` */}

```ts
(handler: MissingHandler | null) => void
```

Installer en callback som kalles for hver uløste nøkkel. Send `null` for å fjerne den.

{/* /generated:method:$setMissingHandler */}

**Typedefinisjon**:

```typescript
type MissingHandler = (locale: string, key: string, routeName: string, instance?: unknown, type?: string) => void
```

```typescript
// Set a custom handler
$setMissingHandler((locale, key, routeName) => {
  console.error(`Missing translation: ${key} in ${locale} for route ${routeName}`)
  // Send to Sentry or other error tracking service
  // Sentry.captureMessage(`Missing translation: ${key}`)
})

// Remove the handler
$setMissingHandler(null)
```

**Brukstilfeller**:

- Logge manglende oversettelser til feilsporingstjenester (Sentry, LogRocket osv.)
- Samle analyse av manglende oversettelser
- Egendefinert feilhåndtering for manglende oversettelsesnøkler

## 🔢 Tall- og datoformatering

Metoder for å formatere tall og datoer etter lokale-konvensjoner.

### `$tn`

{/* generated:method:$tn — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: number, options?: Intl.NumberFormatOptions): string (value: number, key: string, overrides?: Intl.NumberFormatOptions): string (value: number, key: string, locale: string, overrides?: Intl.NumberFormatOptions): string }
```

Formater et tall med `Intl.NumberFormat` i aktiv lokale. En nøkkel velger et navngitt format
fra konfigurasjonen.

{/* /generated:method:$tn */}

```typescript
// Inline options
const formattedNumber = $tn(1234567.89, { style: 'currency', currency: 'USD' })
// "$1,234,567.89"

// Named format (from nuxt.config i18n.numberFormats)
const price = $tn(1000, 'currency')
const priceDe = $tn(1000, 'currency', 'de')
const compact = $tn(1000, 'currency', { notation: 'compact' })
```

Ukjente navngitte format-nøkler faller tilbake til standard `Intl.NumberFormat`-alternativer. I utvikling (klient) sendes et `console.warn` når `missingWarn` er aktivert (standard).

**Konfigurasjonseksempel**:

```ts
export default defineNuxtConfig({
  i18n: {
    numberFormats: {
      en: {
        currency: { style: 'currency', currency: 'USD' },
        decimal: { style: 'decimal', minimumFractionDigits: 2, maximumFractionDigits: 2 },
      },
      de: {
        currency: { style: 'currency', currency: 'EUR' },
      },
    },
  },
})
```

**Brukstilfeller**:

- Formatere tall som valuta, prosent eller desimaltall i riktig lokaleformat
- Gjenbruke navngitte formater på tvers av appen (paritet med Vue I18n-migrering)

### `$td`

{/* generated:method:$td — do not edit; run `pnpm run docs:generate` */}

```ts
{ (value: Date | number | string, options?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, overrides?: Intl.DateTimeFormatOptions): string (value: Date | number | string, key: string, locale: string, overrides?: Intl.DateTimeFormatOptions): string }
```

Formater en dato med `Intl.DateTimeFormat` i aktiv lokale. En nøkkel velger et navngitt format
fra konfigurasjonen.

{/* /generated:method:$td */}

```typescript
const formattedDate = $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' })
// "Friday, September 1, 2023"

const short = $td(new Date(), 'short')
const longDe = $td(new Date(), 'long', 'de')
```

Ukjente navngitte format-nøkler faller tilbake til standard `Intl.DateTimeFormat`-alternativer. I utvikling (klient) sendes et `console.warn` når `missingWarn` er aktivert (standard).

**Konfigurasjonseksempel**:

```ts
export default defineNuxtConfig({
  i18n: {
    datetimeFormats: {
      en: {
        short: { year: 'numeric', month: 'short', day: 'numeric' },
        long: { year: 'numeric', month: 'long', day: 'numeric', weekday: 'long' },
      },
    },
  },
})
```

**Brukstilfeller**:

- Vise datoer i et format som samsvarer med brukerens lokale
- Dele korte/lange/dato-tids-presets på tvers av appen

### `$tdr`

{/* generated:method:$tdr — do not edit; run `pnpm run docs:generate` */}

```ts
(value: Date | number | string, options?: Intl.RelativeTimeFormatOptions) => string
```

Formater en dato som relativ tid ("3 dager siden") med `Intl.RelativeTimeFormat`.


{/* /generated:method:$switchLocale */}

### `$switchRoute`

{/* generated:method:$switchRoute — do not edit; run `pnpm run docs:generate` */}

```ts
(route: RouteLocationNamedRaw | RouteLocationResolvedGeneric | string, toLocale?: string) => void
```

Naviger til en annen rute og behold aktiv lokale, eller bytt til `toLocale`.

{/* /generated:method:$switchRoute */}

**Eksempler**:

<CodeGroup>
```typescript String Path
// Switches to the given path with the current locale

```

```typescript String Path with Locale

$switchRoute('/about', 'fr')
```

```typescript Named Route
// Switches to a named route with the current locale
$switchRoute({ name: 'page' })
```

```typescript Named Route with Locale
// Switches to a named route and changes the locale to Spanish
$switchRoute({ name: 'page' }, 'es')
```
</CodeGroup>

> [!IMPORTANT]
> `$defineI18nRoute` leveres av **define-pluginen** og er kun tilgjengelig via `useNuxtApp()` — den er **ikke** en del av `useI18n()`-returobjektet.
> Destrukturer den alltid fra `useNuxtApp()` inne i `script setup`. Å kalle `$defineI18nRoute(...)` som en bar global gir `"$defineI18nRoute is not defined"` under SSR/prerender.

**Parametere**:

- **locales**: `string[] | Record<string, Record<string, string>>` — Tilgjengelige lokaler for ruten
- **localeRoutes**: `Record<string, string>` — Valgfri. Egendefinerte ruter for bestemte lokaler
- **disableMeta**: `boolean | string[]` — Valgfri. Deaktiverer i18n-metatagger for alle eller bestemte lokaler

**Grunnleggende eksempel**:

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr', 'de'],
  localeRoutes: {
    en: '/welcome',
    fr: '/bienvenue',
    de: '/willkommen',
  },
  disableMeta: false,
})
```

> 📖 **For detaljerte brukseksempler, konfigurasjonsformater og beste praksis, se [guiden for oversettelser per komponent](/guides/per-component-translations).**

### `$setI18nRouteParams`

{/* generated:method:$setI18nRouteParams — do not edit; run `pnpm run docs:generate` */}

```ts
(value: I18nRouteParams) => I18nRouteParams
```

Sett per-lokale-parametere for gjeldende rute, slik at et dynamisk segment kan skille seg per språk.
Kall den under SSR, før head rendres.

{/* /generated:method:$setI18nRouteParams */}

```typescript
// in pages/news/[id].vue
// for en/news/1-first-article
const { $switchLocaleRoute, $setI18nRouteParams, $defineI18nRoute } = useNuxtApp()
$defineI18nRoute({
  localeRoutes: {
    en: '/news/:id()',
    fr: '/nouvelles/:id()',
    de: '/Nachricht/:id()',
  },
})
const { data: news } = await useAsyncData(`news-${params.id}`, async () => {
  let response = await $fetch("/api/getNews", {
    query: {
      id: params.id,
    },
  });
  if (response?.localeSlugs) {
    response.localeSlugs = {
      en: {
        id: '1-first-article'
      }
      fr: {
        id: '1-premier-article'
      }
      de: {
        id: '1-erster-Artikel'
      }
    }
    $setI18nRouteParams(response?.localeSlugs);
  }
  return response;
});
$switchLocalePath('fr') // === 'fr/nouvelles/1-premier-article'
$switchLocalePath('de') // === 'de/Nachricht/1-erster-Artikel'
```

## 🔧 Cache- og hjelpe-metoder

### `$has`

{/* generated:method:$has — do not edit; run `pnpm run docs:generate` */}

```ts
(key: string) => boolean
```

Om en nøkkel lar seg løse i aktiv lokale. Bruk den til å forgrene på valgfri tekst i stedet for å
rendre en rå nøkkel.

{/* /generated:method:$has */}

Under sideoverganger innenfor samme lokale, dyp-fletter v3 automatisk oversettelser fra siden du forlater inn i denne ordboken til overgangen er fullført — så nøkler fra forrige side kan fortsatt returnere `true` en kort stund. Det finnes ingen `previousPageFallback`-opsjon; denne atferden er innebygd. Se [FAQ — sideoverganger](/guides/faq#-why-do-translations-break-during-page-transitions-especially-with-defineasynccomponent).

```typescript
if ($has('welcome')) {
  console.log($t('welcome'))
} else {
  console.log('Key not found')
}
```

### `$clearCache`

{/* generated:method:$clearCache — do not edit; run `pnpm run docs:generate` */}

```ts
() => void
```

Slipp hver cachet chunk, på klienten og i den aktive ordboken.

{/* /generated:method:$clearCache */}

**Tilgang**: `useNuxtApp().$clearCache`. Deklarert i `NuxtAppOnlyInjections` i stedet for `PluginsInjections`, så den er typet, men bevisst fraværende fra `useI18n()`-hjelpe-objektet:

```typescript
const { $clearCache } = useNuxtApp()
// All cached translations are removed; next render will re-fetch them
$clearCache()
```

## 🧭 `useI18nLocale`-composable

Den sentraliserte composablen for lokale-tilstandshåndtering. Bruk denne i stedet for å manipulere `useState('i18n-locale')` eller `useCookie('user-locale')` direkte.

```typescript
const {
  setLocale, // (locale: string) => void — updates state + cookie
  getLocale, // () => string | null — from state or cookie
  getPreferredLocale, // () => string | null — validated against locales list
  getEffectiveLocale, // (route, getLocaleFromRoute) => string
  resolveInitialLocale, // (options) => string
  isValidLocale, // (locale) => boolean
  locale, // Ref<string | null> — reactive state
  localeCookie, // CookieRef — reactive cookie
  syncLocale, // (locale) => void — sync to cookie only
  validLocales, // string[] — list of valid locale codes
} = useI18nLocale()
```

### Nøkkelmetoder

| Metode                  | Beskrivelse                                                   |
| ----------------------- | ------------------------------------------------------------- |
| `setLocale(locale)`     | Setter lokale i både `useState` og cookie atomisk             |
| `getLocale()`           | Returnerer gjeldende lokale fra state eller cookie            |
| `getPreferredLocale()`  | Returnerer lokale validert mot `locales`-listen, eller `null` |
| `isValidLocale(locale)` | Sjekker om en lokale-kode er i den konfigurerte `locales`-listen |

### Bruk i egendefinerte plugins

```typescript
// plugins/i18n-loader.server.ts
export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,
  setup() {
    const { setLocale } = useI18nLocale()
    // Detect locale from headers, domain, etc.
    setLocale('de')
  },
})
```
