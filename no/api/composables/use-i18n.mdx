# 🛠️ `useI18n`-composable

Composablen `useI18n` i `Nuxt I18n Micro` gir tilgang til de fleste runtime-i18n-hjelperne i komponenter og skript. Metodene er tilgjengelige **både med og uten `$`-prefiks** (for eksempel `$t` og `t`).

Noen injeksjoner — `$defineI18nRoute` og `$clearCache` — er kun tilgjengelige via `useNuxtApp()`. Se [Metoder — `$defineI18nRoute`](/api/methods#definei18nroute) og [`$clearCache`](/api/methods#clearcache).

## 📊 Hva den returnerer

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

Alle runtime-hjelpere, som et vanlig objekt.

De samme funksjonene pluginen injiserer som `$t`, `$tc` osv., tilgjengelige både under
det dollar-prefikserte navnet og et bare alias — slik at `const \{ t \} = useI18n()` og
`const \{ $t \} = useI18n()` begge fungerer.

**Returnerer** — hjelperne beskrevet i [metodereferansen](/api/methods)

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

Alle hjelpere den returnerer — `$t`, `$tc`, `$has`, `$switchLocale` og resten — er listet
med signatur og dokumentert i sin helhet på [metodereferansen](/api/methods).

## API-er kun via `useNuxtApp()`

Disse returneres **ikke** av `useI18n()`. Importer dem fra `useNuxtApp()`:

| Metode                     | Formål                                                                          |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | Lokale-ruter, begrensninger og inline-oversettelser per side i `script setup`   |
| `$clearCache()`            | Tømmer in-memory oversettelses-cache og lastede chunker                         |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

Se [Metoder](/api/methods) for fullstendige signaturer og eksempler.

## 🛠️ Eksempelbruk

### Grunnleggende lokale-uthenting

Hent gjeldende lokale for applikasjonen.

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### Oversettelse med parametere

Oversett en streng med dynamiske parametere, med en fallback-standardverdi.

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### Bytte lokaler

Bytt applikasjonen til en annen lokale.

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### Generere en lokalisert rute

Generer en rute lokalisert til gjeldende eller angitt lokale.

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
