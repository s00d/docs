[CLI-veiledningen](/no/guide/cli) viser de vanlige arbeidsflytene. Denne siden lister opp alt, og er generert fra den samme tabellen som driver `--help`.

## Felles flagg {#common-flags}

| Flagg | Standard | Beskrivelse |
| --- | --- | --- |
| `--cwd` | gjeldende katalog | Prosjektkatalog |
| `--logLevel` | `info` | Utdatanivå: silent, info |
| `--debug` | `false` | Skriv ut en stakksporing når en kommando feiler |

## Inspiser {#inspect}

### `info` {#info}

Skriv ut den oppløste i18n-konfigurasjonen for prosjektet

| Flagg | Standard | Beskrivelse |
| --- | --- | --- |
| `--json` | `false` | Skriv ut JSON i stedet for tekst |

### `check` {#check}

CI-porten: feiler ved manglende, tomme, ekstra, udefinerte eller ubrukte nøkler og ødelagte plassholdere

| Flagg | Standard | Beskrivelse |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` fra nuxt.config | Oversettelseskatalog, relativt til prosjektet |
| `--only` | alle unntatt duplicates | Kommaseparerte kontroller som skal kjøres: missing, empty, extra, placeholders, undefined, unused, duplicates. `unused` oppgitt her feiler når den ikke kan kjøres |
| `--duplicates` | `false` | Rapporter også samme tekst under ulike nøkler |
| `--ignore` | — | Kommaseparerte glob-mønstre for kildefiler som skal hoppes over, relativt til prosjektet |
| `--json` | `false` | Skriv ut JSON i stedet for tekst |

```bash
i18n-micro check
i18n-micro check --only missing,placeholders --json
```

### `stats` {#stats}

Vis hvor ferdig oversettelsen er per locale

| Flagg | Standard | Beskrivelse |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` fra nuxt.config | Oversettelseskatalog, relativt til prosjektet |
| `--html` | — | Skriv også en HTML-rapport til denne filen |
| `--json` | `false` | Skriv ut JSON i stedet for tekst |
| `--baseRef` | — | Git-ref å sammenligne fullføringsgraden med, f.eks. HEAD~1 eller main |

```bash
i18n-micro stats --baseRef main
i18n-micro stats --html reports/i18n.html
```

### `lint` {#lint}

Kontroller teksten i oversettelser; feiler når problemer gjenstår

| Flagg | Standard | Beskrivelse |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` fra nuxt.config | Oversettelseskatalog, relativt til prosjektet |
| `--rules` | alle, eller `enabledRules` fra .i18n-lintrc.json | Kommaseparerte regler som skal kjøres: no-trailing-spaces, no-multiple-spaces, no-empty-translation, eller en egendefinert |
| `--fix` | `false` | Rett det som kan rettes: mellomrom, og egendefinerte regler med en erstatning |
| `--json` | `false` | Skriv ut JSON i stedet for tekst |

```bash
i18n-micro lint --rules no-trailing-spaces --fix
```

### `search` {#search}

Søk i nøkler og verdier, og vis hvor hver nøkkel brukes

| Flagg | Standard | Beskrivelse |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` fra nuxt.config | Oversettelseskatalog, relativt til prosjektet |
| `<query>` | — | Tekst eller nøkkel å søke etter |
| `--caseSensitive` | `false` | Skill mellom store og små bokstaver |
| `--onlyUnused` | `false` | Bare nøkler som `clean` ville fjernet; søket blir valgfritt |
| `--scope` | `all` | Hvor det skal søkes: global, pages, all |
| `--limit` | — | Returner maksimalt så mange nøkler |
| `--ignore` | — | Kommaseparerte glob-mønstre for kildefiler som skal hoppes over, relativt til prosjektet |
| `--json` | `false` | Skriv ut JSON i stedet for tekst |

```bash
i18n-micro search "Welcome"
i18n-micro search --onlyUnused
```

## Oversettelsesarbeidsflyt {#translation-workflow}

### `extract` {#extract}

List opp nøklene kildefilene bruker som ennå ikke har tekst, og legg til de som har en standardtekst i standard-localet

| Flagg | Standard | Beskrivelse |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` fra nuxt.config | Oversettelseskatalog, relativt til prosjektet |
| `--ignore` | — | Kommaseparerte glob-mønstre for kildefiler som skal hoppes over, relativt til prosjektet |

```bash
i18n-micro extract
```

### `translate` {#translate}

Fyll inn manglende oversettelser fra standard-localet via en oversettelsestjeneste

| Flagg | Standard | Beskrivelse |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` fra nuxt.config | Oversettelseskatalog, relativt til prosjektet |
| `--service` | — | Oversettelsestjeneste: ai, azure, deepl, google, libretranslate, yandexcloud |
| `--token` | — | API-nøkkel. Foretrekk miljøvariabelen I18N_TRANSLATE_TOKEN: flagg havner i skallhistorikken |
| `--options` | — | Tjenestealternativer som key:value-par, separert med komma |
| `--locale` | alle locales unntatt standard | Kommaseparerte locales som skal fylles |
| `--replace` | `false` | Oversett alle nøkler på nytt og erstatt eksisterende verdier |
| `--dryRun` | `false` | Tell nøkler og tegn per locale; send ingenting |
| `--chunkSize` | — | Strenger per forespørsel; begrenset til det tjenesten godtar |
| `--pluralSeparator` | `\|` | Skilletegn for flertallsformer i meldinger |
| `--glossaryFile` | `.i18n-glossary.json` når den finnes | Ordlistefil, brukt av tjenesten `ai` |

```bash
i18n-micro translate --dryRun
I18N_TRANSLATE_TOKEN=... i18n-micro translate --service deepl --locale de,fr
i18n-micro translate --service ai --options provider:openai,model:gpt-4o-mini
i18n-micro translate --service libretranslate --options baseUrl:https://translate.example.com
```

### `sync` {#sync}

Fjern nøkler som standard-localet ikke har; stopper når det ikke kan bevises at det er trygt. Manglende nøkler forblir manglende

| Flagg | Standard | Beskrivelse |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` fra nuxt.config | Oversettelseskatalog, relativt til prosjektet |
| `--ignore` | — | Kommaseparerte glob-mønstre for kildefiler som skal hoppes over, relativt til prosjektet |
| `--dryRun` | `false` | List opp hva som ville blitt fjernet; skriv ingenting |
| `--force` | `false` | Fjern nøkler selv om det ikke kan bevises at det er trygt |

```bash
i18n-micro sync --dryRun
```

### `clean` {#clean}

Fjern nøkler som ingenting i prosjektet bruker; stopper når det ikke kan bevises

| Flagg | Standard | Beskrivelse |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` fra nuxt.config | Oversettelseskatalog, relativt til prosjektet |
| `--include` | — | Regulært uttrykk: vurder bare samsvarende nøkler for fjerning |
| `--exclude` | — | Regulært uttrykk: fjern aldri samsvarende nøkler |
| `--ignore` | — | Kommaseparerte glob-mønstre for kildefiler som skal hoppes over, relativt til prosjektet |
| `--dryRun` | `false` | List opp hva som ville blitt fjernet; skriv ingenting |
| `--force` | `false` | Fjern nøkler selv om bruken ikke kan bevises for alle |

```bash
i18n-micro clean --dryRun
i18n-micro clean --exclude '^errors\.'
```

## Refaktorering {#refactoring}

### `text-to-i18n` {#text-to-i18n}

Erstatt hardkodet tekst i Vue-maler med oversettelseskall, og rapporter hardkodet tekst i kode

| Flagg | Standard | Beskrivelse |
| --- | --- | --- |
| `--translationFile` | `<translationDir>/<defaultLocale>.json` | Filen de nye nøklene skrives til |
| `--path` | hele prosjektet | Fil eller katalog som skal behandles |
| `--context` | — | Prefiks for genererte nøkler |
| `--ignore` | — | Kommaseparerte glob-mønstre for kildefiler som skal hoppes over, relativt til prosjektet |
| `--dryRun` | `false` | Vis hva som ville endret seg; skriv ingenting |
| `--interactive` | `false` | Bekreft eller rediger hver genererte nøkkel |

```bash
i18n-micro text-to-i18n --dryRun
i18n-micro text-to-i18n --path components --context ui
```

### `rename` {#rename}

Gi nytt navn til en nøkkel eller et navnerom i alle locales og i kildefiler

| Flagg | Standard | Beskrivelse |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` fra nuxt.config | Oversettelseskatalog, relativt til prosjektet |
| `--from` **\*** | — | Gjeldende nøkkel eller navnerom |
| `--to` **\*** | — | Ny nøkkel eller nytt navnerom |
| `--ignore` | — | Kommaseparerte glob-mønstre for kildefiler som skal hoppes over, relativt til prosjektet |
| `--dryRun` | `false` | Rapporter endringene; skriv ingenting |

**\*** påkrevd.

```bash
i18n-micro rename --from common.save --to actions.save
```

### `pseudo` {#pseudo}

Fyll et locale med pseudo-oversettelser for å finne layout-problemer og hardkodet tekst

| Flagg | Standard | Beskrivelse |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` fra nuxt.config | Oversettelseskatalog, relativt til prosjektet |
| `--sourceLocale` | standard-localet | Locale som skal leses |
| `--targetLocale` **\*** | — | Locale som skal fylles |
| `--replace` | `false` | Overskriv eksisterende verdier |

**\*** påkrevd.

### `format` {#format}

Skriv locale-filer på nytt med sorterte nøkler og ensartet innrykk

| Flagg | Standard | Beskrivelse |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` fra nuxt.config | Oversettelseskatalog, relativt til prosjektet |
| `--indent` | `2` | Antall mellomrom i innrykket |
| `--sortKeys` | `true` | Sorter nøkler; bruk --no-sortKeys for å beholde rekkefølgen |
| `--check` | `false` | Feil hvis en fil ville endret seg; skriv ingenting |

```bash
i18n-micro format --check
```

## Utveksling {#exchange}

### `export` {#export}

Eksporter locale-filer til PO eller CSV, med teksten fra standard-localet som kilde

| Flagg | Standard | Beskrivelse |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` fra nuxt.config | Oversettelseskatalog, relativt til prosjektet |
| `--format` | `po` | Filformat: po, csv |
| `--dir` | `pots` for po, `csv_exports` for csv | Utdatakatalog, relativt til prosjektet |
| `--force` | `false` | Overskriv filer som er endret siden forrige eksport og aldri importert |

```bash
i18n-micro export --format csv
```

### `import` {#import}

Flett PO- eller CSV-filer inn i locale-filene

| Flagg | Standard | Beskrivelse |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` fra nuxt.config | Oversettelseskatalog, relativt til prosjektet |
| `--format` | `po` | Filformat: po, csv |
| `--dir` | `pots` for po, `csv_exports` for csv | Inndatakatalog, relativt til prosjektet |
| `--dryRun` | `false` | Rapporter hva som ville blitt importert; skriv ingenting |

```bash
i18n-micro import --format csv --dryRun
```

### `sync-remote` {#sync-remote}

Hent globale oversettelser fra, eller send dem til, HTTP-endepunktet i .i18n-remote.json

| Flagg | Standard | Beskrivelse |
| --- | --- | --- |
| `--translationDir` | `i18n.translationDir` fra nuxt.config | Oversettelseskatalog, relativt til prosjektet |
| `--pull` | `true` | Hent fra den eksterne kilden |
| `--push` | `false` | Send til den eksterne kilden |
| `--force` | `false` | Ved henting, bruk den eksterne verdien; ved sending, overskriv tekst som bare finnes eksternt |
| `--dryRun` | `false` | Rapporter hva en henting ville endret; skriv og send ingenting |

```bash
i18n-micro sync-remote --dryRun
i18n-micro sync-remote --no-pull --push
```

## Lint-regler {#lint-rules}

| Regel | Finner | Rettes av `--fix` |
| --- | --- | --- |
| `no-trailing-spaces` | Mellomrom på slutten av en verdi eller linje | ja |
| `no-multiple-spaces` | To eller flere mellomrom på rad | ja |
| `no-empty-translation` | En tom eller blank verdi | nei |

## Avslutningskoder {#exit-codes}

| Kode | Betydning |
| --- | --- |
| `0` | Ferdig, ingenting å rapportere |
| `1` | Funn: `check`, `lint` eller `format --check` fant noe, `clean` eller `sync` kunne ikke bevise at en fjerning var trygg, `export` ville overskrevet uimportert arbeid, `translate` utelot nøkler, `import` eller `sync-remote` møtte en konflikt, en `sync-remote`-sending ville fjernet ekstern tekst. En `--dryRun` av `clean`, `sync` eller en `sync-remote`-henting rapporterer disse og avslutter med `0` |
| `2` | Feil: ugyldig bruk, uleselig prosjekt, nettverks- eller filfeil |

## Konfigurasjonsfiler {#configuration-files}

| Fil | Brukes av |
| --- | --- |
| `.i18n-lintrc.json` | `lint`: `enabledRules`, `disabledRules`, `customRegexRules` (`name`, `pattern`, `flags`, `description`, `replacement`) |
| `.i18n-remote.json` | `sync-remote`: `url`, `path`, `token`, `auth` (`username`, `password`). `type` kan utelates; bare `custom` finnes |
| `.i18n-glossary.json` | `translate --service ai`: `entries` med `source`, `target`, og valgfrie `from`, `to` |

## Miljøvariabler {#environment-variables}

| Navn | Brukes til |
| --- | --- |
| `I18N_TRANSLATE_TOKEN` | API-nøkkel for `translate`. Leses også fra `.env` |
| `I18N_REMOTE_TOKEN` | Bearer-token for `sync-remote`. Leses også fra `.env` |
| `AI_GATEWAY_API_KEY, OPENAI_API_KEY, ANTHROPIC_API_KEY` | Nøkkel for tjenesten `ai`, når `I18N_TRANSLATE_TOKEN` ikke er satt |
| `DEFAULT_LOCALE` | Overstyrer `defaultLocale`, som i modulen |
