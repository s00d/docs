---
title: "Hooks"
description: "Runtime-hooken i18n:register: legg til oversettelser fra en Nuxt-plugin ved lasting og ved navigasjon."
---

Modulet kaller én runtime-hook (app-hook), `i18n:register`. Bruk den når en plugin eller en modul legger til oversettelser som ikke finnes i `locales/`-filene dine. Callbacken din får en `register`-funksjon som fletter oversettelser inn i siden som vises.

## `i18n:register` {#i18nregister}

```ts
'i18n:register': (
  register: (translations: unknown, locale?: string) => void,
  locale: string,
) => HookResult
```

| Argument | Beskrivelse |
| --- | --- |
| `register(translations, locale?)` | Dypfletter `translations` inn i sidechunken for ruten som lastes, for `locale` (standard: hookens `locale`). Nøkler som allerede finnes, overskrives. |
| `locale` | Localet for ruten som lastes. |

Hooken er typet via `RuntimeNuxtHooks`, så `nuxtApp.hook('i18n:register', …)` trenger ingen cast.

## Når den utløses {#when-it-fires}

Loader-pluginen (`i18n-plugin-loader`) kaller den:

1. én gang ved oppstart, når alle plugins har kjørt (`app:created`) og før appen rendres;
2. i sin `router.beforeEach`, etter at målsidens oversettelser er lastet, når stien endres — ved hver navigasjon under `no_prefix`.

Hver callback og hvert `register`-kall avventes før appen rendres eller navigasjonen fortsetter, så siden rendres med de flettede nøklene. Med [`hooks: false`](/no/api/module-options#hooks) kalles hooken aldri.

## Eksempel {#example}

```ts
// plugins/i18n-extra.ts
export default defineNuxtPlugin((nuxtApp) => {
  nuxtApp.hook('i18n:register', async (register, locale) => {
    const extra = await $fetch<Record<string, unknown>>(`/api/cms-strings/${locale}`)
    register(extra, locale)
  })
})
```

Dette er en runtime-hook: registrer den med `nuxtApp.hook` i en plugin, ikke med `nuxt.hook` i `nuxt.config` eller i en moduls `setup`. En modul legger til en slik plugin med `addPlugin`.
