# API-referanse

## Runtime-API

- [Metoder](/api/methods) — `$t`, `$ts`, `$_t`, `$_ts`, lokale-veksling, ruting-hjelpere
- [Hendelser](/api/events) — `i18n:register`, `i18n:beforeLocaleSwitch`, `i18n:afterLocaleSwitch`
- [Oversettelser og cache](/api/cache) — `TranslationStorage`, lasting av payloads, `$clearCache`

## Server-mellomvare

Server-håndterere bruker dedikert mellomvare (ikke klient-`$t`-hjelperne):

- [`useTranslationServerMiddleware`](/guides/server-side-translations#-using-translations-in-server-handlers) — oversett i API-ruter og server-håndterere
- [`useLocaleServerMiddleware`](/guides/server-side-translations#-using-locale-information-in-server-handlers) — les gjenkjent lokale og metadata

Se hele [guiden for server-side oversettelser](/guides/server-side-translations) for oppsett, prioritering av lokale-gjenkjenning og eksempler.
