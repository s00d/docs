Denne delen lister opp alle alternativer, hjelpere, hooks, composables og komponenter i Nuxt-modulen, i tillegg til det eksporterte API-et for hver `@i18n-micro/*`-pakke. Bruk den til å slå opp en signatur eller en standardverdi; [Veiledningen](/no/guide/getting-started) forklarer hvordan du bruker dem. De fleste tabellene her er generert fra kildekoden, så de samsvarer med koden.

## Nuxt-modul {#nuxt-module}

| Side | Dekker |
| --- | --- |
| [Modulalternativer](/no/api/module-options) | Alle `i18n`-nøkler i `nuxt.config`, med type og standardverdi |
| [Hjelpere](/no/api/methods) | `$t`, `$tc`, `$tn`, `$td`, `$localePath`, `$switchLocale`, `$defineI18nRoute` og resten |
| [Hooks](/no/api/events) | Runtime-hooken `i18n:register` |

## Composables {#composables}

| Composable | Brukes til |
| --- | --- |
| [`useI18n`](/no/composables/useI18n) | Hjelperne i `<script setup>` |
| [`useI18nLocale`](/no/composables/useI18nLocale) | Locale-tilstand og cookie i en egendefinert deteksjonsplugin |
| [`useI18nHead`](/no/composables/useI18nHead) | Overstyringer per side av de genererte SEO-taggene |
| [`useLocaleHead`](/no/composables/useLocaleHead) | SEO-taggene som et objekt, for din egen `useHead` |

## Komponenter {#components}

| Komponent | Gjengir |
| --- | --- |
| [`<i18n-t>`](/no/components/i18n-t) | Én oversettelse, med flertall, formatering og slot-interpolering |
| [`<i18n-link>`](/no/components/i18n-link) | En `NuxtLink` til den lokaliserte ruten |
| [`<i18n-switcher>`](/no/components/i18n-switcher) | En nedtrekksmeny for locale |
| [`<i18n-group>`](/no/components/i18n-group) | En blokk med et felles nøkkelprefiks |

## Server {#server}

Nitro-handlere bruker `useTranslationServerMiddleware` og `useLocaleServerMiddleware`, ikke klienthjelperne. Se [Serverruter](/no/guide/server-side-translations).

## Pakker {#packages}

[Pakke-API-er](/no/api/packages/overview) lister opp eksportene til hver `@i18n-micro/*`-pakke, med én generert side for hver.
