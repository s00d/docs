# 📚 Eksempler og bruk av Nuxt I18n Micro

Denne seksjonen viser ulike eksempler på hvordan du bruker `Nuxt I18n Micro` i din Nuxt.js-applikasjon. Du får se hvordan du bytter locales, bruker komponentene `<i18n-link>`, `<i18n-switcher>` og `<i18n-t>`, og hvordan du håndterer oversettelsesnøkler dynamisk.

## 🛠️ Grunnleggende oppsett

Her er et grunnleggende oppsett for å komme i gang med `Nuxt I18n Micro`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr', disabled: false, displayName: 'English' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr', disabled: false, displayName: 'Français' },
      { code: 'de', iso: 'de-DE', dir: 'ltr', disabled: false, displayName: 'Deutsch' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
    meta: true,
  },
})
```

## 🌍 Locale-bytte

### Programmatisk bytte av locales

Dette eksempelet viser hvordan du bytter locales programmatisk med knapper:

```vue
<template>
  <div>
    <p>Current Locale: {{ $getLocale() }}</p>
    <div>
      <button v-for="locale in $getLocales()" :key="locale.code" :disabled="locale.code === $getLocale()" @click="() => $switchLocale(locale.code)">
        Switch to {{ $t(locale.code) }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $getLocale, $switchLocale, $getLocales, $t } = useNuxtApp()
</script>
```

### Eksempel-JSON for locale-bytte

```json
{
  "en": "English",
  "fr": "Français",
  "de": "Deutsch"
}
```

### Bruk av `<i18n-switcher>`-komponenten

Komponenten `<i18n-switcher>` gir en nedtrekksmeny for locale-bytte med tilpassbare etiketter:

```vue
<template>
  <div>
    <i18n-switcher :custom-labels="{ en: 'English', fr: 'Français', de: 'Deutsch' }" />
  </div>
</template>
```

## 📝 Rendering av dynamiske nøkler fra oversettelsesfiler

I noen tilfeller vil du kanskje iterere over dynamiske nøkler lagret i oversettelsesfilene og rendere verdiene deres betinget. Eksempelet nedenfor viser hvordan du gjør dette med `Nuxt I18n Micro`.

### Eksempel: Rendering av dynamiske nøkler

Dette eksempelet henter en array med nøkler fra en bestemt oversettelsessti (i dette tilfellet `dynamic`) og itererer over dem. Hver nøkkel sjekkes for eksistens med `$has` før verdien renderes med `$t`.

```vue
<template>
  <div>
    <div v-for="key in $t('dynamic')" :key="key">
      <p>
        {{ key }}: <span v-if="$has(key)">{{ $t(key) }}</span>
      </p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t, $has } = useNuxtApp()
</script>
```

### Eksempel på oversettelsesfil (`en.json`)

```json
{
  "dynamic": ["key1", "key2", "key3"],
  "key1": "This is the first key's value",
  "key2": "This is the second key's value",
  "key3": "This is the third key's value"
}
```

### Eksempel: Rendering av dynamiske nøkler fra et objekt

I dette eksempelet håndterer vi et objekt som er lagret i oversettelsesfilen. Vi henter og itererer over nøklene i objektet og rendrer dynamisk både nøkkelnavn og tilhørende verdier.

```vue
<template>
  <div>
    <div v-for="(value, key) in $t('dynamicObject')" :key="key">
      <p>{{ key }}: {{ value }}</p>
    </div>
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $t } = useNuxtApp()
</script>
```

### Eksempel på oversettelsesfil (`en.json`)

```json
{
  "dynamicObject": {
    "title": "Welcome to our site",
    "description": "This is a brief description of our services.",
    "footerNote": "Thank you for visiting!"
  }
}
```

## 🌟 Bruk av `<i18n-t>` for oversettelser med slots og interpolasjon

Komponenten `<i18n-t>` er nyttig for å rendre oversettelser med dynamisk innhold og HTML-tagger:

```vue
<template>
  <i18n-t keypath="greeting" tag="h1">
    <template #default="{ translation }">
      <strong>{{ translation.replace('page', 'page replace') }}</strong> <i>!!!</i>
    </template>
  </i18n-t>
</template>
```

### Eksempel-JSON for `<i18n-t>`

```json
{
  "greeting": "Welcome to the page"
}
```

### Med interpolasjon

```vue
<template>
  <i18n-t keypath="welcome" :params="{ username: 'Alice', unreadCount: 5 }"></i18n-t>
</template>
```

### Eksempel-JSON for interpolasjon

```json
{
  "welcome": "Hello {username}, you have {unreadCount} unread messages."
}
```

## 🌟 Bruk av `$tc` for pluralisering

Funksjonen `$tc` i `Nuxt I18n Micro` håndterer pluralisering basert på antall og locale-innstillinger. Dette er nyttig for å tilpasse meldinger dynamisk til antall — for eksempel varer, varsler eller andre entiteter som varierer i antall.

### Eksempel: Bruk av `$tc` for pluralisering

I det følgende eksempelet viser vi en melding som angir antall epler ved hjelp av `$tc`. Oversettelsesnøkkelen håndterer flere flertallsformer basert på antallet som oppgis.

```vue
<template>
  <div>
    <!-- Display a pluralized message about the number of apples -->
    <p>{{ $tc('apples', 0) }}</p>
    <!-- Outputs: no apples -->
    <p>{{ $tc('apples', 1) }}</p>
    <!-- Outputs: one apple -->
    <p>{{ $tc('apples', 10) }}</p>
    <!-- Outputs: 10 apples -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tc } = useNuxtApp()
</script>
```

### Eksempel-JSON for pluralisering

Slik kan du definere oversettelsen i JSON-filen for å håndtere ulike flertallsformer:

```json
{
  "apples": "no apples | one apple | {count} apples"
}
```

### Forklaring

- **`$tc('apples', 0)`**: Returnerer den første formen, brukt når antallet er null (`"no apples"`).
- **`$tc('apples', 1)`**: Returnerer den andre formen, brukt når antallet er én (`"one apple"`).
- **`$tc('apples', 10)`**: Returnerer den tredje formen med tallverdien, brukt når antallet er to eller mer (`"10 apples"`).

### Ytterligere eksempel med mer kompleks pluralisering

Hvis applikasjonen din må håndtere mer komplekse flertallsregler (f.eks. spesifikke tilfeller for null, én, to, få, mange, andre), kan du utvide oversettelsesstrengene tilsvarende:

```json
{
  "apples": "no apples | one apple | two apples | a few apples | many apples | {count} apples"
}
```

- **`$tc('apples', 2)`**: Kan settes opp til å returnere `"two apples"`.
- **`$tc('apples', 3)`**: Kan returnere `"a few apples"`, avhengig av reglene som er definert for antallet.

## 🌐 Bruk av `$tn` for tallformatering

Funksjonen `$tn` formaterer tall i henhold til gjeldende locale ved hjelp av `Intl.NumberFormat`-API-et. Dette er nyttig for å vise tall på en måte som samsvarer med brukerens regionale innstillinger, som valuta, prosent eller andre tallformater.

### Eksempel: Bruk av `$tn` for tallformatering

```vue
<template>
  <div>
    <!-- Format a number as currency -->
    <p>{{ $tn(1234567.89, { style: 'currency', currency: 'USD' }) }}</p>
    <!-- Outputs: $1,234,567.89 in 'en-US' locale -->

    <!-- Format a number with custom options -->
    <p>{{ $tn(0.567, { style: 'percent', minimumFractionDigits: 1 }) }}</p>
    <!-- Outputs: 56.7% in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tn } = useNuxtApp()
</script>
```

## 🗓️ Bruk av `$td` for dato- og tidsformatering

Funksjonen `$td` formaterer datoer og klokkeslett i henhold til gjeldende locale ved hjelp av `Intl.DateTimeFormat`-API-et. Dette er nyttig for å vise datoer og klokkeslett i formater som er kjente for brukeren basert på deres locale-innstillinger.

### Eksempel: Bruk av `$td` for dato- og tidsformatering

```vue
<template>
  <div>
    <!-- Format a date with full options -->
    <p>{{ $td(new Date(), { weekday: 'long', year: 'numeric', month: 'long', day: 'numeric' }) }}</p>
    <!-- Outputs: "Friday, September 1, 2023" in 'en-US' locale -->

    <!-- Format a date with time -->
    <p>{{ $td(new Date(), { hour: '2-digit', minute: '2-digit', second: '2-digit' }) }}</p>
    <!-- Outputs: "10:15:30 AM" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $td } = useNuxtApp()
</script>
```

## 🗓️ Bruk av `$tdr` for relative datoer

Funksjonen `$tdr` formaterer datoer som relative tider (f.eks. "5 minutter siden", "2 dager siden") i henhold til gjeldende locale ved hjelp av `Intl.RelativeTimeFormat`-API-et. Dette er nyttig for å vise tidsdifferanser relativt til nåværende dato og klokkeslett.

### Eksempel: Bruk av `$tdr` for relativ datoformatering

```vue
<template>
  <div>
    <!-- Format a date as a relative time -->
    <p>{{ $tdr(new Date(Date.now() - 1000 * 60 * 5)) }}</p>
    <!-- Outputs: "5 minutes ago" in 'en-US' locale -->

    <!-- Format a date that is in the future -->
    <p>{{ $tdr(new Date(Date.now() + 1000 * 60 * 60 * 24)) }}</p>
    <!-- Outputs: "in 1 day" in 'en-US' locale -->
  </div>
</template>

<script setup>
import { useNuxtApp } from '#imports'

const { $tdr } = useNuxtApp()
</script>
```
