**Dato**: 2024-12-24

**CLI-versjon introdusert**: `v1.1.0`

![v1.1.0 CLI text-to-i18n-demo](/images/text-to-i18n.gif)

Vi er glade for å kunne lansere den nye `text-to-i18n`-kommandoen i Nuxt I18n Micro CLI! Denne kraftige funksjonen automatiserer prosessen med å hente ut hardkodede tekststrenger fra kodebasen din og gjøre dem om til i18n-oversettelsesnøkler. Den er laget for å spare tid, redusere feil og effektivisere lokaliseringsarbeidsflyten din.

## Viktigste fordeler {#key-benefits}

- **Automatisk tekstuthenting**: Skanner Vue-maler, JavaScript- og TypeScript-filer.
- **Sømløs nøkkelgenerering**: Lager strukturerte oversettelsesnøkler basert på filstier og innhold.
- **Effektiv oversettelseshåndtering**: Oppdaterer oversettelsesfilene dine og bevarer eksisterende oppføringer.

## Slik fungerer det {#how-it-works}

1. **Filskanning**: Behandler filer i sentrale mapper som `pages`, `components` og `plugins`.
2. **Tekstbehandling**: Identifiserer og henter ut oversettbare strenger og genererer unike nøkler.
3. **Oppdatering av oversettelser**: Setter automatisk inn nye nøkler i oversettelsesfilene dine og beholder den nestede strukturen.

## Bruk {#usage}

```bash
i18n-micro text-to-i18n [options]
```

Eksempel:

```bash
i18n-micro text-to-i18n --translationFile locales/en.json --context auth
```

## Eksempler på transformasjoner {#example-transformations}

### Før {#before}

```vue
<template>
  <div>
    <h1>Welcome to our site</h1>
    <p>Please sign in to continue</p>
  </div>
</template>
```

### Etter {#after}

```vue
<template>
  <div>
    <h1>{{ $t('pages.home.welcome_to_our_site') }}</h1>
    <p>{{ $t('pages.home.please_sign_in') }}</p>
  </div>
</template>
```
