# Runtime-overstyringer for i18n

Bruk denne guiden når du trenger å kjøre ett byggeartefakt med ulike locale-standarder per miljø (for eksempel: ulike tenant-instanser).

## Hva kan overstyres ved kjøretid

Modulen støtter trygge runtime-overstyringer for:

- `defaultLocale`
- `fallbackLocale`
- `disabledLocales`

Disse overstyringene legges oppå byggekonfigurasjonen fra `.nuxt/i18n.strategy.mjs` og `.nuxt/i18n.config.mjs`.

## Hva som ikke kan overstyres ved kjøretid

`strategy` (`no_prefix`, `prefix`, `prefix_except_default`, `prefix_and_default`) er et anliggende ved byggetid fordi det påvirker atferden til genererte ruter.

Hvis du sender en runtime-overstyring av strategien, blir den ignorert og det logges en advarsel.

## Overstyringer basert på RuntimeConfig

Angi runtime-verdier under `runtimeConfig.public.i18nRuntime`:

```ts
export default defineNuxtConfig({
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

## Overstyringer via miljøvariabler

Du kan også konfigurere overstyringer via miljøvariabler:

- `NUXT_I18N_DEFAULT_LOCALE`
- `NUXT_I18N_FALLBACK_LOCALE`
- `NUXT_I18N_DISABLED_LOCALES` (kommaseparert, f.eks. `fr,it`)

Aliaser for fallback støttes også:

- `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES`

## Valideringsregler

Ved kjøretid validerer modulen overstyringer for å unngå en ødelagt tilstand:

- Du kan ikke deaktivere alle locales.
- `defaultLocale` må peke til en aktivert locale.
- `fallbackLocale` må finnes blant deklarerte locales.

Hvis en overstyring er ugyldig, beholder modulen en trygg verdi og logger en advarsel.

## Merknader for deployments med flere instanser

Denne runtime-funksjonen er designet for aktivering av locales og standarder per instans uten å bygge på nytt.

Hvis instanser krever ulike URL-strategier (`no_prefix` vs. `prefix`), bruk separate bygg for hver strategi.

## Deaktiverte locales og statiske payloads

`runtimeConfig.public.i18nRuntime.disabledLocales` oppdaterer ruting, switcher og Nitro-payload-**handleren** — men Nitro serverer filer under `public/` **før** den handleren.

Hvis `translationPayloads.publicAssets` (eller Node SSRs tvungne offentlige kopi) allerede har skrevet `/_locales/\{page\}/\{locale\}/data.json`, kan ikke en runtime-deaktivering skjule den filen. Foretrekk `locale.disabled: true` ved byggetid slik at premerge ikke sender ut statiske payloads for den locale-en.
