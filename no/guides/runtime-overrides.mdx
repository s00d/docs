# Runtime i18n-overstyringer

Bruk denne guiden når du trenger at ett byggeartefakt kjører med ulike lokale-standarder per miljø (for eksempel: ulike tenant-instanser).

## Hva som kan overstyres i kjøretid

Modulen støtter trygge runtime-overstyringer for:

- `defaultLocale`
- `fallbackLocale`
- `disabledLocales`

Disse overstyringene anvendes oppå byggetids-konfigurasjonen fra `.nuxt/i18n.strategy.mjs` og `.nuxt/i18n.config.mjs`.

## Hva som ikke kan overstyres i kjøretid

`strategy` (`no_prefix`, `prefix`, `prefix_except_default`, `prefix_and_default`) er en byggetids-sak fordi den påvirker atferden til genererte ruter.

Hvis du sender en runtime-strategi-overstyring, ignoreres den og en advarsel utstedes.

## RuntimeConfig-baserte overstyringer

Oppgi runtime-verdier under `runtimeConfig.public.i18nRuntime`:

```ts
export default defineNuxtConfig({
  runtimeConfig: {
    public: {
      i18nRuntime: {
        defaultLocale: 'de',
        fallbackLocale: 'en',
        disabledLocales: ['fr'],
      },
    },
  },
})
```

## Overstyringer via miljøvariabler

Du kan også konfigurere overstyringer via miljøvariabler:

- `NUXT_I18N_DEFAULT_LOCALE`
- `NUXT_I18N_FALLBACK_LOCALE`
- `NUXT_I18N_DISABLED_LOCALES` (kommaseparert, f.eks. `fr,it`)

Fallback-aliaser støttes også:

- `NUXT_PUBLIC_I18N_RUNTIME_DEFAULT_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_FALLBACK_LOCALE`
- `NUXT_PUBLIC_I18N_RUNTIME_DISABLED_LOCALES`

## Valideringsregler

I kjøretid validerer modulen overstyringer for å unngå ødelagt tilstand:

- Du kan ikke deaktivere alle lokaler.
- `defaultLocale` må peke til en aktivert lokale.
- `fallbackLocale` må finnes i deklarerte lokaler.

Hvis en overstyring er ugyldig, beholder modulen en trygg verdi og logger en advarsel.

## Merknader for multi-instans-utrullinger

Denne runtime-funksjonen er designet for per-instans lokale-aktivering og standarder uten å bygge på nytt.

Hvis instanser krever ulike URL-strategier (`no_prefix` vs `prefix`), bruk separate bygg for hver strategi.

## Deaktiverte lokaler og statiske payloads

`runtimeConfig.public.i18nRuntime.disabledLocales` oppdaterer ruting, switcher og Nitro payload-**handleren** — men Nitro serverer filer under `public/` **før** den handleren.

Hvis `translationPayloads.publicAssets` (eller Node SSRs tvungne offentlige kopi) allerede har skrevet `/_locales/\{page\}/\{locale\}/data.json`, kan en runtime-deaktivering ikke skjule den filen. Foretrekk `locale.disabled: true` ved bygg slik at pre-merge ikke utsteder statiske payloads for den lokalen.
