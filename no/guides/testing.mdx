# 🧪 Testing av `Nuxt I18n Micro`-modulen

## 📖 Introduksjon til testing

Å teste `Nuxt I18n Micro`-modulen er avgjørende for å sikre at applikasjonens lokaliseringsfunksjoner fungerer som forventet. Denne dokumentasjonen veileder deg gjennom oppsett av testmiljøet, oppretting av mock-konfigurasjoner for vitest og skriving av tester for komponentene. For et praktisk eksempel, se [eksempelprosjektet på GitHub](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/test-utils/example).

Se [Testing av rutingsstrategier](https://github.com/s00d/nuxt-i18n-micro/blob/main/docs/guide/testing-strategies.md) for hvordan dette repositoriet kjører sine egne testsett — Vitest-prosjektene `unit` / `integration` / `e2e`, per-strategi-filene (`test/strategies-*.test.ts`) og genererings-regresjoner.

## 🛠️ Sette opp testmiljøet

### 1. Installer `@i18n-micro/test-utils`

Først må du installere testverktøyene for `Nuxt I18n Micro`. Denne pakken gir de nødvendige verktøyene for å mocke og teste i18n-konfigurasjonene dine.

```bash
npm install @i18n-micro/test-utils --save-dev
```

### 2. Opprett en mock-konfigurasjonsfil

Deretter oppretter du en fil for å sette opp mock-i18n-konfigurasjonen. Denne filen brukes til å mocke i18n-funksjonene og -verktøyene under testene.

```typescript
// tests/unit-setup.ts

import { mockNuxtImport } from '@nuxt/test-utils/runtime'
import { vi } from 'vitest'
import { i18nUtils } from '@i18n-micro/test-utils'

export function createFakeI18n() {
  return {
    $getLocale: vi.fn(i18nUtils.getLocale),
    $t: vi.fn(i18nUtils.t),
    $tc: vi.fn(i18nUtils.tc),
    $setLocale: vi.fn(i18nUtils.setLocale),
    $getLocaleName: vi.fn(i18nUtils.getLocaleName),
    $setLocaleName: vi.fn(i18nUtils.setLocaleName),
    $getLocales: vi.fn(i18nUtils.getLocales),
    $setLocales: vi.fn(i18nUtils.setLocales),
    $defaultLocale: vi.fn(i18nUtils.defaultLocale),
    $setDefaultLocale: vi.fn(i18nUtils.setDefaultLocale),
    $getRouteName: vi.fn(i18nUtils.getRouteName),
    $settRouteName: vi.fn(i18nUtils.settRouteName),
    $ts: vi.fn(i18nUtils.ts),
    $tn: vi.fn(i18nUtils.tn),
    $td: vi.fn(i18nUtils.td),
    $has: vi.fn(i18nUtils.has),
    $resolveTranslations: vi.fn(i18nUtils.resolveTranslations),
    $setTranslation: vi.fn(i18nUtils.setTranslation),
    $mergeTranslations: vi.fn(i18nUtils.mergeTranslations),
    $switchLocaleRoute: vi.fn(i18nUtils.switchLocaleRoute),
    $switchLocalePath: vi.fn(i18nUtils.switchLocalePath),
    $switchLocale: vi.fn(i18nUtils.switchLocale),
    $switchRoute: vi.fn(i18nUtils.switchRoute),
    $localeRoute: vi.fn(i18nUtils.localeRoute),
    $localePath: vi.fn(i18nUtils.localePath),
    $setI18nRouteParams: vi.fn(i18nUtils.setI18nRouteParams),
  }
}

mockNuxtImport<() => ReturnType<typeof createFakeI18n>>('useI18n', () => vi.fn(() => createFakeI18n()))

export const setTranslationsFromJson = i18nUtils.setTranslationsFromJson
```

### 3. Konfigurer Vitest

Konfigurer nå Vitest til å bruke mock-konfigurasjonsfilen og sette opp testmiljøet.

```typescript
// vitest.config.ts

import { defineVitestConfig } from '@nuxt/test-utils/config'

export default defineVitestConfig({
  test: {
    watch: false,
    setupFiles: ['./tests/unit-setup.ts'],
    include: ['./**/*.spec.ts'],
  },
})
```

## 🧪 Skrive tester

### Eksempelkomponent

Her er et eksempel på en enkel komponent som bruker `useI18n`-composablen til å oversette meldinger.

```vue
<script setup lang="ts">
const { $t } = useI18n()

const props = defineProps({
  message: {
    type: String,
    default: null,
  },
})

// Test to see that $t works in script setup as well as the template
const message = props.message || $t('defaultMessage')
</script>

<template>
  <div>
    <p>Test from component: {{ $t('welcome') }}</p>
    <p data-testid="message">Test message from props: {{ message }}</p>
  </div>
</template>
```

### Testfil

La oss nå skrive en test for denne komponenten.

```typescript
// tests/unit/example.spec.ts

import { describe, it, expect, beforeEach } from 'vitest'
import { mount } from '@vue/test-utils'
import ExampleComponent from '@/components/ExampleComponent.vue'
import fs from 'fs'
import path from 'path'
import { setTranslationsFromJson } from './unit-setup'

describe('ExampleComponent', () => {
  beforeEach(async () => {
    const fileContent = fs.readFileSync(path.join(__dirname, '../../locales/en-GB.json')).toString()
    await setTranslationsFromJson('en', JSON.parse(fileContent))
  })

  it('renders the welcome message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.text()).toContain('Test from component: Welcome')
  })

  it('renders the default message correctly', () => {
    const wrapper = mount(ExampleComponent)
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Default Message')
  })

  it('renders the custom message correctly', () => {
    const wrapper = mount(ExampleComponent, {
      props: {
        message: 'Custom Message',
      },
    })
    expect(wrapper.find('[data-testid="message"]').text()).toContain('Test message from props: Custom Message')
  })
})
```

## 📝 Beste praksis for testing

- **🔧 Mock i18n-funksjoner:** Mock alltid i18n-funksjonene med `@i18n-micro/test-utils` for å sikre konsistente og forutsigbare testresultater.
- **⚙️ Bruk Vitest for enhetstester:** Vitest er et kraftig testrammeverk for Vue-applikasjoner. Bruk det til å skrive enhetstester for komponentene dine.
- **📚 Dokumenter testene:** Dokumenter tydelig formålet og forventede utfall for hver test. Dette bevarer klarhet og gjør det enklere for andre (eller ditt fremtidige jeg) å forstå testene.

## 📊 i18n-hjelpe-metoder

Under er en tabell som beskriver alle hjelpe-metodene som `@i18n-micro/test-utils` tilbyr.

| Metode                                          | Beskrivelse                                                                                                                                 |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `t(key, params, defaultValue)`                  | Oversetter en nøkkel med valgfrie parametere og en standardverdi.                                                                           |
| `tc(key, params, defaultValue)`                 | Oversetter en nøkkel med flertallsstøtte.                                                                                                   |
| `setTranslationsFromJson(locale, translations)` | Laster oversettelser fra et JSON-objekt for en bestemt lokale.                                                                              |
| `getLocale()`                                   | Returnerer gjeldende lokale.                                                                                                                |
| `setLocale(val)`                                | Setter gjeldende lokale.                                                                                                                    |
| `getLocaleName()`                               | Returnerer gjeldende lokale-navn.                                                                                                           |
| `setLocaleName(val)`                            | Setter gjeldende lokale-navn.                                                                                                               |
| `getLocales()`                                  | Returnerer listen over tilgjengelige lokaler.                                                                                               |
| `setLocales(val)`                               | Setter listen over tilgjengelige lokaler.                                                                                                   |
| `defaultLocale()`                               | Returnerer standardlokalen.                                                                                                                 |
| `setDefaultLocale(val)`                         | Setter standardlokalen.                                                                                                                     |
| `getRouteName()`                                | Returnerer gjeldende rutenavn.                                                                                                              |
| `settRouteName(val)`                            | Setter gjeldende rutenavn.                                                                                                                  |
| `ts(key, params, defaultValue)`                 | Oversetter en nøkkel og returnerer resultatet som en streng.                                                                                |
| `tn(value, options?)`                           | Formaterer et tall med inline `Intl.NumberFormatOptions`. Navngitte formater krever modulkonfigurasjon og er ikke tilgjengelige i denne frittstående hjelperen. |
| `td(value, options?)`                           | Formaterer en dato med inline `Intl.DateTimeFormatOptions`. Navngitte formater krever modulkonfigurasjon og er ikke tilgjengelige i denne frittstående hjelperen. |
| `has(key)`                                      | Sjekker om en oversettelsesnøkkel finnes.                                                                                                   |
| `resolveTranslations()`                         | Returnerer det aktive oversettelses-treet for gjeldende lokale og rute.                                                                     |
| `setTranslation(key, value)`                    | Erstatter verdien ved `key` i den aktive ordboken (erstatter, ikke fletter).                                                                |
| `mergeTranslations(newTranslations)`            | Fletter oversettelser inn i den aktive lokalen i kjøretid.                                                                                  |

Ved å følge disse stegene kan du effektivt teste `Nuxt I18n Micro`-modulen og sikre at applikasjonens lokaliseringsfunksjoner fungerer som forventet.
