# 🌐 Integrasjonsguide for Crowdin

## 📖 Introduksjon

Å integrere Crowdin i prosjektet strømlinjeformer lokaliserings- og oversettelsesprosessen. Det gjør det enklere å administrere oversettelser på tvers av flere språk og plattformer. Denne guiden gir en trinnvis gjennomgang av oppsettet av Crowdin med prosjektet ditt, inkludert konfigurasjon, opplasting av kilder og nedlasting av oversettelser.

## 🔧 Installasjon og oppsett

For å komme i gang med Crowdin må du installere Crowdin CLI globalt på maskinen din og initialisere den i prosjektkatalogen.

### 📦 Installere Crowdin CLI

Installer først Crowdin CLI globalt via npm:

```bash
npm install -g @crowdin/cli
```

### 🛠 Initialisere Crowdin i prosjektet ditt

Initialiser Crowdin i prosjektet ved å kjøre:

```bash
crowdin init
```

Denne kommandoen veileder deg gjennom oppsettet, inkludert å sette prosjekt-ID, API-token og andre konfigurasjonsdetaljer.

## 🗂️ Konfigurasjonsguide

### 📄 Konfigurasjonsfilen for Crowdin (`crowdin.yml`)

Konfigurasjonsfilen for Crowdin (`crowdin.yml`) definerer hvordan kildefilene mappes og hvor oversettelser skal plasseres. Under følger et eksempel på konfigurasjon:

```yml
'project_id': 'YOUR_PROJECT_ID'
'api_token': 'YOUR_API_TOKEN'
'base_path': './locales'
'base_url': 'https://api.crowdin.com'
'preserve_hierarchy': true

files:
  [
    { 'source': '/en.json', 'translation': '/%two_letters_code%.json' },
    { 'source': '/pages/**/en.json', 'translation': '/pages/**/%two_letters_code%.json' },
  ]
```

### 📂 Sentrale konfigurasjonsparametere

- **`project_id`**: Din Crowdin-prosjekt-ID. Denne identifiserer prosjektet i Crowdin der oversettelser administreres.
- **`api_token`**: API-tokenet som brukes til autentisering. Sørg for at dette tokenet har riktige tillatelser til å laste opp og ned oversettelser.
- **`base_path`**: Angir basiskatalogen for kildefiler. I dette eksempelet lagres oversettelser i `./locales`-katalogen.
- **`base_url`**: Basis-URL for Crowdin API-et.
- **`preserve_hierarchy`**: Når satt til `true`, opprettholder Crowdin mappestrukturen til kildefilene dine i prosjektet.

### 📂 Fil-konfigurasjon

`files`-seksjonen mapper kildefilene dine til stier der oversettelser lagres. For eksempel:

- **Kildesti**: Definerer plasseringen av de opprinnelige oversettelsesfilene.
- **Oversettelses-sti**: Angir hvor de oversatte filene lagres i Crowdin. Plassholdere som `%two_letters_code%` brukes til å sette språkkoden dynamisk i filstiene.

## ⬆️ Laste opp kildefiler til Crowdin

Når Crowdin-konfigurasjonen er satt opp, kan du laste opp kildefilene med følgende kommando:

```bash
crowdin upload sources
```

Denne kommandoen laster opp alle spesifiserte kildefiler i konfigurasjonen din til Crowdin, slik at de blir tilgjengelige for oversettelse.

## ⬇️ Laste ned oversettelser fra Crowdin

Etter at oversettelser er fullført eller oppdatert i Crowdin, kan du laste dem ned til prosjektet med:

```bash
crowdin download
```

Denne kommandoen henter de nyeste oversettelsene fra Crowdin og lagrer dem i henhold til stiene angitt i konfigurasjonsfilen.

## ⚙️ Beste praksis

### 🔑 Konsistent navngivning av nøkler

Sørg for at oversettelsesnøkler er konsistente på tvers av alle filer for å unngå forvirring og duplisering.

### 🧹 Regelmessig vedlikehold

Gå periodisk gjennom og rydd opp i ubrukte oversettelsesnøkler for å holde filene organiserte og håndterlige.

### 🛠 Automatiser opplastinger og nedlastinger

Integrer Crowdin CLI-kommandoene i CI/CD-pipelinen din for å automatisere opplasting av kildefiler og nedlasting av oversettelser, slik at oversettelsene alltid er oppdaterte.

Ved å følge denne guiden kan du sømløst integrere Crowdin i prosjektet ditt og sikre en effektiv og organisert tilnærming til å administrere internasjonaliseringsarbeidet.
