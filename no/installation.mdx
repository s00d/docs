## Krav

- **Node.js**: 18 eller nyere.
- **Nuxt**: 3.x eller 4.x.

Modulen støtter både Nuxt 3-prosjektstrukturen (`pages/**/*.vue`) og Nuxt 4-strukturen (`app/pages/**/*.vue`). Oversettelser ligger som konvensjon i prosjektroten (`locales/`), også når du bruker Nuxt 4-mappen `app/`.

## Installer Nuxt-modulen

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

Registrer den i `nuxt.config.ts`:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Se [Kom i gang](/quickstart) for en fullstendig gjennomgang, eller [Konfigurasjonsreferansen](/guides/configuration) for alle alternativene.

## Prosjektstruktur

Som standard forventer modulen:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

Filer på rotnivå slås sammen med hver sidespesifikk fil ved byggetid. Sidespesifikke filer opprettes automatisk hvis de mangler under `nuxt dev`.

## Nuxt 4-struktur

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

For å samlokalisere oversettelser under `app/`, sett `translationDir: 'app/locales'`.

## TypeScript

Modulen genererer omkringliggende typer for `useI18n`, `$t` og relaterte hjelpere basert på filene for standardlocale. Dette er aktivert som standard (`types: true`).

For sterkere typing av oversettelsesnøkler, se [`@i18n-micro/types-generator`](/integrations/types-generator).
