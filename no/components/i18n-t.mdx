---

`<i18n-t>` gjengir én oversettelse inn i et element. Bruk den når en oversettelse trenger komponenter inni seg (en lenke i en setning), en flertallsform, eller et formatert tall eller en formatert dato. Den løser nøkkelen for gjeldende rute, som `$t`.

## Props {#props}

| Prop | Type | Standard | Beskrivelse |
| --- | --- | --- | --- |
| `keypath` **\*** | `string` | — | Oversettelsesnøkkel som skal gjengis. |
| `plural` | `number \| string \| null` | — | Antall som velger flertallsformen. Sett den for å bruke `$tc` i stedet for `$t`. `null` betyr ikke satt. |
| `tag` | `string` | `'span'` | Element som skal gjengis. |
| `params` | `Record<string, string \| number \| boolean>` | — | Interpoleringsverdier som settes inn i oversettelsen. |
| `defaultValue` | `string` | `''` | Gjengis i stedet for komponenten når `hideIfEmpty` undertrykker en tom oversettelse. |
| `html` | `boolean` | `false` | Gjengi oversettelsen som HTML i stedet for tekst. Bare for oversettelser du kontrollerer: `params` escapes, oversettelsen gjør ikke det. |
| `hideIfEmpty` | `boolean` | `false` | Gjengi ingenting når oversettelsen løses til en tom streng. |
| `customPluralRule` | `PluralFunc` | `null` | Flertallsregel kun for dette elementet, som overstyrer den konfigurerte. Svaret brukes som det er; `null` gjengis tomt. |
| `number` | `number \| string \| null` | — | Formaterer verdien med `$tn` og sender den til oversettelsen som `{number}`, sammen med `params`. |
| `date` | `Date \| string \| number \| null` | — | Formaterer verdien med `$td` og sender den til oversettelsen som `{date}`, sammen med `params`. |
| `relativeDate` | `Date \| string \| number \| null` | — | Formaterer verdien med `$tdr` og sender den til oversettelsen som `{relativeDate}`, sammen med `params`. |

**\*** påkrevd.

## Gjengivelsesregler {#rendering-rules}

Det første tilfellet som passer, bestemmer resultatet:

1. `number` — oversettelsen med `{ ...params, number: $tn(number) }`.
2. `date` — oversettelsen med `{ ...params, date: $td(date) }`.
3. `relativeDate` — oversettelsen med `{ ...params, relativeDate: $tdr(relativeDate) }`.
4. `plural` — formen `$tc` velger, inkludert [`=0 `-markøren](/no/api/methods#$tc), med `{ ...params, count }`; eller `customPluralRule(keypath, count, params, locale, t)` når den er satt, som leser råverdien, markøren inkludert, og hvis svar brukes som det er, der `null` er tomt.
5. Ellers oversettelsen med `params`.

`null` regnes som ikke satt. I alle tilfeller:

- `defaultValue` står i stedet for en manglende nøkkel, i hver gren.
- `hideIfEmpty` gjengir `defaultValue` i stedet for et tomt resultat.
- `html` gjengir resultatet som HTML. `params` escapes, oversettelsen gjør ikke det; slots ignoreres.
- En `default`-slot mottar `{ translation }`, og navngitte slots ignoreres.
- Ellers erstatter hver navngitte slot hver `{name}`-plassholder, før en param med samme navn. En param-verdi som ser ut som en plassholder, forblir tekst.

Utdata fra `date` og `relativeDate` har `data-allow-mismatch="text"`, fordi serverens tidssone og klokke ikke er nettleserens. Sett [`timeZone`](/no/api/module-options#timezone) for å gjengi samme kalenderdato i begge; `relativeDate` avhenger av klokken, så den kan fortsatt avvike.

## Eksempel {#example}

```json
{
  "terms": "I accept the {link}.",
  "termsLink": "terms of use",
  "items": "no items | one item | {count} items"
}
```

```vue
<template>
  <i18n-t keypath="terms" tag="p">
    <template #link>
      <NuxtLink :to="$localePath('/terms')">{{ $t('termsLink') }}</NuxtLink>
    </template>
  </i18n-t>

  <i18n-t keypath="items" :plural="cart.length" />
</template>
```

`html` setter `innerHTML`: bruk det bare for oversettelser du kontrollerer. `params` escapes, så brukerdata er trygge der, og det samme gjelder en nøkkel som ikke fant noen oversettelse.
