title: "Astro-øyer"
description: "Oversettelser i Vue-, React-, Preact- og Svelte-øyer med @i18n-micro/astro."
---

En øy kjører i nettleseren, der serverens i18n-instans ikke finnes. `@i18n-micro/astro` lar siden velge nøklene en øy trenger, sende dem som én prop og lese dem i øya via en liten rammeverksadapter. Du får `t`, `tc`, `tn`, `td`, `tdr` og `has` i Vue-, React-, Preact- og Svelte-øyer, med bare de valgte strengene i HTML-en.

## Oppsett {#setup}

Sett først opp [Astro-integrasjonen og middlewaren](/no/integrations/astro-package#setup), og legg deretter til rammeverksintegrasjonen du bruker (`@astrojs/vue`, `@astrojs/react`, `@astrojs/preact`, `@astrojs/svelte`). Øyadapterne trenger det rammeverket som peer: `vue` `^3.3.0`, `react` `^16.8.0 || ^17.0.0 || ^18.0.0 || ^19.0.0`, `preact` `^10.0.0 || ^11.0.0` eller `svelte` `^4.0.0 || ^5.0.0`.

## Sende oversettelser til en øy {#pass-translations-to-an-island}

```astro
---
// src/pages/index.astro
import { getI18nProps } from '@i18n-micro/astro'
import Counter from '../components/Counter.vue'

const i18n = getI18nProps(Astro, ['counter.title', 'counter.apples'])
---

<Counter client:load i18n={i18n} />
```

`getI18nProps(Astro, keys?)` returnerer `{ locale, fallbackLocale, currentRoute, translations }` (typen `I18nClientProps`). Send inn nøklene øya bruker: hver av dem slås opp på serveren som `t()` (rute-, rot- og reserveordbøker), og bare nøkler som blir funnet, havner i HTML-en. Uten `keys` sendes alt `t()` kan svare på på denne siden, i hver øy, så 2000 rotnøkler blir omtrent 100 KB per øy; i utviklingsmodus vises en advarsel om dette over 20 KB.

Øyer oversetter bare fra det objektet. `t` returnerer nøkkelen for alt som ikke er sendt med, og lenkede meldinger slås ikke opp.

## Vue {#vue}

Kall `provideI18n(() => props.i18n)` i øyas rotkomponent og `useAstroI18n()` i barna. Vues `inject` ser ikke en verdi som er levert av samme komponent, så hooken må kjøre i et barn, ikke i roten:

```vue
<!-- src/components/Counter.vue -->
<script setup lang="ts">
import { provideI18n } from '@i18n-micro/astro/client/vue'
import type { I18nClientProps } from '@i18n-micro/astro'
import CounterBody from './CounterBody.vue'

const props = defineProps<{ i18n: I18nClientProps }>()
provideI18n(() => props.i18n)
</script>

<template><CounterBody /></template>
```

```vue
<!-- src/components/CounterBody.vue -->
<script setup lang="ts">
import { ref } from 'vue'
import { useAstroI18n } from '@i18n-micro/astro/client/vue'

const { t, tc } = useAstroI18n()
const count = ref(0)
</script>

<template>
  <h3>{{ t('counter.title') }}</h3>
  <button @click="count++">{{ tc('counter.apples', count) }}</button>
</template>
```

## React og Preact {#react-and-preact}

```tsx
// src/components/Counter.tsx
import { useState } from 'react'
import { I18nProvider, useAstroI18n } from '@i18n-micro/astro/client/react'
import type { I18nClientProps } from '@i18n-micro/astro'

function Body() {
  const { t, tc } = useAstroI18n()
  const [count, setCount] = useState(0)
  return <button onClick={() => setCount(count + 1)}>{t('counter.title')}: {tc('counter.apples', count)}</button>
}

export default function Counter({ i18n }: { i18n: I18nClientProps }) {
  return (
    <I18nProvider value={i18n}>
      <Body />
    </I18nProvider>
  )
}
```

For Preact importerer du `I18nProvider` og `useAstroI18n` fra `@i18n-micro/astro/client/preact`; API-et er det samme.

## Svelte {#svelte}

```svelte
<!-- src/components/Counter.svelte -->
<script lang="ts">
  import { createI18nStore, useAstroI18n } from '@i18n-micro/astro/client/svelte'
  import type { I18nClientProps } from '@i18n-micro/astro'

  export let i18n: I18nClientProps
  const { t, tc } = useAstroI18n(createI18nStore(i18n))
  let count = 0
</script>

<button on:click={() => count++}>{t('counter.title')}: {tc('counter.apples', count)}</button>
```

`useAstroI18n(store)` returnerer også `store` for `$store`-lesing i malen.

## Persisterte øyer {#persisted-islands}

En øy med `transition:persist` får nye props etter en navigasjon. React, Preact og Vue (gitt en getter) følger dem. I Svelte beholder du storen og sender dem videre: `const store = createI18nStore(i18n)`, `const { t } = useAstroI18n(store)`, deretter `$: store.set(i18n)` (med runes: `$effect(() => store.set(i18n))`).

## API {#api}

| Inngang | Eksporter |
| --- | --- |
| `@i18n-micro/astro` | `getI18nProps`, typen `I18nClientProps` |
| `@i18n-micro/astro/client/vue` | `provideI18n(props \| () => props)`, `useAstroI18n()` |
| `@i18n-micro/astro/client/react` | `I18nProvider` (prop `value`), `useAstroI18n()` |
| `@i18n-micro/astro/client/preact` | `I18nProvider` (prop `value`), `useAstroI18n()` |
| `@i18n-micro/astro/client/svelte` | `createI18nStore(props)`, `useAstroI18n(store)` |
| `@i18n-micro/astro/client` | de rene funksjonene `translate` og `hasTranslation`, uten rammeverk |

Hver `useAstroI18n` returnerer `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has`, `setLocale`, `setRoute` og `locale`. En øy har én flettet ordbok, så dens `has` er sann for en nøkkel `t` kan svare på, også fra reserve-localet; på serveren ser `has` bare på det aktive localet.
