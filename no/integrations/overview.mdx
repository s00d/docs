`@i18n-micro/*`-pakkene bringer oversettelseskjernen i Nuxt I18n Micro til Vue, React, Preact, Solid, Astro, VitePress og vanlig JavaScript. Bruk dem når appen din ikke er en Nuxt-app, eller når et skript eller en server utenfor Nuxt trenger de samme oversettelsesfilene. Alle pakkene deler én instansmodell, én kontrakt for ruteradaptere og de samme fire komponentene, som beskrives én gang på denne siden.

| Stakk | Pakke | Ruter-inngang |

Ruter-inngangen er en separat import, så en app uten ruter tar aldri med en i bunten.

`@i18n-micro/core`, `@i18n-micro/types` og `@i18n-micro/utils` installeres sammen med disse pakkene; du importerer dem sjelden direkte. Signaturene til alle eksporter står i den genererte [pakkereferansen](/no/api/packages/overview).

Hver pakke har en lekeplass (playground) under `packages/<name>/playground` i repositoriet.

## Instansen {#the-instance}

`createI18n(options)` returnerer én instans som holder ordbøkene, gjeldende locale og gjeldende rute. Alternativene er de samme i alle pakker:

| Alternativ | Type | Standard | Merknader |
| --- | --- | --- | --- |
| `locale` | `string` | påkrevd | Aktiv locale. |
| `fallbackLocale` | `string` | `locale` | Slås opp når en nøkkel mangler i `locale`. |
| `messages` | `Record<locale, Translations>` | `{}` | Rotordbøker (ruten `'index'`). |
| `routeMessages` | `Record<route, Record<locale, Translations>>` | `{}` | Ruteordbøker. Bare Runtime, React, Preact, Node og VitePress. |
| `plural` | `PluralFunc` | `defaultPlural` | Egendefinert flertallsregel. |
| `missingWarn` | `boolean` | `true` | `console.warn` i nettleseren for en manglende nøkkel, bare under utvikling. |
| `missingHandler` | `(locale, key, routeName) => void` | — | Kalles i stedet for advarselen. |
| `numberFormats` | `Record<locale, Record<name, Intl.NumberFormatOptions>>` | — | Navngitte formater: `tn(9.5, 'currency')`. |
| `datetimeFormats` | `Record<locale, Record<name, Intl.DateTimeFormatOptions>>` | — | Navngitte formater: `td(date, 'short')`. |
| `timeZone` | `string` | kjøretidens sone | IANA-sone for `td`-datoer; påvirker ikke `tdr`. Sett den slik at server og nettleser rendrer samme dato. |
| `now` | `() => number` | `Date.now` | Klokken til `tdr`. Gi hydreringen serverens tid slik at begge rendrer samme tekst. |
| `localeIso` | `Record<code, string>` | — | BCP 47-tagg som brukes for flertallsregler (`ua` → `uk-UA`). React, Preact og Solid henter den fra `iso` i providerens `locales`. |

Ordbøkene ligger i `i18n.storage.translations`, et `Map` med nøkler på formen `locale:route` (`en:index`, `en:about`).

En nøkkel slås opp i ordboken for gjeldende rute, deretter i rotordboken, først for `locale`, deretter for `fallbackLocale`. En manglende nøkkel returnerer selve nøkkelen (eller `defaultValue` du sender inn).

```ts
i18n.addTranslations('en', { nav: { home: 'Home' } }) // root, deep-merged
i18n.addRouteTranslations('en', 'about', { title: 'About us' }) // route chunk
i18n.addTranslations('en', { nav: { home: 'Start' } }, false) // replace instead of merge
i18n.setRoute('about')
i18n.t('title') // 'About us'
i18n.t('nav.home') // 'Start' (root key, still visible on the route)
```

### Oversett og formater {#translate-and-format}

| Metode | Returnerer |
| --- | --- |
| `t(key, params?, defaultValue?, routeName?)` | Verdien (streng, tall, objekt) med `{param}` interpolert. |
| `ts(...)` | Samme som `t`, som streng. |
| `tc(key, count \| params, defaultValue?)` | Flertallsform. |
| `tn(value, options \| name)` | `Intl.NumberFormat` i aktiv locale. |
| `td(value, options \| name)` | `Intl.DateTimeFormat`. |
| `tdr(value, options?)` | Relativ tid (`3 days ago`). |
| `has(key, routeName?)` | `true` når aktiv locale har nøkkelen (rute- eller rotordbok; reserven sjekkes ikke). |

`defaultPlural` deler verdien på `|` og velger formen på indeks `count`, begrenset til den siste; et negativt, desimalt eller `NaN`-antall velger den siste formen.

En egendefinert `plural` mottar `(key, count, params, locale, getter)`. Les verdien gjennom `getter(key)`; ikke del opp nøkkelen:

```ts
import type { PluralFunc } from '@i18n-micro/vue'

const plural: PluralFunc = (key, count, params, _locale, getter) => {
  const value = getter(key)
  if (typeof value !== 'string') return null
  const forms = value.split('|').map((form) => form.trim())
  return (count === 1 ? forms[0] : forms[1] ?? forms[0])!.replace('{count}', String(count))
}
```

## Ruteradapter {#router-adapter}

SPA-pakkene er ikke avhengige av en ruter. En ruteradapter (`I18nRoutingStrategy`) forteller dem hvordan de leser gjeldende sti, navigerer og bygger en lokalisert sti. De innebygde adapterne setter prefiks på alle locales unntatt `defaultLocale` (`/about`, `/de/about`).

| Medlem | Påkrevd | Brukes av |
| --- | --- | --- |
| `getCurrentPath(): string` | ja | sjekk av aktiv lenke (etter side; spørrestreng og hash teller ikke), `switchLocale` (beholder dem) |
| `push({ path }): void` | ja | `switchLocale`, `<I18nLink>` uten `linkComponent`, `<I18nSwitcher>` |
| `replace({ path }): void` | ja | — |
| `resolvePath(to, locale)` | nei | `localePath`, `localeRoute`, `<I18nLink>`; uten den returneres stier uendret |
| `linkComponent` | nei | `<I18nLink>` rendrer den (f.eks. `RouterLink`) i stedet for `<a>` |
| `getRoute()` | nei | `{ fullPath, query }` for SEO-hjelpere |

`push` og `replace` er påkrevd i Vue, React, Preact og Solid. Astro har sin egen adapter på serversiden med valgfrie `push`/`replace` (se [Astro](/no/integrations/astro-package#router-adapter)).

En minimal adapter for en hvilken som helst historikkbasert ruter:

```ts
import type { I18nRoutingStrategy } from '@i18n-micro/react'

const locales = ['en', 'de']
const stripLocale = (path: string) => path.replace(/^\/(en|de)(?=\/|$)/, '') || '/'

export const historyAdapter: I18nRoutingStrategy = {
  getCurrentPath: () => window.location.pathname + window.location.search + window.location.hash,
  push: ({ path }) => window.history.pushState({}, '', path),
  replace: ({ path }) => window.history.replaceState({}, '', path),
  resolvePath: (to, locale) => {
    const path = stripLocale(typeof to === 'string' ? to : to.path || '/')
    return locale === 'en' ? path : `/${locale}${path === '/' ? '' : path}`
  },
}
```

## Komponenter {#components}

Vue, React, Preact og Solid leveres med de samme fire komponentene. Propsene deres samsvarer; React, Preact og Solid sender andre props videre til rotelementet.

### `<I18nT>` {#&lt;i18nt&gt;}

| Prop | Type | Merknader |
| --- | --- | --- |
| `keypath` | `string` | påkrevd |
| `params` | `object` | interpolasjonsverdier |
| `plural` | `number \| string` | rendrer `tc(keypath, count)` |
| `number` | `number \| string` | sender `tn(number)` som `{number}` |
| `date` | `Date \| string \| number` | sender `td(date)` som `{date}` |
| `relativeDate` | `Date \| string \| number` | sender `tdr(relativeDate)` som `{relativeDate}` |
| `tag` | `string` | innpakningselement, standard `span` |
| `html` | `boolean` | render oversettelsen som HTML; den må være til å stole på, parametere escapes |
| `defaultValue` | `string` | brukes i stedet for en manglende nøkkel, og rendres uten innpakning når `hideIfEmpty` skjuler en tom verdi |
| `hideIfEmpty` | `boolean` | render ingenting for en tom oversettelse |
| `customPluralRule` | `PluralFunc` | flertallsregel for dette elementet |

Bare én formateringsprop gjelder, sjekket i denne rekkefølgen: `number`, `date`, `relativeDate`, `plural`.

#### Rik tekst {#rich-text}

En `{placeholder}` kan inneholde et element. I Vue er det en navngitt slot; i React, Preact og Solid gir propen `components` elementer, eller funksjoner som returnerer et element, etter navn. Uansett slår det en parameter med samme navn, fungerer i alle grener og overlever en locale som endrer rekkefølgen på plassholderne.

```tsx
// { "terms": "I accept the {link} of {company}" }
<I18nT keypath="terms" params={{ company: 'ACME' }} components={{ link: <a href="/terms">terms</a> }} />
```

I Solid sender du en funksjon når en plassholder gjentas: én node kan bare stå ett sted. `children` erstatter teksten; som funksjon får de `{ translation }`, akkurat som Vues standard-slot. `html` ignorerer alt dette.

### `<I18nLink>` {#&lt;i18nlink&gt;}

| Prop | Type | Merknader |
| --- | --- | --- |
| `to` | `string \| { path }` | lokaliseres gjennom adapterens `resolvePath` |
| `activeStyle` | stilobjekt | slås sammen over `style` på gjeldende side; React, Preact og Solid bruker den også på en seksjon over |
| `localeRoute` | funksjon | overstyrer `resolvePath` for denne lenken |

Eksterne URL-er (`https://`, `mailto:`, `tel:`) rendres som `<a target="_blank" rel="noopener noreferrer">`; din egen `target` eller `rel` vinner. `onClick` kjører alltid. Et klikk med modifikatortast, en annen museknapp eller en `target` overlates til nettleseren.

### `<I18nSwitcher>` {#&lt;i18nswitcher&gt;}

En nedtrekksliste over aktiverte locales (locales med `disabled: true` skjules) med innebygde standardstiler. Elementene er lenker, med `lang`, `hreflang` og `dir` fra locale-en. Som standard setter et klikk på en av dem locale og kaller adapterens `push` med den lokaliserte gjeldende stien; en `switchLocale`-prop erstatter den handlingen. Med en `localeRoute` og ingen ruter følger nettleseren lenken. Escape eller et klikk utenfor lukker den.

| Prop | Merknader |
| --- | --- |
| `locales`, `currentLocale`, `getLocaleName` | overstyrer de leverte verdiene |
| `switchLocale(code)` | erstatter det innebygde byttet |
| `localeRoute` | erstatter `resolvePath` |
| `customLabels` | `{ de: 'DE' }` |
| `customWrapperStyle`, `customButtonStyle`, `customDropdownStyle`, `customItemStyle`, `customLinkStyle`, `customActiveLinkStyle`, `customDisabledLinkStyle`, `customIconStyle` | stiloverstyringer |

### `<I18nGroup>` {#&lt;i18ngroup&gt;}

En `<div class="i18n-group">` som gir en `t` med prefiks til barna sine. Den setter **ikke** prefiks på `<I18nT>` eller `t()`-kall inni den; bare `t`-en den sender ned har prefiks.

| Prop | Merknader |
| --- | --- |
| `prefix` | påkrevd, f.eks. `'profile'` |
| `groupClass` | ekstra klasse på innpakningen |

`t` med prefiks kommer gjennom en scoped slot i Vue (`v-slot="{ t }"`) og et render-prop-barn i React, Preact og Solid (`{({ t }) => …}`).

## Typede nøkler {#typed-keys}

`t()` godtar hvilken som helst streng. For å få autofullføring for nøklene dine genererer du en deklarasjon med [typegeneratoren](/no/integrations/types-generator). Nøkler foreslås, men håndheves ikke, og parametere er ikke typet.

## Sammenlignet med Nuxt-modulen {#compared-with-the-nuxt-module}

Pakkene har ingen filbasert ruting, ingen server-middleware og ingen oversettelseslaster: du bestemmer når JSON skal lastes (`import`, `fetch`, eller `@i18n-micro/node` på serveren) og hvilken ruteradapter som skal brukes. Locale-deteksjon, SEO-meta og rutegenerering er Nuxt-funksjoner; Astro har sin egen middleware for deteksjon og `useLocaleHead` for SEO.
