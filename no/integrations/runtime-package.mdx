`@i18n-micro/runtime` er den rammeverksuavhengige i18n-instansen: ordbøker, `t()`, flertallsformer, `Intl`-formatering og et abonnement på endringer, uten `fs` og uten rammeverk. Bruk den i ren TypeScript, en web worker, en edge-funksjon eller som grunnlag for din egen binding. React-, Preact-, Node- og Astro-pakkene utvider den samme klassen.

## Installasjon {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/runtime
```

```bash npm
npm install @i18n-micro/runtime
```

```bash yarn
yarn add @i18n-micro/runtime
```

</CodeGroup>

Ingen peer-avhengigheter. For oversettelsesfiler på disk bruker du [`@i18n-micro/node`](/no/integrations/nodejs-package).

## Oppsett {#setup}

```ts
import { createI18n } from '@i18n-micro/runtime'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    en: { greeting: 'Hello, {name}!', apples: 'no apples | one apple | {count} apples' },
    de: { greeting: 'Hallo, {name}!' },
  },
  routeMessages: {
    about: { en: { title: 'About us' } },
  },
})
```

Alle alternativer (`plural`, `missingWarn`, `missingHandler`, `numberFormats`, `datetimeFormats`) er listet i [instansen](/no/integrations/overview#the-instance).

## Oversette {#translate}

```ts
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!'
i18n.tc('apples', 5) // '5 apples'
i18n.tn(1234.5) // '1,234.5'

i18n.setRoute('about')
i18n.t('title') // 'About us' (route dictionary)
i18n.t('greeting', { name: 'Ada' }) // 'Hello, Ada!' (root, still visible)
```

Last inn flere ordbøker senere:

```ts
i18n.loadMessages({ fr: { greeting: 'Bonjour, {name} !' } }, { about: { fr: { title: 'À propos' } } })
i18n.addTranslations('fr', { nav: { home: 'Accueil' } }) // deep merge; pass false to replace

await i18n.loadFromUrl('/locales/fr.json', { locale: 'fr' })
await i18n.loadFromUrl('/locales/pages/about/fr.json', { locale: 'fr', routeName: 'about' })
await i18n.loadFromUrls([
  { url: '/locales/en.json', locale: 'en' },
  { url: '/locales/de.json', locale: 'de' },
])
```

`loadFromUrl` bruker `fetch` (send med `init` for headere) og kaster en feil ved et svar som ikke er OK. `loadFromUrls` laster én etter én.

## Bytte locale {#switch-locale}

```ts
i18n.locale = 'de'
i18n.t('greeting', { name: 'Ada' }) // 'Hallo, Ada!'
```

Endringer i locale, rute og ordbok varsler abonnenter, og det er slik rammeverksbindinger rendrer på nytt:

```ts
const stop = i18n.subscribe(() => {
  document.querySelector('#greeting')!.textContent = i18n.t('greeting', { name: 'Ada' }) as string
})
i18n.locale = 'fr'
stop()
```

`getSnapshot()` returnerer en streng som endres ved hvert varsel (for stores i `useSyncExternalStore`-stil).

## Per forespørsel {#per-request}

Instansen har ett locale og én rute. På en server skal du ikke bytte en delt instans per forespørsel: to samtidige forespørsler ville se hverandres locale. `i18n.fork(locale)` gir en forespørsel sin egen: eget locale, egen reserve og egen rute; de samme ordbøkene, formaterne og reglene. En fork koster det samme uansett hvor mange ordbøker det finnes. En fork ser skrivinger til forelderen fram til sin første egne skriving, og dens skrivinger blir værende i den. [Node.js](/no/integrations/nodejs-package#per-request) legger til `run`.

## API {#api}

| Medlem | Merknader |
| --- | --- |
| `t`, `ts`, `tc`, `tn`, `td`, `tdr`, `has` | se [Oversette og formatere](/no/integrations/overview#translate-and-format) |
| `locale`, `fallbackLocale` | get/set |
| `currentRoute`, `setRoute(name)`, `getRoute()` | aktiv rute, standard `'index'` |
| `loadMessages(messages?, routeMessages?)` | flett mange locales og ruter samtidig |
| `addTranslations(locale, tree, merge = true)`, `addRouteTranslations(locale, route, tree, merge = true)` | |
| `loadFromUrl(url, { locale?, routeName?, init? })`, `loadFromUrls(entries)` | `fetch` JSON |
| `hasTranslation(key)` | aktivt locale, hvilken som helst rute (i motsetning til `has`, som sjekker aktiv rute og rot) |
| `setTranslation(key, value)`, `resolveTranslations()` | skriv én nøkkel; les det flettede treet |
| `clear()`, `clearCache()` | fjern alle ordbøker |
| `subscribe(cb)`, `getSnapshot()` | endringsvarsler |
| `storage` | `{ translations: Map<'locale:route', Translations> }` |

En kode som ikke er en språkkode, får flertallsformene sine fra `localeIso: { ua: 'uk-UA' }`; `localeIsoMap(locales)` bygger dette fra oppføringene i en locale-liste som har en `iso`.

Moduleksporter: `createI18n`, `I18n`, `fetchJsonTranslations`, `FormatService`, `interpolate`, `localeIsoMap` og typene `I18nOptions`, `LoadFromUrlOptions`, `LoadFromUrlEntry`, `TranslationStorage`, `Translations`, `Locale`, `PluralFunc`. Fullstendige signaturer: [pakkereferanse](/no/api/packages/runtime).
