---
title: "Typegenerator"
description: "Generer TypeScript-autofullføring for oversettelsesnøkler fra JSON-filene dine, i Nuxt eller et hvilket som helst Vite-prosjekt."
---

`@i18n-micro/types-generator` leser hver JSON-fil i oversettelsesmappen din og skriver en deklarasjon som lister opp alle nøkler. Legg den til når du vil at editoren skal foreslå nøkler i `t()`, `$t()` og `<I18nT keypath>`. Den fungerer som en Nuxt-modul og som en Vite- eller Rollup-plugin, og genererer på nytt når en fil endres.

## Installer {#install}

<CodeGroup>

```bash pnpm
pnpm add -D @i18n-micro/types-generator
```

```bash npm
npm install -D @i18n-micro/types-generator
```

```bash yarn
yarn add -D @i18n-micro/types-generator
```

</CodeGroup>

Peer-avhengighet: `@nuxt/kit` `^3.18.0 || ^4.0.0`. Bare `/nuxt`-inngangen importerer den; i et rent Vite-prosjekt kan peer-advarselen ignoreres.

## Nuxt {#nuxt}

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro', '@i18n-micro/types-generator/nuxt'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

Modulen skriver `.nuxt/types/i18n-micro.d.ts`, og Nuxt legger den til i typekonteksten; du trenger ikke inkludere noe manuelt. Den leser `i18nTypes.translationDir`, ellers der `nuxt-i18n-micro` leser oversettelser: `translationDir` (fra `i18n` eller inline modulalternativer, standard `'locales'`) i hvert lag, og `additionalTranslationDirs`. Redigering av en JSON-fil i den mappen genererer typene på nytt i `nuxi dev`. `i18nTypes.outputFile` ignoreres i Nuxt (en advarsel sier fra om det).

## Vite {#vite}

`I18nTypesPlugin` er en Vite-plugin, som Rollup også godtar. For andre bundlere kaller du `generateTypes` i et skript.

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { I18nTypesPlugin } from '@i18n-micro/types-generator'

export default defineConfig({
  plugins: [
    vue(),
    I18nTypesPlugin({
      srcDir: process.cwd(),
      translationDir: 'src/locales',
      outputFile: 'src/i18n-micro.d.ts',
    }),
  ],
})
```

| Alternativ | Påkrevd | Merknader |
| --- | --- | --- |
| `srcDir` | ja | Basismappe; `translationDir` løses opp relativt til den. |
| `translationDir` | ja | Mappe med JSON-filene (inkludert undermapper som `pages/`), eller en liste med mapper. |
| `outputFile` | nei | Hvor deklarasjonen skal skrives; standard `<srcDir>/i18n-micro.d.ts`. |

Pluginen genererer én gang ved byggestart og, på utviklingsserveren, på nytt 300 ms etter en endring i mappen. Sørg for at `include` i `tsconfig.json` dekker utdatafilen.

## Bruk nøklene {#use-the-keys}

Den genererte filen utvider `DefineLocaleMessage` i `@i18n-micro/types`, som gjør `TranslationKey` om til nøklene dine:

```ts
declare module '@i18n-micro/types' {
  export interface DefineLocaleMessage {
    nav: object
    'nav.home': string
    'profile.title': string
  }
}
```

Nøklene er de som `t()` svarer på, også objekter, fra hvert språk og hver sidefil, med typen til JSON-verdien deres. `TranslationKey` er unionen av disse nøklene pluss en hvilken som helst streng, så du får autofullføring, ikke feil: en feilstavet eller dynamisk nøkkel kompilerer fortsatt. Parametere og returverdier er ikke typet.

For dynamiske nøkler under et kjent prefiks snevrer `ScopedKey<'prefix'>` inn til de samsvarende nøklene:

```ts
import type { ScopedKey } from '@i18n-micro/types'

const statusText = (status: string) => t(`status.${status}` as ScopedKey<'status'>)
```

`TranslationKey` og `ScopedKey` kommer fra `@i18n-micro/types` (React, Preact og Solid re-eksporterer `TranslationKey`; Vue gjør det ikke).

## API {#api}

| Eksport | Inngang | Merknader |
| --- | --- | --- |
| `I18nTypesPlugin(options)` | `@i18n-micro/types-generator` | Vite- og Rollup-plugin |
| `generateTypes(options)` | `@i18n-micro/types-generator` | skriver filen, returnerer stien |
| `getTypesString(options)` | `@i18n-micro/types-generator` | returnerer deklarasjonen uten å skrive |
| `formatKeyProperty(key)` | `@i18n-micro/types-generator` | hjelpefunksjon |
| Nuxt-modul (`configKey: 'i18nTypes'`) | `@i18n-micro/types-generator/nuxt` | alternativ `translationDir` |

Fullstendige signaturer: [pakkereferanse](/no/api/packages/types-generator).
