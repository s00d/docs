`@i18n-micro/devtools-ui` er oversettelseseditoren fra Nuxt DevTools-fanen, pakket som en webkomponent med en Vite-plugin. Legg den til i et Vue-, React-, Preact-, Solid- eller Astro-prosjekt for å bla gjennom og redigere JSON-filene i oversettelsesmappen fra nettleseren under utvikling. Nuxt-apper har den allerede i [Nuxt DevTools](/no/guide/devtools).

![DevTools UI: et filtre og en editor med teksten fra standard-localet ved siden av hver nøkkel](/images/devtools/02-translations-editor-dark.webp)

## Oppsett {#setup}

```ts
// vite.config.ts
import { defineConfig } from 'vite'
import { i18nDevToolsPlugin } from '@i18n-micro/devtools-ui/vite'

export default defineConfig({
  plugins: [i18nDevToolsPlugin({ translationDir: 'src/locales' })],
})
```

| Alternativ | Standard | Merknader |
| --- | --- | --- |
| `translationDir` | `'src/locales'` | Mappe med JSON-filene, relativt til Vite-roten. |
| `base` | `'/__i18n_api'` | Basesti for API-endepunktene. |
| `injectButton` | `true` | Legg til en flytende knapp på sider som serveres gjennom Vites `index.html`-transformasjon. Astro har ikke slike sider: se nedenfor. |
| `defaultLocale` | første locale-fil i `translationDir` | Rapporteres av `/config`. |
| `fallbackLocale` | `defaultLocale` | Rapporteres av `/config`. |

Pluginen kjører bare på utviklingsserveren (`apply: 'serve'`); et produksjonsbygg inneholder ingenting fra den. Knappen åpner `/__i18n_devtools.html`, som leser og lagrer filer via pluginens endepunkter:

| Endepunkt | Gjør |
| --- | --- |
| `GET <base>/translations` | alle ordbøker under `translationDir`, etter relativ sti |
| `POST <base>/save` | body `{ file, content }`; overskriver en eksisterende `.json` i `translationDir`, 403 for alt annet. Den oppretter aldri en fil |
| `GET <base>/config` | `{ defaultLocale, fallbackLocale, locales, translationDir }`; `locales` kommer fra rotfilene i `translationDir` |

Endepunktene svarer bare devtools-siden: en forespørsel fra en annen opprinnelse eller vert gir `403`, og `/save` godtar bare `application/json` (`415`). Siden får beskjed om filendringer over Vites HMR-socket.

I Astro legger du til integrasjonen i stedet for pluginen. Den legger til en app i utviklingsverktøylinjen:

```ts
// astro.config.mjs
import { defineConfig } from 'astro/config'
import { i18nDevToolsIntegration } from '@i18n-micro/devtools-ui/vite'

export default defineConfig({
  integrations: [i18nDevToolsIntegration({ translationDir: 'src/locales' })],
})
```

Lagring skriver bare filen. En app som importerer JSON-en via Vite, får den via HMR; for redigeringer som brukes direkte på den kjørende instansen, bruk en bro.

## Bro til en kjørende instans {#bridge-to-a-live-instance}

For å bygge inn editoren på din egen side og få redigeringer brukt på den kjørende instansen umiddelbart, oppretter du en bro fra en adapter og sender den til elementet `<i18n-devtools-ui>`:

```ts
import { createBridge, register } from '@i18n-micro/devtools-ui'
import { i18n, locales } from './i18n' // a runtime, React, Preact or Solid instance

register() // defines <i18n-devtools-ui> once

const bridge = createBridge({
  adapter: {
    getRouteCache: () => Object.fromEntries(i18n.storage.translations),
    addTranslations: (locale, content, merge) => i18n.addTranslations(locale, content, merge),
    addRouteTranslations: (locale, route, content, merge) => i18n.addRouteTranslations(locale, route, content, merge),
    subscribe: (cb) => i18n.subscribe(cb),
    getCurrentLocale: () => i18n.locale,
  },
  locales,
  defaultLocale: 'en',
  translationDir: 'src/locales',
})

const el = document.createElement('i18n-devtools-ui') as HTMLElement & { bridge: typeof bridge }
el.bridge = bridge
document.body.append(el)
```

`getRouteCache` må returnere ordbøkene med nøkler på formen `locale:route` (`en:index`, `en:blog-post`), som er det `i18n.storage.translations` inneholder. For en Vue-instans bruker du `i18n.global.getRouteCache()` og `i18n.global.subscribeToChanges(cb)`.

`saveTranslation` oppdaterer instansen først, og sender deretter en POST til `<base>/save`. Når det ikke finnes noe endepunkt (et statisk forhåndsvisningsbygg) eller utviklingsserveren ikke kan nås, lagres redigeringen i `localStorage`; enhver annen lagringsfeil gjenoppretter den forrige ordboken og kaster en feil.

| --- | --- |
| `i18nDevToolsPlugin(options)`, `i18nDevToolsIntegration(options)` | `@i18n-micro/devtools-ui/vite` |
