### 説明 {#description}

`untestutils/perf` を使い、共通の辞書プロファイルのもとで **素の Nuxt**、**i18n-micro**、**`@nuxtjs/i18n`** を比較します。

注目点：ビルド時間、ピーク RSS、デプロイ可能な **コード vs 翻訳（アセット）vs 合計**、そして負荷（Artillery）。

### 測定方法に関する注記 {#methodology-notes}

- 指標は **フィクスチャごとに 3 回連続実行した平均値** です（交互実行ではありません）。
- **成果物**：強制的な `nuxi build` 後の Nitro node-server `.output/server/index.mjs`。`nuxt-i18n-micro` は **ビルド済みモジュールの dist** です（`dev:prepare` の jiti スタブではありません）。[ベンチマークの測定方法](https://s00d.github.io/nuxt-i18n-micro/contributing/performance-methodology) を参照してください。
- **翻訳** = `bundle.asset`（ロケール JSON、`chunks/raw/`、`isTranslationFile` に一致するロケールチャンク）。
- **コード** はソースマップ（`*.map`）を除外します。フィクスチャはリポジトリからモジュールをリンクしているため、Nitro はモジュールについては完全なマップを書き出し、npm 依存関係については書き出しません。
- **plain-nuxt** は同じ量の末端データを静的 JSON として配信します。負荷時は I/O が重くなりますが、これは「i18n のオーバーヘッド」ではありません。
- 負荷プロファイル `--load full`：ウォームアップ 6s@6 + メイン 60s@60、上限なし（従来どおり）。
- クールダウン `--cool fast`（測定方法のドキュメントを参照）。
- `runs` 回のビルドはそれぞれ **強制** 実行されます（ウォームキャッシュでビルド時間がゼロになることはありません）。
- 表中の Artillery の **エラー率** は、負荷メトリクスにおける HTTP ステータスエラーです。グラフには `vusers.failed`（飽和時のクライアントタイムアウト）もプロットされており、HTTP エラー率が 0% のままでもこちらは高くなることがあります。
### 実行 {#runs}

以下のすべての指標は **3 回の実行の平均値** です。

### フィクスチャのプロファイル {#fixture-profile}

| 項目 | 値 |
|------|-------|
| ロケール | **4**（`en`、`de`、`ru`、`fr`） |
| ページ | **2**（`index`、`page`） |
| インデックスのツリー | 深さ **5**、分岐 **7** → ロケールあたり **16,807** 個の末端キー |
| その他のページ | 深さ **5**、分岐 **6** → ページ・ロケールあたり **7,776** 個の末端キー |
| 目的 | デフォルトの CLI プロファイル（`--locales 4 --keys 10000`）。回帰検出用の負荷では値を引き上げます |

辞書は `scripts/perf-fixtures/perf-shared/runtime.json`（CLI が書き出します）から取得されるため、3 つのフィクスチャすべてが揃った状態に保たれます。

## 注記 {#notes}

- 共通プロファイル：4 ロケール × 2 ページ × 約 16.8k のインデックス末端キー。
- 負荷：プログラムによる Artillery のみ — ウォームアップ **6s@6** + メイン **60s@60**、VU 上限なし（従来の YAML の測定方法）。パスはランタイムプロファイルから取得 — `scripts/src/perf/load.ts` を参照。
- クールダウン：ビルド後 2 秒、実行間 3 秒、フィクスチャ間 5 秒。ビルドは毎回強制実行されるため、平均値がキャッシュヒットで薄まることはありません。
- 日常的な再実行：`pnpm test:performance`（`--load short --cool fast`）。
- このページの再生成：`pnpm -C scripts cli performance --load full --only all --runs 3`。
- フラグ：`--locales N --keys K --only all|micro|i18n|plain --runs N --skip-load --cool fast|strict`。
