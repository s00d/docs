このページでは、`@nuxtjs/i18n` アプリを nuxt-i18n-micro に対応付けます: オプション、ヘルパー、ファイル構成です。既存のアプリでモジュールを入れ替える際に使用してください。URL はそのまま維持でき(戦略名は同じです)、翻訳はページごとの JSON ファイルに移動します。

<Tip>

**nuxt-i18n-micro 自体をアップグレードしますか?** — [アップグレード](/ja-jp/guide/upgrade)を参照してください。

</Tip>

## モジュールを入れ替える {#swap-the-module}

```bash
npm uninstall @nuxtjs/i18n
npm install nuxt-i18n-micro
```

```ts
// nuxt.config.ts — before
export default defineNuxtConfig({
  modules: ['@nuxtjs/i18n'],
  i18n: {
    locales: [
      { code: 'en', language: 'en-US', file: 'en.json' },
      { code: 'de', language: 'de-DE', file: 'de.json' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    langDir: 'locales',
    detectBrowserLanguage: { useCookie: true, cookieKey: 'i18n_redirected', redirectOn: 'root' },
  },
})
```

```ts
// nuxt.config.ts — after
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US' },
      { code: 'de', iso: 'de-DE' },
    ],
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    translationDir: 'locales',
    localeCookie: 'i18n_redirected',
    autoDetectPath: '/',
  },
})
```

## オプション {#options}

| `@nuxtjs/i18n` | nuxt-i18n-micro |
| --- | --- |
| `locales[].code` | `locales[].code` |
| `locales[].language`(v9 より前は `iso`) | `locales[].iso` |
| `locales[].name` | `locales[].displayName` |
| `locales[].dir` | `locales[].dir` |
| `locales[].domain` | `locales[].baseUrl`(スキームを含むオリジン) |
| `locales[].domainDefault` | `locales[].baseDefault` |
| `differentDomains`, `multiDomainLocales` | 不要: `baseUrl` だけでホストによるルーティングが行われます。[レイヤーとドメイン](/ja-jp/guide/layers#multiple-domains)を参照 |
| `locales[].file` / `files`, `langDir`, `lazy` | `translationDir`。ファイルは名前で検出され、常にページごとに読み込まれます |
| `defaultLocale`, `strategy` | 同じ名前、同じ 4 つの値 |
| `baseUrl` | `metaBaseUrl` |
| `customRoutes: 'config'` + `pages` | `globalLocaleRoutes` |
| `detectBrowserLanguage: false` | `redirects: false`(リダイレクトなし)または `autoDetectLanguage: false`(ヘッダーを無視) |
| `detectBrowserLanguage.useCookie` / `cookieKey` | `localeCookie: '<name>'`(`null` で Cookie を無効化) |
| `detectBrowserLanguage.redirectOn: 'root'` | `autoDetectPath: '/'`(デフォルト) |
| `detectBrowserLanguage.redirectOn: 'no prefix'` | `autoDetectPath: 'no_prefix'` |
| `detectBrowserLanguage.redirectOn: 'all'` | `autoDetectPath: '*'` |
| `vueI18n` 設定ファイル(`fallbackLocale`, `numberFormats`, `datetimeFormats`) | `i18n` 内の `fallbackLocale`, `numberFormats`, `datetimeFormats` |

`alwaysRedirect` はありません。Cookie が設定されていれば、`/` は訪問のたびにそれに従います。全一覧は[モジュールオプション](/ja-jp/api/module-options)を、検出ルールは[ロケール検出](/ja-jp/guide/locale-detection)を参照してください。

## ヘルパーとコンポーザブル {#helpers-and-composables}

| `@nuxtjs/i18n` / vue-i18n | nuxt-i18n-micro(テンプレート / `useI18n()`) |
| --- | --- |
| `const { t } = useI18n()` | `const { t } = useI18n()`、テンプレートでは `$t` |
| `t('key', count)`, `tc` | `$tc('key', count)` |
| `te('key')` | `$has('key')` |
| `n(value, 'currency')`, `d(date, 'short')` | `$tn(value, 'currency')`, `$td(date, 'short')` |
| — | `$tdr(date)`: 相対時間(「3 日後」) |
| `locale.value` | `$getLocale()` |
| `locales.value` | `$getLocales()` |
| `setLocale('de')` | `$switchLocale('de')` |
| `useLocalePath()('about')` | `$localePath({ name: 'about' })` |
| `useLocaleRoute()` | `$localeRoute()` |
| `useSwitchLocalePath()('de')` | `$switchLocalePath('de')` |
| `useSetI18nParams()` | `$setI18nRouteParams()` |
| `useLocaleHead()` | `meta: true` で自動。カスタムの head には [`useLocaleHead`](/ja-jp/composables/useLocaleHead) |
| `defineI18nRoute({ paths: { de: '/ueber-uns' }, locales: [...] })` | `$defineI18nRoute({ localeRoutes: { de: '/ueber-uns' }, locales: [...] })` |
| `<NuxtLinkLocale to="about">` | `<i18n-link :to="{ name: 'about' }">` |
| `<i18n-t>` | `<i18n-t>`(スロットが `{name}` プレースホルダーを埋めます) |
| サーバールートでの `$i18n` | `useTranslationServerMiddleware(event)`。[サーバールートと API](/ja-jp/guide/server-side-translations) を参照 |

`useI18n()` は自動インポートされます。`$defineI18nRoute` は `$` を付けたままにする必要があります。ビルドがその呼び出しを読み取るためです。すべてのヘルパー: [メソッド](/ja-jp/api/methods)。

## 翻訳ファイル {#translation-files}

ロケールごとの 1 つの大きなファイルのキーを、ルートファイルとページごとのファイルに移動します:

```text
locales/
├── en.json              # keys used on many pages (nav, footer)
├── de.json
└── pages/
    ├── index/en.json    # keys of pages/index.vue
    └── about/en.json    # keys of pages/about.vue
```

すべてをルートファイルに置いたままにしても動作し、最初のステップとしてはそれが最も手早い方法です。分割するまでは `disablePageLocales: true` を設定してください。[翻訳ファイル](/ja-jp/guide/translations)を参照してください。

### メッセージ構文 {#message-syntax}

| vue-i18n | nuxt-i18n-micro |
| --- | --- |
| `{name}` 名前付き補間 | 同じ |
| `car \| cars`(2 形式: 1 → 最初) | 形式は 0 から数えて個数で選ばれます: `no cars \| one car \| {count} cars` と記述します |
| `@:other.key` リンクメッセージ | 非対応: テキストを繰り返すか、コードで組み立ててください |
| `@.upper:` 修飾子 | 非対応: コードでフォーマットするか `<i18n-t>` を使用してください |
| `{'@'}` リテラルエスケープ | 不要: 置換されるのは `{word}` トークンのみです |
| JS/TS メッセージファイル | JSON のみ |

複数形ルールは [`plural`](/ja-jp/api/module-options#plural) オプションで置き換えられます。

## 切り替え後の確認 {#check-after-the-switch}

- 以前のすべての URL が引き続き解決されること。戦略名は一致しており、カスタムパスは `globalLocaleRoutes` または `$defineI18nRoute` に移ります。
- `hreflang`、canonical、`og:locale` は `meta: true` で標準で出力されます。手書きのものは削除してください。
- JSON のパースエラーはファイルパスをログに出力します。開発環境では、キーが見つからない場合にブラウザーのコンソールに警告が出力されます。
