![v2.14 リリース](/images/2.14.0.png)

Node.js、Vue 3、Astro 向けのまったく新しいインテグレーションを備えた **v2.14.1** を発表します！ これらのパッケージは、同じコアロジックを共有して一貫性とパフォーマンスを保ちながら、同じ強力な i18n 機能をお気に入りのフレームワークにもたらします。

## 新機能 {#what’s-new}

- **@i18n-micro/node** - あらゆる Node.js アプリケーション、CLI ツール、バックエンドサービスで i18n 翻訳を使用できます
- **@i18n-micro/vue** - リアクティブな翻訳とルート固有のサポートを備えた、国際化のための Vue 3 プラグイン
- **@i18n-micro/astro** - 完全な TypeScript サポートを備えた、国際化のための Astro インテグレーション
- **@i18n-micro/types-generator** - 完全な型安全性と IDE のオートコンプリートを備えた、翻訳キー用の TypeScript 型の自動生成

## 主な機能 {#key-features}

すべてのインテグレーションは、同じコアの利点を共有しています。

- 軽量かつ高性能
- ルート固有の翻訳のサポート
- 組み込みの複数形処理
- 数値、日付、相対時間のフォーマット
- 完全な TypeScript サポート
- 同じ JSON 翻訳ファイル構造

**Types Generator** は、さらに開発者体験を向上させます。

- JSON 翻訳ファイルからの型の自動生成
- コンパイル時に検証される型安全な翻訳キー
- IDE のオートコンプリートを完全サポート
- 翻訳ファイル変更時のホットリロード
- ランタイムオーバーヘッドゼロ

詳細なドキュメントと例については、[リポジトリ](https://github.com/s00d/nuxt-i18n-micro)を訪れるか、[ドキュメント](https://s00d.github.io/nuxt-i18n-micro/)をご覧ください。
