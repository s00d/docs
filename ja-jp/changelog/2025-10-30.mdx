**日付**: 2025-10-30

**バージョン**: `v2.0.0`

![v2.0.0 release](/images/2.0.0.png)

開発環境で翻訳ファイルのサーバーサイド HMR を導入しました。JSON 翻訳ファイルが変更されると、サーバーキャッシュは影響を受けるキーのみを無効化し、以降のリクエストはすぐに最新のデータを受け取ります。再起動は不要です。

## 新機能 {#what’s-new}

- 翻訳ファイルのサーバーサイド HMR
- ページ/ロケール単位での即時キャッシュ無効化
- コンテンツ編集中のシームレスな開発体験

## 仕組み {#how-it-works}

- `src/runtime/server/plugins/watcher.dev.ts` のウォッチャーが `<rootDir>/<translationDir>/**/*.json` を監視します
- ページファイル(例: `pages/<page>/<locale>.json`)は `_locales:merged:<page>:<locale>` を無効化します
- ルートレベルのファイル(例: `<locale>.json`)は、そのロケールのマージ済みキーをすべて無効化します
- 開発環境で `experimental.hmr !== false` の場合、`src/module.ts` から自動的に登録されます

## 設定 {#configuration}

```ts
export default defineNuxtConfig({
  i18n: {
    experimental: { hmr: true }, // default in dev
  },
})
```
