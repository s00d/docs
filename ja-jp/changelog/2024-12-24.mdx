**導入された CLI バージョン**: `v1.1.0`

![v1.1.0 CLI text-to-i18n のデモ](/images/text-to-i18n.gif)

Nuxt I18n Micro CLI に新しい `text-to-i18n` コマンドが加わったことをお知らせします！この強力な機能は、コードベースからハードコードされたテキスト文字列を抽出し、i18n の翻訳キーに変換する作業を自動化します。時間を節約し、ミスを減らし、ローカライズのワークフローを効率化するように設計されています。

## 主なメリット {#key-benefits}

- **テキスト抽出の自動化**: Vue テンプレート、JavaScript、TypeScript のファイルをスキャンします。
- **シームレスなキー生成**: ファイルパスと内容に基づいて、構造化された翻訳キーを作成します。
- **効率的な翻訳管理**: 既存のエントリを保持したまま翻訳ファイルを更新します。

## 仕組み {#how-it-works}

1. **ファイルのスキャン**: `pages`、`components`、`plugins` などの主要なディレクトリ内のファイルを処理します。
2. **テキストの処理**: 翻訳可能な文字列を特定して抽出し、一意のキーを生成します。
3. **翻訳の更新**: 新しいキーを翻訳ファイルに自動的に挿入し、そのネスト構造を維持します。

## 使い方 {#usage}

```bash
i18n-micro text-to-i18n [options]
```

例：

```bash
i18n-micro text-to-i18n --translationFile locales/en.json --context auth
```

## 変換の例 {#example-transformations}

### 変換前 {#before}

```vue
<template>
  <div>
    <h1>Welcome to our site</h1>
    <p>Please sign in to continue</p>
  </div>
</template>
```

### 変換後 {#after}

```vue
<template>
  <div>
    <h1>{{ $t('pages.home.welcome_to_our_site') }}</h1>
    <p>{{ $t('pages.home.please_sign_in') }}</p>
  </div>
</template>
```
