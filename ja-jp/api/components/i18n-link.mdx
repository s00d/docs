# 🌍 `<i18n-link>` コンポーネント

`Nuxt I18n Micro` の `<i18n-link>` コンポーネントは、現在のロケールに基づいてルートを自動的にローカライズする多目的なリンクコンポーネントです。`<NuxtLink>` コンポーネントのラッパーとして機能し、アクティブなリンクのスタイリングや外部リンクのサポートといった追加機能を提供します。

## ⚙️ Props

{/* generated:component:i18n-link — do not edit; run `pnpm run docs:generate` */}

| Prop | 型 | デフォルト | 説明 |
| --- | --- | --- | --- |
| `to` **\*** | `RouteLocationNamedRaw \| RouteLocationResolvedGeneric \| string` | — | ターゲットルート。自動的にローカライズされます。外部 URL はそのまま渡されます。 |
| `activeStyle` | `Partial<CSSStyleValue>` | — | リンクが現在のルートを指しているときに適用されるインラインスタイル。 |

**\*** 必須。

### スロット

| スロット | バインディング | 説明 |
| --- | --- | --- |
| `default` | — | リンクの内容。 |

{/* /generated:component:i18n-link */}

`to` は `NuxtLink` が受け付けるものすべてを受け付けます — パス、名前付きルート、解決されたルートオブジェクトなど。
絶対 URL は検出され、ローカライズされずにプレーンな `<a target="_blank" rel="noopener noreferrer">` としてレンダリングされます。

## 🛠️ 使用例

### 基本的な使い方

```vue
<i18n-link to="/about">About Us</i18n-link>
```

この例は、現在のロケール向けにローカライズされた `/about` ページへのリンクを作成します。

### インラインスタイルでのアクティブなリンクのスタイリング

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold' }">About Us</i18n-link>
```

ユーザーが `/about` ページにいるとき、リンクはボールドテキストになり、インラインスタイルでアクティブなリンクを直接スタイリングできます。

### 外部リンクの扱い

コンポーネントは外部リンクを自動的に検出し、セキュリティのために必要な属性を追加します。

```vue
<i18n-link to="https://example.com">Visit Example</i18n-link>
```

このリンクは `https://example.com` を新しいタブで開き、`rel="noopener noreferrer"` を適用します。

## 🎨 スタイル

コンポーネントはアクティブ状態にクラスではなくインラインスタイルを使用するようになりました。これらのスタイルは `activeStyle` prop を使ってカスタマイズできます。

### デフォルトのアクティブスタイル

- **フォントウェイト**: `bold`
- **色**: ブラウザのデフォルト色を継承(`activeStyle` に `color` が指定されていない場合)。

`activeStyle` prop を通じてカスタムスタイルを提供することで、これらを上書きできます。

### カスタムアクティブスタイル

```vue
<i18n-link to="/about" :activeStyle="{ fontWeight: 'bold', color: '#42b983' }">About Us</i18n-link>
```

この例では、リンクはアクティブ時にボールドかつ緑になります。

## 🚀 追加機能

### カスタムコンテンツ用のスロット

スロットを使ってリンク内にカスタムコンテンツを渡せるため、さまざまなユースケースで柔軟に使用できます。

```vue
<i18n-link to="/about">
  <span>About Us</span>
</i18n-link>
```

### アクセシビリティの強化

コンポーネントは `aria-label` などのアクセシビリティ属性をサポートし、よりアクセシブルな体験を保証します。

```vue
<i18n-link to="/about" aria-label="Learn more about us">
  About Us
</i18n-link>
```
