# 🌍 `<i18n-t>` コンポーネント

`Nuxt I18n Micro` の `<i18n-t>` コンポーネントは、スロットを通じた動的コンテンツの挿入をサポートする柔軟な翻訳コンポーネントです。翻訳にカスタム Vue コンポーネントや HTML コンテンツを補間でき、高度なローカライズシナリオを実現します。

## ⚙️ Props

| Prop | 型 | デフォルト | 説明 |
| --- | --- | --- | --- |
| `keypath` **\*** | `string` | — | レンダリングする翻訳キー。 |
| `plural` | `number \| string` | — | 複数形フォームを選択するカウント。設定すると `$t` の代わりに `$tc` を使用します。 |
| `tag` | `string` | `'span'` | レンダリングする要素。 |
| `params` | `Record<string, string \| number \| boolean>` | `() => (\{\})` | 翻訳に代入する補間値。 |
| `defaultValue` | `string` | `''` | `hideIfEmpty` が空の翻訳を抑制するときに、コンポーネントの代わりにレンダリングされます。 |
| `html` | `boolean` | `false` | 翻訳をテキストではなく HTML としてレンダリングします。自分で管理しているコンテンツにのみ使用してください。 |
| `hideIfEmpty` | `boolean` | `false` | 翻訳が空文字列に解決される場合、何もレンダリングしません。 |
| `customPluralRule` | `PluralFunc` | `null` | この要素のみに適用する複数形ルール。設定されたルールを上書きします。 |
| `number` | `number \| string` | — | 値を `$tn` でフォーマットし、`\{number\}` として翻訳に渡します。 |
| `date` | `Date \| string \| number` | — | 値を `$td` でフォーマットし、`\{date\}` として翻訳に渡します。 |
| `relativeDate` | `Date \| string \| number` | — | 値を `$tdr` でフォーマットし、`\{relativeDate\}` として翻訳に渡します。 |

**\*** 必須。

{/* /generated:component:i18n-t */}

一度に適用されるのは `plural`、`number`、`date`、`relativeDate` のいずれか 1 つだけです。複数が設定された場合は、このリストで先にあるものが優先されます。

### Prop ごとの例

```vue
<!-- keypath: レンダリングする翻訳 -->
<i18n-t keypath="feedback.text" />

<!-- plural: 複数形フォームを選択 -->
<i18n-t keypath="items" :plural="10" />

<!-- params: 翻訳に補間 -->
<i18n-t keypath="greeting" :params="{ name: 'Ada' }" />

<!-- tag: レンダリングする要素 -->
<i18n-t keypath="feedback.text" tag="p" />

<!-- number / date / relativeDate: フォーマットして補間 -->
<i18n-t keypath="cart.total" :number="1234.5" />
<i18n-t keypath="post.published" :date="post.createdAt" />
<i18n-t keypath="post.ago" :relative-date="post.createdAt" />

<!-- hideIfEmpty とフォールバック -->
<i18n-t keypath="promo.banner" hide-if-empty default-value="Nothing to show" />
```

```json
{
  "items": "Nothing|You have {count} item|You have {count} items"
}
```

## 🛠️ 使用例

### 基本的な使い方

```vue
<i18n-t keypath="feedback.text" />
```

これは `feedback.text` の翻訳を `<span>` タグ内にレンダリングします。

### 動的コンテンツのためのスロット使用

`<i18n-t>` コンポーネントはスロットの使用をサポートしており、翻訳の特定部分に動的に Vue コンポーネントや他のコンテンツを挿入できます。

```vue
<i18n-t keypath="feedback.text">
  <template #link>
    <nuxt-link :to="{ name: 'index' }">
      <i18n-t keypath="feedback.link" />
    </nuxt-link>
  </template>
</i18n-t>
```

この例では、`feedback.text` 翻訳文字列内の `\{link\}` プレースホルダーが `<nuxt-link>` コンポーネントに置き換えられ、そのコンポーネント自身も別の翻訳コンポーネントを含んでいます。

### 複数形処理

```vue
<i18n-t keypath="items.count" :plural="itemCount" />
```

これは `itemCount` の値に基づいて複数形ルールを自動的に適用します。

## 🚀 追加機能

### デフォルトスロット

特定のスロットが提供されていない場合、翻訳された文字列全体を提供するデフォルトスロットを通じて翻訳をカスタマイズできます。

```vue
<i18n-t keypath="welcome.message">
  <template #default="{ translation }">
    {{ translation.replace('Nuxt', 'Vue') }}
  </template>
</i18n-t>
```

### 条件付きレンダリング

`hideIfEmpty` prop を使うと、翻訳文字列が空の場合に何もレンダリングしないようにできます。

```vue
<i18n-t keypath="optionalMessage" :hideIfEmpty="true"></i18n-t>
```

### カスタム複数形ルール

カスタム関数で複数形を処理できます。

```vue
<i18n-t
  keypath="items"
  :plural="itemCount"
  :customPluralRule="
    (key, count, params, locale, t) => {
      const raw = t(key, params)
      if (!raw) return null
      return count === 1 ? 'One item' : `${count} items`
    }
  "
/>
```

### スロットを使った高度な例

スロットを使って翻訳コンテンツのレンダリング方法をカスタマイズできます。

```vue
<i18n-t keypath="welcomeMessage">
  <template #default="{ translation }">
    <strong>{{ translation }}</strong>
  </template>
</i18n-t>
```
