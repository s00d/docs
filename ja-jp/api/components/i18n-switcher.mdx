# 🌍 `<i18n-switcher>` コンポーネント

`Nuxt I18n Micro` の `<i18n-switcher>` コンポーネントは、アプリケーション内で異なるロケール間を切り替えるための、ユーザーフレンドリーなドロップダウンインターフェースを提供します。このコンポーネントは高度にカスタマイズ可能で、アプリケーションのデザインとレイアウトにシームレスに統合できます。

`disabled: true` のロケールはドロップダウンから**除外**されます(`$getLocales()` からは SEO や head タグ用に引き続き利用できます)。切り替え可能なロケールにのみ `NuxtLink` と `hreflang` が付きます。

すべてのパーツはデフォルトでスタイルなしです。`custom*Style` prop はインラインスタイルオブジェクトを受け取り、スタイリングだけでは不十分な場合は以下のスロットがマークアップを完全に置き換えます。

## 🛠️ 使用例

### 基本的な使い方

```vue
<template>
  <i18n-switcher />
</template>
```

これによりデフォルトのスタイルと動作を持つロケール切り替えがレンダリングされます。

### カスタムラベルとインラインスタイル

```vue
<template>
  <i18n-switcher
    :customLabels="{ en: 'English', fr: 'Français' }"
    :customWrapperStyle="{ backgroundColor: '#f8f9fa', padding: '10px' }"
    :customButtonStyle="{ backgroundColor: '#007bff', color: '#fff', borderRadius: '4px' }"
    :customDropdownStyle="{ border: '1px solid #007bff', boxShadow: '0 2px 8px rgba(0, 0, 0, 0.1)' }"
    :customItemStyle="{ margin: '5px 0', padding: '5px' }"
    :customLinkStyle="{ padding: '8px 16px', color: '#333', textDecoration: 'none' }"
    :customActiveLinkStyle="{ color: 'green', fontWeight: 'bold', backgroundColor: '#f0f0f0' }"
    :customIconStyle="{ fontSize: '20px', color: '#007bff' }"
  />
</template>
```

この例では、カスタムラベルとインラインスタイルを備えた、完全にカスタマイズされたロケール切り替えを示します。

## 🔌 スロット

スイッチャーのすべての視覚パーツを置き換えられます。スロットは上記の props テーブルとともに一覧化されています。各スロットにはテンプレートコンテンツを渡せます。

```vue
<i18n-switcher>
  <template #before-button>
    <span>🌐</span>
  </template>

  <template #before-item="{ locale }">
    <img :src="`/flags/${locale.code}.svg`" :alt="locale.code">
  </template>

  <template #after-dropdown-items>
    <a href="/help/languages">Missing a language?</a>
  </template>
</i18n-switcher>
```

名前が `-item`、`-link-content` で終わる、または `before-item` で始まるスロットは、それが属する `locale` オブジェクトを受け取ります。

## 🎨 スタイル概要

`<i18n-switcher>` コンポーネントには、インラインスタイルで定義された基本スタイルが付属しており、prop からカスタムスタイルを渡すことで容易にオーバーライドできます。デフォルトのスタイリングの概要は以下のとおりです。

- **ラッパー**: ドロップダウンの配置を制御します。
- **ボタン**: ドロップダウンの開閉ボタンをスタイルします。
- **ドロップダウン**: ドロップダウンリストをスタイルします。
- **項目**: リスト内の各項目をスタイルします。
- **リンク**: 各項目内のリンクをスタイルします。
- **アイコン**: ドロップダウンインジケーターアイコンをスタイルします。

対応する prop を通じてカスタムスタイルを渡すことでこれらをカスタマイズでき、ロケール切り替えをアプリケーションの UI へシームレスに統合できます。
