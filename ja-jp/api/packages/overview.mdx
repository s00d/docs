---
title: "パッケージ API"
description: "すべての @i18n-micro/* パッケージのエクスポート API。CI がソースと照合する API スナップショットから生成されています。"
---

Nuxt モジュールは小さな `@i18n-micro/*` パッケージから構成されており、その多くは単独でも動作します：Vue アプリでは `@i18n-micro/vue`、どこでも使える `@i18n-micro/core` などです。これらのページでは、パッケージがエントリーポイントごとに何をエクスポートしているかを確認できます。各ページは、[`pnpm run api:surface`](https://s00d.github.io/nuxt-i18n-micro/contributing/maintenance-commands#api-surface) が TypeScript ソースと照合するスナップショットから生成されているため、CI に気づかれずにエクスポートが変わることはありません。
