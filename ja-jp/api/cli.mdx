[CLI ガイド](/ja-jp/guide/cli)では一般的なワークフローを紹介しています。このページではすべてを一覧にしており、`--help` を生成するのと同じテーブルから生成されています。

## 共通フラグ {#common-flags}

| フラグ | デフォルト | 説明 |
| --- | --- | --- |
| `--cwd` | カレントディレクトリ | プロジェクトディレクトリ |
| `--logLevel` | `info` | 出力レベル: silent、info |
| `--debug` | `false` | コマンドが失敗したときにスタックトレースを出力する |

## 調査 {#inspect}

### `info` {#info}

プロジェクトの解決済み i18n 設定を出力する

| フラグ | デフォルト | 説明 |
| --- | --- | --- |
| `--json` | `false` | テキストの代わりに JSON を出力する |

### `check` {#check}

CI ゲート: 欠落、空、余分、未定義、未使用のキーや壊れたプレースホルダーがあると失敗する

| フラグ | デフォルト | 説明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config の `i18n.translationDir` | 翻訳ディレクトリ(プロジェクトからの相対パス) |
| `--only` | duplicates 以外のすべて | 実行するチェックのカンマ区切りリスト: missing、empty、extra、placeholders、undefined、unused、duplicates。ここで `unused` を指定した場合、実行できないと失敗する |
| `--duplicates` | `false` | 異なるキーに同じテキストがある場合も報告する |
| `--ignore` | — | スキップするソースファイルのカンマ区切りの glob(プロジェクトからの相対パス) |
| `--json` | `false` | テキストの代わりに JSON を出力する |

```bash
i18n-micro check
i18n-micro check --only missing,placeholders --json
```

### `stats` {#stats}

ロケールごとの翻訳完了率を表示する

| フラグ | デフォルト | 説明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config の `i18n.translationDir` | 翻訳ディレクトリ(プロジェクトからの相対パス) |
| `--html` | — | このファイルに HTML レポートも書き出す |
| `--json` | `false` | テキストの代わりに JSON を出力する |
| `--baseRef` | — | 完了率を比較する Git ref(例: HEAD~1 や main) |

```bash
i18n-micro stats --baseRef main
i18n-micro stats --html reports/i18n.html
```

### `lint` {#lint}

翻訳のテキストをチェックする。問題が残っていると失敗する

| フラグ | デフォルト | 説明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config の `i18n.translationDir` | 翻訳ディレクトリ(プロジェクトからの相対パス) |
| `--rules` | すべて、または .i18n-lintrc.json の `enabledRules` | 実行するルールのカンマ区切りリスト: no-trailing-spaces、no-multiple-spaces、no-empty-translation、またはカスタムルール |
| `--fix` | `false` | 修正可能なものを修正する: スペース、および置換を持つカスタムルール |
| `--json` | `false` | テキストの代わりに JSON を出力する |

```bash
i18n-micro lint --rules no-trailing-spaces --fix
```

### `search` {#search}

キーと値を検索し、各キーの使用箇所を表示する

| フラグ | デフォルト | 説明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config の `i18n.translationDir` | 翻訳ディレクトリ(プロジェクトからの相対パス) |
| `<query>` | — | 検索するテキストまたはキー |
| `--caseSensitive` | `false` | 大文字と小文字を区別する |
| `--onlyUnused` | `false` | `clean` が削除するキーのみ。クエリは省略可能になる |
| `--scope` | `all` | 検索範囲: global、pages、all |
| `--limit` | — | 返すキーの最大数 |
| `--ignore` | — | スキップするソースファイルのカンマ区切りの glob(プロジェクトからの相対パス) |
| `--json` | `false` | テキストの代わりに JSON を出力する |

```bash
i18n-micro search "Welcome"
i18n-micro search --onlyUnused
```

## 翻訳ワークフロー {#translation-workflow}

### `extract` {#extract}

ソースファイルが使用しているがまだテキストのないキーを一覧表示し、デフォルトテキスト付きでデフォルトロケールに追加する

| フラグ | デフォルト | 説明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config の `i18n.translationDir` | 翻訳ディレクトリ(プロジェクトからの相対パス) |
| `--ignore` | — | スキップするソースファイルのカンマ区切りの glob(プロジェクトからの相対パス) |

```bash
i18n-micro extract
```

### `translate` {#translate}

翻訳サービスを通じて、デフォルトロケールから欠落している翻訳を埋める

| フラグ | デフォルト | 説明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config の `i18n.translationDir` | 翻訳ディレクトリ(プロジェクトからの相対パス) |
| `--service` | — | 翻訳サービス: ai、azure、deepl、google、libretranslate、yandexcloud |
| `--token` | — | API キー。I18N_TRANSLATE_TOKEN 環境変数の使用を推奨(フラグはシェル履歴に残るため) |
| `--options` | — | key:value ペアのサービスオプション(カンマ区切り) |
| `--locale` | デフォルト以外のすべてのロケール | 埋めるロケールのカンマ区切りリスト |
| `--replace` | `false` | すべてのキーを再翻訳し、既存の値を置き換える |
| `--dryRun` | `false` | ロケールごとのキー数と文字数を数える。何も送信しない |
| `--chunkSize` | — | リクエストあたりの文字列数。サービスが受け付ける上限で制限される |
| `--pluralSeparator` | `\|` | メッセージ内の複数形の区切り文字 |
| `--glossaryFile` | 存在する場合は `.i18n-glossary.json` | 用語集ファイル。`ai` サービスで使用される |

```bash
i18n-micro translate --dryRun
I18N_TRANSLATE_TOKEN=... i18n-micro translate --service deepl --locale de,fr
i18n-micro translate --service ai --options provider:openai,model:gpt-4o-mini
i18n-micro translate --service libretranslate --options baseUrl:https://translate.example.com
```

### `sync` {#sync}

デフォルトロケールにないキーを削除する。安全であることを証明できない場合は停止する。欠落しているキーは欠落したままになる

| フラグ | デフォルト | 説明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config の `i18n.translationDir` | 翻訳ディレクトリ(プロジェクトからの相対パス) |
| `--ignore` | — | スキップするソースファイルのカンマ区切りの glob(プロジェクトからの相対パス) |
| `--dryRun` | `false` | 削除される内容を一覧表示する。何も書き込まない |
| `--force` | `false` | 安全であることを証明できなくてもキーを削除する |

```bash
i18n-micro sync --dryRun
```

### `clean` {#clean}

プロジェクト内でどこからも使用されていないキーを削除する。それを証明できない場合は停止する

| フラグ | デフォルト | 説明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config の `i18n.translationDir` | 翻訳ディレクトリ(プロジェクトからの相対パス) |
| `--include` | — | 正規表現: 一致するキーのみを削除対象とする |
| `--exclude` | — | 正規表現: 一致するキーは決して削除しない |
| `--ignore` | — | スキップするソースファイルのカンマ区切りの glob(プロジェクトからの相対パス) |
| `--dryRun` | `false` | 削除される内容を一覧表示する。何も書き込まない |
| `--force` | `false` | すべてのキーについて使用状況を証明できなくてもキーを削除する |

```bash
i18n-micro clean --dryRun
i18n-micro clean --exclude '^errors\.'
```

## リファクタリング {#refactoring}

### `text-to-i18n` {#text-to-i18n}

Vue テンプレート内のハードコードされたテキストを翻訳呼び出しに置き換え、コード内のハードコードされたテキストを報告する

| フラグ | デフォルト | 説明 |
| --- | --- | --- |
| `--translationFile` | `<translationDir>/<defaultLocale>.json` | 新しいキーの追加先ファイル |
| `--path` | プロジェクト全体 | 処理するファイルまたはディレクトリ |
| `--context` | — | 生成されるキーのプレフィックス |
| `--ignore` | — | スキップするソースファイルのカンマ区切りの glob(プロジェクトからの相対パス) |
| `--dryRun` | `false` | 変更内容を表示する。何も書き込まない |
| `--interactive` | `false` | 生成されたキーを 1 つずつ確認または編集する |

```bash
i18n-micro text-to-i18n --dryRun
i18n-micro text-to-i18n --path components --context ui
```

### `rename` {#rename}

すべてのロケールとソースファイルで、キーまたは名前空間の名前を変更する

| フラグ | デフォルト | 説明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config の `i18n.translationDir` | 翻訳ディレクトリ(プロジェクトからの相対パス) |
| `--from` **\*** | — | 現在のキーまたは名前空間 |
| `--to` **\*** | — | 新しいキーまたは名前空間 |
| `--ignore` | — | スキップするソースファイルのカンマ区切りの glob(プロジェクトからの相対パス) |
| `--dryRun` | `false` | 変更内容を報告する。何も書き込まない |

**\*** 必須。

```bash
i18n-micro rename --from common.save --to actions.save
```

### `pseudo` {#pseudo}

ロケールを疑似翻訳で埋め、レイアウトやハードコードされたテキストの問題を見つける

| フラグ | デフォルト | 説明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config の `i18n.translationDir` | 翻訳ディレクトリ(プロジェクトからの相対パス) |
| `--sourceLocale` | デフォルトロケール | 読み込むロケール |
| `--targetLocale` **\*** | — | 埋めるロケール |
| `--replace` | `false` | 既存の値を上書きする |

**\*** 必須。

### `format` {#format}

キーをソートし、インデントを統一してロケールファイルを書き直す

| フラグ | デフォルト | 説明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config の `i18n.translationDir` | 翻訳ディレクトリ(プロジェクトからの相対パス) |
| `--indent` | `2` | インデントのスペース数 |
| `--sortKeys` | `true` | キーをソートする。順序を保持するには --no-sortKeys を使用する |
| `--check` | `false` | ファイルが変更される場合は失敗する。何も書き込まない |

```bash
i18n-micro format --check
```

## 交換 {#exchange}

### `export` {#export}

デフォルトロケールのテキストをソースとして、ロケールファイルを PO または CSV にエクスポートする

| フラグ | デフォルト | 説明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config の `i18n.translationDir` | 翻訳ディレクトリ(プロジェクトからの相対パス) |
| `--format` | `po` | ファイル形式: po、csv |
| `--dir` | po の場合は `pots`、csv の場合は `csv_exports` | 出力ディレクトリ(プロジェクトからの相対パス) |
| `--force` | `false` | 前回のエクスポート以降に変更され、まだインポートされていないファイルを上書きする |

```bash
i18n-micro export --format csv
```

### `import` {#import}

PO または CSV ファイルをロケールファイルにマージする

| フラグ | デフォルト | 説明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config の `i18n.translationDir` | 翻訳ディレクトリ(プロジェクトからの相対パス) |
| `--format` | `po` | ファイル形式: po、csv |
| `--dir` | po の場合は `pots`、csv の場合は `csv_exports` | 入力ディレクトリ(プロジェクトからの相対パス) |
| `--dryRun` | `false` | インポートされる内容を報告する。何も書き込まない |

```bash
i18n-micro import --format csv --dryRun
```

### `sync-remote` {#sync-remote}

.i18n-remote.json の HTTP エンドポイントからグローバル翻訳をプルする、またはプッシュする

| フラグ | デフォルト | 説明 |
| --- | --- | --- |
| `--translationDir` | nuxt.config の `i18n.translationDir` | 翻訳ディレクトリ(プロジェクトからの相対パス) |
| `--pull` | `true` | リモートからプルする |
| `--push` | `false` | リモートへプッシュする |
| `--force` | `false` | プル時はリモートの値を採用し、プッシュ時はリモートにのみ存在するテキストを上書きする |
| `--dryRun` | `false` | プルで変更される内容を報告する。何も書き込まず、何もプッシュしない |

```bash
i18n-micro sync-remote --dryRun
i18n-micro sync-remote --no-pull --push
```

## Lint ルール {#lint-rules}

| ルール | 検出内容 | `--fix` で修正 |
| --- | --- | --- |
| `no-trailing-spaces` | 値または行の末尾のスペース | はい |
| `no-multiple-spaces` | 2 つ以上連続するスペース | はい |
| `no-empty-translation` | 空または空白のみの値 | いいえ |

## 終了コード {#exit-codes}

| コード | 意味 |
| --- | --- |
| `0` | 完了、報告事項なし |
| `1` | 検出あり: `check`、`lint`、`format --check` が何かを検出した、`clean` または `sync` が削除の安全性を証明できなかった、`export` がインポートされていない作業を上書きしようとした、`translate` がキーを取りこぼした、`import` または `sync-remote` が競合に遭遇した、`sync-remote` のプッシュがリモートのテキストを削除しようとした。`clean`、`sync`、または `sync-remote` のプルを `--dryRun` で実行した場合はこれらを報告し、`0` で終了する |
| `2` | 失敗: 不正な使い方、読み取れないプロジェクト、ネットワークまたはファイルのエラー |

## 設定ファイル {#configuration-files}

| ファイル | 使用元 |
| --- | --- |
| `.i18n-lintrc.json` | `lint`: `enabledRules`、`disabledRules`、`customRegexRules`(`name`、`pattern`、`flags`、`description`、`replacement`) |
| `.i18n-remote.json` | `sync-remote`: `url`、`path`、`token`、`auth`(`username`、`password`)。`type` は省略可能。存在するのは `custom` のみ |
| `.i18n-glossary.json` | `translate --service ai`: `source`、`target`、および省略可能な `from`、`to` からなる `entries` |

## 環境変数 {#environment-variables}

| 名前 | 用途 |
| --- | --- |
| `I18N_TRANSLATE_TOKEN` | `translate` の API キー。`.env` からも読み込まれる |
| `I18N_REMOTE_TOKEN` | `sync-remote` の Bearer トークン。`.env` からも読み込まれる |
| `AI_GATEWAY_API_KEY, OPENAI_API_KEY, ANTHROPIC_API_KEY` | `I18N_TRANSLATE_TOKEN` が設定されていない場合の `ai` サービスのキー |
| `DEFAULT_LOCALE` | モジュールと同様に `defaultLocale` を上書きする |

## 削除されたコマンド {#removed-commands}

| コマンド | 代替 |
| --- | --- |
| `validate` | check |
| `diff` | check --only missing |
| `check-duplicates` | check --only duplicates |
| `export-csv` | export --format csv |
| `import-csv` | import --format csv |
| `estimate` | translate --dryRun |
| `optimize` | check --only duplicates |
| `backup` | git(ロケールファイルはすでに git で管理されています) |
| `restore` | git(ロケールファイルはすでに git で管理されています) |
| `init` | nuxi init の後、nuxt-i18n-micro を modules に追加 |

| `replace-values` | エディターまたは sed |
| `glossary` | .i18n-glossary.json を手動で編集 |
