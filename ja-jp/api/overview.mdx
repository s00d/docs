このセクションでは、Nuxt モジュールのすべてのオプション、ヘルパー、フック、コンポーザブル、コンポーネントに加え、各 `@i18n-micro/*` パッケージのエクスポート API を一覧にしています。シグネチャやデフォルト値を調べる際に利用してください。使い方は[ガイド](/ja-jp/guide/getting-started)で説明しています。ここにあるほとんどの表はソースから生成されているため、コードと一致しています。

## Nuxt モジュール {#nuxt-module}

| ページ | 内容 |
| --- | --- |
| [モジュールオプション](/ja-jp/api/module-options) | `nuxt.config` のすべての `i18n` キーと、その型およびデフォルト値 |
| [ヘルパー](/ja-jp/api/methods) | `$t`、`$tc`、`$tn`、`$td`、`$localePath`、`$switchLocale`、`$defineI18nRoute` など |
| [フック](/ja-jp/api/events) | `i18n:register` ランタイムフック |

## コンポーザブル {#composables}

| コンポーザブル | 用途 |
| --- | --- |
| [`useI18n`](/ja-jp/composables/useI18n) | `<script setup>` 内でのヘルパー |
| [`useI18nLocale`](/ja-jp/composables/useI18nLocale) | カスタム検出プラグインでのロケール状態と Cookie |
| [`useI18nHead`](/ja-jp/composables/useI18nHead) | 生成された SEO タグのページ単位の上書き |
| [`useLocaleHead`](/ja-jp/composables/useLocaleHead) | 独自の `useHead` 用に、SEO タグをオブジェクトとして取得 |

## コンポーネント {#components}

| コンポーネント | 描画内容 |
| --- | --- |
| [`<i18n-t>`](/ja-jp/components/i18n-t) | 複数形、フォーマット、スロット補間に対応した 1 つの翻訳 |
| [`<i18n-link>`](/ja-jp/components/i18n-link) | ローカライズされたルートへの `NuxtLink` |
| [`<i18n-switcher>`](/ja-jp/components/i18n-switcher) | ロケールのドロップダウン |
| [`<i18n-group>`](/ja-jp/components/i18n-group) | 共通のキー接頭辞を持つブロック |

## サーバー {#server}

Nitro ハンドラーでは、クライアント用ヘルパーではなく `useTranslationServerMiddleware` と `useLocaleServerMiddleware` を使用します。[サーバールート](/ja-jp/guide/server-side-translations)を参照してください。

## パッケージ {#packages}

[パッケージ API](/ja-jp/api/packages/overview) では、すべての `@i18n-micro/*` パッケージのエクスポートを、パッケージごとに生成された 1 ページずつで一覧にしています。
