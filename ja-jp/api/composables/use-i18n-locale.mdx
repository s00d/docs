# useI18nLocale

## シグネチャ

{/* generated:symbol:useI18nLocale — do not edit; run `pnpm run docs:generate` */}

```ts
useI18nLocale(): { getEffectiveLocale: (route: unknown, getLocaleFromRoute: GetLocaleFromRoute) => string; getLocale: () => string | null; getLocaleWithServerFallback: (serverLocale?: string | null) => string | null; getPreferredLocale: () => string | null; hashCookie: any; isValidLocale: (locale: string | null | undefined) => locale is string; locale: any; localeCookie: any; resolveInitialLocale: (options: ResolveInitialLocaleOptions) => string; setLocale: (locale: string | null) => void; syncLocale: (locale: string | null) => void; validLocales: string[] }
```

i18n のロケール管理のための集中エントリポイントです。
`useState('i18n-locale')`、ロケール Cookie、同期ユーティリティを組み合わせています。

{/* /generated:symbol:useI18nLocale */}

## 使い方

```vue
<script setup>
const {
  locale,
  localeCookie,
  hashCookie,
  validLocales,
  getPreferredLocale,
  getLocale,
  getLocaleWithServerFallback,
  getEffectiveLocale,
  resolveInitialLocale,
  setLocale,
  syncLocale,
  isValidLocale,
} = useI18nLocale()

// ロケールを設定(state と Cookie を更新)
setLocale('de')

// 現在のロケールを取得(state → Cookie)
const current = getLocale()

// 有効な優先ロケールを取得
const preferred = getPreferredLocale()
</script>
```

## API

| プロパティ/メソッド                                 | 型                                | 説明                                                                          |
| ----------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| `locale`                                        | `Ref<string \| null>`               | リアクティブなロケール状態(`useState('i18n-locale')`)                                    |
| `localeCookie`                                  | `Ref`                               | ロケール Cookie(`localeCookie` オプションが有効な場合)                                |
| `hashCookie`                                    | `Ref`                               | `hashMode` がアクティブなときに使用される Cookie                                                |
| `validLocales`                                  | `string[]`                          | モジュール設定からの有効なロケールコード(`disabled` を除く)                        |
| `getLocale()`                                   | `() => string \| null`              | 現在のロケール: state → Cookie(ハッシュモードではハッシュ Cookie)                         |
| `getPreferredLocale()`                          | `() => string \| null`              | state/Cookie からのロケールを `validLocales` で**検証**したもの、または `null`             |
| `getLocaleWithServerFallback(serverLocale?)`    | `(serverLocale?) => string \| null` | state → Cookie → オプションのサーバーコンテキスト(`no_prefix` の初期化中に使用)              |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string`             | 翻訳読み込み用のロケール: ハッシュモードでは state を優先、それ以外はルートから読み取ります。 |
| `resolveInitialLocale(options)`                 | `(options) => string`               | ロケールを解決: state → `serverLocale` → route。必要に応じて state を同期します。             |
| `setLocale(locale)`                             | `(locale: string \| null) => void`  | ロケールを設定し、Cookie に同期します。                                                       |
| `syncLocale(locale)`                            | `(locale: string \| null) => void`  | Cookie のみを同期します(state 更新なし)。                                                  |
| `isValidLocale(locale)`                         | `(locale) => boolean`               | 文字列が `validLocales` にあるかを確認します。                                                 |

### `resolveInitialLocale` オプション

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

起動時にメインプラグインが内部で使用します。代替の検出フローを実装するカスタムプラグインからも呼び出せます。

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

指定されたルートオブジェクトについて、翻訳を読み込みメッセージをフォーマットするために使用されるロケールを返します。

## プログラム的なロケール設定

`useState('i18n-locale')` を直接使うのではなく、`useI18nLocale()` を推奨します。

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // 独自の検出ロジック
    setLocale(detectedLocale)
  },
})
```

<Tip>
`setLocale()` はロケールの設定(state + Cookie)のみを更新します。クライアント上でアクティブな翻訳コンテキストも再読み込みするには、`useNuxtApp()` または `useI18n()` の `$switchLocale()` を使用してください。特に URL が変わらない `no_prefix` では重要です。[FAQ — URL を変更せずにロケールを切り替える](/guides/faq#-switch-locale-without-changing-the-url) を参照してください。
</Tip>
