# useI18nLocale

## シグネチャ

{/* generated:symbol:useI18nLocale — do not edit; run `pnpm run docs:generate` */}

```ts
useI18nLocale(): { getEffectiveLocale: (route: unknown, getLocaleFromRoute: GetLocaleFromRoute) => string; getLocale: () => string | null; getLocaleWithServerFallback: (serverLocale?: string | null) => string | null; getPreferredLocale: () => string | null; hashCookie: any; isValidLocale: (locale: string | null | undefined) => locale is string; locale: any; localeCookie: any; resolveInitialLocale: (options: ResolveInitialLocaleOptions) => string; setLocale: (locale: string | null) => void; syncLocale: (locale: string | null) => void; validLocales: string[] }
```

i18n ロケール管理の一元的なエントリポイント。
`useState('i18n-locale')`、ロケールクッキー、および同期ユーティリティを組み合わせています。

{/* /generated:symbol:useI18nLocale */}

## 使い方

```vue
<script setup>
const {
  locale,
  localeCookie,
  hashCookie,
  validLocales,
  getPreferredLocale,
  getLocale,
  getLocaleWithServerFallback,
  getEffectiveLocale,
  resolveInitialLocale,
  setLocale,
  syncLocale,
  isValidLocale,
} = useI18nLocale()

// Set locale (updates state and cookies)
setLocale('de')

// Get current locale (state → cookie)
const current = getLocale()

// Get valid preferred locale
const preferred = getPreferredLocale()
</script>
```

## API

| プロパティ/メソッド                                 | 型                                | 説明                                                                          |
| ----------------------------------------------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| `locale`                                        | `Ref<string \| null>`               | リアクティブなロケール状態(`useState('i18n-locale')`)                                    |
| `localeCookie`                                  | `Ref`                               | ロケールクッキー(`localeCookie` オプションが有効な場合)                                |
| `hashCookie`                                    | `Ref`                               | `hashMode` がアクティブなときに使用されるクッキー                                                |
| `validLocales`                                  | `string[]`                          | モジュール設定からの有効なロケールコード(`disabled` を除外)                        |
| `getLocale()`                                   | `() => string \| null`              | 現在のロケール: state → クッキー(ハッシュモードではハッシュクッキー)                         |
| `getPreferredLocale()`                          | `() => string \| null`              | state / クッキーからのロケールを `validLocales` に対して**検証**したもの、または `null`             |
| `getLocaleWithServerFallback(serverLocale?)`    | `(serverLocale?) => string \| null` | state → クッキー → オプションのサーバーコンテキスト(`no_prefix` の初期化中に使用)              |
| `getEffectiveLocale(route, getLocaleFromRoute)` | `(route, fn) => string`             | 翻訳を読み込むロケール: ハッシュモードでは state を優先、それ以外はルートから読み取る |
| `resolveInitialLocale(options)`                 | `(options) => string`               | ロケール解決: state → `serverLocale` → ルート。必要に応じて state を同期             |
| `setLocale(locale)`                             | `(locale: string \| null) => void`  | ロケールを設定し、クッキーへ同期                                                       |
| `syncLocale(locale)`                            | `(locale: string \| null) => void`  | クッキーのみを同期(state は更新しない)                                                  |
| `isValidLocale(locale)`                         | `(locale) => boolean`               | 文字列が `validLocales` にあるかを確認                                                 |

### `resolveInitialLocale` オプション

```typescript
interface ResolveInitialLocaleOptions {
  route: unknown
  serverLocale?: string | null
  getLocaleFromRoute: (route?: unknown) => string
}
```

起動時にメインプラグインが内部的に使用します。代替の検出フローを実装するときにカスタムプラグインから呼び出せます。

### `getEffectiveLocale`

```typescript
const { getEffectiveLocale } = useI18nLocale()
const { $getLocale } = useNuxtApp()

const locale = getEffectiveLocale(route, (r) => $getLocale(r))
```

指定されたルートオブジェクトに対して、翻訳を読み込みメッセージをフォーマットするために使用されるロケールを返します。

## プログラム的なロケール設定

直接 `useState('i18n-locale')` を使うより、`useI18nLocale()` を優先してください:

```ts
// plugins/i18n-loader.server.ts
import { defineNuxtPlugin } from '#imports'

export default defineNuxtPlugin({
  name: 'i18n-custom-loader',
  enforce: 'pre',
  order: -10,

  setup() {
    const { setLocale } = useI18nLocale()
    const detectedLocale = 'ja' // Your detection logic here
    setLocale(detectedLocale)
  },
})
```

<Tip>
`setLocale()` はロケール設定(state + クッキー)のみを更新します。クライアントでアクティブな翻訳コンテキストも再読み込みするには、`useNuxtApp()` または `useI18n()` の `$switchLocale()` を使用してください。特に URL が変わらない `no_prefix` では重要です。[FAQ — URL を変更せずにロケールを切り替える](/guides/faq#-switch-locale-without-changing-the-url) を参照してください。
</Tip>
