# 🌍 `useLocaleHead` コンポーザブル

`useLocaleHead` コンポーザブルは、`Nuxt I18n Micro` のユーティリティで、ローカライズされたルート用の SEO 属性と HTML メタタグを管理するのに役立ちます。HTML ドキュメントの `lang` と `dir` 用の属性を動的に生成し、ローカライズされたコンテンツの SEO を向上させる `meta` と `link` タグを作成します。

## ⚙️ オプション

現在のルート用の SEO head タグ: すべてのロケールの `hreflang` 代替と
`x-default`、canonical リンク、`og:locale`、および `<html>` 上の `lang`/`dir`。

`meta` が無効な場合、またはデフォルト値の調整が必要な場合にのみ必要です — `meta: true` の場合、モジュールが同じタグを自ら登録します。

## 🛠️ 戻り値

`useLocaleHead` コンポーザブルは、ソースデータが変更されたときに呼び出す必要のあるリアクティブオブジェクトと更新関数を返します。両方の形は、上記のシグネチャに含まれており、ソースから生成されています。

### `metaObject`

`useHead(metaObject)` に適したリアクティブな head ペイロード(html 属性、meta、link)。

- **例**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

現在のルート、ロケール、設定に基づいて `metaObject` を再計算します。入力が変わったとき(例えばルート変更時)に呼び出してください。

- **例**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### `link` と `meta` へのアクセス

`link` と `meta` の配列は `metaObject.value` を通じてアクセスできます:

- **例**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // Output: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // Output: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ 使用例

### 基本的な使い方

デフォルトオプションでロケール固有の head 属性を生成します。

```js
const head = useLocaleHead()
```

### 識別子属性のカスタマイズ

生成されるタグにカスタム識別子属性を使用します。

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### SEO 属性を無効化

SEO 関連のメタタグと link タグを追加せずに head 属性を生成します。

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### ベース URL を指定

canonical と代替 URL 用にカスタムベース URL を設定します。

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 追加機能

### SEO のメタタグと link タグ

`addSeoAttributes` が有効な場合、コンポーザブルは次のタグを自動生成します:

- 現在のロケール用の `og:locale`(`language_TERRITORY`、アンダースコア)。`locale.og` から派生、または可能な場合は `locale.iso` から変換。
- ページの canonical URL 用の `og:url`。
- 代替言語版用の `og:locale:alternate`。
- SEO 最適化のための `rel="canonical"` と `rel="alternate"` リンク。
- デフォルトロケールの URL を指す `hreflang="x-default"` リンク。これは、定義されたロケールのいずれとも言語が一致しないユーザーにどの URL を表示すべきかを検索エンジンに伝えます。

### 動的なロケールと方向

コンポーザブルは、現在のルートのロケールに基づいて `lang` と `dir` 属性を動的に決定し、HTML ドキュメントが国際的なユーザー向けに正しく構成されるようにします。

### ローカライズされたルートの処理

ルートがロケールコードでプレフィックス付けされている場合(例: `/en/about`)、コンポーザブルは URL 生成用にフルパスをインテリジェントに調整し、SEO 属性が正確かつ関連性のあるものになるようにします。

このコンポーザブルは、Nuxt アプリケーションを国際的なオーディエンス向けに最適化するプロセスを簡素化し、サイトがグローバルな検索エンジンとユーザーに適切に対応できるようにします。

## 🛠️ 使用例

以下の例は、Vue コンポーネント内でデフォルト設定を使って `useLocaleHead` コンポーザブルを使う方法を示します:

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### コードの説明

- **`useLocaleHead` コンポーザブル**: このコンポーザブルは `<script setup>` セクションで呼び出され、`htmlAttrs`、`meta`、`link` を含むオブジェクトを返します。

- **`<html>` タグ**: HTML ドキュメントの `lang` と `dir` 属性は、現在のロケールに基づいて動的に決定され、`<html>` タグに適用されます。

- **`<head>` セクション**:
  - **メタタグ**: `og:locale`、`og:url`、およびページの代替言語版を指定する `rel="canonical"` と `rel="alternate"` タグを含む SEO 関連メタタグが生成されます。
  - **Link タグ**: canonical リンク、代替言語版へのリンク、`hreflang="x-default"` リンク(デフォルトロケール URL を指す)が含まれます。

- **`<body>` セクション**: ページのメインコンテンツがここに表示されます。この例では、シンプルなヘッダーと段落が使用されています。

### 📝 備考

1. **属性**: 使用される属性(`lang`、`dir`、`rel`、`href`、`hreflang`、`property`、`content`)は、`useLocaleHead` が返すオブジェクトから抽出されます。

2. **SEO タグの生成**: `addSeoAttributes` オプションが `true` に設定されている場合、コンポーザブルは現在のロケール用に SEO タグを自動生成します。

3. **ベース URL**: `baseUrl` オプションを使用してカスタムベース URL を設定でき、canonical と代替リンクを正しく生成できます。

この例は、`useLocaleHead` をアプリケーションのコンポーネントに統合して、正しい SEO 属性を確保し、ローカライズされたページの検索エンジンインデックスを改善する容易さを示しています。

## 🧩 カスタマイズとライフサイクル

- `useLocaleHead` はそれ自体では変更を購読しません。`metaObject` と `updateMeta` を返します。
- 入力が変わったとき(通常はルート変更時)に `updateMeta()` を呼び出してください。プラグインから呼び出す例:

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## 代わりに `useI18nHead` を使う場合

`meta: true`(デフォルト)の場合、**ページごとの**オーバーライド(カスタム hreflang、追加の `og:title`、部分的な無効化)には [`useI18nHead`](/api/composables/use-i18n-head) を優先してください。`meta: false` の場合や、`useHead` を自分で管理する場合のみ、`useLocaleHead` を直接使ってください。
