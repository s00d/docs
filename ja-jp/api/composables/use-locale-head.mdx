# 🌍 `useLocaleHead` コンポーザブル

`useLocaleHead` コンポーザブルは `Nuxt I18n Micro` のユーティリティで、ローカライズされたルート用に SEO 属性と HTML メタタグを管理する助けとなります。HTML ドキュメントの `lang` と `dir` 属性を動的に生成し、ローカライズされたコンテンツの SEO を向上させる `meta` と `link` タグを作成します。

## ⚙️ オプション

{/* generated:symbol:useLocaleHead — do not edit; run `pnpm run docs:generate` */}

```ts
useLocaleHead(options: UseLocaleHeadOptions): { metaObject: Ref<{ htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }, MetaObject | { htmlAttrs: { dir?: "ltr" | "rtl" | "auto"; lang?: string }; link: { href: string; hreflang?: string; rel: string; [key: string]: string | undefined }[]; meta: { content: string; property: string; [key: string]: string }[] }>; updateMeta: () => void }
```

現在のルートの SEO head タグ: すべてのロケールと `x-default` の `hreflang` 代替、canonical リンク、`og:locale`、`<html>` の `lang`/`dir`。

`meta` が無効になっている場合、またはデフォルトを調整する必要がある場合にのみ必要です。`meta: true` の場合、モジュール自身が同じタグを登録します。

## 🛠️ 戻り値

`useLocaleHead` コンポーザブルは、リアクティブなオブジェクトと、ソースデータの変更時に呼び出すべき更新関数を返します。両方の形状は、ソースから生成された上記のシグネチャに含まれています。

### `metaObject`

リアクティブな head ペイロード(html 属性、meta、link)で、`useHead(metaObject)` に適しています。

- **例**:
  ```js
  const { metaObject } = useLocaleHead()
  useHead(metaObject)
  ```

### `updateMeta`

現在のルート、ロケール、設定に基づいて `metaObject` を再計算します。入力が変わったとき(たとえばルート変更時)に呼び出します。

- **例**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  useHead(metaObject)
  watch(
    () => route.fullPath,
    () => updateMeta(),
    { immediate: true },
  )
  ```

### `link` と `meta` へのアクセス

`link` と `meta` 配列は `metaObject.value` を通じてアクセスできます。

- **例**:
  ```js
  const { metaObject, updateMeta } = useLocaleHead()
  updateMeta()
  console.log(metaObject.value.link)
  // 出力: [{ id: 'i18n-can', rel: 'canonical', href: 'https://example.com/about' }, ...]
  console.log(metaObject.value.meta)
  // 出力: [{ id: 'i18n-og', property: 'og:locale', content: 'en_US' }, ...]
  ```

## 🛠️ 使用例

### 基本的な使い方

デフォルトオプションでロケール固有の head 属性を生成します。

```js
const head = useLocaleHead()
```

### 識別属性のカスタマイズ

生成されるタグにカスタムの識別属性を使用します。

```js
const head = useLocaleHead({ identifierAttribute: 'data-i18n' })
```

### SEO 属性の無効化

SEO 関連の meta と link タグを追加せずに head 属性を生成します。

```js
const head = useLocaleHead({ addSeoAttributes: false })
```

### ベース URL の指定

canonical と代替 URL 用のカスタムベース URL を設定します。

```js
const head = useLocaleHead({ baseUrl: 'https://mywebsite.com' })
```

## 🚀 追加機能

### SEO Meta と Link タグ

`addSeoAttributes` が有効な場合、コンポーザブルは以下のタグを自動的に生成します。

- 現在のロケールの `og:locale`(`language_TERRITORY`、アンダースコア区切り)。`locale.og` から派生させるか、可能な場合は `locale.iso` から変換されます。
- ページの canonical URL に対する `og:url`。
- 代替言語版に対する `og:locale:alternate`。
- SEO 最適化のための `rel="canonical"` と `rel="alternate"` リンク。
- デフォルトロケールの URL を指す `hreflang="x-default"` リンク。これは、定義されたロケールと言語が一致しないユーザーに対して検索エンジンがどの URL を表示すべきかを示します。

### 動的なロケールと方向

コンポーザブルは、現在のルートのロケールに基づいて `lang` と `dir` 属性を動的に決定し、HTML ドキュメントが国際的なユーザー向けに正しく構成されていることを保証します。

### ローカライズされたルートの処理

ルートがロケールコードでプレフィックスされている場合(例: `/en/about`)、コンポーザブルは URL 生成のためのフルパスを賢く調整し、SEO 属性が正確かつ適切であることを保証します。

このコンポーザブルは、Nuxt アプリケーションを国際的な視聴者向けに最適化するプロセスを簡素化し、サイトがグローバルな検索エンジンとユーザーに対して十分に準備されていることを保証します。

## 🛠️ 使用例

以下の例は、Vue コンポーネント内でデフォルト設定を用いて `useLocaleHead` コンポーザブルを使う方法を示します。

```vue
<script setup>
import { useRoute, watch } from '#imports'
const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({
  addDirAttribute: true,
  identifierAttribute: 'id',
  addSeoAttributes: true,
})
useHead(metaObject)
watch(
  () => route.fullPath,
  () => updateMeta(),
  { immediate: true },
)
</script>
```

### コードの説明

- **`useLocaleHead` コンポーザブル**: このコンポーザブルは `<script setup>` セクションで呼び出され、`htmlAttrs`、`meta`、`link` を含むオブジェクトを返します。

- **`<html>` タグ**: HTML ドキュメントの `lang` と `dir` 属性は現在のロケールに基づいて動的に決定され、`<html>` タグに適用されます。

- **`<head>` セクション**:
  - **Meta タグ**: SEO 関連のメタタグ(`og:locale`、`og:url`、代替言語版を指定する `rel="canonical"` と `rel="alternate"` タグを含む)が生成されます。
  - **Link タグ**: canonical リンク、代替言語版へのリンク、および `hreflang="x-default"` リンク(デフォルトロケールの URL を指す)が含まれます。

- **`<body>` セクション**: ページのメインコンテンツはここに表示されます。この例では、シンプルなヘッダーと段落が使われます。

### 📝 メモ

1. **属性**: 使用される属性(`lang`、`dir`、`rel`、`href`、`hreflang`、`property`、`content`)は、`useLocaleHead` から返されるオブジェクトから抽出されます。

2. **SEO タグの生成**: `addSeoAttributes` オプションが `true` に設定されている場合、コンポーザブルは現在のロケール用の SEO タグを自動的に生成します。

3. **ベース URL**: `baseUrl` オプションを使って独自のベース URL を設定し、canonical と代替リンクを正しく生成できます。

この例は、`useLocaleHead` をアプリケーションのコンポーネントに統合して、正しい SEO 属性を確保し、ローカライズされたページの検索エンジンインデックスを改善するのがいかに簡単かを示しています。

## 🧩 カスタマイズとライフサイクル

- `useLocaleHead` はそれ自体で変更を購読しません。`metaObject` と `updateMeta` を返します。
- 入力が変わったとき(通常はルート変更時)に `updateMeta()` を呼び出す必要があります。たとえばプラグインからは以下のようにします。

```ts
// plugins/02.meta.ts
export default defineNuxtPlugin(() => {
  const route = useRoute()
  const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
  useHead(metaObject)
  if (import.meta.server) updateMeta()
  else
    watch(
      () => route.fullPath,
      () => updateMeta(),
      { immediate: true },
    )
})
```

## `useI18nHead` を使うべき場合

`meta: true`(デフォルト)の場合、**ページ単位**の上書き(カスタム hreflang、追加の `og:title`、部分無効化)には [`useI18nHead`](/api/composables/use-i18n-head) を優先してください。`useLocaleHead` を直接使うのは、`meta: false` の場合や、自分で `useHead` を管理する場合のみです。
