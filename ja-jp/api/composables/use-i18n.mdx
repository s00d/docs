# 🛠️ `useI18n` コンポーザブル

`Nuxt I18n Micro` の `useI18n` コンポーザブルは、コンポーネントやスクリプトからほとんどのランタイム i18n ヘルパーへのアクセスを提供します。メソッドは **`$` プレフィックス付きと付きなしの両方**(例: `$t` と `t`)で利用可能です。

一部の注入(`$defineI18nRoute` と `$clearCache`)は `useNuxtApp()` からのみ利用できます。[メソッド — `$defineI18nRoute`](/api/methods#definei18nroute) と [`$clearCache`](/api/methods#clearcache) を参照してください。

## 📊 返り値

{/* generated:symbol:useI18n — do not edit; run `pnpm run docs:generate` */}

```ts
useI18n(): PluginsInjectionsWithAliases
```

すべてのランタイムヘルパーをプレーンオブジェクトとして返します。

プラグインが `$t`、`$tc` などとして注入する同じ関数で、ドル記号付きの名前と素のエイリアスの両方で利用可能です。したがって `const \{ t \} = useI18n()` と `const \{ $t \} = useI18n()` の両方が動作します。

**戻り値** — [メソッドリファレンス](/api/methods) で説明されているヘルパー

```ts
const { t, tc, switchLocale, getLocale } = useI18n()

t('welcome', { name: 'Ada' })
tc('items', 3)
switchLocale('de')
```

{/* /generated:symbol:useI18n */}

返されるすべてのヘルパー — `$t`、`$tc`、`$has`、`$switchLocale` など — は、シグネチャとともに [メソッドリファレンス](/api/methods) に完全に記載されています。

## `useNuxtApp()` 専用 API

これらは `useI18n()` からは返されません。`useNuxtApp()` からインポートしてください:

| メソッド                     | 目的                                                                         |
| -------------------------- | ------------------------------------------------------------------------------- |
| `$defineI18nRoute(config)` | ページごとのロケールルート、制限、`script setup` 内でのインライン翻訳 |
| `$clearCache()`            | インメモリの翻訳キャッシュと読み込み済みチャンクをクリア                            |

```typescript
import { useNuxtApp } from '#imports'

const { $defineI18nRoute, $clearCache } = useNuxtApp()

$defineI18nRoute({
  locales: ['en', 'fr'],
  localeRoutes: { en: '/about', fr: '/a-propos' },
})
```

完全なシグネチャと例は [メソッド](/api/methods) を参照してください。

## 🛠️ 使用例

### 基本的なロケール取得

アプリケーションの現在のロケールを取得します。

```js
const { $getLocale } = useI18n()
const locale = $getLocale()
```

### パラメーター付き翻訳

動的パラメーターとフォールバックのデフォルト値を使って文字列を翻訳します。

```js
const { $t } = useI18n()
const welcomeMessage = $t('welcome', { name: 'Jane' }, 'Welcome!')
```

### ロケールの切り替え

アプリケーションを別のロケールに切り替えます。

```js
const { $switchLocale } = useI18n()
$switchLocale('de')
```

### ローカライズされたルートの生成

現在または指定したロケール向けにローカライズされたルートを生成します。

```js
const { $localeRoute } = useI18n()
const route = $localeRoute('/about', 'fr')
```
