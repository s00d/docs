# 🛠️ `nuxt-i18n-micro` の DevTools

## Vue DevTools(ブラウザ拡張機能)

開発時、モジュールは `@vue/devtools-api` を通じて **Vue DevTools** のカスタムインスペクターとタイムラインを登録できます。これは以下の Nuxt DevTools タブとは別物です。

| ツール | 適した用途 |
|------|----------|
| **Vue DevTools** | ライブロケール、インメモリ翻訳キャッシュ、`$t` タイムライン(`debug: true`)、欠落キーイベント |
| **Nuxt DevTools タブ** | ディスク上の JSON ファイルの編集、設定概要、インポート/エクスポート |

vue-devtools プラグインは `nuxt dev` 中にのみ登録されます(本番ビルドには含まれません)。メインプラグイン内の開発時専用のブリッジ状態は、`import.meta.dev` のデッドコード除去により削除されます。

Nuxt タブは維持したまま、ブラウザ統合を無効にするには以下のように設定します。

```ts
export default defineNuxtConfig({
  i18n: {
    vueDevtools: false,
  },
})
```

詳細な `$t` タイムラインイベントには `debug: true` が必要です。

## 📖 Nuxt DevTools とは

DevTools は `nuxt-i18n-micro` モジュールにシームレスに統合された強力な開発支援ツールです。ローカライズと翻訳タスクを管理するための直感的なインターフェースを提供し、ワークフローをより高速かつ効率的にします。利便性を重視する開発者向けに設計された Nuxt DevTools は、コーディングとランタイム管理のギャップを埋めます。

## 🌟 `nuxt-i18n-micro` の DevTools の主な機能

### 1. **ロケール管理**

アプリケーション内のロケールを簡単に閲覧、選択、管理できます。単一言語でも複数言語でも、DevTools はすべてのローカライズ設定を扱う集中ハブを提供します。

### 2. **翻訳の編集**

統合された JSON エディターを通じて翻訳ファイルを直接編集できます。これにより外部ツールの必要がなくなり、ワークフローを中断せずにリアルタイムでの更新と変更が可能になります。

### 3. **ファイルのインポートとエクスポート**

翻訳ファイル管理のプロセスを簡素化します。

- **エクスポート**: バックアップや外部利用のために翻訳を JSON ファイルとして保存します。
- **インポート**: コンテンツを最新に保つため、更新された翻訳ファイルをプロジェクトに読み込みます。

### 4. **リアルタイムプレビュー**

開発環境内で変更を即座に確認できます。この機能により、公開前に翻訳と設定の正確性を確認できます。

### 5. **シームレスな Nuxt 統合**

DevTools は `nuxt-i18n-micro` とネイティブに動作し、追加のセットアップなしでその機能を強化します。Nuxt のモジュラーで柔軟な構造を維持しながら、ローカライズのニーズに適応します。

## 🛠️ なぜ DevTools を使うのか

Nuxt DevTools は、ローカライズが必要なプロジェクトにとって欠かせない追加機能です。以下の点で開発者を助けます。

- **時間の節約**: ファイル管理や形式検証などの反復作業を自動化します。
- **エラーの削減**: 翻訳を編集するための安全で直感的な環境を提供します。
- **コラボレーションの改善**: 非開発者でも翻訳を簡単に管理できるようにします。
- **ワークフローの効率化**: 複数のローカライズタスクを 1 つのインターフェースに集約します。

---

## 🚀 ローカライズを掌握する

Nuxt DevTools を `nuxt-i18n-micro` に統合することで、多言語アプリケーションの管理がわかりやすく効率的になります。翻訳を微調整する場合でも、新しいロケールを追加する場合でも、DevTools は洗練されたユーザーフレンドリーな体験を提供するために必要なツールを備えています。
