## 動作要件

- **Node.js**: 18 以降。
- **Nuxt**: 3.x または 4.x。

このモジュールは Nuxt 3 のプロジェクトレイアウト(`pages/**/*.vue`)と Nuxt 4 のレイアウト(`app/pages/**/*.vue`)の両方をサポートします。慣例として、Nuxt 4 の `app/` ディレクトリを使う場合でも翻訳はプロジェクトルート(`locales/`)に配置します。

## Nuxt モジュールのインストール

<CodeGroup>
```bash npm
npm install nuxt-i18n-micro
```

```bash pnpm
pnpm add nuxt-i18n-micro
```

```bash yarn
yarn add nuxt-i18n-micro
```

```bash bun
bun add nuxt-i18n-micro
```
</CodeGroup>

`nuxt.config.ts` で登録します:

```typescript
export default defineNuxtConfig({
  modules: ['nuxt-i18n-micro'],
  i18n: {
    locales: [
      { code: 'en', iso: 'en-US', dir: 'ltr' },
      { code: 'fr', iso: 'fr-FR', dir: 'ltr' },
    ],
    defaultLocale: 'en',
    translationDir: 'locales',
  },
})
```

完全なウォークスルーは [クイックスタート](/quickstart) を、すべてのオプションについては [設定リファレンス](/guides/configuration) を参照してください。

## プロジェクト構成

デフォルトでは、モジュールは次の構成を想定しています:

```text
my-project/
├── locales/
│   ├── en.json
│   ├── fr.json
│   └── pages/
│       └── index/
│           ├── en.json
│           └── fr.json
├── pages/
│   └── index.vue
└── nuxt.config.ts
```

ルートレベルのファイルは、ビルド時にすべてのページ固有ファイルへマージされます。ページ固有のファイルは、`nuxt dev` 中に不足していると自動生成されます。

</Info>

## Nuxt 4 レイアウト

```text
my-project/
├── app/
│   └── pages/
│       └── index.vue
├── locales/
│   └── en.json
└── nuxt.config.ts
```

`app/` 配下に翻訳を同居させるには、`translationDir: 'app/locales'` を設定します。

## エコシステムパッケージ

| パッケージ | 用途 |
| --- | --- |
| [`@i18n-micro/vue`](/integrations/vue) | Vue 3 統合(Nuxt なしのスタンドアロン)。 |
| [`@i18n-micro/react`](/integrations/react) | React 統合。 |
| [`@i18n-micro/preact`](/integrations/preact) | Preact 統合。 |
| [`@i18n-micro/solid`](/integrations/solid) | SolidJS 統合。 |
| [`@i18n-micro/astro`](/integrations/astro) | Astro 統合。 |
| [`@i18n-micro/node`](/integrations/nodejs) | Node.js サーバーサイドローダー。 |
| [`@i18n-micro/types-generator`](/integrations/types-generator) | 翻訳ファイルから TypeScript 型を生成。 |
| [`@i18n-micro/devtools-ui`](/integrations/devtools-ui) | フレームワーク非依存の DevTools パネル。 |

内部の共有パッケージは推移的に取り込まれます。

## TypeScript

このモジュールは、デフォルトロケールのファイルを基に `useI18n`、`$t`、および関連ヘルパーのアンビエント型を生成します。これはデフォルトで有効です(`types: true`)。

翻訳キーの型付けを強化するには、[`@i18n-micro/types-generator`](/integrations/types-generator) を参照してください。
