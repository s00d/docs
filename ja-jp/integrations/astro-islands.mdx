---
title: "Astro アイランド"
description: "@i18n-micro/astro を使った Vue、React、Preact、Svelte アイランド内での翻訳。"
---

アイランドはブラウザで実行されるため、サーバーの i18n インスタンスは存在しません。`@i18n-micro/astro` を使うと、ページがアイランドに必要なキーを選び、それを 1 つの prop として渡し、小さなフレームワークアダプターを通じてアイランド内で読み取れます。Vue、React、Preact、Svelte のアイランドで `t`、`tc`、`tn`、`td`、`tdr`、`has` が使え、HTML には選んだ文字列だけが含まれます。

## セットアップ {#setup}

まず [Astro インテグレーションとミドルウェア](/ja-jp/integrations/astro-package#setup)をセットアップし、次に使用するフレームワークのインテグレーション（`@astrojs/vue`、`@astrojs/react`、`@astrojs/preact`、`@astrojs/svelte`）を追加します。アイランドアダプターは、そのフレームワークをピア依存として必要とします：`vue` `^3.3.0`、`react` `^16.8.0 || ^17.0.0 || ^18.0.0 || ^19.0.0`、`preact` `^10.0.0 || ^11.0.0`、または `svelte` `^4.0.0 || ^5.0.0`。

## アイランドに翻訳を渡す {#pass-translations-to-an-island}

```astro
---
// src/pages/index.astro
import { getI18nProps } from '@i18n-micro/astro'
import Counter from '../components/Counter.vue'

const i18n = getI18nProps(Astro, ['counter.title', 'counter.apples'])
---

<Counter client:load i18n={i18n} />
```

`getI18nProps(Astro, keys?)` は `{ locale, fallbackLocale, currentRoute, translations }`（型 `I18nClientProps`）を返します。アイランドが使うキーを渡してください。各キーはサーバー上で `t()` と同様に（ルート、ルート共通、フォールバックの辞書から）解決され、見つかったキーだけが HTML に含まれます。`keys` を省略すると、このページで `t()` が返せるすべてがすべてのアイランドに送られるため、ルートキーが 2000 個あるとアイランドごとに約 100 KB になります。開発環境では 20 KB を超えると警告が表示されます。

アイランドはそのオブジェクトからのみ翻訳します。渡されていないものに対して `t` はキーを返し、リンクされたメッセージは解決されません。

## Vue {#vue}

アイランドのルートコンポーネントで `provideI18n(() => props.i18n)` を呼び出し、その子コンポーネントで `useAstroI18n()` を呼び出します。Vue の `inject` は同じコンポーネントが provide した値を参照できないため、フックはルートではなく子で実行する必要があります。

```vue
<!-- src/components/Counter.vue -->
<script setup lang="ts">
import { provideI18n } from '@i18n-micro/astro/client/vue'
import type { I18nClientProps } from '@i18n-micro/astro'
import CounterBody from './CounterBody.vue'

const props = defineProps<{ i18n: I18nClientProps }>()
provideI18n(() => props.i18n)
</script>

<template><CounterBody /></template>
```

```vue
<!-- src/components/CounterBody.vue -->
<script setup lang="ts">
import { ref } from 'vue'
import { useAstroI18n } from '@i18n-micro/astro/client/vue'

const { t, tc } = useAstroI18n()
const count = ref(0)
</script>

<template>
  <h3>{{ t('counter.title') }}</h3>
  <button @click="count++">{{ tc('counter.apples', count) }}</button>
</template>
```

## React と Preact {#react-and-preact}

```tsx
// src/components/Counter.tsx
import { useState } from 'react'
import { I18nProvider, useAstroI18n } from '@i18n-micro/astro/client/react'
import type { I18nClientProps } from '@i18n-micro/astro'

function Body() {
  const { t, tc } = useAstroI18n()
  const [count, setCount] = useState(0)
  return <button onClick={() => setCount(count + 1)}>{t('counter.title')}: {tc('counter.apples', count)}</button>
}

export default function Counter({ i18n }: { i18n: I18nClientProps }) {
  return (
    <I18nProvider value={i18n}>
      <Body />
    </I18nProvider>
  )
}
```

Preact では `I18nProvider` と `useAstroI18n` を `@i18n-micro/astro/client/preact` からインポートします。API は同じです。

## Svelte {#svelte}

```svelte
<!-- src/components/Counter.svelte -->
<script lang="ts">
  import { createI18nStore, useAstroI18n } from '@i18n-micro/astro/client/svelte'
  import type { I18nClientProps } from '@i18n-micro/astro'

  export let i18n: I18nClientProps
  const { t, tc } = useAstroI18n(createI18nStore(i18n))
  let count = 0
</script>

<button on:click={() => count++}>{t('counter.title')}: {tc('counter.apples', count)}</button>
```

`useAstroI18n(store)` は、テンプレート内で `$store` として読み取るための `store` も返します。

## 永続化されたアイランド {#persisted-islands}

`transition:persist` を持つアイランドは、ナビゲーション後に新しい props を受け取ります。React、Preact、Vue（ゲッターを渡した場合）はそれに追従します。Svelte ではストアを保持して props を渡し続けます：`const store = createI18nStore(i18n)`、`const { t } = useAstroI18n(store)`、そして `$: store.set(i18n)`（runes の場合は `$effect(() => store.set(i18n))`）。

## API {#api}

| エントリ | エクスポート |
| --- | --- |
| `@i18n-micro/astro` | `getI18nProps`、型 `I18nClientProps` |
| `@i18n-micro/astro/client/vue` | `provideI18n(props \| () => props)`, `useAstroI18n()` |
| `@i18n-micro/astro/client/react` | `I18nProvider`（`value` prop）、`useAstroI18n()` |
| `@i18n-micro/astro/client/preact` | `I18nProvider`（`value` prop）、`useAstroI18n()` |
| `@i18n-micro/astro/client/svelte` | `createI18nStore(props)`, `useAstroI18n(store)` |
| `@i18n-micro/astro/client` | フレームワークに依存しない純粋な `translate`、`hasTranslation` |

すべての `useAstroI18n` は `t`、`ts`、`tc`、`tn`、`td`、`tdr`、`has`、`setLocale`、`setRoute`、そして `locale` を返します。アイランドは 1 つのマージ済み辞書を持つため、その `has` は `t` が返せるキー（フォールバックロケールからのものも含む）に対して true になります。サーバー上では `has` はアクティブなロケールのみを参照します。
