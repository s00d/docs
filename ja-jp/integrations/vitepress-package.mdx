`@i18n-micro/vitepress` は VitePress サイトにランタイム辞書を追加します。Markdown 内の `$t` と `<I18nT>`、パスヘルパー、SEO タグを提供し、[`@i18n-micro/vue`](/ja-jp/integrations/vue-package) 上に構築されています。同じ UI 文字列が多くのページに現れ、それをロケールごとに重複させたくない場合に使用します。ロケールは VitePress 自身のパスロケール（`/`、`/fr/`）に従います。

## 使うべき場面 {#when-to-use-it}

| 必要なもの | 解決策 |
|------|----------|
| `.md` の複製、URL プレフィックス | VitePress の `locales` |
| ランタイムの `$t` / コンポーネント / パス同期 / SEO head | `@i18n-micro/vitepress` |
| デフォルトテーマの UI ラベル（`docFooter`、検索 UI） | ロケールごとの独自の `themeConfig` |

<Tip>

**Playground** — [`packages/vitepress/playground`](https://github.com/s00d/nuxt-i18n-micro/tree/main/packages/vitepress/playground) — `pnpm -C packages/vitepress/playground dev`

</Tip>

## インストール {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vitepress
```

```bash npm
npm install @i18n-micro/vitepress
```

```bash yarn
yarn add @i18n-micro/vitepress
```

</CodeGroup>

ピア依存関係：`vitepress` `>=1.0.0 || >=2.0.0-alpha.0`、`vue` `^3.3.0`。Node スクリプトは `@i18n-micro/node` を使用します。これはパッケージと一緒にインストールされ、`/node` を通じて再エクスポートされます。公開されている型は、`skipLibCheck: false` の場合 Vue 3.5.5 以降を必要とします。テンプレートで一般的な `skipLibCheck: true` の場合は、それより古いバージョンでもコンパイルできます。

## セットアップ {#setup}

```
locales/en.json
locales/fr.json
locales/pages/guide/demo/en.json   # optional page-scoped
locales/pages/guide/demo/fr.json
```

ページファイルは Nuxt/Astro と同じ方法でルート名に対応付けられます（`guide/demo` → `guide-demo`）。

### 1. 設定 — `@i18n-micro/vitepress/config` {#1-config-—-@i18n-micro/vitepress/config}

```ts
// .vitepress/config.mts
import { defineConfig } from 'vitepress'
import { withI18n, buildVitePressLocales } from '@i18n-micro/vitepress/config'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English', og: 'en_US' },
  { code: 'fr', iso: 'fr-FR', displayName: 'Français', og: 'fr_FR' },
]
const defaultLocale = 'en'

export default defineConfig(
  withI18n(
    {
      locales: buildVitePressLocales(locales, defaultLocale),
      // themeConfig.i18nRouting is injected automatically
    },
    {
      locale: defaultLocale,
      defaultLocale,
      locales,
      translationDir: 'locales',
      metaBaseUrl: 'https://example.com', // optional SEO head
    },
  ),
)
```

### 2. テーマ — `@i18n-micro/vitepress/theme` {#2-theme-—-@i18n-micro/vitepress/theme}

```ts
// .vitepress/theme/index.ts
import DefaultTheme from 'vitepress/theme'
import { defineI18nTheme } from '@i18n-micro/vitepress/theme'

export default defineI18nTheme(DefaultTheme)
```

初期ロケールはインストール前に現在のパスから取得されます（`/fr/…` でデフォルトロケールが一瞬表示されることはありません）。

### 応用：手動での `createI18n` {#advanced-manual-createi18n}

クライアント用のファクトリは 1 つです：Vue プラグイン + パスメソッド + `enhanceApp`（ルーターヘルパーの個別エクスポートはありません）。

```ts
import { createI18n, messagesFromGlob } from '@i18n-micro/vitepress'

const i18n = createI18n({
  locale: 'en',
  defaultLocale: 'en',
  locales: [{ code: 'en' }, { code: 'fr' }],
  messages: messagesFromGlob(import.meta.glob('../../locales/*.json', { eager: true })),
})

i18n.localizePath('/guide', 'fr')
// in theme enhanceApp:
i18n.enhanceApp({ app, router })
```

### Node スクリプト — `@i18n-micro/vitepress/node` {#node-scripts-—-@i18n-micro/vitepress/node}

`@i18n-micro/node` の `createI18n` / `loadTranslations`（Astro や CLI と同じ）を使用し、`BaseI18n.extend` で VitePress のパスメソッドを付加します。

```ts
import { createI18n } from '@i18n-micro/vitepress/node'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  translationDir: './locales',
  locales: ['en', 'fr'],
  defaultLocale: 'en',
})
await i18n.loadTranslations()
i18n.t('cta.readMore')
i18n.localizePath('/guide', 'fr')
```

パスを使わない素の Node：`import { createI18n } from '@i18n-micro/node'`。

## ページ内の翻訳 {#in-page-translations}

VitePress の各 Markdown ファイルは Vue SFC です。

### グローバルコンポーネントと `$t`（Markdown で推奨） {#global-components-and-$t-recommended-in-markdown}

`createI18n` / `defineI18nTheme` は `@i18n-micro/vue` をインストールし、`I18nT` / `I18nLink` / `I18nGroup` / `I18nSwitcher` と `$t` / `$tc` / `$ts` を登録します。

```md
{{ $t('cta.readMore') }}

<I18nT keypath="greeting" :params="{ name: 'VitePress' }" />

<I18nLink to="/guide/demo">Demo</I18nLink>
```

### `<script setup>` 内での `useI18n` {#usei18n-in-<script-setup>}

```md
<script setup>
import { useI18n } from '@i18n-micro/vitepress'
const { t, tc, locale, localePath, switchLocale } = useI18n()
</script>

# {{ t('section.title') }}
```

## 言語ドロップダウン {#language-dropdown}

`locales` に複数のエントリがある場合、VitePress は独自の言語メニュー（`VPNavBarTranslations`）を表示します。`withI18n` は `themeConfig.i18nRouting` を接続するため、地球儀アイコンのメニューが `<I18nSwitcher>` / パスヘルパーと一致します。

`<I18nSwitcher>` はカスタムレイアウトでのみ使用し、デフォルトの地球儀メニューと並べて使わないでください。

## SSR に関する注意 {#ssr-notes}

- プリレンダリング時のロケールは、Cookie ではなく URL パスから取得されます。
- テーマのコードはインポート時に `window` に触れてはいけません。
- Node での設定評価で `virtual:i18n-micro/*` が読み込まれないよう、`defineI18nTheme` は `/theme` からインポートしてください。

## API 一覧 {#api-surface}

| エクスポート | 役割 |
|--------|------|
| `createI18n` (`.`) | クライアント：Vue プラグイン + パスメソッド + `enhanceApp` |
| `getLocaleFromPath` / `stripSiteBase` / `routeNameFromPath` (`.`) | `syncWithVitePress: false` の場合の手動ロケール同期 |
| `createI18n` (`/node`) | Node：`@i18n-micro/node` + パスメソッド |
| `defineI18nTheme` (`/theme`) | ボイラープレート不要のテーマ |
| `withI18n` (`/config`) | 設定 + 仮想モジュール + オプションの SEO |
| `buildVitePressLocales` (`/config`) | `Locale[]` から VitePress の `locales` を構築 |
| `buildVitePressLocaleHead` (`/config`) | 手動の SEO head（`metaBaseUrl` でも使用） |
| `messagesFromGlob` | `createI18n` 向けのオプションの glob → メッセージマップ |
| `useI18n` / `I18nT` / … | `@i18n-micro/vue` から再エクスポート |
| `BaseI18n.extend` (`@i18n-micro/core`) | 任意の i18n インスタンスにカスタムメソッドを付加 |

## OpenAPI 形式のサイト（インテグレーションの固定事項） {#openapi-style-sites-integration-locks}

回帰テストスイート：`packages/vitepress/tests/integration-openapi.test.ts`（深いパス、`base=/openapi_docs/`、同期オフ + 手動ロケール、Node ジェネレーター、SEO）。

| パターン | 対処法 |
|---------|---------|
| 深い `/…/{spec}/{op}` ページで、ルート共通の UI JSON のみ | デフォルトの `syncWithVitePress: true`（ページ辞書がない場合は `setRoute('index')` を維持）**または** `syncWithVitePress: false` + `getLocaleFromPath` を推奨 |
| ページ辞書なしで `setRoute(deepName)` を決して呼ばない | `setRoute('index')` するまでルート共通の UI キーが消えます |
| ジェネレーター / `getTranslation` | `/node` の `createI18n` + `await loadTranslations()` + `i18n.t(key)`（`i18n.locale` を設定） |
| `transformPageData` でのカスタム canonical | `withI18n` に `meta: false` を渡す（タグの重複を回避） |
| サイトの base を伴うパッケージの SEO | `metaBaseUrl` + VitePress の `base` → 絶対 URL に base が含まれます |
| 古いパッケージビルドからの名前変更 | `withI18nMicro` → `withI18n`、`createVitePressI18n` → `createI18n`、`loadMessages` → node の `createI18n` |
