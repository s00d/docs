`@i18n-micro/vue` は、Nuxt I18n Micro の翻訳コアを備えた Vue 3 プラグインです。リアクティブな `t()`、グローバルな `$t`、4 つのコンポーネント、オプションの vue-router アダプターを提供します。Nuxt でビルドされていない Vite または SSR の Vue アプリで使用してください。インスタンスモデル、ルーターの契約、コンポーネントの props は他のパッケージと共通で、[フレームワーク](/ja-jp/integrations/overview) で説明しています。

## インストール {#install}

<CodeGroup>

```bash pnpm
pnpm add @i18n-micro/vue
```

```bash npm
npm install @i18n-micro/vue
```

```bash yarn
yarn add @i18n-micro/vue
```

</CodeGroup>

ピア依存関係: `vue` `^3.3.0`、`vue-router` `^4.5.1 || ^5.0.0`(オプション、`@i18n-micro/vue/router` を使う場合のみ)。公開されている型は、`skipLibCheck: false` の場合 Vue 3.5.5 以降が必要です。一般的なテンプレート設定である `skipLibCheck: true` の場合は、それより古いバージョンでもコンパイルできます。

## セットアップ {#setup}

```ts
// src/main.ts
import { createApp } from 'vue'
import { createI18n } from '@i18n-micro/vue'
import App from './App.vue'
import en from './locales/en.json'

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales: [
    { code: 'en', iso: 'en-US', displayName: 'English' },
    { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
  ],
  defaultLocale: 'en',
})

createApp(App).use(i18n).mount('#app')
```

`useI18n()` には `locales` と `defaultLocale` が必須です。これらがないと `I18nLocalesKey not provided` がスローされます。`createI18n` に渡す(上記のとおり)か、`useI18n({ locales, defaultLocale })` に渡すか、`app.provide(I18nLocalesKey, …)` と `app.provide(I18nDefaultLocaleKey, …)` を通じて渡してください。

プラグインは `I18nT`、`I18nLink`、`I18nGroup`、`I18nSwitcher` をグローバルに登録し、テンプレートに `$t`、`$ts`、`$tc`、`$tn`、`$td`、`$tdr`、`$has`、`$i18n` を追加します。コンポーネントの外では、インスタンスは `i18n.global` です。その他のオプションは [インスタンス](/ja-jp/integrations/overview#the-instance) にあります。Vue では `routeMessages` は使用できないため、`addRouteTranslations` を使用してください。

## 翻訳する {#translate}

```vue
<script setup lang="ts">
import { useI18n } from '@i18n-micro/vue'

const { t, tc, tn } = useI18n()
</script>

<template>
  <h1>{{ t('greeting', { name: 'Ada' }) }}</h1>
  <!-- Hello, Ada! -->
  <p>{{ tc('apples', 3) }}</p>
  <!-- 3 apples -->
  <p>{{ $t('nav.home') }} · {{ tn(1234.5) }}</p>
</template>
```

`useI18n()` は、翻訳メソッド(`t`、`ts`、`tc`、`tn`、`td`、`tdr`、`has`)、`locale`(書き込み可能な computed)、`getLocale`、`getLocales`、`defaultLocale()`、`getLocaleName`、`localePath`、`localeRoute`、`switchLocale`、`setRoute`、`getRoute`、`addTranslations`、`addRouteTranslations`、`mergeTranslations`、`resolveTranslations`、`setTranslation`、`clearCache`、`instance` を返します。

辞書はいつでも追加で読み込めます。それらを読み取るすべてのコンポーネントが再レンダリングされます。

```ts
const { addTranslations, addRouteTranslations, setRoute } = useI18n()

addTranslations('de', (await import('./locales/de.json')).default)
addRouteTranslations('en', 'about', { title: 'About us' })
setRoute('about') // t('title') now reads the 'about' dictionary first
```

## ロケールを切り替える {#switch-locale}

```ts
const { locale, switchLocale } = useI18n()

locale.value = 'de' // only the locale
switchLocale('de') // the locale, then router.push to the localized current path
```

ロケールの辞書は、切り替えの前または後に読み込んでください。切り替え自体は何もフェッチしません。

`<I18nGroup>` は、スロットにプレフィックス付きの `t` を渡します。`<I18nT>` 内のキーや通常の `t()` にはプレフィックスは付きません。

```vue
<I18nGroup prefix="profile" v-slot="{ t }">
  <h2>{{ t('title') }}</h2>
  <!-- profile.title -->
</I18nGroup>
```

## ルーティング {#routing}

vue-router アダプターはサブパスにあるため、メインのエントリーが `vue-router` をインポートすることはありません。

```ts
// src/main.ts
import { createApp } from 'vue'
import { createRouter, createWebHistory } from 'vue-router'
import { createI18n } from '@i18n-micro/vue'
import { createVueRouterAdapter } from '@i18n-micro/vue/router'
import App from './App.vue'
import Home from './pages/Home.vue'
import About from './pages/About.vue'
import en from './locales/en.json'

const locales = [
  { code: 'en', iso: 'en-US', displayName: 'English' },
  { code: 'de', iso: 'de-DE', displayName: 'Deutsch' },
]

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/:locale(de)?', component: Home },
    { path: '/:locale(de)?/about', component: About },
  ],
})

const i18n = createI18n({
  locale: 'en',
  fallbackLocale: 'en',
  messages: { en },
  locales,
  defaultLocale: 'en',
  routingStrategy: createVueRouterAdapter(router, locales, 'en'),
})

createApp(App).use(router).use(i18n).mount('#app')
```

`createVueRouterAdapter(router, locales, defaultLocale)` は、デフォルト以外のすべてのロケールにプレフィックスを付け(`/about`、`/de/about`)、`<I18nLink>` を `RouterLink` としてレンダリングします。ルートからのロケールの読み取りは自分で行い(たとえば `router.beforeEach` 内で)、`i18n.global.locale.value` を設定してください。`i18n.setRoutingStrategy(adapter)` で後からアダプターを設定することもできます。カスタムアダプターについては [ルーターアダプター](/ja-jp/integrations/overview#router-adapter) を参照してください。

## SSR {#ssr}

- ルーター、i18n インスタンス、アプリは、リクエストごとのレンダー関数の中で作成してください。インスタンスを 1 つ共有すると、ある訪問者のロケールが別の訪問者に漏れてしまいます。
- サーバーでは `createMemoryHistory()` を使用し、URL からロケールを取得して、`renderToString` の前にその辞書(およびフォールバックの辞書)を読み込んでください。
- ロケールをクライアントに送り(たとえば `window.__STATE__` スクリプトで)、ハイドレーションが一致するように同じ `locale` でクライアントインスタンスを作成してください。
- `<I18nSwitcher>` はドロップダウンが開いているときにのみ `window.location` を読み取るため、サーバーでもレンダリングされます。

`packages/vue/playground` には、`entry-server.ts` / `entry-client.ts` の完全なペアがあります。

## SEO head {#seo-head}

`useLocaleHead(options)` は、ロケールとルーターアダプターから、`lang`/`dir`、canonical、`hreflang`、`og:locale` のタグを構築します。ルートが変わったら `updateMeta()` を呼び出し、`metaObject` を head マネージャーに渡してください。

```ts
import { watch } from 'vue'
import { useRoute } from 'vue-router'
import { useHead } from '@unhead/vue'
import { useLocaleHead } from '@i18n-micro/vue'

const route = useRoute()
const { metaObject, updateMeta } = useLocaleHead({ baseUrl: 'https://example.com' })
watch(() => route.fullPath, () => updateMeta(), { immediate: true })
useHead(metaObject)
```

オプション: `baseUrl`(文字列または関数)、`addDirAttribute`(デフォルト `true`)、`addSeoAttributes`(デフォルト `true`)、`identifierAttribute`(デフォルト `'id'`)、`hreflangBaseLanguage`(デフォルト `false`)。`disabled: true` または `seo: false` のロケールには alternate リンクが付きません。
