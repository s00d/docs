`<i18n-t>` は 1 つの翻訳を要素としてレンダリングします。翻訳の中にコンポーネント(文中のリンクなど)を含める必要がある場合、複数形を使う場合、数値や日付をフォーマットする場合に使用します。`$t` と同様に、現在のルートに対してキーを解決します。

## Props {#props}

| Prop | 型 | デフォルト | 説明 |
| --- | --- | --- | --- |
| `keypath` **\*** | `string` | — | レンダリングする翻訳キー。 |
| `plural` | `number \| string \| null` | — | 複数形を選択する数。設定すると `$t` の代わりに `$tc` が使われます。`null` は未設定を意味します。 |
| `tag` | `string` | `'span'` | レンダリングする要素。 |
| `params` | `Record<string, string \| number \| boolean>` | — | 翻訳に代入される補間値。 |
| `defaultValue` | `string` | `''` | `hideIfEmpty` によって空の翻訳が抑制されたときに、コンポーネントの代わりにレンダリングされる値。 |
| `html` | `boolean` | `false` | 翻訳をテキストではなく HTML としてレンダリングします。自分で管理している翻訳にのみ使用してください。`params` はエスケープされますが、翻訳自体はエスケープされません。 |
| `hideIfEmpty` | `boolean` | `false` | 翻訳が空文字列に解決された場合、何もレンダリングしません。 |
| `customPluralRule` | `PluralFunc` | `null` | この要素にのみ適用される複数形ルールで、設定済みのルールを上書きします。その戻り値はそのまま使用され、`null` は空としてレンダリングされます。 |
| `number` | `number \| string \| null` | — | 値を `$tn` でフォーマットし、`params` とともに `{number}` として翻訳に渡します。 |
| `date` | `Date \| string \| number \| null` | — | 値を `$td` でフォーマットし、`params` とともに `{date}` として翻訳に渡します。 |
| `relativeDate` | `Date \| string \| number \| null` | — | 値を `$tdr` でフォーマットし、`params` とともに `{relativeDate}` として翻訳に渡します。 |

**\*** 必須。

## レンダリングルール {#rendering-rules}

最初に一致したケースが出力を決定します:

1. `number` — `{ ...params, number: $tn(number) }` を使った翻訳。
2. `date` — `{ ...params, date: $td(date) }` を使った翻訳。
3. `relativeDate` — `{ ...params, relativeDate: $tdr(relativeDate) }` を使った翻訳。
4. `plural` — `$tc` が選択した形式([`=0 ` マーカー](/ja-jp/api/methods#$tc)を含む)を `{ ...params, count }` で使用します。`customPluralRule` が設定されている場合は `customPluralRule(keypath, count, params, locale, t)` を使います。これはマーカーを含む生の値を読み取り、その戻り値はそのまま使用され、`null` は空になります。
5. それ以外の場合は `params` を使った翻訳。

`null` は未設定とみなされます。すべてのケースで次のようになります:

- どの分岐でも、キーが存在しない場合は `defaultValue` が代わりに使われます。
- `hideIfEmpty` は空の結果の代わりに `defaultValue` をレンダリングします。
- `html` は結果を HTML としてレンダリングします。`params` はエスケープされますが、翻訳はエスケープされません。スロットは無視されます。
- `default` スロットは `{ translation }` を受け取り、名前付きスロットは無視されます。
- それ以外の場合、各名前付きスロットは同名のパラメーターより先に、すべての `{name}` プレースホルダーを置き換えます。プレースホルダーのように見えるパラメーター値はテキストのままです。

`date` と `relativeDate` の出力には `data-allow-mismatch="text"` が付与されます。サーバーのタイムゾーンと時刻はブラウザーのものと異なるためです。[`timeZone`](/ja-jp/api/module-options#timezone) を設定すると、両方で同じ暦日がレンダリングされます。`relativeDate` は時刻に依存するため、それでも異なる場合があります。

## 例 {#example}

```json
{
  "terms": "I accept the {link}.",
  "termsLink": "terms of use",
  "items": "no items | one item | {count} items"
}
```

```vue
<template>
  <i18n-t keypath="terms" tag="p">
    <template #link>
      <NuxtLink :to="$localePath('/terms')">{{ $t('termsLink') }}</NuxtLink>
    </template>
  </i18n-t>

  <i18n-t keypath="items" :plural="cart.length" />
</template>
```

`html` は `innerHTML` を設定します。自分で管理している翻訳にのみ使用してください。`params` はエスケープされるため、ユーザーデータはそこでは安全です。翻訳が見つからなかったキーも同様に安全です。
